Volume rendering transforms raw scientific data into insightful images. It is an integral part of scientific visualization and crucial for analyzing complex data in physics, astronomy, biology, and medicine. By visualizing volume data, scientists can isolate and explore critical structures within the data, leading to novel insights and effective communication of intricate phenomena. However, the growing size and complexity of these datasets pose significant challenges to achieving efficient rendering. This dissertation addresses these challenges by incorporating machine learning into performance-critical components of traditional scientific rendering algorithms. These neural rendering approaches enable faster rendering, improve image quality, and reduce computational costs.This work introduces three novel techniques for neural rendering, each targeting a distinct stage of the rendering process. First, a neural post-processing model that operates in image space to reconstruct sparse and foveated framebuffers to significantly enhance the rendering performance of ray-marched volume rendering. Second, a neural radiance cache that operates in world space, learning spatial-directional radiance with phase function parameterization to enable real-time global illumination for path tracing. Third, an adaptive radiance cache that operates in path space and is designed to handle dynamic volume path tracing scenarios where scene parameters, such as lighting and transfer functions, frequently change.Together, these contributions improve rendering performance, quality, and adaptability across various applications in visualization. Each chapter of this dissertation addresses specific challenges in volume visualization, forming a cohesive set of tools that integrate machine learning to enhance rendering systems. As scientific visualization continues to evolve, I hope that my work inspires further exploration and adoption of neural methods to address emerging challenges and advance applications in the field
