Summary
Closes the renderer-parity gap left by PR #37: the Reactor theme now runs the same Gray-Scott reaction-diffusion simulation on WebGPU (the project's default renderer) as on WebGL2. Implements .claude/plan/05-reactor-webgpu-port.md. Largely mechanical — translates the GLSL shaders to WGSL and reuses the WebGPU render-texture / bind-group patterns already present in the codebase.
Implementation
REACTOR_STEP_WGSL — verbatim translation of FRAG_REACTOR_STEP. Reads the front RT via textureSample with a NEAREST sampler (the laplacian needs exact texel reads). 9-tap stencil unchanged.
REACTOR_SEED_WGSL — translation of FRAG_REACTOR_SEED. Uniform carries (resX, resY, count, _) + up to 8 disc entries as vec4 (16-byte stride alignment). Raises B to 0.9 inside each disc.
Pipelines — two GPURenderPipelines targeting rgba8unorm, compiled lazily on first reactor frame. Sampler + 1×1 dummy texture are eager because BG_WGSL now declares the reactor texture binding unconditionally — every frame's bg bind group must supply a valid texture even when kind != 8.
RT pair — two GPUTextures (rgba8unorm, RENDER_ATTACHMENT | TEXTURE_BINDING), half-canvas size, capped at 256×256. Initial fill via clear-render-pass (clearValue: (0.05, 0, 0, 1) → Gray-Scott equilibrium A=1, B=0). Re-allocates on size change, freed on theme switch.
BG_WGSL — gains @binding(1) reactorSamp + @binding(2) reactorTex + a kind == 8 display branch matching the WebGL2 acid-green ramp on the B concentration. Bind group is rebuilt each frame in drawBackground because the front-RT index ping-pongs and the view changes on resize.
drawBackground — kind ladder extended with reactor → 8. Execution sequence runs before the bg display pass: ensure RTs → maybe seed (every 10 s) → 5 step iterations → display pass.
Cleanup — destroy() frees RTs + uniform buffers + dummy. Sampler + pipelines persist (cheap; avoids recompiling on theme toggles).
