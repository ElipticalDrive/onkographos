# SOC 2025 — 3D Gaussian Splatting

Educational implementation of **3D Gaussian Splatting** (Kerbl et al., SIGGRAPH 2023) built from first principles.

## What this repo covers

| Module | Contents |
|--------|----------|
| `rasterization/` | Triangle rasterizer from scratch (perspective projection, z-buffer, Gouraud shading) |
| `gaussian_splatting/gaussian.py` | 3D Gaussian primitive with covariance from quaternion + scale |
| `gaussian_splatting/projection.py` | EWA projection of 3D Gaussians to 2D screen space |
| `gaussian_splatting/renderer.py` | Alpha-compositing renderer + tile-based variant |
| `gaussian_splatting/optimization.py` | Loss functions (L1 + D-SSIM), densification heuristics, training loop structure |

## Quick start

```bash
pip install -r requirements.txt

# Rasterization demo (coloured cube)
python rasterization/demo.py

# Gaussian splatting demo (sphere of 400 splats)
python gaussian_splatting/demo.py
```

Outputs are saved to `outputs/`.

## Key paper

> **3D Gaussian Splatting for Real-Time Radiance Field Rendering**  
> Bernhard Kerbl, Georgios Kopanas, Thomas Leimkühler, George Drettakis  
> SIGGRAPH 2023 — [arXiv 2308.04079](https://arxiv.org/abs/2308.04079)

## Algorithm in one paragraph

A scene is represented as N learnable 3D Gaussians, each with a position, orientation (quaternion), scale, opacity, and colour (spherical harmonics). To render a view, each Gaussian is projected to a 2D ellipse on the image plane using the local Jacobian of the perspective transform (EWA splatting). The resulting 2D Gaussians are depth-sorted and alpha-composited front-to-back. Gradients flow back through the differentiable rasterizer to optimise all Gaussian parameters simultaneously. Adaptive density control (clone / split / prune) during training lets the scene grow detail where needed.
