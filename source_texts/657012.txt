Sub-Tasks:
Use a noise generator to create a Heightmap of blocks for any given Chunk position/size.
Pass through created Heightmap to fill vertical spaces (ex: one block is two block spaces higher than an adjacent block, there'll be an empty space below it that the player can see through)
Figure out how to add water mesh
Completion Criteria:
Chunk's are populated according to terrainBuilder algorithms without any vertical gaps between adjacent blocks
Blocks have different Types assigned according to their heights when loaded to the Chunks
Blocks should be populated with their absolute world positions

The only inputs that REALLY matter are 1. the Seed you give to the constructor and 2. the position of the chunk passed to the getChunkBlocks() function
The output should always be EXACTLY the same if those two parameters don't change.
This means that the TerrainBuilder should take care of ensuring smoothness from one chunk to another as long as the two chunks are exactly one CHUNKWIDTH apart.
The output vector will have the heightmap blocks for the first WIDTH*WIDTH indexes (row by row) and should have the gapfilling blocks afterwards in order
Using the first WIDTH*WIDTH blocks in the vector, you should be able to see the highest block for any x-z coordinates in the chunk

Heightmap Generation Details:
NoiseType: Perlin Fractal
Parameters we might later change:
Frequency: 0.01 (default) [increasing this will make terrain more noisy]
Octaves: 3 (default) [increasing this will add noise at different frequencies]
see: https://www.redblobgames.com/maps/terrain-from-noise/ to understand octaves better
Parameters we probably won't change:
Fractal Type: FBM (Fractional Brownian Motion)
Lacunarity: 2.0
Gain: 0.5
