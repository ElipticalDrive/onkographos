Summary
Improve viewport orientation feedback, surface readability, and the first-run experience. Replace the manual orientation panel with an optional free-axis trackball mode.
Scope
Add a toggle between the existing turntable controls and free-axis Trackball/Arcball rotation.
Animate axis-widget and W/A/S/D/Q/E view changes from the current camera orientation to the target orientation over 300 ms instead of snapping.
Prevent browser drag/context cursor behavior while interacting with the viewport.
Render meshes fully opaque by default.
Add a screen-space depth + normal edge shader so uniformly colored RGB meshes retain visible shape detail.
Show an RGB/CMY colored cube before a PLY is loaded. Treat +Z as up and slowly auto-orbit the preview until the user first interacts with the viewport.
Acceptance criteria
Trackball mode permits roll and can be toggled without breaking view presets or the axis widget.
Preset/key transitions use a 300 ms linear orientation interpolation from the current camera to the requested view.
Pointer dragging does not trigger native page dragging, selection, or a context cursor/menu.
Mesh opacity defaults to 100%, with depth/normal edge enhancement available in the renderer.
The empty state displays a colored cube and auto-orbits around the Z-up axis only until first viewport interaction.
Unit tests, Pages build tests, and browser interaction checks pass.
