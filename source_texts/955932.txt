what Nerfs are will help frame particle Nerfs contributions neural Radiance Fields create a model of the world where each point in space is associated with a Radiance value and a density value to render the world from a particular Viewpoint rays are cast through each pixel of the image plane then points are sampled along the Rays and the radiance and density values are computed finally the radiance and densities of the sampled points are reduced into the pixel colors this process is differentiable and given multiple ground truth images taken from known poses the radiance and density Fields can be learned in such a way that realistic images and accurate depth maps can be rendered from viewpoints that were not part of the original training data different Nerf methods can often be distinguished by the manner in in which they map between points and space to radius values this map is often split into two components the first component referred to as the encoding Maps a 3D coordinate to a feature space of arbitrary Dimensions it is this part of the formulation that is often different between various Nerf architectures the second component Maps the feature from the encoding layer to Radiance and density values the choice of encoding has a large effect on the speed at which a Nerf is learned particle Nerf's contribution is in part in new encoding that is designed to quickly update the radiance field when motion occurs to observe the problem the online challenge presents to current encodings consider a Radiance field that has already been trained on a scene we will consider how two candidate encodings for the online setting behave when an object within the scene begins to move the first encoding we use is known as instant NGP this encoding devides the world into a grid and Associates with each corner of a feature of a predetermined dimension querying the radiance of an arbitrary point in space is a matter of interpolating the features from the surrounding corners and mapping the interpolated feature into a Radiance and density value using a neural network as the object moves the features associated with the corners need to be unlearned at certain locations and relearned at others although inin GP is designed for static scenes it is extremely fast and well optimized and is therefore a valid Brute Force strategy that could potentially work in an online setting in contrast the second encoding we consider is known as time aware neuro voxal and it is designed to learn Dynamic scenes albeit in an offline manner the tnv encoding is part of a body of work that seeks to capture 3D video we adapt this encoding to operate in an online setting methods like tnv utilize the concept of a canonical space as time changes and objects move the query points along array at a certain time are first morphed into the coordinate system of the canonical space this morphing is usually done by a Time conditioned neural network named a deformation Network the strategy of bending Rays removes the need to learn an unlearn features when movement occurs instead tracking movement is primarily done by learning the appropriate time conditioned deformation Network time aware neural voxal is one of the fastest methods that implement the strategy and is therefore a plausible candidate that could be ported to the online setting particle Nerf's main Insight is that when movement occurs in the scene it is easier for the Learned features to move rather than to relearn to facilitate this instead of associating features with a locked regular grid we instead associate them with particles in Space the positions of the particles are optimized together with the associated features to query the encoding at an arbitrary coordinate features from the neighboring particles are collected those features are then weighted by a gaussian that decays with distance the weighted features are then summed together the resulting interpolated feature is given to a neural network from which Radiance and density values are computed because the queried feature depends on the distance of the particles and not their explicit coordinates a collection of particles that is translated or rotated will continue to represent the same geometry the particles in our encoding are all also associated with the velocity and they are acted upon by a particle-based physics system that is responsible for all particle movements when the gradients of the Reconstruction loss relative to the particle positions are calculated they are interpreted as velocity impulses which are ultimately resolved by a physics Loop the physics system also provides a means with which we can add physical priors directly to the particles in particle Nerf we add a collision constraint that gives particles a physicality and removes the possibility of multiple particles occupying the same space our results show the particle Nerf is capable of learning a 3D scene and that the particles tend to follow an object as it moves in this scene an object is being observed by 10 cameras the particle encoding is continuously being trained on The observed images we continuously render
