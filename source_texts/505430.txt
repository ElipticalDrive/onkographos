Hit-testing mixes CSS pixels with device pixels.
projectedRef holds points in canvas backing-store pixels. The resize handler sizes the canvas as innerWidth * dpr, and the draw loop scales every coordinate by dpr. findVenueAt compares clientX - rect.left in CSS pixels against those points. When devicePixelRatio is above 1, hover and click hit the wrong venue. At dpr 2, the click target is displaced by a factor of two. The pan handler at line 258 already applies dpr.
Scale the pointer position by canvas.width / rect.width. The bounding box of a diamond also overlaps neighbouring footprints. Use a point-in-polygon test instead.

-    const x = clientX - rect.left;

+    const x = (clientX - rect.left) * (canvas.width / rect.width);
