Hi, I've digged into the code and solved it. If system locales are set to some European languages sscanf expects float number to contain a coma instead of a point. See https://stackoverflow.com/q/13489940/7708542 for reference. The simplest solution is to run LC_ALL=en_US ./inviwo.
