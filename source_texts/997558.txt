Parent roadmap: #482 · Milestone: PP-05 · Source baseline: develop@b4476062ea89e14acc3f5c9a6509caa3e7075eaa (repin before implementation) · Status: PLANNED / NOT IMPLEMENTED.
Exclusive code owner: COLOR. Paths: Source/Renderer/PostProcessing/Color/**. Dependencies: PP-04. Shared graphics ABI, FrameGraph, GRDG, ShaderCooker, and native drivers remain their existing owners; never introduce a second GPU scheduler or canonical asset registry. No new branch is authorized.
Complete implementation
Implement COL01–COL04 and COL09–COL13: ACES-fit, AgX-style, neutral/custom/local maps; SDR and qualified HDR10/scRGB/HLG surface output; exactly one transfer and gamut transformation.
Acceptance and negative cases
Color ramps, monotonic response, no double transfer, SDR-only swapchain, metadata/monitor change, UI paper-white and white point. Ship legal cooked variants for each planned era (M/C/P/L/X/F); report every unsupported variant with an explicit reason. Include exact-SHA C++17 CMake/CTest/GoogleTest/Clang23 AST, pinned formatter, 100% achievable CPU line/branch/function coverage, and real backend GPU image tests where claiming native execution. No placeholder-only closure, no native hardware PASS from a mock.
Cross-system rules: sealed memory, no STL threading; shared scene/material/mesh/BVH resources, canonical GRDG authority, FrameGraph-only pass scheduling, native backend device ownership. Retain existing effect-specific producers in GI/FOG/Shadows/Shader rate issues.
