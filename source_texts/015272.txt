Efficient and Compact Grid Structures for Enhanced Ray Tracing Performance
DESCRIPTION
This paper presents innovative acceleration structures for ray tracing, focusing on compact and hashed grid methods that optimize both build and render times. The compact grid offers linear build time and optimized memory usage by minimizing the memory footprint, making it suitable for dynamic scenes and large models. The hashed grid further reduces memory usage and enhances traversal efficiency. Comparative results illustrate significant improvements in performance metrics over traditional grid data structures, paving the way for future advancements in hierarchical grid frameworks and other acceleration techniques.
