Summary
This PR extends the Minecraft 26.1 rendering module with an occlusion-culling framework and GPU-side rendering infrastructure. It adds an OpenGL samples-query backend, Hi-Z depth-processing foundations, feature-submit filtering, and compute/texture capability plumbing.
Changes
Added OcclusionCuller, OcclusionKey, OcclusionMethod, culling statistics, and wrapped submit-node storage.
Added automatic backend selection with Hi-Z, GPU Query, and no-op implementations.
Added pooled OpenGL samples queries, AABB query rendering, frustum pre-pass support, and one-frame-latency result reads.
Added visibility filtering for vanilla and NeoForge block, model, item, flame, leash, name-tag, particle, shadow, text, and custom feature renderers.
Added padded R32F depth conversion and FidelityFX SPD mip-chain foundations.
Refactored compute pipelines to use named resource layouts and ordered binding allocation.
Added explicit texture, image, buffer, atomic-counter, and bindless image-array bindings.
Added GPU capability reporting, extended texture formats, OpenGL texture allocation, and ARB bindless texture handles/residency scopes.
Added reusable GPU resource pools, transform/size UBOs, rendering debug options, and development JVM arguments.
Updated ApiStatus.Internal placement and sync-module imports.
Added the test_occlusion block, block entity renderer, generated assets, and compute-test binding updates.
