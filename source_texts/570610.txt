Motivation
A structural ray-generation program such as:
```
rt::RayTracer<ProgramLayout> tracer;
tracer.trace(desc, scene, program, payload);
```
fails for -target cuda/-target ptx before code generation because the structural trace capability and lowering dispatch omit CUDA. This blocks the structural Cornell-box pipeline on OptiX.
Proposed solution
Treat CUDA as another consumer of the existing portable structural ray-tracing lowering. That path already converts structural trace and stage-input operations into the native ray-tracing IR consumed by the CUDA/OptiX emitter.
Change summary
Admit CUDA in the structural trace capability.
Run portable entry-point synthesis, trace lowering, and stage-input lowering for CUDA targets.
Add CUDA code-generation coverage to the complete triangle hit/miss integration test.
Update the structural coverage manifest.
Concepts and vocabulary
Portable structural lowering: the target-independent adapter synthesis used by native ray-tracing pipeline targets before their existing backend legalization and emission.
Structural stage input: a property operation such as payload, world-space ray data, or primitive index that is replaced with the native stage ABI value.
Process report
The exact input shape is a IRStructuralRayTracingTrace produced from RayTracer.trace, plus synthesized structural stage adapters decorated with IRStructuralRayTracingEntryPointInfoDecoration. This is the canonical representation used by D3D and Vulkan, not an accidental CUDA-specific spelling. CUDA already emits the native operations produced by lowerPortableStructuralRayTracingOperations and lowerPortableStructuralRayTracingStageInputOperations; the target predicate was the missing routing decision.
No new CUDA representation, emitter special case, or fallback was added. The integration test fails at capability checking without this change and emits optixTrace plus native raygen/miss/closest-hit entry points with it. Structural callable dispatch remains unchanged because it is a separate operation and is not exercised by this pipeline.
