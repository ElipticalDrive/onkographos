Motivation
Provide a lightweight browser prototype of a voxel world so users can run a simple Minecraft-like demo in the browser.
Ship a minimal first-person interaction model (pointer-lock, movement, block placement/removal) to explore core gameplay mechanics.
Include a small, documented example that can be served from the repo root for quick local testing.
Description
Add index.html with HUD, crosshair and a module entry for the demo.
Add main.js implementing a voxel world using Three.js and PointerLockControls, including world generation (64×64 base layer), raycast-based block highlighting, left-click removal and right-click placement, WASD + Space/Shift movement, and basic movement clamping.
Add style.css for HUD and crosshair styling and global layout rules.
