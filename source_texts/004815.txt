Abstract
The pre-integrated volume rendering technique is widely used for creating high quality images. It produces good images even though the transfer function is nonlinear. Because the size of the pre-integration lookup table is proportional to the square of data precision, the required storage and computation load steeply increase for rendering of high-precision volume data. In this paper, we propose a method that approximates the pre-integration function proportional to the data precision. Using the arithmetic mean instead of the geometric mean and storing opacity instead of extinction density, this technique reduces the size and the update time of the pre-integration lookup table so that it classifies high-precision volume data interactively. We demonstrate performance gains for typical renderings of volume datasets.

Introduction
Pre-integrated volume rendering is a technique for reconstructing the continuous volume rendering integral [1], [2], [3], [4], [5]. Assuming linearity of the volumetric function along a ray and using a preprocessed lookup table (called pre-integration table), this method eliminates a lot of artifacts in discrete volume sampling and reduces the sampling rate for rendering. The pre-integrated volume rendering defines the color and the opacity of one fragment using two consecutive sample values as an index for the pre-integration table constructed before rendering for a given classification function (Fig. 1).
The original pre-integration table is indexed by three integration parameters: two consecutive sample values and the distance between them. As the table is three-dimensional, it requires a huge amount of storage. To reduce memory consumption and accelerate the pre-integration step, Engel et al. reduced the dimensionality of the table from three to two by assuming a constant sampling distance [1]. However, the table is still bulky when we deal with high-precision data such as 12 bits per voxel data, which are common in medical applications. A 12-bit volume dataset requires 256 times more memory and update time than an 8-bit volume dataset.
In this paper, we present a new approximation technique to reduce the dimensionality of the table from two to one, and compare the error introduced by the approximation with that of existing methods. We consider the precision problem of data types, which is important because supported data types are limited on graphics hardware, for pre-integration accumulation. Our method reduces table size dramatically for high-precision volume data. The proposed method can be performed in real-time even when handling high-precision volume data.
The Section 2 is dedicated to review of existing pre-integrated volume rendering techniques. In the Section 3, we explain the proposed method in detail and analyze the mathematical error of the method. Section 4 provides the experimental results.

Conclusion
We describe a method for approximating the pre-integration function. Using arithmetic mean instead of geometric mean, our method takes O(n) time and memory consumption. Thus, we can generate the pre-integration table in real time for high-precision volume datasets such as medical datasets. By storing opacity instead of extinction density, we can limit each table value and guarantee the accuracy of the arithmetic operation for the pre-integration table.
