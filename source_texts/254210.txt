Motivation
Add a new canvas 2D point-cloud effect that forms a recognisable hand silhouette using a signed distance field (SDF) and deterministic iso-surface sampling for stable visuals and audio-reactive behavior.
Keep the effect self-contained and reuse the existing 3D helpers and sphere-cloud rendering style so it fits the engine without new subsystems.
Description
Add src/renderer/effects/handSdfCloudEffect.ts which implements SDF primitives (sdSphere, sdCapsule, sdRoundBox), sdHand (palm, fingers, thumb + smooth unions), deterministic lattice sampling with hash3, normal estimation via finite differences, and a renderer that lights, rotates, projects and draws glowing points.
Build and cache the point cloud once via buildHandCloudPoints() (store normals, hue seed and deterministic seed) and expose handCloudBounds for tests.
Register the effect as handcloud in src/renderer/effects/index.ts, add debug controls for speed, scale, density, and gesture in src/renderer/debug/effectDebug.ts, and document the new entry in the README Effect catalog.
Add deterministic unit tests src/renderer/effects/handSdfCloudEffect.test.ts that assert stability, point count range, bounds and normalized normals.
Testing
Ran the test suite with npm run test (Vitest) and all tests passed: 74 tests, 74 passed including the new handSdfCloudEffect tests.
Verified deterministic point count with a quick script: buildHandCloudPoints() produces 7306 points with the chosen defaults and constants (bounds x[-1.8,1.2], y[-0.8,2.2], z[-0.9,0.9], grid 44×56×30, threshold 0.05).
