Parent: #489
Priority: P2
Parallel lane: GPU silhouette sampling, glow, and outline
Summary
Move glow and outline generation from CPU silhouette dilation and derived surfaces into GPU sampling/passes. Preserve the exact visibility and ownership rules for local-player outlines, visible/occluded actors, exits, and other annotated map objects.
Scope
Pass source texture, effect parameters, outline color/width, glow color/intensity, and deterministic phase/seed data through the reviewed GPU effect contract.
Implement a bounded fragment-neighbor, mask, or extra-pass design that handles transparent/color-key pixels, atlas padding, clipping, transforms, stretching, and fractional scale without sampling neighboring sprites.
Preserve current pulse/randomization semantics as a deterministic shader input or explicitly reviewed visual-contract change; do not introduce frame-dependent nondeterminism.
Keep CPU authority for whether an outline or glow is allowed. Occluded/hidden entities must not become visible because a neighboring sample is shaded.
Eliminate per-frame CPU silhouette walks and processed glow/outline surfaces after warmup.
Acceptance criteria
Glow and outline fixtures match the reviewed contract for normal, alpha, animated, rotated, zoomed, stretched, atlas-edge, clipped, and multi-depth sprites.
Local-player and visible/occluded monster/NPC outline behavior remains correct with fog-of-war and remembered-world rules.
The steady-state path has no per-sprite CPU mask dilation, surface allocation, or processed-texture upload for these effects.
Neighbor sampling is bounded, clamps to the sprite/atlas boundary, and cannot bleed pixels from adjacent resources.
GPU cost, pass count, overdraw, temporary targets, and retained memory are measured on the motivating dense scene.
Resource reset, failure, and unsupported-parameter paths remain atomic and GPU-only.
Dependencies and coordination
Blocked on the effect ABI and can proceed in parallel with simple effects, transforms, stretching, and projected-light lookup. Coordinate mask/owner semantics with the living-occlusion child; if a shared coverage pass is introduced, document ownership so two agents do not implement incompatible silhouette paths.
Validation
Add deterministic shader/golden tests and dense roof/actor fixtures. Run the client build/test workflow and warm/cold production-path measurements with atlas padding and clipping cases.
