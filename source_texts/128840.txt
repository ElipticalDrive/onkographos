Area
renderer
Requirement
Split from #161 (authored CameraComponent). The component stores/edits/serializes projection and orthographicSize, but the production render path still projects every camera as perspective: command_buffer_flush.cpp and its consumers — shadow cascade splits, SSAO/post radius scaling, light-culling frustum math — all assume fovRadians. Authors selecting Orthographic today get perspective output (documented in the component tooltip and CLAUDE.md).
Acceptance criteria
An orthographic authored camera renders orthographically end to end: correct projection matrix through the flush path, shadow cascades computed from the ortho frustum, SSAO/post radii scaled sensibly, light culling using the ortho volume. CPU-verifiable projection/culling tests plus a gpu-labeled smoke; determinism suite green.
Constraints and cut lines
Do not wire partially — a half-converted consumer set produces silently-wrong rendering, which is why #161 deferred this whole. 2D-style features (pixel-perfect zoom, etc.) stay out of scope.
Origin
#161 closure report, 2026-08-17.

Closed by #260 (merged 4829a22, 2026-08-19). Evidence per the closure contract:
Projection kind reaches the renderer: CameraEntry and renderer::CameraState carry projection/orthographicSize; engine_unit_command_buffer pins the state round-trip and that camera_projection_matrix reproduces math::ortho/math::perspective exactly per kind.
One projection builder serves flush, render-prep CPU culling, scene captures, and the editor frustum gizmo — culling can no longer disagree with rasterization. engine_unit_light_culling proves tiled culling honors an ortho volume.
Cascaded shadows: near/far now passed explicitly; the old perspective-only matrix recovery is deleted. Red-on-base evidence: reinstating that algebra makes the new engine_unit_shadow_map corner-containment case fail (exit 92); fixed revision passes.
Lighting view vector under ortho: constant camera forward via uCameraForwardOrtho (forward + deferred). Sky keeps perspective directional sampling by design (documented — parallel rays would sample one sky direction).
Authoring: Lua add/get_camera_component projection kind + size, validated (engine_unit_scripting); struct CameraManager::evaluate snaps kind, lerps size (engine_integration_camera); gpu smoke ortho_camera_render_test renders authored-ortho frames on a real device.
Scope: editor viewport lens, SceneCaptureComponent projection, and fog falloff deliberately unchanged (pre-existing, documented in the PR). Camera-arbitration findings filed separately as [P3][Audit] Viewport camera arbitration is implicit across pause and debug-detach modes #259.
Platform scope: all 6 canonical lanes + MSVC/GCC compat, determinism, ASAN/UBSAN, TSAN green on the PR (18/18).
