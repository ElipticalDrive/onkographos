# Interactive DICOM Viewer

This project is a lightweight tool for reading, sorting, and visualizing DICOM series (CT or MRI) directly within a Jupyter Notebook. It stacks individual `.dcm` files into a 3D volume and provides an interactive interface to scroll through slices.

## Features

* **Automatic Sorting:** Reads a folder of mixed `.dcm` files and sorts them anatomically based on the `ImagePositionPatient` (Z-axis) metadata.
* **Volume Stacking:** Converts the sorted slices into a unified 3D NumPy array.
* **Interactive UI:** Uses `ipywidgets` to allow real-time scrolling through the volume.
* **Windowing Control:** Includes sliders to adjust minimum and maximum intensity (brightness/contrast) for better visualization of different tissue types.

## Requirements

You will need the following Python libraries:

* `pydicom`
* `numpy`
* `matplotlib`
* `ipywidgets`

To install them, run:

```bash
pip install pydicom numpy matplotlib ipywidgets
```

## Usage

1. Clone this repository or download the notebook.
2. Place your DICOM files in a folder named `recon` inside the project directory (or update the `dcm_path` variable in the code to point to your data).
3. Start Jupyter Notebook:

```bash
jupyter notebook
```

4. Run the cells. The output will generate an interactive widget with sliders for Z-axis navigation and intensity adjustment.

## Configuration

* **File Path:** Looks for `./recon` by default.
* **Sorting Order:** The code currently sorts in reverse order (`reverse=True` in the lambda function) to handle standard head-to-toe ordering. You can toggle this if your slices appear backward.

* ## Performance & Optimization

* **Fast Parameter:** The tool supports a `Fast` parameter configuration. You can toggle this setting to optimize CPU and GPU resource allocation, allowing for smoother rendering and faster processing times depending on your hardware capabilities.

## Environment & Standalone Usage

This tool is built with `ipywidgets` and is specifically intended to run in **Jupyter Notebook** environments (JupyterLab, Google Colab, VS Code Notebooks).

If you wish to run this code as a standalone Python script (e.g., via `python main.py` in a terminal), `ipywidgets` will not render the sliders. In that case, you should modify the visualization section to use `matplotlib.widgets.Slider` instead. The data loading and sorting logic remains the same.

## Notes

This viewer renders **raw pixel data**. While this is sufficient for visual inspection, it does not currently apply the `RescaleSlope` and `RescaleIntercept` linear transformation required to get true Hounsfield Units (HU).
