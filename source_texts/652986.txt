# WebGL Phong Illumination

An interactive WebGL 2.0 application implementing the Phong illumination model with both Gouraud (per-vertex) and Phong (per-fragment) shading. Developed from the $21^{st}$ of November 2024 to $2^{nd}$ of December 2024.

**Authors:** Gonçalo Mourão - Gustavo Sousa

---

## Overview

This application renders a 3D scene with a single user-selectable object lit by up to three configurable light sources. All scene parameters — object geometry, material, lighting, camera, and render options — are controlled through a `dat.gui` interface in real time. The entire scene configuration (objects, lights, camera) is loaded from JSON files at startup, making the application data-driven.

---

## Features

- **Two shading modes** switchable per object: Gouraud (lighting computed per vertex in the vertex shader) and Phong (lighting computed per fragment in the fragment shader)
- **Three independent light sources**, each defined in a different coordinate frame: world, object, and camera
- Each light can be toggled active/inactive, switched between point and directional, and have its ambient, diffuse, and specular intensities set independently
- **Perspective camera** controlled by mouse drag (orbital, locked to origin) and scroll wheel (fovy); near/far adjustable via GUI
- Toggleable **back-face culling** and **depth buffer**
- Optional **light source visualisation** — small coloured spheres drawn at each active light's position
- Seven selectable object geometries: Cow, Bunny, Cube, Cylinder, Pyramid, Sphere, Torus
- Per-object material controls: Ka, Kd, Ks (RGB, 0–255 in GUI, normalised to [0,1] for shaders), and shininess
- Wireframe overlay toggle
- Optional helicopter ambient sound
- Scene graph, lights, and camera loaded from external JSON files

---

## Interface Layout

| Panel | Location | Contents |
|---|---|---|
| Object controls | Top-left | Primitive selector, transform (position X/Z, rotation Y, scale XYZ), material (shader, Ka, Kd, Ks, shininess) |
| Scene controls | Top-right | Options (animation, sound, wireframe, backface, z-buffer, view lights), camera (fovy, near, far, eye/at/up readouts), lights (world, object, camera) |
