Goal
Reemplazar el sphere/enhanced-sphere tracer por Segment Tracing (Galin et al. 2020), que aprovecha cotas Lipschitz locales por primitiva para avanzar segmentos enteros en lugar de pasos puntuales. Reportado 2-5× más rápido que ESL en SDFs de CSG analítico — exactamente nuestro caso de uso.
Approach
Sphere tracing avanza `d` (distancia al campo). Segment tracing avanza `d / λ` donde `λ` es la constante de Lipschitz local del SDF en la región actual. Para primitivas analíticas (sphere, box, capsule, etc.) `λ` es trivial de derivar en cerrado.
Para CSG `min(a, b)`: `λ_csg = max(λ_a, λ_b)`.
Para smooth blend: `λ_smooth ≈ λ_a + λ_b` (cota conservadora).
```
// Pseudo-WGSL:
let d = sdf(P);
let lambda = sdf_local_lipschitz(P);  // ← clave: cota local, no global
let safe_step = d / lambda;            // garantizadamente no atraviesa
P += dir * safe_step;
```
Para una sphere de radio `r`, `λ = 1` (gradient unitario). Para un torus, `λ` es función del punto. La estimación local — no global — es lo que hace que segment tracing sea estricamente mejor que sphere tracing.
Paper: https://hal.science/hal-02507361 (9 páginas, abierto).
Tareas
Auditar primitivas SDF en `crates/ome_ecs/src/sdf_*.rs` y derivar λ local para cada una. Documentar en cada componente.
Extender el shader para evaluar `(d, λ)` por primitiva en lugar de solo `d`.
Implementar la combinación de λ para CSG operations (min/max/smooth).
Reemplazar el step de ESL (feat(render): enhanced sphere tracing (Keinert 2014) — fix concave-neck convergence #222) por el step de segment tracing.
Mantener ESL como fallback si la heurística de λ falla en alguna región.
Benchmark exhaustivo vs ESL en escenas de stress (CSG profundo, muchas primitivas).
Acceptance Criteria
Frame time disminuye 2× o más vs ESL (feat(render): enhanced sphere tracing (Keinert 2014) — fix concave-neck convergence #222) en escena de `TestEngine2.0`.
Cero artifacts nuevos comparado con ESL — segment tracing es strict improvement.
Cada primitiva SDF documentada con su fórmula de λ local en docstring.
Tests unitarios verifican monotonía: `segment_step <= sphere_step` siempre.
Notas
BLOQUEADA por feat(render): enhanced sphere tracing (Keinert 2014) — fix concave-neck convergence #222 (ESL): ESL es el baseline que segment tracing reemplaza. Implementar ESL primero, validar artifacts resueltos, luego sumar segment tracing como optimización pura de performance.
Combinable con feat(render): adaptive epsilon — eliminate distance-dependent shimmer + iteration waste #223 (adaptive epsilon).
Cuando se llegue a esta issue, evaluar si segment tracing reemplaza ESL completamente o coexiste como modo opcional para SDFs analíticos.
