Change
Mesh::ray_crossings and InsideIndex decided whether a ray crosses a triangle with a Möller-Trumbore test using half-open barycentric bounds (u in [0, 1), u + v < 1). Those bounds depend on each triangle's own vertex order, so a ray through an edge shared by two triangles was counted in both or in neither.
The bracket example's hole centre falls on a diagonal of the base's top triangulation, so it was counted 0 or 2 times where it should be once, and bracket_example_cuts_two_through_holes_and_reopens failed.
Both now use one watertight test, ray_crosses:
The side of the ray each edge lies on is the signed volume dir · ((p − o) × (q − o)). This value is exactly antisymmetric in floating point, so the two triangles that share an edge see it with opposite signs.
A ray lying exactly on an edge's line is assigned to one side by the edge's endpoints in lexicographic order, the same for both triangles.
