As a side note, I want to point out two things:
While the algorithm in the paper is guaranteed to be watertight, it is only for the case when det = 0 returns false. The code in this PR that does edge intersection in this PR may not be watertight.
There is also a question of intersection of a ray with a bounding box that may result in false negatives. See this paper for example (I think they fix it by extending each box by 2 ulp in each direction). So may need some more work for robustness.
