Repeated native math and rendering algorithms now share GLM kernels, and camera, culling, visibility and stream-allocation queries return complete values. This removes output-parameter APIs, manual scratch partitioning and repeated channel/index arithmetic across model generation, mesh submission, visibility and pixel conversion.
Model generation shares position transforms, planar mapping and ordered quad emission. Camera projection returns a named result; unprojection returns an optional value.
Culling owns its selected triangles, vertex list and inverse remap. Renderer gathers, rebasing, copied vertex streams and stable radix passes use shared typed operations; allocation and binding return complete records.
Eleven packed-pixel conversions share byte-addressed iteration and channel extraction. Native pixel-format lookup returns a value, and YUV math uses GLM.
Mesh visibility returns owned ordered polygons and quad cells instead of global fixed-capacity buffers. Octree collision and occlusion share optional GLM plane contacts; dominant-axis classification and triangle/frustum plane construction have canonical implementations.
Framebuffer accumulation uses GLM channel vectors instead of four repeated scalar operations. SDL GPU vertices/uniforms use typed GLM fields with exact layout assertions; fetching returns complete values, and row/column transfers share one implementation. Unused abort-only MMX methods are removed.
Preserves triangle order, active-index duplicates, stable equal-key sorting, pixel lookup/scatter rules, packed shader layouts and the distinct one-unit collision/five-unit occlusion policies. Related fixes reject projections outside the clip range, skip empty software visibility submissions, remove the 20,000-cell visibility cap, classify degenerate prop normals deterministically, and avoid null/invalid buffer address arithmetic. Empty device transfers remain clean.
Validation: focused geometry, renderer, pixel/surface and record fixtures passed at batch boundaries; changed-source include hygiene passed. Actual old/new UBSan comparisons covered 4,574,448 procedural vertices, 400,000 camera queries, 90,000 culling/filter cases, 275,000 pixel conversions, 230,000 visibility cases, 5,000 stable sorts, 15,000 index gather/rebase cases, 25,000 accumulation operations and 25,000 device transfers. GPU fetch comparisons and independent null/unaligned cases covered 80,000 vertices.
Linux, ASan and include-hygiene CI passed for preceding head 4111f58; the final accumulation/GPU addition will run the same CI. Relaxed plus experimental semantic jscpd scans guided and rechecked the changes. Their counts include declaration/semantic false positives and do not prove that the overall 500-duplicate goal is complete.
