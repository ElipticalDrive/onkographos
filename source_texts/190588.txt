Session 2 of the Hunyuan3D-2.1 MLX port (#989): latent → occupancy field → mesh.
What landed
fusion_mlx/threed/shape_vae.py — ShapeVAEDecoder (post_kl + 16 self-attn blocks with per-head affine LayerNorm qk-norm) + GeoDecoder cross-attn SDF head (Fourier-encoded query points, K/V from ln2(latent)). decode_volume builds the (res+1)^3 scalar grid by chunked geo queries.
fusion_mlx/threed/marching_cubes.py — pure-numpy Lorensen–Cline marching cubes (ported from ddalcu/mlx-serve zig). Inside-positive sign, CCW-outward winding via global vote, per-vertex −∇field normals, OBJ export.
Forward ported from ddalcu/mlx-serve src/hunyuan3d.zig (VaeBlock + GeoDecoder + fourierEmbed) and src/marching_cubes.zig.
Correctness fixes vs the initial draft
Verified against the zig reference + real vae.safetensors keys:
scale_factor: divide (not multiply) — reference applies latents / scale_factor before post_kl.
Fourier: raw 2^k frequencies, no π (reference comment + test confirm).
q_norm: per-head affine LayerNorm(head_dim) with weight+bias (the draft omitted it; checkpoint ships both q_norm.weight and q_norm.bias).
q/k/v bias: QuantizedLinear(bias=False) — the checkpoint ships no linear .bias for q/k/v (only quant biases); out/mlp keep bias=True.
geo forward: ln1 pre-attn on q_emb, ln3 pre-mlp, ln_post final; ln2 used only for K/V prep (the draft misused ln2 in the residual path).
Tests
9 new (Fourier shape+freqs, VAE structural forward, geo module structure, MC sphere closed-manifold Euler=2, outward normals, empty grid, two-sphere Euler=4, real-weight load+forward, decode_volume pipeline → OBJ). All 13 threed tests pass; ruff + black --check clean.
Status
Real mesh extraction needs a DiT-sampled latent (Session 3, not yet ported); random latents stay negative (empty mesh), so the pipeline test asserts the grid is finite + MC runs without error, not mesh non-empty. Remaining sessions: S3 MoE DiT + flow-match, S4 texture paint UNet, S5 /v1/3d/generate API + EnginePool E2E.
