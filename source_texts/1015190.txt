Summary
Spherical harmonics (SH). worker/pipeline/train.py trains degree-3 SH instead of one fixed color per Gaussian, so highlights on glossy surfaces move as the camera orbits. The degree rises from 0 to 3 over the first tenth of the run, as gsplat's reference trainer does. Spark already renders up to degree 3, so the viewer needs no SH change.
Two export formats.
.ply keeps the SH fields (f_rest_*) and stays the Download button's file, because it is lossless and every splat tool reads it.
.spz (Niantic's compressed format) is what the viewer loads. worker/pipeline/spz.py writes version 3 with numpy and gzip, following Niantic's reference encoder, since that encoder has no Python bindings.
Web.
New nullable jobs.result_spz_s3_key column (migration 0010), set by the worker's completion callback.
The owner page loads the .spz through the new web/app/api/v1/splats/[splatId]/viewer-splat/route.ts, and the public preview page through getPublicSplat.
/download still serves the .ply. There is no .ply fallback for the viewer, because no splats exist yet.

One of four degree-3 runs had large floaters in front of the thumbnail's camera. The other three were clean. There was only one degree-0 run to compare against, so it isn't known whether SH causes them.
Test plan
worker:check, web:check, biome:ci, and the worker and web test suites pass.
worker/tests/test_spz.py decodes the .spz and checks every attribute against its quantization step, including a far-away point that lowers position precision instead of wrapping.
The .spz renders in the viewer, upright and framed by the capture's cameras.
Spark renders a file written at 10 fractional bits identically to one written at 12.
Check highlights on a glossy capture, and frame rate on a phone.
