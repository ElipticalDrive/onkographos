What this does
Task S2. `reconstruct.image_to_mesh(rgba, seed, device)` turns a cutout into a vertex-coloured `trimesh.Trimesh` on CPU. The same code runs on CUDA.
TripoSR is vendored under `src/sketch2shape/vendor/tsr/` at upstream commit 107cefd, with its MIT licence and a `SOURCE.md` listing every change.
`torchmcubes` is replaced by scikit-image marching cubes. A sphere test caught inward-facing triangles in my first version, so the face winding is now tested.
The checkpoint's ViT keys are renamed at load time. The locked transformers 5 uses different layer names than the 4.35 checkpoint.
The DINO config is inlined, so a run needs no network once weights are in place.
Grid is 192 on CPU and 256 on CUDA, one `resolution` argument.
`scripts/download_weights.py` fetches TripoSR, SD 1.5, ControlNet scribble and rembg isnet-general-use into `weights/`. I ran it for TripoSR and rembg. The SD 1.5 and ControlNet file lists match the repo listings, but I have not downloaded them.
Measured on an M2 MacBook Air CPU
One chair image, seed 1, one run each. Rows 1 and 2 in `EXPERIMENTS.md`.

No CUDA run yet. That needs the pod.
TripoSR's native frame has Z up and the front on +X. `finalize_mesh` in S3 has to apply `(x, y, z) -> (y, z, x)`.
Heads-ups for other owners
`pyproject.toml` gets a ruff exclude for `src/sketch2shape/vendor`.
New shared helper `src/sketch2shape/weights.py` gives every stage the weights paths. Udit, set `REMBG_HOME` to `rembg_home()` and load SD with `safety_checker=None`, because the download skips that folder.
No contract in `types.py` or `docs/api.md` changed.
