Motivation
Provide an optional post-rotation stage that snaps Kabsch-rotated node coordinates onto an exact uniform rectilinear lattice (spacing = L already produced by Kabsch) so exported hexahedra become exact axis-aligned boxes for rectilinear validation.
Keep existing rotation-only behavior unchanged when :snap is not requested and refuse :snap for non-Kabsch methods to avoid ambiguous/invalid operations.
Description
Parse colon-delimited --op align_axes:<method>[:<modifier>...] tokens with SplitColonTokens, enable snap when present, and reject unknown modifiers or snap with non-kabsch methods (usage error).
Implement snapping data structures SnapAxisResult and SnapResult and a SnapAxis helper that assigns integer plane indices, fits a single phase per axis using the existing L, and computes max_residual, max_plane_spread, and unique_planes for each axis.
Wire snapping into the kabsch apply path strictly after the rotation is applied to all exported nodes and before export: run per-axis fits, enforce the SNAP_SEP = 0.25 * L separability guard, check per-element plane counts to detect collapse (cells_collapsed) or multi-plane cells (cells_nonunit), and only then write snapped coordinates phase + k*L back to nodes.
Emit diagnostics under the mesh.align_axes.snap.* namespace when snap is on and print mesh.align_axes.snap=off when not requested; update CLI help and README.md to document align_axes:kabsch:snap behavior and failure modes.
Add/modify tests to cover snap success and negative usage: extended MESHPP/tests/run_apply_pipeline.sh to validate snap=on diagnostics and MESHPP/tests/run_negative_cases.sh to reject :snap with simple/pca.
Testing
Built the tool with make -C MESHPP which succeeded.
Ran the CI script ./MESHPP/tests/ci.sh which completed and reported the pipeline checks and negative checks as PASS.
Updated unit/integration test scripts MESHPP/tests/run_apply_pipeline.sh and MESHPP/tests/run_negative_cases.sh to exercise align_axes:kabsch:snap and invalid modifier cases, and these tests passed in the CI run.
