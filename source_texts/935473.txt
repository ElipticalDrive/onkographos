Cost of a 64-bit virtual address space
BIGGER POINTERS
n Pointers must be 64 bits (8 bytes) instead of 32 bits:
v Significant impact for pointer-intensive programs!
n Pointer intensive programs suffer from:
v Reduced effective L1/L2/TLB cache sizes
v Reduced effective memory bandwidth
v Increased alignment requirements, etc
n Pointer intensive programs are increasingly common:
v Recursive data structures (our focus)
v Object oriented programs

Impact of Type-Homogeneity/safety
n Compression requires rewriting structures:
v e.g. malloc(32) à malloc(16)
v Rewriting depends on type-safe memory accesses
n We can’t know how to rewrite unions and other cases
v Must verify that memory accesses are ‘type-safe’
n Pool allocation infers type homogeneity:
v Unions, bad C pointer tricks, etc à non-TH
v Some pools may be TH, others not
n Can’t index compress ptrs in non-TH pools!
