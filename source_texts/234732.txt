The README lacked documentation for the 3D Gaussian Splatting (3DGS) expressions feature implemented in LCC_Render.py and LCC_GLSL_Renderer.py.
Changes
Main features section - Added 🆕 3DGS feature with six sub-capabilities:
GLSL renderer (OpenGL-based high-performance viewport rendering)
EWA splatting (elliptical weighted average projection)
Covariance matrix processing (adaptive 3D→2D projection)
Instancing optimizations (GPU-driven rendering)
Texture-based data management
Quaternion rotation system
Import settings - Documented four new GLSL parameters:
Use GLSL Viewport - Toggle OpenGL renderer (default: on)
Viewport Density (%) - Sampling rate 0.1-100% (default: 10%)
Chunk Grid Size - Spatial partitioning grid size
Chunk Culling Distance - Distance-based chunk exclusion
Technical section - Added comprehensive 3DGS implementation details:
GLSL system: texture-based instancing, adaptive sampling, dynamic sorting
Covariance & EWA: 3D matrix computation (V = M × M^T), camera space transformation, Jacobian-based 2D projection, eigenvalue decomposition, 3σ Gaussian falloff
Instancing: GPU memory placement, single draw call for millions of splats, quad geometry (2 triangles/splat), frustum culling
Shaders: vertex (quaternion→rotation matrix, covariance computation, 2D projection, eigendecomposition), fragment (α = exp(-0.5 × r² × 9) with 9 = 3² normalization)
Technical details
The GLSL vertex shader projects 3D Gaussians to 2D screen space:
```
// Compute 3D covariance: V = (R·S) × (R·S)^T
mat3 M = quatToMat3(rot) * scale_matrix;
mat3 V = M * transpose(M);

// Project via Jacobian: V_2d = J × W × V × W^T × J^T
mat3 J = jacobian(focal, pos_cam);
mat3 V2d = J * camera_transform(V) * transpose(J);

// Eigendecomposition for ellipse axes
float lambda1 = 0.5 * (cov00 + cov11 + sqrt((cov00 - cov11)² + 4·cov01²));
float r1 = 3.0 * sqrt(lambda1);  // 3σ radius
```
Fragment shader applies Gaussian falloff with early discard for performance.
Fallback to geometry node-based rendering when GLSL unavailable.
