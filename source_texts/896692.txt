# ProceduralGenerationWorld (Voxel World)

[Japanese (日本語版)](./README.ja-JP.md)

## Overview
This project is a personal attempt at creating a 3D voxel game engine and procedural world generator, similar to Minecraft, from scratch using C++11 and OpenGL 3.3.

![Cover GIF](./Docs/procedural-world.gif)

## Features
1. Procedural World Generation
   - Fractal octave noise for generating natural terrain contours
   - Generates stone at lower elevations, sand along coastlines and riverbanks, and dirt/grass on the surface.
   - Automatically floods empty volumes below sea level with water blocks.
2. Chunk Management & Infinite Streaming
   - World data is partitioned into discrete vertical chunks for memory and mesh management.
   - Loads and unloads chunks on the fly around the player's position based on some render distance (default: 8 chunks).
3. Voxel Rendering Optimizations
   - Only exterior faces exposed to air or water are generated to minimize draw calls and vertex counts.
   - Block templates define UV coordinates for individual faces (top, bottom, sides) from a single shared texture atlas.
4. Day / Night Cycle + Dynamic Atmosphere
   - Configurable game-tick time system for transitioning between Dawn, Day, Dusk, and Night.
   - Dynamic ambient + diffuse lighting based on time of day.
   - Atmospheric fog shader (`fogDensity`, `fogGradient`) smoothly blending distant geometry into the dynamic sky color.
5. Interaction & Player Systems
   - Free 3D camera with pitch/yaw mouse look and WASD movement.
   - Ray-marching along the camera's forward vector to detect targeted blocks in real time.
   - Ability to remove block in front of the player via left-click.
   - Font rendering for displaying player position, current chunk coordinates, and targeted block data.

## Controls
| Input | Action |
| :--- | :--- |
| **W / S** | Move Forward / Backward |
| **A / D** | Strafe Left / Right |
| **Mouse Move** | Look around (Yaw / Pitch) |
| **Left Click** | Mine / Destroy targeted block |

## Tech Stack & Libraries
- **Language**: C++11
- **Graphics API**: OpenGL 3.3
- **Windowing & Input**: [GLFW 3](https://www.glfw.org/)
- **OpenGL Loader**: [GLAD](https://glad.dav1d.de/)
- **Mathematics**: [GLM](https://github.com/g-truc/glm) (OpenGL Mathematics)
- **Noise Generation**: [FastNoiseLite](https://github.com/Auburn/FastNoiseLite)
- **Font Rendering**: [FreeType](https://freetype.org/)
- **Image Loading**: [stb_image](https://github.com/nothings/stb)
- **Build System**: CMake (3.10+)

## Project Structure

```text
|-- Headers/
|   |-- EntityTemplates/    # Block templates and atlas UV managers
|   |-- Enums/              # Block types (Stone, Sand, Dirt, Water) & block face enums
|   |-- Scenes/             # BaseScene, MainScene, SandboxScene
|   |-- Utils/              # MathUtils and NoiseUtils
|   |-- BatchRenderer.hpp   # 2D/3D quad batch renderer
|   |-- Camera.hpp          # FPS camera
|   |-- Chunk.hpp           # Chunk data and meshing logic
|   |-- World.hpp           # World chunk streaming and raycasting
|-- Source/                 # Implementations corresponding to Headers
|-- Resources/
|   |-- Shaders/            # GLSL shaders (Main terrain, Water, SunMoon, UI, Font)
|   |-- Textures/           # Block atlas and moon textures
|   |-- Fonts/              # TTF font files
|-- Deps/                   # Third-party vendor dependencies (FastNoiseLite, GLAD, GLM, etc.)
|-- CMakeLists.txt          # CMake configuration
|-- build.sh                # Build helper script
```
