What
Add the sfm stage. It runs COLMAP feature extraction (with masks applied at extraction), matching and mapping, records model_analyzer metrics, and fails on the v1 gates. It runs on the GPU host (popos), per ADR-0008.
Where M1 left off
What's merged (feat(core): add ToolRunner with native, podman and docker runtimes #19, feat(core): add stage cache, manifest and pipeline runner #22, feat(frames): extract and blur-filter video frames; wire up run #24, feat(containers): add the segmentation image for the masks stage #25, feat(masks): add the masks stage on the segmentation container #26):
The ToolRunner, with native, podman and docker runtimes.
The stage cache with manifests (ADR-0004).
The frames and masks stages.
What run produces today: shoreline-recon run configs/<dataset>.toml gives frames/<fp>/images/ and masks/<fp>/masks/<image>.png (COLMAP convention, black = ignore) on the Mac, for both clips.
Spike settings to start from (ADR-0002, decision 2; spike/m0/remote/sfm.sh):
COLMAP 4.2.1 CUDA, colmap/colmap@sha256:c1de51615dff… under Apptainer.
16,384 SIFT features, single camera.
Sequential matching for Laajasalo, exhaustive for Vartiosaari.
Gates: configs/defaults.toml [gates] sets registered ratio ≥ 0.85, reprojection ≤ 1.0 px and track length ≥ 3. The spike registered 121/121 and 117/117 at about 0.7 px.
Open design questions (decide before building)
How stages reach the GPU host. Nothing supports this yet.
(a) Run shoreline-recon on the host, with a host tools file using the Apptainer runtime. Masks then need an amd64 segmentation image (ADR-0006).
(b) Add an ssh runtime to the ToolRunner that syncs mounts and runs one tool remotely, so the pipeline stays on the Mac.
(c) Run frames and masks locally, sync work/<dataset>/ to the host, and run SfM onwards there.
Fingerprints include native tool versions (ADR-0004). Frames made with the Mac's ffmpeg therefore miss the cache under the host's ffmpeg, which affects (a) and (c).
Apptainer runtime ([Feature] core: ToolRunner Apptainer runtime arm #13). Needed in every option.
Where the metrics come from. Parse colmap model_analyzer output, or read the model (the kickoff asks for text and binary model parsing).
Acceptance criteria
shoreline-recon run produces sparse/0 for both clips, with masks applied at extraction
model_analyzer metrics are in the manifest, and the gates are evaluated
Registration matches the spike: all frames registered, reprojection error about 0.7 px
Related: #13, #9, ADR-0008.
