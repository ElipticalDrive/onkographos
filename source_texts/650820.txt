# Complex Function Visualizer

A Python application that visualizes complex functions using domain coloring and optional
iteration paths. Each pixel represents a complex number, and its color is determined by the
function's output using HSV color mapping.

Type any expression in `z` and `c`, and watch how it transforms the complex plane in real time.
