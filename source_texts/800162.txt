Why
The world needed to behave like a real Minecraft-style chunked world instead of a single fixed 32x16x32 array. The previous frame rebuilt all visible geometry and did not provide separate grass face textures or native block storage.
What changed
Define a 32 x 32 x 32 chunk world where every chunk is 32 x 32 x 32 blocks.
Generate chunks lazily and store each chunk's block data in native memory allocated with nmemCalloc, accessed with memGetByte/memPutByte, and released with nmemFree.
Build and cache one static OpenGL VBO mesh per nearby chunk; render only chunks around the active camera instead of rebuilding the entire world every frame.
Invalidate cached meshes when blocks are edited.
Add separate grass top, grass side, and dirt atlas tiles in the Minecraft Classic style.
Keep dedicated snake and apple atlas layers with correct green/red mapping.
Preserve free-camera editing, smooth follow-camera behavior, corrected face winding, and voxel AO.
Validation
./gradlew.bat --no-daemon clean build passes successfully.
