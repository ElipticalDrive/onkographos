Parent Epic: #457
Description
Implement all scene query functions: raycasting, shape casting, point queries, and batch queries for performance optimization.
Note: This is a wrapper for Rapier Physics, a fast 2D physics engine written in Rust and compiled to WebAssembly.
Consolidates: #472 (Raycasting) + #473 (Shape Casting) + #474 (Point Queries) + #475 (Batch Queries)
Lua API
Raycasting (3 functions)
```
-- Cast ray from (x1,y1) to (x2,y2), return first hit
local hit = physics.raycast(world, x1, y1, x2, y2)
-- Returns: {body, shape, point_x, point_y, normal_x, normal_y, t} or nil

-- Cast ray and get all hits
local hits = physics.raycast_all(world, x1, y1, x2, y2)
-- Returns: {{body, shape, point_x, point_y, normal_x, normal_y, t}, ...}

-- Cast ray with filter function
local hit = physics.raycast_filtered(world, x1, y1, x2, y2, function(shape)
  return shape:get_parent_body():get_type() == "dynamic"  -- only hit dynamic bodies
end)
```
Shape Queries (6 functions)
```
-- Cast a shape from (x1,y1) moving towards (x2,y2)
local hit = physics.shapecast(world, shape, x1, y1, x2, y2)
-- Returns: {body, shape, point_x, point_y, normal_x, normal_y, t} or nil

-- Get all shapes overlapping with a shape at position
local shapes = physics.shapes_intersecting(world, shape, x, y)
-- Returns: {shape1, shape2, ...}

-- Get closest point on any collider to given point
local result = physics.closest_point(world, x, y)
-- Returns: {shape, point_x, point_y, distance} or nil

-- Check if a point is inside any solid collider
local inside = physics.point_in_solid(world, x, y)
-- Returns: shape or nil

-- **NEW** Get all shapes within an axis-aligned bounding box
local shapes = physics.shapes_in_aabb(world, min_x, min_y, max_x, max_y)
-- Returns: {shape1, shape2, ...}

-- **NEW** Project point and get feature info (edge/vertex)
local result = physics.project_point_and_get_feature(world, x, y)
-- Returns: {shape, point_x, point_y, distance, feature_type, feature_id} or nil
```
Point Queries (2 functions)
```
-- Get all bodies containing a point
local bodies = physics.bodies_at_point(world, x, y)
-- Returns: {body1, body2, ...}

-- Get all shapes containing a point
local shapes = physics.shapes_at_point(world, x, y)
-- Returns: {shape1, shape2, ...}
```
Batch Queries (2 functions)
```
-- Get all body positions in one call (optimization)
local positions = physics.get_all_positions(world)
-- Returns: {[body_id] = {x = x, y = y, rotation = r}, ...}

-- Get all body velocities in one call
local velocities = physics.get_all_velocities(world)
-- Returns: {[body_id] = {vx = vx, vy = vy, angular = av}, ...}
```

Optimization Rationale (Batch Queries)
With 100 bodies at 60 FPS:
Without batch: 100 × 60 = 6,000 boundary crossings/second
With batch: 1 × 60 = 60 boundary crossings/second
