# 3DGS to Voxel OpenUSD

Convert 3D Gaussian Splatting (3DGS) or PLY point clouds to OpenUSD with GPU-instanced voxel rendering.

## Installation

```bash
pip install numpy Pillow usd-core
```

## Quick Start

```bash
# GUI mode
python gui.py

# CLI mode
python pipeline.py input.ply output.usdc --resolution 0.1
```

## Pipeline

```
PLY/3DGS → Voxelize → PointInstancer → USDC
```
