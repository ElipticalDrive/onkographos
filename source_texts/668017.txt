Contributor
This PR adds occlusion culling to hide objects that are completely blocked by other objects from the camera's view, complementing the existing size-based culling system.
Problem
The existing culling system only performed size-based culling (hiding objects smaller than a pixel threshold during interactions). There was no occlusion culling to hide objects that are completely occluded by other geometry, which is important for performance optimization in complex 3D scenes.
Solution
Implemented a new OcclusionCullingController class that uses Three.js raycasting to detect when objects are blocked from the camera's view:
Raycasting-based detection: Casts rays from camera to object centers to detect occlusion by other geometry
Performance optimized: Processes only 20 objects per frame with incremental updates to maintain smooth frame rates
Hysteresis system: Requires 3 consecutive frames before changing visibility to prevent flickering
Independent operation: Works alongside existing size-based culling without interference
UI Changes
Added a new "Occlusion: Off/On" toggle button in the toolbar, positioned next to the existing "Cull: Off/On" button for size-based culling. Both culling systems can be enabled/disabled independently.
Technical Implementation
New controller class: OcclusionCullingController in src/culling.ts
Viewer integration: Connected to animation loop, model loading, and clearing systems
UI integration: Added toggle button and event handlers in src/main.ts
Clean architecture: Follows existing patterns and maintains code consistency
Testing
To verify the implementation:
Load a complex 3D model with overlapping/nested geometry
Navigate around the model to different viewing angles
Toggle "Occlusion: On" and observe objects behind others become hidden
Toggle "Occlusion: Off" and verify all objects become visible again
Test both culling systems together for comprehensive optimization
The implementation preserves all existing functionality while adding this important performance optimization feature.
