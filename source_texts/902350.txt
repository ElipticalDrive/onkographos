This change addresses performance issues in the voxel game by switching from individual meshes per block to THREE.InstancedMesh. This drastically reduces the number of draw calls.
Key Changes:
Refactoring: Removed the naive "one mesh per block" approach. Block data is now stored as simple types in a worldData Map.
Rendering: rebuildChunk now groups blocks by material and creates a single InstancedMesh for each material type within a chunk.
Interaction: Updated raycasting to identify blocks via instance ID and calculated coordinates.
Fixes: Addressed potential regressions such as "ghost blocks" from trees crossing chunk boundaries by scanning a padded area during chunk generation, and restored particle colors.
Testing: Verified functionality using a Playwright script checking for successful load, mining, and placing.
