Does anyone have performance close to the one stated in paper?
I used the same dataset, but the best I could achieve is PSNR = 20.01, SSIM on grayscale image = 0.8313, SSIM on RGB image = 0.7578. Because there is no code for calculation of these metrics, I assume this can be the reason of different results, though I implemented metrics carefully based on papers and existing implementation in skimage. I run training and test in total about 10 times, but PNSR never was close to declared in paper value of 22.27.
