Hi community,
Following problem: I have a voxel grid (not as an octree just a regular grid) in which every point of a voxel has the signed distance to the surface. I need to convert my voxel grid to the octree, which is used in the Screened Poisson reconstruction in order to use the adapted marching cubes algorithm used in Screened Poisson Reconstruction. I tried to debug the poisson reconstruction step by step to see how the data for marching cubes in Screened Poisson Reconstruction is set up, but it is very hard to read and understand.
What would be the easiest way to get this done? My current idea is to take the points (the positions with a pseudo normal, because I have no normals) of my voxel grid as input. The GetMCIsoSurface method takes parameters densityWeights, solution and isoValue. For signed distance function isoValue would be zero, but I do not know what to do with densityWeights and solution, since this will not be correctly set up if I do not provide correct normals.
Can someone help me who is more proficient with the code and the theory all behind that? Big thanks in advance!
