Descripción
Implementar G-Buffer y pipeline de deferred shading. El G-Buffer es la pieza arquitectónica que unifica el lighting de SDF y mesh en el hybrid renderer (#91). Ambos passes escriben al mismo G-Buffer, y un lighting pass posterior lee de él.
Layout del G-Buffer
Attachment
Format
Content
RT0
RGBA8Unorm
Albedo (RGB) + Metallic (A)
RT1
RGBA16Float
Normal (RGB, octahedral encoded) + Roughness (A)
RT2
RGBA8Unorm
Emissive (RGB) + AO (A)
RT3
RG16Float
Motion Vectors (RG)
Depth
Depth32Float
Depth buffer
Tareas
Crear G-Buffer textures (RT0-RT3 + depth)
Resize G-Buffer on window resize
SDF pass: ray march → write to G-Buffer (compute o fragment)
Mesh pass: rasterize → write to G-Buffer (vertex/fragment)
Lighting pass: fullscreen quad/triangle, read G-Buffer, output lit color
Normal encoding/decoding (octahedral — 2 components → 3)
Reconstruct world position from depth + inverse VP matrix
Debug visualization: show individual G-Buffer channels
Stencil or material ID for different shading models
Criterios de Aceptación
SDF y mesh geometry visibles en el mismo frame
Lighting aplicado uniformemente a ambas representaciones
Sin artefactos en bordes SDF↔mesh
G-Buffer debug muestra albedo, normals, roughness, depth separados
Performance: G-Buffer fill < 1ms a 1080p

// Lighting pass — fullscreen triangle
struct GBufferSample {
    albedo: vec3<f32>,
    metallic: f32,
    normal: vec3<f32>,
    roughness: f32,
    emissive: vec3<f32>,
    ao: f32,
    depth: f32,
    world_pos: vec3<f32>,
}

fn sample_gbuffer(uv: vec2<f32>) -> GBufferSample {
    var s: GBufferSample;
    let rt0 = textureSample(gbuffer_albedo_metallic, gbuffer_sampler, uv);
    let rt1 = textureSample(gbuffer_normal_roughness, gbuffer_sampler, uv);
    let rt2 = textureSample(gbuffer_emissive_ao, gbuffer_sampler, uv);

    s.albedo = rt0.rgb;
    s.metallic = rt0.a;
    s.normal = octahedral_decode(rt1.rg);
    s.roughness = rt1.a;
    s.emissive = rt2.rgb;
    s.ao = rt2.a;
    s.depth = textureSample(gbuffer_depth, gbuffer_sampler, uv);
    s.world_pos = reconstruct_world_pos(uv, s.depth);

    return s;
}
