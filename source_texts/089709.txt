This PR introduces the ability to generate "porous" point clouds, allowing users to simulate porous materials by dropping a specified percentage of voxels.
The feature adds a --porous parameter that leverages a fast, custom Linear Congruential Generator (LCG) seeded by spatial coordinates. This approach ensures deterministic outputs (the same mesh and resolution will always drop the same particles) without requiring external random number generator crates or complicated thread-synchronization across Rayon's parallel iteration loops.
To maintain clean and DRY code, the particle insertion logic (including the pre-existing phase_sphere check) was extracted into a shared add_particle closure inside the parallelized row-scanning loop.
Appropriate integration tests have been added using parry3d's procedural mesh generation capabilities to verify both the new porosity feature and the existing phase sphere logic.
