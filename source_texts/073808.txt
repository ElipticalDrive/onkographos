# Comparative Benchmarking of Sparse Volumetric Data Structures for Rocket Combustion Simulations with a Proposed Morton Spatial Hash Representation

## Introduction

Modern rocket combustion simulations generate large three-dimensional (3D) volumetric datasets containing physical properties such as **temperature**, **pressure**, and **density**. These datasets are inherently **sparse**, meaning that only a small portion of the computational domain contains active combustion regions, while the majority of the space remains empty.

Traditional dense voxel grids allocate memory for every voxel regardless of whether it contains meaningful data. As simulation resolution increases, this approach leads to excessive memory consumption and unnecessary computational overhead.

Sparse volumetric data structures address this problem by storing only the active regions of the simulation, significantly improving memory efficiency while maintaining fast data access. Several sparse representations have been proposed, each with different trade-offs in terms of memory usage, insertion speed, lookup performance, scalability, and implementation complexity.

Despite their widespread use, there is currently no comprehensive benchmark that evaluates these data structures under varying sparsity levels in dynamic rocket combustion environments, where flame fronts continuously evolve over time.

This project performs a comparative benchmarking study of major sparse volumetric data structures and proposes a lightweight **Morton Spatial Hash Representation** designed specifically for dynamic combustion simulations. The objective is to evaluate each approach based on performance, memory efficiency, and scalability to identify the most suitable representation for sparse rocket combustion data.
## Problem Statement

Rocket combustion simulations present several computational challenges due to the size and dynamic nature of volumetric data. These challenges include:

- Extremely large three-dimensional computational grids
- High levels of sparsity, where only a small fraction of voxels contain meaningful data
- Dynamic flame propagation requiring continuous updates
- Frequent neighborhood queries performed by Computational Fluid Dynamics (CFD) solvers
- Memory limitations during large-scale simulations

Existing sparse volumetric data structures offer different trade-offs between memory efficiency and computational performance. However, there is no comprehensive evaluation that determines which representation performs best under varying sparsity conditions in aerospace combustion simulations. This research addresses that gap through systematic benchmarking.

## Objectives

The primary objectives of this research are:

- Benchmark major sparse volumetric data structures used in scientific computing.
- Evaluate their performance across different sparsity levels.
- Propose a **Morton Spatial Hash** representation for dynamic sparse combustion domains.
- Develop a decision framework that recommends the most appropriate data structure based on simulation characteristics.

---

## Research Questions

- **RQ1:** Which volumetric data structure provides the highest memory efficiency for sparse combustion domains?
- **RQ2:** Which representation offers the fastest point lookup and neighborhood traversal performance?
- **RQ3:** How do different data structures scale as sparsity increases?
- **RQ4:** Can the proposed **Morton Spatial Hash** representation achieve competitive performance compared to **Octrees** and **OpenVDB**?
