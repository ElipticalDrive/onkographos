Goal
Replace the temporary value-noise + fbm density function in VolumetricCloudPass with the actual noise model used by NadirRoGue/RenderEngine.
What to port from RenderEngine
NoiseInitializer: generate on GPU
perlinworley.comp -> 128^3 RGBA8 Perlin-Worley FBM (base shape)
worley.comp -> 32^3 RGBA8 Worley FBM (erosion)
weather.comp -> 2048^2 RGBA8 weather/coverage map
volumetricclouds.frag density function:
height fraction via spherical shell (innerSphereRadius, outerSphereRadius, sphereCenter)
sampleCloudDensity() with weather texture coverage, base shape remap, erosion
cloud type gradient (stratus/stratocumulus/cumulus mix)
wind advection
Files expected to change
crates/aether-engine/src/renderer/passes/volumetric_cloud/mod.rs
crates/aether-engine/src/clouds/generate.rs (already mostly ported; wire into pass)
assets/shaders/clouds/volumetric_clouds.wgsl (new)
crates/aether-engine/src/renderer/resource.rs (add noise texture resources if needed)
Tests / verification
Unit tests: cargo test -p aether-engine --lib
Build launcher: cargo build -p aether-launcher --release
Run: E:/Users/ruochenhua/.cargo/aether-target/release/aether-launcher.exe --scene scenes/13_clouds.ron --screenshot tests/output/clouds/phase3/phase3_clouds_noise.png --exit-after-frames 60 --no-gui-overlay
Screenshot must show cloud puffs / patches, not uniform white noise or black screen.
Acceptance criteria
Perlin-Worley and Worley textures bound to the volumetric cloud shader
Density sampled via RenderEngine's sampleCloudDensity() logic
Visual output has recognizable cloud shapes
All existing 198 lib tests still pass
