Isaac Simで 3D Gaussian Splatting を表示する
Python
Omniverse

0
Last updated at 2026-07-18Posted at 2026-06-27
1. はじめに
Isaac Sim 6.0.1では、3D Gaussian SplattingのデータをUSDとして読み込むことで、シミュレーション空間内に高品質な実環境の3D表現を配置できる。
本記事では、SuperSplatで公開されている3D Gaussian SplattingのPLYファイルを、NVIDIA Omniverseのusd-convert-gsplatを用いてUSDに変換し、Isaac Sim上で表示確認するまでの手順を紹介する。

3. 入力データの準備
入力とする3D Gaussian Splattingのデータは、SuperSplatから入手する。XGRIDSのPortalCamで撮影・作成された高品質な3D Gaussian Splattingが見つかったため、これを用いる。
https://superspl.at/scene/c84335ae
Microsoft Redwest campus (XGRIDS PortalCam) by tosolini, licensed under CC BY 4.0
ダウンロードボタンからPLYファイルをダウンロードする。
4. usd-convert-gsplatの準備
3D Gaussian SplattingのPLYを、Isaac Simで3D Gaussian Splattingとして読み込み可能なUSDに変換するため、usd-convert-gsplatを導入する。
以下を実行してインストールする。なお、READMEにはusd-coreのインストールについて言及がないが、usd-coreをインストールしないと実行時にエラーになるため、別途インストールが必要。
Copied!
```
uv venv
source .venv/bin/activate
git clone https://github.com/NVIDIA-Omniverse/usd-convert-gsplat.git
cd usd-convert-gsplat
uv pip install ./source/python/
uv pip install usd-core
```
5. PLYからUSDへの変換実行
Copied!
```
usd-convert-gsplat -i './Microsoft Redwest campus (XGRIDS PortalCam)/scene.ply' -o './Microsoft Redwest campus (XGRIDS PortalCam)/scene.usd'
```
6. Isaac Simに取り込んで確認
Isaac Simに出力されたUSDファイルをドラッグ&ドロップする。読み込むと、180度反転しているように見える。
X軸のRotateを設定し、180度回転させる。
ズームしてみると、綺麗に表示できていることが確認できる。
7. まとめ
本記事では、SuperSplatから取得した3D Gaussian SplattingのPLYファイルを、usd-convert-gsplatを使ってUSDに変換し、Isaac Sim 6.0.1上で表示する手順を確認した。
usd-convert-gsplatを利用することで、PLY形式の3D Gaussian Splattingデータを比較的簡単にIsaac Simへ取り込むことができる。一方で、環境によってはusd-coreの追加インストールが必要になる点や、読み込み後に座標系・回転方向の調整が必要になる点には注意が必要である。
3D Gaussian SplattingをIsaac Sim上で扱えるようになると、現実環境を高品質に再現した背景やシーンをシミュレーションに活用できるため、ロボットシミュレーションや合成データ生成などへの応用も期待できる。
補足
Isaac Simに読み込み可能なUSDに変換する別の方法として、OpenUSDのpy3dgsPlyToUsd.pyを用いる手段もある。なお、この方法は、Omniverseのマニュアルからも参照されていた。
2026/07/19追記
Isaac Simに3DGSのインポート機能は統合されていた模様...
File -> Importでファイルのインポート画面を表示し、Choose a Converterから3D Gaussian Splat(Particle Field)を選択すると、3DGSのインポートができる。
