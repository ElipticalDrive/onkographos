This adds the first real solver. It traces rays from every source to every receiver and reports EDT, T20, T30, C50, C80, D50 and Ts per receiver for each octave band.
Engine
BVH (ra-engine/src/bvh.rs): built over all triangles except contact faces, with a binned surface-area heuristic and flat arrays, and two-sided Möller–Trumbore intersection. A test checks it against brute force on 500 random triangles and 2,000 rays.
Ray tracer (ra-engine/src/rt.rs, solver rt):
Each ray carries 1/N of its source's energy per band.
At each hit it loses (1 − α). It then reflects as a mirror or, with the band-mean scattering as probability, in a cosine-weighted direction. Both branches are reweighted per band so the result stays unbiased.
Air absorption follows ISO 9613-1.
Receivers are spheres that score chord length over sphere volume. Direct sound is added exactly, with a visibility test.
Rays stop at −90 dB or at the end of the run.
Each ray is seeded from the source and ray index, so splitting the run into different chunks gives the same result. Transcendentals go through libm, and the air absorption in ra-core now does too.
Receiver radius: when the radius is 0, the run picks one that late-decay rays cross about once per millisecond, √(V / (π·N·c·1 ms)), clamped to 0.3–5 m.
Sources and receivers:
ra_core::{Point, Setup}, with from_model marking points read from the model.
SetScene takes model points. They replace the previous model points, and points added in the app are kept.
New command SetSetup, which requires unique, non-empty names.
Run defaults to every receiver. It returns RunResults: metrics per receiver from ra-metrics, mean free path, leak fraction and the radius used.
Format 1.2: an optional setup/points.json, written only when there are points, plus a setup hash. The new browser-written sample is validation/formats/1.2-test-room.raproj; CI now compares against it, and the 1.1 and 1.0 samples still open. docs/format.md is updated.
ra-cli run <file.raproj> [request.json]: for headless runs.
App
Importers:
Rhino: point objects on layers whose names contain source, speaker or talker become sources. Names with receiver, listener, seat, mic or position become receivers.
SketchUp: guide points inside groups tagged or named the same way. openskp gives guide points no tag of their own.
Sources and receivers panel: a table in model coordinates, in metres. Rows can be added, renamed, moved and removed. Edits run one at a time. A new point starts inside the room, at the leak test's seed point.
Ray tracing panel: inputs for rays, length and radius (empty means auto). It shows progress, mid-frequency (500 Hz and 1 kHz) EDT, T30, C80, D50 and Ts per receiver, and T30 per octave. It warns when rays leak.
Checked
Unit tests: cargo fmt, clippy -D warnings, workspace tests and vitest all pass.
Shoebox: with uniform absorption, T30 is within 10 % of Eyring (α 0.1 and 0.3). Mean free path is within 5 % of 4V/S, energy is conserved with no absorption, direct sound is exact, and results do not depend on chunking.
Uneven absorption: with only the floor absorbing, the decay moves from Eyring (fully diffuse) towards long grazing decays (nearly specular), as expected. This was a manual check and is not committed.
Smoke test: traces the hall fixture. The 1.2 sample was written twice and the copies are identical.
Arthur Ashe (browser): 50,000 rays in 9 s with an auto radius of 3 m. Mid T30 is 6.5 s against Eyring's 3 s. The absorption sits on the seating bowl, so a diffuse-field formula comes out short.

Sources and receivers are point objects on layers named like Sources and
Receivers in Rhino (guide points in such groups in SketchUp), or added
and moved in a table in the app. The project keeps them in
setup/points.json (format 1.2); re-importing replaces the model's points
and keeps the app's. A Run button traces every source to every receiver
and shows EDT, T30, C80, D50 and Ts per receiver. The receiver radius
defaults to one a ray crosses about once per millisecond, so large rooms
get usable decays from the same ray count. Air absorption now uses libm,
like the tracer, so browser and native results agree. ra-cli gains run.
