Summary
Implements ADR-0025 (Documentation/ArchitectureDecisions/0025-voxel-graphics-and-magicavoxel-import.md): voxel rendering through ordinary meshes (no render-backend changes), MagicaVoxel import, animation, an editable chunked world, physics and editor integration. A usage guide is in Documentation/Voxels.md.
.vox import (AdaAssets, AdaScene): parser for SIZE/XYZI/RGBA/MATL/LAYR and the nTRN/nGRP/nSHP scene graph. .vox is now a ModelAsset3D extension, so Model3DSource loads it unchanged. MagicaVoxel (right-handed, Z up) is converted to the engine's left-handed Y-up space by swapping Y and Z (baked into vertices with reversed winding; node matrices conjugated). 1 voxel = 0.1 units by default.
Mesher (AdaRender): VoxelGrid + VoxelMesher with culled or greedy quads, palette in vertex colors, per-vertex ambient occlusion, and a region mode for chunk meshing.
Hybrid scene: entity hierarchy by default; mergeStatic rasterizes static subtrees into one mesh (inner faces culled), falling back to separate meshes above a volume limit.
Per-model settings: Model3DSource.voxel (VoxelImportSettings: voxel size, merge static, fps) reaches the importer as an asset query (castle.vox#voxelSize=0.05&mergeStatic=1&fps=24), the mechanism other assets use for options.
Animation: nTRN keyframes (lerp/slerp) and nSHP model switching, driven by a root VoxelAnimationPlayback3DComponent clock; Model3DSource.autoplay/repeats control it.
Dynamic world: VoxelWorldStorage (thread-safe 32³ chunks, dirty tracking incl. diagonal neighbours) and VoxelWorldMeshing3DSystem (parallel meshing from padded snapshots under a per-update budget).
Physics: Shape3DResource boxes gain a backwards-compatible center; VoxelColliderBuilder merges voxels into boxes; per-chunk static colliders (world space, follow the world); detachFloatingIslands + VoxelIsland.spawnBody for cut-off blocks.
Editor: .vox is a model asset: import and drop copy it, it opens in the 3D preview (frame info, Play/Pause drives the voxel clock), Add to Scene places a Model 3D entity, and the Model 3D inspector has voxel size, merge static and animation fps. Scene loading in the editor honours the settings. The glTF-only agent model tools keep rejecting .vox. Editor docs updated.
Verification
Engine: 1618 tests in 283 suites pass on Swift 6.3.2 (swift test), including new suites for the parser, fixtures, mesher, scene builder, animation, storage, world system, physics and import settings.
Editor: 10 new tests (EditorVoxelModelTests: import/drop, resolve, save/reopen/load in edit and Play, settings round trip, preview Play/Pause, agent tool boundary) and the existing glTF model tests pass. The full Editor suite has 16 failing tests that fail the same way without my Editor changes (AdaScript views disabled by ADR-0016, UI-default expectations, package manifest check), and one AdaScript preview test that fails in isolation on the base too.
Gated Metal smoke tests (ADAENGINE_VOXEL_METAL_SMOKE=1) render castle, robot (two animation frames), a 3x3-chunk terrain before/after editing and a detached block falling onto a platform; the PNGs were inspected.
Real files: all 15 .vox files of the MagicaVoxel 0.99.7.2 release (vox/, version 200, including the animated T-Rex, Gomez and deer) parse and render on Metal, and the PNGs were inspected. The pivot floor(size / 2) matches the _t values in the samples, and the rotation matrix is applied the same way as in the ogt_vox reference loader. The samples are not in the repository (history of this branch contains them in one commit, removed in the next); they are used through the gated ADAENGINE_VOX_SAMPLES tests.
The synthetic fixtures from script/generate_vox_fixtures.py remain for tests that need exact, known content.
Notes for review
Swift 6.2.3 cannot build the package because of an existing error at Sources/AdaUI/DSL/Navigation/NavigationBarNode.swift:177; 6.3.2 builds it. Everything above was run on 6.3.2 (Editor build: ADAENGINE_PACKAGE_PATH and ADA_MCP_LOCAL_PATH set, and the engine directory named AdaEngine, because a worktree directory name changes the package identity).
Swift 6.2.3's coroutine splitter crashes on a task-group closure inside the system's async update; the meshing is split into static helpers as a workaround (commented in code).
Behaviour change: Shape3DResource.offsetBy now offsets boxes too (it returned the box unchanged before).
Existing engine issue found, not changed here: Physics3DSyncSystem overrides only a body's mass, keeping the inertia computed from its density. Heavy dynamic boxes (e.g. mass 400 on the default density 1) then tunnel through a thin static box. Voxel islands avoid it by choosing a density that matches the requested mass.
Not done
MATL materials (parsed, not applied), community package support for .vox (that pipeline validates glTF content and needs a .vox validator first), AdaAnimation clips for voxel nodes, skinning and GPU paths (ADR stage 7). Instancing needs no voxel-specific work: copies of one asset share buffers and are batched by the existing 3D renderer (tested, see Documentation/Voxels.md).
