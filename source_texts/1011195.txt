What and why
BV-C7 of docs/architecture/adr-beyond-vram-worlds.md (section 10 row BV-C7, D-12, D-13, section 9.2, M1c row). The generator and the beyond-VRAM workflow can now write Tier A as plain GSQ (plain v3 + bit 7, paged GSQ v1 chunks). They prime it into the runner's world cache, and that prime deletes the uncompressed M1 world.
Generator (io/gs_world_generator.*): GenerateOptions::codec_id selects GSQ v1 with the D-12 pre-registered block (gsq_v1_codec_params()). The codec block is part of gen_sha, so flat and GSQ worlds never share a cache key. The read-back runs once over the file:
it checks the table structure: contiguous, aligned and ascending page runs that end at the chunk table, splat counts, and zero padding;
it runs gs_gsq::verify_page on every page;
it records each chunk's page run (first_page, page_count, pages_offset, pages_bytes, pages_sha256).
The manifest gets a top-level codec block: id, page count, stored bytes, the SHA-256 of the decoded digest set, constant_groups and heterogeneous_chunks. The flat manifest bytes are unchanged.
Verifiers: C++ verify_world() and the stdlib verify_world_manifest.py (the lane's V2) both verify GSQ worlds:
the extension's codec block against the manifest's writer codec;
the chunk and page tables;
every page-run digest, the zero padding, the decoded digest set and the file digest;
a manifest whose codec is not the file's encoding (codec_mismatch).
--content refuses a GSQ world explicitly. It does not skip it.
Script binding / entry points: generate(..., codec="none"|"gsq_v1"), generate_world.gd --codec, generate_world.py --encoding plain_v3_gsq.
Dispatch lane (dispatch_lane.py): --encoding for generate, prime-cache and cache-check.
The encoding applies to Tier A only. T0 stays uncompressed: the BV-07 F/k sweep regenerates T0 subsets uncompressed, and one sweep must not mix codecs.
The cache key is told apart by codec in three places: the world id (A-plain_v3_gsq), gen_sha (codec block) and .key.json encoding. cache-check refuses a key that records another encoding as cache_stale. prime-cache refuses a manifest whose writer codec differs from the requested one.
Delete the M1 file (D-13): once the compressed Tier A key is complete (never before, so a failed prime keeps it), the prime removes <cache>/A-plain_v3_uncompressed/. The removal is recorded as deleted_m1_world in the prime record. The prime record also carries world bytes, B/splat, the codec block and the generation time.
GSQ disk budget: the ADR section 5.3 line "Steady from M1c: A plain GSQ … 7.6" (7.6 GB).
Workflow beyond_vram_flythrough.yml: new input encoding (default plain_v3_gsq). The weekly schedule uses it too (D-13: every gated run from M1c on is compressed). It is passed to prime-cache and cache-check, and the run name and prime artifact name include it.
world_cache: gsq_page_builder.{h,cpp} join the generator source fingerprint.
GSQ does not become an engine default (#1357). Only the lane's Tier A world is compressed. The real-scan visual check of #1357 is still open.

Base the upload oracle on the packed GPU record size
For the newly supported GSQ Tier A runs, this computes 288 bytes per degree-3 splat, but that is the decoded CPU representation, not the GPU upload representation. GaussianStreamingSystem::_pack_chunk_data() packs SH into PackedGaussian (176 bytes, as asserted in renderer/gaussian_gpu_layout.h), and StreamingUploadPipeline counts the actual packed bytes uploaded. Since summarise_path() now uses this helper's result as its denominator, uploading each visible splat exactly once reports an amplification of approximately 0.61 instead of 1, understating re-upload amplification. Keep decoded CPU bytes separate and derive the upload oracle from the effective packed GPU stride.
