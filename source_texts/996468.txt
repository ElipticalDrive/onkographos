Added APIs
Chunk.getBlock(x, y, z) — read a block by chunk-local coordinates.
Chunk.getEntities() — query entities currently tracked by the chunk.
Chunk.isGenerated() and Chunk.isSlimeChunk().
Chunk.isForceLoaded, Dimension.setForceLoaded() and Dimension.getForceLoadedChunks().
Dimension.getChunkAtAsync() with timeout, generation and plugin-owned load tickets.
Implementation
Adds the C++ API, Python bindings and generated stubs following the existing Endstone level API patterns. Chunk loading is coordinated through the shared load queue so asynchronous requests release their temporary holds and plugin-owned force-loading tickets are restored safely.
Testing
Verified with a fresh Windows build, C++/Python tests and the live BDS 1.26.45.1 server using the Chunk API Lab plugin.
