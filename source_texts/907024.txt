Context
Visibility system that culls invisible objects using a spatial octree. Objects outside the view frustum are never enqueued, eliminating unnecessary GPU geometry processing. Depends on #99.
New files
src/renderer/OctreeVisibilitySystem.h
src/renderer/OctreeVisibilitySystem.cpp
Implementation
OctreeNode (private inner struct)
```
struct OctreeNode {
  core::BBox3 bounds;
  std::unique_ptr<OctreeNode> children[8];  // null = leaf
  std::vector<Renderable*> renderables;
  bool IsLeaf() const { return children[0] == nullptr; }
};
```
Class interface
```
class OctreeVisibilitySystem : public IVisibilitySystem {
 public:
  OctreeVisibilitySystem(const core::BBox3& world_bounds, int max_depth);

  static int ComputeNumLevels(float world_size, float min_cell_size = 10.f);

  void AddRenderable(Renderable* r) override;
  void RemoveRenderable(Renderable* r) override;
  void OnRenderableMoved(Renderable* r) override;
  void CullAndEnqueue(const core::ViewFrustum& frustum) override;
  void Clear() override;

 private:
  OctreeNode root_;
  int max_depth_;

  void Insert(OctreeNode* node, Renderable* r, int depth);
  void Remove(OctreeNode* node, Renderable* r);
  void CullNode(const OctreeNode* node, const core::ViewFrustum& frustum) const;
  void SplitNode(OctreeNode* node) const;
};
```
ComputeNumLevels
```
// Returns min(8, max(1, (int)ceil(log2(world_size / min_cell_size))))
// Example: world_size=1000, min_cell_size=10 → 7 levels (~7.8-unit leaf cells)
```
Insertion rule
An object is placed in the deepest node whose bounds fully contain its world_bbox_. Objects larger than a node stay at the parent. This avoids inserting any object into multiple nodes.
AddRenderable: recurse from root, find target node, append to its renderables_, store the node pointer in r->SetVisibilityId(reinterpret_cast<uintptr_t>(node)). Call r->SetVisibilitySystem(this).
O(1) removal
RemoveRenderable: read OctreeNode* from r->GetVisibilityId(), erase r from that node's renderables vector (swap+pop). Call r->SetVisibilitySystem(nullptr).
Move handling
OnRenderableMoved: read old node from visibility_id_. If the renderable's new world_bbox_ still fits inside that node, do nothing. Otherwise remove from old node and re-insert from root.
CullAndEnqueue
DFS from root. For each node:
Call frustum.ContainsBBox(node.bounds) — if entirely outside, skip the whole subtree.
Otherwise call r->Enqueue() for all renderables in this node.
Recurse into non-null children.
This prunes entire subtrees early when a node is outside the frustum.
Clear
Recursively set SetVisibilitySystem(nullptr) on all renderables, clear vectors, destroy children.
