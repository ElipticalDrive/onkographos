Add greedy mesher, worker pool, packed faces and terrain rendering
…
0905c4a
```
- mesh/appearance.rs: flat per-state appearance table (Arc-shared with
  workers) and procedural 16x16 builtin placeholder textures; glass and
  leaves use binary alpha for cutout.
- mesh/face.rs: the 8-byte PackedFace format with pack/unpack and a
  documented (u, v) frame per direction, mirrored in terrain.wgsl.
- mesh/greedy.rs: greedy mesher over a padded 34^3 view with uniform fast
  paths, the face rule (missing neighbors cull but stay AO-open), classic
  corner AO and per-slice maximal-rectangle merging, plus a 200-case
  property test against an independent naive mesher.
- mesh/pool.rs: MeshPool with named jbm-mesh-N threads, a
  Mutex<Receiver> job queue with bounded recv waits, versioned results,
  prompt discard-on-drop shutdown and panic surfacing through try_recv.
- world.rs: ClientWorld with CubeData/UnloadCube handling, neighbor
  re-dirtying, per-cube versions and nearest-first take_dirty.
- render/chunks.rs + shaders/terrain.wgsl: vertex-pulled terrain pass,
  one faces storage buffer and one draw per cube, camera-relative origins
  buffer rewritten per frame, CPU frustum culling, cutout + directional
  shading with AO-aware triangle diagonals.
- app.rs / game main: link-driven client runtime (Hello/Welcome, 20 Hz
  PlayerInput, submit/upload budgets, clean exit on link death) and the
  in-process server wiring; wave A redraw/occlusion handling unchanged.
- texture_array.rs: average mip alpha linearly (was sRGB-bent) and set
  repeat addressing so merged faces tile per block.
- Screenshot tests mesh_blocks, mesh_ao, mesh_cube_border and
  mesh_far_origin (same golden as mesh_ao at ~1e9 blocks out); existing
  goldens unchanged. mesh bench: terrain_like median 244 us (<=300 us).
```
