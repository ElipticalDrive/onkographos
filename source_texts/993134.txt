Motivation
Enable streaming of an effectively unbounded voxel world by moving a world anchor so only nearby chunks are generated and rendered, keeping memory and CPU bounded.
Make remeshing incremental and local to affected regions to avoid expensive full-world rebuilds during anchor movement.
Description
Add a new WorldStreamer component that tracks the anchor chunk, generates missing chunks within a configurable visible radius, unloads distant chunks with a configurable unload radius (hysteresis), and rebuilds only dirty regions (voxels/src/main/java/voxels/editor/WorldStreamer.java).
Change EditorScene to attach WorldStreamer at startup instead of precomputing a full chunk grid and to initialize RegionRenderSystem for streaming usage (voxels/src/main/java/voxels/editor/EditorScene.java).
Extend VoxelWorld with streaming-friendly APIs: hasChunk, removeChunk, getChunks, getRegion, automatic empty-region cleanup on chunk removal, and deduplicated chunk insertion (voxels/src/main/java/voxels/world/VoxelWorld.java).
Replace region chunk list with a keyed map in Region to allow efficient add/remove and provide isEmpty and getChunks views (voxels/src/main/java/voxels/world/Region.java).
Refactor RegionRenderSystem to key the mesh cache by region coordinates, add buildMesh and invalidateRegion APIs, and make mesh building usable from both parallel startup and incremental streaming (voxels/src/main/java/voxels/render/RegionRenderSystem.java).
Implement dirty-region detection that also marks neighbor regions when chunks are added/removed on region borders so region meshes remain seamless across boundaries.
Testing

Attempted mvn test -DskipTests inside the voxels module but Maven plugin resolution failed due to network restrictions (Maven Central returned HTTP 403), so compilation/tests could not be completed in this environment.
Repository-level changes were committed and basic runtime behavior was validated by static inspection of modified classes (no runtime unit tests executed due to the above download restriction).
