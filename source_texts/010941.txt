This document evaluates and compares several Java-based volume rendering frameworks: Java3D API, Jogl (Java OpenGL API), a multi-histogram method, and WildMagic. It implements volume renderers for each framework using the platform-independent Java language. Quantitative performance tests measure frames per second and memory usage. The multi-histogram method interactively renders volumetric shading using data derivatives. Jogl and WildMagic use the GPU for parallel processing. WildMagic provides the best quality but is most difficult to extend, while the multi-histogram method has intuitive tools but slow performance with detailed data.
