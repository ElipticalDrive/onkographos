Closes #64.
Adds participating-media support (scattering / absorption / emission) integrated into the path-trace kernel, toggleable per scene.
Integrator
Free-flight distance sampling — analytic inversion of the homogeneous free-flight pdf p(t) = σ_t·exp(-σ_t·t). The sampled distance races the surface hit each bounce; if the medium wins, the ray scatters/absorbs before reaching geometry. This is delta tracking with the majorant equal to the real density, so the null-collision loop collapses to the closed form; sampleMediumDistance/mediumTransmittance are the only two functions a future heterogeneous density field would need to change.
Absorption vs. scattering — survival probability equals the single-scattering albedo σ_s/σ_t, which makes the surviving path weight exactly 1 (unbiased, minimum variance, no explicit transmittance factor in the throughput).
Henyey–Greenstein phase function — samplePhaseDirection with anisotropy g (0 isotropic, >0 forward, <0 back); the sample is drawn from the phase function so the estimator weight stays 1.
Volumetric NEE — sampleMediumDirectLight does single-scattering next-event estimation toward the area light: phase function in place of the BRDF, no cosine foreshortening at a volume vertex, and the light contribution attenuated by the Beer–Lambert (ratio-tracking) transmittance along the shadow ray.
Russian roulette and firefly clamping apply unchanged; MAX_VOLUME_SCATTERS bounds the tracking loop.
Two ways to use it
Global fog — volumetrics in src/constants.ts (density, scatterAlbedo, anisotropy, color, emission), uploaded as u_Fog* uniforms.
Bounded medium — new MATERIAL_VOLUME (7) primitive, packed vec3(type, σ_t, scatter albedo). Rays cross the index-matched boundary unrefracted and are tracked only inside the object's span. A demo fog sphere is added to the scene.
Non-volume scenes stay correct
volumetrics.density defaults to 0, which makes sampleMediumDistance return +inf — the surface branch is taken every iteration and transport is identical to the previous surface-only integrator. Both the vacuum short-circuit and the density gate are covered by tests.
Also fixes a pre-existing missing closing brace on isEmissiveMaterial in pathtrace.frag.
Verification
npx vitest — 35/35 pass (5 new tests across tests/shaders.test.ts and tests/constants.test.ts).
npm run lint (eslint) — clean.
npm run build (tsc + vite) — clean.
GLSL differential — the assembled shader was compiled with glslangValidator on this branch and on a pristine git archive export of origin/main. Both produce a byte-identical error set (a pre-existing .zw swizzle on a vec3 in the untouched triangle-unpack path, plus the assign-type error it causes), so this change introduces zero new shader errors. Those two are out of scope here.
feat: add volumetrics/participating media (closes #64)
