Summary
Two companion documents for rendering 8K (7680×4320) volumetric scenes with Blender 5.x + Cycles/OptiX on AWS Blackwell GPUs:
BLACKWELL_8K_MASTER_SPEC.md — the pipeline authority.
§§0–9 — the locked spec (engine/device, sampling, volumes, output/colour, camera, AWS instance/driver/storage/IAM/S3, proofs, headless render script, encode chain). Corrections against verified July-2026 AWS/Blender reality are marked [FIX], additions [ADDED].
§10 — gap check: instance decision table (why G7e/RTX PRO 6000, not P6/B200), worker bootstrap, quota/launch/IAM commands, dead-man switch + idle watchdog, numeric output-validation gates, failure→cause→fix table, first-run order of operations, and the unattended job runner (run_job.sh).
§11 — second-pass audit record: nine defects found in the spec itself, each fixed in place and marked [FIX v2 — Issue N].
VOLUME_LOOK_LAW.md — the look authority. Deterministic look-dev from six numbers measured off each dataset's cache (air floor, percentiles, gradient median, voxel size, depth): derivation formulas for threshold/ramps/opacity/boundary boost/density/emission, a fixed lighting/camera/colour rig, phase-selected quality tiers, and a symptom→knob iteration table. Cross-referenced with the master spec; its two deliberate overrides (biased volume integrator for tier step-rate control; 85 mm hero lens) are stated in place on both sides, and the six measurements ship with the job as look.json.
Key verified facts baked in
g7e (RTX PRO 6000 Blackwell SE, 96 GB, RT cores, plain On-Demand/Spot) is the right render box; P6/B200 has no RT cores, rents only as 8-GPU units, and benches ~half an RTX PRO 6000 in Blender Open Data.
Blender 5.0 breaking changes: media_type must be set before OPEN_EXR_MULTILAYER; the default unbiased volume integrator has no step-rate knobs (volume_biased gates them); tiling is always on.
Blackwell on Linux requires the open NVIDIA kernel modules and R575+; headless OptiX needs libnvoptix.so.1 (graphics driver package, not compute-only installs).
Frame-validation gate (oiiotool stats on AgX-baked proofs) tested empirically against black/gray/noise frames.
Second-pass audit fixes (§11)
False OptiX proof now actually renders; AMI-seed box launches with stop (terminate is workers-only); hero runtime ceiling derived from the smoke render; volume integrator committed (unbiased, biased as explicit budget fallback or look-law tier requirement); exact Blender build pinned with a refusing assert + guarded property setters; authoring boundary stated honestly (data→cache is a local manual pre-step, runner fails fast if the cache is missing); Spot launch profile actually configured (interruption-behavior=stop + resume); single driver floor.
