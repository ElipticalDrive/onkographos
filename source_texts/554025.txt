The historical MATLAB ray code can return the wrong voxel index and physical length for a segment ending inside a voxel, and its wrapper can overwrite the final sparse coefficient. This introduces a new shared C++11 traversal that exposes ordered voxel indices, physical lengths and entry/exit parameters, with a documented lower-corner coordinate convention.
The implementation includes NumPy packaging, matrix-free scalar forward/adjoint operations, cached symmetric rank-m LRT operators, MATLAB MEX/build/compatibility wrappers, scalar and tensor-block CIL LinearOperators, and examples for CGLS and noncommuting matrix transport. The old source is not bundled or relicensed; NOTICE credits David Szotten and Jacobs et al., and the existing Apache-2.0 LICENSE is preserved.
Validation: all 13 local Python tests pass, including 4,000 random rays against an independent plane-sorting oracle, scalar/tensor adjoint checks, complex ordered transport, and actual CIL integration at upstream commit b39f95799bf1af891a896fc4be704986284b593e. C++ CMake/CTest and ASan/UBSan checks pass (LeakSanitizer disabled for the container). Serial/OpenMP builds and wheel installation were exercised. Scalar CIL CGLS reaches a relative data residual of 1.68e-4 after 30 iterations; tensor CGLS also runs.
Keep this as a draft pending MATLAB MEX compilation/execution and review of numerical conventions. MATLAB is not installed in the development environment. GitHub CI covers Python on Linux/macOS/Windows, OpenMP and pinned CIL integration.
Performance is documented rather than assumed: the new one-pass serial kernel was about 19% slower than the old C kernel on the comparison workload. Benefits are corrected edge cases, explicit ordered intervals, allocation/memory improvements, optional parallel tracing/projection and geometry reuse. For 20,000 rays through a 64^3 grid, four-thread forward projection took 5.48 ms; cached CSR application took 1.62 ms, excluding matrix construction.
See README.md, docs/legacy-audit.md, docs/performance.md and docs/validation.md for the interfaces, measurements, limitations and reproduction commands. LRTinMatlab and the target repository's visibility are unchanged.
