This PR turns the repository from a placeholder into a runnable Rust game foundation aligned with the request: a Minecraft-like voxel sandbox using a modern Rust engine. It establishes core prototype gameplay primitives and adds explicit attribution guidance for Veloren-related reuse.
Project bootstrap (Rust + modern engine)
Initialized a Cargo binary project at repository root.
Added bevy as the engine dependency with explicit feature selection for rendering/windowing.
Prototype gameplay foundation
Replaced hello-world entrypoint with a Bevy app setup:
3D camera/player entity
Directional light + ambient light
Sky/clear color and window config
Added keyboard movement system (W/A/S/D, Space, Shift).
Added a simple daylight cycle system by rotating the sun transform.
Voxel world generation
Introduced src/world.rs with deterministic flat-world block position generation.
Spawned a 16x16 block terrain from generated voxel positions with alternating materials.
Documentation and attribution
Updated README.md with current scope, run/test commands, and attribution/licensing note referencing Veloren.
```
pub fn flat_world_positions(width: i32, depth: i32, y: i32) -> Vec<(i32, i32, i32)> {
    (0..width)
        .flat_map(|x| (0..depth).map(move |z| (x, y, z)))
        .collect()
}
```
