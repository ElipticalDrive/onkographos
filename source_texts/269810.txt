What feature do you want?
A Bounding Volume Hierarchy (BVH) acceleration structure to dramatically speed up ray-object intersection tests in complex scenes.
Why is it needed?
Currently, every ray tests against every object in the scene (O(n) complexity per ray, O(n*m) for n objects and m rays), making renders with 1000+ objects prohibitively slow. A BVH reduces this to O(log n) per ray by organizing objects into a hierarchical tree structure, providing 10-100x speedups and enabling practical rendering of complex scenes.
Expected implementation
Ray intersection should hierarchically traverse a binary tree of bounding boxes
Only test rays against objects within intersected bounding volumes
Early exit when ray misses a bounding box (skipping all children)
Build tree automatically from scene objects before rendering
Output should be pixel-identical to current implementation
Possible approach
Create an AABB (Axis-Aligned Bounding Box) class with ray intersection using the slab method
Implement BVHNode class as a binary tree that recursively subdivides objects
Add bounding_box() method to all hittable objects (Sphere, HittableList, etc.)
Construction: recursively split objects by sorting along a random axis; create leaf nodes for 1-2 objects
Replace direct world intersection with BVH root traversal in rendering loop
Files needed: aabb.py, bvh.py
