Trenchblocks MagicaVoxel Map Format
Trenchblocks maps are standard MagicaVoxel .vox files with additional conventions. The binary container, chunks (SIZE, XYZI, RGBA, nTRN, nGRP, nSHP, dictionaries, palette index 0 = empty, etc.) are MagicaVoxel as documented in ogt_vox.h.
This document only describes Trenchblocks-specific constraints and meanings.
Overview

Fixed meta / reserved / map layout (see below)
Larger maps (T5..T8) are not defined. More than four 256 x 256 tiles is invalid.
Map box
Export uses an axis-aligned map box (xmin, ymin, zmin) + (sx, sy, sz):
1 <= sx,sy <= 512
1 <= sz <= 256
At least one solid voxel inside the box
Voxels outside the box are discarded
Tile grid (T1..T4)
Always a fixed 2 x 2 of MagicaVoxel models. Each model SIZE is (256, 256, sz) even if the map box does not fill the quadrant. Empty models are still written.

```

```
World to local:
```
tx = floor((x - xmin) / 256)
ty = floor((y - ymin) / 256)
local = (x - ox, y - oy, z - oz)
```
Scene order
Models and named scene nodes appear in order T1, T2, T3, T4 (model ids 0..3). Not grid scan order.
Each tile nTRN has:
_name = T1 / T2 / T3 / T4
_t = tile center in world space: (ox + 128, oy + 128, oz + sz / 2)
Scene topology: root nTRN -> nGRP of four (nTRN + nSHP) pairs.

Index 7 is pure black. Identify it by palette index, not RGB alone. Terrain black must use a slot in 17..255.
Map colors (17..255)
Terrain remaps into this range. Exporters may:
Seed a compact forced atlas of opaque map colors from index 17
Apply optional color-reduction steps (median cut, octree, Wu, k-means, or uniform snap), preserving forced colors
Fill remaining free slots with a final quantize pass
Assign each terrain voxel the nearest opaque entry in 17..255 by L1 RGB distance; fallback index 17
Gameplay markers (stamps)
Markers are solid voxels with meta indices 1..8. At the same cell, a stamp overrides terrain color.
Placement
Build a heightmap of the highest solid map z per (x, y) in the box first.
Source
Placement
Point2D / Zone2D
Empty column -> z = zmin; else z = top + 1
Point3D / Zone3D
Exact authored coordinates (not lifted)
Stamps must stay in zmin .. zmin + 255; exceeding height 256 is invalid
Same cell: last stamp wins
Effective sz may grow to include stamps (still <= 256)
Recognized meta names (group name if grouped, else object name):
FlagRed, SpawnRed, FlagBlue, SpawnBlue, PickupHealth, PickupAmmo, PickupSatchel, SpectatorSpawnPoint
Spawn filtering (LayersPlayerSpawn)
Optional CSV of layer names that hold player-spawn geometry (tokens trimmed of ASCII space/tab).
When non-empty and at least one listed layer exists:
Blocking volume = visible layers whose names are not in the CSV
SpawnRed / SpawnBlue only: skip if blocking has any solid in that XY column (2D) or that exact cell (3D)
If no listed layer exists, filtering is off. Other meta types are never filtered.

Validation checklist
Valid MagicaVoxel .vox per ogt_vox.h
Exactly four models, scene-named T1..T4 in that order
Each SIZE XY is 256 x 256; shared Z in 1..256
Empty quadrants still present (empty models + named nodes)
Palette 1..8 match the meta RGB table (opaque)
Palette 9..16 unused for map geometry
Tile _t centers consistent with some shared map-box origin
