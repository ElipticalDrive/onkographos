Descripción
Partículas colisionando contra world SDF en un compute dispatch: 1 thread por partícula, 1 SDF query, push-out + velocity reflection. Sub-millisecond para 100k partículas. #97 es solo "Decisión" sin implementación concreta. Mayor impacto visual con menor esfuerzo.
Tareas
Compute shader: 1 thread per particle, eval SDF at particle position
Collision response: push-out along SDF gradient + velocity reflection
Friction: reduce tangential velocity on contact
Particle lifetime reduction on impact (configurable)
Spawn sub-particles on impact (sparks, splashes)
Configurable collision response per particle type (bounce, stick, slide, die)
SDF world query (scene SDF evaluation)
SDF object query (per-object SDF in local space)
Benchmark: 10k, 100k, 1M particles vs SDF
Criterios de Aceptación
100k particles colisionan contra SDF world < 0.5ms
Particles rebotan correctamente en superficies SDF
Sin particles atravesando superficies (tunneling)
Friction visible: particles ruedan por pendientes
Configurable: rain sticks, sparks bounce, snow slides
Ejemplo de Código
```
struct Particle {
    position: vec3<f32>,
    velocity: vec3<f32>,
    lifetime: f32,
    particle_type: u32,
}

@compute @workgroup_size(64)
fn particle_sdf_collision(@builtin(global_invocation_id) id: vec3<u32>) {
    let idx = id.x;
    if idx >= params.particle_count { return; }
    
    var p = particles[idx];
    if p.lifetime <= 0.0 { return; }
    
    let dist = eval_scene_sdf(p.position);
    
    if dist < params.particle_radius {
        let normal = calc_sdf_normal(p.position);
        
        // Push out of surface
        p.position += normal * (params.particle_radius - dist);
        
        // Velocity reflection with restitution
        let vn = dot(p.velocity, normal);
        if vn < 0.0 {
            let restitution = particle_params[p.particle_type].restitution;
            let friction = particle_params[p.particle_type].friction;
            
            let v_normal = normal * vn;
            let v_tangent = p.velocity - v_normal;
            
            p.velocity = v_tangent * (1.0 - friction) - v_normal * restitution;
            
            // Lifetime reduction on impact
            p.lifetime -= particle_params[p.particle_type].impact_lifetime_cost;
        }
    }
    
    particles[idx] = p;
}
```

Notas Técnicas
1 SDF eval per particle = O(n) total, fully parallel
SDF gradient (normal) via central differences: 6 SDF evals per particle
Para tunneling prevention: marchamos a lo largo de velocity (mini-CCD, 2-3 steps)
