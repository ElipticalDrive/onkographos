Summary
While I was writing some additional Tests for the Geometric objects I found a bug where if a ray is perpendicular to the sphere it will return the distance from the sphere minus the radius of the sphere. this is likely due to using the dot product during calculation.
Example Code
```
 BoundingSphere sphere = new BoundingSphere(Vector3.Zero, 1);

Assert.AreEqual(null, new Ray(Vector3.UnitY * 4, -Vector3.UnitY - Vector3.UnitX * 2).Intersects(sphere)); 
// The Distance returned is 3
Assert.AreEqual(null, new Ray(Vector3.UnitY * 5, -Vector3.UnitY * 1 - Vector3.UnitX * 1).Intersects(sphere));
// The Distance returned is 4
Assert.AreEqual(null, new Ray(Vector3.UnitY * 5, -Vector3.UnitY * 1 - Vector3.UnitX * 1000).Intersects(sphere));
// The Distance returned is 4
```
What version of MonoGame does the bug occur on:
MonoGame 3.7

Windows
