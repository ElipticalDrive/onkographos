Motivation
Move the renderer toward a chunked vertex-buffer pipeline (16×16×16 chunks) to enable batched meshing and reduce per-block draw overhead.
Reduce rendered geometry by emitting only visible faces (faces adjacent to air) and prepare a proper atlas/UV mapping strategy for 16×16 textures.
Improve player movement feel and robustness by using an AABB-aware player with step-up support and a slightly stronger ground friction to match the requested momentum model.
Description
Added a 16×16×16 byte-ID chunk container world.VoxelChunk and ChunkWorld.buildVoxelChunk(...) to snapshot world sections for meshing.
Introduced graphics.MeshBuilder and graphics.ChunkMesh which iterate a VoxelChunk, perform hidden-face/backface culling (emit a face only when adjacent cell is air) and append a single contiguous FloatBuffer per chunk with vertex layout position + UV + normal.
Added graphics.TexturePack (atlas & per-face tile loading with classpath fallback), game/tiles/TEXTURE_STANDARD.md and rendering helpers that set image smoothing off to preserve 16×16 nearest-neighbor look; FirstPersonRenderer and CameraRenderer were adapted to use the atlas/fallback and non-blurred sampling.
Converted player/physics to volume-aware behavior by adding AABB constants (RADIUS = 0.3, HEIGHT = 1.8, STEP_HEIGHT = 0.5, EYE_HEIGHT = 1.62), split axis movement (moveAxisX/moveAxisZ) with step-up checks, and tuned PhysicsEngine to include tick-scaled friction (GROUND_FRICTION_PER_TICK = 0.91), jump buffering, coyote time, terminal velocity, and bounded collision resolution.
Added UX/game scaffolding: FXGameState, FXGameUpdateSystem, FXGameRenderSystem, FXGameInputHandler, FXGameAssets, HudRenderer, simple gameplay systems (MiningSystem, Inventory, CraftingSystem), BlockVisuals, and ChunkWorldIO save/load utilities.
Small fixes: ChunkCommandExecutor.fill(...) now reports the actual filled count, world.BlockType extended with atlasId/per-face texture names and hardness for mining, and Raycaster step constant was centralized.
Testing
Non-JavaFX compile check succeeded with: cd game/src && mkdir -p /tmp/voxel-build && javac -d /tmp/voxel-build -cp ../lib/json.jar world/*.java engine/*.java gameplay/*.java commands/*.java graphics/CameraRenderer.java graphics/ChunkMesh.java graphics/MeshBuilder.java Main.java AIClient.java which completed without errors.
Attempted full compile including JavaFX UI with javac -cp ../lib/json.jar world/*.java engine/*.java gameplay/*.java commands/*.java graphics/*.java ui/*.java Main.java AIClient.java FXGame*.java and it failed in this environment because JavaFX classes/toolchain are not present (expected limitation of this container).
No automated unit tests were added; validation consists of the non-UI compile and the static checks described above.
