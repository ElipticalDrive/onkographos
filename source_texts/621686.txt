```
Adds proper non-uniform scaling support following Inigo Quilez's canonical
SDF reference (https://iquilezles.org/articles/distfunctions/):

  float opScale(vec3 p, float s, sdf3d primitive) {
    return primitive(p/s) * s;
  }

Key implementation:
- generateScaledNode() wraps any node with scale transform
- Uniform scale: exact SDF (multiply distance by s)
- Non-uniform scale: conservative bound (multiply by min(s.x, s.y, s.z))

As IQ notes: "Non uniform scaling is not possible (while still getting
a correct SDF)" - the min() approach prevents raymarcher overshoot.

This fixes flower-meadow.json where petals use scale: [1, 0.4, 1] to
flatten spheres into disc shapes. Previously scale was ignored entirely.
```
