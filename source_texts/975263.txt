Description
For scientific visualisation, Gouraud shading is often used. It would be nice if typst provided this: Coons Patches, Tensor product patches, Free-form gouraud meshes.
Supported in PDF: https://opensource.adobe.com/dc-acrobat-sdk-docs/pdfstandards/pdfreference1.7old.pdf
Supported in SVG through JS: http://tavmjong.free.fr/SVG/POLYFILL/MESH/mesh.html
Use Case
Scientific visualisation, sophisticated drawings
Gouraud shading currently could be implemented using https://web.archive.org/web/20080222025310/http://www.svgopen.org/2005/papers/Converting3DFaceToSVG/index.html, but I assume this will result in ugly antialisasing fringes between adjacent rectangles.
