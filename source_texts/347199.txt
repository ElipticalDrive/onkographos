Implements three distinct rendering strategies for visualizing hundreds of millions of drillholes as exaggerated 3D pipes on a globe, each optimized for different constraints.
Algorithms
LOD + Octree Spatial Indexing (algorithm_lod.py)
O(log n) spatial queries via octree
Distance-based LOD with deterministic hash sampling
Frustum culling for visible set reduction
Hierarchical Clustering (algorithm_clustering.py)
Multi-level k-means (configurable depth)
Dynamic aggregation: individual drillholes near camera, cluster representatives at distance
Representative selection via centroid proximity
GPU Instanced Rendering (algorithm_gpu.py)
Instance buffer layout (position, direction, scale, metadata)
Complete shader pipeline (vertex/fragment/compute)
Compute shader frustum culling
Core Infrastructure
Base Classes (drillhole_visualization.py)
Lat/lon → Cartesian conversion
Bounding box computation
Cylindrical pipe geometry generation (configurable segments)
Quality Levels: LOW | MEDIUM | HIGH | ULTRA - adjusts culling aggressiveness and sampling rates
Usage
```
from algorithm_lod import LODVisualizationAlgorithm
from drillhole_visualization import Drillhole, VisualizationQuality

drillholes = [Drillhole(lat, lon, depth, diameter) for ...]

algo = LODVisualizationAlgorithm(exaggeration_factor=1000.0)
algo.prepare_data(drillholes)

visible = algo.get_visible_drillholes(
    camera_position=(7000000, 0, 0),
    camera_direction=(-1, 0, 0),
    quality=VisualizationQuality.HIGH
)
```
