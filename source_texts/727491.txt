Hi,
For your 1st question, eul2rotm is converting Euler angle to rotation matrix, not "Axis-angle" vector to rotation matrix. This code uses Rodrigues / Axis-angle format because original Tsai method using this formulation, and data provided in this repo is also in Axis-angle format.
For your 2nd question, I donot know any code that implement "eye-out-of-hand" calibration, because for my project its "eye-in-hand". But mathmatically, these two configuration have the save solving method. You can find some tutorial and convert to your configuration.
Good luck~
