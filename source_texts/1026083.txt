This now works:
```
tasks:
  - schema: generate_volume_element_from_voronoi
    inputs:
      microstructure_seeds::from_file:
        path: <<demo_data_file:seeds.txt>>
        box_size: [1, 1, 0.5]
        phase_label: Cu
        delimiter: ","
        columns: [0, 1, 2]
      orientations::from_file:
        path: <<demo_data_file:quaternions.txt>>
        delimiter: "   "
        start_index: 1 # header row
        unit_cell_alignment:
          x: a
          y: b
          z: c
        representation:
          type: quaternion
          quat_order: vector_scalar
      homog_label: SX
      VE_grid_size: [4, 4, 2]
      periodic: true
```
Added a test as well.
The MicrostructureSeeds and Orientations ParameterValue classes must be imported when the script runs, since that's how hpcflow discovers the classes.
