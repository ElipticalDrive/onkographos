What's new in Huygens 26.10
This release makes stitching easier than ever with the new Stitch Express tool, and then use the new high resolution 3D rendering for Resolution Pyramids in the MIP renderer to inspect the results. In the Object Analyzer, you can now directly create plots of your results with the new Data Analyzer tool. Segmentation has been improved as well: Cellpose 3D now supports both Cellpose-SAM as well as older models, and a brand new
segmentation mode for segmenting spots has been introduced. Additionally, this release introduced support for deconvolving Nikon NSPARC images. Other than that there are many more improvements, as presented in the list below.
(E/P) Huygens Stitch Express:
New tool for stitching which automatically stitches and deconvolves images that contain the necessary metadata.
(E/P) Huygens Stitcher:
Changed how the corner overlap is stitched. This fixes an uncommon bug where normalization of tile corners was wrong but it changes all stitch results a little bit.
There are now choices for how to combine the overlap regions of tiles.
If corner to corner overlap is relatively small it is now skipped while estimating the best overlaps. This can improve results slightly due to these corners having the least reliable contributions to the best overlap position estimations. And if tiles are very big it siginifically improves processing speed.
Made it possible to do stitch jobs with few large tiles in limited RAM.
Now more completely supports deconvolution template, it is now possible to use "Automatic" deconvolution. Only bleaching stays not supported.
(E/P/C) Deconvolution:
More robust automatic Signal-to-Noise estimation leading to more reliable deconvolution results.
Array Detector Deconvolution:
Add deconvolution support for the Nikon NSPARC array detector confocal microscope.
(E/P/L) Object Analyzer:
Added new Data Analyzer tool for plotting the analysis results.
Added new segmentation mode for analyzing spots.
Cellpose 3D:
Added support for Cellpose-SAM models.
Improved rendering and analysis after using Cellpose 3D segmentation.
Added interactive threshold based on the cell probabilities.
The install location of Cellpose packages can now be customized.
Cellpose 3D & AI segmentation:
Added support for for Blackwell generation GPUs (e.g. RTX 50xx cards).
Installation is now also possible on most networks behind a proxy server.
Changed the "Intensity in the other channel" analysis preset to "Intensity in each channel". It now reports intensities for all channels, instead of only the ones selected in a segmentation group.
Reorganized the analysis presets related to distances. These are now grouped by the type of distance being measured (CM-to-CM, CM-to-surface, or surface-to-surface).
Added interface for grouping objects. This succeeds the "anchor" mechanism from previous versions.
(E/P) MIP Renderer:
Add resolution level rendering for Resolution Pyramids to improve interaction and quality.
(E/P) Surface Renderer:
Added color schemes to surfaces to allow more freedom in coloring
(E/P/L) 3D Renderers:
Double click in the MIP or Surface Renderer to change the rotation point
Added different panning mode to change the rotation point also in the Z dimension
(E/P/L) Movie Maker:
Added support for saving movies as mp4 files. This applies to movies in other render tools as well.
(All) File Formats:
HDF5: Improve loading speeds for very large HDF5 files with many tiles or time frames.
ND2: Allow reading of all Raw NSPARC 25-detector datasets when present in ND2 files.
Minor changes
(E/P/L) Huygens Everywhere:
Improved server-side code in order to speed up login handling.
(E/P/L) Workflow Processor:
Changed how result names are constructed. Now they contain less redundant information and always have the suffix at the end of the name.
Added the option to customize the suffix in the result name.
A temporary 'inProgress' version of the template file is put in the result folder while processing. This file isn't removed if the processing fails, which helps investigating issues. It also solves possible race conditions while parallel processing.
Before starting any workflows all images on GPU VRAM are moved to system RAM to give the Workflow tasks as much VRAM as possible.
Added the 'Convert' task to the Workflow Processor in the Localizer, so images read as Z-stack can be converted to a time series.
(P/L) Python Scripting:
Updated the Huygens Python version from 3.11 to 3.14.
Updated Numpy version from 1.26.2 to 2.3.5.
Changed the way how Huygens saves the Python module paths set in the preferences, the directory path saved is now a few levels higher. See the manuals for instructions on how to set these module paths.
(C) Huygens CLI (command line interface):
If the '-imgOpen' and/or '-resultDir' argument are found but not valid the execution is now aborted.
The output after getting bad aguments is now more informative. Allowing easier bugfixing of scripts calling the CLI.

Improved crosstalk estimation for low signal data.
Improved consistency of the result of the 'Fast mode'.
Added deconvolution (with bleaching correction enabled) as a recommended solution to solve bleaching.
Added an easier way to export results as a CSV.

Show warnings when doing restoration operations more than once by accident.

For ome-tiff clarify the sizes of resulting image when using load according to xml meta data and indicate when this might be preferred.

Improve the drift corrector in the Localizer wizard.

26.04 release
This release brings new Cellpose 3D integration in the Object Analyzer, as well as in the Workflow Processor. 3D renderers now contain free camera movement around and through objects. For the Stitcher this release brings a drastic speed improvement in stitching and vignetting correction. For all the new features and other changes, see below:
(E/P/L) 3D Renderers:
All 3D Renderers have an extra option where you can freely move the camera around and through the object.
Added different surface rendering material presets to customize the surface look using e.g. transparency or shininess.
(E/P) Deconvolution Express:
Improved deconvolution of short or curved filaments
Improved SNR estimation and deconvolution of Aurox images.
(E/P) Huygens Stitcher:
Drastically improve processing speed for stitching time series in the stitcher for several file formats (CZI, OBF, HDF5, ICS).
Stitcher layout can now be drawn from 2D Slices to speed up the verification of the tile layout.
Both vignetting estimation methods (region-based and radial-based) are significantly faster on large tiles.
Updated icons in user interface.
(P) Input tiles from a single container image file (like .czi, .lif, .lux.h5) can be converted to Huygens pyramid HDF5 files once, which will speed up subsequent reading, especially if not all tiles fit in RAM.
(P) Stitcher layout can be drawn from a lower-resolution version of the image if the input is available as Huygens Pyramid HDF5 files.
(E/P/L) Object Analyzer:
Added Cellpose segmentation.
Added support for having multiple elements in a Region of Interests (ROI) active at the same time. This way it is possible to e.g. have one ROI element per cell, and then get analysis results on a per cell basis.
Most operations that add to the ROI now add one or more new elements to it.
Most operations that modify the ROI now modify each element individually.
Using the "Analyze ROI" button now gives a result for each ROI element.
The "Grow ROI" option is now faster and gives more natural results.
New Experiment report editor window, for easier analysis parameter selection.
New data table with improved clarity, basic hide and sort options, and additional infographics.
Data CSV export:
Added export options to filter data and configure CSV settings.
Improved CSV structure to enhance usability for data analysis.
Workflow Designer:
Added Cellpose segmentation and AI segmentation to the Workflow Designer.
Added a task for saving the ROI to the Workflow Designer.
(E/P) Colocalization Analyzer:
Added support for having multiple elements in a Region of Interests (ROI) active at the same time. This way it is possible to e.g. have one ROI element per cell, and then get Colocalization results on a per cell basis.
Added Otsu-threshold to the automatic threshold estimation methods.
Threshold settings are now confirmed explicitly when measuring colocalization in time series, if not all frame thresholds were set by hand.
Added more progress reporting during threshold estimation methods.
(E/P) Multi Renderer:
Added new render tool that can compare 2D slices and 3D MIP projections.
(P) Workflow Processor:
Added the option to output files in "Resolution pyramid HDF5 format".
The "Stitch images" task detects the output format "Resolution pyramid HDF5 format" and stitches the result directly into the output. This makes stitching much more memory efficient.
(P) Resolution Pyramids:
The histogram of a resolution pyramid can now be computed while the data is in RAM for another operations. This makes it significantly faster as it saves a round of file IO, for example when generating a pyramid.
A pyramid result of the Stitcher now has the histogram already computed.
(All) File Formats
File Readers:
OIB: Added support for reading OIB (Olympus Image Binary) files.
HDF5: Improve the parsing of the geometry for sub resolutions of BigDataViewer bdv.h5/xml pairs.
File Writers:
All: increased the allowed file name length from 127 to 255 bytes (ascii characters).
HDF5: Updated the internal layout of the Huygens HDF5 format. HDF5 files written in the 26.04 cannot be read by earlier Huygens versions. Files written by earlier Huygens versions can still be read by the 26.04.
HDF5: Added support for exporting/saving images in HDF5 format that is compatible with Bio-Formats and BigDataViewer.
This still writes a regular Huygens HDF5 filename.h5 including all meta data.
Two accompanying files with filename_bdv.h5 and filename_bdv.xml are written that can be read by Bio-Formats and BigDataViewer.
(P) A resolution pyramid can also be saved (for export) in a BigDataViewer compatible file.
Minor Changes
(E/P/L) User Interface:
Added new render interface used in Decon Express, Stitcher, Hot/cold pixel corrector, Bleaching corrector and Operations window.
(E/P/L) License window:
Updated GUI. Summarized less-relevant information and added more relevant information.
It is now possible to open this window from the main Huygens window via a button that describes the currently active license at a glance.
(E/P/L) Object Analyzer:
After selecting an area, a menu is now shown with features that the area can be used for.
Added more options to the right-click menu.
Use a more concise and consistent selection of parameters for the "Small particles geometry" preset.
(All) Image histograms:
For integer data increase the binCnt of a computed histogram. This improves the accuracy of the histogram and makes it easier to create histograms with a smaller binCnt from one with a larger binCnt.
(P) Operations Window:
Added "Rolling ball" filter. This filter removes uneven backgrounds and can be useful for visualizing and analyzing data with large background variations.
(All) Windows:
Enabled long path support for Huygens on application level. This implies that if a windows system/computer also has long paths supported, file paths longer than MAX_PATH (260 characters) should work smoothly.
Bug fixes
(E/P/L) File series tool:
Improve the image names when using the separate image/tile/ tile (2nd) counter for a counter without leading zero's, i.e. 1,2,3,...,11,12.
Allow the use of an ignored counter when (only) a separate image counter is used to open multiple files.
MacOS only: fix the file series tool hanging when opening a file series using drag and drop.
(E/P/L) Workflow Processor:
Extra file open settings task: for a file series fix a potential issue with reading the data when decreasing the 'From' value of a counter.

25.10 release
Summary:
Huygens 25.10 supercharges your image segmentation with AI templates, in 2D and 3D! System-wide 16-bit float support delivers up to 2x speed increases for analyses. Removing Hot & Cold pixels is now easier than ever with automated detection. Visualize your terabytes large datasets, even on a laptop! From broad, structural overviews down to the smallest detail, view massive images with ease using the new Resolution Pyramids, exclusive to Professional. With a complete refresh of the UI across all products—and a new native app on MacOS Ventura (>13)—Huygens both looks sleeker and loads faster. True to our dedication to support the whole microscopy community, Huygens now also offers an option for deconvolution for Aurox microscopes.

(All) Change in scripting with images/tables:
Creating images or tables returns a handle instead of their name.
Handles are to be used for Tcl and Python scripting.
Previously, the image name served this purpose and images could therefore not be renamed.
Rename images or tables without creating copies
Right-click the thumbnail and select "Rename Image/Table" or press F2 as a shortcut.
Use Tcl scripting with the rename command 'oldName rename newName'

All Huygens Products
New way to handle shape changing PSFs
The shape of PSFs suffering from spherical aberration due to refractive index mismatch is dependent of their depth position in the specimen. Previously this was solved by splitting the image into 'bricks', each with their own PSF. Though efficient, this could give rise to difficult to avoid gluing artifacts. With the new 'sub-brick' method, the Fast Fourier Transform (FFT) based convolution operations which are the heart of all deconvolution algorithms, are replaced by multiple FFTs, each with different PSFs. This new technique is available for the CMLE, QMLE and the new GMLE deconvolution algorithms.
GMLE
The GMLE algorithm is based on the Maximum a Posteriori probability estimation with Good's roughness regularization. It is related to our workhorse CMLE algorithm, but has rapid convergence like the QMLE algorithm. Using the newly developed sub-brick scheme, it is able to deal with shape changing PSFs without resorting to brick-wise processing.
GMLE is by default available for STED data. To use GMLE in the Deconvolution wizard for other imaging modalities 'Expert mode' needs to be switched on.
New product Huygens Titan
Indexes all your microscopic images. Titan is a local indexer; you don't need to upload and convert your files to a centralized database, the images and the database stay on your personal computer.

The brand new option called the 'Object Stabilizer' (currently in beta) to measure and correct for cell motion, thermal drift, shaking, and other types of movement. It can stabilize and align by means of:
cross correlation;
object tracking;
center-of-mass alignment.
Optical parameters now also include the coverslip position and the imaging direction for improved handling of spherical aberration, in turn leading to improved deconvolution results.

Visualization templates for all our 3D renderers, so you can store your favorite views and reuse them with other datasets.

Quicker creation of LIF sub-image jobs.
New options for TIFF format output: scaled or clipped results.
The Colocalization Analyzer can export the 3D colocalization map as an image, or as a new channel to the original stack. You can later take this map into the Object Analyzer for more complex analysis.
The Object Analyzer contains many new features, like:

Analysis history that you can save, to reproduce the analysis with the same dataset or reuse with other datasets. This also facilitates batch analysis.
Undo mechanism, to quickly revert for example an unfortunate object deletion or filtering.
Import analysis and visualization conditions from any other open O.A. instance, so that you can replicate them for different datasets.
Render all objects with their accompanying numerical label, for easier analysis reference.
Reference 3D cube to know the orientation of the dataset even at large zooms.
Cropped datasets can be exported as new channels to the original image, not only overwriting the original ones.
Optional on-screen tips to guide you.
More possibilities for setting the ROI.
More possibilities for selecting anchors, also by filtering the objects based on the reported parameters.
Discarded objects and selected anchors are remembered, for the current segmentation parameters, when changing frames in a time series or channels in a pipe.
