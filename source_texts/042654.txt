Event camera has the advantages in high temporal resolution and dynamic range and therefore can be used to improve various computer vision tasks such as optical flow, video frame interpolation or video enhancement, which are illposed problems to conventional color frame cameras. To utilize event camera for these tasks, the raw event data is usually represented as voxel grid so that it can be processed as structured imagery data by deep learning models. However, explicitly storing the event voxel grid is very inefficient because event data is spatiotemporally sparse, resulting in a lot of empty voxels. Therefore, in this work, we proposed a learning-based framework to represent event voxel grid using neural networks and/or neural features. Three neural representations are proposed and analyzed: 1) MLP, 2) Tensor Decomposition, and 3) Hash Encoding. Experimental results validate the pros and cons of each representation and reveal potential future research directions.
