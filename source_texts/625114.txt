Goal
Port the tileable 3D noise primitives from sebh/TileableVolumeNoise into Rust so we can generate the same noise textures that clayjohn/realtime_clouds uses offline.
What to implement
crates/aether-engine/src/clouds/noise.rs (new module):
worley_noise(p: Vec3, cell_count: f32) -> f32 — returns distance to nearest cell point, tileable over [0,1].
perlin_noise(p: Vec3, frequency: f32, octaves: i32) -> f32 — FBM Perlin, tileable.
worley_fbm(p: Vec3, cell_counts: &[f32], weights: &[f32]) -> f32 — weighted sum of multiple Worley octaves.
perlin_worley(p: Vec3, ...) -> f32 — Perlin remapped into Worley range as described in GPU Pro 7 / HZD.
Helper remap and smoothstep mirroring the C++ versions exactly.
Tests (TDD)
worley_noise returns values in [0, 1].
perlin_noise returns values in [0, 1].
Both are tileable: f(p) == f(p + (1,0,0)) for integer cell counts.
Deterministic: same seed/inputs give same output.
Save a 2D slice of each noise to tests/output/clouds/phase0/noise_slice.png for visual sanity.
Acceptance criteria
cargo test -p aether-engine --lib passes.
Generated noise values match the reference C++ implementation within 1% on a fixed set of samples.
Screenshot folder tests/output/clouds/phase0/ is created and populated.
