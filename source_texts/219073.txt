Goals
Add GPUCommandGraph operations for mesh geometry and point-cloud processing, with interactive examples that keep processed attributes on the GPU.
Changes

Add @luma.gl/gpgpu/gpu-pointcloud: deterministic voxel representatives with source IDs/population counts, plus exact bounded radius filtering.
Add additive GPU octrees with immutable source positions, a source-index buffer, contiguous node ranges, deterministic sampling, and capacity reporting.
Add a progressive octree example with tile bounds, source/visible counts, and the GPU Graph panel.
Add side-by-side labs with synchronized orbit controls, logarithmic population-based point sizing, a 2–16 voxel grid control, input-grid visualization, and source/filtered counts.
Put controls in the standard top-left infobox and expose a reusable GPU Graph debug tab backed by the existing inspector.
Add API documentation, catalog entries, thumbnails, GPU correctness tests, and API contract tests.

Limits
The voxel grid is dense and bounded. Radius filtering is exact O(N²), intended for bounded clouds or reduced voxel representatives; it is not an accelerated large-cloud neighbor search. The additive octree processes resident packed data with maximum depth 10; streaming and view-dependent traversal remain future work. Mesh topology is supplied explicitly as CSR adjacency. GPU timestamp samples are displayed only when provided; the lab currently records CPU encoding timings.
Note
Medium Risk
Large new experimental compute surface (especially the multi-pass octree) with strict buffer/view contracts; risk is mitigated by extensive tests and validation, but incorrect caller topology or binding layout can still produce silent wrong results.
Overview
Adds experimental WebGPU GPUCommandGraph operations for mesh geometry and point clouds, plus interactive labs that render from GPU buffers with minimal readback.
@luma.gl/gpgpu/gpu-geometry introduces GPUMeshNormals, GPUMeshVertexNormals, and pinned Jacobi GPUMeshSmoothing, composed with caller-supplied CSR topology. @luma.gl/gpgpu/gpu-pointcloud adds deterministic voxel downsampling (min source ID + population counts), exact O(N²) radius outlier filtering, and GPUPointCloudOctree for sparse additive tiles (Morton sort, scans, source-ID ranges without reordering positions). A shared getSpatialOperationNodes helper generates WGSL compute kernels and enforces WebGPU writable-binding disjointness (256-byte alignment).
Package exports, API docs, catalog entries, and three WebGPU examples ship with a shared gpu-spatial-lab template (side-by-side views, graph debug tab, voxel grid / count sizing for point clouds; dedicated octree demo with progressive detail). Vitest adds WebGPU correctness tests and node contract tests for capacities, aliasing, and octree overflow semantics. compact-dropdown switches dataset access to bracket notation for stricter TypeScript.
