Summary
Add comparison_gaussian_splatting, a forward-only CUDA Gaussian surfel renderer for robotics map visualization.
Render a synthetic 3D map as sparse CPU Gaussians vs dense CUDA Gaussians, plus a CUDA opacity/density panel.
Add docs, CMake target, README entries, and publish comparison_gaussian_splatting.gif to gh-pages.
Results
Latest local run:
Correctness check on 2,048 Gaussians: CPU 35.07 ms, CUDA 29.624 ms, accumulator MAE 0.000000.
Animated average: CPU 66.84 ms/frame for 4,096 Gaussians, CUDA 0.77 ms/frame for 65,536 Gaussians.
Per-Gaussian throughput: CUDA 0.0118 us vs CPU 16.319 us, about 1381x faster.
Notes
This is intentionally forward-only. It does not add 3DGS training, SH colors, COLMAP loading, or sorted alpha compositing; those can be follow-up PRs if needed.
Validation
rtk cmake -S . -B build
rtk cmake --build build --target comparison_gaussian_splatting -j$(nproc)
rtk ./bin/comparison_gaussian_splatting
