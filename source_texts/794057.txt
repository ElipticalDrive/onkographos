# Point Cloud Registration & Evaluation

This project implements a complete pipeline for aligning two 3D point clouds using a combination of **Global Coarse Registration (RANSAC)** and **Local Fine Alignment (ICP)**. It also includes a custom implementation of the **Chamfer Distance** metric to evaluate the quality of the registration.

![https://miro.medium.com/v2/resize:fit:1200/1*n8bSN3EZKB9qxX27gdOvug.png](image.png)

## Features

* **Two-Stage Alignment:** Combines RANSAC-based global registration for rough alignment and ICP for high-precision refinement.
* **Feature Extraction:** Uses Fast Point Feature Histograms (FPFH) to identify correspondences between point clouds.
* **Custom Evaluation:** Measures geometric similarity using a manually implemented Chamfer Distance algorithm optimized with KD-Trees.
* **Visualization Ready:** Generates `.ply` files compatible with CloudCompare and Open3D.
