Summary
This PR replaces the previous shader-based edge rounding system (normal bending + dithered alpha clipping) with a geometry-level beveling approach that only applies to the chunk containing the player camera. The new system adds per-vertex offset data to the mesh, allowing actual silhouette edges to be chamfered inward, providing a more convincing rounded appearance while maintaining performance for distant chunks.
Key Changes
Meshing System
FHktVoxelMesher: Added BevelSize and FHktVoxelMeshNeighbors* parameters to MeshChunk(), MergeQuads(), and EmitQuad() methods
Silhouette Detection: Implemented per-corner bevel offset calculation in EmitQuad() that:
Probes neighboring cells (including across chunk boundaries via neighbor pointers) to detect silhouette edges
Applies inward offset (in-plane) and normal-opposite offset (into solid) only to silhouette corners
Quantizes float offsets to int16 (1/1024 voxel precision) for storage efficiency
FHktVoxelVertex: Extended from 8 to 16 bytes, adding BevelOffsetX/Y/Z (int16 × 3) + padding fields
FHktVoxelMeshNeighbors: New struct to pass 6-directional neighbor chunk pointers to the mesher for boundary probing
Terrain Actor
UpdatePlayerChunkBevel(): New method that:
Tracks player camera position and determines current chunk coordinate
Detects chunk transitions and option changes
Requests remeshing of previous/new chunks with appropriate bevel values via SetRequestedBevel()
Removed shader-based parameters: EdgeRoundStrength, EdgeAlphaStrength, EdgeAlphaStart replaced with bEnableChunkEdgeRounding (bool) and ChunkEdgeRoundingBevel (float)
LOD Settings: Removed EdgeRoundScale field; normal map scaling now independent of edge treatment
Rendering Pipeline
Vertex Factory:
Added BevelOffsetComponent stream (VET_Short4) to vertex factory data
Removed shader parameters for edge round/alpha strength
Shader now applies bevel offset in vertex shader: LocalPos += float3(Input.BevelOffset.xyz) * BevelScale
Removed Shader Functions: Deleted HktApplyEdgeRounding() and HktApplyEdgeAlpha() from HktVoxelStylized.ush
Chunk Component: Removed SetEdgeRoundStrength(), SetEdgeAlphaStrength(), SetEdgeAlphaStart() methods and related render-thread calls
Mesh Scheduling
FHktVoxelMeshScheduler: Enhanced to pre-fetch 6-directional neighbor chunks when bevel is active, passing them to mesher tasks via lambda capture
Maintains zero-overhead path for non-beveled chunks (no neighbor lookup)
Data Storage
FHktVoxelChunk: Added RequestedBevelBits (atomic uint32) to store bevel size via bit-cast, enabling thread-safe game-thread writes and worker-thread reads
Implementation Details
Bevel is only applied at LOD 0 (full detail); higher LODs automatically disable it to save triangles
Silhouette detection uses representative sample cells at quad edges rather than testing entire edges, trading perfect accuracy for efficiency
Neighbor chunk pointers are captured in task lambdas, ensuring chunk lifetime safety during meshing
Offset quantization (1/1024 voxel) provides sub-voxel precision while fitting in int16 range
The system gracefully degrades: chunks without bevel data render identically to before (all offsets = 0)
