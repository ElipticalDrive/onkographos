Extract Mesh from Splat contours the gaussian density, which leaves a hidden inner wall whenever the shell leaks, so real TripoSplat meshes come out hollow, doubled and full of tunnels.
Add solid (default on): fills behind the contour using a Poisson fit of the gaussian normals. Also removes pits and noise.
Add fill (advanced): how large an opening gets closed.
Change defaults: resolution 512, smooth 3.
With solid off, the output is unchanged for the same inputs.

The density contour keeps a hidden inner wall behind the surface: it is only
removed when the shell has no leak at all, and real TripoSplat splats leak, so
meshes come out hollow, doubled and full of tunnels. Fit the interior from the
gaussians' orientation and fill behind the contour instead, which also closes
the pits left by gaps in the splat. A fill input sets how large an opening gets
closed. Turning solid off keeps the old output.

SplatToMesh adds solid reconstruction, enabled by default, and a fill input. The solid path adjusts splat scales, reconstructs an interior from oriented splats, and updates and refines the extracted mesh when reconstruction returns a fill. If no splats pass the surface-reach filter, the fill is not produced. The default resolution increases from 384 to 512.
