Closes #49
Draws the compiled board: per-material, per-chunk hex-prism meshes with only exposed faces, a level-slicing hook, and BoardPlugin wiring.
Acceptance criteria
Bridges and overhangs render with their gaps: bridge_keeps_its_gap_and_draws_its_underside (deck underside drawn, nothing in levels 1..4; slab top still drawn), stacked_segments_hide_the_shared_face.
Exposed faces only: lone_slab_has_top_bottom_skipped_and_six_walls, walls_shared_with_a_neighbor_are_not_drawn, faces_are_wound_outward.
Level slicing: slicing_hides_levels_and_exposes_what_is_below.
Chunking and determinism: chunks_cover_the_board_and_meshing_is_deterministic.
Notes for the reviewer
Face generation is Bevy-free in strata_scene::terrain (so it is unit-testable); strata_render::board only converts it to Bevy meshes and spawns them.
Added CompiledBoard::hexes() to strata_model to iterate the board.
Rebuilds are per chunk (8x8 hexes) through DirtyChunks; ClientBoard or LevelSlice changes mark everything. Terrain in CompiledBoard is static and BoardChanges only tracks removed features and occupancy, so nothing marks single chunks yet. The hook is there for features and the editor.
Materials use the tinted fallback (§13.4). Texture lookup from assets.lua needs AssetsPlugin, which does not exist yet.
Feature spans are not drawn here; only terrain segments.
Line budget: 267 / 500.
Follow-ups
Insert ClientBoard from the client when a match starts (nothing inserts it today, so BoardPlugin is idle until then).
Textured materials once AssetsPlugin resolves assets.lua.
Draw feature segments and react to removed_features.
Terrain-name hover (§13.4).
Checklist
cargo fmt, cargo clippy -D warnings and cargo test pass locally
python scripts/line_budget.py --base origin/master passes
Unit tests live in separate tests.rs files
No floats, HashMap/HashSet, clocks or rand in core crates (floats only in strata_scene/strata_render)
