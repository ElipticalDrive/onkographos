A single Perlin octave makes every hill the same size, which reads as artificial. fbm_noise sums several octaves, each at higher frequency and lower amplitude, so broad landforms carry finer ridges and detail on top. It matches the noise_fn interface, so the composition root injects it into generate where perlin used to go and nothing else changes.
The octave counts and falloff live as constants next to DEFAULT_SCALE, since a pure noise_fn cannot read runtime config. Dividing by the summed amplitude keeps the output in perlin's ~[-1, 1] range, which also makes a single octave reduce exactly to perlin, pinned as a test. The base scale drops to 0.01 so the lowest-frequency octave spreads over many samples.
