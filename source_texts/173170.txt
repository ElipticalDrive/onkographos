VoxelForge — 3D Models Voxel Model converter.
VoxelForge converts textured 3D models — and now AI-generated 3D meshes from images — into fully editable voxel models.
Generate voxel meshes with adjustable resoution, depth, voxel size and decimation settings, then export them for use in Blender, MagicaVoxel, Unity, Unreal Engine, Godot or other 3D/game pipelines.
Designed for artists, game developers, voxel creators, technical artists and procedural asset makers.
VoxelForge 4.6 introduces a major new workflow: drag an image into the editor, generate a 3D mesh through the integrated AI pipeline, preview the result, voxelize it, and send it directly into your scene — all without leaving the application.

• Convert textured 3D meshes into voxel models
• Convert generated 3D meshes into voxel geometry
• Image-to-3D generation pipeline powered by TRELLIS.2

AI 3D Generation
VoxelForge 4.6 integrates a local image-to-3D generation workflow based on TRELLIS.2, using the stableprojectorz fork by Igor Aherne.
The workflow is built directly into the editor:
• Drag and drop an image
• Adjust generation settings
• Set seed and decimation
• Generate a 3D mesh
• Preview the mesh
• Voxelize the result
• Send it into your scene
• Export it for your production pipeline
The generation system runs locally through a FastAPI server launched by VoxelForge.
Automated AI Installation
VoxelForge includes an automated installation pipeline for the AI generation backend.
The installer can handle:
• Python virtual environment setup
• PyTorch + CUDA installation
• CUDA 12.4 / 12.1 / 11.8 options
• TRELLIS.2 dependencies
• o_voxel compilation
• Large wheel downloads with resume support
• Colorized installation logs
• Error reporting for troubleshooting
A Hugging Face token wizard is also to be configured for gated models such as DINOv3 and RMBG-2.0.
Animated Voxelization
VoxelForge can voxelize animated meshes while preserving their animations.
This allows you to convert:
• Characters
• Creatures
• Machines
• Props
• Animated game assets
into voxel models without losing motion.
This feature is especially useful for stylized game assets, retro-inspired characters and animated voxel prototypes.
PBR-Aware Voxel Import
VoxelForge now recognizes and preserves key PBR material information during voxel conversion.
Supported material data includes:
• Metalness
• Specular
• Roughness
• Associated texture maps
• Vertex color information
• Palette-based color workflows
Your materials keep their visual identity after conversion: metal stays metal, plastic stays plastic, and stylized materials remain readable in-engine.
