# 3D Gaussian Splatting — 自适应密度控制消融实验

温州大学《三维深度感知》课程实验。围绕 3DGS 论文 (Kerbl et al., ACM TOG 2023)
第 5.2 节的**自适应密度控制**机制做消融，量化 Clone 与 Split 两种操作各自的贡献。

实现是**纯 PyTorch 手写**的：不依赖 CUDA 扩展，高斯采用各向异性椭球
（逐轴尺度 + 四元数旋转 → 2D 协方差投影），光栅化与反向传播全部自己写，方便逐项对照实验变量。

## 实验设计

| 实验组 | 密度控制 | 说明 |
|---|---|---|
| Baseline | Clone + Split | 论文原始设定 |
| No-Densify | 无 | 固定初始高斯数，不增密不剪枝 |
| Clone-Only | 仅 Clone | 只复制小高斯填补欠重建区域 |
| Split-Only | 仅 Split | 只把大高斯分裂成两个更小的高斯 |

## 实验配置

| 项目 | 值 |
|---|---|
| 数据集 | NeRF Synthetic (Lego)，100 训练视图 / 5 验证视图 |
| 训练分辨率 | 100 × 100 |
| 初始高斯数 | 2,000 |
| 最大高斯数 | 15,000 |
| 损失函数 | L1 |
| 优化器 | Adam，LR 0.005 线性衰减至 0.0005 |
| 早停 | PSNR 连续 200 轮无提升 |
| 渲染器 | 纯 PyTorch 手写，batch_size = 1000 |
| 硬件 | RTX 4060 Laptop 8GB |
