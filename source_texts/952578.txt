Related to #24. Stacked on #25's PR.
What
tests/ghost_volume/ghost_volume.py: runs the seeded 64^3 problem with one backend on 1, 2, 4 and 8 ranks.
It counts the cells with u <= 0.3 and their volume, and requires the count to equal the 1-rank count exactly.
gs_ghost_volume_compare then requires equal counts across backends.
Ascent's threshold keeps a cell if any corner is in range, so Ascent is compared with the ADIOS2 any-corner count.
tests/render/render_check.py: renders each backend on 1 and 4 ranks with one camera and fixed colour ranges, headless through EGL.
It fails if more than 0.1% of pixels differ by more than 24/255.
Images are kept in the build tree. CTest labels are backends and render.
docs/in-situ-backends.md gains a Rendering section: the measurements, why the old shifting trick was wrong, the per-backend rules for clean images, and headless EGL.
Checked
Ghost volume: Catalyst, PVTI, Kombyne and ADIOS2 count 356 cells on every rank count. Ascent counts 2460, equal to the ADIOS2 any-corner count.

Cache variable GS_PVPYTHON_FOUND persists a stale path.
find_program(GS_PVPYTHON_FOUND pvpython) stores its result in the CMake cache. If pvpython is removed or PATH changes, the cached path stays. The tests then register with a missing executable. Use a regular variable name together with unset(... CACHE), or call find_program(GS_PVPYTHON NAMES pvpython) directly. Direct use also removes the need for the manual copy.

-set(GS_PVPYTHON "" CACHE FILEPATH "pvpython used to read PVTI and Kombyne output in the ghost volume test")

tests/ghost_volume/ghost_volume.py runs the seeded 64^3 problem to step
100 with one backend on 1, 2, 4 and 8 ranks and counts the cells with
u <= 0.3 on every corner, plus their volume: Catalyst in situ (threshold,
non-ghost count, IntegrateVariables), PVTI and Kombyne output read back
with pvpython (Kombyne masked by __ghostCells), and ADIOS2 output counted
directly on the periodic global array from bpls (the reference). The
count must equal the 1-rank count exactly and the volume agree within
1e-12; gs_ghost_volume_compare then requires equal counts across
backends (volume 1e-12 between same-method backends, 1e-6 against the
analytic value, since ParaView integrates float32 points).

CTest adds a test per enabled backend (label "backends"); CI builds no
backends and skips them. On the workstation all four backends count 356
cells on every rank count; ctest 9/9 in 56 s. Ascent is not in the test
yet.
