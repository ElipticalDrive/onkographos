Replaces the standard diff-gaussian-rasterization with the FastGS engine (AccuTile tile optimization + per-Gaussian metric accumulation), adds multi-view consistency-guided densification/pruning, and merges cleanly with the latest main (spatio-temporal pruning + gauss_contrib per-pixel contribution).
FastGS CUDA Extension (diff-gaussian-rasterization-fastgs/)
Full C++/CUDA source for the FastGS rasterizer. Key differences from the standard rasterizer:
AccuTile: compact ellipse-based tile assignment (Speedy-Splat derived); controlled by mult (β)
Warp-parallel backward pass: per-bucket, replaces the per-tile backward
metric_map accumulation: forward pass optionally counts high-error pixels contributed by each Gaussian (get_flag=True → accum_metric_counts)
JIT-loaded via gaussian_renderer/diff_gaussian_rasterization_fastgs.py.
render_fastgs() (gaussian_renderer/__init__.py)
```
pkg = render_fastgs(cam, gaussians, pipe, bg, mult=0.5,
                    get_flag=True, metric_map=metric_map)
# pkg["accum_metric_counts"]  → int32 per-Gaussian high-error pixel count
```
For 4D Gaussians, marginal temporal opacity is folded into per-Gaussian opacity before the 3D rasterizer.
Multi-view Consistency Scoring (utils/fast_utils.py)
sampling_cameras(stack, n) — random camera sampling without replacement
compute_gaussian_score_fastgs(camlist, ...) — renders each view twice: first to build a normalised L1 loss map → binary metric_map, then with get_flag=True to accumulate counts. Returns importance_score (densification gate) and pruning_score (budget-controlled removal weight)
Extended GaussianModel
New accumulator xyz_gradient_accum_abs: tracks |∇| from the 4-component FastGS screenspace tensor
New methods: densify_and_clone_fastgs, densify_and_split_fastgs, densify_and_prune_fastgs, final_prune_fastgs
Densification gates clone/split through importance_score > fastgs_importance_threshold; pruning uses 50%-budget stochastic removal weighted by pruning_score

Merge with main
One conflict in gaussian_renderer/__init__.py resolved by keeping both:
FastGS render_fastgs() block (ours)
compute_contrib=False parameter on render() + gauss_contrib return key (main's spatio-temporal pruning feature)
Main's additions (compute_temporal_score, prune_by_spatio_temporal_score, generate_prefilter_masks, --prune_short_timespan_iters) are all present in the merged result.
