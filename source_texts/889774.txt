# Python Ray Tracer

A Python ray tracer that renders scenes of spheres using Phong shading, hard shadows, and recursive reflections. Output is written as a PPM image.

## Requirements

- Python 3
- NumPy (`pip install numpy`)

## Usage

```bash
python RayTracer.py <scene_file>
```

## Scene File Format

Plain text, one directive per line:

NEAR 1
LEFT -1
RIGHT 1
BOTTOM -1
TOP 1
RES 600 600

SPHERE s1 0 0 -10 2 2 2 1 0 0 0.2 0.6 0.4 0.3 16
LIGHT l1 5 5 0 1 1 1

BACK 0.1 0.1 0.1
AMBIENT 0.2 0.2 0.2
OUTPUT output.ppm


- `SPHERE`: `name x y z sx sy sz r g b ka kd ks kr n`
- `LIGHT`: `name x y z r g b`

## How It Works

1. Rays are cast from the eye through each pixel on the near plane.
2. Ray–sphere intersection is solved in each sphere's canonical (unit-sphere) space.
3. The closest hit is shaded with ambient, diffuse, and specular lighting, accounting for shadows.
4. Reflective surfaces recursively trace reflected rays (up to 3 bounces).
5. Final colours are written to a `.ppm` image.

## Output

Produces a `.ppm` file, viewable directly or convertible with GIMP or other:

```bash
convert output.ppm output.png
```
