The plugin itself is not responsible for loading 3D textures. Godot is. Godot now supports loading 3D textures, which my plugin supports. To import a 3D texture, you'd have to import it in a sort of "flip book" format (Tiled PNG); where each layer of the 3D texture is stored in an atlas left to right, top to bottom (or was it bottom to top?). That's how my plugin generates 3D noise textures as well.
About using this for scientific datasets however, my plugin might not be the best tool for that. It's designed for physically based fog, so it's rendering resolution is low; not a good thing when you're visualizing volumes with great detail. A ray-marcher would be better suited for that task. But if you want to try it anyway, be my guest. Who knows? It might work for your case anyway.
P.S.: This plugin wasn't designed for VR since the performance penalty might be too great.
