Summary
Parallelizes per-structure mesh extraction (marching cubes + smoothing + decimation over ~84 independent structures) using a ProcessPoolExecutor. Workers load the cortical label volume once via an initializer instead of pickling the full array per task.
Pins structure segmentation to CPU only (CUDA_VISIBLE_DEVICES=-1 before the antspynet import).
Why CPU-only
GPU acceleration was implemented, benchmarked on PY26N009_dev1 (RTX 4080 SUPER), and rejected: it gave no speedup (marginally slower). The cost is CPU-bound ANTs preprocessing (N4, brain extraction, template registration) plus CPU mesh extraction -- not the thin GPU-able inference slice, which GPU init/transfer overhead outweighs.

Output is identical: same 78/84 structures (the same 6 small DKT regions report "no voxels" as before). The antspynet DKT phase (~102 s) is untouched.
Still-open lever (not in this PR)
Reuse the brain extraction mesh_extractor.py already computes instead of re-running antspynet's full do_preprocessing -- would cut into the ~100 s DKT phase, but changes the preprocessing path and needs validation against real data.
