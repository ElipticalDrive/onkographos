Motivation
Reduce full-world rebuilds and frame hitches by splitting the terrain into manageable chunks and only remeshing touched regions.
Eliminate dark/black triangle artifacts and harsh lighting from the previous single-mesh approach while preserving the stylized ground texture.
Improve sculpting performance so mining/building updates only the triangles/regions affected by the brush rather than rebuilding the entire mesh every edit.
Description
Replace the monolithic terrain mesh with a chunked system using CHUNK_SIZE, chunks map, and createChunks(...) to create per-chunk Mesh objects and metadata (mesh.metadata.terrainChunk).
Add per-chunk meshing via buildChunkMesh(chunk) and incremental remeshing via dirtyChunks + rebuildDirtyChunks(maxPerFrame) so only dirty chunks are rebuilt (edits mark affected chunks with markChunksDirtyByVoxelBounds(...)).
Change brush flow so modifyField(...) updates voxel values in a bounded region and calls the dirty-marking routine, and picking now targets chunk meshes by checking mesh?.metadata?.terrainChunk.
Apply shading/material tweaks to reduce artifacting: terrainMaterial.twoSidedLighting = true, lowered/specular/ambient tuning, and per-chunk meshes no longer receive shadows to avoid dark triangles; HUD updated to show total triangles and dirty chunk queue size.
Testing
Served the app locally with python3 -m http.server 4173 and confirmed assets were served successfully (passed).
Ran a Playwright script that loaded http://127.0.0.1:4173 and saved a screenshot to artifacts/marcher-chunked-performance.png to validate rendering and chunked meshing (passed).
Reviewed the source and diffs (git diff, nl -ba main.js) to verify CHUNK_SIZE, buildChunkMesh, dirtyChunks logic, markChunksDirtyByVoxelBounds, and picking changes were applied (passed).
