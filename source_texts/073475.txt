Summary
Delivers Film path Phase A — a clear jump from grainy splat-disk previews toward continuous, lookdev-usable smoke volumes.
Higher-res Eulerian density: smoke presets default to 48³ (~110k cells, 8× legacy 24³). Sim cost scales O(n³); cook time rises but density is substantially smoother for volume rendering.
GPU volume raymarch replaces CPU screen-space splat/MIP post-pass:
Full-screen wgpu pass uploads per-frame density as R32Float 3D texture
Manual trilinear sampling via textureLoad (R32Float is non-filterable)
Beer-Lambert absorption + simple single-scatter / ambient phase
Camera-basis ray reconstruction; optional warm/cool temperature tint from solver stats
Visual QA: new heuristics reject splat-disk dot-matrix patterns (Laplacian high-frequency energy + similar-radius blob count) while keeping existing slab-rejection tests
Artifacts regenerated: smoke_puff_wgpu_preview.png, smoke_sphere_wgpu_preview.png
Out of scope (hooks remain)
NanoVDB sparse LOD, multi-scattering, path-traced volumes, pyroclastic noise — .vdb / .evol export paths unchanged.
Test plan
cargo test -p elfentier_core (70 tests)
WGPU_BACKEND=vulkan cargo test -p elfentier_wgpu (20 tests)
Artifact tests write updated PNGs and pass preview_has_soft_smoke_plume + anti-splat heuristics
