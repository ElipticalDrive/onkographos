PR #3635 review round 1 hardened dp_output.rs fail-closed (strict alpha in (0,1), K_CAP tail mass charged against delta/2, claims downgraded to a calibrated (eps,delta) target). The remaining unquantified gap is the floating-point inverse-CDF sampler itself (Mironov CCS'12 precision side-channels). Implementing the exact discrete-Laplace simulation sampler (CKS, already named in the module docs as the residual gate) would let the module state a full (eps,delta) accounting; until then the docs deliberately claim only a DP target, not an achieved guarantee. Distribution-level statistical tests of the sampler (privacy-loss bound, not just variability) should land with it.
🤖 Discovered by the SPARQ worker while implementing #2990. Out-of-scope for that PR; captured as follow-up.
