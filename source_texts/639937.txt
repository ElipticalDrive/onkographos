Concept-first rebuild focused specifically on how a real 3D object becomes 2D orthographic views.
Based on the validated Class 6 / Sistema Diédrico stack, but deliberately simplifies the narrative before the ISO A / ISO E standards comparison.
Main sequence:
one coherent asymmetric 3D object;
PV, PH and lateral projection planes;
FRONT / ALZADO generated with parallel projectors normal to PV;
TOP / PLANTA generated with parallel projectors normal to PH;
RIGHT / PERFIL generated from the same object coordinates;
object disappears while the projected views remain;
literal 90° PH abatimiento around LT;
aligned 2D views on a clean drawing sheet;
final five-step reproducible method for students.
No equations in the core explanation. The goal is geometric intuition and real animated motion rather than a PowerPoint-like slideshow.
Dedicated CI: py_compile/geometry gate → literal PQL complete-timeline gate → literal PQH 1920×1080/30 fps → full decode → 72-frame audit contact sheet → SHA-256 → exact direct GitHub publication and re-download verification.
Target final file:
published_renders/Dibujo_Tecnico_3D_to_2D_Orthographic_Projection_V6_FULL_TOTAL_FINAL_pqh.mp4
Workflow run started automatically from the branch push; keep draft until the final direct-publication gate passes.
