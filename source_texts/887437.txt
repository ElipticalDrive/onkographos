Summary
Sculpt places Color Picker beside Shapes. Shapes groups Box/Cube, Sphere, Cone, Cylinder and Pyramid with Stamp and Drag modes, plus box fill in the selected part.
Stamp previews the complete voxel surface and visible outline on the document plane. Above Floor raises the base in whole voxels. Each click creates an editable part and supports Undo. Drag sets a rectangular base or radial footprint, then uses pointer height to preview the finished solid before committing.
Shift-drag with Line selected locks the starting column and derives voxel height from the current projection. Ordinary blank documents start at 32×32×16 and frame their floor. New Grid Size uses whole-number fields and step buttons for empty parts and new documents.
Test plan
Built the macOS editor and passed 133 editor and Lua-session unit tests.
Native Shapes passed 22/22. Covered repeated elevated stamps at 30°, dimensioned primitives, a two-stage drag and cancellation at 67°, plus New Grid Size, Create Part and New with the discard prompt.
Native region tools passed 35/35, including a five-cell vertical line at both angles, preview, commit, Undo and Escape. Reviewed the rendered contour in the Metal captures.
Native part sizes (12), documents (25), material tools (12), sculpt (46) and camera gestures (44) passed with zero layout findings.
Checked header conventions, comment references, formatting and whitespace. Launched the installed Debug executable on the normal startup path and observed 32×32×16.
