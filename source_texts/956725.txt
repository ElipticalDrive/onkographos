Chunk performance — stacked on co-op PR #19
The 12×12 terrain streamer now greedily merges adjacent coplanar top tiles and continuous exposed cliff faces, where their height and material agree. It preserves per-world-tile 16×16 texture detail using new greedy_atlas.gdshader (world-repeat UV + UV2 tile ID), rather than stretching pixel art across large quads.
Uses the same checked-in 64×64 atlas, and derives collider geometry from the resulting mesh. Existing camp, portals, dungeons, multiplayer lobby, crafting and saves remain unchanged. tests/greedy_meshing.gd checks vertex reduction, repeated-UV shader and chunk correctness. All legacy CI remains in place.
Future biome definitions can reuse the same greedy mesher. This PR does not create infinite terrain or change resource persistence. Android graphics/performance still require physical testing. No main merge. See docs/GREEDY_TERRAIN.md.
