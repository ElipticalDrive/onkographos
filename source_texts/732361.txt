Problem
set_transform throws whenever rotation_degrees is supplied:
```
in method 'RQuaternion_FromRotationMatrix', argument 2 of type 'RL::CMatrix3< float > const &'
```
The error aborts the whole call, so position/scale are dropped too. Root cause: RLPy.RMatrix3().FromEulerAngle(...) returns a tuple (RMatrix3, RStatus), but the code passed the whole tuple to RQuaternion.FromRotationMatrix.
Fix
Index [0] to extract the matrix, per the official Reallusion RLPy docs. Also extend get_transform to return rotation (rotation_quaternion always, plus best-effort rotation_degrees) so a rotation can be verified.
Verified live against iClone 8: a 45°/90° Z rotation applies and reads back correctly.

matrix itself. The code passed the whole tuple to RQuaternion.FromRotationMatrix,
which raised:

  in method 'RQuaternion_FromRotationMatrix', argument 2 of type

whenever rotation_degrees was supplied. Indexing [0] extracts the matrix, per
the official Reallusion RLPy docs. Verified live against iClone 8.
