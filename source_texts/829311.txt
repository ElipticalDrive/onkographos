# VoxelWright

<p align="center">
  <img src="assets/brand/finalists/voxelwright-primary-interlock.png" alt="VoxelWright interlocking block logo" width="220">
</p>

VoxelWright turns voxel files and Studio models into Roblox Parts.

It can:

- Open MagicaVoxel `.vox` files.
- Open Java Edition `.schem` files.
- Open Bedrock Edition `.mcstructure` files.
- Open a selected range from a Bedrock Edition `.mcworld` archive.
- Turn a model in Studio into small 3D blocks called voxels.
- Join nearby blocks to make fewer Parts.
- Add your own Roblox texture images to Minecraft-style blocks, including Common Shapes.
- Optionally animate mapped water during Play/Test. The choice is Off by default; mapped water adds one runtime Script when enabled.

VoxelWright is available on the Roblox Creator Store. Search for **VoxelWright** in the Creator Store to find the plugin. See the [release notes](docs/release-notes.md) for changes and the [install and update guide](docs/install-update.md) for setup help.

The plugin code is kept in a private repository. This public repository holds help pages and the issue tracker. To share feedback, [report a bug](https://github.com/nathangeology/VoxelWright/issues/new?template=bug-report.yml) or [request a feature](https://github.com/nathangeology/VoxelWright/issues/new?template=feature-request.yml).

## Safety and privacy

VoxelWright does not track how you use it or send plugin data over the internet. File reading and model building happen on your computer. You can remove a completed build with Studio Undo.

You must have permission to use and publish every model, structure, and texture you import.

## Minecraft notice

VoxelWright works with some files made for Minecraft. It does not include Minecraft, Minecraft textures, or other Mojang or Microsoft game files.

> **NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.**
