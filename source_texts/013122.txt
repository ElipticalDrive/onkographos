Summary
Implements a new voxel-based ray tracing system using DDA (Digital Differential Analyzer) traversal through a 128³ block-occupancy grid. This provides an alternative global illumination method and a fallback for specular reflections when screen-space ray tracing misses.
Key Changes
New voxel_rt.glsl module: Core DDA ray tracing implementation featuring:
VoxelDDA(): Efficient voxel grid traversal with axis-aligned hit detection
SampleVoxelLighting(): LPV-based lighting lookup at hit surfaces
ApplyVoxelRT(): Hemisphere GI sampling (drop-in replacement for SSRT)
VoxelReflectionFallback(): Specular reflection fallback when SSR coverage is incomplete
Settings additions (settings.glsl):
New VOXEL_GI indirect effect mode (option 6)
Configurable parameters: VOXEL_GI_SAMPLES, VOXEL_GI_STEPS, VOXEL_REFL_STEPS
Optional VOXEL_RT_REFLECTIONS feature flag for reflection fallback
Integration points:
composite1.fsh: Conditional inclusion and application of ApplyVoxelRT() when VOXEL_GI mode is active
specular.glsl: Optional voxel reflection fallback integrated after SSR with coverage-based blending
Stability fixes (composite6.fsh):
Added epsilon guards to prevent division by zero in invTonemap(), FastCatmulRom(), and TAA blending calculations
Implementation Details
Requires LPV (Light Propagation Volumes) and GL_ARB_shader_image_load_store support
Uses feet-relative world-space coordinates consistent with existing camera systems
DDA traversal includes ray bias to avoid self-intersection and handles near-parallel rays gracefully
GI mode combines sky occlusion with LPV colour bleeding for realistic indirect lighting
Reflection fallback scales voxel lighting to match typical sky-reflection brightness ranges
Gracefully degrades to SSRT when voxel RT requirements aren't met

Three division-by-zero / NaN sources in the TAA resolve pass (composite6.fsh)
were producing black pixel artifacts, especially prominent on RTX 5070 Ti where
Blackwell's aggressive FP16 FTZ behaviour turns near-zero history samples into
exact zeros:

1. invTonemap(): col/(1-luma) could divide by zero when a tonemapped value
   landed on exactly 1.0 due to FP16 rounding — now guarded with max(...,1e-5).

2. FastCatmulRom(): color.rgb/color.a divides by the weight sum which can be
   zero on degenerate geometry edges — now guarded with max(color.a,1e-5).

3. blendingFactor ghosting rejection: abs(clamped-history)/clampedframeHistory
   produced 0/0 = NaN for fully-dark pixels (caves, shadow interiors); NaN
   propagated through clamp() as black on NVIDIA — now guarded with
   max(clampedframeHistory, vec3(1e-4)) to stay above the FP16 subnormal floor.

Implements a full DDA (Digital Differential Analyser) ray tracer over the
existing 128^3 block-occupancy voxel grid (imgVoxelMask, populated each frame
in the shadow pass).  No new buffers or passes are needed.

New file  shaders/lib/voxel_rt.glsl
  • VoxelDDA()  – 3-D DDA traversal; handles grid bounds, sign-safe boundary
    distances, and returns face-centre position + axis-aligned normal.
  • SampleVoxelLighting()  – reads the LPV half a block in front of the hit
    face so the indirect colour at the surface comes from propagated light.
  • ApplyVoxelRT()  – drop-in replacement for ApplySSRT(); traces
    VOXEL_GI_SAMPLES (default 4) cosine-weighted hemisphere rays, blends sky
    contribution with LPV colour bounce at hits.
  • VoxelReflectionFallback()  – single specular DDA ray; activated only when
    the screen-space reflection missed (enviornmentReflection.a < 1).

settings.glsl
  • New mode  VOXEL_GI = 6  added to the indirect_effect enum.
  • Default changed from SSAO_FILTERED to VOXEL_GI.
  • Tunable constants: VOXEL_GI_SAMPLES, VOXEL_GI_STEPS, VOXEL_REFL_STEPS.
  • VOXEL_RT_REFLECTIONS is commented-out by default (uncomment to enable the
    specular fallback).

composite1.fsh
  • Includes voxel_rt.glsl when VOXEL_GI or VOXEL_RT_REFLECTIONS is active.
  • New #if block for indirect_effect == VOXEL_GI; falls back to ApplySSRT
    on hardware without IRIS_FEATURE_CUSTOM_IMAGES / LPV.

specular.glsl
  • After getEnvironmentReflections(), if VOXEL_RT_REFLECTIONS is defined and
    SSR missed, VoxelReflectionFallback() fills in LPV-sampled voxel colour.
