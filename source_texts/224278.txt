Summary
This PR adds a comprehensive suite of advanced mesh processing and implicit surface generation algorithms to geometry3Sharp, including marching cubes with continuation support, advanced remeshing, mesh boolean operations, and various mesh repair/optimization utilities.
Key Changes
Mesh Generation & Implicit Surfaces
MarchingCubesPro: Advanced marching cubes implementation with:
Parallel computation support
Multiple rootfinding modes (SingleLerp, LerpSteps, Bisection)
Continuation method support for efficient surface generation
Caching of corner values and edge vertices for performance
CachingMeshSDF: Lazy-evaluated signed distance field for meshes
Narrow-band computation mode for efficient continuation methods
Caching of distance values to avoid redundant calculations
Support for both crossing-count and parity-based winding number computation
CachingGridImplicit3d: Lazy-evaluated trilinear interpolant for dense grids
Defers grid value computation until needed
Supports analytic function fallback
Advanced Remeshing
RemesherPro: Enhanced remesher with intelligent edge queue tracking
FastSplitIteration for rapid edge length convergence
TrackedSmoothPass and TrackedProjectionPass for efficient iteration
Face-aligned projection support
Significantly faster convergence than standard remesher
Mesh Operations
MeshMeshCut: Mesh-mesh intersection and cutting operations
Segment insertion and edge connection
Vertex snapping with configurable tolerance
Support for tracking cut vertices and segments
MeshBoolean: Boolean operations (union, difference, intersection)
Built on MeshMeshCut infrastructure
Vertex snap tolerance configuration
MinimalHoleFill: Quasi-developable hole filling
Gaussian curvature optimization
Triangle quality optimization
Boundary triangle handling options
AutoHoleFill: Intelligent hole filling strategy selection
Analyzes hole characteristics to choose optimal filling method
Supports multiple fill types (planar, minimal, smooth)
SmoothedHoleFill: Iterative hole filling with smoothing
Optional offset direction support
Laplacian smoothing with configurable iterations
Pre/post-remeshing options
Mesh Repair & Cleanup
MeshAutoRepair: Comprehensive mesh repair pipeline
Degenerate edge collapse
Border triangle erosion
Interior/occluded component removal
Orientation consistency checking
MeshRepairOrientation: Consistent triangle orientation
Component-based orientation analysis
Outward/inward facing detection
RemoveOccludedTriangles: Ambient occlusion-based triangle removal
Identifies and removes interior/occluded faces
RemoveDuplicateTriangles: Duplicate triangle detection and removal
Orientation-aware comparison
MergeCoincidentEdges: Edge merging with spatial hashing
Configurable merge distance
Unique pair filtering option
Mesh Topology & Analysis
MeshTopology: Topological feature extraction
Boundary edge identification
Crease edge detection (angle-based)
Junction vertex identification
Edge loop and span extraction
MeshSpatialSort: Component sorting and containment analysis
Identifies solid/cavity relationships
Winding number-based containment testing
Support for open mesh containers
MeshWindingNumberGrid: Discrete winding number sampling
Full grid or narrow-band computation modes
Fast sweeping for efficient propagation
Optional SDF grid generation
MeshScalarSamplingGrid: Generic scalar function sampling on grids
Similar architecture to winding number grid
Supports arbitrary scalar functions
Mesh Editing Utilities
MeshInsertProjectedPolygon: Polygon insertion via planar projection
Seed triangle-based flood fill
Optional polygon interior removal
Edge simplification support
