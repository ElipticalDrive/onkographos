"volume". We can call this "density", which   is the most common name of a volume if it's just 
a scalar field. Press P to edit the parameters. Here I will set the name to "$OS" for 
operator string. If you middle click on   the name you can see this will expand to 
the name of the node that is "density". We are going to use a scalar volume. You can 
also use a vector or matrix but for now we will   work with scalar. Every voxel in the volume 
will contain one value that is our density. Next set the default density to 1 so we 
can see something. Then change the size   to 2 by 2 by 0.5. Now you can see this is 
quite coarse so each voxel is quite big. Change the voxel size. Go to uniform sampling and 
change this to "by size" then set the div size to   0.01. That means that each voxel is basically 
1cm by 1cm by 1cm if we assume one unit is 1m. This volume consists of small boxes 
and each box is a voxel and each   voxel contains a density value. If 
the density is 1 you can see it as   white and if it is 0.5 it is weaker 
and if it is 0 then we have nothing. Next press Tab and "vop" and select Volume 
VOP and connect this to the density. If you   have never used VOPs before you 
can learn more in my VOP lesson. Display this and go inside and delete 
everything here. Instead press Tab and   type "snippet" and press P and 
you can see here code snippet   and here we can type VEX code. You can 
learn more about VEX in my VEX lesson. Grab the position into float variables. 
Float x equals @P.x and float y equals   @P.y float z equals @P.z. This 
grabs the position x, y and z. Create a float d for density and set 
this to 0 initially. Then assign this   density to our density. @density equals 
d. This should remove all the values. Export the density. Type an asterisk here and   this will export all fields. Now 
you can see we have 0 density. Play around with this. If x is less than 
0 then d equals 1. Now we have density   everywhere where the x is less than 0. Try 
the y or the z. Now you know how this works. Try to make a circle. X times x plus y times y is 
less than 1. If you watched the early lesson about   COPs you have seen this formula before. Now we 
have a cylinder because we have three dimensions. Use an arctangent. Atan2 and x and y. Mirror this 
in x by taking the absolute of the x. Move this   whole formula into a separate variable. Float a 
equals this formula. Check if a is less than 0. Make this a bit smaller so we can add 
here an offset. Move everything in the   y direction. Subtract 0.5 perhaps. 
Carve out these edges a little bit.   See if a is less than z square. That will 
give a little bit of roundness. Take the   z here and multiply by 2. Now we
