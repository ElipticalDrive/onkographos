Summary
Build system: CMake with FetchContent for all deps (glad2, GLFW 3.4, GLM, Dear ImGui docking branch, nlohmann/json, stb_image, tinyfiledialogs); Python/jinja2 check at configure time
Globe renderer: CubeSphere (64 subdivisions), equirectangular UV computed in fragment shader from sphere normal, directional lighting; CCW winding fixed across all 6 faces
Camera: arcball orbital camera — left-drag to orbit, scroll to zoom
Undo/redo: CommandStack + Command interface wired to Ctrl+Z / Ctrl+Y and Edit menu
World I/O: New World dialog, Open World (folder picker), Save (Ctrl+S); persists world.json via nlohmann/json; creates bodies/, media/notes/, assets/textures/, assets/heightmaps/ skeleton
CelestialBody: Star / Planet / Moon, serialised into world.json
ImGui docking: default panel layout on first launch (World+Layers left, Inspector right, Timeline bottom); View → Reset Layout; globe visible through PassthruCentralNode + NoBackground
World panel: body list with type icons, + to open Add Body modal, auto-selects first body on world open
Inspector: shows selected body properties (type, radius, axial tilt, rotation period, orbital period)
Globe ↔ body: reloads texture from {world}/assets/textures/{id}.{jpg,png} on selection, falls back to assets/surface.*; updates window title
VS Code: .vscode/c_cpp_properties.json with all FetchContent include paths for IntelliSense
Test plan
cmake -B build configures without errors (requires Python + jinja2)
cmake --build build --config Debug builds lorekeeper.exe without warnings
App launches showing globe in centre, four panels docked around it
File → New World: dialog opens, Create button disabled until both fields filled, world created and World panel updates
File → Open World: picks existing world folder, loads name + bodies
File → Save / Ctrl+S: writes world.json
World panel +: Add Body dialog, body appears in list and Inspector after adding
Clicking a body in the list updates Inspector and window title
Ctrl+Z / Ctrl+Y: undo/redo (no-op stubs visible, infrastructure ready)
View → Reset Layout restores default panel positions
Globe rotates smoothly with left-drag; scroll zooms
