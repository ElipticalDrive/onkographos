Summary
Replace the PyTorch-centric package with a standalone C++ library built by Bazel
Port 2D Gaussian splatting (CPU forward/backward, tiled) and 3D projection with alpha compositing
Add optional CUDA 2D forward path (nvcc genrule) and OpenMP-parallel CPU kernels
Move the original Python/PyTorch implementation, training scripts, and JIT extensions to legacy/
BREAKING CHANGE
The installable Python package and torch extensions are no longer built from the repository root. Use Bazel targets (//src/tinysplat, //examples:render_2d) or refer to legacy/ for the previous workflow.
Test plan
bazel test //tests:gaussian_2d_test
bazel run //examples:render_2d
bazel run //examples:render_2d_cuda -- --cuda (when CUDA toolkit is available)
