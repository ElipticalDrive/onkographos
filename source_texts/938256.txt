Summary
Expand the world texture atlas from a single row to a 16×16 tile grid so textures for newly registered blocks can actually be loaded and sampled in-world.
Resolve each block face to its Minecraft texture path instead of falling back to the grass-block top tile for unknown voxel IDs.
Add top/side mappings for logs, basalt, blackstone, pumpkin, melon, hay bale, crafting table, furnace, and other appended blocks; use each plant's own texture in crossed-plane meshes.
Preserve grass/foliage tinting and update break-particle UV rectangles for multi-row atlas tiles.
Missing textures now fall back to stone rather than silently showing grass-top.
Validation
Inspected the source changes and confirmed the old single-row UV lookup and generic grass-top fallback were removed.
A local TypeScript/Vite build and in-game visual test have not yet been run; please verify those before merging.
