Summary
Implements the first voxel-world foundation: a finite 256×256 flat test terrain with sparse vertical section storage, neighbour-aware face culling, and efficient combined mesh rendering.
Architecture
Data layer
World — owns 256 chunk columns, provides global getBlock(x,y,z) queries (Y range 0–1023)
ChunkColumn — 16×16 horizontal chunk; owns a sparse Map<sectionY, ChunkSection>
ChunkSection — compact 16×16×16 Uint8Array voxel storage (4096 bytes)
BlockId — numeric IDs: AIR(0), GRASS(1), DIRT(2), STONE(3)
Mesh generation
ChunkMesher — builds one BufferGeometry per populated section; emits a face only when the neighbour in that direction is non-opaque; neighbour lookup goes through World.getBlock() for cross-chunk and cross-section correctness
Rendering
WorldRenderer — manages Three.js meshes (one mesh per section with visible faces); meshes built once at startup, not per frame
OrbitCamera — drag-to-orbit + scroll/pinch zoom (desktop + mobile)
React
Debug overlay showing world/chunk/section/mesh/face/triangle/FPS stats
React does not manage voxels or chunk meshes
Test world terrain
Ground height Y=64: grass top, 3 dirt layers, stone below to Y=0
256 chunk columns × 5 allocated sections = 1,280 sections (sections Y=0–4 only; Y=5–63 never allocated)
692 rendered meshes (sections with zero exposed faces produce no geometry)
197,632 visible faces / 395,264 triangles (matches analytical expectation: top + bottom + 4 world-edge sides only)
Verification
npm run build passes
GitHub Pages base path unchanged
No mesh-per-block, no React-per-block, no per-voxel JS objects
Face culling across chunk and section boundaries
Mobile-friendly pointer controls (drag + pinch zoom)
