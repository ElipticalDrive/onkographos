Summary
This takes the first two commits of #1090 by @skies912, with the comments trimmed to the project's conventions. The code is unchanged.
R_CullBox tests one corner per plane. A box is behind a plane only if its corner farthest along the plane's normal is. The result is the same, with a quarter of the distance calculations.
Each subview's frustum is narrowed to the rect of its face. A face samples its subview at its own screen coordinates, so only that rect is ever read. The four side planes are built from the rect, with the view's own basis vectors, so they hold for mirrors as well as portals.
The third commit of #1090 (sprite culling for each view, and one batch for each texture) is not included. The measurements below show that it adds little on top of the narrow frustum, and it needs a RenderSprite field, which changes the cgame API.

I believe this is not the case for portals. Mat4_LookAt builds x as up × forward, which is the same relation to view->right in the main view, and the main view is not drawn mirrored, so NDC +x corresponds to right there. A portal carries the basis through a rigid rotation, which preserves the cross product, so up' × forward' keeps that relation to right' and NDC +x still corresponds to right'. Only a reflection flips the cross product; that is the mirrored case, where the layer is stored flipped and R_SubviewScissor mirrors the rect, while the world-space planes built from the reflected right bound the rays that the face actually samples. No change made.
