# Volumetric Raytracer

A raytracer based on the Nori raytracer further developed for a rendering competition.
Check out my live presentation about the implemented features [here](https://youtu.be/YRrMZ_qQMW0?si=LSQD_d5ITSt6vbFQ&t=1205)!

## Rendering Competition Image

For the rendering competition I submitted the following render which highlights multiple features implemented.
The image is quite complex with 3D scanned meshes and high quality texture maps resulting in the render taking up to 70Gb of memory during rendering.
There are more than a thousand lights, hence there was the need for better light sampling which was succesfully achieved by using light cache points which store the lights in sorted distance per axis. These acted as a sort of lookup tables.
Furthermore, the renderer is volumetric and uses object instancing with multiple mesh resolutions. It is also capable of rendering curves which were important for the hairs of characters.
