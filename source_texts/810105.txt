This PR introduces methods and machinery to randomly resample any particle object across SPH kernels into N new particles with or without masks. Attributes can be resampled in a number of different ways:
"duplicated" — Every child inherits the parent value unchanged. Default for intensive quantities (metallicity, optical depth, alpha enhancement, elemental abundances, custom attributes).
"proportional" — The parent value is divided equally among children (value / resample_factor), conserving the total sum. Default for extensive quantities (initial_mass, current_mass, masses, dust_masses).
"normal" — Each child is drawn from Normal(value, σ) independently. σ defaults to the population standard deviation; can be fixed via ("normal", sigma).
"lognormal" — Like normal but in log-space (LogNormal(log(value), σ_log)), keeping values positive. Best for metallicities, SFR, ages.
"conserved_normal" — Starts from the proportional split, adds Gaussian scatter, then renormalizes each group so children sum exactly to the parent value. Scatter with exact conservation.
SFH/MetalDist sampling — When a parametric SFH or metallicity distribution is provided to Stars.spatially_resample, ages and metallicities are continuously sampled from 1‑D or 2‑D (SFZH) distributions instead of the mode-based resampling, with masses conserved to the original total.
This lays the groundwork for more refined resampling techniques in the future that better respect the matter field.
Closes #1071. Closes #892. Closes #891.
