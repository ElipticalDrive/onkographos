Motivation
Expose sphere-tracing tunables so users can adjust sdfScalar and LODScalar at runtime to control ray-marching behavior and LOD heuristics.
Allow the PBR background to be configured via a color picker so the fallback color used by the ray marcher is user-editable (used in ray_marcher_AR miss path at line 58).
Ensure the UI, runtime scene state, GPU upload, and shader layout all carry the new parameters end-to-end.
Description
Added a new sidebar accordion section "Sphere Tracing Settings" with a scripts/UI/sphere_tracing_section.gd controller exposing SDFScalar and LODScalar sliders wired to StateBus.scene and the scene state file scripts/state/scene_state.gd.
Added a background color picker to the existing PBR UI in scripts/UI/pbr_section.gd and bound it to StateBus.scene.background_color.
Extended SceneStateR (scripts/state/scene_state.gd) with sdf_scalar, lod_scalar, and background_color and updated GPU packing in scripts/gpu_layout.gd to include these values.
Updated the shader-side scene buffer (shaders/includes/shared_data.gdshaderinc) to include sdf_scalar, lod_scalar, and background_color, and modified shaders/includes/rayMarcher/ray_marcher_AR.gdshaderinc to use scene.sdf_scalar/scene.lod_scalar and return scene.background_color.rgb on a miss.
Wired the new UI resources into the scene file modules/renderer/FractalRenderer.tscn so the new controls are present in the sidebar.
Testing
Ran repository symbol searches (rg) to verify the presence and wiring of SphereTracing, sdf_scalar, lod_scalar, BackgroundColorPicker, and background_color across UI, state, GPU packing and shader files, and these checks succeeded.
Printed and inspected file excerpts (sed/nl) for scene_state.gd, gpu_layout.gd, shared_data.gdshaderinc, ray_marcher_AR.gdshaderinc, pbr_section.gd, sphere_tracing_section.gd, and FractalRenderer.tscn to validate the end-to-end changes and these inspections matched the intended edits.
