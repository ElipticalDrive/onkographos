# variational-level-set-vision-graphics

`variational-level-set-vision-graphics` is a research-grade CV–CG pipeline for reconstructing, editing, rendering, and evaluating closed 3D objects with a shared signed distance field (SDF).

The CV side reconstructs a dense SDF from calibrated multi-view silhouettes using differentiable NeuS-style volume rendering and generalized variational level-set regularization. The CG side applies local constructive solid geometry edits, repairs the edited distance field, extracts a watertight mesh, fuses multi-view vertex appearance, and exports PLY, GLB, Blender, and rendered preview assets.

## Capabilities

- Multi-view visual-hull initialization from NeRF Synthetic cameras and alpha masks.
- Coarse-to-fine `64³ → 128³ → 192³` SDF optimization in PyTorch.
- Differentiable silhouette, depth, and normal rendering.
- DRLSE and narrow-band Eikonal regularization without periodic reinitialization.
- Audited sphere/box CSG and local topology-preserving SDF repair.
- Marching Cubes mesh extraction, topology checks, vertex-color fusion, and GGX presentation assets.
- Train, validation, and frozen test-set metrics for silhouette IoU, boundary F-score, SDF quality, topology, and appearance.
- Hash-bound checkpoints, provenance reports, deterministic archive tooling, and supply-chain gates.

The geometry contract assumes one calibrated, rigid, opaque, closed object inside `[-1.2, 1.2]³`. The SDF sign convention is negative inside and positive outside. Camera pose estimation, transparent media, dynamic geometry, UV texture recovery, and non-rigid simulation are outside the current scope.

## Environment

The validated baseline is:

- Python 3.12.13
- PyTorch 2.5.1 and torchvision 0.20.1
- CUDA 12.4

Install the locked dependencies from the repository root:

```powershell
python -m pip install -r requirements-torch-cu124.txt
python -m pip install -r requirements-torch-runtime.txt
python -m pip install -r requirements.txt
python -m pip install -r requirements-dev.txt
```

## Dataset

The publicly available dataset exclusively uses the 8 Blender scenes from NeRF Synthetic. The official repository provides data entry points, camera coordinate conventions, and a Blender loader; the public compressed package is approximately 1.68 GB. The 8 scenes are trained one by one, not concurrently in GPU memory. During training, each image is resized to 400×400, while validation and final rendering remain at 800×800. [NeRF official code and data description](https://github.com/bmild/nerf)

Place the official NeRF Synthetic dataset under:

```text
data/raw/nerf_synthetic/
├── chair/
├── drums/
├── ficus/
├── hotdog/
├── lego/
├── materials/
├── mic/
└── ship/
```

Each scene must contain `transforms_train.json`, `transforms_val.json`, `transforms_test.json`, and their referenced RGBA images. RGB is used only after geometry is frozen; alpha masks provide the reconstruction supervision.

## Quick start

Run the small CPU-only synthetic demonstration:

```powershell
python -m demo.minimal_end_to_end --output-dir artifacts/demo
```

Train the complete Lego reconstruction schedule:

```powershell
python scripts/train_reconstruction.py --scene lego --output-dir artifacts/training
```

Resume a checkpoint with a bounded number of additional steps:

```powershell
python scripts/train_reconstruction.py `
  --scene lego `
  --resume artifacts/training/lego/latest.safetensors `
  --max-steps 100 `
  --output-dir artifacts/training
```

Run the checkpoint-to-edit-to-CG quality pipeline:

```powershell
python scripts/validate_cg_pipeline.py `
  --checkpoint artifacts/training/lego/latest.safetensors `
  --device cuda `
  --output-root artifacts/cg_lego
```

Run the repository checks:

```powershell
python -m ruff check .
python -m mypy src demo
python -m pytest -q
```

The current frozen repository passes Ruff, mypy over 54 source files, bytecode compilation, and 128 behavioral tests.

## Validation status

The complete Lego path passes the fixed 192³ geometry, editing, appearance, presentation, and 200-view test gates. In the seven-scene promotion batch, Chair, Hotdog, and Materials pass; Drums, Ficus, Mic, and Ship are explicitly retained because the fixed dense single-SDF representation was falsified for their thin, disconnected, foliage-like, or systematically biased geometry.

The final release archive is intentionally not created. The fixed PyTorch 2.5.1 baseline currently reports 19 unique CVEs. Runtime dependencies and the exact 50-package license closure otherwise pass their gates.
