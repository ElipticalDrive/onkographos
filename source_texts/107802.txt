This issue is created as a todo list for the incremental implementation of the Volumetric Clouds
Ray-marched cloud rendering (separate spatial shader)
Procedural Perlin-Worley noise
Height gradient profiles (stratus, stratocumulus, cumulus, cumulonimbus)
Basic Beer-Lambert lighting
Shadow rays for self-shadowing
Wind animation
Day/night color sync with atmosphere
Beer-Powder bright edge approximation
Henyey-Greenstein phase function (silver lining)
Multi-scattering approximation
Temporal reprojection (render at reduced resolution)
3D noise texture support (baked, faster than procedural)
