💡 What: Refactored getBounds and gridMethodVolume in src/lib/compute/pointCloudVolume.ts to calculate bounding box extents (minE, maxE, minN, maxN) iteratively using a single for loop, removing .map() chains and spread syntax (...) combined with Math.min()/Math.max().
🎯 Why: Using spread syntax (...) with Math.min()/Math.max() on large arrays like dense 3D point cloud surfaces can exceed V8 engine maximum call stack limits and trigger Out of Memory exceptions due to heavy intermediate array allocations during mapping.
📊 Impact: Prevents "Maximum call stack size exceeded" crashes during volume computations on extremely dense point clouds, saves heap memory by not creating four separate intermediate mapped arrays, and decreases processing time for large dataset bounds extraction.
🔬 Measurement: This optimization improves processing reliability for large datasets without breaking expected mathematical outputs, verified through passing regression tests and test suites.
