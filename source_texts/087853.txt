Analysis (2026-06-13)
ClipVolumeByIsovalue for 2D Image meshes. Current implementation is 3D-only. The 2D case would extract a contour from an Image mesh rather than an isosurface. Algorithm investigation needed to determine if the same Marching Cubes/Tetrahedra approach generalizes to 2D (Marching Squares). Separate module or extension TBD.
