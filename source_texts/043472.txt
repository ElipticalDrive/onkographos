## 🔎 Overview

IGS is a dialog-based Visual C++/MFC application that embeds a VTK render window inside a native Windows interface. It reads a text `.header` file, resolves the matching raw volume named by `OrgFile`, converts the samples into `vtkImageData`, and renders the result with `vtkOpenGLGPUVolumeRayCastMapper`.

The active application focuses on a compact workflow:

1. Select a volume header.
2. Parse the dimensions, voxel spacing, rescale parameters, and patient position.
3. Load and preprocess the corresponding 16-bit raw volume.
4. Display the volume in an interactive 3D scene.
5. Inspect picked 3D coordinates through the application window title.

<a id="key-features"></a>

## ✨ Key Features

- **Custom volume ingestion** — reads a `.header` file paired with a two-byte-per-voxel raw volume.
- **Header-driven preprocessing** — applies dimensions, voxel spacing, rescale parameters, byte swapping, and selected patient-position transforms.
- **GPU volume rendering** — uses VTK's OpenGL GPU volume ray-cast mapper with composite blending and configurable transfer functions.
- **Native embedded viewer** — hosts the VTK render window inside an MFC dialog control.
- **Interactive 3D navigation** — inherits VTK trackball-camera rotation, panning, and zoom behavior.
- **Spatial picking** — left-button interaction performs cell picking and reports the selected 3D coordinate in the window title.
- **Debug and Release support** — provides dedicated x64 configurations and runtime DLL paths.
