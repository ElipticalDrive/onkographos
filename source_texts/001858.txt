# cub3D — Our first RayCaster with miniLibX

A pseudo-3D maze game built from scratch in C, inspired by Wolfenstein 3D (1992). The engine uses ray-casting to render a first-person view of a 2D map in real time.

---

## Description

cub3D is a graphical project from the 42 curriculum. The goal is to build a ray-casting engine using the miniLibX library — the same technique used by id Software in the early 1990s to create the first FPS games.

The program reads a `.cub` scene file that describes the map layout, wall textures, and floor/ceiling colors. It then renders a real-time 3D-like view from the player's perspective, where walls are drawn taller or shorter depending on how far away they are.

**How ray-casting works in one sentence:** for every column of pixels on screen, a ray is cast from the player's position into the 2D map — when it hits a wall, the distance is used to calculate how tall to draw that wall on screen.

---

## Features

**Mandatory**
- Real-time pseudo-3D rendering using the DDA ray-casting algorithm
- 4 distinct wall textures depending on wall orientation (North, South, East, West)
- Configurable floor and ceiling colors (RGB)
- Player movement with W / A / S / D
- Camera rotation with left / right arrow keys
- Clean exit on ESC or window close button
- Full `.cub` map file parser with error handling

**Bonus**
- Wall collision detection
- Minimap overlay
- Mouse-controlled camera rotation

## Installation

**Requirements:** gcc, make, miniLibX (Linux or macOS)

```bash
git clone https://github.com/rossnotfromfriends/cub3d.git
cd cub3D
make
```

Run with a map file:

```bash
./cub3D maps/map.cub
```

---

## Map file format

The `.cub` file must follow this structure:

```
NO ./textures/north.xpm
SO ./textures/south.xpm
WE ./textures/west.xpm
EA ./textures/east.xpm

F 220,100,0
C 50,50,200

1111111
1000N01
1111111
```

- `0` — empty space
- `1` — wall
- `N` / `S` / `E` / `W` — player start position and facing direction
- The map must be fully enclosed by walls
- The map must always be the last element in the file
