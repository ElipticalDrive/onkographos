The author's exterior reconstruction algorithm is used to reconstruct two high-quality finely sampled exterior tomographic data sets from a high-resolution cone beam computed tomography scanner developed by Perceptics, Inc. One data set is complete exterior data and the other data set is limited-angle exterior data with an angular range of . The author adapts his algorithm to reconstruct this limited-angle data set. Reconstructions are also made from two subsets of this data set: a highly limited-angle data set with an angular range of , and a data set with sparser data ( of the original data). A description of the inversion algorithm and a continuity estimate (stability bound) for the algorithm are given.
