# Gaussian Splat Viewer

A web-based LiDAR point cloud viewer using Three.js and WebGL2 with Gaussian splatting technique for high-quality visualization.

## Features

- **Gaussian Splatting**: Points rendered as billboard splats with Gaussian alpha falloff for smooth, organic appearance
- **Custom Shaders**: GLSL vertex and fragment shaders for optimized rendering
- **Smooth Camera Controls**: Orbit controls with damping for intuitive navigation
- **Binary Point Cloud Support**: Efficient loading of binary point cloud data
- **WebGL2 Rendering**: Hardware-accelerated graphics using Three.js
- **Responsive Design**: Adapts to any screen size
