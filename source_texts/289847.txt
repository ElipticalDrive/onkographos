Summary
Adds native 3D Gaussian Splatting support to geobim.app — load Gaussian-Splat reconstructions as native Cesium 3D Tiles (glTF KHR_gaussian_splatting, GPU-decoded since CesiumJS 1.135, no custom renderer). Source via self-hosted tileset.json URL or Cesium Ion.
Changes
splat.js — loader with own registry (BimViewer.splat.instances, not loadedAssets) so IFC/Revit filters, IBL, the lighting monitor, PBR shaders, env-maps and performance presets never touch splats (they would break rendering). Each tileset registered in lighting.monitoredTilesets so the 2s lighting monitor skips it. Non-cumulative height (ellipsoid normal via baseline transform) + ENU-local orientation fix + terrain clamp.
splat-ui.js / ui-splat-section.js / splat-styles.css — "Gaussian Splats" sidebar section: URL/Ion-id load (Enter), clamp checkbox, demo button, per-instance list (flyTo / show-hide / remove / SSE / height / rotation). Status + CORS/404 error feedback for self-hosted sources.
ui.js + integrated-zoffset-styles.css — per-asset "clamp to terrain" button in the Assets panel, wired to the existing BimViewer.clampAssetToTerrain (works for Ion splats loaded via the normal asset selector too).
Hosting / pipeline
geobim.app DocumentRoot = /var/www/christoflorenz.de → splats under data/tiles/gauss/ are same-origin (no CORS needed; .htaccess sets CORS/MIME/-Indexes anyway). data/ is gitignored. Pipeline: 3dgs-ply-3dtiles-converter (PLY → 3D Tiles).
Notes
Tested with CesiumJS 1.141. qa-check.sh: 0 errors.
Lesson learned: use compact object scans (small bounding radius); full-scene reconstructions (Tanks&Temples, interiors) look blurry via flyTo because the camera frames the whole cloud.
