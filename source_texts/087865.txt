Package 10.4 — CPU efficiency and complete 2D exports
Based on merged Package 10.3 (#72).
Reuse one locally centered ConvexGeometry + EdgesGeometry per inequivalent center. Translate per-instance vertices, preserve normals, per-site colors/opacities, coordination, hull area/volume and merged scene. Track template count/reuse/bytes. Real 5³ BaTiO₃ WebGL verifies 125 TiO₆ octahedra from one local template.
Move 768px 2D marching-squares contour generation into the existing offline Worker, including positive/negative/balanced levels, saddle disambiguation, invalid Miller regions and a 60k segment cap. Return transferable packed Float32 segments; keep existing stroke styles.
Move 64×64 physical-coordinate 2D slice CSV sampling to the Worker (transferred Float64 coordinates + Float32 values), with request invalidation, 20s safety fallback, and independent numeric parity.
Select preview-only uniform marching-tetrahedra stride from a bounded 6³ crossing-density probe. The final scientific isosurface remains byte-identical to Package 10.3; this is not local spatial adaptive meshing.
Extend native + real Chromium/WebGL regressions; bump offline shell cache and refresh EN/TR docs, ROADMAP, title translation.
The interactive 192px slice, line profiles, GPU memory profiling, and true crack-free locally adaptive surfaces remain future work. No numerical units, atom/bond/polyhedron/surface safety limits, or scientific interpretation are changed. Do not merge pending CI.
