Summary
Oversized scans can now proceed through a crop and an explicit downsampling choice:
```
check 1 mm GPU buffer size
  oversized → niimath robust FOV neck crop → check again
  still oversized → offer smallest fitting voxel size → retry on user choice
```
Preserve the upload and record preprocessing in the run report. Coarser processing grids are experimental; the app flags their unvalidated population comparisons. The IXI norms are pinned and checksummed, with data version b23bda1938a5 visible in About, above the charts, and in saved JSON. Release: 0.7.20261014.
Evidence
Before: a scan exceeding the GPU buffer limit was rejected.
After: real niimath browser tests exercise crop-first handling, downsampling offers/retries, disabled cropping, and cancellation.
Default 1 mm CPU fast labels have 0 / 814,528 mismatches against the FreeSurfer fixture. A real full-head 1.3 mm browser run completes and downloads labels with correct spacing and positive physical volumes.
Unit coverage checks native/WASM geometry, padding, physical volumes, immutable population-data identity, and displayed version. Browser coverage checks the saved data version and interactive volume report.
Production SynthSeg build, interface audit, phone tests and shared interface workflows passed. Astra independently reviewed standards and spec/correctness: neither found actionable issues. Astra also reviewed the CI harness update and independently passed all 21 affected tests. Final checks passed: 15 app unit tests, 44 package tests (7 existing data-gated skips), all 494 repository contracts, lint, and 17 browser interaction tests. PR CI finished with 85 passing checks and 4 expected skips. The separate full-catalog pre-merge run, including hardware GPU suites, also passed. SynthSeg passed 22 hardware browser tests, 21 software browser tests, native full-volume CPU parity and installer verification.
Merge Danger
Door: two-way
Source changes can be reverted. The original upload is retained.
Blast Radius: SynthSeg
Shared SynthSeg preprocessing gains an optional 1–3 mm grid; default 1 mm arithmetic is preserved. Coarse outputs change model scale and have not been validated against the 1 mm norms. Deployment follows the repository's GitHub Pages workflow after merge.
