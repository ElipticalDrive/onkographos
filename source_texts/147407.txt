Abstract
Neural radiance fields (NeRFs) revolutionized 3D reconstruction by learning continuous scene representations from sparse 2D images, yet face two limitations: (i) inadequate modeling of channel–space interactions by MLP-based architectures and (ii) ineffective use of collective supervision information between distant pixels in the optimization process. To address these challenges, we propose mixed feature radiance field (MixeRF), which combines multi-resolution hash encoding with a multi-dimensional feature interaction network. The hierarchical hash table improves the training efficiency, while the cross-feature mechanism enhances the channel–space interdependence for fine scene detail recovery. We further design distribution-aligned normal distribution residual loss based on distributional alignment to perform global pixel supervision by predicting the minimization of the distributional distance between residuals and Gaussian noise. To balance optimization stability with reconstruction quality, we introduce a smooth approximation technique for differentiable loss function fine-tuning. Experiments on mixed indoor/outdoor datasets demonstrate consistent performance gains: +2.13 dB higher PSNR than Nerfacto on the Lego dataset and 2.2 dB higher PSNR than Instant-NGP on the Fern dataset. The smooth approximation technique incurs merely 1.15 dB average cross-dataset PSNR degradation (range: 0.06–0.96 dB) while preserving optimization stability.

Appendix A
1.1 Proof of Lemma 1
Proof of Lemma 1
Since both \(P_{Res}\) and \(P_{n}\) are empirical distribution functions for the same number of observations n, we can express \(P_{Res}\) and \(P_{n}\) in terms of their sample points. Specifically, we have:
$$\begin{aligned} & P_{Res}(x)=\frac{1}{n} \sum _{i=1}^{n} I(res_{i}\le x), \end{aligned}$$
(A1)
$$\begin{aligned} & P_{n}(x)=\frac{1}{n} \sum _{i=1}^{n} I(n_{i}\le x), \end{aligned}$$
(A2)
where \(I(res_{i}\le x)\) is an indicator function that is 1 if \(res_{i}\le x\) and 0 otherwise. We can compute \(d_{TVD}(P_{Res}, P_{n})\):
$$ d_{{{\text{TVD}}}} (P_{{{\text{Res}}}} ,P_{n} ) = \int_{{ - \infty }}^{\infty } {\left\| {\frac{1}{n}\sum\limits_{{i = 1}}^{n} I ({\text{res}}_{i} \le x) - \frac{1}{n}\sum\limits_{{j = 1}}^{n} I (n_{j} \le x)} \right\|_{1} } dx. $$
(A3)
For the above expression, we can perform a transformation as follows; the two forms of expression are equivalent. It is defined as follows:
$$ d_{{{\text{TVD}}}} (P_{{{\text{Res}}}} ,P_{n} ) = \int_{{ - \infty }}^{\infty } {\left\| {\frac{1}{n}\sum\limits_{{i = 1}}^{n} I ({\text{res}}_{i}^{ \uparrow } \le x) - \frac{1}{n}\sum\limits_{{i = 1}}^{n} I (n_{i}^{ \uparrow } \le x)} \right\|_{1} } dx, $$
(A4)
where \(res^{\uparrow }_{i}\) denotes the ith residual sample after the ascending operation and \(n^{\uparrow }_{i}\) denotes the ith noise sample after the ascending operation. Since \(\frac{1}{n}\sum _{i=1}^{n} [ I( res^{\uparrow }_{i}\le x)- I(n^{\uparrow }_{i}\le x)]\) is a piecewise continuous function, we can express the above equation in the following form:
$$ \begin{aligned} d_{{TVD}} (P_{{Res}} ,P_{n} ) & = \frac{1}{n}\int_{{ - \infty }}^{{\min \left( {res_{1}^{ \uparrow } ,n_{1}^{ \uparrow } } \right)}} {\left\| {\sum\limits_{{i = 1}}^{n} I \left( {res_{i}^{ \uparrow } \le x} \right) - I\left( {n_{i}^{ \uparrow } \le x} \right)} \right\|_{1} } dx \\ & \quad + \frac{1}{n}\int_{{\min \left( {res_{1}^{ \uparrow } ,n_{1}^{ \uparrow } } \right)}}^{{\max \left( {res_{n}^{ \uparrow } ,n_{n}^{ \uparrow } } \right)}} {\left\| {\sum\limits_{{i = 1}}^{n} I \left( {res_{i}^{ \uparrow } \le x} \right) - I\left( {n_{i}^{ \uparrow } \le x} \right)} \right\|_{1} } dx \\ & \quad + \frac{1}{n}\int_{{\max \left( {res_{n}^{ \uparrow } ,n_{n}^{ \uparrow } } \right)}}^{{ + \infty }} {\left\| {\sum\limits_{{i = 1}}^{n} I \left( {res_{i}^{ \uparrow } \le x} \right) - I\left( {n_{i}^{ \uparrow } \le x} \right)} \right\|_{1} } dx, \\ \end{aligned} $$
(A5)
Due to the properties of the \(\frac{1}{n}\sum _{i=1}^{n} [ I( res^{\uparrow }_{i}\le x)- I(n^{\uparrow }_{i}\le x)]\) function, the above expression can be simplified to the following form:
$$ d_{{{\text{TVD}}}} (P_{{{\text{Res}}}} ,P_{n} ) = \frac{1}{n}\int_{{\min \left( {res_{1}^{ \uparrow } ,n_{1}^{ \uparrow } } \right)}}^{{\max \left( {res_{n}^{ \uparrow } ,n_{n}^{ \uparrow } } \right)}} {\left\| {\sum\limits_{{i = 1}}^{n} I \left( {{\text{res}}_{i}^{ \uparrow } \le x} \right) - I\left( {n_{i}^{ \uparrow } \le x} \right)} \right\|_{1} } dx. $$
(A6)
For the above expression, based on the triangle inequality, we can obtain the following relationship:
$$\begin{aligned} \begin{aligned}&0 \le \frac{1}{n} \int _{\min \left( res^{\uparrow }_{1} , n^{\uparrow }_{1} \right) }^{\max \left( res^{\uparrow }_{n} , n^{\uparrow }_{n} \right) }\left\| \sum _{i=1}^{n} I\left( res^{\uparrow }_{i} \le x\right) -I\left( n^{\uparrow }_{i} \le x\right) \right\| _{1} d x \\&\le \frac{1}{n} \int _{\min \left( res^{\uparrow }_{1} , n^{\uparrow }_{1} \right) }^{\max \left( res^{\uparrow }_{n},n^{\uparrow }_{n} \right) } \sum _{i=1}^{n}\left\| I\left( res^{\uparrow }_{i} \le x\right) -I\left( n^{\uparrow }_{i} \le x\right) \right\| _{1} d x .\end{aligned}\end{aligned}$$
(A7)
Now we prove that:
$$ 2{\mathcal{L}}_{{\text{Re} s}} = \frac{1}{n}\int_{{\min \left( {res_{1}^{ \uparrow } ,n_{1}^{ \uparrow } } \right)}}^{{\max \left( {res_{n}^{ \uparrow } ,n_{n}^{ \uparrow } } \right)}} {\sum\limits_{{i = 1}}^{n} {\left\| {I\left( {res_{i}^{ \uparrow } \le x} \right) - I\left( {n_{i}^{ \uparrow } \le x} \right)} \right\|_{1} } } dx $$
(A8)
Due to the linearity of the integral, the above expression can be written as:
$$\begin{aligned} \frac{1}{n} \sum _{i=1}^{n}\int _{\min \left( res^{\uparrow }_{1}, n^{\uparrow }_{1}\right) }^{\max \left( res^{\uparrow }_{n}, n^{\uparrow }_{n}\right) } \left\| I\left( res^{\uparrow }_{i} \le x\right) -I\left( n^{\uparrow }_{i} \le x\right) \right\| _{1} d x.\end{aligned}$$
(A9)
Thus, we have:
$$\begin{aligned} \begin{aligned}&\frac{1}{n} \sum _{i=1}^{n} \int _{\min \left( res^{\uparrow }_{1}, n^{\uparrow }_{1}\right) }^{\max \left( res^{\uparrow }_{n}, n^{\uparrow }_{n}\right) }\left\| I\left( res^{\uparrow }_{i} \le x\right) -I\left( n^{\uparrow }_{i} \le x\right) \right\| _{1} d x \\&=\frac{1}{n} \sum _{i=1}^{n}\int _{\min \left( res^{\uparrow }_{i}, n^{\uparrow }_{i}\right) }^{\max \left( res^{\uparrow }_{i},n^{\uparrow }_{i}\right) }\left\| I\left( res^{\uparrow }_{i}\le x\right) -I\left( n^{\uparrow }_{i} \le x\right) \right\| _{1} d x \end{aligned}\end{aligned}$$
(A10)
because of
$$ \int_{{\min \left( {res_{i}^{ \uparrow } ,n_{i}^{ \uparrow } } \right)}}^{{\max \left( {res_{i}^{ \uparrow } ,n_{i}^{ \uparrow } } \right)}} {\left\| {I\left( {res_{i}^{ \uparrow } \le x} \right) - I\left( {n_{i}^{ \uparrow } \le x} \right)} \right\|_{1} } dx = \left\| {res_{i}^{ \uparrow } - n_{i}^{ \uparrow } } \right\|_{1} . $$
(A11)
Therefore, we obtain:
$$ \frac{1}{n}\sum\limits_{{i = 1}}^{n} {\int_{{\min \left( {res_{i}^{ \uparrow } ,n_{i}^{ \uparrow } } \right)}}^{{\max \left( {res_{i}^{ \uparrow } ,n_{i}^{ \uparrow } } \right)}} {\left\| {I\left( {res_{i}^{ \uparrow } \le x} \right) - I\left( {n_{i}^{ \uparrow } \le x} \right)} \right\|_{1} } } dx = \frac{1}{n}\sum\limits_{{i = 1}}^{n} {\left\| {res_{i}^{ \uparrow } - n_{i}^{ \uparrow } } \right\|_{1} } . $$
(A12)
Notice that:
$$\begin{aligned} \frac{1}{n} \sum _{i=1}^{n}\left\| res^{\uparrow }_{i}- n^{\uparrow }_{i} \right\| _{1} = 2\mathcal {L}_{Res} ;\end{aligned}$$
(A13)
therefore, the following result can be concluded:
$$\begin{aligned} 0\le d_{TVD}(P_{Res}, P_{n})\le 2\mathcal {L}_{Res} .\end{aligned}$$
(A14)
By the property of convergence, we can see that when \(\mathcal {L}_{Res}\longrightarrow 0\), \( d_{TVD}(P_{Res}, P_{n})\longrightarrow 0\) as well.
\(\square \)
Appendix B Smooth Approximation
Definition 1
(The Dirac delta function \(\delta (x)\)) The Dirac delta function \(\delta (x)\) is a distribution (or generalized function) defined by the following properties:
1.
\(\forall x\ne 0\), \(\delta (x)=0\)
2.
\(\delta (0)=\infty \).
3.
\(\int _{-\infty }^{\infty } \delta (x)dx=1\).
Based on the properties of the Dirac delta function mentioned above, it is easy to conclude that \(\forall f(x)\in \mathcal {F} \), \(\int _{-\infty }^{\infty } f(x)\delta (x-a)dx=f(a)\), where is a set of functions defined on \(\mathbb {R} \) that have countably many discontinuities. Thus, we can find a smooth approximation of the function \(\delta (x)\) as \(\varphi (x)\). According to \(\int _{-\infty }^{\infty } f(x)\delta (x-a)dx=f(a)\), we have \(g(a) = \int _{-\infty }^{\infty } f(x)\varphi (x-a)dx\approx f(a)\). At this point, g(x) serves as a smooth approximation of f(x).
Properties based on absolute value functions, we can define it as follows: \(\left| x \right| =\max (-x,x)\). Based on Observation 3.3, the smooth approximation of \(\left| x \right| \) can be expressed as the solution to the following integral:
$$\begin{aligned} \int _{-\infty }^{\infty } \varphi (x-y)\max (-y,y)dy. \end{aligned}$$
(B15)
Here, there are various forms of \(\varphi (x)\), and this paper chooses the following:
$$\begin{aligned} \varphi (x)=\lim _{t \rightarrow \infty } \frac{e^{tx}t}{(1+e^{tx})^{2}} .\end{aligned}$$
(B16)
t denotes a positive scaling parameter that controls the sharpness of the approximation function at \(x=0\). As t increases, the peak of the approximation function at \(x = 0\) becomes steeper and thus closer to the properties of the Dirac function. The final solution to the smooth approximation of \(\left| x \right| \) is to solve the following integral:
$$\begin{aligned} \int _{-\infty }^{\infty } \frac{e^{t(x-y)}t}{(1+e^{t(x-y)})^{2}}\max (-y,y)dy .\end{aligned}$$
(B17)
According to the method of integration by parts, it is easy to obtain:
$$\begin{aligned} \int _{-\infty }^{\infty } \frac{e^{t(x-y)}t}{(1+e^{t(x-y)})^{2}}\max (-y,y)dy=\frac{2\ln (1+e^{tx})}{t} -x .\end{aligned}$$
(B18)
Thus, we have the following relationship:
$$\begin{aligned} \lim _{t \rightarrow \infty } \frac{2\ln (1+e^{tx})}{t} -x = \left| x \right| . \end{aligned}$$
(B19)
