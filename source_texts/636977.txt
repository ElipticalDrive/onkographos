The explicit extra-plane API only returns one Depth/SelectionMask plane, leaving multi-channel files unusable. Extend the same owned API to return all zero, one or two supported planes in source order, including mixed kinds and duplicate kinds, with independent source depths and owned buffers. Kind/index/depth/source and oriented geometry remain explicit; no units, thresholds, coverage, Alpha or compositing interpretation is inferred.
Depends on draft #89 and its #88…#75/#73/#72 stack. Main0.0.41 is unchanged. Partial #42 only: original-profile Gray/RGB integer SDR, independent8/9/10/12/16-bit source depths, full-resolution, one full-canvas Modular frame, no preview/XYB/resampling. Count3+, Alpha combinations, Spot/other kinds, float/subsampled extras and unqualified layers reject the whole request without dropping channels. Names remain an upstream API limitation; source-header retention is opaque. The historical refused-selection-multiple fixture is now explicitly accepted as two SelectionMask planes.
All existing codec/input/pixel/byte/workspace caps and Main5 policy remain. Only this entry point's supported plane count changes1→2. Preflight already accounts for actual channel count; adapter accounting now admits simultaneous color + both plane payloads, fixed temporary handles and all descriptors before allocations. Each plane reserve is fallible. Independent Vec owners and iter_mut keep byte-view borrows disjoint until final ownership transfer. No dependency changes, all-codec heap/RSS guarantee or large-image enablement.

Five C-readable negative inputs cover3 channels, Spot mixing, float, subsampling and layers.
209 expanded native tests (library97, existing Depth6/Selection6, new two-plane5), minimal17, disabled targets0. Joint420/419-byte output boundary, exact workspace/metadata/input/pixel/frame/layer limits, every truncated prefix, all17 cancellation checkpoints,9 actual allocation failures (including the second plane after the first is live), recovery/scoped release and existing API refusals pass.
Actual wasm32/Node727 grouped checks pass without host imports. New target participates in all disabled/minimal/EX/CMS/macOS/Windows/actual Windows32 CI rows.
Displayed C/product sRGB color and both diagnostic plane arrays match byte-for-byte.
