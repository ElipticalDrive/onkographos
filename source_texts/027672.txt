Procedural Loop Volumes: fog, smoke,
steam and dust that loop perfectly. No simulation, no cache and no bake. Install the ZIP from Get Extensions,
Install from Disk. The Volumes tab appears in the sidebar. Start with one click. Wrap the scene in fog puts a
fog box around everything visible, and a large ground plane
becomes the floor of the fog. Wrap what the camera sees
fits the box to the camera, so you only render volume where it shows. Choose one of twelve presets,
calibrated in metres: smoke, steam, low fog,
dense fog, stage haze, dust in a light beam,
a sandstorm, even a nebula. Simple mode is the preset,
five sliders and a colour: amount of fog, blob size,
swirl, movement and loop length. Set the loop length and the
volume closes on itself. Frame 241 is identical to frame 1, and the jump at the loop is the same
size as any other step between frames. There is no seam to hide. The loop runs on drivers
stored in the file, so the .blend renders the same
on a machine without the add-on: send it to a render farm,
a client or a colleague. Advanced mode opens everything:
noise, detail, distortion,
a ground fog gradient, anisotropy, emission, and wind and
rise in metres per loop. Visibility is in metres too: the distance at which the
fog hides what is behind it. Check the loop goes through every
volume and rebuilds missing drivers. Export the loop to VDB,
one file per frame, or save your volume to the
Asset Browser to use it in any file. It works in Cycles and in EEVEE:
one button sets EEVEE up for volumes. Procedural Loop Volumes,
for Blender 4.5 and newer. The link is in the description.
