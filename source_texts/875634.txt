This looks like a very useful project and I like the name. One thing I did notice, though, is that it is using older Perlin noise for its noise. Perlin noise is smooth, but it produces a lot of 45 and 90 degree bias. Simplex is much more subtle with its grid structure. I don't know if this is the case for you, but most projects I see that use older Perlin noise, do so more from hearing about it first than anything. IMO, the PCG community needs more libraries and examples which feature Simplex, instead or at least as the default case, compared to Perlin. I quickly put together some code that should work to convert the existing Perlin generator. I haven't tested it, so it could require some fixes, but you're welcome to use it and/or modify it for whatever.
Replace fract_perlin_at with
```
double
fract_simplex_at(fract_simplex *simpl, double x, double y)
{
	const double F2 = 0.366025403784439;
	const double G2 = -0.211324865405187;
	double s = (x + y) * F2;
	double xs = x + s, ys = y + s;
	int xs0 = floor(xs), ys0 = floor(ys);
	double xsi = xs - xs0, ysi = ys - ys0;
	int i1 = ysi > xsi ? 0 : 1, j1 = ysi > xsi ? 1 : 0;
	double grads[6];
	fract_simplex_gradient(simpl, xs0,      ys0,      grads + 0, grads + 1);
	fract_simplex_gradient(simpl, xs0 + i1, ys0 + j1, grads + 2, grads + 3);
	fract_simplex_gradient(simpl, xs0 + 1 , ys0 +  1, grads + 4, grads + 5);
	double t = (xsi + ysi) * G2;
	double dx0 = xsi + t, dy0 = ysi + t;
	double dx1 = dx0 - i1 - G2, dy1 = dy0 - j1 - G2;
	double dx2 = dx0 - (1 + 2 * G2), dy2 = dy0 - (1 + 2 * G2);
	double vx0 = dot(dx0, dy0, grads[0], grads[1]);
	double vx1 = dot(dx1, dy1, grads[2], grads[3]);
	double vx2 = dot(dx2, dy2, grads[4], grads[5]);
	double a0 = 0.5 - dx0 * dx0 - dy0 * dy0 - dz0 * dz0;
	double a1 = 0.5 - dx1 * dx1 - dy1 * dy1 - dz1 * dz1;
	double a2 = 0.5 - dx2 * dx2 - dy2 * dy2 - dz2 * dz2;
	double value = 0;
	if (a0 > 0) value += (a0 * a0) * (a0 * a0) * vx0;
	if (a1 > 0) value += (a1 * a1) * (a1 * a1) * vx1;
	if (a2 > 0) value += (a2 * a2) * (a2 * a2) * vx2;
	return value;
}
```
Replace fract_perlin_best with
```
void
fract_simplex_best(fract_simplex *simpl, double x, double y, int *ox, int *oy)
{
	const double F2 = 0.366025403784439;
	const double G2 = -0.211324865405187;
	double s = (x + y) * F2;
	double xs = x + s, ys = y + s;
	int xs0 = floor(xs), ys0 = floor(ys);
	double xsi = xs - xs0, ysi = ys - ys0;
	int i1 = ysi > xsi ? 0 : 1, j1 = ysi > xsi ? 1 : 0;
	double grads[6];
	fract_simplex_gradient(simpl, xs0,      ys0,      grads + 0, grads + 1);
	fract_simplex_gradient(simpl, xs0 + i1, ys0 + j1, grads + 2, grads + 3);
	fract_simplex_gradient(simpl, xs0 + 1 , ys0 +  1, grads + 4, grads + 5);
	double t = (xsi + ysi) * G2;
	double dx0 = xsi + t, dy0 = ysi + t;
	double dx1 = dx0 - i1 - G2, dy1 = dy0 - j1 - G2;
	double dx2 = dx0 - (1 + 2 * G2), dy2 = dy0 - (1 + 2 * G2);
	double corrs[] = {
		dot(dx0, dy0, grads[0], grads[1]),
		dot(dx1, dy1, grads[2], grads[3]),
		dot(dx2, dy2, grads[4], grads[5]),
	};
	int index = 0;
	for(int i = 1; i < 3; i++){
		if(corrs[i] > corrs[index])
			index = i;
	}
	*ox = xs0 + (index & 1);
	*oy = ys0 + ((index & 2) >> 1);
}
```

Whenever you store your gradients to the array in the init function, multiply both the sin and cos components by 99.2043537115249. This will make the noise output range -1 to 1, for the fract_simplex_at function. The fract_simplex_best function may require some experimentation. Relatedly, note that its (*ox, *oy) output is in skewed integer coordinates, rather than true floating point coordinates.
