First 3D world-rendering milestone
Create a populated demo world using the existing Minosoft-core PortableWorld block storage.
Extract exposed voxel faces into an interleaved position/color triangle mesh.
Render that mesh with GLES 3 shaders, depth testing, face culling, perspective projection, and a slowly orbiting camera.
Wire the world preview into the existing Graphics Preview action, replacing the violet clear-only placeholder when no Minosoft graphics runtime is attached.
Scope and limitations
This renders actual stored block geometry, but it is not yet a Minecraft save/world loader or upstream Minosoft renderer. Demo state IDs are illustrative; no Minecraft textures, lighting, input, chunk streaming, or gameplay yet.
Verification needed
No Android APK build or on-device graphics test has been run. Test shader compilation, triangle winding/culling, performance and Android context recreation on an actual GLES 3 device.
Branch
Based on the unmerged landscape/UI branch in PR #2 so the graphics work builds on the new launcher.
