Summary
Adds modelstudio/, a self-hosted, pure-Node 3D modeling studio and live WebXR VR world builder with spatial AI pointing and open MCP support (no Blender, GPU, cloud account, or credits required):
3D Generation & Modeling Engine (61-command registry):
30 procedural SDF prompt archetypes (character, robot, barn, windmill, silo, haybale, fence, well, bridge, campfire, furniture, vehicles, architecture, props) + explicit SDF specs + multi-view silhouette image-to-3D carving (visualHull).
Mesh repair (weld, hole fill, degenerate/duplicate removal, normals), voxel remeshing with UV/weight transfer, attribute-preserving decimation, cylindrical/box/triplanar UV projection, radial brush sculpting, symmetry, and transform baking.
15 PBR material presets, AO/albedo/normal texture baking up to 2048², UV-space texture painting, humanoid/quadruped auto-rigging with symmetry-aware weight repair, 7 procedural animation clips, software PNG preview renderer, and full GLB export/import round-trip.
Live WebXR VR World (/vr):
Standard W3C WebXR (immersive-vr + optional immersive-ar color passthrough) supporting Meta Quest 3S (Touch Plus controllers + Quest Hand Tracking pinch, zero external CDN dependencies) as well as any WebXR headset and a desktop WASD + mouse-look walkthrough mode.
11 biomes (hayfield, meadow, forest, snow, desert, beach, mars, night-clearing, cyberpunk, courtyard, studio), shared procedural rolling terrain heightfield (terrainHeightAt), GPU-instanced wind-swaying hay/grass/wildflowers/fireflies, and automatic foliage clearings around buildings.
Built-in zero-dependency ECDSA-P256 SAN self-signed HTTPS generator (src/server/tls.mjs, npm run start:vr) so WebXR and browser voice input work over local Wi-Fi on Meta Quest headsets out of the box.
Spatial "Right There" Voice/Text AI & Open MCP (/mcp, /mcp/sse, stdio):
Live controller/hand/mouse ray pointing + "Right There" beacon (vr.point, vr.context) with pointer lock at speech start, resolving commands like "chatgpt make this a hayfield and put a green barn right there" to exact pointed 3D coordinates grounded on terrain.
Works offline with a zero-key multi-clause spatial planner or connects to OpenAI / ChatGPT / Ollama / LM Studio / OpenRouter tool-calling endpoints.
Open MCP over Streamable HTTP (POST /mcp), SSE (GET /mcp/sse), and stdio (src/mcp/main.mjs) with live SSE hot-reload into connected VR headsets.

Each requestAnimationFrame tick awaits animation.sample over HTTP and sync({force:true}), which refetches the whole snapshot, rebuilds every BufferGeometry, and re-downloads every texture (?t=${Date.now()} defeats the HTTP cache — api.js:46).
