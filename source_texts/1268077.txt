# Voxel Renderer

A high-performance voxel-based ray tracing renderer with support for multiple data structures including Sparse Voxel DAG (SVDAG) and Symmetry-aware SVDAG (TSVDAG).

## Overview

This project implements an efficient voxel renderer that converts triangle meshes into voxelized representations and renders them using ray tracing. It supports three rendering modes:

- **Vanilla**: Standard octree-based sparse voxel representation
- **SVDAG**: Sparse Voxel Directed Acyclic Graph with node sharing
- **TSVDAG**: Symmetry-aware SVDAG with geometric transformations for additional compression

## Features

- **Multiple Data Structures**: Octree, SVDAG, and TSVDAG implementations
- **Ray Tracing**: Efficient ray casting with BVH-like traversal
- **Interactive Viewer**: Real-time camera controls with progressive rendering
- **OBJ Mesh Loading**: Import standard Wavefront OBJ files
- **Parallel Rendering**: OpenMP-accelerated rendering pipeline
- **BMP Export**: Save rendered images in BMP format
