Describe the project you are working on
Developing Godot itself, this came out of discussions within the rendering team.
Describe the problem or limitation you are having in your project
We render our main viewports "upside-down" which requires a flip in the projection matrix and reversing back face culling. The same applies for rendering particle height fields and shadows. The material preview and reflection probe rendering on the other hand are done "rightside-up".
This all in itself is not a huge problem however it is causing a lot of confusion both in maintaining the code and implementing compositor effects.
The reason for this is that on Vulkan, images need to be submitted as such for display.
It is worth investigating if we can add some consistency in the orientation of rendering, and only flip the image in the final blit stage, though we need to ensure that interop with other systems (like OpenXR) is maintained. Judging from the current code OpenXR expects images right side up on OpenGL, but upside down on Vulkan.
Describe the feature / enhancement and how it helps to overcome the problem or limitation
This will be a matter of going through the code and ensuring that we render images right side up until final presentation, and evaluate what other measures are needed.
