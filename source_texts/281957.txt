RELEASE GATE G1 — executed independent fixture regression on current audit runtime (Python 3.13.5, NumPy 2.3.5). This comment supplements the draft; it does NOT claim the real Volume/Zarr suite ran at head e8d57377.
```
import numpy as np
from fractions import Fraction
outlier = np.iinfo(np.uint64).max
base = np.arange(999)
old = np.concatenate([[outlier], base]).astype(np.uint64)
new = np.array([int(outlier)] + base.tolist(), dtype=np.uint64)
assert int(old[0]) == 0                          # reproducible old fixture defect
assert int(new[0]) == 18446744073709551615      # fixed fixture preserves real outlier
assert round(Fraction(2**64-1, 3)) == 6148914691236517205
```
Result: 3/3 assertions PASS. NumPy emitted the expected RuntimeWarning: invalid value encountered in cast only on the old, defective construction. The corrected code is already the exact Git blob ae34f85379c68b5ec3d2021c098857a6561e59f9 in this draft branch.
