This is a draft implementation of volume scattering for Appleseed.
Main changes:
Extend Tracer so it can properly calculate transmission when tracing shadow rays through participating media.
Migrate to spectra in Tracer.
Implement integration of rendering equation for scattering media (one distance sample per ray).
Fix some critical issues of phase functions.
Add test scenes.
