LineSegment::getMinimumDistance(const Point&) returns the perpendicular distance from the point to the infinite line through the segment. It ignores the segment end points, so a point past either end gets a distance that is too small.
Reproduce
```
double s[2] = {0.0, 0.0}, e[2] = {4.0, 0.0}, c[2] = {7.0, 0.0};
SpatialIndex::LineSegment ls(s, e, 2);
ls.getMinimumDistance(SpatialIndex::Point(c, 2)); // returns 0, expected 3

double ds[2] = {0.0, 0.0}, de[2] = {1.0, 1.0}, c2[2] = {4.0, 5.0};
SpatialIndex::LineSegment diag(ds, de, 2);
diag.getMinimumDistance(SpatialIndex::Point(c2, 2)); // returns 0.707, expected 5
```
Ball uses this method for line segments, so the wrong value also affects Ball::intersectsShape, Ball::touchesShape and Ball::getMinimumDistance. A ball of radius 1 centered at (10, 0) reports that it intersects the segment from (0, 0) to (4, 0), and its minimum distance to it is 0 instead of 5.
A degenerate segment (start equals end) returns the distance along one axis only, instead of the distance to the point.
Expected
The distance from the point to the closest point on the segment, as Region::getMinimumDistance and Point::getMinimumDistance do for their shapes.
