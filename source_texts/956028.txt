⚡ Is there an underlying problem to be solved?
There is no procedural generation. Open worlds at MMO scale cannot be hand-placed; terrain detail, scatter, roads and structures must be generated deterministically from seeds, identically on server and clients, offline for baking and at runtime for streaming cells.
📝 What should the system provide?
The contract: a generator is a pure function of (world seed, cell coordinates, generator version, inputs); outputs are typed point sets, height or material deltas, spline networks, structure placements; generator version stored with cached output.
A typed point-data graph (sample, filter, transform, scatter, spawn) with nodes declaring reads and writes; compiled by the graph compiler (S47) to C++ for shipping and interpreted in the editor; hand-written C++ generators against the same interfaces until S47 exists.
Cell generation on Background fibers as part of streaming (S40) with latency measured against streaming speed; results cached by content hash.
Global passes (hydraulic erosion, road networks) offline in the worker role (S58) with border overlap, baked into terrain tiles; runtime edits are deltas (S28).
Integer hashes for randomness; in-tree deterministic transcendental functions for authoritative paths (shared with S59).
✅ How do we know it is done?
Given a cell seed, when generated on two machines, then the outputs are bit-identical; a generator version bump invalidates the cache.
Given a forest, a road network and a rock scatter, when generated across cell boundaries, then no seams appear (test compares borders).
Given a 10 km² terrain, when erosion is baked in the worker role, then it loads as tiles and the bake time is recorded.
Scatter feeds foliage (S25) without stored instance data.
🧭 What is covered now, what is left for later?
Covered now: contract, graph, scheduling and caching, erosion baking, scatter, road splines, determinism rules.
Left for later: wave-function-collapse structure generation, building grammars, GPU generators, the node authoring UI (S42, S47).
🕶️ How should the solution look like to achieve the points above?
Battle plan system S33, topic Procedural generation.
💬 Do you have any additional considerations?
Blocked by S27 (and S47 for the authoring UI). Which generators are authoritative versus cosmetic is a per-generator decision recorded in its asset.
