Porting Notes by Ericson2314
==============================================================================

Making Ken Silverman's "Voxlap" voxel graphics engine run on any platform with
SDL and C++.

Build Prerequisites:
------------------------------------------------------------------------------

 - Build Tools:
   1. Option 1
      - MSVS utilities (nmake, ml, cl)
      - Windows SDK (libs)
   2. Option 2
      - MinGW/GCC
      - Nasm in %MinGW%/bin
 - Graphics
   1. Option 1
      - DirectX SDK (libs)
   2. Option 2
      - SDL DEV-MinGW/GCC and RUNTIME (libs)
