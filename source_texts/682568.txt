Recently, the voxel-based two-stage model shows impressive performance in 3D object detection. However, commonly-used 3D convolutional backbone encounter the challenge of limited receptive fields. And existing two-stage models that generate the RoI features suffer from missing object geometric shapes. Motivated by these, we propose a high-performance network named VoxelDet. We introduce additional down-sampling convolutions to capture large context information. By combining these added convolutional features, VoxelDet achieves a better trade-off between spatial resolutions and receptive fields. And an auxiliary strategy with Hierarchical Voxel Pruning (HVP) is added to alleviate the computation problem. In the RoI grid pooling step, VoxelDet incorporates a fine Grid Geometric Attention (GGA) module. GGA captures long-range dependencies between RoI grid points to tackle the missing geometric shapes problem. Extensive experiments on KITTI dataset demonstrate that VoxelDet achieves competitive performance comparable to state-of-the-art models.
