Marcher — SDF Ray Marching Studio
A real-time GPU signed-distance-field ray marcher and scene composer, built as a Vite + React + TypeScript app. You build 3D scenes out of distance-field primitives, combine them with constructive-solid-geometry operators, give each node a material, and light the result — and the whole scene is compiled to a single WebGL2 fragment shader on the fly.
Lives at https://kkd16.github.io/agent-experiments/projects/marcher-sdf-q9x3/ once merged.
What it does
9 primitives — sphere, box, round box, torus, capsule, cylinder, cone, octahedron, plane — each with its own parameter schema.
CSG operators — union / subtract / intersect, each available hard-edged or as a smooth blend with an adjustable radius. Node order is the fold order, so reordering changes the boolean result.
Per-node transforms (position, rotation, uniform scale) and materials (colour, metallic, roughness, reflectivity, emission).
Full raymarched lighting — a directional sun with soft penumbra shadows, ambient occlusion, hemispheric sky/ground ambient, fake environment reflections, distance fog, ACES tonemapping and a vignette.
Live GLSL codegen — the scene compiles to a map() distance function (with nearest-material tracking) embedded in the raymarcher. Per-node numbers are uploaded as uniforms, so dragging a slider updates the shader's inputs without recompiling; a recompile only happens on structural changes.
The editor
Orbit camera: drag to orbit, shift/right-drag to pan, scroll to zoom, plus auto-rotate.
Scene tree with select / visibility / reorder / duplicate / delete and an add-primitive menu.
Node inspector + a "World" panel for camera, sun, environment, ground, render quality and post-processing.
Five presets (Genesis, Lattice, Orrery, Monolith, Bloom), a GLSL viewer with copy, keyboard shortcuts, a help overlay, and localStorage autosave (guarded so it still renders in the sandboxed catalog thumbnail).
Architecture
Scene model (scene/) → GLSL library + codegen + shader assembly (sdf/) → WebGL2 renderer + orbit-camera maths (gl/) → a reducer-driven editor (state/) and React UI (components/). See JOURNAL.md for the module map and backlog.
Verification
node scripts/verify-project.mjs marcher-sdf-q9x3 passes: scope + conformance + pnpm lint + pnpm build all green.
Additionally smoke-tested in headless Chromium: the WebGL2 canvas renders real geometry (verified non-flat framebuffer), the GLSL panel populates, and there are no console/page errors.
