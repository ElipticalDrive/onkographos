When this index is passed to build_task_aware_swap_candidates_payload, every non-explicit InteriorGS object is silently removed because the default SWAP_MIN_TOTAL_DETECTIONS is 2 and _apply_detection_support_filter treats the presence of n_total_detections: 0 as explicit evidence of insufficient support. Reject incomplete compressed-splat profiles
When a PLY merely declares a positive chunk count and these property names, this branch labels it supersplat_compressed_3dgs without checking binary-little-endian encoding, element order, property scalar types, required scale/color chunk ranges, or the SH element.
