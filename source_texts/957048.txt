Problem
S3D-6 requires every image-changing behaviour to be game-settable. TAA's main ghosting controls were fixed: TemporalStabilityFactor was only ever TemporalAntiAliasingAttribs::default(), the rejection and variance-clip constants were #defines in TemporalAntiAliasingStructures.wgsl, DFX-19's still-pixel history was two consts in the accumulation shader, and the history filters were a const feature-flag set in sgl-3d/src/view/post_fx.rs (#52, from the #49 audit).
Result
sgl-3d: FrameInput::taa: TaaParameters (exported, Default, not #[non_exhaustive]), built by FrameInput::new. Fields: temporal_stability_factor, still_history_factor, still_motion_pixels, motion_vector_diff_factor, min_variance_gamma, max_variance_gamma, depth_disocclusion_threshold, variance_intersection_max_t, and the filters as named bools (AR-5): bicubic_filter, gaussian_weighting, ycocg_color_space.
Every default is the value TAA used before: DiligentFX's 0.9375 / 0.75 / 2.5 / 256 / 0.9 / 10, DFX-19's (Bevy's) 0.01 px and 0.985 (D-17), and Hydrogent's TAAFeatureFlags (Catmull-Rom only). The image does not change by default.
sgl-post-fx: the defines and the still constants are TemporalAntiAliasingAttribs fields after upstream's four, in Rust and WGSL (16 → 48 bytes), defaulting to the same values. The library stays SGL3D-agnostic; SGL3D maps TaaParameters onto the attributes and FeatureFlags in its integration. Recorded as PROVENANCE.md DFX-25.
Out-of-range values are clamped in the integration (shares to 0..=1, the rest to 0..=f32::MAX, NaN to 0). Without that, a NaN or an infinite factor times a zero motion or deviation becomes NaN in the TAA history, which keeps it.
Decisions
Names. The fields keep DiligentFX's names (AR-8 port rule, as CrystalParameters mirrors ScreenSpaceReflectionAttribs): motion_vector_diff_factor (TAA_MOTION_VECTOR_DIFF_FACTOR), min_/max_variance_gamma (TAA_MIN/MAX_VARIANCE_GAMMA), variance_intersection_max_t (TAA_VARIANCE_INTERSECTION_MAX_T), and bicubic_filter / gaussian_weighting / ycocg_color_space (FEATURE_FLAG_*). The issue's shorthand names are not used. The DFX-19 values keep their existing constant names.
Out of scope. SkipRejection, upstream's static-image switch, is not in the issue's list and is not exposed.
AR-8. view/post_fx.rs was over 600 lines, so the authored-parameter defaults and attribute mapping (Crystal's, moved unchanged, and TAA's new code) now live in view/post_fx/parameters.rs.
Filter changes. A new combination of filters builds its pipeline on first use. That frame goes through unjittered and unresolved, as DiligentFX's first frame does (DFX-2). This is documented on TaaParameters.
Where it plugs in (AR-9)
Stage order: unchanged. The renderer's post-effect context prepare (before geometry) takes FrameInput::taa's filters as TAA's FeatureFlags. Stage 8 (Antialiasing) passes FrameInput::taa to PostFx::temporal_anti_aliasing, which maps it to TemporalAntiAliasingAttribs for TAA's uniform.
Contracts touched: the public plain data FrameInput / TaaParameters (AR-7). Also sgl-post-fx's TemporalAntiAliasingAttribs layout, one definition per language, now tied by SGL3D's existing layout test: rust_mirrors_match_wgsl_layouts against naga's layout of the port's TAA program. That program is also validated by every_program_composes_and_validates.
Deleted: the TAA_FEATURE_FLAGS const, the WGSL TAA_* defines and the TAA_STILL_* consts. No parallel path or shim.
Validation
New GPU test stages::antialiasing::tests::taa_history_weights_follow_frame_input renders real frames of an unlit cube with TAA:
Still camera, defaults: history weight > 0.5 and the jittered edges blend history.
Still camera, still_history_factor 0: weight exactly 0, and the TAA output equals its input (the composite) within 1e-3.
Panning camera (about 0.85 px/frame), defaults: weight > 0.5.
Panning camera, temporal_stability_factor 0: weight exactly 0.
I confirmed the test fails when either weight is not wired through (each mapped back to its constant): 0.985 and 0.83 against 0. With two WGSL fields swapped, both the layout test and the GPU test fail.
cargo test -p sgl-3d --lib layout_tests, cargo test -p sgl-post-fx (incl. every TAA feature permutation), cargo clippy -p sgl-post-fx -p sgl-3d --all-targets -- -D warnings, cargo fmt.
bun scripts/tasks.ts check: passed (exit 0) on macOS with the GPU required, all lanes including the browser lane
Not exercised: the clamping has no test. On Metal, NaN in min/saturate does not reliably reach the history, so a GPU test would not fail without the clamp. Look was not judged (RD-4).
Closes #52
