SDF Near-Surface Combined Vol+Surf Sampling (α=2.0)
Hypothesis
Apply inverse SDF near-surface importance weighting to both volume and surface point sampling simultaneously, using:
```
weight = 1.0 / (1.0 + α * |sdf|)
```
Volume sampling: near-aerodynamic-surface volume points receive higher weight (|sdf|≈0 → weight≈1.0); far-field points (|sdf|≈80m) receive weight≈0.006.
Surface sampling: surface points in regions of high curvature / near-zero SDF gradient (sharp edges, wake-adjacent zones) receive higher weight.
This tests whether concentrating the model's training budget at the fluid-structure interface on both channels simultaneously yields better surface pressure and wall-shear accuracy than volume-only or uniform sampling.
Current active experiments:
nezuko SDF-Stratified + Stochastic Volume Sampling Combined (corrected dataset) #1054 (tlkx2jyh): inverse SDF on volume only + stochastic switching
tanjiro SDF-Stratified Alpha Sweep: α=1.5, 3.0, 4.0 (corrected dataset) #1055 (58hk6r36): inverse SDF on volume only, α-sweep (1.5 / 3.0 / 4.0)
This PR uniquely tests the combined vol+surf variant with α=2.0 (matching SOTA α for fair comparison).

Implementation Instructions
Step 1: Define the stratified dataset subclass (BOTH vol and surf)
After the existing dataset is constructed (look for where train_dataset is created in train.py), insert the following monkey-patch block. Use __class__ reassignment — do NOT use types.MethodType (that is a silent no-op for __getitem__).
```
import torch
import types  # not used below, just in case it's already imported

SDF_ALPHA = 2.0  # near-surface weighting strength

# ── Volume SDF weighting ──────────────────────────────────────────────────────
# weight = 1.0 / (1.0 + α * |sdf_vol|)
# Near surface (|sdf|≈0) → weight≈1.0; far field (|sdf|≈80m) → weight≈0.006
_orig_getitem_cls = type(train_dataset)

class _SDFStratifiedDataset(_orig_getitem_cls):
    """Dynamically subclassed dataset: inverse-SDF importance sampling on vol+surf."""

    def __getitem__(self, idx):
        sample = super().__getitem__(idx)

        # ── Volume points ────────────────────────────────────────────────────
        # Assume sample['vol_pts'] shape [N_vol, 4] where col 3 = SDF value
        if 'vol_pts' in sample:
            vol_pts = sample['vol_pts']          # [N_vol, 4] or [N_vol, D]
            sdf_vol = vol_pts[:, 3].abs()        # |sdf| for each vol point
            weights_vol = 1.0 / (1.0 + SDF_ALPHA * sdf_vol)
            weights_vol = weights_vol / weights_vol.sum()

            N_vol = vol_pts.shape[0]
            chosen_vol = torch.multinomial(weights_vol, N_vol, replacement=False)
            sample['vol_pts'] = vol_pts[chosen_vol]

            # Resample corresponding vol labels/values if present
            for key in ('vol_p', 'vol_vals', 'vol_labels'):
                if key in sample:
                    sample[key] = sample[key][chosen_vol]

        # ── Surface points ───────────────────────────────────────────────────
        # Assume sample['surf_pts'] shape [N_surf, D]; col 3 = SDF (should be ~0 for surface)
        # Use |sdf_surf| if available, else use distance to nearest-surface proxy.
        # If no SDF column on surf_pts, fall back to geometric normal magnitude as proxy.
        if 'surf_pts' in sample:
            surf_pts = sample['surf_pts']        # [N_surf, D]
            if surf_pts.shape[1] > 3:
                sdf_surf = surf_pts[:, 3].abs()
            else:
                # Fallback: weight by inverse distance from centroid (proxy for curvature)
                centroid = surf_pts[:, :3].mean(dim=0, keepdim=True)
                sdf_surf = (surf_pts[:, :3] - centroid).norm(dim=1)

            weights_surf = 1.0 / (1.0 + SDF_ALPHA * sdf_surf)
            weights_surf = weights_surf / weights_surf.sum()

            N_surf = surf_pts.shape[0]
            chosen_surf = torch.multinomial(weights_surf, N_surf, replacement=False)
            sample['surf_pts'] = surf_pts[chosen_surf]

            for key in ('surf_p', 'surf_vals', 'surf_labels', 'surf_wss'):
                if key in sample:
                    sample[key] = sample[key][chosen_surf]

        return sample

# Apply via __class__ reassignment (the ONLY correct way to override __getitem__ on an instance)
train_dataset.__class__ = _SDFStratifiedDataset

# Sanity check — will raise if the patch didn't take
assert type(train_dataset).__name__ == '_SDFStratifiedDataset', \
    f"SDF patch not active! type={type(train_dataset).__name__}"

print(f"[SDF] inverse near-surface vol+surf sampling enabled: alpha={SDF_ALPHA}")
```

The DrivAerML dataset returns a `DrivAerMLCase` namedtuple/dataclass with attribute access, not a dict. Replace the entire implementation block with the following corrected version.
Bug summary
```
# WRONG — sample is a DrivAerMLCase, not a dict:
if 'vol_pts' in sample:
    vol_pts = sample['vol_pts']
surf_wss = sample['surf_wss']
```
`DrivAerMLCase` attributes are: `.volume_x`, `.volume_y`, `.surface_x`, `.surface_y`, `.case_id`, `.metadata`. There is no `.vol_pts`, `.surf_pts`, or `.surf_wss` key.
Additionally, the run command is missing the required model size flags — without them the run uses default (smaller) architecture instead of the 512-hidden/4-head/128-slice SOTA config.
Corrected implementation
Replace the monkey-patch block in the PR body with this:
```
import torch
from data.loader import DrivAerMLCase

_ALPHA = 2.0   # near-surface weighting strength
_N_VOL = None  # set to int to cap volume points; None = keep all but resample

class _SDFStratifiedDataset(type(train_dataset)):
    """Inverse-SDF importance sampling on volume points (surface via existing loader)."""

    def __getitem__(self, idx):
        view = self.views[idx]
        counts = self.store.case_point_counts(view.case_id)
        surface_idx = self._indices(
            counts["n_surface"], self.max_surface_points, view,
            group_view_count=view.surface_view_count,
        )
        case = self.store.load_case(
            view.case_id,
            surface_rows=None if surface_idx is None else surface_idx.numpy(),
            volume_rows=None,
        )

        # Volume: inverse-SDF weighting — col 3 of volume_x is the SDF value
        n_total = case.volume_x.shape[0]
        n_sample = n_total if self._sdf_n_vol is None else min(self._sdf_n_vol, n_total)
        sdf_vals = case.volume_x[:, 3].abs()
        weights = 1.0 / (1.0 + self._sdf_alpha * sdf_vals)
        vol_idx = torch.multinomial(weights, n_sample, replacement=False)
        vol_idx = vol_idx.sort().values

        # Surface: inverse-SDF weighting — surface_x col 3 is SDF (≈0 on surface;
        # non-zero for near-surface ghost/halo points in some builds).
        # If all surface SDF values are zero, this degenerates to uniform sampling
        # (no harm done). Check the log line below to confirm.
        n_surf_total = case.surface_x.shape[0]
        n_surf_sample = n_surf_total  # resample same count, just reorder by weight
        sdf_surf = case.surface_x[:, 3].abs() if case.surface_x.shape[1] > 3 else torch.zeros(n_surf_total)
        weights_surf = 1.0 / (1.0 + self._sdf_alpha * sdf_surf)
        surf_idx = torch.multinomial(weights_surf, n_surf_sample, replacement=False)
        surf_idx = surf_idx.sort().values

        print(
            f"[SDF] vol: n={n_sample}/{n_total}, "
            f"surf: n={n_surf_sample}/{n_surf_total}, "
            f"surf_sdf_nonzero={int((sdf_surf > 0).sum())}/{n_surf_total}",
            flush=True,
        ) if idx == 0 else None  # only log for first sample each epoch

        return DrivAerMLCase(
            case_id=case.case_id,
            surface_x=case.surface_x[surf_idx],
            surface_y=case.surface_y[surf_idx],
            volume_x=case.volume_x[vol_idx],
            volume_y=case.volume_y[vol_idx],
            metadata={},
        )

train_dataset._sdf_alpha = _ALPHA
train_dataset._sdf_n_vol = _N_VOL
train_dataset.__class__ = _SDFStratifiedDataset
assert type(train_dataset).__name__ == '_SDFStratifiedDataset', \
    f"SDF patch not active! type={type(train_dataset).__name__}"
print(f"[SDF] combined vol+surf inverse-SDF sampling active: alpha={_ALPHA}", flush=True)
```

Two implementation divergences from your suggested code
I implemented your hypothesis intent but diverged from the literal code in two places where verification revealed the surface data contract is different than the suggestion assumed. Flagging these so you can confirm or correct:
1. Surface inverse-curvature proxy uses panel area, not SDF
Your suggested code used case.surface_x[:, 3].abs() as the surface SDF. However, surface_x does not contain SDF — the data layout is:
```
surface_xyz.npy:     (N, 3)  x, y, z
surface_normals.npy: (N, 3)  nx, ny, nz
surface_area.npy:    (N,)    per-panel area
volume_xyz.npy:      (N, 3)  x, y, z
volume_sdf.npy:      (N,)    SDF  ← only here
```
The loader stacks surface arrays into surface_x = [x, y, z, nx, ny, nz, area] (7 dims). So surface_x[:, 3] is nx (normal-x component, range −1..+1), not SDF. Using nx as if it were SDF would bias toward panels with normals perpendicular to the X axis — physically uncorrelated with curvature.
My fix: surface importance uses inverse panel area as a curvature proxy:
```
area_z = area / area.median().clamp_min(1e-12)   # scale-free
surf_weights = 1.0 / (1.0 + alpha * area_z)
```
This concentrates samples on small panels (high mesh refinement → near edges, curvature features) and downweights large coarse panels. Empirically the concentration ratio is ~8.3× more samples per unit area on the smallest decile vs. largest decile at α=2.0.
Volume weighting is exactly as you specified: w = 1 / (1 + α · |sdf|), sourced from volume_sdf.npy. Empirical near-surface concentration is ~4.3× at α=2.0.
2. IO-optimized patch (loads only sdf/area arrays, then mmap-reads chosen rows)
The naive patch (load_case(...) → full case in RAM → slice in torch) loaded ~620 MB per sample and produced ~56 min/epoch. The optimized version loads only volume_sdf.npy + surface_area.npy (~75 MB combined), computes the multinomial sample indices, then load_case(..., surface_rows=surf_idx, volume_rows=vol_idx) mmap-reads only the chosen rows. New speed: ~45–48 min/epoch.
This also necessitated killing the previous (slow) run at ~02:10 UTC (W&B runs sda2zcd2 etc., aborted at step ~8258). The new run uses the same training config — only the data-loader internals changed.
