高斯泼溅图层可提供针对复杂几何的高度逼真的可视化效果，而这是传统摄影测量方法无法实现的。 例如，您可以在各种基础设施工作流中呈现诸如电力线、防护栏和天线等细小而复杂的结构。 此外，您还可以捕捉到各种人造结构的透明或反射效果，例如建筑物的窗户或金属表面的反光。
高斯泼溅图层是局部或全球场景中 3D 图层类别的 3D 图层。 您可以向场景添加高斯泼溅图层，并将其与其他图层进行合并。 您可以使用高斯泼溅图层可视化和浏览其他图层，例如要素图层、影像图层以及其他 3D 图层。
高斯泼溅图层可表示构建环境。
除了人造结构之外，该图层还能以高保真的方式可视化植被等自然对象。 其中包括树叶，从而使用户能够对树种或其他类型的植被进行分类。 该图层还可呈现雾、烟或水面反射等其他视觉效果，以便用户能够捕捉到尽可能自然的外观。
高斯泼溅图层可表示树木。
高斯泼溅可视化
3D 高斯泼溅是一种用于实时辐射场渲染的技术。 该技术会利用神经场并根据二维图像重建场景的三维表示。 这种体绘制技术基于数百万个模糊椭圆体，并通过自适应过程进行创建。 每个高斯泼溅点均由其位置、旋转、大小、颜色和透明度进行定义。 这些高斯泼溅点会在一同渲染时相互混合，形成平滑逼真的 3D 表示。
逻辑示意图将显示屏幕上渲染的各个泼溅点。
根据观察者视角或观看方向的不同，高斯泼溅点会在颜色和强度上进行动态适应。 这使您能够在环绕观察反光材料时真实描绘其材质。 如果处理过程中可用区域的倾斜影像不足，高斯泼溅点将缺失，或仅显示一个视域椭圆。
您可以在图层属性对话框上找到有关高斯泼溅图层的常规信息和显示选项。 要访问属性，请在内容窗格中右键单击高斯泼溅图层，然后单击属性。
注:
不支持视域等 3D 探索性分析工具。 无法选择单个高斯泼溅点。 Vulkan 渲染引擎不支持高斯泼溅图层。
高斯泼溅图层数据源
您可以通过在添加数据对话框中选择支持格式（如 JSON 或 3TZ）的 3D 切片数据集来创建高斯泼溅图层，或是使用从路径添加数据对话框来处理托管在 ArcGIS Online 中的 3D 切片服务。 根据 3D 切片规范，高斯泼溅图层要求 3D 切片数据集包含 ESRI_crs 和 3DTILES_content_gltf 扩展模块。 第三方软件必须遵循 3D 切片规范并指定所需的扩展模块，才能将 3D 切片数据集识别为高斯泼溅图层。
注:
当前不支持非地理空间格式，例如 PLY。
您可以通过 ArcGIS Reality for ArcGIS Pro 生成 3D 切片数据集以用作高斯泼溅图层。
ESRI_crs 扩展模块
在使用 GIS 中的数据时，正确定义坐标系至关重要。 ESRI_crs 扩展模块支持用户在任何明确定义的坐标系 (WKID) 中使用水平和垂直坐标系。 例如，您可以在 ArcGIS Pro 或其他 ArcGIS 应用程序中以工程所需的投影坐标系查看高斯泼溅图层。 如果您还想将高斯泼溅图层提供给其他第三方应用程序，则可以在 WGS 1984 中查看相同的数据。 凭借这个扩展模块，您不再需要提供采用 WGS 1984 椭圆体垂直坐标系的数据。 您可以定义自己的坐标系，并且无需复制数据，即可在定义为 WGS 1984 的场景中使用数据。
3DTILES_content_gltf
要正确渲染高斯泼溅点，必须包含正确的高斯泼溅和压缩算法。
共享高斯泼溅图层
您可以将高斯泼溅图层作为 Web 图层共享，或是在 Web 场景中共享到 ArcGIS Online 或 ArcGIS Enterprise 12.1 和更高版本。 或者，使用 3D 切片包工具创建 .3tz 文件，并使用共享包工具将其上传到 ArcGIS Online 或 ArcGIS Enterprise 12.1 和更高版本。
从文件
请完成以下步骤以从 .json 或 .3tz 文件添加高斯泼溅图层：
在地图选项卡的图层组中，单击添加数据 。
在添加数据对话框上，浏览至 JSON 或 3TZ 格式的切片集 ，然后单击确定。
仅当采用 JSON 格式的切片集的文件名为 tileset.json 时，才能识别该切片集。
场景中随即添加一个高斯泼溅图层。
