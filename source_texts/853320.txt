Task
Migrate the already-correct production u64 -> f32/f64 low/high sequence from
assembly-string construction into typed post-register-allocation machine
records consumed by both assembly and object serializers.
This issue owns only the integer-to-float direction. It does not wait for or
modify the independent float -> u64 correctness fix #7251, and it does not
retire the global direct-object Cast gate.
Current findings
Audit baseline: main@f55be174, 2026-09-02.
compiler-backend-u64-to-float-cast-asm implements the full unsigned range:
test the sign bit; use signed cvtsi2s{s,d}q on the low path; otherwise copy
the low bit, shift a destructive working copy right, restore the sticky low
bit with OR, convert, and double with adds{s,d}.
Selection already interns deterministic high/done i64 label IDs from the
containing IR block label, SSA destination, and suffix. Assembly rendering
then combines the function identity with each label and immediately flattens
the branch, definitions, and operands into one String. The migration should
preserve those IDs as function-scoped local identities; it need not invent a
second label allocator, and it must not treat an IR-label ID as globally
unique across functions.
Regalloc reports two GP scratch requirements for every u64 -> float cast:
FloatCastValueGp receives the destructive working copy and
FloatCastScratchGp preserves the low bit. A spilled result additionally
uses FloatCastValueXmm. The migration must consume those planned, distinct
homes exactly.
The production fixture now contains tests: lock exact u64-to-float runtime rounding bits #7449 exact f32/f64 bit-payload checks at precision and high-path tie boundaries; that reviewed oracle landed through PR tests: lock exact u64-to-float rounding #7724 before this record migration.
Linux/Windows assembly checks assert textual label, js, andq, shrq,
orq, addsd, and addss shapes. Windows force-selects assembly for this
fixture, and the authoritative direct-object semantic gate rejects all
Cast instructions.
backend: record source-located scalar fault blocks in shared machine programs #7345 owns the generic stable-local-label and fixed-width local-transfer API
inside its fault-block slice. backend: migrate scalar physical moves, float rodata, and RIP-relative fixups #7301 owns final GP/XMM register/spill operands,
backend: migrate full-width scalar integer materialization to shared machine records #7202 full-width integer materialization, and backend: migrate branch-free scalar float conversions to machine records #7253 checked scalar conversion
opcodes.
The sequence also needs register test/mov/or, immediate-one and/shr,
and precision-matched scalar add. Reuse common checked primitive
descriptors from backend: migrate checked scalar shifts to shared machine records #7204/backend: migrate scalar SSE2 expressions to shared machine records #7205 if available; otherwise publish the narrow rows
from this issue for those consumers. Do not create a cast-private encoder and
do not wait for either broad migration.
Focused issue/PR searches found no duplicate implementation or claiming PR.
Landing shape
Consume tests: lock exact u64-to-float runtime rounding bits #7449's reviewed exact-bit production oracle.
Preserve the existing function-scoped high/done identities and emit the
selected test/branch/low-convert/jump/high-transform/convert/double sequence
as checked records using final physical homes.
Serialize the same records to existing Linux/Windows assembly and through
the common x86 encoder/local-layout pass into ELF/COFF bytes.
Do not extend the broad object-only Cast-as-move placeholder. Leave its
deletion, whole-program Cast eligibility, and source-level no-assembler
matrix enforcement to backend: retire Cast object fallback after full scalar matrix parity #7355 after every scalar cast producer lands.

Acceptance criteria
Production selection emits one checked typed sequence for u64 -> f32 and
u64 -> f64: test/sign branch, low conversion, jump, high-path copy/low-bit/
shift/OR, conversion, and precision-matched doubling.
Results match tests: lock exact u64-to-float runtime rounding bits #7449 and SPEC §3.8 over the full u64 range under the hosted
default round-to-nearest, ties-to-even environment, including zero, precision
boundaries, 2^63-1, 2^63, high-path tie-adjacent values, and u64::MAX.
Do not broaden this into a new non-default MXCSR guarantee.
Preserve the existing high/done semantic IDs once in production selection
and scope them by function in the machine program. Assembly and bytes consume
the same label IDs, fixed-width branch records, layout, and local fixups; no
serializer reconstructs names from function/block/destination text.
FloatCastValueGp, FloatCastScratchGp, and optional FloatCastValueXmm
name final physical homes. Value and low-bit GP homes are distinct, the
destructive shift always targets the working copy, and the live source is
never modified.
Invalid scratch aliasing, wrong register class/width, missing or duplicate
function-local label, cross-function target, unsupported precision, or
incomplete sequence fails deterministically before serialization with
bounded cast/function context.
Assembly serialization is byte-for-byte text identical to current Linux/
Windows output, including label placement and instruction order. Any
intentional normalization is separately justified and measured.
Exact ELF/COFF byte and local-layout goldens cover testq, js, both
cvtsi2s{s,d}q forms, jmp, register movq/orq, immediate-one
andq/shrq, adds{s,d}, short/near boundary policy, low/extended GP and
XMM registers, REX/prefix order, and direct/spilled input/result plans.
Focused shared-record object tests execute or otherwise prove the selected
sequence independently of the old object-IR selector. tests: lock exact u64-to-float runtime rounding bits #7449's source oracle
may remain assembly-backed here; final source-level direct-object parity and
assembler-fatal enforcement belong to backend: retire Cast object fallback after full scalar matrix parity #7355 after its observation
dependencies are available.
Do not remove the whole-program Cast exclusion or claim the public fixture
no-assembler here. The final matrix/eligibility gate is backend: retire Cast object fallback after full scalar matrix parity #7355.
Report record bytes/allocations, backend time, generated instruction/code
size, and peak memory before/after. Run typelisp fmt, focused tests under
the repository cap, bootstrap/fixpoint, and hosted Linux/Windows CI.
Assumptions / blockers
Blocked on #7055, #7202, #7253, #7301, and #7345; #7449 landed through PR #7724 and supplies the exact-bit production oracle. It is not blocked on
#7251, #7204, #7205, completion of broad #7028/#7029, general calls, runtime
helpers, or unwind work. After the remaining named prerequisites land, remove blocked
and add ready-for-implementation.
Coordinate reusable primitive opcode tables with #7204/#7205 and the
shared-core/target-adapter boundary with #5347.
