Problem
Current global sort + tile binning pipeline remains too expensive for 10M+ splat targets.
Observed constraints include pass-heavy radix sorting and duplicated heavy work in binning stages.
Scope
optimize sort throughput (pass count, prefix strategy, subgroup efficiency)
reduce duplicated work/atomics in binning count+emit paths
preserve strict global depth ordering across all objects/instances/scenes
keep within RenderingDevice API constraints
Acceptance Criteria
improved throughput on synthetic heavy lanes without correctness regressions
lower sort+binning stage time at same visible splat counts
parity checks for multi-object depth correctness remain green
