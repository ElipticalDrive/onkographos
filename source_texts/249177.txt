Hi, thanks for sharing this repository — it’s been very helpful.
I’m trying to understand how the robot geometry is handled in the preprocessing pipeline. From what I see:
voxelized_pointcloud_sampling.py always loads a *_scaled.off file
convert_to_scaled_off.py only converts mesh files (.obj, .off, etc.)
In datasets/arm/UR5/, there is a UR5.urdf but no corresponding UR5.obj
The only existing *_scaled.off (e.g. untitled_scaled.off) seems to correspond to an obstacle, not the robot
My question is:
How is the UR5 robot geometry (and end-effector/gripper) supposed to be voxelized?
Is there an expected merged mesh for the robot (e.g. UR5.obj) that should be provided manually?
Or is there a script that converts the URDF into a single mesh for voxelization?
If grippers are changed, what is the recommended way to update the robot geometry used for training?
Any clarification on the intended workflow would be greatly appreciated.
Thanks again for the great work!
