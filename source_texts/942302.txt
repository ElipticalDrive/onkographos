Pro_V1.0.3.13
7fc98ba
产品官网：https://mls4dlive.cn/
Resolved flickering issues and enhanced rendering quality.
Added support for Constrained Aspect Ratio.
Fixed an issue where toggling visibility failed in packaged builds.
Implemented linear depth to prevent depth overflow when zooming out, resolving incorrect occlusion of 3D meshes by the Gaussian scene.
Added Contrast adjustment: Use console command r.MLSLabs.Contrast (Default: 1.15).
Added Saturation adjustment: Use console command r.MLSLabs.Saturation (Default: 1.0).
Ubuntu 22.04 support for Gaussian Splatting rendering (performance/FPS par with Windows), For the plugin package, please make a separate inquiry via mlsmediaservice@mlslabs.com.cn.
Filter thumbnails in 3D preview viewports to avoid crowding all 3D viewports (inc. Asset Editor).
Support anti-aliasing on the edges of 3D meshes after blending Gaussian colors. For high-quality anti-aliasing, switch the anti-aliasing
method to TSR. If you want to avoid flickering, change the anti-aliasing method to FXAA.
Support rendering Gaussian scenes in multiple viewports;
Support normal rendering for off-screen components such as SceneCapture.
1，解决闪烁问题，提升渲染效果；
2，支持固定相机宽高比（ConstrainedAspectRatio）；
3，修复打包后程序显示隐藏失效问题。
4，采用线性深度，避免镜头拉远时出现深度溢出，导致三维Mesh被高斯场景错误遮挡。
5，支持调整对比度，控制台命令：r.MLSLabs.Contrast 默认值1.15
支持调整饱和度，控制台命令：r.MLSLabs.Saturation 默认值1.0
6. 支持 Ubuntu 22.04 的高斯泼溅（Gaussian Splatting）渲染，其性能与帧率（FPS）基本与 Windows 持平（插件包请单独咨询mlsmediaservice@mlslabs.com.cn）。
7. 过滤 3D 预览视口中的缩略图，以避免挤占包括资产编辑器（Asset Editor）在内的所有 3D 视口。
8. 支持混合高斯颜色后 3D 网格体边缘的抗锯齿。若要获得高质量的抗锯齿效果，请将抗锯齿方法切换为 TSR；如果想避免闪烁，请将抗锯齿方法更改为 FXAA。
9. 支持在多个视口（Multiple Viewports）中渲染高斯场景。
10. 支持 SceneCapture 等离屏组件（Off-screen Components）的正常渲染。
