Is your feature request related to a problem? Please describe.
A common use of vertex colors is to bake Ambient Occlusion into a mesh. Many programs, like blender, even have ways to automatically set up those values based on angles and lines of sight. This is especially useful if you are using textures which are not atlassed to anything or materials which don't use the UVs, like Triplanar, because it allows you to give proper ambient occlusion to areas on the model, and is more efficient than a texture simply because most ambient occlusion is caused by the broader features and creases of an object.
There is also a technique where you use the vertices of terrain, instead of a splat map, to switch between different terrains, and vertex color is a way to do that.
There are also techniques which use vertex to tint Albedo for details.
Unfortunately, resonite PBS materials do not currently have any way to use vertexes.
Describe the solution you'd like
The ability to use the Vertex Color, to tint the Albedo, Splatmap, Ambient Occlusion. This would be especially good if individual channels could be selected for each, allowing us to pack, or if a more specialized vertex-attribute could be selected.
Describe alternatives you've considered
There might be a way to fake this with an unlit multiply using the vertex color, but doesn't that seem a little unreasonable?
It also occurs to me that this might get put off until custom shaders, but that is still quite a ways away and this is something we could start using right now. Even if it does have to wait till then, I would really like to at least see the example when those come out.
