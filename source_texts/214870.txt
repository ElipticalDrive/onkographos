Description
🚀 ViscoBurst v1.0: Viscoelastic Worthington Jets & Droplets Simulator
Overview
ViscoBurst is a comprehensive framework for simulating viscoelastic Worthington jets and droplets produced by bursting bubbles. This first official release provides researchers with tools to investigate the complex dynamics of bubble cavity collapse in viscoelastic media.
🌟 Key Features
Core Simulation Capabilities
Advanced Physics Modeling
Two-phase viscoelastic flow simulation using Oldroyd-B constitutive model
Volume of Fluid (VoF) method for interface tracking
Adaptive Mesh Refinement (AMR) with quadtree grids
Log-conformation approach for numerical stability
Parameter Space Exploration
Comprehensive Control Parameters
Deborah number (De): Relaxation time effects
Elastocapillary number (Ec): Elastic to surface tension ratio
Ohnesorge number (Oh): Viscous to inertial-capillary effects
Bond number: Gravitational effects
Analysis Tools
Data Extraction (C)
Core data extraction utilities
Jet height analysis tools
Base property analysis
Droplet statistics computation
Facet and inertial properties analysis
Cell counting utilities
Visualization & Analysis (Python)
Bubble bursting phenomena visualization
Facet analysis and two-bar representations
Viscous dissipation studies
Data output and plotting utilities
Interactive Jupyter notebooks
Multi-Platform Support
Flexible Deployment Options
Local execution (MacOS/Linux)
HPC cluster support (MPI-enabled)
OpenMP parallelization for Linux systems
💻 Installation
Prerequisites
Basilisk C (http://basilisk.fr)
C compiler toolchain (Xcode Command Line Tools for macOS)
MPI for cluster deployment (optional)
