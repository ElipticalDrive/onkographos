Implements the backend-agnostic CPU reference for RFTraceKit per the phase1-cpu-prototype OpenSpec change — all 47 tasks. This is the correctness baseline that future GPU backends (Metal/CUDA/OpenCL) are validated against.
What's included
Core geometry — Eigen Vec3/Ray/Triangle/AABB, Möller–Trumbore intersection, NanoRT-style BVH (median split) with closest-hit and occlusion queries, validated against a brute-force reference.
Scene & import — Scene model (materials + presets, antenna patterns, transmitters, receivers, Z-up coordinate system, per-triangle material resolution); Assimp glTF/OBJ import with Y-up→Z-up normalization; JSON material loading with validation.
RF physics (header-only) — FSPL, Fresnel reflection (TE/TM), penetration loss, phase, delay, antenna gain, coherent/incoherent power aggregation.
Simulation & results — Backend interface + CPU backend; point-receiver mode with LOS and specular reflections (image method up to maxReflections); deterministic output. RFPath/RFResult model, per-receiver aggregation, JSON + CSV export.
Build & tooling — CMake (C++20) with optional backend flags; vcpkg manifest or system deps; justfile (vcpkg-optional with system/Homebrew fallback); GoogleTest via pinned FetchContent.
Verification
just ci passes end-to-end: 53 tests under clang, a second gcc build+test, an ASan/UBSan build+test, openspec validate --all --strict, and both examples.
Examples: simple_los (LOS link budget), city_reflection (LOS + reflection).
CPU BVH closest-hit ~0.5 Mrays/s single-threaded over 50k triangles (within the 100k–1M rays/s Phase 1 target).
Notes / deviations
BVH uses median split (not SAH) — meets correctness + sublinear requirements; SAH is a future optimization.
GMock not yet linked (nothing to mock in Phase 1; arrives with CPU-vs-GPU consistency tests).
Tests: 53 covering geometry, BVH, scene, import, RF formulas, simulation, results, and golden scenes (empty, single-wall reflection, two-building canyon).
