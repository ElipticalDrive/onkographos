Abstract
In volumetric video content, dynamic 3D objects containing frame information,
akin to a video, are utilized to depict the movement of 3D objects. Due to their
larger data size compared to static 3D objects, efficient compression techniques
are imperative for dynamic 3D objects. Consequently, the moving picture experts
group (MPEG) has undertaken research on video-based dynamic mesh coding
(V-DMC) for compressing dynamic mesh, and video-based point cloud compression (V-PCC) for compressing dynamic point cloud. Moreover, mesh and point
cloud serve as data structures representing 3D object in virtual reality, each with
distinct advantages and disadvantages. Hence, advancements in volumetric video
can be anticipated through the conversion of dynamic point cloud obtained from
real world into dynamic meshes, which offer rendering advantages. Enabling realtime streaming of volumetric video using dynamic mesh necessitates not only the
conversion between dynamic point cloud and dynamic mesh but also efficient compression techniques tailored for dynamic point cloud or dynamic mesh. This paper
conducts experiments involving conversion and compression from dynamic point
cloud to dynamic mesh using a poisson surface reconstruction (PSR) based converter and international compression standards for dynamic mesh and dynamic
point cloud. Furthermore, subjective performance evaluations are conducted on
the experimental results, comparing the dynamic meshes generated using V-DMC
and V-PCC.

1 Introduction
Immersive content, which immerses users in realistic artificial virtual environments
or overlays computer-generated information onto the real world, is experiencing rapid
growth. Prominent examples of immersive content include 3 degrees of freedom
(3DoF), 3DoF+, and 6 degrees of freedom (6DoF), as well as volumetric immersive
video and virtual reality generated through mathematical operations, offering users
realistic visual environments and interactions[1–4]. Within the moving picture experts
group (MPEG), active standardization efforts are underway to enhance the compression efficiency of 3DoF and 6DoF videos. Additionally, research is being conducted on
volumetric videos, which capture real-world objects as 3D data and present them to
users. Point cloud and mesh serve as data structures representing 3D objects in virtual
reality and volumetric video. Fig. 1 shows the structure of both the point cloud and
mesh. Point cloud is a data structure that represents a 3D object by aggregating points
containing geometric position, color, and normal vector data. Compared to mesh, point
cloud has a simpler structure, making them easier to process and analyze. They convey
object information through the position and color of each point. Moreover, point cloud
is advantageous for creating real-world 3D objects, such as those captured by 3D scanners and light detection and ranging (LiDAR) systems. Consequently, the point cloud
format is primarily utilized in 3D reconstruction processes that generate object information by scanning real-world objects. On the other hand, mesh is a data structure

that depicts a 3D object by connecting vertices to form small polygons and applying
texture mapping to surfaces. Typically, mesh consists of triangular polygons. Mesh
requires fewer points compared to point cloud, and their data size can be significantly
reduced by down-sampling the resolution of texture maps. Additionally, mesh can render more realistic by incorporating shading effects that adjust the brightness of object
based on factors like viewpoint, light distance, and angle. These effects are achieved
through texture mapping applied to the surface, along with lighting effects and shading
techniques. Therefore, in virtual reality content aiming for a high level of realism in 3D
space representation, mesh is primarily employed to depict 3D objects. In computer
graphics, 3D objects primarily utilize skeleton animation, a technique that involves
placing a skeleton onto a mesh through rigging and applying joint movements to convey
motion. In the case of static mesh, there isn’t a significant difference in data size since
the movement of 3D objects can be depicted using the rigged mesh data along with
animation information of the skeleton. However, when skeleton animation is applied to
volumetric video capturing real-world 3D objects, reproducing the movement of object
and integrating it seamlessly with the acquisition process becomes challenging due to
complex post-processing. Consequently, to represent the movement of real-world 3D
objects accurately, data for all frames are stored and rendered akin to video frames,
termed as dynamic mesh and dynamic point cloud, respectively. Dynamic mesh and
dynamic point cloud store object data for each frame, resulting in a data size increase
proportional to the duration of the object’s movement. Consequently, dynamic mesh
and point cloud obtained from real-world often possess data sizes too large for realtime streaming and immersive media content, highlighting the necessity for efficient
compression standards. To address this, the moving picture experts group (MPEG)
has established V-PCC as a standard for dynamic point cloud compression and VDMC as a standard for dynamic mesh compression, with ongoing research focused
on standardization efforts. Since dynamic mesh and dynamic point cloud possess distinct data structures, it’s imperative to investigate which structure is more efficient
for use in volumetric video. Additionally, given that V-PCC focuses solely on dynamic

2 Related Work
This section introduces the encoding process and performance evaluation method of
V-PCC, a compression standard for dynamic point cloud, and V-DMC, a compression
standard for dynamic mesh.
2.1 Video-based Dynamic Point Cloud Compression (V-PCC)
V-PCC is a standard for the compression method of dynamic point cloud conducted
by MPEG. MPEG announced a call for proposal (CfP) for point cloud compression
in 2017, and based on 13 responses, a test model (TM) for dynamic point cloud
using video codecs appeared at the 120th MPEG conference[5]. The TM was officially
named V-PCC in 2018, and standardization work began, and standardization research
is being conducted for the purpose of real-time streaming volumetric video content
using point cloud[6]. Figure 4 shows the V-PCC encoding process. V-PCC divides
point clouds into several patches to generate three types of 2D images: occupancy
information, geometry information, and attribute information. Geometry information
includes spatial position and shape information of each patch, attribute information,
and occupancy information includes information on occupied pixels of other patches.
These four types of data are compressed to generate a final bitstream, and during
the decoding process, the 3D point clouds are reconstructed through four data. Atlas
information is compressed by applying prediction between patches, similar to interpatch prediction of video codecs, and geometry, occupancy, and attribute information
are compressed using the existing video compression standard. Advanced video coding
Fig. 4: V-PCC Encoder Block Diagram

(AVC), high efficiency video coding (HEVC), and veritable video coding (VVC) are
applicable, and V-PCC CTC recommends the HEVC.
2.2 Video-based Dynamic Mesh Coding(V-DMC)
V-DMC, similar to V-PCC, stands as a standard for dynamic mesh compression, and
standardization research is actively pursued for facilitating real-time streaming of volumetric video content comprising dynamic mesh. In 2022, MPEG initiated a call for
proposals (CfP) specifically targeting dynamic mesh compression and were received
from prominent industrys including Apple, InterDigital, Sony, Nokia, and Tencent.
Among the proposals submitted, those from Apple and InterDigital demonstrated
superior compression performance compared to the anchor model presented by MPEG
for comparison purposes[7]. Consequently, the compression algorithm developed by
Apple served as the foundation for the creation of the V-DMC Test Model (TM). This
marked a significant milestone in the standardization efforts for dynamic mesh compression of MPEG[8]. Figure 5 shows the encoding process of V-DMC. Initially, the
V-DMC encoder embarks pre-processing of the input mesh. During the pre-processing,
V-DMC first obtain decimated mesh by reducing the number of vertices in the original
mesh. Subsequently, the subdivision process is executed, wherein an arbitrary number
of iterations are generated between vertices. While various subdivision schemes exist,
V-DMC adopts a mid-point subdivision scheme, which involves creating temporary
iterations at the midpoint coordinates of two adjacent vertices. Finally, in the displacement process, movement vectors, termed displacement vectors, are calculated for gap
of the temporary iterations generated during subdivision and destroyed vertices during
decimation. Consequently, during the preprocessing phase, the decimated meshes and a
set of displacement vectors are generated. It’s noteworthy that subdivision can be performed during the decoding process without necessitating the storage of separate data.
Fig. 5: V-DMC Encoder Block Diagram
6
As a result, the original mesh can be reconstructed solely with the decimated mesh
and displacement vectors. This capability enables V-DMC to achieve significant compression efficiency. Following pre-processing, the decimated mesh is compressed with
DRACO, a mesh compression software developed by Google. Meanwhile, the displacement vector is packed and processed using wavelet transform, generating 2D images
that are subsequently compressed using video codecs. V-DMC adopts the screen content coding (SCC) extension standard for compression of screen content within the
high efficiency video coding test model (HM). This standard is utilized for compressing both displacement vectors and textures. Finally, the mesh, compressed through
DRACO, along with the displacement vector and texture compressed through the
video codec, are consolidated into the final bitstream. This comprehensive compression
process ensures efficient storage and transmission of dynamic mesh data.

3 Dynamic Point Cloud Compression and
Conversion Experiments
Mesh and point cloud serve as fundamental data structures for representing 3D objects
in virtual reality, each offering distinct advantages and disadvantages. Point cloud,
8
characterized by its simple data structure, excels in 3D object acquisition. Conversely,
mesh, with its ease of application in computer graphics technologies such as shading, proves advantageous for rendering purposes. Consequently, converting real-world
acquired dynamic point cloud into dynamic mesh holds the potential to enhance the
quality of volumetric videos. Real-time streaming of such volumetric videos necessitates efficient conversion and compression processes between dynamic point cloud
and dynamic mesh. By optimizing these processes, dynamic point cloud acquired by
real world can be represented efficiently with dynamic mesh, thereby facilitating the
delivery of higher-quality volumetric video content in real-time streaming scenarios.
This section outlines the detailed process of the experiment and introduces converter,
which efficiently converts a dynamic point cloud into a dynamic mesh. The experiments aim to generate dynamic meshes with dynamic point clouds by compressing
V-DMC and V-PCC, respectively. Depending on whether the conversion from dynamic
point cloud to dynamic mesh occurs before or after transmission, there are two methods: compressing the dynamic point cloud with V-PCC or compressing dynamic point
cloud with V-DMC after converting dynamic point cloud to dynamic mesh. And this
experiments adopt the CTC specified by each international standard as an experimental conditions. By analyzing the results under various experimental conditions,
the study aims to identify differences in outcomes. The converter plays a crucial role
in this experiment by efficiently converting dynamic point cloud to dynamic mesh.
By leveraging the PSR algorithm, the converter ensures accurate and detailed generation of dynamic meshes from dynamic point clouds[12–14]. This effective converter
enables experiments to compare the performance of different transmission methods
by generating dynamic mesh similar to original dynamic point cloud. Figure 8 shows
architecture of experiment conducted in this paper. This experiment is an experiment
for real-time streaming of a real-time acquired dynamic point cloud to a dynamic
mesh, and for this purpose, uses a PSR converter that efficiently converts the dynamic

point cloud to dynamic mesh. Also, in this real-time streaming scenario, depending
on when the dynamic point cloud is converted through a PSR converter, it is possible to decide which compress standard to use between a dynamic point cloud or a
dynamic mesh, so the purpose of this experiment is to compress the dynamic point

each international standard. Each experiment condition involves varying multiple compression parameters, including texture quantization parameters (QP), displacement
QP, and mesh QP for both V-DMC and V-PCC. For V-PCC, the experiment conditions involve varying the number of points, while for V-DMC, differences in texture
resolution and mesh complexity are considered. In contrast, the PSR converter process maintains consistent parameters and processes across all experiments to ensure
fairness and comparability. The experiments utilize the test sequences specified by
V-PCC, including Dancer, Soldier, Longdress, and Basketball, each consisting of 15
frames. Figure 9 shows the process of converting a dynamic point cloud to a dynamic
mesh using the PSR algorithm. The converter is developed using Python and utilizes
various libraries including OpenCV, PyMeshLab, UVAtlas, and MeshLab in the conversion process. The PSR algorithm serves as the primary method for converting a
dynamic point cloud into a dynamic mesh. It estimates vertices and faces based on
the normal vector of each point in the point cloud. However, when applying PSR to a
point cloud with a high concentration of points, it can result in the creation of excessive vertices and faces, leading to a large and complex data structure. To mitigate this
issue, the PSR converter employed in this experiment applies down-sampling to significantly reduce the number of points in the point cloud. Subsequently, each point in
the point cloud undergoes a normal estimation process to acquire information about
its normal vector. The PSR algorithm is then applied to the pre-processed point cloud
10
Fig. 10: PSR Octree Depth Parameter Test
to convert it into a mesh. After the application of the PSR algorithm to the point
cloud, unnecessary vertices and faces may be generated, complicating the mesh data
structure and consuming unnecessary data. To address this issue, a post-processing
step is undertaken to remove incorrectly generated vertices and faces. Firstly, vertices
and faces that are incorrectly generated or redundant are identified and removed. This
streamlines the mesh data structure and reduce unnecessary data. Subsequently, isolated vertices, which do not contribute to constructing faces and are not connected to
any other vertices, are identified and removed. These isolated vertices are considered
unnecessary for representing 3D objects. Finally, non-manifold vertices are identified
and removed. A non-manifold mesh deviates from the typical structure where all 3D
meshes can be unfolded into a 2D form. Non-manifold states occur when three faces
share one edge, multiple surfaces are connected to one vertex, a face is created inside
the mesh, or the normal vectors of adjacent surfaces are opposite to each other. Maintaining the manifold properties of the mesh is crucial as non-manifold meshes can lead
to complications and errors in processing and utilization. By identifying and removing
vertices that cause non-manifold properties during the post-processing step, the manifold properties of the mesh are preserved, ensuring its integrity and usability. The
mesh generated through the post-processing process has color information in the faces
and vertices, and this data structure does not interfere with the representation of a 3D
object, but other rendering environments and V-DMC use a mesh that contain color
information in texture, so it should be converted into a mesh that contain color information in texture. In this experiment, UVAtlas of Microsoft that is used in V-DMC
to texture generation is used to texture generation. In the conversion process from a

point cloud to a mesh, the algorithms employed offer parameters that enable adjustment of both the data size and quality of the resulting 3D object. For instance, in
Simplification, increasing the number of points to be deleted can significantly reduce
the data size. However, if too many points are removed, it can adversely affect the surface created by the PSR algorithm. Additionally, the PSR algorithm features an octree
depth parameter, which serves as a means for quality control of surface reconstruction.
Adjusting this parameter allows for fine-tuning of both the quality and data size of
the generated mesh. This paper conducts experiments to assess the efficacy of different parameter configurations in converting a point cloud with very high density into
a mesh. Through systematic adjustment of these parameters and thorough analysis
of their impact on the resulting mesh, our study aimed to identify optimal configurations that achieve a balance between reducing data size and preserving surface quality.
This empirical investigation offers valuable insights into parameter settings that lead
to the most favorable outcomes in terms of mesh conversion from high-density point
clouds. Such insights are crucial for optimizing the process of point cloud to mesh
conversion, thereby enhancing the efficiency and quality of 3D object representation
in various applications. Figure 10 shows the outcomes of the PSR parameter experiment aimed at identifying the optimal parameters of the PSR converter. In the case of
simplification, the data size of the converted mesh experienced a substantial decrease
as the number of points of the point cloud is reduced. However, if more points are
removed beyond 95 percent of the original density, issues arose in reconstructing dense
areas effectively. As a result, in the converter utilized in this experiment, the number
of points is reduced to target the range of 5 percent to 7 percent of the original density. This parameter configuration strikes a balance between achieving significant data
size reduction and preserving the integrity of dense areas during mesh reconstruction.
By adopting this approach, the PSR converter effectively converts high-density point
clouds into meshes while mitigating potential issues related to excessive point removal.

The octree depth parameter of the PSR algorithm plays a crucial role in determining the level of segmentation of the reconstruction grid. As the octree depth value
increases, the size of the reconstruction grid expands exponentially, doubling with each
increment. A lower octree depth value results in a reconstruction grid composed of
larger cells, providing only an approximate representation of the overall surface shape.
Conversely, a higher octree depth value leads to a reconstruction grid composed of
smaller cells, enabling a more precise representation of the detailed structure of the
surface. However, it’s important to note that while higher octree depth values can produce high-quality meshes with intricate surface details, they also lead to larger data
sizes for the generated meshes. In experiments with the octree depth parameter, it is
observed that a mesh with a similar appearance to the original point cloud can be
generated with an octree depth of 8. However, to reproduce areas with even higher
complexity, such as facial features, a minimum octree depth of 10 is typically required.
This demonstrates the trade-off between mesh quality and data size, where higher
octree depth values yield more accurate representations but also result in larger file
sizes. The objective of PSR converter experiments is to ensure that the resulting mesh
exhibits minimal differences in appearance compared to the original point cloud. This
is crucial for providing users with an immersive and realistic experience, as the rendered content must closely resemble reality. Figure 11 shows original point cloud and
converted mesh by PSR with V-PCC test sequence. Utilizing PSR converter developed
in this study, this paper proceeds to conduct dynamic mesh generation experiments
employing both the V-DMC and V-PCC standards. These experiments aim to evaluate the effectiveness of each compression method in generating dynamic meshes from
high-density point clouds. By comparing the results obtained from both V-DMC and
V-PCC approaches, the study seeks to identify the most suitable compression standard
for real-time rendering of volumetric video content and to present research directions.

5 Conclusion
As research on next-generation realistic content continues due to the growing interest in extensive reality and advancements in hardware, dynamic mesh and dynamic
point cloud have emerged as key components for utilizing 3D objects acquired from
the real world. Technologies such as RiDAR primarily capture objects in a point cloud
structure, while in rendering environments, mesh structure is favored due to their
compatibility with computer graphics technologies such as shading. Thus, to achieve
more realistic object rendering, it becomes imperative to convert and render objects
acquired via dynamic point cloud into dynamic mesh. Furthermore, in the process
of compressing and transmitting 3D objects in real-time streaming, it is essential to
16
determine which data structure is efficient and minimizes loss between dynamic mesh
and dynamic point cloud. This paper conduct experiments involving the compression
and conversion of dynamic point cloud to dynamic mesh using V-DMC and V-PCC,
which are international standards for 3D dynamic object compression established by
MPEG. Additionally, this paper develops and utilizes to experiments the efficient
PSR converter for generating dynamic mesh with high-data-size dynamic point cloud.
Subjective performance evaluation are performed on the dynamic meshes generated
through each compression standard, and the results are meticulously analyzed to
identify parameters that significantly contribute to the quality of the final generated
dynamic meshes in each compression process. Through these experiments, this paper
discovers that applying PSR after compression to V-PCC and transmission effectively
reconstructions high-quality dynamic mesh in the real-time streaming of volumetric
videos. Furthermore, this paper observe that changes in experimental conditions of
V-PCC have a significant impact on the quality of dynamic mesh generation, whereas
changes in experimental conditions through V-DMC have a relatively smaller effect.
Therefore, in compression through V-DMC, focusing on the mesh generation process
through PSR converter before compression proves to be an efficient compression and
transmission strategy. Aim of this paper is to contribute to research in the real-time
streaming, compression, and transmission of dynamic 3D objects.
