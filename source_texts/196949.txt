This documentation describes the main features of FIDDO (FInite Difference Diffusion in
Olivine). FIDDO is set of MATLAB routines that can be used to calculate the concentration
profiles of Fe-Mg zonation in olivine in 1 dimension. The routines must all be placed in a
common folder. These routines are:
•
Olivine_Diffusion_Vect.m
•
FIDDO.m
and they can be run by typing FIDDO in the MATLAB command window.
The chemistry of olivine is described by the mineral formula [Fe,Mg]2SiO4. FIDDO utilizes
the conservative, finite-difference method for the solution of the diffusion problem in 1
dimension. The code has been written in general form using functions that would allow the
more transparent presentation of the results. More technical details follow below. The
software and the present documentation are provided free of charge1. At this point, all the
provided routines have been tested for compatibility with OCTAVE.

Introduction
The purpose of the present document is not to provide a detailed review of the literature
on olivine diffusion, but to provide a concise introduction on the methods that are
implemented in FIDDO and to show the respective governing equations. We have tried to
keep the text to a minimum and show how the program can be easily used. Our algorithms
have been evaluated and the results have been compared with an analytical solution for
non-linear diffusion that varies with concentration. The results of this comparison and a
worked example are given in the following sections.

Worked Example
The main routine of FIDDO is Olivine_Diffusion_Vect.m that takes an initial concentration
array as input and produces the result of diffusion as output. To use this code, an additional
routine was created, FIDDO.m, where the user specifies an initial concentration profile,
initial pressure and a temperature values, a thermal history, and the angles needed to
calculate the direction cosines (eq. 3). For simplicity, we have assumed a cooling history with
a constant cooling rate (25K/yr) at constant pressure. These numbers can be trivially
changed in the top sections of FIDO routine (Fig. 2). The result of the calculation is shown in
figure 3.

Using FIDDO in OCTAVE
Although FIDDO was written originally in MATLAB, compatibility with octave has been
checked and the codes work normally. The only issues are related to labeling during plotting.
In that case, the option “’intepreter’,’latex’” and he symbol “$” must be deleted from the
axis lables/titles.
