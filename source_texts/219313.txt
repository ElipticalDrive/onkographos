Description
Software for Monte Carlo light multi-scattering.
The software can use the averaged scattering matrix of a particle, or many scattering matrices, each corresponding to a single orientation of the particle.
The description of the method is under submission process.
Input can be generate using the single scattering software: https://doi.org/10.5281/zenodo.18995083
