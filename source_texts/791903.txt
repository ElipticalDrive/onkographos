Add regression coverage for GJK precision on small simplices and the capsule/ellipsoid geometry from #3714.
Upstream commit 3bbf510 now contains the numerical fix as part of its broader NativeCCD update. After merging main, this PR retains the upstream implementation unchanged and only adds two tests:
SmallTriangleDistance: compare point-to-triangle distance with the analytic value sqrt(0.005) across six triangle sizes, checking convergence as well as distance.
CapsuleEllipsoidTightTolerance: check the reported geometry against an independent distance/normal reference at five CCD tolerances, with distance queries at scales 0.1, 1 and 10.
These complement upstream's CapsuleEllipsoidSmallSimplex, which uses a different geometry and checks a shallow penetration. The added cases cover an analytic triangle distance, separated capsule/ellipsoid distance, normals and scaling.
Validation on Linux x86-64, GCC 11, Release, against main b16e0983880f00776e5b9fcf5c18aef2c3cf0705:
All 169 enabled tests across engine_collision_{gjk,convex,driver,box,continuous}_test pass in both double and single precision. The continuous suite has one pre-existing disabled test in each build. Single precision uses -DmjUSESINGLE for both C and C++.
Both added tests fail on the original unchanged base 7d16745b2af574bc717e75190e6c3ad69d029074 and pass on the current upstream implementation. Tolerances remain unchanged; MJTOL_SCALE=0 diagnostics were checked in both precisions.
The PR-file pre-commit checks (whitespace, EOF, clang-format) and git diff --check pass. The full MuJoCo test suite was not run.
Reference: for an axis point p in ellipsoid coordinates with semiaxes a, solve sum(a_i^2p_i^2/(a_i^2+t)^2)=1 for t>=0. The closest ellipsoid point is q_i=a_i^2p_i/(a_i^2+t). Minimizing ||p-q|| along the capsule axis selects its negative endpoint in this example; subtracting the capsule radius gives 1.9899367727234385e-5 m. Transforming (q-p)/||q-p|| gives the expected normal.
Thanks to @son-engr-kr for the reported geometry and investigation. This contribution was developed with an AI coding assistant; the validation above was executed on local source builds.
