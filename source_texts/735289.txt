# Cub3D

The `cub3D` project is part of the 42 Network curriculum. It is a **simple 3D game engine** inspired by the legendary **Wolfenstein 3D**, built using the **C programming language** and the **MLX42 graphics library**.

This project introduces the concept of **raycasting**, allowing you to render a 3D environment from a 2D map, simulating a first-person perspective.

---

## Features

- **Raycasting Engine**: Real-time rendering of a 3D environment from a 2D map.
- **Smooth Player Movement**:
  - Move forward/backward (`W`, `S`)
  - Strafe left/right (`A`, `D`)
- **Camera Rotation**:
  - Rotate using arrow keys
  - Mouse rotation *(bonus)*
- **Wall Textures**:
  - Different textures for North, South, East, West walls.
- **Floor & Ceiling Colors**
- **Map Parsing**:
  - Reads `.cub` configuration files
  - Validates textures, colors, and map structure
- **Error Handling**:
  - Handles invalid maps and inputs safely
- **Memory Management**:
  - No memory leaks (Valgrind / ASan clean)
- **Bonus Features** (if implemented):
  - Minimap
  - Mouse control
  - Door system / animations
