Summary
bakeSdfGrid previously accepted any positive grid below the integer indexing limit, allowing huge author-time allocations. Add a caller-controlled working-payload budget (256 MiB by default) that counts both dense voxel records and temporary distance samples before either allocation. Replace the enum-number cutoff with an explicit built-in allowlist.
Accepted grids retain the same occupancy, materials, anchors and shared voxel lighting path. Grids beyond 64 cubed remain supported within the chosen budget. The budget excludes allocator overhead, existing caller assets and later pool/GPU uploads; it is not an RSS limit. Actual allocation failures still propagate normally.

Review — bakeSdfGrid working-payload budget and explicit primitive allowlist
Verdict: approve
Head 0ab68809, base master, MERGEABLE/CLEAN. All 8 checks on the head are green (comment-refs, linux-build, format-check, header-checks, instruction-size, no-plan-files, closes-lint, whitespace). Header-only change in engine/prefabs/irreden/voxel/, so it does not hit the scout's opus-class core paths, and no render/shader code is involved (cross-host smoke does not apply).
What I verified
Budget arithmetic. maxCells = min(maxWorkingBytes / bytesPerCell, INT_MAX) with the per-axis test size[axis] > maxCells / count is the same overflow-safe form as the old INT_MAX / count check. It gives an inclusive byte boundary (count * bytesPerCell <= budget), and a zero budget makes maxCells == 0, so every positive extent is rejected. The size_t max budget case is clamped back to the integer cell-index limit, so the ivec3(INT_MAX) rejection holds on the second axis (INT_MAX > INT_MAX / INT_MAX).
Accounting matches the real allocations. forEachSdfGridCell (sdf_fill.hpp:37) allocates exactly one std::vector<float> of total cells, and bakeSdfGrid allocates count VoxelRecords. bytesPerCell = sizeof(VoxelRecord) + sizeof(float) covers both, and evaluateGrid writes into the caller's span. The budget check runs before either allocation.
Allowlist. The switch lists all nine built-in ShapeType values and sends CUSTOM_SDF and default to return {}. Out-of-range casts such as 10 and UINT32_MAX are rejected, and a new enum value now fails closed instead of using the evaluator's fallback box. The old numeric cutoff is gone.
Existing callers. shape_debug/main.cpp:4360 and sdf_voxel_scene.hpp:43 take the new default parameter. Both bake small grids (about 11 cubed), far below 16.7M cells, so behavior is unchanged.
Tests. BudgetIncludesOutputAndScratchWithInclusiveByteBoundary pins zero, output-only, and one-byte-short as rejected and the exact boundary as accepted, which would catch dropping the scratch term. DefaultBudgetRejectsLargeValidGridAndAllowsBeyondLegacy64Cube covers the large-grid, INT_MAX, and 65-cubed cases. ExplicitBuiltinSupportRejectsUnknownTypes covers every primitive plus the rejected values. The PR body reports a positive control and all nine SdfBake.* / SdfBakePool.* tests passing on macOS.
Docs. The voxel-and-sdf-rendering.md paragraph matches the code: default 256 MiB, zero budget, empty-asset returns, and allocation failure propagating. The audit-todo update matches too. Neither adds a comment ref (comment-refs is green).
Nits (follow-up)
engine/prefabs/irreden/voxel/sdf_bake.hpp:47 — bytesPerCell hard-codes the assumption that forEachSdfGridCell holds exactly one float per cell. The comment names that coupling, and the boundary test would catch a change to the scratch size. If forEachSdfGridCell ever gains a second scratch buffer, the budget silently under-counts, so a shared constant or a pointer from the iterator's own doc comment would keep the two in step. Optional.
Native Windows validation is listed as pending in the PR body. Nothing in the change is platform-specific (std::size_t arithmetic and IRMath::min), so I do not expect a difference.
Test plan the author should run before merge
None beyond the green CI; the Windows run, when convenient, is fleet-run IrredenEngineTest '--gtest_filter=SdfBake.*:SdfBakePool.*'.
Opus recheck not required.
Escalation: none. Safe for merge.
