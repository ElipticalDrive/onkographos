Implements a complete compressive sensing system for hyperspectral imaging using coded aperture techniques.
Core Implementation
CompressiveHSI class: Random Gaussian measurement matrices with configurable compression ratios (default 0.5)
Compression: Matrix multiplication approach for efficient measurement acquisition
Reconstruction algorithms:
L1 minimization via ISTA (Iterative Soft Thresholding) - highest quality reconstruction
Orthogonal Matching Pursuit (OMP) - fastest greedy sparse recovery
Total Variation minimization - edge-preserving reconstruction
Utilities
Synthetic hyperspectral data generator with configurable sparsity
Quality metrics: PSNR, RMSE, relative error
Example demonstration script comparing all three algorithms
Quick validation test for CI/development
Usage
```
from compressive_hsi import CompressiveHSI, generate_synthetic_hsi, compute_metrics

# Generate or load HSI cube (height × width × spectral_bands)
hsi_cube = generate_synthetic_hsi(32, 32, 31, sparse=True)

# Configure system with 3.33x compression
chi = CompressiveHSI(spatial_dims=(32, 32), spectral_bands=31, compression_ratio=0.3)

# Compress and reconstruct
measurements = chi.compress(hsi_cube)
reconstructed = chi.reconstruct_l1(measurements)  # or reconstruct_omp, reconstruct_tval3

# Evaluate quality
metrics = compute_metrics(hsi_cube, reconstructed)
```
Dependencies
NumPy ≥1.20.0
SciPy ≥1.8.0 (updated from 1.7.0 to address CVE)
Typical reconstruction quality at 30% compression: PSNR 25-49 dB depending on algorithm and data sparsity.
