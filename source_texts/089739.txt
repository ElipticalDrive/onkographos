## 项目简介

DICOM Viewer 是一个可独立部署的 Web 医学影像浏览器。用户从本机选择包含同一序列的 DICOM 文件夹后，应用会直接在浏览器中完成文件读取、序列校验、体数据构建和可视化，不依赖账号系统、数据库或业务后端。

项目聚焦于 DICOM 浏览与交互本身，适合用于医学影像 Web 可视化学习、功能原型、科研辅助工具和二次开发基础工程。

> [!IMPORTANT]
> 本项目目前仅用于技术研究、教学演示和非诊断场景，不属于经过认证的医疗器械软件，不应直接用于临床诊断或治疗决策。

## 核心功能

| 模块 | 能力 | 说明 |
| --- | --- | --- |
| 本地文件夹读取 | DICOM 文件夹选择 | 通过浏览器文件夹选择能力批量读取本地 `.dcm` 文件 |
| 序列校验 | Series UID 一致性检查 | 检测到多个不同序列时停止加载，避免错误地混合重建 |
| 影像视图 | MPR 多平面重建 | 同时显示轴位、冠状位和矢状位视图，并支持切片联动 |
| 360° 视图 | 多视图空间定位 | 组合三平面切片与空间定位视图，提供片厚及显示区间控制 |
| 3D 视图 | GPU 体渲染 | 支持体数据重建、轨迹球旋转和渲染参数调节 |
| 图像操作 | 缩放、旋转与翻转 | 支持放大、缩小、平移、平面旋转、水平翻转和垂直翻转 |
| 测量标注 | 长度、角度与自由描边 | 在影像视图中创建测量结果，并在侧栏集中查看或删除 |
| 显示调节 | 窗位、窗宽与区间 | 调整 VOI 显示范围，适配不同组织与灰度区间 |
| 3D 参数 | 裁剪、色彩与透明度 | 提供 X/Y/Z 裁剪、传递函数、采样距离、环境光和漫反射调节 |
| 响应式界面 | 桌面与窄屏布局 | 工具栏和侧边控制区会根据可用空间调整布局 |
