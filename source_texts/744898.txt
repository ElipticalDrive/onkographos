Description
3D surfaces in InVesalius can sometimes appear flat, making it harder to understand depth in complex anatomical structures like skulls or joints.
This PR introduces Screen Space Ambient Occlusion (SSAO) — a lightweight rendering enhancement that adds subtle shadows in recessed areas, improving depth perception and overall visual clarity.
What’s Changed
Added an SSAO toggle option in the 3D view toolbar
Implemented SSAO rendering using VTK (vtkSSAOPass)
Ensured compatibility by checking VTK version before enabling
Handled errors gracefully by automatically disabling SSAO if unsupported
How It Works
When SSAO is enabled:
The renderer applies an additional pass that simulates soft shadows in crevices
This enhances depth cues without changing the actual geometry or colors
Disabling SSAO restores the default rendering pipeline
Visual Impact
The effect is intentionally subtle, focusing on usability rather than dramatic visuals:
Better depth perception in complex regions (e.g., skull, joints)
Improved visibility of fine structures and cavities
No changes to original colors or geometry
Works seamlessly with existing tools and interactions
Compatibility
VTK 9+ → SSAO enabled
Older VTK versions → Feature safely disabled with a warning
Performance
SSAO uses additional GPU resources, so a slight performance drop (~10–30% FPS) may be noticeable on some systems.
It can be toggled off at any time for smoother interaction.
Testing
Tested on macOS with VTK 9.3.0
Verified toggle behavior and stability
Confirmed no conflicts with existing tools (zoom, rotate, measure)
Error handling and fallback behavior validated

Hi @paulojamorim sir,
Regarding requirement 2 (SSAO on Volume Raycasting):
I investigated the current VTK capabilities used in InVesalius (VTK 9.3.0)
and found the following:
Basic SSAO works correctly for surface rendering using parameters like
radius, bias, kernel size, and blur.
For volume raycasting, enabling ShadeOn() improves visual depth by computing
normals, but SSAO-specific effects appear limited.
I reviewed the Kitware article you shared:
https://www.kitware.com/screen-space-ambient-occlusion-for-volumes/
The article describes additional controls for volume SSAO (SetDepthFormat,
SetVolumeOpacityThreshold, SetIntensityScale, SetIntensityShift). However,
these appear to be either not available or not exposed in the current Python
bindings of VTK 9.3.0 — the article was published December 18, 2023, shortly
after VTK 9.3.0 released on November 9, 2023, suggesting these improvements
may target a newer version.
To ensure forward compatibility, I have added hasattr() guards so that if
these features become available in newer VTK versions, they will be used
automatically.
Based on this, full SSAO support for volume raycasting may depend on newer
VTK updates.
Would you recommend upgrading to a newer VTK version (e.g., 9.4+) for better
support, or should I proceed with the current implementation as a partial solution?
Thanks for your guidance.
Best regards,
Prateek Rai
