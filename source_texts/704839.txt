Implement bicubic texture resampling via the Sigg & Hadwiger fast fold (4 hardware bilinear samples), exposing a Mitchell-Netravali B/C API mirroring Skia's SkCubicResampler.
SamplingOptions: add CubicResampler{B,C}; B==0 && C==0 disables it
GPU: bicubic WGSLTextureFragment variant with an independent pipeline key; cubic_weight via standard if/else-if; sampler forced linear; precompiled variant
SW: cubic falls back to bilinear
IO: serialize B/C (fills the slot reserved in the skia format)
example/golden: runnable bicubic example, image golden tests
