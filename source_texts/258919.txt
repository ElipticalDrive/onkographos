Hi @duycd2212 - nice job getting that far! I have been doing the same pre-processing (i.e. converting .obj files to SDFs via mesh_to_sdf and clipping the values to be within [-0.1, 0.1]). Perhaps you could also try this further step for pre-processing described in the paper Neural Wavelet-domain Diffusion for 3D Shape Generation (Hui et. Al, 2022, https://arxiv.org/pdf/2209.08725):
In the first step, we scale each shape to fit $[−0.45, +0.45]^3$ and sample an SDF of resolution $256^3$ to implicitly represent the shape. Importantly, we truncate the distance values in the SDF to $[−0.1, +0.1]$, so regions not close to object surface are clipped to a constant.
I believe you can scale each shape to fit in $[−0.45, +0.45]^3$ by using scale_ratio = 0.9 below:
```
from mesh_to_sdf import mesh_to_voxels

resolution = 256 
voxels = mesh_to_voxels(mesh, resolution, scale_ratio = 0.9)
```
Note that the author, Ka-Hei Hui, in that paper I linked is also the first-author in the 'Make-a-Shape' paper which designed the novel wavelet-tree representation, so I think the above pre-processing steps are a good bet!

Thank you, @kurtenkera. Your information is extremely helpful to me. After reviewing the GitHub repository on Neural Wavelet-domain Diffusion for 3D Shape Generation, here is my current preprocessing pipeline:
.obj file -> Flip -> Convert to manifold watertight object -> TSDF (scale_ratio=0.9 + 0.1 clipping) -> Wavelet
The result seems to match the paper, but it still does not work well with complex objects.
Regarding your question about high_indices and high_values: Yes, I use reverse engineering to derive highs_values from highs and highs_indices. I obtained the highs_indices from the extract_full_indices() function (They filtered low and highs as outlined in the paper), followed by some postprocessing.
I implemented the code myself and am happy to share it with you. Some of the code is hard-coded based on the configs.
```
def batch_extract_highs_values(
output_stage=2,
max_depth=3,
shape_list = [[256, 256, 256], [136, 136, 136], [76, 76, 76], [46, 46, 46]],
device = 'cuda',
batch_size = 1,
highs_indices=None,
highs_recon=None,
):
cnt = 0
highs_values_list = []
for idx in range(max_depth):
current_stage = (max_depth - 1) - idx # 2 1 0

    padding_size = (
        shape_list[-1][0] * (2**current_stage) - shape_list[idx + 1][0]
    ) // 2 # 8  0

    if current_stage < output_stage:
        assert highs_indices.size(0) == batch_size

        indices_len = 7 * ((2**current_stage) ** 3) #  56  7
        high_indices_idx = highs_indices[:, :, cnt : cnt + indices_len] #[1,:,:,0:56] [1,:,:,56:63]
        high_indices_idx = high_indices_idx.reshape((-1, 5)).long() 

        high_new = highs_recon[idx]
        high_new = torch.nn.functional.pad(high_new, (padding_size, padding_size, padding_size, padding_size, padding_size, padding_size))

        high_values_idx = high_new[
            high_indices_idx[:, 0],
            0,
            high_indices_idx[:, 1],
            high_indices_idx[:, 2],
            high_indices_idx[:, 3],
            high_indices_idx[:, 4],
        ]
        high_values_idx = high_values_idx.view(batch_size, -1, indices_len)
        highs_values_list.append(high_values_idx)
        cnt += indices_len
highs_values = torch.cat(highs_values_list, dim=-1)
return highs_values
```
