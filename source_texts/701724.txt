Summary
When an SVG element or ancestor <g> applies a non-uniform 2D affine transformation (such as transform="scale(sx, sy)" where sx != sy, or a transformation containing shear/skew), oksvg renders strokes with uniform scalar thickness rather than transforming the stroke pen into the transformed coordinate space.
Minimal Standard SVG Reproduction
```
<svg xmlns="http://www.w3.org/2000/svg" width="128" height="128" viewBox="0 0 128 128">
  <g transform="scale(0.5, 2.0)">
    <rect x="32" y="8" width="64" height="48" style="fill:#3b82f6;stroke:#1e3a8a;stroke-width:12;stroke-linejoin:round;" />
  </g>
</svg>
```
Expected vs. Actual Behavior
Expected (SVG Standard, browsers, Inkscape, resvg, Cairo):
Horizontal stroke lines should be scaled by 0.5 * 12px = 6px.
Vertical stroke lines should be scaled by 2.0 * 12px = 24px.
The stroke outline should form an elliptical pen shape under non-uniform scaling.
Actual in oksvg:
Both horizontal and vertical stroke borders render at a uniform 12px thickness.
Root Cause
In SvgPath.DrawTransformed(), path coordinates are multiplied by the transformation matrix mAdder.M before being fed to rasterx.Dasher.
rasterx.Dasher only accepts a scalar LineWidth and calculates normal offsets in the already-transformed coordinate space using a circular pen.
Because the vertices are already transformed, Dasher cannot distinguish between horizontal and vertical axes, causing strokes to ignore the directional scaling of the CTM.
Working Solution / Workaround
For any developers encountering this limitation, you can achieve accurate non-uniform stroke scaling by wrapping rasterx.Scanner with a transformation proxy that transforms local stroke edges directly into the rasterizer edge table:
```
type transformScanner struct {
    rasterx.Scanner
    matrix rasterx.Matrix2D
}

func (ts *transformScanner) Start(a fixed.Point26_6) {
    ts.Scanner.Start(ts.matrix.TFixed(a))
}

func (ts *transformScanner) Line(b fixed.Point26_6) {
    ts.Scanner.Line(ts.matrix.TFixed(b))
}
```
When rendering an anisotropic stroke:
Render the fill first using svgp.DrawTransformed(r, opacity, t).
Stroke in local un-transformed space through a localDasher := rasterx.NewDasher(w, h, &transformScanner{Scanner: r.Scanner, matrix: totalMatrix}).
Feed the untransformed path vertices (svgp.Path.AddTo(localDasher)) with the local svgp.LineWidth.
The dasher computes the stroke outline in local coordinates, and transformScanner warps the resulting line segments through totalMatrix.TFixed(pt) as they are written into the rasterizer's scanline bucket table, rendering the exact elliptical stroke without winding defects.
