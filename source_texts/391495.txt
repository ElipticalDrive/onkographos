Scope
Add apps/rsovte-omega-xp as an isolated, dependency-free sparse virtual 3D simulator.
Implement deterministic 20-bit x/y/z coordinate generation and a versioned reversible 64-bit-per-point .rs3d packet (24-byte header, FNV checksum, strict validation).
Implement source-cell-preserving anisotropic recurrent contraction; bounded spectral-radius tuner; explicit 1,000-pass emulation, active-point pruning, residual and digest evidence.
Add interactive rotatable 3D point-cloud viewer, PNG 960p/4K/8K output, .rs3d export/import, audit JSON, Node CLI, and focused regression tests.
Add path-scoped GitHub Actions job that executes tests, replays sample packet and archives audit results.
Link from repository README without modifying existing Jarvis-X runtime modules.
Mathematical and security boundaries
G=1,000,000, b=1024, 977 folded cells/axis including the terminal partial cell. Physical allocation O(n), not 10^18 voxels.
Only the retained integer-coordinate packet is reversible. The recurrent contraction and PNG are lossy representations.
FNV-1a is not cryptographic authentication.
No autonomous learning, bank/device integrations, new hardware claims or production speed claims.
Verification
The original standalone reference runner was executed locally with 20,000 particles, seed 42, 1,000 steps, and returned digest 3DC62705, 239,736 point updates and 5,576 searched candidates.
New on-repository Node tests and CLI replay are specified by .github/workflows/rsovte-omega-xp.yml. Await repository CI before promoting or merging.
Review focus
Confirm implementation codec compatibility with the reference packet, numerical stability and deterministic digest.
Confirm browser rendering safety/resource limits and claims, then review CI artifact evidence.
Draft: requires verification. Existing main remains unchanged.
