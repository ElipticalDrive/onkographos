Add two optional 3DGS viewport modes: basic stochastic accumulation and SteadySplats spatial and temporal resampling. Alpha blending remains the default. The training loss is in #3726; the two PRs can be reviewed and merged on their own.
The renderer follows SteadySplats, Algorithms 1-3 and section 4.3. It samples fragment visibility, keeps the nearest surviving radial depth, reuses four neighbors with a distinct K=4 occluder FIFO, and reprojects color history with soft rejection. It skips primitive depth sorting and retains the existing tile grouping operations.
SteadySplats uses per-primitive spatiotemporal blue noise by default. Basic mode uses white noise as a reference. The 128 x 128 x 64 volume comes from the repository's reproducible offline generator. No third-party texture or SDK code is bundled.
Each sample is shown at once. Refinement stops at 16 frames by default; the control permits up to 1024. The request, settings, and IPC proxy share one default. Camera and overlay redraws preserve history, including combined pivot-animation requests. Scene edits, mode changes, and resize reset history. Perspective background samples reproject as directions at infinity. Orthographic background samples bypass temporal reprojection.
At rest, a separate running average follows the official web viewer. It averages spatial estimates for eight frames, then raw visibility samples, and blends into the temporal result with weight n/(n+8). This extends the paper's motion filter. Shared-memory neighborhood reads and reuse of unchanged projection/tile data reduce repeated work without changing sample weights or the full Catmull-Rom filter.
The controls use the existing rendering panel, Python properties, MCP tools, saved settings, and all ten locale bundles. Support is limited to 3DGS without LOD. Depth views, exact-depth consumers, editing guides, offscreen previews, and exports retain alpha blending. Live viewport captures preserve stochastic history.
Validation on Windows with CUDA 12.8 and RTX 5090:
Application and focused test builds passed.
17 Vulkan GPU tests passed, covering visibility, background mass, spatial weights, partial workgroups, temporal rejection, stationary averaging, and background reprojection under translation and rotation.
37 viewport/settings/frame-ledger tests passed, including camera/overlay history retention and shared refinement defaults.
118 Python checks passed, including STBN uniformity and spatial/temporal spectra.
Property-view contracts match the upstream ROI-at-end field (Crop the trained model to the training crop box when training ends #3737), including its automatic placement in More Parameters.
C++ formatting, diff checks, locale completeness, and UI string checks passed.
Live bicycle checks covered camera movement, stationary refinement, and idle behavior. Linux runtime validation and broader scene/motion checks remain open.
Basic history uses 32 bytes per pixel. SteadySplats history uses 160 bytes per pixel, including the stationary average, plus four bytes per Gaussian for radial depth keys. The shared STBN volume adds 1 MiB per renderer/device. Native HiGS remained faster during motion in the earlier local measurements; this PR makes no general frame-rate claim.

I read the paper and checked the code against it: Algorithms 1–3, the border rule, the STBN offsets and the viewer's at-rest average all match. Then I pushed fixes onto your branch, merged with current master:
Memory: history, the STBN volume and the index copy are now freed when the mode is switched off. Before, ~0.15–0.34 GiB stayed resident until the scene was released.
Python default: the property metadata now reports the shared refinement default (16; it said 32).
STBN volume: generated at build time by the same generator, bit-identical, instead of checking in the 1 MiB binary.
History reads: Catmull-Rom history fetches are clamped at zero, as in the viewer, so the −0.007 undershoot next to an edge no longer feeds back into history. There's a GPU test for it.
Cleanup:
the nine other locales are translated;
the docs page is trimmed to what users need, and notes that meshes and camera frustums keep alpha blending;
the ledger and settings tests are no longer compiled into a second binary;
formatter-only hunks are gone;
the contract-throw test is dropped.
Measured at 1080p on an RTX 4080:
Speed: at 5M Gaussians both modes are about 2× slower than alpha blending, since they skip HiGS and early termination. At 10M, stochastic is level with alpha or faster (19.7 vs 22.1 ms) and SteadySplats is within 10%.
Reuse cache: saves 16–22% per refinement frame, so it stays.
VRAM: SteadySplats adds ~330 MiB at 1080p.
