Summary
The binning pass rescaled every splat's opacity by sqrt(det(cov2d) / det(cov2d + low_pass)). That is the Mip-Splatting opacity compensation. It is correct only for splats trained with antialiasing (Mip-Splatting, gsplat rasterize_mode="antialiased"). Classic 3DGS adds a 0.3 px² low-pass with no compensation, and classic-trained opacities depend on it. The references:
Inria cuda_rasterizer/forward.cu:109-110.
gsplat v1.4.0 rendering.py:41,49,312: eps2d=0.3, default classic, compensation only when rasterize_mode == "antialiased".
aras-p GaussianSplatting.hlsl:87-88.
Applied to classic scans, the rescale makes small splats see-through (#1173).
This PR makes the compensation conditional and sets the low-pass default to the reference value:
tile_binning.glsl project_gaussian_2d(): alpha_rescale = antialiased ? sqrt(det_raw / det) : 1.0. antialiased is the new instance flag GS_INSTANCE_FLAG_ANTIALIASED, bit 4 of InstanceDataGPU.ids[1], mirrored in gaussian_gpu_layout.h and gs_instance_layout.glsl.
New node property GaussianSplatNode3D.rendering/antialiasing_compensation (Auto / Off / On). Auto resolves in this order:
the asset's recorded training mode, from the spz_antialiased import metadata that ResourceImporterSPZ writes from SPZ header flag 0x1;
the new project setting.
New project setting rendering/gaussian_splatting/rasterization/antialiasing_compensation. Bool, default false (classic), which matches gsplat's default. Restart-required, like low_pass_filter. Nodeless instances use it directly: the director's world-submission shim and the resident bootstrap instance.
rendering/gaussian_splatting/rasterization/low_pass_filter default 0.05 → 0.3. The value lives in gs::RASTER_LOW_PASS_FILTER_DEFAULT, which also replaces the 0.35 struct fallbacks in tile_render_types.h, rasterizer_interfaces.h and tile_renderer.cpp. With compensation off this is exactly Inria/gsplat/aras-p classic. With it on, it is exactly gsplat antialiased.
Raw SPZ loads (GaussianSplatAsset::load_from_file: legacy-path migration, reload, drag/drop) now record spz_antialiased from the loader statistics, as ResourceImporterSPZ does, and drop a stale flag for other formats (round 2, Codex P1). When the flag changes they emit changed again, so an Auto node re-registers with the final value (round 3, Codex P2).
Test project: tests/examples/godot/test_project/project.godot pins low_pass_filter 0.05 → 0.3. The 0.05 pin dates from Harden Gaussian renderer streaming and diagnostics pipeline #326, which paired it with the always-on compensation.
Why a node property plus a project default, not a new asset field. The training mode belongs to the data, but today only SPZ import metadata records it, and Auto already reads that. A persisted asset field needs a cache/format bump. Drafts #1200 (GSF v3, GaussianData::antialiased) and #1201 (SPZ v4) add exactly that field. Once #1200/#1201 land, Auto will read the per-asset flag, a one-line change in _resolve_antialiasing_compensation(). PLY records no training mode, so for PLY the node property or the project setting is the only source.
