Ray-Triangle Intersection (Peter Shirley's Ray Tracing in One Weekend)
Hello, I've been working on my implementation of ray-triangle intersection to add in my ray tracer which I've been following from Peter Shirley's book, Ray Tracing in One Weekend (https://raytracing.github.io/books/RayTracingInOneWeekend.html#overview). I've been having a tough time, even seeing a triangle on my screen. Can anyone help in guiding me where I'm going wrong? I would like to explain my approach which uses the technique described by Prof. Cem Yuksel (https://www.youtube.com/watch?v=HV2dKIQcp6k&t=523s).
I would first calculate the 2 edges, p0p1 and p0p2, then I'll get the area of the whole triangle (area_p0p1p2). I would then create two vectors from the ray (ray_p0 and ray_p1) and use them to get the area of the two triangles so that I can further calculate u (alpha) and v (beta) by dividing it by the area of the whole triangle. This should give me the barycentric coordinates but I always end up getting a value of 1 for both u and v. The relevant part is the hit_triangle and ray_color method. Thank you in advance!
#include "color.h"
#include "ray.h"
#include "vec3.h"
#include <iostream>
#include <fstream>
double hit_triangle(const point3& p0, const point3& p1, const point3& p2, const ray& r, double &u, double &v) {
vec3 p0p1 = unit_vector(p1 - p0);
vec3 p0p2 = unit_vector(p2 - p0);
double area_p0p1p2 = unit_vector(cross(p0p1, p0p2)).length() / 2;
vec3 ray_p0 = unit_vector(p0 - (r.direction()));
vec3 ray_p1 = unit_vector(p1 - (r.direction()));
double area_p0p1ray = unit_vector(cross(ray_p0, ray_p1)).length() / 2;
vec3 ray_p2 = unit_vector(p2 - (r.direction()));
double area_p1p2ray = unit_vector(cross(ray_p2, ray_p1)).length() / 2;
u = area_p0p1ray / area_p0p1p2;
v = area_p1p2ray / area_p0p1p2;
if (u < 0) return -1;
if (v < 0) return -1;
return 1;
}
color ray_color(const ray& r) {
double u;
double v;
auto t = hit_triangle(point3(-1.0, -0.1, -1), point3(0.25, 0.25, -1), point3(-0.5, -0.1, -1), r, u, v);
if (t > 0.0) {
// vec3 N = unit_vector(r.at(t));
return color(u, v, 0);
}
vec3 unit_direction = unit_vector(r.direction());
t = 0.5*(unit_direction.y() + 1.0);
return (1.0-t)*color(1.0, 1.0, 1.0) + t*color(0.5, 0.7, 1.0);
}
int main() {
// Image
const auto aspect_ratio = 16.0 / 9.0;
const int image_width = 800;
const int image_height = static_cast<int>(image_width / aspect_ratio);
// const int image_height = 5;
std::cout << "Image width: " << image_width << std::endl;
std::cout << "Image height: " << image_height << std::endl;
// File
std::ofstream file_to_save_image;
file_to_save_image.open("ray_triangle.ppm");
// Camera
auto viewport_height = 2.0;
auto viewport_width = aspect_ratio * viewport_height;
auto focal_length = 1.0;
auto origin = point3(0, 0, 0);
auto horizontal = vec3(viewport_width, 0, 0);
auto vertical = vec3(0, viewport_height, 0);
auto lower_left_corner = origin - horizontal/2 - vertical/2 - vec3(0, 0, focal_length);
std::cout << "viewport width: " << viewport_width << std::endl;
std::cout << "viewport height: " << viewport_height << std::endl;
std::cout << "horizontal: " << horizontal << std::endl;
std::cout << "vertical: " << vertical << std::endl;
std::cout << "lower left corner: " << lower_left_corner << std::endl;
// Render
file_to_save_image << "P3\n" << image_width << " " << image_height << "\n255\n";
for (int j = image_height-1; j >= 0; --j) {
// std::cerr << "\rScanlines remaining: " << j << ' ' << std::flush;
for (int i = 0; i < image_width; ++i) {
auto u = double(i) / (image_width-1);
auto v = double(j) / (image_height-1);
ray r(origin, lower_left_corner + u*horizontal + v*vertical - origin);
color pixel_color = ray_color(r);
write_color(file_to_save_image, pixel_color);
}
}
std::cerr << "\nDone.\n";
}
