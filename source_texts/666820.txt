This PR implements Phase 1 of the volumetric lighting system. It sets up the foundational spatial framework using a cascaded Froxel grid.
Key changes:
New VolumetricLightingManager to manage GPU resources (3D textures, SSBOs, UBOs).
volumetric_grid_init.comp shader for initializing world-space bounding volumes for each voxel.
Logarithmic Z-distribution for optimal depth resolution near the camera.
Integration into the main render loop in src/graphics.cpp.
Standardized constants and bindings for the new system.
Fixes for std140 layout alignment issues in shaders.
Support for rotation-aware grid updates and temporal cascade update frequencies.
