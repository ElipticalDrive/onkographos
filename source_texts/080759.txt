💡 What: Bypassed the self.mesh.distance_to_local_point() query for exterior voxels when a narrow_band is not used in solid voxelization, assigning f32::INFINITY instead.
🎯 Why: To eliminate wasted computation. BVH distance queries are expensive. When solid voxelizing without a narrow band, we only care about retaining voxels that are inside the mesh. Calculating the exact distance for exterior voxels that are just going to be discarded was a major bottleneck.
📊 Impact: Significantly reduces voxelization time for solid block filling (when narrow_band is None), effectively reducing total BVH distance queries to only the internal volume of the mesh.
🔬 Measurement: Checked via cargo bench ensuring performance improves or stays roughly equivalent for tiny cubes (small N), with expected massive asymptotic speedups for large scale solid voxelizations. Verified correctness via cargo test, specifically test_sdf_invariants to ensure the core voxelization logic remains intact.

When solid voxelization is performed without a narrow band, we only retain voxels that are strictly inside the mesh (`keep = is_inside`). However, the previous implementation unconditionally called `distance_to_local_point` (an expensive BVH query) for every point, immediately discarding the result if the point was outside. This commit optimizes that path by assigning `f32::INFINITY` to exterior points, completely skipping the BVH query and dramatically speeding up solid voxelization.

Preserve zero-distance surface voxels before skipping
When solid voxelizing without a narrow band, voxel centers that lie exactly on the mesh surface but are classified as outside by the parity test are now discarded. For example, if the mesh's max-X face falls on a voxel center (e.g. object width/resolution has a .5 fractional cell), partition_point(|&hx| hx <= x) makes is_inside false at that face; previously distance_to_local_point returned 0.0, so sdf <= 0.0 kept the boundary voxel, but this branch assigns INFINITY and drops it. This can create a missing boundary layer in solid output for aligned meshes.
