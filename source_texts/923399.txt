Hi @i-tanvir. This is looking great so far.
My main technical comment would be we need to check if it's possible to include Markdown formatted text with Sphinx Gallery (which is how we render the Python tutorial examples to the HTML documentation) rather than reStructuredText as it looks like you are currently using a mix of the two, in particular (LaTeX) mathematical notation is usually included with the :math: directive in reStructuredText rather than $ delimiters.
If it's easier for you to write in Markdown, one option might be to just draft the tutorial text in Markdown now and then we can look at using a tool like pandoc to convert to the text to reStructuredText format.
The content so far looks great, I've added some suggested additions / clarifications, mainly to add some additional context for readers less familiar with the mathematics.

Hi @i-tanvir this is looking in great shape - from my perspective I think this is almost ready to merge in to main s2fft repository other than needing to deal with the Markdown to reStructuredText comment conversion so it get's rendered by Sphinx Gallery correctly.
There are a couple of options of how to proceed here
We merge this in to your fork's main branch (the current PR target) with the aim of merging the other tutorial PRs you have open in to main on your fork as well then creating one PR from your fork main to the upstream s2fft repository with all the tutorials.
We retarget this pull request to be to merge in to the upstream main and also do this for the other PRs.
The latter approach has the advantage that the comment thread in this PR and others will be more easily accessible from main repository (as it should then appear in list of PRs on that repository) and I think should still be possible.
