Summary
BVH8: Use Moeller-Trumbore for Triangle4v single-ray intersection
For static Triangle4v leaves in the BVH8 single-ray path (BVH8Triangle4vIntersector1Pluecker), this swaps the Plücker intersector (with the robust flag on) for the Möller-Trumbore intersector (robust flag off). The Möller test does fewer operations per triangle. Other intersectors (Triangle4i and the other BVH widths) are unchanged.
Plücker is watertight: a ray that crosses a shared edge of two triangles always hits one of them. Möller-Trumbore is not guaranteed to be, so in rare cases a ray can pass through a shared edge. The hit distance and barycentric values also differ slightly from Plücker's, so rendered images change in a few pixels.
Files: kernels/bvh/bvh_intersector1_bvh8.cpp
