Contributor
Builds a comprehensive Chinese-language learning resource for 3D Gaussian Splatting, covering theory through working implementation.
Documentation (35K+ chars, 5 chapters)
Theory: Gaussian mathematics (1D/2D/3D), covariance matrices, quaternion parameterization
Rasterization: Projection with Jacobian, alpha compositing, depth ordering
Implementation: Data structures, optimization (bounding box, early termination)
References: Curated papers (original 3DGS, Mip-Splatting, 4D-GS), implementations, datasets
Code (~2K lines)
Core rasterizer (gaussian_rasterizer.py):
```
# 3D→2D projection with proper covariance transformation
J = np.array([
    [fx / z, 0, -fx * x / (z**2)],
    [0, fy / z, -fy * y / (z**2)]
])
cov_2d = J @ cov_3d @ J.T

# Alpha compositing with transmittance tracking
for gaussian in sorted_by_depth:
    alpha = opacity * gaussian_value
    color += alpha * transmittance * gaussian_color
    transmittance *= (1 - alpha)
```
Progressive examples:
gaussian_2d.py: Visualize covariance effects, rotations, mixtures
gaussian_3d.py: Ellipsoid rendering, projection demonstrations
simple_rasterizer.py: Basic point splatting, depth testing
simple_scene.py: End-to-end multi-Gaussian rendering
Implementation notes
Quaternion-based rotation avoids gimbal lock, maintains positive definiteness
Bounding box culling reduces per-pixel overhead ~10x
Numerical stability via covariance regularization (+= 1e-6 * I)
Module structure supports import as library
Repository provides clear learning path: 2D fundamentals → 3D projection → complete scenes.
