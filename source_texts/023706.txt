Reference only. Keep as draft; do not merge.
The implementation continues in three stacked drafts: #3789 (shared voxel engine and CLI), #3791 (box authoring, Walk UI and .licht integration), and #3793 (optional surface generation and export UI). Merge in that order. This reference preserves the original complete implementation and its history.
Scenes can generate native voxel collision nodes and test them with a collision-aware Walk camera, without running an external splat-transform process.
Add sparse Gaussian voxelization with CUDA acceleration, Auto resolution, surface cleanup and optional connected filtering, filling and carving. Asynchronous generation reports numeric progress and current stages, supports cancellation, and preserves existing results on failure.
Render translucent first-hit voxel faces and edges through sparse Vulkan traversal. Preview uses occupancy directly; optional triangle surfaces are separate scene nodes.
Preserve collision data through .licht save/reload, deferred hydration, transforms, duplication and delete undo. Export SuperSplat voxel pairs or GLB surfaces through File and context menus.
Add capsule-based Walk movement with wall sliding, minimum step-up, ground following, ceiling clearance and separately smoothed camera motion. Loaded hidden colliders also enable Walk. Live preview and Walk scrubs sit under Rendering > Collision.
Validation:
Full application build and all four native suites pass: 63 CPU tests, 19 scene/archive/export/controller tests, eight BVH/CUDA tests and nine Vulkan correctness tests. Four controller cases also pass ten shuffled repeats.
322 focused Python checks pass. All 63 CPU tests pass ASan/UBSan; three affected lookup/worker tests pass five shuffled TSan repetitions with matching, fully instrumented oneTBB and no suppressions.
Frozen Garden validation uses 20M Gaussians trained for 30k iterations at images_4, SH 0. Earlier tuning reduced generation from 8.592 to 4.103 seconds; methodology and limits are documented in docs/docs/features/collision.md and tests/benchmarks/collision/README.md.
Matched checks before/after the latest simplifications give generation medians 4.125/4.093 seconds and peak RSS about 3.75 GiB. Three 1080p views remain 0.675–0.858 ms per warmed overlay pass; capsule queries remain about 0.539 µs. Occupancy archives and all three rendered images are byte-identical. These are component timings, not viewport FPS.
A separate CPU fixture improves eight-worker voxelization 4.741→3.181 ms and weak-support bounds preparation 1.271→0.569 ms.
Scope cleanup removed obsolete helpers, unused controls/styles and redundant state. The latest pass removes the test-only boundary-face API, shares sparse point lookup, replaces manual worker pools with bounded TBB, and replaces progress-string parsing with numeric progress. Production shrank another 152 lines; added tests/build wiring total 159 lines, so that pass adds seven lines overall. All requested features remain in this single PR.
Known limits: nine non-English locales still use English Collision placeholders. CPU preparation/postprocessing/assembly remain; the pipeline is not wholly GPU-resident. Explicit memory/work budgets apply. Overlapping independent previews are draw-order dependent; individual voxel editing is unavailable.
The branch includes fetched master f7113b1ac. Commits use subjects only, without attribution trailers.
