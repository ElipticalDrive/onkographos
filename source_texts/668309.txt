Descripción
Optimizar colisiones usando broadphase en GPU: reducir O(n²) pares a O(n) mediante estructura espacial. Dos fases de implementación.
Phase 1: Spatial Hashing (GPU compute)
Tres compute dispatches:
Count: cada objeto calcula su celda hash, atomicAdd al bin counter
Prefix Sum: parallel prefix sum para offsets en el output array
Scatter: cada objeto se escribe en su posición del array ordenado
Resultado: array ordenado por celda → iterar dentro de cada celda para pares.
Tareas Phase 1
AABB de cada entidad con CollisionShape
Compute shader: hash de AABB center → cell ID
Compute shader: atomic count per cell
Compute shader: parallel prefix sum
Compute shader: scatter objects into sorted array
Pair extraction dentro de cada celda
Integrar con BufferPool para buffers intermedios
Phase 2: LBVH (GPU BVH)
Cuando spatial hashing no escala (objetos de tamaños muy variados, queries jerárquicas), migrar a LBVH. Ver #115 para la implementación compartida del BVH.
Tareas Phase 2
Usar BVH de feat(core): Spatial Acceleration Structure — BVH/Octree compartido #115 para broadphase AABB overlap queries
Refit del BVH para objetos que se mueven poco (sin rebuild completo)
Benchmark spatial hash vs LBVH en escenas reales
Ejemplo de Código (Phase 1 - WGSL)
```
// Pass 1: Count
@compute @workgroup_size(64)
fn count_bins(@builtin(global_invocation_id) id: vec3<u32>) {
    let idx = id.x;
    if idx >= params.entity_count { return; }
    let aabb = aabbs[idx];
    let cell = hash_position(aabb_center(aabb), params.cell_size);
    atomicAdd(&bin_counts[cell], 1u);
}

// Pass 2: Prefix sum (parallel Blelloch scan)
// Pass 3: Scatter
@compute @workgroup_size(64)
fn scatter(@builtin(global_invocation_id) id: vec3<u32>) {
    let idx = id.x;
    if idx >= params.entity_count { return; }
    let aabb = aabbs[idx];
    let cell = hash_position(aabb_center(aabb), params.cell_size);
    let offset = atomicAdd(&bin_offsets[cell], 1u);
    sorted_entities[prefix_sums[cell] + offset] = idx;
}
```
Performance Esperada
~0.1ms para 10k objetos en GPU moderna (spatial hash)
~0.5ms para 100k objetos con LBVH
