Closes #9980
Background
This PR adds rotation support for OrthographicView, a feature that has been requested in #3290. Users working with 2D visualizations (CAD viewers, floor plans, game maps) often need to rotate the view, but OrthographicView previously lacked this capability.
Change List
Add rotationOrbit property to OrthographicViewState for Z-axis rotation (in degrees)
Apply rotation to view matrix in OrthographicViewport using Matrix4.rotateZ()
Enable Ctrl+drag (Cmd+drag on Mac) rotation in OrthographicController
Add programmatic rotation methods to OrthographicController:
rotate(deltaAngle) - rotate by delta
rotateLeft(speed) / rotateRight(speed) - rotate by fixed amount
setRotation(angle) - set absolute rotation
getRotation() - get current rotation
Add unit tests for OrthographicViewport rotation
Add example demonstrating the rotation feature

Yes, it's used in _handleRotate() at line 139.
During drag rotation, _handleRotate is called on every mouse move (~60fps). If we used this.transition (300ms animation), each rotation update would trigger a new animation, causing input lag and choppy visuals.
NO_TRANSITION_PROPS (transitionDuration: 0) applies rotation immediately without animation, ensuring smooth real-time feedback during drag.
