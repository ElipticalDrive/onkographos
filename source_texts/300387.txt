# RayTracing

 RayTracing is a CPU Ray Tracing Renderer written in C++ based on [Ray Tracing in One Weekend](https://raytracing.github.io).

## Build Instructions

To compile the program open a terminal in the projects root folder and run the command:

```console
cmake --build build --config release
```

To run the program use the command:

```console
build\Release\RayTracing.exe
```

The render will be saved at:

```console
renders\image.png
```

## Features

* Materials
* * Diffuse
* * Reflective
* * Dielectric
* * Emissive
* * Volumetric
* Primitives
* * Sphere
* * Quad
* * Triangle
* * Ellipse
* * Ring
* * Infinite Plane
* Textures
* Skybox
* BVH
* Multithreading
