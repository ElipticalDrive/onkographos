Summary
Godot has no global wind; foliage sway is user vertex() code. Driving it through skinned Nanite keeps bounds and velocity exact and avoids programmable-raster cost for every leaf.
Plan reference
§21.4 Nanite parity · contract N10 · GN-7 · N6

Implementation steps
Resource. VirtualGeometryWind: a trunk plus ≤8 branch bones, generated at import from bind-pose geometry (height and distance from the trunk axis), or taken from a glTF skeleton if one exists. Weights are written with Skinned Nanite offline: skinned-surface eligibility, per-cluster bone lists and bone-space bounds in the DAG builder, .ngm skinning chunk #159's skinning chunk. Import option virtual_geometry/wind (off).
Parameters. World3D.wind_direction, wind_strength and wind_gust_frequency, forwarded through a new RenderingServer.scenario_set_wind().
Procedural bones. skinning_inc.glsl computes each bone transform in the shader from (wind parameters, TIME, instance seed, bone rest data). The previous frame uses the previous TIME. No palette arena entry is needed.
Bounds. Cull inflates by the resource's declared maximum sway.
VSM. Through the SKINNED entry, as procedural skinning on the dynamic layer.
Settings. rendering/nextgeo/experimental/foliage_wind = false.
Acceptance criteria
Build (PR basics, §22):
0 bytes of per-instance palette memory for wind instances.
PR basics: builds on the touched CI targets (Windows and Linux Vulkan, macOS Metal, Windows D3D12); CI, unit tests and doctests pass, with new tests added; 0 validation errors (Vulkan validation layers, Metal API validation, D3D12 debug layer) on the phase smoke scene (§22); renders it without crashing on the RTX 4080 SUPER and on the M5 Max.
Measured in PQ:
GN-7: wind velocity mean error ≤0.1 px against a per-instance CPU reference; 0 culled-but-visible clusters over 10,000 frames.
The wind share of N6 is recorded (GN-7).
Validation
At PR time (PR basics): CI; Vulkan and D3D12 on the RTX 4080 SUPER and Metal on the M5 Max run the phase smoke scene (§22) and the palette-memory check.
In PQ (§22), with GN (#166): the GN-7 and N6 lines on Vulkan and D3D12 (RTX 4080 SUPER and RTX 5090), Metal M5 Max. N6, the Foliage Field NextGeo total, carries the UE bar (≤1.20× UE 5.8 against the Foliage Field port from #234, §23); the wind share inside it is report-only, and on the M5 Max N6 is recorded only. There is no M2 run.
Parallelization
Lane nextgeo-runtime. Branch feature/pn-foliage-wind. Open a PR.
Out of scope
A general physics wind system.
Wind on non-virtual meshes.
