Abstract. We present GHARP (Real-time Gaussian Head Animation
from Large-scale Reconstruction Prior), a method that animates 3D human heads in real time from a few input images of a subject and a driving
expression signal. We decouple the problem into an identity stage that
builds a representation of the subject’s geometry and appearance offline,
and an animation stage that predicts expression-dependent residuals on
top of it at runtime. This separation offers a favorable trade-off with
respect to fidelity, quality and runtime: the identity stage can be expensive while the animation stage runs a lightweight network, optimized for
mobile devices. Our method performs animation in a semantically structured latent space of a pretrained reconstruction model, where expression
changes remain spatially contained, making residual prediction efficient.
This reconstruction prior provides a consistent spatial layout, allowing
fusion of multiple input views into a compact, fixed-size canonical Gaussian representation. While this two-stage design improves the runtimequality trade-off, it still inherits a problem common to all expressiondriven avatar methods: expression codes describe only the face and thus
omit body pose and clothing position, making these regions underspecified in the input. The animation network faces an ill-posed mapping and
resorts to averaging over conflicting body appearances, producing blur
and temporal flicker. We address this with a body alignment network
that learns to align the person’s body in the target image with the input
reference images, removing the ambiguity from the training signal. Our
method achieves state-of-the-art quality on the Ava-256 benchmark while
running up to 13× faster on an A100 GPU with 8× fewer Gaussians.

communication. Recent advances in 3D Gaussian Splatting [26] have made realtime, high-quality rendering of 3D scenes practical, spurring a growing body of
work on Gaussian-based head avatars.
Per-subject optimization methods [1, 33, 52] achieve impressive quality by
fitting a Gaussian Splatting model to dense multi-view captures, but require
expensive light-stage hardware and hours of per-subject optimization, making
them impractical for scalable deployment. Feed-forward methods remove this
requirement: a neural network takes a few input images of a subject paired
with an expression code and directly predicts an animated avatar. Avat3r [30]
and FastGHA [22] demonstrated high-quality feed-forward reconstruction and
animation, yet both predict pixel-aligned Gaussians for each input view, causing
the total Gaussian count and inference cost to grow linearly with the number of
input images, precluding deployment on resource-constrained devices.
These limitations share a common root: jointly learning reconstruction and
animation couples the cost of animation to the reconstruction complexity. In this
work, we show that performing animation in a structured latent space of a pretrained reconstruction model decouples these two processes while also providing
a strong prior for animation. We use HeadsUp [46] as a reconstruction prior to
encode input images into 2D latents. A convolutional decoder then maps these
latents into Gaussian UV maps, i.e. UV-parameterized Gaussians anchored to a
neutral head template. The convolutional nature of the decoder ensures that a
2D position in the latent maps to a fixed facial region. Therefore, latents from
input images with different expressions are semantically aligned. This structure
allows us to model a change in expression as a localized delta rather than a global
transformation. However, running the decoder per frame would be too costly. Instead, we build a canonical Gaussian UV map once, then predict a residual on
top at animation time. Since the number of Gaussians remains constant, this
decouples the animation cost from both the reconstruction model’s complexity
and the number of input views.
This residual formulation benefits from a canonical representation that is as
close to the target as possible, thereby reducing the variance of the residuals predicted at runtime. We construct this canonical representation by fusing multiple

input views in the latent space into a compact representation that captures the
subject’s face geometry and appearance across viewpoints and expressions. This
representation is then decoded into the canonical Gaussian UV map. To further
model person-specific facial motion across expressions, we introduce a deformation latent that encodes subject-specific facial dynamics. Both the canonical
representation and the deformation latent are pre-computed once per subject.
Consequently, runtime inference requires only a lightweight convolutional network that takes as input the canonical Gaussian UV map, the deformation latents
and a target expression code to predict the residual.
Body pose and clothing may also vary across input images independently
of facial expression. Since the expression code does not explain these variations,
the network averages over conflicting body appearances, which manifests as temporal jittering during animation. To resolve this ambiguity, we introduce a body
alignment network (BAN) that composites supervision targets in the shared UValigned latent space, taking the facial expression from the target and the body
appearance from a reference image. To summarize, our main contributions are:
1. A real-time, animation-focused head avatar method, based on a decoupled identity and animation design. With the identity network running
only once per subject, the approach achieves a faster runtime by using a
lightweight animation network that animates the avatar at a constant cost,
independent of the number of input views.
2. A body alignment network (BAN) that resolves the ill-posed animation
of body regions not described by the expression signal, improving temporal
stability at animation time.
3. We show that the UV-parameterized latent space of a pretrained face reconstruction model is a structured prior for avatar animation: its spatial
alignment across different input images enables identity construction, animation, and body alignment to all operate within a single shared representation.
Our experiments show state-of-the-art results at a fraction of the cost: on an
A100, we are up to 13× faster than FastGHA [22] and 86× faster than Avat3r [30];
on an iPhone 17 Pro, we are 31× faster than FastGHA with 8× fewer Gaussians,
achieving 522 FPS on an A100 and 690 FPS on an iPhone 17 Pro.

rendering speeds far below real-time. Alternative representations including deformable point clouds [82], implicit surfaces [76, 81], and mesh-based neural rendering [17] improved efficiency or geometric coverage but still fall short of real-

Feed-forward Avatar Creation.
Animation in 2D. A parallel line of work performs head reenactment directly
in 2D or with shallow 3D proxies [8, 9, 11, 18, 27, 39, 42, 54, 63, 75], achieving
fast and generalizable animation, but without true viewpoint control or explicit
3D geometry. In contrast, our method produces explicit 3D geometry with true
viewpoint control — a combination lacking in 2D reenactment approaches.
Animation in 3D. Recent feed-forward methods have shown that cross-subject
generalization and sparse-input reconstruction are achievable from multiple images [6, 22, 30, 68, 80] or even a single image [5, 21, 25, 38]. However, most approaches either struggle with real-time animation or rely on per-pixel Gaussian
representations [22, 30] that compromise view and temporal consistency, with
rendering cost and memory that grow linearly with the number of input views.
In contrast, we introduce a fixed-size identity representation that decouples animation cost from the input count and a body alignment network that maintains
consistent geometry across views and time.
Accelerated Avatars. Several methods specifically target real-time or ondevice inference, mainly focused on subject-specific settings [12, 23, 36, 44, 53,
64, 69, 73]. While these works demonstrate that speed and quality can coexist,

3
Method
An overview of our method can be seen in Fig. 2. We use a learned prior based
on an encoder HE and decoder HD architecture. The encoder HE compresses
calibrated input views into a compact UV-aligned 2D latent representation Z ∈
R32×32×512 . The decoder HD maps latents to UV-parameterized 3D Gaussians
anchored to a neutral head mesh template. We refer to it as a Gaussian UV
map with spatial dimensions HU V and WU V . Each Gaussian is characterized
by a position µ ∈ R3 , a scale s ∈ R3+ , a unit quaternion rotation q ∈ R4 , an
opacity α ∈ [0, 1], and spherical harmonic color coefficients k ∈ R12 (SH degree
1), for a total of dG = 3+3+4+1+12 attributes per Gaussian. Our method takes
N input images of a subject {I1 , . . . , IN | Ii ∈ RH×W ×3 } and an expression
code w and produces an animated avatar represented as a Gaussian UV map
U ∈ RHU V ×WU V ×dG .
We formulate animation as residual learning in the canonical Gaussian space.
A change of expression between two frames corresponds to a localized delta on
top of the Gaussian attributes. This residual deforms non-rigid regions of the
face, such as the cheeks, mouth, and eyelids, while keeping attributes like skin
texture and pores almost intact. Let C ∈ RHU V ×WU V ×dG denote a canonical
Gaussian UV map, a set of splats that encode the subject’s static appearance
and geometry. We learn a lightweight animation network E such that:
U = E(w, D) + C,
(1)
where w is an expression code and D denotes the deformation latent.
While C is a learned canonical representation that combines identity information from the input images (Sec.3.1), D encodes face deformations across
expressions. This decomposition minimizes the workload of E by offloading as
much information as possible into C. We detail the architecture of E in Sec.3.2.

3.2
Animation Network
The animation network E in Eq. (1) takes as input w and D, and outputs a
residual for each Gaussian parameter in the canonical UV map. The expression
code w ∈ RM , where M is the dimension of the expression code, is processed by
an MLP, then tiled and concatenated with D along the channel dimension. E
is implemented as a ResNet [20] decoder which processes this input to produce
a residual delta map E(w, D) ∈ RHU V ×WU V ×dG . This architecture is a natural
choice for this decoder as it exploits the spatial structure of the UV layout while
executing efficiently on GPU for real-time animation. We refer to Supp. Mat. A.1
for architecture details.

3.5
Body Alignment Network (BAN)
Body pose and clothing vary between input reference images independently of
facial expression. Since the expression code cannot explain these variations, supervising against raw captures forces the network to average over conflicting
body appearances, which manifests as temporal jitter at inference (Fig. 5) and a
loss of details. The body alignment network (BAN) addresses this by compositing face and body information in the latent space to produce aligned supervision
targets.
As shown in Fig. 4, BAN takes as input the reference latent HE (Iref ), where
Iref is one of the N input images, and a target latent HE (IGT ) and predicts spatial blending weights m and a correction term δa . The aligned latent is computed
as:
Aℓ = σ(m) ⊙ HE (IGT ) + (1 − σ(m)) ⊙ HE (Iref ) + δ a ,
(7)
where δ a allows the output to deviate from a pure interpolation of the two
inputs. The aligned latent is decoded with the frozen decoder to produce an
aligned Gaussian UV map A = HD (Aℓ ). Compositing in the latent space keeps
A on the decoder’s data manifold, so any blended latent decodes to a plausible
Gaussian head. Image-space compositing would instead introduce seams and

Experiments
4.1
Datasets and Expression Codes
Internal10K Dataset. We use an internal multi-view dataset of over 10K subjects captured with a head-focused rig comprising 16 calibrated RGB cameras
at a resolution of 1000 × 750 pixels. Each recording session includes a range of
facial expressions and speech sequences. For training, we sample 100 expressiondiverse frames per subject across all 10K identities. Evaluation is performed on
100 frames from a held-out set of 50 subjects.
Ava-256 Dataset. We additionally finetune and evaluate on Ava-256 [43], a
public multi-view dataset containing 256 subjects captured with 80 RGB cameras at 1024 × 667 resolution. We use the 4TB variant of the dataset. Following
the protocol of Avat3r [30], we train on 244 subjects with 1000 frames each and
evaluate on the remaining 12 subjects using approximately 1000 sampled frames.
Expression Codes. We generate the expression codes using the ARKit [2] face
tracker, which fits a set of 51 blendshape bases to each frame, yielding per-frame
weights w ∈ R51 . Each dimension corresponds to a semantically meaningful
facial action (e.g. left eye blink or jaw open).
4.2
Experimental Setup
Training Setup. We follow a two-stage training strategy. First, we freeze the
HE and HD (see Fig. 2) pretrained on Internal10K with HU V = WU V = 256 and
train the remaining modules, FC , FD and E, with N input frames and one target
frame sampled from random viewpoints and expressions. In the second stage, we
first finetune HE and HD and then the remaining modules on Ava-256. In this
stage, we use furthest distance viewpoint sampling for input frame selection in
both training and validation, following [22, 30], and a random target frame. We
use HeadsUp [46] as a prior HE and HD . The input frames are downsampled to
500 × 375 for Internal10K and to 512 × 334 for Ava-256. More training details in
the Supp. Mat. A.2.

Canonical Representation. We ablate the learned canonical representation

metrics, as E must learn larger residuals to animate an arbitrary G1 and correct

expression code to the animation network in Eq. (1). As shown in Tab. 4 and
Fig. 8(e), this leads to loss of subject-specific details and worse identity preservation across expressions, as the expression codes are subject-agnostic.

Conclusion
We presented GHARP, a method for real-time animation of 3D Gaussian head
avatars on top of a learned canonical Gaussian representation. This formulation
allows us to capture the subject appearance and geometry in a fixed-size set of
Gaussians, thus decoupling animation cost from the number of input views. Additionally, a body alignment network (BAN) resolves appearance inconsistencies
in the body region during training, improving temporal stability at animation
time. Experiments demonstrate state-of-the-art quality while animating up to
8x fewer Gaussians with an order of magnitude lower inference cost. Limitations
of the proposed method include the dependence on the calibrated camera poses;
therefore, inaccurate estimates could propagate through the encoder. Future extensions could include robustness to temporal variations or noise in the input
signal and material factorization for portrait relighting.

A.4
Baselines
For our baseline comparison, we evaluate our method against Avat3r [30] and
FastGHA [22], representing state-of-the-art methods in feed-forward 3D head
animation. For both baselines, we first pretrain on Internal10K and finetune on
Ava-256, following the same two-stage protocol as our method. On Ava-256, we
also compare against the concurrent UIKA [68].
Avat3r [30]. Since the official Avat3r code is not available, we built upon the
reimplementation used by the authors of HeadsUp [46], provided to us. This
reimplementation follows the corresponding publications as closely as possible.
The original method precomputes DUSt3R [66] and Sapiens [28] features only
for a subset of 10 frames per subject due to the computational cost of running
DUSt3R, as it operates on pairs of images, introducing O(n2 ) DUSt3R evaluations. Our setup requires all 1000 frames per subject, making DUSt3R extraction
prohibitive. We replace it with DINOv3 [58], a universal feature extractor which
operates on single images and scales to per-frame extraction while retaining geometric awareness. For Sapiens [28], we took a publicly available 1B checkpoint.
On top of the HeadsUp implementation that does not require rigging with the
same model, here we add expression conditioning, the way it is proposed in the
original Avat3r work. Specifically, we transform expression codes through a shallow MLP into 20 tokens fed to the generator’s cross-attention layers, following
the Avat3r recipe, using the same expression codes as our method for driving.
Confidence-based masking in skip connections of Avat3r has been implemented
through known foreground masks that already give us foreground/background
separation and remove the need to estimate it. On top of L1, SSIM, and LPIPS
used in Avat3r, we also add DINOv2 [47] perceptual loss similar to [48] that,
as we found, significantly improved the results. Additionally, we found it important to introduce two regularizations that significantly improve initialization and
convergence: a scale penalty to prevent Gaussians from becoming too large and
a silhouette loss that encourages the Gaussians opacity to be close to the target
foreground mask (only enabled during the first few epochs). While DINOv2 loss
and these additional regularizations were found to improve performance compared to literal reimplementation, we added them to reach better photorealism
of Avat3r than reported, which makes that baseline even stronger. Without those
changes, our Avat3r implementation is still producing plausible results.
FastGHA [22]. FastGHA predicts pixel-aligned Gaussians with a feed-forward
transformer conditioned on DINOv3 [58] and Stable Diffusion VAE features [55].
To support sparse-view reenactment, Gaussians are predicted in the canonical
head frame and rigged with per-Gaussian deformations predicted from expression codes and parameterized by a dedicated shallow MLP. FastGHA relies on
position maps from VGGT [65] as geometry supervision that acts as a regularization, unlike in Avat3r using similar feature matching maps from DUSt3R [66]
as an additional input. Precomputing VGGT maps on sets of multi-view images
would require infeasible compute time, as it would require O(nd ) evaluations (n
GHARP: Real-time Gaussian Head Animation
27
being the overall number of frames and d the number of input views to VGGT),
and it was omitted for that reason. However, this component should have a
smaller effect on the final result, due to its regularization nature. Since the code
of FastGHA is also not available publicly, similar to Avat3r, we relied on a FastGHA reimplementation that fully builds upon the one created by HeadsUp [46]
authors. Following HeadsUp, we made two modifications to improve the convergence and generalization of FastGHA. First, we added an extra learnable encoder
in parallel to the frozen DINOv3 [58] and Stable Diffusion VAE [55] encoders.
Second, we replaced the frozen Stable Diffusion VAE decoder with a learnable
residual decoder to improve gradient.
Training is stage-wise: in the beginning of training, we train FastGHA for
a number of epochs in a reconstruction-only setting (i.e. when for every individual sample, inputs and targets are always from the same timestamp – as in
HeadsUp), and only then continue in standard reenactment setting, as we observed the optimization was not as stable if training directly for reenactment.
Also, we introduce a silhouette loss (during the first few epochs) and a scale
penalty for better convergence and initialization, the same way as for Avat3r.
Incorporated changes only marginally improve quality and were added to make
FastGHA an even stronger baseline on top of the literal reimplementation.
UIKA [68]. UIKA reconstructs an animatable Gaussian head avatar from a
given number of input images in a single forward pass. It reprojects each input
image into the FLAME UV space, fuses all views with learnable UV tokens in a
transformer, and decodes them into canonical Gaussians that are animated with
linear blend skinning. Like our method, it builds a fixed-size UV representation
that is independent of the number of input views and animates in real time. This
makes it the most closely related concurrent baseline. We start from the authors’
released checkpoint that was trained on public monocular and multi-view head
datasets. This checkpoint takes the role of the Internal10K pretraining used for
the other baselines and keeps UIKA’s prior public and reproducible. We finetune
it on Ava-256 with the official training code and use the same training data
and held-out subjects as for our method. We keep UIKA’s architecture, frozen
DINOv3 encoder, losses and optimizer unchanged. Unlike our method, UIKA
is driven by FLAME parameters instead of ARKit codes. We therefore add a
small MLP, trained jointly with UIKA, to map our ARKit codes to FLAME [35]
expression, jaw, eye and neck parameters. The head pose is given by the cameras,
expressed in the per-frame head coordinate frame. To bring the Ava-256 data
into UIKA’s canonical FLAME space, we register the FLAME template to the
Ava-256 mesh template and fit per-subject FLAME shape parameters to the
tracked Ava-256 meshes. Each training sample uses 1 to 4 input views and 4
supervision views. We train on 2 H100 GPUs with a batch size of 2 per GPU.
We sweep the learning rate over {5 × 10−5 , 10−4 , 5 × 10−4 } and keep 5 × 10−5 ,
as it gives the best LPIPS, PSNR and CSIM. We report the checkpoint at 8k
iterations, after the metrics have plateaued. At test time, UIKA uses the same 4

Body Alignment Network (BAN)
Fig. 4 in the main paper shows an overview of BAN training. This section provides more details on the network architecture and supervision losses.
Blending network. The blending network is a 6-layer convolutional network
operating at 32×32 resolution. It takes the concatenated latents [Zref , ZGT ] ∈
R32×32×1024 and outputs a 1024-channel tensor split channel-wise into the blending weights m and correction δ a . The final convolution is zero-initialized so the
network starts at a 50/50 average of Zref and ZGT .

Training supervision. The aligned Gaussian UV map A is rendered from
multiple viewpoints. Pretrained face-parsing and person-segmentation networks
operate on the renderings to produce binary masks for the face region and the
body region. The face region of the aligned rendering is supervised against the
target rendering, while the body region is supervised against the reference rendering. Mask boundaries are randomized stochastically per iteration to prevent
seam artifacts.
Losses. L1 and LPIPS reconstruction losses are applied to the masked face and
body regions, while an adversarial loss is applied to the full rendering (Tab. 11).
The adversarial loss is a hinge GAN applied on 256×256 random crops of the rendering. The discriminator is conditioned on a separate reference-view rendering
to encourage subject-specific realism. A gradient penalty is applied periodically
during training for stability.

Identity Network Performance
We additionally compared the latency of our identity network to the analogous
appearance-encoding stages of Avat3r [30] and FastGHA [22]. In each method we
measured all steps from the input images up to the decoding stage: for ours, up
to the canonical Gaussian UV maps and deformation latents; for Avat3r, up to
(but excluding) the cross-view transformer; for FastGHA, up to (but excluding)
the Gaussian decoder. All measurements were performed on a single A100, using
one batch of four input views.
Measurements. Our identity network runs in 71 ms, compared to 242 ms for
FastGHA and 2384 ms for Avat3r. The identity network is executed only once per
identity, while subsequent animation is significantly faster (see Tab. 13). For the
baselines, the main bottlenecks are the image encoders: Sapiens [28] in Avat3r
and DINOv3 [58] in FastGHA (or even heavier VGGT). When we reduced the
Sapiens input resolution in Avat3r from 1024×1024 to 512×512 or 512×320, its
latency dropped to 588 ms and 437 ms, respectively, which is still in both cases
significantly larger than for our method.
A.12
In-The-Wild Setting
In this section, we evaluate our algorithm on in-the-wild data. Fig. 13 shows
an example of self-reenactment for our algorithm compared with Avat3r and
FastGHA. We extract the expression codes using ARKit from a video recorded
with an iPhone 15. The video frames are shown in the bottom row. Then we
captured an image of the same subject that we used as input for the identity
generation (left column). We use the models trained for one input view for this
experiment. All the models receive the exact same inputs. The self-reenactment
rows show the animated avatar with the expressions from the bottom row and
the identity from the left column. Since ARKit [2] is robust to in-the-wild data,
and we abstract the driving expression into expression codes, the algorithms
can handle in-the-wild reference expressions without issues. Our model reconstructs identity with a high level of detail from a single input image, whereas
FastGHA [22] and Avat3r [30] exhibit substantially greater degradation in fine
detail and identity preservation. Our model relies on the HeadsUp prior, which
was trained on studio data with specific camera configurations and focal lengths.
Jointly adapting the prior and our model to more diverse capture settings is an
interesting direction for future work.
