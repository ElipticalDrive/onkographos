Contributor
Build a functional voxel game from scratch with procedural generation, world persistence, and first-person controls.
Implementation
Block System
7 block types with solid/transparency properties and unique colors
Chunk-based storage (16x16x64) using flat Vec for efficient serialization
Procedural Generation
Perlin noise terrain with multi-octave height maps
Biome-aware block placement (sand below Y=35, grass above)
Tree generation with 4-block trunks and 3x3x3 leaf canopies
World Persistence
Binary serialization via bincode/serde
Auto-save on exit, auto-load on startup
Entry-based chunk caching prevents duplicate generation
Rendering Pipeline
wgpu-based renderer with depth testing
Greedy face culling (only render visible faces)
Dynamic chunk meshing within 3-chunk render distance
Per-face ambient occlusion shading
First-Person Controls
Camera with clamped pitch, unrestricted yaw
WASD movement, Space/Shift for vertical
Mouse-look on left-click-and-drag
Code Structure
```
// Chunk uses flat indexing for O(1) access and serialization
fn get_index(&self, x: usize, y: usize, z: usize) -> usize {
    x + z * CHUNK_SIZE + y * CHUNK_SIZE * CHUNK_SIZE
}

// Face culling reduces geometry by ~80%
if cy + 1 >= CHUNK_HEIGHT || chunk.get_block(cx, cy + 1, cz).is_transparent() {
    self.add_face(x, y + 1.0, z, ...);
}
```
Tests: 7 unit tests covering block properties, chunk operations, world generation, and serialization round-trips.
Dependencies: wgpu 0.19, winit 0.29, glam 0.24, noise 0.8 - all vulnerability-free.
