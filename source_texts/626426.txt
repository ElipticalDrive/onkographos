Is your feature request related to a problem? Please describe.
Resonite currently supports viewing Gaussian Splats, but external tools are required to create these, which generally work pretty well but lack a lot of the interactivity/usability I feel could come from implementing a mechanism to create splats ingame
Describe the solution you'd like
I would like if resonite had a full Gaussian Splat creation system, including Feature Extraction, Feature Matching, and Reconstruction. These steps would likely behave similarly to programs like COLMAP.
I feel that as a VR platform Resonite actually would be an incredibly powerful tool for creating these and editing the initial conditions for point cloud/splat generation as for parts of the process that involve matching images to the environment you could essentially perform near-realtime corrections to image placement with accurate perspective
Now to be clear: when I say "Near-Realtime" I mean that if an image was moved, it would
in some amount of time
update the point cloud/in progress splat to reflect the resulting changes from this
The biggest benefit of this is that you can essentially immerse yourself in the scene while reconstructing the point cloud, allowing some corrective placements to be made (which the algorithm could probably still shift some but it would probably be told to prefer the manual placements)
And on the silly end of things you could also just make splats out of complete junk just to see what happens for fun
Describe alternatives you've considered
The only real alternative to this is if someone made a standalone VR splat reconstruction software, but I think thats pretty niche and resonite is a lot closer to having something like that than any of the spat reconstruction software existing
Additional Context
I've tried making a few splats now and I found the process cool, but in areas with a lot of similar-ish details its easy for the algorithms to get lost and place everything together, if I had the ability to break apart those photos in VR and place them around as is it would be a lot easier to get a mostly accurate splat.
This existing could also open the door to creating splats on a VR headset, using the external cameras to take screenshots directly brought into resonite and placed at the location of the user for more accurate reconstructions.

This would be great, but I doubt it can be done at this point due to compute constraints. Unless using a highly optimized algorithm like the one developed by Scaniverse, even on a decent midrange GPU the splatting takes up all the GPU resources and still takes an hour or more to fully train a scene. Something adjacent that can definitely be done today though is better editing tools, like additional boolean modifiers (since we currently only have AND in the form of clipping volumes).
