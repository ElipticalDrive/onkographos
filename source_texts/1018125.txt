🚀 Feature Description
Implement the bonus features for the miniRT ray tracer project, extending the mandatory requirements with advanced rendering capabilities including additional primitives, multi-light support, texture mapping, bump mapping, and global illumination techniques.
🎯 Problem Statement
The current mandatory implementation of miniRT covers basic ray tracing with spheres, planes, and cylinders, a single ambient/diffuse light model, and no texture support. To achieve a higher grade and produce more visually compelling renders, the bonus features must be completed. These additions are required to unlock full project scoring and demonstrate mastery of advanced ray tracing concepts.
💡 Proposed Solution
Implement the following bonus features on top of the validated mandatory base:
Support for additional primitives: cone, hyperboloid, paraboloid
Multiple diffuse light sources in the scene file
Specular reflection (Phong model — shiny surfaces)
Checkerboard texture pattern on any object
Bump mapping / normal perturbation via texture maps
Reflection (mirror-like surfaces)
Refraction + transparency (glass effect)
🔄 Alternatives Considered
Skipping bonus entirely and focusing on mandatory polish was considered, but the score ceiling without bonus is too low. Alternatively, implementing only specular + multi-light (easiest bonuses) was weighed, but full bonus completion provides the best return given the shared infrastructure (e.g. Phong shading is a prerequisite for specular before reflection/refraction).
📋 Implementation Details
Add cone and update scene parser to handle co objects with apex, axis, and half-angle
Refactor lighting loop to iterate over a list of light sources instead of a single one
Add specular term to Phong model — requires shininess coefficient in material struct
Implement checkerboard UV mapping, linked per-object via scene file flag
Add recursive reflect_ray() call in cast_ray() capped at a MAX_DEPTH constant
Implement Snell's law refraction in refract_ray() with IOR stored per object
No external dependencies beyond the already-permitted mlx / libft
Ensure mandatory scenes still render correctly after all refactors — no regressions
🎨 Example Usage
```
# compile bonus
make bonus

# run with a bonus scene
./miniRT_bonus scenes/bonus_scene.rt
```
```
# scene with cone + multi-light + specular + checkerboard
A  0.2   255,255,255

L  -40,50,0    0.7   255,255,255
L   40,30,-10  0.5   200,180,255

C  0,0,-5   0,0,1   70

co  0,1,0   0,-1,0   30   255,100,50
    specular: 200   roughness: 0.3

sp  0,0,3   2   255,255,255
    checkerboard   reflection: 0.8   ior: 1.5
```

🏆 Acceptance Criteria
Cone primitive intersects correctly and obeys mandatory scene file grammar
Multiple lights cast correct shadows independently; no light bleeds through opaque objects
Specular highlights appear correctly on curved surfaces with varying shininess values
Checkerboard texture is correctly UV-mapped on sphere, plane, cylinder, and cone
Reflection is recursive up to MAX_DEPTH with no stack overflow on adversarial scenes
Transparent sphere renders visible refraction (objects behind appear shifted/magnified)
All mandatory test scenes pass without visual regression
No forbidden functions — norm compliant (norminette returns 0 errors)
No memory leaks reported by valgrind on all bonus scenes
Documentation updated in README with bonus scene syntax
⚖️ Priority
High — required for full project score
📝 Additional Context
Bonus must be submitted in a separate bonus/ directory with its own Makefile rule (make bonus). The bonus binary must be named miniRT_bonus. All bonus features are evaluated only if the mandatory part passes perfectly.
Recommended implementation order based on dependencies:
Specular shading (Phong)
Multi-light support
Reflection (recursive rays)
Refraction (Snell's law + IOR)
Checkerboard / texture mapping
New primitives (cone, etc.)
