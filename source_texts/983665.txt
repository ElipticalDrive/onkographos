Goal
Creating chunks of terrain with different Level Of Detail that connect seamlessly
Implementation
For a LOD0 node the previous structure of just Leafs and Internal nodes was fine, but for LOD1 we want to be able to generate the mesh with half as many polygons which are twice the size.
For LOD2 there would be half as many again and the size would double again, and so on ...
We can enable this by simplifying the octree.
For more info you can visit this article.
Seams for different LODs
The seam generation is the same as before. We gather the seam nodes from our target chunk + the neighbouring chunks
The seam nodes may be different sizes so we need to process the input nodes in stages along with the newly constructed parent nodes until all the nodes have the same size
Finally we construct the seam nodes with the seam octree that has been generated
