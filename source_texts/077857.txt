Python implementation of Generalized Symmetric Dual Marching Cubes (GSDMC) for extracting constant-wind-speed isosurfaces from 3D NetCDF wind-field data (ERA5, WRF, generic layouts).
Core algorithm (gsdmc/core.py)
Vectorised 8-bit case-index computation over all cells simultaneously
Per-active-cell QEF minimisation (gsdmc/qef.py) using edge intersection points and finite-difference gradient normals; Tikhonov-regularised toward the mass point for rank-deficient cases
Dual mesh assembly: np.where finds active primal edges; four adjacent-cell dual vertices form quads split to triangles with correct outward winding
Supporting modules
reader.py – read_wind_field(): auto-detects U/V/W variable names for ERA5/WRF/generic layouts, collapses optional time dimension, returns WindFieldData with speed array + coordinate metadata / grid spacing
wind.py – compute_wind_speed(u, v, w) and wind_speed_percentile()
mesh.py – Mesh class with OBJ (save + load), ASCII PLY, and ASCII STL export
tables.py – cube vertex/edge topology and per-axis adjacent-cell offsets for dual-quad generation
Usage
```
from gsdmc import read_wind_field, extract_isosurface, Mesh, wind_speed_percentile

data = read_wind_field("era5_wind.nc")
isovalue = wind_speed_percentile(data.speed, 90)   # e.g. 90th-percentile speed

vertices, triangles, normals = extract_isosurface(
    data.speed, isovalue=isovalue,
    spacing=data.spacing, origin=data.origin,
)

Mesh(vertices, triangles, normals).save_obj("wind_iso.obj")
```
Tests
66 tests across test_gsdmc.py, test_wind.py, test_reader.py, test_mesh.py covering geometry correctness, edge cases (empty/trivial fields, tiny grids), QEF vs average-point mode, all three mesh I/O formats, and NetCDF reading variants.
