This pull requests aims to replace the current named_vtk with a new one that will:
Write .vts files instead of .vtk so they can be paired with a .pvd and include a time component.
Small adjustments so that when opening these in paraview they immediately plot relative to the ASPECT surface.
Output more FastScape fields on the visualization.
The conversion to writing the .vts files was done using Claude, while the rest I did with some trial and error. At the moment, rather than rewrite the .pvd every time, we append it. Because of this Claude had it write a .pvd_index file to deal with restarts. I think this is maybe easier than saving the history within ASPECT and sending it every time (assuming this is truly necessary). Also, for now I have kept the function name as VTK, which could be renamed to VTS or something else. Initially I was thinking to leave it for older installations, but since more parameters are transferred now I suppose it will break older coupling versions anyway.
Any comments on this initial change? Additional note, I should add more comments to this as well instead of mostly using the AI ones.
