Motivation
Provide a performance-focused Minecraft-style voxel prototype in a single pyblocks.py by replacing the prior testing/demo code with a chunked, streaming, procedurally-generated world and basic gameplay features.
Meet the project requirements: 16x16 chunks, deterministic seed-based noise terrain, configurable render distance, chunk load/unload around the player, first-person controls, block interaction, and simple crafting.
Description
Rewrote pyblocks.py to add a World/Chunk system with deterministic noise (hash2, smooth_noise, fbm) and per-chunk generation (CHUNK_SIZE = 16, vertical CHUNK_HEIGHT, sea level, ores, trees) and replaced the old immediate block model.
Implemented dynamic chunk streaming with update_visible_chunks() that loads nearby chunks and unloads distant ones using a configurable RENDER_DISTANCE (default 2), and added per-chunk mesh building that culls hidden faces and produces indexed vertex lists using GL_TRIANGLES.
Added a first-person GameWindow controller with walk/run/crouch/jump, simple gravity and collision (collide), raycast-based block selection (hit_test), breaking/placing blocks, hotbar/inventory management, and the full block ID catalog (0..30).
Added crafting systems with a 2x2 inventory craft and a 3x3 crafting table (RECIPES_2x2 / RECIPES_3x3), UI text overlays, and helper utilities for chunk/local coordinate math and voxel face generation.
Testing
Ran python -m py_compile pyblocks.py after the refactor and after a GL primitive change to ensure the file compiles without syntax errors, and the compilation completed successfully.
No automated runtime graphical tests were executed in CI; the changes were validated via successful Python byte-compilation locally.
