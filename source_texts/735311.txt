# cub3d — Raycasting Engine in C

A simple 3D raycasting engine inspired by **Wolfenstein 3D**, developed from scratch in C using SDL3. This project implements the **DDA (Digital Differential Analyzer)** algorithm for real-time rendering.

## ✨ Features

- Raycasting engine for real-time 3D rendering from a 2D map
- DDA algorithm for efficient ray–wall collision detection
- Smooth player movement with wall sliding
- Modular architecture (Engine, Player, Map, Main)
- Performance-oriented design using structs and low-level pixel buffers

## 🛠️ Technologies

- **C language** — manual memory management and performance focus
- **SDL3** — window creation, input handling, and rendering
- **Linear algebra and trigonometry** for camera rotation and perspective projection
