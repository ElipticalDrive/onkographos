Owner
Implements GPU-side resource parity from svg-fidelity-complete-v0.5 without merging parallel branches.
Completed scope:
external texture-backed embedded PNG/SVG image rendering with intrinsic SVG sizing and preserveAspectRatio
premultiplied-alpha texture upload semantics
native vector/SVG pattern fills with repeated bounded texture sampling
deterministic isolated fallback for patterned strokes
native mask command handling through isolated compositing without silent drops
explicit GPU texture lifetime/resource bindings and render-target-capable GpuTexture
public offscreen texture/view interface for later native filter passes
reusable FilterExecutionRequest / GpuFilterExecutor boundary without inventing a second FilterGraph
clipping/resource transform interaction preserved through the hybrid scene
GPU diagnostics for unsupported/filter-deferred operations
GPU resource tests now run in CI on Ubuntu and macOS
architecture documentation in docs/GPU_RESOURCES_V06.md
Preserved:
existing solid, linear-gradient, and radial-gradient GPU rendering
deterministic CPU resource fallback where the current Vello Hybrid API lacks native support
Not included:
CPU/native FilterGraph implementation owned by filter-graph-v0.6
font loading or shaping
SVG importer semantic redesign
SVG reconstruction fallbacks
merges from parallel branches
CI verification on the final branch head:
Runtime regression: Ubuntu + macOS pass
Renderer GPU type-check + GPU resource tests: Ubuntu + macOS pass
Renderer CPU: Ubuntu pass; macOS check/tests pass with the existing SVG fidelity script still running at the final verification point
