When exporting meshes in unbounded mode, I find that the resulting mesh has two layers (one on top with the desired information, and one on the bottom with a weird stripey texture). See the effect in the following three images (first is top view, second is bottom view, third is demonstrating the presence of two layers).
I assume this has something to do with the SDF looking like:
```
  top    <-- outside (positive)
-------  <-- surface
  b/w    <-- inside (negative)
-------  <-- weird texture 
 below   <-- outside again (positive)
```
In bounded mode, this issue is not present, as I assume anything below the object is processed as "in" the object.
I am using the Ref-NeRF real dataset (specifically, the sedan object), but this happens with all the other datasets I've tried on unbounded extraction too. I am generating pose information with colmap, and calling 2dgs with the following code:
```
subprocess.run([
    "python3", "2d-gaussian-splatting/train.py",
    "-s", dataset_path,
    "-m", model_path
], check=True)
subprocess.run([
    "python3", "2d-gaussian-splatting/render.py",
    "-s", dataset_path,
    "-m", model_path,
    "--unbounded",
    "--mesh_res", "1024",
    "--skip_train", "--skip_test"
], check=True)
```
To my knowledge I have not made any modifications to the original source code.
