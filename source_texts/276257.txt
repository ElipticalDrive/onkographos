This PR introduces a robust volumetric lighting system with support for god-rays, cascading froxel grids, and tight integration with the existing weather and atmospheric systems.
Key features:
Froxel Cascades: A 4-cascade 3D grid system (160x90x64 resolution per cascade) using logarithmic depth distribution to maintain high detail near the camera while supporting long-range volumetric effects.
Fog Revamp: The atmospheric scattering system (aerial perspective) now samples local weather scalars (humidity) and aerosols, resulting in physically grounded, spatially-varying fog that reacts to the LBM weather simulation.
Temporal Accumulation: Implemented jittered sampling and history reprojection within the froxel injection phase to reduce noise and allow for stable rendering at lower resolutions.
Environment Grounding: Radiance injection now includes Spherical Harmonics (SH) ambient irradiance lookups, ensuring volumetrics are properly tinted by the environment and sky.
Optimization: Used compute shaders for radiance injection and Z-axis integration (prefix-sum style) for maximum efficiency.
UI & Integration: Added detailed sliders for Volumetric Intensity, Anisotropy, and Temporal Alpha in the Environment UI. The effect is registered as an early post-processing pass.
Demonstration: A new example examples/volumetric_lighting/main.cpp is included to showcase god-rays and dynamic fog transitions.
Refactorings:
Modified ShadowManager::BindForRendering to accept ShaderBase&, enabling shadow map usage in compute shaders.
Fixed an inclusion dependency in math.glsl to ensure PI is always available for phase functions.
