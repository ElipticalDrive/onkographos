Is your feature request related to a problem? Please describe.
When viewing dicom images, they are sometimes displayed with the three planar views representing the standard basis and sometimes with the views representing the basis, also called direction cosines, from the dicom header.
That is, sometimes the normals to each of the planes are (1 0 0), (0 1 0), (0 0 1). When this view is enabled, the images in the planes are re-sliced from the volume image. The 3D image is shown as an obliquely oriented slab relatively to its coordinate-aligned bounding box.
Sometimes the normals to each of the plane are determined by the basis in the dicom headers, also called the direction cosines. This is some clinically relevant basis, such as the short axis planes with normal long axis direction. One planar image shows the scan image itself, while the other two are sliced orthogonal to the scan planes. The 3D image is shown aligned with its minimal bounding box.
When loading, sv usually shows the first view. If I swap to the segmentation view then go back to path or other tools that show the standard four panels, it goes to the second and does not change back.
Describe the solution you'd like
A button could be added that allows the user to swap between these views.
Describe alternatives you've considered
Only using the dicom-basis views is usually okay. If swapping is not feasible, the oblique view should be removed and dicom-basis view should be default.
