# rust-voxlap-vxl

Reimplementation of VOXLAP's voxel storage in hopefully-idiomatic Rust:

- Compressed in-memory using the same RLE format as .vxl map files
- Batched edits

Todo:

- Floating block detection
- Make errors less catastrophic?

VOXLAP engine by Ken Silverman (http://advsys.net/ken)

## Why?

Just to learn more about VOXLAP and Rust. Frankly this project has been "outdated" from its very beginning, and for that reason I won't be publishing this as a crate. Any modern project will want to use data structures that are tailored more to working with GPUs. Ace of Spades was an abberation, cause CPU renderers like VOXLAP are cool but they've been pretty much irrelevant for, what, a quarter of a century?

## Was this made with AI?

Not exactly, but it's tricky. I used AI to dissect VOXLAP's impenetrable codebase. Unfortunately, AI is good at picking out patterns that would take me weeks of study. Really, [you try reading it yourself](https://github.com/MuffinTastic/wowanothervoxlap/blob/master/voxlap/voxlap/voxlap5.c). I also used it to get suggestions on code I've already written.

Other than that, I'm a staunch believer in AI melting your brain if you let it. I make all the decisions, even if it takes me like 10x as long. AI is not a "co-engineer", it's a tool.
