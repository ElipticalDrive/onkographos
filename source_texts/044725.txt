A full volumetric box view — depth as the vertical axis, with adjustable vertical exaggeration — distinct from the flat 2-D plate carrée map projection already built on this branch (viewer/src/core/projection.ts's ProjectionMode). This is the "box view" mentioned as a non-goal in tomography-globe-viewer-spec.md §11, asked for and costed but not scheduled.
Roughly 2.5–3× the isosurface work, and multiplicative rather than additive — it touches every module. Three costs called out as not obvious up front:
Every geometry is currently built as a sphere (core, surface, pick target, cutaway walls, floor cap, coastlines, land fill) — each needs a parameterised builder for a box.
The boundary overlay's occlusion model relies on a sphere's horizon (dot(v, camDir) > R/d); a box has none, so this would need real depth testing instead.
The antimeridian stops being free — deep-time-map works in 3-D unit vectors where the dateline isn't special, but in plate carrée every feature crossing ±180° draws a full-width streak, and coastlines/the cutaway polygon would need the same treatment; the poles become lines.
This would be a display choice, not a change of model — all spherical geometry (great-circle densification, the scanline mask, rotations) stays computed on the sphere; only the final world-position mapping changes.
