Owner
Why
Sculpting in the kernels was limited to a single radial sphere displacement (geometry_ops::Brush) and an SDF sphere add/remove, with almost no test coverage. This PR first brings the existing sculpting under test, then completes the library with a classic brush set shared by every kernel plus richer SDF strokes, and finally tightens the structure so kernels share one implementation.
What
Shared engine (crates/geometry-ops/src/sculpt.rs)
Brush kinds: grab, draw (along normal), inflate (per-vertex normal), smooth (one-ring Laplacian), flatten (project to average tangent plane), pinch.
Falloffs: smooth, linear, sharp, root, sphere, constant.
Optional X/Y/Z symmetry across world planes (mirror centers are deduplicated when on the plane).
SculptTarget is an owned value (positions, unit normals, one-ring adjacency) with SculptTarget::from_faces for polygonal faces of any arity, so polygon meshes and subdivision cages share one Newell-normal/ring builder; NURBS build their own from the control net and reuse unit_or_zero.
Each brush kind is one small method on a per-center Pass (weights, affected set, area normal, weighted centroid) instead of a monolithic match inside the loop; adding a brush touches one variant and one method.
codec helpers (object / required / optional) replace repeated hand-written field extraction in Brush, Deformation, Symmetry and SculptBrush. The legacy Brush now uses Falloff::Smooth.
Kernel wiring
polygon-core: sculpt_target / sculpt on Mesh.
subdivision-core: Cage::sculpt_target / Cage::sculpt.
nurbs-core: sculpt_curve / sculpt_surface with normals derived from the control net (curvature direction for curves, cross of finite differences for surfaces, periodic wrap).
sdf-core: new Field::Capsule and Field::SmoothDifference, smooth_min, SdfTool / SdfStroke (sphere, box, capsule; add/remove; optional smooth blend) and Field::sculpt; sculpt_sphere is now a shorthand over sculpt. WGSL shader and flat.rs encoding updated (kinds 10 and 11).
Bridge, TS and UI
WASM ops polygon_sculpt, subdivision_sculpt, nurbs_sculpt_curve, nurbs_sculpt_surface, sdf_sculpt.
TS wrappers: sculptPolygonMesh, sculptSubdivision, sculptNurbsCurve / sculptNurbsSurface, sculptSdf, sculptMesh, with validateSculptBrush; validateSdfBudget now skips capsule endpoints.
Pure helpers buildSculptBrush / isFractionalSculptKind (geometryEditing) and meshCentroid (meshEditing) hold the brush-assembly logic; MeshModeler.vue only binds settings to them in its new Sculpt panel (kind, falloff, radius, strength, XYZ mirror).
Tests and docs
Rust unit tests in geometry-ops, polygon-core, subdivision-core, nurbs-core and sdf-core (legacy brush, new engine, from_faces on quads and triangles).
tests/sculpting.test.ts: 14 WASM integration tests (legacy brush across kernels, brush directions, flatten coplanarity, smooth convergence, symmetry, NURBS sculpt, SDF strokes and smooth blend, UI brush assembly).
docs/design/native-modeling-operations.md documents the sculpting API and architecture and drops "advanced sculpt brushes" from Still missing.
Notes for review
Smooth/flatten/pinch strength is a fraction in [0, 1]; draw/inflate strength is a signed distance (negative carves).
The smooth-blend test checks the exact seam value k * h * (1 - h) = k / 4 on the intersection circle of two unit spheres.
Verified: cargo test --workspace (1524 passed), clippy clean in touched code, npm run typecheck, vitest (only the 7 pre-existing engineManifest / g0ToolchainFingerprints fingerprint failures remain, unrelated to this change).
CI is red on main too: dtolnay/rust-toolchain@nightly-2026-09-10 is not a resolvable action ref; that workflow fix is out of scope here.
