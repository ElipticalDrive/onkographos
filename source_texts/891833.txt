Guard unsupported volume formats before binding raymarch textures
This pass binds item.residency.view/sampler unconditionally, but the new shader contract is fixed to texture_3d<f32> (packages/renderer/src/shaders/built_in_volume_raymarch.wgsl) while volume residency accepts any GPUTextureFormat via VolumeAsset.pixelFormat (packages/gpu/src/residency.ts). Scenes with non-float or unfilterable formats (for example rgba8uint or r32float) now pass capability preflight (volume: supported) and then fail at runtime with WebGPU bind-group validation errors when this path executes, so the renderer should reject or gate incompatible formats before encoding this bind group.
