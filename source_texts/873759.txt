Check that the smoke texture unit is enabled
When a smoke texture remains bound on an inactive texture unit, this scan still classifies every subsequent draw as a smoke draw because it examines bindings without checking glstate->enable.texture[unit] or whether the current program samples that unit. Persistent GL bindings are common, so unrelated draws can flush transition records and exhaust the 128-record budget before the actual smoke draw, invalidating the diagnostic ordering used by WO-033.

Clear stale targets when texture names are reused
When a diagnostic texture is deleted and GLES later reuses its numeric name for an uncategorized image, this early return leaves the old category and target in sGLTextureCategories and sGLTextureTargets. A repo-wide search of the bridge and OSG/GL4ES patches finds no deletion or unregister path, so later lookups can misclassify the replacement texture as foliage or smoke and produce false targeted evidence; registration must clear an existing entry for category NONE, or texture deletion must unregister the name.
