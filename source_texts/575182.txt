[![COSMIC Ecosystem](https://img.shields.io/badge/COSMIC-Ecosystem-purple.svg)](https://github.com/cosmic)

**Photorealistic 3D human reconstruction from phone rotation videos.**

CODA Forge is a 17-stage pipeline that takes a simple phone video of a person rotating and produces a textured, watertight 3D model ready for printing, rendering, or VR. It runs end-to-end with no manual intervention — from video input to GLB/OBJ/STL export.

## Features

- **17-stage automated pipeline** — quality check through export with checkpointing and resume
- **Multi-backend depth** — Depth Anything V2, MiDaS, or CPU fallback
- **COLMAP SfM** — camera pose estimation and dense point cloud generation
- **Neural reconstruction** — ECON, PIFuHD, SMPL-X implicit surface methods
- **Face reconstruction** — MediaPipe + FLAME face mesh with UV texture
- **Gaussian splatting** — optional neural rendering for photorealistic output
- **Texture baking** — xatlas UV unwrapping with multi-view texture blending
- **3D print ready** — watertight mesh cleanup, volume estimation, STL export
- **Quality reporting** — HTML/PDF reports with geometry and similarity metrics

## Quick Start

```bash
pip install coda-forge-3d
coda-forge --video input.mp4 --height 175
```

## Install

```bash
git clone https://github.com/coda-forge/coda-forge-3d.git
cd coda-forge-3d
pip install -e .
```
