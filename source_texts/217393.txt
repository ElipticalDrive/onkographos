This PR adds slice rendering to Neuroglancer. A slice has a projection rendered on it from a sub volume of voxels, which is defined by voxel range.
Voxel range
Voxel range is implemented as the number of voxels that are used from each side of the slice for projection rendering. The default is 0.
Minimum and maximum intensity rendering modes are implemented. The default is maximum.
Layer
A layer with slice as its type is implemented. This layer stores position, orientation, voxel range, and rendering mode properties for the slice.
Gizmo
A gizmo is implemented for changing position, orientation, and voxel range.
