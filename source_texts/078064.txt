Goal
Create a naive block-based mesher for debugging SDF and voxel correctness.
Steps
Create BlockMesher.cs in Scripts/World/Meshing/.
Implement BuildMesh(ChunkData chunk, WorldSettings settings) -> MeshData:
For each voxel:
If solid (density < 0), emit cube faces only where neighbor is air.
Use unit cubes scaled by voxelSize.
How to test
In VoxelWorld, temporarily use BlockMesher to build meshes for a few chunks.
Verify you see big blocky terrain roughly matching the island, mountain, etc.
