# 📐 3D Helical Cone-Beam CT Image Reconstruction (LSQR Algorithm)

An end-to-end high-performance system for **3D Helical Cone-Beam Computed Tomography (CT) Image Reconstruction**. This project uses ray-casting geometry and the **LSQR (Least Squares QR)** iterative solver algorithm to reconstruct 3D attenuation volume densities ($X$) from 2D X-ray projection measurements ($B$).

Both **CPU (C)** and **GPU-accelerated (CUDA)** implementations are provided.

## 🔬 Project Overview

In Computed Tomography (CT) scanning, an X-ray source and detector rotate around an object, recording total X-ray absorption along rays (line integrals). 

This project solves the linear inverse problem:
$$\mathbf{A} \cdot \mathbf{X} = \mathbf{B}$$

Where:
- $\mathbf{X}$ is the unknown **3D Voxel Density Grid** ($512 \times 512 \times 512 = 134,217,728$ voxels, $\sim 536.87 \text{ MB}$).
- $\mathbf{B}$ is the **Projection Measurements Vector** ($473 \text{ angles} \times 512 \times 512 \text{ detector pixels} = 123,994,112$ values, $\sim 495.98 \text{ MB}$).
- $\mathbf{A}$ is the implicit system projection operator (ray-voxel interaction matrix).

## ⚙️ Mathematics & Geometry

| Parameter | Value | Description |
| :--- | :--- | :--- |
| **Volume Grid ($\mathbf{X}$)** | $512 \times 512 \times 512$ | 3D Voxel resolution |
| **Object Diameter** | $80.86 \text{ mm}$ | Physical bounding diameter ($\text{voxel size} = 0.157929 \text{ mm}$) |
| **Projections ($N_{pa}$)** | $473 \text{ angles}$ | Angular projections over $640^\circ$ span |
| **Detector Grid ($N_{det} \times N_{slice}$)** | $512 \times 512$ | Detector pixels per projection angle |
| **Source-to-Object ($\text{scob}$)** | $166.641 \text{ mm}$ | Distance from X-ray source to rotation center |
| **Source-to-Detector ($\text{scd}$)** | $1238.157 \text{ mm}$ | Distance from X-ray source to detector panel |
| **Detector Pitch ($d$)** | $0.8 \text{ mm}$ | Size of each detector pixel |
| **Helical Shift** | $0.136 \text{ mm}$ | Helical vertical movement per angle |
