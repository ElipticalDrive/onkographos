Add Information Next-Best-View Evaluation Pipeline
Summary
This PR extends FastGS with an information-theoretic framework for evaluating and ranking candidate viewpoints for Next-Best-View (NBV) planning.
The implementation enables estimation of the expected information gain of candidate camera poses by computing renderer information for each candidate, accumulating prior information from existing observations, and ranking viewpoints using information-theoretic optimality criteria.
The work is inspired by recent research on active reconstruction and uncertainty-aware view planning, particularly POp-GS and FisherRF.
⸻
Motivation
Modern 3D reconstruction systems typically assume that input images have already been captured. In active reconstruction, however, the objective is to determine where the camera should move next in order to maximise the expected improvement in reconstruction quality.
This PR adds the core components required to evaluate candidate viewpoints based on their expected contribution to the reconstruction, enabling FastGS to serve as the rendering backend for information-driven view planning pipelines.
⸻
Features
Compute renderer information for arbitrary candidate viewpoints.
Accumulate prior information from all existing training views.
Estimate the expected information gain of candidate viewpoints.
Rank viewpoints using:
T-optimality (trace maximisation)
D-optimality (determinant maximisation)
Support both independent and greedy sequential ranking strategies.
Pipeline
```
Train Gaussian Splatting

    ↓

Generate Candidate Views

    ↓

Compute Renderer Information

    ↓

Compute Prior Information

    ↓

Rank Candidate Views

    ↓

Suggested Next-Best Views
```
Related Work
This implementation is inspired by the following papers:
POp-GS: Point-based Online Planning for Gaussian Splatting, which proposes uncertainty-driven next-best-view planning for 3D Gaussian Splatting.
FisherRF: Active View Planning with Fisher Information for Neural Radiance Fields, which formulates active view planning as an information maximisation problem using Fisher Information.
While this implementation follows the same overall principles, it is designed as a lightweight extension to FastGS that enables experimentation with information-theoretic view planning methods without modifying the underlying Gaussian Splatting optimisation pipeline.
⸻
Future Work
Potential future extensions include:
Additional optimality criteria (A-, E- and G-optimality)
Online iterative next-best-view planning
Multi-view batch selection
Integration with robotic or autonomous camera platforms
Evaluation on larger active reconstruction benchmarks
