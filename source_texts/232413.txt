Parent: #110
目的
現行AutoPhotogrammetryが既に生成している Nerfstudio/Splatfacto config + checkpoint + cameras を利用し、rendered depthをTSDFへ統合してtriangle meshを生成する経路を正式baselineにする。
これは PLY-only converter ではない。Gaussian PLYの点分布を直接mesh化する #112 と分離し、内部producer pipelineだから使える高情報量のmesh extraction として扱う。
一次情報
Nerfstudio公式:
ns-export tsdf --load-config CONFIG.yml --output-dir OUTPUT_DIR
TSDFはdepth mapsからsurfaceをmeshとして抽出し、公式docsでは全modelで動作する方式と説明
https://docs.nerf.studio/quickstart/export_geometry.html
AutoPhotogrammetryがpinしている Nerfstudio revision 50e0e3c70c775e89333256213363badbf074f29d の ExportTSDFMesh:
https://github.com/nerfstudio-project/nerfstudio/blob/50e0e3c70c775e89333256213363badbf074f29d/nerfstudio/scripts/exporter.py
同revisionのSplatfactoはevaluation時にdepth outputを持つ設定を実装している:
https://github.com/nerfstudio-project/nerfstudio/blob/50e0e3c70c775e89333256213363badbf074f29d/nerfstudio/models/splatfacto.py
TSDF原理:
RGB-D + camera intrinsics/extrinsicsを Truncated Signed Distance Function volumeへ統合
triangle mesh extraction
Open3D公式: https://www.open3d.org/docs/latest/python_api/open3d.pipelines.integration.TSDFVolume.html
実装要件
1. run artifactからconfig/checkpointを解決
mesh exportが必要になってから再学習しない。
successful quality/default or production Splatfacto runを参照
exact config.yml
exact checkpoint path / checkpoint hash or immutable identity
Nerfstudio revision
source dataset contract
camera transforms
が揃っている場合のみ実行する。
現行run manifestに不足があれば producer側manifestを先に拡張する。
2. TSDF parameterを明示
Nerfstudio ExportTSDFMesh の主要parameterをmanifestへ保存:
downscale factor
resolution x/y/z
batch size
bounding box min/max
texture method
target face count
refinement settings
自動設定する値でも、最終値を必ず保存する。
3. bounding volume
固定 [-1,1]^3 を全sceneへ盲目的に使わない。
camera / sparse points / Gaussian bboxから候補を算出
orientation canonical frameと整合
cropがgeometryを切っていないことをreportする
extreme unbounded sceneはBLOCKEDまたは別profileとする
4. rawとpostprocessedを分離
最初に upstream tsdf_mesh.ply をimmutable raw artifactとして保存する。その後のdecimation / UV / texture / GLB等は別Issueの派生成果物にする。
実証
最低2sceneで:
successful Splatfacto run
ns-export tsdf
raw mesh生成
vertex/face/component/bbox
runtime / peak VRAM/RAM
input config/checkpoint/revision
output SHA-256
を保存する。
受け入れ条件
現行Docker imageのpinned NerfstudioだけでTSDF exportが動く
学習を暗黙に再実行しない
exact config/checkpoint/upstream revisionをmanifest化する
bounding boxをscene evidenceから決め、使用値を保存する
raw TSDF meshを後処理前に保存する
2scene以上で成功/失敗を再現可能に記録する
#112のPLY-only方式と出自を混同しない
TSDF meshを「ground truth」扱いしない
