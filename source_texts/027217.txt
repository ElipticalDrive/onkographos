Summary
Unified OpenVDBVolume component that merges Classic and Realtime renderers into a single entry point with shared Inspector UI and per-mode parameters
Cross-pipeline spot lights (up to 2) with smooth inverse-square distance falloff and cone attenuation, working on both HDRP and Built-in RP
Standard RP light color integration — Realtime shader reads _LightColor0 from Unity's forward rendering instead of hardcoded white
HDRP shader compatibility — Uses UNITY_MATRIX_M for object-to-world transforms, resolving HDRP compilation errors while maintaining Built-in RP support
Keyword-gated features — All shared features (directional light, ambient, color ramp, spot lights, shadow casting) use shader_feature_local for zero GPU cost when disabled
Realtime rendering pipeline — Occupancy grid empty-space skipping, adaptive stepping, temporal jitter, Henyey-Greenstein phase function, multi-scatter approximation
Quality presets — Low / Medium / High / Ultra one-click configurations
Bug fixes — Spotlight double-intensity fix, OpenVDBVolume naming conflict resolution, HDRP unity_ObjectToWorld access error fix
Documentation — Updated README.md and added full Japanese README_ja.md

```
Major overhaul introducing a modern real-time volumetric rendering system:

**GPU Compute Shaders:**
- OccupancyGridBuild: Generates sparse occupancy grid for empty space skipping
- BrickMapBuild: Converts dense volumes to sparse brick atlas format
- TemporalReprojection: Amortizes rendering cost across frames

**Enhanced Ray Marching (Standard + HDRP):**
- DDA-based empty space skipping via occupancy grid
- Adaptive step size based on camera distance
- Temporal jitter (Interleaved Gradient Noise) for TAA integration
- Henyey-Greenstein phase function for realistic scattering
- Multi-scattering approximation (powder effect)
- Early ray termination optimization

**Runtime Components:**
- OpenVDBRealtimeVolume: Main rendering controller with per-feature toggles
- OccupancyGridGenerator: GPU occupancy grid builder
- BrickMapGenerator: Sparse brick atlas construction
- TemporalVolumeRenderer: Frame history management
- VolumeLODController: Distance and frame-budget based quality scaling
- VolumeQualityPreset: Configurable quality presets (Low/Medium/High/Ultra)
- VolumeDataConverter: Volume analysis, normalization, and LOD generation
- OpenVDBRealtimeSequencePlayer: Animated VDB sequence playback

**Integration:**
- New VolumeRenderMode (Classic/Realtime) in import settings
- Importer auto-selects realtime shader and attaches components
- Custom editors for all new components
- HDRP shader GUI for material-level feature control

**Research Documentation:**
- Comprehensive survey of volumetric rendering techniques (docs/)
```

```
Features:
- Light Influence: _LightInfluence/_AmbientInfluence multipliers to control
  how much scene lights affect the volume, independent of _Intensity (density).
  Fixes bug where lightColor was never applied to lightenergy accumulation.
- Shadow Casting: Integrate existing VolumeHDRPShadowCaster.hlsl as a
  ShadowCaster pass. Configurable density threshold and extra bias.
  Toggle via OpenVDBHDRPVolume component (renderer.shadowCastingMode).
- Color Ramp: Gradient-to-texture mapping for density-based coloring.
  Alpha channel modulates opacity. Baked as 256x1 RGBA32 texture.
- Spot Lights: Manual uniform approach supporting up to 2 spot lights
  with distance/cone attenuation (angleScale/angleOffset from Unity Light).
- Consistent Density: Fixed normalization range in native plugin for
  VDB sequence playback. Auto-detect scans all frames for global min/max.
```

Fix spotlight spatial offset caused by HDRP camera-relative rendering
…
b0cf0a7
```
HDRP uses camera-relative rendering where UNITY_MATRIX_M transforms to
camera-relative world space (camera at origin), not absolute world space.
Spotlight positions from C# are in absolute world space, causing a mismatch
that scales with camera distance from origin.

Fix: Convert camera-relative sample positions to absolute world space
before spotlight attenuation computation. Uses _WorldSpaceCameraPos offset
for Realtime HDRP path and GetAbsolutePositionWS() for Classic HDRP path.
Standard RP is unaffected (UNITY_MATRIX_M already gives absolute coords).
```
