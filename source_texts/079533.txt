# CSCI 580 Final Project: Procedural Floating Island Renderer

A procedurally generated floating landmass system featuring volumetric clouds and asteroids, stylized as voxels or low-poly meshes. Built with OpenGL and real-time rendering.

## Features

- **Procedural Island Generation**: Creates organic island shapes by blending multiple spheres using signed distance fields (SDFs) and smooth union functions
- **Dual Mesh Generation**: Supports both smooth meshes (Surface Nets) and blocky voxel meshes
- **Volumetric Cloud Rendering**: Real-time ray-marched clouds using 3D Perlin noise
- **Dynamic Chunk System**: Infinite world generation with on-demand loading/unloading
- **Interactive Controls**: Real-time parameter adjustment for clouds and camera movement
