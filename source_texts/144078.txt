RebusFarm is your render farm for V-Ray
Since 1997, V-Ray is a 3D rendering software for visualizations and 3D computer graphics, developed by Chaos Group in Sofia, Bulgaria. RebusFarm supports the following 3D software with VRay: 3ds Max, Cinema 4D, Maya, Blender, Modo, SketchUp, Rhino, Softimage and Revit.

V-Ray Render Farm Software
Our Render Farm for VRay supports the VRay Standalone Renderer, using the (*.vrscene) format and we also support the native file format of the 3D application. The benefit of the native format is, that you can upload your render job to the V-Ray Render Farm much faster because of the lower file size. This helps you to avoid long waiting times for scene conversion and it allows you to use 3rd party plugins.
