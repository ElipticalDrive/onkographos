Motivation
Perlin noise is currently available, but complex organic textures (clouds, terrain, marble) benefit greatly from multi-octave Fractal Brownian Motion (FBM). Furthermore, smooth motion transitions and UI animations require standard easing functions.
Proposed API / Scope
Fractal Brownian Motion (FBM):
NoiseFBM(x, y float64, octaves int, persistence, lacunarity float64) float64
NoiseFBM3D(x, y, z float64, octaves int, persistence, lacunarity float64) float64
Easing functions:
Linear, Quadratic, Cubic, Quartic, Sine, Exponential, Elastic, Bounce easing functions (In, Out, InOut).
Tasks
Implement FBM noise functions in noise.go
Implement easing functions in easing.go
Add unit tests and visual/property tests
