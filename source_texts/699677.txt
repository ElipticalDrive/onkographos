Motivation
3D face geometry already supports opt-in derived descriptors such as centroid, area, normal, and site/face intersection data.
Add the solid angle subtended by each face polygon at the corresponding cell site as another generic geometric descriptor.
This is useful for angular face weighting, exposed-direction analysis, coordination descriptors, and downstream constructions that replace artificial box truncation by a radial boundary.
Proposed scope
Extend annotate_face_properties() with:
```
face["solid_angle"]  # float, steradians
```
Compute the value from the ordered face vertices relative to cell["site"], using a numerically robust triangulation / atan2 formulation.
The descriptor should be:
unsigned and independent of face-cycle orientation;
available for both standard and power cells;
None for genuinely undefined/numerically singular cases rather than silently inventing a value;
documented as a numerical descriptor of the returned native face geometry.
For a convex cell whose site lies strictly inside the cell, the face solid angles should sum to approximately 4*pi. This invariant must not be assumed for arbitrary power cells, where the generating site may lie outside its own cell.
Timing
Not required for the v0.9.0 stabilization milestone. Treat as a small downstream-driven feature for the v0.9.x soak / pre-1.0 period.
Start with the existing Python face-property post-processing; move computation into the native layer only if profiling demonstrates a meaningful benefit.
