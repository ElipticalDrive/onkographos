Implicit surfaces

Description
2D fluid-like blobs (metaballs) that merge and separate smoothly using implicit surfaces and marching squares for contour generation. Creates organic, liquid-like movement.
Why It's Impressive
Beautiful organic visuals
Foundation for 2D fluid simulation
Shows implicit surface concepts
Real-time mesh/contour generation
Used in many classic games
Interactive Features
Add/remove metaballs with mouse
Adjust blob radius and strength
Control threshold value
Change grid resolution
Animate metaballs
Different rendering modes (filled, outline, both)
Physics integration option
Technical Highlights
Marching squares implementation
Field value calculation
Linear interpolation for smooth edges
Efficient grid evaluation
Multiple metaball influence combination
Real-time contour extraction
