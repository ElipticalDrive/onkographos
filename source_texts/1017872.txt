Mesher: atlas mode (atlas: true, used by every world mesh) merges coplanar faces greedily by shape alone. Each quad owns a block of texels in a 3-plane RGBA8 atlas:
plane 0: lamp rgb and sun per corner
plane 1: sky and AO per corner, plus vary and edge bits per voxel
plane 2: colour and emissive code per voxel
mergeMeshes concatenates blocks and packAtlas shelf-packs them, writing each quad's block origin into vertex bytes 8..11.
Shader (ATLAS define): bilinear corner light/AO, plus a texelFetch of the voxel's colour, vary and edges. The bevel now uses each voxel's own edges.
engine/atlas.ts:
Textures upload on arrival; uploading mid-pass clobbered unit 0, which darkened zoomed-out views in testing.
Each draw binds the texture to the unit three gave tAtlas, so materials don't re-upload all their uniforms per chunk.
Removes: the gradient merge from v0.10.23/24, which no longer has any users.
Results: lv0 quads 718k → 251k (−65%) over a quarter of the chunks. Atlas plus vertex memory is lower than before, and bake time is a bit lower too.
Checks: headless day, night, zoomed-out (zoom 60) and first-person screenshots match main apart from crowd movement.

…at merges (v0.10.15)

- orderFaces puts seam faces in their own first segment, drawn only with the
  two-sided cutaway material (they were collapsed in the vertex shader anyway).

  see them (+X faces by descending x, etc.) for better early depth rejection.
