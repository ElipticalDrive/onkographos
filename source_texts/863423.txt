Repo
This project is a WebGPU 3D Gaussian Splat viewer including the following features:
Point cloud rendering
Gaussian rendering
Preprocessing, depth sorting, indirect splat rendering
view-frustum culling
3D covariance
2D projection of covariance
conic and radius eval
view-dependent color (3rd degree spherical harmonics)
Radix depth sorting
Performance review with gaussians, render types, and culling
