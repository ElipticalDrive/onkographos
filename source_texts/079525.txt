# go-minecraft

A real-time 3D voxel renderer written in Go — infinite procedural terrain, day/night cycle, dynamic clouds, and water rendering.

**Stack:** [go-gl](https://github.com/go-gl/gl) (OpenGL 4.1 Core) · [GLFW](https://github.com/go-gl/glfw) · [mathgl/mgl32](https://github.com/go-gl/mathgl) · [go-perlin](https://github.com/aquilax/go-perlin)

## Setup (Ubuntu)

**Go dependencies** (fetched automatically by `go run` / `go mod download`):

| Module | Purpose |
|--------|---------|
| `github.com/go-gl/gl` | Generated OpenGL 4.1 Core bindings via cgo — all draw calls, shader compilation, buffer uploads |
| `github.com/go-gl/glfw/v3.3/glfw` | Window creation, OpenGL context, keyboard/mouse input via the GLFW C library |
| `github.com/go-gl/mathgl/mgl32` | Vectors, matrices, and projection helpers tuned for OpenGL (column-major `Mat4`) |
| `github.com/aquilax/go-perlin` | Perlin noise used by the terrain generator for fractional Brownian motion height maps |

**System dependencies** (C toolchain + OpenGL + X11 headers required by go-gl/GLFW):

```sh
sudo apt-get update
sudo apt-get install -y gcc libgl1-mesa-dev xorg-dev
```

**Go 1.26 or later** — the apt package is typically too old, so install from snap or the official tarball:

```sh
# snap (simplest)
sudo snap install go --classic

# or: download tarball from https://go.dev/dl/ and extract to /usr/local/go
```

Verify: `go version` should print `go1.26` or higher.

**ffmpeg** (only needed for `--output demo.mp4`):

```sh
sudo apt-get install -y ffmpeg
```

## Setup (Windows)

go-gl uses cgo, which requires a **64-bit GCC**. The old MinGW that ships with many Windows tools is 32-bit and will produce a cryptic linker error.

**1. Download a 64-bit GCC** from [WinLibs](https://winlibs.com/) — pick the UCRT, POSIX threads, SEH build, e.g.:

```
winlibs-x86_64-posix-seh-gcc-14.3.0-mingw-w64ucrt-12.0.0-r1.zip
```

Extract the zip to a permanent location (e.g. `C:\mingw64`).

**2. Add to PATH** — add `C:\mingw64\bin` to your *User* PATH, and make sure it appears **above** any existing 32-bit MinGW entry (e.g. `C:\MinGW\bin`).

**3. Verify** in a new PowerShell window:

```powershell
gcc -dumpmachine   # must print x86_64-w64-mingw32
```

**4. Install Go 1.22+** from https://go.dev/dl/ (Windows AMD64 MSI).

**5. Set environment variables** (User scope):

| Variable | Value |
|----------|-------|
| `CGO_ENABLED` | `1` |
| `CC` | `gcc` |

**ffmpeg** (only needed for `--output demo.mp4`) — download from https://ffmpeg.org/download.html and add the `bin/` folder to your PATH.

## Running

```sh
# Interactive window
go run .

# Scripted 20-second demo flythrough (window)
go run ./cmd/demo

# Render demo to video (requires ffmpeg in PATH)
go run ./cmd/demo --output demo.mp4
```

## Project layout

```
go-minecraft/
├── main.go                   # entry point: constructs config, wires FlyController
├── cmd/demo/main.go          # scripted demo: window or video output
└── internal/
    ├── engine/
    │   ├── config.go         # Config with WindowConfig, render.SkyConfig, render.FogConfig sub-structs
    │   ├── engine.go         # Engine: owns window, renderer, chunk manager; Run / Step / Snapshot
    │   ├── controller.go     # Controller interface; FlyController, StaticController
    │   └── chunks.go         # ChunkManager: generation pool, mesh pool, load/unload
    ├── render/
    │   ├── config.go         # SkyConfig, FogConfig with defaults
    │   ├── renderer.go       # multi-pass frame: opaque → sun → clouds → water
    │   ├── shader.go         # GLSL compile/link; go:embed directives
    │   ├── chunk_mesh.go     # ChunkMesh: 6-float vertex layout, opaque+transparent draw
    │   ├── quad_mesh.go      # SunMesh, CloudMesh: shared 2-float quad upload/draw helpers
    │   ├── texture.go        # texture atlas (go:embed + image/png)
    │   ├── rendertarget.go   # FBO + ReadPixels for headless/offscreen rendering
    │   └── shaders/          # GLSL source files (embedded at compile time)
    ├── mesher/
    │   ├── mesher.go         # BuildChunkMesh: face culling, atlas UVs, opaque+water split
    │   ├── faces.go          # data table of 6 face templates (no switch statements)
    │   └── pool.go           # bounded worker pool for parallel mesh building
    ├── terrain/
    │   ├── generator.go      # deterministic chunk generation: fBm height, biomes, sea level
    │   ├── noise.go          # Perlin fBm helpers
    │   └── pool.go           # bounded worker pool for parallel chunk generation
    ├── world/
    │   ├── block.go          # BlockID type and constants
    │   ├── block_props.go    # per-block properties and atlas UV offsets
    │   ├── chunk.go          # fixed [16×256×16] block array; immutable after generation
    │   └── world.go          # map[ChunkPos]*Chunk, coordinate helpers
    ├── camera/
    │   └── camera.go         # free-fly camera: LookAt, ProcessMovement, ProcessMouse, Rotate
    ├── input/
    │   └── handler.go        # GLFW callbacks, RWMutex, mouse delta accumulation
    └── window/
        └── window.go         # GLFW init, OpenGL context, LockOSThread in init()
```
