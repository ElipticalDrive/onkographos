A2. The reflection is a real mirror of the local water datum. New file: src/rendering/planarMirror.ts.
Plane height. The mirror plane is the sheet under the camera (sampleWaterSheetY), not WATER_LEVEL = 0.5. The waterLevel prop now means the sheet's offset above the path, which is what it always was for forces.
Mirror math. It uses Reflector / ReflectorNode math with an oblique near plane, with the right depth range for WebGL and WebGPU. No renderer.clippingPlanes are involved, so clipping works on the node Renderer too (2c).
Left↔right flip. The suspected flip is real. A camera built from a reflected position, target and up vector has its right axis negated. The GLSL and TSL water shaders now sample at u' = 1 − u, which is exact for symmetric projections.
planarMirror.test.ts puts the camera on a riverbank with the datum at Y −137. It checks that a point's reflection lands where its mirror image projects on the main camera's screen, and that geometry below the plane is clipped, on both coordinate systems.
Depth. The render target has a depth buffer. An archived note says depthBuffer: false was part of an old glBlitFramebuffer fix. This target is not multisampled, so nothing blits it.
A3. The TSL fallback really falls back.
createGameRenderer's GLSL fallback pins the session to glsl (reason: 'renderer-fallback') before any host resolves. resolveMaterialBackend() reads the pin first, and remounts don't retry the node renderer.
If a host already resolved tsl in this session, the factory throws MaterialBackendFallbackError. App then sets the backend to glsl (new Canvas key, so a GLSL remount) without recording a boot failure.
App's renderer request and the DebugPanel use the new requestedMaterialBackend(), which does not count as a host. After a fallback the panel shows "node renderer failed to start — GLSL fallback for this session" instead of the mismatch warning.
Phase B, the parts done here
B1, one shadow render per frame (GLSL). The composer's scene pass (SceneRenderPass) turns shadowMap.autoUpdate off for the rest of the chain, so SSAO's normal pass no longer re-renders soft-PCF shadow maps. driver.render() restores it in a finally. The reflection render also skips the shadow update. Per-light shadow updates on the node path are per camera; that path is not changed here.
B2, cheaper reflection.
Water sits on WATER_SURFACE_LAYER. FlowingWater enables that layer on the main camera, and the mirror camera's mask leaves it out, so the scene.traverse is gone.
The target is half the drawing buffer, aspect kept and capped by the LOD budget.
The render is skipped (strength published as 0) while the camera is below the datum or no frustum corner reaches below it.
The frame loop allocates nothing.
The pass is now a lazy chunk, mounted only on High/Ultra.
B3. Effect presence (SSAO, god rays) comes from the effective LOD quality (effectsForLODQuality), like the AA tier. An adaptive High → Medium drop now sheds SSAO.
