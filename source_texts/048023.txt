Description
3D tetrahedral meshes of male human torso including the heart, suitable for finite element calculations of cardiac electrophysiology and electromechanics. This repository includes a variant with a subdivided right ventricular outflow tract (RVOT).
The cell array named `Material` included with each mesh labels the organs as tabulated in the file `material.tab`.
