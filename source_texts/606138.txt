The flickering is actually produced by the moving boat. So there is certain angles, where the culling does not work properly.
I was playing arround for days tracing down the problem. I could not manage to reproduce it in a new project that I can share, but I could fix it by doing this:
In the OceanPlanarReflection.cs on line 191 the cullingMatrix is calculated:
_camReflections.cullingMatrix = _camReflections.projectionMatrix * _camReflections.worldToCameraMatrix;
And for some reason, which I do not understand, it is done again after the rotaion is set at line 202.
By removing line 202 I could get rid of the flickering reflections.

Thanks for reporting.
It looks like its set to the culling matrix from the current camera first, then set to what i would think is the correct matrix in the second step. It should be easy to verify by placing some objects in a scene and moving the camera around and watching the reflection, to see which culling matrix is correct (without baked occlusion). This stuff is also based heavily on Unity's planar reflection script from way back (i have a feeling its in the Environment standard assets pack), so we should check there and see if they do the same thing, or if its a bug we've introduced.
What we have (using the second culling matrix) has worked well so far, but we have not tested much with baked occlusion i think. I wonder if there is something here. On that topic - there is an alarmingly-similar issue described here: https://forum.unity.com/threads/water-reflections-occlusion-culling.322379/ . From 5 years go though.
When we've had a chance to play around with it myself or one of the others will post back. let us know if you find anything in the meantime.
