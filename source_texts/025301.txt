Problem Statement
Kitware's webinar What's New in VTK-wasm (slides) covers where VTK-wasm stands today:
VTK-wasm runs the VTK C++ rendering pipeline in the browser through WebAssembly. It can be used from JavaScript, Python, and trame.
JavaScript developers can build standalone 3D visualization apps that run only in the browser.
trame apps can move rendering from the server to the client with vtklocal.LocalView.
Existing VTK C++ apps can be ported or wrapped to run natively in the browser.
The main live demo is volume rendering in the browser.
pyvista-wasm only renders surface geometry today (add_mesh, add_points). It has no ImageData and no Plotter.add_volume. So the use case the webinar highlights most, volumetric scientific data such as CT/MRI scans and simulation fields, can't be done with pyvista-wasm. The webinar shows VTK-wasm can already do it.
Proposed Solution
Add volume rendering that follows PyVista's API:
Add a pyvista_wasm.ImageData dataset with dimensions, spacing, origin, and point/cell data arrays.
Add Plotter.add_volume(volume, scalars=None, cmap=None, opacity="linear", clim=None, show_scalar_bar=True). Back it in the TypeScript glue layer with vtkSmartVolumeMapper (or vtkGPUVolumeRayCastMapper), vtkVolume, vtkVolumeProperty, vtkColorTransferFunction, and vtkPiecewiseFunction.
Support PyVista's preset opacity transfer functions ("linear", "sigmoid", "geom", and the others), plus custom opacity arrays.
Add an example dataset that works well for volume rendering, such as examples.download_head() or examples.load_frog_tissues(), so docs and JupyterLite can show the feature.
Alternatives Considered
Use contour() / threshold() to extract isosurfaces and render them with add_mesh. This loses the semi-transparent look of volume rendering, and every new isovalue needs another round trip through filtering.
Render on a server and stream images, like trame's remote rendering. This goes against pyvista-wasm's goal of running entirely in the browser.
Example Usage
```
import numpy as np
import pyvista_wasm as pv

grid = pv.ImageData(dimensions=(64, 64, 64), spacing=(1, 1, 1))
x, y, z = np.meshgrid(*(np.linspace(-1, 1, 64),) * 3, indexing="ij")
grid.point_data["values"] = np.exp(-(x**2 + y**2 + z**2) * 4).ravel(order="F")

plotter = pv.Plotter()
plotter.add_volume(grid, scalars="values", cmap="viridis", opacity="sigmoid")
plotter.show()
```
