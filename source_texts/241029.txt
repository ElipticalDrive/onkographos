Description
Adds WebGL-based Gaussian splat rendering to pyvista-js for visualizing 3D Gaussian Splatting and NeRF scene representations.
Implementation
Reader and Mesh Classes
GaussianSplatReader: Loads .ply and .splat files with Gaussian parameters (position, scale, rotation, opacity, spherical harmonics color)
_GaussianSplatMesh: Mesh subclass that stores splat data and generates rendering code
Supports both ASCII and binary PLY formats (little/big endian)
Data Processing
Python: Extracts positions for bounding sphere calculations
JavaScript: Parses complete splat data with property layout detection from PLY header
Transformations: exp() for log-space scales, sigmoid() for opacity, spherical harmonics to RGB for color
Integration
Compatible with existing pyvista-js rendering pipeline via vtk.js
Full test coverage with sample data and error handling tests
Usage
```
import pyvista_js as pv

# Load Gaussian splat data
reader = pv.GaussianSplatReader("scene.ply")
splat_mesh = reader.read()

# Visualize
plotter = pv.Plotter()
plotter.add_mesh(splat_mesh, style="points", point_size=10)
plotter.show()
```
PLY Format
Expected properties: x, y, z (position), scale_0/1/2 (log-scale), rot_0/1/2/3 (quaternion), opacity (pre-sigmoid), f_dc_0/1/2 (SH coefficients).
