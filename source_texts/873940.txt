In this PR, I've added an ellipsoid.py file which contains all the helper functions neccessary to align and center the point cloud with respect to the x, y, and z axes. I've also edited io.py to use a wrapper function to call the COLMAP export functions (write_points(), write_images(), and write_cameras()) in that order. Finally, I've added a unit test to ensure that the se3.js constructor properly creates a pose matrix given rotation and translation matrices.
