Today each shading point picks one of the nearby block lights at random (plus ReSTIR for block lights). In rooms and caves with many torches, lanterns, glowstone or lava, most picks land on lights that barely reach the point, so the direct light from them is noisy.
Next-event estimation with adaptive targeting (NEE-AT, the light sampling in NVIDIA's RTX Path Tracing sample) learns, per screen tile or world cell, which lights actually contribute, and picks those more often. A feedback pass each frame updates the per-cell light lists.
What it changes for the player: less grain and fewer crawling spots in places lit by many block lights. The look does not change.
Notes:
Write it from the published technique; RTXPT's code is under the NVIDIA RTX SDK license and must not be copied.
Has to work with the existing ReSTIR for block lights, BedrockPointLights and emission (EmissionTiles).
Estimate: 3-5 days. Measure the denoised noise before/after at fixed views (like the Sobol runs on perf/rtxpt-techniques).
