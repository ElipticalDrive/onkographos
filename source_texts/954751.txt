This PR lets a PlayCanvas-style SOG LOD stream (GaussianSplattingStream) live as a part of a GaussianSplattingCompoundMesh, so streamed splats are depth-sorted and drawn together with the compound's static parts in a single interleaved pass — instead of as a separate mesh, worker, and draw call. The streaming engine keeps running its own LOD/eviction/relayout loop against a reserved region of the compound's shared atlas.
What's included
Hosted streaming — compound.reserveStreamingPart(...) reserves a row-aligned region of the shared atlas; the stream GPU-decodes into it at a base offset. Added via AddGaussianSplattingStreamPart(Async), returning the same GaussianSplattingPartProxyMesh as a static part (place / frame / gizmo / removePart all work identically).
Single sort/draw — per-part active-LOD ranges feed one global interval union; no sort-worker or render-shader changes were needed.
Full parity — multiple streaming parts, in-atlas memory-budgeted eviction, GPU defrag/relayout, and coexistence with static parts, all row-band-scoped so a shared static part is byte-identical across a relayout.
Voxel-IBL shadows for streamed splats (rotation/scale decoded into a shared half-float MRT).
Higher-order SH for streamed splats (baked into a shared packed-u32 SH atlas; reuses the existing draw path). Includes a WGSL processor fix to allow integer render targets on WebGPU.
Memory reclamation — removePart tombstones a streaming region (cheap); compactAtlas()
relocates survivors and frees the reclaimed rows.
Implementation highlights
Shared MRT atlas is simultaneously an FBO attachment and CPU-sub-uploadable on WebGL2 + WebGPU (no engine usage-flag change needed).
SOG up-axis lives on the part proxy's world matrix, so it composes with the compound transform.
Streaming regions are GPU-authoritative: atlas grow/compaction backs up and restores their texels and CPU sort positions via the work buffer's copy shaders.
Testing
Unit (NullEngine): reservation/row-alignment, interval-union math, capacity + SH validation, tombstone/compaction (incl. stale-range regression), removed-handle invalidation, WGSL integer detection.
Visualization (WebGL2 + WebGPU): Gaussian Splatting LOD COMPOUND, Gaussian Splatting LOD SH and IBL Shadows with committed reference images.
Cross-backend GPU spikes for Sigma reconstruction, relayout/compaction byte-consistency, IBL shadows, and SH; downstream viewer Playwright suite green.
Notes
GaussianSplattingStream remains usable standalone (unchanged public API); hosted mode is the new path. Requires WebGL2/WebGPU (float/integer render targets).

Fix stale uOffset in GS work buffer decode after compactAtlas
…
54bc658
```
Bind uOffset at render time from the live _baseOffset (alongside the
scissor) instead of in _apply*Pack at call time. compactAtlas() can
relocate a region during the deferred-decode window via setBaseOffset;
binding at call time left uOffset pointing at the old rows while the
scissor covered the new ones, so every fragment failed the shader range
test and the region was silently dropped despite decode reporting
success.
```

Recompute compound bounds after compactAtlas rebuild
…
12761d8
```
compactAtlas() rebuilds via _addPartsInternal, which computes bounds from
the zero-box placeholder sources it builds for reserved streaming parts,
then swaps the real proxies back — but nothing recomputed bounds after
the swap. A static-transform compound never flags bounds dirty, so the
stale (degenerate) bounds persisted and isInFrustum could cull the whole
mesh; a stream-only compound collapsed to a point. Mirrors the recompute
_tombstonePart already does. Placed after the tombstone set is cleared so
a survivor reusing a tombstoned index isn't skipped by the filter.

Adds a regression test asserting the cached bounds (the frustum-culling
path, which getBoundingInfo would otherwise lazily mask) reflect the
surviving stream after compaction.

Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>
```
Fix SH reuse guard reading stale _shMrtAtlasTextureCount
…
3657272
```
_canReuseCachedData compared _shMrtAtlas.length against
_shMrtAtlasTextureCount, but that field is only refreshed inside
_updateTextures — which the incremental path never runs. So reserving a
degree-1 SH stream then addPart-ing a higher-degree static part passed
the guard on a stale count, skipped growing the SH atlas, and appended
plain RawTextures into _shTextures (which then leaked). Pass the required
(merged sh.length) count into the guard and compare against that,
removing the write-after-read ordering dependency.

Also frees, as defence in depth, any _shTextures entries beyond the
MRT-backed set in both disposal paths (the _shMrtAtlas branch otherwise
skips the else-if that frees them).

Adds a white-box guard test (the real incremental path needs sub-texture
uploads NullEngine can't do).

Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>
```
Harden WGSL fragData output-type inference against false positives
…
7da3293
```
The inference scanned the raw fragment source with comments intact and
searched the whole file for the RHS identifier's declaration. So a
commented-out `// fragData0 = vec4<u32>(...)` above a real float write,
or a same-named integer local in any helper function, could flip a valid
float output to vec4<u32> and produce a WGSL compile error on a shader
that builds fine today — and this path runs for every WGSL fragment
shader that writes fragData.

Scan a comment-stripped copy and scope the declaration lookup to `fn
main`'s body up to the write (WGSL requires a local be declared before
use in its own scope). Sentinel checks (MRT_AND_COLOR, dual-source,
oitDepthSampler) intentionally stay on the raw source.

Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>
```
Size streaming write transients by count, not global atlas offset
…
1ceef0e
```
_writeStreamingSplats allocated covA/covB/colorArray sized to `end`
(globalOffset + count), so a small write near a large atlas's tail
allocated and zero-filled tens of MB per call (a 1M-splat model streamed
in 4k chunks churned ~19.5 GB) — imposed on the public writeSplats CPU
fallback with no opt-out.

Decouple the transient index from the atlas index: _makeSplat gains an
optional dstArrayIndex (default dstIndex) used for covA/covB/colorArray,
while dstIndex still addresses _splatPositions and the rotation arrays.
_writeStreamingSplats now allocates count-sized transients, fills them
from 0, and rebases the per-row upload offset by globalOffset. The
persistent rotation arrays are sized to the atlas (_splatPositions),
independent of the now-smaller covA. ~80 MB/call -> ~128 KB.
```

Match WGSL entry point exactly when scoping fragData inference
…
4f92656
```
The scope boundary used indexOf("fn main"), a substring match that
`fn mainHelper()` / `fn mainLighting()` declared before the entry point
also satisfy — setting mainBodyStart to 0 so the helper's integer local
is pulled into scope and flips a valid float output to vec4<u32>. And
Math.max(0, ...) silently turned a no-match into a whole-source scan (the
behaviour the scoping removed).

Match `\bfn\s+main\s*\(` exactly and gate the lookup on mainBodyStart >=
0, bailing to the vec4<f32> default on no-match. Adds regression tests
for a `main`-prefixed helper before main and a helper after main.
```
