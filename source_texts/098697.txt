Export Voxel Isosurface (Multidimension Tools)
Summary
Exports one or more isosurfaces from a voxel layer, scene layer package, or netCDF file.
Usage
Exports one or more isosurfaces to a single output multipatch feature class or each isosurface as an individual multipatch feature class in a geodatabase.
Continuous variables populate the Isosurface Definition parameter dropdown. These variables are based on double or floating point numbers as defined in the netCDF file. Discrete variables are not provided in the dropdown.
The spatial reference of the output matches the input voxel layer.
You can only provide a value for one output parameter; you cannot specify an Output Feature Class and Target Workspace parameter value at the same time.
When specifying the Target Workspace parameter, the output feature classes do not have exaggeration applied by default. Adjust the vertical exaggeration in the Elevation page of the layer properties, when added to a local scene.
Exaggeration and color are applied when the Output Feature Class parameter is specified and the output is added to the active local scene.
Output fields added to the feature class include variable name, isosurface value, surface area, local time and source time for time enabled datasets.
Check the Enable Time Export parameter for datasets that contain a time dimension.
An empty output warning appears if isosurface values are empty for an isovalue or time value when time is enabled. Examine the attribute table in the output feature class to determine which object IDs are empty for a given value.
Use the time slider with the output feature class to visualize isosurface values across time.
Datasets with irregular Z spacing may not match exaggeration of voxel layer. The layer properties Source page contains information on a voxel layers Z dimension. A Regular or Irregular value will be listed for Interval. Use the regularize Z script tool to fix irregular Z values.

Code sample
ExportVoxelIsosurface example 1 (Python window)
The following python script exports two isosurfaces to a single multipatch feature class.
```
import arcpy
arcpy.md.ExportVoxelIsosurface(
    in_dataset=r"C:\data\air_quality.nc",
    isosurface_definition="pm10 0.2;pm10 0.3",
    enable_time="TIME_DISABLED",
    out_feature_class=r"C:\data\isodata.gdb\air_quality_pm10",
    in_workspace=None
)
```
ExportVoxelIsosurface example 2 (Python window)
The following python script exports three isosurfaces as separate multipatch feature classes in a geodatabase.
```
import arcpy
arcpy.md.ExportVoxelIsosurface(
    in_dataset=r"C:\data\air_quality.nc",
    isosurface_definition="pm25 0.2;pm25 0.5;pm25 0.6",
    enable_time="TIME_DISABLED",
    out_feature_class=None,
    in_workspace=r"C:\data\isodata.gdb"
)
```
