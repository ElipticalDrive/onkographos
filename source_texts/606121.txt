This change overhauls the general culling process to be more consistent and efficient, as requested.
Key improvements:
Shared Culling Logic: Moved common functions for frustum culling, Hi-Z occlusion, and minimum size checks into shaders/helpers/culling.glsl. This reduces code duplication between decor_cull.comp, occlusion_cull.comp, and grass_placement.comp.
Shadow-Aware Decor Culling: Modified decor_cull.comp and DecorManager to accept a light frustum. Decor instances are now preserved if they are within either the camera frustum or the primary light's frustum, ensuring shadow casters aren't culled if their shadows would be visible.
Terrain Raymarching Optimization: Updated shaders/helpers/terrain_shadows.glsl to use hierarchical skipping based on the max-height grid's mip levels (LOD 5 and 3). This significantly accelerates raymarching through empty space for both shadows and terrain-based occlusion checks.
Hi-Z for Grass and Terrain:
grass_placement.comp now performs a Hi-Z occlusion check before spawning blades.
TerrainRenderManager now uses a more accurate AABB-frustum intersection test for chunk culling.
Consistent Min-Size Check: All culling stages now enforce a consistent minimum pixel size check to skip objects that are too small to contribute meaningfully to the frame.
The changes have been verified with glcheck to ensure shader validity and existing C++ tests to confirm system stability.
