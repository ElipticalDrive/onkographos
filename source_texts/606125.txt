Summary
Surfaces the meshlet object-stage cull effectiveness as a HUD number. Previously the survivor count was decided on-GPU (SIMD compaction → set_threadgroups_per_grid) and never read back, so there was no way to tell how much the frustum / backface-cone / cluster-LOD cull was actually removing.
Rebased onto main after #62 (the meshlet pipeline) merged — this is now a standalone change on top of it. The survivor counter sits at object buffer(9); the Hi-Z occlusion added in #62 uses buffer(10), so they coexist without collision.
What it does
Object shader: after each object threadgroup computes its survivor count, lane 0 atomic-adds it into a small GPU-write/CPU-read counter. Gated by a statsEnabled flag on MeshletParams so only the main pass accumulates — the depth pre-pass leaves it 0 and never binds the counter, so the number reflects the main pass alone.
Renderer: reads the counter back best-effort (~1 frame stale, single shared buffer read-then-reset, matching the existing GPUDRV/cluster-histogram readback pattern), and shows Cull: S / T survive (P%) in the Meshlet panel — T is the CPU-known submitted meshlet count, S the GPU survivor count. Counter is zeroed at creation to avoid a garbage first read.
FrameStats gains meshletTotal / meshletSurvivors.
Now the cull is measurable: move the camera (or toggle Hi-Z occlusion) and watch the survivor % drop as frustum/cone/LOD/occlusion cull more — useful for evaluating the meshlet path against CPU whole-object culling on heavier scenes (e.g. Intel Sponza inside the arcades).
Scope / notes
Metal only — the atomic lives in the MSL object shader; Vulkan's Meshlet.task has no such binding and the path is inactive on MoltenVK. The readback/bind and statsEnabled are gated on the Metal backend.
Best-effort gauge, not a per-frame-exact value (documented in-code).
No new render passes; the counter is populated during the existing meshlet draw.
Verification
MSL isn't compiled in this environment — the macOS CI xcrun metal step compile-checks the shader. On device: enable Meshlet mode and confirm the Cull: S / T line moves as you change the camera / occlusion toggle, with no frame-time or visual regression.
