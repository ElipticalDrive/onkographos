This PR adds several creative generation features for voxelizing meshes:
Twist: Using the --twist <amount> flag, you can twist the mesh along the Z axis, rotating vertices proportionally to their Z coordinates.
Taper: Using the --taper <amount> flag, you can scale the mesh XY coordinates proportionally to the Z coordinates.
Gyroid Infill Phase: By passing the --gyroid <scale> flag, voxelization calculates a procedural gyroid structure in 3D space. Voxels that fall inside the gyroid pattern are assigned phase = 1, while others remain 0. This is exceptionally useful for simulating lightweight interior infill structures.
XYZ Export: Adds .xyz as an output extension natively. Space-separated X Y Z coordinates only, matching common point cloud utilities without header overhead.
All features include CLI configuration matching Args through clap and seamlessly merge into MeshProcessor's processing pipelines. Tests pass perfectly.
