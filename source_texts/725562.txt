This submission addresses a broad overhaul of the Titan Voxel Engine to modernize it based on the STACK_2025_2026.md guidelines.
Key improvements:
Modernized to wgpu 23 and winit 0.30 architectures, allowing the app loop to function properly with ApplicationHandler.
Added multi-threaded meshing and map generation via rayon using a 3x3 Chunk grid instead of a single small block.
Implemented culling logic for faces inside mesher.rs to only render exterior voxels on all 6 faces, optimizing polygon counts significantly.
Fixed numerous compiler warnings across the repository.
Checked and verified WGSL shading logic for texturing.
