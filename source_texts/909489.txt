Summary
Reduce Bezier and spherical-harmonics overhead while retaining deterministic mathematical results and HDR reference outputs.
Changes
Evaluate native Vector Bernstein polynomials with one fresh result and reuse each adaptive polygon's chord.
Cache bounded immutable SH normalization layouts and reuse paired-order Legendre evaluations.
Replace analytical rotation generators with ordered three-term tuples while retaining builtin summation behavior.
Preserve sampling counts/depth, ownership, signs/indexing, validation and compensated projection.
Performance
Six paired blocks across two executions cover 33 workloads. Measured median gains include native cubic evaluation 4.25x, ordinary adaptive sampling 1.13–1.15x, L2 RGB rotation 1.75x, reconstruction 1.36x and angular projection 1.42x.
Scalar cubic evaluation incurs approximately 28 ns (11%) dispatch overhead. The SH cache retains memory. Depth-cap timing remains inconclusive. The report retains raw timings, intervals, profiles, allocations and these trade-offs; no universal speedups are claimed.
Testing
2,194 passed; 0 expected/unexpected failures; 0 skips, including 94 independent new regressions.
1,313 bit-identical result groups against merged PR Reduce Vector and Quaternion operation overhead #36, including complete sampled curves.
HDR regeneration matches all seven committed files, coefficients, selected linear values and decoded sphere pixels; golden outputs are untouched.
Clean wheel/sdist builds, isolated installed-wheel checks and fresh-checkout benchmark/HDR verification pass.
