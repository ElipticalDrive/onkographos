A new workbench page at /garage/, like /lab/. Open the taxi, orbit it, and paint on it. Save writes the skin into the repo, and the game draws it.
How it works
Paint is stored in 3D space, so there are no UVs. Each vehicle type has a small RGBA voxel volume over its own frame (src/util/paint.js). For the taxi that's 64×42×36 voxels, each 1/16 unit. The fragment shader looks the colour up by position, so a skin survives the code-generated geometry changing.
Paint is looked up at the rest position. Each painted vertex carries paintPos: where it sits with every hinge shut. Paint on the flank of a shut car is therefore on the door when it swings open, and the same goes for the bonnet and boot.
Shader: propMaterial({ paint }) runs after <color_fragment>. Paint replaces the vertex colour and keeps the material colour, so the wreck scorch and the highlight lift still apply. Lighting, AO, Crayon and Cartoon don't change. All skins share one program.
Paint modes: the alpha byte stores the mode (bare, tinted or fixed). Tinted paint picks up an ambient car's per-instance colour and fixed paint ignores it. That's groundwork for car and cop skins; the taxi only uses fixed.
Saving: a dev-server endpoint in vite.config.js writes assets/skins/taxi.json. HMR then repaints the taxi live in any open game tab, with no reload. A built bundle downloads the file instead.
Garage tools: orbit view and the game's own camera at play zoom, left/right mirror, colour pick, undo/redo, an hour slider, and toggles for the door and the boot/bonnet.
The shipped taxi.json is blank, so the game looks exactly as it did before.
Testing
npm run check is all green. The new garage step (18 checks) covers:
the codec round-trip;
paintPos matching each part's live transform chain at rest;
paint on a shut flank reading on the open door, while the door is physically elsewhere;
the shader patch finding every anchor in three's Lambert source.
Drove /garage/ in headless Chromium: painted the flank and roof, opened the door and lids, switched to the game camera, and saved. The file was written and the paint reloaded from disk. The game also boots with ?cartoon, ?crayon and ?ao=on with no shader errors.
tools/smoke.mjs scores 79/100 against both this bundle and the base branch, with the same pedal and route-drag failures in each. That's the headless environment, not this change.
Notes
The roof sign stays unpainted because its colour is a state (lit means a rider is aboard). The lamps, bumper and openings also stay unpainted.
The brush is a ball, so a big brush on the flank also catches the tops of the tyres.
The door glass sits 0.23 units off the cabin window, so paint on the window doesn't carry onto it. Paint the glass with the door open.
/garage/ ships to the web deploy like /lab/ and is excluded from the iOS build (tools/ios-sync.mjs).
Rollup now emits a third shared chunk (taxi-*.js). It's modulepreloaded from index.html, so the service worker still precaches it.
