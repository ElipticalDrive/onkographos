Pull request overview
Consolidates 3D volumetric-field isosurface rendering behind a new Isosurface class and MarchingCubesWrapper backend abstraction (with a default WASM marching-cubes implementation and a non-wired GPU path), and adds UI for color/opacity/triangle-sorting plus structure-switching fixes (camera reset, field cleanup).
Changes:
Introduce Isosurface / MarchingCubesWrapper and a new WASM marching-cubes implementation; gut Render3DFieldModule.js to delegate to them.
Add color, opacity, and camera-distance triangle-sorting controls to the field panel; hook camera-end events for sort updates.
Refactor structure switching to reset view, refresh field state, and trigger a re-render of the field on selection.
