Found while testing src/interaction/raycast.rs:132-144 (no existing issue): Raycast selects voxels touched only at an exact corner.
Cause
The raycast advanced through tied axis boundaries one axis at a time, checking side-adjacent voxels that the ray only touched at a corner. This could select a block the ray never entered.
Fix
Advance every axis whose boundary distance matches the nearest crossing before checking the next voxel. The regression test verifies that an edge-touching voxel is skipped and the diagonal destination is reached.
Verified
Regression test interaction::raycast::tests::exact_corner_crossing_skips_edge_touching_voxel: fails on main without the fix and passes with it (cargo test exact_corner_crossing_skips_edge_touching_voxel -- --nocapture).
cargo test --workspace passes.

Other raycast behavior and interaction code remain unchanged.
