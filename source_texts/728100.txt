Part of #365 / #159 Stage E.
This first diffuse-GI slice establishes the portable ray and hit contract without prematurely composing unfiltered one-sample GI into production PBR.
Implemented:
Runtime diffuse-GI pass using the existing camera/depth/surface-guide/TLAS contracts
deterministic temporally varying cosine-weighted hemisphere sampling with CPU/HLSL parity
environment radiance miss/fallback result
authoritative TLAS-array-index to Runtime scene-instance mapping
compact committed-hit record in the current camera-relative frame for the upcoming shared history-radiance resolve
capability-driven no-op when RT or a cooked shader is unavailable
regression coverage for constants, deterministic sampling, hemisphere/unit-vector guarantees, shader identity mapping, and real-backend fallback initialization
Deliberately not in this slice:
previous-frame committed-hit radiance resolve
denoising/reconstruction
PBR composition
production shader scheduling/cooking in RuntimeSceneRenderer
Those remain subsequent #365 slices so VICE does not ship a noisy one-sample GI term or double-count existing diffuse IBL.
Exact-head macOS ARM64 and Windows x64 CI must be green before merge.
