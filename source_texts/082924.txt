Summary
Bootstrap the repository with CMake + Ninja, FetchContent dependencies (GLFW, glad GL 4.6, GLM, Dear ImGui, doctest), and Constitution-compliant directory layout with docs and READMEs.
Implement milestones 0–2: GLFW window with input, fixed-timestep app loop, GL 4.6 renderer with shader hot-reload (F5), ImGui debug overlay, free-fly camera, and a hardcoded 32³ test chunk.
Add CPU-side voxel mesher with per-voxel face culling, per-corner ambient occlusion (s1/s2/c rule), asymmetric quad flipping, 8-byte packed vertices, and sky-tinted directional + ambient lighting with distance fog.
Include doctest coverage for voxel indexing, AO truth table, quad-flip decision, and mesher face-count fixtures (6 / 10 / 54 / hollow shell).
Fix inverted mouse Y-axis for natural look controls.
Test plan
cmake -B build -G Ninja && cmake --build build succeeds (requires MSVC dev shell, Python 3 + pip install glad2 on first configure)
ctest --test-dir build passes (7 test cases)
Run build/game/game.exe from build/game/ — sky-blue clear color, test chunk visible
Fly around at 60+ fps (VSync off in overlay); WASD + mouse look feels natural (non-inverted Y)
Staircase/trench AO gradients are smooth with no diagonal creases (toggle AO debug with F2)
Shadowed areas are blue-tinted; distant geometry fades to sky color
F1 wireframe toggle, F5 shader hot-reload work
Confirm no glad/GL includes outside engine/render/
