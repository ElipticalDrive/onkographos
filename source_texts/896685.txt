## Overview

Procedural Worlds 3D is a fully playable Minecraft-style voxel engine written from scratch in Python. Every aspect — from the block registry and texture atlas pipeline to per-chunk mesh generation, Perlin-noise terrain, biome system, water physics, and UI state machine — is implemented in a single source file. The engine targets **60 FPS** with chunk-based rendering and face-culling optimizations.
