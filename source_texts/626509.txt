I know we are still about to discuss this, consider this PR an argument for doing it this way.
VoxelParticles reside in a VoxelParticleWorld, WorldObjects don't see them at all
VoxelParticles are drawn using instancing, all in one run
VoxelParticles checked for intersection with WorldObjects every 0.3s and removed if such occurs
Effective Buffer management (spatial locality)
More effective buffer-streaming. the mutable buffers are mapped to ram and update.
This is still WIP. Missing:
Tree structure in VoxelParticleWorld for preselection based on camera-frustum
Containing worldtree-node for voxelparticles for faster intersection-polling
Beside these flaws, this works really nice here, giving me steady hundreds of FPS in realistically filled scenes.
Try it out please and report if its working!
PS: The lags when shooting the normandy / the planet come from the splitdetector and sometimes the splitter.
