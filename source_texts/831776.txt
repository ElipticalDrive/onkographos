Summary
This PR removes the player chunk edge rounding (geometry beveling) feature from the voxel terrain system. This feature previously applied beveled geometry to the chunk containing the player's camera to create rounded silhouettes on greedy-merged quads.
Changes Made
Removed properties from AHktVoxelTerrainActor:
bEnableChunkEdgeRounding - toggle for the feature
ChunkEdgeRoundingBevel - bevel depth control (0.0-0.45 voxel units)
Removed member variables:
PlayerChunkCoord - tracks the current player chunk coordinate
bPrevEnableChunkEdgeRounding and PrevChunkEdgeRoundingBevel - change detection for live toggling
Removed methods:
UpdatePlayerChunkBevel() - main update logic that detected camera chunk changes and triggered remeshing
GetPlayerChunkCoord() - getter for current player chunk
ShouldBevelChunk() - predicate to determine if a chunk should be beveled
GetChunkEdgeRoundingBevel() - getter for bevel depth
Removed logic:
Removed UpdatePlayerChunkBevel() call from Tick()
Removed initialization of beveling state in BeginPlay()
Removed initial bevel application when chunks are loaded in GenerateAndLoadChunk()
Implementation Details
The beveling system used per-vertex offset streams (int16, 1/1024 voxel unit precision) that were applied only to silhouette edge vertices of the player's chunk. The shader would add these offsets to vertex positions to create the beveled geometry effect. This removal simplifies the meshing pipeline by eliminating the need to track and update the player chunk separately from the standard chunk streaming system.
