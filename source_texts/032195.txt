# Voxel Engine

A high-performance, from-scratch Voxel Engine designed for the **Raspberry Pi 4**, built with C++ and OpenGL ES 3.1.

## 🎯 Project Goals
- **Performance-First:** Optimized for ARM-based hardware (M1/M2/M3 Mac for development, Raspberry Pi 4 for deployment).
- **Future-Proof:** Designed with a Rendering Hardware Interface (RHI) to allow future migration to Vulkan or Metal.
- **Educational:** Implementing core voxel technologies (Chunking, Instancing, Raycasting) without a heavy third-party engine.
