# ComfyUI-RadixXR

View Idol's gaussian splats inside a ComfyUI node with [radix](https://github.com/sparkjsdev/radix).

`Radix Splat Viewer (XR)` takes a `MODEL_3D` splat file from `Create 3D File (from Splat)` and
renders it in an in-node WebGPU canvas. Orbit it with the mouse, then press **Open in VR** to run
the same scene as an immersive WebXR session: one splat renderer, re-sorted against whichever
camera is active — the desktop camera, then the XR camera while presenting. GPU sort on WebGPU,
worker sort on the WebGL2 fallback.

![Splat loaded into the node viewport](docs/node-preview.png)
![Same scene after dragging the orbit](docs/node-orbit.png)

The screenshots are a headless Chrome run of the Idol workflow: `webgpu-gl` sort, 4000 splats, the
viewport sized to the node.

## Requirements

- **WebGPU** for the GPU splat sort. Without it radix falls back to WebGL2 and sorts in workers.
- **WebXR** needs a secure context: serve ComfyUI on `http://localhost` or https. Over plain
  `http://127.0.0.1` or a LAN IP, `navigator.xr` is undefined and the button stays hidden. A headset
  browser, or [IWER](https://iwer.dev) emulating XR, both work.
- Chrome/Edge or Firefox with WebXR enabled.

## What radix reads

`Create 3D File (from Splat)` writes `.ply`, `.splat`, and `.spz`, and those carry spherical
harmonics in radix's own layouts. `.ksplat` is advertised by the node but radix has no ksplat
reader, so it errors with "unknown file format" instead of rendering nothing.

## Setup

`npm install` in this directory pulls three and radix, then copy the built modules into `web/`:

```sh
cp node_modules/three/build/three.module.js \
   node_modules/three/build/three.webgpu.js \
   node_modules/three/build/three.core.js \
   node_modules/three/build/three.tsl.js web/
sed -e 's/from "three\/webgpu"/from ".\/three.webgpu.js"/' \
    -e 's/from "three\/tsl"/from ".\/three.tsl.js"/' \
    -e 's/from "three"/from ".\/three.module.js"/' \
    node_modules/@sparkjsdev/radix/dist/radix.module.js > web/radix.module.js
```

The vendored copies are committed so the node works without a build step. Sort workers load
radix's core module from a blob URL inside `radix.module.js`, so no extra worker file is needed.

## Options

| Option | Effect |
| --- | --- |
| `preview_height` | Height of the viewport in the node; drag the node edge to resize further |
| `projection` | radix projection method: `ewa`, `3dgut`, `htgs`, `raygs` |
| `sh` | Spherical harmonics in GPU arrays: `ext`, `packed`, or `off` for base color only |
| `flip` | Flip Y, since splats are usually stored y-down |
| `xr_scale` | WebXR eye-buffer scale factor |
