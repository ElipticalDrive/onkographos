Add simple-compute-ray-tracing to New Graph, canvas Quick Add, configuration templates and the CLI/installed SDK. Its single editable compute kernel casts a pixel-center camera ray, tests every world-space triangle with a two-sided Möller–Trumbore intersection, retains the nearest in-range hit, then displays unlit material base color plus emission or the authored environment on a miss. The standalone graph ends in ToneMap → Export, with no authored hit buffer or accumulation.
The scene API already flattens primitive instances into world-space triangles. This educational template has no direct-light evaluation, shadows or indirect bounces. It retains the existing native Metal/Vulkan scene-compute requirement and native resource preparation. The generated persistent wrapper keeps the frozen TLAS binding live in its existing Dimensions.z == 0 ABI guard; RenderGraphRayPass::Initialize sets that field to one, so valid launches execute the authored triangle loop. Runtime formats, binding validation and device qualification stay unchanged.
