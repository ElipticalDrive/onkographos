Overview
Extension of Dual Contouring (DC) and Dual Marching Cubes (DMC) algorithms to accept optional precomputed inside-voxel vertex coordinates voxel_vertices $(M, 3)$, completely bypassing iterative QEF/Newton-Raphson solves and enabling high-speed learned or customized dual isosurface extraction.

Technical Documentation & Rigorous Verification: Dual Contouring & DMC with Precomputed Inside Vertices (v0.6.5)
1. API Usage & Executable Python Code Snippets
```
import torch
import conquer3d
from conquer3d.ops import dual_contouring, dual_marching_cubes

# 1. Prepare grid, active voxels, and signed distance field
# grid_vertices: (N, 3), voxels: (M, 8), sdf: (N,)
# voxel_vertices: (M, 3) precomputed inside-voxel coordinates matching grid_vertices frame

# 2. Fast Dual Contouring with Precomputed Inside Vertices (bypasses QEF SVD)
verts_dc, faces_dc = dual_contouring(
    grid_vertices=grid_vertices,
    voxels=voxels,
    sdf=sdf,
    voxel_vertices=voxel_vertices, # (M, 3) float32 on CUDA
    iso=0.0,
    quad_split=True # True for Delaunay triangles (F, 3), False for quads (Q, 4)
)

# 3. Dual Marching Cubes with Precomputed Inside Vertices (bypasses Newton-Raphson)
verts_dmc, faces_dmc = dual_marching_cubes(
    grid_vertices=grid_vertices,
    voxels=voxels,
    sdf=sdf,
    voxel_vertices=voxel_vertices, # (M, 3) float32 on CUDA
    iso=0.0,
    quad_split=True
)
```
2. Advantages & Core Capabilities
Fast-Path Kernel Dispatch for Dual Contouring: When voxel_vertices (M, 3) is supplied, DC completely bypasses iterative 3x3 Jacobi SVD QEF diagonalization and normal field interpolation, accelerating extraction by 1.3x - 1.7x.
Direct Learned & Custom Geometric Injections: Enables deep geometric models (e.g., Neural Dual Contouring / NDC) to predict inside-cell vertex coordinates and extract reconstructed 3D meshes without runtime optimization.
Strict 2-Manifold Topological Integrity in DMC: DMC preserves closed multi-contour cell decomposition, 2-pass edge emission, parallel Radix sort, and Delaunay quad triangulation with custom vertex positions.
3. Disadvantages & Known Trade-offs
voxel_vertices must have shape (M, 3) where M is the number of active voxel cells (voxels.shape[0]).
DMC Throughput Parity: In DMC, execution time is dominated by 2-pass multi-contour table lookups, edge instance emissions, and parallel Radix sort; therefore, precomputed vertices provide geometric customization with parity runtime (~1.0x), whereas the 1.3x - 1.7x speedup specifically benefits Dual Contouring.

5. Technical Insights & Architectural Decisions
In dc.cu, detect_active_voxels_kernel identifies active cells and bipolar edge counts in parallel with minimal register usage, compacting directly from voxel_vertices without temporary (M, 3) QEF buffer allocation.
In dmc.cu, dmc_extract_dual_vertices_and_edges_kernel assigns out_vertices[dual_vert_idx] = precomputed_vertices[m] directly while preserving closed contour edge pairing.
