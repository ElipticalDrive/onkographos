Adds ReferenceTraversal::GpuCompute, the GPU implementation of the RT1 reference path tracer required by the CPU/GPU reference rule. Compute kernels run the CPU oracle's whole integral on the device: median-BVH traversal with float32 ports of the oracle's slab and watertight triangle tests, masked opacity, light proposals (analytic, emissive triangles, environment), power MIS, visible-GGX/Lambert sampling, compensated roulette, and Kahan-compensated emission/direct/indirect accumulation. Every random value uses the oracle's Philox address, so both implementations trace matching paths. No native ray queries are needed; devices without compute reject with Unsupported.
API
EnableReferenceRendering(trace, reduce, options) takes the cooked renderer_reference / renderer_reference_reduce recipes and a new GpuByteBudget.
AdvanceReferenceCapture(capture, surface) submits one sample per pixel plus a reduction pass in a frame of surface; the one-argument form returns InvalidDescription when a dispatch is due, without failing the capture.
A 48-byte reduced status record is read back each sample; committed sums are read back at powers of two, every 16th sample, on failure and at the target. CopyReferencePixels / EncodeReferenceHdr return the latest read-back image.
Pixels commit independently: an invalid contribution keeps that pixel's sums, and the capture fails after the image is read back. A target-only update continues; other changes rebuild transactionally.
LUHDR01 flag 64 marks GPU-compute captures; scripts/reference-hdr reports gpu_compute.
Editor: the Reference capture window offers GPU compute alongside the CPU oracle and native ray queries.
Evidence (Apple M5 Metal, macOS 26.6, debug)
L6 fixture at 16×12, 64 spp — orthographic depth 4; perspective with directional/point/spot/area lights, depth 8, roulette from 2; single bounce: largest CPU/GPU RGB distance 0.0 for every AOV. Closest, null-BSDF and roulette counts equal; visibility differs by 1 of 11,661 (a shadow contribution rounding to zero in one precision).
~8.8k-triangle glossy metal sphere plus a masked, linearly filtered sRGB textured quad (32×24, 16 spp): max 3.8e-5, RMS 1.4e-6, identical query counts.
Editor lit viewport fixture (textures, point lamps): within the 0.002 threshold.
Target continuation equals a fresh capture bit for bit; LUHDR flag and null-surface retry covered.

Strict MkDocs, check-docs, build-api --bootstrap (no new gaps), check-wiki --documentation-only, docs/recipe/LUHDR Python regressions pass.
Not yet qualified: the kernels compile to SPIR-V and WGSL locally, but SPIR-V validation and Vulkan/WebGPU pixel parity first run in batch CI. One dispatch covers the whole image (no tiling), so very large dense scenes can approach device command timeouts.
