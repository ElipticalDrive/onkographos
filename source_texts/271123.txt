What
An optional rendering loss for the diffusion mode, diffusion.photom. It is off by default.
Each training step already predicts the clean grid (x0_hat). The new loss:
Decodes x0_hat (GSDiffusionModel.decode).
Renders it at the views of loss.photom.for (target views by default), through model_forward(gauss=...).
Compares the renders with the dataset's rendered images, using the deterministic model's L1 + 0.85·D-SSIM (loss.photom weights).
Adds weight times the result to the x0 loss.
Config (conf/train_gs.yaml):
```
diffusion:
  photom:
    enabled: false
    weight: 1.0
    t_range: [0.3, 1.0]   # per volume: its timestep averaged over the 6 layers must be in this range
    start_seconds: 0      # off until the train clock reaches this
    validate: true        # validations also log <set>/<name>/loss/photom (ungated, one-step x0 at the seeded t)
```
The intended ablations are each one override:
t_range;
start_seconds;
weight;
the comparison target: real images now, renders of the fitted grids later (not implemented).
Other changes
New logging: train/loss/x0 is now logged separately, because train/loss includes the photometric term when enabled. New keys: train/loss/photom, .../photom_l1, .../photom_dssim, .../photom_frac (fraction of volumes inside t_range), and the same loss/photom* keys in the validations.
Guards: with the loss enabled, data.num_views >= 2 is required when targets are rendered, and loss.background must be null. The images are premultiplied over black, and this path does no background compositing.
Spike skip: it now applies to the total loss.
Testing
I tested the new loss on the 3 local test grids, with the model replaced by a stub. The script is untracked, at bla/_test_photom.py.
Ground-truth x0: photometric 0.078 (L1 0.012). That is the floor set by the fits themselves.
x0 with 0.5σ noise: 1.03, and the gradient reaches x0_hat.
Gating:
t below the range gives 0;
a mixed batch gives the right fraction;
the validation form ignores t.
I have not yet run the full model with this loss on the cluster. That smoke comes after this PR.
