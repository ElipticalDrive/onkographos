Problem and resulting behavior
Support direct scalar-field callbacks and reconstruction from contacts, signed-distance samples, inside/outside constraints, and normals. Do not require a known distance function to infer a domain.
Dependencies
#4, #3
Acceptance criteria
Common scalar/batch evaluation and optional gradients; distinguish implicit fields from guaranteed distance fields.
Finite bounds and sampling tolerances for callback reconstruction/extraction.
Weighted observations, orientation constraints, and documented paths for inequalities and fault constraints.
Evaluate compact support, hierarchical, and partition-of-unity approaches against a dense small-problem oracle.
Classification and surface extraction have explicit topology, boundary, and approximation behavior.
Test duplicate/conflicting constraints, degenerate geometry, extrapolation, and scale beyond RAM.
Design contracts
The repository architecture and benchmark contracts are being developed under docs/rewrite/. Performance claims require matched statistical quality, recorded resource use, and reproducible inputs.

Added bounded partition-of-unity Hermite RBF reconstruction to the replacement crate. This advances M2; the issue remains open.
domains::partition::PartitionRbf accepts explicit spherical patches, streams coverage validation and spatial constraint queries, fits coordinate-normalized Gaussian Hermite models, and blends them using Wendland C2 weights. Gradients include derivatives of the normalized weights. Every derivative location must also have a scalar observation, which is necessary for unsmoothed Hermite interpolation to survive blending. No implicit zero-value assumption is made. Smoothing weights refer to radius-normalized functionals, as documented by the API.
Local system size and overlap are capped. Empty/overfull patches, holes, duplicate functionals, singular systems, failed true-residual checks, source failures and cancellation return errors without a partial model. Canonical constraint ordering preserves successful results across source traversal orders and worker-pool sizes. Current patch fitting is serial. Input can stream, but fitted coefficients and the patch index remain resident.
The dense reference now releases its quadratic workspace reservation after fitting and retains only its model-payload reservation. Fused value/gradient evaluation uses one Gaussian exponential per constraint instead of separately repeating it for each derivative.
Generated curved-surface benchmark, Apple M4 Max, three processes:
262,144 surface nodes provide 1,048,576 scalar/derivative constraints.
65,536 local patches; at most 52 constraints per local solve; 3,397,636 retained constraints including overlap.
Median fitting: 5.74392 seconds, including coverage, source queries, solves and residual checks.
Median 10,000 held-out value/gradient predictions: 44.8557 ms.
Peak process RSS: 327,516,160 bytes; retained logical reservation: 251,003,136 bytes.
Held-out value RMSE: 0.000902326; gradient-component RMSE: 0.0111009. Maximum errors are 0.00627304 and 0.0877686 respectively. No wrong signs at the tested nonzero surface offsets.
Every numeric result/checksum repeats across all three runs. The fixture is generated from an analytic function and requires no proprietary data. It is not an exact signed-distance field or a beyond-RAM demonstration.
Six new tests cover Hermite interpolation, analytic gradients against finite differences, patch-boundary continuity, an independent single-patch dense reference, source-order/worker repeatability, coordinate scales 1e-100 through 1e100, smoothing and memory accounting, invalid/orphan/duplicate constraints, resource bounds and failure propagation. Validation passed 128 workspace tests, four doctests, ten Python tests, strict core Clippy, formatting and whitespace checks. Four device-required tests were ignored in this CPU validation.
Evidence: docs/rewrite/domain-partition-results.json and docs/rewrite/benchmarks.md, including source/executable/lockfile identities and raw-report hashes. Current stable faer/rstar are reused; no new dependency was needed. General PU construction reference: https://epubs.siam.org/doi/10.1137/24M1663843. This does not reproduce that paper's automatic clustering, polynomial enrichment or distributed implementation.
Remaining: automatic covers/shape parameters, polynomial precision, flat-kernel stabilization, faults/inequalities, irregular geological contacts, parallel fitting, durable out-of-core models, surface extraction and topology validation. The implementation is local, not merged or released, and does not establish fastest-library performance.
