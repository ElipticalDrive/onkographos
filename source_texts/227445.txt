Summary
Two changes on top of main (the earlier WindFire/CoronalMassEjection/Eyeball/Marble work already landed via the reconciliation merge):
Metaballs — a new full-color effect ported from a Pixelblaze 2D pattern (ZRanger1, MIT). A few control points bounce inside a box; each pixel colors from a multiplicative voronoi distance field, so nearby blobs fuse instead of merely overlapping. Fire palette (deep-red→orange hue band, brightness shaped by 1.2 - wave(5·d)). The simulation steps at the original's fixed ~52 ms rate off the real clock, so motion is frame-rate independent. num_points / speed / splatter / edge are exposed as constructor kwargs; the multi-panel nodeId() branch is dropped. ~0.5 ms/frame at 64×64.
WindFire tweak — raise the flame's vertical base (_Yp offset -0.3 → +0.4) so the fire sits higher on the panel.
Registration (data-driven surface, canonical → 9 effects)
lib_shared/config/effects_settings.json (Metaballs enabled)
browser-preview symlink + heart-message-manager/py-config.toml
heart-matrix-controller/README.md
count/name-set tests bumped 8→9 (effects_settings_test, effects_loader_test, patterns_import_test, api_config_validation_test)
Testing
Validated locally: all 9 canonical effects resolve via dynamic import; Metaballs constructs + ticks; blobs light/merge/split with a fiery palette; all touched files compile.
