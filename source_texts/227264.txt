What does this pull request do?
Adds kornia_3d::voxel on the host. Until now kornia-3d has had no voxel structure (#185).
VoxelLayout holds the voxel size and origin. Keys are exact: floor((p − o) / s) per axis, computed in f64 and stored as i32, negative keys included and range-checked. A reciprocal estimate falls back to the division near voxel boundaries, so the key is always floor(fl((v − o) / s)).
VoxelKey, VoxelConnectivity (6/18/26 offsets), VoxelError (thiserror), MAX_VOXEL_POINTS.
VoxelGrid<T> is a sparse std::collections::HashMap keyed by VoxelKey. It has insert / get / remove / iteration, sorted_keys, and neighbour iteration that skips keys outside i32.
VoxelView<'a> is a cloud grouped by voxel, borrowing the cloud: packed 128-bit (key, index) words are sorted, and the run starts give each voxel's point indices (a CSR of indices, ascending within a voxel). No point data is copied. API: len, is_empty, cloud, layout, key(v), keys(), centre(v), voxel(v) (iterator over the voxel's point indices), and the reductions:
first() / nearest() → PointCloudView<'a>: one input point per voxel (lowest index / nearest to the voxel centre, ties to the lowest index), zero copy;
centroids() → owned PointCloud (averaged points; colors rounded half up; normals renormalized), reduced in parallel over the voxels, each voxel in ascending index, so deterministic.
Built by VoxelView::new(cloud, &layout) (owns its buffers) or VoxelDownsampler::view(&mut self, cloud, &layout) (borrows the reusable scratch, so repeated calls do not reallocate the sort buffers).
voxel_downsample(cloud, &layout, mode) stays as the one-call wrapper: VoxelView::new plus the reduction named by DownsampleMode (Centroid, First, NearestToCentre), copied into an owned PointCloud, in ascending key order. VoxelDownsampler::downsample_into keeps writing the points (and chosen indices) into caller-owned buffers; it is the allocation-free slice form and the host twin of feat(3d): add the CUDA voxel filter #1243's device op.
voxel_neighbour_counts counts occupied neighbour voxels per point; remove_sparse_voxels filters on them and returns the kept points as a PointCloudView of the input.
kornia_3d::pointcloud::PointCloudView<'a>: a borrowed index subset of a PointCloud. PointCloud::select(indices) checks the indices and the attribute lengths once (FilterError::IndexOutOfRange, FilterError::AttributeLengthMismatch); a Vec<u32> is moved in, a &[u32] borrowed (Cow<'a, [u32]>). Accessors point(i) / color(i) / normal(i) (Option), allocation-free iterators points() / colors() / normals(), indices(), cloud(), into_indices(), and to_point_cloud() for the owned copy.
bench_voxel times downsample_into (3 modes), voxel_downsample with colors and normals (3 modes), the zero-copy view paths (view_first_cpu, view_nearest_cpu, view_centroids_attrs_cpu, view_first_to_point_cloud_cpu, voxel_view_new_cpu), remove_sparse_voxels returning its view and with the copy, and the 26-neighbour counts, on 100k / 1M points.

Departures from #1220:
voxel_downsample(cloud, &layout, mode) takes a VoxelLayout (voxel size and origin) instead of a bare voxel_size, so results can sit on a fixed grid. Open3D's grid is reproduced with origin = min_bound − voxel_size / 2; PCL's VoxelGrid uses [0.0; 3]. Both are stated in the rustdoc.
PCL was not available as a baseline. Open3D and NumPy were.

PointCloud::select(indices) returns a PointCloudView: the cloud,
borrowed, and the indices (moved in from a Vec or borrowed from a
slice), checked once; accessors and iterators read through without
copying and to_point_cloud() makes the owned copy. It replaces the free
select_points.

VoxelView exposes the voxel grouping VoxelDownsampler already builds
(sorted key/index words plus run starts): keys, per-voxel point
indices, centres, and the reductions first()/nearest() (a
PointCloudView of the input, zero copy) and centroids() (an owned
cloud, same arithmetic as before). VoxelView::new owns its buffers;
VoxelDownsampler::view borrows the scratch so reuse does not
reallocate. voxel_downsample stays as the one-call owned wrapper and
remove_sparse_voxels returns its kept points as a PointCloudView.
