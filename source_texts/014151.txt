Original video: This Tiny Algorithm Can Render BILLIONS of Voxels in Real Time
Original author: Deadlock
Release date: 2025-09-05
Video link: https://www.youtube.com/watch?v=ztkh1r1ioZo
00:00 Introduction
The video begins by introducing the topic, explaining that it will reinvent the voxel ray traversal algorithm from scratch to achieve real-time rendering of billions of voxels, and previews optimization techniques to improve frame rates.
01:06 What is a voxel
Explains the concept of voxels, analogizing them to pixels as the basic unit of 3D space, and introduces voxel data storage methods, including flattening functions for converting 3D coordinates to 1D indices and methods for converting spatial positions to voxel coordinates.
03:34 What is a ray
Defines the mathematical concept of a ray, represented by an origin and a direction vector, explains the meaning of the ray parameter t, and introduces the core idea of voxel ray traversal: checking voxels sequentially along the ray direction until a solid voxel is found or the grid is exited.
04:50 Naive method
Introduces a simple implementation of voxel ray traversal: starting from the ray origin, advancing with a fixed step size and checking voxels. Points out the issues of potentially missing voxels and inefficiency.
05:50 First voxel
Explains how to determine the first voxel intersected by the ray. If the origin is inside the grid, the voxel coordinates of the origin are taken directly; if outside, the Ray AABB intersection algorithm (slab method) is used to calculate the entry point of the ray into the grid, thereby determining the first voxel.
07:32 Next voxel
Describes how to find the next voxel intersected by the ray. Treating the voxel grid as a stack of axis-aligned planes, the intersection parameter t of the ray with each plane is calculated, and the t values are compared to determine the direction in which the ray exits the current voxel, thus obtaining the next voxel. This method is the fast voxel traversal algorithm proposed by Amanatides and Woo in 1987.
11:13 Rendering practice
Introduces the process of rendering using this algorithm. Using the Stanford bunny model as an example, it explains the need to voxelize it first, emit rays for each pixel via a compute shader, use the traversal algorithm to determine voxel intersection information, and provide data for basic shading, texture mapping, and secondary ray tracing.
12:13 Optimization methods
Introduces optimization techniques to improve performance. First, using a z-order curve to store voxel data improves spatial locality and cache utilization, increasing the frame rate from 12 FPS to 102 FPS; further, using GPU-specific 3D textures to store voxels achieves a frame rate of 121 FPS, a 10x performance improvement.
14:34 Summary and outlook
Summarizes the implementation process from voxel and ray definitions to a complete real-time rendering pipeline. Points out that there is still room for improvement, such as data compression and optimizing traversal using grid sparsity, and previews the next episode, which will introduce sparse voxel octrees and improved traversal algorithms.
