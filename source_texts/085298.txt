Need
Optimizations to improve quality, speed, and use cases of cinematic rendering features
Feature
CVR for multiple-component volumes: add the option to turn on/off various cinematic rendering techniques for individual component, or a selection of them, including gradient shading, volumetric shading, LAO, hybrid, etc. Right now user can turn shading on/off for each component.
Better noise texture: use blue noise instead of white noise to reduce unnatural artifact, and increase "randomness" for random number sampler.
Multiple scatter: improve algorithm in "multiple_scatter" branch to achieve interactive rendering with reasonable quality using multiple scatter. Reference for the implemented algorithm:
Path Integration for Light Transport in Volumes
Practical Rendering of Multiple Scattering Effects in Participating Media
Tentatively add pre-computed gradient texture and/or deep shadow map to increase interactive frame rate.
