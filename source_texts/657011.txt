Pull Request Overview
This PR implements a comprehensive world generation system for a voxel-based game, replacing the previous basic terrain generation with a sophisticated biome-based approach using Perlin noise. The changes include a complete world generation pipeline with continental, erosion, and peak/valley noise layers, biome computation, cave generation, and tree placement.
Complete rewrite of terrain generation using custom Perlin noise implementation and spline-based height mapping
Implementation of biome system with 7 different biome types (Plains, Desert, Forest, Tundra, Swamp, Ocean, Mountain)
Addition of cave generation using 3D Perlin noise and tree generation in forest biomes
Enhanced debugging capabilities with heightmap/biome map exports and expanded UI controls
