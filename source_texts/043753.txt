Please write a brief description of the application area of project
Modern game engines such as Unreal provide incredible graphical fidelity for video games, providing features such as Raytracing and many other effects to produce stunning scenes. Why not use this for scientific visualization? This is not a new idea and there are some companies who use game engines for non-gaming professional visualizations.
Please describe the project.
The idea of this project is to develop an open-source visualization tool for scientific data that is based on a modern game engines and can be used as a stand-alone application to load various typical scientific data formats and visualize them professionally with advanced lighting effects and other options to produce stunning visualizations.
We are open in what game engine we want to use. Unreal Engine is most advanced but also a serious heavy-weight. Also available are Unity (though license situation would need to be clarified) and open-source engines such as Godot or Bevy which are graphically not as advanced but have easy to work with licenses.
What will be the outputs of this project?
The Minimum Viable Product for this project is to develop an app that provides visualizations of simple surface meshes, and other similar data (e.g. mesh plots of functions). Once this works we can look at full volume meshes, slices, and other advanced features. Eventually we would like to provide most of the functionality that tools such as Paraview offer, which are based on the well established VTK library for scientific visualization but which does not have the advanced graphical features of game engines.
