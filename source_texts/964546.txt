Ce que fait cette PR
L'éclairage PBR (#124) : la BRDF de Cook-Torrance, un soleil, et les lumières ponctuelles lues dans le cluster du pixel (ADR-0024).
shaders/mesh.slang : distribution GGX, ombrage de Smith, Fresnel de Schlick, diffus de Lambert ; la normale inclinée par la normal map ; le soleil sur tout l'écran ; les lumières ponctuelles du cluster du pixel (clusterOf, le calcul inverse du tri), atténuées en inverse du carré jusqu'à leur portée ; une lumière ambiante en attendant l'IBL (M5.4).
setFrameLighting : les constantes d'éclairage, une fois par command list ; le frame binding set lit les lumières et les listes des clusters.
Le sandbox : un soleil de biais et huit lumières de couleur qui tournent autour du modèle.
La référence du cube du test de fumée est redessinée, éclairée.

Guide de lecture
shaders/mesh.slang : brdf, attenuationOf, clusterOf, puis fragmentMain.
engine/render/include/levain/render/mesh_pass.hpp : Sun, FrameLighting, setFrameLighting.
sandbox/src/main.cpp : demoLightsAt, et le tri dans renderFrame.
engine/render/README.md : la section « L'éclairage PBR ».
