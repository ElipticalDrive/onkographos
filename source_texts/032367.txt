Cloud simulation plays an important part in outdoors simulation.But in fact,it is not widely used just because of lower speed.To balance between real-time rendering and higher fidelity,BOX or DOME modeling method is always used in cloud simulation,which is neither vivid nor can pass through.There is another method to be chosen,that is,volumetric cloud.But unfortunately,it has the same disadvantages.To dealing with these problems,this paper discusses how to create a radiometry model for volumetric cloud simulation,by virtual of multiple forward light scattering.This model is so vivid that it even can provide argent cloud edges.In addition,an algorithm is given,integrating preprocessing and real-time computing.This algorithm makes full use of graphics hardwares,hence it can offer higher rendering speed and better real-time interactions.
