Summary
The resolve now averages each sample by the pixel's sample count instead of a fixed exponential weight.
```
 resolve
   fetch scene color, screen motion, and linear view depth
   fetch the reprojected sample count
-  mix(history, current, 0.9)
+  weight = count / (count + 1)
+  mix(history, current, weight)
+  count = min(count + 1, 512)
   reset count to 1 when the depth range rejects the history
   clamp the history to the 3x3 YCoCg variance box
```
The fixed 0.9 weight gave the eight jitter phases unequal weights, so a still image settled into a period-eight limit cycle. A reset now starts at count 1 (new-sample weights 1/2, 1/3, ...) and settles at 512. The count follows the reprojected surface; a depth rejection restarts it, so a disocclusion does not bake an edge pattern into the history.
The clamp changes from the min/max intersection to a 2σ variance box. The min/max box collapsed on flat neighborhoods and caused phase-dependent pops.
The harness gains a settle command that renders frames without writing a PNG. scenarios/taa-static.json now settles 520 frames, past the 512-sample cap, and gates 60 steady frames. scenarios/taa-motion.json moves the camera up the stairs, turns, holds, and gates the hold.
