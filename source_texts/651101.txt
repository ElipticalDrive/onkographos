What changed
New Organic Blob（ぷっくりブロブ） procedural preset from the model library, Add Shape … menu, and Japanese/English command palette.
Exposes sliders for protrusion strength, irregularity/lobe count, smooth SDF join, vertical aspect ratio, and deterministic random seed.
Generates a normal editable Group of 10–20 native sphere SDF primitives (base sphere + seeded asymmetric lobes). Reuses the existing SDF smooth union and GPU shader; no baked geometry, custom renderer branch or file-format change.
Off-thread 96×96 real CPU SDF preview, 140ms slider debounce, single outstanding preview worker, and stale-result suppression. No high-resolution meshing during parameter changes.
Applying inserts exactly one group using existing Undo/Redo and serialization. Existing sphere inspector, gizmos, Melt settings and STL/3MF export keep working.
Adds unit tests for deterministic seeds, finite parameters, all lobes attached, JSON round trip, editing, Undo/Redo, preset discovery, and an ignored heavy STL/3MF export+reimport integration test.
Adds apps/meltcad/ORGANIC_BLOB.md instructions and verification plan.
Known limitation
The preset's blend uses the scene-wide Melt mode/amount, as existing shapes do. At Melt amount 0, soft joins are disabled; the card warns rather than changing unrelated scene settings. Sliders configure the new blob before insertion. Afterwards every sphere remains editable; reopening an editable parametric history is not implemented.
Verification
Draft / not verified on a Rust/Windows machine. Source authored via GitHub connector. cargo, GUI screenshots, mesh export round-trip and hardware speed results have not been run here; no performance claims are made. Please run:
```
cargo fmt --all -- --check
cargo test --locked -p meltcad --release organic_blob -- --nocapture
cargo test --locked -p meltcad --release organic_blob_mesh_exports_roundtrip -- --ignored --nocapture
cargo test --locked -p meltcad --release
```
Then inspect the UI, default appearance, generated group/gizmo behavior and GPU/CPU silhouettes. No existing release or production branch was overwritten.
