# Medical Image Processing Tool - Run-Length Encoding (RLE) Compressor

A high-performance biomathematical software component written in strict ISO C99 designed to clear background noise from Computed Tomography (CT) scans using a custom threshold activation, followed by data volume minimization via loss-less Run-Length Encoding (RLE).

This tool is structured natively for production systems, fulfilling high-performance computing constraints with clean memory operations in Linux environments.

## Technical Features
- **Strict ANSI/ISO C99 Compliance:** Built using rigorous compiler checks (`-Wall -Wextra -Wundef -Werror -Wuninitialized -Winit-self`) to prevent pointer mismatches, memory leakage, or uninitialized state bugs.
- **Dynamic Heap Management:** Allocates continuous 1D hardware simulation buffers directly on the heap, optimizing cache coherence during element lookup operations.
- **Modular Code Architecture:** Separates definition blueprints (`compresor.h`), step-by-step algorithms (`compresor.c`), and execution contexts (`main.c`) handled through an automated build framework.

## Mathematical Formulation
The signal pipeline executes an initial background suppression step emulating a linear activation function (ReLU):

$$f(x) = \begin{cases} x & \text{if } x \geq \theta \\ 0.0 & \text{if } x < \theta \end{cases}$$

Where $\theta$ represents the clinical threshold ($0.40$). The output stream is then encoded into sequential paired sets $[C_i, V_i]$, where $C_i$ denotes consecutive identical item instances and $V_i$ represents the value magnitude.
