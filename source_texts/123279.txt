General course objectives:
To give the participants an overview of real time computer graphics systems (as they for instance appear in connection with CAD, VR, game engines, computer animation, 3D multimedia, and scientific visualization) and enable them to apply and develop graphics algorithms for visualization, modelling, and animation.
Learning objectives:
A student who has met the objectives of the course will be able to:
Apply an application programming interface such as OpenGL for program development
Access graphics hardware using shader languages such as Cg/GLSL
Define a 3D scene with different object types, light sources etc.
Apply diffent camera types and geometries for visualising the scene
Interact with the scene using various interaction techniques
Model light-material interaction for a surface and develop simple shaders
Simulate surface details using texture mapping and bump mapping
Simulate the environment using environment mapping
Simulate shadows and specular interreflections
Interactively edit simple 3D models
Animate camera and object positions
Use dynamic light settings
Content:
OpenGL as an API. Extended camera models. Transformations and projections.
Local contra global illuminations models. Hybrid methods.
Real time rendering: Shadow algorithms. Bump, reflection, environment and multi-texture mapping.
3D graphics cards and implementing vertex, pixel and unified shaders in GLSL/Cg.
Interaction techniques (picking, selecting, rubber banding, events).
Procedural modelling: Trees, plants, clouds, 2D- and 3D texture mapping.
Volume modelling. Boundary, CSG, Analytic (B-spline, Nurbs), and Voxel modelling (Volume sculpting, volume rendering)
Remarks:
Introduction course to computer graphics at the M.Sc. level.
The course runs along with 02562 and the two courses complement each other. However, you can attend both courses independently.
The course is a prerequisit for course 02563 and an optional prerequisit for 02566.
Bachelor student with interest in computer graphics may follow the course
