In order to create a more realistic cloud simulation environment, volumetric cloud modeling combined with real meteorological data is usually considered. At present, cloud simulation based on real meteorological data basically adopts physical modeling methods, such as solving fluid dynamics equations and particle system modeling, etc. However, these methods involve a large amount of calculation for solving calculus equations, so they are often limited in the scale of drawing, and it is difficult to perform real-time simulation in large-scale scenes. The authenticity and real-time performance of volumetric cloud simulation still need to be further improved. Therefore, through the analysis of existing research, a three-dimensional volumetric cloud construction method based on meteorological data is proposed. The specific method is to generate a two-dimensional cloud map based on humidity data, and then combine the cloud map with an improved height density function to make the shape and density of the cloud change with height and meteorological data, and combine it with multiple noises to construct the shape and details of the cloud. Finally, the Raymarching algorithm is used for rendering, and finally a large-scale volumetric cloud that matches the meteorological data is constructed. This paper combines meteorological data with non-physical modeling methods effectively. Experimental results show that the volumetric cloud modeled by this method matches the cloud map generated by meteorological data, and is more realistic in shape and appearance. The cloud body modeling results have more realistic details without distortion.
