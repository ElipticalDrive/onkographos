3D support for algorithms/math/intersection, plus a new @papit/gjk. Needed by rigidbody (#188) and arrow-style hit tests. Pure, no allocations in the hot path (out params), plain [x, y, z] numbers, existing 2D API unchanged.
Tasks
Shared types. Vec3, Segment, Ray, Plane, Sphere, Capsule, AABB3 where they're needed, same style as the 2D ones.
box: AABB overlap and point-in-box for 3D (any dimension by array length). Ray vs box (slab test).
circle → sphere: point-in-sphere, sphere vs sphere, ray vs sphere. The 2D circle crossing stays as it is.
line: closest points between two 3D segments (params + distance), segment vs capsule (arrow hits), ray vs plane.
triangle: closest point on a 3D triangle, ray vs triangle (Möller–Trumbore).
New @papit/gjk: support(direction) for sphere, box, capsule, point cloud (hull); GJK overlap + distance; EPA for depth and normal. Tests per shape pair, near-touching and degenerate cases.
sat: stays 2D, README points to gjk for 3D. polygon: stays 2D.
READMEs (complexity per function), CATALOG.
Each package gets real node:test tests, floats compared with a tolerance.
