This repository contains a dataset from three distinct experiments used to validate volumetric quantitative transmission Optical Coherence Tomography (vqtOCT) and demonstrate its advantages through a direct comparison with the well-established Holographic Tomography (HT) [1]. The experimental data were collected using a swept-source Mach-Zehnder-based system with angular scanning for three samples: a simple, well-characterized PMMA microsphere, a 3D-printed single-cell phantom [2] and a fixed HeLa cell line.  The deposited dataset is provided in the cloud-ready OME-Zarr format, archived as individual ZIP files (.ome.zarr.zip). For each of the three experiments, the dataset includes 6 such files: raw full-field transmission OCT data (object and background reference measurements) acquired for two illumination angles (2 files), phase and amplitude sinograms retrieved through HT and vqtOCT (2 files), and the final 3D RI reconstructions (HT and vqtOCT) calculated using the Gerchberg-Papoulis (GP) algorithm [3] with Rytov approximation (2 files). Each file is named according to its assigned Universally Unique Identifier (UUID). Technical and experimental metadata is inherently embedded and structured within the OME-Zarr files and the accompanying CSV database. The PNG files provide a 2D preview of the data stored in compressed OME-Zarr files.  The dataset can be seamlessly explored using the publicly available BioFile Finder web application. Please download and unzip the archive files before using BioFile Finder.
