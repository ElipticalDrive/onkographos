💡 What: In MeshProcessor::voxelize (solid mode), the logic was updated to fast-path exterior voxels (!is_inside) when narrow_band is None. It bypasses the expensive self.mesh.distance_to_local_point call and assigns a dummy positive SDF (1.0), which immediately fails the sdf <= 0.0 keeping condition.
🎯 Why: distance_to_local_point is an expensive BVH query. For solid voxelization without a narrow band, we only care about interior points (or points exactly on the boundary). Computing the exact distance for exterior points is wasted CPU time, as those points will always be discarded.
📊 Impact: Reduces BVH traversal overhead significantly by entirely skipping distance calculations for all exterior voxels when a narrow band is not specified. (Note: Benchmark improvements are heavily dependent on mesh size, resolution, and the ratio of bounding box volume to actual mesh volume).
🔬 Measurement: Verify by running the test suite (cargo test) to ensure output parity is maintained, and run cargo bench to observe the performance behavior on standard shapes.

In solid voxelization, the naive approach computed the exact BVH distance (`distance_to_local_point`) for all points. However, when `narrow_band` is not used, any point determined to be exterior (`!is_inside`) is subsequently discarded since its SDF will be positive, making `sdf <= 0.0` false.
This optimization skips the expensive BVH query for exterior voxels in this scenario, assigning a dummy positive SDF (`1.0`) directly.
