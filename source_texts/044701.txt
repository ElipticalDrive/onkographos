The operations and avatar displays now use a shared Canvas 2D renderer: a rotating cyan sphere with a gold corona, a colored module atlas, and a volumetric particle silhouette with a face view. Conversation styling matches the other displays. Module buttons still open their existing read-only details and amount masking remains enabled by default.
Automatic quality starts light, measures actual draw cost and frame intervals, increases detail when there is headroom, and falls back to light or economy when drawing slows. Manual light/detail choices remain available. Backing canvases are capped at 1920×1080; geometry is cached, hidden tabs cancel animation, paused scenes draw once without a busy loop, and reduced-motion changes are followed. The local server serves the new visual script under the existing session guard and CSP. No external runtime dependencies or new AI providers are required.
Validation: 41 desktop companion tests passed; the new renderer budget/lifecycle test passed; controller smoke checks rendered all scenes using native Canvas; JavaScript syntax, SHA256SUMS, and diff checks passed. The preview PNGs are actual Canvas exports, not browser screenshots or benchmarks on the user's Mac. Full browser layout verification is still unavailable here.
Particles and cluster links are decorative navigation, not measured neural activity. Phrase animation remains approximate and does not produce or synchronize audio. Instructions and developer preview exports are included.
