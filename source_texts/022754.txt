NIPS 2019
Motivation
Conventional geometric deep learning methods are memory inefficient as well as requires 3D supervision.
Key Idea
Represent scenes implicitly with continuous functions (MLP).
Differentiable Ray Marcher obtains the surface.
Per-Pixel Conv operation obtains the multi-view consistent RGB color.
Employ hyper-network with latent codes to generalize to multiple scenes of same class.
Previous Approach
Voxel grid, mesh, point cloud = discrete
Occupancy Field, SDF = Requires 3D supervision.
Method
Overview
Continuous Implicit Representation
Neural Rendering = Surface + Color
Ray Marching -> Surface
Pixel Generator -> Color
Apply 1x1 Conv to each feature vector output of 3D coordinate (x,y,z)
Generalize across scenes
To generalize across scenes of same class, train a hyper-network that maps lower dimensional latent vectors to continuous representation function parameters.
