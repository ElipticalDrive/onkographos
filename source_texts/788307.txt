# pcl_box_filter

A ROS2 package for filtering and downsampling point clouds from multiple cameras using a voxel grid filter and bounding box cropping. Visualize the filtered results in RViz.

## Features

- Subscribes to two camera point cloud topics.
- Applies bounding box cropping and voxel grid downsampling to each point cloud.
- Publishes filtered clouds to separate topics.
- Includes launch file for multi-camera setup and RViz visualization.
