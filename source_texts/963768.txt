Etape 39 — RTAO design
Algorithm
One cosine-weighted hemisphere ray per fragment per frame —
Malley's method (θ from sqrt(r₂)), the canonical unbiased Monte
Carlo estimator for the Lambertian AO integral
(1/π) ∫_Ω V(ω) cos(θ) dω.
Short TMax (AO_MAX_DIST = 2 m) — local contact occlusion only;
broader darkening would overlap with GI.
Shadow-style RayQuery with
RAY_FLAG_ACCEPT_FIRST_HIT_AND_END_SEARCH | RAY_FLAG_SKIP_CLOSEST_HIT_SHADER — we only need the hit bit.
No new BLAS or descriptor — reuses the existing TLAS and the
reservoir SSBO.
Denoising without a separate pass
Temporal: EMA with alpha = 1 / temporal_M (same alpha
derivation as the indirect-GI EMA — pre-spatial M so repeated merges
don't dilute the update rate below a single fresh sample).
Spatial: while the existing ReSTIR spatial-reuse loop iterates
neighbours, accumulate their ao values into
ao_spatial_sum / ao_spatial_count, gated by the same
reservoirSurfaceMatches() similarity test that controls the ReSTIR
merge (normal dot ≥ 0.906, position delta ≤ 1 m) so AO doesn't blur
across silhouette edges. After the loop,
r.ao = (r.ao + ao_spatial_sum) / (1 + ao_spatial_count).
Combined with temporal M ≈ 20 frames × up to 5 accepted neighbours,
effective AO sample count reaches ~100 — noise-free without a
dedicated filter pass.
Reservoir struct
Replaced the previously-unused indirect_pad (float, 4 bytes) with
ao (float, 4 bytes). Struct stays 80 bytes — the shading_pos +
shading_normal_oct fields added in PR fix: rendering audit — 20 critical/warning findings across shaders + Vulkan sync #97 were already laid out
with 16-byte alignment, so no repacking was needed.
Emissive-pixel early-out stores ao = 1.0 (self-lit surfaces aren't
occluded; combined with the M == 0 check in
reservoirSurfaceMatches, these reservoirs are rejected by
neighbours anyway — the 1.0 is defensive).
Composite changes (canonical AO application)
Split the ReSTIR direct lighting into direct_diffuse and
direct_specular. This is the same split my PR fix: rendering audit — 20 critical/warning findings across shaders + Vulkan sync #97 first commit
tried — but for a different, literature-backed reason this time:
AO represents diffuse-hemisphere visibility and must multiply the
Lambertian lobes only, per canonical PBR practice. Specular (analytic
Cook-Torrance), RT reflection, and emissive are not attenuated.
Final composite:
```
colour = (indirect_gi + direct_diffuse) × ao_factor
       + direct_specular
       + emissive
       + reflected_colour × F_view
```
When camera.emissive_count == 0 the whole ReSTIR path is skipped
and ao_factor defaults to 1.0, so AO has no effect — matches the
fallback-ambient branch's existing semantics.

── RTAO design ──

- One cosine-weighted hemisphere ray per fragment per frame (Malley's
  method — the unbiased Monte Carlo estimator for the Lambertian AO
  integral (1/π) ∫_Ω V(ω) cos(θ) dω).

  contributes — global darkening would come from broader GI.
- Shadow-style RayQuery: RAY_FLAG_ACCEPT_FIRST_HIT_AND_END_SEARCH |
  RAY_FLAG_SKIP_CLOSEST_HIT_SHADER — we only care if ANY geometry was
  within TMax of the surface.
- No new BLAS or descriptor — reuses the existing TLAS + the reservoir
  SSBO for accumulation.

── Denoising without a separate pass ──

- Temporal: EMA with alpha = 1 / temporal_M (same derivation as the
  indirect-GI EMA — pre-spatial M so repeated merges don't dilute the
  update rate below a single fresh sample).
- Spatial: while iterating neighbours in the existing ReSTIR spatial
  reuse loop, accumulate their AO values into ao_spatial_sum /
  ao_spatial_count (gated by the same reservoirSurfaceMatches()
  similarity test that controls the ReSTIR merge, so AO doesn't blur
  across silhouette edges). After the loop, blend: r.ao = (r.ao +
  ao_spatial_sum) / (1 + ao_spatial_count).
- Combined with temporal M ≈ 20 frames × up to 5 accepted neighbours,
  effective AO sample count reaches ~100 — noise-free without a
  separate filter pass.

── Reservoir struct ──

- Replaced the previously-unused indirect_pad (float, 4 bytes) with
  `ao` (float, 4 bytes). Struct stays 80 bytes. The prior shading_pos
  and shading_normal_oct additions (Etape 38 audit pass) were already
  sized for 16-byte alignment, so no layout rearrangement was needed.
- Emissive-pixel early-out stores ao = 1.0 (self-lit surfaces aren't
  occluded by AO; storing full visibility means neighbours picking up
  these reservoirs via spatial reuse don't get artificially darkened
  by an incompatible sample — combined with the M == 0 check in
  reservoirSurfaceMatches, these reservoirs are always rejected anyway).

  diffuse-hemisphere visibility, not specular visibility.
- Final composite:
  `colour = (indirect_gi + direct_diffuse) × ao_factor
         + direct_specular
         + emissive
         + reflected_colour × F_view`

  whole ReSTIR path is skipped and ao_factor stays at 1.0, so AO has
  no effect — matches the fallback-ambient branch's semantics.
