# Physically Based Rendering (PBR) Pipeline – Microfacet BRDF & Image-Based Lighting

This project was implemented as part of a Physically-Based Rendering Course and represents a rendering pipeline that uses microfacet theory and image-based lighting techniques.

The implementation includes:

- Cook-Torrance microfacet BRDF
- Schlick Fresnel approximation
- Beckmann Normal Distribution Function
- Smith Geometry function
- Environment reflection using cubemaps
- Diffuse and specular Image-Based Lighting (IBL)
- Monte Carlo precomputation of irradiance maps
- Gamma correction

## Project Objectives
The aim of the project was to implement a physically plausible shading model capable of:
- Simulating realistic material behavior
- Modeling rough and metallic surfaces
- Integrating environment-based lighting
- Supporting texture-driven material properties
