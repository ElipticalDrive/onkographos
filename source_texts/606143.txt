Summary
Meshlet-level Hi-Z occlusion culling on top of the instance-level system from #31. Off by default (Renderer::meshlet_occlusion_culling_ = false), and it only acts while occlusion culling and meshlet culling are both on, so merging does not change rendering.
Task shader: meshlet_task.slang tests each meshlet's world bounding sphere (wind padding included) against the Hi-Z in both depth prepass phases.
Record and replay: each prepass phase sets a bit per emitted meshlet in a per-frame bitset; forward replays those bits instead of re-testing, so it draws exactly the prepass winners and the EQUAL depth test stays exact. No single pyramid reproduces both phases' decisions, so a forward re-test could drop a prepass winner (a hole showing the HDR clear colour).
Late phase: late_cs gives meshlet batches the union command (first, n1 + n2) (CullPC::late_union_meshlet_batches), so meshlets phase 1 deferred are retested against this frame's pyramid. cull_skip_recorded_bit keeps the ones phase 1 already drew from drawing twice.
Bitset: include/rendering/meshlet_visibility.hxx (layout, offsets, 2^28-bit cap). emit_batch reserves a range per opaque and mask meshlet batch; GpuDraw::transform_index (unused, always the instance index) becomes meshlet_visibility_offset. prepare_frame decides, grows (power-of-two) and clears the buffer. A frame over the cap runs without meshlet occlusion (instance level continues) and warns once.
Barriers: task write -> task read | write before the late prepass, task write -> task read before forward; the statistics readback barrier now includes the task-shader stage.
Stats and UI: slots 4 and 5 of the occlusion statistics (each view's stats_address points at its own counter), FrameStats::deferred_meshlet_count / occluded_meshlet_count, a Scene stats line, a Lighting checkbox, --meshlet-occlusion=on|off, and a meshlet_occlusion key in the benchmark JSON (true only when it was active).
Docs: a "Meshlet level" section in docs/occlusion-culling.md, updates to meshlet-rendering.md and perf-benchmark.md. The M2 spec file is removed now that it is implemented.
PC grows by one pointer (occlusion), so ForwardPushConstants and ShadowPushConstants gain occlusion_address; shadows leave it null and never set an occlusion bit.
