Summary of Changes
Hello, I'm Gemini Code Assist1! I'm currently reviewing this pull request and will post my feedback shortly. In the meantime, here's a summary to help you and other reviewers quickly get up to speed!
This pull request significantly enhances the accuracy and robustness of the 'splash to grid' conversion process, especially for simulations using non-Cartesian coordinate systems. By introducing sub-pixel interpolation, it improves the representation of fine-scale particle features on a coarser grid. Additionally, it refines mass calculation methods to correctly account for the varying volume elements inherent in different geometries and improves the automatic detection and handling of periodic boundaries, leading to more physically consistent results.
Highlights
Sub-pixel Interpolation: Implemented sub-pixel interpolation and refinement for 3D SPH kernel calculations, particularly beneficial for particles with small smoothing lengths in non-Cartesian geometries. This ensures more accurate representation of particle data on the grid.
Mass Calculation for Non-Cartesian Geometries: Introduced new subroutines (get_mass_in_box and grid_total_mass_geom) to accurately calculate total mass for both particles within a box and on the grid, correctly accounting for volume elements in various non-Cartesian coordinate systems (cylindrical, spherical, etc.).
Improved Periodic Boundary Handling: Enhanced the handling of periodic boundary conditions, especially for non-Cartesian geometries. The system now automatically assumes periodicity for the second coordinate (phi) if its range is 2*pi and no periodic boundaries are explicitly defined.
Refactored Smoothing Length Logic: Simplified the logic for handling particle smoothing lengths (hi) during interpolation, removing a special case that previously adjusted hi when it was smaller than a minimum threshold.
