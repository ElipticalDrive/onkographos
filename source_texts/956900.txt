Documents the per-splat anti-aliasing compensation from playcanvas/engine#9921, for the 2.24 docs branch.
Changes:
New page Gaussian Splatting > Building > Anti-Aliasing (en + ja): why splats trained with anti-aliasing need the compensation, how it is detected from each format, setting antiAlias on a resource whose file does not record it (including streamed scenes), the scene-wide app.scene.gsplat.antiAlias override, and the cost of mixed scenes. Added to the sidebar and the engine llms.txt index.
PLY: the header comments that record anti-aliased training (antialiased 1, SplatRenderMode: mip).
SPZ: the antialiased flag is no longer ignored.
Streamed SOG: the model field of lod-meta.json (written by splat-transform from Record the splat model in lod-meta.json splat-transform#368).
The Editor's Anti-Alias row on the Rendering settings page is left as is until the Editor control has an automatic option (playcanvas/editor#2470).
