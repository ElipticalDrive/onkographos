This python 3.12 algorithm is an approximate solution of the point-in-polyhedron problem for 3-dimensional mainly convex irregular bodies. This is a problem notorious issue in geometry, but no sufficient software exists to both analyze the inside of proteins and provide an output, which can be used for plotting with matplotlib directly. The algorithm is a part of a Master Thesis, a crucial part of which is to tell whether lipids are placed inside or outside a protein. The usability of the algorithm is limited because the geometries are sliced into 2-dimesional projections and approximated as circles. These circles act as detection radius to the arithmetic center of the point cloud. Further elaborated solutions might exists and should be considered first, because this documentation is thought to be a reference to the corresponding Thesis primarily.
