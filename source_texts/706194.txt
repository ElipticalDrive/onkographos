# Cinematic 3D Gaussian Splat Tour Generator

A comprehensive pipeline for generating professional, cinematic video tours from 3D Gaussian Splat files (`.ply`). This system analyzes the 3D geometry of a scene, plans an optimal camera path (walking or orbiting), smooths the movement using cinematographic heuristics, and renders high-quality video using a hybrid Python/JavaScript architecture.

## 🎥 Features

*   **Smart Scene Analysis**: Voxelizes the point cloud to detect navigable floors, obstacles, and the "center of mass" of the scene using Connected Components and Contour analysis.
*   **Path Planning Algorithms**:
    *   **Contour Orbit**: Generates a smooth flight path that follows the exact shape of the island/object (using Convex Hulls and Expansion).
    *   **Viewpoint Walk**: Uses A* pathfinding to connect interesting vantage points on the navigable floor.
*   **Cinematic Smoothing**:
    *   B-Spline interpolation for organic movement.
    *   **"Visual Gravity" Look Targets**: The camera intelligently looks towards open spaces and scene centers while avoiding walls.
    *   **POI Stabilization**: Locks the camera view forward when approaching Points of Interest to prevent motion sickness.
*   **Flexible Rendering**:
    *   **Interactive Web Demo**: Full UI to configure, preview, and render videos.
    *   **CLI Headless Mode**: Automated rendering using Playwright (GPU required).

## 📂 Project Structure

```text
├── configs/
│   ├── config.js          # Generated dynamically for headless rendering
│   └── default.yaml       # Configuration for analysis and smoothing
├── inputs/                # Place your .ply files here (ignored by git)
├── outputs/               # Generated paths (.json) and videos (.mp4)
├── src/
│   ├── app.py             # FastAPI Backend for the Web Demo
│   ├── main.py            # CLI Entry point
│   ├── scene_analyzer.py  # Voxelization & Geometry Geometry logic
│   ├── tour_generator.py  # Path planning strategies (Orbit/Walk)
│   ├── path_smoother.py   # Splines & Cinematic Look heuristics
│   ├── renderer.py        # Playwright wrapper for headless rendering
│   └── utils.py           # Math helpers
├── demo.html              # Main Interactive Web Application
├── index.html             # Lightweight frame renderer (manual mode)
├── render.html            # Headless rendering target
└── requirements.txt       # Python dependencies
```

## ⚙️ Prerequisites

1.  **Python 3.8+**
2.  **FFmpeg**: Required for stitching frames into MP4 video. Ensure it is added to your system PATH.
3.  **Node.js / HTTP Server**: To serve the HTML frontend.
4.  **GPU**: Rendering Gaussian Splats requires a GPU with WebGL support.
    *   *Note:* The headless CLI renderer (`renderer.py`) uses Playwright but **requires a GPU environment** (or a system that supports hardware acceleration for headless browsers).
