summary
add Cook-Torrance GGX beside the existing Blinn-Phong shader family
add sanitized baseColor, metallic, and roughness uniforms
add textured and normal-mapped GGX variants with shared lights and light-0 shadows
route glTF metallic/roughness factors directly into GGX
add the roughness/metallic grid demo and four GGX goldens
formula choices
D: Trowbridge-Reitz GGX with alpha = roughness^2 using the Disney convention.
G: Smith geometry with Schlick-GGX, using k = alpha / 2 for direct lighting.
F: Schlick Fresnel. F0 = 0.04 for dielectrics and F0 = baseColor for metals.
Diffuse: Lambert scaled by kd = (1 - F) * (1 - metallic).
Specular: D * G * F / max(4 * (N dot L) * (N dot V), epsilon).
Roughness has a 0.045 floor. Lighting accumulates in linear space and encodes sRGB once.
HDR is not included. Bright specular values clamp at 1.0 until the HDR milestone.
hand-computation appendix
At roughness 0.5, alpha = 0.25; for N dot H = 1, D = 5.092958.
With base color (0.8, 0.2, 0.1), F0 at metallic 0, 0.5, and 1 is (0.04, 0.04, 0.04), (0.42, 0.12, 0.07), and (0.8, 0.2, 0.1).
For roughness 0.5, N dot L = 0.5, and N dot V = 0.8, Smith G is 0.8619529.
For N = L = V = (0, 0, 1), base color 0.8, metallic 0, and roughness 0.5, the full BRDF is 0.29539157 per channel.
