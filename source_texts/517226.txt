Add BVH and AABB bounding boxes computed on java and sent to CUDA. Replaces the current O(N) solution for checking if a ray will intersect each object with an O(log N) solution where we check the following:
Does the object hit the bounding box around the entire scene? Yes? continue. No? end ray.
Does the object hit the left split bounding box (depth = 1) Yes? continue. No? does it hit the right split bounding box? Yes? continue. No? end ray.
Keep splitting each bounding box in half in the most efficient axis until the newest set of boxes each holds around 4 primitives (triangles or spheres), now called leaves.
Once the code has its leaf, compute ray intersection for the primitives in that leaf.
