For creating synthetic images of outdoor scenes, clouds play an important role to enhance the realism of the scene. Therefore, many
methods have been proposed for visual simulation of clouds. However, in order to generate realistic clouds, the user has to adjust
many parameters involved in the methods. Although choosing appropriate parameters is not a difficult task for experienced users, it
becomes a serious problem for novice users who have no sufficient
prior knowledge on nether the parameters nor the methods. In order
to address this problem, we propose a sketch-based retrieval system
for cloud volumes by using a precomputed database. The database
of cloud volumes is generated in advance by numerical analysis of
atmospheric fluid dynamics. Next, the user sketches the desired
shape of clouds at the desired position on the screen and then our
system searches for the optimal cloud volume from the database.
Our system allows the novice users to intuitively design the desired
and realistic cloud scene.
Our task is then to provide the user with an intuitive and interactive
mechanism to retrieve the desired cloud volume. For the intuitiveness, we develop a sketch-based retrieval system. The user sketches
a rough two-dimensional shape at the desired position on the screen
and then the system retrieves the optimal cloud volume from the
database so that the shape of the retrieved clouds matches the userspecified two-dimensional shape. For the interactivity, the retrieval
process is accelerated by compressing the cloud volume by using
the singular value decomposition (SVD). We will demonstrate the
usefulness of our system by showing realistic cloud scenes designed
by our system.

Introduction
Related Work
In compute graphics, a so-called procedural approach is often used
for generating three-dimensional clouds [Ebert 1997]. Methods
based on this approach typically uses the idea of fractals. One of
their advantages is the cheap computational cost. Although these
methods provides us with powerful tools for modeling clouds, it is
often difficult to adjust many parameters involved in those methods to create the desired and realistic clouds. [Schpok et al. 2003]
proposed a real-time cloud modeling system; the images of clouds
are rendered in real-time while the user adjust the parameters. However, a trial-and-error process is still required to produce the desired
clouds. The appearance of the clouds generated by the procedural
appraoch sometimes looks noisy.
Synthetic images of outdoor scenes often contain the sky and clouds
in the background. Many methods have therefore been proposed
for synthesizing realistic three-dimensional clouds. Methods using fluid simulation [Miyazaki et al. 2002] or fractal noise functions [Ebert 1997] have been widely used. However, when using
these methods, many parameters must be specified by the user and
the relationship between the parameters and the resulting clouds is
highly nonlinear. Consequently, it is often difficult to create realistic clouds with the desired shape at the desired position. This is
particularly true for novice users who have no little prior knowledge
on the parameters.
Sketch-based methods have been proposed for intuitively generating clouds with the desired shapes [Wither et al. 2008; Stiver
et al. 2010]. These methods allow the user to draw the desired
shape of the clouds on the screen and the system generate the threedimensional density distribution of the clouds by using the procedural methods. Although these methods are useful , we still need to
adjust the parameters for the procedural method.
Several sketch-based systems have been proposed to address the
above problem [Ebert 1997; Wither et al. 2008; Stiver et al. 2010].
Conceptually, these systems ask the user to specify a rough shape
of the desired clouds, and the systems add small-scale details to
it by using either a noise function or fluid simulation. Although
these systems are useful, the user still has to adjust the parameters

Retrieval Process
5.2
The user can retrieve the desired cloud volume from the database
by sketching an overall shape of the desired clouds on the screen.
We provide the user with two user interfaces for specifying the desired shape by a sketch. From the user’s sketch, a three-dimensional
shape is generated. We call the three-dimensional shape a query
shape. The query shape is then compared to the shape of clouds
in the database to find the optimal cloud volume. In this section,
we first explain the user interfaces and the method for creating the
query shape. Next, the method for retrieving the cloud volume is
explained.
5.1
Creating Query Shape from Vertical Shape
Retrieval of Cloud Volume
Our system searches the database for the cloud volume that is most
similar to the query shape. To calculate the similarities between
the query shape and the volumes in the database, we first convert
the query shape into volume data, namely the query volume. The
similarity is calculated by the sum of the squared differences of
densities between them. In the proposed method, by approximating the query volume using the basis vectors uk (k = 1, 2, ..., K)
computed by using SVD (see Section 4.2), the similarities are calculated very efficiently. We describe the details of these processes
in the following.

Experimental Results
This section demonstrates some examples obtained by using our
method. We used a computer with CPU: Core(TM) i7-2600K
3.40GHz and Memory: 8.00GB. We simulated dynamic cumulus
clouds by fluid simulation to construct the database. The grid size
used in the simulation is 96×96×128. From the simulated dataset,
we extract 137 cloud volumes and store them in the database. These
volumes are normalized to volumes with a 20 × 20 × 20 grid before
the singular value decomposition. We use Autodesk Maya 2016 for
rendering the final images.
