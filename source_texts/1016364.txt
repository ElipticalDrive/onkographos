Third step of the renderer milestone: soft shadows from the main directional light.
What's in it
computeShadowCascades() (public, unit-tested): up to 4 cascades with blended uniform/logarithmic splits.
Each cascade bounds its slice of the view with a sphere computed in view space, so its size doesn't change when the camera turns.
The light-space centre snaps to whole texels, so shadow edges don't shimmer.
Each cascade extends casterDistance towards the light, so casters outside the view still cast.
Culling: the existing parallel pass now records one mask per object (camera plus each cascade). Each pass gets its own block in the shared instance buffer.
Casters:
Opaque casters batch by mesh.
Alpha-masked casters keep their material for alpha testing.
Blended materials don't cast.
Shadow map: a D32 texture array using standard depth, because NVRHI's comparison samplers always compare with LESS.
PCSS receiver:
A blocker search sized by the light's angularDiameter, then a rotated Vogel-disc PCF.
Normal-offset and depth bias.
Dithered transitions between cascades and a fade-out near maxDistance.
API:
ShadowSettings on SceneRendererDesc, plus setShadowSettings() and shadowCascades().
Shadow statistics in RenderStats.
DirectionalLight gains castShadows and angularDiameter.
ADR 0015, English and Turkish docs.
Verification
MSVC Debug/Release and clang-cl Debug build with zero warnings; all tests pass, benchmarks included.
Unit tests: split monotonicity, every slice corner inside its cascade, casters towards the light inside the depth range, size unchanged when the camera rotates, sub-texel camera moves shifting the shadow map by whole texels.
GPU test: an invisible roof above the view shades the ground. A large angularDiameter brightens the penumbra near the edge. Both castShadows = false and enabled = false light the ground evenly. Zero validation errors.
Checked visually with the viewer's screenshot: sky-tinted soft shadows under the sphere grid, no acne.
Known limitations (also in ADR 0015)
Penumbrae are capped at 5% of a cascade's width.
Only one directional light casts shadows; point-light shadows come later.
Noise-rotated kernels are meant to be smoothed by TAA (M3d).

The first DirectionalLight with castShadows now casts soft shadows from
opaque and alpha-masked meshes.

- computeShadowCascades(): up to 4 cascades split by the practical scheme,
  each bounding its view slice with a view-space sphere (rotation
  invariant) snapped to whole texels (no shimmering), extended towards
  the light by casterDistance. Public and unit-tested.
- Culling records a pass mask per entity (camera + each cascade) in the
  same parallel pass; per-pass instance blocks share the instance buffer;
  casters batch by mesh, masked ones keep their material for alpha
  testing; both faces cast with slope-scaled bias.
- Shadow map: D32 array with standard depth (NVRHI comparison samplers
  use LESS). PCSS receiver: blocker search sized by the light's angular
  diameter, rotated Vogel-disc PCF, normal offset and depth bias,
  dithered cascade transitions, fade-out at maxDistance.
- ShadowSettings on SceneRendererDesc / setShadowSettings(); stats for
  shadow casters and draw calls; DirectionalLight gains castShadows and
  angularDiameter.
- Unit tests (splits, frustum containment, rotation invariance, texel
  snapping) and a GPU test with an off-screen caster, penumbra width and
  both ways of turning shadows off. ADR 0015, EN/TR docs.
