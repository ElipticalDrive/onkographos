Description
PyPI Compatibility Fix: Removed the direct git url dependency (lpips @ git+https://...) to comply with PyPI publishing rules, and replaced it with a standard dependency on torchmetrics[image].
Backward Compatible LPIPS: Updated the existing compute_lpips function to lazily auto-install the richzhang/PerceptualSimilarity package from GitHub upon first usage. Removed its dependency on OpenCV (cv2) to support headless environments.
New Torchmetric Metric: Added compute_lpips_torch() as a modern PyPI-installable alternative.
Documentation & Tests: Updated README.md and added tests/test_lpips.py to cover the new implementations.
