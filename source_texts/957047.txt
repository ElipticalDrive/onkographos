Overview
Render optional temporal antialiasing through the canonical Scene resource and its existing Editor composition. Replace the operation's incomplete camera/history contract with coherent jittered camera samples, actual previous-camera/object/bone motion, depth rejection and recording-safe history.
This fourth focused renderer PR is stacked on #460 (TE/SceneDirectionalShadows) under the authorized dependent-PR workflow. Scene remains the world-rendering entry point, with its original source identity and root interfaces.
Key Changes
Add the missing temporal camera preparation boundary. Its immutable typed snapshot explicitly supplies view constants, visibility, rasterization and reconstruction; scheduling remains resource-authored.
Author the camera producer and corrected TAA directly in Scene. Enable the camera occurrence to enable both jitter and reconstruction. The default is disabled: forward exact HDR input, emit no temporal GPU work and allocate no histories. Reject an enabled jitter producer paired with a disabled resolver.
Use an eight-sample Halton sequence and actual previous camera matrices. Preserve unjittered NDC velocity from existing object/bone history. Keep color accumulation on a stable pixel grid while reprojecting raw depth with jitter compensation.
Add background/depth-disocclusion rejection and camera-rotation sky reprojection. Keep neighborhood clipping, blend contribution, motion response and depth threshold reflected.
Preserve RGBA32Float HDRSceneColor in Scene, with a separate RGBA32Float kernel using the shared algorithm; retain RGBA16Float input/output support. Resolved HDR feeds exposure/display and Editor overlays.
Replace mutable ping-pong ownership and borrowed callbacks with occurrence-owned, completion-aware slots. Retain pipelines, samplers and color/depth allocations in recordings; use explicit GAL readiness and revision-checked promotion. Completed recordings still prevent their slots from being overwritten.
Reset incompatible histories on first use, cuts, resizing, reloads and skipped world updates. Match color and camera frame identities, without resetting one world merely because another world advances the device clock.
Document topology, formats, controls, image acceptance, memory and remaining work. Load canonical dependencies in the isolated graph-layout fixture.
Validation
Passed Windows/MSVC Debug builds of GraphicsCoreTest, GraphicsFoundationTest, EditorFrameworkTest, EditorEngineProcessFrameworkTest and GpuDrivenScene.
Passed RendererAssetPreparation, GraphicsCoreTest (79 subtests), GraphicsFoundationTest (114 subtests) and EditorEngineProcessFrameworkTest (76 subtests), on Vulkan.
Compared actual full GPU images from unjittered rendering, jittered current-frame rendering and reconstruction in two worlds with independent views, real box/floor geometry, contrasting materials and a sun.
At 129×97, reconstruction changes 1,401 final pixels. Summed RGB byte variation across six warmed comparisons falls from 187,966 to 152,587, about 19%. This is a deterministic fixture measure, not a general performance/quality claim.
Compared GPU velocity with geometric projection: 7,544 camera-motion pixels, 209 moving-object pixels and 256/194 pixels on changing bone poses, allowing RG16Float storage and raster reconstruction tolerance. Verified exact current color at 197 newly revealed pixels.
Repeated the complete comparison with mesh shaders and extended storage formats disabled; AO is explicitly disabled for that device.
Verified first frames, cuts, odd resize, resource reload, orthographic cameras, paused/resumed views, independent-world destruction and a full Scene recording executed after world/instance destruction.
Verified RGBA16Float HDR readbacks, distinct slots while completed recordings remain retained, invalidation between setup/execution, and output after owner retirement.
Verified temporal output through Editor composition and exact baseline restoration when disabled. Passed EditorDocuments (20 subtests) and NodeLayout (3 subtests).
Ran the standalone Vulkan sample for 300 frames using the generated resource table. Its default temporal path remains disabled; active acceptance is supplied by the GPU comparisons.
All five authored resources export byte-identically through the production compiler; Scene/Editor source identities and required depth/HDR interfaces are preserved. Passed pinned formatting, changed-source and whitespace checks. Generated pipeline binaries, tables, captures and logs are excluded.
The initial image test exposed ineffective jitter-shifted color accumulation; the final stable-grid resolve produces the reduction above. Later fixture checks corrected paused-view result expectations, matched the shader's velocity dilation for disocclusion classification, allowed actual half-precision/raster rounding, and registered dependencies for isolated layout execution.
Compatibility and Acceptance Limits
Scene remains opt-in for TAA and preserves its existing rendering behavior while disabled. Each retained Scene history slot uses 20 bytes per pixel (RGBA32Float color plus R32Float depth), before allocation overhead; slot count follows actual in-flight and retained recordings. The path uses compute and requires neither mesh shaders, extended storage formats nor hardware ray tracing.
This is render-resolution antialiasing. Temporal upsampling, reactive masks for future transparency/particles, morph-history acceptance, representative quality/performance work, stereo and other backends remain separate work. Surfaces moving in depth may conservatively reject valid history; no dedicated previous-position/depth MRT is added. Temporal AO and SSR retain their own acceptance work. Standalone callers omitting the optional camera snapshot retain responsibility for their motion/depth contract.
Reflections, transparent/particle rendering and geometry-dependent GI remain tracked renderer work. This PR and its predecessors are not merged by this task.
