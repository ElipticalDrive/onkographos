What this adds
A browser-based 3D viewer with orbit/zoom/pan controls, wireframe and axis toggles, mesh counts/bounds, and PNG export.
Local file loading for legacy ASCII VTK POLYDATA, STL, OBJ, PLY, and GLB surface meshes. The default view is explicitly synthetic demo geometry.
cardianatomy export-surface to extract exterior triangles from supported linear tetrahedron, hexahedron, wedge, and pyramid meshes, removing internal shared faces.
Tests for tetrahedral surface extraction and internal-face removal, viewer JavaScript syntax smoke check, README and format/privacy documentation, and a GitHub Pages deployment workflow.
Important limits
The viewer is for geometry inspection, not reconstruction or clinical validation. Conversion preserves coordinates but intentionally drops point/cell attributes, anatomical labels, fiber/scar arrays and scalar data. Higher-order, voxel, and polyhedron cell types fail explicitly. The static viewer's model files are parsed locally in the browser; its pinned Three.js modules are loaded from jsDelivr.
