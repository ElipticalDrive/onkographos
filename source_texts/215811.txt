The mesh generator supports balanced binary octrees, but the reviewed evolution studies use 3:1 refinement. Topology support must not be confused with a qualified binary solver. This is a qualification task for the selected compatible coupling, not a commitment to the deferred SBP-SAT research option #17.
Exercise 2:1 face/edge/corner ownership and more than two mesh levels; report the total largest/smallest cell ratio separately from adjacent-level grading.
Verify coverage, magnetic face partition, electric constraints, positive mass and uniform-grid recovery.
Run constant fields, non-node 3D waves, oblique interface scattering and long-time/precision tests; preserve [P0] Fix closed-patch interface accuracy and certify composite constraints #37 failures and the [P0] Maintain focused adaptive verification gates alongside the prototype #13 gates.
Integrate the geometry-driven guide/core/boundary/buffer policy; verify material/source/port/CPML handling through [P0] Implement the 3D coarse–fine interface, then a locally refined waveguide #15/[P0] Demonstrate locally refined 3D straight-waveguide accuracy and GPU savings #35.
Compare against the 3:1 implementation and both uniform baselines at declared error tolerances. Record invalid/failed cases rather than calling topology counts speedups.
#37 determines the compatible trace construction; #35 owns the end-to-end waveguide comparison. Start topology/ownership checks independently; retain the current 3:1 controls.

The first actual binary-octree driven-guide comparison is now implemented, with three real refinement levels (25 to 200 nm cells), matched direct uniform kernels and a 12.5 nm uniform reference underway. The 12.8 µm-wide case measures 0.530 s / 101.32 MB owned versus 11.774 s / 1213.47 MB for uniform 25 nm: 22.2× warm trajectory speed and 12.0× owned-memory reduction. Accuracy will be reported against the reference before publishing the result.
Remaining physical qualification is explicit: this uses an impressed pulse and matched-conductivity sponge, not a pure guided mode or CPML. The measured sponge normal-flux defect is now isolated as #42; expensive host assembly is #43. The existing closed-patch accuracy/Gauss gates remain open. Setup and diagnostic cost are separate from warm timings, and the uniform baseline was strengthened (3D launch, ~3.3× faster than the first flat kernel) before claiming the large-domain speedup.
