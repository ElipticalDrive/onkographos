Description
This adds the ability for users to use the Pointer Coordinates plug-in to estimate sky luminance in cd/m².
We expose a common API through Atmosphere and LandscapeMgr, as to keep the plug-in independent from the individual atmosphere models
We use the luminance reported by the respective atmosphere model, with interpolation matching their rendering paths
To ease workload on the GPU, we only update 5 times per second
This is the first step towards more accurate twilight/moonlight simulation.
Code generated by Codex (GPT-6 Astra). I've tested the code and it runs smoothly on my system and seems accurate (of course, I haven't verified it).
