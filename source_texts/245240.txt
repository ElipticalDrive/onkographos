Adds gallery/mountains.ps: an alpine range under cumulus, ray-marched one ray per pixel in pscat 0.6.2. It's marked % Status: draft. Marking it final is your call.
What's in it
Ray marching is the default renderer. The spike's code is promoted into lib/: fc_sky, fc_clouds, fc_terrain, fc_noise2, fc_erode and fc_render. spikes/ is unchanged.
Terrain:
a massif mask decides where ranges and valleys go;
domain-warped ridged noise on new 2D gradient noise makes the ridges (on value noise they drew rings);
erosion fBm adds gullies;
hydraulic erosion (240k droplets on a 1024² map) is added as a correction to the procedural terrain.
Shading:
soft terrain shadows and cloud shadows on the ground;
sky visibility and concavity measured from a ring of four nearby height samples;
snow by elevation, flatness, hollows and aspect;
rock with strata and mottling, and shading normals tilted on steep slopes so faces fracture in the light;
a linear-light pipeline (sRGB palette in, tone curve and gamma out).
Atmosphere: haze integrated along each ray, and a cloud coverage map that makes distinct cumulus groups.
Renderer: the image size follows page × DPI × Res; depth edges are antialiased adaptively.
Tooling:
render.sh -D NAME=VALUE passes settings to a piece;
scripts/check_names.sh catches scratch-name collisions between libraries (one corrupted the first render);
scripts/codex_critique.sh and scripts/codex_pairwise.sh run Codex image reviews;
spikes/heightmap.ps is a top-down terrain diagnostic.
Notes: CLAUDE.md and docs/template-repo-notes.md gain this work's lessons.
The full write-up (technique, iteration history, timings, known limits) is in docs/mountains.md.
How "good enough" was decided
Codex's absolute 1–10 realism score stayed at 3 through every round, so it was used only to spot symptoms. Blind pairwise comparisons in both orders measured progress. The current version beat draft 2 and the first erosion version on realism and aesthetics, in both orders, twice.

current (320×200)
Testing
scripts/render.sh gives ok with lint clean, at 160×100, 320×200, 640×400 and 1280×800.
scripts/check_names.sh passes.
The 1280×800 render took 34.2 min (an 84 s bake plus 32.8 min of rendering, with 7,430 pixels antialiased).
Known limits
The foreground ridge is still smooth and dune-like.
There's faint grain inside the clouds.
Snow is colour only, not geometry.
No trees yet.
Refs #1. The issue stays open for trees, and for the clouds-and-mountains piece it describes.
