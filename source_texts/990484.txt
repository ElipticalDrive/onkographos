## Optimization — tight, opacity-aware splat bounds (`tight_bounds`, default on)
- Reference: square around the 3σ circle of the major axis (radius = 3·sqrt(λ_max)).
- Tight: axis-aligned box of the ellipse region where alpha ≥ 1/255 (everything else is discarded anyway):
k = min(3, sqrt(2·ln(255·opacity))) standard deviations, per axis sqrt(Σ'xx), sqrt(Σ'yy)
(exact bounding box of the ellipse). Gaussians with 255·opacity ≤ 1 are culled entirely.
- Used for both the quad size and the tile rect.
- Bicycle, default camera, 1280×800:
| | tight off | tight on |
|---|---|---|
| visible gaussians | 1,063,091 | 974,698 (−8%) |
| quad render pass | 9.78 ms | 2.11 ms (4.6×) |
| quad gpu total | 14.13 ms | 6.04 ms |
| tile keys | 5.58 M | 2.30 M |
| tile sort / raster | 12.70 / 6.31 ms | 6.79 / 3.48 ms |
| tile gpu total | 20.05 ms | 11.20 ms |
| PSNR vs off | – | 75.6 dB (quad), 70.3 dB (tile) |

// Half extent (pixels) of the screen space quad of a splat.
// Default: a square around the 3 sigma circle of the major axis, like the reference implementation.
// Tight bounds: the axis aligned box of the ellipse outside of which alpha < 1/255 (those fragments are
// discarded anyway): k sigma with k = sqrt(2 ln(255 opacity)), capped at 3 sigma, using the per axis
// standard deviations sqrt(cov_xx), sqrt(cov_yy). Returns 0 when the splat can never reach alpha 1/255.
fn splat_extent(cov2d: vec3<f32>, lambda1: f32, opacity: f32) -> vec2<f32> {
if render_settings.tight_bounds > 0.5 {
let op = 255.0 * opacity;
if op <= 1.0 {
return vec2<f32>(0.0);
}
let k = min(3.0, sqrt(2.0 * log(op)));
return ceil(k * sqrt(vec2<f32>(cov2d.x, cov2d.z)));
}
return vec2<f32>(ceil(3.0 * sqrt(lambda1)));
}

// WebGPU framebuffer y points down, NDC y points up
