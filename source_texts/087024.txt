The OSPRay renderer is the default renderer for Volume Rendering and isosurfaces, regardless of the data type. OSPRay should only be the default for unstructured grids (e.g. MPAS).
To reproduce:
Load any structured grid data set (e.g. Duku).
Create a volume renderer.
Look under the appearance tab and OSPRay is the selected rendering algorithm
