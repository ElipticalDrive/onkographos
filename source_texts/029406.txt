# Volume Encoding Gaussians: Transfer Function-Agnostic 3D Gaussians for Volume Rendering
![alt text](teaser-camready.png)
## Description
This is the implementation for Volume Encoding Gaussians: Transfer Function-Agnostic 3D Gaussians for Volume Rendering. This work adapts 3D Gaussian Splatting for volume data visualization by removing color and opacity attributes for each Gaussian, training only scalar values and enabling interactive transfer function application post-training. 

## Setup

```bash
conda create --name VEG python=3.9
conda activate VEG

#* install necessary dependencies
pip install -r requirements.txt
pip install -e ./submodules/diff-gaussian-rasterization
pip install -e ./submodules/simple-knn  
```

## Dataset structure
We organize image datasets for training and testing like so:
```
.
└── dataset
    ├── TF01
    │   ├── test
    │   ├── train
    │   ├── transforms_test.json
    │   └── transforms_train.json
    ├── TF02
    ├── TF03
    ...
```
where ``dataset`` is the volume dataset name, ``TF01`` is the first transfer function (TF), ``test`` and ``train`` contain the testing and training images, and ``.json`` files store the camera poses.

If using our create_data.py script to evaluate on transfer functions unseen during training (using the eval_full flag) there will also be folders named ``CCTF01``, ``NATF01``, and ``BTF01`` holding the test images for random colormaps, narrow opacity maps, and broad opacity maps respectively. 

## Data Creation, Training and Evaluation
This script will create training and testing images for a given .vtk, .vti, .vtu, or .raw (from the OpenSciVis repo) volume dataset. By default, this will create images for 5 training transfer functions and test images for those along with random colormaps, narrow opacity maps, and broad opacity maps in the same way as the paper. 
```bash
bash scripts/create_data.sh <dataset file>
```
This script will train a model using our defaults given a dataset folder like above that contains multiple sets of images rendered with different transfer functions:
```bash
bash scripts/train_model.sh <dataset>
```
After training, this script will evaluate PSNR using all the test images in a given folder (including training and testing TFs):
```bash
bash scripts/render_model.sh <dataset>
```
This script will start the GUI for a given model:
```bash
bash scripts/gui.sh <dataset>
```
The data creation, model training, and model rendering scripts can also be run without shading using create_data_unshaded, train_model_unshaded, and render_model_unshaded instead.

## FAQ / Frequent Errors

**Q: How can I prevent `error: identifier "FLT_MAX" is undefined` when installing simple-knn?**

Add `#include <float.h>` alongside the other include statements in `simple_knn.cu`.

**Q: Why does my process get killed before training starts when running the train script?**

This is usually because the size of the training image sets are too large for your device's memory. You can reduce the image size of use less training transfer functions.
