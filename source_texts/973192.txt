Summary
Depth of field is computed only for perspective cameras. A Projection "orthographic" camera with DepthOfField set renders in sharp focus in every hider. Spec 031 keeps it that way on purpose: FR-024, the maintainer's decision P-Q10 "keep off".
Background
Spec 031 replaces the two hider-specific circle-of-confusion formulas with one signed LensModel::circleOfConfusion(z), which Reyes and raytrace both use:
The raytracer uses the exact thin lens, CoC = imagePlane·A·|1/z − 1/f|.
Reyes over-blurred by about 1.35–1.39× the physical radius.
LensModel is perspective only. An orthographic lens model needs a different relation, because the image scale doesn't depend on depth. Adding it would change orthographic renders that carry DepthOfField, which no spec in the current round may do.
Proposal
After spec 031 merges:
Extend LensModel with an orthographic circle of confusion.
Implement it once for every camera hider, following the artifact-effect uniformity rule (no per-hider special case).
Add analytic tests next to test_camera_lens_model.cpp, plus a parity scene for Reyes and raytrace.
Notes
Blocked by spec 031 (Spec 031: Geometry uses IDicer/IRayContext; delete the Dispatch/Stub pairs #37).
An enhancement, not a bug: today's behaviour matches what 031 specifies.
