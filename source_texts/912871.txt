# Lock-Free Concurrent Skip List

This project implements a sorted, multi-level concurrent skip list for `i64` keys and values.

## Guarantees

- `insert`, `search`, and `delete` are lock-free operations.
- Updates use atomic compare-and-swap loops.
- Readers never dereference an unprotected node: `crossbeam-epoch` pins the calling thread and retires removed nodes only after all pre-existing guards have left their epochs.
- A delete first marks a node logically, then unlinks it physically. Searches never return logically deleted values.

The current API reserves `i64::MIN` for the head sentinel. The list must also be quiescent before it is dropped; callers must not destroy the list while another operation is in progress.

## Run

```text
cargo test --all --release
cargo test --doc
```

The integration tests include concurrent insertion, duplicate-key races, deletion races, and a mixed read/write stress run.
