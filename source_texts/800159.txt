Add static/voxel/lib, a small no-build ES module library for voxel
dioramas, served next to the pieces that will use it:

- VoxelGrid: sparse chunked storage with shape brushes (spheres,
  cylinders, tubes, roofs, SDFs, heightmaps, text slices and pixel text)
- Palette: named materials uploaded as a texture, with per-voxel color
  variation, glow, flicker, wind sway, water and glass
- a greedy mesher with vertex AO, bevel edge data and optional baked
  ray-traced AO and colored light from emissive voxels
- Stage: camera fitting, soft sun shadows, a generated sky environment,
  a shadow-catcher ground with contact shadows and optional reflections,
  GPU particles, and a ?debug panel for tweaking the look live
- a post pipeline: MSAA HDR, bloom, depth of field or tilt-shift, fog,
  tone mapping, grading, vignette and grain
- looks: data-only presets for whole moods (pastel, neon, cozy, ...)
- generators for trees, rocks, plants, clouds, terrain, houses and props
- a MagicaVoxel .vox importer

three.js r186 is vendored as a single minified module. voxel/tools has
the vendoring script, a dev server and a headless screenshot harness;
voxel/lab has unpublished test scenes.

voxel: merge faces across bevel edges, add unit tests
…
8a1a287
```
The convex-edge mask was part of the greedy merge key, so faces along
an edge never merged with their neighbours: a 2-voxel bar meshed to 10
quads instead of 6 and a flat slab to 48 instead of 6. Edges between
merged faces are flat by construction, so drop the mask from the key,
require only each border edge of the merged rectangle to be uniformly
convex or flat, and derive the quad's mask from its border faces.

voxel/tools/test.mjs covers the grid, shapes, palette texture layout,
mesher invariants (winding, AO, merging, transparency, bevel bits),
light and AO bakes, and .vox parsing in about half a second.

…
f55a22c
```
- pond() hung when part of the basin hung over an empty column; set()
  now rejects non-finite coordinates instead of writing at y = 0, and
  get() floors like set() does
- water/glass opacity and per-material ior had no effect: the strings
  they patched live inside included chunks, so splice in patched copies
  of transmission_fragment and lights_physical_fragment
- roof() lost its relief and ridge for fractional slopes, and hip roofs
  could lose their ridge; thickness is now an integer and the ridge is
  measured
- house() reported slope-1 ridge heights, burying chimneys on steeper
  roofs; it now measures the roof it drew
- merge() shared nested objects with the presets, so ?debug edits
  leaked into DEFAULT_LOOK and LOOKS
- stamping a grid onto itself never finished
- ascii({ flip }) mirrored ragged rows by their own length
- .vox materials are named by index and color, so two models no longer
  reuse each other's colors
- the floor reflection mismatched an off-center ortho camera
- point-light shadows get a voxel distance material (sway, shadow:false)
- captureViews() restores the camera; recenter() agrees with
  stamp({ center })

Regression tests for each case are in voxel/tools/test.mjs, and
voxel/lab/glass.js covers the shader-side fixes.

voxel: parallel big-scene pipeline (clusters, workers, region modules)
…
f3b2b33
```
- models are meshed as clusters (columns of 4×4 chunks by default), one
  frustum-culled mesh each, sharing one set of materials per model
- buildMesh can emit a subset of chunks, bake only around a region and
  return plain typed arrays; the Baker reads just the chunks it needs
- lib/pool.js + lib/worker.js: a module-worker pool that meshes clusters
  (stage.addAsync) and builds regions/assets off the main thread
- stage.world(): a scene made of region modules (one file per region —
  one per subagent), built in parallel, merged (worker-created materials
  are remapped), clustered and meshed in parallel; regions can emit
  particles, lights and actors, and instance shared assets; ?region=
  builds a subset to test one region in isolation
- palette serialize/deserialize/absorb, grid adopt/forEachIn/chunkKey
- shadow map refresh modes (sun.update: 'always' | 'static' | N frames)
- contact shadows read only each model's bottom band; keepGrid: false
  frees voxel memory after meshing (pick() falls back to mesh data)
- registry.js: named shading bundles (cel, rim, posterize, pulse,
  height-tint) composable per model via `shading`
- lab/bigworld: 16 regions (~1M voxels, 2.2M triangles, 57 draw calls)

Each piece in pieces.json can have a short name; tools/links.mjs generates
static/v/<short>/index.html, a copy of the piece's page with
<base href="/voxel/<slug>/"> and a canonical link, so the short URL serves

stage.world resolves module URLs against document.baseURI so world pieces
work from the short URL too. The cottage is /v/cot.

voxel: guard shaders against NaN/Inf (white bloom discs on mobile GPUs)
…
a74c18c
```
On a phone (Firefox/Android) single pixels went non-finite and bloom smeared
them into white discs with black centres. Fixes the likely source and every
spec-undefined op, and adds guards so one bad pixel can't bloom:
- AO: clamp the interpolated vertex AO before pow() (fully occluded corners
  interpolate slightly below 0 on mobile GPUs -> pow(negative) = NaN)
- grid lines, outline, vignette, fog, stars, moon disc: no smoothstep with
  equal or reversed edges
- NaN/Inf guards at the voxel material output, particles, the bloom input
  taps and the composite; particle colors clamped, an uninitialized global
  initialized
- ?debug overlay shows the GPU and fragment highp precision
