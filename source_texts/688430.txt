Description
Adds physically-based path tracing renderer with both CPU and GPU (CUDA) implementations for realistic lighting and global illumination.
Key Features
Dual Backend Support: CPU fallback with optional CUDA acceleration
Cook-Torrance BRDF: Physically-based material system with metallic/roughness workflow
BVH Acceleration: Spatial acceleration structure for efficient ray-triangle intersection (10-100x speedup)
Direct + Indirect Lighting: Multiple importance sampling with configurable bounce depth
CUDA Texture Support: Hardware-accelerated texture sampling on GPU
Technical Details
Implements Möller-Trumbore ray-triangle intersection
SAH-based BVH construction with nth_element partitioning
Stack-based BVH traversal (no recursion on GPU)
Russian roulette path termination for unbiased rendering
Smooth shading with interpolated vertex normals
Performance
GPU: ~178ms for 800x400 @ 256 samples/pixel (15K triangles)
BVH provides ~50-100x improvement over brute-force intersection
Usage
```
// Configure samples for quality/speed tradeoff
int samplesPerPixel = 256; // Higher = less noise

// Render with GPU (if available)
renderer.RenderScene(width, height, triangles, bvhNodes, lights, camera, samplesPerPixel);
```
Future Work
Denoiser integration (OIDN/OptiX)
Importance sampling for specular highlights
Environment map support
Progressive accumulation
