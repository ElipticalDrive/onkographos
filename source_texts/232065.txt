Motivation
The backward pass for 2D Gaussian splatting involves computing color gradient accumulation, which can be expressed as a matrix-vector product per pixel: W^T @ grad_out. The tiled GEMM approach processes each 16x16 tile independently using shared memory to cache Gaussian data.
Changes
Add : CUTLASS-style CUDA extension with tiled GEMM backward kernel
Shared memory layout: G2 structs (52B × 64), fp16 weight matrix (64×256 = 32KB), accumulators
Falls back to per-Gaussian iteration for tiles exceeding MAX_POOL=64 (Pascal sm_61 48KB shared memory limit)
Fix: build_tile_pools_gpu now uses .copy_() for tensor assignment instead of reassignment
Benchmark (P106 / GP106 / sm_61)

Notes
Forward pass is identical to existing CUDA backend (no speedup expected)
Backward pass is the main target: warp-level matvec for color gradients vs atomic accumulation
MAX_POOL=64 is constrained by Pascal shared memory limit (48KB); larger pools require Volta+ for 96KB
