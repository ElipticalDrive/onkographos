# CoT Faithfulness: Probes + Thought-Anchor Resampling

Correlational analysis comparing two signals of reasoning faithfulness in LLM chain-of-thought:

1. **Supervised probes**: Per-layer linear probes trained on hidden states to find a "faithfulness direction", using labeled faithful/unfaithful responses from the [ChainScope](https://arxiv.org/abs/2503.08679) dataset. Probe weights are projected per-token to produce token-level faithfulness scores.

2. **Behavioral resampling**: Sentence-level importance via paired resampling, following the [Thought Anchors](https://arxiv.org/abs/2506.19143) method. For each sentence chunk, we generate rollouts with and without the chunk and measure the KL divergence between the resulting answer distributions.

3. **Comparison**: Chunk-level probe scores are compared against resampling importance to test whether the probe's internal faithfulness signal correlates with the behavioral causal importance of each reasoning step.

## Structure

- `CoT-faithfulness.ipynb` -- main analysis notebook
- `lib.py` -- model loading, hidden state extraction, batched generation, answer parsing
- `anchor_lib.py` -- chunk-to-token alignment for mapping sentence boundaries to token indices
- `chainscope/` -- submodule providing faithful/unfaithful response labels (gemma-2-2b-it)
- `thought-anchors/` -- submodule providing sentence chunking utilities
- `figs/` -- output figures
