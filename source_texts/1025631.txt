Problem
The env-material studio work (#813) shipped water + grass editor-authorable kinds and DoF/chromatic-aberration post passes, but deferred two reference-parity items: raymarched volumetric clouds (as a sky option) and a soil crack/moss material-variation seam (onBeforeCompile Worley/FBM masks driven by params + seed). Without them the GrassSystemThreeJS-style "Soil Studio" and cloudy-sky look can't be reproduced end-to-end.
Context
PR feat: parametric asset studio seam — registerable kinds, schema→inspector, generators #814 added the studio seam ([FEATURE] Parametric asset studio seam — registerable kinds with param-schema inspectors and renderers #809) and the water/grass_field kinds + DoF/CA passes; the two items below are the remainder.
Sky today: packages/shell/src/weather/* / the environment sky option — no volumetric cloud layer.
Terrain detail material: packages/core/src/world/features.ts detail.material + the shell terrain material — a fixed PBR map set, no per-fragment crack/moss variation.
The studio seam is now the home for both: register a soil terrain-scoped kind (params + seed) via registerSceneKind, and a volumetric_clouds sky option.
Suggested scope
Volumetric clouds: raymarched cloud layer as a sky/environment option (density, coverage, height, speed, sun-scatter); mounted from the environment sky seam, off by default.
Soil material-variation seam: crack/moss masks (Worley + FBM) injected into the terrain detail material via onBeforeCompile, driven by params + seed; expose as an editor-authorable terrain-layer kind on the [FEATURE] Parametric asset studio seam — registerable kinds with param-schema inspectors and renderers #809 seam.
Register a soil studio (schema + resolver) as the adopter proving Harvest: first-person looter-shooter engine hardening #2, alongside water/grass.
