Phase 3 — Actual VR Rendering
Goal
Scene renders correctly in stereo on Quest 3 — left eye and right eye with correct perspective separation.
Background
Each WebXR frame provides views[2] — left/right eye — each with:
viewPose.matrix (4x4, world-to-eye transform)
projectionMatrix (4x4, eye-specific FOV)
viewport[4] (x, y, w, h — region of the render target for this eye)
Tasks
Locate Substrata's render loop entry point in webclient/ code
Locate where camera view + projection matrices are set
Locate glViewport calls
In webxr_frame_cb: loop over views[0] and views[1]:
glViewport per eye
Feed viewPose.matrix (inverted) as view matrix into Substrata camera
Feed projectionMatrix into Substrata projection
Call Substrata scene render
Add vr_mode bool flag — when true, skip normal mouse/keyboard camera update
Account for player world-position offset + head pose offset
Disable 2D HUD elements in VR mode (or defer to Phase 5)
Test with WebXR Emulator Chrome extension before Quest 3
Test on Quest 3, verify correct stereo separation
Depends on: P2
Estimated: 1-2 weeks (most complex phase)
