With the panorama (equirectangular) view on, point-cloud mode kept drawing an ordinary perspective view; only splats were rendered as a panorama.
The panorama flag now reaches the Vulkan point-cloud request, and in panorama mode the point shader projects view-space directions to equirectangular coordinates and uses radial depth; perspective, orthographic and splat rendering keep their existing paths. The panorama path adds one matrix inverse per update (about 0.14 ms per 1M-point update measured). No new UI text, no .licht change.
Tests: PointCloudVulkanProjectionTest.* (generated point cloud: points behind the camera, depth, toggling panorama on and off, unchanged perspective/orthographic output) fails before and passes after; 252 C++ and 99 Python related tests pass.
Honor equirectangular projection in point mode
