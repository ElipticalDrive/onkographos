Motivation
Provide an in-browser SDF-based “liquid” editor with GPU raymarching, boolean blending and an interactive authoring UI for authoring metaball-style forms.
Replace the previous gallery entrypoint and legacy UI surface to make the editor the primary experience in App for easier developer testing and iteration.
Ship an explicit developer guide and a short smoke-test checklist so reviewers can validate features quickly in the browser.
Description
Add a new components/SDFLiquidEditor.tsx React component that implements a full-screen raymarching shader, SDF primitives (sphere, box, cylinder), smooth union (smin) and subtraction, a liquid shading model, and an interactive control panel using OrbitControls and TransformControls.
Replace the previous App.tsx contents with a minimal entry that renders SDFLiquidEditor and removes the old thumbnail carousel, model loader, AR toggles and legacy control panel.
Implement uniform-backed primitive syncing using a MAX_PRIMITIVES uniform array and local refs (primitivesRef, selectedIdRef, smoothnessRef) to minimize reallocation and frequent shader updates.
Add README.md rewritten to document local run instructions (npm install, npm run dev), keyboard/mouse/editor controls and a concise 2-minute smoke test checklist for manual verification.
Testing
Ran npx vite build, which completed successfully and produced dist/ assets; the build output included a CSS @import ordering warning and a chunk-size warning but still finished.
No unit tests were modified or added in this change set and npm run build (which runs tsc && vite build) may still fail in this repository due to an existing TypeScript config mismatch unrelated to these changes.
