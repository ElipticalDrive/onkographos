Summary
Implements froxel-frustum volumetric fog to simulate sun/moon light scattering, built on the existing pathtracing capabilities (TLAS visibility rays) instead of shadow maps.
Frame graph (RtComposite.recordFrame, after the indirect trace): fog bake raygen → barrier → fog apply compute → barrier → DLSS-RR → exposure/bloom/display. The volume stores pre-exposed scatter + transmittance, so the downstream exposure divide stays exact and reconstruction/metering see the finished signal.
Bake (shaders/pipelines/world/fog.rgen.slang):
One thread per froxel column (render-res/8), 48 exponential view-depth slices from 0.5 blocks
Single-scattered sunlight + moonlight with per-column shadow rays via visibility() — fog shadows match surface shadows exactly, including stained glass and cutout alpha
Post-atmosphere illuminance from the same transmittance LUT + sun/moonIlluminance that drive the sky and NEE; bodies >50x dimmer than the other skip their ray for the whole column
Sky-dome ambient + airglow floor, Henyey-Greenstein phase, height falloff vs sea level, 2-octave detail noise, static IGN slice dither (temporally stable with or without DLSS-RR)
Apply (shaders/pipelines/fog/apply.comp.slang): linearizes the reversed-Z depth buffer through the projection's third row, samples the volume at each pixel's scene depth, blends scene*T+L in place.
Host wiring:
New RtVolume (3D storage+sampled image) and RtFogPipeline (apply compute pass, PushAddr push layout)
RtComposite: volume alloc sized from render res, fog.rgen.spv as world raygen index 2, three fogParams push words, gated dispatches via fogActive() — runtime toggle/retune needs no rebuild
RtPipeline: world binding 12 fogVolume, RAYGEN stage on the sky-view LUT
RtContext.createVolume + 3D-capable requireStorageImageSupport
GenerateRtBindings: FOG_VOLUME world binding + FOG pipeline spec
Config: new Rt.Fog settings (enabled, density, anisotropy, max distance, height falloff) with video-options entries, en_us locale keys, and README update. Underwater boosts density x6 with the biome water tint.
Verification
No Java/Slang toolchain is available in this environment, so this has not been compiled. Mitigations done instead:
Full git diff review of every touched file
Brace/paren balance checks on all new files
Every cross-module Slang symbol, struct field, and unit convention (100 blocks = 1 km, flags bit 0 = submerged, reversed-Z [1,0]) verified against existing code
Recommend a full build + in-game check (day/night cycle, underwater, fog toggle) before merging.

Fog apply: center-tap fallback for fully depth-rejected pixels
…
eb749df
```
When sub-pixel geometry (distant leaves, wires) depth-rejects all four
bilateral taps, every weight underflows to 0 and the guarded normalize
(0 / 1e-6) collapses the pixel to black. An epsilon-weighted center tap
falls those pixels back to their own depth's fog instead, with <=0.25%
bias on normal pixels.

Temporal fog: spatiotemporal bake jitter + history accumulation
…
a0130a9
```
Bake jitters sub-froxel XY and slice position every frame from a tiled
64^3 RGBA blue-noise volume (Christoph Peters CC0 3D noise, repacked
offline by tools/repack_bluenoise64.py; replaces the static IGN dither).
The apply pass reprojects last frame's result through the guide motion
vectors and blends it with the live bilateral upsample (0.85 feedback),
with AABB history clamping and ~10% log-depth disocclusion rejection.

History lives in a render-res RGBA16F ping-pong pair selected by frame
parity in-shader, so descriptors are written once per resize and the
read image is never the write image (no in-dispatch barrier; the
pre-apply full barrier covers the cross-frame RAW). fogParams2.w carries
the host's history-valid flag, cleared by rebuilds, fog toggles, and
skipped frames.

prevInvViewProj, teleport reset. Binding generator: FOG spec 6 -> 13
bindings, WORLD storage-image pool count covers the fog volume.

Memory: ~64MB at 1080p/64 slices (FRESH 16 + A/B 32 + ages 8 + prevDepth 8).

Fog: port previous engine's sampling discipline (depth-only R1, grid-…
…
462b286
```
…wide R2, penumbra, analytic slices)

The old froxel engine diagnosed our two artifacts in its own comments: XY
jitter walks samples across silhouettes where binary visibility cannot
converge (edge flicker), and per-froxel RNG makes neighbours disagree in
lattice-sized blotches (blockiness). Port its sampling core into our
stronger pipeline (bilateral composite + 3D reprojection stay):

- Bake columns sit on exact froxel centres: XY STBN jitter removed, fog no
  longer consumes the STBN volume (stays bound for future use).
- In-slice depth from a grid-wide shared R1 golden-ratio sequence: every
  column integrates the same depth each frame, neighbours always agree.
- Shadow rays sample a grid-wide shared R2 direction inside each light's
  disc (sun/moon angular radii, decorrelated offsets): penumbra integrates
  over frames, shaft edges go soft without extra rays. Phase keeps the
  unjittered disc centre.
- Analytic per-slice integration (S*(1-e^-sd)/s) instead of point sampling:
  exact at any optical thickness; no brightness pumping in thick slices.
- Water anisotropy 0.55 -> 0.82 (previous engine's physical value).

Side benefit: with neighbours agreeing, the accumulate fresh-cross box is
tight again, so history clamping actually works.

Fog: fix global shake (delta change tracking), exposure/medium histor…
…
ad84f95
```
…y fixes, STBN removal

The ported grid-wide shared sampling broke the accumulate fresh-box clamp's
validity condition: agreeing neighbours collapse the box onto today's fresh
value, so clamping history into it erased the temporal integral and the raw
per-frame R1/R2 jumps showed through as global shake. Fixes + hardening:

- Remove the fresh-neighbourhood box clamp; change detection is now a
  relative delta (3x + absolute floors) that fast-tracks by capping the
  effective age at 3 instead of resetting to zero: lighting steps converge
  in a few frames, penumbra fringes can't pop, the R1/R2 integral blends
  untouched. Also saves 6 fresh taps per voxel.
- Exposure compensation (previous engine's historyScale): pre-exposed
  history is rescaled by this/prev preExposure (fogParams1.z, was reserved)
  before blending, so fog tracks exposure transitions instead of lagging.
- Medium-transition reset: air <-> water lighting models must never blend
  (the old engine rejected those voxels too); submerging/surfacing now
  clears fog history like a teleport.
- Cleanup: STBN fully removed (binding 13 decl, RtStbn, world-pipeline
  layout + setter + wiring, 1MB noise volume, repack script, CC0 notice) —
  analytic R1/R2 sequences replaced it; no shader consumer remained.
