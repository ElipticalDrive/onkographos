1. Core SAT Implementation (engine/physics/include/SAT.hpp, engine/physics/src/SAT.cpp)
Projection & Interval Math: Created Projection struct representing 1D intervals [min, max] with overlap detection, containment handling, and overlap magnitude calculation.
Edge Normal Extraction: SAT::GetAxes computes unit-length 2D edge perpendicularsfor all edges of both shapes.
Separation & MTV Solver:
Projects both shapes onto each candidate axis.
Returns non-collision immediately upon detecting any separating axis (early-exit optimization).
Computes the Minimum Translation Vector (MTV), adjusting for interval containment, and ensures the collision normal consistently points from Shape A to Shape B.
### 2. Collider Enhancements (engine/physics/include/Collider.hpp, engine/physics/src/Collider.cpp)
Added ColliderType::Polygon to ColliderType enum.
Added localVertices member to store polygon vertices in local space.
Added Collider::CreatePolygon(...) factory method.
Added Collider::GetWorldVertices(const RigidBody& body) to transform local box corners or polygon vertices into world space.
Updated Collider::RecalculateProperties: Added polygon branch using the Shoelace formula to compute area, mass from density, and maximum vertex distance for broadphase AABB bounding radius.
3. NarrowPhase Integration (engine/physics/include/NarrowPhase.hpp)
Refactored NarrowPhase::ResolveBoxBox to use SAT::TestPolygonPolygon on transformed world vertices.
Added NarrowPhase::ResolvePolygonPolygon.
Updated NarrowPhase::ResolveCollision to route Box-Box, Polygon-Polygon, and Box-Polygon pairs through SAT.
Preserved existing collision signatures with zero breaking changes to higher-level engine systems.
4. Build System & Test Suite (test/SATTest.cpp, CMakeLists.txt, engine/CMakeLists.txt)
Added physics/src/SAT.cpp to ENGINE_SOURCES in engine/CMakeLists.txt.
Registered SATTest executable with CTest in the root CMakeLists.txt.
Created comprehensive test suite in test/SATTest.cpp covering:
Non-colliding separated boxes.
Overlapping boxes with exact MTV penetration depth and normal validation.
Rotated polygon (triangle) vs. box intersection.
Edge-to-edge touching contact boundary cases.
