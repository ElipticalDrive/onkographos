Summary
This PR implements post-evaluation Cotangent Laplacian surface mesh relaxation with an iterative volume-preservation penalty constraint solver in Rust, exposes the solver configuration and volumetric query API via PyO3 and C-FFI, and updates the Python SJCalc sliding joint solver to sample post-relaxation surface normals and volumetric centers.
Changes Made
Rust Core & Spatial (src/spatial/laplacian.rs, src/spatial/mod.rs, src/morpher.rs):
Created CotangentLaplacianCache to precompute mesh topology adjacencies and cotangent edge weights ($\frac{\cot \alpha + \cot \beta}{2}$).
Thread-local scratch buffers (with_scratch_buffer) to eliminate heap allocations during iterative relaxation steps (~0.15ms execution time per frame).
Implemented parallelized 3D enclosed mesh volume and volumetric centroid computation (calculate_volume_and_center) using single-pass Rayon par_iter().fold().
Added vertex surface normal calculation (calculate_surface_normals).
Integrated relax(&self, vertices: &mut Vec<Vec3>) into Morpher::evaluate() after morph delta combination.
PyO3 & C-FFI Bindings (src/python.rs, src/ffi.rs):
Exposed relaxation configuration setters (set_relaxation_enabled, set_relaxation_factor, set_max_iterations, set_convergence_threshold) and volumetric/surface query methods (get_volume, get_volumetric_center, get_surface_normals) on PyMorpher.
Added corresponding C-FFI functions (avicreator_morpher_set_relaxation, avicreator_morpher_get_volume, avicreator_morpher_get_volumetric_center).
Python Sliding Joints (lib/sliding_joints.py, lib/morpher.py):
Added update_volumetric_metrics, sample_surface_normal, and calc_volumetric_distance to SJCalc.
Updated _calc_influence scope in SJCalc to expose volumetric_center, mesh_volume, and surface_normals for joint math expressions.
Updated Morpher.update() in Python to query Rust PyMorpher post-relaxation metrics and sync them to SJCalc.
Tests (tests/test_laplacian_relaxation.rs, tests/test_sliding_joints_relaxation.py, python_tests/test_libavicreator.py):
Added Rust unit tests verifying volume preservation (< 0.5% volume change under extreme morphs vs 5% target), surface spike smoothing, volumetric metric correctness, and frame execution performance (< 3.0 ms threshold).
Added Python unit tests verifying SJCalc weight adjustments driven by post-relaxation volumetric centers and surface normals.
Added C-extension tests for PyMorpher relaxation configuration and volume query functions.
Verification
All Rust workspace tests pass (cargo test --release --workspace).
All Python pytest suites pass (bash scripts/dev.sh test).
PyMorpher C-extension integration tests pass (python_tests/test_libavicreator.py).
