The document presents a novel hierarchical voxel block hashing method for efficient integration of depth images in 3D reconstruction, allowing for adaptive resolution levels based on the complexity of the scene. This approach utilizes hash functions for data access, significantly reducing memory usage by storing only necessary details within a truncation band. Experimental results demonstrate its capability to operate at high framerates with state-of-the-art accuracy and substantial memory savings compared to traditional fixed voxel grid methods.

The document presents a novel hierarchical voxel block hashing method for efficient integration of depth images in 3D reconstruction, allowing for adaptive resolution levels based on the complexity of the scene. This approach utilizes hash functions for data access, significantly reducing memory usage by storing only necessary details within a truncation band. Experimental results demonstrate its capability to operate at high framerates with state-of-the-art accuracy and substantial memory savings compared to traditional fixed voxel grid methods.
