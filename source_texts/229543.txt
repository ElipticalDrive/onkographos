Ports the boidish volumetric cloud rendering system into the Brassica frame graph engine architecture. Features included:
Adjustable resolution rendering scale.
SVGF (Spatio-Temporal Variance-Guided Filtering) multi-pass à-trous spatial and temporal filtering.
Staggered 8x8 tile queue scheduling with Morton/Owen scrambling, priority scoring, and indirect SSBO dispatches.
Adaptive volumetric raymarching with bifurcated step size logic, bounding box space skipping, and distance-based noise LODs.
Layered self-shadowing system using an 8-height-slice deep opacity map array with 2x2 Bayer staggered updates for self-shadows and scene geometry shadows/ambient occlusion.
Full parameter reflection, ConfigManager persistence, UI controls in QuickSettingsWidget, and Vulkan-free unit tests passing cleanly in make graph-test.
