Towards true volumetric refractive index investigation in tomographic phase microscopy at cellular level - dataset
🔗 Dataset page: https://zenodo.org/records/7326417
⬇️ Download: https://zenodo.org/records/7326417
📄 Paper: none found
Six 3D refractive-index reconstructions from an optical diffraction tomography system (Warsaw University of Technology) of three cell types (SH-SY5Y neuroblastoma, A549 lung adenocarcinoma, HL-60 white blood cells), each reconstructed with two algorithms (direct inversion and Gerchberg-Papoulis with finite object support, GPSC). Each MATLAB file holds the RI volume, the sample size (dx), mean RI values and a binary cell mask.
