Image.read, read_nifti, and read_nrrd all accept load_data=False to populate grid metadata (origin, spacing, direction, shape) from the header without loading voxels (the #452 lean path). read_dicom_series (image.py:460) has no such option, so checking whether a DICOM series shares a grid with a NIfTI/NRRD file forces a full volume decode through SimpleITK.
Add a header-only path that reads series geometry (slice positions, spacing, direction, shape) without decoding pixel data, so same_grid / assert_same_grid can compare a DICOM input cheaply.
