Summary
Transforms the empty AI Studio starter into WorldGen — a full interactive procedural world generator with terrain, biomes, rivers, and optional Gemini-powered lore.
What's included
Procedural generation engine
Custom seeded Perlin noise with fractal Brownian motion
13 biomes: ocean, beach, grassland, forest, jungle, desert, savanna, tundra, snow, mountain, volcanic, swamp, and rivers
River carving from highland sources to sea level
Reproducible worlds via shareable seeds
Interactive experience
Canvas map renderer with zoom (scroll) and pan (shift+drag)
Click any region to inspect elevation, moisture, temperature, and biome
Real-time terrain parameter controls (scale, octaves, sea level, climate)
PNG export for generated maps
Polished dark UI with biome legend
AI lore (optional)
Gemini integration for world names, region descriptions, and hidden history
Graceful fallback lore when no API key is set — full experience works offline
Getting started
```
npm install
npm run dev
```
Optional: copy .env.example to .env and set VITE_GEMINI_API_KEY for AI-powered lore.
Architecture
```
src/
├── lib/
│   ├── noise.ts      # Seeded Perlin noise + fBm
│   ├── worldgen.ts   # Terrain, biomes, rivers
│   ├── colors.ts     # Biome color mapping
│   └── gemini.ts     # AI lore generation
├── components/       # Canvas, controls, region panel
└── hooks/            # World generation state
```

Pull request overview
This PR turns the starter project into WorldGen, a Vite + React + TypeScript app that procedurally generates a 2D world (elevation/moisture/temperature), renders it on an interactive canvas, and optionally generates lore via Gemini with offline fallbacks.
Changes:
Adds a seeded procedural generation engine (noise, biomes, rivers) plus world/region types.
Implements the interactive UI (canvas renderer, control panel, region inspector, styling, PNG export).
Adds optional Gemini-based lore generation (with fallback content) and updates project scaffolding/docs.
