# Analytical Modeling of 3D Volumetric Data

3D MRI volume rendering, segmentation, and interactive anatomical visualization using real-world spatial coordinates.

## Overview
This project focuses on accurately picking a point within a 3D volumetric MRI dataset and retrieving its precise, real-world spatial coordinates. It combines volume rendering, segmentation, and interactive visualization to enable reliable anatomical point localization directly within the 3D volume.

## Objectives
This project has two main targets:

1. **Interactive Point Picking** — Given a 3D volumetric MRI scan, enable interactive point selection within the volume and return the accurate real-world coordinates of the selected point, supporting anatomically meaningful analysis of the underlying structures.
2. **Optimal Voxel Value Range Selection** — Determine the best voxel value range that best represents the volume, to be used for rendering and analysis.

## Approach
This project is built using **computer graphics techniques**, leveraging:
- **VTK** (Visualization Toolkit)
- **ITK** (Insight Toolkit)

Two possible approaches were considered for visualizing and interacting with the 3D volume:
1. **Surface Rendering**
2. **Volumetric Rendering**

**Volumetric rendering** was chosen as the primary method, mainly due to computational power constraints, making it a more practical fit for this project's requirements.

## Detailed Methodology

Using the Python packages VTK and ITK, a volume-rendered representation of the 3D MRI scan is generated.

Point picking is performed using a two-point method:
1. **Surface Point** — The user selects a point directly on the surface of the rendered volume.
2. **Corrected Point (2mm Offset)** — A second point is computed 2mm away from the surface point, along the perpendicular direction to the surface at that location. The coordinates of this corrected point are the ones printed as the final output.
