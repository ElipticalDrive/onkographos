Add --no-interop parameter to disable CUDA-OpenGL interoperability
```
When the --no-interop flag is provided to the ALIEN GUI:
- CUDA-OpenGL interop API calls are bypassed
- Rendering data is copied from GPU to CPU using cudaMemcpy
- CPU-side data is uploaded to OpenGL buffers via glBufferSubData

This is useful for systems where CUDA-OpenGL interop doesn't work.

Co-authored-by: chrxh <73127001+chrxh@users.noreply.github.com>
```
