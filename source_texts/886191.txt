Hi there
I'm a new pyvista user and so far have found it very useful. I have some inconsistencies when using the ray_trace module. So far am I just looking at the intersection of rays with a generic cylinder.
I generate a number of rays all begin at the same point and finish at a point corresponding to a 101x201 grid. I then intersect these rays with a cylinder to obtain the points of intersection. This scenario is repeated after rotating the rays around the cylinder.

Rotated scenario:
I then compute the distance of each ray from source to the point of intersection. The results should be identical for each scenario due to the symmetric nature of the problem, however I'm finding that the distances returned are slightly different.
I've attached a code snippet below for reference.
```
import numpy as np
import math
import pyvista as pv
import pyvistaqt as pvqt

draw = pvqt.BackgroundPlotter()

flatmesh = pv.Plane(center=(0,0,0), direction=(0,0,1), i_size=40, j_size=20, i_resolution=200, j_resolution=100)
# Rotation angle is either 0 or -15
flatmesh.rotate_x(0)
draw.add_mesh(flatmesh, color='Red', lighting=False, show_edges=True, opacity=0.25)

points = flatmesh.GetPoints()
flatmesh_coords = vtk_to_numpy(points.GetData())

cyl= pv.Cylinder(radius=10, height=40, center=(0.0, 0.0, 0.0), direction=(1.0, 0.0, 0.0), resolution=5000, capping=True)
draw.add_mesh(cyl, color='Yellow', lighting=True, show_edges=True, opacity=0.5)


# Ray coordinates are either [0, 0, 100] or [0, 25.8819, 96.59258]
intersection_coordinates_cyl = []
for i in range(len(flatmesh_coords)):
    cyl_point, cyl_cell = cyl.ray_trace([0, 0, 100], [flatmesh_coords[i][0], flatmesh_coords[i][1], flatmesh_coords[i][2]], first_point=True, plot=False)
    intersection_coordinates_cyl.append(cyl_point)
intersection_coordinates_cyl = np.array(intersection_coordinates_cyl)

# First point is either [0, 0, 100] or [0, 25.8819, 96.59258]
cyl_distarr=[]
for i in range(len(flatmesh_coords)):
        dist = math.sqrt((0 - intersection_coordinates_cyl[i][0])**2 + (0 - intersection_coordinates_cyl[i][1])**2 + (100 - intersection_coordinates_cyl[i][2])**2)
        cyl_distarr.append(dist)
distarr = np.array(cyl_distarr).reshape(101,201)
print(distarr)
```
I've also noticed that for the first array in the distance matrix, the values are not symmetric along the length of the cylinder. The first and last 3 values are different and I have no clue why.
I would greatly appreciate any help with this! Thank you so much!

When you make a pv.Cylinder, it's generated using vtkCylinderSource, which is a polygonal cylinder. Most likely, when you call ray_trace, the rays are being intersected with the individual polygonal facets making up the cylinder. As you rotate the cylinder, where the rays strike the surface of the polygonal cylinder will change, leading to the error you see. The magnitude of this error will decrease if you increase resolution, but will approach machine precision very slowly, since the facets are flat.
To get machine precision like you want, you would need to represent the cylinder using an implicit surface instead. I doubt that this can be done with PyVista.
