config sections

```
paths: ...
dataset: ...
model:
  tag: <source encoder tag>
  freeze_encoder: true
embeddings:
  input_dir: ...
voxel_dataset:
  input_dir: .../voxel_supervision/...
decoder:
  spec: frozen_embedding_decoder_v1
  embedding_dim: 384
  class_count: 6
  hidden_channels: [128,64,32]
  upsample_factors: [[2,2,2],[2,2,2],[2,2,2]]
tiles:
  core_size_tokens: [8,8,8]
  context_halo_tokens: [1,1,1]
train:
  epochs: 50
  batch_size: 1
  learning_rate: 1.0e-3
  weight_decay: 1.0e-4
  class_weight: balanced
  seed: 42
  num_workers: 0

  gradient_clip_norm: 1.0
```

output contract
```
latest.pt
best.pt
resolved_config.json
run_metadata.json
history.csv
train_tile_manifest.json
validation_tile_manifest.json
```
checkpoint payloadは最低限:
```
epoch / global_step
model_state_dict
optimizer_state_dict
amp_scaler_state_dict optional
best_selection_state
training history current metrics
resolved config
class weights
source embedding metadata path/hash
source valid-token path/hash
voxel dataset metadata/split-grid hash
tile manifest hashes
RNG states
checkpoint kind
```
best checkpoint
固定されたselection rule:
```
primary: validation macro_f1 higher
secondary: validation mean_iou higher
tie: validation weighted CE lower
```
epsilonを明示し、deterministicに選択してください。training hyperparameter tuningを自動化しないでください。
resume
--resume <latest.pt> でepoch boundaryまたは保存したstepから再開。
source artifact hash、decoder architecture、tile manifests、class weightsが一致しないresumeを拒否。
optimizer/scaler/RNGを復元。
completed runにresumeした場合の挙動を明確にする。
CLI
```
python proc/seis_ssl_cluster/train_f3_lithology_voxel_decoder.py \
  --config <yaml> \
  --dry-run

python ... --config <yaml> --device cpu --max-steps 2
```
Support:
```
--dry-run
--device auto|cpu|cuda
--max-steps N
--resume PATH
```
Dry-runはarray全読込やtrainingをせず、geometry/source identity/output planを表示します。
runner要件
encoder/checkpointをロードしてforwardしない。入力はprecomputed embeddingのみ。
common class weightsはvoxel dataset train countsから計算。
fixed epochs。early stoppingは初期benchmarkでは追加しない。
output collisionはresume/overwriteなしで拒否。
historyはepochごとのtrain/validation primary metrics。
logにvoxel数を独立sample数としてconfidence claimしない。
テスト
config validation/unknown keys。
CPU 2-step end-to-end。
latest/best selection。
resume exact continuation。
identity mismatch resume rejection。
completed checkpoint behavior。
source embeddingが更新されない。
output collision。
dry-run no-write。
standard JSON/history CSV。
