Volumes with unknown modality now start with a grayscale appearance fitted to their scalar distribution. The three adaptive presets offer Transparent, Balanced, and Surface appearances; declared CT, MR, and US metadata select the corresponding medical defaults, with an adaptive fallback when the selected absolute-range preset would be fully transparent. Explicit and saved settings take precedence.
The rendering controls can reset the current preset's color and opacity settings while preserving lighting. Preset thumbnails use the same fitted settings as the volume view. See the adaptive fitting and default selection.
The opacity editor cancels superseded histogram calculations so switching presets cannot restore an older histogram.
