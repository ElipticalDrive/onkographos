Issue body actions
Unsupported for SDF bodies:
Sensors and trigger events.
Shape casts, which include Rapier’s kinematic character controller (if it ends up being used).
Continuous collision detection — there is no sweeping collision detection.
Mesh, terrain, and compound colliders.
The engine currently exposes only boxes, spheres, planes, raycasts, and raycast vehicles, so there are no conflicts yet (this is an issue in and of itself of course).
Raycasts Work – PhysicsWorld::raycast hits SDF surfaces, and vehicle wheels use rays too. I didn’t specifically test a vehicle driving on SDF ground.
Rapier’s contact-reuse shortcut is off for any pair involving an SDF body – This is disabled with a no-op filter. That only costs performance for those pairs. If the engine later adds its own physics hooks, they’ll also receive SDF pairs.
No authoring path yet – SDF bodies are code-only for the time being.
