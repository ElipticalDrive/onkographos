💡 What
Extracted global WebGL program activation (gl.useProgram) and uniform settings (uVP, uCamera, uTorch, uSunDir, uFogColor, etc.) out of per-chunk rendering (drawWorldMesh) into prepareWorldProgram(), which is called once per render pass (programOpaque and programWater).
🎯 Why
Previously, drawWorldMesh was setting all 15 global WebGL uniforms on every single chunk mesh (25–81 chunks rendered twice per frame = 50–162 calls to set 15 uniforms each frame, totaling 750–2,430 GL API calls per frame). None of these uniforms vary per chunk mesh!
📊 Impact
Reduces global WebGL uniform calls by >90% per frame (from ~1,500 down to 30), significantly lowering CPU driver overhead during WebGL rendering and providing a smoother framerate.
🔬 Measurement
Verified locally with node -c and automated Playwright E2E suite evaluating BlockRealmDebug.selfTest(). All 7 self-tests pass.
