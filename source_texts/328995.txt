In order to properly determine what needs to be rendered, we need some bounding volumes.
I think, this needs to go into the gfx layer, because it is of graphical nature only. We only need to determine the volume for graphics rendering, e.g. is the light intersecting or is the camera intersecting an object.
For physics I will use JOLT anyways, so why making a big fuss about it.
We need the following volumes:
sphere
aabb
obb
frustum
I think this is enough for the beginning. Keep it simple. And then, those volumes need to be easily accessable in the scene graph, so we can group volumes.
So for the scene graph we need:
bounding_volume_component
So any visitor can access it.
