Resolution
Decision
Place one storage-independent seam at the Voxel Frontend interface. A Render Path consumes a pinned Voxel Scene View and derives everything renderer-specific from that view; it never observes a dense layout, SVO nodes, packed storage words, balancing operations, or a shared GPU acceleration representation.
Scene and value semantics
A Voxel Scene View presents one monotonically ordered Voxel Scene Revision and a revision-consistent catalogue of:
Voxel Volumes with stable identities, finite integer-local bounds, scene-space origins, and uniform voxel sizes. Rotation and non-uniform scale are outside the first-five-milestone contract.
Voxel Materials with stable identities and linear base colors. Occupied voxels are opaque in this contract; broader material and transparency models are deferred.
A Voxel Value is either Empty or a Voxel Material identity. Storage Tier encodings are not Voxel Values.
Query semantics
A Render Path requests an axis-aligned integer-coordinate Voxel Region within a named Voxel Volume. The Voxel Frontend returns the logical Voxel Values in arbitrary batches. Batch shape, order, and partition are non-semantic: dense scanning and SVO traversal may batch differently, but consumers must reconstruct identical coordinate/value contents.
Coordinates outside a valid volume's finite bounds are logically Empty so meshing-neighbor reads and ray exits share one rule. An unknown volume or material identity is an explicit error rather than empty space.
Revision, change, and asynchronous semantics
A Voxel Scene View is read-only and remains stable while its handle is retained, even if later edits publish newer revisions. This lets meshing, upload, and traversal-data preparation run asynchronously without edit locks or whole-scene canonical copies.
A Voxel Change Set spans a base revision and a result revision. It reports storage-independent semantic invalidations for:
volume addition, removal, bounds, origin, or voxel-size changes;
material catalogue changes; and
changed Voxel Regions.
Changed regions may conservatively over-report but must never omit changed coordinates. Change sets carry invalidations, not editor commands, SVO operations, or required value patches; consumers re-read the result Voxel Scene View. Consecutive change sets may be coalesced. Change history is bounded, and an unavailable revision range returns an explicit resync requirement so the Render Path rebuilds from the latest view.
Ownership
The Voxel Frontend owns logical scene state, edit semantics, Storage Tier selection, view lifetime, and change history. Each Render Path owns all derived CPU/GPU state, including greedy meshes, compute-traversal structures, upload scheduling, caches, and any later KHR acceleration structures. Derived work may be discarded or superseded when a newer revision arrives; publishing it must remain revision-aware.
Camera and render parameters, hit/image results, and presentation stay on the Render Path/Render Backend side. They are not Voxel Frontend scene semantics.
Alternatives rejected
Locked live reads couple rendering latency to edits.
Whole-scene canonical copies undermine the sparse-tier proof.
Per-voxel-only reads make bulk meshing and GPU preparation pay a shallow repeated-call interface.
Fixed canonical bricks impose a second layout on both dense and SVO tiers.
Value-bearing patches duplicate region reads, while edit-command logs couple rendering to user intent.
Shared acceleration structures leak one Render Path's needs across the seam.
Roadmap consequence
The second through fifth milestone candidates can now share one stable contract: dense and editable-SVO Storage Tiers sit behind the Voxel Frontend, while greedy raster and compute ray Render Paths consume the same versioned scene, region, material, and change semantics. The evidence ticket retains ownership of exact scenes, scales, correctness comparisons, timing targets, and measurement protocols.
This clears the map fog around GPU ownership, snapshot granularity, change propagation, and asynchronous scheduling. It surfaces no new Wayfinder ticket.
