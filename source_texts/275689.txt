Description
Combined sub-etapes 41b (per-froxel emissive sampling → neon light shafts)
and 41c (spatial blur + temporal reprojection) into one PR. Iterative
quality work in this session showed that single-frame Monte Carlo over
17 000 emissive triangles is fundamentally too noisy without temporal
filtering — Frostbite / Wronski 2014 always pair the two for that reason.
41b — emissive sampling (inject_density.slang)
Per-froxel CDF-weighted emissive triangle pick (4 samples per froxel)
TLAS shadow ray with RAY_FLAG_CULL_NON_OPAQUE so glass / pillar don't
block volumetric light
Henyey-Greenstein phase function (g = 0.6, atmospheric haze)
Per-sample firefly clamp (3.0) before averaging
Inject DSL extended: binding 0 = froxel image, 1 = TLAS, 2 = emissive SSBO
Push constants 112 → 128 B (frame_count, emissive_count,
total_emissive_power, hg_g)
41c — spatial blur + temporal reprojection (volumetric_filter.slang, NEW)
Replaces the iteration-3 standalone blur shader with a single filter pass
that does both spatial 3×3 XY blur AND temporal reprojection
Reprojects froxel centre through prev_view_projection, samples last
frame's filter output trilinearly, EMA-blends with α = 0.1
Two ping-pong filter images (history alternates each frame)
One-shot startup UNDEFINED → GENERAL transition for the ping-pong
pair; per-frame barriers use eGeneral → eGeneral so history survives
Cross-frame compute MemoryBarrier2 added at top of recordFrame
alongside the existing fragment-stage reservoir barrier
Push constants 176 B (two mat4s + camera_pos + alpha + dimensions +
flags + near/far) — exceeds Vulkan-spec-min 128 B but well within RTX
4090's 256 B budget
Other
Grid resolution bumped 160×90 → 320×180 (×4 cells; ~30 MB per
image × 3 = ~90 MB volumetric VRAM). At 1280×720 each froxel covers a
4×4 px screen tile rather than 8×8 — visibly finer light-shaft detail.
Effective sample count per froxel: 4 inject × 9 spatial × ~10 temporal
≈ 360. Reads as soft cyberpunk atmospheric haze rather than animated
noise.
Docs: PBR.md Volumetric Fog section rewritten end-to-end (filter
pass, ping-pong, temporal reprojection math, cross-frame barrier
rationale). VISION.md / ARCHITECTURE.md tables updated for the
three-pass pipeline. CLAUDE.md + README.md status paragraphs.

Additional Notes
The Volumetric Fog section in docs/PBR.md documents the math for both the
emissive sampling estimator (joint-area PDF derivation, Henyey-Greenstein
formula, Z reprojection inverting the logarithmic depth mapping) and the
ping-pong synchronisation rationale. Worth a read for the why-not-just
questions.
Future fidelity improvements are queued for Phase 8 Etape 42 (temporal
denoising for all RT output — likely SVGF / A-SVGF — which would naturally
extend to volumetrics; bilateral upsample in composite; depth-aware fog
cutoff; RIS for volumetric in-scattering).
