Prototype
5cm fixed grid with deduplication and interpolation along continuous controller motion (VoxelWorld).
Squeeze/grip rising edge toggles Gallery vs Paint mode. In Paint mode, hold trigger and move an aim-pose brush tip ~12cm forward to draw. Existing gallery manipulation remains unchanged when toggled back.
First Vulkan renderer draws shader-animated cube voxels using existing procedural pipeline. 2048-cell hard limit, one draw per cell (temporary; hardware instancing next).
Transient voxels only, no eraser/serialization/material picker yet.
Test
Build Quest APK on branch feature/voxel-airbrush-v01, install, squeeze once, then hold trigger and trace a curve in air. Squeeze again to restore sculpture manipulation. Validate continuous lines and original interactions.
Not built or tested on device yet; please do not merge before validation.
This PR intentionally targets PR #6's scene foundation instead of main.
