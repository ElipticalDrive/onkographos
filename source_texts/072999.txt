WAVE Client Renderer is a Three.js-based library for Volume Rendering via Ray Casting.
GPU accelerated Volume Ray Casting is usually implemented multi-pass rendering.
The first pass of shaders is very simple. It draws to the texture coordinates (at object coordinates) of position their the rays hit the back side of cube.
You can find examples of GLSL shaders, with ejs templet below.
firstPass.frag
```
Copyprecision mediump int; 

precision mediump float; 



varying vec4 backColor; 



void main(void) 

{ 

    gl_FragColor = backColor; 

} 
```
firstPass.vert
```
Copyprecision mediump int; 

precision mediump float; 



attribute vec4 vertColor; 



varying vec4 backColor; 

varying vec4 pos; 



void main(void) 

{ 

    backColor = vertColor; 



    pos = projectionMatrix * modelViewMatrix * vec4(position, 1.0); 

    gl_Position = pos; 

}  
```
The second pass performs an actual sampling of the data and visualization of final image.
