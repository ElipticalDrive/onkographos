Summary
This PR significantly enhances block texture generation by introducing procedural detail layers built from tileable noise functions. Rather than flat colors or simple per-pixel jitter, textures now feature geological structure (fractured rock with veins), natural material variation (soil with damp patches, sand with wind ripples, gravel with varied pebbles), and weathering effects (worn mortar, chipped brick corners, moss/rust tints on ores).
Key Changes
New Noise Primitives
Added deterministic spatial hash functions (hashi, hashf) for position-based randomness
Implemented periodic value noise (pnoise) with configurable period for seamless tiling
Added fractal Brownian motion (fbm) for multi-octave geological mottling
Implemented Worley/cellular noise (worley) for discrete lumps (stones, pebbles, ore nuggets)
Added ridge function for thin vein/crack patterns
Shared Material Builders
rockShade(): Fractured rock with plate structure, dark fractures, mineral veins, and surface detail
soil(): Packed earth with damp patches, tiny pebbles, root strands, and clod grain
New Block Textures
Added dirt pattern using the soil builder
Added sand pattern with wind ripples, dune shading, and grain clusters
Added gravel pattern with varied-size rounded pebbles and deep crevices
Enhanced Existing Patterns
speckle: Now uses tileable mottle instead of pure jitter for softer variation
brick: Added course jitter, worn mortar erosion, corner chips, diagonal cracks, and weather stains
cobble: Redesigned with Worley cells for individual stone identity, warm/cool tinting, and weathered edges
planks: Added horizontal grain streaks, knots with rings, and saw marks
rings: Added warp for organic growth rings, pith darkening, and radial season cracks
bark: Redesigned with vertical furrows, deep grooves, and bark cracks
ridges: Redesigned as rounded ribs with areoles (spine bumps)
grassTop: Uses clump field for tufted growth with cool shaded pockets and sunlit blade tips
grassSide: Irregular overhang depth per column, dangling blades, and seamless soil transition
stone: Thin wrapper over shared rock builder
leaves: Worley-based clumps with overlapping light/shadow masses and faceted edges
glass: Enhanced sheen band, secondary polish streaks, and corner glints
lantern: Per-pane glow cores fading to warm amber, mullions, corner brackets, and metal wear
ore: Material-aware rendering (coal=matte, iron=rusty metal, gold=bright specular, gems=faceted)
glow: Luminous pods in honey base using Worley clustering
bookshelf: Varied book spine widths/colors, leaning books, missing slots, and shelf shadows
furnace: Iron band with rivets, ember glow gradient, and hot coal glints
tallGrass: Tapered blade silhouettes with sunlit tips
flower: Petal ring with bright center and stem leaf
Notable Implementation Details
All noise is periodic at 16px (TILE) so textures tile seamlessly across block faces and walls read as continuous material rather than obvious repeating grids
Worley cell scales (4 or 8) divide TILE for clean seams
Position-hashed detail (veins, cracks, stones) is independent of draw order, enabling consistent appearance across any viewing angle
Material feel is derived from color properties (luminance for ore types, hue for warm/cool tinting)
Shared builders (rockShade, soil) ensure cohesive appearance across related blocks (ore sits in stone, grass sides match dirt)

Rewrite every procedural pattern with tileable spatial-noise structure
(position-hashed value noise, fbm, and Worley cellular helpers) so surfaces
read as real material instead of static. Because each block face samples one
shared 16px layer, the new structural detail is made seamless at period 16, so
a wall reads as continuous rock/soil/sand rather than an obvious repeating grid.

- stone: fractured plates, quartz veins, cracks, chips, geological mottle
- dirt: packed soil, pebbles, roots, moist patches (shared spec with grass
  sides/bottom so they dedup to one layer)
- grass: clustered blades + irregular overhang with dangling blades
- cobble: packed weathered stone setts with mortar + per-stone tone
- brick: worn/eroded mortar, cracked & chipped bricks, uneven courses, stains
- planks: horizontal wood grain, knots, saw marks, per-board tone
- logs: warped growth rings + bark rim (top); vertical bark furrows (side)
- sand: seamless wind ripples + grain clusters; gravel: rounded size-varied pebbles
- leaves: overlapping sunlit / shadowed foliage clumps
- glass/lantern/glowstone/bookshelf/furnace: polished pane, warm graded glow,
  luminous pods, varied book spines, firebox embers
- ores: per-ore identity derived from the spot color (matte coal, rusty iron,
  gold specular, emerald/crystal facets) with clusters + veins in a stone matrix
- speckle: gentle mottle so snow/water/mud/terracotta aren't flat static

Adds dedicated dirt/sand/gravel patterns (blocks.ts) reusing existing colors.
No block ids/shapes/light/opacity or save format changed; deterministic output,
16x16 resolution, layer dedup, and all public APIs preserved.
