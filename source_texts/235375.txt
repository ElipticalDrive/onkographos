Overview
Implement Milestone 1 (M1) of OMG4 integration into LichtFeld Studio: the ability to load pre-trained OMG4 4D Gaussian Splat models and render them in real-time with time scrubbing via the existing Sequencer playhead.
This covers Phase 1 (Core Data Model), Phase 2 (4D Rasterization Backend), and the loader portion of Phase 4 (I/O).
Reference: The OMG4 paper is at https://arxiv.org/html/2510.03857v1 and the reference implementation is at https://github.com/MinShirley/OMG4
Phase 1: Core Data Model — SplatData4D
1.1 Create SplatData4D class
Create a new class SplatData4D that extends the existing SplatData (in src/core/include/core/splat_data.hpp) with additional temporal attributes required by 4D Gaussian Splatting.
New file: src/core/include/core/splat_data_4d.hpp
SplatData4D should inherit from or wrap SplatData and add:
Tensor _t — temporal center position [N, 1]
Tensor _scaling_t — temporal scale in log-space [N, 1]
Tensor _rotation_r — right-isoclinic 4D rotation quaternion [N, 4]
float time_duration[2] — the time range (e.g., [-0.5, 0.5] or [0.0, 10.0])
bool rot_4d — flag indicating whether 4D rotation is used
Add computed getters mirroring OMG4's GaussianModel:
get_t() — returns _t
get_scaling_t() — returns exp(_scaling_t) (activated)
get_rotation_r() — returns normalize(_rotation_r)
get_cov_t(scaling_modifier) — computes the temporal variance component from the 4×4 covariance
get_marginal_t(timestamp, scaling_modifier) — computes the Gaussian temporal marginal exp(-0.5 * (t - timestamp)^2 / sigma_t)
Also add raw tensor accessors (t_raw(), scaling_t_raw(), rotation_r_raw()) following the same pattern as SplatData's existing means_raw(), scaling_raw(), etc.
Add serialization support (serialize/deserialize) that extends SplatData's serialization with the 4D fields.
New file: src/core/splat_data_4d.cpp
Implement the SplatData4D methods. The key math to port from OMG4 is the 4D covariance conditioning. From OMG4's gaussian_model.py:
```
def build_covariance_from_scaling_rotation_4d(scaling, scaling_modifier, rotation_l, rotation_r, dt=0.0):
    L = build_scaling_rotation_4d(scaling_modifier * scaling, rotation_l, rotation_r)
    actual_covariance = L @ L.transpose(1, 2)
    cov_11 = actual_covariance[:,:3,:3]
    cov_12 = actual_covariance[:,0:3,3:4]
    cov_t = actual_covariance[:,3:4,3:4]
    current_covariance = cov_11 - cov_12 @ cov_12.transpose(1, 2) / cov_t
    symm = strip_symmetric(current_covariance)
    mean_offset = cov_12.squeeze(-1) / cov_t.squeeze(-1) * dt
    return symm, mean_offset.squeeze(-1)
```
This computes the Schur complement to condition the 4D Gaussian on time, yielding a 3D covariance and a spatial mean offset.

Phase 2: 4D Rasterization Backend
2.1 CUDA kernel for 4D→3D conditioning
New file: src/cuda/condition_4d.cu (or placed alongside existing CUDA code in src/rendering/rasterizer/)
Implement a CUDA kernel condition_4d_gaussians_kernel that:
Takes as input: means [N,3], t_centers [N,1], scaling_xyzt [N,4], rotation_l [N,4], rotation_r [N,4], opacities [N], and a scalar float playhead_time
For each Gaussian i:
Compute dt = playhead_time - t_centers[i]
Build the 4×4 scaling-rotation matrix L using build_scaling_rotation_4d() (port from OMG4's utils/general_utils.py)
Compute the 4×4 covariance: Σ = L @ L^T
Extract Σ_11 [3×3], Σ_12 [3×1], σ_t [scalar]
Compute conditioned 3D covariance: Σ_3d = Σ_11 - Σ_12 @ Σ_12^T / σ_t
Compute mean offset: Δμ = (Σ_12 / σ_t) * dt
Compute marginal opacity: α_t = α * exp(-0.5 * dt² / σ_t)
Output: conditioned means_3d [N,3] (original means + offset), conditioned opacities_3d [N], and conditioned 3D covariance parameters (or equivalent scale/rotation that the existing rasterizer expects)
The build_scaling_rotation_4d function constructs a 4×4 matrix from 4D scaling and left/right isoclinic rotations. From OMG4's reference:
Build rotation_l (4×4 left-isoclinic) and rotation_r (4×4 right-isoclinic) from the two quaternions
Build diagonal scaling matrix S from 4D scaling
L = rotation_l @ rotation_r @ S
Provide a C++ host wrapper: void condition_4d_gaussians(...) that launches the kernel.
