Phase 11, milestone 29: engine channel packing (decision 0208).
Controls: no new keys or mouse actions. One new row in the Export window: Realism maps.
What it does
Painted roughness, metal and glow now go out with exports.
Inside a glTF (Godot, Unity, Unreal, Blender, Solis): roughness and metal as glTF's own map, an "ORM" image (occlusion in red, roughness in green, metal in blue), and glow as an emissive map. Engines read these by themselves.
Export → Realism maps (shown while a painted material uses the realism channels) adds files beside the model:
In the file (standard): nothing more for glTF; an OBJ gets an ORM beside it.
ORM beside it: for Godot's and Unreal's materials set up by hand.
Unity mask map beside it: what Unity's HDRP wants (metal, occlusion, detail mask, smoothness). The Unity preset picks this.
Separate maps beside it: roughness and metal as two grey files.
OBJ materials name them (map_Pr, map_Pm, map_Ke), so tools that read PBR materials from OBJ pick them up.
Every map is padded like the colour, and the texture budget lists each map by name (colour, ORM, glow, mask map…).
The choice is remembered with the other export settings.
Two things wait for later, said in the decision and the manual:
Occlusion inside the ORM and mask map is white for now (it darkens nothing). Engines add their own, and a baked one can be painted in from Bakes.
Normal maps come with height and normal painting (milestone 32).
Tests
fileio: a glTF holds roughness and metal as its own ORM (factors 1, nothing beside it as standard); the ORM holds white occlusion, roughness and metal, named in an OBJ's .mtl with -imfchan; glow goes out as emissive (glTF and OBJ map_Ke); Unity's mask map goes beside a glTF with smoothness in alpha; separate grey maps are named by map_Pr and map_Pm; hand-painted sets send out only their colour.
ui: the Export window shows Realism maps and lists the ORM in the budget; the Unity preset asks for the mask map beside the file; the choice is remembered.
Local checks (all passed): cargo fmt --all -- --check, cargo clippy --workspace --all-targets -- -D warnings, cargo doc with warnings as errors, cargo test --workspace, the UI reference pictures and render GPU tests (REQUIRE_GPU=1, Mesa), cargo build -p app, cargo deny check, the window smoke test.
How to test
Paint a cube with the realism channels (see the last pull request): a steel + Fill (Metal 100%, Roughness 25%) and some rust.
File → Export, made for Godot, into a Godot project. In Godot, the material shows the steel's shine and the rust's dullness (Godot's material shows a Metallic and Roughness texture).
Paint a glowing spot (Glow) and export again: Godot shows it glowing (Emission is on).
Choose Unity: Realism maps reads Unity mask map beside it, and a _MaskMap.png lands beside the .glb.
Custom settings → OBJ: an _ORM.png sits beside the .obj and its .mtl names it. Try Separate maps beside it too.
The Texture budget lists each map.
