What is asked
A study of procedural generation for objects (props, assets) and materials (roughness, wear, layering), with cited sources.
Why it matters: The owner listed materials, objects and roughness first in his request, and no report answers it.
What is true today
The five procedural-generation reports barely cover it: none covers objects, and materials appear only through Unreal's Substrate.
What is missing
The study, mapped to primitives the engine can run deterministically.
How we will know it is done
A report with cited sources is in the library, and each technique it keeps names the procgen module that would host it.
