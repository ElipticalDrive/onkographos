Summary
Add an experimental normalized-Gaussian generator and held-out tabular simulation pilot, outside the public Trex API. This transfers the representation and split/refine idea from Gaussian splatting, not the image rasterizer or opacity compositing. The density family is an ordinary full-covariance Gaussian mixture; EM is the essential comparator.
Learn probability masses, means and Cholesky covariance factors with Adam likelihood fitting; use an eigenvalue floor to prevent covariance collapse.
Grow from 1 to 32 components with principal-axis splits that preserve component mass and first two moments. This is uniform doubling, not residual-directed splitting or pruning.
Compare with EM-GMM, merged WGAN/PTGAN/DDPM, training-row bootstrap, and independent target draws where available.
Include executable benchmark scripts, six mathematical checks, small result summaries, and an executed notebook with component-shape and generated-sample plots.
Experiment and findings
Three seeds each cover an eight-mode ring, a curved continuous distribution, and the 445-row Lalonde experimental sample. Transformations fit training rows only; validation selects mixture capacity; final comparisons use held-out rows. Results include 60 method/seed/dataset comparisons and 108 mixture-capacity records.

On the curved target, EM's complete capacity search takes 0.220 seconds versus 3.261 seconds for split/refine on the reference hardware. This pilot supports Gaussian mixtures as a lightweight baseline; it does not establish a general advantage from splat-style fitting.
The neural baselines use short 1,500-update runs, not tuned or convergence-certified comparisons. Training budgets differ across model families. EM runs on CPU in float64; split/refine and neural models run on an RTX 5070 in float32. GPU times are synchronized and mixture fit times include the entire capacity search.
Validation
python -m pytest -q -o addopts= benchmarks/gaussian_tabular/test_model.py: 6 passed in the existing Torch environment.
Checks cover independent SciPy log-density agreement, moment-preserving splitting, sampling moments/reproducibility, finite-difference covariance gradients, bimodal fitting, and input validation.
All EM fits report convergence; final baseline uses float64 to avoid float32 sampling covariance warnings.
Review notebook executed successfully; rendered figures, mathematics, and mobile/desktop report layout checked.
Public package code is unchanged; the full Trex suite was not run. Existing repository CI builds documentation, not these estimator tests.
Scope and limitations
Lalonde reuses existing binary rounding and nonnegative clipping. It is not a correct mixed discrete/continuous likelihood; no held-out density likelihood is claimed for Lalonde.
The treatment/outcome regression diagnostic is a descriptive association, not causal-effect recovery or inferential coverage.
No privacy guarantee, conditional sampler, residual-directed densification/pruning, or production API is introduced.
Next comparisons should separate fixed-K EM, adaptive EM and adaptive Adam, then add proper categorical/Bernoulli and hurdle support.
