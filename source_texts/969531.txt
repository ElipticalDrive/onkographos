Parent roadmap: #36 · Task ID: VG-R4-02 · Stage: R4
Work owner: Virtual Geometry GPU compute and CPU oracle
Source touchpoints: Source/Renderer/VirtualGeometry/; Source/Renderer/Occlusion/; Shader/VirtualGeometry (native); traversal fixtures
Blocked by: #40 (VG-R1-02), #49 (VG-R3-03), #50 (VG-R4-01)
Objective
Culling chooses complete groups of resident clusters based on bounds, cone tests, screen error and conservative hierarchical depth occlusion.
Implementation contract
Implement root-to-child traversal, per-instance bounds, projected error metric, parent fallback, cone/backface tests, first/post Hi-Z if validated, visible cluster compaction, bounded work queues and indirect command creation. Build independent scalar CPU reference oracle.
Acceptance
CPU/GPU visible set equivalence within conservative false-positive tolerance; no gaps or double geometry across cuts; camera teleport/fast rotation, depth conventions, size changes, overflows, missing pages and occlusion-history invalidation covered.
Negative cases
Holes at LOD boundary; stale Hi-Z occludes newly visible object; queue overflow silently drops required parent; GPU traversal accesses evicted page.
Protected ownership
No isolated Vulkan/D3D12 culler implementation; both use same logical visible meshlet set.
Required evidence
Pinned source SHA; ABI/format and compilation evidence; locally achievable 100% line/branch/function module coverage with CTest/GoogleTest, relevant sanitizer checks; real Vulkan/D3D12 capture and budget traces where this task touches GPU. Stage/issue status stays open until these are observed, not merely designed.
CPU oracle and cross-tier extension (2026-11-04)
Implement deterministic CPU complete-group LOD cut first from the same hierarchical SIRPack bounds/monotonic error and residency snapshot for every backend. The compiled logical cut/draw plan is #269 and cannot depend on compute/Hi-Z/indirect/GPUScene mirrors. GPU traversal and visibility are optional accelerated implementations which must reproduce the selected complete surface coverage; conservative extra draw is permitted, missing group is not. No occlusion-dependent child refinement before all sibling pages are ready. Validate child fallback, camera teleports, invalid GPU depth history and queue overflow with geometry coverage oracle; GL1.2/D3D7 paths never require native Hi-Z.
