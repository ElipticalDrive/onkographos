What to do
Compute the star grain SDF using angular sector decomposition — exploit the N-fold rotational symmetry to simplify the calculation.
Steps
Convert grid coordinates to polar: $r = \sqrt{x^2 + y^2}$, $\theta = \text{atan2}(y, x)$
Map $\theta$ into one sector: $\theta_{sector} = \theta \mod (2\pi / N)$
Within one sector, the star profile is a curve from the valley radius to the tip radius
Compute the signed distance to this profile
The SDF for the whole star is the same as the SDF in one sector (by symmetry)
Key details
The sector approach reduces the problem to computing distance to a single "tooth" of the star
The profile within a sector can be parameterized as straight lines from tip to valley
Watch out for the seam where sectors meet — the SDF must be continuous across sector boundaries
torch.atan2 is the PyTorch function for 2-argument arctangent
Done when
The SDF correctly represents the star shape in all sectors
No discontinuities or artifacts at sector boundaries
The zero contour matches the expected star profile
Dependencies
Implement StarGrain class #77 — StarGrain class
Design note — analytical SDF is validation/optional (June 11, 2026)
This grain's closed-form signed_distance is an exact, validation-time convenience: it gives a noise-free starting field and a reference to check the numerics against. It is not required. Arbitrary and uploaded geometry flows through the generic pipeline — object → mesh → generalized winding number sign field (#158) → numerical SDF (#3) → φ — and this grain may use that same path. The simulator must never depend on every grain having a closed-form SDF. See #135 for the unified pipeline.
