Summary
Two native noise operators for the two octave loops at the top of the fractal_clouds profile (#736 comment, "Still slow" item 3):
```
x y oct gain lac offset wgain angle ridgedmf2 v   % Musgrave's ridged multifractal
x y oct gain lac angle erodedfbm2 v               % derivative-damped ("eroded") fBm
```
Operand order differs from the issue's sketch. oct gain lac comes first, as in fbm2/ridged2, and gain keeps the family's meaning: the amplitude ratio per octave (Musgrave's H is gain = lac^-H). Musgrave's feedback gain is wgain.
oct is an int or a real in 0..32. The fractional last octave's term is scaled by the remainder, so detail fades in continuously.
angle (degrees) rotates the domain each octave: p' = lac·R(angle)·p, plus the existing k·SHIFT offset.
ridgedmf2 follows Musgrave's RidgedMultifractal. Each octave's signal is sig = (offset-|n|)²·w, and the next weight is w = clamp(sig·wgain, 0, 1). His early exit is dropped so the sum is exact.
erodedfbm2 follows the common (Quílez) formulation. It keeps a running gradient sum d += ∇n and adds amp·(n / (1 + d·d)) per octave.
Frozen algorithm, as perf: native noise operators (noise2/noise3, value noise, fBm) #734.
Fixed f64 operation order, spelled out in the module header.
cos/sin go through fmath exactly as the PostScript operators do.
One IEEE division per octave in erodedfbm2. It is correctly rounded and so deterministic; the header now names it.
References. lib/noiseref.ps gains nrridgedmf2/nrerodedfbm2, and tests/noise.rs holds them bit-equal.
The test covers 4 seeds × 40 points × 8 octave walks × 5 shapes: octave counts 0, 0.3, 2.5, 4.999, 5, 5.0 and 32.0; angles 0, 37, −90, 360 and 21.5; and both edges of the weight clamp.
It is sensitive enough that re-associating one addition in the reference fails it (94 of 1600 samples differ).
Pinned values, edge cases (including linear fade-in), errors, and --sweep-seed reach are tested too.
Catalog and docs. Catalog rows in src/capabilities.rs, a runnable psart skill example (checked by tests/skill_blocks.rs), the pscat skill listing, docs/guides/artkit.md, HANDOFF, and notes/845-ridged-multifractal-eroded-fbm.md.
Timing. µs per call at 5 octaves, gross per loop iteration, best of 3 × 200k iterations, Apple M4 shared at load ~9. The empty-loop floor is 0.13.
