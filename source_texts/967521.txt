Summary
Greedy meshing replaces per-face quads on the default path.
Measured before writing it: one terrain chunk (a solid 32³ stone layer) emitted
6144 quads per-face; merging brings that to 6. So the win is real, not assumed.
Sweeps per face direction, builds a per-layer mask of "what type, if anything, draws
here", extends a run along v, then replicates it along u.
Only same-type cells merge — different materials go to different meshes.
Blocked cells never enter the mask, so merging subsumes face culling.
The subtle part is winding: the four corners are hand-assembled, so u × v must
equal the face normal. Get it wrong and backface culling draws the face from inside —
while vertex counts and surface area still look right.
The per-face path stays, reachable via cull_hidden_faces = false, both as an escape
hatch for raw geometry and as the independent implementation the tests compare against.
One self-correction worth flagging: my first comparison test asserted the two paths
produce the same vertex set. That judges successful merging as failure — merging's whole
point is dropping interior vertices. The correct invariant is equal surface area, which
is what the committed test checks.

Greedy meshing replaces per-face quads on the default path. Measured first:
one terrain chunk (a solid 32^3 stone layer) emitted 6144 quads; merging brings
that to 6, so the win is real rather than assumed.

The implementation sweeps per face direction, builds a per-layer mask of "what
type, if anything, draws here", and extends a run along v then replicates it
along u. Only same-type cells merge, since different materials go to different
meshes. Blocked cells never enter the mask, so merging subsumes face culling.

The subtle part is winding: the four corners are hand-assembled, so `u x v` must
equal the face normal. Get it wrong and backface culling draws the face from
inside -- while vertex counts and surface area still look right.

The per-face path stays, reachable via `cull_hidden_faces = false`, both as an
escape hatch for raw geometry and as the independent implementation the tests
compare against. My first comparison asserted equal vertex sets, which judges
successful merging as failure; the correct invariant is equal surface area.
