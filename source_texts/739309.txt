Purpose and dependency
Draft, nonproduction stacked PR. This branch is based on Checklings preproduction PR #302. It advances Grant's approved twelve huge persistent biomes by proving nearby terrain streaming, 35/70-player synthetic interest behavior, and a viewable offline 12-biome map inspector. Claude remains the game/design integration lead.
No live game code, student accounts, school PINs, saved trainers, rewards, deployments, or protected Design Bible were changed.
Completed implementation
Chunk streaming and shared cache: chunk-stream.mjs serves only nearby 32×32 versioned immutable terrain, with per-actor 3×3 interest windows, a bounded LRU, 3-chunk delta on a chunk boundary, map/instance isolation, strict inputs, and actor visibility derived from the other actor's occupied chunk (not mere window overlap).
Synthetic classroom load: chunk-stream-benchmark.mjs models 35 or 70 trainer subscriptions clustered/distributed over 256×256 and 512×512 regions. Counts raw uncompressed JSON payloads, chunk generation, eviction, hits and local CPU cost. It is not a WebSocket, Chrome or classroom network test.
Seed-stable organic footpaths: organic-routes.mjs replaces the initial giant straight debug-cross roads with curved, two-tile-wide connected trails between all nine authored destination points per biome. Passes the existing reachability checks and deterministic chunk reconstruction. Bridge markers remain stable across generated chunks.
Baseline ecological terrain separation: a small read-only terrainWithoutDebugPaths export in the already-experimental prototype.mjs ensures the organic overlay does not show the old grid roads underneath. No production module was modified.
Offline world inspector: map-preview.mjs generates a self-contained HTML map inspector for all twelve biomes, with dropdown selection, zoom/pan, tile hover, symbolic tile colors, nine landmark labels and seeded geographic persistence. It was rendered and visually reviewed in headless Chrome on TheAtlas; the screenshot caught the debug grid artifact that was then fixed.
Readiness report: docs/checklings/preproduction/CHUNK-STREAMING-READINESS.md gives the exact results, a proposed server-authoritative streaming protocol, privacy guards, cache tradeoffs and real Chromebook/network rollout gates.
Verified on TheAtlas
30/30 new targeted tests passing.
76/76 combined tests passing, including all 46 parent PR Checklings: 300-line biome roster, balance baseline and isolated worldgen proof #302 experiments, with source downloaded at exact child branch commit.
12 biome preview datasets verified (256×256), with 512×512 jungle and arctic route tests.
Offline HTML includes no external asset or server dependencies; unsafe seed text cannot inject HTML.
Representative synthetic results (not real student load)
35 trainers clustered in one 512×512 jungle: 315 chunk copies sent, 12 unique terrain chunks generated in total across initial join and one shared chunk crossing, about 418,110 bytes of initial uncompressed JSON for all 35.
One boundary crossing adds only three new chunks per trainer and removes three; six remain subscribed.
70 dispersed trainers over two 512×512 regions: ~795,064 bytes of initial JSON, 599 historical chunk generations, 503 evictions in a deliberately small 96-chunk global cache. This exposed a genuine tuning tradeoff for wide distribution.
Do not confuse cache generation with completed gameplay scalability: no real WebSockets, collision-safe mobile clients, SQLite transaction load, remote game saves, actual images/sprites, 35 physical school Chromebooks, or network latency were tested.
How to review
Review/merge PR Checklings: 300-line biome roster, balance baseline and isolated worldgen proof #302 first. This is a dependent, draft child PR, not a standalone release.
Inspect CHUNK-STREAMING-READINESS.md and the chunk-stream and organic-routes tests.
Optionally generate a standalone 12-region world inspector with node apps/checkaverse/experiments/worldgen/map-preview.mjs <scratch-preview.html>; it can also generate 512-square samples with --512.
Claude should decide how the proposed protocol fits signed Check-In identities, authoritative movement, dynamic residents and travel between actual Wilds gates. This lab itself is not ready to import into server.mjs or the school-facing client.
Keep draft until design lead signs off on an isolated network/browser integration and real classroom QA, especially save/reconnect, privacy and teacher pause.
Scope: No live deployments. No new playable biomes, maps, sprites or Checklings were advertised as finished.
Final visual QA note
After inspecting Bramblefen in headless Chrome, the first map preview still showed the parent experiment's straight debugging crossroads. That issue was fixed by separating the base ecological terrain from the debug paths and then overlaying deterministic curved routes. The revised Bramblefen preview was visually checked. Verdant Crown (jungle) and Frostglass Reach (arctic) were also rendered separately through the standalone file's ?region=verdant_crown and ?region=frostglass_reach selections. Their symbolic habitat patterns are distinguishable, but all twelve are still based on a shared nine-anchor geometry; unique biome-specific macro layouts and original art remain unsolved and are explicitly flagged in the readiness document.
The full isolated parent-and-child Node suite was rerun after the final inspector changes at exact commit 0ec74faa911bde311599e892d144fd715455091e: 76/76 passed on TheAtlas. This remains a nonproduction engineering/design proof, not a playable student map.
