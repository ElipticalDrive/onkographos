Summary
Enhance the 3D pressure field visualization to show the vector dynamics of the pressure field — not just the scalar magnitude. These features make wave propagation, spiral structures, and convergence zones directly visible, and serve as validation tools for nowcast inference development.
Proposed features
Phase 1: Gradient flow lines (streamlines)
Compute pressure gradient vectors from the grid using finite differences
Trace streamlines by integrating particles along the gradient field
Render as curved lines draped on the 3D surface (same technique as state boundary lines)
Between interacting H/L systems, these will visually reveal spiral inflow/outflow patterns
Toggle in the scene controls toolbar
Phase 2: Vorticity overlay
Compute curl of the gradient field (scalar vorticity on the 2D surface)
Render as a color overlay or heatmap on the pressure surface
Highlights areas where the atmosphere is "spinning" at the mesoscale
Useful for identifying developing rotation signatures from pressure data alone
Phase 3: Convergence/divergence shading
Compute divergence of the gradient flow field
Convergence zones (negative divergence) = likely updrafts — shade warm
Divergence zones = subsidence — shade cool
Bridges the horizontal pressure pattern to vertical motion
Phase 4: Temporal animation
Store a rolling window of pressure grids (2-3h, ~24-36 snapshots at 5-min intervals)
Animate the 3D surface over time — pressure waves visibly propagate
Playback controls (play/pause, speed, scrub) similar to the radar timeline on MapView
Requires backend support: ring buffer of grid snapshots (in-memory or SQLite)
Implementation notes
Phase 1 is self-contained and can land independently
Gradient computation: central finite differences on the 120x120 grid
Streamline integration: 4th-order Runge-Kutta on the gradient field, fixed step count
Surface draping: same bilinear height sampling as StateBoundaryLines (toScene() pattern)
Render as THREE.Line segments with configurable color/opacity
Phase 4 depends on backend changes to retain grid history
Relationship to nowcast
These visualizations double as development/validation tools for wave dynamics inference in kanfei-nowcast. See companion issue in that repo.
