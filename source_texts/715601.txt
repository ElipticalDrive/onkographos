System Information

Issue description
Setting a custom projection, one with an oblique (tilted) near plane, for a Camera3D using camera_set_xr_projections breaks how shadows render in the image. More specifically, distant shadows disappear, and close shadows appear sharp and only show at odd angles.
Figure 1: The top half shows the faulty behaviour, and the bottom half shows the expected.
An image from a projection with a tilted near plane should ideally have the same shadows as a typical, untilted perspective projection.
Steps to reproduce
Open the MRP in 4.8-beta1+, and play the main scene.
Move around the scene with WASD + Mouse to observe the lack of shadow in the mirror.
Notice the objects in the mirror cast no shadows despite having them outside of it. In certain positions, such as the one in Figure 3, you can actually see shadows, and observe that they are much sharper in the mirror image than outside.
Press Tab to toggle the mirror camera between a normal perspective projection and an oblique one. Shadows now match the scene... but you can unfortunately see the post that exists behind the mirror.
Enter will freeze the image from the mirror camera and F will hide it completely.
Figure 3: Finicky camera position that showcases unusually sharp shadows in the reflection.
Without the MRP... the issue will be a little harder to reproduce or observe. In a new 3D scene with a DirectionalLight3D with shadows enabled, a Camera3D, and objects to cast and receive shadows, select a plane to serve as the custom near clip plane, making sure the normal points away from the camera. (The camera must be 'behind' the plane.) Use the function below to build an oblique matrix.
```
# Produces a perspective projection such that the
# near plane is the arbitrary `clip`.
static func oblique_perspective(camera: Transform3D, clip: Plane, fov: float, aspect: float, near: float, far: float) -> Projection:
	var p := Projection.create_perspective(fov, aspect, near, far)
	var inv := camera.affine_inverse()
	var n := inv.basis * clip.normal
	var c := Vector4(n.x, n.y, n.z, -n.dot(inv * clip.get_center()))
	var q := Vector4((signf(c.x) + p.z.x) / p.x.x, (signf(c.y) + p.z.y) / p.y.y, -1.0, (1.0 + p.z.z) / p.w.z)
	var c2 := c * (2.0 / c.dot(q))
	p.x.z = c2.x
	p.y.z = c2.y
	p.z.z = c2.z + 1.0
	p.w.z = c2.w
	return p
```
Pass this in a single element array (i.e. [projection]) with your Camera3D's RID to RenderingServer.camera_set_xr_projections() in _process and move around.
