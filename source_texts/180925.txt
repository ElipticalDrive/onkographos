The SparseGrid class is the central data structure in svox2 (Plenoxels) that efficiently represents volumetric scenes using a sparse voxel grid. Rather than storing data for every point in a dense grid, it only allocates memory for non-empty voxels, allowing for high-resolution representations with manageable memory usage. This page documents the implementation, interfaces, and usage of the SparseGrid class.
For information about how rays interact with this grid, see Camera and Rays. For details on different basis functions used to represent view-dependent effects, see Basis Functions.
Overview
SparseGrid stores scene information in a sparse format using:
Density values (opacity) at each voxel
View-dependent color information using various basis representations
A link structure that maps 3D coordinates to data indices
The class supports operations for sampling points in the grid, volume rendering, and gradient-based optimization.

Data Structure
The SparseGrid represents a 3D scene with the following key components:
Links Tensor: A 3D tensor of indices mapping grid coordinates to data indices in the sparse arrays. Empty voxels are marked with -1.
Density Data: Stores opacity values for each non-empty voxel.
Feature Data: Stores color/appearance information using various basis representations (e.g., spherical harmonics).
Optional Background Model: For representing distant scene elements without requiring a large grid.

Initialization
SparseGrid can be initialized with various parameters to control grid resolution, bounds, and basis function types:
ParameterDescription
resoGrid resolution (int or [x, y, z])
radiusHalf-size of grid in world units
centerCenter of grid in world units
basis_typeType of basis function (SH, 3D texture, MLP)
basis_dimDimension of basis functions
use_z_orderWhether to use Z-order curve for data layout
use_sphere_boundWhether to use spherical bounding instead of cubic
When initializing, the grid can be constrained to a sphere rather than a cube by setting use_sphere_bound=True, which helps reduce memory usage for scenes that are roughly spherical.

Resampling and Grid Modification
SparseGrid supports dynamic resolution changes through the resample method, which creates a new grid at higher resolution while maintaining sparsity:
```
Apply thresholdOriginal GridSample density at new resolutionWeight or Sigma ThresholdingCreate sparse maskOptional: Dilate maskReindex linksSample colors at sparse locationsCreate new sparse grid
```
The resample method is crucial for multi-resolution optimization strategies:
```
# Increase grid resolution while preserving datagrid.resample(    reso=256,                # New resolution    sigma_thresh=5.0,        # Density threshold    weight_thresh=0.01,      # Weight threshold (if cameras provided)    dilate=2                 # Dilation of mask for preserving neighborhoods)
```
The grid can also be modified to use a different basis dimension:
```
# Change the number of spherical harmonics coefficientsgrid.resize(basis_dim=16)  # Must be a square number for SH
```

Integration with PyTorch
The SparseGrid class extends nn.Module, making it fully compatible with the PyTorch ecosystem:
Parameters like density_data and sh_data are PyTorch nn.Parameter objects
Gradient computation is supported for optimization
Custom autograd functions are implemented for efficient backpropagation
It can be used with PyTorch's optimization algorithms
This integration enables end-to-end differentiable rendering and optimization.

Summary
The SparseGrid class is the foundation of the svox2/Plenoxels system, providing an efficient representation for volumetric scenes. Key advantages include:
Memory Efficiency: Stores only non-empty voxels
Speed: CUDA-accelerated operations for sampling and rendering
Flexibility: Supports different basis functions for view-dependent effects
Differentiability: End-to-end gradients for optimization
Scalability: Allows dynamic resampling for multi-resolution optimization
Understanding how SparseGrid works is essential for effectively using the svox2 library and developing novel neural rendering techniques.
