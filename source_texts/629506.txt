This PR introduces two highly useful mathematical features for generating complex, porous structures and structural infills directly during the voxelization process:
Gyroid Infill: Users can now specify a --gyroid-scale and --gyroid-thickness to hollow out solid geometries with a Gyroid TPMS (Triply Periodic Minimal Surface). This is incredibly useful for 3D printing, reducing weight while maintaining structural integrity.
Porosity Simulation: The --porosity argument allows users to specify a probability (0.0 to 1.0) to uniformly omit internal solid voxels, creating a sponge-like interior structure. This is implemented using a high-frequency, sine-based pseudo-random hash function for deterministic and high-performance noise generation.
Both modifiers intelligently fall back and are safely bypassed if the user requests a --surface-only export, preventing logical conflicts or empty shells. Tests and benchmarks have been updated accordingly.

Validate modifier inputs
When users pass invalid numeric modifier values such as --porosity 2 or --gyroid-thickness -0.1, these fields are accepted as plain f64s and the later voxel filter deterministically drops every interior voxel (hash < p is always true for p > 1, and val.abs() > negative is always true). That can silently produce empty particle sets or fail VOX export instead of rejecting values outside the advertised probability/thickness domain; add finite/range validation here or in voxelize.
