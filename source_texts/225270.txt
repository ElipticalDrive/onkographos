Feature description
Atta currently relies on traditional rasterization techniques for rendering, which, while fast, often requires approximations for complex lighting effects like soft shadows, accurate reflections, and refractions. To achieve a higher level of visual fidelity and more realistic sensor simulation (especially for cameras), implementing ray tracing is essential.
Ray tracing simulates the physical behavior of light, enabling photorealistic rendering with physically accurate lighting, shadows, reflections, and refractions. Integrating real-time ray tracing capabilities, similar to those found in simulators like NVIDIA Isaac Sim, would significantly enhance Atta's visualization quality and provide a foundation for highly realistic simulated camera sensors crucial for robotics applications like vision-based navigation and manipulation.
This feature proposes integrating a real-time ray tracing pipeline into Atta's rendering engine.
Tasks
Research real-time ray tracing APIs and hardware requirements (e.g., Vulkan Ray Tracing, DirectX Raytracing (DXR), NVIDIA OptiX).
Choose the most suitable ray tracing API based on Atta's architecture, target platforms, and performance goals.
Integrate the chosen ray tracing API/SDK into Atta's build system and graphics backend.
Implement or integrate support for building acceleration structures (e.g., Bounding Volume Hierarchies - BVHs) from scene geometry.
Modify the rendering pipeline to incorporate ray tracing passes (e.g., for primary rays, shadows, reflections).
Develop ray generation, intersection, and shading shaders/programs.
Extend material definitions to include properties relevant for ray tracing (e.g., reflectivity, roughness, index of refraction).
Integrate ray tracing with the existing scene representation and lighting system.
Optimize the ray tracing implementation for real-time performance on supported hardware.
Implement UI options to enable/disable ray tracing features and control quality settings (e.g., sample counts, ray depth).
Test thoroughly with various scenes, lighting conditions, and hardware configurations.
Update documentation regarding rendering options and requirements.
