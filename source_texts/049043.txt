# sdf-editor

A visual node-based editor for ray-marched Signed Distance Field scenes

## About

This project is meant for pedagogical purposes and to play around with Signed Distance Fields. Any modern browser should be good to run it, but beware that touchscreen interaction is not great.

More information about the project can be seen in the [slides](./Slides.pdf). A live version is available in [sdf.shaie.ar](https://sdf.shaie.ar/).

Some sample scenes are provided in the [Sample Scenes](./Sample%20Scenes/) folder. Import them from the frontend to see! (Click on the file selector on the lower-left corner, and then update on the lower-right).

## Running the project

Make sure `code-gen.wasm` is present in the `public/` directory of the frontend (this is provided in this repo). Otherwise, use `go` to build from the [code gen](./code-gen/) module. 

To run the frontend:
- `yarn install` the dependencies in the `frontend/` folder
- `yarn dev` to run the development server


Alternatively, build the frontend with `yarn install` and `yarn build`, and open `frontend/dist/` on a static server allowing CORS (otherwise the cubemaps won't be able to be loaded from the iframe). A simple way to do this is using the VS Code live server. **NOTE: Open VS Code on the dist/ folder for serving! otherwise the browser will block the requests.**
