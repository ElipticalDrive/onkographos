Implements the complete NG-GS pipeline from scratch on a skeleton repository. Takes a trained 3DGS model as input, identifies boundary Gaussians via 2D segmentation, builds a continuous feature field with RBF interpolation and Multi-Resolution Hash Encoding (MRHE), then jointly optimises NeRF + 3DGS to enhance boundary detail.
Pipeline
```
Trained 3DGS → Boundary Detection (SAM) → RBF + MRHE Feature Field → NeRF-GS Joint Optimisation → Refined model
```
New modules
models/gaussian_model.py — 3DGS model: per-Gaussian attributes (xyz, SH, scale, rotation, opacity), PLY I/O, covariance construction, Adam param groups
models/feature_field.py — MRHE: N nested hash grids at geometrically increasing resolutions, trilinear interpolation per level, MLP decoder; follows Müller et al. (Instant-NGP)
models/nerf_model.py — NeRF MLP with sinusoidal positional encoding, MRHE geometry feature injection, static volume_render integral
utils/boundary_detection.py — renders training views, runs SAM (or mock) per-view, extracts boundary pixels via mask erosion/dilation (OpenCV → scipy → numpy fallback chain), votes across views to label each Gaussian
utils/rbf_interpolation.py — RBF interpolant supporting gaussian, multiquadric, inverse_multiquadric, thin_plate kernels; Cholesky solve with ridge regularisation; chunked evaluation
utils/camera_utils.py — pinhole Camera dataclass, world↔camera transforms, per-pixel ray generation, stratified ray point sampling
scene/dataset.py — COLMAP binary + text format readers (cameras.bin/txt, images.bin/txt), SceneDataset PyTorch Dataset
pipeline.py — orchestrates all four steps; joint optimisation loop blends GS photometric loss with boundary-focused NeRF loss (lambda_boundary, nerf_weight)
train.py — full CLI entry-point via argparse mapping to NGGSConfig dataclasses
config.py — typed dataclasses for all hyper-parameters (Gaussian, Segmentation, RBF, MRHE, NeRF, Train)
Example usage
```
python train.py \
    --data_dir   data/garden \
    --ply_path   output/point_cloud/iteration_30000/point_cloud.ply \
    --num_iterations 10000 \
    --lambda_boundary 0.5 \
    --nerf_weight 0.5 \
    --output_dir results/garden
```
Use --seg_backend mock to run without a SAM checkpoint (useful for dry-runs).
