Overview
Raw voxels are grey-scale by default (no colour information from LiDAR). Photogrammetric projection paints RGB colour onto the voxel surface by projecting captured camera frames onto the 3D geometry using known camera pose and intrinsics — the same technique used in photogrammetry pipelines.
The result is a single 4 096 × 4 096 GPU texture atlas (MTLTexture) that maps UV coordinates to real-world surface colour. The StructurePass fragment shader samples this atlas via UV coordinates stored in PackedVoxel.
Metal compute pipeline:
```
For each camera frame:
    1. Metal compute kernel: for each voxel surface in camera frustum,
       project worldPos → camera NDC → image UV
    2. Visibility test: voxel normal dot camera direction > 0 (front-facing only)
    3. Confidence accumulation: higher confidence = more recent or more frontal observation wins
    4. Atomic write to atlas texel (blending via running average)
```
Subtasks
Design UV coordinate packing: PackedVoxel gains uv: SIMD2<UInt16> (normalised 0–65535 → 0.0–1.0), update struct to 20 bytes (or pack into existing 32-bit field)
Define TextureAtlas class: MTLTexture (4096×4096, BGRA8Unorm), tile allocator (row-first packing), allocate(size: SIMD2<Int>) -> CGRect
Metal compute shader texture_projection.metal:
Input: MTLTexture (camera RGB frame), MTLBuffer (voxel positions), camera intrinsics + pose uniform
Project each voxel to image space, sample bilinear, blend into atlas texel (running average)
Atomic counter per texel for confidence weighting
TextureProjector actor: queues frames from capture session, dispatches compute kernel
TextureProjector.project(frame: MTLTexture, pose: Pose3D, intrinsics: simd_float3x3) async
Atlas serialisation: TextureAtlas → PNG chunks for .botmap section type 8
Atlas deserialisation: PNG → MTLTexture on load
Swift Testing: project a known solid-colour frame onto a known voxel — assert atlas texel matches input colour within ± 5 intensity units
Dependencies
Blocked by #2 (PackedVoxel), #9 (capture session provides frames + poses), #14 (StructurePass must sample atlas UV)
Acceptance Criteria
After projecting 50 frames of a white wall scan, ≥ 90% of visible wall voxels have non-default colour (not [128,128,128])
Atlas tile allocation never overlaps (allocator correctness test)
Atlas PNG serialise → deserialise → MTLTexture round-trip: pixel values preserved within ± 2 intensity units (PNG quantisation)
Compute kernel runs in < 10 ms per frame for a 256×192 depth map + 4 096 × 4 096 atlas on M1 Pro GPU
StructurePass renders textured voxels visually consistent with input video colour
Implementation Notes
Atomic texel blend: Metal atomic_fetch_add on packed RGBA not available; use separate atomic_uint confidence buffer + separate colour accumulator, normalise on read
Camera intrinsics matrix: [[fx, 0, cx], [0, fy, cy], [0, 0, 1]] — cx, cy are principal point in pixels
Atlas tile size: start with 64×64 per chunk face — 4096/64 = 64 tiles per row → 4096 tiles total (more than enough for typical maps)
UV packing in PackedVoxel: replace flags: UInt8 with u: UInt8, v: UInt8 (low res, 256×256 per tile is sufficient)
