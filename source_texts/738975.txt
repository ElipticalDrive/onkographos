Project Description
Retro Raycasting Engine is a pseudo-3D game engine built from scratch using vanilla JavaScript, mimicking the rendering technology of 90s classics like Wolfenstein 3D.
Instead of using modern 3D libraries (like Three.js), this project uses Raycasting mathematics. It casts imaginary rays from the player's viewpoint into a 2D grid map. It calculates the intersection distance using trigonometry and the DDA (Digital Differential Analyzer) algorithm to render vertical wall strips on the HTML5 Canvas, creating the illusion of a 3D environment.
Key Features
DDA Algorithm: Implements the efficient "Digital Differential Analyzer" algorithm for fast grid traversal and wall collision detection.
Trigonometric Rendering: Uses raw Math (Cos, Sin, Tan) to calculate field-of-view (FOV) and correct "fish-eye" lens distortion.
First-Person Controller: Custom input handling for movement and camera rotation within the mathematical world space.
Minimap Overlay: A top-down 2D view that renders the ray paths in real-time for debugging and navigation.
Texture Mapping (Procedural): Generates shading effects based on distance (lighting falloff) to enhance depth perception.
