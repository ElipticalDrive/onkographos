Descripción
Detectar colisiones evaluando el SDF de la escena para cada entidad. Distance < 0 = penetración.
Tareas
Evaluar SDF para cada entidad con collider
Detectar penetración (distance < threshold)
Calcular collision info: point, normal, depth
Batch collision queries en GPU
Ejemplo de Código
```
struct CollisionInfo {
    hit: u32,
    point: vec3<f32>,
    normal: vec3<f32>,
    depth: f32,
}

@compute @workgroup_size(64)
fn detect_collisions(@builtin(global_invocation_id) id: vec3<u32>) {
    let idx = id.x;
    let pos = positions[idx].xyz;
    let radius = colliders[idx].radius;
    
    let dist = eval_scene(pos);
    
    var info: CollisionInfo;
    if dist < radius {
        info.hit = 1u;
        info.normal = calc_normal(pos);
        info.depth = radius - dist;
        info.point = pos - info.normal * dist;
    }
    
    collision_results[idx] = info;
}
```

Update — consume ActiveOrigin from ome_core::coord (added 2026-04-26 ter post-#50 merge)
ome_core::coord ships the hierarchical coordinate system: UniverseCoord (i32 sector + DVec3 offset, sector size 1024 m), LocalCoord (relative to a celestial body via CelestialBodyRef), CameraRelativeCoord (f32 near zero for GPU consumption), and the ActiveOrigin resource (the universe coord that defines (0, 0, 0) of the simulation frame).
When this issue is implemented, the physics system MUST:
Read ActiveOrigin (resource, inserted by CorePlugin) to know the world anchor of the simulation frame.
Run all collision detection in the active local frame — entities' GlobalTransform.translation is already relative to ActiveOrigin, so f32 precision stays good.
For physics regions far from the active origin (feat(physics,streaming): PhysicsActiveRegion — distance-based simulation enable/disable via Rapier islands #311 PhysicsActiveRegion), convert query positions to the chunk's local frame via LocalCoord::from_universe(world, chunk_origin, chunk_ref) so each chunk's collision math runs in its own near-zero f32 frame.
Subscribe to origin rebase events (filed as a follow-up to Hierarchical coordinate system #50; helper check_rebase already exists): when the active origin shifts by delta, every cached collision pair's positions get the same shift applied. The decision logic is in ome_core::coord::rebase; the apply step is owned by physics.
f64 escape hatch: for cross-sector queries (rare, e.g. orbital simulation), rebuild positions via UniverseCoord + delta in f64, run the math, cast back. Default hot path stays f32.
This is not part of #50's scope — coord system foundation shipped in PR #314. This is the consumption contract that physics owes when it lands.
