PBI-342 — Thin-film iridescence
Milestone: M45 OpenPBR Surface — Physically-Based Realistic Mode (Ray-Traced) · Feature: F03 BSDF/Lobe Evaluator
Goal
Add the thin-film interference term, embedded in the Fresnel term per the spec (not a
separate slab), derived via Airy summation.
Scope / work
thin_film_weight/thin_film_thickness/thin_film_ior interference term, via the
spec's recommended Belcour & Barla model ("A Practical Extension to Microfacet Theory
for the Modeling of Varying Iridescence", ACM TOG 2017 — index.html §Thin-film-
iridescence cites this as [#Belcour2017]; not the arXiv id originally listed here,
which does not correspond to a real paper and was written before the spec's full text
was fetched locally).
API contracts (interfaces / enums / collections)
None — internal shading library.
Acceptance criteria
CPU oracle test reproduces the expected iridescent color shift vs. thickness/angle
(measurable R/G/B separation at representative thicknesses, and non-monotonic
reflectance across a thickness sweep at fixed angle — the two defining signatures of
Airy-summation interference).
thin_film_weight=0 reproduces PBI-341's output exactly.
Depends on
PBI-341.
