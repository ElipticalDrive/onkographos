Abstract:
This paper presents a bidirectional path tracing algorithm for multiple light sources based on triangular grids. Ray tracing algorithms face challenges in lighting computation cost as the number of light sources increases. Existing methods face issues with storage resource waste. The proposed algorithm quickly builds a triangular mesh on the object surface, randomly samples each mesh for light source visibility tests, and filters out low-contributing light sources, thereby reducing storage space consumption. The algorithm pre-computes visibility between objects and light sources by sampling triangle grids, enhancing the efficiency of the bidirectional path tracing algorithm in multisource scenes and achieving real-time global illumination. A comparative analysis, conducted within the Falcor open-source rendering framework, revealed that the proposed algorithm exhibited comparable image quality to WRRBDPT, yet demonstrated significantly superior temporal performance.

I. Introduction
Ray tracing algorithms obtain global lighting effects with higher realism by simulating the propagation of real light in the scene. In scene rendering, light sources have always been an important factor affecting the cost of light calculation. As the number of light sources increases, the number of rays that need to be computationally simulated at each point in the ray tracing algorithm also increases linearly, and the lighting computation cost grows accordingly. Quickly filtering out non-contributing or lower-contributing light sources is an effective way to reduce the lighting computation cost.
