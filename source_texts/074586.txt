In principle, we should treat
filename (str)
array (array_like) + edges + origin
grid (Grid)
also as part of how to treat the input argument grid.
To make this approach maintainable and extensible, we should be thinking about breaking the loading process into steps
format detection
dispatch to a loader that returns either a Grid or a wrapper data structure
extract data from loader into the Grid (if necessary)
Ideally, we have the loader functionality bundled with the wrapper classes when possible so that all format-specific code lives in the same place.
