In this algorithm the user first specifies a threshold（阈值） value.
在该算法中，用户首先指定了一个阈值。
For this value, some voxels will be entirely inside or outside the corresponding isosurface（等值面） and some voxels will be intersected by the isosurface.
对于这个值，一些体素完全在等值面内部或者外部，一些体素会与等值面相交。
In the first pass of the algorithm the voxels that are intersected（分割的） by the threshold value are identified.
在该算法的第一阶段中，被阈值分割的体素将会被确定。
In the second pass these voxels are examined and a set of one or more polygons is produced, which are then output for rendering.
在该算法的第一阶段中，体素将会被检测，一个或多个多边形将会被产生，然后他们将输出。
Each of the voxel's 8 vertices can be either inside or outside of the isosurface value, thus, there are 2^8 = 256 possible ways in which a surface can intersect the voxel.
每个体素的8个顶点都可以等值面是内部或者外部，因而，每一个体素2 ^ 8 = 256种可能的方式。
By symmetry these 256 ways can be reduced to 15.
通过对称性可以将这256种可能减少到15 种。
The exact edge intersection points are determined and the polygons are created.
确切的边缘交叉点得到确定并予以创建的多边形。
Use a Table Lookup to Reduce Edge Intersection Tests
使用查表来减少边缘相交测试
Basic Idea
基本思路
1）For Each Cell Through Which an Isosurface Passes Create Small Polygons
每个单元通过该等值面通行证创建小多边形
2）Approximating the Surface Within the Cell
近似平面内的细胞
3）Surfaces Intersect Edges Where Vertices Bracket the Threshold
表面相交边的顶点在哪里支架的阈值
Marching Cubes Algorithm移动立方体算法
User Specifies Threshold Value用户指定阈值
Read Four Slices(切片) Into Memory读四块切片到内存
Scan Middle Two Slices and Create a Cell扫描中间两片，并创建一个单元格
Classify Eight Vertices. Construct Index Number.
对八个顶点进行，构建索引号。
Use Index to Look Up List of Edges
使用索引查找边缘
Find 3 Surf/Edge Intersections via Linear Interpolation
通过线性插值查找3表面/边缘交点
Calculate Unit Normal (Gradient) at 3 Intersections
计算单位法线（梯度）
Output the Triangle Vertices and Vertex Normals
输出的三角形顶点与顶点法线
