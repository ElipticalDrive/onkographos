Summary
Implements the foundational architecture and first 4 core issues for Milestone 1 (Friday demo), including full material support (diffuse, dielectric glass, metal mirror) driven by stage_basis:
Issue Repo skeleton, CMake, Eigen, OpenMP #1: Modern CMake build skeleton with Eigen 3.4.0, OpenMP, nlohmann/json, and stb (closes Repo skeleton, CMake, Eigen, OpenMP #1)
Issue stage basis: local frame at a normal #12: stage_basis local orthonormal frame at a surface normal ($Q \in \mathrm{SO}(3)$) via Duff et al. (2017) and classical Gram-Schmidt with JSON trace validation ($Q^T Q = I_3$, $\det(Q) = 1$) (closes stage basis: local frame at a normal #12)
Issue Camera, rays, image buffer, PNG output #19: Pinhole camera, ray generation, float HDR image buffer, and PNG export with gamma $2.2$ correction (closes Camera, rays, image buffer, PNG output #19)
Issue Sphere and plane intersection #21: Analytical ray-sphere and ray-plane intersections, hit records, and scene rendering (closes Sphere and plane intersection #21)
Review Refinements & SOTA Additions
Stage Basis Diffuse Integration: Lambertian::scatter samples cosine-weighted hemisphere directions in local coordinates and rotates them to world space using stage_basis_normal(rec.normal) ($Q \in \mathrm{SO}(3)$), establishing the linear algebra core of Monte Carlo bounce sampling.
Glass (Dielectric) Material: Snell's law refraction with stochastic Schlick Fresnel reflection probability via thread-local RNG.
Metal (Mirror) Material: Orthogonal reflection $v - 2(v \cdot n)n$ with roughness fuzz unit-sphere perturbation.
Procedural Floor: Dedicated CheckerMaterial class for spatial tile patterning.
Performance & Stability:
Converted HitRecord::material to const Material* to eliminate OpenMP atomic reference counter overhead during candidate hit copies.
Granularized OpenMP scheduling by scanline row schedule(dynamic, 1).
Added camera look/up singularity fallback in Camera.
Added zero-direction assert guard in Ray.
Conventions & Testing:
Added docs/CONVENTIONS.md documenting coordinate frames, double vs. float precision, scanline flip mapping ($v = (\text{height}-1-y)/(\text{height}-1)$), and gamma 2.2 pipeline.
Integrated CTest in CMakeLists.txt for automated test discovery.
Verification & Tests
Build: Single-command clean build: cmake -B build && cmake --build build
CTest Suite: 100% tests passed (test_basis - 1,009 test cases, test_intersections)
NumPy Reference: Passed pytest tests/test_basis.py verifying basis matrix invariants against NumPy
Image Artifacts:
gradient.png: 400x225 sky gradient (horizon white to zenith blue)
spheres_on_plane.png: 640x360 16 spp render featuring dielectric glass, red diffuse, chrome mirror, gold mirror, and checkerboard floor
Code Quality: All pre-commit hooks (clang-format, ruff, check-yaml, etc.) passing with 0 errors
