Part of #6869 (charter #6868). Second of three stacked PRs: pure LOD selection plus pacing. It is based on #6874 (the COPC reader); review only the top commit. PR 3 (viewer integration) closes the issue.
What
packages/pointcloud/src/lod/ is renderer-independent: no GPU, no I/O, no clock. It is a clean-room implementation from the technique description in #6869.
selectLod(root, camera, { pointBudget, pixelThreshold = 96, maxNodes = clamp(budget/128, 8, 1024) }) over a generic LodNode (id, bounds, pointCount, children | null where null means the hierarchy is not loaded yet):
Frustum-cull with Gribb/Hartmann planes for WebGPU clip space. Forward and reverse Z both work, and a degenerate (infinite-far) plane is dropped.
Refine priority-first: pop the selected node with the largest projected screen span (bounding-sphere diameter in px, perspective or orthographic) and add its visible children, while the span exceeds the threshold and the node cap allows. Refinement is all-children-or-none in strict priority order, so a smaller cap's selection is a prefix of a larger one's (monotone). Parents precede children (the octree is additive).
Water-fill the budget: one common level, small nodes filled completely, and the integer remainder handed out deterministically. Each node gets points (≤ its own count) and a stride hint with ceil(count / stride) ≤ points.
Nodes that should refine but whose children are not loaded are reported in needsChildren.
Ties break by id, so the result is independent of child order.
LodPacer: passBudgets(full) returns [first, full], where the first pass is sized to a time budget (200 ms) from a learned read rate. observe(points, ms) feeds an asymmetric EMA: it drops fast (α 0.5) and rises slowly (α 0.1). Each sample is clipped to [rate/4, rate·4] first, and uninformative samples are ignored.
shouldReplacePass(current, candidate): replace what is on screen only with more points for the same view, or a complete pass for a newer view. A stale view never wins.
createCopcLodTree(hierarchy, info, originOffset): presents a partially loaded COPC hierarchy as LodNodes.
Bounds come from the voxel key, in the decoded frame (native minus originOffset).
A node whose child is the root of a pending page reports children: null; pendingPagesUnder(node) names exactly those pages.
Hosts move the camera into this frame (view-projection × placement) instead of re-boxing the bounds. That also avoids a second copy of the renderer's internal transformAabb.
Evidence
Property tests run on seeded synthetic octrees: 120 (octree, camera, budget) cases, with perspective, reverse-Z and orthographic cameras.
Culling is checked by an independent oracle. It projects the 8 corners to clip space and requires that all of them fail one clip inequality. This is a different computation from the plane test the implementation uses.
The tests are not vacuous. More than 1/3 of cases refine past 3 nodes, more than 1/2 of cases have culled nodes, and there are more than 100 refinement checks in total.
