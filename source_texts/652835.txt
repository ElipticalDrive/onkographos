Description
Create a procedural terrain generator that produces natural-looking 2D landscapes using Perlin noise. The generator should support biome-specific parameters (such as mountain height, frequency, and variation) and be extendable for future features like temperature or humidity maps.
Goals
Generate a heightmap using Perlin noise.
Support configurable parameters:
BaseHeight
HeightVariation
MountainFrequency
MountainHeight
NoiseScale
Render the terrain using tiles or a mesh.
Provide a preview mode for debugging and tuning parameters.
Prepare the system for biome-based generation logic.
Tasks
Create NoiseSettings (struct or ScriptableObject) to store terrain parameters.
Implement PerlinNoiseGenerator with adjustable settings.
Create height generation logic based on X coordinate.
Support unique settings per biome (e.g., mountains in tundra vs. desert).
Add NoisePreview MonoBehaviour that renders terrain in editor via mesh.
Ensure editor-only preview doesn’t affect build runtime.
Acceptance Criteria
Heightmap generation is smooth and consistent using Perlin noise.
Terrain varies visibly when parameters change.
Different biomes generate distinct terrain features.
Code is modular, testable, and documented.
Editor preview works without entering Play mode.
