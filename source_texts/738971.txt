Adds a first-person 3D maze game to the minigames page. Player navigates a procedurally generated maze to reach the goal as fast as possible.
Implementation
Rendering: Wolfenstein-style raycasting using DDA algorithm on a Canvas element — efficient grid-stepping instead of fixed-step ray marching
Maze generation: Recursive backtracker on a 15×15 grid, guarantees solvable path from (1,1) to bottom-right
Scoring: max(100, 10000 - elapsed_seconds * 100) — rewards speed
Controls: WASD/arrows for keyboard, D-pad touch controls for mobile
Visual aids: Minimap overlay (top-right), green goal marker (🏁) visible in 3D view, distance-based wall shading with side differentiation
Integration
Follows existing minigame hook pattern (useMaze → MazeBoard). Wired into all the standard game lifecycle points: GAMES array, startGame, isGameOverNow, currentScore, isGameOver, play-again button state.
```
const GAMES: GameDef[] = [
  // ...existing games
  { id: "maze", name: "3D Maze", emoji: "🏁" },
];
```
