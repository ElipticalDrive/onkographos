We adopt a right-hand coordinate system with: +x points outwards, +y points to the right, and +z points upwards. c2w defines how a point in camera coordinate system can be transformed to the world coordinate system. It contains information about camera rotation and translation. Use c2w if you want to project 2D points to 3D space using predicted depth. mvp_mtx is the projection matrix which defines how a 3D point is projected to the screen. It contains both information about camera extrinsics and intrinsics.

I think the pts_2d on this line is homogenous:
```
pts_2d = pts_4d @ lidar2img_rt.T
```
and you should do a perspective division to get normalized device coordinates (NDC) where x, y, z are in [-1,1], after which you could shift and re-scale to get screen pixel coordinates:
```
# x, y, z in pts_ndc are in [-1, 1]
pts_ndc = pts_2d / pts_2d[...,3:4]
```
To get 3D coordinates from pixels, a easy way would be to use rays_o and rays_d (here I assume the depth is the distance from the 3D points to the camera center):
```
pts_3d = rays_o + rays_d * depth
```
