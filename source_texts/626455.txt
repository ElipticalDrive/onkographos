SDF builder (Lubx.Sdf) で使える形と演算を、Inigo Quilez の distance functions と Mercury の hg_sdf で定番のものまで広げる。
これまでは sphere / box / capsule / torus の 4 形と、move / rotate / scale / mirror_x / smin / ssub などの演算だけだった。
公開の Mesh.SdfOp / LUB_MESH_SDF_OP_* は 16〜54 を足しただけで、既存の値は変えていない。
足したもの
形 (16〜32)
RoundCone(a, b, ra, rb): 両端の半径が違うカプセル (2 つの球の凸包)。端の半径をそろえて折れ線に並べると、Smin なしで段差のない先細りの管になる。
RoundBox(hx, hy, hz, r): 辺と角を丸めた箱。
BoxFrame(hx, hy, hz, e): 辺だけの枠。
Ellipsoid(rx, ry, rz): 楕円体。
CappedCylinder(a, b, r): 任意の向きの、端が平らな円柱。
CappedCone(a, b, ra, rb): 任意の向きの、端が平らな円錐台。
RoundedCylinder(r, h, e): 縁を丸めた円柱。
CappedTorus(angle, rMajor, rMinor): 正面向きのトーラスの弧。
Link(le, rMajor, rMinor): 鎖の輪。
HexPrism(h, depth) / TriPrism(h, depth): 六角柱と三角柱。
Octahedron(s): 正八面体。
Pyramid(w, h): 四角錐。
CutSphere(r, h): 平面で切った球。
SolidAngle(angle, r): 球の扇形。
Rhombus(la, lb, h, r): 菱形の板。
Vesica(a, b, w): 両端が尖ったレンズ (葉・花びらの形)。
点や距離を変える演算 (33〜40, 43〜46)
MirrorY() / MirrorZ()
Elongate(hx, hy, hz): 原点で切り開いて引き伸ばす。
Twist(k) / Bend(k): ねじる・曲げる。
Repeat(sx, sy, sz, nx, ny, nz): 回数つきの繰り返し。
PolarRepeat(n): Y 軸回りの繰り返し (花びら、歯車の歯、光線)。
Revolve(o): 子の z = 0 の断面を Y 軸回りに回した回転体 (壺、カップ)。
Extrude(h): 子の z = 0 の断面を Z 方向に押し出す。
Displace(amp, freq, octaves, seed): value noise の fbm で面を凸凹にする (岩、雲、幹)。純粋な算術なので、どの環境でも同じ木は同じメッシュになる。
Round(r): 表面を太らせて丸める。
Onion(t): 殻にする。
2 つの子を結ぶ演算 (41, 42, 47〜54)
Smax(b, k): smooth intersection。
Xor(b)
hg_sdf の結合:
UnionChamfer / IntersectChamfer / SubtractChamfer(b, r): 面取りした和・共通部分・差。
UnionStairs(b, r, n): 継ぎ目を階段にした和。
Groove(b, ra, rb): 溝。
Tongue(b, ra, rb): 盛り上げた帯。
Pipe(b, r): 2 つの面の交線に沿った管。
Engrave(b, r): V 字の刻み。
距離は iq / hg_sdf の式どおりで、多くは厳密。
ellipsoid と tri_prism は近似の距離 (面の位置は正確)、twist / bend / displace は距離が厳密でなくなる。
どれも meshing (符号と面の近くの勾配) には十分。
実装
src/sdf.c
点の変換 (move〜revolve) を sdf_xform に、形の距離を sdf_prim に、hg_sdf の結合を hg_op にまとめた。sdf_eval / sdf_eval_mat / sdf_eval_part (bone の部位距離) は、それを共有する。
材質:
round / onion / extrude / displace は子の材質を保つ。
smax は smin と同じ重みで材質を混ぜる。
xor と hg_sdf の結合は、結果の面がどちらの子のものかで材質を選ぶ。
AABB は op ごとに保守的に出す。
twist / bend / polar_repeat は回転し得る範囲を取る。
revolve は断面の x の範囲を半径にする。
repeat は個数ぶん、displace は amp だけ、面取りと階段は r だけ広げる。
変換 (conv_node) で値を検査して拒む (楕円体の半径 0、軸の長さ 0、切る高さが半径の外、殻の厚さ 0、繰り返しの負の値、ノイズの周波数 0、面取りの幅 0 など)。sin/cos や軸の長さはここで前計算する。
src/sdf.h: 内部の op を「形、子 1 つ、子 2 つ」の順に並べ直した。
cs-lib/lub_stub.cs: Mesh.SdfOp に値を足し、SdfNodeDesc.Params の説明に全 op の並びを書いた。
cs-lib/lubx/Sdf.cs / SdfPanel.cs: builder、OpName、panel の値を足した。
生成物は scripts/gen-api.sh で再生成した。web/gen/lub-api-docs.json の差分の多くは、stub の行番号がずれたことによるもの。
テスト (tests/c/sdf_smoke.c)
各 op を meshing し、頂点が sdf.c とは独立に求めた面に乗るかを見る。
閉じた式で見るもの:
楕円体の式、八面体の L1 ノルム。
角丸の箱、縁を丸めた円柱は、内側の形から一定の距離にある。
弧のトーラスは、弧までの距離で見る。
切った球、扇形、四角錐の面。
回転体はトーラスに、押し出しは両端の閉じた円柱になる。
外形の寸法で見るもの:
枠、円柱・円錐台、鎖の輪、六角柱・三角柱、菱形、レンズ。
演算が置くべき位置で見るもの:
繰り返しが指定の個数で止まる (遠くの目印の球で格子を広げて確かめる)。
極座標の繰り返しが +X から始まる n 個の位置に並ぶ。
ねじった箱を戻すと箱に乗り、曲げは +Y へ曲がる。
殻に内側の面があり、smax の面は両方の球の中にあり、xor は重なりをくり抜く。
面取りの頂点が箱の面か 45 度の面に乗り、面取りの面が実際にある。階段は和から r の範囲に収まる。
溝・帯・刻み・管の頂点がそれぞれの面に乗り、帯の高さが ra になる。
displace は amp の範囲内で実際に面を動かし、同じ値なら同じメッシュになる。
ほかに、round が子の色を保つこと、新しい変換の下で bone が結べること、不正な値を拒むことも見る。
確認
tests/c/sdf_smoke.c を src/sdf.c / src/surfacenets.c と一緒に gcc で直接ビルドして実行し、sdf smoke OK。
ASan / UBSan 付きでも通る。
式を 1 か所ずつわざと壊して (約 35 通り) 落ちることを確かめた。落ちないのは八面体の距離の倍率だけで、面の位置が変わらないので正しい。
全 op を sdf_mesh_build で meshing し、ラスタライズした一覧画像で形を目で確かめた。
scripts/gen-api.sh --check: 0 problems。scripts/format.sh --changed を通した。
cs-lib を参照する csproj を dotnet build し、TinyC# の analyzer を含めてエラーと警告は無し。
native の full build、golden、web は、この環境 (Vulkan 無し) では回していないので CI に任せる。
