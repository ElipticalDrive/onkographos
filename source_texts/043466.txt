# Remote Rendering

A high-performance **remote 3D DICOM Volume Renderer** that allows real-time interactive visualization of medical CT/MR scans directly in the browser.

## Key Features
- GPU-powered 3D volume ray casting using VTK
- Real-time interaction via WebSocket (rotate, zoom, pan)
- Multiple clinical presets (Bone, Lung, Soft Tissue, Vascular, Tumor, etc.)
- DICOM file upload support
- Low-latency remote rendering architecture

## Use Cases
- Remote medical image viewing
- Teleradiology applications
- Educational medical imaging tools
- Research & prototyping for 3D medical visualization
