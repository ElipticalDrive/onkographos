This PR adds comprehensive documentation explaining the Level of Detail (LOD) algorithm principle behind the command:
```
splat-transform lod0.ply --lod 0 lod1.ply --lod 1 lod2.ply --lod 2 scenes/lod-meta.json
```
What's Added
Documentation Files
docs/LOD_ALGORITHM.md: Complete technical explanation of the LOD algorithm, covering:
Multi-level input processing and LOD tagging
K-d tree spatial data structure construction
Hierarchical spatial partitioning using count and size thresholds
LOD-based file organization with binning strategy
Bounding box calculation for 3D Gaussian ellipsoids
Morton ordering for spatial locality optimization
Output metadata structure and file organization
docs/LOD_ALGORITHM_CN.md: Chinese translation of the algorithm documentation with culturally appropriate explanations
docs/ALGORITHM_SUMMARY.md: Concise overview tying together the algorithm flow and practical benefits
README Updates
Added --lod action to the Actions section (was missing from documentation)
Added lod-meta.json to supported output formats table
Created new "Level of Detail (LOD)" examples section with practical usage patterns
Added reference links to detailed algorithm documentation
Algorithm Overview
The LOD system creates hierarchical structures for efficient 3D Gaussian splat rendering by:
Processing multiple input files, each tagged with a specific LOD level
Building a K-d tree from 3D centroids for spatial organization
Recursively partitioning space based on splat count (512K threshold) and spatial size (16 units)
Organizing splats by LOD level within each spatial region
Generating compressed SOG files with Morton ordering for cache efficiency
Creating a hierarchical metadata structure for spatial queries
Benefits
Adaptive Rendering: Applications can load appropriate detail levels based on viewing distance
Spatial Efficiency: K-d tree structure enables efficient frustum culling
Streaming Support: Hierarchical file organization supports progressive loading
Memory Optimization: Selective loading of detail levels reduces memory usage
This documentation addresses the need for understanding the sophisticated spatial indexing and compression algorithms that enable efficient rendering of large-scale 3D Gaussian splatting scenes.
