💡 What:
Batched the path drawing operations for volumetric god-rays in public/js/visuals/Parallax.js. Hoisted ctx.beginPath() before the loop and ctx.fill() after it.
🎯 Why:
Calling beginPath() and fill() inside a hot rendering loop causes redundant, expensive interactions with the HTML5 Canvas 2D API context per-frame, contributing to frame budget saturation.
📊 Impact:
Eliminates 5 unnecessary pairs of ctx.beginPath() and ctx.fill() calls per frame when rendering the daylight sun in the parallax background.
🔬 Measurement:
Visuals test suite (npm run test:visuals) confirmed parity, rendering performance can be tracked by a reduction in time spent in rendering scripts via Chrome DevTools Performance profile during the daytime weather phase.
