Issue body actions
We want to add a Path Tracing Renderer to FunGT as an alternative rendering backend alongside OpenGL.
This will allow physically based rendering (PBR) of our scenes (e.g., Pixar ball) with global illumination, soft shadows, and realistic lighting.
Goals
Implement a CPU-based path tracer first (for simplicity & reference).
Later, explore GPU acceleration with SYCL/CUDA/Metal/Vulkan.
Integrate with FunGT’s existing model loading system.
Sub-tasks / Milestones
Core Path Tracer
Implement ray representation (origin, direction).
Add ray–triangle intersection function.
Add ray–sphere and ray–plane intersections (for test scenes).
Add simple camera model (pinhole camera).
Implement basic path tracing loop (bounce rays, accumulate light).
Scene Representation
Extract triangles from loaded meshes.
Store geometry in a BVH (bounding volume hierarchy) for acceleration.
Add support for Pixar ball model.
Materials & Shading
Implement Lambertian diffuse shading.
Add reflective and refractive materials.
Add texture sampling for materials.
Integration with FunGT
Render to an offscreen buffer (path tracer output).
Display path traced image in ImGui viewport.
Toggle between OpenGL rasterization and Path Tracing.
Optimization / Extensions (Future)
GPU acceleration with CUDA.
GPU acceleration with SYCL.
Denoising filter for noisy renders.
Importance sampling and next-event estimation.
CPU acceleration with multithreading.
