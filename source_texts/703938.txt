Pull Request Overview
This pull request adds sparse rendering functionality for Gaussian Splatting, allowing rendering at specific pixel locations rather than full images. The PR plumbs sparse rendering functions from C++ to Python and adds comprehensive unit tests for both forward and backward passes.
Adds three new sparse rendering methods: render_depths_sparse, render_features_sparse, and render_images_and_depths_sparse
Implements autograd support for sparse rasterization through new RasterizeGaussiansToPixelsSparse class
Adds unit tests validating sparse rendering matches dense rendering at specified pixels for both forward and backward passes
