Abstract
We present algorithms that compress two- and three-dimensional seismic data arrays. These arrays are piecewise smooth in the horizontal directions and have oscillating events in the vertical direction. The transform part of the compression process is an algorithm that combines wavelet and the local cosine transform (LCT). The quantization and the entropy coding parts of the compression were taken from wavelet-based coding such as set partitioning in hierarchical trees (SPIHT) and embedded zerotree wavelet (EZW) encoding/decoding schemes that efficiently use the multiscale (multiresolution) structure of the wavelet coefficients. To efficiently apply these codecs (SPIHT or EZW) to a mixed coefficient array, reordering of the LCT coefficients takes place. This algorithm outperforms other algorithms that are based only on the 2D wavelet transforms such as JPEG 2000 standard. The algorithms retain fine oscillatory events including texture even at low bit rate. The wavelet part in the mixed transform of the hybrid algorithm utilizes the library of Butterworth wavelet transforms that outperforms the commonly used 9/7 biorthogonal wavelets. In the 3D case, the 2D wavelet transform is applied to horizontal planes while the LCT is applied to its vertical direction. After reordering the LCT coefficients, the 3D coding (SPIHT or EZW) is applied. In addition, a 3D compression method for visualization is described. For this, the data cube is decomposed into relatively small cubes, which are processed separately.

Appendix: LCT internals
Let f be a function defined on R and assume that we have a partition of the line into a set of disjoint adjacent intervals. If for each interval we have an expansion of f in terms of an orthonormal base of this interval, then we say that this is a “windowed base” expansion of f on R (Averbuch et al. 1993). There exists a smooth orthogonal basis with an arbitrary partition of the line. The bases consist of cosine (or sine) multiplied by a smooth cutoff function (bell function) that overlaps adjacent intervals. The cosine functions used in the expansion are similar to the basis functions of DCT-IV and DCT-II, and thus, these local trigonometric bases are called the Local Cosine Transform (LCT)
. Using DCT-IV or DCT-II with the appropriate LCT will be called LCT-IV or LCT-II, respectively. Multiplication by the bell function can be implemented by folding
the overlapping parts of the bell into the original intervals. In the discrete case, this fact allows us to perform the LCT in two successive steps: (1) Application of the folding operation on the original audio frame (preprocessing). (2) Application of the DCT-IV on the folded segment. The inverse LCT (ILCT) can be performed in a similar way using an unfolding operation in which the signal samples are unfolded back to the overlapped bells and then multiplied by the bell functions. In Averbuch et al. (2000, 2001c) it was proved that the LCT can effectively detect oscillatory phenomena. After its application, the data is smoother. The multiscale LCT was shown to fit seismic compression (Averbuch et al. 2001a).
Suppose we have an arbitrary function f defined on the interval I = [0, 1]. We extend the function to \([-\varepsilon,1+\varepsilon ]\) such that it is even with respect to 0 and odd with respect to 1. Clearly, it means that f can be expanded into a Fourier series by means of the orthonormal base \(\sqrt{ 2}\cos \left [(k + \frac{1} {2})\pi x\right ]\). If we extend f to be even with respect to 0 and even with respect to 1 then f can be expanded in terms of the orthonormal base \(\sqrt{ 2}\cos (k\pi x)\). Switching between even and odd will result in replacing cosine by sine. 1.1 LCT-IV: Local Cosine Transform Type IV
Theorem 1 shows us how to construct an orthonormal base for L

$$\displaystyle{ 1.\ \ \beta (x) = 0\quad x \leq -1.\quad 2.\ \ \beta (x) = 1\quad x \geq 1.\quad 3.\ \ \beta (x)^{2} +\beta (-x)^{2} = 1\mbox{ for all }x. }$$
(11)
Let \(\{\varepsilon _{j}\}\) be a sequence such that \(a_{j} +\varepsilon _{j} = a_{j+1} -\varepsilon _{j+1}\). We can now define a bell function b
j

$$\displaystyle{ b_{j}(x) = \left \{\begin{array}{l} \beta \left (\frac{x-a_{j}} {\varepsilon _{j}} \right )\begin{array}{*{20}c} &&\\ \end{array} x \in \left [a_{j} -\varepsilon _{j},a_{j} +\varepsilon _{j}\right ] \\ \beta \left (\frac{a_{j+1}-x} {\varepsilon _{j+1}} \right )\begin{array}{*{20}c} &\\ \end{array} x \in [a_{j+1} -\varepsilon _{j+1},a_{j+1} +\varepsilon _{j+1}]. \end{array}\right. }$$
(12)
In this definition, the bell
has two parts. The left part is an increasing function from 0 to 1 and the right part is a decreasing function from 1 to 0. At the intersection point between these parts the bell has the value \(\sqrt{ 2}/2\). In addition, b

$$\displaystyle{ u_{j,k}(x) = \sqrt{ \frac{2} {l_{j}}}b_{j}(x)\cos \left [\left (k + \frac{1} {2}\right )\pi \frac{x - a_{j}} {l_{j}} \right ] }$$

1.2 Discretization of LCT-IV
The LCT basis functions u

For each i ∈ Z, we define a discrete bell function \(\hat{b}_{j}(i)\) as \(\hat{b}_{j}(i) = b_{j}\left (i + \frac{1} {2}\right ),\quad i \in Z.\) We also define a discrete version of the cosine set as \(\hat{f}_{j,k}(i) = \sqrt{ \frac{2} {l_{j}}}\cos \left [\left (k + \frac{1} {2}\right )\pi \frac{i+\frac{1} {2} -a_{j}} {l_{j}} \right ]\). Finally, we define the discrete sequences:
$$\displaystyle{ \hat{u}_{j,k}(x) =\hat{ b}_{j}(i)\hat{f}_{j,k}(i) = \sqrt{ \frac{2} {l_{j}}}b_{j}\left (i + \frac{1} {2}\right )\cos \left [\left (k + \frac{1} {2}\right )\pi \frac{i + \frac{1} {2} - a_{j}} {l_{j}} \right ], }$$
(14)
where \(a_{j} -\varepsilon _{j} \leq a_{j+1} +\varepsilon _{j+1}\) and \(0 \leq k \leq \frac{1} {2}\left (a_{j+1} +\varepsilon _{j+1} -\left (a_{j} -\varepsilon _{j}\right )\right )\); \(\hat{u}_{j,k}(i)\) is the discrete LCT basis function. For each j, the functions \(\hat{f}_{j,k}(i)\) are evidently the basis functions for the DCT-IV transform over the interval [a
j
, a

1.3 Implementation of LCT-IV by Folding
From the proof of Theorem 1 we know that:
$$\displaystyle\begin{array}{rcl} & & \int \limits _{a_{j}-\varepsilon _{j}}^{a_{j+1}+\varepsilon _{j+1} }b_{j}(x)f(x)\sqrt{ \frac{2} {l_{j}}}\cos \left [\left (k + \frac{1} {2}\right )\pi \frac{x - a_{j}} {l_{j}} \right ]dx \\ & & \qquad = \int \limits _{a_{j}}^{a_{j+1} }\tilde{F}_{j}(x)\sqrt{ \frac{2} {l_{j}}}\cos \left [\left (k + \frac{1} {2}\right )\pi \frac{x - a_{j}} {l_{j}} \right ]dx, {}\end{array}$$
(15)
where \(\tilde{F}_{j}(x)\) is defined as
$$\displaystyle{ \tilde{F}_{j}(x) = b_{j}(x)f(x) + b_{j}\left (2a_{j} - x\right )f\left (2a_{j} - x\right ) - b_{j}\left (2a_{j+1} - x\right )f\left (2a_{j+1} - x\right ). }$$
(16)
The discrete analogues of Eq. (15) are
$$\displaystyle{ \begin{array}{l} \sum \limits _{i=a_{j}-\varepsilon _{j}}^{a_{j+1}+\varepsilon _{j+1}}b_{j}\left (i + \frac{1} {2}\right )f\left (i + \frac{1} {2}\right )\sqrt{ \frac{2} {l_{j}}}\cos \left [\left (k + \frac{1} {2}\right )\pi \frac{i+\frac{1} {2} -a_{j}} {l_{j}} \right ] \\ = \sum \limits _{i=a_{j}}^{a_{j+1}}\hat{F}_{j}\left (i + \frac{1} {2}\right )\sqrt{ \frac{2} {l_{j}}}\cos \left [\left (k + \frac{1} {2}\right )\pi \frac{i+\frac{1} {2} -a_{j}} {l_{j}} \right ],\end{array} }$$
(17)
where \(\hat{F}_{j}(i) =\tilde{ F}_{j}\left (i + \frac{1} {2}\right )\). Equation (17) tells us that in the discrete case rather than calculating the inner products with the sequence \(\hat{u}_{j,k}(i)\), we can preprocess the data so that the standard DCT-IV algorithm can be used. This may be visualized as folding
the overlapping parts of the bells back into the interval. The folding can be transposed onto the data, and the result is disjoint intervals of samples. Since the folding operation is completely reversible, these samples can be later unfolded to reproduce the smooth overlapping segments. Therefore, the discrete LCT-IV will be implemented in two steps. First, we perform the folding operation on the source data and then apply the DCT-IV on the folded data.
Assume that we wish to fold the function f(x) across the points a
j
and a
j+1 using the bell b(x) = b
j
(x). In other words, we want to fold the overlapping parts \(\left [a_{j} -\varepsilon _{j},a_{j}\right ]\) and \(\left [a_{j+1},a_{j+1} +\varepsilon _{j+1}\right ]\) back into the interval [a
j
, a
j+1]. By the translation operator we can see this as having to fold the function f(x) across 0, onto the intervals \(\left [-\varepsilon _{j},0\right ]\) and \((0,\varepsilon _{j}]\), using the bell b(x). Then, folding replaces the function f(x) with the left and right parts f
−(x) and f
+(x) as follows:
$$\displaystyle{ \begin{array}{lll} f_{-}(x)& =&b(-x)f(x) - b(x)f(-x)\quad x \in [-\varepsilon _{j},0], \\ f_{+}(x)& =&b(x)f(x) + b(-x)f(-x)\quad x \in [0,\varepsilon _{j}].\\ \end{array} }$$
(18)
The symmetry of the bell allows us to use b(−x) instead of using the bell attached to the left interval. The folding function has the same polarity as the basis functions of DCT-IV, e.g., positive (even) on the left side and negative (odd) on the right side:
$$\displaystyle{ \begin{array}{lll} f_{-}(-x)& =& - f_{-}(x)\quad x \in [-\varepsilon _{j},0] \\ f^{+}(-x)& =&f^{+}(x)\quad x \in (0,\varepsilon _{j}].\\ \end{array} }$$
(19)
The formulas for the unfolding can be reached by solving two sets of two equations. For example, consider the next set of equations:
$$\displaystyle{ \begin{array}{lll} f_{-}(-x)& =& - b(-x)f(x) + b(x)f(-x)\quad x \in (0,\varepsilon _{j}] \\ f^{+}(x) & =&b(x)f(x) + b(-x)f(-x)\quad x \in (0,\varepsilon _{j}].\\ \end{array} }$$
(20)
By multiplying the upper equation by b(x) and the lower by \(-b(-x)\) and then summing the resulting equations, we have
$$\displaystyle{ b(x)f^{+}(x) - b(-x)f_{ -}(-x) = (b(x)^{2} + b(-x)^{2})f(x). }$$
(21)
The fact that the bell b(x) function satisfies the orthogonality property \(b^{2}(x) + b^{2}(-x) = 1\) implies
$$\displaystyle{ f(x) = b(x)f^{+}(x) - b(-x)f_{ -}(-x)\quad x \in [0,\varepsilon _{j}]. }$$
(22)
A similar set of equations and a similar argument will give us the formula for the case \(x \in [-\varepsilon _{j},0]\). Thus, we found that the unfolding
operation reconstructs f(x) from f
− and f
+ with the following formulas:
$$\displaystyle{ f(x) = \left \{\begin{array}{c} b(x)f^{+}(-x) + b(-x)f_{-}(x)\begin{array}{*{20}c} &\\ \end{array} x \in [-\varepsilon _{j},0] \\ b(x)f^{+}(x) - b(-x)f_{-}(-x)\begin{array}{*{20}c} &\\ \end{array} x \in (0,\varepsilon _{j}]\\ \end{array} \right.. }$$
(23)
Therefore, the unfolding operation
will be used to implement the Inverse LCT (ILCT).
