Parent
#16 — Controlled 3D scientific figures.
What to build
Evaluate one local mesh inset from the measured reconstruction-transition figure using Maquette through Studio display controls. Preserve the original metric mesh, point populations and numeric results, and compare against the accepted raster/hybrid baseline before any adoption.
Acceptance criteria
Inspect the exact candidate Maquette release, dependency/license terms and compiler compatibility; distinguish new results from ARIA's historical 0.1.1 smoke fixture.
Freeze input mesh/data hashes, units, basis/up axis, camera/projection, viewport, fit/crop, colour scale and relevant display-decimation settings. Any simplified display mesh remains separate from metric geometry.
Test a small representative fixture and one bounded actual inset, choosing SVG or PNG based on demonstrated depth-order/visibility behavior and cost, not a blanket vector-only requirement.
Preserve before/after camera registration and distance scales. Verify vector-overlay alignment through projected landmarks or another explicit geometric check; matching azimuth alone is insufficient.
Exercise parameter edit/preview/undo/save/reopen where supported and record exact outcomes. Known occlusion, transparency, clipping, normalization or asset failures are visible, not polished away.
Compare native baseline/candidate at destination size, record latency/output size and publish an explicit adopt/retain-baseline/reject decision with source/render identities and limitations.
If adopted, add the optional recipe/fixture and exact capability level to the existing renderer reference. If rejected after an executed bounded test, retain the baseline and record why; do not advertise integration success.
Blocked by
Demonstrate human–agent camera refinement on ARIA's existing Scenery figure #27 — the accepted first live Scenery pilot precedes optional renderer expansion.
Source anchors and exclusions
Measured transition owner
Historical Maquette fixture guidance
Primary package documentation
Observed 2026-09-20. Access to actual assets and authorization for any ARIA candidate changes are prerequisites at execution. Missing evidence is not a negative experimental result. No recomputation/change of metric definitions, automatic thesis inclusion, global package upgrade or full dense-scene migration. This evaluation does not block core collaboration delivery.
