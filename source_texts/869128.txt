Purpose
Implement only the shared shot controls approved at SH-R1: aspect-ratio crop and coherent yaw/pitch/roll/FOV or equivalent eye/sheet adapter. Keep inspection orbit and drawing navigation separate.
This is a planned, optional extension of the existing perspective/Halasz tool. Keep one shared world/projection, preserve the default workflow and legacy lessons, and keep shadows off until explicitly enabled. Reference guidance is adapted by the user's integration request.
Dependencies
SH-R3 / #11
Follow the dependencies and the milestone review gates in the roadmap. Use a focused pull request and retain the current regression checks.
Acceptance criteria
Crop changes leave world geometry fixed. Camera editing leaves proxy and light fixed in world space; all five views and VPs agree.
Horizon dragging changes exactly the documented camera/framing parameter and cannot store an independent horizon value.
Roll rotates the horizon and picture coherently; FOV uses defined angular semantics rather than relabeling arbitrary display zoom.
Preserve original presets and explicit physical picture-plane lessons, legacy saved views, and camera-projection parity tests.
Provide shot lock, reset/undo, numeric/readout precision, and approved rolled/pitched reference scenes.
Reference and evidence
Reference coverage: FR-100–106; FR-109.
Roadmap: SHADOW-ROADMAP.md. Requirement coverage: SHADOW-REQUIREMENTS.md.
Record implementation PRs, tests, reviewed commits, findings/resolutions, and applicable numeric/browser/device/user/export evidence here. Status is planned; no code review, external-app test, device test, or user test has passed by creation of this issue. Do not close this task merely because CI passes.
