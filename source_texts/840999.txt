# 3d_gs_nbv

**Active 3D Gaussian Splatting with D-Optimal Next-Best-View Planning**
*(IEEE CASE 2026)*

A pipeline that reconstructs a rock using 3D Gaussian Splatting (3DGS), selecting each new camera view greedily via D-optimal Fisher information maximisation. Gaussians are initialised from a prior Poisson mesh (frozen XYZ positions) and trained online as views are added.

---

## Overview

```
dataset/
│  rock_points/rock_mesh_init.ply   ← Poisson mesh prior (XYZ frozen)
│  Images/kf_XXXX_rgb.png           ─┐
│  Depth/kf_XXXX_depth.png           ├─ candidate view pool
│  Masks/kf_XXXX_mask.png           ─┘
│  kf_poses.txt                     ← camera poses for every candidate
        │
        ▼
 Step 0 — mask_generator.py (preprocessing, run once)
        │  Projects rock PLY → convex hull → binary rock masks
        │  Saves Masks/kf_XXXX_mask.png
        ▼
 main.py
        │
        ├─ Seed selection (4 views, azimuth-spaced at 0°/90°/180°/270°)
        │       + seed training (3 000 iters)
        │
        ├─ Greedy NBV loop (up to N_SELECT total views)
        │       For each candidate: render → compute Fisher hessian
        │       Pick view with highest D-optimal score → train 1 000 iters
        │
        └─ Final render pass + model save
                ▼
        test_runs/<run_id>/
```

## Repository Structure

```
3d_gs_nbv/
├── src/
│   ├── config.py           # ★ All paths, camera params, tunable constants
│   ├── main.py             # ★ Entry point — seed → NBV loop → save
│   ├── data.py             # Frame dataclass + dataset loader
│   ├── gaussian_model.py   # 3DGS model (frozen XYZ, learnable appearance)
│   ├── trainer.py          # Training loop (L1 + SSIM loss)
│   ├── fisher.py           # D-optimal Fisher information score
│   ├── nbv.py              # Greedy NBV selector
│   ├── visualizer.py       # Live Viser viewer (localhost:8080)
│   ├── renderer.py         # Offline PNG renderer (no display needed)
│   ├── mask_generator.py   # Preprocessing — generates rock masks from depth
│   ├── report.py           # CSV + JSON run summary
│   └── verify_alignment.py # Debug: overlays PLY projections on images
├── dataset/
│   ├── Images/             # kf_XXXX_rgb.png   (uint8 BGR, 1280×720)
│   ├── Depth/              # kf_XXXX_depth.png (uint16, millimetres)
│   ├── Masks/              # kf_XXXX_mask.png  (binary, generated by mask_generator.py)
│   ├── rock_points/
│   │   └── rock_mesh_init.ply  # Poisson mesh used to initialise Gaussians
│   └── kf_poses.txt        # Camera poses (see format below)
├── test_runs/              # Output directory (gitignored)
├── render_video.py         # Renders a video from a completed run
└── Active_3DGS_NBV_Colab.ipynb  # Colab-compatible notebook
```
