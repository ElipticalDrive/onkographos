# Wolfenstein-style software raycasting in C and SDL2, with the 2D rays and the 3D projection side by side.

Software raycasting engine inspired by Wolfenstein 3D. Casts 120 rays through an 8×8 grid and renders the 3D view with distance shading, fisheye correction, a ceiling, and a floor, while the 2D map shows the rays as they are cast.

## Controls

Arrow Left/Right rotate; Arrow Up/Down move. Close the window to quit.

## Build

```
make
```

Remove the binary with `make clean`.

## Usage

```
./raycaster
```
