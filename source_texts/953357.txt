Overview
Implement the Jump Flood Algorithm (JFA) based SDF generation pipeline — the foundation that all lighting subsystems (shadows, culling, GI) depend on.
Requirements
Input: Binary occlusion render target (shadow casters rendered as white silhouettes)
Output: SDF texture with R = distance to nearest occluder, GB = vector to nearest occluder
Algorithm: JFA in O(log2(N)) fullscreen fragment shader passes (no compute needed — WebGL compatible)
Render targets: Ping-pong pair for JFA flood (RG = nearest seed UV), final SDF RT (RGB: dist + vector)
Materials: Seed material, JFA materials A/B (ping-pong), distance materials A/B
Implementation Details
SDFGenerator.ts — JFA converts binary occlusion → SDF
Seed pass: occlusion RT → pingRT
For step = maxDim/2 down to 1: JFA pass alternating ping↔pong
Distance pass: final JFA RT → sdfRT
Two JFA materials required because TSL texture() captures the Texture object reference at node creation
Fragment-shader only path works on both WebGPU and WebGL
Current State
Initial implementation exists in packages/core/src/lights/SDFGenerator.ts but needs validation and optimization.
