Facilitating the remote visualization of volume data, where data generated is generated at one source and visualized from any source has been the dream of researchers. This paper describes the development of a volume rendering kernel that has been developed using Java. This kernel generates volume rendered images from 3D voxel volumes. The kernel is small so it can be easily implemented, it uses Java and hence can run on any machine on the network. We describe the implementation and give examples that demonstrate the feasibility of our system for remote visualization that can be efficiently used for a wide range of applications.
