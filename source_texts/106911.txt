Owner
Summary
THREEFOLD's runtime now uses cute, Minecraft-style voxel art with big visual effects, and plays entirely in the browser. The owner asked for this on 13 October: "Turn this into a browser based game — more cute cartoony, like Minecraft. Add amazing visual effects." The direction is recorded in docs/voxel-art-direction.md.
Nothing changes in the simulation, game rules, quest, collision, twelve-guild scope or open-PvP rules. The previous concept art, Meshy/Blender sources and their evidence stay in the repository; the client no longer loads the GLBs. No paid generation or provider job was used.
What's in it
Voxel world (apps/client/src/voxel/):
Highcross and the Briar March are generated from 0.5 m blocks, with a painted 64-tile atlas and face-culled meshing with baked AO.
The world has water, waterfall and foliage sway, a night glow, and trees and houses that fade when they hide the player.
Seed 1847 produces 65 structures, 35 lights and 48 ambient emitters. Building footprints stay inside the server's collision boxes, which a test checks.
Characters: chibi voxel Knight, Cyborg, Briar Hound, Mara, Nemi and Concord Watch. Their springy procedural animation follows the server's windup, impact and recovery timings.
Effects (apps/client/src/vfx/):
Combat VFX are driven by confirmed server events: windup rings, the Pulse Lance beam, voxel debris, stars, trails, shake and hit-stop.
Ambient VFX: fireflies, petals, butterflies, smoke, river sparkles, waterfall mist and the astrolabe.
Lighting and post-processing:
day/night sky;
shadows and a six-light budget;
bloom and ACES tone mapping;
tilt-shift, vignette, and selection and ink outlines;
low/medium/high quality presets.
HUD and audio: pixel-art icons and portraits, a voxel minimap, bundled Fredoka and Pixelify Sans fonts, and music-box synthesized audio.
Solo mode:
LocalConnection runs the authoritative World in the page at the server's 20 Hz / 10 Hz cadence and command limits, and saves to localStorage.
A Web Locks single-writer guard stops a stale tab from overwriting newer progress.
Multiplayer via Colyseus is unchanged (?server).
Tools:
tools/capture-voxel.mjs captures labelled headless frames with JSON sidecars.
npm run build:artifact -- [outDir] [--standalone] writes a static solo build.
Docs:
README, concept, plan, asset bible and checkpoint status record the direction change.
Journal entry 009 has eight labelled in-engine captures from commit b7e4018.
Review
An adversarial code review of the client diff found:
High: a solo tab left on the entrance screen could write an older world over newer progress. Fixed with a lock plus reload-on-join; unit tests and a real Chromium two-tab check confirm it.
Medium: build-artifact could delete any folder it was given. It now refuses folders that hold other work.
Lows: silent save failures, a lost selection outline after a guild change, and black cloud material. All fixed.
Two items were deferred deliberately:
First-use shader compiles: the owner reports good performance, and the fix touches lighting.
A few bugs that already exist on main: suggested as a separate task.
Test plan
npm run typecheck, npm test (58 pass), npm run build, npm run format:check
npm run validate:assets, npm run validate:plan
New tests: voxel world layout vs. server collision; in-browser world connection, including two-tab save safety
Headless Chromium captures of the production build at b7e4018:
23 frames: town, gate, combat effects, river, memorial, refuge, inventory, codex, night;
zero console messages;
131–230 draws per frame.
Real Chromium two-tab check of the lock on the rebuilt bundle
Real-hardware frame and memory trace for the voxel build. Not yet measured; the owner's report of good performance is informal.
