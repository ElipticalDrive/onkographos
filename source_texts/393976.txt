# 🌌 Ray Marching and Procedural Modeling in GLSL

This repository contains the complete implementation and report for the **Image Synthesis (Computer Graphics)** course project developed at **Université Claude Bernard Lyon 1**.  
The project explores **ray marching**, **lighting models**, **signed distance functions (SDF)**, and **procedural texturing** entirely in **GLSL**, inspired by modern ShaderToy techniques.

---

## 🧠 Overview

The goal of this project was to design a mini real-time renderer capable of simulating light interaction with geometric primitives using **ray marching**.  
All shaders were implemented in **GLSL**, compiled instantly (0.0s), and achieved maximum FPS performance on the test machine.

---

## 🧩 Project Structure

| File | Description |
|------|--------------|
| `primitives.glsl` | Basic geometric primitives (sphere, box, torus, cylinder, ellipsoid) using signed distance functions (SDF). |
| `primitives_extra.glsl` | Boolean operations (union, intersection, difference) combining primitives into complex objects. |
| `light.glsl` | Implementation of lighting components (ambient, diffuse, specular). |
| `phong.glsl` | Full **Phong illumination model** combining all light contributions. |
| `advanced_modelisation.glsl` | Procedural surface deformation (sinusoidal waves, bumps, noise). |
| `advanced_modelisation_with_texture.glsl` | Procedural wood texture with turbulence and noise-based pattern generation. |
| `BVH.glsl`, `BVH_2.glsl` | Implementation of **Bounding Volume Hierarchies** (spherical bounds) for performance optimization. |
| `compared.glsl` | Benchmark comparing ray marching with and without BVH optimization. |
| `UE-INF1207M_TP_Synthese_Rapport_Image.pdf` | Final project report with visuals, analysis, and ShaderToy links. |
