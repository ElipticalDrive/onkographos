Parallel algorithm is an important approach to accelerate volume rendering techniques,but the most existing parallel volume rendering algorithms are designed for regular grids. This pa-per presents a parallel algorithm for rendering irregular volumes in distributed computing environ-ment. By using a static data partition and distribution scheme, the algorithm avoids data redistribu-tion and data communication between computing nodes during rendering process. In order to makethe volume rendering and image compositing to be performed in parallel, the algorithm uses a delib-erately optimized image composition method. This method not only improves the parallelism of thealgorithm, but also avoids the network communication jams. The paper also gives a new load bal-ancing strategy which combines the static and dynamic load balancing schemes. This new load bal-ancing strategy further improves the efficiency of the algorithm. At last, the implementation andexperiments demonstrate good speedup and scalability of the algorithm.
