Summary
Adds toupy/tomo/cone_phase.py, which connects the non-linear iterative phase retrieval to the existing FDK cone-beam reconstruction through the Fresnel scaling theorem.
effective_fresnel_distance(geometry) computes z_eff = R1·R2/(R1+R2) for a ConeBeamGeometry.
cone_phase_retrieval_fdk(...) works in two stages. First it runs iterative_phase_retrieval on each projection in the effective parallel-beam frame. Then it applies fdk_reconstruct to the retrieved phase stack.
It supports optional TV regularisation.
It warns when the effective Fresnel number is outside the usable phase-contrast range.
It forwards cuda=.
This is the cone-beam equivalent of Paganin + FDK, using the non-linear solver.
Example: tutorial/example_cone_phase_fdk.py simulates a micro-CT geometry, retrieves the phase and reconstructs with FDK. With 300 angles and a Hann filter, the volume RMSE is 0.068 for the iterative retrieval, against 0.060 for the clean-phase reference and 0.118 for TIE-Hom.
Test: test/cone_phase_test.py is a self-checking round-trip test.
Notes
This work dates from June 2026. dev is merged in, and the conflicts were in .gitignore, CHANGELOG.md and toupy/tomo/__init__.py. All were resolved by keeping both sides. toupy/tomo/__init__.py now imports cone_phase alongside the two-pass and FBaP modules.
The full suite (pytest test, 48 tests) passes locally.
This is merged ahead of the planned single-commit Black reformat.

```
Add toupy.tomo.cone_phase coupling the non-linear iterative phase retrieval to
the existing FDK cone-beam reconstruction via the Fresnel scaling theorem.

- effective_fresnel_distance(geometry): z_eff = R1*R2/(R1+R2) for a
  ConeBeamGeometry (R1=SOD, R2=SDD-SOD).
- cone_phase_retrieval_fdk(intensity, geometry, wavelength, delta_beta, ...):
  per-projection iterative_phase_retrieval in the effective parallel-beam frame
  (z_eff, geometry.effective_pixel_size), then fdk_reconstruct on the retrieved
  projected-phase stack. Optional TV regularisation; warns if the effective
  Fresnel number is outside the usable phase-contrast range. cuda= forwarded.

Decoupled pipeline (wave optics per projection, ray geometry in FDK) — the
cone-beam analogue of Paganin+FDK, with the non-linear solver instead.

tutorial/example_cone_phase_fdk.py: simulation -> retrieval -> FDK demo on a
homogeneous 3-D phantom (micro-CT geometry: M=2, 1 um eff. pixel, z_eff=7.5 cm).
Validated: FDK(iterative+TV) RMSE 0.137 ~= FDK(clean phase) 0.136, vs
FDK(TIE-Hom) 0.146.

Prototype for the 0.5.x line; not a release.
```

```
The default ram-lak filter amplified high-frequency streaking off the sharp
high-contrast shell, and 120 angles undersampled the 360 deg orbit. Use 300
projections and the Hann-apodised ramp filter (an FDK setting, independent of
phase retrieval): volume RMSE drops to iterative 0.068 / clean-phase ref 0.060
(TIE-Hom 0.118), and the line/strap artifacts are gone.
```
