# 3DGS Batch Processing System

COLMAP과 Original 3D Gaussian Splatting을 이용해 여러 이미지 데이터셋을 일괄 처리하는 배치 파이프라인입니다.

---

## Overview

이 프로젝트는 여러 개의 이미지 zip 데이터셋을 한 번에 처리하여, 각 데이터셋에 대해 COLMAP 기반 카메라 포즈 추정과 3D Gaussian Splatting 학습을 자동으로 수행합니다.

실행이 완료되면 데이터셋별 학습 결과와 함께, 주요 PLY 결과만 모은 폴더가 자동으로 생성됩니다.

---

## Pipeline

- 이미지 zip 데이터셋 입력
- 압축 해제 및 이미지 루트 자동 탐색
- COLMAP 기반 카메라 포즈 추정
- Original 3D Gaussian Splatting 학습
- 7,000 / 30,000 iteration 결과 저장
- 최종 PLY 파일 자동 수집 및 정리

---

## Environment

- GPU: NVIDIA A100
- Reconstruction: COLMAP
- Training: Original 3D Gaussian Splatting
- Output: Gaussian Splatting PLY
- Input: 이미지 zip 데이터셋
- Docker: COLMAP 및 3DGS 실행 환경은 docker/ 폴더의 Dockerfile을 기반으로 구성됩니다.

---

## Usage

input_zip/ 폴더에 이미지 zip 파일을 넣은 뒤 실행합니다.

    ./run.sh --iterations 30000 --resolution 1600 --save-iterations 7000 30000

---

## Input Dataset

입력 데이터셋은 zip 파일 형태를 권장합니다.

예시:

    object_name.zip
    dataset_name.zip
    student01_object.zip

zip 내부에는 이미지 파일이 포함되어 있어야 하며, 폴더가 한 번 포함되어 있어도 자동으로 이미지 루트를 탐색합니다.

지원 이미지 형식:

    .jpg / .jpeg / .png

---

## Recommended Capture Guide

좋은 재구성 결과를 위해 다음 촬영 방식을 권장합니다.

- 약 50장 이상의 이미지를 촬영
- 물체는 고정하고, 카메라가 물체 주변을 반구 형태로 이동
- 각 이미지 간 충분한 시점 겹침 유지
- 물체 전체가 프레임 안에 들어오도록 촬영
- 배경이나 주변 특징점이 일부 포함되도록 촬영
- 물체를 손으로 움직이거나, 같은 각도에서 줌인/줌아웃만 반복하는 방식은 피할 것

약 50장 정도로도 실습용 결과 생성은 가능하지만, 세부 표현 품질은 다소 제한될 수 있습니다.

본 프로젝트에서는 약 300장 규모의 데이터셋까지 실험하였으며, 이미지 수가 증가할수록 더 안정적인 재구성과 풍부한 디테일 표현이 가능하지만 처리 시간이 증가합니다.

## Output Structure

각 데이터셋의 결과는 output/ 폴더 안에 개별 폴더로 저장됩니다.

    output/
    └── timestamp_dataset_iter30000_res1600/
        ├── point_cloud/
        │   ├── iteration_7000/
        │   │   └── point_cloud.ply
        │   └── iteration_30000/
        │       └── point_cloud.ply
        ├── 3dgs.log
        └── run_summary.txt

배치 실행이 완료되면 주요 PLY 파일만 모은 폴더도 생성됩니다.

    output/
    └── timestamp_summary/
        ├── dataset_iter7000.ply
        ├── dataset_iter30000.ply
        ├── another_dataset_iter7000.ply
        └── another_dataset_iter30000.ply

---

## Notes

- work/는 COLMAP 및 학습용 중간 파일이 저장되는 폴더입니다.
- output/은 학습 결과가 저장되는 폴더입니다.
- input_zip/은 실행할 zip 데이터셋을 넣는 폴더입니다.
- input_backup/은 데이터셋 보관용 폴더로 사용할 수 있습니다.
- work/, output/, input_zip/, 로그 파일, 대용량 zip 데이터셋은 GitHub에 포함하지 않습니다.
