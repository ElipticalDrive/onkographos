Summary
Implements Approach D from docs/research/sdf-csg-composition.md: linearise the CSG tree to a flat token array in postfix order. The shader walks the tokens once with a fixed-size 16-slot evaluation stack — no GPU recursion, deterministic results regardless of entity creation order.

Migration default tree
```

```
ADD-like = MODE_REPLACE ∪ MODE_SMOOTH_UNION. When role smoothness is 0 the smin clamps to k=1e-5 (effectively hard min) — legacy scenes with all-default SdfBlend render identically.
INTERSECT = MODE_SMOOTH_INTERSECTION. SUB = MODE_SMOOTH_SUBTRACTION.
Per-role k = max over the role's instances — tracked as a known minor drift on mixed-mode scenes (documented in update.rs comment), addressed when the tree-editor UX ships.
Within each role, leaves fold pairwise into a balanced subtree of depth ceil(log2(N)). Total tree depth covers ~65k primitives within the 16-slot stack.
SdfBlend component remains the user-facing API for the Inspector; the GPU-side blend fields are what got dropped.

Acceptance from issue body
Subtractive entity created first still subtracts (default tree rebuilds from full ECS state every frame; spawn order is irrelevant after the entity-index sort).
Reordering creation history of two entities never changes the rendered output (verified by order_independence_within_role test + manual scene reorder).
Per-entity smoothness controls the local blend radius (now via the operator edge of its role; user-visible behaviour preserved through Inspector).
Sphere-tracing converges on scenes with mixed roles + smooth blends.
Old scenes load and render identically post-migration (verified by smoke test on existing .ome_scene files; legacy MODE_REPLACE entities collapse to k≈0 smin which is hard-union-equivalent).
Stack overflow validated at upload time — CsgError::StackOverflow returned by serialise_postfix; an if let Err(...) in update.rs logs a warning and falls back to empty token stream + sky render.

Replace per-entity flat-fold SDF composition (where iteration order
silently determined the visible result) with a CSG tree linearised to a
flat array of tokens in postfix order. The shader walks the array once
with a fixed-size 16-slot evaluation stack — no GPU recursion, no
order-dependent renders.

- New `raymarch/csg_tree.rs`: `CsgNode` tree + balanced pairwise fold +
  DFS-postfix serialiser + depth>16 rejection. 10 unit tests cover
  token layout, balanced depth, overflow guard, migration shape, and
  order-independence within role.
- `SdfInstance` -> `SdfPrimitive` (64 B; blend metadata removed from
  the GPU struct, now lives on operator tokens).
- `SceneMeta` carries `primitive_count` + `token_count`.
- Scene bind group expanded to 3 SSBOs (meta + primitives + tokens).
- `raymarch_main.wgsl::eval_scene` rewritten as postfix evaluator with
  `array<f32, 16>` stack; new `apply_op` dispatches the 6 CSG ops.
- Migration default tree:
  smooth_subtract(
      smooth_intersect(smooth_union(adds, k=max), intersects, k=max),
      subs, k=max).
  MODE_REPLACE entities collapse cleanly when role smoothness is 0
  (smin clamps k to 1e-5, equivalent to a hard min).
