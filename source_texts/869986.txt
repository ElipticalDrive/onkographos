Abstract:
We study the partitioning of a regular rectangular grid for the purpose of parallel
5-point stencil computations. In a well-defined formulation, the parts have an equal number of
points, each part has a connected set of points, and the total communication volume is minimised.
We present an optimal solution and a theoretical proof of optimality for the 16 × 16 grid problem
with 4 connected parts, as a representative of a larger class of regular grid partitioning problems.
The proof is based on a systematic derivation of isoperimetric inequalities that provide lower
bounds on the number of neighbouring points of a connected part in different cases with up to
4 borders touched by the part. The theoretical optimality result is confirmed by computations
solving an Integer Linear Program (ILP) using Gurobi software, which took nine days using 32
concurrent threads. The ILP computation is made four orders of magnitude faster by adding
heuristic constraints to the ILP as suggested by the theory. Finally, larger grids of size up to
1024 × 1024 were tackled by a hybrid approach combining an initial combinatorial solution with
a constrained ILP. The resulting communication volumes are presumably close to optimal. They
are always better than the state-of-the-art hypergraph partitioning tools, with gains between 6.3%
and 12.2% for the 1024 × 1024 grid. Furthermore, the hybrid approach is faster than all except
one partitioner; that partitioner is the one over which the proposed approach obtains the largest
volume reduction for the 1024 × 1024 grid.

Introduction
In numerically solving partial differential equations with the finite difference method, a physical
domain is discretised and a computational domain of a set of discrete points is obtained. A
suitable pattern, called stencil, around each point is defined, where the computational scheme
updates a value at each point using the other points in this pattern. We are interested in twodimensional (2D) domains and discretisation using the five-point stencil, where two points (i, j)
and (i′ , j ′ ) of the resulting grid are neighbours iff |i − i′ | + |j − j ′ | = 1. In these I × J grids,
a point itself is also in the stencil, so that the required computations proceed by updating the
value of each point using its current value and the current values of all its neighbours.
A 2D grid of size I × J has grid points (i, j), where each coordinate is numbered from 0,
so 0 ≤ i < I and 0 ≤ j < J. All coordinates i and j in this article will be integers. We also
assume that I, J ≥ 2. In visualisations, we identify each grid point (i, j) with a small circle,
where the point is at the centre. Point (0, 0) is at the bottom left and point (I − 1, J − 1) at
the top right, see Figure 1. Column i consists of all grid points with first coordinate i, and row
j consists of all grid points with second coordinate j. The neighbours of a point (i, j) are the
points (i − 1, j), (i + 1, j), (i, j − 1), (i, j + 1) whenever they exist. Each interior point of the grid
has four neighbours; each corner point has only two neighbours; and the remaining border points
possess three neighbours. In the figures, a point is linked with an edge to each of its neighbours.
A grid can be partitioned for the purpose of a parallel 5-point stencil operation, where each
processor of a parallel computer obtains a part of the grid points. A part of the partitioning
is a subset V of the points. In a K-way partitioning, there are K nonempty disjoint parts Vk ,
k = 0, 1, . . . , K − 1. A part touches the left border of the grid if it includes a point (0, j). It
touches the right border if it includes a point (I − 1, j), and similar for the bottom and top
borders. We denote the number of touched borders by T = T (V ), with 0 ≤ T ≤ 4. The set V of
Figure 2 has T (V ) = 2 because it touches the bottom and right borders.
The total communication cost C of a parallel 5-point stencil operation is the communication
volume incurred by transferring all the needed data from the part where they reside in the
partitioning to the processor responsible for the stencil computation. Define the set N (V ) of
neighbours of a subset V as the set of grid points (i′ , j ′ ) ∈
/ V that are a neighbour of a point
(i, j) ∈ V . We define R(V ) = |N (V )|, the number of neighbours of V , which equals the number
of data words that part V in a partitioning needs to receive to perform the stencil computations
for the points in V . We can then calculate C as the sum over all parts Vk of the value R(Vk ).
We could instead calculate the same number C also by summing the number of data words to
be sent, but the number of sends for a part cannot be computed in isolation, as it also depends

The name we give to the problem refers to the more general version known as the hypergraph
partitioning problem, where each vertex of the hypergraph represents a grid point, and each
hyperedge represents a grid point and its neighbours.
In our theoretical derivations, from here on until Section 4.2, we will consider a restricted
version of Grid-2D(I, J, K), namely the problem Grid-2D-connected(I, J, K) where every part
Vk has to be connected with the connections provided by the edges of the grid. In the theoretical
sections, we implicitly define every part to be a connected subset, unless stated otherwise. The
set V of Figure 2 is such a connected subset.
The requirement that a part should be connected is imposed for several reasons: first, many
applications require the outcome of partitioning a grid problem to be connected parts; second,
merging several connected components into a single connected component usually (but not always) reduces the number of neighbours; third, it helps obtaining theoretical results on the
number of neighbours.
We are not aware of any polynomial time algorithm for the Grid-2D or Grid-2D-connected
problem. The general version of Grid-2D, hypergraph partitioning, is known to be NP-complete [?].
Whether or not our specific problem is NP-hard remains, to the best of our knowledge, an open
problem.
The graph partitioning problem for a grid with the objective of minimising the total edge cut
is a related but different problem than ours. It has entirely different optimal solutions (based
on rectangular subblocks) and it does not reflect the true communication cost of the stencil
operation, but only a very rough approximation thereof, see [?]. The main reason is that a value
at a grid point to be sent to two neighbouring points that reside on the same processor, actually
only needs to be sent once, whereas two edges are cut that contribute towards the edge-cut
metric.
In this paper, we are guided by the particular problem Grid-2D-connected(16,16,4). We
develop analytical tools to verify that a 4-way partitioniing of the 16×16 grid with communication
cost C = 57, claimed to be optimal in earlier work [2], is in fact optimal. Our analytical tools are
derived and proved for the general case and are thus useful in considering more general cases. We
make use of them in developing a set of heuristic decisions for an integer linear programmingbased solution, and for developing a practical heuristic which obtains the best known bound

Many physical applications require much more elaborate gridding techniques than the one we
consider. Furthermore, balancing the number of grid points per processor does not necessarily
lead to perfect computational load balance, as the interior points, border points, and the corner
points have different computational cost with the 5-point stencil. Nonetheless, the theoretical
results developed here will shed light on practical approaches. For example, we can check the
performance of sparse matrix and hypergraph partitioners on a regular grid problem. For this, the
grid partitioning problem can be translated to an equivalent sparse matrix problem, with every
matrix row representing a grid point and every off-diagonal nonzero in the matrix representing
a connection with one of the four neighbours. This is done for example in [5, Section 4.9], where
the Mondriaan sparse matrix partitioner is used to partition a 12 × 12 grid into 8 nearly equalsized subsets, showing a preference for connected parts and for stepwise boundaries between
parts. Furthermore, the special case we treat is the basis for a fast Breadth-First-Search (BFS)
partitioning algorithm [13] for the general rectangular case.
The ultimate goal for this line of work, in this paper and beyond, is to find an optimal balanced
K-way partitioning of the I × J grid of any size, with every part having a connected set of IJ/K
grid points, and with the minimum total communication cost C. Previous approaches [13,
18] with a similar goal start with a 4-way partitioning of a smaller square grid and extend
that partitioning to a general I × J grid and the desired number of parts. These approaches
demonstrate significant gains with respect to the standard partitioning tools. The contributions
of the current paper explain the success of the previous work for the 4-way partitioning case.
This paper also develops theory that gives lower bounds for the communication volume of
a part in an I × J grid, exhaustively covering the separate cases of the number of borders
T (V ) ≤ 4 that a part can touch. Here, we build on techniques by Wang and Wang [21] who
obtained optimal multidimensional shapes for a single part; in two dimensions this solves the
cases T (V ) = 0 and T (V ) = 2. Bollobás and Leader [7] provide a different proof for the case
T (V ) = 2 based on compressing the set V while reducing the cost R(V ). We will build on this
for the case T (V ) = 4. Our inequalities in all cases, including T (V ) = 0, 2, 4 are proven with
detailed arguments. Such problems concerning the minimal boundary size for a single part are
known as discrete isoperimetric inequality problems. Earlier studies in this area consider a single
part and its complement in an infinite grid, but not the overall partitioning problem into K
parts. To the best of our knowledge, the derived isoperimetric inequalities for the cases of a part
touching one, three, and four borders are novel. Furthermore, to the best of our knowledge, no
previous work has combined individual case results to demonstrate an optimal partition. We
achieve this for the 4-way partitioning of the 16 × 16 grid. More recent work along these lines
investigates the optimum shape of a part in grids of various underlying geometries (including
the grids addressed here), methods for counting those shapes, and the properties of the optimum
shapes in different sizes [3, 4, 19].

Communication lower bounds for separate parts
We derive lower bounds on the number of receives for separate parts, irrespective of the configuration of their neighbouring parts. We will do this by distinguishing the possible cases from
T = 0 to T = 4, but in a different order, starting with the easiest case T = 2.
3.1
Case T = 2
The case of two touched borders is straightforward if these borders are not adjacent, see Figure 4.
Lemma 3.1. Let V be a part with T (V ) = 2 that touches two nonadjacent borders. If these
borders are the bottom and top borders, then R(V ) ≥ 2J. If they are the left and right borders,
then R(V ) ≥ 2I.
Proof. Assume that the touched borders are at the bottom and the top. Since V does not touch
the left border, there exists a point (i, j) ∈
/ V to the left of V in every row j, 0 ≤ j < J, as V
is connected so that there exists a path from bottom to top in V . Hence, V has at least J left
neighbours. Similarly, V has at least J right neighbours, so R(V ) ≥ 2J. The case for V touching
the left and right borders is proven in a similar way.
The optimal number of neighbours for this case is R(V ) = 2J, since we can attain the lower
bound by assigning the complete columns 1, . . . , ⌊n/J⌋ of the grid to part V , where n = |V |, as
well as the bottom n mod J points of the next column.
Let us now consider the case that V touches two adjacent borders. The following lemma
can be used to derive a lower bound on the number of neighbours for parts that contain a point
in the interior of the grid and touch two adjacent borders. It will also be used in the proof of
Lemma 3.3 which gives the optimal lower bound for T = 2.

and left borders. Let k be such that ϕ2 (k) < n ≤ ϕ2 (k + 1). Then
R(V ) ≥ k + 3.
The lower bound R(V ) = k + 3 is attained by a set of grid points S consisting of the ϕ2 (k) points
of ∪kr=0 Wr and n − ϕ2 (k) contiguous points from Wk+1 .
Proof. The proof is a direct translation of the proof of [21, Lemma 4.1] to the two-dimensional
case where a set of the form of S is called a ‘standard sphere’.
Assume that V , S, and k are as given. Take a point (i, j) ∈ V with i + j ≥ k + 1. If such
a point does not exist, then V ⊆ ∪kr=0 Wr , so |V | = n ≤ ϕ2 (k), which is a contradiction. Now
apply Lemma 3.2, which gives R(V ) ≥ i + j + 2 ≥ k + 1 + 2 = k + 3.
For V = S, we have R(V ) = k + 3, as follows. First, there are s = n − ϕ2 (k) points in
Wk+1 , namely (i, k + 1 − i), i0 ≤ i < i0 + s, that have a total of s + 1 neighbours in Wk+2 ,
namely the set (i, k + 2 − i), i0 ≤ i ≤ i0 + s. Second, the remaining k + 2 − s points in Wk+1
are neighbours of points in Wk . The number of elements of these two disjoint set of neighbours
is (s + 1) + (k + 2 − s) = k + 3, hence reaching the lower bound on R(V ).
This means that sets of the form S are optimal for T (V ) = 2. Figure 6 gives an example set

i + j < i′ + j ′ or i + j = i′ + j ′ and i > i′ . The points of the grid in increasing simplicial order
are thus (0,0), (1,0), (0,1), (2,0), (1,1), (0,2), . . ., (I − 2, J − 1), (I − 1, J − 1). Bollobás and
Leader prove that the first n points in this order form a set S that attains the lower bound of
Lemma 3.3 for an infinite grid (taking I = J = ∞ in our notation), a result earlier obtained
by Wang and Wang [21]. This result corresponds to choosing i0 = k + 2 − s in the proof of
the lemma. Furthermore, they also prove that taking the first n points in the simplicial order
within an I × I grid has minimal boundary size, even if more than two borders are touched. The
resulting subset is connected, so it is a part. Note that this problem is not the same as finding a
part V with n points and minimal boundary size that satisfies the constraint of touching three
borders, or four borders.

3.5.1
Dropping operation
To prove optimality for general subsets V of grid points, it is useful to be able to transform a
subset V into another subset V ′ with the same number of grid points and a smaller or equal
neighbour count, and with a more beneficial structure such as dense rows or columns at the
borders of the grid. The following dropping operation is such a transformation.
For a subset of grid points V , not necessarily connected, define the transformed subset
Drop b (V ) = {(i, j) : 0 ≤ i < I ∧ 0 ≤ j < ci },
where ci ≥ 0 is the number of elements of V in column i. The transformation is carried out by
dropping all elements of V in the different columns straight down to the bottom. The dropping
operation to the bottom is illustrated in Figure 15. Similarly, we can define Drop t (V ), Drop l (V ),
Drop r (V ) for droppings towards the top, left, and right border, respectively.

Dropping is a form of compression [7], where a subset V is transformed into a subset V ′

each column form a contiguous block touching the bottom border and those in each row form a
contiguous block touching the left border.

3.5.3
Case T = 4 without dense rows or columns
The case that remains for a part with T = 4 is the case where no row or column is dense. We
have some computational evidence that the bound of Lemma 3.13 also holds for this case, but
we do not have a proof. The evidence concerns the problem of a 16 × 16 grid with n = 64 and
with limited imposition of connectivity. This problem was found to have an optimal solution V
with R(V ) = 22, where V happens to be connected. This result exactly fits the lemma.
The difficulty in finding a proof is that we cannot use the drop operation that simplified the
proof of Lemma 3.13, in the present case where there are no dense rows or columns. This is
because dropping a part V with T (V ) = 4 towards a border will in this case cause the result V ′
not to touch the opposite border any more, and the operation will yield T (V ′ ) = 3. We may need
to find a different transformation that maintains the number of touched borders as the basis for
a proof in this case.
The fact that there are no dense rows or columns does however provide us with another,
weaker bound. This bound is in fact the same as for the case T = 3.

Using the theoretical findings
In this section we put the theoretical findings developed so far into use. First, we certify that
a previously claimed result is optimal. Our aim is in doing so is to give a guideline in applying
our theoretical results. Second, we develop heuristic approaches informed by the theory.
4.1
Optimal partitioning of a square 16 × 16 grid into 4 parts
It was claimed previously [2] that an optimal 4-way partitioning of the 16 × 16 grid had a total
communication volume of 57. We show that this is true. We will do this first by deriving a lower
bound R(V ) ≥ 12 on the number of receives per part V , by considering the five different cases
T (V ) = 0, 1, 2, 3, 4 separately. Then we will combine the individual cases.

Purely combinatorial approach
A purely combinatorial approach using breadth-first search (BFS) was investigated by George

Hybrid heuristic
We can combine the combinatorial and the ILP approaches. We start with Algorithm 1 to
obtain an initial solution in linear time. Then we identify the set C of points that need to be
communicated. We use the formulation ILPCorCenForb and additional constraints to fix the
assignment of all points in P \ C as computed by the combinatorial algorithm. The variables
corresponding to the points in C are left as free. We do not use the ball constraints for the
connectivity as the free points are at the boundary of the parts. We then run an ILP solver on
this constrained formulation of ILPCorCenForb. We call the resulting heuristic method rbFast
which is shown in Algorithm 2.
Algorithm 2 rbFast (I)
Require: I × I, grid size
Ensure: The grid points are partitioned into four.
1: Call Algorithm 1
2: Let C be the set of points that need to be communicated.
3: Build ILPCorCenForb, fix the points P \ C to their part found at Line 1, and solve the updated ILP.
In rbFast, C has a cardinality of the order of O(I). The constraints on the centre points
and the forbidden assignments are in effect; we do not add the connectivity constraints, as we
deal with the boundary only. Approaches similar to Algorithm 2 have been used successfully in
the literature for general graph partitioning [?]. There, ILP-based formulations in the spirit of
BasicILP are used to refine the boundary of obtained partitions. In such a general setting, there
is not much theoretical guideline to build stronger ILPs similar to ILPCorCenForb, and a lot
more machinery is required to solve the resulting ILPs with a branch-and-bound approach.

6
Concluding remarks
We have studied the problem of partitioning a regular rectangular grid into equal-sized connected
parts for the purpose of parallel 5-point stencil computations, where the objective is to minimise
the total communication volume. We have first systematically derived isoperimetric inequalities
that provide lower bounds on the number of neighbouring points of a part when the part touches
zero, one, two, three, or four borders. To the best of our knowledge, the derived isoperimetric
inequalities for the cases of a part touching one, three, and four borders are novel, while those
for the cases of a part touching zero or two borders are known. Our inequalities in all cases
are proven with detailed arguments. We have then combined the results to present an optimal
solution along with the proof of optimality for the 16 × 16 grid problem with 4 parts, which was
an open problem.
We have made use of the presented theoretical results in two practical contexts. First, we have
added constraints heuristically to an integer linear programming formulation of the problem at
hand and obtained an improvement of four orders of magnitude in the run time. Second, we have
combined the enriched formulation with a combinatorial solver to propose a practical method
to partition grids. Experiments with this method in 4-way partitioning of grids of size up to
1024×1024 show that it consistently obtains solutions with a smaller communication volume than
the state-of-the-art hypergraph partitioners. For the 1024 × 1024 grid, the improvements range
from 6.3% to 12.2%. Furthermore, the proposed method is also faster than the best available
tool for partitioning this grid, while achieving a 6.3% quality improvement over it.

We are confident that some of the solutions obtained by the proposed partitioning method
(see Table 3) are optimal or very close to optimal. We leave it as an open problem to show
if any of them are optimal. Our methodology in Section 4.1 where we showed the optimal
partitioning of the 16 × 16 grid is clearly a basis for generalisation but this would require possibly
tedious adaptations for other grid sizes. A rigorous, easy to follow recipe for that methodology,
potentially based on computational tools rather than a full analytical result, will certainly be of
value.
The strongest ILP formulation, ILPCorCenForbConn, allowed an ILP solver to obtain optimal
solutions to the 32 × 32 case, while the 64 × 64 case seems out of reach. A careful implementation
of a branch-and-bound approach, on top of state-of-the-art symmetry-breaking techniques and
local cuts, can use more theoretical results from Section 3, and could possibly solve that case
optimally, which is a natural next step.
