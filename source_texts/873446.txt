Contributor
Adds SE(3) pose representation supporting multiple initialization formats and evaluation strategies.
Implementation
Hybrid evaluation: @cached_property for lazy computation, eager=True flag pre-computes all representations (matrix, quaternion, euler, se(3) vector)
Initialization: Supports translation + rotation matrix/quaternion/euler/axis-angle, 4x4 homogeneous matrix, se(3) vector, or identity
Operator overloading: * for composition and point/point-cloud transformation
Numerical stability: .normalize() re-orthonormalizes rotation via SciPy's Rotation class
Usage
```
from pose6dof import Pose6D
import numpy as np

# Lazy by default - properties computed on access
pose = Pose6D(translation=[1, 2, 3], euler=[0, 0, np.pi/4])

# Eager mode pre-computes all representations
pose_eager = Pose6D(translation=[1, 0, 0], quaternion=[0, 0, 0.7071, 0.7071], eager=True)

# Composition and transformation
pose3 = pose1 * pose2
transformed_points = pose * points_array

# Access any representation
T = pose.matrix       # 4x4 SE(3) matrix
q = pose.quat         # [x, y, z, w]
rpy = pose.euler      # [roll, pitch, yaw]
xi = pose.se3         # [rotvec(3), trans(3)]
```

38 tests covering initialization variants, lazy/eager evaluation, pose composition, point transformation, normalization, inverse, edge cases, and representation consistency.
Original prompt
Create a Python class Pose6D for SE(3) using NumPy and SciPy.
Key Design Principles:
Hybrid Evaluation: Implement both lazy evaluation (using cached_property) and optional eager evaluation to pre-compute all representations (matrix, quat, euler, se3) upon initialization.
Cache Management: Ensure that cached representations are consistent with the primary state.
Flexible Initialization: Support multiple input formats.
Operator Overloading: Provide intuitive * for composition and point transformation.
Numerical Stability: Include a .normalize() method to ensure the rotation remains orthonormal.
