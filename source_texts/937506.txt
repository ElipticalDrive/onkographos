Summary
Lane 13 (world-outdoor) Wave B / M2–M3 (DESIGN.md §9.2, ADR-008). Two deliverables, both as header-only internal kernels with a single new Catch2 test TU.
1. SIMD fast-path for heightfield sampling / traversal — engine/world/outdoor/HeightfieldSimd_internal.h
sample_bilinear_x8 — 8-wide bilinear height sampler.
march_packet8 / march_rays — 8-wide ray-vs-heightfield packet intersection (+ a JobSystem batch driver).
lod_for_distance / select_lods_x8 / select_chunk_lods — CDLOD chunk LOD selection, vectorised, with a JobSystem driver.
Every kernel reproduces its scalar reference per lane (same op order — mul+add, never fused multiply-add — so packed lanes match the scalar path to fp tolerance; LOD selection matches exactly).
Per ADR-008 this is the sampler / intersection fast-path for the existing CDLOD heightfield (the kernel the §8.2 hybrid shadow path and heightfield physics raycasts use), not a reintroduced raymarcher backend.
2. Spline track editor — engine/world/outdoor/SplineEditor_internal.h
Control-point insert / move / remove (+ append).
to_segments — uniform Catmull-Rom → cubic Bézier, emitting the already-public SplineRoadSegment; interpolates the knots, C1 across joins, supports closed loops.
Arc-length parameterisation: build_arc_table + sample_at_arc_length (constant-speed sampling for even road-texture spacing / AI line / physics waypoints).
Banking: per-knot, interpolated smoothly along each segment in the sampled frame, plus auto_bank (bank-into-corners from local curvature).
Ownership / cross-lane notes (for the orchestrator)
All edits are within engine/world/outdoor/ plus the one allowed new test file tests/unit/world_outdoor_waveb_simd_spline.cpp. tests/unit/CMakeLists.txt is untouched (it GLOBs with CONFIGURE_DEPENDS). No public header changed.
Cross-lane include (no action needed): the SIMD kernels consume lane 03's inline back-end via simd/Simd_internal.h (cmp/blend/min/max/sqrt/f32x8 aren't on the frozen Simd.h surface, which only exposes the f32x4 arithmetic set). This is header-only and compile-time-resolved — psynder_simd is already a PUBLIC dependency of this lane, so there is no new link edge. Precedent: the SIMD unit tests include the same header. If you'd prefer these kernels promoted onto the frozen public Simd.h, that's a lane-03 public-header change to coordinate.
Frozen-header handling: the editor state types (SplineTrack / TrackControlPoint) live in detail because Terrain.h is frozen. The editor's output is the public SplineRoadSegment, so the public contract is unchanged. If lane 22 (editor) later needs these types public, that's a coordinated Terrain.h change.
The two new headers are #included from Terrain.cpp so they get lib-level compile coverage on all five CI jobs (incl. Windows clang-cl + the dedicated build, where tests are OFF) — matching the existing pattern (Terrain.cpp already includes Scatter_internal.h / Raymarch_internal.h without calling them directly).
Test plan

Linux · Vulkan · x86_64 (SSE/AVX) — build + ctest
Linux · Dedicated · headless — build (tests OFF; header compile coverage via the lib)
Windows · Vulkan · clang-cl — build (tests OFF; header compile coverage via the lib)
clang-format check
New cases in world_outdoor_waveb_simd_spline.cpp: SIMD-vs-scalar parity (bilinear, ray packet, LOD), the JobSystem batch drivers vs a per-element scalar loop, and the spline editor ops / Catmull-Rom interpolation / arc-length constant-speed sampling / banking. Headers + test verified to compile locally under MSVC /W4 /permissive-; runtime parity is validated by the macOS + Linux CI test jobs.

Pull request overview
This PR adds two new header-only internal subsystems under engine/world/outdoor/ for Wave B: an 8-wide SIMD fast-path for heightfield sampling/ray traversal/CDLOD LOD selection, and a spline track editor that can mutate control points and derive road segments with arc-length parameterized sampling and banking. It also adds a single Catch2 unit-test TU to validate SIMD-vs-scalar parity and spline editor behavior, and wires the new headers into Terrain.cpp for compile coverage.
Changes:
Add HeightfieldSimd_internal.h: 8-wide SIMD bilinear sampling, ray-vs-heightfield packet intersection (+ JobSystem driver), and SIMD CDLOD chunk LOD selection (+ JobSystem driver).
Add SplineEditor_internal.h: spline track editing ops, Catmull-Rom→Bezier derivation, arc-length table + constant-speed sampling, and curvature-based auto-banking.
Add tests/unit/world_outdoor_waveb_simd_spline.cpp to validate SIMD parity, batch drivers, and spline editor functionality; include new headers from Terrain.cpp for non-test builds.
