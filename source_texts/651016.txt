Description: Adds Voxel Architect, an isometric building sandbox. It provides a studio-grade environment for creating 3D-feeling structures using 2D canvas projections.
Key Features:
Isometric Projection: Custom-built renderer for projecting 3D voxel coordinates onto 2D space.
Depth Sorting: Implementation of the "Painter’s Algorithm" to ensure correct layering of cubes.
Studio UI: Professional-grade toolbox including color palettes, rotation controls, and grid stats.
Persistence: LocalStorage integration to save and resume complex builds.
Technical Details:
Math: Custom isometric coordinate transformation (X, Y, Z -> ScreenX, ScreenY).
Architecture: Decoupled World Model and Rasterization Renderer.
Files: 12 modular files for 3D state management.
