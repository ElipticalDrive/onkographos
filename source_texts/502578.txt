Pull request overview
This PR updates the texture-space dosimetry pipeline for the Unity/HDRP DXR irradiance simulation by fixing UV-space baking orientation, introducing a ray traced shadow/visibility bake into a dose texture, and wiring the new baker into the simulation scene and controller.
Changes:
Added a UV-space MRT baker shader to output world-space Position/Normal maps with a Y-flip alignment for ray tracing dispatch.
Added a DXR .raytrace raygen+miss shader and a new IrradianceBaker C# component to build an RTAS and accumulate Lux-hour dose into an RFloat texture.
Updated LightDoseSimulator to dispatch the DXR bake during the simulation loop and apply a preview texture; updated the scene to include the new baker component.
