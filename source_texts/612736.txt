This change optimizes atmospheric and sky rendering by replacing expensive on-the-fly FBM and Curl noise computations with lookups from pre-generated textures managed by NoiseManager.
Key components:
Noise Generation: NoiseManager now generates a 2D blue noise texture (256x256) in addition to the 3D Simplex/Worley/FBM and Curl textures.
Shader Helpers: fast_noise.glsl provides a standardized API for shaders to access specific noise types from the packed channels of the pre-generated textures.
Atmosphere Refactor: atmosphere.frag cloud layer now uses pre-computed 3D FBM.
Sky Refactor: sky.frag nebula effects now use pre-computed FBM and Curl noise.
Integration: Updated the graphics engine to ensure these textures are correctly bound and available to the relevant rendering passes.
