What and why
draw geometry stages, and what Rethinking Voxels needed (60d3a679b)
Flat terrain draws a program with a geometry stage without its index buffer: the vertex stage reads it (set 5) and the draw has an instance for each triangle the geometry stage may emit.
Programs that write only images draw into a sink that keeps nothing.
The pack's images are cleared before the shadow pass, not after it, and a pass that samples an image it stores samples last frame's copy. Images an atomic function uses are made for atomics (Metal dropped them otherwise), and images bind in vertex stages where the device lets them.
HORIZON_SHADER_PACK_DUMP= logs how many of a pack image's texels are set, for debugging.
Rethinking Voxels r0.1-beta9 voxelizes the world in its shadow pass and lights it with its colored voxel lights.
a terrain or shadow program that writes only images is drawn (8429a924e)

Needs changes: 2 issues (plus one doc nit).
Reviewed only this PR's two commits (860b4b5b7, 1861ee515) against #4450's head: gfx.rs, flat.rs, pack_atlas.rs, pack_images.rs, pack_post.rs. Read the code and did not run it. No pack was rendered and no GPU path was exercised.
image_copies shifts a u16 by a custom image's index (pack_post.rs:1313, also used at :1993 and :2178). Nothing limits how many image.* a pack declares (post.rs pushes every one). At index 16 or higher, debug builds panic with a shift overflow and release builds copy and sample the wrong image.
The copy for "samples and stores" passes is taken once, at the start of the frame (pack_post.rs:3122). So such a pass never sees what the shadow pass, compute programs or earlier composites wrote to that image this frame. For a clear = true image it also samples last frame's contents where GL would see the cleared image. Copying right before each pass with image_copies != 0 would keep wgpu's no-aliasing rule and stay close to GL.
Nit: PULL was inserted between FACE's doc comment and FACE (pack_atlas.rs:116-128). PULL now carries both docs and FACE has none.
The earlier review's point (a geometry program that writes only images was skipped) is fixed. Those passes now draw with only the depth attachment (pack_post.rs:2313), and VERTEX_WRITABLE_STORAGE / TEXTURE_ATOMIC are requested where available (gfx.rs:1075-1077).
