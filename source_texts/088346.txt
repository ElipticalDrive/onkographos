Description
Adds ODF (Orientation Distribution Function) and Tensor (Diffusion Tensor Imaging) visualization to dipy_horizon via FURY actors. This introduces two new interactive tab classes with slicing panels, colormap controls, and state serialization, plus a WebGPU-compatible streaming widget for Jupyter notebooks.
Motivation and Context
Closes #3502
The dipy_horizon interactive viewer supported tractograms, anatomical images, peaks, ROIs, and surfaces — but had no way to visualize ODF glyphs or DTI ellipsoids. Researchers working with CSD (Constrained Spherical Deconvolution) or DTI models had to use separate scripts to visualize their results, breaking the interactive workflow.
This PR closes that gap by adding:
ODFTab: renders spherical harmonic coefficients as ODF glyphs using fury.actor.odf_slicer, with per-axis interactive slicing, normalization toggle, scale and colormap controls
TensorTab: renders DTI ellipsoids using fury.actor.tensor_slicer, with three coloring modes (FA-RGB, scalar FA, mean diffusivity), per-axis slicing, and scale controls
Data loaders supporting both NIfTI (4-D SH coefficients, eigenvalue/eigenvector pairs) and .npz formats
CLI flags: --odf, --odf_scale, --odf_colormap, --odf_sh_basis, --odf_no_norm, --tensor_evals, --tensor_evecs, --tensor_colormap, --tensor_scale, --backend
Backend auto-detection cascade: FURY_BACKEND env var → Pyodide → GLFW → VTK fallback
HorizonWidget for Jupyter streaming (FURY FuryStreamInteractor) and HorizonWGPUApp as a migration target for the upcoming FURY wgpu backend (FURY NF: Added support to colorize each line points indivdually #942)

Practical Usage Examples
```
# 1. Show only CSD fiber orientation distribution function (fODF) glyphs
dipy_horizon --odf csd_sh_coeffs.nii.gz

# 2. Customize ODF appearance
dipy_horizon --odf csd_sh_coeffs.nii.gz --odf_scale 1.5 --odf_colormap viridis

# 3. Show only DTI tensor ellipsoids with FA-weighted RGB coloring
dipy_horizon --tensor_evals dti_evals.nii.gz --tensor_evecs dti_evecs.nii.gz

# 4. Tensor ellipsoids colored by scalar fractional anisotropy (FA)
dipy_horizon \
  --tensor_evals dti_evals.nii.gz \
  --tensor_evecs dti_evecs.nii.gz \
  --tensor_colormap fa

# 5. Display both ODF glyphs and tensor ellipsoids together
dipy_horizon \
  --odf csd_sh_coeffs.nii.gz \
  --tensor_evals dti_evals.nii.gz \
  --tensor_evecs dti_evecs.nii.gz

# 6. Include anatomical background image (T1, T2, etc.)
dipy_horizon t1.nii.gz \
  --odf csd_sh_coeffs.nii.gz \
  --tensor_evals dti_evals.nii.gz \
  --tensor_evecs dti_evecs.nii.gz

# 7. Use experimental WebGPU backend (useful for notebooks or browser-based viewing)
dipy_horizon --odf csd_sh_coeffs.nii.gz --backend webgpu
```
Generating Input Files with DIPY
```
# -----------------------
# DTI (Diffusion Tensor Imaging)
# -----------------------
from dipy.reconst.dti import TensorModel
tenfit = TensorModel(gtab).fit(data, mask=mask)

import nibabel as nib
nib.save(nib.Nifti1Image(tenfit.evals, affine), "dti_evals.nii.gz")
nib.save(nib.Nifti1Image(tenfit.evecs, affine), "dti_evecs.nii.gz")


# -----------------------
# CSD (Constrained Spherical Deconvolution)
# -----------------------
from dipy.reconst.csdeconv import ConstrainedSphericalDeconvModel, auto_response_ssst

response, _ = auto_response_ssst(gtab, data, roi_radii=10, fa_thr=0.7)
csd_fit = ConstrainedSphericalDeconvModel(gtab, response).fit(data, mask=mask)

nib.save(nib.Nifti1Image(csd_fit.shm_coeff, affine), "csd_sh_coeffs.nii.gz")
```
