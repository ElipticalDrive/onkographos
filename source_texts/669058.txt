Stacked on #117, targeting feature/voxel-region-editing. Merge #117 first, then retarget this PR to main.
Adds Polygon > Convert Selected Mesh to Voxels and Voxel > Convert Selected Voxels to Polygon. Both operate on current scene geometry, preview the output, keep the source, preserve world placement/grid scale and membership, and add the result with geometry/selection Undo. Polygon conversion exposes local cell size and Solid/Shell/Surface modes and samples base-color/alpha and vertex colors. Voxel conversion generates an editable flat block surface with material groups and repeating UV0/UV1 coordinates.
Voxel region menu commands now open an Apply/Cancel settings preview. Signed extrusion supports 1..32 cells, rotation +/-90 degrees around object-grid axes with bounds/Cell 0/custom cell-centre pivots, and integer scale 2..8. Snapshot computations use the existing background job service. Changed inputs invalidate previews; scene/region changes require recomputation before applying. Result display is capped at 20,000 cells/triangles.
Adds Single Cell / Connected Piece click modes. With X-Ray off, box and brush candidates need a first-hit scene ray to that exact object/cell, handling other-object and self-occlusion. Visibility uses bounded samples, so narrow visible slivers can be missed. Ray-budget exhaustion refuses a partial selection.
Converted voxel palettes are object-owned and persisted through DVOX plus scene format 8's explicit palette-ID lists. Existing scenes still load; palette-free saves retain formats 6/7. Rendering, camera preview, clipboard/Extract, cloning and Play density retain/use these definitions. New palette scenes require the updated reader. Conversion is bounded by dense-grid, raster-work, image, geometry and palette budgets.
Limits: no smoothing, UV atlas packing, detailed-shader/normal-map baking, or manifold repair for touching voxel cells. Material layers are not copied as unresolved palette references. The source retains anchors, prefab/socket relationships, scripts and children; outputs are independent geometry.
Validation: source review only. No builds, automated tests or CI were run, per the user's instruction. The commit includes [skip ci]. Manual handoff and limits: docs/editor-conversion-selection-preview-2026-10-12.md.
