Describe the missing learning path
NeRFTrainer's existing pointwise RGB loss does not use densities: actual density_head gradients remain None and density weights never update. NeRFRenderer can compute density-sensitive rendered RGB, but its network query runs under no_grad, so that observation cannot train the field. The service therefore lacks the ray-observation objective needed to learn density from image RGB.
To Reproduce
Main78dd7a6af45dbf6158c982f6d4f5668d1a287332, actual tiny NeRFNetwork(frequencies0,direction frequencies0,hidden_dim2,layers1), CPU Torch2.8. Native linear weights map positive z to color logits, constant density0.4. A two-sample ray along+Z on[0.1,1] yields RGB0.6687559 with requires_gradFalse. Actual pointwise train_step reports loss0.1182136 against RGB0.3, but both density-head gradients are None and density weights unchanged. The same rendered observation has a nonzero analytic density derivative approximately-0.1294.
Expected behavior / acceptance
Add an explicit differentiable ray-render path that preserves current inference defaults and the completed volume integration law.
Add named ray-observation training using complete owned compatible origins/directions/target RGB, interval/sample/batch/epoch/work admission and the actual volume-rendered pixel objective. Both density and color receive native gradients and optimizer updates.
Preserve the old pointwise fitting API as an explicitly documented pointwise objective; never silently reinterpret point positions as ray origins or claim it trains density.
Provide a bounded mounted ray-training consumer with honest objective metadata. No real cameras/sensors/providers; synthetic explicit ray/RGB observations only.
Verify independent analytic two-sample volume/density/color gradients, finite-difference controls, actual accepted native optimizer references, complete dataset rejection and existing renderer/pointwise compatibility.
Environment
macOS/Python3.12/CPU Torch2.8.0, synthetic tensors only.
Additional context
Substantial missing native density-learning objective/observation pipeline, distinct from completed #17182/#17183 skip/volume-axis/transmittance repair and #17220/#17221 camera geometry. Original NeRF paper describes learning from differentiable rendering of image observations: https://arxiv.org/abs/2003.08934 . Preserve current sampling/infinite-tail convention, no hierarchical sampler/empirical reconstruction quality/production fit/whole-epoch or optimizer-recovery claim. Please assess actual scope/evidence without assuming Hard/30 points.
