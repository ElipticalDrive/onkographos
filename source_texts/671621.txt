Summary
Fix the Paired JiT validation metrics that were inflated by skull-stripped BraTS background.
Brain-masked PSNR & SSIM: full-volume scoring was dominated by ~80–90% background zeros (trivially matched between src and tgt), inflating toward the copy-src ceiling (~23.8 dB). Both val/psnr and val/ssim are now computed over the brain mask (tgt > 0). PSNR uses brain-region MSE; SSIM multiplies both pred and tgt by the mask before the 3D SSIM (the tgt==tgt identity still yields exactly 1.0).
data_range clamp: data_range = max(tgt[max−min], 1.0), aligning with the VAE's [0,1] intensity convention (BraTS MR percentile normalization is clip=False, so the bright tail can exceed 1.0).
Metric names are unchanged, so ModelCheckpoint(monitor="val/psnr") needs no change — it now selects on brain-region fidelity instead of background.
Context
Surfaced by a multi-agent audit of the VAE encode/decode/scaling calls (benchmarked against NVIDIA NV-Generate-CTMR): the VAE itself is correct — the ~24 dB reading was a measurement artifact of full-volume scoring on skull-stripped data (the copy-src baseline already scores ~23.8 dB full-volume). This PR fixes the metric so it reflects true task difficulty.
Tests
test_brain_mask_excludes_background (new): a 90%-background volume where pred is exact on background but wrong inside the brain → masked PSNR ≪ full-volume PSNR; masked SSIM < 1 and within [0,1].
Updated the two PSNR pin tests to the brain-masked recompute.
Updated the DDP baseline to the masked values (val/psnr=15.495928, val/ssim=0.221532).
Full suite: 486 passed, 0 failed.
