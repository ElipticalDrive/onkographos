What
Reinstates classical mesh photogrammetry as the primary pipeline — COLMAP dense MVS → Poisson surface reconstruction → texture → export — replacing an Instant-NGP/NeRF attempt and an evaluated-but-rejected 3D Gaussian Splatting plan.
Both neural routes hit toolchain fragility on the GTX 1650: Instant-NGP needed far more VRAM headroom than the resize gave it (97 photos × ~195 MB ≈ 19 GB against 4 GB), and gsplat's prebuilt wheels are Python-3.10-only on Windows, forcing a parallel Python install alongside the laptop's 3.13. COLMAP's own Windows release ships CUDA precompiled — unzip and run, no compiler, no version pinning — which removes that class of risk entirely.
Reuses the existing sparse SfM model (colmap_work/sparse/0, 97/99 images registered, 64,945 points) unchanged. COLMAP's feature extraction/matching/mapping never re-runs.

Testing
COLMAP and OpenMVS aren't installed in the dev environment this was built in, so stages that wrap them (8–11) were dry-run and unit-tested (argument parsing, command construction, JSON logging) rather than run against real binaries. What could run end-to-end, did:
07_prepare_scene.py — run against this repo's real images/ + colmap_work/sparse/0/: reports 99 images on disk, 97 registered, 64,945 points — an exact match to the known-good reconstruction.
09_dense_stereo.py's OOM auto-retry ladder — verified against a fake failing binary: 2400 → 1200 → 800, succeeded, every attempt logged.
10_fuse_mesh.py — run against real synthetic PLY output; point/vertex/face counts and colour detection all correct.
12_export_mesh.py — run for real with trimesh; produced a valid .glb confirmed via file.
13_turntable_render.py — run for real with Open3D. First attempt used OffscreenRenderer, which fails headlessly on macOS ("EGL Headless is not supported on this platform"); rewritten to the legacy Visualizer(visible=False) API and re-verified, including confirming actual frame-to-frame rotation via pixel differencing, not a frozen frame.
run_dense_pipeline.py — dry-run tested end to end, plus --resume skip logic and failure-stops-chain-with-resume-hint, both confirmed against real files.
Also in this PR
Fixes .gitignore, which left ~2.1 GB of zips/PDF/video/colmap_work/ untracked but not ignored.
garuda_cv_pipeline.md rewritten to describe the current pipeline, fold the two rejected neural approaches into a one-paragraph "considered and rejected" note, and correct a factual error (the excluded images are IMG_6081/IMG_6082, not IMG_6108, which registered fine).
