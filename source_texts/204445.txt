Summary
Added comprehensive algorithmic and architectural documentation in docs/features/floorplan-contour-export.md explaining 2D contour tracing, Marching Squares isocontour extraction, polygon simplification, and SVG vector path string generation used in src/lib/floorplan/contourSvgExporter.ts and src/wasm/floorplan/contour_tracer.c.
Key Documentation Highlights
Mathematical Foundations: Details 2D grid cell discretization, 4-bit state indexing, continuous sub-pixel linear interpolation, and disambiguation of saddle points (Cases 5 & 10).
16-Case Lookup Table: Includes visual ASCII case lookup matrices and exhaustive case mapping specifications for all 16 corner occupancy configurations.
Polygon Assembly & Smoothing Pipeline: Documents segment chaining, Ramer-Douglas-Peucker (RDP) collinear wall simplification, and Chaikin corner-cutting spline curves.
SVG Generation & Serialization: Details contourToSvgPathData, architectural styling presets (CONTOUR_STROKE_PRESETS), metadata headers, round stroke joins, and client-side browser Blob download logic.
