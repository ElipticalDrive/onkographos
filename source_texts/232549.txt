# 03-pbr-sphere-ibl

**Concept:** Vulkan PBR sphere with Cook-Torrance BRDF + image-based lighting

## Build

Requires Vulkan SDK 1.3+, CMake 3.20+, GLFW 3.4+.

```
cmake -B build -S .
cmake --build build --config Release
```
