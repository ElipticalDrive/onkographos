Closes #27
Summary
Implements deterministic procedural nebula generation using Stellar transaction hashes as seeds.
Changes
Seeded PRNG (\createRNG): mulberry32 algorithm for fast, deterministic pseudo-random numbers
Hash-to-seed (\hashToSeed): converts Stellar transaction hashes (hex strings) into numeric seeds
Perlin noise: 2D and 3D implementations with fractal Brownian motion (fbm2D/fbm3D) for organic patterns
5 nebula patterns: spiral, ring, cluster, filament, and core — each producing visually distinct distributions
Two output formats: \generateNebula\ returns portable particle arrays; \generateNebulaGeometry\ returns Float32Arrays ready for Three.js BufferGeometry
Configurable: custom color palettes, radius, particle count
42 unit tests: determinism, bounds checking, edge cases, all patterns, noise range validation
Files
\src/utils/procedural/nebula.ts\ — core implementation
\src/utils/procedural/tests/nebula.test.ts\ — test suite
Acceptance Criteria
Deterministic generation from seed
Multiple nebula patterns/types
Consistent results for same seed
Visually appealing distributions (Perlin noise + FBM)
Performance optimized (pre-allocated Float32Arrays, mulberry32 PRNG)
