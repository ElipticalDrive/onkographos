Summary
This draft starts a clean, incremental modern browser-engine rebuild on rebuild/voxelcraft-modern-core, without changing or deleting main.
Documents the initial MCPE 2013 source/architecture audit, proposed module boundaries, phase gates, and unresolved licensing restrictions.
Adds an original, framework-independent world core: stable block registry, 3D chunk coordinates including negative positions, chunk storage, revision/dirty tracking, and a single world-edit API.
Adds original physics primitives: immutable AABB geometry, axis-specific movement clipping, and voxel DDA raycasting with face, hit point, and max-reach results.
Adds deterministic Node tests and a dedicated CI workflow.
Keeps the existing browser game intact as a compatibility/reference implementation; the new core is not yet wired into the live renderer.

Important boundaries
This is a foundation milestone, not a claim that the modern game is complete.
MCPE 2013 source has no discoverable license file in the repository tree; Mojang/Microsoft assets remain rights-restricted. No copied C++ code or newly redistributed assets are introduced by this core.
Next milestone: integrate raycasting and transaction-based world edits behind the browser runtime, then build/test player collision and movement against explicit invariants.
Do not merge until subsequent mechanics milestones and their tests are reviewed; this PR is intentionally draft.
