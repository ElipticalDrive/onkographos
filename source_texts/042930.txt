This pull request introduces WebCraft, a complete browser-based voxel game engine inspired by Minecraft, built with WebGL and JavaScript.
Summary
WebCraft is a full-featured voxel game implementation that supports both single-player and multiplayer modes. It includes a complete rendering pipeline, physics simulation, block system, player controls, and networking infrastructure.
Key Changes
Core Game Engine:
js/blocks.js - Comprehensive block type system with 100+ block definitions (stone, dirt, wood, ores, etc.) with texture mapping and directional rendering
js/world.js - World container managing 3D block arrays and world state
js/render.js - WebGL-based renderer with shader system, camera management, and mesh generation
js/physics.js - Physics simulation for gravity and collision detection
js/generator.js - Procedural terrain generation using Perlin noise-like algorithms with smoothing
Player & Interaction:
js/player.js - Local player controller with movement, camera control, inventory management, and input handling
js/mobs/zombie.js - Mob entity system (zombie implementation)
js/touch-controls.js - Touch input support for mobile/tablet devices with on-screen joystick and controls
js/helpers.js - Vector math and utility classes
Networking & Multiplayer:
js/network.js - Socket.io-based client-server communication for multiplayer gameplay
server.js - Node.js server implementation for hosting multiplayer worlds
UI & Styling:
singleplayer.html / multiplayer.html - Game entry points
style/world.css, style/main.css, style/gui.css, style/touch.css - Complete UI styling with Minecraft-like aesthetics
style/menu.css - Menu styling
Menu pages: menus/worlds.html, menus/server-list.html, menus/options.html, menus/skin.html
Assets & Resources:
Complete resource pack with 100+ block textures in resource_packs/default/textures/block/
GUI textures (inventory, hotbar, crosshair, containers)
Entity textures (player model)
Minecraft-style font (minecraftia.ttf)
Additional Features:
js/items/items.js - Item system with tools and weapons
js/blocks/crafting.js - Crafting system
js/blocks/blockActions.js - Block interaction handlers
skin-3d/ - 3D player skin viewer component with CSS 3D transforms
Notable Implementation Details
Uses glMatrix for 3D math operations
WebGL with custom vertex/fragment shaders for block rendering
Procedural terrain generation with configurable roughness and smoothing
Pointer lock API for immersive mouse control
Responsive design supporting desktop, tablet, and mobile devices
Modular architecture separating concerns (rendering, physics, networking, UI)
