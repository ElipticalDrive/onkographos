Owner
A full pass over the path tracer. Builds and runs on the RTX 3070 Laptop GPU; clean under the Khronos validation layer.
Rendering
Next-event estimation + BSDF sampling combined with multiple importance sampling
Correct Lambert / normalized Phong / mirror / dielectric BSDFs (exact Fresnel, TIR); removes the old IOR and throughput fudge factors
Fixes the flipped-normal bug (normals resolved in the closest-hit shader, no Y-flip in the loader)
Float32 accumulation, ACES tonemap, sRGB
Denoiser: the CPU 8-bit Haar threshold becomes an edge-avoiding À-Trous wavelet filter on the GPU (~3 ms at 1024²), guided by albedo/normal/depth, with a variance-scaled colour weight and firefly clamp.
Engineering: discrete-GPU selection, device-local geometry, synchronization2 barriers, aligned SBT, CMake-compiled shaders, CLI + --headless PNG mode, GPU timestamps in the title bar.
Repo: removes the course template files and reference images; new README with renders and measured performance.
Portability and repo hygiene: explicit standard includes so the code builds with GCC/Clang (libstdc++) as well as MSVC; MIT LICENSE (vendored libraries and the CC BY 3.0 Cornell box models keep their own licenses, listed in the README); .editorconfig, .clang-format matching the existing style (not applied tree-wide) and .gitattributes; README badges and Linux build packages.

Rendering
- Next-event estimation with multiple importance sampling (power heuristic);
  area-weighted light selection over all emissive triangles
- Correct BSDFs: cosine-weighted Lambert, normalized Phong glossy lobe,
  mirror, smooth dielectric with exact Fresnel and TIR (removes the old
  fudge factors on IOR and throughput)
- Face/shading normals resolved in the closest-hit shader, fixing the
  flipped-normal bug; no more Y-flip in the loader
- Robust ray offsets (Ray Tracing Gems), Russian roulette, NaN guard
- Float32 accumulation, ACES tonemap, sRGB output

Denoiser
- Replaces the CPU 8-bit Haar threshold with an edge-avoiding A-Trous
  wavelet filter on the GPU (5 compute passes, ~3 ms at 1024^2), guided
  by first non-specular albedo/normal/depth, variance-scaled colour weight
  and firefly clamp; lights are kept out of the filter

Engineering
- Picks a discrete GPU with ray-tracing support (was: first device)
- Device-local geometry via staging uploads; synchronization2 barriers;
  proper acquire/present semaphores; aligned single-buffer SBT
- Shaders compiled by CMake (glslc); no checked-in SPIR-V
- CLI: scene path, size, spp, depth, camera, exposure, --headless,
  --compare; GPU timestamp timings in the window title
- Clean under the Khronos validation layer (-DVPT_VALIDATION=ON)
- Removed course template files and reference images; new README with
  renders, measured performance and build instructions
