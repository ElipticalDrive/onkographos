Light Plugins Epic
Parent issue tracking all light source plugin implementations.
Must Have (Required)
Point Light (#implemented)
Ambient Light (#implemented in Core)
Directional Light (Implement DirectionalLight plugin #25)
Should Have
Drop shadows (#implemented in Core)
Could Have (Bonus)
Multiple directional lights (0.5 pts)
Multiple point lights (0.5 pts)
Colored light (0.5 pts)
Phong reflection model (2 pts)
Ambient occlusion (2 pts)
Implementation Notes
All lights must:
Implement ILight interface
Export extern "C" ILight* create(...) function
Be built as .so plugins in plugins/lights/
Have a handler in LightFactory
Note: Some features like Phong and Ambient occlusion may be material-side or core rendering features.
Reference: PDF pages 3-4
