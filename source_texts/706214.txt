# gaussian-splatting-nerf

Fast novel-view synthesis for manufacturing digital twins: 3D Gaussian
Splatting (Kerbl et al 2023) with a vanilla NeRF baseline for honest
comparison. Capture an industrial asset on a phone, run COLMAP, train
either backend, view the result in a browser.

## why this repo

A plant engineer wants a photorealistic 3D of a piece of equipment by
end of day, from a one-minute phone video, viewable on a laptop without
special software. NeRF and its variants are the classical answer;
3D-GS is the 2023 answer that trains 5x faster and renders 200x faster.
This repo does both and reports the gap on our own captures, not
somebody else's benchmark split.

## pipeline

```
phone video
    |
    v
video_to_frames  ---->  images/frame_*.jpg
    |
    v
COLMAP (pycolmap)  ---->  sparse/0/{cameras,images,points3D}.bin
    |                     +
    v                     transforms.json
scene_loader
    |
    +-------> src/gs/splatting_train.py  ---->  runs/gs_<scene>/gs_checkpoint.pt
    |                                                 |
    |                                                 v
    |                                          src/export/to_ply.py       -> .ply
    |                                          src/export/to_splat_web_format.py -> .splat
    |                                                 |
    |                                                 v
    |                                          src/viewer/  (three.js WebGL)
    |
    \-------> src/nerf/nerf_train.py     ---->  runs/nerf_<scene>/nerf_checkpoint.pt

both backends -> src/eval/novel_view_render.py -> PSNR / SSIM / LPIPS on held-out cams
```

## quick start (runs offline, CPU only)

The full reconstruction needs a CUDA GPU + COLMAP (see the next section). To
prove the plumbing without either, there is a small CPU smoke: it fits a
handful of differentiable 2D gaussians to a tiny synthetic image (so the
training loop + photometric loss + PSNR metric run for real on CPU), runs the
PSNR/SSIM/LPIPS eval on a tiny fixture, exports a PLY + packed `.splat`, and
checks the WebGL viewer HTML/JS is present and well-formed. No GPU, no COLMAP,
no network.

```
# torch/numpy are assumed present; scikit-image + plyfile go in a repo-local venv:
python -m venv --system-site-packages .venv
.venv/Scripts/python -m pip install scikit-image plyfile   # or: pip install -r requirements.txt

python scripts/cpu_smoke.py      # the smoke
python -m pytest -q              # 24 unit tests, no CUDA needed
```

**What this is and is not.** The CPU smoke proves the training loop, loss,
PSNR/SSIM eval, PLY/`.splat` export, and viewer plumbing all work. It is NOT
a scene reconstruction: `src/gs/cpu_splat.py` is a small pure-PyTorch 2D
splatter, not the CUDA `diff_gaussian_rasterization` op. The headline
PSNR/SSIM/LPIPS-vs-NeRF numbers below need a CUDA GPU + COLMAP and are not
produced by the smoke. LPIPS is skipped offline because its pretrained weights
download on first use; PSNR + SSIM run fully offline. COLMAP (`pycolmap`),
`tinycudann`, and `diff_gaussian_rasterization` are all guarded so the modules
import without them.

## full pipeline (needs CUDA GPU + COLMAP)

```
git clone https://github.com/sudsho/gaussian-splatting-nerf
cd gaussian-splatting-nerf
pip install -r requirements.txt
# tinycudann needs the CUDA toolkit at build time:
pip install git+https://github.com/NVlabs/tiny-cuda-nn/#subdirectory=bindings/torch
# GS rasterizer (CUDA op, from Inria reference):
git clone --recursive https://github.com/graphdeco-inria/gaussian-splatting /tmp/gs
pip install /tmp/gs/submodules/diff-gaussian-rasterization /tmp/gs/submodules/simple-knn

# preprocess a scene from a phone video
bash scripts/colmap_all.sh cnc_lathe data/raw/cnc_lathe.mp4

# train
bash scripts/train_gs.sh cnc_lathe
bash scripts/train_nerf.sh cnc_lathe

# evaluate on held-out cameras
bash scripts/eval_all.sh cnc_lathe

# view in the browser
python -m src.export.to_splat_web_format \
    --ckpt runs/gs_cnc_lathe/gs_checkpoint.pt \
    --out  out/cnc_lathe.splat
bash scripts/launch_viewer.sh out/cnc_lathe.splat
```

## layout

```
configs/default.yaml         config for both backends
src/data/                    video decode, COLMAP wrap, scene loader
src/gs/                      gaussian model, densification, opacity reset, SH, train, cpu_splat (CPU smoke)
src/nerf/                    positional encoding, hash grid, MLP + volume render
src/eval/                    psnr/ssim/lpips + novel-view render
src/export/                  ply + packed .splat for the web viewer
src/viewer/                  small three.js WebGL viewer for .splat
scripts/                     colmap_all, train_gs, train_nerf, eval_all, launch_viewer, cpu_smoke
tests/                       unit tests that run without CUDA
docs/                        method, colmap_notes, gs_vs_nerf, viewer_notes, digital_twin_use_case
benchmarks/                  results table + ablations
notebooks/                   analyze_scenes, densification_ablation
ci/test.yml.example          copy to .github/workflows/test.yml to enable CI
Dockerfile                   cuda 11.8 + colmap + python + deps
docker-compose.yml           gs-nerf service + nginx viewer
Makefile                     install / lint / test / colmap / gs / nerf / eval / viewer
```
