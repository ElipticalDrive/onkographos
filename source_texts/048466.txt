Hi,
Thank you for your patience. VtkUnityWorkbench uses the VtkToUnity structure and partly provides its API too. However, the plugin focuses on making VTK available through introspection within a Unity XR environment.
The backing idea is to have interaction-guided access to VTK. How to build and use the project is described in the main repository
The plugin is not currently developed in the industry.
I would be interested to hear how you would like to use the plugin, so I could help you more effectively.
