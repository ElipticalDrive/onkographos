Aufgabenpaket 1 – V1.4.1 Flight Depth & Backface Rendering
Stacked on top of PR #16 / v1.4-flight-canonical-batch-2e.
Flight depth
splits both perpendicular flight planes on the physical dart axis
renders four half-fins instead of two whole intersecting transparent draw objects
sorts the four half-fins back-to-front in camera space
preserves edge-on degeneration handling and the fixed tip contract
Plane B / backface
removes the former strongly blurred/darkened front-face copy
derives an explicitly APPROXIMATED reverse surface from the dominant source-material colour
suppresses logos, readable text and asymmetric colour artwork
keeps only very weak low-frequency luminance variation
preserves the authored alpha channel exactly, including translucent material
QA completed
npm run validate: PASS
deterministic static + software pose QA: PASS
Browser/WebGL QA: PASS
all 16 presets: PASS
Tip drift: 0 px
WebGL context-loss/restore: PASS
four-half-fin topology/self-test: PASS
targeted depth matrix: 8 presets × 7 roll angles × 3 incidence angles = 168 renders, PASS
no page or console errors

Manual visual QA / Red Team
Reviewed the generated roll/incidence contact sheets, source-vs-render sheets, Plane-A/Plane-B texture QA and the all-presets pose gallery.
Result:
no remaining whole-plane “blade through flight” artifact observed
no mirrored/readable Plane-B text observed
no grey/brown foreign-surface blocker observed after the final backface revision
edge-on cases remain stable
unknown reverse surfaces remain correctly labelled APPROXIMATED
existing white alpha fringes on some source flights remain a later V1.4.3 concern and are intentionally outside this package
Package result: PASS.
Draft only. Do not merge to main.
