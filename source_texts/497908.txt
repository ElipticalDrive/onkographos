Create a DSL AST for SDFs
Use interval arithmetic instead of direct arithmetic
To raymarch:
a. Partially evaluate/constant fold the SDF
b. If the SDF has simplified to a single value, return that value for all pixels in the range
c. Subdivide the input range
d. Repeat
