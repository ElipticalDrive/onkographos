# CUDA Ray Tracer

A simple ray tracer built with C++ and NVIDIA CUDA. The project demonstrates how a graphics workload can be parallelized on a GPU by assigning one CUDA thread to each pixel.

The program supports both CPU and CUDA GPU rendering, making it possible to compare the execution time of the two approaches.

## Project Overview

The renderer creates a 3D scene containing several spheres and light sources. For every pixel, a ray is generated from the camera and traced through the scene.

The renderer calculates:

- Ray-sphere intersections
- Diffuse lighting
- Specular highlights
- Shadows
- Reflections
- Final pixel colors

The GPU implementation performs these calculations in parallel using CUDA.

## How CUDA Is Used

The main GPU implementation is located in:

    src/renderer.cu

The renderer uses a CUDA kernel called `renderKernel`.

Each CUDA thread is responsible for calculating one pixel.

The kernel uses 16 × 16 thread blocks:

```cpp
dim3 block(16, 16);
```

The pixel coordinates are calculated from the CUDA block and thread indices:

```cpp
int x =
    blockIdx.x * blockDim.x +
    threadIdx.x;

int y =
    blockIdx.y * blockDim.y +
    threadIdx.y;
```

For every pixel, the CUDA thread:

1. Generates a camera ray.
2. Tests the ray against the spheres.
3. Finds the closest intersection.
4. Calculates lighting.
5. Checks for shadows.
6. Calculates reflections.
7. Stores the final color in the framebuffer.

This allows many pixels to be processed simultaneously by the GPU.

## CPU Implementation

The project also contains a CPU renderer.

The CPU implementation uses nested loops over:

- Image height
- Image width
- Samples per pixel

The CPU and GPU renderers use the same basic ray-tracing logic.

This allows the project to compare the execution time of CPU and GPU rendering.
