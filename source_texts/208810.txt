Pull request overview
This PR adds a new reconstruction pipeline implementing “Dual Contouring of Signed Distance Data” (Carrera et al., 2026) to gpytoolbox, including the C++ core algorithm, pybind11 bindings, a Python wrapper API, and a Python test suite to validate correctness and expected behavior.
Changes:
Adds C++ implementation for dual contouring from regularly sampled SDF grids (new dual_contouring_of_signed_distance_data/* module).
Exposes the implementation via a new pybind11 binding (_dcsdd_cpp_impl) and a Python wrapper (dual_contouring_of_signed_distance_data), and exports it from gpytoolbox.
Adds a comprehensive Python test file covering reconstruction accuracy, comparisons to marching cubes, and input validation.
