Summary
restore the numerical ray-tracing nucleus below the corrected PreparedSurface boundary
keep camera-, clipping-, and surface-space rays distinct while sharing SURFER's ray parameter
preserve the F64 polynomial/geometry/root path and F32 material/color path
port the production low-degree/Descartes first-root split, including EPSILON = 1e-7 and no square-free conversion
add sphere clipping, gradient normal handling, front/back materials, SURF-style lighting, ARGB conversion, and the current orthographic yaw/pitch/zoom slice
refactor the C into named function composition while retaining Stussak's RayCreator, ClipToSphere, UnivariatePolynomial, DescartesRootFinder, gradient/normal, material, and shading concepts
keep the current C17 numerical behavior unchanged; no production Java replacement and no ICK-only syntax in this pass
add host tests and sanitizer CI

The bounded C tests cover parameter-preserving sphere clipping, sphere first root, an exact even-multiplicity tangent root, a miss, the linear closed-form path, camera-space hit/normal orientation, a small rendered sphere, and rotation-invariant sphere silhouette.
Scope
This is a working prepared-surface ray tracer, not Java parity and not a production renderer replacement yet. Remaining parity work is documented in native/README.md: exact XYZ→XY→univariate/Kahan order, gradient specialization order, adaptive OG_1x1/QUINCUNX antialiasing, concurrency/cancellation, the versioned primitive-array/JNI handoff, and the frozen Java oracle corpus.
The old pure-Idris tracer is historical reference work; it was never pushed. This PR follows the later architecture: typed Idriç semantic front end → C numerical renderer → thin Android shell.
