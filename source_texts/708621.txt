# GaussianSplatExecutor

**Best-in-class LuaU Gaussian Splat visualization script for Roblox executors (2026).**

Live web search (weao.xyz / arxiv / GitHub) shows no prior complete Gaussian Splatting ports to Roblox executor LuaU. This is the reference implementation.

## Features
- Anisotropic 2D Gaussian kernel approximation via Drawing Circles
- Depth-aware scaling + opacity falloff
- Adaptive density based on camera distance
- Team check / self filter
- High-performance RenderStepped loop with rate limiting
- Full getgenv() config + public API
- Clean destroy / rebuild

## Usage
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/territorialism/GaussianSplatExecutor/main/main.lua"))()
```

## API
```lua
GaussianSplat.Config.MaxSplatsPerTarget = 64
GaussianSplat.SetColor(Color3.fromRGB(255, 100, 100))
GaussianSplat.Toggle(true)
GaussianSplat.Rebuild()
GaussianSplat.Destroy()
```

## Architecture
Single-file executor script. State in getgenv(). Drawing objects pooled per target. No external deps beyond standard UNC Drawing.

Made for Synapse Z / Wave / Delta / any full UNC executor.
