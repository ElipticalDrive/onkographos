The signed-band obstacle SDF was the voxelization hotspot (~15-18s/call at
res 128-256, and re-run every frame for animated obstacles). The cost is the
band-cell -> triangle distance, whose per-512-point-chunk triangle bbox
prefilter barely pruned: np.argwhere returns band cells in raster order, so a
chunk is a narrow column spanning the whole mesh along one axis, and its
elongated bbox overlaps most triangles.
Reorder the band cells along a Morton (Z-order) curve before chunking, so each
chunk is a compact 3-D cluster whose tight bbox selects only nearby triangles.
Distance is order-independent, so the output is bit-identical (verified: max
diff 0.0 vs raster order), and chunk=512 remains optimal (larger chunks widen
the bbox and regress). Measured ~27-29% faster on the distance pass and
~20-26% off the whole SDF voxelization at res 128-256; the residual per-frame
cost is now the O(res^3) parity scan.
Adds a permutation test and an order-invariance test for the reordering, and
updates the stale README note (voxelization has been vectorized since v0.10).
