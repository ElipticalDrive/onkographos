Summary
This pull request writes the 43 pages of the sub-area Random number generation to the bar of the merge sort page.
It covers the basic ideas: pseudorandom number generators, seeds, generator period, equidistribution, jump-ahead, the spectral test, the Marsaglia hyperplane theorem, and statistical tests for randomness.
It covers the linear generators:
the middle-square method
linear congruential generators with the Hull-Dobell theorem, the Park-Miller minimal standard, and RANDU as the classic failure
multiple recursive generators, MRG32k3a and L'Ecuyer's combined generators
lagged Fibonacci, multiply-with-carry and RANLUX
linear feedback shift registers, the Mersenne Twister, WELL, xorshift and xoshiro/xoroshiro
It covers scrambled and counter-based generators: SplitMix64, PCG, Philox and Threefry.
It covers integers and bits: uniform random integer generation, modulo bias, Lemire's bounded integers, and unbiased bits from a biased coin.
It covers low-discrepancy sequences: Halton and Sobol.
It covers cryptographic generation:
entropy sources and true random number generators
cryptographically secure PRNGs, Blum-Blum-Shub and Blum-Micali
Hash_DRBG, HMAC_DRBG and CTR_DRBG
Dual_EC_DRBG with a working demonstration of its backdoor
Each page separates what is proved (period, equidistribution, exactness of a method, security reductions under stated assumptions) from what is only empirical (passing test batteries). Each implementation uses only the Python standard library and masks to the word size. Generators are tested against published reference outputs: MT19937 with seed 5489, the authors' reference code for xoshiro, SplitMix64 and PCG, the Random123 known-answer tests for Philox and Threefry, and the NIST CAVP vectors for the three NIST DRBGs. Periods are checked by brute force for small parameters.
The Dual_EC_DRBG tests use the known-answer data from the OpenSSL FIPS 2.0 source code, since NIST publishes no current vectors. Each page passes the gate.
Some chapter numbers, page ranges, DOIs and adoption claims could not be checked against the source, and the pages mark them for a later check.
