# Medical Volume Renderer

A high-performance WebGPU-based medical volume renderer for visualizing DICOM scan data with real-time ray casting. This project demonstrates advanced GPU programming techniques including bricking acceleration, surface-aware gradient sampling, and an interactive 3D lasso selection tool.

![Medical Volume Renderer](https://img.shields.io/badge/WebGPU-Enabled-blue) ![License](https://img.shields.io/badge/license-GPL%20v3-green)

## ✨ Features

- **Real-time Volume Ray Casting**: GPU-accelerated direct volume rendering using WebGPU
- **Bricking Acceleration**: Empty space skipping with chunk-based min/max acceleration structures (16.9x performance improvement)
- **Surface-Aware Gradient Sampling**: Intelligent lighting calculations only at density boundaries
- **Interactive 3D Lasso Tool**: Draw contours in screen space to mask/select volumetric regions using point-in-polygon ray casting
- **Perona-Malik Smoothing**: Anisotropic GPU-accelerated edge-preserving smoothing during DICOM conversion
- **Window/Level Controls**: Standard medical imaging controls for visualizing different tissue types
- **Blinn-Phong Shading**: Gradient-based lighting with configurable ambient/diffuse/specular components
- **Cutting Cube**: Interactive widget for clipping the volume with visual feedback
- **AWS CloudFront Deployment**: Production-ready deployment with HTTPS support

## 🔧 Prerequisites

- **Node.js** (v18 or later)
- **Python 3.x** with the following packages:
  - `numpy`
  - `pydicom`
  - `cupy` (optional, for GPU-accelerated Perona-Malik smoothing)
  - `cupy-cuda13x` (if using CUDA 13.x)
- **CUDA Toolkit** (optional, for GPU smoothing during conversion)
- **AWS Account** with IAM user credentials (for deployment)
- **Browser** with WebGPU support:
  - Chrome/Edge 113+ (recommended)
  - Access via HTTPS or localhost (WebGPU security requirement)
