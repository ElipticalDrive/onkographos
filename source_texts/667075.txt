Summary
Overlap and volume metrics can now evaluate partially annotated segmentations. Exclusions apply before validating either input and remove voxels from all confusion counts, including TN.
```
mask AND target != ignore_index
  → C++/OpenMP or Triton count pass (checked PyTorch fallback)
  → shared overlap/volume scores
  → per-case and distributed aggregation
```
Adds mask and ignore_index to the seven overlap/volume functions, their stateful wrappers, and collections. Fully excluded cases follow existing zero-denominator settings (NaN by default). Surface/clDice collections reject partial-label options because their boundary/topology semantics are undefined. Existing C entry points remain available. README and Wiki sources mark the API unreleased; no publication workflow is changed.
Evidence
The new contract is checked against independent NumPy voxel selection, including ignored sentinel values, noncontiguous arrays, empty inputs, mixed numeric representations, invalid included values and distributed aggregation.
Before: installed 0.0.1a4 raises TypeError: dice() got an unexpected keyword argument 'ignore_index' for a target containing -1.
After: the same example excludes that target voxel, tolerates its invalid prediction, and returns [[0.0, 0.5]].
Full CPU/CUDA suite: 3,106 passed, 41 skipped. Mypy: 33 source files passed.
PR CI: installed sdist on Python 3.10 / PyTorch 2.4.1 / NumPy 1.x, 1,380 passed, 644 skipped, plus all 33 source files type-checked.
Push CI also passed on attempt 2 with the same counts. Attempt 1 timed out in the existing test_ddp_gathers_all_ranks after all new masking tests passed. The unchanged-commit retry succeeded; the initial hang's cause is unconfirmed, and no timeout was relaxed.
Synthetic 2 × 128³, four classes, 80% inclusion, two CPU threads, 5 warmups/30 samples: masked index collection 3.910 ms C++ vs 54.532 ms checked PyTorch; 0.729 ms Triton vs 1.489 ms checked PyTorch. CUDA peak additional allocation: 8,704 vs 117,442,048 bytes. Includes validation and synchronization; inputs are contiguous.
Unmasked medians against installed 0.0.1a4: CPU index 2.355 → 2.316 ms, CPU one-hot 7.221 → 7.234 ms; CUDA index 0.703 → 0.703 ms, one-hot 0.715 → 0.715 ms. No material regression observed on this workload.
Reproduce: OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 TORCHINDUCTOR_COMPILE_THREADS=1 CI='' python -m pytest -q; python -m mypy src/exacta scripts/check_release.py; python benchmarks/bench_masked_metrics.py --device cuda --size 128 (also --device cpu).
Merge Danger
Door: Two-way. Revert the feature commit to remove these additive APIs; no stored-data migration or release publication is involved.
Blast Radius: Metrics. Shared counting kernels affect overlap/volume evaluation on CPU and CUDA. Surface and topology masking is explicitly rejected. Multi-GPU NCCL remains unverified; distributed masking coverage here uses CPU/Gloo.
