Branch: frontier-voxel-engine · Tracking: #24 · Architecture: https://github.com/DrewPhi/MicroVoxelProceduralGeneration/blob/frontier-voxel-engine/frontier/ARCHITECTURE.md
Task and acceptance
Phase: World generation | Dependencies: FV03/FV04 | Gate: G1.
Implement deterministic kilometer-scale provinces, ridgelines/basins/plateaus, domain-warped ridged fBm with meaningful octave frequencies, altitude/rock/slope conditioned detail, and controllable seeds. Start with the dramatic look of the analytic branch, not a blind port of the legacy visuals. The canonical field must remain stable at every display resolution. Produce documented seed gallery with deep valleys, ridges, flat plains and steep mountains; expose visual parameters without requiring train/fitting.
Acceptance: beautiful large-scale forms in no-haze far views, continuous region boundaries, bounded sampling cost, and terrain source queried at arbitrary integer voxel locations. Include deterministic parity tests.
Legacy reference policy
R — inspect DrewsAnalyticRendering/src/terrain.rs for FBM aesthetic and main/successor/world/src/generation/landforms.rs, noise.rs for data/seed conventions. Do not transplant the old coarse terrain machinery or analytic quadratic fitting. Reference https://github.com/Auburn/FastNoise2 (MIT; verify deps if importing).
Guardrail: work only in frontier/ until a separately approved promotion; reproduce baseline tests without copying its architectural failure modes.
Agreed refinement: laptop performance and voxel-faithful quality
Sequence clarification: production geography follows the early #47/#55 ownership smoke gate. Supply simple deterministic source fixtures for #33–#39 first; this issue's full visual/geological scope must not block renderer feasibility tests.
Current implementation priority
User steering: bring a lightweight seeded procedural FBM source into the next renderer checkpoint now, alongside the native reference fixture. Do not wait for full geology, tectonics, drainage or erosion. Use the same CPU canonical source for sampled render pages and native voxel queries. Keep fixed source seeds/parameters and benchmark real terrain variation early. This does not waive the later voxel-faithful handoff, cave/edit ownership, moving clipmap, or measured G1/G3 gates. A bounded surface-only prototype must explicitly disclose unsupported edits/volumes and fixed coverage; no issue is complete merely because an FBM screenshot renders.
Implementation checkpoint — 9550ed1
Implemented early lightweight CPU-canonical FBM source now: validated seed/scale/amplitude/octaves/roughness, continuous domain warp and mixed ridges, column-centered native quantization, authoritative World::fbm and cached native column queries. Seed7/42 captures inspected and source/native parity tested. This is not production geology/provinces/erosion and does not complete the full issue.
Measurements, captures inventory and remaining work.
