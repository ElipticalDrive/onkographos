Large GDML scenes can block the viewer while meshes and actors are built. This change opens a responsive loading window, prepares meshes in a cancellable worker, displays a coarse preview, and then refines to full detail while preserving camera and visibility controls. Repeated opens reuse validated meshes.
The implementation adds:
Content-based numeric mesh caching with dependency/resolution invalidation and corrupt-cache recovery.
Shared meshes and GPU instances, deferred volume loading, and bounded UI updates for large scenes.
Optional annotated CCM PMT exterior display, with full geometry retained for clipping and sections.
Worker package-import and native window-close fixes, including cancellation, late-result handling, and reopening in the same Python process.
Usage documentation and regressions for transforms, picking, cache behavior, worker lifecycle, and native rendering.

Invalid local hit fraction ordering across transforms
python/​_visualization_render.py:335
IntersectWithLine returns t along each instance's transformed local segment. Comparing those fractions across instances is not a valid ordering for the non-uniformly scaled/sheared placements supported above, so a farther world-space hit can win picking. Transform the hit back to world coordinates and compare its parameter (or distance) along the original world ray.
Worker cache warnings not propagated to caller
python/​_visualization_scene.py:404
In the default progressive path this warning is emitted inside the worker process, whose stderr is redirected to worker.log by MeshJob; successful worker logs are never surfaced to the caller. Thus GDML containing DOCTYPE/entity declarations is silently rendered without caching, contrary to the documented behavior that this condition produces a warning. Propagate warning events (and the other cache warnings) back through the UI process before calling warnings.warn.
Stale partial cache files survive warm loads
python/​_visualization_scene.py:480
This sweep only runs for directories represented in pending_cache. On a warm load where every requested mesh is already a cache hit, pending_cache is empty, so stale .partial-* files left by a killed worker are never removed. Sweep the current cache-key directory whenever persistent caching is enabled, not only when new entries are pending.
