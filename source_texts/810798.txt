#### Abstract

Voxel-based volumetric mapping is fundamental to 3D reconstruction, yet fixedresolution grids remain inherently inefficient – wasting memory in uniform regions and losing detail in complex ones. Existing adaptive methods, such as MAP-ADAPT, partially address this by varying resolution based on geometry and user-defined semantic class lists, but these heuristics require expert tuning, lack generalization to unseen objects, and provide no explicit mechanism to control memory usage. We propose an adaptive framework that refines voxels based on semantic entropy, which captures label uncertainty, together with geometric curvature and texture richness as scene complexity cues, yielding principled resolution allocation without reliance on semantic taxonomies. To make the accuracy-memory trade-off explicit and user-controlled, we further introduce a reinforcement learning agent that learns voxel subdivision policies under a user-specified target memory budget, replacing hand-tuned thresholds with a single intuitive control parameter. The resulting multi-resolution TSDF achieves higher geometric accuracy, better semantic consistency, and improved memory-accuracy trade-offs compared to MAP-ADAPT and fixed-resolution baselines on both synthetic and real-world datasets. ### 1 Introduction

Autonomous systems rely on 3D maps that capture geometry, color, and semantics to perceive, navigate, and interact with their environment. Volumetric representations based on Truncated Signed Distance Fields (TSDFs) [17, 18, 19] have become the standard for dense reconstruction, offering accurate geometry and consistent integration over time. However, conventional TSDF pipelines employ a fixed voxel resolution, which leads to redundant storage in large homogeneous regions (e.g., walls or floors) and loss of detail in complex areas.

Semantic entropy highlights object boundaries where multiple labels compete; geometric complexity responds to corners and curved surfaces (e.g., sofa armrests); and texture complexity activates on visually detailed regions such as carpets. These complexity cues drive selective voxel refinement, while a reinforcement learning agent uses a user-specified target memory budget to balance reconstruction fidelity and storage cost. Recent work has therefore shifted toward adaptive mapping, where voxel resolution is adjusted according to scene complexity. MAP-ADAPT [31] represents an important step in this direction, combining geometric cues and manually defined semantic classes to control voxel subdivision. By allocating higher resolution to semantically meaningful regions, it achieves compact multi-resolution 3D voxel maps while maintaining fidelity. However, its refinement policy remains tied to user-specified semantic classes and fixed geometric rules, requiring dataset- or task-specific design choices and providing no class-agnostic measure of semantic ambiguity or texture complexity. Moreover, these deterministic rules provide no principled mechanism to manage the trade-off between reconstruction quality and limited storage capacity.

We address these limitations by reformulating adaptive mapping as a data-driven refinement problem guided by semantic uncertainty and geometric/texture complexity. Each voxel maintains a semantic class distribution whose entropy quantifies label uncertainty, complemented by geometric curvature and texture richness scores that capture local scene complexity. Subdivision is triggered when semantic uncertainty is high or when scene complexity indicates that coarse resolution cannot faithfully represent the local geometry or appearance, ensuring that memory is devoted to informative regions rather than predefined object categories. This data-driven refinement produces adaptive maps that respond dynamically to scene complexity, semantic ambiguity, and visual richness.

While these signals provide a principled refinement criterion, the deterministic variant

relies on threshold selection and provides no direct mechanism to target a desired memory operating point. To overcome this, we introduce a reinforcement learning agent that learns to control subdivision under a user-defined target storage budget. The agent observes local and global voxel statistics and learns subdivision policies that maximize reconstruction accuracy while penalizing budget overuse (see Figure 1\). The target budget corresponds directly to a physical memory amount (e.g., in megabytes), providing an intuitive interface for resourceaware mapping.

Our main contributions are as follows:

- Unified adaptive mapping framework: We integrate geometric, semantic, and texture complexity signals into a multi-resolution TSDF representation that generalizes beyond class-based heuristics and scales with available memory.
- Uncertainty- and complexity-driven adaptivity: We trigger voxel refinement using semantic entropy as a measure of label uncertainty, complemented by geometric curvature and texture richness as scene complexity signals, providing a unified and data-driven subdivision criterion.
- Reinforcement-learned subdivision policy: We train an RL agent using Proximal Policy Optimization (PPO) [24] to decide when and where to subdivide, learning budget-aware policies that trade map fidelity against storage cost.

# 2 Related Work

Volumetric Mapping. Volumetric 3D reconstruction based on Truncated Signed Distance Fields (TSDFs) is widely used for dense scene mapping [17, 18, 19]. These methods integrate RGB-D observations into voxel grids, providing continuous surface representations and free-space reasoning. To mitigate the memory footprint of dense grids, hierarchical data structures such as voxel hashing [8, 18] and octrees [6, 27] have been proposed to allocate voxels only near surfaces. While these systems achieve real-time performance and scalable mapping, they typically rely on a fixed voxel resolution, which limits their ability to represent both fine local details and large-scale environments efficiently. Neural implicit methods such as NeRF [15] and 3D Gaussian Splatting [9] target image rendering rather than explicit volumetric mapping, and do not produce TSDF grids, semantic labels, or free-space representations required for planning and navigation.

Semantic Mapping. Integrating semantic understanding into 3D mapping has been central to advancing scene perception. Early works like SemanticFusion [12] fused per-frame semantic predictions into surfel-based reconstructions, while Kimera [22] combined realtime metric reconstruction with semantic fusion into a unified volumetric mesh. Instanceand panoptic-level methods [5, 13, 16, 28] further extended these ideas by maintaining perobject volumes or combining instance labels. However, these pipelines generally operate at uniform spatial resolution, distributing computational and memory resources equally across all regions, independent of their semantic or geometric complexity.

Adaptive Mapping. To improve efficiency, adaptive techniques dynamically adjust voxel resolution based on scene content or task relevance. Geometry-based adaptivity refines regions of high curvature, surface density, or structural complexity [25, 26, 27, 33]. These approaches improve geometric fidelity near surfaces but lack semantic or visual awareness. Semantic-based adaptivity extends this idea by incorporating object information to guide

MAP-ADAPT demonstrates real-time adaptive reconstruction by refining user-specified semantic classes, but its reliance on manually defined rules limits generalization to unseen categories and neglects uncertainty in semantic or textural predictions that could indicate ambiguous or informative regions.

Uncertainty and Learning-Based Adaptivity. Several works have incorporated uncertainty into mapping, active exploration, and reconstruction. SemanticFusion [12] and Kimera [22] maintain probabilistic class distributions per voxel, though uncertainty is not used to influence map structure. Information-theoretic formulations [1, 2] employ entropy and mutual information to guide exploration; notably, semantic entropy within a Bayesian Octree has been used to drive active exploration via mutual information maximization [1]. Reinforcement learning has similarly been applied to active exploration and mapping [3, 21, 32], demonstrating that learned policies can balance performance and efficiency. However, these exploration-focused methods determine where to move next rather than how to allocate reconstruction resolution along a fixed trajectory. In contrast, we formulate voxel subdivision as an uncertainty-driven refinement problem and leverage reinforcement learning to learn adaptive, budget-aware subdivision policies that directly regulate the trade-off between reconstruction fidelity and storage capacity.

We propose an adaptive 3D semantic mapping framework that refines voxel resolution by explicitly targeting high-uncertainty regions. We build upon MAP-ADAPT [31], which operates on an adaptively subdivided voxel grid and controls subdivision via manually defined semantic classes and geometric complexity. In contrast, we (i) reformulate voxel subdivision as an uncertainty-driven refinement problem, using semantic, geometric, and textural complexity as proxies to trigger adaptive resolution allocation, and (ii) learn a budget-aware, soft-constrained subdivision policy with reinforcement learning (RL) that replaces handtuned thresholds with a single intuitive parameter: the target storage budget.

Preliminaries. We consider a sequence of RGB-D frames {(Ik ,Dk)} K k=1 with camera poses {Ck} and per-frame semantic predictions {Pk}, where Ik and Dk are the input image and depth in the k-th frame. The goal is to reconstruct an adaptive-resolution TSDF map M that allocates fine resolution only where it meaningfully reduces uncertainty. We adopt a hierarchical voxel hashing structure in the spirit of MAP-ADAPT [31], with three resolution levels (coarse: 8 cm, medium: 4 cm, fine: 1 cm voxels). Each voxel vi stores vi = {di ,Si ,gi ,ti}, where di ∈ R is the TSDF value, Si ∈ R C denotes the semantic log-scores over C classes, gi ∈ R a geometric complexity scalar, and ti ∈ R a texture complexity scalar. Semantic entropy H sem i is derived on-the-fly from the normalized semantic distribution P*ˆsem *i obtained from Si , while the combined uncertainty proxy hi used by the RL agent is computed from all three modalities as defined in Section 3.3. #### 3.1 Uncertainty-Driven Adaptive Mapping

We propose our uncertainty-aware adaptive mapping pipeline Un-Map-Adapt.

Voxel uncertainty and complexity measures. Each voxel vi maintains a semantic class distribution; geometric and texture complexity are fused as scalar attributes computed in the observation domain. Semantic entropy captures label uncertainty across observations, motivating refinement at class boundaries; geometric curvature identifies edges and corners where coarse voxels lose structural detail; and texture richness flags visually dense regions where low resolution causes blurring.

Semantic entropy. In each voxel, we fuse per-frame class probabilities into semantic logscores Si using a Bayesian update similar to SemanticFusion [12] and Kimera [22]. After fusion, the normalized class probabilities are as follows:

$$\hat{\rho}_i^{\text{sem}}(c) = \frac{\exp(S_i(c))}{\sum_{c'=1}^C \exp(S_i(c'))}, \quad c = 1, \dots, C. \quad (1)$$

The semantic entropy is then as follows:

$$H_i^{\text{sem}} = - \sum_{c=1}^C \hat{p}_i^{\text{sem}}(c) \log \hat{p}_i^{\text{sem}}(c). \quad (2)$$

We use entropy as a class-agnostic measure of predictive ambiguity: it increases when probability mass is distributed across competing labels and does not depend on which semantic class is most likely, thereby highlighting regions that may benefit from finer resolution. Geometric complexity. We estimate geometric complexity using the change-of-curvature (CoC) descriptor [20], similar to [31]. For each depth frame, pixels are back-projected to 3D at stride 2 for efficiency, producing a subsampled point cloud. For each 3D point p, we find all neighbors within radius r=0.1 m using a KD-tree and compute the local covariance matrix as

$$\mathbf{C}(p) = \frac{1}{n} \sum_{i=1}^n (p_i - \bar{p})(p_i - \bar{p})^\top, \quad (3)$$

where ¯p is the local centroid and n is the number of neighbors. Let λ1 ≥ λ2 ≥ λ3 ≥ 0 be the eigenvalues of C(p); the CoC is defined as: CoC(p) = λ3/(λ1 + λ2 + λ3) ∈ [0,0.33], where CoC≈0 indicates a locally planar surface and CoC≈0.33 indicates an isotropic, maximally complex neighborhood. The per-point CoC values are stored at their original pixel coordinates (u,v), producing a per-frame 2D complexity map. These per-observation values are then fused into each voxel vi as a single scalar gi via confidence-weighted accumulation (weight wj = 1/z 2 j , where zj is the observation depth, downweighting distant measurements) as:

$$g_i \leftarrow \frac{w_i g_i + w_j \text{CoC}(p_j)}{w_i + w_j}. \quad (4)$$

High gi indicates geometrically complex or curved regions, such as edges and corners, that benefit from finer voxel resolution.

Texture complexity. We compute a per-pixel texture complexity map for each RGB frame using local gradient entropy. We apply 3×3 Sobel filters to obtain horizontal and vertical gradients Gx, Gy, and compute per-pixel gradient magnitudes m(u,v) = p Gx(u,v) 2 +Gy(u,v) 2 . For each pixel (u, v), we extract a 5×5 neighborhood (with reflect padding at borders), yielding 25 gradient magnitude samples. These are binned into a 20-bin histogram spanning the local [m*min,*m*max] range of the window, normalized to a probability distribution {*pj} 20 j=1 , and Shannon entropy is computed as:

$$H^{\text{tex}}(u, v) = - \sum_{j=1}^{20} p_j \log(p_j + \varepsilon), \quad \varepsilon = 10^{-6}. \quad (5)$$

Intuitively, flat textureless regions concentrate gradients in a single bin (low entropy), while richly textured regions spread mass across bins (high entropy). The resulting entropy map is z-normalized per image over valid pixels as:

$$t(u, v) = \frac{H^{\text{tex}}(u, v) - \mu_H}{\sigma_H}, \quad (6)$$

where µ*H* and σ*H* are the mean and standard deviation computed over all valid pixels in the frame, making complexity values comparable across images with different overall texture levels. Positive per-pixel values are then projected into 3D and fused into each voxel vi as a single scalar ti via confidence-weighted accumulation (weight wj = 1/z 2 j ) as ti ← (wi ti + wj t(uj ,v j))/(wi +wj). High ti indicates visually rich regions like boundaries and textured surfaces that are prioritized for subdivision even when geometric complexity is low.

Deterministic complexity-threshold subdivision. MAP-ADAPT subdivides voxels according to manually specified semantic classes and geometric complexity thresholds. We replace these class-based rules with per-modality complexity thresholds. For a voxel at level ℓ ∈ {coarse,medium}, subdivision is triggered if any of the following holds: H sem i > τ sem ℓ , gi > τ geo ℓ , ti > τ tex ℓ . If subdivision is triggered, the parent vi is replaced by n*ℓ of its children {*v (k) i } n*ℓ *k=1 , whose initial TSDF and semantic fields are interpolated from the parent and neighboring voxels. This can be interpreted as refining voxels in which at least one modality exhibits high complexity. The semantic threshold is shared across both levels, while the geometry and texture thresholds are level-specific for the coarse-to-medium and medium-to-fine transitions. Defaults are τ sem=0.10, τ geo lo =0.05, τ geo hi =0.10, τ tex lo =1.0, τ tex hi =2.0, calibrated by inspecting complexity distributions on a held-out training scene. This deterministic variant removes dependence on predefined class lists from [31], but it still requires hand-tuning thresholds and is not budget-aware. Table 9 analyzes sensitivity to these thresholds, showing that their selection jointly determines the accuracy–memory operating point.

#### 3.2 TSDF Integration and Field Updates

For each frame k, we lift pixels (u, v) with depth z into 3D points p = π −1 (u,v,z) and cast rays from the camera center to p into the voxel grid. Voxels whose centers fall within a truncation band [z− µ,z+ µ] are updated. Each observation j contributes with weight wj = 1/z 2 j (downweighting distant measurements). For a voxel vi , the TSDF value di and its weight wi are updated as

$$d_i \leftarrow \frac{w_i d_i + w_j d_j}{w_i + w_j}, \quad w_i \leftarrow w_i + w_j. \quad (7)$$

Semantic fusion (logit accumulation). Instead of directly accumulating probabilities, each voxel maintains a vector of log-scores (logits) Si ∈ R C. Given a per-frame class probability vector Pj ∈ [0,1] C at the projected point (with ∑c Pj(c) = 1), we form an updated logit proposal as

$$S_i^{\text{rpop}}(c) = S_i(c) + w_j \log(P_j(c) + \varepsilon), \quad (8)$$

where wj is the observation weight and ε is a small constant to avoid log0. We apply an exponential moving average:

$$S_i(c) \leftarrow (1-\lambda)S_i(c) + \lambda S_i^{\text{prop}}(c), \quad (9)$$

with fusion rate λ ∈ (0,1]. Setting λ = 1 recovers simple additive accumulation Si ← Si + wj log*Pj* . To obtain a normalized class distribution for entropy or rendering, we compute the stable softmax as:

$$\hat{P}_i^{\text{sem}}(c) = \frac{\exp(S_i(c) - m_i)}{\sum_{c'} \exp(S_i(c') - m_i)}, \quad m_i = \max_c S_i(c). \quad (10)$$

Finally, semantic entropy is obtained by:

$$H_i^{\text{sem}} = - \sum_{c=1}^C \hat{p}_i^{\text{sem}}(c) \log \hat{p}_i^{\text{sem}}(c). \quad (11)$$

#### 3.3 Budget-Aware RL Subdivision Policy (UnRL)

Although the uncertainty formulation above is principled, it still requires manual threshold selection and provides no direct mechanism to target a desired global storage budget. Thus, we cast adaptive subdivision as a sequential decision problem and train an RL agent to choose complexity thresholds per region while penalizing budget overuse.

Spatial blocking and uncertainty proxy. For each frame, we cluster voxels into spatial blocks of fixed size (e.g., 0.5m) using a grid index. Let B = {1,...,B} be the set of blocks and V*b* the voxels assigned to block b. For each voxel vi ∈ V*b*, we compute a normalized uncertainty proxy as hi = w˜sem*H*˜ sem i + w˜ geo*g*˜i + w˜tex*t*˜i , where H˜ sem i = H sem i /log*C*, with C the number of semantic classes, ˜gi = min(gi , 0.333)/0.333, and t˜i = min(ti , 3.0)/3.0 denote the per-voxel semantic entropy, geometric complexity, and texture complexity normalized to [0,1], and ˜w*sem = *w˜ geo = w˜tex = 0.33 are fixed equal weights used across all datasets.

$$\mu_b = \frac{1}{|v_b|} \sum_{i \in v_b} h_i, \quad \sigma_b = \sqrt{\frac{1}{|v_b|} \sum_{i \in v_b} (h_i - \mu_b)^2}. \quad (12)$$

We then importance-sample N blocks with probabilities proportional to µ*b*, focusing the agent on informative regions over large uniform areas. Tables 6 and 7 analyze the spatial block size and number of sampled blocks, respectively, showing stable performance around the default configuration.

Observation space. The agent observes the statistics of N sampled blocks and global summary variables. The observation state is as follows:

| $\mathbf{s} = [\mu_1, \sigma_1, \dots, \mu_N, \sigma_N, \bar{h}, \sigma(h), \rho_{\text{used}}, \rho_{\text{budget}}]$ | (13) |
|------------------------------------------------------------------------------------------------------------------------|------|
|------------------------------------------------------------------------------------------------------------------------|------|

where h¯ and σ(h) are the mean and standard deviation of hi over all voxels in the frame, ρused ∈ [0,1] is the fraction of the voxel budget currently consumed, and ρbudget is the fixed target budget ratio for the current agent.

Action space and subdivision rule. For each sampled block b, the agent predicts a pair of complexity thresholds (τ0,b, τ1,b) from a discrete set T = {0.0,0.025,0.05,0.1,0.25,0.5}. The environment encodes this as a MultiDiscrete action over 2*N* indices into T . For voxels in block b, the predicted thresholds induce a three-level decision:

$$\text{level}(v_i) = \begin{cases} \text{coarse,} & h_i \leq \tau_{0,b}, \\ \text{medium,} & \tau_{0,b} < h_i \leq \tau_{1,b}, \\ \text{fine,} & h_i > \tau_{1,b}. \end{cases} \quad (14)$$

Each subdivision decision updates a voxel budget counter, with coarse, medium, and fine levels incurring different costs; the medium level contributes a fraction αmid ∈ (0,1) of the fine-level budget cost, serving as a cost-effective intermediate.

Supervision losses and reward. To provide a training signal, we precompute high-resolution reference reconstructions at 1cm voxel size using Voxblox [19]. Each coarse (8 cm) parent voxel maintains up to 83 child slots at the finest (1 cm) resolution, populated from this reference; only children with nonzero observation weight contribute to the loss computation. For each lower-resolution voxel, we derive per-voxel losses by comparing its semantic label, RGB color, and TSDF value to these aggregated child voxels.

Concretely, Lsem is the fraction of child voxels whose semantic label differs from the parent (indicator-based, range [0,1]); Ltex is the mean L2 RGB distance between parent and children normalized by √ 3 (range [0,1]); and Lgeo is the mean L1 TSDF difference normalized by the truncation distance 2µ (range [0,1]). We denote these normalized losses by Lsem,Ltex,Lgeo ∈ [0,1]. They are combined into a single reconstruction loss as follows:

$$\mathcal{L} = w_{\text{sem}} \mathcal{L}_{\text{sem}} + w_{\text{tex}} \mathcal{L}_{\text{tex}} + w_{\text{geo}} \mathcal{L}_{\text{geo}}, \quad (15)$$

with equal weights w*sem = *w*tex = *w*geo = 0.33, fixed across all datasets and shared with the proxy weights used in *hi . Table 8 evaluates sensitivity to the reward-weight configuration and shows that balanced settings yield similar performance. For voxel vi , we denote the resulting combined loss by L*i* .

At each step, we compute a per-voxel reward that encourages subdivision where it reduces reconstruction loss while penalizing unnecessary refinement. For a voxel assigned to

$$r_i^{(\ell)} = \begin{cases} -\mathcal{L}_i, & \ell = \text{coarse}, \\ \alpha_{\text{mid}}(\mathcal{L}_i - \lambda_{\text{sub}}), & \ell = \text{medium}, \\ \mathcal{L}_i - \lambda_{\text{sub}}, & \ell = \text{fine}, \end{cases} \quad (16)$$

where λsub > 0 is a subdivision penalty and αmid ∈ (0,1) downweights the effect of medium resolution relative to fine. Intuitively, subdividing is only beneficial when the expected improvement in reconstruction outweighs the subdivision cost. The step reward is obtained by averaging over all updated voxels and computing a temporal difference relative to the previous step to stabilize learning.

Budget penalty. Let N*large be the number of 8cm voxels required to fill the bounding box of the scene, computed once at episode initialization from the known scene extent. We define a per-scene budget as *N*budget = ρbudget*N*large, where ρbudget ∈ (0,1] is the fixed budget ratio for the current agent. Given the fixed storage footprint *sv (in bytes) per voxel, this corresponds to a target memory M*target = *N*budget*sv, i.e., a target storage budget in MB or GB. Let N*sub denote the current effective number of subdivided voxels (medium and fine levels, accounting for their relative cost). We compute the used fraction as ρused = min *N*sub/*N*budget, 1.0 . A penalty is applied when ρused exceeds an offset ρ0 (*e.g., 0.7 of the allocated memory) as:

$$r_{\text{budget}} = \begin{cases} 0, & \rho_{\text{used}} \leq \rho_0; \\ \beta_{\text{budget}} (\rho_{\text{used}} - \rho_0), & \rho_{\text{used}} > \rho_0, \end{cases} \quad (17)$$

where βbudget < 0 controls the severity of overuse. The total reward becomes rt = rt + r*budget, with *rt denoting the mean voxel-level reward. This formulation applies a budgetaware soft constraint: rather than a formal hard constraint with satisfaction guarantees, the penalty makes sustained budget violations suboptimal during training, empirically yielding tight budget adherence at inference.

Training. We train the policy using PPO [24], following a reinforcement-learning formulation in which each episode corresponds to a complete scene and the agent sequentially selects thresholds for blocks across frames. We train separate agents for different fixed budget ratios ρbudget, each targeting a different memory regime.

Inspired by RL-VO [14], which uses cross-attention for variable-length RL observations, we adopt a PerceiverIO architecture [7] for the variable number of sampled blocks N. Each block's (µ*b*,σ*b*) pair is a key–value input; four learned latent queries compress all block features into a fixed 256-dim representation processed by an MLP to produce the action distribution over 2*N* threshold indices. The value network additionally receives the global critic features (h¯, σ(h), ρused, ρbudget), focusing the critic on budget context.

We train our reinforcement-learning agent on 50 scenes randomly sampled from the ScanNet training split [4], disjoint from all evaluation scenes. Each scene provides a sequence of RGB-D frames with corresponding camera poses and precomputed 1 cm Voxblox reference reconstructions used for reward computation. Training is performed for a total of 10 million environment steps. Each policy is trained separately for approximately 24 hours on a single consumer-grade RTX 3080 (10 GB), using the precomputed 1 cm reference reconstructions for reward supervision. At inference, these references are no longer required: the user simply selects a desired storage-budget regime, and the corresponding policy predicts subdivision thresholds directly from the observed block uncertainty statistics {µ*b*,σ*b*}. Additional training details, including hardware and total training cost, are provided in Appendix C.

# 4 Experiments

We evaluate geometric reconstruction, semantic accuracy, texture fidelity, and efficiency on both synthetic and real-world benchmarks, comparing fixed-resolution baselines, MAP-ADAPT, and our uncertainty- and RL-driven variants.

Datasets. Following MAP-ADAPT [31], we evaluate on 81 scenes (all disjoint from the 50 ScanNet scenes used for RL training): (i) HSSD [10] provides photorealistic synthetic indoor scenes with noise-free ground-truth geometry, semantics, and textures. (ii) ScanNet [4] contains real-world RGB-D scans with measurement noise, missing depth, and partial semantic annotations, testing robustness under realistic conditions.

Metrics. All metrics are computed on meshes extracted from the adaptive TSDF grids. (i) Geometry: mean completion error and completion ratio within 5 cm. (ii) Semantics: vertex labels from the fused voxel distribution are rendered into held-out test views via raycasting and compared to ground-truth semantic projections, penalizing both label errors and geometric misalignment. (iii) Texture: MS-SSIM and LPIPS [30] on raycasted color renderings. (iv) Efficiency: total voxel count, peak memory, and per-frame integration time. All adaptive methods share the same TSDF integration and meshing pipelines [31].

#### Baselines and Ablations.

- Voxblox (8 cm, 4 cm, 1 cm) [19]: Fixed-resolution baselines at each of the three levels that the adaptive methods select among during subdivision. The 1 cm grid provides a quality upper bound at prohibitive memory cost.
- MAP-ADAPT [31]: Uses geometric CoC [20] and a manually selected semantic class list, limiting generalization. We use the official HSSD configuration; for ScanNet, we adopt the same list with unknown classes assigned to coarse resolution.
- MAP-ADAPT-SPLIT-AVG [31]: MAP-ADAPT averaged over 5 runs with randomly sampled semantic class lists, where each list specifies which class labels trigger fineresolution subdivision. This evaluates sensitivity to class list selection when no datasetspecific configuration is available.
- UN-MAP-ADAPT (OURS): Our method using semantic entropy, geometric complexity, and texture complexity as subdivision signals, without user-defined class lists.
- UNRL (OURS): Budget-aware RL refinement trained at 25% and 75% target voxelbudget regimes, providing budget-aware refinement at inference.

We omit Multi-TSDF [23], which has been shown to underperform MAP-ADAPT. We further evaluate robustness to the semantic segmentation backbone by replacing RefineNet with SegFormer; Table 5 shows consistent accuracy–memory behavior with the alternative backbone.

Results on ScanNet. Table 1 shows that our uncertainty-driven refinement outperforms MAP-ADAPT on almost all metrics. UN-MAP-ADAPT (OURS) achieves lower completion error and higher Compl. <5cm than MAP-ADAPT, and also improves semantic accuracy and photometric quality. These improvements primarily arise from automatically identifying informative or uncertain regions for refinement, rather than relying on a preselected class list. Importantly, this enables generalization to scenes containing object categories not explicitly known during system design. Because our method additionally refines texture-rich regions, which are ignored entirely by MAP-ADAPT, the unconstrained variant naturally allocates more voxels, as expected. This additional cost directly motivates the budget-aware RL variant, which recovers the efficiency advantage while preserving the broader refinement criteria.

The RL-based variant learns predictable trade-offs between memory and accuracy. At 75% of the voxel budget, the reconstruction quality is close to our deterministic model, while memory is reduced by more than half. These results confirm that the agent learns to allocate resources where they most reduce reconstruction loss. At extreme budgets (25%), the policy prioritizes high uncertainty and complexity regions, maintaining key structural and semantic details, and gracefully reducing resolution elsewhere.

Although the RL agent and all hyperparameters were trained on ScanNet, our uncertainty-driven model again surpasses MAP-ADAPT across geometric and texture metrics. This demonstrates a key strength of our formulation: since voxel refinement is triggered by modality-specific uncertainty and complexity signals rather than predefined semantic categories, the method naturally generalizes to scenes containing previously unseen objects, materials, and textures.

### 5 Conclusion

This work tackles the absence of explicit, user-controllable accuracy–memory trade-offs in current volumetric mapping pipelines. MAP-ADAPT offers limited control through manual class lists and class-dependent subdivision levels, but this requires expert tuning, fails to generalize, and becomes impractical in scenes with many small or unseen objects. Our method provides a principled and fully automatic alternative: uncertainty- and complexity-driven refinement removes dependence on semantic taxonomies, while a reinforcement-learning policy enables direct specification of a desired memory budget, with the system allocating resolution accordingly. Experiments on real and synthetic datasets show that our approach matches or surpasses MAP-ADAPT in geometric, semantic, and texture accuracy, while delivering predictable and stable performance under varying storage constraints. By making the target memory budget the primary user-facing parameter, our framework provides a flexible and scalable approach to adaptive 3D mapping. Our evaluation is currently limited to the indoor RGB-D setting of ScanNet and HSSD. Nevertheless, the semantic, geometric, and texture cues exploited by our approach are not intrinsically tied to indoor scene categories. Extending and adapting the method to outdoor and larger-scale mapping scenarios is an important direction for future work.

### B.2 UN-MAP-ADAPT Parameter Sensitivity

UN-MAP-ADAPT uses five hand-tuned thresholds that control when a voxel is subdivided based on its semantic entropy (τ sem), texture complexity (τ tex lo , τ tex hi ), and geometric complexity (τ geo lo , τ geo hi ). Unlike UnRL, which learns a subdivision strategy end-to-end, UN-MAP-ADAPT requires these thresholds to be specified manually and jointly determines the accuracy–memory operating point.

Table 9 sweeps all five thresholds from loose (top rows, fewer subdivisions, low memory) to strict (bottom rows, more subdivisions, high memory). Loose settings dramatically reduce memory but at significant accuracy cost: the loosest configuration degrades completion error to 2.22 cm and semantic accuracy to 71.17%. As thresholds tighten, accuracy improves rapidly up to the default configuration (highlighted), after which returns diminish: below τ sem=0.10, further tightening yields less than 0.03 cm improvement in completion error while continuing to increase memory from 5.32 GB toward 5.69 GB.

This sweep illustrates the core motivation for our RL-based approach. The optimal threshold configuration depends on the target memory budget, scene complexity, and downstream task requirements, and must be re-tuned whenever any of these factors change. UNRL (OURS) replaces this manual search with a learned policy that automatically discovers the appropriate subdivision strategy for a given budget constraint, removing the need for perdeployment threshold engineering.

# C Training Hardware and Runtime

All experiments, including both 3D semantic scene reconstruction and RL policy training, were conducted on a single workstation equipped with an Intel Core i7-14700K processor (20 cores, 28 threads) and an NVIDIA GeForce RTX 3080 GPU (10 GB VRAM, CUDA 12.2).

For RL training, we used PPO with 4 parallel environments via SubprocVecEnv, training for 10M timesteps per experiment. Evaluation was performed every 50k steps on a held-out validation set of 5 episodes, with model checkpoints saved every 250k steps. Each training run took approximately 24 hours.

The 3D reconstruction pipeline, which generates the RL dataset by processing ScanNet scenes into per-frame voxel observations and reconstruction losses, was executed on the same machine.
