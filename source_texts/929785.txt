Atomic operations like compare_and_swap compare values using bitwise equality, which is different than the equality established by property.equatable. We should provide a means to check if two values are considered equal by compare_and_swap and use this function in the documentation and specification and also for a lock-based or not-synchronized implementation of compare_and_swap and similar operations.
