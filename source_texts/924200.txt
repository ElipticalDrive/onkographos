Motivation
Перевёл стартовую болванку в работоспособный игровой прототип с приоритетом на геймплей (копать/ставить/двигаться) и оптимизацию рендеринга.
Упростить дальнейшее добавление текстур и UI, добавить пул чанков и стриминг для повышения производительности.
Description
Реализован менеджер мира WorldManager для динамической подгрузки/отключения чанков и кэш-пула (src/world/world_manager.py).
Переписан Chunk на сборку мешей с face-culling (создание мешей по типам блоков, отсечение внутренних граней) и поддержкой установки/удаления блоков (src/world/chunk.py).
Улучшена генерация рельефа: фрактальный value-noise с настраиваемыми параметрами вместо простого random (src/world/generator.py).
Вынесены и расширены настройки (src/settings.py) — добавлен путь к текстурам, параметры шума, рендер-дистанция и таймер обновления чанков.
Добавлена поддержка текстур блоков с fallback на встроенный white_cube и инструкция для пользовательских текстур в assets/textures/blocks/ (src/world/blocks.py, assets/textures/README.md).
Обновлён игровой цикл и ввод: хотбар-текст, выбор блока (1/2/3 и колесо), рамка выделенного блока, ломание/постановка (src/main.py).
Курсор центра экрана включён и настроен (src/player/controller.py).
Обновлён README.md с описанием новых возможностей, структуры проекта и быстрого старта.
Testing
Запуск статической проверки: python -m compileall src — успешно (все модули скомпилировались).
Попытка запустить игру: python src/main.py — не удалось в текущем окружении из‑за отсутствия пакета ursina (локальная установка блокируется сетью/proxy).
Попытка установить зависимости: python -m pip install -r requirements.txt — неудача из‑за сетевой ошибки/ProxyError при загрузке ursina.

Fix voxel hit conversion to avoid checkerboard targeting
The chunk mesh is built in corner coordinates (x..x+1), but this hit-to-voxel conversion subtracts 0.5 and then uses round(), which performs bankers rounding. When ray hits land on integer face planes (a common case), values like n + 0.5 snap to different sides by parity, so visible blocks intermittently resolve to adjacent air and cannot be highlighted/mined reliably.

Bound chunk cache growth during world streaming
Every newly visited chunk is added to self.chunk_cache, but chunks are never evicted anywhere in WorldManager (out-of-range chunks are only disabled). During long movement in one direction, memory usage will grow monotonically as all historical chunk block maps/meshes remain retained, which eventually degrades performance or can exhaust memory.
