So after having several ppl tried the system, they all find its difficult to "create sweep on a plane", because they have to use raycasting's point to snap to the center of a circle.
One way to improve this, is for "creating sweep on a plane" we use projection rather than ray casting. The controller's tip will project to the virtual plane and use the projection point to snap to the circle's center. This works great, but I'm not sure how to change the laser beam's visual to map the projection point.
Here is a screenshot:
Let me explain the img (since it's hard to understand). The green plane is the plane were the sweep curve located, also the plane that the controller's tip (end of the red laser) projected onto, now the white dot is the actual projected tip that I managed to create. Though as you can see, the laser beam is visually still aiming to the raycasting direction. Is there a way to change this?
For creating the projection here is what I did - I created a rayProjection function inside the UtilOld that is very similar to the raycasting function.
```
    public static void rayProjection(Point3d pos, ref List<Rhino.DocObjects.ObjRef> rhinoObjs, ref Point3d projectP, out Guid projectObjID)
    {
        Rhino.DocObjects.RhinoObject tmpprojectObj = null;
        List<Point3d> ptList = new List<Point3d>();

        for (int i = 0; i < rhinoObjs.Count; i++)
        {
            List<GeometryBase> geometries = new List<GeometryBase>();
            //Rhino.DocObjects.ObjRef obj = new Rhino.DocObjects.ObjRef(rhinoObjs[i]);
            geometries.Add(rhinoObjs[i].Object().Geometry);

            Brep gBrep = rhinoObjs[i].Object().Geometry as Brep;
            ptList.Add(gBrep.ClosestPoint(pos));
        }

        projectP = ptList[0];
        tmpprojectObj = rhinoObjs[0].Object();
        projectObjID = tmpprojectObj.Id;

    }
```
