Topic: Fence removal from images

Meeting Note6
We try to use the Total Variation inpainting to do the inpaint.
The iterative process of the TV repair equation is an anisotropic diffusion process, when solving for J, (u) the smallest u, the neighborhood of the repair area is treated with the same weight no matter where the gradient is large or where the gradient is small.
The reference point is used for repair. This method has a better effect on the smooth-changing image, but it will produce unnatural transitions and edge modeling for images with drastic changes and large areas to be repaired.
(1) Read in the image to be repaired;
(2) Set the number of iterations n and the gradient threshold k, calculate the mask information of the image, and perform (3), (4), (5) on each pixel in the mask;
(3): For each pixel in the mask, calculate the value of the modulus of the gradient of the surrounding reference point and the value of the diffusion function according to the formula.
(4): If the pixel is located outside the area to be repaired, do not change the pixel; otherwise, perform (5),
(5): Calculate the formula to get the new pixel value and save it in the new image;
(6): Repeat the above steps, end after n generations and display the repaired image
The results obtained using this method did not achieve the effect we wanted. The fence turned gray, and the effect of inpaint was not ideal. Next, we wanted to use the inpaint method of deep learning to improve the inpaint's effect
