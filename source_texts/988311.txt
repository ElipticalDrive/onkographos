Summary
This PR adds batch-level hard_voxelization to the code base, and thus, it allows the model to take points and points-level batch indices to voxelize points.
Note that the new hard_voxelize returns coords in (x, y, z) and voxel-level batch indices (batch_indices) seperately in the data class VoxelsData.
Main changes

Add VoxelsData [1] to save voxelization results.
Replace old hard_voxelize by the new hard_voxelize [2] to perform batch-level voxelization without a for-loop. Note that it performs sample-level capping at max_voxels, and thus, it requires to run unique_consecutive twice in the implementation.
Upload npz files for unittest:

raw_points: Raw points in (number_points, ) for a batch size of 2.
raw_batch_indices: Points-level batch indices.
expected_voxels: Expected voxels output (batch_size*max_num_voxels, max_num_points, 5).
expected_coords: Expected coords output (batch_size*max_num_voxels, 40 in (batch_size, x, y, z).
expected_num_points: Expected number of points (batch_size*max_num_voxels) for each voxels.


Add unittest (TestVoxelization)[3] to test if hard_voxelization works as expected.
Update PointPillarPreprocessor to use the new hard_voxelize [4].
Move test_detection3d.py to TestPointPillarPreProcessor [5] and TestHardVoxelizationDummyPointData [6].

def test_basic_two_voxels(self) -> None:
"""
Test basic case with two voxels and three points.
The first two points fall into the same voxel, and the third point falls into a different
voxel.
"""
points = torch.tensor(
[
[0.1, 0.1, 0.0, 1.0], # voxel (x=0,y=0,z=0)
[0.2, 0.2, 0.0, 2.0], # voxel (x=0,y=0,z=0) - same
[1.1, 1.1, 0.0, 3.0], # voxel (x=1,y=1,z=0)
],
dtype=torch.float32,
)
points_batch_indices = torch.tensor([0, 0, 0], dtype=torch.int32)
voxels_data = hard_voxelize(
points,
points_batch_indices,
self.voxel_size,
self.pc_range,
max_num_points=5,
max_voxels=10,
)
voxels = voxels_data.voxels
coords = voxels_data.coords
num_points = voxels_data.num_points
self.assertEqual(voxels.shape, (2, 5, 4))
self.assertEqual(coords.shape, (2, 3))
self.assertEqual(num_points.tolist(), [2, 1])
# Coords in XYZ order: first voxel is x=0,y=0,z=0; second is x=1,y=1,z=0
self.assertEqual(coords[0].tolist(), [0, 0, 0])
self.assertEqual(coords[1].tolist(), [1, 1, 0])

def test_boundary_points_never_exceed_grid(self) -> None:
"""Test the points that are on the edge never exceed the grid size."""
# A point one float32 ulp below the upper range bound can floor to
# coord == grid_size due to rounding; it must be dropped, not scattered
# out of bounds downstream.

pc_range = torch.tensor([-92.16, -92.16, -3.0, 92.16, 92.16, 7.0], dtype=torch.float32)

points = torch.tensor(
[
[edge, 0.0, 0.0, 1.0],
[0.0, edge, 0.0, 2.0],
[0.0, 0.0, 0.0, 3.0],
],
dtype=torch.float32,
)
points_batch_indices = torch.tensor([0, 0, 0], dtype=torch.int32)

points,
points_batch_indices=points_batch_indices,
voxel_size=voxel_size,

max_voxels=10,
)
self.assertTrue((voxels_data.coords[:, 1] < 768).all())
self.assertTrue((voxels_data.coords[:, 2] < 768).all())
