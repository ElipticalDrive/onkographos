Segment and Support: a dual-purpose Deep Learning solution for Limited Angle Holographic Tomography - dataset
🔗 Dataset page: https://zenodo.org/records/13591396
⬇️ Download: https://zenodo.org/records/13591396
📄 Paper: none found
Training data for the SnSNet network for limited-angle holographic (optical diffraction) tomography. Synthetic 3D volumes of randomly placed spheres (augmented with noise, rotation, holes, flipping, blur, shifts) are paired with versions degraded by a missing-cone artifact (3D Fourier spectrum masking). An experimental part holds erroneous direct-inversion refractive-index reconstructions of cells, organoids and 3D-printed phantoms, each with a binary object mask generated by thresholding with the GTVIC algorithm. Every volume is 128x128x128, float32 TIFF. Pretrained SnSNet weights, config and an inference script are included.
