Adds working GLB/OBJ-to-voxel downloads and eight searchable converter pages using the existing GLB-to-LEGO visual format: /{glb,obj}-to-{vox,qb,binvox,xyzrgb}. A shared LEGO design promotion links converter visitors to the existing 3D-object, image, and text-prompt design workflows.
The backend reuses the trimesh surface voxelizer, skips brick optimization, and returns a private file attachment. VOX preserves a limited color palette, QB and XYZRGB preserve sampled RGB, and BINVOX exports occupancy only. Standalone OBJ materials and external GLB resources are not loaded. Upload size, geometry, resolution, concurrent workers, process memory on Linux, and conversion time are bounded; temporary uploads are removed.
Each page includes distinct visible format guidance and FAQs, canonical/social metadata, WebApplication/FAQ/breadcrumb schema, pre-rendered HTML, sitemap entries, permanent HTML redirects, and crawlable related-tool/footer links. The original mesh preview is extracted for reuse by the LEGO and voxel uploaders.
Validation: 652 frontend tests and 1,189 backend tests passed, including real conversion workers through the HTTP endpoint and all eight conversion pairs. Coverage thresholds passed, the production build passed, and desktop/mobile layouts were checked with no horizontal overflow.
Google Search Console accepted a resubmission of https://brickbuilder.ai/sitemap.xml on October 17. The current production sitemap does not include these new routes yet. Deploy both services after merging, then inspect the live VOX URLs and resubmit the updated sitemap. This PR intentionally remains open for the production merge.
