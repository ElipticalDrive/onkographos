Add a core raymarching strategy for any scene composed of cubes and spheres with the possibility to easily expand with other, well known 3D primitives.
Whilst most of the code is original work by @ScorpionX90. The primitive SDF functions we're kindly fetched from:
Quilez, I., n.d. Distance functions. Available at: https://iquilezles.org/articles/distfunctions/
(Accessed: 2 April 2026).
Pull request includes:
Removal of existing lighting model (phong)
Cube & Sphere SDF function
RayMarching algorithm based on the global SDF
RayMarching algorithm based on the water cubes SDF
SDF object data passing over uniforms
