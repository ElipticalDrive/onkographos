What has changed and why?
Adds synchronized orthographic views to make inspecting and editing point-cloud annotations easier from multiple angles.
Show optional Top, Side, and Front projections alongside the 3D scene, with bidirectional zoom and pan synchronization using a shared world-space target and scale.
Edit annotations in any viewport while keeping the editing toolbar in the main scene. Navigation and keyboard helpers follow the active viewport.
In orthographic views, show only the selected annotation and clip points within 0.5 m of its faces to keep editing focused.
Resize one face while keeping the opposite face fixed. Rotate in the projection plane with an external ring that stays outside the box as the camera zooms; Escape cancels a drag.
Expand and restore individual views without resetting their cameras. Handle initial layout sizing and subsequent resizes consistently.
Add session-persisted scene settings for projections, point size, navigation helpers, and annotation tooltips, plus a collapsible camera strip.
Split the workspace into focused components and hooks, using scoped contexts to avoid prop drilling and documented type contracts.
Review guide: The commit stack introduces standalone components and contracts first, then hooks, then final composition. Much of the diff is workspace extraction; focus behavioral review on scale synchronization, camera initialization/resizing, and viewport input ownership. No backend API or database changes are required.
How has it been tested?
Frontend formatting, ESLint, and TypeScript/Svelte checks passed (Node 24.13.1; zero type errors or Svelte warnings).
Focused cuboid and viewport suite: 158 tests passed across 23 files, including rotation in all three projection planes, projected-corner bounds, and cancellation on Escape, pointer cancellation, lost capture, and unmount.
Visually verified the external rotation ring in Storybook by dragging through a 90° rotation. Preview: Components → PointCloudLabelingWorkspace → CuboidLayer → Orthographic rotation.
Earlier full frontend run: 3,917 tests passed; two unrelated Header/Menu dataset-split dialog tests failed. A menu failure reproduced in isolation; the affected point-cloud suites passed. The focused suites were rerun after the latest changes.
