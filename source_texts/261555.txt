💡 What: This PR applies several highly-effective performance optimizations to the innermost loop of MeshProcessor::voxelize.
Replaces the partition_point O(log N) lookup with a rolling hit_idx (amortized O(1)) to calculate intersections to the right. Since the innermost loop iterates X in strictly ascending order, a sliding window against the sorted hit_xs is mathematically identical and strictly faster.
Initializes hit_xs with Vec::with_capacity(8) to eliminate the dynamic allocation overhead of Vec::new() for almost all realistic scanlines.
Hoists the invariant mathematical components of phase_sphere filtering out of the innermost ix loop.
In solid voxelization mode (when surface_only is false), bypasses the very expensive BVH distance_to_local_point query entirely for points outside the mesh (!is_inside) when narrow_band is None. These voxels are simply discarded immediately.
🎯 Why: The innermost loop (ix) evaluates every single potential voxel in the grid's bounding box. For a high-resolution mesh, this runs hundreds of millions of times. Eliminating redundant BVH queries and allocations in this critical path yields massive performance benefits without altering behavior.
📊 Impact: Significantly improves voxelization performance, especially for solid volumes where exterior voxels often account for over 50% of the volume bounding box and are now skipped entirely. Amortized O(1) tracking removes an O(log N) operation per grid point.
🔬 Measurement: Code correctly builds (cargo check) and all invariant test assertions pass successfully (cargo test). Evaluated logic correctness via Code Review.

Preserve zero-SDF boundary voxels in solid mode
In the narrow_band == None path, the new else { (0.0, false) } branch skips distance_to_local_point for every parity-outside voxel, which changes behavior for grid points that lie exactly on the mesh surface: those points can be parity-outside but still have distance == 0, and the previous logic kept them via sdf <= 0.0. With this optimization they are now always dropped, so solid voxelization can lose boundary voxels for meshes/resolutions where voxel centers land on the surface.
