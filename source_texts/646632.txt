# Volume Normalizer

An ffmpeg-based Batch Volume Normalizer.

## Usage

This package installs an executable under the alias `volnorm`. Simply pass the
path or paths to this executable and those files will be normalized.

see `volnorm --help` for optional parameters.

    volnorm <path>

## Installation

Requires Python 3.12 or later.

    pipx install git+https://github.com/therealzanfar/volume_normalizer.git
