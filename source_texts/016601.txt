Abstract
Scientific applications generate an unprecedented volume of
data, overwhelming the network and file systems’ bandwidth and
posing challenges for efficient and scalable data retrieval and analysis. Progressive data compression offers a promising solution by
enabling on-demand retrieval at reduced size. However, existing
progressive methods either fail to bound the errors in essential
quantities of interest (QoIs) derived from raw data or suffer from
suboptimal retrieval efficiency. In this work, we propose QProR,
an efficient QoI-based progressive framework that optimizes progressive retrieval for target QoIs. Our key contributions include:
(1) a systematic framework that integrates error-controlled lossy
compressors with bitplane encoding while decoupling the two processes for high flexibility and adaptability; (2) a novel weighted
bitplane encoding method which incorperates QoI knowledge into
data refactoring to enhance retrieval efficiency; (3) an optimized
retrieval strategy that accounts for the varying impacts of different variables on multivariate QoIs; (4) comprehensive evaluations
using six real-world datasets from multiple scientific applications
and thorough comparisons against state of the arts. Experimental
results demonstrate that QProR achieves up to 80.38% reduction
in the retrieval size under the same requested QoI error tolerance,
when compared with the best-performing existing methods. When
transferring 384 GB of scientific data to remote sites, QProR delivers
up to 1.68× speedup in the end-to-end data transfer performance.

Introduction
Today’s large-scale scientific simulations and instruments generate an unprecedented amount of data, necessitating the need
for effective data management. For instance, fusion simulations
with 2 trillion particles produce over 200 PB of data in a single
run [2], and climate simulations generate 200 TB of data every 16
seconds [15]. These data are too large to be stored in high-end
parallel file systems (PFS) for long-term archives, so they must be
moved to lower-tier storage, such as tapes, upon generation. When
needed in post hoc data analytics such as visualization and feature
extraction, these data will be retrieved from the lower-tier storage
systems and transferred over wide area networks, where the I/O
and data transmission bandwidth become a significant performance
bottleneck. This severely limits the end-to-end performance of scientific data analytics and thus hinders timely scientific discoveries.
Error-controlled lossy compression [4, 27, 36, 37, 43] has been
proposed and rapidly developed in the last decade to mitigate the I/O
and data transfer bottlenecks, and they have already been integrated
into scientific data management libraries including HDF5 [20]
and ADIOS-2 [17] to accelerate scientific workflows. State-of-theart error-controlled lossy compressors such as SZ [30, 34, 43, 52],
ZFP [36], and MGARD [4–6, 33] provide rigorous error control
to preserve the integrity of scientific data, demonstrating great
potentials in scientific applications including cosmology [46], climatology [24], quantum computing [48], and deep learning [26].
However, a key limitation of these single-error-bounded compressors is the need to predefine error bounds before data storage. Since
the lost details cannot be recovered, users often set conservative
error bounds to ensure the retention of potentially important information for diverse downstream analyses. This cautious approach
can lead to sub-optimal reduction ratios, limiting the efficiency of
lossy compression.

Progressive data compression [9–11, 45] offers a more flexible
alternative by enabling data reconstruction with variable error
bounds. Originating from the JPEG/JPEG2000 in the image processing domains, progressive compression refactors data into a hierarchical representation, allowing for near-lossless storage when
necessary while supporting on-demand retrieval at reduced precision/size. Despite the potential overhead introduced during data
refactoring, progressive approaches improve retrieval efficiency
by reducing the amount of data that needs to be transferred and
recomposed. More importantly, it eliminates the risk of irreversible
information loss inherent in single-error-bounded compressors.
However, progressive compressors that impose error bounds solely
on raw data [21, 31, 40, 50] may fail to control deviations in downstream Quantities-of-Interest (QoIs). Critical QoIs, such as physical
properties [18, 25, 47] and topological features [28, 29, 49], can
be disproportionately distorted, as point-wise errors in raw data
may be disproportionately amplified in the QoIs. A prior study [39]
demonstrates that lossy compressors with error control on raw data
produce incorrect results for detecting blobs in fusion applications—
a key feature for assessing fusion reaction stability. Without addressing this limitation, unintended errors could arise in scientific
analyses, potentially forcing users to retrieve data at full precision,
negating the benefits of progressive compression.
Recently, a framework has been proposed to enable progressive
retrieval with error control on derivable QoIs [47]. Given a QoI
function (uni-variate or multi-variate) and an initial error bound for
data retrieval, this framework estimates the maximal error in the
QoIs based on the recomposed data value and the point-wise error
bound. It then iteratively retrieves and recomposes additional data
fragments, checking the QoI error till the prescribed error tolerance
is met. While this approach ensures error control on a broad range
of derivable QoIs, its efficiency remains sub-optimal for several
reasons. First, it applies a uniform point-wise error bound across
the entire dataset, even though QoI errors may be amplified nonlinearly by different data values. As a result, a few sensitive data
points often dominate the maximal QoI error, while most other data
points are unnecessarily overpreserved. Furthermore, the tightly
coupled multilevel decomposition and bitplane encoding in the
design make it difficult to isolate the processing of data points,
thereby challenging the ability to address the above limitation. In
addition, for multivariate QoIs, the framework treats all variables
equally in error estimation, failing to account for their differing
impacts. Consequently, this framework often leads to redundant
data retrieval for post hoc data analytics, increasing latency in
responding QoI-related scientific data queries.
In this work, we design and develop QProR, a QoI-error-controlled
Progressive framework for scientific data archival and transfer, featuring end-to-end optimizations for both data refactoring (writing)
and retrieval (reading). Specifically, we decouple data decomposition from encoding procedures to isolate the decomposition errors
for each data point, and we introduce a novel encoding method that
accounts for the varying impacts of different data points on target
QoIs. Additionally, we propose an adaptive algorithm to adjust the
data error bounds for multivariate QoIs during retrieval, reducing
the overall data required to meet prescribed target QoI tolerance.
Our key contributions are as follows.

Related Works
In this section, we review related works on error-controlled
scientific data compressors and progressive compressors.
2.1
Error-controlled Data Compressors
The vast amount of data produced by scientific applications has
led to severe problems in the underlying data storage, transfer, and
analytics, which motivates the use of efficient and effective compression methods in scientific data management tasks. However,
generic lossless compressors, such as GZIP [14], ZSTD [12], and
BLOSC [8], have limited compression ratios on floating-point scientific data and thus fail to address the data challenge. Meanwhile,
traditional lossy compressors from the image processing community, including JPEG [45] and JPEG2000 [41], could not provide a
quantified bound on the decompressed data, leaving uncertainties
in the post hoc data analytics. Under such circumstances, errorcontrolled lossy compression has been proposed as an alternative
way to bridge the gap because it can significantly reduce the size
of scientific data while enforcing user-specified error bounds.
Error-controlled lossy compressors can be broadly categorized
into prediction-based ones and transform-based ones, depending
on how the data is decorrelated. The former relies on various prediction algorithms for decorrelation, while the latter utilizes domain

transforms. SZ [30, 34, 43, 52] is the most widely known family of
prediction-based compressors featuring adaptive prediction algorithms. It first decorrelates data using best-fit prediction algorithms,
including Lorenzo [23], regression [30], and splines [52], and then
quantizes the difference between the original data and the predicted data to integers with a linear-scaling quantizer [43]. This
stage significantly reduces the entropy in the data while enforcing
error control. After that, the quantized integers are further compressed by Huffman encoding [22] and lossless compression such
as ZSTD [12]. ZFP [36] is a typical transform-based compressor
that utilizes near-orthogonal transforms for data decorrelation. It
divides data into independent blocks and uses the same exponent
to convert floating-point data into fixed-point representations, and
then performs a near-orthogonal transform on the fixed-point data.
The transformed coefficients are then encoded by an embedded
encoding algorithm that efficiently encodes the necessary information based on the user-specified error bounds. MGARD [4–6] is
another family of error-controlled compressors that builds upon
wavelet transforms and finite element theory. It leverages specific
transforms in the prediction-based compression pipeline to reduce
data and features a rigorous theory of error control.
Recently, variants of these compressors have been proposed to
enable error control on Quantities of Interest (QoIs) in addition
to the one on raw data, as QoIs represent essential information
in scientific data that should not be altered during compression.
MGARD [6] is one of the first compressors that provide guaranteed
error control on bounded-linear QoIs. Later, a variation of SZ [25]
has been proposed to preserve certain families of non-linear QoIs.
These efforts have further been extended to other compressors to
preserve topological features such as critical points [29, 32], contour
trees [19, 49], and Morse-Smale segmentations [28].
While error-controlled lossy compressors have been rapidly developed in the last decade and gradually applied in scientific applications, they have one severe limitation: only one prescribed error
bound is specified during compression. In contrast, scientific data
may be used in diverse post hoc analytics that require various precision. As such, scientists have to choose a conservative error bound
that is sufficient for all analytics, resulting in low compression ratios
and, thus, limited benefits in data storage and transfer.
2.2
Data Refactoring and Progressive Retrieval
To meet the diverse requirements of scientific data analytics,
progressive representations are considered an alternative way to
mitigate the pressure for data retrieval. Unlike error-controlled
lossy compression, progressive methods refactor data into a series
of precision fragments, which can be used to reconstruct the original
data to various precision in a progressive fashion. While this may
not reduce the size of data when writing it to storage systems,
it provides the flexibility to retrieve only the necessary data for
post hoc data analytics and significantly accelerates retrieval. Such
privilege is highly appreciated in the context of scientific data
management, where data is usually written once upon generation
and retrieved multiple times for diverse analytics.
The most well-known progressive method is JPEG [41, 45] from
the image processing community, where the image data is first

divided into different blocks, and then each block of data is independently decorrelated by discrete cosine transform and progressively
encoded by bitplane encoding. ZFP [36] has a progressive mode that
adopts a similar paradigm, but provides point-wise error control
using a smaller block size and a tailored near-orthogonal transform.
PMGARD [31] couples the decomposition methods and error control theory in MGARD with bitplane encoding to enable both 𝐿 2
and 𝐿 ∞ error control in its progressive formats. Another simple yet
effective method has been proposed in [40], which generates errorcontrolled progressive representations by iteratively compressing
the data and the resulting residues using existing error-controlled
compressors with progressively decreased error bounds. Recently,
IPComp [50] was proposed to leverage interpolation in SZ3 [52]
for effective data decomposition, achieving high retrieval efficiency
on multidimensional scientific datasets.
Despite recent advances in generic progressive methods, most
of them remain QoI-agnostic and thus fail to provide any error
guarantee for downstream data analytics. To address this problem,
a rigorous theory [47] has been proposed to enable QoI error control
for certain families of QoIs by leveraging the error control of the raw
data, and it has been integrated and evaluated with three existing
progressive methods. While it provides guaranteed error control
for the target QoIs, it suffers from limited efficiency because it uses
a uniform error bound across all data points during refactoring.
Instead, the proposed QProR framework carefully addresses such
limitations by proposing novel algorithms to efficiently prioritize
data points based on their impacts to the target QoI.

System Overview
We present an overview of the proposed framework in Figure 1
with blue boxes representing proposed components, cyan boxes indicating optimized components, and white boxes denoting existing
components for scientific data refactoring and progressive retrieval.
Similar to existing methods, our framework has a data refactoring
stage, which writes data upon generation, and a retrieval stage,
which retrieves data with guaranteed QoI error control for post hoc
data analytics. During data refactoring, we propose to decouple
error-controlled lossy compressors with bitplane encoding to form
new families of progressive methods that isolate the error control
of data points. This facilitates easy integration of existing and new
compression algorithms while allowing for prioritization of data
points during refactoring. We then propose weighted bitplane encoding, a novel encoding method that considers the diverse impact
of different data points on the QoI error estimation, to further improve the efficiency. During retrieval, we first adapt the decoding
and recomposition stages to make them consistent with the data
decomposition and encoding stages during refactoring, and then
carefully optimize the way to update the raw data error bound in
the iterative procedure.

Approximation-based Progressive Methods
In this section, we describe how we form a new family of progressive methods by loosely coupling generic error-controlled lossy
compression with bitplane encoding.
Prior work [31] has tightly coupled bitplane encoding with the
MGARD lossy compressor [5] to develop PMGARD, a progressive
method with strict error control on raw data. Specifically, PMGARD

uses MGARD to decompose the original data into mutilevel coefficients, and encode the coefficients in each level separately with
bitplane encoding. However, since errors in different levels have
different impacts to the reconstructed data, certain modifications
to the encoding mechanisms are hard to apply. For instance, it is
difficult to exclude singular data points (which have usually been
encoded in other forms such as lossless formats) during encoding
because omitting one single data point may impact a sequence of
dependent data points. As a result, prior work [47] linearizes data to
1D after filtering data points with unbounded error estimation (e.g.,
the supreme of QoI error for 1/𝑥 could be infinity if 𝑥 = 0 so any
data point equal to 0 should be filtered), and perform progressive
encoding on the linearized data. This leads to suboptimal efficiency
because the spatial correlation in the original data is overlooked. It
also limits the use of the proposed weighted bitplane encoding (to
be detailed in Section 6), where each data is assigned to a different
weight and encoded based on such weight. As such, we propose
to loosely couple error-controlled lossy compressors with bitplane
encoding to better leverage spatial correlation while allowing for
certain customization.

As described in Algorithm 1, we leverage off-the-shelf errorcontrolled lossy compressors to compress multidimensional scientific data with a pre-defined error bound, and then encode the
residue using bitplane encoding. We omit the algorithm to obtain
the approximation during retrieval, as it is a simple application
of decompression similar to the one in refactoring (line 3). Since
error-controlled lossy compression is treated as an approximation
of the original data by design, we name it approximation-based
progressive method. Note that this is different from the iterative
procedure to generate progressive fragments with error-controlled
lossy compressors [40], which iteratively invoke the compression
functions on the residues with decreasing error bounds. In contrast,
our method decorrelates the data once and encodes the residue
with bitplane encoding, featuring high throughput during retrieval
with fine-grained error control. This also opens opportunities for
customization with new compression methods and optimizations
associated with bitplanes. Specifically, this method allows for easy
integration of filtering mechanisms and modifications to bitplane
encoding, as the use of error-controlled lossy compressors is decoupled from the encoding procedure. For instance, the singular
data points can be filtered by skipping the specific positions during
bitplane encoding, and the modifications to incorporate weights
will be detailed in the next section.

Traditional bitplane encoding treats each data point equally to
enforce a uniform error bound on raw data. This could lead to
inefficiency when QoI error is the target, because QoIs may nonuniformly amplify the error on raw data. In this section, we propose
a novel weighted bitplane encoding algorithm that effectively addresses such limitations.

Unlike traditional QoI-agnostic bitplane encoding, the proposed
weighted bitplane encoding takes the QoI information into account
by first computing the weights based on the target QoI. Noticing
that the value of 1/𝑥 will be amplified a lot when 𝑥 is relatively
small, a natural idea is to reduce the error on raw data in those cases.

We evaluate our methods regarding error control, retrieval efficiency, and data transfer performance using six real-world datasets.
Specifically, we validate that the proposed method provides guaranteed QoI error control for the derivable QoIs in the GE example, and
then compare its efficiency with three state-of-the-art approaches

We then describe the coordinate descent algorithm by first analyzing the limitations in the prior work [47]. Specifically, prior
work updates the data error bounds during progressive retrieval by
simultaneously reducing the error bounds for all variables, which
assumes that the error on each variable has similar impact to the
estimated supremum of QoI errors. This may not always be true
due to the diversity in QoIs, and we propose to address this problem
without comprising the retrieval performance by the coordinate
error bound descent algorithm presented in Algorithm 7.
The goal of this algorithm is to find the new data error bound
after knowing that the supremum of QoI errors with the current
data representation exceeds the tolerance, and it is only applied
to a single data point with the maximal estimation of QoI error
for performance consideration. Instead of uniformly reducing the
error bounds on all variables, we proportionally decrease the error
bounds of all variables according to their normalized contributions
to the reduction of the estimated QoI error, and then estimate the
new QoI error based on the new error bounds. This evaluation
is performed on each variable (lines 2-6), and we proportionally
adjust them based on their normalized contributions to reducing
the estimated QoI error (line 7-12). The procedure is repeated until the current estimation of QoI error is less than the requested
QoI tolerance. While this algorithm may take more iterations to
complete, it introduces little overhead as all the evaluations are
performed on only one data point.

8.2
Guaranteed QoI Error Control
We then demonstrate the guaranteed QoI error control in QProR
using all the QoIs with the GE data. We present and compare three
121
values in this evaluation: (1) requested QoI tolerance, which denotes
the desired QoI tolerance 𝜏 specified by users; (2) max estimated QoI
error, which represents the supremum of the estimated QoI error
using the theories in [47]; and (3) max real error which indicates the
maximum of actual QoI errors computed from the QoIs of current
data representations and those of original data.
As illustrated in Figure 4, the max real error in QProR is always
smaller than the max estimated error, which is close to but strictly
smaller than the requested tolerance in all the six QoIs. This indicates that QProR can faithfully enforce the QoI error tolerance.
A clear gap is observed between the max estimated QoI error and
the max real error for 𝑃𝑇 and 𝜇 though, which is mainly caused
by the iterative estimation of supremum due to the complex forms
of the two QoIs. Such phenomenon is unavoidable when the error
estimation is iteratively applied (rather than directly solved), and it
is also observed in prior work [47].
8.3
Comparison with State of the Arts
We compare QProR with [47], the only prior work that provides
guaranteed QoI error control during progressive retrieval. While
three progressive methods (PSZ3, PSZ3-detla, and PMGARD-HB)
have been integrated into [47], we omit PSZ3 due to its low efficiency. Instead, we integrated the latest progressive data compressor, IPComp, which is more efficient for scientific data [50]. For a
fair comparison, we use an optimized version of the prior work
that leverages multidimensional data decomposition (instead of the
default 1D decomposition in [47]), so our baselines already deliver
much higher efficiency than those presented in [47]. As analyzed
in Section 5, we use the tailored GE approximator for unstructured
GE data and HPEZ approximator for the other multidimensional
datasets.

Data Transfer Performance
We demonstrate how QProR can benefit scientific data management using a practical use case of remote data transfer. The experimental setup is as follows. The refactored data is stored at one
cluster [3], and the request for data retrieval is initiated from another cluster [1] with 𝑉𝑡𝑜𝑡𝑎𝑙 as the target QoI under a commonly
used tolerance 𝜏 = 10 −3 . The data is transferred via Globus [16], the
leading research cyberinfrastructure widely used for scientific data
sharing and management. This setup reflects a common scenario in
which domain scientists must download data from remote servers
to local machines for post hoc data analysis and visualization. To
demonstrate how the progressive methods perform with increasing
data sizes, we conduct a weak-scaling experiment using 128, 256,
512, and 1024 cores, respectively. In all the experiments, each core
is processing a fixed size (128 × 512 × 512 ) of data from the JHTDB
dataset, so the total size of the processed data increases with the
number of cores. We report the data refactoring time and data retrieval size in Table 6 and 7, respectively, and plot the end-to-end
data transfer time (which includes both retrieval time and transfer
time) in Fig. 7.
According to Table 6, PSZ3-delta has the slowest refactoring
time, because it needs to perform multidimensional compression
multiple times. IPComp is the fastest among all the methods, mainly
because it quantizes the data to a certain accuracy before refactoring. This reduces the number of bitplanes to store, but it may not
be able to recover data to the highest precision. QProR has comparable performance to IPComp and PMGARD despite the introduction

for floating points.
During retrieval, QProR yields the smallest size, mainly because
of the use of advanced approximators and priorization of sensitive
data points with weighted bitplane encoding. In absolute terms, it
leads to 24.41%, 28.40%, 29.22%, and 25.46% reduction in the retrieval
size under the four evaluated scales when compared with the best
existing method. Meanwhile, QProR has a competitive retrieval
time when compared with the baselines, as shown in Fig. 7. This is
because QProR only performs multidimensional data once with the
approximator, whereas the others need to do so every time in each
iteration during the retrieval. As a result, QProR yields the fast endto-end data transfer time in all the cases. Specifically, performance
gain is up to 1.68× over the best existing method and 14.04× over
vanilla transfer of the original data.

Conclusion
In this paper, we present QProR, an efficient framework that
supports progressive retrieval with guaranteed QoI error control.
QProR introduces a new family of progressive methods that loosely
couple error-controlled lossy compressors with bitplane encoding,
leverage them to achieve high efficiency through optimized encoding algorithms and retrieval procedures. Experimental evaluations
demonstrate that QProR delivers up to 80.38% reduction on the
retrieval size with comparable throughput when compared to stateof-the-art progressive approaches under the same requested QoI
error tolerance, and this leads to up to 1.68× speedup in end-to-end
data transfer. In the future, we will investigate novel algorithms
to compute weights more effectively across diverse QoIs. We will
also leverage advanced hardware, such as GPUs, to further improve
QProR’s throughput.

Discussion of limitations
QProR encodes the data based on the prior knowledge of the
target QoIs. As long as the target QoI is known during refactoring,
QProR always delivers high efficiency by accounting for the error
amplification in QoI computations. If QoI information is not known
during refactoring, QProR will fall back to use traditional bitplane
encoding. However, we argue that many QoIs (e.g., total velocity, kinetic energy, and momentum) in scientific data are common across
disciplines and are well known prior to any post hoc data analysis,
thereby facilitating the use of QProR in practice.
