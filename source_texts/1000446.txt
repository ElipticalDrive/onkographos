Goal
Add reusable higher-level noise composition kernels after the base noise sources exist.
Depends on #110. Simplex/Worley implementations can then be used as representative inputs.
Scope
Add domain-neutral combinators inspired by pmndrs/math/src/noise/fractal.ts:
fBm
ridged multifractal
billow
2D and 3D domain warping
2D and 3D curl-noise helpers
Keep the base sampler caller-supplied so the combinators do not own terrain/world-generation policy.
Design constraints
Explicit octave/lacunarity/gain semantics.
No hidden allocation in repeated sampling.
Deterministic handling of zero octaves and invalid/non-finite configuration.
Curl finite-difference epsilon is explicit/configurable rather than ambient.
Avoid closure/dynamic-dispatch overhead in hot loops where a generic/static API can preserve composability.
Evidence
Compare fBm/ridged/billow to straightforward loop oracles.
Check domain warp determinism and coordinate behavior.
Check numerical curl properties on analytical scalar/vector potentials where possible.
Add Divan scenarios across octave counts and point batches.
Keep timing informational; use deterministic work/allocation ratchets for blocking evidence where practical.
