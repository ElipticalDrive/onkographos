Context
This PR :
adds a 'Volume Options' menu in the volume3d viewport to control volume decimation (downsizing) and downsampling.
incorporates the orientation controller, volume cropping and volume cropping control tools from cornerstone.
replaces the MPR orientation corner menu in the volume3d viewport with the 3D slicer orientation widget.
Changes & Results
volumeDecimation
Automatic decimation is applied to volume and volume3d viewports when the number of voxel is higher than a threshold set in the configuration file with name volumeAutoDecimationThreshold .
When slice decimation is applied, the thumbnail image count shows both the decimated and original image count.
volumeDownsampling:
Volume downsampling reduces load on the GPU.
A GPU test is ran once and the sample distance multiplier are automatically set according to the settings desired under highGpu/migGPU/lowGPU. With the threshold settings below, highGpu have score of 100%, midGpu 99-90%, lowGpu are <89%.
```
customizationService: [
    {
      volumeDecimation: {
        volumeAutoDecimationThreshold: 500_000_000,
        dangerouslyTurnOffDecimationNotification: false,
      },
    },
    {
      volumeDownsampling: {
        highGpu: {
          rotateSampleDistanceFactor: 2,
          sampleDistanceMultiplier: 1,
        },
        midGpu: {
          rotateSampleDistanceFactor: 2,
          sampleDistanceMultiplier: 2,
        },
        lowGpu: {
          rotateSampleDistanceFactor: 3,
          sampleDistanceMultiplier: 2,
        },
        thresholdHighPercent: 100,
        thresholdMidPercent: 90,
      },
    },
 
```
Testing
To enable auto decimation
Set volumeAutoDecimationThreshold to a number (e.g. 500 million) in configuration file:
volumeAutoDecimationThreshold: 500_000_000,
Any volume whose estimated voxel count is above this value will be decimated when loaded (e.g. downsized so the resulting voxel count is at or below the threshold). The exact decimation (in-plane and slice) is chosen automatically.
Setting to a low value, ex 5M, allow testing with small datasets.
Disable auto decimation
Omit volumeAutoDecimationThreshold from the config, or set it to null / undefined. No automatic decimation will be applied; volumes load at full resolution (subject to other limits in your app).
Manually changing the decimation can be done in the 3D viewport Window/Level corner menu.
