Real geometry shadowing (review-only)
This branch extends the already tested World Engine → native WebGPU → H.264 canary chain on PR #1459. The existing post-production and GGX code stays in place.
Implementation:
Optional visualScene.directionalShadows with target directional light, focus, bounded extent, resolution and depth bias.
Deterministic and digest-bound light-space matrix and per-object castsShadow/receivesShadow flags.
True depth-only GPU geometry pass, depth32float texture, comparison sampling of light-map in the fragment GGX/legacy direct lighting.
The owned EvercraftWebGpuRenderer and browser-GPU movie proof both have shadow depth passes. Alpha-masked objects are conservatively excluded as casters until alpha-test prepass is implemented.
Existing non-opt-in scenes retain their canonical plan receipts and no-shadow pixel behavior.
Scene canary uses directional sun light and real moving cast shadows in a 640×360 48-frame review film.
Added five contract/shader/fail-closed tests. Existing World Engine, Browser Worker, cinematic pixels, and Forge checks must pass before anything can be promoted.
Important: A passing shader pipeline is not proof of a beautiful or physically complete shadow solution. Pixel differences must be inspected by the founder; shadow acne, bounds, bias, and artificial scene geometry can still fail. This branch makes no claims about shipping photoreal video, deployment, hardware GPU acceleration or publishing. No paid dependencies.
Parent PR #1459, graphics mission #1450.
Native GPU visual acceptance | October 19
All four required workflows green on head 369a4aa01cd324f16166a6d654b3672b2c54c992: World Engine, Evercraft Browser Worker, World Engine cinematic pixels and full Forge checks.
CI's 640×360, 24fps, 2-second, 48-frame H.264/AAC synthetic canary is verified via https://github.com/jgaethle10/forge-operator/actions/runs/39373906155. Its read-only receipt includes two GPU-controlled first-frame counterfactuals made with the exact same scene and time:
Shadows ON vs shadows disabled: 8,200 distinct visibly changed (>8 RGB) pixels, 3.56% of the 230,400-pixel frame. CI fails if below 300. The original first attempt merely darkened too much; this corrects sun direction (downward) and separates shadow-casting props from receiving floor.
PCF-filtered vs unfiltered hard shadow: 27,440 visibly changed (>2 RGB) pixels, 11.91% of the frame. CI fails if below 10. 3x3 PCF kernel softens shadow-map stepping; resolution and filter radius are controlled by digest-bound scene inputs.
CI artifacts contain native shadow enabled, disabled and hard-shadow PNGs alongside the video and SHA-256 output receipt. No pixel changes are inferred solely from code patterns.
Creative verdict remains INTERNAL REVIEW. Self-shadow artifacts, bias tuning, coarse geometry, repetitive metal textures and test-tone audio are still limitations. No 1080p, dramatic genuine source assets, physical simulation or deploy/publish claims. Shadowed output is a verified technical canary, not an approved sales film. Do not merge or publish until deliberate founder review and production QA.
