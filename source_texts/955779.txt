Outcome
Provide the first M0 geometry primitive: convert a non-empty 3D binary occupancy grid into an axis-aligned triangle mesh by emitting only exposed voxel faces.
In scope
A small Python package scaffold.
A deterministic occupancy-grid meshing function.
Removal of faces shared by adjacent occupied cells.
Vertex welding by exact grid coordinates.
Consistent outward triangle winding.
Unit tests for one voxel, adjacent voxels, disconnected voxels, input validation, determinism, and edge-manifold output.
Out of scope
Greedy coplanar face merging.
STL/GLB export.
Character body parts and scale conventions.
Relief, materials, joints, CLI, API, or AI providers.
Acceptance criteria
A single occupied voxel produces the expected closed cube mesh.
Shared internal faces are absent for adjacent occupied cells.
Output ordering is deterministic.
Triangle winding produces positive signed volume.
Every mesh edge has exactly two incident faces for tested solid inputs.
Empty or non-3D inputs fail with clear errors.
The complete test suite passes on supported Python versions.
Dependencies
Product direction: SPEC.md section 5.4.
No blocking implementation issue.
