### **PR Type**
Enhancement, Bug fix


___

### **Description**
- Add BVH acceleration structure for ray tracing
  - Implement AABB, BVH construction (SAH), and traversal
  - Integrate BVH into ray intersection logic for performance

- Implement camera movement and rotation controls
  - Add keyboard hooks for WASD, arrow keys, space, shift
  - Add camera translation and rotation logic

- Add multi-threaded tile-based rendering system
  - Implement tile splitting, worker threads, and synchronization
  - Integrate SSAA (super-sampling) and FXAA (anti-aliasing)

- Enhance lighting with Phong/Blinn-Phong shading and reflection
  - Add per-object specular, shininess, and reflectivity parsing
  - Add recursive ray tracing for mirror reflection

- Refactor and fix object intersection code (sphere, plane, cylinder)
  - Fix hit record initialization and normal orientation
  - Standardize miss return values to -1.0

- Add debug utilities and configuration improvements
  - Add scene debug print, debug flags, and config for SPP
  - Update Makefile and scripts for new modules and threading
