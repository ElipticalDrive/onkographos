Adds --seed-pointcloud and a GUI PLY picker for initializing Gaussians from an ordinary XYZ + RGB cloud. This allows COLMAP camera poses to be used with a registered LiDAR cloud without rewriting points3D.
The external cloud replaces the dataset seed points before centering and coordinate transforms. The existing PLY reader and Gaussian seeding pipeline are reused, and the option also works with Nerfstudio datasets. An empty path keeps the current behavior; init_ply retains its existing meaning.
The GUI preserves the selected cloud when changing presets, provides a button to restore the dataset cloud, and shows the initialization source and a notice when random initialization or a resumed model makes the selected cloud unused. Interface text is included in all 13 languages.
Validation:
Windows Vulkan build and a one-step synthetic COLMAP training run with checkpoint output.
Parser regressions covering ASCII/binary PLY, path handling, invalid clouds, centering, Nerfstudio transforms, and config round trips; existing relative-path, random-point, and preset tests also passed.
GUI checks for preset changes, restoring dataset points, and explicit/automatic random initialization.
CUDA was not built; this change is in shared host-side parsing, configuration, and GUI code and does not modify kernels.
Fixes #125.
