Summary
Promote Medium::sigma_a / sigma_s from scalar to Vector3D so the
renderer can reproduce the depth-dependent color shift that defines the
underwater look (red attenuates faster than blue → blue-green haze).
Transmittance (homogeneous Beer-Lambert and heterogeneous quadrature)
now returns Vector3D; shadow-ray and surface-segment attenuation in
pathtracer.cpp updated accordingly.
Scatter-event weight uses chromatic albedo_c() (sigma_s / sigma_t
per channel) instead of scalar albedo.
Heterogeneous path preserved: delta_track keeps a scalar
sigma_t_avg majorant; density_scale(p) is a pure [0, 1] multiplier
so Woodcock tracking stays valid for chromatic sigma_t.
Add max_shadow_dist cap (env var MEDIUM_MAX_DIST) so directional /
infinite-distance lights still contribute when transmittance would
otherwise go to zero.
Scalar Medium(sa, ss, bbox, fade) constructor kept for backward
compatibility; env-var overrides (MEDIUM_SIGMA_A[_R/G/B],
MEDIUM_SIGMA_S[_R/G/B], MEDIUM_MAX_DIST) applied on construction.
Rationale
Wavelength-dependent σ is the single most impactful feature for an
"underwater" look — the color shift with depth is the defining visual
property of water. Heterogeneous density (already in main) handles
local turbidity, but chromatic σ is what turns a gray fog into water.
Test plan
Builds clean on macOS (clang) with existing CMake
Smoke render of dae/sky/CBspheres_lambertian.dae with
MEDIUM_SIGMA_A_R=0.30 MEDIUM_SIGMA_A_G=0.10 MEDIUM_SIGMA_A_B=0.05 MEDIUM_SIGMA_S_R=0.08 MEDIUM_SIGMA_S_G=0.15 MEDIUM_SIGMA_S_B=0.25 MEDIUM_MAX_DIST=3.0 shows clear cool blue-gray cast with red
attenuated more than blue through the bounded fog region.
Re-render milestone images with chromatic underwater parameters
Compare against existing scalar-medium renders for regression
(scalar mode: set MEDIUM_SIGMA_* env vars equal across channels)
