# Parallel Projection System for Godot 4

## Summary

Custom 3D rendering system implementing real-time axonometric
(parallel) projection for triangles and voxel geometry.

## Features

- Generalized parallel projection (isometric and axonometric)
- Real-time rotation through dynamic basis recomputation
- Optimized rendering using shader-based batching (single GPU draw call)

## Mathematics

Let $(Vx, Vy, Vz)$ be the projected basis vectors in 2D space.
For any 3D point $(x, y, z)$, the 2D projected position is:

$x·Vx + y·Vy + z·Vz$

Rotations are performed by applying a rotation matrix to the basis vectors.

## Limitations

Prototype implementation. \
No advanced mesh optimizations or complex mesh support yet. \
Designed for high-performance voxel worlds using a single MeshInstance2D.

## How to use

Open the project with Godot 4.4 and run the main scene.
The projection system is located in `/parallel-projection`.
