D2e — deterministic projected-surface mesh finalization
Completes the deterministic D2 operator pipeline with one finalizer that runs exactly once after convergence.
Revision after real-image inspection
The first D2e prototype used exposed faces of occupied 25 mm voxels.
That implementation was deterministic but a real-photo reconstruction showed it was the wrong meshing primitive:
```
sparse 2.5D surface samples
        ↓
solid occupied cubes
        ↓
blocky/thick voxel shell

four face-local vertices per quad
        ↓
every quad is an indexed mesh island
```
The revised D2e removes the voxel-shell finalizer entirely.
Revised pipeline
```
final D2c refined state
        +
original D2a camera
        |
        v
project final 3D points into source camera
        |
        v
nearest-Z z-buffer
one point / source pixel
        |
        v
deterministic 2D Delaunay chart
        |
        v
filter triangles:
  projected edge <= 16 px
  depth jump <= max(50 mm, 3% near depth)
        |
        v
orient toward source camera
        |
        v
weld shared vertices
        |
        v
area-weighted vertex normals
        |
        +--> scene.glb
        +--> scene.obj
        +--> scene_mesh.ply
        +--> mesh.json
```
Frozen dependency
```
SciPy 1.18.1
```
The adapter verifies the exact version before triangulation. It is already present in the D2a environment used by the current live gates.
Why this surface model is scientifically better
D2a–D2d currently know the source-visible metric surface and deterministic reprojections of that existing geometry.
They do not know the unseen backside.
So D2e now emits a coherent open source-visible 2.5D surface rather than inventing a closed volumetric shell. If D2f later adds genuinely new multi-view image evidence, we can justify a multi-view/TSDF finalizer then.
Determinism
```
visible vertices:
  ascending source-pixel index

Delaunay tie breaking:
  deterministic tiny chart-only perturbation
  exported 3D XYZ unchanged

accepted triangles:
  canonical cyclic representation
  lexicographic ordering

normals:
  area-weighted shared vertex normals
```
Topology regression guard
The verifier explicitly checks that the mesh has shared indexed topology and recomputes connected components from the GLB index stream.
This prevents the failed "one quad = one disconnected index island" representation from returning.
Coordinate convention
```
+X = image right
+Y = image down
+Z = camera forward
units = meters
```
Inputs
Final D2c state:
```
fusion.json
refined_points.f32le
```
Original D2a camera:
```
prior.json
camera.json
```
The same finalizer and source-camera treatment are used exactly once for both fixed and emergent experiment arms.
Outputs
```
scene.glb       primary artifact
scene.obj       text interoperability/debug export
scene_mesh.ply  inspectable triangle mesh
mesh.json       deterministic provenance/content manifest
telemetry.json  non-content timing/environment metadata
```
Gate
```
python tools/verify_evoscene_d2e.py --live
```
Defaults:
```
source:
trials/evoscene-d2d-smoke/closed-loop-a

camera:
trials/evoscene-d2a-smoke/run-a
```
The gate verifies:
```
Zig/Python D2e contract agreement
exact SciPy version
synthetic welded one-component surface
source + camera provenance
source-camera z-buffer accounting
triangle pixel-gap threshold
triangle depth-discontinuity threshold
triangle winding toward source camera
shared indexed topology
connected-component count
finite positions
unit shared normals
GLB 2.0 structure/accessors/bufferViews
OBJ counts
PLY counts
byte-identical duplicate finalization
full zig build test
```
Expected terminal verdicts:
```
D2e welded_topology: yes
D2e byte_identical_repeat: yes
D2e GLB validation: PASS
D2e OBJ validation: PASS
D2e PLY validation: PASS
D2e LIVE PASS: deterministic projected surface generation complete
D2e REPOSITORY PASS: full Zig test suite complete
```
This PR remains draft until the revised local live gate passes.
D2 completion
Once revised D2e validates:
```
D2a real metric depth + camera prior
D2b explicit backprojection + point cloud
D2c deterministic fusion + geometry refinement
D2d deterministic novel-view render/reprojection
D2e deterministic projected-surface mesh finalization
```
constitute the complete deterministic D2 real local reconstruction operators substrate.
D2f remains optional learned novel-view evidence and is not required before D3.
