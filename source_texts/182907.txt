GitHub - 3dgeo-heidelberg/vapc: Voxel Analysis for Point Clouds
VAPC is a Python library for voxel-based point cloud operations. 3D/4D point clouds are used in many fields and applications. Efficient processing of dense time series of point clouds or large study sites requires tools for automatic analysis.
