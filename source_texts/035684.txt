# Interactive Dynamic Volume Illumination with Refraction and Caustics
This repository contains the reimplementation of the paper: "Interactive Dynamic Volume Illumination with Refraction and Caustics" by Mag-
nus and Bruckner (2018).

# Main Algorithm
![algorithm summary](vis2025/images/algorithm_summary.png)

The main algorithm can be found in *resources/shaders/algorithm/algorithm.comp* which is run for every plane cutting through the volume. In summary at each plane we do a backward integration step to compute light directions and intensities and a forward integration step to compute view ray directions as in the above image.

To store intermediate results we use two sets of 6 buffers and on each iteration we select one set as input and the other as output and swap them at the end of each iteration in a ping-pong fashion. The buffers are as follows:
- light intensity buffer (`lb`): containing the radiance arriving at the voxel
- light direction buffer (`ldb`): containing the direction to the light (at the viewer position)
- color buffer (`cb`): used to store the accumulated color and opacity along the view rays
- medium buffer (`mb`): containing the accumulated medium color
- view position buffer (`vpb`)
- view direction buffer (`vdb`)

Before the main algorithm, at the start of the frame we initialize the above in *resources/shaders/reset_buffers/reset_buffers.comp*.

# Building and running
The project can be build on Windows using any Visual Studion version with C++20 support. Furthermore the Vulkan SDK needs to be installed and to run the project, a GPU supporting Vulkan 1.3 or higher is required. To build and run simply open the solution file select "Release x64" and run.

# Code Structure
The render loop is located in *src/core/obsidian.cpp* in the function `Obsidian::flow()`, while the two main compute shaders are located in the *resources/shaders/* folder. UI code is located in *src/platform/ui.cpp*.

# Controls
View can be rotated by clicking the left clicking and dragging the mouse, zoom with the right mouse button, while transfer function values can be adjusted using the UI.
