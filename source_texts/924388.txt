Motivation
Enable ray-state arrays (rays geometry, directions, wavelengths, intensities, refractive indices, attenuations, colors) to be hosted either on CPU or GPU so tracing stages can operate on device-resident buffers when available.
Provide a small, low-risk integration point (runtime backend selection + buffer descriptors) so GPU support can be enabled incrementally while preserving the existing CPU-only analytic tracing implementation.
Description
Added a runtime backend selector functions/rt_backend.m that chooses CPU vs GPU based on the USE_GPU_ARRAYS environment variable and local gpuArray availability.
Introduced a minimal buffer abstraction via functions/rt_array_buffer.m, functions/rt_create_ray_buffers.m, and functions/rt_type_bytes.m to describe CPU/GPU arrays, hold metadata, and provide simple upload/download helpers.
Extended the Rays class (classes/Rays.m) with a buffers field and methods syncToBuffers, syncFromBuffers, and bufferLocation to mirror ray-state arrays into buffer descriptors and to keep CPU/GPU copies consistent; constructor, append, subset, truncate, intersection/interaction output paths were updated to synchronize buffers.
Updated Bench.trace (classes/Bench.m) to select and log the backend, synchronize the input rays to the chosen backend, and keep ray buffers synchronized across tracing stages.
Added a parity example examples/example_gpu_arrays_compare.m that renders a simple scene with both CPU and GPU backends and checks image difference, and documented usage in README.md (added GPU backend section describing USE_GPU_ARRAYS).
Testing
Ran repository checks and discovery commands: git diff --check succeeded and repository grep/searches (rg ...) were executed to verify integration points.
Committed the changes successfully (git commit) which reported the created/modified files.
Attempted a runtime check with octave --version but the environment does not include Octave/MATLAB so GPU/CPU parity execution was not possible here (runtime tests not executed).
A CPU/GPU parity sample (examples/example_gpu_arrays_compare.m) was added for local verification; it should be run on a machine with MATLAB/Octave and GPU support to validate parity (not executed in this environment).
