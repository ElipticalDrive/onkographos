Wavelet based image order rendering algorithm was presented by Gross and Lippert in 1997. But in its realization, the definition of differential sampling parameter and data structure given by Gross and Lippert need to be consulted. Besides, the algorithm needs huge storage when dealing with large scale 3D data sets. Here investigated is improved wavelet based image order rendering algorithm by using 3D CT medical data. The paper, first, describes the key technologies of wavelet based image order rendering, i.e. object classification/segmentation, transfer function, wavelet representation of volume data (color, opacity), shading computing and volume rendering integration computing, and then, corrects the definition of differential sampling parameter, suggests a new data structure and describes a method to create the data structure using the relativity of neighbored sampling points in one ray as much as possible. Thirdly, a more practical shading computing method is given. Fourthly, a new method of wavelet based image order rendering is presented. Finally, practicability of the algorithms is checked by example.
