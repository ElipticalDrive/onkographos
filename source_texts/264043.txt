V8.03.00
FEATUREF18347Animation Editor: Animation channels now correctly listen to property changes done by Gizmos when no keyframe is present on that timeline position.
FEATUREF18515Animation Editor: Added "Auto Keyframes" mode to the Animation Editor which automatically inserts or edits keyframes when you edit an animated property. This replaces the "Teach In" button.
FEATUREF18560Animation Editor: It is now possible to select and bring bound animation channels into view via context menu on Nodes and PropertyGroups.
FEATUREF18907Animation Editor: Improved Animation Editor - 1) Adding keyframe can be done with a shortcut from all editors, not just AE; 2) Gizmo manipulation is enabled for animated properties; 3) All channels can be selected via Ctrl+A.
FEATUREF19042Animation Editor: Animation channel that are named X, Y or Z now have a distinct color that corresponds to the gizmo axes.
FEATUREF14711Arrow Node: When the node is used with splines, the spline can be followed at constant velocity independent of density of spline keys. This does not work for splines with multiple segments.
FEATUREF15866Configuration Editor: Added an option to download a machine's log history to the download buttons in the Config Editor, etc.
FEATUREF18883Designer: Log window's context menu now allows to open log files folder.
FEATUREF18529Designer / ContentEditor: Made unlinked Hierarchy nodes in CE distinguishable by text color and name suffix.
FEATUREF18911Designer / Director / Runtime: We upgraded all main Ventuz applications to be built on .Net 10.
FEATUREF19054Designer / Runtime / VMS: On crashes of these apps automatically a memory dump is stored in ProgramData\Ventuz8\CrashDumps.
FEATUREF15070Designer / Vx: Vx nodes that are missing their plugins are now listed in the 'Issues' tab of the Scene Statistics.
FEATUREF18686GLTF Import: Now supports KHR_materials_transmission (partially) and KHR_materials_variants extensions.
FEATUREF18368Geometry / Rendering: Added support for Gaussian Splats import (.ply and .spz) and rendering. Use the new 'Gaussian Splat' node. Import also works via drag&drop into Hierarchy Editor.
FEATUREF19003Input Boards: Improved reliability of Deltacast HDMI capture. You can now switch the board between HDMI and DVI via the Device Config, even while Ventuz is running, solving compatibility issues with some sources. DVI over HDMI cables is enabled by the monitor or capture device, the GPU adapts to the video "sink".
FEATUREF18831Launcher / Designer / Vx API: From Launcher and Designer you can now start the Vx Plugins manager tool that works similar to the NuGet manager in Visual studio. See documentation for details.
FEATUREF18684LiveLink / Geometry Import: Updated the Cinema 4D plugin installer for the 2026 Cinema 4D version.
FEATUREF18152Material System: We implemented the Z-near-fadeout effect from the Particle System's Sprite renderer for all materials.
FEATUREF18210Material System / Modes: The existing triplanar model space mapping worked on model space coordinates after skinning and instancing. Now there is an option to have it work on the original model space vertices, so for instance in a bone animated mesh, the model space textures stick to the mesh. This is also very useful with the new particle mesh splitters.
FEATUREF18941Nodes: SystemID node now provides basic information about Vx plugins availability.
FEATUREF18791Nodes / Material: Substance Material node will now create a PBR material if applicable.
FEATUREF18740PBR Material: Added Transmission property and texture channel for per-pixel physically based translucency
FEATUREF10333Particle System: Smooth Particle Hydrodynamics (SPH) allows to have particles interact with each other, for fluid like effects and more importantly to control particle behavior, flocking and de-clumping.
FEATUREF10579Particle System: The Mesh Emitter/Renderer combination now correctly calculates normals. There is a new option to enable this, which is enabled by default on new nodes: 'Recalculate Normals' in Attributes property on the Emitter.
FEATUREF11041Particle System: Added new shape "Vortex" to module ShapeForce, which is the same as the "Axis" with "Tangential" switched on - but this feature was overlooked by many users so we wanted to make it more prominent.
FEATUREF11064Particle System: All Forces now have a "PerParticleAmount" property that allows to control the force per particle, for instance through a texture.
FEATUREF15408Particle System: Added Performance Statistics section about individual particle systems and extended the summary found in the advanced GPU stats.
FEATUREF15986Particle System: Allow the Mesh Renderer to override the flipbook texture animation from the per particle animation.
FEATUREF17274Particle System: Added some of the functionality of the Remap module to the Force modules. This allows for some creative use of the Force modules, and it allows to modify the force by mapping it to Aux, manipulating it otherwise and then applying it. The Math and Remap modules have been extended to allow applying a force.
FEATUREF17497Particle System: Modifier Module "Texture" now supports the 'Mirror' and 'MirrorOnce' texture wrapping modes.
FEATUREF18015Particle System: Introducing new Emitter module - the Torus Knot.
FEATUREF18097Particle System: The Nexus renderer has two new Selector modes 'Amount to selection' and 'Amount Range' to use the particle amount value as base for Color and Alpha.
FEATUREF18151Particle System: In Nexus renderer it is possible to select points directly from triangles now.
FEATUREF18159Particle System: The Remap module has a new mode "Ramp In Out" that allows to easily set up a curve that fades in and out, with variable gamma.
In the same way, the gradient module has now a "min and max" mode that allows to place a gradient by specifying minimum and maximum instead of offset and scale.
FEATUREF18229Particle System: A new pair of particle modules allows simple mesh explosion effects. The "Mesh Splitter" module pre-slices a mesh and attaches particles. The "Render Splitters" module renders the particles using the pre-sliced geometry.
FEATUREF18230Particle System: Introducing new module "Explosion" that adds a force just for one frame.
FEATUREF18236Particle System: "Activation" is a new particle system attribute that can be used to "remember" how active a particle is in a simulated particle system. This can be used to prevent forces from acting on a particle until "something" happens, like a collision event or an explosion trigger.
FEATUREF18243Particle System: The module "Orientate to Center" now has the 'PerParticleAmount' and 'UseActivation' properties. They interpolate between the original orientation and the orientation towards center, depending on the individual particle values.
FEATUREF18395Particle System: Reworked particle system forces. More uniform behavior inside and outside simulation loops, better way to map force effect to aux attributes. This is exposed through new property groups. The old property groups have been removed from the toolbox, but old scenes will still load and use them as before.
FEATUREF18613Particle System: The particle color was written incorrectly to the PBR base colors, depending on the selected workflow. For better color mapping we added the Particle Color material stage to manually select on which color channel the particle color values are mapped.
FEATUREF18614Particle System: Added new particle attribute - CreationTime.
FEATUREF18615Particle System: Added filter for particle renderer and particle link out: this allows to select a mesh per particle to be used in rendering and other effects.
FEATUREF18643Particle System: We added a property to manual set the time format for the FunctionalTimeOverride. You can choose now between milliseconds, seconds and frames.
FEATUREF18653Particle System: We added a switch to Repeater module to use the local coordinate system instead of world coordinates and a mirror function.
FEATUREF18675Particle System: In Remap module we added new modes to "Function": Steps, StepsClamped, StepsWrapped.
FEATUREF18990Particle System: Added PhaseSpeed property for various modules to ease the synchronization of particle rendering in a multi-machine Cluster. See documentation for details.
FEATUREF18625Render Setup Editor: A screen's resolution can now automatically be calculated from its size and pixel pitch.
FEATUREF18796Render2Disk: Added AVC/HEVC 4:2:2 encode on NVIDIA Blackwell / Intel Arc and later GPUs, and a "web optimized" option for MP4 based formats.
FEATUREF18979SDI: Added new quality mode for AJA external keying, which allows for HDR keying. This only works for modes that output on adjacent connectors, like 1+2 or 3+4. Many boards like Kona 3,4,5 which beforehand output on 1+3 and 2+4 now have the option to output on 1+2 and 3+4, the new quality mode is not available on the old 1+3 and 2+4 streams. The old mode was only 8 bit RGBA which is not good enough for HDR, the new mode is 10 bit YUV-K, which is fine. Internal keying is still limited to 8 bit RGBA.
FEATUREF15931ST2110: Added support for ST2110 on Deltacast 10G boards and Black Magic 10G / 100G boards.
FEATUREF18633Transitions / Templates / Designer: It is now possible to set the Animation In/Out alignment and the Offsets on custom Transitions scenes. See documentation for details.
FEATUREF18824Vx API: Added Hierarchy/Content Container and Output nodes the Ventuz.Intrinsic Api.
FEATUREF18839Vx API: Extended API to allow instancing all 'native' Ventuz nodes like Mover and Touch Button.
FEATUREF18981Vx API: Official release of the Ventuz Extension API (Vx) to code custom node, Designer UI extensions and services. This API also provides the possibility to programmatically build scenes. Note that this API is not available in the Community Edition. See documentation in the new project 'Ventuz Extension API Demo' for further details.
FEATUREF18904WebBrowser Node: Added "Open DevTools" button to node's Property Editor page.
FEATUREF18925WebBrowser Node: Added Chromium remote debugging port option to the Machine Configuration. See Web Browser node's documentation for details.

FEATUREF18176New Video Input option "Keep Alive": Ventuz will switch off video inputs that are not used by any Live Video node to reduce CPU load. For some users, this has been causing more trouble than it is worth: Switching can cause CPU load spikes that are worse than keeping things running, and the video stream is not immediately available when used, displaying color-bars for a few frames. Now there is an option that keeps unused video streams alive even when they are not used. Workarounds in the past include using the "Tracking Source" options that has keep-alive as a side-effect and placing unconnected live video nodes in the layout or root scene.

FEATUREF18206Nodes: Arrow node has a new property in "Anchor" mode and the new "Anchor on Sphere" mode: "TextureScale" scales the V coordinate of the texture along the shaft. If set to 0, the texture goes from 0 to 1 along the whole shaft, otherwise the texture is scaled along the length of the arc.

FEATUREF18227Particle System: Functional particle system time is derived from the Cluster Clock via a floating point conversion. This gets inaccurate after some time.
