Summary
This PR adds optional differentiable per-Gaussian masks to gsplat's classic
3DGS rasterizer and demonstrates them with the hard Gumbel-Softmax training
scheme from MaskGaussian (CVPR 2025).
The new gaussian_masks argument is optional, so existing callers and the
unmasked rendering path retain their current behavior. When supplied, each
mask multiplies its Gaussian's clamped base alpha inside the rasterizer. The
backward pass explicitly propagates the corresponding mask gradient, including
for hard-zero straight-through samples and saturated base alphas.
What changed
expose optional gaussian_masks: [..., N] through the public
rasterization() API and the Python/C++/CUDA wrapper stack;
implement forward and backward mask handling for packed and unpacked classic
3DGS rasterization paths;
keep the pure-PyTorch implementation aligned with the CUDA semantics;
add a mask configuration to examples/simple_trainer.py with the paper's
mask initialization, hard Gumbel-Softmax estimator, regularization, and
ten-sample periodic pruning schedule;
use deterministic score argmax for evaluation and PLY export;
preserve mask parameters and optimizer state across densification and
pruning;
document the API and add a resumable, paired 13-scene benchmark runner and
aggregation utility.
API and compatibility
gaussian_masks defaults to None. No mask tensors are allocated and no
additional per-intersection mask operations are performed in the existing
unmasked path. The initial implementation intentionally targets the classic
3DGS projection/rasterization path; unsupported combinations fail early with a
clear error instead of silently ignoring masks.
Validation
Local validation on an NVIDIA H200 with PyTorch 2.9.1 and CUDA 12.8:
core CPU suite: 570 passed, 890 skipped;
focused mask GPU tests: 10 passed;
full GPU suite: 2092 passed, 138 skipped, 18 xpassed; the four remaining
failures are confined to untouched 2DGS/eval3d test paths, while all focused
mask tests pass;
compression test with PLAS/torchpq/CuPy dependencies: passed;
clean-snapshot JIT build and an explicit AOT wheel build of the 3DGS CUDA
extension, followed by mask tests loaded from each new binary: passed;
Sphinx warnings-as-errors build, Black, clang-format, and git diff --check:
passed;
unmasked and masked end-to-end trainer smoke tests: passed.
Benchmark protocol
The formal comparison uses all 13 scenes reported by MaskGaussian:
Mip-NeRF360: bicycle, bonsai, counter, flowers, garden, kitchen, room, stump,
and treehill;
Tanks & Temples: train and truck;
Deep Blending: drjohnson and playroom.
Every trainer run uses 30,000 steps and seeds 42, 43, and 44. The beta matrix
contains 39 default and 39 mask runs; the alpha matrix adds another 39
mask runs while reusing the same paired baselines, for 117 formal runs in
total. Runs are paired by scene and seed, and method order alternates between
seeds to reduce order bias. Each run records PSNR, SSIM, LPIPS-VGG, active and
total Gaussian counts, checkpoint and PLY sizes, peak GPU memory, wall-clock
training time, and rendering FPS. Final statistics report paired
mask-minus-default changes with sample standard deviations.

comparisons, beta reduces active Gaussians in every scene and improves both
training time and rendering FPS in every scene:

Reproduction
With the datasets in the layout documented in
examples/benchmarks/mask_gaussian/README.md:
```
bash examples/benchmarks/mask_gaussian/run.sh
```
The runner resumes completed experiments and refuses to publish the final
summary unless all expected methods, seeds, and scenes are present with finite
metrics and their final checkpoint/PLY artifacts.
Scope
This PR does not add masks to 2DGS, 3DGUT, distributed rendering, or eval3d.
Those paths have different forward/backward contracts and should be handled in
separate changes with their own focused validation.
