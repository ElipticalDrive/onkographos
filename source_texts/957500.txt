Done when
Chunk meshes made only of quads share one static index buffer instead of each owning an index range.
The index memory of loaded chunks drops accordingly, visible in the memory report.
Meshes that contain non-quad geometry (generic shapes, special models) still work.
The world looks the same as before.
The rendering benchmark shows no higher frame time.
Notes: A quad needs the same six-index pattern (0 1 2 2 1 3), shifted by 4 per quad, so one shared buffer can serve every chunk through the vertex offset of the draw command. Today each chunk stores 6 four-byte indices per quad next to its 4 eight-byte vertices, about 40 % of its mesh memory. This task has to be settled together with how generic shapes (#98) are meshed, since they may not be quads. It also gets less valuable if merged faces (#177) shrink the meshes first, so measure the index share after that.
