Summary
Add a deterministic grid-mesh integration test for BVH query conservativeness and candidate uniqueness.
Add a second seeded 512-triangle nonuniform/degenerate corpus and 256 query boxes checked against an independent O(N) triangle-AABB overlap oracle; false positives are allowed, false negatives are not.
Add a dependency-free build/query benchmark for 10k / 100k triangles, with the 1M-triangle case opt-in.
Report repeated query batch-mean p50/p95/p99, mean candidate count, stable checksums, and a single build-time observation; build time needs repeated fresh-process measurements before comparison.
Document SAH, Morton/LBVH, dynamic refit, query-aware optimization, and multi-cluster meshlet evaluation gates, including provisional project targets.
Validation status
The test and benchmark code are committed to this PR head but have not been executed in this session.
No correctness pass or speedup is claimed until the targeted Cargo commands run against this exact head and their raw outputs are retained.
The benchmark remains a planar-grid timing workload; the seeded nonuniform corpus currently strengthens correctness coverage, not benchmark distribution coverage.
