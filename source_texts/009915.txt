This document describes a direct volumetric rendering method based on point primitives that can visualize medical image data in 3D without requiring specialized graphics hardware. The method renders each voxel as a point cloud colored based on pixel values. It allows basic 3D interaction and visualization of datasets like the Visible Human in real-time at around 15 frames per second for low-resolution images. Current work is optimizing the algorithm to skip hidden voxels for faster rendering and adding zooming functionality while maintaining performance without graphics hardware acceleration.
