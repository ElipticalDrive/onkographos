Description
Resolve USD mesh shading into Newton's existing triangle topology and per-vertex
normals, following the agreed renderer-neutral direction for 1.7. This replaces
the earlier subdivision-token propagation and viewer-specific flat-shading path.
Load authored normals on untextured visual meshes too, and canonicalize the
supported USD normal interpolation modes. Honor the caller's averaging or
vertex-splitting policy, including its angle threshold, for uniform normals.
Generate faceted normals for none/bilinear meshes without authored normals;
generate smooth normals otherwise, before UV expansion to avoid shading seams.
Preserve each component's normals when merging differently shaded USD meshes.
Include normals and UVs in viewer prototype identity without changing the
physics mesh hash.
Export final polygonal meshes with explicit normals through USD/RTX. Replace
stale shading and topology when a mesh name is reused. Do not reinterpret
triangulated meshes as source subdivision control surfaces.
Generate missing normals on RTX runtime mesh updates too, including topology
changes and point-only deformation; preserve explicitly supplied normals.
Keep source mass properties during visual expansion and avoid duplicate mesh
loading in the collider mass fallback. Document the topology change and the
load_normals=False geometry-only escape hatch in API docs and Towncrier.
No new public shading enum, raw USD token on Mesh, mutable viewer side channel,
or GL shader change is needed. Exact source USD topology/subdivision passthrough
is outside this PR; no separate 1.6.1 patch is included here.
Closes #4052

Bug fix
Steps to reproduce:
Import a shared-vertex USD terrain mesh with no authored normals and
subdivisionScheme = "bilinear".
Render it with ViewerGL or ViewerRTX.
Without this PR, sharp edges become smooth in GL, and the USD/RTX output falls
back to subdivision instead of retaining the terrain's intended appearance.
Minimal reproduction:
```
import numpy as np
from pxr import Usd, UsdGeom

import newton
import newton.usd

stage = Usd.Stage.CreateInMemory()
mesh = UsdGeom.Mesh.Define(stage, "/Terrain")
mesh.CreatePointsAttr([(0, 0, 0), (1, 0, 0), (0, 1, 0), (0, 0, 1)])
mesh.CreateFaceVertexCountsAttr([3, 3])
mesh.CreateFaceVertexIndicesAttr([0, 1, 2, 0, 3, 1])
mesh.CreateSubdivisionSchemeAttr(UsdGeom.Tokens.bilinear)

loaded = newton.usd.get_mesh(mesh.GetPrim(), load_normals=True, compute_inertia=False)
assert loaded.normals is not None
np.testing.assert_allclose(
    loaded.normals[loaded.indices], [(0, 0, 1)] * 3 + [(0, 1, 0)] * 3
)
```

# Description

Update Newton to commit `5ea82eef6f7911388025a8df6ccdb172e2fed286` and
MuJoCo/MuJoCo Warp to 3.14. Adapt checkpoint loading, actuator
selection, cable indexing, deformable registration, and visualization to
the changed interfaces. Workspace requirements and wheel metadata use
the same Newton revision.

## Runtime changes and their upstream causes

- **Actuator checkpoints — [Newton
#4347](newton-physics/newton#4347 Newton
removed TorchScript/dict loading. Export existing TorchScript MLP/LSTM
checkpoints to dynamic-batch `.pt2` during USD authoring, preserving
metadata and device placement. Users keep their existing paths and
actuator configurations.
- **Actuator parameters — [Newton
#4430](newton-physics/newton#4430 Selection
caches now belong to each view. Initialize the DOF mapping cache in
Isaac Lab's lightweight PhysX/OVPhysX view and borrow the updated
mapping methods. Remove its duplicate world-mask implementation.
- **Cable indexing — [Newton
#4124](newton-physics/newton#4124 Standalone
cables now include the free root joint. Its child is the root segment,
so the link array already contains every segment. Remove the separate
root binding and `link_count + 1`; use one child-body ID array for
writes. Masked writes and CUDA capture remain covered.
- **Deformable registration — [Newton
#4363](newton-physics/newton#4363 Mesh
builders now record their own surface/volume ranges. Remove Isaac Lab's
duplicate calls to the deleted private recording methods and read the
new records directly.
- **Live plots — [Newton
#4186](newton-physics/newton#4186 Read
histories from `PlotLogger`, their new owner. The old viewer-level
lookups left GL plots empty.
- **Contact visualization — [Newton
#4340](newton-physics/newton#4340 Replace
the removed `sensing_obj_transforms` alias with `sensing_transforms`.
- **Rendering references — [Newton
#4177](newton-physics/newton#4177 Refresh
four ANYmal images for authored mesh normals and USD sharp shading.
Pixel and SSIM tolerances are unchanged. Disabling the upstream
normal-loading change made both affected Newton cases pass against the
old references, confirming the cause.

All seven upstream changes are included in the pinned revision.

## Why the reset code can be removed

The rebind callback was introduced in [Isaac Lab
#4818](#4818), when hard
resets restarted simulation without first dispatching `STOP`. [Isaac Lab
#8027](#8027) subsequently
added `STOP` before model recreation. Assets are now invalidated and
their existing `PHYSICS_READY` initialization constructs new views,
data, and actuators. Rebinding the discarded data is redundant.

The extra callbacks run before asset initialization and access the
previous data's weak view reference. Newton #4430 removed global caches
that accidentally retained those views, exposing `ReferenceError` in
rigid objects and collections. Articulations avoided that error only
because the shared view registry retained their old views; a
joint-wrench sensor initialized first could then select a view of the
old model.

Remove these extra callbacks across rigid objects, collections,
articulations, cables, deformables, and MPM. Clear Newton's old registry
entries and per-model actuator/step hooks before rebuilding. Each data
instance binds once during construction. Remove the rebind-only proxy
branches, timestamp invalidation, actuator-executor rebinding, and
cleanup overrides. Keep articulation's model-init/post-step cleanup and
its separate joint/body ordering setup, which still have callers.

This preserves the existing hard-reset lifetime: reacquire `asset.data`
and its arrays after `sim.reset(soft=False)`. Soft resets retain the
current model and data. The direct `ArticulationData` test now retains
its `ArticulationView` explicitly, matching production ownership instead
of relying on Newton's former global cache.

Existing asset tests now exercise two real hard resets, state writes,
physics steps, fresh data containers, and stable callback counts.
Replace the synthetic array-swap/rebind test and its helper with this
lifecycle check; remove the actuator test whose only caller was the
deleted private rebind method. Extend the existing nested-root sensor
test to initialize the sensor first. This follow-up removes 200
production lines and 449 lines overall, without adding production files,
classes, or helpers.

PhysX and OVPhysX retain their existing reset lifecycle. Inline five
one-use proxy-initialization helpers into buffer creation, and remove
the unused OVPhysX articulation-data invalidation method and its
test-only assertions. Keep PhysX articulation's helper because ordering
changes call it again. This cleanup removes 64 production lines and 14
test lines (76 net lines including two changelog fragments), with no new
helpers or public API changes.
