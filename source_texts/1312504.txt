Describe the feature you would like to be added.
Paraview has the plugin Surface LIC that enables the use of 2D Line Integral Convolution (LIC) on any surface. LIC visualizes vector data as a smooth flow field with a uniform density. It is a great tool to generate pretty and detailed vector field visualizations.
For me personally it is the main feature that currently sets ParaView apart from pyvista.
Links to VTK Documentation, Examples, or Class Definitions.
LIC is already implemented in Paraview through VTK. VTK already has all of the necessary functionality:
vtkLineIntegralConvolution2D
vtkSurfaceLICMapper
vtkSurfaceLICInterface
vtkSurfaceLICHelper
vtkSurfaceLICComposite
vtkLICRandomNoise2D
vtkLICRandomNumberGeneratorInterface
Pseudocode or Screenshots
The way to use LIC could be something like this:
```
import pyvista as pv

vector_data = pv.read(vector_data_mesh_path)

p = pv.Plotter()
p.add_mesh(vector_data, representation="LIC", representation_args=representation_args)
p.show()
```
And the results would be similar to the ones in the ParaView wiki.

CompositeSurfaceLICMapper class
plotting/composite_mapper.py
```
class CompositeSurfaceLICMapper(
    vtk.vtkCompositeSurfaceLICMapper,  # type: ignore
    CompositePolyDataMapper,
):
    def __init__(
        self, dataset=None, theme=None, color_missing_with_nan=None,
    ):
        """Initialize this composite mapper."""
        super().__init__(
            dataset,
            theme,
            color_missing_with_nan,
            interpolate_before_map=False # Interpolation before map breaks LIC
        )

        self._lic_interface = self.GetLICInterface()
        self._set_default_lic_parameters()

    def _set_default_lic_parameters(self):
        """Set default parameters for the Line Integral Convolution (LIC) interface."""
        self.number_of_steps = 20
        self.step_size = 0.5
        self.normalize_vectors = 1
        self.enhanced_lic = 1

        # Surface LIC rendering
        # self.color_mode = self._lic_interface.COLOR_MODE_MAP
        # self.enhance_contrast = self._lic_interface.ENHANCE_CONTRAST_LIC
        self.map_mode_bias = 0.25
        self.low_lic_contrast_enhancement_factor = 0.3
        self.high_lic_contrast_enhancement_factor = 0.3
        self.anti_alias = 0

        # Surface LIC parallelization
        self.composite_strategy = 2  # Balanced

    @property
    def number_of_steps(self):
        return self._lic_interface.GetNumberOfSteps()

    @number_of_steps.setter
    def number_of_steps(self, steps):
        self._lic_interface.SetNumberOfSteps(steps)

    @property
    def step_size(self):
        return self._lic_interface.GetStepSize()

    @step_size.setter
    def step_size(self, size):
        self._lic_interface.SetStepSize(size)

    @property
    def normalize_vectors(self):
        return self._lic_interface.GetNormalizeVectors()

    @normalize_vectors.setter
    def normalize_vectors(self, normalize):
        self._lic_interface.SetNormalizeVectors(normalize)

    @property
    def enhanced_lic(self):
        return self._lic_interface.GetEnhancedLIC()

    @enhanced_lic.setter
    def enhanced_lic(self, enhanced):
        self._lic_interface.SetEnhancedLIC(enhanced)

    @property
    def lic_vector(self):
        return self.GetInputArrayToProcess(0, 0, 0, 0)
    
    @lic_vector.setter
    def lic_vector(self, vector):
        self.SetInputArrayToProcess(0, 0, 0, 0, vector)
```

Add LIC style property using surface representation
```
@style.setter
def style(self, new_style: str):  # numpydoc ignore=GL08
    new_style = new_style.lower()

    if new_style == 'wireframe':
        self.SetRepresentationToWireframe()
        if not self._color_set:
            self.color = self._theme.outline_color  # type: ignore
    elif new_style == 'points':
        self.SetRepresentationToPoints()
    elif new_style == 'surface' or new_style == 'lic':
        self.SetRepresentationToSurface()
    else:
        raise ValueError(
            f'Invalid style "{new_style}".  Must be one of the following:\n'
            '\t"surface"\n'
            '\t"wireframe"\n'
            '\t"points"\n'
        )
```

With the subplots it seems like there might be a bug with the vtkCompositeSurfaceLICMapper which means all subplots are actually being rendered in the same origin subplot. Looking into the mapper it appears to perform the LIC operation on a frame buffer and then copy back to the screen.
https://github.com/Kitware/VTK/blob/master/Rendering/LICOpenGL2/vtkSurfaceLICInterface.cxx#L581
```
import pyvista as pv
from pyvista import examples

p = pv.Plotter(shape=(1,2), border_width=3)

p.subplot(0,0)

hills = examples.load_random_hills()
p.add_mesh(
    pv.MultiBlock([hills]),
    style="lic",
    lic_vector="Normals",
    scalars="Elevation",
    cmap="terrain",
    show_scalar_bar=False,
)

p.add_mesh(
    pv.Cone(center=(0, 0, 0)), color="red"
)
p.add_text(
    "Plot 1",
)

p.subplot(0,1)

p.add_mesh(
    pv.MultiBlock([hills.rotate_z(45)]),
    style="lic",
    lic_vector="Normals",
    scalars="Elevation",
    cmap="terrain",
    show_scalar_bar=False,
)

p.add_mesh(
    pv.Cone(center=(0,1,0)), color="blue"
)

p.add_text(
    "Plot 2",
)

p.link_views()

p.show()
```
