# Voxel Hashing Revisited
## What is this repo for
This repo is created to make the voxel hashing capable of running anywhere without Visual Studio. We prepare to support ubuntu, jetson, windows, and anywhere else with `NVCC` & `GCC`. We intend to do raycasting without shader settings. (Do the pseudo-shading with cuda kernel to create a realistic raycasting result.)
## Original Voxel Hashing
We translate the original code of https://github.com/niessner/VoxelHashing to support compiling on UBUNTU.
## Traits
1. we do not use shader and visualization for now, which will be done for future.
2. we do not support `ICP` & `LOOP CLOSURE` & `RELOCALIZATION` as well, the pose is used as an input to the system, in the format of c2w(camera to world). We tested on multi-dataset like `REPLICA` & `TUM-RGBD`, even tested with the `ORB-SLAM2` RGBD mode with kinect on real world indoor scene.
3. If you want a whole system which capable of running without pose on RGBD input, please refer to BUNDLE FUSION, which is also a great work done by voxel hashing team. https://github.com/niessner/BundleFusion, and Ubuntu version: https://github.com/FangGet/BundleFusion_Ubuntu_Pangolin (but this repo does not support ray cast for now.)
## How to use
```shell
# first enter the repo's directory
mkdir build && cd build
cmake .. && make
./test_voxel_hashing /path/to/dataset/ /path/to/config.json
```
