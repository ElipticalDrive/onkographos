This WIP starts migrating to a texture atlas. The first module (written by
hand, artisanally, the way that's the most fun) is an implementation of a strip
packing algorithm. I have some tests that I will push up shortly.
The next steps:
Add tests for this
Figure out what to do if we need multiple texture atlases
Use a texture atlas or multiple texture atlases in the volume rendering by supplying a single texture and using a ivec3 uniform to provide lookups.
I may completely remove or decline the bindless texture PR, but it might also
be worthwhile to leave it and use it in the case that we need multiple
atlases. So, it should probably go in, and then this should build on it.
