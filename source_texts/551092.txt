Overview
Converts BlueRush from a 2D grid simulation into a true 3D voxel flood simulation, and adds column-fill placement so the Wall and Object tools build down to the floor in a single click.
3D voxel simulation (Sessions 8–12)
Grid3D (simulation3d.rs) — width × height × depth voxel grid, gravity-biased 6-direction water diffusion, 3D depth-pressure, and 3D object physics.
Face-culled voxel rendering (render.rs) — one mesh per cell category, emitting only faces adjacent to transparent cells; rebuilt on a GridDirty message.
Perspective orbit camera (camera.rs) — scroll to change orbit distance, middle-drag to pan.
Active-layer editing — ActiveLayer + Layer −/+ UI; cursor ray-casts to the active Y plane.
3D level format — LevelData/CellPlacement gain optional depth/z; levels/valley-flood.json is a 40×20×40 Rock bowl with a corner Spring. Old 2D levels still load (depth defaults to 1).
Persistence — SaveData round-trips depth.
Column-fill placement tools (Session 13)
Wall → drops a solid, water-tight Cell::Wall dam from the active layer down to the floor.
Objects (200–5000 kg) → a stack of Cell::Object(w) filling the empty (Air) column so blocks rest on the floor instead of floating.
Spring / Drain / House / Erase → unchanged (single cell at the active layer).
Extracted a generic column_changes(grid, x, z, active_layer_y, can_fill) pure function (caller supplies the fillable predicate and fill cell), with wall_column_changes() as a thin wrapper. handle_input placement restructured into a clean match.
Testing
33/33 unit tests pass, including 3D simulation conservation/pressure/buoyancy tests, wall + object column-fill tests (fill, clamp, bounds, skip-fixtures), and render-pipeline tests proving a filled column builds a tall pillar mesh (244 verts) vs a lone cube (24 verts).
cargo build + cargo test clean; app verified interactively via cargo run.
