Migrated from mors119/copc-adapter#337. This repository owns Tiles implementation. Original discussion remains linked for provenance.
Compatibility rule: copc-tiles depends on a pinned/verified public copc-adapter contract; the adapter must not depend on copc-tiles. Never import adapter private files across repository boundaries.
Goal
Implement standard 3D Tiles 1.1 implicitTiling with OCTREE, bounded subtree depth, availableLevels and deterministic subtree/content URI templates.
Implementation and acceptance criteria
Implement standard 3D Tiles 1.1 implicitTiling with OCTREE, bounded subtree depth, availableLevels and deterministic subtree/content URI templates.
Produce tile/content/child-subtree availability bitstreams, correct Morton indexing and binary subtree representation, including sparse octree and empty-content cases.
Do not mistake childrenComplete === false for absent children. Load required hierarchy pages before declaring availability; do not force an unbounded full-tree preload.
Test hand-authored fixtures for root/leaf, sparse siblings, subtree boundaries and deep levels with official validator, network-request counts and memory bounds.
Dependencies
T5
Shared architecture contract (applies to all T1–T12 issues; adapted for separate repository)
Preserve existing @frillab/copc-adapter/cesium, /three, default A cache, published APIs, Direct renderer behavior and performance. Never mutate the source COPC or require preconversion.
Scope: original COPC point chunks → standards-compliant 3D Tiles 1.1 with glTF POINTS. Out of scope: surface/mesh reconstruction, textures, proprietary tile formats, engine forks and replacing the default renderer.
Reuse the Core hierarchy, Range, LAZ decode and CRS transform pipeline. Do not run Direct NodeSelector in the Tiles path: standard Tiles renderers own tile selection and LOD.
Keep PreparedPointData stable (Source/Geographic/ECEF Float64 and requested point attributes). Support default A and experimental E cache layouts by read-only views of existing buffers; never silently discard available precision/attributes.
Performance blocker: basic Tiles encoding must not require compactEPointCacheNodeToPreparedPointData() or cachedPointDataToPreparedPointData() and thereby trigger unnecessary ECEF→Geographic conversion or 24 bytes/point materialization. No unnecessary Source/Geographic recomputation, full-tree point decoding, duplicate LOD pipelines, or renderer dependencies inside Core. Measure genuinely necessary tile-local allocation and GLB serialization separately.
Fail or explicitly document unsupported precision, CRS/vertical datum, missing attributes and 64-bit metadata representation. Do not silently narrow values or claim conformance before validation.
Keep Tiles functionality in this independent @frillab/copc-tiles package. @frillab/copc-adapter must not import or depend on this package. Reuse only approved public adapter contracts; coordinate missing APIs in a separately reviewed adapter PR.
Upstream adapter references (not files in this repository): packages/core/copc/types/copc.ts, packages/core/point/preparedPoint.ts, packages/core/point/compactEPointCache.ts, packages/core/copc/hierarchy/types.ts, packages/core/copc/backend/types.ts.
PR gate: independently reviewable scope, targeted quantitative validation, all affected Direct regressions passing, and no stable API declaration before acceptance. Use English for issues/PRs.
