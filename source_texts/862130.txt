Description
Added CPU and CUDA versions of the simple voxel noise filter, documentation/schema updates as well. This implementation is based on the polar voxel outlier filter, removed all the diagnostics and visibility features for this implementation also found in autoware_pointcloud_preprocessor.
The CPU version in autoware_pointcloud_preprocessor, filters noise by removing voxels that match noise conditions based on point count, average intensity, and optionally return-type classification. It supports both PointXYZIRC and PointXYZIRCAEDT, and can also publish a debug noise pointcloud.
The CUDA version in autoware_cuda_pointcloud_preprocessor provides the same polar voxel noise filtering behavior with GPU acceleration. It uses the same core parameters and filtering concept as the CPU implementation, but runs the voxelization and filtering path on CUDA. It also supports both PointXYZIRC and PointXYZIRCAEDT and optional noise cloud publishing.
This PR adds schema and documentation.

[comment]
It may be better to add destructor to free cuda memory.
```
CudaPolarVoxelNoiseFilter::~CudaPolarVoxelNoiseFilter()
{
  // Wait for pending asynchronous operations
  if (stream_) {
    cudaStreamSynchronize(stream_);
  }

  // Free allocated device memory
  if (primary_return_type_dev_) {
    cudaFreeAsync(primary_return_type_dev_.value().return_types, stream_);
  }

  // Destroy memory pool and stream
  if (mem_pool_) {
    cudaMemPoolDestroy(mem_pool_);
  }
  if (stream_) {
    cudaStreamDestroy(stream_);
  }
}
```

New sensing component autoware::near_weak_return_filter::NearWeakReturnFilterComponent. A point is dropped
only if ALL hold: its own `distance` field (range from the sensor) < max_distance, its intensity <=
max_intensity, and at most max_neighbors other returns lie within neighbor_radius_ratio x its range (3D):

near-range noise returns are scattered. The idea (sparse AND weak = noise) is upstream's polar voxel noise
filter (autoware_universe autowarefoundation#12496, simple mode), here per point and only near the sensor (upstream drops
every point outside its radius band, so it cannot be a near-range gate as is). A cloud without
x/y/z/intensity/distance is passed through unchanged; a cloud with nothing to drop is republished as is.
