# CycleGAN Image-to-Image Emoji Translation

This project explores emoji image generation and cross-domain emoji style translation with GAN-based models. It trains a baseline Vanilla GAN for emoji synthesis and a CycleGAN for unpaired image-to-image translation between Apple-style and Windows-style emoji images.

The repository includes the training code, Apple/Windows emoji datasets, saved checkpoints, loss plots, and visualized outputs from the trained models. See [`description.pdf`](description.pdf) for the original project description/report.

![Transformer](doc/image/transfer.png)

## Highlights

- Vanilla GAN baseline for generating Apple-style emoji images from random noise.
- CycleGAN model for bidirectional translation:
  - Apple emoji -> Windows emoji
  - Windows emoji -> Apple emoji
- Cycle-consistency loss to preserve emoji content while changing visual style.
- Training logs and result images saved for comparison.

## Dataset

The dataset is organized by emoji vendor/style:

| Split | Domain | Images |
| --- | --- | ---: |
| Train | Apple | 2,270 |
| Train | Windows | 2,014 |
| Test | Apple | 100 |
| Test | Windows | 100 |

Images are loaded from `workspace/emojis`, resized to `32 x 32`, converted to RGB tensors, and normalized to `[-1, 1]`.
