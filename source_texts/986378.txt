This PR introduces a suite of creative features to voxelizer-rs.
Users can now generate hollow shell structures (--hollow), map a procedural swirling flow field to the particles (--fiber), and select cuboid regions for custom phases (--phase-box).
Furthermore, it adds visually appealing exports like SDF heatmapping for PLY point clouds (--ply-heatmap), and full mesh generation for Minecraft-style OBJ models (--obj-cubes).

Correct cube face winding for OBJ export
When --obj-cubes is used, this bottom face is emitted as v_idx, v_idx + 1, v_idx + 2, v_idx + 3, which gives it a +Z normal even though the outside of the bottom face is -Z. The back and left faces below have the same inward winding pattern, so OBJ viewers/importers that honor face winding or back-face culling can render those sides incorrectly or compute inverted normals. Reorder the affected face indices so all cube normals point outward.
