Motivation
Introduce a workspace crate that provides Phase 1 data primitives for voxel geometry without any rendering or mesh logic.
Provide a compact, deterministic encoding for per-voxel corner offsets and a packed material identity suitable for downstream contouring.
Represent a standard 256³ cluster with a sparse storage strategy so most uniform clusters are cheap to represent.
Keep the implementation simple and safe (no unsafe, std-only) while leaving a clear TODO for the intended octree+dense-leaf refactor later.
Description
Add new workspace crate crates/flicker-voxel with #![deny(unsafe_code)], module-level docs describing the right-handed, Y-up coordinate convention and sparse-storage rationale, and public re-exports at the crate root.
Implement CornerVector with byte encoding/decoding (from_components, from_bytes, to_components, to_bytes), clamping on encode, a DEFAULT center vector, and equality based on encoded bytes.
Implement Material as a packed 12/12/8 u32 with new(primary, secondary, blend) -> Option, from_raw, accessors, EMPTY, and Hash/Default support.
Implement Voxel as { corner: CornerVector, material: Material } with DEFAULT and accessors.
Implement LocalCoord validated constructor for cluster-local coordinates and constants CLUSTER_DIMENSION = 256 and CLUSTER_VOXEL_COUNT = 256³.
Implement Cluster as a base Voxel plus a HashMap<LocalCoord, Voxel> of overrides, with empty(), uniform(base), infallible get, set that removes overrides matching the base, override_count, is_uniform, and an overrides() iterator; the overrides field contains a TODO noting the future octree+dense-leaf replacement.
Add comprehensive in-module tests for corner_vector, material, voxel, LocalCoord, and Cluster, including a realistic dense sphere override test to exercise the sparse store.
Testing
Ran cargo fmt --check and the code is formatted cleanly.
Ran cargo build -p flicker-voxel which succeeded without errors.
Ran cargo test -p flicker-voxel and all tests passed (20 unit tests, 0 failures).
Ran cargo clippy -p flicker-voxel -- -D warnings and the crate is clean of lints under the workspace conventions.
