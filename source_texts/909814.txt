Generate one unified voxelized scene hashmap that contains:
XYZ coordinate to Model ARC, possibly with bounding box
Then generate on the GPU with ONLY the viewable parts/frustum culling:
Density (occupancy)
by Bounding Box or similar technique
Material properties (PBR parameters)
Don't think that is needed
Surface normals [?]
Unsure if this will be needed either
Generate the light volume map through ray marching:
Each light source to voxel
Note: Light frustum should be slightly bigger than scene voxel frustum to support light sources outside of view bleeding into the scene
Accumulates light contribution based on scene voxel data (like occupancy)
In the PBR pipeline:
Use light volume for illumination
Combine with regular PBR calculations
Note: There might be a required darkening step before IBL to produce better shadows
For Model updates:
Update affected region in scene voxel volume
Mark affected region as dirty
Reprocess all lights for that region only
For Light updates:
Only reprocess the changed light
Add/subtract its contribution from final light volume
No need to recalculate other lights
PBR Material Shader: Using Futures Lighting
```
@group(2) @binding(0) var scene_volume: texture_3d<f32>;
@group(2) @binding(1) var light_volume: texture_3d<f32>;
@group(2) @binding(2) var volume_sampler: sampler;

fn sample_voxel_lighting(world_pos: vec3<f32>) -> vec3<f32> {
    // Convert world position to voxel space
    let voxel_pos = world_pos * config.voxel_scale;
    
    // Sample light volume with trilinear filtering
    let light = textureSample(light_volume, volume_sampler, voxel_pos);
    
    return light.rgb;
}

fn calculate_pbr_lighting(
    normal: vec3<f32>,
    world_pos: vec3<f32>,
    metallic: f32,
    roughness: f32,
    albedo: vec3<f32>
) -> vec4<f32> {
    // Get pre-computed voxel lighting
    let voxel_light = sample_voxel_lighting(world_pos);
    
    // NOTE: This is IBL! We actually don't require any light information in our shader other than the light volume from futures lighting and IBL!
    // Combine with regular PBR calculations
    let direct_light = calculate_direct_lighting();
    let indirect_light = calculate_indirect_lighting();
    
    return vec4<f32>(
        (direct_light + indirect_light + voxel_light) * albedo,
        1.0
    );
}
```
Calculating lights for voxel lighting
```
struct Light {
    position: vec4<f32>,    // w component stores light type (0=point, 1=directional, 2=spot)
    color: vec4<f32>,       // rgb = color, a = intensity
    direction: vec4<f32>,   // xyz = direction, w = radius/range
    properties: vec4<f32>,  // x = spot angle, y = spot blend, z = falloff
}

fn calculate_light_contribution(light: Light, voxel_pos: vec3<f32>, normal: vec3<f32>) -> vec3<f32> {
    let light_type = u32(light.position.w);
    var contribution = 0.0;

    switch light_type {
        // Point Light
        case 0u: {
            let to_light = light.position.xyz - voxel_pos;
            let distance = length(to_light);
            let normalized_distance = distance / light.direction.w;
            contribution = (1.0 - min(normalized_distance, 1.0)) * light.properties.z;
        }
        // Directional Light
        case 1u: {
            let cos_angle = max(dot(normal, -light.direction.xyz), 0.0);
            contribution = cos_angle * light.color.a;
        }
        // Spot Light
        case 2u: {
            let to_light = normalize(light.position.xyz - voxel_pos);
            let cos_angle = dot(to_light, light.direction.xyz);
            if (cos_angle > light.properties.x) {
                contribution = smoothstep(
                    light.properties.x,
                    light.properties.x + light.properties.y,
                    cos_angle
                );
            }
        }
        default: {}
    }

    return light.color.rgb * contribution;
}
```
