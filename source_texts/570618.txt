Refactors monolithic main.cu into modular components and adds optional OptiX integration for RTX hardware acceleration (2-10x speedup on supported GPUs).
Code Organization
core/ - Application state management
cuda_utils.cuh - Error handling, safe allocations
app_config.cuh - Centralized configuration
render_state.cuh, scene_state.cuh, radiosity_state.cuh, ui_state.cuh - State management
rendering/ - Integrators
path_tracer.cuh - Path tracing with MIS
radiosity_renderer.cuh - Radiosity solver
ui/ - ImGui windows
controls_window.cuh, grid_window.cuh
OptiX Integration
accel/ - Hardware acceleration
optix_types.cuh - Launch params, SBT records, state structures
optix_wrapper.cuh - Context/pipeline management with stub fallback
optix_programs.cu - Ray generation, hit/miss programs
Build System
```
# Standard build
cmake -B build -S .

# With OptiX (RTX acceleration)
cmake -B build -S . -DENABLE_OPTIX=ON -DOptiX_INSTALL_DIR=/path/to/optix
```
Auto-detects OptiX SDK
Multi-arch support: sm_60, sm_70, sm_75, sm_80, sm_86
Post-build asset copying
