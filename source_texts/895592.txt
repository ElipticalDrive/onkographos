Normalize the Ashikhmin-Shirley NDF at grazing angles
When either anisotropic roughness approaches 1.0, which both the Inspector and scene format permit, nu/nv approach zero and this expression becomes approximately 1 / (2π * NoH^4). It therefore diverges toward grazing angles instead of remaining normalized (NoH = 0.1 yields about 1591), producing severely over-bright Ashikhmin-Shirley highlights. Use the normalized Ashikhmin-Shirley distribution and apply the same correction to the CPU reference implementation in Brdf.h.

Rebuild the anisotropic frame around the mapped normal
For textured Ashikhmin-Shirley materials with a non-neutral normal map, tangent and bitangent were constructed around geometricNormal, but the query uses the mapped N. Passing that old frame here means it is no longer orthogonal to the shading normal, so halfTangent is not a valid tangent-space projection and the anisotropic lobe changes shape and orientation with normal-map perturbations. Reproject the tangent onto N and rebuild the bitangent before evaluating this branch.
