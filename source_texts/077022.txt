Depends on CesiumGS/cesium-native#1480 getting merged first.
The above mentioned PR makes a number of changes to SPZ decoding. This PR lets Cesium for Unreal gaussian splats work correctly with those changes.
Many of these changes have to do with supporting the other supported component types for KHR_gaussian_splatting attributes. The newly added flag forceFloatAccessors is used, as Cesium for Unreal will convert everything to floats anyways, so it makes sense to receive the SPZ data directly instead of running it through a conversion in the middle. However, you can comment out the line options.contentOptions.spzDecoderOptions.forceFloatAccessors = true to verify that these other component types are supported. Support for these is necessary for supporting non-SPZ gaussian splat glTFs, which will not be run through this conversion process.
