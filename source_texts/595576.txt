Implemented new features to allow users to generate hollow voxel shells and apply 3D infill structures (like gyroids and grids) to the interior, as well as updating the CSV, PLY, and VTK exporters to emit the SDF value.
Hollowing (--shell-thickness): Evaluates the SDF to detect the deep interior of an object and carve it out, leaving behind a solid outer boundary.
Infill (--infill-pattern & --infill-scale): Supports "gyroid", "grid", and "lines" internal structural support patterns generated mathematically across the Euclidean grid.
Exporters: SDF is now visible in the standard output formats so users can visualize distance fields.
Tests: Added test_hollow_shell and test_infill_grid to guarantee logic and parity.

Reject invalid infill scales
When a user passes --infill-scale 0 (or NaN), the value is accepted and used as the pattern scale, causing gyroid math to produce non-finite values and grid/lines to evaluate rem_euclid(0.0) as NaN, so all requested interior support is silently omitted and the output is just the hollow shell. Add finite, positive validation before using the scale.
