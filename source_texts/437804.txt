Volumetric PT for Homogeneous Volumes
Color vPT(x, ω)
tmax = nearestSurface(x, ω)
t = -log(1 - randf()) / σt
// Sample free path
if t < tmax: // Volume interaction
x += t * ω
pdf_t = σt * exp(-σt * t)
(ω’, pdf_ω’) = samplePF(ω)
return Tr(t) / pdf_t * (σa * Le(x, ω) + σs * PF(ω, ω’) * vPT(x, ω’) / pdf_ω’)
else: // Surface interaction
x += tmax * ω
Pr_tmax = exp(-σt * tmax)
(ω’, pdf_ω’) = sampleBRDF(n, ω)
return Tr(tmax) / Pr_tmax * (Le(x, ω) + BRDF(ω, ω’) * vPT(x, ω’) / pdf_ω’)
