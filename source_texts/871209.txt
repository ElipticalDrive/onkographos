Motivation
Remove visible artifacts (concentric rings, chunk seams and unstable hits) caused by fragile AABB tests and DDA/rope traversal in voxel ray tracing.
Improve grass/leaf probing and cloud/godray compositing so small features and sun disc attenuation behave consistently across LODs.
Make shadow and fog computations more robust to avoid incorrect occlusion from special voxels and numerical edge cases.
Description
Reworked AABB slab code to compute a reusable CubeSlab and moved normal selection into cube_hit_normal_from_slab, and updated the public API via aabb_hit_normal_inv to use the slab reuse pattern (src/shaders/ray/aabb.wgsl).
Rewrote chunk tracing to use a macro 3D-DDA, tightened leaf traversal and rope stepping, added macro-cell early-out and robust stepping/epsilon handling, and improved grass-on-air probing logic (src/shaders/ray/chunk_trace.wgsl).
Improved grass and leaf handling: stable cell picking, LOD selection from ray distance (grass_lod_from_t), SDF trace LODs, and a safer try_grass_slab_hit that avoids inside-voxel artifacts (src/shaders/ray/grass.wgsl, src/shaders/ray/leaves.wgsl).
Fixed cloud/sky/godray/composite interactions and sampling spaces so sun-disc attenuation is driven by the visual cloud transmittance, godray sampling uses full-res UVs, and composite tonemapping/dither is applied stably (src/shaders/ray/clouds.wgsl, src/shaders/ray/godrays.wgsl, src/shaders/ray/composite.wgsl, src/shaders/ray/sky.wgsl).
Hardened fog and shadow code: removed problematic guards, made sun_transmittance_geom_only DDA stable, treated MAT_LIGHT/special voxels correctly for visibility, and added a distance gate for displaced-leaf shadow testing (src/shaders/ray/fog.wgsl, src/shaders/ray/shadows.wgsl).
Miscellaneous stability and quality fixes in shading and wind helpers: simplified AO sampling, normalized spec/normal calculations, and minor cleanup in svo_query and wind helpers to avoid integer wrap and edge cases (src/shaders/ray/shading.wgsl, src/shaders/ray/svo_query.wgsl, src/shaders/ray/wind.wgsl).
Testing
No automated tests were executed as part of this change; only source edits were made and committed (no shader compile or runtime validation run in CI during this PR preparation).

Reintroduce parallel-axis handling in slab test
The new cube_slab_inv blindly multiplies by inv for all axes; when a ray is parallel to an axis, safe_inv yields BIG_F32, so t0/t1 become huge even if the origin lies outside the slab. That turns obvious misses into apparent hits and can make aabb_hit_normal_inv report intersections for parallel rays that never enter the box. You need the old parallel-axis containment check (or an equivalent mask) to reject those cases.

Clamp macro coords in signed space to avoid wrap
Here floor(lp / cell) is cast to u32 before clamping. If lp is negative (e.g., when a nudged query is just outside root_bmin), the cast wraps to a huge unsigned value and the clamp snaps it to MACRO_DIM - 1, not 0, so macro occupancy queries hit the wrong cell at chunk boundaries. The previous signed clamp avoided this; this should be clamped as i32 before converting to u32.
