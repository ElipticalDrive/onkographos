Owner
Region construction used separately allocated path and center buffers, a separately owned region map and an unused allocated table. Mesh serialization duplicated bulk vector I/O by component count and exposed raw pointer/count and void-pointer APIs through the octree header.
Own region paths, GLM centers and the provisional remap in vectors. Own the region map as a value and move it into the runtime pre-tree. Remove the unused table. Use common box center, distance and region-cell overlap math, retaining weighted-center float rounding and existing merge/rekey order.
Consolidate six bulk vector readers/writers and their overload wrappers into local typed mesh-record handling. Reads accept counted spans. Writes share typed byte-counting and release storage after successful I/O. Preserve integer-write exceptions, vector diagnostics, field order and disk record widths; integer triples no longer pass through a float-vector reinterpret cast. GLM runtime vectors still convert from explicit asset records. Remove the mesh loader's dependency on the octree header.
Share validated counted permutations between polygon and vertex reindexing. Reorder all GLM attributes, reference tables, shade groups and active polygons through one permutation record; share corner remapping while preserving external UV references and shade canonicalization. Invalid permutation sizes, repeated indices and out-of-range indices fail before table mutation. Consolidate six finite-channel validation loops while retaining each diagnostic.
Share renderer drain synchronization across immediate/sorted submission, buffer reset and statistics reset. Preserve owner-only device submission, registry-lock release while waiting, submission order and cross-thread statistics policy. Return fully initialized native pixel formats through one component-conversion implementation. Generate UV/flat expansion sort keys through one counted-span path and use std::bit_cast for depth ordering.
Use one model-instance render scope for ordinary, linked-mesh and 2D draws. The scope restores the model-view stack and exclusion mask on successful and failed draws, retaining 2D exclusion behavior. Return animated positions, vertex normals and polygon normals as a named borrowed frame record; keep main/highlight channel routing distinct. Software culling takes counted normal spans and rejects incomplete input before changing renderer state.
Replace material vertex splitting’s repeated initialization and linear candidate scans with one source/material lookup and owned temporary records. Preserve first-face order, kind and UV selection. Remove the fixed four-times-input scratch limit, skip unused source vertices, and commit polygon pointers only after allocating the final contiguous table. Keep progress reporting in the level-build caller so geometry processing has no startup-UI dependency. A regression exercises 80 material groups per vertex and repeated material faces.
Stacked on #156, which is cut at the conditional-channel/path-cell batch. Cut at the material vertex-splitting batch; further work is stacked separately.
Validation: affected native targets build; all 52 geometry cases and the renderer ownership suite pass, including multi-member region merging and weighted centers. The serialization suite passed for the I/O batch with byte-for-byte checks across sunlight/material configurations and injected-failure ownership checks. Changed C++ sources pass direct include checks with assertions enabled. The preceding renderer-dispatch head passed full Linux and ASan tests; its include CI found a duplicate <cassert> include, now removed. Current drawing sources pass the full configured clang-tidy checks locally. The preceding head passed Linux, ASan and include-hygiene CI. The material-splitting batch passes the native build, all 52 geometry cases and full configured clang-tidy checks; CI is submitted for its final head.
Identical relaxed experimental semantic scans: region construction retains 8 candidates, with source tokens falling from 23648 to 23327; mesh I/O falls from 8 to 6 candidates (4.6% to 3.7%), with tokens falling from 29018 to 28725. The renderer mesh/modeler/vertex-pipe family falls from 6 to 3 candidates (7.0% to 1.9%), with source tokens falling from 26722 to 26513. The renderer-dispatch family falls from 14 to 10 candidates (5.1% to 3.7%); existing concurrent-borrower, owner-thread, mixed-pass UV and sorting regressions pass. Animation/model-instance scans fall from 5 to 4 candidates (3.4% to 2.8%); new regressions cover frame counts and invalid indices, short normal spans, and successful/failed aligned and unaligned draws. Candidate pairs overlap and are not independent fix counts. Different polygon-validation boundary policies remain separate. The legacy uv run wiz8 pr-check entrypoint remains unavailable (ModuleNotFoundError: wiz8decomp.cli).
The matching engine/render-math semantic scan falls from 8 to 7 candidates (5.4% to 5.2%), with source tokens falling from 21554 to 21139.
