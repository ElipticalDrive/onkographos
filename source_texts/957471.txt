🎯 Why: Per-vertex noise generation (Perlin/Value/FBM) is incredibly expensive due to millions of inner loop function calls (like Math.floor, lerp, grad, and fade).
💡 What: Flattened and unwrapped the math logic inside Noise.noise and CLOUD_NOISE.fbm2D. Replaced dynamic switch/branching for gradient vectors with static Float64Array lookups initialized once, removing object creation and reducing V8 execution overhead.
📊 Impact: ~45% reduction in execution time for both Noise.fractal (131ms -> 70ms) and CLOUD_NOISE.fbm2D (105ms -> 96ms). This significantly accelerates terrain and cloud generation.
🔬 Measurement: Run pnpm test:perf to verify the new generation times pass the performance budgets.
