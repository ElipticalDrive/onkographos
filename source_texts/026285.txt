Fire today = blackbody emissive + ray-traced fire lights + speckle + gas-medium smoke — physical, but with no flame structure (no tongues, vortices, coherent lean/plume). This arc adds it: a render-only 2D stable-fluids VFX sim (Ignitement-style: GLSL fragment ping-pong over textures — no compute, no CUDA↔GL interop needed, matching our stack), one-way fed by the real fire intensity, wind (m/s), and temperature fields, rendered through the existing blackbody + advected-noise machinery.
Plan: docs/fire_vfx_plan_2026-08-24.md (arc F0-F4, reuse inventory, constraints). Survey: docs/Breach_Fire_Rendering_Summary.md. July research pass: docs/fire_rendering_research.md (its Q2/Q3 items - curl noise, particles riding real wind - land inside this arc).
Decisions locked 2026-08-24 (Erik; revisitable at F0):
Whole-map fixed-resolution VFX grid, M texels/tile as quality knob (~8 desktop / 4 laptop). Camera-following domain (Ignitement's windowing) = v2, trigger: real maps outgrow the whole-map budget (all current maps are test maps; real sizes unknown).
v1 renders flame only — smoke stays with gas_medium (the canonical smoke look); dodges the plume_k_scale soot-scale hack until Smoke saturates to black far too early (diagnostic first, taste second) #6 retires it.
Determinism-exempt by construction: reads dequantized copies, writes no synced state (fire_lights heat = 0.0 pin is the precedent), never runs headless.
Arc shape: F0 design doc + adversarial critique (with Erik) → F1 substrate (RTs + source/wind bridge, debug view) → F2 mini-Stam loop (SL advect, inject at burning open faces, vorticity confinement, Jacobi project) → F3 flame render pass (HUMAN-TEST) → F4 pseudo-volume height + embers v1 as the first canonical particle primitive (HUMAN-TEST).
PARKED — trigger: physics lid closed (milestone 1), specifically after #12 (fire & heat tuning defines this system's input signal) and #6 (soot density scale). Depends on #51 (wind units) being fixed. Then runs as an orthogonal arm alongside animation + ML.
Budget target ~1-1.5 ms GPU desktop at M=8; laptop tier M=4; measured in lighting_demo from F1 on.
