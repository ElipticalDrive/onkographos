Problem
Grid.getCellsForSegment() allocates an arrow function closure (cellId) => { out[index++] = cellId; } on every segment traversal query when calling traverseRay(), generating GC pressure during raycasts and line-of-sight checks against the spatial grid.
Affected Files
src/geometry/grid.ts
Suggested Fix
Inline the DDA ray traversal loop directly in getCellsForSegment or use a reusable bound visitor to populate the out array without allocating a closure per call.
Acceptance Criteria
AC-1: Grid.getCellsForSegment(start, end, out) runs without allocating an arrow function closure.
AC-2: Traversed cells and order match DDA ray path identically.
AC-3: Existing tests in tests/geometry/grid.test.js continue to pass.
