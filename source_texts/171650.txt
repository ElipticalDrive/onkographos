A novel image compression technique is presented for low cost multimedia applications. The technique is based on quadtree segmented two-dimensional predictive coding for exploiting correlation between adjacent image blocks and uniformity in variable block size image blocks. Low complexity visual pattern block truncation coding (VP-BTC) defined with a set of sixteen visual patterns is employed to code the high activity image blocks. Simulation results showed that the new technique achieved high performance with superior subjective quality at low bit rate.
