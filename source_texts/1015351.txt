# Hypernet: Image-to-3D Research Archive

A complete record of a multi-month image-to-3D research project. Twelve experimental phases trace the path from per-shape neural-network weight prediction (which fails informatively at small data scale) to a working DeepSDF + image-conditioned latent diffusion pipeline.

> **Try the working pipeline live:** [**HuggingFace Space**](https://huggingface.co/spaces/bobthebuilderinternational/image-to-3d-deepsdf) — upload 1-8 images of an object, get a 3D mesh back. No install needed.
>
> **Full technical write-up:** see [`docs/thesis.docx`](./docs/thesis.docx) — 30-page report with figures, tables, and quantitative diagnostics.
>
> **Dataset:** [bobthebuilderinternational/hypernet-image-to-3d-data](https://huggingface.co/datasets/bobthebuilderinternational/hypernet-image-to-3d-data) on HuggingFace (4,127 files, 26 GB — meshes, SDF samples, multi-view tarballs, DINOv2 features, all checkpoints).

It produces topologically correct outputs (humanoid → humanoid, head → head, long-thin → long-thin) — qualitatively beyond pure nearest-neighbor retrieval, despite training on ~10⁻³ the data scale of large-scale published image-to-3D systems.

## Working pipeline (phase 11 + 12)

```
input image(s)
    → DINOv2 ViT-B/14 (CLS features per view)
    → DiT [image-conditioned latent diffusion]
    → 64-dim shape latent z
    → shared DeepSDF decoder
    → SDF
    → marching cubes
    → output mesh (.obj)
```

| Component | Details |
|---|---|
| Shared SDF decoder | 8-layer MLP, hidden=512, ReLU + positional encoding, ~1.95M params |
| Per-shape latent | 64-dim, jointly optimized with decoder (DeepSDF-style) |
| Image features | DINOv2 ViT-B/14 CLS token (768-dim per view) |
| DiT | d_model=384, n_layers=4, ~10M params, predicts 64-dim latent as single token |
| Conditioning | Cross-attention to (DINOv2 CLS + sinusoidal pose embedding) per view; K∈[1,8] views |
| Diffusion | Cosine T=500, x_0 prediction, DDIM sampling at 50 steps |
