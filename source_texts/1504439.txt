Overview
Add order-independent transparency for correct rendering of translucent objects.
Details
Weighted Blended OIT (McGuire and Bavoil 2013) or per-pixel linked lists
Separate accumulation and revealage render targets
Composite pass to blend transparent surfaces over opaque geometry
Integration with the existing render pass system (c_PassTransparent)
Correct depth interaction with opaque objects
Motivation
The current renderer has no robust transparency handling. Without OIT, overlapping transparent objects render incorrectly depending on draw order. This is essential for glass, water, particle effects, and UI elements in 3D.
