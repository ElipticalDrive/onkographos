Goal
Begin an independent BeamRT sunlight-shadow renderer using BeamNG depth, normals, camera-ray reconstruction, and the engine auto-bound world-space sunDirection. This is independent of PR #1's sun-contact blending experiment.
Files
lua/ge/extensions/beamrt/shadowRenderer.lua: self-contained opt-in PostEffect lifecycle, quality modes, preview toggles, cleanup.
shaders/beamrt/beamrtSunShadowTraceP_v001.hlsl: first-view depth-ray traversal along the real sun direction. Produces #BeamRT_SunShadowVisibility with R visibility, G coverage/confidence, B NdotL, A receiver validity.
shaders/beamrt/beamrtSunShadowPreviewP_v001.hlsl: preview mask, coverage, sun direction, native mask, and per-pixel disagreement.
SUN_SHADOW_EXPERIMENT.md: short install, debug and rollback instructions.
Intentional boundaries
No changes to main.lua, GI tracer, composition, or other production shaders.
No claim of full scene/cascade shadow replacement, no geometry outside the screen, no raytraced local-light shadows, no temporal stabilization yet.
Cinematic is more samples/longer reach, not yet true soft penumbras.
Screen-space unknowns retain confidence information and must not be blindly treated as illuminated downstream.
Quality presets
playable = half resolution, 24 steps, 18m
cinematic = native resolution, 96 steps, 55m
Test
Check out this branch, restart if necessary, then GE Lua:
```
extensions.load("beamrt_shadowRenderer")
beamrt_shadowRenderer.setQuality("playable")
beamrt_shadowRenderer.enable()
beamrt_shadowRenderer.setView("identity")
```
Expect magenta identity screen.
Batch preview views: sun, classification, native, difference. Save four frames in one session. See SUN_SHADOW_EXPERIMENT.md.
Validation status
Static review of the 2- and 3-input shader layouts and isolated Lua control path complete. BeamNG runtime shader compilation, exact sun uniform availability, projected depth hit behavior, and visual accuracy not verified yet. Do not merge before those pass.
