This PR is an internal refactoring work of silx backprojector, with the following aims:
Fourier filtering done with internal silx.math.fft module (using GPU when available): add a SinoFilter class (sinogram convolution in Fourier domain).
Code readability: refactor Backprojection
Input/output can be numpy and pyopencl arrays.
Enable to choose another filter than default Ram-Lak in FBP
It depends on #2366.

The SinoFilter class is not as straightforward as foreseen. There are some issues ending up in a less readable code:
pyopencl does not support rectangular copies (even Device to Device). Therefore, we have to (1) write a kernel, and (2) create auxiliary buffers for D->H and H->D rectangular copies.
The FFT behavior is different when using the numpy backend (for example numpy always returns float64 results)
When using the OpenCL backend on CPU, we have to wrap many calls with "array.finish()", otherwise "funny" things happen because of the asynchronous operations happening on the arrays.
