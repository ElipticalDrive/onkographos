Describe the bug
The OSPRay volume renderer seems to only work with structured grids. When trying to plot anything else, the rendered image is just empty (no error or warning messages).
When using the OSPRay volume renderer on a structured grid, adding a threshold operator causes the volume to completely vanish, even if the threshold accepts the entire range of data. I'm guessing the threshold changes the data from structured to unstructured.

To Reproduce
Open noise.silo and enable OSPRay
Add a volume plot
Change the renderer to OSPRay
Plot the volume
Now add a threshold operator and leave min and max
Draw again (plot will vanish)
Expected behavior
We should be able to plot unstructured volumes. At the very least, we should raise some kind of error/warning if a user tries to plot something that OSPRay can't currently handle.
Additional context
OSPRay is definitely capable of rendering unstructured volumes.
