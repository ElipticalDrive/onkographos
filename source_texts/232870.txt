Walkthrough
A new frustum utility header provides AABB-frustum intersection testing via Plane and Frustum classes and a transformAABB function. Bounding box fields are added to mesh data structures and components. The rendering system is updated to perform per-camera frustum culling during draw command generation.
Changes
Cohort / File(s)
Summary
Frustum Utility
common/math/Frustum.hpp
Introduces Plane struct with normal, distance, normalize() and distanceTo() methods. Adds Frustum class for constructing from view-projection matrix with intersectsAABB() method using p-vertex optimization. Includes transformAABB() free function implementing Arvo's method for AABB transformation by 4x4 matrix.
Mesh Data Structures
engine/src/assets/Assets/Model/Model.hpp, engine/src/components/StaticMesh.hpp
Adds localMin and localMax (glm::vec3) fields to Mesh struct and StaticMeshComponent. StaticMeshComponent also adds hasBounds (bool) flag. Memento in StaticMeshComponent extended to persist and restore these new bounds fields.
Model Import & Factory
engine/src/assets/Assets/Model/ModelImporter.cpp, engine/src/EntityFactory3D.cpp
ModelImporter now populates minBB and maxBB in Mesh return. EntityFactory3D initializes hasBounds to true and sets localMin/localMax for all created mesh types and model instances, propagating bounds from model meshes to StaticMesh components.
Rendering System
engine/src/systems/RenderCommandSystem.cpp
Refactors draw command generation to per-camera loop. Constructs frustum from each camera's view-projection matrix. Performs frustum culling: transforms local AABB to world space for entities with bounds and skips rendering if AABB does not intersect frustum. Defers shader lookup and moves command creation inside per-entity loop with camera-specific uniforms.

```
sequenceDiagram
    participant Camera
    participant Frustum
    participant Entity
    participant Mesh
    participant Renderer

    Camera->>Frustum: construct(viewProjectionMatrix)
    Frustum->>Frustum: extractPlanes(vp)
    Frustum->>Frustum: normalize planes
    
    loop For each entity
        Renderer->>Entity: getStaticMesh()
        Entity-->>Renderer: Mesh with bounds
        
        alt Mesh has bounds
            Renderer->>Mesh: getLocalBounds()
            Renderer->>Renderer: transformAABB(local, transform)
            Renderer->>Frustum: intersectsAABB(worldMin, worldMax)
            Frustum-->>Renderer: intersection test result
            
            alt AABB intersects frustum
                Renderer->>Renderer: createDrawCommand()
                Renderer->>Renderer: setupUniforms(camera)
            else AABB culled
                Note over Renderer: skip rendering
            end
        else No bounds
            Renderer->>Renderer: createDrawCommand()
        end
    end
    
    Renderer-->>Camera: drawCommands
```
