What
Upgrades the STL/3MF export pipeline to state-of-the-art SDF meshing. The pipeline is now:
Manifold dual contouring — one vertex per marching-cubes surface patch per cell (Nielson's dual marching cubes) instead of one per cell, so ambiguous cells containing two surface sheets stay manifold instead of pinching into non-manifold vertices. Patch grouping is driven by the existing TRI_TABLE.
Truncated-SVD QEF (qef.ts, Ju/Losasso/Schaefer/Warren 2002) — replaces the Tikhonov-regularized solve. Rank-deficient directions fall back to the mass point; strong directions solve exactly, so sharp edges and corners are reproduced essentially exactly (corner test tolerance tightened from 0.2 to 0.02, and a rotated-box corner lands within 0.05).
Secant-refined edge crossings — bisection + a final secant step, cached per grid edge.
Coplanarity-aware quad splits — each DC quad is triangulated along whichever diagonal keeps the two triangles most coplanar, avoiding slivers/folds on curved surfaces.
Error-bounded QEM simplification — exports now use simplifyMesh(mesh, { maxError: 0.05 * voxel }) instead of a blind keep-50% ratio: flat regions decimate freely, curved/sharp regions stop at the error budget. The old numeric-ratio API still works.
Isosurface projection (meshRepair.ts) — after simplification, vertices are Newton-projected back onto the SDF zero set (clamped, monotone-improvement only), removing residual grid bias.
Validation — analyzeMesh reports watertightness / manifoldness / winding consistency, and tests now assert watertight output for sphere, box, torus, the two-sheet ambiguous-cell case, plus signed-volume accuracy (within 2% of analytic, outward wound).
