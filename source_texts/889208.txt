Issue body actions
Scatter instances hidden behind terrain or behind other props are drawn: pebbles behind a boulder, rocks behind a crater rim. The scatter cull pass tests range, fades, the frustum and the horizon only.
Approach
Two-phase hierarchical-Z occlusion culling (Haar and Aaltonen, "GPU-Driven Rendering Pipelines", SIGGRAPH 2015; Wihlidal, "Optimizing the Graphics Pipeline with Compute", GDC 2016), with the depth prepass the target architecture calls for:
Early phase: draw into depth what was visible last frame (a visibility bit per instance that persists across frames), build the depth pyramid.
Late phase: test every other instance's box against the pyramid, draw those that pass, update the bits.
The depth prepass also gives contact shadows and screen-space ambient occlusion their depth; nothing here may block them.
Proposed in a first pass
The prepass draws terrain and meshes, with the same dither discard as the forward pass; the forward pass then tests EQUAL without writing depth, and vertex positions are Invariant so both passes rasterize the same depth.
Visibility in one persistent buffer imported into the render graph, each scatter page holding a range of bits from a first-fit allocator.
The pyramid built in compute, one level per dispatch, R32 float, folding odd sizes (Darnell); GraphImageDescription::mip_levels becomes an enum with a full-chain case so the graph resolves the chain from the size.
The terrain and mesh draw loops move out of the forward pass so the prepass and the forward pass share them.
The debug overlay counts occluded instances.
To decide
Wireframe (debug.wireframe) against an EQUAL depth test.
Built on height tiles (heights computed once per tile): the prepass and the cull read the cached ground.
