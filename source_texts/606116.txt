Implemented an improved culling system that scales render distance based on object size, luminosity, and night-time lighting conditions.
Key changes include:
New Culling Helper (shaders/helpers/culling.glsl): Centralizes the logic for calculating maximum render distances (maintaining a target pixel size) and performing Hi-Z occlusion tests.
Culling Data UBO: Added a new UBO (Binding 9) to provide minPixelSize, nightVisionBoost, and viewportHeight to the GPU, allowing for "cacheable" culling parameters.
Optimized Particle Simulation: The fire.comp shader now uses the culling helpers to skip expensive operations (curl noise, terrain collision) for particles that are occluded or beyond their useful render distance. Ambient spawns now correctly scale their visibility at night based on luminosity.
Decor Culling Refactor: Replaced the redundant culling logic in decor_cull.comp with the centralized helpers.
C++ Plumbing: Updated the Visualizer to initialize and update the CullingData UBO per frame and pass Hi-Z resources to the particle system via FireEffectManager.
Shader Stability: Added include guards to temporal_data.glsl to fix redefinition errors during the unified shader build process.
Verified via make check and make glcheck.
