Summary
Add support for playing Lottie animations using our existing SDF (Signed Distance Function) rendering infrastructure in ydraw/hdraw.
Documentation
See detailed implementation plan: docs/ygpu-lottie.md
Scope
Phase 1: Static Lottie Rendering
Lottie JSON parser
Parse shape layers: rectangle, ellipse, polystar
Parse fill and stroke
Map to SDFPrimitive structs
Phase 2: Basic Animation
Keyframe data structures
Linear interpolation
Bezier easing curves
Animation timeline / playback control
Transform application (CPU-side)
Phase 3: Path Support
Parse Lottie path vertices
Decompose into Bezier3 primitives
Handle closed vs open paths
Phase 4: Transform Optimization
Extend SDFPrimitive with transform matrix
Update shader to apply transforms
Phase 5: Advanced Features
Gradient fills
Simple masks (SDF intersection)
Trim paths
Repeaters
Out of Scope (v1)
Text layers
Image layers
Effects (blur, shadow, glow)
Complex masks/mattes
Expressions
3D layers
References
Lottie Documentation
Inigo Quilez 2D SDF Functions
