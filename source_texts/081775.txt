This PR addresses the bottlenecks in the Dazzle GI system where voxelization was missing and surfel management was failing to capture scene geometry.
Key changes:
Render-Hook Integration: Moved Dazzle GI dispatch from FinishUpdate to the AfterOpaque render stage. This ensures that the system has access to the current frame's G-buffer (Color, Depth) for surfel spawning.
Compute-Based Voxelization: Replaced the disabled vertex/pixel shader voxelizer with a robust compute shader (dazzle_voxelize_cs.shader) that uses RayQuery to populate the global voxel grid for the entire volume.
Hardware RT Support: Updated dazzle_cascades_trace_cs.shader to optionally use hardware raytracing for interval tracing, while maintaining the SDF-based software path as a fallback.
Performance & Stability: Using compute-based voxelization improves efficiency and avoids potential stability issues on Vulkan associated with legacy UAV rasterization.
These changes ensure a "no shortcuts" functional implementation of the Dazzle GI pipeline.
