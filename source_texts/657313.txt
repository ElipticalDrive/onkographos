Is your feature request related to a problem?
Currently no $phong shader support.
Describe the solution you'd like
I utilize $phong frequently in mapping. It's a low-cost way enhancing details, especially on models. If you could somehow incorporate this back into the supported shaders for static lights, that'd be amazing. Example of difference below in Momentum vs. CS:S:
Describe alternatives you've considered, if any.
Dynamic lights were suggested, but could be impractical for larger areas of a map that need more indirect lighting for $phong. $phong is typically used to circumvent having to utilize cubemaps for basic reflections or visual smoothing of angles.
Additional context
Most of the $phong I use is on vertexlitgeneric models. Example .vmt below:
`"vertexlitgeneric"
{
"$basetexture" "co/road"
"$bumpmap" "co/road_bump"
"$detail" "co/road_lights"
"$detailscale" "1"
"$detailblendmode" "2"
"$detailblendfactor" "0.05"
"$phong" "1"
"$phongexponent" "1"
"$phongexponentfactor" "0.25"
"$phongboost" "0.25"
"$phongtint" "[1 1 1]"
"$phongfresnelranges" "[1 1 1]"
"Proxies"
{
"TextureScroll"
{
"TextureScrollVar" "$basetexturetransform"
"TextureScrollRate" "0.25"
"TextureScrollAngle" "-90"
}
```
    "TextureScroll"
    {
        "TextureScrollVar" "$bumptransform"
        "TextureScrollRate" "0.25"
        "TextureScrollAngle" "-90"
    }
}
```
}`
$rimlight is currently functioning fine, even with purely static lights.
One of my previous CS:S maps, bhop_vixen (https://steamcommunity.com/sharedfiles/filedetails/?id=2788561758) would be a test for whether $phong is working with static lights. Download is also below:
