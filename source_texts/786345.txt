Description
radiance scene files and metric results generated from high quality referece images for an office building near LAX.
contents of lci_tempate.tar.gz:
ALLSKIES:
4294 sky conditions generated by write_skydefs.py
based on LAX.epw, all conditions with solar altitude >= 2 degrees, diffnorm > 5 w/m^2
INSGEO/: (scene files that can be made into an instance using setup.sh)
EXT.rad INT.rad LIT2.rad baseglz.rad site.rad
MATERIAL/:
all.mat
POINTS/: (reference view locations as sensor points)
ref_views.pts
RAD/:
ROIglz.rad big.rad
ROI/: (radiance scene polygons describing zones around each point)
o1.rad o2.rad z1.rad z2.rad
VIEWS/: (reference views)
o1ref.vf o1ref_r.vf o2ref.vf o2ref_r.vf z1ref.vf z1ref_r.vf z2ref.vf z2ref_r.vf
refs/: (source weather data and model units)
lax.epw lax.wea sky_runorder.txt units.txt
reference images generated with run_step.sh
2phs images generated with 2phase_run_auto.sh
contents of ref_data.tar.gz:
refimgs/ref_data_view_*_metric.txt (for each view)
columns: month day hour dgp illum ugr ugp dgp_t1 dgp_t2 avglum loggcr logpwgcr
data generated with the run_step.sh file in lci_tempate.tar.gz for all sky files
metrics computed with run_rayt.sh in lci_tempate.tar.gz
scripts require python3.6-3.8 on mac os or linux with the following packages installed: raytraverse v1.2.7
