Summary
Native noise operators, as the issue asked: seedable, documented, and bit-identical on every platform.
Closes #734
New operators (src/ops/noise.rs, pscat extensions): noiseseed, gnoise2, gnoise3, gnoise2d (n dx dy), vnoise2, vnoise3, fbm2, fbm3, vfbm2, vfbm3, ridged2, ridged3. The names don't collide with artkit's noise2/noiseinit or with anything else in lib/, gallery/, examples/ or tests/.
Deterministic algorithm. Only f64 add, subtract and multiply in a fixed order, plus floor and table lookups: no division, no libm, no FMA. The 2D gradient noise is artkit's exact formula. The 3D version is Perlin's improved noise. Value noise uses the lattice value (h-127.5)*0.0078125. fBm is unnormalized, with a fixed per-octave domain shift. oct must be 0..32, otherwise rangecheck.
Seed. noiseseed builds its own Fisher-Yates table from a private LCG. It never reads or moves rand, and both directions are tested. A fresh interpreter behaves as if 0 noiseseed had run.
lib/noiseref.ps is the PostScript reference (nrgnoise2 ...). It reproduces every operator bit for bit on pscat, and it also runs in Ghostscript, where it matches to 32-bit-real precision.
artkit's noise2 is now native through a dot-named .permnoise2 that reads Perm on each call and uses PostScript's int/real promotion. Results stay bit-identical, type included: an integer lattice point still returns 0 or 0.0 exactly as before. Ghostscript keeps the procedure. fillkit's fkfbm inherits the speed-up.
Docs: a pscat skill section, a psart skill bullet, docs/guides/artkit.md, HANDOFF, and notes/734-native-noise.md.
No visible change, so no demo render: the identity check below is byte-identical. Tier (a).
Benchmark (pscat only, no Ghostscript)
Release build, Apple M4. Figures are µs per loop iteration over 200,000 iterations, min of 5 runs. Each iteration also does 3 mul and 2 dup to make the coordinates, so the empty row is the floor. The native rows sit on that floor: a native call's own cost is below what this harness can resolve, which is why gnoise3 reads 0.175 against the floor's 0.18.
