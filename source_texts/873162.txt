## Setup Environment
```

git clone https://github.com/.....
cd ....

# Build basic environment
conda create -n octreesplatting python=3.7
conda activate octreesplatting

# Install dependencies
pip install torch==1.12.1+cu116 torchvision==0.13.1+cu116 -f https://download.pytorch.org/whl/torch_stable.html
```

## Datasets
We suggest use datasets [MipNeRF-360](https://jonbarron.info/mipnerf360/)  and [Tanks&Temples and Deep Blending](https://repo-sam.inria.fr/fungraph/3d-gaussian-splatting/datasets/input/tandt_db.zip). Thanks for their wonderful work. Please organize the dataset like below:

```
datasets/
├── mipnerf/
│   ├──bicycle
|   ├──bonsai
|   ├──counter
|   ...
├── db/
│   ├──drjohnson
│   └──playroom  
...

```

## Run

**1.Train single scene**

To train, render, and evaluate, use the following commands:

```
python train.py -s datasets/mipnerf/bicycle -m output/mipnerf/bicycle --eval --prune_ratio 0.1
python render.py -m output/mipnerf/bicycle
python metrics.py -m output/mipnerf/bicycle
```

Here, `--prune_ratio` simply sets the simplification ratio in the final stage (e.g., 0.1 removes 10% of the points).

**2.Evaluate all datasets**
To train, render and evaluate all datasets use the following commands:

```
# train MipNeRF360
bash scripts/run_mipnerf.sh

# train Deep Blending
bash scripts/run_db.sh

# train Tanks&Temples
bash scripts/run_tandt.sh
```
**3.Collect Results**
During training and rendering, key data information will be written to the corresponding JSON files. You can quickly collect key metrics from the dataset using the following command.

```
python statistics.py --results_dir output/mipnerf
```
