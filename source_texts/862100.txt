Optimize memory usage in voxelization steps
Summary
This PR reduces peak RAM usage during voxelization operations by:
Slice-wise ellipsoid computation (embedding.py): Replaces full 3D meshgrid allocation (3×N×8 bytes for float64) with slice-by-slice computation that only allocates one 2D slice at a time.
Morphological shell generation (embedding.py, pipeline.py): Defaults to binary dilation instead of distance_transform_edt for shell generation. EDT allocates a full float64 grid; morphological ops stay in boolean space.
Explicit memory cleanup: Added del statements to free large arrays (voxel grids, masks, labels) as soon as they're no longer needed.
Optimized connectivity analysis (connectivity.py): Removed port_mask and reachable_mask allocations by computing port labels directly from boundary face slices and using component sizes instead of np.isin.
int32 labels (repair.py): Uses int32 dtype for connected component labels instead of default int64.
Updates since last revision
Fixed bug where domain_mask was deleted before being used in shell generation code. The deletion is now correctly placed after shell generation completes.
Review & Testing Checklist for Human
Verify the slice-wise ellipsoid computation produces identical results to the original meshgrid approach (test with EllipsoidDomain)
Test that use_morphological_shell=False still works correctly (EDT fallback path)
Run the full test suite: pytest vascular_lib/tests/ vascular_network/tests/
Test with a real large STL file to verify memory reduction is meaningful
Recommended Test Plan
Create a test case using EllipsoidDomain and compare output meshes before/after this PR
Run embed_tree_as_negative_space() with output_shell=True to verify shell generation works
Profile memory usage on a large mesh (e.g., 500+ voxels per dimension) to confirm reduction
Notes
The morphological shell gives thickness in voxel units rather than continuous world units - this is a slight semantic change from the original EDT behavior
The use_morphological_shell and use_morphological parameters default to True for memory efficiency; users can set to False if they need exact world-unit thickness

Key optimizations:

1. embedding.py:
   - Replace full meshgrid ellipsoid computation with slice-wise approach
     (reduces peak memory from 3*N*8 bytes to N/nx*8 bytes)
   - Add use_morphological_shell parameter (default True) to use binary
     dilation instead of EDT for shell generation
   - Add explicit del statements to free large arrays early
   - Use in-place boolean operations where possible

2. connectivity.py:
   - Remove port_mask and reachable_mask allocations
   - Compute port labels directly from boundary face slices
   - Compute reachable voxels from component sizes instead of np.isin

3. repair.py:
   - Add explicit del for vox and vox_filled after extracting mask
   - Use int32 dtype for labels array (via output parameter)
   - Add explicit del for labels after component filtering

4. pipeline.py:
   - Add use_morphological parameter to make_scaffold_shell_from_fluid
   - Default to morphological dilation instead of EDT
   - Add explicit del statements throughout

These changes significantly reduce peak RAM usage during voxelization
operations, especially for large grids.
