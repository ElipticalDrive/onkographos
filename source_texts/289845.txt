Summary
HDR tone-mapping fix in process-scene.ps1: moved tonemap=hable before the BT.709 transfer step — was causing COLMAP to register only 0.5% of frames (3/620); now registers ~90%
Floater cleanup pipeline (clean-splat.py): 5-pass automated removal (opacity threshold → scale cap → auto-crop bbox → SOR statistical outlier removal → optional density filter); removes ~31% of Gaussians while preserving surface geometry with --no-density
PLY → .splat converter (ply-to-splat.py): packs 3DGS PLY into 32-byte-per-Gaussian .splat binary for Postshot, SuperSplat, and web viewers
Stats tool (splat-stats.py): prints scale/opacity percentile distributions to help tune clean-splat.py thresholds
Setup script (setup-windows.ps1): one-time workstation bootstrap — winget packages (Git, ffmpeg, Node.js, Miniconda), COLMAP latest CUDA build, nerfstudio conda env, working directory scaffold
.gitignore: excludes splatting working dirs (frames/, colmap_out/, outputs/, export/, done/, incoming/*)

Run ply-to-splat.py on cleaned PLY — confirm .splat opens in Postshot or SuperSplat
Run splat-stats.py on a raw splat.ply — confirm scale/opacity tables print without error
