Motivation
Package the heightmap→particle concept into a reusable, production-ready toolkit that developers can drop into projects.
Provide a modular API (ParticleLandscape) plus renderer/effects so scenes can be configured declaratively with fog, hover, masking, and infinite tiling.
Optimize for high particle counts by using BufferGeometry and GPU shaders so large point-cloud terrains (300k+ particles) are practical.
Description
Added a modular engine under engine/ with core/ParticleLandscape.js, core/ParticleRenderer.js, and core/TerrainManager.js plus loaders/HeightmapLoader.js, utils/HeightmapUtils.js and utils/NoiseGenerator.js to convert heightmap pixels into particle attributes (x = pixel x, y = height, z = pixel y).
Implemented GLSL shaders (engine/shaders/particle.vert, particle.frag, fog.frag) and effect wrappers (effects/FogEffect.js, HoverEffect.js, MaskEffect.js) to support atmospheric fog, distance fade, GPU hover displacement, and circular masking.
Added demos (demos/basic-terrain, demos/infinite-terrain, demos/fog-landscape, demos/alien-world) with index.html and main.js for each, plus reusable demo helpers in demos/shared-demo.js and procedural heightmap creation in demos/shared-heightmap.js.
Included a Node CLI heightmap generator at terrain-tools/heightmap-generator.js using the bundled NoiseGenerator, a Vite scaffold (vite.config.js), package.json scripts, and a comprehensive README.md describing installation, usage, terrain creation, and performance tips.
Testing
Ran the generator to create a test PNG with node terrain-tools/heightmap-generator.js --width=64 --height=64 --seed=5 --output=/tmp/particle-landscape-test.png which succeeded and produced a valid PNG file.
Performed static JS checks with find engine demos terrain-tools -name '*.js' | xargs -n 1 node --check to ensure no syntax errors were detected (no errors returned).
Served the repo with a local static server and captured screenshots of the landing page and basic demo via headless browser to validate the packaged entry and demo pages (screenshots collected as artifacts).
Attempted npm install / full Vite dependency install but it was blocked in this environment due to registry 403 Forbidden, so a full local build/install could not be completed here.
