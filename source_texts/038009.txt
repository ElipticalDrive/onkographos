Implements report row L-4: fog spot cones + raymarched spot shafts (Wave 4), on top of L-1 (spot lights, atlas) and L-3 (ComputeShadows, fog parity), rebased on A-2/A-3.
What
VolumetricFogEffect.setSpotLights(renderer.spotLightsBuffer, renderer.spotShadowAtlas) binds the renderer's spot buffer and atlas (ComputeShadows bindings 7-9). The cones then scatter in the froxels through volumetric_fog_spot.wgsl, which L-3 already compiled into the injection but left bound to empty stand-ins. Rust: set_spot_lights.
spotScattering: { kind: 'froxels' } | { kind: 'raymarched', steps } ports SpotScattering::Raymarched (#33):
the half-resolution shafts entry (volumetric_fog_shafts.wgsl, appended to the injection WGSL as Rust does);
the temporal filter (volumetric_fog_shafts_temporal.wgsl), with history A/B, a reset on camera frame gaps and in resetHistory;
the composite's depth-aware upsample (shafts flag, binding 6).
All of it runs on the shared Rust WGSL via ?raw, with no WGSL edits. ShaftParams is 208 B, matching ShaftParamsGpu.
The shafts bind the sky lighting and local volumes from A-2, as Rust does.
examples/index_spot_lights.html gains fog=0 and shafts=<steps>, with the fog settings of the Rust spot-lights example.
Verification
tsc && vite build pass.
