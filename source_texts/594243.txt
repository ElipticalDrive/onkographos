Context
Downstairs (the deep Piccadilly line level) looks too wet. The local lights also ignore the walls: light and the wet specular reflections show on surfaces that a wall hides from the light. Sean asked: can the lighting be smarter without ray tracing, and does that need swindowzig changes or only changes in the action renderer?
scene.wgsl already has SDF ambient occlusion, so a signed distance field of the map may already be available to the shader.
Acceptance Criteria
Downstairs surfaces are less wet: less gloss and smaller reflections. The floor still reads as a tube station floor.
Local lights respect walls. A surface that a wall hides from a light gets no diffuse or specular light from it. Use a method that is cheap enough for a laptop GPU (for example SDF soft shadows, a per-light occlusion test, or a light shadow map). Choose one and say why in the PR.
Frame time on the deep level does not get much worse. Give a before and after number in the PR (the debug screen or a GPU timer).
The PR body answers Sean's question: did this need swindowzig changes, or only action changes? If swindowzig changed, follow .claude/rules/swindowzig-libs.md.
Files Likely Touched
apps/action/game/src/scene.wgsl, render.zig, map.zig, possibly utils/swindowzig/libs/sw_gpu
Priority
P1
Notes for the worker
Read apps/action/README.md first. Update it for every control, map or system that you change.
Build: cd apps/action/game && zig build. Types: yarn workspace action test:types. Map audit: zig build floorplan -- earls_court audit.
Ports 4080 and 4790 are Sean's dev servers. Do not stop them. If you run the game, use PORT=4081 or higher.
Deathmatch is networked. A change that other players must see goes through server/index.ts and net.zig.
