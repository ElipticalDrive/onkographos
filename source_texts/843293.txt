$\begingroup$
I have a fixed $n \times n$ matrix $M$ whose entries are all either $0$ or $1$. I want to compute the product $Mv$ for various vectors $v \in \mathbb{R}^n$ (or over other fields/rings and abstract data types).
Since $M$ is fixed and does not change, is it possible to design a preprocessing algorithm that examines $M$ (possibly taking exponential time in $n$) and subsequently allows each matrix-vector multiplication $Mv$ to be computed in sub-quadratic (e.g., $O(n^{2-\epsilon})$) time?
Are there known characterizations of matrices (e.g., based on rank, sparsity pattern, or combinatorial structure) for which such fast multiplication is possible?
Any preprocessing must be confined to operations over the ring of integers. Furthermore, the complexity is measured strictly by the number of additions and subtractions. Computing a scalar multiple such as $k \cdot a$ (for an integer $k > 1$) would itself require $\sim \lfloor \log ⁡ 2 k \rfloor$ additions through repeated doubling, and this cost must be accounted for in the complexity analysis.

To complement the existing answers, a simple information-theoretic counting argument shows that $\Omega(n^2 / \log n)$ operations are necessarily for generic matrices $M \in \{0, 1\}^{n \times n}$. The result of the preprocessing phase is an addition-and-subtraction-only algorithm that computes $v \mapsto Mv$. Any such algorithm can be written as a straight-line program (without conditional jumps or loops) of the form
\begin{align}
v_{n+1} &:= v_{i_1} \pm v_{j_1} \\
v_{n+2} &:= v_{i_2} \pm v_{j_2} \\
&\hspace{3.5mm}\vdots \\
v_{n+L} &:= v_{i_L} \pm v_{j_L} \\
\mathrm{retur}&\mathrm{n}\ (v_{k_1}, \dots, v_{k_n})
\end{align}
Here, $v_1, \dots, v_n$ are the entries of the input vector $v$, and $v_{n+1}, \dots, v_{n+L}$ denote temporary values computed by the program. The number of such programs of length $L$ is precisely:
$$ 2^L (n+L)^n \prod_{i=0}^{L-1} (n+i)^2 \le 2^L (n+L)^{n+2L} $$
To represent all $2^{n^2}$ possible matrices $M$ by a program of length $L$, we must have:
\begin{align}
2^L (n+L)^{n+2L} &\ge 2^{n^2} \\
L + (n+2L) \log_2(n+L) &\ge n^2 \\
2L \log_2 L &\gtrsim n^2 \\
L &\gtrsim \frac{n^2}{4 \log_2 n}
\end{align}
This, in particular, implies that $O(n^{2 - \epsilon})$ cannot be achieved for any $\epsilon > 0$ outside an asymptotically vanishing class of matrices $M$. The Method of Four Russians is generically optimal.

I don't know what kinds of matrix patterns you are interested in, but there are some.
Suppose that the $\{0,1\}$ valued matrix $M$ represents a partial order $\le$, i.e. $M_{ij} = 1$ if and only if $i \le j$ (in the partial order). Then, if the partial order has suitable form, there are fast algorithms for $Mv$, using a "monotone circuit" (additions only, and the time complexity is measured as the number of additions).
If the order is a lattice with $n$ elements and $j$ join-irreducible elements (elements that cover exactly one element), it can be done in $O(nj)$ time (Björklund et al.), which could be much less than $O(n^2)$.
If the order is an ER-labelable or semimodular lattice, with $e$ edges in its covering relation, it can be done in $O(e)$ time (Kaski et al.).
Björklund, Andreas; Husfeldt, Thore; Kaski, Petteri; Koivisto, Mikko; Nederlof, Jesper; Parviainen, Pekka, Fast zeta transforms for lattices with few irreducibles, ACM Trans. Algorithms 12, No. 1, Article No. 4, 19 p. (2016). ZBL1398.68694.
Kaski, Petteri; Kohonen, Jukka; Westerbäck, Thomas, Fast Möbius inversion in semimodular lattices and ER-labelable posets, Electron. J. Comb. 23, No. 3, Research Paper P3.26, 13 p. (2016). ZBL1377.06006.

$\begingroup$
You are looking for a small linear circuit computing the transformation $Mv$. In the general case there might not be a sub-quadratic circuit, but for a rank $k$ matrix $M$ you can use the factorization $M = AB$ for $A \in \mathbb{Q}^{n \times k}, B \in \mathbb{Q}^{k \times n}$ to compute $Mv = ABv$ in $O(nk)$ time.
For a sparse matrix $M$ with $|M|$ ones you can compute $Mv$ in time $O(|M|)$.
These can both be generalized to decomposing the matrix $M$ to a sum of low rank or sparse matrices. However, since rank and sparsity are subadditive, this reduces to just decomposing to a single low-rank and a single sparse matrix.
This problem is studied in operations research and machine learning, see for example Dimitris Bertsimas, Ryan Cory-Wright, Nicholas A. G. Johnson, Sparse Plus Low Rank Matrix Decomposition: A Discrete Optimization Approach (2023).
In case the matrix has some more specific combinatorial structure it's definitely possible that you can construct better circuits manually, and if $n$ is small you can also try general circuit minimization - I'm not aware of anything for linear circuits specifically, but it's likely that some approaches can be adapted.

I don't know how to get $n^{2-\varepsilon}$ but getting $o(n^2)$ is not hard.
The following is back-of-the-envelope and constants need adjusting.
Put $t=\ln n/\ln\ln n$. If the total number of 1s in the matrix is greater than $n^2/t$, there is a $t\times t$ submatrix of all 1s. See here for a precise bound.
Such a submatrix can be handled in $2t$ rather than $t^2$ additions. Repeatedly remove these submatrices until the number of 1s drops below
$n^2/t$ then do the rest naively in $n^2/t$ additions. This gives $O(n^2\ln\ln n/\ln n)$ additions altogether.
I expect this can be improved by working more carefully. The whole is related to the problem of decomposing bipartite graphs into complete bipartite subgraphs, which is a studied problem.
Note that a $t\times t$ submatrix can be handled in $O(t)$ additions if the number of 0s in it is $O(t)$. I don't know how to incorporate that into the argument.

$\begingroup$
Also as a reminder, if the number of non-zero entries $|M|$ is small, there exists a simple algorithm in $O(|M|)$, which you should stick to if the matrix is sparse. We have that $$(Mv)_i = \sum_{j=1}^{n} M_{ij} v_j = \sum_{j=1}^{n} \mathbf{1}[M_{ij}=1] v_j $$ This sum can be computed in $O(k_i)$, where $k_i$ is the number of non-zero elements of the $i$th row vector of M. Do this for all rows and you get $O(|M|)$.

A version of this question was exactly studied in this recent paper The Structural Complexity of Matrix-Vector Multiplication (https://arxiv.org/abs/2502.21240), where they showed that for binary matrices with VC dimension $d$, there is an algorithm with preprocessing $O(n^2)$ and query time $O(n^{2 - 1 / d })$ which gives subquadratic time algorithms for moderate VC dimension.
