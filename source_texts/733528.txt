Volumetric Fog Enhancement
Goal: Replace flat distance-based fog with ray-marched volumetric fog for dramatic visual improvement in corridors, outdoor areas, and underwater sections.
Phase 1 Scope (this issue)
Half-resolution ray-marching pass (16 steps)
3D procedural density field (no texture — avoids memory cost)
Temporal reprojection for stability
CLI toggle: -vfog 0/1/2 (off/low/high)
Legacy fog fallback when disabled
Out of scope (future issues)
Phase 2: Light interaction (point lights, ambient scattering)
Phase 3: God rays, light shafts, quality presets
Phase 4: Localized fog volumes per-sector
Performance Budget
Target: ≤1.5ms at 1080p with 16 steps at half resolution
Fallback: legacy fog when -vfog 0 or hardware unsupported
Integration Notes
Descent 3 uses a batch-heavy 1999 scene graph (many small GL_TRIANGLE_FAN draws)
Renderer is OpenGL 3.2 core with shader pipeline (Renderer struct in HardwareOpenGL.cpp)
Current fog: rend_SetFogState / setFogEnabled / setFogBorders uniforms
Post-process fits cleanly: render scene → ray-march fog → composite
Testing
Render tests with Mesa/EGL headless backend
Capture baseline screenshots before volumetric fog
Compare fog density at known positions (level geometry)
References
Volumetric Fog GitHub Sample
