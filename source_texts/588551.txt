Explore codebase and understand BezierSimplex/ControlPoints structure
Derive de Casteljau algorithm for Bézier simplex subdivision
Implement torch_bsf/splitting.py:
split(bs, i, j, s) — core de Casteljau split
reparametrize(t, i, j, s, subsimplex) — re-parameterize data points to a sub-simplex
longest_edge_criterion(bs, s) — select edge with max value-space length
max_error_criterion(params, values, grid_size) → SplitCriterion factory
split_by_criterion(bs, criterion) — convenience wrapper
Export new symbols from torch_bsf/__init__.py
Write tests/splitting.py (99 tests, 97% coverage of splitting.py)
Full test suite passes
Code review feedback addressed:
_precompute_shift_rows now accepts device param and creates shift tensor on that device directly
split() passes device=b.device to _precompute_shift_rows (no more .to() round-trip)
subsimplex validated as "A" or "B" (raises ValueError otherwise)
grid_size < 1 raises ValueError
max_error_criterion inner closure moves params/values to model's device and dtype
Shape validation in max_error_criterion inner closure
reparametrize validates s ∈ (0,1) and i/j bounds (raises ValueError for invalid inputs)
reparametrize validates t is a 2-D tensor with at least 2 columns (raises ValueError with a clear message for 1-D/scalar inputs)
reparametrize requires t to be a floating-point tensor (raises ValueError for integer/bool dtypes to prevent silent truncation)
max_error_criterion docstring is now the first statement (so __doc__ is set correctly); validation follows after
_precompute_shift_rows now validates direction explicitly and raises ValueError for unknown values
_precompute_shift_rows builds shift indices in a Python list then creates a single tensor (avoids per-element CUDA/MPS kernel launches)
longest_edge_criterion derives index_to_row from public bs.control_points.indices() (no longer uses _index_to_row)
_split_core private helper extracted; split() delegates to it; max_error_criterion caches per-edge precomputations (alpha_i/alpha_j, shift tables) outside the s_cand loop
max_error_criterion now uses list(bs.control_points.indices()) and builds index_to_row locally instead of accessing private _indices/_index_to_row
torch.ones_like(row_sums) in test
Unit tests added for all max_error_criterion validation branches: grid_size < 1, params/values not 2-D, mismatched N, wrong params shape, wrong values shape
Unit tests added for reparametrize t rank/shape/dtype validation: test_reparametrize_t_not_2d, test_reparametrize_t_too_few_columns, test_reparametrize_t_not_floating
doctest_default_flags in docs/conf.py now includes IGNORE_EXCEPTION_DETAIL | DONT_ACCEPT_TRUE_FOR_1

Pull request overview
Adds functionality to subdivide a Bézier simplex along a chosen edge using a de Casteljau-style recursion, including utilities to reparameterize samples onto sub-simplices and choose split edges/locations via criteria.

Re-exports splitting symbols from torch_bsf/__init__.py for top-level access.
Adds a comprehensive tests/splitting.py suite for structural properties, continuity, reproduction, and public exports.
