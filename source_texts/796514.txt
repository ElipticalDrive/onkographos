Simulation output data for long-term fire-vegetation simulations with the individual-based, spatially explicit model LAVESI-FIRE. The individual folders include all simulation output data for two simulated scenarios: normal fuel availability ("1_LAVESI-FIRE_output_normalfuel") and reduced fuel availability ("2_LAVESI-FIRE_output_reducedfuel"). Each of these two scenarios was simulated ten times ("_rep1" to "_rep10") under otherwise equal parameters. In each folder, following files can be found (_214497XX refers to the climate input used for the simulation): datatrees_currencies_214497.csv: Timeseries data; one file. Simulation area-wide summarized data on tree abundance, climate, environment and fire occurrence. Each row of the table represents an individual annual simulation timestep. databiomassgrid_1_214497_XXX_1_X.csv: Spatial data; one file every 100 simulation timesteps. Each file includes tree abundance for one tree species (_1 = Larix gmelinii; _2 = Larix sibirica; _3 = Larix cajanderi; _4 = Picea obovata; _5 = Pinus sylvestris; _6 = Pinus sibirica), summarized in grid cells with x- and y-coordinates. datatrees_TreedensityXXX_214497.csv: Spatial data; one file every 100 simulation timesteps. Each file includes tree density, environment, and fire occurrence, summarized in grid cells with x- and y-coordinates. For more detail, please refer to the corresponding research paper (submitted, DOI to be added once published).

Description
Simulation output data for long-term fire-vegetation simulations with the individual-based, spatially explicit model LAVESI-FIRE. The individual folders include all simulation output data for two simulated scenarios: normal fuel availability ("1_LAVESI-FIRE_output_normalfuel") and reduced fuel availability ("2_LAVESI-FIRE_output_reducedfuel"). Each of these two scenarios was simulated ten times ("_rep1" to "_rep10") under otherwise equal parameters. In each folder, following files can be found (_214497XX refers to the climate input used for the simulation):
datatrees_currencies_214497.csv: Timeseries data; one file. Simulation area-wide summarized data on tree abundance, climate, environment and fire occurrence. Each row of the table represents an individual annual simulation timestep.
databiomassgrid_1_214497_XXX_1_X.csv: Spatial data; one file every 100 simulation timesteps. Each file includes tree abundance for one tree species (_1 = Larix gmelinii; _2 = Larix sibirica; _3 = Larix cajanderi; _4 = Picea obovata; _5 = Pinus sylvestris; _6 = Pinus sibirica), summarized in grid cells with x- and y-coordinates.
datatrees_TreedensityXXX_214497.csv: Spatial data; one file every 100 simulation timesteps. Each file includes tree density, environment, and fire occurrence, summarized in grid cells with x- and y-coordinates.
For more detail, please refer to the corresponding research paper (submitted, DOI to be added once published).
