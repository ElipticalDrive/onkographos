# Vulkan PBR + IBL Renderer

基于 **Vulkan 1.4** 的实时物理渲染器：Cook-Torrance BRDF + 图像光照（IBL），实现 **Kulla-Conty 多次散射能量补偿**（直接光与 IBL 两种形式），并通过**白炉测试**验证能量守恒。

采用现代 Vulkan：RAII 封装、Dynamic Rendering、Synchronization2。着色器使用 **Slang** 编写并编译为 SPIR-V。

## 特性

- **PBR 着色**：Cook-Torrance BRDF（GGX 分布 + Smith 几何项 + Schlick 菲涅尔）
- **完整 IBL 管线**（3 个 Compute Shader 预计算）：等距柱状图→Cubemap、辐照度卷积、GGX 重要性采样镜面预滤波（Split-Sum，11 级 mip）
- **Kulla-Conty 多次散射能量补偿**，两条独立路径：
  - 直接光：Kulla-Conty 原始公式（E_o / E_i / E_avg LUT）
  - IBL：Fdez-Aguera 解析积分形式
- **白炉测试**：测试材质（F0=1）下，直接光 / IBL 两种光照均可开关能量补偿、调节粗糙度，直观对比
- **两种模式**：Test（炉测试）/ Normal（头盔 + 真实贴图），ImGui 切换
- **直接光 / IBL 互斥切换**：Direct = 单一方向光 + 纯黑背景；IBL = 环境天空盒 + 环境光
- 现代 Vulkan：Dynamic Rendering、Synchronization2、全 RAII 资源管理
