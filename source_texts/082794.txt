Summary
Add Lichtfield Studio to our comparative benchmarks as another splatting library to compare against GSplat and FVDB.
What is Lichtfield Studio?
Lichtfield Studio is a recent neural 3D splatting library that enables real-time rendering of scenes from radiance fields using specialized splatting kernels. Unlike GSplat (Gaussian Splatting), Lichtfield Studio introduces alternative kernel approaches and optimization techniques. For more info see its repository here.
Tasks:
Integrate Lichtfield Studio into utilities in tests/benchmarks/comparative/comparison_benchmark.py.
Update matrix configuration in tests/benchmarks/comparative/README.md to support Lichtfield runs.
Include Lichtfield Studio in the comparative docs (README) where GSplat and FVDB are currently mentioned.
Ensure results for Lichtfield Studio are generated in the reports and summary statistics.
Briefly explain differences between Lichtfield Studio, GSplat, and FVDB in documentation.
