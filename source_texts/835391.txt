Habitat raster generation computes slope/carve for plant suitability, then soil blending recomputes both at the same point. Each repeated slope query reads terrain height four more times. Reuse those values through an optional soil-blend argument and one two-number scratch object per Habitat. Preserve ordinary number precision and the legacy query path for other callers; no per-node allocation or visual-policy changes.
Reproduced on published 0.0.18 · 421d34b, with the native terrain, grass generator and meshes. Across 6,358 cold nodes:
Slope calls: 12,716 → 6,358.
Carve calls: 12,716 → 6,358.
Height evaluations: 77,662 → 52,230 (25,432 removed).
All 31 grass tiles / 4,088 instances, complete raster values, active buffers and bounds match the native control. Full-scene post-render pixels are identical; final draw calls/triangles/textures stay 245 / 1,889,302 / 174.
Repro: node tools/repro-live-habitat-surface-sample.mjs --url https://ael-dev3.github.io/Tervain/ --out habitat-surface-proof.
Receipt, JSON and matched images.
Production build and 52 tests pass, including a baseline-failing slope-query regression, exact soil-weight comparisons, zero supplied values, legacy callers and terrain texture workers. No hardware frame-time or historical hitch-resolution claim; hardware play-gate receipt remains required.
Stacked on #539; only surface-sample reuse is new here. The baseline includes #539's crown reuse, while terrain-call counts and all generated data must still match published controls. Related: #326.
