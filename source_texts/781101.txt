Algebraic multigrid (AMG) methods are
scalable, robust, and non-intrusive
▪ Multigrid recursively coarsens the problem to provide O(N) cycling
— Relaxation efficiently reduces “oscillatory” error modes
— “Smooth” error modes can be represented on coarse-grids
— V-cycle convergence factor is independent of problem size with O(N) cost
▪ Algebraic multigrid (AMG)
— Relies only on the matrix
— Relaxation: Jacobi, G-S, etc.
— Algebraic coarsening/interp
— Galerkin coarse-grid operators
Ac = PTAP

LLNL-CFPRES-2012828
PFMG is a highly efficient semi-coarsening
multigrid solver for structured problems
▪ Structured interface
— Domain consists of logically rectangular
boxes
— Matrix defined by grids and stencils
▪ PFMG
— Semi-coarsening
— Operator-based, two-point interpolation
— Galerkin coarse-grid operators
— Regular stencils throughout hierarchy
▪ Highly efficient, but limited
applicability
5
LLNL-CFPRES-2012828
BoomerAMG is a robust, general-purpose,
unstructured AMG with many options
▪ Unstructured interface
— Arbitrary matrices
— Parallel CSR data structure
Row Pointer: [i0, i1, i2, … , iNrows]
…
Column Indices: [j0, j1, j2, … , jNNZ]
▪ BoomerAMG
Data: [a0, a1, a2, … , aNNZ]
— Ruge-Stüben AMG
— C/F splitting (coloring scheme or
maximal independent set)
— Operator-based interpolation
— Galerkin coarse-grid operators
— Specialized solvers for elasticity, H(div),
H(curl), etc.
▪ Widely applicable, but no
exploitation of structure
6
LLNL-CFPRES-2012828
SSAMG is a new block-structured AMG that
is widely applicable and highly efficient
▪ Semi-Structured interface
— Block-structured domains
— Node, edge, face, cell variables
— Matrix consists of struct matrices for
each part/var and a ParCSR matrix
▪ SSAMG (new as of hypre 3.0)
— Semi-coarsening within parts
— Operator-based interpolation
— Galerkin coarse-grid operators
PTAP = (Ps + Pu)T(As + Au)(Ps + Pu)
▪ Goal: broad applicability and
efficiency through use of structure

LLNL-CFPRES-2012828
Several algorithmic improvements for
SSAMG are still planned
▪ Default only includes structured interpolation within part
PTAP = PsT(As + Au)Ps
— No grows of the unstructured portion of the coarse-grid operators
— Simplified matrix product for coarse grids
▪ Including unstructured interpolation across part boundaries
— Can improve convergence
— More complicated matrix product
— Potential growth of unstructured portion
▪ Different coarsening strategies
— Currently only semi-coarsen by factor 2
— Full coarsening mimicked by “skip” option

Using unstructured interpolation can
lead to significant convergence benefits
▪ Test problem: 3D anisotropic diffusion
▪ SSAMG-PCG iteration counts decrease by 2x
when using unstructured interpolation
▪ Performant implementation is work in progress
