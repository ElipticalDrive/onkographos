# ShadingModels

A Java image generator that renders the same scene with three different shading / light-transport models so they can be compared side by side.

## Scene

A fixed configuration of **8 spheres arranged in 2 rows of 4**, lit by a single point light. The geometry and camera are identical across all three renderers — only the shading model changes.

## Renderers

| Mode      | What it does                                                                 |
|-----------|------------------------------------------------------------------------------|
| `blinn`   | Local Blinn-Phong shading (ambient + diffuse + specular). No reflections, no shadows. |
| `whitted` | Blinn-Phong + shadow rays + recursive mirror reflection (and refraction for transparent materials). |
| `path`    | Monte Carlo path tracing. Cosine-weighted hemisphere sampling, emissive surfaces as light sources, Russian-roulette termination. |

## Output

Each run writes a PNG to `results/<mode>.png`.

## Usage

```bash
javac -d out $(find src/main/java -name "*.java")
java -cp out com.rt.Main <mode> <spp> <out.png>

# examples
java -cp out com.rt.Main blinn
java -cp out com.rt.Main whitted
java -cp out com.rt.Main path 256 results/path.png
```

## Layout

```
src/main/java/com/rt/
  core/        Vec3, Ray, Camera, Intersection, Light
  geometry/    Hittable, Sphere, Scene
  material/    Material (diffuse, specular, reflectivity, ior, emission)
  shading/     Shader + BlinnShader / WhittedShader / PathShader
  render/      Renderer (pixel loop, PNG writer)
  Main         CLI entry point + scene setup
```

The `core` and `geometry` packages are adapted from the sibling `AccellerationStructures` project; everything in `shading/`, `material/`, and `render/` is new.
