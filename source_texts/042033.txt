This adds a --bf16 option that runs the NeRF MLP under bfloat16 autocast on CUDA. Ray sampling and volume rendering stay in float32: the MLP's output is cast back to float32 before rendering. It's off by default.
Measured on an NVIDIA L4 (24 GB) with 8 CPU cores, running python run_nerf.py --config configs/lego.txt on master against python run_nerf.py --config configs/lego.txt --bf16 on this branch: 50 training steps after 10 warm-up steps, two seeds, with both versions run back to back on the same machine for each seed.

That's 2.03x faster per step, with the same loss and 45% less peak memory.
The loss on this scene varies a lot between seeds, so a short run can only rule out large changes. A full training run is the better check of image quality.
