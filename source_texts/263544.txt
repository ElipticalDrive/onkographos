# Hash‑NeRF: Efficient Neural Radiance Fields with Multi‑Resolution Hash‑Grid Encoding

> *Efficient Neural Radiance Fields via Multi-Resolution Hash-Grid Encoding: Reproduction, Architecture Modification, and Empirical Evaluation*
> — Intezar Mehdi · Babar Ayub · Haider Rasool Qadri

This repository contains a PyTorch implementation of **Hash‑NeRF**, a fast NeRF variant that replaces sinusoidal positional encoding and a deep MLP with a **multi‑resolution learnable hash table** and a lightweight 4‑layer MLP.

The model trains on a free‑tier Tesla T4 GPU in **1‑2 hours** (40,000 iterations), reaching **24.19 dB PSNR** on Lego and **25.72 dB** on Chair — using only **~82 million ray samples** vs. 1.2 billion for original NeRF.
