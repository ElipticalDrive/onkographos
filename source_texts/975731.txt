Issue body actions
The frame sequence is advect → splat → divergence → pressure → gradientSubtract → advect dye (renderer.ts:561-614). There is no vorticity pass, and no curl computation in simulation.wgsl — its entry points are exactly advect, divergence, pressure, gradientSubtract, resample, splat.
Semi-Lagrangian advection (simulation.wgsl:73-92) is unconditionally stable but strongly numerically diffusive: the bilinear gather at sampleAt (:37-48) smears each backtrace, which is what kills small-scale rotation. The velocity dissipation on top compounds it:
```
// simulation.wgsl:90
let decay = 1.0 / (1.0 + advectParams.dissipation * u.dt);
```
Vorticity confinement is the standard companion pass to Stam's stable fluids and the single biggest visual-quality lever available here — swirls persist and curl instead of dissolving.
It slots in cleanly: one new entry point computing curl and adding the confinement force, plus a strength descriptor in settings.ts alongside the existing five so it is tunable from the panel and settable to zero.
Acceptance criteria
A frame runs a vorticity-confinement step after velocity advection and the splats and before divergence, so the pressure projection returns the field to divergence-free.
A strength vorticityConfinement is in NumericSettings with a descriptor in SETTING_DESCRIPTORS (minimum 0; maximum and default chosen empirically). It shows as a slider in the panel, is saved, restored and clamped through the same path as the other settings, and takes effect from the next frame without a rebuild.
At strength 0 the velocity field is unchanged by the step (the step may be skipped entirely).
The force arithmetic has a CPU twin tested in the style of projection.test.ts, pinning: a rotating field gains a force that strengthens the rotation; a uniform or irrotational field gains zero force; the force scales with the strength; the grid metric (toCells) is honoured; walls and wrapped edges are both handled.
The new pipeline, bind groups and uniform layouts are covered by tests in the existing derive-from-the-shader style, and pnpm run lint, pnpm run test:coverage and pnpm run build pass.
Out of scope: changing the advection scheme (e.g. MacCormack), changing other settings' defaults, visualising vorticity.
Spec answers
Input domain: none. Checked: no criterion parses free text; the only external input is the stored settings blob, already clamped by normaliseSettings.
Shared predicates: wall vs wrapped edge handling is defined once, by loadAt and applyVelocityBoundary in simulation.wgsl; the grid metric by toCells / toStored in projection.ts.
Failure policy: none. Checked: the change adds no external read or call; pipeline creation failure follows the existing createPipelines path.
Failure class: none. Checked: a feature addition, not a defect fix.
Reachable ends: a wall cell's velocity after the confinement force passes through the projection and gradientSubtract's applyVelocityBoundary, so the free-slip wall (zero normal component) holds.
