Goal (future / not an immediate implementation)
Once voxel smoke in #546 is working and profiled, explore one unified volumetric renderer for local voxel smoke and an optional lightweight atmospheric fog density function. Reintroduce distance/height fog only if before/after visual evidence shows a worthwhile improvement, not automatically.
The current atmospheric fog is deliberately being disabled in #545. This issue must not block that removal or the voxel-smoke feature.
Questions to answer
Can the existing local voxel density field and a cheap analytical heightFog(worldPos) feed the same extinction/in-scattering integration and composite, without rendering fog and smoke separately or double-counting scattering?
What representation gives acceptable detail and scale? Prefer local world-space smoke grids + procedural atmospheric density, not one massive 3D grid covering the full 900 m atmosphere. Evaluate camera-aligned froxels only with an identified benefit.
Can far fog use closed-form Beer–Lambert transmittance / lower sample budgets, while nearby dense smoke uses more expensive adaptive ray steps? Preserve RGB extinction and physically legible depth cues.
How should volumetric lighting reuse CSM and local lights with bounded cost? How should a half-resolution light/scatter buffer be reconstructed without depth halos, disocclusion smearing or temporal flicker given the current world TAA-before-fog order?
Does it materially improve day/sunset/night/long-street scenes versus no fog and the old fog baseline from chore(render): disable current fog and validate before/after visuals + performance #545? Check sky dome double-scattering, exposure, NVG post-processing and separate viewmodel composition.
Deliverable
A short architectural decision / bounded technical spike (not a new general-purpose rendering framework).
Matched final-frame A/B/C captures: fog off; former atmospheric fog; proposed unified density/rendering, in identical scene/lighting/time settings.
Matched GPU compute/pass timings and browser frame pacing under empty and smoke-heavy scenes, including resource footprint and visual artefacts.
Decide explicitly: ship unified atmospheric fog, keep voxel smoke with fog disabled, or pursue a smaller alternative. State measurable go/no-go criteria and minimal implementation follow-up if justified.
Constraints
Dependency: feat(fx): interactive GPU voxel smoke with bullet holes and volumetric lighting #546 for the working smoke field; use chore(render): disable current fog and validate before/after visuals + performance #545 visuals as baseline.
Do not independently resurrect the old fog pass or duplicate the voxel smoke implementation.
Preserve sky/clouds/IBL, world depth/TAA, atmospheric sky dome, heat haze, first-person rendering and lifecycle contracts.
Keep authored assets local and respect AGENTS.md / ARCHITECTURE.md.
Research context: https://youtu.be/VVSw3qgy3Nc ; Bart Wronski/Frostbite unified volumetric fog ideas, evaluated critically rather than copied wholesale.
