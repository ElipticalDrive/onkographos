Motivation
Introduce a playable browser-based voxel foundation that supports procedurally generated terrain, efficient chunk meshing, player control, and persistence.
Description
Add project scaffolding and build config including package.json, tsconfig.json, vite.config.ts, index.html, and README.md.
Implement core world systems in src/world and src/world/Chunk.ts with deterministic heightmap generation (src/utils/Noise.ts), chunk loading/unloading, and hidden-face voxel meshing that separates opaque and transparent geometry.
Add gameplay systems: block registry (src/blocks/BlockRegistry.ts), player controller (src/player/Player.ts), inventory (src/inventory/Inventory.ts), creature entity (src/entities/Glowhorn.ts), HUD (src/ui/Hud.ts), save system (src/save/SaveSystem.ts), and the application entry src/main.ts that wires rendering, input, raycast targeting, mining/placement and save persistence.
Include UI and presentation assets via src/styles.css and basic index.html canvas bootstrapping.

No automated tests were added or executed as part of this change.
