Repeated numerical refinement currently uses nsolve entrypoints that prepare symbolic evaluators per call. This adds a caller-prepared scalar callback API for reuse inside numerical sampling: nsolve_bracketed takes an existing value/derivative callable, a numerical sign bracket, and explicit tolerances/work limits.
The implementation uses native numeric-domain arithmetic throughout, including f64, double-double, multiprecision and tracked values. It safeguards Newton steps with bisection, reports nonfinite values, invalid brackets, stagnation and limits explicitly, and retains a native Newton correction at accepted roots so zero-centred coefficient uncertainty is preserved. Strict bracket stopping is the default; the optional Newton-correction policy is explicitly a local heuristic. Returned floating brackets are not certified intervals.
Regression tests live in src/solve/bracketed.rs.
Validation after rebasing onto main (436b108): 2 tests pass with cargo test -p symbolica --lib --features bincode,serde solve::bracketed -- --test-threads=1. Changed-file rustfmt and git diff --check pass.
