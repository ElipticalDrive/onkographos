VTK now supports ambient occlusion for volume rendering. It would be very interesting for InVesalius to have this functionality.
This activity must implement an option to enable or disable ambient occlusion. The VTK version must be checked; if it is a version lower than 9, a message should be displayed to the user indicating that it is not possible to activate this feature.
It is recommended to perform tests on different video cards as well.
