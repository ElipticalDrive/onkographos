Proven gap
Current accepted Render code already has:
open renderer representations rather than a closed Mesh | Sdf | Volume root enum;
RenderRepresentationProtocol::FieldDistance;
RenderFieldDistanceProtocolEvidence with exact/conservative error guarantees;
RenderFieldDistanceQuery and RenderFieldDistanceSample in scene meters;
R4 method requirements where representation requirements are alternatives;
semantic planning/compatibility for FieldDistance.
But the maintained path remains surface-only:
RenderSurfaceProtocolEvidence can declare a request-scoped semantic-input requirement;
R5 semantic_binding.rs normalizes only surface input bindings;
admit_render_plan_with_surface_inputs(...) admits only surface inputs;
deterministic admission rejects a selected representation with no surface input;
deterministic execution/WGSL physically realizes only sphere/plane surface inputs;
no maintained execution path turns a field-distance representation into pixels.
The proof-private R6 field sphere is not production authority.
Accepted SDF rendering designs require sparse/sampled fields as renderer representations and real visual runtime proof. A game-owned shader, source-domain type tunnel, or mesh proxy would violate that architecture.
Mission
Extend the existing maintained semantic renderer with one narrow, request-scoped sampled field-distance input family and one bounded field evaluator, while keeping semantic values separate from physical realization and preserving current surface rendering.
Do not create a universal dynamic-input registry.
Selected Render contract
Parallel typed field input
Add a renderer-owned field semantic-input module parallel to surface_input.rs.
The first public shape represents one finite sampled signed-distance field in representation-local metric space with explicit:
finite local origin/bounds;
finite positive sample spacing or equivalent deterministic grid geometry;
bounded dimensions of at least 2 samples per axis;
finite signed-distance estimate samples in representation-local metres;
one finite non-negative maximum absolute field-query error bound in representation-local metres applying to the deterministic trilinear reconstruction;
temporal validity;
optional source generation for cache/history invalidation.
The error carried here is the current binding's pointwise FieldDistance query error evidence. It is not a generic source/product quality score and does not replace RenderRefinementEvidence.
Keep the semantic axes distinct:
```
FieldDistanceGuarantee
    pointwise error of renderer FieldDistance queries

current field semantic-input error
    source-owned bound for this request-scoped sampled value
    that must fit the representation's declared FieldDistance guarantee

RenderRefinementEvidence
    separate representation refinement/model relation
    when such a relation is independently claimed
```
For GP1B3, the World metric contract's conservative signed-distance reconstruction bound may supply the current field-query error because that contract already bounds the reconstructed distance estimate against the intended signed distance. Do not copy the same number into refinement merely for symmetry; use refinement only when a distinct finer/source-model relation is actually claimed.
Expose validated constructors/accessors. Reject non-finite values, any dimension below 2, invalid spacing, sample-count mismatch, negative/non-finite query error, and derived-bound overflow. Expose the derived finite local metric bounds so execution does not re-infer domain extent.
For the first dense-field contract, semantic binding requires the concrete representation's intrinsic RenderSpatialCoverage to be finite and to match the sampled input's derived local metric bounds exactly. A finite grid must not satisfy an unbounded representation or a different finite domain and then silently turn out-of-grid queries into misses. Partial/subset/superset coverage relations require separate consumer evidence; do not generalize them here.
Keep the public surface concrete to this consumer. No Any, string-keyed bag, generic byte payload, source-domain product type, GPU handle, or closed global representation enum.
Field protocol requirement
Give RenderFieldDistanceProtocolEvidence the same explicit request-scoped prerequisite capability already used by surface evidence.
A concrete field representation may declare that a current field semantic input is mandatory.
Planning/admission must fail closed when:
the selected field representation requires an input and none is bound;
the binding targets another representation;
validity/coverage does not satisfy the request;
source generation is incompatible with retained history;
the current sampled-field query error, transformed into scene metres by the accepted exact similarity scale, exceeds the selected representation's declared FieldDistance guarantee.
This preserves accepted R3 semantics: RenderFieldDistanceSample is a bounded estimate of the true signed distance, and an exact guarantee means zero pointwise query error. A trilinear scalar reconstruction must not be relabeled exact merely by declaring its interpolant to be the representation field.
Surface and field prerequisites remain separate typed families.
R4 maintained-method alternative
For the maintained deterministic method, add FieldDistance as a legal alternative representation requirement only where the first consumer is proven:
perspective radiance;
perspective distance/depth;
perspective object identity.
Do not broaden probe/other outputs merely for symmetry.
The accepted R4 vocabulary already distinguishes exact and bounded field-query guarantees, but a fixed world-scale threshold is not a truthful method capability for this evaluator. Add the smallest consumer-proven requirement form equivalent to Conservative:
Exact still means zero pointwise query error;
Bounded { max } remains useful when a method truly requires a fixed maximum;
Conservative means the method can semantically consume any representation carrying an explicit finite non-negative FieldDistance guarantee; it does not mean unknown/unbounded error.
R4 planning therefore validates that a conservative guarantee is explicit. R5 execution admission remains free to reject a concrete field/grid/error combination when the finite step budget, hit tolerance, or evaluation extent cannot make progress safely. This preserves semantic applicability != current executability and avoids hard-coding the maintained arena's physical scale into generic RunenRender method semantics.
The existing surface alternatives remain valid.
Maintained execution
Extend deterministic admission/lowering/execution so one output may contain both:
existing analytic surface objects (sphere/plane); and
bounded sampled field-distance objects.
For a sampled field object:
classify the object's accepted local_to_scene field transform;
require an exact positive similarity-transform distance scale in the first maintained contract; translation, rotation/reflection orientation handling, and uniform positive scale are supported, while non-uniform/sheared affine field objects fail closed even when a conservative lower-bound scale exists;
transform the ray/query into representation-local metric space;
sample/interpolate the field deterministically;
convert the local metric estimate and current binding query-error bound to scene metres through the exact similarity scale; validate that scene-space error against the selected R3 FieldDistance guarantee and use max(0, abs(estimate) - error) as the conservative safe lower-bound basis;
enforce a fixed finite step budget and finite evaluation extent;
refine/hit only within the declared error/tolerance policy;
derive an oriented normal from bounded local field samples/finite differences for the existing radiance path;
choose the nearest valid result against analytic surface hits;
retain scene object/material/object-id semantics from the ordinary RenderSceneSnapshot.
This restriction is semantic, not merely an implementation shortcut. The accepted public FieldDistance query/result contract is in scene metres, and the existing conservative non-similarity transform classification supplies only a safe lower-bound scale; it does not by itself prove an error-bounded scene-distance estimate. Broader affine field execution requires separate semantic authority rather than silently weakening R3.
One field representation must not cause one fullscreen pass per entity. The accepted SDF policy is one bounded view evaluation over the selected candidates.
Physical realization
The first implementation may realize the finite sampled field through a renderer-owned buffer/texture representation internal to deterministic execution. Backend objects stay private.
The public semantic input is not a GPU resource and must remain usable by a future standalone RunenRender extraction.
Do not depend on world_sdf, WorldSdfPayloadRef, ProductIdentity, chunk IDs, or gameplay types in the generic Render contract.
Generation / temporal history
Field source generation must participate in the same compatibility/history-reset rules as other maintained semantic inputs. Reconcile this against accepted #1067 state before implementation; do not create a parallel temporal-history authority.
The current T2 execution path records surface semantic-input generations in its retained-history compatibility key. When physical field execution activates after #1095 releases deterministic_execution.rs, field generations must join the existing accepted semantic-input generation compatibility set rather than create a second history key or field-only reset path. Mixed surface+field frames must reset when either selected input generation becomes incompatible.
Required proofs
At one unchanged reviewed head prove at minimum:
valid finite sampled-field input construction with an explicit finite non-negative pointwise query-error bound;
non-finite/bad dimensions/sample-count/spacing/error and derived-bound overflow reject;
a field representation can require one request-scoped field input;
missing/mismatched/invalid field input rejects admission, including finite sampled-grid coverage that does not exactly match the concrete representation's finite intrinsic coverage;
exact representations reject non-zero current query error, conservative representations accept only bindings whose scene-scaled error is within the declared R3 FieldDistance guarantee, and independent RenderRefinementEvidence remains a separate axis;
existing sphere/plane surface inputs still admit and render unchanged;
a synthetic metric sampled sphere field produces non-background perspective radiance;
perspective depth/distance and object identity identify the field hit correctly;
a scene containing both an analytic sphere and sampled field selects the nearest hit correctly;
translation/rotation/uniform-scale object transforms move/scale the field representation without rewriting source field values, and non-similarity affine transforms fail closed;
finite evaluation extent and finite step budgets fail closed;
conservative-error stepping uses the admitted scene-space FieldDistance error bound and does not overstep the synthetic known surface in the maintained proof;
numerical field normal is finite/stable enough for the maintained oriented-radiance path;
field source-generation change invalidates incompatible retained temporal history through the accepted mechanism;
one field object does not multiply fullscreen passes by entity count;
no world_sdf/World/game/Product dependency enters the generic Render semantic module;
existing exact-head Render Lab founding/temporal/Vulkan proofs remain green.
Prefer a synthetic renderer-owned field fixture whose analytic reference is known. Do not use the maintained game as the generic Render proof.
