Context
Currently, Cornerstone isn't able to load single-slice volume in a volume viewport.
However, the stack viewport in vtk is more or less a single slice vtk volume viewport, so it is be possible to enable single slice volumes in the volume viewport. (thanks @wayfarer3130)
There is logic in place that assumes multiple slices. This PR fixes it, allowing single slice volumes in CS3D.
Changes & Results
Handle 1-slice case in util files for loading volumes
Use pixel spacing in columns/rows to make cubic voxels
Prevent scrolling if 1 slice only
Small additional style changes
