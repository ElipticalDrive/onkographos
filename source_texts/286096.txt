# VoxV2

Prototype mobile voxel renderer for Unity 6, built around chunked voxel storage,
Burst-compiled greedy meshing, procedural generation, and a top-down mobile
player controller.

The project is a source-only package snapshot: it keeps the reusable runtime,
editor tooling, shaders, resources, and test scenes without Unity `Library/`,
IDE caches, build outputs, or local machine state.

## Highlights

- Chunked world storage with sectioned vertical layout
- Burst + Jobs greedy mesher with light-aware merge rules
- Procedural terrain, vegetation, rivers, landmarks, and imported-world data
- Top-down player controller with camera rig, autojump, block break/place, and
  mobile-friendly input
- Blueprint/build systems, hotbar UI, FPS counter, zoom slider, and aim ghosts
- Editor tooling for bootstrap setup, texture-array generation, and world import

## Layout

- `Runtime/` - runtime asmdef `VoxV2.Runtime`, namespace `VoxV2`
  - `Core/` - `VoxChunk`, `VoxWorld`, `VoxBlock`, `VoxConstants`
  - `Mesher/` - `VoxMesher` greedy mesher
  - `Generation/` - procedural generation and imported-world data
  - `Player/` - controller, camera rig, build/blueprint systems
  - `UI/` - hotbar, palette, FPS counter, zoom slider
  - `Config/` - ScriptableObject-style world, generation, player, and input configs
  - `VoxV2Bootstrap.cs` - entry point
- `Editor/` - custom inspectors, world importer, batch setup tools
- `Resources/` - materials, block arrays, modes, campaigns, and imported worlds
- `Shaders/` - voxel material shaders
- `Scenes/` - test scenes

## Engine

- Unity 6000.3.10f1
- URP 17.3.0
- New Input System
- Burst, Jobs, Mathematics, Collections
