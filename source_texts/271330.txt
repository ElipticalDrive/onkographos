build: add lint-ci and lint-full-ci targets (CI Docker image)
…
b8b54c1
```
Add make/just targets that run clang-tidy inside the published CI image
(ghcr.io/yoyonel/suckless-ogl-ci:latest) without requiring any local
toolchain:

- lint-ci      : Debug build + incremental lint via CI container
- lint-full-ci : same but with Tracy + SSBO features enabled

Container engine is auto-detected (podman first, then docker).
CMake configure and glad build happen fully inside the container at
/tmp/build-ci{,-full}, keeping the local workspace clean.
Lint cache is redirected to /tmp via --cache-dir to avoid permission
errors on read-only container mounts.
```
