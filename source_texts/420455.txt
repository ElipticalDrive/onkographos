playcanvas/engine#9098 adds off-center projection support to the engine: a generic camera.projectionOffset (Vec2, half-frustum NDC units), plus a PerspectiveCorrection script (scripts/esm/camera/perspective-correction.mjs) built on top of it.
The script implements architectural shift-lens correction: when the camera looks up or down, it levels the rendering camera and compensates with a vertical projection offset, so vertical lines stay parallel (two-point perspective) while the framing is preserved. It's still a plain pinhole projection, so splat rendering needs no shader changes and there is no per-frame cost — it works on both WebGL2 and WebGPU renderers.
It would be great to expose this in the viewer once the engine release containing #9098 is available:
a verticalCorrection setting (0 = true perspective, 1 = fully parallel verticals), either as a viewer setting or a UI slider
implementation is just adding the PerspectiveCorrection script to the camera entity and driving its verticalCorrection attribute
This is particularly effective for architecture / urban capture scenes — see the example in the engine PR (gaussian-splatting/lod-streaming example, Vertical Correction slider).
