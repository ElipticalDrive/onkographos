3D fractals — distance-estimated Mandelbulb & Mandelbox
Adds escape-time 3D fractals to the procedural toolkit. Each fractal has no
surface equation but admits a distance estimator (a lower bound on the
distance to the set), so the engine's existing sphere-tracer marches them like
any SDF — reusing the raymarch, finite-difference normal, IQ soft shadow, and
AO patterns. Surfaces are coloured from the orbit trap (minimum |z| over
the iteration) with an IQ cosine palette.
What's in it
procedural.fractal — two device @wp.func distance estimators returning
wp.vec4 (de, trap, escape_iter, final_r):
mandelbulb_de — White & Nylander triplex power z → z^power + p in
spherical coords, analytic DE 0.5·log(r)·r/dr via the running derivative.
mandelbox_de — Lowe box-fold + sphere-fold + scale, DE = |z|/|dr|.
scenes/mandelbulb — glowing power-8 Mandelbulb whose power morphs 2→8
over time as the lobes grow in; orbit-trap colour, soft shadows, AO, luminous
closest-approach halo, slow spin.
scenes/mandelbox — the iconic crisp ringed cube (scale −1.5), iridescent
orbit-trap colour, soft shadows + AO, tight edge glow.
Research — docs/research/13-3d-fractals.md (Mandelbulb/Mandelbox/orbit-trap
physics, cited: White-Nylander 2009, Lowe 2010, Hvidtfeldt DE series, Quilez).
Docs — gallery "3D fractals" section + tiles, procedural API reference entry,
README toolkit note + gallery tiles, scene count 94 → 96.
Tests — tests/test_fractal.py: in-kernel DE invariants (finite, ≥0,
monotone along a radial ramp, origin on the set, orbit trap bounded).
Verification
python -m tests.test_fractal → ALL PASSED (plus test_procedural,
test_engine, test_public_api, test_raytrace green).
mkdocs build --strict → exit 0.
Both scenes rendered and visually verified (previews under docs/engine/):
the Mandelbulb reads as intricate glowing power-8 lobes with iridescent shells;
the Mandelbox reads as the recognizable ringed cube with concentric-eye faces.
CPU-verified here; the kernels scale unchanged to CUDA.

procedural/fractal.py: two device @wp.func distance estimators for the engine's
sphere-tracer. mandelbulb_de(p, power, iters) iterates the White-Nylander triplex
power z -> z^power + p in spherical coords with a running derivative for the
analytic DE 0.5*log(r)*r/dr (power 8 = the classic look). mandelbox_de(p, scale,
iters) does Lowe's box-fold + sphere-fold + scale, DE = |z|/|dr|. Each returns
vec4(de, orbit_trap, escape_iter, final_r) — the trap (min |z|) + escape iter
drive the colouring. Exported from `procedural`.

Verified by tests (test_fractal, in-kernel): both DEs are finite, non-negative,
grow monotonically along a radial ramp outward, and read ~0 at the origin (which
is on the set); the Mandelbulb orbit trap is recorded + bounded. ALL PASSED.
