I'm not sure this applies to a Godot implementation... remember this module can't litterally replace Godot's renderer, it has to work within its limitations.
Maybe doable with shaders, but then everything else in Godot becomes somewhat unusable (non-voxel entities, shadow mapping and all the rest). It's almost like this would need to be its own engine to be used at full potential.
That voxplat looks impressive though, could be worth getting a test of this running in Godot, probably doesn't need this module given it's all shaders? One area it could be definitely useful is for far-away terrain, like said in the repo.
