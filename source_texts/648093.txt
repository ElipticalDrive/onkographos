目的
height fieldの勾配からnormalを生成し、共有directional lightによるsurface shadingを実装する。
このIssueの重要な検証は、光源を動かしたときにhighlightがCSS offsetではなく 曲面上を連続的に移動すること。
Normal生成
height field H(x,y) の有限差分からnormalを求める。
概念:
```
dx = H(x + ε, y) - H(x - ε, y)
dy = H(x, y + ε) - H(x, y - ε)

N = normalize(vec3(-dx * sx, -dy * sy, normalScale))
```
実際のscaleはscene unit / render-target resolutionを考慮して決める。
forward/central differenceの選択理由をコメントすること。
Lighting
このIssueではmaterial Issueより前なので、最低限のsurface responseでよい。
必須:
shared directional light
diffuse term
simple specular termまたはdebug specular
ambient/fill最低限
ただし最終material modelは #16 で置き換える前提。
必須debug view
Height
Normal RGB visualization
xyz → rgbへ可視化
Diffuse-only
Specular-only
Combined shading
Normal mapを出さず最終色だけで完了にしない。
視覚テスト
light directionを左右へ動かしたとき:
rounded edgeの明るい側が連続的に移動する
反対側が暗くなる
highlight位置が単純なbox-shadow offsetでは説明できない
surface中央のflat regionとedge regionでnormal responseが異なる
非目標
physically complete material presets
GGX tuning
cast shadow
multiple object occlusion
DOM
React
禁止
box-shadow
CSS gradientをlight responseの代用にする
normalを固定ベクトルにする
light.xyから単純にhighlight位置を平行移動するだけ
Acceptance Criteria
height bufferからnormal bufferを生成する
flat surface中央ではnormalがほぼ+Zを向く
bevel/edgeではheight勾配に応じてnormalが傾く
normal値が正規化される
normal debug viewを表示できる
directional light変更がpixel shadingへ反映される
light移動に対してhighlightが曲面上を滑る
deterministicな小fixtureでnormal計算をtestできる
Definition of Done
Height geometryが実際にsurface orientationへ変換され、そのorientationがlightingを決めていること。
DeepSeek / 実装担当への進行ルール
このIssueを実装するときは以下を厳守する。
このIssueのscopeだけを実装する。 後続Issueの機能を先回りして作り込まない。
実装前にParent / Depends onのIssueを読み、そこで固定された座標系・buffer意味論・禁止事項を変更しない。
Acceptance Criteriaを別手段で「それっぽく」満たしたことにしない。特にSDF / height / normal / visibility等、明示された中間表現は実際に生成する。
禁止事項に書かれたCSS近似やshortcutをrenderer coreへ持ち込まない。
debug viewが要求されているIssueでは、最終見た目だけでなく中間bufferを人間が確認できる出力を残す。
