Advanced nanoscale imaging techniques increasingly produce multivariate volumetric datasets containing multiple channels per voxel, such as elemental maps from X-ray fluorescence tomography, electron energy loss spectroscopy (EELS), or multimodal imaging combining complementary techniques. Traditional single-channel visualization requires viewing each channel separately, making it difficult to observe important cross-channel correlations and spatial relationships. Previous work demonstrated prototype multivariate volume rendering capabilities using radial colormaps and interactive lens exploration [1-3]. Here we present ongoing work to integrate these techniques into VTK, ParaView, and both desktop and web-based Tomviz platforms for production use. Building on our Phase I SBIR prototypes, we are integrating multivariate volume rendering into the core VTK [4] visualization library and ParaView [5] platform - the first implementation of multivariate volume rendering in these widely-used libraries - to make these capabilities broadly accessible. The radial colormap approach maps N-dimensional voxel values to a circular color space, enabling simultaneous visualization of channel relationships. Our development effort includes HPC-enabled radial color filters in VTK for scalable parallel rendering, an interactive transfer function editing with histogram-based channel control, reusable web components using the trame framework [6] for browser-based visualization, and a web-based Tomviz deployment with client-server architecture for remote visualization. The web-based architecture enables access from mobile, desktop, cloud, and HPC platforms while maintaining desktop Tomviz’s full capabilities. The new color-opacity transfer function editor has been developed as a modular, open source trame component, enabling its reuse across multiple ParaView-based applications beyond Tomviz (Fig. 1). This component provides interactive opacity editing for precise control over visible data ranges in volumetric datasets and has already been integrated into other visualization workflows. The trame-based Tomviz application architecture leverages these reusable open source components to enable full pipeline editing, operator customization, and responsive 3D visualization accessible through standard web browsers, with multi-view rendering capabilities shown for nanoparticle tomography data (Fig. 2). The radial colormap approach integrated into ParaView successfully reveals spatial correlations between multiple elemental channels that would be difficult to perceive using traditional single-channel visualizations, enabling interactive exploration of datasets with millions of voxels (Fig. 3). The integration of multivariate volume rendering into VTK and ParaView will make these capabilities broadly accessible across the scientific visualization ecosystem, with applications spanning materials science, medical imaging, and biological microscopy. With VTK downloaded more than 1 million times per month, this work will impact a substantial user community. The web-based Tomviz platform addresses the growing need for remote visualization of large tomography datasets on powerful workstations or HPC resources, complementing the established desktop application. Together with ongoing development of AI-assisted segmentation and annotation frameworks, these production-ready tools will enable the materials microscopy and broader imaging communities to efficiently explore increasingly complex multivariate datasets that were previously difficult to visualize and analyze [11].
