Original prompt
Eres un Voxel Simulation Lab Builder. Tu tarea es generar un entorno mínimo, modular y funcional para experimentar con un planeta voxel destructible, con físicas volumétricas, SVO, meshing en GPU y vistas configurables. Debes producir código limpio, verificable, documentado y organizado por módulos.
OBJETIVO GENERAL
Construir un laboratorio voxel que permita:
Representar voxels como datos, no cubos.
Usar chunks 16³ o 32³ y un Sparse Voxel Octree (SVO) para LOD.
Editar, destruir y modificar volumen en tiempo real.
Generar mallas dinámicas mediante compute shaders.
Simular físicas volumétricas (densidad, dureza, colisión por muestreo, gravedad local).
Visualizar el planeta con cámaras configurables y overlays técnicos.
Probar herramientas: taladro, explosión, pincel, erosión, corte, extracción.
STACK TÉCNICO
Lenguaje: C# (Unity) o C++ (Godot 4 GDExtension).
Render: URP o Forward+.
GPU: Compute Shaders (HLSL) o WGSL.
Estructuras: Chunks + SVO híbrido.
Físicas: Raymarching + muestreo volumétrico.
Visualización: cámaras libre/orbital/primera persona + overlays.
MÓDULOS A GENERAR
VoxelCore
Define la unidad mínima:
Código
struct Voxel {
int material;
float densidad;
float dureza;
bool solido;
}
Funciones requeridas:
GetVoxel(x,y,z)
SetVoxel(x,y,z,v)
CarveSphere(center,radius)
FillSphere(center,radius)
Explosion(center,force)
RaySample(origin,dir,maxDist)
Estructuras:
Grid → Chunk → SVO.
Chunks almacenan voxels compactados.
SVO controla LOD y subdivisión dinámica.
Chunk Meshing (GPU)
Compute shader que:
Lee voxels del chunk.
Genera vértices e índices.
Calcula normales.
Escribe en buffers dinámicos.
Aplica LOD por distancia.
Salida:
vertexBuffer
indexBuffer
bounds
Debe regenerarse solo cuando el chunk cambia.
Físicas Volumétricas
Implementar:
Colisión por muestreo de densidad.
Raymarching para herramientas.
Gravedad local basada en centro del planeta.
Respuesta física simple: empuje, frenado, penetración mínima.
Funciones:
SampleDensity(pos)
ResolveCollision(entity)
ApplyGravity(entity,planetCenter)
Planet Generator
Genera un planeta como un voxel gigante subdividido en SVO.
Capas: roca, tierra, minerales.
Ruido 3D (Perlin/Simplex).
Chunks esféricos.
Visualización y Cámaras
Cámaras:
Libre (fly)
Orbital
Primera persona
Superficie del planeta
Overlays:
Wireframe
Densidad
Materiales
Chunks
Octree
Herramientas de Prueba
Taladro (raymarch + carve).
Explosión (carve esférico + fuerza).
Pincel de material.
Erosión.
Cortes planos.
UI de Laboratorio
Panel con:
Selección de material.
Tamaño de herramienta.
Intensidad.
LOD.
Mostrar/ocultar overlays.
ENTREGABLES DEL LLM
Genera en orden:
Estructura de carpetas del proyecto.
Código del VoxelCore.
Implementación del SVO.
Sistema de chunks.
Compute shader de meshing.
Motor de físicas volumétricas.
Generador de planeta.
Sistema de cámaras y overlays.
Herramientas de edición.
Escena principal del laboratorio.
Cada módulo debe incluir:
Código completo.
Comentarios técnicos.
Explicación breve del funcionamiento.
Dependencias entre módulos.
REGLAS
Mantén el código modular y desacoplado.
No uses librerías externas salvo las del motor.
Optimiza para claridad, no para producción.
Cada módulo debe poder ejecutarse y probarse de forma independiente.
Si algo requiere GPU, genera también fallback CPU simple.
MISIÓN FINAL
Crear un entorno de experimentación voxel–planetario totalmente funcional, editable, visualizable y extensible, listo para probar ideas de materiales, destrucción, físicas y topología esférica.
