💡 What
Extracted hot mathematical helper functions (grad, lerp, fade, and permutation arrays) out of the Noise and CLOUD_NOISE object scopes and directly into their respective module scopes. Additionally, we've inlined simple math expressions and simplified loop properties.
🎯 Why
In hot inner loops representing millions of procedural terrain queries, calling functions attached to an object (e.g. this.noise, this.lerp) invokes expensive Javascript property lookups that V8 struggles to fully optimize due to scope bindings. Refactoring them to module scope completely eliminates this object property lookup overhead.
📊 Impact
Perlin Noise (3D): ~20% improvement (from 134ms down to ~107ms median) by un-nesting lerp chains and extracting module variables.
Value Noise (Cloud fbm2D): ~10% improvement (from ~100ms down to ~94ms median) by extracting mathematical interpolation state caching in the inner loop block.
🔬 Measurement
Run node scripts/perf.mjs to observe that both noise generators are now passing strictly within the tight performance budgets. Run npm test to verify zero precision regressions.
