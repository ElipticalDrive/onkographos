Summary
Implements DX11 Enhanced Phase 3 atmospheric rendering for base/object and terrain SM4 shaders.
Rendering changes
Replaces Enhanced per-pixel linear fog with authored-range-driven exponential-squared extinction.
Adds aerial perspective and conservative scene/ambient atmospheric coloration.
Adds primary directional-light forward scattering with a safe non-directional fallback.
Adds camera-relative height fog and horizon haze on Enhanced High + static IBL, reusing the existing inverseViewMatrix binding.
Separates Enhanced emissive contribution so it receives reduced atmospheric extinction rather than being erased at the same rate as reflected lighting.
Keeps atmosphere post-GGX/post-IBL; no BRDF tuning was changed.
Preserves current terrain roughness/F0/IBL specular calibration and terrain detail behavior.
Removes the obsolete magenta IBL debug marker and adds CR_ATMOS_DEBUG_MODE diagnostic views.
Compatibility
DX11 Enhanced per-pixel tiers: exponential/aerial atmosphere.
Enhanced High + IBL: full height + horizon model.
Vertex-lighting fallback, OG Retro, and non-Enhanced: legacy linear fog unchanged.
No new engine hooks, framebuffer/depth sampling, post-processing, HDR, SSR, SSAO, bloom, or ray marching.
No new material/program bindings were required; Enhanced High IBL already binds inverseViewMatrix.
Validation/tooling
Extends Tools/Validate-DX11Shaders.ps1 with atmosphere debug compile permutations while retaining existing Enhanced/IBL/PSSM/Retro/vertex fallback cases.
Adds Docs/DX11_ENHANCED_ATMOSPHERE.md with calibration constants, mission-fog mapping, tier behavior, limitations, debug modes, and runtime checklist.
Runtime validation focus
misn04 is a useful first scene, but the implementation is mission-agnostic. Validate light/heavy authored fog, sun-facing and sun-away horizons, elevated/valley terrain, emissive vehicles/buildings, PSSM/no-shadow, and Retro comparison.
Validation status
Final PR diff is limited to the two DX11 SM4 shaders, shader validation matrix, and atmosphere documentation.
The PR is mergeable with main.
fxc.exe is not available in the current Linux execution environment, and this repository currently has no PR-triggered shader-validation workflow, so the updated PowerShell matrix still needs to be run on Windows with a Windows SDK before merge.
