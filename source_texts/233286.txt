Description
Adds modules/experimental/splat: an interactive 3D Gaussian splat viewer built on the SDL3 GPU API, with OpenInventor examiner-style navigation. It doubles as a self-contained learning reference on Gaussian splatting for readers new to the topic.
Rendering pipeline
At load time the CPU converts each splat's scale and rotation into a 3D covariance, Σ = R·S·Sᵀ·Rᵀ, and uploads the scene once to a storage buffer.
When the camera moves, a worker thread (AsyncSorter) sorts splats far to near using a 16-bit counting sort, which is O(N). Rendering keeps the last order until a new one is ready.
One instanced draw call renders a 4-vertex quad per splat.
splat.vert projects the covariance to screen space (EWA: Σ' = J·W·Σ·Wᵀ·Jᵀ), eigen-decomposes it and emits a quad covering ±3σ.
splat.frag evaluates α·exp(-½r²) and outputs premultiplied colour.
Blending uses the premultiplied "over" operator, with no depth buffer.
Shaders are GLSL, compiled to SPIR-V at build time by glslangValidator and embedded as generated headers, so only the Vulkan backend is supported.
Navigation (ExaminerCamera)
Virtual-trackball rotation about the focal point, with inertial spin after release.
Pan, dolly (drag and wheel), seek (pick a splat and fly towards it), view all, and home / set home.
View all frames the median position and median radius, so the sparse shell of distant background splats in captured scenes doesn't dominate.
Formats (file_io.h)
.splat (antimatter15, 32 bytes per splat) is the native format, read and write.
3DGS binary .ply can be read; only the degree-0 (view-independent) colour is used.
Layouts are documented in docs/file_formats.md.
scripts/spz_to_splat.py converts Niantic SPZ v2 files and maps their y-up axes to the y-down convention used by .splat.
Sample models (models/, Git LFS)
hornedlizard.splat and racoonfamily.splat, converted from Niantic's SPZ samples (MIT).
f3d_small.splat from f3d's test data (BSD-3-Clause).
Licence texts and attribution are included.
Educational material
docs/gaussian_splatting.md is a first-principles primer: gaussians and covariance, projection, compositing, sorting, and how scenes are trained.
It includes a concept-to-code table, experiments to try and a glossary.
The shaders are commented as numbered steps that match the primer.
SDL GPU wrappers (src/gpu.h) and the sorting thread (src/async_sorter.h) live in private files, so viewer.cpp reads top-down as the algorithm.
Repository-wide changes
.gitattributes: LFS rules for *.splat and *.ply.
toolchains/install_base.sh: installs glslang-tools.
```
grape_splat_view --file=modules/experimental/splat/models/hornedlizard.splat   # --up=-y default (y-down scenes)
```
Known limitations
Vulkan only.
Degree-0 colour only, so no view-dependent effects.
Ordering is by splat centre, so intersecting splats can briefly "pop" as the view changes.
Not yet built with GCC.
Racoon and f3d model orientation not visually confirmed.
