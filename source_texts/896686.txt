## 这是什么

Voxel Terra 是一次极限 AI 工程实验：在约 24 小时内，从零构建一个可实际游玩的 Minecraft 风格浏览器生存游戏，而不是只做一段地形 Demo。

除了人类提出目标、反馈体验和验收结果外，项目的程序架构、TypeScript 实现、游戏系统、视觉资产工作流、自动化测试、性能优化与文档均由 **GPT-5.6-Sol** 在 Codex 中完成。

它包含程序化世界、生存循环、合成与熔炼、装备和附魔、村庄与交易、生物 AI、昼夜天气、存档系统，以及桌面和移动端界面。所有内容直接运行在浏览器中。

> **AI-native, not AI-mocked.** 这里没有预渲染的假游戏画面。README 中的图片全部来自项目真实运行画面，并由自动化浏览器验收流程捕获。

## 24 小时里做了什么

- **程序化世界**：384 格垂直世界、群系、洞穴、河流、矿脉、树木、植被与结构生成。
- **PBR 方块渲染**：独立颜色、法线、粗糙度和自发光图集，支持水体、熔岩、火把与点燃熔炉。
- **完整生存循环**：生命、饥饿、溺水、跌落、窒息、燃烧、护甲、死亡与重生。
- **采集与制造**：工具等级、耐久度、掉落物、2x2/3x3 合成、工作台、熔炉与燃料系统。
- **装备与附魔**：武器、工具、四件护甲、经验等级、青金石，以及锋利、效率、时运、保护、耐久。
- **动态村庄**：稀疏结构网格、建筑台地、农田、道路、战利品箱、四种职业村民、猫与交易。
- **九类生物**：牛、羊、猪、鸡、僵尸、骷髅、蜘蛛、村民和猫，包含寻路、战斗、繁殖与掉落。
- **可交互世界**：箱子、床、双格门、弓箭、液体传播、昼夜循环、天气与空间音效。
- **工程化质量**：Web Worker 区块构建、IndexedDB V2 存档、响应式 UI、中英文物品名与画质设置。
- **自动化验证**：20 个测试文件、166 项测试、类型检查、生产构建和桌面/移动端浏览器视觉回归。

## 技术架构

```mermaid
flowchart LR
    UI[React 19 UI] <--> STORE[Zustand State]
    STORE <--> ENGINE[TypeScript Voxel Engine]
    ENGINE --> WORKER[Web Worker Chunk Builder]
    ENGINE --> THREE[Three.js / WebGL]
    ENGINE <--> SAVE[IndexedDB Save V2]
    WORKER --> WORLD[Procedural World]
    THREE --> PBR[PBR Texture Atlases]
```

核心技术：**TypeScript 5.9 · React 19 · Three.js · WebGL · Zustand · Vite · Vitest · Playwright · Sharp**

## 立即运行

要求：Node.js 20.19 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:5173/`。

生产构建与验证：

```bash
npm run build:textures
npm run typecheck
npm test
npm run build
```
