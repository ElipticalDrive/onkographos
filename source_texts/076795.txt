This PR modernizes the Signed Distance Field (SDF) rendering system, addressing breakage from previous system-wide changes and adding new volumetric capabilities.
Key improvements:
Scalability: Shifted to SSBO management for SDF sources, allowing for many more simultaneous shapes.
Volumetrics: Added support for participating media rendering within SDF boundaries, enabling realistic smoke and explosion effects.
Integration: SDF sources are now managed via SdfShape, making them standard scene objects that can be positioned, scaled, and animated easily.
Performance: The new SdfVolumePass utilizes sphere tracing for fast surface detection and intelligent raymarching that only evaluates density near shape boundaries. Temporal reprojection is used to stabilize and optimize the final output.
Demonstration: Provided a new explosion modeling API and a minimal orange explosion demo to showcase the volumetric capabilities.
Additionally, a bug in WeatherManager that caused unit tests to fail was identified and fixed.
