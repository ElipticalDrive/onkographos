Swapped the sphere renderer from Phong-style specular highlights to a glass-like refraction model so the output reads as translucent material rather than glossy diffuse+specular shading.
Refraction-based lighting model
Replaced calculateLighting with calculateGlassLighting.
Added vector helpers (clamp, dot, normalize, refract) to compute refracted direction and light response.
Introduced glass parameters (GLASS_IOR, FRESNEL_POWER, REFRACTION_AMOUNT, TRANSMISSION) to control optical behavior.
Glass color composition
Replaced applyLighting with applyGlassLighting.
Combined distance attenuation + Fresnel edge term + refracted light term into RGBA output.
Added alpha/transmission blending to produce a translucent glass look.
UI/label alignment
Updated page title and preview heading from specular/phong naming to Glass Refraction for accurate behavior labeling.
```
const { diffuse, fresnel, refractiveLight } = calculateGlassLighting(
  d.x, d.y, d.z,
  lightPos.x, lightPos.y, lightPos.z,
  sphereCenter, sphereCenter, sphereCenter
);
const litColor = applyGlassLighting(d.baseColor, diffuse, fresnel, refractiveLight);
```
