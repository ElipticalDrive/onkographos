@ryanreadbooks @mkabtoul @zichunxx Hello, I have successfully called pcl.octree. The issue you encountered is due to using
pip install python-fcl
, as the official library does not include methods like insertPointCloud in the octree class, which causes the error
TypeError: cinit() takes exactly 2 positional arguments (1 given).
The editor might find the error to your local project, but the actual file fcl.pyx is located in /home/lu/.local/lib/python3.8/site-packages/fcl (lu is my system name). You can find that it is incomplete there, but please don’t attempt to modify it directly, as it won’t work, and do not update to the official 0.7.0.7 version since it still lacks the relevant content.
First, you need to uninstall the current library with:
pip uninstall python-fcl
Then, download one of these two projects from GitHub:
```
https://github.com/automatika-robotics/python-fcl
https://github.com/cedriclmenard/python-fcl-octomap
```
In the project, run
pip install .
to install. Make sure to check your pcl installation location. If you installed it with ROS, you will need to add "/opt/ros/noetic/include" to include_dirs in setup.py to avoid errors. After installation is complete, you can directly use any of the following code snippets to test:
import numpy as np
import fcl
x = np.random.random([100, 3])
resolution = 0.02
object1 = fcl.OcTree(r=0.02, points=x)
object2 = fcl.Box(1, 2, 3)
o1 = fcl.CollisionObject(object1, fcl.Transform())
o2 = fcl.CollisionObject(object2, fcl.Transform())
request = fcl.CollisionRequest()
result = fcl.CollisionResult()
req = fcl.collide(o2, o2, request, result)
print(req)
