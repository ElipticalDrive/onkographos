What
vf_pelorus_mc_vulkan emitted an integer-pel block-matching MV field. The roadmap's top lever — the ADR-0113 MC→denoise motion-compensated warp — needs sub-pel MVs to pay off (warping by an integer-pel MV still ghosts the moving regions). This refines mc to sub-pel and is the prerequisite the warp was gated on.
Changes
Sub-pel refinement (parabolic SAD fit). After the integer diamond search converges, evaluate the block SAD at the minimum and its 4 axis-neighbours and fit a parabola per axis; the vertex gives a [-0.5, 0.5] offset (taken only when curvature is positive). Reuses the cooperative block_sad — 4 extra workgroup reductions, no new fetches. A leading barrier() publishes s_best_*; a barrier() after each SAD avoids a WAR race on s_sad[].
Quarter-pel grid (Q2 fixed-point). Emit round((best+offset)·4), conforming the PelorusMotionSection MV grid to ADR-0113's long-specified ¼-pel contract.
Units coordination. Summary scalars (global_motion_*, motion_magnitude_*) stay in whole luma pixels (host ÷4). The NVENC ME-hint consumer (patch 0008) round-÷4 into its integer-pixel hint field — which also fixes the prior 4×-too-small hint (a plausible contributor to that path's measured no-gain; retest now unblocked).
Lockstep. pelorus_mc.comp mirrors the refinement (AGENTS rule 4).
ABI
PelorusMotionSection is unchanged (32 bytes, frozen) — the quarter-pel unit is a documented convention (interop.h comment), no PELORUS_ABI_MINOR bump. vmafx reads the pixel-domain scalars (unchanged), not the raw grid.
Validation
On a known ~0.51 px/frame scroll, measured global_motion_x ≈ 0.55 px (fractional) where integer-pel mc rounded to 0/1; quarter-pel sub-pel fractions present across the field.
nvenc.o compile-verified with --enable-nvenc — the encoder TU the patch-stack CI never builds (the PR fix(vulkan): runtime-only GPU defects across the filter family (chroma-passthrough macro + mc descriptors) #23 blind spot), so the ÷4 change + the hand-diff hunk-header fix are checked before merge.
Full 18-patch stack git am-applies; mc + mc→scenecut run clean on vk:0; meson test --suite=fast 11/11; pelorus_mc.comp glslang-clean.
Deliverables
ADR-0130 (+ index), docs/metrics/mc.md + interop.h unit docs, docs/rebase-notes.md entry (incl. the encoder-TU compile caution), changelog fragment + rendered CHANGELOG.md, regenerated patches 0007/0008/0011 (0011 = hunk-offset cascade only).
No new user surface → no new per-surface doc (the mc.md update covers the unit change).
Follow-up: per-block confidence (the second half of the half-pel+confidence plan) lands next as its own PR — it needs the append-only ABI extension + the vmafx mirror.
