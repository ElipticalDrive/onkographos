Implements the accepted 0.5-A transformations design.
Completed:
all six proper Euler and six Tait-Bryan sequences
intrinsic/extrinsic Euler semantics
shared tolerance validation
public SO(3) predicate with True/False/None symbolic semantics
public SE(3) predicate with True/False/None symbolic semantics
shared SO(3)/SE(3) private validators
quaternion conversions:
rot2quat()
quat2rot()
axa2quat()
quat2axa()
quaternion normalization, double coverage and canonical sign handling
robust dominant-component numerical matrix-to-quaternion conversion
symbolic quaternion conversion fallback
rotation-vector conversions:
rot2rotvec()
rotvec2rot()
shared axis/angle decomposition used by rot2axa() and rot2rotvec()
small-angle numerical series for rotvec2rot()
principal rotation-vector convention
vex() as inverse of skew() with tolerance-aware skew validation
invhtm() now validates rigid SE(3) structure
axa2rot(..., deg=True) for degree/radian symmetry
deprecated compatibility wrappers in moro.util:
is_SO3()
is_SE3()
isrot()
ishtm()
updated theory docs for Euler/Tait-Bryan, quaternions, rotation vectors, vex, and SE(3) validation
cleanup of redundant private tolerance helper
expanded transformations regression suite (119 tests in test_transformations.py)
Final verification status:
public functions and all exports are consistent
PR is mergeable
GitHub Actions test workflow added in .github/workflows/tests.yml; the final matrix validates Python 3.11, 3.12, 3.13 and 3.14.
