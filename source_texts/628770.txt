Author
This pull request introduces a differentiable voxelization feature to the codebase, including C++ and Python bindings, a new compute shader implementation, and updates to the ESLint configuration. The main focus is on enabling efficient and differentiable conversion of point clouds to occupancy grids, with gradient computation, which is useful for AI and graphics applications. Additionally, some test scaffolding has been removed.
Differentiable Voxelization Feature:
Added C++ implementation diff_voxelize.cpp for differentiable voxelization, computing both occupancy and point gradients, and optimized with precomputed weights and gradients for efficiency.
Introduced Python bindings in diff_voxelize.py to compile and call the C++ voxelization logic, with a user-friendly API for converting points to occupancy grids and retrieving gradients.
Exposed the Python API in the package via src/ai/__init__.py, making diff_voxelize available for import.
Added a new Vulkan compute shader diff_voxelize.comp.glsl for GPU-accelerated differentiable voxelization, supporting gradients and atomic updates to 3D images.
Configuration and Test Updates:
Updated eslint.config.cjs to ignore additional directories and set up proper environment globals for Node.js and ES2021, improving linting accuracy and developer experience.
Removed legacy and redundant test logic from test_capsule_ground.py related to capsule-ground collision, cleaning up test scaffolding. [1] [2]
