FROZEN LANGUAGE / SEMANTICS / COMPATIBILITY
Add source1-only torus #id;, type selector torus and existing ID selector through original parser/AST/cascade/compileGpu. Explicit version:1 and sourceVersion1 opt-in stay mandatory. Source0/default still rejects torus; source0/Scene0/IR1 and existing primitive meanings/shader lowering stay unchanged. Add an additive TorusSceneObject discriminant to Scene1/renderIR2, with majorRadius and minorRadius plus current common source1 data/rotation. Retain existing common fields/default placeholders if required by the original Scene1 contract; they do not create accepted torus radius/size properties. Original front end and structured compileScene/compileGpu must use the same admission/lowering, source ranges and diagnostics. No version bump/new package/dependency.
Torus is centred at local origin, its circle is in local XZ and its axis is local Y. major-radius is distance from origin to tube centreline; minor-radius is tube radius. Both are scene units, not native CAD millimetres. Defaults major1/minor.25. Local outer X/Z extents are2*(major+minor), local full Y extent2*minor; hole radius=major-minor. This child admits only an ordinary ring: finite0<minor<major, major+minor<=1000. Both represented Float32 radii must be positive/finite, represented minor<major and represented sum<=1000. Reject relational overflow/collapse after complete selector cascade and in structured admission; no clamp/heal or horn/spindle torus. Properties accepted for torus are major-radius/minor-radius plus current color/translate/rotate-x/y/z. Existing rotate degree bounds, translation/source/object/shader/step budgets are retained. Generic radius, size, height, start/end are refused for torus; new major/minor properties are refused on existing primitives. Later ID override can make a provisional type-rule radius pair valid; require final semantic relation, not premature relation checks.
In local coordinates after existing inverse rigid rotation/translation, lower the independently defined ring distance:
length(vec2(length(localPoint.xz)-majorRadius,localPoint.y))-minorRadius.
This is distance to the local centreline circle minus the tube radius; use original generated SDF helper/compiler, existing shading/ray marcher and update lifecycle. Original type semantic/IR carries radii without replacing a native CAD surface/packet. No analytic CAD torus, B-Rep, NURBS, Boolean/CSG, group instances, materials overhaul or commercial parity claim.
