Context
The TSDF pipeline (#8) and the in-viewer Voxelize button (#10) render the
fused volume as voxel cubes only. Wanted: a smooth triangle mesh of the
tsdf = 0 isosurface via marching cubes, with per-vertex colors, selectable
alongside the voxel view — in the main viewer's TSDF panel, in the standalone
VoxelViewer, and as a GLB export from the tsdf_fusion.py CLI. Extraction
works from the existing sparse band; no re-fusion needed. Dependency:
scikit-image (user-approved; trimesh's marching cubes delegates to it anyway).
Acceptance criteria
extract_mesh(band, min_weight=...) returns world-space vertices,
faces, per-vertex colors and normals from the sparse TSDF band, using
the observed-voxel mask (no phantom surfaces at unseen boundaries);
empty result handled as None
Main viewer: Scene dropdown gains "Mesh" — selecting it hides the
point cloud/voxels and shows the colored mesh; switching back needs
no recompute; Iso slider disabled in Mesh mode; Min Weight re-extracts
Standalone VoxelViewer: Render Mode gains "Mesh" with the same rules
Loading a new sequence invalidates the cached mesh
CLI: --mesh exports <output>_mesh.glb (loadable, vertex colors)
and defaults the viewer to Mesh mode; clear error if scikit-image
is missing
scikit-image added to the vis extra in pyproject.toml
Tasks
lingbot_map/utils/meshing.py: extract_mesh, mesh_to_trimesh,
export_mesh_glb (lazy skimage import)
voxel_viewer.py: add_mesh_scene + Render Mode "Mesh"
point_cloud_viewer.py: Scene "Mesh", lazy threaded extraction, cache
tsdf_fusion.py: --mesh flag
