This pull request introduces significant improvements and refactoring to the raytracer's core rendering pipeline, focusing on generalizing object intersection, improving performance, and enhancing realism in ray-object interactions. The major changes include replacing sphere-specific logic with a generalized SDF-based ray marching approach, introducing new rendering constants, and improving the handling of translucent and reflective materials.
Rendering Pipeline Refactor and Generalization
Replaced the sphere-only intersection logic in Renderer with a generalized ray marching algorithm using signed distance functions (SDFs), allowing support for more complex objects and efficient handling of object lists (Renderer.cpp, Renderer.hpp). [1] [2] [3] [4] [5] [6] [7] [8] [9]
Added new SDF-based object types (Box, Cone, CsgObject, Cylinder, Icosahedron, SquarePyramid, TriangularPyramid) to the build process, enabling the renderer to work with a wider variety of primitives (CMakeLists.txt).
Performance and Quality Enhancements
Introduced and tuned several new constants for ray marching, such as BOUNCES, REFRACTION_MIN, HIT_EPSILON, RAY_BIAS, MAX_STEPS, and more, to improve rendering quality, avoid artifacts, and prevent infinite loops in complex scenes (Renderer.cpp).
Changed OpenMP threading to use the number of available processors and switched to dynamic scheduling for better load balancing during rendering (Renderer.cpp). [1] [2]
Material and Lighting Improvements
Improved handling of translucent and refractive materials, including correct calculation of transmission, refraction, and Fresnel effects, and added logic to avoid self-intersection after bounces (Renderer.cpp). [1] [2] [3] [4]
Camera and Image Handling
Changed CameraFactory::getCamera() to return a const reference, avoiding unnecessary copies and improving efficiency (CameraFactory.cpp, CameraFactory.hpp). [1] [2]
Optimized OpenGL texture updates in ImageWrapper by using glTexSubImage2D for updating texture data and ensuring proper texture initialization and resizing (ImageWrapper.cpp). [1] [2]
Codebase Modernization
Updated includes and data structures to support the new SDF object list and generalization (Renderer.hpp).
These changes collectively make the renderer more flexible, efficient, and capable of rendering complex scenes with a variety of object types and material properties.
