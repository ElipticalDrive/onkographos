Summary
Adds a new 3D projected camera view to the TUI, toggled with the V key. The existing 2D slice view is preserved. Both views read from the same VoxelGrid with no intermediate framebuffer — each terminal cell is computed directly via DDA voxel raycasting and shape-aware glyph selection.
Key Changes
New 3D rendering pipeline (render3d.rs):
Orthographic camera projection with orbit controls
DDA (Digital Differential Analyzer) voxel raycasting per terminal cell
4-quadrant sub-ray sampling for shape-aware glyph selection
Face-based shading (top/side faces have different brightness)
Material-specific coloring with height-based ambient occlusion
Camera system (camera.rs):
Orbit camera with focus point, distance, yaw, and pitch
Orthographic projection (parallel rays, consistent scale)
Terminal aspect ratio correction (characters are ~2:1 height:width)
Methods for flying, panning, orbiting, and zooming
Glyph atlas (glyph.rs):
Curated set of ~20 ASCII characters with precomputed shape descriptors
4-value coverage pattern per glyph (top-left, top-right, bottom-left, bottom-right)
Euclidean distance matching to select best glyph for each cell
Inspired by Alex Harri's "ASCII characters are not pixels" technique
Input handling (input.rs):
Separated 2D and 3D input handlers
3D controls: WASD (fly/pan), Q/E (orbit), Shift+W/S (zoom), J/K (focus Z)
View toggle with V key (available in both modes)
App state (app.rs):
Added ViewMode enum (Slice2D / Projected3D)
Camera instance created on first switch to 3D mode
Focus synchronization between 2D and 3D views
Implementation Details
Raycasting: DDA algorithm with AABB grid intersection, handles near-zero direction components gracefully
Shading: Combines face orientation (top=1.0, X-face=0.75, Y-face=0.6) with height-based ambient (underground darker)
Glyph selection: Per-cell 4 sub-rays (2×2 grid) produce coverage pattern; closest glyph by Euclidean distance is chosen
Water special case: Fully-covered water cells render as ~ instead of shape-matched glyph
Sky gradient: Empty cells show height-based sky color (brighter at top)
Design Notes
See decisions/2026-03-12T16:00:00_3d_terminal_viewport.md for detailed rationale on orthographic vs. perspective, glyph descriptor design, and future work (perspective projection, overlays, minimap).

- A/D: pan camera left/right
- Q(shift)/E: orbit around focus point
- Shift+W/S: zoom in/out
- J/K: move focus up/down
- V: toggle between 2D slice and 3D projected view
- R: reset camera orientation

The existing 2D slice view is preserved and both views read from the
same VoxelGrid — no second scene graph or image conversion pipeline.
