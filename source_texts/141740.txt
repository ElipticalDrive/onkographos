Frequently Asked Questions
Common technical and compatibility questions
What versions of Nuke are supported?
This tool was compiled and optimized for Nuke 16 and Nuke 17. You must have a Nuke Indie or Nuke Commercial License. We have confirmed successful testing on the following setups:
Windows
RTX 3090 (Confirmed)
Linux
RTX 3090 (Confirmed)
Mac
Metal GPU (Confirmed)
Some Nuke 15 versions have also been tested to work. Pro Tip: If you encounter issues in Nuke 15, try turning off "Vectorize CPU" in the Blink node settings. You can try the free DEMO download available on this page to test your specific machine before purchase.
Important!
If you bring the node into any version that isn't Nuke 16.0v6, Nuke will automatically recompile the node. This means you will have a loading screen of about 30 seconds to 1 minute—it doesn't mean the software has crashed. The included tutorial video shows how to avoid this loading screen in the future.
Is this true 3D?
Yes, this volumetric noise renderer is a full rendering engine. The noise is generated procedurally, which allows for very quick iteration / playback speed.
Do I need a GPU? What PC requirements?
The logic in this kernel is reliant on GPU heavy calculations. With a GPU, iteration is nearly instantaneous on medium/large volumes, so a good GPU is recommended. This was produced on a machine with an RTX 3090.
How large can the volumes get?
Because this tool does not rely on pre-calculated Voxels, you can have very complex volumes that are relatively large (roughly 4 to 6 times the size of a house) and still have near-instant playback with a decent GPU (3090+). However, you still need to optimize the number of samples if you have a huge volume.
How many lights are supported?
Currently one directional light is supported which keeps the tool lightweight and fast.
Is Motion Blur / Defocus supported?
Yes, you can render motion vectors from this toolset and use Vectorblur. This calculates the motion of the camera as well as the velocity of the noise.
Defocus is not supported inside the node due to performance overhead, but volumes in the foreground can be manually defocused effectively in a VFX context.
Does this use VDBs?
No. This generates 3D procedural noise; it does not load pre-created VDB files. This tool serves better as a general-purpose 3D Volumetric Noise generator.
Do Occlusions support Deep Compositing?
Currently Occlusions support P Data or Z-Depth data. While it can't replace deep volumetric renders for every shot, it is useful on a large variety of shots and can significantly reduce turnaround speed.
Are updates included?
Small compatibility fixes are included. An entirely new Version 2 in the future would likely include an upgrade fee to support further development.
Are GUI/render licenses separate?
All licenses are GUI-based. For rendering on nodes, you have unlimited usage. This node template is not hard-coded with licensing keys.
Is it a subscription or 1-time payment?
All Licenses are a one-time payment only; they are not subscriptions.
