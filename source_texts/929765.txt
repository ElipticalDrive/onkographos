What
The translator's shared memory byte store (SharedStore8, also the 16-bit SharedStore16) was a compare-and-swap loop on the word, from upstream Ryujinx. GenerateSharedStore now clears the field with an atomic AND and sets it with an atomic OR. Lanes writing other bytes of the same word commute with both, so the word ends as the loop left it, without retries. A chain change: translator rebuilt, dmsh_chain.lock and dmsh_chain.h updated (chain 26a894c0f40a), the StageMemory test checks the new form. DM_NVN_SKIP_MESH=1 drops every task / mesh draw (as DM_NVN_SKIP_FS drops draws by fragment shader): how the cost was isolated.
Why
A task or mesh shader writes its primitive indices and count as bytes (0x927 modes 0x80 and 0x88). The 32 lanes of a workgroup write neighbouring bytes, so four lanes contend for each word and the loop ran about four times a store, with a divergent retry each time. Ocarina of Time's foliage mesh shaders have ten such stores a lane, over tens of thousands of workgroups a frame.
Semantics: two lanes writing the same byte at once now get a mix of their values where the loop gave one of the two; the hardware's order between them is undefined as well. No shader seen writes the same byte from two lanes.
Measured
The Legend of Zelda: Ocarina of Time, Kokiri Forest, M3 Pro (18 GB), DM_NVN_GPUPROF=every:600. The pass after the opaque pass holds the foliage mesh draws; a render pass's start stamp is written after its vertex stage, where Metal runs the object and mesh stages, so the mesh work shows as the gap before that pass or as its duration.
