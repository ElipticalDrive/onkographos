What changed
World::sort_by::<T>(key): reorders every archetype holding T by a u64 key (Archetype::permute / Column::permute; entity locations updated). Parallel key sort above 50k rows.
spatial_key(pos, cell): Morton (Z-order) key of a position's grid cell.
The built-in rebuild_spatial_grid system sorts entities by spatial_key every SPATIAL_SORT_EVERY = 32 ticks, so neighbors in space are neighbors in memory.
Boids example sorts its own entities the same way.
Verification
cargo build --workspace --examples, cargo test --workspace, cargo clippy --workspace --all-targets: all clean.
New tests: crates/crabby_ecs/tests/entities.rs (sort order, entity handles still resolve, components travel with entities), tests/spatial.rs (spatial_key_orders_nearby_cells_together, built_in_grid_sorts_entities_by_cell).
Miri (Stacked Borrows, --tests --no-default-features): all pass.
