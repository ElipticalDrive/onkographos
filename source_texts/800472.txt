What
Gap loop round 2 (analytic-sdf-ui): analytic 2D SDF coverage for UI/text in a new abrash_core::sdf_ui module — the CPU equivalent of the shader idiom smoothstep(fwidth(d), -fwidth(d), d), so UI shapes and glyph-like outlines get MSAA-quality edges with no multisample buffer and no supersampling.
smoothstep(edge0, edge1, x) — GLSL-style Hermite ramp; reversed edges (which GLSL leaves undefined and the SDF idiom depends on) are defined, equal edges degenerate to a step.
fwidth_from_samples(d, d_x, d_y) — |d_x − d| + |d_y − d|, the Manhattan form GPUs use for fwidth.
sdf_coverage(d, fwidth) — distance → coverage in [0, 1]: exactly 0.5 on the edge, saturating half a derivative-width either side, hard-step fallback for degenerate widths.
stroke_coverage(d, fwidth, half_width) — anti-aliased strokes centred on the d == 0 contour (panel borders, focus rings, outlines).
sample_coverage / sample_coverage_scaled — three-tap sampling (centre + one pixel in x/y); the scaled form takes the world-space size of one pixel, so edge softness stays exactly one screen pixel at any UI scale — resolution independence for text.
fill_sdf_shape / stroke_sdf_shape — render any closure over the existing abrash_core::sdf 2D primitives into a Framebuffer, clipped to an optional IRect, compositing with Color::blend_over at alpha × coverage. Coverage-0 pixels are left byte-identical (no lossy sRGB round-trip).
New example sdf_ui_demo (cargo run -p abrash-core --example sdf_ui_demo): panel + border stroke, ring avatar, pill button → PPM (39,847 non-background pixels at 320×180, verified).
Tests
19 new unit tests + 8 doctests covering the spec invariants: coverage range/monotonicity, 0.5-on-edge, saturation distances, reversed/degenerate smoothstep, stroke symmetry, scaled sampling at two pixel scales, clip behaviour, blending over an existing background, a composed panel+pill scene, and a deterministic (d, fwidth)-plane sweep.
cargo test -p abrash-core: 1553 lib passed, 0 failed (+1 integration, 484 doctests passed)
cargo clippy -p abrash-core --all-targets: zero new warnings (lib stays at its 11 pre-existing)
