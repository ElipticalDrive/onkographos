Adds loading of XGRIDS LCC2 (.lcc2) level of detail Gaussian splat scenes, streamed like lod-meta.json scenes. Data Organization Format originated from XGRIDS.
Changes:
A gsplat asset can now load an .lcc2 file. Each node of an LCC2 tree holds one LOD level of its region and is replaced by its children for more detail, so the tree loads directly as a hierarchical streamed octree (perf: Choose streamed gsplat LOD by walking a node hierarchy #9883), and its .sog splat files stream on demand. The scene's environment file loads as the environment; meshes and collision data are not loaded.
The LCC2 parser is registered with the gsplat resource handler for the .lcc2 extension.
API Changes:
New supported format, no new API:
```
const asset = new Asset('scene', 'gsplat', { url: 'https://example.com/scene/scene.lcc2' });
```
Examples:
New gaussian-splatting/streamed-lcc2: streams the Tunis scene by Andrii Shramko, with renderer, LOD preset, splat budget, debug render and stats controls.
Renamed gaussian-splatting/lod-streaming to streamed-sog, and lod-streaming-sh to streamed-sog-sh. The old paths redirect to the new ones.
gaussian-splatting/viewer: opens a scene from a URL (an on-screen field, or #/gaussian-splatting/viewer?url=...), including streamed lod-meta.json and .lcc2 scenes; adds a splat budget slider for streamed scenes; the camera can fly as well as orbit.
