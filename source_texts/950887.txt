User-facing 3D output — reuse established Gaussian .splat donor
This is a focused functional follow-on to the WRE V2L18.3 main-integration PR #322 (base SHA 655aba9ae1eea886132f3287b40eb50708bbcdae, not default main). No second 3D solver, CUDA kernel, framework, workflow or training machinery is added. The existing PR #322 already exposes a glTF RGB centers-only export; this PR additionally exports the actual Gaussian 3D scene attributes (XYZ, exp(log-scale), color, opacity, quaternion) into the established antimatter15/splat 32-byte-per-Gaussian .splat format, usable by existing Gaussian viewers.
Reuse rather than reinvent: Copy the targeted tested CPU exporter export_verified_gsplat_splat and its tests from prior experiment PR #265, immutable source fb73a59107814a3477ed05a487a33d2378c548ff, into this canonical stacked integration branch. The previous experimental #265 is not independently integrated or merged; any eventual merge must avoid duplicate export definitions. Three allowlisted paths only: src/wre/reconstruction/static_appearance_baseline.py, src/wre/reconstruction/__init__.py, tests/test_static_appearance_baseline.py.
The function first calls existing materialize_verified_gsplat_ply on a real on-disk PLY (59 float32 fields), reads its verified bytes in bounded batches, applies the established SH0 RGB conversion, float32 scale exponentiation, sigmoid opacity and normalized quaternion, outputs 32-byte little-endian records in stream, verifies source SHA-256 against audited materialization, hashes destination and refuses overwrite/partial files. Does not modify original PLY. The two reused tests decode generated bytes independently, validate RGB/scales/quaternion/opacity/hash/no-overwrite and reject corrupted PLY/zero quaternion/extreme scales without partial output.
Evidence boundaries: CPU-only tests use synthetic but byte-real two-record PLY. They do not train gsplat, render a frame, prove photorealism, use CUDA, or show a product viewer. Full native co-import test is in separate PR #341; real 16-photo COLMAP→Gaussian-initialization/WebGL experiment is in #340, without GPU training, and its gallery PR #342. None of those other workstreams should be modified or claimed passed by this PR. GitHub Dependency Graph HTTP404/#226 remains a separate official vulnerability review blocker. Parent PR #322 is still DRAFT; do NOT merge out of order.
Acceptance: exact-HEAD GitHub fast-ci pytest/Ruff/Pyright and applicable builds, verified destination bytes and hashes, one independent read-only L2 for this functional lot once stabilized (not per formatting SHA), and honest CPU/GPU separation.

def export_verified_gsplat_viewer_bundle(
*,
artifact_ref: ArtifactRef,
output_root: Path,
profile: GsplatStaticAppearanceTrainingProfile,
bundle_path: Path,
) -> Sha256Digest:
"""Package one audited Gaussian scene as reusable .splat and RGB-center .glb.
Both formats are generated by the existing CPU exporters from the same
verified original PLY. The archive contains byte-for-byte derived files
and a manifest with source/output SHA-256s. Neither viewer file is a
trained radiance renderer: the GLB shows centers and .splat stores SH0.
"""
if not isinstance(bundle_path, Path) or not bundle_path.is_absolute():
raise TypeError("gsplat viewer bundle destination must be an absolute Path")
parent = _safe_root(bundle_path.parent, "gsplat viewer bundle parent")
destination = parent / bundle_path.name
if destination.suffix != ".zip" or destination.exists() or destination.is_symlink():
raise GsplatStaticAppearancePreflightError(
"gsplat viewer bundle requires a new .zip destination"
)
verified = materialize_verified_gsplat_ply(
artifact_ref=artifact_ref, output_root=output_root, profile=profile
)
created = False
try:
with tempfile.TemporaryDirectory(prefix="wre-gsplat-view-", dir=parent) as folder:
work = Path(folder)
splat = work / "scene.splat"
centers = work / "centers.glb"
splat_hash = export_verified_gsplat_splat(
artifact_ref=artifact_ref,
output_root=output_root,
profile=profile,
splat_path=splat,
)
glb_hash = export_verified_gsplat_rgb_centers_glb(
artifact_ref=artifact_ref,
output_root=output_root,
profile=profile,
preview_path=centers,
)
manifest = {
"format": "wre-gsplat-viewer-bundle-v1",
"source_ply": {
"relative_path": profile.expected_ply_relative_path,
"sha256": str(verified.entries[0].sha256),
},
"outputs": {
"scene.splat": {"sha256": str(splat_hash), "size_bytes": splat.stat().st_size},
"centers.glb": {"sha256": str(glb_hash), "size_bytes": centers.stat().st_size},
},
"notes": [
"scene.splat: SH0 color only; not full view-dependent radiance",
"centers.glb: glTF POINTS; not anisotropic Gaussian rendering",
"No GPU training or reconstruction quality is attested by this bundle",
],
}
encoded = (
json.dumps(manifest, sort_keys=True, separators=(",", ":"), allow_nan=False)
+ "\n"
).encode("utf-8")
with destination.open("xb") as output:
created = True
with zipfile.ZipFile(output, mode="w", allowZip64=True) as archive:
for name, path in (("scene.splat", splat), ("centers.glb", centers)):
entry = zipfile.ZipInfo(name, date_time=(1980, 1, 1, 0, 0, 0))
entry.compress_type = zipfile.ZIP_STORED
with path.open("rb") as source, archive.open(entry, "w") as target:
shutil.copyfileobj(source, target, length=1024 * 1024)
entry = zipfile.ZipInfo("manifest.json", date_time=(1980, 1, 1, 0, 0, 0))
archive.writestr(entry, encoded)
digest = hashlib.sha256()
with destination.open("rb") as zipped:
while chunk := zipped.read(1024 * 1024):
digest.update(chunk)
return Sha256Digest(digest.hexdigest())
except Exception:
if created:
destination.unlink(missing_ok=True)
raise
