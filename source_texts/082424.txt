Use Case
Dark colors render as transparent in Vol-E, which is unwanted behavior when coloring segmentations by a color map. Users would like to see shapes even when a darker color is applied, particularly for segmentations.
The transfer function editor should still control opacity, however.
Solution
There is a function in the raymarch shader called luma2Alpha that currently converts color luminance to alpha. One solution would be to add a flag for segmentation rendering (or when colorizing) that disables luma2Alpha.
This might be problematic because of the fuse step that we perform... Does the fuse step need to write alpha values to the volume texture?
