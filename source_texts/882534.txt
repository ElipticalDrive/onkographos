Implement 7 embedding fixes for Object 3 bifurcation tree
Summary
This PR implements 7 fixes to improve Object 3 bifurcation tree embedding and prevent issues with carving detection, mesh repair, and voxelization:
Fix 1: Mask-based carving check - Replaced unreliable volume-based comparison with voxel count comparison from embedding metadata. Void meshes often have zero/incorrect volume due to uncapped tubes or self-intersections.
Fix 2: Fill voxel grids before marching cubes - Added voxels.fill() in voxel_union_meshes() to get solid volumes instead of surface shells, which produce fragile non-manifold results.
Fix 3: keep_largest_component parameter - Added parameter to repair_mesh_for_embedding() and embed_void_in_cylinder(). Object 3 now uses keep_largest_component=False to preserve all 4 disconnected inlet trees that would otherwise be dropped by meshfix_repair.
Fix 6: Debug artifacts - Added printing of domain/void/solid voxel counts and saves {object}_embedding_debug.json with metadata for debugging carving failures.
Fixes 4, 5, and 7 were already implemented in PR #120 (axis swap removal, validation thresholds, 25µm pitch).
Review & Testing Checklist for Human
Verify embed_tree_as_negative_space returns voxel_counts in metadata - The mask-based check (lines 838-843) relies on result['metadata']['voxel_counts'] containing 'domain', 'void', 'solid' keys. If these are missing, all values default to 0 and carving will incorrectly fail.
Test Object 3 generation end-to-end - Verify all 4 inlet trees are preserved in the final mesh (not dropped by repair)
Test that .fill() change doesn't break Objects 2, 4, 5 - The voxel_union_meshes change affects all objects using voxel union
Verify debug JSON is written correctly - Check that intermediate/object3_embedding_debug.json contains expected voxel counts

Fix 1: Replace volume-based carving check with mask-based test
- Volume comparison is unreliable for void meshes (uncapped tubes, self-intersections)
- Now uses voxel counts from embedding metadata: void_mask.sum() > 0 AND
  solid_mask.sum() < domain_mask.sum() - epsilon

Fix 2: Make voxel_union_meshes use .fill() before marching cubes
- Without .fill(), voxelized() returns surface occupancy shell
- This produces fragile non-manifold results and nonsense volumes
- Now calls voxels.fill() to get solid volumes

Fix 3: Prevent repair from dropping trees (keep_largest_component parameter)
- Added keep_largest_component parameter to repair_mesh_for_embedding()
- Object 3 now uses keep_largest_component=False to preserve all 4 inlet trees
- Other objects default to True for backward compatibility
