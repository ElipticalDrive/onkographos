# OpenGL Cloud Renderer

Real-time volumetric cloud rendering in OpenGL, inspired by Guerrilla Games' 
[Nubis](https://www.guerrilla-games.com/read/nubis-cubed) cloud system from Horizon Zero Dawn.

## Rendering

Clouds are rendered using raymarching with single scattering toward the sun. 
Several optimizations keep the technique interactive:

- **Adaptive step size**:  steps grow larger at distance and in empty regions; 
  when the ray enters a cloud, it backsteps and continues with finer steps
- **Early termination**: marching stops once transmittance drops below a threshold, 
  skipping regions that would contribute negligibly to the final color

## Noise

Cloud density is defined procedurally using 3D Worley and Perlin noise textures, 
generated on the CPU and uploaded to the GPU as 3D textures.

## Controls

| Key | Action |
|-----|--------|
| `W` `A` `S` `D` | Move camera |
| Mouse | Look around |
| `X` | Release mouse |
| `Y` | Lock mouse |
| `J` `K` `L` `I` `U` `O` | Scroll 3D noise texture |

## How to run (Windows only)
* Download executable and assimp dll (releases)
* Switch into volumetrics branch
* Copy executable and assimp dll into `OpenGL Experiments` folder
* run `OpenGL-Experiments.exe`
