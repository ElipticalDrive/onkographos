This branch is a month's work on the painterly stylized pipeline, and is its proof of concept. I have done a lot of experimenting in this branch and have made the following main features: McLaren Voxel Cone Tracer and Surface Stable Voronoi Flooding Paint.
Changes:
Voxels are now anisotropic, meaning they contain directional information for each voxel face (total 6)
Created a voronoi noise variant with line sdf, instead of euclidian distance
Implemented RuneVision's Surface-Stable technique, which uses uv-frequency to determine pattern size.
Seperated Prepasses from VCT Pipeline
Voxel Rasterization without geometry shader, using 3 orthographic perspectives
Custom mip volume generation
New cone tracing buffer containing GI, AO and SH, combined with BRDF.
Refactored cone tracing algorithm.
Spec Cube Pass that stores directional skybox data in realtime on a cubemap
Lighting bounces in volumes for more detailed voxel data.
2 Voronoi Hash buffers in VCT
2 Voronoi flooding pass chains in VCT
Proper temporal anti-aliasing for VCT denoising
Refactored Depth-Normal based blur
Custom motion vectors pass
Branch has one issue where the Resource ID gets out of range after a while, will be fixed later.
