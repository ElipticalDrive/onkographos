Gaussian orbitals are used as basis functions for approximating the wave function in quantum chemistry, where visual representations of molecular systems aid in understanding complex electronic structures. Since the wave function is represented as a linear combination of Gaussian orbitals, evaluating the probability density across a three-dimensional domain is computationally demanding, making interactive visualization challenging. Four direct volume rendering variants were implemented to visualize probability density functions using synthetically generated Gaussian orbitals. Gaussian orbitals were evaluated on-the-fly using compute shaders and fragment shaders without the need for an intermediate storage step. The on-the-fly renders were compared against rendering the probability density using a precomputed scalar field calculated on the CPU and GPU with compute shaders. Both methods were evaluated against a reference image at different grid resolutions and step sizes to see convergence behaviors. An orbital count performance study was performed to analyze the benefits of each approach. The results show that transfer function design is the dominant factor in convergence behavior. When the scalar field needs to be represented using a fine grid resolution it was found that ray marching a 3D texture hits a caching bottleneck making on-the-fly rendering favorable up to a certain number of orbitals. Ultimately, neither approach is universally superior, as the optimal choice depends on the transfer function design, the molecule being evaluated, and hardware constraints.
