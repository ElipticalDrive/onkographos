Phase 5S T3a (docs/phase5s/T3a-octree-key-routing.md): S4 of docs/design/scale-out.md §7.1. Octree::new no longer sorts any key across the ranks; the octree is the Phase 5 octree key for key on every run.
Change (nd-octree only)
First sort removed. route_keys sorts each rank's input keys once, refines provisional blocks by weight alone (O1's round without the distinct-key rule, one all-reduce per round), cuts them with partition_blocks, and sends the keys deduplicated as (key, multiplicity) pairs in one all-to-all-v; the receiver k-way merges the runs. compute_coarse_tree counts d(b) and w(b) from the routed keys and their multiplicities, so the blocks, weights and cut are Phase 5's.
Second sort and second key move removed. balance routes each rank's locally linearized 2:1 closure by the partition bounds and linearizes on arrival. Deviation from the brief: keys are placed by their first finest descendant, not their own Morton key — a closure key coarser than a rank's first block sorts before that rank's bound and would otherwise reach a rank holding none of its descendants.
New debug checks: routed keys distinct across ranks (communicate_back), every balanced leaf owned by its rank. Octree::new's collective list and octree/CLAUDE.md's construction contract updated. No public API change; rlst's parallel_sort is no longer used by nd-octree.
Tests
Unit tests: routing rounds on hand-made counts, merge of (key, multiplicity) runs, rank_counts vs sort_to_bins, block counts from pairs, the routed balance against morton::balance (65 lib tests pass).
octree/examples/phase5_reference/ — a private copy of the Phase 5 construction (removed when T3 lands). Both MPI examples assert leaves, own/global blocks, bounds, all_keys with KeyType, and block weights equal on every rank. Two deliberate mutants were caught.
test_mpi_construction_edge_cases gains every key on one rank, every key identical, a root-only tree with many keys; its existing key generator overflowed level 16 above rank 227 (found at 512 ranks in debug) and now stays in range on any rank count.
