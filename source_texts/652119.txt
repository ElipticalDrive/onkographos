Extends griddata to support 3D interpolation using tetrahedral barycentric coordinates, and adds a new griddata_triangles API for extracting simplex indices in both 2D and 3D.
3D interpolation: New linear_interp3d using Cramer's rule to solve for barycentric coordinates in tetrahedra
Dimension-agnostic API: griddata() gains a dims parameter (2 or 3) with interleaved point layout
griddata_triangles(): New function returning flat simplex index arrays (triangles for 2D, tetrahedra for 3D)
Refactored Qhull init: Extracted init_qhull() helper with heap-allocated qhT and proper cleanup
Refactored 2D interpolation: Renamed linear_interp2d_facet → linear_interp2d, cleaned up control flow
Typed error codes: Added QHULL_GENERAL_ERROR, INT_ALLOCATION_ERROR, TRIANGLE_INDICES_ERROR
5 new tests: 3D constant/linear field interpolation, 3D simplex extraction, minimum-points error, 2D simplex list
