# Marching Cubes 3D Visualization

A web application for 3D surface reconstruction using the your choice of Voxels, Marching Cubes, Marching Cubes 33 algorithms, with support for MRI data visualization and performance benchmarking.

Data Source: UNC Paired 3T-7T dataset
- https://www.nature.com/articles/s41597-023-02400-y
## Requirements

- Python 3.x

## Installation

1. Clone the repository
2. Install Python dependencies:

```bash
pip install -r requirements.txt
```

## Usage

1. Start the Flask server:

```bash
python main.py
```

2. Open your browser and navigate to:
   - `http://localhost:5000/` - Main demo page
   - `http://localhost:5000/mri` - MRI data viewer
   - `http://localhost:5000/tests` - Performance benchmarks
   - `http://localhost:5000/tests-mc33` - MC33 correctness tests
