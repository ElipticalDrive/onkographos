Volume Rendering Using Arnold
A Free Tutorial Series from Saber Jlassi
In this free tutorial series, Saber Jlassi will show you how to render fire, smoke, and clouds in Houdini using Arnold.
Arnold is one of the most important render engines for Houdini artists. It has been used on countless projects to craft realistic VFX work and we use it all the time to create incredible FX work.
We thought it’d be fun to release a video tutorial series covering how to approach volume rendering using this tool. Below you will find the series in its entirety.
Note that Arnold 5 and 6 utilizes a new version of the shader that is briefly explained in video 5 and is much easier to use. The content of this tutorial is 100% valid and is 100% applicable to the latest Arnold and Houdini version.
It’s best to use the latest shader that ships with Arnold 6 by using the IPR and tweaking the value you should see so you have a clear indication of what the result looks like.
The cloud chapter contains an updated hip file that is made using the latest Houdini and Arnold version.
