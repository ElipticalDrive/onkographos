@copilot in a sample .splat sh_degree is always 0 is this correct?
Yes, this is correct. The .splat format only stores 32 bytes per splat (position, scale, RGBA color, and rotation) and does not include spherical harmonics data. Therefore, sh_degree is always 0 for .splat files.
Only .ply and .spz formats support spherical harmonics coefficients. For SH rendering, you'll need to use PLY files with f_dc_* and f_rest_* properties, or SPZ files with embedded SH data.
