Summary
Add a validated, zero-copy reader for NanoVDB Float trees.
Validate Root/Upper/Lower/Leaf node ranges and child offsets at construction time.
Use unchecked fixed-layout reads in the sampling hot path while retaining the existing ReadAccessor.
Add regression coverage comparing the direct sampler with the existing accessor.
Validation
cargo fmt --manifest-path nanovdb-rs/Cargo.toml
cargo test --manifest-path nanovdb-rs/Cargo.toml --lib
6 tests passed.
pbrt-r4 experiment produced an identical EXR hash and improved bunny-cloud tiny runtime from about 1.48s to 1.07–1.09s.
Notes
The validated view is tied to the exact byte slice used during validation; mismatches return None so callers can retain a fallback path.
