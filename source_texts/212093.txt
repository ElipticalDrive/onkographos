# SmoothVoxels
My attempt to implement smooth voxels using Surface Nets (isosurface extraction) algorithm from signed distance field (SGF) data.  

VoxelUtils.cs contains the logic for converting an sdf into mesh:   

-VertexGridWrapper class takes a 3D float array (of sdf data) as parameter from which it compute a SurfaceNetData object (vertex and normal) information for each individual voxel.  
-VertexGridWrapper index acces is overloaded so we can get vertex and normal of each voxel[x][y][z] by calling (instance)VertexGridWrapper[x][y][z] (return a SurfaceNetData object)

-Mesher class contains helper methods for creating mesh from a 3D array of SurfaceNetData.
