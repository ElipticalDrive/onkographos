Contributor
Builds a complete voxel game playable in modern browsers via npm install && npm run dev.
Stack
Rendering: Three.js r160 + WebGL, programmatic 256×256 canvas texture atlas (no copyrighted assets)
Terrain: simplex-noise 4.x with seeded RNG for reproducible worlds
Storage: localforage (IndexedDB) for multi-world persistence
Build: Vite 5, ES modules throughout
World & Rendering
Chunk system (16×16×256), per-face mesher with solid/transparent/plant geometry separation
Simplex-noise terrain with 3 biomes (plains, forest, desert), caves, ore veins, trees
27 block types; day/night sky cycle with dynamic lighting and distance fog
Frustum + face culling; Uint8Array block storage per chunk
Player & Physics
Pointer-lock first-person camera; WASD + sprint/sneak/jump/swim/fly
AABB collision resolved axis-by-axis (X → Y → Z); raycasting for block targeting
Block breaking (hardness-based timing) and placement from hotbar selection
UI & Crafting
Drag-and-drop 36-slot inventory + 9-slot hotbar; scroll/number-key selection
Pattern-matching crafting system with 15+ recipes (2×2 and 3×3 grids)
Title screen, loading progress bar, pause menu with settings sliders, F3 debug overlay
Mobile: virtual joystick + touch look controls
Bug fixes (from review)
Physics.js: ceiling collision was a no-op ternary (dy < 0 ? 0 : 0); now correctly snaps position to floor on downward impact, ceiling on upward
TerrainGenerator.js: all Math.random() calls replaced with this._rng() (seeded) — ore veins, decoration, and tree height are now fully reproducible from the same seed
Inventory.js: removed incorrect "reference not copy" comment on slice()
Original prompt
Build a Browser-Based Minecraft Clone (WebCraft)
Overview
Create a complete, browser-based Minecraft-like voxel game called WebCraft from scratch. The game should be fully playable in modern web browsers with smooth 3D rendering, core Minecraft mechanics, and responsive UI.
Technology Stack
Rendering: Three.js with WebGL2
Build Tool: Vite for fast dev server and optimized production builds
Language: JavaScript (ES modules)
Physics: Custom lightweight AABB collision detection
Storage: IndexedDB via localForage for world persistence
Noise Generation: simplex-noise library for terrain generation
UI: HTML/CSS overlay on WebGL canvas

Core Features to Implement
1. World Generation
Chunk System: 16×16×256 block chunks, only render chunks within render distance (8-12 chunks)
Terrain Generation: Use simplex noise for height maps with multiple octaves
Biomes: At least 3 biomes (plains, forest, desert) with different terrain features
Structures: Trees (oak, birch), flowers, and tall grass placement
Caves: Simple cave generation using 3D noise
Water: Water blocks at a fixed sea level
2. Block System
Implement at least these block types:
Stone, Dirt, Grass Block, Sand, Gravel
Oak Log, Oak Leaves, Birch Log, Birch Leaves
Oak Planks, Cobblestone, Bricks
Water, Glass, Coal Ore, Iron Ore, Gold Ore, Diamond Ore
Crafting Table, Furnace (visual only for furnace)
Bedrock (unbreakable bottom layer)
Torch (with light emission visual)
Tall Grass, Flowers (red, yellow)
Each block should have:
Unique texture (top, side, bottom can differ — e.g., grass block)
Hardness value (affects break time)
Transparency flag
Whether it's solid (for collision)
3. Rendering Engine
Greedy Meshing: Merge adjacent same-type faces into larger quads to dramatically reduce polygon count
Face Culling: Don't generate faces between two adjacent solid blocks
Texture Atlas: Single texture atlas image with all block textures; compute UV coordinates programmatically
Frustum Culling: Only render chunks visible to the camera
Fog: Distance-based fog matching sky color for smooth chunk loading boundaries
Day/Night Cycle: Gradual sky color transition, directional light rotation
Ambient Occlusion: Simple vertex-based AO for block edges/corners
4. Player & Physics
First-Person Camera: Pointer lock API for mouse look
Movement: WASD movement, space to jump, shift to sneak/slow walk, double-tap W to sprint
Gravity & Jumping: Realistic gravity with jump height of ~1.25 blocks
Collision Detection: AABB collision against world blocks, prevent walking through walls
Swimming: Slower movement in water, ability to float up
Block Interaction:
Left click: Break block (with mining animation/progress)
Right click: Place block from selected hotbar slot
Middle click: Pick block type from world
