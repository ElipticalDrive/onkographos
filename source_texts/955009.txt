Hi, thank you very much for sharing EnvGS — it is a really impressive work.
I am interested in using your 2D diff-surfel-tracing module in my own 3D reconstruction project.
From my understanding of the paper, EnvGS first uses 2DGS diff-gaussian-rasterization to reconstruct the base Gaussians,
and then applies 2D diff-surfel-tracing to further optimize the representation and add learnable nn.parameters
(e.g., specular / roughness) to model view-dependent effects.
If my understanding is correct, I would like to ask:
Is it possible to directly use the 2D diff-surfel-tracing alone (without the base 2DGS rasterization stage) to reconstruct 3D scene from multi-view images?
Thank you very much!

Hi @qingpowuwu ,
Yes, it is possible to directly use the 2D diff-surfel-tracing alone.
https://github.com/xbillowy/diff-surfel-tracing?tab=readme-ov-file#core-snippets shows an example of how to use the tracer directly, and the demo video is actually trained with diff-surfel-tracing alone (without rasterization).
