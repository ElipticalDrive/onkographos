SpatialMind AI is a high-performance WebGL platform designed to render, inspect, and converse with massive 3D Gaussian Splatting environments. It combines real-time spatial Level-of-Detail (LOD) tiling with in-memory multi-spectral transformations and a conversational 3D Spatial RAG search pipeline.

---

## ✨ Key Features

| Feature | Description |
|---------|-------------|
| **60 FPS WebGL Engine** | Renders 4.8M+ 3D Gaussian Splats at locked 60 FPS using an adaptive O(N log N) frustum plane tiling strategy |
| **Multi-Spectral Vision** | Server-side binary byte mutation engine alters raw 32-byte splat parameters in RAM for Satellite, LiDAR, Thermal IR, and X-Ray views — zero disk overhead |
| **Conversational 3D RAG** | Combines Qdrant Vector Search, Neo4j Scene Graphs, and LLMs (Llama 3 / GPT-4o) for natural language → 3D camera flights + GPU shader highlights |
| **Render Quality Controls** | Resolution scaling (720p → 4K) with real-time contrast, saturation, and sharpness post-processing |
| **First-Person Navigation** | WASD keyboard controls for immersive 3D environment exploration |
