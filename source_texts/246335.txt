Audio Communication Group, Technische Universiät Berlin, Germany
These supplementary materials are intended to illustrate the effect of Masked Magnitude Least Squares
(MMagLS) rendering. They contain example auralization of a source moving along the median plane. As
illustrated, the source starts below the listener and then moves upward until it arrives at the starting position
again. We provide an MMagLS rendering, that can be compared to the a MagLS and reference rendering.
In all cases we used KU 100 HRTFs [2]. The MMagLS and MagLS renderings were created using first order
Ambisonics, and the reference was created using 44th order Ambisonics.
Use headphones for listening.
