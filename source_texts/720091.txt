M3-V Prompt 12 — Context-halo chunked voxel decoder inference
Prompt 11 完了後に実行してください。F3全volumeを一括GPU/RAM展開せず、各voxelを一度だけ書くchunked inferenceを実装します。
新規実装
```
src/seis_ssl_cluster/f3/lithology/voxel_decoder_inference.py
src/seis_ssl_cluster/config/f3_lithology_voxel_inference.py
proc/seis_ssl_cluster/predict_f3_lithology_voxels.py
tests/seis_ssl_cluster/test_f3_lithology_voxel_decoder_inference.py
tests/seis_ssl_cluster/test_config_f3_lithology_voxel_inference.py
```
inference tiling
Prompt 09と同じcore tile + context halo geometryを使用します。
core tilesはtoken gridをnon-overlap partition。
model inputはcore+halo。
decoder outputからcore voxel領域だけを切り出し、output memmapへ書く。
各original-volume voxelは最大一度書く。
token paddingに対応するvolume外voxelは保存しない。
source valid-token gridをnearest voxel maskへ展開し、invalid voxelはsentinel。
Overlap averaging用の巨大 [X,Y,Z,C] float32 accumulatorは作らないでください。context halo + core cropでseam contextを確保します。
input identity
```
decoder best.pt
resolved decoder config/source hashes
embedding volume + metadata + valid tokens
class info
```
checkpointがbindしたembedding/valid/supervision/tile identityと一致しない場合はfailしてください。別encoder embeddingへのdecoder流用をsilentに許可しないでください。
outputs
Prompt 05 schema:
```
f3_voxel_predictions.npy       int16
f3_voxel_confidence.npy        float16
f3_valid_voxel_mask.npy        bool
f3_voxel_probabilities.npy     optional float16
prediction_metadata.json
```
metadata:
```
prediction_kind: frozen_embedding_decoder
decoder checkpoint path/hash
source model/embedding identity
tile/core/halo geometry
patch size
write_probabilities
coverage summary
```
coverage safety
実行中に軽量なcore coverage accountingを行い、以下を保証してください。
```
original voxelで duplicate writeなし
valid voxelで missing writeなし
invalid voxelはsentinel
all outputs finite where valid
```
full-size coverage gridを常設artifactとして保存する必要はありません。debug/test用temporary memmapまたはtile geometryによるassertでよいです。
CLI
```
python proc/seis_ssl_cluster/predict_f3_lithology_voxels.py \
  --config <yaml> --dry-run
```
Support:
```
--device
--write-probabilities override optional
--overwrite explicit
```
--skip-existing を追加する場合は、complete artifact validationに成功したrunだけskipしてください。
テスト
small modelでwhole-grid forwardとtiled core outputが一致。
non-divisible token grid / volume crop。
edge halo padding。
exact-once coverage。
invalid token sentinel。
optional probabilitiesとconfidence整合。
checkpoint/source identity mismatch。
output collision/partial artifact。
dry-run no-write。
CPU inference smoke。
