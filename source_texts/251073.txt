Our implementation of sort-free Gaussian Splatting still uses the tile-based rendering approach from 3DGS. This means we need to assign the Gaussians (GS) to different tiles. Think of the ‘sort’ part here as replacing grouping with sorting instead.
You can see this explained in the README of our GitHub repo https://github.com/LiYukeee/sort-free-diff-gaussian-rasterization:
The code still includes a Radix Sort, but we have removed the GS depth component from the keys required by the Radix Sort. This means that sorting is now based solely on the tile ID to which the GS belongs. This approach is a form of lazy approach, using sorting as a substitute for classification. While this change may impact performance, it will not affect rendering quality.
