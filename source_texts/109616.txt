# Voxel Hashing Visualization Suite

A set of tools to visualize synchronized depth, albedo, normal, and surface-rendered images produced by the voxel hashing pipeline.

## Features

- Synchronized 2x2 display of image types (depth, albedo, normal, surface)
- Video-style playback with play/pause, previous/next, first/last
- Frame slider and playback speed control (0.1x to 5.0x)
- Fullscreen toggle for detailed inspection
- High-quality image scaling (LANCZOS4)
- Command-line viewer with interactive mode and export

## Directory Structure

The tools expect the following structure under the chosen output directory:

```
output/
├── depth/
├── albedo/
├── normal/
└── surface/
```

Each subdirectory should contain PNG files named with zero-padded 5-digit indices, e.g. `00000.png`, `00001.png`, etc.

## Installation

```bash
cd /home/hmy/voxel_hashing/Simple_visualization
pip3 install -r requirements.txt --user
```

## Quick Start

```bash
python3 quick_start.py
```

## GUI Visualizer

```bash
python3 visual.py
```

Controls:
- Select Output Directory: Choose the `output` folder containing the subdirectories
- Play/Pause: Start/stop playback
- ◀◀/◀/▶/▶▶: First/Previous/Next/Last frame
- Speed: Adjust playback speed (0.1x–5.0x)
- Fullscreen: Toggle fullscreen mode (Esc to exit)
- Keyboard: Left/Right, Home/End, Space, Esc

## Command-line Viewer

```bash
# Interactive mode
python3 simple_viewer.py --interactive

# Show a specific frame
python3 simple_viewer.py --frame 10

# Save a frame as an image
python3 simple_viewer.py --frame 5 --save frame_005.png
```

## Requirements

- Python 3.6+
- OpenCV (opencv-python)
- NumPy
- Matplotlib
- Pillow (PIL)
- Tkinter (usually included with Python)

## Troubleshooting

- No images found: verify the directory structure and file names
- GUI issues: try the command-line viewer (`simple_viewer.py`)
- Keyboard shortcuts not working: click on the window to focus
