Summary
Indirect firefly clamp. Each camera sample's indirect light is capped at a max-channel limit, scaling the colour whole (crust:indirectClamp / --indirect-clamp). On by default at 10, as in production renderers; 0 is the unbiased estimator and bit-identical to the previous renderer. Direct light is never clamped — including a primary bounce that escapes to a dome or sun — so both MIS halves stay paired. Pinned by indirect_clamp_never_touches_direct_light.
visibility = "invisible" is honoured. The subtree is pruned (geometry and lights, read at the evaluated time, and inside prototypes). The top-level walk still descends it for cameras only, so --camera keeps working on hidden rigs. ALab parks four lights this way, and all four used to light the shot.
UsdPreviewSurface opacity as translucency. Under the default opacityThreshold = 0, opacity < 1 maps to transmission_weight = 1 − opacity refracting at ior (how ALab authors all its glass). A textured ior below 1 keeps the constant (production ior maps are 0 in UV gutters), and make_ray reads a textured opacity at the hit so guided refraction crosses the interface correctly. opacityThreshold > 0 (cutout) stays unimplemented and renders opaque.
Notes
The default render is now biased: on the checked-in samples at 16 spp the clamp moves 0–0.17% of pixels (outliers only). Use --indirect-clamp 0 for convergence/bias measurements and golden A/Bs.
Test plan
CI: cargo fmt --check, cargo clippy -D warnings, cargo test --workspace
scripts/check_images.sh check with --indirect-clamp 0 shows no change
