# AmSDE
Alternating Multi-scale Stochastic Differential Equations (AmSDE) for Accelerated Inverse Problem Solving.
This repository contains three experimental modules:
- **CT**: Limited-data CT reconstruction
- **MRI**: Under-sampled MRI reconstruction
- **NI**: Natural image generation and inpainting
## Overview
AmSDE is a score-based generative model that leverages stochastic differential equations for solving inverse problems.
## Quick Start
Each experiment has its own directory with detailed documentation:
| Module | Directory | Description |
|--------|-----------|-------------|
| **CT** | `CT/` | CT reconstruction with limited-angle data |
| **MRI** | `MRI/` | MRI reconstruction with under-sampled k-space |
| **NI** | `NI/` | Natural image generation and inpainting |
## Getting Started
### CT Experiment
```bash
cd CT/
# See CT/README.md for detailed instructions
python PCsampling_demo.py
```
### MRI Experiment
```bash
cd MRI/
# See MRI/README.md for detailed instructions
python main.py --config=configs/ve/ve.py --mode=sample --workdir=results
```
### Natural Image Experiment
```bash
cd NI/
# See NI/README.md for detailed instructions
python natural_image_generation.py --task unconditional --output_dir results/unconditional_test
```
## Requirements
All experiments require:
- Python 3.8+
- PyTorch 1.12+
- CUDA 11.3+ (for GPU acceleration)
Refer to each module's `requirements.txt` or `environment.yml` for specific dependencies.
