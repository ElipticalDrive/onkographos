Hi,
Is it possible to extend slicer code to slice SDF based geometry instead of mesh based? What changes would be needed to make this work? E.g., with upcoming 3MF volumetric/implicit based designs for lattice structures, we will need to find a way to directly slice such volumetric data instead of generating mesh (which can result in giga-bytes of data).
If you can provide a conceptual outline of how this can be done, we can extend this excellent project even further.
Regards
SK

it's possible but probably not practical. as I understand it, SDF is good for organic shapes but not geometries with flat surfaces and hard edges. an SDF will realistically need to be converted to a mesh for rendering / interactions. 3JS will not handle it natively. the SDF format may be more space efficient for a large class of organic objects but will trade that for much more complex computations either in slicing or mesh conversion or both.
