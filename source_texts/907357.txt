Summary
Adds voxel-based mesh operations that compose with B-rep shapes, on top of the voxel seams. This directly attacks two of brepjs's stated weaknesses — robust CSG and offset/shell — by routing through a representation (a dense SDF) where those operations are unconditionally well-defined: min/max of two fields can't fail, and an iso-level shift can't self-intersect.
API
Layer 2 (src/voxel) — mesh ops, all Result<KernelMeshResult>:
```
offsetMesh(mesh, distance, opts?)              // exact SDF iso-shift (+grow / -shrink)
shellMesh(mesh, thickness, opts?)              // hollow inward wall
voxelBoolean(a, b, 'union'|'intersection'|'difference', opts?)   // robust CSG
```
Shape conveniences (mesh a B-rep shape, then the op):
```
offsetShape(shape, d) · shellShape(shape, t) · voxelBooleanShapes(a, b, op)
latticeInfillShape(shape, { type:'gyroid', period, thickness })   // the "lattice this part" one-liner (Layer 3)
```
Implementation
Rust (packages/brepjs-voxel-wasm) — three wasm entries reusing voxelize_mesh + ops + surface_nets_mesh:
offset_mesh — new_sdf = sdf - distance (the voxelizer is a true SDF, so this is exact); the bbox is expanded by distance.max(0) so an outward offset doesn't clip at the grid edge
shell_mesh — max(solid, -(solid + thickness))
voxel_boolean — voxelize both meshes onto a shared union-bbox grid, then min/max/max(a,-b)
ops.rs — offset_sdf + shell_sdf helpers
TS — shapeToMeshInput meshes a Shape via the topology mesh() API (ShapeMesh.vertices/.triangles map field-for-field to VoxelMeshInput); every op mirrors repairFns (validate-in-TS, defense-in-depth wasm guards, try/catch the fallible call, using the handle).
Verification
31 cargo + 97 vitest — offset (both directions, exact bbox), shell, all 3 booleans, the B-rep conveniences against a real OCCT box, and Result-contract guards (non-finite distance, non-positive thickness, out-of-bounds indices)
typecheck, lint, boundaries, knip green; size 287.15 kB < 290 kB; 52 KB wasm
Build process
Built via a multi-agent workflow; the review returned no P1/P2 findings (two P3 comment nits and a test-symmetry gap addressed here).
Deferred
Performance scaling (hierarchical FWN — the brute-force voxelizer is O(voxels×triangles)), persistent grid handles, meshToBrep reconstruction.

Introduces voxel-based mesh operations — offsetMesh, shellMesh, voxelBoolean — and corresponding B-rep shape convenience wrappers by routing through a dense SDF where CSG and offset are unconditionally well-defined, addressing brepjs's two stated weaknesses.
Rust layer (lib.rs, ops.rs): three new #[wasm_bindgen] entry points reuse the existing voxelize_mesh + surface_nets_mesh pipeline; offset_sdf shifts the iso-level in place, shell_sdf applies max(s, -(s+t)), and voxel_boolean voxelizes both meshes onto a shared union-bbox grid before combining SDFs — all with matching Cargo tests.
TypeScript layer (meshOpsFns.ts, shapeMesh.ts): follows the repairFns pattern throughout (TS-side validation → resolveEngine → using handle → try/catch); meshFromResult now guards against empty geometry output, addressing the previous reviewer comment; shapeToMeshInput wraps topology tessellation in a Result and is exported for callers who need custom deflection.
