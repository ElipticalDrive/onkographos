Virtual Process could simulate the actual process using 3D-geometric's dynamic growth generated by computer, however the key is how to generate compellent and natural 3D-geometric.In this paper we put forward a Virtual Process based on Visualization of 3D Spatial Data Sets Method.This method is similar to 3D-reconstruction of medicinal data, which is a process from 2D-slice to 3D- geometric.First, generating 2D-slice bitmap by doing Mathematical Morphology to original layout based on Virtual Process datas,then using these 2D-slice bitmap to initialize the 3D Data Sets. At last constructing 3D-geometric using Marching Cubes Method. This paper explain how to do Mathematical Morphology to original layout based on the Process datas and how to generate 3D-geometric from3D Data Sets.
