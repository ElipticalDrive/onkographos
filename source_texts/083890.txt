Feature Implementation
This PR implements three creative new features that greatly enhance the visualization and functional capabilities of the voxelizer tool.
Procedural Infill (--infill, --infill-scale): During solid voxelization, the user can now specify "gyroid" or "grid" patterns to hollow out the mesh using procedural mathematical evaluations. This allows generating lightweight internal structures suitable for 3D printing simulations.
Cube Voxel Geometry Export (--export-cubes): Standard .obj export only outputs single vertices. If users want to render the voxelization as physical blocks in software like Blender, they can now pass --export-cubes, which outputs actual 8-vertex 12-face cube geometry for each generated particle.
SDF Heatmap Point Cloud (--color-sdf): Debugging signed distance fields is tricky. With this flag, the .ply exporter will attach RGB properties to vertices, utilizing a red/blue color gradient that mathematically corresponds to the voxel's specific sdf float value.

Reject unknown infill patterns
When --infill is set to anything other than the two implemented strings, such as a typo like --infill gyriod, voxelize still succeeds and silently emits the original solid fill because the pattern falls through both branches. Since the CLI exposes this as a user-selected pattern, invalid values should fail fast, e.g. with a clap value parser or an explicit error, rather than producing a misleading result.
