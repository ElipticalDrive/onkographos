Motivation
Block edits were marking regions dirty immediately while CPU/GPU meshing/upload had not completed, causing region rebuilds from incomplete chunk meshes and a one-frame visual blink.
Description
Remove eager MarkRegionDirty(...) calls from RequestNeighborRemesh in src/voxel/BlockEdit.cpp so edits only enqueue remesh (RequestRemesh) and the existing upload path drives region dirtying once new mesh data is ready.
Testing
Attempted an automated build with cmake -S . -B build && cmake --build build -j4, which failed in this environment due to FetchContent failing to clone https://github.com/glfw/glfw.git (network/403), so no local compile/run verification could be completed here.
