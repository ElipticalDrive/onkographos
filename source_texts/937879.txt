Motivation
Provide a structurally sound, playable single-player voxel sandbox (Minecraft-like) implemented in TypeScript + React + Three.js with clear module boundaries and maintainable code.
Use chunked, deterministic procedural terrain so the world can be streamed around the player and edited persistently.
Deliver an initial, production-minded feature set (meshing, movement/collision, mining/placing, hotbar, and persistence) that can be iterated toward performance and gameplay parity.
Description
Added a chunked world model and deterministic terrain generator with modification tracking and streaming via src/world/* (includes VoxelWorld, Chunk, TerrainGenerator, block definitions, and coordinate utilities).
Implemented a CPU-friendly mesher with face culling and per-face shading in src/rendering/mesher.ts, and integrated it into the Three.js scene management in src/game/Game.ts with dirty-chunk remeshing.
Implemented first-person gameplay systems: input handling, pointer-lock camera, gravity/jump, axis-wise collision resolver, and voxel raycast-based mining/placement in src/player/* and src/game/*, plus a simple hotbar and UI overlay in src/ui/* and src/App.tsx.
Added persistence layer using localStorage to save/load player state and serialized block modifications (src/persistence/save.ts), and included deterministic unit tests for coords, terrain, and persistence under tests/*.test.ts and a README documenting architecture, controls, playtest checklist, performance notes, and known limitations.
Testing
Unit tests were added for coordinate mapping (tests/coords.test.ts), terrain determinism (tests/terrain.test.ts), and persistence serialization (tests/persistence.test.ts), but they were not executed in this environment.
Attempted dependency install with npm install failed in this environment due to registry access policy (403 Forbidden), so automated test execution (npm test) and dev server run (npm run dev) were not possible here.
To run locally, install dependencies and run npm test to run the unit tests and npm run dev to launch the playable prototype (see README for controls and verification checklist).
