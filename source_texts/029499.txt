Detailed PR Summary: Ray Tracing (#10)
Branch: ray-tracing → main | 71 commits | 59 files changed | +3,599 / -465 lines
Overview
This PR adds a GPU-accelerated progressive path tracer to the custom physics engine using OpenGL compute shaders, alongside a full BVH acceleration structure, a new lighting system, and supporting UI and physics integration.
New Files
File
Purpose
src/assets/shaders/raytrace/raytrace.comp
650-line GLSL compute shader (OpenGL 4.3 core) implementing BVH-traversal path tracing with PCG-based Monte Carlo sampling, Lambertian diffuse, emissive surfaces, a configurable sun light, sky gradient, checkerboard floor, and a progressive accumulation buffer for multi-frame refinement
src/graphics/raytrace/SceneRayTracer.cpp/.h
961-line host-side orchestrator: gathers geometry from the scene, uploads triangle & BVH data as SSBOs, dispatches the compute shader, blits the accumulated image to the framebuffer, and handles adaptive resolution scaling
src/graphics/raytrace/TriangleBvh.cpp/.h
CPU-side BVH builder using surface-area heuristic (SAH) binning; packs triangles and nodes into flat GPU-ready arrays; supports fast in-place refit() for moving objects
src/ui/settings/GraphicsTab.cpp/.h
New "Graphics" settings tab in the settings dialog
src/ui/settings/GraphicsSettings.cpp/.h
Settings state backing the Graphics tab (ray trace on/off, global light, exposure)
src/ui/inspector/ThermalInspectorWidget.cpp
Inspector panel for thermal/emission properties

Ray Tracer Technical Details
GPU Shader (raytrace.comp)
8×8 workgroup compute shader writing to a rgba16f accumulation image
Iterative BVH traversal with a 64-entry stack (no recursion)
Both triangle meshes and analytic spheres supported
PCG random number generator for per-pixel, per-frame noise variation
Lambertian diffuse BRDF with cosine-weighted hemisphere sampling
Emissive surfaces (physics bodies with temperature/emission > 0 glow)
Directional sun light with configurable on/off
Sky gradient (horizon ↔ zenith ↔ ground)
Checkerboard ground plane
Progressive accumulation: each frame blends with all previous frames → image converges over time
BVH (TriangleBvh)
SAH binning builder (8 bins per axis)
refit() fast-path for animated/moving geometry that preserves tree topology
Supports rebuild detection: structure hash vs. geometry hash to decide full rebuild vs. refit vs. nothing
Host (SceneRayTracer)
Adaptive internal resolution scaling (0.25× – 1×) for performance control
SSBO management for triangles, BVH nodes, lights, and spheres
Accumulation reset on camera move, object add/remove, or shader change
Output blitted from internal resolution to full framebuffer via glBlitFramebuffer
Exposure control applied in the present pass
UI Changes
Settings → Graphics tab: toggle ray tracing on/off, toggle global sun light, adjust exposure
Inspector: thermal/emission properties exposed per object
