[[abstract]]A new color image compression technique based on moment-preserving and block truncation coding is proposed. An input image is divided into nonoverlapping blocks and each block pixel is assigned one of two representative colors, which are computed with analytic formulas derived from preserving certain moments in the block. A bit map is then generated for each block to represent the pixels' colors. Different uniformity conditions in the representative colors are also identified and utilized to save code bits. Good average compression ratios up to about 13 can be achieved, as shown by experimental results
