PyVista: How to produce Volume Render from semi-structured spheroid?
(I am a noob at volume rendering and this should be an easy question)
Hi, I'm a college student who had a computational astrophysics research opportunity last winter. Our task was to write a python script to render 3d plots of a black hole accretion disk, specifically its volume density.
Although I'm no longer getting paid to do this, I never solved one problem, whose solution feels like it should be tantalizingly easy: I was only able to load in the data as a point cloud with a colormap to represent the volume density of that point. But what we ultimately wanted to make was a volume render, like the one shown here.
The data are spheroidal, so each density value corresponds to a point in the center of a six-sided spherical wedge. I have access to the list of centers and the list of all points.
Here is what I'm currently doing, after I manually convert from spherical to cartesian coords:
```
# coords: the stack of the x, y, and z arrays corresponding to each wedge-center
# lrho: the density scalar we want to load in
mesh = pv.PolyData(coords)
mesh['lrho'] = data

plotter = pv.Plotter()
plotter.add_mesh_threshold(mesh, scalars = 'lrho', point_size = 1)
plotter.show()
```
And this works just fine, but it doesn't render smooth, continuous volume the way we'd like. The plot looks like this right now.
Any help would be greatly appreciated!
