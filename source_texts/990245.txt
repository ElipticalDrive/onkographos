Work in sandbox only, mpaykin1/meta6 read-only.
Game: games/veil-terraces/index.html. Actual frustum terrain+prop culling, WebGL2 instancing, cached VAO state + instance matrices, chunk streaming, adaptive DPR and new packed normal/color geometry 36→20 B/vertex. Reusable shared modules: visibility.js and packed-mesh.js. voxel.js not yet integrated.
Current head ea28eee, exact-head Chromium WebGL2 benchmark PASS: https://github.com/mpaykin1/meta6-lab/actions/runs/42356142235
With 25 fully loaded chunks in this run (software-rendered Chromium, not physical phone): mobile FPS 45.65→44.07, draw calls 53→12, p95 33.4→33.4ms; desktop FPS 22.91→26.13, draw calls 53→14, p95 50.1→50.1ms. GPU vertices 20B vs 36B each. Mobile FPS did not improve in this sample; transient noise possible; do not claim guaranteed FPS gain.
Previous known-good uncompressed head b9049b6 benchmark PASS: https://github.com/mpaykin1/meta6-lab/actions/runs/42355324189 (mobile 52.41→55.56, desktop 29.14→33.00).
