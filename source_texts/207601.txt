Problem
The watertight ray–triangle test treats edges as inclusive, so a ray never slips between triangles. The other side of that is that a ray through a shared edge hits both triangles, and a ray through a vertex shared by a fan hits every triangle in the fan. A 6-triangle fan gives 6 hits at the same t. This is specified and documented on raycast_all.
Phase 5 inside/outside tests and thickness rely on watertight raycasts. Parity counting and signed winding counts are both wrong with duplicate hits, so they need a rule for merging hits at one crossing point.
Options
Dedup at the caller: merge hits at equal t (and point), then count each crossing once, with its sign from the face normals.
Half-open tie rule in ray_triangle: e.g. a top-left rule in the sheared 2D space, so that exactly one triangle owns each edge and vertex. This changes raycast_all's output, so it is a behaviour change.
Generalized winding numbers (Phase 5's winding mode), which do not use ray parity at all.
Done when
Phase 5's design picks one approach and tests it on rays through vertices and edges of closed meshes.
