release notes
```
Highlights from this release:  

Removed support for delayed loading (out-of-core loading) from the core
library to improve performance and reduce code complexity. As a result,
OpenVDB no longer depends on Boost.
Introduced the openvdb::codecs framework for stream encoding and decoding,
along with read-time grid type conversion (for example, reading a FloatGrid
as a HalfGrid).
NanoVDB GPU tools can now allocate through injectable memory resources,
and the dual-space buffers and related transfer methods are deprecated
ahead of their removal in 14.0.

See the release notes for more details.
```
View the full release notes at https://github.com/AcademySoftwareFoundation/openvdb/releases/tag/v13.2.0.
