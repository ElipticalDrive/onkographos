Goal
Generate smooth terrain meshes using Marching Cubes over voxel densities.
Steps
Create MarchingCubesMesher.cs in Scripts/World/Meshing/.
Add static edge and triangle tables for MC.
Implement BuildMesh(ChunkData chunk, WorldSettings settings) -> MeshData:
Iterate cells of size 1 in voxel index space (x=0..size-2 etc).
Read 8 corner densities.
Compute case index.
Skip if 0 or 255.
Interpolate vertices along edges using density values.
For now, compute normals via simple cross products per triangle.
How to test
Swap VoxelWorld mesher from BlockMesher to MarchingCubesMesher.
Generate a subset of chunks.
Confirm the terrain looks smooth and organic.
