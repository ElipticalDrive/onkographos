fix(render): Make ray spawning robust at planetary scales
…
6edfd1b
```
Replace the fixed 256-ULP origin offset, which exceeded feature sizes at
large camera-relative ranges (~8.2 km at 3.8e8 m, past a 6 km cloud gap):

- Continue alpha pass-through and transmittance rays on the same ray via
  Ray::tnear + advance_ray_t (exact, no coordinate offset)
- Offset bounce/shadow spawns along the geometric normal by a propagated
  position-error bound (Interaction::p_err, 16 ULP of frame magnitude)
- Solve ellipsoid intersection in double with the stable closest-approach
  discriminant (was up to ~57 km of hit-t error at the limb in float32)
- Make medium sampling segment-relative for continuation rays
- Enable RTC_SCENE_FLAG_ROBUST on TLAS and BLAS builds
- Refactored multiple functions to ensure Clang can successfully apply
Named Return Value Optimization (NRVO) and Guaranteed Copy Elision (URVO).

fix: Clamp Lambert phase function to avoid negative irradiance
…
c4f7804
```
Near a phase angle of pi, catastrophic cancellation in the Lambert
phase function could produce slightly negative values in float
precision, causing resolve_irradiance to throw on valid scenes.
Clamp the phase function to zero and clamp dot(V, L) into [-1, 1]
before acos to guard against NaN.

Pull request overview
This PR advances Huira to v0.9.6 with a set of rendering robustness and variance-reduction changes, primarily targeting unresolved rendering correctness at extreme camera-relative scales (e.g., Earth/cloud artifacts at lunar range) and adding explicit sampling support for “indirect sources” (reflectors like Earthshine).
Changes:
Improves intersection robustness and self-intersection handling by introducing same-ray continuation (Ray::tnear() + advance_ray_t()), adding Embree robust traversal flags, and tightening spawn-point offseting via a propagated position-error bound.
Adds indirect-source (reflector) designation, collection, bounding proxies, and explicit sampling/MIS integration in the path tracer; expands unresolved sphere lighting to handle multiple lights + indirect sources with shadowing.
Adds look_at callbacks for instances and updates CI/packaging to support macOS x86_64 plus various build/link fixes.
