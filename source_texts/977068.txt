Summary
Per-robot temporal occupancy filtering
add per-cell temporal free/occupied evidence to remove dynamic-object trails without semantic detection
count each cell at most once per mapping frame, regardless of ray density
clear established occupied cells after 4 free frames by default
require 3 occupied frames before committing a new obstacle in previously free space
decay contradictory evidence and reset stale evidence
use an 8-byte stable evidence record and reset frame scratch only for cells touched by that scan
Local-window odometry correction
refine each incoming frame with scan-to-submap planar ICP against the latest 10 corrected scans
raw odometry provides the relative-motion prediction
voxel downsampling, spatial-hash nearest neighbours, a small correlative search, and trimmed correspondences
correspondence-count, overlap, RMSE, RMSE-improvement, and correction-size gates
do not apply the initial-RMSE gate when the odometry seed has insufficient overlap; this lets the bounded coarse search safely recover
automatically fall back to the odometry prediction and reset the window on tracking/timestamp/jump failures
publish the pose actually used by the mapper on toy/corrected_odometry without publishing another TF tree
Two-live merged-map cleanup fix
run_two_mid360_2d_mapping.sh --mapping-host displays /toy_record/merged_global_occupancy by default. The previous merger rebuilt that map from the two persistent robot global maps and resolved every conflict as occupied. As a result, a stale occupied cell from either robot could never be cleared in the displayed merged map even when current free-space observations existed.
keep the existing record_republisher.py executable name and replace its installed implementation with a temporal wrapper
use each persistent per-robot global map at most once as startup bootstrap data
update the merged map from new /r0/toy/local_occupancy and /r1/toy/local_occupancy observation frames
deduplicate timer republishes using the original sensor timestamp
transform robot 1 observations through the current inter-robot alignment
maintain free/occupied evidence directly in the common map frame
clear merged occupied cells after 4 free observation frames and confirm new obstacles after 3 occupied frames
give free observations a 5 cm Manhattan footprint to tolerate grid quantization and small pose jitter
give occupied priority only inside the same current observation frame, rather than forever because of a stale global map
reset and re-seed merged evidence after a significant inter-robot alignment change
add runtime counters for observed, free, occupied, cleared, and newly committed cells
Validation
GCC and Clang C++17 syntax compile of the mapper with lightweight ROS message/API stubs
temporal per-robot state-transition tests, including compact-state size verification
synthetic asymmetric-geometry ICP pose recovery
moving-object outlier robustness test
invalid-initial-overlap/coarse-search recovery regression test
stationary raw-odometry drift simulation using a 10-frame local window
8 standalone temporal merged-grid tests covering free clearing, occupied confirmation, same-frame conflict priority, dynamic grid growth, and free-observation inflation
Python syntax compilation and common-grid quantization smoke tests
YAML parsing/default assertions and Git blob hash verification
A full ROS 2 colcon build/test was not run in this environment because the ROS 2 toolchain is not installed. The new tests are registered in CMake for execution in the repository's normal ROS 2 workspace.
Deployment note
run_two_mid360_2d_mapping.sh sources the workspace's install/ tree. Pulling or switching the source branch is not enough: rebuild co_3dto2d_mapping on both robot laptops before retesting. The mapping-host startup log must contain Temporal merged occupancy enabled=true source=local_observation; otherwise an older installed executable is still running.
