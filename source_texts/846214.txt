Abstract
During large-scale simulations, intermediate data products such as image databases have become popular
due to their low relative storage cost and fast in-situ analysis. Serving as a form of data reduction, these
image databases have become more acceptable to perform data analysis on. We present an image-space
detection and classification system for extracting vortices at multiple scales through wavelet-based filtering.
A custom image-space descriptor is used to encode a large variety of vortex-types and a machine learning
system is trained for fast classification of vortex regions. By combining a radial-based histogram descriptor,
a bag of visual words feature descriptor, and a support vector machine, our results show that we are able to
detect and classify vortex features at various sizes at multiple scales. Once trained, our framework enables
the fast extraction of vortices on new, unknown image datasets for flow analysis.
Keywords: Turbulence, Vortex detection, Image processing, Machine learning

Vortices are typically described by their mathematical behavior, but also contain well defined visual

55

56

57

58

59

61

64

65

66

67

68
extraction. For example, features that would be unclassified by traditional methods could be learned and
69
correctly identified using machine learning techniques.

2.3. Bag of Visual Words
101
A Bag of Visual Words (BOVW) is constructed by using vector quantization of descriptors extracted
102
from image patches. It is used for image classification [21, 22, 23, 24]. A BOVW method defines image
103
features as words (or visual words) and counts the occurrences of each feature in an image. A BOVW
104
descriptor of an image is thus a histogram.
105
The visual words in a histogram form the dictionary (or codebook) of the BOVW model. The visual
106
words must be chosen so that they relate to features that are common among images to make it possible to
107
classify an image/object. The occurrences of the words in one image should make it possible to distinguish
108
that image from another. One expects the distribution of the words to differ significantly. To compute a
109
dictionary one usually performs feature detection and description steps for a set of images, resulting in a set
110
of feature descriptors. These are used to produce a smaller set of descriptors representative for groups of
111
descriptors, those becoming the words. Clustering can be used to compute visual words which, for instance,
112
can be defined as centroids of clusters via a K-means algorithm.
113
The BOVW descriptor of an image can be computed as the histogram, capturing the frequencies of
114
each word in the image. Given an image, in order to compute the histogram one can perform the feature
115
detection and description steps; subsequently, for each feature descriptor obtained, one accumulates the bin
116
related to the closest word by an appropriate distance metric.
117
2.4. Support Vector Machines
118
A support vector machine (SVM) computes a hyperplane that best separates a set of n-dimensional
119
feature descriptors, using labels of two classes [25, 26]. The hyperplane is a decision boundary: a new
120
sample can be classified as belonging to one of the two classes according to the side of the hyperplane it is
121
on.
122
Among all possible hyperplanes, an SVM computes the one that maximizes the margin to the samples in
123
the classes, i.e., it maximizes the distance to the nearest samples in each class, the support vectors. Often
124
a data set is not linearly separable in d-dimensional space. For this reason, an SVM maps d-dimensional
125
features to a higher-dimensional space where it is more likely to have a separation hyperplane. This map
5
126
is performed by a kernel function, e.g., a linear, polynomial or radial basis function. For details concerning
127
the optimization process, we refer to [27, 28, 29].

138
One of the most critical components in our pipeline is to select image-space features that will be relevant
139
to domain-specific applications. In this work, we’ve focused on the extraction of vortex-like features by using
140
a 2-D representation of them. Through the use of the Okubo-Weiss criterion, regions in velocity magnitude
141

142

143

144

145
features perceived by human vision to aid in differentiation. Machine learning algorithms typically require
146
a single-channel input, causing a conversion between a chromatic colormap to a grayscale image to pass-
147

148
commonly known as a grayscale colorset.

Once training is finished, new unknown test images are considered to classify features. Given an image
192
patch input, the SVM produces a positive or negative response that relates to the distance to the fitted
193
hyperplane used to differentiate between various words. The kernel function used for the fitted hyperplane
194
is not the default linear separable function, but rather a third-degree polynomial function, which allows non-
195
linear classifications. The signed orthogonal distance from the oriented hyperplane is the output response
196
value and is normalized between -1 and 1. These distances represent the separation between the visual
197
words ”vortex” and ”non-vortex”.
198
When investigating a new image, the brute-force, non-efficient method is to consider every single pixel of
199
the new image at the dataset’s native resolution. This becomes computationally expensive when considering
200
potentially thousands of individual images, adding up to many billions of pixels. To significantly improve
201
compute performance, first we must select regions from these new images that we want to consider. The
202
selection is performed by a low-cost ellipse region extraction pipeline, as shown in Figure 6. The extracted
203
region is related to the bounding rectangle that includes the ellipse. It is worth to note that fitting a
204
squared region to an elongated feature could include data from extraneous dynamics unrelated to the vortex.
205
Therefore, the bounding rectangle is better to avoid such interference.
206
To extract the ellipse regions, we first compute the gradients of an image in the x and y directions.
207
An efficient way of computing this at multiple resolutions is through the use of discrete wavelet transforms
10
208
(DWT) and using their horizontal and vertical detail coefficients. The Haar DWT high-pass filter that we
209
used approximates a differential for obtaining the gradients. By using coefficients at different scales of the
210
wavelet decomposition it is possible to control the identification from finer to coarser features.
211
From the gradients of the wavelet transform in a given scale, we perform an edge detection [32]. The
212
curvature at each point p of the edges is then computed as κ(p) = 1/R(a), such that R(a) is the radius
213
of the osculating circle at p. We then threshold the edge points p using this κ(p) value to remove straight
214
edges and maintain curved edges that may be formed by vortices.
215
Contours given by the connected components of the resulting edges are then extracted and used to fit
216
ellipses [33] which represent regions where vortexes may potentially exist. Once these ellipses are computed,
217
we extract an affine bounding-box region around the ellipse which is considered for classification.
218
A further filtering step may be applied to avoid extremely elongated ellipses which still may occur due
219
to noisy curvature values. The thresholding of ellipses is computed using the eccentricity (ratio of the minor
220
and major axis lengths). The smaller the ratio the more elongated is the ellipse. Due to the wavelet structure
221
used to generate the gradients in the previous step, contours can be generated at multiple resolutions using
222
wavelet’s native hierarchy, allowing the extraction to be performed at multiple scales.
223
The relatively low computation cost of these routines reduces the computational cost further rather than
224
attempting to perform a classification query for the entire resolution of the image, at every pixel.

4. Experiments and Results
226
In the following we present experiments and results achieved by our method. The experiments were
227
performed using turbulence data from the Johns Hopkins Turbulence Database [13], which consists of the
228
velocity components at 1015 time instances in a volume of 1024 × 1024 × 1024 voxels. The time instances
229
are separated by a constant time step of 0.04 and cover the initial state, growth, and long time decay of
230
turbulence. For training, we used 2D slices from 11 time instances (one slice per time instance), starting
231
from time t=6 and up to time t=12, spanning frames numbers 150 to 300. Since the peak of turbulence
232
kinetic energy occurs at t ≈ 11.4, the training set covers the strong growth regime, as well as the beginning
233
of turbulence decay. The 2D slices contain the direction of gravity and a homogeneous (horizontal) direction,
234
and correspond to a 1/4 of the domain depth in the third (horizontal) direction.
235
Magnitude images were computed from the velocity components and patches were manually selected to
236
build a dataset for training and testing the SVM classifier. The SVM implementation of OpenCV [34][35]
237
was used with a polynomial kernel of degree 3, gamma value of 1 and coefficient 0. The termination criterion
238
was set to 100 iterations. The dataset contains 447 features: 229 of these features were labeled to the vortex
239
class and 218 features were labeled to the non-vortex class. The vortex patches were chosen so that the
240
vortex center is fully contained inside the patch and nearly located at the center of the patch. Patches of

293
of full data, provided that a complementary dataset can be used for training. Thus, through training and

5. Conclusions
346
As current and future supercomputers produce insurmountable amounts of data year-over-year, it has
347
become necessary to use approaches for data reduction to alleviate bandwidth limitations and facilitate the
348
study of new simulations. The generation of Cinema image databases has been a recent popular approach
349
capable of generating high temporal fidelity snapshots of simulations that otherwise would be skipped by
350
conventional restart state writes. Performing data analysis on these massive restart files is prohibitive due
351
to required resources, making the analysis of high-fidelity image database data a prominent approach.
352
We presented a method for classification of features in flow dataset that uses a 2D approach to discrim-
353
inate between vortex and non-vortex features. In the method we propose the use of radial gradients to
354
produce a Bag of Words descriptor for the features, which are classified using a Support Vector Machine.
