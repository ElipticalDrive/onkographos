# Noise

A GPU-accelerated noise generation toolkit for Unity. Author procedural noise as ScriptableObject assets, bake to 2D, 3D, and cubemap textures directly in the editor.

## Why I Built This

I kept running into the same problem: I needed noise textures for procedural content — terrain, clouds, surface detail, VFX — and the workflow was always "open Substance Designer, tweak some nodes, export, reimport into Unity, check if it looks right, go back to Substance." For noise that was feeding directly into gameplay or shaders, that round-trip didn't make sense.

I also needed cubemap noise for a disco-ball-like effect where light patterns needed to tile across all six faces seamlessly. I couldn't find any existing tool that generated seamless cubemap noise, so I built one.

The other motivation was referenceability. When noise is authored as a ScriptableObject, other systems can reference the noise configuration directly instead of a raw texture that could get accidentally swapped or deleted. A `NoiseLayer` SO is a named, configurable asset that you can drag into any baker or reference from code.

## What It Does

You create **NoiseLayer** assets that define a single noise channel — type, frequency, octaves, FBM mode, domain warping, remapping. Then you create a **Baker** asset (2D, 3D, or Cubemap) and assign up to four NoiseLayer references to the R, G, B, and A channels. Hit Bake in the inspector and it dispatches compute shaders to generate the texture on the GPU, storing the result as a sub-asset you can use immediately.

Everything is seeded and deterministic. Same settings, same output.
