Thanks, these are useful features: overlay fine-tuning, portable calibration export/import (nice validation, and good that network URLs are not exported) and image adjustments.
Before merging, a few things need to change:
i18n: none of the new UI strings go through t(), e.g. "Adjust camera overlay", "Export calibration…", "Brightness", the hardware labels, and all status and error messages. The UI is German by default, with English in src/locales/en.json. Please write the strings in German with t('…') and append the English translations to en.json (see docs/i18n.md).
Live preview frame rate: the camera panel and the calibration dialog now redraw the preview through getImageData every 250 ms instead of showing the video directly. That drops the live view to about 4 fps, even when every adjustment is neutral. Please keep the direct video/canvas when adjustments are identity, and consider a CSS filter or a per-animation-frame draw otherwise.
CameraStream now draws every network frame into netView even when it isn't attached. That's fine if it's needed, but please only do it when an adjusted preview actually consumes it.
Please add the features to docs/features.md and docs/features.de.md, and wire the new test scripts into package.json, or drop the ones that aren't needed.
Please drop the "AI-generated by …" comments from the source files. The disclosure in the PR description is enough.
