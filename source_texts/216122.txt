Examples of existing libraries for
1. Marching Cubes:
https://scikit-image.org/docs/stable/auto_examples/edges/plot_marching_cubes.html
C Version https://github.com/dvega68/MC33_c_library MC33 library version 5.2 This library is a new version of the MC33 library of the paper: Vega, D., Abache, J., Coll, D., A Fast and Memory-Saving Marching Cubes 33 implementation with the correct interior test. https://facyt-quimicomp.neocities.org/MC33_libraries.html
https://github.com/dvega68/MC33_cpp_library MC33++ library version 5.2 This library is a C++ version based on the MC33 library of the paper: Vega, D., Abache, J., Coll, D., A Fast and Memory-Saving Marching Cubes 33 implementation with the correct interior test. https://facyt-quimicomp.neocities.org/MC33_libraries.html
https://github.com/pmneila/PyMCubes PyMCubes is an implementation of the marching cubes algorithm to extract iso-surfaces from volumetric data.
https://github.com/JustusThies/PyMarchingCubes PyMarchingCubesявляется ответвлением от PyMCubes, с другой реализацией фактической маршевой функции
https://github.com/BorisTheBrave/mc-dc library covers how to implement 2d / 3d Marching Cubes and Dual Contouring.
https://github.com/Magnus2/MeshReconstruction This is a small library that can reconstruct a triangle mesh from a signed distance function using the Marching Cubes algorithm and export it to a file in the obj format.
https://github.com/swiftcoder/isosurface Isosurface extraction algorithms implemented in Rust.
https://github.com/smistad/GPU-Marching-Cubes A GPU implementation of the Marching Cubes algorithm for extracting surfaces from volumes using OpenCL and OpenGL. But this software has been moved into the FAST framework where it is further developed and maintained.
https://github.com/seung-lab/zmesh Vacancy: A Voxel Carving implementation in C++.
https://github.com/aparis69/MarchingCubeCpp C++ implementation
2. Dual Marching cubes:
https://github.com/planaria/dmc (https://www.cs.rice.edu/~jwarren/papers/dmc.pdf)
https://github.com/andygeers/DualMarchingCuboids Because the author is a bear of little brain, the solution needs to be easily understood and implemented without lots of complicated maths (or third party maths libraries which are almost as complicated as the maths itself)
3. Marching Tetrahedra:
https://github.com/Calvin-L/MarchingTetrahedrons
https://github.com/andresbejarano/MarchingTetrahedra Require VTK library
https://github.com/dborah123/marching-tetrahedra This project was built in flux.
4. Combine
https://github.com/JuliaGeometry/Meshing.jl This package provides a comprehensive suite of meshing (isosurface extraction) algorithms for use on distance fields and other structured datasets. Algorithms included: Marching Tetrahedra, Marching Cubes, Naive Surface Nets. Written on Julia.
https://github.com/voxelbased/core Voxel-based is a collection of voxel algorithm implementations for the Unity Engine. Algorithms included: Boxel, Marching Cubes, Marching Tetrahedra, Naive Surface Nets, Dual Contouring of Hermite Data, Cubical Marching Squares. Written on С#.
