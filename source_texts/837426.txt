User-facing 3D functionality: inspect actual 2D ↔ 3D SfM correspondences
Extends parent PR #382's interactive real 16-photo PyCOLMAP SfM landmark inspector. This is an independent stacked functional increment; parent remains unchanged for its already scheduled L2. Base immutable SHA 7e65fe3374d537be956e86b16302208eb3791de3. No merges and no added solver, framework, paid API or model download.
In the existing CPU SfM export, read actual measured pycolmap.Point2D.xy feature pixels for each registered image and triangulated point ID from the real 16-photo model (Pierre Moulon/OpenMVG Palm Desert Micro, CC BY-NC 4.0 — strictly NONCOMMERCIAL). Append the measured (u_A,v_A,u_B,v_B) to up to eight genuine shared 3D landmarks for each of 120 camera pairs, retaining exact 3D XYZ, track support and native point reprojection error. No synthetic coordinates, projection, simulated new view or original source photographs bundled.
Reuse existing offline model-viewer WebGL UI: clicking an actual triangulated 3D landmark now reports its measured source-image pixel coordinates in both selected SfM cameras, along with its 3D position, number of observations and the native in-sample residual. Reverse-camera selection preserves correct A/B point association. Shows pixels only (no claim that operator-supplied local images are calibrated, original source photography verified by WRE, physical metres, capture chronology, 4D or GPU training).
The real PyCOLMAP export cross-checks measured feature/point IDs against the previous real track-intersection matrix. The genuine headless Chrome/SwiftShader browser test clicks the 3D hotspot on the actual GLB and verifies the two 2D coordinates to 2 decimals against independently read JSON of actual exported measurements; it reverses camera A/B and verifies the values are reversed without inventing data. This is not a quality benchmark or a GPU demonstration.
Scope and gates
One file only .github/workflows/gsplat-common-runtime-import.yml, optional external CI workflow expressly allowed by V2L18.3; no new dependency/contract/type.
Requires parent [V2L18.3] Inspect measured SfM 3D landmark support in offline viewer #382 (draft) and its parents; check exact-head fast-ci and native gsplat-common-runtime-import with actual Chrome test before asserting end-to-end browser success.
