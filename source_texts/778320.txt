As a feature request, adding a default PBR shader rendering option (with emissive texture layer to include a lighting surface) to support what most other current development systems include. Such an option could follow this texture index pattern:
SetObjectImage(ObjNum,0,DiffuseImage)
SetObjectImage(ObjNum,1,PBRImage)
SetObjectImage(ObjNum,2,EmissiveImage)
SetObjectImage(ObjNum,3,ShadowImage)
SetObjectPBRMode(ObjNum,1) ` to enable
The PBR image should use minimal index space (just one) with RGB channel packing so that other indexes are still available for other possible options. The RGB elements of the PBRImage could include the following for common formatting:
(R)ed = Metal
(G)reen = Roughness
(B)lue = AO/Specular
I wouldn't expect AGK to have the same kind of interface slider controls that Unreal has per entity (ie https://docs.unrealengine.com/en-us/Engine/Rendering/Materials/PhysicallyBased ), instead just providing the ability for the developer to control such parameters with their own PBR textures.
If not this, then at least the old Lambertian approach as a minimum by default with diffuse + normalmap + specular + emissive + shadow. But PBR would be far preferred and more inline with other development systems (and with a Vulkan rendering path).
