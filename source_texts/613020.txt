Using an SVO, the system should generate nodes and layers based on a voxel resolution and the navigation volume bounds. Generation should happen when the game is played, when a button in the editor is pressed, or when an exposed value is changed.
The implementation follows Chapter 21 of Game AI Pro 3, which covers flight navigation. The SVO should store the nodes of each layer in an array, the leaf nodes in an array, and the Morton codes in an array. The layers are generated from the bottom up, after which neighbors are assigned to each node from the top down. The nodes are sorted in Morton order so that they are bit-aligned.
Requirements for the SVO generation:
-Arrays to store the layers with their nodes, the leaf nodes, and the Morton codes
-A function to create all the nodes and layers
-A function to create the leaf nodes
-A function to create the subnodes
-A function to create all neighbors for each node
-A function that checks for collision within a node’s bounds to determine whether it contains an object
-A library for Morton ordering to use within the SVO
-An exposed variable for the voxel resolution
