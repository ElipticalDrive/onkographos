Summary
Coordinated follow-up for BabylonJS/BabylonNative#2027.
Forward each color texture's generateMipMaps intent through the optional ninth native MRT argument. Preserve authored mip storage without automatic regeneration in regular and layered MRTs, frame graph targets, explicit-depth attachment, and sample-count reconstruction. The legacy single-target fallback forwards the first color's flag without shifting layer/mip arguments.
Include generation policies in layered and shared frame graph framebuffer compatibility checks, so changing intent cannot reuse a framebuffer with stale generation flags. Existing argument positions and older-runtime behavior remain compatible.
Companion BabylonNative PR: BabylonJS/BabylonNative#2028
Honoring the new MRT argument requires the companion Native runtime change; older runtimes continue their existing behavior.

## Summary

Separate follow-up to #2025, tracked in #2027. Resolving an MRT base
level must not regenerate caller-authored higher mips when automatic
generation is disabled.

Append optional `autoGenerateMips: boolean[]` after the existing layers
and explicit-depth arguments. Each entry controls its corresponding
color attachment. Omitted flags preserve legacy automatic generation,
and single-framebuffer behavior remains unchanged. Invalid flag types
and attachment counts throw explicit errors.

Using per-attachment flags avoids overwriting an authored chain when
another attachment legitimately needs automatic generation. Mip
allocation and the existing format/base-level capability checks remain
separate.

Companion Babylon.js PR:
BabylonJS/Babylon.js#19120

Both changes are needed to forward and honor the intent. This PR does
not pin an unpublished Babylon.js revision.

through Playground on real Metal: 30 mip readbacks cover disabled,
enabled, mixed, and omitted flags, followed by explicit generation of a
previously preserved chain, plus invalid arguments. Before the fix an
authored value of `17` became `64`; afterward it remains `17`.
- Six existing R32F/RG32F/RGBA32F single-target mip readbacks still
pass.
