This paper presents adaptation of H.264 deblocking filter algorithm for parallel processing of pixel locations. Main target was to realize real-time H.264 Main Profile deblocking filter with minimal memory and computational requirements for processors with vector oriented instruction set. A short overview of entire H.264 deblocking filter is presented, but main focus in this paper is on deblocking filter when macroblock-adaptive frame-field coding is in use. © 2006 by MIPRO.
