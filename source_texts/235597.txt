Objective
Complete the first physical-device depth-to-mesh production path following research transfer and ADR 0016.
Scope
Consume native ARKit/ARCore depth+confidence+intrinsics+pose without round-tripping full-rate buffers through WebView.
Explicitly classify DepthScaleEvidence. Invoke the new DepthFusionGate immediately before actual metric integration, not at raw observation storage; preserve rejected raw evidence.
Distinguish fresh ARCore raw depth from reprojected frames; handle repeated/decreasing timestamps and clock-domain/epoch boundaries.
Validate camera-to-depth extrinsics, units, invalid/zero pixels, confidence masks, uncertainty and stride before rays become geometry.
Implement spatially chunked TSDF with truncation/weight saturation/memory budget and dirty-region mesh extraction. Existing SparseSurfaceVolume is an occupied-voxel preview, not a TSDF.
Preserve provenance/integration logs per chunk for replay or reintegration after pose updates, and keep frame tasks off the UI thread.
Export an independently validated metric GLB from a real scan.
Verification / done when
Deterministic replay validates duplicates, uncertainty, occlusion, pose corrections, checkpoint/resume, bounded memory and mesh update policy.
Physical Android camera-only and ARCore raw-depth sessions documented; physical iOS ARKit depth sessions documented; browser fallback independently evaluated.
CI Rust tests plus per-device P50/P95 ingest-to-preview latency, fresh-versus-admitted frame counts, CPU/GPU load and ≥10-minute thermal session.
Claim only the specific certified device/sensor paths. Do not close from host CI or emulator alone.
Follow-up to #6; #6's sparse preview completion does not imply true TSDF or device-certified integration.
