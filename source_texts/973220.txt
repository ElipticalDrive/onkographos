Adds methods for propagation-based / holotomographic X-ray nanotomography.
All new compute functions accept cuda=True (CuPy) with automatic CPU fallback.
Rebased onto current master (0.3.0); pure additions, no changes to existing modules.
Phase retrieval (toupy.restoration)
tie_hom — single-distance TIE-Hom (Paganin) for homogeneous objects.
ctf_retrieve — CTF retrieval, unified for single-distance, batched, and
multi-distance (holotomographic) inversion (delta_beta + list of distances).
Fixed sign convention (I−1 = −2 sin(χ) φ).
iterative_phase_retrieval — nonlinear retrieval inverting the exact Fresnel
forward model (CG, analytic adjoint, FD-verified). Single/multi-distance,
Tikhonov + total-variation regularisation. Accurate in the multi-fringe /
higher-δ/β regime where TIE-Hom blurs.
suggest_holo_distances — rule-based, gap-free multi-distance series.
Ring artifact correction (toupy.restoration)
remove_rings_wavelet_fft, remove_rings_titarenko, remove_rings_stack.
TV reconstruction (toupy.tomo)
tv_reconstruction, chambolle_pock_tv (Chambolle–Pock primal–dual).
Examples (tutorial/)
example_phase_retrieval_tv_ring.py
example_iterative_phase_retrieval.py
example_iterative_phase_tomography.py (+ CTF frequency-coverage diagnostic)
Verification
Adjoint gradients finite-difference verified (rel err ~1e-10).
All three examples run; e.g. tomography RMSE TIE-Hom 0.33 → iterative 0.10 →
holotomography 0.075 (clean reference 0.075).
Full package imports and examples pass on top of current master.
See CHANGELOG.md for details.

Add toupy.restoration.phase_retrieval for propagation-based / holotomographic
X-ray phase retrieval. All compute functions accept cuda=True (CuPy) with
automatic CPU fallback.

- tie_hom: single-distance TIE-Hom (Paganin) retrieval for a homogeneous
  object (fixed delta/beta).
- ctf_retrieve: CTF retrieval, unified for single-distance images, batches of
  independent projections, and multi-distance (holotomographic) inversion
  (pass a list of distances + a stack). The homogeneous absorption term
  recovers low frequencies / DC; multiple distances fill the CTF zeros.
  Sign convention: I-1 = -2 sin(chi) phi for the exp(+i pi lambda z |u|^2)
  propagator (leading minus, otherwise the retrieved phase is inverted).
- iterative_phase_retrieval: nonlinear retrieval inverting the EXACT Fresnel
  forward model by conjugate-gradient minimisation (analytic adjoint gradient,
  finite-difference verified). Warm-started from TIE-Hom. Single- or
  multi-distance (nonlinear holotomography, valid for strong phase where the
  linear CTF fails). Tikhonov (reg_smooth) and edge-preserving total-variation
  (reg_tv) regularisation. Handles a 1-D projection line exactly.
- suggest_holo_distances: rule-based, gap-free geometric multi-distance series
  (CTF-zero interleaving), parametrised by the Fresnel-number span; verifies
  frequency coverage.

Add toupy.restoration.ring_correction for sinogram ring/stripe removal
(cuda=True supported):

- remove_rings_wavelet_fft: multi-scale Haar-wavelet stripe removal. Each band
  is corrected by subtracting the angular-mean residual (median baseline along
  the pixel axis). Because the subtracted stripe is constant across angle, real
  angularly-varying signal is never removed — safe on every band including the
  approximation.
- remove_rings_titarenko: single-scale median-profile correction.
- remove_rings_stack: apply either method across a 3-D sinogram stack.
