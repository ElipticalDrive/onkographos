I implemented a version of DDGI in Unity and found that using a sparse voxel octree is much more efficient than large, dense 3D grids and allows a user to have much more control over the density of probes.
My implementation first creates a low-resolution voxelization of the scene that is used to subdivide an octree encapsulating the entire scene until the desired density at any point is achieved (density is higher near the camera and around geometry). A user could also add arbitrary 3D volumes to further subdivide the octree or add flags to the voxel fragments (which currently are just a binary value to represent that geometry is present) produced by the voxelization step to request increased density around specific objects. This first part is done entirely in pixel and compute shaders almost every frame.
Probes are then created at the corners of the leaf nodes of the octree and the algorithm proceeds more or less as before except the lighting shader traverses the octree to retrieve the eight indices to the probes that are positioned at the corners of the leaf node encapsulating the lighting position. I couldn't find a good way to retrieve the unique corner positions of the leaf nodes completely on the GPU side so this requires an async readback of the leaf nodes but it's very little data and this is important in order to have persistent probe indices (using a map from positions to indices) anyway.
Overall the performance impact is negligible given the benefit of having reduced or zero (probably not zero if using hysteresis) probe density in empty space and basically automatic cascades without having multiple grids seems to be worth it. I also implemented a very similar octree system for light culling (that manages a light list in a way similar to clustered deferred rendering) so that lights can be evaluated with exactly the same code in both arbitrary pixel and raytracing shaders. This allows for efficient lighting of the DDGI probe rays to the point where I can trace hard shadows for 1024 point and spot lights every frame (1spp for primary, mirror reflection and GI rays each) without adding much to the execution time.
