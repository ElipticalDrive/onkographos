# HybridSfM

HybridSfM is a compact learning project for following the path from calibrated multi-view images to a renderable 3D Gaussian representation.

The repository has two complementary parts:

- **Mini-SfM** is a small, readable implementation of essential-matrix RANSAC, relative pose recovery, triangulation, PnP, tracks, and bundle adjustment.
- **COLMAP and Vanilla 3DGS bridges** make it possible to use the same feature front end with a mature mapper and then optimize its sparse model with the official Gaussian Splatting implementation.

It is intended for studying the handoff between geometry and neural rendering, not as a replacement for COLMAP or a production reconstruction system.

## Pipeline

```text
Calibrated images
  -> SIFT or SuperPoint features
  -> nearest-neighbor or LightGlue matching
  -> Mini-SfM or COLMAP sparse reconstruction
  -> COLMAP cameras.bin / images.bin / points3D.bin
  -> Vanilla 3D Gaussian Splatting
  -> Gaussian PLY, novel-view renders, PSNR / SSIM / LPIPS
```

The sparse SfM PLY contains triangulated 3D points and colors. The final 3DGS PLY is a different representation: each vertex stores a Gaussian center, anisotropic scale, rotation, opacity, and spherical-harmonic appearance coefficients.
