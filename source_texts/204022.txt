Algorithm (summary)
Build O(N log N): during top-down subdivision, wire neighbors via parent/sibling
links + _find_neighbor_of_greater_depth (Samet 1990 tree descent). No all-pairs scan.
Balance O(N log N): collections.deque work queue — push split candidates, never
rebuild full adjacency inside the loop.
Locate O(log N): tree descent via _children_idx. Replaces O(N) linear scan.
leaf_graph O(N): read stored _neighbor_idx pointers. No all-pairs comparison.

Implemented three key functions:

T009: _find_neighbor_of_greater_depth() – Samet (1990) algorithm
  - Finds neighbor in given cardinal direction (W=0, E=1, S=2, N=3)
  - Handles both boundary (exterior) and interior children
  - Recursively descends only when needed; O(log N) per call

T010: _split_leaf() – Split a leaf into 4 children with pointer wiring
  - Appends 4 children to nodes list
  - Wires sibling neighbors via direct arithmetic (O(1))
  - Wires external neighbors via _find_neighbor_of_greater_depth (O(log N))
  - Marks parent as internal

T011: Rewrote build_octree() to use pointer wiring
  - Top-down recursive subdivision with _split_leaf()
  - Sets global _nodes reference for property resolution
  - Calls _balance_2to1() with work queue

T012: Rewrote _balance_2to1() with work queue
  - No adjacency rebuild; O(N log N) amortized
  - Deque of leaf indices; enqueue children when parent split
  - Each node enqueued O(1) times under 2:1 constraint

T013: Deleted old O(N²) functions
  - Removed _build_adjacency(), _are_edge_adjacent(), _intervals_overlap()
