Overview
This database contains several contents with for each content, the reference (without processing or
degradation) and seven different compression rates in jpeg or jpeg2000. There is one spreadsheet
with the individual score and the MOS for each video for the ACR methodology. A text file presents
the conditions in which the still images was evaluated.
This database completes the MICT database with different protocol, different type of display device
and different populations. The results of the two databases can be used to consider the display
technology and the population in a quality model, like in the associated paper for example.

Provided data
All provided data are on our FTP server at :
ftp://ftp.ivc.polytech.univ-nantes.fr/IRCCyN_IVC_Scores_On_Toyama_Images/
The images
On the FTP server, we provide the images in the directory "Images". These images are BMP files.
Subjective scores
The subjective scores are provided.
An Excel file is provided. In this file, there are two spreadsheets, one for each test session (JPG and
JP2). In the 2 spreadsheets, an image is associated to a line and an observer to a column. You have
access to all individual vote from each observer to each image.
The last column is the Mean Opinion Score (MOS).
