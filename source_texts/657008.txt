Implements a complete terrain generation system for CM2D using the existing Bitmap<T,C> template infrastructure, enabling procedural heightmap and biome generation for game maps.
Noise Generators (inc/hgl/2d/NoiseMap.h)
NoiseGenerator - Abstract base with consistent [-1, 1] output contract
PerlinNoise - Classic gradient noise with 256-element permutation table
SimplexNoise - Faster implementation with precomputed skewing factors (F2=0.366, G2=0.211)
VoronoiNoise - Cellular patterns with proper distance normalization
FractalNoise - Multi-octave FBM wrapper with configurable lacunarity/persistence
Terrain Maps (inc/hgl/2d/TerrainMap.h)
HeightMap extends Bitmap32F - Elevation data with:
GenerateFromNoise() - Fill from any noise generator
Normalize() - Remap to arbitrary ranges
CalculateSlopeMap() - Gradient magnitude using central differences
ApplyThermalErosion() - Slope-based material movement
ApplyHydraulicErosion() - Water-based sediment transport
BiomeMap extends BitmapGrey8 - Classification into 9 types (Ocean, Beach, Plains, Forest, Desert, Tundra, Snow, Mountain, River) from height/temperature/moisture maps
TerrainGenerator - High-level orchestration with seed independence via XOR derivation
Implementation
7 source files in src/Terrain/ with optimized algorithms:
Perlin uses fade function t³(t(6t-15)+10) for smooth interpolation
Simplex reduces artifacts with skewed grid traversal
Erosion uses iterative relaxation with configurable rates
Seed derivation uses golden ratio constants (0x9E3779B9, 0x517CC1B7) to prevent correlation
Usage
```
#include<hgl/2d/TerrainMap.h>

TerrainGenerator gen(512, 512, seed);
HeightMap heightMap;
gen.GenerateDetailed(heightMap, 1.0f, 6, 50);  // scale, octaves, erosion_iters

BiomeMap biomeMap;
gen.GenerateBiomes(biomeMap, heightMap);

SaveBitmapToTGA("terrain.tga", &heightMap);
```
Example program in example/TerrainGenExample.cpp demonstrates all features with TGA export. Full API documentation in docs/TerrainGeneration.md.
