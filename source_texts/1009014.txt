Summary
This PR adds a detailed specification and research notes for replacing the current baked L2 spherical harmonics (SH) irradiance encoding with a DDGI-style octahedral irradiance probe atlas. The change targets performance optimization on pre-RTX late-GTX hardware (Pascal/Turing) by moving directional reconstruction from per-pixel ALU to hardware-filtered texture fetches, while preserving per-probe Chebyshev visibility by default.
Key Changes
Specification document (index.md): Complete plan covering goals, scope, acceptance criteria, and seven sequential/concurrent tasks:
Task 1: Octahedral atlas format and base bake
Task 2: Animated delta re-encoding (per-light delta volumes)
Task 3: Runtime GPU resources and loader
Task 4: Compose-pass rework (per-texel octahedral blending)
Task 5: Runtime sampler rework (8-probe loop with hardware bilinear)
Task 6: Aggressive option (Chebyshev skip toggle + CLI flag)
Task 7: GPU timing instrumentation
Research notes (research.md): Background investigation including:
Problem framing (current SH cost structure)
Why octahedral resolves the hardware-filtering vs. per-probe-visibility tradeoff
Alternatives considered (reconstruct-once SH, aggressive single-tap, L1 SH, ambient cube)
Visibility model scope (isotropic per-probe, unchanged from M9)
Fog interaction (dual-direction read, unaffected by aggressive toggle)
M9 reconciliation and wgpu/hardware notes
Notable Details
Scope boundaries: Visibility stays isotropic (per-probe (E[d], E[d²]) Chebyshev); directional octahedral depth is future work. Probe placement, grid resolution, and ray count unchanged. No runtime SH↔octahedral switch — one-way content migration.
Acceptance criteria: Visual equivalence to pre-migration SH, material fetch-count reduction, GPU timing instrumentation, animated light modulation, fog directional response, and aggressive-option measurability.
Wire format: New octahedral section(s) mirroring existing ShVolume (id 20) and DeltaShVolumes (id 27) conventions; decision on sibling IDs vs. in-place replacement deferred to Task 1.
Open questions: Tile resolution (4×4 interior vs. 6×6/8×8), octahedral seam convention, aggressive fallback path, and memory delta confirmation.
This is a planning document; implementation follows the sequenced task breakdown.
