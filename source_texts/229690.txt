概要
BLCS合成データ生成で、asset-localなテニスボールGaussianをフレームごとに剛体変換し、背景3DGSと同じrasterizationへ直接投入できるcomposition modeを追加します。
主な変更
nht-render --composition とrequest/result JSON Schemaを追加
背景Gaussianと動的Gaussianをjoint eval3d rasterizationし、direct linear RGB・alpha・expected depth・instance IDを生成
フレーム×カメラ順のsparse chunkとして結果を公開
positive uniform similarity、tensor dtype/shape、timeline、出力ownershipをfail-closedで検証
CUDAのコンパイル済みchannel集合に合わせてsemantic channelをzero-padし、8 objectを1 passで処理
composition contractとCLI使用例をREADMEへ追加
検証
python -m pytest -q tests/test_export.py tests/test_frames.py tests/test_preflight.py tests/test_run_state.py tests/test_sfm_helpers.py tests/test_training.py (86 passed)
python -m ruff check nht_pipeline tests
python -m mypy nht_pipeline (24 source files)
実B00シーン: 1024 frames × 8 objects、1280×720をCUDAで完走（peak 836,119,040 bytes）
親リポジトリのBLCS実装は、このPRのコミットをsubmodule gitlinkとして参照します。
