Pull request overview
This PR updates the WayFASTER ROS 2 inference pipeline to optionally consume a sparse PointCloud2 (e.g., LiDAR) and voxelize it directly, instead of relying on a dense depth image that is first projected into a point cloud.
Changes:
Add a use_pointcloud mode to the inference node to synchronize RGB with either depth images or PointCloud2, and voxelize accordingly.
Introduce pointcloud voxelization (voxelize_pointcloud) in preprocessing and add launch-file parameters for pointcloud topics and cropping configuration.
Add local helper/testing scripts related to updating the node and validating pc2.read_points.
