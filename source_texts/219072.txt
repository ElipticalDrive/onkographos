Closes #3477
Background
Point clouds need additive levels of detail without reordering their source attributes. This PR adds GPUPointCloudOctree, which builds an immutable-position octree using a packed source-ID buffer and contiguous per-tile ranges.
Stacked on #3466 while the initial GPU geometry/point-cloud operations are under review. Merge that prerequisite first, then retarget this PR to master.
Rationale
Each tile retains a deterministic spatial sample and passes only its remaining IDs to children. Rendering ancestors plus descendants adds detail without duplicating source rows. Sparse breadth-first metadata exposes parent/child links, point ranges, subtree counts and explicit capacity overflow.
Change List
Add GPU Morton sorting, sampling, scans and range partitioning with no intermediate CPU readback.
Add a 32,768-point example with tile bounds, progressive detail, source/visible counts, orbit controls and the reusable GPU Graph panel.
Document metadata, ownership, sampling, overflow and resident-data limits; register the example and thumbnail.
Test CPU-reference agreement, unique ownership, boundaries, invalid points, offsets, repeated encoding, overflow and depth extremes.
Validation
Passed locally: nvm use, yarn install, yarn lint fix, yarn build, yarn website:build (runs the website workspace build), standalone example typecheck/build, focused Node contract/catalog tests and spatial headless GPU tests. Octree tests also pass with core WebGPU limits and no skipped tests. Verified progressive controls and rendering in the browser. The full pre-commit Node run passed 4,304 tests but timed out in the unchanged 20,000-row splat-hierarchy stress test. That unchanged stress test passed in isolation (57.67 seconds including startup); the duplicate hook was bypassed to publish this PR for CI. Prerequisite review fixes for writable binding alignment, normal scaling and geometry control state are incorporated, with passing focused regressions. Full CI passed on e23b3fa, including build/lint, Node tests and coverage, all three browser coverage shards, visual checks, example builds and the website build. Both automated reviews passed. The sidebar display-density review finding is fixed and resolved. Prerequisite #3466 is also fully green on 89787d4.
Limits
Experimental WebGPU operation for resident packed data; maximum depth 10. Fixed passes scan the original point capacity at each level. Streaming, view-dependent traversal and a loaders.gl tile-source adapter are outside this change.
