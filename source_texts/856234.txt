Hello Emmanuelle,
now that I think to it, not only positivity could be enforced but more in general the constraint to a convex domain : I could add a minimum and a maximum.
So why?
Because at the same cost that you need to solve
argmin_x ( 1/2 L2(x-z)^2 + w TV(x) )
you can solve
argmin_x ( 1/2 ||x-z||^2 + w TV(x) ) + Indicator(x, domain)
and keeping the same structure of the current implementation.
In the current implementation, calling p the dual variables of the variations ,
the following equation is implicitly solved :
min_x 1/2 ||x -(z+div(p) ||^2 + Indicator(x, domain) ......
The extra Indicator term implies an extra projection that is what I have added in the routine.
( the same would not be trivial for a more general problem containing
|| M.x - (z+div(p) ||+... with M a matrix, which should be solved by keeping the primal-dual method explicit and thus with more dual variables ( see Convex optimization problem prototyping for image reconstruction in computed tomography with the Chambolle-Pock algorithm Emil Y. Sidky, Jakob H. Jørgensen, and Xiaochuan Pan ))
Do you want me to generalise to a convex domain ( minimum and maximum values given as either None, or a float or an array of floats) ( and always with M= identity)?
To tell you more about the usage it is used to reconstruct volumes on ID20, at given photon-out energy, using several crystal analyzers in 1:1 imaging configuration. The deconvolution may introduce artifact, especially using super resolution, the pixel being smaller in general than the point spread function of the optics. And sometimes the deconvoluted signal may have some negative artefacts ( may be some absorption effect?).
So that's why I adapted the CP_tv to clip optionally on the positive domain ,
Have a nice day
