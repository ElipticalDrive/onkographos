## Overview

<div align="center"><img src="./assets/overview.png" width=60%></div>

We present *Perturbed Gaussian Ensemble*, a novel active view
selection framework for progressive reconstruction tailored specifically to X-ray
Gaussian Splatting. By applying stochastic density perturbations to
low-density primitives that are highly susceptible to geometric degradation
and measuring the structural disagreement in projection space, our method
accurately localizes epistemic uncertainty and predicts the next best view.

## Installation

```bash
# Download code
git clone https://github.com/yulunwu0108/Perturbed-Gaussian-Ensemble.git --recursive

# Install environment
cd Perturbed-Gaussian-Ensemble
conda env create --file environment.yml
conda activate perturbed-gaussian-ensemble
```

## Dataset

Download the data from [this link](https://drive.google.com/drive/folders/1_D4Ft1RrIDkCRyEpmp6qBUoeom7PIV59?usp=sharing) and extract the scenes under `data/`. Each scene should contain `meta_data.json`, the referenced projection and volume arrays, and an initialization point cloud. For example:

```text
data/
└── scene_name/
    ├── meta_data.json
    ├── vol_gt.npy
    ├── init_scene_name_random.npy
    ├── proj_train/
    │   └── ... .npy
    └── proj_test/
        └── ... .npy
```

## Run

Run the following commands from the repository root in the activated environment.

```bash
CUDA_VISIBLE_DEVICES=0 python active_train.py \
    -s <path to dataset> \
    -m <path to model output> \
    --method ensemble \
    --schema v24init2
```

| Argument | Description |
| --- | --- |
| `-s`, `--source_path` | Scene directory containing `meta_data.json`. |
| `-m`, `--model_path` | Output directory for models, metrics, and logs. Use a separate directory for each run. |
| `--ply_path` | Path to the initialization point cloud (`.npy`), e.g., `data/scene_name/init_scene_name_random.npy`. |
| `--method` | View selector: `ensemble` for our method or `rand` for random selection. Default: `rand`. |
| `--schema` | `v<N>init<K>` selects `N` total views starting from `K` initial views. The total must not exceed the candidate pool. Default: `all`, which uses every training view without acquisition. |
| `--iterations` | Total optimization iterations. Default: `30000`. |
| `--ensemble_num_trials` | Number of perturbation trials per acquisition. Default: `10`. |
| `--ensemble_low_density_ratio` | Fraction of Gaussians with the lowest densities to perturb. Default: `0.1`. |
| `--ensemble_scale` | Density multipliers are sampled uniformly from `[1 - scale, 1 + scale]`. Default: `0.5`. |

After training, evaluate the saved model:

```bash
CUDA_VISIBLE_DEVICES=0 python test.py -m <path to model output>
```
