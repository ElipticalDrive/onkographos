# 🔬 UniC-Lift

**Unified 3D Instance Segmentation via Contrastive Learning with 3D Gaussian Splatting**

[![Python 3.9+](https://img.shields.io/badge/python-3.9+-blue.svg)](https://www.python.org/downloads/)
[![PyTorch 2.0+](https://img.shields.io/badge/pytorch-2.0+-ee4c2c.svg)](https://pytorch.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

A modular PyTorch implementation of the UniC-Lift architecture for lifting 2D instance segmentation into 3D using Gaussian Splatting with learned instance embeddings.

> **Paper:** *UniC-Lift: Unified 3D Instance Segmentation via Contrastive Learning* 

---

## Architecture

```mermaid
graph LR
    A["3D Gaussians<br/>(xyz, color, opacity,<br/>scale, rotation)"] --> B["+ d-dim<br/>Embeddings"]
    B --> C["Differentiable<br/>Rasterizer"]
    C --> D["RGB Image<br/>(3×H×W)"]
    C --> E["Embedding Map<br/>(D×H×W)"]
    
    D --> F["L_render<br/>(L1 + SSIM)"]
    E --> G["L_cluster<br/>(Contrastive)"]
    E --> H["L_triplet<br/>(Boundary)"]
    B --> I["L_3D<br/>(KNN Reg)"]
    
    E --> J["E2L Decoder<br/>sigmoid → binary<br/>→ integer labels"]
    J --> K["Instance<br/>Segmentation"]
    
    style A fill:#1a1a2e,stroke:#16213e,color:#e0e0e0

    style C fill:#0f3460,stroke:#533483,color:#e0e0e0
    style J fill:#533483,stroke:#e94560,color:#e0e0e0
    style K fill:#e94560,stroke:#e94560,color:#fff
```
