Summary
Modern C++ port of volrover's legacy C volren software raycast volume renderer into libcvc as cvc::volren (inc/cvc/volren/ + src/cvc/volren/, following the nav/vis module layout), per the modernization roadmap. The ray/isosurface-intersection subset of libiso (the only part the renderer used — one call site, iso_intersectW) is absorbed as an internal detail; libiso's mesh-extraction role stays with the existing cvc::iso(). Full design + fidelity notes: docs/VOLREN_API.md.
Design
No globals, no singletons: the legacy VolRenEnv/MultiVolRenEnv aggregate becomes value types owned by a raycaster instance; every #define is a typed constant (defaults::/limits::); the header-static MC/specular tables are inline constexpr; the spline-gradient cache that forced vrCopyEnv per OpenMP thread is a per-ray stack object.
cvc objects at the boundary: cvc::volume in (shallow copy, buffer pinned via active_storage() for the render), cvc::image out — RGBA8 color (top-left origin) + f32 eye-space depth map with depth_to_window_z() for a later gl_FragDepth composite.
cvcGL-compatible camera: eye/focal/up pose (CameraController::getPose() feeds straight in), vertical fov in degrees (vtkCamera::ViewAngle), SetParallelScale ortho semantics.
Scene-graph transforms: each volume carries a mat4 model_transform in exactly cvcGL's convention (row-major double[16], column-vector points — the GraphicsNode matrix state-key encoding). Object-space raycasting through the affine inverse; iso hits keep world-comparable ray parameters so the depth map stays consistent; normals return via the inverse-transpose.
State tree for all settings: state_settings two-way binds the full surface at <prefix>.volren.* (state_object pattern, synchronized seeding via state_init_scope, mutex-guarded snapshot). Transfer functions use VolumeNode's transfer_function.color/.opacity flat-CSV encoding so the same editors drive both renderers.
Modern threading: tile-parallel via cvc::thread_pool (a private pool by default — thread_pool supports only one in-flight parallel_for, so borrowing the shared computePool() blindly can deadlock; flagged separately for a core fix). Output is byte-identical for any thread count; progress through app::threadProgress; boost interruption between slabs; exceptions in pool tasks are captured and rethrown on the orchestrator.
Fidelity vs legacy (full catalogue in the doc)
Preserved: per-cell (not per-sample) contribution, front-to-back associated-color compositing with 0.95 early termination, quadratic-B-spline (de Boor) gradients, MC cell intersection with the VTK table family (consistent with cvc::iso(..., FASTCONTOURING)), gradient-magnitude opacity modulation, Blinn-Phong with the 0.9 gain.
Fixed: multi-light overwrite (= vs +=), blue-diffuse-from-green-light, env[0] iso frames in multi-volume, FLOAT assert(0) (all cvc::data_types render), ignored shininess, cut planes (declared-but-dead in the tracer) now implemented, raster rounding to 32 / dropped remainder tiles, divide-by-alpha saturation hack, camera-inside-volume rendering.
Dropped: materials/ColorMode (never consumed by the tracer), the .cnf format, vrLoadVolume's format zoo (superseded by cvc::volume_file_io), MPI drivers, RawV multi-variable volumes (future work).
Testing
144 tests across six new gtest suites (registered per the 4-step pattern): camera math (38), transfer functions (27), kernels vs analytic fields — trilinear exactness, spline gradient recovering linear-field gradients, MC tables cross-validated against the legacy headers, cell intersection vs closed forms (26), math/mat4/depth (24), end-to-end renders (21) incl. thread-count byte-invariance, transform equivalence, depth-map latching, cut planes, multi-volume, and state binding (8). An adversarial multi-agent review (5 dimensions, every finding independently verified) produced regression tests + fixes for: translucent-iso depth latching, NaN-voxel/pose hardening (no UB casts, no unbounded march), the state-binding plateau drop, CSV precision, and the pool-sharing deadlock hazard.
Full local suite passes except three pre-existing ImageMagick codec tests that fail against the local deps prefix (delegates missing; master's build-debug against system IM6 passes them) — unrelated to this change.
Follow-ups
cvcGL drop-in node: textured quad + depth texture + //VTK::Depth::Impl replacement using depth_to_window_z (integration recipe in the doc); the node composes its scene-graph world matrix and hands it to volume_settings::model_transform.
CUDA path per the voxels_kernels.cu precedent.
Core cvc::thread_pool concurrent-parallel_for deadlock (separate task).
