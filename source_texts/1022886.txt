Part of #155. Two shader changes:
1. New shader: compute_occupancy.rs
After voxelize, per-brick compute pass checks if any voxels are occupied.
Output: brick_occupied[TOTAL_BRICKS] — 0 or 1 per brick.
Dispatch: 1D, 64 threads/workgroup, ceil(TOTAL_BRICKS/64) workgroups.
Push constants:
```
pub struct ComputeOccupancyPushConstants {
    pub grid_size: u32,
    pub brick_size: u32,
    pub bricks_per_axis: u32,
    pub _pad: u32,
}
```
Bindings:
binding 0: voxels: &[u32] (read) — voxel grid from voxelize pass
binding 1: brick_occupied: &mut [u32] (write) — output occupancy
Logic (helper function): For brick at index idx, compute brick coords (bx,by,bz), iterate all 8x8x8 voxels in that brick. If any voxel != 0, set occupied = 1. Use while-loops.
2. Modify render shader: compute/render/mod.rs
In the ray march loop, before stepping into a voxel, check the brick occupancy.
Add binding for brick_occupied: &[u32].
In the DDA march:
```
let brick = pos / brick_size;
let brick_idx = bz * bpa * bpa + by * bpa + bx;
if brick_occupied[brick_idx] == 0 {
    // Skip to next brick boundary
    // Advance t by distance to next brick boundary along ray direction
    continue;
}
// Normal per-voxel march
```
The brick skip optimization: when an empty brick is hit, advance the ray to the far side of that brick rather than stepping voxel-by-voxel. Compute the exit distance using standard DDA on the brick grid.
Register in mod.rs
Add pub mod compute_occupancy; to compute/mod.rs.
Closes part of #155
