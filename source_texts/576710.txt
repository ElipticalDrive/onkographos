Add a span renderer so callers can draw transformed, painted, masked SDF shapes directly into borrowed premultiplied RGBA rows without allocating or resampling a temporary image. SSE2/NEON evaluate coordinates, distances, gradients, coverage, mask multiplication, and blending in four-pixel packets; scalar code handles tails, unsupported CPUs, and per-call comparison.
The new sdfy/spans API provides prepared circular/elliptical fields, solid/two-stop/three-stop/four-corner paints, local clipping, byte or RGBA alpha masks, fill/stroke/drop/inset-shadow coverage, source-over and masked replacement. drawRoundedBox is an image wrapper over drawRoundedBoxSpan; distance/distances support custom samplers. Inputs are borrowed synchronously. Public constructors validate finite prepared values, and mismatched masks fail before writes. Existing drawSdfShape behavior stays compatible.
Elliptical rounded boxes previously spilled SIMD packets to arrays and called the scalar distance function four times. This change evaluates all four distances in SSE2 or NEON registers, including quadrant selection, radius clamping, and mixed elliptical, circular, and sharp corners.
Batches without corner pixels skip corner math, and circular batches skip ellipse calculations. ARM64 uses vector hardware division and square roots; ARM32 uses vector reciprocal estimates with Newton refinement. Existing imports through the fallback modules remain compatible. No threading or GC behavior changes.
Bump the package from 0.8.4 to 0.8.5, and document the SIMD behavior.
Validation:
Full nim test suite.
Direct scalar/SIMD comparisons for mixed corners, degenerate bounds, quadrant boundaries, the near-center epsilon branch, and 2,000 deterministic randomized packets.
Native ARM64 NEON and x86_64 SSE2 executed through Rosetta; scalar-only tests also pass.
ARM32 semantic check passes; ARM32 runtime validation remains unavailable.
Added a reproducible release benchmark comparing direct scalar calls, the former scalar-lane SIMD path, and the new SIMD path. Each sample evaluates 16,384,000 points; results are the minimum of five release-mode samples, with matching checksums.

Native macOS uses Nim 2.2.12/Clang; Docker uses nimlang/nim:2.2.4 with GCC 12.2. Docker executes on a native x86_64 remote host without CPU emulation. All 11 focused SIMD tests and 8 scalar-only tests pass in Docker. These timings compare implementations within each environment, not CPU performance across environments.
The benchmark compares this kernel with the former four-scalar-lane implementation. Distance-kernel timings are not end-to-end FigDraw timings; the direct span integration is in elcritch/figdraw#100.
Circular rounded-box SIMD
Also reduce SSE2 absolute values from negate/max pairs to sign-bit clearing and reuse vector square roots for ARM32 instead of spilling four lanes to scalar sqrt. ARM64 retains its existing hardware vector-square-root path. Public signatures, threading, and GC behavior are unchanged.
Added test_rounded_box_simd.nim to nim test, covering signed zero, quadrant selection, per-corner/zero/negative/oversized radii, degenerate bounds, and 2,000 deterministic randomized packets. Full local nim test, native Linux/x86_64 focused tests, and ARM32 semantic checks pass; ARM32 runtime is untested.

Span tests cover paints/effects, clipping, both mask formats, both blend modes, odd/empty/short spans, unaligned views/guards, identical destination/mask aliasing, image-wrapper parity, and validation before writes. Solid compositing byte arithmetic matches scalar exactly. SIMD gradient/shadow comparisons allow one channel value at rounding boundaries; Gaussian shadows use vector range reduction and a polynomial approximation.
Validation: full nim test; final span regressions on native NEON, Rosetta SSE2, Docker native Linux/x86_64 and scalar-only builds; ARM32 semantic check; AddressSanitizer. ARM32 runtime remains untested. Astra reviewed both the API and FigDraw integration; its gradient-reciprocal validation finding was fixed with regressions and rechecked, with no remaining findings.
