Contributor
The existing LOD pipeline forces dense 16×16 heightmap diffusion for every chunk, wasting compute on empty cells. This adds a sparse octree representation to TerrainPatch and a matching generation path in DiffusionChunkGenerator, aligning the data contract with Voxy's octree storage schema.
Changes
Voxel.java (new)
Immutable value class for a single occupied voxel at (x, y, z) in octree-local space. equals/hashCode make it safe as a Set key.
TerrainPatch.java
Added OCTREE_SIZE = 8 constant.
Two fields computed automatically from the heightmap in the constructor:
Set<Voxel> occupiedVoxels — only terrain positions, unmodifiable.
int[][][] octreeStructure — 8×8×8 binary occupancy grid [x][y][z]; Y axis quantises the height range into OCTREE_SIZE levels.
Public accessors: getOccupiedVoxels(), getOctreeStructure() (defensive copy), getOccupiedVoxelCount().
Fully backward-compatible; no existing constructor or method changed.
DiffusionChunkGenerator.java
New buildSparseOctree(chunkX, chunkZ, heightmap8x8, biomes64, lod):
Validates 8×8 input dimensions upfront.
Applies OCTREE_SIZE - lod smoothing passes (LOD 0 → most detail, LOD ≥ 8 → no-op).
Returns a TerrainPatch with the sparse occupancy already populated.
```
// Before: always diffuse all 256 values
buildSurfaceWithLOD(chunkX, chunkZ, fullHeightmap16x16, biomes, lod);

// After: work only over the occupied 8×8 patch surface
TerrainPatch patch = generator.buildSparseOctree(chunkX, chunkZ, heightmap8, biomes64, lod);
Set<Voxel> occupied = patch.getOccupiedVoxels();   // only terrain voxels
int[][][] octree    = patch.getOctreeStructure();  // Voxy-compatible 8×8×8 grid
```
Tests
VoxelTest — equality, hashing, Set deduplication.
New TerrainPatchTest cases — OCTREE_SIZE constant, all three accessors, binary-value invariant, lowest-Y-level always-occupied invariant (including flat-heightmap edge case), defensive-copy isolation, occupiedVoxels↔octreeStructure cross-consistency.
New DiffusionChunkGeneratorTest cases — return type, occupied voxels non-empty, wrong-size input rejection, multi-LOD validation with bounds checks.

Original prompt
Sparse Octree Reconstruction Model
Instead of refining dense heightmaps, generate only the occupied voxels at each octree node:
• Input: Parent octree node (8 child voxels)
• Output: Refined occupancy grid for children (8×8×8 subdivision)
• Data schema: Store only non-empty octree nodes, predict which of the 8 subdivisions have terrain
• Advantage: Naturally sparse—only predicts/stores voxels where terrain exists
Parent LOD (sparse): 8 voxel nodes →
Model predicts → Which of 512 child voxels are occupied
Result (sparse): Only populate the occupied children
Why Your Current Model Wastes “Sparse”
Your current design:
// DiffusionChunkGenerator.buildSurfaceWithLOD()
// For each LOD, you're refining a FULL 16×16 heightmap
// Even if LOD 0 has only 3 terrain peaks, you're diffusing all 256 values
Voxy’s octtree stores only occupied nodes—but you’re forcing dense prediction everywhere, then throwing away empty cells.
Recommended Next Steps
Modify TerrainPatch to store sparse occupancy (LODiffusion):
// Instead of:
int[][] fullHeightmap; // Always 16×16
// Use:
Set occupiedVoxels; // Only terrain voxels
int[][][] octtreeStructure; // Aligned with Voxy's schema
Change training target in train.py (VoxelTree):
• Input: Parent octree node (sparse feature vector)
• Output: Child voxel occupancy predictions (bitmap or sparse list)
• Loss function: Sparse reconstruction loss (not dense MSE)
Export as Voxy-compatible model (VoxelTree):
• ONNX export with batch voxel prediction
• Encode output as sparse voxel coordinates + properties
NOTE: The training pipeline is in the VoxelTree repo, not here. Let's align LODiffusion with Voxy, then I'll train new models that fit the contract later in the other repo.
