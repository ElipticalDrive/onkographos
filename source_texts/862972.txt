Identified translation cost
physx_source_aggregate_projection_sort_native.hlsl preserves the original aggregate-owned eight stable four-bit radix passes, but the current native lowering computes the 32-lane stable equal-digit rank with a per-lane unrolled 32-element comparison and calculates completion with another 32-element loop. Each pass also uses multiple group-memory barriers and global scratch traffic. This replaces the original single-warp radix/scan structure with more shared-memory coordination and O(32²) lane comparisons per chunk.
The result is behaviorally source-derived, but the execution strategy needs an independent cost comparison, especially for aggregates exceeding 32 endpoints and wave64 devices. No claim of actual slowdown is made without hardware measurement.
Required work
Measure GPU time, register pressure, LDS occupancy, atomic contention, and command-recording cost for representative small/medium/large aggregate distributions. Compare the current stable-rank lowering with a subgroup-aware packed ballot/prefix implementation preserving exact stable digit ordering and identical endpoint/handle output on Vulkan and D3D12. Never assume physical subgroup width equals logical 32 lanes; keep one source-owned aggregate projection history and current/previous slot model.
Acceptance
Bit-exact sorted key/handle parity for equal keys, odd endpoint tails, 1/31/32/33/35/64/128+ members and multiple aggregates per group on both backends; test multi-frame self/root-static/root-root found/lost parity and rollback. Record hardware GPU timings and choose the faster supported lowering without a runtime mode ladder, CPU sort, extra dispatch, or history copy. Functional software GPU and WARP runs are not throughput evidence.
N2 integrated baseline
The source sort retains eight stable four-bit radix passes, the original member/projection storage and the fixed multi-frame history schedule. The native projection shader no longer inserts device-memory barriers between independent chunks within one pass; cross-pass visibility and intra-chunk group synchronization remain. Vulkan and D3D12 independent tests cover 128-member multi-chunk output and three-frame slot reuse.
Subgroup packed-rank replacement is not selected without comparative hardware GPU timings. Measure current native dispatch time, occupancy/register pressure and large-aggregate scaling as part of N3 performance acceptance. Keep the original source-stable key/handle oracle and both backend conformance suites.
