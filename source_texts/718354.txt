```
    Thanks for your interest in our work. Sure you can use the _interp model to obtain values by sending the sampling points and then perform ray marching. 
    Regarding the hash mapped input, each point (x', y') in the image corresponds to a value obtained after applying hash coding to the original image coordinates (x, y). The color value of each point is predicted from the diner model.
    In order to obtain the hashed input (d), after training DINER, you can iterate through each value in the hash table, feed it into the MLP to obtain the corresponding predicted color value, and then plot it. 
    As for the learned INR, we mainly focus on the properties of the second half of the diner model(MLP). We feed normalized grid coordinates into the trained MLP and visualize the learned function mapping, which represents a mapping relationship from the hashed coordinates to their corresponding colors.
    I hope my answer can help you.
```
