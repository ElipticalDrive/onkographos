Objective
Add a reusable debug-line rendering facility that can display world-space reference geometry and object bounds without embedding diagnostic rendering directly in the Sandbox.
Current Context
The Sandbox currently renders its reference grid through dedicated grid buffers and shader state.
Viewport selection uses reusable sphere and transformed-box bounds, but those bounds cannot currently be visualized. Rendering them as wireframes would make selection, transform, and spatial-query behavior easier to inspect.
The grid and bounding-box visualization share the same underlying requirement: rendering colored world-space line segments.
Dependencies
Add viewport object selection and visible feedback
Add a minimal Sandbox debug UI
Implementation Notes
Introduce a narrow reusable line-rendering path.
Keep backend-neutral debug geometry descriptions in ForgeSim::Renderer.
Keep OpenGL buffer, shader, and draw-call ownership in ForgeSim::Renderer::OpenGL.
Keep debug-visibility policy in the Sandbox or debug UI.
Support colored world-space line segments.
Add helpers for producing a reference grid and wireframe boxes.
Render transformed object bounds using the same model transform used for picking.
Allow bounding-box visualization to be enabled or disabled.
Migrate the existing Sandbox grid to the reusable line-rendering path.
Preserve independent visibility control for the grid and object bounds.
Avoid introducing a general renderer abstraction or complete debug-drawing framework.
Keep ForgeSim::Core independent of rendering and graphics types.
Acceptance Criteria
Arbitrary colored world-space line segments can be rendered
Line rendering is reusable outside SandboxApplication
OpenGL resource ownership remains in ForgeSim::Renderer::OpenGL
ForgeSim::Core does not depend on debug geometry or rendering code
The existing reference grid uses the reusable line-rendering path
Grid appearance remains correct
Object bounding boxes can be rendered as wireframes
Rendered bounds use the same transforms and local bounds as viewport picking
Bounding-box visualization can be enabled and disabled
Grid and bounding-box visibility can be controlled independently
Debug-line rendering respects the active camera view and projection
Resizing, minimizing, and restoring remain safe
Backend-neutral geometry generation has deterministic headless coverage where practical
Clean Debug and Release builds succeed
Debug and Release tests pass
The Sandbox works in both configurations
Changes are committed and pushed
Out of Scope
Physics collision visualization
Mesh-triangle wireframes
Mesh-accurate selection
A complete immediate-mode debug-drawing API
Persistent debug primitives
Debug text rendering
Renderer-backend abstraction
Non-OpenGL implementations
Editor viewport architecture
Bounding-volume editing
