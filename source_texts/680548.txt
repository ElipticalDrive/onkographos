Description
Expose the voxel distances already computed for adaptive infill through a reusable physical-distance API. An optional exterior transform makes the field signed, negative inside.
Share retained grid storage with existing adaptive profiles, preserving their interior costs. Sampling supports interpolation, bounded resolution, cancellation and construction progress.
Tests
Signed-distance and existing adaptive-field suites.
Validated with a focused native C++17 Release harness on Linux and changed-line clang-tidy. Full application and Windows/macOS builds were not run for this extraction.
