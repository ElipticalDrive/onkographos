Gaussian splat tiles (KHR_gaussian_splatting + SPZ) as native Blender 5.3 3DGS point clouds
cesium-native already decodes KHR_gaussian_splatting (also the KHR_gaussian_splatting_compression_spz_2 form) into POSITION, COLOR_0, KHR_gaussian_splatting:ROTATION/SCALE and SH_DEGREE_d_COEF_n attributes. This PR carries those through the direct-mesh path and turns each tile into a native Gaussian splat cloud.
tileset/native_mesh.py: _splat_arrays extracts rotation, scale, SH per POINTS primitive, composes the node transform rotation / uniform scale, and conjugates into Blender's Z-up frame (q -> (x, -z, y, w), s -> (sx, sz, sy)), which preserves the splat covariance (tests/test_splat_math.py). Payload gets splats, splat_rotation, splat_scale, splat_sh.
io/__init__.py: _store_splat_attributes writes Blender's conventions on the vertex-only mesh (radiance:base = SH DC + opacity, scale in metres, rotation as w,x,y,z, radiance:sh_n); on Blender ≥ 5.3 the shared OGC3D Splats group (Mesh to Points → Set Point Cloud Type: 3D Gaussian Splat) is attached, older Blender keeps the coloured-points path. apply_point_display leaves splat tiles alone.
Scene origin: a tileset whose root centre is inside the Earth (not georeferenced, e.g. 3dtiled output) gets an identity frame (origin at lat 90 / lon −90 / h −b, so ENU = XYZ) instead of a meaningless cartographic origin; the panel shows "Local tileset".
Sidebar hint in Display when splat tiles are loaded; README section.
Tested in Blender 5.3 beta (cesium-native-python static cp313 wheel):
public sample WilliamLiu-1997/3D-Tiles-RendererJS-3DGS-Plugin data/Elevator-3dtiles/tileset.json (3D Tiles 1.1, SPZ_2, SH degree 3): 336 tiles streamed, ~6 ms/tile import, EEVEE 3 s / Cycles 83 s renders, Workbench shows coloured points, Rendered viewport shows splats;
local 3dtiled splat tilesets (non-georeferenced): upright with the identity frame.
Known limits: Blender sorts splats per object, so during a REPLACE transition overlapping parent/child tiles blend in undefined order for a moment; Material Preview relies on Blender's splat support in the beta.

cartographic position: the tileset's Z-up metres become the scene.
