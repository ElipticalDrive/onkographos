Goal
Flatten a region to create a city plateau, blending with surrounding terrain.
Steps
Create CityPlateauSdf.cs in Scripts/World/SDF/.
For CityPlateauFeature:
Compute distance to centerXZ.
Create a mask via smoothstep (inside radius = 1, outside = 0).
Compute target plateauHeight.
Blend base terrain height toward plateauHeight in this area.
Return SDF for plateau-corrected height.
How to test
Preview SDF slices near city center.
Observe flat-ish region at plateau height; edges smoothly blend into surrounding terrain.
