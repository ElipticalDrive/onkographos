This commit optimizes the cloud raymarching/sphere-tracing loop in `atmosphere_lowres.comp` by introducing a low-resolution (128x32x128) 3D SDF texture that acts as a conservative proxy of the analytical cloud SDF.

Changes include:
1. Created `cloud_3d_sdf_bake.comp` compute shader to analytically bake the lofted cloud SDF into the 3D texture using unadvected coordinates.
2. Allocated and managed `_cloudSdf3DTexture` in `AtmosphereManager` using GL_R32F format and bound it to Unit 45 (GL_REPEAT horizontally, GL_CLAMP_TO_EDGE vertically).
3. Dispatched the 3D SDF bake shader in `AtmosphereManager::Update` whenever cloud parameters are updated.
4. Optimized the raymarching loop in `atmosphere_lowres.comp` to first sample the 3D SDF texture to skip empty space conservatively, and only perform full analytical evaluations inside active cells.
5. Fully validated all shaders with `make glcheck` and verified C++ build and tests.
