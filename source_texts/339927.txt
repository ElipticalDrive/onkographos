Summary
This adds volume rendering for three-dimensional variables on HEALPix grids. It is mainly intended for atmospheric fields such as cloud water (clw) and cloud ice (cli).
The Volume layer is disabled by default and can be enabled from the Layers panel.
Features
Ray-marched volume rendering on the globe
Support for up to four compatible variables at once
Individual colors and opacities per variable
Reduced sampling while moving the globe for smoother interaction
Adaptive 3D texture resolution based on HEALPix resolution, GPU limits and a memory budget
Background texture construction using a Web Worker
Loading and texture-construction progress
Reuse of the HEALPix spatial mapping between timesteps
Shareable Volume state in the URL
Mobile-friendly color and opacity controls
“Land and sea” mask option for viewing volumes without the scalar field
The source data is converted into an 8-bit equirectangular 3D texture. If a geometric height coordinate is available, it is used for vertical interpolation; otherwise the model-level ordering is used.
This MR intentionally supports HEALPix only. Support for other grid types can be added separately once suitable datasets are available for testing.
Testing
Tested manually with clw, cli and other 3d variables of HEALPix datasets
I recommend this dataset for testing, higher zoom levels produce nicer volumes
Tested timestep changes, multiple volumes, colors, opacities and URL restoration
105 unit tests pass
ESLint, TypeScript checks and production build pass
