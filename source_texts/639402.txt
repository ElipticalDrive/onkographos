Goal
Map merged AR-09 face-light samples onto the exact vertices produced by the existing deterministic greedy mesher, while preserving the canonical mesh object and delaying PlayCanvas allocation to a later slice.
Pipeline
```
canonical greedy mesh
  + alumbra.chunk-face-light/1
        ↓
geometry-path discovery
        ↓
face-normal and voxel sampling
        ↓
alumbra.vertex-light-sidecar/1
        ↓ later pooled GPU upload
```
Requirements
discover every mesh geometry group without assuming one material layout;
align one u8x2 sunlight/emitted pair with every vertex;
support local-space and world-space mesh positions;
map outward normals to the fixed west/east/down/up/north/south face order;
cover greedy quads spanning multiple voxels;
preserve the existing mesh object and index buffers exactly;
deterministic geometry paths and group ordering;
bounded sidecar evidence with no position, normal, index or light buffers;
malformed normals, coordinate space, group shape and revision mismatch fail before GPU allocation;
no Engine, Hodos, DOM, PlayCanvas or storage dependency in the sidecar builder.
Follow-up
AR-11 will install the sidecar as a bounded PlayCanvas vertex attribute through the existing prebuilt renderer and resource pools.

Closing as superseded/not planned. The reviewed implementation did not introduce a second alumbra.vertex-light-sidecar/1 geometry model. Instead, canonical greedy meshing directly emits aligned renderer-owned Uint8Array sunlight/emitted channels per material group, includes them in mesh signatures and worker validation (#46/#47), then projects them through the existing pooled prebuilt renderer as bounded vertex colours (#49). That path supports greedy quads, exact revision/profile/generation evidence, reuse/replacement and pre-allocation failure without a separate sidecar authority. The later viewport coordinator and live lighting train build on that single model.
