# Cimacraft

Cimacraft is a comprehensive, Minecraft-inspired voxel game and engine built from the ground up in Java using LWJGL. It features an expansive set of systems including procedural world generation, complex machinery, item and fluid logistics, a redstone-like power system, and a custom physics engine.

## Core Features

*   **Voxel Game Engine**: A complete, custom-built engine managing rendering, windowing, input, and UI.
*   **Procedural World Generation**: Utilizes `FastNoiseLite` to generate infinite, chunk-based worlds with distinct biomes, complex cave systems, rivers, and strategic ore distribution.
*   **Advanced Logistics and Machinery**:
    *   **Energy System**: Generate power with solar panels, store it in energy cells, and power a variety of electric machines like furnaces and pumps.
    *   **Fluid Dynamics**: Features a complete fluid system with tanks for storage and pumps for extraction.
    *   **Transport Network**: A sophisticated cable system for transporting items, fluids, and energy. Includes "smart" cables with filtering, routing logic (round-robin, nearest-first), and redstone control.
*   **Redstone-like System**: A fully-featured logic system with components like torches, repeaters, comparators, and redstone dust to create complex contraptions.
*   **Dynamic Piston Mechanics**: Functional pistons and sticky pistons capable of pushing and pulling sequences of up to 12 blocks.
*   **Modular Item & Block Framework**: A highly extensible system for defining blocks and items. Blocks can have custom geometries (slabs, stairs, cables), and items possess components that dictate their behavior (tools, armor, placeable items).
*   **Crafting and Processing**:
    *   A full-featured crafting system that supports shaped and shapeless recipes loaded from JSON files.
    *   A variety of processing machines, from starter fuel-based furnaces to advanced alloyers and compactors.
*   **Custom Physics & UI**:
    *   A custom physics engine that handles entity movement, collision with the voxel world, gravity, and player-specific actions like crouching and step-assist.
    *   A flexible UI system for creating the in-game HUD, inventory screens, and detailed machine interfaces.

## Key Architectural Systems

The project is structured into several key packages that manage different aspects of the game:

*   `/engine`: The core game engine layer. It is responsible for low-level operations like creating the window, handling user input, managing the main game loop, and the rendering pipeline (shaders, meshes).
*   `/world`: Contains all logic for the game world, including `Chunk` management, the `WorldGenerator` for procedural generation, the `LightEngine` for lighting calculations, and physics/logic subsystems like `LiquidSimulator` and `RedstoneSystem`.
*   `/block`: Defines all blocks, their properties (`BlockDefinition`), behaviors, and associated `BlockEntity` (tile entity) logic for complex blocks like machines and chests. It also contains the geometry handlers for non-cubic blocks.
*   `/item`: Manages all items, their components (`ItemComponent`), and the inventory system. This includes definitions for tools, armor, materials, and recipes.
*   `/fluids`: An independent system for handling liquids, complete with its own inventory, slots, and rules for interaction.
*   `/entity`: Governs game entities, such as the `Player` and `DroppedItemEntity`, and integrates them with the `PhysicsSystem`.
*   `/ui`: Implements the entire user interface, from the main game `HUD` and `InventoryUI` to specific interfaces for every machine and interactive block.

## How to Run

This project is built using Gradle.

1.  Clone the repository to your local machine.
2.  Navigate to the root directory of the project.
3.  Run the application using the Gradle wrapper:

    *   On Windows:
        ```shell
        gradlew.bat run
        ```
    *   On Linux/macOS:
        ```shell
        ./gradlew run
