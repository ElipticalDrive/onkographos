The Gaussian Splatting page did not cover the opt-in GPU depth sort from BabylonJS/Babylon.js#19013, nor several features added since: loader options, point splatting, the debugger, hosted streamed parts and the streaming splatBudget. This brings the page up to date so users can discover and tune them.
New or extended sections:
GPU depth sorting: UseGpuSort, useGpuSort, GpuSortMinFrameInterval, and the conditions that fall back to the CPU sorter. A note says it is off by default and may change.
Rendering and sorting settings, loader options and safe orbit camera limits.
Point splatting (WebGPU) and the GaussianSplattingDebugger.
Streaming: splatBudget, resident-memory semantics, and streamed SOG as a part of a compound mesh. The section is no longer labelled experimental.
Supported formats now mention compressed and half-float PLY and SPZ v4, also reflected on the importer page.
Thumbnails are added for the Gaussian Splatting playgrounds that were missing one.
This is a draft because the GPU sort API only exists in the still-open Babylon.js#19013. Everything else was checked against Babylon.js master. The GPU sort section should be re-checked against the final API before merging.
Worth a look: rangeResidency is described in text only, because its playground is a 90-splat unit test.
To preview locally: npm run dev, then open /features/featuresDeepDive/mesh/gaussianSplatting.
