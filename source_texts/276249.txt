Summary
The forward pass fogs opaque surfaces by reading the froxel volume, but the transparent template does not read it, so glass in fog is unfogged. The transparent template can read the volume as the opaque one does.
User stories
As a technical artist, I want transparent surfaces in fog to be fogged, so that glass does not stand out of the haze.
Requirements
The transparent template reads the fog volume at each pixel's position, trilinearly: color × transmittance + scattered, as the opaque forward pass does.
Both transparency paths (moment-based and sorted) apply it.
Acceptance criteria
A glass pane behind fog in the sample is fogged.
The rendering docs describe the built feature, in the present tense.
When to do this
When transparent surfaces in fog show in a game.
Context
Rendering: Volumetric fog
Rendering: Transparency
