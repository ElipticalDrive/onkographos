Summary
add plugins/vasp_isosurfaces.py outside the core src package
generate positive and negative VASP isosurfaces with periodic boundaries and smooth vertex normals
interpret public isosurface levels using VESTA units
save and reload renderer-independent mesh geometry through versioned .npz caches
use yellow and cyan translucent default materials with transmit=0.3 and filter=0.1
document the optional scikit-image dependency and basic usage
Why
Isosurface extraction is domain-specific and potentially expensive, while atomic-povray only needs the resulting generic triangle meshes. Keeping this helper in a top-level plugin preserves the core package boundary and avoids making scikit-image a core dependency.
Validation
python -m py_compile plugins/vasp_isosurfaces.py on the exact published module content
inspected the branch diff against current main
verified both published files and the exact default material definitions through the GitHub connector
The full project test suite was not run because the change is an external, uninstalled plugin and the transient workspace lacks ASE/scikit-image. The module is based on the previously numerically validated standalone implementation; this PR changes its default materials and repository placement.
