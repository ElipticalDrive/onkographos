I think that it makes sense to add wrappers for external tomographic reconstruction algorithms because HyperSpy can take care of keeping the calibration and of parallelizing the reconstructions if needed. However, probably we need a more general approach. What about:
```
reconstruction = tilt_series.tomographic_reconstruction(reconstruction_algorithm, kw1, kw2, kw3)
```
tomographic_reconstruction could call Signal.map if parallelization is needed and do the right thing with the output. Otherwise it could simply call the function, getting the angles from the first axis and then return an Image with the right calibration.
