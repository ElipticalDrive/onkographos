Hello Piero,
Thanks for this. It is a great resource.
I have been trying to combine your acceleration structure with this tutorial
http://blog.three-eyed-games.com/2019/03/18/gpu-path-tracing-in-unity-part-3/
Which I have already modified to have transparency and refraction.
I am having issues with your ray triangle intersection and discarding backfaces.
The triangle intersection test in the tutorial follows that of Möller and Trumbore
Like so, which allows for backface culling.
```
bool IntersectTriangle_MT97(int offset, Ray ray, float3 vert0, float3 vert1, float3 vert2,
	inout float t, inout float u, inout float v, inout float2 uvHit)
{
	// find vectors for two edges sharing vert0
	float3 edge1 = vert1 - vert0;
	float3 edge2 = vert2 - vert0;

	// begin calculating determinant - also used to calculate U parameter
	float3 pvec = cross(ray.direction, edge2);

	// if determinant is near zero, ray lies in plane of triangle
	float det = dot(edge1, pvec);

	// use backface culling
	if (det < EPSILON)
		return false;
	float inv_det = 1.0f / det;

	// calculate distance from vert0 to ray origin
	float3 tvec = ray.origin - vert0;

	// calculate U parameter and test bounds
	u = dot(tvec, pvec) * inv_det;
	if (u < 0.0 || u > 1.0f)
		return false;

	// prepare to test V parameter
	float3 qvec = cross(tvec, edge1);

	// calculate V parameter and test bounds
	v = dot(ray.direction, qvec) * inv_det;
	if (v < 0.0 || u + v > 1.0f)
		return false;

	uvHit = _M_UVs[offset] * u + _M_UVs[offset + 1] * v + _M_UVs[offset + 2] * (1 - u - v);
	//uv = new Vector(uvHit[0], uvHit[1], 0);

	// calculate t, ray intersects triangle
	t = dot(edge2, qvec) * inv_det;

	return true;
} 
```
Any ideas.
