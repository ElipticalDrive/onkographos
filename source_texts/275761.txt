# RayTracer-CUDA

A simple ray tracer built in C and accelerated using NVIDIA CUDA.

## Features

* CPU ray tracer written in C
* Sphere-ray intersection using quadratic equation solving
* Lambertian diffuse lighting
* Multiple spheres with independent colors
* Sky gradient background
* CUDA implementation using one GPU thread per pixel
* Performance benchmarking between CPU and GPU implementations

## Project Structure

```text
cpu/

```

## Rendering Pipeline

Pixel → Camera Ray → Sphere Intersection → Closest Hit → Lighting → Color

## Performance

Resolution: 800 × 600

| Implementation        | Time       |
| --------------------- | ---------- |
| CPU (Apple M2)        | 0.111329 s |
| GPU Kernel (Tesla T4) | 0.000236 s |
| GPU Total Pipeline    | 0.297059 s |

Kernel-level speedup: ~472×
