This change adds mesh completion mode B: hold two fixed TSDF moments separately and compose them with smooth-min (smin) before Marching Cubes. It enables organic neck-like fusion at the seam and blends A/B colors naturally in the composed region, with tunable k.
What this adds
TSDFView mesh-mode controls for two-volume composition:
meshUseSmoothUnion
meshSmoothUnionVolumeB
meshSmoothUnionK (meters)
Optional dual-volume path in MC dispatch; default behavior remains unchanged when smooth union is off.
Compute-side composition (before MC)
TSDFMarchingCubes.compute now accepts optional second SDF/color buffers.
Per-corner composition logic:
both corners valid: polynomial smooth-min + matched color blend
only one valid: pass-through that corner
MC then runs on the composed field.
Safety / fallback behavior
Smooth union is applied only when volume A/B grids are compatible (Dim + WorldFromVoxel).
On mismatch, extraction falls back to volume A and emits a warning.
```
float h = saturate(0.5 + 0.5 * (b.x - a.x) / k);
float s = lerp(b.x, a.x, h) - k * h * (1.0 - h); // smooth-min
float3 c = lerp(cb, ca, h);                       // seam color blend
```
