Introduces verifier/tetra_mesh.py as a deterministic TMP v1 geometry verification layer, and wires it to a frozen golden vector + CI matrix to prove hash stability across OS/Python combinations.
Core verifier (verifier/tetra_mesh.py)
Canonical JSON serialization (REPEAT C14N v1 — JCS/RFC 8785, consistent with existing verifier/__main__.py)
Signed volume computation: V = det(v2-v1, v3-v1, v4-v1) / 6
Cell invariants: structural validity, edge/face consistency, orientation, non-zero volume
verify_mesh() → TMP receipt (result: PASS|FAIL|ERROR, canonical_hash, errors[])
compute_mesh_hash() — timestamp-free, deterministic hash suitable for golden comparisons
Golden vector (tests/vectors/)
golden_tetra_mesh.json — canonical unit tetrahedron using integer coordinates (eliminates float representation divergence across platforms)
golden_tetra_mesh.sha256 — frozen digest (sha256:268994a1…); test failures signal unintended canonicalization drift
Tests (tests/)
test_golden_vector.py — digest format, hash-vs-frozen match, receipt field assertions
test_replay_golden_vector.py — determinism across repeated calls, mutation → hash change, coplanar mutation → FAIL
test_cli_golden_vector.py — subprocess integration: exit codes 0/1/2, --print-hash output
CLI (cli/verify_tetra_mesh.py)
```
python cli/verify_tetra_mesh.py tests/vectors/golden_tetra_mesh.json --print-hash
```

Frozen Digest File:

Golden Vector Tests:
tests/test_golden_vector.py

tests/test_replay_golden_vector.py
Replays the verification of a mesh and ensures it matches the stored receipt.
Hash Freezer Script:
scripts/freeze_golden_vector.py

Used for manual, controlled updates and not in CI automatically.
CLI Test:
tests/test_cli_golden_vector.py

Uses Python versions 3.11 and 3.12.
Includes a step to print the computed hash in CI logs for debugging mismatches.

Purpose
The Tetrahedral Mesh Protocol (TMP) defines a deterministic method for encoding, measuring, and verifying geometric state using tetrahedral meshes.
The protocol enables geometric substrates (Platoputer systems) to produce REPEAT-verifiable receipts by canonicalizing tetrahedral state and validating structural invariants.
The tetrahedron is chosen because it is the minimal rigid volumetric primitive in three-dimensional space. Complex geometries can be decomposed into tetrahedral meshes while preserving deterministic verification properties.
