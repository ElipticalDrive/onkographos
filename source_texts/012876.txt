Goal
Build a solid software 3D rendering foundation on top of the existing terminal renderer (src/renderer/, src/tui/) so that Aura can host first-person voxel experiences (Minecraft-like) entirely inside the TUI.
This is not a full game. It is the reusable rendering base:
Half-block pixel framebuffer
Camera + primary rays
Voxel volume storage
DDA raycaster
Basic shading / fog / sky
Tight integration with draw_batch / present_batch
Clean Aura-facing surface (primitives or stdlib)
Current foundation (already landed)
TermCell with Unicode + 24-bit RGB / 256-color
FramebufferSoA + FramebufferOwned
draw_batch / draw_cell + dirty region tracking
present_batch with zero-copy + synchronized output (CSI ?2026)
TUIRuntime double-buffer + headless mode
Half-block pixel counter already exists (g_tui_half_block_pixels)
Design principles
Stay on the terminal path — no GPU / OpenGL / Vulkan dependency for the base.
Pixel abstraction first — treat each terminal cell as two vertical pixels via ▀.
Hot path in C++ — DDA and framebuffer writes stay in the renderer engine; Aura drives camera, world, and game logic.
Measurable — every stage exposes counters (rays cast, hits, present bytes, frame time).
Headless-testable — all core algorithms must run without a real TTY.
Child issues (implementation order)
Half-block pixel framebuffer layer
Camera + primary ray generation
Voxel volume / chunk storage
DDA voxel raycaster core
Shading, distance fog, sky, basic materials
Frame loop integration with present_batch
Aura EDSL / primitive surface for 3D
Success criteria (Epic level)
Can render a first-person view of a small voxel scene at interactive rates in a modern terminal
All core pieces are unit-testable in headless mode
Clear separation: engine (C++) vs. game/agent logic (Aura)
Documentation + minimal demo (spinning camera over a few chunks)
Non-goals (this epic)
Full Minecraft game mechanics
Multiplayer / networking
GPU acceleration
Complex texture atlases or PBR
Entity animation system
References
Existing: src/renderer/render_primitives.hh, batch_terminal.hh, src/tui/tui_runtime.hh
Classic technique: DDA voxel traversal (Amanatides & Woo)
Display: Unicode half-block ▀ + truecolor
