First contact-time research for source-original DX2 collision geometry
Stacks on #45's independent full translating-capsule/Level triangle geometry oracle. Adds a numeric first-entry time bracket for a constant-orientation capsule against each original MOPP-linked nondegenerate Level triangle, plus the closest-point normal from the triangle to capsule axis when geometrically defined.
Golden-section search finds the convex segment-to-triangle distance minimum over t∈[0,1], followed by bisection to bracket first entry into distance <= capsule_radius + 1e-7 Level units, with <=1e-8 normalized time-parameter bracket width. Near-tangencies, numerical-only threshold contacts, initial overlaps and zero-separation unresolved normals are explicit. This is not an authenticated Havok time-of-impact, collision response or contact manifold.
New implementation
research/dx2/inspect_mopp_capsule_first_contact.py: source-Level independent closest-point features, per-triangle time bracket and normal estimate, original triangle IDs, and fail-closed comparison with PR Research: independent original-Level swept capsule geometry and MOPP candidate enclosure #45 full-sweep IDs.
research/dx2/audit_mopp_capsule_first_contact.py: strict owner-GMP source validation, seeded random/aimed source sweeps, old/new independent geometry ID comparison, both research MOPP candidate modes, exclusive sanitized JSON outside Maps. Original GMP/IBD never written.
20 new asset-free synthetic geometry regressions, plus 7 original Level fixture integration tests. Tests exercise analytical sphere and vertical capsule against floor, edge/corner/outward normals, initial penetrations, grazing, reversed winding, source ID gaps, deterministic input, intentionally bad synthetic MOPP spatial branch, and independent closest feature comparisons.
Documentation: docs/research/DX2_MOPP_CAPSULE_FIRST_CONTACT_TOI.md.
Read-only original 19-map evidence
The user's private original Seattle GMP corpus supplied 16 expanded-bounds random plus 16 randomized triangle-aimed capsule sweeps per map: 608 sweeps, with 1,028 original triangle-hit occurrences recovered by BOTH the old full-sweep geometry oracle and the new first-contact geometry solver, zero missing/extra source triangle IDs. 406 first normals were geometrically defined; 11 sweeps started within the contact threshold. Source map XYZ and original bytecode remain private and uncommitted. The private sampler uses full GMP-SHA seed mixing; committed CLI uses validated Level-SHA mixing so exact random sequences differ but distribution/verification is reproducible.
Local validation: all 27 new asset-free tests passed in the independent local source/fixture environment, including 400 random closest-feature distance comparisons to the prior scalar oracle; a separate 3,000-case random check also passed. Full GitHub Python/Godot CI pending. Keep draft until remote checks and Havok runtime research review; do NOT integrate into native collision writing or claim playable game collision.
