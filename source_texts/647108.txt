Owner
Turns the mask system from a curated dropdown into a full generative space. Every press produces a new deterministic SDF composition tree and a fresh set of effect knobs, all reproducible from a single `maskSeed`.
What it does
Randomises two things independently or together:
Axis
What varies
Shape
An SDF composition tree: random primitive leaf (from all 13 `SDF_SHAPES`) with a random modifier chain (rotate/translate/annular/warp/round), optionally combined with a sibling subtree via a weighted operator (smoothUnion / union / subtract / intersect variants). Recursion depth 2 by default.
Effect
`maskStrength`, `maskSoftness`, `maskScale`, `maskRotation`, `maskInvert`, `maskDeflect`, `maskSteer` — jittered inside curated envelopes that avoid the invisible/obliterated corners of the space.
How to use it
Interactive
Open the ★ Mask (SDF) folder in the GUI
Press Random shape, Random effect, or Random both
Or press Shift+M anywhere for random-both + immediate re-render
The `Last mask seed` field shows the seed used for the current roll (copy it to reproduce)
URL
`?maskSeed=N` triggers a random roll on load, deterministic per N
Combine with `?seed=N` to lock the flow field and vary only the mask
Batch harness
No changes needed. `P.maskSDF` and the effect knobs are already serialised in the manifest, so any random roll persisted via style-config.json is exactly reproducible.
Guarantees
Byte-identical when unused. The randomiser is only reachable via URL param, GUI button, or keybind. Default renders at any `seed=N` are unchanged.
Independent randomness. All mask-random calls flow through a local Mulberry32 PRNG. p5's global `random()` stream — consumed by the Poisson-disc pool, particle starts, and `mutate` — is never touched.
Fully serialisable. The synthesised SDF tree is plain JSON assignable to `P.maskSDF`; manifests capture it directly.
Verified
Three headless renders at `seed=42` with `maskSeed=null | 7 | 42` produced structurally distinct masks:
maskSeed=7 → `{shape: circle, r: 0.35}`, strength 0.48, hard clip
maskSeed=42 → `annular(union(warp(translate(...)), ...))`, strength 0.33, deflect 0.58
Same flow field in all three cases — only the mask changed.
Next candidates (not in this PR)
Mask contact sheet — batch harness flag `--maskSweep=` that renders one `activeSeed` with N random masks and lays them out on a contact sheet. Directly extends the "randomise the winners" theme.
Per-field masking — allow the same random mask to affect only the A field ("call") or only the B ("response"), so the two flows read as differently constrained bodies.
Curated bounds override — a `maskTaste` param that narrows the envelopes further (e.g. only smooth-unions, only warped shapes) once a preferred sub-region is identified.

- _randomMaskPrimitive: weighted picker over all 13 SDF_SHAPES with
  size envelopes tuned to canvas-normalised units
- _maybeWrap: probabilistic modifier chain (rotate 55%, translate 45%,
  annular 15%, warp 35%, round 20%)
- randomMaskSDF(rng, depth): recursive tree builder up to depth 2 with
  weighted operator picker (smoothUnion biased for organic feel)
- randomMaskEffect(rng): jitters effect knobs inside curated envelopes
  (avoids the invisible/obliterated corners of the space)
- GUI buttons in ★ Mask (SDF): Random shape / Random effect / Random both
- Keybind Shift+M → randomiseMaskBoth() + startRender()
- 'Last mask seed' display in GUI (listen()-bound for live updates)

Byte-identical guarantee: with no ?maskSeed and no button/keybind press,
the mask randomiser code is never reached. Existing seed=N renders are
unchanged.

random calls flow through the local PRNG; flow-field determinism is

This PR extends the existing SDF mask system from a preset-based selector into a deterministic generative mask space by adding a local PRNG-based “mask randomiser” that can synthesize new SDF trees and roll mask effect parameters from a single maskSeed (via URL, GUI, or keybind) without consuming p5’s seeded random() stream.
