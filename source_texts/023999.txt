Compression of Voxelized Vector Field Data by Boxes is Hard
Simon Zhang∗
arXiv:2510.20801v2 [cs.CC] 4 Nov 2025
Abstract
Voxelized vector field data consists of a vector field over a high dimensional lattice. The
lattice consists of integer coordinates called voxels. The voxelized vector field assigns a vector
at each voxel. This data type encompasses images, tensors, and voxel data.
Assume there is a nice energy function on the vector field. We consider the problem of lossy
compression of voxelized vector field data in Shannon’s rate-distortion framework. This means
the data is compressed and then decompressed up to an error bound on the energy distortion
at each voxel.
Our first result is that under certain conditions, lossy compression of voxelized vector fields is
undecidable to compute. This is caused by having an infinite number of Euclidean vectors. We
formulate this problem instead in terms of clustering the finite number of indices of a voxelized
vector field by boxes. We call this problem the (k, D)-RectLossyVVFCompression problem.
We show four main results about the (k, D)-RectLossyVVFCompression problem. The
first is that it is decidable. The second is that decompression for this problem is polynomial
time tractable. This means that the only obstruction to a tractable solution of the (k, D)RectLossyVVFCompression problem lies in the compression stage. This is shown by the
two hardness results about the compression stage. We show that the compression stage is
NP-Hard to compute exactly and that it is even APX-Hard to approximate for k, D ≥ 2.
Assuming P ̸= N P , this shows that when k, D ≥ 2 there can be no exact polynomial time
algorithm nor can there even be a PTAS approximation algorithm for the
(k, D)-RectLossyVVFCompression problem.

Introduction
In 1959 Shannon formulated rate-distortion theory [S+ 59]. In this theory we are given a domain
X equipped with a distortion function ρ : X × X → R≥0 . The distortion function on a pair
(x, y) ∈ X × X , denoted ρ(x, y), determines the cost of replacing an element x ∈ X with the
element y ∈ X . In rate-distortion theory the goal is lossy compression of a random variable
X to an estimated random variable X̂. The random variable X̂ is called the reconstruction and
differs from X up to a bound on its distortion. The reconstruction is still supported on the support
X . Shannon formulates this as minimizing the rate R, or bits of information per sample from X
needed for the reconstruction X̂ [Cov99]. A robust formulation for a sequence of random variables
is expressed by the following optimization problem. We call this the lossy indexed compression
problem (LossyIndexedCompression):

1.1
Voxelized Vector Field Data
The image compression problem was our original motivation for the lossy indexed compression
problem. We would like to formulate this problem in terms of an arbitrary indexed set of vectors.
We call an enumerable set of fixed-length real valued vectors that can be stored, retrieved and
managed a vector database. When this enumeration can be multi-indexed, its storage format
is a tensor data type, or multi-indexed array of real numbers. This data type includes traditional
images [ahm06], matrices [Str22], as well as voxel data [LH06, ZDL+ 20] etc.
When the index size scales, the compression problem is known to be hard for tensors. It is known
that compressing a sparse matrix is NP-Hard [GJ]. It is also known that compressing a 0-1 rectilinear polygon by rectangles is NP-Hard [GJ]. We would like to investigate the hardness of a closely
related compression problem involving multi-indexed vector databases.
In the following, we formulate a data type to represent multi-indexed vector database in the form
of a discretized vector field.
Let n ∈ N be the total number of vectors in a vector database X. As a vector database, each vector
in X can be enumerated as Xi ∈ RD , i ∈ [n] where D ∈ N is the length of each fixed-length vector.
This is called flat-indexing. We call the integer i the primary key in the flat-index for the vector
record Xi . The flat index up to set bijections is also called the support of X, denoted supp(X).
Throughout this exposition, we can assume that the numerical inputs r ∈ R to all algorithms are
from the rationals. These must have a finite bit string representation.
Let Bit(•) denote the map from a number to a single bit string representation. For a number r,
let size(r) denote the number of bits returned by Bit(r). We assume that rational numbers q < 1
have size(q) = Θ(log( 1q )) and that for all n ∈ N, size(n) = Θ(log(n)). These include delimiters to
denote the start and end of the numerical representation.

Remark 2. The lossy indexed compression problem is inherently a learning problem. This is
because the encoder-decoder pair can use the input data (X, f, ε) in the optimization problem.
A clustered indexed algorithmic compression scheme cannot learn over data. This means that the
program size of the compression and decompression algorithms C and D are O(1).
A sufficient condition for the no learning criterion is an asymmetric causal relationship from the
encoder to the decoder. A learnable encoder would then no longer be able to update its code over
samplings (x1 , ..., xn ) ∼ P (X1 , ..., Xn ) since it cannot check for index consistency from the decoder.

(k, D)-RectLossyVVFCompression is APX-Hard
In order to prove that the (k, D)-RectLossyVVFCompression problem is APX-Hard, we need
to find a PTAS reduction from an APX-Hard problem. A potential candidate problem is the
rectangle cover problem, also known as the “geometric set cover problem by rectangles” in the
computational geometry literature [HW86].
In the rectangle cover problem, the instances are range spaces, which are pairs consisting of a
set X and a collection of subsets of X. The range space for the rectangle cover problem is a set
of points on the plane and a collection of rectangles on the plane. The goal is to find the minimum
cardinality rectangle cover of the points. It is known to be APX-Hard [CG14].
In fact, this is APX-Hard even when the collection of rectangles on R2 only intersect either emptily
or at their boundaries at exactly 4 points. We call this problem the 2-DimSpecialBoxCover
problem. We would like, however, an even more simplified version of the problem to fully exploit
planarity.
We can start from a combinatorial set system problem, unrelated to geometry, known to be APXHard [CG14]. It is called the Special-3SC problem. It is a special case of the minimum vertex
cover problem on graphs of degree at most three and can be reduced from the minimum vertex cover
problem on degree 3 regular graphs (3VC). The 3VC problem is known to be APX-Hard [CG14].

Interval Tree Data Structure
An interval tree [Ede80] is a dynamic data structure that stores a collection of intervals on the real
line. It has three operations that can be performed on it. Let T denote an interval tree. The three
operations and their complexity are shown below:
1. (Insert): Insert(T , I) : I = [a, b], a, b ∈ R
(a) Adds an interval to the collection of intervals stored by T .
(b) This takes time O(log(n)).
2. (Delete): Delete(T , I) : I = [a, b], a, b ∈ R
(a) Delete an existing interval from T . If there is none, then do nothing.
(b) This takes time O(log(n)).
3. (Query) Query(T , I) : I = [a, b], a, b ∈ R
(a) Queries for all possible intervals in T intersecting with I an existing interval from T .
(b) This takes time O(log(n) + k) where k is the number of intervals returned by the query.
