Purpose
Two gaps stopped yapRover from building without OpenCASCADE. Both were found by building it with field primitives in place of the DSL's mesh ones:
fillet needed a BREP and OCC.
compound dropped its operands' SDF trees. Every later boolean against a compound then fell back to the mesh engine; one took 154 s against a 730k-triangle operand.
Changes
sdf.fillet(node, r) (new yapcad/sdf/fillet.py) rounds every edge.
It is exact for the analytic primitives: box → rounded_box, cylinder → the new exact rounded_cylinder primitive.
It works through similarity transforms (uniform scale divides the radius) and on each body of a compound.
Edgeless primitives are unchanged.
Both rounded primitives replay through OCC, so filleted parts still export analytic STEP.
sdf.fillet_solid re-meshes no coarser than its input and keeps a derived BREP when the tree still replays.
Refused with an explanation, not approximated:
combined fields (rounding operands would also round edges the boolean removes; this needs sampled-grid re-distancing);
non-uniform scales;
mesh-only solids.
The plan for these is in docs/SDF-DESIGN.md §10.5, including a prerequisite found while writing it: solid transforms leave a stale ['procedure', 'prism(...)'] record.
sdf.compound node.
As a field it is a union, so booleans combine it exactly like one.
to_solid meshes each body separately at the whole's cell size, pushing transforms down onto the bodies.
OCC replays it as a TopoDS_Compound.
DSL.
fillet takes the field path for SDF-authored solids, and its error for mesh-only solids now says what is supported.
compound keeps the fields when every operand is SDF-authored; mixed compounds are unchanged.
Results
yapRover built from field primitives with these builtins (still harness-assisted for primitive authoring and the bevel gear) matches the earlier fully harness-patched build in all 48 components:
chassis +0.002% against the exact BREP volume, wheel −0.05%, bogies exact, all closed;
the four rocker meshes are still open because they hit the 256 resolution cap, a separate issue.
Testing
New tests/test_sdf_fillet.py: 25 tests covering field exactness, analytic volumes, transforms, refusals, compound meshing, serialisation, booleans, OCC replay, and the DSL builtins with OCC disabled.
test_sdf.py gains samples for the new kinds, so the property tests cover them.
pytest in the OCC env: 1848 passed, 22 skipped. SDF tests on Python 3.14 without OCC: 322 passed, 81 skipped.
flake8 --select=E9,F63,F7,F82 src tests clean.
This is independent of #63.
