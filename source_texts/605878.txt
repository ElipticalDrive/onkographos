ABSTRACT
In the management of spatio-temporal data, a data
structure must manage multiple versions of a data structure eciently, and provide quick and exible search
methods not only for temporal or spatial queries, but
also for the combined queries of spatial and temporal
intervals. The persistent MD-tree, called the PMD-tree
is developed by extending a hierarchical data structure
to support accesses to multiple versions. The PMD-tree
has the novel properties that the tree representing any
time aspect of a data structure is always balanced, and
that the storage utilization rate is more than 66.6%.
The algorithms of the PMD-tree, space and time analyses, and search performances compared to the MD-tree
are described in the paper.
1 INTRODUCTION
The spatial data structures[1,4] become very important
in the elds of image processing, computer graphics,
CAD, GIS(Geographic Information Systems), and so
forth. Recently, several techniques [2,3] have been developed for managing not only the newest version of a
data set but also the old versions of the data. However,
these techniques have the disadvantage that search and
insertion performances vary depending on the insertion
order and the distributions of the data.
In the paper, a new spatio-temporal data structure,
called the PMD-tree, is described. The PMD-tree is developed by extending a balanced hierarchical data structure for multidimensional data, called the MD-tree[4],
to manage the spatial temporal data. In the PMD-tree,
even if data were deleted all data were not removed but
left in the structure. In other words, a PMD-tree holds
any versions of an MD-tree eciently. The structure inherits the novel features of the MD-tree that a tree corresponding to any time is balanced, and that the storage
utilization rate of the tree is higher than 66.6%.
2 THE PMD-TREE
The PMD-tree(Persistent MD-tree) is developed by
making the MD-tree persistent. Fig.1 shows a simple
PMD-tree which consists of two versions of an MD-tree
with two roots, R0, and R1. In the followings, the definition, structures, and algorithms of the PMD tree are
described.
2.1 De nition and structure of the PMD-tree
At rst, a brief introduction of an MD-tree data structure is descried. An MD-tree consists of two types of
nodes; leaf and internal node. Data are stored in only
leaves. Each node corresponds to a (hyper-) rectangular
region. The root corresponds to the entire data space.
A lower node corresponds to a sub-region of the parent
area. If a data of L is inserted into a full leaf L, the
corresponding region is split into two sub-regions such
that at least half of data in L are contained in each subregion. Then a new leaf corresponding to one of the
sub-regions is created and data in the sub-region are
moved from L to the new leaf. In the MD-tree, since
only the newest version is remained, we can not access
any older versions of the MD-tree.
On the other hand, as shown in Fig.1, a PMD-tree
manages multiple roots of the MD-tree. A PMD-tree
also consists of two types of node; leaf and (internal)
node. A node and a leaf have two states; live and dead.
A data has also two states; live and deleted (or dead).
A live interval of a data, leaf, or node is represented
by live time [T1, T2), where T1 indicates the time it
was created, and T2 (> T1) indicates the time it was
deleted. Each node has a time interval (life time) of
the node. A node with interval [T1,-) is still live and
is a node of the newest version of the structure. When
inserting data, if an internal node is split, or the area
corresponding to an internal node is modi ed, the node
becomes dead and a new node is created to manage the
children of the dead node.
2.1.1 Internal node and leaf
An internal node In has the following elds;
Node In = f Rect m, (Ts, Te), P array[4], L no,
O no, O p, Rect c g,
where Rect m is a rectangle which encloses all rectangles
of the lower nodes of In, (Ts, Te) is the live time interval
of In, P array[4] is an array of child pointers, L no is the
number of live child nodes, O no is the number of dead
child nodes, O p is a pointer to the old version node
of In, and Rect c is a circumscribed rectangle which
encloses all the data in the sub-tree rooted with In. If
Te of a node is '-', the node is live, and if Te has a
value, the node is dead. In Fig.1 dead nodes and leaves
are represented by black circles and boxes.
A leaf L has the following elds;
Leaf L = f Rect m, D[C], E no, D no, Rect c g,
where Rect m is a rectangle corresponding to leaf L,
D[C] is an array of pointers to the data, E no is the
number of live data, D no is the number of deleted data,
and Rect c is a circumscribed rectangle which encloses
all the data in L.
2.2 Construction of A PMD-tree
The data insertion is described referring a PMD-tree in
Fig.1. At rst, a data is inserted into an empty MDtree. When the rst data is inserted into an MD-tree at
time 0, a new root R0[0,-) and a leaf L0[0,-) in Fig.1
are created. The data is inserted into L0. R0 and L0
correspond to the entire data space. New data are also
inserted into L0 until the number of the data in L0 is
less than or equal to the capacity C. If a data is inserted into L0 with C data, L0 is split into two leaves,
L0[0,-) and L1[0,-), by the leaf splitting algorithm[4] of
the MD-tree. Then some data in L0 and the new data
are moved to L1 such that both leaves have more than
C/2 data each. L1 becomes a child of R0. If a data
is inserted to a full leaf with some siblings, the same
adjustment technique[4] as the B-tree is applied to the
MD-tree. In the PMD-tree, if the number of children
of a node exceeds the capacity, the node becomes the
dead node and two new nodes are created to manage
the children of the dead node.
To make the MD-tree persistent, the node and leaf
structures and the algorithms of the MD-tree are extended as follows in the PMD-tree.
(1) An internal node of an MD-tree can have at most
3 child nodes. In a PMD-tree, an internal node can
have at most 4 child nodes if at least one child is
dead.

2.2.1 Data insertion and node splitting
The following algorithm inserts a data in a PMD-tree.
Data insertion
(1) By tracing from the root of the newest version tree
to the lower nodes whose Rect m's include the centroid of a data, nd a leaf in which the data is
inserted. If the leaf is not full, the data is inserted.
(2) If the found leaf is full, the region of the leaf is split
and new leaves are created by the MD-tree's algorithm[4]. The data in the leaf are moved to the corresponding new leaves. When the parent, say Ip,
of the leaf becomes to have 4 leaves, Ip becomes a
dead node. And then two new nodes, which are new
children of the parent of Ip, are created to manage
two of four leaves each.
(3) If the number of the children of a node exceeds the
capacity by the splitting, the node becomes dead,
and new two nodes are created to manage the live
children of the node.
(4) (3) is recursively applied to the parent of the new
nodes. If the parent does not exist, a new root is
created to manage the new nodes.

2.3 Data search
The PMD-tree supports several types of data searches
such as range searches for the newest version or old versions of the tree, nearest neighbor searches, and range
searched for data which were inserted or deleted in an
interval [T1, T2). These spatial searches with time interval [T1, T2) can be performed by the following algorithm. Range search with time interval: searching data
which were live at some time in a given interval and were
included in a given range.
Let R be a range and [T1, T2) be a time interval.
(1) By tracing from a root whose interval includes T2,
to lower nodes, nd every leaf whose Rect c intersects with R.
(2) For every leaf found, check the leaf and old versions of the leaf whether their time intervals intersect with [T1, T2). If a leaf has non-empty intersection, collect data in the leaf whose Rect c's intersect
with R.

Data insertion cost consists of two parts; nding a leaf
in which a data should be inserted and reorganizing a
PMD-tree if necessary. Both costs are proportional to
the height of the newest version MD-tree in the PMDtree. Therefore the cost is O(log (N )), where N is the
total number of live data. The deletion cost is also proportional to the height of the newest version tree.
As for the time for searches in the PMD-tree, the
times for performing the range search for the live data
using the PMD-tree and using the MD-tree are the same
because live nodes in the PMD-tree construct the same
structure as the MD-tree. Thus the search cost for the
newest version data is O(log(N ) + F ), where N is the
number of live data and F is the number of found data.
A rectangular range search with time interval is performed by two steps as shown in 2.3. This process requires the time proportional to the height of the sub
PMD-tree whose root was live at that period and the
time proportional to the data found. That is, the time
for the range search with time interval is O(log (Lt)+ F ),
where Lt and F is the numbers of the leaves in the subPMD-tree and the data found, respectively.
