Closes #112. Closes #113. There is one commit per issue; the combinators reuse the Worley sampler as a base.
#112 Worley
API: worley2/worley3 return WorleySample<N> with:
f1 and f2, as Euclidean distances;
nearest, the offset to the nearest feature point;
feature_id: u64.
worley2_feature/worley3_feature expose one cell's feature point.
Feature points: one per lattice cell. Each comes from the shared Permutation and the cell coordinates, with no global RNG. The field repeats every 256 cells, like Perlin. Ties are broken by the smaller feature id.
Search: exact. It visits the 3^N neighbourhood first, then widens ring by ring while a nearer F2 is still possible. A plain 3×3 search is wrong at lattice corners. There is no heap allocation.
Tests:
A brute-force oracle re-derives every feature point and scans a 9^N neighbourhood, which is provably wide enough. Results match bit for bit across 8,000 2D and 1,800 3D generated samples, including negative, boundary and 1e12 coordinates.
An adversarial corner scan found 42 2D and 51 3D cases that need the ring widening, and all match the oracle.
Pinned fixtures and a zero-allocation test.
#113 Combinators
Samplers: generic Sampler2/Sampler3 traits, implemented for Fn closures, so there is no dyn in the hot loop.
Fractal::new(octaves, lacunarity, gain): normalized fBm, billow and ridged noise in 2D and 3D. Ridged has no octave feedback, which is documented.
It returns a typed CombinatorError for zero or more than 32 octaves, invalid lacunarity or gain, and an overflowing schedule.
DomainWarp::new(amplitude): 2D and 3D warps, with one offset sampler per axis.
Curl::new(epsilon): curl2 takes a scalar potential and curl3 a vector potential. Epsilon is explicit, and the code divides by the step that can actually be represented at the coordinate.
Tests:
The fractals match a plain powi loop oracle over Perlin, Simplex and Worley bases.
Warps equal the manual displacement exactly.
Curls match analytic potentials to second order.
Curl fields of noise potentials have divergence ≤ 1e-9; a gradient control field exceeds 1.
Zero allocations.
.performance/contract.json gets zero-allocation entries for both, matching the existing Simplex entry.
Bench (Divan, shared 4-core VM, advisory)

to the nearest feature point and a stable feature id. Feature points are
derived from the shared seeded Permutation (one per cell, no global RNG);
ids are distinct per 256-cell period. The search visits the 3^N

generated fixtures and an adversarial lattice-corner scan that needs ring
expansion, pinned fixtures, allocation regression, Divan benches for

Add Sampler2/Sampler3 (blanket-implemented for Fn closures) so base
fields are monomorphised into combinator loops without dyn dispatch.

returns typed CombinatorError for zero or too many octaves, invalid
lacunarity/gain and overflowing schedules; it provides normalised 2D/3D
fBm, billow and feedback-free ridged sums. DomainWarp displaces 2D/3D
coordinates by per-axis offset samplers with a validated amplitude. Curl
builds 2D scalar-potential and 3D vector-potential curl fields with an
explicit central-difference epsilon, dividing by the represented step.

Evidence: powi loop oracles over Perlin/Simplex/Worley bases, warp
determinism and manual-displacement equality, analytic curl potentials,
numerical divergence-free checks with a gradient control, allocation
regression, Divan benches over octave counts and point batches,
verification-matrix fragment and an allocation contract entry.
