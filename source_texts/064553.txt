In this thesis, we focus on the development of object-based techniques for image reconstruction and segmentation. The main approach explored in this thesis is based on geometric boundary parameterizations using curve and surface evolution techniques. 
The first problem we address is the development of a theory for geometric parameterization and subsequent image formation for tomographic problems using curve evolution techniques. We formulate the image formation problem as an optimization problem in determining multiple object and background regions, each characterized by unknown structured intensity profiles. Our results provide curve evolution techniques for generating images which combine the theory of curve evolution used in segmentation with optimization techniques for inverse problems. We have extended the theory to deal with unknown numbers of regions, each with different internal intensity structure. The resulting algorithms are computationally efficient and robust to limited and/or poor data situations. We also extend the 2-D curve evolution image reconstruction techniques to 3-D and derive surface evolution equations for solving 3-D tomographic inverse problems. 
A special case of the above theory is when the tomographic operator is an identity operator, so the data collected is related to individual pixel intensities. In this case, the object-based image reconstruction problem simplifies to a segmentation problem. We develop a new adaptive curve evolution algorithm for image segmentation, which can use a single curve evolution to segment images with multiple regions with independent intensities. This algorithm adaptively estimates the local mean intensity for each connected region enclose by a curve segment inside the image domain and develop gradient flows for curve evolution using these adaptive mean intensity estimates. The resulting algorithm can handle images with multiple intensity levels and multiple non-overlapping regions, without solving a full segmentation/estimation problem as is done in previous work by Mumford and Shah. We also extend the segmentation approach to obtain a hybrid curve evolution approach for image segmentation, to be used in segmentation of images collected by laser radar (ladar). This hybrid approach allows the combination of the parametric and non-parametric representations for efficiently handling background and target regions based on different underlying intensity properties. 
As an application, we focus on the problem of underground imaging using ground penetrating radar and inverse scattering. (Abstract shortened by UMI.)
