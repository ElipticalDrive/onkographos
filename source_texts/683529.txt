Summary
New package @frapx/glsl-sdf (planned 0.1.0): 2D/3D signed distance primitives, hard/smooth booleans, and domain ops (rotate, repeat, limited repeat, twist, bend), all frapx_-prefixed.
Five disjoint groups (sdf2d, sdf3d, sdfOps, sdfDomain, sdf) with no duplicate signatures, so any combination concatenates into one shader. GLSL ES 1.00 and 3.00 compatible.
examples/vite-sdf (2D distance field + 3D raymarch), docs site page, README/AGENTS/RELEASING updates.
MIT LICENSE in the repo root and every published package, enforced by pnpm check:licenses in CI and before publishing. Distance functions attribute Inigo Quilez's MIT-licensed Shadertoy sources.
Pages workflow also redeploys when packages/glsl-sdf changes.
Test plan
pnpm typecheck / pnpm build / pnpm test locally
pnpm test:e2e locally: GPU evaluation of ~75 analytic cases in an RGBA32F target (ES 1.00 and 3.00), WebGL1 compile of each group
Same e2e under SwiftShader (--use-angle=swiftshader): EXT_color_buffer_float is available and all cases pass
examples/vite-sdf checked in a real browser at 1440px and 390px
CI
Merging this and #2 (M1+M2) in either order conflicts in AGENTS.md, README.md and three CHANGELOGs (text only); the resolution is verified locally.
No version bump or publish in this PR.
