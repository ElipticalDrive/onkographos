```
Replaces the single-Scene design with a multi-layer pipeline:

  WORLD layers → worldFBO → PostProcessChain → screen
  SCREEN layers → drawn directly on top

  RenderTarget / Framebuffer / ScreenTarget  — GL render target abstractions
  Layer / BaseLayer                          — replaces Scene interface

    GL resources lazily initialized on first renderFrame()

existing start(Scene) / testscene path is unchanged for backward compatibility.
```

Add SkyLayer + GodRaysPass: procedural sky with god ray post-processing
…
8933f18
```
SkyLayer (WORLD, order 0):
- Fullscreen quad drawn at max depth with depth writes off — always
  behind scene geometry without interfering with the depth buffer.
- Fragment shader reconstructs per-pixel world ray direction via
  inverse view rotation (transpose of the rotation matrix) and
  inverse projection (1/P.m00, 1/P.m11 focal reciprocals).
- timeOfDay-driven sky gradient (night → dawn → noon → dusk palette),
  sun disc and soft halo that track the sun's world-space direction.
- Computes sun screen-space UV each frame and writes to GameState
  (sunScreenX, sunScreenY, sunIntensity) for GodRaysPass.

GodRaysPass (PostProcessPass):
- Crytek light-shaft technique (GPU Gems 3 §13): 64-sample radial
  blur from each pixel toward the sun's screen UV, accumulating
  scattered light with exponential decay (DECAY=0.97).
- Additively blended on top of the scene colour — no separate FBO
  needed for the radial contribution.
- Automatically registered into the PostProcessChain by SkyLayer's
  first render() call (lazy GL init pattern).

GameState: added sunScreenX, sunScreenY, sunIntensity fields.

Main: wired in GameState + SkyLayer; state.timeOfDay = 0.45 (just
before noon) for a strong sun angle and visible god rays on launch.
```
