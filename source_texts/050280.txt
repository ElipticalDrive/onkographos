Enhanced the cloud rendering layer by introducing a 128x128x128 3D volume texture to break up linear cloud structures, integrating local ambient occlusion and albedo parameters, optimizing the raymarching cadence with a density-dependent step size strategy, and generating full mipmaps for the 2D weather map with dynamic LOD sampling to preserve space skipping while removing the old history-based cadence.

…ce, and weather map mipmaps

- Added a GL_RGBA16F 3D cloud volume texture of dimensions 128*128*128.
- Baked tiling 3D noise (R), local upward-facing AO (G), and high-frequency albedo (B) once using the new cloud_3d_volume_bake compute shader.
- Integrated the 3D volume with the existing clouds.glsl density system using 0.75x slower advection.
- Generalised calculateCloudDensity signature to return a CloudDensityResult struct propagating density, advection, AO, and albedo.
- Implemented density-dependent variable raymarching step size cadence (finer on wisps, larger on empty space, largest in dense cores) using actual step size for Beer's law integration.
- Enabled weather map mipmap generation (GL_LINEAR_MIPMAP_LINEAR) and dynamic distance-based LOD texture sampling to preserve space skipping.
- Removed the old history-based ray marching start/end cadence.
- Fully validated all shaders and passed all 29 unit tests.
