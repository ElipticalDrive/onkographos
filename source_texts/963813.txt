# Solar System Ray Tracer

This project implements a ray tracer that renders a realistic scene of the Solar System at a given simulation time, from a specified camera position, orientation, and up vector.

## Features

- Ray-sphere intersection for planets, moon, and sun
- Object transformations (orbital and rotational positions)
- Surface textures for planets and moon
- Sun as emissive light source
- Global illumination and shading (ambient, diffuse, and specular lighting)
- JSON configuration for scene setup

## Project Structure

- `src/`: Source code directory
  - `vector.py`: Vector math utilities
  - `ray.py`: Ray class for ray tracing
  - `camera.py`: Camera setup
  - `objects.py`: Geometric objects like spheres
  - `materials.py`: Material properties and textures
  - `orbital.py`: Orbital mechanics calculations
  - `scene.py`: Scene management
  - `main.py`: Main entry point
- `textures/`: Directory for planet and celestial body textures
- `output/`: Directory for rendered images
- `scene_config.json`: Configuration file for simulation settings
- `run.py`: Simple script to run the ray tracer

## Requirements

- Python 3.6+
- NumPy
- Pillow (PIL)

Install requirements:

```bash
pip install -r requirements.txt
```

## Usage

1. Place planet textures in the `textures/` directory (optional)
2. Modify `scene_config.json` to set simulation time and camera parameters
3. Run the ray tracer:

```bash
python run.py
```

## Configuration

The `scene_config.json` file allows you to configure:

- `time`: Simulation time in seconds
- `camera`:
  - `position`: Camera position [x, y, z]
  - `look_at`: Point the camera is looking at [x, y, z]
  - `up`: Camera up vector [x, y, z]

Example configuration:

```json
{
    "time": 86400,
    "camera": {
        "position": [0.0, 15.0, 50.0],
        "look_at": [0.0, 0.0, 0.0],
        "up": [0.0, 1.0, 0.0]
    }
}
```

## Rendering Settings

You can adjust rendering settings in `src/main.py`:

- Image dimensions
- Samples per pixel (higher = better quality but slower)
- Maximum ray depth (higher = more accurate light bounces but slower)

## Getting Planet Textures

You can download realistic planet textures from:
- NASA's Solar System Exploration: https://solarsystem.nasa.gov/
- Solar System Scope: https://www.solarsystemscope.com/textures/
- Planetary Texture Maps: https://planetpixelemporium.com/planets.html

Recommended texture filenames:
- `sun.jpg`
- `mercury.jpg`
- `venus.jpg`
- `earth.jpg`
- `mars.jpg`
- `jupiter.jpg`
- `saturn.jpg`
- `uranus.jpg`
- `neptune.jpg`
- `moon.jpg`
