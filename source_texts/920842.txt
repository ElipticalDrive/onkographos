# Viettel AI Race 2026 - 3D Gaussian Splatting Pipeline

A lightweight release of my solution pipeline for Viettel AI Race 2026,
Problem 1: BTS Digital Twin.

The project trains a separate 3D Gaussian Splatting (3DGS) model for each
scene, evaluates candidate configurations on leakage-free holdout views,
renders the requested camera poses, and validates the final submission before
packaging.

## What is included

- dataset and camera-pose inspection;
- COLMAP camera conversion and radial-distortion handling;
- deterministic holdout construction for profile selection;
- per-scene 3DGS training orchestration and checkpoint resume checks;
- target-pose rendering;
- PSNR, SSIM, LPIPS, and official-score evaluation;
- submission dimension/name validation and size-aware packaging;
- unit tests for pose conversion, scene preparation, training resume, and
  submission packaging.

Large or competition-specific artifacts are excluded: the dataset, model
checkpoints, rendered images, submission ZIP files, cloud-sync scripts, and
machine-specific paths.

## Pipeline

```text
competition dataset
       |
       v
inspect + prepare COLMAP scenes
       |
       v
build deterministic holdout views
       |
       v
train candidate 3DGS profiles per scene
       |
       v
evaluate PSNR / SSIM / LPIPS and select profile
       |
       v
retrain on all valid views and render test poses
       |
       v
validate filenames + dimensions -> package ZIP
```

## Requirements

- Python 3.10+
- CUDA-capable PyTorch for training/evaluation
- the official
  [graphdeco-inria/gaussian-splatting](https://github.com/graphdeco-inria/gaussian-splatting)
  repository at the commit recorded in `configs/default.yaml`

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements-gpu.txt
```

Install a PyTorch build that matches your CUDA environment before installing
the GPU requirements.

## Typical workflow

Inspect and prepare scenes:

```bash
python scripts/inspect_dataset.py --dataset-root /path/to/dataset
python scripts/prepare_scenes.py \
  --dataset-root /path/to/dataset \
  --output-root work/prepared \
  --undistort-radial
python scripts/make_holdout_data.py \
  --prepared-root work/prepared \
  --output-root work/holdout
```

After training and rendering, validate and package the output:

```bash
python scripts/validate_submission.py \
  --dataset-root /path/to/dataset \
  --submission-root work/submission
python scripts/package_submission.py \
  --dataset-root /path/to/dataset \
  --submission-root work/submission \
  --output submission.zip
```

Run the CPU-safe test suite:

```bash
pytest -q
```

The competition dataset is not redistributed. Use the files supplied through
the official competition channel and follow the organizer's rules.
