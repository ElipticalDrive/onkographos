API
Expose the denoised & upscaled texture as a target rather than just rasterizing. Possibly enough to just use a "render to target"? Assuming it doesn't result in unnecessary copies or textures
Add more custom, user-defineable hooks for materials, tracing, light sampling
Diagnostics call: one function returning kernel compile times, BVH stats ( node count, depth, memory ), the GPU frame time and frame budget, the ray pool size, memory per target and buffer ( output, sample counts, aux, ray data, texture atlas ), and scene counts ( meshes, triangles, materials, lights, textures ).
User seed: let the user set the global random seed ( WebGPUPathTracer: Add a global random seed #925 ) so animations can give each frame its own repeatable noise.
Bugs
The texture info table goes stale when textures are added after the kernels compile: updateMaterials repacks the atlas, but the uniformArray length is fixed at compile time. Move it to a storage buffer or recompile when it grows.
No NaN / inf guard before a sample is accumulated, so one bad sample stays in the pixel's average.
Thin-wall surfaces follow the material side, so a front-side-only pane disappears from behind.
Accumulation averages color weighted by alpha rather than premultiplied, so edges over a transparent background speckle after denoising.
Textures
Textures are always read at mip 0, causing aliasing on minified textures. Revisit with bindless / hardware sampling.
Texture atlas size budget: cap the atlas memory and downscale textures automatically past it, reporting when it happens. Matters on mobile.
Performance
resetSlotsKernel and copyRayDataKernel aren't in the async compile list, so they compile synchronously on first use.
The BVH traversal stack is a fixed 60 deep and overflow silently drops geometry (three-mesh-bvh).
Denoising
Progressive denoising: the denoiser only runs once the render settles. Options: run OIDN on the fly ( a small model, or at sample milestones like 1, 4, 8, 16 ), a weightless joint non-local means ( JNLM ) filter guided by albedo, normal and variance, or SVGF ( SVGF Denoiser implementation #292, SVGF Implementation Discussion #511 ).
