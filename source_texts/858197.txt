Implements an optimized branchless Ray-AABB intersection algorithm on flat Float32Array buffers using the Slab Method, following TDD (spec written first).
Algorithm (packages/core/src/ray.ts)
Replaced the per-axis if (dx !== 0) … else if (outside slab) return -1 branch structure with a fully branchless formulation. Zero direction components naturally yield ±Infinity via 1/0, which propagates correctly through Math.min/Math.max without explicit guards:
```
const idx = 1 / dx;  // ±Infinity when dx === 0
const t1x = (minX - ox) * idx;
const t2x = (maxX - ox) * idx;
// … same for y, z

const tmin = Math.max(Math.min(t1x, t2x), Math.min(t1y, t2y), Math.min(t1z, t2z));
const tmax = Math.min(Math.max(t1x, t2x), Math.max(t1y, t2y), Math.max(t1z, t2z));

if (tmax < 0 || !(tmin <= tmax)) return -1;  // !(<=) catches NaN (0×∞ edge case)
return tmin >= 0 ? tmin : tmax;
```
The guard uses !(tmin <= tmax) rather than tmin > tmax to handle the degenerate 0 × ∞ = NaN case (origin exactly on an AABB face with a zero direction component), which a plain > comparison silently misses.
Spec (packages/core/tests/ray.test.ts)
Expanded from 4 basic smoke tests to 14 targeted cases with exact toBeCloseTo distance assertions:
Axis-aligned hits: +X / +Y / +Z with exact entry distance
Negative direction: exact entry distance from far side
Diagonal rays: YZ-plane (dx=0) and full 3D, with analytically computed expected t
Misses: lateral offset, pointing away, parallel-outside-slab, diagonal near-miss
Inside-box origin: asserts exact exit distance (0.5), not just >= 0
Buffer offsets: non-zero ray offset and non-zero AABB offset in the flat array
Asymmetric boxes: non-unit box with known exact entry distance
