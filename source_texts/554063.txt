On this page
Look inside a part during review
A surface view can hide details captured in a volume scan. Volume Rendering brings voxel data into a 3D inspection experience, helping users explore internal regions and understand where they sit in a part.
Use it in industrial CT software, non-destructive inspection tools, and material or geological research applications.
How it works
Load a voxel dataset and choose how density values should appear. Add sections or clipping to expose a region, then let users explore it alongside reference geometry. Adjust detail and data loading for your dataset and hardware so review stays responsive.
Show the region a user needs to inspect
Place sections at chosen orientations, combine clipping planes, and adjust how density values appear. Users can isolate an area, inspect a slice, or explore a wider volume.
Synchronized views help keep a local detail connected with its position in the overall dataset.
Bring scans and reference geometry together
Display volume data alongside CAD-derived or textured mesh models. This supports visual comparison and helps users understand scan information in an engineering context.
GPU rendering, levels of detail, and out-of-core data handling support larger datasets. Choose a setup around your dataset size, graphics hardware, and expected interaction speed.
Work with scans larger than graphics memory
Industrial computed tomography (CT) can produce very large datasets. Levels of detail and out-of-core handling load data for the current view within available memory. Users can explore a scan larger than graphics memory.
GPU rendering supports changes to sections, density display, and viewing position. Dataset size and workstation hardware still affect response time, so viewing settings should suit the equipment used by inspection teams.
Share an internal finding with production teams
A quality engineer may see a suspicious region in a CT scan, while production staff only know the outside of the part. A single unmarked slice can be hard to locate and discuss. Volume viewing helps place the observation inside a recognizable 3D shape.
An inspection application can combine sections, clipping, density display, and reference geometry to show the region clearly. It can save relevant viewing settings with an inspection record so another reviewer can return to the same area. Teams can discuss the observation in context and decide which further analysis is needed.
This supports communication between inspection, manufacturing, and suppliers. Your application manages reports and follow-up actions, while dedicated analysis procedures provide any measurements or defect decisions. Keeping the visual finding and later analysis together makes it easier to explain why a part needs additional investigation.
Build a wider inspection tool
Connect rendering with your analysis tools for tasks such as cavity review, object separation, or defect classification. These processing features can be added as application features around the viewer.
