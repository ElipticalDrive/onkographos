Context
Phase 1.D's production rasterizer uses compute culling + indirect draw against a vertex pull setup (vs_vbuf_scene). That works on every wgpu adapter but leaves performance on the table where mesh shaders are available: the meshlet model maps directly onto NV/AMD/Intel mesh-shader pipelines and a single dispatchMesh call replaces the cull dispatch + indirect draw chain.
This issue adds a feature-gated mesh-shader rasterizer alongside the existing compute+indirect path. Compute path stays the production default; mesh shaders are opt-in via wgpu::Features::EXPERIMENTAL_MESH_SHADER (or whichever flag wgpu exposes by then).
Scope
Pipeline detection:
GpuContext::new requests Features::EXPERIMENTAL_MESH_SHADER opportunistically.
A new MeshShaderSupport: Resource exposes is_supported() -> bool that downstream stages check.
MeshletMeshShaderRasterizer:
Mesh shader (ms_meshlet) emits one workgroup per surviving meshlet. Reads the same MeshletDescriptor storage buffer + the cull-output visible_meshlets array.
Task shader (ts_cull) replaces the standalone cull compute pass when mesh shaders are live: per-task-thread frustum + backface + Hi-Z, falls through to EmitMeshTasks(visible_count).
Fragment shader unchanged — same visibility-buffer write the compute path produces.
MeshletRenderStage toggle:
Detection at startup picks MeshletVisRasterizer (compute+indirect) or MeshletMeshShaderRasterizer (mesh shaders). The user does not opt in by hand.
Snapshot test: same scene, both paths, identical visibility buffer (within float epsilon on the world-space normal pack).
DOD / ECS / GPU-Driven alignment
DOD: shaders read the same MeshletDescriptor POD. No data layout change.
GPU-Driven: mesh-shader path collapses cull + raster into one pipeline submission. Single dispatch on the GPU side.
ECS: zero changes.
Acceptance
On a mesh-shader-capable GPU (RX 9070 XT in dev): runtime selects the mesh-shader path.
On adapters without the feature: runtime falls back to compute+indirect, no panic.
Visibility buffer of the bench scene is byte-identical between paths (or within a documented float-epsilon tolerance for the encoded normal).
Bench frame time on the same scene drops by >20% with mesh shaders enabled (RX 9070 XT).
Refs Phase 1.D.7 follow-up listed in #117.
