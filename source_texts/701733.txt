Adds a transform area to the Illustrator server and extends align_items.
New tools (packages/illustrator/src/tools/transform.js)
transform_each: Object > Transform > Transform Each through the object model. Scales, moves, rotates and flips each item around its own reference point. It can apply random amounts, make copies, and transform the object, its pattern fills, or both. Scale Strokes and Scale Corners are optional.
shear_items: shears along a horizontal, vertical or angled axis with PageItem.transform and an app.getIdentityMatrix() matrix.
apply_matrix: applies an affine matrix given in artboard terms (y down) around a reference point.
repeat_transform: Object > Transform > Transform Again (transformagain), repeated a given number of times.
resize_items: sets width and height (Transform panel W/H), as absolute or relative values. It supports constrained proportions, a reference point, Use Preview Bounds, Scale Strokes and Scale Corners.
get_bounds: reports geometric, visible and control bounds in artboard points.
nudge_items: moves items the way the arrow keys do, by the Keyboard Increment preference, with an option for 10x (Shift).
set_transform_options: sets the Transform panel reference point (plugin/Transform/AnchorPoint), Scale Corners (policyForPreservingCorners) and Show/Hide Bounding Box. It reports the related preferences too.
reset_bounding_box: Object > Transform > Reset Bounding Box.
distribute_items: distributes by left, centre or right edges, by top, centre or bottom edges, or by equal horizontal or vertical space. It can also space items an exact distance apart from a key object.
make_envelope: Object > Envelope Distort > Make with Top Object.
edit_envelope: Envelope Distort > Release, Expand, and Edit Contents.
expand_objects_on_path: Object > Objects on Path > Expand.
distort_items: free or perspective distort of the bounding-box corners, applied as the Free Distort effect and expanded by default.
Changed
align_items: adds to: key_object with keyObjectId, a center_middle edge (horizontal and vertical centre in one step), and usePreviewBounds.
set_path_options: now also claims Transform panel > Align to Pixel Grid, which it already sets.
Preference keys and the Free Distort parameters follow published scripts. They are cited in the module comment: creold/illustrator-scripts ResizeToSize.jsx, Rescale.jsx and SelectPointsByType.jsx, and swwwitch/illustrator-scripts SmartFreeDistort.jsx.
Not scriptable
These are recorded for the atlas because their only command opens a dialog or needs clicks:
Make with Warp, Make with Mesh, Envelope Options and its five settings
Objects on Path > Attach and Options
