Abstract
As an alternative method to optical endoscopy, visual quality and interactivity are crucial for virtual endoscopy. One solution is to use the 3D texture map based volume rendering method that offers high rendering speed without reducing visual quality. However, it is difficult to apply the method to virtual endoscopy. First, 3D texture mapping requires a high-end graphic workstation. Second, texture memory limits reduce the frame-rate. Third, lack of shading reduces visual quality significantly. As 3D texture mapping has become available on personal computers recently, we developed an interactive navigation system using 3D texture mapping on a personal computer. We divided the volume data into small cubes and tested whether the cubes had meaningful data. Only the cubes that passed the test were loaded into the texture memory and rendered. With the amount of data to be rendered minimized, rendering speed increased remarkably. We also improved visual quality by implementing full Phong shading based on the iso-surface shading method without sacrificing interactivity. With the developed navigation system, 256×256×256 sized brain MRA data was interactively explored with good image quality.
Introduction
The most effective way to diagnose diseases is to see the affected regions directly. But this is very difficult or even impossible with optical endoscopy in the distal regions of tubular organs and the vascular system. Virtual endoscopy using 3D visualization techniques [1] provides many advantages over conventional endoscopy systems. Using virtual endoscopy, it is possible to observe organs that cannot be seen with conventional endoscopy systems such as brain vascular channels. There is no pain for the patients and the risk of infection caused by camera insertion is eliminated [2]. The most desired thing to the virtual endoscopy as an alternative method to conventional endoscopy is visual quality and interactivity [3]. To implement interactive navigation, surface rendering methods are typically used. Because surface rendering uses intermediate polygonal representations of the iso-surface to construct scenes, it is not accurate enough for clinical examinations [4]. For better image quality, volume rendering methods have been used [3], [5]. But, volume rendering methods still take a very long time to render scenes even when acceleration algorithms are used. One solution for real-time volume rendering is to use hardware acceleration such as the OpenGL 3D texture map based volume rendering method. It offers significantly faster rendering speed as well as good image quality [4], [6], [7]. But, it can not replace conventional endoscopy because of several problems. First, 3D texture mapping is hard to use in a clinical setting. Because, it requires a high-end graphic workstation such as an SGI Onyx machine that supports OpenGL 3D texture services. Second, memory swapping caused by texture memory limits of the graphics board reduces the frame-rate. Third, the lack of shading reduces visual quality significantly [3]. The purpose of this paper is to solve these problems and implement a high-quality and interactive virtual endoscopy system using the 3D texture map based volume rendering method.

3D texture map based volume rendering
3D texture map based volume rendering is one of the direct volume visualization methods. The basic concept of the method is to define a 3D texture and render it by mapping it to a stack of polygon slices. The polygon slices are blended and the results rendered in the scene [6], [8]. The method produces interactivity as well as high visual quality when used with OpenGL hardware acceleration. The 3D texture services included in OpenGL 1.2 are only supported by a few high-end graphic workstations
