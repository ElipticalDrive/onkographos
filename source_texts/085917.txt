Summary
Implement the first VAFT-native learned inverse model for offline rotational soft-X-ray (SXR) tomography of magnetic-island structure, using PyTorch and the common ML lifecycle from #669.
This issue does not aim to reproduce the historical TensorFlow/Keras implementation numerically. Instead, it preserves the original scientific intent and macro-architecture while moving directly to a revised first VAFT model:
```
vest_sxr_mi_reconstruction_vaft_v0
```
The intended end-to-end lifecycle is:
```
VAFT equilibrium
        ↓
equilibrium-aware MI phantom / emissivity model (#886)
        ↓
SXR forward projection
        ↓
SyntheticDatasetArtifact
        ↓
case-level train / validation / test split
        ↓
PyTorch SXR reconstruction transformer
        ↓
physics-consistent validation
        ↓
ModelArtifact
        ↓
vaft-nn
        ↓
canonical experimental soft_x_rays ODS
        ↓
offline MI reconstruction
```
The model should remain a rotational-tomography model, not a generic image-to-image network: the temporal axis of the SXR sinogram represents additional projection information generated by a rotating magnetic island.
Architecture refresh from #669
This learned inverse model should use #669 as the canonical ML lifecycle rather than defining a parallel validation/artifact architecture.
Ownership is:
```
SXR / tomography domain APIs
    physical input/target semantics
    synthetic forward model coupling
    reconstruction-result meaning

vaft.process.ml
    reusable training/inference computation

vaft.validation.ml / domain validation
    synthetic holdout assessment
    experiment-domain assessment
    OOD / applicability
    robustness
    physics/LOS consistency interpretation

vaft-nn
    immutable validated artifact distribution
```
The synthetic target lineage must remain explicit: a network trained on #886 phantoms learns that synthetic target distribution, not experimental truth directly.
Therefore separately assess:
```
synthetic holdout fidelity
synthetic -> experiment domain shift
forward/LOS consistency
independent MHD/equilibrium evidence
```
and do not collapse these into one reconstruction score.
Perturbation robustness to noise, missing channels, gain/baseline changes, timing shifts, or equilibrium variation should reuse #1642 where implemented. Training-domain applicability should compose with #1628/#669.
Scientific intent
The original VEST study introduced deep-learning reconstruction because the sparse SXR LOS geometry alone is insufficient for direct 2-D reconstruction of a dynamically rotating magnetic island.
The intended measurement principle is:
```
limited poloidal LOS coverage
        +
magnetic-island rotation
        ↓
time-dependent SXR pattern
        ↓
rotational sinogram
        ↓
2-D MI reconstruction
```
The model should primarily recover quantities that materially affect the SXR pattern, such as:
```
poloidal mode number m
rational-surface localization
rational-surface radius / gross scale
coarse MI morphology
```
It should not pretend to infer quantities that are poorly identifiable from the available SXR geometry alone.
In particular, the original parameter study showed a degeneracy between toroidal mode number and temporal repetition in a single poloidal SXR view. Therefore, n should not initially be treated as a free SXR-only reconstruction target.
Likewise, weakly observable equilibrium-shaping parameters should preferably come from an equilibrium or remain fixed/conditioned rather than being hallucinated by the learned inverse model.
1. Go directly to a PyTorch VAFT v0
Do not add TensorFlow as a supported VAFT ML backend solely to reproduce the historical notebook.
The historical implementation remains useful as:
a scientific-intent reference;
an architecture-family reference;
a reference for synthetic-data augmentation ideas;
a reference experimental application.
The first maintained VAFT model should be PyTorch:
```
SXRReconstructionTransformer
```
with release/model identity such as:
```
vest_sxr_mi_reconstruction_vaft_v0
```
2. Preserve the macro-architecture, not historical implementation accidents
Keep the original architecture family:
```
rotational SXR sinogram
        ↓
patch / token embedding
        ↓
local Conv1D feature extraction
        ↓
Transformer encoder
        ↓
spatial reconstruction decoder
        ↓
2-D tomogram
```
The intended responsibilities are:
```
local channel/time structure
    → convolution

long-range channel/time relationships
    → self-attention

inverse spatial reconstruction
    → reconstruction decoder
```
Historical TensorFlow-specific details, notebook-global dimensions, local paths, and accidental implementation constraints should not be preserved.
All input/output dimensions and hyperparameters must be explicit in a model specification.
Example:
```
SXRReconstructionModelSpec(
    input_arrays=("vertical", "horizontal"),
    temporal_samples=...,
    patch_size=...,
    embedding_dim=...,
    conv_channels=...,
    n_heads=...,
    n_layers=...,
    output_grid=(nz, nr),
)
```
3. Offline reconstruction semantics
This model is explicitly an offline spatial reconstruction model.
It does not need to satisfy a real-time causal inference constraint.
A reconstruction may therefore use rotational context around the target state. However, temporal alignment remains part of the model definition and must be explicit.
For example:
```
TemporalContextSpec(
    mode="offline",
    alignment="centered",
    duration=...,
)
```
or another documented alignment selected during validation.
The model should be invariant, as far as practical, to arbitrary absolute rotation phase / time-window origin while preserving the physically meaningful rotational morphology.
4. Use #886 as the source of synthetic MI physics
Do not reintroduce the old standalone geometric phantom generator inside this ML issue.
#886 — Add equilibrium-aware magnetic-island phantom and synthetic SXR forward model is the upstream source of synthetic training physics.
The intended synthetic lineage is:
```
VAFT equilibrium
        ↓
q profile / rational surface
        ↓
straight-field-line magnetic coordinates
        ↓
analytic MI topology
        ↓
emissivity response model
        ↓
SXR LOS forward projection
        ↓
rotational synthetic SXR
```
The equilibrium should remain the source of truth for:
magnetic-axis position;
flux-surface shaping;
Shafranov shift;
rational-surface location;
local flux expansion;
safety-factor profile.
The learned-model issue should own dataset construction and inversion, not magnetic-island topology formulas.
5. Synthetic parameter space should follow observability
Do not randomize every possible phantom parameter indiscriminately.
Parameters that the model should learn to reconstruct or discriminate
Examples:
```
m
rational-surface location
island gross radial scale / width
coarse MI morphology
```
Nuisance / augmentation parameters
Examples:
```
initial rotation phase
window starting phase
rotation rate / rotation count in the context window
emissivity amplitude
slow amplitude evolution
measurement noise
```
Quantities not initially inferred from SXR alone
Examples:
```
n
weakly observable shaping parameters
other quantities below the diagnostic identifiability limit
```
These should instead be fixed, provided by the equilibrium, or introduced later as conditioning information if scientifically justified.
6. Dataset split must occur at the synthetic-case level
The original notebook generated random temporal crops from a common synthetic population. The VAFT implementation must avoid correlated train/test leakage.
Correct ordering:
```
SyntheticCaseSpec
        ↓
train / validation / test assignment
        ↓
temporal crop / phase augmentation
```
not:
```
all synthetic sequences
        ↓
random temporal crops
        ↓
random crop-level split
```
The same equilibrium + island-parameter realization must not contribute correlated windows to more than one split.
Use a stable group-aware split where practical.
7. SyntheticDatasetArtifact
Training should consume a reproducible synthetic dataset artifact rather than implicit notebook arrays.
At minimum preserve:
```
equilibrium identity
island specification
emissivity-model identity
SXR geometry identity
case parameters
random seed / RNG provenance
measurement-error realization
input tensor definition
target grid / quantity
case-level split membership
VAFT revision
dataset fingerprint
```
Support both:
In-memory input
```
dataset = prepare_sxr_reconstruction_dataset(
    cases=synthetic_cases,
    spec=dataset_spec,
)
```
Local materialized dataset
```
dataset = prepare_sxr_reconstruction_dataset(
    path="/srv/vaft-training/sxr/mi-v0/",
    spec=dataset_spec,
)
```
Keep synthetic generation and model training as separable stages so one dataset can benchmark multiple model revisions.
8. Use canonical experimental SXR ODS for inference
Experimental inference must not depend on notebook-local CSV readers.
Use:
```
VEST SXR source
        ↓
vaft.machine_mapping.soft_x_rays
        ↓
canonical shot-level soft_x_rays ODS
        ↓
reconstruction preprocessing
        ↓
PyTorch model
```
#131 already established one canonical shot-level soft_x_rays IDS/ODS across available DAQ sources.
#599 established the canonical FileDB/HSDS persistence/replication contract.
The ML model should consume the scientific diagnostic representation rather than know DAQ filenames.
9. Do not hard-code the model around anonymous channel indices
The historical model used the original two 20-channel arrays:
```
vertical   : 20 LOS
horizontal : 20 LOS
-------------------
baseline   : 40 LOS
```
This remains the intended vaft_v0 baseline geometry.
However, current VAFT mapping also contains additional SXR arrays:
```
bottom   : 16 physical LOS, Be/Al two-filter measurements
lowermid : 16 physical LOS, Be/Al two-filter measurements
```
Therefore the model contract must not define its scientific identity as merely n_channels=40.
Prefer explicit array/measurement identity:
```
SXRReconstructionInputSpec(
    arrays=("vertical", "horizontal"),
    ...
)
```
with the final tensor assembled from canonical channel metadata.
This keeps v0 compatible with the original rotational-tomography task while allowing a later multi-array / multi-spectral extension without replacing the entire model contract.
10. Unify training and inference preprocessing
The historical notebook used different normalization/scaling procedures for synthetic training and experimental inference.
vaft_v0 should define one explicit:
```
SXRReconstructionPreprocessSpec
```
covering at least:
```
array selection
physical channel order
channel validity
calibration / gain handling
baseline handling
optional vacuum-reference subtraction
filtering
detrending / fluctuation extraction
resampling
temporal context
normalization
missing-channel policy
```
Reuse existing vaft.process.soft_x_rays primitives whenever their scientific semantics match.
Do not preserve historical hard-coded transforms such as anonymous first/second channel blocks or an unexplained fixed gain solely for notebook compatibility.
11. Filtering semantics must be explicit
#626 resolved the problem of implicitly mixing causal and zero-phase filtering in SXR processing.
This reconstruction workflow must select filtering conventions explicitly.
Because the model is offline, zero-phase processing may be appropriate, but the model must not inherit a phase convention accidentally from a helper default.
The chosen convention is part of PreprocessSpec and model provenance.
12. Rotational augmentation
Absolute initial island phase should normally be a nuisance variable.
Training may therefore use:
```
random starting phase
circular temporal shift
rotation-period sampling
rotation-rate variation
```
Prefer circular/periodic sampling over physically duplicating arrays when possible.
The intended learned invariance is:
```
absolute phase / time origin
        → nuisance

rotational spatial morphology
        → preserved information
```
13. Measurement/domain randomization
Synthetic-to-experimental domain transfer requires instrument variation beyond ideal forward signals.
Reuse #677 — Add common measurement-error models for synthetic diagnostics where possible.
Conceptual order:
```
MI / emissivity physics
        ↓
ideal SXR forward model
        ↓
measurement / instrument error model
        ↓
synthetic training observation
```
Initial candidates include:
```
Gaussian additive noise
gain error
offset error
slow intensity drift
channel-dependent variation
```
Do not bury stochastic noise inside the ideal #886 forward operator.
14. Reconstruction output must have explicit physical semantics
Do not expose the learned output merely as a flattened vector.
Return a structured result, for example:
```
SXRReconstructionResult(
    time=...,
    r=...,
    z=...,
    emissivity_perturbation=...,
    ...
)
```
The exact target quantity must agree with the selected #886 emissivity model:
```
epsilon(R,Z)
or
delta_epsilon(R,Z)
```
Record:
```
R/Z grid
coordinate convention
normalization
units / relative-unit semantics
target definition
```
in the DatasetArtifact and ModelArtifact.
15. Physics-consistent loss
Preserve the original scientific idea that a valid reconstruction must also reproduce the SXR measurement.
For reconstructed emissivity:
$$\hat{\mathbf{s}} = \mathbf{G}\hat{\boldsymbol{\epsilon}}$$
use a loss of the form:
$$\mathcal{L}
=
\lambda_{\mathrm{image}}\mathcal{L}_{\mathrm{image}}
+
\lambda_{\mathrm{LOS}}\mathcal{L}_{\mathrm{LOS}}.$$
The image term may combine pixel accuracy and structural similarity, e.g.
```
L1 / MSE
+
SSIM-like structural term
```
while the LOS term compares the reconstructed field after the actual forward projector with the synthetic/measured SXR observation.
Prefer applying the real differentiable geometry operator over learning a separate arbitrary SXR-output head.
16. Relationship to #267 classical tomography
#267 — Add SXR tomography inversion with flux-aligned and iso-flux reconstruction owns classical numerical inverse tomography.
Conceptually:
```
#267
SXR
 → regularized numerical inverse
 → epsilon(R,Z) / epsilon(rho)

```
These should share, where practical:
```
LOS geometry matrix
forward projector
output grid

```
They should also become cross-validation references rather than duplicate implementations.

18. Validation
A. Independent synthetic holdout
Evaluate unseen physical synthetic cases, not merely unseen temporal crops.
Metrics may include:
```
MSE / MAE
SSIM / structural correlation
peak / localization error
rational-surface radius error
m-mode identification
```
B. LOS reprojection consistency
```
reconstructed tomogram
        ↓
same SXR forward projector
        ↓
reprojected SXR
        ↕
input SXR
```
Report per-channel and aggregate residuals.
C. Physical parameter recovery
For synthetic cases, evaluate recovery of quantities that are actually observable, such as:
```
m
rational-surface localization
island radial scale
```
D. Experimental consistency
Because no true 2-D emissivity ground truth exists for an experimental VEST shot, use:
```
measured-vs-reprojected SXR consistency
temporal continuity
rotation-frequency consistency
Mirnov / fluctuation evidence
equilibrium / rational-surface consistency
```
where available.
Do not equate a visually plausible learned tomogram with validated ground truth.
19. Applicability domain
Record the training domain explicitly:
```
supported m range
equilibrium family/range
rational-surface range
island-width range
rotation-rate range
SXR geometry revision
measurement-error/noise range
```
Inference should be able to report an applicability warning when the input is clearly outside the trained domain.
A learned OOD detector is not required for v0.
20. Multi-array / additional-SXR follow-up direction
The current VAFT SXR mapping contains more information than the original 40-channel rotational-tomography study:
```
vertical + horizontal
    → original 40-LOS baseline

bottom + lowermid
    → additional 16 + 16 physical LOS
    → paired Be/Al two-filter measurements
```
The v0 model should use the original vertical/horizontal arrays first, but its contracts must permit later extension.
A follow-up model can investigate:
```
additional poloidal coverage
+
possible additional toroidal viewing location
+
spectrally filtered Be/Al measurements
```
This may improve:
spatial identifiability;
rational-surface localization;
separation of geometry from emissivity amplitude;
potentially the n/rotation degeneracy if the additional arrays are confirmed to provide an independent toroidal view;
joint emissivity / spectral-state constraints.
However, the additional arrays must not simply be appended as anonymous extra channels:
Be and Al signals share physical LOS but have different spectral response;
their forward model is not identical to the original broadband/proxy brightness channels;
their toroidal placement is still provisional under Confirm the provisional toroidal placements written for SXR, CES and the camera #746.
Therefore multi-array training should be a separate scientifically validated extension after v0.

Non-goals
The initial v0 does not require:
numerical reproduction of the historical TensorFlow implementation;
real-time causal tomography;
generic arbitrary-emissivity neural tomography;
3-D tomography;
SXR-only reconstruction of toroidal mode number n;
inversion of every equilibrium-shaping parameter;
nonlinear MHD simulation;
self-consistent 3-D island equilibrium;
replacement of Add SXR tomography inversion with flux-aligned and iso-flux reconstruction #267 classical tomography;
reimplementation of Add equilibrium-aware magnetic-island phantom and synthetic SXR forward model #886 island/forward physics;
automatic promotion of a newly trained model to production;
use of the additional two-filter arrays in the first v0 training corpus.
