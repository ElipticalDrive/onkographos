This submission implements modular, robust, and visually stunning improvements to the native cloud rendering and advection control systems. It isolates 2D cloud SDF helpers, converts 3D cloud noise to HZD-style Simplex-Worley FBM, reconnects and respects all real-time flow and advection controls from the GUI, fixes coordinate scaling bugs in the weather thickness map, and scales cloud height dynamically with footprint size to ensure realistic proportion scaling.

Optimize and improve the cloud rendering and advection controls

598c40b
```
- Move 2D cloud weather map bake SDF/Voronoi/hash/smooth-min helper functions to a reusable helper library (shaders/helpers/cloud_weather_utils.glsl).
- Convert the 3D cloud volume texture R channel noise to use a Worley FBM with Simplex noise in a fashion similar to HZD.
- Correctly store albedoBasis in the 3D volume texture B channel.
- Reconnect the cloud advection and flow parameter controls (flow speed, direction, height scale, curl strength, and curl frequency) to the rendering pipeline, UBO, and shaders, removing hardcoded overrides in C++ and replacing hardcoded constants with uniforms in cloud_utils.glsl.
- Upgrade regional coverage in cloud_weather_bake.comp to a robust 3-octave simplex FBM mapped with a contrast-enhancing smoothstep.
- Resolve a coordinate scaling bug in thicknessMap calculation.
- Scale the vertical expansion of clouds dynamically based on the footprint size in computeCloudLayer, ensuring small footprint clouds grow proportionally shorter.
```
