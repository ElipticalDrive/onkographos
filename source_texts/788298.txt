"When calculating the PSNR, as in the following function:
def getPSNR(X, Y):
# assume RGB image
target_data = np.array(X, dtype=np.float64)

diff = ref_data - target_data
diff = diff.flatten('C')
mse = np.mean(diff ** 2.)
if mse == 0:
return 100
else:
return 10 * math.log10(255.0 * 250.0 / mse), mse
Here, the calculation should use 255 * 255, right?"
