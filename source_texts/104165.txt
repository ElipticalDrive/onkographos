Browser GPU Benchmark Online with Live Results
Volume Shader BM is a free, no-install browser benchmark that runs a versioned ray-marching workload and reports FPS, frame time, min/max FPS, duration, stability, and the verified renderer backend. It measures the browser graphics stack for one run; it does not read temperature, power, clocks, or system-wide GPU utilization.
Run browser GPU testView methodology
Browser results vary by driver, power mode, background tabs, thermal state, and API support. For fair comparison, repeat the test with the same preset and browser conditions.
A browser-first benchmark
The test focuses on real browser graphics performance rather than synthetic native-only workloads. It captures the practical path users experience in web apps, shaders, visualization tools, and interactive 3D pages.
Useful comparison dimensions
Results are most useful when grouped by preset, device type, GPU model, browser, and rendering API. The leaderboard separates mobile and desktop classes so phone scores are not mixed with PC scores.
Shareable result evidence
A valid submission can produce a public result page with environment details and benchmark metrics, making it easier to share a run without relying on screenshots alone.
FAQ
Does it work without installing software?
Yes. The benchmark runs in a modern browser with WebGL2 support, and supported browsers can also expose WebGPU paths.
Why do browser scores differ from native benchmarks?
Browser benchmarks include browser engine, graphics API, sandboxing, and power-management behavior, so they answer a different question from native tools.
