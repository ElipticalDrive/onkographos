This commit adds a new volumetric cloud rendering system that balances visual realism and real-time performance. Key features include:
Cloud Volume & Raymarching:
World-space bounded cloud layer (CLOUD_MIN_HEIGHT to CLOUD_MAX_HEIGHT)
Ray-AABB intersection for determining entry/exit points
Adaptive step sizing based on distance for performance
Scene depth clamping to avoid rendering in front of geometry
Early-out when transmittance becomes negligible
Density Field:
Tileable 3D procedural noise (gradient/Perlin + Worley)
Low-frequency FBM for base cloud coverage/shape
High-frequency FBM with Worley noise for edge detail/erosion
Height-based density profile (flat dense bottoms, tapered tops)
Anvil effect for cumulus-like cloud shapes
Wind advection with vertical shear animation
Lighting & Scattering:
Beer-Lambert extinction with powder effect
Single scattering from directional sun light
Dual-lobe Henyey-Greenstein phase function (g ≈ 0.75)
Self-shadowing via light marching toward sun
Multi-scatter approximation for cloud interior brightening
Silver lining effect at cloud edges
Integration & Output:
RGB color + transmittance output for proper alpha compositing
Blue noise-like ray jitter for TAA/reprojection compatibility
Configurable via CLOUD_RENDERING_MODE setting (0=Minecraft, 1=Physical)
Cloud shadows on terrain
Preserves Minecraft-style blocky clouds as fallback option
New settings exposed in Settings.hlsl for full customization:
CLOUD_BASE_NOISE_FREQ, CLOUD_DETAIL_NOISE_FREQ
CLOUD_HEIGHT_GRADIENT_BOTTOM/TOP, CLOUD_ANVIL_BIAS
CLOUD_EXTINCTION_COEFFICIENT, CLOUD_HG_ASYMMETRY
CLOUD_SHADOW_MARCH_STEPS, CLOUD_JITTER_STRENGTH

```
This commit adds a new volumetric cloud rendering system that balances
visual realism and real-time performance. Key features include:

Cloud Volume & Raymarching:
- World-space bounded cloud layer (CLOUD_MIN_HEIGHT to CLOUD_MAX_HEIGHT)
- Ray-AABB intersection for determining entry/exit points
- Adaptive step sizing based on distance for performance
- Scene depth clamping to avoid rendering in front of geometry
- Early-out when transmittance becomes negligible

Density Field:
- Tileable 3D procedural noise (gradient/Perlin + Worley)
- Low-frequency FBM for base cloud coverage/shape
- High-frequency FBM with Worley noise for edge detail/erosion
- Height-based density profile (flat dense bottoms, tapered tops)
- Anvil effect for cumulus-like cloud shapes
- Wind advection with vertical shear animation

Lighting & Scattering:
- Beer-Lambert extinction with powder effect
```

```
The clouds weren't visibly moving because the wind offset calculation
lacked appropriate time scaling. Changes:

- Add time scaling factor (0.05) to convert game time to visible motion
- Use fmod to prevent floating point precision issues with large time values
- Apply consistent wind time scaling to both main and cheap density functions
- Fix detail noise animation to use the scaled wind time
```
fix: Remove visible creases in volumetric clouds
…
8d220f5
```
The cloud noise had visible seams/creases caused by:
1. sin()-based hash functions with precision issues at large values
2. Improper negative coordinate handling in tiling

Fixed by:
- Replaced sin()-based hash33/hash31 with pure arithmetic hashes
- Added proper wrapCoords() helper using floor division for correct tiling
- Normalized gradient vectors in Perlin noise for consistent amplitude
- Removed buggy manual negative value handling
```
