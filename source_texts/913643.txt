Extend the fixed 780-leaf 3D waveguide refinement family to the memory limit of this machine. First remove volume-sized Python/SciPy assembly bottlenecks while validating equivalence to the existing operator. Record serial full-trajectory timings, full-field finiteness, setup and host/GPU peaks, and reference sensitivity. Include uniform rows marked infeasible from exact allocation/index bounds; never extrapolate runtime speedups. Preserve the known sponge/flux failure (#42). Publish latest flagship results in README and a detailed capacity report. Related: #41, #43, #44.
