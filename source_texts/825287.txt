# 2D Image to 3D Point Cloud Reconstruction

[![Python](https://img.shields.io/badge/Python-3.8%2B-blue.svg)](https://www.python.org/)
[![PyTorch](https://img.shields.io/badge/PyTorch-2.0%2B-ee4c2c.svg)](https://pytorch.org/)

This project implements a deep learning pipeline that reconstructs a 3D point cloud from a single 2D RGB image. Using a CNN-based encoder and an MLP-based decoder, the model learns to map 2D projections to 3D spatial coordinates.

## Overview

The architecture follows an Autoencoder-like structure:
*   **Encoder:** A deep Convolutional Neural Network (CNN) that extracts latent features from a 224x224 RGB image.
*   **Latent Space:** A 256-dimensional vector representing the core geometric features of the object.
*   **Decoder:** A Multi-Layer Perceptron (MLP) that maps the latent vector to 1024 points (x, y, z coordinates).
*   **Training Objective:** Optimized using the **Chamfer Distance** loss to minimize spatial discrepancy between predicted and ground truth point clouds.
