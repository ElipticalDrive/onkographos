# 体渲染传递函数编辑器 (Transfer Function Editor)

这是一个用于医学三维可视化领域中**体渲染传递函数（Transfer Function）编辑器**的实现。

---

## 📁 项目整体架构

```
tfeditor/
├── main.cpp                    # 程序入口，窗口和渲染循环管理
├── imgui/                      # ImGui 库（UI框架）
├── shaders/                    # OpenGL 着色器
│   ├── ui2d.vert              # 2D UI 顶点着色器
│   └── ui2d.frag              # 2D UI 片段着色器
└── src/
    ├── tf/                     # 传递函数核心模块
    │   ├── tf_editor.h/.cpp   # TF编辑器核心类
    │   └── tf_gl.h/.cpp       # OpenGL LUT纹理管理
    └── ui/                     # UI渲染模块
        ├── ui_types.h         # 基础类型定义
        ├── input_state.h/.cpp # 输入状态管理
        └── ui_renderer2d.h/.cpp # 2D渲染器
```
