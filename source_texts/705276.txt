Hi,
I am using Potree / potree-core inside a custom Three.js editor.
My goal is to select a screen-space rectangle, mark the visible point cloud points inside it, and then temporarily hide them with a hotkey. Later I want to show them again.
The problem is that hiding does not work cleanly: instead of only hiding the selected visible surface points, I get larger scrambled / rectangular holes, which look octree-related. Showing all points again works.
Is there a recommended Potree approach to achieve this properly?
I am especially wondering:
Should I avoid modifying visible node geometries directly?
Is there a stable way to identify and hide selected points across octree nodes?
Is there a better approach for temporary hide/show of selected point cloud regions?
Thanks.

Hey Julian, if you're using potree, then you must consider using slicing tool offered by potree. You can get this using BoxVolume.
You can add a Boxvolume using viewer.scene.addVolume. Set correct ClipTask for viewer and set correct location and size for the box volume. That's it. You will be able to achieve your desired result of hiding points inside the rectangle or so.
