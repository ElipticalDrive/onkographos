Other information:
This PR introduces a new module to volmdlr: voxelization.py
This module has a main class called Voxelization that allows to create and manipulate voxelization from volmdlr geometry.
Some of the functions for voxelization has been cythonized in the file voxelization_compiled.pyx to improve performance.
Two different algorithms are available to voxelize a geometry: iterative and octree.
At the moment, iterative is set by default because more performant.
Two different display method are available: one that create a ClosedTriangleShell3D from the triangulation of each individual voxel, and another one that ClosedShell3D by creating some PlaneFace3D by extracting the contours of each face and letting volmdlr triangulate them from display, to avoid over-triangulation.
At the moment, the first one is set by default in volmdlr_primitives because the second seems to still be buggy in some cases, and have shadow issues.
All the code is commented, so don't hesitate to have a look at it. Reviews, bug report and feature request are welcomed.
Approach explained
The voxelization is defined in an implicit grid of the 3D space. The grid is defined by the size of the voxels.
The implicit grid is defined by discretizing the 3D space into axis aligned cubes with given size, with the origin of the global landmark (0, 0, 0) always being a corner point (and not inside a cube).
For example, in 1D and with a voxel size of t, the set of voxels (defined by minimal and maximal point) can only be defined as:
{i ∈ N, t ∈ R | (i * t, (i+1) * t)}
The corresponding set of voxel centers is defined by the following set: {i ∈ N, t ∈ R | (i + 0.5) * t}
This approach allows to always define voxelization of same size in the same grid of the 3D space, which is very useful to perform very fast Boolean operations.
