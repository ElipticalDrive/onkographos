Summary
This PR replaces the ASCII art-based fish rendering with a procedural 3D sunfish model using signed distance functions (SDFs), and adds a new microscope geometry for the Research section. Both models use surface-sampling techniques to generate particle targets, enabling proper 3D lighting and normal-based shading.
Key Changes
Sunfish Geometry: Replaced FISH_ART ASCII art with a procedural SDF-based sunfish (Mola mola) featuring:
Flattened oval body disc with rear truncation
Tall dorsal and anal fins for characteristic silhouette
Scalloped clavus (rudder-like rear fin) instead of a tail
Surface sampling with gradient-based normal calculation
Kind-based shading (body, fin, eye/mouth)
Microscope Geometry: Added complete compound microscope model with:
Curved support arm, foot, stage, objective, eyepiece, focus knob, and illuminator dome
Capsule-based SDF primitives for cylindrical components
Three material kinds: metal (with specular highlights), dark (low-light parts), and lens (bright/reflective)
Scaling and centering adjustments for proper frame positioning
Rendering Updates:
Updated particle data structure to store normal vectors (nx, ny, nz) and material kind instead of weight/face flags
Added microscope weight to morph system (state 1)
Implemented proper normal transformation during rotation for both sunfish and microscope
Added material-specific shading: microscope uses specular highlights and facing-based brightness; sunfish uses speckled grey with fin blade brightening
Animation Behavior:
Sunfish holds face-on view with slow underwater sway instead of spinning (preserves disc silhouette)
Microscope rotates at 1.1x base speed for research section pacing
Drag interaction overrides automatic rotation for both models
CSS Updates:
Changed scroll-snap behavior: removed snap from content-container, added scroll-snap-align: center and scroll-snap-stop: always to individual .scroll-section elements for per-section snapping
Implementation Details
Both geometries use the same SDF surface-sampling pipeline:
Random point generation in bounding volume
Distance field evaluation and filtering (points near surface)
Gradient computation via finite differences
Surface projection along gradient
Material kind determination at projected point
Duplicate padding to fill particle count
The normal vectors are properly rotated during 3D transforms using the same rotation matrix applied to positions, enabling correct lighting across morphing states.
