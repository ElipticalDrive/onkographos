# Surface Reconstruction

## Overview
This project implements implicit and neural implicit surface reconstruction. It it uses or learns a signed distance function (SDF) from a sparse point cloud with normals and reconstructs the 3D surface using marching cubes. Check out the [report](https://github.com/ThomasLagkalis/Surface-Reconstruction/blob/main/report.pdf) for the results.

## Requirements

Make sure you have the following installed:

- Python 3.13
- PyTorch
- NumPy
- Scikit-image
- Trimesh
- Pyglet (`pip install pyglet<2`)

You can install everything via:

``
pip install -r requirements.txt
``

## Usage

To run the implicit SDF reconstruction run:

``
python naiveReconstruction.py
``

The default dataset is the 1000 pts bunny. You can change it using the flag --file [PATH]. Where path can be:

1. '' data/bunny-500.pts '' for the dataset of 500 pts bunny
2. '' data/sphere.pts for '' the sphere 

To train the neural network on a point cloud file (e.g., bunny-1000.pts):

``
python neuralNetReconstruction.py --input_pts data/bunny-1000.pts
``

After training, you can visualize the reconstructed surface with marching cubes using:

`` 
python neuralNetReconstruction.py -e
``

You can customize training with additional flags, such as:

```bash
--epochs [INTEGER]             # Train for [INTEGER] epochs
--train_batch [INTEGER]        # Change training batch size to [INTEGER]
--clamping_distance [FLOAT]    # Clamp SDF values within +-[FLOAT]
--sample_std [FLOAT]           # Standard deviation for SDF sampling
```
