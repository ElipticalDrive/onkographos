Summary
Closes roadmap §1 ("Signed distance fields for skin meshes (octree)") in full — the entry is removed from doc/roadmap.md rather than left as a stale gap.
The primitive (v9.24.0): grid() — the library's first mesh generator — plus voxelize() (all/surface/inside fill), sample_distance/distance_to_surface/surface_watertight_check. Output is an ordinary hexahedron Mesh, so every writer, crop, isosurface, --color-by and the viewer already work on it with no new format and no new code.
compute_sdf (v9.25.0): the grid and the field in one call. structure="octree" refines only near the surface via refine's Balanced closure (a v9.23.0 prerequisite fix to that closure's hanging-node reporting and cross-pass tearing) — its zero level set is the same contour, bit-for-bit, as a uniform grid at the same finest resolution, from far fewer cells. Both octree failure modes (field interpolated one pass early; selection carried across a pass) have sabotage-verified oracles.
.vti (format 42): VTK XML ImageData. The one format whose Origin/Spacing/WholeExtent attributes are a generated grid's header — the only one that round-trips it, since no format persists arbitrary field_data. Writing a non-lattice (including a partial one — voxelize's surface/inside fills, or an octree) is refused by name.
crop(where=("array", "<", value)): a general cell_data predicate crop, sharing refine's comparison evaluator so the two can't drift on boundary cases (a non-finite value never matches, including under !=). Offsetting and inside/outside turned out to need no new operations at all — isosurface at a non-zero level and crop(where=...) composed with a cell-centred distance field already are the features.
Every surface: C++, Python (with byte-identical numpy twins throughout), C API, Fortran, Julia, R, WASM, both CLIs, MCP (42 tools), the settings pipeline, and the browser viewer.
example/python/03_mesh_operations.ipynb gained a real, re-executed section demonstrating all of the above with PyVista, and four new screenshots are embedded in doc/sdf.md, doc/voxelize.md and doc/crop.md.
ABI held at 6 throughout — every header change is Tier C, reviewed in doc/abi_reviews.md.
