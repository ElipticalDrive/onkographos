Description
Simulations of different reaction-diffusion systems. 2D models are 100x100 nodes grid. 1D model 100 nodes chain.
biomass_{BIFPARAM} = biomass model
fn_{BIFTYPE}_{BIFPARAM} = fitzhugh-nagumo model
gl_{BIFTYPE}_{BIFPARAM} = ginzburg-landau model
nonlinear_1d_{BIFPARAM} = nonlinear dynamical model, 1D chain of reactive systems
Note that fn_turing is not really a turing bifurcation, but rather a travelling wave emission.
