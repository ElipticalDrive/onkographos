Overview
Implement interactive camera controls for 3D globe navigation.
Requirements
Camera Class (render/render_camera.h)
Arcball rotation: Click-drag to rotate view around sphere
Zoom: Mouse wheel or pinch to zoom in/out
Pan: Middle-click drag to pan view (optional)
View matrix generation (lookAt)
Projection matrix generation (perspective)
Arcball Mathematics
Map 2D mouse position to 3D unit sphere
Calculate rotation axis and angle from drag
Accumulate rotations using quaternions
Smooth interpolation for camera movements
Zoom Control
Distance from target (sphere center)
Min/max distance clamping (e.g., 2× to 10× sphere radius)
Smooth zoom animation
FOV adjustment option
Input Handling
Qt mouse event integration
Support for touch gestures (future)
Keyboard shortcuts for reset view
Double-click to reset camera
View State
Camera position (spherical coordinates)
Look-at target (sphere center)
Up vector
Field of view
Near/far clipping planes
Key Files
src/render/render_camera.h (new)
src/render/render_camera.cpp (new)
Acceptance Criteria
Smooth arcball rotation
Mouse wheel zoom
Min/max zoom limits
View matrix calculation
Projection matrix calculation
Reset to default view
Responsive input handling
No gimbal lock
Technical Notes
Use quaternions for rotation storage
Initial camera: distance = 3× sphere radius, looking at origin
Default FOV: 45°
Near plane: 0.1, Far plane: 1000.0
Journey Mode Integration
This arcball camera is the foundation for the multi-scale zoom camera (#164) used in Journey Mode. The zoom camera extends this with:
Logarithmic scale transitions
Object tracking during zoom
Cinematic easing functions
See SDP v3 Section 4.8 for camera system architecture.
References
Ken Shoemake's arcball paper
glm::lookAt and glm::perspective
SDP v3 Section 6: Phase 1 Rendering Updates
