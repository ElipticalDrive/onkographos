how does Dataset emitter work with point data ? atleast in the demo phynemoresults.usd the Vel vector numpy_array doesnt exist, would it work if the Vx,Vy,Vz are stored in npz.
Yes, that should work. The Dataset emitter is really just a wrapper around NanoVDBEmitter in Flow. During execution it converts the points/fields to a NanoVDB using a voxelization implementation that simply uses gaussian splatting of the points (on going work should respect topology, if present in the data model). 1 component and 3 component fields are supported. So Vx,Vy,Vz work.
Wasnt able to change the colormap of the emitter, how to ?
