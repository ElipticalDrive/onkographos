Owner
Forest raster rendering culls complete instances, so partially visible models can submit substantial offscreen geometry. This adds an experimental grouped resident meshlet path with conservative hierarchy bounds, coherent complete-model LOD selection and portable WebGPU compute/indirect draws. Baseline remains default: grouped GPU means were 1.36% / 0.58% slower than baseline in the two measured views, and preprocessing adds startup cost. Fine mode remains unsupported experimental research without an equivalent forest sweep.
This draft is stacked on PR #1, exact base 8f82e06ccadbc77f017eb3d6baba269d3eef93db, targeting fix/mobile-gpu-session-recovery. Its diff excludes the dependency's mobile/path-tracing work. Review owner can retarget after that dependency merges; no merge, deployment or dist packaging is included.
Implementation
Partition each existing complete model LOD into deterministic Morton-ordered clusters with at most 64 referenced vertices / 64 triangles; build an eight-way hierarchy of conservative float32 spheres and escape links. Group up to eight adjacent meshlets into each grouped draw.
Choose one complete model level per instance using cumulative simplifier error and 90% demotion hysteresis. Frustum-cull the selected hierarchy, preserving exact level-zero triangles, materials, transforms, leaf masks and complete-model fallbacks within explicit draw/storage budgets.
Use ordinary compute plus indexed indirect raster draws with firstInstance=0; no mesh shader extension. Grouped flag is ?meshlets=1&meshletGroup=8.
Drain prior work, write current settings, dispatch a dedicated cull and read current diagnostics in queue order. Performance sampling disables diagnostic counters.
Add a bounded validation-only paired capture path, strict CPU count/history oracles, stored four-sample depth readback, preserved failure reproductions and CPU-only receipt/media reconciliation. Production renderer source is unchanged by the later acceptance instrumentation.
```
flowchart LR
  A[Existing complete model LODs] --> B[Deterministic clusters and conservative hierarchy]
  B --> C[Compute root frustum test and coherent LOD]
  C --> D[Selected hierarchy traversal]
  D --> E[Visible instance lists]
  E --> F[Indexed indirect raster draws]
  A --> G[Complete fallback for unadmitted models]
  G --> F
  F --> H[Paired selected-LOD reference and recorded acceptance]
```

Grouped evidence and visual limits
The reconciled ledger combines 17 valid stored-depth prefix captures (0..16) plus 62 passing v3 continuation captures (17..78): 79 unique sampled poses across Trail, Canopy, Under crowns, Clearing and Whole stand. It covers 167 transformed triangle probes, five target promotion/demotion cycles, and 15 stable identical-camera/detail holds. All decoded normal/reference color pairs are identical; all recorded strict count/history/overflow and four-sample depth checks pass. Total comparison scope is 40,953,600 color pixels and 163,814,400 recorded depth samples at relative tolerance 2^-20.
Each reference renders every cluster belonging to the same complete selected model LOD with the same root cull, material shader, instance transforms and masks. Production hysteresis is retained in this campaign. It isolates additional cluster rejection; it does not compare against the default baseline or independently test every root-cull decision. Full-detail checks cover four views; approximately 1.89-billion-triangle Whole-stand full detail is excluded by the 600M budget. Raw depth buffers were not separately archived for CPU re-comparison.
Ordered visual review is complete with a material limit: Under-crowns cases 38..43 are nearly black in both paired renders, despite nonzero/full depth coverage; Clearing has substantial shared foreground occlusion. The dark route's cause is unconfirmed. These frames are preserved. This evidence does not establish continuous no-popping or unobtrusive transitions. Original complete LODs still switch discretely without geomorph/blending. See the ordered review.
Other complete strips: Canopy, Clearing, Whole stand.
Validation and preserved failures
339 browser CPU tests pass, with exact oriented geometry, deterministic grouping/budgets, enclosing spheres, seeded clipping equivalence, thresholds/hysteresis, diagnostic ordering, injected depth holes/all-clear evidence, stale history and strict fallback-count failures.
All 72 protected hashes and docs/SOURCE_BASELINE.json match exact public base 8f82e06. Path-tracing BLAS/TLAS, transport, native code and asset contracts remain preserved. The four production meshlet files are unchanged by this acceptance-evidence commit.
Naga 30.0.1 validates the production/controlled shaders and three isolated acceptance shaders with all flags and no optional capabilities. CPU policy export reproduces the successful native shader/helper hashes.
Historical failures remain explicit in the ledger: the initial discard-depth evidence is invalid; the first count oracle confused selected-level bounds with root populations; the stored-depth v2 run failed at pair 26 on one conservative binary32 tangency. The fallback proof and binary32 proof diagnose them without loosening count equality or changing production culling. The later v3 continuation is a separate pass, not a relabeled failed receipt.
The 62-pair native continuation took 66.445 seconds; browser/server/daemon release confirmed 2026-10-07T21:47:24.3814427Z, outer launcher 70.034 seconds. Sandboxing and pre-spawn argument allowlisting were retained. Final reconciliation and media review used CPU only, with no further browser/GPU work.
Reproduction and remaining scope
Architecture and acceptance commands describe flags, deterministic provenance, preserved receipt boundaries and CPU-only reconciliation. A fresh native campaign must start at case zero unless valid prefix evidence is separately supplied; the checked-in callback preserves the measured case-17 continuation configuration.
Fine mode has no equivalent 79-case sweep and remains clearly unsupported experimental research. Other adapters, every intermediate animation frame, arbitrary-camera behavior, the dark route's cause and Whole-stand full detail remain unverified. Streaming is not implemented: no page fetching, residency table, eviction, compression, virtual geometry, occlusion or dynamically simplified cluster cuts. This is not Nanite parity and does not fix the separate Adreno shader compile failure. Parent owns review, merge and publication.
