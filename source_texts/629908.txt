The format file MagicaVoxel-file-format-vox.txt said 4 | int | version number : 150,
But I checked the example .vox files (3x3x3.vox cars.vox castle.vox chr_knight.vox doom.vox and the rest in the vox folder) in hex mode, and I found that all their 5th byte is C8, that's '200' in DEC,
the 5th to 8th are C8 00 00 00
I am using a vox convert tool from other authors, and I found the converted files' 5th byte is 96, that's '150' in DEC,
the 5th to 8th are 96 00 00 00
I know these example files are from the MagicaVoxel's project itself, so the C8 should be the correct one.
But I'm confused that, the 5th byte, why it is C8, since the format file defined that it should be '150', a version number.
If it should be C8 and not be '150'(write as 96) for some reason, I shall use this issue URL to tell that convertor's author there are something.

Newer versions of magicavoxel use version number 200. The example files used by ephtracy could have been made by an older version of the program but if you save a .vox file (that has version number 150) it becomes version number 200. Other tools may create files for older versions of the program. Hope that clears some things up :)
