PM REVIEW — CHANGES REQUIRED on exact head 54b9c24e3b2ce8bc77d98693a352a2fe9ef9b42a.
Exact-head Character, Repository Layout, Worldgen Inspector and Deterministic Worldgen CI are green, but the protected MAP-016-specific contract is not yet satisfied.
Verified directly on the current source:
Volatile timing still contaminates deterministic mesh identity. extraction_ms / preparation_ms are populated from Time.get_ticks_usec() inside MeshData.metrics, while accepted MeshData canonical fingerprinting includes metrics. Observational timing must be separated from fingerprint material.
Halo output ownership is still missing. The mesher grows/intersects scan bounds with the one-sample halo and emits every cube in that expanded scan. There is no explicit requested-cell cube ownership gate. Halo samples may be read; neighboring cells must not both emit halo cubes.
Fragmentless cell world bounds are still wrong. _AABB_from_plan(plan) returns empty AABB() when there are no fragments instead of deriving the requested geometry-cell world bounds from the cell address + partition configuration.
Accepted descriptor realization remains partial. The current field still does not explicitly consume all accepted chamber/tunnel shape parameters (including chamber floor_bias / wall_roughness and remaining authored asymmetry/ceiling semantics, tunnel parameterized roughness, and explicit clearance_margin semantics). The new tunnel/entrance fixtures prove non-empty SDF path execution only; they do not prove parameter sensitivity or reordered-equivalent identity.
Placeholder fallback still exists. If MC emits no indices for non-empty fragments, the code calls _append_box_shell(fragment.clipped_source_bounds, ...) and records fallback_shell_count. MAP-016 replaces the placeholder representation and may not silently resurrect clipped box shells.
Still required after repair: adjacent-cell shared-boundary seam equivalence, negative-coordinate adjacent seam equivalence, deterministic fingerprints after timing separation, correct empty-cell AABB + empty buffers, descriptor-change sensitivity vs reordered-equivalent inputs, chamber+tunnel union continuity, entrance-mouth continuity, finite inward normals/valid indices, and proof of no fallback geometry.
The broad green CI remains useful integration evidence, but it does not waive these MAP-016 acceptance requirements. OBS-001/#160 stays blocked.
