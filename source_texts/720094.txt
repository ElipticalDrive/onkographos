Summary
Permeates the verified Dr Moagi / Klein-Net C++17 3D auto-encoding and decoding reference into the existing Jarvis-X C++ runtime without changing the behavior of existing DM3D byte-exact codecs or trainable ANN components.
Changes
cpp_runtime/dm3d_klein_codec/dr_moagi_3d_engine.cpp: 3-channel Cartesian voxel field, orthogonal 2x2x2 → 4 coefficient encoder, decoder, CTR acceptance/backtracking, persistent Ω memory, CLI and JSON/CSV/OBJ exports.
cpp_runtime/dm3d_klein_codec/CMakeLists.txt: standalone C++17 target and two CTest checks.
cpp_runtime/dm3d_klein_codec/README.md: mathematical derivation, commands, invariant and claim boundaries.
cpp_runtime/CMakeLists.txt: integrated add_subdirectory(dm3d_klein_codec).
.github/workflows/dm3d-klein-codec.yml: focused GCC/Clang/MSVC build-and-test matrix.
Mathematical contract
For an even grid N, X ∈ R^[3,N,N,N], Z ∈ R^[3,N/2,N/2,N/2,4]:
```
target = E_3D(X)
candidate = Z + η * [(target - Z) + μ * (Ω - Z)]
Xhat = D_3D(candidate)
CTR: accept if MSE(X, Xhat) <= MSE(X, D_3D(Z)) + 1e-10
Ω <- βΩ + (1-β) Z_accepted
```
The encoder/decoder are an orthogonal projection on the block basis {1,sx,sy,sz}. For stationary inputs with μ=0, the excess reconstruction MSE contracts by (1-η)^2 per accepted iteration in exact arithmetic.

Scope and scientific honesty
This is a lossy numerical reference codec with synthetic three-channel input and a Klein-inspired 256-node visualization mesh, not a trained ANN, production multimedia ingestion pipeline, exact-lossless compressor or 1 GB memory allocator. No speedup claims are made. Repository CI results remain to be confirmed.
