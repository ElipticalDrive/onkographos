I'm trying to implement a customer sampler according to http://distributionsjl.readthedocs.io/en/latest/extends.html.
For a univariate discrete sampler the following works
```
type SimpleDist <: Sampleable{Univariate, Discrete}
    par::Int
end

function rand(S::SimpleDist)
    p = Distributions.DiscreteUniform(0,S.par)
    val = Distributions.rand(p)
    return(val)
end
```
and can be used via
```
p = SimpleDist(4)
rand(p)
```
but I'm stuck with creating a multivariate sampler. According to the doc, I need a type and 2 methods
```
type CorrDice <: Sampleable{Multivariate, Discrete}
end

Base.length(S::CorrDice) = 2

function _rand!{T<:Real}(S::CorrDice, x::AbstractVector{T})
    x = [1,1]
    return(x)
end
```
but Julia throws the error message as below at me. I'm a bit lost with the error message but it seems that I need a different type signature for _rand! - But which one (and does the doc need to be updated)?
