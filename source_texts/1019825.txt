Preprocessing still shared pointer slots between child nodes, linked surface chains, compact arrays and region lists, with manual teardown and a separate counted-node subclass. Path-build props and conditional records also outlived failed builds, while prop collision tables used malloc/new arrays and duplicate counts.
Own child nodes directly and keep polygon/physical-surface banks and region IDs in standard containers. Remove the pointer union, counted subclass/global counter, linked-list arena, rearrangement pass, fixed region scratch allocation and their manual cleanup. Only the two produced surface kinds remain; compact OCT runs retain insertion order, deduplication and zero terminators. Size branch storage from the owned tree and region storage from the actual accumulated bound.
Return owned pre-prop records with vector stop meshes, store conditional records in the map by value, and restore borrowed spatial entries and game-data state on every exit. Prop collision vertices/surfaces also own vectors, so rebuilding animation geometry releases prior storage and uses container sizes. Runtime geometry and navigation algorithms retain their existing calculations.
Existing fixtures cover ordered queries, region merging, conditional blockers, surface compaction, submesh splitting and exact OCT bytes. Extend them with repeated animated-prop rebuilding, region-run emission, and consuming child nodes into compact indices in octant order. No new test framework or serialization layer.
The runtime GLM migration is already on main; this PR contains the remaining preprocessing and collision-table ownership changes, plus removal of the unused item-cursor declaration.
Production LOC against merge base b34fe722: +234/−498, net −264 (tests excluded).
Verification at b24434fa: Linux, AddressSanitizer and clang-tidy and clang-format pass. The native suite passes all 224 tests, including the 11 licensed runtime scenarios and software-GPU rendering.
