M384 — optional native AABB distance gate
Stacked on M383 / #399. Extends existing Combat → Attack Range Gate with a persistent Use Native Hitbox Distance toggle (default OFF).
When both the Attack Range Gate and the new setting are enabled, the exact native Minecraft 1.8.9 player ray hit's Entity.getEntityBoundingBox() supplies [minX,minY,minZ,maxX,maxY,maxZ]. The final synthetic left-click gate calculates the shortest 3D distance from the local player position to that bounding box instead of distance to the entity's position. A malformed/inverted/nonfinite/missing box fails closed. The original player kind/index and range checks remain, as do AntiBot, Friend Guard, Team Guard, Wall Check and vanilla ray-hit confirmation. Reading the hitbox at runtime happens only when the new option is active.
No hitbox mutation, raycast extension, packet spoofing or guarantee of server-side reach. Manual vanilla clicks are unchanged. This is a distance-gating improvement, not an increased reach cheat.
Verification
Final SHA: 518ae7303fac0dd15efa350c56cc5aece687714e
Foundation CI UX S23: source-native scroll depth cue informed by real Mojang screenshots #858 / run 38043179313: SUCCESS, Ubuntu and Windows, including foundation verification, transformed-host regression tests and launcher smoke.
Exactly two commits, eight changed files above M383. CI V354: single original Minecraft rotation writer across Spin, Aura, Aim Assist and Jitter #857 found a regression test order error (checked ray-hit bounds before test had assigned the ray-hit player), corrected at final head.
Unit tests cover enabled/disabled range, native AABB proximity, invalid/unknown/nonfinite/inverted bounds, setting persistence and no change to default positional range.
Transformed-host fixture verifies source-derived box from the confirmed player ray hit, and rejects nonplayer hits.
Limits
CI and synthetic transformed-host fixtures are not live Minecraft 1.8.9 multiplayer gameplay proof. Distance is to local player position (not precisely camera eye reach). Actual extended reach/hitbox scaling remains unimplemented pending exact native raycast and server-acceptance evidence. Stacked and not merged into main, which remains at M353. Tracking #368.
