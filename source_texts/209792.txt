Hello, thank you for your great work. I am reproducing your work on the DTU dataset using MLP parameterized SDF.
Do I need to use position encoding like NeRF when pretraining MLP, and if use position encoding, how to set frequency?
@jmunkberg @frankshen07 @jialechen7 @JiyouSeo
Currently, I use position encoding when pretraining MLP. Besides, I also adopt the positional encoding in NeRF and progressively fit the frequencies similar to SAPE during formal training, which is proposed in paper.
```
#my position encoding 
def PE(self,x, L,iteration):
    pe = []
    for i in range(L):
        if i+1<=4:
            weight=1.
        else:
            weight = min(1,iteration/(self.FLAGS.iter/2))
        for fn in [torch.sin, torch.cos]:
            pe.append(weight*fn(2.**i * x))
    return torch.cat(pe, -1)
```

```
def pretrain(self):
    lossfunction=torch.nn.MSELoss()
    optimizer=torch.optim.Adam(self.decoder.parameters(),lr=1e-3)
    for it in range(1000):
        #randomly sample 1000 points inside a unit cube
        data= (torch.rand((1000,3))).cuda()                                       # Q1: do this line correct?
        #compute gt sdf value for sampled points，gt.shape=(1000,1)
        gt= util.length(data)/self.FLAGS.mesh_scale-0.4
        gt=gt.squeeze()
        input_=self.PE(data,6,0)                    #Q2: should  I use position encoding and is this line correct?
        sdf,_=self.decoder(input_)
        loss=lossfunction(sdf,gt)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        if (it+1)%100==0:
            print(f"iter:{it},training loss:{loss}")
```
