# HoloCall — 4D Gaussian Splat Holographic Video Calls

Real-time volumetric video calls using mirror-based gaussian splat capture. You appear as a hologram on someone's Quest headset.

## The Idea

Instead of 50+ cameras ($50,000+), use **2-3 mirrors + 1 camera** ($500) to capture a person from all angles simultaneously. Encode to gaussian splats in real-time on GPU, stream over WebRTC, render as hologram on Quest 3.

```
YOUR SIDE                          THEIR QUEST
                                      
Mirror ╱                              🥽
      ╱                               │
 YOU ○  📷 → GPU Encode → Stream → Holographic YOU
      ╲                               │
Mirror ╲                              sitting at
                                   their workbench
```

## Architecture

```
holocall/
├── capture/                    # Camera + mirror capture pipeline
│   ├── calibration/            # Mirror geometry calibration (ArUco)
│   ├── mirror-extraction/      # Extract virtual camera views from mirrors
│   └── encoder/                # Real-time gaussian splat encoder (CUDA)
│
├── streaming/                  # Network transport
│   ├── server/                 # Signaling + relay server
│   └── protocol/               # Splat delta compression + WebRTC
│
├── viewer/                     # Rendering on receiving end
│   ├── quest-native/           # Unity Quest 3 hologram renderer
│   └── web-preview/            # Browser preview (Three.js)
│
├── shared/                     # Common code
│   ├── types/                  # Splat data structures
│   └── math/                   # Mirror reflection math, camera models
│
├── hardware/                   # Build instructions for capture booth
│   └── booth-design.md         # Mirror angles, camera placement, BOM
│
├── docs/                       # Technical docs
│   ├── ARCHITECTURE.md
│   ├── CALIBRATION.md
│   └── PATENT_NOTES.md
│
└── tests/                      # Test suite
```
