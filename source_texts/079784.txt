Summary
Introduces a new tool pointcloud4d that transforms RGB video with depth and alpha passes into cinematic point-cloud videos with virtual camera flythrough, advanced post-processing effects, and synchronized audio-reactive elements.
Key Changes
New render pipeline (render_pointcloud4d.py):
Unprojection of depth maps into 3D point clouds with temporal coherence via stable jitter sampling
Subject/environment separation using alpha masks with distinct shading treatments
4D motion effects including intro assembly, transition vortex bursts, ember particles, and outro dispersion
Virtual camera with Catmull-Rom keyframe interpolation, handheld drift, and dynamic pivot tracking
Advanced post-processing:
Z-buffered point splatting with additive haze layer
Volumetric backlighting, god rays (radial zoom-blur), bloom pyramid, anamorphic streaks
ACES tonemapping, chromatic aberration, vignette, film grain, and 2.39:1 letterbox
Audio-reactive bloom and rim lighting via RMS analysis
Analysis pipeline (analyze function):
Single-pass depth/alpha/audio analysis extracting transition energy, subject depth tracking, and loudness envelope
Temporal smoothing and interpolation for stable per-frame parameters
Parallel rendering:
Multiprocessing worker pool for frame-range distribution
MJPEG intermediate encoding with H.264 final output and audio passthrough
Documentation (README.md):
Korean-language guide covering input conventions, execution, pipeline stages, and tuning parameters
Depth convention clarification (dark=near, bright=far per Depth-Anything style)
Implementation Details
Depth-to-Z conversion uses power curve (Z = Z_NEAR + (Z_FAR - Z_NEAR) * d^1.8) for perceptual depth scaling
Flying pixel removal via gradient thresholding on depth discontinuities
LiDAR scan pulse and ember effects driven by per-particle random phase and energy envelope
Camera motion includes dolly-zoom sequences and subject-depth-aware pivot adjustment
Temporal coherence maintained through seeded random number generation per spatial sample
