Lets a SOG v3 file carry any number of typed per-gaussian blind fields, read in shaders through generated accessors. Based on @slimbuck's slimbuck#84, whose two commits are kept here, with review changes and an example on top.
Changes:
meta.blind is now a list of RGBA8 blind textures. Each holds up to 4 bytes of fields, packed in order (little-endian): u8 u16 u24 u32, f16 f32, or unorm8 unorm16 mapped over an optional range (default [0, 1]).
Shaders read each field through a generated getBlind_<name>(), returning uint / u32 for integer types and float / f32 otherwise. A SOG_BLIND_<name> define marks each field the file has, with the name sanitized to an identifier.
The decoding lives in a static shader chunk, and the accessors are generated once per resource, in the device's shader language only.
A SOG load now fails when any of its textures fails to load, and an error thrown while loading becomes a load error instead of leaving the asset loading.
Blind data is GPU only: decompress no longer turns it into a column.
The data is assumed valid, as the writer checks it; debug builds assert on unknown types, fields that do not fit their texture and repeated names.
API Changes:
The meta.blind format of SOG v3 files:
```
// before
"blind": { "name": "id", "bytes": 2, "files": ["blind.webp"] }

// after
"blind": [
    { "files": ["blind_0.webp"], "fields": [
        { "name": "logo", "type": "u8" },
        { "name": "edge", "type": "unorm8", "range": [0, 1] }
    ] }
]
```
Reading blind data in a shader, for example in a work buffer modifier:
```
// before
#ifdef SOG_BLIND
    uint id = getBlind();
#endif

// after
#ifdef SOG_BLIND_logo
    uint logo = getBlind_logo();
#endif
```
The writer is slimbuck's splat-transform sog-v3 branch (--sog-blind). It still writes each field's offset and a min / max pair, which need to become field order and range to match.
Examples:
New gaussian-splatting-fx/blind-data: the PlayCanvas logo as SOG v3 with two blind fields, logo (u8, 1 on the logo) and edge (unorm8, the distance across the front face to the logo outline), used to sweep a shine across the logo and run hue waves across the pillow.
