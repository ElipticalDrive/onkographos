Motivation
Provide a compact, dependency-free C11 CPU ray tracer that can load Wavefront OBJ + MTL scenes and demonstrate BVH-accelerated triangle ray tracing with reflections.
Offer a simple example scene and an easy build/run flow so the renderer can be used as a starting point for experimentation and extension.
Description
Add a new top-level folder cpu_obj_renderer containing a Makefile, README.md, an example scene (examples/mirror_room.obj + mirror_room.mtl), and the renderer implementation at src/main.c.
Implement OBJ/MTL parsing supporting v, vn, f, mtllib, usemtl and MTL properties newmtl, Kd, Ks, Ns, and refl/reflectivity in src/main.c.
Implement triangle storage, BVH build (median split on widest centroid axis), AABB overlap test, Möller–Trumbore triangle intersection, and a traversal-based intersection routine used by the CPU ray tracer.
Implement shading with diffuse + Phong specular, hard shadows, a sky fallback, supersampling anti-aliasing, recursive mirror reflections, simple material-derived reflectivity, and a command-line interface for resolution, --samples, and --bounces.
Testing
Built the project with make -C cpu_obj_renderer, which completed successfully.
Ran the renderer on the included example with ./cpu_obj_renderer/objrt cpu_obj_renderer/examples/mirror_room.obj /tmp/mirror_room.ppm 160 90 --samples 1 --bounces 2 and it produced a PPM output file.
Validated the PPM header and file size with a Python check (reading /tmp/mirror_room.ppm) which passed, confirming the output dimensions and pixel count; a separate file-based check failed due to the environment missing the file command.

Store child indices before updating nodes
For scenes large enough to make push_node grow nodes->data during the recursive build (e.g. a few hundred triangles with the current 256-node initial capacity), this assignment can write through a stale address because the left-hand side may be evaluated before build_bvh(...) reallocates the array. I reproduced this with a 600-triangle OBJ under ASan as a heap-use-after-free at this line. Compute the child index into a local first, then assign nodes->data[ni].left/right after the recursive call returns.
