in the 1d transfer function tab, change color table by selecting a new one via the color table button.Apply.The color and opacity bars update appropriately.Now click 'reset'.The color and opacity bars reset, but the color table name in the button remains the same. Have only tested trunk.
Comments:
Color table name is not a first-class Volume Plot attribute. It is only a gui button that when changed grabs from the viewer the ColorControlPointList associated with the color table name, then sets the Volume atts 'colorControlPoints'. That's why the button doesn't get updated when the atts are 'reset'.This also means you cannot change the Volume Plot's color control points by simply changing to a different color table name.Should a 'colorTableName' att be added to the Volume plot?
