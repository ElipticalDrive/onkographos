# Multi-Camera 3D Reconstruction

A Python and OpenCV perception project using calibrated camera views, voxel visual-hull carving, feature matching, robust pose estimation, and colored point-cloud rendering.

![Reconstructed point cloud](voxel_reconstruction_point_cloud.png)

## Pipeline

1. Use calibrated camera poses and silhouettes from multiple views.
2. Carve a voxel visual hull to reconstruct the observed volume.
3. Extract Harris features and establish cross-view correspondences.
4. Reject outliers with RANSAC.
5. Estimate camera pose using SVD.
6. Render face-center, true-color, and false-color point-cloud outputs.

RANSAC was introduced after raw correspondences produced unstable pose estimates and unreliable geometry.
