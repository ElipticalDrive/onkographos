Updated Plane.distance to use direct closed-form symbolic formulas for Point3D, LinearEntity3D (Segment3D, Ray3D, Line3D), and Plane, enabling exact evaluation on symbolic coordinates without Undecidable errors.
References to other Issues or PRs
Fixes #30790
Brief description of what is fixed or changed
Previously, Plane.distance(o) used intersection checks (self.intersection(o) and pi in o), which fail on symbolic coordinates with Undecidable: Cannot determine if ... is in ... (e.g. p.distance(Segment3D(Point3D(0, 0, z1), Point3D(0, 0, z2)))).
Following the Lean4-backed closed-form formulas proposed by @sylee957 in #30778 (comment 6302265516), this PR updates Plane.distance to use direct closed-form formulas:
Point3D: Abs(a) / N
Segment3D: (Abs(a) + Abs(b) - Abs(c)) / (2 * N)
Ray3D: Abs(a) * (1 + Min(0, sign(a * c))) / N
Line3D: Abs(a) * (1 - Abs(sign(c))) / N
Plane: self.distance(o.p1) if self.is_parallel(o) else S.Zero
Where $P = \text{self.p1}$, $n = \text{Point3D(self.normal_vector)}$, $a = n \cdot (A - P)$, $b = n \cdot (B - P)$, $c = n \cdot (B - A)$, and $N = \sqrt{n \cdot n}$.
Other comments
All existing tests in sympy/geometry/tests/test_plane.py continue to pass. A comprehensive regression test suite test_plane_distance_symbolic has been added covering symbolic segments, rays, lines, and point conversions.

if isinstance(o, Plane):
    n = Point3D(self.normal_vector)
    m = Point3D(o.normal_vector)
    a = n.dot(o.p1 - self.p1)
    delta = n.dot(n) * m.dot(m) - n.dot(m)**2
    N = sqrt(n.dot(n))
    return Abs(a) * (1 - sign(delta)) / N
