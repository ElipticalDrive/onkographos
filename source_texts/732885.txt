Issue body actions
Modernize the renderer from raster-forward to RT-first hybrid. Clustered Forward+ with bindless throughout, hardware ray tracing for shadows + GI + reflections, full Wronski volumetric fog with light injection + multi-scatter, ReSTIR DI/GI + SVGF denoising, path-traced reference mode. RT-mandatory.
Showcase target: Bhaal Temple, fully RT-lit.
Foundation
bindless-migration (refactor: bindless descriptor indexing throughout #128): full descriptor indexing across all shaders
slim-gbuffer (feat: slim G-buffer (normal + roughness + motion + matID) #129): normal + roughness + motion vectors + material ID
forward-plus (epic: Forward+ Clustered Lighting #54): clustered lighting + light assignment
volumetric-fog (feat: volumetric-fog #130): Wronski frustum voxel + light injection + multi-scatter
volumetric-validation (fix: volumetric-validation #131): VUID fixes
volumetric-fog-polish (feat: volumetric-fog-polish #132): deferred sub-tasks + canonical inject/integrate math fix
image-quality (feat: image-quality #135): TAA (Karis14) + specular AA (Tokuyoshi19) + ACES/AgX
Hardware RT
rt-extensions (feat: rt-extensions #137): 4 KHR RT extensions + pipeline/SBT factories + RT-mandatory device gate
blas-tlas (feat: blas-tlas #138): per-mesh BLAS (static + skinned) + per-frame TLAS rebuild on async compute
rt-shadows (feat: rt-shadows #140): RT sun shadows default, raster CSM kept as a compare toggle
GI + reference
restir-di: Bitterli 2020 direct lighting reservoir resampling
svgf-denoiser: Schied 2017 behind an IDenoiser abstraction
restir-gi: Ouyang 2021 indirect bounce reservoirs
path-trace-reference: ground-truth PT mode reusing the RT infrastructure
Reflections + fog polish
rt-reflections: stochastic GGX reflections + denoise
volumetric-rt-shadows: shadow rays from the froxel volume
gpu-particles (epic: GPU Particle System #57): compute sim, showcase-sized (parallelizable, not part of the shipped arc)
Out of arc, later series: character-shading (skin / hair / cloth), gpu-driven (mesh shaders + meshlet baker + HiZ), virtual-geometry (Nanite-class).

rt-renderer arc complete. Shipped v3.0.0 → v3.0.18; milestone Release published (v3.0.18 — RT Renderer, https://github.com/Hekbas/Luth/releases/tag/v3.0.18).
Phases A–D all landed — bindless, slim G-buffer, Forward+, volumetric fog, image quality (TAA/AgX), RT extensions + BLAS/TLAS + RT shadows, ReSTIR DI+GI, SVGF, path-traced reference, RT reflections, volumetric RT fog shadows — each sub-effort closed via its own Closes trailer.
The one remaining checklist item, D.3 gpu-particles, is re-homed as a standalone effort (#57): the v3.1 material-system research showed particles are a self-contained sprite pass, parallelizable and not part of the RT arc. Next series is material-system (v3.1.0). Closing the umbrella.
