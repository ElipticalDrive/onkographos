Summary
Implements the structural foundation for per-entity participating media binding and removes the legacy Hanrahan-Krueger "fake SSS" approximation from Disney BSDF in preparation for physically-based Random Walk subsurface scattering (Phase 3).
This is a two-phase commit:
Phase 1: MediumInterface plumbing — value structs for medium binding, per-entity medium stack routing, and YAML schema for medium libraries.
Phase 2: Disney clean break — removal of subsurface, subsurface_color, and flatness parameters; automated migration of 23 YAML scene files.
Key Changes
Phase 1 — MediumInterface & Medium Stack
NEW MediumInterface.cs — value struct {Interior, Exterior} identifying participating media on both sides of a surface.
NEW MediumStack.cs — fixed-capacity (8), zero-alloc ref-struct stack for tracking nested refractive media through path tracing. Supports push/pop with overflow detection (drops oldest + warning).
NEW MediumBoundHittable.cs — wrapper that stamps every hit with a MediumInterface, enabling per-entity medium binding without modifying primitive geometry.
MODIFY HitRecord.cs — added MediumInterface MediumIface field to carry binding information through the renderer.
MODIFY SceneData.cs — added List<MediumData>? Mediums for scene-level medium library and InteriorMedium/ExteriorMedium fields on EntityData.
MODIFY SceneLoader.cs:
Refactored BuildGlobalMedium → BuildMedium(MediumData) for reusable medium construction.
Build medium library from mediums: YAML block before entity creation.
Resolve per-entity medium bindings and wrap with MediumBoundHittable if binding present.
Warn on duplicate IDs and unresolved references.
MODIFY Renderer.cs — thread ref MediumStack mediums through TraceRay, ShadeSurface, and ShadeSampleBounce. Active medium = mediums.Top ?? _globalMedium. Copy-on-write stack at transmission events.
NEW MediumStackTests.cs (9 tests) — validate push/pop balance, overflow behavior, null handling, and value-copy semantics.
NEW MediumBoundHittableTests.cs — verify medium interface routing on wrapped hits.
Backward compatibility: Legacy currentAbsorption and BsdfSample.NextSegmentAbsorption remain functional; existing scenes (e.g., cristallo.yaml) render identically.
Phase 2 — Disney Clean Break
MODIFY DisneyBsdf.cs:
Removed properties: Subsurface, SubsurfaceColor, Flatness.
Removed constructor parameters: subsurface, subsurfaceColor, flatness.
Removed helper: ResolveSubsurfaceColor.
Updated DiffTrans documentation: back-hemisphere tint is now baseColor (Cycles-style); dedicated subsurface_color knob removed in favor of per-entity Random Walk SSS via MediumInterface.
Diffuse lobe is now pure Lambert + Burley retro-reflection; no Hanrahan-Krueger flat blend.
NEW src/Tools/MigrateFakeSss/Program.cs — standalone migration tool that strips legacy fake-SSS YAML fields:
Scalar fields (subsurface, subsurface_color, subsurface_radius, flatness) → single-line removal.
Block fields (subsurface_texture, subsurface_color_texture, flatness_texture) → header + indented children removed.

The Hanrahan-Krueger "flat blend" approximation that used to ride on the
Disney diffuse lobe via `subsurface`, `subsurface_color`, `flatness`,
`subsurface_radius` is gone. SSS is now a per-entity volumetric
phenomenon driven by `interior_medium`; Phase 3 ships the Random Walk
integrator that consumes it.

DisneyBsdf:
- Removed `Subsurface`, `SubsurfaceColor`, `Flatness` properties + ctor
  parameters + ShadingParams fields + EvalParams binding.
- Removed `ResolveSubsurfaceColor`. The diffuse lobe is now pure Lambert
  + Burley 2012 retro-reflection Fresnel in all three entry points
  (Evaluate, EvaluateDirect, ScatterDiffuse). The `diff_trans` (Disney
  2015 foliage) lobe is retained and now tints from `baseColor`
  (Cycles-style).

SceneLoader:
- Stops binding the removed parameters at Disney construction.
- Emits a consolidated `Warn` when YAML carries any legacy field
  (`subsurface*`, `flatness*`, `subsurface_radius`). The fields stay on
  `MaterialData` (parsed but ignored) so legacy scenes still load.

Migration:
- New tool `src/Tools/MigrateFakeSss/` (not in solution). Line-based
  stripper for the seven legacy keys (scalar + block forms),
  `--dry-run` preview, in-place rewrite. Run on `scenes/`: 23 YAML
  files cleaned, 491 lines removed across material libraries and
  showcase scenes.

Tests:
- Removed two specs targeting deleted behaviour
  (Flatness_FullyFlat_MatchesSubsurfaceFullyOn,
  SubsurfaceColor_OverridesBaseColorInFlatLobe).
- Updated DiffTrans backhemisphere test to expect baseColor tint.
- 471 / 471 green.

Smoke renders: cristallo.yaml (no legacy field — invariato),
tempio-romano.yaml (marmo migrato — Lambert come atteso fino a Phase 3).
