Description
I would like to contribute a Client-Side WebGL Ray-Traced Volumetric Cloud & Atmosphere Simulator under Project/HTML,CSS,JS.
An advanced 3D visualizer using WebGL ray-marching to render realistic volumetric clouds, atmospheric Rayleigh and Mie scattering, and dynamic sun lighting.
Problem
Developers studying computer graphics and atmosphere rendering lack browser-native tools to experiment with volumetric ray-marching shaders without external game engine dependencies.
Proposed Solution
Build a WebGL application where users adjust cloud density, altitude, wind speed, sun azimuth/elevation, and atmospheric scattering coefficients with real-time shader compilation.
Features
Volumetric ray-marching shader rendering 3D cloud noise textures (Perlin-Worley noise)
Atmospheric Rayleigh and Mie light scattering simulation
Dynamic sun position controller (time-of-day slider)
Interactive 3D orbit camera controls
High-res PNG snapshot generator
Tech Stack
HTML5
CSS3
JavaScript (WebGL 2.0, GLSL Shaders, 3D Noise Algorithms)
