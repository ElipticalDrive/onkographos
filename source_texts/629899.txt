The chunk sizes in (the MagicaVoxel file format spec)[https://github.com/ephtracy/voxel-model/blob/master/MagicaVoxel-file-format-vox.txt] are 32bit integers, however ogt_vox.h uses 32bit unsigned integers.
As a result ogt_vox.h can write a >2GB file which MagicaVoxel cannot read, and in some of my tests the app crashed.
Being able to write a larger file size is likely useful, especially if other readers support this. So I'm not sure if we want to resolve this or ensure it's documented.
