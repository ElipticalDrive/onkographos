Descripción
Sistema de queries de física que permite hacer raycasts, spherecasts, boxcasts y overlaps. Los queries se encolan en CPU, se ejecutan en batch en GPU, y los resultados se leen directamente del buffer.
Arquitectura Simple
```
┌─────────────────────────────────────────────────────────────────┐
│                    PHYSICS QUERIES                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Frame N:                                                       │
│  ├─ CPU: physics.push_raycast(origin, dir, dist)               │
│  ├─ CPU: physics.push_sphere_overlap(center, radius)           │
│  └─ Queries se acumulan en query_buffer                        │
│                                                                 │
│  Sync CPU → GPU:                                                │
│  └─ Upload query_buffer                                         │
│                                                                 │
│  GPU (compute shader):                                          │
│  └─ Ejecuta TODOS los queries en paralelo → results_buffer     │
│                                                                 │
│  Frame N+1:                                                     │
│  ├─ CPU: let hits = physics.read_raycast_results()             │
│  └─ Resultados disponibles directamente (buffer ya mapeado)    │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```
Tareas
PhysicsQueries resource con buffers
push_raycast(), push_spherecast(), push_boxcast()
push_sphere_overlap(), push_box_overlap()
read_raycast_results(), read_overlap_results()

Compute shader overlap_batch.wgsl
Layer masks para filtrar colisiones

Ejemplo de Código
API Simple (Rust)
```
fn combat_system(
    mut physics: ResMut<PhysicsQueries>,
    shooters: Query<(&Transform, &Weapon), With<Shooting>>,
) {
    // Leer resultados del frame anterior
    for hit in physics.read_raycast_results() {
        if hit.entity != Entity::INVALID {
            damage_entity(hit.entity, 10.0);
            spawn_particles(hit.point, hit.normal);
        }
    }
    
    // Encolar nuevos queries para el próximo frame
    for (transform, weapon) in shooters.iter() {
        physics.push_raycast(
            transform.position,
            transform.forward(),
            weapon.range,
            CollisionLayers::ENEMIES,
        );
    }
}

fn explosion_system(mut physics: ResMut<PhysicsQueries>) {
    // Leer overlaps del frame anterior
    for overlap in physics.read_overlap_results() {
        for entity in overlap.entities.iter() {
            apply_explosion_force(*entity, overlap.center);
        }
    }
}

Estructuras
```
// Query input
#[repr(C)]
pub struct RaycastQuery {
    pub origin: Vec3,
    pub direction: Vec3,
    pub max_distance: f32,
    pub layer_mask: u32,
}

// Query output
#[repr(C)]
pub struct RaycastResult {
    pub hit: u32,           // 0 o 1
    pub entity_id: u32,
    pub distance: f32,
    pub point: Vec3,
    pub normal: Vec3,
}

// Resource principal
pub struct PhysicsQueries {
    // CPU → GPU
    raycast_queries: Vec<RaycastQuery>,
    overlap_queries: Vec<OverlapQuery>,
    
    // GPU buffers
    query_buffer: Buffer,
    results_buffer: Buffer,      // GPU escribe aquí
    staging_buffer: Buffer,      // Para readback
    
    // Resultados listos para leer
    raycast_results: Vec<RaycastResult>,
    overlap_results: Vec<OverlapResult>,
}

impl PhysicsQueries {
    pub fn push_raycast(&mut self, origin: Vec3, dir: Vec3, dist: f32, mask: u32) {
        self.raycast_queries.push(RaycastQuery {
            origin, direction: dir, max_distance: dist, layer_mask: mask,
        });
    }
    
    pub fn read_raycast_results(&self) -> &[RaycastResult] {
        &self.raycast_results  // Ya están ahí del frame anterior
    }
}

Compute Shader
```
// shaders/raycast_batch.wgsl

struct RaycastQuery {
    origin: vec3<f32>,
    direction: vec3<f32>,
    max_distance: f32,
    layer_mask: u32,
}

struct RaycastResult {
    hit: u32,
    entity_id: u32,
    distance: f32,
    _pad: f32,
    point: vec3<f32>,
    _pad2: f32,
    normal: vec3<f32>,
    _pad3: f32,
}

@group(0) @binding(0) var<storage, read> queries: array<RaycastQuery>;
@group(0) @binding(1) var<storage, read_write> results: array<RaycastResult>;
@group(0) @binding(2) var<storage, read> sdf_scene: array<SdfInstance>;

@compute @workgroup_size(64)
fn main(@builtin(global_invocation_id) id: vec3<u32>) {
    let idx = id.x;
    if idx >= arrayLength(&queries) { return; }
    
    let query = queries[idx];
    var result: RaycastResult;
    result.hit = 0u;
    
    // Ray march contra escena SDF
    var t = 0.0;
    for (var step = 0; step < 128; step++) {
        let p = query.origin + query.direction * t;
        
        let closest = scene_sdf(p, query.layer_mask);
        
        if closest.distance < 0.001 {
            result.hit = 1u;
            result.entity_id = closest.entity_id;
            result.distance = t;
            result.point = p;
            result.normal = calculate_normal(p);
            break;
        }
        
        t += closest.distance;
        if t > query.max_distance { break; }
    }
    
    results[idx] = result;
}
```
Flujo Interno por Frame
```
1. Frame Start
   └─ Resultados del frame anterior ya están en raycast_results/overlap_results

2. CPU Systems
   ├─ read_raycast_results() → devuelve slice, sin copia
   ├─ Gameplay usa resultados
   └─ push_raycast() → encola nuevos queries

3. Pre-GPU Sync
   ├─ Upload query_buffer con queries encolados
   └─ Clear vectores de queries

4. GPU Compute
   └─ raycast_batch.wgsl procesa todo en paralelo

5. Post-GPU Sync
   ├─ Copy results_buffer → staging_buffer
   ├─ map_async(staging_buffer)
   └─ Poll hasta que esté listo

6. Frame End
   └─ Copiar staging a raycast_results (listo para frame siguiente)
```
