Motivation

Add another scene to the app that demonstrates a CPU ray-cast implicit ellipsoid rendered into a GPU texture, and expose interactive controls for it in the Scenes UI.
Keep the existing fog postprocess sensible by disabling it for scenes that do not provide a depth buffer suitable for the fog pass.

Description

Added a new scene implementation FogScene (files FogScene.h / FogScene.cpp) which performs CPU-side quadric math, ray-quadric intersection and normal evaluation, generates an RGBA image, uploads it to a D3D12 texture each frame, and presents it fullscreen via a simple PSO and SRV.
Integrated the new scene into the application by including FogScene in App.h, extending the SceneKind enum with Implicit, adding a FogScene implicit; member, and wiring implicit.Init, implicit.Render, implicit.OnResize, and implicit.Cleanup into the app lifecycle in App.cpp.
Extended the Scenes UI in App.cpp to add the "Implicit Ellipsoid" selector entry and controls for ellipsoid parameters and rendering options (rx, ry, rz, shininess, rotX, rotY, zoom, panX, panY, viewSize, and renderScale), and adjusted saved scene index clamping to include the new option.
Adjusted fog postprocess logic and UI so fog is disabled for Cube and Implicit scenes by skipping fog UI and setting cb.fogDensity to 0.0f when those scenes are active.

Testing

Ran cmake -S . -B build, which configured and generated build files successfully in this environment.
Ran cmake --build build, which failed in this Linux container because the project depends on Windows SDK headers (windows.h) that are not available here (build failure unrelated to the new scene logic).
