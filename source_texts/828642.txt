Goal
Design and implement opt-in result resampling from supported linear volume meshes onto VTI cell centers.
Why
Version 0.2.0 correctly omits results during voxelization because entity identities change. A narrower volume-mesh-to-grid operation can have defined mathematics: cell fields can be sampled piecewise constantly, and nodal fields can be interpolated inside linear cells.
Proposed scope
Volume mesh input only; surface-only fields are outside the first implementation.
Sample target VTI cell centers that are classified inside the source volume.
Treat source cell fields as piecewise constant.
Interpolate source nodal scalar/vector fields with the source cell's linear shape functions.
Require an explicit option naming the resampling method; keep omission as the default behavior.
Define deterministic ownership on shared faces and an explicit policy for uncovered or multiply covered sample points.
Acceptance criteria
Add a design note with shape functions and point-in-cell rules for Tet4, Hex8, Wedge6, and Pyramid5.
Preserve occupancy separately from sampled result arrays.
Report the method, source/target locations, sampled count, uncovered count, overlap count, and any extrapolation.
Reject nonfinite values, degenerate/inverted source cells, unsupported component layouts, and ambiguous overlap unless a documented policy is selected.
Verify exact recovery of constant fields and bounded error for analytic linear fields on each supported cell kind.
Add independent VTK checks for emitted VTI arrays and regression tests for boundary points and grid alignment.
