The DMCSurfaceExtractor raised ImportError when the optional diso module wasn't installed, blocking 3D generation. Users were forced to either install diso or manually reconfigure to use standard marching cubes.
Changes
Automatic fallback: DMCSurfaceExtractor now falls back to MCSurfaceExtractor when diso is unavailable or fails to initialize
Exception handling: Catches ImportError for missing module and common initialization errors (RuntimeError, ValueError, TypeError, AttributeError)
User feedback: Emits UserWarning with actionable message; logs debug info for initialization failures
Documentation: Added optional dependencies section to README
Implementation
```
class DMCSurfaceExtractor(SurfaceExtractor):
    def __init__(self):
        super().__init__()
        self._use_fallback = False
        
    def run(self, grid_logit, *, octree_resolution, **kwargs):
        if not hasattr(self, 'dmc') and not self._use_fallback:
            try:
                from diso import DiffDMC
                self.dmc = DiffDMC(dtype=torch.float32).to(device)
            except ImportError:
                warnings.warn("diso module not found. Falling back to standard marching cubes...")
                self._use_fallback = True
                self._fallback_extractor = MCSurfaceExtractor()
        
        if self._use_fallback:
            return self._fallback_extractor.run(grid_logit, octree_resolution=octree_resolution, **kwargs)
        # ... use diso
```
The fallback initializes once and reuses the same MCSurfaceExtractor instance for subsequent calls.
