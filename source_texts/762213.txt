Summary
Enable BakedSDF to use depth and normal priors during training, similar to MonoSDF/NeuS variants.
Motivation
Upstream PR: autonomousvision#231
BakedSDF currently only uses RGB supervision. Adding depth/normal prior support would improve reconstruction quality, especially for challenging regions with weak texture.
Implementation
Minimal change - remove constraints preventing BakedSDF from using monocular cues:
File: sdfstudio/models/bakedsdf.py (or equivalent config)
Change: Allow depth_loss, normal_loss to be enabled for BakedSDF
