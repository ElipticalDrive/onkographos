README.md
binvox2stl
Converts a binary voxelgrid (.binvox) file into a mesh file (.STL) using the Marching Cubes method.
It makes use of binvox-rw-py and TriMesh libraries.
Usage:
```
python binvox2mesh.py <FILENAME>
```
Example:
```
python binvox2mesh.py sample_model.binvox
```
You can view your generated meshes with MeshLab or https://3dviewer.net/ or any other STL mesh viewer.
