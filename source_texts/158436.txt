Ray-Box Intersection Algorithm
Abstract
The computational bottleneck in a ray tracer using
bounding volume hierarchies is the
ray intersection routine with axis-aligned bounding boxes.
We describe a version of this routine that uses
IEEE numerical properties to
ensure that those tests are both robust and efficient.
