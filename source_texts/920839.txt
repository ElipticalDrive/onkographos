# 🚁 Aerial 3D Reconstruction via Gaussian Splatting using UAV

## 📌 Project Overview
An end-to-end computational pipeline transforming raw UAV (drone) footage into high-fidelity 3D environments. This project leverages COLMAP for Structure-from-Motion (SfM) feature matching and Gaussian Splatting for advanced 3D rendering.

![3D Model Preview](output/3d_model_preview.png) *(Note: Ensure this path matches your uploaded preview image)*

## 📸 Data Capture Guidelines (Optimal Drone Data)
To ensure the best possible 3D reconstruction, the UAV data was captured following strict photogrammetry principles:
*   **Zero Blur:** High shutter speeds were maintained to prevent motion blur from degrading feature tracking.
*   **High Overlap:** Flight paths ensured 70-80% overlap between sequential frames.
*   **Full Coverage:** Multi-height orbits were flown, combining Nadir (top-down) and Oblique (angled) perspectives.
*   **Lighting Optimization:** Auto-exposure was locked, and overcast lighting was utilized to avoid baked-in harsh shadows.
*   **Stability:** Fast, erratic FPV-style turns were avoided to prevent rolling shutter and misalignment.

## 📂 Repository Structure
Due to GitHub's file size limits, this repository contains the computational pipeline, training notebooks, and documentation. Large datasets and video renders are hosted externally.

*   `/extract` - Scripts for parsing and preparing raw video frames (e.g., `extract_frames_from_video.py`).
*   `/training` - Jupyter notebooks for configuring and running the model training (e.g., `gaussian-splat-training.ipynb`).
*   `/output` - Static previews of the point clouds and final reconstructions.
*   `/docs` - Comprehensive project report and technical presentation slides.
