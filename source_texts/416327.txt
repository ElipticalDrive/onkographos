Summary
This PR uses fitted voxel planes to return surface heights and normals and judge headroom, slope, and steps in meters. It adds tiled GPU plane fitting, merges matching planes across grid lines, and adds geometric tests, recording helpers, and plane-fit timing.
Two traversability defects must be fixed before merging: closing restores occupied cells rejected for clearance or slope, and merging sloped overhead surfaces causes clearance to be overestimated. Focused execution reproduced both failures. The revised closing assertion also has a non-blocking coverage gap: required hole fills can disappear without failing the assertion.
T-Rex validation blocked
GPU execution could not start because no suitable graphics adapter was available. CPU execution confirmed the affected logic and assertion behavior; full GPU extraction remains unverified.
GPU surface cells now use fitted planes for height and walking checks.
Recorded lidar clouds can be compared with GPU surface heights and steps.
GPU tests run one at a time by default.

Merged ceilings appear too high
underside clamps a fitted plane to its remaining voxel's bounds, but merge_columns removes the lower voxel when a plane crosses a grid line. This clips away the lower part of a sloped ceiling and overestimates headroom.

Preserve the merged plane's lower extent when calculating headroom. This must be fixed before merging because the robot can be directed into insufficient clearance.
