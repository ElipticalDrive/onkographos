This PR implements a near-complete rewrite of the volumetric cloud rendering pipeline. It switches from rendering at half resolution using a fragment shader to a high-fidelity "Horizon Zero Dawn" style technique.
Key architectural changes:
Packed Dispatch: Cloud raymarching now occurs in a compute shader (atmosphere_lowres.comp) at quarter resolution. Each thread computes one pixel in a packed buffer, corresponding to a specific pixel in a 2x2 interleaved grid on the full-resolution frame, driven by a Bayer pattern.
Full-Res Temporal Reconstruction: A new compute shader (cloud_temporal_reprojection.comp) runs at full resolution to "unpack" the new samples and accumulate them into a full-resolution history buffer using reprojection and variance clipping.
Full-Res Spatial Filtering: The À-Trous wavelet filter now operates at full resolution to smooth out the reconstructed frame while preserving sharp edges.
Simplified Composition: The final composition shader no longer needs expensive bilateral upsampling, as it directly samples the high-quality full-resolution cloud buffer.
These changes significantly improve visual quality by rendering at the native resolution's pixel grid while maintaining performance through sub-sampling.
