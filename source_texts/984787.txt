Contributor
This change introduces a reverse ray-tracing workflow that converts a 2D edge source (Sketch/SVG) into a cylindrical shadow model using a user-selected light point. Rays are projected from source edges to the cylinder and used to carve transmissive slots so projected shadows map back to the source image.
New reverse-ray geometry core
Added freecad/HexLatticeMaker/reverse_ray_core.py with pure geometry helpers:
2D ray→cylinder intersection (line_cylinder_intersection_2d)
angular deduplication to avoid redundant cuts (dedupe_angles)
parameter validation (validate_reverse_ray_params)
model construction (create_reverse_ray_cylinder) that:
builds a hollow cylinder shell
samples edge geometry from the input shape
computes ray hit points on cylinder perimeter
cuts vertical slot cylinders at those hit locations
Workbench command integration
Added CreateReverseRayTracingModelCmd in freecad/HexLatticeMaker/init_gui.py
Registered command in toolbar and menu as Create Reverse Ray Cylinder
Command flow:
selection[0]: source object with edges (Sketch/SVG)
selection[1]: light point source (vertex/point-like object)
prompts for cylinder radius/height
creates Part::Feature output ReverseRayCylinder
Docs and discoverability
Updated README.md feature list and usage section with the new reverse-ray command and selection contract.
Targeted unit coverage
Added tests/test_reverse_ray.py for intersection behavior, dedupe logic, and parameter validation.
```
shape = create_reverse_ray_cylinder(
    image_shape=source.Shape,   # Sketch/SVG edge shape
    light_point=light_point,    # selected point/vertex
    cylinder_radius=40.0,
    cylinder_height=120.0,
)
```
