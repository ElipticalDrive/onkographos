Summary
New compute_occupancy shader: scans 8x8x8 bricks after voxelize, writes per-brick occupancy map (1 = any voxel non-empty, 0 = fully empty)
Render shader optimization: adds brick_occupied binding (set 0, binding 3) and skips empty bricks during DDA ray march by advancing to the next brick boundary
Registered compute_occupancy module in compute/mod.rs
Key design decisions
Occupancy shader reads the flat u32 voxel buffer (same as voxelize output) and checks the occupied slot (offset +3 per cell)
Brick skip in render uses DDA-style exit: computes distance to each brick face along the ray and advances along the nearest exit axis
Helper functions brick_exit_steps and check_brick_skip are split out to satisfy trap #4a and clear_grid compute shader #15
Integration notes for gpu-core / server
Server needs to: allocate brick_occupied buffer (32^3 = 32768 u32s), create compute pipeline for compute_occupancy, dispatch after voxelize, bind to render descriptor set at binding 3
Entry point SPIR-V name: compute::compute_occupancy::compute_occupancy
Push constants: ComputeOccupancyPushConstants { grid_size: 256, brick_size: 8, bricks_per_axis: 32, _pad: 0 }
Test plan
Verify SPIR-V compilation (cargo build passes)
Server integration: allocate buffer, dispatch, bind
Visual regression: scene should render identically with occupancy skip enabled
Performance: measure frame time improvement on sparse scenes
