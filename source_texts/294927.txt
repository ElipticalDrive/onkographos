# Marching cubes CUDA Project

## Get started
Build Marching Cubes Generator

Run exact commands in terminal or use commands from **makefile**.

```bash
mkdir build && cd build
```

```bash
cmake -D BUILD_VIEWER=OFF ..
```

```bash
cmake --build .
```

Run generator. Command line argument is expansion factor (make initial grid bigger).
```bash
./generator 1
```

## 1. Functional Requirements
The system is designed to procedurally generate volumetric terrain and extract 3D surfaces using the Marching Cubes algorithm. The core functional requirements are:

* **Volumetric Data Generation**: Generate a 3D scalar field (density grid) using procedural noise and recursive grid expansion.

* **Isosurface Extraction**: Process the 3D grid to identify the surface boundary at a specific isovalue threshold.

* **Mesh Generation**: Convert the isosurface data into a triangle mesh format (vertices and indices).
* **Performance Analysis**: Provide a benchmarking harness to measure execution time and memory throughput across different kernel implementations.

* **Visualization**: Render the resulting geometry in an interactive 3D environment.
