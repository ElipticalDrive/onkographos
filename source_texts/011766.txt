What is Rendering?
Rendering is the process of generating a 2D image from a 3D model or scene using computer
programs. It transforms mathematical descriptions of objects, lighting, and camera positions into
the final visual output displayed on screen.
The most important stages of rendering:
1. Modeling Stage
●​ 3D objects are defined using mathematical representations
●​ Objects described by vertices, edges, and polygons (typically triangles)
●​ Geometric data stored in memory (coordinates, shapes, sizes)
What is a Mesh?
A mesh is a collection of vertices, edges, and faces that defines the shape of a 3D object in
computer graphics.
Components of a Mesh:
1.​ Vertices (singular: vertex)
○​ Points in 3D space defined by coordinates (x, y, z)
○​ The "corners" of the 3D shape
○​ Example: A cube has 8 vertices
2.​ Edges
○​ Lines connecting two vertices
○​ Form the "skeleton" of the shape
○​ Example: A cube has 12 edges
3.​ Faces (or Polygons)
○​ Flat surfaces bounded by edges
○​ Usually triangles or quadrilaterals (quads)
○​ Triangles are preferred because they're always flat (planar)
○​ Example: A cube has 6 faces
Simple Triangle Mesh:
v1 (vertex 1)
/\
e1 / \ e2 (edges)
/ \
/________\
v2 e3 v3
Face: The triangle formed by v1, v2, v3
Why Meshes Matter for Rendering:
●​ The GPU processes each polygon in the mesh
●​ More polygons = more processing time
●​ Level of Detail (LOD) systems use different mesh densities based on distance from
camera
●​ Optimized meshes balance visual quality with rendering speed
2. Scene Setup
●​ Positioning of objects in 3D space
●​ Camera placement and viewing angle defined
●​ Light sources positioned and configured
●​ Material properties assigned (color, texture, reflectivity)
​ Camera Placement
The virtual camera determines what part of the 3D scene is visible and how it appears on
screen.
Camera Parameters:
1. Position
●​ Camera location in 3D space (x, y, z coordinates)
●​ Example: Camera at (0, 100, -200) looking at ice sheet at origin (0, 0, 0)
2. Orientation (Look Direction)
●​ Where camera is pointing
●​ Defined by:
○​ Target point: What camera looks at
○​ Up vector: Which direction is "up" for camera
●​ Example: Looking at center of ice sheet from above and to the side
3. Field of View (FOV)
●​ How wide the camera can see (in degrees)
●​ Narrow FOV (30°-60°): Telephoto lens effect, magnified view
●​ Wide FOV (90°-120°): Wide-angle lens, more visible but distorted edges
●​ Human eye: Approximately 90-100° FOV
●​ Example: 60° FOV for ice visualization gives natural perspective
4. Aspect Ratio
●​ Width-to-height ratio of viewing window
●​ Example: 16:9 (widescreen), 4:3 (traditional)
3. Geometry Processing
●​ Transformation: Objects are moved, rotated, and scaled to their correct positions
●​ Projection: 3D coordinates are converted to 2D screen coordinates
●​ Clipping: Parts of objects outside the viewing area are removed
●​ Objects transformed from world space → camera space → screen space
4. Rasterization
●​ Vector data (lines, polygons) converted to pixels (raster data)
●​ Determines which pixels on screen are covered by each polygon
●​ Creates the basic shape of objects on the 2D display
●​ Key process: Scan conversion turns geometric shapes into pixel grids
​ Why Rasterization is Fast:
1.​ Parallel processing: GPU can rasterize many triangles simultaneously
2.​ Simple calculations: Mostly addition and comparison
3.​ Hardware acceleration: GPUs designed specifically for this
4.​ Predictable performance: Time proportional to number of polygons
5. Shading and Lighting
●​ Light calculations applied to each pixel/polygon
●​ Determines color and brightness based on:
○​ Light source positions
○​ Surface normals (direction surface is facing)
○​ Material properties
○​ Viewer position
●​ Shading models: Flat shading, Gouraud shading, Phong shading
Gouraud shading is a method used in computer graphics to simulate the differing effect of light
and color across the surface of an object. Intensity- interpolation is used to develop Gouraud
shading. By intensity interpolation, the intensity of each and every pixel is calculated.
Intensity interpolation is a digital image processing technique used to estimate and fill in
unknown pixel intensity values (color/brightness) between existing data points. It is essential for
image resizing (zooming), rotation, geometric transformations, and 3D reconstruction from 2D
slices. Common methods include nearest-neighbor
6. Texture Mapping
●​ 2D images (textures) wrapped onto 3D surfaces
●​ Adds detail without increasing polygon count
●​ Example: Ice texture applied to glacier surface showing cracks and patterns
Additional Rendering Concepts (IB Relevant)
Ray Tracing
●​ Simulates light rays traveling from camera through each pixel
●​ Traces rays backward to light sources
●​ Highly realistic but computationally expensive
●​ Used for: reflections, refractions, shadows
●​ Too slow for real-time (usually); used in pre-rendering
GPU vs CPU Rendering
●​ GPU (Graphics Processing Unit): Thousands of small cores, excellent for parallel
tasks, handles rendering pipeline
●​ CPU (Central Processing Unit): Fewer, powerful cores, handles game logic, physics,
AI
Past Paper Question & Answer
Question: Once the 3D visualization has been rendered, when the user drags a slider bar to
simulate the amount of ice that has melted, the visualization is re-rendered without any delay.
Describe how this 3D visualization is rendered.
Model Answer:
The 3D visualization is rendered using real-time rendering techniques to ensure no delay
when the slider is moved.
Pre-computation and Optimization:
●​ The 3D model of the ice sheet is pre-loaded into memory with all geometric data
(vertices, polygons) ready for processing
●​ Level of Detail (LOD) models are prepared - simpler versions of the geometry for faster
rendering
●​ Texture maps and material properties are cached in GPU memory for quick access
●​ The rendering pipeline is optimized for the specific hardware being used
When the slider is moved:
1.​ Update geometry: The ice model's vertices are adjusted based on the slider value to
represent melted ice (vertices lowered/removed to show reduced volume)
2.​ Geometry processing: The modified 3D coordinates are quickly transformed and
projected onto 2D screen space using matrix operations performed by the GPU
3.​ Rasterization: The GPU rapidly converts the polygons to pixels using hardware
acceleration
4.​ Shading and lighting: Pre-calculated lighting values are applied, or simple shader
programs run on the GPU to calculate pixel colors in parallel
5.​ Z-buffering: The depth buffer determines which surfaces are visible, handling
overlapping geometry
6.​ Frame buffer update: The new image is written to the frame buffer and immediately
displayed
Key techniques for "no delay":
●​ GPU acceleration: Graphics Processing Unit performs parallel calculations on
thousands of pixels simultaneously
●​ Simplified geometry: Uses optimized polygon meshes that balance quality with
rendering speed
●​ Frame buffer swapping: Uses double buffering - one buffer displays current image
while next frame renders to second buffer, then they swap
●​ Spatial data structures: Uses octrees or BSP trees to quickly determine which parts of
the scene need updating
●​ Shader optimization: Pre-compiled shader programs run efficiently on GPU
●​ Minimal recalculation: Only the ice geometry is updated; static elements (background,
UI, camera) remain unchanged
The combination of hardware acceleration, optimized algorithms, and pre-computed data
enables the visualization to re-render at 30-60 frames per second, making slider movement
appear smooth and instantaneous.
