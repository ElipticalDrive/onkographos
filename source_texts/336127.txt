OK, I think I have this mostly figured out. My main concerns now have to do with coordinates and physics. Let's consider a case where the voxels aren't isotropic, and let's imagine that one axis is at 10x worse resolution than the other two (so that the aniostropy is a big, big deal). Then traversing a voxel along a "skinny" direction should (if we're modeling the physics correctly) cause a much smaller reduction in the integrated translucency than traversing the same voxel in the "fat" direction, because in the real world we've passed through very different amounts of "stuff" depending on the tracing direction. This seems to have several consequences:
In the raytracing equation we need to compute a stepsize_world
Per-voxel alpha needs to be quoted in units of opacity/length (where length = world length)
If you specify the input as an AxisArray, and let's say you specify the axis information in microns. Should alpha be opacity/micron? Or opacity/scaledps, where scaledps = ps ./ maximum(ps)? It's interesting to think about the consequences of supplying the "same" image at two different resolutions (like in an image pyramid), say one version of dimensions m-by-n-by-p with pixel spacing Δx-by-Δy-by-Δz, and the other at size m/2-by-n/2-by-p/2 with pixel spacing 2Δx-by-2Δy-by-2Δz. How should the alpha channel data scale with the resolution?
The transformation to normalized coordinates in the textures means that even the array size (not just pixel spacing) will end up influencing the physics here.
So I'm checking in to see if you follow a particular standard/reference/philosophy with regards to these issues, or whether there hasn't been a lot of attention paid to this yet in the volume imaging and if you'd appreciate someone coming in and thinking it through for you.

OK, we'll see if this passes tests. Meanwhile, if you want some fun, clone the brand-new https://github.com/timholy/AllenBrain.jl and run Pkg.build on it. Then download the 50um resolution dataset from http://download.alleninstitute.org/informatics-archive/current-release/mouse_ccf/annotation/ccf_2016/. Finally, in the directory you stored it, try this:
```
using AllenBrain

if !isdefined(Main, :vertexlist)
    global g, vertexlist, aob, baot, mea, aaa, pmco, bstp
    g, vertexlist = ontology("mouse")
    const aob  = structureids(r"AOB", vertexlist)
    const baot = structureids(r"BA$", vertexlist)
    const mea  = structureids(r"MEA", vertexlist)
    const aaa  = structureids(r"AAA", vertexlist)
    const pmco = structureids(r"COApm", vertexlist)
    const bst  = structureids(r"BST", vertexlist)
end

using FileIO, AxisArrays, Unitful, Colors
using Unitful: μm

ano = load("annotation_50.nrrd")
ano = AxisArray(ano.data, (:P, :I, :R), (50μm, 50μm, 50μm))

volumedata = colorize!(ano, RGBA(1,1,1,0.2),
                       aob=>RGBA(5.0,0,0,10.0),
                       bst=>RGBA(0,5.0,0,10.0),
                       pmco=>RGBA(2.0,0,5.0,10.0),
                       mea=>RGBA(1,0,5.0,10.0),
                       union(baot,aaa)=>RGBA(0,0,4.0,10.0))

visualize_volume(volumedata)
```
My favorite new way to explore brain anatomy 😄.
