Abstract The point cloud density is an important indicator of the characteristics of the point cloud data. The point cloud is composed of n points, and its density is the performance of the distribution density of points in a certain spatial range. In related application fields, point cloud density directly affects the accuracy and details of the model. High-density point clouds can show more tiny features and details, but they also generate large amounts of data, requiring significant storage and computing resources. On the contrary, although the low-density point cloud has a small amount of data and is more convenient for storage and rapid processing, it may lose some key details. The density of the point cloud presents a trade-off between data volume and detail. Different application scenarios need to balance the density of the point cloud according to the actual needs. Determining the appropriate density for each application scenario is the problem addressed in this paper.
