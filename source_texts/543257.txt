Sparselandtools is a Python 3 package that provides implementations for sparse representations and dictionary learning. In particular, it includes implementations for **For Sparse Representations:** * Matching Pursuit * Orthogonal Matching Pursuit * Thresholding Pursuit * Basis Pursuit **For Dictionaries in General:** * Mutual Coherence * DCT Dictionary * Haar Dictionary * Overcomplete DCT Dictionary * Visualization Tools for Dictionaries **For Dictionary Learning:** * K-SVD Algorithm * Approximate K-SVD Algorithm **For Application:** * Approximate K-SVD Image Denoiser
