⚡ Is there an underlying problem to be solved?
Rendering records per object on the CPU and binds per draw. Real-time photoreal rendering of massive scenes needs a GPU-driven pipeline: GPU-resident instance, material and geometry tables, culling and draw generation on the GPU, indirect draws, and a visibility buffer that defers material evaluation. Micropolygons (S18), virtual shadow maps (S19), GI (S20), particles and foliage assume it.
📝 What should the system provide?
GPU tables for instances (camera-relative float transforms, S07), materials (parameter block offsets, feature bits), geometry (meshlet ranges, bounds, cones) and lights, updated through persistent mapped upload rings by the scene mirror.
Bindless: one descriptor set with runtime arrays for textures, buffers and samplers; nonuniformEXT indexing (IR support from S11).
Culling: instance frustum and HZB occlusion (two-pass), meshlet cone and bounds tests, indirect draw and dispatch argument generation.
Visibility pass writing { instance id, triangle id }; material classification into per-material tile lists; a resolve pass per material permutation computing barycentrics and analytic derivatives.
A decided GPU minimum spec (descriptor indexing and 64-bit atomics required; mesh shaders and ray query optional with compute fallbacks), recorded as an ADR.
The existing meshes and materials rendered through the new path; the old per-object passes removed.
✅ How do we know it is done?
Given a 1M-instance test scene, when rendered, then draws are indirect from GPU tables and CPU submission time is near constant in instance count (numbers in the PR).
Given the visibility buffer with ten material permutations, when resolved, then the image matches the forward reference in the harness within tolerance.
Given occluded instances, when the two-pass culling runs, then disocclusion artefacts are absent in the golden video and the culled count is reported.
Texture filtering through analytic derivatives matches hardware derivatives within tolerance on the test pattern.
🧭 What is covered now, what is left for later?
Covered now: tables, bindless, culling, indirect draws, visibility buffer, classification and resolve, minimum spec ADR, migration.
Left for later: micropolygon clusters and software raster (S18), virtual shadow maps (S19), mesh-shader path, deferred versus forward-from-visibility-buffer final decision (made here, revisited with S22).
🕶️ How should the solution look like to achieve the points above?
Battle plan system S15, topic GPU-driven rendering.
💬 Do you have any additional considerations?
Blocked by S12, S14, S07. Blocks S16, S17, S18, S19, S20, S22, S25. Alpha-tested geometry cost in the visibility pass must be measured.
