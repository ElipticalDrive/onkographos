What this adds
tools/emit/gradient_reference.py (modelled on df_reference.py) writes one manifest, test/gtest/data/gradient/gradient.json (47 KB, plain JSON, no .npy), over this tree's own data/basis and data/aux_basis files, spherical throughout. Every gradient is stored as [x, y, z] rows, one per atom, dE/dR in hartree/bohr, with coordinates in bohr.

#497
The contraction matrices are a recipe, not a file: M_mn = 1/(m+n+1), the Hilbert matrix the coulomb/ fixtures already use. W_PQ = 1/(P+Q+1) and Γ_mnP = 1/(m+n+P+1). All indices are 0-based in PySCF's spherical AO order. Each element is one IEEE division, so the C++ tests can rebuild them bit for bit. Γ for cc-pVTZ would be several MB, so it is not stored.
Optimizer: no geomeTRIC or pyberny is in the lock, and adding one is outside this PR's files. So the optimizer is Newton's method on PySCF's analytic DF-RHF gradient: the Hessian is a central difference of that gradient, rigid modes are projected out, and it converges to max force < 1e-7. The file records this.
Self-checks in the script:
Every analytic contraction and every DF and direct term is checked against a 4th-order central finite difference of the matching energy, with the matrices held fixed. The step is 1e-3 bohr and the tolerance 1e-7·max(1, max|G|).
Each term set is checked against PySCF's own total to 1e-9.
The DF E_J and E_K are checked against PySCF's get_jk.
Every gradient's sum over atoms must be ~0.
test/gtest/data/README.md has a new table row and a gradient/gradient.json section with the regeneration command.
What was run
UV_PROJECT_ENVIRONMENT=$PWD/.venv uv sync --frozen --group tools, then UV_PROJECT_ENVIRONMENT=$PWD/.venv uv run --frozen --group tools tools/emit/gradient_reference.py. It took 2m26s on one thread, and every internal assertion passed.
Determinism: I ran the generator a second time and compared the output with cmp against the first run's copy. They are byte-identical, so a re-run gives no diff.
pytest -m "not slow" -n 8 -rs in the tools-group env: 156 passed, 0 skipped.
The same in a fresh plain uv sync --frozen env (no tools group): 118 passed, 6 skipped. All six are needs the \tools` dependency group, including the new test_cheapest_case_reruns`.
devtools/format.sh --check passed, and so did the pre-commit hooks.
No C++ was touched or built.
