개요
엔진에 Quaternion 기반 카메라 자세 시스템을 구현한다. FPS / 3인칭 카메라 두 모드 지원.
작업 범위
Quaternion 자세 저장
카메라 회전을 Quaternion으로 저장·누적
매 프레임 view 행렬은 Quaternion → matrix 변환으로 생성
FPS / 3인칭 카메라 모드
World up 고정 패턴:
`right = normalize(world_up × forward)`
`camera_up = forward × right`
forward가 world_up과 정렬 시 특이점 → epsilon 클램프 (±89.9° 등)
직교성 자동 보정
Quaternion 누적 후 매 프레임 단위화 (length 1 보장)
직교 행렬 자체는 누적하지 않음 (Quaternion이 baseline)
출처
Luna, Introduction to 3D Game Programming with DirectX 11 §1.4.2 (외적 직교화) + §3 (Transformations) 사전 빌드업
일반 카메라 시스템 설계 지식

체감 실험: 회전 누적 시 직교성/단위성 오차 측정
수용 조건
FPS 카메라 (마우스 입력 → yaw/pitch → Quaternion 누적) 동작

전치 활용 추가 메모 (Luna §2.3 학습 시 도출)
회전 행렬은 직교 행렬 → $$R^{-1} = R^T$$ 활용:
일반 역행렬 계산 $$O(n^3)$$ → 전치 $$O(n^2)$$ 로 큰 절감
카메라 자세를 회전 $$R$$ + 위치 $$t$$ 로 표현하면:
```
view = | R^T   -R^T t |
       |  0     1     |
```
view matrix 계산 시 inverse 함수 호출 대신 전치 활용
구현 시 적용:
View matrix 계산은 XMMatrixInverse가 아닌 회전 부분 전치 + translation 부호 반전으로 직접 구성
단위 테스트: 일반 inverse 결과와 비교해 동등성 검증
연관 책 절: Luna §2.3 (전치의 성질, 특히 직교 행렬에서 $$R^{-1} = R^T$$)
