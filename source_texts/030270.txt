Objective
Add native 3D Gaussian Splatting while reusing the proven scene, camera, experiment, metric, checkpoint, and benchmark infrastructure without routing 3DGS through NeRF ray rendering.
Scope
Add Gaussian means, scale/rotation or covariance, opacity, and spherical-harmonic state.
Add initialization from supported scene/COLMAP inputs.
Define a rasterizer adapter with an optimized optional backend and a testable reference/mock path.
Add optimizer parameter groups and pluggable densification, splitting/cloning, pruning, and opacity-reset policies.
Add full-image training and rendering through the shared method lifecycle.
Add versioned checkpoint and PLY/export support.
Report Gaussian count, quality, training/render speed, peak memory, and model size.
Design constraints
Reuse shared cameras, scenes, transforms, metrics, experiment metadata, CLI concepts, and report schema.
Do not use RayBundle or the NeRF volume compositor.
Keep backend licensing and platform constraints explicit.
Keep an accelerator-independent contract test path.
Required tests
Gaussian state validation and serialization.
Projection/rasterizer adapter contract tests.
Density-control strategy tests.
Full-image training-step gradient smoke test.
Train/render/resume/export integration.
Fixed-budget benchmark through the shared runner.
Acceptance criteria
Basic 3DGS trains, renders, resumes, and exports.
Shared engine contains no method-name branches.
Optional optimized rasterizer failure produces a clear capability error or supported fallback.
Benchmark artifacts use the same dataset/metric/provenance standards as NeRF.
