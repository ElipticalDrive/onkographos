This paper introduces an efficient method to compute the wavelet transform for huge 3D volume data like seismic data or 3D medical images with minimum resources. The method consists in a local data processing while reducing considerably the memory requirements. The resulting wavelet transform is identical to the one obtained if the whole 3D object was stored in memory.

Abstract
en
This paper introduces an efficient method to compute the wavelet transform for huge 3D volume data like seismic data or 3D medical images with minimum resources. The method consists in a local data processing while reducing considerably the memory requirements. The resulting wavelet transform is identical to the one obtained if the whole 3D object was stored in memory.
