Functional Gaussian appearance preview — not only centers
Stacked strictly on PR #264 (feature/v2l18-3-gsplat-glb-centers-export) at immutable base 005ba8d5f83c46868b05a6a909740c3061c792b2, without moving its L2-reviewed SHA. This is a new functional export of actual anisotropic Gaussians in a compact interoperable format, not a new GPU trainer or custom renderer.
export_verified_gsplat_splat(*,artifact_ref,output_root,profile,splat_path) reuses the existing full materialization audit of a pinned gsplat v1.5.3 59-float PLY; streams it in bounded 1024-record batches, checks the same source SHA-256 again at end, leaves the canonical original PLY untouched, and emits the actual antimatter15 .splat 32-byte per Gaussian layout: float32 XYZ (12B), float32 exp(log-scale) anisotropic size (12B), uint8 RGBA from SH0 and sigmoid opacity (4B), and uint8 normalized wxyz quaternion (4B). Output SHA-256 returned; no optional Torch, gsplat, CUDA, network, new dependency or custom splatting renderer. Higher-order SH remain only in the canonical PLY; .splat bakes DC color and is NOT a lossless physical model.
Existing viewer format evidence: upstream https://github.com/antimatter15/splat/blob/main/convert.py and https://github.com/antimatter15/splat/blob/main/main.js; 32-byte row also implemented by other existing Gaussian viewers such as xeokit. The existing RGB GLB remains an easily inspectable point-only fallback; this new file preserves opacity, scale and orientation for splat-specific viewers. No viewer launch or GPU rendering success is claimed.
Tests create real binary PLY records with two different positions, colors, log-scales, opacity and quaternion orientation, call the actual converter, decode independently with struct.iter_unpack('<6f8B'), verify all record fields, 32B/record, original model unchanged, output SHA, public API, and overwrite refusal; negative tests exercise invalid source PLY, zero quaternion and unrepresentable scale with no residual file. Scope is exclusively 3 V2L18.3-allowlisted files src/wre/reconstruction/static_appearance_baseline.py, src/wre/reconstruction/__init__.py, and tests/test_static_appearance_baseline.py. No new workflow or second solver.
CI & L2: await exact candidate SHA fast-ci Ruff/Pyright/pytest and existing native checks. One read-only independent L2 on stable functional lot after CI, not per formatting commit. No actual gsplat GPU training on this head; CPU tests build a binary splat from controlled Gaussian PLY fixture only.
