
# 1. はじめに
本記事では、スマートフォンで撮影した動画を元に3D Gaussian Splatting（以下、3DGS）モデルを作成し、NVIDIA Omniverse（Isaac Sim）に取り込むまでの一連の手順を解説する。具体的には、nerfstudioを用いた3DGSの生成、生成したPLYファイルのUSDZ形式への変換、そしてOmniverse上での表示確認までを行う。

# 2. 手順
## 2.1 3D Gaussian Splattingの作成
### 2.1.1 3DGSの作成に用いるソフトウェア
3DGSの作成にはnerfstudioを用いる。nerfstudioではコマンドを数回実行するだけで簡単に3DGSの作成ができる。

https://github.com/nerfstudio-project

### 2.1.2 nerfstudioの起動
erfstudioにはPythonライブラリ版とDocker版があるが、今回はDocker版を使用する。
カレントディレクトリを /workspace に指定して、Dockerコンテナを起動する。

```bash
docker run --gpus 'device=1' \
    -u $(id -u):$(id -g) \
    -v "$(pwd):/workspace/" \
    -e HOME=/tmp \
    -p 7007:7007 \
    --rm \
    -it \
    --shm-size=12gb \
    -e TORCHINDUCTOR_CACHE_DIR=/tmp/torchinductor_$(id -u) \
    ghcr.io/nerfstudio-project/nerfstudio:latest 
```

なお、筆者の環境はRTX 5060tiとRTX3060のデュアルGPU環境であるが、5060tiがトレーニング時に使用されるとCUDAやPyTorchのバージョンに起因するエラーが発生したため、RTX 3060を使用するようにGPUを指定した。`--gpus 'device=1'`

```bash
ns-train splatfacto --data  workspace/colmap_output --output-dir workspace/train_output
```

### 2.1.5 3DGSモデルのエクスポート
作成した3DGSモデルは、PLYファイル形式でエクスポートできる。`Export`タブから `Generate Command`を選択すると、エクスポート用のコマンドラインが表示される。

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4072158/0574ea9e-a17c-4267-a8a7-b91795b811db.png)

上記をコピーして実行する。

```
ns-export gaussian-splat --load-config workspace/train_output/colmap_output/splatfacto/2026-02-15_042150/config.yml --output-dir workspace/splat/ 
```

エクスポートに成功すると、指定したディレクトリに`splat.ply`が出力される。

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4072158/17c24e50-3f6c-4639-8aff-5c3e28fd27bf.png)


### 2.1.6 SuperSplatで出力した3DGSモデルを確認する
出力した3DGSモデル(.ply)ファイルをブラウザで利用可能な3DGS編集ツールSuperSplatに取り込んで確認する。

https://superspl.at/editor

`splat.ply`をドラッグ&ドロップして正常に表示されればOK。

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4072158/38d25661-6bec-4dc2-b332-27c6d2de4095.png)

## 2.2 PLYファイルのUSDZ形式への変換
3DGSのPLYファイルは、そのままではNVIDIA Omniverseで扱えないため、NVIDIAが提供している「3DGRUT」というツールでUSDZ形式に変換する。

https://github.com/nv-tlabs/3dgrut.git

公式サイトの手順に従い、Dockerイメージをビルドして起動する。

```bash
git clone --recursive https://github.com/nv-tlabs/3dgrut.git
cd 3dgrut
docker build . -t 3dgrut
xhost +local:root
docker run -v --rm -it --gpus 'device=1' --net=host --ipc=host -v $PWD:/workspace --runtime=nvidia -e DISPLAY 3dgrut
```

変換を実行する。

```bash
python -m threedgrut.export.scripts.ply_to_usd ./splat.ply --output_file ./output.usdz
```


## 2.3 NVIDIA Omniverseに取り込む
### 2.3.1 NVIDIA Omniverseのダウンロードと起動

NVIDIA Omniverse（Isaac Sim）のビルド済みバイナリを以下のサイトからダウンロードする。

https://docs.isaacsim.omniverse.nvidia.com/5.1.0/installation/download.html

今回は Linux (x86_64) の 5.1.0 を選択。

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4072158/78b15454-d12a-461d-b1ec-35fd5067f366.png)

ダウンロード完了後、zipを展開して以下のコマンドを実行する。

```bash
$ ./isaac-sim.selector.sh 
```

Isaac-simを選択して`START`。

# 3. まとめ
本記事では、スマートフォンで撮影した動画から3D Gaussian Splattingモデルを作成し、NVIDIA Omniverseへ取り込む手順を解説した。nerfstudioを用いることで、コマンド数回の実行で3DGSの生成が可能であり、生成過程はWebブラウザ上でリアルタイムに確認できる。出力されたPLYファイルは、3DGRUTを用いてUSDZ形式に変換することで、Omniverse上で読み込めた。
