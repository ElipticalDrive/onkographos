Summary
Complete end-to-end Gaussian splatting pipeline for photo-realistic zone visuals. Splats are trained from LiDAR-backed RGB keyframes captured by the mapper and rendered as an optional layer in the web editor and Unity navigator, with toggleable visibility.
Status: ✅ Implementation complete — All code functional, all tests passing (42/42). Ready for device/GPU verification.
Architecture
```
Mapper (iOS)              Training Worker          Web / Unity
  ↓ capture                  ↓ GPU training          ↓ rendering
transforms.json     →     gaussian-splat.spz   →   GaussianSplats3D
+ depth + conf.          (nerfstudio/gsplat)       aras-p/Unity
```
