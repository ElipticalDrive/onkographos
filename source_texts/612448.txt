The combined XYZ/first-attribute fallback recreates active output buffers for every batch. Extract that fallback and reuse one private output array per recording call, copying each active prefix to its original unified staging offset before overwrite. With four-wide batches and 19 attributes, active/dummy output creation requests drop from 20 to 5 (15 MiB fewer summed descriptors at 262,144 cells).
Preserve the empty guard, preferred packed/fused priority, scalar/two/four-channel kernels and empty-tail semantics, unchanged absent-slot helper, input recycling, copy regions and transfer/submit/map/wait counts. Arrays remain private to each call. The first active array is now created before the first batch upload; subsequent batches introduce reuse dependencies in the existing encoder. Source requests and descriptor sums are established; latency and physical/peak memory savings are unmeasured.
Validation: 332 native image/voxel/readback/filter/facade tests; 19,406,168 guarded raw original/CPU words, 285,334,110 guarded original/current fallback/preferred recorder comparisons and 803,088 concurrent owned words. Boundary tests include all tail widths, zero attributes, 31 attributes, NaN/signed-zero bits, upload recycling and owned results. All-features/all-targets Clippy, CPU-only/minimal/CI WASM, formatting and whitespace pass. Source audit checks 486 unchanged original GPU/image files, exact original selector/fallback restoration and 490 source/executable hashes. Fixtures guard the XYZ prefix and exercise attribute recording; public combined-call regressions additionally pass. No latency benchmark was performed.
