Affected area
Rendering / Editor environment settings
Problem
The current sky-authoring workflow is difficult to use reliably. In particular, replacing the sky material does not work as expected, leaving the user unable to configure the desired sky through the normal editor workflow.
The Environment settings already expose a skybox material slot and a built-in procedural default. This report concerns the reported failure of material replacement and the need for a clearer environment model; it is not a claim that a material slot is entirely absent.
Reproduction workflow to verify
Open a scene and its Environment settings.
Select or drag a different sky-compatible material into the skybox material slot.
Check that the selected asset and the rendered sky both change.
Save and reopen the scene, then compare the Scene view, Game view, and built Player.
The exact affected build and a minimal reproduction material still need to be attached. The cause of the assignment failure has not been established.
Expected workflow
Provide a clear, Unity-inspired sky/environment type selector with three explicit choices:
Physically based sky: configure the atmosphere and sun through parameters appropriate to a physical sky model.
Material-based skybox: assign a sky material and edit its supported shader parameters.
Cubemap: assign a cubemap asset directly, with appropriate orientation and intensity controls.
The current procedural sky should not be presented as a physically based model unless it actually implements one.
Requested changes and acceptance
Fix material selection, assignment, and propagation to the renderer so replacing a supported sky material produces the expected visible result.
Show the settings relevant to the selected environment type and make the active source unambiguous.
Report invalid or unsupported assets clearly, rather than silently retaining or substituting a different sky.
Preserve the selected type, asset references, and parameters through scene save/reload and game builds.
Keep Scene view, Game view, and Player rendering consistent, and make the relationship between the visible sky, ambient lighting, and reflections clear.
Verify material replacement and type switching without requiring an editor restart.
