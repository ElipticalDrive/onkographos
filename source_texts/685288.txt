# Voxel Display

A virtual 64x32 voxel display using SVG. Built on [heerich](https://github.com/meodai/heerich).  Inspired by the [Tidbyt](https://tidbyt.com/).

**[Live Demo](https://mberg.github.io/voxel-display/)**

## Install

```bash
npm install voxel-display
```

## Quick Start

```html
<div id="display"></div>
<script type="module">
  import { VoxelDisplay } from 'voxel-display'

  const display = new VoxelDisplay({
    container: document.getElementById('display'),
    width: 32,
    height: 16,
  })

  // Draw a pixel
  display.setPixel(10, 5, 1)

  // Render
  display.renderTo()
</script>
```
