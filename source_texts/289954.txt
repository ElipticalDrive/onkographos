An octree-based method is presented for the automatic grid generation and CFD solution of flows around complicated geometries.This method decouples the input surface and resultant volume grid so that the user need only be concerned with the actual input geometry and flow conditions.To encourage its use as a design tool, a complete parametric aircraft specification has been added to rapidly generated well-formed input geometries and model realistic aircraft shapes; support is included for embedded boundary conditions to handle jet engines and propellers.Object-oriented programming is used for the implementation, and coarse-grain parallel computing code has also been used to reduce the time required for the computation.
