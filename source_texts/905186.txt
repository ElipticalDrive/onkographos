Hi,
We do have simpler shapes including spheres and ellipsoids, which are in the primitive strokes category. For these simple primitives, we use the analytical formula of their SDFs.
And when u calculate the sdf, u can directly find the stroke which interact with the query points
Do you mean applying the ray-SDF intersection test instead of ray marching of the SDF volume? Indeed this can lead to a faster finding of intersection points for simple SDFs, however for more complex shapes, there may not exist an analytical formula to compute the intersection point, and some kind of root finding scheme is required, which is not computationally cheaper than the current method. In addition, using ray tracing will lead to a surface-based rendering model, which can be more difficult to optimize than the volume-based rendering model in this method. Considering these points, we end up using ray marching, which also allows it to be adapted to arbitrary shapes of strokes.

Hi,
It does not compute the SDF value twice, but computes the SDF gradient if the adaptive scaling is enabled (inv_scale_radius=true and enable_multiscale=true). We use the gradient of SDF function (a unit vector representing the normal direction) and multi-scale vector to estimate how much the SDF is stretched, and modify the radii used to compute the alpha value.

__device__ static float2 sdf_cubic_bezier(float3 pos, float3 A, float3 B, float3 C, float3 D, float r1, float r2)
{
constexpr float step = 1.0f / num_samples;
float dist_min = 1e9f;
float t_min = 0.0f;
float t_start = 0.0f;
float3 segment_start = point_cubic_bezier(t_start, A, B, C, D);
for (int i = 1; i <= num_samples; i++) {
float t_end = i * step;
float3 segment_end = point_cubic_bezier(t_end, A, B, C, D);
float2 dist_and_t = point_segment_distance(pos, segment_start, segment_end);
if (dist_and_t.x < dist_min) {
dist_min = dist_and_t.x;
t_min = t_start * (1.0f - dist_and_t.y) + t_end * dist_and_t.y;
}
t_start = t_end;
segment_start = segment_end;
}
float3 P = point_cubic_bezier(t_min, A, B, C, D);
float dist = length(P - pos);
float r = lerp(r1, r2, t_min);
return make_float2(dist - r, t_min);
}
