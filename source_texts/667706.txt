Describe the project you are working on
3D enviroments
Describe the problem or limitation you are having in your project
Volumetric fog sometimes looks unnatural and out of palce
Describe the feature / enhancement and how it helps to overcome the problem or limitation
change in godot/servers/rendering/renderer_rd/shaders/environment/volumetric_fog_process.glsl to use anisotropy in fog accumulation calc
```
float transmittance = exp(-d * fog.a);

float anisotropy_factor = 1.0 - params.phase_g;

vec3 emission = ((fog.rgb - fog.rgb * transmittance) / max(fog.a, 0.00001));

fog_accum.rgb += emission * fog_accum.a * anisotropy_factor;
fog_accum.a *= transmittance;
```
Describe how your proposal will work, with code, pseudo-code, mock-ups, and/or diagrams
Note: Same volumetric fog parameters except for density that has to be change in order to compensate the accumulation
