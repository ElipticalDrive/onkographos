How to load
```

  baseline: 'VoxelSpace';
  repository: 'github://pavel-krivanek/VoxelSpace/src';
  load.
```
How to run
Copy maps into the image directory and then evaluate:
```
VoxelSpaceMorph new openInWindow.
```
