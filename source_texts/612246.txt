Closes #24. Part of M0: Skeleton.
Summary
The sparse 8³ brick store from ADR 0002, and a test Planet that every machine generates bit-identically.
```
crates/
├── brick-store/   # NEW leaf crate: storage only, no deps, no GPU
│   ├── coord      # VoxelCoord / BrickCoord (i32, floor div; overflow panics in every profile)
│   ├── brick      # occupancy + palette Materials (1/2/4/8 → 16-bit), uniform = flag only
│   └── store      # hash index; iteration only via sorted_coords()
└── planet-gen/
    ├── generate_brick(seed, coord)   # pure; GENERATOR_VERSION = 1
    ├── clippy.toml                   # bans std transcendentals, powi/powf, HashMap/HashSet
    └── tests/golden.rs               # 15 committed brick hashes (FNV-1a over canonical content)
.github/workflows/ci.yml
+ determinism: {ubuntu, windows} × {debug, release} → same golden hashes
```
brick-store is its own crate so that planet-gen and, later, sim can both use it without a dependency cycle.
The test Planet:
```
generate_brick(seed, coord)
  far outside / deep inside the surface band → uniform brick (no sampling)
  otherwise, per Voxel: integer-hash value noise (3 octaves) + sqrt distance
    → air / soil (4 Voxels) / rock
```
1500-Voxel radius (300 m across).
Only + - * /, sqrt and exact int↔float casts. No libm is needed, and clippy blocks the std transcendentals.
