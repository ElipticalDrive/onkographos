Goal
Fix actual missing terrain/cliff faces, limited vertical streaming, and bland single-texture distant terrain seen in November 5 gameplay. Create real highland relief without faking mountains only in LOD.
Implemented
Surface-aware vertical residency: for opt-in --torus-test-ne --distant-terrain, find min/max authoritative surface heights over every 16×16 hex column and stream all Y sections from a section below the lowest surface up to the highest. Bounded column cache, invalidated after torus rebase. Normal no-LOD streaming unchanged.
Shared near geology: Grass on low gentle surfaces, Rock on steep/high surfaces through the authoritative deterministic periodic source. Deeper layers still Soil/Rock.
Distant geological materials: LOD surface triangles choose existing granite vs grass/soil-top textures using altitude and slope; no new texture dependencies.
Mountain belts: new periodic regional uplift mask combined with narrower ridgeline field, up to 250m of additional uplift. Plains elsewhere remain possible; this is a new experimental worldgen revision (3), incompatible with any hypothetical persisted terrain from older algorithms.
Regression tests: local section-height coverage, shared surface cover, and large-region mountain height (>320m) and total relief (>=120m) for seed 42.
CI
Mountain-code commit 66511f9421e96172e3c708a058f49b7f19a8d35e passed GitHub Rust foundation workflow. Latest documentation-only commit checks are running.
Native acceptance
git fetch origin
git switch feature/mountain-surface-residency-materials
cargo test
cargo run --release -- --torus-test-ne --distant-terrain --stream-budget 4
Record 30–60 seconds of hills, visible rock, cliffs and F12 resident markers; copy F2 log if holes or stalls occur.
Remaining limits
Hex-to-triangle seam is not guaranteed watertight; requested-radius mask can still temporarily hide LOD while resident sections are filling; long cliff columns may increase CPU section work; no 3D far caves/overhangs or persistence, snow, vegetation, tectonic erosion. Keep as a draft, stacked on draft PR #73; do not merge without Windows visual verification.
