Motivation
Replace the old padded 3x chunk world generation used to extract a single chunk with a chunk-local generator to reduce memory/CPU and make chunk generation explicit and testable.
Provide a chunk-focused API so generation can be run per-chunk deterministically and allow lightweight neighbor context (halo) where needed for seam continuity.
Split heavy hydrology/vegetation/material passes into chunk-scoped variants that can operate on deterministic local data rather than a full temporary world.
Description
Introduced generate_chunk_direct(seed, chunk_coord) -> Chunk and routed generate_chunk to call it, removing the old generate_world(config) padded extraction path.
Added generate_chunk_from_config to run the procgen pipeline on a single chunk-sized World and return the generated Chunk.
Factored hydrology construction into build_hydrology_cache_impl(...) and added build_hydrology_cache_for_chunk(...) which uses a 1-voxel halo (pad_x = 1, pad_z = 1) instead of the previous full padding.
Added chunk-scoped wrapper entry points (cave_carve_pass_chunk, surface_layering_pass_chunk, vegetation_pass_chunk) and routed chunk-local generation through these so stage intent is explicit and can be specialized later.
Added a regression test independently_generated_chunks_keep_boundary_columns_continuous which independently generates adjacent chunks and asserts boundary column voxel parity on east/west and north/south seams.
Testing
Formatted code with cargo fmt --all and it completed successfully.
Ran cargo test independently_generated_chunks_keep_boundary_columns_continuous -- --nocapture and it passed.
Ran cargo test chunk_border_waterline_uses_global_context -- --nocapture and it passed (existing global-context seam test remains green).
