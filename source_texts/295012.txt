"Before" GPU bytes are the same quad count × 216 B: the mesher does not change, so the quad count is the same. The new [GPU MESH] log line gives the "after" number.
Changes
16 bytes per quad, not 8. Each corner has 18 bits of light and AO (6 each), and 8 bytes is not possible without a change to the light values. The 12 light fields are exact integer ratios (AO is k/42, light is k/60), so the decode gives the same f32 values bit for bit.
vs_chunk in voxel.wgsl reads the quads from a per-chunk storage buffer (16-byte header = chunk origin) and makes the 6 vertices of the 2 triangles: draw(quads × 6), no vertex or index buffer. The cylinder and the border keep the old pipeline.
The upload packs the CPU mesh. The incremental edit, the depth-off sort and the GPU debug highlight still work on the CPU VoxelVertex mesh. A mesher that writes packed quads is part of perf: mesh from a dense padded block array with binary greedy meshing #593.
No arrays in vs_chunk. The first version used var<private> tables, and the frame was 60% slower (2.93 ms) on Metal. Bit constants fixed it.
Tests (zig build test now runs the voxel mesher tests): a round trip of every vertex of naive and greedy meshes with classic, moore and propagated AO (packQuad → unpackCorner, the Zig mirror of vs_chunk), and a check that the shader's bit constants match face_layouts.
gpu: BindGroup.release on native and web. The web bridge also drops the handle of a destroyed buffer. setBindGroup with no dynamic offsets now passes 2 arguments: with an explicit undefined, Chrome 154 threw "cannot be converted to a sequence" from the render loop.
Test plan
Pixels: 11 scenes, main against this branch (Metal, --async-chunks=off --debug=off): 9 byte-identical (framespike, FXAA, MSAA 4, AO classic and moore, cave skylight, glowstone, naive meshing, hilly). dig_relight and depth-stencil off: 1 pixel each, off by 1/255. A debug check showed every packed quad decodes to the exact vertex, so the 1 pixel is a rasterization difference at a triangle edge.
Native: build, headless TAS, 5 s GPU smoke test. zig build test passes.
Web: the voxel WASM renders in Chrome 154 with no errors.
Goldens CI (lavapipe).
