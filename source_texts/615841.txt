Contributor
Replaces naive per-voxel cube triangulation (12 tris/voxel, non-watertight) with AMR boundary-face meshing that emits only exposed faces with vertex dedup. Adds rendering of the original STL/STEP mesh as a semi-transparent reference overlay.
New: js/amr-surface-mesh.js
generateUniformSurfaceMesh() — boundary-face extraction from uniform voxel grid with indexed output (positions, normals, stress, indices)
generateAMRSurfaceMesh() — handles variable-size leaf cells; subdivides faces at coarse↔fine transitions to prevent cracks
checkWatertight() — validates every undirected edge appears exactly twice
indexedMeshToTriangles() — converts indexed mesh to flat triangle array for STL serialization
Vertex dedup via quantized position keys. Per-vertex stress averaged from contributing boundary cells.
Refactored: js/exporter.js
generateSTL() delegates to generateUniformSurfaceMesh() → indexedMeshToTriangles() instead of addCubeTriangles() per voxel
Eliminates redundant internal faces; output is watertight by construction
Modified: js/viewer.js
Stores model.originalVertices on import and builds GPU buffers for the original triangle mesh
Renders reference mesh as 25% alpha overlay via new uAlpha uniform in the mesh fragment shader
Public API: setReferenceModel(vertices, bounds), toggleReference()
```
// Single voxel → 12 triangles, watertight, deduped to 8 vertices
const mesh = generateUniformSurfaceMesh({ densities: new Float32Array([1.0]), nx: 1, ny: 1, nz: 1 });
// mesh.watertight === true
// mesh.indices.length === 36 (12 tris × 3)
// mesh.positions.length === 24 (8 verts × 3)
```
Tests
14 new tests (42–55) covering uniform/AMR mesh generation, vertex dedup, watertight validation, stress mapping, inactive cell exclusion, and triangle conversion.
