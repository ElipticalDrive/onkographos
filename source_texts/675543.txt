# CPU Ray Marcher

A CPU-only, path-traced ray marching renderer, written in Rust: signed
distance field (SDF) geometry, a BVH with interval-based sphere-tracing
acceleration, SIMD-batched primitive evaluation, a unified GGX
diffuse/glossy/mirror/glass material, and a Next Event Estimation + Multiple
Importance Sampling (NEE+MIS) path tracer supporting diffuse lighting,
reflections, and refraction (with total internal reflection and Beer-Lambert
absorption).

## Building

```bash
cargo build --release --workspace
```

## Rendering the demo scenes

```bash
cargo build --release --workspace
./target/release/renderer-cli \
  --scene crates/scene/examples/cornell_glass.ron \
  --out out/cornell_glass_final.png \
  --spp 512
```

A second scene, `crates/scene/examples/phos.ron`, demonstrates that a
character can be built out of nothing but `Sphere`/`Capsule` primitives
chained with `SmoothUnion`: a stylized glass humanoid figure (a nod to
Phosphophyllite from *Houseki no Kuni*) standing in the same room.

```bash
./target/release/renderer-cli \
  --scene crates/scene/examples/phos.ron \
  --out out/phos_final.png \
  --spp 256
```

A third scene, `crates/scene/examples/crystal_forest.ron`, is built to
stress lighting and sky rather than character/CSG sculpting: nine colored
glass crystals (`Intersection(Box3, Box3 rotated 45°)` for an octagonal
cross-section, five different Beer-Lambert absorption recipes — amethyst,
sapphire, emerald, rose, citrine), lit by a distant "moon" `Sphere` light
plus two small saturated accent lights nested at ground level for colored
rim-light through the glass, all enclosed in a hand-built three-band sky
(`Subtraction`-hollowed concentric shells, dusk-to-indigo) with tilted
emissive-box "aurora" ribbons and a few star spheres crossing it — no flat
`environment_radiance` void.

```bash
./target/release/renderer-cli \
  --scene crates/scene/examples/crystal_forest.ron \
  --out out/crystal_forest_final.png \
  --spp 96
```

A fourth scene, `crates/scene/examples/backrooms.ron`, is the odd one out:
deliberately all-diffuse, no glass or mirror anywhere. It's a 60-unit
liminal corridor (sickly yellow wallpaper, damp carpet, a low drop
ceiling, alternating support pillars) lit by five recessed fluorescent
`Quad` panels. There's no fog/extinction in this renderer, so the "fades
into darkness" look at the far end is just physically-based light falloff
between panels -- the corridor is fully sealed (a real end wall, not a
void escape), it's simply far enough from every light to render near-black.

```bash
./target/release/renderer-cli \
  --scene crates/scene/examples/backrooms.ron \
  --out out/backrooms_final.png \
  --spp 320
```

The renderer writes progress to stdout and overwrites `--out` periodically
during the render (so you can watch it converge), then writes the final
image once the target spp is reached.
