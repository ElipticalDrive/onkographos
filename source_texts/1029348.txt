Summary of Changes
This PR resolves layout/rendering bugs across the Video and Luma NeRF pipelines, aligns quilt focus math with the WebGL preview, ensures host-agnostic Blocks metadata publishing, and completes a full feature assessment across all input modes (Video, Images, and Luma NeRF).
1. Luma NeRF Pipeline Fixes (LumaLightfieldDownloader.tsx)
Prevent Infinite Re-render Loop (React Error #185): Removed premature onDone() call inside the fetch catch block which previously caused downstream components to loop infinitely when frame extraction failed.
Safe Payload & Zip Extraction: Added defensive chaining guards around Luma API metadata parsing and filtered ZIP contents strictly for valid image files (.jpg, .png, .webp), preventing silent failures on unexpected archive structures.
Safe Range Calculation: Fixed negative index frame range calculations when processing small or empty frame sequences.
2. Video Pipeline Aspect Ratio (LightFieldFocusViewer.tsx)
Dynamic Frame Aspect Ratio: Updated container styling to derive aspect ratio dynamically from video source frames (width / height), preventing letterbox squishing on widescreen captures.
3. Quilt Parallax Scale Fix (QuiltImage.tsx)
Synchronized Export Scaling: Aligned focusValue calculation directly with active focus state, removing the 10x scale mismatch between the WebGL preview and 2D canvas exports.
4. Host-Agnostic Blocks Metadata (PublishToBlocksButton.tsx)
Replaced hardcoded domain strings with dynamic window.location.origin resolution for seamless publishing from custom domains, local setups, or community forks.
Comprehensive Assessment & Testing
Video: Tested widescreen video sweeps end-to-end on Looking Glass Go hardware.
Images: Verified image sequence upload, frame selection, focus editing, cropping, and export. Confirmed working as expected with no regressions.
Luma NeRF: Verified with public Luma NeRF capture URLs (verified successful frame unzipping, range selection, cropping, and focus editing without crash).
