Description
기존 FogComponent의 Disabled/Linear/Exp/Exp2 설정을 실제 메쉬 렌더링 결과에 반영한다. Scene에서 RenderFog를 제출하고 DX11ScenePreparation이 상수 버퍼에 값을 올리지만, 현재 Mesh.hlsl은 Fog를 적용하지 않는다.
Tasks
Mesh.hlsl에서 카메라와 월드 위치의 거리로 Linear/Exp/Exp2 fog factor를 계산한다.
기존 FogColor, density, start/end distance, mode 상수와 셰이더를 연결하고 비정상 범위 입력을 안전하게 처리한다.
조명 계산 후 fog 색상을 혼합하되 alpha mask/transparent 동작을 유지한다.
Fog 없는 장면과 각 mode의 근거리·원거리 메쉬를 비교 검증한다.
Done Criteria
FogComponent의 mode·color·distance·density를 변경하면 메쉬의 거리별 렌더링 결과가 즉시 반영된다.
Disabled에서는 기존 장면과 동일하며, Linear/Exp/Exp2는 서로 구별되는 거리 감쇠를 보인다.
