FDS script (.fds) and voxelization scripts (.py) to input forest TLS point clouds into FDS. In particular, these scripts have been used to input the TLS point clouds from 2 Mediterranean forest stands, available in https://doi.org/10.5281/zenodo.20268505  The method involves a 2-step voxelization in order to distribute the bulk density of the vegetation as a function of the number of returns in the point cloud (.py files). The vegetation scenarios are then input to FDS as .bdf files. The simulation parameters are defined in the .fds file.

Description
FDS script (.fds) and voxelization scripts (.py) to input forest TLS point clouds into FDS.
In particular, these scripts have been used to input the TLS point clouds from 2 Mediterranean forest stands, available in https://doi.org/10.5281/zenodo.20268505
The method involves a 2-step voxelization in order to distribute the bulk density of the vegetation as a function of the number of returns in the point cloud (.py files).
The vegetation scenarios are then input to FDS as .bdf files. The simulation parameters are defined in the .fds file.
