Summary
Follow-up to #2-#20. The feasibility doc's own "what this explicitly is NOT" list (Section 23) named volumetric media as one of the pieces missing from this POC's material/light/shape coverage. This adds the simplest real version: a single, uniform fog filling the entire scene volume (not attached to any one object's geometry), avoiding the boundary-tracking problem a more general per-object medium would need.
The technique is textbook free-flight distance sampling: each bounce draws a random scattering distance t = -ln(1-u)/sigmaT from the medium's own exponential transmittance distribution and compares it to the surface hit's own distance. This single stochastic comparison makes both outcomes come out unbiased with no extra transmittance multiplier needed in either branch - reaching the surface without scattering needs weight 1 exactly (survival probability under an exponential distribution IS the transmittance), and a scattering event needs weight sigmaS/sigmaT exactly. Both derivations were worked through algebraically before being committed to code.
A scattering event spawns a continuation ray via sampleUniformSphere() (a genuinely different sampling domain from every existing BSDF/phase function - every other direction sampler orients around a surface normal; a volume scattering point has none) with an isotropic phase function, and does its own NEE against the light list using the same sampleAreaLight()/MIS machinery every surface material's NEE branch already shares. Getting this consistent needed one more fix: shadow rays are a separate, deterministic occlusion test that doesn't automatically account for the medium's own attenuation along their length, so an explicit exp(-sigmaT*shadowDist) transmittance factor was added to every NEE contribution in the shader (the new volume one, and both existing surface ones), or a foggy scene would have looked inconsistent.
Result
Verified three ways: an A/B render with fogSigmaT = 0 reproduces the previous committed render pixel-plausibly identically. The committed scene (sigmaT = 0.05) shows a subtle, physically-plausible atmospheric haze. A third render at sigmaT = 0.25 (verification only, not committed) shows a dramatically thicker haze with steeper depth falloff, confirming the effect's strength scales with the physical parameter correctly.
docs/METAL_GPU_FEASIBILITY.md section 26 records the full details.
Verification
Both the ad-hoc clang++ build and the CMake RT_BUILD_METAL target build and render correctly
A/B comparison (fogSigmaT = 0) confirms the medium path is a true no-op when disabled
Strength-scaling comparison (0.05 vs 0.25) confirms the physics responds correctly to the extinction parameter
