3DGSをブラウザで見られるようにした
3D Gaussian Splatting（3DGS）をブラウザで表示できるWebGPUビューアを作って公開した。
デモ: https://amabito.github.io/hyper-viewer/
GitHub: https://github.com/amabito/hyper-viewer
ライセンス: Apache 2.0（商用利用可）
PLYファイルをドラッグ&ドロップするだけ。
従来の課題
3DGSモデルを表示するには:
Copied!
```
従来:
├── Python環境構築
├── PyTorch + CUDA インストール
├── ラスタライザのビルド
└── ビューアスクリプト実行

→ 環境構築だけで1時間以上
→ GPUがないPCでは動かない
→ 他人に見せるのが大変
```
解決策
Copied!
```
HyperViewer:
├── URLにアクセス
├── PLYファイルをドロップ
└── 表示される

→ インストール不要
→ スマホでも動く
→ URLを送るだけで共有可能
```
