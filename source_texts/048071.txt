What
A complete signed-distance-field terrain workstation running in the browser (zero dependencies):
Multifractal mountain synthesis — seeded Perlin ridged/hybrid multifractal + domain warp + super-elliptical peak mask + directional tilt gradient. Octaves auto-clamped so every feature is ≥ 3 voxels.
True 3D SDF voxelisation — narrow-band fast-sweeping Godunov redistancing (verified |∇d| ≈ 1), 100×64×100 m test domain, up to 288²-class grids (~24 M cells) in a Web Worker.
SDF-native hydraulic erosion (not mesh/heightmap erosion): droplets flow on the implicit isosurface via tangent-projected gravity + Newton reprojection onto the evolving zero level set; cuts/deposits are volumetric stamps into the distance field; CFL clamps, waterfall bypass, pit fill, evaporation; talus slumping; then D8 priority-flood drainage + stream-power incision E = K·A^m·S^n for real dendritic channel networks — all carved back into the SDF, which is re-redistanced after every batch.
SAT maps (Gaea-style): flow, sediment, wear, peaks, pointiness, slope, height, wetness — packed 2×RGBA8, driving triplanar material (rock/grass/talus/sediment/snow, wetness darkening, channel streaks).
Renderer — WebGL2 sphere tracing of the 3D distance texture with soft shadows, AO, snow line, fog, plus an SDF inspector (clip plane, distance contours, voxel grid).
Professional dark UI — schema-driven control rail, pipeline console, live progress, SAT map gallery + lightbox, and a resolution ↔ cut audit: per-column cut budget is enforced inside the stamp kernel (≤ 0.35 vox/step, ≤ (2.5+6·depth) vox/column), and the audit re-measures the actual heightfield change — max cut vs budget and channel depth in voxels are reported and badge-checked.
Exports — in-browser ZIP: 16-bit heightmap, all 8 SAT maps, u16 SDF volume + JSON header, params, AUDIT.md.
Validation (node harnesses, deterministic per seed)
node tools/worker-e2e.mjs 192 130000 (the actual browser worker): grid 192×123×192, voxel 520.8 mm, channels 0.61 m ≈ 1.17 vox, max cut 4.50 m vs 5.21 m budget, zero degenerate columns, ZIP/PNGs header-verified.
node tools/sim-test.mjs: post-erosion |∇d| mean 0.96 (field stays a true distance field).
Preview: docs/preview_eroded_192.png — dissected massif with dendritic drainage.
Run
node server.js → http://localhost:8080 (live preview is running in this session).
