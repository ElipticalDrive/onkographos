# Analytical Gaussian Rasterization

A differentiable PyTorch/CUDA rasterizer for 3D Gaussians that analytically
integrates each projected Gaussian over the pixel footprint. In addition to RGB
color and screen-space radii, it returns alpha-weighted view-space depth and an
alpha image, with gradients for color, depth, and alpha losses. And also adapted a
gsplat inspired batched rasterization.

The package is distributed as `analytical-gaussian-rasterization` and imported
as `analytical_gaussian_rasterization`. It is intentionally distinct from
`diff-gaussian-rasterization`, so both implementations can be installed in the
same environment.
