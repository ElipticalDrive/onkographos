Summary
Phase 0 of the post-pivot roadmap (plan C — Star Citizen hybrid).
Removes the SDF raymarching render path entirely from the engine:
Editor viewport: 5-pass flow (sky → raymarch → mesh → gizmos line → gizmos mesh) reduced to 4-pass (sky → mesh → gizmos line → gizmos mesh)
Standalone RenderPlugin: mirrored — sky + mesh only
All raymarch + tile-cull + GDF cascade infrastructure deleted (raymarcher, tile-cull pre-pass, sparse chunk pool, BVH integration on the render side)
LoC delta: −9058 lines (−9113 deleted, +55 inserted).
ome_sdf crate is preserved (re-purposed as SDF brushes for voxel authoring). It will feed the Phase 2.5 voxel + Dual Contouring pipeline. SDF primitives, components (SdfSphere/Box/Capsule/Cylinder/Torus/Plane), and WGSL primitives stay.
ome_bvh is retained for now (used by ome_physics and ome_world); will be reviewed when Rapier integration replaces the physics broadphase.
