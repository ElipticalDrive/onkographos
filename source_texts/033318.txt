Owner
This advances reusable rendering, physics, detail selection and streaming. Camera changes can now select Source/Half/Quarter meshes through retained GPU geometry, collision shapes can be prepared on a bounded worker and published only for the current source, and voxel snapshots share unchanged chunk payloads. A bounded single-bounce diffuse-light reference feeds the Vulkan shader and responds to sun changes and opening/closing an enclosure.
The queue corrections cover reset, rapid reversal and buffered-result retention. Numeric LOD checks reject unrepresentable projection/hysteresis inputs and use stable view-forward depth. An opt-in native/Android detail check exercises nine phases including perspective/orthographic zoom, edits, zero extent and renderer recreation; CI requires its terminal pass marker.
Validation:
326 workspace Rust tests pass;3 existing gates remain ignored. Strict workspace Clippy, formatting and documentation checks pass.
Native Vulkan geometry-cache,11-frame instancing,30-frame shadow and37-frame indirect checks pass with validation enabled. The integrated54-frame detail check selects all three LODs and passes all9 phases.
OnePlus13 Android16: indirect off/on, sun movement, enclosure changes and HOME/resume pass at7211b7d; direct ARM64 asynchronous collision creation/removal/contact/falling passes at9cf26a1.
Combined ARM64 APK at1abe19b passes page-size/alignment/signature checks. OnePlus13 detail check passes1080 presented frames/all9 phases, with actual HOME/resume and explicit renderer recreation. All9 phase screenshots captured; this is functional validation, not complete transition-quality acceptance.
The lighting path is opt-in and limited to bounded unit-voxel diffuse bounce; measured full preparation/upload is roughly39–45ms on the phone. It does not implement reflections or complete M4. LOD error/dilation are heuristics, with abrupt transitions and small-cavity limitations. Collision publication still needs production frame-loop budgeting. Shared snapshots retain logical source-byte accounting; no mobile memory or thermal gain is inferred from host sharing tests. The separate background-lighting controller experiment is outside this PR.
