A browser-native 3D visualizer and lightweight analyzer for plasma simulation output from PIC and MHD codes. Volume raymarching, orthogonal slices, and GPU field-line tracing run on WebGPU with no install; data is read from pypic-blessed formats (Zarr v3) under the same canonical field schema, so the browser view and the Python analysis agree by construction.

Description
A browser-native 3D visualizer and lightweight analyzer for plasma simulation output from PIC and MHD codes. Volume raymarching, orthogonal slices, and GPU field-line tracing run on WebGPU with no install; data is read from pypic-blessed formats (Zarr v3) under the same canonical field schema, so the browser view and the Python analysis agree by construction.
