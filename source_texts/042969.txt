Motivation
Provide a minimal, playable browser-based voxel foundation with deterministic terrain, chunked meshing, and an interactive player and HUD.
Establish core content (blocks, items, recipes, creature entity) and persistence for future gameplay features and iteration.
Description
Add project scaffold and build config including package.json, tsconfig.json, vite.config.ts, index.html, and README.md with run instructions and project overview.
Implement rendering and game loop in src/main.ts with Three.js scene setup, daylight, particle effects, input handling, and save/load integration.
Add deterministic world generation and chunked voxel meshing in src/world/World.ts and src/world/Chunk.ts (hidden-face meshing with per-face vertex colors and separate transparent/opaque meshes), plus noise utilities in src/utils/Noise.ts.
Add gameplay systems: block registry (src/blocks/BlockRegistry.ts), items (src/items/ItemRegistry.ts), inventory (src/inventory/Inventory.ts), crafting recipes (src/crafting/Recipes.ts), a simple wandering creature (src/entities/Glowhorn.ts), player controller (src/player/Player.ts), HUD (src/ui/Hud.ts), styles (src/styles.css), and localStorage save system (src/save/SaveSystem.ts).
Testing
Performed a full build/typecheck with the project build script via npm run build, which runs tsc --noEmit and the Vite build, and it completed successfully without type or build errors.
