This PR adds random-walk BSSRDF option that uses glass BSDF for surface scattering. (High-order scattering still uses diffuse approximation though)
Another changes:
Add volume anisotropy parameter for random-walk BSSRDF (and corresponding reparametrization)
Move random-walk SSS to the separate OSL closures: randomwalk_diffuse and randomwalk_glass
Unfortunately, there was a bug in Dwivedi sampling and it is disabled for now
Fix SSS taken into account after diffuse bounce even when diffuse bounce set to 0 #1779
About Dwivedi sampling:
When Dwivedi sampling is used instead of classical sampling, it gives severe fireflies on low-probability paths. When it is accurately mixed with classical sampling using MIS, some fireflies still remain.
In the previous build, the pdf of Dwivedi sampling was not taken into account properly, which removed fireflies, but made renders incorrect (slightly brighter).
Now, if we want to fix Dwivedi, we need to compare the renders carefully against the references from this PR.
