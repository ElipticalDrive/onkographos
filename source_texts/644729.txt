# Priority-Based Bitrate Allocation for VASTile

An end-to-end simulation pipeline for testing Priority-Based Bitrate Allocation (IPBA) in VASTile (Variable-Sized Tile) 360-degree video streaming.

## Overview
This project simulates adaptive bitrate streaming for 360-degree video using a custom tiling mechanism (VASTile) and a priority-based bitrate allocator. It aggregates real user viewing traces (from the 2019-360dataset) to generate heatmaps, calculates tile priorities based on viewer attention (FoVf, FoVb, Buf), and intelligently distributes available bandwidth.

The core contribution is the **Iterative Priority-Based Allocation (IPBA)** algorithm, which redistributes leftover residual bandwidth to lower-priority tiles that would otherwise be dropped, ensuring a smooth and unbroken viewing experience without exceeding the network budget.

## Features
- **Trace Loading & Aggregation:** Parses and aggregates `.csv` viewing traces from multiple users to accurately model real-world viewing behavior for a specific video.
- **VASTile Generation:** Dynamically generates variable-sized tiles grouping regions by foreground (FoVf), background (FoVb), and buffer zones.
- **EWMA Bandwidth Estimation:** Simulates network fluctuations using an Exponentially Weighted Moving Average.
- **Representation Snapping:** Enforces standard representation ladders (e.g., 144p, 360p, 720p, 4K) for strict bitrate compliance.
- **Pass-Based Redistribution (IPBA):** Iteratively upgrades lower-priority tiles with leftover bandwidth while perfectly maintaining strict priority preservation (higher priority always gets >= bitrate).
- **Comprehensive Metrics & Graphs:** Automatically validates the logic and generates publication-ready visualization graphs for:
  - Bandwidth Utilization
  - Priority Preservation
  - Representation Upgrades (Before vs After IPBA)
  - VASTile Layout Mapping

## Usage
Ensure you have the necessary dependencies installed (`matplotlib`, `pandas`, `numpy`).

To run the full end-to-end simulation:
```bash
python src/simulation.py
```

This script will process the user trace data, run the allocation, and output all generated metrics and graphs to the `results/` directory.

## Project Structure
* `src/simulation.py` - The main entry point tying all modules together.
* `src/redistribution.py` - Core implementation of the Pass-Based IPBA algorithm.
* `src/graphs.py` - Matplotlib logic for plotting metrics.
* `src/config.py` - Configuration parameters (bandwidth, representations, dataset selection).
* `2019-360dataset/` - Directory containing real user head-tracking traces.
* `results/` - Output directory for all generated `.png` graphs and `.json` data.
