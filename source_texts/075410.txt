Implements the add-voxelization OpenSpec change — a mesh-native voxelizer produced entirely from cmg-owned geometry + predicates. Built via a multi-agent workflow (core → C ABI → Python/Swift+docs → verify); every stage built and tested with real evidence, and I re-verified the full suite independently.
Core — cmg::voxelize::voxelize(PLC, VoxelOptions) -> VoxelGrid
Exact-predicate classification (the spec's hard requirement): a vertical scanline per xy-column counts crossings against the fan-triangulated boundary using only cmg::robust::orient3d — plane-side sign change and matching edge orientations — with a deterministic (x,y) nudge when any orient3d is exactly 0 (grazing). No epsilon-ray speckle.
Efficiency: triangles bucketed by xy-projection, so each column tests only nearby triangles (~O(cells + triangles)).
Occupancy: cell inside iff an odd number of crossings lie above its center. SDF: exact point-to-triangle distance (Ericson), signed by the parity (negative inside).
Bindings + docs
C ABI: cmg_plc_voxelize + cmg_voxels_* accessors (opaque handle, status codes, never throws).
Python: cybermesh.voxelize(plc, resolution=64, mode="occupancy"|"sdf", pad=1) → NumPy (nx,ny,nz) uint8/float32 grid + origin/spacing.
Swift: CyberMesh.voxelize (source-only; symbol-aligned to the C ABI).
README: documents voxelization and its honest positioning vs OCCT — mesh-native and exact-predicate, but fidelity bounded by the input tessellation; OCCT is the tool for exact curved-surface (STEP/IGES) fidelity.
Validation
tests/test_voxelize.cpp: cube + sphere volume convergence, determinism, watertight no-speckle, SDF sign — 138 tests, 0 failed across default / -Werror / ASan / single-precision and clang++ (independently re-verified from a clean build).
Python voxelize test passes (unit-side-2 cube: occupancy volume 8.000, SDF interior negative / exterior positive).
openspec validate --all --strict green (19 items). The add-voxelization change is archived (spec merged into openspec/specs/voxelization + language-bindings delta), so specs stay in sync with the code.
Deferred (documented non-goals)
B-Rep/exact-surface (CAD) voxelization; hex meshing; marching-cubes/iso-surfacing; octree meshing; conservative GPU-raster semantics; healing non-watertight input; GPU-accelerated classification (SDF is brute-force point-triangle for v1).
