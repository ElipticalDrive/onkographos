Objective
Implement one topology-safe deep-interior contact discriminator for the pinned Tissu MeshCollider on exact current main. This is the sole active implementation axis for the current tunic blocker.
Authoritative base

Evidence and causal hypothesis
The current canonical tunic failure is a finite, fast simulation that falls through to a floor bundle despite step-0 target clearance >= 8 mm. Pinned MeshCollider::resolve only corrects when nearest-surface distance <= thickness. The rejected #2396 nearest-face half-space heuristic moved valid far-outside particles and broke existing native regressions. Research #2397 therefore selected a closed-manifold inside/outside predicate independent of nearest-face sign.
Exact implementation scope
Modify only:
docker/freecad-ci/apply-tissu-contact-fix.py
transient generated Tissu native test/source edits inside the pinned build image as required by that script.
Behavior:
Detect the already-supported closed, two-manifold, consistently oriented mesh state.
Add a deterministic BVH-accelerated point-in-closed-mesh parity predicate.
Use a small fixed set of non-axis-aligned ray directions; do not rely on one axis-aligned ray.
Fail closed when rays disagree or when an intersection is ambiguous/degenerate.
In MeshCollider::resolve, preserve the existing near-surface/outside path unchanged.
Only when m_closedManifold is true, nearest-surface distance is greater than thickness, and parity classifies the point as inside, project to closest point plus verified outward surface normal * thickness and reuse the existing velocity/friction path.
Do not modify Solver::step ordering; no extra solver/collider pass.
Do not change fixture geometry, seams, pins, attachments, cloth mesh, solver iterations/substeps/timestep/gravity/friction, collision triangle budget, thresholds, timeouts, workflow topology, UI/camera gates, or public production ABI.
Mandatory native regressions
Retain every existing MeshCollider.* regression and add focused tests for:
deep-interior point in existing closed tetrahedron projects outside;
far-outside point at (100,100,100) remains unchanged;
existing multi-particle case keeps far-outside particles unchanged while resolving inside particles;
reversed consistently oriented closed tetrahedron/cube remains correctly classified;
open triangle mesh never enters deep-interior correction;
transformed/rotated closed-mesh case remains valid;
parity is deterministic and ambiguous/shared-edge/corner ray cases fail closed.
The native regression command must remain MeshCollider.* and the provenance record must still prove the exact pinned commit.
