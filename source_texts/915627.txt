Summary
This PR introduces a new diamond material system that renders objects with physically-based refraction, total internal reflection, and chromatic aberration effects. The implementation uses ray tracing within the shader to simulate light behavior through a transparent medium.
Key Changes
New diamond material module (src/diamondMaterial.js):
Implements a custom shader material with vertex and fragment shaders for diamond rendering
Uses BVH (Bounding Volume Hierarchy) acceleration structure for efficient ray-geometry intersection testing
Generates a procedural environment map with realistic lighting for reflections
Supports configurable IOR (index of refraction), bounce count, and chromatic aberration
Provides helper functions: createDiamondMaterial(), applyDiamondMaterial(), restoreOriginalMaterial(), and isDiamondMaterial()
Material preset integration (src/main.js):
Added diamond material support to the material preset system
Automatically applies diamond material when 'diamond' preset is selected
Restores original material when switching away from diamond preset
Passes preset-specific parameters (color, dispersion) to the diamond material
Export handling (src/exporter.js):
Temporarily swaps diamond materials back to original materials during GLB export
Ensures exported files contain standard materials compatible with other tools
Restores diamond materials after export completes
Dependencies (index.html):
Added three-mesh-bvh library for BVH acceleration structure support
Implementation Details
The diamond shader performs ray tracing within the geometry to calculate refracted ray directions
Supports two chromatic aberration modes: fast (approximate) and accurate (per-channel IOR calculation)
Uses total internal reflection detection to handle light bouncing inside the material
Environment map sampling provides realistic reflections based on refracted ray directions
Material properties (color, IOR, dispersion) are exposed as configurable uniforms and properties
