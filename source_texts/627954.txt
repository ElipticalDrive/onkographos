Summary
Completed octomap-style voxel grid visualization for stereo-based spatial mapping. The system now renders 3D occupancy information onto the 2D camera feed with proper perspective projection.
Changes
Voxel Grid Projection: Added _voxel_to_2d() method to project 3D voxel coordinates to 2D image pixels using camera intrinsics
Occupancy Visualization: Implemented _draw_occupancy_grid() to render voxels with:
Depth-based color gradient (blue=far, red=near)
Layered rendering from far to near for proper occlusion
Adaptive voxel size based on distance
Voxel Wireframes: Added _draw_voxel_wireframe() to show 3D spatial structure with 12 edges per voxel
Grid Building: Integrated _build_occupancy_grid() into render pipeline to quantize detected objects into voxel space
Visualization Pipeline: Updated render_frame() to build and render occupancy grid before drawing objects
Features
Ground plane perspective grid showing spatial layout
Detected object contours with semi-transparent fill
Octomap-style voxel grid indicating occupied 3D space regions
Proper 3D-to-2D perspective projection for all elements
Distance-aware coloring and sizing
Technical Details
Voxel size: 0.1m for detailed occupancy representation
Projection uses camera matrix (focal length, principal point)
Depth-based sorting prevents occlusion artifacts
Wireframe edges rendered only when corners project into frame
