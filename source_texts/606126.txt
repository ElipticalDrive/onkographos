This PR introduces several cutting-edge Modern OpenGL (AZDO) optimizations to maximize framerate and minimize driver overhead:
Bindless Textures: Modifies AssetManager to manage 64-bit texture handles and residency. The rendering pipeline now passes these handles through CommonUniforms, allowing shaders to sample textures without the standard 'texture unit' binding bottleneck.
GPU-Accelerated Culling & Command Compaction: Implements a compute shader (cull.comp) that performs both frustum and Hi-Z occlusion culling. Instead of the vertex shader simply discarding fragments, this system filters the draw command buffer itself on the GPU. The visible commands are executed using glMultiDrawElementsIndirectCountARB, ensuring only visible geometry is ever processed by the rasterizer. A robust fallback to standard MDI is provided for hardware lacking the indirect count extension.
Zero-Overhead Profiling: Adds include/profiler.h with PROJECT_PROFILE_SCOPE macros. These macros resolve to high-precision scoped timers when PROFILING_ENABLED is defined and completely disappear in release builds.
Performance Documentation: Records the technical rationale and estimated impacts in .jules/PERFORMANCE_LOG.md.
Verified with a full C++ build, shader validation (make glcheck), and the core test suite.
