Summary
Implements Slice 1 of #202: a minimal, runnable physically based path tracer.
This PR establishes the foundational infrastructure for CPU rendering, prioritizing accurate light transport and extensibility.
What's included
New src/render module: structured into image.rs (PPM export), ray.rs (intersection), and integrator.rs (path tracing loop).
Camera integration: uses the existing Camera::ray API to generate primary rays.
Intersection: Möller–Trumbore ray-triangle intersection against ViewScene instances.
Path tracing: recursive diffuse bounces (Global Illumination) with Russian Roulette termination.
Parallelism: uses rayon to parallelize pixel rendering.
Demo scene: a reproducible test (render_demo_cube) that renders a cube on a scaled plane with soft shadows and saves to demo_render_path_traced.ppm.
Verification
cargo test render_demo_cube --release -- --nocapture generates the demo image.
cargo clippy --all-targets --all-features -- -D warnings passes.
cargo fmt --all passes.
Scope & Next Steps (Tracked separately)
This PR strictly implements Slice 1 (Runnable Foundation). The following features from #202 are not yet implemented:
Area lights, HDRI lighting, or configurable bounce depth (Slice 2).
AOVs and Multilayer OpenEXR export (Slice 3).
UV-space texture baking (Slice 4).
UI / Viewport integration. The renderer is currently exposed via a test/module API, not a button in the native Editor.
Closes #202 (partial: Slice 1 only).
Summary by CodeRabbit
New Features
Added rendering that turns scenes into images, with configurable image dimensions, sample count, and maximum bounce depth.
Rendered images include direct lighting, surface colors, and indirect light from bounced rays, with a subtle blue background where rays miss.
Added support for detecting intersections between viewing rays and scene geometry.
Images can be saved as PPM files, with accumulated samples averaged and color values adjusted for display.
