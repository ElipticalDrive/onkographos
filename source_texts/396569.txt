Resolves #168
This PR adds volume rendering of numpy arrays in accordance with #168. It uses the vtkGPURayCastMapper to generate an output volume that can be added to a plotter.
TODO and limitations
Does not currently allow for scalarbars
Currently downscales input data to range 0-255
Add methods for rotation/translation
In general, because the mapper used is different from e.g. the polydata mappers, some standard functionality is not currently available.
No tests available due to no (afaik) intensity data in examples.
No way of changing global opacity level (due to (4.)).
Examples
```
import pyvista as pv

data = <some intensity array data>
p = pv.Plotter()
p.add_volume(data, resolution='[.5, 1, 1])
p.show()
```
or
```
import pyvista as pv

data = <some intensity array data>
pv.plot(data, resolution=[.5,1,1], opacity='linear')
```

Additions
Sigmoidal Opacity Transfer Functions
I also added some more opacity transfer functions - particularly a few different spreads of a sigmoid under 'sigmoid' and 'sigmoid_*' (where * can be numbers 3-10. 'sigmoid' is 'sigmoid_10')
```
import pyvista as pv
from pyvista import examples

vol = examples.download_knee_full()

cpos = [(-381.74, -46.02, 216.54),
        (74.8305, 89.2905, 100.0),
        (0.23, 0.072, 0.97)]

p = pv.Plotter(notebook=True)
p.add_volume(vol, cmap='viridis', opacity='sigmoid')
p.camera_position=cpos
p.show()
```
In contrast to the linear mapping:
```
p = pv.Plotter(notebook=True)
p.add_volume(vol, cmap='viridis', opacity='linear')
p.camera_position=cpos
p.show()
```
