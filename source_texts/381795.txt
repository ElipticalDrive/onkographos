M3-V Prompt 09 — Deterministic voxel tile dataset と encoder pairing contract
Prompt 08 完了後に実行してください。precomputed embedding volumeからdecoder training/validation tileを生成します。random voxel cropではなく、全supervised voxelを一意にcoverするdeterministic core-tile方式を採用してください。
新規実装
```
src/seis_ssl_cluster/f3/lithology/voxel_tiles.py
src/seis_ssl_cluster/data/f3_voxel_decoder_dataset.py
tests/seis_ssl_cluster/test_f3_voxel_tiles.py
tests/seis_ssl_cluster/test_f3_voxel_decoder_dataset.py
```
core tile + context halo
Token gridをnon-overlapping core tileに分割します。
```
core_size_tokens: [8,8,8]      # reference full setting
context_halo_tokens: [1,1,1]
```
各item:
```
input token crop = core + available halo; edgeはzero/invalid padding
model output      = input token crop × patch size
loss/eval region  = core voxel regionだけ
```
これにより各supervised voxelは同一splitでちょうど一つのcore tileに属し、contextは重複してもmetric/lossは重複しません。
tile manifest
supervision split gridとgeometryだけからdeterministic manifestを生成してください。embedding値に依存させません。
各tile recordは最低限:
```
tile_id
split
core_start_token_xyz
core_stop_token_xyz
input_start_token_xyz
input_stop_token_xyz
input_padding_before_xyz
input_padding_after_xyz
core_voxel_start_xyz
core_voxel_stop_xyz
supervised_voxel_count
per_class_supervised_counts
```
要件:
train/validation別manifest。
supervised voxelが0のtileはdatasetから除外。
全split voxelをexactly once coverしたことをbuilder時にassert。
manifest JSONとcanonical SHA-256 identityを生成可能。
same supervision/configならモデルに関係なく同一manifest。
dataset input
```
embedding .npy [TX,TY,TZ,D]
valid_tokens .npy [TX,TY,TZ]
embedding metadata
label volume [X,Y,Z]
supervision_split_grid [X,Y,Z]
class info
tile manifest
```
dataset output
PyTorch dataset itemは少なくとも:
```
embeddings: float32 [D,ITX,ITY,ITZ]
token_valid_mask: bool [ITX,ITY,ITZ]
labels: int64 [IVX,IVY,IVZ], outside/unknown=-1
supervision_mask: bool [IVX,IVY,IVZ]
core_mask: bool [IVX,IVY,IVZ]
tile_id / geometry metadata
```
supervision_mask は requested split、known class、canonical valid voxel、in-volume、core region の積。context halo内のラベルをlossへ入れないでください。
pairing contract
MAE/M1/M2-A embeddingは次を厳格に照合します。
```
volume shape
patch size
token grid shape
embedding dim
preprocessing / zero-mask geometry
valid_tokens bitwise identity
```
supervision artifactが記録したcanonical valid-token hashとcandidate hashが違えばfail。silent intersectionで評価集合を変えないでください。
sampling / DataLoader
dataset自体にrandom samplingを入れない。
train tile orderのshuffleだけDataLoader generator seedで制御。
data augmentationは初期benchmarkではなし。
.npy はmmapし、full embedding/labelをRAM copyしない。
workerごとのmmap再openが必要ならsafeに実装する。
テスト
non-divisible token gridのcore partition。
edge halo padding。
exact-once supervised coverage。
train/validation leakageなし。
contextラベルがloss maskに入らない。
canonical valid mask適用。
unknown label除外。
model A/Bでmanifestとtile geometryが同一。
valid-token mismatchを拒否。
mmap-backed datasetとcollate。
deterministic shuffled order with seed。
