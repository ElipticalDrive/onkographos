A large, coherent upgrade to Marcher — SDF Ray Marching Studio (projects/marcher-sdf-q9x3/) that clears the entire original backlog and turns the renderer into a proper studio. Everything stays inside the one project folder.
What's new
Rendering
Real reflection bounce — reflective materials now march a genuine second ray and mirror the actual scene (and each other), Fresnel-weighted, roughness-attenuated and metal-tinted. Replaces the old fake sky-only reflection; shade was split into localShade + a reflection pass so the bounce reuses shading.
2×2 anti-aliasing toggle — HDR-correct (averages before tonemap), great for stills.
Modelling
Domain modifiers per node: infinite/limited repeat (tilings), mirror symmetry, twist, bend, plus post-distance round and hollow shell/onion. Values ride in uniforms (uModA/uModB), so only switching a modifier recompiles; twist/bend distances are safety-scaled to keep sphere-tracing stable.
Five new primitives: ellipsoid, hex prism, pyramid, link, rounded cone.
Procedural textures (triplanar where it matters): checker / noise / marble / wood / grid, uniform-driven via uMatTex.
Motion
Per-node animation channels — spin / bob / pulse, evaluated on the uniform-upload path every frame (zero React churn), behind a scene-level master switch.
Output
Standalone HTML export — bakes the whole scene (geometry, materials, lighting, camera orbit and node animation) into one dependency-free WebGL2 page.
PNG capture straight from the canvas.
Polish — four new presets (Colonnade, Gyre, Kaleido, Menagerie), refreshed inspector sections, World panel toggles, help overlay and shortcuts (P capture, E export).
Verification
Passes the exact CI gate locally: conformance + pnpm lint + tsc + vite build.
The generated fragment shader for all 10 scenes was machine-checked for brace/paren balance and valid standalone-HTML output (WebGL2 has no compile step in CI, so the GLSL was reviewed and generation-tested).
Journal updated with the full plan (all items checked) and a session-log entry.
