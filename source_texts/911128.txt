Context
Deferred from #209 (Phase 3: WebGPU Optional Enhancements). Both enhancements require shadow-casting lights, which are currently disabled. Depends on #233 (enable sunLight shadows with pre-compiled shadow maps).
Enhancements
1. GodraysNode for Volumetric Light Shafts
Replace or supplement the billboard god rays in Ocean._createGodRays() with Three.js r183's TSL godrays() post-processing node for physically-based volumetric light scattering.
Import:
```
import { godrays } from 'three/addons/tsl/display/GodraysNode.js';
```
Setup: Wire into UnderwaterEffect's post-processing chain:
```
const godraysPass = godrays(scenePass.getDepthNode(), camera, sunLight);
godraysPass.maxDensity.value = 0.5;
godraysPass.density.value = 0.7;
godraysPass.raymarchSteps.value = 60; // tune for performance
```
Key decisions:
Gate on ultra tier only — raymarching 60 steps/pixel is expensive
Keep billboard god rays as fallback for low/medium/high tiers (no feature removal)
Fade godrays with depth like the existing billboard rays (visible in shallow/twilight zones, hidden deep)
Insert the godrays pass before the underwater ShaderPass in the composer chain (after bloom, before underwater grading)
2. biasNode for Depth-Adaptive Shadow Bias
Use light.shadow.biasNode to modulate shadow bias via a TSL node based on ocean depth, reducing shadow acne at varying distances from the shadow camera.
Setup:
```
// Depth-adaptive bias: increase bias in deeper zones where shadow map precision degrades
const depthFactor = smoothstep(float(0), float(720), abs(positionWorld.y));
sunLight.shadow.biasNode = mix(float(-0.001), float(-0.005), depthFactor);
```
Additional targets (after sunLight):
Player SpotLights in ExternalLightingSystem.js — if headlight shadows are enabled, they illuminate terrain at steep angles and benefit from bias tuning
Creature PointLights — if any gain castShadow = true in the future
Files to modify
src/shaders/UnderwaterEffect.js — Add godrays pass to composer chain (ultra tier)
src/environment/Ocean.js — Set biasNode on sunLight shadow, expose sunLight for godrays pass
src/Game.js — Wire godrays into post-processing, pass sunLight reference
Acceptance Criteria
godrays() post-processing active on ultra tier with visible volumetric light scattering near surface
Billboard god rays preserved as fallback on lower tiers
biasNode set on sunLight with depth-adaptive bias
No shadow acne on terrain in shallow or deep zones
Godrays fade with depth (not visible in abyss)
npm run build passes
No regression in visual quality at any tier
