Closes #89.
downsample now finds exposed Voxels with bit operations on the occupancy masks: it shifts the occupancy ±1 along each axis, taking each face's layer from the touching brick. It also counts the solid Voxels in each block with a popcount, so it reads Materials only for the exposed solid Voxels.
The output is bit-identical. The old per-Voxel rule is kept in the tests as a reference, and differential tests compare against it:
random bricks;
stratified ground with caves;
bricks next to uniform or unheld neighbours;
a hole at every edge and corner.
The existing LOD goldens and the refresh == rebuild tests are unchanged.
