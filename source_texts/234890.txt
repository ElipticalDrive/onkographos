# gaussian-splatting-scene

A minimal 3D Gaussian Splatting scene: learnable means, scales, rotations,
colors, and opacities, rendered via the `gsplat` differentiable rasterizer.
Initialized directly from the DUSt3R point cloud (InstantSplat's core idea:
skip random/SfM initialization, start from a geometry-model point cloud so
optimization converges fast with very few input views).
