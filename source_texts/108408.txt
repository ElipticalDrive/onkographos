# CUDA Marching Cubes - Procedural Isosurface Extraction

A CUDA implementation of Marching Cubes for extracting a compact triangle mesh from a procedurally generated 3D scalar field.

## Technical Goals

- Procedural density-field evaluation
- Deterministic cell classification
- Compact triangle generation
- Prefix-sum / stream-compaction pipeline
- GPU shared-memory reuse
- Deterministic output ordering
- Optimization of repeated corner evaluations

## High-Level Pipeline

1. Evaluate and classify grid cells
2. Determine triangle counts
3. Compute output offsets with prefix scan
4. Interpolate crossed edges
5. Emit compact triangles in deterministic order

## Optimization Approach

The baseline implementation evaluates each cell corner independently when classifying and emitting triangles. The optimized approach processes spatial tiles and reuses neighboring corner samples through shared memory so adjacent cells can reuse work instead of recomputing the same scalar-field values.

## Results

The optimized implementation achieved roughly 2x-3x speedup over the direct baseline on tested NVIDIA CUDA hardware while preserving deterministic output.

## Engineering Challenges

- Exact floating-point semantics
- Deterministic triangle ordering
- Prefix-sum correctness
- Shared-memory tiling
- Synchronization
- Memory/performance tradeoffs

## Skills Demonstrated

CUDA, C++, GPGPU optimization, parallel prefix scan, shared memory, graphics algorithms, numerical correctness, benchmarking.
