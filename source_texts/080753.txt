💡 What: Bypass expensive BVH distance queries for exterior voxels during solid voxelization when no narrow band is used.
🎯 Why: Voxels far outside the mesh are discarded anyway, but computing their exact distance using distance_to_local_point wastes immense CPU time in the tight inner loop.
📊 Impact: Reduced voxelize benchmark time from ~798-925µs down to ~535-542µs, yielding roughly a ~33% performance improvement on solid voxelization.
🔬 Measurement: Run cargo bench to observe the performance impact before and after the change on voxelize.

Keep boundary voxels before skipping SDF
When a default solid voxelization sample lands exactly on a mesh face but the scanline parity marks it outside, this branch now replaces the real zero distance with +inf, so the later sdf <= 0.0 check drops that boundary voxel. This can happen because the row lookup excludes hits at the current x coordinate (hx <= x), and the previous distance query preserved those surface cells by returning 0; the optimization therefore creates holes on aligned/slanted boundaries unless users explicitly pass a narrow band.
