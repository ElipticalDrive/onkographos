Owner playtest note (2026-09-19): "The fires are still billboards — they should be 3D plasma."
Context — #468 (closed today) already reworked the shader, and left exactly this open
#468 rebuilt the savanna's campfires (Testbed/Content/Shaders/Flame.fx, SceneRenderer.DrawFlame) from one sine-wobbled tongue into three tongues over two scrolling fBm noise fields (the "plasma" internal structure), a heat-gated colour ramp (yellow-white seat → orange body → red tips), a spark particle system, and — in its last comment — switched the blend mode from additive to premultiplied-alpha so the reds and oranges actually survive over a bright sky instead of washing to white. That work is real and the fire now reads correctly from a distance, in colour.
But #468's own middle comment already named exactly the owner's complaint here, and it was left open rather than acted on:
"Still one billboard per fire, so no depth when the chapter intro orbits round fire 0 — the 'few billboards per fire' from the issue text is the next step if it shows in play. Left open for that."
It shipped anyway (the colour/blend problem was judged the more urgent half), but the underlying geometry is unchanged: each campfire is still a single flat camera-facing quad. From straight on it now looks like a real fire; from an angle — exactly what the savanna's chapter-intro orbit and the front end's menu orbit both do around fire 0 — a flat quad has no depth and can flip from "fire" to "a picture of a fire" as the view angle changes.
What is wanted
Genuine volumetric/3D-reading fire, not a single 2D quad however good its shader is. #468's own issue text already sketched the options, still unbuilt:
A few billboards per fire (crossed or scattered around the pit), on the same pattern LavaFountain.fx already uses for the volcano's fountains (New scene: an erupting volcano — black basalt and rivers of red-orange lava, ballistic lava fountains, drifting ash, and stone that cracks glowing under it all #223) — multiple camera-facing quads from one static buffer, so the fire has silhouette from more than one angle.
A genuine 3D mesh with the noise-driven shading mapped onto it instead of a flat plane, if that reads better and is affordable.
Where
Flame.fx, SceneRenderer.DrawFlame/CampfireConfig, docs/scenes.md's campfire section. Reference Volcano.fx/LavaFountain.fx (#223) for the existing many-billboard fire pattern in this codebase. Measure with the fixed-camera benchmark discipline #468 itself used (13 units out, the flame filling the lens) before and after, since the savanna already has the least frame-time margin of any scene (#165, #172). Related: #468, #223, #451 (the savanna rework this sits beside but is deliberately separate from, since the fire is the scene's one close-up).

On `main` — merge `4a90b7d` (branch `481-campfire-billboards`, `51ebee7`).
Three camera-facing billboards per fire now, not one — the same architecture `LavaFountain.fx` (#223) already established for the volcano's jets (one static buffer of camera-facing quads, drawn per source), scaled down to three fixed sub-flames rather than hundreds of particles. `Flame.fx`'s new `SUBFLAME_COUNT` (3), `SUBFLAME_OFFSET`/`SUBFLAME_SCALE`/`SUBFLAME_SEED_OFFSET` arrays place two smaller licks at fixed world-space offsets beside the original quad; each vertex's `Position.X` (unused until now) says which sub-flame it belongs to, so one draw call still does the whole fire (`SceneRenderer`'s `FLAME_SUBFLAME_COUNT`, matching the shader's own constant).
Sub-flame 0 is the old single quad exactly — zero offset, full scale, no seed shift — so the view the fire was tuned against (front-on, the play camera, #468's own reference photographs) is pixel-for-pixel unchanged. Confirmed with a before/after pair at the identical camera via `git stash`. The other two sub-flames are smaller (0.62/0.55 scale), tucked close enough that head-on they read as part of the same fire.
The depth is genuine parallax, not a per-quad trick — each sub-flame still always turns to face the camera (that's what a billboard is), but the three of them sit at different world positions, so as the view orbits the fire their screen-space arrangement shifts against each other and against the ground, exactly the cue a billboard tree cross or a grass clump's few crossed quads reads as volume from. Verified from the side and from the diametrically opposite side (a different tongue arrangement each time, not a symmetric artifact).
Cost: measured on the notebook this session ran on (no discrete GPU) — the delta came back inside this machine's own run-to-run noise at both ssaa 2× and 4×, and the sign didn't even hold between the two supersample levels. Recorded honestly in `docs/scenes.md` rather than left silent or fabricated against the reference desktop; the desktop measurement #468 itself did (+0.13 ms on a 6900 XT) is the number to trust if a tighter one is wanted, and the geometry added here (two quads scaled to ~0.6 of one that already cost that little) should sit well under it.
All four solutions build clean; `LevelGen`/`ScoreSim` gates pass untouched.
