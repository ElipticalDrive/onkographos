Question
Under nvos-ludvig-online-all-view-eight-v1 and spin-ludvig-online-full-mask-available-nine-v1, what one globally frozen, task-agnostic RGB-assisted Registered-2D Query Modality Compiler should use the authorized all-view captured RGB, positive-scribble or complete-mask prompt schema, and a preregistered query-time vision model to produce Canonical Query Evidence and one Gaussian Query Posterior for both public benchmarks? Freeze model and preprocessing identity, prompt sanitization, multiview evidence construction, candidate and calibration semantics, Query Workspace lifecycle, abstention, forbidden rendered-RGB and persistence paths, and the smallest exact-contract prototype/pilot that distinguishes vision-model, registration, field, and posterior failures. Treat the prior RGB-free Registered Raster-Adjoint Evidence and Observation-Anchored Signed Region-Hypothesis Marginal as diagnostic controls rather than the Primary path.

Prototype ready for HITL review
The throwaway RGB-assisted Registered-2D query compiler decision lab is captured at commit ed63729.
The current recommendation for Choose the shared RGB-assisted reference-prompt query mechanism for NVOS and SPIn-NeRF is a hash-pinned official-SAM3-code/public-ModelScope-mirror synchronous multiview candidate marginal:
Freeze official SAM3 source 46957e47805eaa273f4aa7bbbd25a88bca9108ce, checkpoint SHA-256 9999e2341ceef5e136daa386eecb55cb414446a00ac2b55eb2dfd2f7c3cf8c9e, config SHA-256 4616385e4b21f2e5e22c875b65679185cbccfa95de42542b9166f7dc3d57160f, the point-only interactive interface, Sam3Processor(resolution=1008) preprocessing, FP32 weights with CUDA BF16 autocast, and Query Abstention rather than a CPU/model fallback.
Keep POSITIVE_SCRIBBLE_RASTER and COMPLETE_BINARY_MASK as two typed sanitizers under one compiler identity. NVOS unlabeled pixels remain unknown. SPIn foreground/complement are positive/negative. A frozen SplitMix64 sampler produces ten point-prompt candidates without random sampling.
Freeze all ten reference candidates before processing other views. Lift each candidate with exact W_ref^T, project only Gaussian posterior/visibility—not RGB—into every registered camera, invoke the same model independently on every authorized captured RGB, and aggregate views symmetrically so view order cannot become semantic state.
Register every returned mask with the exact per-view front-to-back compositor adjoint. Retain all legal candidate fields as current-query hypotheses; weight them only by typed prompt consistency, source-frozen SAM quality, and field support, then marginalize them with the fixed Boundary-Calibrated Field Region Hierarchy into one Gaussian Query Posterior.
Use one source-frozen affine fusion and a final binary Gaussian boundary of exactly posterior >= 0.5. Do not use complete-reference IoU to create a SPIn-only calibration path, and never use a target mask or metric to select a candidate, threshold, hierarchy, or retry.
Start every execution with an empty Query Workspace. RGB embeddings, masks, candidate primitive fields, weights, and fits are query-derived and are destroyed after prediction sealing; they never become scene state, a Rebuildable Warm Cache, or cross-query object memory.
Retain the RGB-free Registered Raster-Adjoint Evidence plus Observation-Anchored Signed Region-Hypothesis Marginal only as matched diagnostic arm A; compare it with recommended arm M on byte-identical cold fields in registered2d-sam3-multiview-consensus-full8-plus-available9-v1.
After all predictions are sealed, compute evaluator-only V, R, and F ceilings to distinguish vision-candidate, registration, and field/carrier failures. If all three pass but M fails, assign the failure to candidate likelihood, view aggregation, hierarchy marginal, or global calibration. The ceilings cannot select the method output.
The proposed mechanism gates are zero Query Abstentions; NVOS macro foreground IoU at least the 91.25768502741802 VPA floor, target status reported against 92.4, at least +1.0 pp over A, and no task more than 0.5 pp below A; SPIn-NeRF Available-Nine scene macro at least 93.7200449592385, at least +1.0 pp over A, and no scene more than 0.5 pp below A. Passing admits the mechanism only to the five-contract baseline reconstruction; it is not a current row, advancement, or claim.
No benchmark was run and no result is claimed. This prototype ticket remains open pending the human's actual selection. In the lab, use the “建议组合”, “两种 prompt”, and “归因分叉” walkthroughs, then copy the decision token or state the requested change here.

Resolution
The human selected the recommended combination after reviewing the RGB-assisted Registered-2D query compiler decision lab, captured at commit ed63729.
Adopt registered2d-sam3-multiview-consensus-v1, a hash-pinned official-SAM3-code/public-ModelScope-mirror Synchronous Multiview Candidate Marginal, as the Primary Registered-2D Query Modality Compiler shared by nvos-ludvig-online-all-view-eight-v1 and spin-ludvig-online-full-mask-available-nine-v1. It compiles either authorized reference-prompt schema and every registered captured-RGB view into Canonical Query Evidence, then emits one Gaussian Query Posterior through the existing Canonical Query Interface. Benchmark identity cannot select a model, sampler, view schedule, candidate rule, calibration, threshold, hierarchy, or fallback.
The RGB-free Registered Raster-Adjoint Evidence plus Observation-Anchored Signed Region-Hypothesis Marginal selected by Choose RGB-free reference-prompt completion for NVOS and SPIn-NeRF remains immutable Context Evidence and matched diagnostic control A; it is not the Primary path under the current LUDVIG-online contracts.
Query-Time Vision Model identity
Freeze the Query-Time Vision Model as official SAM3 code with the public ModelScope mirror checkpoint:
source repository commit: 46957e47805eaa273f4aa7bbbd25a88bca9108ce;
checkpoint SHA-256: 9999e2341ceef5e136daa386eecb55cb414446a00ac2b55eb2dfd2f7c3cf8c9e;
config SHA-256: 4616385e4b21f2e5e22c875b65679185cbccfa95de42542b9166f7dc3d57160f;
loader family: build_sam3_image_model with enable_segmentation=false and enable_inst_interactivity=true;
image interface: Sam3Processor.set_image followed by the point-only processor.model.predict_inst interface;
model-call contract: multimask_output=false, exactly one finite mask, quality value, and low-resolution-logit output per call;
numerical policy: weights remain FP32 and CUDA inference runs under BF16 autocast; model-wide BF16 casting is prohibited; and
failure policy: an unavailable or identity-drifted SAM3 CUDA runtime returns typed Query Abstention. It cannot fall back to CPU, SAM v1, another checkpoint, a cached mask, or another decoder.
The audited LUDVIG SAM v1 ViT-H dependency remains the comparator's Method Contract and a same-evaluator control. It is not a runtime fallback or alternate RADIO-GS model.
Every authority row must additionally bind the exact loader implementation, complete source tree, dependency/container identity, CUDA stack, device, determinism settings, and Stage Receipt evidence required by the existing Runtime Compliance Proof. A filesystem path is only a locator and never the model identity.
Frozen RGB preprocessing and reference registration
For every view, open the exact content-bound registered captured raster with Pillow, apply convert("RGB"), and preserve the raster's calibration-bound width and height. Sam3Processor(resolution=1008) then performs its frozen transform: uint8 image, resize to 1008 × 1008, float scaling to [0,1], normalization with channel mean and standard deviation both 0.5, and bilinear restoration of mask logits to the original registered raster dimensions.
When the authorized prompt raster and captured reference RGB have different dimensions, map prompt-pixel centers to the captured-RGB raster by
x_rgb + 0.5 = (x_prompt + 0.5) * W_rgb / W_prompt
and the analogous y rule. Clip nothing silently: an out-of-bounds mapped point, mismatched reference identity, missing calibration, unknown resize/crop, or shape disagreement fails before model inference. The sanitizer receipt binds source RGB bytes, decoded tensor, prompt bytes, dimensions, mapping rule, point coordinates, model-preprocessed tensor, restored outputs, and their content identities.
Typed prompt sanitization and deterministic reference candidates
One compiler accepts two typed schemas. Schema may select only the evidence admitted by the Authorized Query Input:
POSITIVE_SCRIBBLE_RASTER requires the official reference identity/calibration and a nonempty in-bounds positive population. Only explicitly marked pixels are positive. Every unlabelled pixel remains unknown; no negative prompt, background label, or complement is synthesized.
COMPLETE_BINARY_MASK requires the canonical official reference identity/calibration, a strict binary mask, nonempty foreground, and nonempty complement. Foreground is positive evidence and the complete complement is negative evidence. The exact full mask remains the registered reference anchor; point sampling does not reduce its evidence authority.
Use the same deterministic SplitMix64 ranker for both schemas. Let pixel_id be row-major in the original prompt raster. Rank positives by SplitMix64(pixel_id XOR 0x243F6A8885A308D3), tie-breaking by ascending pixel_id; take the first 30 and reshape contiguously into ten triplets. For a complete mask, independently rank complement pixels with salt 0x13198A2E03707344, take the first 30, and pair each negative triplet with the corresponding positive triplet. Insufficient population fails closed.
SplitMix64 is frozen modulo 2^64 as:
z = x + 0x9E3779B97F4A7C15;
z = (z XOR (z >> 30)) * 0xBF58476D1CE4E5B9;
z = (z XOR (z >> 27)) * 0x94D049BB133111EB; and
return z XOR (z >> 31).
The ten calls produce a fixed candidate bank K=10. A candidate is a typed hypothesis, not an execution seed or a model-selection arm. Every call must return exactly one valid mask; the query cannot drop a failed candidate, change K, resample points, or choose another prompt policy.
Synchronous all-view evidence construction
Freeze all ten reference candidates before processing any other view. For each candidate k:
Lift its reference mask to Gaussian domain with the exact front-to-back reference compositor adjoint W_ref^T, using only frozen Gaussian geometry/covariance, opacity, reference calibration, and current-query mask evidence.
Project the candidate's Gaussian probability and visibility into every registered camera through the Camera-Raster Output mathematics. This renders posterior/visibility only; it never renders or synthesizes RGB.
In the projected raster, the visible posterior >= 0.5 population is positive and the visible posterior < 0.5 population is negative. Select exactly three pixels from each population by SplitMix64 ranking over pixel_id XOR sign_salt XOR low64(candidate_sha256) XOR low64(view_sha256), using positive salt 0xA4093822299F31D0 and negative salt 0x082EFA98EC4E6C89. Insufficient positive, negative, or visible support returns Query Abstention.
Invoke the identical pinned SAM3 point call independently on that view's exact authorized captured RGB. No output from one non-reference view may change the prompts, candidate set, model configuration, or execution of another view.
Register the returned mask with that view's exact compositor adjoint W_v^T and retain mask mass and visible mass with complete Evidence Lineage.
All registered captured-RGB views required by the contract participate, including the scored NVOS target and scored non-reference SPIn views. Missing, skipped, duplicated, or reordered views cannot change semantic results: aggregation is keyed by immutable view identity and reduced in canonical digest order with a frozen numerical summation contract. Gaussian-rendered RGB, sequential self-training, video-order propagation, filename-order dependence, target-mask assistance, and per-view semantic routing are prohibited.
For each candidate and Gaussian, pool view evidence by the symmetric visibility-normalized mass ratio
q[k,g] = sum_v mask_mass[v,k,g] / max(sum_v visible_mass[v,g], epsilon)
with one globally frozen epsilon and numerical reduction identity. The source-frozen calibration must bind the exact epsilon and all learned constants before benchmark metrics are released; no scene or benchmark may choose them.
Candidate likelihood and one Gaussian Query Posterior
Preserve all ten candidates as hypotheses. For each candidate, compute one task-agnostic likelihood from:
typed prompt consistency, expressed as the mean Bernoulli log-likelihood on exactly the labelled prompt pixels—positive pixels only for POSITIVE_SCRIBBLE_RASTER, and foreground plus complement for COMPLETE_BINARY_MASK;
the pinned SAM3 quality output under one source-frozen affine calibration;
the candidate's symmetric all-view registered evidence; and
candidate agreement with the decoded semantic/boundary Capability Views and the fixed Boundary-Calibrated Field Region Hierarchy.
The likelihood form, coefficients, temperature, epsilon, clipping, normalization, and deterministic tie handling are identical across tasks and scenes and may be fitted only on independent source-train evidence. A complete mask supplies more labelled likelihood terms because its schema authorizes them; it does not select a SPIn-only model, candidate, threshold, or calibration family.
Normalize the ten candidate likelihoods with one frozen softmax and marginalize every candidate together with every legal field-hierarchy hypothesis. Winner-take-all candidate selection, top-view selection, hierarchy-level selection, per-scene region count, reference-IoU branch routing, and target-metric selection are prohibited.
The exact registered authorized prompt remains an observation anchor. The all-view candidate marginal and field-hierarchy marginal may complete unobserved or partially observed Gaussians under one source-frozen anchor-preserving logit transport; they may not reverse a fully observed positive or negative anchor. The resulting calibrated per-Gaussian probability is the single Gaussian Query Posterior. Both contracts use the exact binary boundary posterior >= 0.5, and Camera-Raster Output consumes the same continuous posterior. There is no per-task, per-scene, per-query, per-view, reference-IoU-selected, or metric-swept threshold.
Query Workspace lifecycle and forbidden persistence
Every query starts from an empty Query Workspace. Decoded captured-RGB embeddings, SAM3 states, masks/logits, sampled points, registered candidate primitive fields, candidate weights, query-local fits, posterior intermediates, and output rasters bind the complete scene, method, contract, query, view, model, and lineage identities.
All such objects remain Query Workspace. They may be retained only as immutable sealed outputs/audit children of that exact query and must not:
update Deployment Scene State or the Canonical Capability Feature;
become a query-independent Rebuildable Warm Cache;
persist as a SAM/descriptor/candidate semantic scene bank;
accumulate into cross-query object memory;
influence another query; or
be reopened by a later query as semantic evidence.
The only reusable query-independent topology is the bitwise-rebuildable Boundary-Calibrated Field Region Hierarchy compiled from legal cold state and Global Method Parameters. Query masks may change likelihoods over it but cannot rebuild it.
Missing or forbidden lineage; model/code/checkpoint/config/environment drift; an invalid sanitizer, prompt population, reference mapping, view manifest, candidate count, model output, camera, compositor, hierarchy, or cache identity; insufficient projected signs or visibility; contradictory evidence; nonfinite arithmetic; missing output support; or cohort incompleteness returns typed Query Abstention. Abstention is distinct from all-background and cannot trigger any legacy, RGB-rendered, cached, task-specific, or threshold-relaxed fallback.
Smallest exact-contract pilot
Freeze Development Evidence identity registered2d-sam3-multiview-consensus-full8-plus-available9-v1:
Prospective component freeze. Bind both current Evaluation Contracts, exact cohort/query/view manifests, model and preprocessing identities, sampler salts and K, compositor and output identities, Capability Views/hierarchy, candidate likelihood/training authority, anchor transport, calibration, implementation, environment, and Runtime Compliance Proof schema before opening a new benchmark metric.
Cold and runtime preflight. On every sidecar-free D512/L512 cold field, remove Training Artifacts and caches, rebuild every permitted Capability View and hierarchy twice bitwise, start an empty Query Workspace, disable network, expose only exact allowlisted inputs, and trace the full process. A failed SAM3 CUDA smoke call or any missing registered view stops before scoring.
Exact cohorts. Run all eight official NVOS tasks and all registered captured views per query. Run the complete Available-Nine SPIn cohort and every registered captured view; the canonical reference supplies the prompt but is not scored, and every non-reference annotated frame is scored. A subset is diagnostic only.
Matched causal arms. On byte-identical cold fields run A, the frozen RGB-free diagnostic control, and M, the selected synchronous RGB-assisted compiler. They share prompt manifests, field, hierarchy, W, posterior schema, 0.5 boundary, Camera-Raster Output, evaluator, implementation envelope, and execution environment; only the newly authorized RGB/vision/candidate evidence differs.
Prediction seal. Seal every Canonical Query Evidence root, posterior, prediction, and Query Abstention for both arms and both contracts before the evaluator first opens any target mask or releases any metric or ceiling. Missing executions, candidate/view drops, reference scoring, fallback, or identity drift fails the pilot.
Mechanism gates. M must have zero Query Abstentions. NVOS must reach macro foreground IoU at least the same-evaluator VPA floor 91.25768502741802, report status against the conditional target 92.4, improve A by at least +1.0 pp macro, and regress no official task by more than 0.5 pp. SPIn-NeRF must reach Available-Nine scene-macro foreground IoU at least its same-evaluator floor/conditional target 93.7200449592385, improve A by at least +1.0 pp, and regress no scene by more than 0.5 pp. Pixel accuracy is mandatory report-only for both.
Sealed failure attribution. Only after predictions are sealed may the evaluator compute V, the best target performance present in the frozen SAM3 candidate bank; R, the best target performance representable after exact candidate registration and fixed output; and F, the best target performance representable by the fixed field hierarchy and output. These ceilings are diagnostic only and cannot select or mutate M.
The failure cascade is fail-closed: preflight failure is compliance/runtime failure; V failure is vision-model/preprocessing/prompt-sampling failure; V passing with R failure is camera/compositor/registration failure; V and R passing with F failure is Canonical Capability Feature/boundary hierarchy/output-carrier failure; all three passing with actual M failure is candidate-likelihood, view-aggregation, hierarchy-marginal, anchor-transport, or global-calibration failure.
Passing only one contract rejects the shared mechanism. Passing both admits this exact component identity only to Reconstruct the destination-compliant five-contract baseline gap matrix. It does not create a Canonical Current Row, Joint Development Baseline, Development Advancement, Claim Promotion, or Five-Benchmark Claim Outcome, and it does not authorize the final five-benchmark campaign.
Rejected alternatives and map impact
Reject scene/runtime model routing; random point sampling; treating NVOS unlabelled pixels as background; reference-only RGB as the Primary online mechanism; sequential view rollout; Gaussian-rendered RGB; nearest-Gaussian registration as the Primary lift; winner-take-all candidate/view/hierarchy selection; SPIn-only reference-IoU calibration; target-metric tuning; persistent SAM/descriptor/candidate caches; cross-query object memory; and every silent fallback.
No new ubiquitous-language term is required: Query-Time Vision Model, Query Modality Compiler, Canonical Query Evidence, Gaussian Query Posterior, Capability View, Query Workspace, Boundary-Calibrated Field Region Hierarchy, Query Abstention, Information Grant, Stage Receipt, and Runtime Compliance Proof already cover the decision. registered2d-sam3-multiview-consensus-v1 and Synchronous Multiview Candidate Marginal are component identities for /to-spec, not new persistent domain objects.
No new ticket or fog graduation is required. Closing this decision removes the native blocker from Reconstruct the destination-compliant five-contract baseline gap matrix. This session does not work that newly unblocked ticket.
