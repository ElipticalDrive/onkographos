Fixes: #1287
This PR introduces a mathematically robust Quadratic Error Function (QEF) solver utility inside math_utils.py.
This utility forms the foundational linear algebra requirement for modern, feature-preserving surface extraction methods like Dual Contouring.
Key Features:
SVD Pseudo-inverse solver: Implemented using numpy.linalg.lstsq with a strict tolerance to safely handle under-determined and ill-conditioned matrices (such as perfectly collinear or coplanar intersection normals), avoiding LinAlgError crashes.
Improved Numerical Stability: Minimises error mathematically by calculating offsets relative to the mass point.
Fallback Logic: Gracefully falls back to the exact mass point boundary if the SVD solution diverges mathematically.
Test Suite: Added tests/test_qef_solver.py with 100% mathematical logic coverage, explicitly testing orthogonal planes (standard), parallel planes (singular fallback), and collinear normals (under-determined edges) to prove stability.
