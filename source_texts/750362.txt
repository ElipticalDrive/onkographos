Motivation
Provide directional self-shadowing for volumetric clouds by accounting for cloud density along the light ray and attenuating direct in-scattering using Beer–Lambert transmittance.
Expose tunables for light march quality and shadow strength and reduce temporal flicker/artifacts when using low light-step counts via blue-noise jitter for temporal accumulation.
Description
Added cloud_light_steps: i32 and shadow_strength: f32 to VolumetricCloud with defaults and inspector sliders in vetrace_engine/src/components/components.rs.
Upload the new parameters into the GPU cloud payload via GpuVolumetricCloud.light_padding in vetrace_engine/src/scene/scene.rs.
Implemented light-march / transmittance sampling in the standalone cloud raymarch shader (vetrace_engine/assets/shaders/wgpu/clouds/cloud_raymarch.comp.wgsl) by adding blue_noise_jitter, light_transmittance, accumulating optical depth, converting to transmittance with exp(-optical_depth * strength), and multiplying cloud in-scattering by that transmittance.
Mirrored the same approach in the production hybrid raytrace cloud compositor (vetrace_engine/assets/shaders/wgpu/hybrid/raytrace.comp.wgsl) by adding cloud_blue_noise_jitter, cloud_light_transmittance, per-pixel jitter, and passing id.xy into composite_clouds; added guards for near-zero light direction to avoid divide-by-zero.
Testing
Ran rustfmt --check vetrace_engine/src/components/components.rs vetrace_engine/src/scene/scene.rs, which passed for the modified files.
Ran cargo check, which could not complete in this environment due to a missing system dependency: wayland-client.pc required by wayland-sys (build failed with pkg-config error). No shader runtime tests were executed here.
