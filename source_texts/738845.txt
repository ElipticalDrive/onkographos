S6 — GPU froxel compute pass (D3D)
Ports the pure-CPU froxel volumetrics pass (FroxelVolumePass.Populate +
FroxelCameraVolume) to a D3D11 compute kernel — the GPU twin, proven
bit-parity against the CPU pass by a headless WARP gate.
What's here
FroxelKernelSource — shared HLSL, two entry points (one-source /
two-compiler ready for a later Vulkan kernel, exactly like
ReliefRaymarchKernelSource):
CSFroxelIntegrate — one thread per column: noise-modulated density →
extinction + multi-light Henyey-Greenstein in-scatter, integrated
front-to-back into the volume (float4/cell = in-scatter RGB + transmittance).
CSFroxelComposite — one thread per pixel: world depth → continuous slice
through the exponential grid, sample the integrated column, blend over the
fog-free beauty (beauty·T + inScatter·255).
Noise (Hash3D/ValueNoise3D/FbmCloud3D), spot cone (SmoothCone) and
light resolve (ResolveLight) are line-for-line ports of the relief
kernel's helpers — already parity-proven by --reliefgpuraymarch.
FroxelGpuKernel (Rendering.D3D) — two-pass dispatch; the volume buffer is
written as u0 (integrate) then read as t2 (composite). 224 B cbuffer twin.
IFroxelVolumeKernel + FroxelGpuUniforms (Engine) — backend-agnostic seam
input bundle carrying the same FroxelGrid + FroxelMedium the CPU
FroxelCameraVolume.Apply builds, so GPU == CPU by construction. Mirrors
IReliefRaymarchKernel / ReliefUniforms (Relief 3D Slice 3d: host wiring — GPU relief kernel with CPU fallback #162).
--froxelgpu WARP gate (FroxelGpuProbe) — no GPU needed; diffs a GPU
dispatch against FroxelCameraVolume.Apply.
Parity
--froxelgpu: mean channel diff 0.000, max 1 LSB (float shader vs double
CPU), fog changed 100% of pixels → PASS. --reliefgpuraymarch unchanged
(mean 0.271). Suite 1709/1709 (+4 uniform-seam tests).
Safety
Nothing calls the kernel in the live render path yet → default byte-identical.
Follow-ups (documented on the roadmap)
Vulkan froxel kernel — the HLSL is already one-source/two-compiler-ready
(relief Relief 3D Slice 3b: D3D relief-raymarch kernel dispatch + --reliefgpuraymarch gate #160→Relief 3D Slice 3c: Vulkan relief-raymarch backend + lavapipe smoke #161 precedent).
Host wiring — thread an IFroxelVolumeKernel factory through
FractalRenderHost + bootstrap so a GPU relief + froxel render composites
on-GPU from the relief depth AOV, lifting the current force-CPU (relief Relief 3D Slice 3d: host wiring — GPU relief kernel with CPU fallback #162
seam precedent).
