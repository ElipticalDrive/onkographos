Pull Request Overview
This PR implements CPU-based voxel meshing and chunk streaming utilities for a 3D rendering system. The implementation includes greedy meshing algorithms, distance-based level-of-detail (LOD) chunk caching, and frustum culling utilities for optimized rendering of voxel-based worlds.

Author
This pull request introduces a new voxel chunk rendering pipeline with frustum culling, greedy meshing, indirect draw batching, and chunk LRU caching. It adds several new modules under src/render and src/world, along with corresponding unit tests. The changes also clean up and simplify configuration files for linting and type checking.
Voxel Rendering Pipeline Additions:
Added src/render/culling.py with utilities for frustum culling of chunk meshes, including extracting frustum planes and checking bounding box intersection.
Added src/render/indirect_batch.py providing CPU-side batching of multi-draw-indirect commands for visible chunk meshes.
Added src/world/chunk_cache.py implementing an LRU cache for chunk streaming, with distance-based LOD selection and mesh generation via greedy meshing.
Added src/world/greedy_mesher.py implementing a greedy meshing algorithm for voxel chunks, generating contiguous quads for visible faces.
Testing:
Added new tests for chunk caching, frustum culling, batching, and greedy meshing in tests/test_chunk_cache.py, tests/test_culling_batch.py, and tests/test_greedy_mesher.py. [1] [2] [3]
Removed legacy and CI-skipped capsule collision/property tests from tests/test_capsule_ground.py and tests/test_capsule_properties.py. [1] [2]
Configuration Cleanup:
Simplified and deduplicated ignore patterns in eslint.config.cjs, ensuring proper exclusion of build, test, and asset directories. [1] [2]
Cleaned up mypy.ini to clarify exclusion of physics and test modules from type checking.
