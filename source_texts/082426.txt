Would it be possible to have a gray level test image, in order to see it, and possibly to have the possibility to see it in orthoslices rendering or in volume rendering, with an inferno map for example (see example there )
import vtk
Utiliser une palette prédéfinie (ex: "Inferno")
Charger l'image 3D TIF
reader = vtk.vtkTIFFReader()
imgPath="/home/rfernandez/Bureau/A_Test/Aerenchyme/Xrays/12_Archi/Archi_small.tif"
reader.SetFileName(imgPath)
reader.SetFileName(
"/Donnees/DD_CIRS626_DATA/EARSCAN/BLE_002/BLE_S4/Ge3D_8bit.tif"
#"/home/rfernandez/Bureau/A_Test/Aerenchyme/Xrays/sixteenShort_rmbg.tif"
)
reader.SetFileName("/home/rfernandez/Bureau/A_Test/Aerenchyme/Xrays/01_Archi/01_Archi_small.tif")
reader.SetOrientationType(4) # Adapter selon l'orientation de votre image
reader.Update()
Mapper l'image en volume
volume_mapper = vtk.vtkSmartVolumeMapper()
volume_mapper.SetInputConnection(reader.GetOutputPort())
Choix d'une colormap native
preset_name = "Inferno" # Autres exemples : "Inferno", "Viridis", "Plasma", "Rainbow", etc.
color_preset = vtk.vtkColorSeries()
color_preset.SetColorSchemeByName(preset_name)
Remplir la Color Transfer Function avec les couleurs du preset
num_colors = 256
p0 = 30
p1 = 75
p2 = 80
p3 = 85
p4 = 90
p5 = 95
p6 = 100
p7 = 110
p8 = 120
p9 = 150
color_transfer_function = vtk.vtkColorTransferFunction()
color_transfer_function.AddRGBPoint(p0, 0.0, 0.0, 0.0) # Noir
color_transfer_function.AddRGBPoint(p1, 0.1, 0.0, 0.5) # Violet bleuatre foncé
color_transfer_function.AddRGBPoint(p2, 0.4, 0.0, 0.4) # Violet foncé
color_transfer_function.AddRGBPoint(p3, 0.6, 0.0, 0.6) # violet rose
color_transfer_function.AddRGBPoint(
p4, 0.8, 0.3, 0.4
) # rose tendant vers le rouge
color_transfer_function.AddRGBPoint(
p5, 0.9, 0.5, 0.1
) # rouge tendant vers l'orange
color_transfer_function.AddRGBPoint(p6, 1.0, 0.5, 0.0) # Orange net
color_transfer_function.AddRGBPoint(
p7, 1.0, 0.7, 0.0
) # orange tendant vers le jaune
color_transfer_function.AddRGBPoint(p8, 1.0, 0.9, 0.2) # jaune
color_transfer_function.AddRGBPoint(p9, 1.0, 1.0, 1.0) # blanc
iMin = 50
iMax = 150
opacity_transfer_function = vtk.vtkPiecewiseFunction()
Arch
opacity_transfer_function.AddPoint(0, 0.0) # Transparent
opacity_transfer_function.AddPoint(10, 0.0) # Transparent
opacity_transfer_function.AddPoint(30, 0.2) # Semi-transparent
opacity_transfer_function.AddPoint(130, 0.8) # Presque opaque
Roots beaut
opacity_transfer_function.AddPoint(0, 0.0) # Transparent
opacity_transfer_function.AddPoint(50, 0.0) # Transparent
opacity_transfer_function.AddPoint(60, 0.2) # Semi-transparent
opacity_transfer_function.AddPoint(130, 0.8) # Presque opaque
Propriétés du volume
volume_property = vtk.vtkVolumeProperty()
volume_property.SetColor(color_transfer_function)
volume_property.SetScalarOpacity(opacity_transfer_function)
volume_property.ShadeOn() # Activer les ombres pour un rendu réaliste
volume_property.SetInterpolationTypeToLinear()
Création du volume
volume = vtk.vtkVolume()
volume.SetMapper(volume_mapper)
volume.SetProperty(volume_property)
Configurer le rendu
renderer = vtk.vtkRenderer()
renderer.AddVolume(volume)
renderer.SetBackground(0.1, 0.1, 0.1) # Fond sombre pour un bon contraste
Configurer la fenêtre de rendu
render_window = vtk.vtkRenderWindow()
render_window.AddRenderer(renderer)
render_window.SetSize(800, 800)
Configurer l'interacteur
interactor = vtk.vtkRenderWindowInteractor()
interactor_style = vtk.vtkInteractorStyleTrackballActor()
interactor.SetInteractorStyle(interactor_style)
interactor.SetRenderWindow(render_window)
Ajout d'une caméra interactive
camera = renderer.GetActiveCamera()
camera.SetPosition(0, 0, -500) # Ajuster selon votre image
camera.SetFocalPoint(0, 0, 0)
Lancer le rendu interactif
render_window.Render()
interactor.Start()
