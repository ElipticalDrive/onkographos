It would be useful to support nerfstudio's dataset format for interoperability. This allows using a dataset with a transforms.json file specifying camera poses along with images. Of particular note here are use cases when one generates poses without an algorithm like COLMAP (e.g. using robot pose data from mounted cameras). I have used this to compare the various nerfstudio implementations for NeRFs and Gaussian splats vs. the techniques in this repo.
