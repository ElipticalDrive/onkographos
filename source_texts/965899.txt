What
Turns Marcher (projects/marcher-sdf-q9x3/) from a raymarcher-with-fake-ambient into a real progressive path tracer. It puts a multi-bounce Monte-Carlo light-transport integrator on top of the accumulation buffer that a previous session built, so surfaces are lit by genuine indirect light — colour bleeding, soft contact shadows, and physically soft area lighting that the old single-bounce shade could only approximate.
The engine
pathTrace() in the shared shader body (src/sdf/shader.ts), dispatched from renderSample on a new uIntegrator uniform (0 = raymarch shade, 1 = path trace) — no recompile on toggle. Each vertex stochastically takes a cosine-weighted diffuse lobe or a roughness-driven glossy/mirror lobe (Fresnel-weighted probability); throughput carries the surface albedo (→ colour bleeding); Russian roulette prunes dim paths after two bounces.
Next-event estimation — neeSun() samples the sun's angular disc with one shadow ray; neeEmitters() samples every emissive node as an area light with a jittered surface point for soft penumbrae. Emission and the sharp solar disc are gated behind a specular flag so NEE is never double-counted.
Brightness-matched radiometry — the path tracer stays in the same artistic units as the raymarch shade, so flipping the Lighting toggle changes the character of the light, not the exposure. A firefly clamp tames stray bright samples.
UI + scenes
World → Render gains a Ray march / Path trace segmented switch, Bounces (1–12) and Firefly clamp sliders (with an accumulation reminder), and a path traced badge in the viewport HUD.
New Render fields (integrator/bounces/fireflyClamp) thread through types → presets → reducer → renderer upload + accumulation view-hash; old saves backfill via defaultRender().
Two showcase presets up front: Cornell Box (the canonical GI test — red/green walls bleeding onto the floor and blocks under a ceiling panel) and Radiance (a matte sphere glowing red and blue from bounce light between two coloured walls, with a chrome sphere mirroring it).
Verification
The exact CI gate is green: scope + conformance + frozen install + pnpm lint + tsc + vite build + build-output.
pnpm test passes 9 Vitest cases, including a new one asserting the accumulation shader carries the whole GI machinery (pathTrace/neeSun/neeEmitters/cosineHemisphere/glossyLobe/visibility + the uIntegrator dispatch) and that the showcase presets ship in path-trace mode.
Drove the built app in headless Chromium (SwiftShader WebGL2): the Cornell Box path-traces with clear red/green colour bleeding and soft contact shadows, the path traced badge and spp HUD are live, toggling back to Ray march works, and there are no shader-compile or JS errors.
All changes live inside projects/marcher-sdf-q9x3/ (Golden Rule). The journal's Session 4 plan and the Help overlay document the feature.
