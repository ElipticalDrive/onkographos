Adds modular, improved Gaussian Splatting implementation with full point properties, depth-aware rendering, and progressive training.
New Modules (optimized/)
gaussian_points.py - Learnable point cloud with XYZ, RGB (sigmoid), opacity (sigmoid), scale (exp) properties
depth_aware_render.py - Back-to-front depth sorting, alpha compositing, batched rendering (1000 pts/batch)
losses.py - L1 + SSIM photometric loss, opacity/scale/spatial regularization
progressive_training.py - Dynamic densification (clone high-gradient points) and pruning (remove low-opacity)
learnable_camera.py - Per-view yaw/pitch, shared focal length
train.py - Dual optimizers (geometry 0.01, camera 0.001), cosine annealing LR
Key Improvements over aistudio/
Feature
Basic
Optimized
Point Properties
XYZ, RGB
XYZ, RGB, Opacity, Scale
Rendering
Additive blending
Alpha compositing + depth sort
Loss
MSE
L1 + SSIM + regularization
Training
Fixed points

Camera
Fixed
Learnable extrinsics
Usage
```
from optimized import GaussianPoints, LearnableCamera, render_fast, combined_loss

points = GaussianPoints(num_points=1000, device=device)
camera = LearnableCamera(num_views=4, device=device)

xyz, rgb, opacity, scale = points.get_point_data()
yaw, pitch, focal = camera.get_view(0)
rendered = render_fast(xyz, rgb, opacity, scale, yaw, pitch, 256, focal.item())
```
Original prompt
Task
Create a new folder called optimized/ in the root of the repository and add improved Gaussian Splatting implementation files for better 3D head reconstruction results.
Files to Create
1. optimized/gaussian_points.py
Learnable 3D Gaussian point cloud class with full properties:
XYZ positions (learnable)
RGB colors with sigmoid activation for [0,1] range
Opacity (Alpha) with sigmoid activation
Scale (Size of each Gaussian) with exp activation for positive values
parameters() method to return all learnable parameters
2. optimized/depth_aware_render.py
Improved renderer with proper depth ordering:
Project 3D points to 2D with perspective projection
Filter visible points (on-screen check)
Sort points by depth (back-to-front) for proper alpha compositing
Batched rendering (1000 points per batch) to prevent VRAM overflow
Alpha compositing instead of additive blending: C_out = C_new * alpha + C_old * (1 - alpha)
Include the project_3d() function for 3D to 2D projection with yaw/pitch rotation
3. optimized/losses.py
Combined loss functions with regularization:
Photometric Loss: L1 loss (sharper than MSE) + SSIM loss (structure preservation)
Opacity Regularization: Encourage points to be visible
Scale Regularization: Prevent tiny/huge points
Spatial Regularization: Keep points in a reasonable volume
Include compute_ssim() helper function
4. optimized/progressive_training.py
Progressive training strategy class:
Start with fewer points (e.g., 500) and grow to max (e.g., 10000)
densify() method: Add new points where gradients are high (clone high-gradient points with small perturbation)
prune() method: Remove points with very low opacity
5. optimized/learnable_camera.py
Camera model with learnable extrinsics:
Learnable yaw and pitch per view (4 views)
Learnable focal length (shared across views)
get_view(view_idx) method to get camera parameters for a specific view
parameters() method for optimizer
6. optimized/train.py
Main training script that integrates all components:
Initialize GaussianPoints, LearnableCamera
Two separate optimizers: faster LR for geometry (0.01), slower for camera (0.001)
Cosine annealing LR scheduler
Load 4 ground truth images (1.jpg, 2.jpg, 3.jpg, 4.jpg)
Training loop with:
Render all 4 views
Compute combined loss
Backpropagation and optimization
Periodic visualization
Import from all other modules in the folder
7. optimized/README.md
Documentation explaining:
Overview of improvements over the basic aistudio/ implementation
Description of each module
Usage instructions
Requirements
Comparison table (Point Properties, Rendering, Loss Function, Training, Camera, Memory)
Technical Requirements
All files should use PyTorch
Support CUDA (GPU) with CPU fallback
Use proper Python typing hints where appropriate
Include docstrings for classes and functions
Files should be importable as modules (use relative imports where needed)
