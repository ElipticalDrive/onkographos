This change refactors the terrain rendering system to use a GPU-driven pipeline. Terrain chunks are now subdivided into 8x8 patches, allowing for more precise frustum and Hi-Z occlusion culling in a new compute shader. Rendering is handled via a single indirect draw call, significantly improving performance and reducing CPU overhead.
Key improvements:
More granular visibility control (64 patches per chunk vs 1).
GPU-side occlusion culling using the Hi-Z pyramid.
Reduced CPU-to-GPU synchronization and state changes via indirect rendering.
Deterministic tessellation factors maintained across patch/chunk boundaries.
