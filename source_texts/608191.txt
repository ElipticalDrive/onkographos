Describe the problem or limitation you are having in your project
With the addition of fog volumes, I can see a lot of developers planning to use them to implement clouds with using fog shaders(planned, unless I got it wrong).
One thing that make clouds look good in games are the silver lining resulting from more dense areas being darker from behind, which requires self shadowing. This will be especially useful for flight sim games or any game where you can get up close to the clouds.
Another graphical feature developers might want are cloud shadows that globally affect objects, which require fog volumes to be able to appear in shadow maps. This is a more advanced technique and to be honest, might be overkill.
Describe the feature / enhancement and how it helps to overcome the problem or limitation
Self shadowing: realistic clouds.
Fog volume shadows: global cloud shadows.
Describe how your proposal will work, with code, pseudo-code, mock-ups, and/or diagrams
There would be an option to able this in the VL section for environment or fog volumes themself. I initially wanted to propose this into 4.0 but then realised how stupid that was.
For self shadowing, raymarching might work, although I don't know if it would work considering that volumetric fog in Godot uses frustum aligned voxels.
For cloud shadows, I don't even know.
If this enhancement will not be used often, can it be worked around with a few lines of script?
With a few lines? No, but definitely possible to be implemented as a plugin that fake the effects.
Is there a reason why this should be core and not an add-on in the asset library?
Probably more convenient as a built-in option.

Several problems.
Volumetric fog fades at a distance fairly quickly so they're not good for this (clouds, without mesh fakes, which FYI can be easily made to cast shadows)
Volumetric fog shadows would be hard to define how deep they start within the fog volume
Volumetric fog is affected by shadows/light itself in such a way that they'd be hard to control because they'd quickly darken under shadows in unrealistic fashion
