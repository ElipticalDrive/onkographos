Description
Raw measurement data and processed results for the paper "Tailored 3D microphantoms: An essential tool for quantitative phase tomography analysis of organoids", Biocybern. Biomed. Eng. 45 (2025) 247–257. https://doi.org/10.1016/j.bbe.2025.03.003.
Measurement data.zip - Archive contains .bmp files with raw images captured by the cameras in corresponding systems. Included .txt files contain key system parameters used for demodulation and reconstruction.
3D refractive index reconstructions.mat - MATLAB structure file containing expected and measured 3D RI distributions for the corresponding systems and organoid samples.
