As discussed in meeting:
We will try to keep the NifTI/Nibabel workflow to avoid a major refactoring
We will refactor again the loader part to convert images + ground truth to Nibabel objects instead of numpy arrays, this only impact the work done in the previous PR New loader: Load PNG/TIF/JPG microscopy files as numpy array #734.
All the processing for inference/testing will be done with those Nibabel objects/NifTI files (as it is right now)
We will need a function to convert the predictions back to the original file format at the end
This does not impact the image patching done in Generate 2D patches for microscopy loader #747/New loader: Generate 2D patches #763 nor the reconstruction from 2D patches started in Implement image reconstruction from 2D patches for MRI data #781/Add image reconstruction from 2D patches #782.
