Recently, 3D Gaussian Splatting (3DGS) has emerged as a convincing alternative to Neural Radiance Field (NeRF)-based methods, which suffer from prohibitive computational overhead due to neural network inference, while maintaining comparable image quality. This thesis presents a comprehensive analysis of the 3DGS rendering pipeline characteristics, identifies fundamental bottlenecks, and proposes a hardware accelerator architecture specifically designed for resource-constrained edge computing environments and diverse spatial computing applications.

Through systematic workload characterization of the 3DGS rendering pipeline across multiple hardware platforms, this work identifies critical performance bottlenecks that hinder real-time rendering in edge computing environments. The profiling results reveal that each stage of the pipeline consisting of preprocessing, sorting, and rasterization exhibits distinct operational characteristics. Notably, alpha-blending, which constitutes the core operation of the rasterization stage, emerges as the dominant computational bottleneck. Additionally, memory usage analysis reveals significant optimization opportunities in the storage and processing of Gaussian parameters.

This study addresses the memory wall problem that arises when state-of-the-art acceleration techniques are applied to the 3DGS rendering pipeline. While existing approaches successfully accelerate compute-intensive operations, they unintentionally alter workload characteristics, transforming previously minor stages into primary bottlenecks. Recent work demonstrates that parallel optimization of sorting and rasterization shifts the performance bottleneck to the preprocessing stage, where memory bandwidth limitations dominate end-to-end execution time.

To address this emerging architectural challenge, this thesis proposes a Processing-In-Memory (PIM)-based accelerator architecture for the 3DGS rendering pipeline that co-optimizes memory hierarchy and computing resources. The proposed architecture leverages near-memory processing capabilities to achieve the operational efficiency required for real-time rendering while mitigating memory bandwidth constraints. By offloading the preprocessing stage to in-memory processing units and integrating specialized external accelerator logic for sorting and rasterization, the architecture achieves balanced utilization of both memory bandwidth and computing resources.

The proposed 3DGS rendering pipeline accelerator architecture bridges the performance gap between server-scale systems and mobile platforms, enabling efficient 3DGS rendering on edge computing devices. This approach resolves fundamental trade-offs between rendering quality and computational efficiency, establishing a pathway toward ubiquitous deployment of high-quality real-time 3DGS rendering as a foundational component of extended reality and spatial computing applications.
