rendering: Make the ray-traced effects work in the player.
…
57f853b
```
The SSR and GI tracing mode was set without its override flag, so the
volume ignored it and ray tracing never kicked in. The settings now go
to every global volume, since the table's and the player's share a
priority and which one got them changed from launch to launch.

Ray-traced reflections and GI only run where the pipeline asset traces,
missing components are added, and the effects whose ray tracing passes
the player strips (AO, subsurface scattering, path tracing, ray-traced
shadows) are kept off. Experimental recursive rendering flags the clear,
refractive materials for HDRP's recursive pass. Instantiated profiles
are released once their volume is gone.
```

```
The camera enables dynamic resolution with the chosen upscaler and quality (optimal settings), only where HDRP detects it and the cabinet projection allows temporal AA. The camera's own AA is off while an upscaler runs, since HDRP would still add FXAA after it. Reports the render scale from the camera's HDCamera, because HDRP resets the active DynamicResolutionHandler after each render.
```
