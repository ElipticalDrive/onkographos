The current ortho views do not sync their viewer_model.dims.ndisplay property, so they can be rendered as 2D or 3D view individually. However, it can be useful to display 3D renderings in all views, but synced-rotated so that you can see the object from different angles simultaneously (optionally in combination with (clipping) planes).
Since the ortho views are reflected+rotated views of the main viewer, the 3D rendered copies are also mirrored, which is a bit confusing. Instead, the same axes order could be shared by the different viewers if they are all displayed in 3D. This also circumvents the need to rearrange the (clipping) plane order of the normal and position, and only requires syncing of the respective rotations.
This PR updates the controls for camera syncing (one setting to sync zoom, center, and angles simultaneously, instead of separate zoom and center) and display syncing (2D/3D and grid mode), and adds a hook to sync clipping planes. Optional 'ortho-planes' (3D) or canvas borders (2D) indicate the plane positions along the different axes.
