Adds vxgi-light-bake (Baked Voxel Cone Tracing) alongside live VXGI. Initialization bakes 64 samples into a 1024-square HDR atlas using the same 128-voxel, three-cone, 40-degree, one-bounce VXGI settings, waits for GPU completion, and releases the volume. Frames use baked indirect diffuse with live direct/specular lighting and TRAA; live VXGI screen-space AO is not baked.
Uses the MIT LightMapper/UV atlas implementation from mrdoob/three.js#34991, pinned and vendored without changing the existing Three.js fork revision. Restores borrowed geometry/materials on disposal and snapshots posed geometry for baking. Includes dispatch and hardware integration checks; registers the variant in existing VXGI benchmark workloads.
Validation:
pnpm build, pnpm tsc, formatting, and pnpm lint passed (lint warnings, including one upstream baker shadowing warning).
All 320 tests passed with coverage using four workers and a 30-second timeout. The initial default run passed 318 and timed out on two existing CLI/history tests.
Hardware integration passed on NVIDIA RTX 3060 Ti, Ampere, D3D12 driver 32.0.16.1714 for Cornell, Breakfast Room, Dogwood, and Coffee Maker. Checks completed startup bake, finite nonnegative and nonzero atlas irradiance, rendering, camera movement, and scene restoration.
Dogwood emits an upstream atlas Float32 precision warning about possible UV overlap; this is a baking limitation retained for comparison.
Dependency audit reports seven existing advisories (two critical, four high, one moderate) through the unchanged path-tracer workspace dependencies.
Fidelity captures and the four-scene representative benchmark results follow in separate PRs after this implementation merges.
Closes #248
Browser hardware smoke capture passed. A known position/normal-field atlas check also passed. The baked Cornell output has visible irradiance bands absent in live VXGI; retained upstream sampler output will be documented in the fidelity results. Initialization primes source shadow maps before volume injection.
