1. To run the script, first you must download it. 
 2. Open Blender, and delete all lights and cameras.
 3. Then, add your own custom primitives with the "Add:Mesh:" button.
 4. Next, import the downloaded Python script into Blender's "scripting" tab and click the run button.
 5. Go to the top left hand corner of Blender, and click on "window".
 6. Select "Toggle System Console".
 7. Paste the output of Blender's terminal ("float map(...){}") over the existing map() function on this Shadertoy project: [https://www.shadertoy.com/view/7cBXzm](https://www.shadertoy.com/view/s3SGzh)
