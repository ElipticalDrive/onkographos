Summary
This PR adds the graphics benchmarking paths for both 3D Gaussian Splatting and InstantNGP.
For 3DGS, kb-nano keeps a layered L1/L2/L4 implementation while importing the critical projection, tile-intersection, and rasterization kernels directly from gsplat.
The benchmark uses the real poster COLMAP sparse scene from nerfstudioteam/datasets, initializes Gaussians from sparse 3D points, and compares our render path
against gsplat.rasterization.
For InstantNGP, kb-nano uses a thin wrapper over the official pyngp backend for render benchmarking, and keeps kernel-level wrappers for the field stack (HashGrid,
direction encoding, FullyFusedMLP) against direct tinycudann. The render benchmark uses the official fox scene, and the kernel benchmark uses real fox training-
view ray samples derived from cached snapshot metadata instead of synthetic random inputs.
README was updated to match the current implementation, dependency setup, benchmark commands, real-data workload description, and the latest measured results.
