Other Features and Details
I essentially rewrote the project from scratch. The libraries I used were:
Vulkan SDK, GLFW, GLM, Dear ImGUI, nlohmann/json, Native File Dialog Extended, tinygltf, tinyobjloader, stb (stb_image and stb_image_write).
I no longer use command line arguments to load scenes. It loads 'scenes/cornell.json' at startup, and then you can use the file picker in the ImGui settings window.
Some scene loading options I added are:
Import scale
Up axis
Fallback/override material especially for scenes with no materials
I made the JSON format support the following:
Support for material types of: Diffuse, Emissive, Specular, Mirror, Glass
IOR is a key
ROUGHNESS is a key
SPECULAR_COLOR is a key
