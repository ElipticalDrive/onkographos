Global requirements: C++17, global-namespace first-party types, pinned formatting, max four parameters/function, exact-source Clang AST/CMake/CTest/GoogleTest and 100% achievable locally compilable CPU line/branch/function coverage; relevant shader oracle tests and actual native hardware proof for GPU outcomes. Task SHD-15 — Implement adaptive visibility shading rate maps and temporal reconstruction
Owner: Shading rate/resolution owner. Existing renderer program stage: W6/W7.
File/domain ownership: Source/Renderer/ShadingRate/; Tests/Renderer/ShadingRate/.
Hard shader contract prerequisites: SHD-03 valid gradient provenance, SHD-13 real material classification, SHD-14 bounded work outputs.
True external integration/hardware gates: #57 FrameGraph and native driver with rate/fallback support; valid history/motion source. Required for real rate-map/temporal acceptance.
Deliverables and callable / data contracts
Full-resolution coverage/depth; generate per-tile/material rate eligibility from material IDs, depth/normal/velocity edges, disocclusion/confidence and material shader restrictions. Support declared software material-rate resolve and optional native VRS where profile supports. Include full-rate rescue and temporal invalidation; validate reconstruction.
Acceptance and negative probes
Images vs full-rate: thin foliage, transparency, high-frequency UV, camera cut, sprint, disocclusion, material edges; no leakage; count actual material invocations, variance and temporal stability. Negative missing history and wrong material ID.
R2 — native/integration acceptance boundary
Track: GPU-INTEGRATION. Definition of done: Full-rate reference vs adaptive-rate GPU images across thin foliage, alpha/disocclusion/motion/camera cuts, correct rate and history gating, explicit full-rate rescue, on-device shader invocation/quality metrics, bounded history and correctness under invalid inputs.
Milestone rule: This issue is not gated by completion of other unrelated shader drivers, optional branches or release-wide SHD-22. It may be closed when its own driver/GPU artifact is integrated under its authorized owner with exact-SHA tests, source-scope coverage, native hardware evidence where required, and independent QA. Source-only reference work can be acknowledged without falsely accepting a GPU-dependent milestone. Dependency authority: #77 R2.
Protected boundaries / stop conditions
No universal hardware VRS requirement; no change to logical material/coverage semantics.
Handoff evidence
Source commit/branch and changed-file inventory, exact file and source revision identity.
CMake C++17 build, formatter/AST, GTest/CTest with source-matched coverage and sanitized negative tests (where CPU code exists).
Shader IR/oracle fixtures and cross-backend GPU image/telemetry acceptance where GPU code is implemented; distinguish NOT_RUN.
Independent review checks ownership, ABI and dependency proofs. Remain OPEN until native integration/QA passes.
