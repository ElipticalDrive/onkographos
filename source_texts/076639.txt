Owner
Grid downsampling: Large volumetric grids (e.g. 480x48x576 = 13M points from CHGCAR files) are block-averaged to ≤500K points before marching cubes, keeping the UI interactive. Small grids pass through unchanged.
Debounced rendering: Slider changes are debounced (50ms) so dragging the isovalue doesn't trigger expensive marching cubes on every pixel of drag.
Cell-boundary clipping: Use periodic=false for charge density isosurfaces so they clip at cell boundaries (matching VESTA) instead of wrapping across the cell with stretched triangles.
Camera sync fix: Break effect_update_depth_exceeded infinite loop in the isosurface demo page by skipping synced_scene_props writes when position/target haven't changed.
DraggablePane tab redesign: Move drag handle, reset, and close buttons from an overlapping overlay into a protruding tab on the pane's right edge, so they never obscure internal content.
An interactive Periodic control lets users wrap isosurfaces across cell boundaries.
Closes #317

…xes (#322)

* Add grid downsampling for large isosurface volumes

Large CHGCAR files (e.g. 480x48x576 = 13M grid points) freeze the UI
because marching cubes runs synchronously on the main thread.

Add downsample_grid() that block-averages the grid to stay under 500K
points before isosurface extraction. Small grids pass through unchanged
(factor=1, zero overhead).

Closes #317

* Debounce and downsample isosurface rendering

- Use downsample_grid before marching cubes to keep rendering interactive
- Debounce slider changes (50ms) to avoid repeated expensive recomputes
- Use periodic=false to clip isosurfaces at cell boundaries (matching VESTA)

* Fix camera sync infinite loop on isosurface demo page

The on_camera_move callback always created a new synced_scene_props
object (via spread), triggering Structure's $effect.pre which re-emitted
the camera move, causing effect_update_depth_exceeded.

Skip the write when position/target haven't actually changed.

* Move DraggablePane controls to side tab outside content area

The drag handle, reset, and close buttons were overlapping internal pane
content (e.g. IsosurfaceControls reset button). Move them into a small
tab protruding from the pane's right edge so they never obscure content.

* Add large-grid CHGCAR test file for performance testing

80x80x96 grid (614K points) with FCC-like Si4 structure and bond charge
density for testing isosurface downsampling and rendering performance.

* Fix downsample_grid edge case and expand tests

The fixed-stride block mapping (ix * factor) produced empty blocks when
max(2,...) clamping gave more output cells than ceil(n/factor). Switch to
proportional partitioning that evenly divides [0,n) into non-empty blocks
regardless of axis size vs factor.

Also trim large test grids (200^3, 480x48x576) to keep the suite fast.

* Remove redundant volume tracking and tighten coverage test

- Drop void volume from $effect — ds_result already depends on volume
- Replace uniform-data coverage test (can't detect gaps) with non-uniform
  weighted reconstruction that verifies no source cells are lost or
  double-counted
- Remove redundant output shape test (implicitly covered by all others)
- Remove unused n_src variable

* Fix anisotropic budget overflow and broken pane selector

- downsample_grid: iterate factor until clamped output fits budget;
  the single cbrt step overshot for shapes like 2000x2000x2 where
  max(2,...) prevents the small axis from shrinking
- DraggablePane: fix > section > div selector broken by pane-content
  wrapper (direct-child no longer matches); use descendant selector
- DraggablePane: replace magic -4px max-height with inherit
- Test: fix "exactly 500K" to actually use 500K (100x100x50)
- Test: add anisotropic 2000x2000x2 budget case

* Update DraggablePane test for control-tab rename

The class was renamed from control-buttons to control-tab but the test
selector wasn't updated.

* Fix extreme aspect ratio test to actually trigger downsampling

The test used 1000x3x3=9K which is under budget, so downsample_grid
returned early without exercising the clamping path. Use 500x500x3=750K
which exceeds the budget and tests the min-2 clamping on the z-axis.

* Fix output dim exceeding source dim in downsample_grid

max(2, ceil(nx/factor)) can produce new_nx > nx when nx=1, causing
partition to generate out-of-bounds indices and division by zero.
Clamp each output dim to not exceed the source dim.

* Add periodic wrapping toggle for isosurfaces

Adds a "Periodic" checkbox to IsosurfaceControls that wraps isosurfaces
across periodic cell boundaries instead of clipping at cell edges.
Disabled by default (preserving current VESTA-style clipping). Only
takes effect for periodic volume data (CHGCAR); non-periodic .cube files
are unaffected regardless of toggle state.

* Cap controls pane height, fix comment, remove debug logs

- StructureControls: set --pane-max-height to 70vh to prevent stretching
  off screen on shorter viewports
- downsample_grid: fix comment to accurately describe clamp_dim behavior
  (returns 1 for single-cell axes, not 2)
- Remove debug instrumentation from Isosurface.svelte

* Fix reset button closing pane instead of resetting position

reset_position() sets show_control_buttons=false, which removes the
button from the DOM. The click then bubbles to the document handler
where pane_div.contains(detached_node) returns false, triggering
close_pane(). Fix by stopping propagation on the reset button click.

* Add resize grip to DraggablePane

Adds a bottom-right diagonal grip (3 lines like a textarea) for drag-to-
resize. New resizable prop controls the mode: 'both' (default), 'width',
'height', or 'none'. Reset position also clears custom size.

* Reset pane size on double-click of resize grip

* Add Playwright tests for isosurface controls and DraggablePane

Tests cover:
- Neg. lobe toggle adds/removes negative surface
- Periodic toggle is present and toggleable
- Resize grip visible, drag-to-resize changes width
- Double-click resize grip resets size
- Control tab shows reset/close after drag, reset keeps pane open

* Simplify downsample_grid tests

- Parameterize 3 uniform-value tests (positive/negative/small-axis) into
  one test.each with shared assert_all_cells helper
- Inline grid_mean (used only once)
- Remove redundant toBeLessThanOrEqual assertion after toBe(1)
- Extract triple-nested cell check into reusable assert_all_cells helper

* Fix outdated comment about periodic being always false

* Pin svelte to 5.52.0 to work around mdsvex breakage

Svelte 5.53.0+ adds a _comments key to the parser output that crashes
mdsvex's extract_parts (pngwn/MDsveX#778). Fix pending in
pngwn/MDsveX#779. Revert once mdsvex releases the fix.

* Replace periodic wrapping with halo-padded grid extension

The old wrap_periodic toggle passed periodic=true to marching cubes,
creating stretched triangles across the cell. Replace with halo padding:
pad_periodic_grid copies border cells from the opposite face onto each
boundary, then marching cubes runs on the larger grid with periodic=false.
Isosurfaces naturally extend beyond the cell to close partial spheres
into complete enclosed shapes.

* Increase periodic halo padding from 15% to 30% to close sphere holes

* Replace Periodic checkbox with Halo range slider

Users can now drag the Halo slider (0-0.5) to control how far
isosurfaces extend beyond cell boundaries. At 0 (default), surfaces
clip at the cell edge. Sliding right extends them further to close
partial spheres. Replaces the binary wrap_periodic toggle.

* Refactor isosurface extraction, fix DraggablePane overflow/resize, improve select UX

- Hoist grid padding into rebuild_geometries so it's computed once per rebuild
  instead of per-layer, make extract_surface a pure function
- Precompute partition ranges in downsample_grid to avoid redundant Math.round
  in inner loop; clamp negative pad_fraction in pad_periodic_grid
- Extract vecs_equal to $lib/math as shared utility
- Fix pane content overflow: add box-sizing: border-box to .pane-content
- Fix resize grip click-outside race: use pointer capture + rAF to defer
  resizing flag, clear maxHeight in position effect
- Default resizable to 'none', opt in with resizable='both' in StructureControls
- Fix ColorScaleSelect/Color scheme select: remove pointer-events: none so
  clicking selected item opens dropdown, use <label> + flex layout to prevent
  width overflow, collapse search input with ulSelectedStyle/inputStyle

* Add vecs_equal tests and strengthen isosurface type tests

Cover vecs_equal edge cases (undefined, identity, strict equality).
Parameterize downsample_grid no-op and pad_periodic_grid early-return
tests. Add coverage for negative pad_fraction clamp, floor(n/2) cap,
and anisotropic dims. Merge redundant dims/offset tests.

* Fix periodic=true regression causing stretched boundary surfaces

* Fix resize grip Playwright failures in CI

Revert setPointerCapture to document listeners — headless Chromium
doesn't reliably redirect pointerup to captured elements during
Playwright's simulated mouse events, causing on_up to not fire and
the pane to close via click-outside. Add explicit pane visibility
assertions after drag for clearer failure diagnostics.

* Remove compare mode, reference overlay, and debug panel from isosurface demo

These were development/debugging tools added while fixing the VESTA
rendering discrepancy. Now that isosurface rendering is correct, they
clutter the demo page without providing user value.

* Add slice resolution slider and editable number inputs

Add n_points parameter to sample_hkl_slice for user-controlled
resolution. Finer interpolation produces smoother slices. Replace
static text labels with editable number inputs for both the d
position and resolution controls, allowing precise value entry.

* Replace isosurface file buttons with FilePicker component

Reuses the existing FilePicker for the isosurface demo page instead of
a custom nav. Adds label/type support to FileInfo, colored type badges
(shown only when label hides the extension), volumetric format colors,
and fixes the legend divider visibility. Also inlines reset_parse_metadata
and flattens the now-unnecessary viewer-grid wrapper.

* Swallow post-resize click to prevent pane closure in CI

The resizing flag guard was insufficient — in headless Chromium,
pointerdown may not reach the grip's handler, so resizing was
never set to true. Instead, swallow the click event that fires
after pointerup using a one-time capture-phase listener.
