Goal
Add clouds to projects/raytrace as a volumetric scattering medium: rays entering a bounding box integrate a continuous density field ρ(x) with Beer-Lambert extinction and single-scattering brightening, instead of treating clouds as boolean geometry. This gives translucent wispy edges, opaque cores, and sun-lit self-shadowing.
Gap: noise library is 2D only
The projects/noise library's point/vector types are hardcoded to 2D (geometry::point_<2> / xmmt::double2), and every generator is 2D:
perlin(point, ...), simplex(point, ...), worley(point, ...)
fractal_brownian(point, ...) — the FBM helper exists but only for 2D
cell_flows/fade/hash_* underpinning the above
There is no 3D variant of any of these, so a 3D FBM density requires new foundational noise first.
Proposed work
1. noise project — 3D support
Add 3D point_/vector_ aliases and a 3D hash.
Generalize perlin (and ideally simplex) to 3D — classic improved Perlin generalizes directly (8 corner gradients).
Add a 3D fractal_brownian(point_3,...) overload sharing the octave loop with the 2D version.
2. raytrace — density + integration
CloudLayer: owns the bounding box, material params (extinction σ, scattering albedo), sun direction, and a density(R3 point) -> precision closure:
```
ρ(p) = fbm3(p * scale) * verticalProfile(y) * horizontalEnvelope(xz)
```
CloudIntegrator: ray-box intersection for entry/exit, then step through the volume summing τ = Σ ρ Δs, with T = exp(-σ·τ) and a sun-facing gradient term for local brightening.
3. Tests (gtest)
3D noise: FBM mean unit range, Perlin continuity/gradient sanity vs the 2D harness.
Density: profiles peak mid-layer and taper to zero at the box faces; integrand non-negative.
Integration: uniform-density box recovers Beer-Lambert exactly; empty box transmits 1.
Definition of done
world_outrun/the demo camera loop renders a cloud bank with lit tops and soft, translucent undersides, backed by the 3D FBM density model.
