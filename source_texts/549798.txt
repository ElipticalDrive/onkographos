An example should be implemented that demonstrates how to utilize the GPU to speed up the ray tracing process. Given the simplicity of the basics.cpp example, it would probably be a good idea to implement a version of this example that uses the GPU in order to create rays and process sphere and triangle intersections. This example should be implemented while pulling in as few external libraries as possible and duplicating as little code as possible.
