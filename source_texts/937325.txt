Descrição
O noise3D em terrain.js não é verdadeiramente 3D. É uma aproximação que combina duas chamadas noise2D:
```
noise3D(x, y, z) {
  const a = this.noise2D(x + y * 0.31, z + y * 0.17);
  const b = this.noise2D(x * 1.7 + z * 0.23, y * 1.3 + x * 0.11);
  return (a + b * 0.5) / 1.5;
}
```
Localização
src/world/terrain.js — método noise3D da classe SimplexNoise
Problema
Como usa noise2D, as cavernas geram padrões沿线 (column-like) ao longo de eixos
Cavernas aparecem como tubos retos ou fatias ao invés de volumes 3D orgânicos
Os artefatos de cisalhamento (shearing) ficam visíveis quando se voa ou cai em uma caverna
A distribuição não é isotrópica — cavernas são mais longas em certos eixos
Solução sugerida
Implementar Simplex Noise 3D verdadeiro (o algoritmo de Akenine-Möller é bem documentado) ou usar uma biblioteca como simplex-noise do npm que suporta 3D nativamente.
Gravidade
Média — Cavernas funcionam mas têm artefatos visuais óbvios para jogadores atentos
