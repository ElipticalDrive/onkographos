Summary
This PR introduces GPU acceleration for PyRadiomics shape features (volume, surface area, diameters) using CUDA kernels.
It integrates transparently into the existing API, achieving 7×–85× speedups while maintaining numerical consistency with the CPU version.
Key Changes
CUDA Marching Cubes
Parallel cube processing for surface/volume.
Optimizations: shared memory caching, coalesced memory access, Structure-of-Arrays layout.
CUDA Diameter Kernel
Parallel distance computation for maximum 3D & plane-restricted diameters.
Optimizations: equal work distribution, local accumulators, shared memory tiling, block-level reduction.
Integration
Conditional compilation (CUDA_EXTENSIONS_ENABLED).
Runtime GPU detection with CPU fallback.
API preserved – no user code changes.
Testing & Benchmarks
Validation against CPU with floating-point tolerance.
Automated benchmarking on RTX 4070, Tesla T4, and A100.
Speedups: 7×–85× depending on GPU & dataset.
