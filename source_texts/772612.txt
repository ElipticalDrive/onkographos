Introduces the minimal infrastructure to read a VTK multiblock (.vtm) file
and produce a fully initialised NeoN UnstructuredMesh:

- cmake: add NeoN_WITH_VTK option, VTK 9.6.0 dependency (CommonCore,
  CommonDataModel, IOXML, FiltersCore)
- io/connectivity: cell-to-face reconstruction from vtkUnstructuredGrid
  (faceTopology, cellReconstruction, nodeOrdering, vtkExtraction)
- io/geometry: face centres/areas and cell centres/volumes computation
- io/meshConverter: buildBoundaryMesh + multiBlockPatchNames helpers,
  adapted to the current develop BoundaryMesh constructor
- io/vtmMeshReader: readVtm() — reads block 0 as volume grid, matches
  boundary faces to VTM patches by sorted node-set, builds a permuted
  face layout grouped by patch, stores faceNodes/patchNames in stencilDB
