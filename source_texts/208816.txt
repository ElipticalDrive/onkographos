Parent
Part of the production planetary voxel terrain umbrella in #60 and the extraction gate in docs/planetary_voxel_renderer_plan.md. Builds on the bounded residency contract from #62 and GPU atlas/page table from #65.
Goal
Implement and measure GPU Transvoxel and feature-preserving manifold dual-contouring extraction against the same authoritative planetary page/cache API, then promote exactly one production extractor using the documented performance, topology, and quality gate.
Scope
Define one shared extraction input/output contract over resident page slots, generation IDs, neighbor halos, dirty microbricks, transition masks, and bounded mesh arenas.
Add deterministic scalar-field fixtures covering planes, spheres, caves, thin features, sharp corners, materials, negative page coordinates, and adversarial 2:1 LOD boundaries.
Implement GPU Transvoxel classification, compaction, vertex/topology emission, and transition cells.
Implement GPU feature-preserving manifold dual contouring with deterministic Hermite/QEF handling and topology tests.
Build generation-tagged bounded vertex/index/meshlet outputs; retain the old generation until replacement publication completes.
Add GPU readback validation for indices, bounds, topology, cracks, stale generations, capacity overflow, and cross-page seams.
Record dirty-page latency, total frame cost, vertex/triangle/meshlet counts, upload/dispatch bytes, geometric error, crack count, and manifold failures on identical inputs.
Promote dual contouring only if it stays within 25% of Transvoxel dirty-page time while materially reducing mesh size or error and passing all manifold/crack gates. Otherwise promote Transvoxel.
Remove the losing implementation from the production graph after retaining benchmark fixtures and evidence.
Compatibility boundaries
Do not modify voxel_demo, voxel_demo_raymarch, their existing passes, or helio-voxel-core.
Do not reuse or resize existing voxel pools.
Do not require mesh shaders, sparse textures, ray tracing, or vendor extensions.
Do not change the default graph or required GPU features when the planetary extension is disabled.
Acceptance gates
Both prototypes consume the same resident page representation and fixtures.
Rust/WGSL layouts and all append/indirect capacities have executable parity and overflow tests.
Neighbor halos and adversarial 2:1 transitions produce no holes or T-junction cracks.
Dual-contouring output passes manifold topology checks before it can be selected.
Stale jobs cannot replace current mesh generations; the prior mesh remains visible until atomic publication.
Arena memory remains within configured budgets under repeated edits, eviction, and replacement.
GPU readback proves index validity, bounds containment, transition coverage, and capacity safety.
Benchmark evidence records both algorithms on the same hardware, pages, and dispatch limits.
Exactly one extractor is selected by the documented 25% gate and the decision is committed to the tracker.
Existing voxel demos and default graph regression checks remain unchanged and pass.
Stop/redesign conditions
Stop and redesign this milestone if neither extractor can produce crack-free 2:1 topology within bounded arenas, if dirty-page backlog cannot meet the edit-latency target after focused optimization, or if integration requires changing default Helio behavior.

CPU manifold-oracle validation found a real topology failure before the GPU path could be promoted: a dense ambiguous field produced 461 non-manifold indexed edges and 1,070 non-manifold vertices even though the smooth fixtures passed.
Root cause: DMC permits distinct parallel topological edges between the same QEF vertices, but direct quad triangulation collapses them into one index edge. Page ownership can also clip a boundary cycle into disconnected fans sharing one index.
PR #105 corrects the oracle with canonical face-segment/quad-center simplicial subdivision plus deterministic disconnected-link splitting. The original failing dense field now reports zero non-manifold edges and vertices; closed-sphere, adjacent-page parity, material, QEF, full planetary GPU regressions, strict clippy, Helio lib, and both retained voxel demo checks are green.
Issue #96 stays open: the GPU manifold implementation must now reproduce this corrected topology before the matched extraction benchmark.
