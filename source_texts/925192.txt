Follow-up user request, 19 October 2026. Tracking: #3.
User need
A reusable procedural noise and pattern library that can be called from Clay Form to add detail to meshes as textures, texture paint, brush alphas or geometry displacement. Provide an editable noise modifier that can be switched on/off for a non-destructive workflow.
Shared generator library
Investigate a reusable internal API and suitable dependencies, including licensing, maintenance, deterministic output and CPU/GPU tradeoffs. All consumers should use the same generator definitions and saved presets.
Scope a broad initial palette: value/gradient noise, cellular/Voronoi, fractal/fBm, ridged/turbulence variants, domain warping, and geometric patterns such as waves, stripes, checker/grid and spots. Publish supported generators and stage additional families explicitly.
Expose appropriate seed, scale/frequency, amplitude, octaves, persistence/lacunarity, offset/rotation, contrast/remapping and blending controls, with previews and reusable named presets.
Define 2D/3D sampling, object/world/UV coordinates, tiling/seam behavior, numeric ranges and versioned reproducibility. Sampling should not change merely because the camera moves.
Consumers
Generate standalone texture images and material-channel inputs, with explicit resolution, precision and colour/data interpretation; bake/export to images for external editing or Blender exchange.
Use generators as a texture-paint source, with brush strength, pressure, masks, spacing and blend controls through Paint texture images directly through the model viewport #11.
Generate reusable relief/height alphas and integrate their presets/assets into Improve alpha creation, library management, stencils, and brush integration #14, including scale, inversion, falloff and stamp preview.
Add a persistent per-submodel noise/displacement modifier with enable/bypass, editable parameters and seed, strength, mask/vertex-group influence and a clearly defined displacement direction. Toggling off restores the unmodified upstream result; re-enabling produces the same detail.
Define modifier order relative to subdivision, thickness, topology changes and other modifiers. Preview must leave source geometry intact; an explicit apply/bake creates geometry in one undoable operation. Handle inadequate mesh resolution and invalid/non-finite outputs clearly.
Save generator versions/parameters and modifier state. Keep previews responsive with bounded jobs and cancellation, and define export behavior for live procedural content versus baked results.
Acceptance
Demonstrate several distinct generator families and repeatable output from saved seeds/presets after reopening a project.
Use the shared generator through texture creation, painting, alpha stamping and a geometry modifier; verify consistent mapping and parameter interpretation.
Toggle and edit the modifier repeatedly without accumulating deformation; test mask/group influence, ordering and source edits. Apply, undo and redo without losing the original editable state.
Verify documented tile seams, object/world mapping and UV behavior; test representative mesh/image sizes and cancellation.
Export a generated image for GIMP/Blender and compare its values/appearance against the in-app result under the documented conventions.
Dependencies and staged delivery — reviewed 25 October 2026
Texture-paint foundation #11 and its UV prerequisite #12 are complete in merged PR #63. The procedural library and its consumers are now unblocked and in Backlog. Alpha library #14 is complete, with its native link retained as history.
The standalone generator library, presets and geometry modifier can start independently. Coordinate modifier evaluation with #19 and later consumers with #65/#66/#67/#69, without making those entire features prerequisites. Deliver core generators/modifier first if useful, then dependent consumers.
