Summary
Adds a 19-slide PowerPoint presentation on 3D Gaussian Splatting (Kerbl et al., SIGGRAPH 2023), generated programmatically with python-pptx.
Contents
The deck covers:
Background & motivation (NeRF limitations, problem definition)
Core method (3D Gaussian representation, spherical harmonics, differentiable splatting)
Rendering pipeline and training (loss, adaptive density control)
3DGS vs NeRF comparison table
Results, applications, limitations, and future directions
Technical evolution timeline and summary
Files
3D_Gaussian_Splatting.pptx — ready-to-use presentation (dark tech theme)
scripts/create_3dgs_ppt.py — generator script for easy edits and regeneration
Usage
```
python3 scripts/create_3dgs_ppt.py
```
Output is written to 3D_Gaussian_Splatting.pptx in the repo root.
