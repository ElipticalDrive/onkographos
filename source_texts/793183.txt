What to build
Add a separable nonlinear color transformation that completes the public workflow while measuring interpolation approximation against independent analytic values instead of limiting the oracle to exact linear cases.
Covers user stories 9, 11, 14, 19, 21, and 25 from #25.
Acceptance criteria
Evaluation inputs include neutral, primary, and secondary ramps plus deterministic pseudo-random samples from a recorded seed.
Trilinear and tetrahedral cases each report approximation metrics against independently generated expected values.
Numerical gates are explicit test metadata and expected values are never generated by the evaluator under test.
A valid case that misses its numerical gate emits a deterministic failed report and exits 1, distinct from invalid input.
