Implements all Project 7 requirements in project_7_script.js and a new project_7_vol.wgsl, referencing the patterns established in scrolls 11 and 12.
Shader (project_7_vol.wgsl)
24 compute entry points — 12 rendering modes × 2 camera types (orthogonal + projective/pinhole):
Mode
Technique
MIP
Maximum Intensity Projection
DRR
Beer-Lambert X-ray simulation
LinearTF
Linear intensity → opacity mapping, front-to-back alpha compositing
PiecewiseTF
5-stop piecewise linear colour + opacity
GradientTF
Central-difference gradient magnitude → edge highlight
SpectralTF
ROYGBIV rainbow colourmap
WarmCoolTF
Cool-blue → warm-orange cinematic ramp
Terrain
DDA voxel traversal with Lambertian face shading
Cloud / Fire / Smoke
Perlin volumetric density, alpha compositing, per-effect colour palettes
Composed
Terrain DDA + cloud layer composited in one pass
Data generators (project_7_script.js)
ProceduralSphereData — analytic sphere + torus density field (64³, 12-bit range)
BiasedTerrainData(bias) — Perlin fBm heightmap; bias shifts biome distribution:
Grass 0.00, Snow +0.28, Water −0.28, Dirt/Rock +0.15
CloudData / FireData / SmokeData — 3-D Perlin turbulence at 64³
ComposedSceneData — terrain codes [1–6] in lower 55 % + cloud density [100–200] in upper layers, both in one 128×64×128 buffer so the composed shader can distinguish them with a single voxel read
Rendering object & scenes
Project7Object extends VolumeRenderingObject: manages 11 GPU dataset buffers and all 24 pipelines, selecting the correct (mode, cameraType) pair per frame.
17 named scenes cover every rubric item — switchable via Tab/Shift+Tab or 1–0; camera controllable with WASD, Q/E, arrow keys, Z/X, P (toggle ortho↔projective), +/− (focal), R (reset).
