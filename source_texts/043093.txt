SynPhoRest v2.0 is a software developed for the generation of synthetic dataset related to forest environments. By applying procedural generation, SynPhoRest is able to generate a virtual forest environment and allow the extraction of  RGB images, semantic segmentation maps and depth maps. The virtual environment is navigable, using both grounded and aerial POVs, with togglable view modes for each data type available. The extraction can be performed manually or using the automated methods included, with each group of data being stored in the appropriate folder at the launcher directory.  Related to the article "SynPhoRest - A Procedural Generation Tool of Synthetic Photorealistic Forest Datasets" DOI: 10.1007/978-3-031-58676-7_6, as part of  "Robot 2023: Sixth Iberian Robotics Conference",  Lecture Notes in Networks and Systems book series volume 976.
