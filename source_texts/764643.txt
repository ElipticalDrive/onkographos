Summary
This PR introduces Blockwelt, a complete, self-contained Minecraft-like voxel game that runs entirely in the browser. The game features procedurally generated terrain, block placement/destruction, player physics, and a chunk-based rendering system—all without external assets or build tools.
Key Changes
Procedural world generation — Uses seeded Perlin noise (fBm) to generate terrain with varied biomes (grass, sand, water), plus randomly placed trees. Each session generates a unique world.
Voxel rendering system — Implements chunk-based mesh generation with face culling and vertex colors. The world is divided into 16×16 chunks, each with merged opaque and transparent (water) geometry for efficient rendering.
Player mechanics — Full first-person controller with:
WASD movement, mouse look with pointer lock
Gravity-based jumping and sprinting
Toggle-able flight mode
AABB collision detection against the voxel grid
Block interaction — Left-click to break blocks, right-click to place them. Seven block types available via hotbar (grass, dirt, stone, sand, wood, leaves, water).
Self-contained implementation — Includes:
Custom seeded RNG (mulberry32) and Perlin noise implementation (no external noise libraries)
Three.js for 3D rendering (vendored locally)
Plain HTML/CSS/JS with no build step or external dependencies at runtime
UI & UX — Start/pause overlays, hotbar selection, debug info display, crosshair, and responsive controls.
Notable Implementation Details
Noise generation: Implements 2D Perlin noise with gradient interpolation and fBm for multi-octave terrain variation
Chunk meshing: Dynamically rebuilds affected chunks when blocks are placed/destroyed
Collision: Separates axis-aligned movement to allow sliding along obstacles
Materials: Uses vertex colors instead of textures for block faces, reducing asset requirements
Performance: Fog and limited draw distance keep rendering efficient for the 64×64×40 world
The game is fully playable immediately upon loading—no installation, compilation, or external services required.
