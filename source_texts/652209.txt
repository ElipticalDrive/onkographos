Sorry for never having responded, it must have somehow got lost in my inbox.
Perspective transformations would be nice but cannot be captured by a linear transformation matrix. Perhaps we could work towards a more general transformation mapping structure such that we can also support radial / polar coordinates for example. Perhaps something along func(Coord) Coord would do. This would be a pretty heavy undertaking though, since a lot of code would need to be touched. Also, I'm not sure what the performance would be given that most rendering targets (PDF, SVG) work with affine transformation matrices exclusively.
