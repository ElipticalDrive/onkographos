为 Apple GPU 和基于瓦片的延迟渲染量身打造 App
了解 Apple GPU 的特色功能，包括图像块、瓦片着色器和光栅排序组。
概览
Apple 芯片中的 GPU 实现了一种称为瓦片式延迟渲染 (TBDR) 的渲染技术，可优化性能和能效。GPU 将渲染目标分解为由较小区域组成的网格，这些区域称为瓦片。它会用一个 GPU 核心处理每个瓦片，并常常同时运行多个核心。GPU 会延迟每个瓦片的渲染阶段，直到评估完该瓦片的所有几何体。
从 A11 开始，Apple 设计的 GPU 提供了多项可显著增强 TBDR 的功能。你的 App 可以通过 Metal API 访问这些增强功能，帮助 App 和游戏达到新的性能和能力水平。这些功能包括 imageblocks、tile shading、raster order groups 和图像块采样覆盖率控件。A11 及更高版本的 Apple GPU 还可提升片段丢弃性能，并简化 subsurface scattering、order-independent transparency 和 tile-based lighting algorithms 等技术的实现。
分块延迟渲染，绘制更多内容
您的 App 可以在 TBDR GPU 上绘制更复杂的场景，因为它通过节省时间、能耗和内存带宽，性能显著优于传统的即时模式 (IM) GPU。例如，即时模式 (IM) 会完全处理线条和三角形等基元，无论它们在渲染中是否可见。
TBDR GPU 通过同时处理渲染通道的所有几何体并仅对可见的原始体进行着色来避免执行不必要的工作。GPU 将工作拆分为拼贴，以便能够单独且同时处理与每个拼贴相交的所有几何体，并丢弃任何被遮挡（或隐藏）的原始体。然后，GPU 为每个拼贴从剩余的可见原始体生成片段（或潜在像素），使用片段着色器处理片段，并将片段写入 拼贴内存。拼贴内存是快速、临时存储器，驻留在 GPU 本身。GPU 完成将每个拼贴渲染到拼贴内存后，会将最终结果写入设备内存。
瓦片内存是 TBDR 的重要组成部分，因为尽可能避免访问设备内存可节省时间和能量。片段着色器核心对瓦片内存的访问比 GPU 对设备内存的访问有重要优势，包括以下几点：
比设备内存快数倍的带宽
访问延迟远低于设备内存
能耗显著低于访问设备内存
当 GPU 运行渲染通道中写入分块内存的最后阶段时，可以开始后续渲染通道的顶点阶段。由于这两个阶段往往使用不同的计算和内存组件，因此 GPU 通过并行运行这两个阶段可以同时使用更多硬件块。
使用 imageblocks 自定义片段着色器
你可以在图形处理器的高带宽内存区域 imageblock memory 中定义和操作自定义的每像素数据结构。Imageblock 是存储在本地内存中的结构化图像数据的图块，可让你描述 Apple GPU 可以高效地操作的图块内存中的图像数据。Imageblock 与片段处理和图块着色阶段深度集成，也可用于计算内核。Metal 一直以来都在搭载 Apple 芯片的设备上向 imageblock 渲染，但从 A11 GPU 开始，Metal 让你可以完全控制 imageblock 中的数据结构。Imageblock 可在渲染通道的片段和图块阶段之间传递数据。线程组内存适用于非结构化数据，但 imageblock 更适用于图像数据。
图像块是具有宽度、高度和像素深度的 2D 数据结构。图像块中的每个像素可以由多个分量组成，你可以将每个分量作为其自己的图像切片来寻址。例如，你可以有三个图像切片，分别 represent 反照率、镜面反射和法线分量。
图像块可用于内核函数和片段函数，并在图块的整个生命周期内（贯穿多次绘制和分派）持续存在。图像块持久化意味着，你可以使用图块着色器在单个渲染通道中混合渲染和计算操作，且两者都可以访问同一个本地内存。通过将多个操作保留在图块内，你便可以创建能驻留在本地 GPU 内存中的复杂算法。
你现有的代码会自动创建与渲染附件格式相匹配的 imageblock。不过，你也可以在着色器中完全定义自己的 imageblock。你定义的 imageblock 可以比渲染附件创建的那些复杂得多。例如，imageblock 可以包含额外的通道、数组和嵌套结构。此外，你可以在计算的不同阶段为不同目的重复使用所定义的 imageblock。
在片段着色器中，当前片段只能访问与其在图块中的位置关联的 imageblock 数据。在计算函数中，线程则可以访问所有 imageblock 数据。使用附件进行渲染时，加载和存储操作仍然会在图块内存中读取和写入数据。但是，如果使用显式 imageblock，请使用计算函数来显式读取和写入设备内存。GPU 可能会利用内存硬件，通过高效的块传输将图块内存的内容自动刷新到系统内存。
使用瓦片着色器在渲染和计算通道中节省内存带宽
瓦片着色可让你将渲染和计算操作合并到单个渲染通道中，同时共享本地内存。许多渲染技术需要绘制和计算命令的混合。传统 GPU 将渲染和计算命令分别分为不同的通道。这些通道通常不能直接相互通信。App 通过将一个通道的结果保存到设备内存中，然后将该数据加载回下一个通道来解决此限制。在某些情况下，例如在多阶段渲染算法中，应用可能会多次将中间数据复制到设备内存中。
分块着色器是在渲染通道中执行的计算或片段函数。它们允许你的 App 计算数据并将其保存到 GPU 上的分块内存中，该内存在不同渲染通道之间会持久保留。
使用瓦片着色器的 App 可以通过将数据存储在更快的瓦片内存中来避免将中间结果存储到设备内存中，从而节省时间。
光栅顺序组的序列操作
你的 App 可以使用 光栅排序组 精确控件访问相同像素坐标的并行片段着色器线程的顺序。光栅排序组提供片段着色器有序内存操作并简化渲染技术，例如与顺序无关的透明度、双层几何体缓冲区和体素化。
Metal 保证 GPU 按绘制调用顺序进行混合，从而营造出 GPU 按顺序渲染场景的错觉。例如，这里有一个包含两个重叠三角形的场景。蓝色三角形部分遮挡其后面的绿色三角形。
每个三角形的片段着色器在各自的线程上并发运行。后部三角形的片段着色器可能不会在前部三角形的片段着色器执行之前执行，这对于需要其他三角形着色器结果来执行自定义混合函数的着色器来说可能是个问题。由于并发，此读取-修改-写入序列可能会创建竞态条件。
光栅顺序组通过同步针对相同像素坐标和采样的线程，来克服这种访问冲突（如果你启用逐样本着色）。
若要实现光栅排序组，请使用属性限定符注释内存指针。通过这些指针访问像素的着色器将按照每个像素提交顺序进行。硬件将等待任何与当前线程重叠的较旧片段着色器线程完成，然后才继续当前线程。
近期 Apple GPU 上的 Metal 扩展了光栅顺序组，为其增添了额外功能。它们允许你同步 imageblock 和线程组内存中的各个通道。你也可以创建多个顺序组，从而实现更精细的同步，并最大程度减少线程等待访问的次数。例如，这些光栅顺序组可以提高 延迟着色 技术的性能，这是一种流行的照明技术，与 TBDR 无关。传统上，延迟着色需要两个阶段：
填充几何缓冲区（或g-缓冲区）并生成多个纹理。
通过使用这些纹理计算着色结果来渲染光体积。
延迟着色会耗用大量内存带宽，因为着色器在第一阶段将这些纹理写入设备内存，然后在第二阶段又将它们读回。你可以使用多个顺序组将两个渲染阶段合并为一个，从而无需使用中间纹理。为此，请将几何缓冲区保持为瓦片大小的区块，以便它们能保留在本地 imageblock 内存中。
在传统 GPU 上，负责次要光源的线程需要等待前一个线程完成后才能开始访问。此等待会迫使线程串行运行，即使内存操作之间没有冲突。
你可以使用多个顺序组并发运行互不冲突的读取：
将三个几何缓冲区字段（反照率、法线和深度）添加到第一个组
将累积光照结果添加到第二组
Apple GPU 可以将这两个组分别排序，这样对第二个组的未完成写入就不会阻碍对第一个组的读取。
两条线程在执行结束时同步，以累加光照效果。
使用增强型多重采样抗锯齿自定义像素混合
你可以通过在瓦片着色器内访问多重样本跟踪数据来创建自定义多重样本消除锯齿（MSAA）算法。MSAA 是一种通过为每个像素使用多个深度和颜色样本来改善原始体边缘外观的技术。
每个像素只有一个采样点，三角形要么覆盖该点，要么不覆盖，这在某些角度下可能导致边缘出现锯齿。
不过，4x MSAA 通过在四个不同位置对每个像素进行采样来平滑锯齿边缘。GPU 会平均像素内每个样本的颜色，以确定其最终颜色。
Apple GPU 具有高效的 MSAA 实现。硬件会跟踪每个像素是否包含图元的边缘，因此仅在必要时运行逐样本混合。如果另一个图元覆盖了像素内的样本，GPU 便只会对整个像素混合一次。
Apple GPU 会跟踪每个像素的唯一样本（或颜色）数量，并在渲染新图元时更新该数据。例如，考虑一个包含两个重叠三角形边缘的像素，其样本位置代表三种不同的颜色。
A11 之前的 Apple GPU 会逐个混合像素覆盖的三个样本。从 A11 开始，Apple GPU 仅混合两次，因为有两个样本共享相同的颜色。在此示例中，索引 1 处的颜色是绿色和粉色的混合，索引 2 处的颜色是粉色。
Apple GPU 可以减少像素中的唯一颜色数量。例如，如果 GPU 在先前的三角形之上渲染不透明三角形，就会用单一颜色来表示该像素。
在这种情况下，新的三角形会覆盖所有样本，GPU 可以通过将三种颜色合并为一种来 represent 单一颜色。
你可以通过修改图块着色器中的采样覆盖率数据来实现自定义解析算法。例如，考虑一个包含不透明几何体和半透明几何体的单独渲染阶段的复杂场景。你可以在混合半透明几何体之前添加一个图块着色器来解析不透明几何体的采样数据。
分块着色器处理本地内存中的数据，并可作为不透明几何阶段的一部分。
