[ENH] Conforming unit tetrahedra from closed volumes via TetGen
ClosedUnitVolumes.tetrahedralize() meshes all units at once with TetGen
(optional tetgen package): the shared complex is the PLC, each shell piece
gets a winding-number-checked region seed, input triangle index is the facet
marker so boundary faces map back to their patch and side units.
collapse_short_edges: feature-preserving needle collapse on the shared
complex (patch-interior vertices merge, feature-line vertices slide, junctions
fixed; link and fold checks; re-audited). Model 7 quality meshing goes from
40 s / 670k tets to ~1.1 s / 78k tets.
Self-intersections raise closed_volume_self_intersection; unit tet volumes
must equal the shell volumes.
UnitTetMesh data class, example --tetrahedralize, docs and tests.
Co-Authored-By: Claude Opus 5.5 noreply@anthropic.com
[ENH] Add explode and inset options for tetrahedral visualization
Enhanced render_tetrahedra to support exploded and inset visualizations with explode and inset parameters.
Updated CLI to include --explode and --inset options for visualization customization.
Refined mesh rendering to enable exploded unit separation and inset box filtering for improved visualization clarity.
