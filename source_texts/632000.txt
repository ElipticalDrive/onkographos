Contributor
Adds interactive 3D point cloud visualization examples demonstrating capabilities similar to the VGGT (Visual Geometry Grounded Transformer) CVPR 2025 Best Paper demo.
Changes
examples/point_cloud.py: Basic point cloud example with 10K points, scalar coloring, and interactive camera controls
examples/point_cloud_streamlit.py: Advanced Streamlit app featuring:
4 procedural models (sphere, torus, bunny, double helix)
Model switching and density controls (1K-20K points)
Multiple coloring modes (elevation, distance, X/Y coordinates)
8 colormaps with real-time statistics display
examples/README.md: Comprehensive documentation for all examples with usage instructions
pyproject.toml: Added NPY002 and ERA001 exemptions for examples directory
Example Usage
```
import numpy as np
import pyvista_js as pv

# Generate point cloud
theta = np.random.uniform(0, 2 * np.pi, 5000)
phi = np.random.uniform(0, np.pi, 5000)
r = np.random.normal(1.0, 0.1, 5000)

points = np.column_stack([
    r * np.sin(phi) * np.cos(theta),
    r * np.sin(phi) * np.sin(theta),
    r * np.cos(phi)
])

# Create and visualize
point_cloud = pv.PolyData(points)
point_cloud.point_data["elevation"] = points[:, 2]

plotter = pv.Plotter()
plotter.add_mesh(point_cloud, scalars="elevation", cmap="viridis", style="points")
plotter.show()
```
The Streamlit version provides an interactive UI for exploring different point cloud models and visualization parameters.

<issue_description>## Summary
Add a sample/example that demonstrates interactive 3D point cloud visualization similar to the VGGT (Visual Geometry Grounded Transformer) demo page.
Background
VGGT is the CVPR 2025 Best Paper Award winner that performs 3D reconstruction from images. Their demo page features:
Interactive 3D point cloud viewers with camera orbit controls
Dense point cloud rendering from multi-view depth estimation
Side-by-side comparison views of 3D reconstructions
Thumbnail galleries with clickable 3D model switching
Real-time WebGL-based rendering
Proposal
Create a sample page using pyvista-js that demonstrates similar capabilities:
3D point cloud rendering: Display dense point clouds with color information
Interactive camera controls: Orbit, zoom, and pan around reconstructed scenes
Multiple model switching: Allow users to switch between different 3D reconstructions
Responsive design: Work well on both desktop and mobile browsers
This would serve as a great showcase for pyvista-js's capabilities in the scientific visualization and computer vision domain.
Reference
VGGT demo: https://vgg-t.github.io/
VGGT paper: https://arxiv.org/abs/2503.11651</issue_description>
