Description
This PR fixes transformation matrix corruption and bounding box distortion in the SIMD culler by implementing direct algebraic quaternion-to-matrix conversion in defaultModelMatrix.
Summary of Changes:
Direct Quaternion Matrix Construction: Replaced trigonometric functions (Math.sin, Math.cos) in defaultModelMatrix with direct column-major 4x4 matrix derivation from quaternions ([x, y, z, w]).
Euler Angle Conversion: Added eulerToQuaternion helper to convert 3-element Euler rotation arrays [rx, ry, rz] to unit quaternions.
Quaternion Normalization: Added normalizeQuaternion to ensure non-unit quaternions are normalized before matrix conversion.
Bounding Box & Radius Verification: Ensured transformed AABB extents via transformAABB produce accurate bounding sphere radii in upsertObject.
Unit Testing: Added unit tests in simd-culler.test.ts verifying identity quaternions, 90-degree X/Y/Z rotations, non-unit normalization, Euler conversion, and bounding sphere radii.
