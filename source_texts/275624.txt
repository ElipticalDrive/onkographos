What
Adds material-removal simulation to the CAM simulator — the heavier refinement deferred from #122. The path simulator animated a marker; this carves a voxel stock so the user watches material disappear as the program runs.
Default Material view when a job is present; a View dropdown toggles Material ⇄ Path playback. Play/Pause · Step · Reset · Speed and the move counter all work in both views; the material view also shows % stock remaining.
Voxel grid (voxel_grid.go): uniform occupancy grid as a packed bitset (a 96³ grid ≈ 110 KB).
Unified cutter profile (cutter.go): flat endmill / ball nose / drill·v-bit cone all collapse to one radiusAt(dz) function, so one stamp routine removes the material under any tool.
Densify-and-stamp sweep (voxel_sweep.go): each toolpath segment is split into sub-cell steps and stamped, so fast moves never skip cells; cuts are recovered from the job's host-free path generation, giving the exact cutter + path per operation.
Exposed-face meshing (voxel_mesh.go): the solid/empty boundary is emitted as quads with interior faces culled, pushed to the viewport via AddMesh.
Incremental driver (voxel_sim.go): carving advances with playback and rebuilds on scrub-back; resolution is half the smallest cutter radius, coarsened only past a 3M-cell cap — and the chosen cell size is reported so any coarsening is visible (no silent cap).
Why
A toolpath marker shows where the tool goes; material removal shows what the part becomes — the verification a machinist actually wants before posting. Voxels (vs. a Z-map heightfield) keep the door open to undercuts/through-features and match what "voxel simulation" means.
Scope: blocky exposed-face meshing is deliberately honest about voxel resolution and free of marching-cubes ambiguities — a faithful preview without claiming more precision than the grid holds.
Design (geometry-math discipline)
Framed as subtracting each cutter's swept solid from a stock AABB at voxel tolerance. Chose a 3D occupancy grid + densify-and-stamp + exposed-face surface. Pitfalls guarded: cell ≤ ½ smallest tool radius and densify ≤ cell (else fast moves stamp nothing); cell-count cap with coarsen-and-report; resolution tied to stock/tool scale (no magic constant); path Z treated as the cutter tip, ball centre offset up by R.
Tests (TDD)
Each pure layer RED→GREEN: grid (solid init, clear/count, centre, bounds); cutter profiles (flat/ball/cone + tool mapping); sweep (stamp footprint, height limit, gap-free channel, per-op cutter); mesh (single-voxel cube, interior-face cull, empty grid, world-space verts); resolution choice + cap. Controller: defaults to Material, carves the stock, View toggle round-trip, and the animation tick loop carves to completion.
Full bridge suite + -race green, golangci-lint clean.

Extend the toolpath simulator with FreeCAD-style material removal: instead of
only animating a marker along the path, carve a voxel stock so the user watches
material disappear as the program runs. Material is the default view when a job
is present; a View dropdown switches between Material and Path playback.

How it works:
- The stock box is voxelised into a uniform occupancy grid (a packed bitset).
  Cell size is half the smallest cutter radius so a tool spans a few cells,
  coarsened only if the grid would exceed a 3M-cell cap (the chosen size is
  reported so any coarsening is visible).
- Every supported cutter (flat endmill, ball nose, drill/v-bit cone) collapses
  to one "radius at height above the tip" profile, so a single stamp routine
  removes the material under any tool.
- Cuts are recovered by re-running the job's host-free path generation, which
  yields the exact cutter and toolpath per operation. Each segment is densified
  to sub-cell steps and stamped, so fast moves never skip cells.
- The solid/empty boundary is meshed by exposed-face extraction (interior faces
  culled) and pushed to the viewport; carving is incremental as playback
  advances and rebuilds on scrub-back.

Blocky exposed-face meshing is honest about voxel resolution and free of
marching-cubes ambiguities — a faithful machining preview without claiming
more precision than the grid holds.
