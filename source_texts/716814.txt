Summary
Addresses the six issues identified in the PR30 review. Topología ya cayó — this PR targets fidelidad física.
Changes
Resolution 128³ → 256³: cell size 0.022→0.011 units (~0.76mm/voxel). 4x detail fidelity for faces, edges, and fine features. Runs in ~19s — viable for CI.
Degenerate check fixed: now uses cross-product area threshold (< 1e-20), not just index equality (a === b). Catches collinear and near-zero-area triangles.
Outward normals: marching cubes winding order reversed → positive signed volume. STL normals point outward as slicer expects.
Engraving improved: stroke width now max(cellSize * 1.2, charHeight * 0.12) — proportional to glyph size, not voxel cell. Character height bumped 22%→28% of pedestal (~2.4mm at scale).
Extended GEOMETRY_GATE.json: widthMM, depthMM, volumeCM3, surfaceAreaCM2, normalsOutward, triangles, stlBytes, voxelRes
Fabrication gate enforced: printer envelope ≤200mm per axis, positive volume, outward normals — all checked in allPass
CI reproducibility: git diff --exit-code on GEOMETRY_GATE.json and PRINT_PREFLIGHT_REPORT.md after regeneration. Committed artifacts must match regenerated.
Docs corrected: wall thickness ≥1.0mm → ~0.93mm (statistical estimate) with caveat
