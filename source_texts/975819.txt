# pcg64-np

PCG64 (XSL-RR) random number generator compatible with NumPy's `default_rng()`.

## Overview

This crate provides a pure Rust implementation of:

- **SeedSequence**: NumPy's seed sequence algorithm for deterministic seeding
- **PCG64**: The PCG64 random number generator with XSL-RR output function

The implementation is a direct port from NumPy's C source code (`pcg64.h`, `pcg64.c`, `_pcg64.pyx`), ensuring bit-exact compatibility.

## Installation

```bash
cargo add pcg64-np
```

## Usage

```rust
use pcg64_np::numpy_pcg64_from_seed;

let mut rng = numpy_pcg64_from_seed(42);

// Generate random u64 values
let value: u64 = rng.next_u64();

// Generate random f64 values in [0, 1)
let float: f64 = rng.gen_f64();
```

## NumPy Compatibility

This crate produces **bit-exact** results matching NumPy's `default_rng(seed)`:

```python
import numpy as np

rng = np.random.default_rng(42)
print(rng.random())  # 0.7739560485559633
```

```rust
use pcg64_np::numpy_pcg64_from_seed;

let mut rng = numpy_pcg64_from_seed(42);
assert_eq!(rng.gen_f64(), 0.7739560485559633);
```

## Algorithm Details

- **PCG Variant**: PCG64 (XSL-RR output function)
- **State Size**: 128 bits
- **Output Size**: 64 bits
- **Period**: 2^128
- **Seeding**: NumPy's SeedSequence algorithm
