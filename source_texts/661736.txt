Description
Add opt-in lossless HDF5 and TIFF/OME-TIFF compression/decompression while keeping native formats. HDF5 uses official tools with gzip/shuffle; TIFF uses Deflate. These formats also occur in arivis/BigDataViewer microscopy workflows.
Inputs remain read-only. Outputs use private staging and verified data/metadata, hashes and reports. Includes explicit reference/region verification and BigTIFF padding/growth safeguards. Unsupported rewrites fail explicitly; already-compressed TIFFs are copied unchanged before rewrite-only checks. Container bytes may differ.
Fixes #115. Independent of copying feature #114. Requires bundled Python/HDF5 tools and four pinned packages; see czishrink/ScientificFormats/README.md.
Validation
310 C# tests and 33 codec tests (including synthetic TIFF overflow cases) passed on Windows, plus mixed-format round trips and MSI build/content checks. Seven local H5 recordings passed levels 1/9, decompression and direct MATLAB reads. Linux codec runtime/vendor-viewer checks remain pending. The license allowlist includes Zlib for NumPy’s bundled components; security checks remain enabled.
Checklist
Self-review, documentation, version update and regression tests completed.
Existing copyright and license notices retained.
Upstream checks/review pending; remains draft.
Amin Khosrozadeh, PhD — Prof. Vassiliki Nikoletopoulou lab, DNF, UNIL.
