Abstract
In volume visualization the de
nition of transfer functions is a critical task
for the generation of informative images. We have the fact nowadays that
the complexity of the images increases. So the problems of designing proper
transfer functions are growing too. In this work an image-based approach
is presented, which tries to simplify this task by providing multiple preview
images for di
erent function settings, so that the user can imagine more
easily how the
nal image will look like.
