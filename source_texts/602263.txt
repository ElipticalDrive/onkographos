Hello! I am not sure if this is a feature missing from the lighting engine or if I simply couldn't figure out how to do it, but it seems (as of now) impossible to project shadows onto and from moving objects and only seems to work on tilesets with the provided colliders. There is no way to move tiles around like objects, as far as I'm aware so this makes it really difficult to project shadows onto, say the player object.
Is there any way to achieve this?
Thanks in advance!

Hello,
I don't know what kind of shadows you want to project. If it's shadow projection like tiles use (raycasting), you can't do that. This type of projection is based on square shape, so if you want to proceed the same effect with a more complex shape, this will require a lot more of algorithm. You could do the same kind of logic with moving object that are square based, but this will require more cpu ressources. But like i said, for more complex shape (circle), it will require a totally different technique to cast shadows (i think).
However, there is a feature in the lighting engine to project simple object shadows. This shadows are very simple, it's just the base sprite (let's say your player), that been duplicated in black. Then, the position and the shape of the shadows is relative to the differents sources lights.
This method is simple, but can be really helpful and do pretty stuff (add some volume in your scene).
To achieve that, you just need to set the parent of your object to "o_shadow_caster_par". If your object have "o_shadow_caster_par" as a parent, it will cast his shadow on surface below it.
This kind of shadow projection is entirely based on this excellent tutorial : https://www.youtube.com/watch?v=haU-lUkitas
I suggest you to see the video, in order to see if the technique match your expectation and also to know a little how this works. The light engine can render this type of shadow in a flat mode (example, on a wall, for 2D POV), or in a curve mode (like in the video, on a floor, with view from above).
Hope this will help you.
EDIT : I just noticed out that i didn't implement this shadow casting system in the repo, so you will not find the parent object that i told (o_shadow_caster_par) ... sorry for that, i will do that as soon as i can, so every one can enjoy this feature with the engine. I will add documentation for this too.
