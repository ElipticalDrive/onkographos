SOLVED
I found someone on Discord who provided me with a .zip file where their voxel was loaded correctly.
Here’s what I did: For the Godot Steam version (Latest (4.2.2.)), I downloaded the plugin (MagicaVoxel importer with extensions++ 1.2 3D Tools 4.0 Community) from the Godot website. I extracted it using 7zip and manually moved it via Windows Explorer to where Godot would normally install it. Then, I meticulously checked that every file was present and activated the plugin through Project Settings -> Plugin.
Now, here’s the trick: my .vox file exported from MagicaVoxel didn’t work, BUT when I moved my figure directly from the MagicaVoxel directory without using the export step, my figure was loaded without any problems or errors.
Conclusion: It seems that the export function of MagicaVoxel has some kind of error. You need to move your creations directly from the “C:***\MagicaVoxel\MagicaVoxel-0.99.7.1-win64\vox” directory into Godot for it to be transferred into a MeshInstance3D.
