This is a major expansion of the voxel engine, adding complete terrain generation with biomes, a full lighting system with shadows, player physics and mining mechanics, and particle effects.
Summary
Transforms the engine from a basic voxel renderer into a playable Minecraft-like game with procedurally generated terrain, day/night cycles, player movement, block mining, and visual polish.
Key Changes
Terrain & World Generation
Implement climate-driven terrain with four biomes (plains, desert, snowy mountains, dense forest)
Add cave generation, trees (oak, birch, pine, cactus), and cross-plant foliage (tall grass, flowers)
Expand block types from 7 to 23 (wood, leaves, sandstone, snow, ice, glass, etc.)
Mirror GPU worldgen logic in CPU terrain.ts for parity testing and spawning
Add comprehensive terrain tests validating biome distribution, surface continuity, and decoration
Lighting & Shadows
Implement cascaded shadow maps (2 cascades, 2048×2048) for directional lighting
Add per-vertex ambient occlusion and biome-based tinting (grass/foliage colors)
Implement day/night cycle with sun/moon positioning and sky gradient
Add shadow pass pipeline and depth-only rendering for opaque geometry
Procedural Textures
Generate 16×16 pixel-art block textures procedurally on CPU
Create full mip chain for all textures (36 layers including 10 mining crack stages)
Implement biome tinting system (full and masked modes) for grass, leaves, and plants
Add texture layer mapping and WGSL code generation for shader integration
Player Physics & Interaction
Implement swept-AABB collision detection with gravity, jumping, sprinting
Add walking mode with ground friction, step climbing, and swimming
Implement mining system with crack stages (0–9) and block break times
Add debris particle system (GPU-simulated, CPU-spawned) for block breaking
Create hotbar UI with 9 selectable blocks and keyboard/wheel selection
Rendering Improvements
Add alpha-tested (cutout) geometry pipeline for glass and plants
Implement overlay pass for water, target box, mining cracks, and particles
Add instanced particle rendering with GPU simulation
Expand mesh format to support three geometry types (opaque, water, cutout)
Testing & Validation
Add comprehensive test suites for terrain, physics, particles, cascades, and sky
Implement GPU ↔ CPU parity checks for worldgen and meshing
Add smoke tests with screenshot capture for visual validation
Add CI workflow for automated testing
Documentation & Polish
Completely rewrite README with architecture overview, controls, and performance notes
Add detailed comments to terrain generation explaining the pipeline
Update shader prelude with new constants and texture functions
Improve UI with hotbar display and updated control hints
Notable Implementation Details
Terrain uses a spline-based heightmap with biome-weighted blending and 3D detail noise that fades with altitude, ensuring single-surface-per-column with no floating slivers
Shadow cascades use practical splitting (blend of logarithmic and uniform) with texel snapping to prevent shimmer
Particles use a ring buffer with GPU simulation; CPU only writes new spawns
Block textures are generated deterministically using hashed-gradient noise, enabling offline generation and full mip chains
Player physics resolves movement per-axis (Y, X, Z) with continuous swept collision to prevent tunneling
Mining cracks overlay the target block using a separate render pass with depth read-only access
