Summary
VOX format fidelity and scene model work (roadmap P0-4, P2-1, P2-2, P2-5..P2-10).
Corpus helper (tests/helpers/corpus.ts) reads the 15 MagicaVoxel samples via MAGICAVOXEL_HOME / MAGICAVOXEL_PATH and skips when absent; synthetic v200 fixtures are built in code for CI.
Corpus test: 15/15 samples decode strictly and round-trip byte-for-byte, with chunk counts asserted per file.
src/voxChunks.ts: typed DICT/STRING, rOBJ, rCAM, NOTE, IMAP, META and MATL codecs; unknown keys and chunks are preserved; exposed as scene.render.
load_vox {modelIndex} and new load_vox_models (all models + a scene); the multi-model error names both options.
src/rotation.ts: packed _r helpers for the 24 orientations (and the 24 mirrored encodings).
src/sceneBake.ts: new flatten_scene; extract_scene_model {bake, instance}.
Scenes are stored parsed with copy-on-write edits and Map indexes (docs/scene-performance.md).
Optional lenient parsing with warnings (strict stays the default; voxel cap and bitset duplicate detection unchanged).
replace_scene_model {remap}: palette-less models use the default palette; mismatches name the first differing index and both colors.
The set_scene_material registration line is untouched, so changing its range stays a one-line diff.
Tests
npm run typecheck && npm test: 123 tests (121 pass, 0 fail, 2 skipped) with the MagicaVoxel install available; 105 tests (100 pass, 0 fail, 5 skipped) without it, as in CI.
