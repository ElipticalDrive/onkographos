What
A triangle mesh with vertex colors from the cleaned dense cloud (docs/dense-mvs.md 3.13, step 12).
Field: for each lattice node, the weight-averaged signed plane distance of the oriented points within R (truncated, TSDF-like), weight (1 - d²/R²)². Sparse lattice of 8³ bricks, spacing 1.5 x median point spacing, R = 2.5 spacings. The cell grid of the points is the spatial hash of cloud-clean.ts.
Cubes: marching cubes, 256-case Lorensen-Cline table (Bourke numbering, from three.js MarchingCubes), vertices welded by edge key, counter-clockwise from the normal side.
CPU reference meshDenseCloud (src/reconstruction/dense-mesh.ts). GPU meshDenseCloudGpu (src/gpu/dense-mesh.ts, dense-mesh.shade.ts): meshNodeField, meshClassify, shared flag scan, meshEmit, meshVertices; the host welds keys.
Lab: ?denseMesh=1 meshes the final cloud (off by default, since it costs time on a phone); Display popover "Mesh" switch (off by default, disabled without a mesh); "Export mesh PLY" (binary, with faces); dense.mesh and options.denseMesh optional in the v5 record (no format bump).
Measurements (2026-10-20, shared 4-core container, no physical GPU, Node 22.22.0, kernels at 4b784ef)
Owner's lab PLY: 209,283 points, cleaned (minFraction 0.1) to 82,968. Spacing 0.0483, R 0.121.
