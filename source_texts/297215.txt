A ray passing through a box in CLOSEST mode can return the entry point, normal, and distance together with the exit face’s hitFaceIndex. The index is assigned for every intersection, including farther hits that the closest-hit check discards.
This moves the face-index assignment alongside the accepted hit data in each raycast mode. The regression checks a ray through a box; two additional tests cover ALL and ANY.
This revisits the bug reported in #184, which was closed without merging.
Verification: all 92 tests pass with yarn test --runInBand; yarn typecheck and yarn build pass too. Against unchanged master, the closest-hit regression fails with face index 1 instead of 0, while the other two cases pass. The fixtures run locally without a browser or graphics context.
Best Regards, Tarik
