Summary
Fix 4x4 algorithm: the existing multiply4By4MatrixAWith4By4MatrixB had mismatched coefficient formulas for c14 through c44 — they didn't match the upstream Rust src/gen.rs. Tests against naive matmul caught this; the formulas were re-transliterated faithfully from upstream.
Add three more algorithms from upstream src/gen.rs:
multiply2By2MatrixAWith2By3MatrixB (11 multiplications instead of 12)
multiply2By2MatrixAWith2By4MatrixB (14 instead of 16)
multiply3By3MatrixAWith3By3MatrixB (23 — matching Laderman/Smirnov)
Add property tests comparing each algorithm against naive O(n^3) row-major matmul over 64 random matrices per case.
Output convention note
The upstream algorithms emit the result as np.array([c11, c12, ...]).reshape(n, m).T. That's effectively column-major encoding of the m×n product. The test helper reorderResult unwinds that to row-major before comparing with naive matmul. The public function shape is preserved verbatim from upstream Rust.
Test plan
gradle test — all 6 tests pass (2x2, 2x3, 2x4, 3x3 by 3x3, 4x4, identity)
gradle build — clean build
