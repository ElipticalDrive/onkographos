New collision research milestone
Adds an independent continuous fixed-axis translating capsule-versus-original-Level-triangle geometry oracle. A swept capsule is the radius neighborhood of the parallelogram traced by its moving centerline segment (or a segment if stationary/parallel); minimum triangle-to-patch distance determines contact. Original source triangle IDs, overlap, reversed winding and degenerate nonleaf gaps are retained.
Candidate MOPP traversal is separate: use PR #44's source-observed whole-swept-AABB branch walker over an axis-specific AABB that mathematically encloses the capsule. The default still conservatively explores unknown diagonals. A negative-control fixture demonstrates the previously known spatially incorrect synthetic MOPP may still omit a real capsule hit. No native Havok collision/contact or new MOPP builder is implied.
Private 19-map source-byte audit
All original user-owned Seattle GMP maps read without modification and verified against #30/#36 source records. Shape: vertical centerline radius 0.2 and half-axis length 0.5 in original Level units. Across 608 independent expanded-bounds random sweeps and 608 separately triangle-aimed off-surface sweeps, independent capsule geometry found 1,993 original triangle-hit occurrences, and both MOPP candidate modes retained all hits over 2,432 candidate comparisons, zero observed omissions. The capsule hits were separately checked to be a subset of the enclosing moving-box geometry SAT hits. Source assets and original XYZ coordinates not committed. One-unit MOPP quantization comparison tolerance remains research-only.
Files
research/dx2/inspect_mopp_swept_capsule.py: independent f64 segment/triangle and triangle/triangle minimum-distance geometry, fixed-axis moving capsule and MOPP AABB-enclosure walker.
research/dx2/audit_mopp_swept_capsule.py: source-authenticated original GMP/Flesh/Level/MOPP read-only owner-map CLI, seeded two-strata samples, independent PR Research: continuous swept-AABB original-triangle SAT and shape-expanded MOPP candidates #44 SAT containment gate, new sanitized JSON outside source Maps.
native_editor/tests/test_dx2_mopp_swept_capsule.py: 25 asset-free capsule geometry and source MOPP failure tests.
native_editor/tests/test_dx2_mopp_swept_capsule_audit.py: 6 source-Level fixture tests, including intentionally incorrect synthetic collision trees, immutability and refusal behavior.
docs/research/DX2_MOPP_SWEPT_CAPSULE_DISTANCE.md: findings, reproduction and explicit limitations.
Validity limits
A fixed-axis translating capsule test is NOT a Havok runtime capsule sweep, character controller, time-of-impact solver, physical-material reader or native Level/MOPP writer. No evidence that actual DX2 uses this shape or geometry scale. Keep research-only and draft pending full GitHub CI and review; original retail maps never written.
Second 19-map geometric sensitivity test
A separate read-only original owner-map test used a tilted capsule axis (1,1,0.25) normalized, radius 0.15 and half-axis length 0.75 Level units, with 16 independent random + 16 triangle-aimed sweeps per map. Across 608 additional sweeps, the independent capsule oracle found 1,094 geometric original source triangle-hit occurrences; both MOPP modes retained all of them in 1,216 additional comparisons with zero observed omissions. The same random seed and source-hash mix were used, so paths overlap statistically with the vertical-shape experiment: it is a shape-orientation/size sensitivity test rather than an independent random population. Combined across two configurations: 1,824 sweeps, 3,087 geometric source-hit occurrences, 3,648 candidate comparisons, zero observed missing IDs. Both sanitized audit result files are in the provided PR45 research archive. Local independent sweep geometry tests passed; GitHub CI for PR45 is still queued and must not be called green until completed.
