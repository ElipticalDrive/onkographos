Reworked the entire terrain rendering pipeline to eliminate tessellation shaders, reducing draw call overhead and improving rendering performance.
Specifically:
Updated CPU chunk generation to generate 0.5-unit vertex spacing (resolution 65x65) and updated normal/metrics loops.
Implemented pre-generated LOD index buffer grids for 4 discrete LOD levels in a static EBO and direct empty/EBO-bound terrain VAO.
Created a new compute shader terrain_mesh_bake.comp that bakes vertex-level heights, normals, displacements, biomes, and custom erosion parameters directly to the global terrain_vbo_ SSBO.
Created a new prepare compute shader terrain_prepare.comp that performs CPU-to-GPU indirection frustum and occlusion culling and selects distance-based LOD levels, writing direct MDI DrawElementsIndirectCommand structures.
Rewrote terrain.vert to pull vertex data from the baked vertex buffer using gl_VertexID and set up standard outputs for terrain.frag.
Removed obsolete tessellation shaders terrain.tcs and terrain.tes.
