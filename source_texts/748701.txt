Abstract
The growing demand for immersive experiences in AR/VR and volumetric media has intensified interest in scalable dynamic scene reconstruction. While 3D Gaussian Splatting (3DGS) enables real-time rendering of static scenes, existing dynamic extensions remain constrained by high memory consumption, limited temporal scalability, and impractical storage requirements—especially for long sequences on consumer-grade hardware.We present a differential 4D Gaussian Splatting pipeline that enables full-scene dynamic reconstruction with per-frame delta encoding and online updates. By decoupling temporal dependencies through batch-wise optimization and storing only inter-frame differences, our method achieves real-time rendering (>30 FPS and up to 60 FPS) on consumer-grade GPUs with maintaining a compact representation (<1MB per frame storage, <7.6GB peak memory usage), all while preserving high visual fidelity and seamless handling of emerging objects. Beyond the initial conference version, this journal work provides enhanced differential frame analysis, checkpoint-based ablation studies, and comprehensive baseline comparisons, offering a reproducible and scalable framework for temporally stable, arbitrarily long volumetric sequences.
