Implemented a 2-cascade volumetric lighting system using logarithmic froxel sampling. The system integrates directly with the weather simulation by using localized aerosol concentration and humidity data from the LBM grid to drive atmospheric density and scattering. God-rays are supported via shadowed light injection in the froxel grid, and ambient contribution is derived from spatial SH probes. The result is blended with the existing aerial perspective fog in the post-processing pipeline. All GPU resources are triple-buffered to avoid race conditions.
