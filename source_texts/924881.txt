⚡ Is there an underlying problem to be solved?
```
We need a possibility to cleanly render rounded boxes with anti-aliasing to support more complex ui elements composed of primitives.

The current implementation supporting border radius for box rendering relies on geometry generation, which may introduce a significant performance impact, once the required geometry exceeds a certain level. Furthermore it requires super-sampling or a shader-level integration of anti-aliasing, as we end up with jagged edges otherwise.
```
📝 What should the system provide?
```
* introduce compact representation of required data for shader integration
* introduce efficient representation of required data in ui command capture
* support rounded box primitives as part of shape compositing
```
