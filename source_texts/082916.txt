It would be nice to combine voxel textures at runtime to reduce bind material calls during rendering. This would help the most in cities because they are CPU bound even with Vulkan.
Arena organizes its voxel textures in .SET files which are 3-4 textures for each building, but the modern way should be one big texture sub-allocated within.
Probably add a RenderTextureAtlas which manages the contents of an ObjectTextureID. It maintains a 2D heap and maybe pairs a TextureAsset with a 2D span. RenderVoxelChunkManager's batching probably needs revision, it needs a RenderTextureAtlasEntryID comparison with adjacent faces instead of an ObjectTextureID comparison. Fragment shaders probably need UV coordinates revised too so they're not all 0 to 1.

We can start with generating a texture atlas. Something like:
```
struct RenderTextureAtlasManager
{
    static constexpr int WIDTH = 2048; // Or 1024 or 4096...
    static constexpr int HEIGHT = WIDTH;

    ObjectTextureID atlasTextureID;
    // @todo 2D heap that remembers free rectangles

    bool init(Renderer &renderer)
    {
        this->atlasTextureID = renderer.createObjectTexture(WIDTH, HEIGHT, 1);
        if (this->atlasTextureID < 0)
        {
            return false;
        }

        return true;
    }

    Rect add(const TextureBuilder &textureBuilder)
    {
        Rect rect;
        // @todo find a free rectangle in 2D heap
        // @todo write textureBuilder texels to that rect with renderer.lockObjectTexture() / unlockObjectTexture()
        return rect;
    }
};
```
TextureManager loads the texture file into RAM and then we write those bytes to VRAM with renderer.populateObjectTexture().
LoadVoxelDefTextures() in RenderVoxelChunkManager.cpp could be where we add textures into a texture atlas, like this:
```
void LoadVoxelDefTextures(..., RenderTextureAtlasManager &textureAtlasManager)
{
    ...

    ScopedObjectTextureRef voxelTextureRef(textureID, renderer);
    RenderVoxelLoadedTexture newTexture;
    newTexture.init(textureAsset, std::move(voxelTextureRef));
    textures.emplace_back(std::move(newTexture));

    Rect textureRect = textureAtlasManager.add(textureBuilder);
    if (textureRect.isEmpty())
    {
        DebugLogErrorFormat("Couldn't find a free %dx%d rect in atlas.", textureBuilder.width, textureBuilder.height);
    }
```
We might be able to assume voxel texture dimensions are 64. That would make the 2D heap easier.
There is no mipmapping in this engine.
