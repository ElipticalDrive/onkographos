Motivation
Provide a self-contained Godot 4 project that demonstrates a playable voxel sandbox with core systems implemented so the project can be opened and iterated on quickly.
Establish a clean architecture and folder layout for voxel blocks, chunked world streaming, procedural generation, player interaction, UI, systems and simple mobs.
Deliver a runnable scene graph and basic persistence so further features (AI, crafting depth, lighting optimizations) can be built on a working base.
Description
Add project configuration and top-level scenes (project.godot, scenes/main.tscn, scenes/player.tscn, scenes/hud.tscn, scenes/mob.tscn) wired to scripts/main.gd as the entrypoint.
Implement voxel systems: scripts/world/block_registry.gd for block metadata, scripts/world/world_generator.gd for Perlin-like terrain, biomes, caves, ores and tree placement, and scripts/world/world.gd for world/chunk management and block override storage.
Implement chunk mesh generation and collision in scripts/world/chunk.gd using face-culling meshing (CHUNK_SIZE 16 × CHUNK_HEIGHT 64), with dynamic chunk loading/unloading and neighbor refresh on block changes.
Implement player and gameplay systems: scripts/player/player_controller.gd for FPS movement, camera, raycast-based break/place, scripts/systems/inventory.gd and scripts/systems/crafting.gd for inventory/hotbar and basic recipes, scripts/ui/hud.gd for HUD, scripts/mobs/mob.gd for simple wandering/chase mobs, and scripts/systems/save_system.gd for serializing block overrides to user://world_save.json.
Testing
Attempted to run the project headlessly with godot --headless --path voxel_game --quit, which failed because the godot binary is not present in the environment (test aborted).
Performed repository and file validations including file creation and pattern checks (file listings and rg scans) which confirmed all scenes and scripts were created and referenced correctly.
Project-level smoke validation (scene wiring and script references) was inspected by opening and listing the main files and scripts, and no runtime errors were produced during these static inspections.
