Got clarification on this during the coffee and code on Aug 15, 2026. This was because TryCreateFromSaturating and similar were thought to be not exposed, but if I'm understanding the problem right, these can actually be called by using a generic method.
For example, I used this code to call TryConvertFromChecked:
```
private static bool TryConvertFromCheckedFromDouble<TTo, TFrom>(double value, [MaybeNullWhen(false)] out TTo result)
    where TTo : INumberBase<TTo>
    where TFrom : INumberBase<double>
{
    if (typeof(TTo) == typeof(double))
    {
        result = (TTo)(object)value;
        return true;
    }

    return TFrom.TryConvertToChecked(value, out result);
}
```
