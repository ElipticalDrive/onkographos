Summary
Implements BH #2A, the pointer-free Morton/Z-order substrate that sits between the merged BH #1 recursive correctness reference and a future GPU traversal implementation.
This PR deliberately does not claim GPU acceleration. It freezes the data structure and evidence contract first.
What changes
Morton/Z-order resident ordering
16 bits per planar axis
one 32-bit Morton key per resident body
stable key sorting, preserving original resident order for equal keys
fixed 16-level Morton topology cap
Flat tree
Adds a separate flat representation alongside the frozen recursive BH #1 tree:
contiguous Morton entry array;
pointer-free flat cell array;
explicit u32 child indices;
contiguous body ranges per cell;
bottom-up total-mass / centre-of-mass aggregation;
iterative stack traversal;
same s / d < theta opening rule;
same target-containing-cell rejection;
final-quantized leaves may exceed the configured bucket, with maximum occupancy exposed as receipt evidence.
The recursive BH #1 tree remains the scientific oracle.
New verification surface
```
cargo run --manifest-path nbody/Cargo.toml --locked --offline -- verify-flat
```
The gate checks:
stable equal-key ordering;
frozen host record sizes;
exact root range / total mass preservation;
theta-zero parity with direct O(N²) forces;
theta-0.5 accuracy inside the BH Transform VORTEX into a spinning galaxy with Rust/Wasm acceleration #1 error gates;
close flat-vs-recursive agreement on the deterministic fixture;
repeatable discrete topology checksum.
New flat receipt
```
cargo run --manifest-path nbody/Cargo.toml --release --locked --offline -- \
  flat-probe --preset collision --particles 16384 --theta 0.5 --seed 303 \
  --receipt runs/barnes-hut-flat/receipt.json
```
galaxy.barnes-hut-flat-receipt.v1 records:
Morton width;
entry/cell record sizes;
flat layout bytes;
cell / leaf / depth counts;
maximum leaf occupancy;
topology checksum;
tree construction time separately from traversal time;
direct-probe time and acceleration error;
force-term accounting;
explicit CPU-only / no-GPU-speed-claim scope.
CI runs verify-flat plus a parsed 512-body flat receipt smoke test.
Precision boundary
The flat CPU reference intentionally retains f64 aggregates. This PR does not combine topology migration with an f32 precision migration.
The next phase, BH #2B, can therefore introduce explicit shader transfer packing and measure it independently:
```
frozen Morton entries + flat cells
  -> explicit f32 packed transfer records
  -> WGSL/CUDA buffer parity
  -> GPU traversal
  -> GPU leapfrog
```
That phase must continue to compare against both BH #1 recursive forces and the direct O(N²) oracle.
Roadmap
Updates ROADMAP.md and docs/BARNES-HUT.md so BH #1 is recorded as frozen by merged PR #18, BH #2A is this phase, and BH #2B is the next GPU execution rung.
