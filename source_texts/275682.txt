Scope (post-2026-05-06 upgrade)
Froxel-based volumetric fog (Bart Wronski, Frostbite SIGGRAPH 2014; matured by Lumen and id Tech 7). Replaces the original per-pixel raymarch scope — that approach is O(pixels × steps) and doesn't scale at planet density.
3D froxel grid in view-space (typical 160×90×64). Each froxel stores (scattering_rgb, extinction).
Pipeline (4 compute passes + apply)
Density injection (compute): participating-media density per froxel from height fog + local volumetric primitives (VolumetricBox, VolumetricSphere components, future).
In-scattering (compute): sun + light contributions per froxel, evaluating Henyey-Greenstein phase function (anisotropy parameter, forward-scattering for god rays).
Accumulation (compute): ray-march through froxel slices along view-Z, producing a 3D LUT of accumulated in-scattering + transmittance.
Apply (deferred shader): sample the LUT by view-space depth, lerp into the lit color.
Why Froxel vs per-pixel raymarch
Per-pixel raymarch: O(pixels × steps). Froxel: O(froxels × 1) regardless of resolution.
Light contribution amortized — every pixel inside a froxel reads the same in-scattering.
Composes natively with feat(render): AtmosphereVolume component per-planet (sky PR B) #248 AtmosphereVolume — atmospheric scattering injects density at planet-relative heights into the same froxel grid.
Henyey-Greenstein phase function
```
fn phase_hg(cos_theta: f32, g: f32) -> f32 {
    let g2 = g * g;
    let denom = 1.0 + g2 - 2.0 * g * cos_theta;
    return (1.0 - g2) / (4.0 * 3.14159 * pow(denom, 1.5));
}
```
g = anisotropy: −1 = backward, 0 = isotropic, +1 = forward.
Forward (~0.7–0.8) gives the god-ray look.
Tasks
Allocate 3D froxel storage texture (rgba16float, view-space).
Pass 1: density injection compute shader (height fog + per-volume primitives).
Pass 2: in-scattering compute shader (sun + lights × phase function per froxel).
Pass 3: accumulation compute shader (ray-march along view-Z).
Pass 4: apply in deferred shader (sample LUT by view-space depth).
ECS components: VolumetricFog (density / scattering / absorption / anisotropy / max_distance).
Optional: half-resolution froxel grid + temporal reprojection.
Acceptance criteria
Visible god rays from directional light through dense fog volume.
Height fog integrates with froxel density injection.
Configurable density / scattering / absorption / anisotropy from ECS / inspector.
Composes with feat(render): AtmosphereVolume component per-planet (sky PR B) #248 (atmosphere drives heightwise density at planet scale).
Performance target: < 1.5 ms at 1080p RX 9070 XT for the full 4-pass pipeline.
