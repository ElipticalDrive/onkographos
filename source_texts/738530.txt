Summary
use physical per-eye origins for volumetric phase calculations
isolate volumetric blur, composite, and temporal history by eye
keep each SSR resource sample inside its resolved eye using its own bounds
preserve the existing cross-eye SSR ray marcher
apply the corrections automatically in VR without runtime shader branches
Benefits
stops volumetric fog and light shafts from bleeding across the stereo
eye seam
uses each physical eye for phase direction, improving stereo depth and
spatial consistency
prevents blur, composite, and temporal history from contaminating the
other eye
reduces wrong-eye SSR sampling and seam artifacts without removing
cross-eye reprojection
Implementation comparison
SSR/wrong-eye sampling:
```
- return FrameBuffer::GetDynamicResolutionAdjustedScreenPosition(
-     Stereo::ConvertToStereoUV(raySample, eyeIndex));

+ return Stereo::ClampToEyeUV(
+     normalizedUV, eyeIndex, activeDimensions) * resolutionScale;
```
Before, the UV could land on or cross the boundary between the two eyes.
After, it is restricted to the resolved eye's texel centers.
Volumetric shaft direction:
```
- float3 viewDirection = normalize(-positionWS.xyz);

+ float3 viewDirection = normalize(
+     FrameBuffer::ViewToWorld(float3(0, 0, 0), true, eyeIndex)
+     - positionWS.xyz);
```
Before, both eyes calculated scattering toward the shared origin
(0,0,0). After, each eye calculates it toward its actual physical eye
position.
Review follow-up
reuse FrameBuffer::ViewToWorld and Stereo::ClampToEyeUV
centralize texture-aware dynamic-resolution clamping
remove experimental toggles and their shared-data branch flags
cache SSR depth dimensions outside the raymarch loop
add focused coverage for dynamic-resolution eye-seam clamping
regenerate en.json after removing the obsolete UI strings
Testing
built the Release CommunityShaders target successfully
passed 1,649 assertions across 153 C++ test cases
ran the pinned clang-format and all pre-commit hooks successfully
regenerated en.json and verified it with extract-i18n.py --check
previously verified the volumetric fog and shaft correction in Skyrim VR
previously verified SSR remains visually equivalent to the current
cross-eye path
Shader compilation and HLSL unit tests are covered by the PR checks.
Limitations
SSR still cannot reconstruct reflection data that is absent from the
screen. This change prevents wrong-eye filtering and sampling artifacts;
it does not provide off-screen reflection information.
