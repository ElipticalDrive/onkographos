## Project Summary
Hexahedral meshing has been proven to be significantly faster in the solving of most partial differential equations and other complicated problems for physical simulations, for two reasons: the number of cells is lower by about 10-25%, as compared to tetrahedral meshing, and hexahedral cells approximate the frame fields more accurately. But hex-meshing is a hard problem and is often done by parametrizing tetrahedral meshes and extracting hexahedral meshes using certain heuristic rules. The algorithm to be implemented is delineated in the paper by Lyon et al - 'HexEx: Robust Hexahedral Mesh Extraction'. My work was to incorporate the algorithm to create hexahedral meshes using combinatorial maps package in CGAL.

The algorithm assumes a parametrization for tetrahedral meshes as input. A dummy parametrization was used to test the algorithm, this is yet to be tested with parametrizations more faithful to the original topology of the input object, such as [CubeCover](http://www.mi.fu-berlin.de/en/math/groups/ag-geom/publications/db/2011_Nieser-Reitebuch-Polthier_CubeCover.pdf).  The discrepancies with dummy parametrization was unforeseen and implementing a good method for parametrization of tetrahedral meshes is yet to be done.

[Documentation and future work](https://docs.google.com/document/d/1Csd8-aKrFbMXecQ_2Hcf2FkdewuE8IpfpP7P5CdC_xI/edit?usp=sharing)

The work was done in the branch: https://github.com/CGAL/cgal-public-dev/tree/gsoc-2017-HexEx-vasudha.
