What
Opens Phase 2 (arbitrary-geometry intake): geometry coming out of CAD software (STL) can now enter the B4 surrogate stack as a boolean mask on the canonical grid — the entry point the roadmap flagged as the remaining gap after the shape-family generator (#236) and SDF encoder (#235).
src/tensorlbm/voxelize.py (+742, numpy + stdlib only, no torch)
STL loader — binary + ASCII with auto-detect; tolerant of CRLF / endsolid names / empty solids; byte-offset ValueError on truncation.
is_watertight — directed-edge manifold + orientation check (hash-based); reported, not required — open meshes voxelize with documented caveats.
mask_from_stl — vectorized Moller-Trumbore ray-parity voxelizer; robust=True (default) applies a deterministic transverse ray perturbation that resolves the shared-edge/vertex degeneracy; cell-centre sampling matching the existing geometry_voxel convention; output (nz, ny, nx) bool with streamwise x = axis 2 (B4 tensor layout).
place_on_grid — canonical-frame placement: uniform scale to a streamwise extent fraction, transverse centring, hull nose at cx = nx*0.35 per SUBOFF convention. Contract pinned exactly by tests.
sdf_from_mask — small signed-distance seam for the encoder input. Exact brute force is the default up to 32^3; beyond that a 3-4-5 chamfer with a documented worst-case bound (~11%, shallow diagonals). Docstring steers callers to the geom_encoder boundary-restricted EDT once B4-SDF: learned geometry representation (exact-EDF encoder) vs v3 hand channels #235 merges — the exact EDT is deliberately NOT duplicated here.
Division of labor vs geometry_voxel.py (already on main)
geometry_voxel is the solver-side path: torch/Triton, CUDA kernels, BFL q-field for LBM boundaries. This module is the CPU/numpy counterpart for the surrogate stack — importable without torch (serving guardrail path, CI, laptops), plus canonical placement and the SDF seam, which the solver path does not provide. The doc records this split and the post-#235/#236 integration plan (mask -> geom_encoder EDT -> SDFCondFNODrag; STL round-trip gate off suboff_cad families).
Cross-validation against main (reviewer-run, pre-push)
On 4 shared fixtures (axis box, icosphere subdiv 2, 31/17-deg rotated box, radius-5 icosphere subdiv 3 with 33 208 solid cells) voxelize.mask_from_stl agrees bitwise (100 %, 0 diff cells) with main's geometry_voxel.voxelize_stl_reference at identical origin/spacing — two independent implementations of the parity test, same answers.
Benchmark (reproduced by reviewer, cell counts exact, timings within noise)
icosphere 5 120 tris -> 32x32x64: 0.183 s (27 288 cells); 64x64x128: 0.660 s (218 187 cells)
prolate SUBOFF-like L/D 6 -> 32x32x64: 0.243 s; 64x64x128: 0.929 s
Tests
20 new (tests/test_voxelize.py), including: exact integer-placement box mask; icosphere volume convergence; rotated-box volume; binary-vs-ASCII loader equivalence; truncation errors; watertight true/false; degenerate shared-edge robustness with an exact analytic contract (naive parity demonstrably corrupts >= 8 columns on the same mesh; robust perturbation resolves every one, with the exact epsilon semantics documented in the test).
Verification (by reviewer, pre-push)
Tests both venvs: GPU 20 passed / ci-cpu 20 passed (OMP_NUM_THREADS=1).
Neighbor suite (geometry_voxel / suboff_cad / ship_cad / offshore_cad / propeller_cad): 116 passed — no interference.

New tensorlbm.voxelize (numpy + stdlib only):
- load_stl: binary and ASCII STL reader with auto-detection, CRLF and

- mask_from_stl: vectorised Moller-Trumbore ray-parity voxelizer on
  the B4 canonical (nz, ny, nx) grid with deterministic sub-cell ray
  perturbation and strict barycentric bounds so grid-aligned shared
  edges and vertices cannot double-count crossings

  length 0.6nx, nose upstream at 0.05nx) returning voxel-index tris
- sdf_from_mask: signed distance seam (exact brute force on small
  grids, two-pass 3-4-5 chamfer otherwise); geom_encoder stays the
  post-235 encoder-input path

Tests: tests/test_voxelize.py (20 tests, fixtures generated in-test).
Benchmark: benchmarks/b4_voxelize_bench.py (sub-second at 64x64x128
for 5120-triangle meshes). Docs: docs/voxelize_stl_20260824.md.
