Part of IstiN/fa_craft#1 (the fa_craft voxel widget's world currently renders sky-fill; this adds the missing rendering API). Upstream voxel/mesh node route as approved on that issue: pure Dart, vertex buffers per chunk, rebuilt only on edit.
API
Dart node — new voxel renderer type, backed by a bridge-owned JsVoxelWorld:
```
{ "type": "voxel", "id": "fa-craft", "width": 480, "height": 240 }
```
The world is a core capability: JsWidgetBridge._handleHostCall intercepts the voxel.* namespace before the host handler and serves it from the bridge world that also feeds the renderer. No host object, no new channel — it reuses __jsr_host_call, so the bootstrap and both engines are untouched. Hosts (or older runtimes) without the interceptor reject voxel.*, so widgets can probe and degrade.
JS surface (ES5) — jsr.hostCall:

voxel.mesh
{id, key, origin, positions, colors, indices}
ONE chunk's vertex buffers as plain flat arrays (xyz per vertex, rgb per vertex, quad/tri indices, CCW-from-outside winding). Returns {ok, faces}. Re-push only dirty chunks on edit — untouched chunks keep their buffers
voxel.camera
{id, position, yaw, pitch, fov?, light?, skyColor?}
Minecraft yaw/pitch convention; pushes repaint
Rendering pipeline (js_voxel_node.dart, ~610 lines): per-chunk AABB frustum culling → per-face near-plane clipping (Sutherland–Hodgman) → painter's-order depth sort → CustomPainter paths. Pure Dart, deterministic, no natives.

The async bridge does not bottleneck at fa_craft's chunk scale: an edit re-uploads one chunk (plain-array JSON) and repaints immediately. Recommendation: default view distance of 2 chunks radius (5×5 visible chunks ≈ 51k faces worst case ≈ ~2–5 ms/frame), degrading to radius 1 on low-end devices. Disclosed: numbers are debug-mode JIT; release AOT is faster; web Worker number measured via flutter test --platform chrome with a headless shell.
Tests / evidence

Gallery goldens: all 39 green (existing widget goldens re-run against this branch; no golden changed). Full suite: 615 passing. flutter analyze: 13 findings = pre-existing baseline, none new.
Production screenshot of the example widget through the jsr_widget CLI: chunked terrain renders (sky + shaded green terrain, buttons live).
I4 compliance
Pure Dart — zero new packages, zero native deps, app-size neutral (pubspec deps unchanged; the node is one new source file plus wiring). Example widget is hand-rolled ES5.
Docs updated: AGENTS.md (Voxel Support), both .agents/skills (authoring: node + JS surface; engine: core-capability hostCall pattern), CHANGELOG.md (Unreleased).
