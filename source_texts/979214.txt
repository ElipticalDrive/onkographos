Summary
This PR introduces a table-based codex to accelerate Hilbert index encoding/decoding
PR Adds a Hilbert order index to Spin #2011 introduced a Hilbert codec using Skilling's algorithm which converts from a Morton index to Gray code one bit at a time
PR Adds Hilbert ordering to BVH tree and space-filling curve example #2021 added the Hilbert index to the BVH tree and added an example application
This PR uses precomputed tables to convert groups of index bits between Morton and Hilbert indices and adds a benchmark
In 2D, we convert 3 levels at a time (6 bits), in 3D, we convert 2 levels at a time (6 bits), in 4D, we convert one level at a time (4 bits)
I've included the Python script that generates the lookup tables so we could increase the number of levels (at the cost of larger lookup tables). The experiments that I ran don't appear to justify the extra expense.
