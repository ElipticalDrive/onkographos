Summary
Phase 8 sample_ref did order-1 interpolation inside a single 128^3 chunk. For any sample with local coordinate greater than 127, scipy map_coordinates(..., mode='constant', cval=0) returns 0 instead of reading the adjacent chunk. That breaks the preregistered trilinear sample on chunk faces.
Fix: plan chunks for both floor and ceil of each inside point, assemble a sub-volume from the cache, then interpolate once.
Verification
```
$ python3 -m pytest tests/test_phase8_sample_ref.py -q
..                                                                       [100%]
2 passed in 0.41s

$ python3 -c "..."  # fixture: adjacent chunks valued 100 and 200, sample at x=*.127.5
sample_ref at chunk face 127.5: 150.0 (expect 150.0)

$ python3 -m pytest tests -q
27 passed
```
Independent expected value in the new test is map_coordinates on an explicitly assembled 128x128x256 block (150.0), not geometric proximity to ink.
