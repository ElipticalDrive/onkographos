Summary
New /fractal3d page — "Fractal Lab 3D" — a real-time, GPU ray-marched explorer for three classic 3D fractals, sibling to the 2D /fractal. Same dark/gold styling, lazy-loaded, with Fullscreen/Hide-UI, palettes, presets, auto-rotate/animate and 4K/8K PNG export.
These fractals are infinitely-detailed implicit surfaces (no mesh), so each pixel is sphere-traced in a WebGL fragment shader using a distance estimator per fractal, then shaded with normals, soft shadows, AO, fresnel glow and fog.
What's in it
Three fractals (u_type switch in the shader):
deBulb — Mandelbulb (White & Nylander power-n, default power 8)
deBox — Mandelbox (box-fold + sphere-fold with scalar running derivative)
deJulia — Quaternion Julia (q -> q² + c, Hubbard–Douady DE)
Orbit camera — drag to rotate, scroll/pinch to zoom; per-fractal default framing.
Controls — per-fractal presets, defining-parameter slider (power / scale / constant w), iterations, quality, 5 palettes (reused from 2D), colour shift, auto-rotate, animate, reset.
Fullscreen (button + F) and Hide UI (button + H), matching /fractal and /sky.
High-res export — Screen / 4K / 8K, re-rendered off-screen (no upscaling).
Performance — dynamic internal resolution (drops while the camera moves, refines at rest) + a quality slider driving max step count and surface-detail threshold.
Homepage tile + /fractal3d added to the 404.html SPA route allowlist.
Note on per-fractal framing
The Mandelbox bulk is much larger than the ~unit Mandelbulb/Julia, so a single fixed camera distance puts the camera inside it (renders as noise). Fixed with per-type defaults:
```
DEFAULT_DIST = { mandelbulb: 2.8, mandelbox: 7, julia: 2.6 }
FAR          = { mandelbulb: 8,  mandelbox: 16, julia: 8 }  // ray far-plane uniform u_far
```
Switching fractal reframes the camera; the wheel/pinch zoom clamp was widened to 14 to accommodate the Mandelbox.
Scope
v1 ships the three fractals above; Menger Sponge / Sierpinski are fast-follows. pnpm run check + pnpm run build pass; all three verified rendering in-browser.
