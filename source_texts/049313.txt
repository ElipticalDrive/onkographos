From roadmap.md — P2 (performance and scalability)
Description
Explore isosurfaces, Q-criterion, and volume raymarching as separate visualization modes.
These advanced visualization techniques would enable richer flow analysis:
Isosurfaces: Render surfaces of constant field value (e.g., pressure = P₀, velocity magnitude = U₀)
Q-criterion: Identify and visualize vortex structures using the Q-criterion (Q = ½(|Ω|² − |S|²) > 0)
Volume raymarching: Direct volume rendering through the 3D field for continuous density/opacity visualization
Acceptance Criteria
Isosurface extraction and rendering for scalar fields (pressure, velocity magnitude)
Q-criterion computation and isosurface visualization for vortex identification
Volume raymarching shader for direct volume rendering
Each mode is selectable independently in the UI
Performance is acceptable for interactive use at typical grid resolutions
