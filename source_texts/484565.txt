# 3D Volumetric Rendering with NeRF

This project is a TensorFlow + Keras adaptation of the official [Keras NeRF example](https://keras.io/examples/vision/nerf/). It implements minimal NeRF volumetric rendering, depth rendering, novel-view synthesis, and a 360-degree camera video.

## Runtime and Dataset

- **Runtime:** Google Colab GPU or any TensorFlow-supported environment
- **Framework:** TensorFlow and Keras 3
- **Dataset:** a local Keras Tiny NeRF `.npz` file with `images`, `poses`, and `focal`
- **Repository fallback:** the already-downloaded `nerf_synthetic/lego` Blender scene is adapted locally when the NPZ path is absent
- **No dataset download is performed by the project**

Set `dataset.npz_path` in `configs/tiny_nerf.yaml` to the local NPZ path. The loader uses `np.load` and reads `images`, `poses`, and `focal`.

## Implementation

The implementation follows the Keras example: Keras camera ray generation, near/far bounds of `2.0` and `6.0`, randomized 32-sample ray sampling during training, 16-level positional encoding with raw coordinates, and a minimal 64-unit Dense MLP with four outputs. The outputs are three RGB values and one density value. Rendering uses alpha compositing, transmittance, RGB accumulation, and expected depth.

Training uses a custom `keras.Model` with Adam, MSE, loss tracking, and PSNR tracking. This is intentionally a single minimal network. Coarse/fine networks, hierarchical importance sampling, 64+128 samples, and 200K-iteration full NeRF training are future work rather than implemented features.

## Defaults

| Setting | Default |
|---|---:|
| Epochs | 20 |
| Batch size | 5 images |
| Samples per ray | 32 |
| Positional encoding levels | 16 |
| Near / far | 2.0 / 6.0 |
| Evaluation | MSE and PSNR |

All values are configurable in `configs/tiny_nerf.yaml`.

## Install and Run

TensorFlow does not currently publish a Windows wheel for Python 3.14. On Windows, use Python 3.12 or run the project in Google Colab. The existing `.venv` is Python 3.14 and must not be used for TensorFlow.

```powershell
py -3.12 -m venv .venv312
.\.venv312\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Google Colab GPU:

```bash
pip install -r requirements.txt
```

Then run:

```bash
python scripts/train_tiny.py --config configs/tiny_nerf.yaml
python scripts/render.py --config configs/tiny_nerf.yaml --checkpoint outputs/checkpoints/nerf.weights.h5
```

The existing `train_full.py` command remains a compatibility alias, but it also runs the minimal Keras model. It does not train a coarse/fine architecture.

## Mathematics

The ray equation is $r(t) = o + td$. For a sample with density $\sigma_i$ and interval $\Delta_i$:

$$
\alpha_i = 1 - \exp(-\sigma_i \Delta_i),\qquad
T_i = \prod_{j<i}(1 - \alpha_j),\qquad
w_i = T_i\alpha_i.
$$

The rendered values are:

$$
RGB = \sum_i w_i c_i,\qquad Depth = \sum_i w_i t_i.
$$

The optimized loss is mean squared error, and PSNR is reported as the image-quality metric.

## Limitations and Future Work

The minimal example is designed for clarity and Colab execution. It does not claim SSIM, LPIPS, error heatmaps, coarse/fine hierarchical sampling, or a full NeRF architecture as implemented. Those may be added as optional extensions.
