Completes Advanced Voxel Architectures Rec 1: the GPU DAG raymarcher becomes
the default render path, and first-person voxel editing lands.

## Raymarch-by-default
- Flip `RenderConfig::default().shading` LegacyVertexColor -> RaymarchDagShading.
- Mesh path stays fully reachable via `--shading mesh` / `RenderPreset::Legacy`.
- Bare-run smoke: ray_spawns=358, mesh_spawns=0 (raymarch is the default).

## First-person voxel editing
- `atomr-worlds-voxel::world_dda::world_ray_first_solid` — a pure f64
  Amanatides-Woo picker over the unbounded 1 m/voxel grid (WorldRayHit:
  cell/normal/place_cell/material/t_entry). Explicitly NOT WGSL-mirrored, so it
  stays out of the raymarch determinism gate.
- `crate::modes::edit` — EditState (material/tool/radius/reach/last_hit),
  tool+material selection (digits / Tab / [ ]), and `fp_edit_voxels`: aim with
  the camera, left-click carves, right-click places; single-voxel + sphere/cube
  brushes. Gated on the cursor already being grabbed so the focus click doesn't
  also carve.
- Host stays the sole mutator: single voxels send WriteVoxel (integer pos),
  brushes send WriteRegion with voxel_center_metric = (cell+0.5)*mpv (mirrors
  the host apply_region). The client only predicts touched bricks via
  InteractionUnit::affected_voxels (the same call the host uses) and re-fetches
  authoritative bytes — nothing render/DAG-derived flows into GetBrick.
- Flicker-free live refresh: `fetch_and_build` extracted from BrickGenWorkers so
  streamed and edited bricks build identically; `spawn_edited_brick` does a
  make-before-break swap reusing spawn_brick_entity verbatim (works for every
  ShadingMode + both render paths). Refresh is size-gated: <=16 bricks sync in
  place, larger brushes drop entries and re-stream async.
- Resident Arc<Brick> on LOD-0 LoadedChunk feeds the picker with zero host
  round-trips.
- HUD: centered crosshair + tool/material/radius readout + a 3D selection
  highlight cube, all skipped under the harness.

## Release A/B (harness/scenes/perf_raymarch_ab.toml, sprint fly-through)
Recorded as data, not a gate (decision: commit to raymarch-default regardless;
mesh stays one flag away). raymarch / mesh:
- p50  1997 -> 2566 us  (1.29x)
- p99  18191 -> 37234 us (2.05x)
- mean 4074 -> 3847 us  (0.94x, raymarch lower)
- VRAM dag_bytes 552 KB vs mesh_bytes_est 10.45 MB (~18.9x less)
- acquire_us_mean 3.4 us << p50
Does not clear the strict p50<=1.10x bar; the frag_depth/early-Z overdraw ceiling
is the p50 cost and the single-pass/compute node is the named follow-up lever.

## Tests
`cargo test --workspace` green (645 passed): world_dda unit tests, client<->host
contract tests (real LocalHost: WriteVoxel touches exactly one voxel; brush
center math lands on target and the prediction covers it), refresh-filter unit
test, and a headless ECS test for the make-before-break swap. Docs + roadmap
memory updated.
