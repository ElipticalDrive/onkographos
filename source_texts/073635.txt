Direct visualization from a NRRD file is not supported in X3DOM yet. You should use the <ImageTextureAtlas> node instead of the <ImageTexture3D> node. To achieve this you need to convert the volume data into a texture atlas first:
https://github.com/VolumeRC/AtlasConversionScripts/wiki/convertingNRRD
https://github.com/VolumeRC/AtlasConversionScripts/wiki/Visualization
I will try to make a working example for you as soon as I have some time
