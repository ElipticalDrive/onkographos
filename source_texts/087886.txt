Chiseled-heavy worlds dropped to single-digit FPS. NeoForge redrew every chiseled block each frame through a block entity renderer and a 1,000-entry FIFO model cache; both loaders meshed through a global lock with the old face-region extractor.
ShapeMesher: binary greedy meshing over 16-bit occupancy rows per palette state; faces against opaque bits are never emitted.
ShapeMesh/ShapeMeshes: one immutable mesh per distinct shape, stored on the shared VoxelBlobStateInstance, invalidated on model reload.
ChiseledEmitter: mesh to quads; drops block-edge cells covered by an opaque neighbouring chiseled block.
NeoForge: ChiseledBlockStateModel (DynamicBlockStateModel) replaces the BER; Fabric emitQuads uses the same mesh. Bit tints are baked in.
Thread-safe caches; fluid tables are swapped, not cleared, on reload.
meshBenchmark task and README performance table. On a 522,404-block world: quads -49%, meshing 2.2-2.8x faster per shape, 3.3x for the heaviest view.
NeoForge smoke now loads a world and checks the chunk model directly.

Chiseled-heavy worlds dropped to single-digit FPS. NeoForge redrew every
chiseled block each frame through a block entity renderer and a 1,000-entry
FIFO model cache; both loaders meshed through a global lock with the old
face-region extractor.

- ShapeMesher: binary greedy meshing over 16-bit occupancy rows per palette
  state; faces against opaque bits are never emitted.
- ShapeMesh/ShapeMeshes: one immutable mesh per distinct shape, stored on the
  shared VoxelBlobStateInstance, invalidated on model reload.
- ChiseledEmitter: mesh to quads; drops block-edge cells covered by an opaque
  neighbouring chiseled block.
- NeoForge: ChiseledBlockStateModel (DynamicBlockStateModel) replaces the
  BER; Fabric emitQuads uses the same mesh. Bit tints are baked in.
- Thread-safe caches; fluid tables are swapped, not cleared, on reload.
- meshBenchmark task and README performance table. On a 522,404-block world:
  quads -49%, meshing 2.2-2.8x faster per shape, 3.3x for the heaviest view.
- NeoForge smoke now loads a world and checks the chunk model directly.
