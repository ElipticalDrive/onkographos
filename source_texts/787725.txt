# Ray E-Commerce Stream Analytics Tutorial

This project demonstrates how to build a real-time analytics and personalization pipeline for e-commerce web logs using [Ray](https://ray.io/). It showcases stateful session management, dynamic user intent inference, and personalized recommendations-all in pure Python, without the complexity of traditional streaming frameworks.

## Features

- **Session Actors:** Each user session is managed by a dedicated Ray actor, maintaining state across events.
- **Intent Inference:** User intent is inferred dynamically from session history.
- **Personalization:** Real-time recommendations are generated based on user behavior and profile.
- **Scalable & Pythonic:** Uses idiomatic Python and Ray’s distributed computing primitives.

## Project Structure

```
.
├── main.py                # Driver script: simulates log events and orchestrates Ray actors
├── event_simulator.py     # Generates realistic e-commerce web log events
├── user_session_actor.py  # Defines the UserSessionActor and recommendation logic
├── requirements.txt       # Python dependencies (Ray, etc.)
└── README.md              # Project documentation (this file)
```
