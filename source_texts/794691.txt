Summary
add a parser-agnostic GaussianData contract built from Three.js StorageBufferAttribute objects
add a single-cloud Three.js PassNode positioned by an empty Object3D
implement projection, hierarchical exclusive scan, intersection emission, stable LSD radix sorting, tile ranges, and front-to-back rasterization as explicit WGSL source wrapped with wgslFn
keep numIntersections on the GPU and launch K-dependent stages through Three.js IndirectStorageBufferAttribute
provide exact float32 and packed tile16 + depth16 sorting
expose a color StorageTexture plus an optional standard perspective-depth StorageTexture
expose Three.js-owned intermediate attributes through pass.getResources() for reuse by other Three.js node code or wgslFn kernels
support canonical real SH degrees 0–3
organize stateful pipeline classes one per file and keep shader algorithms in a parallel src/kernels/ tree
Architecture
```
GaussianPass
└── TiledGaussianPipeline
    ├── ProjectionStage        ← kernels/projection.ts
    ├── ExclusiveScanStage     ← kernels/scan.ts
    ├── IntersectionStage      ← kernels/intersections.ts
    ├── RadixSorter            ← kernels/radix.ts
    ├── TileOffsetBuilder      ← kernels/tileOffsets.ts
    └── TileRasterizer         ← kernels/rasterization.ts
```
The renderer uses public Three.js APIs throughout: StorageBufferAttribute, IndirectStorageBufferAttribute, StorageTexture, wgslFn, and WebGPURenderer.compute(). It does not access GPUDevice, GPUBuffer, command encoders, or the WebGPU backend.
Non-trivial shader control flow and math stay in readable WGSL strings. TSL is limited to the thin binding layer that connects Three.js resources, uniforms, built-ins, storage textures, and compute nodes to those wgslFn functions.
```
const pass = gaussianPass(renderer, camera, data, cloudTransform, {
  depthSortMode: "float32",
  intersectionCapacity: 4_000_000,
  outputDepth: true,
});

const colorNode = pass.getTextureNode("output");
const depthNode = pass.getTextureNode("depth");

const pipeline = new RenderPipeline(renderer);
pipeline.outputNode = colorNode;
```
The render path performs no GPU-to-CPU synchronization. readStats() remains an explicit optional diagnostic readback for capacity overflow.
Validation
npm run format:check
npm run typecheck
npm test
npm run build
all explicit wgslFn pipelines for both float32 and packed16 compiled, validated, and dispatched with Three.js over Dawn/WebGPU null backend, including indirect dispatch and optional depth output
