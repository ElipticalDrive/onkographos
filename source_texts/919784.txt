Rendering photorealistic images, that is, images that mimic reality, is very useful for the entertainment industry, such as in the production of movies and video games, as it helps improve the user experience. To render these types of images, all the physical effects produced by the objects in the scene must be considered. For example, a photo-realistic image must have transparency, depth in the scene, shadows produced by objects, the different materials of the surfaces must be able to be identified, like if the object is smooth or rough, among others. These effects vary depending on the type of material. One particular effect is caustics, which is produced by objects with specular surfaces, such as water, or reflective materials, such as metals. This effect is an accumulation of light at specific areas in the scene that occurs because the light, when it hits the specular material, changes direction following Snell's physical laws, and also, it is focused by the curvature of the specular object. Rendering caustics is very complicated because it requires finding the exact path the light takes between two points connected by the specular surface. Standard rendering algorithms like Path Tracing fail to find these paths or take too long to do so. Some solutions based on Manifold-Exploration methods effectively find these specular paths. However, they use the Newton-Raphson method to find the roots of a complicated objective function, which, in turn, can be challenging.This thesis presents two alternative methods for finding specular paths to render caustics. The first method reduces the dimensionality of the search from a 3D search on the surface of the object to a search on a one-dimensional curve. For this, we introduce the coplanarity constraint. This constraint determines that at a specular point, the incident vector, the refracted/reflected vector, and the normal vector must be coplanar. This coplanarity constraint creates a one-dimensional curve in the specular object. We traverse this curve to find the specular path using a second constraint to guide this search. This second constraint is given by the fact that the angle between the refracted/reflected vector at the specular path and the vector connecting that path to the light must be zero. This dimension reduction in the search makes our algorithm fast and efficient, allowing for rendering animated scenes containing caustics.The second method we propose is to compute Manifold Next-Event Estimation without using the Newton-Raphson method, that is, without using derivatives. Instead, we propose to use the Nelder-Mead method, which searches for the minima of an objective function, iteratively evaluating the function at three local points (a simplex). Our method achieves results similar to those of the state-of-the-art. While it may take longer to converge to a valid solution than the Newton-Rapson method, the strength of our method lies in its simplicity of implementation and its ease of inclusion as part of a global illumination rendering system.
