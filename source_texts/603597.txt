This is my solution.
```
 function checkHQSplatandOrthographicCamera () {
          if (viewer.scene.cameraMode === CameraMode.ORTHOGRAPHIC && viewer.useHQ) {
            viewer.setFOV(0);
          } else {
            viewer.setFOV(60);
          }
        }
```
