Summary
Position encoding: Sinusoidal positional encoding for injected activation vectors — RoPE doesn't survive in the residual stream, so without this activations lack position information. Integrated into core/ao.py and train_mixed.py materialization.
Corpus pre-tokenization: corpus_tokenize.py eliminates 7x redundant tokenization across dataset loaders via parallel multiprocessing. All loaders now accept pre-tokenized entries and check for _ctx_ids.
Persistent data cache: data_cache.py uses SHA-256 hashing of all data-generation params to pickle and reuse training data across runs.
Multi-GPU random-layer training: train_random_layers.py — Poisson-sampled random layer subsets (mean=5) instead of fixed 3-layer approach. Includes grouped-per-layer prefix format, single-forward-pass multi-layer materialization, torchrun/NCCL support, 2-stage curriculum, third-binned eval logging, and per-task loss decomposition.
Test plan
Verify train_mixed.py still works with existing corpus (position encoding + caching additions)
Run train_random_layers.py single-GPU to validate data loading and training loop
Run train_random_layers.py multi-GPU with torchrun --nproc_per_node=2
Check wandb logging (third-binned eval, per-task loss)
