Part of the Bragg edge epic (#451).
What
New crates/nereids-raytrace/ crate implementing parallel-beam ray tracing
through a 3D voxel grid for neutron transmission imaging.
Core algorithm
Amanatides-Woo DDA (Digital Differential Analyzer):
Given a ray origin and direction, step through voxels one at a time
At each step, advance to the next voxel boundary along the axis with the
smallest t_max value
Record (voxel_index, path_length) for each traversed voxel
O(N) where N is the number of traversed voxels (typically ≈ grid_size)
Reference: Amanatides & Woo, "A Fast Voxel Traversal Algorithm for Ray Tracing"
(Eurographics 1987).
Types
```
pub struct VoxelGrid {
    pub dims: [usize; 3],      // (Nx, Ny, Nz)
    pub size: [f64; 3],        // physical size in meters
    pub origin: [f64; 3],      // physical origin
}

pub struct RaySegment {
    pub voxel_index: usize,    // flat index into dims[0]*dims[1]*dims[2]
    pub path_length: f64,      // meters
}
```
Functions
Single ray
```
pub fn trace_ray(
    grid: &VoxelGrid,
    origin: [f64; 3],
    direction: [f64; 3],
) -> Vec<RaySegment>
```
Parallel beam projection (single value per voxel)
```
pub fn parallel_projection(
    grid: &VoxelGrid,
    values: &[f64],            // flat array, one value per voxel
    beam_direction: [f64; 3],
) -> Array2<f64>               // (det_rows, det_cols) line integrals
```
Detector pixel grid: for beam along z, detector is in the xy-plane with the
same pixel pitch as the voxel grid. For arbitrary beam directions, the detector
grid is perpendicular to the beam.
Parallelized with rayon: each detector pixel (ray) is independent.
Wavelength-resolved projection
```
pub fn spectral_projection(
    grid: &VoxelGrid,
    cross_sections: &Array4<f64>,  // (Nx, Ny, Nz, N_lambda) in cm^-1
    beam_direction: [f64; 3],
) -> Array3<f64>                   // (det_rows, det_cols, N_lambda) transmission
```
Optimization: compute ray path once per pixel, then accumulate
−ln(T_λ) = Σ_k Σ_k(λ) × δ_k for all wavelength bins
simultaneously. The inner loop is a dot product (path_lengths · cross_sections
per voxel), which is SIMD-friendly.
Returns transmission T = exp(−line_integral) for each pixel and wavelength.
Tests
Uniform block: all voxels same value σ. Line integral along z-axis
through center equals σ × Nz × voxel_size_z.
Single voxel: 1×1×1 grid, T = exp(−σ × size_z).
Off-axis ray: beam at 45° through a 2D grid, path lengths equal
voxel_size × √2 for diagonal traversal.
Empty voxels: zero cross-section voxels contribute nothing.
Symmetry: rotating beam direction 90° and transposing the grid
gives the same result.
Spectral consistency: spectral_projection with identical cross-sections
at all wavelengths gives uniform transmission across wavelength axis.
Dependencies
nereids-core (constants)
ndarray (Array2, Array3, Array4)
rayon (parallel iteration)
