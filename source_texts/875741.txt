Summary
This PR implements P4-12 Procedural Synthesis and P4-13 Analysis Primitives for the image engine.
P4-12 — Procedural Synthesis
Implemented clean-room, dependency-free procedural synthesis functionality, including:
OpenSimplex2-based 2D noise
OpenSimplex2 improved-coordinate variant
Interpolated value noise
FBM (Fractal Brownian Motion)
Worley/cellular noise
Domain warping with genuine coordinate displacement and resampling
Linear gradients
Radial gradients
Placeholder frame generation
Deterministic identicon generation
Deterministic seeded behavior
Public API exports through the CV module index
The implementation does not introduce an external noise library and remains aligned with the project's IP-clearance requirements.
P4-13 — Analysis Primitives
Implemented the required image-analysis primitives, including:
Histogram generation
Luminance histogram
Channel statistics
Mean and variance analysis
Entropy calculation
Color statistics
Image bounds/region analysis
Edge-density analysis
Connected-component analysis
Image complexity/quality-related analysis helpers
The P4-13 implementation was previously completed and remains unchanged by the P4-12 work in this branch.
Verification
P4-12
Focused P4-12 tests: 21/22 passed
Remaining failure: domain-warp divergence assertion caused by 8-bit output quantization.
Investigation confirmed that:
warpStrength produces genuine non-zero coordinate displacement.
Continuous floating-point fBm outputs differ between warped and unwarped sampling.
The outputs become identical only after Math.round() converts them to 8-bit pixels.
No artificial pixel perturbation or test weakening was introduced.
P4-13
P4-13 implementation and associated tests were previously verified.
No P4-13 regression was introduced by the P4-12 implementation.
Repository checks
pnpm lint — passed
TypeScript/build checks — passed
Full engine test suite — 890/891 passed
The single remaining failure is the same P4-12 domain-warp quantization case.
Scope
P4-12 procedural synthesis
P4-13 analysis primitives
No CI configuration changes
No unrelated P4 task changes
No test weakening
No external noise-library dependency introduced
Known Limitation
The remaining domain-warp test failure is a quantization-related fixture issue rather than evidence that domain warping is a no-op. The implementation produces different continuous values and genuine coordinate displacement before the final 8-bit quantization step.
