Direct volume rendering of scalar fields uses a transfer function to map the measured data to the colors and opacities. This paper advocates the use of multi-scale boundary information in transfer functions with a methodology for computing high-quality boundary measurements. A new multi-scale approach for the extraction of boundary from volume datasets is described. First, the boundary voxels are defined with gradient magnitude threshold to refine the dataset. Then the boundaries are detected as the maxima in cumulative Laplacian-weighted gray value histograms with a computationally efficient method roquiring only a single pass through the boundary volume. Multi-scale smoothing of the cumulative Laplacian-weighted gray value histogram using Gaussian filters of various sizes allows the iso-surfaces to be defined hierarchically over a scale space map. Finally the Gaussian transfer function is designed by the boundaries for the high-quality rendering.
