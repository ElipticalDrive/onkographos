This commit makes the application fully functional for viewing 3D quaternion
fractals (Mandelbulb) in real-time with interactive camera controls.

Changes:
- Implemented GPU-accelerated Mandelbulb raymarching kernel in IlgpuFractal.cs
  - Distance estimation algorithm for true 3D fractal surfaces
  - Camera-aware perspective projection with configurable FOV
  - Surface normal calculation for realistic lighting
  - Configurable parameters (power, iterations, bailout radius)

- Added complete 3D scene setup in Main.cs
  - Real-time texture streaming from GPU compute to Godot material
  - First-person camera controls (WASD + mouse look + vertical movement)
  - Interactive fractal power adjustment (Q/E keys, 2.0-16.0 range)
  - Per-frame rendering at 800x600 resolution

- Created comprehensive README.md documenting:
  - Architecture and technical implementation
  - Build instructions and requirements
  - Control scheme and customization options
  - Future enhancement roadmap

- Updated next.md with current implementation status

The application now renders true 3D Mandelbulb fractals using raymarching,
not 2D projections. Users can navigate through and around the fractal geometry
