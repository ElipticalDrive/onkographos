What this closes
reconstruction/meshing/ was an empty scaffold and Geometry(type=MESH, data_uri, data_hash) -- designed for real mesh artifacts since day one -- was never produced by anything. The glTF exporter explicitly excluded MESH payloads. This PR wires the last unmapped leg of the capture spine:
```
fused metric cloud -> filtered/oriented -> COLMAP CPU poisson_mesher
  -> MeshData artifact (content-addressed, sha256)
  -> Geometry(type=MESH, data_uri, data_hash) + STRUCTURE entity in WorldIR
  -> glTF TRIANGLES primitive + Studio web viewer mesh layer
```
Implementation
reconstruction/meshing/mesh.py — MeshData (vertices/faces/per-vertex normals), deterministic binary encoding (artifact-hashable), binary-PLY writer/reader that follows header-declared property types (COLMAP writes property list int int vertex_indices; uchar assumptions misparse it).
reconstruction/meshing/preprocess.py — deterministic voxel downsample, statistical outlier filter, camera-oriented PCA normals (scipy cKDTree, oriented toward observing camera centers), and a camera-envelope filter: the triangulated sparse cloud defines the plausible scene extent (95th-percentile distance-to-nearest-camera); depth-unprojection artifacts beyond it are cut with reported facts.
reconstruction/meshing/surface.py — mature backend: the configured COLMAP binary's CPU poisson_mesher. Capability-probed (colmap help must list the command); adapts to two observed COLMAP 4.2 behaviors: the density-bounded solver depth (auto-retries at the reported maximum) and trim-vs-sparsity (COLMAP's dense-pipeline trim=10 empties sparse clouds; default 0 here). Honest MeshingUnavailableError/MeshingError; no fabricated fallback mesh.
Pipeline stage 3.6 (engine/pipeline/vertical_slice.py) — meshes the fused metric cloud, persists the artifact, attaches the geometry + entity, and rolls back if the world fails its validation gate. The METRIC gate uses the scale-anchoring stage's fact directly (a metadata read would race stage 4 -- regression-tested). artifact_store now also flows to the compiler, so promoted planes persist real point payloads.
glTF exporter — resolvable MESH payloads export as real TRIANGLES primitives; index width follows vertex count (uint32 >65,535). Cube fallback only when no real artifact exists. Plane/object entities export as POINTS primitives from their real artifacts.
Studio viewer — --mesh embed (or served fetch) renders the reconstructed surface as a translucent layer; header-driven PLY triangle parser.
reconstruction/mvs/README.md — documents that classic dense MVS (patch_match_stereo) is dependency-blocked: the environment's COLMAP 4.2.0 is CPU-only. Not silently emulated.
Real-data verification (observed, this environment)
Real 28-image room fixture, full pipeline (run_vertical_slice.py, MiDaS_small, mesh depth 9):
25/28 cameras registered (honest PARTIAL), scale=metric (0.2458 m/unit from the measured 0.44 m baseline)
Envelope filter cut 43,445 depth-noise points (envelope 4.63 m from 1,051 real sparse points) -- without it the mesh came out at 400 m / kilometer scale
Room mesh: 240,735 vertices, 482,260 faces at honest room scale (extent 15.8 x 5.7 x 15.8 m), persisted as artifact://23a91a39..., mesh.ply written
WorldIR: 71 entities, 4 measurements, 0 validation errors after the mesh lands
glTF export: room mesh as mode-4 TRIANGLES (1,446,780 uint32 indices) + 48 entities as real POINTS primitives from their artifacts; exports/scene.gltf written
Synthetic-plane backend checks: 3k pts -> 9k-vert mesh (extent 2.2 m for a 2 m plane); 40k pts -> 75k verts / 150k faces in 1.6 s
Tests
tests/test_meshing_pipeline.py: 27 deterministic tests (MeshData roundtrips incl. COLMAP-style headers, preprocessing determinism + normal orientation, stage skip paths, artifact roundtrip, exporter TRIANGLES) + a dependency-gated real-COLMAP test (REALITY_COLMAP)
Full suite: 1294 passed, 1 pre-existing SAM torch-hub env failure (unrelated), 1 gated skip
