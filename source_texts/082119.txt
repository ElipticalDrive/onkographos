# CS677 Assignment 2

This zip file contains the asg2.py, hostfile, opacity_TF.txt, color_TF.txt, Report.pdf and image files from different runs.

The main Python program uses mpi4py, numba, scipy, numpy and PIL libraries to execute the program in a parallel environment, handle the dataset values better and image rendering. It also uses sys and gc libraries to take command line arguments and collect garbage.

## Exceptions to the assignment questions - 
 
1. The command to execute include following parameter ```--mca btl_tcp_if_include eno1``` this code specify the interface on which mpi should connect to other systems
2. The hostfile is in format of IP addresses instead of hostnames as the systems were unable to process hostnames.

## Steps for program execution
  1. Run command
     ```
     bash script.sh
     ```
     > This script is for installing openmpi, python, pip, numpy, numba and mpi4py (You can ignore these commands on preinstalled systems)
  2. Make sure opacity_TF.txt and color_TF.txt are in same folder in which volume_rendering.py is present.
  3. Execute the command in format given in assignment in terminal
     ```
     mpirun --mca btl_tcp_if_include eno1 -hostfile hostfile -np 8 python3 asg2.py Isabel_2000x2000x400_float32.raw 2 2 2 0.5 opacity_TF.txt color_TF.txt
     ```
  4. The resulting image will be stored with the name "px_py_pz.png"
