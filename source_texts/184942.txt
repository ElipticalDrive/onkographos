This file includes pre-trained models of our approach in every C3VD sequence. We provide models for all variants of the presented ablation study, described in the paper "Realistic Endoscopic Illumination Modeling for NeRF-Based Data Generation".

Researchers can use the provided models directly to render endoscopic datasets using the paper's open-source code repository (https://github.com/surgical-vision/REIM-NeRF).

Instructions on how to extract and use the provided models are included in the main readme.md file of the afforemented code repository.
