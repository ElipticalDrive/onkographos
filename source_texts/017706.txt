Abstract
Texture-mapping hardware has been successfully exploited for
volume rendering. In this paper, we combine splatting method
with 2D texture mapping efficiently and propose an algorithm for
footprint algorithm based volume rendering accelerated by multi
texture mapping. First of all, a regular data set is divided by some
texture slices along the primary viewing direction. Then the
segmented data are projected to the texture slices plane. Lastly, all
these texture slices compose the final image by blending. With our
algorithm, the scaled volume data set can be rendered effectively
and fast but not degrade the quality of image remarkably.
In this paper, by combining the advantages of hardware-assisted
method with footprint algorithm, we present a new algorithm,
which can achieve much faster rendering speed. It reduces time
complexity of depth sorting by dividing volume data and
composes the final image through hardware-assisted texture slices
blending. These will be described in section 3.2 and 3.3
respectively. The remainder of this paper is organized as follows.
In Section 2 we briefly review related work, and in Section 3 we
describe the algorithm in detail. The method of this paper is
compared with traditional footprint method and experimental
results in Section 4. Finally, in Section 5 we end the paper with
conclusion.

Introduction
Volume visualization is a research area that deals with various
techniques for extracting meaningful visual information from
abstract and complex volume data. It has been successfully applied
into several applications, including medical visualization,
computational fluid dynamics, seismology, and natural phenomena
simulation. One of the most frequently applied techniques for
visualization is direct volume rendering (DVR), which produces
3D rendered images of high quality directly from volume data.
DVR techniques obtain a synthetic image of the VoI (volume of
interest) directly from the volume data, without any intermediate
surface representation. Compared to surface rendering techniques,
the major advantage of DVR is that all gray level information
which has originally been acquired is kept during the rendering
process. Furthermore, DVR allows a combined display of different
aspects such as opaque and semitransparent surfaces, cuts and
maximum intensity projections.

Related Work
Footprint method, introduced by Westover, voxels are traversed in
either front-to-back or back-to-front order consistent with a given
viewpoint. These algorithms access the volume data in storage
order, in such a way that each voxel is visited only once, thus
avoiding redundant computation. During the traversal, each voxel
is classified and shaded by user-supplied opacity and material
transfer functions. Then it is projected into the image plane, and its
contribution is accumulated to an image buffer using a projected
reconstruction kernel, called a footprint.
Over the years, many computer graphics researchers have
developed accelerate splatting algorithms. [Laur and Hanrahan
1991] describe a hierarchical footprint method by using octree to
exploit coherence of homogeneous region and to enable
progressive refinement during rendering. [Insung 1995] developed
an efficient data structure to skip voxels that do not contribution to
the rendering image. [Daqing Xue 2005] developed a splatting
algorithm that utilizes the new capabilities of vertex programs and
the OpenGL extensions on a PC equipped with an NVIDIA
GeForce4 display card.
However, rendering speed has always been a major problem in
direct volume rendering, because all regions of the volume may
contribute to the image, and because new orientations generally
require considerable re-computation. A number of methods
offering different combinations of rendering speed versus image
quality have been presented. Image-order algorithms like ray
casting produce superior quality images, but have to traverse the
data structure redundantly. Some object-order methods like
General-purpose texture-mapping hardware has been used in
direct volume rendering for several years. With the advances in
graphics hardware, the rendering speed has dramatically increased
as well as various features that improve image quality, such as
lighting and tri-linear interpolation, have become available.
Texture mapping is an established rendering technique used to
enhance the realism of 3D models. In computer vision, 3D models
are typically constructed using multiple images (and possibly
range data); their textures are recovered using combinations of
appropriately extracted parts of the source images.

The main advantage of splatting(or footprint) method is the
storage-order access to the data. In an orthographic view, the
footprint of the projected reconstruction kernel for any sample is a
constant except for a screen space offset. This allows us to build a
footprint function table once and use the table for all samples. In
practice, lookup tables for the filter weights avoid excessive
arithmetic complexity. In our algorithm, the voxel is projected by
using the improved splatting method which can avoid popping and
splatting overlay. Compared with the traditional method, we
projected the voxels onto the texture slice plane directly other than
screen plane. For these purposes, we define the texture slice as
follows (Figure 3):
1. Every point in texture has been set to be RGBA mode.
2. The original α value of every point is zero.
3. Every texture slice parallels to the view plane.
4. The number of points in horizontal direction (x axis) and
vertical direction (y axis) on all texture slices is equivalent
respectively.
Figure 4: Projecting the voxels to the texture plane
After all texture slices being made, texture blending is the last but
key step which composes the final image. In this step, the textures
must be mapped onto the polygon surface in the scene firstly. In
texture mapping, each polygon vertex is given a point in the
texture space, and the graphics system maps values from the
texture map onto the polygon surface by interpolating texture
coordinates. In order to blend correctly, all the texture slices are
paralleled with the screen plane (Figure 5) and each polygon
vertex coordinates(x and y) are equal except z . Furthermore, the
order of blending is front-to-back which is same with voxels
projection.
