GradInf is an open-source Haskell library for gradient inference, a new approach to gradient estimation. It is released under the Apache-2.0 license. The methods implemented in GradInf are described in the following publication. Gaurav Arya, Mathieu Huot, Moritz Schauer, Alexander K. Lew, and Feras A. Saad. 2026. GradInf: Gradient Estimation as Probabilistic Inference. Proceedings of the ACM on Programming Languages 10, PLDI, Article 243 (June 2026), 27 pages. https://doi.org/10.1145/3808321 The tarball grad-inf.tar.gz contains Source code of the library. Documentation of the library API and usage tutorials. Experimental pipeline to reproduce the results in the paper. A Docker image with all necessary dependencies pre-installed is provided in grad-inf-experiments-docker.tar.gz.For the latest version, please visit https://github.com/probsys/grad-inf.
