What to build
A sparse octree radiance cache that can replace the dense mip-mapped volume, starting from the data structure itself and its cone-integration semantics — all on the CPU, no GPU work yet.
Today the GI cache is a dense uniform grid at res=128 over a scene whose width is 640, so each cache cell averages 5×5×5 voxels. A chair leg 3 voxels thick becomes a 4% grey smear; specular gloss is hard-clamped to diffuse so the smears do not read as speckle. The cone math is a faithful port of the reference VCT — the data feeding it is what limits quality.
This ticket builds the replacement structure and its traversal rules, and proves on the CPU that it fixes the resolution problem.
Acceptance criteria
An octree whose leaves carry aggregated radiance / albedo / alpha / emission for a block of voxels, sized so a 3-voxel-thick chair leg survives rather than being averaged away (leaf size is a parameter, not hard-coded)
Interior nodes are DAG-deduplicated (repeated structures such as bookshelf shelves and basket weave share nodes)
The builder handles non-power-of-two scene sides correctly — the living room is 640 per axis, whose enclosing cube is 1024, and the padded region produces no nodes
Cone level selection is defined by the cone's cross-section radius growing with distance: a far sample stops at a coarse node instead of over-sampling fine ones. There is no mip chain and no LOD parameter anywhere in this rule
CPU-side tests assert all three: a 3-voxel leg is preserved through the tree, empty octants produce no nodes, and node count is far below voxel count

Also asserts empty octants produce no nodes (empty_octants_produce_no_nodes: a chain of 7 single-child levels dedupes to ONE 2-word node) and node count far below voxels (node_count_far_below_voxel_count).
Deviation from the spec worth recording: the spec's §4.1 says the leaf grid for the living room is 128 per axis → 7 interior levels. Verified and pinned. The spec's first draft had said 4 levels; that error is what prompted the 'non-2-power sides' requirement, and living_room_depth_matches_the_design now locks the corrected arithmetic.
Not done (next tickets): crate::svo is intentionally NOT reused as the GI structure — only its flat traversal layout carries over. Its 2×2×2 hard-coded leaf makes node count proportional to voxel count. Nothing GPU-side exists yet; the cone rule is a CPU function only.
