Context
app/primitives/overlay/fog-overlay.vue and app/primitives/overlay/background-texture.vue both pipe a 3-octave simplex FBM through smoothstep and color mixes. The result is structurally flat — drifting noise blobs without organic detail. We want to push visual expressiveness on both while keeping the current performance envelope.
Current baseline (must not regress)
30fps cap
3 octaves FBM (4th/5th previously dropped as negligible after smoothstep)
Cached uniform locations
Conditional render by colorMode (background-texture.vue dark-only, fog-overlay.vue light-only)
prefers-reduced-motion pauses time
visibilitychange stops raf on hidden tabs
DPR capped at 1.0
No npm dependencies added
Direction
Any of these, alone or combined, as long as it fits the 30fps budget.
Structural
Domain warping (snoise(p + snoise(p))) for fog tendrils and rust corrosion edges
Worley / cellular noise for rust pitting and flake grain
2D curl noise for fluid-like fog motion instead of plain translation
Spatially separated masks for rust vs. blood regions rather than uniform mixing
Post-processing
Vignette and subtle chromatic aberration in dark mode
Hash-based grain / film noise overlay (no extra FBM)
Cheap bloom approximation on bright rust veins
Directional light leaks cutting through the fog
Constraints
Keep total octave count at or below current (combine smarter, don't add)
No increase in per-frame uniform uploads
Preserve DPR cap, visibility handling, reduced-motion support
No new npm dependencies
Stay on WebGL (WebGPU migration and three.js are out of scope)
Tasks
Prototype domain-warped fog in app/primitives/overlay/fog-overlay.vue
Prototype cellular-noise rust pitting in app/primitives/overlay/background-texture.vue
Measure fps and GPU time before / after
Tune parameters so the overlay stays background, not subject
Verify light/dark transitions render cleanly
Out of scope
WebGPU migration
Adopting three.js or similar runtime
Interactive effects (mouse-driven, scroll-reactive, etc.)
