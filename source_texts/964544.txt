Summary
Implements WI-C3-07. Stacked on #67 (C3-06), targeting staging.
PbrMetallicRoughness.frag now evaluates the existing global light rig through a Cook-Torrance GGX/Smith/Schlick metallic-roughness BRDF: F0 = mix(0.04, albedo, metallic), kd = (1-F)(1-metallic), alpha = roughness².
Remaining roles per deep-dive policy: packed MR texture (roughness G, metallic B, linear), tangent-space normal mapping (scale, world TBN, double-sided back-face flip), occlusion R channel modulating the summed per-light ambient, and sRGB-decoded emissive added after lighting.
UV0/UV1 selection stays independent per binding; base-color and emissive decode from sRGB, data textures stay linear; final linear color encodes to sRGB locally until G6.
New PbrShaderBindingTests (headless device): full material resource set binds constants + five role textures + five samplers, with constants written through both UV-set selections. Visual proof is C3-10/11.

dotnet test src --filter Category!=Interactive: 1169 passed, 0 failed.
Both shader stages compile via glslangValidator in the build; format verify, brace check: clean.
