This dataset contains the 30 485 496 regular triangulations of the Hypersimplex(2,7) computed with mptopcom. The triangulations were computed up to symmetry and the result contains one representative from every orbit. The dataset is structured as follows: `hypersimplex_2_7.dat` contains the input points and the group acting. `hypersimplex_2_7_reg.result.*.xz` contains the output from mptopcom. Since the computation was too large, it had to split up into eleven parts.

Description
This dataset contains the 30 485 496 regular triangulations of the Hypersimplex(2,7) computed with mptopcom. The triangulations were computed up to symmetry and the result contains one representative from every orbit. The dataset is structured as follows:
`hypersimplex_2_7.dat` contains the input points and the group acting.
`hypersimplex_2_7_reg.result.*.xz` contains the output from mptopcom.
Since the computation was too large, it had to split up into eleven parts.
