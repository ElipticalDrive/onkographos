What this changes
Draws that sample a 2D texture array as a 3D texture were skipped ("texture type 5 (shader D3)").
The hardware lets a shader read a 2D array through a 3D sampler, with the layers as depth slices. Games do this with colour lookup tables: they render the table's slices into a 2D array, then sample it as 3D in post-processing. Those lookup draws were skipped.
Such a texture now gets a real 3D image of its own, filled from the array's layers in guest memory. Layers the GPU has rendered since are copied in from their render targets, the same way volume() keeps 3D textures up to date. Its cache key carries an extra bit (ARRAY_VOLUME) so it never collides with a real 3D texture at the same address. Only uncompressed block-linear arrays are handled; anything else is still reported and skipped.
In the test run that found it, this took the skipped lookup-table draws from 31 to none.
