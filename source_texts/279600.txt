# SplatConverter

一个将`.ply`文件转换为`.splat`文件的工具
## 一、安装步骤
```
pip install -r requirements.txt
```
## 二、转换规则

在运行时，原`.ply`文件中的字段将会经过如下数学计算而被放到`.splat`文件之中：

1. xyz：与ply保持一致，float32类型

2. scales：经过指数变换，float32类型

   > $$
   > scales_{splat} = \exp{(scales_{ply})}
   > $$
   >
   > 

3. color：由rgb和opacity组成，unit8类型。其中rgb经下述方式得到：

   >$$
   >\begin{align}
   >	SH_C0 = 0.28209479177387814 \\
   >       r = (0.5 + f\_dc\_0 * SH\_C0) × 255 \\
   >       g = (0.5 + f\_dc\_1 * SH\_C0) × 255  \\
   >       b = (0.5 + f\_dc\_2 * SH\_C0) × 255
   > \end{align}
   >$$
   >
   >
   >
   >opacity经如下方式得到：
   >$$
   >opacity_{splat} =
   >\frac{1}{1+\exp{-opacity_{ply}}} × 255
   >$$

4. rot：先对进行归一化，再映射到`[0,255]`，unit8类型

   >$$
   >rot_{splat} = \frac{rot_{ply}}{||rot_{ply}||} \times 128 + 128
   >$$
