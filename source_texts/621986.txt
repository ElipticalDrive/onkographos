Changes all rolled up:
A few NVidia deprecation fixes
Support for vec3 color buffers
Changes to camera movements (movement per keypress)
Updates bundled GLFW to most recent version
Updates bundled tinygltf to most recent version
Adds a CUDA summing kernel to average samples GPU side before transferring averaged values from GPU to CPU. CMake files took quite a bit of changing to make this work, the trick was compiling both Optix PTX functions and CUDA kernels within the same library.
Tweaked control of samples per ommatidium (introducing a coded limit to avoid crashes)
Changes to make it possible to run compound-ray alongside mathplot. Changed glad headers to OpenGL 4.1 (cross platform compatible).
Made compound-ray installable (libs in /usr/local/lib, includes in /usr/local/include/compound-ray/ etc)
Separated the OpenGL-specific parts of newGuiEyeRenderer AWAY from libEyeRenderer, allowing libEyeRenderer to be used in a program that has its own OpenGL setup without interference.
Adds some libEyeRenderer API calls to transfer the compound-eye camera frame of reference to client code
