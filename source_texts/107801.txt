Current state
The noise library (noise/noise.hpp) provides 2D-only noise functions: perlin(), simplex(), worley(), turbulence(), turbulentsin(), fractal_brownian(). All operate on noise::point which is a 2D type. There is an existing @todo at line 83: "The set of 3d perlin noise gradients".
Goal
Add 3D variants of the noise functions. The key changes:
1. New type
```
using point3 = geometry::point_<3>;
```
2. 3D noise functions
```
namespace noise {
    precision perlin(point3 const& p, precision scale, seeds const& s, precision gain);
    precision simplex(point3 const& p, precision scale, seeds const& s, precision gain);
    precision worley(point3 const& p, precision scale, seeds const& s, precision gain);
    precision fractal_brownian(point3 const& p, precision seed, size_t octaves,
                               precision lacunarity, precision gain,
                               precision init_amplitude, precision init_frequency);
}
```
3. Implementation approach
For 3D Perlin:
Extend the existing cell_flows() to handle 3D (8 corners instead of 4)
3D gradient vectors from a pre-computed set (Perlin 2002 provides 12 gradient vectors)
The fade function (6t^5 - 15t^4 + 10t^3) remains the same, applied per-component
Trilinear interpolation instead of bilinear
For 3D Simplex:
Uses a 3D simplex (tetrahedral tiling) instead of 2D triangles
Standard simplex noise algorithm with 4 corners per simplex
4. Volumetric texture mediums
Once 3D noise exists, create a medium that uses it:
volumetric_noise medium taking a 3D point (world space) instead of a mapped 2D UV coordinate
Enables solid textures that look consistent when carved/cut (no surface stretching)
Useful for marble, wood grain, clouds, and other natural materials
