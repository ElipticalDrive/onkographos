NeRF represents a 3D scene as a neural network: given photographs from several angles it synthesises a photorealistic view from any new one. The name is literal — the field is a 5D function returning the colour leaving a point in a given direction together with how opaque that point is, neural is that it lives in weights rather than a table, and rendering is photographing that field.
Sections
The network — the (x,y,z,θ,φ) → (RGB,σ) signature; positional encoding (ten bands for position, four for direction, so 63 and 27 numbers) because an MLP on bare coordinates learns only low frequencies and renders blurred; eight layers of 256 with the encoded position concatenated back in at the fifth. The asymmetry at the end is the design: density sees position alone, only colour sees direction, which buys specular highlights without letting the geometry change with viewpoint.
The training loop — the reference implementation's optimisation step. The MSE against photographed pixels is the entire supervision: no depth maps, no masks, no 3D ground truth. Geometry arrives only because it is the one way to explain several views at once.
What the density means — σ is a probability density, per unit length and possibly far above one. Only σ·dt is a probability.
From field to pixel — the rendering integral. dT/dt = −σT is where the exponential comes from, and T·σ·dt is the distribution over where a ray terminates, so C is an expected colour.
The figure
Inline SVG of the MLP in assets/image/. Labels translated from Chinese (including <title> and <desc>, which screen readers announce), and a C2PA provenance blob stripped — 28% smaller. Every label checked against its box width at 14px; no overflow.
Architecture independently verified against a Keras model of the same network: nerf_compact, 11 layers, and every dimension in the figure confirmed — 63, 319, 27, 283, 128, 3, 1.
