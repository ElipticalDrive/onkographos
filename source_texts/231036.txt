Programme context. Part of the neural-fields work across the stack (wave epic jejjohnson/geostack#82). The literature review is geostack report 18 and the plan is the neural-fields design page; both land in jejjohnson/geostack#87. Everything needed to implement this issue is below.
Problem / Request
Add a notebook that fits a neural field directly on along-track altimetry (no regridding) in the Western Mediterranean and scores it against the three operator runs already in docs/notebooks/irregular_geometry.ipynb (regridded FNO, ManifoldNO in a Slepian basis, GeoFNO).
User Story
As a new geonnax user, I want one worked example showing a SIREN reconstructing SSH from tracks, with its failure modes, so I can judge when a neural field beats an operator.
Motivation
The only INR example in geonnax is the synthetic XCH₄ demo in the README. The geostack case 9 benchmark (jejjohnson/geostack#85) needs a reference neural-field mapper, and this notebook is it.
Demo To Implement
```
enc = geonnax.SphericalHarmonicEncoder(l_max=40, input_mode="lonlat")
time = geonnax.CyclicEncoder(period=365.25)
field = geonnax.SIREN.init(in_features=enc_dim + 2 + 1, hidden_features=256, out_features=1,
                           depth=4, key=key)
def f(lon, lat, t):                     # one example
    return field(jnp.concatenate([enc(jnp.array([lon, lat])), time(t), jnp.array([t / T])]))[0]
# Fit with optax Adam on (lon, lat, t, sla) track points; minibatches of 4,096 points.
# Evaluate on the notebook's existing 1/20° grid and on held-out tracks.
# Show geostrophic currents with geonnax.diffops.surface_grad_enu if jejjohnson/geonnax#132 has landed.
```
Variants to compare: SH + SIREN; GaussianFourierEncoder + MLP (#133, if landed); MultiScaleSIREN.
Implementation Steps
Reuse the data loading of irregular_geometry.ipynb; author as jupytext, execute, commit .ipynb (see the add-notebook skill)
A results table: RMSE on held-out tracks, effective resolution from the PSD, train time
A short "when it fails" section (low track density, high ω₀ overfitting noise)
Definition of Done
Notebook executed, in mkdocs.yml nav, mkdocs build --strict passes
Testing
Runs on CPU in < 10 min with the committed settings
