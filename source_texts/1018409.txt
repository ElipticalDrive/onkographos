New Features
Create an individual square grid cell by specifying its size, position, and coordinate reference system. Cells are bounded by the coordinate system’s area of use and include an identifier.
Generate a global collection of square grid cells in a chosen coordinate reference system. Cells include identifiers and an estimated equator cell width.
Grid generation can be computationally expensive; exporting the collection before further processing is recommended.

Walkthrough
The change adds FeatureAccessor.cell to create an indexed cell and FeatureCollectionAccessor.grid to create a grid collection in a requested CRS. Both use CRS area-of-use bounds from pyproj. The change adds tests and a runtime dependency.
Changes: CRS Grid APIs
Layer / File(s)
Summary
Create one indexed grid cell
geetools/ee_feature.py, pyproject.toml, tests/test_Feature.py
FeatureAccessor.cell creates a rectangular feature using CRS bounds, size, and cell indices. The feature ID includes the CRS, size, and indices. Tests cover default and custom indices, cell size, bounds clamping, and projected and polar CRS inputs.
Build the grid collection
geetools/ee_feature_collection.py, tests/test_FeatureCollection.py, tests/test_FeatureCollection/serialized_test_split.yml
FeatureCollectionAccessor.grid builds a collection from CRS bounds and cell coordinates. Each feature has a formatted ID and an equator_cell_size_m property. Tests cover geographic, projected, and polar CRS inputs. The serialized fixture changes the split-count expression to convert the sum to an integer.

🎯 Functional Correctness | 🟡 Minor | ⚡ Quick win
Prevent out-of-range indexes from creating invalid bounds.
For a positive size, a negative index places the lower edge below the CRS minimum. An index beyond the CRS maximum places the lower edge above the maximum, while the upper edge remains clamped to the maximum. ee.Geometry.Rectangle can therefore receive bounds outside the CRS area or reversed bounds, causing invalid cell construction. This defect is independent of antimeridian handling.
Clamp the lower edges to the CRS bounds, or reject indexes outside the grid before constructing the rectangle.
