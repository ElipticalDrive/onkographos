Octree preprocessing manually allocated shared geometry, face runs, sorting/UV workspaces, and mesh-writing arrays. It also published collision build tables through global raw pointers.
Use owning vectors for the shared vertices/polygons, per-vertex face lists, mesh build streams, UV/sort scratch, region remapping, and the OCT writing workspace. Return collision build geometry to the preprocessing caller. Delete the global tables, shared-free tracking, capacity-growth helper, duplicated geometry counts, custom workspace moves/destructor, and manual allocation cleanup. The preprocessing service and prop list also own their storage directly.
Keep the existing partitioning, winding, UV deduplication, sunlight, and file field order. OCT arrays transfer float components and fixed-width triangle indices explicitly. Existing byte-exact/fault tests and geometry compaction/material-split tests are retained; a seven-region test exercises the corrected submesh allocation bound beyond the old six-region limit.
Status reporting draws only when a video window exists, so the same preprocessing path can run without a framebuffer. Tagged node storage and other preprocessing buffers outside this coherent group remain separate follow-ups.
Production LOC against merge base 77686d9f: +223/−599, net −376 (tests excluded).
Verification at a59e84bd: Linux, AddressSanitizer and clang-tidy and clang-format pass. The native suite passes all 223 tests, including the 11 licensed runtime scenarios and software-GPU rendering.
