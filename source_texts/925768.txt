# 🧮 Matrix Operations Library in C++

Welcome to the **Matrix Operations Library**, a lightweight and educational C++ project designed to explore and implement core concepts like:

- ✅ Classes & Objects  
- ✅ Inheritance & Encapsulation  
- ✅ Deep Copy / Copy Assignment  
- ✅ Operator Overloading  
- ✅ Dynamic Memory Allocation using Raw Pointers  
- ✅ Function Overriding & Polymorphism  
- ✅ Mathematical logic in object-oriented design

This project is pure **vanilla C++**, no libraries, no STL containers — just raw control.
