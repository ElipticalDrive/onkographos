This PR adds temporal anti-aliasing (TAA) to the GPU renderers. It is item I2 on HALO_INFINITE_STYLE_ROADMAP.md. TAA smooths out what 4× multisampling (MSAA) can't fix: thin trim, fine texture detail and shimmering edges that crawl as the camera moves.
How it works
Turning on SceneDraw.temporal changes how the WebGPU and WebGL2 renderers draw each frame:
Jitter. Each frame, the camera is shifted by a fraction of a pixel. The shifts follow an 8-step pattern (a Halton 2,3 sequence), so over eight frames each pixel is sampled at eight different points.
History. A pass on the GPU blends each new frame into a running "history" image, stored in half floats:
Each pixel finds where it was last frame using its depth and the old and new camera positions, so the history follows the camera as it turns or moves.
The history is clamped to the colours around each pixel in the new frame. Anything that moved or just came into view replaces the old image instead of leaving a trail.
The new frame contributes 10% of the result.
Sharpen. A sharpening pass restores crispness. It is limited by the neighbouring colours so it adds no halos, and it never feeds back into the history.
Before readback. All of this runs on the GPU before the frame is read back, so the usual one- or two-frame readback delay doesn't affect it.
Shared code. The maths and both shader versions live in render/temporal.ts.
Off by default. With it off, the GPU renderers still match the software rasteriser pixel for pixel.
Settings
Render cap. A new temporal render cap is on for the Xbox 360 tier and the Modern tier. Halo: Reach shipped its own temporal anti-aliaser on the Xbox 360.
Quality. A new temporal quality setting is on for the high and medium presets, off for low.
Plumbing. The mesh overlay turns TAA on only when both allow it.
Lockout runs on the Xbox 360 tier, so it gets TAA with no changes. I checked it in Chromium on WebGL2: it renders, reports no GL errors, and the bots don't smear.

temporal.test.ts covers:
The jitter sequence.
The jittered projection, for both perspective and orthographic cameras.
The reprojection: a still camera maps each pixel to itself, and a moving camera finds where a point was last frame.
When the history is trusted.
The cap, the quality presets and the overlay switch.
Checks. npm run typecheck is clean, npm run lint shows 0 errors and 23 warnings, npm run test passes (3000 tests), and check:dist passes.
Limitation
Only the camera's motion is reprojected; objects don't report their own motion. A fast-moving object relies on the colour clamp to avoid smearing.
