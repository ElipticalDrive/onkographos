The design of the Georgia Tech Time Warp (GTW, version 2.0) executive for cache-coherent sharedmemory multiprocessors is described. The programmer &apos;s interface is presented. Several optimizations used to efficiently realize key functions such as event list manipulation, memory and buffer management, and message passing are discussed. An efficient algorithm for computing GVT on shared-memory multiprocessors is described.
