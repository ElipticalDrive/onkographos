核心逻辑：将image(512512)分区(1616),针对选定的分区保留最有可能splatting到该区域的gaussians,对这些gaussian按照ray-space下的深度排序（从浅到深，同时这一分区所有pixel将共享这一ordering).遍历该分区中的pixel，结合排好序的gaussian列表，使用alpha-blending算法计算Pixel-value。
将问题拆解：
1.分区完成后，分区中的pixel索引（16*16）如何与image中的pixel索引映射(因为alpha-blending中用的footprint函数需要的是ray-space下的坐标），这涉及到如何设置分区顺序（即如何给不同位置的分区标号）。
2.保留策略，即如何确定哪些高斯应该保留下来。
3.排序（快速排序），效率至上，输入和输出应该都为一个高斯列表。
4.在分区给定、高斯已排好序、各个pixel索引也确定，对每一个pixel进行alpha-blending（输入pixel索引、高斯列表，输出Pixel-value).这里可使用cuda加速计算,为每一个pixel-value的计算分配一个cuda thread,所有的pixel共享gaussian列表。

def render(K,gaussian_list,image): ###假设thread会自动遍历idx,因此pixel也会得到遍历
```
tile_x = blockIdx.x%tiles_xnum
tile_y = blockIdx.x/tiles_ynum

pixel_x = threadIdx.x%16
pixel_y = threadIdx.x/16



img2tile_offset = torch.tensor([-16*tile_x,-16*tile_y,0])

ray2tile = K;
ray2tile[:,2] = ray2tile[:,2]+img2tile_offset;      ##ray2tile = ray2img + img2tile

pos_tile = torch.tensor([pixel_x,pixel_y,1]);
pos_ray = torch.inverse(ray2tile)@pos_tile;


pixel_value = alpha_blending(gaussian_list,pos_ray)
image[pixel_y,pixel_x] = pixel_value

return image
```
