Add a one-bounce screen-space indirect diffuse GI pass to the deferred renderer — the last missing flagship post-FX (the pipeline already had TAA, FXAA, MSAA, Bloom, HDR/tonemap + auto-exposure, SSAO, GTAO, SSR, DoF, motion blur, volumetric fog, colour-grading LUT, vignette, chromatic aberration).
For each opaque pixel the shader casts a cosine-weighted hemisphere of short rays (Malley sampling on a Duff orthonormal basis) around the G-buffer normal, linear-marches each against scene depth, and on a hit samples the lit scene colour as incoming indirect radiance. The hemisphere mean, tinted by the receiver albedo, is ADDED to the lit colour (indirect diffuse is extra bounced light, unlike SSR's replace/mix), so a saturated wall bleeds its colour onto a neutral floor. Screen-space only: rays that leave the screen or hit the sky contribute nothing and fade out at the borders.
Pipeline placement (deferred-only): AOApply -> SSGI -> SSR -> Bloom. SSGI runs before SSR so reflections include the bounced light; SSR now reads SSGIColor as its freshest upstream. On the forward path SSGIColor is never declared, so the pass self-skips and downstream aliases back to the upstream colour.
Implementation:
PostProcess_SSGI.glsl + Passes/SSGIRenderPass (modelled on SSRRenderPass; linear march, no HZB).
SSGIUBO at binding 40 (UBO_SSGI), SSGIColor blackboard/resource slots, settings + SanitizeSSGI + step/ray caps in PostProcessSettings.
Wired through the Renderer3D UBO upload, blackboard declaration, PostProcessColor priority, blackboard fingerprint, and render-graph node registration.
Scene-YAML serialization (both paths) + editor Post Processing panel section.
Tests:
ScreenSpaceGIMathTest (CPU contract): UBO layout, projection round-trip, octahedral normals, orthonormal basis, the E[cos] = 2/3 cosine-weighting contract, march bounds, estimator, fade curves, sanitization.
SSGIVisualEvidenceTest (L8): renders the full deferred pipeline and asserts a red wall bleeds red onto a white floor (off-vs-on differential, two poses); SKIPs cleanly when no GL 4.6 context exists.
RenderGraphFingerprintTest gains an SSGIEnabled reactivity case.
SSGITest.olo demo scene (ships with SSGI on, like SSRTest.olo).

This PR implements a complete Screen-Space Global Illumination (SSGI) rendering feature in the deferred graphics pipeline. It introduces SSGI configuration parameters, a dedicated render pass with full render-graph integration, pipeline wiring to fit SSGI between AOApply and SSR, GPU state management, editor UI controls, comprehensive mathematical and visual validation tests, and a demo scene.
