Owner
Adds an alternative diffuse-irradiance generator that projects the source environment cubemap onto a 9-coefficient L2 spherical-harmonics basis (Ramamoorthi-Hanrahan) and rasterises the irradiance cubemap via a per- fragment SH evaluation shader, instead of the existing Monte-Carlo cubemap convolution. Output is bit-compatible with the convolution path (same RGBA32F irradiance cubemap, same binding) so no PBR shader changes are required — only the generator swaps.
Toggle: EnvironmentMapComponent gains a m_UseSphericalHarmonics field, exposed in the editor inspector under IBL settings. Flipping it drops the cached EnvironmentMap and forces a regen on the next tick. The IBLCache hashes the flag, so round-tripping between the two paths is cache-fast after the first regen of each. Field round-trips through SceneSerializer (YAML) and SaveGameComponentSerializer (binary).
Benefit is generation speed (~3–10x faster than 1024-sample Monte-Carlo, visible in the new (X.XX ms, ...) log lines on both generators); visual output is matched within the L2 frequency band.
Bug fixes along the way:
Cosine-lobe constants (1, 2/3, 1/4) instead of raw Ramamoorthi (π, 2π/3, π/4) so the SH output matches the convolution path's irradiance/π normalisation. Initial implementation produced ~π× too bright output.
Inlined SH evaluation directly off the UBO in IrradianceFromSH.glsl. The earlier version copied u_SHCoefficients[i].xyz into a local vec3 array and passed that to evaluateSH(); on driver the local- array copy collapsed channels and produced exact R=G=B output.
Bumped IBLCache version 2 → 4 to invalidate stale cache files written by the buggy intermediate versions.
New files:
OloEditor/assets/shaders/IrradianceFromSH.glsl
(none on the C++ side — additions live in existing files)
Changed:
OloEngine/src/OloEngine/Renderer/EnvironmentMap.{h,cpp}: SH branch in GenerateIrradianceMapWithConfig; CreateFromCubemap / CreateFromEquirectangular gain an IBLConfiguration overload.
OloEngine/src/OloEngine/Renderer/IBLPrecompute.{h,cpp}: new GenerateIrradianceMapFromSH and ProjectCubemapToSH; chrono-based elapsed-time logging on both irradiance generators.
OloEngine/src/OloEngine/Renderer/IBLCache.cpp: cache version bumped to 4 with comment chain explaining v2/v3/v4 invalidations.
OloEngine/src/OloEngine/Renderer/LightProbeBaker.h: ProjectToSH promoted from private to public so IBL can reuse it.
OloEngine/src/OloEngine/Renderer/Renderer3DLifecycle.cpp: registers the new shader (totalShaders3D 41 → 42).
OloEngine/src/OloEngine/Renderer/ShaderBindingLayout.h: adds SHCoefficientsUBO struct (9 vec4, 144 B) at UBO_SH_COEFFICIENTS = 35.
OloEngine/src/OloEngine/Scene/Components.h: m_UseSphericalHarmonics field + operator== entry.
OloEngine/src/OloEngine/Scene/Scene.cpp: threads IBLConfiguration through env-map lazy load.

SHProjectionTest.ChannelAsymmetryIsPreservedThroughProjectionAndScaling (regression test for the grayscale-collapse)
ComponentRoundTrip.EnvironmentMapComponentSurvivesYAMLRoundTrip extended to verify m_UseSphericalHarmonics survives YAML round-trip.

A follow-up that lets PBR shaders sample SH coefficients directly from a UBO (instead of via the rasterised cubemap) would convert the 98 KB irradiance cubemap into a 144 B UBO upload — that's deferred because it touches all 10 PBR shader variants.
