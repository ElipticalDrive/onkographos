Description
This pull request introduces the RayCaster project, a C-based implementation inspired by Wolfenstein 3D that uses raycasting principles to create a 3D graphical view inside a maze. The project leverages miniLibX for graphics rendering and GLFW for window management.
Project Highlights:
A realistic 3D maze with first-person navigation.
Map parsing from .cub files, allowing texture customization.
Smooth rendering of walls, floors, and ceilings with designated colors.
Intuitive keyboard navigation (W, A, S, D keys) and camera rotation with arrow keys.
Includes support for both Linux and macOS systems via make linux and make macos commands.
Implementation Details :
Raycasting Engine: Uses raycasting algorithms to render a 3D view based on 2D map data.
Graphics Library: The project includes miniLibX (as a submodule) and relies on GLFW for window and event management.
Map Configuration: The project reads .cub files, which define map structure, textures, and colors. An example .cub file is located in the maps directory.
Argument Parsing: The program requires a .cub file as a map argument. If the argument is missing or invalid, the program will return an error message.
Memory Management: Ensures all allocated memory is properly freed, with no leaks tolerated.
