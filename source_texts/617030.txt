Python Bindings for PolySoupToLevelSet and Shrink-Wrap Utility
Overview
This PR adds Python bindings for OpenVDB's polySoupToLevelSet tool and introduces a new shrink-wrap-python utility that provides a command-line interface for converting USD meshes to OpenVDB level sets with LOD pyramid generation.
Changes
1. Python Bindings (openvdb/openvdb/python/pyGrid.h)
Added three overloaded static methods to FloatGrid and DoubleGrid classes:
convertPolygonSoupToLevelSet() - Three Overloads
Overload 1: Voxel Size Range
```
grids = FloatGrid.convertPolygonSoupToLevelSet(
    minVoxelSize=0.1,
    maxVoxelSize=0.8,
    points=vertices,      # Nx3 numpy array
    triangles=tris,       # Mx3 numpy array (optional)
    quads=quads,          # Kx4 numpy array (optional)
    erode=8.0,
    thres=0.0,
    halfWidth=3.0
)
```
Overload 2: Dimension + Bounding Box
```
grids = FloatGrid.convertPolygonSoupToLevelSet(
    dim=256,
    bboxMin=(0, 0, 0),
    bboxMax=(100, 100, 100),
    points=vertices,
    triangles=tris,
    quads=quads,
    erode=8.0,
    thres=0.0,
    halfWidth=3.0
)
```
Overload 3: Min Voxel Size + Bounding Box
```
grids = FloatGrid.convertPolygonSoupToLevelSet(
    minVoxelSize=0.1,
    bboxMin=(0, 0, 0),
    bboxMax=(100, 100, 100),
    points=vertices,
    triangles=tris,
    quads=quads,
    erode=8.0,
    thres=0.0,
    halfWidth=3.0
)
```
Features
LOD Pyramid Generation: Returns a list of grids from finest to coarsest resolution
Flexible Input: Supports triangles, quads, or mixed topology
Shrink-Wrap Deformation: Uses ShrinkWrapLimit functor with configurable erode and thres parameters
Type Safety: Only available on floating-point grids (FloatGrid, DoubleGrid)
Implementation Details
Uses nanobind for efficient numpy array handling
Leverages nb::ndarray with shape and dtype constraints for type safety
Supports optional triangle/quad arrays (at least one must be provided)
Constructs math::BBox internally from min/max tuples
Returns Python list of grid pointers (automatically managed by nanobind)

3. Shrink-Wrap Python Utility (shrink-wrap-python/)
New command-line utility for USD to VDB conversion with simplified interface.
Directory Structure
```
shrink-wrap-python/
├── README.md          # Comprehensive documentation
├── shrink_wrap.py     # Main CLI script
└── usd_utils.py       # USD mesh reading utilities
```
Key Features
Simplified Command-Line Interface
The CLI automatically generates output filenames, eliminating redundancy:
```
# VDB output (creates input-out.vdb)
python shrink_wrap.py input.usd --voxel 0.1

# USD mesh output (creates input-out.usd)
python shrink_wrap.py input.usd --to-mesh --voxel 0.1
```
Output Naming Convention:
Default (VDB): <input_basename>-out.vdb
With --to-mesh: <input_basename>-out.usd
Multi-LOD: <input_basename>-out_lod0.usd, <input_basename>-out_lod1.usd, etc.
Output is created in the same directory as the input file.
Command-Line Arguments
Required:
input.usd: Input USD mesh file
Conversion Mode:
--to-mesh: Convert grids back to mesh (output as USD)
Level Set Parameters (one required):
--voxel FLOAT: Voxel size for finest level set
--dim INT: Grid dimension for finest level (alternative to voxel size)
--bbox-min X Y Z: Bounding box minimum (optional, auto-computed)
--bbox-max X Y Z: Bounding box maximum (optional, auto-computed)
--erode FLOAT: Maximum deformation allowed (default: 8.0)
--threshold FLOAT: Closing threshold (default: 0.0)
--half-width FLOAT: Narrow band half-width in voxels (default: 3.0)
Mesh Conversion Parameters:
--adaptivity FLOAT: Mesh simplification (0-1, default: 0.0)
--isovalue FLOAT: Isovalue for mesh extraction (default: 0.0)
Output Options:
--finest-only: Only write finest grid (skip LOD pyramid)
Implementation Highlights
shrink_wrap.py (~340 lines):
generate_output_filename(): Auto-generates output paths based on input and mode
read_mesh_from_usd(): Loads and triangulates USD meshes
polygon_soup_to_level_set(): Wrapper for Python bindings
levelset_to_mesh(): Converts level sets back to mesh
write_grids_to_vdb(): Writes LOD pyramid to VDB file
usd_utils.py (~270 lines):
USDInterface: Complete USD mesh reading/writing utilities
Handles world transforms, mesh merging, and triangulation
Supports mixed triangle/quad topology
N-gon fan triangulation
Usage Examples
Convert simple mesh to VDB:
```
python shrink_wrap.py sphere.usd --voxel 0.5
# Output: sphere-out.vdb
```
High-resolution conversion with custom parameters:
```
python shrink_wrap.py detailed_mesh.usd \
    --voxel 0.01 \
    --erode 5.0 \
    --half-width 5.0
# Output: detailed_mesh-out.vdb
```
Convert to simplified mesh:
```
python shrink_wrap.py input.usd \
    --to-mesh \
    --voxel 0.1 \
    --adaptivity 0.005
# Output: input-out.usd
```
Create multiple LOD meshes:
```
python shrink_wrap.py input.usd \
    --to-mesh \
    --voxel 0.1
# Output: input-out_lod0.usd, input-out_lod1.usd, ...
```

This commit adds Python bindings for OpenVDB's polySoupToLevelSet tool and
introduces a new shrink-wrap utility for converting USD meshes to OpenVDB
level sets with automatic LOD pyramid generation.

Python Bindings (pyGrid.h):
- Added convertPolygonSoupToLevelSet() with three overloads:
  1. minVoxelSize + maxVoxelSize
  2. dimension + bounding box
  3. minVoxelSize + bounding box
- Returns list of grids (LOD pyramid) from finest to coarsest
- Supports triangles, quads, or mixed topology
- Includes shrink-wrap deformation (erode, thres parameters)
- Only available on floating-point grids (FloatGrid, DoubleGrid)

Unit Tests (TestOpenVDB.py):
- Added testConvertPolygonSoupToLevelSet() covering all three overloads
- Tests LOD pyramid validation, background values, active voxel counts
- Verifies type safety (unavailable on BoolGrid, Vec3SGrid)
- 153 lines of comprehensive test coverage

Shrink-Wrap Utility (shrink-wrap-python/):
- New command-line tool for USD to VDB conversion
- Simplified CLI: auto-generates output filenames from input
  * Default: input.usd -> input-out.vdb
  * With --to-mesh: input.usd -> input-out.usd
  * Multi-LOD: input-out_lod0.usd, input-out_lod1.usd, etc.
- Supports multiple conversion modes (voxel size, dimension)
- Optional mesh reconstruction with adaptivity
- Comprehensive error handling and validation
- Full documentation in README.md (220+ lines)

Dependencies:
- numpy, usd-core (pip install usd-core)
- OpenVDB Python bindings

Files:
- Modified: pyGrid.h (+246), TestOpenVDB.py (+153)
- Added: shrink-wrap-python/ (README.md, shrink_wrap.py, usd_utils.py)
