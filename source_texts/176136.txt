Edited
the swirling texture actually requires you to sample the texture using spherical coordinates, or theta and phi-based coordinates. You can compute this from the normal (theta = atan2(x, z), phi is literally y)
once you managed to compute theta and phi, you can offset the theta value based on the phi value, like this:
theta = theta + phi * distortionAmount
and use the new theta to sample the texture.
i sampled the same texture 8 times with a weighted combination, each time with a slight offset to create this layered effect.
```
for(uint i = 1; i < 8; i++){
    //offset the sample point in the view direction

    head += viewDir;
    //conveniently, because the sphere is located at the origin, the normal is just the normalized position

fixed3 newNormal = normalize(head);
    //compute theta and phi from normal and map to 0-1 range

float theta = (atan2(head.x, head.z) + UNITY_PI) / UNITY_TWO_PI;
float phi = (newNormal.y + 1) * 0.5;
    //the lower the phi, the more offset i add to theta

float2 baseUV = float2(theta + _Time.r * 4 - (1 - phi) * 0.6, 0.5 * phi - _Time.g * 0.05);
fixed3 tex = tex2D(_Galaxy, baseUV, _Galaxy_TexelSize.x, _Galaxy_TexelSize.y);

texSum += tex * weight; 
weight *= 0.5f;
```
}
its probably not a good idea to use atan2 in a for loop, but i couldn't figure out better ideas than that. besides, one layer already look impressive enough.
as for the stars, they are actually particles.
