Pull request overview
This pull request represents a significant rewrite of the Quality renderer to implement physically-based path tracing with direct light sampling and multiple bounces for indirect illumination. The changes also refactor the volume sampling infrastructure to use exact voxel-based majorant grid computation and replace the callback-based DDA traversal with a cleaner stateful iterator pattern.
Changes:
Rewrote the Quality renderer with proper path tracing including Russian roulette, direct light sampling from volume scatter points, and multi-bounce indirect illumination
Refactored majorant grid computation to use exact per-cell min/max values from raw voxel data rather than approximate world-space sampling
Replaced callback-based DDA traversal (dda.h) with a stateful GridTraversal iterator for improved control flow
Simplified light sampling API to work from arbitrary 3D positions (vec3) rather than requiring a Hit object
Fixed ambient light contribution calculation and volume opacity scaling in the Interactive renderer
