This change refactors the DecorManager to offload the heavy lifting of decor placement and frustum culling to the GPU.
Previously, the CPU would loop over all chunks, perform frustum culling, and dispatch a compute shader for each visible chunk. Now, the CPU uploads all registered chunk data to an SSBO and issues a single dispatch for all chunks. The compute shader handles AABB-frustum culling and uses a versioning system to only regenerate decor when necessary (e.g., when a chunk is new or terrain has changed).
Rendering is now done using glMultiDrawElementsIndirect, which allows the GPU to control exactly how many instances are rendered per chunk without CPU intervention. The vertex shader was updated to 4.6 to support gl_BaseInstance, ensuring correct indexing into the instance SSBO.
This results in significantly reduced CPU overhead and better GPU utilization.
