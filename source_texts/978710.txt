Add 2D and 3D Morton/Z-order bit-interleaving kernels for compact spatial keys.
Acceptance criteria:
encode/decode round trips for supported unsigned coordinate widths
deterministic bit-interleaving with clearly documented range limits
2D and 3D variants
tests around zero, maximum supported coordinates, and randomized deterministic fixtures
no floating-point/world-coordinate policy in this kernel; consumers map coordinates separately
registry metadata and README documentation
Keep this as a pure integer spatial primitive that can later be consumed by grids, octrees, BVHs, and world-generation code.
