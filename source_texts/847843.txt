Pull request overview
This PR adds a new “cuda_bricks” storage backend to the spiral fitting pipeline, providing a bounded on-device LRU cache for exact uint8 voxel gathers (surf-SDT and Lasagna normals/grad-mag) to avoid dense GPU copies while keeping sampling semantics unchanged.
Changes:
Introduces CudaBrickVolume, a lazy fixed-size brick cache with LRU eviction for aligned uint8 Zarr channels, plus unit tests.
Extends SDT + Lasagna sampling/gather paths (sdt_losses.py, losses.py) to support the new cuda_bricks backend.
Wires backend selection and cache-budget knobs through volume preparation, fit configuration/validation, and the VC3D UI.

For cuda_bricks, this path assumes lasagna_volume['normal_channels'] are always valid ints and that the returned tensor is already on points_working_zyx.device. If normal_channels contains None (e.g., volume prepared with use_normals=False) this will crash inside CudaBrickVolume when it casts channels to int.
