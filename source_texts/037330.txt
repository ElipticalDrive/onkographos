This change massively extends the rendering engine with support for advanced
realistic graphics and scalable lighting architecture. Key enhancements include:
- Added simulated path tracing with physically-based reflections, supporting
  multiple light bounces and mirror reflections.
- Implemented support for unlimited dynamic light sources, each capable of
  producing multiple shadows per object using improved shadow mapping.
- Introduced clustered shading and lighting model for large scenes,
  removing previous limits for active lights and improving scalability.
- Added voxel-based lighting propagation, including volumetric voxelization
  with a CPU+GPU BVH acceleration structure for real-time global illumination.
- Integrated Godrays, light shafts, radial and exponential fog, and full
  volumetric lighting via voxel grids.
- Implemented vector-cascaded pre-trace light propagation for fast
  indirect lighting across large 3D levels.

These changes significantly improve visual fidelity and support for modern,
large-scale levels. There may be performance impacts depending on hardware.
BREAKING CHANGE: Requires modern GPU (OpenGL 3+) and may need new graphics settings.
