Motivation
Provide a self-contained MATLAB implementation of the Feldkamp-Davis-Kress (FDK) cone-beam CT reconstruction algorithm and clarify where the main entry point and docs live.
Make the code immediately usable by documenting required geo fields and giving a quick usage example.
Description
Added fdk_reconstruction.m which implements volume = fdk_reconstruction(proj, geo) and performs distance weighting, 1D u-direction filtering, and cone-beam backprojection with magnification correction and discrete angular integration.
Implemented filter_projection_u that applies a frequency-domain ramp filter with selectable filterType options (ram-lak, shepp-logan, cosine) and appropriate FFT/IFFT handling and scaling.
Implemented validate_geometry to enforce required geo fields and check projection size and angle count consistency and warn on suspicious geometry (DSD <= DSO).
Added README.md at the repository root that documents the main function location (fdk_reconstruction.m), quick usage (volume = fdk_reconstruction(proj, geo);), required/optional geo parameters, and a short description of the reconstruction steps.
Testing
Verified repository file layout with a file listing using pwd; find . -maxdepth 3 -type f and inspected the README with nl -ba README.md to confirm content and locations.
Performed static checks by reviewing the new MATLAB code for argument validation and shape consistency through the validate_geometry function.
No runtime numerical tests were executed because MATLAB/Octave is not available in the current environment, so algorithm execution was not validated here.

Use per-view beta spacing in angle integration
The reconstruction multiplies each slice by mean(diff(unwrap(geo.beta))), which assumes uniformly spaced projection angles, while validate_geometry only verifies the angle count. When geo.beta is non-uniform (for example due to gated scans or dropped views), this gives incorrect integration weights for individual projections and biases voxel intensities; either validate that spacing is uniform or apply per-view Δβ weights during accumulation.
