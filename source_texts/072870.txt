# MedVis — Medical Image Analysis Platform

**[Live Demo](https://funeconomist.github.io/MedicalImageProject/)**

A browser-based medical image viewer featuring multi-planar reconstruction (MPR), 3D volume rendering, threshold segmentation, and real-time voxel probing. Built with the same core technology stack as [3D Slicer](https://www.slicer.org/) — VTK and ITK — deployed entirely on the web.
