You already know the model faces -Y. Align silhouettes, sample the reference image color for each front-visible voxel, majority-vote per segment. That handles the visible side with photo-accurate colors and leaves the LLM to only reason about back/hidden segments. This is a classical approach and it's where paired image/voxel data genuinely shines — as a way to validate the projection, not as retrieval fodder.
If this works, couldn't we do the same with reference images for top, bottom, side, back?
