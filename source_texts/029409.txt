# EGGS: Explicitly Granular 3D Gaussian Splatting via Luma-Aware and Volume-Preserving Attribute Factorization

This is the official implementation of **EGGS**, a 3D Gaussian Splatting compression method.

## Setup

This code has been tested with Ubuntu 22.04, Python 3.11, PyTorch 2.5.1, and CUDA 12.1.

Clone the repository:

```bash
git clone --recursive https://github.com/Ingyu-Jeong/EGGS.git
cd EGGS
```

Set up a conda environment:

```bash
conda create -n eggs python=3.11 -y
conda activate eggs

# Install CUDA toolkit
conda install -c "nvidia/label/cuda-12.1.0" cuda-toolkit

# Install PyTorch
pip install torch==2.5.1 torchvision==0.20.1 torchaudio==2.5.1 --index-url https://download.pytorch.org/whl/cu121

# Install packages
pip install -r requirements.txt --no-build-isolation

# Install cuML
pip install "cudf-cu12==25.2.*" "cuml-cu12==25.2.*"

# Install tiny-cuda-nn
pip install git+https://github.com/NVlabs/tiny-cuda-nn/#subdirectory=bindings/torch --no-build-isolation
```

Build [TMC13](https://github.com/MPEGGroup/mpeg-pcc-tmc13):

```bash
git clone https://github.com/MPEGGroup/mpeg-pcc-tmc13.git
cd mpeg-pcc-tmc13
mkdir build
cd build
cmake ..
make
cd ../..
```

## Training

For full evaluation on [Mip-NeRF 360](https://jonbarron.info/mipnerf360/) and [T&T+DB COLMAP](https://repo-sam.inria.fr/fungraph/3d-gaussian-splatting/datasets/input/tandt_db.zip):

```bash
python full_eval.py -m360 /path/to/MipNeRF_360 -tat /path/to/TanksAndTemples -db /path/to/DeepBlending
```
