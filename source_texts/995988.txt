Implements deterministic 2D noise kernels for WPH-003 under Week 1 tracking #16. All kernels are pure Java, immutable and independent of Minecraft worldgen APIs. Callers can pass the same base seed to every kernel; sample order has no effect.
Kernels and API
PhaseNoise.sample(long seed, double x, double z) is the only sampling interface. Production code lives in dev.fangbm.worldphase.worldgen.noise.
Kernel / configuration
Algorithm
Conservative output range
GradientNoise(frequency)
Eight unit gradients on a hashed 2D lattice, quintic interpolation, 1/sqrt(2) scaling; coherent Smooth base
[-1, 1]
RidgedNoise(frequency, octaves)
1 - abs(base); 1–8 octaves with lacunarity 2, persistence 0.5, normalized positive weights
[0, 1]
WorleyNoise(frequency)
Euclidean F1, one deterministic feature point per cell
[0, sqrt(2)] in scaled cell units
DomainWarpNoise(baseFrequency, warpFrequency, strength)
Independent gradient X/Z displacements, one warp layer, then original-seed base sampling
[-1, 1]
Worley searches two neighboring rings, skipping cells whose bounding-box distance cannot improve the best candidate. The own-cell feature bounds the search by sqrt(2), so no cells beyond radius 2 can win. A regression fixture demonstrates why a fixed 3×3 search is insufficient for full-cell jitter. No feature table is stored.
Determinism and seed/hash scheme
Stateless SplitMix64 avalanche finalizer; intentional 64-bit overflow and unsigned shifts.
Cell hash: mix(seed XOR channel XOR mix(cellX XOR X_SALT) XOR rotateLeft(mix(cellZ XOR Z_SALT), 32)).
Stable explicit channels: GRADIENT, WORLEY_X, WORLEY_Z, WARP_X_1, WARP_Z_1. Warp channel seeds use mix(baseSeed XOR salt); the base keeps the original seed. No additive Phase seed offsets or mutable random streams.
Feature offsets use the upper 53 hash bits mapped to [0,1). Java 25 strict arithmetic and StrictMath.floor/sqrt keep numeric operations reproducible.
Finite scaled coordinates are supported within ±2^50, including each octave and warped base coordinate. Invalid configuration/unsupported coordinates throw IllegalArgumentException instead of silently saturating or returning NaN/Infinity.
The exact constants, input contract and range reasoning are documented in docs/NOISE_KERNELS.md.

Sources, licensing and design choices
The noise kernels are written for WorldPhase. Smooth uses the standard gradient-dot/quintic interpolation idea described by Ken Perlin's Improved Noise reference; its copyrighted 3D code and permutation table are not copied or bundled. The stateless integer finalizer is adapted from Sebastiano Vigna's SplitMix64 (2015), with its public-domain dedication / unrestricted permission and warranty notice retained in NoiseHash.java. No external noise library is added. WorldPhase's own code keeps the repository's current All Rights Reserved status.
Two deliberate choices relative to Technical Design v0.1: the example OpenSimplexNoise class is replaced by GradientNoise, which meets the requested coherent gradient/simplex-style contract; Ridge's exponent is fixed to sharpness=1, retaining only frequency and octave count as necessary parameters. This is normalized ridged octave noise, not a weighted multifractal feedback implementation. No compatibility hack is involved.
PhaseDefinition is unchanged. This PR adds no DensityFunction, dimensions, worldgen JSON, transfer, commands or tutorials. Validation proves the kernels, not generated terrain.
