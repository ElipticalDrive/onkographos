Summary
Implements a procedurally-rendered, torus-wrapped (seamlessly infinite-scrolling) world map. When you scroll past the right edge, you see the left side; past the bottom, the top — the world never ends, it loops seamlessly.
What Changed
Core: Perlin Noise Terrain Generation (src/core/Noise.zig — NEW)
Implements 2D Perlin noise with a seeded permutation table (Fisher-Yates shuffle from 64-bit seed)
Periodic tiling: noise at (period_x, y) equals noise at (0, y), guaranteeing seamless left↔right and top↔bottom edges
Fractal Brownian Motion (FBM) with configurable octaves for natural-looking terrain
Quintic fade curve for smooth interpolation
Core: Map Wrapping (src/core/Map.zig)
Replaced box-blur terrain generation with Perlin FBM noise that tiles at map.width × map.height
Added torus coordinate methods:
wrapX(x), wrapY(y) — wrap any integer coordinate into [0, width)/[0, height)
wrapPos(pos) — wrap a MapPos into valid range
getNeighborWrapped(pos, dir) — always returns a valid wrapped neighbor
getAllNeighborsWrapped(pos) — 6 wrapped neighbors
directionToWrapped(from, to) — direction-aware wrapping
getTileWrapped(x, y), heightAtWrapped(x, y) — renderer-friendly wrapped access
Terrain boundary detection (isTerrainBoundaryWrapped) uses wrapping so edges blend correctly
Water smoothing uses wrapped neighbors so edge water tiles are properly handled
All existing tests pass + new tests for wrapping and Perlin periodicity
Rendering: Seamless Torus Display (src/render/map_renderer.zig)
The MapRenderer.render() now draws the map at 4 offsets (0,0), (+mapW,0), (0,+mapH), (+mapW,+mapH) so wherever the camera is, the visible area is fully covered
Added u_offset uniform to the terrain vertex shader to shift each copy by the correct pixel offset
Height/shading calculations use heightAtWrapped/shadeAtWrapped so edge tiles reference correct neighbors across the seam
Terrain boundary detection uses isTerrainBoundaryWrapped for seamless transitions
Camera (src/render/Camera.zig)
Added wrap(map_w, map_h) method to wrap camera position within map bounds for infinite scrolling
Gameplay: Wrapping Support
Pathfinder.zig: Uses getAllNeighborsWrapped and directionToWrapped for torus pathfinding
RoadBuilder.zig: bestStep uses getNeighborWrapped, path steps use wrapPos
Game.buildRoad: Path validation uses wrapPos so roads can cross map edges
BuildingPlacer.zig: Mouse-to-tile uses wrapX/wrapY instead of clamping
app.zig: mouseToTile() wraps; wave rendering uses wrapped water checks; road rendering uses wrapped neighbors
Shader (src/render/Shader.zig)
Added uniform vec2 u_offset to the terrain vertex shader
Vertex position: vec2 pos = a_position + u_offset for multi-pass offset rendering
Map Size
Currently 64×64 as before, but all code uses map.width/map.height throughout — easy to change later.
Design Decisions
Perlin noise (not value noise) as requested — produces more natural terrain with directional features
Gameplay wraps as requested — roads, pathfinding, building placement all work across map edges
Seamless edges ensured by periodic Perlin noise — height at (0,y) smoothly connects to (width-1,y)
4-copy rendering approach: draw the full map VBO at 4 offsets, simplest to implement and GPU-culls offscreen copies automatically
Proof of work — screenshots
The game running under Xvfb + llvmpipe software OpenGL (no GPU), driven with xdotool (WASD scroll + mouse-wheel zoom) and captured with scrot. Each frame has a distinct pixel-content hash and ~500 distinct colors, confirming the Perlin-noise terrain renders and the camera scrolls in every direction. Because of the torus wrapping, scrolling past an edge reveals the opposite edge — land everywhere, no blue void.

fix(map): sample Perlin noise in fractional domain, not integer tile …
…
1dc2961
```
…coords

Classic Perlin noise is exactly 0 at integer grid points (the fractional
offset is (0,0), so all corner gradients dot to 0). generateTerrain was
calling fbm_perlin2d with raw integer tile coordinates (0,1,2,...,63),
so every tile got noise=0 -> after normalization the entire field
collapsed to a single value -> the whole map became water (height <=
water_threshold=3). This is why the torus screenshots showed only water.

Fix: divide tile coordinates by a feature_scale (4.0) before sampling,
and divide the tiling period by the same factor, so:
  - adjacent tiles land on different parts of the Perlin field (noise
    actually varies across the map), and
  - the noise still tiles seamlessly at the map edges (left<->right,
    top<->bottom) because the period scales with the sample coordinates.

After the fix the terrain distribution is healthy (seed 42, 64x64):
  Water 1.8%, Grass 82.7%, Tundra 15.1%, Snow 0.4%
instead of 100% water.

Add two debug tools (terrain-hist, noise-check) and refresh the torus
run screenshots, which now show actual land (grass/tundra/snow) with
seamless torus wrapping in all scroll directions.
```

Update — fixed the all-water map 🐛➡️🏔️
You were right — the previous screenshots showed only water. I found and fixed the bug.
Root cause
generateTerrain called fbm_perlin2d with raw integer tile coordinates (0, 1, 2, … 63). Classic Perlin noise is exactly 0 at integer grid points (the fractional offset is (0,0), so all four corner gradients dot to 0). So every tile got noise = 0 → after normalization the entire height field collapsed to a single value → the whole map fell into the height ≤ 3 water band. 100% water.
I confirmed this with a debug tool (zig build terrain-hist):
```
Before fix:  Water: 4096 (100.0%)   Grass: 0   Tundra: 0   Snow: 0
              Height histogram: h0: 4096 tiles   <- every tile height 0
```
Fix (src/core/Map.zig)
Sample the noise in a fractional domain: divide tile coordinates by a feature_scale (4.0) before sampling, and divide the tiling period by the same factor. Now:
adjacent tiles land on different parts of the Perlin field → noise actually varies across the map
the noise still tiles seamlessly at the map edges (period scales with the sample coordinates), so torus wrapping is preserved
```
After fix:   Water: 74 (1.8%)   Grass: 3388 (82.7%)   Tundra: 617 (15.1%)   Snow: 17 (0.4%)
             Height histogram: h0..h15 spread across all 16 levels
```
Corrected screenshots
Same Xvfb + llvmpipe headless run, same scroll sequence — but now the map is actual land (grass / tundra / snow) with seamless torus wrapping. Each frame has a distinct pixel hash and ~500 distinct colors (vs. ~21 before).
Note: filenames were renamed to bypass GitHub's raw-CDN cache, which was serving stale (water-only) blobs for paths that existed in the first commit.
