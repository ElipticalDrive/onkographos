What / why
This PR fixes two estimator bugs. Each one comes with a seeded, deterministic test, and I checked that each test fails on the old code.
Stratified pixel sampling was biased when spp is not a perfect square (src/sampling.ts).
stratifiedOffset used a floor(sqrt spp)² grid. Every sample beyond that count wrapped back onto the first cells.
The pixel value is the plain mean of all samples, so those cells counted twice. At spp = 5 the expected offset was (0.45, 0.45) instead of (0.5, 0.5).
All five gallery scenes use a non-square spp (220–320). At spp = 250 the expected vertical offset was 0.456.
Fix: extra samples are now drawn uniformly over the whole pixel. This still takes two RNG draws, so determinism is kept and renders at square spp are byte-identical to before.
Smooth Dielectric applied Schlick to the inside cosine when a ray leaves the glass (src/materials.ts).
Schlick is only accurate with the cosine on the optically thinner side.
At 40° inside n = 1.5, the glass reflected about 4% of rays. The exact Fresnel value is 0.245, and a ray entering along the refracted direction did reflect 0.245, so reciprocity was broken.
Fix: when leaving the medium (and there is no total internal reflection), reflectance now uses the transmitted cosine. Entering rays, RNG draw order and unit throughput are unchanged, so energy is still conserved.
I also updated the docs: the test count goes from 276 to 278 in README, CLAUDE.md and TDD, and CHANGELOG has an Unreleased entry.
Verification
New tests before the fix: stratified mean was 0.051 away from 0.5 (limit 0.01); Fresnel reciprocity gap was 0.20 (limit 0.02). Both pass after the fix.
npm run lint, npm run typecheck, npm run build and vitest run: 32 files, 278/278 pass.
Checked with no code changes: GGX conductor scatterPdf integrates to the measured acceptance rate and gives mean attenuation of about 1 (roughness 0.3/0.8/1, three incidence angles). Russian roulette divides throughput by p. A 48×36, 16 spp pass over every gallery scene produced no NaN or Inf samples.

Owner decisions
Gallery renders. The PNGs in renders/ were made before both fixes; glass and sub-pixel weighting now differ slightly. I did not regenerate them because npm run render:all takes minutes per scene.
Repository description still says "274 tests"; the docs now say 278. The description is a repository setting, so it is left for you.
Gamma. Output uses a pure 2.2 gamma rather than the piecewise sRGB curve. Texture decode uses the same 2.2, so the round trip is consistent, and the docs say "sRGB-ish". Left as is.
Self-intersection epsilon. T_MIN = 1e-4 is an absolute world-space value, fine at the gallery scales. Scenes modelled at millimetre scale would lose contact detail.
Non-finite samples. samplePixel drops a non-finite channel but still divides by spp, which darkens the pixel slightly. toneMap maps +Inf to black under reinhard/aces. I could not reach either through the renderer.
