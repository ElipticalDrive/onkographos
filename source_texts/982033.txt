Goal
The screen post effects look like the game's: ambient occlusion, volumetric light, depth of field, and the lens flare.
Gaps
No open spec describes the game's post-effect shaders, so OpenSky uses its own versions. Each differs from the game:
Ambient occlusion (bSAOEnable) darkens the whole lit colour. The game darkens only the ambient light, so a surface in full sun stays bright in its creases.
Volumetric light (bVolumetricLightingEnable) uses a fixed strength, reach, and scattering asymmetry. The game takes them from the weather's VOLI record. OpenSky already parses VOLI but does not use it.
Depth of field (bDoDepthOfField) blurs only past the focus distance. The image-space DNAM fields for the near blur, the sky blur, and the blur radius are not decoded, so the blur radius is a fixed 8 pixels at 1080 lines.
The lens flare (bLensFlare) draws OpenSky's own ghost pattern. The game's flare comes from the LENS record that the weather or the sun names.
Done when
Each effect is compared with the Windows reference game in the same scene and weather, and each item above either matches or is listed with the measured difference.
