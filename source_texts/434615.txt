Julia software and development tools
This is a list of Julia software and tools, including IDEs, notebook environments, package management tools, scientific and machine-learning libraries, debugging and performance tools, and related projects.
Integrated development environments and editors
[edit]
Visual Studio Code — supports Julia through the official Julia extension, which provides a full IDE experience including LSP, REPL integration, debugging, profiling, plotting, etc.[1][2] It can be combined with an Emacs keymap or Vim extension, or with vscode-neovim[3] for full embedded Neovim instance.
JetBrains — supports Julia through the Flexible Julia plugin for JetBrains IDEs[4]
Emacs — supports Julia through major modes and related packages, such as julia-mode, julia-repl, and Eglot configured for Julia's LanguageServer.jl[5]
Neovim — supports Julia development through plugins and language-server integration.[6]
Vim — supports Julia editing through syntax highlighting, plugins, and language-server integration.[7] Neovim generally offers a richer and more modern extensibility/integration environment.
Zed — has a JuliaEditorSupport extension providing language-server support, REPL/tasks, and a plot pane.
Sublime Text — supports Julia through syntax highlighting and Julia-related packages[8]
Atom — formerly supported for Julia development through Juno[9]
Juno — a Julia-focused IDE built on Atom[10][11]
JuliaPro (discontinued) — a former Julia distribution bundled with development tools[12][13]
Notebook environments
[edit]
Jupyter — web-based notebook environment with Julia support[14]
Pluto.jl — reactive notebook environment for Julia[15]
Google Colab — cloud notebook platform with Julia support[16]
Quarto — scientific and technical publishing system with Julia support[17]
Package management and build tools
[edit]
Pkg — built-in package manager for Julia[18]
JuliaHub — platform for package, project, and cloud-based Julia workflows[19][20]
PackageCompiler.jl — compiler tool for creating apps, libraries, and system images[21]
StaticCompiler.jl — compiler for producing small standalone binaries from a static subset of Julia[22]
PrecompileTools.jl — package precompilation tool[23]
Revise.jl — updates method definitions in a running Julia session[24]
Debugging and performance tools
[edit]
Debugger.jl — source-level debugger for Julia[25]
JuliaInterpreter.jl — interpreter used for debugging and code analysis[26]
Profile — built-in profiling tool[27][28]
BenchmarkTools.jl — benchmarking package for Julia[29]
JET.jl — static analysis and code analysis tool[30]
Cthulhu.jl — interactive tool for examining generated code and type inference[31]
Testing and documentation tools
[edit]
Test — built-in unit testing standard library[32]
Documenter.jl — documentation generator for Julia packages[33]
Literate.jl — tool for writing Julia code as literate programs[34][35]
Aqua.jl — package quality-assurance tool for Julia projects[36]
Scientific computing and mathematics
[edit]
JuMP — algebraic modeling language for mathematical optimization[37]
DifferentialEquations.jl — suite for differential equation solving[38]
Symbolics.jl — symbolic computing library[39]
ForwardDiff.jl — automatic differentiation package[40]
Optim.jl — mathematical optimization package[41]
Roots.jl — numerical root-finding package[42]
Data science and visualization
[edit]
DataFrames.jl — tabular data manipulation library[43]
CSV.jl — package for reading and writing comma-separated values[44]
Makie.jl — visualization library[45]
Plots.jl — plotting front end for Julia[46]
Gadfly.jl — plotting and data visualization package[47]
AlgebraOfGraphics.jl — grammar-of-graphics-style visualization library[48]
Machine learning and artificial intelligence
[edit]
Flux.jl — machine-learning library[49]
MLJ.jl — machine-learning framework[50]
Knet.jl — deep-learning framework[51]
Turing.jl — probabilistic programming library[52][53]
BetaML.jl — machine-learning toolkit[54]
Web and application development
[edit]
Genie.jl — web framework for Julia[55]
HTTP.jl — package for HTTP clients and servers[56]
Oxygen.jl — web framework for building APIs and web applications[57]
Dash.jl — Julia interface for Dash applications[58]
Interoperability tools
[edit]
PythonCall.jl — interoperability package for Python and Julia[59]
PyCall.jl — interface for calling Python from Julia[60] (older than the modern PythonCall.jl)
JuliaLibWrapping.jl — a tool for turning Julia packages into shared libraries with C and Python interfaces (or more "R and Matlab are likely to follow soon")[61] Builds on JuliaC.jl, to compile to small binaries.
RCall.jl — interface for calling R from Julia[62]
JavaCall.jl — interface for calling Java[63]
CxxWrap.jl — interoperability package for C++[64]
MATLAB.jl — interface for MATLAB[65]
