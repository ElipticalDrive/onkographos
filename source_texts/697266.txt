Contributor
Refines mobile support and rendering (WebGPU/WebGL) with a reduced UI, and overhauls the physics hot loop — f32 typed arrays, zero-allocation broad phase, fps-adaptive quality — targeting stable 60fps on any device.
Changes
Physics: allocation-free f32 hot loop
Particle state moved from object array to parallel Float32Array/Int32Array SoA fields; JIT sees monomorphic typed-array math instead of megamorphic property access.
Merges use swap-remove instead of filter() (eliminates O(n²) copies); pair keys are numeric (a * 65536 + b) instead of template strings; contactVis pooled; merge queue is a flat Int32Array.
Broad phase replaced Map/Set-based SpatialHash with a fixed-storage uniform grid (UniformGrid): Int32Array cell buckets + stamp-based dedup, no per-step allocation, no pair sorting — insertion order already yields deterministic Gauss-Seidel iteration.
Positions/velocities/forces computed in f32-friendly form; fixed-point (i32/i64) evaluation deferred — f32 typed arrays already unlock the JIT fast path without quantization risk to Hertz contact stability.
Adaptive 60fps governor
Frame-rate EMA drives a quality tier: subSteps 16 → 12 → 8 and position-correction iterations 3 → 2 → 1 when fps drops, recovering when headroom returns. Frame rate stays stable instead of fixed-cost physics stalling slow devices.
Rendering tiers: WebGPU → WebGL1 → Canvas2D
New renderer-webgl.ts: instanced sprite quads from a pre-baked texture atlas (reuses the cached particle sprites) + instanced additive glow quads for force chains/effects. Covers Safari/iOS, which lacks WebGPU.
WebGPU: per-level colors precomputed once as f32 (no per-frame hex parsing); drop preview folded into the main instanced pass; force chains and effects render as additive-blend glow quads in the same render pass as particles — Canvas2D overlay now draws text/walls only.
UI: reduced, not added
Removed the compact-help strip and the in-canvas status line; touch devices (pointer: coarse) get a 2-button toolbar (Model/Chain) since tap/drag/swipe already covers movement and drops.
BGM mute (footer, hover-reveal)
Bottom-right mute button appears on hover; state persists via cookie:
```
function writeMuteCookie(muted: boolean) {
  const expires = new Date(Date.now() + 365 * 864e5).toUTCString();
  document.cookie = `bgm_muted=${muted ? 1 : 0}; expires=${expires}; path=/; SameSite=Lax`;
}
```
README: checked per request — already minimal (2 lines), nothing to trim.
Version 3.6.0; service worker cache bumped to v5.
