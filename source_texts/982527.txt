Adds a Unity MonoBehaviour that generates reproducible, geologically-plausible mountain terrain via a configurable multi-stage pipeline.
Generation pipeline
Fractal Voronoi — Multi-octave F1 Voronoi noise (voronoiScale, octaves, persistence, lacunarity). Inverted so ridges form at cell boundaries.
Hydraulic erosion — Rain → steepest-descent flow → capacity-based erode/deposit → evaporate. Carves valleys and alluvial fans.
Thermal erosion — Proportional slope-excess redistribution to neighbouring cells. Smooths ridges into natural talus fields.
Post-processing — Optional [0,1] normalisation and configurable box-smoothing passes.
Key design points
public int seed drives System.Random; identical seeds produce identical terrain.
All erosion and noise parameters are [SerializeField]-exposed for Inspector tuning — including flowFraction (fraction of water/sediment moved per step) rather than a hardcoded constant.
ApplyToTerrain() writes directly to Unity's TerrainData.SetHeights.
ExportHeightmap() returns a safe float[,] deep copy for external use.
Usage
```
// Attach ProceduralMountainGenerator to a GameObject with a Terrain component.
var gen = GetComponent<ProceduralMountainGenerator>();
gen.seed = 42;
gen.GenerateTerrain();

// Access raw data for mesh or texture generation:
float[,] heights = gen.ExportHeightmap();
```
Terrain is also regenerated automatically on Start() when a targetTerrain is assigned.

Overview
Implement a procedural mountain generation system for Unity using C# that combines:
Fractal Voronoi patterns for base terrain generation
Hydraulic erosion simulation to create realistic water flow patterns and valleys
Thermal erosion simulation to create realistic slope degradation and talus deposits
Seed system to allow reproducible and varied terrain generation layouts
Requirements
Create a ProceduralMountainGenerator class that:
Generates heightmaps using fractal Voronoi patterns
Applies hydraulic erosion to simulate water erosion
Applies thermal erosion to simulate slope-based material movement
Supports configurable seed for reproducible terrain generation
Key features to implement:
Customizable terrain resolution/size
Adjustable Voronoi fractal parameters (scale, octaves, persistence, lacunarity)
Hydraulic erosion parameters (iterations, rain amount, sediment capacity)
Thermal erosion parameters (iterations, talus angle, sediment amount)
Real-time seed modification to regenerate terrain with different layouts
Height normalization and smoothing options
Integration points:
Should work with Unity's built-in terrain or mesh generation systems
Provide method to export heightmap data
Include performance optimization considerations
Documentation:
Include inline code comments explaining the algorithms
Provide usage examples in a demo script or comments
Document all public parameters and their effects
Acceptance Criteria
Procedural mountain generation produces visually realistic terrain
Hydraulic and thermal erosion create realistic geological features
Seed system allows reproducible terrain generation
Code is optimized for reasonable performance (should generate terrain in reasonable time)
All public methods and parameters are documented
