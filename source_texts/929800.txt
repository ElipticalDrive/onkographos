Adds ARMv6-M support (Cortex-M0/M0+, RP2040) through an optional portable-atomic feature
These targets don't support atomic CAS, so AtomicPtr::compare_exchange isn't available
The new feature uses portable-atomic with critical-section support. Also replaces the deprecated compare_and_swap calls with compare_exchange
The public API remains unchanged
