Context (ADR-0060)
Vivid already has a full modern PBR pipeline — but not where the metaballs are. Render3D (meshes) runs Cook-Torrance GGX + Smith + Schlick Fresnel from the shared PBR_BRDF_WGSL preamble (gpu_3d.h:529) and split-sum IBL. SDF3D (raymarched metaballs, where #355's triplanar maps live) reimplemented Blinn-Phong with a flat ambient and reached none of it.
ADR-0060 decides every surface shades through one PBR model, finishing the unification ADR-0051 began (which unified the light uniform but left the BRDF divergent).
Phase 1 — GGX + Fresnel on the SDF path
sdf3d.cpp now concatenates PBR_BRDF_WGSL (the same preamble Render3D's textured path adds).
Its Blinn-Phong block is replaced by the identical Cook-Torrance eval: spec = D_GGX·G_Smith·F_Schlick / (4·NdotV·NdotL), F0 = mix(0.04, base, metallic), energy-conserving kD = (1-F)(1-metallic) diffuse — byte-identical to render_3d.cpp:638-654.
PI is defined only in PBR_BRDF_WGSL, so no redefinition; saturate was already in scope. WGSL-internal — no operator ABI change.
Result
The triplanar roughness/metallic maps now shade the way they do in Unity/Unreal/TouchDesigner/glTF — tight GGX highlights, grazing Fresnel — instead of a broad Blinn-Phong wash. The blob's tight beauty shot reads as wet liquid metal.
Scope
Phase 1 only. Phases 2–3 (IBL / environment reflections on the SDF path) are proposed in the ADR, not in this PR. Existing SDF looks shift (GGX ≠ Blinn-Phong lobe); demos tuned to the old lobe may want a light re-tune.
Verification
Full ctest: 100/100, 0 failures.
A minimal Image → SDF3D sphere: broad wash → tight GGX highlight. Blob tight shot: flat colour wash → reflective liquid metal.
Best reviewed alongside #356 (the host fix that makes triplanar textures apply at all).
