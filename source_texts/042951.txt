Implementar a base voxel sem usar um Mesh por bloco.
Implementado
BlockRegistry;
Chunk 16x16 com altura fixa inicial;
armazenamento compacto em Uint16Array;
ChunkManager;
visible-face culling entre chunks;
greedy meshing;
Web Worker pool;
dirty chunk rebuild;
invalidação de chunk vizinho em edição de borda;
DDA voxel raycast;
mineração/quebra de blocos;
colocação de blocos;
hotbar;
texture atlas original;
collider trimesh agregado por chunk;
testes de negative coordinates, raycast, border dirty e greedy meshing;
build Vite compatível com Vercel.
Arquitetura
```
VoxelWorld
 -> Chunk/Uint16Array
 -> padded snapshot
 -> MeshWorkerPool
 -> GreedyMesher
 -> Three BufferGeometry
 -> Rapier trimesh collider
```
Vercel
Mantida como restrição permanente:
Workers via new URL(..., import.meta.url);
gameplay client-side;
output estático dist/;
nenhum servidor Node obrigatório.
Aceite
Jogador quebra e coloca blocos em 3D; chunks são remeshados fora da main thread e o renderer usa geometrias agregadas.
Validação
testes unitários;
TypeScript;
Vite production build;
smoke test visual/manual no navegador.
