Replace references to non-existent linearClampSampler with manual
trilinear interpolation using Load() operations in both
AccumulateInscatter.hlsl and AccumulateGIInscatter.hlsl.

The RTXStub signature only defines pointSampler, so implementing
manual trilinear sampling ensures proper smooth interpolation for
temporal accumulation without depending on unavailable samplers.

Changes:
- Add sampleInscatterTrilinear() function using 8-point Load sampling
- Add sampleGITrilinear() function for GI accumulation
- Replace SampleLevel calls with new trilinear functions
