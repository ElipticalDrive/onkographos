Motivation
Provide a minimal but working MVP desktop app to convert LiDAR-scanned point clouds (.ply) into editable 2D floor templates for 1:1 printing and Illustrator editing.
Prioritize a reliable end-to-end flow for .ply import → floor detection → 2D projection → outline generation → PDF/SVG export while exposing parameters and minimal 2D editing for manual fixes.
Keep heavy processing off the UI thread and include pragmatic fallbacks and user-visible TODOs for unsupported formats (OBJ/STL/GLB are marked as unsupported in the MVP).
Description
Added a complete scaffold floor-template-app/ with dependency list (requirements.txt) and a README.md containing run and PyInstaller instructions and MVP notes.
Implemented the processing pipeline: voxel downsampling in pipeline/preprocess.py, RANSAC floor detection (up to 3 planes) in pipeline/floor_detect.py, floor point extraction and 3D→2D projection in pipeline/project_to_2d.py, alpha-shape based outline generation and simplification in pipeline/outline.py, and offsetting via pipeline/offset.py.
Built a PySide6 GUI in app/ui/ with main_window.py wiring import/detect/generate/export actions and a 2D editor view2d.py that supports grid toggle, vertex dragging, and hole creation (circle/rect/polygon), plus dialogs in dialogs.py and project save/load in io/project_store.py.
Implemented vector exports: PDF generation with reportlab in export/export_pdf.py and SVG generation with svgwrite in export/export_svg.py, both include a 100mm guide, origin mark, and notes (file, timestamp, scale, parameters); unit conversions use app/utils/units.py and geometric helpers are in app/utils/geom.py.
UX details: PLY is the supported import path (io/importer.py) with informative warning for mesh files, scale calibration via two-point click and ask_distance_mm, GPU/3D view uses Open3D separate window, and heavy tasks run in a Worker executed on QThread to avoid UI freeze.
Export operations apply offsets transiently (apply/restore) so the in-memory edited outline is preserved after writing the output.
Testing
Automated tests: none were executed as part of this change (no test suite included), so no automated pass/fail results are available.
Manual/runtime checks: repository includes README.md with venv/pip install and python -m app.main instructions for manual verification and a PyInstaller example command for building a single executable.
