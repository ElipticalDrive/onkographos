Summary
Adds rendering for 3D Gaussian Splatting PLY files, with no new dependencies.
Detection/parsing (src/splat.js, src/ply.js): binary or ASCII PLYs with f_dc_*, opacity, scale_*, rot_* are treated as splats. Color = 0.5 + SH_C0 · f_dc, opacity = sigmoid, scale = exp, rotation normalized.
GPU data: center, 3D covariance (already mapped to the viewer's Z-up, radius-normalized space), and RGBA packed into an RGBA32UI texture (48 B/splat).
Rendering (src/viewer.js): instanced quads, per-splat EWA projection in the vertex shader (perspective and ISO), premultiplied alpha blending with depth test against the grid/bbox but no depth writes.
Sorting (src/splat-sort-worker.js): 16-bit counting sort back-to-front, re-run in a worker only when the view direction changes.
UI: "Gaussian splats" toggle and "Splat scale" slider; Type shows "Gaussian splat"; points are off by default for splat files; point-normal controls hidden (3DGS normals are zero).
Sample: test-data/sample-splat.ply (5,240 splats, 1.3 MB) generated deterministically by scripts/generate-splat-sample.mjs.
The PLY header fix (binary data starting with a newline byte) originally in this branch shipped separately in Release v0.5.3: fix binary PLY data skipped after end_header #20 (v0.5.3); main was merged in here.
Version bumped to 0.6.0.
Known limitations: SH degree 0 only (no view-dependent color); compressed splat formats not supported; far-away floaters enlarge the bounding box so the scene may start small.
Closes #17

as depth-sorted anisotropic Gaussian splats in WebGL2:

- Decode SH DC color, sigmoid opacity, exp scale, and normalized rotation
- Pack center, covariance, and color into an RGBA32UI texture
