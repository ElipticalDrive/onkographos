Scope
Research-only GT0 implementation based on the October 19 ground-truth investigation. This PR does not target main or modify PR #285. No GTA launches, RPH native calls, live asset confirmation, mod installation, shooting, or destructive mechanics.
Included
Offline deterministic source-aware intersection index for triangle and oriented box primitives with row-vector placement transforms, overlap detection, activation/coverage qualifiers and NO live-confirmation claims.
Import of existing PRIVATE CodeWalker candidate pool: reconstruct box geometry; intentionally do not invent triangle vertices.
Strict private catalog JSON Schema + independent source/screenshot/session/material/thickness confirmation-gate validator.
Planned read-only native filter matrix for E0.2's suspected transparency category exclusion; original trace (17,7) preserved and new tests remain NOT_RUN.
Optional Durty/CodeWalker spawnable model-hash candidate discovery; not dependent on Menyoo or external editors.
Deny-by-default aggregate-only public export and synthetic unittest + CI.
Evidence preserved
Existing E0 GTA results remain 28/30 material matches; wall 3/4 disagreement; 8/10 within 1 cm; inside-solid 0/10. No existing E0 evidence or experiment code modified.
Non-goals / blockers
No complete YBN/YMAP/YTYP+DLC graph importer yet; existing CodeWalker exports omit triangle vertices and installed mod precedence. Current index only analyzes explicitly supplied PRIVATE primitives and announces coverage gaps. Real identity requires GT1 private source collection and GT2/GT3 interactive GTA verification. Keep draft until offline tests and privacy acceptance are reviewed.
