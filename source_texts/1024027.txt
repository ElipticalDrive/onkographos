SUMMARY
A quick and efficient method is required for conversion of data from contour form into matrix nodal values.
A
new computer program, described in this paper, was developed
which uses a PDP-9 digital computer and a graphic digitizer.
Through use of this program a contour map may quickly be converted to matrix form with virtually no errors.
This work was performed by the Water and Land Resources
Department of Battelle-Northwest for application to the
Radionucludes in Soils Program sponsored by the Atlantic
Richfield Hanford Company.

INTRODUCTION
The Radionuclides in Soils Program being conducted by
Battelle-Northwest for the Atlantic Richfield Hanford Company
has as its major objective the development of a groundwater
management system for the Hanford Reservation.
The primary
segments of this management system are mathematical models
which can predict transient groundwater and contaminant
movement
.
These models require various types of input information,
much of which can be represented by a surface, i.e., groundwater potential contour maps.
In applications this data must
be efficiently converted from maps and charts to a form which
can be input to computer programs by techniques such as a
three-dimensional equation or a two-dimensional array containing surface elevations.
Complex surfaces are usually difficult to describe by a
three-dimensional equation and even if such an equation can
be developed the computer calculations required during use
can be lengthy.
The second method (a two-dimensional array)
is sufficient to describe most surfaces and computer application is normally easier than for the three-dimensional equation.
This report describes a new interpolation scheme
to accomplish efficient computer input of data with a graphic
digitizer utilizing the two-dimensional array method.
