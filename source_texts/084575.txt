Summary
Generate CPU-rendered thumbnails for 3D Gaussian splats in the 3D Preview Thumbnail pipeline, and accept the common splat file formats. No GPU is required.
Motivation
Today a 3D Gaussian Splatting .ply (including the Gaussian Splat Toolbox pipeline's output) is routed to the mesh handler as a plain point cloud. Its colours are not read (they live in spherical-harmonic f_dc_* properties), near-transparent "floater" splats are drawn opaque, and the thumbnail is an unrecognisable blob. .spz, .sog, .splat, .ksplat and .lcc are not accepted at all, although the VAMS splat viewers open them.
Scope
Routing by content. Sniff the PLY header: a vertex element with f_dc_0, opacity, scale_* and rot_* goes to a new splat_handler; a vertex-only PLY goes to the point-cloud handler (with its point budget); a PLY with faces stays with the mesh handler.
Formats. .ply (3DGS), .compressed.ply, .spz, .sog, .splat, .ksplat, .lcc. Non-PLY formats are converted to a 3DGS PLY inside the container with the PlayCanvas splat-transform CLI (MIT licence), pinned to an exact version and installed from a lockfile. Conversion runs on CPU; only splat-transform's own image rendering needs a GPU, and it is not used.
CPU rendering. Colour from the degree-0 spherical-harmonic term (0.5 + 0.28209479 × f_dc), opacity from sigmoid(opacity), splats below an opacity threshold dropped, per-splat size from exp(max(scale)), drawn with VTK's point-Gaussian mapper. Sample to a splat budget, weighted by opacity, for large scenes.
Framing. Opacity-weighted 2nd–98th percentile bounds so stray splats do not shrink the subject; an elevated exterior view for room-scale environment captures.
Orientation. Check against Gaussian Splat Toolbox output; captures exported in the original 3DGS convention are Y-down and need flipping.
Registration. Add the extensions to the pipeline's inputFileFilters, the CDK allowedInputFileExtensions list, the pipeline README and documentation page, and add the splat-transform and Node.js runtime licence entries to NOTICE.md and the documentation notices page.
Out of scope
Anisotropic (EWA) splat rasterisation, view-dependent colour (spherical-harmonic bands above degree 0), and any GPU rendering path.
Acceptance
A splat produced by the Gaussian Splat Toolbox, and one sample of each listed format, render a recognisable, correctly coloured, correctly oriented subject with a transparent background on every frame.
