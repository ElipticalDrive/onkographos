"Traditional" raycasting (like Wolf3D) and voxels, how?
The paper A Fast Voxel Traversal Algorithm for Ray Tracing is a good starting point - it's a fast variant of the DDA algorithm. Basically start with your voxel data in a 3D array and then you can use this algorithm to traverse and find 'full' voxels. You can probably find some example code online if you search.
