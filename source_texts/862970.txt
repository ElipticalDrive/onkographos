What changed in this PR
Adds a new batched stable sort mode that runs entirely within a single SYCL work-group (radix “single group”), and refactors shared radix-sort building blocks to be reused across kernels.
Changes:
Introduces radix_single_group_tag and dispatch path to a new one-work-group batched radix sort kernel.
Refactors onesweep kernel code by extracting shared utilities (load, bin extraction, sub-group ranking, SLM scatter).
Adds/extends tests and CMake generation for the new single-group configuration and updates feature macros.

Batched stable sort: radix_single_group_tag with a one work-group kernel
…
1150daa
```
radix_single_group_tag sorts segments which fit in one work-group tile with
a one work-group radix sort kernel, which packs several segments per
work-group at sub-group granularity and needs no temporary global memory.
It accepts any work-group size that is a multiple of the sub-group size, up
to 1024. The sub-group ranking of the onesweep kernel is extracted so that
both kernels share it.
```
