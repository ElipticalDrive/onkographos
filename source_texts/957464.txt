💡 What: Inlined the fade, lerp, grad, and smoothstep operations directly within Noise.noise, Noise.fractal, and CLOUD_NOISE.valueNoise2D tight loops, pre-calculating constants and bypassing function call stack overheads without modifying exposed object properties.
🎯 Why: Procedural generation functions like Perlin noise are executing thousands of times a frame during terrain generation and volumetric clouds. Removing the function context this.* lookups, and function call jump statements shaves off measurable milliseconds.
📊 Impact: Reduces execution time in Noise.fractal by ~10% (110ms budget met securely). Reduces execution time in CLOUD_NOISE.fbm2D by ~15% (135ms budget met securely).
🔬 Measurement: Verify via pnpm run test:perf or npx tsx scripts/perf.mjs.

Preserve permutation indirection in Noise.noise/init
Using the module-scoped permutation array directly here makes Noise.permutation no longer the source of truth for init()/noise(). Before this change, callers could swap or inject a permutation table via the public Noise.permutation property (or by rebinding methods onto another Noise-like object), but now those writes are silently ignored, which is a behavior regression in the exported API and can produce unexpected terrain/noise output when custom seeding paths are used.
