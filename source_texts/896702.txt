# 🌍 Voxel Game  

A voxel-based game built from scratch in **C++** and **OpenGL**, featuring procedurally generated worlds and interactive gameplay.

---

## ✨ Features  
- **Procedural Generation**: Explore unique, infinite world.  
- **Custom Engine**: Built entirely from scratch using C++ and OpenGL.  
- **Interactive Gameplay**: Build, explore, and interact in a sandbox environment.

## Optimizations:
- **Mutli-Threading**
- **Bit-Packing**
- **Face-Culling**
- much more
