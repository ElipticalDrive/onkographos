A learned chess mesh can agree with sparse LiDAR returns while extending into background in the reference image. This adds lidar-video refine-silhouettes to remove that unsupported completion and write a new, complete candidate manifest for the existing audit workflow.
The operation voxelizes the watertight prior at 1 mm and carves only known background in the declared reference mask. Other instances and out-of-frame regions remain unknown. Capture, calibration, reference selection, observations, expected inventory, pose scale and acceptance thresholds are preserved. Generated candidates are never automatically accepted; all original views and square bounds still pass through the unchanged importer.
Measured development result
f8 passes the existing depth, silhouette and square-bound checks. Other-view IoU is 0.544262, above the unchanged 0.500 threshold; median surface distance is 4.285 mm and p90 is 16.607 mm.
b8 remains rejected, with failing-view IoU 0.433846. The complete two-object scene is still blocked. This PR does not claim a finished reconstruction or fresh independent agent approval.
Carving removes unsupported shape; it cannot recover missing geometry. Fresh b8 generation from another recorded reference is a separate pending experiment. A100 connection attempts failed before inference could start.
Validation
161 tests passed, including actual voxelization, occlusion/unknown-region preservation, memory bounds and input immutability.
Integration coverage changes every non-reference mask and depth: candidate mesh bytes remain identical, while the downstream importer rejects the changed evidence.
Ruff and git diff --check pass.
scikit-image emits NumPy 2.5 deprecation warnings in marching cubes; no test failures.
Only source, tests and documentation are included. Private captures, masks, generated meshes and local audit evidence are excluded. These repeatedly inspected views are development evidence; a separate evaluation recording is required for an independent accuracy claim.
