Summary
Normalize series names and volume titles across the application to ensure consistent display, storage, and matching behavior.
Problem
Series names and volume titles can be stored or displayed inconsistently, which can lead to duplicate-looking entries, mismatched search results, and an uneven UI experience.
Scope
Define normalization rules for series names
Define normalization rules for volume titles
Apply normalization consistently where titles are entered, updated, displayed, or compared
Review existing logic that may depend on raw values
Acceptance Criteria
Series names are normalized using a documented and consistent rule set
Volume titles are normalized using a documented and consistent rule set
Creating or editing affected records applies the same normalization behavior
Displayed values remain predictable and do not create duplicate-looking variants
Existing matching/search behavior is verified against normalized values
Notes
Because this repository appears to be an ASP.NET/C# web app, this likely affects model validation, persistence/update flows, and UI rendering for manga series and volume entities.
