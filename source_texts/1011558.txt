Before you start
I wrote this request in English.
I searched the open and closed issues and nobody has asked for this yet.
What is it about?
Graphics, weather and effects
What problem does this solve?
Ray tracing is currently used for lighting only, and shadows still look unrealistic, which stands out next to the ray-traced lighting. Indirect lighting is also limited, so scenes like bus interiors, etc. don’t get realistic light bounce or soft shadow falloff.
What would you like to see?
I’d like to propose adding path tracing as an optional alternative to the current ray tracing mode.
Since the ray tracing infrastructure already exists, it could be extended to support path tracing, which would give physically accurate soft shadows, contact shadows and indirect lighting.
This could be a separate, opt-in setting offering the best possible visual quality, intended for users with capable hardware.
How does OMSI 2 do it?
No response
Alternatives considered
A smaller step would be ray-traced shadows using the existing ray tracing code. That would fix the most visible issue, but wouldn’t cover indirect lighting. I’d be happy to see soft shadows as a first phase, with full path tracing as the long-term goal.
