# 3x3matrix-calculator-python
A menu driven python program that performs various operations on a  3x3 matrix

##Features
-Addition
-Subtracion (A-B and B-A)
-Multiplication (AXB AND BXA)
-Scalar multiplication
-Matrix Transpose 
-Determinant 
-Inverse

##Concepts used:
-User defined functions
-nested lists
-nested loops
-mathematical algorithms

##How to run:
-Download the file 
-Run it using python 3
Follow the onscreen menu
