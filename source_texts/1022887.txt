Feature
Build a brick occupancy bitmask each frame so the render ray march can skip empty regions.
Current problem
Each pixel ray-marches up to 256 steps through the voxel grid.
Sky pixels (hitting nothing) are the most expensive — full 256 steps for nothing.
Implementation
1. Brick occupancy pass
After voxelize: new compute pass iterates voxels, marks which 8³ bricks are occupied.
Output: u32[323232/32] bitmask or bool[32768] array.
32³ bricks for 256³ grid with BRICK_SIZE=8.
2. Ray march with brick skipping
```
while t < max_t:
    brick = pos / BRICK_SIZE
    if !brick_occupied[brick]:
        // Skip entire brick
        t += distance_to_next_brick_boundary
        continue
    // Normal per-voxel DDA march within brick
    ...
```
Expected speedup
Sky pixels: 256 steps → ~32 brick checks → ~10x faster
Surface pixels: modest improvement (still need per-voxel march near surfaces)
Overall: 3-5x render improvement
