Replace sort-based TopK with packed-counter radix select for all k values.
Key optimizations:
Packed-counter ranking (zero atomic contention) with subgroup-shuffle prefix sum
Vectorized initial loads (aligned_vector<scalar_t, 4>) reducing memory transactions 4x
Heap-select path for K≤16 with large dimensions (single-pass scan + single-tile radix)
Multi-tile radix merge for arbitrarily large dimensions
Adaptive GROUP_SIZE matching problem size (64-1024)
Benchmarked on Intel Arc Pro B60: peak 6.43x speedup, avg 1.74x across 132 configs.
Authored with Claude.
