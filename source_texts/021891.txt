yt has a basic GUI for interactive volume rendering. It hasn't really take off, partially because it depends on a GUI/OpenGL stack that is nontrivial to install and isn't packaged on conda-forge. For a while we maintained a custom channel and buildbots to build packages but that proved unsustainable, so right now the packaging story is pretty much broken :/
We should explore, either in the context of glue-vispy-viewers or in a new plugin, integrating the shaders from the yt IDV system into glue. That could happen via vispy's OpenGL context or via a lower-level mechanism in QT.
One cool aspect of yt's interactive volume renderer is that it natively supports AMR data.
http://yt-project.org/doc/visualizing/interactive_data_visualization.html
