This PR implements "RGB Voxel Coloring (Iter 8)," a major feature that enriches depth-sample observations with camera pixel colors and visualizes the resulting 3D occupancy grid using instanced cubes. The changes span AR math (Bresenham line tracing, inverse unprojection), depth sampling (RGB lookup acquisition), a complete occupancy-grid port with carving semantics, recorder state (new rgb option, defaults), WebXR integration (blit-based RGB capture), visualization (Three.js instances), and extensive test coverage including property tests validating mathematical invariants.

In Three.js, THREE.InstancedMesh does not have a .dispose() method. Calling this.mesh.dispose() will throw a TypeError at runtime and crash the application during teardown. To release the GPU resources of the instanced attributes, you should dispose its instanceMatrix and instanceColor attributes directly.
Suggested change
this.arSpaceNode.remove(this.mesh);
this.mesh.instanceMatrix.dispose();
this.mesh.instanceColor?.dispose();
