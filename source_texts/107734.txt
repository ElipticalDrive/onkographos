Summary
Issue #36 asks whether top vision LLMs (GPT-5, Gemini, etc.) can generate a voxel structure resembling an input picture directly, instead of the image → 3D (Trellis/SAM3D) → voxelization pipeline — and if so, to compare the two and algorithmically fill gaps.
This adds an experiment harness built on the pipeline's existing xyzrgb format and conventions (Z-up grid, httpx-based LLM calls as in llmRender.py):
backend/src/utils/llm_voxel_generation.py — pure, testable utilities:
build_voxel_generation_messages — chat-completions prompt asking a vision LLM for a solid, connected, grounded voxel model as {"voxels": [[x,y,z,r,g,b], ...]}
parse_llm_voxel_output — tolerant parser (JSON object/array, {x,y,z,r,g,b} objects, plain xyzrgb lines, code fences); drops out-of-grid voxels, dedupes, enforces limits
fill_gaps — closes enclosed cavities and one-voxel surface holes (binary closing + fill_holes), coloring new voxels from nearest neighbors; never alters original voxels
compare_voxel_models / describe_voxels — normalizes both models into a shared cube (so a 32-grid LLM output can be scored against higher-resolution pipeline output) and reports occupancy IoU
Fixes See if top LLMs can generate a voxel structure resembling picture #36
