Owner
Adds GPU programming to Dream through ordinary functions marked as compute, render, or ray-tracing shaders. A Dream generator compiles them ahead of time with pinned Slang and emits typed wrappers and shader bundles; applications load recorded layouts without loading the Slang compiler.
Included
system.gpu: buffers, textures, bindless handles, render/compute/ray-tracing pipelines, acceleration structures, ray queries, autodiff, cooperative types, and generated argument validation.
system.window: native GLFW and browser windows, input, frame loops, and GPU surfaces.
Native slang-rhi host and browser WebGPU host, with presentation, resize, resource lifetime, and device-loss handling.
Generator framework, source-mapped diagnostics, shader layout recording/replay, deterministic bundle checks, and the float16 primitive.
Windows fixes for D3D12 resource bindings and swapchain lifetime, CUDA context and parameter binding, and strict AOT DLL detection. Cross-platform fixture regeneration preserves targets unavailable on the build host.
Integer-to-string formatting writes two UTF-16 digits per division and handles signed minima with unsigned magnitude. Native and Node assertions cover boundaries and round trips.
Validation
Windows RTX 4080: Vulkan and D3D12 execute full ray-tracing pipelines, ray queries, and bindless sampling. Vulkan also executes cooperative matrices/vectors and autodiff. CUDA compute passes. Native Vulkan, D3D12, and WebGPU pass compute, rendering, real-window presentation, resize, and device-loss checks.
Apple M3: compute, rendering, autodiff, half buffers, and backend selection on Metal, MoltenVK, and Dawn; ray queries and cooperative matrices on Metal.
Real browser WebGPU passes in Windows Chromium/Edge and Linux lavapipe CI, including compute/readback, rendered pixels, canvas presentation, resize, and device destruction.
Local Windows workspace build, strict clippy, workspace tests, full native and Node corpus, shader golden/determinism tests, freestanding runtime checks, and documentation gates pass.
Linux benchmark rerun passes the gate: string concatenation is about 37% faster than the exact PR base; substring spans, list push, and all macro rows pass. Regex remains a performance follow-up: both attempts measured roughly 11% slower, with the rerun confidence interval crossing the 10% budget and producing an inconclusive decision. Its captured kernel IR is unchanged apart from descriptor numbering; this does not prove performance parity. Final platform CI status is shown by the checks.
Remaining limits
Metal full ray-tracing pipelines and browser ray tracing are unavailable. D3D11 device creation is blocked by the pinned host's missing fences. CUDA/D3D12 cooperative vectors need optional upstream integrations. Ray payloads, hit attributes, and recursion remain limited to 128 bytes, 32 bytes, and depth 1. A recurring hardware GPU CI runner and several shader-language extensions remain follow-ups.
Implementation details and remaining work: docs/internals/18-gpu-shader-bundle.md, 19-gpu-host.md, and 20-slang-gpu-remaining-work.md.
