pkg178 Stage 4 PR-1 — thin-film Fresnel utility + CPU dielectric
First PR of the thin-film/thin-wall block. Adds the shared Belcour-Barla 2017 Airy-reflectance utility (thin_film_fresnel.h, host+device-ready) and integrates it into the CPU dielectric specular + transmission Fresnel (both faces, backface film-IOR adjust). Per-λ spectral uses the analytic phasor (no LUT); RGB uses a Rec.709-baked CIE sensitivity LUT (thin_film_cie_table.h + mechanical generator). Energy compensation left film-free (mirrors Cycles — no double-count). New params thin_film_thickness (nm) + thin_film_ior, default thickness 0 = off.
Verbatim port (cited in-code): Cycles bsdf_util.h fresnel_iridescence_channel/iridescence_airy_summation_channel/fresnel_dielectric_polarized (BSD-3), bsdf_microfacet.h adjust_thin_film_ior_at_backface + thin-film branch; Belcour & Barla, TOG 36(4):65.
Verified (CPU)
thickness-0 bit-equality: EXACT (maxAbsDiff 0.000e+00 vs a fresh pre-change build) — true no-op when off.
Analytic-phase check (standalone): 6/6 configs match the closed-form single-film Airy (Δ ~1e-6); furnace bound R∈[0,1]; TIR.
Furnace (linear) 7/7; chi² 33 passed, 1 xfailed (film-ON specular chi² passes → sampler/pdf unchanged); 46 regression tests green; GPU/CPU parity green (thickness=0 keeps GPU untouched).
vs Blender 5.2 Cycles (lead spot-check): at 500 nm/ior 2.0 both engines shift toward green (Cycles chroma [0.221,0.398,0.381], Astroray [0.299,0.371,0.330]) — hue direction confirmed (rules out OPD/IOR inversion). Pixel-matched exact hue-trajectory sweep is the block-level gate at the GPU stage (PR-3).
Sampler/pdf deliberately byte-unchanged (film scales eval only — correct one-sample-MIS; chi² confirms). GPU twin = PR-3; conductor = PR-2 (utility entry already present); thin wall = PR-4; addon sockets = PR-5.
