Description
This PR implements a NeRF (Neural Radiance Fields) 3D Volumetric Inspection Engine under backend/ml/nerf/nerf_inspector.py to detect cargo container structural damage from 2D multi-view smartphone photos.
Features
3D voxel density point cloud synthesis from multi-angle image features
Container wall dent depth and volumetric damage calculation (in cc)
Structural damage severity classifier (Minor/Moderate/Severe)
Automated unit test suite under backend/ml/nerf/test_nerf.py
