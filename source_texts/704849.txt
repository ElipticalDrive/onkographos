Summary
Adds the Mitchell-Netravali (B, C) bicubic resampler to :kanvas-skia and routes it through SkSamplingOptions.cubic, SkBitmapShader, and SkBitmapDevice.drawImageRect.
New public API : SkCubicResampler(B, C) with Mitchell / CatmullRom presets + SkSamplingOptions(SkCubicResampler) convenience ctor. When cubic is non-null it takes precedence over filter / mipmap, matching upstream's useCubic branch.
New canary GM BicubicGM ports gm/bicubic.cpp (3 drawImage rows + 2 shader-fill rows over a 7×7 line image) ; similarity vs original-888/bicubic.png is 88.5 % at tolerance 8.
Implementation notes
SkCubicBC.weight(t, B, C) evaluates the piecewise cubic kernel for t ∈ [0, 2), returns 0 beyond 2. Verified by SkCubicResamplerTest against the closed-form scalar weights and the 4-tap partition-of-unity property.
The shader path samples a 4×4 neighbourhood, weighted by k(dx)·k(dy), normalised by the sum of weights ; channels are clamped to [0, 1] (or [0, 255] on the 8-bit path) to absorb the kernel's negative-lobe overshoot. Per-axis tile mode is honoured uniformly across the 4×4 grid.
The device path uses the same kernel but clamps the 4 source-x / 4 source-y indices to the image bounds (kClamp equivalent — matches drawImageRect's existing nearest/linear semantics).
Nearest / linear paths are unchanged ; existing image-sampling GMs (TinyBitmapGM, Bug6783GM, BitmapRectRoundingGM, etc.) all keep their pre-existing similarity scores.
