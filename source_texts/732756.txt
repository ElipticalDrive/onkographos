User-facing 3D output — reuse established Gaussian .splat donor
This is a focused functional follow-on to the WRE V2L18.3 main-integration PR #322 (base SHA 655aba9ae1eea886132f3287b40eb50708bbcdae, not default main). No second 3D solver, CUDA kernel, framework, workflow or training machinery is added. The existing PR #322 already exposes a glTF RGB centers-only export; this PR additionally exports the actual Gaussian 3D scene attributes (XYZ, exp(log-scale), color, opacity, quaternion) into the established antimatter15/splat 32-byte-per-Gaussian .splat format, usable by existing Gaussian viewers.
Reuse rather than reinvent: Copy the targeted tested CPU exporter export_verified_gsplat_splat and its tests from prior experiment PR #265, immutable source fb73a59107814a3477ed05a487a33d2378c548ff, into this canonical stacked integration branch. The previous experimental #265 is not independently integrated or merged; any eventual merge must avoid duplicate export definitions. Three allowlisted paths only: src/wre/reconstruction/static_appearance_baseline.py, src/wre/reconstruction/__init__.py, tests/test_static_appearance_baseline.py.
The function first calls existing materialize_verified_gsplat_ply on a real on-disk PLY (59 float32 fields), reads its verified bytes in bounded batches, applies the established SH0 RGB conversion, float32 scale exponentiation, sigmoid opacity and normalized quaternion, outputs 32-byte little-endian records in stream, verifies source SHA-256 against audited materialization, hashes destination and refuses overwrite/partial files. Does not modify original PLY. The two reused tests decode generated bytes independently, validate RGB/scales/quaternion/opacity/hash/no-overwrite and reject corrupted PLY/zero quaternion/extreme scales without partial output.
Evidence boundaries: CPU-only tests use synthetic but byte-real two-record PLY. They do not train gsplat, render a frame, prove photorealism, use CUDA, or show a product viewer. Full native co-import test is in separate PR #341; real 16-photo COLMAP→Gaussian-initialization/WebGL experiment is in #340, without GPU training, and its gallery PR #342. None of those other workstreams should be modified or claimed passed by this PR. GitHub Dependency Graph HTTP404/#226 remains a separate official vulnerability review blocker. Parent PR #322 is still DRAFT; do NOT merge out of order.
Acceptance: exact-HEAD GitHub fast-ci pytest/Ruff/Pyright and applicable builds, verified destination bytes and hashes, one independent read-only L2 for this functional lot once stabilized (not per formatting SHA), and honest CPU/GPU separation.
