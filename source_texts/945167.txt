Issue description
When Triplanar is enabled in a StandardMaterial3D that uses streamed textures, only the lowest allowed LOD is loaded.
Steps to reproduce
Open MRP (Inactivity Decay Rate is set to 100ms to speed up the bug showcase)
Open node_3d.tscn
Focus on the MeshInstance3D and zoom in to see the bug better
Optionally increase Max LOD in the Textures menu for a more dramatic effect
Select polyhaven_brick_pavement_03/brick_pavement_03.tres
Enable UV1/Triplanar
Move the mouse around a bit to redraw the editor
Texture quality will decrease to the lowest possible
Disable UV1/Triplanar
Texture quality will get back to normal

You need to use STREAMING_UV built in for texture streaming to work correctly with triplanar materials
@tdaven This is a bit of an issue for usability. Users can turn any texture into a streamed texture. But they can also enable triplanar in the StandardMaterial3D, which means they won't have direct access to the STREAMING_UV builtin.
Maybe we should just write some rough proxy uv to STREAMING_UV no matter what?
