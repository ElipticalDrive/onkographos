💡 What:
Refactored the SDF computation in the solid voxelization loop (MeshProcessor::voxelize) to lazily evaluate self.mesh.distance_to_local_point. For exterior voxels (where is_inside is false) without a narrow_band, the keep flag will invariably be false. We can skip the expensive distance query for these points.
🎯 Why:
Calling distance_to_local_point performs an expensive BVH query. Evaluating it unconditionally for every point in the bounding box grid, especially for sparse meshes where a vast majority of the volume is empty exterior space, drastically wastes CPU cycles. Skipping this for voxels we know we're going to throw away saves substantial computational time.
📊 Impact:
Significantly reduces solid voxelization time (measured on the order of 10s-30s+ on dense meshes in empty grid space). Empty exterior cells are now evaluated with essentially just the $O(\log N)$ binary search from the scanline raycast optimization, rather than a full distance query.
🔬 Measurement:
Run the test suite cargo test test_sdf_invariants to verify no functionality changes occurred and that standard outputs are maintained. Voxelize a large mesh without --narrow-band and compare the Voxelization complete in X.XXs times to prior runs.

In `MeshProcessor::voxelize` (solid voxelization), `self.mesh.distance_to_local_point` is an expensive BVH distance query. Previously, it was evaluated unconditionally for every voxel cell.
This patch delays the evaluation so that it only runs when necessary: either when `narrow_band` is provided (where the distance decides if the voxel is kept) or when `is_inside` is true. For exterior voxels without a narrow band, we immediately assign `keep = false` and skip the distance query entirely, significantly speeding up voxelization of empty space around meshes.

Preserve zero-distance boundary voxels in solid mode
In the non-surface_only path with narrow_band == None, this branch now treats every !is_inside point as discardable without evaluating distance. That changes prior behavior (sdf <= 0.0) for points exactly on the surface: if scanline parity classifies a boundary point as outside (common at ray hits on edges/vertices), distance_to_local_point can be 0 and the voxel used to be kept, but is now dropped. This can remove boundary voxels (and thin features) for grid-aligned meshes, so the optimization introduces a geometric regression rather than a pure performance change.
