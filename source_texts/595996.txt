The rendering pipeline has no custom anti-aliasing implemented yet.
Symptom: SDF-rendered geometry shows pixel-stepping along silhouettes that flips frame-to-frame as objects move or the camera turns. Surface patterns (checker floors, fractal banding) show moire at glancing angles or at distance. Reproducible in every example that uses an SDF raymarch path.
Root cause: every SDF raymarch node in rye-render writes one fragment shader sample per pixel with no coverage estimation. Standard wgpu MSAA doesn't help SDF raymarchers. MSAA varies depth-buffer coverage per fragment but the fragment shader (which IS the geometry for a raymarcher) runs once per pixel and casts one ray. All MSAA samples in a fragment get the same shaded color, so silhouettes alias the same as without it.
Two-axis problem:
Silhouettes alias because the marcher returns binary hit/miss with no sub-pixel coverage.
Surface/pattern shading aliases because there's no filtered sampling of procedural textures or supersampling of the shading.
Proposed fixes (engine-level, any one independently useful):
Distance-based silhouette AA, applied uniformly in the kernel layer (~30 LOC per kernel, or a shared WGSL helper in the prelude). At the final hit, compute pixel world-radius from depth + fov + resolution, then coverage = smoothstep(-pixel_r, +pixel_r, sdf). Blend hit color against background by coverage. Cheap, no extra texture, fixes silhouettes only. Best landed as a rye-render::raymarch::aa WGSL snippet so every kernel composes the same logic.
Engine-wide supersampling pass (4x fragment cost + offscreen 2x texture + bilinear resolve). Lift "render to a 2x texture, resolve to surface" into a RenderDevice helper or a Supersampled wrapper node so any raymarch node can opt in. Catches silhouettes, surface shimmer, and pattern moiré.
FXAA post-process pass (~80 LOC + one fullscreen pass). Lands as a standalone rye-render::postfx::FxaaNode (matches the existing postfx feature flag). Cheaper than 2; less accurate than 1 at silhouettes but also helps surface aliasing. Composable with any node that writes the surface.
