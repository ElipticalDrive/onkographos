Real-time time-division color electroholography using a single GPU and ...
Real-time time-division color electroholography for a 3D object consisting of around 1000 points per color when an NVIDIA GeForce GTX TITAN was used as the GPU and the proposed method was effective for various GPUs. We propose real-time time-division color electroholography using a single graphics processing unit (GPU) and a simple synchronization system
