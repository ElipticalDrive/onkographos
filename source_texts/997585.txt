Background
This PR is extracted from my local forge branch.
The forge branch is my personal working branch of pygfx and contains several relatively aggressive and experimental changes. It is primarily used to explore rendering features and architectural directions that may not yet be ready for direct upstream integration.
Originally, I planned to add HDR rendering and tone mapping support after completing #1165 ColorSpace Management, since a unified color space pipeline would be the ideal foundation for these features. However, #1165 is still under development and may take some time to finalize.
That said, even without #1165, it is still feasible to introduce HDR rendering and tone mapping in a meaningful and self-contained way. Doing so already brings a noticeable improvement to the final visual quality and lays practical groundwork for future color space management work.
Overview
This PR introduces High Dynamic Range (HDR) rendering support and a flexible tone mapping system to pygfx, enabling more realistic lighting, improved highlight handling, and better overall color reproduction.
Changes
Core HDR Rendering
HDR Renderer Option
Added an hdr=True parameter to WgpuRenderer to explicitly enable HDR rendering mode.
HDR Color Format
When HDR is enabled, the blender uses the rgba16float texture format for color targets instead of the default format, allowing a significantly wider dynamic range for color values.
Blender Enhancement
Updated the Blender class to support HDR rendering via a new enable_hdr parameter.
Tone Mapping Effect Pass
New ToneMappingPass Class
Introduces a post-processing effect pass that converts HDR color values into displayable LDR (Low Dynamic Range) output.
Multiple Tone Mapping Operators:
Supports 6 different tone mapping modes:
linear — Simple exposure with clamping
neutral — Khronos PBR Neutral Tone Mapper (default, Use Khronos' specification)
reinhard — Classic Reinhard operator
cineon — Filmic operator (by Jim Hejl and Richard Burgess-Dawson)
aces_filmic — ACES filmic tone mapping
agx — AgX tone mapping
Configurable Exposure:
Added exposure control to adjust brightness before tone mapping
HDR Requirement Check:
Introduced a REQUIRES_HDR flag and corresponding validation to ensure tone mapping passes are only used with HDR-enabled renderers.
Minor Fixes
Color Class: Removed unnecessary alpha clamping in _set_from_rgba method to allow HDR values.
