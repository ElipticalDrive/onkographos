Summary
Adds three framebuffer-sampling rendering primitives to GPUI for backdrop blur, liquid-glass refraction, and mirrored frame slices.
Primitive::BlurRect — dual-Kawase blur of the current framebuffer, clipped to a rounded rectangle. Supports uniform or linear-gradient blur strength.
Primitive::LensGroup — refraction + chromatic aberration + Fresnel edge highlight over the union of 1..=8 rounded rectangles, merged with a per-fragment smooth-min of their SDFs (the GPU equivalent of SwiftUI's GlassEffectContainer(spacing:)).
Primitive::MirrorRect — a source region of the framebuffer composited at a destination with an optional flip, rounded-rect clip, and backdrop blur (SwiftUI backgroundExtensionEffect() analogue).
Wired through the scene, window, and both Metal and WGPU backends; DirectX renders a flat tinted-quad fallback instead of a hole.
Public API
```
Window::paint_blur_rect(bounds, corner_radii, BlurEffect {
    radius, radius_end, gradient_direction, kernel_levels, tint,
});

Window::paint_lens_rect(bounds, corner_radii, LensEffect {
    radius, radius_end, gradient_direction, kernel_levels,
    refraction, depth, dispersion, splay,
    light_angle, light_intensity, tint,
});

Window::paint_lens_rect_union(
    shapes,               // 1..=MAX_LENS_SHAPES_PER_GROUP (=8) LensShapeSpecs
    edge_blend_distance,  // smooth-min radius merging shape SDFs
    LensEffect { .. },
);

Window::paint_mirror_rect(source, destination, corner_radii, MirrorEffect {
    axis, clip_to_destination, blur, tint,
});
```
Builders for HIG defaults: BlurEffect::{new, linear_gradient, with_gradient_direction}, LensEffect::{new, linear_gradient, with_gradient_direction}, MirrorEffect::{new, with_blur}, LensShapeSpec::{new, with_content_mask}. BlurAxis::{Horizontal, Vertical} picks a normalized gradient direction; MirrorAxis::{None, Horizontal, Vertical, Both} maps flip bits.
kernel_levels is clamped to 1..=5 and selects the Kawase pyramid depth per frame.
radius scales the per-pass offset relative to a 20 px reference; radius_end + gradient_direction turn a uniform blur into a per-pixel interpolation between the un-blurred snapshot and the max-blurred pyramid output. The gradient is a mix(unblurred, max-blurred, t) approximation — visually plausible for HIG scroll-edge fades, not a true per-pixel Gaussian.
light_angle is a Radians newtype; paint_lens_rect* debug_asserts the scalar inputs are finite.
On Metal, MetalRenderer::new takes an enable_frame_sampling: bool (flipped to true at the GPUI window callsite). When false, the three sampling primitives warn_once and silently skip — same pattern as the wgpu path when a surface lacks COPY_SRC.
How the snapshot pipeline works
Each blur/lens/mirror batch needs the current framebuffer as input. The renderers:
Compute Scene::max_blur_kernel_levels() and Scene::max_blur_radius() once per frame.
On the first sampling batch of the frame, break the current render pass and build a BLUR_CHAIN_LEVELS-deep Kawase pyramid in place: level 0 is a copy of the drawable; each subsequent mip is a downsample pass rendered directly into that mip through a per-mip view / set_level. The separate chain textures plus the upsample pass the original design used are gone — the fragment shaders sample the pyramid directly.
Cache the pyramid. Subsequent sampling batches in the same frame reuse it. Any non-sampling primitive batch invalidates the cache.
fs_blur_rect / fs_lens_rect / fs_mirror_rect sample the cached pyramid (the lens fragment loops over up to 8 shapes with an exponential smooth-min). The lens shader short-circuits three texture samples to one when dispersion == 0, skips the Fresnel path when light_intensity == 0, and returns zero for pixels outside the anti-aliased corner SDF. The mirror shader flips UVs per MirrorAxis and routes through the same rounded-corner clip.

Review history
Two deep-review rounds over the branch. The first flagged 27 findings (3 P1 correctness bugs, 12 P2 perf/test/consistency issues, 11 P3 cleanups, 1 P4 nit); the second covered the multi-shape / gradient-blur / mirror additions plus the in-place pyramid rewrite. Headline fixes:
P1 — queue.write_buffer race on blur_params_buffer causing both passes to read the second-written value. Now a single write with dynamic offsets.
P1 — BlurEffect::kernel_levels and BlurEffect::radius were dead fields — never read by any shader. Now drive the Kawase pyramid depth and offset multiplier respectively.
P1 — Per-batch snapshot collapsed to one per frame via a dirty flag on both renderers.
P2 — Kawase pyramid now rendered in place via per-mip views / set_level. Eliminates the frame → chain[0] copy plus N chain[i] → pyramid mip i blits per snapshot and halves scratch VRAM; the upsample pass + intermediate chain textures are gone (dead code — fragment shaders only sample the pyramid).
P2 — set_framebuffer_only(false) no longer unconditional on Metal; gated by enable_frame_sampling (defaulted to true at the window callsite).
P2 — sRGB surface formats no longer double-correct gamma in the Kawase chain (chain textures use format.remove_srgb_suffix()).
P2 — Lens fragment shaders short-circuit texture sampling and Fresnel math when inputs make them no-ops; corner_avg / edge_band moved to vertex shader.
P2 — MSL discard_fragment swapped for return float4(0) on lens early-exits; refracted_uv clamped to [0,1]; safe_dir = weighted_dir / max(len, 1e-4) in the Fresnel select; gradient_direction normalized inside gradient_target_radius.
P2 — DirectX stubs upgraded from no-op to a tinted-quad fallback so the three unimplemented primitives render a flat tint rather than leave a hole.
P3 — Primitive::LensRect(LensPrimitive) renamed to Primitive::LensGroup; LensRect::shape_offset / shape_count document the caller-value-overwrite contract; BlurRect / MirrorRect with zero radius filtered from max_blur_kernel_levels.
Deferred as a follow-up: union-AABB scissor on snapshot passes. Non-trivial cross-shader UV work; marginal benefit now that the single-frame dirty-flag cache already collapses N snapshots to one.

```
Implements two new GPUI scene primitives for per-element backdrop
compositing:

- `Primitive::BlurRect` — dual-Kawase (Marius Bjorge, SIGGRAPH 2015)
  backdrop blur with configurable kernel levels, corner radii, and tint.
- `Primitive::LensRect` — Liquid Glass composite: backdrop blur plus
  parabolic UV refraction, chromatic aberration, and directional Fresnel
  edge glow.

Both primitives are wired through the full rendering pipeline on every
backend:

- **WGPU** (`gpui_wgpu`): framebuffer snapshot via `copy_texture_to_texture`,
  separate `blur_io_shaders.wgsl` module with sRGB-correct downsample/
  upsample, plus `fs_blur_rect` / `fs_lens_rect` compositing entry points.
- **Metal** (`gpui_macos`): `MTLBlitCommandEncoder::copy_from_texture` for
  the snapshot, MSL port of both shader modules, cbindgen-generated input
  index enums.
- **DirectX** (`gpui_windows`): exhaustive-match stub returning `Ok(())`.

Public API additions on `Window`:
- `paint_blur_rect(bounds, corner_radii, BlurEffect)`
- `paint_lens_rect(bounds, corner_radii, LensEffect)`

Each call forces a render-pass break so the framebuffer can be sampled,
then re-opens the pass with `LoadOp::Load` for subsequent primitives.

Tests: WGPU pipeline-creation smoke test, Scene round-trip test for both
primitive types.
```

```
fs_lens_rect / lens_rect_fragment always issued three textureSamples,
```

gpui_macos: Gate MetalLayer framebuffer_only opt-out behind a flag
…
613f555
```
Calling `set_framebuffer_only(false)` unconditionally disables on-chip
tile-memory optimizations for the drawable for the lifetime of the
layer. The overwhelming majority of Zed frames contain no blur / lens
primitive, so every shipping build was paying a presentation-cost
regression for a feature that may never be used in the session.

Plumb a new `enable_frame_sampling` flag through `new_renderer` /
`MetalRenderer::new` / `new_internal`. Only flip
`layer.set_framebuffer_only(false)` when the flag is true, or when
`cfg(any(test, feature = "test-support"))` is active (so visual-test
screenshots keep working). When disabled, `BlurRects` / `LensRects`
batches silently skip rendering — the same failure mode as the wgpu
path when a surface doesn't advertise COPY_SRC.

The existing `gpui_macos` call site in `window.rs` passes `false`
today; any caller that actually paints `BlurRects` / `LensRects` must
pass `true`.
```

gpui_wgpu: Wire kernel_levels + radius; fix blur_params write race
…
ca4a017
```
The BlurRect/LensRect chain was using two scratch textures (full + half)
and hardcoded offset_multiplier=1.0, so `BlurEffect::kernel_levels` and
`BlurEffect::radius` had no effect on the rendered output. It also ran
two `queue.write_buffer` calls into offset 0 of a single-slot
`blur_params_buffer` before submit, so both passes actually read the
second write — the downsample pass sampled with half-resolution params
instead of full-resolution ones.

Restructure the snapshot pipeline:

- Replace the snapshot/half pair with a `BLUR_CHAIN_LEVELS`-deep mip
  chain of `wgpu::Texture`s on `WgpuResources`. Level 0 is surface-sized
  and receives the framebuffer snapshot; each subsequent level is half.
- Fold `ensure_blur_textures` into `ensure_intermediate_textures` so
  one allocation site owns both the path intermediate textures and the
  blur chain.
- Allocate chain textures with `format.remove_srgb_suffix()`. When the
  surface happens to be an sRGB variant (possible on adapters that only
  expose sRGB BGRA/RGBA), this avoids double-correcting gamma — the
  hardware no longer transfers sRGB on sample and the manual pow() in
  `blur_io_shaders.wgsl` runs against raw bytes.
- Pre-build a down/up bind group per chain transition in
  `create_blur_io_bind_group`, keyed on the source view. The previous
  code recreated two bind groups every `snapshot_and_blur_frame` call.
- Grow `blur_params_buffer` to `BLUR_PARAMS_SLOT_COUNT` slots aligned to
  `min_uniform_buffer_offset_alignment`. Switch the bind-group layout
  to `has_dynamic_offset: true` and write all per-pass params in one
  `queue.write_buffer` call. Each `set_bind_group` now passes the slot
  offset so the write-race is eliminated by construction.
- Change `snapshot_and_blur_frame` to loop down N then up N steps,
  where N is `kernel_levels.clamp(1, BLUR_CHAIN_LEVELS - 1)`.
- Add `Scene::max_blur_kernel_levels` and `Scene::max_blur_radius`
  helpers; the main draw loop samples these once per frame and maps
  radius to `offset_multiplier = radius / BLUR_REFERENCE_RADIUS_PX`
  (reference = 20px, current default).

This also resolves the `let _ = half_tex` unused-binding cleanup that
was previously called out separately — the destructure is gone.
```

gpui: Cache blur snapshot across batches within a frame
…
ace5e9e
```
Every BlurRects/LensRects batch unconditionally ran
snapshot_and_blur_frame — full-surface framebuffer copy plus two
Kawase passes per blur-chain level. With N blur primitives interleaved
with other primitives at different z-orders, the scene iterator emits
N batches and the renderer paid that cost N times.

Add a local `blur_snapshot_valid: bool` in the draw loop on both
renderers. It's false at frame start and whenever a non-blur primitive
batch writes to the main target. On a blur / lens batch, reuse the
```

tahoe-gpui follow-ups blocked on this fork
Implementing tahoe-gpui Phase 2 (GlassEffectContainer / morphing) and a couple of Phase 3 items needs three further extensions on top of the primitives this PR introduces. Filing them here so the surface stays in one PR's discussion thread per the project's GPUI-fork routing rule.
1. Multi-shape LensRect + edge_blend_distance — unblocks Phase 2 in full
Apple's GlassEffectContainer(spacing:) merges every glassEffect inside it into a single shared lens with edges that blend when shapes fall within spacing of each other (cf. SwiftUI GlassEffectContainer). Without this on the fork side, every tahoe-gpui glass surface paints in isolation — adjacent pill buttons can't merge into Safari's toolbar capsule.
Proposed shape change:
```
pub struct LensRect {
    pub shapes: SmallVec<[LensShape; 2]>,
    pub edge_blend_distance: Pixels,
    pub effect: LensEffect,
}

pub struct LensShape {
    pub bounds: Bounds<Pixels>,
    pub corners: Corners<Pixels>,
}

impl Window {
    pub fn paint_lens_rect_union(
        &mut self,
        shapes: impl IntoIterator<Item = LensShape>,
        edge_blend_distance: Pixels,
        effect: LensEffect,
    );
}
```
The fragment shader composites the SDF union of every LensShape, smoothed over edge_blend_distance, into a single framebuffer sample — i.e. one render-pass break per container, not one per shape. The single-shape paint_lens_rect stays as a thin wrapper over the multi-shape path.
This unblocks the entire tahoe-gpui Phase 2 stack: GlassEffectContainer, GlassNamespace, glassEffectID, glassEffectUnion, and GlassEffectTransition::matchedGeometry all hang off it.
2. Variable-radius paint_blur_rect — unblocks HIG scroll-edge "Hard" effect
paint_blur_rect today takes a single scalar radius. HIG §scroll-edge-effects describes a blur strength that fades across the edge band — soft and hard both want a per-row blur strength, not a gradient over alpha. tahoe-gpui currently approximates with a linear-color-stop gradient and leaves a // TODO: variable-radius blur primitive at crates/tahoe-gpui/src/foundations/materials.rs:1481 and :1561.
Proposed extension:
```
pub enum BlurStrength {
    Uniform(Pixels),
    LinearGradient { from: Pixels, to: Pixels, axis: Axis },
}

pub struct BlurEffect {
    pub strength: BlurStrength,
    // existing fields …
}
```
The Kawase chain stays per-frame — a linear-gradient strength just modulates the per-pixel blur radius lookup at sample time.
3. Framebuffer-mirror primitive — unblocks backgroundExtensionEffect
SwiftUI's backgroundExtensionEffect() (macOS 26+) mirrors the host view into the surrounding safe area, blurs the mirror, and clips the copies to prevent overlap. tahoe-gpui's Sidebar::background_extension(Hsla) is a static-color workaround that explicitly defers this — see crates/tahoe-gpui/src/components/navigation_and_search/sidebar.rs:94-100.
Proposed primitive:
```
impl Window {
    pub fn paint_mirror_rect(
        &mut self,
        source: Bounds<Pixels>,
        destination: Bounds<Pixels>,
        axis: MirrorAxis, // Horizontal | Vertical | Both
        clip_to_destination: bool,
        blur: Option<BlurEffect>,
    );
}
```
Implementation can ride the same Kawase chain the existing blur primitive populates — the mirror is a flipped UV sample of the snapshot texture, optionally re-blurred. Same render-pass-break budget as paint_blur_rect.
These three are independent and can land as separate PRs after this one merges. (1) is the largest payoff per LOC since it unlocks all of Phase 2; (2) and (3) each unblock one concrete tahoe-gpui component.

```
* gpui: Replace mix approximation with true mip-pyramid variable blur

The previous variable-radius blur mixed the un-blurred framebuffer with
```

```
layer. The overwhelming majority of Zed frames contain no blur / lens
primitive, so every shipping build was paying a presentation-cost
regression for a feature that may never be used in the session.

Plumb a new `enable_frame_sampling` flag through `new_renderer` /
`MetalRenderer::new` / `new_internal`. Only flip
`layer.set_framebuffer_only(false)` when the flag is true, or when
`cfg(any(test, feature = "test-support"))` is active (so visual-test
screenshots keep working). When disabled, `BlurRects` / `LensRects`
batches silently skip rendering — the same failure mode as the wgpu
path when a surface doesn't advertise COPY_SRC.

The existing `gpui_macos` call site in `window.rs` passes `false`
today; any caller that actually paints `BlurRects` / `LensRects` must
pass `true`.

* gpui_wgpu: Wire kernel_levels + radius; fix blur_params write race

The BlurRect/LensRect chain was using two scratch textures (full + half)
and hardcoded offset_multiplier=1.0, so `BlurEffect::kernel_levels` and
`BlurEffect::radius` had no effect on the rendered output. It also ran
two `queue.write_buffer` calls into offset 0 of a single-slot
`blur_params_buffer` before submit, so both passes actually read the
second write — the downsample pass sampled with half-resolution params
instead of full-resolution ones.

Restructure the snapshot pipeline:

- Replace the snapshot/half pair with a `BLUR_CHAIN_LEVELS`-deep mip
  chain of `wgpu::Texture`s on `WgpuResources`. Level 0 is surface-sized
  and receives the framebuffer snapshot; each subsequent level is half.
- Fold `ensure_blur_textures` into `ensure_intermediate_textures` so
  one allocation site owns both the path intermediate textures and the
  blur chain.
- Allocate chain textures with `format.remove_srgb_suffix()`. When the
  surface happens to be an sRGB variant (possible on adapters that only
  expose sRGB BGRA/RGBA), this avoids double-correcting gamma — the
  hardware no longer transfers sRGB on sample and the manual pow() in
  `blur_io_shaders.wgsl` runs against raw bytes.
- Pre-build a down/up bind group per chain transition in
  `create_blur_io_bind_group`, keyed on the source view. The previous
  code recreated two bind groups every `snapshot_and_blur_frame` call.
- Grow `blur_params_buffer` to `BLUR_PARAMS_SLOT_COUNT` slots aligned to
  `min_uniform_buffer_offset_alignment`. Switch the bind-group layout
  to `has_dynamic_offset: true` and write all per-pass params in one
  `queue.write_buffer` call. Each `set_bind_group` now passes the slot
  offset so the write-race is eliminated by construction.
- Change `snapshot_and_blur_frame` to loop down N then up N steps,
  where N is `kernel_levels.clamp(1, BLUR_CHAIN_LEVELS - 1)`.
- Add `Scene::max_blur_kernel_levels` and `Scene::max_blur_radius`
  helpers; the main draw loop samples these once per frame and maps
  radius to `offset_multiplier = radius / BLUR_REFERENCE_RADIUS_PX`
  (reference = 20px, current default).

This also resolves the `let _ = half_tex` unused-binding cleanup that
was previously called out separately — the destructure is gone.

* gpui: Cache blur snapshot across batches within a frame

Every BlurRects/LensRects batch unconditionally ran
snapshot_and_blur_frame — full-surface framebuffer copy plus two
Kawase passes per blur-chain level. With N blur primitives interleaved
with other primitives at different z-orders, the scene iterator emits
N batches and the renderer paid that cost N times.

Add a local `blur_snapshot_valid: bool` in the draw loop on both
renderers. It's false at frame start and whenever a non-blur primitive
batch writes to the main target. On a blur / lens batch, reuse the
cached chain when valid; otherwise run snapshot_and_blur_frame and
set the flag true. For typical UI scenes this collapses N snapshots
to one, regardless of draw-order interleaving.

* gpui: Replace mix approximation with true mip-pyramid variable blur

The previous variable-radius blur mixed the un-blurred framebuffer with
the full-strength Kawase result per pixel, which reads as "both sharp
and soft" at mid-range strengths rather than as a clean intermediate
blur. Switch to a preserved downsample pyramid with per-pixel fractional
mip sampling so each target radius lands on the pyramid level that
actually matches its Gaussian sigma.

- New `blur_pyramid_texture` (single mipmapped texture with N mips) on
  both Metal and wgpu. Mip 0 holds the un-blurred framebuffer copy;
  subsequent mips are populated after each Kawase downsample pass (on
  Metal via `copy_from_texture` into the destination mip; on wgpu via
  `copy_texture_to_texture`). The full dual-Kawase chain still runs so
  `chain[0]` keeps its dual-filter max-blur quality for any consumer
  that wants it.
- `framebuffer_snapshot_texture` retires - it's now pyramid mip 0.
- Fragment shaders replace `mix(sharp, blurred, strength)` with
  `sample_blur_pyramid(uv, target_radius)` which computes
  `level = kernel_levels + log2(strength)`, clamps to [0, kernel_levels],
  and samples with trilinear filtering. Doubling the target radius
  bumps level by 1, matching the pyramid's exponential sigma spacing.
- Samplers gain `mipmap_filter = Linear` (was Nearest on wgpu, unset on
  Metal) so trilinear actually kicks in across mips.
- `SceneBlurParams` grows a `kernel_levels: f32` field that the shader
  uses as the log2 clamp ceiling; `max_blur_radius` stays as the
  per-pixel strength normalizer.
- wgpu's pyramid mip count is clamped to what the surface size
  supports (a 20x20 surface hosts at most 5 mips, not 6).
- Bind group layouts drop the old `unblurred_texture` entry (binding
  5); the pyramid view replaces the single-mip chain[0] view at
  binding 2.

* gpui: Per-shape content masking for multi-shape lens groups

rendering. Per-shape masks are applied as a soft attenuation inside
```
