Summary
Implements the random-walk subsurface scattering (SSS) integrator as Phase 3 of the MediumInterface plan. This adds a dedicated hero-wavelength spectral-MIS path for light transport inside participating media bound to geometry, replacing the single-channel free-flight sampler for scattering-enabled HomogeneousMedium instances.
Key Changes
New RandomWalkSss.cs partial class: Implements RandomWalkSubsurface() method with:
Hero-channel selection proportional to current throughput
Per-channel free-flight distance sampling on the selected hero channel
Balance-heuristic MIS combination across all three RGB channels
In-scattering NEE (next-event estimation) at every volume event
Russian Roulette termination with configurable start bounce and max-bounce hard ceiling
Restricted BVH queries via HitRecord.EntityRoot to prevent boundary leakage
Dispatch infrastructure in Renderer.cs:
New SssMode enum (Auto / Off) to gate the random-walk dispatch
New RandomWalkConfig struct with quality presets (Preview / Normal / High)
ResolvePushedMedium() method to demote scattering media to absorption-only when SSS is disabled
IsScatteringMedium() predicate to identify participating media (σ_s > 0)
Dispatch logic in ShadeSampleBounce() that routes entry refraction into scattering media to the random walk instead of TraceRay()
Core data structure updates:
HitRecord.EntityRoot field to store the bound entity's root hittable (populated by MediumBoundHittable)
Public accessors on HomogeneousMedium for SigmaA, SigmaS, and SigmaT
Comprehensive test suite (SssRandomWalkTests.cs):
Test 1: Verifies σ_s = 0 media fall back to legacy Beer-Lambert path
Test 2: White-furnace energy conservation (σ_a = 0, σ_s > 0, matched IOR)
Test 3: Spectral color bleed with wavelength-dependent absorption
Test 4: Dense-medium robustness (σ_t = 50, low budget) produces finite values
Test 5: SssMode.Off bypass verification
Documentation: Updated Phase 3 status in mediuminterface-and-random-walk-sss.md
Implementation Details
Spectral unbiasedness: The MIS estimator weights all three channels at every event, ensuring correct color bleeding even with strongly wavelength-dependent absorption coefficients.
Boundary confinement: Queries against entityRoot (not the global BVH) prevent the walk from leaking through coincident surfaces into adjacent geometry.
Exit handling: No second Fresnel evaluation at exit — the entry-side transmission factor (already in throughput) is the only Fresnel coupling, matching Cycles' default and enabling exact energy conservation for matched-IOR (η = 1) configurations.
Firefly control: Depth-aware NEE clamp inside the walk (ClampWalkInScattering()) damps deep-volume spikes without flat-clamping early bounces.
Deterministic tests: All tests force Sampler.SetKind(SamplerKind.Prng) for reproducible expected values independent of Sobol prefix layout.
