# flux-metal-ops

Differentiable Gaussian rasterization on Apple Silicon, split into separately
installable license scopes. This repository includes **no training pipeline**,
models, datasets, service configuration, credentials or pretrained binaries.

| Distribution | What it provides | License |
|---|---|---|
| `flux-metal-ops` | Projected 2D Gaussian blend/VJP, CPU staging bridge, build/cache, validation and generic orchestration | Apache-2.0; see LICENSE and NOTICE |
| `flux-metal-ops-research` | 3D projection/VJP, precise ellipse tile selection, SH, numerical reference and compatibility API | Original Gaussian-Splatting research/evaluation terms; see packages/research/LICENSE.md |

The root LICENSE **does not cover the research companion**. Installing both
provides the complete differentiable 3D renderer with the retained research
restrictions. File counts or lines of Apache code do not remove those conditions.
The core alone accepts already projected means/conics and caller-generated,
depth-sorted tile bins; it is not a complete 3D renderer or a trainer.

## Install from source

Validated: Apple Silicon, Python 3.11.13, PyTorch 2.14.0, Xcode 15.4 with Metal
compiler, macOS SDK 14.5. Other versions are not yet validated. Dependencies are
PyTorch and ninja; the first native call builds sources in a fingerprinted cache.
No CUDA dependency, prebuilt `.metallib`, hidden trainer path or CPU fallback.

```sh
# Apache projected core only:
python -m pip install .
python examples/projected.py

# Full 3D renderer: read and accept the companion's license first.
python -m pip install . ./packages/research
python examples/synthetic.py
```

Offline: build the two wheels separately and install them together from a locked
wheelhouse with matching versions `0.1.0a2`; native compilation still needs Xcode,
PyTorch headers and ninja. The optional `research` extra names the companion;
no package registry release is claimed by this local repository.

## APIs and contracts

`blend_tiles` takes float32 MPS tensors: means2d `[N,2]`, conics `[N,3]` in `(a,b,c)`
order, RGB `[N,3]`, opacity `[N]`/`[N,1]`, fixed background `[3]`. Supply flattened
row-major 16x16 tile bins as integer `point_indices`, `starts`, `counts` on CPU or
MPS. `starts/counts` each have exactly `ceil(W/16)*ceil(H/16)` entries; empty
tiles have count zero. Each range must be contiguous and already ordered front to back. Returns
`[3,H,W]`, owns its storage and supports first derivatives of all four point inputs.
Pixel alpha threshold is 1/255, cap .99 with straight-through alpha derivative;
transmission stop threshold is 1e-4. These are the retained numerical contract,
not a claim of exact gsplat semantics. See `examples/projected.py`.

With the companion installed, the compatibility API is:

```python
from flux_metal_ops import GaussianRasterizationSettings, GaussianRasterizer
```

The full API preserves four-channel screen gradients (signed x/y and accumulated
absolute x/y) required for densification. Camera/background settings are fixed;
trainable settings are rejected. Float inputs must share a device and dtype.
`backend="metal_native"` fails if MPS is unavailable; `backend="reference"` is an
explicit Torch numerical reference. Metric statistics use the explicit Torch
path, not a claim of fully native execution. Precomputed covariance requires
`projection_backend="torch"`. Diagnostic radii/metrics are non-differentiable.
Default outputs own storage. Optional `RasterizationContext(reuse_canvas=True)`
is for strictly sequential streaming; consume a frame before reusing its canvas.
The native staging bridge is serialized; this is not a concurrent training API.

`python -m flux_metal_ops.build` builds only Apache sources. Research geometry is
compiled lazily into a different artifact when explicitly requested by full 3D
execution. `METAL_OPS_CACHE` selects the cache. Build manifests include source,
compiler, dependency and binary hashes; mismatched cached artifacts fail closed.

See THIRD_PARTY.md for pinned upstream sources and license scope, VALIDATION.md
for measured coverage, and the Git repository's provenance/ for the source inventory (not shipped in the core sdist). This is a local
pre-release; no external publication has been performed.

Compatibility changes from a1: full-renderer names require explicit imports and
are intentionally omitted from `import *` in the core-only package. Image sizes
and chunk budgets must be Python integers; `mult` must be finite and positive;
metric maps must be float32 on the input device. Unsupported settings gradients
are rejected instead of silently returning no gradient. Directly importing the
internal `flux_metal_ops.rasterizer` module requires the companion; prefer the
public imports above. The research extra resolves only when matching wheels are
available in an explicitly configured wheelhouse until a registry release exists.

The saturated/early-stop background VJP is corrected relative to a1. Forward
images are unchanged; nonblack-background gradients in that previously untested
branch may change. See VALIDATION.md for the failing oracle and regression scope.
