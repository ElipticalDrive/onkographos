# Video-to-3D Gaussian Splatting (COLMAP → Inria 3DGS)

A Kaggle-first pipeline that converts drone video footage of Glencoe into a **3D Gaussian Splat** using the canonical COLMAP → 3DGS workflow.

**Video → frame extraction → COLMAP SfM → camera model normalization (OPENCV → PINHOLE) → Inria 3DGS training → novel-view rendering → MP4/GIF outputs.**

![](3dGS.png)

## Pipeline Overview

```
Drone MP4 → ffmpeg frames → COLMAP SfM → camera normalization → 3DGS training → render MP4/GIF
```

| Step | Tool          | Output |
|------|---------------|--------|
| Frame extraction | `ffmpeg`      | PNG frames (10s @ 30fps) |
| Camera poses + sparse 3D | COLMAP        | `cameras.txt`, `images.txt`, `points3D.txt` |
| Camera model conversion | Custom Python | OPENCV → PINHOLE |
| 3DGS training | Inria         | Trained Gaussian model |
| Novel-view rendering | Render tool   | MP4 + GIF |
