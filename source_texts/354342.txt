# GLASS MIRAGE

[![Render CI](https://github.com/samikshagiri25cmg/Glass_mirage/actions/workflows/render.yml/badge.svg)](https://github.com/samikshagiri25cmg/Glass_mirage/actions/workflows/render.yml)

A hybrid realtime and offline GPU raymarching renderer built with Rust, `wgpu`, and WGSL, supporting deterministic headless rendering, shader hot reload, GPU readback pipelines, and multipass postprocessing workflows.

# Features

* GPU raymarching using signed distance fields (SDFs)
* Sphere tracing renderer
* Procedural animation
* Smooth blending (`smin`) and domain repetition
* Numerical gradient normal estimation
* Diffuse lighting, fog, and procedural sky shading
* Offscreen rendering architecture
* Multipass postprocessing pipeline
* Tone mapping
* Chromatic aberration
* Shader hot reload using filesystem watching
* Deterministic offline rendering
* Headless rendering mode (`--render`)
* GPU texture readback and frame export
* PNG sequence + ffmpeg video encoding
* CI pipeline which exports a video artifact of ademoscene on every commit in GitHub.
