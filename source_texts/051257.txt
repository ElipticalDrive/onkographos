Description
Advanced alternative to Marching Cubes that preserves sharp features and edges. Generates terrain meshes with proper corners and edges instead of smoothed-out shapes.
Why It's Impressive
More sophisticated than Marching Cubes
Preserves sharp features (cliffs, edges, corners)
Better for architectural/man-made structures
Shows advanced mesh generation
Research-level algorithm
Interactive Features
Compare with Marching Cubes side-by-side
Adjust feature detection threshold
Real-time terrain editing
Show vertex placement (QEF solutions)
Toggle sharp feature preservation
Material assignment based on surface orientation
