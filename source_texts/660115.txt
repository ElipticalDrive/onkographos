Context
Verified: every texture is created with its full mip chain (desc.generate_mips = true in Engine/Graphics/Resources/ResourceRegistry_Textures.cpp) and stays resident for the lifetime of the scene; there is no VRAM budget. A shipped game reads its core .vpak completely into RAM (Editor/Core/Services/AssetVfs.cs). A 2×2 km Battle Royale map with hundreds of 2K–4K PBR materials cannot work that way — Warzone-class games keep only the mips the camera actually needs. #128 builds the asynchronous loading infrastructure; this issue is the texture streamer on top of it.
Goal
A texture streamer that keeps every texture at the mip level its on-screen size requires, inside a configurable VRAM budget: refine as the camera approaches, evict when over budget.
Acceptance Criteria
Each texture has a resident mip range; the mip tail (≤ 64×64) is always resident, so nothing is ever missing
Wanted mip per texture from screen-space size (distance, per-mesh UV density, FOV, render resolution); ADS/scope zoom raises priority
Pool budget setting (r.Streaming.PoolSizeMB, default derived from GPU memory); lowest-priority mips are dropped first when over budget
Mip upgrades go through the async upload queue with a per-frame byte cap — no frame spikes
DX12 and SDL GPU (Metal/Vulkan); single mips are read from the pak without loading the whole texture
Debug view tinting resident vs. wanted mip; numbers in the streaming overlay
A 4 GB texture test scene runs inside a 1.5 GB pool with no visible blur once streaming settles
Technical Notes
Priority uses the same squared-distance metric as the LOD thresholds in DX12Renderer.h / SdlGpuRenderer.h, scaled by UV density computed at import
First version: recreate the texture with the new mip count and copy resident mips (works on every backend); tiled/reserved resources and sampler feedback stay with perf: virtual texturing / sampler feedback streaming #140
Dependencies
core: async asset streaming — textures & meshes on demand #128 (async asset streaming)
rendering: BCn texture compression at import (BC1/BC3/BC5) + compiled-texture cache #179 (BCn compression)
core: streaming-ready cooked formats — per-mip/per-LOD offsets in .vpak, async file I/O #196 (core: streaming-ready cooked formats — per-mip/per-LOD offsets in .vpak, async file I/O)
