Summary
Add src/world/noise.zig: seeded 2D/3D Perlin noise with fBm (fractal Brownian motion) for terrain heightmap generation. Supports configurable octaves, lacunarity, and persistence. Pure math with no allocations.
Add src/world/terrain_gen.zig: chunk terrain generator that populates 16x16x16 chunks with layered blocks (bedrock at y=0, stone, dirt, grass/sand surface) using noise-driven heightmaps. Sand appears at low elevations, grass at higher ones.
8 noise tests (determinism, output range [-1,1], frequency scaling, seed independence) and 6 terrain tests (bedrock placement, surface block types, determinism, layering order) all passing.
Test plan
zig test src/world/noise.zig -- 8/8 passed
zig test src/world/terrain_gen.zig -- 20/20 passed (includes transitive tests from noise, chunk, block)
Determinism verified: same seed + coordinates = identical output
Output range verified: noise values stay within [-1, 1]
Layer ordering verified: bedrock -> stone -> dirt -> grass/sand (bottom to top)
