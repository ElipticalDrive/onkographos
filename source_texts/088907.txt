Using NVIDIA Index plugin for Paraview on HiPerGator
Why using index?
Interactive Volume rendering
Compare iso-value surface rendering, if volume too low, we have too much redundant feature, too high we may miss important value. Using IndeX, make it easy to filter interactively.
Step to run pvserver
Prepare the compiled Paraview with Index
Download the headless - EGL version from the paraview download site and untar it. for example, the latest version is ParaView-5.10.1-egl-MPI-Linux-Python3.9-x86_64.tar.gz.
In the $PARAVIEW/bin folder you'll find the pvserver/pvbatch executables AND mpiexec executable. You should use that mpiexec to launch pvserver/pvbatch, because they were compiled for it.
2. Submit job to run server:
```
#! /bin/bash -l
#SBATCH --job-name="pvserver"

## Node Info

#SBATCH --exclusive
#SBATCH --nodes=1
#SBATCH --ntasks=128
#SBATCH --mem=2000GB # mem per node
#SBATCH --cpus-per-task=1
#SBATCH --partition=hpg-ai
#SBATCH --gpus=a100:8

#SBATCH --time=12:00:00
#SBATCH --output=log.out

pwd;hostname;date;
nvidia-smi

module purge
module load cuda/11.4.3
module list

echo Running on $SLURM_JOB_NUM_NODES nodes with $SLURM_NTASKS tasks.
echo $CUDA_VISIBLE_DEVICES

source ./license.lic # specify license file location

srun ./ParaView-5.10.1-egl-MPI-Linux-Python3.9-x86_64/bin/mpiexec -n $SLURM_NTASKS ./ParaView-5.10.1-egl-MPI-Linux-Python3.9-x86_64/bin/pvserver --mpi --force-offscreen-rendering --displays $CUDA_VISIBLE_DEVICES
```
3. Wait for the server until the following prompt appears:
```
Waiting for client...
Connection URL: cs://c1101a-s17.ufhpc:11111
Accepting connection(s): c1101a-s17.ufhpc:11111
```
4. Reqest a paraview client on hwgui partition
5. modify the server configuration: file -> connect -> Choose Server Configuration -> edit server, change the host to the server hostname
Click save
Click connect
Wait for the server console:
Client connected.
```
	-----------------------------------------------------
	  By loading the 'pvNVIDIAIndeX' plugin you have accepted the EULA shipped with it.
	  If that is not acceptable, please restart the application without loading
	  the 'pvNVIDIAIndeX' plugin.
	-----------------------------------------------------
```
6. Verify the server is connected correctly:
```
    a. Open tools->manage plugins->pvNVIDIAIndeX, make sure both remote and local are loaded for server/client mode. 
```
Can toggle on auto load for future loading
b. open view-> memory inspector, see server memory allocation
c. Make sure both client and server have hardware support
i. help -> about -> client inforamtion -> OpenGL renderer = RTX6000
-> connection information->OpenGL renderer = A100
7. Edit -> Setting -> Render View -> Advanced -> Disable ICeT
8. Test Paraview server:
```
  a. Open sources -> alphabatical ->wavelet, click apply to display view, select surface in display
  b. Select NVIDIA IndeX in representation and coloring RTData to display wavelet result.
  c. Sources->cylinder->ht=10, radius=5
  d. View -> color map editor, select wavelet, by adjusting the color map curve, you could have different rendering of the volume data.
```
