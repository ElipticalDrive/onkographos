Ello Johaan, with the forked repository i reworked the implementation to be separate from the components.
I didn't change much besides adding a way to use a box count for the voxel/decomposition and allow users to time the creation / algorithms
I don't expect you to accept the pull request, just wanted to show you the changes that i did incase you wanted to add some parts of what I did
a quick thing I noticed while working:
The voxel Collider creation takes a whole lot more time then others I've worked with. the ray intersection test seems to be really inefficient since the raycast is called for every triangle for every point, even with a 8k verts / 5k triangle mesh.
A suggestion would be to use a SpacialBinaryTree / Mesh BVH to speed up the raycast queries, or to use a mesh SDF if your more comfortable with a sdf repersentation
