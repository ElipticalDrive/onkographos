I have neglected jaxsplat for a while now, mainly due to the fact that using dynamic shapes with JAX is not feasible. The classical 3DGS1 heuristic densification strategy (clone/split/prune) naturally requires dynamic shapes as it dynamically controls the number of Gaussians. This does not play nicely with JAX.
More recently, non-heuristic methods for density control have been proposed. In particular, 3DGS-MCMC2 maintains a constant number of Gaussians, and performs "relocations" of Gaussians (justified by SGLD). This would fix the problem with dynamic shapes. Of course, most of the existing work on GS is based on PyTorch, and it remains to be determined whether an overhaul of jaxsplat would be worth the effort.
