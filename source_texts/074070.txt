Volumetric Rendering with 3D Texture Slicing
2024 Individual Project
This project explores advanced 3D graphics techniques to visualize volumetric data, such as CT scans and MRI outputs, which do not have defined surfaces like traditional mesh-based objects. Implemented in C++ and OpenGL, the application uses the 3D Texture Slicing algorithm to reconstruct a 3D representation of internal structures by sampling raw binary volume data. A key component of the application is the interactive slicing tool: a transparent plane with distinct red borders that users can manipulate in real-time. By rotating and translating this plane using mouse and keyboard inputs, users can dynamically slice through the 3D volume to inspect specific cross-sections and internal details.

Features
Features highlighted are my primary contributions.
Implemented 3D Texture Slicing: Developed the core algorithm to render volumetric data by stacking semi-transparent polygon slices.
Interactive Slicing Plane: Created a user-controlled transparent plane with red visual guides that can be rotated and moved via mouse and keyboard to dynamically cut through the volume.
3D Texture Management: Programmed the ingestion of raw binary datasets (e.g., CT Head, Engine block) into OpenGL 3D texture objects.
Raw Data Parsing: Created a system to parse and load generic .raw volume data files for visualization.
Interactive Visualization: Integrated camera controls to allow users to orbit and inspect the volumetric model from different angles.
