Tracking issue for v0.3.0 candidate features. Assign individual issues from this list as work begins.
Candidate features
New fractal forms
Quaternion Julia sets (4D slice rendering)
Newton fractal generalised to degree-n polynomials
Kleinian group limit sets
Burning Ship 3D variant
Mandelbulb power variants (power 4, 6, 16)
Interactivity
Arrow keys / mouse-wheel to tweak active parameter (c, power, scale, fold) live
On-screen parameter display (current value + step size)
Undo history for parameter changes (ring buffer, Z key)
Export
S key → PNG screenshot with fractal metadata embedded in EXIF/comment
Animated GIF export (N frames, configurable)
Performance
Numba JIT for inner escape-time loop (Mandelbrot, Julia, BurningShip)
Tile-based parallelism for 3D renderer (multiprocessing or threading)
Packaging / distribution
PyPI publish via hatch build && twine upload
Homebrew formula (macOS)
GitHub Actions release workflow (auto-publish on tag push)
DoD gates for v0.3.0 (TBD)
Gates to be defined once feature set is locked. Candidates:
Screenshot: exported PNG must contain correct fractal name in EXIF
Param tweaking: parameter changes must be reflected in the next rendered frame
Performance: escape-time forms must render ≥ 60 fps at 800×600 with Numba
