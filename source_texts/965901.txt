Description
Single-bounce indirect illumination replaces the flat ambient constant with physically correct GI. Also fixes two pre-existing RT bugs found during the math audit.
What changed
Indirect GI (mesh.slang): cosine-weighted hemisphere sampling via Frisvad orthonormal basis, Russian roulette (probability scaled by surface luminance), two-bounce path tracing (eye -> surface -> bounce -> light), temporal EMA accumulation in the reservoir's indirect field.
Reservoir extended (pipeline.hpp, mesh.slang): added float3 indirect + padding (48 -> 64 bytes per pixel). Reservoir buffers now 530 MB each at 4K.
Bug fix: temporal reprojection Y-flip (mesh.slang): prev_ndc mapped with float2(0.5, -0.5) instead of 0.5 -- slangc -fvk-invert-y only negates SV_Position, not TEXCOORDs, so the Y axis was vertically mirrored.
Bug fix: reflection normal (mesh.slang): reflections now use the unflipped geometric normal (N_geo) instead of the two-sided lighting normal (N), preventing incorrect reflection angles on steep back-facing terrain slopes.
Related Issue
Phase 8 Etape 38. Follows Etape 37 (PRs #87, #88, #89).

Screenshots / Logs
Indirect GI visible as faint coloured patches on the obsidian floor near neon tubes. Temporal reprojection fix improves ReSTIR convergence. Reflection angles corrected on steep terrain.
Additional Notes
Russian roulette probability is luminance(base_colour) * 10, clamped to [0, 0.95]. For obsidian (luminance ~0.007), only ~7% of pixels trace indirect rays -- the rest terminate early.
The indirect term accumulates via EMA in the reservoir: alpha = 1/M. Converges over ~20 frames.
World-space irradiance cache (TODO acceptance criterion) is deferred -- the temporal EMA provides adequate convergence for the current static scene.

Single-bounce indirect illumination replaces the flat ambient constant
with physically correct GI. Cosine-weighted hemisphere sampling, Russian
roulette termination, two-bounce path tracing (eye → surface → bounce
→ light), temporal EMA accumulation in the reservoir.

- Cosine-weighted hemisphere via Frisvad orthonormal basis + PCG hash
- Russian roulette with probability = luminance(base_colour) × 10
- At bounce hit: read hit normal from vertex SSBO, evaluate full direct
  illumination with NdotL + shadow ray (no light leaking)
- Indirect accumulated via exponential moving average in reservoir
- Reservoir struct extended with float3 indirect (48 → 64 bytes)

Bug fixes (RT math audit — 10 issues total):
- Temporal reprojection Y-flip: float2(0.5, -0.5) NDC→UV mapping
- Reflection normal: use unflipped N_geo for reflect() direction
- Back-facing reflection guard: skip when dot(N_geo, V) <= 0
- Emissive pixel reservoir zeroing: prevent stale spatial reuse data
- Reflection rays: RAY_FLAG_NONE (neon tubes visible from both sides)
- GI bounce NdotL: read hit normal from vertex SSBO for correct term
- GI bounce shadow ray: prevent light leaking through geometry
- Indirect EMA alpha: use temporal_M only (not post-spatial M) to avoid
  diluting convergence rate from ~5% to ~0.2% per frame
- Reservoir buffer zero-init: vkCmdFillBuffer prevents garbage on frame 1
- Reservoir bounds guard: prevent out-of-bounds writes above 4K

clang-format does not understand and mangles into invalid syntax. Discovered
during Etape 38 when an accidental clang-format pass on mesh.slang broke the
