Summary
Fixes #187 (part of epic #169) and is stacked on #343.
Bridson sampling:
It runs on the integer lattice: candidates are snapped before the distance test, so min_dist holds exactly between the anchors it yields.
The point-cloud path is documented as greedy thinning and uses a background grid instead of rebuilding a KD-tree each time a point is accepted.
max_tries applies to rasters only.
Jitter: uses floor(u·step), so integer offsets are uniform.
Centred anchors: the convention (the pixel sits at chip index size//2) is documented and pinned. The false claim that it matches georeader's centring, which uses banker's rounding, is gone.
Antimeridian and polar checks: the antimeridian check runs only for ordered tracks, and the polar check uses the destination CRS's area of use.
Geometry × domain combinations that couldn't be reached:
SpatialRandom on a VectorDomain: integer anchors map to centroids for the KNN and radius graphs.
KNNGraph caps k at N.
SphericalCap on a GridDomain takes index-dict anchors and returns a {dim: slice} box plus a mask, so it splits and merges through XarrayField.
SpatialRectangular's grid size must match the dims.
Validation: step, jitter, n_samples, min_dist, max_tries and k are checked.
Other fixes:
AlongTrack keeps the final vertex.
(N, 3) arrays are accepted.
SpatialGeometry.extent is removed.
TypeErrors raised in window code are no longer swallowed.
Tests

test_random_on_vector_domain
SphericalCap split and merge on a grid

67 of these fail on the #185 branch. At the top of the stack: patcher 978 passed. The geotoolz fast tier (4105 passed), ruff, ty and mkdocs build --strict are all clean.
Breaking
Constructors raise new validation errors.
PoissonDisk and jitter draw different anchors for the same seed.
AlongTrack can add the final point.
SphericalCap returns a different type on a grid.
extent is removed.

Sampler fixes from the #169 review:

- SpatialPoissonDisk on a raster runs Bridson on the integer lattice:
  candidates are snapped to their pixel before the distance test, so
  min_dist holds exactly between the yielded anchors (the float-then-cast
  version let pairs come as close as 1.0 for min_dist=2). On a
  PointDomain the subset is documented as what it is - greedy
  random-order thinning - and uses a background grid instead of a
  cKDTree rebuild per accepted point (O(N) expected, not O(N^2 log N));
  max_tries is documented as raster-only.
- Jitter offsets are floor(u * step), uniform over the integers, instead
  of int() truncation toward zero (P(0) was 0.126, +-8 unreachable).
- The centred-anchor convention (coordinate's pixel at chip index
  size // 2) is documented and pinned; the docstring no longer claims
  equivalence with georeader's read_from_center_coords, which rounds the
  continuous corner with banker's rounding.
- The antimeridian check only runs on ordered tracks (SpatialAlongTrack),
  not on an unordered SpatialExplicitCoords catalogue; the polar check
  consults the destination CRS's area of use.
- SpatialAlongTrack keeps the final vertex when resampling; (N, 3) arrays
  are accepted like 3-D LineStrings.
- Validation: positive integer step, non-negative jitter / n_samples,
  min_dist > 0, max_tries >= 1, KNN k >= 1.

Geometry x domain combinations a sampler can actually reach:

- int anchors (SpatialRandom on a VectorDomain) map to the feature
  centroid in SpatialKNNGraph / SpatialRadiusGraph;
- SpatialKNNGraph caps k at N instead of returning scipy's sentinel N;
- SpatialSphericalCap on a GridDomain finds the lat/lon dims by name,
  accepts the index-dict anchors grid samplers yield (or a (lat, lon)
  pair) and returns a {dim: slice} box plus the cap mask as weights;
- SpatialRectangular on a GridDomain requires one size per dim.

Also: SpatialGeometry.extent (dead code) is removed, and
_safe_base_weights no longer swallows every TypeError - ragged
geometries are detected up front, so a bug in a SpatialCustom fn
surfaces.

BREAKING CHANGE: invalid step / jitter / n_samples / min_dist /
max_tries / k raise ValueError at construction; SpatialPoissonDisk and
SpatialJitteredStride draw different anchors for the same seed;
SpatialAlongTrack(spacing=...) may yield one more (final) point;
SpatialSphericalCap on a GridDomain returns a masked {dim: slice}
window instead of an argwhere array; SpatialGeometry.extent is removed;
a TypeError raised by a window's weights now propagates.

Closes #187
