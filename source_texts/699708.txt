💡 What: Caches the Delaunay triangulation indices (simplices) in create_normal_map based on the number of landmarks.
🎯 Why: scipy.spatial.Delaunay is computationally expensive (~2ms per call) and was being called on every frame. Since the face mesh topology (connectivity) is generally stable for a given number of landmarks (e.g., 478 from MediaPipe), we can reuse the triangulation indices.
📊 Impact: Reduces frame processing time by ~2ms (estimated based on benchmark). For 30fps video, this is ~6% of the budget.
🔬 Measurement: Added tests/test_face_helper.py which mocks scipy.spatial.Delaunay and asserts it is called only once for multiple invocations with valid landmarks. Use python3 tests/test_face_helper.py to verify.

Caches Delaunay triangulation indices (`simplices`) in `create_normal_map` based on the number of landmarks.
This avoids recomputing the triangulation on every frame (~2ms) for a static mesh topology (e.g. MediaPipe 478 points).
Includes a validity check (max edge length < 0.5 * face span) to prevent caching distorted topologies.
Adds `tests/test_face_helper.py` to verify caching behavior.
