Summary
3D escape-time fractals, written as equations. A recursive function's self-call now spreads a point or quaternion into consecutive parameters (lib/geom.ts case loop, lib/defs.ts). The Mandelbulb and quaternion Julia sets become user-space rows instead of built-ins:
```
n = 8
S(R, t, p) = R (sin(t) cos(p), sin(t) sin(p), cos(t))
r(a, b, c) = sqrt(a^2 + b^2 + c^2)
T(a, b, c) = S(r(a, b, c)^n, n acos(c/r(a, b, c)), n atan2(b, a))
G(a, b, c, k) = {r(a, b, c) > 2: ln(r(a, b, c))/n^k, k >= 12: ln(r(a, b, c))/n^k, G(T(a, b, c) + (x, y, z), k + 1)}
G(x, y, z, 0) = 0.001
```
```
Q(a, b, c, d, k) = {|quat(a, b, c, d)| > 2: …, Q(quat(a, b, c, d)^2 + C, k + 1)}
Q(x, y, z, s, 0) = 0.001
```
Each returns the orbit's Green function ln|p|/nᵏ rather than an escape count. Escape counts jump, which the raymarcher refuses. This recipe is documented in llms.txt.
Argument counts: self-calls passing only plain numbers are still checked on the definition row. Otherwise the count is checked once point sizes are known: "A recursive call passes 3 values, and the function takes 4."
New Mandelbulb (slide n) example. The quaternion Julia example and about-page card now use the user-space form. qjulia(c, s) is kept, with its help entry removed, so old links still open.
Faster implicit surfaces (all of them). Surfaces raymarch into an offscreen colour+depth target that is composited back, so they still depth-test against everything else.
Nothing about the surfaces changed (hover, editing another row): the target is reused, ~1–2 ms instead of a full raymarch.
View or slider moving: half resolution when a panel is over 2M pixels.
At rest (after 150 ms): full-resolution cells in dither order, each drawn as a dense quarter-size image and scattered into place. Masking individual pixels saved nothing, because GPUs shade in quads. Then 7 jittered samples are averaged in for anti-aliasing, which softens the dust at fractal edges.
Bisection 24 → 12 halvings, still far below a pixel.
Measured on a full-screen Mandelbulb (2400×2444): ~55 ms per frame before; ~9–18 ms while moving; refinement frames ~17 ms. The converged image is bit-identical to a direct full-res render (0 of 65,536 pixels differ).
SHOTS_PORT / PERF_PORT override the screenshot and perf scripts' dev-server ports.
Not in this PR
|(1, 2, 2)| evaluates to 1, because the 3D tuple flattens into abs(1, 2, 2). This is already on main, and worker/typed-values-compat.test.ts pins it on purpose. Fixing it changes existing links, so it's left for a decision.
A recursive function can't name a parameter w: it's read as the complex variable.
pnpm perf: the orbit scenarios' compilesAfterLoad baseline (5) was already stale on main (7). This PR adds 2 (composite and scatter programs). The baseline isn't updated here; CI doesn't run it.
