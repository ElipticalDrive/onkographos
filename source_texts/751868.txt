This paper presents an efficient compression method for Layered Depth Image (LDI) depth data using geometry proxy. An LDI is one of the Image Based Representation (IBR) methods and is efficient for rendering. The drawback of LDI, however, is large amount of data. Since an LDI stores multiple attribute values which have different characteristics, those characteristics should be considered during encoding process to prevent disturbing artifacts such as geometry distortion. Among the attribute values stored in an LDI, depth data changes smoothly in most of regions. Thus, piecewise approximation can be applied. For enhancing the efficiency of depth data approximation, the usage of geometry proxy is proposed. Then depth data approximation is applied on a Layered Depth Difference Image (LDDI), a difference between an LDI and a geometry proxy. Experimental results show that compression efficiency is improved with the help of a geometry proxy and an LDDI.
