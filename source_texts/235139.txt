# 3DGS Viewer

A native **3D Gaussian Splatting** viewer for macOS, built with **Metal** compute & render pipelines. Projection, sorting, and rendering are performed entirely on the GPU — no per-frame CPU-GPU data transfer.

| Truck Scene (1.7M gaussians) | Train Scene (1.1M gaussians) |
|:---:|:---:|
| ![truck](docs/truck.png) | ![train](docs/train.png) |

## Features

- **Full GPU Pipeline** — Gaussian projection, bitonic sort, and instanced rendering all run on the GPU via Metal compute + render passes
- **Zero Per-frame Upload** — Scene data is uploaded once; sorted indices and projection results stay in GPU buffers
- **Real-time Performance** — 1.7M gaussians at interactive frame rates on Apple Silicon
- **COLMAP Integration** — Auto-loads training camera parameters from `cameras.json` or `sparse/0/images.bin`
- **Multiple Formats** — PLY (3DGS standard), OBJ (mesh-to-gaussian conversion)
- **ImGui Interface** — FPS counter, frame time graph, render count control, training view navigation

## Architecture

```
┌─────────────────────────────────────────────────────────────┐
│                    Metal Command Buffer                      │
│                                                              │
│  ┌──────────────── Compute Passes ────────────────────────┐  │
│  │                                                        │  │
│  │  1. Reset visible count                                │  │
│  │           ↓                                            │  │
│  │  2. Project all gaussians (1 thread per gaussian)      │  │
│  │     • World → Camera → Screen transform                │  │
│  │     • 3D covariance → 2D conic (EWA splatting)        │  │
│  │     • Frustum culling, radius computation              │  │
│  │     • Write: projection data, depth keys               │  │
│  │           ↓                                            │  │
│  │  3. Bitonic sort by depth (GPU, ~230 sub-passes)       │  │
│  │     • Ascending order: farthest → nearest              │  │
│  │     • Invisible gaussians (depth=FLT_MAX) sort to end  │  │
│  │           ↓                                            │  │
│  │  4. Setup indirect draw args (instance count, base)    │  │
│  │                                                        │  │
│  └────────────────────────────────────────────────────────┘  │
│                          ↓                                   │
│  ┌──────────────── Render Pass ───────────────────────────┐  │
│  │                                                        │  │
│  │  5. Instanced quad rendering (indirect draw)           │  │
│  │     • Vertex: read sorted projection → position quad   │  │
│  │     • Fragment: evaluate 2D Gaussian → alpha blend     │  │
│  │     • Blending: premultiplied alpha (back-to-front)    │  │
│  │                                                        │  │
│  │  6. ImGui overlay                                      │  │
│  │                                                        │  │
│  └────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```
