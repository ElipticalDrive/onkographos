Splats trained with anti-aliasing are rendered with a screen-space filter plus an opacity compensation (#9921). The engine used the 0.3 px² filter of gsplat's anti-aliased mode for them, but Mip-Splatting and the mip mode of Brush (and Spirula Studio's mip primitive) train with 0.1 px², and render too soft with 0.3. File tags do not record the filter size, so it is a scene setting.
Changes:
New GSplatParams#antiAliasFilterSize: the variance of the filter in pixels squared, default 0.3 (unchanged look). It applies to the splats rendered with the compensation; other splats keep the 0.3 dilation of standard training. In a scene mixing both kinds, each splat uses its own filter.
Applied the same way by the quad renderers and the GPU-sort projector, on WebGL2 and WebGPU.
On an anti-aliased scene against reference renders: at 0.3 the result matches main; set to 0.1, it is 47.3 dB from a 0.1 px² reference, against 39.9 dB with 0.3.
API Changes:
New GSplatParams#antiAliasFilterSize (number, default 0.3).
```
// splats trained with Mip-Splatting or Brush's mip mode
app.scene.gsplat.antiAliasFilterSize = 0.1;
```
Examples:
gaussian-splatting/viewer: an AA Filter Size slider next to the Anti-alias setting.
Performance:
No new shader variants: the filter size is a uniform where a constant was. A smaller filter draws slightly smaller quads for small splats.
feat: Add GSplatParams#antiAliasFilterSize
