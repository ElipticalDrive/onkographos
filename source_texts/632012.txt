Summary
Adds a native pure-Rust Kernel Density geoprocessing tool (kernelDensity) under Analysis › Density as part of the roadmap item ("Kernel density (heat map) as a tool and as a renderer; point clustering").
Highlights:
Core Kernel Density Engine (crates/analysis/src/density.rs):
Implements 2D Quartic (biweight, default) and Gaussian kernels.
Calculates magnitude-per-unit-area continuous density surfaces with cell-corner-centered GeoTransform alignment.
Adds Silverman's rule of thumb for automatic bandwidth/search radius estimation based on standard distance and median/IQR of input points (falling back gracefully for single or coincident points).
Computes default adaptive cell size (~250 cells along the longer dimension, span = width.max(height)) when unspecified.
Bounds memory and computation with strict guards:
Output grid bounded by MAX_DENSITY_CELLS = 16_000_000.
Aggregate cell visits bounded by MAX_DENSITY_WORK = 400_000_000 (matching MAX_IDW_WORK).
Bounded point-neighborhood bounding boxes to skip irrelevant distant cells.
Floating-point overflow / underflow guards rejecting non-normal search radii and ensuring finite accumulation.
Geoprocessing Tool Registration (crates/analysis/src/tools.rs):
Registers kernelDensity tool spec taking input (PointLayer), optional field (NumericField weight), radius, pixelSize, kernel (Quartic/Gaussian), extent, crs, and output.
Enforces strict validation: validates projected coordinate systems (with clear distinction between layer CRS and explicit crs parameter), validates input parameter types (field, crs, kernel, extent, output), supports both Point and MultiPoint geometries, validates non-zero extent dimensions, and emits single-band Float32 GeoTIFF raster bytes (OutputLayer::Raster).
Documentation & Assistant:
Documents kernelDensity in docs/user-guide/analysis.md (Analysis › Density), including parameter details, Silverman bandwidth calculation and fallbacks, and MultiPoint weighting.
Adds tool definition and parameter signature to the AI Assistant geoprocessing skill (crates/assistant/skills/geoprocessing/SKILL.md).

Density engine tests in crates/analysis/src/density.rs (Silverman bandwidth math, circular Quartic falloff, GeoTIFF encoding/decoding bit-exact roundtrip, subnormal/overflow radius guards).
