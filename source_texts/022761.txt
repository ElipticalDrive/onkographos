## Motivation

- NeRF encodes single scene in a separate network, which is inefficient.
- NeRF is test-time optimization method, resulting in many hours of scene specific training.

## Key Idea

- Inputs pretrained encoder based pixel-aligned image feature volume for amortized inference.
- Outputs NeRF representation in a feed forward manner with image camera view input.

## Previous Approach

- SRN : outputs feature vector instead of RGB + sigma.
- NeRF

## Method

### Overview

![image](https://user-images.githubusercontent.com/46308407/126921384-ed9afeb2-139e-40bd-bb54-ef2ca606ef11.png)

- An Image Net pretrained encoder outputs 3d feature volume for a given query image.
- The volume is bilinearly upsampled for pixel-alignment.
- Incorporate image feature into NeRF inference framework via residual layer. (**AdaIN** style)

### Multiple Views

![image](https://user-images.githubusercontent.com/46308407/126921527-995fd5d5-ccce-4a8f-946c-08d6f1589769.png)
![image](https://user-images.githubusercontent.com/46308407/126921543-e0d11f8c-7f07-493f-b7d3-770b617d53c7.png)

- Transform query point with view specific camera intrinsic.

![image](https://user-images.githubusercontent.com/46308407/126921563-da833701-4f16-4b95-9240-298b78bb3ab1.png)

- Obtain intermediate vectors for each view.

![image](https://user-images.githubusercontent.com/46308407/126921582-d4eb5988-aeae-4a75-afdf-cb16683d4f41.png)

- Aggregate multiple views via **average pooling**.

## Comments

- Their novelty is roughly two folds: added an encoder for feature-based amortized inference and promoted view-centered rendering.
- Wonder if pretrained image net backbone encoder is the best choice.
- The fact that they can render novel views from few images (even as little as one) is impressive, but the output quality is proportionately compromised, so not entirely sure if it's a decent step forward.
