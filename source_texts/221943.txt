Motivation
Reduce point-rendering surface modes to a single, simpler mode by removing Surfel/EWA/Gaussian splatting code paths and related UI, keeping the engine focused on flat-disc point rendering.
Eliminate multiple mode-specific staging/buffer complexity and shader branches to simplify maintenance and testing.
Description
Removed Surfel, EWA, and GaussianSplat values from Geometry::PointCloud::RenderMode, leaving only FlatDisc (FlatDisc remains as 0).
Simplified PointCloudRenderPass so SubmitPoints(...) only accepts FlatDisc and ignores non-flat mode submissions, consolidated staging to a single buffer, and removed per-mode descriptor buffers and logic in src/Runtime/Graphics/Passes/Graphics.Passes.PointCloud.*.
Replaced multi-mode point shaders with flat-disc-only vertex/fragment shaders in assets/shaders/point.vert and assets/shaders/point.frag (removed surfel/EWA/gaussian branches and inputs).
Forced UI and app behavior to use FlatDisc only: sandbox UI no longer exposes mode selection and demo point clouds / vertex visualization are fixed to FlatDisc (src/Apps/Sandbox/main.cpp).
Updated mesh/mesh-rendering paths to assume only flat-disc vertex views where appropriate and adjusted vertex normal usage to be safe when advanced splat modes are absent (src/Runtime/Graphics/Passes/Graphics.Passes.Mesh.cpp).
Cleaned up component/module comments and feature registry descriptions to remove references to removed splatting modes (src/Runtime/Graphics/Graphics.Components.cppm, src/Runtime/Graphics/Graphics.cppm, src/Runtime/Runtime.Engine.cpp).
Updated unit tests and test expectations to reflect flat-disc-only semantics and the new behavior that non-flat-mode submissions are ignored (tests/Test_PointCloud*.cpp, tests/Test_GraphRenderPass.cpp).
Testing
Ran a repository-wide search to ensure no remaining Surfel, EWA, or GaussianSplat references under src/, tests/, and assets/shaders/ and confirmed removals (rg search; succeeded).
Ran quick sanity checks (reading .md files) to verify documentation references were adjusted (python script reading .md files; succeeded).
Attempted a CMake configure (cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug) to validate build configuration, but configure failed due to network-restricted environment blocking FetchContent (failed fetching external dependency glm from GitHub), so a full build/test run could not be completed in this environment.
Updated and committed the following tests to match the new behavior: tests/Test_PointCloud.cpp, tests/Test_PointCloudRenderPass.cpp, and tests/Test_GraphRenderPass.cpp (tests were adjusted but not executed here due to the configure/build failure).
