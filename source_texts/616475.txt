## Compilation instructions

make a directory called build and use cmake to compile

```
mkdir build
cd build
cmake ..
make -j
./sdfRenderer
```

You can also use the prebuilt executable provided

## Keyboard controls

W, A, S, D, Q, E can be used to move the green sphere around
L can be used to toggle ambient occlusion
K can be used to toggle the area light
the camera can be controlled with the mouse while left click is held

## Editing the scene

Some effects can be changed by editing the `test.frag` shader, this also works with the prebuilt executable

the blending facter for SDF unions can be changed with the `BLEND_FACTOR` constant at the top
the amount of samples used for AO can be changed with the `AOSAMPLES` constant near the top

phong illumination can be used instead by uncommenting the line at the bottom of `main()`

```
    col = color*get_light_info(hit_point, normal);
		//col = phong;
```

To change SDF's and lights this requires editing the main.cpp file and compiling
The SDF's are initialized in the `createScene()` function
The lights's are initialized in the `createLights()` function
