# multi-volume-sdf-raymarching

A Vulkan-based volume renderer for signed distance fields (SDFs) using compute shaders. This project demonstrates multi-volume continuous smooth surface rendering with ray marching, lighting, and ghost voxel border handling to eliminate seams.

# So whats the point
 I feel that SDFs + RayMarching + Radiance Fieldw + Octrees/Grids might all you need for usual GI and good graphics, this was just a begining.


## Features

- **Ray Marching SDF Rendering**: Efficient sphere tracing through 3D SDF volumes.
- **Multi-Volume Grid**: 8x8x8 grid of 3D textures for large-scale scenes.
- **Seamless Borders**: Ghost voxel technique prevents visible cracks at volume boundaries.
- **Directional Lighting**: Simple Lambert diffuse shading with optional soft shadows.
- **Interactive Camera**: FPS-style controls for exploration.
- **Vulkan Compute Shaders**: High-performance GPU-accelerated rendering.

## Requirements

- **Rust**: Install from [rustup.rs](https://rustup.rs/).
- **Vulkan SDK**: Download from [LunarG Vulkan SDK](https://vulkan.lunarg.com/sdk/home).
- **Windows**: Tested on Windows with PowerShell for shader compilation.

## Building

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd vkfrag
   ```

2. Build the shaders:
   ```powershell
   .\build_shaders.ps1
   ```

3. Build and run the application:
   ```bash
   cargo run --release
   ```
   **Note**: The application may take a few minutes to load due to volume data generation and Vulkan initialization.

## Usage

- **Controls**:
  - **Mouse**: Left-click and drag to look around.
  - **WASD**: Move forward/backward/left/right.
  - **Space/Shift**: Move up/down.
  - **Close Window**: Exit the application.

- The application renders a noisy sphere SDF in a 3D grid. Move the camera to explore the volume.

## Project Structure

- `src/main.rs`: Vulkan setup, window management, and volume data generation.
- `shaders/`: GLSL compute and fragment shaders.
  - `volume.comp`: Main compute shader for ray marching and shading.
  - `blit.vert/frag`: Simple fullscreen quad shaders for display.
- `build_shaders.ps1`: PowerShell script to compile GLSL to SPIR-V.
- `Cargo.toml`: Rust dependencies (ash for Vulkan bindings, winit for windowing).

## Technical Details

- **Volume Generation**: Procedural SDF with FBM noise, stored in 3D textures with ghost borders.
- **Rendering Pipeline**: Compute shader dispatches rays per pixel, traces through the SDF grid.
- **Lighting**: Directional light with Lambert diffuse; soft shadows via SDF marching.
- **Optimizations**: Early ray termination, dithered starting points, and boundary blending.
