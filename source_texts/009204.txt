Ray Tracing Acceleration Structures on Mobile Environments
Nuno Guilherme Sousa
[Link]@[Link]
Instituto Superior Técnico, Lisboa, Portugal
May 2018
Abstract
Mobile devices are quickly getting more powerful and more capable of performing computationally
expensive tasks. One of such tasks is Ray Tracing. A lot of research has been done both into the
process of accelerating Ray Tracing using Acceleration Structures, and into the computational power of
GPUs. However, with mobile GPUs having different architectures and limitations, not much research
has been done into the usage of such GPUs in the process of Ray Tracing. Our work tries to fill this
void by providing a performance analysis not only of Ray Tracing as a whole, but also the specific
performance of different Acceleration Structures and different techniques. As such, we implemented
an Android Application using OpenGL ES capable of Ray Tracing different scenes, applying several
Acceleration Structures and rendering techniques. This application was then used to gather results,
using measurements both provided by the application itself and third party tools. The gathered results
led us to conclude that, currently, mobile environments seem to favour Acceleration Structures that
use reduced memory bandwidth and ALU usage. We also concluded that using a Hybrid Rendering
Technique seems to be the best approach for current hardware.
Keywords: Ray Tracing, Acceleration Structures, Mobile Environment, Android, OpenGL ES

What role do acceleration structures play in ray tracing, and why are KD-Trees and BVHs considered state of the art in this context?
Acceleration structures in ray tracing are crucial for minimizing computational time by reducing the number of ray-primitive intersection tests, which is the most computationally intensive task. KD-Trees and BVHs are considered state of the art because they efficiently organize and subdivide the space, allowing for faster traversal and intersection testing. Both use the Surface Area Heuristic (SAH) to optimize their performance by selecting suitable splitting points during construction, maximizing the efficiency and speed of ray tracing .
Why might the KD-Pushdown traversal algorithm perform poorly compared to other traversal methods in complex scenes?
KD-Pushdown traversal algorithm tends to perform poorly in complex scenes because it results in increased ALU instructions per fragment and higher memory bandwidth usage. The algorithm involves more traversal steps due to the high number of nodes in KD-Trees, necessitating additional node traversals and memory accesses, which reduces efficiency. This inefficiency is exacerbated in complex scenes where the traversal demands are higher, leading to possible performance bottlenecks .
What benefits do BVH Trail traversal methods have over KD-Tree based traversal methods in complex ray tracing scenarios?
BVH Trail traversal methods have benefits over KD-Tree based methods in complex ray tracing scenarios primarily due to their efficiency in handling multiple levels of scene complexity with fewer node traversals and lower memory bandwidth requirements. BVH structures generate fewer nodes compared to KD-Trees, and the BVH Trail method efficiently manages traversal through complex geometries by avoiding excessive memory accesses, thus increasing performance. These factors contribute to BVH Trail's ability to maintain faster rendering speeds in complex scenes compared to more bandwidth-heavy KD-Tree traversal methods .
What specific challenges do mobile environments pose for ray tracing, and how do tile rendering and OpenGL ES potentially offer solutions?
Mobile environments pose challenges for ray tracing due to constraints like power draw limitations, reduced memory bandwidth, and heat dissipation issues. These limitations affect computational power and resource availability. Tile rendering offers a potential solution by organizing rendering operations more efficiently to optimize memory usage and bandwidth. Additionally, using OpenGL ES allows for leveraging existing hardware and software optimizations specifically designed for mobile environments, potentially compensating for some of the architectural compromises inherent to mobile devices .
How does the choice of intersection and traversal costs in the SAH-based construction of acceleration structures affect their performance?
In SAH-based construction, setting the intersection cost higher than the traversal cost typically enhances performance. This choice encourages the algorithm to prefer splitting scenarios that minimize intersection tests rather than traversal steps, favoring efficient navigation through nodes. The balance of these costs influences how finely an acceleration structure is subdivided and impacts both the overall computational efficiency and resource utilization during ray tracing. Keeping the traversal cost slightly higher than the intersection cost generally yields optimal results across various scenarios .
Explain how modifying primitive layouts can impact performance in shader execution for different scene complexities.
Modifying primitive layouts can significantly impact shader execution performance by altering memory bandwidth usage and fetch efficiency. In more complex scenes, a split layout where vertices and normals are stored separately allows for higher memory efficiency, as unused normals do not consume bandwidth. This can lead to faster shader execution due to fewer required memory fetches for relevant data, especially in high-complexity scenes where access frequency to scene geometry increases. These optimized layouts enhance rendering performance by aligning memory access patterns with computational demands .
Discuss the trade-offs between storing primitives in a compact versus split layout for shader storage buffer objects in ray tracing applications.
The trade-offs between storing primitives in compact versus split layouts in shader storage involve memory usage versus retrieval efficiency. A compact layout conserves memory by using extra instruction padding but may introduce complexity and extra instructions for data retrieval, impacting performance. In contrast, a split layout separates data like vertices and normals, which can improve memory bandwidth usage, as bandwidth is not wasted on irrelevant data like normals during intersection tests. This separation can yield better performance, particularly in scenes with high geometric complexity, by reducing memory fetches .
How does the SAH algorithm help in constructing KD-Trees and BVHs, and what assumptions does it make?
The Surface Area Heuristic (SAH) helps in constructing KD-Trees and BVHs by determining the best splitting points for nodes, thereby organizing space more effectively and minimizing ray-primitive intersection tests. It assumes that rays are uniformly distributed in space and not blocked by objects, weighing the costs of traversing nodes against ray-triangle intersections to calculate the total cost. By recursively applying SAH, one can efficiently build these acceleration structures .
Why is GPU-based ray tracing a focus over CPU-based methods in the context of this study, particularly for mobile environments?
GPU-based ray tracing is the focus over CPU-based methods in this study because GPUs are inherently more suited for handling the parallel processing demands typical of ray tracing, enabling more efficient and faster computations. Mobile GPUs, such as the Qualcomm Adreno 540 used in the implementation, offer significant performance advantages in this regard. While the initial study phase included a CPU-based implementation, it was noted to be less optimized and served primarily as a performance baseline, highlighting the superiority of GPU processing for real-time applications on mobile platforms .
In what ways does memory bandwidth affect the performance of KD-Tree and BVH algorithms on mobile devices?
Memory bandwidth significantly impacts the performance of KD-Tree and BVH algorithms on mobile devices because these structures dictate how memory is utilized during node traversal. KD-Trees, which often have more nodes, require more memory fetches, leading to potentially higher memory bandwidth usage. In contrast, BVHs can perform better in this aspect due to fewer node traversals. Effective memory bandwidth usage is critical because mobile platforms have restricted memory and bandwidth capabilities, making it essential to optimize these aspects for better performance .
