Suppose I have a 2D-surface embedded in a 3d-volume for example the surface of a sphere,
which is defined by r² = x² + y² + z². Now I want to calculate the volumes generated by the cut of this surface within a cube. As an example see this image 
 
 So in this case one volume would be simply V = 4/3 πr³/8 = π/8 ~ 0.5239,
 what would be a fast way to calculate this numerically with high accuracy? 
My first idea was to use a simple monte-carlo method which seems to work but is not fast enough since I have to repeat this procedure for around 1000 cubes. For example: 
 import numpy as np

def get_pi(n):
    k = 10000
    m = n/k
    result = 0
    for i in range(m): #split up n to save memory
        x = np.random.rand(k)
        y = np.random.rand(k)
        z = np.random.rand(k)
        r = np.sqrt(x**2+y**2+z**2)
        t = r<1
        result += np.sum(t)/float(k)*6
    result /=m
    return result
