Repair
Plane splitting now honors all option combinations, including None, and constructs only requested-side lists and results. Indexed face data is compacted through each retained/generated face's original attribute index. Direct corner ranges use the retained-face count, preserving face-local interpolation and seams across shared cut vertices.
Whole-side checks use direct height scans rather than allocating predicates and invoking a delegate per vertex. Existing whole-side identity, tolerance/coplanar ownership, winding, and source immutability are preserved. Grouping, topology, and ClipByPlane cap generation are unchanged.
Evidence
209 regressions, including the original quad failures, retained-only/mixed faces, attribute layouts, edge seams, and 180 seeded convex polygons across all options.
651 tests pass in both Release and Debug, with 2 existing skips. Split dispatch and all three attribute-projection methods have complete line/branch coverage.
For 65,536 attributed crossing quads, a negative-only request takes 69.128 → 30.549 ms and 72,882,712 → 47,028,400 B. The baseline is its working two-sided-plus-discard workaround; the old one-sided API throws.
The corresponding valid two-sided path measures 70.189 → 69.199 ms. Whole-side classification is faster. Other two-sided cases show small changes in both directions; all slower samples, identical-binary controls, and the initial repair's timing anomaly remain published.
Complete tables, raw samples, benchmark sources, and methodology

Honor None and one-sided options without building discarded-side faces or
vertices. Keep shared cut-point storage for either requested side and reuse
cut vertices along indexed edges. Preserve whole-side mesh identity and the
existing tolerance and coplanar ownership rules.

Build compact indexed face-value maps from source attribute indices used by
both retained faces and fragments. Append exactly the generated face count
and inherit each fragment's original face attribute. Copy direct corner
ranges using the retained-face count, preserving interpolation parameters
on each original edge and discontinuities across shared geometric edges.

Use direct height scans for whole-side classification to remove predicate
closures and per-vertex delegate dispatch. Remove unused split-point reads,
an unused count, and redundant tuple dispatch without changing public APIs.

Add 209 regressions covering options, typed attribute layouts, retained and
cut faces, shared-edge seams, empty and coplanar inputs, tolerance boundaries,
source immutability, and seeded clipping/area/winding oracles. Document the
plane-splitting contract separately from grouping, topology, and cap generation.
