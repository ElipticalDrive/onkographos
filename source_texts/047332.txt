#  3D Brain MRI Volume Renderer

An interactive 3D volume rendering tool for brain MRI data, built entirely in Python using VTK, NiBabel, and NumPy. Explore internal anatomical brain structures in real time — cortical folding, deep white matter, subcortical regions — directly from a raw MRI volume, with no segmentation mask needed.

## Features

- GPU-accelerated ray-cast volume rendering via VTK
- Real-time interactive cropping along X, Y, and Z axes
- Intensity clipping to isolate tissue layers
- Transfer function manually calibrated to actual voxel spacing (0.781 mm x 2.0 mm x 0.781 mm)
- Gradient opacity for sharp anatomical edge definition
- FXAA anti-aliasing and 8x multisampling for clean output
- Fully local — no cloud dependency, no segmentation mask required
- Runs on any standard Windows/Linux machine with a GPU
