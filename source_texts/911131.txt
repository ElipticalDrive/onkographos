Implements a "Chromatic Ferrofluid Refraction" portfolio frontend using React Three Fiber with a full raymarching pipeline in GLSL. No pre-made assets—100% code-generated visuals.
Raymarching Shader (src/shaders/ferrofluidShader.js)
SDF scene composition: Mandelbulb fractal + Gyroid minimal surface + metaball blending
Lighting: Procedural IBL, volumetric god-rays, soft shadows, multi-sample AO
Material: High-index refraction (IOR 2.42), chromatic dispersion, mercury/chrome reflectance
Interaction: Shape mutation via mouse uniforms, camera rotation
```
// Core SDF with fractal interpolation
float sdfScene(vec3 p) {
  float metaballSurface = metaballs(rotatedP, time);
  float gyroidPattern = gyroid(rotatedP + vec3(time * 0.1), 4.0, 0.03);
  float fractal = mandelbulb(mandelbulbP, power) / 1.5;
  
  float surface = smax(metaballSurface, -gyroidPattern * 0.5, 0.1);
  return smin(surface, fractal * 0.8, 0.2 * blendFactor);
}
```
R3F Scene (src/components/)
FerrofluidScene: Custom shaderMaterial with real-time uniform updates
PostProcessing: Bloom, ChromaticAberration (mouse-speed reactive), Noise, SMAA, ACES tonemapping
GlitchText: Character scrambling on hover with progressive resolution
Stack
React 19 + Vite
@react-three/fiber, @react-three/drei, @react-three/postprocessing
256-step raymarching, no optimization per spec
