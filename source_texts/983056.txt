Pull request overview
This PR expands Babylon-Lite’s Gaussian Splatting support to handle SPZ and SOG containers, compressed/chunked PLY, and view-dependent spherical-harmonics (SH) shading. It adds new lab scenes and Playwright parity tests to compare Lite output against Babylon.js reference renders, while keeping bundle-size impact contained via dynamic imports.
Changes:
Added SH-capable Gaussian Splatting render pipeline (dynamic-imported only when SH is present).
Added new loaders for SOG (zip + WebP) and SPZ (gzip/binary), plus compressed-PLY (+SH) parsing.
Added new parity scenes/tests (122–124) and updated scene config + bundle manifests.
