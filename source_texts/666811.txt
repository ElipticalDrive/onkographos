First slice of roadmap S6 (parent #389, tracking #408): a froxel (frustum-voxel) unified volume march (Frostbite / Hillaire 2015). Today's volumetrics are a per-surface single-scatter ray march (#388); a froxel volume LUT unifies fog across all 3D types and gives the temporal stability animated fog needs.
What landed
FroxelGrid (Engine/Rendering/Lighting/FroxelVolume.cs) — camera-frustum froxel resolution + exponential near-dense depth-slice distribution (depth = near·(far/near)^(z/dim)), SliceThickness, and an invertible DepthToSlice for depth-indexed compositing.
FroxelIntegrator — energy-conserving front-to-back scattering integration of a froxel column (Hillaire slice accumulation: per-slice T = exp(-σ·d), in-scatter ∫ scatter·T = scatter·(1-T)/σ with the σ→0 limit, accumulated by running transmittance) → per-slice (in-scatter, transmittance), plus a depth Sample that interpolates the integrated column.
Pure math, no device state / RNG → --batch-identical + a twin for a future GPU froxel pass. Existing volumetric path untouched → default renders unchanged.
Verification
Server.Tests/FroxelVolumeTests.cs (6) — exponential + monotone depth, DepthToSlice inverts + clamps, empty column fully transparent, uniform-medium far transmittance == exp(-σ·distance), in-scatter accumulates monotonically, sample interpolates + clamps. All green. Engine builds clean.
Honest scope
The grid + integration + sampling primitives are here. Populating the 3D volume (density × phase × per-light in-scatter, reusing AddVolumeScatter/#388), compositing the beauty against the LUT by depth, and temporal reprojection are the integration follow-ups.
Follow-ups (tracked in #408)
Populate + composite the 3D froxel volume (gate so no-fog scenes are byte-identical); temporal reprojection via Scene Engine (additive, gated); GPU froxel compute pass diffed against the CPU column integrator; unify the existing per-surface march through the LUT; UI.
Non-goals: multiple-scattering / full RTE solve; adaptive/sparse froxel structures — the uniform frustum grid is the scope.
