Use the 3D Texture SDF node to generate signed distance field textures from 3D data for creating smooth shapes and effects.

Description
The 3D Texture SDF node generates the signed distance field of a shape from the Input’s 3D texture mask representing the slices of the shape’s volume.
Inputs
Mask Input GrayscaleThe 3D texture mask representing the slices of a shape’s volume.
Parameters
Threshold FloatWhen the shape volume is described by a fading gradient, sets the gradient value at which the surface of the shape is detected.
Output IntegerThe type of distance field which should be output:
- Distance Field: outputs a distance field describing the distances outside the shape.
- Signed Distance Field: outputs a distance field describing the distances outside (positive) and inside (negative) the shape.
