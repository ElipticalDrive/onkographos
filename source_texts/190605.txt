Summary
This PR adds two major geometry processing algorithms to the kernel:
Marching Cubes — Isosurface extraction from scalar fields on regular 3D grids
Surface Reconstruction — Point cloud to triangle mesh conversion via implicit surface methods
These algorithms enable volumetric processing workflows and are foundational for many geometry applications.
Key Changes
Marching Cubes Implementation
Geometry.MarchingCubes.cppm — Public interface defining ScalarGrid (regular 3D grid of scalar values), MarchingCubesParams, and MarchingCubesResult structures
Geometry.MarchingCubes.cpp — Core implementation (645 lines):
Standard lookup tables from Lorensen & Cline (1987): edge table (256 entries) and triangle table (256×16 entries)
Per-cube isosurface extraction with 8-bit vertex classification
Linear interpolation for intersection point positioning on edges
Gradient-based normal computation via central differences
Vertex welding — Edge-based deduplication ensures shared vertices between adjacent cells are created once, producing watertight meshes without duplicates
Optional normal computation and configurable isovalue
Conversion to halfedge mesh via ToMesh()
Surface Reconstruction Implementation
Geometry.SurfaceReconstruction.cppm — Public interface with ReconstructionParams and ReconstructionResult
Geometry.SurfaceReconstruction.cpp — Complete pipeline (263 lines):
Validates input point cloud (minimum 3 points)
Normal estimation via PCA + MST orientation (if not provided)
Octree spatial indexing for efficient nearest-neighbor queries
Signed distance field computation:
Nearest-point method: d(g) = dot(g - p_nearest, n_nearest)
Weighted k-NN method: Inverse-distance weighting over k neighbors for smoother results
Regular grid generation with configurable resolution and bounding box padding
Marching Cubes integration for isosurface extraction at zero level-set
Halfedge mesh conversion
Testing
Test_SurfaceReconstruction.cpp — Comprehensive test suite (577 lines):
Marching Cubes: invalid/empty grids, sphere SDF, plane SDF, normal computation, vertex positioning, resolution scaling, custom isovalues, vertex welding validation
Surface Reconstruction: input validation, sphere reconstruction with provided/estimated normals, parameter variations, mesh topology (Euler characteristic)
ScalarGrid utilities: validity checks, access/set operations, position computation
Helper functions: Fibonacci sphere sampling, analytical normal generation, SDF grid creation
Integration
Updated CMakeLists.txt to include new source files
Updated Geometry.cppm to export new modules
Updated README.md and CLAUDE.md documentation
Notable Implementation Details
Lookup tables: Standard 256-entry edge and triangle tables ensure correctness and performance
Vertex welding strategy: Uses edge keys (axis + grid-vertex origin) to uniquely identify shared edges, eliminating duplicate vertices while maintaining mesh connectivity
Gradient computation: Central differences on the scalar field provide smooth normal estimates
Spatial indexing: Octree with configurable split policy and depth enables efficient k-NN queries for large point clouds
Robustness: Comprehensive input validation, epsilon handling for numerical stability, degenerate case detection
Flexibility: Supports both single-neighbor (fast) and k-NN (smooth) signed distance methods; optional normal estimation

Hoppe et al., "Surface Reconstruction from Unorganized Points", SIGGRAPH 1992

Remove negation when emitting Marching Cubes normals
For scalar fields that follow the standard signed-distance convention (inside < iso, outside > iso), the gradient already points from inside to outside, so pushing -grad flips every computed normal inward. This makes ComputeNormals=true produce systematically inverted normals (e.g., spheres), which breaks lighting and any downstream logic that assumes outward-facing normals.
