We were thinking about the gaps that appear sometimes between block faces. We think they can only appear when the vertices are already converted to floats.
But why do we use floats at all? Just send [Vector3<u8>; 4] to the GPU and use vertex pulling. We should try this and compare performance.
And then it's "just" one step from porting the mesh generation code to the GPU. Probably a bit challenging, but might be worth it. We think we should really give this a try (try as more things to see performance differences and improve graphics/GPU coding skills).
