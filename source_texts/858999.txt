Heavy Bug-Fixes, with various tasks:
Look Task no longer render distance dependent (had to do with number of loaded chunks, and non-constant time random access)
Pathfinding issues at the boundary
Build Task leading to non-essential constant remeshing.
Improved meshing significantly, so small changes are done "cheaply" and can be remeshed efficiently later. Also, the meshing method allows for greedy meshing + meshing of blocks which have non-cubic models.
Added octree based world saving, making it much more dense (~14* smaller).
Sprites now cast shadows and adapt to the lighting level. Shadow mapping bias function is finally good and doesn't cause artifacts.
Also added general block properties so that individual blocks are never referenced in the code, just general block properties that are relevant for whatever algorithm. This will hopefully cause less conflicts in the future, and less "manual" case handling.
Other minor bug fixes here and there.
