Aim To implement volume rendering based on texture mapping usually by hardware,its function is implemented by using Java 3D.A virtual heart system was proposed by using Java+Java 3D.Methods After the pre-processing of CT sliced data,image filter,segmentation,registration and clip,The texture mapping is implemented by programming,and finally the three-dimensional visualization of heart is presented.Results A virtual heart system was implemented using Java 3D.Especially volume rendering based on texture mapping was implemented by software.Conclusion Rendering based on texture implemented by Java 3D instead of hardware can reduces costs.
