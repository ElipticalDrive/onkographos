Refactor all point shape shaders to use the concept of signed distance functions/fields (SDF).
The currently implemented points should be easy to move over, fill/stroke need a little thought.
Important point to note, currently we have distance functions that are 1 on the boundary, these are what need changing to a genuine sdf.
This issue is a bit of an idea dump, but want to ensure there is enough information.
For a shape/scene its SDF is a function that gives the minimum distance from a point to the boundary of the shape, it is positive outside, and negative inside.
E.g for a circle it would be f(p, r) = length(p) - r, where p is the sample point, and r is the radius.
This would look like this
Lots of SDFs here.
The benefits of SDFs is that they can be composed in various ways, and transforms can be applied
to sample point before feeding it in, this means complex scenes can be constructed.
E.g.
```
float union_(float d1, float d2) {
     return min(d1, d2);   
}

float symDiff(float d1, float d2) {
    return min(max(-d1, d2), max(-d2, d1));
}

float diff(float d1, float d2) {
    return max(-d1, d2);
}

float intersect(float d1, float d2) {
    return max(d1, d2);
}
```
Can also smoothly join shapes, see here.
This should make it easier to properly do fill and stroke too, needs investigating but based on these. Also since we want the background transparent/not there, do we discard fragments or blend to something transparent?
```
float fillMask(float dist) {
	return clamp(-dist, 0.0, 1.0);
}

float innerBorderMask(float dist, float width) {
	float alpha1 = clamp(dist + width, 0.0, 1.0);
	float alpha2 = clamp(dist, 0.0, 1.0);
	return alpha1 - alpha2;
}

float outerBorderMask(float dist, float width) {
	float alpha1 = clamp(dist, 0.0, 1.0);
	float alpha2 = clamp(dist - width, 0.0, 1.0);
	return alpha1 - alpha2;
}
```
See https://www.shadertoy.com/view/4sXBWs, https://www.shadertoy.com/view/4dfXDn (especially useful)
One final benefit is this would enable easier animations/transitions in webgl, i.e. since the scenes are just functions, we could interpolate between them for the transition. https://www.shadertoy.com/view/3tSGDy
Also fonts! https://github.com/Chlumsky/msdfgen

Can do rotational symmetry like this.
```
float box(vec2 p, float a, float b) {
    vec2 d = abs(p) - vec2(a, b);
    return length(max(d, 0.0)) + min(max(d.x, d.y), 0.0);
}

vec2 rotSymPoint(vec2 p, int n) {
    float an = 3.141593 / float(n);
    float bn = mod(atan(p.x, p.y), 2.0 * an) - an;
    return length(p) * vec2(cos(bn), abs(sin(bn)));
}

float rotSymBox(vec2 p, float a, float b, int n) {
    return box(rotSymPoint(p, n), a, b);    
}
```
