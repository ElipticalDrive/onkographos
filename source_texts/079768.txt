Scientific visualization systems normally use keyboard or mouse as input devices and desktop screens or printers/plotters for output. virtual Environment systems, on the other hand, use devices like glove or head mounted display and a number of software techniques in order to achive realistic, immersive real-time graphics. This paper discusses the techniques used for Virtual Environments and investigates possibilities to construct systems that use Virtual Environment techniques for Scientific Visualization. Several examples are given of Immersive Scientific Visualization
