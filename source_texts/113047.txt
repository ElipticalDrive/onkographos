What
S9 — mesher selector (3D-Rendering-Roadmap §S9, Refs #391 #389). Dual contouring (#446) shipped reachable only through the exporter API. Expose it so the user can choose the isosurface mesher on the export panel: Marching Cubes (smooth, default) or Dual contouring (keeps hard creases sharp — Mandelbox facets, KIFS corners).
How
New MeshingMode enum (Abstractions) shared by the snapshot and the UI args.
UserBulbViewModel.ExportMeshingModeIndex (combo index) + ExportMeshingMode (enum), persisted per bulb via UserBulbSnapshot.ExportMeshingMode (nullable → older snapshots default to Marching Cubes). Carried on MeshExportEventArgs.MeshingMode.
AvaloniaShellBootstrap UserBulb export switches to ExportDualContouring when selected (else ExportMarchingCubes); colour + print-readiness ride both paths.
"Mesher:" combo on the UserBulb export panel; the Crease / SS / Seal-box-faces knobs are now noted as Marching-Cubes-only in their tooltips.
Tests
UserBulbExportSnapshotTests: the mode round-trips through JSON; an older snapshot reads as null (default MC). DC/MC geometry is covered by DualContouringTests / McMeshValidationTests. Suite 1646/1646.
Remaining S9
DC boundary cap, orbit-trap MC colour driver, weld-based manifold auto-repair.
