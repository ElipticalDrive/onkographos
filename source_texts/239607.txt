get_burn_area_interpolator meshes the burn-area iso-surface on np.ma.filled(regression_map, max_iso_level + 1.0) (machwave/models/grain/fmm/_3d.py:374-376), lifting every masked casing cell above every iso level. The comment states this makes marching cubes "mesh only the burning front, not the wall", which holds only while the propellant next to the casing is still unburned. Once a cell adjacent to the casing has been consumed, the step from that burnt-out cell up to the fill value is itself a level crossing, and marching cubes meshes it as casing wall and adds it to the burn area.
With the default inhibition (casing inhibited, both end faces exposed) propellant is burnt back from each end face, so the band of exposed casing grows as 2 * pi * outer_diameter * web_distance.

The reported curve is reproduced to within 0.7% by "analytic + 2piouter_diameter*web", which is exactly the casing area over the band burnt back from the two end faces.
Swept-volume consistency on the same segment (regression is uniform, so the integral of burn area over the web must equal the propellant volume):
```
integral(get_burn_area dw, 0..web_thickness) = 2.535e-3 m^3
actual propellant volume                     = 2.135e-3 m^3   -> 1.187x
```
Burn area feeds the chamber pressure mass balance directly, so chamber pressure, thrust and total impulse are inflated by a comparable margin and the tail-off never fully collapses. Every existing 3D burn-area test inhibits the outer surface and both end faces, the one configuration with no exposed casing, so none of them sees this. examples/finocyl_motor.py runs the default inhibition.
Fix: stop the masked fill from creating a level crossing against already-burnt cells. Fill masked cells by nearest-neighbor extension of the adjacent regression value, or mesh with the casing filled below every level and subtract the resulting boundary area, or drop meshed faces whose centroid lies on the masked boundary. Add a swept-volume check to the 3D test set.
Distinct from #402 and #451, which addressed the opposite error (a fixed rim exclusion that discarded real burning front near the wall); the lift-the-mask strategy that replaced it over-counts instead.
