Implement Deterministic Noise Engine and fractal_clouds Layer Renderer
Summary
Implement a deterministic multi-octave Fractal Brownian Motion (fBm) Perlin/Simplex noise generator and the FractalCloudsLayerRenderer (type = fractal_clouds) used by layer1 in number.gfx.
Technical Specification
1. .gfx Syntax Example (number.gfx)
```
  layer1 = {
    type = fractal_clouds
    color = color_ramp(NAMED_COLORS.WHITE, NAMED_COLORS.BLACK)
    mix = multiply
    size = output.dimensions
  }
```
2. Deterministic Noise Engine (GfxStudio.Core.Noise)
Implement 2D, 3D, and 4D gradient noise (Perlin / OpenSimplex2S) initialized with a 256-entry permutation table shuffled deterministically using the layer's GfxRandom instance.
Implement Fractal Brownian Motion (fBm) combining multiple octaves of noise:
$$\text{fBm}(x, y, z) = \frac{\sum_{i=0}^{\text{octaves}-1} \text{amplitude}_i \cdot \text{Noise}(x \cdot \text{freq}_i, y \cdot \text{freq}_i, z \cdot \text{freq}i)}{\sum{i=0}^{\text{octaves}-1} \text{amplitude}_i}$$
Normalize output values to [0.0, 1.0] so they map cleanly across the full span of color_ramp(...).
3. fractal_clouds Layer Properties
color (optional, defaults to color_ramp(NAMED_COLORS.WHITE, NAMED_COLORS.BLACK)): GfxColorRamp (or GfxColor) used to map normalized noise value v in [0, 1] to an RGBA pixel via colorRamp.Sample(v).
size (optional, defaults to output.dimensions): Dimensions.
scale / frequency (optional float, default 4.0 per canvas dimension or pixel scale 0.05): Controls cloud feature size.
octaves (optional int, default 5, clamped 1..12): Number of fractal detail octaves.
persistence / gain (optional float, default 0.5): Amplitude multiplier per octave.
lacunarity (optional float, default 2.0): Frequency multiplier per octave.
phase / z (optional float, default 0.0): 3rd-dimension offset for animating evolving clouds over time (phase = frame.progress * 2.0).
loop_seamless (optional bool, default false): When true, maps phase (0..1) onto a 4D circle $(\cos(2\pi t), \sin(2\pi t))$ in 4D noise space for seamless looping GIF animations!
Tasks
Implement PerlinNoise / SimplexNoise and FractalBrownianMotion in GfxStudio.Core.Noise seeded via GfxRandom.
Implement FractalCloudsLayerRenderer : ILayerRenderer writing directly to SKBitmap pixel spans (GetPixelSpan()) for high-performance generation.
Support color_ramp mapping (color_ramp(NAMED_COLORS.WHITE, NAMED_COLORS.BLACK)), optional octaves, scale, persistence, lacunarity, phase, and loop_seamless.
Write unit tests in GfxStudio.Tests/Rendering/FractalCloudsLayerRendererTests.cs verifying determinism (same seed = identical pixel buffer; different seed = different buffer) and color_ramp mapping.
Acceptance Criteria
layer1 from number.gfx renders a 64x64 grayscale fractal cloud texture spanning white-to-black and composites onto layer0 via mix = multiply.
Rendering fractal_clouds twice with the same seed produces byte-for-byte identical pixel data.
Setting loop_seamless = true and animating phase from 0.0 to 1.0 produces identical start (0.0) and end (1.0) frames for seamless GIF loops.
