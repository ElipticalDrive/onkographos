Summary
Adds a FogSettings component (colour, FogMode exponential-squared/linear, density/start/end) plus Renderer3D.SetFog/DisableFog, following the opt-in shape SetShadowMap/DisableShadows and SetEnvironmentMap/DisableIBL already use — including the "clear stale state" branch in MeshRenderSystem so a shared renderer doesn't leak fog into a scene that doesn't want it.
Fog is applied in both the PBR and Blinn-Phong shading branches, after lighting and emissive, before the alpha write, so opaque, transparent, and additive surfaces at the same depth fog consistently.
Exponential-squared is the default mode; linear start/end is available for authored control.
The skybox is left unfogged for this first cut, per the discussion on the issue.
Fog colour is a plain Color field — day/night coupling (warm at the horizon, cool at night) is left to the caller (e.g. alongside TimeOfDay), not baked into the renderer.
Defaults off: a world with no FogSettings entity calls DisableFog, so every existing scene renders unchanged.
Registered with ComponentRegistry.RegisterEngineComponents() (FogSettingsSerializer, type id "FogSettings"), so it round-trips through prefab/scene JSON.
New docs page: docs/fog.md, linked from docs/index.md and CLAUDE.md.
Closes #217.
