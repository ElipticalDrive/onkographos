Add Spherical Beta view-dependent color with diffuse/specular separation and PLY export
Adds support for Spherical Beta (SB), the view-dependent color model from
Deformable Beta Splatting
(Liu et al., SIGGRAPH 2025). SB replaces the higher SH bands with a few explicit
specular lobes, matching or beating SH quality with far fewer per-splat values —
2 lobes (12 floats) against SH bands 1–3 (45 floats).
Trainers write the lobes to PLY as sb_params_* columns; this makes SuperSplat
read, render, edit and re-export them. Files without those columns are
unaffected — SB is detected per-file and every shader path sits behind
#if SB_LOBES > 0.
Rendering
sb-utils.ts packs the lobes into an RGBA32F atlas (2 texels per lobe, indexed
by splat.index); evalSB in the splat shader adds them to the SH color:
```
C += sum_l pow(max(dot(dir, lobeDir_l), 0), 4 * exp(beta_l)) * softplus(rgb_l)
```
SH evaluation is untouched and the two share one view direction, so a file may
carry either model or both.
UI
SB lobes slider beside the existing SH bands slider.
Color mode selector (Full / Diffuse / Specular), reproducing the paper's
light decomposition. Diffuse compiles out both view-dependent terms; Specular
substitutes the background for the band-0 term so splats with no
view-dependent energy blend away.
Export
splat-serialize.ts writes sb_params_* back out, handling the parts that
aren't a passthrough:
Mixed lobe counts on merge — columns are channel-major
(sb_params_{channel * lobes + lobe}), so fewer-lobe sources need index
remapping, not copying.
Absent lobes — 0 isn't neutral (softplus(0) ≈ 0.1 would add a visible
specular term), so they're padded with a raw value that activates to zero.
Baked transforms — a lobe is a direction, so rotation applies to it
directly. The SB analogue of the existing SH rotation, and much cheaper.
maxSBLobes export setting mirrors maxSHBands.
Compatibility
Lobes are additive properties; the standard f_dc_* / f_rest_* schema is
untouched, so viewers without SB still load the file and render the diffuse
base. A sb_params_* count that isn't a whole number of lobes, or exceeds the
supported count, is rejected with a warning rather than partially read — a
partial read would misinterpret one channel as another.
Notes for review
SB_MAX_LOBES is 2, covering the paper's configuration. It bounds the shader
loop and atlas size, not the model; raising it is a one-line change.
The > 0 in #if SB_LOBES > 0 is deliberate: PlayCanvas's preprocessor treats
bare #if NAME as #ifdef NAME, so a 0-valued define would still be taken.
Locale strings added for all nine supported languages.
