Overview
Before this PR the Standard shader used:
Blinn-Phong is the primary lighting technique used and is blended with Fresnel and image-based lighting to approximate physically based lighting. (Source)
To improve the accuracy and results of the standard shader we are adopting roughly the same PBR rendering methods used by Unity's Universal Render Pipeline. Adopting Unity's lighting pipeline with the built-in system was previously impractical due to how expensive it is for mobile stereo headsets. URP has made vast improvements in this domain.
Using RenderDoc you can compare the account of instructions between a lit material with specular, reflections and using spherical harmonics (direct and indirect lighting) in the old and new implementation:
```
Graphics Tools/Standard before: 105 instructions 1 texture sample
Graphics Tools/Standard after: 68 instructions 1 texture sample
```
Instructions don't always equal cost, but you can roughly reason that the shader is now simpler and has improved lighting quality.
From a quality standpoint we now see more accurate specular reflections on smooth non-metallic surfaces (bottom left of the matrix) and improved Fresnel lighting.

Breaking changes
Removed refraction support (since it was not accurate, and I don't think it many people used it).
Spherical harmonics requires the surface to be lit. (If this is an issue, we can look at changing this).
Changes
Fixes: Port Graphics Tools-Unreal's lighting model to Unity #16
Note initially I tried porting the Graphics Tools for Unreal lighting model to Unity. It worked but didn't look quite the same and was more expensive that URP's lighting model. With that info in had I decided to not unify the lighting models and stick with Unity's lighting algorithms.
