# NUAA-Computer-Graphics-Survey

南京航空航天大学计算机图形学综述作业：围绕新视角合成（Novel View Synthesis, NVS），梳理从神经辐射场（NeRF）到 3D Gaussian Splatting（3DGS）的神经渲染技术路线，包含英文综述论文、LaTeX 源码、参考文献和图表材料。

## 基本信息

- 课程：计算机图形学
- 作业：综述作业
- 论文题目：*Neural Rendering for Novel View Synthesis: From NeRF to 3D Gaussian Splatting*
- 作者：丁俊泽
- 学校：南京航空航天大学
- 指导教师：魏明强老师

欢迎感兴趣的同学点点 star！

## 项目内容

本项目以文献综述和 LaTeX 论文写作为主要内容，从场景表示、任务设置与系统改进三个角度组织新视角合成方法，并讨论画质、速度、内存和可控性之间的取舍。

- **技术基础**：相机与射线参数化、体渲染、采样、反走样、编码与优化，以及 Gaussian Splatting 的渲染过程。
- **场景表示**：辐射场、面向表面的隐式表示、显式高斯表示，以及表示方式对几何、编辑和资产导出的影响。
- **任务设置**：静态与动态新视角合成、稀疏视角、几何重建、逆渲染与重光照、编辑控制和 SLAM。
- **方法改进**：整理 NeRF、Mip-NeRF、Mip-NeRF 360、Instant-NGP、3DGS、4DGS 等相关路线中的质量、效率、压缩和动态场景扩展。
- **对比分析**：通过分类图、时间线、渲染流程图和对比表格总结代表性方法的特征与评价维度。

## 阅读方式

直接打开根目录的 [综述论文 PDF](162330318+丁俊泽+计算机图形学综述作业.pdf) 即可阅读完整作业。章节源码、图表和参考文献位于 `代码文件/`，便于学习论文组织和 LaTeX 排版。

## 编译环境

- LaTeX 环境：TeX Live 或 MiKTeX
- 编译工具：pdfLaTeX、BibTeX、latexmk
- 主要模板与宏包：IEEEtran、amsmath、hyperref、algorithm、algpseudocode、TikZ、PGFPlots、forest、subfig、booktabs、tabularx、adjustbox 等

## 编译方式

在仓库根目录进入 `代码文件/` 后编译：

```bash
cd "代码文件"
latexmk -pdf -interaction=nonstopmode -halt-on-error 0_main_TPAMI.tex
```

latexmk 会自动处理参考文献和交叉引用所需的多轮编译，生成 `代码文件/0_main_TPAMI.pdf`。

也可以手动运行：

```bash
pdflatex -interaction=nonstopmode -halt-on-error 0_main_TPAMI.tex
bibtex 0_main_TPAMI
pdflatex -interaction=nonstopmode -halt-on-error 0_main_TPAMI.tex
pdflatex -interaction=nonstopmode -halt-on-error 0_main_TPAMI.tex
```

使用在线 LaTeX 编辑器时，可将 `代码文件/` 内的源码、参考文献、模板和图表一起导入，并将 `0_main_TPAMI.tex` 设为主文档，使用 pdfLaTeX 编译。
