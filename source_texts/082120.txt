# Parallel Volume Rendering with Binary-Swap Compositing

## Overview
This project implements **parallel volume rendering** of 3D scalar fields (e.g., Isabel Hurricane dataset) using **MPI**.  
The dataset is divided among multiple processes for **ray casting**, and results are combined using a **binary-swap image compositing algorithm** to achieve scalable scientific visualization.

## Features
- **3D Data Partitioning**: Splits volumetric data into sub-blocks across processes.  
- **Ray Casting Renderer**: Performs front-to-back compositing with user-defined step size.  
- **Transfer Functions**: Maps scalar values to RGB and opacity via interpolation.  
- **Binary-Swap Compositing**: Efficient parallel image merging across MPI ranks.  
- **Performance Analysis**: Logs timing of ray casting, compositing, and load imbalance.

## Requirements
- C++11 or later  
- MPI (e.g., OpenMPI or MPICH)  
- `stb_image_write.h` (for PNG export)
