Reproduced on main 560e45f0d3e3735b543423a9599f1ff1ca296287.
Transform.from_look_at derives camera width from the cross product of the viewing direction and world up (0, 0, 1). An exactly upward or downward view makes that product zero, and normalization produces NaNs in the rotation matrix.
```
import numpy as np
import visu3d as v3d
tr = v3d.Transform.from_look_at(
    pos=np.zeros(3), target=np.array([0., 0., 1.]))
print(tr.R)  # NaNs in the first two columns
```
Use a deterministic alternate up axis in this collinear case, leaving ordinary orientations unchanged. World y supplies a valid frame for either pole. Roll is otherwise unspecified at a pole; this is a convention rather than a guarantee of globally smooth roll. Coincident position/target inputs are outside this fix.
Nine regressions verify poles, translated origins, mixed batches, proper rotations, inverse composition, JAX JIT/finite autodiff output and a PyTorch gradient pass. A broader local run has 47 PyTorch batching failures that also reproduce on unchanged upstream with identical node IDs; those are separate.
