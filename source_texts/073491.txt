```
<scene version="2.0.0">

			<translate y=".48"/>

	</shape>

	<sensor type="perspective">
```

Could you maybe just blend the volume parameters and then render the volume that has already been blended? Alternatively, you would need to extend volpath to be able to keep track of a list of volumes, and then evaluate them all jointly. We don't plan to support this in the near future, since handling overlapping volumes introduces quite a bit of complexity to the code for a more niche use case. I am closing this issue for now
