Motivation
Provide a modern GPU showcase effect that demonstrates signed-distance-field raymarching and fractal geometry in a single, self-contained effect.
Allow audio-reactive visuals and timeline-driven quality/ camera parameters while falling back to the existing CPU fractal when WebGL isn't available.
Description
Add src/renderer/effects/raymarchFractal.ts implementing a fullscreen-quad WebGL fragment shader (inline GLSL) that raymarches SDFs, supports Mandelbulb (default) and Mandelbox fractals, estimates normals, and applies diffuse/ambient/specular/rim lighting and fog; MAX_STEPS is 120 by default and quality scales the step count.
Create TypeScript plumbing for lazy WebGL init, shader compile/link, a single quad buffer, uniform setting (time, resolution, audio features, quality, camera/fractal params), and a fallback to the existing FractalEffect when WebGL is unavailable.
Register the effect in src/renderer/effects/index.ts as raymarch_fractal and update README.md effect catalog to document available params (quality, fractal, cameraRadius, cameraHeight, cameraOrbitSpeed, paletteSpeed, audioReact, beatKick, fractalScale).
Add src/renderer/effects/raymarchFractal.test.ts and helper validation functions: normalizeRaymarchFractalParams and buildRaymarchFractalUniforms (both exported) to support unit testing and parameter clamping.
Testing
Added unit tests in src/renderer/effects/raymarchFractal.test.ts that validate parameter normalization and uniform mapping and ran them with npm run test; the test run passed (2 tests, 2 passed).
The WebGL path was exercised manually during development (dev server started) but only the unit tests are part of the automated test run described above.
