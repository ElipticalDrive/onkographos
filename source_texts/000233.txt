## Another voxel ray tracing demo

This is another voxel ray tracing demo with much more complex shader. However this complexity may bring significant performance difference on differenct devices or even the same card with different driver.

This demo contains a much better denoiser and partially support multiple objects rendering, but only the main object cast shadows.

## How to run the demo
1. Download Rust toolchain.
2. run `cargo run -r -p main`. Make sure that `-r` is used, because without it, it may take significantly more time to generate the tarrain before rendering.
