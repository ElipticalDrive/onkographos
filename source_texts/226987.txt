Summary
Leaf cards currently retain normals from their individual planes. Add a Foliage Normals Mesh Lab tab that builds a smooth volume proxy from selected foliage faces and transfers its interpolated normals to separate source-mesh clones across all corresponding LODs. Trunk and branch faces, source transforms and imported FBX assets are preserved.
Selecting a mesh also processes its matching renderers in every LOD of the same LODGroup or named sibling chain. Selected submesh numbers follow their material references when LOD material slots are reordered. LOD0 proxy source limits proxy construction while transfer, Apply/Undo and both saves include all matching levels. Preview LOD displays one level at a time. Missing selected materials leave that level untouched; ambiguous mappings fail before any scene or asset mutation.
Smoothing rejects per-component volume ratios outside 50-150%, including expansion of a small shell hidden by aggregate diagnostics. Separate FBX save refuses regenerated tangent frames when the source uses Tangents = None, while normal-only results preserve that import mode. LOD matching does not use a renderer family name that repeats within the selected source level; distinct mesh names can identify the selected part.
Stage pipeline: capture in root-local space → deterministic area scatter → union of sphere primitives through the existing native voxel remesher → Taubin smoothing → isotropic proxy remeshing → nearest-triangle barycentric normal transfer. Remeshing provides target edge length, split/collapse/flip, projected tangential relaxation, triangle budgets, topology validation and uniformity diagnostics. Sphere and open hemisphere normal proxies are also available.
Reuse MeshAccess, RemeshNative, RemeshTopology, MeshGeometry, TriangleBvh, GpuBvh, MeshViewport3D and existing asset helpers. Separate per-renderer snapshots preserve channels and split vertices shared by selected/excluded faces. CPU/GPU transfer reports misses, distances and canonical CPU queries. Apply supports Undo/Redo; save produces separate _FoliageNormals Mesh assets or FBX variants.
Save Separate FBX delegates to the shared atomic SDK document writer with Normals | Tangents intent and an explicit foliage submesh/corner mask. It preserves source control points, polygons (including quads), UV sets/names/precision, vertex colours, material assignments, nodes/transforms and exact excluded FBX normals/tangent frames. Coincident faces of different materials are disambiguated by submesh usage. Only the new importer's shading settings are configured; source FBX/importer bytes and scene references remain unchanged. Requires the optional Unity FBX Exporter and source Normals = Import; ambiguity and unsupported sources fail explicitly.
Add stage invalidation/cancellation and deferred cleanup, shared preview modes and documentation. The hub restores only its owned temporary mesh assignments so applied meshes survive refresh/window close.
Capture validates mesh contents and the current eligible renderer set before applying or saving. Additional vertex streams are refused, transient Apply is blocked in Prefab Mode, and shared-source saves reserve distinct paths before the asset batch. Foliage UV validation ignores excluded triangles; partial FBX exports retain the source tangent import/calculation mode. These review fixes have dedicated regression coverage; gating Sonar findings are corrected without suppressions.
Partial FBX export requires complete, identifiable source-node coverage for shared geometry and rejects failed imports, removing the variant. Generated tangents keep excluded zero defaults when the source has no frames. Shape proxies validate only the active radius setting. Unreadable capture preserves raw attribute formats and streams; UI availability caches mesh fingerprints between change events while Apply and Save always check current source data.

Review Notes
Focus on root-local normal matrices (M.inverse.transpose into capture, M.transpose back), channel-preserving selected/excluded boundary splits, cancellation/disposal and applied-mesh ownership.
Static MeshRenderer write-back only. No alpha-texture sampling, runtime component, dense SDF asset, source FBX overwrite or skin write-back. The envelope uses the existing meshoptimizer voxel backend; no native source or binary is changed by this PR.
Fine pine profiles exposed point/edge contacts in native voxel output. Strict validation rejects these before Transfer. The validated pine profile uses 4% diagonal spacing, radius multiplier 1.6, dedup fraction 0.01, voxel resolution 64 and three Taubin iterations at strength 0.5. This tuning and the backend limitation are documented.
GPU edge/limit/miss hits use CPU BVH canonicalization for parity; this mixed work is counted and timed. Remesh surface-fit checks are sampled rather than a certified Hausdorff bound, and exhaustive self-intersection detection is not provided.
The real pine source uses Mesh Compression Low. Stored excluded FBX normals remain exact; Unity's lossy reimport can requantize normals/tangents when their range changes. Compression settings are inherited and reported with a warning. This is document data preservation, not a guarantee of bit-identical compressed Unity vertex buffers. Mesh Compression can be disabled on the new FBX without changing the source. Calculated-source normals are refused to avoid changing excluded shading when the variant switches to Import.

Invalidate captures when mesh contents change
When a captured Mesh is modified in place between Transfer and Apply—such as by another editor tool, an Undo operation, or an asset reimport—this check still succeeds because it compares only the object reference, transform, and materials. CanApply consequently permits assigning a clone built from the old vertex/index snapshot, silently replacing the renderer's current geometry with stale data. Track a mesh-content fingerprint/version or subscribe to mesh-change invalidation before treating the capture as current.
