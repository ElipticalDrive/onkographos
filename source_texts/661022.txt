# AOShadowLayer for MapLibre GL JS

MapLibre's `fill-extrusion` layer gives you 3D buildings, but they hover above the ground like paper cutouts. **AOShadowLayer** fixes that by merging two cheap, planar techniques -- SDF-based ambient occlusion and projected footprint shadows -- into a single `CustomLayerInterface` that runs in four GPU passes and one screen composite. No shadow maps, no extra cameras, no depth textures. Just drop in a single ES module and your buildings look grounded.

## How It Works

The layer reuses MapLibre's existing fill-extrusion geometry (zero additional uploads) to produce:

- **Ambient occlusion** via Jump Flood Algorithm (JFA) to build a distance field, then exponential falloff for a soft contact shadow.
- **Directional footprint shadows** rendered into a stencil-masked offscreen FBO to eliminate triangle overlap, with a built-in Gaussian blur.
- **Screen-multiply composite** that merges both effects in one blend: `1 - (1-shadow)(1-ao)`.

## Quick Start

```javascript
import { AOShadowLayer } from './ao-shadow.mjs';

const layer = new AOShadowLayer({
  buildingsLayerId: '3d-buildings',
  sourceId: 'openfreemap',
});

map.on('load', () => {
  // add your fill-extrusion buildings layer first, then:
  map.addLayer(layer, '3d-buildings');
});
```

Open [`index.html`](index.html) for a complete working example with interactive sliders.

## Performance

CPU overhead is negligible — typically **0.4–0.6 ms per frame** (under 3% of a 16.6 ms frame budget at 60 fps). The shadow pass is the only measurable cost at ~0.05 ms avg; seed, JFA, and composite are effectively free. Peak spikes of 6–13 ms are caused by browser GC or MapLibre tile decode, not this plugin. Tested at zoom 15–18 with 2–5 visible tiles and 90k–450k triangles per frame.
