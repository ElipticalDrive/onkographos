Part of #568
Read, apply and write .cube LUTs, so a person can use their own look (made in Resolve, bought or exported) and take a grade out of Shaderera.
Read the Adobe/Resolve .cube format: 1D and 3D, TITLE, DOMAIN_MIN/DOMAIN_MAX, LUT_1D_SIZE/LUT_3D_SIZE, with clear errors for a bad file.
Apply in WGSL from a 3D texture with tetrahedral interpolation (trilinear as an option), plus a CPU version that gives the same values (as look-tonemap and render-srgb do: within one 8-bit step, checked on the GPU).
Write a table back to .cube.
The README says the LUT's input and output space are the LUT author's; the plugin does not convert spaces (that is color-spaces).
No LUT ships with the plugin.
Done when: a 33³ LUT read from a file and applied on the GPU matches the CPU within one 8-bit step, read → write → read is identical, and the color-* category is added where plugin categories are listed.
