Optimized Ray Tracing Using Spatial Hash Function and Grid Techniques
DESCRIPTION
This project presents an optimization of ray tracing techniques, specifically comparing Bounding Volume Hierarchy (BVH) and a new Spatial Hash Function approach. We explore the creation of grids and bounding boxes for scene objects, utilizing a hash function to simplify the process of identifying object intersections with rays. Our findings indicate scenarios where Spatial Hash Functions outperform BVH, particularly when objects are unevenly distributed. This research demonstrates the potential efficient integration of spatial hashing in ray tracing applications.
