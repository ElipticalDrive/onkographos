Summary
Goal: remove two pieces of per-frame work whose inputs rarely change, so they become do-once-and-reuse.
1. Volumetric fog raytraced shadow shader table (Tr2VolumetricsRenderer).
The froxel fog pass that traces sun shadows built a local Tr2RtShaderTableAL on the stack every frame, which created a committed GPU upload buffer, filled it, and released it again at the end of the frame. The shader table is now a member of the renderer, so its buffer persists and is only rebuilt when the description changes. The same pass was also constructing BlueSharedString objects for its technique name, shader options and parameter names on every call; those are now file-scope constants.
2. Reference point cast (EveSpaceObject2).
Each update cast the object's ball-position function to IEveReferencePoint to read the reference position, which is an interface query on every object every frame. The cast result is now cached together with the pointer it was taken from, and only redone when the ball-position object is replaced.
Linked issue (optional)
Testing
Windows, DX12, release build. Measured in the EVE Frontier client on the QA Megastructure route (1080p, low preset) against origin/main: about -0.5 ms frame mean with raytraced shadows and -0.65 ms with cascaded shadows (single flights, ~0.5 ms noise band; the low preset sets volumetrics to LOW, so the fog part is understated there). Smoke test of this branch alone: full route flown with raytraced shadows, no frames over 100 ms, no crash dumps. Not built on Mac.
