Summary
SDFStudio currently has limited BRDF/PBR support confined to texture export (texture_utils_v2.py). This issue tracks integrating material properties (roughness, metallic, specular) into the core training pipeline, enabling:
Material-aware rendering during training
Per-method control over which material properties to learn
Proper physically-based losses and supervision
Current State
Existing PBR infrastructure:
texture_utils_v2.py extracts roughness, specular, tint from model outputs at export time
ORM texture packing for glTF export (Occlusion/Roughness/Metallic)
No material-aware rendering during training
Gaps:
No BRDF evaluation in forward pass (diffuse + specular lobes)
No learnable material parameters in SDFField or models
No material-based losses (e.g., supervision from captured SVBRDF, IBL consistency)
No environment map / IBL support
Scope
Phase 1: Core BRDF Integration
Add material MLP heads to SDFField (roughness, metallic, diffuse albedo)
Implement microfacet BRDF evaluation (Cook-Torrance or similar)
Optional: learnable environment map or SH lighting representation
Update renderers to accumulate diffuse + specular contributions
Phase 2: Method-Specific Adaptations
Flag to enable/disable material learning per method (e.g., use_brdf: bool)
Material supervision losses (if priors available)
Update configs for methods that would benefit (NeuS-facto, MonoSDF, etc.)
Phase 3: Export & Validation
Update texture_utils_v2.py to use trained material properties (not proxy inference)
Test with glTF viewers (Three.js, Blender)
Document configuration and expected inputs
References
Existing code: sdfstudio/exporter/texture_utils_v2.py:619-1058
Relevant papers: Refer to PhySG, NeRFactor, IRON for SDF+BRDF reconstruction patterns
Related upstream work: Check if autonomousvision/sdfstudio has merged any BRDF features
Notes
Keep architecture modular: not all methods need materials. Default behavior should match current RGB-only training.

Cross-reference: GS-side BRDF/PBR research
The GS community is converging on the same goal from the other direction. Key methods:
Relightable 3D Gaussians (ECCV 2024)
GS-IR (CVPR 2024)
GeoSplatting (ICCV 2025)
SVG-IR (CVPR 2025)
GS + Discretized SDF (ICCV 2025) — uses SDF prior within GS
The Discretized SDF paper is particularly relevant: it bridges SDF geometry (our domain) with GS rendering + Principled BRDF.
Related mini-mesh issues: #11 (PBR texture extraction), #13 (GS methods), #14 (hybrid SDF→GS), #16 (Blender integration).
