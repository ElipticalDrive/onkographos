🗿 Project: MonolithRay
🚀 Issue: Implement CPU-Based Signed Distance Field Raymarcher
🧩 Description
Create a cinematic 3D renderer using signed distance fields computed entirely on the CPU. Rays march through space pixel-by-pixel to render mythological structures with ambient occlusion and soft shadows.
✅ Features
SDF-based world definition
Raymarching per pixel using ImageData
Dynamic camera movement
Lighting and shadow approximation
Web Worker optimization support
🛠️ Tasks
Implement SDF primitives and scene blending
Write raymarch loop for distance stepping
Calculate normals for lighting
Render pixels into canvas buffer
Parallelize heavy loops using workers
