#  JumpAround — Physically-Based Pong

Classic Pong rebuilt as a real-time computer graphics showcase in Java + JOGL (Java OpenGL). Instead of flat rectangles, every object is lit with **Phong and GGX microfacet BRDF shading** — and you can tweak the material and lighting live while you play.

## Highlights

- **GGX microfacet BRDF** — physically-based specular highlights with live-adjustable **metallic** and **roughness** parameters
- **Phong shading** — switchable shading model for side-by-side comparison
- **Dynamic lighting** — move the light direction manually or make it follow the ball
- **Power-ups** — grow, shrink, and star pickups rendered with textured quads
- **Custom rendering pipeline** — VBO mesh loading, texture loading, GLSL shader compilation and hot-recompile, skybox

## Controls

**Gameplay**

| Key | Action |
| --- | --- |
| `W` / `S` | Player 1 up / down |
| `P` / `L` | Player 2 up / down |
| `SPACE` | Start / restart |

**Lighting & materials** — adjust light direction, toggle light-follows-ball, and step metallic/roughness values at runtime (see key hints in `PongGame.java`).

## Tech Stack

- Java + JOGL (OpenGL bindings)
- GLSL shaders (Phong + GGX microfacet)
- Custom VBO/texture loaders

## Running

1. Open in IntelliJ IDEA (project files included)
2. Add JOGL natives for your platform to the classpath
3. Run `src/PongGame.java`
