Motivation
Provide utilities to convert external sparse SatelliteSfM point clouds into the normalized affine world frame used by the project and to diagnose coordinate mismatches.
Make initial Gaussian initialization and pruning thresholds configurable to reduce training collapse risk.
Handle dataset-specific meter/pixel resolution when exporting DSMs during rendering.
Description
Added two dataset-creation utilities: scripts/dataset_creation/convert_satellitesfm_ply_to_eogs.py to convert/fit input .ply clouds into the EOGS affine normalization and scripts/dataset_creation/check_affine_pointcloud_alignment.py to inspect coordinate alignment and camera consistency.
Expanded README.md with usage examples for conversion, diagnostic guidance, and tips to avoid training collapse (example flags: --prune_opacity_threshold, --init_opacity, --init_scale_multiplier, --init_scale_floor).
Exposed new model initialization parameters in ModelParams: init_opacity, init_scale_multiplier, and init_scale_floor, and a pruning parameter in OptimizationParams: prune_opacity_threshold.
Updated Gaussian initialization in create_from_pcd to accept and apply init_opacity, init_scale_multiplier, and init_scale_floor when computing initial scales and opacities.
Made scene loading skip regenerating points3d.ply if it already exists and added stronger validation that a loaded PLY contains points, raising an error if not.
Replaced hardcoded pruning threshold with the configurable opt.prune_opacity_threshold in train.py and moved opacity retrieval logic to avoid duplicated calls.
Improved DSM export in render.py by selecting a per-dataset dataset_resolution (special-cased for paths containing IARPA and JAX) and using it consistently for tiling and affine transform creation.
Testing
Performed basic smoke tests by importing modified modules and invoking the new scripts' argument parsing via --help, which completed successfully.
Ran a lightweight runtime smoke check invoking train/render entrypoints in a dry configuration to verify that the new arguments are parsed and that code paths for initialization and pruning execute without immediate errors.
No new automated unit tests were added in this change.
