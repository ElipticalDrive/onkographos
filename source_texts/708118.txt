The pipeline can now train static 3D Gaussian Splatting reconstructions for one or more exported 4DAnyone frames using a manually installed Nerfstudio environment. Each frame has an independent training pass/checkpoint and optional reconstruction recording pass, so restarting after a later failure preserves completed frames.
The implementation follows the working Nerfstudio Splatfacto Colab: prepare a private RGBA copy from RGB images and masks (threshold 127, 1px erosion), remove training mask paths, retain seed points/cameras, run stock Splatfacto against all cameras with random backgrounds, and export the full SH Gaussian PLY. The default compact profile retains 60,000 iterations, split cutoff 32,000, SH degree 2, and the notebook's densification/regularization settings.
Add separate standalone utility files/commands: recon-prepare-rgba, recon-splatfacto, and recon-splatfacto-rerun. Utilities accept only operation arguments, emit JSON progress/results on stdout, and send upstream diagnostics to stderr/log files. They contain no worker or notification integration.
Enable pipeline.reconstruction with type nerfstudio_splatfacto. Select all exported Nerfstudio frames by leaving config.frames null, or select a subset. Add generator options, complete disabled-stage profiles in existing JSON examples, and an enabled config/splatfacto-run.example.json using an existing 4DAnyone source.
Launch training in the configured nerfstudio_bin/python; run ns-train and ns-export from that bin directory. Support a separate interpreter for Rerun. Tools/environments remain manually installed; the pipeline installs no dependencies and does not patch upstream sources.
Keep per-frame datasets, model configs/checkpoints, dataparser transforms, TensorBoard files, training/export logs, full PLY and a frame manifest. Validate Gaussian fields, including higher SH coefficients. Include model/recording results in the run manifest and normal S3 upload.
Adapt the notebook's optional Rerun recording utility: native Gaussian PLY import, cameras aligned through Nerfstudio's dataparser transform/scale, four selected views, Gaussian-center debug view, model statistics and TensorBoard metrics. Sampling limits only the recording copy; the full Gaussian PLY remains intact.
Validation: python -m pytest — 156 passed. Tests exercise real utility subprocesses with fake upstream train/export executables, RGBA source preservation and mask processing, stdout/stderr separation, failures between frames, durable resume, forced reruns, manifest integration, generator selection and AWS composition. A real Rerun 0.36 SDK exports a nonempty recording from synthetic Gaussian data while preserving the full PLY. Installed recon-splatfacto --help, the enabled example's recon-aws-worker plan, and git diff --check also passed.
GPU training and an end-to-end AWS reconstruction were not run here. The notebook's training environment is Python 3.11, PyTorch 2.2.2+cu121, Nerfstudio 1.1.5 and gsplat 1.4.0. Reconstruction currently consumes the enabled Nerfstudio dataset export task; reconstruction recording-only runs from another experiment are rejected explicitly.
