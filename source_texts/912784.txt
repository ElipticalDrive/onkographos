Scope
Introduces the audited foundation for high-quality procedural trees without enabling them in world generation yet.
architecture and migration plan
BASIC / MID / HERO hard generation budgets
validated immutable environment inputs
immutable parent-before-child branch graph
complete voxel model validated before world mutation
deterministic fingerprints
regression self-test registered in Gradle check
Safety
The existing vegetation runtime remains unchanged. This PR creates testable pure models first so future growth algorithms cannot place partial, overlapping, unbounded, or non-deterministic trees.
