Goal
Create a new VolumetricCloudPass that ray-marches the cloud layer and writes to CloudColor (Rgba16Float), using the noise textures from Phase 0.
Shader port
Translate clayjohn/realtime_clouds sky.frag into WGSL:
Ray/sphere intersection for cloud layer bottom/top.
density() function sampling Perlin-Worley, Worley, weather map.
march() function: front-to-back ray-march with light sampling loop.
Simple output: vec4(L, alpha) without full lighting yet.
Render pass structure
crates/aether-engine/src/renderer/passes/volumetric_cloud/mod.rs
Reads: none initially (uses own uniforms).
Writes: CloudColor.
Holds bind groups for noise textures + uniform buffer.
Pass::should_run returns true when optional.clouds is present.
Tests (TDD)
Pass signature declares CloudColor write.
Shader compiles and pipeline builds successfully.
Uniform buffer layout matches WGSL struct.
Headless test: pass resolves resources without panic.
Acceptance criteria
cargo test -p aether-engine --lib passes.
Pass initializes when a scene contains a Clouds component.
Depends on
