Implement ML-based methods to do tomographic reconstruction.
The goal is to develop metrics, datasets and models to improve tomographic reconstruction, and to be able to integrate it with other code.
Here are some recent papers:
https://arxiv.org/pdf/2312.17265
https://journals.aps.org/prxenergy/abstract/10.1103/PRXEnergy.4.013002
https://www.mdpi.com/2571-712X/8/2/43
https://iopscience.iop.org/article/10.1088/1748-0221/20/06/P06034/pdf
First steps based on the paper 2312.17265:
download the dataset: https://www.kaggle.com/datasets/tomandjerry2005/muons-scattering-dataset
check out this repo: https://github.com/jedlimlx/Muon-Tomography-AI
run the deep learning based code in the repo on the dataset, visualize the results.
