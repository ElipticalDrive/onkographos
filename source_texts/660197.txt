Completes all 52 items from OPTIMIZATIONS.md (v134 → v183), plus bug fixes.
Memory & saves
Voxel store: VOX_HEAD 200→16, on-demand column growth, arena allocator, 1-bit visBits (~76MB → ~9.5MB)
Saves: IndexedDB + gzip (.svw), auto-migrates old saves; fixes const-SEED load crash
Load time
Time-sliced async world gen with staged progress bar
Minified + pre-gzipped libs (1.6MB → 205KB over the wire, old-iOS fallback)
Meshing Web Worker (LOD/save-load async, digging stays sync)
Cache-busting via hash-versioned libs + ETag/immutable server headers
Rendering
One mesh per chunk, greedy meshing, Int16 positions + packed normals/colors
Per-vertex sky/Lambert shading; speckle reconstructed in fragment shader
Far-terrain 4x4 batched merged meshes; render-distance slider (1=28m, 2=44m)
Static shadow caching (redraw only on change) + player-centered texel-snapped shadow box
Removed all 26 backdrop-filter blurs; sky pinned to far depth; ghost/outline unified
Mobile GPU
MAX_PIXEL_RATIO 1.5 touch / 2 desktop, MSAA off on high-DPR touch
Physics & colliders
Adaptive physics tick (120Hz, drops under load)
Collider streaming: radius-1 body + sync build guarantee, dirty-set batching, build-ahead scan with airLo early stop
Powder/sand: sweep removed, budget carry, adrift flood fill anchored at airLo, per-frame debris catch bbox
Sphere-collision contact hooks (6 hooks/step vs 344-contact scan)
Allocation-free aim/tool/crouch paths
Verified per-item with differential tests (byte-identical world gen over 3,000 seeds), in-browser playtests on the live tunnel, and syntax checks. Game version v134 → v183.
