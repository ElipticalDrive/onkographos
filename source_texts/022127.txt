# NeRF and 3D Reconstruction Project

This repository contains my implementation for the NeRF and 3D reconstruction assignment for COMS 4732: Computer Vision II. The work is split across two Jupyter notebooks and a small set of supporting Python files.

## Project Structure

The submission is organized as follows:

- `part1.ipynb` or the Part 1 notebook: contains the complete code for Part 1
- `part2.ipynb` or the Part 2 notebook: contains the code for training the NeRF model up to generating the depth map
- `src/dataset_3d.py`: TODOs completed for the 3D dataset loading utilities
- `src/rendering.py`: TODOs completed for ray sampling and rendering utilities
- `visualize_viser.py`: used for interactive visualization
- `README.md`: this file

If your notebook filenames are different, replace `part1.ipynb` and `part2.ipynb` with the actual filenames.

## Compute Used

Different parts of the assignment were run on different compute environments:

- **Part 1** was trained and executed on **Google Cloud**
- **Part 2** was trained and executed on the **Columbia Insomnia cluster**

## Overview

This project focuses on multi-view 3D scene understanding and novel view synthesis.

- **Part 1** contains the full implementation required for the first section of the assignment
- **Part 2** contains the NeRF training pipeline, including data loading, ray generation, volume rendering, training, validation rendering, and depth map generation
- The Part 2 notebook also includes functions carried over from `vis_orbit.py` for orbit-based rendering and visualization

The NeRF implementation learns a continuous 3D representation of the scene from posed images and renders images from held-out or novel viewpoints.
