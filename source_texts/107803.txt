Background
The current AetherEngine volumetric cloud pass is a minimal placeholder that uses simple value-noise + fbm. This issue serves as the parent roadmap for porting the full cloudscape implementation from NadirRoGue/RenderEngine, which itself is based on the Horizon: Zero Dawn SIGGRAPH 2015 talk and Sebastien Hillarie's TileableVolumeNoise.

Common verification checklist
Each phase must pass before the next begins:
cargo test -p aether-engine --lib (198 tests)
cargo build -p aether-launcher --release
Run launcher with scenes/13_clouds.ron and save screenshot to tests/output/clouds/phaseN/
Visually inspect screenshot; do not proceed if output is black or completely blown out
