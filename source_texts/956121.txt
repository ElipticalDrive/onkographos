This makes the depth fog fade directly to the sharpest possible version of the sky, as opposed to a blurred version that is less suitable for open world fog fading.
Subtle differences may still be noticeable when using a sky material with nearest-neighbor filtered textures, as it's always sampled with bilinear filtering. I've been wondering how we can improve upon this (perhaps with a project setting to adjust this sampler like godotengine/godot-proposals#8063), but it's not too noticeable in practice if your Camera3D's Far property is adjusted to match the fog's end distance. Doing so is also beneficial for performance anyway.
Given this makes #84792 a lot more useful for open world games and affects visuals of projects using that feature, it would be good to get this in for 4.3 if possible 🙂
The appearance of exponential fog isn't affected by this PR.
This closes Fog aerial perspective does not blend seamlessly into the sky #97803.

It's nice to have the fog blending with far away edges, but there are a few details that I wanted to point out, just in case:
This is because the radiance map is always read with bilinear filtering, but you may use nearest-neighbor filtering in PanoramaSkyMaterial to get a pixel art sky. I pointed this out in OP. With the approach currently taken in this PR, there's no easy solution to this, especially since the radiance map likely has a different resolution than the sky texture.
Tested this locally and works great. Still a discussion about this PR?
As #89995 (comment) mentioned, it may be better to reimplement this PR as a separate feature that actually samples the sky shader directly instead of using the radiance map. This will allow it to correctly match skies with low-resolution, nearest-neighbor filtered textures. This should also be possible to implement in Compatibility.
I don't have time to look into this right now, so feel free to take over this PR if you'd like.
