This PR implements a complete, register-safe volumetric rendering extension for Caustica:
Core shader changes:
math.slang: hg_dual(), fbm3d(), densityField()
medium.slang: Medium expanded with scattering + dual-lobe phase fields
indirect.rgen.slang: closed-form scattering + emission integrals with density-scaled attenuation
segment.slang: unpack defaults preserve phase settings
world_common.slang: FEATURE_SCATTERING + FEATURE_VOLUME_EMISSION bits
Design guarantees preserved:
True 3D participating media (not screen-space / not fake fog)
Energy-conserving dual-lobe Henyey-Greenstein (forward + backward scattering)
No noise / no ghosting / no pixelation (closed-form integrals, deterministic evaluation, continuous world-space)
Emission safe (continuous emission separate from RIS reservoir)
RIS safe (binary visibility unchanged)
Stack safe (depth-2 fixed fields, no arrays)
Includes VOLUMETRIC_PROPOSITIONS.md (398 lines) with full architecture documentation, compatibility matrix, and recommended first-step guidance.
