Turns the M4 trainer core into a full 3DGS training schedule.
Densification: clone / split / prune on the accumulated positional gradient, with opacity resets, under a hard Gaussian budget derived from the free device memory (90% by default) so an 8 GB card never runs out.
SH up to degree 3, with the view-direction gradient term that M4 skipped, and a degree ramp every 1000 iterations.
Schedule: exponential position learning-rate decay, opacity resets, pruning of low-opacity and oversized splats.
Performance: separable SSIM and a per-stage GPU profile printed at the end.
Progress: periodic PSNR / Gaussian count / VRAM output, and a checkpoint .ply every 5000 iterations so splat view can look mid-training. Checkpoints are held back for 1000 iterations after an opacity reset, which otherwise produced an almost black file.
Fix: the SSIM gradient produced 0 × ∞ = NaN on pixels whose covariance term is exactly zero in one channel, poisoning every Gaussian covering that pixel while the loss stayed finite. The division is now cancelled analytically, and densification drops any non-finite Gaussian as a safety net.

A full 30,000-iteration re-run with the NaN fix is in progress; the number will be added here when it finishes. A logged 6200-iteration run shows zero non-finite Gaussians at every iteration, where the same run before the fix went bad at iterations 439 and 1125.
Testing
67/67 tests pass on the Steam Machine (GCC 16). New tests cover budget enforcement, the SH gradient against finite differences, densification keeping the count under budget, and densification removing non-finite Gaussians. No test reproduces the exact zero covariance that triggered the NaN, because it can't be produced on demand.
Not tested: real photos or video, Windows and CI, Vulkan validation, GPUs without float atomics, the VRAM budget at realistic limits (no run came near it).
Known limits
~8 it/s at 800×600. Compositing and the backward pass take over 90% of GPU time and the cost barely changes with resolution; not yet understood.
The 1080p figure used far fewer iterations and isn't a fair comparison yet.
