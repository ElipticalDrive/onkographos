# Matrix Transpose Program (C++)

This is a simple C++ program that calculates the transpose of a 3x3 matrix using functions.

## Concept
The program takes a 3x3 matrix and swaps rows with columns to create the transpose matrix.

## Technologies
C++
Functions
2D Arrays

## Learning Outcome
This project helped me understand:
- How to pass a 2D array to a function
- Matrix transpose logic
- Using functions in C++
