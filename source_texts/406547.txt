Description
Add the mesh reconstruction package together with the repository baseline it needs, as five stage commits on one branch.
Canonical route: COLMAP known-pose model → OpenMVS DensifyPointCloud → ReconstructMesh → RefineMesh.
A/B route: Open3D alpha shape on the COLMAP CUDA dense cloud.
Canonical output: W-frame metres PLY/GLB/OBJ + mesh_manifest.json + SHA-256 checksums.
Mesh measurements are diagnostic only: g3_report.json has status: "measured", measured values, and reference values; no pass/failures fields and no threshold gate.
C++ raylidar_cli mesh validate remains the structural ingest gate.
Windows min/max macro collision in data_process/src/dataset/acquire.cpp is fixed with parenthesized (std::numeric_limits<...>::max)().
Closes #18.

Windows build fixes in the first commit:
data_process/src/dataset/acquire.cpp uses parenthesized (std::numeric_limits<...>::max)() to avoid the max macro collision.
src/CMakeLists.txt restores the RAYLIDAR_VERSION="${PROJECT_VERSION}" compile definition for raylidar_runtime; the refactor had dropped it while src/version.cpp still uses the macro.
CommandRegistrar/RegisterCommand move from data_process/src/cli/dispatch.cpp to core/src/cli/dispatch.cpp, so the evaluation DLL resolves the registrar symbols on Windows instead of leaving them unresolved for the executable.
Data bundle
Team-restricted Google Drive link:
https://drive.google.com/file/d/1NhETMB441QMgmPOMsnXYZtpdhLCfxOu7/view?usp=sharing
Contents:
mesh.ply (W frame, metres)
60 rectified image_00 RGB frames (4615–4674) used for reconstruction
camera intrinsics/extrinsics (K, P_rect, T_W_C, T_W_V)
ray convention and five camera-outside directions
gt_rays.bin with 1,765,175 frozen camera-origin rays (RLGR, 96-byte records)
manifests and SHA-256 checksums
Additional notes
G3 measurements are diagnostic only; the A/B report lists measured values per route without PASS/FAIL, and mesh_manifest.json/index.json record g3_status: "measured".
No alignment, ICP, Umeyama, or scale correction exists in the construction path.
GT/rays are read only by diagnostics; they are never construction inputs.
tools/mesh/reconstruct/viz.py, scripts/export_phase4_bundle.py, and docs_local/ are intentionally excluded.
The root C++ tests/ tree is excluded and gitignored; the package keeps its own tools/mesh/reconstruct/tests.
readability-identifier-naming is not enabled in .clang-tidy: existing calibration/geometry code uses T/R/T_AB and camelCase public fields; the separate naming proposal remains PR fix: C++ naming conventions #11.
KITTI-360 RGB is non-commercial research data; keep the Drive link team-restricted.
