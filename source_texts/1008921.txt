Stabilize closest-point calculations for thin triangles
For thin, nonzero-area reference triangles, cancellation in these dot-product determinants can classify an interior point as lying outside an edge and report a false deviation. With a=(0,0,0), b=(1e8,0,0), c=(1e8,1,0) and p=(5e7,0.25,0), all coordinates are exactly representable as mesh positions, but this function returns (5e7,0,0): a point actually on the reference surface receives a 0.25 mm deviation. This also corrupts tolerance counts and statistics. Use a numerically stable region calculation or a thin-triangle fallback, and add an analytic regression test; the existing brute-force test reuses this helper and therefore cannot detect the error.
