Full rewrite of the document representation from a per-voxel Map to a set of disjoint axis-aligned colour boxes per object. Prototype to evaluate, per discussion.
Headline result
The furnished M.03 room with solid 15 cm walls — ~5.0M cells if voxelised — is now 34 boxes, built in ~0.5 ms (the hollow-voxel hack took ~610 ms). The "thick walls are pathological" problem disappears: a solid wall is one box.

How it works
boxes.ts — box algebra: add/erase/paint carve the target region out of overlapping boxes (≤6 fragments each) and re-add as needed; a uniform-grid has() index for fast point queries; worldBox() (90° rotations keep boxes axis-aligned); boundaryCells() emits just the surface cells of the union.
Meshing reuses the existing per-cell mesher + baked AO unchanged. It's fed boundaryCells() plus a box-indexed has(), so the result is identical to meshing every cell — but interior cells are never visited. This sidesteps the AO problem I flagged earlier: AO stays per-cell at surfaces; only storage/iteration changed.
Editing: box brush add/erase are single region ops; paint recolours; move-collision is box-vs-box overlap; measure / thumbnails / colour counts all read boxes. The edited object is a single mesh rebuilt on a debounced frame (the chunk system is gone).
Persistence serialises objects as 7-tuple boxes; localStorage key bumped to v11.
Correctness
selfcheck brute-forces the algebra against a reference voxel map over 300 random add/erase/paint ops: boxes stay disjoint, occupancy + colour match exactly, the grid has() matches, and boundaryCells() emits precisely the occupied-cells-adjacent-to-empty. deno fmt/lint/check/test and the build all pass.
Evaluation notes / where to back off
Fragmentation is real but bounded (≤ cell count, as predicted): 300 random ops fragmented 1.6k cells into ~225 boxes (peak 327). Structured box-drawing stays tiny; pathological per-cell churn would approach parity. No coalescing/merge pass yet — that's the obvious next step if fragmentation bites.
No incremental chunk remesh. The edited object re-meshes wholesale (rAF-debounced) on each edit. Coarse box ops make this fine; heavy paint on a huge object is the case to watch.
Plants are blocky — a sphere isn't a box, so the seed's foliage is stepped boxes. Fine for the box aesthetic; organic shapes would need run decomposition.
Needs a real browser pass to confirm rendering/picking/measure feel right — the tests cover the pure algebra, not the three.js paths.
