Simulation code for FASHION (Feedback-driven Anisotropic Self-organized Heterogeneity In Oriented Networks), a three-phase biophysical model explaining the violet/white checkerboard pattern of the snake's head fritillary (Fritillaria meleagris). The model combines a Turing reaction-diffusion process (Gray-Scott) spatially constrained by the tepal's veins, anisotropic diffusion of a colorant factor confined to the inter-vein corridors, and a bistable Hill-function pigment response that sharpens the pattern into a binary checkerboard. This repository accompanies a manuscript currently in preparation. It contains five self-contained, pure NumPy/Matplotlib Python scripts, with no other files or prior steps required to run any of them: two fast, small-domain (7 veins) scripts for direct classroom reuse (a vein-free Gray-Scott control and the full FASHION model, ~1 min each), an animation script generating an .mp4 of the pattern-formation process (needs ffmpeg), and two large-domain (15 veins) variants used to produce the manuscript's quantitative statistics (tens of minutes, not classroom-paced). See README.md for exact dependencies, measured runtimes, and usage.
