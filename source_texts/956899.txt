Changes the default of antiAliasFilterSize from 0.3 to 0.1, the filter size most training software (Mip-Splatting, Brush mip mode and others) uses.
Changes:
GSplatParams#antiAliasFilterSize now defaults to 0.1; JSDoc updated
Gaussian splat viewer example default updated to match
Unit test updated
API Changes:
Default value of app.scene.gsplat.antiAliasFilterSize: 0.3 -> 0.1. Splats trained with the anti-aliased mode of gsplat (0.3) should set it explicitly:
```
app.scene.gsplat.antiAliasFilterSize = 0.3;
```
feat: Default antiAliasFilterSize to 0.1
