Context
Follow-up to the reference-image visual-hull / hull-as-scaffold work for voxelization (improving model quality, especially characters/people). That work ships as B1 first; this issue tracks the upgrade to B2.
Background: today the reference brief silhouettes are a validation oracle only — ModelPlanner is gated on them (width match + every silhouette cell inside some part box) but geometry is authored freely and only IoU-checked post-hoc in ModelValidator.CheckSilhouette. ModelAssembler.Compose is a pure union with no clipping. Nothing fuses front+side silhouettes into a 3D volume.
B1 (shipping first — not this issue)
Constrain-existing via a destructive post-assembly clip: after ModelAssembler.Compose, delete any voxel that projects outside a supplied-axis silhouette (visual-hull intersection), with safety:
Per-part clip accounting (we still have each part's world-voxels pre-union).
Tiered response: light clip → silent; moderate clip → re-author signal ("reposition/resize this part"); severe clip → do NOT delete the part, keep authored geometry and force re-plan (never manufacture a missing limb).
Global confidence floor: if the clip removes more than a threshold fraction of total model mass, discard the hull and fall back to free authoring + today's IoU gate (a bad reference image must never be worse than no reference image).
Gated entirely on a ReferenceBrief with silhouettes existing — no-reference path (cactus/tree/rock) is byte-for-byte unchanged.
B2 (this issue)
Replace the destructive clip with a forward per-part authoring bound: hand each part author its slice of the hull as a hard mask up front, so geometry is born inside the envelope and there is nothing to clip. Cleaner, non-destructive, and removes the over-clip failure mode entirely (over-clip in B1 is a depth-axis risk that grows with the number of views).
Why deferred
B2 requires mapping hull regions → parts, i.e. a light segmentation step, which B1 deliberately keeps off the critical path. The per-part clip-ratio accounting B1 produces is exactly the data needed to bootstrap B2's per-part hull regions, so B1 is not throwaway — it's the stepping stone.
Rough scope when picked up
Fuse supplied-axis silhouettes into a 3D occupancy hull (visual-hull intersection of extrusions).
Map hull sub-volumes to planned parts (segmentation — coordinate with the 2D-segment→back-project rigging idea).
Pass each part author a per-part hull mask as a hard cap in PartAuthor (layers/primitives/script must respect it).
Keep the global confidence floor + no-reference passthrough from B1.
Decide interaction with the existing IoU gate (likely still runs as a backstop).
Acceptance
Characters authored with ≥2 reference views fit the hull without any destructive post-assembly deletion.
No regression to the no-reference path.
B1's global floor / fallback behaviour preserved.
Filed from a design session; B1 accepted as v1.
