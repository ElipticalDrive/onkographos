Project:
Volumetric rendering and
research was traditionally done on high-end professional graphic
workstations. Recent advances in general consumer hardware,
particularly in the consumer graphics industry, has allowed researchers
and developers to explore a new lower cost solution for volumetric
rendering. The goal of this project is to investigate volumetric
rendering on current day PCs and consumer level video hardware.
Features:
Loads RAW volumetric data sets
Per-Pixel hardware accelerated Color/Transparency
mapping
Volume rotation via Texture Coordinate
transformations
Graphic Acceleration through DirectX 9.0b (vertex
shader 1.1 and pixel shader 1.4 support required)
In program Alpha transfer map adjustment
Future Development:
Experiment with various Voxel Lighting techniques
using pixel shaders
Experiment with volume clipping techniques using
pixel shaders
In program color transfer map adjustment
Automatic alpha transfer map assignment via
histogram processing
Development Machine:

Programmed with Microsoft Visual C++ 6.0 and Direct
X 9.0b graphics API
Windows XP
