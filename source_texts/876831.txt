Motivation
Provide a pipeline to render orbit RGB/mask sequences from 3DGS PLYs and export per-frame poses so datasets can be consumed by COLMAP and downstream reconstruction tools.
Support direct creation of COLMAP-compatible TXT/BIN sparse models from rendered orbit outputs and from original PLY point clouds to avoid running full Colmap when only synthetic data is available.
Add utilities for mesh extraction with mask-aware integration and marching-tetrahedra, and a mask refinement tool using GroundingDINO + SAM2 to improve mask quality before training/extraction.
Description
Extended milo/convert.py with a --from_orbit_output mode and implemented write_colmap_binary_model and build_colmap_from_orbit_outputs to emit COLMAP TXT and BIN files and to optionally write RGBA images with mask alpha.
Added milo/convert3dgs.py which builds a COLMAP dataset from a 3DGS PLY and its rendered poses, including write_binary_model and load_points_from_ply to export points3D from the PLY.
Rewrote milo/render_3dgs_orbit_video.py to a more flexible renderer that loads native 3DGS PLYs, centers the model, supports near/far dual-distance orbit configs, writes per-frame images, masks, and poses/*.json, and uses a GaussianRasterizer path for native rasterization via render_native_rgb and render_frame.
Added mesh extraction scripts: milo/eval/dtu/mesh_extract_dtu_mask.py for mask-aware TSDF integration and milo/mesh_extract_integration_mask.py implementing marching tetrahedra with binary-search refinement and per-vertex color estimation.
Added milo/refine_masks_gdino_sam2.py which refines existing masks using GroundingDINO to propose boxes and SAM2 to predict masks, with options to intersect with existing masks and automatic model-path resolution.
Added a specialized training script milo/train_mask_regular_densification.py for mask-aware training with regularized densification, mesh-in-the-loop regularization, depth-order priors, and lots of CLI options for experimentation.
New and updated helpers include save_pose_json, load_native_3dgs_ply, percentile_bbox, estimate_fovy_deg*, orbit_position*, build_camera, and reliance on scene.colmap_loader.rotmat2qvec, PIL, numpy, plyfile, torch, and optional open3d/sam2/GroundingDINO integrations.
Testing
No automated tests were executed for these changes as part of this rollout.
