Description
Added automated unit tests for ray intersection functions, migrating interactive tests from test_geometry.cpp to proper unit tests that can run in CI/CD pipelines.
Changes:
Added unit tests for rectangle_ray_intersection in unit_test_geometry.cpp
Added unit tests for circle_ray_intersection in unit_test_geometry.cpp
Added unit tests for triangle_ray_intersection in unit_test_geometry.cpp
Added unit tests for quad_ray_intersection in unit_test_geometry.cpp
Added unit tests for bitmap_ray_collision in unit_test_bitmap.cpp
Added test for detecting closest intersection among multiple shapes
Added necessary includes for geometry headers and physics
Motivation:
The ray intersection functionality previously only had interactive visual tests that required manual inspection. These new automated tests enable continuous integration testing and prevent regressions.

Author
Updated bitmap ray-collision tests in unit_test_bitmap.cpp:
Switched from loaded PNGs to created/drawn bitmaps to avoid transparency ambiguity.
Added setup_collision_mask(...) after drawing/clearing, since bitmap_ray_collision relies on the bitmap’s pixel mask (created bitmaps don’t have one until it’s generated).
Changed the “multiple bitmaps” section to use a single ray that intersects all three bitmaps, and updated the assertion to REQUIRE(collision_1 && collision_2 && collision_3).
Replaced “always true” assertions with meaningful REQUIRE / REQUIRE_FALSE checks.
Added a multi-cell bitmap case where one cell is drawn and the other is transparent to validate cell-specific behavior.
Updated geometry ray-intersection tests in unit_test_geometry.cpp:
Replaced the DBL_MIN miss-case with a clearer missed-ray scenario.
Fixed the circle “ray starts inside” expected results to match docs (hit point at origin, distance 0).
Reworked triangle + quad tests to use axis-aligned shapes so hit point + distance can be asserted precisely.
Removed the “closest intersection among multiple shapes” test as it wasn’t testing a single API surface and duplicated earlier coverage.
Verification:
skunit_tests "[ray_collision]" passes (exit code 0)
skunit_tests "[ray_intersection]" passes (exit code 0)
