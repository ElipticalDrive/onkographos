Vicomtech contributed the volume rendering component in x3dom. Here is an older demo page:
http://demos.vicomtech.org/
http://volumerc.org/demos.html
You could use a transfer function to map from grey to color.
The cartoon style lets you add colors:
http://volumerc.org/demos/x3dom/x3dom-examples/CartoonStyle-interactive.html
The ShadedVolumeStyle scene works when you paste the x3d below here
http://andreasplesch.github.io/Library/Viewer/x3dom.html
```
<X3D xmlns='http://www.web3d.org/specifications/x3d-namespace' showStat='true' showLog='true' width='500px' height='500px'>
  <Scene>
    <Background skyColor='0 0 0'></Background>
    <Viewpoint id='front' position='0 0 300'></Viewpoint>
    
    <!--<PointLight id='point' on='TRUE' intensity='0.9000' ambientIntensity='0.0000' color='0.0 0.6 0.0' location='0 0 300' attenuation='0 0 0' radius='5.0000'></PointLight>-->

      <ShadedVolumeStyle lighting='TRUE' shadows='TRUE'>
        <Material diffuseColor='1.0 0 0' specularColor='1 0 0' ambientIntensity='0.4'></Material>
      </ShadedVolumeStyle> 
    </VolumeData>
  </Scene>
</X3D>
```

There is only very basic support for lightning with the ShadedVolumeStyle which uses phong based illumination (no shadows), finding the correct parameter values can be tricky. All the other volume nodes should work as expected.
The (functional/volren) are legacy files, they are not x3dom compatible, for volren examples look-up the official examples page, the regression-suite tests and the Vicomtech demo page.
The best way to colorize a volume is to define a transfer function with the OpacityMapVolumeStyle node. A transfer function is an image of 256 pixels wide and >= 1 pixels height that maps each data value to a given color and opacity. Check the volren example source.
I am working in a web based x3dom compatible transfer function editor right now, this would help with the process of adding color to the volume. I may contribute soon with an update of the main volren example as soon as I have a public prototype.
