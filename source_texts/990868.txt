Why
pushFace runs for every emitted voxel face. Position packing repeatedly dereferenced four nested face.v[vertex][axis] arrays even though the six face templates are immutable.
Change
Precompute one flat 12-number position-offset array per face at startup and use it in pushFace. Vertex values/order, geometry, AO, UVs, materials, Golden Graphics, AutoDemo, Creature Factory, controls/mobile and Cloudflare behavior are unchanged.
Evidence
representative position-pack benchmark: flat offsets faster in 9/9 runs (~235.6–259.9 ms vs ~264.5–305.1 ms per 2M iterations after warm-up)
focused voxel Golden Graphics/water/performance: 13/13 PASS
npm run check:fast: 61 JS files PASS
npm run golden:check: PASS
npm run quality:regression: 97.58 / NO_REGRESSION / 0 violations
git diff --check: PASS
A separate pushFace-specialization candidate was tested first and rejected because it was not consistently faster. This PR only contains the measured 9/9 winner. Merge only after required repository gates are green.
