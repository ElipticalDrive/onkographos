Goal
Create SDF for the main mountain(s) with domain warping and ridged noise.
Steps
Create MountainSdf.cs in Scripts/World/SDF/.
For each MountainFeature in SdfContext:
Shift p by centerXZ.
Compute radial distance.
Apply domain warp to p.xz using Noise2D.
Compute base cone-like term (dist/radius + y/height).
Add ridged noise for rocky details.
Mask with a smooth falloff from center.
Combine all mountains with min() across features.
Return large positive value if far from any mountain bounds.
How to test
In VoxelPreviewWindow, show XZ and XY slices near mountain area.
Confirm you see uplifted region where mountain should be.
