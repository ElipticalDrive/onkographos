EOGS had no way to extract a 3-D triangulated mesh from a trained Gaussian model. This adds mesh extraction using the Gaussian Opacity Fields (GOF) method (Yu et al., SIGGRAPH Asia 2024) — the current state-of-the-art for mesh extraction from standard 3-D Gaussian Splatting without retraining.
Approach
Builds a volumetric density field over a voxel grid by splatting each Gaussian with its full anisotropic covariance (Σ = R diag(s²) Rᵀ), truncated at 3σ:
```
f(x) = Σᵢ αᵢ · exp(−½ · (x−μᵢ)ᵀ Σᵢ⁻¹ (x−μᵢ))
```
Extracts the isosurface via skimage.measure.marching_cubes
Assigns per-vertex colours from the DC spherical-harmonics component of the nearest Gaussian (KD-tree lookup)
Changes
scene/gaussian_model.py — new GaussianModel.extract_mesh(path, resolution=256, density_threshold=1.0) method
render.py — render_sets wires in the mesh step; CLI gains three new flags:
```
python render.py -m <model_path> \
    --extract_mesh \
    --mesh_resolution 256 \   # voxel grid resolution (default 256)
    --mesh_threshold 1.0      # marching-cubes isosurface level
```
Output is written to <model_path>/mesh_iter{N}_res{R}_thr{T}.ply
requirements.txt — adds scikit-image, trimesh, scipy
