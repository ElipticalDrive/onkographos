Before implementing all of M1, complete the code-driven visual proof specified in TASK_RENDER_001. Details in Procedural Rendering Strategy and Performance Plan.
Definition of Done: Verified official P0 rendering integration or explicit local-only fallback; three visually different real shader planets; low-poly 3D ship; instanced asteroids; seven hex tiles; same scene rendered from both perspective-chase and orthographic flight; real desktop and mobile screenshots, actual benchmark details, no console/shader errors; draft PR for review. Do not touch STARBOX, lot #696, payments or live P0.
The AI-generated concept illustrations are NOT runtime evidence. A separate offline Code Visual Lab experiment exists with a tested Canvas 2D fallback; its WebGL shader still requires a GPU-capable test before it can be called verified.
