# Voxel Surface Studio

Standalone Unity-powered app for sparse surface voxel assets with per-face materials and a built-in pixel editor.

Open this folder with Unity Hub and press Play. The app bootstraps itself at runtime; Unity is only the engine shell, not the intended end-user environment.

## Core ideas

- Sparse chunked surface voxels, optimized for hollow voxelized models.
- Per-face material assignment.
- Materials and pixel documents are separate reusable resources.
- Runtime preview uses chunk mesh caches and greedy meshing.
- Pixel editor can be used independently or as a material/tile authoring tool.

## Runtime flow

- Start page has only `New Project` and `Open Saved Project`.
- New project chooses either `3D Project` or `2D Project`, project folder, and file name.
- 3D projects use the fixed suffix `.vss3d`.
- 2D projects use the fixed suffix `.vss2d`.
- Open project filters files by the chosen project kind.
- Edits stay in memory until the user explicitly saves.

## Runtime controls

- `Ctrl+N`: go to New Project
- `Ctrl+S`: save the active project
- `Ctrl+O`: go to Open Project
- `F11`: fullscreen
- 3D project: `V/B/E/A/D` for Select/Paint/Erase/Add/Delete, `F` focus, `1-4` material slots.
- 2D project and 3D face pixel panel: `B/E/I/X` for Pencil/Eraser/Eyedropper/Swap Colors.

The current runtime UI is a functional scaffold. It uses Unity IMGUI so the application flow can be tested immediately; a polished production UI can replace it without changing the core data model.
