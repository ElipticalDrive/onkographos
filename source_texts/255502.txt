Add Monte Carlo ray-tracing view factor module for arbitrary 3D surfaces
with cosine-weighted hemisphere sampling, achieving 0.7ms mean per pair
(70x under the 50ms target).

Optimizations:
- Back-face/distance culling: skip non-visible pairs without ray casting
- Adaptive ray count: scale rays 1x-4x based on distance-to-size ratio
- Parallel ray casting via rayon (behind 'parallel' feature)
- Reciprocity shortcut in matrix mode: compute F_ij for i<j, derive F_ji
- O(1) memory: streaming accumulator (~256 bytes per pair)

New files:
- src/ray_tracing.rs: Surface3D, MonteCarloViewFactor, 17 unit tests
- benches/view_factor_perf.rs: criterion benchmark (100 random pairs,
  mean/median/p95 reporting, ray-count sweep, matrix benchmark)

Benchmark results (100 random urban surface pairs):
  Mean=0.737ms  Median=0.696ms  P95=1.065ms  Max=1.127ms

Regression tests verify MC results match numerical integration reference
within 5% tolerance, plus reciprocity (A_i*F_ij = A_j*F_ji).
