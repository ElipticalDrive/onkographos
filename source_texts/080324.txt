This adds runtime texture compression to StereoKit! Textures now compress on the GPU as they load, using ASTC or BC depending on what the device supports. That saves 4-8x the GPU memory and bandwidth depending on Quality(4x)/Small(8x) settings, and it's on Quality by default! For the vast majority of content, you will probably not even notice!
Tex.DefaultCompression can be used to change or disable SK's default compression level, and compression can also be controlled per-texture via TexData flags. Note that since this is on by default, and compression can change colors, you may need to turn this off for exact textures like lookup tables or exact color palettes!
Additionally, global textures and buffers are now matched by name instead of register! Renderer.SetGlobalTexture("my_tex", tex) fills every shader texture named my_tex (local material overrides of these parameters still win). StereoKit's reflection cubemap is now provided this way as sk_cubemap. The register based versions still work, but are deprecated.
Things to watch out for are:
With compressed textures, Format reports a compressed format, and GetColorData returns compressed blocks. Use TexData.CompressNone for textures you need to read back on the CPU!
The new SetColors overloads are now asynchronous by default, and the texture keeps its previous content until the new data lands. Add TexData.Blocking if you need it right away.
Material.GetTexture now returns null for texture slots left at the shader's default.
In C, tex_set_mem merged srgb_data and blocking into one flags parameter. A 5 argument call still compiles in C, but blocking silently becomes priority!
The test app also has a new Texture Inspector tool, which is handy for poking at textures and checking each channel on its own.
