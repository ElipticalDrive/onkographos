As requested by @G4G , I split down the pull request #453 into smaller patches.
This is the first one.
point cloud class
regular grid computation
neighbor computation (ball query)
point density estimation
spatial sampling (poisson disk and cell-average)
point hierarchy class
1x1 convolution and pooling layers
MCConv layer (incl. Monte-Carlo integration approximation method)
PointConv layer
KPConv layer (incl. constant summation approximation method and kernel point initialization)
example Colab-Notebooks
custom-ops package (CUDA-kernels)
Note:
The code is slightly different from the first PR #453. It's now possible to execute all functions in graph mode.
