Summary
Four original four-stage teaching animations with GitHub-readable static SVG fallbacks and shared MkDocs Play/Pause controls. This PR originally introduced BPE and NeRF; the latest commit adds k-means Lloyd iteration and RMSProp squared-gradient memory. No Mermaid diagrams, external SVG resources, or new JavaScript dependencies.
1. BPE — ordered merge learning
Count adjacent symbol pairs in the toy corpus mama × 4, map × 1, learn m + a → ma (9), then ma + ma → mama (4), and apply the ordered rules.
Toy counts are not tokenizer benchmark measurements.
Animated SVG plays on MkDocs; the still image above is readable in GitHub Markdown.
2. NeRF — front-to-back ray compositing
Ray sampling → opacity → transmittance weights → pixel composite.
Reproducible toy example: α=(.10,.65,.40), T=(1,.90,.315), w=(.100,.585,.126), residual background transmittance .189.
These values are not model outputs or benchmark results.
Animated SVG plays on MkDocs.
3. k-means — Lloyd's assignment/update loop (new)
Seed two centroids → assign 12 points to their nearest centre → move each centre to its assigned mean → reassign and recompute.
Colour distinguishes the two clusters; orange dashed lines show actual centroid displacement. The example's within-cluster squared-distance cost falls from approximately 323k → 97k → 31k in arbitrary plotted coordinate units, not benchmark measurements.
The static overview shows all four stages; animated SVG cycles through them in 8 seconds.
4. RMSProp — coordinate-wise exponential memory (new)
Four gradient vectors: (4,1), (4,1), (1,4), (1,4). Toy parameters: β=.5, v₀=(1,1), ε=0, η=1.
Shows the squared-gradient EMA and the resulting per-coordinate magnitude |g|/√v, before the negative update sign. Values are calculated, not measured from training; the chosen hyperparameters are for visual clarity.
Animated SVG cycles through four updates in 8 seconds.
