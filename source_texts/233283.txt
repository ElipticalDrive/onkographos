What this builds
A new primitive class for captured content: a CPU reference implementation of 3D Gaussian splatting (Kerbl et al., SIGGRAPH 2023), following the paper's three stages in a new abrash_core::gaussian_splat module:
Gaussian — an anisotropic ellipsoid: world centre, quaternion rotation, per-axis standard deviations (covariance R · diag(scale²) · Rᵀ), linear RGB colour, clamped opacity. Spherical splats get a one-liner constructor.
project_gaussian — EWA projection: the 3D covariance moves to view space and through the Jacobian of the perspective projection, giving a screen-space 2D covariance + its inverse. The covariance is carried basis-vector-wise throughout (columns are images of basis vectors, screen covariance via quadratic/bilinear forms in the Jacobian rows), so no row/column-major reading of any matrix can sneak in. Includes the reference implementation's 0.3 low-pass diagonal (sub-pixel splats still cover a pixel instead of aliasing away) and a footprint radius of ceil(3σ) from the largest covariance eigenvalue, clamped to a caller max.
render_gaussians — stable depth sort (nearest first; exact ties keep input order, so output is deterministic), then front-to-back premultiplied compositing with per-pixel transmittance and the 1/255 early exit: once a pixel is saturated, farther splats are skipped entirely — the CPU half of the GPU tile rasteriser's trick. Output is a SplatImage of straight-alpha linear colours over a caller background, with a render_gaussians_to_framebuffer convenience wrapper. Stats report projected/culled splats, fragments evaluated/blended/skipped-saturated, and pixels painted.
Spec, pinned by tests (20 unit + 3 doctests)
Centre alpha is exactly the opacity; falloff is opacity · exp(-½ dᵀΣ⁻¹d) (checked against the analytic screen σ); alpha is symmetric and monotone along a ray.
Anisotropy: equal normalised distance along the long/short axes gives equal alpha; a 90° rotation about the view axis swaps the screen covariance axes.
Screen size scales as 1/depth² in variance (doubling depth quarters it).
An opaque near splat hides everything behind it — verified via the saturated-skip counter, not just the pixel colour.
Translucent stacking matches the over operator 1-(1-a)³ for three coincident splats.
Distinct depths render identically in any input order; tied depths follow input order (both directions asserted).
Behind-near / beyond-far / NaN inputs cull; fully off-screen splats evaluate zero fragments while edge-crossing splats still paint the edge; zero-scale splats still paint via the low-pass filter; radius clamps to max_radius.

Honest scope
This is the correctness-first reference: one global sort, no tiling, no spherical-harmonics view-dependent colour (one RGB per splat), no depth peeling. Those are throughput/fidelity refinements that must not change the image this module produces — the tests are the contract they'd be checked against.
