🚀 Feature
A perspective camera sensor that can be initialized with custom intrinsics (i.e. fx/fy/cx/cy/s).
Motivation
I think it's a pretty common use-case to want to model a real-world sensor (i.e. Intel Realsense) with known intrinsics.
Pitch
It would be helpful if you could directly instantiate a perspective camera sensor with known intrinsics through the C++ or even Python API.
Alternatives
This feature is implemented in many other rendering frameworks such as here.
Additional context
This API or something similar (i.e. an explicit projection matrix) definitely exists at a low level, but it would be nice if it could be exposed in the C++ or even Python API. I'm open to starting an implementation, but would appreciate some guidance on how to work it into the habitat codebase and interface with Magnum.
