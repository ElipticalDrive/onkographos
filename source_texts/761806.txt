Wavefront shade_shadow multiplied camera NEE by live path throughput after the BSDF/RR step. Floor lighting picked up an extra Lambert weight (≈ albedo), so the rect looked like a different intensity than Embree.
Fix (pbrt SampleLd / CPU Path Tracer):
Bake throughput × Illuminant(Le) × Albedo(f) × geom into the shadow slot at enqueue. shade_shadow adds that spectrum as-is.
Specular / SDS light hits use causticFireflyCap (floor 10), same as CPU.
Caustics off skips SDS (look-through-glass-at-light), same as CPU suppressCausticLight.
CPU PT NEE is no longer RGBIlluminantSpectrum(Le·f·geom) — it is the book product Illuminant(Le) × Albedo(f) × geom, matching GPU and BDPT.
Version 0.9.36.
Tests: host suite 110144 checks, 16 pre-existing FAIL (cook + MTLX volume ports; this build has no MaterialX). SOL_ONLY_SPECTRAL 111/0. OptiX not compiled here.
Windows: BUILD_WINDOWS_FULL.bat, close Grendizer first (LNK1168).
