Hi, thanks for the great work. I followed the configuration provided in the README to train on the Mip-NeRF 360 garden scene, but the quality of the reconstructed environment map and irradiance renders do not match the ones shown in Figure 2 of the paper, as seen below:
Environment map:
Irradiance for the first training image:
Can you please let me know if you used a different configuration to get the results? These are the exact commands I used, without changing any of the default arguments:
```
python train.py \
-m output/garden \
-s ../data/mip_nerf_360/garden \
--iterations 30000 \
-i images_2 \
-r 1 \
--eval

python baking.py \
-m output/garden \
--checkpoint output/garden/chkpnt30000.pth \
--bound 16.0 \
--occlu_res 256 \
--occlusion 0.4

python train.py \
-m output/garden \
-s ../data/mip_nerf_360/garden \
--start_checkpoint output/garden/chkpnt30000.pth \
--iterations 40000 \
-i images_2 \
-r 1 \
--eval \
--metallic \
--indirect \
--gamma

python render.py \
-m output/garden \
-s ../data/mip_nerf_360/garden \
--checkpoint output/garden/chkpnt40000.pth \
-i images_2 \
-r 1 \
--eval \
--skip_train \
--pbr \
--metallic \
--indirect \
--gamma
```
Thank you.
