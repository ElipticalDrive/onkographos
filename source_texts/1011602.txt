Why
Comparing our render to a Sketchfab reference of the same model, ours looked pale, plasticky, cool and washed-out. An ultracode multi-agent audit of the render pipeline (7 agents, findings grounded file:line) traced it to the tone-mapping operator, the lighting balance, and a path-tracing divergence.
Changes
Default tone mapping: ACES Filmic → Khronos PBR Neutral. ACES desaturates bright values toward white, so saturated paint highlights (a glossy orange roof) clipped to white and lost their colour. PBR Neutral — built for product/e-commerce — rolls highlights off filmically while preserving material hue, so colours stay rich and highlights keep their tint.
Fixed a latent tone-mapping-operator bug. three renumbered the tone-mapping enum in r160+ (AgX/Neutral added), so toneMapping: 6 in the defaults (commented "ACESFilmic") was actually AgX and only rendered as ACES via an unrelated string fallback — meaning AgX/Neutral could never actually be selected. The operator map + converter now cover agx/neutral and map the real THREE.*ToneMapping constants.
Brighter, bright-but-matte high-key lighting. Near-neutral studio key (was pure white — it was tinting neutral models) over a generous diffuse ambient/hemisphere fill, warm-neutral bounce instead of a cold blue one. Brightness now comes from the diffuse fill, so environmentIntensity drops 0.7 → 0.5 (reflections read matte, not mirror-glossy) with exposure nudged 1.1 → 1.15. Presets retuned to match.
Path tracing inherits the scene/renderer colour state instead of hardcoding environmentIntensity = 2.0 (which made the converged frame ~2.9× brighter than the raster preview) + a dead exposure = 1.5 override. The path-traced frame and raster preview now match.
Default FOV normalized to 45° everywhere (defaultOptions already used 45; the deep ViewerFactory/ThreeCamera fallbacks were a wide 75°).
Verified
Iterated the look against the reference via headless Playwright screenshots (brightness raised, highlight clipping gone, gloss reduced). All 635 unit tests pass (presets/tone-mapping/PT baselines updated); render-smoke 8/8 real-WebGL pixels still pass without re-baselining — the default-look pixel asserts (corner bg, floor luminance, contact-shadow, chroma) held. lint/typecheck/build/smoke/type-smoke/attw green.
Scope note
Crevice ambient occlusion (the reference's biggest remaining advantage) is a separate follow-up: an opt-in GTAO pass behind a flag (it needs an EffectComposer and would break the on-demand render economics of the lazy many-viewers grid if made default). Matching the reference's fully-matte paint is a material/texture property we render faithfully and won't override globally.
