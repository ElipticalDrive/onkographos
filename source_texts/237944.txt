Description
For many training use cases, sampling is often important to train robust models.
In the basic case, you want to use a RandomSampler which is equivalent to local shuffling.
For more advanced use cases, you may want weighted random sampling or stratified sampling if your training data is very imbalanced.
See PyTorch samplers for some examples: https://pytorch.org/docs/stable/data.html#torch.utils.data.Sampler
When using AIR and Ray Datasets, we should provide an API for users to implement various sampling procedures.
Implementation wise, this would look like a windowed all-to-all operation, which may or may not be on the same process as the training worker.
