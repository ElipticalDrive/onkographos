Pull request overview
Adds an (intended-to-be optional) BVH acceleration structure using SAH to reduce per-ray primitive intersection cost by moving traversal responsibility into Scene and exposing per-primitive AABB bounds.
Changes:
Introduces Geometry::AABB + RayTracer::BVH (SAH builder + traversal) and stores BVH state inside Scene.
Updates Camera to call Scene::prepareAccelerationStructure() once per frame and query Scene::hit() for intersections.
Extends primitive API with APrimitive::getBounds() and implements bounds for Sphere (with Plane/Cylinder treated as unbounded); updates multiple scene configs and adds Doxygen docs.

* Behavior:
* - BVH is enabled only when the camera initializer contains `useBVH = true`
* - the camera asks `Scene` to prepare acceleration data, but does not own the BVH itself
* - `Scene` stores the BVH and the unbounded fallback primitives for the current render pass
* - bounded primitives are inserted into the tree
* - unbounded primitives, such as planes and infinite cylinders, stay on the linear fallback path
* - when the flag is absent or false, the renderer keeps the original linear traversal
