What
Add binary 3DGS PLY export for one batch item of activated MLX Gaussian attributes. Closes #34 once merged.
Why
The Gaussian attribute conversion needs a file format that preserves the upstream geometry and 3DGS conventions for compatible viewers.
How
Validate FP32 attribute shapes and finite input/transformed values, select one batch item, rotate positions and quaternions from z-up to y-up, inverse-activate clamped opacity and scale, and write the 17 upstream vertex properties in binary little-endian order. The exporter uses MLX and the Python standard library; it exclusively creates the selected trusted local .ply path and never overwrites an existing file.
```
flowchart LR
  A[Batched activated Gaussian attributes] --> V[Validate and select one batch]
  V --> T[Rotate axes and inverse-activate fields]
  T --> P[Binary 3DGS PLY]
  P --> G[Compatible Gaussian viewer]
```

IDOL_REFERENCE_SOURCE=../idol-sdk-reference python -m unittest discover -s tests -v: 109 tests passed locally using Python 3.13.14.

A synthetic colored sphere with 1500 Gaussians, exported by this implementation, was opened directly and rendered locally in the antimatter15/splat viewer, commit ba182b51b7c2ad5738cdd6741cd63336d27470fb, served on localhost. No user data or weights were uploaded.
A write-time I/O failure can leave an incomplete new file. This check covers one viewer and a synthetic scene, not all viewers, full-size Gaussian limits ([5.7] Test Gaussian counts #36) or end-to-end inference.
