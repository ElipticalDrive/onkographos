mrc_base.h defines memcpy/memset/strlen/etc. as macros that redirect
through MR_* function pointers. Including <string.h> after mrc_base.h
causes the standard library declarations to expand through these macros
and clash with the function-pointer declarations.

strlen() in this file already resolves through SkySDK's
'#define strlen mrc_strlen', so the standard header is not needed.
