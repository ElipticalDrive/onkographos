```
MeshBVH
- Queries take an options object { cull: 'none'|'back'|'front'|boolean,
  near, far } and return a fresh hit (or write into an optional target)
  instead of one static object shared by every tree.
- raycastAll(): every crossing, sorted by distance.
- intersectsRay(): real any-hit early-out instead of a closest-hit query.
- Static raycastGeometry() / raycastGeometryAll(): the same queries without
  building a tree, so a brute-force fallback no longer requires one.
- Hits report frontFace and subGeometryIndex; only LOD 0 index ranges of
  each SubGeometry are indexed (previously every index, including other
  LODs). getSubGeometryIndex().
- Positions/attributes are read through getAttributeView(), which also
  understands the interleaved `all` buffer of compose_bin (prefab)
  geometry; the BVH used to throw "no position attribute" on those.
- build() forces a (re)build with a given leaf size; get() ignored
  maxLeafTris once cached.
- refit(): recompute node bounds after moving vertices in place.
- get() follows the new GeometryBase.version: a position re-upload refits,
  replaced vertex/index arrays rebuild.
- Traversal stack is sized from the tree depth; the fixed 128-entry stack
  overflowed on deep trees and the traversal then spun forever.
- Doc: splits are at the centroid-bounds midpoint, not the mean.

GeometryBase.version / GeometryVertexBuffer.positionVersion: change
counter bumped by setIndices/setVertexs/setAttribute and position uploads.
GeometryVertexBuffer.composeBinLayout getter.

test/system/MeshBVH.test: 12 cases (adds cull/near/far, raycastAll,
tree-less parity, true non-indexed geometry, compose_bin, sub-geometry/LOD
ranges, version refit/rebuild, depth > 128).
```

feat(pick): pick skinned and morph-target meshes as drawn (CPU deform…
…
0fe3287
```
…ation)

The GPU deforms these meshes in the vertex shader, so ray picks against
the static geometry hit the bind pose (for skinned glTF the skinning
matrix replaces the node transform, so hits could be off entirely).

- MeshDeformer replays the shader on the CPU: morph targets first
  (position * baseInfluence + Σ w_i * a_morphPositions_i, via vIndex),
  then skinning — each bone's world matrix read from the same global
  matrix slot the shader reads (Matrix4.dynamicGlobalMatrixRef), times the
  skin's inverse bind matrix, blended by joints0/weights0 (+joints1/
  weights1). Works for SkinnedMeshRenderer2 + AnimatorComponent (glTF) and
  SkinnedMeshRenderer + SkeletonAnimationComponent (prefab). Output is a
  CPU-only geometry (no GPU buffers), cached per renderer and recomputed
  only when bone matrices or morph weights change; queries use a refit BVH.
- MeshRaycast.intersectRenderer: renderer-aware query used by Raycaster
  and MeshColliderShape. Raycaster.deformation / MeshColliderShape
  .deformation: 'cpu' (default) | 'bindPose' | 'skip'. ColliderComponent
  fills MeshColliderShape.renderer so PickFire follows animation too.
- AnimatorComponent.jointMatrixIndexTable (CPU copy of the GPU table);
  MorphTargetData.influences / morphTargetCount / baseInfluence.
- MeshBVH.getAttributeView: 4-wide joints/weights, 1-wide vIndex, 3-wide
  morph attributes.
- test/system/SkinnedRaycast: CPU hits vs the GPU pixel picker's G-buffer
  position on an animated Soldier (10/10 within 0.3 on a ~36-unit model;
  bind pose 0/10) and the lion's blend shapes (9/9); morph math for
  relative/absolute targets, modes and caching; mesh collider.
```
