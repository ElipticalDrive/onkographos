Parent
Phase 0 of the Horizon Zero Dawn-level volumetric cloud roadmap: docs/research/volumetric-clouds-roadmap.md.
What to build
Replace the straight-line self-shadow march with the HZD cone-sampling approach: six jittered samples in an expanding cone toward the sun plus one far sample for distant shadowing. Add a CPU unit test for sample distribution and an integration test showing cone integration is smoother than straight-line integration, then add the NOISE_KERNEL and raymarch_to_light function in WGSL and call it from the primary march.
Screenshot convention
All screenshots for this task go to tests/output/volumetric-clouds/phase-00-fix-prototype/task-05-cone-light-march/.
Required files:
shadow_straight.png
shadow_cone.png
difference.png (optional)
See docs/research/volumetric-clouds-screenshot-convention.md for the full convention.
Acceptance criteria
New unit test verifies six cone samples advance along the sun direction with increasing radius and the far sample is placed at step_size * 8.0.
New integration test shows cone march produces a smoother optical-depth estimate than straight-line march.
cargo test -p aether-engine --lib passes.
target/release/aether-launcher.exe scenes/13_clouds.ron shows softer shadow transitions and more believable distant cloud shadows.
