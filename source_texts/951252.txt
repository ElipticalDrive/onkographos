Descripcion
Componentes SDF separados por primitiva. Cada forma SDF es su propio componente. Usados tanto para render (ray marching) como para colisión (GPU physics).
Componentes

```
    pub radius: f32,
    pub visible: bool,
    pub collide: bool,
}
```

Usa Transform.rotation para la normal del plano.
Ventajas
Cada primitiva tiene solo los campos que necesita
#[derive(Reflect)] directo en todas
CSG operations se harían via Parent/Children (hijo con operación = subtraction/intersection)
Agregar nueva primitiva = nuevo archivo
Notas
El sistema de render SDF itera cada tipo por separado para generar el shader
collide: true hace que el shape participe en colisión GPU sin necesidad de un CollisionShape separado
El visible: false + collide: true permite collision-only shapes (triggers, invisible walls)
Dependencias
Bloquea: Collision detection con SDF #40 (SDF Collision Detection), feat(render): SDF Compute Pathtracer — iluminación físicamente correcta #127 (SDF Pathtracer), feat(sdf): Sparse SDF Storage #136 (Sparse SDF Storage), Hybrid Rendering Pipeline (SDF + Mesh) #91 (Hybrid Rendering)
Bloqueado por: nada
Relacionado: feat(physics): CollisionShape — ECS component mapping to rapier colliders #137 (CollisionShape), feat(ecs): MeshRenderer component — referencia a mesh y material para render de geometría #180 (MeshRenderer — contraparte mesh)
