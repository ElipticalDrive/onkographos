RNoise claims four independent R² dimensions but rescales one scalar using the 2D plastic constant. In the X channel, P and 1/P cancel, leaving fract(t); adding an integer seed has no effect on this channel at fixed sample coordinates. The remaining arbitrary multipliers do not construct a four-dimensional R-sequence.
Use the four-dimensional generalized golden ratio (P^5 = P + 1) with coefficients 1/P through 1/P^4 and flatten the existing 32×32 tile into a sequence index. Keep the R² temporal tile shift, API, and tile size. Correct the documentation to describe deterministic R⁴ samples instead of claiming independent random dimensions or a 64×64 tile.
Reproduce by compensating for the temporal tile shift to compare the same coordinates at seeds 0 and 1. On dev the X values differ only by floating-point roundoff; each channel should change phase.
Validation: changed-file ESLint passes. Hardware GTX 1050 WebGPU and WebGL2 readbacks of all 1024 tile samples at both seeds match a double-precision R⁴ reference within 1e-4 and all channels change with seed. Dev fails the X-channel seed regression. The SSR + denoising example renders without console/page errors and a screenshot was captured. Core units 1957 pass/1 todo; addon units 99 pass; core lint passes. No typecheck script exists.
This changes the noise pattern. It does not claim independent randomness, better denoising quality, or better performance; a deterministic multidimensional sequence still has finite-sample correlations. Further quality comparisons belong to the noise-improvement study. The R-sequence construction is documented in https://docs.sciml.ai/QuasiMonteCarlo/dev/samplers/ (GoldenSample/KroneckerSample; Roberts 2018).
Independent fix from bhouston/agent-swarm#56, tracked by bhouston/agent-swarm#65. Based directly on dev.
Final integration validation (all nine fixes applied to a temporary local validation branch): core unit suite 1960 pass / 1 todo, addon suite 99 pass; core lint, changed-file ESLint, test lint, and example coverage pass. Hardware WebGL2 and WebGPU shader readback regressions pass. Full addon lint still has 5 existing errors, and full example lint has 16 existing errors plus 2 warnings, all in untouched files. The full screenshot suite was not run because its configured software rendering is prohibited on this runner.
