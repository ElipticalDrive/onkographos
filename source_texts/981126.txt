[MAG-038] Plan coarse-to-fine brush strokes from a reference
Campaign: Operation Renaissance | Release: 0.5.0 | Priority: P0 | Area: painter
Objective
Implement a real multiscale painterly reconstruction algorithm.
Implementation requirements
Select passes from broad to fine based on reference pyramid, canvas error and region thresholds.
Use stable seeded sampling and bounded stroke budget; plan strokes before drawing to avoid scheduling-dependent output.
Expose stylistic parameters for brush radii, error threshold, palette quantization and detail priority.
Acceptance criteria
Flat images use few broad strokes and fine details receive additional paint only when needed.
Same reference/settings/seed yield same ordered stroke plan across worker counts.
Memory and step budget controls prevent runaway reconstruction.

Validation / implementation handoff
Implement in pure Luau using the checked-in Jess package manifest and existing modules. No mandatory external programs, Python, Redis, ImageMagick, graphics C extensions, or network services.
Add tests and visual references appropriate for the issue; run package tests, strict style, existing golden checks and relevant benchmark rows.
Do not modify 0.1.3 legacy outputs unless a clearly versioned opt-in API requires it; never regenerate old goldens to hide regressions.
Update jess.toml test/module/export entries when necessary, and relevant README/site/bench docs when semantics change.
Capture actual commands, runtime version, new tests, performance impact and limitations in the PR description.
Do not open a PR until the issue is implemented and locally validated; blocked/unfinished work belongs on the branch or in an issue comment.
Definition of done
Public APIs and semantics documented; implementation obeys architecture RFC MAG-003.
Issue-specific acceptance criteria and tests complete.
Review handoff includes reproduction and metrics where appropriate.
