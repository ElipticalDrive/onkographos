This pull request introduces a comprehensive set of improvements to the volume rendering core for the Isis DICOM Viewer iOS app, focusing on enhanced DICOM geometry handling, flexible multiplanar reformatting (MPR), improved volume rendering shader capabilities, and more robust integration between Swift and Metal. The changes add new files for DICOM geometry and MPR plane material, extend the volume rendering pipeline with new rendering methods and gating options, and improve gradient calculation accuracy in shaders. These updates lay the groundwork for advanced visualization features such as thick slab MPR, gated projections, and anatomically correct volume scaling.
New Features and Major Additions
Added DICOMGeometry.swift to encapsulate essential DICOM geometry mapping between world coordinates, voxel space, and normalized texture coordinates, including world-to-voxel and world-to-texture transformations and plane conversion utilities.
Introduced MPRPlaneMaterial.swift and mpr.metal to support multiplanar reformatting (MPR) with fine and thick slab rendering, including MIP/MinIP/Mean blend modes, and HU normalization, enabling advanced slicing and projection within the volume. [1] [2]
Volume Rendering Pipeline Enhancements
Extended VolumeCubeMaterial with new rendering methods (minip, avg), gating controls for projections, support for real volume dimensions, and the ability to apply transfer functions to projections. The uniforms struct and related API were refactored for clarity and completeness. [1] [2] [3] [4] [5]
Improved handling of empty or missing data in VolumeTextureFactory, ensuring a valid fallback 1x1x1 texture is created when no part is selected, preventing runtime errors.
Shader and Gradient Calculation Improvements
Refactored gradient calculation in shared.metal to accept real volume dimensions as a parameter, ensuring accurate gradient magnitude computation for lighting and rendering effects.
These changes collectively enable more precise and flexible medical image visualization, supporting advanced MPR and volume rendering techniques with robust geometry and shader integration.
