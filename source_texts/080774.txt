Implemented creative procedural modifiers for mesh voxelization:
- `--scale-xyz`: Non-uniform anisotropic scaling during initial `TriMesh` construction.
- `--hollow <thickness>`: Extracts a hollow shell by discarding internal solid voxels beyond a specific depth/distance from the surface.
- `--gyroid <frequency>,<thickness>`: Generates a beautiful procedural gyroid lattice infill using a 3D trigonometric function during solid voxelization testing, ideal for 3D printing preparation.

These features plug natively into the existing parallel Rayon raycast loops without affecting memory overhead.

Validate modifier thickness values before voxelizing
When the CLI is invoked with invalid modifier dimensions such as --hollow=-0.1 or --gyroid=10,-0.1, these raw f64 values are accepted and passed through to the voxelizer. A negative hollow thickness makes the sdf < -h check discard essentially every interior voxel, and a negative gyroid thickness makes val.abs() > thickness true for every candidate, so the command can silently succeed with an empty or nonsensical output instead of rejecting the input. Please add finite, non-negative validation for these thickness parameters, similar to --narrow-band.
