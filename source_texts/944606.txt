Fixes the hang after swapchain init when voxelizing dense GLTFs on the main thread by clamping voxel density and adding robust fallbacks.
Changes
Auto‑clamp voxel density: increases voxel size until total grid cells ≤ ~8M. Logs dims and adjusts with a single pass loop ([vox] tagged logs).
Close‑surfaces retry: if flood‑fill yields zero solids, retry once with --close-surfaces (auto) and log.
Fallback to demo: if retry is still empty, logs and falls back to the demo grid so the app never beachballs.
Why
Large GLTF + small --voxel-size could create tens of millions of voxels and beachball the window during surface mark + flood‑fill.
The cap keeps rasterization and fill under control so swapchain init isn’t followed by a frozen UI.
Notes
No threading changes yet (optional next step). This is a cheap guardrail that keeps UX smooth.
CI: cargo xtask ci is green (fmt, clippy ‑D warnings, WGSL validation, tests, schema).
How to verify
Coarse demo:
cargo run -p ruinsofatlantis -- --vox-sandbox --voxel-demo --voxel-size 0.1 --chunk-size 32 32 32
GLTF demo (auto clamp kicks in as needed):
RUST_LOG=info cargo run -p ruinsofatlantis -- --vox-sandbox --voxel-model assets/models/ruins.gltf --voxel-size 0.05 --chunk-size 32 32 32
Observe [vox] dims=… (~x.xxM) log lines and no UI hang. Press 3 to blast; R to reset/replay.
