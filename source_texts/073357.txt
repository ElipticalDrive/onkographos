Summary
Currently, examples/06_voxel_renderer showcases voxel raymarching via DDA in a fragment shader.
A great complementary example would be a classic polygonal chunk mesher that generates indexed 3D quad meshes from voxel chunk arrays using Greedy Meshing (combining coplanar adjacent faces into single quads).
What this demonstrates:
lgpu dynamic rendering with a dedicated depth buffer (TextureFormat::Depth32Float).
Structured vertex & index buffer allocation using device.create_buffer_init_slice().
Drawing with encoder.draw_indexed_with_depth().
A real-world reference for game developers building block games or voxel engines with lgpu.
Relevant APIs
lgpu::Device::create_graphics_pipeline_with_depth
lgpu::CommandEncoder::draw_indexed_with_depth
lgpu::BufferUsage::VERTEX / INDEX
