Changes
Player Struct
Changed player.x and player.y from int to double to represent precise world coordinates rather than map grid indices.
Ray Data Structures
Introduced t_ray struct to encapsulate DDA raycasting parameters.
Added t_ray_data struct with fields angle, angle_offset and dist for per-frame ray results.
Added rays array of t_ray_data in the t_game struct so each ray is cast only once per frame.
DDA Raycasting
Created cast_rays file that implements the DDA algorithm to compute actual wall distances for every screen column.
Updated minimap renderer to use real DDA distances instead of placeholder values.

Pull Request Overview
This PR implements DDA-based minimap rendering by switching to precise world coordinates and introducing raycasting data structures and logic.
Player position and direction now use double precision and are offset to the world cell center.
Added t_ray and t_ray_data for DDA raycasting and compute per-frame distances.
Updated minimap drawing to render rays using real DDA distances.
