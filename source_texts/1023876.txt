# DualNumbers-Julia

This project implements a **Dual Number arithmetic system** in Julia using Pluto.jl to compute **first- and second-order derivatives** via automatic differentiation.

---

## 📌 Objective

The objective is to:
- Design and implement a Dual Number system in Julia
- Implement core algebraic operations and elementary functions
- Compute first- and second-order derivatives using automatic differentiation

---

## 📘 Concept

A dual number is defined as:

D = a + bε, where ε² = 0. 

- `a` → value (primal)
- `b` → derivative (ε coefficient)

---

## ⚙️ Features

- Custom `Dual` type
- Operator overloading:
  - `+`, `-`, `*`, `/`, `^`
- Elementary functions:
  - `sin`, `cos`, `exp`, `sqrt`
- Automatic differentiation:
  - First derivative
  - Second derivative (nested dual numbers)
