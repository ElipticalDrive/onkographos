Light Propagation Volumes (LPV) is a lightweight method of rendering Diffuse Global Illumination which approximates the bounce light from the sun. Built from scratch with performance and simplicity of usage in mind, the plugin provides an efficient method of lighting the game environments.
Features
Instant reaction from lighting change (no ghosting or temporal noise)
Cascade system, supporting for a farther light travel distance
Custom implementation of Occlusion (or Geometry Volume) based of SDF, preventing a lot of light leaking
Supports Sky Atmosphere & Volumetric Cloud Shadows
Supports DX11, DX12 & Vulkan
Supports stereo rendering
Game-ready performance
No special setup required
Configurable CVars
Lightweight
No method of GI out there is perfect, so here are some cons
Supports only Deferred renderer (Forward renderer is not supported - engine limitation)
Not physically correct, so it’s not the best fit for cinematics
Some light leaking remains unavoidable because of the low resolution nature of the effect
