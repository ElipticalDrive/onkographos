# Recoverable image-space ray-budget allocation for NeRF training

This repository contains the reproducibility package for the manuscript:

**Recoverable image-space ray-budget allocation for representation-agnostic NeRF training acceleration**

The artifact accompanies a resubmission to *The Visual Computer* and provides
the implementation, configuration templates, processed experiment summaries,
diagnostic figures and rerun scripts used in the revised manuscript.

## What is included

- `code/nerf-ours/`: NeRF training code with the image-space quadtree sampler,
  soft pruning and split-only recovery logic.
- `code/nerfpp-ours/`: NeRF++-style training code used for the supplemental
  Ship transfer probe, with the same warm-up pruning and split-only recovery
  controller integrated into its ray-sampling path.
- `configs/`: Blender-synthetic scene configuration files, including the
  NeRF++-style Ship transfer-probe configs under `configs/nerfpp-blender-ship/`.
- `data/`: processed CSV tables used by the manuscript, including runtime
  breakdowns, sensitivity/Pareto summaries, repeated-seed summaries and the
  NeRF++-style Ship transfer-probe summary.
- `figures/`: manuscript and diagnostic figure assets.
- `scripts/`: experiment queue, summary and diagnostic-asset helpers.

Large datasets, checkpoints, tree pickle files and rendered image folders are
not stored in this repository. The public Blender synthetic dataset should be
downloaded separately from the original NeRF project.

## Main reproduced evidence

The current artifact documents the following revised-manuscript experiments:

- Principal Lego 18-epoch runtime comparison:
  progressive baseline, fixed soft pruning and split-only mean-standard-deviation recovery.
- Lego 4-epoch sensitivity/Pareto probe over pruning threshold and residual-ray ratio.
- Lego 4-epoch three-seed variability probe.
- Supplemental NeRF++-style Ship 18-epoch transfer probe.
- Diagnostic rendering-error maps and quadtree visualizations.

The manuscript intentionally treats the evidence as scoped to Blender-synthetic
scenes and a limited set of implementations. Real captured, unbounded and
strongly view-dependent scenes remain future validation targets.

## Minimal environment

The NeRF experiments were run in a CUDA-enabled PyTorch environment. A typical
setup is:

```bash
cd code/nerf-ours
pip install -r requirements.txt
```

The original experiments used an RTX 4090-class GPU for the reported runtime
breakdowns. Smaller GPUs can run smoke tests but should not be used for direct
runtime comparison with the manuscript tables.

## Minimal reproduction commands

Replace `../../data/nerf_synthetic/lego` with the local path to the Blender Lego
scene if needed.

Short soft-pruning probe:

```bash
cd code/nerf-ours
python run_nerf.py \
  --config ../../configs/lego.txt \
  --datadir ../../data/nerf_synthetic/lego \
  --half_res \
  --N_rand 4096 \
  --seed 0 \
  --n_epoch 4 \
  --init_level 5 \
  --subdivide_every 999 \
  --prune_after_epoch 1 \
  --prune_loss_thres 0.010 \
  --coarse_ray_ratio 0.20 \
  --coarse_min_rays 10 \
  --randSamp_perc 1.0
```

Long split-only recovery probe:

```bash
cd code/nerf-ours
python run_nerf.py \
  --config ../../configs/lego.txt \
  --datadir ../../data/nerf_synthetic/lego \
  --half_res \
  --N_rand 4096 \
  --seed 0 \
  --n_epoch 18 \
  --init_level 7 \
  --subdivide_every 999 \
  --prune_after_epoch 3 \
  --prune_loss_thres 0.001 \
  --coarse_ray_ratio 0.20 \
  --coarse_min_rays 10 \
  --dynamic_tree_update \
  --dynamic_update_after_epoch 4 \
  --dynamic_update_every 1 \
  --dynamic_merge_loss_thres 0.005 \
  --dynamic_split_only \
  --dynamic_split_loss_thres 0.001 \
  --dynamic_split_metric mean_std \
  --dynamic_split_std_weight 1.0 \
  --dynamic_split_max_depth 1 \
  --randSamp_perc 1.0
```

The manuscript experiment queues are provided in:

```bash
scripts/run_tvc_mandatory_experiments.sh
scripts/run_tvc_mandatory_experiments.ps1
```

Additional Chair/Ficus progressive-baseline runs for cross-scene rendering
comparison can be launched with:

```bash
bash scripts/run_tvc_mandatory_experiments.sh cross_scene_baselines
```

Supplemental NeRF++-style Ship transfer probe:

```bash
bash scripts/run_nerfpp_ship_transfer.sh /path/to/nerf_synthetic/ship
```

This command first converts the Blender synthetic Ship scene into the normalized
NeRF++-style directory layout, then runs the 18-epoch baseline and split-only
mean-standard-deviation recovery configurations used for the transfer-probe
summary in `data/tvc_nerfpp_ship_e18_summary_20260620.csv`.

Processed summaries can be regenerated from completed logs using:

```bash
python scripts/summarize_tvc_mandatory_experiments.py
```

Diagnostic assets can be regenerated only when the relevant checkpoints and
`treeDivide_*.pkl` files are available:

```bash
bash scripts/export_tvc_diagnostic_assets.sh
```

## Data availability

The Blender synthetic dataset is publicly available from the original NeRF
project. This repository includes processed metrics and configuration templates,
but not the dataset images, pretrained models, checkpoints or full rendered
test folders.
