Summary:
The previous PR added cuteDSL kernels for mxfp8 quantization. This PR adds a public frontend following #195481, and hooks up the mxfp8 recipes to the kernels from the previous PR.
Specifically, we add:
public F.quantize_tensor to quantize along a single 2d axis (dim-k or dim-m) and F.quantize_tensor_dual for quantizing along both a 2d axis and its inverse (dim-km and dim-mk). For now, only mxfp8 with RTNE is supported. Other recipes and argument settings will be added in future PRs.
_quantize_tensor and _quantize_tensor_dual private APIs to native_functions.yaml for the dispatcher
The new user facing APIs:
```
# docblock in the code, skipped here for brevity
class ScalingAlgorithm(enum.IntEnum):
    MXFP_E8M0_RU = 0
...

# docblock in the code, skipped here for brevity
def quantize_tensor(
    input: Tensor,
    *,
    dim: tuple[int, int],
    scaling_type: ScalingType,
    qdata_dtype: torch.dtype,
    scaling_algorithm: ScalingAlgorithm,
    swizzle_type: SwizzleType,
    scaling_type_use_square_block_size: bool = False,
) -> tuple[Tensor, Tensor]

# docblock in the code, skipped here for brevity
def quantize_tensor_dual(
    input: Tensor,
    *,
    dim: tuple[int, int],
    scaling_type: ScalingType,
    qdata_dtype: torch.dtype,
    scaling_algorithm: ScalingAlgorithm,
    swizzle_type: SwizzleType,
    scaling_type_use_square_block_size: bool = False,
) -> tuple[Tensor, Tensor, Tensor, Tensor]
```
Quantizing to mxfp8 looks like this:
```
_MXFP8_KWARGS = {
    "scaling_type": F.ScalingType.BlockWise1x32,
    "qdata_dtype": torch.float8_e4m3fn,
    "scaling_algorithm": F.ScalingAlgorithm. MXFP_E8M0_RU,
    "swizzle_type": F.SwizzleType.SWIZZLE_32_4_4,
}

# dim-k
x_k_q, x_k_s = F.quantize_tensor(x, dim=(-2, -1), **_MXFP8_KWARGS)
# dim-m
x_m_q, x_m_s = F.quantize_tensor(x, dim(-1, -2), **_MXFP8_KWARGS)
# dim-km
x_k_q, x_k_s, x_m_q, x_m_s = F.quantize_tensor_dual(x, dim=(-2, -1), **_MXFP8_KWARGS)
# dim-k with 32x32 scaling
x_k_32x32_q, x_k_32x32_s = F.quantize_tensor(
    x, 
    dim=(-2, -1),
    scaling_type_use_square_block_size=True,
    **_MXFP8_KWARGS,
)
# batched
x = torch.randn(B0, M, B1, K, B2, device="cuda")
xq, s = F.quantize_tensor(x, dim=(1, 3), **_MXFP8_KWARGS)
```

an optional flag to skip outputting the dim-m qdata output for quantize_tensor_dual + square scaling
