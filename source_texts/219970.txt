# Morton Pointcloud

A Python library for efficiently encoding and processing point cloud data using Morton encoding (Z-order curve).

## Description

Morton encoding is a space-filling curve technique that maps multidimensional data to one dimension while preserving locality of the data points. This makes it useful for:

- Spatial indexing and nearest neighbor searches
- Efficient storage and retrieval of point cloud data
- Octree/quadtree data structure implementations
- Accelerating spatial operations on point clouds

This library provides efficient tools for working with Morton encoded point cloud data in Python.
