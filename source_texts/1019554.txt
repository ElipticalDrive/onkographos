Pull request overview
This PR introduces an optional 8×8×8 Morton-tiled voxel storage layout (selected at build time) and threads the resulting “flat index” convention through DICOM voxel loading and raytracing so traversal emits indices matching the chosen layout.
Changes:
Add osh_voxel_order module (Morton-8 indexing + row-major→layout reordering) and wire it into osh_common.
Extend osh_raytrace_grid with tile_order and update Siddon/Jacobs traversal to emit Morton-tiled indices when requested.
Update DCM geometry parsing/tests and add new unit tests validating reordering and Morton indexing.
