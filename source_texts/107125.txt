Motivation
Provide a first vertical slice of a world-space volumetric dust system by implementing a low-frequency far-field representation and an interactive Three.js demo to validate contracts and rendering approach.
Establish public data contracts and a deterministic packet-tier so future WebGPU MAC-grid islands and grid↔packet handoff can be added behind the same interface.
Ship a runnable dev/build configuration and a small automated test suite to catch regressions in the packet simulation.
Description
Added a Vite + TypeScript + Three.js application that renders an interactive city-block scene with orbit controls, lighting, rubble, and a UI to trigger repeatable collapse events (index.html, package.json, tsconfig.json, src/main.ts, src/style.css).
Implemented a deterministic far-field VolumePacketSimulation that emits mass-conserving MediumEmissionEvents, advances packets at a fixed 20 Hz step, models wind entrainment, cold-aerosol density loading, ground interaction, packet expansion, and rigid-body wake coupling (src/simulation.ts).
Declared typed public contracts VolumePacket, MediumEmissionEvent, and DynamicBodySample and a small quality enum in src/types.ts used across simulation and renderer.
Added an instanced anisotropic volumetric shader and instance-update logic to visualize packets as ellipsoids with procedural turbulence and forward scattering, plus a small UI showing active packet count and field mass (src/main.ts).
Included unit tests for the packet simulation that verify mass conservation, ground containment, and response to off-screen body wakes (src/simulation.test.ts) and small operational files (.gitignore, README updates).
Testing
Ran the unit test suite with vitest and all tests passed (2 tests, 2 passed).
Performed a production build (tsc --noEmit && vite build) which completed successfully and produced the distributable assets.
Ran npm install and the test/build steps in CI-like commands during development and observed no automated-test regressions.
