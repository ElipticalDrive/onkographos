Devlog
Added
Voxel data model (src/world/block.rs, chunk.rs, coords.rs): block IDs/properties, signed world and chunk coordinates, negative-coordinate-safe mapping, and fixed 16×16×16 chunk storage.
Deterministic terrain generation (src/world/generation.rs): seeded terrain, flat mode, hills, and plains/desert biomes.
Exposed-face meshing (src/world/mesh.rs): emits visible block faces and samples neighbors across chunk boundaries.
GPU world rendering and background streaming (src/renderer.rs, src/world/streaming.rs, src/main.rs): render chunk meshes, generate chunks on a worker thread, and stream a horizontal region around the camera; include CPU/GPU mesh memory estimates.
Project status and implementation notes (README.md, ROADMAP.md, docs/MILESTONE_2.md).
Fixed / replaced
Replaced the initial standalone cube scene with generated voxel terrain and chunk meshes as the rendered world.
Made chunk-edge face visibility depend on neighboring world data, including neighbors that have not been loaded into the active view.
Verification
cargo fmt --all -- --check
cargo check --locked --all-targets --all-features
cargo clippy --locked --all-targets --all-features -- -D warnings
cargo test --locked --all-targets --all-features -- --nocapture — 20 tests passed.
git diff --check
Interactive rendering was verified on Intel Iris Pro / Metal on macOS.
Known limits
Streaming is horizontal on the camera's current vertical chunk layer.
Water uses the opaque color pipeline; transparency and fluid simulation are not implemented.
Greedy meshing was considered but not implemented; exposed-face meshing remains the correctness baseline.
Windows and Linux GPU runtime were not verified; CI does not establish runtime rendering support.
