Cloud volumes currently affect camera rays, but do not attenuate light traveling from a light source to a shaded surface. Add cloud transmittance to the lighting/shadow-ray path so clouds cast soft volumetric shadows onto scene geometry.
Scope
Evaluate each relevant CloudLayer along light rays from shaded points, using the existing density integration and Beer-Lambert transmittance.
Limit integration to the light path (including finite light distance) and preserve the current result when the path misses every cloud.
Compose transmission through multiple cloud layers without applying camera-ray cloud scattering a second time.
Definition of done
Surfaces behind a cloud receive less direct illumination when the light path intersects the cloud; equivalent surfaces with an unobstructed light path remain unaffected.
Tests cover a cloud intersecting a shadow ray, a ray missing the cloud, finite-distance lights, and multiple cloud layers.
