The tuto
Seems a full cubic matrix of "126" is centered on origine at Z=0
so this in a modeler without unity
(12.6 * 2 = 25.2)
Say this object inside a 3D modeler
Imported in Magica we have that even the size of the Moi Object is twice, *10 or any thing else!
It centered along the biggest length(s) and adapted to 126 along the 3 axis x,y,z
We need to have a cool trick for have any position wanted inside the Matrix 126
The trick is to modelize (or place) in the modeler your object inside 8 cubes who are in the corner of the Matrix!
Like this you can have any objects who will be easilly aligned!
Here objects must be aligned on a side and smallest than "126" )
So something like that very easy to erase when objects are aligned like you want!
When you increase size object inside Moi in using more than one matrix (if it not sufficient for a big object(s) )
cubes become more smaller and increase the precision!
