Goal
Shoot a ray from the camera through each pixel and test whether it hits a single sphere. Hits are colored solid red; misses show the sky from M1.
Tasks
Add a Vec3 class (add, subtract, scale, dot, length, normalize)
Add a Ray class with origin, direction, and at(t)
Add a simple camera that generates a ray for pixel (i, j)
Implement hit_sphere(center, radius, ray) using the quadratic formula
Render a red sphere centered in front of the camera
Acceptance criteria
Output shows a red circle centered in the image on the sky background
Moving the sphere's center in code moves the circle in the image as expected
You have set a breakpoint inside hit_sphere in the VS Code debugger and stepped through one hitting ray and one missing ray (note what you learned in the PR description)
Tool focus
VS Code debugger: breakpoints, conditional breakpoints (e.g. only for pixel at the image center), the Variables panel, and the Debug Console.
