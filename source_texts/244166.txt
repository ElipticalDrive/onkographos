Summary
Fixes delta-tracking free-flight and path depth so fog multiple scattering can run at 1000+ bounces. Builds on #11 (VDB fog pipeline).
Changes
Raise null-collision safety caps on VDB free-flight / ratio-tracking Tr and homogeneous tracking from 256/64/512 to 2²⁰ so dense Λ·L segments no longer truncate mid-walk (biased early exit).
Lift Max Ray Depth and Russian Roulette Depth UI/settings range from 64 → 4096 (volume scatters count toward path depth).
Regression: free-flight completes; settings accept depth 1024. SOL_ONLY_VDB=1 tests pass locally.
Usage
For deep volume MS set e.g. Max Ray Depth = 1024 and Russian Roulette Depth ≈ the same (otherwise RR kills deep paths early). Algorithm remains unbiased delta tracking.
