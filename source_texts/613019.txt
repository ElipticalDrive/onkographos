Via offline mesh conversion to a SVO of SDF values, and shader traversal using Morton code lookup via binary search. In theory, the SVO binary data could be packed into e.g a PNG image file, then uploaded to the shader as a texture. We can then build a small library of SVO meshes in this PNG form, and use them in scenes.
