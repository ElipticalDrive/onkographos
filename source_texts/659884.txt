TILE tensors carry their tile geometry in TensorSpec and buffer pages. These ops accept small tiles without a check, then use 32x32 counts/sizes: TILE_HEIGHT/WIDTH/HW, tt::tile_size(format) or missing tile_format_metadata (default 32x32: dataflow_buffer_spec.hpp:94-96). Results include stalls, wrong values, writes into another allocation and unrelated errors. Binary_ng rejects non-32x32 since #60507. We found no per-op support contract: docstrings list TILE only; #14517 concerns CCL, #47597/#36281 LLK.
One Blackhole chip, main f5985995a, default fast dispatch, fresh processes. Controls first; noncompleting cases last. Timeout/reset observations are prose.

A. Argmax
Run python3 repro_argmax_small_tile.py for controls, then --case 32x16; repeat with --shape small --keepdim. Run --case 16x32 and --shape small --keepdim --case 16x32 last in separate fresh processes; each selected case follows controls.
```
#!/usr/bin/env python3
"""One chip. Controls first; a selected small tile runs last.

--case 16x32 or 32x16; --shape small gives [1,1,64,96], large gives
[2,3,64,96]. --keepdim selects the output shape. Every row permutes 0..95,
so the values are exact in bfloat16 and each row has one maximum.
"""
import argparse
import math
import torch
import ttnn


def run_case(device, shape, tile, keepdim, seed):
    gen = torch.Generator().manual_seed(seed)
    rows = math.prod(shape[:-1])
    host = torch.stack([torch.randperm(shape[-1], generator=gen) for _ in range(rows)])
    host = host.reshape(shape).to(torch.bfloat16)
    layout = ttnn.ROW_MAJOR_LAYOUT if tile is None else ttnn.TILE_LAYOUT
    options = {} if tile is None else {"tile": ttnn.Tile(list(tile))}
    tensor = ttnn.from_torch(host, dtype=ttnn.bfloat16, layout=layout, device=device,
                             memory_config=ttnn.DRAM_MEMORY_CONFIG, **options)
    stored = ttnn.to_torch(tensor).clone()
    if not torch.equal(stored, host):
        raise AssertionError("Input roundtrip differs before argmax")
    expected = stored.float().argmax(dim=-1, keepdim=keepdim)
    tile_name = "ROW_MAJOR" if tile is None else "%dx%d" % tile
    label = f"argmax {list(shape)} {tile_name} keepdim={keepdim}"
    print(f"{label}: calling argmax", flush=True)
    output = ttnn.argmax(tensor, dim=-1, keepdim=keepdim)
    print(f"{label}: call returned; synchronizing", flush=True)
    ttnn.synchronize_device(device)
    got = ttnn.to_torch(output).long()
    if got.shape != expected.shape:
        raise AssertionError(f"{label}: shape {tuple(got.shape)}, expected {tuple(expected.shape)}")
    wrong = int((got != expected).sum())
    print(f"{label}: {wrong} of {expected.numel()} indices wrong", flush=True)
    return wrong


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--case", choices=("16x32", "32x16"))
    parser.add_argument("--shape", choices=("small", "large"), default="large")
    parser.add_argument("--keepdim", action="store_true")
    args = parser.parse_args()
    shape = (1, 1, 64, 96) if args.shape == "small" else (2, 3, 64, 96)
    device = ttnn.open_device(device_id=0)
    try:
        for i, tile in enumerate(((32, 32), None)):
            if run_case(device, shape, tile, args.keepdim, 10 + i):
                raise AssertionError("Control failed")
        if args.case:
            tile = tuple(map(int, args.case.split("x")))
            run_case(device, shape, tile, args.keepdim, 3 if args.case == "16x32" else 4)
    finally:
        ttnn.close_device(device)


if __name__ == "__main__":
    main()

R. Cached reshape and two-call stack/unsqueeze
Save as repro_reshape_small_tile_cached.py. Run without arguments and with --back-to-back for controls. Then, in fresh processes, run --case reshape and --case reshape --back-to-back; selected small-tile case last.
```
#!/usr/bin/env python3
"""Two identical calls with program cache enabled; controls precede the selected case.

Default: 32x32 controls only. Select the final small-tile case with --case.
By default synchronize and compare call 1 before calling again. Add
--back-to-back to queue both calls before synchronization, as in the old repros.
"""
import argparse
import torch
import ttnn


CASES = ("stack", "unsqueeze", "reshape", "reshape-unsqueeze")


def run_case(device, case, tile, seed, back_to_back):
    inputs, stored = [], []
    for offset in range(2 if case == "stack" else 1):
        gen = torch.Generator().manual_seed(seed + offset)
        host = (torch.randint(-16, 17, (2, 3, 64, 96), generator=gen).float() / 8).to(torch.bfloat16)
        tensor = ttnn.from_torch(host, dtype=ttnn.bfloat16, layout=ttnn.TILE_LAYOUT,
                                 tile=ttnn.Tile(list(tile)), device=device,
                                 memory_config=ttnn.DRAM_MEMORY_CONFIG)
        readback = ttnn.to_torch(tensor).clone()
        if not torch.equal(readback, host):
            raise AssertionError("Input roundtrip differs before the first call")
        inputs.append(tensor)
        stored.append(readback)
    if case == "stack":
        expected = torch.stack(stored, dim=3)
        call = lambda: ttnn.stack(inputs, 3)
    elif case == "unsqueeze":
        expected = stored[0].unsqueeze(3)
        call = lambda: ttnn.unsqueeze(inputs[0], 3)
    elif case == "reshape-unsqueeze":
        expected = stored[0].reshape(2, 3, 64, 1, 96)
        call = lambda: ttnn.reshape(inputs[0], [2, 3, 64, 1, 96])
    else:
        expected = stored[0].reshape(2, 3, 128, 48)
        call = lambda: ttnn.reshape(inputs[0], [2, 3, 128, 48])
    label = f"{case} tile {tile[0]}x{tile[1]}"

    def compare(output, number):
        got = ttnn.to_torch(output)
        if got.shape != expected.shape:
            raise AssertionError(f"{label}: shape {tuple(got.shape)}, expected {tuple(expected.shape)}")
        wrong = int((got != expected).sum())
        print(f"{label} call {number}: {wrong} of {expected.numel()} values wrong", flush=True)
        return wrong

    before = device.num_program_cache_entries()
    print(f"{label}: calling first operation (cache entries {before})", flush=True)
    first = call()
    after_first = device.num_program_cache_entries()
    if back_to_back:
        print(f"{label}: first call returned; deferring synchronization", flush=True)
    else:
        print(f"{label}: first call returned; synchronizing", flush=True)
        ttnn.synchronize_device(device)
        first_wrong = compare(first, 1)
    # Keep first and the same input objects alive across the second call.
    print(f"{label}: calling second operation with identical inputs "
          f"(cache entries {after_first})", flush=True)
    second = call()
    print(f"{label}: second call returned; synchronizing", flush=True)
    ttnn.synchronize_device(device)
    if back_to_back:
        first_wrong = compare(first, 1)
    second_wrong = compare(second, 2)
    after_second = device.num_program_cache_entries()
    print(f"{label}: cache entries {before} -> {after_first} -> {after_second}", flush=True)
    return first_wrong or second_wrong


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--case", choices=CASES)
    parser.add_argument("--back-to-back", action="store_true")
    args = parser.parse_args()
    device = ttnn.open_device(device_id=0)
    try:
        device.enable_program_cache()
        for i, case in enumerate(CASES):
            if run_case(device, case, (32, 32), 100 + 10 * i, args.back_to_back):
                raise AssertionError("32x32 two-call control failed")
        if args.case:
            tile = (32, 16) if args.case == "reshape" else (16, 32)
            run_case(device, args.case, tile, 300 + 10 * CASES.index(args.case), args.back_to_back)
    finally:
        ttnn.close_device(device)


if __name__ == "__main__":
    main()

```
#!/usr/bin/env python3
"""Match the original two-call stack/unsqueeze device and readback sequence.

Run without arguments for 32x32 controls first. Then, in fresh processes, run
--case stack or --case unsqueeze. A selected case has no preceding warmup,
preserving the original absence of preceding warmup. All time limits and
device recovery belong to the external runner.
"""
import argparse
import torch
import ttnn


SHAPE = (2, 3, 64, 96)
SEEDS = {"stack": (491855706, 491855707), "unsqueeze": (832501207,)}


def neq(a, b):
    return (a != b) & ~(torch.isnan(a) & torch.isnan(b))


def run_case(case, tile):
    device = ttnn.open_device(device_id=0, l1_small_size=32768, trace_region_size=0)
    try:
        device.enable_program_cache()
        grid = device.compute_with_storage_grid_size()
        print(f"compute grid {grid.x}x{grid.y}", flush=True)
        inputs, hosts = [], []
        for seed in SEEDS[case]:
            gen = torch.Generator().manual_seed(int(seed) % (1 << 31))
            host = torch.randn(SHAPE, generator=gen).to(torch.bfloat16)
            tensor = ttnn.from_torch(host, dtype=ttnn.bfloat16, layout=ttnn.TILE_LAYOUT,
                                     device=device, memory_config=ttnn.DRAM_MEMORY_CONFIG,
                                     tile=ttnn.Tile(list(tile)))
            inputs.append(tensor)
            hosts.append(host)
        label = f"{case} tile {tile[0]}x{tile[1]} original sequence"
        # No input readback, cache-count query or synchronize is inserted here.
        if case == "stack":
            x0, x1 = inputs
            print(f"{label}: calling first operation", flush=True)
            out1 = ttnn.stack([x0, x1], 3)
            print(f"{label}: calling second operation with identical inputs", flush=True)
            out2 = ttnn.stack([x0, x1], 3)
        else:
            x = inputs[0]
            print(f"{label}: calling first operation", flush=True)
            out1 = ttnn.unsqueeze(x, 3)
            print(f"{label}: calling second operation with identical inputs", flush=True)
            out2 = ttnn.unsqueeze(x, 3)
        # Retain both device outputs and clone each readback, in the original order.
        print(f"{label}: second call returned; reading output 1", flush=True)
        got1 = ttnn.to_torch(out1).clone()
        print(f"{label}: output 1 read; reading output 2", flush=True)
        got2 = ttnn.to_torch(out2).clone()
        print(f"{label}: both outputs read; reading inputs", flush=True)
        stored = [ttnn.to_torch(t).double() for t in inputs]
        input_changed = any(t.shape != h.shape or bool(neq(t, h.double()).any())
                            for t, h in zip(stored, hosts))
        if case == "stack":
            expected = torch.stack(stored, dim=3)
        else:
            expected = stored[0].unsqueeze(3)
        got1, got2 = got1.double(), got2.double()
        if got1.shape != expected.shape or got2.shape != expected.shape:
            raise AssertionError(f"{label}: output shapes differ from {tuple(expected.shape)}")
        bad1 = neq(got1, expected) | (~torch.isfinite(got1) & torch.isfinite(expected))
        bad2 = neq(got2, expected) | (~torch.isfinite(got2) & torch.isfinite(expected))
        wrong1, wrong2 = int(bad1.sum()), int(bad2.sum())
        repeats = int(neq(got1, got2).sum())
        print(f"{label} call 1: {wrong1} of {expected.numel()} values wrong", flush=True)
        print(f"{label} call 2: {wrong2} of {expected.numel()} values wrong", flush=True)
        print(f"{label}: {repeats} repeated-call differences; inputs changed: {input_changed}", flush=True)
        return bool(wrong1 or wrong2 or repeats or input_changed)
    finally:
        # Inputs and both outputs are still live here, as in the original run().
        print("closing device", flush=True)
        ttnn.close_device(device)
        print("device closed", flush=True)


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--case", choices=("stack", "unsqueeze"))
    args = parser.parse_args()
    if args.case:
        return int(run_case(args.case, (16, 32)))
    for case in ("stack", "unsqueeze"):
        if run_case(case, (32, 32)):
            raise AssertionError(f"{case} 32x32 control failed")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

F. ttnn.gather and ttnn.fill_implicit_tile_padding: 32x32 controls and a 16x16 gather without padding, then 16x16 and 16x32 tiles
```
"""ttnn.fill_implicit_tile_padding with a 16x16 or 16x32 tile writes past the pages of the tensor it pads, into the
next DRAM allocation. ttnn.gather runs that fill on its input and index tensors before it computes, so a 16x16
gather changes its index input.

All tensors are uploaded first, in interleaved DRAM: each case's tensors one after the other (DRAM allocates
upward), then a 4 KB-per-bank spacer, so a case can only change its own tensors and its spacer. The 32x32 cases and
a 16x16 gather of width 32 (no padding, so no fill) run first. Values are exact in their dtypes."""
import torch
import ttnn

device = ttnn.open_device(device_id=0)
DRAM = ttnn.DRAM_MEMORY_CONFIG


def upload(values, dtype, tile):
    return ttnn.from_torch(values, dtype=dtype, layout=ttnn.TILE_LAYOUT, tile=ttnn.Tile(tile), device=device,
                           memory_config=DRAM)


def spacer():
    return ttnn.from_torch(torch.zeros(1, 1, 8, 2048, dtype=torch.bfloat16), dtype=ttnn.bfloat16,
                           layout=ttnn.ROW_MAJOR_LAYOUT, device=device, memory_config=DRAM)


def x_values(width):  # multiples of 1/4 in [-7.5, 7.5]
    i = torch.arange(64 * width).reshape(1, 1, 64, width)
    return ((i % 61 - 30) / 4).to(torch.bfloat16)


def index_values(width):  # 0 .. width - 1
    rows = torch.arange(64).reshape(1, 1, 64, 1)
    cols = torch.arange(width).reshape(1, 1, 1, width)
    return ((rows * 5 + cols * 3) % width).to(torch.int32)


def index_back(t):  # the uint32 index as exact integers
    return torch.from_numpy(ttnn.to_torch(t).numpy().astype("int64"))


def gap(first, second):
    return second.buffer_address() - first.buffer_address()


# (name, tile, width); 8388736 is 0x00800080, two bfloat16 copies of 1.18e-38, the value gather fills its input with
gather_cases = [
    ("gather, 32x32 tile, width 31", [32, 32], 31),
    ("gather, 16x16 tile, width 32", [16, 16], 32),
    ("gather, 16x16 tile, width 31", [16, 16], 31),
]
fill_cases = [
    ("fill_implicit_tile_padding(x, 7.0), 32x32 tile", [32, 32]),
    ("fill_implicit_tile_padding(x, 7.0), 16x16 tile", [16, 16]),
    ("fill_implicit_tile_padding(x, 7.0), 16x32 tile", [16, 32]),
]
gathers = []
for name, tile, width in gather_cases:
    x = upload(x_values(width), ttnn.bfloat16, tile)
    index = upload(index_values(width), ttnn.uint32, tile)
    gathers.append((name, x, index, spacer()))
fills = []
for name, tile in fill_cases:
    x = upload(x_values(31), ttnn.bfloat16, tile)
    after_x = upload(torch.full((1, 1, 64, 32), 3.0, dtype=torch.bfloat16), ttnn.bfloat16, tile)  # whole tiles
    fills.append((name, x, after_x, spacer()))


def run_gather(name, x, index):
    x_dev, index_before = ttnn.to_torch(x).float(), index_back(index)
    out = ttnn.to_torch(ttnn.gather(x, 3, index)).float()
    index_after = index_back(index)
    wrong = int((out != torch.gather(x_dev, 3, index_before)).sum())
    changed = index_after != index_before
    cols = changed.nonzero()[:, 3]
    where = "columns %d-%d" % (int(cols.min()), int(cols.max())) if len(cols) else "none"
    print(f"{name}: {wrong} of {out.numel()} output values wrong; index input changed in {int(changed.sum())} of "
          f"{changed.numel()} ({where}; {int((index_after[changed] == 8388736).sum())} now 8388736, "
          f"{int((index_after[changed] == 0).sum())} now 0); index buffer {gap(x, index)} bytes above x's",
          flush=True)


def run_fill(name, x, after_x):
    x_before = ttnn.to_torch(x)
    ttnn.fill_implicit_tile_padding(x, 7.0)
    x_changed = int((ttnn.to_torch(x) != x_before).sum())
    after = ttnn.to_torch(after_x)
    print(f"{name}: x changed in {x_changed} of {x_before.numel()} values; the tensor allocated next "
          f"({gap(x, after_x)} bytes above x) changed in {int((after != 3.0).sum())} of {after.numel()} values, "
          f"{int((after == 7.0).sum())} of them now 7.0", flush=True)


run_gather(*gathers[0][:3])  # controls
run_fill(*fills[0][:3])
run_gather(*gathers[1][:3])
run_gather(*gathers[2][:3])  # cases
run_fill(*fills[1][:3])
run_fill(*fills[2][:3])
ttnn.close_device(device)

E. ttnn.ema: 32x32 control, then 16x32, 32x16 and 16x16 tiles, with a guard tensor after the output
```
#!/usr/bin/env python3
"""ttnn.ema of a TILE input with a 16x32, 32x16 or 16x16 tile writes past its output in DRAM.

The 32x32 case is the control. Each case allocates a guard, a placeholder with the output's spec and a second
guard, frees the placeholder, and calls ttnn.ema(x, 0.5), whose output then takes the placeholder's slot
(DRAM allocates upward, so the second guard is the next allocation after the output).
x[..., 0] is 0, so the documented start value and the device's agree (TT #61221 does not show here).
Run: python3 repro_ema_small_tile.py
"""
import torch
import ttnn

GUARD = 7.0
T = 96
ALPHA = 0.5


def run_case(dev, tile):
    th, tw = tile
    kw = {"tile": ttnn.Tile([th, tw])}
    g = torch.Generator().manual_seed(1)
    x_t = (torch.randint(-16, 17, (1, 1, 1, T), generator=g).float() / 8).to(torch.bfloat16)
    x_t[..., 0] = 0
    x = ttnn.from_torch(x_t, dtype=ttnn.bfloat16, layout=ttnn.TILE_LAYOUT, device=dev,
                        memory_config=ttnn.DRAM_MEMORY_CONFIG, **kw)
    # 4 KB of -3.0 in each DRAM bank right after x, so that the bytes the reader takes past each input page are
    # not guard values (the EMA of a run of 7.0 converges to 7.0 and would hide changed guard words).
    filler = ttnn.from_torch(torch.full((1, 1, 8, 2048), -3.0, dtype=torch.bfloat16), dtype=ttnn.bfloat16,
                             layout=ttnn.ROW_MAJOR_LAYOUT, device=dev, memory_config=ttnn.DRAM_MEMORY_CONFIG)
    # Guards fill whole tiles ([1, 1, th, 96] has the output's pages), so every word of a page is visible.
    guard_host = torch.full((1, 1, th, T), GUARD, dtype=torch.bfloat16)

    def make_guard():
        return ttnn.from_torch(guard_host, dtype=ttnn.bfloat16, layout=ttnn.TILE_LAYOUT, device=dev,
                               memory_config=ttnn.DRAM_MEMORY_CONFIG, **kw)

    guard_before = make_guard()
    holder = ttnn.allocate_tensor_on_device(x.spec, dev)
    slot = holder.buffer_address()
    guard_after = make_guard()
    ttnn.deallocate(holder)

    y = ttnn.ema(x, ALPHA)
    ttnn.synchronize_device(dev)

    xd = ttnn.to_torch(x).double()
    ref = torch.empty_like(xd)
    ref[..., 0] = xd[..., 0]
    for t in range(1, T):
        ref[..., t] = ALPHA * ref[..., t - 1] + (1 - ALPHA) * xd[..., t]
    yd = ttnn.to_torch(y).double()
    wrong = int(((yd - ref).abs() > 2.0 / 128).sum())
    before = int((ttnn.to_torch(guard_before) != GUARD).sum())
    after = int((ttnn.to_torch(guard_after) != GUARD).sum())
    n = guard_host.numel()
    print("ema tile %dx%d: %d of %d values wrong; tensor allocated after the output: %d of %d words changed; "
          "before it: %d of %d; output in the placeholder slot: %s"
          % (th, tw, wrong, T, after, n, before, n, y.buffer_address() == slot), flush=True)
    for t in (y, guard_after, guard_before, filler, x):
        ttnn.deallocate(t)


def main():
    dev = ttnn.open_device(device_id=0)
    try:
        for tile in ((32, 32), (16, 32), (32, 16), (16, 16)):
            run_case(dev, tile)
    finally:
        ttnn.close_device(dev)


if __name__ == "__main__":
    main()

B. ttnn.batch_norm (eval): 32x32 control, then 16x16, 16x32 and 32x16 tiles; a 16x16 output between two guards
```
#!/usr/bin/env python3
"""ttnn.batch_norm (eval) with TILE inputs whose tile is 16x16, 16x32 or 32x16.

float32, all tensors in interleaved DRAM:
  1. x, running_mean, running_var with 32x32 tiles (control), then with each small tile; the output is
     preallocated with the default 32x32 tile and filled with a sentinel.
  2. x, running_mean, running_var and the preallocated output all with 16x16 tiles, between two guards
     (DRAM allocates upward, so the second guard is the next allocation after the output).
Run: python3 repro_batch_norm_small_tile.py
"""
import torch
import ttnn

EPS = 1e-3
SENTINEL = -12345.0
GUARD = 7.0
SHAPE = (1, 1, 33, 65)


def put(dev, t, tile, dtype=ttnn.float32):
    kw = {} if tile is None else {"tile": ttnn.Tile(list(tile))}
    return ttnn.from_torch(t, dtype=dtype, layout=ttnn.TILE_LAYOUT, device=dev,
                           memory_config=ttnn.DRAM_MEMORY_CONFIG, **kw)


def eval_inputs(dev, tile):
    g = torch.Generator().manual_seed(2)
    x = put(dev, torch.randint(-64, 65, SHAPE, generator=g).float() / 16, tile)
    rm = put(dev, torch.full((1, 1, 1, 1), 0.5), tile)
    rv = put(dev, torch.full((1, 1, 1, 1), 2.25), tile)
    return x, rm, rv


def compare(name, x, rm, rv, y):
    xd, rmd, rvd = (ttnn.to_torch(t).double() for t in (x, rm, rv))
    ref = (xd - rmd) / torch.sqrt(rvd + EPS)
    yd = ttnn.to_torch(y).double()
    wrong = int(((yd - ref).abs() > 1e-3 * (1 + ref.abs())).sum() + torch.isnan(yd).sum())
    left = int((yd == SENTINEL).sum())
    return "%s: %d of %d values wrong (%d NaN), %d still hold the sentinel" % (
        name, wrong, ref.numel(), int(torch.isnan(yd).sum()), left)


def default_output_case(dev, tile):
    x, rm, rv = eval_inputs(dev, tile)
    out = put(dev, torch.full(SHAPE, SENTINEL), None)
    y = ttnn.batch_norm(x, eps=EPS, training=False, running_mean=rm, running_var=rv, output=out)
    name = "batch_norm x/mean/var tile %s, output tile 32x32" % ("32x32" if tile is None else "%dx%d" % tile)
    print(compare(name, x, rm, rv, y), flush=True)
    for t in (out, rv, rm, x):
        ttnn.deallocate(t)


def small_output_case(dev, tile):
    x, rm, rv = eval_inputs(dev, tile)
    th, tw = tile
    padded = (1, 1, -(-SHAPE[2] // th) * th, -(-SHAPE[3] // tw) * tw)  # the output's pages, every word visible
    guard_host = torch.full(padded, GUARD)
    guard_before = put(dev, guard_host, tile)
    out = put(dev, torch.full(SHAPE, SENTINEL), tile)
    guard_after = put(dev, guard_host, tile)
    y = ttnn.batch_norm(x, eps=EPS, training=False, running_mean=rm, running_var=rv, output=out)
    ttnn.synchronize_device(dev)
    line = compare("batch_norm all tiles %dx%d (output too)" % tile, x, rm, rv, y)
    after = int((ttnn.to_torch(guard_after) != GUARD).sum())
    before = int((ttnn.to_torch(guard_before) != GUARD).sum())
    n = guard_host.numel()
    print("%s; tensor allocated after the output: %d of %d words changed; before it: %d of %d"
          % (line, after, n, before, n), flush=True)
    for t in (guard_after, out, guard_before, rv, rm, x):
        ttnn.deallocate(t)


def main():
    dev = ttnn.open_device(device_id=0)
    try:
        for tile in (None, (16, 16), (16, 32), (32, 16)):
            default_output_case(dev, tile)
        small_output_case(dev, (16, 16))
    finally:
        ttnn.close_device(dev)


if __name__ == "__main__":
    main()

```
#!/usr/bin/env python3
"""One Blackhole chip, default dispatch: avg control, avg small tile, max copy error.

Run: python3 repro_pool_small_tile.py
Each case uses independent exact dyadic bfloat16 data. References use input
readback. The avg control is exact; the small-tile case uses 0.125 tolerance.
"""
import torch
import ttnn


COPY_ERROR = "Input and output tensors must have the same tile shape when layout is TILE"


def upload(device, shape, tile, seed):
    gen = torch.Generator().manual_seed(seed)
    host = (torch.randint(-16, 17, shape, generator=gen).float() / 8).to(torch.bfloat16)
    tensor = ttnn.from_torch(host, dtype=ttnn.bfloat16, layout=ttnn.TILE_LAYOUT,
                             tile=ttnn.Tile(list(tile)), device=device,
                             memory_config=ttnn.DRAM_MEMORY_CONFIG)
    stored = ttnn.to_torch(tensor).clone()
    if not torch.equal(stored, host):
        raise AssertionError("Input roundtrip differs before pooling")
    return tensor, stored.double().reshape(1, 8, 8, 32).permute(0, 3, 1, 2)


def compare(name, output, expected, tolerance):
    got = ttnn.to_torch(output).double().reshape(expected.shape)
    bad = ~torch.isfinite(got) | ((got - expected).abs() > tolerance)
    wrong = int(bad.sum())
    print(f"{name}: {wrong} of {expected.numel()} values wrong", flush=True)
    return wrong


def avg_case(device, tile, seed):
    x, stored = upload(device, (1, 8, 8, 32), tile, seed)
    expected = torch.nn.functional.avg_pool2d(stored, (2, 2), (1, 1), (0, 0),
                                             count_include_pad=True)
    expected = expected.permute(0, 2, 3, 1).reshape(1, 1, 49, 32)
    name = "avg_pool2d [1,8,8,32] tile %dx%d" % tile
    print(f"{name}: calling avg_pool2d", flush=True)
    output = ttnn.avg_pool2d(x, 1, 8, 8, 32, [2, 2], [1, 1], [0, 0], False, True)
    ttnn.synchronize_device(device)
    tolerance = 0.0 if tile == (32, 32) else 0.125
    return compare(name, output, expected, tolerance)


def max_case(device):
    x, stored = upload(device, (1, 1, 64, 32), (32, 16), 2)
    name = "max_pool2d [1,1,64,32] tile 32x16"
    print(f"{name}: calling max_pool2d", flush=True)
    try:
        output = ttnn.max_pool2d(x, 1, 8, 8, 32, [2, 2], [1, 1], [0, 0], [1, 1], False)
        ttnn.synchronize_device(device)
    except RuntimeError as exc:
        if COPY_ERROR not in str(exc):
            raise
        print(f"{name}: raised {type(exc).__name__}: {COPY_ERROR}", flush=True)

    expected = expected.permute(0, 2, 3, 1).reshape(1, 1, 49, 32)
    compare(name + " (call completed)", output, expected, 0.0)

    main()

A. Argmax's scanner walks four 16x16 faces. argmax_tile_layout.hpp:219-254, reader_argmax_tile_layout.cpp:58-60 scan nonexistent faces 2/3 of a two-face tile. R. Tiled reshape mixes actual-tile counts with default-tile output/transfers.     """First line of the error and the first compiler error line, without local directories."""
    text = str(exc)
    head = text.split("info:", 1)[-1].split("backtrace:")[0].strip().splitlines()

import ttnn

        return ttnn.from_torch(x.contiguous(), device=device, dtype=ttnn.bfloat16, layout=ttnn.TILE_LAYOUT,

Line labels give file:line at f5985995a; links pin current main a699bc1be, checked 2026-11-02. The relevant ranges were compared directly: the cited code is the same in f5985995a.
Prefill Q
The basic operand loop checks layout() == Layout::TILE but no tile shape (sdpa/device/sdpa_device_operation.cpp:36-41, sdpa/device/sdpa_device_operation.cpp:44-51). The factory computes Sqt = padded_Sq / TILE_HEIGHT and DHt = DH / TILE_WIDTH (sdpa/device/sdpa_program_factory.cpp:1248-1257) and uses q_tile_size = tt::tile_size(q_df) (sdpa/device/sdpa_program_factory.cpp:1761-1764). The reader constructs Q page indices in these 32-row units and calls read_chunk_with_padding<q_tile_bytes> (sdpa/device/kernels/dataflow/reader_interleaved.cpp:563-572); that helper reads tile_bytes at each successive page id (sdpa/device/kernels/dataflow/dataflow_common.hpp:163-169). A BF16 16x32 tile is 1024 bytes, whereas these CB transfers use 2048-byte tiles. The code proves inconsistent page size and row geometry. The one-chip output establishes 1024 wrong values for this fixture; exact contents beyond an admitted small source page are not inferred from source alone.
MLA decode attention sink
The sink validator checks padded shape, BF16, TILE and DRAM, but no tile geometry (sdpa_decode/device/sdpa_decode_device_operation.cpp:559-585). Both sink tile shapes pad [256,1] to [256,32]. With 256 query heads the factory's num_q_heads <= 16 half-tile condition is false, so stats_tile is full 32x32 (sdpa_decode/device/sdpa_decode_program_factory.cpp:510-513, sdpa_decode/device/sdpa_decode_program_factory.cpp:543-551), and the sink CB uses that statistics tile (sdpa_decode/device/sdpa_decode_program_factory.cpp:642-644). The reader explicitly assumes “the DRAM buffer stores full tiles (32x32)” and reads attention_sink_tile_bytes at successive source page ids (sdpa_decode/device/kernels/dataflow/reader_decode_all.cpp:254-264). This establishes the mismatch. The one-chip output establishes 4096 wrong values; neither that count nor the source alone establishes every erroneous head mapping.
Chunked page-table storage
For chunked input, validation requires a device ROW_MAJOR INT32 table on Q's device (sdpa/device/sdpa_device_operation.cpp:252-258) and checks its batch against Q (sdpa/device/sdpa_device_operation.cpp:299-304), but never rejects sharding. In the flexible chunk_start_idx_tensor path, compute_chunked_params sets page_table_stick_size = max_blocks_per_seq * sizeof(int32_t) (sdpa/device/sdpa_program_factory.cpp:160-166): 32 bytes for this eight-entry row. reader_interleaved invokes the shared row reader with the batch as page id (sdpa/device/kernels/dataflow/reader_interleaved.cpp:443-450). The helper builds a TensorAccessor then reads that complete row-sized transfer from page_id = batch_idx (sdpa/device/kernels/dataflow/dataflow_common.hpp:71-91). A [2,4] width shard contains only half of each eight-entry row. This proves that validation admits a representation not reconstructed by this row read; the source does not determine the contents of every extra byte. The one-chip run shows every value wrong for both users, with 0 at both printed batch-0 rows; the older mesh receipts also report 1024/1024 wrong in batch 0, with 0 at the two printed rows.
Separate V layout
For MLA, the validator sets const Tensor& v = use_mla ? tensors.k : tensors.v.value(); and runs storage/layout/dtype checks on that alias (sdpa/device/sdpa_device_operation.cpp:36-41, sdpa/device/sdpa_device_operation.cpp:44-51). Its final padding loop uses the same alias (sdpa/device/sdpa_device_operation.cpp:572-576). Thus a supplied separate V is not the operand whose layout was checked. The factory instead selects tensor_args.v.value_or(tensor_args.k) (sdpa/device/sdpa_program_factory.cpp:1152-1155) and uses v_tile_size = tt::tile_size(v_df) (sdpa/device/sdpa_program_factory.cpp:1761-1764). The independent-V reader calls read_chunk_with_padding<v_tile_bytes> (sdpa/device/kernels/dataflow/reader_interleaved.cpp:952-961), whose transfer is tile_bytes at each page id (sdpa/device/kernels/dataflow/dataflow_common.hpp:163-169). The BF16 V here has 64-byte ROW_MAJOR rows, while the reader requests 2048-byte tiles. The code proves the unchecked actual V reaches tiled addressing; it does not predict all bytes read for arbitrary invalid layouts.

The single-core factory of untilize_with_unpadding, which use_multicore=False selects, is another routine in this family. The call is ttnn.untilize_with_unpadding(x, [0, 0, 110, 31], use_multicore=False) of a DRAM BF16 TILE tensor [1, 1, 111, 64], on one Blackhole P150 chip at main 3facb4345ea, in the default fast dispatch:
With a 16x32 tile, the call returns, but reading its output back did not finish within 120 s, in 3 of 3 runs.
With a 16x16 tile, the same happened, in 1 of 1 run.
With a 32x16 tile, it returned 3173 of 3552 values wrong.
With the default 32x32 tile, it was exact (0 of 3552 values wrong) in all 4 runs.
We reset the chip after each run that did not finish.
This factory counts tiles with the 32x32 constants, so this issue's fix needs to cover it as well. It must either honor the input tile geometry or reject unsupported tiles before building the program. It is separate code from the multi-core interleaved factory in an earlier comment on this issue.
Repro (one Blackhole chip, main 3facb4345ea)
Run python3 repro.py 32x32 32x16 16x32, then, after a chip reset, python3 repro.py 32x32 16x16. Each case runs in its own process.
```
"""ttnn.untilize_with_unpadding(x, [0, 0, 110, 31], use_multicore=False) of a DRAM BF16 TILE tensor [1, 1, 111, 64]
with the default 32x32 tile and with 32x16, 16x32 and 16x16 tiles. Values are multiples of 1/8, exact in bfloat16.

python3 repro.py [TILE ...]   TILE in 32x32 (default tile), 32x16, 16x32, 16x16; default: all four, in that order.
Each case runs in its own process; one that does not finish within LIMIT seconds is killed. One Blackhole chip.
"""

import re
import subprocess
import sys

LIMIT = 120
TILES = ["32x32", "32x16", "16x32", "16x16"]


def one(tile):
    import torch
    import ttnn

    label = f"{tile} tile" + (" (default)" if tile == "32x32" else "")
    h, w = map(int, tile.split("x"))
    device = ttnn.open_device(device_id=0)
    x = (torch.randint(-16, 17, (1, 1, 111, 64), generator=torch.Generator().manual_seed(0)) / 8).bfloat16()
    kwargs = {} if tile == "32x32" else {"tile": ttnn.Tile([h, w])}
    xt = ttnn.from_torch(
        x, dtype=ttnn.bfloat16, layout=ttnn.TILE_LAYOUT, device=device, memory_config=ttnn.DRAM_MEMORY_CONFIG, **kwargs
    )
    try:
        print(f"{label}: calling untilize_with_unpadding", flush=True)
        y = ttnn.untilize_with_unpadding(xt, [0, 0, 110, 31], use_multicore=False)
        print(f"{label}: call returned; reading the output back", flush=True)
        got, want = ttnn.to_torch(y).double(), x[:, :, :111, :32].double()
    except Exception as exc:
        text = re.sub(r"/\S*/", "", " ".join(str(exc).split("backtrace:")[0].split()))  # drop local directories
        print(f"{label}: raised {type(exc).__name__}: {text[:200]}", flush=True)
    else:
        if got.shape != want.shape:
            print(f"{label}: output shape {list(got.shape)}, expected {list(want.shape)}", flush=True)
        else:
            print(f"{label}: {int((got != want).sum())} of {want.numel()} values wrong", flush=True)
    ttnn.close_device(device)


def run(tile):
    """Run one case in a child process; print only the child's own result lines."""
    child = subprocess.Popen(
        [sys.executable, __file__, "--one", tile], stdout=subprocess.PIPE, stderr=subprocess.STDOUT, text=True
    )
    try:
        out, _ = child.communicate(timeout=LIMIT)
        finished = True
    except subprocess.TimeoutExpired:
        child.kill()
        out, _ = child.communicate()
        finished = False
    for line in out.splitlines():
        if line.startswith(f"{tile} tile"):
            print(line, flush=True)
    if not finished:
        print(f"{tile} tile: did not finish within {LIMIT} s; process killed", flush=True)
    elif child.returncode:
        print(f"{tile} tile: process exited with status {child.returncode}", flush=True)


if __name__ == "__main__":
    if sys.argv[1:2] == ["--one"]:
        one(sys.argv[2])
    else:
        for tile in sys.argv[1:] or TILES:
            assert tile in TILES, tile
            run(tile)

Cause
Links pin main de69037d3; the card run used main 3facb4345ea, and the cited files are the same in both.
The single-core factory counts and sizes tiles with the 32x32 constants (untilize_with_unpadding_single_core_program_factory.cpp:63, line 83, lines 112-115, line 218):
line 63: int32_t num_tiles = a.physical_volume() / TILE_HW;
line 83: uint32_t num_tiles_in_row = input_x / TILE_WIDTH;
lines 112-115: the padded and leftover row blocks in TILE_HEIGHT, e.g. num_leftover_Y = output_y - (output_y / TILE_HEIGHT * TILE_HEIGHT);
line 218: the compute block count num_tiles / num_tiles_per_block
Its input buffer entry is tt::tile_size(format), 2048 bytes for BF16 (line 55). The reader copies one entry of that size from each page address (reader_unary_interleaved_start_id_metal2.cpp:33, line 47). The writer's row blocks are 32 rows (writer_unary_unpad_dims_split_rows.cpp:17, lines 88-99).
For [1, 1, 111, 64] with a 16x32 tile, the padded shape is [1, 1, 112, 64]: 14 pages of 1024 bytes. The factory counts 7168 / 1024 = 7 tiles and 2 per row, so compute untilizes 7 / 2 = 3 blocks. The writer waits for 111 / 32 = 3 full row blocks plus one of 15 leftover rows, 4 blocks in all. With a 16x16 tile the counts are the same (7 tiles, 3 blocks). With a 32x16 tile the padded height is 128, so the factory counts 8 tiles and 4 blocks, matching the writer. Its reader still copies 2048 bytes at each of the first 8 of 16 1024-byte pages. This is a source reading; we did not trace the kernels. Validation checks only that the physical volume is a multiple of TILE_HW (untilize_with_unpadding_device_operation.cpp:129-133). use_multicore=False selects this factory for an interleaved output (lines 85-86).
The Quasar copy has the same counts (experimental/quasar/.../untilize_with_unpadding_single_core_program_factory.cpp:47, lines 64, 93-96 and 192); we did not run it.
