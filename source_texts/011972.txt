WebGPU-based ray tracing renderer as an alternative to the existing Three.js rasterizer, accessible via a dedicated Render tab in the header navigation. Includes directional lighting, shadow rays, and interactive controls.
Core renderer (webgpu-ray-tracer.ts)
WGSL compute shader with DDA voxel grid traversal — each pixel casts a ray, steps through the 3D grid
Directional light source with diffuse (N·L) shading
Shadow rays via DDA traversal toward the sun for hard shadows on voxels and ground plane
Block colors from project palette via storage buffer
Ground plane with grid lines and shadow receiving
Subtle sky gradient background
Fullscreen triangle render pass to blit compute output to canvas
Exported pure functions (packVoxelData, packPalette, buildUniformData, sunDirFromAngles) for testability
RenderSettings interface with sensible defaults for all lighting parameters
Render tab and UI
Model/Render tab switcher in the header nav bar — clicking Render switches the entire view mode
When in Render mode, modeling UI (block drawer, floating toolbar, objects panel) is hidden and replaced with a dedicated Lighting sidebar:
Sun Direction slider (0–360° azimuth)
Sun Elevation slider (5–90°)
Sun Intensity slider
Sun Color presets (Warm, White, Cool, Gold, Pink)
Ambient Light intensity slider
Shadow Strength slider
Reset to defaults button
Clicking Model switches back to the full modeling UI
Render tab gated on WebGPURayTracer.isSupported()
Engine integration (voxel-engine.ts)
setRayTracingEnabled(bool) swaps between WebGL canvas and WebGPU canvas
Ray tracing auto-enables when entering the Render tab and auto-disables when switching back to Model
setRenderSettings() / getRenderSettings() for controlling lighting from the UI
Voxel data gathered from ChunkManager.getVoxelAtWorldPos() into flat buffer
Dirty tracking via store subscription — voxels and palette only re-uploaded on state change
Camera and lighting uniforms updated every frame (cheap write, always needed for orbit)
Existing orbit camera controls (right-click rotate, shift+click pan, scroll zoom) work on the ray traced view
```
// Toggle ray tracing on
await engine.setRayTracingEnabled(true);

// Update lighting
engine.setRenderSettings({ sunAzimuth: 180, sunElevation: 45, sunIntensity: 1.5, ... });
```
Tests
21 unit tests covering voxel packing, palette packing, sun direction math, and uniform buffer layout (including lighting parameters)
All existing tests unaffected
