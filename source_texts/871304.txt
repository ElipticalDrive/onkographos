Work item
L3.6 — Reconstruction importer
Objective
Convert audited L3.5 solver-native COLMAP sparse models into explicit WRE estimated-geometry contracts with provenance, while preserving local-frame/scale uncertainty and avoiding premature SpatialFragment acceptance.
Reuse
Reuse official pycolmap.Reconstruction(path) from the exact approved PyCOLMAP/COLMAP 4.2.0 environment to read native sparse model files. WRE does not reimplement or manually parse COLMAP binary reconstruction formats.
Implemented:
adds solver-independent estimated-geometry models for calibration, camera pose, sparse 3D points/tracks and one local sparse reconstruction;
uses the persisted L3.2 ObservationId <-> COLMAP image name mapping rather than guessing observation identity;
rechecks L3.5 model file membership, SHA-256 and byte length before PyCOLMAP reads a model;
derives deterministic estimate/frame/calibration/point IDs from the content-addressed L3.5 model manifest;
imports COLMAP cam_from_world() as camera-from-local-frame semantics rather than claiming a global world frame;
marks the L3 monocular baseline LocalScaleStatus.UNRESOLVED;
preserves multiple COLMAP sub-models as separate local estimates;
keeps zero L3.5 models as an explicit unresolved/empty import result;
does not create SpatialFragment, merge models, resolve scale, georeference geometry or implement L3.7;
records the reviewed handoff L3.6 done -> L3.7 ready in canonical project metadata.

Known limitations / follow-up
L3.6 imports estimated sparse geometry only. It does not decide fragment membership, choose between competing models, establish world/metric scale, anchor geometry, add covariance, or provide the L3 end-to-end fixture. L3.7 remains a separate work item and PR after L3.6 merges; L4 must not start until the L3.7 fixture and required L3 lot review are complete.
