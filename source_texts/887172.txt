Problem
Line Mode is one of the in-stage button codes (CHEAT_LINEMODE, toggle, single and multiplayer). When it's on, boss.c ends each frame with a full-screen G_RM_VISCVG fill rectangle. That fill visualises the coverage value the RDP keeps for edge anti-aliasing, which gives the game its white-outline "line mode" look.
Stage::FinishFrame (src/level/Stage.cpp) emits the same commands, but libultraship's interpreter has no coverage buffer. In 1-cycle mode GfxDpFillRectangle draws an ordinary quad with the last combiner. The VISCVG blender doesn't read memory colour in the slot the interpreter checks for blending, so the fill is probably opaque and covers the whole view. This hasn't been checked in the running game.
Work
Check what Line Mode looks like now. The in-stage button code works; the dev-tools cheat toggle tracked separately will make this easier.
If it's a solid fill, decide how to get the look back:
(a) Emulate coverage in libultraship. This would mean a separate edge pass: drawing triangle edges, or deriving coverage from MSAA. That is a libultraship-wiiu issue of its own.
(b) An approximation in frigate, for example redrawing the frame's geometry as wireframe when the cheat is on.
Pick one and file the libultraship-wiiu side if needed.
Until then, skip the fill rectangle while Line Mode is on, so the cheat at least doesn't blank the screen. Add a TODO pointing here.
