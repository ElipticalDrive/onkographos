Programme context. Part of the neural-fields work across the stack (wave epic jejjohnson/geostack#82). The literature review is geostack report 18 and the plan is the neural-fields design page; both land in jejjohnson/geostack#87. Everything needed to implement this issue is below.
Problem / Request
Generalize the BNF estimator plumbing (_bnf_init_fn, _bnf_log_joint in api/_bnf.py) into NeuralFieldEstimator, which takes any PyroxModule mapping coordinates to a field (e.g. BayesianSIREN behind SphericalHarmonicEncoder) and fits it with pyrox.inference.ensemble_map / ensemble_vi, on plain arrays or an xarray Dataset, not only pandas.
User Story
As someone comparing a Bayesian SIREN with SH encoding against BNF on the same tracks, I want one estimator API so the only change is the model.
Motivation
The ensemble runners in pyrox.inference are generic, but the only end-to-end path is BNF-specific and pandas-only. The geostack anchors (jejjohnson/geostack#85) hand over padded arrays with a valid mask (GeoPoints.to_jax(pad_to=N)), not DataFrames.
Proposed API
```
est = NeuralFieldEstimator(
    model_fn=lambda: BayesianSIREN.init(in_features=enc_dim, hidden_features=128, out_features=1, depth=4),
    encoder=geonnax.SphericalHarmonicEncoder(l_max=20, input_mode="lonlat"),   # optional, deterministic
    noise="learned", ensemble_size=8, inference="map", num_epochs=2000, learning_rate=5e-3,
)
fitted = est.fit(X, y, sigma=sig, valid=mask, seed=0)      # arrays: X (N, D), y (N,), mask (N,)
fitted = est.fit_xarray(ds, coords=("lon", "lat", "time"), target="sla", sigma="sla_err", seed=0)
mean, q = fitted.predict(X_new, quantiles=(0.05, 0.5, 0.95))
```
BNFEstimator becomes a thin subclass that builds BayesianNeuralField and its pandas preprocessing.
Mathematical Notes
Log joint per ensemble member with params θ and valid mask m:
$$\log p(\theta, y) = \sum_i m_i \log \mathcal N\big(y_i \mid f_\theta(\gamma(x_i)),\ \sigma_i^2 + \sigma_0^2\big) + w \log p(\theta)$$
with w = prior_weight (0 MLE, 1 MAP), exactly as EnsembleMAP expects log_joint(params, x, y) -> (loglik, logprior). Padded rows (mᵢ = 0) must not change gradients.
Implementation Steps
packages/pyrox-nn/src/pyrox_nn/api/_field.py: NeuralFieldEstimator, FittedNeuralField
Refactor api/_bnf.py to reuse it; keep BNFEstimator's public behaviour
xarray path behind an optional extra (no hard dependency in pyrox_nn core)
Definition of Done

Testing

BNFEstimator regression against stored predictions
