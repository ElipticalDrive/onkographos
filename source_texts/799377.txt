The splat viewer downloads unused rendering/format support, and its scene status looks like another keyboard hint. Build it with the existing size-oriented WASM profile, remove unused tonemapping LUTs, and opt out of automatic 4D pipeline and glTF/GLB scene-loader registration. Put status above a divider with muted controls below. Other examples and the SOG decode worker keep their release profiles.
The vendor's default/headless/viewer presets retain both optional formats. Library consumers can enable dimensify_splat/gaussian-4d and dimensify_splat/gltf; the standalone picker and URL parser remain PLY/SOG/streaming. SH3, GPU radix sorting, CPU sorting fallback and Feathers remain available.

The final compressed module is 19.86% smaller overall; feature pruning saves another 206,683 bytes (2.52%). Actual hosting compression can differ. A tested Binaryen -Oz pass increased compressed size and was rejected; no new build tool is required.
Validation: 302 native library tests passed (46 GPU tests ignored in that invocation), plus all 26 reviewed Metal GPU correctness cases. Both registration tests also passed with the optional 4D/glTF features enabled. Viewer WASM Clippy with warnings denied, the WebGL feature build and formatting checks passed. The first pass passed 178 Python tests, including profile-selection regression tests.
All 19 browser launch/loading/embedding checks passed on baseline and final builds. Ten fixed-view PLY/SOG/streaming captures have exact RGBA equality across both size-reduction passes; desktop and 390px footer captures were inspected. A repeat normal release showcase build reproduced the final module SHA-256 (32353faabced11868d58156fbb8c7fa65fc1b40c3e190d77a25243d5ee3351e8). SOG worker files remain byte-identical.
This establishes module-size savings and tested rendering/input correctness, not a frame-time improvement or total site transfer. Runtime performance of the new profile still needs a matched benchmark; the existing real-scene harness records instrumented release builds. Generated captures, raw sizes, hashes and logs remain ignored local artifacts. Reviewed Pixel Eagle references and regression thresholds are unchanged.
