This contains a functioning implementation of the method of reciprocal vectors, as found in Chateur et alia (1998), for calculating the gradient of a vector field from 4 vertices in a tetrahedron configuration. As the name of the project implies, this is intended for use on data from the MMS mission, but the mathematics and functions used here are generally applicable. A set of functions for interfacing with the MMS Science Data Center API for downloading data from the SDC is also included here but is not required for usage and alternate API implementations for the MMS SDC exist (e.g. https://github.com/argallmr/pymms) NOTE: Future versions may change the function titles; caution is advised if using this library in constructing automated analysis tools.
