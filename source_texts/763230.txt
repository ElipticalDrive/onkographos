## 🚀 Overview

**[🚧 Work In Progress 🚧]**

Developing a custom **Unreal Engine 5 Editor Plugin** from the ground up using **C++** and the **Landscape API**. This tool aims to streamline environment creation by providing procedural terrain generation, dynamic material assignment, and aggressive viewport rendering optimization.

Currently, this repository highlights the architectural design and the ongoing C++ implementation of the core algorithmic modules. The project is focused on memory-safe low-level engine interactions and minimizing performance overhead in the editor viewport.

## 🛠️ Architecture & Core Modules

The plugin architecture is partitioned into highly cohesive logical blocks:

* **Noise Generation Engine**: Implements layered Perlin and Simplex noise algorithms to procedurally generate natural-looking height maps directly within the editor. *(Implementation In Progress)*
* **Landscape Material Allocator**: Handles height-map driven texture layer blending. Automates slope-based material assignment (e.g., applying rock textures to steep gradients and grass to flat planes). *(Architectural Phase)*
* **LOD & Tessellation Manager**: Intercepts the rendering pipeline to manage mesh Level of Detail (LOD). Implements distance-based tessellation control to aggressively cull unseen geometry. *(Prototyping Phase)*
* **Slate UI Integration**: A custom, lightweight editor dock tab built with Unreal's Slate framework, allowing artists to tweak noise frequencies, blend weights, and LOD distances in real-time. *(Scaffolding Completed)*

## 🔍 Optimization & Performance Targets

A major focus of this tooling development is engine performance. The plugin is strictly designed to achieve:

* **Viewport Efficiency**: Targeting a 40% render performance improvement in the editor viewport by dynamically scaling tessellation depth based on camera proximity.
* **Memory Management**: Enforcing strict C++ memory discipline to prevent memory leaks during massive procedural generation operations, utilizing UE5's smart pointer library (`TSharedPtr`, `TWeakPtr`) effectively.

## 📂 Directory Structure

The project adopts the standard Unreal Engine 5 Plugin directory hierarchy:

```text
UE5_ProceduralTerrain/
├── Config/                   # Default plugin configurations
├── Resources/                # Icons and Slate UI styling assets
├── Source/                   
│   ├── TerrainEditor/        # Slate UI and Editor-only C++ logic
│   │   ├── Private/          # UI implementations (Active Development)
│   │   └── Public/           # Interfaces and Slate widget declarations
│   └── TerrainRuntime/       # Core procedural generation and LOD algorithms
│       ├── Private/
│       │   ├── NoiseGenerator.cpp      # Perlin/Simplex math (WIP)
│       │   └── LODManager.cpp          # Tessellation logic (WIP)
│       └── Public/
│           ├── NoiseGenerator.h
│           └── LODManager.h
├── Docs/                     # System architecture diagrams and logic flow
└── ProceduralTerrain.uplugin # Plugin descriptor file
```
