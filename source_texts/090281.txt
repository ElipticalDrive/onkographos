A new placeholder type, voxel: a small 3D model of voxels rendered into the 2:1 isometric view, in the active UI palette. Three-tone light from the palette roles, an inner line where a part stands in front of another, top-edge highlights, an outline, and the four facings from one model (models face E). Models are built-ins (turret, pylon, crate, tank) or a JSON kept in the game (box, cylinder, dome, ring, voxel, decal parts); decals (orb, spark, cross) pin pixel details to a 3D point. 2 px voxel steps below 48 px, 4 px above; a model that doesn't fit is an error, never a crop. Same placeholder marker, so real art is never overwritten.
CLI and manifest: --model, --facings, --unit; {facing} in out paths or a _N/_E/_S/_W suffix. README section, agent rule (prefer voxel models for isometric pieces), tests.
Born in Ember Signal (tools/voxel_sprites.py), made palette- and game-agnostic here.
