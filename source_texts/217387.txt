Adds ImageDataFilters.slab_projection, which collapses a slab of an image onto a reference image: each reference point takes the maximum, minimum, or mean of the image along a segment thickness world units long, normal to the reference. mode='max' is a maximum intensity projection, and the default thickness spans the whole image. It wraps the slab mode of vtkImageReslice, the most common vtkImageReslice feature pyvista does not expose (155 public GitHub files call SetSlabNumberOfSlices, 153 of them with SetSlabModeToMax). Parameter names follow resample and reslice.
Without a reference, image.slab_projection(axis='z') projects across the image's middle slice, giving the 2D MIP; axis takes world x/y/z or index i/j/k, a rotated direction_matrix on the reference gives an oblique slab, and a volume reference a sliding slab per slice.
There is no anti_aliasing, since blurring before a maximum dims the peak it should find; project, then resample(..., anti_aliasing=True) instead.
vtkImageReslice rounds slab samples to whole input slices when SlabSliceSpacingFraction is exactly 1, so the filter never passes that value.
The oblique anatomy example compares maximum-intensity slabs on the faces of a scan-aligned and a bone-aligned block, with the scapula highlighted.
slab_projection and reslice cross-reference each other; a slab with a thickness of 0 samples the same values as reslice.
