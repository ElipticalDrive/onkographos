Game showed black screen due to CDN blocking of Three.js library. Rebuilt using pure JavaScript raycasting engine inspired by Wolfenstein 3D/Doom.
Changes
Core Engine Replacement
Removed Three.js CDN dependencies (270 lines)
Implemented custom raycasting engine with Canvas 2D API (612 lines total)
Classic ray-per-column rendering with distance-based wall shading
Billboard sprite system for enemies (always face player)
Performance Optimizations
Capped raycasting at 640 rays (was 1:1 pixel ratio)
Proper column scaling for arbitrary screen widths
Spawn point tracking for consistent enemy respawn
Key Algorithm
```
// Cast rays across FOV and render vertical wall strips
const NUM_RAYS = Math.min(640, canvas.width);
for (let i = 0; i < NUM_RAYS; i++) {
    const rayAngle = player.angle - HALF_FOV + i * DELTA_ANGLE;
    const depth = castSingleRay(rayAngle);
    const wallHeight = (TILE_SIZE * canvas.height) / depth;
    const columnWidth = canvas.width / NUM_RAYS;
    ctx.fillRect(i * columnWidth, y, columnWidth, wallHeight);
}
```
Result
No external dependencies. Game runs entirely client-side with authentic Doom-style rendering.
