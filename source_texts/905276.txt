# Octree with VTK in C++ [ENG]

@ShinjiMC - By Braulio Nayap Maldonado Casilla

A simple Octree structure that can build up on the Point Clouds

## Build

```
    mkdir build
    cd build
    cmake -DBUILD_EXAMPLE=ON ..
    cmake --build .
    ./program
```
