Adds an opt-in visual comparison for the Spike B synthetic mesh:
build_marching_cubes_preview.py generates an ignored OBJ with scikit-image Marching Cubes from the same deterministic mask used by the voxel-face artifact.
app/?surface=marching-cubes loads that OBJ with smooth vertex normals; the default remains the exact voxel-face mesh with flat normals.
The viewer accepts only two fixed source names, so the query string cannot control an arbitrary fetch path.
The UI and README make the clinical boundary explicit: this is a synthetic segmentation surface, not MRI or a patient/anatomy finding. A 3D surface loses MRI intensity/texture and must be read alongside 2D/MPR images. The interpolated preview is not used by the current picking harness or acceptance evidence.
