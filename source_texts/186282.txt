Hi @MayuOshima,
MISE is an algorithm to extract a mesh from a continuous occupancy function representation. I'm not sure what you want to achieve, but you can take a look at the interface. Here you can see how it is used in practice. If you want to reconstruct from a point cloud instead, take a look at configs/pointcloud/onet.yaml. Note however, that the pretrained model was trained on (aligned) ShapeNet. So, if you want to apply it to some different object category you might want to retrain / finetune the network.
