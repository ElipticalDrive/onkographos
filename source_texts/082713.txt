# Point Cloud Voxelization Project

## Overview
This repository contains a **voxel grid down‑sampling** implementation for 3D point clouds. Two versions are provided:
- **Sequential (CPU) version** – `benchmark_sequential.exe`
- **Parallel (CUDA/GPU) version** – `benchmark_parallel.exe`

The goal of the project is to compare the performance and correctness of the CPU and GPU implementations on large LiDAR datasets (for this project nuScenes). The code is written in modern C++ 17 with CUDA 12.x support and compiled via CMake.

## Prerequisites
| Requirement | Reason |
|---|---|
| **Windows 10/11** (PowerShell) | OS used for development |
| **Visual Studio 2022** (C++ workload) | Provides MSVC compiler compatible with CMake |
| **CUDA Toolkit 12.x** | Required for the GPU implementation |
| **CMake ≥ 3.20** | Generates Visual Studio solution |
| **Git** (optional) | For cloning the repository |

Make sure the CUDA toolkit version matches the installed Visual Studio version. The project was tested with **CUDA 12.6** and **MSVC 19.40**.

---

## Building the Project
Open a **Developer PowerShell** (or regular PowerShell) and execute the following from the repository root:
```powershell
# 1. Create a build directory
mkdir build
cd build

# 2. Configure with CMake (Release configuration)
cmake .. -G "Visual Studio 17 2022" -A x64 -DCMAKE_BUILD_TYPE=Release

# 3. Build the executables
cmake --build . --config Release
```
The binaries will be placed in `build/Release/`:
- `benchmark_sequential.exe`
- `benchmark_parallel.exe`

---

## Running the Benchmarks
Both executables share the same command‑line interface:
```
benchmark_<mode>.exe <path-to-bin-or-directory> <leaf_size> [target_point_count]
```
- **`<path>`** – Either a single `*.bin` file or a folder containing many nuScenes LiDAR scans.
- **`<leaf_size>`** – Voxel side length in metres (e.g., `0.1`).
- **`[target_point_count]`** – Optional maximum number of points to load (useful for scaling tests).
