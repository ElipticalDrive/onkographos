Added a new module misc/TetraMesh to support GPU-based volume rendering of tetrahedral meshes. The current implementation relies on Shader Storage Buffers Objects (OpenGL 4.3).
The TetraMeshProvider class serves as interface between arbitrary tetra meshes and the GPU implementation/buffers. An example implementation can be found in the VTKToTetraMesh processor and its data provider VTKTetraMeshProvider.
