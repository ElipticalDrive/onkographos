Problem (upstream link)
isl-org/Open3D#7557 reports that the public ColorGrading.ToneMapping enum was ignored by the Filament renderer. Original contributor PR #7567, authored by Maximilian Stölzle (mstoelzle), restores the mapping and tests LINEAR versus ACES, but it does not independently test LINEAR versus FILMIC or FILMIC versus ACES. This is fork-only test support of that open contributor PR, not a competing upstream submission.
Root cause (file:line at the SHA)
On fork main at b6c5e196384ad71e75b6e6f9c5da22d046221f1d, cpp/open3d/visualization/rendering/filament/FilamentView.cpp:249-302 comments out the tone-mapper selection and builder invocation. All three enum values therefore use the default mapper.
The original contributor's exact head ed9cb386cac3173ee2ab2aa7016fb8e4a419b74f restores five supported modes and has one LINEAR/ACES CPU test in python/test/visualization/test_cpu_rendering.py.
Change
Goal lock: independently exercise all three supported pairs on Linux x86_64 software/EGL Filament; preserve the original contributor implementation unchanged; require genuine native RED on base and GREEN on this exact head before describing this as validated.
Added python/test/visualization/test_tone_mapping_pairwise_review.py with exactly three parameterized CPU pytest instances: LINEAR/ACES (minimum gap 20), LINEAR/FILMIC (10), FILMIC/ACES (10). Each compares means of the same 160×90 white-background scene in a 45×45 interior crop and isolates Filament execution in a bounded child process. The new test file can also be copied unchanged to a base checkout for the RED control. The explicit OPEN3D_CPU_RENDERING=true and Linux x86_64 guard matches existing tests.
Ancestry: main base b6c5e196384ad71e75b6e6f9c5da22d046221f1d → original contributor commit ed9cb386cac3173ee2ab2aa7016fb8e4a419b74f → one fork test-only commit d66a131f35d9e4e4ac8fc9fbe9cb8c1b4f2ada16. One file in the new worker commit; the PR necessarily also shows the contributor's unmerged original three-file patch. Preserve the original author's credit.

Hand-calculated expectation, not execution: Averaging each RGB triplet reported in isl-org#7557 yields mean gaps on unfixed base of 0.007737 (LINEAR/ACES), 0.012510 (LINEAR/FILMIC), and 0.004774 (FILMIC/ACES), all below the respective 20/10/10 thresholds.
