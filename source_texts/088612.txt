The authors of TensoRF acknowledge that their implementation could be sped up by combining the ray sampling stage with that of instant ngp. Using nerfacc we could try to introduce TensoRF for the neural radiance field and use the spacial hash tables of instant ngp to improve the speedup this library already provides. This thread will be used to document all ongoing issues with this implementation process and potential issues with this feature integration.
