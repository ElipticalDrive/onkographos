# pixel-to-voxel

Multi-camera voxel-carving pipeline with Kalman tracking and real-time orthographic visualisation, enabling sub-pixel moving object detection and tracking. Based on [Pixeltovoxelprojector](https://github.com/ConsistentlyInconsistentYT/Pixeltovoxelprojector).

## Overview

Cameras observe a simulated scene. Per-frame background-subtracted difference images are back-projected into a shared 3D voxel grid (voxel carving). Bright voxels are clustered into measurements fed to a constant-velocity Kalman tracker. Three visualisation scripts render the result in different layouts.

```
sky_sim/        simulated scenario data and video rendering
tools/          camera geometry utilities (focal length, projection)
detection6/     voxel pipeline, tracker, and visualisation
  _backend.py   pure data: voxel grid, tracker, background subtractors
  _ui.py        drawing, rulers, overlays, playback loop
  native.py     Python bindings for the C++ VoxelGrid
  tracker.py    VoxelKalmanTracker + volume_cluster_centroids
  cpp/          C++ VoxelGrid source
  view_voxel.py     5-panel orthographic + camera view
  view_topdown.py   single full-size XY top-down view
  view_camera.py    side-by-side raw camera feeds
```

## Requirements

- Python 3.10+
- OpenCV (`cv2`)
- NumPy
- Compiled `detection6/native` C++ extension

## Running

```bash
# 5-panel orthographic layout
python -m detection6.view_voxel

# Pure top-down XY view
python -m detection6.view_topdown

# Raw camera feeds
python -m detection6.view_camera
```
