What
Lights imported glTF PBR materials through a Cook-Torrance metallic-roughness BRDF on the software rasteriser — the verifiable reference path for the Modern (AAA) tier, ahead of the deferred WebGPU WGSL variant. This is the shading half of Phase 2 (the data model landed in #48).
Why
The "both worlds" plan (see AAA_TIER_ROADMAP.md) routes a top Modern tier to a richer PBR pipeline while the fantasy tiers stay byte-identical. The software rasteriser is kept as the reference/fallback path because WGSL can't be verified without a GPU device; this makes the metallic-roughness response real and testable now, and the WebGPU shader will mirror it in-browser.
Changes
meshRasterizer — buildPbrFrag gates the BRDF on a material carrying any metallic-roughness signal (a map, or a metallic/roughness/emissive factor). Absent that, the fantasy Blinn-Phong/diffuse path runs byte-identically. Threads mr/occlusion/emissive maps through renderMeshScene → drawMesh/eachTriangle → rasterizeTriangle. GGX NDF, Schlick-GGX geometry, Fresnel-Schlick, F0 = mix(0.04, albedo, metallic), AO + emissive terms, a flat-ambient IBL stand-in, two-sided normal.
MeshOverlaySurface — decodes metallicRoughnessImage/occlusionImage/emissiveImage into the new texture arrays and carries them through posed instances.
renderCaps.capTextures — fits + preserves the three PBR map arrays so a budgeted rebuild never silently drops them.
meshRasterizerPbr.test.ts — metallic vs dielectric, roughness response, F0 tint, emissive floor, occlusion, packed-map channels, and the fantasy-path gate.
Rebuilt committed player dist; updated AAA_TIER_ROADMAP.md (Phase 2 software path marked landed).
Verification
npm run verify green (typecheck, lint, 2078 tests + 7 new, dist parity). Headless render confirms polished-metal (albedo-tinted specular, no diffuse), rough-dielectric (diffuse albedo), and emissive (self-lit) spheres.
Shading is done in non-linear byte space for now; a linear/gamma-correct HDR pipeline is Phase 4.
