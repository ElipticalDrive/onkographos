# A null-scattering path integral formulation of light transport
This page contains comparisons of integrators for all of the scenes found in [our paper](https://cs.dartmouth.edu/~wjarosz/publications/miller19null.pdf). See the paper for more details on the scene set up, scene statistics, and a commentary on results.
## Renders
The following pages contain full-size renders for different integrators with an
easy way to compare each integrator. The page allows you to select various scenes rendered with different integrators for six scenes. Below the image, there are
comparison zoom ins for the portion of the image your mouse is hovering over.
