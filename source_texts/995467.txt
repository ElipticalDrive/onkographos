Motivation
Provide a small, dependency-light math layer for the AHRS core that is ROS-free and mypy-friendly.
Supply row-major matrix helpers and 3x3 utilities needed for covariance, gating and innovation math used by the AHRS filter.
Description
Added oasis_control/oasis_control/localization/ahrs/ahrs_linalg.py which defines Matrix and Vector types, row-major indexing helpers, validation helpers, matrix operations (mat_get, mat_set, mat_transpose, mat_mul, mat_vec_mul, mat_add, mat_sub, mat_scale, symmetrize, is_finite_seq) and 3x3-specific utilities (mat3_det, mat3_inv, mat3_solve, quad_form_3).
Implemented minimal SPD/covariance utilities clamp_diag_3 and project_to_symmetric_psd_3 with clear documentation about the pragmatic fallback behavior.
Added innovation/gating helpers innovation_covariance and mahalanobis_d2_3 and documented mathematical meanings (innovation covariance, Mahalanobis distance).
Added oasis_control/test/test_ahrs_linalg.py containing deterministic pytest coverage for transpose, multiplication, inversion/solve, symmetry, Mahalanobis, PSD fallback and finiteness checks.
Testing
Ran tox which runs formatting checks, isort, mypy, flake8 and the test suite, and all checks passed.
Ran the package tests via pytest --rootdir=oasis_control oasis_control/test oasis_control/test/integration and all tests passed (60 passed).
Executed the new unit tests in oasis_control/test/test_ahrs_linalg.py (including test_transpose_roundtrip_2x3, test_mat_mul_identity_3x3, test_mat3_inv_identity, test_mat3_solve_known_system, test_symmetrize_makes_symmetric, test_mahalanobis_d2_matches_manual, test_project_to_symmetric_psd_3_fallback_on_bad_matrix, test_is_finite_seq) and they all succeeded.
