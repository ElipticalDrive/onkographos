Phase 2: 3D Raycasting with DDA Algorithm
This issue covers the implementation of the core 3D rendering using raycasting and the DDA algorithm.
Goal: Transform the 2D top-down map into a pseudo-3D first-person view similar to Wolfenstein 3D, with correct perspective, wall rendering, fisheye correction, and simple shading.
Tasks (in order of implementation):
Calculate ray direction for each screen column
DDA initialization (map coordinates, deltaDist, sideDist, step)
Implement the DDA marching loop and wall hit detection
Calculate perpendicular wall distance and fisheye correction
Compute wall height and draw start/end points
Draw vertical wall stripes with basic shading (darker for horizontal sides)
Add simple ceiling and floor rendering
Integrate everything with existing player movement and map
Important notes:
Only use 2D drawing functions from raylib (DrawLine, DrawRectangle, etc.)
No use of BeginMode3D or built-in 3D camera allowed
All calculations must happen in the main render loop
Test goal: In PLAY mode, see proper 3D corridors with perspective
Each task will have its own separate issue and corresponding PR.

فاز دوم: رندرینگ سه‌بعدی با پرتوها و الگوریتم دی‌دی‌ای
این مسئله مربوط به پیاده‌سازی بخش اصلی رندرینگ سه‌بعدی با استفاده از روش پرتوها و الگوریتم دی‌دی‌ای است.
هدف: تبدیل نمای دوبعدی از بالا به نمایی سه‌بعدی اول‌شخص شبیه به ولفنشتاین سه‌بعدی، با پرسپکتیو درست، رسم دیوارها، اصلاح اعوجاج چشم‌ماهی و سایه‌زنی ساده.
وظایف (به ترتیب اجرا):
محاسبه جهت پرتو برای هر ستون صفحه
مقداردهی اولیه متغیرهای دی‌دی‌ای
اجرای حلقه دی‌دی‌ای و تشخیص برخورد با دیوار
محاسبه فاصله عمود و اصلاح چشم‌ماهی
محاسبه ارتفاع دیوار و نقاط شروع و پایان
رسم خطوط عمودی دیوار با سایه‌زنی ساده
افزودن سقف و کف ساده
ادغام همه با حرکت بازیکن و نقشه موجود
نکات مهم:
فقط از توابع رسم دوبعدی کتابخانه استفاده شود
استفاده از حالت سه‌بعدی آماده یا دوربین داخلی ممنوع است
همه محاسبات باید در حلقه اصلی رسم انجام شود
هدف آزمایش: در حالت بازی، راهروهای سه‌بعدی با پرسپکتیو صحیح دیده شود
هر وظیفه در یک مسئله جداگانه پیگیری خواهد شد و با درخواست کشیدن مربوطه بسته می‌شود.
