Cache mesh collision edge vectors
…
6253d0f
```
Store local-space center and half-vector data for packed mesh collision edges and pass it through the generic collision pipeline. Mesh-SDF contact kernels can then avoid two indirect vertex fetches and two point transforms for each edge while keeping the old index-based path as a fallback.

This reduces the PhoenX nut/bolt default 80x80 captured frame from about 15.0 ms to about 14.0 ms on the test GPU, with the mesh-mesh SDF kernel dropping by several percent.

Tests: uv run --extra dev -m newton.tests -k test_contact_reduction_global

Tests: uv run --extra dev -m newton.tests -k test_collision_pipeline
```
