Current text
The early-stop option proposed in #2940 needs a worked example showing how to choose its parameters and evaluate the result on a real workload.
Suggested text
Add a short example in English and Chinese using a workload from #2941. Show:
The dataset, query split, k, recall target R and coverage target C.
How to calibrate fixed ef_search, choose an early-stop parameter and freeze the settings before evaluation.
The commands to enable/disable early stopping and compare recall, coverage, latency and QPS.
A case where fixed search was retained or validation failed, and what that means for using the option.
The example should use the calibration workflow described in #2939 and explain the measurements in #2941. State when a change in the workload, filtering, metric or index requires calibration again.
Additional context
Part of #2840. Each example should state the implementation version, dataset and settings corresponding to the results in #2941. The source references above refer to fd077c3f.

#2840, #2939, #2940, #2941; coverage output in #2841 / #2864.
