Summary
This PR introduces a complete region-based map streaming system with procedural terrain generation for HktMapGenerator. The system enables per-region independent landscapes that can be dynamically loaded/unloaded at runtime, along with terrain recipe-based procedural heightmap generation.
Key Changes
Data Structure Expansion (HktMapData.h)
Added FHktTerrainFeature and FHktTerrainRecipe structs to support procedural terrain generation with noise parameters (Perlin, Ridged, Billow), octaves, lacunarity, persistence, and feature-based terrain modification
Added FHktMapGlobalEntity and EHktGlobalEntityType for map-wide entities (world bosses, NPCs, spawners)
Added FHktMapEnvironment for weather, time of day, fog, wind, and ambient VFX configuration
Restructured landscape data to support both direct heightmap paths and procedural generation via terrain recipes
Added per-region spawners, stories, and props with independent lifecycle management
Procedural Terrain Generation (HktTerrainRecipeBuilder)
Implemented Perlin noise with 8-gradient directions for improved quality
Added Ridged and Billow noise variants
Implemented Fractional Brownian Motion (FBM) for multi-octave noise synthesis
Added terrain feature application system (mountains, valleys, ridges, plateaus, craters, river beds) with customizable falloff curves
Implemented hydraulic erosion simulation for natural terrain weathering
Supports direct heightmap generation from FHktTerrainRecipe for ALandscape import
Runtime Region Streaming (HktMapStreamingSubsystem)
New WorldSubsystem for dynamic region activation/deactivation based on player position
Per-region landscape instantiation and destruction
Region-scoped spawner and story management
Auto-streaming timer with configurable update intervals
Global entity and environment persistence across region transitions
Region Volume and Spawner Management
AHktMapRegionVolume: Box-based region boundary visualization and overlap detection
AHktSpawnerActor: Entity spawning with rule-based activation (Always, OnStoryStart, OnTrigger, Timed)
Respawn timer support for continuous entity generation
Story Registry (HktMapStoryRegistry)
Centralized story tag management for global and region-scoped stories
Auto-load support for stories linked to region activation
Story lifecycle tied to region streaming
Editor Integration
Extended HktMapGeneratorSubsystem with parsing for new terrain recipe and global entity data
Added JSON serialization/deserialization helpers for Vector2D, Color, and Rotator types
Integrated terrain recipe builder into map generation pipeline
Python Schema Updates (map_tools.py)
Expanded HKTMAP_SCHEMA with terrain recipe, global entities, and environment sections
Added per-region landscape configuration
Documented procedural generation parameters for LLM consumption
Implementation Details
Region Independence: Each region owns its own ALandscape instance, enabling true per-region streaming without partial landscape loading constraints
Noise Quality: Perlin noise uses normalized gradients and proper fade curves for smooth interpolation
Feature Blending: Terrain features use distance-based falloff with three curve types (linear, smooth, sharp) for natural transitions
Erosion: Hydraulic erosion simulates water flow and sediment deposition for realistic terrain weathering
Backward Compatibility: Direct heightmap paths still supported alongside procedural generation
