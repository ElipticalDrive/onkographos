Summary
Adds a Minimum Intensity Projection (MinIP) option to the View tools, next to MIP. It renders the 2D viewports with the darkest value along each ray instead of the brightest.
VolumeViewport now picks the blend mode from the view mode (MIP or MinIP); both project through the whole volume.
The button appears wherever MIP does (volume exams: mask, mask review, DICOM review, NIfTI review). Stack exams are unchanged.
Adds implementation notes in docs/minimum-intensity-projection.md.
Changes
src/features/presentationSlice.js: ViewOptions.MIN_PROJECTION and the minProjection visibility flag.
src/features/tools/toolsConfig.js: the new View button.
src/components/VolumeViewport.jsx: blend-mode selection.
No public API or DB schema changes.
