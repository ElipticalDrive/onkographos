MOTIVATION
POINT CLOUD DATA IS A VERY POPULAR DATA FORMAT USED FOR SEVERAL
APPLICATION LIKE SURVEYING, TRANSPORTATION, AND GEO-MAPPING ETC.
BENEFIT OF POINT CLOUD:
1. HIGH ACCURACY AND DETAIL
2. VERSATILE
3. REAL TIME
4. CAN BE USED FOR DISTANCE MEASUREMENT, OBJECT RECOGNITION, SURVEYING
AND CAN BE CONVERTED INTO MULTIPLE FORMAT LIKE DEM AND 3D MESH ETC
THE DISTRIBUTION OF 3D CONTENT THROUGH WEB BROWSERS HAS GAINED
POPULARITY IN RECENT TIMES.
Growing usage and precision of advanced depth sensors fuels demand for eﬃcient point cloud
management to enable interactive visualization

CLOUD OPTIMIZED POINT CLOUD FORMAT (COPC)
●
THE POINT DATA IS ORGANIZED INTO A CLUSTERED OCTREE STRUCTURE,
AND THE OCTREE IS STORED IN A SINGLE FILE USING VARIABLE-SIZED
CHUNKS FOR EFFICIENT STORAGE.
●
ALLOWS THE DATA TO BE CONSUMED SEQUENTIALLY MAKING USE OF
HTTP RANGE QUERY.
●
BY READING THE FIRST 589 BYTES PROVIDES INFORMATION ABOUT POINT
SIZE, HIERARCHY PAGE ( OCTREE HIERARCHY IS ARRANGED IN PAGE) IS
OBTAINED.
Fig: Multi resolution octree structure as a Mesh
(in left) and its graph representation (right)
Each entry in pages refer to the size and offset of that chunk i.e node
allowing node to be directly read.

Data Management Techniques
Caching:
●
Caching done automatically by the browser (GET requests, cache req/response)
●
JS Map to store data (e.g., LRU cache). This will be ﬂushed when close tab, session expires, close browser
●
Persistent cache via ﬁle API (very recent) using Origin Private File System (OPFS)
Prefetching:
●
loading and processing data before it is actually needed for rendering.
●
improve performance by reducing the time needed to load data
WebGPU
●
Successor to WebGL 2.0
●
Lower Level API providing compute ability
●
WebGL 2.0 is based on OpenGL ES 3.0
whereas WebGPU is based on modern low
overhead API like Vulkan and Metal.
●
Data from host to shader are sent on

MULTI LAYER CACHE AND WEBGPU FOR HIGH PERFORMANCE
POINT CLOUD STREAMING DATA ACCESS
WE AIM TO EXPLOIT DIFFERENT STRATEGIES TO ALLEVIATE STATE OF ART OF LARGE SCALE POINT CLOUD VISUALIZATION IN WEB.
CONTRIBUTION OF THIS WORK ARE:
1. FIRST OPEN-SOURCE VIEWER OF COPC DATA USING A PARALLEL WORKFLOW LEVERAGING WEBGPU TO EFFICIENTLY STREAM
AND RENDER DATA ASYNCHRONOUSLY.
2. IMPLEMENT A MULTI-LAYERED CACHING SCHEME LEVERAGING PERSISTENT FILE STORAGE
3. PRE-FETCHING STRATEGY TO FURTHER IMPROVE THE PERFORMANCE OF OUR CACHING AND STREAMING SYSTEM.

CONCLUSION
1.
Utilizing a multi layered integrated cache system yields significant
improvements in the performance of web-based point cloud data
visualization.
2.
The use of persistent cache improves performance by 2x to 3x (and more on
slower networks)
3.
Multilayer and persistent caching is a key component for applications with
limited network availability
