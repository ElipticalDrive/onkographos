What has changed and why?
Adds point cloud accumulation — the ability to merge point clouds from neighbouring ticks around the current frame into a single view, giving a denser representation of the scene.
New pure utility functions handle batch merging (mergePointBatches, createSegmentedPointBatch), frame accumulation (mergeAccumulatedFrames, createAccumulatedFrameSelector), and color/buffer computation (getPointCloudColors, getPointCloudFrameColors, createPointCloudFrameBuffers).
useCloudPointFrame is extended with accumulationTickNumbers to load and merge frames from a configurable window of ticks around the current one.
The prefetch range (getMcapTickPrefetchRange) is widened to cover the accumulation window so neighbouring ticks are ready when needed.
The workspace controller and provider expose accumulatePointClouds and accumulationRadius settings; useWorkspacePlayback resolves the tick numbers and passes them to the hook.
PointCloudPoints is refactored to use the new color/buffer utilities; projectionOverlay is updated for segmented batches.
New AccumulationSettings and PointSizeSettings UI components are wired into SceneViewSettings.
How has it been tested?
Run application with MCAP file and in 3D scene select "accumulation" for 3D scene rendering, also test how 3D scene reacts with playback and changes in accummulation settings

Summary by CodeRabbit
New Features
Point-cloud details can accumulate data from nearby sequence ticks. Enable accumulation in scene settings and adjust the radius from 1 to 10 ticks.
Accumulation settings persist across workspace mounts, and playback loads surrounding ticks based on the selected radius.
Bug Fixes
Point colors display correctly when some point batches lack RGB color data.
