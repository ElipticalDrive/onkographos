Summary
```
RGBGrid parameters
  -> Flat RGB voxel grids + 16³ spectral majorants
  -> existing volume_data buffer + RGBGrid record fields
  -> shared RGB-to-spectrum lookup
  -> primary tracking and shadow ratio tracking
```
Adds RGBGrid absorption and scattering to the WebGPU medium path.
Converts each voxel to the sampled spectrum before trilinear interpolation, using the selected color space.
Makes r4 CPU RGBGrid construction use ParameterDictionary::color_space(), matching pbrt-v4.
Rejects coefficient values whose constructed spectral maximum is non-finite or cannot be represented as f32.
Reports non-empty RGB Le grids as unsupported; emission remains out of scope.
Evidence
Before: WebGPU medium dispatch supported homogeneous, uniformgrid, and cloud records; RGBGrid was unsupported. The r4 CPU RGBGrid path always used sRGB.
After: Focused tests pass for rgb_grid_medium, gpu_webgpu_scene_medium, RGBGrid Flat IR, WebGPU ABI, and WGSL validation. Regression tests cover selected CPU color space and f32 spectral overflow. The GPU lookup probe matched CPU spectrum samples within 3e-6 in all four color spaces and stayed under the computed majorant.
GPU, r4 CPU, and v4 CPU rendered a 128×128 RGBGrid absorption scene at 256 spp. Channel means were GPU [0.2668, 0.3372, 0.3677], r4 CPU [0.2660, 0.3363, 0.3662], and v4 CPU [0.2654, 0.3360, 0.3656]. The visual comparison is in works/20261011/rgbgrid/rgbgrid-visible-comparison.png in the devkit workspace; per-pixel differences include independent sampling noise.
Merge Danger
Door: Two-way
Blast Radius: Medium
VolumeMediumRecord grows by one vec4<u32> for all volume records. Existing volume kinds initialize the added field to zero; ABI size and offsets are covered by tests.
