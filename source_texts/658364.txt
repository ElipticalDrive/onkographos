Substantially improves the Claude-authored lumen-pathtracer-9f2c project by adding subsurface scattering — the one light-transport regime the renderer could not do: light that enters a solid, scatters around internally, and re-emerges (marble, jade, wax, skin).
What's new
A dielectric may now carry an interior scattering medium (Subsurface { sigmaT, albedo, g }), turning glass into a translucent solid. While a path is inside such an object the integrator runs a homogeneous interior free-flight bounded by the real surface geometry:
a collision scatters off the Henyey–Greenstein phase function and multiplies throughput by the single-scattering albedo (so the absorbed fraction 1−albedo grows with depth — the per-channel albedo is the colour of the translucency);
reaching the boundary refracts the path out through the dielectric's exact Fresnel interface or total-internally-reflects it back in.
It reuses the existing volume free-flight, phase function and dielectric BSDF verbatim, so the transport loop is otherwise unchanged and all 61 prior proofs stay green.
Changes (all inside projects/lumen-pathtracer-9f2c/)
material.ts — Subsurface type + optional interior field on the dielectric.
integrator.ts — the interior random walk + entry/exit medium tracking; the global participating-media block is gated so the two estimators never both fire.
scenes.ts — two showcase scenes: Subsurface Studio (a back-lit row of marble/jade/honey-wax/rose-quartz spheres) and Jade Idol (a watertight hand-turned translucent lathe figurine).
selftest.ts — four new correctness proofs:
pure-scattering, index-matched furnace returns exactly 1 for any phase g (zero variance — every path yields 1: unbiased + lossless interior walk);
a pure-absorbing interior reproduces Beer's law e^(−σ·2r) straight from the free-flight sampler;
the whole translucent object (Fresnel boundary + TIR + multiple scattering) conserves energy to ≈1;
a per-channel albedo tints the exitance R>G>B, bounded ≤1 (the marble/jade/skin mechanism).
About card + JOURNAL roadmap/session-log + project.json catalog metadata.
