# 3D SPH Fluid Simulation

Real-time **Smoothed Particle Hydrodynamics** in 3D, with two-way rigid-body coupling, **Marching Cubes** surface reconstruction, and a **GPU compute-shader ray tracer** for the reconstructed water surface.

## What's in the box

- **Solver**: 3D SPH with cubic-spline kernel — density, pressure, viscosity, gravity. Optional OpenMP parallelisation.
- **Rigid coupling**: rigid spheres exchange momentum with the fluid (buoyancy, drag, contact response).
- **Surface reconstruction**: Marching Cubes on a density grid sampled from the particle field.
- **Renderers**: particle splats, rasterised mesh, mesh-on-particles overlay, and a GPU ray tracer in a compute shader.
- **Ray-tracer features**: Snell refraction at the water surface, Beer–Lambert volumetric absorption, Fresnel reflection, Reinhard tone mapping.
- **Headless mode**: dump frames to disk (`--headless`), then stitch with ffmpeg.

## Requirements

- CMake ≥ 3.10
- A C++17-capable compiler (GCC / Clang / MinGW)
- OpenGL 3.3+ (4.3+ required for the ray-tracing mode — compute shaders)
- GLFW, GLAD, GLM — **bundled** under `dep/` (zlib / MIT licenses)
- Optional: OpenMP (auto-detected, parallelises the solver)
- Optional: ffmpeg (for the `make video` target)

## Build & run

```bash
make build              # cmake + make
make run                # build, then open an interactive window

# headless rendering pipeline
make frames             # 20 s simulation, every 25th frame
make allframes          # 20 s simulation, every frame
make video              # stitch frames with ffmpeg
```

Or call the binary directly:

```bash
./fluidSim --headless --duration 15 --every 5 --output out/
```

## Source layout

```
src/
  main.cpp                       window, camera, main loop
  Vector.hpp                     small typedefs (Real, tIndex)
  simulation/
    SphSolver.hpp                SPH + rigid bodies (no GL deps)
  geometry/
    MarchingCubes.hpp            isosurface from a scalar field
  rendering/
    ShaderUtils.hpp              shader compile/link helpers
    Rasterizer.hpp               particle / mesh / box / sphere passes
    RayTracer.hpp                GPU ray tracer (compute shader)
    shaders/                     GLSL: particle, box, mesh, sphere,
                                  raytrace.comp, quad
dep/                              vendored GLFW + GLAD + GLM
```

## Default scene

A 5 × 10 × 5 domain with a 5 × 6 × 5 fluid block at the bottom.
At t = 5 s a heavy gold ball (ρ = 8000) drops in and sinks. At t = 15 s a red light ball (ρ = 500) lands, dunks under the surface, then bobs back up.
