Module Name
Noise
Description
Provide deterministic 1D/2D/3D procedural noise generators powered by IRandomSource.
This enables reproducible textures, heightmaps, domain-warp inputs, animation curves,
and other effects that depend on coherent noise.
Fits RNGenie's mission: same source/seed/stream => same output across platforms and runs.
Scope
MVP
Algorithms: Improved Perlin (PerlinImproved) and Simplex (Simplex) noise.
Dimensions: 1D, 2D, 3D.
Fractals: fBm, Turbulence, Ridged multifractal
Optional seamless tiling (periodic noise) per axis.
Reproducible when used with a seeded IRandomSource (e.g. Pcg32Source).
Potential later additions
Variants: OpenSimplex2, Worley/Cellular, ValueNoise, Domain Warp.
Normal-map generator, color gradients/palettes.
SIMD/Parallel rendering helpers.
4D noise for animated volumes/time-based noise.
Implementation Notes
Suggested namespace: RNGenie.Noise
Key types/classes/structs:
public interface INoise
double Noise1D(double x)
double Noise2D(double x, double y)
double Noise3D(double x, double y, double z)
public readonly struct NoiseSettings
double Frequency, double Amplitude, int Octaves, double Lacunarity, double Gain
bool Title, int PeriodX, int PeriodY, int PeriodZ
int SeedOffset (optional per-texture offset)
Implementations:
public sealed class PerlinImproved : INoise
public sealed class Simplex : INoise
public sealed class TiledNoise : INoise (thin wrapper that enforces periodic indexing)
Fractals:
public static class Fractal
FBm(...), Turbulence(...), Ridged(...) overloads for 1D/2D/3D
Integration with existing RNG sources/distributions
IRandomSource is used at construction time to shuffle permutation tables and select gradient sets.
Equal (algorithm version, RNG rng, seed/stream, settings) => byte-identical outputs.
Distributions are not required, we only need uniform randomness for table shuffles (Durstenfeld w/ NextInt()?)
Performance
Allocation-free inner loops, precompute/double permutation tables.
Prefer float in pixel rendering, double in API for precision.
(Later) SIMD with System.Numerics.Vector<T> and row-wise Parallel.For in sample renderers.
Numerical ranges
Raw noise ~ [-1, +1]. Recommend mapping to [0,1] via (v+1)*0.5 for images.
Tests
Determinism
Same IRandomSource seed/stream + settings => identical grids (1D/2D/3D).
Continuity & bounds
Values are within [-1,1] (allow tiny epsilon).
Neighboring samples differ smoothly (no jumps at cell boundaries).
Tiling
For Tile=true, check edges match (row 0 == row N, col 0 == col N) per configured period.
Fractal composition
fBm/Turbulence/Ridged return plausible ranges (no explosions) for typical (Octaves, Lucinarity, Gain).
Constructor randomness
Different seeds produce different permutation tables (statistical sanity: hash of table differs).
Performance smoke
512x512 fBm render under a modest time budget in CI (non-flaky threshold).
Samples
RNGenie.Samples:
Heightmap (PNG): 512x512 fBm (Simplex) using Pcg32Source.
Clouds: Turbulence(Simplex) with soft contrast.
Marble: sin(x*freq + turbulence(...)) mapped to grayscale.
Tiled Texture: Demonstrate seamless wrap with PeriodX=PeriodY=256.
CLI knobs: width/height, seed, algorithm, octaves, frequency, gain, lucinarity, tile period.
