Closes #18.
What changed
flint-procgen's noise module no longer wraps noise-rs. Every function in it is now written from scratch, and the public API callers use (NoiseSource, PerlinNoise, SimplexNoise, ValueNoise, WorleyNoise, Fbm, perlin_fbm/simplex_fbm) is unchanged.
PermutationTable: bytes 0–255 shuffled by SeededRng (Fisher–Yates), mirrored to 512 entries. It drives Perlin, simplex and value noise, so new(seed) and from_rng(&mut SeededRng) both work.
Perlin 2D/3D: improved (2002) Perlin with a quintic fade. The 2D version uses eight gradients of equal length √2, which makes its peak exactly ±1. The 3D version uses the 12 cube-edge gradients and is divided by a measured peak (1.0025 over 24M samples).
Simplex 2D/3D: Gustavson's formulation with the exact r² = 0.5 kernel, so it stays continuous across simplex boundaries. The output scales (70.0 / 76.5) come from measured peaks.
Value noise: lattice values in [-1, 1] with quintic interpolation.
Worley: f1_f2(x, y) -> WorleySample { f1: f32, f2: f32 }, normalised to about [0, 1], with f1 <= f2 always. with_metric(VoronoiMetric) selects Euclidean, Manhattan, Chebyshev or Minkowski. The search walks rings of cells outward and stops once no unvisited cell can beat F2, so it is exact; a brute-force test checks this. The NoiseSource modes (cell value, or signed F1) are kept.
Fbm: adds with_amplitude. With 1 octave, frequency 1 and amplitude 1 it returns exactly the base noise. 0 octaves returns 0 instead of NaN.
The noise dependency is removed from flint-procgen. flint-terrain still uses it, so the workspace dependency stays.

cargo test passes for the whole workspace, including 472 tests in flint-procgen, and clippy reports nothing new in noise.rs.

- Worley F1/F2 (WorleySample) with selectable VoronoiMetric and an

  debug PNGs written to target/test-output/noise/
