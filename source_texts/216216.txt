Webinar presenting the Mesh Optimizer, a tool developed at FBK-3DOM within 3DBigDataSpace to make heterogeneous, heavy 3D heritage models reusable for XR and web applications. The tool runs an automated end-to-end pipeline built on a Python orchestration layer, Blender for mesh processing and baking, CGAL for adaptive isotropic remeshing, and a machine-learning step (PartUV) for semantic UV generation, all packaged in Docker for reproducibility. The workflow moves through pre-processing, remeshing, initial decimation to a manageable target (about 300k faces), part-based UV generation, PBR texture baking (normal, ambient occlusion, roughness) and final decimation, exporting an optimised GLB with embedded textures. The webinar shows the configuration parameters (resolution, quality preset, remeshing tolerance, edge limits, Hausdorff threshold) and how to run the tool from a Docker container.
