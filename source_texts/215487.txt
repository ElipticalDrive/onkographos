Description
ArchimedLight v0.3.0
Diff since v0.2.0
This release adds voxel-based light simulations with terrain, improves performance for repeated calculations, corrects light interception in finite triangle scenes, and introduces interactive browser demos.
Breaking changes
Performance improvements
Reuse diffuse-light calculations as the sun moves. With cache_radiation=true and all_in_turtle=false, only the changing solar response is replaced. Recorded wheat benchmarks measured approximately 22× and 153× faster subsequent timesteps, depending on configuration, with substantially lower allocations and retained cache storage. These measurements exclude compilation and initial preparation. ([#62](https://github.com/VEZY/ArchimedLight.jl/pull/62))
Reduce scene-preparation overhead by avoiding repeated MTG root searches when resolving emitters and component metadata. ([#59](https://github.com/VEZY/ArchimedLight.jl/pull/59))
Corrections and behavior changes
Correct finite-scene clipping at oblique light angles. Non-toric triangle scenes now use a fitted projection plane perpendicular to each light direction, keeping elevated geometry within the sampled domain. Results can therefore change for previously clipped scenes. Toric projection behavior is preserved, and pixel_size retains its horizontal-ground resolution meaning. ([#61](https://github.com/VEZY/ArchimedLight.jl/pull/61))
Add opaque ground models with zero transmission and outward Lambertian reflection, and correct voxel traversal for rays starting exactly on periodic boundaries. ([#63](https://github.com/VEZY/ArchimedLight.jl/pull/63))
New features
Voxel light transport and terrain
Simulate PAR and NIR interception and multiple scattering on plant area density grids using the new CPU voxel backend.
Import AMAPVox .vox files and individual/organ information from .jsonl and .jsonl.gz files.
Include flat ground, PLY terrain meshes, or digital terrain models, with configurable soil reflectance.
Assign optical properties to foliage, wood, individuals, and soil materials. Inspect light budgets by voxel, individual, organ, or ground patch.
Use familiar entry points such as read_scene, models_for, run_light, component_values, and lightplot, with open or horizontally periodic boundaries.
Voxel vegetation uses Beer–Lambert attenuation and isotropic scattering. Attribution from point proportions is an explicit modelling assumption, rather than a measurement of organ area. ([#63](https://github.com/VEZY/ArchimedLight.jl/pull/63))
Documentation and maintenance
Refresh the documentation with Bonito and interactive wheat and voxel/terrain demos that calculate light directly in the browser. ([#60](https://github.com/VEZY/ArchimedLight.jl/pull/60), [#63](https://github.com/VEZY/ArchimedLight.jl/pull/63))
Add an Applications gallery covering intercropping, agrivoltaics, rice canopies, and oil-palm experiments. ([#64](https://github.com/VEZY/ArchimedLight.jl/pull/64))
Consolidate developer guides, remove obsolete scripts and unused assets, and replace the evaluation viewer's Python data builder with Julia and automated freshness checks. ([#66](https://github.com/VEZY/ArchimedLight.jl/pull/66))
