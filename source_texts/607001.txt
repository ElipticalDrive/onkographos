Convert arbitrary OBJ meshes into a fixed-size binary occupancy grid (e.g., 32x32x32 or 64x64x64) that can serve as input to a 3D CNN surrogate model.
Requirements
Take any OBJ mesh and normalize it to fit within a unit bounding box
Rasterize the mesh into a 3D voxel grid using ray casting or surface voxelization
Output a binary occupancy tensor: 1 = solid, 0 = fluid
The voxelization must be deterministic and resolution-configurable
Handle non-watertight meshes gracefully (surface-only voxelization as fallback)
Implementation
Python library (ml/voxelize.py) for training data generation
C implementation (simulation/src/voxelize.c) for real-time inference
The existing isInsideCarModel() ray-casting in the OBJ loader can be adapted
Considerations
Resolution trade-off: higher resolution captures more detail but increases model input size. 32^3 = 32K voxels, 64^3 = 262K.
Orientation normalization: longest axis should align with flow direction (x), matching the auto-rotation logic in main.c
The grid should include some padding around the object for the CNN to see the boundary layer region
Prerequisite for #149 (geometry-aware Cd surrogate).

Both sides of this now exist on branch anyobj-surrogate:
Python: ml/anyobj/geometry.py voxelize() rasterizes any mesh into a solid occupancy grid over [-1,1]^3 (cell-center containment test). Deterministic, resolution-configurable, longest axis rotated to X, padding around the body. Falls back to the convex hull for non-watertight meshes when computing descriptors.
C: simulation/src/voxelize.c (the real-time inference side), which geometry.py mirrors for parity.
Likely closeable. The only requirement not explicitly exercised is surface-only voxelization for badly non-manifold meshes; the current path uses solid containment plus a hull fallback.
