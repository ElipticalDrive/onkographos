Part 2 of 4 of #1314
This adds TriangulatePolygonsOfElements (Element Commands, registered for 1.7.3). It triangulates the plan polygon of Slabs, Zones, Hatches, Meshes and Roofs with ACAPI_Polygon_TriangulatePoly, which is ACAPI_Goodies (APIAny_TriangulatePolyID, …) on AC25/26. It needs no other part and starts from main.
```
{"elements": [{"elementId": {"guid": "…"}}]}
```
→
```
{"triangulations": [{"triangles": [{"vertices": [{"x": 0, "y": 0}, {"x": 1, "y": 0}, {"x": 1, "y": 1}]}, …]}]}
```
The output is aligned with the input. An element of any other type, a missing element or a failed call gets an error item.
Notes
Response shape: each triangle is an object {"vertices": [3 coordinates]}, not the bare nested array the issue sketched. Every other list in the add-on's responses holds objects, so this keeps to that pattern.
Element types: the polygon comes from the element's memo (APIMemoMask_Polygon), the same coords GetDetailsOfElements reads for these types. For a multi-plane Roof that is its contour, and for a Mesh it is the plan outline (no z).
AC25/26: the TAPIR_Polygon_TriangulatePoly wrapper makes the AC27+ / AC25/26 split the same way the TAPIR_Polygon_* wrappers in ExtendedElementCommands.cpp do.
Adds the example Examples/triangulate_polygons_of_elements.py. It prints the triangle count and summed triangle area per element, plus the error item a Wall gets.
To confirm against the DevKit (no DevKit on the runner)
A maintainer should check these against the DevKit headers and docs. They come from the issue's declarations and how the code base calls similar functions, not from the DevKit itself:
Result handle layout: the code assumes the handle TriangulatePoly returns holds three API_Coords per triangle. If its size is one more than a multiple of three, item 0 is treated as unused, like in memo coord handles.
Who frees the handle: the code assumes the caller owns it and frees it with BMKillHandle.
AC25/26 parameters: APIAny_TriangulatePolyID is assumed to take the memo as par1 and API_Coord*** as par2.
Untested in Archicad
This change has not been run in Archicad. To verify it, load the add-on built for this PR, open a project that has a Slab, Zone, Hatch, Mesh and Roof (with a hole in at least one), and run python archicad-addon/Examples/triangulate_polygons_of_elements.py. Each element's summed triangle area should match its area in Archicad (holes excluded, arcs approximated). The Wall should get an error item.
