First of the reusable .ari scene-DSL capabilities for the lsystem_forest port (the reusable-capabilities-first approach): make the VTK GPU-mapper volume node's colour authorable from a document.
Problem
A type: volume node (VTK VolumeNode, distinct from the software volren/volslice) was the one renderer whose colour couldn't be set from .ari — only ambient/diffuse mapped, so it always rendered with the default grayscale ramp. The sea and cloud volumes in lsystem_forest both need an explicit, shaded transfer function.
Change
A volume: block, parallel to volren:/volslice::
```
- node: sea
  type: volume
  source: field.vol
  material: { ambient: 0.3, diffuse: 0.7, specular: 0.4, specular_power: 18 }
  volume:
    shaded: true
    transfer_function:
      points:
        - { value: 0.0, color: [0.00, 0.42, 0.78, 0.0] }
        - { value: 1.0, color: [0.01, 0.09, 0.22, 0.5] }
```
New SceneVolume struct (scene.h) + loader block, reusing the shared parse_scene_tf TF vocabulary.
Realizer feeds it to VolumeNode::setTransferFunction (colour [s,r,g,b,…] + opacity [s,a,…] tables split from the rgba points) and setShading, and now also applies the material's specular/specular_power (previously only ambient/diffuse).
TF point values are absolute scalar values — the VTK mapper takes the raw domain, so auto_domain/window (honoured by volren/volslice) don't apply here. Each knob applies only when stated, so an unstyled volume keeps VolumeNode's tuned defaults (no behaviour change for existing scenes).
Tests
Loader: VolumeTransferFunctionAndShading, VolumeWithoutSettingsKeepsDefaults.
Realize (offscreen, cvcgl_ariadne_realize): our green channel 0.42 + opacity 0.5 reach the mapper, and shaded: false flips VolumeNode's default-true shading.
Part of the lsystem_forest Ariadne port; the procedural in-memory volume source + per-frame field updates are follow-up increments.

```
A geometry node can now be a displaced grid with no asset:
source: { heightfield: { size, resolution, layers: [...], colors: [...] } }.
The height at each grid point is the sum of composable layers — dome (radial
Gaussian) and wave (travelling sine) — and the realizer builds the cvc::geometry:
a res×res grid over [-size/2,size/2]², world→[0,1]² UVs, height-gradient normals,
grid triangulation, and (when colors is given) per-vertex band colours. fit: is
ignored (already centred/sized like a primitive); mesh-level shape only — fine
surface detail belongs in a fragment shader, a later increment.

reaches its amplitude). The reusable terrain primitive for the lsystem_forest
island. Stacks on #549 (volume transfer function).
```

```
* ariadne(scene): procedural heightfield geometry source

A geometry node can now be a displaced grid with no asset:
source: { heightfield: { size, resolution, layers: [...], colors: [...] } }.
The height at each grid point is the sum of composable layers — dome (radial
Gaussian) and wave (travelling sine) — and the realizer builds the cvc::geometry:
a res×res grid over [-size/2,size/2]², world→[0,1]² UVs, height-gradient normals,
grid triangulation, and (when colors is given) per-vertex band colours. fit: is
ignored (already centred/sized like a primitive); mesh-level shape only — fine
surface detail belongs in a fragment shader, a later increment.

Pinned by the loader HeightfieldSource gtest and the offscreen
cvcgl_ariadne_realize (res² verts/uvs/colours, 2·(res-1)² tris, dome centre
reaches its amplitude). The reusable terrain primitive for the lsystem_forest
island. Stacks on #549 (volume transfer function).

* docs(roadmap): record increment 7 (heightfield geometry source)

* ariadne(scene): geometry textures via material: { texture }

A geometry node can carry an image texture sampled through its UVs:
material: { texture: <uri> } (or { texture: { uri|file: <uri> } }). The realizer
resolves the URI through the shared §13.4 bridge (resolve_to_file), reads it with
cvc::read_image, and applies it via GeometryNode::setTexture; an unresolved URI or
unreadable image warns and skips (never throws), and a mesh with no UVs is simply
unaffected. Pairs with the heightfield primitive for textured terrain.

Pinned by the loader MaterialTexture gtest (scalar + {uri} forms) and the
offscreen cvcgl_ariadne_realize (valid texture loads with no warning on a
UV-bearing heightfield; a bad URI warns but still creates the node).
```
