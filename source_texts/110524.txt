Proven frame mismatch
Current PR #8 head 926ef4adf9adc0bf2956585416d2de819d9ccd01, reverified during this pass.
MeshJoiner.join_with_voxel_remesh documents voxel_size in world units. Its default is max world-bounds extent / 64, with an absolute 1e-4 floor. It then assigns that number directly to a REMESH modifier. join_simple makes objects[0] active and joins into its existing object frame; neither it nor attempt duplication bakes the resulting scale.
Blender's 5.2 modifier implementation passes the mesh and voxel_size to its remesher. The voxel kernel constructs its grid from that size and the mesh positions, without applying the object's world matrix. Thus this parameter is in the mesh's coordinate frame, not automatically world units.
Tiny source/operator witness
Executed the unchanged join_with_voxel_remesh function body using inert join/modifier operators and prescribed objects with the same world bounds [-1,1]^3. This isolates parameter construction; it does not claim newly executed native remeshing.
Identity object scale: local modifier size .03125, world steps (.03125,.03125,.03125).
Uniform object scale (2,2,2), compensating local geometry: local size remains .03125, world steps become (.0625,.0625,.0625).
Scale (2,.5,1), compensating local geometry: same local size, world steps (.0625,.015625,.03125).
Equivalent world geometry therefore gets different physical resolution solely from its authored transform decomposition. Choosing a different first object can also select another frame. PrimitivePlacer intentionally assigns non-unit/nonuniform object.scale, so this boundary is not limited to imported pathological meshes.
Buildable implementation
Define a remesh execution frame and explicit requested/resolved voxel units. For isotropic world-space resolution, build an owned evaluated mesh in a rigid/unit-scale working frame, rather than passing a scalar through arbitrary affine scale.
Transform all joined operands coherently into that frame, preserving evaluated geometry and correcting reflected winding under Preserve solid winding when evaluated meshes cross reflected world transforms #44. Remesh there, then map the result into the chosen output object frame. Preserve source objects until the attempt is admitted and committed.
Uniform scale may be converted analytically when safe, but dividing by one scale component or a mean is not a correct fix for nonuniform scale/shear. Reject unsupported/singular transforms explicitly.
Derive automatic resolution from declared world-space feature/error targets and a work/memory plan. Make the absolute floor a documented numerical/runtime limit or a scale-aware policy, not an accidental change in shape quality after unit conversion.
Record requested world size, execution transform, resolved grid size, world bounds, native runtime and realized quality/cost in JoinAttempt. A nonempty output alone is not fidelity acceptance; reuse Guard mesh postprocessing with geometric validity and fidelity, not connectivity scores alone #94's geometric/protected-feature guards.
Preserve explicit mode/fallback provenance. Do not silently call an anisotropic result isotropic or overwrite source geometry while recovering from a failed remesh.
Tests and acceptance
Native qualification on the supported Blender version: the same world surface encoded with baked coordinates, uniform/nonuniform scales, parent transforms and reflected frames must produce equivalent geometry within the declared voxel error, or an explicit unsupported result.
Permute operand order. The requested physical grid must not change with the active object's scale; if a declared grid orientation/phase changes, account for it and bound the effect.
Known narrow gaps/thin features at just above/below the chosen world resolution distinguish under-resolution from transform bugs.
Pure planning tests cover the exact .03125 witnesses, explicit user size, zero/nonfinite sizes, unit conversion and singular/ill-conditioned transforms.
Failure injection leaves original geometry, transform, selection and owned temporary datablocks correct.
Benchmark frame preparation, voxel work and acceptance separately at equal physical resolution. A scale bug reducing effective detail must never count as a speedup.
Related #62 concerns glTF export unit conversion, #93 OpenVDB persistence, and #94 output fidelity. This issue owns the separate native mesh-join remeshing frame/resolution contract. No local unpushed work or fresh native run was inspected.
