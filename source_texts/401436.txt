Implements browser-based point cloud processing demo showcasing downsampling, segmentation, and clustering algorithms. Features distance-aware downsampling technique from research papers that preserves geometric features via local curvature analysis.
Implementation
Algorithms
Downsampling: uniform, random, voxel grid, distance-aware (adaptive sampling based on local curvature)
Segmentation: RANSAC plane detection (single and multi-plane)
Clustering: K-means, DBSCAN
Visualization
Custom 3D canvas renderer with perspective projection
Interactive camera controls (drag/scroll)
Synthetic datasets: indoor scene, outdoor scene, car object (10.5k points)
Performance tracking
Live metrics: processing time, point reduction ratio
Comparison chart across methods
Distance-aware achieves 81% reduction while preserving features
Key Technical Details
Distance-aware downsampling computes local curvature via k-NN variance, adaptively keeps points based on geometric complexity:
```
const keepProb = BASE_KEEP_PROBABILITY + curvatures[i] * MAX_CURVATURE_BONUS;
// High curvature areas (edges, corners) → high keep probability
// Flat regions → aggressive downsampling
```
Tab-based UI organizes controls by operation type. All algorithms configurable via sliders/dropdowns.
