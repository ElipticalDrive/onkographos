Hi @kobeleenders,
With the blender_config.txt provided in the repo (reproduced below), training a NeRF uses 8.9GB of GPU RAM.
Usage is at 4.7GB at first, but after a few iterations it jumps to 8.9GB (maybe after doing the first preview re-rendering).
```
expname = blender_paper_lego
basedir = ./logs
datadir = ./data/nerf_synthetic/lego
dataset_type = blender

no_batching = True

use_viewdirs = True
white_bkgd = True
lrate_decay = 500

N_samples = 64
N_importance = 128
N_rand = 1024
```
