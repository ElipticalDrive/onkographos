Purpose and Overview
The Greedy Meshing Algorithm is an optimization technique used to efficiently render voxel worlds by reducing the number of triangles needed. This document explains how the algorithm is implemented in the codebase and how it fits into the overall meshing system.
Instead of generating 12 triangles (2 per face) for each visible voxel, greedy meshing combines adjacent faces of the same type into larger rectangles. This can dramatically reduce the polygon count and improve rendering performance.
For information about the overall mesh generation process, see Mesh Generation Process.
Sources: README.md7 ChunkMeshActual.cs1-785
Core Concept
The core idea behind greedy meshing is to merge adjacent voxel faces with identical properties (such as texture ID) into larger rectangular faces. The algorithm "greedily" attempts to create the largest possible face by expanding along two axes.
```

```

Algorithm Workflow
The algorithm processes each voxel in the chunk, working through the following steps:
Initialization - Set up temporary storage and mesh visiting trackers
Voxel Iteration - Iterate through all voxels in the chunk using heightmap optimization
Face Examination - For each voxel, check each of its six faces
Face Merging - For each visible face, attempt to merge along two axes
Triangle Generation - Generate triangles for the merged faces
Finalization - Transfer the mesh data to the vertex buffer


Face Merging Process
The face merging process is the core of the greedy meshing algorithm. For each face direction, it follows a two-step merging process:
Primary Axis Merging: First, the algorithm attempts to merge along the primary axis (usually the Y axis)
Secondary Axis Merging: Then, it tries to merge along a secondary axis (X or Z, depending on the face)
The specific axes used for merging depend on the face direction:
Face DirectionPrimary Merge AxisSecondary Merge Axis
Left (X-)YZ
Right (X+)YZ
Bottom (Y-)XZ
Top (Y+)XZ

Front (Z+)YX

Face Merging Logic
The merging process follows these steps for each face:
Check if the face should be rendered (not covered by another voxel)
Mark the face as "visited" in the mesh visiter
Try to expand along the primary axis as far as possible

Summary
The greedy meshing algorithm is a crucial optimization technique that enables efficient rendering of voxel worlds. By combining adjacent faces with identical properties, it significantly reduces the polygon count while maintaining the same visual appearance.
The implementation in this codebase uses a two-axis merging approach combined with several optimizations such as heightmap-based traversal, mesh visitor pattern, and efficient memory management.
