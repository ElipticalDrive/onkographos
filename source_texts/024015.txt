Abstract
Event cameras capture dynamic scenes by asynchronously outputting pixel-level brightness changes, offering significant advantages such as microsecond-level response times, ultra-high dynamic range, and low power consumption. These characteristics make them particularly suitable for high-speed motion capture and extreme lighting scenarios. However, the inherent sparsity and asynchronous nature of event streams pose challenges for mainstream vision algorithms, which typically require dense and structured inputs. Existing approaches, which can be categorized into sparse and dense representations, often suffer from limited adaptability, information loss, and computational redundancy. To address these issues, we propose EventVCE (Event Voxel Compressed Encoding), a novel framework for efficient event data representation based on voxel compressed encoding. The key contributions of this work are: (i) Efficient Feature Compression: By incorporating compressed sensing theory, we introduce a dynamic random coding mask combined with a spatio-temporal modulation mechanism, significantly reducing data redundancy while minimizing storage and transmission overhead. (ii) Enhanced Feature Representation: The compressed encoding process extracts essential dynamic features while preserving critical spatio-temporal information. (iii) Seamless Compatibility and Adaptability: The framework outputs a standard 2D tensor compatible with conventional CNNs, enabling end-to-end processing. It supports mainstream image preprocessing and enhancement techniques and allows dynamic configuration of encoding parameters to adapt to varying scene complexities.Experimental results demonstrate that EventVCE achieves competitive performance in object recognition tasks, while significantly reducing computational and storage costs. The framework effectively balances computational efficiency and recognition accuracy, offering a highly compatible and practical solution for efficient event data processing.
Keywords: event camera, Spatio-temporal voxelization, Voxel compressed encoding, object recognition
