Create a family of classes that represent the numerical matrix types provided by GLSL and which are most useful to graphics programming. This includes:
4x4
4x3,3x4
3x3
3x2,2x3
2x2
You only need to implement the basic operations:
Matrix Multiplication
Matrix/Vector multiplication
Determinant where possible
Inverse
Note that it may be tempting to use the '~' operator for the inverse, but the inverse is not guaranteed to exist (the transformation is not affine)
Trace, Transpose
Matrix arithmetic
Matrix/Scalar arithmetic
And some basic named constructors:
Rotation
axis/angle; No Euler angles in order to avoid gimbal lock
Projection
