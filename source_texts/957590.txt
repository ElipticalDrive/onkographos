What and why
点群 → Gaussian splat（静岡の LAS/LAZ をブラウザで速く・WebGPU・CPU fallback なし・本人裁定 2026-11-06）の 4 手順をまとめた PR。
1. Converter (@ortho-earth/globe + @ortho-earth/splat 0.7.0)
map.readPointCloud(src, { crs, vertical, maxPoints, onProgress }) → PointCloudDump (ENU Float32 points around an anchor, elevations, RGB, intensity, classification). COPC: shallow nodes first; the depth that hits maxPoints is stride-sampled across all its nodes. isSplatUrl accepts .las/.laz/.zip.
addData(url | File | Blob | PointCloudDump, { kind: "splat", crs, vertical, maxPoints, color, cloud }): cloud-gpu.ts (WGSL: spatial-hash counting sort, exclusive scan, leader/merge with neighbour covariance, coarser levels merged from the finer one) builds the splat levels on the shared GPUDevice; each frame draws the level whose splats are ~pxPerSplat px. Handle: levels / level / points / plan / ms / read() / setAltitude(); addSplatCloud(map, data) reloads read() data without conversion.
WebGL2 renderer refuses (ready rejects with WebGPU is required for point cloud splats); buildCloudCpu is the reference for tests and the CLI only.
2. /japan/pointcloud (apps/pointcloud)
Points are read by the page, converted on the GPU, and both the points and the converted levels are saved on the device (pc-cache.ts: OPFS → IndexedDB → pass-through, 2 GB budget, oldest-first eviction; pc-pack.ts packs typed arrays). Reopening a sheet needs no download and no conversion; colour / detail / opacity re-convert the saved points without downloading. Height offset = setAltitude; fit-to-terrain = class-2 points vs map.sampleTerrain.
No WebGPU → whole-page error (noWebGpu), no WebGL2 fallback; glOverlay dropped. Dictionary: new strings in 25 languages. vite.config adds moduleUrlAsChunk (as in apps/splat).
3. Export (cloud-export.ts): cloudToSpz, spzPlacement, cloudTo3DTiles (tileset.json + one glb per level, KHR_gaussian_splatting + _compression_spz_2, REPLACE, ENU → ECEF root transform), zipStore. Page buttons: SPZ (finest level + placement.json) and 3D Tiles (all levels), each one zip.
4. CLI sdk/splat/scripts/las2splat.mjs <in> --out <dir> [--gpu|--cpu] …: --gpu (default) runs the browser pipeline in the headless Chrome for Testing with a real GPU (packages/globe/tests/tool-las2splat.html, input/output through a small local HTTP server); --cpu runs the same algorithm in node.
Also: zoomscale.ts classifies readPointCloud as "none" (CI's tests/zoomscale.mjs was red).
