⛏️ Mini Craft
A new first-person 3D voxel sandbox in the spirit of Minecraft, rendered with raw WebGL — no runtime dependencies, in keeping with the repo's TypeScript ES-module conventions.
What it does
Procedural world — layered value-noise terrain with grass, dirt, stone, sand, oceans/lakes, beaches and scattered trees, split into 16×16 chunks.
Custom WebGL renderer — per-chunk meshing that emits only exposed faces, with baked ambient occlusion + directional face shading, a procedurally painted texture atlas (no image assets ship), distance fog, an underwater tint, and a separate translucent pass for water and glass.
First-person gameplay — walk with gravity & jumping, or toggle fly; mine and place blocks via raycasting; a 10-block hotbar.
Mobile first-class — full touch support: on-screen movement stick, drag-to-look, and jump/mine/place buttons; desktop uses pointer lock, WASD, mouse look, and 1–9 / wheel to pick blocks.
Persistence — the world seed and every edited block are saved via the shared MG.storage store; a New world header action regenerates. Localized in en / ru / es.
Files
games/minecraft/ — index.html, mc.css, and ES-module sources under js/ (main, world, blocks, textures, mat4, glutil, i18n).
Registered in games.ts (home page) and build.ts (bundle list).
Verification
bun run lint, bun run typecheck, bun run check, and bun run build all pass. The world generator and chunk mesher were additionally spot-checked headlessly (max per-chunk index 6043, well under the Uint16 limit).
