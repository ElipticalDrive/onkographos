Shaftcast
A first-person raycasting engine rendered straight to the terminal — a small, dependency-free Python CLI that builds a pseudo-3D Wolfenstein-style view from a 2D grid map using nothing but the Python standard library.
What it is
DDA raycasting — for every screen column, cast a ray through the grid using the Digital Differential Analyzer algorithm to find the first wall hit; scale the wall slice's height by ray length to fake depth perspective.
ASCII shading — wall columns are drawn with a distance-based luminance ramp (e.g. #%+~. style), so nearby walls are bright and far walls fade. Optional per-tile textures, ceiling/floor fills.
First-person movement — WASD to walk/strafe, arrow keys or Q/E to rotate; run at a fixed grid of columns/rows sized to your terminal via shutil.get_terminal_size, with a frame loop using time.
Map editor convenience — load a map from a small text file, plus a couple of built-in mazes; optional 2D minimap overlay.
Why
Pseudo-3D from a 2D grid is a compact, satisfying graphics/computing showcase (no GPU, no math library — just integer DDA stepping and simple trig) that fits comfortably in a single coding session and fills the 'retro FPS / raycasting' niche, complementing the repo's existing terminal automata and browser games.
Scope
Single-file Python CLI, Python standard library only (argparse, math, shutil, sys, time), no external dependencies, no assets.
