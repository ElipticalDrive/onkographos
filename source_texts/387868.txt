This update significantly improves the volumetric cloud rendering pipeline by transitioning from a planar to a spherical world model.
Key improvements include:
Enhanced Raymarching: The DDA and main marching loops now support up to 512 iterations, with refined termination based on transmittance and atmosphere shell intersections.
Spherical Mapping: Cloud sampling now uses longitude and latitude-based arc lengths, eliminating planar distortion and correctly wrapping clouds around the planet.
Toroidal Topology: The JFA distance map generation and DDA grid traversal now support seamless wrapping across texture boundaries by implementing toroidal distance and modulo-based stepping.
Accurate Motion Vectors: Temporal reprojection now reconstructs previous world positions in spherical space, greatly improving stability for a moving camera on a curved surface.
Robustness: Fixed several bugs, including a longitude seam-crossing issue in the DDA initialization and variable scope errors. Verified all changes with the project's shader validation and unit test suites.
