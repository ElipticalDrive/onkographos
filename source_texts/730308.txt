# PBR PRT realtime renderer

这是一个基于 C++、OpenGL 3.3 和 Spherical Harmonics（SH）的 Probe-based realtime Global Illumination renderer。项目在同一个 source tree 和 executable 中保留两种 direct-light BRDF：

- `--renderer pbr`：Cook-Torrance PBR direct-light adapter，也是默认和正式自动化运行模式。
- `--renderer phong`：Phong direct-light adapter，用于交互观察和 compatibility regression。

Scene、Ray/Surfel、Irradiance convolution、SH projection、3D texture 与 reconstruction 由两种模式共享。当前 GI transport 只需要考虑 **one indirect bounce**。

场景墙面和立方体按哑光涂漆 dielectric 建模：`metallic=0`、`roughness=1`、`IOR=1.5`、`AO=1`。Fresnel normal-incidence reflectance 由 IOR 计算，而非直接写死 F0。RGB 墙面 albedo 用于观察 diffuse color bleeding，不额外施加 saturation 或 GI gain。

自动化运行的 scene、material、camera、viewport、light、SSAA 与 output semantics 固定在 [`realtime-render-contract.json`](realtime-render-contract.json)。修改 renderer 时必须保持该 contract；完整兼容要求见 [`AGENTS.md`](AGENTS.md)。

PRT 的 one-bounce transport、Probe/Surfel 数据流、SH projection/reconstruction 与已知局限见 [`docs/prt-realtime-global-illumination.md`](docs/prt-realtime-global-illumination.md)。

## 环境要求

- Windows 10/11 或 x86-64 Linux；Linux CI/headless 路径已在 Ubuntu 24.04 验证。
- Python 3.10+；当前 Python tools 仅使用 standard library，`requirements.txt` 不包含第三方 package。

可统一执行依赖安装命令（当前不会额外安装 package）：

```text
python -m pip install -r requirements.txt
```
- Windows：Visual Studio 2022 任一 edition，安装 `Desktop development with C++` workload 和 `C++ CMake tools for Windows`。
- Ubuntu 24.04：安装 C++ compiler、CMake、Ninja、GLFW、Assimp、Mesa OpenGL 与 Xvfb：

```bash
sudo apt-get update
sudo apt-get install -y \
  build-essential cmake ninja-build pkg-config \
  libgl1-mesa-dev libgl1-mesa-dri mesa-utils \
  libglfw3-dev libassimp-dev \
  libx11-dev libxrandr-dev libxinerama-dev libxi-dev libxcursor-dev libxxf86vm-dev \
  xvfb python3-venv
```

- Runtime 需要 OpenGL 3.3 Core Profile。可以使用 GPU driver，也可以在没有 GPU、`/dev/dri` 和物理 display 的 Linux 上使用 Mesa llvmpipe + Xvfb。
- RenderDoc 可选，仅在 GPU frame capture 时需要。

仓库包含 GLM、GLAD 及 Windows 所需的 GLFW/Assimp headers/libraries；Linux build 使用上面明确列出的 system GLFW/Assimp/OpenGL packages。Build script 不会联网下载 dependency。

## 快速开始

Windows PowerShell：

```powershell
# 使用 VS2022 bundled CMake/Ninja 构建 Release executable
python .\tools\build.py --renderer pbr

# 启动默认 PBR renderer
.\bin\getting_started\PRTdemo.exe --renderer PBR

# 构建并运行全部无窗口 regression tests
python .\tools\test.py
```

构建 cache 位于 `build-auto-vs2022-ninja/`，executable 固定输出到：

```text
bin/getting_started/PRTdemo.exe
```

Linux shell：

```bash
python3 ./tools/build.py --renderer pbr
./bin/getting_started/PRTdemo --renderer PBR
python3 ./tools/test.py
```

Linux build cache 位于 `build-auto-linux-ninja/`，executable 固定输出到 `bin/getting_started/PRTdemo`。没有 GPU/display 时不要直接启动交互窗口；由 trusted evaluator 使用 Xvfb + llvmpipe 执行 one-shot capture。可先确认 software OpenGL：

```bash
LIBGL_ALWAYS_SOFTWARE=true GALLIUM_DRIVER=llvmpipe \
  xvfb-run -a -s '-screen 0 1600x1200x24' glxinfo -B
```

输出中的 `OpenGL renderer string` 应包含 `llvmpipe`，OpenGL core profile 应不低于 3.3。

程序默认最高 `70 FPS`。控制台每 30 帧输出一次完整 frame 的 FPS、平均 frame time、采样帧数和 frame cap；按 `[`/`]` 后会输出当前 RGB light intensity。
