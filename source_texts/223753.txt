Description
Implement the 3D reconstruction engine using the voxel carving (Shape from Silhouette) method.
Requirements
Create a 3D bounding box in world coordinates scaled by the reference card.
Project 2D segmentation masks into the 3D voxel grid.
Sum the remaining 'non-carved' voxels to calculate the physical volume ($V = \sum \Delta x \Delta y \Delta z$).
Basis
This follows the Anthimopoulos/Dehais pipeline for computationally tractable mobile food volume estimation.[5, 6]
