# livewire

Standalone **WebGPU** renderer for Gaussian splats in the **Spark RAD** format
(as emitted by splatiler). Compute-first: global back-to-front GPU radix sort,
EWA-projected instanced quads, indirect draw. Built around the splat problem
rather than a mesh tile pipeline.

Plain JS + WGSL, no build step.

## Run

```sh
python3 serve.py        # http://localhost:8080/   (localhost is a secure context)
```

Open in a WebGPU browser (recent Chrome/Edge; Safari/Firefox behind flags).

- drag = rotate · shift/right-drag = pan · wheel = zoom

## Status

- **P0** scaffold: device + canvas + orbit camera + sanity triangle. ✅
- P1: RAD load + GPU dequant + unsorted EWA splats (DC color).
- P2: depth-key + radix sort + indirect draw → sorted alpha-over.
- P3: RAD LOD-tree cut → bounded visible count (scalable).
- Later: SH (view-dependent), out-of-core streaming, HTGS.

## Format

Targets Spark RAD (`RAD0`/`RADC`, raw-deflate columns, RUB frame, single-rooted
LOD tree). See `splatiler/src/rad.c` and `splatiler/test/decode_rad.py`.
