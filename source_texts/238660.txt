Goals
Make implicit 3D Tiles initialization complete without subtree network I/O or eager hierarchy allocation.
Request subtree availability only when traversal determines that the boundary is visible, inside its viewer request volume, and above the SSE threshold.
Correct implicit level and availability indexing so the declared last level is materialized without loading beyond it.
Changes
Replaces recursive implicit expansion with a pure, one-resource materializer for QUADTREE and OCTREE subtrees.
Preserves lazy child-subtree boundaries in runtime headers and loads them through the existing request scheduler, including progressive and foveated priorities.
Shares in-flight requests, inherits source query parameters and resolvers, and retains a configurable parsed-subtree LRU via 3d-tiles.maximumCachedSubtrees.
Keeps REPLACE parent coverage while metadata is pending and keeps hierarchy loads separate from render-content/GPU cache accounting.
Adds public child lifecycle state plus Tiles3DSource.getImplicitTilingStats() diagnostics, with TSDoc throughout the new API and implementation.
Corrects breadth-first tile availability, child-subtree Morton indexing, deep coordinate arithmetic, and availableLevels count semantics.
Adds sparse QUADTREE/OCTREE, last-level, bounds, URL/query, cache/deduplication, destruction, traversal, and coverage tests plus a 1,365-tile materialization benchmark.
Adds a dedicated Implicit documentation tab and guide, cross-links the related SSE/LOD, hierarchy, scheduling, resource, caching, diagnostics, and API pages, and updates What’s New.

Current limitations
Only the first content-availability stream is materialized; multiple contents remain future work.
S2-derived implicit descendants retain the root oriented box conservatively rather than deriving tighter child S2 boxes.
Additional subtree/tile metadata semantics beyond availability remain future work.
