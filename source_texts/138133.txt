Ray casting and ray-sphere intersection test for OpenGL 4.5.0 C++
This is an example of ray casting and ray-sphere intersection testing for C++ using OpenGL 4.5.0 core running Visual Studio 2022. This method is achieved by casting a ray from a mouse point in viewport coordinates that projects a line into the correct space for interaction.
