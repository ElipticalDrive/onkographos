Summary
Adds a new Rust + Python hybrid package (gsplat-rust-renderer) to the monorepo — a GPU-accelerated Gaussian Splatting viewer built as a custom Rerun visualizer. This is the first Rust package in the monorepo.
Rust binary: Custom Rerun viewer with a tile-based compute renderer (wgpu/WGSL) that extends the built-in Spatial3DView with a GaussianSplats3D visualizer — no fork of Rerun required
Python module: Gaussians3D dataclass with PLY parser and Rerun logging, using tyro + simplecv RerunTyroConfig for CLI
7-stage GPU compute pipeline inspired by Brush: project → compact → map intersections → radix sort → tile offsets → tile raster → composite
No CUDA dependency — all GPU work uses wgpu (Vulkan/Metal backend)
What Changed
New package: packages/gsplat-rust-renderer/
src/ — 3 Rust source files (~5K lines) with thorough documentation comments
shader/ — 7 WGSL compute/render shaders with pipeline stage headers
gsplat_rust_renderer/ — Python module with jaxtyping annotations, beartype activation
tools/log_gaussian_ply.py — tyro CLI with RerunTyroConfig for flexible output modes
tests/ — 7 passing tests (import smoke + Gaussians3D unit tests)
docs/architecture.md — detailed internals (per-frame pipeline, GPU stages, component contract, buffer management)
README.md — usage-focused with badges, quick start, task tables, Python API example
Monorepo integration
pixi.toml — new gsplat-rust-renderer feature with Rust 1.93 toolchain, clang, cmake, X11/Wayland libs, tyro, simplecv; 6 tasks; prod + dev environments with own solve-group
pyrefly.toml — project-includes, search-path, site-package-path entries
.gitignore — target/ and examples/*.ply for the new package
Key Design Decisions
Self-contained feature: Does not pull in common or cuda features — has its own deps (rust, clang, cmake, numpy, tyro, simplecv, plyfile, rerun-sdk) to keep the solve-group small and fast
Two-process model: Rust viewer runs as a standalone native window, Python sends data over gRPC — keeps the render loop free from GIL contention
Cloud caching: Visualizer caches RenderGaussianCloud per entity path, keyed by splat count + SH shape + transform signature — only rebuilds when data changes
SH evaluation on GPU: Spherical harmonics up to degree 4 (25 coefficients/channel) evaluated per-splat in the projection shader
Usage
```
# Terminal 1: Launch the viewer
pixi run --frozen -e gsplat-rust-renderer viewer

# Terminal 2: Log example chair PLY
pixi run --frozen -e gsplat-rust-renderer log-ply

# Log your own PLY
pixi run --frozen -e gsplat-rust-renderer -- python tools/log_gaussian_ply.py \
    --rr-config.connect --ply-path /path/to/scene.ply
```
