Download the Processed DVM Dataset:
You can obtain the processed DVM dataset by visiting the following link:
Processed DVM Dataset
Download the Original DVM Dataset: Ensure that you also download the original DVM dataset.
File Tree Structure: Organize the datasets in the following directory structure:
```
/data/
|-- car_studio
|   |-- dv.json
|   |-- mask
|   `-- patch
`-- dvm
    `-- resized_DVM
```
Ensure that the downloaded files are placed in the correct folders as indicated.
