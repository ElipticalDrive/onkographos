🧠 Overview
This PR introduces EldritchEclipse, a 2D signed distance field (SDF) raymarching engine with volumetric light accumulation. Procedural monoliths cast dynamic shadows and god rays through adaptive ray stepping and multi-pass light blending.
The system simulates atmospheric scattering and real-time interactive lighting.
Closes #3968
✨ Key Technical Features
Signed Distance Field Definitions: Procedural shape distance functions.
Adaptive Raymarching: Minimum-distance step heuristic.
Surface Intersection Detection: Threshold-based hit detection.
Shadow Ray Casting: Secondary rays for occlusion testing.
Volumetric Light Accumulation: Multi-pass intensity buffer.
Atmospheric Scattering Effect: Layered glow blending.
Interactive Light Control: Real-time position adjustment.
🛠️ Tech Stack
Frontend: HTML5, CSS3
Rendering Engine: Vanilla JavaScript
Graphics API: HTML5 Canvas
🕹️ How to Test
Navigate to /projects/EldritchEclipse/index.html.
Move light source interactively.
Observe raymarching shadows.
Enable volumetric accumulation.
Stress test with multiple SDF shapes.
