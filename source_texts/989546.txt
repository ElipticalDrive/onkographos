💡 What: Replaced nested Python loops in boundary filtering with vectorized NumPy slice assignments and replaced `np.linalg.norm` with squared distance comparisons for depth filtering in `vggt_comfy_nodes.py`.
🎯 Why: Iterative Python loops and redundant square root operations are significant bottlenecks when processing large point clouds in ComfyUI batch inference.
📊 Impact: Expected speedup of ~3.5x for boundary filtering and ~4.8x for depth filtering, significantly reducing latency for multi-frame point cloud generation.
🔬 Measurement: Verified with standalone benchmarks and confirmed no regressions with the full test suite (34 passing).

Pull request overview
Improves performance of point-cloud filtering in the ComfyUI VGGT inference node by replacing Python-loop-based boundary masking with vectorized NumPy slicing, and by replacing np.linalg.norm depth checks with squared-distance thresholding.
Changes:
Replaced np.linalg.norm(... ) <= max_depth with x²+y²+z² <= max_depth² for faster max-depth filtering.
Reimplemented boundary filtering via reshape(S,H,W) + slice assignments to avoid nested Python loops.
Documented the optimization learnings in .jules/bolt.md.
