Motivation
Introduce a new hand-shaped, stylised point-cloud effect that uses a signed-distance-field (SDF) iso-surface sampler so the cloud forms a recognisable open hand while matching the existing sphere-cloud visual style.
Description
Add src/renderer/effects/handSdfCloudEffect.ts which implements a compact SDF hand model (rounded palm, thenar mound, four finger capsules, angled thumb), a deterministic lattice-based iso-surface sampler buildHandCloudPoints(), normal estimation via finite differences, and a Canvas2D renderer that reuses precomputed points and normals and supports speed, scale, density, and gesture params.
Register the effect under the key handcloud in src/renderer/effects/index.ts and add the effect entry to the README Effect catalog (README.md) so timelines can select it.
Add unit tests src/renderer/effects/handSdfCloudEffect.test.ts that verify deterministic point generation, bounds containment, and normals magnitude.
Implementation notes: model bounds [-1.8..1.2] x [-0.9..2.2] x [-0.9..0.9], grid 48x56x40, iso threshold ~0.041, and precomputes ~10k points at default density to keep runtime rendering fast.
Testing
Ran the test suite with npm run test (Vitest); all tests passed including the new buildHandCloudPoints tests — total 75 tests passed across the suite.
The new effect tests exercise determinism, bounds, and normal quality and completed successfully.
