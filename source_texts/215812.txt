Summary
HeightMap and Octree already have a tree structure, but some of their queries fell back to the generic Shape versions, which loop over every mesh triangle. This PR implements those queries on the trees and fixes the bugs found along the way.
HeightMap
contains and intersect(point, radius) now descend the quad tree.
Correctness: the generic sphere query missed spheres just below the ground that touch an occupied cell, because a height-map mesh has no bottom faces.
Memory leak: HeightMapNode's destructor was = default, so child nodes were never deleted. valgrind on master: 2.4 KB lost for two small height maps. Now 0.
Double free: HeightMap (and HeightMapNode) had a custom copy constructor, but the implicit copy assignment only copied the root_ pointer. Both now have a deep-copy assignment operator.
The Shape::intersect overloads were hidden by HeightMap::intersect(Ray), so hmap.intersect(p, r) did not compile. Added using Shape::intersect.
Octree
intersect(point, radius) now descends the tree and tests each child cube against the sphere. Before, it built a mesh of all cubes (12 triangles each) and looped over every triangle.
Correctness: getBoundingBox() came from Shape, which caches it and never invalidates the cache, so it was stale after add/clear/raytrace. It is now computed from the tree and cached, and every change to the tree clears the cache together with the mesh.

- Octree had a copy constructor, but the implicit (shallow) copy
  assignment: both octrees shared and deleted the same tree, and its nodes
  referred to the source octree. Implement a deep copy assignment, and
  delete the (shallow) copy operations of OctreeNode, which can only be
  copied for a tree.
- OctreeNode::contains passed the point unchanged to the child nodes,
  while the children use coordinates relative to their own corner (as in
  add). Octree::contains was wrong for any tree deeper than one level.
- HeightMap::operator=: own the copied tree by a unique_ptr, so it is not
  leaked when copying the shape throws.
- HeightMapNode::operator=: copy the box before cloning the children, so
  the clones are not leaked when copying the box throws.
- Remove the redundant mesh copy in the HeightMap copy constructor and the
  redundant cache invalidation in Octree::raytrace.
