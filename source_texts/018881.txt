Transfer function design is one of the most important procedures in volume rendering. Transfer function maps, which is a function mapping relationship, data values to display attributes, such as color and opacity. This chapter introduces region growing- based multi-dimensional transfer function design method, which can improve the effect of the multi-dimensional transfer function design, and help the users save the time used in the interactive design and decrease the difficult. In order to use the spatial information as independent variable, we combine spatial information to generate multi-dimensional transfer function. This chapter discusses the GPU-based transfer function lookup method and illumination parameter setting problems.
