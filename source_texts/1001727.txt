s_dicom_sorting was static in dicom_internal.h, which gave each file its own copy: dicom_sort set the one in dicom_parse.c and dicom_order_slices read the one in dicom_decimal.c, which is NULL, and every series of more than one slice faulted in qsort. engine_ingest_set no longer drops the zip archive's index when a set ends. The index is replaced when another archive opens, and zip_resident_release still drops it, which makes a call of one series cost one ingest and not a re-read of the central directory.
