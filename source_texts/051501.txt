Query adjacent chunks when culling edge faces
generate_mesh only checks neighbors via chunk.get_voxel_safe, which returns 0 for any out-of-bounds lookup, so every solid voxel on a chunk edge is treated as exposed even when the adjacent chunk has a solid voxel at the same world position. With the new 3x3 chunk generation in State::new, this guarantees seam-internal faces are emitted twice across chunk borders, substantially inflating vertex/index counts and GPU overdraw as world size grows.
