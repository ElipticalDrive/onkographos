Intent
Advance HAIZ toward cinematic, believable spatial scenes with measured graphics headroom, not a decorative particle pile or any copied Dream Road resources.
Implemented
Static box batching based on actual Three.js r128 BoxGeometry topology and world matrices; grouping only opaque meshes with shared material/shadow/render ordering, preserving all authored material maps and scene geometry. Separately instanced ground-contact shading uses one original radial-alpha texture for the desk group.
Upgrade outside foliage from primitive solid tree blobs to locally sourced HAIZ tropical-leaf transparency atlas in crossed planar InstancedMesh clusters, respecting low / balanced / high budgets.
Fix flaky Android API 33 CDP Page.captureScreenshot by taking actual device-composited PNG snapshots via adb exec-out screencap -p, validating signature and size; all WebView interaction, offline and private-note persistence assertions remain in CDP.
Require the new script in native packaging manifest and assert performance diagnostics in an actual browser test.
Provide a design/measurement report at docs/haiz-design/IMMERSIVE-ROOM-V2-MATERIAL-AND-GPU-20261025.md.
Measured evidence (real Linux Chromium WebGL, software renderer)
At the same fixed camera:
Desktop: 352 → 102 draw calls, ~71% fewer.
Phone viewport: 166 → 58 draw calls, ~65% fewer.
292 static opaque meshes become 16 instancing groups; 276 theoretical mesh-submission savings.
CI for statically batched geometry: successful run 40164475244.
Leaf-atlas variant: successful run 40164548971, including desktop and mobile screenshots.
These values are draw calls, not measured FPS, and not evidence of equivalence with Dream Road's Unity visual fidelity.
Release gates
WebGL fidelity/performance test passes in desktop + mobile viewport.
Android API33/API35 and iOS native matrix must pass on this PR.
Review screenshot lighting and foliage in fixed reference frames.
Real vivo S10 cold start/thermals/fps memory checks and iOS device checks when available.
Proven authored modular models / baked indirect light for actual commercial-grade art quality.
Draft. This PR targets PR #14's unmerged feat/immersive-classroom-20261025, not main. Never copy or redistribute proprietary Dream Road assets, code or audio. No deployment or release made.
