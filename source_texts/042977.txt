# Volume4D Viewer - interactive 4D volume visualization

**Developer:** [Jonathon Brunson](https://github.com/jonathonb21) | [jonathonbrunson21@gmail.com](mailto:jonathonbrunson21@gmail.com)

WebGPU/Rust-backed viewer I built for space + time volumetric data. Includes a Python API, Jupyter inline viewer, and WASM build for browser-based exploration.

## Install

```bash
pip install vape4d
```

## Viewer (Jupyter)

```python
from vape4d import viewer
import numpy as np
from matplotlib import pyplot as plt
viewer(np.random.rand(1, 1, 32, 32, 32), plt.get_cmap("viridis"))
```
