Summary
OpenAzrael Texture Lab RT-POC-01 provides a repository-safe, reproducible texture-remaster experiment pipeline without changing gameplay, room geometry, UVs, collision or KG-001 semantics.
The branch is synchronized with current mainline context v116-context-v28. Localization remains ADR-024; mainline Candidate bug reporting is ADR-025; Texture Lab is ADR-026.
Presentation tiers
Classic — immutable decoded source-reference pixels
Enhanced — deterministic mathematical reconstruction
AI Restored — constrained learned restoration/upscale
AI Recreated — image-conditioned generative reconstruction
Generated pixels remain outside normal Git history.
Source-safe / deterministic foundation
86 Classic PNG corpus confirmed
canonical 12-texture R1/R7/R8 POC
deterministic 4x nearest / bicubic / Lanczos generation
source-safe Pillow toolchain pinned to Pillow==12.3.0
mathematical bake-off and drift calibration refuse an unpinned Pillow version
alpha-safe legacy-magenta handling with exact binary mask lock
hidden RGB normalization below fully transparent pixels
technical validation: dimensions, alpha/color-key safety, round-trip metrics, seam metrics
structural-drift QA: low-frequency layout, edge map, alpha silhouette
deterministic drift baseline kept as observational calibration evidence
local AI preflight intentionally requires a fresh schema-v2 recalibration under the pinned Pillow toolchain before real AI execution
AI Restored contract
Real-ESRGAN v0.3.0 exact upstream commit pinned
RealESRGAN_x4plus exact checkpoint size/SHA-256 pinned
isolated Python environment supported
runtime doctor verifies source commit, checkpoint identity and Python dependencies
restore adapter re-verifies registered runtime identity immediately before inference
AI Restored eligibility: 11/12; KEYHOLE# remains deterministic Enhanced/nearest
AI Recreated contract
canonical Qwen-Image-Edit-2511 single-image ComfyUI API workflow
fixed seed 734234, 40 steps, CFG 4, Euler/simple, no Lightning LoRA
exact diffusion/text-encoder/VAE filenames, sizes and SHA-256 identities pinned
resumable Qwen model bootstrap installs only pinned HTTPS sources, verifies size/SHA-256 before finalizing files, and never silently overwrites an invalid final model
ComfyUI doctor verifies required runtime node classes/input schemas
Qwen preflight verifies workflow topology, bindings, sampling and model hashes
positive/negative conditioning separated
model is conditioned on the deterministic 4x Enhanced canvas while Classic remains structural/alpha truth
AI Recreated eligibility: 10/12; KEYHOLE# and SHIELD1 excluded
Atlas / special-asset handling
BAPFLOR#: exact alpha lock + U/V seam review
WEL_PUZ1: puzzle-geometry review
BAPTAP: measured R8 UV evidence shows four ordered horizontal atlas quarters
BAPTAP Recreated path is split -> four isolated Qwen jobs -> exact stitch -> full-atlas QA
split/stitch pixel identity is unit-tested before AI is involved
Staged execution gates
Named presets:
restored_smoke_1 -> restored_smoke_4 -> restored_full
recreated_smoke_1 -> recreated_smoke_4 -> recreated_atlas -> recreated_full
Each named run has an isolated evidence directory under .local/texture_lab/runs/rt_poc_01/<preset>/.
A staged run executes:
prerequisite manual-approval gate
pinned-toolchain/local disk/input/hardware preflight
backend doctor / model preflight
generation
hard technical QA
structural-drift QA
stage-scoped manual review queue
fingerprinted visual review pack with per-texture full/detail/alpha comparison evidence and 3x3 repeat-sampling seam previews
Approval receipts are explicitly manual and fingerprint the current plan, local/runtime preflights, technical report, structural report, generation/job records, review queue, generated output hashes and the exact visual-review pack used for inspection. Changed evidence makes an old receipt stale. Approval only unlocks the next experiment stage; it never promotes a texture to production.
Repository safety
Classic commercial-derived pixels, generated Enhanced/AI pixels, model weights, local runtimes, screenshots and transient run evidence remain outside normal Git history. Git contains tooling, policy, workflow metadata, compact reviewed evidence and tests.

an existing real run is refused by default; --replace-existing-run is the explicit clean-rerun opt-in
dry-runs never clear stage evidence or generated candidates
QA/provenance linkage
technical QA schema v5 records Classic source SHA-256 plus candidate SHA-256
structural QA schema v2 is stage-scoped and records the same source/candidate hashes
stage gate verifies technical/structural/review schemas, exact preset IDs, variants and hash linkage to the visual review pack

Recreated job records must match pinned Qwen workflow/model/seed, canonical positive/negative prompts, submitted workflow bindings, conditioning/source/output hashes

Production registry / export hardening
