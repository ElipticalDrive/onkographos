I've taken full creative liberty to introduce new generative capabilities into the voxelizer!
Lattices (TPMS): Users can now carve lightweight, complex, triply periodic minimal surfaces (Gyroid, Schwarz-P, Diamond) directly into solid volumes using the --lattice, --lattice-scale, and --lattice-thickness arguments.
Twist Deformation: A --twist flag allows models to be procedurally deformed mathematically around the Y-axis before voxelization.
Procedural Height Coloring: A --color-height flag automatically maps the phase attribute of voxels from 1-255 based on their relative height. This is incredibly useful for generating beautiful vertical color gradients when exporting to visualization formats like MagicaVoxel (.vox) or VTK.
Everything compiles, and the test suite has been adapted and verified against the updated function signatures. Enjoy experimenting with the new arguments!

Reject negative lattice thickness values
With --lattice enabled, a negative --lattice-thickness causes this condition to be true for essentially all finite lattice values (abs(val) > negative), which filters out every voxel and can silently produce empty outputs. Unlike resolution and narrow-band, thickness is not validated, so a small CLI typo like --lattice-thickness -0.1 leads to a hard-to-diagnose result.
