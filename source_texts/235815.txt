Context
Currently camera::cast(image::point const& p) generates a single ray from a pinhole camera model. There's no support for spherical/equirectangular (lat/long) or cube map projections.
Goal
Support rendering into 360° spherical images, useful for environment maps, VR content, and skybox generation. The output image maps longitude to X (0..width) and latitude to Y (0..height), covering the full sphere.
Suggested Approach
Add a Projection enum to the camera class:
```
enum class Projection { Perspective, Equirectangular, CubeMap };
```
The cast() method would branch on the projection type:
Perspective: current pinhole model (unchanged)
Equirectangular: map raster X→longitude (0..2π) and Y→latitude (-π/2..+π/2), then compute the world-space ray direction
CubeMap: render 6 faces separately and assemble
Equirectangular rays from (x,y):
```
lon = 2π * x / width
lat = π * y / height - π/2
dir = (cos(lat)*sin(lon), sin(lat), cos(lat)*cos(lon))
```
The camera constructor or a setter could accept the projection type and any additional parameters (e.g., spherical coverage angle).
