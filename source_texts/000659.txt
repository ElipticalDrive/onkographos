A high-performance, GPU-accelerated implementation of the Amanatides & Woo 3D Voxel Traversal Algorithm. Written in pure Python using Numba (CUDA), this library allows for extremely fast ray-voxel intersection calculations without the need for C++ compilation. It is designed for LiDAR processing, ray tracing simulations, and volumetric analysis.
