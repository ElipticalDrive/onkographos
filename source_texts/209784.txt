❓ Questions about pytorch3d.structures.Pointclouds
In Pytorch3d document, It looks to be input hyperparameter 'points'(verts) should be 3 channel(x,y,z coordinate).
But, I would like to use the coordinates that apply positional encoding to verts(coordinate) as used in NeRF.(More than 3 channel)
Is there a way to apply positional encoding in xyz coordinate and input to a PointClouds?

The Pointclouds object is designed for points is 3D with literal locations. It doesn't support positional encoded locations. What functionality of the Pointclouds object do you want to use?
(If you are actually looking at NeRF type models the the starting point in PyTorch3D is implicitron and it has RayBundle classes.)
