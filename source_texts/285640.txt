This patch implements significant improvements to the voxel engine across multiple files:
Meshing (src/mesher.rs): Replaced the placeholder mesher with a proper face-culling algorithm. It iterates over the 6 adjacent neighbors of each voxel, only generating faces when adjacent to empty or transparent blocks, vastly improving rendering efficiency. Added proper Counter-Clockwise (CCW) winding order for the generated faces.
Terrain & State (src/state.rs): Replaced the static flat terrain generation with a dynamic sine-wave based height map, correctly placing Grass (ID 2) at the surface and Dirt (ID 1) below. Extracted texture paths into a constant array TEXTURE_PATHS.
Initialization & Safety (src/main.rs): Removed the unused shader_loader module. Replaced hard panics (.unwrap()) during winit EventLoop and WindowBuilder initialization with safe match statements, logging errors gracefully.
Clean Up: Deleted unused legacy GLSL shader files (shaders/voxel.vert, shaders/voxel.frag) and the dummy src/shader_loader.rs file.
Testing (src/chunk.rs, src/mesher.rs): Added unit test test_voxel_indexing to verify the flat array 1D index calculations and boundary conditions in Chunk logic. Added unit test test_neighbor_culling to verify the new mesher correctly culls internal faces between adjacent blocks.
Maintenance: Suppressed compiler warnings for unused fields designed for future use (position in Chunk, texture in Texture) via #[allow(dead_code)]. Added target/ to .gitignore.
