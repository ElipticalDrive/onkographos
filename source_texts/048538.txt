# Direct Volume Rendering (DVR) System

DVR is a lightweight, C++17-based volume rendering application. It uses a custom software-based raycasting engine to integrate volume data along rays and render it. The system provides multiple transfer functions for varied visualizations and uses OpenGL/GLFW with Dear ImGui for its user interface.

## Features
- **Software Raycasting Engine**: Performant trilinear interpolation and ray-sphere intersection.
- **Transfer Functions**: Several built-in colormaps (Greyscale, Structural, Heat Scatter, Density Distribution, Viridis).
- **Math Utilities**: Built-in simple 3D math library (`math3d.h`) for vector operations.
- **Testing Suite**: Comprehensive unit testing utilizing GoogleTest to validate core logic, convergence (RMSE), and data boundaries.
- **Screenshot Utility**: Capture rendering frames straight from the buffer to an image utilizing `stb_image_write`.

## Project Structure
```text
DVR/
├── CMakeLists.txt        # CMake build configuration
├── src/
│   └── main.cpp          # Application entry point & ImGui interface
├── include/              # Core logic headers
│   ├── math3d.h          # 3D vector operations
│   ├── renderer.h        # Volume raycasting engine 
│   ├── screenshot.h      # stb_image PNG export
│   ├── transfer.h        # Transfer functions and RGBA lookup
│   └── volume.h          # Volume data structures and sampling
├── tests/                # GoogleTest suite
│   ├── test_math3d.cpp   # Validation of math functions
│   ├── test_renderer.cpp # Verification of rendering & RMSE
│   ├── test_transfer.cpp # Validation of transfer bounds & lookups
│   └── test_volume.cpp   # Validation of 3D data volumes
└── screenshots/          # Output folder for generated visual results
```

## Dependencies
The project pulls most dependencies automatically, but requires some foundational tools:
- **C++17 Compiler** (Clang/GCC/MSVC)
- **CMake** (3.20+)
- **OpenGL/GLFW**
- ImGui & GLAD (Included in the `external` directory)
- GoogleTest (Automatically fetched by CMake)

## Build Instructions

1. **Clone or navigate** to the project directory:
   ```bash
   cd /path/to/DVR
   ```
2. **Configure the project** with CMake:
   ```bash
   cmake -S . -B cmake-build-debug
   ```
3. **Build the Main Executable**:
   ```bash
   cmake --build cmake-build-debug --target dvr
   ```
4. **Run the Application**:
   ```bash
   ./cmake-build-debug/dvr
   ```

## Running the Tests

A dedicated test suite `dvr_tests` validates the individual components of the system to ensure correct execution. The tests include an RMSE convergence check which outputs screenshot files inside the `/screenshots` directory.

1. **Build the Tests**:
   ```bash
   cmake --build cmake-build-debug --target dvr_tests
   ```
2. **Run CMake Test Suite**:
   ```bash
   cd cmake-build-debug && ctest -V
   # OR run directly:
   ./cmake-build-debug/dvr_tests
   ```
