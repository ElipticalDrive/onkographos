You can simply use the following code:
```
pred_volume = ...

with open('/tmp/%s.binvox' % model_id, 'wb') as f:
    vox = binvox_rw.Voxels(pred_volume.cpu().numpy(), (32,) * 3, (0,) * 3, 1, 'xyz')
    vox.write(f)
```
