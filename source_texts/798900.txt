My take on a chunk based procedural generation system.
Hello, please note that I am a beginner. I'm quite aware there are many way's to optimise what I'm doing here :) At this stage its bare basics to getting the generation functional. Tweaking will be done, flexibility will be increased and added!
Here is what I've come up with
Procedural Chunk generation:
Idea is to split all dungeons up into a grid with a fixed X and Y amount. In this example i'm using 6x6 which is 36 chunks. I'm using 10x10 cubes, but eventually these will be replaced with models.
Each chunk has a chunk type. Each level has a list of chunk types, and the amounts that can be spawned. For example, two chunk types would be "Enemy" and "Treasure". You would create/model/script multiple chunks for each chunk type.

How it works
Okay so I've created it quite simple. I've created a Level, which comprises of a list of ChunkTypes and their amounts. Once you press space bar, it calls createLevel.
CreateLevel will go trough and use a random number to determine which chunktype to render. Once the chunk type is determined, it will grab a chunk of that type. There are multiple chunks per type, as seen in the image by the different shades of color.
Once the chunk is found, it is instantiated at the spawn position. Since i'm dealing with 10x10 cubes, i'm cheating and setting the next spawn position -10 units over on the x axis.
I've got another cheater if statement, that will move the spawn point -10 on the z axis every 6 (6x6gid) passes through the loop. This needs fixing but works for now.
I then continue to loop for the duration of the grid count (6x6 grid = 36 loops). The black and white determine the start and end points.
Once I have this working, flexible and in place, it's just a matter of modelling up 21+ chunks under a theme :)
Need to improve
I'm sure there is a better way of doing this, but currently, i'm linking all of my chunk's as prefabs to a chunk manager. As the game grows, this chunk manager would contain a lot of links to game objects. It would work, but would be incredibly frustrating if I lost all of the links or something silly.
I can't quite think of a better way to do this, besides maybe using object pooling or loading the prefabs directly from a resource folder. Any ideas is appreciated.
