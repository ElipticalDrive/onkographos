Parent: #6
Depends on: #9
Objective
Create the shared data boundary used by NeRF, later NeRF variants, and native 3DGS without forcing method-specific batching or rendering into the dataset layer.
Scope
Add typed Camera, SceneMetadata, SceneObservation, RayBundle, and RenderOutput values.
Document shape, dtype, device, value range, batching, and coordinate convention for every public tensor.
Separate Blender image/camera loading from ray generation and training-ray sampling.
Move alpha compositing and scene normalization into explicit transforms.
Generate only selected NeRF rays during training instead of materializing every image ray before sampling.
Preserve full-image validation and evaluation observations.
Add deterministic scene fingerprints and split metadata.
Non-goals
General-purpose universal renderer abstraction.
NeRF component extraction.
3DGS rasterization or Gaussian initialization.
Shared trainer implementation.
Required tests
Camera construction and validation.
OpenGL camera convention and projection.
Blender-format fixture loading.
Background compositing and scene transform behavior.
Exact aligned ray sampling, replacement, and deterministic generator behavior.
Phase 0 numerical regression compatibility.
Acceptance criteria
Dataset adapters return observations and cameras, not method-owned ray batches.
NeRF ray preparation consumes the shared observation contract.
Full-image methods can consume the same observation without a RayBundle.
Public tensor contracts are documented and validated.
Training no longer constructs unused full-image ray tensors.
Phase 0 regression stays within tolerance.
