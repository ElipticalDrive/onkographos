Dataset Definition
1. Dataset Format
The project will use volumetric datasets in the NRRD format.
NRRD files will represent the three-dimensional matrix used as the input to the projection algorithm.
2. Primary Dataset
The primary dataset will be an MRI NRRD dataset from the open-source 3D Slicer project, as recommended by the assignment.
The exact NRRD file selected for the project will be recorded in the project documentation once selected.
3. Dataset Information to Record
For every selected NRRD dataset, the project documentation should record:
Filename
Source
Matrix dimensions
Data type
Number of voxels
Any relevant metadata needed to reproduce the experiment
4. Test Dataset Categories
The testing strategy should use datasets that allow the algorithm to be tested under different conditions.
Dataset A — Primary MRI Dataset
The main real-world NRRD dataset used for the demonstration.
Purpose:
Demonstrate the complete system.
Test realistic volumetric data.
Generate the final demonstration output.
Dataset B — Small Dataset
A smaller NRRD dataset or controlled test volume.
Purpose:
Make manual verification easier.
Test correctness of individual projections.
Debug boundary and coordinate handling.
Dataset C — Performance Dataset
A dataset suitable for performance measurements, including a volume corresponding to the assignment's large-volume performance target.
Purpose:
Measure projection speed.
Evaluate whether the implementation meets the required FPS target.
5. Plane Test Cases
The datasets will be tested using multiple plane configurations, including:
A plane located well inside the volume.
A plane near a volume boundary.
A plane that causes some sampled points to lie outside the volume.
Different plane orientations.
Three-point plane definitions.
Four-point plane definitions.
6. Reproducibility
The final project documentation will record the exact dataset files used for the final experiment so that the experiment can be reproduced.
