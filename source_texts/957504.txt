Problem Statement
Rendering large datasets in the browser can cause performance issues or hit WebAssembly memory limits. Currently, there is no mechanism to split large data into smaller chunks and render them incrementally.
Proposed Solution
Add a chunked/streamed rendering pipeline that:
Splits large meshes into manageable chunks
Renders chunks incrementally (e.g., via progressive loading or LOD)
Avoids Wasm memory exhaustion with very large datasets
Alternatives Considered
Loading the full dataset at once and relying on Wasm memory limits to handle it (fails for very large data)
Server-side downsampling before sending to WASM (loses fidelity)
Example Usage
```
import pyvista_wasm as pv

mesh = pv.load_large_mesh("big.vtk")
renderer.render_chunked(mesh, chunk_size=10000)
```
PyVista Comparison
PyVista handles large datasets natively via VTK's streaming and LOD capabilities. This feature would bring a browser-compatible subset to pyvista-wasm.
