What does this PR do?
Adds an immersive, highly sophisticated procedural generation studio titled Perlin Noise Terrain Sandbox under Projects/Perlin Noise Terrain Sandbox/. Moving away from external physics or generation packages, the application constructs a native, multi-octave 2D Perlin noise engine linked directly to low-level canvas pixel data array buffers (putImageData). It implements fractal Brownian motion synthesis using quintic fading splines, integrates an automatic radial gradient attenuation masking algorithm to shape organic island geographies, processes real-time parameter modulation slider lines (sea levels, peak altitude coefficients, lacunarity weights), exposes active terrain telemetry indices, maps zero-refresh procedural regeneration loops, and ships a native image asset exporter.
