Motivation
Deliver Ticket 5 from the unified executable plan to allow one invocation of biomesh to export both occupied and empty meshes after a single preprocessing pass.
Prevent accidental overwrites by requiring explicit distinct output targets for both-mode and performing robust path collision checks.
Description
Added both-mode orchestration to examples/biomesh.cpp so --mesh both runs occupied and empty mesh generation sequentially against the same VoxelGrid (preprocessing executed once).
Introduced exportAndReport(...) helper to centralize reporting, efficiency calculation, large-mesh warnings, and export invocation (MeshExporter::exportMesh).
Enforced dual-output argument rules and collision detection by canonicalizing paths with std::filesystem::weakly_canonical(...).lexically_normal() and rejecting identical resolved paths.
Preserved existing numeric and enum validation (voxel_size, padding, inflate-factor, --format) and extended argument validation to forbid/require --output, --occupied-output, and --empty-output per the CLI contract in docs/biomesh_cli_contract.md.
Testing
Built the project successfully with cmake -S . -B build && cmake --build build --target biomesh -j4 (succeeded).
Ran ./build/biomesh data/test_peptide.pdb 2.0 --mesh both --occupied-output /tmp/occ.msh --empty-output /tmp/emp.msh --format gid and observed successful generation and export of both meshes to the specified files (succeeded).
