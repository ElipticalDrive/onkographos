The need for developing effective coding techniques for various multimedia services is increasing in order to meet the demand for image and video data. In this paper, a block-zero tree coding (BZTC) algorithm is proposed for multilayer coding and progressive transmission of images. The BZTC algorithm is constructed as an embedded coding so that the encoding and decoding process can be terminated at any point and allowing reasonable image quality. Some features of our BZTC algorithm are (1) prediction of the significance of blocks across scale, (2) state transition rules for representing the significance block map, and (3) block coding by vector quantization using a multiband codebook consisting of several subcodebooks dedicated for each band at a given threshold.
