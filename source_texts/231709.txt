Last big item for 1.7.0 release. Still work in progress. Based on https://github.com/quadjr/aframe-gaussian-splatting implementation
I adapted style, made a few minor tweaks and commented thoroughly. I still don't fully understand some of the details. Good opportunity to deepen understanding of 3D gaussian splats for those interested. Before merge we should thoroughly understand the code and optimize.
I recommend getting acquainted with the original paper: https://arxiv.org/pdf/2308.04079
In the code comments you'll see references to other relevant literature.
In VR on a Quest 3 when the sample splat is fully loaded (~1.1M splats rendered) I get ~14fps.
Quick overview:
As output of the training process splats are represented as ellipsoids with a position, scale, color and shape that are later projected to 2D ellipses to be renderer on screen
Each splat is rendered as a quad with a color that gets positioned, scaled and shaped following each ellipse characteristics.
Splats are sorted in a worker. Splats are instances and we have to sort them out to render them in the correct order (back to front)
Current implementation doesn't support spherical harmonics. Color of splats varies depending of point of view vs a fixed color.
Add 3D gaussian splats support

Wheel far from invented. Stuff evolving quick.
On the training, compression, rendering and sorting side there's plenty to experiment with. But this is about making it a core component of A-Frame. From the perspective of the user the relevance is being able to add "splats" to their scene. People will expect to be able to use the output of tools like SuperSplat and Scaniverse and have it perform comparable as well.
In other words, we'd end up implementing loading of compressed .PLY files, .SPZ files, supporting the spherical harmonics for view dependent lighting and implementing the sorting in WASM using SharedArrayBuffer, progressive loading, perhaps even 2DGS support. All things that have been done numerous times.
For experimenting, the core isn't the right place IMO. And for providing a component for users, we'd end up implementing (and maintaining!) a lot of features. I agree with @koktavy that wrapping mkkellogg/GaussianSplats3D is a better path to stay up to date. We can always contribute upstream if we do find improvements.
mkkellogg performance is ~24fps on Quest 3 on the simple demo scene. Playcanvas ~17fps (similar to ours) on the same truck splat on this PR's example.
Both of those render at full resolution. I'm not able to reproduce ~17fps using the component in this PR when setting the xrPixelRatio to 1.0, so there's quite a bit of catching-up to do. Ideally there'd be an apples-to-apples comparison with various implementations all rendering the same scene under the same conditions.
Scenes from Into the Scaniverse are the only ones I've seen decently performing on Quest 3 (~72fps). Presumably cherry picked.
Not sure if they really cherry pick them, as they do allow users to create their own and post them on the map. From what I gather they do a lot of pre-processing. One thing I have noticed is that the background is actually static despite the Gaussian Splat appearance. This presumably helps quite a bit as it saves on the number of splats as well as reduces overdraw caused by large splats in the background.
We can render at 90fps on Quest3 up to ~150k splats.
Splats don't have a fixed cost associated with them. They vary in size and spatial distribution. Overdraw really kills performance AFAICT, so ~150k splats representing a "full scene" or ~150k focussed on a single object will likely perform wildly different.

If you want to experiment with https://github.com/mkkellogg/GaussianSplats3D here is the component I did today.
I can't put that on glitch, gtlich doesn't support setting the headers as far as I know so you will get the error
Uncaught (in promise) DataCloneError: Failed to execute 'postMessage' on 'DedicatedWorkerGlobalScope': SharedArrayBuffer transfer requires self.crossOriginIsolated.
So here is the code:
in webpack.config.js add:
```
    headers: {
      'Cross-Origin-Embedder-Policy': 'require-corp',
      'Cross-Origin-Opener-Policy': 'same-origin',
    }
```
Run the repo with
```
npm run start:https
```
create examples/showcase/gaussian-splat/index.html
```
<html>
  <head>
     <script type="importmap">
      {
        "imports": {
          "@mkkellogg/gaussian-splats-3d": "https://cdn.jsdelivr.net/npm/@mkkellogg/gaussian-splats-3d@0.4.7/build/gaussian-splats-3d.module.js",
          "aframe": "https://cdn.jsdelivr.net/gh/aframevr/aframe@cd543c6cbf52c81f14ac0d3a41cb9a883047c7ac/dist/aframe-master.module.min.js",
          "three": "https://cdn.jsdelivr.net/npm/super-three@0.173.5/build/three.module.js",
          "three/addons/": "https://cdn.jsdelivr.net/npm/super-three@0.173.5/examples/jsm/"
        }
      }
    </script>
    <script type="module">
/**
 * @license MIT
 */
import AFRAME from "aframe";
import * as GaussianSplats3D from "@mkkellogg/gaussian-splats-3d";
AFRAME.registerComponent("kgaussiansplat", {
  schema: {
    src: { type: "string", default: "" },
    up: { type: "vec3", default: { x: 0, y: -1, z: 0 } },
    sphericalHarmonicsDegree: { type: "int", oneOf: [0, 1, 2], default: 0 },
    splatAlphaRemovalThreshold: { type: "int", min: 0, max: 255, default: 1 },
    sceneRevealMode: { type: "string", oneOf: ["Default", "Gradual", "Instant"], default: "Default" },
  },
  init() {
    this.defaultUp = new THREE.Vector3(0, 1, 0);
    this.viewer = new GaussianSplats3D.DropInViewer({
      sharedMemoryForWorkers: true, // better keep that to true and define the headers 'Cross-Origin-Embedder-Policy': 'require-corp', 'Cross-Origin-Opener-Policy': 'same-origin'
      dynamicScene: true, // if it is set to false, I don't see anything
      halfPrecisionCovariancesOnGPU: true,
      inMemoryCompressionLevel: 2, // for non ksplat files
      sceneRevealMode: GaussianSplats3D.SceneRevealMode[this.data.sceneRevealMode],
      sphericalHarmonicsDegree: this.data.sphericalHarmonicsDegree,
    });
    const showLoadingUI = false;
    this.viewer
      .addSplatScenes(
        [
          {
            path: this.data.src,
            splatAlphaRemovalThreshold: this.data.splatAlphaRemovalThreshold,
          },
        ],
        showLoadingUI
      )
      .then(() => {
        this.el.setObject3D("mesh", this.viewer);
      });
  },

  update(oldData) {
    if (
      (oldData.src !== undefined && oldData.src !== this.data.src) ||
      (oldData.splatAlphaRemovalThreshold !== undefined &&
        oldData.splatAlphaRemovalThreshold !== this.data.splatAlphaRemovalThreshold)
    ) {
      this.remove();
      this.init();
      return;
    }
    if (
      oldData.sphericalHarmonicsDegree !== undefined &&
      oldData.sphericalHarmonicsDegree !== this.data.sphericalHarmonicsDegree
    ) {
      this.viewer.setActiveSphericalHarmonicsDegrees(this.data.sphericalHarmonicsDegree);
    }

    // Calculate rotation from default up vector (0,1,0) to desired up vector
    if (!this.defaultUp.equals(this.data.up)) {
      if (this.data.up.x === 0 && this.data.up.y === -1 && this.data.up.z === 0) {
        this.el.object3D.rotation.set(0, Math.PI, Math.PI);
      } else {
        const targetUp = new THREE.Vector3().copy(this.data.up).normalize();
        const quaternion = new THREE.Quaternion();
        quaternion.setFromUnitVectors(targetUp, this.defaultUp);
        this.el.object3D.quaternion.copy(quaternion);
      }
    }
  },

  remove() {
    const mesh = this.el.getObject3D("mesh");
    if (mesh) {
      this.el.removeObject3D("mesh");
      mesh.dispose();
      // https://github.com/mkkellogg/GaussianSplats3D/blob/2dfc83e497bd76e558fe970c54464b17b5f5c689/src/DropInViewer.js#L118-L120
      // in v0.4.7 DropInViewer.dispose doesn't dispose those:
      mesh.callbackMesh.material.dispose();
      mesh.callbackMesh.geometry.dispose();
    }
    this.viewer = null;
  },
});
    </script>
  </head>
  <body>
    <a-scene
      background="color: #ffffff"
      renderer="antialias: false"
      inspector="url: https://cdn.jsdelivr.net/gh/c-frame/aframe-editor@1.7.x/dist/aframe-editor.min.js">
      <a-entity kgaussiansplat="src: jade_drums.ply; up: 0 -1 0; sphericalHarmonicsDegree: 0; splatAlphaRemovalThreshold: 20"></a-entity>
      <a-entity id="rig" position="0 0 2">
        <a-entity id="camera" position="0 1.6 0" camera look-controls wasd-controls></a-entity>
      </a-entity>
    </a-scene>
  </body>
</html>
```
Download https://github.com/gmix-tech/small_splats/blob/main/ply/jade_drums.ply or any ply, splat, ksplat, spz files and put it in the same directory and change the kgaussiansplat with the correct filename of course. You can enable the inspector to tweak the properties.
open https://localhost:8080/showcase/gaussian-splat/
