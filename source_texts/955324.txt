Description
This PR introduces a Pareto-optimal hybrid space-filling curve to the spatial point sorting engine. The implementation addresses the cache locality degradation associated with pure Morton (Z-order) sorting's discontinuous jumps, while mitigating the high instruction overhead inherent to pure Hilbert curve bitwise rotations.
The architecture employs a two-tier synthesis for 64-bit spatial keys:
Top-Level Partitioning: The upper 16 bits of the $(X, Y)$ coordinates are interleaved using Morton Z-order (_pdep_u64 via BMI2 when available). This clusters points into coarse spatial grid tiles at $O(1)$ hardware latency.
Intra-Tile Micro-Sorting: The lower 16 bits are mapped using a localized Hilbert curve to ensure continuous memory traversal within each tile, eliminating internal boundary discontinuities.
The resulting 64-bit keys are processed via a 4-pass 16-bit LSD Radix Sort, yielding strict $O(N)$ execution. The unified dispatch interface in algoat::sort is extended to support SpaceFillingCurve::Hybrid, defaulting to Morton to ensure zero backward compatibility breakage.

Implements a Pareto-optimal hybrid space-filling curve for spatial point
sorting that balances compute overhead and spatial cache locality.

- Top-Level Partitioning: Uses Morton (Z-order) bit-interleaving on the
  highest 16 bits of (X, Y) coordinates to cluster points into coarse
  spatial buckets efficiently.
- Intra-Tile Micro-Sorting: Employs a localized Hilbert curve on the
  lowest 16 bits of (X, Y) coordinates to enforce continuous memory
  traversal inside each tile, avoiding intra-tile discontinuities.

A 4-pass 16-bit LSD Radix sort processes the resulting 64-bit spatial
keys in linear time. The SpaceFillingCurve enum is exposed through the
unified dispatcher in algoat::sort, defaulting to Morton to preserve
backward compatibility.
