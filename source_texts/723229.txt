Problem / Request
xrtoolz.interpolate has regrid_like (xr.interp, not conservative), coarsen_conservative (integer factors only, cos-lat weights) and reproject_match (rioxarray; conservative only through rasterio's sum/average resampling, raster-only). There is no conservative regrid from one rectilinear grid to an arbitrary other rectilinear grid — the operation every flux / inventory / emission field needs so that basin totals are preserved. The design roadmap lists it ("v0.4+ — additional regridding methods (conservative approximation)").
User Story
As a user rasterising a 0.1° emission inventory onto a 1 km analysis grid (or coarsening model output onto a satellite grid), I want regrid_conservative(ds, target) to preserve the integral of every extensive field to floating-point precision, so that the regridded prior sums to the published basin total.
Motivation
plumax#81 (EDGAR / GFEI / EPA inventory prior) has "integrating the regridded fixture over a known basin matches the published total within 1 %" as its definition of done, and per the plumax xrtoolz boundary rule it will call xrtoolz for the regrid. reproject_match(resampling="sum") is the v1 stand-in; this issue is the proper primitive, also useful for coarsen_conservative's non-integer case and for the WRF-vs-ERA5 parity check.
Proposed API
```
# packages/xrtoolz/src/xrtoolz/interpolate/_src/grid_to_grid.py

def regrid_conservative(
    ds: xr.Dataset | xr.DataArray,
    target: xr.Dataset | xr.DataArray | Mapping[str, np.ndarray],
    *,
    dims: tuple[str, str] = ("lat", "lon"),
    geometry: Literal["spherical", "planar"] = "spherical",
    bounds: Mapping[str, xr.DataArray | np.ndarray] | None = None,
    target_bounds: Mapping[str, xr.DataArray | np.ndarray] | None = None,
    mode: Literal["mean", "sum"] = "mean",
    normalize: Literal["destarea", "fracarea"] = "fracarea",
    skipna: bool = True,
) -> xr.Dataset | xr.DataArray:
    """First-order conservative regrid along two rectilinear dims.

    ``mode="mean"`` preserves intensive fields (concentration, mixing ratio):
    ``out = Σ_ij w_ij f_ij / Σ_ij w_ij``. ``mode="sum"`` preserves extensive
    fields (mass, flux × area): ``out = Σ_ij w_ij f_ij``. ``w_ij`` is the
    overlap area between source cell ``i`` and target cell ``j``; on a
    ``"spherical"`` geometry areas are ``R² Δλ (sin φ₊ − sin φ₋)``, on
    ``"planar"`` they are ``Δx Δy``. Cell bounds default to midpoints between
    centres (CF ``bounds`` variables used when present or passed explicitly).
    ``normalize="fracarea"`` renormalises by the *valid* (non-NaN) overlap so
    partially masked targets keep the mean of their valid part;
    ``"destarea"`` divides by the full target area (ESMF/xESMF naming).
    """

def overlap_weights_1d(
    src_bounds: Float[np.ndarray, "n+1"], tgt_bounds: Float[np.ndarray, "m+1"]
) -> Float[np.ndarray, "m n"]:
    """Length (or sin-lat) overlap of each source interval with each target interval."""
```

Design Snapshot
Separable weight construction — the whole algorithm for rectilinear grids:
```
W_lat = overlap_weights_1d(sin(src_lat_bounds), sin(tgt_lat_bounds))   # (m_lat, n_lat), spherical
W_lon = overlap_weights_1d(src_lon_bounds, tgt_lon_bounds)             # (m_lon, n_lon), radians
# planar: use the raw bounds for both axes
valid = np.isfinite(f)                                                  # (n_lat, n_lon)
num = einsum("ai,bj,ij->ab", W_lat, W_lon, np.where(valid, f, 0.0))
den = einsum("ai,bj,ij->ab", W_lat, W_lon, valid.astype(float))       # fracarea
out = num / den            # mode="mean";  mode="sum": out = num * R**2 (spherical)
```
overlap_weights_1d is clip(min(b_hi_src, b_hi_tgt) - max(b_lo_src, b_lo_tgt), 0) on the outer product; sort/flip descending latitude first and flip back. Longitude wrap: unwrap target bounds into the source's periodic range before overlap (document the lon_wrap=360.0 assumption; lon_180_to_360 / lon_360_to_180 from xrtoolz.transforms already exist). Apply through xr.apply_ufunc(..., input_core_dims=[dims], output_core_dims=[dims], vectorize=False, dask="allowed") so extra dims (time, level) broadcast and dask chunks along non-regridded dims stay lazy; regridded dims must be single-chunk (same rule as sample_at_points, _check_dask_chunks).

Mathematical Notes
Source cells $i$ with area $a_i$ and values $f_i$; target cells $j$; overlap areas $w_{ij} = |c_i \cap c_j|$ with $\sum_j w_{ij} = a_i$ (interior) and $\sum_i w_{ij} = a_j$.
$$\text{mean: } \bar f_j = \frac{\sum_i w_{ij} f_i}{\sum_i w_{ij},[f_i \text{ valid}]},\qquad
\text{sum: } F_j = \sum_i w_{ij} f_i$$
Spherical cell area with bounds $(\lambda_-, \lambda_+)\times(\varphi_-, \varphi_+)$: $a = R^2(\lambda_+-\lambda_-)(\sin\varphi_+ - \sin\varphi_-)$, so overlaps factorise into a longitude length times a $\sin\varphi$ length.
Invariants for tests:
Conservation: $\sum_j a_j \bar f_j = \sum_i a_i f_i$ when the target covers the source (mean mode, no NaN); $\sum_j F_j = \sum_i f_i$ (sum mode).
Constant preservation: $f \equiv c \Rightarrow \bar f_j = c$ for every target cell with non-zero overlap, including partially covered edge cells (fracarea).
Identity: target grid = source grid $\Rightarrow$ output equals input to round-off.
Coarsen consistency: aligned integer factor $\Rightarrow$ equals coarsen_conservative.
Linearity and non-negativity of weights.
