Changes
GPU robust preprocessing
lib/cuda/preprocess_cuda.cu runs the per-sample passes:
block medians and MAD variances (exact radix selection);
the running median;
whitening, the bad-block sums and the output pass.
The block-level steps stay on the host. Their code is shared with the CPU through RobustStages (lib/io/preprocess_robust.cpp).
z-score and zap/birdies stay on the CPU.
The CLI preprocesses on the search's backend (5-8 s → 0.2 s at 2^25).
cuFFT removed
GpuFFTManager (lib/cuda/fft_cuda.cu): one PortableFFT per row, real packing for even lengths, Bluestein otherwise.
A row's output does not depend on the batch, inputs are preserved, and there are no plans. Speed matches cuFFT: W2L 52.4 vs 52.8 ms, W2Ln 31.6 vs 32.1 ms.
GPU Fourier searches support nbins <= 2048 and reject larger values early (check_gpu_fourier_nbins).
Fourier brute fold: accuracy
kernel_fold_complex_tiled replaces both kernels:
phasors from the double phase reduced to a cycle, then sincospif;
re-seeded every 64 samples;
two-level sums;
tiles in shared memory.
Fused scorers (bit-exact)
One multi-value butterfly for all width maxima in the FFA warp scorers.
c2c step phasors are computed once per transform and shared.
About -10% on the fused kernels.
Standalone FFA and EP on the sweep kernel
FFA::execute, compute_ffa* and EP's FFA stage use the sweep's brute-fold and merge kernels (FP32 phasors).
The replaced kernels are kept in lib/cuda/ffa_legacy_kernels_cuda.cu.
Not done (measured or decided)
Deterministic run-length time brute fold: 3.7-5.5x slower, reverted.
Fourier brute fold as GEMM: the fold is 17-34 ms per run; not worth it.
Cone tiling across freq-only groups (F3): not done. Estimated about 15% of freq-only wall time.
Device-specific scorer tuning: out of scope (portability).

…rute fold

Final CUDA optimizations for FFA. Every sweep workload is 2-5.6x faster.

Preprocessing
- Robust preprocessing runs on the GPU for GPU searches. Medians use exact
  radix selection. The block-level host steps are shared through RobustStages.
  The z-score method and the spectral zap stay on the CPU.
- At 2^25: 5.2-7.9 s on one core becomes 0.2 s.

FFTs
- cuFFT is removed. GpuFFTManager runs each row through PortableFFT, with
  real packing for even lengths and Bluestein's algorithm otherwise. A
  row's output does not depend on the batch, inputs are preserved, and
  there are no plans. Speed matches cuFFT on the sweep R2C.
- GPU Fourier paths accept nbins <= 2048 (shared memory fits on every
  architecture); larger values are rejected when the search is built.
- The EP reserve drops from 1.5 to 0.5 GiB for multi-nbins sweeps. EP
  memory model 9.

Fourier brute fold
- New kernel_fold_complex_tiled: phasors from the double phase reduced to
  a cycle, then sincospif, re-seeded every 64 samples; two-level sums;
  segments tiled through shared memory; 1D grid.

Fused scorers (exact)
- One multi-value butterfly reduces all width maxima in the FFA warp
  scorers. The c2c step phasors are shared across a transform's lanes.

Standalone FFA and EP
- FFA::execute, compute_ffa* and EP's FFA stage use the sweep's brute-fold
  and merge kernels.
- Host overloads use the per-thread default stream.
