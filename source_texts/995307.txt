Confirmed while adding #16 sampling regressions: projectOnStraightLine accepts a projection only if some coordinate of A is less than B. A segment directed nonincreasingly in all coordinates therefore rejects an interior projection, and getProjDistance falls back to the more distant endpoint. For A=(-1,0,0), B=(-2,0,0), C=(-1.5,0,0), the true distance is zero; the current query returns0.5. This affects nearest-segment selection and clearance sampling.
Reproduce both endpoint orders with analytic interior, exterior, transverse and degenerate cases in2D/3D.
Replace orientation heuristics with the scalar projection parameter on[0,1], preserving the projected-point output.
Keep these tests in CI and cross-link Mask-domain generation can produce coincident tissue-terminal positions #16; rerun Debug/Release and anatomical pilots with unchanged geometric oracles.
The first #16 correction exposed this independent defect; the current full local test suite is not green (9/14) and remains uncommitted until diagnosed. No threshold or oracle has been loosened.
