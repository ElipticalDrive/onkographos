PointCloudDensityCalculator
Version 3 (Build 22623)
Description
Overview
Description
This transformer calculates the density of an input point cloud and outputs a raster where each cell indicates the density.
Details
Input point clouds are converted into a numeric (UINT32) raster where each cell value represents the number of points falling into the cell.
See More
Usage
This transformer accepts point clouds as input.
Input Ports
PointCloud: This transformer accepts point clouds as input.
Output Ports
DensityRaster: This transformer outputs a UINT32 numeric raster with cell values representing point cloud density.
Parameters
Density Raster Pixel Size: The pixel size of the output raster can be set by the user.
