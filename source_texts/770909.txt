```
* Fix LTO cache key collisions (NVIDIAGH-1511)

LTO artifacts were cached under filenames derived from only seven hex
characters of the symbol hash. Different LTO symbols could collide on
that short prefix, causing cached artifacts to be reused for the wrong
symbol.

Use a longer cache key prefix for LTO artifacts and make missing,
invalid, or stale FFT metadata sidecars rebuild cleanly. Validate
cached shared-memory metadata as a concrete non-negative Python integer
so corrupt JSON booleans are treated as cache misses.

Only replace the primary .lto output when a stale sidecar made the
existing cache entry inconsistent. This preserves the multi-process
behavior where concurrent writers do not overwrite an already-created
cache output.

Add regression coverage for synthetic short-prefix collisions, cache
misses from bad FFT metadata, preserving concurrent cache outputs, and
replacing invalid metadata after a rebuild.

Signed-off-by: Eric Shi <ershi@nvidia.com>
```

Add SeedField Q-function extraction with geometry folding
…
550fa57
```
SeedField is an AdjointField whose eval_inner/eval_grad_inner return
injected seeds (selected branchlessly through the Sample's test_dof
slot) instead of evaluating shape functions, so a user's @integrand
body is reused verbatim as a pointwise Q-function. extract_qfunction
evaluates the integrand d+1 times per quadrature point with seeds
(v=1, grad v=0) and (v=0, grad v=e_i) - exact for forms linear in the
test function - and folds the geometry factors (grad u = J^-T
ref-grad, weight * |det J|) computed per quadrature point from the
element deformation gradient.

Unsupported inputs fail loudly instead of extracting garbage: side
(face) domains, non-cell geometries, operators outside the supported
set (inner/outer/grad/degree), and incompatible fields all raise with
actionable messages, keeping the eventual transparent dispatch
conservative. Validated against closed forms for mass, stiffness and
advection and against the naive integrate() oracle on sheared 2D and
anisotropic 3D grids at degrees up to 5, on CPU and CUDA.
```
