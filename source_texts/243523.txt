What
add scroliq-subgrid-run as a reproducible Subgrid Marching Tetrahedra candidate adapter
pin the reviewed upstream default to hbaktash/subgrid-marching@bc4a04946025d9c27eab620555bf93c611cf0d73 (MIT)
require an exact clean upstream checkout and hash the built executable
consume only a frozen explicit .npz tetrahedral edge-intersection artifact
run only the default primal extractor for the first experiment (no greedy/numerical-merge hyperparameter search)
refuse stale outputs/logs
audit the produced OBJ with existing scroliq-obj
record upstream/source/input/output/log hashes plus non-even tets
mark the receipt ink_blind=true and geometry_candidate_only
Evidence
Subgrid Marching Tetrahedra (ACM TOG/SIGGRAPH 2026, DOI 10.1145/3811358) is designed for multiple surface crossings per tetrahedron and intersection-free output. The public upstream repository is MIT licensed and provides an explicit edge-intersection interchange path.
The adapter intentionally freezes edge-intersection bytes so a future A/B measures the meshing construction rather than allowing each method to silently resample a different geometry hypothesis.
Stability check
CI is the objective gate. Deterministic tests use a temporary clean Git checkout and ignored fake build artifact to verify:
exact commit/license/executable binding
wrong commit rejection
dirty checkout rejection
successful output hash + OBJ audit
exit-zero/missing-output failure
nonzero-exit failure even with valid OBJ
stale-output refusal
explicit .npz input requirement
Grand Prize + frozen data
This does not select Subgrid as the production mesher and changes no frozen prize artifacts. It creates a reproducible candidate-generation path for an ink-blind held-out geometry experiment.
Docs
Adds docs/subgrid-mesher.md and updates AGENTS.md.
