Description
This dataset contains the figures, scripts, and intermediate data used to generate the results presented in the manuscript, which can be found at doi.org/10.1364/OE.561735.
The folder structure reflects the figure numbers in the manuscript:
- `01_Fig1` to `07_Fig7` contain the final PNG images used in the publication.
- `02_Fig2` includes the individual holograms and the Python script used to generate them.
- `04_Fig4` includes the comparison script between pointcloud and wireframe holograms, as well as the input image used for the FFT-based algorithm. Reference computation times are hardcoded in the script.
- `06_Fig6` contains additional `.tif` holograms (pointcloud, FFT, wireframe) stored in a subfolder named `Tif images`.
All code is written in Python and uses only standard scientific libraries (NumPy, Matplotlib, Pillow). The data are provided to ensure transparency and reproducibility.
Please cite this dataset using the Zenodo DOI if you reuse or reference any part of it.
