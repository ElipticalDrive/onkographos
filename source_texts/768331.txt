This PR introduces a comprehensive multi-dimension system, successfully generating distinct, procedurally generated realms: the cavernous Nether and the infinite floating islands of The End.
Key Changes:
Block Registry: Added definitions and procedural textures for blocks like Netherrack, End Stone, Crimson Nylium, Shroomlight, Basalt, Purpur, etc.
World Generation (Worker):
Refactored worker.js chunk routing to support multiple dimensions.
The Nether: Added 3D FBM cave carving, Y=0/128 bedrock boundaries, Y=31 lava oceans. Utilized temperature/humidity 2D noise mapping to generate 5 precise biomes with custom ground cover and vertical structures (Fungal Trees, Bone Ribs, Glowstone clusters).
The End: Implemented distance-based chunk generation for a central spawn island with obsidian pillars, a massive void gap, and procedural fractured outer islands.
Game State & Lighting: Added an activeDimension state. Pressing P dynamically hot-swaps dimensions, recalculating chunk meshes. Sky clear colors and fog colors smoothly update per dimension (e.g., dynamic crimson/grey fog across Nether biomes).
Physics: Implemented the 50% speed reduction when walking on Soul Sand and integrated true damage ticks when falling into the void in The End.
