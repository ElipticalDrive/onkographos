We use Warp quite a bit in our work. When creating a .nvdb file from Warp, its writer calls Python’s blosc.compress() without specifying a compressor, so it uses the default BloscLZ codec. The vendored Blosc library in PR #2363 only supports LZ4, so its NanoVDB reader cannot read these .nvdb files. This PR adds the BloscLZ decoder so OpenVDB’s NanoVDB tools can read files written by Warp. It also adds the required license notices and tests with a file generated by Warp.
