Abstract
The visualization of multi-resolution analysis and wavelet transforms is traditionally confined to static,
post-processing desktop environments. This document introduces Wavelet Vision Pro, a real-time Android application designed to bridge the gap between theoretical signal processing and interactive education. Utilizing
the Android CameraX API and custom-built multithreaded mathematical engines, the application performs
up to 4-level 2D discrete wavelet transforms (DWT) and Spatial Lifting Schemes directly on live camera feeds.
Operating entirely in the RGB color space. As of v.1.0, the app features 17 distinct frequency subbands, 9
classical wavelet families, and an interactive laboratory for dynamic lifting scheme generation.
1
Welcome to Wavelet Vision Pro
Wavelet Vision Pro v.1.0 is a high-performance, real-time application designed to perform multi-level 2D
wavelet decomposition directly on your live camera feed. Built for both educational visualization and advanced
signal processing analysis, the app operates natively in the RGB color space and is highly optimized for mobile
architectures.
1.1
Key Features at a Glance
• Real-Time Processing: Achieves a stable 30 FPS throughput using strictly in-place arithmetic and zeroallocation memory management.
• Extensive Wavelet Library: Supports 9 classical orthogonal wavelet families out of the box, including
Haar, Daubechies (4-12), Symlets (4-6), and Coiflet 1.
• Deep Decompositions: Supports up to 4 levels of decomposition for standard wavelets, with dynamically
calculated safe depths for custom schemes.
• Custom Lifting Engine: A fully customizable spatial lifting scheme allowing users to define their own
Predict and Update operators dynamically.
• Smart Color Normalization: Independent min-max normalization per color channel ensures deep-level
details remain visible without chromatic washout.
1.2
Understanding the Visual Output
When you apply a wavelet transform to your live feed, the image is split into four distinct subbands. In a
Multi-Level Decomposition, the top-left Approximation (LL) quadrant is iteratively split again and again
(visually demonstrated through Fig. 1). Interpretation of the subbands is as follows,
◦ LL (Approximation): The top-left quadrant. This is the blurred, low-pass version of your feed. It retains
the core color and structural volume.
◦ HL (Horizontal Detail): The top-right quadrant. Highlights horizontal edges and features.
◦ LH (Vertical Detail): The bottom-left quadrant. Highlights vertical edges and features.
◦ HH (Diagonal Detail): The bottom-right quadrant. Highlights diagonal textures and high-frequency noise.

Mobile Processing Pipeline
To achieve real-time performance without frame dropping, the application utilizes the Android CameraX ImageAnalysis API.
• Resolution & Matrix Sizing: The target analysis resolution is constrained to a 640 × 480 or 640 × 768
aspect ratio. This keeps the tensor arrays mathematically manageable for CPU-bound computations, averting
Out-Of-Memory (OOM) exceptions common in high-megapixel mobile sensors.
• Color Extraction: Frames are delivered in the YUV_420_888 format. The engine isolates the Y (luminance)
and U/V (chrominance) planes, forcibly rewinding memory buffers to avert pipeline stalls, and converts them
into independent R, G, and B integer arrays for parallel decomposition.
• Concurrency Strategy: Processing runs on a dedicated SingleThreadExecutor. A strict Boolean gating
flag paired with a try-finally block guarantees that if a single frame encounters a mathematical boundary
error, the flag resets, dropping the frame but preserving the live camera stream.
2.5
Mobile Optimizations
The classical convolution DWT requires O(N M ) complexity per level and secondary memory buffers. By utilizing
the Lifting Scheme factorization, Wavelet Vision Pro reduces operational complexity to O(N (|P | + |U |)/2). Most
critically, lifting allows for fully in-place computation directly within the spatial memory tensor, virtually
eliminating cache misses and ensuring seamless real-time processing on mobile hardware.

Educational User Guide
Wavelet Vision Pro v.1.0 is a high-performance, real-time application tailored for students and researchers
to visualize how frequency filtering alters real-world geometries and colors.
3.1
Installation and App Availability
The application is distributed as a standalone Android Package Kit (.apk) file. To install the application on an
Android device:
1. Download the provided WaveletVisionPro.apk file to your Android device.
2. Navigate to your device’s File Manager and tap the .apk file.
3. If prompted by Android Security, toggle Allow from this source in your settings to permit the installation.
4. Launch the app and explicitly grant Camera Permissions when prompted as the application requires this
to process the live visual feed.
3.2
Navigating the Interface
The main interface is designed to mimic a modern smartphone camera while offering deep analytical controls.
• Frequency Dropdown (Left): Select from 17 distinct frequency bands, ranging from the Original RGB
feed down to Level 4 high-frequency details (e.g., L4-HH).
• Wavelet Dropdown (Right): Switch dynamically between 9 mathematical wavelets, including Haar,
Daubechies (4 through 12), Symlets (4 and 6), and Coiflet 1.
• Action Buttons: Utilize the interface at the bottom to switch the camera (L), freeze/unfreeze the frame
for detailed study (circular shutter button), or save the current mathematical output to your gallery (").
4
Interactive Lifting Laboratory
For advanced students, Wavelet Vision Pro v.1.0 includes a secondary interface, namely, the Lifting Camera.
Accessed via a dedicated button, this laboratory allows users to construct bespoke wavelets by manually inputting
coefficients for the Predict (P ) and Update (U ) operators. The resulting subbands are interpolated and scaled in
real-time to fill the device screen. Note that the built-in configuration of the lifting wavelet mimics the classical
Haar wavelets in lifting settings.
4.1
Navigating the Interface
The interface for Lifting Wavelet Vision Pro v.1.0 is also designed to mimic a modern smartphone camera while
offering deep analytical controls.
• Predict Coefficients (Left): Write a combination of positive real numbers separated by commas that serve
as the predict operator (high-frequency capturing operator).
• Update Coefficients (Right): Write a combination of positive real numbers separated by commas that
serve as the update operator (smoothing operator).
• Action Buttons: Utilize the interface at the bottom to switch the camera (L), freeze/unfreeze the frame for
detailed study (circular shutter button), save the current mathematical output to your gallery ("), go back
to the standard wavelet interface (#), and apply the current lifting wavelets (✓).
Educational Exercise: The LeGall 5/3 Wavelet
To replicate the famous lossless compression wavelet used in the JPEG 2000 standard, open the Lifting
Camera and input the following weights:
• Predict Weights: 0.5, 0.5
• Update Weights: 0.25, 0.25
Press the Apply (✓) button to instantaneously compile and apply this wavelet to the live feed.
Dynamic Safety & Decomposition Limits
In the lifting scheme, image dimensions halve at each decomposition level. The app actively calculates the
maximum safe decomposition level (Lmax ) to prevent the signal boundary from shrinking below the length
of your custom filter. Levels that mathematically break the current filter size are dynamically filtered out
of the UI dropdowns to prevent application crashes.
