I brainstormed and implemented a set of creative voxel-generation modifications that bring interesting new structural capabilities to voxelizer-rs.
--hollow <thickness>: Modifies the Signed Distance Field check during solid voxelization to discard voxels deep within the object (sdf < -thickness), leaving a thin inner shell.
--porosity <threshold>: Evaluates a high-frequency sine-based pseudo-random hash field derived from XYZ coordinates to optionally discard voxels at random. This allows creating swiss-cheese or spongy patterns procedurally without modifying the input mesh.
--particle-jitter <amplitude>: Jitters final particle output coordinates. Standard grid voxelization looks extremely uniform. By feeding coordinates through distinct X/Y/Z sine hashes, the final particle positions can be slightly displaced, creating a more organic, noisy look, especially useful when exporting point clouds (CSV/PLY).
Also addressed an insightful code review point ensuring the hash prime polynomials used for porosity don't overlap with the X-axis jitter generation. Tests are all passing and I added documentation to the README.
