# Ellipsoid-placement-algorithm
This algorithm was developed in order to create complex geometrical modelling for Monte Carlo simulations, specially TOPAS. It places ellipsoids efficiently and without overlap within a cylindrical boundary, using both Hilbert Curve for voxelization and AMR (Adaptive Mesh Refinement) for voxelization optimization. 

Instructions on how to use the program syntax can be found as soon as the user executes the main file, elipsus_v5.py. Besides, visuals.py is a tool that can be used to visualize the results of dose deposition in each cell, using a colormap to do so. It has been configured to work for .csv outputs of the TOPAS Monte Carlo Code.
