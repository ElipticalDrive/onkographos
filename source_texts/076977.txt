About LiveVolume
Introduction
LiveVolume is a free, volume rendering software application for medical imaging and biological visualization. The software generates volume-rendered images interactively using GLSL (OpenGL Shader Language). LiveVolume is also equipped with a real-time, shadow generation engine based on the CUDA parallel computing architecture from NVIDIA. Scientists and technicians can use the software for both medical imaging and the visual analysis of microscopic images in the field of biotechnology.
Functional overview
Supports DICOM[1], RAW, TIFF and LiveVolume formats(vol)
Generates volume-rendered images with single- or multi-color maps
Interactive color map customization
Generates fused 3D images with any cross-section
Region growing function
Interactive shadow rendering
Measurement tools
ROI extraction
MIP (Maximum Intensity Projection)
