# 3DGS Voxelizer

Turn a 3D Gaussian Splatting scan into colored voxel blocks, inside NVIDIA
Omniverse.

<p align="center">
  <img src="exts/danci.voxelizer.tool/data/preview.png" width="480" alt="Voxelized splat scene">
</p>

You give it a splat file (`.ply` or `.spz`). It gives you a stack of colored
cubes that looks like your scene, right there in the viewport. Drag a slider
and the blocks get bigger or smaller, live.

The result is ordinary OpenUSD, so you can save it, hand it to someone else,
drop it into another scene, or load it into Isaac Sim and have robots bump
into it.

## Install

You need an Omniverse app that is built on Kit — **USD Composer**, **Isaac
Sim**, or any Kit app. Then:

1. **Download this repository.** Click the green *Code* button above →
   *Download ZIP* → unzip it somewhere you will remember, for example
   `C:\omniverse-tools\3dgs-voxelizer-Omni`.
2. **Open your Omniverse app** and go to the menu **Window → Extensions**.
3. In the Extensions window, click the **hamburger icon** (☰, top left of that
   window) and choose **Settings**.
4. Under *Extension Search Paths*, click the **+** button and paste the path
   to the `exts` folder inside what you unzipped. Using the example above:
   ```
   C:\omniverse-tools\3dgs-voxelizer-Omni\exts
   ```
5. Back in the Extensions window, type `3dgs` in the search box. **3DGS
   VOXELIZER** appears — click the toggle to turn it **on**.
6. Tick **AUTOLOAD** if you want it to come back automatically next time.

That's it. The tool now lives at **Window → 3DGS Voxelizer**.

## Use it

1. Open **Window → 3DGS Voxelizer**. A panel appears.
2. **Drag your `.ply` or `.spz` file onto the panel**, or click *Browse…* and
   pick it. It starts building right away — no extra button to press.
3. After a moment, colored cubes appear in the viewport.
4. **Drag any setting and it rebuilds automatically.** Try *Voxel size* first:
   smaller number means smaller, more detailed blocks.

Everything you do can be undone with **Ctrl+Z**.

## What the settings do

| Setting | In plain terms |
|---|---|
| **Voxel size** | How big each block is. Smaller = more detail, more blocks, slower. Start at 1 and adjust. |
| **Min opacity** | Splat scans have faint, cloudy specks around them. Raise this to throw the faint ones away and clean up the result. Only appears for splat files. |
| **Stage scale** | Makes the whole thing bigger or smaller. Leave at 1. If your model comes in tiny in USD Composer, try 100. |
| **Flip axis** | If the model is upside down or mirrored, tick X, Y or Z until it looks right. Instant, and you can untick it. |
| **Physics collision** | Makes the blocks solid, so things can land on them and robots can drive over them. Leave off if you only want to look at it. |
| **Export USD…** | Saves your blocks as a single file you can reuse or send to someone. |
| **Adopt Selected** | Reopened a scene later and want to keep tweaking the blocks? Click the blocks in the *Stage* list, then click this. |

## If something looks wrong

**Nothing appeared.** Look at the text at the bottom of the panel — it says
what happened. If it says the file could not be read, the file is probably not
a real `.ply` / `.spz`.

**The model is tiny, or huge.** That is a units mismatch, not a bug. Set
*Stage scale* to 100 in USD Composer (which measures in centimeters), or leave
it at 1 in Isaac Sim (which measures in meters).

**It is upside down or mirrored.** Use *Flip axis*. Different scanning apps
disagree about which way is up.

**Everything got slow.** You made the blocks too small, so there are too many
of them. The panel warns you past about 800,000 blocks. Raise *Voxel size*.

**The blocks look washed out or noisy.** Raise *Min opacity* to drop the faint
specks the scanner left behind.

## For developers

The pipeline (`exts/danci.voxelizer.tool/danci/voxelizer/tool/core.py`)
depends only on `numpy` and `pxr`, so it also runs outside Omniverse in any
environment with `usd-core` — useful for batch jobs:

```python
from danci.voxelizer.tool import core

pc = core.load_pointcloud("scan.ply")
centers, colors, _ = core.voxelize(pc, resolution=1.0, min_opacity=0.3)
core.author_voxel_instancer(stage, centers, colors, resolution=1.0)
```

Loading the extension from a terminal instead of the UI:

```
kit.exe your_app.kit --ext-folder path/to/3dgs-voxelizer-Omni/exts --enable danci.voxelizer.tool
```

Running the tests (needs `numpy`, `usd-core`, `pytest`):

```
python -m pytest tests/ -q
```

Architecture, USD layout, units policy and the verification record are in
[docs/TECHNICAL.md](exts/danci.voxelizer.tool/docs/TECHNICAL.md).

## Requirements

Kit SDK 106 or newer. Pure Python, nothing to compile. Tested on USD Composer
(Kit 110.2) and Isaac Sim 6.0.1 (Kit 110.1).
