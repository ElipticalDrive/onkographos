Description
I would like to contribute a Client-Side WebGL Raymarching & Signed Distance Field (SDF) Sandbox under Project/HTML,CSS,JS.
A 3D graphics sandbox utilizing WebGL fragment shaders to render complex 3D scenes using Raymarching and Signed Distance Fields (SDFs).
Problem
Graphics programmers need browser tools to visually write and debug GLSL Raymarching shaders without complex 3D mesh loaders.
Proposed Solution
Build a WebGL application where users edit GLSL Raymarching code, combine SDF primitives (Spheres, Cubes, Toruses), and apply ray-traced lighting.
Features
Live GLSL Raymarching fragment shader editor
Signed Distance Field (SDF) primitive shape library & CSG boolean operations (Union, Subtract, Intersect)
Raytraced ambient occlusion, soft shadows, and reflection rendering
Mouse camera orbit controls
High-res PNG screenshot snapshot exporter
Tech Stack
HTML5
CSS3
JavaScript (WebGL API, GLSL Shaders)
Folder Structure
```
Project/HTML,CSS,JS/Client-Side WebGL Raymarching & Signed Distance Field Sandbox/
├── index.html
├── style.css
└── raymarching-sandbox.js
```
