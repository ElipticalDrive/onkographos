Summary
reduce GS Virtual Camera Sampling noise by balancing every above-50% virtual step with a canonical-front gradient while keeping the 50% path unchanged
set the public defaults to 50% share, 75 degrees, and 24 cameras; expose the open front hemisphere through 89 degrees
keep bounded depth as a soft regularizer and preserve PlayCanvas default asynchronous gsplat sorting in Tilt
add the shared scale-biased surface-layer prior and Current-Visibility Compaction v2 controls
align the public metrics labels, README, screenshot, Tilt source, and generated bundle
Why
At 100% virtual-camera share, pseudo-view gradients could dominate the only real image objective and create strong front-view noise. The balanced front anchor caps the effective virtual gradient share at 50% without turning the user-facing sampling control into a false value.
The 75-degree setting remains the conservative default, but it is no longer a hard product limit. Exactly 90 degrees stays excluded because the planar inverse projection is singular there.
Validation
3000-iteration browser A/B:
legacy 100% / 75 degrees: front RGB L1 0.054719, bad pixels 25.02%
balanced 100% / 75 degrees: front RGB L1 0.006470, bad pixels 0.282%
balanced 100% / 89 degrees: front RGB L1 0.006325, bad pixels 0.290%
89-degree browser run: 0 validation errors, standard-alpha 17-property PLY, GPU active/reserved 0/0 after release
source and generated Tilt bundle have byte-identical SHA-256
