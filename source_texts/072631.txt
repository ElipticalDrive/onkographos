The pipeline (cadjoint/meshing)
Five tested stages (design ledger: research/differentiable-meshing-pipeline.md). Gradients ride through the input coordinates of every field evaluation — sample points move with the parameters — never through output values at frozen points.
Differentiable Hermite edge detection (edge_detection.py) — frozen crossing-edge sets, bisection + secant + implicit-function-theorem Newton correction; degenerate root gradients (roots land bit-exactly on flat walls) re-evaluate on the adjacent smooth branch.
Sharp-feature classification (features.py) — face/crease/corner from mean-centered normal spread, exact min/max CSG seam detection, and feature-chain linking for display.
Dual contouring (dual_contouring.py) — differentiable Tikhonov QEF for gradients; rank-revealing sharp placement for the forward mesh (box corners exact to 2.5e-8); deterministic start_inside-wound connectivity.
Octree-pruned detection (adaptive.py) — bit-identical to dense detection, 6–15% of the evaluations; lipschitz is the caller's contract.
Export (export.py) — planar-patch merging into sparse polygon meshes (a box collapses to its 6 faces), OBJ with native n-gons, binary STL, and a deterministic, structurally valid STEP AP214 faceted B-rep (not yet validated against a CAD kernel).

Give Box and Cylinder valid subgradients on their surfaces

```
The epsilon inside sqrt(sum(d*d) + 1e-20) creates an exact stationary
point on every face plane: a point exactly on the surface gets zero
derivatives with respect to both position and parameters, even though
the one-sided subgradient there is well defined. Root finding converges
bit-exactly onto faces, so differentiable meshing hit this on every
box edge and received identically-zero parameter gradients (finite
differences reported the true sensitivity).

Branch on inside/outside instead: on-or-inside points differentiate
through the max(q) branch and receive the correct one-sided
subgradient, while the outside norm keeps a double-where guard so its
unselected branch cannot NaN reverse-mode gradients. Values are
unchanged except for removing the fake 1e-10 offset. Cylinder keeps
the radial epsilon: its degenerate point is the axis, which is
interior. The polygon primitives share the old pattern and are left
for a follow-up.
```

```
New jaxcad.meshing package, built bottom-up from the inputs in pure JAX.
Stage 1a finds sign-changing grid edges host-side and refines each
crossing with bisection + secant + a differentiable Newton correction,
so root positions, parameters, and gradients carry exact
implicit-function-theorem derivatives with respect to design parameters
without unrolling the solver. Stage 1b classifies active cells into
face/crease/corner from the mean-centered spread of incident Hermite
normals, and detects hard-CSG seams exactly from min/max active-branch
changes.

Robustness rules an adversarial review forced in: detection freezes each
edge's inside/outside orientation so lattice vertices exactly on the
surface cannot flip the bracket under float32 re-evaluation; refinement
derives endpoints in float64 with detection's expressions so both
evaluate the field at bit-identical coordinates; Newton steps are
accepted only if they do not worsen the frozen residual, which caps
tangency-degenerate edges (grids far from the origin) at 6e-5 instead
of 5e-3; and every sqrt/normalize is double-where-guarded so degenerate
cells get zero subgradients instead of NaN-poisoning every parameter.

48 tests cover analytic roots, gradient checks against closed forms and
finite differences, hard-CSG unions/intersections, feature
classification on box/sphere/cylinder, and seam detection.
benchmarks/edge_detection_bench.py tracks fidelity, gradient error, and
stage timings. The plan and stage ledger live in
```

```
The wiggle along feature curves was the Tikhonov QEF's mass-point bias,
which varies with how the grid slices the surface in each cell.
extract_mesh now defaults to sharp_qef_vertices for the forward mesh: a
rank-revealing truncated pseudo-inverse that projects planar cells onto
their face, crease cells onto the crease line, and corners onto the
corner - box corner error drops from 1.7e-4 to exactly 0, and cylinder
rim vertices sit on the cap plane to the last bit. Gradients keep the
smooth Tikhonov path; the two differ by the regularization bias.

jaxcad.meshing.adaptive adds octree-pruned detection: blocks where
|f(center) - level| > half_diagonal * L cannot contain the level set
and are discarded, then only surviving cells' corners are evaluated,
through one fixed-size chunked evaluator so the field compiles once.
The octree adapts the search, not the mesh - leaves stay at uniform
depth - so the edge set is bit-identical to dense detection (tested as
exact equality on sphere/box/union/plane) and every downstream stage
works unchanged. Evaluations drop to 6-15 percent of the dense lattice
at resolutions 64-96. extract_mesh exposes it via lipschitz=; the bound
is the caller's contract, and over-claiming only weakens pruning while
under-claiming can lose cells (both tested).
```

```
A feature curve crosses grid cells diagonally, so consecutive feature
cells are usually not mesh-adjacent: classifying sharp mesh edges
traced a staircase around every circular rim. feature_cell_links
connects feature cells across the full 26-neighborhood instead, and
since feature-aware placement puts their vertices exactly on the

vertices are Newton-projected onto the exact intersection curve

zigzag between face-projected vertices.
```
