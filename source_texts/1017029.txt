Description
Artifact for "Random-Access Hardware Sequence Compression" (ISCA 2026).
This artifact contains:
- Software RST compression implementation (C++) for reproducing compression ratio results (Fig. 18, Fig. 19)
- SystemVerilog RTL for the RST compressor and decompressor, compilable with Verilator for functional verification and performance metric extraction
- Pre-generated ASIC synthesis results (ASAP7 7nm, 2.5 GHz) for a scaled configuration
- Synthesis scripts for regeneration (requires Synopsys Design Compiler)
- QEMU VM image with all dependencies pre-installed for easy evaluation
- Memory dump test data from standard benchmarks
See the included README.md for setup and usage instructions.
