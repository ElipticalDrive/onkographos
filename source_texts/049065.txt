Mesh Improvements
glTF mesh loading using the tinygltf library for parsing
Wrote GPU ray triangle intersection kernel
Toggleable mesh AABB culling before triangle tests
Performance Improvements
CPU built octree acceleration for meshes with iterative GPU stack traversal
Toggleable accel modes: brute-force / AABB only / octree (MESH_ACCEL)
Other Features and Details
Optional normalize step on mesh so TRANS / SCALE behave consistently across models
GPU Moller–Trumbore ray triangle intersections tests with interpolated normals
When building octotree do not split node if all triangles are within a sub-node
Nearest first child order from ray direction signs (nearMask with XOR remapping) so closer hits are found early and farther subtrees cull sooner
