What changed
added a shared immutable sparse TSDF snapshot schema for CPU and Metal fusion
added completed-generation tracking to the CPU sparse reference
added bounded incremental mesh patch extraction with deterministic cell ownership
added positive topology and symmetric gradient halos for seamless patch boundaries
added dirty-neighbour invalidation, explicit patch removal, and stale-generation rejection
added a ranged dense extraction primitive so halos inform normals without duplicating cells
added CPU and Metal snapshot integration tests, raw evidence, and roadmap documentation
Why
Full sparse extraction still densified the entire allocated span. That made meshing cost scale with scene extent and could not support responsive reconstruction. Dirty block updates now rebuild only affected cell-owner patches while preserving the existing resolved topology.
Verification
debug build and 33/33 tests
warnings-as-errors CI build and 26/26 tests
sanitizer build and 26/26 tests
Metal API and GPU validation
clang-format and clang-tidy
17/17 benchmark Python tests
Studio launch smoke
1,680 incremental triangles exactly matching 1,680 full-extraction triangles
bit-exact shared patch positions and normals
Remaining work
Patch extraction is still CPU-side and Metal snapshots currently read back all resident blocks. Selective readback, GPU-resident Marching Cubes, asynchronous scheduling, persistence and eviction, and real-capture performance evidence remain open.
