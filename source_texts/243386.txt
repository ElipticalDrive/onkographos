Overview
Visualize plate motion velocities as arrows on the sphere surface showing direction and magnitude of movement.
Requirements
Vector Field Data
Interface with plate velocity data:
```
struct PlateVelocity {
    glm::vec3 position;      // Position on sphere surface
    glm::vec3 velocity;      // Velocity vector (tangent to sphere)
    float magnitude;         // Speed in cm/year
    int32_t plate_id;
};
```
Arrow Rendering
Arrow geometry: Generate 3D arrow meshes
Arrow placement: Regular grid or per-plate sampling
Arrow scaling: Length proportional to velocity magnitude
Arrow coloring: Color by speed or plate ID
Orientation: Arrows tangent to sphere, pointing in velocity direction
Visual Design
Arrow head size: proportional to shaft length
Minimum/maximum arrow lengths for readability
Color gradients:
Slow: Blue (0-2 cm/year)
Medium: Green (2-5 cm/year)
Fast: Red (5+ cm/year)
Optional: Fade arrows by plate age
Placement Strategy
Regular grid: Sample velocities at regular lat/lon intervals
Plate-based: One arrow per plate region
Adaptive: More arrows in high-velocity regions
Configurable density (sparse, medium, dense)
Arrow Geometry
Two approaches:
3D mesh arrows: Cone for head, cylinder for shaft
Billboard arrows: 2D sprites always facing camera (simpler)
Start with 3D mesh for Phase 3, add billboard option later.
Shader Integration
```
// Vertex shader
layout (location = 0) in vec3 aPosition;
layout (location = 1) in vec3 aColor;
uniform mat4 uModel;  // Per-arrow transform
uniform mat4 uView;
uniform mat4 uProjection;

// Fragment shader
in vec3 vColor;
uniform float uAlpha;
```

Acceptance Criteria
Generate arrow geometry (cone + cylinder)
Place arrows on sphere surface
Orient arrows along velocity direction
Scale arrows by velocity magnitude
Color code by speed
Configurable arrow density
Toggle vector field visibility
60 FPS with dense arrow field
Technical Notes
Arrow Mesh Generation
```
// Arrow components
Cone head(radius = 0.02, height = 0.05, segments = 8);
Cylinder shaft(radius = 0.01, height = velocity_magnitude * scale);
```
Arrow Transformation
Start with arrow pointing +Z
Rotate to align with velocity direction (tangent vector)
Translate to position on sphere
Scale length by magnitude
Velocity Sampling
Sample plate velocity field at regular intervals (e.g., every 10°)
Skip ocean-only regions if desired
Ensure arrows don't overlap excessively
Visual Validation
Earth-like test should show:
Pacific Plate: Fast arrows westward
Indian Plate: Fast arrows northward (into Asia)
African Plate: Slow arrows in various directions
Atlantic spreading: Arrows away from mid-ocean ridge
Future Enhancements
Animated arrows (flowing particles along velocity)
Arrow trails showing motion history
Interactive arrow selection for details
