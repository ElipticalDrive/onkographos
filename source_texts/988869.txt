# Voxel-Based 3D World Generator
Minecraft-style voxel city built with Python + ModernGL (OpenGL 3.3).

## Features
- Procedural voxel city generation (roads, buildings, lake, trees)
- Chunked world rendering
- Frustum culling for chunk-level optimization
- Visible-face-only voxel meshing
- Ambient occlusion approximation for voxel depth
- Day/night lighting control
- Water, clouds, and stars rendering
- Interactive block add/remove with ray casting (DDA traversal)
- In-game block palette and day/night slider UI
- Player collision against solid voxels (cannot pass through blocks)

## Tech Stack
- Python
- Pygame
- ModernGL
- NumPy
- Numba
- PyGLM
- OpenSimplex

## Project Structure
- `main.py`: engine startup, game loop, event handling
- `scene.py`: scene composition and render order
- `world.py`: world/chunk container and voxel storage
- `world_objects/chunk.py`: per-chunk voxel generation and render
- `terrain_gen.py`: procedural city/terrain logic
- `meshes/chunk_mesh_builder.py`: voxel mesh construction and AO packing
- `voxel_handler.py`: voxel ray casting + add/remove interaction
- `camera.py`, `player.py`, `frustum.py`: camera and movement systems
- `shader_program.py`: shader compilation/uniform management
- `shaders/`: GLSL shaders (chunk, water, clouds, stars, marker)

## Controls
- `W A S D` / Arrow keys: move
- `Q / E`: move up / down
- Mouse move: look around
- `Left Click`: set voxel (add/remove depending on mode)
- `Right Click`: toggle add/remove mode
- `TAB`: toggle cursor mode for UI interaction
- `N`: toggle day/night
- `1..6`: quick-select common block types
- `Shift`: faster movement
- `Ctrl`: slower movement
- `Esc`: quit

## Setup
```bash
pip install -r requirements.txt
python main.py
```

## Notes
- Designed for OpenGL 3.3 core profile.
- Collision uses voxel occupancy checks with axis-wise movement resolution.
