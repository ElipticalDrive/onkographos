Summary
Adds Android Storage Access Framework folder picking to the MRI Library and preserves the existing individual-file workflow.
Recursively scans selected folders for DICOM Part 10 files, including extensionless scanner files; ignores unrelated sidecars and DICOMDIR.
Reuses the existing DICOM decoder, series UID/geometry checks, memory caps, sorting and .nii.gz writer. Mixed studies/series or unsupported DICOM remain explicitly rejected.
Updates the library UI, user documentation and tests.

Limitations
Supports the current native little-endian, uncompressed, single-frame MONOCHROME2 DICOM subset only (up to 1,024 slices). Generated NIfTI must be imported manually into the app library. Medical/diagnostic validation is out of scope.
