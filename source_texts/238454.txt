Task Assignment
HSLU offers a 3-credit course RayTracing von Grund auf, where students implement a ray tracer
from scratch in a language of their choice. Developing an efficient ray tracer is a lot of work,
naturally the topic ”performance optimizations” comes short. Goal of this project is the design
and implementation of an easy-to-use framework that relies on hardware-acceleration to achieve
maximum performance. As part of the project, a tutorial is written that is ready for classroom
integration.
2
Methodology
A set of milestones was created to track the progress throughout the project:
• Proof of Concept: Implement a ray tracer with the graphics API of choice Vulkan.
• Thin Abstraction Layer: Build a thin abstraction layer around Vulkan to simplify development
of the framework.
• Framework Design and Implementation: Iteratively design and implement the framework.
Keep a working ray tracer handy to track performance and functionality.
• Tutorial: Write a step-by-step tutorial that describes the usage of the framework and builds
an efficient ray tracer in small, incremental projects.
Regular meetings were held with the main advisor to discuss the framework and the possibility
of adding additional features. Many of these ideas were implemented, such as mathematically
defining shapes by writing the ray-geometry intersection logic.
3
Challenges
Working with the selected graphics API Vulkan is very hard. Vulkan is low-level and explicit,
meaning the developer has full control over every aspect of the graphics pipeline. This allows
targeted optimizations but also comes with an increase in complexity. As a reference point,
presenting a single triangle to the screen requires close to 1’000 lines of C++ code.
Framework design was also a one of the major difficulties. Finding the right balance between
exposing and abstracting the low-level Vulkan functions turned out to be quite difficult.

Results
The result of this project is a flexible, feature-rich framework that allows straightforward implementation
of an efficient, real-time capable ray tracer. The tutorial consists of seven incremental projects,
with the following image showing the end result.
The framework also allows rendering of much more complex scenes and more computationally
heavy lighting calculations. A comprehensive, interactive path tracer shows these capabilities.
The implementation is available to students as an example.
The dragon model above is sourced from the Stanford 3D Scanning Repository and consists of
850’412 triangles. The scene is rendered in real-time at a resolution of 1500x1000 on an AMD
Radeon RX 9070 XT GPU.

5
Outlook
Focus of this project was a working solution that could be used in class. This was achieved, but
there are still many open topics that could be implemented in the future. Below is a non-exhaustive
list of the most interesting possible additions:
• Object Movement: Allow individual objects to be moved around / animated.
• Frames in Flight: Increase performance by supporting parallel processing between the
CPU and GPU.
• Direct GPU Memory Access: Modern GPUs allow the CPU direct memory access through
the PCIe lane (ReBAR). This feature is currently not supported by the ray tracer.
• Headless Rendering: Alternative rendering mode that does not render to the screen, but to
an image file. This would add support for rendering high-resolution images that are outside
the resolution of the used monitor.
The features above were not implemented mainly due to time / scope constraints.
