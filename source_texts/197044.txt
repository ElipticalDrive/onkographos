Package 10.6 — conforming adaptive volume previews and polyhedron instancing A/B
Volume (preview only)
Refine nonuniform but globally shared Cartesian axis planes using the residual between a trilinear scalar sample at each candidate cell center and the coarse corner interpolation.
No T-junctions at cell boundaries by construction; ≤32 nodes/axis and ≤3 refinement passes. Report maximum sampled center scalar residual, threshold and acceptance; revert to the prior uniform preview when the proxy threshold cannot be met.
Native closed signed-sphere topology audit (two triangles per interior edge), skew/periodic/potential-color byte-for-byte fixed-grid parity and an oscillatory-grid fallback proof.
Final scientific marching-tetrahedra algorithm remains exactly unchanged. This is not a true local 2:1 octree transition algorithm nor a rigorous global scalar/Hausdorff error bound; full research validation is explicitly deferred.
Polyhedron performance A/B
Experimental Performance panel selector: Merged mesh (default) / GPU instancing. The latter groups by inequivalent center and opacity; shared ConvexGeometry hull vertices, per-instance translation matrices and RGB colors; merged decorative outlines.
Real Chromium/WebGL A/B test on 125 BaTiO₃ TiO₆ octahedra checks atom/poly counts, area, volume, GPU draw groups, CPU-side buffer bytes and poly build duration. No fixed performance pass/fail threshold.
Retain all existing safety caps, EN-default UI, offline PWA cache and EN/TR docs.
Follow-up (10.7)
True local crack-free octree transition templates, scientific iso-position error bounds, external map corpus and multi-GPU/OS benchmarks. No auto-instancing until verified as a net win.
Please leave unmerged until native/independent Gemmi and real browser/WebGL CI checks are green.
