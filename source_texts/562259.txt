💡 What: Optimized the Volumetric God-Rays rendering in Parallax.js by batching canvas path operations. The ctx.beginPath() and ctx.fill() calls are now hoisted outside the for loop.
🎯 Why: Previously, the engine was calling beginPath(), creating a path for one ray, and then calling fill() individually for each of the 6 rays every frame. This resulted in unnecessary overhead. By hoisting the begin/fill commands out of the loop, all rays are batched into a single path drawing operation. This reduces the number of calls to the Canvas API and CPU overhead during hot render loops without changing the final visual output.
📊 Impact: Reduces Canvas API pathing and fill calls for volumetric rays from 6 sets per frame to 1 set per frame.
🔬 Measurement: Verify by running the visual tests (npm run test:visuals) and ensuring no regressions occur in the rendering output. All tests pass successfully.
