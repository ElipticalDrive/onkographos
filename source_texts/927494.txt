There's currently no code path taking a Triangle3D through MVP transforms into screen-space pixels. Implement:
model matrix per mesh instance
multiply by Camera::to_matrix() (view+projection, already partially implemented)
perspective divide to NDC
NDC -> screen-space mapping using WIDTH/HEIGHT, producing Triangle2D for rasterize_triangle
This wires Vertex3D/Triangle3D to the rasterizer and is the missing link between camera and pixels.
