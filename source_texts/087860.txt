Package 10.8.4 — Independent scientific algorithm and fragmentation study
Why: Package 10.8.3 observed very large real 5wkd FWT/DELFWT 48³→64³ area changes. This PR tests whether the effects originate mainly from the production marching-tetrahedra implementation or from voxel sampling / dense fragmentation.
Reproducible experiment: The real 5i55 partial CCP4 and independently Gemmi 0.7.5 regenerated real 5wkd FWT/PHWT and DELFWT/PHDELWT maps are resampled onto identical 32³, 48³, 64³ Float32 grids. The production Worker isoTriangles with validation-only full-grid override and independently implemented scikit-image 0.25.2 Lewiner marching cubes process exactly the same voxel values, signed thresholds and skew Cartesian Å lattice basis: 2 near-peak scalar thresholds × 3 grid sizes × 3 sources = 18 paired comparisons.

Scientific conclusion: two independently developed algorithms exhibit almost the same severe 5wkd area sensitivity when voxel resolution changes. This is substantial evidence of sampling / unresolved feature / threshold sensitivity, not simply a defect unique to marching tetrahedra. These real maps are not demonstrated to converge at 64³. The second mesher is not physical ground truth.
Quality gates and limits
CI installs pinned scikit-image==0.25.2, scipy==1.15.3 alongside Gemmi 0.7.5 / NumPy 2.1.3 (scientific CI only).
Reports: both physical Å² areas and resolution changes, snapped-mesh connected components (0.0005 voxel tolerance), source voxel 6-connected blob counts, and sampled symmetric nearest-vertex Å distances. These distances are not true Hausdorff bounds; fragment counts depend on snapping resolution.
Hard fails: missing/truncated/nonfinite/degenerate surfaces, production 75k-triangle budget violations, spatial domain mismatch and catastrophic >5-voxel geometric misregistration. Observed scientific non-convergence is flagged, not mislabeled as a quality pass.
All numerical results saved to validation-results/volume-independent-10-8-4.json and archived in GitHub Actions, alongside prior 10.8 quality reports. EN/TR README and roadmap updated.
No production/UI rendering behavior changed, no experimental high-accuracy mode enabled. An optional setting is not currently justified by the science.
Follow-up: quantify source-vs-resampled peak occupancy and high-frequency spectral content, compare to voxel resolution and thresholds; pursue an opt-in quality/budget A/B only after a reliable numerical benefit can be demonstrated. Leave unmerged until the latest full native/Gemmi and Chromium/WebGL CI are green.
