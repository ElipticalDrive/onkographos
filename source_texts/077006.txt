Summary
Route direct .ply uploads through the same Gaussian splatting renderer used for NIF viewing.
Remove the direct PLY path's custom point-sprite approximation, which averaged the three scale axes, ignored Gaussian rotations, and did not implement splat depth sorting.
Preserve the decoded-cloud helper and existing NIF renderer unchanged.
Use non-progressive loading for direct PLYs to prioritize final splat ordering/quality, retain low-alpha splats with threshold 1, and dispatch the existing viewer-ready/splat-loaded events.
Validation performed
Confirmed the branch contains the native PLY route and retains mountDecodedCloud, mountInteractiveViewer, and the existing upload route.
Confirmed viewer.html still loads the quality-boost module; this PR does not alter that module.
Browser visual regression testing is still required with the user's original PLY, comparing FUMOCA against Brush and SuperSplat. Non-progressive loading may take longer and use more memory for large PLY files.
This is a draft for review; it is not merged or deployed.
