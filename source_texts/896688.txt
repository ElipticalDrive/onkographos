# VoxelGenesis — Procedural World Generation Engine for Minecraft 1.21.10

**English** | [简体中文](README.zh-CN.md)

> **⚠️ Version Lock**: This project targets **Minecraft Java Edition 1.21.10** (`DataVersion = 4556`, protocol `773`) specifically.
> The generator depends on the exact block IDs, block state properties, and NBT chunk format of this version. **Compatibility with other versions is not guaranteed.**
> To run on a different version, you must obtain the corresponding `minecraft-server.jar` and handle block renames, format differences, and other compatibility issues yourself.

A procedural world generation engine that writes voxel-level data directly into Minecraft's Anvil binary chunk format — no mods, no in-game tools, no runtime dependencies. Pure Python implementation; an end-to-end pipeline from a seed number to a playable save file with **100% byte-level determinism**: repeated builds produce identical SHA-256 hashes.

An entire modern world is constructed on a canvas of tens of thousands of voxels — villa complexes, seaside parks, ocean cruise ships, supercar showrooms, underwater restaurants, and private vaults — all composed purely of block states, **generating zero entities and zero armor stands**. Every chandelier, every car, every sculpture is made of voxels.

## Core Capabilities

- **Native Anvil I/O** — Direct NBT serialization/deserialization and non-cross-boundary 64-bit chunk bit-packing, bypassing all intermediary tools and game runtime
- **Byte-Level Determinism** — Fixed timestamps, gzip mtime=0, coordinate-hash deterministic RNG; two full builds produce zero-diff SHA-256 across all chunks
- **Triple Verification Pipeline** — 1.21.10 NBT schema validation → 3D spatial connectivity walkability audit → full chunk readback comparison, ensuring zero-entity compliance
