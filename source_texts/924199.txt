Problem Statement
EntityItemRenderer currently applies a static 64-block horizontal distance cutoff. On 1440p and 4K displays, a dropped item at 64 to 128 blocks remains clearly visible (between 4x3 and 9x6 pixels). Hard-culling items at 64 blocks causes noticeable pop-in before the client unload boundary (~128 blocks).
Architectural Solution
Resolution-Aware Scaling:
Scale the culling threshold dynamically based on viewport height and current FOV so culling only triggers when projected screen size falls below sub-pixel visibility (~1.5 pixels). On 4K displays, this naturally extends visibility out to chunk unload range.
Impostor / Billboard LOD:
Substitute complex 3D voxel item meshes beyond the distance threshold with a lightweight 2D billboard quad displaying the primary item texture, avoiding multi-draw call overhead while preventing visual pop-in.
Acceptance Criteria
Replace static 64-block cull with resolution/FOV-aware threshold or billboard LOD.
Eliminate visible item pop-in on 1440p and 4K displays.
Maintain GPU draw call reduction benefits.
