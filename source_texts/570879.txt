Summary
Restructures the repo from two loose scripts into an installable superquadrics package, consolidating the geometry and plotting functionality (distance/CBF/kinematics/ROS deliberately left to the other repos).
Superquadric = shape + pose. Constructed from a SuperquadricShape dataclass (scales, exponents) plus a pose (center + settable pose property; rotation as matrix / Euler xyz / quaternion).
Geometry: inside_outside_function (single + batched), analytic grad_inside_outside_wrt_point and hessian_inside_outside_wrt_point, get_surface_points (uniform-angle or arc-length modes, configurable n_fine), and generate_mesh / to_mesh (local / world triangle meshes).
Robustness: SuperquadricShape validates positive scales/exponents and lengths, and warns for e > 2 (non-convex). Gradient/Hessian are regularized at axis-aligned points via a scale-relative clamp (removable singularity for e <= 2).
Plotting: Open3D (modern rendering API, supports transparency) and PyVista backends, plus a superquadric_plotter dispatcher; both honor opacity.
Packaging: per-backend extras [pyvista] / [open3d] / [viz] / [examples]; the core depends only on numpy+scipy (viz libs imported lazily). MIT license; GitHub Actions CI; requires-python >= 3.10.
Example: examples/visualize.py renders both backends side by side with a shared orthographic camera and a left-to-right opacity gradient (images shown in the README).
Test plan
```
pip install -e ".[viz,dev]"
pytest -q          # 37 passed
```
Coverage:
Construction in all 3 rotation formats; transform round-trip; shape-as-input contract + TypeError on misuse.
inside_outside_function classifies inside/outside; batched matches single.
Gradient & Hessian verified two ways: vs. central finite differences (general exponents) and vs. the closed-form ellipsoid (2P(p-c) / 2P) at exponents=[1,1].
Axis-aligned points return finite gradient/Hessian (clamp), matching the ellipsoid there.
Surface points satisfy F ~= 1 (both simple and uniform modes); mesh shape counts + unit-sphere radius.
SuperquadricShape validation: rejects non-positive / wrong-length; warns at e > 2, silent at e = 2.
pose / pose_inverse property + setter; public API exports.
Plotting (skips if backend absent): both backends build valid geometry headless; Open3D opacity sets the transparency material.
Manual visual check:
```
pip install -e ".[examples]"
python examples/visualize.py --opacity 0.5 --out examples/images
```
