Motivation
Provide an educational web demo that demonstrates Rayleigh and Mie scattering and lets users compare sky color behavior on Earth, Mars, and Venus.
Description
Add a static single-page UI (index.html) with controls for planetSelect, sunAngle, and dust and visual panels for a sky preview and scattering-by-wavelength bars.
Implement simulation logic in script.js with planetary presets, color mixing utilities, a path-length based pathFactor, and dynamic SVG bar rendering in drawBars.
Add styling in styles.css for layout, the sky gradient, sun disc, controls, and charts.
Add README.md with instructions to run the demo locally via python3 -m http.server 4173 and basic usage notes.
