🌒 Project: EldritchEclipse
🚀 Issue: Implement 2D Signed Distance Field Raymarching with Volumetric Light Accumulation
🧩 Description
Create a real-time volumetric lighting engine using signed distance fields to render procedural monoliths casting god rays and long dynamic shadows.
✅ Features
Signed Distance Field shape definitions
360° raymarching from light source
Adaptive step marching using SDF
Hard shadow detection
Multi-pass light accumulation buffer
Atmospheric scattering effect
Interactive light source control
🛠️ Tasks
Implement SDF distance functions
Step rays using minimum distance heuristic
Detect surface intersection threshold
Cast secondary rays for shadow testing
Accumulate light intensity in buffer
Normalize and blend volumetric glow
Optimize ray loops for performance
