The hit method in the [sphere] class performs ray-sphere intersection tests, which involve dot products and square root calculations. These operations can be parallelized using CUDA.
Use:
Thrust for parallelizing the intersection tests. Thrust is a parallel algorithms library which resembles the C++ Standard Template Library (STL).
cuBLAS – Accelerates linear algebra operations. While not directly used here, it may optimize matrix-heavy operations for advanced camera transformations.
