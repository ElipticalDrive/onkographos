Hello! Thanks for the nice library! I would find the isosurface rendering mode helpful. If you are open to a PR, I would be happy to make an attempt at it.
If I understand correctly, to implement, I would have to:
Update the VolumeRayIso material class such that the render_mode is set to iso (or whatever the name should be)
Register the VolumeRayIso material class on the VolumeRayShader class
Add a render_mode_iso() function to the volume_ray.wgsl file (https://github.com/pygfx/pygfx/blob/main/pygfx/renderers/wgpu/wgsl/volume_ray.wgsl) performs the ray cast and color calculation that returns the RenderOutput struct.
In terms of the render_mode_iso() function, I would propose to model it after the shader in vispy, as that has worked for me in the past, but I would be open to suggestions.
