Hi, thanks for the great work on SAGE-3D!
I'm trying to understand the pipeline for generating the collision mesh USD files
in the SAGE-3D_Collision_Mesh dataset (e.g., Collision_Mesh/839873/839873_collision.usd), and Occupancy png.
The README mentions that each collision body is decomposed into convex hulls for
efficient collision detection, and that the dataset contains 554,000+ collision body
instances across 1,000 indoor scenes. However, the generation process is not documented
in either the dataset README or the main repository.
Could you clarify the following:
Source geometry: Are the collision meshes derived from the original indoor triangle
mesh scenes used to train the 3DGS, or are they extracted from some other source?
Decomposition tool: Which convex hull decomposition tool was used (e.g., V-HACD,
CoACD, or something else)? What were the key parameters (e.g., max convex hulls per
object, resolution)?
Per-instance vs. per-scene: Are collision bodies generated per object instance
(using the bounding boxes / instance masks from labels.json) and then merged into
a single scene-level USD file, or is the entire scene mesh decomposed at once?
Reproducibility: Is there a script or workflow in the repository (or planned to
be released) that allows users to reproduce the collision USD files from the raw
InteriorGS data?
Understanding this pipeline would be very helpful for extending the dataset to new scenes
or adapting it to other simulation platforms.
Thanks in advance!
