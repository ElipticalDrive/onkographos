This updates the renderer from chunk/octree traversal toward an SDF-first rendering path. The primary path tracing shader now ray-marches a procedural signed-distance scene and renders a voxel-like world inspired by the referenced IQ/Shadertoy work, while preserving the existing fullscreen path tracing / temporal accumulation / denoise pipeline.
Renderer shift: octree traversal → SDF ray marching
Replaced the fragment shader’s chunk/octree intersection path with signed-distance evaluation and sphere tracing.
Kept the existing Vulkan-side frame graph, push constants, lighting buffers, temporal pass, and denoise pass unchanged to minimize host-side churn.
Voxel-like SDF world
Built a procedural scene that reads as blocky/voxel terrain rather than smooth implicit blobs.
Added terraced terrain, caves, trees, rocks, and material selection for grass/dirt/sand/snow/forest/stone.
Preserved normal generation, direct lighting, sky lighting, and bounce-based path tracing on top of the new hit model.
Path tracing shader cleanup
Raised the default march budget to better fit SDF traversal.
Renamed the exposed debug control from DDA terminology to ray-march terminology.
Parameterized shader tuning values used for terrain shaping, RNG seeding, march stepping, and refinement.
Representative shader change
```
bool sceneIntersect(Ray ray, float maxDistance, out Hit hit)
{
    uint maxRaySteps = max(pc.settings.w, 32u);
    float t = 0.0;

    for (uint stepIndex = 0u; stepIndex < maxRaySteps && t < maxDistance; ++stepIndex) {
        vec3 position = ray.origin + ray.direction * t;
        DistanceSample marchSample = sceneDistance(position);

        if (marchSample.distance < kHitThreshold) {
            hit.found = true;
            hit.t = t;
            hit.position = position;
            hit.normal = estimateNormal(position);
            hit.material = marchSample.material;
            hit.albedo = materialAlbedo(hit.material, hit.position);
            return true;
        }

        t += clamp(
            marchSample.distance * kRayMarchStepMultiplier,
            kRayMarchMinStep,
            kRayMarchMaxStep);
    }

    return false;
}
```
