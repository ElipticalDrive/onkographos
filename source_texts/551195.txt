Implements the rendering model described in #674–#677: objects are now drawn from shared indexed geometry (one per binding), with faces lit by hemisphere and key/fill lights, edges inked as fat lines (sharp dark, tangent lighter), and a silhouette pass for curved surfaces. Selection and hover are tinted overlays, never replacement colours. Parts are coloured by a palette (stable across reloads) or by drawing rules.
Core rendering changes:
Shared geometry: Drawn interface holds indexed faces and edges; Shared map caches geometry by Placement.geometry so all objects of one binding reuse it
Materials: One MeshStandardMaterial per colour (with metalness 0.05, roughness 0.55), shared across all objects of that colour; LineMaterial for edges with per-segment vertex colours (sharp vs tangent)
Lighting: Hemisphere light (sky/ground), key and fill directional lights following camera, soft room environment (0.35 intensity) for gradient on curved faces
Silhouette pass: Renders object normals/depths to a target, then inks where depth steps (curved faces turning away, parts occluding)
Tinting: Selection and hover drawn as geometry overlays with face-indexed texture, tinted by GLOW constants (face 0.5, body 0.28, hover 0.35/0.2)
Part colouring (#676–#677):
New colours module: palette() assigns stable colours by part digest (binding key or solid name), survives reloads and numeric edits
fills() reads drawing rules (fill properties) to override palette colours per object
STEP export writes part colours as AP214 presentation on solids
CLI --drawing flag specifies .svd file for colour rules
Geometry building:
mesh::Drawn replaces own: positions, normals, per-vertex face index, indexed triangles, sharp/tangent edge counts
face_edges() refactored to sides() + inked(): identifies sharp edges (turn > EDGE_TURN) and tangent edges, returns as one fat line set
Tests in drawn_mesh.rs verify triangle fidelity, vertex sharing, edge classification
Web app:
Box3D now holds shared (geometries), materials (per colour), edgeInk (line material), tinted (selection overlays)
Placed tracks geometry, faces, mesh, edges, tint instead of just group
buildTints() rebuilds selection/hover overlays when picked/hovered changes
tangentEdges view option controls tangent edge visibility (drawing fewer line segments)
DrawCounts reports lines and silhouettes flag
Documentation:
Updated box3d.ts header with rendering model details
Added part_colours.rs test for palette stability and drawing overrides
plates/ example demonstrates multi-part assembly with colour rules in .svd

Track B of #668.

#674 One indexed geometry per shape. `mesh::drawn` lays `grouped`'s
triangles over vertices shared within a face, each vertex with the face it
is of; `gcs_solid_drawn` hands it over as one f32/u32 buffer (replacing
`gcs_solid_own`). `Placement.geometry` (`EvaluatedSolid::geometry_serial`)
is one for every solid of a binding, so the box holds their geometry once.
`box3d` draws an object as one mesh and one line set, with one shared
material per colour; a selected or hovered face is a tint overlay over the
object's own geometry, each face lit from a texture its vertices index.

#675 Edges as fat lines: `mesh::drawn`'s sharp edges dark and tangent ones
lighter (View > Tangent edges), the faces polygon-offset behind them; and a
screen-space silhouette pass over the objects' view normals and depths.

#676 A colour per part (`colours.rs`): by binding, every placement one
colour, from a twelve-colour palette indexed by a digest of the part less
its numbers (`program::part_of`), probing to a free colour, so a reload and
a numeric edit keep it. Hemisphere, key and fill lights and a RoomEnvironment.

#677 A `.svd` rule outside every sheet takes `fill: #rrggbb`, the colour of
the parts its path names (`drawing::fills`, `drawing::colours`). The
workspace reads the drawing beside the model by its stem; `solventc
--step-assembly` writes it (or `--drawing PATH`'s) into the STEP's styled
items, and `--png` shades in the same colours. `examples/plates/` is the
corpus case. Spec 0.196, solvent-drawing.md and the contract record it.

- `mesh::sides` is the one triangle-side matcher `face_edges` and `inked` read.
- The language stamps `Binding::part` (the key less its numbers) beside the
  key, rather than `program::part_of` parsing the key's format back apart.
- `Shape::renamed_from: Option<u64>` replaces the `geometry: 0` sentinel; a
  rename shares its `Drawn` by `Rc`.
- `colours::of_name` is the PNG's colour for a solid that is no object; the
  CLI's drawing loader (`load_beside`) and the ABI's bundle loader
  (`bundled`) are one each; `fills` reads each object's part once.
- `gcs_solid_drawn` writes four counts and the face ids as f32.
- box3d: a tint hangs in its object's group, so a drag moves it rather than
  rebuilding it, and is worked out again only when the selection or the
  hover changes; materials keyed by the colour as given; `release` no longer
  needs to know what objects share; `sync` builds through one `rebuild`.
