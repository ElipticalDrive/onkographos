# Real-time 3D Gaussian Splatting

*[English](README.en.md)*

自作ゲームエンジン MitiruEngine（DirectX 12）に実装した、実時間 3D Gaussian Splatting ビューアです。写真から再構成した点群（splat）シーンを GPU で描画します。

![Real-time 3D Gaussian Splatting demo](docs/demo.gif)

▶ フル動画: [`docs/demo.mp4`](docs/demo.mp4) · ポートフォリオ用 lab ページ: [`docs/lab.html`](docs/lab.html)

収録シーンは `assets/nike.splat`。Nike シューズを約26万 splat で構成しています。

## 実装内容

- `.splat` ローダ。antimatter15 形式（32 B/splat）の position、scale、color（u8）、rotation（u8 quaternion）を解析し、シェーダで使用する `StructuredBuffer<Splat>`（64 B）のレイアウトへ展開します。

- EWA 楕円射影スプラッティング（DirectX 12 / HLSL）。各 splat の 3D 共分散 `R·S·Sᵀ·Rᵀ` をヤコビアンで 2D へ EWA 射影し、conic Gaussian としてインスタンス化したビルボード矩形で描画します。合成にはプリマルチプライ over、描画には 4× MSAA FP16 を使用しています。

- O(N) の深度バケットソート。毎フレームの CPU 深度ソートを `std::sort`（O(N log N)）からカウンティングソートへ置き換え、数百万 splat でも実時間で奥から手前への順序を保ちます。

- フローター除去。中央値とパーセンタイルを基準に、孤立した遠方点、grazing で白い尾を引く巨大 splat、ほぼ透明な点などの再構成ノイズを読み込み時に自動除去します。

- PCA による自動アップライト。物体中心のシーンを主成分解析で立て直し、最大主軸（長手）を X、高さを Y、幅を Z に整列します。被写体が水平に寝て側面がカメラを向く配置です。

- シーン境界球に基づくカメラの自動フレーミング、距離比例ズーム、無操作時の自動周回を実装しています。

> MitiruEngine には、ONNX Runtime と DirectML を使って 3D⇄2D を行き来する「現像」機構として、実時間ニューラル style 変換も実装しています。この lab デモは 3D 描画部分のみを扱います。

## 実行

```console
mitiru run
```

操作は次のとおりです。

- ドラッグまたは A / D で周回
- W / S でズーム
- 無操作時は自動周回
- ESC で終了

> ビルドには自作ゲームエンジン MitiruEngine が必要です。このリポジトリはデモ／ショーケースとして公開しています。

## リポジトリ構成

- `src/main.cpp`
  
  ビューア本体です。flat POD で約70行。カメラ操作と自動フレーミングを担当します。

描画パイプラインは MitiruEngine 側にあります。

- `include/mitiru/render/SplatScene.hpp`
  
  `.splat` ローダとフローター除去。

- `include/mitiru/render/dx12/DX12Splat.hpp`
  
  描画パスと深度バケットソート。

- `include/mitiru/render/dx12/DX12SplatShaders.hpp`
  
  EWA 楕円射影を行う HLSL シェーダ（VS / PS）。

- `Screen::loadSplatScene`、`Screen::drawSplats`、`Screen::splatBounds` から各処理を呼び出します。

実装の詳細は [`docs/splatting-dx12.md`](docs/splatting-dx12.md) にまとめています。

## ライセンス / 出典

`nike.splat` は、antimatter15 が公開している splat データ（cakewalk/splat-data）です。

ビューアとエンジンは自作です。
