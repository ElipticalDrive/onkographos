Dear Authors,
Thank you for your excellent work.
As far as I know, for some of the compared methods, such as FlashVSR, the evaluation code for metrics like PSNR and LPIPS is not publicly available.
Could you kindly share how you obtained these metrics for those methods? Any information about the evaluation protocol, implementation details, or code would be very helpful for me in making a fair comparison between your work and theirs in my paper.
Thank you very much for your time and help.

@Teiboku Thank you for your interest.
To ensure a strictly fair comparison across all methods, we did not rely on the individual evaluation scripts from each repository. Instead, we evaluated all generated results uniformly using our own metric calculation pipeline. Here are the specific implementation details:
1. Evaluation Scripts: We calculate the metrics using our script located at finetune/scripts/eval_all_metrics.py. You can execute this via the run_eval_all.sh script. Please refer to our README for specific instructions on how to run it.
2. Metric Libraries:
We utilize the pyiqa library to calculate PSNR, SSIM, LPIPS, CLIPIQA, and MUSIQ.
For DOVER and FasterVQA, we use their respective official libraries (details can also be found in the README).
3. Comparison Protocol: For all compared methods (including STAR, DOVE, SeedVR, and FlashVSR), we used their officially released code and pre-trained weights to run inference on the test datasets. Once the output results were generated, we evaluated all of them under the exact same pipeline mentioned above to get the final metrics.
