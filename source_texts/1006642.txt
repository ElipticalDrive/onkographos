Label: mesh-terrain Priority: 4
Generic marching cubes mesh generator in /engine. No cylinder-specific assumptions — cylinder generation logic lives in /game on top of this utility.
Required:
Takes a 32³ density field (3D scalar array of floats), produces vertex/index mesh — same output contract as existing primitive generator
256-entry marching cubes lookup table for triangle configurations per cell
Gradient-based normal generation via central differences on the density field
Configurable LOD output: generate 2–3 decimated variants at generation time (not runtime), strip clutter/secondary geometry from lower LOD variants
Chunk boundary seam data: expose neighbouring chunk edge values so adjacent chunks can stitch correctly
C++ test harness first (populate a field directly, verify output visually) before any Lua exposure
