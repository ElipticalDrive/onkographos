v5 — implicit modelling: signed distance fields → marching cubes
Substantially improves the existing Claude project scanline-3d-7r4k (a from-scratch software 3D renderer + path tracer) by adding a whole new geometry pillar. Until now every object was authored explicitly (parametric meshes, imported OBJ). This adds the implicit half of modelling: a shape is the zero set of a signed distance field, and the triangles are discovered by a hand-written marching cubes polygoniser that drops straight into the same rasterizer and path tracer.
What's new (all inside projects/scanline-3d-7r4k/)
src/sdf/sdf.ts — an SDF algebra: distance primitives (sphere, box, rounded box, torus, capped cylinder, capsule, plane, gyroid TPMS), boolean and smooth-minimum CSG (union/intersect/subtract), domain transforms (translate, scale, rotate X/Y/Z, twist, onion shells, infinite repeat), and a central-difference gradient for normals. Every op is a plain closure over numbers.
src/sdf/marchingcubes.ts — the Lorensen–Cline algorithm with Paul Bourke's verbatim 256-entry edge table + 256×16 triangle table. Samples the field on an n³ grid, interpolates a vertex onto each crossed cell edge, and welds vertices across cells by a global per-edge key so the output is a closed indexed manifold with smooth gradient normals — plus isWatertight, signedVolume, and an OBJ-style fitMesh.
src/sdf/scenes.ts — seven implicit scenes: metaballs, a 3-axis-drilled machined part, a gyroid shell clipped to a sphere, a twisted bar, a blended critter, a genus-flipping ring, and a carved sphere — with live smoothness/iso knobs.
src/sdf/verify.ts — an 8-check self-test that re-derives the hard claims independently: analytic primitive distances, the smooth-min inequality, CSG sign algebra, the marched sphere (watertight + on-surface + outward-wound + analytic volume), the Euler characteristic that fixes topology (sphere χ=2, torus χ=0 / genus 1), gradient normals, the analytic gradient, and an empty field → empty mesh.
Integration — a new Implicit (SDF) scene preset frames the marched mesh, and a control-panel section exposes the gallery, grid resolution, blend and iso sliders with a live read-out (triangles · welded vertices · watertight · march time). The mesh feeds the existing rasterizer and BVH path tracer unchanged.
