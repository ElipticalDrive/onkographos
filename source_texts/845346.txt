Clarified current behavior
SimScope currently uses held temporal volume samples. That behavior is intentional and scientifically valid; coarse-looking playback is not automatically a viewer defect. Before implementation, inspect the actual recorded field timestamps and exporter cadence.
Goal
Add an optional smooth visualization-time interpolation mode for adjacent temporal field samples only when structural/scientific compatibility is established.
Scientific requirements
preserve Hold mode
do not interpolate incompatible grids/schemas/units/identities
distinguish recorded, held, and reconstructed display states
do not rewrite source arrays/timestamps/capture bytes
do not silently change numerical/source probe semantics
keep playback tied to physical time, not output frame rate
Acceptance
Verify source cadence on the problematic sparse-field case before implementation.
Controlled sparse capture reproduces existing Hold behavior exactly.
Interpolation changes the displayed field continuously between compatible samples.
Exact recorded timestamps reproduce exact recorded states.
Incompatible samples fall back safely to Hold.
Validate representative non-negative and signed/complex-component channels.
Preserve source hashes and explicit provenance.
Add focused regression coverage for interpolation math, boundaries, compatibility checks, and provenance.
Review boundary
Implement this issue only, validate it, report results, and stop for owner review.
