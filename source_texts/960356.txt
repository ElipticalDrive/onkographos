Adds a shared GLSL cloud model under shaders/include/clouds.glsl. The sky now raymarches a volumetric cloud layer with self-shadowing, silver lining, wind/rain response and daylight/twilight lighting. Terrain, PBR models and actors project the same cloud field along the sun direction to produce soft moving cloud shadows that match the visible cloud motion. Actor shaders now pass world position so the cloud shadow can be evaluated consistently.
