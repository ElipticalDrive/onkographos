clouds.512x512x32.raw.zip
The slow performance is mainly caused by the very high number of bounces inside the cloud. IIRC I read somewhere that hyperion starts to make the cloud more isotropic after a number of bounces, which apparently doesn't hurt the fluffly cloud feeling much and improves performance.
If mitsuba is much faster with comparable settings maybe my handling of the heterogeneous data is not very efficient, despite the acceleration structure (it used to be faster then blender cycles and radeon render pro, half a year ago, both of which apparently have improved performance for this case recently).
I think the residual ratio tracking that is done for transmission had slight performance benefits but did not affect the image very much.
I attached a much smaller cloud. But it will probably also be slow, if you set the albedo very high.
