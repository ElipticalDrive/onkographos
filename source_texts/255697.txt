Logic for sampling additional points inside a shape represented by Gaussian Splats.
Motivation: 3DGS only reconstructs shells of objects. For simulation, we require volumetric mass. We approximate that with additional isotropic gaussians injected to the interior of objects for simulation purposes only. The process is tricky because 3DGS does not produce watertight shells, but rather, anisotropic gaussian samples on it.
Solution: This PR uses a dedicated CUDA kernel (by @charlesloopNV) for solidifying objects in 2 steps:
Convert 3D Gaussians -> Voxels by using kaolin’s SPC (efficient CUDA based Octree)
Volume filling of voxelized shell by carving the space of voxels using rendered depth maps
Algorithmic Flow:
In step 1, the set of gaussians is voxelized using a novel hierarchical algorithm. The axis aligned bounding box of the gaussians is enclosed in a cubical root node of an octree. This node is subdivided in an 8-way split, and a list of overlapping gaussian IDs is maintained for each sub node. The nodes that contain voxels are subdivided again and tested for overlap. This process repeats until a desired resolution is achieved. The nodes at the frontier of the octree are a voxelization of the gaussians, represented by an SPC. However, the SPC does not include voxels ‘inside’ the object represented by the gaussians.
In step 2, we raytrace this SPC from an icosahedral collection of viewpoints to create a depthmap for each view. These depthmaps are fused together into a second sparse SPC using a novel algorithm that maintains the occupancy state for each node of the full octree. These states are: empty, occupied, or unseen.
Finally, the occupancy state of points in a regular grid are determined by querying this SPC. The union of the sets of occupied and unseen points serves as a sampling of the solid object.
Usage Example:
The Simplicits tutorial have been extended to include an example which samples additional points in the volume using the Densifier.
