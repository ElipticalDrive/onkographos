Summary
Adds tests/libslic3r/test_voxel_utils.cpp (tag [VoxelUtils]) covering Feature/Interlocking/VoxelUtils, the voxel grid helpers behind the interlocking generator. Registers it in tests/libslic3r/CMakeLists.txt. Test-only change, no src/ edits.
What's covered
walkLine visits each crossed cell in order and stops early when the callback returns false
walkLine reports exactly one cell for a zero-length segment
walkLine crosses each grid axis in both directions (GENERATE over axis and sign)
toGridPoint / toLowerCorner conversion, including negative cells
walkPolygons follows every boundary edge at the requested z
walkAreas samples only interior cells
DilationKernel CUBE / DIAMOND / PRISM neighborhoods are bounded, unique, contain the origin, and are ordered by size
walkDilatedPolygons expands each visited boundary cell
Known bugs tagged
None. All 7 cases pass on main.
Deviations from the branch version
Include cleanup only: dropped the redundant catch2/catch_all.hpp and unused <algorithm>, and replaced <cmath> with <cstdlib> for integer std::abs. The test bodies are unchanged.
