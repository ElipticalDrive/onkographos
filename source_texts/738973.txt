Summary
New pygame_3d.py — a first-person raycasting 3D entry point that uses the same QuizMazeGame engine as pygame_main.py. No changes to main.py, maze.py, db.py, or view.py.
Run with python pygame_3d.py.
What's new
Raycasting engine
200-column DDA (Digital Differential Analysis) raycaster — same algorithm as Wolfenstein 3D
66-degree FOV with distance fog blending (far walls fade to near-black)
X-side walls slightly brighter than Y-side walls for depth shading
Ceiling: dark forest canopy gradient; Floor: dark soil gradient with depth fade
Trees
Procedural 3-tier conifer sprites (no image files needed)
Scattered at wall-hugging corners of every maze cell (0-2 per cell, seeded)
Billboard rendering with Z-buffer occlusion (trees don't draw over closer walls)
Fog-of-war aware — trees in unvisited cells are hidden
Sound (all synthesised — no audio files)
