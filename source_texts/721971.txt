Abstract:
Line generation algorithm on hexagonal prism grid generates a 3D discrete line on hexagonal prism grid, which is a set of connected voxels approximating the line. An integer algorithm for this issue is presented in this paper. The algorithm is extended from the 2D line generation on hexagonal grid to the hexagonal prism grid based on an adjunct parallelepiped space with the same center and basis vectors.

1. Introduction
3D line generation algorithms that draw a 3D discrete line from a continuous line are basic but very important in volume graphics. These algorithms are used not only for synthesizing voxel-based objects in volume graphics, but also for ray traversal in voxel space[1], [2]. The development of volume graphics has lead to growing interest in 3D line generation. An assortment of 3D scan-conversion algorithms [3] is introduced within the cubic grid. Then a tripod algorithm generating an exact 3D discrete line on the cubic grid[4] is considered. The algorithm for naive 3D discrete line drawing [5] is given and the algorithm based on linear programming algorithm which recognizes any set of points on the cubic grid [6] is proposed. More recent studies[7] propose a volumetric drawing system that directly extracts and renders linear features that lay on isosurfaces within the volume.
