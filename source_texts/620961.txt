I resolve this issue by doing one of these trick:
first one: not optimal but its good to got one of rotate vector, pitch, yaw, or roll like this:
```
var q = {};
    q.x = controllersGamePad[0].pose.orientation[0];
    q.y = controllersGamePad[0].pose.orientation[1];
    q.z = controllersGamePad[0].pose.orientation[2];
    q.w = controllersGamePad[0].pose.orientation[3];
    var yaw = Math.atan2(2.0*(q.y*q.z + q.w*q.x), q.w*q.w - q.x*q.x - q.y*q.y + q.z*q.z);
    var pitch = Math.asin(-2.0*(q.x*q.z - q.w*q.y));
    var roll = Math.atan2(2.0*(q.x*q.y + q.w*q.z), q.w*q.w + q.x*q.x - q.y*q.y - q.z*q.z);
    actor.rotateX(radians_to_degrees(yaw));
    actor.rotateY(radians_to_degrees(pitch));
    actor.rotateZ(radians_to_degrees(roll));
```
Second one its work perfect and smoothly, and its work by calculate degree from w Quaternion, and then we get Axis-Angle, for example:
```
var Θ = Math.acos(controllersGamePad[0].pose.orientation[3])*2;
    var x1 = controllersGamePad[0].pose.orientation[0] / Math.sin(Math.acos(controllersGamePad[0].pose.orientation[3]));
    var y1 = controllersGamePad[0].pose.orientation[1] / Math.sin(Math.acos(controllersGamePad[0].pose.orientation[3]));
    var z1 = controllersGamePad[0].pose.orientation[2] / Math.sin(Math.acos(controllersGamePad[0].pose.orientation[3]));

actor.rotateWXYZ(radians_to_degrees(Θ), x1, y1, z1);
```
