intersect_ray() currently reports initial overlaps even when hit_from_inside is disabled, omits enabled mesh/heightmap backface hits and leaves mesh face indices unset. The concave shape's backface_collision setting is also discarded.
Honor the query flags, retain the resource setting and return original input triangle indices after native BVH reordering. Enabled backface queries visit native triangles within the remaining ray segment's bounds, preserving nearest-hit selection, masks, exclusions and body/area filtering. Internal character recovery rays retain their existing inside-hit behavior. Simulated concave contacts remain one-sided, as documented.
Validation:
The new regression fails on unchanged upstream main f073c2d and passes here. It covers box/sphere/capsule inside hits, rotated body and attachment transforms, front/back mesh face indices and normals, resource flags, filtering, closer convex hits and native heightfield backfaces.
All 36 headless physics tests pass locally with official Godot 4.7 on macOS.
CI passes: normal CMake builds on Linux, Windows and macOS, with all 36 physics tests passing on both Linux and Windows.
git diff --check passes. Based directly on current upstream main with the existing Box3D submodule pin; independent of the heightmap geometry and Web PRs.
