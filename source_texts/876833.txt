Motivation
Provide end-to-end tooling to render orbit sequences from 3DGS PLY models and produce COLMAP-compatible datasets (images, masks, poses, TXT+BIN models).
Support conversion of rendered orbit outputs back into COLMAP format for downstream SfM/NeRF workflows.
Add mesh extraction utilities that respect masks and enable more robust surface reconstruction (marching tetrahedra, integration/depth-fusion modes).
Add utilities to refine masks using GroundingDINO + SAM2 and a training script for mask-aware densification/regularization.
Description
Extended milo/convert.py with --from_orbit_output mode and flags (--images_dir, --masks_dir, --poses_dir, --output_dataset, --write_rgba_images) and implemented build_colmap_from_orbit_outputs plus binary writers to produce cameras/images/points3D TXT and BIN files.
Added milo/convert3dgs.py to build a COLMAP dataset from a native 3DGS PLY and its orbit outputs, including loading PLY colors, downsampling points, writing TXT files and COLMAP BIN files with cameras.bin, images.bin and points3D.bin.
Reworked milo/render_3dgs_orbit_video.py to a modernized renderer that: uses a GaussianRasterizer wrapper, loads native 3DGS PLYs into tensor structures, recenters models, renders dual-distance orbit configurations (near/far), writes per-frame images, masks, and poses JSON files (including colmap_qvec/colmap_tvec), and produces mp4 videos for the orbits.
Added new mesh extraction scripts: milo/mesh_extract_integration_mask.py (integration + marching tetrahedra with optional binary search refinement and view-mask support) and milo/eval/dtu/mesh_extract_dtu_mask.py (mesh extraction that injects external masks and integrates depth/voxel fusion); both integrate mask-aware flows.
Added milo/refine_masks_gdino_sam2.py which refines an existing mask directory using GroundingDINO for box proposals and SAM2 for mask prediction with options to intersect with existing masks and auto-resolve model paths from common submodule locations.
Added milo/train_mask_regular_densification.py, a training entrypoint that integrates mask injection, mesh-in-the-loop regularization, depth-order priors, densification and 3D mip-filter updates for mask-aware Gaussian training.
Miscellaneous improvements: robust input/path resolution, more careful FOV estimation, camera build returns consistent transforms, utilities to save pose JSON, and defensive checks and normalization.
