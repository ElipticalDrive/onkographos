Summary
Port Gaussian point splatting from BabylonJS/Babylon.js#18962 to Lite, supporting streaming and non-streaming Gaussian splats with SH shading.
Add Trogir demo controls for point sampling, density, render scale, occlusion culling, accumulation limits, and experimental temporal reprojection, plus FPS/frame-time and accumulation progress displays.
Keep point sampling and temporal reprojection off by default. Reprojection remains an opt-in experiment with depth-aware bilinear history gathering and point-sampled hole filling.
Fix accumulation convergence, streaming content refreshes at low accumulation limits, and reprojection depth ordering/filtering.
Include architecture documentation, focused lifecycle/HUD tests, and a nonvisual GPU reprojection regression test.
Scope
Scene 331 and all related scene files, parity/reference images, thumbnail, configuration, and scene-specific bundle assertions have been removed from this PR. Babylon.js dependencies and dependency-quarantine settings are unchanged. Scene 331 parity is deferred.
Validation
52 focused Gaussian point-splatting/Trogir HUD unit tests pass.
Tests and lab TypeScript checks pass after scene removal; focused formatting/lint and diff checks pass.
Earlier feature validation passed library typechecking/builds and 12 hardware-GPU reprojection readback cases.
No full-scene, visual/parity, or performance suites run for this PR preparation.
Known experimental limitation
Temporal reprojection can still soften/smear during motion due to single-depth history and repeated resampling; it is disabled by default.

🔵 Needs a closer look
Sampling bias, premature reprojection convergence, and unnecessary GPU work remain unresolved.
No open issues 🎉
4 previously missed issues
In code that hasn't changed since last review
Avoid Hi-Z allocation and writes when occlusion culling is disabled
packages/​babylon-lite/​src/​gaussian-point-splatting/​gps-runtime.ts:224
With occlusionCulling: false (the default), this still allocates the entire Hi-Z depth hierarchy and its level uniforms, while GPS_RESOLVE writes the base level every dispatch. At 3840×2160 with renderScale 1, that is about 42.2 MiB of unused GPU storage and 31.6 MiB of unnecessary writes per accumulation frame. Allocate the hierarchy and enable its writes only when culling is enabled, using an inert binding otherwise. When culling is enabled, continue rebuilding the hierarchy during reset/refresh frames even though rejection is temporarily disabled.
Prevent reprojection from freezing disoccluded pixels prematurely
packages/​babylon-lite/​src/​gaussian-point-splatting/​gps-runtime.ts:449
Reprojection can stop accumulation before newly exposed pixels converge. With a converged view, maxAccumFrames = 8, and renderScale = 1, reprojection sets frames to 7, but pixels with no history receive a count of zero. One dispatch makes frames reach 8 and exhausts the refresh window, so this condition freezes those pixels after one sample while progress reports 8/8. Track convergence separately from retained-history accounting so disocclusions receive the requested samples, and add a low-limit reprojection regression that checks actual pixel counts.
Skip classic projection and sorting when point color replaces the draw
packages/​babylon-lite/​src/​gaussian-point-splatting/​gps-runtime.ts:647
Point color mode still runs classic stream projection and radix sorting on camera/content changes. The preserved classic update queues the shared batch (splat-stream-material.ts:125–139), whose flush calls recordProjectionAndSort (splat-stream-gpu.ts:964–965). After bootstrap, these results serve a suppressed classic draw, so moving large streams pays for both rendering paths. Separate selection, canonical gathering, and bootstrap signaling from classic projection/sorting, and skip the latter when point color replaces the draw. Keep feature-specific decisions behind the opt-in integration seam.
Use a separate random seed for point placement
packages/​babylon-lite/​src/​gaussian-point-splatting/​gps-shaders.ts:360
Point placement reuses the Poisson allocation's random stream. For a single Gaussian (g = 0), its first point (p = 0) uses the same uniform that determined whether the count was nonzero. At Poisson mean 0.2, this point is emitted only when a >= exp(-0.2) ≈ 0.819, biasing placement toward the tails instead of sampling the full profile. Use a domain-separated placement seed so accumulation does not preserve this coverage bias.
