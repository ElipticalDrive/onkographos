This PR fixes some issues with the original implementation of the CDF inverse for Gaussian kernels, cleans the mathematical formulas and fixes the Epanechnikov normalization term.
Other fixes and improvements include:
In 'volprim_prb', we also now handle correctly the case of distance sampling a single Gaussian, routing it to the analytical solution instead of the solvers.
Swapped ray-ellipsoid intersection method to a more accurate one that does not require a different solver.
Support for Mitsuba 3.9 and DrJIT 1.4, no need to install the stale mitsuba branch anymore :)
This PR is in preparation of a larger release supporting Gabor Fields (https://arcanous98.github.io/projectPages/gaborVolumes.html)
