Can separate circumsphere radius from inter-sample distance

Sphere packings can be created efficiently
Packings can be modified for improved quality
Sphere-packings can create the Voronoi crust, a variant of power crust.
• Flip which points are weighted,and which are unweighted
Good-quality polyhedral Voronoi meshes can conform to the Voronoi crust

Summary Message
Good-quality Delaunay and Voronoi meshes can be created
by sphere-packing, instead of traditional Delaunay refinement.
• Flip the role of triangle quality and circumsphere radius
Can separate circumsphere radius from inter-sample distance
• using different values provides flexibility
Sphere packings can be created efficiently
Packings can be modified for improved quality
Sphere-packings can create the Voronoi crust, a variant of power crust.
• Flip which points are weighted,and which are unweighted
Good-quality polyhedral Voronoi meshes can conform to the Voronoi crust
