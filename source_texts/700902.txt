Summary
Implement an Octotree-based spatial index to accelerate triangle intersection detection.
Changes
Added an AABB (Axis-Aligned Bounding Box) representation with intersection and containment checks.
Implemented Octotree with recursive node subdivision and object insertion.
Added spatial queries to retrieve objects whose bounding boxes intersect a given region.
Integrated Octotree into FindIntersectingTriangles(), replacing the naive all-pairs search with broad-phase filtering.
Kept the existing triangle intersection algorithm for narrow-phase geometric checks.
Added unit tests covering tree construction, insertion, subdivision, duplicate IDs, and spatial queries, including boundary cases.
Testing
Added Google Test coverage for Octotree.
Verified spatial query behavior and object retrieval from both parent and child nodes.
Checked boundary-touching and non-intersecting cases.
