Summary
Adds deterministic organic terrain material patches to the semantic mask terrain renderer.
Uses multi-scale fbm, domain-warped noise, and cellular feature points to produce coherent patches instead of random per-tile spam.
Applies biome-aware variant looks: dry dirt/lush/meadow grass, dunes/rock/scrub sand, blue ice/outcrop/tundra snow, cinder/ember ash, and wet beach flecks.
Keeps gameplay semantic truth untouched: patch accents are visual-only, avoid roads/rivers/lakes/mountains/POI footprints, and preserve existing walkability.
Notes
The normal overworld path uses the semantic mask terrain cache, so this lands in the visible renderer rather than only the raw tile debug path.
Terrain patch overlays reuse the active semantic terrain material pool where possible, then add low-alpha color/fleck accents for rule-of-cool variety.
Testing
Not run in this environment; repository checkout/build dependencies are not available here.
