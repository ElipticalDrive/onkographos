Deferred experiment, September 9, 2026
Use authored rasterized polygon actors for the active playable visual iteration in #28/#32. Revisit this issue only when a required body needs blends/cuts/deformation that the polygon authoring route cannot provide cleanly, or measured lighting comparisons justify the work. Compare the same actor and crowded scene, with image/readability and frame-cost evidence, before adopting SDFs.
Parent: #28
Implement one bounded SDF geometry asset with blends/cuts/extrusion/deformation. It must write true hit depth and normals and intersect opaque meshes correctly. Expose bounds/step diagnostics and compare quality/cost with a mesh version.
Compare direct lights/shadows/bloom, 3D radiance cascades and one bounded probe-based indirect-lighting alternative in the SAME visual-showcase scene. Include offscreen emitters/occluders, thin walls, moving lights, camera cuts and dense combat. Record image artifacts, temporal stability and per-pass GPU time.
Choose the default from visual and performance evidence. Current 2D HRC is not 3D GI. three-rc is an architectural reference, not licensed implementation code to vendor. Keep a written adoption/rejection decision; the goal is beautiful readable imagery, not a particular algorithm.
