Goal
Normalize W1–W8 integer quantization, FP8, MXFP4, NVFP4, MXFP8 and future formats through one versioned semantic quantization descriptor, while retaining multiple target-specific packed layouts and arithmetic/dequant families. The descriptor is a common contract; one compulsory physical layout or dequant-to-FP8 path would waste bandwidth and can defeat native tensor operations. Do not claim every format is currently executable on GB10.
Existing implemented seams / ownership
CUDApp main b759afc3f5e46f152ffb06b39882ffa28cacaf96 and omega-mv main 6999fa9e6dae4847c155ef4eacaece74f491d3ca inspected 2026-10-28. Reinspect heads, active branches and complete source/receipts before editing.
Native .om exact format oracles: native/models/mxfp4.om, nvfp4.om, fp8.om, mxdot.om; MXFMT.
FP8 weights/scales and GEMV/GEMM: src/omega_gpu_fp8_api.{c,h}, src/omega_gpu_fp8_pack.c, src/omega_gpu_fp8gemm_api.c. Semantics/type authority: Omega #663; checked tensor lowering CUDApp #35. Existing specialized lossless Inventory FP8 zero channels and implement lossless native weight packing #48 and approximate Evaluate rotation-aware low-bit weights at equal total storage and measured quality #49/Evaluate structured expert factorization with residuals after structural-zero accounting #50, packed-expert [SEM-MOE-K1 P3] Implement opt-in native .om packed-expert decode, verify traffic and GB10 output #78 are separate experiments; reuse instead of replacing them.
Current hardware encoding is the native sm_121 Omega spec/encoder PR #155. FP4 warp-level block-scaled MMA on sm_121a is a candidate requiring own encoded-byte, simulator, device and numerical evidence; do not route through datacenter tcgen05/TMEM on GB10.
Delivery slices
Freeze a canonical, serializable quant descriptor: element encoding and signedness; scale/zero-point dtype, value semantics and shape; group/block sizes and axes; packed bit order/endianness; tensor shape/strides/alignment; rounding/saturation/subnormal/NaN/Inf behavior; effective precision; zero/missing/invalid cases; numerical contract ID and exact/approx classification. Quant metadata must influence identity.
Define distinct semantic format IDs and physical target-layout IDs, a capability/legality table and explicit refusal for unsupported W1–W8/FP formats or invalid combinations. Preserve source bytes/weight identity for lossless transforms.
Implement bounded native .om repack plans for supported formats at model load/preparation, not per token. First slice: existing FP8 E4M3 and one W4/block-scale format with independent exact decode oracle; compare packed weight + scales + alignment and scratch with incumbent. Add other W widths as bounded adapters, not guessed behavior.
Expose verified load/dequant component contracts to a single native GPU realization path (future KSTITCH issue). Dispatch may choose native low-precision MMA, on-chip fused dequant+MMA or verified BF16/FP8 fallback per target/shape, preserving physical storage benefits. No compulsory full expanded DRAM copy.
Measure total loading/repack, resident bytes, weight-read traffic, warm/cold latency, TTFT/TPOT and model-level quality before promoting a lossy representation. Reuse #16, #17, #53 and #57. Reuse packed MoE decode #78 only for a qualified format/producer.
Acceptance / negative gates
Versioned descriptor round-trips and stable hash across native adapters; independent W4/FP8/MXFP4/NVFP4 fixtures, blocks, ragged tails and scale boundaries.
Signed zero, nonfinite/subnormals, zero-point offset, block stride, bit order, scale overrun, malformed/unknown tags and stale-layout mutants cause precise correct output or rejection.
Byte-exact lossless repack; separately bounded error plus held-out logits/tokens/quality for approximations. Source and target numerical assumptions remain declared.
At least one GB10 consumer executes an accepted packed format without forced whole-weight expansion; total bytes and runtime vs incumbent reported, including NO-GO.
Encoder/runtime does not silently claim native low-bit ops where chip verification is missing.
Delivery rules. New first-party production code/tests are native seeded .om; C sources can serve as migration/differential oracles until qualified cutover under #79. Preserve immutable receipts, one writer per shared file, no second GPU session/driver/IR/compiler. No silent CUDA/PTX/cuBLAS dependency. Keep the live 35B, driver and hardware scheduling unchanged; chip tests require an authorized GB10 window. Label HOST_TESTED/SIMULATED/CHIP_EXERCISED/WHOLE_MODEL_QUALIFIED separately; NOT_RUN/BLOCKED cannot become PASS. Record exact source/seed/compiler/target/binary/model hashes, commands/exits, positive and mutation results, baseline/variant raw timings.
Workstream links (2026-10-28)
This format descriptor is consumed by #157 component stitching, #158 cache identity, #57 dual-pipeline selection and #159 grouped MoE. Versioned tensor/dtype semantics stay with Omega #663. Do not activate in serving until the full #5/#106 consumer cutover and #16/#17 qualification.
