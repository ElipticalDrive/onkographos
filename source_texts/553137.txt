Abstract—Recent advancements in neural network (NN)
hardware and software have introduced 8-bit Floating-Point
(FP8) format as promising candidate for reducing memory
usage and computational overhead. This article investigates the
potential for further compressing FP8) data by applying
Golomb–Rice (GR) coding. In the FP8 format, the 8 bits are
allocated to represent the sign, exponent and mantissa using
natural binary encoding. To achieve efficient compression, the
GR code, a variable-length, lossless coding scheme, is applied
exclusively to the exponent bits. In this way, data storage savings
could be achieved, which can be very significant when the large
amount of data has to be stored, such as storing NNs.

II. DESCRIPTION OF THE MODEL
A. Modification of the Floating-Point Format with 8 Bits
The Floating-Point Format with 8 Bits, as illustrated in
Fig. 1, uses Rs=1 bit for sign, Re=4 bits for exponent and Rm=3
bits for mantissa 5]-[8. On the other hand, the modified
version keeps the fixed number of bits: Rs=1 for sign and Rm=3
for mantissa, but introduces the coding of the exponent with
variable length code, as illustrated in Fig. 2. The principle is
simple: use shorter codes for the more frequently occurring
symbols and vice versa, since the idea is to obtain the average
code length less than 8 bits.
Keywords— Floating-Point, Golomb–Rice code
I. INTRODUCTION
Although 32-bit Floating-Point (FP32) format and 16-bit
Floating-Point (FP16) format remain the most commonly used
formats in training and inference of neural networks (NNs), 8bit Floating-Point (FP8) format is gaining attention due to its
potential to offer a favorable trade-off between model
accuracy and efficiency. The latest computers and GPU
support its usage 1, 2]. In this research, we have been
motivated by the idea to further make a saving in the memory
space for storing the data. For this reason, we propose a
modified FP8 format that incorporates the variable length
coding. Golomb-Rice (GR) code is chosen for this purpose
due its simplicity in encoding and decoding 3, 4. Average
code length for different values of variance is computed.

B. The Golomb–Rice coding technique
The Golomb-Rice (GR) coding technique, which belongs
to the group of the variable length codes, is based on the
following principles: number n is decomposed with divisor m
into integer quotient q and a remainder r, i.e. 3:
n = qm + r  n, m, q, r  N 
()
m = 2k  k  N 0 
()
The number n is coded as follows: the quotient q is coded
unary, i.e. an array of q ones is written, then a zero is put in
order to serve as decimal point, and in the end the remainder
r is natural binary coded on k bits. Depending on the
parameter k, the GR coding can be performed in many ways.
For this particular research, examined are variants for k=0,
k=1 and k=2, as shown in the Table I. Si represents the code
itself and li is length. It should be noted that only rows for n
equal from 0 to 15 are employed in the case with Re=4 bits
for exponent, and all given rows (for n equal from 0 to 31)
are employed in the case with Re=5 bits for exponent.
Decoding is done in this way: number of ones before the
first zero, i.e. decimal point, is counted, which represents
quotient q. Then the k bits after the zero are identified and
they represent binary record of remainder r. Since k, q and r
are known, the number is calculated with formulae (10) and
(11). Starting from the (k+1)-th bit after decimal point, the
decoding process continues with counting ones until the next
zero.

IV. DISCUSSION
The numerical results show that obtained total average
code length are in the most cases less than 8 bits,
demonstrating that the proposed model provides the saving for
the data storage. However, for data processing the information
must be decoded back into the standard FP8 format, which
will be the subject of future research.
