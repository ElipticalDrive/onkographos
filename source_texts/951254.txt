Descripción
Implementar CCD aprovechando SDFs. SDF sphere-tracing hace CCD trivial: marchar a lo largo del vector velocidad, con step size = SDF(p), guaranteed no-miss. Evita tunneling para proyectiles y objetos rápidos sin el costo de CCD geométrico.
Tareas
Flag per-entity: ccd_enabled: bool (solo para objetos rápidos)
CCD pass (compute): sphere-trace a lo largo del velocity vector
Time-of-impact (TOI) calculation: fracción del frame donde ocurre la colisión
Sub-step position correction: mover al punto de impacto
CCD vs SDF world (static geometry)
CCD vs SDF objects (dynamic SDF entities)
Velocity threshold: solo activar CCD si |velocity| * dt > shape_radius
Benchmark: CCD overhead para 100, 1000, 10000 projectiles
Criterios de Aceptación
Bullet (radius 0.05, velocity 100m/s) no atraviesa pared SDF de 0.1m
TOI correcto dentro de 1% del frame time
CCD overhead < 0.1ms para 100 CCD entities
Sin false negatives (tunneling) para velocidades razonables (< 500m/s)
Ejemplo de Código
```
// CCD via SDF sphere tracing along velocity
struct CcdResult {
    hit: u32,
    toi: f32,          // time of impact [0, 1] within frame
    hit_point: vec3<f32>,
    hit_normal: vec3<f32>,
}

@compute @workgroup_size(64)
fn ccd_sweep(@builtin(global_invocation_id) id: vec3<u32>) {
    let idx = id.x;
    if idx >= params.ccd_count { return; }
    
    let entity = ccd_entities[idx];
    let pos = positions[entity].xyz;
    let vel = velocities[entity].xyz;
    let radius = shapes[entity].radius;
    let displacement = vel * params.dt;
    let max_t = length(displacement);
    
    // Skip if displacement < radius (no tunneling risk)
    if max_t < radius { 
        ccd_results[idx] = CcdResult(0u, 1.0, vec3(0.0), vec3(0.0));
        return; 
    }
    
    let dir = displacement / max_t;
    var t = 0.0;
    var result = CcdResult(0u, 1.0, vec3(0.0), vec3(0.0));
    
    for (var i = 0u; i < 64u; i++) {
        let p = pos + dir * t;
        let dist = eval_scene_sdf(p) - radius; // shrink by radius for Minkowski sum
        
        if dist < 0.001 {
            result.hit = 1u;
            result.toi = t / max_t;
            result.hit_point = p;
            result.hit_normal = calc_sdf_normal(p);
            break;
        }
        
        t += dist; // guaranteed safe step (SDF property)
        if t >= max_t { break; }
    }
    
    ccd_results[idx] = result;
}
```

Notas Técnicas
SDF CCD tiene complejidad O(1) por query (vs O(n) para mesh CCD)
El step size = SDF(p) es el safe step guarantee de sphere tracing
Para CCD entre dos objetos dinámicos, usar relative velocity en el frame del segundo
