Owner
Select one straight edge on a current solid, choose Chamfer…, enter a positive equal distance, then Preview/Apply. The result is an independent editable Chamfer feature in ordered history, rather than a change to the source extrusion.
Implementation
Native OCCT BRepFilletAPI_MakeChamfer, kernel validity/one-solid/volume checks, and refusal of automatic tangent-chain propagation.
Conservative edge witness scoped to the explicit upstream body: checked segment endpoints and the two adjacent faces' construction ancestry. No persistent viewport index, nearest-edge substitution, or cross-body fallback.
Existing face lineage propagation plus a native bevel construction origin; supports face sketches and further solid operations on the result.
Shared toolbar/tool-island command and existing OperationPanel candidate-document preview actor. Preview is explicit, avoiding a full evaluation on every keystroke. Cancel does not modify history.
Browser entries and color marker; Properties distance editing with stable UUID; History parameters, target/edge references, dependencies and diagnostics.
Atomic failed creation/direct distance edits. Upstream-invalidated unchanged chamfers retain definitions as unresolved and recover via normal Undo/Redo.
Minimal v12 parameter serialization; existing v1–v11 documents remain readable and files without chamfers keep their previous minimum format version. No dependencies added.
Workflow, reference boundary, persistence and limits: docs/CHAMFERS.md.
Validation
643 passed in the complete software-OpenGL/XCB suite (195.72 s), no skips.
44 passed in final chamfer/document kernel checks, including bounds, exact volume reduction, bevel normal and solid validity.
8 passed in focused UI checks: real edge selection, action availability, exact/invalid distance entry, preview/cancel, commit, browser/Properties/history, failed edits, Undo/Redo, save/reopen and subsequent picking. Includes a nonblank rendered-solid framebuffer assertion.
Covers standalone Join/Cut and extrusion histories, an eight-bore cut solid, native tangent-chain refusal, conservative upstream preservation/loss, recovery, bevel-supported sketch transport, downstream Cut and separate subsequent chamfers.
pip check and git diff --check: clean. Uploaded source tree verified identical to the tested local tree.
Local Ubuntu 24.04, pinned Python 3.12 environment, real software rendering. CI covers Ubuntu 22.04/24.04. Remaining warnings are VTK/NumPy array-shape deprecations.
The initial full run exposed a nondeterministic test fixture and a legacy assertion forbidding chamfers in the tool island; both were corrected before the passing full run.
Deliberate limits
One straight edge and equal distance per feature. Curved edges, multiple-edge operations, tangent chains, unequal/angle/variable chamfers and fillets are deferred. Changed segment geometry or adjacent ancestry may make a feature unresolved; edge reassignment/general topological naming is not implemented. Equal distance is nominally 45° at a right-angle corner.
Preview and commit retain sequential regeneration, so complex connected solids can remain slow. The user's large torture-test file was unavailable; no private models were added. v12 chamfer files require the updated application.
