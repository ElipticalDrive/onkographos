A new demo next to the existing ray caster (raycast.asm is unchanged):
src/scripts/gen_raycast_tex.py generates raycast_tex.asm with the same maze, movement and demo walk, plus textured walls. There are seven 32 × 32 textures drawn by the script: stone, brick, wood, riveted metal, mossy stone, a circuit board with a 22V10, and a framed Mandelbrot picture.
Each column works out where the ray hit the wall (two 8 × 8 multiplies), mirrors u so no face is back to front, and copies the texture column through a shading table into zero page x68-x87 (y sides darker, plus 4 distance levels). It then draws the wall with compiled scalers: exact heights 1-30, every other height up to 56, and 8 levels for clipped walls.
The HT/DD tables move to RAM x0100-x1DFF and x4200-x46FF, so the program runs with map 05 and can use ROM x2000-x3FFF (textures) and x6000-xBFFF. Because it uses all of that ROM it isn't in the demo menu ROM.
test_raycast_tex_sim.py checks every view against the Python model. 600 views pass, at 229k-261k clocks a view, so it still runs at 60 views a second.
Also adds build\raycast_tex.bat, raycast_tex.hex (customasm 0.14 output matches placard_sim.py), a README section and reference/raycast_tex_sim.gif.
