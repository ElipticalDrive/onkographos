# Ray Tracing Renderer (C++)

本项目基于 C++ 从零构建了一个基于物理渲染（PBR）理论的高性能光线追踪渲染引擎，完整打通了从底层数学模型、空间加速结构到最终图像生成的全链路渲染流程。

## 核心特性

- **物理材质系统**：实现了多种基于物理的材质模型，精确模拟光线与不同表面的交互行为，支持Lambertian (漫反射)、Metal (金属) 和 Dielectric (电介质) 等材质，支持菲涅尔反射与折射。
- **BVH 加速结构**：引入包围体层次结构 (Bounding Volume Hierarchy)，大幅降低光线求交的时间复杂度，提升渲染效率。
- **高级相机模型**：模拟真实相机光学特性，支持可调节光圈与焦距，支持景深 (Depth of Field) 效果。
- **程序化纹理**：基于 Perlin Noise 实现了棋盘格、大理石等纹理生成。
- **多线程并行**：利用 OpenMP/STL Threads 进行像素级并行计算，充分利用多核 CPU 性能。

## 技术栈与环境

- **语言**: C++17
- **构建工具**: CMake (3.15+)
- **IDE**: Visual Studio 2019 / 2022
- **依赖库**: `stb_image` (纹理加载) 

## 如何开始 (Windows)

本项目使用 CMake 管理构建，推荐使用 Visual Studio 打开。

1. 确保已安装 [Visual Studio](https://visualstudio.microsoft.com/) 并勾选了 "使用 C++ 的桌面开发" 工作负载。
2. 打开 Visual Studio，选择 **"打开本地文件夹"**，选中本项目的根目录。
3. VS 会自动识别 `CMakeLists.txt` 并生成缓存。
4. 在顶部工具栏选择 `x64-Release` ，Release 模式下渲染速度更快。
5. 点击顶部的绿色三角形按钮或按 `F5` 运行。
