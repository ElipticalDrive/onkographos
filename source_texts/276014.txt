Describe your change:
This pull request adds an implementation of the KD-Tree data structure along with related functionalities, such as nearest neighbor searches.
Definition: The KD-Tree is a space-partitioning data structure used for organizing points in a k-dimensional space. (URL: KD-Tree)
Implementation Details:
build_kdtree.py: Contains the function to build a KD-Tree from a set of points.
nearest_neighbor_search.py: Implements the nearest neighbor search algorithm using the built KD-Tree.
kd_node.py: Defines the KDNode class representing nodes in the KD-Tree.
Example Usage:
hypercube_points.py: Provides a function to generate random points uniformly distributed within an n-dimensional hypercube.
example_usage.py: Demonstrates how to use the KD-Tree implementation with the generated random hypercube points and querying for nearest neighbors.
Unit Tests:
test_kdtree.py: Validates the correctness of the KD Tree implementation, including tests for building the tree, querying for nearest neighbors and testing edge cases.
Reference
The Algorithm Design Manual, Latest edition
