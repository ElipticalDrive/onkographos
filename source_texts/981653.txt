Implemented
Two variants share the local image pyramid in ommatidia/src/neural.rs, with separate observation adapters and task heads:
Realtime transport: multiscale diffuse/specular reconstruction, linear recurrent state, moments/confidence and short differentiable unrolls.
Experimental field: posed linear RGB and declared acquisition bounds → image-aligned 3D features → density, emission, view-dependent radiance and constant environment. No G-buffer, velocity, true lights, target depth or scene-ID embedding enters inference. No blade-volume integration.
The field default is wider (64 core channels / 128 hidden units versus the realtime path's 8 channels). Equal-width core shapes are compatible. Shared implementation is not evidence of successful weight transfer or a learned universal transport model.
Source and incident-radiance supervision
Static synthetic captures export exact emitter meshes/radiance, cameras, environment and source/non-source surface probes. Independent lighting seeds change source colour/intensity without moving geometry or cameras.
--incident-probes 24 --incident-batches 8 adds training-only angular incident-radiance labels using the same canonical Blade path tracer as image capture. Manifest v2 stores actual offset world-space origins, unit directions, direct/indirect RGB means, variance of each mean, paired total variance, path depth, batch budget, offsets and radiance ceiling. V1 without incident labels remains supported. Labels are finite-depth, clamped Monte Carlo estimates—not exact infinite-bounce truth. Sampling variance cannot measure truncation bias or unobserved rare paths.
Direct means first-visible source emission or sky; indirect means at least one scattering event beyond the receiving probe. Targets are radiance, not receiver-shaded colour or irradiance: no receiver albedo, cosine, inverse-square multiplier or PDF weighting is baked in. Emitter-aimed and hemisphere proposals are regression strata, not angular quadrature.
field --incident-rays 4 --incident-weight 0.1 couples these targets to the existing field, without adding a separate incoming-light head or new neural parameters:
```
direct   = sum(T * alpha * emission) + T_end * environment
indirect = sum(T * alpha * scattered_radiance)
incident = direct + indirect
```
Image and incident rays constrain the same density/visibility, emission, appearance and image encoder. The auxiliary direct/indirect log-radiance loss uses bounded uncertainty weights. Weight zero preserves graph, rays, initialization and random sampling; only loss masks differ. Missing labels are rejected when incident training is requested. Runtime observations/context exports contain no supervision metadata.
The incident loss remains opt-in for the field experiment. Realtime training is unchanged; no joint-training or realtime-quality gain is claimed. Existing field parameter shapes/checkpoints remain compatible. The appearance branch still models captured illumination, not a relightable BRDF/transport operator.

Quality ablation — mixed, not promoted
bash benchmarks/incident-lavapipe.sh: two fitting geometries under two light seeds, two fitting-disjoint evaluation geometries under a third light seed, six 16×16 cameras each, 24 incident probes, and 128 updates. Repeat with optimization seeds 7/11. Both arms use the same tiny 4-channel/16-hidden model, query counts and initialization; only incident weight 0/0.1 differs. Checkpoints are reloaded before held scoring; no held metric selects a checkpoint or tunes a parameter.

Research boundary: the implementation supplies a tested physical supervision route, not reliable geometry recovery, arbitrary relighting, cross-task transfer, a new realtime checkpoint or DLSS parity.
