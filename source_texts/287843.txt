Bootstraps the repository as a full Angular + Three.js voxel painting app with a top-down orthographic view, stylus-aware drawing, instanced rendering, and volume culling.
Core services
VoxelStoreService — maintains voxel map keyed by "x,y,z", drives reactivity via Angular signals, culls fully buried voxels (6-face neighbor check) before handing data to the renderer; exposes brushSize (1–5) and brushShape (square/round) signals with getBrushPositions and getEraseFootprint helpers
VoxelSceneService — THREE.OrthographicCamera locked to top-down Y axis; rebuilds a single THREE.InstancedMesh (up to 100k voxels, one draw call) with per-instance color via setColorAt whenever the store's version signal ticks; supports scroll-zoom and drag-pan; viewHalfW is derived from canvas width at init (~40 CSS px/voxel)
Input handling (VoxelCanvasComponent)
Consumes raw PointerEvents — works for mouse, touch, and any Web Stylus API compliant device:
```
// Pressure maps to height layer (0–2); tiltX/tiltY (azimuth) captured
const pressureY = Math.round(this.pressure * 2);
this.store.addVoxels(this.store.getBrushPositions(x, z, pressureY));
```
Pointer capture (setPointerCapture) keeps strokes clean across fast movement. Middle/right button pans; scroll wheel zooms. Pixel→world mapping uses THREE.Vector3.unproject(camera) for accuracy.
Rendering details
Voxel geometry is full VOXEL_SIZE — voxels are flush with each other
Unlit MeshBasicMaterial — rendered color matches the chosen palette swatch exactly, no lighting influence
Y-axis is correctly oriented: drag-down reveals larger-Z world; pixelToVoxel uses Three.js inverse projection consistent with the live camera state
Only exposed-face voxels reach the GPU; stack a voxel completely surrounded and it disappears from the draw list automatically
Batch addVoxels / removeVoxels trigger a single mesh rebuild per stroke
Brush options
Size 1–5 — half-extent r = size − 1; buttons in toolbar
Square shape — places a flat (2r+1) × (2r+1) slab at the current pressure height
Round shape — places a filled sphere in all three axes (larger sizes build 3D structure); eraser uses a matching disk footprint
UI
13-color palette toolbar, brush size (1–5) and shape (⬛/⚫) toggles, eraser, and clear-all; hint bar for controls.

Done in commit 7cc8a23. Here's what changed:
Y-axis fixed — pan direction corrected (panZ += on drag-down) and pixelToVoxel now uses vec.unproject(camera) so screen→world mapping is always consistent with the camera state
Increased voxel resolution — viewHalfW is now derived from the canvas width at init time (targeting ~40 CSS pixels per voxel), so the grid fills the canvas naturally regardless of window size
Flush voxels — geometry is full VOXEL_SIZE (removed the previous 8% gap); same-color adjacent voxels merge into a solid surface as expected
Pure color — switched from MeshLambertMaterial + lights to MeshBasicMaterial (no lighting); rendered color now exactly matches the selected swatch
Brush options — added Size 1–5 and Shape ⬛ square / ⚫ round buttons to the toolbar. Square places a flat (2r+1)×(2r+1) slab at the current pressure height; round places a filled sphere in all three axes (so larger sizes build up 3D structure). The eraser also respects the brush shape (square footprint vs disk footprint).
