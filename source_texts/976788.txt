# FloodSim-Mesh-Generator

このプロジェクトでは，点群データを統合し，メッシュを生成する Jupyter Notebook mesh_generation.ipynb を提供する．

## ファイル構成

```plaintext
.
├── sample/                 # サンプルデータを格納するフォルダ
├── mesh_generation.ipynb   # メッシュ生成のためのJupyter Notebook
├── requirements.txt        # 必要なPythonライブラリのリスト
```

## 必要な環境

Python 3.x がインストールされていることを前提とする．また，必要なライブラリは requirements.txt に記載されている．

## ライブラリのインストール

以下のコマンドで必要なパッケージをインストールできる：

```bash
pip install -r requirements.txt
```

## 使用方法

sample/ フォルダ内に処理対象の点群データ（.ply 形式）を配置する．

Jupyter Notebook を起動する：

```bash
jupyter notebook mesh_generation.ipynb
```

Notebook の各セルを順番に実行し，点群の統合とメッシュ生成を行う．

本プロジェクトでは，点群データの統合処理において，z 軸および x 軸を用いた回転を適用し，最適な位置合わせを行う．この処理により，点群の適切な統合が可能となる．

mesh_generation.ipynb の後半部分は，すべての前処理が完了した状態を前提としており，単に実行することでメッシュ生成が完了するように設計されている．

## 依存ライブラリ

```plaintext
open3d
numpy
os
```

詳細は requirements.txt を参照のこと．

## 注意点

sample/ 内のファイル名はスクリプト内で指定されているため，適宜変更が必要な場合がある．

open3d を利用するため，環境によっては追加の設定が必要な場合がある．
