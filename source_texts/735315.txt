# cub3D

cub3D is a graphical 3D game developed in C as part of the 42 school curriculum. The project is inspired by "Wolfenstein 3D" and uses the raycasting algorithm to render a pseudo-3D environment from a 2D map. The graphics are handled using the MiniLibX library.

## Project Overview
This project is written in C and utilizes the MiniLibX library for window management and rendering. Main features include:

- Reading and validating map files (.cub format)
- Raycasting engine for 3D rendering
- Texture mapping for walls and sprites
- Player movement and rotation
- Handling keyboard events for navigation
- Error management and input validation
- Strict adherence to 42 coding standards

## How to Compile
Note: The MiniLibX library used in this project is compatible with Linux.

To build the game, simply run:

```
make
```

This will produce the executable file `cub3D`.

## Usage
Run the game with a valid map file:

```
./cub3D map.cub
```
