Voxelization of Particles
Question
Hey everyone. I’ve been considering adding something similar to Unreal Engine’s particle-driven volumetric fog to my volumetric rendering plugin for Unity.
In general, I think the algorithm is pretty doable to implement—I’ve already got a froxel-based fog that uses a height-based distribution up and running.
The tricky part for me is figuring out how to efficiently take hundreds (or possibly thousands) of particles and efficiently voxelize them into the camera-aligned froxel buffer.
My instinct would be to bind a compute buffer with the particle info to a compute shader, and run a separate thread to voxelize each particle in parallel.
The problem I see with this is that multiple particles can write to the same froxel. I imagine this isn’t a safe thing to do (maybe it is though and I’m mistaken?).
The only alternative I can think of is doing it one by one, but that’s definitely gonna be way too slow.
I guess my final question is: is there a way I can accumulate multiple density samples into the same RW texture pixel from different threads in a compute shader?
