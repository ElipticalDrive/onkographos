Summary
Adds LOTUS-RESTIR-02: opt-in initial reservoir direct lighting at jittered primary surfaces under both reference and wavefront integrators. Reconstructible emissive, analytic and environment samples carry consistent proposal measures; selected-sample visibility and BSDF-emission partitioning prevent double counting. Later bounces retain NEE/MIS.
Includes a Slang reservoir implementation checked against the CPU oracle, packed debug products, separate GPU timing, memory accounting and numerical-failure handling. The roadmap now proceeds to temporal reservoir reuse.
Related work: LOTUS-RESTIR-02.
Impact
Vulkan/core API: adds LightSampling::RestirInitial, a bounded candidate count and reservoir evidence. MIS remains the default.
Both integrators and temporal radiance compatibility include the new mode. Temporal/spatial reservoir reuse and Hydra reservoir controls remain separate tasks.
Installed shader paths stay the same; core and Hydra consumers were rebuilt and tested.
Updates the reservoir contract, capability matrix, roadmap and Unreleased changelog. No many-light speedup is claimed.
Verification
Core build and CTest: 26/26 passed; strict renderer evidence passed.
Hydra/lookdev build and CTest: 51/51 passed, including install-tree and usdview; strict renderer evidence passed.
Runtime-free build and CTest: 14 passed, 2 explained GPU SKIPs.
Documentation checks and 27 Python tests passed; git diff --check passed.
GPU validation: 4,096 CPU/GPU reservoir comparisons per integrator, independent lighting integrals, fractional/opaque visibility, lifecycle/overflow checks and 1,024-spp NEE/MIS comparisons, including Cornell image tiles.
Measured on Windows/MSVC Release with NVIDIA RTX A5000 and OpenUSD 26.08. Fixtures use sample index 17 and eight initial candidates. Details, tolerances and commands: validation report. PFM images and logs are retained locally under build/.
