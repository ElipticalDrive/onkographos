Things to know when merging
Rendering changes on purpose in Remove the RAY_EPS origin offset from the Ray constructor #71, Light tracer: spawn rays with SpawnRay; remove RAY_EPS #73 and PT: skip direct lighting at delta BSDFs #74. Each PR has before/after comparisons at high sample counts (block heatmaps, noise references). None introduces artifacts; Remove the RAY_EPS origin offset from the Ray constructor #71 and PT: skip direct lighting at delta BSDFs #74 remove biases.
API: the Ray constructor is now Ray(orig, dir, tmax = INF, medium = nullptr). The tmin parameter and Ray::mTmin are gone, as are RAY_EPS, Intersection::mRayEps and HeartSurface (with its two scenes in GyunityApp).
Tests: GyunityTest.exe now exits non-zero when a test fails.

The last PR (#79) ran on exactly the tree of this branch: all eight regression images (CornellBoxMesh, CornellBoxMeshWithSlope, EnvironmentMapScene, CornellBoxSphere) are byte-identical to the baseline.

Light tracer: spawn rays with SpawnRay; remove RAY_EPS
…
027c28c
```
LightTracing built its rays by hand: Ray(isect.mPos + dir * RAY_EPS, dir)
for the light ray and each bounce, and Ray(pos, dirToCamera, length) for
the camera connection. Since #71 the Ray constructor no longer adds an
offset, so the camera connection started exactly on the surface and
could hit it again.

All three now use Intersection::SpawnRay (OffsetRayOrigin, based on the
hit point's error bound), like the other integrators. The camera
connection's tMax is the distance from the offset origin to the camera.
RAY_EPS is no longer used and is removed.
```

PT: skip direct lighting at delta BSDFs
…
de4e6ef
```
Next-event estimation can't contribute at a perfectly specular surface:
the BSDF is zero for any sampled light direction. Light reached through
a specular bounce is already counted when the BSDF-sampled path hits the
emitter (deltaBoundEvent). Skipping it saves a shadow ray per specular
vertex and stops consuming random numbers there.
```

Sphere: return hit details; fix occlusion test; stop using Ray::mTmin
…
fa49291
```
Spheres never worked: every scene with a sphere crashed.

- Intersect(ray, isect, t) built the full hit (position, normals,
  shading frame, error bounds) and discarded it: mObjectToWorld(it) was
  not assigned to *isect. Sphere doesn't implement QueryIntersectionInfo,
  so hits had a zero normal, IsSurfaceScatter() returned false, and
  DirectIllumination read the surface hit as a MediumIntersection
  (invalid mPhase pointer).
- Intersect(ray), the occlusion test, discarded mWorldToObject(ray) and
  tested a default Ray with a zero direction: tHit was NaN, which passed
  the range check, so every candidate sphere reported 'occluded'.
- Sample(pdf, u) set mAbsNormal from mNormal before mNormal was
  computed, so it was always zero.
- Hit tests reject tHit <= 0 instead of tHit < r.mTmin (#68). Ray.h's
  deprecation comment now lists only Transform.
```
