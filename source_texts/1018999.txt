Implements a full-screen GLSL fragment shader featuring time-based animation, noise generation, and physically-based light scattering using WebGL + Three.js.
Changes
New shader: /public/shaders/light-scattering.frag
Time uniform drives animated light source, particle motion, atmospheric effects
Resolution uniform handles responsive sizing and aspect ratio
Noise: Perlin 2D/3D, FBM (6 octaves), hash-based PRNG
Light scattering: Rayleigh/Mie phase functions, volumetric ray marching (32 steps), god rays (16 samples), atmospheric fog
Updated WebGLBackground.tsx
Loads light-scattering.frag instead of atmosphere.frag
Resolution uniform now updates on window resize
Fixed resize handler cleanup with ref pattern
Demo page: /shader-demo
Full-screen shader demonstration with feature overlay
Config: next.config.mjs
Added turbopack config for Next.js 16 compatibility

```
// Rayleigh scattering for atmospheric blue
float rayleighPhase(float cosTheta) {
    return (3.0 / (16.0 * 3.14159)) * (1.0 + cosTheta * cosTheta);
}

// Volumetric light via ray marching through 3D noise density
float volumetricLight(vec2 uv, vec2 lightPos, float time) {
    // 32 steps through volume, accumulating density
    for (int i = 0; i < 32; i++) {
        float t = float(i) / 32.0;
        vec2 pos = lightPos + dir * dist * t;
        float density = noise3d(vec3(pos * 3.0, time * 0.1));
        rayStrength += density * stepSize * (1.0 - t);
    }
    return rayStrength;
}
```
