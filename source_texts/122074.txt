Efficient space leaping for ray casting architectures
In this paper, we present an efficient space leaping mechanism which requires only a small amount of SRAM (4 Kbit for a 256 3 volume) and can be easily integrated into ray casting architectures. For each sub-cube of the volume, a bit is stored in an occupancy map, which can be generated in real-time, using the VIZARD II architecture.
