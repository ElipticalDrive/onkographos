Description
Game world is currently a flat 200x200m plane. Procedural terrain generates height and landscape from block-based voxel data. MEGA share has Voxels/ block textures and block.obj.
Acceptance Criteria
Terrain generates procedurally from a seed
Terrain has height variation (hills, valleys, flat areas)
Block textures from Voxels/ assets applied to terrain surfaces
Terrain is walkable — player can traverse height changes
Player collision works on generated terrain (no falling through)
Terrain generates around player's position (ties into Chunk Generation)
Performance: terrain renders at playable framerate on all three platforms
Test: generate from two different seeds, verify different landscapes
Test: player walks across terrain without falling through or getting stuck
Proposed: Noise Algorithm (to confirm)
No noise algorithm is in the code yet -- both the-uninvited and GameCore use a flat or hand-built ground, and the only randomness is rand() for grass scatter. Proposal: FastNoise Lite (single header, MIT licence) using OpenSimplex2 layered in octaves (fractal Brownian motion) for the height field, seeded from the world seed. OpenSimplex2 avoids classic Perlin's grid-aligned artefacts. Open for Mike and Aaron to confirm or change before work starts.
