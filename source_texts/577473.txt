Owner
Adds 3D Gaussian splatting as a first-class scene citizen. Load a .ply or .splat capture, attach a SplatComponent, and the set composites with the forward-rendered PBR scene, depth-tested against opaque geometry and blended premultiplied.
A set draws as one instanced batch of screen-space Gaussian footprints, its per-splat covariance, color, opacity, and spherical harmonics fetched from vertex-stage data textures. A background worker keeps the splats depth-sorted, with a synchronous fallback on the web.
The public API sits under a new Gaussian splatting doc category, GaussianSplats, SplatComponent (opacity, footprint scale, tint, SH degree, antialiasing, crop boxes), SplatData, and the SplatColorSpace, SplatCropMode, and SplatFormat enums. The geometry, material, packer, and sorter stay internal.
The example gains a Gaussian Splats page with two real CC BY captures, an animated crop wipe, and a free camera, and a gaussian_splats smoke scene covers the path (verified locally on Metal, WebGL2, Android GLES, and Android Vulkan). Follow-ups in the design note, .spz, a per-splat modify hook, picking, a global multi-set sort, and a compute GPU sort.

```
Loads 3DGS .ply and .splat files on a background isolate, packs splat
parameters (precomputed covariance, SH bands 0-2) into RGBA32F data
textures, and draws each set as one instanced batch of screen-space
Gaussian footprints in the translucent phase, depth-tested against opaque
geometry and blended premultiplied source-over. Instances draw in
presorted back-to-front order from a 16-bit counting sort on a background
isolate, retriggered when the view direction drifts; ordering along a
fixed direction is translation-invariant, so only rotation resorts.

SplatComponent attaches a set to a node like any other component, with
opacity, footprint scale, tint, SH degree, and antialiased-kernel knobs.
The example app gains a procedural Gaussian Splats scene demonstrating
splat/mesh occlusion.
```
Add splat crop boxes, adaptive footprint cutoff, and a captured asset
…
c8e505a
```
Crop boxes filter splats on the GPU per frame (SplatComponent.setCropBox,
an include or exclude unit-cube transform in the set's local space), so
cutaways and reveals animate freely.

The footprint quad now uses a per-splat cutoff radius derived from final
opacity (past sqrt(2 ln(255 a)) standard deviations the falloff is below
blending precision), which sharply cuts blended fill area in low-opacity
sets, and a clamp keeps a near-camera splat from rasterizing far past the
screen.

The example gains a real 1.5M-splat capture (Strawberry by danylyon,
CC BY 4.0), fetched and compacted to a bundleable .splat by
tool/fetch_splat_asset.sh + tool/ply_to_splat.dart (the file is gitignored
and the example falls back to the procedural nebula when absent), a
source picker, and an animated crop wipe.
```
Speed up large splat sets and add a free camera to the example
…
822bb44
```
The depth sorter is now a long-lived background worker that receives the
positions once at spawn, so a re-sort ships only the direction request
out and transfers the sorted order back, instead of copying the whole
positions array on the UI thread for every sort (a visible stutter while
orbiting million-splat sets). The web build falls back to a synchronous
sort. The splat fragment shader no longer discards; under premultiplied
source-over a zero-alpha output is identical and avoiding discard keeps
tile-based GPUs on their fast fragment path.

The example defaults to FXAA (soft footprints gain nothing from MSAA,
which multiplies blend cost across millions of tiny triangles), shows a
live fps readout, and gains a Quake-style free camera toggled from the
bottom-right corner.

Promote a minimal Gaussian splat public API
…
2f51e1b
```
Exports the load-and-attach surface from the package barrel: GaussianSplats
(the resource and its loaders), SplatComponent (attachment plus every
knob), SplatData (procedural construction), and the SplatColorSpace,
SplatCropMode, and SplatFormat enums the loaders and crop API take. The
geometry, material, packer, and sorter stay internal behind the component,
and the resource's GPU-texture plumbing (paramsTexture, texture dimensions,
fromPacked) is marked @internal so exporting the resource does not leak it.
Adds a Gaussian splatting dartdoc category and moves the splat types onto
it. The example now drives the feature entirely through the public barrel.

A procedural anisotropic splat cloud (degree-1 SH) composited around an

covariance projection and 2D eigendecomposition, the background depth
sort, premultiplied translucent blending over opaque geometry, the SH
texture fetch and evaluation, the crop branch, and the splat/mesh depth
composite. Deterministic (fixed seed), so the packed data and the sort
are identical across runs and backends.
