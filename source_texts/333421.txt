Volumetric Path Tracer is finally added! Currently supports:
Homogeneous medium (object bounded)
Grid volume: density (float), emission (tabulated blackbody emission, float) and albedo (float3). This is not a from-scratch module, since the sparse volume representation is supported by NanoVDB.
Delta tracking free-flight sampling, ratio tracking and residual ratio tracking for transmittance estimation.
Phase functions (HG, Isotropic, Double-HG, Rayleigh, SGGX (API only, no actual implementation)).
Added one BSDF: forward BSDF which does not change any ray property, only used for a null medium bound.
ImGui online param setter for medium and phase function. Medium is not currently supported to change types, yet phase function types can be modified on-the-fly.
Other changes:
Primitive to object mapping: modified to support culling during transmittance estimation.
Better RR.
Infrastructure for Online Neural Path Guiding (NPG WIP):
Wavefront path tracer has two functions that supports the output of training samples, and the injection of network inference results. This might be one of the next step (the other might be time-of-flight rendering).
