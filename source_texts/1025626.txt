Parent
Volumetric cloud upgrade to Horizon Zero Dawn / KONG (Decima/Nubis) quality.
What to build
The current Worley noise uses inverted F1 distance, which produces smooth billowy blobs. The Perlin-Worley blend is a simple linear mix, so it does not model the real process where high-frequency detail erodes the base cloud shape.
This slice rewrites the procedural noise so the base shape and detail erosion are distinct:
Worley noise computes F2 - F1 cellular-edge distance, producing structured cloud masses with natural boundaries.
Feature-point density is increased so patterns are not visibly coarse at 128^3 resolution.
Perlin-Worley becomes an erosion model: density = shape - detail * erosion, where shape comes from Worley F2-F1 and detail comes from high-frequency Perlin-like noise.
Acceptance criteria
worley_noise_3d returns F2-F1 values mapped to [0, 1] and remains deterministic.
Unit tests assert output range, correct dimensions, and bit-for-bit repeatability.
perlin_worley_from_worley implements erosion-style subtraction rather than linear blending.
Shader sample_density uses the new shape/erosion pipeline and still respects the weather-map coverage channel from the previous slice.
Screenshot of scenes/13_clouds.ron shows cloud edges with fibrous, broken detail while preserving large cloud masses (no soap-bubble look).

#109 implementation complete.
Changes
crates/aether-engine/src/renderer/clouds/worley.rs: rewritten to compute F2-F1 cellular-edge distance on a size-dependent dense grid (cell_count = size / 8). Produces structured cloud masses with natural, fibrous boundaries instead of inverted-F1 billowy blobs. Jitter hash is now 3D-correlated to avoid axis-aligned artifacts.
crates/aether-engine/src/renderer/clouds/perlin_worley.rs: rewritten as erosion-style subtraction: shape - detail * 0.55, where shape is low-frequency Perlin FBM and detail is the Worley F2-F1 cellular edge texture.
crates/aether-engine/src/renderer/passes/volumetric_cloud/shader.rs: updated comments and tuned detail-erosion scale/frequency to match the new noise semantics; primary march still uses weather-map coverage from [Cloud] Rewrite weather map with coverage + type/erosion channels #108.
