Contributor
Implements Mitchell-Netravali cubic filter (B=1/3, C=1/3) for image resampling in inc/hgl/2d/Resize.h.
Changes
FilterType enum: Added MitchellNetravali entry
MitchellNetravaliWeight(): Cubic filter weight function with parametric formulation for |x| < 1 and 1 ≤ |x| < 2, support radius of 2
SampleMitchellNetravali(): Template function sampling 4x4 neighborhoods with weight normalization, handles all pixel types (C=1,2,3,4)
Resize() integration: Added switch case invoking new sampler
Usage
```
auto resized = hgl::bitmap::resize::Resize(source, 200, 150, 
                 hgl::bitmap::resize::FilterType::MitchellNetravali);
```
The filter balances sharpness and smoothness, positioned between Bicubic and Lanczos in quality characteristics. All existing filters remain unchanged.

Pull request overview
This PR implements the Mitchell-Netravali cubic filter (B=1/3, C=1/3) for high-quality image resampling, providing a balanced option between sharpness and smoothness in the image resizing toolkit.
Key Changes:
Added MitchellNetravali filter type to the FilterType enum
Implemented MitchellNetravaliWeight() function using the standard Mitchell-Netravali parametric formulation with support radius of 2
Created SampleMitchellNetravali() template function that samples 4x4 pixel neighborhoods with proper weight normalization, supporting all pixel channel types (1, 2, 3, 4 channels)
