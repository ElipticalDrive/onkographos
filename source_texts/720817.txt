Summary
The rendering capabilities every previous rendering release deliberately left behind, plus the
shading depth that only becomes affordable once the material, image, post and shader contexts
exist to express it.
Every light casts a shadow, retiring the single exclusive caster that lighting work has been
built around for several releases. Point lights cast in all directions. The auxiliary passes
reach compositing grade. Every principled property that should accept a texture map does.
Problem
Interactive lighting still carries the one-shadow-caster limit, so a multi-light scene cannot
be judged in the viewport. Several principled properties are authored in a delivery and
ignored on import, so a model looks wrong and nothing says which map was dropped. And the
passes a render writes are a denoiser's input set rather than a compositor's, which for a
large part of this product's audience means the render is not usable in their pipeline at all.
Goal
The interactive viewport judges a lit, materialed scene honestly, every map a delivery
specifies is honoured, and a finished frame can be taken apart and put back together outside
Solarxy.
Value
The lighting story completes. Shadows from every light, in the viewport, including point
lights in all directions.
Deliveries render as authored. The maps a file specifies stop being silently discarded.
A render survives a note. A picture that decomposes into light-transport components is
one a compositor can grade without a re-render.
Scope
In: per-light shadows replacing the exclusive caster; cube-map shadows for point lights;
environment and image-based lighting quality; compositing-grade auxiliary passes beyond the
current set; texture maps for the remaining principled properties; normal and bump handling end
to end; texture coordinate transforms including repeat and offset as first-class operations;
and material assignment and texture workflow as a designed surface. About eight new node types,
because most of this is depth in existing nodes rather than new ones.
Out: anything requiring a device capability the browser lacks. Rewriting either renderer.
This release is the one most likely to shrink. The material, post and shader contexts all
ship before it and each may absorb part of this list, so reviewing it against what actually
shipped is its first planning step rather than an afterthought.
Planned epics
Epics are filed when this release is planned in detail; this list is the current intent.
Per-light shadows and the retirement of the exclusive caster
Point-light shadows in all directions
Compositing-grade auxiliary passes
Texture maps for the remaining principled properties
Normal and bump handling, and texture coordinate transforms
Environment and image-based lighting quality
Material assignment and texture workflow as a designed surface
