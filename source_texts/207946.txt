Scope
Implement synchronous VoxelMesher::bake(Volume) with optional external occlusion cache, directional outside-neighbor provider, configurable tolerance and global inner-shell rule.
Publish immutable voxel visual meshes and depth-only ShadowMap::Mesh, using existing spk::Mesh infrastructure without OpenGL calls during CPU bake.
Preserve semantic slots/opacity, UV, normals, winding and determinism. Triangulate source geometry before clipping for affine vertex-attribute interpolation.
Add numerical, fixture, orientation and neighbor tests, including all 4×4×8×8×6 fixture pairings.
Build layout
Voxel meshing and Model live in the optional graphics target because the existing spk::Mesh depends on GPUResource/LayoutBuffer. CPU baking does not activate GPU buffers or require an OpenGL context; core-only builds remain independent.
