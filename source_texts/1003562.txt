Adds a Warp/M XML loader to torch-tilt-series, shaped like the AreTomo and etomo loaders, and the one primitive it needs in torch-cubic-spline-grids.
torch-cubic-spline-grids: CubicSplineGrid.from_interpolating_data(data)
from_grid_data sets control points. This classmethod instead solves for the control points so the spline passes through data at the grid points. The spline is linear in its control points, so the interpolation matrix is assembled by evaluating one-hot control points at the grid points and the fit is one torch.linalg.solve. About 25 lines, every grid class and dimension, tested from 1-D to 4-D (6 parametrised cases). On Warp's lattice the fit is exact (residual ~1e-5).
torch-tilt-series: from_warp_xml(xml_path, pixel_spacing=None, image_path=None, apply_local_shifts=True, local_shifts_2d=None, device="cpu")
Reads the file with warpxmlfile (same role as alnfile/etomofiles) and maps it onto TiltSeries. The loader builds one CubicBSplineGrid2d.from_interpolating_data per kept tilt and wires that into the existing local_shifts_2d hook.

Awesome work @jtcarrion!
I've been testing this out on a dataset and it look amazing. I just have a couple things I/Claude came across when testing it:
LevelAngleX/Y are silently ignored. warpylib uses them in projection: tilt = angle + LevelAngleY, then Euler(...) @ Rx(LevelAngleX). With non-zero values the projection is wrong by hundreds of Å and nothing warns. This mapping reproduces warpylib exactly (max 0.001 Å):
```
tilt_angles = angles + level_angle_y
x_tilts = -level_angle_x
```
Either map them like this, or raise when they are non-zero.
Behaviour beyond the image edge. _warp_local_shifts_2d clamps the normalised position to [0, 1]. warpylib's grid evaluation doesn't seem to clamp. As far as I can tell its spline continues past the last node, which accounts for the 0.7–2 Å differences above, all for points projecting outside the image (0.2% of point–tilt pairs here). Points near the edge at high tilt are affected. I think this is fine but can you document the difference?
