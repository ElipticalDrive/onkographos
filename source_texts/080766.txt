This PR introduces a creative "porosity" feature to the mesh voxelizer. By providing a --porosity flag with a float value between 0.0 and 1.0, the tool generates a sponge-like, porous particle representation of the mesh instead of a fully solid block. It uses a high-performance pseudo-random spatial hashing technique based on the sin of the particle's coordinates to deterministically drop voxels based on the provided threshold probability. A unit test verifies the statistical accuracy of the ratio.

Validate porosity inside voxelize
Because voxelize is public and the tests/benchmarks call it directly, the CLI parser is not the only entry point. A direct call such as voxelize(..., Some(1.5)) or Some(f64::NAN) bypasses validate_porosity, and the new hash >= p check silently removes all kept voxels instead of returning an error; Some(-0.1) keeps everything. Please mirror the CLI's 0.0..=1.0 validation here, as this method already does for resolution and narrow_band.
