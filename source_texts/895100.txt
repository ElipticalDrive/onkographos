Vendor extension VISRTX_RENDERER_FOG on fast, interactive/default, quality.
Depth-cues camera-visible surfaces toward a fog color. Opt-in, no new ANARI object.
Spec: devices/rtx/docs/renderer-fog.md.
Parameter
Values
fogMode
none (default), linear, exp, exp2
fogDistanceMetric
viewDepth (default), rayDistance
fogColorSource
constant (default), background
fogColor
linear RGB, default (1,1,1)
fogStart / fogEnd
world units, linear only
fogDensity
inverse world units, exp/exp2 only
Alpha, depth, IDs, normals, and albedo are unchanged; misses, volumes, and secondary
transport are not fogged. Invalid active values warn and disable fog for that Commit.
Advertised via device/subtype extension queries and visrtx::getObjectExtensions.
