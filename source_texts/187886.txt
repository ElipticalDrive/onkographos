Running the mesh extraction algorithm on macOS with Retina displays leads to floating point problems when running the mesh extraction, more precisely, when creating a PyVista object. This was fixed by forcing integers: 65930ce
Before this, different NumPy and OpenCV versions used by the various mesh algorithms led to problems on MacOS and had to be downgraded: f86b461 116fbbb
As PyMCubes is not maintained anymore, it might be smartest to switch to a different mesh extraction algorithm altogether to use the latest NumPy and OpenCV versions.
Using the more recent, "improved marching cubes", algorithm, FLYING EDGES, might be smartest.
PyVista has an implementation already: https://docs.pyvista.org/examples/01-filter/marching_cubes.html
