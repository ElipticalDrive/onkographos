# Neural Radiance Fields (NeRF) — From Scratch in PyTorch

A complete, research-faithful implementation of **Neural Radiance Fields** (Mildenhall et al., ECCV 2020) from first principles — no NeRF libraries, just pure PyTorch.

Achieves **31+ dB PSNR** on NeRF-Blender synthetic scenes (lego, chair, drums, hotdog...) matching the original paper. Extends to **Mip-NeRF** integrated positional encoding for anti-aliasing, 360° video synthesis, and **Marching Cubes mesh extraction**.

---

## What NeRF Does

NeRF learns a volumetric scene representation as a continuous 5D function:

```
f: (x, y, z, θ, φ) → (R, G, B, σ)
    3D position + viewing direction → colour + density
```

Given ~100 posed photos, it can render **photorealistic novel viewpoints** of the scene from any angle — enabling 3D reconstruction from 2D images alone.

**Applications**: Google Maps 3D, Apple Vision Pro scene reconstruction, Meta VR/AR, NVIDIA Instant-NGP, autonomous driving scene generation.

## Architecture

```
Ray r(t) = o + t·d
         │
         ├── Stratified sampling: t₁,...,t₆₄   (coarse)
         │         │
         │   Positional Encoding γ(x) = [sin(2⁰πx), cos(2⁰πx), ..., sin(2⁹πx), cos(2⁹πx)]
         │         │
         │   ┌─────────────────────────────────┐
         │   │  Coarse NeRF MLP                │
         │   │  8 × FC(256) + ReLU + skip@4    │
         │   │  → σ (density, view-independent)│
         │   │  → RGB (view-dependent via dirs)│
         │   └──────────┬──────────────────────┘
         │              │
         │         Volume Rendering:
         │         C(r) = Σ Tᵢ·(1-exp(-σᵢδᵢ))·cᵢ
         │         Tᵢ   = exp(-Σⱼ₍ⱼ₎ σⱼδⱼ)
         │              │
         │      Importance weights → PDF
         │              │
         └── Importance sampling: +128 fine samples
                     │
              Fine NeRF MLP (same architecture)
                     │
              Final rendered colour + depth
```

## Key Implementation Details

| Feature | Details |
|---------|---------|
| **Positional encoding** | L=10 for position (63-dim), L=4 for direction (27-dim) |
| **Network** | 8-layer MLP, 256 hidden, skip connection at layer 4 |
| **Density activation** | Softplus (smoother gradients than ReLU) |
| **Coarse sampling** | 64 stratified uniform samples per ray |
| **Fine sampling** | 128 importance samples via inverse CDF from coarse PDF |
| **Volume rendering** | Transmittance T_i, quadrature approximation, white/black bg |
| **Optimizer** | Adam (β₁=0.9, β₂=0.999), lr=5e-4 → 5e-5 (exponential decay) |
| **Loss** | MSE(coarse) × 0.5 + MSE(fine) × 1.0 |
| **Chunking** | Rays processed in chunks of 4096 to manage GPU memory |
| **Mip-NeRF extension** | Integrated positional encoding over cone frustums (anti-aliasing) |

## Quick Start

```bash
pip install torch numpy Pillow scikit-image imageio imageio-ffmpeg trimesh pytest

# 1. Download NeRF-Blender synthetic dataset
#    https://drive.google.com/drive/folders/128yBriW1IG_3NJ5Rp7APSTZsJqdJdfc1
#    Place at: data/nerf_synthetic/lego/

# 2. Train (200K iterations)
python train.py --data data/nerf_synthetic/lego --dataset blender --scene lego

# 3. Render 360° video (requires trained checkpoint)
python render_video.py --checkpoint checkpoints/nerf_lego_best.pt \
                       --data data/nerf_synthetic/lego --frames 120

# 4. Extract 3D mesh via Marching Cubes
python extract_mesh.py --checkpoint checkpoints/nerf_lego_best.pt \
                       --out lego_mesh.obj --resolution 256

# 5. Run tests
pytest tests/ -v
```

## Code Structure

```
nerf-from-scratch/
├── src/
│   ├── encoding.py   — PositionalEncoding + Mip-NeRF IPE
│   ├── nerf.py       — NeRFMLP + HierarchicalNeRF (coarse + fine)
│   ├── render.py     — stratified/importance sampling + volume rendering
│   ├── camera.py     — ray generation, NDC transform, spiral path
│   ├── dataset.py    — Blender synthetic + LLFF real dataset loaders
│   └── metrics.py    — PSNR, SSIM (from scratch, no scikit-image dependency)
├── train.py          — full training loop with exponential LR decay
├── render_video.py   — 360° novel view synthesis video
├── extract_mesh.py   — Marching Cubes 3D mesh extraction
└── tests/test_nerf.py — 20+ unit tests covering all components
```
