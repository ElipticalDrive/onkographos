Package 10.3 — performance and rendering refinement
Based on merged Package 10.2 (#71).
Progressive surfaces: for >=200k voxels, an offline Worker emits a coarse marching-tetrahedra preview before the unchanged full-resolution result. Stale jobs/previews are canceled; only final surfaces enter the bounded 32 MiB cache.
Polyhedron display LOD: distance/count/quality-based outline suppression for dense polyhedra; filled meshes, coordination metrics, areas/volumes, and export geometry are unchanged.
Worker slice PNG: 768px axial/skew Miller plane pixel value/color sampling on the existing offline Worker with transfer buffers, cancellation and synchronous fallback. Interactive previews, contour tracing and CSV stay on the main thread.
Optional hardware GPU timings: WebGL2 EXT_disjoint_timer_query_webgl2, asynchronous query polling, disjoint detection, transparent unavailable state. Never confuse frame-interval or CPU timers with GPU time.
Tests: native Worker preview/final parity, slice sampling/hole guards and LOD decisions; real Chromium WebGL progressive preview, slice PNG Worker, offline Worker, cancellation/cache, and independent Gemmi reference pipeline. English/Turkish documentation and PWA cache version updated.
Scientific voxel values, signed-level interpretation and existing security limits are unchanged. Preview coarseness is not scientific resolution; hardware timings are informational with no fixed FPS/ms gate. Leave unmerged pending CI.
