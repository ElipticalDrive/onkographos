Summary
Increase the visual Gravel Basin terrain mesh from 108 to 162 segments per side while retaining the existing 108-segment collision heightfield. This smooths visible mound and jump silhouettes without increasing physics sampling cost.
Add deterministic per-vertex contour tint based on slope, height, and low-frequency terrain variation so crests, shoulders, and troughs read more clearly.
Add subtle bump mapping from the existing gravel texture for finer surface detail.
Enable the terrain mesh to cast onto itself, revealing directional shadows from jump faces and mound shoulders.
Focus the existing 1024 Gravel Basin shadow map into a tighter 116-unit area that follows the RC truck (snapped in 3-unit increments), improving nearby shadow detail without raising shadow-map resolution.
Keep the previous Gravel Basin pixel-ratio cap and all geometry/collision shapes, jump heights, parked vehicles, concrete structures, and mode restrictions unchanged.
Validation
JavaScript parse checks passed for gravel-map.js and main.js.
Git diff confirms only gravel-map.js and main.js changed.
Static checks confirm collision heights and elementSize remain generated from the original 108-segment grid.
No live browser screenshot or measured FPS benchmark has been performed yet; verify terrain appearance and performance in the preview before merging.
