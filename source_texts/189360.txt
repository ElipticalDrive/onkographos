Description
Hello,
This PR fixes an edge case of bbox::ray_intersect where rays would erroneously report valid intersections in case:
the ray direction is aligned to the z-axis...
And the ray origin is outside the bbox on the y-axis.
In such cases, ray_intersect wrongly returns True. The fix changes the initial checks for any element of ray.d != 0 and adds a bound check. The one case it doesn't cover is if the ray is fully contained in the bounding box and ray.d=(0,0,0). I don't know if this is considered possible in Mitsuba, if it is an issue we could opt for:
```
auto active = dr::any(ray.d != dr::zeros<Vector>()) &&
              dr::all(ray.d != 0.f || (ray.o >= min && ray.o <= max));
```
A minimal reproducer
```
import mitsuba as mi
mi.set_variant("scalar_rgb")

bbox = mi.BoundingBox3f(min=[0.,0.,0],max=[1.,1.,1.])

# Before
ray = mi.Ray3f(o=[0.5, -0.5, 0.5], d=[0., 0., 1.])
print(bbox.ray_intersect(ray)) # (False, inf, 1.3999998569488525)
# (True, -0.4999999701976776, 0.4999999701976776)

# After
ray = mi.Ray3f(o=[0.5, -0.5, 0.5], d=[0., 0., 1.])
print(bbox.ray_intersect(ray))
(False, -0.4999999701976776, 0.4999999701976776)
```
Testing
A test was added in test_bbox.py for this specific case and the test suite passed locally.
