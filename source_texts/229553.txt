Overview
Introduces a native cloud render distance configuration slider (options.cloudDistance) in OreUI Video Settings under the Clouds panel, allowing dynamic adjustment of volumetric cloud simulation range from 8 to 128 chunks.
Visual Preview
OreUI Video Settings: Cloud Distance Slider
Problem
Cloud rendering in Cinnabar used fixed or hardcoded boundary radiuses. On low-end systems, rendering extensive cloud planes can impose unnecessary GPU vertex and fill-rate overhead. Conversely, on high-performance GPUs with extended view distances, clouds would abruptly truncate before the horizon.
Solution
OreUI Video Setting:
Added CloudDistance slider setting in crates/launcher/src/menu/settings_options/definitions.rs under SettingPanel::VideoClouds.
Configurable range between 8 and 128 chunks, with a default of 64 chunks.
Wired localization key options.cloudDistance and format strings in French and English.
Render Engine Integration:
Propagated the active slider value to crates/render-scene/src/cloud_visibility.rs and crates/render/src/cloud_render.rs.
Dynamically updates the mesh cache bounding box (mesh_cache.rs) and atmospheric ceiling calculations in app/src/environment/atmosphere.rs.
Validation
Tested slider responsiveness in OreUI Video settings between 8, 32, 64, and 128 chunks.
Verified visual cloud extent in-game updates immediately without requiring a game restart or chunk reload.
