# RealtimeGaussian

An end-to-end toolkit for turning ordinary video into explorable 3D Gaussian scenes, with custom inference, visualization, benchmarking, and cloud deployment workflows built around [NoPoSplat](https://github.com/cvg/NoPoSplat).

This repository began from the official NoPoSplat research code. The work here extends that base into a practical reconstruction system and uses it to study the limits of local-context streaming 3D Gaussian Splatting.

## What I built

- **Video-to-Gaussian inference:** select frames from a video, run pose-free reconstruction, export Gaussian PLY files, and render novel-view videos through one command.
- **Interactive visualization:** inspect reconstructed splats in the browser with orbit, pan, zoom, opacity filtering, and scale clamping.
- **Realtime rendering path:** benchmark and use the CUDA splatting decoder independently from the heavier reconstruction encoder.
- **Pipeline orchestration:** setup checks, checkpoint downloads, guided launch scripts, and repeatable output organization.
- **Cloud GPU deployment:** provision, bootstrap, run, tunnel into, stop, and remove GCP GPU instances from shell scripts.
- **Streaming reconstruction research:** implement and compare naive stitching, reprojection tracking and gating, Sim(3) alignment, and voxel merging against a Splatfacto baseline.

The custom implementation adds more than 3,700 lines across the inference, viewer, deployment, and evaluation layers.

## Measured performance

Benchmarked on an NVIDIA RTX 4060 at 256 x 256:

| Stage | Measured time | Throughput |
| --- | ---: | ---: |
| Pose-free encoder, two frames to approximately 131k Gaussians | 418 ms | 2.4 frame pairs/s |
| CUDA decoder, one novel view | 14 ms | 72 views/s |
| CUDA decoder, 30 novel views | 100 ms total | 300 views/s equivalent |
| End-to-end reconstruction and one rendered view | 432 ms | 2.3 runs/s |

The decoder is fast enough for interactive rendering; reconstruction remains limited by the ViT-Large encoder.
