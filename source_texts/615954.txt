Adaptive mesh refinement (AFEM) for jno.fem — plus the solver composition it needed
Adds a full adaptive-FEM stack to jno.fem (solve → estimate → mark → refine) and the two FEM-core solver-composition fixes a real workload (a 3D Helmholtz metasurface unit cell) turned out to require.
Adaptive FEM
Forward loop — fem.solve(adapt=AdaptSpec(...)): Zienkiewicz–Zhu recovery estimator + Dörfler bulk marking + in-place metric remesh via Mmg (mmgpy). domain.refine(size_field) is the public remesh primitive.
Adaptive inverse — run_adaptive_inverse(...): alternate differentiable parameter recovery (crux.solve) with refinement, so the mesh ends minimal for the recovered design (κ de-biases; beats uniform ~3×/DOF).
AdaptSpec.eps — plateau-detector stop (patience 2) for both the forward (error estimate) and inverse (recovered parameter) loops.
3D — mmg3d tetrahedral remeshing; the ZZ estimator is now dimension-general (a geometric P1-gradient recovery that also sidesteps a pre-existing 3D gap in _fe_element_gradient_data).
Anisotropic — Hessian-metric refinement (stretched elements aligned to solution curvature), 2D and 3D (Mmg tensor metric); ~8–16× fewer DOFs on oblique/thin layers.
Scalar P1 for now (the estimator assumes one DOF/vertex).
Solver composition (enabling a periodic complex Helmholtz metasurface)
periodic × complex (steady) — periodic ties compose with the complex real-equivalent block (reduce/prolong both real and imaginary legs by the same P). Ported from feat/fem-feature-composition.
Sparse complex block — [[A_r,−A_i],[A_i,A_r]] assembled as a sparse BCOO and solved sparsely instead of densified (~4× faster non-periodic; removes the dense-block memory wall).
Sparse nonconforming periodic reduction — a weighted triplet-remap for interpolation (nonconforming) periodic ties, so PᵀAP stays sparse instead of materialising a dense n_full² intermediate (AFEM produces nonconforming faces).
Docs / tutorials
New tutorials + docs pages: adaptive L-shape, adaptive-inverse (minimal mesh for the recovered design), anisotropic thin layer.
Testing
New: test_fem_adapt.py (2D + 3D, forward + inverse + eps + anisotropic) and test_fem_periodic_complex.py.
Full non-slow suite green: 2364 passed, 12 skipped, 1 xfailed (CPU, fem env).
Notes
Adds mmgpy>=0.16 to the fem dependency group (lazily imported; only needed for adaptive remeshing).
Includes a merge of main (element-zoo, feat(fem): element zoo — Lagrange P3+, spatial-Hessian, Hermite, Argyris C¹, Morley + Kirchhoff-plate BCs #75).
