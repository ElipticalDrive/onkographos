Overview
Refactored the ForwardRenderer into a clearer multi-pass pipeline.
Added shadow mapping support for both directional and spot lights.
Added volumetric lighting to render a visible flashlight cone effect.
Reworked fullscreen.vert to use a CPU-provided quad instead of shader-generated vertices.
Fixed texture_utils::empty(...) by setting GL_NEAREST for both min/mag filters to avoid incomplete render-target sampling.
Main Features
Shadow Mapping
Added depth pass support for directional and spot lights.
Added light-space matrix generation via LightComponent::getLightSpaceMatrix().
Added shadow map sampling in lit.frag using PCF + depth bias.
Volumetric Lighting
Added volumetric-light.frag with raymarching through view-space depth.
Computes spotlight cone contribution and shadow-aware scattering.
Produces a cone-like fog beam effect from the flashlight.
Fullscreen Pipeline Update
Updated fullscreen.vert to consume vertex inputs from CPU mesh attributes.
Added mesh_utils::quad() and reused it for fullscreen passes (postprocess and volumetric).
Forward Renderer Refactor
Split rendering flow into dedicated stages:
shadow pass
scene pass
volumetric pass
postprocess pass
Added helper methods such as:
createSceneFBO()
setupShadowMapping()
setupVolumetricLighting()
collectRenderData(...)
renderShadowPass(...)
renderScenePass(...)
renderVolumetricPass(...)
renderPostprocessPass(...)
uploadLightUniforms(...)
Validation / QA Checklist
Directional shadows render correctly on scene geometry.
Spot shadows align with flashlight direction and cone.
Volumetric cone appears and responds to occlusion.
Fullscreen passes run through the new quad path.
Postprocess still works with and without volumetric pass.
Renderer initialization and teardown complete without resource leaks.
