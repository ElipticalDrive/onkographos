Part of #3063
Adds a first batch of the remaining SDFs, ported from the linked iquilezles articles in the existing tgpu.fn + 'use gpu' + JSDoc style and exported from index.ts:
3D: sdTorus(point, majorRadius, minorRadius); sdCappedTorus(point, sc, majorRadius, minorRadius)
2D: sdHexagon2d(point, radius), where radius is the inradius (flat top/bottom)
Gradient: sdgHexagon2d(point, radius) → vec3f(distance, gradient.xy), as suggested in feat: Implement remaining SDFs #3063. Unlike the reference version, it returns a zero gradient instead of NaN for points exactly on the edge (where the original divides by zero).
Tests
The package had no tests, so this adds tests/shapes.test.ts. The vitest config and the typegpu-testing-utility devDependency are copied from @typegpu/radiance-cascades.
known distances: on the surface → 0, inside → negative, outside → positive
capped torus: arc vs. cap-end regions, x-symmetry
sdgHexagon2d: distance equals sdHexagon2d, gradient matches central finite differences and has unit length, zero gradient on the edge
every function resolves to WGSL
regression tests from review: thin-tube precision in sdCappedTorus (1e8 : 1e-4 radius ratio) and a unit gradient for tiny hexagons
tsconfig.json now includes tests/**/*, so the tests are type-checked in CI
I also checked each shape against brute-force references (exact polygon distance for the hexagon, a densely sampled arc for the capped torus) on random points: max error was about 3e-7.
Checks
vitest run --project @typegpu/sdf: 24 passed
oxlint --type-aware --max-warnings=0 and oxfmt --check: clean
tsc --noEmit for the package (now including tests) and dpdm circular-deps: pass
Happy to add more shapes and gradient variants in follow-up PRs for the rest of #3063.
