Adds a native load_chunk(x, z) method to the WASM plugin API using Pumpkin’s existing get_or_fetch_chunk system.
This allows plugins like world pregenerators to generate/load chunks directly without relying on /forceload, which can cause server freezes.
Summary by CodeRabbit
New Features
Added the ability to load or generate a world chunk at specified coordinates.
Existing chunk retrieval now clearly returns only chunks that are already loaded.
Improved chunk loading to safely reuse chunks loaded concurrently and report newly loaded chunks accurately.
