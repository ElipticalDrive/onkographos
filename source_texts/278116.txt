Author
This pull request introduces a new Vulkan-based greedy meshing compute pass into the codebase. The main changes include adding the compute shader, integrating the meshing pass into the build system, and updating the demo application to initialize, dispatch, and clean up the meshing pass. The implementation is encapsulated in new source and header files, and the shader is compiled and dispatched as part of the rendering pipeline.
Meshing Pass Integration
Added src/render/meshing_pass.cpp and src/render/meshing_pass.hpp implementing the MeshingPass class, which manages Vulkan resources, pipeline creation, and dispatch for the greedy meshing compute shader. [1] [2]
Updated CMakeLists.txt to include the new meshing shader (shaders/meshing/*.comp) in the build process and ensure src/render/meshing_pass.cpp is compiled when building the Vulkan renderer. [1] [2]
Compute Shader Addition
Added shaders/meshing/greedy.comp, a Vulkan compute shader that performs greedy meshing on voxel data and outputs vertex and index buffers using atomic counters.
Demo Application Updates
Modified apps/demo_window.cpp to include and use the new MeshingPass class, initializing it, dispatching the compute pass during command buffer recording, and properly destroying resources on exit. [1] [2] [3] [4]
