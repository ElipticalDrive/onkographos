Changes
This PR extends merged PR #1 on feature/splat-perf.
Repeated sorts recreate draw commands, four tilesets exceed the three-entry worker cache, and spherical harmonics retain unused padding.
Skip steady sorts when the effective float32 depth direction and splat generation are unchanged. Preserve cache-miss recovery.
Reuse draw commands and index-buffer capacity. Rebuild for incompatible shader or capacity changes.
Replace the three-entry position cache with a 128 MiB limit per worker. Add explicit release requests and oversized-input handling.
Pack spherical harmonics (SH) densely during tile loading. Preserve half-precision values and pad mixed degrees with zeros.
No application option is required. Anti-aliasing and opacity thresholds remain unchanged.
Measured results
The baseline is the merged PR #1 commit, e9409954f68c7843998960bf07a3ddaf3fb92ffa.
Measurements use an NVIDIA RTX A4000 on Linux with fixed graphics and memory clocks.
Each workload has two interleaved baseline/candidate pairs. Tile selection remains fixed, and every compared frame has matching splat counts.
The 95th percentile is abbreviated p95. Central processing unit (CPU) times measure the instrumented rendering span.

Dolly median frame time falls by 4.7%. Four-tileset frame p95 falls by 22.0%, and CPU span p95 falls by 68.2%.
Orbit median frame time and graphics processing unit time show no material improvement.
SH packed storage falls by 25% at degree 2 and 20% at degree 3. Degree 1 storage is unchanged.
These combined measurements do not isolate the contribution of each change.
Validation
The full suite reports 15,749 passes and six failures. PR Fix splat sort recovery and resource lifetime #1 reports 15,737 passes with the same six failures.
All 12 added specifications pass. They cover cache bounds, backing buffers, dense packing, sort suppression, and command transitions.
Three camera-pose image pairs and eight rendering-transition image pairs match byte for byte.
Transition captures contain visible geometry and report no graphics errors. They cover display modes, viewport changes, camera changes, and model translation.
Actual worker and WebAssembly probes pass cache-miss, explicit-release, and oversized-input checks.
Packing comparisons preserve every half value for 262,144 splats at each SH degree.
Commit hooks pass lint, formatting, Markdown, and type checks.
The six existing failures concern automatic uniforms, translucent styling, three environment-map cases, and point-cloud picking.
Limits
The cache can retain more memory than the old three-entry policy. Its 128 MiB limit covers retained positions per worker, not total renderer memory.
Oversized inputs require position transfers on subsequent sorts.
The measurements cover one GPU, one operating system, and fixed-selection asset paths. They do not establish streaming or loading gains.
The four-tileset test measures cache contention. It does not validate global depth ordering between overlapping primitives.
See the full results for measurements, evidence files, and validation limits.
