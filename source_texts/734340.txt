Performance issue
VoxelWorld::raycast (crates/voxel_world/src/lib.rs ~707-754) is a voxel DDA that calls self.block(cell)? on every step. block recomputes chunk_coord/local_coord and hashes VoxelWorld::chunks for each cell, even though consecutive DDA cells almost always stay inside the same 32³ chunk — so a ray crossing one chunk repeats the same map lookup up to 32 times. Rays are bounded at 4096 cells and callers include projectiles, melee/grid actions, blast visibility, and simulation checks.
Fix
Keep the current chunk coordinate and a borrowed &Chunk during traversal: the map is hashed once per chunk crossing instead of once per cell. Semantics are preserved exactly — a missing chunk returns None immediately (matching block's None for unloaded chunks), and hit/step ordering and the returned RayHit are unchanged.
Compile-checked with cargo check -p voxel_world -p simulation --tests.
