Substantially improves the existing Claude project scanline-3d-7r4k (a from-scratch software 3D renderer + CPU path tracer) by adding its next graphics pillar: volumetric participating media — a bounded region of space that absorbs and scatters light along the ray, not just at surfaces. This is the layer that produces fog, haze, dusty god-ray beams, smoke and glowing nebulae. Pure CPU TypeScript, no WebGL.
Physics (all unbiased Monte-Carlo, hand-derived)
Light is lost as transmittance e^(−∫σ_t ds) (Beer–Lambert); it turns by the Henyey–Greenstein phase function; the single-scattering albedo σ_s/σ_t is the fraction a collision keeps.
Homogeneous media (fog/haze/beams) use an analytic spectral, per-RGB distance sampler, so fog can be coloured without bias (an "amber smog" reddens what it veils — blue is absorbed faster than red).
Heterogeneous media (smoke/nebulae) use Woodcock delta / ratio tracking over a from-scratch 3-D fBm density field.
In-scattered direct light comes from phase-function next-event estimation, attenuated by the medium itself — so wherever an occluder blocks the key light the shadow volume reads as a real god-ray beam. Surface NEE is medium-attenuated too, so objects correctly dim in fog.
What's new
raytrace/medium.ts — the medium model, HG phase (eval + exact importance sampler, verified E[cosθ]=g), fBm density field, spectral homogeneous sampler, Woodcock trackers, six presets + a runtime builder.
raytrace/tracer.ts — tracePath rewritten to integrate the medium per segment; new phase-function NEE; medium-attenuated surface NEE.
raytrace/bvh.ts — worldBounds() to fit the medium box to scene geometry.
engine/renderer.ts, ui/Controls.tsx, App.tsx — RTSettings.medium, an Atmosphere control panel (presets, density, anisotropy), reset-key tracking.
scene/scene.ts — Cathedral (crepuscular colonnade) and Nebula (glowing fBm cloud) showcase scenes.
raytrace/medium_verify.ts — an 8-check self-test: phase normalisation (∫p dω = 1), isotropy/asymmetry, E[cosθ]=g sampling, Beer–Lambert + multiplicativity, spectral-sampler unbiasedness per RGB channel, delta-tracking escape probability, ratio-tracking unbiasedness + variance reduction, and a multiple-scattering energy-conservation furnace (mean radiance 1.0012 of a unit sky for a lossless medium).
