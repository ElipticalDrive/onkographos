Context
VoxelVisibilityMap.IsAdjacentVoxelTransparent considers each voxel outside the chunk as air. Thus the mesher makes quads on all chunk borders, also between two solid chunks. The player never sees these quads, but the GPU draws them.
Goal
The mesher makes a quad on a chunk border only if the neighbor voxel is air or outside the world.
Tasks
Give the mesher read access to the border voxels of the six neighbor chunks. For example, use a padding of one voxel.
If a neighbor chunk is not generated, consider its voxels as air. Make the mesh again when the neighbor is ready.
When an edit changes a border voxel, make the mesh of the neighbor chunk again.
Measure the number of quads of the default world before and after the change.
Acceptance criteria
The number of quads of the default world decreases. The PR gives the numbers.
A test edits voxels on each chunk border and finds no holes.

Depends on: #45, #47.
