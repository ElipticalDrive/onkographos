Summary
This PR introduces a complete chunk management pipeline for the voxel engine, including disk persistence, dynamic streaming around the player, level-of-detail (LOD) rendering with dither-fade transitions, and cluster-based impostor rendering for distant chunks.
Key Changes
Persistence & Storage
persistence.rs: Binary serialization for chunk data with RLE-compressed cell grids. Chunks are saved to disk in a region-based directory structure with version tracking and external cell reconstruction.
region.rs: Region-level chunk storage with dirty-state tracking (data generation, save state, mesh generation). Chunks are stored in ChunkSlot wrappers with Arc-wrapped data for efficient neighbor sharing.
coords.rs: Coordinate system definitions (ChunkPos, RegionId, ClusterKey) with bounds checking and world-to-chunk conversions.
world_grid.rs: Top-level world resource managing multiple regions and the active region context.
Streaming & Loading
streaming.rs: Per-frame chunk streaming system that loads/unloads chunks based on camera distance, auto-wires neighbor references, and manages entity lifecycle. Includes configurable load radius, budgets, and hysteresis.
world_paths.rs: Platform-specific world save directory resolution (macOS, Windows, Linux).
LOD & Rendering
chunk_lod.rs: Immediate-mode LOD tier management with dither-fade transitions. Implements DitherFadeExtension material for smooth crossfades between Full/Reduced/Hidden tiers. Tracks in-progress transitions and chamfer amount per chunk.
cluster.rs: 4×4 XZ chunk clustering system that merges distant chunk columns into single impostor meshes when all members are at Reduced LOD tier. Includes render stats collection.
Shaders (dither_fade.wgsl, chunk_vertex.wgsl, dither_prepass.wgsl): Screen-space ordered dithering for LOD transitions, chamfer offset vertex attribute handling, and prepass support.
World Generation
worldgen.rs: Island terrain generator using heightmap approach. Generates multi-chunk vertical terrain with configurable peak height, coastline shape, ridges, and flat surroundings.
Integration
lib.rs: Exports new modules and adds ChunkMeshLevel enum to track mesh generation state (None/LodOnly/Full).
meshing.rs: Added ATTRIBUTE_SHARP_NORMAL vertex attribute to preserve original face normals before chamfer smoothing.
chunk.rs: Added Debug impl for ChunkData.
world.rs: Refactored to use new streaming/LOD systems. Removed hardcoded demo chunk, now uses WorldGrid and streaming anchor. Adds SpawnPoint resource and collision layer attachment.
main.rs: Added CLI arguments for world management (--world, --new-world, --clear-world).
debug_ui.rs: Integrated LOD, streaming, and cluster config controls into debug UI.
player.rs: Added StreamingAnchor component to player for chunk streaming.
curtain.rs: Updated level-ready check to wait for chunk meshing completion.
Notable Implementation Details
Immediate-mode LOD: Materials are created once per chunk and mutated in-place every frame, avoiding pipeline re-specialization races.
RLE Compression: Cell grids use run-length encoding with cell type tags (Empty/Local/External) to reduce disk footprint.
External Cell Reconstruction: External cells are not saved to disk; they're reconstructed from neighbor data at load time.
Dither-Fade Transitions: Uses 4×4 Bayer matrix ordered dithering for smooth, flicker-free LOD crossfades.
Cluster Activation: Clusters only render when all members are at Reduced tier; otherwise individual chunks render per their LOD state.
Generation Tracking: Dirty state uses monotonic generation counters to efficiently track what needs saving/meshing/

```
Each chunk has a permanent child (LodChild) holding the alternate LOD
mesh. During tier transitions, both parent and child are visible with

- lod_child_setup: creates permanent child when ChunkLodMesh appears
- lod_transition_start: begins crossfade when target != current tier
- lod_transition_update: animates fade values, finalizes on completion

Debug panel now has transition_duration slider.
```

Add sharp normal interpolation for chamfer fade
…
08d6fd5
```
Stores the original face normal (before chamfer smoothing) as a second
vertex attribute ATTRIBUTE_SHARP_NORMAL (@location(11)). The vertex
shader interpolates: mix(sharp_normal, smooth_normal, chamfer_amount).

At chamfer_amount=1 (close), vertices have smooth bisector normals
(full fillet look). At chamfer_amount=0 (far), normals snap back to
flat face normals (matching the LOD mesh). This eliminates the shading
discontinuity during the fillet→flat transition.

Changes:
- ChunkMeshData gains sharp_normals field
- cut_offset_chamfer captures normals before the smoothing loop
- LOD mesh sets sharp_normals = normals (identical, no chamfer)
- specialize() adds ATTRIBUTE_SHARP_NORMAL at location 11
- Vertex shader blends normals via mix()
```
