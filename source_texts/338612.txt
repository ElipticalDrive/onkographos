Summary
Implements Phase 2 of spatial partitioning with Quadtree (2D) and Octree (3D) hierarchical structures for improved performance with clustered entity distributions.
Closes #207
Changes
New Features
✅ QuadtreePartitioner: 2D hierarchical spatial partitioning
Configurable max depth (1-16, default: 8)
Configurable entities per node (default: 8)
Adaptive subdivision based on entity density
4-way node splitting (Northwest, Northeast, Southwest, Southeast)
✅ OctreePartitioner: 3D hierarchical spatial partitioning
Configurable max depth (1-12, default: 6)
Configurable entities per node (default: 8)
Adaptive subdivision based on entity density
8-way node splitting (all octants)
✅ Configuration:
QuadtreeConfig with world bounds and subdivision parameters
OctreeConfig with world bounds and subdivision parameters
Updated SpatialConfig with Quadtree/Octree support
Updated SpatialPlugin to instantiate all three strategies
Implementation Details
Adaptive Subdivision:
Entities stored only in leaf nodes
Parent nodes subdivide when entity count exceeds threshold
Entity positions tracked for redistribution during subdivision
Efficient O(log n) insert, update, and remove operations
Query Performance:
Broadphase queries with narrowphase position filtering
O(log n + k) query complexity where k is result count
Efficient tree traversal with early pruning
Better performance for clustered distributions compared to grid
Memory Management:
Position tracking dictionary for entity redistribution
Node-based storage with minimal overhead
Clean separation between subdivided and leaf nodes

Breaking Changes
None. This is a purely additive feature that extends the existing spatial partitioning system.
Migration Guide
No migration required. Existing code using SpatialStrategy.Grid continues to work unchanged.
To use Quadtree:
```
var config = new SpatialConfig
{
    Strategy = SpatialStrategy.Quadtree,
    Quadtree = new QuadtreeConfig
    {
        MaxDepth = 8,
        MaxEntitiesPerNode = 8,
        WorldMin = new Vector3(-10000, 0, -10000),
        WorldMax = new Vector3(10000, 0, 10000)
    }
};
world.InstallPlugin(new SpatialPlugin(config));
```
To use Octree:
```
var config = new SpatialConfig
{
    Strategy = SpatialStrategy.Octree,
    Octree = new OctreeConfig
    {
        MaxDepth = 6,
        MaxEntitiesPerNode = 8,
        WorldMin = new Vector3(-10000, -10000, -10000),
        WorldMax = new Vector3(10000, 10000, 10000)
    }
};
world.InstallPlugin(new SpatialPlugin(config));
```
Strategy Selection Guidance
Use Grid when:
Entities are uniformly distributed across space
Entity density is consistent
Predictable, fixed-size cells are acceptable
Use Quadtree when:
Entities cluster in 2D space
Entity density varies significantly
Memory efficiency is important
Use Octree when:
Entities cluster in 3D space
Entity density varies significantly
Working with 3D worlds/simulations
