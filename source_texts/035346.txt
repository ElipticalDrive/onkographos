Problem
The island is built from individual Quaternius grass cubes (Cube_Grass_Single.gltf) placed on a 2.23-unit grid. Each cube has beveled edges, which creates visible V-groove seams between every adjacent cube. The island reads as separate blocks rather than a solid mass.
What we tried
PR Island: fill single-cell interior gaps (morphological closing) #27 (closed): morphological closing to fill single-cell holes. Wrong problem -- the gaps are bevel seams, not missing cells.
PR Island: solid interior with beveled shoreline rim #28 (closed): plain BoxMesh for interior cells (all 4 neighbors filled), beveled Quaternius cube only on shoreline, interior inset 2cm. Looked hideous -- the flat-green interior material clashed with the textured Quaternius top.
Directions to investigate
Greedy meshing (industry standard for voxels): do not render individual cubes. Merge adjacent top faces into larger polygons so there are no internal seams. Keeps the blocky aesthetic on the sides, solid top.
Custom interior material: sample/match the Quaternius grass texture more closely instead of flat green. May need UV work on the BoxMesh.
Single extruded mesh: build the island top as one mesh from the 2D footprint instead of placed cubes. Loses the voxel look entirely.
Non-beveled cube asset: find or make a plain grass cube that tiles cleanly, use everywhere. Simplest if a matching asset exists.
Accept the bevel: the grooves are the Quaternius art style. Decide if this is actually a problem or just how blocky islands look.
Constraints
Shoreline must keep its rounded/beveled treatment where it meets water.
Foam SDF uses _top_layer_cubes -- any approach must keep that populated correctly.
One variable per iteration for art review.
No rush on this -- parking it here for later.
