# Basic 3D Gaussian Splatting Viewer (Three.js)

A lightweight, minimal implementation of the 3D Gaussian Splatting rendering pipeline using vanilla Three.js. 

This project is designed for educational purposes to strip away the complexity of optimized CUDA/WASM implementations and Python training pipelines, focusing entirely on **how the rendering works in the browser**.

## 🚀 Quick Start

1.  **Clone the repository** (or download the files).
2.  **Run a local server**. Because this project uses ES Modules, opening the HTML file directly might trigger CORS errors in some browsers.
    * *Using Python:* `python3 -m http.server`
    * *Using Node:* `npx serve`
    * *VS Code:* Right-click `index.html` and select "Open with Live Server".
3.  **Open in Browser**. Navigate to `http://localhost:8000` (or whichever port your server uses).
