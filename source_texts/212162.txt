Overview
Signed Distance Functions (SDFs) are a powerful mathematical technique for defining shapes implicitly. They enable smooth blending, boolean operations, and efficient ray marching - all relevant to atari-style's visual effects.
What are SDFs?
An SDF returns the distance from any point to the nearest surface:
Negative values: Inside the shape
Zero: On the surface
Positive values: Outside the shape
Key Concepts from Shader Art
From kishimisu's shader tutorial series:
```
// Circle SDF
float sdCircle(vec2 p, float r) {
    return length(p) - r;
}

// Box SDF
float sdBox(vec2 p, vec2 b) {
    vec2 d = abs(p) - b;
    return length(max(d, 0.0)) + min(max(d.x, d.y), 0.0);
}

// Smooth union (blending shapes)
float opSmoothUnion(float d1, float d2, float k) {
    float h = clamp(0.5 + 0.5*(d2-d1)/k, 0.0, 1.0);
    return mix(d2, d1, h) - k*h*(1.0-h);
}
```
Applications to atari-style
Smooth shape transitions: Morph between geometric shapes
Boolean operations: Union, intersection, subtraction of shapes
Soft shadows and glow: Distance-based falloff effects
Procedural patterns: Repeating/tiling with fract() and mod()
