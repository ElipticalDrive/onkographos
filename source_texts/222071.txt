This Zenodo upload includes four .tar.gz files tomos.tar.gz contains the reconstructed tomograms at bin3. The contrast is inverted so signal shows up as white denoised.tar.gz contains the denoised tomograms at bin3. semSeg_actin_channel_binarized.tar.gz contains the semantic segmentation map indicating where in the tomogram the actin filaments are. semSeg_fascin_channel_binarized.tar.gz contains the semantic segmentation map indicating where in the tomogram the fascin crossbridges are. The semantic segmentation maps were binarized at a threshold of 0.95 because they were exceeded the zenodo limit before binarization even with compression. These .tar.gz files are compressed archives of the data, which may be decompressed using: gunzip file.tar.gz tar -xvf file.tar.gz   The decompressed .mrc volumes can be viewed using programs like 3dmod or UCSF chimera. If using chimera, a useful command to view the denoised and semantically segmented maps is:  volume #* style surface level 0.15 step 3 region all  To view finer details, the step size can be adjusted to 1.

Description
This Zenodo upload includes four .tar.gz files
tomos.tar.gz contains the reconstructed tomograms at bin3. The contrast is inverted so signal shows up as white
denoised.tar.gz contains the denoised tomograms at bin3.
semSeg_actin_channel_binarized.tar.gz contains the semantic segmentation map indicating where in the tomogram the actin filaments are.
semSeg_fascin_channel_binarized.tar.gz contains the semantic segmentation map indicating where in the tomogram the fascin crossbridges are. The semantic segmentation maps were binarized at a threshold of 0.95 because they were exceeded the zenodo limit before binarization even with compression.
These .tar.gz files are compressed archives of the data, which may be decompressed using:
gunzip file.tar.gz
tar -xvf file.tar.gz
The decompressed .mrc volumes can be viewed using programs like 3dmod or UCSF chimera. If using chimera, a useful command to view the denoised and semantically segmented maps is:
volume #* style surface level 0.15 step 3 region all
To view finer details, the step size can be adjusted to 1.
