Sure thing, the main difference is how the SDF geometry object stores the underlying data. Previously it was storing the data as a vector specifically for btMiniSdf, which unnecessarily couples the pure geom class to the contact manager.
Now it stores it in a more neutral format, so any SDF producer and consumer can use it without having to do bullet-specific transformations. That all now happens as a bullet util, so the separation of concerns is clearer.
As per Levis suggestion, I've also added support for loading SDFs from a URDF, which necessitates descretising the field, and helpers for de/serialising the field.
Other than that, also added a few more tests.
The 2nd commit then completely removes the SDFMesh from the code based. Happy to split this into a separate PR if that makes things easier.

Just pushed a fix for the failing positive distance test: Stock Bullet routes convex-vs-SDF pairs to btConvexConcaveCollisionAlgorithm, whose SDF branch only emits a contact when the query point is within the probe's surface (dist <= radius).
It ignores btManifoldResult::m_closestPointDistanceThreshold, so contacts at positive distance inside the collision margin band are never generated. Positive-distance contacts are the load-bearing case for motion planning:
TrajOpt's collision costs consume contacts reported at 0 < distance < margin
to obtain a gradient that pushes links apart BEFORE they collide
OMPL-style validity gates admit states by the same margin band.
A backend that only reports penetration still passes every boolean collision check while silently breaking all margin-based consumers since they are the only tests that distinguish "collision detection" from the distance-to-collision contract tesseract requires.
This fix adds TesseractConvexSdfAlgorithm, replicating Bullet's SDF vertex query but widening the acceptance band by the pair's contact distance threshold, registered for convex-vs-SDF pairs via TesseractCollisionConfiguration.
Additions along the way:
Capsule probes are now supported (absent in stock Bullet) by sampling the field along the axis segment with a radius offset; samples are spaced at most one radius apart.
Unsupported probes (cylinder/cone) now warn once per pair instead of silently missing every contact.
