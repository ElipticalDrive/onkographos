Description
Two-species reaction–diffusion system (Gray–Scott):
du/dt = Du*d2u/dx2 - u*v^2 + F*(1 - u),
dv/dt = Dv*d2v/dx2 + u*v^2 - (F + k)*v.
No existing base. Multi-component state (VectorField) with one
FDLaplacianCalculator per component.
Point to settle before implementation: the classic Turing-pattern images are
2D, but v0.10.0 only has UniformGrid1D (2D arrives with DD-051, #152,
v0.11.5). Options: a 1D example (pulse splitting / self-replicating spots),
with the 2D version deferred to a later milestone; or moving this sub-issue
after v0.11.5.
Validation reference: no closed-form solution. Qualitative check against a
published 1D parameter regime, plus a quantitative invariant (e.g. homogeneous
steady state recovered outside the pattern-forming regime).

Choices made at implementation.
1D or 2D: 1D in v0.10.0, so that the seven reference examples can be assessed at this milestone. The 2D version (spots, stripes, labyrinths) follows in [MAINT] Reference example: Gray–Scott Turing patterns in 2D #208, on the milestone that delivers the nD structured grid.
Form: dimensionless, with the scales of Pearson (Science 261, 1993): Du = 2e-5, Dv = 1e-5, ring of period 2.5. Gray–Scott is a model of cubic autocatalysis with no material behind it.
Boundary conditions: a periodic ring, closed by the model itself. oxiflow has no periodic condition for finite differences (FluxBoundary::Periodic belongs to the finite-volume operators), its boundary conditions apply to scalar states only, and FDLaplacianCalculator takes a one-sided stencil at the end nodes. The model replaces the Laplacian there by the centred stencil across the closure. No generic condition was added: the ring is a property of this model, and the question goes to the nD grid.
Validation reference: this issue foresaw only a qualitative check. The linear Turing analysis gives an exact quantitative reference, used as the first case; the self-replicating pulses of Reynolds, Pearson and Ponce-Dawson (Phys. Rev. Lett. 72, 2797, 1994) give the qualitative second case.
Case 1, Turing instability. (F, k) = (0.066, 0.06245), upper homogeneous state u* = 0.49699, v* = 0.25846, stable to uniform perturbations (real part of the eigenvalues −2.2e-3). On the grid, cos(2π m i / n) is an eigenfunction of the discrete Laplacian with q² = (4/dx²) sin²(π m / n); laid on the state along an eigenvector of J − q² diag(Du, Dv), the mode grows as exp(σt). Unstable band: m = 4 to 31, largest at m = 16; modes 0 to 3 have complex eigenvalues and are left out. Four modes, each in its own run: amplitude 1e-7, 256 nodes, RK4, dt = 1, up to t = 300, σ measured by projection on the mode.

The errors do not depend on the time step (dt = 0.5 gives the same values); they come from the nonlinear terms, quadratic in the amplitude (1e-6 gives 5.6e-7 for mode 16), and from rounding for the decaying mode, whose amplitude ends near 8e-11. The rate of the continuous equations is printed, not checked: it shows the spatial error that the discrete q² removes (largest near the band edge, mode 31).
Case 2, self-replicating pulses. (F, k) = (0.04, 0.06), trivial state u = 1, v = 0 with u = 1/2, v = 1/4 on the 21 middle nodes (half-width 0.05, Pearson's perturbation); 512 nodes, RK4, dt = 0.5, up to t = 2500. The pulse splits, then the outermost pulses split at every cycle. A pulse is a run of nodes where v > 0.2.

The counts at these times fall in the middle of the plateaus between splittings: 2, 4 and 6 on 256, 512 and 1024 nodes alike, with the threshold 0.1 or 0.2. The splitting times move with the grid by a few tens of time units.
Six deliberate mutations, all detected, each by the check it targets: the feed term of the model 1 % off and the periodic closure removed (growth rates); Du 0.1 % off in the exact rates and an initial perturbation off the eigenvector (growth rates); k = 0.062 in case 2 (pulse count); the initial perturbation shifted by one node (mirror symmetry).
The reaction–diffusion row of both READMEs now reads "Gray–Scott in 1D: Turing instability, pulse splitting" / "Gray–Scott en 1D : instabilité de Turing, réplication"; the "Gray–Scott Turing patterns" wording of DEVELOPMENT.md §12 still fits the 1D Turing case. The example is added to the reference examples run in CI, and CHANGELOG.md records it. The debug run with default features takes about 6 s; the CI runs the reference examples in release.
