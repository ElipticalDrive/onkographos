Context: #252. In the relit bookcase in examples/bookshelf, moving the key light changed only a flat overlay. Each book's cast shadow is a fixed 9,-4 offset in the book def, and its highlight is hard-coded in the cover brush, so neither followed the light.
Problem
Every effect that implies a light takes its own direction: fx shadow 0,6, fx rim dir:1,1, fx inner, and any dir: a brush reads. A scene with consistent light has to repeat one angle in every one of them, and changing the light means editing all of them.
Proposal
A document light that effects read, like Photoshop's Use Global Light.
Implement the reserved light declaration, which today is E0390 "light (Phase 2) is not yet implemented": light key dir:-30,-60 color:p.warm soft:12.
fx shadow, fx rim and fx inner with no direction of their own take it from the scene light. An explicit direction still wins.
A brush can read the light direction and color as Mark fields, so cover-style shading can turn its highlight toward the light.
palette:-style override: a light: key on a @target or an instance swaps the light, so one file can render several lightings with each.
Open questions
More than one light: allow it, or keep one key light for now.
Whether light also feeds the 3D layer transforms from 3D layer transforms and a scene camera #255, so a turned face darkens by its angle to the light.
Done when
Changing one light line in bookcase.art moves every book's cast shadow and highlight.
Depends on
Implement the ramose shading language and port brushes to it #308 (Implement the ramose shading language and port brushes to it), for the part where brushes read the light as Mark fields. The effect defaults for fx shadow, fx rim, and fx inner can land first.
Part of #287, item 22 of the architecture audit.
Update from the architecture audit (#287)
The open question about 3D is settled: light is one scene value that 2D effects, brushes, and 3D shading all read. Turn 2D nodes in 3D under a scene camera #329 and Add GLB output and a mesh foundation in the shared core #330 use it.
More than one light stays open. A light that brightens dark art #163 asks for a point light with falloff, which should be a kind of this same light declaration, not a second concept.
