Creates a simple voxel-based Minecraft clone using HTML5 Canvas and vanilla JavaScript.
Features
3D Rendering: First-person view with projection, block sorting by distance
Player Physics: Gravity, collision detection, jumping
Block Interaction: Place/break blocks with raycasting
World Generation: Procedural terrain with trees
9 Block Types: Grass, dirt, stone, wood, leaves, sand, water, brick, cobblestone
Inventory Hotbar: Select blocks with 1-9 keys
Files Added
minecraft-game/index.html - Main page with HUD and hotbar UI
minecraft-game/style.css - Styling for game UI elements
minecraft-game/game.js - Game engine (~600 LOC)
minecraft-game/README.md - Usage documentation
