# 3D Object Surface Voxelizer & Interactive Viewer

[![C++17](https://img.shields.io/badge/C%2B%2B-17-00599C?style=for-the-badge&logo=cplusplus&logoColor=white)](https://en.cppreference.com/w/cpp/17)
[![CMake](https://img.shields.io/badge/CMake-3.20+-064F8C?style=for-the-badge&logo=cmake&logoColor=white)](https://cmake.org/)
[![SFML](https://img.shields.io/badge/SFML-3.0.2-8CC445?style=for-the-badge&logo=sfml&logoColor=white)](https://www.sfml-dev.org/)
[![Platform](https://img.shields.io/badge/Platform-Linux%20%7C%20macOS%20%7C%20Windows-lightgrey?style=for-the-badge)]()

A high-performance C++17 engine that converts arbitrary 3D triangular surface meshes (`.obj`) into uniform voxel representations using recursive Octree spatial partitioning (Divide-and-Conquer). The pipeline leverages the Separating Axis Theorem (SAT) for exact triangle-box collision pruning and features an interactive real-time 3D software rasterizer built from scratch with SFML.

## Key Features

- **Divide-and-Conquer Spatial Partitioning**: Hierarchical 3D spatial decomposition via Octree, recursively partitioning bounding volumes into 8 octants.
- **Exact Triangle-AABB Collision (SAT)**: Full 13-axis Separating Axis Theorem testing (box faces, triangle normal, and edge cross products) to prevent geometric leakage and eliminate false positives.
- **Aggressive Subtree Pruning**: Empty bounding boxes containing no geometry are culled early, minimizing computational overhead and memory footprint.
- **Uniform Voxel Mesh Synthesis**: Leaf nodes at the target depth are reconstructed into solid cubic meshes (8 vertices, 12 outward-facing triangular faces) and exported to standard Wavefront `.obj`.
- **Custom Software Rasterizer & 3D Viewer**: Standalone CPU-based rendering engine featuring barycentric triangle rasterization, depth buffering (Z-buffer), directional Lambertian shading, and an interactive orbital camera.
- **Zero-Dependency Setup**: SFML is fetched and compiled automatically via CMake `FetchContent`—no manual library installations required.

## System Architecture & Algorithms

```
                          Input Wavefront OBJ Mesh
                                     │
                                     ▼
                    ┌──────────────────────────────────┐
                    │      Compute Root Cubic AABB     │
                    └──────────────────────────────────┘
                                     │
                                     ▼
             ┌────────────────────────────────────────────────┐
             │       Recursive Octree Divide-and-Conquer      │
             │                                                │
             │   1. Divide parent AABB into 8 octants         │
             │   2. Filter candidate intersecting triangles   │
             │   3. Perform 13-Axis SAT Collision Test        │
             │   4. Prune empty octants (No geometry)         │
             │   5. Recurse until depth == max_depth          │
             └────────────────────────────────────────────────┘
                                     │
                                     ▼
                    ┌──────────────────────────────────┐
                    │      Extract Uniform Voxels      │
                    └──────────────────────────────────┘
                                     │
                                     ▼
                    ┌──────────────────────────────────┐
                    │   Voxel Cube Mesh Generation     │
                    │   (8 Vertices, 12 Faces / Box)   │
                    └──────────────────────────────────┘
                                     │
                   ┌─────────────────┴─────────────────┐
                   ▼                                   ▼
        ┌──────────────────────┐            ┌──────────────────────┐
        │ Export Voxelized OBJ │            │ Interactive SFML     │
        │ File Output          │            │ 3D Software Viewer   │
        └──────────────────────┘            └──────────────────────┘
```
