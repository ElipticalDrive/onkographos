💡 What: Added an early exit to skip the expensive self.mesh.distance_to_local_point() calculation for exterior voxels during solid voxelization when narrow_band is None.
🎯 Why: distance_to_local_point performs a costly BVH query. For non-narrow-band exterior voxels, this exact distance isn't needed (we only need the negative sign/value for interior).
📊 Impact: Expected to improve solid voxelization performance by reducing redundant BVH queries for empty space.
🔬 Measurement: Verify via cargo bench or profiling that execution time for solid voxelization is reduced for meshes occupying a small fraction of their bounding box.

Preserve zero-distance boundary voxels
When solid voxelization runs without narrow_band, this skips every point whose ray-parity test says !is_inside before checking its actual mesh distance. For grid/crop/resolution combinations where a voxel center lies exactly on the mesh surface but the parity test classifies it as outside, the previous code kept that boundary voxel with sdf == 0.0 via sdf <= 0.0; this change drops it entirely, which can leave missing boundary particles in solid output. The optimization should still evaluate distance for these ambiguous surface candidates or otherwise preserve zero-distance voxels.
