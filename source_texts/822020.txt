Please retry. If you run the following command sequence properly you will be able to start getting results:
git clone --recursive https://github.com/nvlabs/instant-ngp
cd instant-ngp
pip install -r requirements.txt
cmake . -B build
cmake --build build --config RelWithDebInfo -j
create a folder called images
copy 50-150 images to the folder
python3 [path-to-instant-ngp]/scripts/colmap2nerf.py --colmap_matcher exhaustive --run_colmap --aabb_scale 16
go to data/nerf and create a folder named after your project
copy the images from [path-to-instant-ngp]/images to data/nerf/[name-of-project-folder]
copy [path-to-instant-ngp]/transform.json to data/nerf/[name-of-project-folder]
./build/testbed --mode nerf --scene [path to training data folder containing transforms.json]
Ensure you have installed the following prerequisistes:
CUDA
Python 9/10
Optix
Vulkan SDK
Anaconda
