Prior to this PR the Grid class held the points as a tensor. This PR changes that so that the points are held as a PointSet. This allows the points from the grid to be immediately used by the basis set.
I also snuck in a new function on the CartesianAO class (and the view) which allows you to evaluate it in a partially normalized form (as needed to agree with libint and the pre-tabulated spherical transform coefficients)
