Summary
Implement a classic Amanatides & Woo DDA voxel traversal that, given a ray and a VoxelVolume, returns the first solid hit.
API sketch
```
struct Hit {
  bool hit = false;
  BlockId block = kAir;
  int x, y, z;          // voxel coordinates
  int face;             // 0..5 (+X,-X,+Y,-Y,+Z,-Z)
  float t;              // distance along ray
  Vec3 position;        // world-space hit point (optional)
};

Hit raycast_voxel(const VoxelVolume& vol, const Ray& ray, float max_t = 1e6f);
```
Batch variant for the full frame is desirable but can be a thin loop over camera_ray + raycast_voxel in Phase 1.
Acceptance criteria
Correct traversal of axis-aligned grid (unit tests against known geometry)
Returns correct face normal index
Handles starting-inside-solid case (either step out or report immediately — document choice)
max_t respected
No heap allocation on the hot path
Deterministic and headless-testable
Basic performance counter: rays cast / hits / avg steps
Implementation notes
Prefer integer/fixed-point friendly formulation where possible, but float is acceptable for Phase 1
Keep the function pure (volume + ray → Hit) so it can be called from both C++ demos and future Aura primitives
References
Amanatides, J., & Woo, A. (1987). A Fast Voxel Traversal Algorithm for Ray Tracing.
