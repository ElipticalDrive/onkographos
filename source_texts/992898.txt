Motivation
Replace procedural terrain regeneration with a deterministic image-driven conversion so imported maps keep their original shape and features.
Provide robust water/land detection that reliably separates exterior oceans from lakes and preserves coastlines and small islands.
Allow users to control how visual map signals map to Minecraft altitudes via configurable layers and presets instead of random generators.
Add previews and validation so users can inspect masks, classes and final heightmap before export.
Description
Reworked the pipeline to be image-first: HSV/luma analysis, flood-fill ocean detection, coastline and distance fields, terrain classification, per-class altitude mapping, controlled smoothing and Minecraft quantification; main logic implemented in script.js (new/updated functions: detectMasks, floodFillOcean, classifyTerrain, buildHeightmap, applyMinecraftLayering, presets and layer UI glue).
Added configurable Minecraft layer definitions and presets (WorldPainter Standard, Minecraft 1.21 Full Height, Cobblemon Balanced, High Contrast, Soft Terrain) and an advanced UI to edit min/max/variation/quant/priority for each layer, wired into the pipeline and export.
Updated UI (index.html) to expose conversion parameters (sea level, min/max Y, water/mountain sensitivities, contour/quant options, advanced layer editor) and new preview modes (original, water/land mask, terrain classes, final heightmap, layers preview, hillshade).
Styling additions for layer controls were added to style.css, and PNG export naming and WorldPainter metadata in JSON export were updated to match the new flow.
Testing
Ran node --check script.js to validate JavaScript syntax and it succeeded.
Attempted node --check script.js && node --check index.html which failed because node --check cannot parse .html files, not because of JavaScript errors.
Manual static checks were performed by loading and lint-checking the updated files for missing references and the new UI element bindings, with no unresolved references found.
