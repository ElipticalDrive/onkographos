Description d'un cadre theorique original fonde sur la transformation de radon. Dans ce nouvel espace de representation il devient possible, par une operation de rearrangement, de redistribuer les valeurs integrales associees aux plans, du systeme de coordonnees lie aux positions de source sur le systeme de coordonnees spheriques du domaine. Pour assurer ce changement d'espace deux formules sont proposees. Il est ensuite analyse l'influence d'un bruit blanc sur les mesures. Il est recherche en particulier a partir de quel niveau une difference sur une valeur reconstruie sera significative et a partir de quelle taille un objet comme sera detecte. Grace a ce modele statistique, il est possible d'evaluer les limites physiques introduites par le bruit photoniquue. Les traitements numeriques permettant de realiser sur calculateur les schemas d'inversion sont decrits
