Summary
This PR introduces a complete Physically Based Rendering (PBR) system to the engine, including tangent space normal mapping, Cook-Torrance BRDF implementation, and a new PBR scene for demonstration.
Key Changes
New PBR Scene (ScenePBR): Added a dedicated scene class that demonstrates PBR rendering with two objects (ground plane and model) using different material parameters
Tangent Vector Calculation: Implemented automatic tangent vector computation for vertices via MakeTangentCalc() lambda, supporting UV tiling for flexible material application
PBR Vertex Format: Created PBRVertex structure with position, normal, UV, and tangent data to support normal mapping in tangent space
Vertex Shader (VS_PBR.hlsl): Transforms light and view directions into tangent space using TBN matrix construction for per-pixel normal mapping
Pixel Shader (PS_PBR.hlsl): Implements full Cook-Torrance BRDF with:
GGX normal distribution function (D)
Smith-Schlick geometric attenuation (G)
Schlick Fresnel approximation (F)
Metallic/roughness material parameters
Reinhard tone mapping for HDR output
Material Parameters: Added PBRParam structure for per-object metallic and roughness control
Scene Integration: Registered ScenePBR in SceneRoot with proper scene enumeration and switching logic
Notable Implementation Details
Tangent vectors are computed per-triangle and averaged across shared vertices for smooth normal mapping
UV coordinates can be scaled during vertex remapping for material tiling (ground uses 4x tiling, model uses 1x)
Normal map is sampled in tangent space, allowing reusable textures across different geometry
Proper handling of edge cases (zero-length tangents, degenerate triangles) during tangent calculation
Material properties (metallic=0.0, roughness varies) demonstrate non-metallic surfaces with different surface roughness
