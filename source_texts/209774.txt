Hypothesis: Fourier-encoded spatial coordinates (NeRF-style positional encoding) — target OOD geometry generalization
PR #3519 (your work) tested Fourier embedding on the conditioning vector (Re, AoA, NACAs, gap, stagger) and found that enriched cond features hurt OOD geometry splits (val_geom_camber_rc +5.5%, val_geom_camber_cruise +3.4%) while modestly helping in-distribution single_in_dist (−5.2%). The mechanism: a richer cond basis let the FiLM MLP make sharper conditional modulations that overfit to in-distribution flow-param structure but didn't transfer to held-out geometry.
The flip-side experiment: apply Fourier features to the spatial path instead — encode (x, y) and optionally (dsdf) with multi-frequency sin/cos basis before the input MLP. This is the original NeRF / Tancik et al. 2020 use case, and targets the OOD camber splits directly: a denser positional basis lets the network represent fine-scale surface curvature regardless of whether the foil shape was seen at training time.
This is mechanistically the opposite of #3519: instead of enriching how the global flow vector reaches every block, we enrich how the spatial coordinates of each mesh point reach the input. The hypothesis: improved spatial representation will compound with FiLM (per-block flow conditioning operates on cleaner spatial features) and benefit OOD geometry splits where the spatial representation must extrapolate.

Mechanism: Tancik et al. 2020 ("Fourier Features Let Networks Learn High Frequency Functions in Low Dimensional Domains") showed that MLP-based coordinate-conditioned networks have a strong low-frequency bias, fixed by Fourier features. The Transolver input MLP that ingests [x, y, dsdf, NACA_dims, ...] has the same bias — adding Fourier features should enable sharper representations of foil surface curvature.
Compound with FiLM: orthogonal — FiLM conditions every block on the (raw) cond vector; spatial Fourier features only change the input MLP's receptive field for spatial structure. Mask agreement should stay at ~0.62.

Arm A is the minimal NeRF-style encoding: enrich the 2D position (x, y) coordinates with [sin(σπ·2^k · x), cos(σπ·2^k · x), sin(σπ·2^k · y), cos(σπ·2^k · y)] for k in range(n_freqs). Adds 2 × 2 × n_freqs = 24 extra input dims for n_freqs=6.
Arm B extends the encoding to include the signed distance function value dsdf, which encodes proximity to the foil surface. SDFs are inherently multi-scale (large gradient near the surface, smooth far away), so multi-frequency encoding may help the network represent boundary-layer pressure structure better. Adds 3 × 2 × n_freqs = 36 extra input dims.
σ=0.5 is conservative: spatial coords are normalized to roughly [−1, 1], so max freq = 0.5π·2^5 = 16π. This gives ~8 cycles across the unit interval at the highest freq — well above the natural foil-curvature scale but below the aliasing regime that hurt PR #3519's Arm B at σ=2.
Why this should work mechanically
Low-frequency bias in MLPs is well-documented. Sitzmann et al. (SIREN), Mildenhall et al. (NeRF), and Tancik et al. all show that standard MLPs cannot represent high-frequency spatial signals without explicit positional encoding. Foil surface pressure has sharp peaks near leading edges and stagnation points — these are high-frequency spatial structures.
Direct attack on OOD geometry weakness. The current model represents foil shape via the NACA digit encoding (input MLP) and the dsdf channel (per-point distance to surface). When the camber values are out of training distribution, the input MLP must extrapolate a 4-digit NACA → continuous shape mapping. Richer Fourier-encoded spatial coords give the network a representation of the queried position that is independent of the foil shape, so the per-block FiLM modulation can apply geometry-agnostic spatial functions.
Compounds with FiLM, not redundant. FiLM conditions the spatial features on (raw) flow params; Fourier-encoded positions enrich the spatial features themselves. The two are operating at different layers of the network.
Conservative σ avoids your [charlie-pai2i-24h-r5][nezuko] Fourier-embedded FiLM conditioning #3519 failure mode. σ=0.5 with n_freqs=6 puts the max freq at 16π — well below the aliasing regime that hurt Arm B (σ=2 with k=8 → 256π). The PR [charlie-pai2i-24h-r5][nezuko] Fourier-embedded FiLM conditioning #3519 negative cause was extreme high-freq mapping; this is calibrated to spatial-coord scale.
Implementation outline (train.py only)
You already implemented FourierEmbedFiLM(n_freqs, sigma, raw_dim) for #3519 (concat-residual pattern). The same building block applies here, just at a different input slot.
CLI flags:
```
parser.add_argument("--fourier_pos_freqs", type=int, default=0,
                    help="Fourier frequencies for spatial coordinates. 0 disables.")
parser.add_argument("--fourier_pos_sigma", type=float, default=0.5,
                    help="Sigma for spatial Fourier embedding (frequencies = sigma * pi * 2^k).")
parser.add_argument("--fourier_pos_include_sdf", action="store_true",
                    help="Include dsdf in Fourier embedding (in addition to x, y).")
```
At input pre-processing (before input MLP):
```
# x is the input tensor; the spatial dims are at known indices.
# From the data layout: spatial coords are x[:, :, 0] (x), x[:, :, 1] (y).
# The dsdf channel is at a specific index — check `data/__init__.py` or
# print the first few values to confirm (likely x[:, :, 2] or similar).

if cfg.fourier_pos_freqs > 0:
    SPATIAL_INDICES = [0, 1]
    if cfg.fourier_pos_include_sdf:
        SDF_INDEX = ???  # CONFIRM from data layout
        SPATIAL_INDICES.append(SDF_INDEX)
    coords = x[:, :, SPATIAL_INDICES]  # [B, N, len(SPATIAL_INDICES)]
    # Build frequency multipliers: sigma * pi * 2^k for k in range(n_freqs)
    freqs = (cfg.fourier_pos_sigma * math.pi *
             torch.pow(2.0, torch.arange(cfg.fourier_pos_freqs, device=x.device, dtype=x.dtype)))
    # [B, N, len(SPATIAL_INDICES), n_freqs] = coord * freq
    coords_x_freq = coords.unsqueeze(-1) * freqs[None, None, None, :]
    sin_feats = torch.sin(coords_x_freq).flatten(2, 3)  # [B, N, len*n_freqs]
    cos_feats = torch.cos(coords_x_freq).flatten(2, 3)  # [B, N, len*n_freqs]
    # Concat to input: [raw_x, sin_feats, cos_feats]
    x_aug = torch.cat([x, sin_feats, cos_feats], dim=-1)
    # IMPORTANT: input MLP first-layer dim needs to grow to accommodate this.
    # Either re-build the model with new input_dim, OR reduce the augmentation
    # via a small projection layer first.
else:
    x_aug = x
```
Input MLP shape change. The Transolver input MLP first linear has shape [X_DIM, n_hidden]. With Fourier augmentation, the effective input dim becomes X_DIM + 2*len(SPATIAL_INDICES)*n_freqs. Easiest: pass the augmented dim through to the model constructor as a new arg. Confirm parameter count delta is small (~1% increase, comparable to your [charlie-pai2i-24h-r5][nezuko] Fourier-embedded FiLM conditioning #3519 +1.4%).
DO NOT modify the cond path. Keep FiLM exactly as merged. The cond vector (Re, AoAs, NACAs, gap, stagger) stays raw — this is the explicit pivot away from [charlie-pai2i-24h-r5][nezuko] Fourier-embedded FiLM conditioning #3519.
Keep everything else unchanged: Cautious AdamW, bf16, FiLM, surf-L1, EMA, scale-inv, Bernoulli residual, NaN sanitization, T_max=25/eta_min_factor=0.10.

Risk / failure modes
σ too large → high-freq overfitting (your [charlie-pai2i-24h-r5][nezuko] Fourier-embedded FiLM conditioning #3519 Arm B failure mode revisited on spatial path). Mitigation: starting at σ=0.5 which gives max freq 16π over a unit-coord domain. If both arms regress, try σ=0.25 in a follow-up.
Encoding dsdf adds OOM-of-magnitude variation. dsdf can range over 5+ orders of magnitude (close to vs far from foil surface). Applying log10 or normalizing dsdf to [−1, 1] before Fourier encoding may be more numerically stable. Arm B encodes raw dsdf — if it diverges or shows training instability in the first 1–2 epochs, log the issue and retry with dsdf_normalized = sign(dsdf) * log(1 + |dsdf|).
The input MLP can't absorb extra dims. Easy fix: project the Fourier-augmented input through a small linear Linear(aug_dim, X_DIM) before passing to the original input MLP. This preserves the model architecture and only adds a thin adapter.
NaN-safe evaluate_split must remain intact. Same caveat — propagate the test_geom_camber_cruise/000020.pt mask workaround.
What I'm explicitly NOT doing here
Not changing FiLM, the cond path, or the architecture beyond input dims.
Not using learned σ (RFF). That's a clean follow-up if Arm A wins but the result is marginal.
Not encoding NACA digits with Fourier — they're categorical-like integer codes, and Fourier-encoding them would produce aliasing artifacts similar to [charlie-pai2i-24h-r5][nezuko] Fourier-embedded FiLM conditioning #3519's Arm B.
Suggested follow-up if this wins
Learnable σ (RFF): Tancik et al.'s learned-σ variant. Single hyperparam, simpler to tune.
Position encoding only at certain attention levels: apply Fourier features at the input AND at every slice-attention block (similar to NeRF's coarse+fine sampling).
Hierarchical position encoding: combine low-σ (geometry-level) and high-σ (surface-pressure-detail) bases.
Compound with per-feature σ on cond (your [charlie-pai2i-24h-r5][nezuko] Fourier-embedded FiLM conditioning #3519 suggested follow-up Loss: Huber/L1 sweep — close train/eval metric gap #1): if spatial Fourier wins, the per-feature σ idea for cond may also help, but the geometry-extrapolation cost of [charlie-pai2i-24h-r5][nezuko] Fourier-embedded FiLM conditioning #3519 needs to be addressed first.
