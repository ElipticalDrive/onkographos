# Octave

An interactive monograph on procedural noise. A single long-form page that develops the subject from randomness and coherence through value noise, Perlin gradient noise and fractal Brownian motion to terrain generation. Five live figures and a literature review.

**Live:** https://pablowilliams.github.io/Octave/

## What is here

Seven sections on one continuous-scroll page:

1. Randomness and coherence
2. **A history of procedural noise: a literature review** — Perlin's noise, the fractal-terrain work of Mandelbrot and of Fournier, Fussell and Carpenter, Lewis's value noise, Perlin's later corrections, simplex noise, Worley's cellular noise and wavelet noise; each traced to the limitation it answered
3. Value noise
4. Gradient noise
5. Fractal noise
6. From noise to worlds
7. Conclusion

Five interactive figures render a genuine noise field with a keyboard-movable probe. Eight references.

## Accessibility

Built to WCAG 2.2 AA. Each `<canvas>` has `role="img"` with an accessible name and a debounced description; the canvas carries a keyboard-movable probe; every figure has a non-canvas data fallback; one `role="status"` region announces results. The table of contents uses in-page anchor links; the reading-progress bar is decorative and `aria-hidden`. All text meets 4.5:1 contrast; controls and focus indicators meet 3:1.

## Stack

Vanilla HTML, CSS and JavaScript. No build step, no frameworks, no dependencies. One stylesheet and one engine (`app.js`).

## Run locally

```bash
git clone https://github.com/pablowilliams/Octave.git
cd Octave
open index.html
```

## Sources

The literature review cites eight works; full details are in the References section of the page. The principal sources are Perlin (1985), Mandelbrot (1982), Lewis (1989) and Perlin (2002).
