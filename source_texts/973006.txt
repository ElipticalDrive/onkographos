Exporting optimized intrinsics seems useful for calibration/debugging, especially when optimize_distortion is enabled.
I would avoid inventing a second camera representation and instead expose the final values using the same convention as the input transform metadata.
For each optimized camera, useful output would include:
focal length / fl_x, fl_y as applicable;
principal point;
distortion parameters;
image dimensions;
camera identifier/frame mapping.
It should also be clear which values were optimized versus held fixed.
A small round-trip test could:
load known intrinsics;
modify/optimize them;
export;
reload the exported camera values;
verify the same ray geometry is reconstructed.
Is there already a supported Python/Testbed accessor for these final values that should simply be documented, or would exposing one be welcome?
