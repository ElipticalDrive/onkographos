Motivation
Provide end-to-end tooling to render 3DGS PLYs into orbit RGB/mask/pose frames and produce COLMAP-compatible datasets for downstream reconstruction and training.
Support creation of COLMAP TXT+BIN models directly from orbit renderer outputs or from original 3DGS PLY point clouds to simplify dataset preparation.
Add mesh extraction flows that respect external masks and improved integration-based marching tetrahedra, and provide a mask-refinement utility using GroundingDINO + SAM2.
Description
Extended milo/convert.py with a new --from_orbit_output mode that builds a COLMAP text+binary sparse model from ./data/{images,masks,poses}, including write_colmap_binary_model and support for writing images as RGBA via --write_rgba_images.
Added milo/convert3dgs.py to build COLMAP datasets directly from a 3DGS PLY (--ply_path), exporting images, masks, poses, sparse TXT files and binary cameras.bin, images.bin, points3D.bin with optional point subsampling via --max_points.
Reworked milo/render_3dgs_orbit_video.py to a modernized renderer that reads native 3DGS PLYs, uses GaussianRasterizer for rasterization, produces per-frame PNG images and masks, writes per-frame poses/*.json, supports dual-distance configs (near/far), and writes outputs under data/{images,masks,poses,video}.
Added mesh extraction utilities: milo/mesh_extract_dtu_mask.py for mask-aware TSDF-based reconstruction from rendered views, and milo/mesh_extract_integration_mask.py which implements marching tetrahedra with binary search and view-mask support plus vertex coloring via depth-fusion/integration SDF evaluation.
Added milo/refine_masks_gdino_sam2.py that refines/filters existing masks using GroundingDINO to predict bounding boxes and SAM2 to generate refined masks, with an option to intersect with original masks.
Added milo/train_mask_regular_densification.py, a comprehensive training script that injects external masks into camera views, supports mesh-in-the-loop regularization, depth-order priors, densification (RaDEGS), and logging/WandB hooks.
