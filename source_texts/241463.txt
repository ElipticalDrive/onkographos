Ohh I'm sorry. Yeah, if you press spacebar in runtime it generates optimized code and copies it to the clipboard. So that path is the fast one, and it has a couple of optimizations that make possible rendering some of the complicated structures.
It can be improved and I will be doing some changes in the future, as I think my approach is too naive as I should get into proper compiler-like optimizations (this repo was a proof of concept mainly). I haven't done any work on UI or usability yet, since after the toolkit came out I'm rethinking what to do.
I see your point regarding the license, I feel the same way, as I prefer something that is more open like MIT, particularly because it would generate more collaboration. I'll try out the toolkit in the following days and experiment a bit to see their main approach. I feel like their focus is more on being a raymarching rendering context for games than an sdf code generator, so there shouldn't be a conflict of interest.
I hope that clears out the doubt!
