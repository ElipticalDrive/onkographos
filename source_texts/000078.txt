## About

This is a WebGPU implementation of the digital differential analyzer (DDA) voxel raymarching algorithm described by Amanatides and Woo in their paper *[A Fast Voxel Traversal Algorithm for Ray Tracing](http://www.cse.yorku.ca/~amana/research/grid.pdf)*, accelerated with a dense octree. You can run the app in browser [at this link](https://webgpu-voxel-raymarching.vercel.app/).

## Features
- Multiple voxel colors and materials, including matte, emissive, metallic, mirror, and eraser
- A dense octree structure for accelerated raymarching
- World interaction with a flexible brush tool (control shape, color, material, size)
- An accumulation denoiser which uses a velocity texture for reprojection
- Fun visual filters (normals, positions, marches, flat colors, depth, toon)
- Depth based smearing prevention
- World and lighting customization using sliders

## Controls
- WASD to move camera
- Hold right click and move mouse to rotate camera 
- Left click to brush
- Space to ascend
- Shift to descend

## Running Locally
You can run the app now [at this link](https://webgpu-voxel-raymarching.vercel.app/), but if you want to run it locally then you will need Node.js installed on your computer. In the project directory simply run `npm install` to install packages, and then `npx vite` to start the app. 

## Implementation Details
Voxel data is stored in a 3D texture. Each voxel is 8 bits, 4 bits for color and 4 bits for type. 4 voxels are packed into each single 32 bit texel on the 3D texture. The octree is also stored as a 3D texture. I experimented with storing the octree data in a linear buffer using morton curve, but found that using a 3D texture was significantly faster for ray traversal, likely because graphics hardware is optimized for spatially local texture access. The raymarcher first marches through the octree texture and once it hits a leaf, will switch to the voxel texture. Lighting is a standard path-tracing implementation where each bounce updates throughput, samples a new direction, and accumulates emitted or reflected light.

## Performance
A powerful GPU is required to run this app at a smooth framerate. An RTX 3090 can run this at 4K and averages around 120fps, but sometimes dips to 60 fps or lower depending on scene complexity. If your GPU is struggling, I would recommend lowering the render scale or making your browser window smaller. Larger worlds also affect performance negatively.
