Tr2VoxelTexture: expose a voxel data channel as a 3D texture
Adds Tr2VoxelTexture, an ITr2TextureProvider that turns one payload channel of a Tr2VoxelData into a 3D texture. Shaders index it with tex[uint3(x, y, z)], and it can be bound with e.g. Tr2RuntimeTextureParameter.
Formats: each voxel type maps to the matching 1/2/4-component format (*_FLOAT, *_UINT, *_SINT), and normalized 8/16-bit channels use *_UNORM/*_SNORM. Boolean channels are unpacked to one byte per element (R8*_UINT).
Unsupported: 3-element channels and normalized 32-bit integer channels. These log an error, and bound parameters fall back to the default 3D texture.
Updates: setting voxelData or channel rebuilds the texture. Edits through SetVoxels to the selected channel are re-uploaded in place.
Tr2VoxelData: adds Tr2VoxelDataTypeName() for logging, plus GetPackedBit/SetPackedBit so the Boolean bit layout is defined in one place.
