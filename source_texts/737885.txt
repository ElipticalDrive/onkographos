As an extension to the previous project, this Unity project has provisions to allow a dynamic octree to track gameobjects and grow at run time in the editor. The hope is to be able to add objects to the octree whose meshes which would then become part of the original skinned mesh renderer. The ability to instantiate vertices as voxel cubes is also provided. - skore11/VoxelTest_DynamicOctree_vertexInstantiate
