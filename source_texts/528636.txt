Background
The previous volumetric cloud implementation has been completely removed from the codebase. We are restarting from zero and porting the proven algorithm from clayjohn/realtime_clouds, which is explicitly designed to approximate the cloudscapes in Horizon Zero Dawn and runs at 0.5–2 ms/frame on a GTX 1050.
Reference projects studied:
clayjohn/realtime_clouds — core ray-marching, Perlin-Worley/Worley noise, weather map, checkerboard upscaling + reprojection.
NadirRoGue/RenderEngine — cone sampling for light march, Beer-Powder-HG lighting, cloud filter/temporal, cloud shadows.
sebh/TileableVolumeNoise — tileable Worley and Perlin noise primitives used by both projects.

Definition of done for the whole roadmap
cargo test -p aether-engine --lib passes.
cargo build -p aether-launcher --release succeeds.
A dedicated test scene (scenes/XX_clouds.ron) launches and renders recognizable clouds.
Every phase saves a screenshot to tests/output/clouds/phase_N/ for visual review.
TDD approach
Each phase must contain tests before/with implementation:
Unit tests for math/noise functions (range, tileability, determinism).
Pass signature / resource tests.
Scene serialization round-trip tests.
Launcher screenshot verification as the final acceptance check.
This issue supersedes the previous generation of open volumetric-clouds issues that targeted the now-deleted implementation.
