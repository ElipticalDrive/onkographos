This MATLAB script sorts a collection of DICOM images according to their DICOM InstanceNumber tag and saves the reordered images into a new folder. The script automatically reads DICOM metadata, identifies the correct slice order, and generates a new sorted DICOM series with sequential filenames. Original metadata are preserved whenever possible using DICOM copy mode.

Features:
- Automatic DICOM folder selection
- Sorting based on DICOM InstanceNumber
- Metadata preservation during export
- Creation of a new sorted DICOM series
- Automatic output folder generation
- Fallback support for images with missing metadata

Inputs:
- Folder containing DICOM (.dcm) images

Outputs:
- New folder named "sorted"
- Sequentially ordered DICOM images (img_001.dcm, img_002.dcm, ...)

Applications:
- MRI, CT, PET, and SPECT image preprocessing
- Image reconstruction workflows
- Radiomics and quantitative imaging pipelines
- Preparation of datasets for machine learning and image analysis
