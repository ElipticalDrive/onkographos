Motivation
Replace the legacy gaussian_lidar layout with a focused, PyTorch-first library that implements virtual LiDAR scanning from 3D Gaussian Splatting scenes and targets Apple MPS/Metal for GPU acceleration.
Provide a clear, testable reference CPU tracer and a path to an MPS-accelerated tracer using torch.mps.compile_shader while keeping the public API PyTorch-native (results remain torch.Tensor).
Description
Removed the old gaussian_lidar tree and the prompt file, and added a new package src/gs_lidar with core modules: gaussian_cloud.py, gaussian_geometry.py, bvh.py, loader.py, lidar.py, cpu_tracer.py, metal_tracer.py, metal/lidar_trace.metal, simulator.py, scan.py, and rerun_viewer.py.
Implemented data types and semantics: GaussianCloud (means/scales/rotations/opacities), FlatBVH (flat tensor BVH), LidarPose/LidarConfig, LidarScan with valid_points() that returns a torch tensor on the scan device, and LidarSimulator to pick CPU/Metal backend.
CPU tracer implements brute-force/BVH flows, per-ray candidate evaluation (t_peak, q_min), stable sort by t_peak, front-to-back alpha compositing and configurable threshold; Metal tracer dispatches a compiled Metal kernel that performs BVH traversal, bounded candidate collection (128), per-ray insertion-sort, alpha accumulation and reports candidate/stack overflow counters.
Added PLY loader that converts canonical 3DGS fields into internal PyTorch tensors (exp for log-scales, sigmoid for opacity logits, quaternion normalization), CLI experiment experiments/01_basic_scan.py, README.md, pyproject.toml, and a suite of unit tests in tests/test_core.py covering geometry, accumulation, BVH parity and a conditional Metal smoke test.
Testing
Ran python -m compileall -q src experiments tests which succeeded for the new/modified Python sources.
Attempted python -m pytest -q but collection failed with ModuleNotFoundError: No module named 'torch' because test dependencies (PyTorch) were not available in the environment; GPU/Metal tests are skipped when MPS/compile_shader is absent.
Attempted uv sync --extra test to install test deps but the environment could not fetch PyPI packages (network/tunnel error), so automated dependency installation did not complete.
