Motivation
Provide a playable browser-first voxel sandbox entrypoint instead of a placeholder README.
Ship a lightweight, single-folder prototype that demonstrates polished gameplay loops (movement, building, undo/redo, minimap, day/night) with no build step.
Prefer browser-compatible patterns (Three.js instancing, Pointer Lock controls, canvas minimap) for fast startup and easy local testing.
Description
Added a playable front end: index.html, styles.css, and src/main.js implementing a procedural voxel world, instanced rendering, pointer-lock first-person controls, block break/place, undo/redo, boost dash, and a dynamic day/night cycle.
Implemented procedural generation helpers: hash2d, smoothNoise, fractalNoise, biomeAt, and terrainHeight, and a seeded world generator with multiple biomes.
Optimized runtime features: instanced meshes for blocks, a canvas minimap with zoom, HUD overlays (hotbar, toast, biome/time/altitude), and lightweight physics/collision for player movement.
Replaced placeholder docs with README.md documenting features, controls, and local run instructions (python3 -m http.server 4173).
Testing
Ran a static parsing check with Node: node --input-type=module -e "import fs from 'fs'; const src = fs.readFileSync('src/main.js','utf8'); new Function(src.replace(/^import .*$/mg,'')); console.log('main.js parses after stripping imports');" which succeeded.
Served the project locally with python3 -m http.server 4173 and verified HTTP responses with curl -I http://127.0.0.1:4173/ and curl -I http://127.0.0.1:4173/src/main.js, which returned successful 200 OK responses.
Browser UI/runtime verification (visual/screenshot) was not executed in this environment due to lack of an interactive browser.
