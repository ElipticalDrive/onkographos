Complete C# port of the Python SDF library for generating 3D meshes from signed distance functions.
Implementation
Core Library (1,237 LOC)
Vector3: 3D vector math with operator overloading
SDF3: Main class supporting | (union), & (intersection), - (difference) operators
Primitives: Sphere, Box, Cylinder, CappedCylinder, Torus, Plane
Operations: Boolean ops with smooth variants, transformations (Translate, Rotate, Scale, Orient)
Core: Parallel mesh generation with automatic bounds estimation and sparse sampling
MarchingCubes: Simplified surface extraction via linear interpolation
StlWriter: Binary STL export
Examples
SimpleTest: Basic sphere generation
CSGExample: Canonical CSG demo (sphere ∩ box - cylinders)
TransformExample: Torus on box with transformations
API Parity
Python and C# use identical operator semantics:
```
// Python: f = sphere(1) & box(1.5)
var f = Sphere(1.0) & Box(1.5);

// Python: f -= c.orient(X) | c.orient(Y) | c.orient(Z)
f = f - (c.Orient(X) | c.Orient(Y) | c.Orient(Z));

f.Save("out.stl");
```
Performance
Parallel batch processing generates meshes in sub-second times:
8.6K triangles (sphere): 0.08s
32K triangles (CSG): 0.30s
24K triangles (transforms): 0.21s
Not Ported
2D SDFs and extrusion operations
Advanced primitives (platonic solids, pyramids)
Deformation ops (twist, bend, elongate)
Text/image support
Mesh import via OpenVDB
See README-CSharp.md and PORTING-SUMMARY.md for complete documentation.
