This is not a necessary task currently but I am leaving information and resources for how to do this.
Read through the streaming section in the voxel hashing paper
This paper stores the entire block heap on the cpu and only the hash table on gpu
The workflow will change from after retrieving traversed voxel blocks for a point cloud, both the gpu and cpu will have to be checked for the voxel blocks and if on cpu stream that chunk back to the gpu. Instead of garbage collection voxel chunks will instead be streamed to the cpu
