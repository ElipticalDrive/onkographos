The core feature to allow this map types is a DiscreteTree class which is the entry of every 2D cell and a ray tracing implementation based on "A fast voxel traversal algorithm for ray tracing."
In future iterations this part could run on a GPU.
It also includes vizkit plugins for the new types and TSDF based surface reconstructions to pcl::Polymesh and a MLSMapPrecalculated based on "Paul Bourke's Marching Cubes".
Edit: There is also the option now to add a occupancy grid map to a MLS in order to model free space.
