Issue body actions
Build an evaluation system that computes all the metrics we need to compare NeRF and VGGT reconstructions. This includes standard metrics like PSNR, SSIM, and LPIPS, plus integrating DreamSim for view synthesis evaluation. If we have ground truth camera poses, add pose accuracy metrics. Also create depth completeness metrics to see how well each method reconstructs the full scene. Build visualization tools that let us compare metrics side-by-side, and create automated report generation so we can quickly see how different methods perform. The goal is to have a unified evaluation pipeline that works for both NeRF and VGGT outputs.
