How do you plan to handle transparency (if that's even a problem)? For example, if you render a volume in MIP mode, will the positions be based on the MIP point?
Yup! The frag depth is based on the point where the fragment color is sampled from. For modes, like MIP, MINIP, attenuated MIP, and ISO, I think it is clear that the sample point is the where the max/min/surface was found. For other modes like additive and translucent, I think it is less clear, but maybe we can do something like the midpoint of nearpos and farpos (or wherever the iteration ends if it terminates early). Thoughts?

I've updated this PR to reflect the vispy PR and also implemented the setting the depth for the labels iso_categorical mode. We can now mill away a labels layer and reveal another layer underneath.
labels_milling.mov
```
"""
Display a labels layer above of an image layer using the add_labels and
add_image APIs
"""

from skimage import data
from scipy import ndimage as ndi
from skimage.morphology import cube
import napari


blobs = data.binary_blobs(length=128, volume_fraction=0.03, n_dim=3)
viewer = napari.view_image(
    blobs[::2].astype(float),
    name='blobs',
    rendering='iso',
    scale=(2, 1, 1)
)
# dilate the image before labeling to avoid z-fighting
labeled = ndi.label(ndi.binary_dilation(blobs, cube(4)))[0]
viewer.add_labels(labeled[::2], opacity=1, name='blob ID', scale=(2, 1, 1))

napari.run()
```
I think this is now ready for review!
