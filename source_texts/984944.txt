🎯 Epic Overview
Prioritate: HIGH
Sprint: MVP v0.1
Estimare: 6-8 ore
Deadline: 14 Noiembrie 2025
📋 Description
Sistem de generare procedurală pentru game world cu tile-based terrain, biomes, și chunk loading. Esențial pentru open-world experience.
✅ Acceptance Criteria
Map generat procedural cu seed reproductibil
Minimum 3 biomes distincte (plains, forest, mountains)
Tile system cu textures pentru fiecare biome
Chunk-based loading pentru optimizare
Smooth transitions între biomes
Perlin/Simplex noise pentru natural terrain
Map vizibil în game cu proper rendering
🔧 Technical Tasks
Tile System
TileType enum (Grass, Water, Stone, Sand, etc.)
Tile struct cu properties (walkable, sprite_index)
TileMap component pentru grid management
Noise Generation
Implement/integrate noise library (simplex/perlin)
Multi-octave noise pentru detalii
Height map generation
Biome System
BiomeType enum
Biome distribution logic
Temperature + moisture maps
Biome-specific tile mapping
Chunk System
Chunk struct (16x16 sau 32x32 tiles)
Chunk loading/unloading based on player position
Chunk cache pentru performance
World Renderer
Efficient sprite batching
Culling pentru off-screen tiles
Z-ordering pentru layers
🔗 Dependencies
Player movement system ([EPIC] Core Game Loop - Player Movement & Basic Mechanics #1)
Camera system ([EPIC] Core Game Loop - Player Movement & Basic Mechanics #1)
Sprite assets (placeholders OK)
📦 External Crates
noise-rs or bracket-noise pentru noise generation
bevy_ecs_tilemap (optional, evaluează vs custom)
🎮 Testing Checklist
Seed-ul generează același world
Performance > 60 FPS cu 1000+ tiles vizibile
Chunk loading smooth (no stuttering)
Biomes distribuite natural
Memory usage acceptabil (< 200MB pentru WASM)
