Faster conversion of Point Cloud to Occupancy Grid and vice versa
Open3D has implemented the voxelization of point clouds. Since Open3D has CUDA bindings, this would speed up converting point clouds to voxel grids.
Please refer to Open3D Voxelization (Occupancy Grid) from Point Cloud
It is important to note that not all points in the Velodyne point cloud should be used to generate the grid. Only the points in the FOV of the camera must be used. The function transform_points_to_occupancy_grid implements this filter. We must see how we can run this filter in parallel or offload the logic.
