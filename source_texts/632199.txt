Adds RGB median-cut quantization, supplied color maps, RGB/RGBA expansion and palette attachment through shared Rust algorithms, CLI/MCP, Python and JavaScript for #289. Generated palettes support 2..256 colors, 5/8-bit precision and GDAL-compatible integer error diffusion. A supplied table determines its own color count; typed nonnegative color_count values are ignored in that mode across the APIs and CLI.
Inputs may be paths, dataset handles or uploaded raster/color-file bytes where applicable. Color tables support indexed GDAL/GRASS text, RGB GMT CPT endpoints and QGIS QML/QLR XML, including hintless UTF-8 BOM-prefixed XML. Indexed CPT interior entries are padding, matching GDAL palette conversion. Explicit QGIS XML alpha is honored rather than reproducing GDAL's parser bug.
Shared VFS/VSI parsing preserves literal filename whitespace across commands, and stat/list reports return the exact inspected name. A whitespace-prefixed URL is a literal local filename; input-list callers retain their own normalization. Distinct-data regressions prove that native and virtual names do not alias trimmed neighbors.
Validation
A local environment with GDAL 3.13.3:
113 exact registered Landsat/OPERA comparisons pass: pixels, palettes, nodata/masks, types, color interpretations, CRS and transforms. Four-entry supplied text tables are exercised with --color-count 2; attachment is checked against GDAL SetRasterColorTable.
15 palette-filtered Rust tests, 49 VSI tests and three CLI regressions pass. CLI tests accept supplied-table counts 0, 1, 257, 65535 and usize::MAX, verify decoded indices, and reject those counts without a table before writing.
Rebuilt optimized artifacts pass 11 Python tests and 12 Node tests, including BOM-prefixed XML, malformed indexed storage, exact path reporting, PNG alpha through GDAL file/byte-package reads and reopened-TIFF validity. Optimized CLI/Python/release WASM builds and pre-commit, including workspace Clippy with warnings denied, pass.
A remote masked COG read/write probe transferred 853,046 bytes before and after, with two versus three GET responses and unchanged data/masks. Supplied-table lookup on the complete Landsat fixture fell from 0.517/0.519 s to 0.284/0.289 s in two local runs with byte-identical output. These are fixture-specific observations, not timing guarantees.
Scope and limitations
Operations materialize full input/output arrays. Shared RGB nodata takes precedence over dataset/alpha/caller masks, matching GDAL. Supplied tables require output_nodata to mark invalid pixels; nodata reservation may truncate a full supplied table. All-invalid generated palettes succeed.
RGBA expansion preserves partial palette alpha and makes dataset-mask/nodata exclusions transparent. Unmapped indices are black in RGB and transparent black in RGBA. GeoTIFF palette storage carries RGB; suitable expanded outputs carry alpha. Dataset masks are retained in handles and GeoTIFF/COG output; other formats and tile-archive restrictions are documented.
XML color files are bounded to 10 MiB, 65,536 elements and 256 nesting levels. The byte limit includes a BOM and is enforced during size-less streaming reads. Algorithm ports and historical libtiff terms are attributed in both NOTICE files. GDALG pipelines and subdataset append remain separate #289 work.
Roadmap edits record already-merged #374/#375/#378. Palette remains unchecked until this PR merges, and #289 remains open.
