Summary
Extends FastInterpolations.jl from 1D + CubicND to a complete N-dimensional interpolation toolkit. Three new ND interpolant types — ConstantND, LinearND, and QuadraticND — plus a shared core infrastructure that unifies all ND algorithms.
The API generalizes the 1D interface naturally: where 1D takes a scalar, ND takes a Tuple for grids, query points, and per-axis settings.
New ND Interpolant Types
ConstantInterpolantND
N-dimensional step (nearest-neighbor) interpolation with per-axis side selection.
```
x = [0.0, 1.0, 2.0, 3.0]
y = range(0.0, 2.0, 20)
data = rand(4, 20)

itp = constant_interp((x, y), data; side=:nearest, extrap=:constant)
itp((0.5, 1.0))   # scalar query
```
Per-axis configuration: side=(:left, :right), extrap=(:none, :wrap)
Batch evaluation: both SoA (xs, ys) and AoS [SVector(x,y), ...] forms
LinearInterpolantND
N-dimensional multilinear (bilinear, trilinear, ...) interpolation.
```
x = range(0.0, 1.0, 11)
y = range(0.0, 2.0, 21)
data = [sin(xi) * cos(yj) for xi in x, yj in y]

itp = linear_interp((x, y), data)
itp((0.5, 1.0))                    # bilinear interpolation
itp((0.5, 1.0); deriv=(1, 0))     # ∂f/∂x (analytical)
itp((0.5, 1.0); deriv=Val((1, 0))) # type-stable derivative via Val
```
O(2^N) tensor-product evaluation with @generated loop unrolling
Full partial derivative support up to first order
QuadraticInterpolantND
N-dimensional quadratic interpolation with precomputed partial derivatives at grid nodes.
```
x = range(0.0, 2.0, 20)
y = range(0.0, 1.0, 15)
data = [xi^2 + yi^2 for xi in x, yi in y]

itp = quadratic_interp((x, y), data; bc=QuadraticFit())
itp((1.0, 0.5))                  # evaluate
itp((1.0, 0.5); deriv=(1, 0))   # ∂f/∂x
itp((1.0, 0.5); deriv=(0, 2))   # ∂²f/∂y²
```
Precomputes all 2^N partial derivative combinations per grid node at build time
O(1) evaluation via tensor-product quadratic polynomial kernel
Supports all QuadraticBC types: Left(...), Right(...), MinCurvFit()
Automatic BC conversion: NaturalBC() → Right(Deriv2(0)), QuadraticFit() → Right(QuadraticFit())
Unified API Design
All ND interpolants follow a consistent pattern:
Feature
API
Construction
method_interp((x, y, ...), data; kwargs...)
Scalar query
itp((x, y, ...))
Batch SoA
itp((xs, ys, ...))
Batch AoS
itp(points)
Derivatives
itp(pt; deriv=(dx, dy, ...)) or deriv=Val((...))
Per-axis config
extrap=(:none, :wrap), search=(Binary(), Hunt())
Shared Core Infrastructure (core/nd_utils.jl)
Extracted ~476 lines of shared utilities used by all ND interpolants:
_resolve_* functions — Convert flexible user input (scalar or tuple) to canonical N-tuple form for extrap, search, side, and BC parameters
_compute_all_local_params — @generated function computing cell index, normalized coordinate, and grid spacing for all N dimensions in a single pass (zero-allocation)
NodalDerivativesND{Tv, N, NP1} — Shared storage for 2^N partial derivative arrays at grid nodes, used by both CubicND and QuadraticND
_resolve_deriv_nd — Unified derivative dispatch supporting Int, Val, and NTuple{N,Int} inputs
CubicND Refactoring
The existing CubicND module was refactored for consistency:
File rename: nd_*.jl → cubic_nd_*.jl for clarity alongside sibling modules
Shared infrastructure: NodalDerivativesND and _compute_all_local_params moved to core/nd_utils.jl
Type constraints relaxed to support heterogeneous grids (see below)
Heterogeneous Grid Support
All ND interpolants now support mixing grid types across dimensions:
```
x = range(0.0, 1.0, 10)         # uniform (Range)
y = [0.0, 0.3, 0.7, 1.5, 2.0]  # non-uniform (Vector)

itp = cubic_interp((x, y), data; bc=CubicFit())  # works!
```
This required changing type constraints from NTuple{N, <:AbstractVector} (all same concrete type) to Tuple{Vararg{AbstractVector, N}} (each axis can differ).
