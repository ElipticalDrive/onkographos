The current voxel tracing logic traverses through the cavities to ray trace and register first hit. Then, further it does path tracing for global Illumination. This is good for creating a render of small voxel assets, but isn't fast enough for real time rendering usage.
We do have run-length optimization to optimize the steps needed for the first hit. While, this is quite a nice speed up, it is unconventional to ray trace a 3d texture, and in practice, I don't think it will be faster than the rasterizing polygons.
One of the problem may be that GLSL shader has to have preset number of iterations to every pixel shader session.
Also, if I wanted to scale to 10K voxel arts in a scene, path tracing quickly becomes a no-brainer.
So, let's update the code so that when I input an voxel file, it would generate an obj kind a file.
voxel ➜ obj, uv, color, prop textures (may be 3d).
