# Ray Tracer Project - Intro to Computer Graphics Course
This project implements a classical Ray Tracer in Python, developed as part of the
*"Introduction to Graphics, Image Processing & Computer Vision"* course at TAU's School of Computer Science (2025–2026),
during the final year of our studies. The project focuses on building a full rendering pipeline from scratch, 
recursively sending the ray from the camera to the 3D objects in the image. 

The project focuses on ray–object intersection, illumination, shadow computation, and recursive light
transport effects. The renderer supports multiple scenes and materials, and was
extended to handle soft shadows, reflections, and transparency to achieve a sense of
visual realism.

More specifically, as a group of 2, we developed the project incrementally, with the following core components:

- Camera model and perspective projection.
- Ray casting and ray–surface intersection (spheres, planes, cubes).
- Phong illumination model (specular & diffuse light computation from various light sources in the scene).
- Hard and soft shadow computation using shadow rays.
- Recursive reflections & transparency handling.
- Scene parsing from text-based scene description files.

The project's final grade - 100.

## Project Structure

The repository is organized in a modular, object-oriented manner, with each
component of the ray tracing pipeline implemented in a dedicated module:

- `ray_tracer.py`: Core ray tracing loop, including ray casting, shading, and recursion control.

- `camera.py`: Camera model and perspective projection logic.

- `light.py`: Light source definitions and illumination parameters.

- `material.py`: Material properties, including diffuse, specular, reflection, and transparency coefficients.

- `scene_settings.py`: Global rendering parameters such as background color, recursion depth, and number of shadow rays.

- `surfaces/`: Objects which represent geometric primitives supported by the renderer (spheres, planes, cubes), each with
  its own ray–surface intersection logic.

- `scenes/` & `new_scenes/`: Text-based scene description files defining camera setup, objects, materials, and lights.

- `Examples/`: Example scenes and corresponding rendered outputs used for testing and visualization.
