Label: mesh-terrain Priority: 7
Cylinder terrain generation script and supporting engine functions. Lives entirely in /game. Uses engine utilities (noise, density field, chunk management) without adding cylinder assumptions to the engine.
Chunk culling algorithm:
Build chunk grid for full volume (2000×2000×2500 at 32³) — ~305,000 slots, cheap bounding-box-vs-circle math only
Outer boundary test: discard chunks fully outside radius 1000m
Inner boundary test: discard chunks fully inside radius 900m
~45,500 chunks survive per 2500m segment — these receive full generation
Heightmap (seamless wrap-around):
height = noise(cos(angle) * r, sin(angle) * r, lengthPosition)
cos/sin guarantees seamless 0°/360° wrap by definition. Length axis not wrapped (bounded by segment walls).
Also required:
Trigger 2D wraparound map generation (ISSUE 12) from same seed before chunk work begins
