Question❓
Does QuasiMonteCarlo.jl handle sampling of discrete variables at all? From the docs it doesn't seem like it does, so I'd have to do my own binning of continuous variables. If it doesn't, are there any plans to include this feature?

No, QuasiMonteCarlo.jl has no native discrete-variable sampling: every sampler produces continuous points in [0, 1)^d (or in [lb, ub] with sample(n, lb, ub, sampler)). You don't have to bin by hand:
Use the inverse CDF of the discrete distribution, which keeps the low-discrepancy structure of the unit-cube points:
```
using QuasiMonteCarlo, Distributions
u = QuasiMonteCarlo.sample(1024, 2, SobolSample())     # 2 × 1024, in [0,1)
k = quantile.(Binomial(10, 0.3), u[1, :])               # Int-valued
c = quantile.(Categorical([0.5, 0.3, 0.2]), u[2, :])    # categories 1, 2, 3
```
For a uniform integer range, bin with floor.(Int, lo .+ (hi - lo + 1) .* u).
I ran this: the Binomial draws have mean 3.0 (exact 3.0), the categorical frequencies are 0.5 / 0.2998 / 0.2002, and a die from floor.(Int, 1 .+ 6 .* u[1, :]) gives 0.1660-0.1670 per face. With LatinHypercubeSample, 12 points binned into 6 levels give exactly 2 per level, so stratification is kept when the number of levels divides n.
Caveats: the transformed integrand has jumps, so QMC convergence is slower than for smooth integrands, and sample(n, lb, ub, ...) with integer bounds does not round for you.
If you'd like first-class support (e.g. an IntegerSample/DiscreteSample wrapper that applies quantile for you), what interface would you want: a distribution per dimension, or just integer bounds? A small PR adding a docs example of the quantile recipe above would also be welcome.
