# Scientific Visualization 2026 – Course Exercises

## Course Exercises Overview

This repository contains C++ and shader implementations for the Scientific Visualization course exercises[cite: 1]:

* **Exercise 1: Point Rendering**
  * Implements 3D point cloud visualization using point splatting, expanding particles into screen-facing billboards, and calculating ray–sphere intersections, depth buffer writing, and transfer function color mapping in the fragment shader[cite: 1].
* **Exercise 2: Direct Volume Rendering**
  * Implements GPU-based direct volume rendering on 3D CT scalar fields via proxy geometry ray marching, Beer–Lambert transfer function lookup, front-to-back compositing, and single-scattering shadow rays[cite: 2].
* **Exercise 3: Isosurface Ray Casting**
  * Directly computes volume isosurfaces by detecting sign changes along camera rays, refining surface intersections using bisection, calculating central difference normals, and rendering Lambertian shading with dynamic shadows[cite: 3].
* **Exercise 4: Critical Point Extraction**
  * Locates and classifies vector field critical points ($v(x) = 0$) using a recursive voxel subdivision algorithm with early-out sign tests, Jacobian matrix evaluation, and eigenvalue analysis (sinks, sources, saddles)[cite: 4].
* **Exercise 5: Line-based Flow Visualization**
  * Traces 3D streamlines using Euler, RK2, and RK4 numerical integration schemes, visualized using the Zöckler et al. illuminated streamline shading model and periodic brightness animation[cite: 5].
* **Exercise 6: Texture-based Flow Visualization (LIC)**
  * Implements Line Integral Convolution (LIC) in a GPU compute shader, generating dense 2D flow representations by convolving noise textures along forward and backward RK4 streamlines[cite: 6].
* **Exercise 7: Unsteady Flow Visualization (FTLE)**
  * Computes Finite-Time Lyapunov Exponents (FTLE) on time-dependent double gyre flows using RK4 trajectory integration, Cauchy–Green deformation tensors, and comparing finite difference gradients against localized linearization methods[cite: 7].
* **Exercise 8: Stream Surface Extraction**
  * Extracts 2D stream surfaces in 3D vector fields using the Hultquist advancing front algorithm, incorporating recursive diagonal edge evaluation and adaptive front refinement[cite: 8].
* **Exercise 9: Feature-based Flow Visualization**
  * Extracts flow structures around 3D geometry using finite-difference spatial derivatives to evaluate four classical vortex criteria: Vorticity Magnitude, Helicity, Q-Criterion, and the $\lambda_2$ Criterion[cite: 9].
