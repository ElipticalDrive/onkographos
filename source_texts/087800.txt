Summary
Avoid repeated surface-structure conflict scans by resolving direct candidate sets against one broad-phase candidate set while preserving deterministic precedence and overlap rules.
Precompute cave value-noise lattice corners per chunk; only build cave channels and vertical spans that can affect the current chunk. Tests verify exact parity with scalar noise.
Cache primary biome influence, hoist material-cover rules and geology scales/weights out of voxel loops, avoid unused cluster rotations, and skip unnecessary geological boundary allocations.
Skip density evaluation for vertical ranges where cave and additive rules cannot apply.
Store per-chunk voxel occupancy in compact per-column solidity masks instead of a dense double array for normal materialization. Exact numeric densities remain available through lazy expansion.
Use unchecked solidity reads only inside chunk-local loops that already establish valid coordinates; retain checked reads for probes that can cross chunk boundaries.
Resolve applicable exposed surface geology before volumetric geology, skipping a volumetric material selection when the surface deposit will overwrite that same voxel.
Avoid redundant surface-destination density checks for regular terrain while retaining fluid, shell-boundary, and additive-formation validation.
Precompute coordinate-hash components for continuous 3D value noise without changing the hash formula or generated outputs.
In fluid meshing, reuse surface-height samples across all meshlets in one immutable worker batch, sample each current voxel's fluid permeability locally, and combine neighbor-block/neighbor-fluid sampling into one world-to-chunk lookup.
In terrain meshing, replace the per-meshlet fine-geometry array with a cleared stack buffer and reuse the greedy face-candidate buffer across all six face orientations.
Fluid simulation rules, source/spread behavior, and rendered fluid geometry are unchanged.
Validation
CI run #40236203555 passed both jobs on commit a6787a9: Core tests, Godot C# builds, headless scene/shader validation, worldgen benchmark/fixtures, and WebUI build/parity.
A subsequent fluid-neighbor sampling optimization was committed as 2b5723c after that successful run. The current head still needs CI confirmation; no performance gain is claimed for the new rendering changes until render-specific measurements are available.
Earlier worldgen diagnostics on the 75-chunk initial area measured about 652 ms cold / 388 ms warm for materialization, versus about 737 / 402 ms in the preceding successful run. Allocations remained about 87.2 MB cold / 55.8 MB warm. These are directional shared-runner measurements and predate the new rendering changes.
The experimental shared corner cache in the terrain density path was discarded because it increased allocations and materialization time. The fluid surface-height cache is a separate, bounded per-worker-batch cache.
This PR targets worldgen-remake; it has not been merged to main.
Scope
No lighting system is reintroduced. Terrain/material decisions remain deterministic in world coordinates. Density representations and rendering scratch/cache state are bounded; fluid meshing reads an immutable worker snapshot.
Incremental chunk materialization
Split biome chunk creation into resumable stages, including terrain setup, vertical terrain layers, surface decorations, cave/material passes, structures, generated fluids, wall details and final objects.
Schedule each chunk stage in bounded worker slices; keep the chunk private until all stages complete, then publish it atomically to live residency.
Bound suspended jobs, prioritize resumptions near the player, and discard paused/in-flight partial jobs safely during selection changes and dimension retirement.
Log per-stage execution count, total and maximum worker time, active/suspended materialization jobs, and end-to-end chunk materialization latency.
No runtime performance improvement is claimed yet. The new diagnostics are intended to identify the dominant stage and distinguish CPU time from queue/scheduling latency in the next profile.
