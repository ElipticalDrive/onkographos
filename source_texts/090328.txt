The function Octree.BuildOctree() has an error with the calculation of the offset position of the added point. An easy way to see this is to:
Run an editor build (from source)
Add a DualContouringObject3D to the bed from the side bar or primitives folder
Set the Iterations to 3
Observe that the corners are not pointy and the edges are not on the cube boundary.
Fixing this issue will result in all the edges and corners of the DualContouringObject3D being sharp at every Iteration size.
This must have a test that demonstrates the functionality is working
I have added another few modes to show some more error conditions as well as the ability to output marching cubes to demonstrate more of what the dual marching should produce.
