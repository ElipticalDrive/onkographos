Motivation and Context
I've build a framework that can voxelize a scene or object to a specified resolution, creating a boundary voxelization (voxels are booleans - either filled or unfilled), and construct other voxelizations within the same VoxelGrid class (signed distance fields, Vector fields, etc). It includes various ways of visualizing the fields constructed which can be tested in Viewer.
The following is an example of a rendered vector-field.
Going in viewer and using Ctrl + Right Click will voxelize a selected object
The voxelization framework has been built in a flexible way such that users can employ the framework for their own purposes.
How Has This Been Tested
A simple test is found in src/tests/VoxelGridTest.cpp, which tests voxelizing a scene, retrieving voxels, and converting voxel indices into global coordinates and vice versa.
Types of changes
Implemented a voxelization framework in VoxelGrid.cpp and VoxelWrapper.cpp
Added a voxel field visualizer in viewer (Ctrl + Right Click)
Added Simulator functions for voxelizing a scene/object, retrieving the voxelization, and visualizing the voxelization mesh.
What else needs to be done
For this PR:
I've built functionality for generating Distance Gradient fields and Signed distance fields, and will be adding those to a utility class in a follow up PR.
I will also do a PR with python bindings and a tutorial.
