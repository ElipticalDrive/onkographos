This PR refactors autoware_downsample_filters voxel-grid downsampling by separating ROS-independent core logic from the ROS node.
Main changes:
Add VoxelGridDownsampleFilter to encapsulate input validation and filtering logic.
Move validation and filtering orchestration from VoxelGridDownsampleFilterNode node into the new core.
For adding tests for the applied changes, I'll create a separate PR.

None yet, but will link to the test PR once created.

Notes for reviewers
This is primarily a refactor for separation of concerns and clearer error propagation.
Interface changes
No ROS topic/service/client interface changes.
No ROS parameter additions/removals/renames.
Effects on system behavior
Normal behavior for valid point clouds is preserved.
