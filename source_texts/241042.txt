Summary
The splat fur coat (PRD Must #2). The dog now has fur: 6000 soft strand splats scattered over its surface, glued to the SDF shapes so they follow the bones, drawn as instanced quads after the dog. It is the "SDF body + Gaussian-splat coat" the Huawei brief names, delivered.
```
build time (pure, tested)                          run time (GPU)
 random points ─► onto a shape's surface            instanced quad per splat
   ─► onto the BLENDED surface of the whole dog       ├ position = its shape's CURRENT matrix × fixed local position
   ─► normal = outward gradient (reject ambiguous)    ├ strand lies back along the body (flow) + a bit outward
   ─► glued to the nearest shape (never eyes/nose)    ├ lit with the body's key light, Gaussian soft edge
   ─► colour = the surface's own colour vote          └ depth-tested against the SDF dog, so far-side strands are hidden
```
```
app/src/renderer/dog/fur/
├── fur.ts / fur.test.ts                 sampleFur + shapeRestMatrices + unionDistance   (31 tests, 4 demo dogs)
└── fur-renderer.ts / .test.ts           FurCoat (instanced strands, flow, scaling)       (6 tests)
app/src/renderer/dog/sdf/SdfDog.ts       builds the coat, feeds it the shape matrices every frame, setFur(on)
app/src/renderer/dog/sdf/debug-view.ts   'coat' x-ray = fur only; 'shapes' hides the fur
app/src/renderer/preview.ts              buttons: "fur: on/off", "x-ray: fur only" (and ?fur=0)
```
Stacked on #13 → #12 → #9. If those are not merged yet this PR also shows their commits; merge them first, or together.
See it: /preview.html?spec=aussie (fur on by default); press fur: on/off to compare, x-ray: fur only to see the coat alone.
Evidence
Gates set beforehand: flicker-free, under ~2 ms extra, clearly better. All passed.
Cost (Apple M4, 800×600, GPU-bound, 3 runs each): fur OFF 2.42 ms → fur ON 3.02 ms at demo size (+0.6 ms); size 1.6: 4.1 ms. Scatter at startup: 288 ms for 6000 splats.
No flicker: every strand is a fixed function of the bone matrices, nothing random per frame; repeated deterministic renders are identical.
Clearly better: standing, running (fur streams back, tail feathered, paws fluffy) and from the front (soft face and chest, eyes and nose clear): see the journal entry.
npm test 337 passed, lint and typecheck clean (run after merging latest dev).
Sampler written test-first, run on all four demo dogs: every splat within 0.6 px of the blended surface; normals unit length and leading outward; valid shape indices; colours 0..1; sizes with variation; fair share per body part; never on eyes or nose; deterministic per seed; white-chest fur bright / black-body fur dark. Mutation-checked (no surface projection broke 4 tests, fur on eyes/nose 4, grey colours 1; renderer: unnormalised flow 1, size ignoring dog scale 1; all restored identical).
A real bug the tests caught: 4 of 1500 greyhound splats pointed sideways in leg/body creases. Fixed in the sampler (reject splats whose normal does not lead outward), not by loosening the test.
Merge Danger
Door: two-way (setFur(false) or removing the buildCoat call restores the plain SDF dog).
Lane B files only; no shared/contract files; dev merged in cleanly. DogFile.coat stays unused (the contract's CoatSplat has no normal, which the strands need), so the fur is generated at load instead.
Blast radius: medium. The dog's look changes everywhere SdfDog is used (fur is on by default), and one extra instanced draw call per frame. If anything looks wrong on another GPU, setFur(false) is the switch.
Honest wording for the pitch / Devpost: these are anisotropic Gaussian-profile splats (soft elongated sprites) rendered as instanced quads and glued to SDF shapes. There is no depth sorting and no spherical harmonics, so call it a splat-style fur coat on an SDF body, not full 3D Gaussian splatting.
Not verified on Windows (RTX 2060) yet.
