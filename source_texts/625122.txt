Summary
Corruption was previously a single scalar per zone — the whole zone darkens uniformly with no geographic variation. This introduces CorruptionField, a 2D noise-driven intensity map, so corruption has organic geography: dark tendrils, relatively safe pockets, interesting navigation.
How it works
CorruptionField.ts wraps FbmNoise (simplex-backed) with domain warping:
```
// Warp the sample coordinates using a second noise layer before sampling.
// This folds smooth blobs into irregular, tendril-like shapes.
const warpX = noise.fbm(wx * halfScale,       wy * halfScale)       * 120;
const warpY = noise.fbm(wx * halfScale + 5.2, wy * halfScale + 3.7) * 120;
const raw   = noise.fbm((wx + warpX) * SCALE, (wy + warpY) * SCALE, 3);
return Math.min(0.9, raw * globalCorruption);
```
Returns 0 when globalCorruption = 0 (world starts clean)
Capped at 0.9 to handle domain-warp amplitude overshoot
The two warp offsets (0, 5.2 / 3.7) keep x/y warp uncorrelated — a standard technique from Inigo Quilez's domain warping article
PathSystem.degradeLocal(callback) — new method that calls callback(cx, cy) per segment centre and degrades proportionally. PathSystem stays decoupled from CorruptionField (no import); GameScene wires them via a closure.
GameScene integration: the degradation tick now samples the field at each segment's world centre instead of passing one global value. Roads running through corruption hotspots degrade faster than roads in cleaner areas.
Key concepts
Domain warping — sampling noise at warped coordinates gives irregular organic shapes without adding noise octaves. Cheap and visually powerful.
Callback decoupling — degradeLocal((cx, cy) => field.sample(...)) keeps the two systems independent and testable.
seed ^ 0xdeadbeef — XOR constant ensures the corruption field and terrain noise have different PRNG states even though both use FbmNoise.
Test plan
npm run typecheck passes
npm run build passes
sample(x, y, 0) returns 0
sample(x, y, 1) returns ≤ 0.9
Path segments visually degrade at different rates when corruption is active

FIL-62 Proc-gen: 2D korruptionsnoisefalt per seed
Syfte
Korruptionen ar idag ett enda skalart varde per zon — hela zoner morknar jamnt utan geografiska monster, inga sakra fickor, ingen taktisk navigation.
Introducera CorruptionField — ett 2D-noisefalt per seed — som driver lokal korruptionsintensitet (0-1) vid varje varldspositon.
Implementation
Skapa src/world/CorruptionField.ts:
```
import { ValueNoise2D } from '../lib/noise';

const SCALE = 0.04;

export class CorruptionField {
  private noise: ValueNoise2D;
  constructor(seed: number) {
    this.noise = new ValueNoise2D(seed ^ 0xdeadbeef);
  }
  sample(wx: number, wy: number, globalCorruption: number): number {
    const raw = this.noise.fbm(wx * SCALE, wy * SCALE, 3);
    return raw * globalCorruption;
  }
}
```
Integration i GameScene:
Instansiera corruptionField med runSeed i create()
Skicka lokal snarare an global korruption till NPC.tick()
Anvand lokalt varde i PathSystem.degradeCondition()
Acceptance criteria
CorruptionField skapad och instansierad med runSeed
sample() returnerar 0 nar globalCorruption = 0
sample() returnerar max 0.9 vid globalCorruption = 1
NPC:er tar emot lokal snarare an global korruption i tick()
npm run typecheck passerar
Teknik och verktyg
Simplex noise — CorruptionField kan bygga pa FbmNoise (simplex-backed) direkt. Simplex ar sarskilt bra for stora patch-format korruption eftersom det inte har de axis-aligned artefakter som value noise hade.
Domain warping — for riktigt organiska korruptionsflasar, warp koordinaterna fore sampling:
```
sample(wx: number, wy: number, globalCorruption: number): number {
  const wx2 = wx + this.noise.fbm(wx * SCALE * 0.5, wy * SCALE * 0.5) * 120;
  const wy2 = wy + this.noise.fbm(wx * SCALE * 0.5 + 5.2, wy * SCALE * 0.5) * 120;
  const raw = this.noise.fbm(wx2 * SCALE, wy2 * SCALE, 3);
  return raw * globalCorruption;
}
```
Voronoi / Worley noise — ger cellformad korruption (som flakar eller smaror). Kombineras med fbm for hybridresultat. Enkel implementation: https://iquilezles.org/articles/voronoise/
Referens: GPU Gems 2 kap 26 "Implementing Improved Perlin Noise" for djupare forstaelse av spektral analys i noise.
