Is your feature request related to a problem?
There is currently no non-destructive way to constrain a model to an arbitrary 3D volume during slicing.
OrcaSlicer already provides Mesh Boolean Intersection, which can achieve a similar result, but it is a destructive geometry operation: it creates a modified mesh instead of keeping the original model and applying the constraint during slicing.
A dedicated Clipping Volume part type would provide the same Model ∩ Volume behavior while keeping the original Part unchanged.
Which printers will be beneficial to this feature?
All
Describe the solution you'd like
Add a new first-class object type called "Clipping Volume", alongside Part, Negative Part and Modifier.
Conceptually, it is an inverted Negative Part:
Negative Part: Model − Volume
Clipping Volume: Model ∩ Volume
The Clipping Volume should be an arbitrary closed 3D mesh. During slicing, all model geometry outside this volume is discarded, while geometry inside remains printable.
The Clipping Volume itself is never printed.
The operation should be non-destructive: the original Part remains unchanged. Moving, scaling or replacing the Clipping Volume should immediately change the resulting sliced geometry without modifying the source model.
Describe alternatives you've considered
Mesh Boolean Intersection — available in OrcaSlicer, but it is a destructive operation that creates modified geometry.
A specially prepared hollow mesh can be imported as a Negative Part to achieve a similar effect. However, creating and modifying such a hollow shape usually requires an external 3D editor, and the resulting geometry is difficult to manipulate using OrcaSlicer's object-level tools.
A dedicated Clipping Volume would provide a non-destructive, slicer-level implementation of Model ∩ Volume.
Additional context
This feature would be especially useful when working with very high-poly models. Performing Boolean operations or editing such models in an external 3D editor can be extremely resource-intensive, making the model difficult to manipulate on less powerful computers.
A non-destructive Clipping Volume handled at the slicer level would allow users to constrain such models without having to perform heavy mesh editing operations beforehand.
