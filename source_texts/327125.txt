Implements Gaussian CUBE file loading and isosurface extraction via
marching cubes for the visual pipeline editor.

New pipeline nodes:
- `load_volumetric`: loads a .cube file (drag-and-drop / file picker),
  parses it client-side with a new TypeScript CUBE parser, and outputs
  VolumetricData
- `isosurface`: accepts VolumetricData and runs a marching-cubes
  algorithm to produce a MeshData output compatible with the existing
  Viewport rendering path; supports optional dual-lobe (negative
  isovalue) for ESP maps / MOs

Key additions:
- `src/pipeline/executors/parseCube.ts` — pure-TS CUBE parser,
  Bohr→Å conversion, data order ix·ny·nz + iy·nz + iz
- `src/pipeline/executors/marchingCubes.ts` — marching cubes with
  Three.js lookup tables, arbitrary nx×ny×nz grids and non-orthogonal
  step matrices, gradient-based normals
- `src/pipeline/executors/loadVolumetric.ts` / `isosurface.ts`
  — pipeline executors forwarding / computing mesh output
- `src/components/nodes/LoadVolumetricNode.tsx` /
  `IsosurfaceNode.tsx` — React UI nodes with file picker, drag-and-drop,
  iso-level input, color pickers, opacity slider, negative-lobe toggle
- `VolumetricData` type added to `PipelineData` union, full port
  declarations and defaults in `types.ts`
- Python `LoadVolumetric` / `Isosurface` node classes with
  serialize/deserialize support in `pipeline.py` and `__init__.py`

Tests (37 new, all green):
- `tests/ts/pipeline/executors/parseCube.test.ts` (13)
- `tests/ts/pipeline/executors/marchingCubes.test.ts` (12)
- `tests/ts/pipeline/executors/isosurface.test.ts` (12)
- `tests/python/test_pipeline.py` — 4 new cases for new Python nodes
