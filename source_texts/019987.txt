What changed
add resumable PHerc1218 umbilicus annotation mode and Villa/Volume Cartographer-compatible JSON output
mirror-aware virtual-slab prefetching for nearby z slices and annotation jumps
add Zarr/c5d LOD generation and closed-loop fidelity checking tools
add apparent-magnification LOD streaming with shallow XY slice rendering
move manifest c5d decode off the shared GPU queue and upload asynchronously from CPU staging
bound fallback lookup and ray traversal, prune slice-local brick selection, and fix final page publication
add Snapdragon X Elite / Adreno X1-85 native tuning, documentation, and benchmarks
Why
The prior whole-depth path mixed independently arriving brick resolutions, thrashed a small atlas, and scheduled c5d compute on the same queue as raycasting. This caused visible brick-grid corruption, slice pop-in, and severe stalls. The annotation workflow also needed a wide, shallow z-navigable view with persistent point output.
Impact
Multilevel manifests now open as an 8-slice XY slab by default. Wheel navigation advances one z slice and Shift+wheel zooms. On PHerc1218, the corrected path renders around 0.8–1.6 ms GPU depending on resolution and navigation scenario, with zero streaming failures in the exercised zoom and full-z sweeps.
Validation
native CTest suite: 5/5 passed
ASan/UBSan CTest suite: 5/5 passed
600-frame PHerc1218 zoom sweep: 0.81 ms mean GPU, zero failures
600-frame full-z sweep: 0.90 ms mean GPU, 144 bricks decoded, zero failures
settled 960x720 capture inspected for brick-grid discontinuities
