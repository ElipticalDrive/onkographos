I've worked out two theories for the lack of an API documentation: (1) there are several incompatible versions of the API currently hosted, (2) the most modern version is exceptionally complicated.
I'd like to be able to stream these points from the potree server into a VR system that is not written in Javascript, but it looks like it would be too hard and not much easier than developing it entirely from scratch.
After attempting to derive a Python interface to the API from the Javascript code, and then finding that it doesn't work when I tried it on a different example (due to (1)), I have made the following minimal set of code that is just able to access the first root node of points to give an idea of what it entails. (To go deeper into the node tree is also pretty complicated.)
First download the following three files generated by PotreeV2.0:
https://potree.org/pointclouds/dechen_cave/metadata.json
https://potree.org/pointclouds/dechen_cave/hierarchy.bin
https://potree.org/pointclouds/dechen_cave/octree.bin
(The last one is 334Mb)
The following code runs in a Jupyter notebook.
```
import os, json, struct, numpy

# open the three files
metadata = json.load(open("metadata.json"))
fhierarchy = open("hierarchy.bin", "rb")
foctree = open("octree.bin", "rb")

# extract the first node of the first chunk in the hierarchy
fhierarchy.seek(0)
hbuffer = fhierarchy.read(metadata["hierarchy"]["firstChunkSize"])

numPoints = struct.unpack("i", hbuffer[2:6])[0]
byteOffset, byteSize = struct.unpack("qq", hbuffer[6:22])

# read and unzip the binary data of the root node
assert metadata["encoding"] == "BROTLI"
import brotli
foctree.seek(byteOffset)
bbuffer = foctree.read(byteSize)
pbuffer = brotli.decompress(bbuffer)

# unpack the complicated packing of the points in this node
mdoffset = numpy.array(metadata["offset"])
mdscale = metadata["scale"]

def dealign24b(mortoncode):
    x = mortoncode;
    x = ((x & 0b001000001000001000001000) >>  2) | ((x & 0b000001000001000001000001) >> 0);
    x = ((x & 0b000011000000000011000000) >>  4) | ((x & 0b000000000011000000000011) >> 0);
    x = ((x & 0b000000001111000000000000) >>  8) | ((x & 0b000000000000000000001111) >> 0);
    x = ((x & 0b000000000000000000000000) >> 16) | ((x & 0b000000000000000011111111) >> 0);
    return x;

ps = numpy.zeros([numPoints, 3])
for j in range(numPoints):
    byteOffset = 16*j
    mc_1, mc_0, mc_3, mc_2 = struct.unpack("<IIII", pbuffer[16*j:16*j+16])
    X = dealign24b((mc_3 & 0x00FFFFFF) >> 0) | (dealign24b(((mc_3 >> 24) | (mc_2 << 8)) >> 0) << 8);
    Y = dealign24b((mc_3 & 0x00FFFFFF) >> 1) | (dealign24b(((mc_3 >> 24) | (mc_2 << 8)) >> 1) << 8)
    Z = dealign24b((mc_3 & 0x00FFFFFF) >> 2) | (dealign24b(((mc_3 >> 24) | (mc_2 << 8)) >> 2) << 8)
    if (mc_1 != 0 or mc_2 != 0):
        X = X | (dealign24b((mc_1 & 0x00FFFFFF) >> 0) << 16) | (dealign24b(((mc_1 >> 24) | (mc_0 << 8)) >> 0) << 24);
        Y = Y | (dealign24b((mc_1 & 0x00FFFFFF) >> 1) << 16) | (dealign24b(((mc_1 >> 24) | (mc_0 << 8)) >> 1) << 24);
        Z = Z | (dealign24b((mc_1 & 0x00FFFFFF) >> 2) << 16) | (dealign24b(((mc_1 >> 24) | (mc_0 << 8)) >> 2) << 24);
    v = numpy.array([X,Y,Z])
    ps[j] = (v*mdscale + mdoffset)
```
We can plot these points as well as calculate the max and min ranges (which don't quite match)
```
from matplotlib import pyplot as plt
%matplotlib inline

X, Y, Z = ps[:,0], ps[:,1], ps[:,2]
plt.scatter(X, Y, marker=".")
print(json.dumps(metadata["attributes"][0], indent=4))
print(json.dumps({"min":[min(X), min(Y), min(Z)], "max":[max(X), max(Y), max(Z)]}, indent=4))
```

hi everyone, I just passed potree viewer.js file to a LLM to get every function accessible within viewer object. I don't think there's everything and I recommend to be extra carefull, LLMs can make mistakes :)
Scene Management
setScene(scene): Assigns a new scene to the viewer.
setControls(controls): Sets the control scheme for navigation.
getControls(): Returns the current control system.
setBackground(bg): Changes the background style (skybox, gradient, color, etc.).
getBackground(): Retrieves the current background setting.
setDescription(value): Sets the viewer's description.
getDescription(): Returns the viewer's description.
setMoveSpeed(value): Adjusts the movement speed.
getMoveSpeed(): Retrieves the current movement speed.
setShowBoundingBox(value): Toggles bounding box visibility.
getShowBoundingBox(): Checks if bounding boxes are visible.
Rendering & View Management
setCameraMode(mode): Sets the camera mode (Perspective, Orthographic, etc.).
setFOV(value): Adjusts the field of view.
getFOV(): Retrieves the current field of view.
setPointBudget(value): Limits the number of points rendered.
getPointBudget(): Retrieves the current point budget.
setFreeze(value): Freezes or unfreezes rendering updates.
getFreeze(): Returns the freeze status.
setClipTask(value): Defines the clipping behavior.
getClipTask(): Retrieves the current clip task.
setClipMethod(value): Sets the clipping method.
getClipMethod(): Returns the current clipping method.
fitToScreen(factor, animationDuration): Zooms the view to fit all objects within the screen.
Clipping & Filtering
setFilterReturnNumberRange(from, to): Defines the range of return numbers to be displayed.
setFilterNumberOfReturnsRange(from, to): Sets the range for the number of returns.
setFilterGPSTimeRange(from, to): Filters points based on GPS time.
setFilterPointSourceIDRange(from, to): Filters points by source ID.
setClipTask(value): Configures clipping task settings.
Measurement & Tools
setClassifications(classifications): Sets the classification visibility.
setClassificationVisibility(key, value): Toggles visibility for a specific classification.
setWeightClassification(w): Adjusts classification weights.
setDEMCollisionsEnabled(value): Enables or disables DEM collision detection.
getDEMCollisionsEnabled(): Retrieves the DEM collision status.
setEDLEnabled(value): Enables or disables EDL (Eye-Dome Lighting).
getEDLEnabled(): Retrieves the EDL status.
setEDLRadius(value): Adjusts the EDL radius.
getEDLRadius(): Retrieves the current EDL radius.
setEDLStrength(value): Adjusts the EDL strength.
getEDLStrength(): Retrieves the current EDL strength.
setEDLOpacity(value): Sets the EDL opacity.
getEDLOpacity(): Retrieves the current EDL opacity.
Navigation & Controls
toggleNavigationCube(): Toggles the navigation cube visibility.
setView(view): Sets the camera view (Front, Back, Top, Bottom, etc.).
zoomTo(node, factor, animationDuration): Zooms into a specific node.
moveToGpsTimeVicinity(time): Moves the camera to a specific GPS timestamp vicinity.
VR & Interaction
toggleSidebar(): Opens or closes the sidebar menu.
toggleMap(): Shows or hides the map view.
loadGUI(callback): Loads the graphical user interface.
setLanguage(lang): Sets the language for the viewer.
setServer(server): Assigns a backend server for data requests.
postMessage(content, params): Displays a notification message.
postError(content, params): Displays an error message.
Project Management
loadProject(url): Loads a Potree project from a JSON file.
saveProject(): Saves the current project state.
loadSettingsFromURL(): Reads viewer settings from URL parameters.
Rendering
render(): Executes the rendering pipeline.
renderVR(): Renders the scene in VR mode.
renderDefault(): Renders the scene in standard mode.
Event Handling
dispatchEvent(event): Triggers an event.
addEventListener(type, listener): Adds an event listener.
removeEventListener(type, listener): Removes an event listener.
Utilities
update(delta, timestamp): Updates the scene state.
updateAnnotations(): Refreshes annotation positions.
resolveTimings(timestamp): Handles performance timing logs.
initThree(): Initializes the Three.js renderer.
initDragAndDrop(): Enables file drag-and-drop functionality.
initGUI(): Initializes the user interface elements.
