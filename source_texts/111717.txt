Summary
Build a unified Gaussian Splatting pipeline that converts video/images (including 360° panoramas) into .ply files viewable in a web-based 3D viewer.
What's included:
3D Viewer (pointcloud/index.html)
WebGL2 Gaussian Splatting renderer (antimatter15/splat engine)
Proper GS rendering: ellipsoid 2D splatting with alpha blending + depth sorting
Auto-center camera on loaded scene
Upload/drag-drop .ply/.splat files
Download progress bar for large files
Live at: https://pointcloud-gefntewq.devinapps.com
Pipeline Scripts (pipeline/)
gs_pipeline.py — Unified pipeline: video/images → frames → depth/COLMAP → .ply
dust3r_reconstruct.py — DUSt3R (CVPR 2024) multi-view 3D reconstruction
pano_to_perspective.py — Convert 360° equirectangular → perspective crops
pano360_to_ply.py — Single panorama depth-based point cloud
depth_to_ply.py, train.py, export.py — OpenSplat integration
DUSt3R Integration
Uses DUSt3R ViTLarge for neural 3D reconstruction from image pairs
Global alignment produces spatially coherent room structure
Works on CPU (~57s/pair, ~40 min for 42 pairs from 3 rooms)
Output: proper Gaussian Splatting PLY with SH coefficients
Matterport-style Tour (matterport/)
Multi-panorama 360° viewer with dollhouse cutaway
Hotspot navigation between panorama positions
Default Scene
DUSt3R reconstruction of living room (300K Gaussians, 71MB)
Shows windows, walls, ceiling, furniture with proper 3D geometry

Review & Testing Checklist for Human
Open https://pointcloud-gefntewq.devinapps.com and verify the default .ply loads (300K Gaussians, ~71MB download)
Try uploading your own .ply/.splat files via the Upload button or drag-drop
Check that orbit (click+drag), pan (right-drag), zoom (scroll) controls work
Verify colors render correctly (not blue/green artifacts)
Notes
Full house reconstruction (all 20 rooms) is processing in background (~3-4 hours on CPU)
For photorealistic quality, a GPU-trained Gaussian Splatting (from video) would be needed
The DUSt3R approach produces geometrically correct reconstructions but with point-cloud-level density (not photorealistic like trained 3DGS)
Pipeline supports RunningHub Apple Sharp workflow output (.ply files)
