Resolution: Parametric Cylinder Mesh Rendering with VITURE IMU Gaze Orientation and Wrap Sampling
1. Architectural Overview & Rendering Pipeline
The DeskWrap XR Compositor renders the shared ultrawide desktop texture onto a curved spatial cylinder aligned with the user's head orientation streamed by the VITURE Beast glasses at 500Hz/1000Hz.
```
+-----------------------------------------------------------------------------------------+
|                                    D3D11 COMPOSITOR                                     |
|                                                                                         |
|   [VITURE Beast Glasses]                                                                |
|       | 500Hz/1000Hz IMU Pose (NWU Quaternion)                                          |
|       v                                                                                 |
|   [nwu_to_d3d11_quaternion] -> q_cam = [qw, -qy, qz, qx]                                |
|       |                                                                                 |
|       v Hotkey Recenter Offset (Ctrl+Alt+Space)                                         |
|   [q_cam' = make_yaw_offset(-yaw_offset) * q_cam]                                       |
|       |                                                                                 |
|       v Invert Rotation to Camera View Matrix (Row-Major)                               |
|   [View Matrix: R(q_cam'^*)]  x  [Proj Matrix (45° vFOV, 16:10)]                        |
|       |                                                                                 |
|       +-----------------------------\                                                   |
|                                      v (Upload to Constant Buffer b0)                   |
|   [Inward Parametric Cylinder Mesh] ----> [Vertex Shader (VSMain)]                      |
|     - R = 1.8m, Arc = 180°-360°                  |                                      |
|     - Clockwise Inward Winding                   v                                      |
|     - Inward Normals: (-sin θ, 0, -cos θ)     [Rasterizer Stage (Cull Back)]            |
|                                                  |                                      |
|   [Shared Desktop Texture (5760x1080)]           v                                      |
|     - IDXGIKeyedMutex Sync                    [Pixel Shader (PSMain)]                   |
|     - Anisotropic 8x Filter                      | (desktop_texture.Sample)             |
|     - AddressU = WRAP, AddressV = CLAMP          v                                      |
|                                              [1920x1200 Swap Chain Output / Glasses]    |
+-----------------------------------------------------------------------------------------+
```
2. Key Technical Findings & Mathematical Specifications
A. Parametric Cylinder Mesh Topology & Inward Front-Facing Winding
Parametric Geometry Equation:
For radius R, arc angle theta_arc, height H, and grid resolution Nu x Nv:
theta(u) = -theta_arc / 2 + u * theta_arc, u in [0, 1]
x = R * sin(theta(u))
y = H / 2 - v * H, v in [0, 1]
z = R * cos(theta(u))
Aspect Ratio Preservation:
To prevent desktop distortion or pixel stretching, cylinder height is derived directly from the virtual desktop's aspect ratio (W / H, e.g. 5760 / 1080 = 5.3333):
H = (R * theta_arc_rad) / aspect_ratio
For R = 1.8m, theta_arc = 180 deg (pi rad), and aspect ratio 5.3333, H = 1.06m (default 1.0m is within 6%).
Inward Front-Face Winding (Eliminating Backface Culling):
In Direct3D 11 with default rasterizer settings (FrontCounterClockwise = FALSE), clockwise triangles are front-facing. When viewed from origin looking toward +Z, vertices ordered (top_left, top_right, bot_left) and (top_right, bot_right, bot_left) form clockwise triangles on the screen whose surface normals point inward toward the viewer at origin.
Seamless 360° Toroidal Closure:
When theta_arc = 360 deg, vertices at u=0 and u=1 share identical spatial 3D coordinates (0, y, -R) while maintaining distinct UV coordinates. This eliminates seam cracks or geometric discontinuities across full wraps.
B. Toroidal Wrap Sampling & Anisotropic Filtering
Horizontal Wrap Addressing (D3D11_TEXTURE_ADDRESS_WRAP):
Horizontal coordinates seamlessly wrap across [0, 1], enabling the virtual desktop to cycle continuously around the user's field of view without clamping distortion or edge artifacts.
Vertical Clamp Addressing (D3D11_TEXTURE_ADDRESS_CLAMP):
Vertical coordinates clamp at 0.0 (top) and 1.0 (bottom), preventing the Windows taskbar from bleeding into the top border or title bars from bleeding into the bottom edge when gazing upward/downward.
Anisotropic Filtering (D3D11_FILTER_ANISOTROPIC, Max Anisotropy = 8):
Curved cylindrical projection causes the desktop surface to be sampled at oblique grazing angles toward peripheral gaze. Anisotropic filtering prevents the severe text blurring inherent to bilinear/trilinear filtering at shallow angles, keeping small text and IDE UI crisp and legible.
C. VITURE NWU to Direct3D 11 Coordinate Basis Mapping
Basis Transformation:
VITURE IMU sensor fusion operates in NWU (North-West-Up, right-handed):
+X_nwu = North (forward heading at initialization)
+Y_nwu = West (left)
+Z_nwu = Up
Direct3D 11 camera space operates in left-handed coordinates:
+X_d3d = East (Right, -Y_nwu)
+Y_d3d = Up (+Z_nwu)
+Z_d3d = North (Forward, +X_nwu)
Quaternion Transformation:
q_d3d = [qw, -qy, qz, qx]
Mathematical proof confirms that evaluating the rotation matrix of q_d3d exactly equals M * R_nwu * M^T, where M is the basis transformation matrix.
Camera View Matrix:
R_view = R(q_cam^*) = R(q_cam)^-1
The conjugate quaternion inverts world rotation into camera view space. The constant buffer stores the matrix in row-major layout (row_major matrix world_view_projection).
D. Software Yaw Recenter Cancellation
Gravity-Aligned Yaw Zeroing:
Recenter hotkeys must cancel yaw drift while strictly preserving gravity-referenced pitch and roll (to maintain an unslanted natural horizon aligned with the vestibular system):
q_offset = make_yaw_offset(-yaw_offset_deg)
q_cam' = q_offset * q_d3d
Where make_yaw_offset(theta) = [cos(theta/2), 0, sin(theta/2), 0].
Applying -yaw_offset_deg in world space zeroes gaze heading to 0.000 deg along +Z, aligning the user's center of gaze with the exact middle of the cylindrical canvas (U = 0.5).
IPC Synchronization:
On hotkey trigger, compositor issues g_ipc.send_recenter(0.0f) over the named pipe, enabling daemon mouse seam hooks to synchronize cursor coordinate wrap offsets.
