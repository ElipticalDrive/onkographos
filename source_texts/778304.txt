Summary
Complete, production-grade texture baking add-on for Blender 4.2 LTS – 5.2 LTS, built against the 5.2.1 Python API.
Features
28 bake passes – PBR channels (Base Color, Metallic, Roughness, Normal, Alpha, Emission, Specular, Height, SSS, Transmission, Coat, Sheen), lighting (AO, Combined, Lightmap, Diffuse, Glossy, Transmission, Shadow, Environment), masks (Curvature, Thickness, Position, UV, Vertex Color, Material/Object ID, Wireframe)
Automatic node handling – temp material copies rewired per channel, node groups inlined, originals untouched
Texture sets – multi-object shared images, per-material images, auto UDIM, High→Low projection with cage / ray distance
Exact color pipeline – linear float targets; sRGB encoding for color, raw for data, independent of AgX/Filmic; Smart Format (16-bit normals, EXR lightmaps)
Supersampling, OpenGL/DirectX normals, channel packing presets (ORM, RMA, Unity Mask/Smoothness, …)
Finish step – baked Principled materials (replace / duplicate) + glTF/GLB (Draco, WebP), FBX, OBJ export
Modal runner – progress, live log, Esc cancel, full scene-state restore even on error
Clean single-tab UI – Bake · Scope · Maps · Resolution · Quality · Output · Packing · Finish · Log
Testing
Real Cycles CPU bakes with the bpy 5.2.1 wheel:
tests/test_baking_soda.py – 12/12 integration tests (channel extraction, node-group inlining, sRGB vs data encoding + bit depth on disk, shared/per-material images, UDIM tiled save, high→low, AO/lightmap/curvature/supersampling, packing, rebuild, GLB export, validation, cancel/restore)
tests/test_ui_draw.py – headless draw of every panel/list state, icon & property validation, operator smoke test
Install
python scripts/build_zip.py → dist/baking_soda-1.0.0.zip → Blender ▸ Preferences ▸ Get Extensions ▸ Install from Disk.
