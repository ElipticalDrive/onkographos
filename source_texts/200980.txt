Replaces shadow-map shadows with exact per-pixel voxel shadows: a 3D DDA (Amanatides-Woo) toward the sun through a bitset occupancy of visible layers with 8³ brick skipping. Shared Rust reference (occupancy.rs) used by the CPU renderer; WGSL mirrors it, with an f32 transliteration test vs the reference. Occupancy updates incrementally via dirty bricks; hidden layers don't cast. Old shadow-map path kept only as a fallback if occupancy allocation/upload fails. AO unchanged.
CPU (box, release, 1024x640): wide 236→135 ms, close-up 472→327 ms. Occupancy build 321 µs; single-voxel update 3.35 µs. GPU perf to be verified on Mac. Review notes in docs/reviews/exact-voxel-shadows.md.
