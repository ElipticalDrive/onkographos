Summary
A library of mathematical tools and algorithms optimized for generating organic voxel terrain, biomes, and structures. This toolkit provides the foundational logic to create complex worlds without grid artifacts, utilizing high-performance noise generation, mathematical terrain modeling, and intelligent object scattering to populate the world efficiently.
Functional Requirements
SIMD-Optimized Noise Library: The system shall provide a suite of noise functions (e.g., Simplex Noise, FastNoise) optimized for SIMD execution to generate organic heightmaps and fields without standard Perlin grid artifacts.
Multi-Noise Biome Mapping: The system shall implement a biome determination logic based on overlapping noise fields (specifically Temperature and Humidity values) to dictate voxel material types at specific coordinates.
SDF & Domain Warping: The system shall support Signed Distance Fields (SDF) and Domain Warping allows users to define terrain shapes mathematically. It must include boolean operations such as Union, Subtraction, and Smooth Blend to merge shapes naturally.
Poisson Disk Scattering: The system shall provide a "Scatter" function using Poisson Disk Sampling to place discrete objects (trees, rocks) at random positions while guaranteeing a configurable minimum distance between them to prevent overlap.
Structure Stamping: The system shall support "Structure Stamps"—pre-allocated voxel arrays representing complex objects (e.g., a tree)—and provide a method to bulk-copy these into world chunks using optimized operations (e.g., bit-masking) rather than setting individual voxels.
Acceptance Criteria
Verified that noise generation produces organic outputs and utilizes SIMD instructions for performance.
Verified that distinct biomes appear correctly where temperature and humidity values intersect in the defined lookup logic.
Verified that SDF operations (Union, Subtraction, Blend) correctly shape the terrain geometry (e.g., creating caves or blending hills).
Verified that scattered objects do not overlap and adhere to the minimum distance rules.
Verified that Structure Stamps are pasted into the world data correctly and efficiently without corrupting existing chunk data.
