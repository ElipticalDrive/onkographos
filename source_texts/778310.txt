Describe the bug?
Only PBS_Triplanar_Metallic and PBS_Metallic sample ambient occlusion from the green channel, all the other variants sample it from the red channel instead.
To Reproduce
Using a packed metallic map of the following standard:
R - Metallic
G - Ambient Occlusion
A - Smoothness
Place it into both the occlusion and the metallicmap slots. The ambient occlsuion will only properly render on PBS_Triplanar_Metallic and PBS_Metallic and will fail to display on the other ones.
I included an example map from the Gas Station you can use.
Expected behavior
All PBS_Metallic variants and Xixie toon should sample ambient occlusion from the green channel.
For clarity's sake the following materials do not sample ambient occlusion from the green channel of the metallic map:
PBS Color Mask Metallic
PBS Displace Metallic
PBS Distance Lerp Metallic
PBS Dual Sided Metallic
PBS Intersect Metallic
PBS Multi UV Metallic
PBS Rim Metallic
PBS Slice Metallic
PBS Stencil Metallic
PBS Vertex Color Metallic
PBS Lerp Metallic
Xiexie Toon

I went ahead and looked through the PBS shaders, and for the most part they all share the same r instead of g error. Four find-and-replace operations could fix all these shaders, but I've also listed the specific problem locations here. There is some identical code in some other shaders but is actually commented out. If shaders are to be consolidated to use shared code as in #1576, a mass fix like this won't be necessary as long as it's fixed in the shared master code. However, these replacements could be done to eliminate the problems this error causes for players in the meantime if that consolidation is on hold due to Geenz issues being in the process of migration.
Fixed by replacing
o.Occlusion = tex2D(_OcclusionMap, IN.uv_MainTex).r; with
o.Occlusion = tex2D(_OcclusionMap, IN.uv_MainTex).g;

GenerateOcclusion
There is also a GenerateOcclusion function shared by the PBS Displace shaders, located Here
This code currently reads like this, with no swizzle (defaults to red)
```
#ifdef _OCCLUSION
o = UNITY_SAMPLE_TEX2D_SAMPLER(_OcclusionMap, _MainTex, IN.uv_MainTex);

#ifdef _LERP
o = lerp(o, UNITY_SAMPLE_TEX2D_SAMPLER(_OcclusionMap1, _MainTex, IN.uv_MainTex1), l);
```
To correctly read green, it would need to be changed to read like this:
```
#ifdef _OCCLUSION
o = UNITY_SAMPLE_TEX2D_SAMPLER(_OcclusionMap, _MainTex, IN.uv_MainTex).g;

#ifdef _LERP
o = lerp(o, UNITY_SAMPLE_TEX2D_SAMPLER(_OcclusionMap1, _MainTex, IN.uv_MainTex1).g, l);
```
