Summary
Long-term tracker for adding signed-distance-field (SDF) surfaces and heterogeneous volumetric raymarching to the path tracer. SDFs slot into the existing acceleration structure as a third primitive variant alongside analytic primitives (src/renderer/AnalyticBvh.{h,cpp}) and triangle CSG meshes (Manifold). Existing primitives are not converted -- the analytic sphere stays exact and ~10 FLOPs, period.
Why
Three classes of geometry the renderer currently can't represent:
Fractal surfaces (Mandelbulb-class) -- no triangle equivalent exists.
Smooth smin-blended organic shapes -- Manifold produces faceted meshes; SDF opSmoothUnion(d1, d2, k) is exact and continuous.
Heterogeneous participating media -- clouds, godrays, non-uniform fog. Plays into sky: spherical-Earth atmospheric model + curved aerial perspective #51's curved-atmosphere if extended to heterogeneous density.
Plus: ground-truth analytic shapes (perfect torus, capsule, rounded box) cheaply, no asset pipeline; future inverse-rendering hook (SDFs are differentiable).
Architecture (load-bearing)
Shape becomes a tagged variant in the BVH leaf. Variants: SHAPE_ANALYTIC (existing), SHAPE_TRIMESH (existing), SHAPE_SDF (new), SHAPE_VOLUME (new, Phase 4).
Each SDF cluster is bounded by a tight world-space AABB stored in the same BVH. Sphere tracing only runs inside that AABB after BVH says the ray entered it. Empty space pays the BVH cost, not the DE cost.
PT main loop dispatches on variant. Hit record format is unchanged (pos + normal + material id), so BSDF / NEE / denoiser see no difference.
Cross-cuts: warp divergence on sphere tracing makes wavefront PT (renderer: wavefront path tracing variant (split megakernel) #76) much more valuable; fractal motion vectors are non-trivial for denoising (denoiser: real NVIDIA NRD library integration on Vulkan (REBLUR / RELAX / SIGMA) #50).
Phases
Phase 1 -- Analytic SDF primitive type. renderer: SDF primitive type (Phase 1 of #96) -- analytic SDFs in AnalyticBvh #97 -- sphere/box/torus/capsule/plane SDF + smooth-CSG ops, slotted into the BVH. No fractals, no procedural. Validates architecture, gives smin blends Manifold can't.
Phase 2 -- Procedural / displaced SDFs. renderer: procedural / displaced SDFs + forward-mode normals (Phase 2 of #96) #98 -- noise displacement, domain repetition, forward-mode normal AD, tri-planar texturing for renderer: textured materials (albedo / normal / roughness via image-based sampling) #74.
Phase 3 -- Fractal showcase. renderer: fractal SDF showcase -- Mandelbulb / Mandelbox / Apollonian (Phase 3 of #96) #99 -- Mandelbulb / Mandelbox / Apollonian DEs. Honest about DE noise floor; per-material denoiser variance hints.
Phase 4 -- Heterogeneous volumetric raymarching. renderer: heterogeneous volumetric raymarching -- clouds, godrays, non-uniform fog (Phase 4 of #96) #100 -- clouds, godrays, non-uniform fog via delta / ratio tracking. Independent of Phases 1-3 (different sampling math, shares the step-loop pattern).
Phases 1-3 are sequential. Phase 4 can run in parallel with any of them.
Cross-deps
denoiser: real NVIDIA NRD library integration on Vulkan (REBLUR / RELAX / SIGMA) #50 NRD -- denoiser motion vectors for fractal pixels (Phase 3)
csg: smooth shading on curved surfaces (sphere / cylinder / drilled cavities) #54 smooth shading on CSG curves -- smin / smooth-blend overlap
sky: spherical-Earth atmospheric model + curved aerial perspective #51 spherical-Earth atmosphere -- Phase 4 heterogeneous-density story
renderer: async analytic-primitive BVH build (post-multi-thousand-prim) #58 async analytic-primitive BVH build -- learns the new SDF leaf type
renderer: textured materials (albedo / normal / roughness via image-based sampling) #74 textured materials -- Phase 2 tri-planar binding point
renderer: wavefront path tracing variant (split megakernel) #76 wavefront PT -- divergence relief, becomes load-bearing in Phase 2+
renderer: hair (Marschner BSDF) + skin (BSSRDF subsurface) materials #87 hair/skin BSDFs -- orthogonal; BSDF dispatch must work on non-triangle hits
Status
Roadmap-level. Phase issues filed and linked above.
Non-goals (for the whole roadmap)
Replacing the analytic sphere / plane / triangle paths with SDFs. The mantra is additive, not substitutive.
Real-time fractals at high spp without denoising -- fractals are accepted as a costly showcase.
SDF-from-mesh conversion. Out of scope.
