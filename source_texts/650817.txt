# Interactive Complex Function Visualizer

A high-performance, real-time interactive **Complex Function Visualization Engine** built with C++, OpenGL (GLSL), and Dear ImGui.

This project dynamically constructs an **Abstract Syntax Tree (AST)** by parsing mathematical expressions on the CPU, and compiles them Just-In-Time (JIT) into **GPU Fragment Shader code**. This enables per-pixel, highly parallelized **Domain Coloring** of complex algebra and transcendental functions directly on the graphics hardware.

---

## What It Does: Mathematical Aesthetics in Real-Time

This engine transforms abstract complex-valued functions $f(z)$ into intuitive, interactive visual maps. By mapping the properties of complex numbers (modulus and argument) to visual attributes (brightness and hue/color channels), it allows you to explore the geometric behavior of functions seamlessly.

**Key Capabilities:**
* **Real-time Interaction:** Pan, zoom, and explore the complex plane at a buttery smooth 60+ FPS, completely unhindered by calculation bottlenecks.
* **Dynamic Expression Parsing:** Type any valid complex function (e.g., `exp(1/z)`, `sin(z^2) + ln(z)`) and see it rendered instantly.
* **Dual Rendering Modes:** Switch between classic Polar Domain Coloring (Hue = Argument, Brightness = Modulus) and Cartesian Projection (Red = Real, Green = Imaginary).

---

## Core Architecture: How It Works

The magic of this visualizer lies in its split-architecture approach, leveraging both the CPU for structural parsing and the GPU for heavy-lifting parallel computation.
