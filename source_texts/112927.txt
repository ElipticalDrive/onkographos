After further testing, it was a little more complicated but I found a simple solution that at least does what I need it to do, and could probably just have adjustable compress enums.
Simply added a boolean to SceneTexture, for only compressing specific textures.
```
##Whether it should be compressed.
@export var compress : bool = true
```
Then compress only when baking, so that when compression isn't allowed in certain exports (like web apparently) it will compress it with no issues as long as you store bakes in that case. This is the entire function, with my changes in SceneTexture.gd.
```
func _set_image(image: Image) -> void:
	assert(image.get_width() == size.x)
	assert(image.get_height() == size.y)

	if compress:
		image.decompress()
		image.convert(Image.FORMAT_RGBA8)

	if _texture.is_valid():
		var new_texture := RenderingServer.texture_2d_create(image)
		RenderingServer.texture_replace(_texture, new_texture)
	else:
		_texture = RenderingServer.texture_2d_create(image)
	RenderingServer.texture_set_path(_texture, resource_path)

	if render_store_bake:
		if compress and _is_baking:
			image.compress(Image.COMPRESS_ASTC,Image.COMPRESS_SOURCE_SRGB,Image.ASTC_FORMAT_8x8)
		_data = image
	else:
		_data = null
```
I have tested in editor and a Web build, and there are no issues for me.
This reduced a 128 x 128 texture from ~87KB to ~23KB

Yeah, runtime baking for the web can be heavy and should be avoided.
The best approach to address all these is to follow Godot's method for importing regular images. Save the rendered output in multiple formats within the cache folder .godot, then export only the format suitable for the target platform. This avoids storing image data in source control, allowing render_store_bake to be enabled by default and facilitating compression management.
I am updating the addon to Godot 4.6.2 (it currently targets 4.3), which will likely introduce breaking changes. As part of this update, I was already considering adopting this method for storing rendered data. Implementing compression within this system should be straightforward.
