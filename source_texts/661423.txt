What changed in this PR
This is a documentation-only PR that corrects the .kiro/specs/compute-ray-tracing/ spec package to match develop at bf909fe0. A prior spec PR (#632) had described #626's MIS shading as part of the compute-ray-tracing template, but develop subsequently changed: commit 01a50759 reverted that template back to one shadowed light sample, and #635 added MIS as a separate veach-guibas-mis template. This PR realigns the normative requirements, design, and task records accordingly, and adds a new design section D9 documenting the MIS template. It changes no code.
Changes:
requirements.md: C10 returns to "emission plus one shadowed light sample," adds that other shading policies ship as separate templates (naming veach-guibas-mis), and re-scopes the C14 Veach/Guibas attribution to that template.

I verified the key facts against the codebase: MAX_RAY_PASSES = 4; the veach_guibas_mis template's four passes and color/lightSampling/bsdfSampling outputs; shade range [2, 9) (count 7) vs the restored [2, 6) (count 4); surface_queries: 1/visibility_queries: 1; the three exact GPU test names; the tests/sdk_consumer/rg2/veach_guibas_reference/ fixture; the native-ray-tracing requirement; and that the D8/D9 anchors resolve to their headings.
