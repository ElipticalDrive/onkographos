Is your feature request related to a problem? Please describe.
If someone wants to see maximum intensity projection (or mean or min) then he has to change the volume rendering technique (Volume rendering module -> Advanced -> Technique) and then set the appropriate volume rendering preset. This is not intuitive at all.
Describe the solution you'd like
Make raycast technique part of the volume rendering property node and allow it to be set in volume rendering presets.
Volume rendering preset file format should be changed to json for future compatibility.
Describe alternatives you've considered
No other alternative is considered. BlendMode is a property of the volume raycast mapper, so rendering technique should not be defined in the view node.
Additional context
https://discourse.slicer.org/t/how-to-enable-maximum-intensity-projection-mip-automatically-for-mrml-presets/40679
