Meshing algorithm for smooth edges in an otherwise blocky world?
Question
Similarly to this post, I've implemented simple Minecraft-like meshing, and while I want to keep things blocky, I also want a slightly higher-poly aesthetic.
I've looked into marching cubes, surface nets and dual contouring, and from my understanding none of them would let me keep the blocky look.
Like the post I linked to above mentions, the game Eco seems to have managed to do this (it even looks like it supports differently smooth edges, going from very round to Minecraft-style). However, I've found very little on the subject and the linked post doesn't contain much regarding it either.
Has anyone seen more examples of this in games? Are there any resources for doing similar things, or does anyone have any idea of how this could be achieved?
I imagine combining subdivision and bevelling algorithms could be one way to do it, but are there other (hopefully easier) ways?

So you still want blocks with a smooth rather than sharp edge? That'd be done while meshing, just create a smooth edge rather than a sharp one. Could define the curve manually or mathematically. The edges that get smooth would be based on what neighbors surround the block, could do texture blending for different block types etc. This approach would also work with greedy meshing.

I would use a tile based approach, for each voxel you choose some mesh from a 3d tile palette and append it to the chunk mesh. This way you would be able to create a unique look for any voxel, not depending on meshing/smoothing algorithm.
