Summary
New dedicated Render workbench providing local ray-traced rendering for Tungsten CAD. This adds a complete Fusion 360-style rendering environment with no external renderer dependencies (only stb_image/tinyexr as small single-header libraries).
What's Included
C++ Ray Tracer Core (Raytracer/)
SAH-based BVH acceleration structure with 12-bin binning and flat array traversal
Unidirectional path tracer with NEE, MIS, and Russian roulette termination
Cook-Torrance GGX PBR shading (D: GGX, G: Smith-Schlick, F: Schlick)
Camera with perspective/orthographic projection and depth of field
Point, directional, area, and environment lights
HDR environment map loading with 2D importance sampling CDF
PNG/JPEG/EXR output with tone mapping (Reinhard, ACES, Filmic)
App Bridge (App/)
RenderMaterial: bridges App::Material and PBR schema
RenderCamera: captures viewer camera from Coin3D
RenderEnvironment: HDRI loading, rotation, ground plane
RenderSettings: resolution, quality, format, tone mapping
RenderQueue: background rendering via QThread
Python Workbench (Gui/)
RenderWorkbench with toolbar/menu
8 commands: Render, Stop, Settings, Scene, Camera, Material, Queue, Preview
Task panels for all settings
Dock widgets for render queue and scene browser
Material presets: Steel, Gold, Plastic, Glass, Wood
Build Integration
BUILD_RENDER CMake option (default ON)
Added to Mod/CMakeLists.txt
Dependencies
Only small single-header libraries (stb_image, tinyexr, miniz - placeholder stubs included).
Next Steps
Download real stb_image/tinyexr headers
Test compilation and workbench loading
Add built-in HDRI presets

```
New dedicated Render workbench providing local ray-traced rendering
with no external renderer dependencies (stb_image/tinyexr only).

C++ Ray Tracer Core (Raytracer/):
- SAH-based BVH acceleration structure with 12-bin binning
- Unidirectional path tracer with NEE, MIS, Russian roulette
- Cook-Torrance GGX PBR shading (D: GGX, G: Smith-Schlick, F: Schlick)
- Perspective/orthographic camera with DOF
- Point, directional, area, environment lights
- HDR environment map loading with importance sampling
- PNG/JPEG/EXR output with tone mapping (Reinhard, ACES, Filmic)

App Bridge (App/):
- RenderMaterial: bridges FreeCAD legacy App::Material and PBR schema
- RenderCamera: captures viewer camera state for ray tracer
- RenderEnvironment: HDRI loading, rotation, brightness, ground plane
- RenderSettings: resolution, quality, format, tone mapping
- RenderQueue: background rendering with QThread

Python Workbench (Gui/):
- RenderWorkbench with toolbar/menu registration
- 8 commands: Render, Stop, Settings, Scene, Camera, Material, Queue, Preview
- Task panels for render settings, scene, camera, material editing
- Dock widgets for render queue and scene browser
- Material presets (Steel, Gold, Plastic, Glass, Wood)

Build Integration:
- BUILD_RENDER option in CMake (default ON)
- RenderRaytracer shared library for C++ core
- Python module installation for workbench UI
- SVG icon for workbench

Note: 3rdParty/ contains placeholder stubs for stb_image.h, stb_image_write.h,
tinyexr.h, and miniz.h. Download real headers from their respective repositories
before building.
```
