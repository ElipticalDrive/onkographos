The reversible data hiding technology allows an original image to be completely restored after the extraction of hidden data embedded in a cover image. In this paper, we propose a new reversible scheme based on locally adaptive coding for VQ-compressed images. Before the data embedding procedure, the VQ index table is pre-processed to create a locally recursive trace. Following this trace to process the VQ index table can get better compression ratios in the data embedding procedure. Besides, compared to Chang et al.'s scheme, which compressed the inputted VQ index value only when the to-be-embedded bit b is 0, our method performs compressing operations in both cases that the to-be- embedded bits b are 0 and 1. The results also show that the proposed method has the best compression ratio and embedding capacity compared with other reversible VQ hiding methods.
