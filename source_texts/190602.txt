python/vibeplot/marching_cubes.py: Full Lorensen & Cline (1987) Marching
Cubes implementation. Extracts isosurfaces from 3D numpy arrays; computes
per-vertex normals via volume gradient (central differences).
python/vibeplot/init.py: Add load_volume(volume, level) API. Converts
Marching Cubes output to vibeplot's vertex/face text format, coloring
vertices by surface normal direction (X→red, Y→green, Z→blue).
Change DEFAULT_HOST to 0.0.0.0 so the WebSocket server accepts connections
from any device on the network (required for phone access).
index.html: Use window.location.hostname instead of hardcoded 'localhost'
for the WebSocket URL, so phones on the same WiFi can connect.

(sin(x)cos(y) + sin(y)cos(z) + sin(z)cos(x) = 0), a beautiful
triply-periodic minimal surface.
python/pyproject.toml: Add numpy as optional 'volume' extra.

Implements Marching Cubes (Lorensen & Cline 1987) entirely in JavaScript,
embedded in index.html. Lookup tables are encoded as compact strings (768 +
2716 chars) and decoded at runtime.

Adds "Load Gyroid (Volume Demo)" to the command palette (Cmd+Shift+P).
Tapping it computes the gyroid isosurface in-browser and loads it via the
existing load_model() pipeline — no Python, no server, no laptop needed.

Works on any WebGPU-capable device that can reach the GitHub Pages URL.
