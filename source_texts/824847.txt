Stack / merge order
Stacked on #2347 — functional-envelope oracle v0.2. Do not merge this PR to main before #2347 is merged or the stack is deliberately rebased.
Summary
Adds a balanced, deterministic AABB bounding-volume hierarchy (BVH) as a broad phase for sparse furniture-footprint collision checks and task-envelope queries.
Preserves the existing exact Rect::overlaps narrow-phase predicate. The hierarchy may prune candidate pairs, but cannot independently assert geometric safety.
Replaces repeated linear envelope lookup, placement lookup, and requirement lookup with stable-ID maps.
Adds a deterministic equivalence test comparing indexed rectangle pairs and queries against brute-force results over hundreds of overlapping synthetic rectangles.
Adds a dependency-free Rust scale benchmark at 25, 100, 1,000 and 10,000 furniture/task checks, reporting local oracle p50/p95. The benchmark is wired into the exact-head workflow without a flaky time threshold.
Documents the complexity boundary: sparse workloads should benefit from candidate pruning; dense overlap-heavy workloads can still be quadratic because emitting every collision is itself quadratic.
Benchmark methodology
The generated corpus is synthetic, sparse, room-local 2D geometry with one mandatory functional-envelope check per item. Corpus construction is excluded from the timer; the timed region includes validation and oracle evaluation over the frozen in-memory JSON document. The benchmark does not measure peak memory, UI time, room-measurement accuracy, live data transport, or a production solver. Results must be recorded from the named commit/runner before setting any SLA.
Safety and claims
The v0.1 and v0.2 synthetic oracle outcomes and unknown-evidence gates remain intact. Any missing/unknown mandatory envelope remains indeterminate/blocked; speed cannot compensate for a false-safe. This is still an axis-aligned 2D synthetic oracle—not qualified biomechanics, wheelchair turning, door-swing arcs, accessibility/code compliance, physical safety, measured-site truth or human benefit.
Qualification
The added exact-head workflow runs formatting, all locked tests, strict Clippy, and the scale benchmark on Rust 1.96.0. This PR remains draft until the exact-head run passes. No performance result or SOTA superiority claim is asserted in this description.
