The caller should be responsible for ensuring that all the touched voxels are generated. It adds a little strain on the caller, since it's possible not all the voxels that might be needed will be needed, but it simplifies this code, and then the isosurface extraction code doesn't have dependencies on any code that knows how to generate voxels.
