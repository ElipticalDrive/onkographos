Procedural world generator using cellular automata — random noise smoothed into coherent terrain that evolves over time via life-like rules.
world.html — new
Terrain generation: Seeded PRNG (mulberry32) → binary noise → 6 cellular automata smooth passes → 7-biome classification (water, sand, grass, forest, mountain, snow)
Evolution: Neighbor-count rules drive terrain change each generation — forests spread into grass, water erodes sand, isolated snow melts, mountains erode
Rendering: 180×100 grid on HTML Canvas at 4px/cell, putImageData for performance
Controls: Seed, density %, single-step evolve, auto-evolve with interval
```
// Deterministic — same seed always produces the same world
const rng = createRNG(42);
const heightMap = buildHeightMap(rng, 48);   // cellular automata smoothing
const world = classifyTerrain(heightMap, rng); // biome assignment
const next = evolve(world);                    // one generation step
```
analyze.js — improved
var → const/let, template literals, input validation
Magic numbers extracted to DISCOUNT_THRESHOLD, DISCOUNT_MULTIPLIER
