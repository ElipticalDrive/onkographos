Motivation
Implement a browser-only pipeline to convert a single-person photograph into a 3D Gaussian Splatting representation with local-only processing and reproducible build/deploy.
Provide developer tooling and CI to validate formatting, types, tests and to produce a GitHub Pages deployable artifact.
Description
Add the full frontend app and runtime: src/* including the pose retargeting (body-viewer.ts), Gaussian builder (gaussian.ts), instanced splat renderer (viewer.ts), exporters (exporters.ts) for PLY/SPLAT/SPZ, pose runtime (pose.ts) and src/main.ts UI glue.
Add helper modules for sorting and reordering splats (splat-sort.ts) and unit tests (*.test.ts) exercising the Gaussian pipeline, sorting and body retargeting.
Add build/runtime scripts: scripts/prepare-runtime-assets.mjs to fetch/check the MediaPipe model and convert the bundled FBX to GLB, and scripts/verify-pages-build.mjs to assert Pages build correctness.
Add project and deployment config: package.json + package-lock.json, tsconfig.json, vite.config.ts, index.html, style.css, DESIGN.md, README.md, and GitHub Actions workflows ci.yml and pages.yml.
Testing
Formatting check was executed via npm run format:check and completed successfully.
Type checking was run via npm run typecheck and passed.
Unit tests were executed with npm test (Vitest) covering the Gaussian pipeline, splat sorting, and GLB pose retargeting, and they passed.
Build and Pages verification were run via npm run build and npm run verify:pages (used by the Pages workflow) and succeeded in validating built assets and the converted rig GLB.
