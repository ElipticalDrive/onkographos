Scope
LP-1: practical local reflection and irradiance probes
Implement select_reflection_probe_mix: bounded, inside-box-only local reflection weights, near-edge fade, deterministic priority, cap of two probes, explicit environment remainder.
Implement sample_reflection_probe_radiance: CPU-reference parallax-corrected roughness-cubemap radiance blending, safe global fallback for missing captures. Returns specular radiance only, avoiding unintended diffuse double lighting.
Add validated IrradianceProbeGrid SH9 trilinear diffuse irradiance reference with per-cell confidence and explicit uncovered fraction for global sky. No entire-grid scan in the shading sampler.
Extend dve_environment_lighting_tests for overlap, priority, seam fade, missing assets, SH9 coverage, out-of-volume and invalid input.
DN-1: optional GI reconstruction
DVE_GI_DENOISER=1 opts in the Vulkan one-bounce path, leaving existing behavior unchanged otherwise.
Temporal history is clamped to a valid same-camera-depth 3x3 current neighborhood to reduce ghost trails.
One-level 5x5 edge-stopping half-res resolve using surface plane, depth, and HDR luminance. Original 3x3 fallback remains for unsupported samples.
No RHI constant buffer ABI changes; test shader contracts.
Scope limits
Local probe functions and SH9 grid are CPU references and rendering contracts; Vulkan GPU resident cubemap arrays, probe capture, editor controls and SH9 grid shading are still future LP-2.
DN-1 is an SVGF-inspired first pass, not multi-level SVGF (no temporal moments, variance or material IDs). It does not denoise Split RC and its extra pixel shader work may cost time on GTX 1080.
No hardware benchmark is claimed. Recommend 1080p A/B captures of camera motion, sun/emissive edits, silhouettes and isolated GPU pass timings.
Docs: docs/light-probes-denoising-lp1-dn1.md. Source manifest refreshed.
Continuation (same PR): LP-2A bake/visibility + DN-1.1
Add deterministic HDR cube-to-SH9 irradiance fitting, weighting each cubemap texel by its exact solid angle and applying the Lambertian convolution kernel π, 2π/3, π/4 across SH bands.
Add transactional multi-probe capture driver; it invokes a caller-supplied cubemap capture, retains individual confidence and commits only if all captures validate.
Add visibility-gated irradiance interpolation that rejects probes behind a wall without renormalizing their energy into invalid neighbors. Unit tests cover a simulated occluded second room.
Improve the existing opt-in DN-1 one-bounce denoiser: normal and tangent-plane consistency, depth matching, current-frame local luminance variance clipping, and stronger refresh under large camera motion. This is not persistent SVGF variance.
Expand tests for constant-cubemap πL irradiance, hemispheric response, invalid captures, transactional failure, cross-wall rejection and shader source contracts.
Documentation updated in docs/light-probes-denoising-lp1-dn1.md.
Remaining: Live scene-owned capture and GPU probe-grid upload/sampling; probe visibility backend; runtime reflection volumes; persistent SVGF moments, multi-iteration à-trous filtering and GTX 1080 performance/visual acceptance. No GPU speedup or live light-probe deployment claim.

Validate resident captures before sampling rather than per lookup
When this CPU reference shades multiple points using a resident capture, every lookup calls IblBakeResult::validate(), which scans all diffuse texels, all specular mip texels, and the entire BRDF LUT. A 256-pixel specular cubemap alone therefore requires checking over 500,000 texels per probe per shading query, even though the actual radiance lookup needs only a few texels. This makes reference rendering scale with total capture size for every shaded point. Validate captures at bake/load or residency time and use only inexpensive structural checks in the sampling path.
