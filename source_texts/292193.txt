Motivation
Reduce arithmetic and synchronization pressure in the shader batch Montgomery inversion to improve throughput on RDNA2 (RX6800) GPUs.
Replace the earlier inclusive Hillis‑Steele scans which performed more multiplies and increased VGPR / barrier contention with a lower-overhead tree scan.
Keep changes minimal and local to the shader runtime path to avoid adding files or unrelated code complexity.
Description
Replaced Hillis‑Steele inclusive prefix/suffix scans with Blelloch upsweep/downsweep trees for both prefix and mirrored suffix products inside shader.comp's main() batch inversion region.
Store suffix inputs mirrored into shared_S[WG_SIZE - 1u - lid] to construct the suffix tree without extra expensive work and to avoid introducing new buffers.
Compute a single inversion of the total product once and convert both trees into exclusive products, then compute per-lane reciprocals as prefix_excl * suffix_excl * inverse(total); initialize out‑of‑range lanes to identity inline.
Changes are confined to the functional portion of the shader (main() batch inversion/scan logic) and do not add files or alter unrelated host code.
Testing
Ran git diff --check and git status --short to validate diffs and workspace state, which completed successfully.
Attempted make clean && make -j4 to build the project, but the build failed in this environment due to missing Vulkan headers (vulkan/vulkan.h), so shader compilation and runtime benchmarking could not be performed here.
