What is Texture Compression?
Texture Compression is a GPU-oriented image encoding method that reduces the memory footprint and bandwidth cost of texture maps used in 3D rendering. It stores pixels in compact compressed blocks that graphics hardware can sample directly, usually with some controlled loss of image quality.
How it works
Most real-time texture compression formats divide an image into small fixed-size blocks and encode each block with a limited set of colors or mathematical parameters. The GPU decompresses only the needed block data during texture sampling, which reduces VRAM use and memory bandwidth compared with uncompressed RGBA textures. Different formats are optimized for color maps, alpha, normal maps, high dynamic range images, or mobile hardware. Choosing the wrong format can cause visible block artifacts, banding, blurry normals, or wasted memory.

Frequently Asked Questions
What is texture compression in 3D graphics?
Texture compression is the process of storing texture images in compact GPU-readable formats to reduce memory use, bandwidth, and often download size in real-time rendering.
How is texture compression different from PNG or JPEG compression?
PNG and JPEG are general image storage formats that are usually decoded before GPU use. GPU texture compression formats are designed so the graphics hardware can sample compressed texture blocks directly during rendering.
Is texture compression lossy?
Most common GPU texture compression is lossy because it approximates groups of pixels with a compact block representation. The amount of visible quality loss depends on the format, bit rate, texture content, and settings.
Does texture compression improve frame rate?
Texture compression can improve performance when a scene is limited by texture memory bandwidth, cache usage, or VRAM pressure. It does not directly reduce polygon count, shader cost, or draw call count.
Which texture compression format should I use?
The best format depends on the target platform and texture type. BC formats are common on desktop and console, ASTC is common on modern mobile hardware, ETC2 is widely supported in OpenGL ES 3.0 and WebGL 2, and PVRTC is used mainly for older Apple-oriented pipelines.
What texture compression format is good for normal maps?
BC5 is commonly used for normal maps on desktop because it stores two channels with better quality than many color formats. ASTC can also work well for normal maps when the block size and quality settings are chosen carefully.
How does texture compression handle alpha transparency?
Some formats include alpha support and some do not. BC3, BC7, ASTC, and ETC2 with alpha are common choices when a texture needs smooth transparency.
Do mipmaps work with compressed textures?
Yes. Each mipmap level is compressed separately, and the GPU samples the appropriate compressed level during rendering. Mipmaps usually improve texture filtering quality and performance.
Can Blender compress textures for a game engine?
Blender can use and display texture images, but final GPU texture compression is usually handled by the game engine, export pipeline, or asset build tool. Engines such as Unity and Unreal Engine provide platform-specific texture compression settings.
