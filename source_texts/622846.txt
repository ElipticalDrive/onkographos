Summary
Adds a new "Viewer" point-of-view option to the 3D model orientation preview in the admin panel. This view matches exactly how the main viewer opens a model, making it the default starting point for orientation adjustments. The preview now recomputes this view after every rotation, ensuring what editors see is what the public will see.
Key Changes
New "Viewer" view mode (frameLikeViewer() function):
Implements the same camera framing logic as the main viewer (viewer.js)
Uses 60° FOV (changed from 45°) to match the viewer
Positions camera on +Z axis looking at the rotated model's center
Applies computeFrame() distance calculation with 1.2 margin
Automatically recomputes after every model rotation
View state tracking:
Added currentView variable to track active view mode
New markView() function updates button aria-pressed states
Dragging/zooming the preview exits "Viewer" mode until explicitly re-selected
UI improvements:
Added "Viewer" button as the first and default view option
Added aria-pressed attributes to all view buttons for accessibility
Added tooltip explaining the "Viewer" view's purpose
Updated hint text to guide users to start from "Viewer" view
Initial view changed:
Model now loads with "Viewer" view instead of "iso" (isometric)
Resize handler reframes to "Viewer" view when active
Internationalization:
Added orientViewViewer and orientViewViewerTitle translation keys
Updated orientHint text in all languages (IT, EN, FR, ES) with new guidance
Updated template.json for future language additions
Styling:
Added CSS rule to highlight active view button with accent color and border
Implementation Details
The frameLikeViewer() function mirrors the viewer's computeFrame() logic:
Calculates bounding box of the rotated model (via pivot object)
Computes required camera distance based on FOV and aspect ratio
Sets near/far planes with appropriate margins for the model size
Updates camera position, target, and projection matrix
Calls controls.update() to sync OrbitControls
The preview now provides a true WYSIWYG experience for model orientation — editors can see exactly how their rotation choices will appear to end users.

that view until the button is pressed again; the active view button is
