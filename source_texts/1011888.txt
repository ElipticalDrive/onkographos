For your consideration, following an initial attempt for a function triliterateBy2 to provide trilaterate-by-area or -by-perimeter.
For all 3 circle combinations, it uses the LatLon.intersections2 method to get the intersection points between the 1st and 2nd circle.
For the -by-area case, it then uses the nearestOn method to get the nearest point between in the radical segment and the center of the 3rd circle. If the distance between those is less than the radius of the 3rd circle (less the given margin eps), there is overlap.
For the -by-perimeter case, it computes the distance between the center of the 3rd circle and the intersection points of the 1st and 2nd circle. Then, it compares the required margin with the closest distance to the closest intersection point.
```
from pygeodesy import EPS, IntersectionError, R_M
from pygeodesy.sphericalTrigonometry import LatLon

distance = 5110

if True:
    p1 = LatLon(42.688839, 2.438857)
    p2 = LatLon(42.635421, 2.522570)
    p3 = LatLon(42.64540, 2.504811)
else:
    p1 = LatLon(42.688839,2.438857)
    p2 = LatLon(42.635421,2.522570)
    p3 = LatLon(42.630788,2.500713)


def trilaterateBy2(p1, d1, p2, d2, p3, d3, area=True, eps=EPS, radius=R_M):
    '''Trilaterate 3 points by area (overlap) or perimeter (intersection).
 
       Margin C{eps} is the required I{minimal overlap} for C{area=True}
       or the I{maximally allowed intersection error} for C{area=False}
       in the same units as C{radius} passed to method C{.distanceTo}.

       @return: 2-Tuple(distance, point) with the C{distance} and I{an}
                intersection C{point}.  If there is no area overlap
                or perimeter intersection, the returned result is
                C({None, None)}.
   '''
    for _ in range(3):
        p1, d1, p2, d2, p3, d3 = p2, d2, p3, d3, p1, d1
        try:
            c1, c2 = p1.intersections2(d1, p2, d2)
            if area:  # check overlap
                if c1 is c2:  # abutting
                    c = c1
                else:  # nearest point on radical
                    c = p3.nearestOn(c1, c2, radius=radius)
                d = d3 - p3.distanceTo(c)
                if d > eps:  # min overlap required
                    return d, c

            else:  # check intersection
                for c in ((c1,) if c1 is c2 else (c1, c2)):
                    d = abs(d3 - p3.distanceTo(c, radius=radius))
                    if d < eps:  # max distance allowed
                        return d, c

        except IntersectionError:
            # no intersection, concentric, etc.
            if area:
                pass
            else:
                break

    return None, None

for area in (False, True):
    d, t = trilaterateBy2(p1, distance, p2, distance, p3, distance, area=area, eps=10)  # meter
    print('trilaterateBy', area, d, (t.lat, t.lon) if t else t)
```
One note, triliterateBy2 only works with sphericalTrigonometry.LatLon due to the lack of the nearestOn2 method for ellipsoidal LatLon classes.

Thank you for your comments! I plan to add a method/function trilateral2 based on your suggestions and it will look like the following, including the concentric cases. Hope you have a change to review and test this one.
```
from pygeodesy import EPS, IntersectionError, R_M, unstr
# from pygeodesy.ellipsoidalVincenty import LatLon
# from pygeodesy.ellipsoidalKarney import LatLon
from pygeodesy.sphericalTrigonometry import LatLon

distance = 5110

if False:
    p1 = LatLon(42.688839, 2.438857)
    p2 = LatLon(42.635421, 2.522570)
    p3 = LatLon(42.64540, 2.504811)
else:
    p1 = LatLon(42.688839,2.438857)
    p2 = LatLon(42.635421,2.522570)
    p3 = LatLon(42.630788,2.500713)


def trilaterate2(p1, d1, p2, d2, p3, d3, area=True, eps=EPS, radius=R_M, wrap=False):
    '''Trilaterate 3 points by area (overlap) or perimeter (intersection).

       Margin C{eps} is the required I{minimal overlap} for C{area=True}
       or the I{maximally allowed intersection error} for C{area=False}
       in the same units as C{radius} passed to method C{.distanceTo}.

       @return: 2-Tuple(distance, point) with the C{distance} and I{an}
                area overlap o perimeter intersection C{point}.  If all
                points and distances are pairwise concentric for C{area=True},
                the point with the smallest distance is returned.

       @raise IntersectionError: No overlap or intersection for the given C{eps}.
    '''
    pc = 0
    for _ in range(3):
        try:
            c1, c2 = p1.intersections2(d1, p2, d2)

            if area:  # check overlap
                if c1 is c2:  # abutting
                    c = c1
                else:  # nearest point on radical
                    c = p3.nearestOn(c1, c2)
                d = d3 - p3.distanceTo(c, radius=radius, wrap=wrap)
                if d > eps:  # exceeds required overlap
                    return d, c

            else:  # check intersection
                for c in ((c1,) if c1 is c2 else (c1, c2)):
                    d = abs(d3 - p3.distanceTo(c, radius=radius, wrap=wrap))
                    if d < eps:  # below permitted error
                        return d, c

        except IntersectionError as x:
            if 'concentric' in str(x):  # XXX ConcentricError?
                pc += 1

        p1, d1, p2, d2, p3, d3 = p2, d2, p3, d3, p1, d1  # rotate

    if area and pc == 3:  # all pairwise concentric
        if d2 < d1:
            d1, p1 = d2, p2
        if d3 < d1:
            d1, p1 = d3, p3
        return d1, p1  # smallest distance and point

    raise IntersectionError(area=area, eps=eps, txt='no overlap' if area else 'no intersection')


for area in (False, True):
    try:
        d, t = trilaterate2(p1, distance, p2, distance, p3, distance, area=area, eps=10)  # meter
        print('trilaterate2', area, d, (t.lat, t.lon) if t else t)
    except ValueError as x:
        print('trilaterate2', repr(x))
```

The latest PyGeodesy 20.9.23 release includes a new method trilaterate5 for all ellipsoidalKarney.-, ellipsoidalVincenty.- and sphericalTrigonometry.LatLon classes to trilaterate 3 circles by intersection or overlap (and with some restrictions for ellipsoidal- and sphericalNvector.LatLon).
The trailing -5 in the name trilaterate5 reflects the returned result, a 5-tuple returned as result. More details in the documentation.
Separately, the original sphericalNvector.LatLon.trilaterate method and sphericalNvector.trilaterate function has been fixed to no longer report false trilaterations (without using an new eps-like keyword argument). And that .trilaterate method is now also available for the ellipsoidalNvector.LatLon class.
Lastly, several new trilaterate tests are based on your examples. Thank you again for reporting the original problem.
