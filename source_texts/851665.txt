Summary
Adds import/export of Gaussian splats as glTF 2.0 binaries (.glb) using
KHR_gaussian_splatting + KHR_gaussian_splatting_compression_spz_2 (3D Tiles /
Cesium / ArcGIS, geo-register plugin). Built on the existing SPZ module.
Read: .glb with the SPZ extension → splats (mesh .glb still goes to the mesh
loader); node matrix applied with the 3D Tiles Y-up→Z-up convention;
lin_rec709_display converted to sRGB on load.
Write: convert in.ply out.glb (also mesh2splat / --export glb) with spec
fields (kernel, colorSpace, OPACITY/SH0/VEC3 SH accessors); positions recentered,
precision via new spz::PackOptions::fractionalBits.
Khronos credited in THIRD_PARTY_LICENSES.md.
Testing (CLI)
Plugin GLB → PLY and PLY → GLB → PLY: lossless apart from SPZ quantization.
Cesium sample GLBs load inside their tileset bounds and round-trip losslessly:
sh_unit_cube,
tower
Tip: the tower loads ~2.5 km from the origin (Z-up). Select it and press F (Focus Selection) to find it.
Corrupt/truncated GLBs fail cleanly with one error line.

cc4bade
```
Add import/export of Gaussian splats stored as glTF 2.0 binaries using
KHR_gaussian_splatting with KHR_gaussian_splatting_compression_spz_2, the
layout produced by the geo-register plugin's 3D Tiles exporter and by
Cesium ion.

Reading:
- SpzLoader claims a .glb only when its JSON declares the SPZ compression
  extension, so mesh .glb files still go to the mesh loader.
- load_spz unwraps the embedded SPZ v3 payload, decodes it without RUB
  conversion and applies the 3D Tiles Y-up->Z-up rotation times the node
  matrix (matrix or TRS), recovering the tile-local frame.
- colorSpace lin_rec709_display is converted to sRGB on load: SH0 exactly,
  higher SH bands scaled by the sRGB curve slope (first-order), with a
  warning.
- Load errors name the container (GLB/SPZ) and file once instead of the
  doubled "Failed to load SPZ:" prefix.

Writing:
- SpzSaveOptions::glb wraps an SPZ v3 payload in a GLB with kernel
  "ellipse", colorSpace "srgb_rec709_display" and the spec accessors
  (POSITION, COLOR_0, SCALE, ROTATION, OPACITY, SH_DEGREE_0_COEF_0 and
  VEC3 higher-degree SH placeholders).
- Positions are recentered into the node matrix and the fixed-point
  fractional bits are chosen from the extent, via a new
  spz::PackOptions::fractionalBits (previously hard-coded to 12).
- New OutputFormat::GLB for `convert`, mesh2splat and --export.

Credit the Khronos glTF 2.0 and KHR_gaussian_splatting specifications in
THIRD_PARTY_LICENSES.md.
```
