The Vulkan backend samples float32 images (R32G32B32A32_SFLOAT) with linear filtering since #56, but Vulkan leaves linear filtering of that format optional. cuCtxCreate now checks VK_FORMAT_FEATURE_SAMPLED_IMAGE_FILTER_LINEAR_BIT in the device's optimal-tiling features for it. It returns VK_ERROR_FORMAT_NOT_SUPPORTED before creating the device when the bit is missing. This is the same plain failure as a device without the descriptor-indexing features, and there is no software fallback.
Found by ws3 in its review of #56.
Testing: make test passes on 4463c56 (NVIDIA, OptiX and Vulkan). The failing branch is untested: the NVIDIA device used has the feature. Intel iGPU: not a test target (Bendik).
