When replicating DA3's novel view rendering results, I found that the multi-view merged 3DGS are not perfectly aligned, as shown in the figure below.
I found that the code predicts an extra offset on the point cloud positions when estimating the Gaussian's positions. After I removed this offset in the code, the point cloud alignment issue was solved, but the novel view rendering quality deteriorated, as shown in the figure below.

Hi @ChangyueShi, thanks for your interest and for reporting this.
We double checked with the same DL3DV scene using the released model, and the results look reasonable on our side. Below is the script we used.
```
import glob, os, torch
from depth_anything_3.api import DepthAnything3
device = torch.device("cuda")
model = DepthAnything3.from_pretrained("depth-anything/DA3NESTED-GIANT-LARGE")
model = model.to(device=device)
example_path = "1K/0a1b7c20a92c43c6b8954b1ac909fb2f0fa8b2997b80604bc8bbec80a1cb2da3/images_4"
images = sorted(glob.glob(os.path.join(example_path, "*.png")))[::10]  # take 31 images

output_dir = "outputs/1K_0a1b7c20"
process_res = 504
export_format = "gs_video"
export_kwargs = {"gs_video":{"trj_mode":"interpolate_smooth"}}

model.inference(
    images,
    extrinsics=None,
    intrinsics=None,
    infer_gs=True,
    export_dir=output_dir,
    process_res=process_res,
    process_res_method="upper_bound_crop",
    export_format=export_format,
    export_feat_layers=[],
    export_kwargs=export_kwargs,
)
```
When it completes, you could see outputs/1K_0a1b7c20/gs_video/0000_interpolate_smooth.mp4, which should match the example we provided below.
0000_interpolate_smooth.mp4
Could you kindly help run the script on your side to confirm? And feel free to let us know if you run into any other issues. Cheers.
