Motivation
Provide a small, self-contained 3D Gaussian splatting renderer that can import ASCII PLY point clouds and produce a rasterized image for quick validation and debugging.
Ship a reproducible Python unit test and a tiny PLY fixture so the renderer behavior can be verified automatically and an example output image can be produced.
Prevent test artifacts from contaminating the repo by ignoring the test output directory.
Description
Add a new Python package scripts/python/gaussian_splatting with renderer.py and __init__.py implementing GaussianPoint, load_ply, render_points, and write_ppm for ASCII PLY import, simple pinhole projection, and Gaussian splatting to an RGB buffer.
Add a small PLY fixture at tests/python_tests/data/3dgs/sample.ply and a unit test tests/python_tests/test_gaussian_splatting.py that renders the fixture, asserts output content/shape, and writes a PPM to tests/python_tests/output/sample_render.ppm.
Update .gitignore to exclude the tests/python_tests/output/ folder and adjust the test to use the correct data path; remove an unused math import in the renderer.
Depend on numpy for numeric operations (arrays, math, and image assembly) used by the new renderer and test.
Testing
Ran the Python unit test with python -m unittest tests/python_tests/test_gaussian_splatting.py, which initially failed due to the missing dependency numpy.
Installed numpy and re-ran python -m unittest tests/python_tests/test_gaussian_splatting.py, which passed (OK).
The test produced tests/python_tests/output/sample_render.ppm, and the test asserted the file exists and has non-zero size.
