[BOUNTY] [$3000] [AGENTS] Implement sparse quadtrees into the atmospherics subsystem
Title.
As it stands, /tg/'s atmospherics subsystem has either naive tile-based atmospherics simulation (with the ideal gas law) or "hot spots"--where an entire volume collapses into a single simulated node. This is extremely wasteful, and atmospherics regularly overtimes by 200-1400%. Realistically, given the size of the areas bounded by the subsystem, we could stop using a naive grid-based approach and use a quadtree instead; nuclear physics has been doing this for ages with neutrino flux simulations, and it works very well. I've personally implemented these algorithms for a GPU-accelerated LPV-style radiance propagation system (over a sparse voxel octree/DAG), and the performance gains are frankly embarrassing.
If you can make this work without breaking the existing unit tests, the money's yours.
