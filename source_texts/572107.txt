Goal
Replace the External Job preview's voxel scatter with CryoSPARC-like solid 3D isosurface renders while preserving the scientific Class Camera Orientation.
Confirmed behavior
Show four columns: 2D Class Average, Matched Projection, exact Camera View Render, and Oblique Inspection Render.
Exact render uses the solved camera and orthographic projection.
Oblique render uses orthographic projection and a default 20-degree horizontal/vertical inspection tilt that can be overridden.
Default appearance is a white solid surface on a dark background.
Extract a triangular isosurface on a rendering grid of at most 192 cubed; do not render voxel scatter.
Default Surface Level is mean plus 1.5 sigma. A raw --surface-level overrides it. If automatic extraction fails, lower the level and retry while recording the final level and a warning.
Retain the main connected component and components at least 1 percent of its size.
Matching always uses the unsharpened Matching Map. Rendering defaults to map; --render-map sharpened uses map_sharp without changing the solved camera.
Use the same framing scale for every class.
Log one four-column preview page per 10 classes.
Save renders/class_NNN_comparison.png, class_NNN_exact.png, and class_NNN_oblique.png for every processed class.
Independent renders default to 1024 by 1024 and allow an override.
Titles include class number, view type, Surface Level, match score, confidence, nearest symmetry axis, and angular distance.
Create Interactive Class Volumes only for one-based Class Numbers requested by --classes.
Compatibility
CryoSPARC server v5.0.6
Python 3.10 through 3.12
CPU/headless rendering; ChimeraX is not required for static PNG generation
Verification seams
Scientific Class Camera Solver
CLI
CryoSPARC External Job adapter
Viewer artifacts
Implementation must follow red-green TDD.
