Replace CPU-side frustum culling with a WebGPU compute shader pass that
runs before render passes. The compute shader tests each object's
bounding sphere against 6 frustum planes and zeroes out the
instanceCount in an indirect draw buffer for culled objects. All
drawIndexed calls are replaced with drawIndexedIndirect, reading from
the GPU-written indirect buffer.
Key changes:
Add WGSL compute shader for parallel frustum plane testing
Add per-object bounding sphere + indirect draw arg staging buffers
Run compute pass before shadow and color render passes
Scene traversal no longer does CPU frustum culling (collects all objects)
Sprites and instanced meshes bypass compute culling (radius=-1 sentinel)
