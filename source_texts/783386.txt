This PR adds src/utils/stl_utils.h, a new GPU-portable STL geometry utility header, along with a full mesh_form example application that demonstrates its use. The implementation follows MATAR/Kokkos best practices for dual-host/device memory and has been validated for correctness on both OpenMP and CUDA backends.
src/utils/stl_utils.h — New STL geometry utility
Provides an stl_data struct that loads and queries binary STL surface meshes from GPU kernels:
Binary STL reader (binary_stl_reader): reads facet normals, vertices, and computes face centers into DCArrayKokkos dual arrays; populates via .host() accessors and syncs with update_device()
Global bounding box (computeGlobalBoundingBox): parallel reduction over all facet vertices using FOR_REDUCE_MIN_CLASS/FOR_REDUCE_MAX_CLASS
Morton-code AABB tree (buildAABBTree): builds a Lauterbach–Karras BVH on the host using Morton-code sorting (Kokkos::sort with a struct-scope comparator), then syncs the full tree to device for query
Nearest-facet query (query_nearest_facet): BVH traversal with priority pruning, KOKKOS_INLINE_FUNCTION — safe to call from FOR_ALL kernels
Triangle closest-point (get_closest_point_on_triangle): Christer Ericson Voronoi-region decomposition, KOKKOS_INLINE_FUNCTION
examples/mesh_form/ — New XPBD mesh relaxation example
Demonstrates stl_utils.h by generating a structured hexahedral box mesh, loading an STL surface, and using XPBD constraints to relax boundary nodes onto the nearest STL surface point. Outputs VTU files for visualization. Currently, the example just test the point/stl intersection work. The xPBD solver is WIP.
src/ELEMENTS.h
Added #include "utils/stl_utils.h" so the STL utilities are available through the main ELEMENTS header.
