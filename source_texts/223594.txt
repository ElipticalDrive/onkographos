Pull request overview
This PR implements Part 1 of masked loading optimization for point cloud octrees. The feature allows users to define spatial mask regions to control point cloud visibility and optimize loading by excluding nodes that fall outside visible mask regions. This addresses issue #11 by preventing unnecessary loading of point cloud data that is not visible to the user.
Changes:
Added MaskRegion and MaskConfig type definitions to support spatial masking with opacity-based visibility control
Implemented mask configuration API methods (setMaskConfig, clearMaskConfig, getMaskConfig) in the Potree class
Added node-level culling via nodeIntersectsMask to skip loading octree nodes outside visible mask regions
Added helper utilities for visualizing mask regions in debug mode
Included comprehensive documentation in MASK_USAGE.md explaining mask concepts and usage patterns
