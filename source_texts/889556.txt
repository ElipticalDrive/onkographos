Owner
Adds shaderpack/mcmetal-rt-pack, our own Iris shader pack built around mcmetal's hardware ray tracing (mcm_trace, mcm_trace_hit, mcm_lights_near). Released under MIT, with our own code only: the ideas come from SEUS PTGI and Complementary, but none of their code is used.
What's in it
Light and shadows
Nishita sky
ACES grading
Auto exposure
RT soft sun shadows
Coloured glass shadows
Half-res RT GI + AO
Coloured block light with per-light shadows
Water and weather
Water waves with RT reflections
Light shafts
Soft clouds
Rain puddles
Caustics and underwater shafts
SEUS-style glass: tint, refraction from the glass streaks, and see-through blending as multiply + add
Other
TAA
LabPBR (normals, smoothness, metals, emission)
Distant Horizons programs (dh_terrain, dh_water)
Presets per Mac: Low, Medium, High, Ultra
Debug views
Tests and tooling
shaderpack/tools/check_pack.py compiles every program with glslang, in GL, RT and DH variants.
New ours-* phases and test stages in tests/game (room, pool, glass, PBR with generated test textures).
Gallery screenshots from M3 Max runs are in shaderpack/screens/.
Tested
On the M3 Max at 2560x1440 there were no compile or link failures and no GPU faults. Frame rates:

7f87396
```
Each light block id (10100-10299) has its own colour and light level (lib/lights.glsl). With mcmetal's
light list (MCMETAL_LIGHTS, mcm_lights_near) each pixel picks one nearby light per frame in proportion
to its unshadowed light and traces a shadow ray to a random point in it; deferred1 accumulates that over
16 frames into colortex7, and deferred2 uses it instead of the lightmap's block light. Without the
light list nothing changes. Options: Coloured Block Light, Coloured Light Strength, debug view 5.
check_pack.py stubs mcm_lights_near and now also compiles the MCMETAL_RT branches of ray-free programs.
```

Adds a standalone MIT-licensed Iris shader pack centered on mcmetal hardware ray tracing, with a deferred rendering pipeline and non-RT fallback.
Implements G-buffer, deferred lighting, ray-traced shadows, half-resolution AO/GI, temporal accumulation, reflections, and colored light.
Adds Nishita sky, ACES tonemapping, auto exposure, clouds, shafts, water, caustics, puddles, glass refraction, TAA, LabPBR, and debug views.
Provides Iris shader programs for terrain, entities, translucency, weather, sky, shadow mapping, and Distant Horizons.
Adds configurable RT settings, presets, render-target blending, material/block classifications, and MIT licensing/documentation.

Tips and commands
Interacting with Sourcery
Trigger a new review: Comment @sourcery-ai review on the pull request.
Continue discussions: Reply directly to Sourcery's review comments.
Generate a GitHub issue from a review comment: Ask Sourcery to create an
issue from a review comment by replying to it. You can also reply to a
review comment with @sourcery-ai issue to create an issue from it.
Generate a pull request title: Write @sourcery-ai anywhere in the pull
request title to generate a title at any time. You can also comment
@sourcery-ai title on the pull request to (re-)generate the title at any time.
Generate a pull request summary: Write @sourcery-ai summary anywhere in
the pull request body to generate a PR summary at any time exactly where you
want it. You can also comment @sourcery-ai summary on the pull request to
(re-)generate the summary at any time.
Generate reviewer's guide: Comment @sourcery-ai guide on the pull
request to (re-)generate the reviewer's guide at any time.
Resolve all Sourcery comments: Comment @sourcery-ai resolve on the
pull request to resolve all Sourcery comments. Useful if you've already
addressed all the comments and don't want to see them anymore.
Dismiss all Sourcery reviews: Comment @sourcery-ai dismiss on the pull
request to dismiss all existing Sourcery reviews. Especially useful if you
want to start fresh with a new review - don't forget to comment
@sourcery-ai review to trigger a new review!
