# 3D Gaussian Splatting for Real-Time Radiance Field Rendering

本仓库拉取自[3D Gaussian Splatting](https://github.com/graphdeco-inria/gaussian-splatting)，在此基础上改进与完善

## Cloning the Repository

该版本库包含子模块，因此请使用
```shell
# SSH
git git@github.com:CNITECH-CV-LAB/gaussian-splatting.git --recursive
```
or
```shell
# HTTPS
git clone https://github.com/CNITECH-CV-LAB/gaussian-splatting.git --recursive
```
