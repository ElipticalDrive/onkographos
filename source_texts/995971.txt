Description:
Build a world generation engine that creates biomes. Since we are avoiding frameworks, you must implement a simple Pseudo-Random Number Generator (PRNG) and a Gradient Noise algorithm (like Value Noise or a simple Perlin clone).
Technical Requirements:
Deterministic results using a seed.
Smooth transitions between biomes.
Tasks:
Create a Random utility class using std::mt19937.
Implement a 2D Noise function with at least 3 octaves to generate a "heightmap".
Map height values to CellType enums: WATER (<0.3), PLAINS (0.3-0.6), FOREST (0.6-0.8), MOUNTAIN (>0.8).
Implement a resource system: FOREST cells should regenerate "Food" energy over time.
Write a "World Printer" that uses different ASCII characters for each biome.
