Feature #179
TSDF Volume Implementation
Overview
The TSDF (Truncated Signed Distance Function) volume implementation provides a robust solution for 3D reconstruction from RGB-D images. This implementation includes methods for volume creation, integration of depth and color data, and extraction of both point clouds and triangle meshes.
Core Components
1. Data Structures
TSDFVolumeColorType
```
pub enum TSDFVolumeColorType {
    None,
    RGB(u8, u8, u8),
}
```
Supports both color and non-color modes
Provides conversion to array format for color operations
Voxel
```
pub struct Voxel {
    pub tsdf: f64,      // Signed distance value
    pub weight: f64,    // Integration weight
    pub color: TSDFVolumeColorType,
}
```
Stores TSDF value, weight, and optional color information
Implements Default trait for initialization
TSDFVolume
```
pub struct TSDFVolume {
    pub voxel_length: f64,
    pub sdf_trunc: f64,
    pub color_type: TSDFVolumeColorType,
    pub volume: Array3<Voxel>,
    pub origin: [f64; 3],
}
```
Manages 3D grid of voxels using ndarray
Configurable voxel size and truncation distance
Supports color integration
2. Core Methods
Volume Creation
```
pub fn new(dims: [usize; 3], voxel_length: f64, sdf_trunc: f64, 
          color_type: TSDFVolumeColorType, origin: [f64; 3]) -> Self
```
Initializes a new TSDF volume with specified dimensions
Sets up voxel grid with default values
Configures volume parameters (voxel size, truncation distance)
Integration
```
pub fn integrate(&mut self, rgbd_image: &RGBDImage, 
                intrinsic: &PinholeCameraIntrinsic, 
                extrinsic: &[[f64; 4]; 4])
```
Key features:
Projects voxels to camera space
Handles out-of-bounds projections
Integrates depth and color information
Uses weighted averaging for updates
Supports camera transformations
Point Cloud Extraction
```
pub fn extract_point_cloud(&self) -> PointCloud
```
Features:
Detects zero-crossings in TSDF values
Computes surface normals
Filters points based on threshold
Returns points and normals
Triangle Mesh Extraction
```
pub fn extract_triangle_mesh(&self) -> TriangleMesh
```
Implementation details:
Uses Marching Cubes algorithm
Includes lookup tables for edge and triangle configurations
Interpolates vertex positions
Generates triangle mesh from TSDF volume
3. Helper Methods
Vertex Interpolation
```
pub fn interpolate_vertex(x1: f64, y1: f64, z1: f64,
                         x2: f64, y2: f64, z2: f64,
                         val1: f64, val2: f64,
                         iso_level: f64,
                         voxel_length: f64,
                         origin: &[f64; 3]) -> [f32; 3]
```
Interpolates vertex positions for mesh generation
Uses linear interpolation between voxel centers
Volume Reset
```
pub fn reset(&mut self)
```
Clears all voxel data
Resets to initial state

Usage Example
```
// Create a new TSDF volume
let mut volume = TSDFVolume::new(
    [10, 10, 10],  // dimensions
    0.1,           // voxel size
    0.1,           // truncation distance
    TSDFVolumeColorType::RGB(0, 0, 0),  // color type
    [0.0, 0.0, 0.0]  // origin
);

// Integrate RGB-D data
volume.integrate(&rgbd_image, &camera_intrinsic, &camera_extrinsic);

// Extract point cloud
let point_cloud = volume.extract_point_cloud();

// Extract triangle mesh
let mesh = volume.extract_triangle_mesh();
```

Author
Hi @edgarriba , That is a totally valid view. I am giving here the references. Mainly referred to the open3d and opencv implemantations:
Structs
Main TSDF Volume structure follows Open3D's Python API
Supporting structures (PinholeCameraIntrinsic, RGBDImage) also mirror Open3D's design
Voxel implementation based on Open3D's VoxelGrid
Methods
Point Cloud Extraction:
Implemented following Open3D's UniformTSDFVolume
Handles zero-crossing detection and normal computation
Mesh Extraction (Marching Cubes):
Combined approach from Open3D and Paul Bourke's implementation
Includes lookup tables for edge and triangle configurations
Opencv implemenation has a reference to this link
Volume Integration:
Based on OpenCV's TSDF implementation
Adapted for Rust's memory and safety model
Note: This part needs additional verification and testing

 - For test cases, I took help from copilot. It's not great at translating the implementation, I tried for integrate specially.
