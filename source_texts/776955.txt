Objective
Provide an opt-in example that loads one locally available supported DICOM-CT-PD examination, applies the documented preprocessing, and reconstructs it.
Constraints
Do not commit clinical datasets.
Require explicit user-provided dataset path.
Clearly state calibration/measurement assumptions and unsupported processing.
Compare with provided reference images only when geometry/series correspondence is established.
Acceptance criteria
Example is excluded from default CI unless a fixture is available.
Missing dataset produces helpful instructions.
Provenance and configuration are recorded.
Output is quantitatively/qualitatively compared with an appropriate reference where valid.
