# Hypertrace

A GPU raymarcher for 3D and 4D fractals, written in Rust with **one external dependency**.

Degree-*n* Mandelbulbs, quaternion Julia and Mandelbrot sets sliced out of 4D, and a
Mandelbox — all rendered by sphere-tracing an analytic distance estimator in a WGSL
fragment shader, with the cyan crevice glow driven by raymarch step count.

![Degree-2 Mandelbulb wallpaper](docs/wallpaper.png)

## The interface

![Hypertrace interface](docs/interface.png)

The interface is deliberately monochrome — the render is the only thing in the window
with a hue, so the chrome stays out of its way. Everything is live: change the fractal,
the power, the 4D slice, the palette or the lighting and the image updates as you drag.
While the view is moving a governor lowers the render scale only as far as it needs to
hold the frame rate, and restores full resolution the moment it settles.

## Screensaver

![Screensaver](docs/screensaver.png)

`F11`, the toolbar button, or `hypertrace --screensaver` starts a fullscreen tour of
every preset, with orbiting cameras, sweeping 4D slices and fades between scenes. Any
key, click or mouse movement dismisses it.

## Running

```sh
./run.sh                 # build and launch
./install.sh             # add to the application launcher (all under $HOME)
./uninstall.sh           # undo install.sh
```

`install.sh` also **renders the app icon using the app's own shader** — the launcher
icon above is a real 4D quaternion Julia set viewed down the axis of its nested shells,
not a shipped image asset.

Command line:

```sh
hypertrace --list-presets
hypertrace --render wall.png 3840x2160 6   # crisp wallpaper preset at 4K
hypertrace --screensaver
hypertrace --icon icon.png 256
```

Every image in this README was produced by `--render`, so you can regenerate any of them.

## The maths

**Mandelbulb** (`z → zⁿ + c`) uses triplex spherical coordinates, since 3D has no
division algebra: raise the radius to the *n*th power and multiply both angles by *n*.
At `n = 2` the `y = 0` plane is where the map degenerates to ordinary complex squaring,
which is why the cutaway exposes an exact 2D Mandelbrot cardioid there.

**Quaternion sets** iterate `q → q² + c` with
`q² = (w² − x² − y² − z², 2wx, 2wy, 2wz)`. The result is 4D, so one component is pinned
to give a 3D cross-section; sweeping it animates through the 4D solid. Pinning `z` keeps
`(w, x, y)` — the slice with real structure. Pinning `w` leaves a near-featureless blob.

**Distance estimation.** Each iteration also carries a scalar derivative `dr`
(`dr ← n·rⁿ⁻¹·dr + 1` for the bulbs, `dr ← 2|q|·dr` for quaternions). On escape,

```
d(p) = 0.5 · |z| · ln|z| / dr
```

bounds the distance to the nearest surface, so rays can sphere-trace in adaptive steps
without overshooting. Normals come from central differences of that field, and the
**step count** doubles as a free ambient-occlusion term — which is where the glow comes
from: deep crevices force many tiny steps, so they light up.

## Getting a crisp image

Detail at depth is iteration-bound before it is resolution-bound.

- **Fractal iterations** — raise first if detail looks melted.
- **Max ray steps** — raise if surfaces look eaten away.
- **Render scale** above 100% is true supersampling.
- **Sharpen** is an unsharp mask applied after tonemapping.

The *Crisp* button in *Quality & sharpness* sets all four at once.

## Dependencies

One: [`eframe`](https://crates.io/crates/eframe), which supplies the window, the event
loop and wgpu. Everything else is in-tree, including things normally taken from crates:

- **`src/png.rs`** — a real PNG codec: adaptive per-row filtering into an LZ77 +
  fixed-Huffman DEFLATE stream, with CRC-32 and Adler-32. Lands within ~22% of
  `zlib -9` on these renders, and its output is verified against stock zlib by the
  test suite.
- **`src/util.rs`** — a parking executor for `block_on`, and the byte casting for
  GPU uploads.

That single dependency is the floor for a GPU application with a window: below it you
are writing a Vulkan loader, an X11/Wayland client and a GUI toolkit by hand.

Needs a Vulkan/Metal/DX12-capable GPU and a current Rust toolchain — newer than a
typical distro-packaged `rustc`; `run.sh` prefers rustup's toolchain automatically.

```sh
cargo test    # PNG codec round-trips, checksums against known vectors
```

## Layout

| file | role |
| --- | --- |
| `src/shaders/fractal.wgsl` | distance estimators, sphere tracing, shading |
| `src/shaders/blit.wgsl` | resolution-independent present + sharpen |
| `src/params.rs` | render state, GPU uniform packing, presets |
| `src/render.rs` | wgpu pipelines, offscreen pass, egui paint callback |
| `src/app.rs` | state, input, quality governor, screensaver, HUD |
| `src/ui.rs`, `src/theme.rs` | controls panel and styling |
| `src/showcase.rs` | the automated tour |
| `src/export.rs`, `src/icon.rs` | background wallpaper export, headless rendering |
| `src/png.rs`, `src/util.rs` | the hand-written bits that avoid dependencies |
