Summary
Extend the native Texture Editor preview to Texture3D assets with slice-based inspection and a native volume visualization mode.
Roadmap metadata
Project Space: Materials
Horizon: Later
Priority: P1
Size: L
Type: feature
Parent Epic: [Epic] Materials, Shaders & Textures #333
Scope
Add Texture3D support to the native texture preview path
Add X, Y, and Z slice inspection
Add slice index controls with correct dimension/range handling
Add grid mode for reviewing multiple slices at once
Add a native volume raymarch view
Add opacity and sample-quality controls for volume visualization
Preserve mip selection where applicable
Add exact texel inspection with x/y/z coordinates using the native inspection API from V2
Keep React responsible for slice controls, labels, rulers, and overlays while native rendering owns texture pixels
Acceptance criteria
Texture3D assets open directly in the Texture Editor native preview path
X/Y/Z slice modes select the correct volume slice and dimensions
Grid mode can inspect a useful range of slices without creating separate preview resources per slice
Volume mode raymarches the actual engine texture resource with adjustable opacity/sample quality
Pixel inspection reports x/y/z and exact source values, including float/HDR values
Preview behavior remains responsive for large volumes and does not block the editor UI
