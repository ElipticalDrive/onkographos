Hi,
first of all: thank you VERY much for this fantastic library!
I tried to do that on my own but failed several times... I have an "open"/planar mesh and tried to use your methods provided but the distances I get are not correct for my mesh. I think that's because it is (nearly) flat and so the minimum distance is (nearly) always 0. It might be a solution to ignore the height (z in my case, coming from 3dsMax) so that only x and y are used for distance calculations but I didn't really know what I was doing when I tried that on my own...
```
public void CalculateDistance_SignedDistanceField(List<Vector3d> points, DMesh3 surface, int cellCount)
        {
            double cell_size = surface.CachedBounds.MaxDim / cellCount;

            MeshSignedDistanceGrid sdf = new MeshSignedDistanceGrid(surface, cell_size)
            {
                ComputeSigns = false
            };
            sdf.Compute();

            var iso = new DenseGridTrilinearImplicit(sdf);
            double[] distances = new double[points.Count];
            for (int b = 0, bMax = points.Count; b < bMax; b++)
            {
                distances[b] = iso.Value(ref points[b]);
            }
            // put distance in range 0 to 1
            distances = distances.Normalize(0, 1);
        }
```
The above leads to strange distances. I tried to edit the Value method of class "DenseGridTrilinearImplicit" but without success to eliminate z in this method.
Any hints or suggestions? Is there a better way to get the 2D distances of a "pointcloud"?
Thank you!!!
