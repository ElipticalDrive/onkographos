Summary
Complete implementation of the Three.js Point Cloud Viewer with the following features:
File Loading: Native file picker via Tauri dialog plugin, supports PCD/PLY/LAS/LAZ formats
Color Modes: Height-based, intensity, RGB, and classification coloring with GLSL shaders
Bounding Boxes: 3D detection visualization with selection and raycasting
LOD System: Octree-based level-of-detail for rendering 10M+ points at 60fps
Streaming: Event-based chunked loading for large files (>1M points)
Controls Panel: Collapsible settings panel with point size, view helpers, keyboard shortcuts

* fix(keyboard): use separate shortcuts for alternative keys

Array combos were being treated as sequences (for vim-style 'g g', 'd d')
but were incorrectly used for alternative keys (j/arrowdown, delete/backspace).

Fixed by registering separate shortcuts for each alternative key.

* fix(keyboard): simplify matchesCombo key matching logic

Removed confusing redundant special case checks that could never
trigger due to the outer condition already being true.

* fix(keyboard): resolve effect_update_depth_exceeded infinite loops

Wrap keyboard store method calls in untrack() to prevent Svelte 5
from tracking reactive state reads that happen inside these methods:

- keyboard.setScope() reads scopeStack before writing to it
- keyboard.register() reads registeredShortcuts before writing to it

Without untrack(), these read-then-write patterns inside $effect
cause infinite re-renders.

Files fixed:
- +layout.svelte: scope setting and shortcut registration effects
- ExecutionView.svelte: shortcut registration effect
- ReviewQueue.svelte: shortcut registration effect
- PlanEditor.svelte: shortcut registration effect
- SetupWizard.svelte: skip button race condition fix
- +page.svelte: setup completion reactivity fix

* fix(keyboard): address code review findings

- Allow both Ctrl and Cmd on Mac for shortcut matching
- Exclude modifier keys from starting key sequences
- Check element.isConnected before restoring focus in FocusTrap
