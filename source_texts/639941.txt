I have extensively looked into a way for OpenSCAD to render single-face planes to a 3D format such as .obj but have not found a solution. My current workflow requires adding extra geometry such as solid cubes then deleting all but one face in Blender. Sometimes you can use custom polygons and paths to achieve what you want but anything that is determined to be 2D is rendered on the 2D plane instead of in 3D space, even though the .obj format would be happy to host it.
2D plane support could make OpenSCAD distinctly more versatile when used for modelling 3D graphics as designs would be far less inefficient.

OpenSCAD can already preview 2D objects arbitrarily positioned and aligned in 3-space. There are even two ways to do it: you can translate/rotate a "native" 2D object, or you can create an incomplete polyhedron. The incomplete polyhedron is in a sense more correct, because the faces are zero thickness, but it doesn't even start to work for rendering. (I'm hazy on whether it would work for preview. I think it would.)
But there's no OpenSCAD-ish way to export the result, except as an image resulting from a preview.
