very rudimentary suggestion to add the ability to use both the perspective and orthographic projections calculations in the base transform type.
with the inclusion of love 12's love.graphics.setProjection and love.graphics.resetProjection functions for easier access to 3d rendering, I think it would be useful to have both of the functions defined in the base love transform class so people don't need to meddle around with ffi cdef's or redefine the matrix themselves to be able to achieve the calculations that are simply not binded.
Matrix4 Function Definitions:
https://github.com/love2d/love/blob/main/src/common/Matrix.cpp#L444
https://github.com/love2d/love/blob/main/src/common/Matrix.cpp#L459
