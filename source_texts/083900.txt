This PR adds several fun and creative features to the CLI to push its utility and interactivity.
Features Added:
Progress Bar (indicatif): Provides a visual progress bar during Rayon parallel voxelization, greatly improving UX for high-resolution meshes.
Terminal Braille Preview (--preview): Generates an instant top-down (X-Z) and front (X-Y) orthographic projection of the resulting point cloud directly in the terminal using braille block characters. This is extremely helpful for getting immediate visual confirmation without needing to open a 3D viewer.
Procedural Modifiers:
--disintegrate <probability>: Randomly drops particles based on a probability threshold, simulating a damaged or dissolved mesh.
--wave <amplitude>,<frequency>: Applies a geometric sine wave displacement across the X-axis onto the Y coordinate, organically warping the final point cloud.

This commit introduces several creative enhancements to `voxelizer-rs`:
- A parallel progress bar powered by `indicatif` to provide visual feedback during voxelization.
- A `--preview` CLI flag that orthographically projects the resulting point cloud and renders it directly in the terminal using braille characters (Top and Front views).
- Procedural mesh modifiers (`--disintegrate <probability>` and `--wave <amplitude>,<frequency>`) that apply random particle dropouts and sine-wave deformations to the point cloud after voxelization.

Validate --disintegrate within [0,1]
--disintegrate is documented and used as a probability, but the code accepts any f64 and compares it directly with rng(). Values greater than 1.0 will delete every particle and values below 0.0 will delete none, which silently produces unintuitive outputs for malformed input instead of a CLI validation error.
