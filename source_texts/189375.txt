Bug
ray_intersect_box uses abs(ray_direction[i]) < MINVAL to decide which axes participate in its slab intersection, but reconstructs face normals only for abs(ray_direction[i]) > EPSILON. A small nonzero axis direction between those two thresholds can produce a valid hit distance and a zero normal even when the face is unambiguous.
Exact witness
Box half-extents: (1,1,1)
Origin: (1 + 2**-23, 0, 0)
Direction: (-2**-22, 1, 0)
Solved hit: t = 0.5, point (1,0.5,0)
Expected outward normal: (1,0,0); observed unmodified normal: (0,0,0).
The regression invokes the actual kernel_test_geom and public newton.intersect_ray paths, not an analytical substitute. The condition remains present on upstream main@bd69b56dc00693976c2fea9bd89afd863178140c in newton/_src/geometry/raycast.py.
Evidence and scope
The narrow original downstream candidate and CPU receipt are recorded in kvnloo/newton commit 878ae1e and factory queue #66: two registered regression tests with 52 subcases, 16 expected failing subcases on baseline, 20 native CPU raycast tests passed with correction, 16 adjacent CPU tests passed, 72 independent probe cases passed; pre-commit passed. Environment: Python 3.12.14, Warp 1.18.0, NumPy 2.5.4, Linux CPU. No CUDA driver, so nvidia-smi/CUDA confirmation unavailable.
The current-upstream port, which preserves intervening raycast and test changes, is fork PR #26, head 2879505, only three files changed and 3 ahead/0 behind. Current-port hosted/native execution has not yet been independently verified; historical native data is explicitly dated.
This differs from #4526: that is MPR collision contact normal, while this is a box raycast query. It also does not touch Featherstone or the other owner's #4762.
Minimal remedy: use abs(ray_direction[i]) >= MINVAL during face-normal reconstruction, matching the axes considered by the slab hit. Preserve solved distance, bounds, EPSILON time matching and corner normal normalization.
Original raycast code credit: nvtw, Daniela Hase, Mustafa H and Alain Denzler; earlier tested downstream correction and QA remain linked. GPT-6 assisted the current-head port under user direction.
