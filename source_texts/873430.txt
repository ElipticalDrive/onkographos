Applications currently have to supply their own SE(3) geometry to propagate uncertainty through 3D transforms. This adds blackwell.spaces.se3 with composition, inversion, point action, exp/log, right retraction, local coordinates, adjoint and covariance transport.
Poses use the plan's [x, y, z, qx, qy, qz, qw] Hamilton quaternion encoding, with six translation-first body tangent coordinates. The public operations differentiate at zero rotation, handle equivalent quaternion signs and document the principal logarithm's 180° discontinuity. Existing belief containers and filter kernels are unchanged.
The runnable uncertainty example propagates the full joint covariance through composition, inversion and point transformation. Tests compare automatic differentiation with analytical Jacobians and finite differences, verify cancellation for a pose and its correlated inverse, and compare 50,000 transformed point samples with the first-order covariance. Integration tests exercise both generic filters, including EKF gradients and particle resampling.
Validation on macOS ARM / Python 3.12.13:
All 91 tests passed with JAX 0.11.1 and with the built wheel in a clean JAX 0.6.0 environment.
The correlated point covariance differs from Monte Carlo by 0.69%; discarding correlation raises the error to approximately 29%.
Ruff, both release examples, strict MkDocs build, source/wheel build and strict Twine metadata checks passed.
