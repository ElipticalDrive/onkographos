New GPU/SOTA feature: a differentiable 3D Gaussian splatting rasterizer, built once in the unified torch backend (src/myraytracer/gpu/) so the same code runs on CPU and GPU by device selection — do not add a separate numpy implementation.
SOTA basis: Kerbl, Kopanas, Leimkühler, Drettakis, "3D Gaussian Splatting for Real-Time Radiance Field Rendering", SIGGRAPH 2023 — represent the scene as anisotropic 3D Gaussians, project to 2D, alpha-composite front-to-back.
Files: src/myraytracer/gpu/splat.py, tests/gpu/test_splat.py (new).
Scope (single session):
A Gaussians dataclass of batched tensors: mean (G,3), scale (G,3), quat (G,4) (rotation), opacity (G,), color (G,3). All tensors on a caller-provided device; reuse gpu/vec.py ops and the device() helper. No numpy path.
rasterize(gaussians, camera, width, height, *, device) -> Tensor(H,W,3) — project each Gaussian to screen space via the existing gpu/camera.py, form the 2D covariance from scale+quat, evaluate the Gaussian footprint per pixel, sort by depth, and alpha-composite front-to-back. Fully batched (tensor ops), no Python loop over Gaussians or pixels beyond the depth-sort.
Deterministic given a seeded torch.Generator.
Autograd-safe throughout — output must be differentiable w.r.t. mean, scale, quat, opacity, color; no in-place ops on tensors that require grad; document any torch.where masking.
Tests: a single white Gaussian at image center produces a bright central blob that decays outward; opacity=0 yields a black image; determinism across two seeded calls; gradcheck (float64) that a small image is differentiable w.r.t. color and opacity.
Docstrings: required on every public function/class — one-line summary plus the compositing invariant (front-to-back order, what opacity/color mean).
