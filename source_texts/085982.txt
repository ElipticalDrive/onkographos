Turn resident voxel chunks into textured geometry through plugins/voxel. Hidden faces are removed across chunk borders, coplanar faces can merge without stretching tiles, and stale or failed replacements preserve the previously uploaded chunk.
Keep storage, queries and meshing CPU-only by default. The optional render feature uses the existing SDK mesh/material APIs; engine crates do not depend on the plugin.
Capture owned owner/neighbor border data and world-specific dependency receipts. Check owner/neighbor generations and revisions, including missing neighbors, before accepting results. Capture data and stamps together with at most seven lookups.
Generate deterministic indexed opaque/cutout batches with outward winding, normals, face tiles, repeating UVs, directional face shading, explicit output limits and 16-bit splitting. Cutout neighbors retain geometry behind their alpha holes. Blended owner blocks are explicitly unsupported for now.
Supply atlas-aware repeating materials (with unwrapped texture gradients), custom material bindings, camera-relative chunk bounds and frustum culling. Validate every material and stage all GPU batches before committing; release partial uploads on failure. Empty results explicitly remove geometry.
Add the SDK's read-only Assets::validate_material extension point, checked authoring recipes, a procedural-texture rendering example, CPU/native CI coverage, and reproducible benchmark/resource reporting.
Validation passed: scripts/check.sh, Rust 1.89 workspace/all-target checks with rendering enabled, generated-project smoke checks, the complete X11 native smoke suite, default-feature CPU tests/query example, and workspace benchmark compilation. The plugin has 35 CPU tests and four documentation snippets, plus a serial native probe covering opaque/cutout pixels, repeated atlas tiles, depth, culling, stale results, unload/reinit, and partial multi-batch rollback. Pixel checks draw retained geometry immediately after the injected failure. The existing SDK probe also verifies rejected GL buffer allocations.

Greedy mode benefits contiguous fixtures; checkerboard geometry stays unchanged and takes about 4.6% more CPU in this run. Culled mode remains selectable. Payload reductions are exact; timing changes require comparable runs and confidence intervals. Native workloads report complete upload/submission wall time and driver stalls, not GPU timers or game FPS.
Clean voxel-meshing-v1 and voxel-render-v1 exports retain revision/toolchain/machine metadata (native run: RTX 4070, NVIDIA 610.57.04, X11). The original 11 storage/query IDs still compare against their previous baseline without metadata/ID mismatches. The 22 CPU and 17 native workload exports also compare with matching conditions and IDs. Native timing preparation excludes snapshot generation.

```

```
SPACE edits a border block and rebuilds affected resident neighbors. The game owns scheduling and teardown. Automatic streaming/rebuild/upload budgets are the separate next issue (#22); propagated lighting and blended sorting remain outside this mesher.
