This PR deletes rendering code that is no longer used:
The halo renderer / volume-integration renderer (HALO_RENDER in surface_pixel, Shaders.cmap_quad, decode_float_vec2, and the commented-out wiring in mriview_surface.js and axes3d.js): an unfinished 2013 experiment, unreachable since the Three.js r69 rewrite in 2014.
VolumeSheets (mriview_surface.js): never instantiated anywhere in the repo's history.
shadowtex.js: never instantiated. Only simple.html loaded it.
setHalo() stays: despite the name, it builds the surface's live mesh. Renaming may need more refactoring, so it is out of the scope of this PR.
Testing
Shader link and headless viewer tests: 203 passed, 1 skipped (opt-in visual comparison).
Follow-ups
simple.html was already broken: it loads files that don't exist.
