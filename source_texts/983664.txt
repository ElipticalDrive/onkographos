Motivation
Promote the existing TypeScript dual-contouring implementation into a canonical shared isosurface kernel for ContentEngin, GameEngin, and LabEngin so all engins use a single, consistent primitive for SDF → mesh extraction.
Surface richer runtime metadata (job envelope, diagnostics, mobile tiers, memory estimates) so engins and rulesets can reason about safe mobile defaults and export quality ladders.
Convert the ContentEngin photo seam from a simple relabel stub into a deterministic algebraic region fitter so image regions produce deterministic SDF hints and procedural part hints for downstream pipeline use.
Description
Introduces a typed IsoSurface job API and helpers in engins/isosurfaceDualContouring.ts including IsoSurfaceJob, normalizeDualContouringSettings, estimateIsoSurfaceMemoryBytes, classifyMobileIsoSurfaceTier, runIsoSurfaceJob, and additional primitive SDF factories (createTorusSDF, createCapsuleSDF, createBoxSDF).
Replaces the simple relabeler with a deterministic algebraic fitter in engins/contentengin/photo/regionDetector.ts that returns AlgebraicRegionFit metadata (fit kind, symmetry/aspect/contour scores, skeleton, SDF hint, inferred label, confidence) and detectSemanticAlgebraicRegions and relabelRegion functions.
Wires photo analysis into recipes by updating engins/contentengin/photo/photoToRecipe.ts to preserve proceduralPartHints on the ContentRecipe, and updates the content build pipeline in engins/contentengin/pipeline/build.ts to attach those hints to matching PartNode metadata before UV/L0D/collision steps.
Adds SDF→mesh helper and recipe-driven mesh generation in engins/contentengin/builders/meshBuilder.ts via sdfFromAlgebraicFit, buildRegionFitContentMesh, and buildImplicitContentMesh using the shared runIsoSurfaceJob path so snapshots include job diagnostics.
Exposes named GameEngin generators in engins/gameengin/procgen.ts (generateCaveChunk, generateRockProp, generateTerrainCutout, generateDestructibleWallChunk) that call the shared iso kernel and return validated snapshot + job info for runtime/world-building use.
Expands LabEngin implicit surface sandbox in engins/labengin/implicitSurface.ts into preset-driven runs (metaball/fluid/particle/terrain-cave/etc.) and routes execution through runIsoSurfaceJob so Lab can publish diagnostics.
Updates ruleset policy metadata for Content/Game/Lab in engins/rulesets/* to reference the sharedKernel, mobile-first qualityLadder/presets/namedGenerators and to list diagnostics the Lab should publish.
Testing
Ran type checking with pnpm typecheck across app/worker/server/test tsconfigs and the run completed successfully.
Ran lint with pnpm lint and ESLint finished with repository warnings (no new lint errors introduced by this change).
