Feature Summary
1D and 2D lookup tables should allow the user to specify the interpolation/matching method:
Exact (match)
Next lower
Linear
This is a limitation of 2D lookup tables particularly, where an exact column match is needed. Improvements to the functionality of 1D lookup could also be implemented.
Also consider a warning flagged if extrapolation occurs (outside of data bounds) or consider denying extrapolation beyond the data-bounds specified.
Problem/Motivation
Lookup tables interpolate linearly in rows, but some model parameters would be better having a 'next lower' or an 'exact' match. Similarly for columns, exact match is useful, but to allow greater flexibility a bi-linear lookup should be permissible (or a next lower).
Proposed Solution
Using 1D or 2D lookup tables allows the user to specify
interp_method = linear # for 1D lookup tables
interp_method = exact, linear # for 2D lookup tables
These are optional parameters and if-not specified would default to linear (rows) and exact (cols).
