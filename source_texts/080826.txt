Adds static procedural clouds to the physical sun-sky example, stacked on #77 (speed-up-sun-sky). Clouds affect the sky, IBL, solar disc, directional/CSM sunlight, ground illumination and exposure. Controls include coverage, altitude, density, feature size and arrangement.
Try the demo · Pinned demo · Raw HTML
The visible sky is now decoupled from the IBL/PMREM chain. The original pixelation came from drawing the background with the same 512×256 equirectangular texture used as the IBL source; the background was not sampling PMREM itself.
In Sky quality:
Background width px: 512, 1024, 2048, 4096 default, 8192. Height is half the width.
IBL source width px: 512 default, 1024, 2048, 4096. PMREM derives its own face size from this source.
The previous default is the minimum for both controls. Changing background resolution rebuilds only the visible texture, retaining the same IBL, sunlight and exposure. Sun/cloud/atmosphere changes update both. Unchanged frames reuse the baked textures. The 4096 background target occupies 64 MiB; 8192 occupies 256 MiB.
The solar disc remains excluded from IBL. A 1×1 GPU pass evaluates solar transmittance from the same cloud density field, and the existing meter readback carries it in alpha. Ground illumination samples the same GPU result; no additional CPU readback barrier is introduced.
Validation on a physical NVIDIA GTX 1050 WebGPU context, using the unchanged checked-in builds served by raw.githack:
Core lint and changed example/addon/benchmark ESLint passed. 1,957 core tests passed (1 todo), 107 addon tests passed. The addon suite logged one resource 404 without assertion failures; the Windows test runner also logged process-cleanup diagnostics. No TypeScript typecheck is configured. Build passed during the initial implementation; this follow-up changes example and validation files only.
All five visible resolutions rendered successfully without increasing lighting bake count, changing PMREM target identity, IBL source dimensions, or sunlight intensity.
16 lighting states passed: elevations 90°, 30°, 5°, −2° × coverage 0, 0.3, 0.7, 1. All radiance finite. Clear endpoint matched 524,288 original atmosphere components bit-for-bit; zero density was transparent; thick overcast suppressed sunlight; directional/CSM intensity matched expected transmittance.
Thirty actual animation calls with unchanged settings caused no new lighting bakes.
