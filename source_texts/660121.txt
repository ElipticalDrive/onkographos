Summary
Add page/tile-based virtual texture residency so very large photogrammetry and environment material sets can scale independently of whole-texture mip residency.
Roadmap metadata
Project Space: Materials
Horizon: Later
Priority: P1
Size: XL
Type: feature
Parent Epic: [Epic] Materials, Shaders & Textures #333
Motivation
ARC already has mip-based texture streaming, which is sufficient for many assets. Massive source-detail geometry and photogrammetry scenes can require multi-gigabyte texture datasets where loading whole mip levels wastes memory on unseen regions. Tiled virtual texturing should be an optional high-end path, not a prerequisite for basic virtual geometry.
Scope
Define backend-neutral virtual texture/page-table contracts
Cook textures into independently addressable tiles with border/gutter handling and deterministic page metadata
Add GPU feedback/request generation and bounded physical tile caches
Add generation-safe async tile IO/upload/eviction with resident fallback mips
Support material sampling through virtual texture page tables without changing authoring semantics
Integrate texture budgets with Add device profiles and scalability tiers #405 device/scalability profiles
Expose residency/request/eviction diagnostics through runtime telemetry and Texture Editor diagnostics
Validate with large photogrammetry/material datasets and camera fly-throughs
Acceptance criteria
Texture memory stays inside configured tile-cache budgets
Missing high-resolution tiles sample a valid resident fallback rather than producing holes/garbage
Tile requests/evictions are generation safe and measurable
Sampling works with normal material UV transforms and explicit gradients
Existing non-virtual textures continue to use the simpler mip-streaming path
Large benchmark scenes can exceed physical texture-memory working set without loading all source texture data
Dependencies
Existing texture cooker/streaming/runtime contracts
Support visibility-buffer material shading with explicit texture gradients #478 explicit-gradient visibility-buffer shading for correct deferred sampling
Add device profiles and scalability tiers #405 device profiles/scalability tiers
Texture Preview V5 — Residency and GPU diagnostics #431 Texture Preview V5 can consume the resulting residency diagnostics
