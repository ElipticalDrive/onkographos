Scope
```
terrain hills 64x64 cell=1 palette=field
  noise cell=16 octaves=3 roughness=50 seed=7 range=0..4
  raise at=20,30 radius=6 by=2
  flatten at=40,10 radius=5 to=1
  heights from=hand_edits   ; optional: a hand grid added on top
```
noise is seeded value noise of the crate's own (no dependency, Decision: depend on spritebox, or stay at zero dependencies #7), with the same parameter names as spritebox's texture (cell, octaves, roughness, seed) so a writer knows them, mapped to a height range in meters. Its algorithm and random stream are documented and pinned: changing them is a breaking change noted in the CHANGELOG.
Edits apply in order: raise/lower (a smooth bump of a radius), flatten (to a height, for building plots and paths), set (one vertex), and a hand heights grid added on top.
The bump profile is a polynomial (smoothstep), not a transcendental function, so the heights are byte-identical everywhere.
Acceptance criteria
The same seed gives the same heights on every CI platform (golden hash, and noise values pinned against a committed fixture); another seed gives others.
A test checks that flatten leaves every vertex inside its radius at the target height.
A 256×256 terrain builds in under 200 ms in release on CI.
Touches: src/terrain.rs, new src/noise.rs, tests/terrain.rs.
