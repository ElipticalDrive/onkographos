# Setup  

Tested on Nvidia RTX 3090/4090. Since our project relies on OptiX, we don’t recommend professional compute cards, which lack ray tracing hardware and fall back to slower software ray tracing.   

Clone the code and create the environment:

```shell
git clone --recursive https://github.com/zjumsj/RelightableGaussianBlendshapes  
cd RelightableGaussianBlendshapes

# create env using conda  
conda create -n relightableGB python=3.9 pip=23.3.1
conda activate relightableGB

# install dependency of OpenEXR
sudo apt install libopenexr-dev
```

Make sure [CUDA 11.8](https://developer.nvidia.com/cuda-11-8-0-download-archive) is installed, and then install PyTorch:    
```shell  
pip install torch==2.0.0 torchvision==0.15.1 --index-url https://download.pytorch.org/whl/cu118  
```

Install the required packages:

```shell
pip install -r requirements.txt  
```

Next, install the following additional packages:  
```shell  
pip install ./submodules/diff-gaussian-rasterization
pip install ./submodules/simple-knn
pip install git+https://github.com/zjumsj/diff_envshade.git
# install FRNN
cd external
git clone --recursive https://github.com/lxxue/FRNN.git
cd FRNN
git checkout efc6b37
cd external/prefix_sum
pip install .
cd ../..
pip install .
cd ../..
```
<!-- pip install git+https://github.com/lxxue/FRNN.git@efc6b37 not work -->

Finally, install [torchoptixext_visibility](https://github.com/zjumsj/torchoptixext_visibility) and [PyTorch3D](https://github.com/facebookresearch/pytorch3d/blob/main/INSTALL.md) (v0.7.1 is recommended) following their instructions.  

Our Gaussian blendshapes are initialized from FLAME model. You need to create an account on the [FLAME website](https://flame.is.tue.mpg.de/download.php) and download FLAME 2020 model. Please unzip FLAME2020.zip and put generic_model.pkl under ./data/FLAME2020.
