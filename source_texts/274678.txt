Baselode JS Specification — Section and Slice Viewing Helpers
Purpose
Add two interactive viewing helpers to the Baselode JavaScript 3D viewer to support common geological and mining interpretation workflows.
Mining and geological modelling software commonly allows users to view a scene using:
Sections (orthogonal vertical cross-sections aligned to coordinate axes)
Slices (arbitrary planar slabs through the model)
These helpers allow users to inspect drillholes, meshes, block models, and other spatial objects by isolating a cross-section or planar slice of the scene.
The implementation must use Three.js-native concepts and integrate cleanly with the Baselode rendering architecture.
Coordinate System Assumptions
Baselode scenes follow the convention:
X = Easting
Y = Northing
Z = Elevation
Z is up
Sections are typically vertical planes aligned to X or Y
Slices can be arbitrary planes in 3D space
Helper 1 — Section Tool
Concept
A section (also called a cross-section) is a vertical planar view aligned to a principal axis.
This tool locks the camera to an orthogonal view and clips the scene so that only geometry behind the section plane is visible.
This is a standard workflow in mining software (Leapfrog, Vulcan, Micromine, Datamine).
Behaviour
When the section tool is active:
The camera switches to orthographic projection
The camera is aligned to either:
+X / -X direction (looking East-West)
+Y / -Y direction (looking North-South)
A clipping plane is inserted at the section position
Geometry in front of the plane (toward the camera) is hidden
Geometry behind the plane remains visible
This produces the visual effect of a geological section view.
Section Plane Definition
The section plane is defined as:
Plane(normal, distance)
Examples:
X Section
normal = (1,0,0)
distance = X0
Y Section
normal = (0,1,0)
distance = Y0
User Controls
The section tool must expose controls allowing the user to:
Choose Section Orientation
X Section
Y Section
Move Section Position
Move the section plane along its orthogonal axis.
X section → slide along X
Y section → slide along Y
Step Controls
Provide incremental stepping:
Step Forward
Step Back
Step size is configurable.
Visual Aids
The tool should optionally render:
a section plane indicator
a grid aligned to the section plane
These assist spatial orientation.
Rendering Implementation
The section tool must use Three.js clipping planes.
renderer.localClippingEnabled = true
A clipping plane is added to the renderer or materials.
Example:
material.clippingPlanes = [sectionPlane]
Clipping must apply to:
meshes
point clouds
lines
drillholes
block models
Public API
enableSectionMode(axis: "x" | "y")
disableSectionMode()
setSectionPosition(distance: number)
stepSection(delta: number)
getSectionPosition(): number
Camera Behaviour
When enabled:
camera = THREE.OrthographicCamera
Camera orientation:
X Section
camera.lookDirection = (-1,0,0)
Y Section
camera.lookDirection = (0,-1,0)
Camera controls must prevent rotation but allow:
pan
zoom
Acceptance Criteria
Activating section mode locks the camera to an orthographic section view.
Moving the section slider updates the clipping plane position.
Geometry in front of the section is hidden.
Geometry behind the section is visible.
All supported Baselode scene objects obey the clipping plane.
Helper 2 — Slice Tool
Concept
A slice (sometimes called a slab slice) displays only objects within a finite thickness around a plane.
Unlike a section:
A slice shows both sides of a plane
Only geometry within a defined distance from the plane is visible.
Slices allow users to inspect narrow zones through a 3D model.
Behaviour
The slice tool defines a planar slab:
Plane(normal, distance)
Width = slice thickness
The visible region is:
distance ± width/2
All geometry outside this slab is hidden.
Slice Plane Creation
The slice plane is defined interactively using a knife-style tool.
Workflow:
User activates slice tool
User draws a line across the viewport
The system derives a vertical slicing plane from that line
The slice plane:
passes through the drawn line
extends infinitely
is not restricted to axis alignment
Slice Thickness
Users define slice thickness.
Example:
10m
20m
50m
The slice thickness determines the slab of geometry rendered.
Slice Movement
Users can move the slice forward/backward orthogonal to its plane.
Controls:
Move Slice Forward
Move Slice Back
This allows the user to scan through the scene.
Rendering Implementation
The slice must be implemented using two clipping planes.
Given a slice plane:
Plane(normal, distance)
Create:
Plane1 = normal, distance + width/2
Plane2 = -normal, -(distance - width/2)
These form a bounded slab.
Objects outside the slab are clipped.
Public API
enableSliceMode()
disableSliceMode()
setSlicePlane(normal: Vector3, distance: number)
setSliceWidth(width: number)
moveSlice(delta: number)
getSlicePlane()
getSliceWidth()
Interaction Helpers
The slice tool must include utilities for deriving a slicing plane from a drawn line.
Suggested helper:
createSlicePlaneFromScreenLine(startScreen, endScreen)
Steps:
Unproject screen coordinates into world space
Generate a vertical plane passing through that line
Compute plane normal orthogonal to the line
Visual Aids
The slice tool should render:
slice plane indicator
optional translucent slab preview
Acceptance Criteria
User can draw a slicing line on screen.
A slice plane is generated from the line.
Only geometry within the slice thickness is rendered.
Slice plane can be translated orthogonally through the scene.
Slice works on all Baselode geometry types.
Integration Requirements
Both helpers must integrate with the Baselode viewer architecture.
They must:
work with Three.js renderer
support clipping of all Baselode geometry types
coexist with other viewer tools
Only one of the following may be active at once:
Section Mode
Slice Mode
Activating one disables the other.
Expected File Structure
baselode-js/src/viewer/helpers/
SectionHelper.ts
SliceHelper.ts
Summary
The implementation introduces two core geological interpretation tools:
Tool
Plane Orientation
Visible Geometry
Section
Axis aligned
Behind plane
Slice
Arbitrary plane
Within slab
These tools allow Baselode to replicate the standard cross-section and slicing workflows used in professional geological modelling software.
