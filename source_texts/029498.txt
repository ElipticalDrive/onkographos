Summary
Make ARC's cooked sparse Mesh Distance Fields resident and traceable on the GPU as the detailed world-space fallback behind screen traces.
Roadmap metadata
Project Space: Rendering
Track: Dynamic Lighting / GI / Reflections
Milestone: DL3.3
Horizon: Later
Priority: P1
Size: XL
Type: feature
Parent Epic: [Epic] Dynamic Lighting, Global Illumination & Reflections #905
Scope
Stream/publish sparse DF bricks into bounded GPU atlases/buffers
Build instance transforms/bounds and geometry-generation lookup
Implement GPU sphere tracing with signed/two-sided modes
Return standard lighting_trace_result-equivalent hit/source data
Handle missing bricks through explicit fallback rather than false hits
Prioritize nearby/relevant DF residency under budget
Add mesh-DF debug visualization and trace statistics
Acceptance criteria
GPU rays can hit resident per-mesh distance fields deterministically
Missing detail degrades to the next trace tier
Runtime residency remains inside configured Lighting Scene budgets
CPU reference tracer remains useful for validation
Stale generations cannot be sampled after replacement
Dependencies
DL3.1
Formalize platform and GPU capability system #404/Add device profiles and scalability tiers #405 capability and budget policy
