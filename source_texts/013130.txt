Summary
Implementation of a standardized GPU utility library (e.g., engine_utils.glsl) that is automatically injected into user-defined compute shaders. This toolkit provides highly optimized mathematical building blocks for voxel traversal, intersection testing, and bit-level data manipulation, ensuring that performance-critical raytracing logic is standardized and efficient across the entire application.
Functional Requirements
Optimized DDA Traversal: The system shall provide a pre-implemented Digital Differential Analyzer (DDA) state machine for grid traversal, handling step logic, axis masking, and coordinate updates to minimize per-voxel traversal costs.
Slab-Method Intersection Testing: The system shall include robust Ray-AABB (Axis-Aligned Bounding Box) intersection functions based on the "slab method" to allow quick culling of chunks or bounding volumes.
Robust Ray Initialization: The system shall provide utility functions for safe ray creation that automatically handle edge cases such as division-by-zero for axis-parallel rays and floating-point epsilon offsets to prevent self-intersection artifacts ("shadow acne").
Data Unpacking & Color Conversion: The system shall include optimized bit-manipulation functions to unpack compressed voxel data (e.g., converting a single uint into a vec4 RGBA color) at the shader level.
Stochastic Noise Utilities: The system shall provide high-performance, low-instruction noise functions (e.g., Gold Noise) to support jittering, sampling, and soft-shadow calculations within the raytracing pipeline.
Acceptance Criteria
Verified that compute shaders can call utility functions without explicit local definitions or manual file includes.
Verified that the DDA implementation correctly traverses a 3D grid, hitting every voxel intersected by a test ray.
Verified that Ray-AABB tests correctly identify intersections at extreme angles and handle parallel-axis rays without crashing or returning NaN.
Verified that unpacked voxel colors match the original input data bit-for-bit.
Verified that using the provided noise functions results in a uniform distribution suitable for Monte Carlo sampling.
