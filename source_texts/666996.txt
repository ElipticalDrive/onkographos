Motivation
Introduce a single froxel-based volumetric fog implementation inside the existing Atmosphere orchestrator so volumetrics, shafts and scattering share the same composite path.
Keep legacy screen-space/texture fog (r_fogvol) as a runtime fallback while adding a gated, safe-to-disable froxel path controlled by new alias CVARs.
Reuse existing engine resources (shadow sampling, frame UBO, depth sampling and postprocess composite) and avoid duplicated godray shafts when froxel mode is active.
Description
Added froxel pipeline stages inside Atmosphere in Quake/gl_rmain.c: Atmosphere_Froxel_InitResources, Atmosphere_Froxel_BuildVolume, Atmosphere_Froxel_LightIntegrate, Atmosphere_Froxel_TemporalResolve, and updated R_Atmosphere_Render to choose froxel vs legacy R_FogVol_Render at runtime.
New compute shaders were added under Quake/shaders/: atmos_froxel_build.comp, atmos_froxel_integrate.comp, and atmos_froxel_temporal.comp, implementing medium evaluation, single-scattering + shadow participation (reusing shadow_sample.glsl), and history clamp/blend reprojection respectively.
Framebuffer and texture resources expanded: new 3D textures for froxel scatter (RGBA16F), transmittance (R16F), history ping-pong, and resolved buffers were added to framebufs.atmos_froxel and are created/cleaned in GL_CreateFrameBuffers / GL_DeleteFrameBuffers.
Postprocess composite (Quake/shaders/postprocess.frag) updated to accept AtmosFroxelScatter and AtmosFroxelTransmittance (bindings 10/11) and new uniforms (locations 28/29) so the composite samples froxel data per-pixel and computes final = color * T + scatter when froxel is enabled.
CVARs and registration: new alias/gate CVARs were added and registered (r_atmos_froxel, r_atmos_froxel_res, r_atmos_zslices, r_atmos_historyweight) while existing fog/godray CVARs remain authoritative for medium and shaft parameters.
Behaviour decisions: when froxel path is active the legacy radial godray contribution is disabled to prevent duplicate shafts (anisotropic phase in froxel integration becomes authoritative), temporal reprojection uses per-frame Halton jitter, history clamp (3x3x3 neighborhood) and a history weight CVAR.
Debug/logging: r_atmos_log prints froxel dimensions and which stages ran, and compute passes are wrapped with group markers like Atmosphere: Froxel Build, Atmosphere: Froxel LightIntegrate, Atmosphere: Froxel Temporal.
Testing
Source-level verification: repository grep/inspection confirmed new symbols, bindings and shader files are present and postprocess.frag is updated to sample froxel textures successfully (static source checks passed).
Build attempt: ran cmake -S . -B build && cmake --build build -j2 to validate integration, but configure/build failed due to missing SDL2 CMake package in this environment (configure error from CMake: SDL2 not found), so shaders were not compiled by the full build.
Sanity checks: framebuffer creation/cleanup paths were exercised in code edits (resource creation in GL_CreateFrameBuffers and deletion in GL_DeleteFrameBuffers) and R_Atmosphere_Render logic was exercised via static analysis; no runtime validation was possible here due to the missing build dependencies.
