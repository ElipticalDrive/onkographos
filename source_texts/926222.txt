Goals
Load color lookup tables as renderer-independent numeric samples without adding dependencies. This branch starts directly from master and is independent of the other format-loader PRs.
Changes
Add metadata-only CubeLUTLoader, ThreeDLLUTLoader and ImageLUTLoader with explicit parser subpaths.
Decode single 1D/3D cube tables, documented grid-first 3dl files with explicit output bit depth, and explicitly tiled opaque 8-bit PNG LUTs.
Normalize table storage to RGB samples with red input varying fastest; retain domains, authored titles, float64 nonuniform input knots, original grid values and source output bit depth.
Validate PNG precision and layout before decoding, reject unsupported sample precision, and bound image LUT dimensions.
Scan quoted titles and comments in linear time.
Reuse existing image APIs with color-space conversion and premultiplication disabled; close temporary bitmaps.
Add direct decoded-pixel conversion utilities, module/website documentation, release notes and deterministic boundary/entrypoint tests.
Register all new production paths under existing coverage gates without changing thresholds.
Reject PNG metadata capable of platform color/orientation transformations before image decoding.
Add a consolidated website format guide with feature cards, format explanations, public usage examples, output contracts, runtime requirements and explicit support limits.
Keep documentation discoverable through module navigation; remove redundant package-root format guides and add SPDX/contributor headers to new source. Upstream THREE.js notices apply only to the directly adapted USDC decoder.
Initial scope
Combined shaper/3D cube files, vendor 3dl headers, implicit bit-depth/layout guessing and nonopaque/high-bit-depth LUT images are unsupported. No interpolation, tone mapping or GPU objects are created.
Validation
yarn.lock unchanged; no new dependencies.
yarn lint fix, yarn test-audit and yarn build pass.
Focused Chromium tests: 29 passed, including PNG midtone preservation.
Final documentation/attribution revision is being verified in current-head CI; prior implementation revisions passed required checks and coverage.
Note
Low Risk
Additive loaders and utilities with no modifications to existing image loading behavior or external dependencies.
Overview
Adds dependency-free color lookup table (LUT) decoding to @loaders.gl/images supporting .cube, .3dl, and explicitly tiled 8-bit PNG files. All loaders normalize source tables to a shared, renderer-independent ColorLUT structure with interleaved Float32 RGB samples in red-fastest order.
Introduces CubeLUTLoader for 1D and 3D text tables, ThreeDLLUTLoader for grid-first tables with explicit output bit depth, and ImageLUTLoader (along with synchronous parseImageLUT) for blue-slice tiled PNG layouts. The image loader inspects PNG chunks and layout constraints prior to decode to reject unsupported transforms, metadata, or transparency.
Exposes lightweight metadata loaders at the package root alongside parser-bearing implementations via dedicated subpaths (./cube-lut-loader, ./3dl-lut-loader, ./image-lut-loader, and ./color-lut), complete with documentation guides and test coverage.
