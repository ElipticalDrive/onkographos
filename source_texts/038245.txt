This release contains the full implementation of the interactive Python tool described in the paper "Visualizing Vector Fields on Seifert Surfaces: A Topological Art Generator" by Carys Garvey. The tool allows users to: Generate Seifert surfaces from classical knots using parametrized equations. Define and push forward vector fields in intrinsic coordinates. Compute and visualize approximate surface divergence. Interactively explore knot and field types, rendering styles, and colormaps. Export high-resolution divergence plots for artistic or mathematical use. This version supports multiple built-in knots and field types, and includes documentation for extension. For academic citation, please use the Zenodo DOI minted with this release.
