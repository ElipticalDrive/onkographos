Completes the codec-layer constexpr work deferred by PR #814 (parent
issue #745). After this PR, zfpblock::compress() / decompress() are
callable in constant-evaluated contexts -- enabling compile-time
generation of compressed coefficient tables for DSP / ML pipelines.

Codec changes (include/sw/universal/number/zfpblock/zfp_codec.hpp):

* zfp_ctzll: replaced __builtin_ctzll / _BitScanForward64 with
  C++20 std::countr_zero (constexpr).
* zfp_bitstream: added a const-buffer reader constructor that
  eliminates the const_cast<uint8_t*>(buffer) in decode_block --
  forbidden in constant evaluation when the storage originated as
  const-qualified. Reader and writer modes share the same class;
  read ops use the const pointer, write ops use the mutable one.
* fwd_cast / inv_cast: added std::is_constant_evaluated() dispatch.
  Runtime path keeps std::frexp / std::ldexp / std::memset. The
  constexpr branch uses two new templated helpers:
    - cx_ldexp<Real>(x, exp): power-of-2 multiplication loop,
      bit-identical to std::ldexp within the codec's exponent range.
    - cx_frexp_exp<Real>(v): returns the exponent std::frexp would
      write, via sw::bit_cast extraction of the IEEE 754 fields.
      Handles both normal and subnormal binary32 / binary64.
* decode_bitplanes: replaced std::memset(ublock, 0, ...) with an
  explicit zero loop on the constexpr branch.
* All remaining helpers (int2uint / uint2int, fwd_lift / inv_lift,
  fwd_xform / inv_xform, encode_bitplanes / decode_bitplanes,
  encode_block / decode_block) annotated constexpr -- mechanical.
* Local arrays inside encode_block / decode_block now value-init
  (Int iblock[N]{}) so they read constexpr-safe before the codec
  fully writes them.

Container changes (zfpblock_impl.hpp):

* compress / decompress and the four mode convenience wrappers
  marked constexpr. Updated the deferral comment that previously
  pointed at this issue.

Test additions (static/block/zfpblock/api/constexpr.cpp):

* All-zero block constexpr roundtrip: encoder hits the zero-flag
  fast path; decoder restores zeros. Exercises bitstream write_bit /
  read_bit and the constexpr-branch memset replacement.
* Power-of-two block constexpr roundtrip: full pipeline
  (fwd_cast + cx_frexp_exp + cx_ldexp + lifting + bitplane) at
  compile time, with a tolerance-based static_assert on the
  decompressed values.
* Negabinary identity static_asserts at both int32 and int64.

Verified on gcc and clang: all 13 zfpblock targets pass; the api.cpp
test's compressed byte sequence ([01 f1 1c c5 61 01 ...]) is
byte-identical between compilers and between this change and main.

Completes the array layer constexpr work tracked under issue #745.
Building on the codec promotion in PR #830 (#815), zfparray<Real, Dim>
is now usable in constant-evaluated contexts -- enabling compile-time
generation of compressed scientific-data tables.

Container changes (zfparray_impl.hpp):

* All member functions annotated constexpr.  No std::is_constant_evaluated
  branching is required: every helper the container calls (encode_block,
  decode_block, zfp_bitstream, ...) is already constexpr after #815.
* _store (the std::vector<uint8_t> compressed buffer) is now mutable.
  This eliminates every const_cast<zfparray*>(this) in the const lazy-
  cache-load methods (operator(), decompress, clear_cache, load_block).
  The cache is an internal implementation detail; const methods are
  entitled to flush it.  flush() and write_back_cache() become const
  members.  Strictly safer and a const-correctness improvement.
* In-class initializers for _n, _rate, _cache, _cached_block, _dirty
  let the default constructor default to `= default` and drop the
  std::memset(_cache, 0, sizeof(_cache)) call that previously needed
  it.  All other constructors drop their memsets too.
* std::memset / std::memcpy replaced with element-wise loops throughout
  (cache copy, store copy, padded-block init).  Mechanical and reads
  identically at runtime; constexpr-safe.

Test additions (static/block/zfpblock/array/array_constexpr.cpp, NEW):

* Default-construct accessors: size, num_blocks, compressed_bytes,
  compression_ratio all constexpr-deterministic at zero state.
* Sized-rate construction: zfparray(8, 16.0) sets up 2 blocks of 4
  with 8 bytes per block -- verified via static_assert.
* Construct-from-source roundtrip: zfparray(8, 32.0, src) + decompress
  recovers powers of two within 2^-20 relative tolerance.  Exercises
  the full per-block codec at compile time through the container.
* set / flush / get roundtrip: write through the cache, flush, read
  back through the (clean) cache.
* Cross-block access: set in block 0, set in block 1 (forces eviction),
  set in block 0 again (forces re-load).  Verifies load_block /
  write_back_cache / flush at constant evaluation.

Test target naming: chose array_constexpr.cpp to match the existing
array_* prefix convention (collides with api/constexpr.cpp otherwise --
compile_all derives target name from the source basename).

Verified on gcc and clang: all 6 zfpblock array + constexpr targets
pass; no regressions in the runtime array tests.
