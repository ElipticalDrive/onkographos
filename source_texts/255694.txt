Summary
Adds a new .voxel.json / .voxel.bin file format for converting Gaussian splat scenes into sparse voxel octrees, primarily for collision detection use cases.
GPU-accelerated voxelization using a WebGPU compute shader with shared-memory tiling and double-buffered CPU/GPU pipelining
Sparse octree output in Laine-Karras node format with Morton-coded spatial indexing
Post-processing filter that removes isolated voxels and fills isolated holes via 6-connected neighbor analysis
Round-trip support: voxel files can be read back and converted to PLY/CSV for visualization and debugging
Pipeline
Compute world-space AABBs for all Gaussians from position, rotation, and scale
Build a BVH over Gaussian AABBs for efficient spatial queries
Tile the scene into 4×4×4 voxel blocks, batched in 16³ regions
For each batch, query the BVH for overlapping Gaussians and dispatch a GPU compute shader that evaluates Gaussian density per voxel using extinction-based (Beer-Lambert) opacity accumulation
Filter: remove isolated solid voxels, fill isolated empty voxels (cross-block aware)
Build a sparse octree bottom-up from Morton-sorted leaf blocks, collapsing fully-solid subtrees
Serialize to .voxel.json (metadata) + .voxel.bin (Uint32 nodes + leaf masks)
CLI
```
# Generate voxel collision data from a splat file
splat-transform input.ply output.voxel.json

# Custom resolution (10cm voxels) and opacity threshold
splat-transform -R 0.1 -A 0.3 input.ply output.voxel.json

# Convert voxel data back to PLY for visualization
splat-transform scene.voxel.json scene-voxels.ply
```
New global options:
-R, --voxel-resolution <n> — Voxel size in world units (default: 0.05)
-A, --opacity-cutoff <n> — Opacity threshold for solid voxels (default: 0.5)
Library API
New exports: readVoxel, writeVoxel, WriteVoxelOptions, VoxelMetadata
Voxel internals also exported for advanced use: computeGaussianExtents, GaussianBVH, GpuVoxelization, buildSparseOctree, alignGridBounds, BlockAccumulator
