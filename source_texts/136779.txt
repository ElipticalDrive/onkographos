1.7. Clipping - developer.openinventor.com
While clip planes can produce the desired visual result, they have some disadvantages for volume visualization. Because the clipping occurs in the rendering pipeline on the GPU, VolumeViz has to load data in system memory and in GPU memory that potentially is not needed for rendering.
