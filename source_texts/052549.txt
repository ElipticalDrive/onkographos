I tried published release binaries and found that "Voxel Cone Tracing" technique does not work: rendered image (see screenshot below) significantly differs from the image demonstrated on the main page of repository. Voxeles debug view shows screen filled with gradient, so it seems like no voxels were generated. In Console.log file I found compilation error for voxelizeFragment.glsl , which seems to be root cause of this issue:
```
[22:08:28] [info] Compiling "Assets/Shaders/Voxelize/voxelizeFragment.glsl" !
[22:08:28] [error] 0(38) : error C7636: format layout qualifier not allowed on image parameter
[22:08:28] [error] On glAttachShader: GL_INVALID_VALUE (A numeric argument is out of range. The offending command is ignored and has no other side effect than to set the error flag.)
```
System configuration:
Windows 11 Pro 22H2 (22621.1344)
GPU: NVidia GeForce RTX 2070 Super, Driver 31.0.15.3118

I found that error is related to the function signature void ImageAtomicAverageRGBA8(layout(r32ui) coherent volatile uimage3D voxels, ivec3 coord, vec3 nextVec3) while the function call is actually commented in the fragment shader function, i.e. not used. Removal of the unused function ImageAtomicAverageRGBA8 code from shader source fixes compilation problem and Voxel Cone Tracing starts working correctly.
