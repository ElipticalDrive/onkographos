Closes #60.
Wave B for Lane 11 / world-outdoor. Three deliverables, all behind the FROZEN public header (Terrain.h) by adding to the internal headers.
Summary
1. Heightmap raymarcher SIMD path (Raymarch_internal.h)
8-wide AVX2 / 4-wide NEON column-batch kernels on top of lane 03's f32x8 / f32x4 packs:
simd_sample_bilinear8 / _4 — bilinear height sample per lane using fma8/fma4. u16 corners promoted scalar; bilinear blend is SIMD-wide.
simd_project_y8 — pinhole projection with blend8 for dist<eps divide-by-zero handling and min8/max8 clamping.
simd_step_columns8 / _4 — full per-column step, lane-pure except for the screen_y < horizon decision (resolved via the per-lane active mask).
simd_advance_batch8 / _4 + simd_batch_done8 / _4 — per-step state update + all-lanes-done short-circuit.
The scalar reference kernels (march_ray, step_column, project_y, logstep_size) are preserved; the SIMD path is opt-in for the tile-job inner loop.
2. CDLOD inter-LOD vertex morph (CdlodMesh_internal.h)
CdlodMorph { lod_level, morph_factor } — per-chunk morph state.
coarse_height_at_lod — sample the bilinear-coarsened heightfield at any LOD stride (2^L); kept-vertex texels collapse to identity.
morph_height — standard lerp(fine, coarse, t).
apply_vertex_morph — endpoint-clean (morph=0 → fine, morph=1 → coarse, bitwise).
compute_chunk_morph — band selection + monotone morph factor inside the band, with morph_start_fraction knob.
build_chunk_with_morph — Wave-A topology with morphed Y per vertex.
Watertight invariant preserved at all LOD levels: same texel + same morph state on both chunks → same f32 → bitwise seam match (pinned by tests at morph = 0, 0.5, 1.0).
3. SplineEditor (Spline_internal.h)
insert_control_point(segment_index, t) — de Casteljau split that reproduces the original curve geometry exactly (pinned by 11-sample geometry test across the seam).
move_control_point(...) / translate_control_point(...) — by absolute set or by delta; global or (segment, local) index.
delete_control_point(...) / delete_segment(...) — removes the segment, stitches predecessor's p3 to successor's p0.
set_banking_at_t(t, banking_rad) / banking_at_t(t) — uniform-by-segment parameterization (good enough for the editor preview; Wave C re-parameterizes on arc length).
Lane 18 consumes the data ops; this PR ships the model only — no UI / IPC wiring.
Test plan
32 new tests under tests/unit/world_outdoor_{raymarch_simd,cdlod_morph,spline_editor}.cpp.
[world_outdoor] filter: 62 cases / 17,793 assertions green.
[world_outdoor][simd] filter (parity + done-mask + advance early-out): 7 cases / 169 assertions green.
Build green: cmake --preset mac-release && cmake --build --preset mac-release clean (zstd version warnings only — pre-existing toolchain mismatch).
