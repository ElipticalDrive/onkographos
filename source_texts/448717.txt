Ports the wavefront renderer's volume list (docs/GPU_SCENE_COMMON.md, Windows to Mac 2026-10-27) to Metal.
The whole, still fog / smoke / cloud spheres are listed (SphereData::listedMedium, Uniforms::mediumListOffset/Count, indices as floats in rgbGridData). The trace skips them for the path's own rays; findListedVolume / traverseListedVolume sample the part of each flight inside the first one it enters, up to the nearest surface, with the ordinary medium shaders. A surface inside a volume ends the flight; a camera (or a bounce) inside one is in it from its origin; the camera fog ends where a volume begins; at the emission-only step a collision ends the path.
Shadow rays through a cloud or grid sphere are now blocked by ratio tracking in sphereIntersectionFunction (as for a homogeneous one), so a surface inside smoke is no longer lit as if there were none. The in-shader transmittances of the cloud and grid shaders are removed (they would count twice).
Against the CPU in 8x8 blocks (64 px, 512 spp, p90): fog-around-objects 0.097 -> 0.008, fire-around-ball 0.37 -> 0.009, smoke-around-camera 0.41 -> 0.010. Pack rows: fog-around-objects 1.001/1.002/1.001, fire-around-ball 1.012/0.999/0.990, smoke-around-camera = the CPU per-channel values within 0.3%. cloud-medium-scene and rgb-grid-nebula moved toward pbrt by 1.5%. lamp-in-fog-with-objects stays noisy (heavy-tailed point lamp inside fog: 1.014 / 1.018 against the CPU at 4096 spp); its baseline row has a known note.
Film doctor: the Mac-only warning about a camera inside smoke is removed (it was true only until now); comments and VIDEO_GENERATION.md updated.
Tests: loader test for the list, three scenes added to the block test, baseline rows updated. Full Mac ctest 30/30 (before merging the latest main; loader test, block checks, shader compile and code-size check re-run after).
Not done on Metal: box volumes, clipped/moving/instanced volumes, the height fog, bounded-fog attenuation of an image-sky NEE.
