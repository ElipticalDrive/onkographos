The basis of this project was to create a Voxel Engine using OpenGL, which would be capable of rendering several thousand voxels on-screen, whilst maintaining an acceptable performance. An additional focus was placed upon the implementation of various optimisation techniques and the utilisation of dynamic lighting. \nThis report will highlight the development process and the various methodologies and techniques used in order to achieve the end result. The result is a Voxel Engine that is capable of generating and rendering large procedurally generated, and dynamically lit environments. \n
