Description
Implement the core terrain generation system for a fixed-size 3D map. The world needs to feature diverse height variations like mountains, hills, plains, and rivers to provide tactical positioning and high-ground advantages for players and AI.
Tasks
Define fixed grid dimensions for the map (e.g., 256x256 or 512x512 units).
Implement a noise-based generation system using Godot's FastNoiseLite.
Create distinct height layers using layered noise (Fractal Noise) to shape plains (low, flat), hills (medium, rolling), and mountains (high, steep).
Carve out river pathways using a separate ridge/cellular noise map or a mathematical curve solver that cuts through the heightmap data.
Generate the physical 3D mesh dynamically or apply the heightmap data directly onto a Terrain3D / custom mesh node.
Acceptance Criteria
Running the scene generates a random, organic layout within the predefined, fixed bounds.
Mountains, hills, and plains blend into each other naturally.
Rivers are visibly lower than the surrounding terrain and form walkable or swimmable paths across the map.
Technical Notes
Use FastNoiseLite with NOISE_TYPE_SIMPLEX or NOISE_TYPE_VALUE_FRACTAL for the best landscape results.
Ensure collision shapes (CollisionShape3D or static body mesh data) are baked dynamically after mesh generation so physics work correctly.
