What this does
Implements every item in UPGRADE_PLAN.md, except Persian UI, which was deliberately dropped — the game stays English, and <html lang> now says so instead of claiming fa.
index.html grows from 1,517 to 2,900 lines and stays a single file with no build step, so double-clicking it on file:// still works.
Rendering
Greedy meshing replaces per-block instancing: coplanar faces sharing a tile and AO merge into single quads, so a chunk is 1–2 draw calls instead of one InstancedMesh per block type.
Procedural 256×256 texture atlas (15 tiles drawn from the coordinate hash — no image files), plus per-vertex ambient occlusion and face-direction shading, so terrain needs no lights. Shadow maps are gone; the player gets a blob shadow.
X-ray is a shader uniform with a per-vertex ore flag instead of a material swap — toggling it rebuilds nothing.
Sky dome with gradient + sun/moon glow, stars, drifting clouds.
World
Infinite streaming world: 16×64×16 chunks generated around the player and unloaded behind them, prioritised by distance, with a meshing budget that shrinks when the previous frame was slow.
Terrain generation is pure (coordinate hash instead of a sequential PRNG), so chunks are identical in any order. The same functions are stringified into a Web Worker, with an automatic main-thread fallback for file:// where blob workers are refused.
Water, sea floors, alpine rock belt, snow line, and trees that no longer clip at chunk borders.
Gameplay
Three new powers (❄️ ice breath, 👊 shockwave punch, ⚡ super speed) alongside laser and x-ray.
Block placement with right click + an 8-slot hotbar (never lets you entomb yourself).
300 s day/night cycle, score with a localStorage highscore, 8 sequential missions, block-break particles with camera shake.
Touch controls: virtual stick, drag-to-look, five on-screen buttons.
Advanced minimap: north marker, heading arrow, height shading, unloaded frontier dimmed, ore markers under x-ray.
Persistence
Save v2 stores the block diff (destroyed, placed, frozen) bucketed per chunk, so edits replay correctly even in regions that are not generated yet — plus pose, score and mission progress. Pause-menu settings persist too.
Bugs fixed on the way
Undefined movementX/movementY poisoned yaw/pitch with NaN for the rest of the session.
A 7-block reach could not place blocks at all from the third-person camera.
The boot frame was rendered from the world origin instead of behind the player.

Not verified — please review
The GLSL shaders are not compile-tested. No headless browser can be installed in this environment, so the smoke test stubs the renderer. The logic around them (uniform values, attributes, triangle/vertex counts) is covered, but visual correctness — atlas orientation, fog, sky, x-ray transparency — needs a look in a real browser. If the screen is black or white, the terrain shader (VERT/FRAG in index.html) is the first suspect and the devtools console will name the compile error.
