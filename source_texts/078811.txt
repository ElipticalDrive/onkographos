Summary
The engine's foundations are now solid (normative physics spec, three golden-tested steppers, runtime voxelDim, clipmap zoom), but its anatomy is still invented:
Lobes are coordinate thresholds: region_zone() in wasm/src/region.h says wz > 0.5 → frontal, |wx| > 0.8 → temporal, and §3.1 mirrors that in JS and WGSL.
The cortex is a deformed UV sphere (src/brain-geometry.js), and tracts are procedural Bézier curves (src/geometry/fibers.js).
SynaptiX projection, BCI channel mapping, sonification lobe stats and the coupling model all key off those boxes.
This issue makes anatomy a data input instead of hard-coded constants. That would let the app show real atlases, real tractography, and eventually real recordings (fMRI/EEG source estimates), which is a large step from a stylized toy toward a usable visualization tool. The stylized defaults stay as the built-in, zero-download first-run.
Design
1. Region label volume (spec change first, per CLAUDE.md §3a)
New spec section in docs/tensor-physics.md: §3.1 regionZone becomes a lookup into a voxelDim³ u8 label volume plus a small region table (label → zone, decay, diffusion, flowBias, retention index). The current thresholds become the built-in procedural atlas, generated by a function that reproduces today's boxes exactly, so the golden fixtures don't move.
Implement it in src/physics/tensor-field.js and wasm/src/region.h together. In WGSL, read it from a new storage buffer (array<u32> packing 4 labels per word) created in createTensorStorageBuffers() and rebuilt by setVoxelDim() (CLAUDE.md §3c.2).
The C ABI gets bte_set_region_labels(ptr, len) and a region table. Regenerate the params header with node scripts/gen_wasm_params.mjs.
Add a second golden fixture with a non-box atlas so the lookup path is tested in all three steppers.
2. Atlas & mesh assets (new module src/anatomy/)
src/anatomy/atlas-loader.js loads a parcellation (Desikan-Killiany, AAL3 or Harvard-Oxford as an MNI-space NIfTI) and resamples it to the current voxelDim using mode-filter downsampling, never trilinear on labels.
src/anatomy/cortex-mesh.js loads a decimated pial/inflated surface (fsaverage5, about 10k vertices per hemisphere) from glTF + meshopt compression, with per-vertex region labels as a custom attribute. The renderer's mesh path gets an "anatomical" geometry source alongside the procedural sphere. Existing shaders keep working because they read tensorData by world position.
New dependencies (all small, ESM, framework-free):
nifti-reader-js to parse .nii/.nii.gz
meshoptimizer (meshopt_decoder.module.js) to decode compressed glTF buffers, or a ~150-line minimal glTF reader to avoid a full scene-graph library
fflate for gzip (NIfTI .gz, .trk.gz)
Assets ship as optional downloads in public/anatomy/ with licence notes (fsaverage and the atlases have redistribution terms; document them in docs/anatomy.md).
3. Tractography → fiber affinities
src/anatomy/tract-loader.js parses TrackVis .trk and MRtrix .tck streamlines (both simple binary formats, no library needed), bins them into voxelDim³ × AFFINITY_SLOTS direction/weight slots, and feeds the existing normalizeFiberAffinities() / bte_set_fiber_affinities() path. The procedural tracts become one generator among several.
Also render the streamlines (decimated) through the existing Connectome fiber pipeline.
4. Real data → tensor
A NIfTI 4D time series (BOLD, or EEG/MEG source estimates exported from MNE) becomes a new TensorPlayer source. Resample each volume to voxelDim³, normalize, and play it back through the same path as .npy/.bin.
Use the atlas to map BCI channels to regions (10-20 electrode positions → nearest cortical label) instead of hard-coded lobe lists in src/bci/.
5. Coordinate-system contract
Define one transform from MNI mm to engine world space (BRAIN_RANGE, currently fround(1.6)) in src/anatomy/space.js, and use it everywhere: atlas, mesh, tracts, electrodes. Unit-test the round-trip.
Phasing
Label-volume spec plus the procedural atlas reproducing today's boxes (no visual change, fixtures unchanged).
NIfTI atlas loader and region table UI (pick an atlas; see region names on hover via src/raycast-utils.js).
glTF cortex mesh.
Tractography import.
NIfTI time-series playback.
Acceptance (phase 1)
npm run test:all passes with unchanged baseline fixture hashes, plus a new atlas fixture that passes in JS, C++ and (via npm run test:wgsl) WGSL.
region_zone() thresholds exist in exactly one generator, with no copies left in WGSL, C++ or JS.
setVoxelDim(48|64) resamples the label volume, and the bind groups are rebuilt.
Out of scope
Clinical claims of any kind. docs/SCIENTIFIC_ACCURACY_REPORT.md should say clearly that atlas-driven visuals are illustrative, not diagnostic.
