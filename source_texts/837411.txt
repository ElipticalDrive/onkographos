Context
The stage currently renders text as a 2D affine (zoom + 2D tilt + pan) baked into each glyphon TextArea left/top. The look is a flat 2D plane — rotation about Z only.
Goal
Add true 3D perspective projection to the camera so the text plane can be tilted away from the viewer (pitch about X) and rotated horizontally (yaw about Y), yielding a 3/4 angled stage with glyphs that diminish toward a vanishing point.
Approach (Option A — hand-rolled perspective, no shader)
Compute each glyph/row's world-space 2D point (wx, wy, 0).
Apply a 3x3 rotation matrix combining tilt (Z), pitch (X), yaw (Y) about the canvas center.
Apply perspective divide: screen = focal_distance * p / (p.z + focal_distance) + center.
Scale glyphon's TextArea by focal_distance / (z + focal_distance).
Fields added to CameraBaseline (serde(default) for backward compat)
pitch: f32 — degrees about X (default 12)
yaw: f32 — degrees about Y (default 6)
focal_distance: f32 — perspective focal distance in canvas-space px (default 2000)
