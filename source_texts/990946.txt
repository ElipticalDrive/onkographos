Release
Deploy a separate playable survival edition at /voxel-wild/v2/, preserving the existing creative island, trailer and v1 saves. This is a substantial survival foundation, not full Minecraft feature parity.
Implemented
Seeded, streamed 16×16×64 chunks, negative coordinates, caves, ravines, biome classifications and ore deposits.
35 block types / 73 combined block-item definitions / 32 recipes; wood-to-diamond tools, durability, tier-gated drops, inventory and workbench progression.
Furnace input/fuel/output, timed smelting with saved progress, chests, doors, beds, torches and buckets.
Health, hunger, armor, drowning/fall/lava damage, food, farming, sheep/pigs/night wanderers, combat, death drops and respawn.
Creative catalog and flight; keyboard/mouse/touch; browser-scoped save and world JSON export/import.
Original procedural graphics and synthesized audio; no runtime dependency or external asset download.
Verification
37 Node core tests passed locally; now gated in Pages CI in addition to, not instead of, existing redirect tests.
34 Chromium integration checks passed: mining/pickup, DOM crafting, station gating, smelting, cursor/save conservation, chest splitting/transfers, farming, source contact, food/armor, death/respawn and mobile layout. No unhandled JS or WebGL errors observed.
Browser suite uses exact source in a local document, a Storage fixture and deterministic simulation ticks; some fixtures stage resources. It is not a live-site load test or an unassisted playthrough.
Uploaded core.js, render.js, game.js, ui.js and index.html Git blob hashes match the locally tested files byte-for-byte.
Known gaps
No multiplayer, redstone, other dimensions, villages/trading, enchanting/brewing, full item/mob catalog, flowing fluids or Minecraft protocol/save compatibility. PARITY.md records exact simplifications and the remaining implementation slices. Physical iPhone/Safari and long-session performance certification remain open.
Safety
Original game file unchanged; separate v2 save namespace; imports validate bounds and confirm replacement of an existing same-seed save.
