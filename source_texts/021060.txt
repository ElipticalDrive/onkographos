Project title
Open the Mind : Streaming out-of-core visualisation of high-resolution 3D volumes.
Short description and goals
Whole-brain histology at cellular resolution runs to terabytes, far more than a workstation or browser can hold. Existing tools either show it as 2D slices or load the whole volume into memory before rendering. This project builds a web viewer that shows the whole brain in 3D in an ordinary browser:
three sliders cut it open, along with a corner cutaway that turns to face the camera as the brain rotates;
zooming in sharpens the cut faces from a coarse overview to finer resolution;
rendering runs on the server GPU, and the browser only receives frames;
memory stays fixed whatever the size of the data, because only what the screen needs is ever loaded.
Goals
Build a multi-resolution brick pyramid from a registered 3D brain volume without ever loading it whole.
Render the pyramid on the server GPU through a fixed-size brick cache, with volume rendering, x/y/z cut planes and a camera-facing cutaway.
Stream the frames to a browser page with sliders and orbit, pan and zoom, keeping interaction smooth.
Show that peak GPU and host memory stay flat from the coarsest level to the finest, and measure frame time and latency.

Skills that would help
Python and NumPy: reading large raw volumes in chunks, array slicing and downsampling.
Computer graphics and volume rendering: ray casting, transfer functions, clip planes and camera maths. Interest is enough, no prior experience needed.
Web development: HTML, JavaScript and a small Python web server, for the browser page with sliders and mouse controls and for streaming frames.
Systems and performance: caching, parallel file I/O, and profiling memory and latency.
Data formats: chunked and compressed formats such as OME-Zarr.
GPU programming: PyTorch, CUDA or CuPy. Useful for writing the ray caster and managing the GPU brick cache.
No neuroscience background is needed. Curiosity about big data and 3D graphics matters more than any single skill.
Good first issues
Render one 3D cube.
Add three x/y/z sliders that cut the cube live.
Memory meter [Python, PyTorch]. Log peak GPU and host memory for every frame and show the numbers on the page. This is the proof that memory stays flat.
Scaling and benchmarking with multiple cubes.
