Is it possible to load other formats than NIFTI and DICOM? I have a DICOM image and an overlay generated on the browser side (as a 2d array with 1 channel) and I'd like to load it. It seems I could convert it to DICOM somehow on the browser side and then load to Papaya but I suppose there must be a more efficient way to do it.

There isn't good support for this right now, but I can think of two ways:
Inside src/js/volume there are subdirectories for the formats it currently supports. This isn't exactly plugin-able right now, but it shouldn't be too difficult to add another format there. Just look in header-nifti.js and header-dicom.js for examples and create corresponding functions (e.g., getImageDimensions(), getVoxelDimensions(), etc). Then in header.js look for papaya.volume.Header.HEADER_TYPE_NIFTI and add the new format anywhere that's used.
A different approach: The data you describe sounds very much like your typical DICOM overlay. Papaya doesn't yet support DICOM overlays, but it wouldn't be too difficult to add and then maybe that could be extended to support some kind of "external overlay".
The issue with the first approach is you'd need to fudge some kind of header. The second approach only needs the 1-channel array. It might be a few weeks, but I'll try to add support for the second one.
