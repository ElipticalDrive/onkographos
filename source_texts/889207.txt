Add persistent static instance batches with spatial cells, GPU frustum/distance/occlusion culling, compacted visibility indices and indexed indirect draws for the main camera and sun cascades. Reuse material, depth and shadow pipelines; retain resident vertex buffers with CPU cell culling on compute-free devices.
Includes Rust/C/C++ creation, transform replacement and release APIs, guide examples, bounded-cell unit tests, offscreen GPU/fallback coverage and headless creation of 100,000 instances. Streaming lifetime is per batch; internal culling cells do not expose separate handles. Target cameras and local-light shadow views remain outside this API.
Validation: full supplied check script (format, workspace/wasm/profiling/no-default lint, workspace tests, API docs, book, generated header, native C/C++ tests and leak checks), plus offscreen visibility/indirect-count/occlusion/cutout/shadow tests. No performance benchmark claims.
