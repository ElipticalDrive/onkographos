Parent tracker: #40
Problem and existing work
Our ray reference traverses a bounded grid with per-cell material reads. It is a correctness reference, not a demonstrated production microvoxel solution.
Scope
Prototype skipping empty regions at chunk/block or tree levels, then fine DDA within occupied blocks. Compare a simple hierarchy before committing to a DAG.
Test compact occupancy and separate material lookup, including 4×4×8 bit blocks and reuse of the last fetched block. Account for hierarchy and material memory, not occupancy alone.
Preserve the reference and shared-depth hybrid path. Keep static/dynamic data separable; no ray-only product decision.
Use DeadlockCode's shader and Cubiquity traversal as references, following component selection and provenance requirements.
Completion criteria
Matched hits, materials, depth and boundary semantics against our reference: tied axes, zero direction components, negative coordinates, inside-solid starts, thin walls and edits.
Bounded build/update/residency and Android functional execution.
Compare total costs using the representative comparison issue; document adopt/adapt/reject/defer.
Mapping: M2, ADR-0005/0006; experimental candidate, not a prerequisite for all existing Phase A work.
Delivery and evidence
Reconciled against main fc6212e02009ced613009fece1386c7b5ddff9aa on 2026-09-13. Extend existing systems; reconcile the live board before implementation. This issue assigns no worker and does not replace the completion plan. Technical implementation/functional acceptance precede Phase B cost ranking and sustained thermal measurements.
Preserve authoritative voxel/material/collision semantics, bounded memory and stale-job rejection. Record source SHA, fixture/seed, commands, quality settings and actual device/OS/driver for results; mark unrun gates explicitly. Store durable findings in repository performance docs and update affected ADRs/STATUS/ROADMAP with the implementation delivery. An experiment may close with an evidenced adopt/adapt/reject/defer conclusion; no speedup is assumed.
