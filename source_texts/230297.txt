Description
Adds a distributed ArborX-based ray tracing module for 2D and 3D level-set interfaces.
Reconstructs rank-local interface primitives using marching squares/cubes.
Supports distributed rays without migrating ray ownership between MPI ranks.
Computes first intersections, reflections, and Fresnel-based energy absorption.
Removes rays below a configurable energy threshold.
Paraview outputs for background level set, interface surface, and intersection data with energy and ray direction-
Adds unit tests covering both 2D and 3D reflection behavior.
Follow-up work:
more test cases (e.g. elliptic melt-pool like surface with rays following a Gaussian distribution)
scaling study
add complex refractive index
compute heat source from the intersection points
This PR serves as a start for your thesis @sophierckr.
