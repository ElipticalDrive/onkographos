Description: Julia package for total-variation (TV) denoising and reconstruction on N-dimensional arrays.
Release notes:
```
This release adds group-sparse total variation denoising and periodic boundary support.

### Added

- Overlapping group-sparse anisotropic TV via `GroupSparseTV`:
  - scalar or per-axis group shapes
  - support for 2D images and 3D volumes
  - `group_sum!` and `group_sum_adjoint!` primitives
- Low-memory ADMM/MM group-sparse solver via `GSTVConfig` for `L2 + GroupSparseTV` problems.
- Reusable GSTV workspaces:
  - `GSTVState` for single solves
  - `GSTVBatchState` for sequential batch processing with bounded spatial workspace
- `Periodic` boundary handling for forward gradients and adjoint-consistent divergence.
- Periodic-boundary support for ROF and PDHG solvers, including batched CPU and CUDA paths.
- CUDA acceleration for periodic operators and overlapping group-sum primitives.

### Documentation

- New guide covering the group-sparse TV model, solver configuration, convergence, and state reuse.
- Updated API reference with `Periodic`, `GroupSparseTV`, `GSTVConfig`, and GSTV state types.
- Expanded batch and CUDA guidance for periodic and group-sparse solves.
- Added group-sparse TV references and a README example.

### Validation

- Expanded tests covering:
  - periodic gradient/divergence adjointness
  - periodic ROF and PDHG solves
  - overlapping group sums in 2D and 3D
  - GSTV solver behavior, state reuse, and batch APIs
  - CUDA periodic operators, group sums, and GSTV solves when CUDA is available

### Compatibility

- Julia `1.11+`.
- CUDA support remains optional through `TotalVariationImageFilteringCUDAExt`.
- CUDA compatibility includes versions `5` and `6`.

### Notes

- `GSTVConfig` requires `L2Fidelity`, `GroupSparseTV`, and `NoConstraint()`.
- `ROFConfig` and `PDHGConfig` do not support `GroupSparseTV`; use `GSTVConfig`.
- GSTV batch solves process final-axis items sequentially through a contiguous spatial workspace.
```
