Found while porting batch B109 (PR #303). Upstream files at commit d29e7758ae26.
1. IntrRay2Arc2.h / IntrSegment2Arc2.h — solid-disk clipping feeds off-circle points into Arc2::Contains (result-corrupting). These queries reuse the ray/segment-vs-circle machinery, which clips against the solid disk: with the ray origin (or a segment endpoint) inside the disk, the clipped "intersection point" is that origin/endpoint itself. Arc2::Contains's one-argument form assumes its input lies on the circle, so the query reports an arc hit at a point that is not on the arc at all. Fixed in the port by intersecting with the circular curve (line-circle roots filtered by t >= 0 / |t| <= extent) — the same technique upstream itself uses in its SegmentMesh2 queries.
2. IntrSegment3Ellipsoid3.h TIQuery — a segment fully inside the ellipsoid reports no intersection, contradicting the FI query in the same header. Same shape as the IntrSegment3Sphere3.h defect reported in #203. Fixed the same way (qm <= 0 || qp <= 0 tested first).
3. IntrLine3Cone3.h::CaseC2NotZeroDiscrZero — vertex test uses only the U-component (result-corrupting for truncated cones). The "line passes through the cone vertex" test t*UdU + UdPmV == 0 is only the axis component of the full condition (P - V) + t*U = 0, so a tangency at a point X != V takes the vertex branch and clamps with height 0 instead of X's height — a truncated cone can reject a tangent point that lies inside its height range. Fixed in the port with the full componentwise test; dedicated regression test.
4. IntrLine3Cone3.h::Result::Convert member templates cannot compile — QFNumber has no conversion to Real; dead code as shipped. Ported as standalone conversion functions.
5-9 (preserved, doc/cosmetic). Duplicated parameter[0] = 0 assignment in IntrSegment2Arc2.h; SetRayNegative's -1 // +infinity comment; stale a0/a1/-a1/2/a3*e comments in IntrSegment3Ellipsoid3.h; IntrPlane3Cylinder3.h Result docs referring to a nonexistent type = NONE and "all zero members" for value-initialized Line3/Ellipse3; discarded FromCoefficients status in GetEllipseOfIntersection.
