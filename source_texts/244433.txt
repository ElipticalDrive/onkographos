This PR implements the "System Attractor" experiment, a "Moonshot" combining Chaos Theory, System Monitoring, and Audio Synthesis.
Features:
Massive Scale Visualization: Renders 500,000 particles using macroquad's draw_mesh with a custom point shader and batching, overcoming immediate mode limitations.
Chaos Metrics: Calculates the Finite Time Lyapunov Exponent (FTLE) in real-time to quantify chaos.
System-Driven Chaos: Maps the host machine's CPU usage to the Prandtl number ($\sigma$) and RAM usage to the Rayleigh number ($\rho$), making the attractor's shape responsive to system load.
Audio Sonification: synthesizing sound based on the attractor's state (Z-axis controls pitch, Velocity controls volume). This is gated behind the audio feature to ensure compilation in environments without ALSA.
Technical Details:
Rendering: Uses gl_use_material with PrimitiveType::Points and a custom GLSL shader.
Simulation: Parallelized using rayon for high performance.
Audio: Thread-safe communication using ringbuf between the simulation and audio callback.
Testing: Includes a test suite verifying the positive Lyapunov exponent of the Lorenz system (after a warm-up phase).
Fixes:
Addressed miniquad 0.4 API changes (BlendFactor::Value, Vertex normal field).
