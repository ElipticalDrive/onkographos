The Khronos ANARI™ (Analytic Rendering Interface) Working Group is excited to share developments as we approach SIGGRAPH 2025, including a first look at ANARI 1.1 updates. With ANARI 1.1 features planned and a growing ecosystem of tools and implementations, the industry's first cross-platform 3D rendering engine API continues to evolve to meet the demands of modern scientific visualization and rendering applications.
ANARI 1.1: Expanding Capabilities with New Features
The ANARI Working Group has just voted on a feature freeze for ANARI 1.1, allowing us to confidently preview the new capabilities that will be introduced in the specification. Building on the solid foundation of ANARI 1.0, which launched in August 2023, version 1.1 introduces substantial enhancements that expand the API's flexibility and power.
New Geometry and Scene Structure Additions
Uniform and Face-Varying Geometry Attributes: ANARI 1.1 introduces more sophisticated attribute handling, enabling both uniform attributes that apply to entire geometries and face-varying attributes that provide per-face variation. This enhancement gives developers greater control over visual appearance and enables more detailed surface representations.
A simple cube scene with face varying colors, as rendered in USDView using VisRTX.
New Isosurface Geometry Type: The new 'isosurface' geometry subtype (KHR_GEOMETRY_ISOSURFACE) enables direct rendering of implicit surfaces defined by constant values within spatial fields. This is particularly valuable for scientific visualization applications that need to visualize specific threshold values within volumetric data, and do so without the memory overhead of pre-computing surfaces explicitly.
Multiple implicit isosurface geometries combined with the original volume rendered using the Visionaray ANARI renderer. Data comes from the SILCC project as an adaptive mesh refinement (AMR) spatial field, rendered directly using a custom ANARI spatial field extension to represent the volume data directly.
Citation: Walch, S., “The SILCC (SImulating the LifeCycle of molecular Clouds) project - I. Chemical evolution of the supernova-driven ISM”, Monthly Notices of the Royal Astronomical Society, vol. 454, no. 1, OUP, pp. 238–268, 2015. doi:10.1093/mnras/stv1975.
Uniform Instance Attributes: Applications can now set uniform attributes that apply to all objects within an instance, streamlining attribute management for complex scenes.
New Spatial Field Additions
ANARI 1.1 significantly expands spatial field capabilities with new subtypes:
Unstructured Spatial Fields (KHR_SPATIAL_FIELD_UNSTRUCTURED): Supporting complex, irregular grid structures commonly used in computational fluid dynamics and finite element analysis.
NanoVDB Spatial Fields (KHR_SPATIAL_FIELD_NANOVDB): Native support for ASWF's NanoVDB open standard format, enabling efficient handling of sparse volumetric data
The OpenVDB Dragon asset, rendered as NanoVDB in TSD using VisRTX.
Cubic Filtering: The KHR_SPATIAL_FIELD_STRUCTURED_REGULAR_CUBIC extension adds high-quality cubic interpolation for structured regular spatial fields, providing smoother reconstructions of volumetric data.
Performance and Scalability Improvements
Instance Transform Arrays: The KHR_INSTANCE_TRANSFORM_ARRAY extension enables applications to efficiently render the same geometry multiple times with different transformations using arrays, dramatically improving performance for scenes with many similar objects.
Array instancing of 1000000 cubes, displayed in USDView using VisRTX.
Data Parallel MPI Support: The KHR_DATA_PARALLEL_MPI extension enables true distributed (i.e., data parallel) rendering across multiple nodes using MPI, crucial for high-performance computing environments dealing with massive datasets. This is also essential for doing in-situ visualization of simulations while they run, saving the I/O + storage overhead incurred by post-hoc visualization setups.
Rendering Enhancements
Official Denoising Support: The KHR_RENDERER_DENOISING extension provides standardized access to denoising capabilities, enhancing image quality in ray-traced rendering scenarios.
"A Beautiful Game" scene from the glTF-Sample-Assets repository, rendered with the Barney ANARI renderer. The left shows the noisy image, and the right using the same image but with denoising enabled.
Better Visibility Controls: New parameters for individual volume and surface visibility provide developers with fine-grained control over which elements are rendered in complex scenes.
Device Instance Initializers: This feature enables implementations to specify which parameters are not changeable after the device is created by the application, allowing them to optimize for specific hardware or use cases during initialization.
Growing the Ecosystem: The ANARI Capability Analysis Tool
Beyond specification enhancements, the ANARI ecosystem continues to expand with new tools. The ANARI Capability Analysis Tool (CAT), developed by Kitware as part of the ANARI SDK helps developers understand the capabilities of different ANARI implementations and optimize their applications accordingly.
The recent integration of ANARI into VisIt, the open-source scientific visualization tool from Lawrence Livermore National Laboratory, demonstrates the specification's real-world impact. This collaboration, led by NVIDIA's Kevin Griffin and LLNL developers, shows how ANARI enables applications to access state-of-the-art rendering capabilities without maintaining multiple custom rendering backends.

Increasing Impact of ANARI
Since the launch of ANARI 1.0 in 2023, we've seen remarkable adoption across the scientific visualization community. Major applications including VMD, VTK/ParaView, and VisIt have integrated ANARI support, while various implementations (OSPRay, VisRTX, Barney, Visionaray, Cycles, etc.) provide access to cutting-edge rendering engines across diverse hardware platforms.
The upcoming ANARI 1.1 specification represents a significant step forward in making advanced 3D rendering accessible to diverse domain experts who are not low-level graphics rendering experts. By providing a high-level, vendor-neutral API, ANARI continues to lower the barriers to accessing state-of-the-art rendering techniques, including ray tracing and global illumination.
As we finalize ANARI 1.1, we're excited about the new possibilities these features will unlock for developers and researchers. The combination of enhanced geometry support, expanded spatial field capabilities, improved performance features, and quality enhancements positions ANARI to meet the evolving needs of scientific visualization, professional visualization, visual effects, and engineering CAD applications.
Get Involved

Specification feedback: file issues in the KhronosGroup/ANARI-Docs GitHub project
SDK feedback: file issues in the KhronosGroup/ANARI-SDK GitHub project
Join the Working Group: become a Khronos member and participate directly in ANARI development.
