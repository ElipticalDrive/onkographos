Phase 1, Task 1 of 6: Hash Map Edge Lookup
Estimated Effort: 2 hours
Risk Level: Low
Status: Ready for implementation
Objective
Implement EdgeMap class to eliminate O(n²) edge lookup bottleneck in adjacency building.
Description
The current _build_elem2edge() and _build_edge2elem() methods iterate through all edges for every lookup, resulting in O(n²) time complexity on large meshes. This task introduces an explicit hash-based edge mapping.
Implementation Details
Create src/chilmesh/mesh_topology.py
```
class EdgeMap:
    def __init__(self):
        self._map: Dict[Tuple[int, int], int] = {}
        self._next_id: int = 0
    
    def add_edge(self, v1: int, v2: int) -> int:
        """Add edge (v1, v2) and return its ID. Maintains canonical form (min, max)."""
        
    def find_edge(self, v1: int, v2: int) -> int | None:
        """Find edge ID for (v1, v2), or None if not found."""
        
    def remove_edge(self, v1: int, v2: int) -> bool:
        """Remove edge, return True if existed."""
        
    def __len__(self) -> int:
        """Total number of edges."""
        
    def to_array(self) -> np.ndarray:
        """Convert to Edge2Vert format: ndarray[n_edges, 2]."""
```
Validation Criteria
Edges stored in canonical form (v1 < v2)
O(1) amortized add, find, remove operations
to_array() returns properly sorted edges
Unit tests for all edge cases (empty, duplicates, etc.)
Deliverables
src/chilmesh/mesh_topology.py with EdgeMap class
Unit tests in tests/test_edge_map.py
Docstrings with type hints
