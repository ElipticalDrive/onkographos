Context
The current heightmap pipeline takes the Azgaard source (1920×1006, u8) and upscales it bilinearly to 2048×1024. At ×100 in-game, each texel covers ~100 world units. The hillshading shader (Sobel gradient) operates on this low-resolution data, producing shadows that are too macro-scale to convey local relief. The terrain looks flat despite having continental-scale elevation data.
Reference screenshot: coastal zone with trees but no visible terrain relief.
Objective
Generate an enriched heightmap at ×4 resolution (~8192×4096) with procedural FBM detail baked in, producing a single source of truth for:
Rendering: hillshading shader reads richer gradient data → visible hills, valleys, cliffs
Tagging: hex cells are tagged with altitude band and slope class for gameplay (resource placement, building restrictions, pathfinding cost)
UI: per-cell altitude display (meters above sea level)
Design Decisions
Pipeline
Source Azgaard heightmap (u8, ~1920×1006)
Bilinear interpolation to target resolution (f32, 0.0–1.0)
Meso FBM (4 octaves, rotated): hills and valleys, ~2–8 km wavelength, ±15–30m amplitude
Micro FBM (2 octaves, rotated): surface texture, ~500m wavelength, ±5–8m amplitude
Altitude-dependent amplitude: coast = minimal noise (15%), mountains = full noise (100%), smooth ramp via smoothstep
Clamp to [0.001, 1.0] — land never pushed below sea level
Quantize to u16 (R16Unorm) — 0.04m precision over 2560m range
Format
Output: Vec<u16>, R16Unorm texture
Resolution: 8192 × (8192 × source_aspect) ≈ 8192 × 4288
Memory: ~70 MB uncompressed, ~15–20 MB zstd-compressed for transfer
Shader impact: textureSample returns 0.0–1.0 identically to R8 → shader reads are transparent

Tagging is based on the enriched heightmap (option A: deterministic, noise baked in data). The shader may add additional normal perturbation for micro-detail rendering, but this does not affect gameplay tags.
Parameters to tune (via Python visualization script)
meso_frequency: 0.003–0.01 (hill size)
meso_amplitude_max: 0.012–0.025 (hill height in normalized units)
micro_frequency: 0.01–0.02 (surface bump size)
micro_amplitude_max: 0.002–0.005 (surface bump height)
altitude_low_threshold: 0.05 (below = flat coast)
altitude_high_threshold: 0.40 (above = full ruggedness)
altitude_min_factor: 0.10–0.20 (coast still gets some noise)
Tasks
Python visualization script: generate comparison images (before/after enrichment, hillshading simulation) to calibrate FBM parameters
Implement generate_enriched_heightmap in Rust (server-side, game-seed or shared crate)
Update heightmap endpoint to serve u16 data (verify compression is applied)
Client: change texture format from R8Unorm to R16Unorm
Shader: reduce slope_scale (8.0 → 2.0–4.0) and Sobel step (×8 → ×2–4) to match new resolution
Implement hex tagging: altitude band + slope class per cell from enriched heightmap
Expose per-cell altitude in UI (meters above sea level)
Benchmark generation time (target: < 15s for ×4 enrichment on top of existing pipeline)
Dependencies
Existing: generate_global_heightmap, Azgaard heightmap pipeline
Chunk height fix (670 → 675) should be done before or alongside
Overlay resource placement (rocks, minerals) depends on tagging from this issue
Out of scope
Occlusion / line-of-crest rendering (separate issue)
Shader micro-detail normal perturbation (separate issue, can use enriched heightmap as base)
Snow rendering at high altitude (separate, uses altitude band)
Tree density variation by altitude (separate, uses altitude band)
