Goal
The DDS parser can now read volume (3D) textures and 8-bit luminance (L8) textures (#1379). The only vanilla volume texture is textures\effects\noisevolume.dds: L8, 128 x 128 x 128, 8 mip levels. Today no renderer path loads a volume texture. A 2D slot that is given this file still gets a placeholder. So the texture is parsed, but nobody sees it.
This issue makes the texture reach the screen in the right place, and proves it with a visual check.
What must be true afterwards
The renderer can upload a volume texture as a 3D Metal texture with its full mip chain, and a shader can sample it.
A volume that fails to load gets a neutral 3D placeholder. It does not stop the frame.
The texture is bound where the game uses it, and nowhere else.
openskycli can render a volume texture to an image, for example one slice at a time, so it can be checked by eye. Today it prints only text for a volume.
Open question: where does the game use it?
We do not know the consumer yet. Do not guess. Find it from data first:
Look for a reference to the path in meshes (shader property texture slots), in plugin records (for example EFSH effect shaders or image-space records), and in the other assets.
If nothing in the data references it, the game binds it internally, probably for an effect shader term such as animated noise or fog. Then confirm the effect and the shader term from observed behaviour or an open source before you wire it. Flag any uncertainty in the docs page.
Record the finding in docs/formats/dds.md or in the rendering docs page of the effect that uses it.
Acceptance gate
A real-data check shows the volume uploads as a 3D texture with 8 levels, and no placeholder is used for it.
A visual check: a before and after capture of a scene or effect that uses the texture. The capture shows the noise term where the game shows it, and not as a flat or placeholder look. Captures go to the gitignored .logs/ folder, and the PR links the local path. Do not commit them: a rendered frame is game content.
A unit test with a synthetic volume fixture covers the upload and the placeholder path.
The Preview panel shows the volume texture.
