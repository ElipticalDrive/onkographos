Pull request overview
This PR refactors chunk voxel storage to support interchangeable voxel representations by introducing serialization and a chunk-data abstraction, then migrating Chunk/World to use it (with DenseGrid as the default implementation).
Changes:
Add ISerializable and IChunkData interfaces; implement DenseGrid as a concrete chunk-data backend.
Update Chunk, World, and terrain generation to use IChunkData via indirection (unique_ptr/pointers).
Consolidate hashing utilities and update vertex data packing + shader decode to expand texture ID bit width.
