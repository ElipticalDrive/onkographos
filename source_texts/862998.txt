Owner and source contract
The original PxgCudaBroadPhaseSap radix implementation retains 32 blocks across three axes, the source PxgRadixSortDesc histogram (16 digits × 32 blocks), and all eight stable four-bit LSD passes. The native portable and subgroup count shaders still write every original histogram address, including unused partitions, with the unchanged input key/rank and output descriptors.
Runtime cost and scheduling
For an empty source radix partition, all 1024 threads take the same uniform early return after sixteen lanes write the mandatory zero histogram bins. This avoids initializing and synchronizing LDS, 16-bin per-thread count arrays and wave reductions or atomics for empty partitions. In small scenes with fewer than 4096 scalar projections, 31 of 32 blocks per axis are empty on every radix pass. The existing 32×3 launch, source stream batch count, device allocations and inter-pass barriers do not change. No runtime mode switch or CPU sort is added. Hardware GPU profiling remains required to establish wall-clock gain.
Integration evidence
Extend the independent source SAP GPU radix test on both Vulkan and D3D12 to check all 512 final-pass histogram entries per axis, including exactly six ordinary and two padded sentinel projections in block zero and zero counts for the other 31 partitions. Existing tests verify stable projection/key and handle ordering for both with-reordering (WR) and without-reordering (WOR), using separate and shared device backing and the native wave/portable kernel selection. All four SDK CI jobs and architecture validation must pass.
Redundancy and retirement
Two original kernel lowerings gain the same uniform empty-partition admission. There is no new host scheduling owner, scratch buffer, descriptor, shader pass, batch submission, or alternate SAP pair history.
Source fidelity and deviations
Fidelity classification: semantics-preserving-lowering
PhysX source: PxgCudaBroadPhaseSap::runRadixSort, RS_MULTIBLOCK_COUNT and the 32-block PxgRadixSortDesc::radixBlockCounts layout.
Departures: Empty source partitions bypass local reductions while still materializing every zero histogram bin consumed by the exact next scatter pass.
Parity evidence: Actual independent GPU shader histogram, stable radix output and original WR/WOR handle histories across both backends.
