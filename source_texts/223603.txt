That worked pretty well (at least on fast hardware). Using the hybrid scheme, where I first use an octree with 8*8*cellsize to do an initial split of the source point cloud, and then use voxelgrid on each of those leafs I get:
any cell size works, no matter how small,
the humungous memory usage of using only voxelgrid has disappeared,
the super-quadratic time used by the octree method has disappeared.
On vrtiny (2.6GHz i7-9750) performance is okay-ish.
On boor (M5 Mac mini) it is outstanding (600Kpoint cloud downsampled to 1mm in 27ms).
For reference: this hybrid trick was picked up from PointCloudLibrary/pcl#5498
