Motivation
The primary inner loop was spending excessive work recomputing macro-cell indices and exit times per step via macro_cell_query_at_t, which is closer to random access than grid traversal.
We need an algorithmic change (no constant tweaks) to make empty-macro skipping O(#macro cells crossed) with minimal math.
Implement a true Amanatides & Woo style DDA for macro cells so traversal does cheap adds on each macro-cell crossing.
Description
Replaced the per-step macro_cell_query_at_t approach with a persistent macro-cell DDA (MacroDDAState) and helpers: macro_dda_init, macro_dda_t_exit, macro_dda_sync, macro_dda_step, and macro_dda_current in src/shaders/ray/chunk_trace.wgsl.
trace_chunk_rope_interval now initializes a macro_state once and uses macro_dda_sync/macro_dda_current to cheaply test macro occupancy and macro_dda_step to advance the macro DDA when jumping empty macro cells.
The new DDA keeps mx,my,mz, tMaxX/Y/Z, tDeltaX/Y/Z, and per-axis steps so each macro-cell exit becomes a few integer/floating adds instead of recomputing floors and boundaries.
Behavior is preserved for edge cases (INVALID_U32 macro base, out-of-chunk positions, tie-aware stepping) while reducing redundant math in the hot path.
Testing
No automated tests were executed as part of this change.
The modified shader file src/shaders/ray/chunk_trace.wgsl was updated and committed (Optimize macro empty skipping DDA).
