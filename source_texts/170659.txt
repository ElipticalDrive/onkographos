When extracting iso-surfaces from large volume data sets, long processing times are required and a high number of
polygons is generated. We propose a massively parallel iso-surface extraction and simplification algorithm. The
extraction is based on the marching cubes algorithm. In order to process large volume data sets, we perform the
extraction with an interleaved simplification step using parallel edge collapses and the quadric error metrics.
Interleaving extraction and simplification is based on locally postponing collapse operations close to the processing
front. In contrast to previous methods, we do not need an explicit simplification error fall-off close to the front.
Thus we can produce meshes with the same quality as if we would simplify the complete mesh after extraction. By
implementing both extraction and simplification on the GPU, we can reconstruct high quality iso-surfaces from
large data sets within a few seconds
