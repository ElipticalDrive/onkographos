This PR introduces several new, highly creative options to the voxelizer, allowing users to modify the resulting particle clouds in unique ways:
Hollowing (--hollow <thickness>): Marks voxels within the defined thickness from the boundary as the "shell".
Gyroid Infill (--gyroid <period,thickness>): Applies a mathematically defined gyroid pattern to the interior volume (excluding the shell), keeping only voxels that satisfy the equation.
Porous Structure (--porous <probability>): Uses a deterministic pseudo-random generator (LCG) based on voxel coordinates to randomly omit voxels in the interior, simulating a porous structure.
Phase Box (--phase-box <min_x,min_y,min_z,max_x,max_y,max_z>): Allows setting phase = 1 for all voxels (both surface and solid modes) that fall within the defined 3D bounding box.
These features expand the tool beyond simple mesh-to-voxel conversion into a procedural generation playground.

Let infill modifiers run after hollowing
When users combine --hollow with --gyroid or --porous, every voxel deeper than the hollow thickness hits this keep = false branch, so the subsequent “interior” modifier block is skipped and the result is only the shell.
