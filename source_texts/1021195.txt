Describe the project you are working on
A voxel game which needs noise to generate world procedurally.
Describe the problem or limitation you are having in your project
The noise calculation is a bottleneck of the game when generating the world.
Describe the feature / enhancement and how it helps to overcome the problem or limitation
See Auburn/FastNoise2: Modular node graph based noise generation library using SIMD, C++17 and templates which is way more faster then FastNoiseLite.
Describe how your proposal will work, with code, pseudo-code, mock-ups, and/or diagrams
A Noise.FastNoise2 class just like the FastNoiseLite class?
If this enhancement will not be used often, can it be worked around with a few lines of script?
Nope.
Is there a reason why this should be core and not an add-on in the asset library?
Noise generation is commonly used in games.

Integrating FastNoise2 without removing FastNoiseLite will likely increase binary size a fair bit.
Is FastNoise2's output identical to FastNoiseLite when using the same parameters (including seed)? If so, then it could be a drop-in replacement to FastNoiseLite so we don't have to keep FastNoiseLite around. FastNoise2 would then be implemented within the FastNoiseLite class, keeping its original name for compatibility.
