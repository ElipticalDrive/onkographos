# Deblur-NeRF for Macro Photography

Enhancing **Neural Radiance Fields (NeRF)** with a **deblurring pipeline** to produce high-quality 3D reconstructions from shallow depth-of-field macro images.  
This project was developed as my MSc Artificial Intelligence dissertation at the University of Surrey.


## 📝 Project Overview

Conventional NeRF struggles with blurred inputs from macro photography.  
This work integrates **image deblurring** and **regularisation techniques** into the NeRF pipeline to:

- Generate **sharper 3D reconstructions** from shallow DOF images.
- Improve quantitative metrics over baseline NeRF (**MSE = 0.0043, PSNR = 20.3 dB, SSIM = 0.534**).
- Run on constrained GPU memory (12 GB) using optimised architectures.

Key contributions:

- Implemented a **hybrid deblurring + NeRF model** in PyTorch.
- Built a **multi-angle image capture pipeline** to construct the training dataset.
- Added **L2 regularisation, dropout, and spatial attention layers** to improve robustness.
- Integrated with **NeRF Studio** to render dynamic 3D scenes and novel viewpoints.

## 🚀 How to Run

1. **Clone this repository**  
   ```bash
   git clone https://github.com/<yourusername>/DeblurNeRF.git
   cd DeblurNeRF
    ```


2. **Create a virtual environment & install dependencies**

```bash
python -m venv venv
source venv/bin/activate  # (Linux/Mac)
venv\Scripts\activate     # (Windows)
 ```

3. **pip install -r requirements.txt**


-Prepare your data

-Place your macro images into the data/ folder or edit the path in config.yaml.

-Images should be captured from multiple viewpoints for NeRF training.

-Train the Deblur-NeRF model

```bash
python src/train.py --config configs/deblurnerf.yaml
 ```


4.**Render new views / evaluate metrics**

```bash
python src/render.py --checkpoint outputs/checkpoint.pth --output outputs/renders/
 ```


5.**View results**

-Check the outputs/ directory for rendered scenes.

-Metrics (MSE, PSNR, SSIM) are logged during training.
