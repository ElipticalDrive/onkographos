When a mounted viewer replaces a volume, the displayed slice now refreshes immediately. Diverging maps default to RGB interpolation, avoiding a green hue between a blue pole and a light neutral; callers can select mode: 'lch' to retain the former colors. Viewer mounting preserves host styles and works with both fixed-height grid cells and auto-height hosts.
SingleSliceViewer also gains screen-space point markers, a query for IDs drawn on the current slice, and worldToSliceIndex(). ColorMap gains LUT-based legend stops and a CSS gradient. The marker slab option is a full thickness in millimeters, and markers are clipped to the usable viewport.
Closes #26, #27, #28, #29, #30.
Validation: 285 display tests passed (8 skipped); full CJS/ESM/types build, browser bundle, and docs build passed; two Chromium Playwright regressions passed for fixed-height and auto-height hosts. The createDiverging default changes intermediate colors for existing callers and is documented in the changelog.
