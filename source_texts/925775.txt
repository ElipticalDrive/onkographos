## Overview

This program demonstrates fundamental matrix mathematics implemented using 2D arrays in C. Each operation — addition, multiplication, and transpose — is implemented as its own dedicated function, keeping the code modular and easy to maintain.

---

## Features

- ✅ Matrix Addition — element-wise sum of two 3x3 matrices
- ✅ Matrix Multiplication — implemented using a triple-nested loop
- ✅ Matrix Transpose — flips a matrix along its diagonal
- ✅ Clean grid-style console output for easy readability
- ✅ Menu-driven interface to select which operation to perform

---

## Program Flow

1. The program displays a menu: **Addition**, **Multiplication**, **Transpose**, or **Exit**.
2. Depending on the choice:
   - **Addition/Multiplication:** the user enters values for two 3x3 matrices (A and B).
   - **Transpose:** the user enters values for a single matrix (A).
3. The corresponding function is called:
   - `addMatrices()` sums each corresponding element of A and B.
   - `multiplyMatrices()` uses three nested loops — row of A, column of B, and the shared dimension — to compute the matrix product.
   - `transposeMatrix()` swaps rows and columns to produce the transposed matrix.
4. The result matrix is displayed in a clean grid format.
5. The menu loop continues until the user selects Exit.
