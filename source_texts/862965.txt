Scope
Mesh: positions, normals and UVs as f32 triples/pairs, u32 indices, counter-clockwise front faces, and its bounds. Public, plain data, no GPU types.
Faces between two solid voxels are removed. Faces of the same key and direction in one plane are merged into the fewest rectangles by greedy meshing; each rectangle is two triangles whose UVs all point at the key's texel (a flat color, so merging changes nothing visible).
A voxel with a translucent color is meshed apart from opaque ones and does not hide the faces behind it.
The output depends only on the model: rectangles are emitted in a fixed order (axis, then plane, then row), so the same text gives the same bytes everywhere.
Mesh::stats(): vertices, triangles, and the triangles a naive one-quad-per-face mesher would have made.
Acceptance criteria
A solid 8×8×8 cube is 12 triangles; a checkerboard of two keys keeps every face; a hollow box has inward faces.
A test asserts every edge of a closed opaque model is shared by exactly two triangles (watertight).
A golden test hashes the mesh bytes of the showcase models; CI runs it on Linux, macOS, Windows and wasm (through a wasm test runner or a native check of the same function under --target), and the hashes match.
Meshing a 64×64×64 random model takes under 100 ms in release on CI.
Out of scope
Smooth normals, welding and other cleanup (0.2), ambient occlusion (0.6).
Touches: new src/mesh.rs, src/mesher.rs, tests/mesh.rs.
