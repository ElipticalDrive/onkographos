Issue body actions
LineSet.ObjectBoundingBox(index) currently ignores the index and returns aggregate bounds. Its ray intersection paths also disagree: one exits on the first accepted cylinder, the filtered path ignores the requested index slice, and rejected hit-filter candidates can overwrite the caller's incoming hit state/cutoff. Results therefore depend on index ordering and may include excluded cylinders.
Return per-cylinder bounds for indexed calls and make both ray paths inspect exactly the requested slice while retaining the nearest accepted hit below the incoming cutoff. Evaluate hit filters against local candidates so rejection leaves caller state unchanged, while preserving the existing convention that true rejects a hit. Add deterministic bounds, ordering, slicing, filter, cutoff, and state-preservation coverage, document the contract, and retain an allocation-free null-object-filter path.

Implemented in #72. Indexed bounds now select one cylinder, both ray paths honor the requested slice and strict incoming cutoff, and candidates are committed only after hit-filter acceptance so rejected or absent hits preserve prior state. The null-object-filter scan remains allocation-free with normalized per-cylinder timings statistically unchanged.
