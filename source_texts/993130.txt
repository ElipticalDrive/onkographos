Summary
Adds seeded world generation with random seeds by default and reproducible --seed / VOXELPOPULI_SEED support.
Expands world content with lava, dungeons, village outposts, crops/farmland, cactus, clay, redstone ore/dust, and related textures/properties.
Removes the separate nuke block path so TNT is the single explosive block, with visible placed TNT and animated primed TNT.
Fixes dirty chunk bookkeeping so placed blocks, torches, and lighting updates remesh correctly.
Renders wheat as crossed crop quads with a cleaner transparent crop texture.
Adds AGENTS.md contributor guidelines.
Root Cause
Placed blocks were setting chunk.dirty inside Chunk::set_block() before World::set_block() checked whether to increment dirty_count, so edited chunks could fail to be scheduled for relighting/remeshing. TNT also had a separate nuke path that diverged from the requested Minecraft-style single explosive behavior.

596-599: 🩺 Stability & Availability | 🔵 Trivial | 💤 Low value
Silent u8 truncation risk in sector_count.
total_len.div_ceil(SECTOR_BYTES) as u8 truncates if a single chunk's compressed NBT ever needs more than 255 sectors (~1MB). In that case the header would advertise fewer sectors than the record actually occupies, corrupting the following chunk's data in the region file. Unlikely with the current block variety and highly-compressible light/biome arrays, but worth a defensive check given it's a silent data-corruption failure mode rather than a crash.
