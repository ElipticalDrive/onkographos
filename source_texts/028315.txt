When Face Culling is enabled then then primitives are discarded, dependent on the winding order of the vertex coordinates, as seen from the point of view.
For this a winding order for the front faces is defined, by glFrontFace. By default this is counter clockwise.
If back faces sculling is enabled:
```
GL40.glEnable(GL40.GL_CULL_FACE);
GL40.glCullFace(GL40.GL_BACK);
```
then the polygons which have the opposite winding order (clockwise) are discarded.
According to your vertex coordinates
```
float[] vertices = { 
    -0.5f,  0.5f, -0.5f, 0, 0, 
    -0.5f, -0.5f, -0.5f, 0, 1,
     0.5f, -0.5f, -0.5f, 1, 1,
     0.5f,  0.5f, -0.5f, 1, 0,

    -0.5f,  0.5f,  0.5f, 0, 0,
    -0.5f, -0.5f,  0.5f, 0, 1,
     0.5f, -0.5f,  0.5f, 1, 1,
     0.5f,  0.5f,  0.5f, 1, 0,

     0.5f,  0.5f, -0.5f, 0, 0,
     0.5f, -0.5f, -0.5f, 0, 1,
     0.5f, -0.5f,  0.5f, 1, 1,
     0.5f,  0.5f,  0.5f, 1, 0,

    -0.5f,  0.5f, -0.5f, 0, 0,
    -0.5f, -0.5f, -0.5f, 0, 1,
    -0.5f, -0.5f,  0.5f, 1, 1,
    -0.5f,  0.5f,  0.5f, 1, 0,

    -0.5f,  0.5f,  0.5f, 0, 0,
    -0.5f,  0.5f, -0.5f, 0, 1,
     0.5f,  0.5f, -0.5f, 1, 1,
     0.5f,  0.5f,  0.5f, 1, 0,

    -0.5f, -0.5f,  0.5f, 0, 0,
    -0.5f, -0.5f, -0.5f, 0, 1,
     0.5f, -0.5f, -0.5f, 1, 1,
     0.5f, -0.5f,  0.5f, 1, 0
};
```
and indices
```
short[] indices = {
     0,  1,  3,  3,  1,  2,
     4,  5,  7,  7,  5,  6,
     8,  9, 11, 11,  9, 10,
    12, 13, 15, 15, 13, 14,
    16, 17, 19, 19, 17, 18,
    20, 21, 23, 23, 21, 22
};
```
This means that the 1st, 3rd and 5th row of indices have the wrong winding order. It has to be:
```
short[] indices = {
     0,  3,  1,  3,  2,  1,
     4,  5,  7,  7,  5,  6,
     8, 11,  9, 11,  10, 9,
    12, 13, 15, 15, 13, 14,
    16, 19, 17, 19, 18, 17,
    20, 21, 23, 23, 21, 22
};
```
