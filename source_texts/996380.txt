Draft, stacked. Built on #368 (and so #363, #364, #366, #367). Its diff against master includes those commits until they merge; the change here is the last commit, feat: trilinear interpolation on PropertyGrid, via StructuredGrid3DGeometry.

Trilinear interpolation of node values on PropertyGrid, so a property can be transferred onto another support: grid.evaluate_value("f", other_support.nodes).
Change
The pure-geometry pieces of the interpolation support move into StructuredGrid3DGeometry, so the support and PropertyGrid share them (moved verbatim): trilinear, position_to_local_coordinates, position_to_dof_coefs, position_to_cell_corners / _vertices, node_indexes_to_position, element_size / element_scale, evaluate_value.
evaluate_value now also accepts (n_nodes, k) data (the 1-D path is unchanged). PropertyGrid.evaluate_value(name, points) interpolates the node property name; NaN outside the grid. Points are in the grid's own frame (no rotation).
Tests

The structured-support reference test from #367 is unchanged and passes, so the support's behaviour did not move.
21 new tests in test_property_grid.py: a linear field is reproduced exactly at random points; node values are returned at the nodes; midpoint equals the mean of the corner values; NaN outside; multi-component data; agreement with the support's own evaluate_value; transfer onto a 3x finer support. Swapping two trilinear corner weights fails 12 of the 51 tests in that file.
packages/loop_common/tests: 234 passed; packages/loop_interpolation/tests: 606 passed; tests: 737 passed. ruff clean on changed files.

Not included: gradients on PropertyGrid; interpolation of cell properties (they are piecewise constant: use cell_value_at).

def position_to_cell_corners(self, pos):
"""Get the global indices of the vertices (corners) of the cell containing each point.
Parameters
----------
pos : np.array
(N, 3) array of xyz coordinates representing the positions of N points.
Returns
-------
globalidx : np.array
(N, 8) array of global indices corresponding to the 8 corner nodes of the cell
each point lies in. If a point lies outside the support, its corresponding entry
will be set to -1.
inside : np.array
(N,) boolean array indicating whether each point is inside the support domain.
"""
cell_indexes, inside = self.position_to_cell_index(pos)
nx, ny = self.nsteps[0], self.nsteps[1]
offsets = np.array(
[0, 1, nx, nx + 1, nx * ny, nx * ny + 1, nx * ny + nx, nx * ny + nx + 1],
dtype=np.intp,
)

globalidx = g[:, None] + offsets[None, :] # (N, 8)
globalidx[~inside] = -1
return globalidx, inside

def evaluate_value(self, evaluation_points, property_array):
"""Trilinear interpolation of node values at the evaluation points.
Parameters
----------
evaluation_points : np.ndarray
N x 3 locations in the grid's own frame
property_array : np.ndarray
values at the nodes, shape ``(n_nodes,)`` or ``(n_nodes, k)``, in node order
(x varies fastest)
Returns
-------
np.ndarray
``(N,)`` (or ``(N, k)``) interpolated values; NaN for points outside the grid
"""
property_array = np.asarray(property_array)
evaluation_points = self.check_position(evaluation_points)
if property_array.shape[0] != self.n_nodes:
logger.error("Property array does not match grid")
raise ValueError(
f"cannot assign {property_array.shape[0]} vlaues to array of shape {self.n_nodes}"
)
idc, inside = self.position_to_cell_corners(evaluation_points)
if idc.shape[0] != inside.shape[0]:
raise ValueError("index does not match number of nodes")
weights = self.position_to_dof_coefs(evaluation_points[inside, :])
if property_array.ndim == 1:
v = np.zeros(idc.shape)
v[:, :] = np.nan
v[inside, :] = weights
v[inside, :] *= property_array[idc[inside, :]]
return np.sum(v, axis=1)
result = np.full((idc.shape[0],) + property_array.shape[1:], np.nan)
result[inside] = np.einsum("nc,nc...->n...", weights, property_array[idc[inside, :]])
return result
