Implement the W17 G09–G11 browser runtime: CPU/WASM BVH construction and queries, WebGPU Morton/radix LBVH and refit, six SDF primitives with CSG/hybrid traversal, and deterministic progressive megakernel/wavefront path tracing.
Expose typed AOVs, EXR/PNG export, scanline tiles, ReSTIR reuse, online guiding, RGB media, scene caching, cancellation and explicit device recovery. Include the review fixes for irregular LBVH counts, lit-medium attenuation/scattering, failed recovery, cache locking, reserved hit IDs and transferable worker results.
Guiding uses shared host-generated float32 probabilities/CDFs; a deterministic real-GPU boundary regression fails before the fix and passes afterward. Float32 bit boundaries also prevent Firefox shader fusion/reassociation from changing surface-light accumulation and medium log/exp phase results. These preserve precision and the existing exact engine-hash assertions.
Validation:
Required hosted CI is green at 65a4551: 284 Chromium checks pass (10 conditional skips) and 289 Firefox checks pass (5 conditional skips), alongside the build/contract job. Completed run. GitHub reports MERGEABLE and CLEAN. The optional WebKit classifier reports missing runner WebGPU and does not qualify WebKit rendering support.
All 19 hosted workflow contract checks pass; full Chromium and Firefox source/dist preflight has a 120-minute job budget.
Both 320×200 interactive demo checks complete all 64 samples and produce nonblank images; their waits include cold shader compilation on macOS CI.
Streaming recovery comparisons wait for harvested GPU LOD readback and assert terrain coverage, convergence and zero refetches; all 17 COG checks and 30 parallel recovery repetitions pass locally.
1,151 TypeScript unit tests; 622 Rust tests during W17 implementation, with both W17 Naga/ABI checks rerun after the final shader change.
All 11 source checks pass on Chromium and headed Firefox 150.0.2 with default preferences. All 11 installed-tarball checks pass on Chromium at runtime revision 0a46179 and Firefox at pushed head 65a4551, including the million-ray fixture, oblique queries, irregular refits, lit media and 96 guided CPU/GPU checkpoints. The additional Firefox installed run selects its browser project while retaining the gate's assertions.
Guided CPU/GPU maximum relative color/weight errors are 1.42e-7/1.41e-7; engine color and weight differences are exactly zero. Scattering checks at one, two and three bounces preserve exact color and direct/indirect AOV equality.
A prior 600-second installed stress completed 35,274 frames with zero retained GPU buffers; the evidence explicitly binds that run to its earlier revision.
Public API/declarations, package contracts and revision/report/tarball digests checked. Detailed results: docs/parity/w17-local-evidence.json, docs/parity/w17-guiding-fix-evidence.json and docs/parity/w17-firefox-fix-evidence.json. Prior evidence retains its original revision bindings.
The pinned W00 1920×1080 discrete/integrated hardware qualification remains pending; local conformance and stress do not qualify those profiles.
