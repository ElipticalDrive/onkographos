The existing interaction lab renders a 2.5D projection. This adds an isolated modeling-lab.html and modular modeling-lab/ environment with actual XYZ geometry, WebGL depth, perspective/orthographic cameras and ray picking. Production Board, Pack, Isometric, Drag Feel and the existing lab sources are unchanged; the README adds a separate entry link.
Implemented: Box/Cube, Line/Polyline, Plane and 3/4-point mesh/bilinear SrfPt; live previews and command/numeric input; XY/XZ/YZ CPlanes, elevation and Elevator; projection-sensitive RMB navigation, anchored wheel zoom, ZE/ZS and explicit targets; additive/removal, directional marquee and component selection; XYZ Gumball/numeric transforms; groups, object tree, common/inherited styles, undo/redo, reusable Block/Insert definitions and validated version-1 JSON save/load. Selection is aqua-cyan #00ffee. Three.js 0.180.0 and its MIT notice are vendored; no runtime CDN/install is needed.
Owner-private cloud preview: https://modeling-lab-3d-jmm-20261017.jazzy-tick-9370.chatgpt.site
Launch from repository root: python3 -m http.server 5173, then open /modeling-lab.html. Isolated package: npm --prefix modeling-lab run build. Read modeling-lab/README.md and modeling-lab/VERIFICATION.md for interaction details, test reproduction and limits.
Validation entirely in remote Linux (no Windows checkout/executor): 15 core tests, 22 real Chromium/SwiftShader WebGL checks, 12 existing regression suites, screenshot inspection, and a byte-verified isolated build. Browser checks include actual toolbar creation, ray selection, numeric and drag transforms, downloaded JSON/file-upload reload, active-command navigation, Elevator, persistent Tab lock, endpoint-only component editing, Escape rollback and no idle redraw loop. GitHub source tree SHA matches the tested cloud index byte-for-byte.
Limits: polygon meshes/bilinear patches rather than Rhino NURBS; no booleans, curved primitives/tangent snaps, .3dm round-trip, nested block editing, topology healing/loops or dense-overlap selection menu. SmartTrack is a bounded four-reference subset; locked geometry is excluded from snaps in this version. Broad legacy performance/stress test.js was not run because the handoff records its existing machine-sensitive gate.
Based on main d798c0d. This is a draft for review only: no merge, main modification or public deployment. The paused feedback automation was not changed.
