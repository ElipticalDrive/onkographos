Adds a new interactive lenticular panel filter that simulates a sheet of cylindrical lenses laid over an image. The effect creates a magnifying, focus-shifting appearance as the viewer tilts the virtual panel.
Changes
New sketch: sketches/lenticular-panel/ with WebGL2 fragment shader implementation
Renders cylindrical lens array with configurable lens count, angle, and tilt
Implements lens magnification, defocus, chromatic aberration (colour split), and specular highlights
Supports mouse/tilt input mapping for interactive X and Y tilt control
Parameters: lens count (6–200, log scale), sheet angle, tilt X/Y, lens power, defocus blur, colour split, and gloss
Mirror mode for selfie camera use
Shader features:
Per-lens view shifting based on tilt angle
Depth-of-field defocus proportional to tilt magnitude
RGB channel separation for chromatic aberration effect
Specular highlight ridge along lens surface
Clamped sampling to prevent edge artifacts
Registry update: Added lenticular-panel to both FILTER_SLUGS and CHAINABLE_SLUGS in src/registry/filters.js, making it available as a chainable filter in the Patch compositor
The sketch follows project conventions: uses createRuntime() for parameter management and input mapping, createGLFilter() for GPU rendering, and includes a manifest with metadata and tags.
