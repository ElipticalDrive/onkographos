euler_to_rotation_matrix(0, 0, pi/2) currently rotates the x axis by 45 degrees. Use full angles in matrix entries and compose rotations as Rz(yaw) @ Ry(pitch) @ Rx(roll) to match euler_to_quaternion. Preserve the existing list return type and apply_rotation_offset(position, pitch, yaw, roll) argument order.
Validation
Three unittest methods pass on the independent upstream patch: axis quarter turns, quaternion agreement for combined angles, and offset argument order.
The same suite reports six failed assertions/subtests on the unmodified upstream implementation.
No simulator required. From the repository root, set PYTHONPATH=PythonClient and run python -m unittest discover -s PythonClient/tests -p test_rotation_utils.py -v.
