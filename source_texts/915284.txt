Motivation
Provide a small, self-contained browser demo that recreates core Minecraft-like voxel interaction for local exploration and prototyping.
Description
Add index.html, style.css, and script.js that together render a voxel terrain using Three.js and set up a minimal HUD and crosshair.
Implement first-person controls with PointerLockControls (WASD movement, mouse look, Space to jump) and simple gravity/ground collision handling.
Create a procedural block world generator and raycast-based block interactions: left-click to remove blocks and right-click to place blocks; include a visible selector wireframe for targeted blocks.
Add responsive resize handling and lightweight lighting (hemisphere + directional) to make the scene viewable across window sizes.
Testing
Served the demo locally with python3 -m http.server 4173 and confirmed the server responded successfully.
Ran a Playwright script that opened http://127.0.0.1:4173, clicked to lock pointer, and captured a screenshot (artifacts/minicraft-home.png) successfully.
Staged and committed the three new files with git add index.html style.css script.js and git commit, which completed without error.
