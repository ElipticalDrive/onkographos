# Ray Tracing: Two Spheres on an Infinite Plane
**Tech Stack:** Java (AWT/Swing)

## About
This project is a simple ray tracer written in Java that renders **two spheres** on an **infinite plane**.  
It demonstrates core computer graphics concepts such as ray–object intersections, shading, surface normals, and shadow calculation.

## Features
- Ray casting per pixel using camera-origin rays.
- **Two spheres** (red and blue) with different radius.
- **Infinite plane** acting as the ground surface.
- Ambient and diffuse (Lambertian) lighting.
- Realistic **hard shadows** calculated using shadow rays.
- Accurate ray–sphere and ray–plane intersection math.
- Fully functional render inside a `BufferedImage` and Swing `JFrame`.

## How It Works
- Rays originate from a virtual camera and pass through every screen pixel.  
- Intersection tests determine which object a ray hits first.  
- Surface normals are used to apply lighting.  
- A secondary “shadow ray” determines if the hit point is in shadow.  
- The final computed color is written into the output image.

## Scene Objects
- **Sphere 1:** Center & radius defined in code (commonly red).  
- **Sphere 2:** Second sphere with different radius (commonly blue).  
- **Plane:** Infinite floor at a fixed y-coordinate (green).

## Controls
This project does not have user controls, it runs as a still image/frame.
