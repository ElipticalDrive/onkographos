Summary
A research-grade, fully-runnable 3D brain-tissue inpainting pipeline for the BraTS 2026 Task 4 challenge (MONAI + PyTorch). Given a voided T1 MRI volume and a binary mask, it reconstructs the healthy tissue inside the masked region. Tuned for a single RTX 5090 (32 GB), 28 GB RAM, 1 TB SSD.
All heavy logic lives in the reusable src/brats_inpaint package; a 12-section notebook orchestrates the full pipeline. References: WaveDiT, FlowLet.
What's included
Data (data.py): automatic case discovery, image/mask/label correspondence verification, graceful handling of missing files, deterministic train/val split.
Transforms (transforms.py): orientation, foreground crop, z-score norm, divisible padding + augmentation (flips, affine, intensity/gamma/noise, elastic, synthetic mask enlargement).
Model (model.py): SwinUNETR Swin-Transformer encoder · 3D Haar wavelet frequency block (low/high branches + attention fusion) · mask-aware cross-attention · residual decoder with deep supervision · boundary-refinement head. Input = concat(voided, mask); output composited so known voxels stay exact.
Losses (losses.py): 0.35·MaskedL1 + 0.25·SSIM + 0.15·Wavelet + 0.15·Gradient + 0.10·GlobalL1, all from scratch, with 10× in-mask weighting.
Training (train.py): bf16 AMP, gradient accumulation/clipping, cosine annealing + warm-up, EMA, channels_last_3d, gradient checkpointing, torch.compile, checkpointing.
Validation (validate.py) / metrics (metrics.py): SSIM/PSNR/MSE and rank-score (Rank(SSIM)+Rank(PSNR)+Rank(MSE)) best-model selection.
Inference (inference.py): MONAI sliding-window + flip-x/y/z TTA.
Visualization / Export: error-map plots, TensorBoard logging, state-dict + TorchScript export.
Verification
Validated end-to-end on CPU with the real MONAI 1.5 / PyTorch 2.12 stack using synthetic NIfTI cases: discovery → transforms → train forward (deep supervision) → all 5 loss terms + backward → full train loop with EMA/scheduler/checkpoint → reload → sliding-window + TTA inference → metrics. The composite was confirmed to preserve known voxels exactly outside the mask. The production config (feature_size=48, 96³) builds at 121.5M params with a clean forward.
Usage
```
pip install torch --index-url https://download.pytorch.org/whl/cu128
pip install -r requirements.txt
export BRATS_DATA_ROOT="D:/M Challange/Inpainting/Data"
jupyter lab   # run notebooks/BraTS2026_Task4_Inpainting.ipynb
```
Set SMOKE_TEST = True in the config cell for a fast sanity run.
