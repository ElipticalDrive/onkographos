# 3D Gaussian Splatting

CMU *Learning for 3D Vision* Assignment 4 — Q1: implement 3D Gaussian Splatting from scratch, including representation, projection, rasterization, and optimization.

## Overview

| Task | Description |
|------|-------------|
| **Render** | Load pretrained Gaussians (`sledge.ply`) and render RGB / depth / mask from multiple views |
| **Train (Cow)** | Initialize isotropic Gaussians from a point cloud and optimize on the cow dataset |
| **Unit tests** | Numerical checks for core operations such as covariance |

Note: I successfully finished the render part and the result is good, which means the redering pipeline is correct. I make sure the training part is runnable but I did not run it thoroughly because of the lack of computation resources.

## Requirements

- Python 3.9+
- CUDA (recommended)
- PyTorch + [PyTorch3D](https://github.com/facebookresearch/pytorch3d)
- `omegaconf`, `imageio`, `numpy`, `Pillow`, `tqdm`, `scikit-image`

Example install (adjust for your CUDA / PyTorch versions):

```bash
pip install torch torchvision
pip install pytorch3d
pip install omegaconf imageio numpy Pillow tqdm scikit-image
```

## Setup

1. **Set `PYTHONPATH`** (source code lives under `src/`):

```bash
# Linux / macOS
export PYTHONPATH="$(pwd)/src:$PYTHONPATH"

# Windows PowerShell
$env:PYTHONPATH = "$(Get-Location)\src"
```

VS Code / Cursor debugging already sets `PYTHONPATH` in `.vscode/launch.json`.

2. **Update output paths**  
   Edit `src/Pathes.py` and set `wsf` to your local project root:

```python
wsf = Path(r"e:\ProjectLocal\learning-for-3D-vision\assignment4\3D Gaussian Splatting")
out_dir = wsf / "outputs"
```

3. **Data**
   - Rendering: `data/sledge.ply`
   - Training: `data/cow_dataset/`
   - Harder scene: prepare `data/materials/` (or pass `--data_path`)

## Usage

Run all commands from the project root.
