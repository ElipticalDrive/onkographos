Context
Add per-vertex ambient occlusion and smooth light to the voxel meshes, and a tint colour for each tint index (for example grass by biome).
Reference: horizon (MIT) at the pin. Read a file with:
gh api 'repos/ludovic111/horizon/contents/<path>?ref=88b3b3e879adde9dc7b5fed8c0ade1f281af347d' -H 'Accept: application/vnd.github.raw'
crates/horizon-client/src/mesher/lighting.rs
Use the reference for the technique. Do not copy game behaviour, game names or file formats. If you port horizon code, add the horizon MIT notice to THIRD_PARTY_NOTICES.md.
Acceptance Criteria
Each vertex gets an ambient occlusion value from its 3 neighbour blocks.
Each vertex gets a smooth light value from the light engine.
The game gives a tint colour function. Quads with a tint index use it.
Greedy meshing still merges faces that have the same AO, light and tint.
The public API has no game names and no game file formats.
No change breaks an existing public API. apps/action and apps/minecraft.seanmizen.com use it. If a break is necessary, give the reason in the PR under Breaking.
New code has tests. zig build test and zig build web pass.
