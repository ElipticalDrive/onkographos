Suggested model
[opus] — designs the on-disk shape primitive registry encoding so adding new ShapeType values (torus, capsule_knot, custom) doesn't bump the format version. Cross-cutting decision.
Context
.vxs v1 dense mode (#664) handles per-voxel records. This ticket adds the shape-group mode: an asset can be saved as a composition of SDF primitive instances instead of a dense voxel grid. The engine already has C_ShapeDescriptor (engine/prefabs/irreden/voxel/components/component_shape_descriptor.hpp:21-37) and a SHAPES_TO_TRIXEL pipeline (engine/prefabs/irreden/render/systems/system_shapes_to_trixel.hpp) — this format persists the inputs to that pipeline.
Shape-group .vxs files render directly via SHAPES_TO_TRIXEL (no voxelization required, no voxel pool allocation). Hybrid mode (#668) combines shape primitives with dense voxel overrides.
Designed so that adding a new ShapeType enum value never breaks an old save — the format writes both numeric id and a string-name table, so an older loader receiving a new save just logs "unknown shape, skipped" and the rest of the asset loads (Extensibility Rule #2).
Acceptance
.vxs shape-group chunks defined:
SHPG chunk: array of primitive instances —
{ uint32 shapeTypeId; uint16 version; vec4 params; Color color; uint32 flags; uint8 bone_id; vec3 offset; quat rotation; uint8 csgOp; }
where csgOp ∈ { UNION, SMOOTH_UNION, SUBTRACT, INTERSECT, NONE }.
SREF chunk: string name-table for ShapeType enum + material registry refs (so a save with a future ShapeType::TORUS_KNOT is recoverable on an older build).
.vxs MODE chunk learns the SHAPES mode tag (DENSE was asset: .vxs v1 dense-mode reader/writer (BNDS, VOXR, LAYR, FRAM, META chunks) #664; HYBRID is asset: .vxs hybrid mode (dense + shape group) + .vxs.json sidecar emitter + round-trip test suite #668).
IRAsset::saveVoxelSet overload accepts std::span<const C_ShapeDescriptor> plus optional per-primitive csgOp/transform parallel arrays.
Loader path: returns a list of C_ShapeDescriptor-shaped records the caller spawns as entities.
Adding a new ShapeType extends the enum in engine/render/include/irreden/render/ir_render_types.hpp plus an sdf<NAME> GLSL/Metal pair — no format change required. Add a "How to add a new SDF primitive" walkthrough to engine/asset/CLAUDE.md.
Round-trip unit test: build a 5-primitive shape group (mixed sphere/box/capsule), save, load, byte-compare.
Edge case: unknown ShapeType numeric id (forward-compat) → loader logs "unknown shape ID=N name=…, skipped" and returns the rest of the primitives.
Critical files

Notes
asset: .vxs v1 dense-mode reader/writer (BNDS, VOXR, LAYR, FRAM, META chunks) #664 and this ticket can run in parallel after asset: extend engine/asset/ with BinaryWriter/Reader + chunk-table header + JSON sidecar emitter #663 lands.
Designed for future CSG-tree extensions; the per-instance csgOp byte is sufficient for v1 (flat composition with smooth-union). A tree structure can land in a SHPT chunk later without bumping the file version.
