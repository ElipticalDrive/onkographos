1. Introduction
• We introduce a unified constrained formulation that couples an RGB–semantic task objective with Gaussian sparsification and attribute vector quantization for compact
Language 3DGS.
Open-vocabulary 3D scene understanding enables objects
in a 3D scene to be localized or segmented using arbitrary
natural-language queries, without restricting predictions to
a predefined class set [28]. This capability supports applications such as AR/VR [19], autonomous driving [8], and
robotic manipulation [14, 31]. Earlier neural-field methods encoded semantics in implicit representations, but repeated volumetric sampling and network evaluation made
training and rendering costly [17, 36]. Language 3DGS
instead attaches vision-language features to explicit Gaussian primitives and reuses the tile-based splatting pipeline
of 3DGS to render semantic feature maps efficiently, avoiding repeated volumetric sampling and per-sample network
evaluation [16, 30, 41].
Directly attaching high-dimensional vision-language
features to individual Gaussians incurs substantial storage
and rendering overhead [30, 41]. LangSplat mitigates this
problem using a scene-specific low-dimensional autoencoder, while LangSplatV2 further replaces the heavyweight
decoder with sparse per-Gaussian coefficients over shared
dictionaries, enabling efficient high-dimensional feature
splatting [22, 30]. These advances reduce the cost of semantic feature representation and inference, but do not target compression of the underlying RGB Gaussian scene.
Consequently, a complete Language 3DGS model still contains the original 3DGS attributes together with additional
semantic parameters. Its compression must therefore preserve both photometric fidelity and semantic responses.
Standard 3DGS compression often combines sparsification or pruning [1, 12, 13, 38, 40] with quantization [21, 24,
25]. Applying them sequentially decouples semantic learning from Gaussian selection, so RGB-driven sparsification
can discard semantically important Gaussians that subsequent stages cannot recover. Figure 1 illustrates this failure
using LangSplatV2 [22], GaussianSpa, and CompGS: semantic representations degrade whether semantic learning
occurs before or after RGB-driven Gaussian sparsification.
Our unified formulation instead coordinates semantic learning, sparsification, and quantization throughout optimization.
To address this gap, we propose C LUNO GS (Compact
Language via Unified Optimization for 3D Gaussian
Splatting). The framework combines RGB reconstruction
and semantic supervision with a cardinality constraint on
Gaussian opacities and vector quantization (VQ) of selected
attributes. Updating the scene parameters, sparse support,
and quantized representations within the same constrained
problem allows them to adapt to one another instead of inheriting irreversible decisions from a preceding stage. We
solve the resulting non-smooth problem with an alternating
primal–dual procedure.
Our contributions are:
• We develop a compact Language 3DGS optimization
framework and solve the unified problem using an alternating primal–dual procedure that coordinates differentiable scene optimization, sparsification, quantization,
and dual updates.
• We evaluate C LUNO GS on LERF and ScanNet-10 using
recent language-field baselines, sequential compression
and ordering controls, qualitative comparisons, and controlled ablations. Across the two benchmarks, C LUNO GS
reduces serialized storage by 80.9–82.8% relative to the
corresponding uncompressed models, with losses of at
most 1.6 mIoU points, 1.1 accuracy points, and 0.07 dB
PSNR.
2. Related Work
Language 3DGS. Language-aware 3D representations
lift 2D foundation-model features into queryable 3D fields,
with LERF providing an early NeRF-based formulation [17]. Language 3DGS methods mainly follow two
paradigms. Render-supervised methods learn per-Gaussian
features or codes by matching rendered feature maps to 2D
supervision, as in LangSplat, Feature 3DGS, GAGS, and
LangSplatV2 [22, 29, 30, 41]. Direct-lifting methods instead register or aggregate multi-view features onto reconstructed Gaussians without iterative semantic fitting, as in
Dr. Splat and Occam’s LGS [7, 18]. LightSplat and ExtrinSplat further replace dense per-Gaussian embeddings with
compact semantic indices or an external object-group index [2, 11]. We build on LangSplatV2 because its semantic coefficients and RGB attributes share the same Gaussian
support, allowing sparsification and attribute quantization
to account for both rendering and semantic quality.
Compact Language 3DGS. Recent work has explored
compact representations for the semantic features in Language 3DGS. DF-3DGS separates RGB and semantic Gaussians and sparsifies the semantic field, while CF3 compresses feature Gaussians through pruning, merging, and
autoencoding [10, 20]. CSGaussian progressively entropycodes both color and semantic attributes [34]. SCOUP
represents semantic features with sparse codes, whereas
CoSAG predicts and entropy-codes compact semantic bindings for individual Gaussians [4, 15]. These methods reduce semantic storage through specialized feature representations and coding schemes.
General 3DGS Compression. RGB-only 3DGS compression reduces active primitives, attribute storage, or bit2
stream size. GaussianSpa and PUP 3D-GS sparsify optimized scenes using constrained or uncertainty-based criteria [13, 40]. Compact 3DGS, C3DGS, and CompGS use
clustering or quantization to reduce attribute storage [21,
25, 26]. RDO-Gaussian jointly optimizes masks and
entropy-constrained attributes, while HAC++ and LocoGS
model context or local coherence for compact coding [6, 32,
35]. FCGS applies a feed-forward codec to an optimized
Gaussian scene [5]. Joint sparsification and quantization
are therefore established in RGB 3DGS. The concurrent
GETA-3DGS preprint also studies joint structured pruning
and heterogeneous quantization [39]. C LUNO GS instead
optimizes opacity with both RGB and semantic supervision before cardinality projection, and coordinates Gaussian
sparsification with attribute vector quantization in the same
constrained formulation.

4. Methodology: C LUNO GS
To compact a Language 3DGS model while preserving semantic and RGB quality, we propose a unified compression framework, C LUNO GS. Our method places semanticsaware Gaussian sparsification and vector quantization in a
single constrained objective. We solve it with a primal–dual
procedure that alternates among differentiable scene optimization, sparsification, quantization, and dual updates.

5.2. Overall Performance
Table 1 evaluates whether aggressive compression can preserve both semantic prediction accuracy and RGB rendering
quality. Across LERF and ScanNet-10, we compare deployable systems from two Language 3DGS paradigms: directlifting methods and render-supervised semantic fields. Semantic metrics and PSNR measure quality, while storage
and peak memory measure deployment cost.
Compared with CF3, the smallest competitor on both
benchmarks, C LUNO GS achieves over 5× storage reduction while also attaining the lowest peak memory. It nevertheless ranks second in every semantic and RGB quality metric; its maximum gaps to LangSplatV2 are only 1.6
mIoU points, 1.1 accuracy points, and 0.07 dB PSNR. The
same trend on both datasets shows that this advantage is not
benchmark-specific.
LangSplatV2 remains the quality leader because its full
model retains detailed semantic coefficients and dictionaries at all three scales. While direct-lifting methods are
designed for efficient querying, both Occam’s LGS and
Dr. Splat trail this render-supervised model in semantic
quality. Occam’s LGS is also storage-intensive on both
datasets and incurs the highest peak memory on LERF.

7. Conclusion
We present C LUNO GS, a unified framework that jointly
sparsifies and quantizes Language 3DGS under RGB and
semantic supervision. Across LERF and ScanNet-10, it
substantially reduces storage and peak memory while retaining competitive RGB and semantic quality. Controlled comparisons show that semantics-aware selection
and primal–dual co-adaptation mitigate the semantic degradation of sequential compression.
