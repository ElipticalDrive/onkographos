Introduction
Open-vocabulary 3D segmentation assigns vision-language aligned semantic features, such as those produced
by CLIP (Radford et al., 2021b), to reconstructed scenes, allowing objects and spatial regions to be identified
using free-form language queries. This capability supports applications such as robotic manipulation (Gu
et al., 2024), complex scene understanding (Kerr et al., 2023) and medical-imaging (Wang et al., 2025).
Existing approaches include grouping-based methods, training-based methods, and heuristic-based methods.
We focus on the latter family, which directly lifts features from 2D images onto a 3D representation.
The process of assigning these features to scene geometry is known as feature lifting. It associates features
observed in rendered images with the primitives contributing to each pixel, using their rendering weights to
aggregate information across views. This provides an efficient way to obtain semantic representations without
training a 3D foundation model from scratch, but introduces a fundamental ambiguity: a 2D observation may
be distributed across multiple primitives, while a primitive may collect observations from different objects.
As a result, feature lifting can entangle semantic evidence before a classifier makes a prediction.
This ambiguity is particularly important near object boundaries. Repeating the lifting process across
views can produce feature entanglement and degraded semantic boundaries, even when the underlying image
features are accurate. Recent work has begun to formalize this problem by treating feature lifting as a linear
inverse problem and quantifying the ambiguity introduced by multiple primitive contributions (Xiong et al.,
2026).
Existing feature-lifting methods largely operate on Gaussian-based reconstructions, where overlap leads
to multiple primitives contributing to the same ray. This raises a more fundamental question: to what extent
is feature-lifting ambiguity a property of the lifting procedure itself, and to what extent is it induced by the
underlying 3D representation?
In this work, we investigate feature lifting as a representation-dependent problem. We ask whether
changing the geometric primitives used to represent the scene can reduce the mixing of semantic evidence,
while keeping the image features and lifting procedure fixed. We consider PowerFoam (Govindarajan
et al., 2026), which represents a scene using bounded power diagrams whose cells partition 3D space. This
non-overlapping spatial support reduces the number of primitives that can contribute simultaneously to a ray,
reducing semantic feature mixing.
We isolate this effect, by evaluating feature lifting independently of errors introduced by the upstream 2D
semantic model. We replace predicted image semantics with ground-truth segmentation and text features,
allowing us to measure the extent of semantic feature mixing caused by a feature lifting onto a chosen
underlying 3D representation. Under this controlled setting, we compare Gaussian-based and PowerFoam
reconstructions using the same lifting procedure and find that the reduced dispersion in PowerFoam leads to
substantially more class-consistency in lifted features. This demonstrates that the choice of 3D primitive can
itself impose a significant limitation on semantic feature lifting. Applied to real datasets, we observe that all
our tested lifting methods achieve improved 3D open-vocabulary segmentation results using PowerFoam
instead of 3DGS as underlying representation.
Our contributions are:
• A controlled study of representation-dependent feature lifting. We isolate the feature-lifting stage
from upstream semantic errors and systematically compare 3D primitives under the same image features
and lifting procedure.
• An analysis of representation-induced feature dispersion. We show that space-partitioning primitives
can substantially reduce semantic feature mixing compared with overlapping Gaussian primitives.
• An open-vocabulary 3D segmentation system based on PowerFoam. We incorporate these insights
into a PowerFoam-based semantic representation and demonstrate improved performance on openvocabulary 3D segmentation benchmarks.

Related work
Existing approaches for lifting 2D features to 3D primitives differ primarily in how the correspondence
between image observations and 3D primitives is established: through training-based, grouping-based, and
heuristic-forward methods.
Early approaches fit continuous 3D semantic fields via scene-specific optimization. LERF, for example,
distills CLIP features into a radiance field (Kerr et al., 2023; Radford et al., 2021b), while LangSplat trains
a scene-specific autoencoder to represent lifted features in a latent space (Qin et al., 2024). OpenGaussian
similarly learns instance-level features together with a codebook for point-level understanding (Wu et al.,
2024). These methods can produce expressive semantic representations, but require computationally expensive
per-scene optimization and may inherit inconsistencies from the underlying multi-view 2D predictions.
An alternative is replacing continuous optimization with discrete associations derived from 2D masks
(e.g., SAM (Kirillov et al., 2023)). LAGA decomposes scenes into object entities by clustering SAM
mask descriptors across views (Cen et al., 2025), while THGS constructs Gaussian adjacency graphs with
contrastive edge reweighting for hierarchical superpoint partitioning (Dai et al., 2025). LUDVIG avoids
training altogether by combining multi-view weighted feature averaging with graph diffusion across adjacent
primitives (Marrie et al., 2025). Although these approaches eliminate dense feature optimization, they
introduce multi-stage grouping heuristics and remain sensitive to primitive spatial overlap.
More recent methods avoid additional optimization by directly inverting the image-to-primitive aggregation used during rendering. Occam’s LGS (Cheng et al., 2025), CosegGaussians (Dou et al., 2025), and
DrSplat (Jun-Seong et al., 2025) independently use row-normalized splatting equations as zero-shot feature
lifter.

Semantic Foam (Sharafeldin et al., 2026) jointly learns reconstruction and object-identity features

effect of the underlying representation on lifting to be isolated from semantic optimization. Building on this
setting, we introduce OV-Foam, an open-vocabulary 3D segmentation framework that lifts 2D vision-language
features onto PowerFoam reconstructions.
3
Method
OV-Foam lifts image features onto a PowerFoam reconstruction. We first describe how the cells define
rendering contributions, then use those contributions in the SFS feature estimator. We then examine how
image observations are distributed across primitives and whether each primitive receives consistent features
from one class or conflicting features from several classes.
3.1
PowerFoam
PowerFoam represents a scene with a power diagram (Govindarajan et al., 2026). Each primitive j is
associated with a center pj and radius aj . For a 3D point x, its power cell Vj is the region where primitive j
has the smallest power distance among all primitives k. The rendering support Cj further restricts this cell to
the primitive’s bounding sphere:
Vj = {x : ∥x − pj ∥2 − a2j ≤ ∥x − pk ∥2 − a2k for all k},
Cj = Vj ∩ Sphere(pj , aj ).
(1)
The power cells partition space, so their interiors do not overlap, although a ray can traverse several cells.
Each primitive is bounded to Cj , so only the portion of its cell inside the bounding sphere can contribute to
rendering.
Within each support Cj , a dipole defines an oriented boundary separating occupied space from empty
space. The dipole provides a planar reference boundary, where occupied space satisfies (x − pj ) · nj < 0,
with nj denoting the outward unit normal and pj the primitive center. A displacement field can deform this
boundary away from the reference plane. For a given ray i, PowerFoam determines the resulting intersections
with both the support Cj and the occupied region. These intersections define the occupied ray segment and
its length ℓij . Density is constant within the occupied region and zero elsewhere. During reconstruction,
primitive centers, radii, densities, dipoles, and enabled displacement parameters are optimized.

lifting ground-truth class masks encoded as text embeddings. Because both reconstructions receive perfect
upstream labels, any difference in the resulting 3D labels proceeds from reconstruction and lifting process,
unaffected by CLIP noise. We then evaluate open-vocabulary segmentation using real SAM/CLIP image
features, testing whether the reconstruction-dependent effects persist under practical, noisy observation
conditions.

Experiments
We evaluate the effect of the reconstruction on feature lifting at three levels. First, we compare the dispersion β
and the fitting gap L(X ′ )−L( b
X) to determine whether the observed differences in β correspond to differences
in the quality of the one-shot lifting solution. We then examine purity and primitive-level prediction accuracy
to determine whether the evidence accumulated by each reconstruction is more class-consistent.
To isolate the effect of the reconstruction from errors in the input image features, we next lift ground-truth
image labels encoded as class text embeddings. This controlled experiment gives both reconstructions the
same correct semantic observations and therefore tests whether differences in the recovered 3D labels arise
from the reconstruction and lifting process itself. Finally, we evaluate CLIP image features, measuring
whether the same differences persist when the lifted observations also contain errors.

For ScanNet, we follow OpenGaussian’s ten-scene point-level evaluation setup (Wu et al., 2024), with
the changes to point assignment and opacity filtering described below. We assign each evaluated point its

Predictions use three different class sets. For PowerFoam, we assign points using the reconstructed surface
inside each cell, represented by its dipole, rather than the cell center alone. This surface can shift during
reconstruction even when the center remains fixed, so the center need not lie in the primitive’s occupied
region (Appendix B.1).

imply better performance on the full scene. We therefore retain all valid labeled ground-truth points for both
representations, so weakly represented regions remain part of the segmentation task. Under this common

measurements identify differences in how the representations distribute and combine image evidence. The
CLIP feature benchmarks establish that replacing Gaussians with PowerFoam can turn those representation
differences into better open-vocabulary segmentation, even when the input features remain imperfect.

Limitations and conclusion
Our ScanNet experiments cover ten scenes and initialize both representations from the same point cloud
through the SfM initialization pipeline. For this benchmark, the supplied point cloud is the ground-truth
geometry provided by ScanNet rather than an image-derived SfM reconstruction. The ground-truth lifting
experiment isolates errors that remain with correct image labels, but does not establish an upper bound over
all lifting methods. Our fitting-gap analysis concerns feature reconstruction loss rather than segmentation
accuracy, and high purity can still reflect consistently incorrect observations. The observed advantages
therefore depend on the reconstruction, input features, and evaluation setting.
We investigated how the choice of reconstruction primitives affects feature lifting. Under matched
reconstruction budgets, PowerFoam has fewer contributors per ray and lower measured dispersion than 3DGS,
while placing more evaluated points on primitives with high-purity evidence. Its one-shot estimate is closer to
its least-squares reference, and lifting correct image labels produces more accurate 3D segmentation. These
advantages extend to real image features, adapting existing lifting methods to PowerFoam improves the
tested ScanNet and LERF segmentation results. Together, these findings establish representation choice as a
practical way to improve semantic lifting without requiring more accurate upstream image features.

ScanNet evaluation protocol
We follow OpenGaussian’s ten-scene point-level evaluation setup (Wu et al., 2024). For our matched
reconstructions, both representations start from the same ground-truth vertices, with one primitive per
vertex. Primitive centers and counts remain fixed during reconstruction, while the remaining reconstruction
parameters are optimized. We then hold the reconstruction fixed during feature lifting.
We assign semantic labels by maximum cosine similarity to the class text embeddings and report mIoU
and mAcc for the 19-, 15-, and 10-class evaluations. Within each scene, these metrics average class IoU and
class recall over the valid ground-truth classes present. Final scores average the scene results.
B.1
Dipole-aware point assignment
For OV-Foam, point ownership uses the reconstructed dipole geometry. A fixed initialization center need
not lie on the occupied side of its primitive’s displaced surface. For each evaluation point q, we take the 64
Euclidean-nearest supported primitive centers and rank them by power distance ∥q − pj ∥2 − a2j . We select
the first candidate satisfying (q − pj ) · nj ≤ hj (q), where hj (q) is the interpolated dipole height at the point’s
tangent-plane coordinates. This test checks the occupied side of the dipole surface.
If no candidate passes, we use the minimum power distance in the same pool. The fallback preserves
assignment coverage, so the dipole test does not discard points. Power distances are evaluated in double
precision. The finite candidate search approximates global power-distance ranking.
