# Getting Started

1. Visit [volumeshader.org](https://volumeshader.org)
2. Choose the appropriate tool based on your needs and hardware capabilities:
   - Use **Volume Shader** for standard rendering tasks
   - Use **Volume Shader BM** for advanced benchmarking on high-end devices
   - Use **Mass Volume Shader BM** for extreme stress testing on workstations/servers

# Overview

A comprehensive browser-based platform for real-time volume rendering, GPU performance testing, and interactive shader experimentation. No installation required—experience cutting-edge graphics technology directly in your browser.

VolumeShader.org provides a suite of tools designed for graphics developers, game engineers, learners, and hardware enthusiasts. 

You can real-time volume rendering and GPU benchmarking with three specialized tools to accommodate different performance needs and use cases.

# Available Tools

## 1. Volume Shader

A standard volume rendering tool that:
- Uses moderate GPU resources, suitable for most computers and mobile devices
- Provides real-time 3D volume rendering
- Includes dynamic lighting and shading
- Features adaptive complexity based on device performance
- Supports WebGL 2.0
[![Volume Shader](https://volumeshader.org/volumeshader.webp)

## 2. Volume Shader BM

An advanced benchmarking tool that:
- Delivers more demanding tests requiring higher GPU performance
- Is ideal for high-end gaming PCs and mobile devices
- Visualizes complex 3D fractals in real-time
- Allows interactive shader code tweaking
- Provides trigonometric and inverse trigonometric function visualization
- Includes an interactive CONFIG panel for live shader editing
[![ Volume Shader BM](https://volumeshader.org/volume-shader-bm.webp)

## 3. Mass Volume Shader BM

The most demanding test in our suite:
- Requires very high GPU performance
- Is suitable for servers and workstations
- Provides extreme stress testing capabilities
- Features multiple intensive rendering operations
- Includes memory bandwidth analysis
- Offers thermal and stability monitoring
[![Volume Shader](https://volumeshader.org/mass-volume-shader-bm.webp)

## Key Features

- **100% Browser-Based**: No installation required—works on desktop and mobile
- **Real-Time Rendering**: Instant visual feedback for all operations
- **Interactive Controls**: Tweak parameters and see results immediately
- **Performance Metrics**: Real-time FPS and GPU usage monitoring
- **Custom Shader Support**: Edit and experiment with shader code
- **Cross-Platform**: Compatible with modern browsers on any device
- **Educational Resources**: Learning materials for volume rendering techniques
