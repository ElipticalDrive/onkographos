Motivation
Provide a single, runnable example that strings together the full 3D reconstruction stack from preprocessing through meshing and postprocessing.
Make it easy to run common workflows (point-cloud fusion or TSDF fusion) with configurable registration and fusion options.
Offer a CLI-driven orchestration layer to standardize I/O, logging, and intermediate result export for downstream use.
Description
Add pipeline_3d_reconstruction.py, a standalone executable that implements preprocessing (voxel_downsample, remove_outliers, estimate_normals), coarse global registration (compute_features, global_registration using FPFH+RANSAC), and local refinement (run_icp, run_gicp, run_colored_icp).
Implement fusion options including point-cloud fusion (fuse_point_cloud, run_pointcloud_fusion) and TSDF fusion (integrate_tsdf, run_tsdf_fusion) plus mesh extraction via Poisson (poisson_reconstruction) and TSDF (extract_mesh_from_tsdf).
Add mesh postprocessing utilities (smooth_mesh, remove_degenerate_faces, repair_holes) and utilities for pose accumulation (accumulate_poses), registration orchestration (register_sequence), and result saving (save_outputs).
Expose configuration and runtime controls via a CLI (--inputs, --fusion-mode, --registration-mode, --skip-global, --rgb-dir, --depth-dir, --intrinsics-json, etc.) and add dependency checks for numpy and open3d in require_open3d().
Testing
Ran python -m py_compile pipeline_3d_reconstruction.py to verify syntax and it succeeded.
Ran python pipeline_3d_reconstruction.py --help to verify CLI parsing and it succeeded.
No runtime data tests were executed in CI because the script requires external point cloud / RGB-D inputs and open3d at runtime.
