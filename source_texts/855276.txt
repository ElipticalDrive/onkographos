# LiDAR-Based Object Detection and Tracking with Enhanced ROI Filtering

[![ROS Version](https://img.shields.io/badge/ROS-Noetic-green)](https://wiki.ros.org/noetic)
[![Language](https://img.shields.io/badge/language-C++-blue)]()
[![Dataset](https://img.shields.io/badge/dataset-KITTI-orange)]()
[![Course](https://img.shields.io/badge/course-AENG%20563-lightgrey)]()

This project implements a LiDAR-based object detection and tracking pipeline in ROS Noetic, tested on multiple KITTI raw datasets. 
Built on top of the baseline detection and tracking framework, it includes individual enhancements to the ROI filtering pipeline and systematic parameter tuning for both detection and tracking modules.

---

## Project Structure

This project has two components:

	1. Baseline object detection and tracking pipeline setup, KITTI dataset conversion to ROS bag format, and demo runs across three KITTI scenarios (Road, Residential, Person).

	2. Enhanced ROI preprocessing pipeline in `roi.hpp` with Statistical Outlier Removal (SOR), Voxel Grid Downsampling, and Passthrough Filtering, along with detection and tracking parameter optimization.

---

## Pipeline Overview

```
LiDAR Point Cloud (ROSBag)
        │
        ▼
ROI Filtering (roi.hpp)
  ├── Statistical Outlier Removal (SOR)
  ├── Voxel Grid Downsampling
  ├── Passthrough Filtering
  └── Cylindrical / Square ROI Filter
        │
        ▼
Ground Removal
  ├── GroundPlaneFittingSegmenter
  └── GroundRANSACSegmenter
        │
        ▼
Non-Ground Segmentation
  ├── RegionEuclideanSegmenter
  └── EuclideanSegmenter
        │
        ▼
Object Tracking (Hungarian Matcher + Robust Kalman Filter)
        │
        ▼
RViz Visualization (Bounding Boxes + Trajectories)
```

## How to use

## [Parameters](./launch/demo.launch)
　*detection.yaml* and *tracking.yaml* configure the detection_node and tracking_node in sample. *kitti/\*.yaml* configure the algorithm parameters for KiTTI Dataset, *Segmenter.yaml* and *TrackingWorker.yaml* separately for **Seg-based Segmentation**, **Tracking**.
```bash
./config
├── detection.yaml
├── kitti
│   ├── Segmenter.yaml
│   └── TrackingWorker.yaml
└── tracking.yaml
```
