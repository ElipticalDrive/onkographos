# C++ CPU Ray Tracer

A small CPU-based ray tracer written in C++17 as a graphics-programming learning project. It renders a pinhole-camera view pixel by pixel and writes the result as a PPM image.

## Implemented

- Custom three-dimensional vector type and arithmetic operators
- Dot products, cross products, vector normalization, and ray evaluation
- Pinhole camera and viewport construction
- Analytic ray-sphere intersection testing
- Surface-normal visualization and a sky gradient
- Portable PPM image output

## Build and run

Requirements: a C++17-compatible compiler and `make`.

```sh
make
make run
```

The rendered image is written to `image.ppm`.

## Project structure

- `main.cpp` — camera setup, rendering loop, intersection test, and pixel shading
- `vec3.h` — vector and point mathematics
- `ray.h` — ray representation and evaluation
- `color.h` — conversion from floating-point colors to PPM output
- `hittable.h` — interface for future scene objects
