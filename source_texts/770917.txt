Replaces Julian Seward's 1996 ternary quicksort (mainSort) and fallback Larsson-Sadakane suffix sort (fallbackSort) with a clean 288-line Two-Stage Induced Suffix Sorting (DivSufSort) engine.
Key Highlights:
Linear-Time Induction: Induces sorted orders for S-type and L-type suffixes in two sequential passes without recursive call stacks.
Radix Pre-sorting: 2-byte radix bucket sort (65,536 buckets) for B* suffixes with AVX2-accelerated slice.cmp string comparison and 64-bit word-parallel LMS bitmask extraction (w & !prev_w).
Memory Safety: 100% safe Rust under #![forbid(unsafe_code)] with zero unsafe blocks.
Allocations: Zero heap allocations; operates strictly within existing EState arr1 (ptr) and arr2 (block + quadrant) buffers (no_std compliant).
Code Footprint: -2,084 net lines removed compared to the original 1996 C-style sorting implementation.

I have updated this PR to address the throughput regressions on repetitive 16-bit raster data (mr -10.5% and x-ray -5.1%) identified in the initial submission.
What Changed
In the initial implementation, suffixes within the same 2-byte bucket were sorted using standard library slice sorting (sort_unstable_by). On structured text, this was fast, but on repetitive data, it repeatedly re-compared identical prefixes across quicksort partitions.
To resolve this, this update introduces:
16-Bit Multi-Key Ternary String Quicksort (ssort_bstar): Sorts B* suffixes by comparing 16-bit words (u16_at, median_u16). On the equal partition (w == pivot), the comparison depth is advanced by 2 bytes without rescanning already matched prefixes. Small partitions ($\le 16$ suffixes) drop down to an inlined insertion sort.
64-Bit Word Comparisons in compare_cyclic_suffixes: Tie-breaking uses u64::from_be_bytes to check 8 bytes per iteration.
Subtractive Cyclic Bounds: Replaces expensive modulo % n operations in hot loops with subtractive bounds checks (if cur_a >= n { cur_a -= n; }) and bit shifts (>> 6, & 63).
Specialized Pair Swap: Fast-paths 2-element buckets (count == 2) with a single conditional branch.

…vSufSort

Replaces Julian Seward's 1996 ternary quicksort (mainSort) and fallback
Larsson-Sadakane suffix sort (fallbackSort) with a clean, foundational
implementation of Two-Stage Induced Suffix Sorting (DivSufSort) for BWT
in pure safe Rust (#![forbid(unsafe_code)]).

Algorithmic Design (Yuta Mori, 2005):
1. Cyclic S/L Classification: Scans the block to label cyclic suffixes
   as S-type (lexicographically smaller than suffix i+1) or L-type
   (larger than suffix i+1) stored in a compact bitset.
2. B* Suffix Extraction & Sorting: Identifies Type B* suffixes (S-type
   suffixes preceded by an L-type suffix) and sorts them lexicographically.
3. Two-Stage Induction:
   - Forward pass: Scans left to right, inducing sorted order for all
     L-type suffixes from already-placed suffixes.
   - Backward pass: Scans right to left, inducing sorted order for all
     S-type suffixes.
4. Sentinel-Free & Safe: Operates entirely within existing EState arr1
   and arr2 buffers without heap allocations or unsafe pointer arithmetic.

Note on test log expectations:
- Updates tests/compress-sample1-log.txt and tests/quick.rs to remove
  legacy Seward -vvvv quicksort recursion traces (e.g. "qsort [0xXX, 0xYY]")
  and fallback sort trigger strings, preserving strict commit bisectability.

Optimizes the Two-Stage Induced Suffix Sorting (DivSufSort) engine by
replacing standard B* suffix comparison with high-throughput string sorting
and word-level cyclic tie-breaking:

1. 16-Bit Multi-Key Ternary String Quicksort: Suffixes partitioned into
   2-byte radix buckets (bstar_ftab) are sorted using a 3-way ternary
   quicksort operating on 16-bit words (ssort_bstar with u16_at and

Reviewing with the LLM it appears this change would require relaxing the fuzzing requirements at least some. I tried to break it up a bit more.
test(fuzz): assert bidirectional cross-decompression in compress_then_decompress (afa6976):
Updates the fuzzer from demanding exact byte-for-byte binary identity with reference C bzip2 (assert_eq!(deflated,
deflated_c)) to bidirectional cross-decompression (decompress_c(deflated_rs) == original and decompress_rs(deflated_c) == original).
Why: In bzip2, inputs with periodic cyclic symmetries (e.g. [10, 1, 10, 1]) have multiple valid BWT permutations. Different suffix sorters can choose different conjugate rows for origPtr while yielding identical BWT columns, identical compression ratios, and 100% lossless decompression.
Establishing this contract first ensures all subsequent commits are continuously green in CI.
perf(blocksort): replace legacy quicksort with base safe Rust DivSufSort (0e9d603):

Deletes ~1,200 lines of quicksort/fallbackSort code.
Covers: cyclic S/L classification, B* suffix extraction, standard B* sorting, and L-forward / S-backward induction passes.
Updates verbose test log expectations to preserve commit bisectability.
