What to build
Evaluate pre-trained Zstandard (RFC 8878) compression dictionaries for high-repetition IELTS evaluation JSON payloads (150KB-500KB) to reduce egress network bandwidth by up to 85% and accelerate client delivery over mobile networks.
IELTS Writing and Speaking evaluation responses contain highly repetitive JSON field keys, rubric descriptors, and standardized feedback templates (task_achievement, coherence_and_cohesion, grammatical_range_and_accuracy, lexical_resource, suggestions, rubric_criteria). Standard dynamic compression (Gzip/Brotli) on isolated small payloads achieves sub-optimal compression ratios because the sliding window cannot leverage shared domain vocabulary.
Evaluating pre-trained Zstandard dictionaries provides:
Pre-baking a compact ~32KB dictionary (ielts_schema_v1.dict) trained on representative grading payloads.
Embedding dictionary support into Fastify HTTP response compression (zstd: { dictionary }) and client apps.
Compressing long evaluation JSON payloads by up to 85% (reducing 50KB-100KB payloads down to 7KB-15KB), significantly cutting cloud egress network costs and improving mobile Time-to-Interactive.
Acceptance criteria
Train a Zstandard dictionary using a sample corpus of 500 representative IELTS evaluation payloads.
Benchmark compression ratio, CPU encode/decode throughput, and payload transfer size comparing Zstandard dictionary vs. standard Gzip/Brotli.
Verify HTTP content negotiation: clients passing Accept-Encoding: zstd negotiate dictionary-backed payloads safely with fallback to gzip for legacy clients.
Record benchmark numbers and client integration recommendations in an ADR linked to API: evaluate HTTP conditional requests and ETags to eliminate redundant JSON payload re-transfers #1053 and Performance: evaluate zero-deserialization binary buffers for static metadata to eliminate V8 GC pauses #1062.
Blocked by
None - can start immediately. Complements #1053 and #1062.

Architectural Guidance: Pre-Trained Zstandard Compression Dictionaries for JSON
Maximizing network and storage efficiency:
Dictionary Training: Train a 110KB Zstandard dictionary (zstd --train) on 1,000 historic IELTS JSON responses.
Compression Ratio: Compressing small, repetitive JSON structures with a pre-trained dictionary achieves > 85% compression (shrinking 50KB payloads to < 5KB) with sub-millisecond decompression times.
