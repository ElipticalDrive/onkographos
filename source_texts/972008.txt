Contains :
3-pass pipeline :
OPAQUE - Depth test ON - Depth write ON - Blending OFF
CUTOUT (vegetation) - Depth test ON - Depth write ON - Blending OFF - Alpha discard in shader
TRANSLUCENT (water) - Depth test ON - Depth write OFF - Blending ON (SRC_ALPHA, ONE_MINUS_SRC_ALPHA) - Sorted far → near
Meshing :
Greedy meshing for terrain (fully working)
Separate mesh buffers per render layer - Chunk meshes cached and reused
Async chunk mesh with textures
frustum culling
Vegetation rendered as cross-quads (billboards) in CUTOUT
Vegetation blocks are not cubes
Water top faces are slightly lower than full block height (Minecraft-style)
Vertex Format :
7 floats per vertex** (locked for now
Also contains, atmospheric fog, day/night cycle, distance-based fog (linear), Altitude-aware fog start & range, Fog color blends smoothly into the sky and Fog hides far cutoff cleanly.
