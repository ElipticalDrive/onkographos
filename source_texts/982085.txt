New package @papit/marching-cubes (packages/algorithms/marching-cubes). Pure. Smooth surfaces from a scalar field (terrain, caves, blobs), built on @papit/corner-lookup (#203). Output is flat typed arrays (positions, normals, indices), compatible with game-mesh Mesh. Part of #207.
Tasks
Scaffold. Marching squares (2D contours) on the corner table.
Marching cubes: field + iso level -> triangles, edge interpolation, shared vertices, normals from field gradient.
Resolve ambiguous cases (consistent triangulation, no holes).
Optional: warp output into irregular grid cells (same bilinear warp as structure) for organic terrain.
Tests: closed sphere has no holes, determinism, vertex count bounds.
README (complexity), CATALOG.
