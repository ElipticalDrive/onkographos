One of the refinement criterion in CheckForRefinement is based on the velocity gradient. However, the MeshRefinement constructor incorrectly overwrites the density refinement criterion when the velocity gradient is specified:
```
    if (pin->DoesParameterExist("mesh_refinement", "dvel_max")) {
      dd_threshold_ = pin->GetReal("mesh_refinement", "dvel_max");
      check_cons_ = true;
    }
```
Moreover, the logic to check for dvel_max is missing in CheckForRefinement. This seems to be an easy fix for someone who wants to gain experience developing AthenaK.
