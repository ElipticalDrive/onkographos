This pull request introduces significant enhancements to the ray tracing system, including new features for materials, lighting, and scene management, as well as improved documentation and functionality for existing components. The most important changes focus on expanding material and lighting capabilities, introducing a Scene class for better organization, and updating the WhittedTracer to use the new scene structure.
Material Enhancements:
ray_tracer/include/LambertianMaterial.h: Added a new LambertianMaterial class implementing the Phong illumination model, including ambient, diffuse, and specular components, with detailed documentation and references.
ray_tracer/include/Material.h: Introduced methods for refraction (refract), Fresnel reflectance (schlickApproximation), and updated the shade method to include the Scene parameter for improved lighting calculations. [1] [2]
Lighting Enhancements:
ray_tracer/include/PointLight.h: Added a new PointLight class representing omnidirectional light sources, including methods for calculating intensity, direction, distance, and shadow checks.
Scene Management:
ray_tracer/include/Scene.h: Introduced a Scene class to encapsulate entities and lights, providing methods for shadow checks and ray-object intersection tests.
Updates to Ray Tracing:
ray_tracer/include/WhittedTracer.h: Refactored WhittedTracer to use the new Scene structure, simplifying light management and improving integration with materials and shadows. Removed redundant methods for direct lighting, reflection, and refraction. [1] [2]
Documentation Improvements:
Enhanced comments and documentation across multiple files (Camera.cpp, Vec3.h, Interval.h) to clarify functionality and improve maintainability. [1] [2] [3] [4]
