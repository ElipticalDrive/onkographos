After you download the binvox, change this line to the executable binvox program. Then run
```
python voxelize.py -s {path-to-your-mesh-file} --res 128 --n_scales 6 -o {save-path.h5}
```
This processes the mesh file (in .stl or .obj format) to .h5 format.
