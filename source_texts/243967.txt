Opening SPZ and SOG files is about 2.5x faster, and SPZ export is 2.6x faster. What gets loaded is bit-identical to before.
classroom (3.34M splats, SH3, RTX 4080)

What was slow: every temporary host buffer went through the pinned allocator, which rounds sizes up to power-of-two buckets and pins pages at roughly 1 GB/s behind a global lock. Pinning only pays off where a copy overlaps an explicit stream, which none of these transient buffers do.
What changed:
SPZ/SOG loaders and exporters, the SH host unpack and the checkpoint serializer's fallback now use plain pageable host memory. The .licht staging path, the training snapshot ring and cached image uploads keep pinned memory because they do overlap copies.
SPZ export uses zstd level 9 instead of 12 (twice the throughput, file +1.3%), splits the worker budget across the six streams by size, and unpacks SH on the GPU like the PLY exporter.
SPZ load decompresses the six streams concurrently and unpacks in parallel straight into pre-faulted tensors. SOG load reads the zip once, decodes the seven WebP images concurrently and dequantises in parallel.
Verification: tensors loaded from SPZ and SOG hash identically to the previous loaders; a regression test asserts SPZ bit-identity with the reference path; the five non-SH SOG images are byte-identical; 190 SPZ/SOG/serialization/checkpoint gtests pass. Numbers above were measured on the rebased branch and current master in the same session.

Pull request overview
This PR optimizes SPZ and SOG import/export hot paths by avoiding pinned host allocations for transient buffers, increasing parallelism in (de)compression and decoding, and adding a bit-identity regression test to ensure the new direct-unpack paths match the existing reference decoding.
Changes:
SPZ load/export now decodes/encodes through packed streams and unpacks directly into pageable host tensors (with prefaulting), and export defaults to zstd level 9 with improved worker budgeting.
SOG load reads the archive once, decodes WebP images concurrently, and reconstructs splat tensors via pageable host buffers before upload.
Adds a test that requires direct unpack output to be bit-identical to the GaussianCloud reference for each attribute.
