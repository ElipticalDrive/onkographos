it depends on your camera.model. the script is accessing 4 params because it assumes the camera.model is "PINHOLE".
Now that you are using "SIMPLE_PINHOLE", you only need to access 3 params.
you can make K[0, 0] and K[1, 1] both = cameras[1].params[0]
the correct code may look like:
K[0, 0] = cameras[1].params[0]
K[1, 1] = cameras[1].params[0]
K[0, 2] = cameras[1].params[1]
K[1, 2] = cameras[1].params[2]

You should not have to change the model from SIMPLE_PINHOLE to PINHOLE. Just, as as @chenbixuan2017 mentioned, you have to change this:
K[0, 0] = cameras[1].params[0]
K[1, 1] = cameras[1].params[1]
K[0, 2] = cameras[1].params[2]
K[1, 2] = cameras[1].params[3]
To this:
K[0, 0] = cameras[1].params[0]
K[1, 1] = cameras[1].params[0]
K[0, 2] = cameras[1].params[1]
K[1, 2] = cameras[1].params[2]
This way you access the parameters of a SIMPLE_PINHOLE: f, cx, cy.
