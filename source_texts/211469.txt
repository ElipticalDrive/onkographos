# NeRF Novel View Synthesis

PyTorch reproduction of Neural Radiance Fields (NeRF) for 3D scene representation and novel view synthesis on the Blender Lego dataset.

The project implements the core NeRF pipeline: positional encoding, camera ray generation, stratified sampling, differentiable volume rendering, hierarchical importance sampling, and coarse/fine MLP networks. The final model synthesizes unseen viewpoints of the Lego scene and reaches approximately 24.4 dB PSNR in the reported experiment.

![Rendered NeRF result](imgs/demo.png)

Demo video: [Lego spiral render](assets/lego_spiral_rgb.mp4)

## Highlights

- Implemented sinusoidal positional encoding for 3D points and viewing directions.
- Built coarse and fine NeRF MLPs with skip connections and view-dependent color prediction.
- Implemented camera ray generation, NDC projection, stratified sampling, and volume rendering.
- Added hierarchical importance sampling to refine samples around high-density regions.
- Trained and rendered the Blender Lego scene with GPU acceleration.
- Evaluated novel-view quality with PSNR and visual inspection.

## Method

NeRF represents a scene as a continuous function that maps a 3D coordinate and viewing direction to volume density and RGB color. For each target image, rays are generated from the camera intrinsics and pose, then sampled at multiple depths. The sampled points are encoded with sinusoidal positional features and passed through MLP networks. Raw density and color predictions are integrated along each ray using alpha compositing to produce the final rendered pixel color.

This implementation uses a coarse network to estimate initial sample weights and a fine network to resample more densely near important scene regions.

## Results

Experiment summary:

| Setting | Value |
| --- | --- |
| Dataset | Blender Lego |
| Framework | PyTorch |
| Training iterations | 5000 |
| Coarse samples | 64 |
| Fine samples | 128 |
| Network depth | 4 |
| Network width | 256 |
| Resolution | Half resolution |
| Final PSNR | ~24.4 dB |

Rendered outputs and checkpoints were produced during training. The final render preserves the overall Lego geometry, color structure, and viewpoint consistency, while some fine details remain blurred because of the reduced network depth and limited training budget.

The experiment write-up is included at [docs/report.pdf](docs/report.pdf).

## Setup

Create an environment with Python 3.8+ and install the required packages:

```bash
pip install -r requirements.txt
```

Download the example NeRF datasets:

```bash
cd nerf
chmod +x download_example_data.sh
./download_example_data.sh
```

## Training

From the `nerf` directory:

```bash
python run_nerf.py --config configs/lego.txt
```

The default Lego config uses half-resolution images, view directions, white background compositing, 64 coarse samples, and 128 fine samples.

## Rendering

To render from a trained checkpoint:

```bash
python run_nerf.py --config configs/lego.txt --render_only
```

Outputs are written under the configured log directory.
