Summary
Fixes movement, terrain clipping, and a major performance regression introduced in v1.5.2.
Root cause of perf hit (v1.5.2)
The propagateDirtyFlags loop marked every neighboring chunk dirty in a cascade, often remeshing the entire loaded region repeatedly. Combined with per-chunk materials and logarithmicDepthBuffer, this tanked mobile FPS and caused stutters that coincided with weather changes.
v1.5.3 fixes
Performance
Remove dirty-flag cascade; only remesh chunks that actually changed
Reload chunk data only when the player crosses a chunk boundary
Budget remesh work to 2–4 chunks/frame (scales up when backlog is large)
Single shared material for all chunk meshes
Remove logarithmic depth buffer; use polygon offset + higher near plane instead
Fewer weather particles on mobile; cached colors; 4-second weather transitions
Clipping
Camera pulls down toward feet when blocked (v1.5.2 lifted into ceilings — made clipping worse)
Depenetration only runs when the player is actually overlapping blocks
peekBlock in collision checks avoids creating orphan chunks
Movement (from v1.5.1)
Fixed double-dt horizontal velocity bug
How to test
HUD shows v1.5.3
FPS should be stable 50–60 on mobile; no stutter when weather changes
Walk hills and chunk borders — camera stays outside terrain
Movement feels normal with WASD/joystick
Fix perf regression and clipping: budgeted remesh, shared material

Performance:
- Remove propagateDirtyFlags cascade that remeshed entire regions every frame
- Only reload chunks when player crosses chunk boundary
- Budget remesh work to 2-4 chunks/frame (adaptive when backlog is large)
- Share one MeshLambertMaterial across all chunk meshes
- Remove logarithmicDepthBuffer (expensive on mobile GPUs)
- Use peekBlock in collision to avoid orphan chunk creation
- Reduce weather particles on mobile, cache Color objects, smooth 4s transitions

Clipping:
- Fix camera pull-down toward feet instead of lifting into ceilings
- Use polygonOffset on terrain to reduce z-fighting without log depth
- Simpler collision: depenetrate only when actually overlapping
- Raise camera near plane to 0.25

Bump build to v1.5.3

Co-authored-by: Kurtis Rogers <kurtmcmurt@gmail.com>
