Added several creative features to enhance the voxelizer's capabilities without constraints.
Twist Deformation (--twist): Added a geometric transformation that rotates points around the Y axis proportional to their Y coordinate, creating spiral and drill-like deformations on standard meshes.
Lattice Infill (--lattice spacing,thickness): Added a procedural structural modifier that hollows out meshes leaving only a 3D grid pattern (using modulo arithmetic filtering).
ASCII Terminal Preview (--ascii-preview): Implemented a fast 2D X-Z plane projection of the voxel data directly to the terminal using block characters, providing instantaneous visual feedback.

Reject non-positive lattice parameters before filtering
The lattice filter assumes positive spacing and thickness, but --lattice currently accepts any floats; with a negative thickness, thickness * 0.5 is negative and mx/my/mz are always non-negative, so this condition becomes true for every candidate voxel and empties the output unexpectedly. Similarly, zero/NaN spacing feeds rem_euclid invalid values and produces non-sensical keep decisions. Please validate lattice inputs (finite spacing > 0 and thickness > 0) before entering this branch so bad CLI values fail fast instead of silently corrupting results.
