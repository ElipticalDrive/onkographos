Adds an RGB variant of the probabilistic map and a matching ROS 2 node, alongside the existing monochrome ones rather than replacing them.
ColorProbabilisticMap: stores an RGB triplet per voxel next to the log-odds occupancy value, updated from PCL point types that expose r/g/b members (e.g. pcl::PointXYZRGB).
ColorBonxaiServer: registered as the composable node bonxai_server::ColorBonxaiServer and built as the color_bonxai_server_node executable, with color_bonxai_mapping.launch.py to bring it up.
bonxai_params.yaml gains a color_bonxai_server_node section; the existing bonxai_server_node section is untouched.
The new files are mainly similar to the existing ones, changes are only added to the update rule (averaging the color values), adding the color field (RGB) to the cell type, and adding color to the published point cloud.
```
template <typename PointT, typename Alloc>
inline void ColorProbabilisticMap::insertPointCloud(
    const std::vector<PointT, Alloc>& points, const PointT& origin, double max_range) {
  const auto from = ConvertPoint<Vector3D>(origin);
  const double max_range_sqr = max_range * max_range;
  for (const auto& point : points) {
    const auto to = ConvertPoint<Vector3D>(point);
    const Color color = ExtractColor(point);
    Vector3D vect(to - from);
    const double squared_norm = vect.squaredNorm();
    // points that exceed the max_range will create a cleaning ray
    if (squared_norm >= max_range_sqr) {
      // The new point will have distance == max_range from origin
      const Vector3D new_point = from + ((vect / std::sqrt(squared_norm)) * max_range);
      addMissPoint(new_point);
    } else {
      addHitPoint(to);
      updateColor(to, color); // <--- The main addition. alongside the color field in the cell.
    }
  }
  updateFreeCells(from);
}
```
