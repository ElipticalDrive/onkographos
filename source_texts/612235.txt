Summary
Implements the seven-step efficiency rearchitecture for Voxy’s LOD core:
Sparse brick + occupancy bitset — WorldSection now stores voxels in SparseBrick (EMPTY / SPARSE / DENSE) with a 32³ OccupancyBitset instead of always allocating dense long[32768] (256 KiB).
Delta mip / dirty invalidation — ingest writes only the touched mip sub-region; DirtyInvalidator coalesces dirty section keys; content generation counters track changes.
Bitset mesher + face-plane neighbors — mesh prepare skips empty occupancy words; neighbors are pulled via 32×32 face extraction instead of materializing full neighbor dense arrays.
GPU request ring — MAX_REQUEST_QUEUE_SIZE raised 50 → 2048; removed the 10 ms async batch sleep; sync-wait uses short parks.
Page store + batched IO — serialization version 1 sparse pages (occupancy + packed non-air); BatchedPageStore coalesces writes; v0 dense LUT format still loads.
TLSF geometry heap + upload rings — AllocationArena backed by TlsfAllocator; added UploadRing for frame-budgeted uploads.
Mapper / mesh control flow — block/biome registration via ConcurrentHashMap.computeIfAbsent; MeshBuildResult + generateMeshResult reduce exception-driven mesh retries.
Compatibility
Existing on-disk sections (storage version 0) still deserialize.
New/updated sections prefer sparse page format when occupancy ≤ dense threshold.
