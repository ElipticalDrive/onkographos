What this does
Replaces the sine-wave Web Audio synth in src/utils/audio.ts with a sample-based foley engine and generates every sample itself — no third-party audio, no API keys, no new dependencies.
The world is a printed dossier: paper, ink, steel, an old Istanbul tram.
Phase 1 — procedural assets (scripts/generate-audio.mjs)
A deterministic, pure-Node DSP renderer (seeded PRNG, biquads/TV filters, modal synthesis, additive oscillators, Schroeder reverb, tanh saturation, windowed-sinc resampling). Every sound layers a transient, a body and a room tail, with per-variant jitter.
26 SFX voices at 44.1 kHz in audio-src/raw/
public/audio/sfx.wav — one 32 kHz sprite, 100 ms gaps, 1.10 MB, + sfx.json ({ sprite: { name: [startMs, durMs] } })
public/audio/ambience.wav — 30 s seamless loop at −26.0 LUFS, true peak −11.5 dBFS
Phase 2 — numeric verification (scripts/verify-audio.mjs)
158/158 checks pass: manifest, slice bounds, headroom (< −1 dBFS), RMS, DC, attack ≤ 10 ms, spectral centroid (stamp/impact < 800 Hz, paper/air brake > 2 kHz), low-band energy, bell modal ratios 1 : 2 : 2.76 : 5.4 : 8.9 with a live fundamental at +600 ms, variant correlation (< 0.9; worst pair is −0.40), and ambience loudness + loop continuity. Results table in audio-src/VERIFICATION.md.
Phase 3 — runtime engine
src/utils/audio.ts plays the sprite through sfx/ambience buses → master → limiter. The only runtime synthesis is the tram rumble (brown noise, 80 → 380 Hz sweep) because it must follow the real animation length (1.65 s, or 0.42 s with reduced motion).
Choreography, on the audio clock: rumble cut → 80 ms silence beat → impact → stamp at +300 ms → sting at +700 ms. playImpact returns 380 ms so App.tsx reveals the verdict exactly on the stamp; controls stay locked until then.
no AudioContext before the start gesture (the pointerdown/keydown auto-start is gone)
tramvay_sound_enabled kept, tramvay_volume added (default 0.7)
no M listener in the module (App owns the key), no sound inside setState updaters
missing or HTML-masked assets degrade to silence with one warning per item
old module preserved as src/utils/audio.synth.ts (nothing imports it; the bundle contains no createOscillator)
all 27 dilemmas tagged with mood, 4 with comic: true
Phase 4 — verification
tsc --noEmit (also --strict), npm run build, dist/audio/ populated, deterministic rebuild produces no diff. No headless browser exists here, so scripts/smoke-audio.mjs drives the real module against a mocked Web Audio graph and the shipped files: happy path plus three failure modes (missing manifest served as index.html with HTTP 200, missing sprite, real 404).
Review
npm run dev → İkilemlere Başla → listen for: click, room tone, lever clack + bell, rising rumble with shrinking rail clacks, dead air, muffled impact, stamp on the result reveal, verdict sting.
Everything is re-tunable: timings live in AUDIO_TIMING in src/utils/audio.ts, sound design in scripts/generate-audio.mjs. Any single sound can be swapped for a real recording by dropping audio-src/raw/<name>.wav and running npm run audio:repackage.
