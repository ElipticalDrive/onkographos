We provided an overview of the Navier-Stokes equations, which are the basis of fluid simulation models. We reviewed Jos Stam’s „Stable Fluids“ [Sta99] as well as PIC/FLIP [ZB05] methods for fluid simulation. Based on [Ngu07] description of applying Jos Stam’s method for water simulation, we had concerns that issues with volume loss and surface modelling may arise and we chose to use PIC/FLIP instead. We prepared a method to visualise water volume based on particle positions modelled by PIC/FLIP by transforming them into a signed distance field, from which a water surface view can be formed by applying sphere tracing. Finally, we implemented all of it using Vulkan graphics application programming interface, which let us execute the simulation and rendering algorithms using the graphics card. The implemented simulator works in real-time, but the scene complexity is not high either, a small volume of water is simulated. Majority of the execution time is spent on particle conversion to SDF as well as its rendering. Improving on these steps may improve the performance. Memory usage is low, the main limiting factor is execution time. The simulator also has a problem with volume loss over time, however the problem may be resolved using a solution described in [KLT+21]
