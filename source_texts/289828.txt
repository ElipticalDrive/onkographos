Goal (owner, 2026-10-20): make the Spirula video -> 3D Gaussian Splatting pipeline usable from AceTeam flows and the ace CLI now.
Today
The engine is built and validated (feat: Spirula splat engine + reconstruct pipeline (video/frames -> 3DGS .ply), decoupled engine for Braindance S1 #1210, shipped v2.178.0): services/spirula-reconstruct/compose.yml is a sandboxed one-shot container (network_mode: none, read-only, caps dropped). It takes RECONSTRUCT_INPUT (a video or frame dir) and writes a .ply under RECONSTRUCT_OUTPUT/<job id>. On an RTX 3090: SfM 120/120 frames, 300k splats, under 1 GB VRAM.
Nothing dispatches it. There is no job type in internal/jobs/internal/worker. The platform-side lifecycle is aceteam-ai/aceteam#9819 (Braindance S1), which is paused on the Ed25519 manifest vs AEP signing-contract gate.
Scope (v1, decoupled from the Braindance signing contract)
A RECONSTRUCT_SPLAT job type. Input is a node-workspace-relative video or frame directory (same confinement as FILE_FETCH / [aceteam#11260 S9] Sovereign image-to-image and inpaint in the diffusers sidecar (MEDIA_GENERATE tasks) #1314; no URLs). Params map to the compose's quality and fps knobs. Output is the .ply (plus the optional mesh) written to the workspace and returned as a relative path with sha256 and size.
Runs the existing compose service per job, with a unique job id, the long watchdog tier, cancellation that stops the container, and progress events (SfM, then training).
Attach the standard signed v2 work receipt (event-style, fail-closed like FILE_INDEX). The Braindance manifest/keyframe signing stays in aceteam#9819 and can wrap this job later.
Licence label: Spirula is GPL-3.0, run as a separate container (aggregation); show the label, don't enforce it (docs(design): engine, model and module licensing #1368 decisions).
Platform/CLI follow-ups to split after this lands: a flow node "Video to 3D splat" (aceteam), and ace splat <video> [--node] (aceteam-ai/ace).
Acceptance
Hermetic tests for payload validation, path confinement, argv/env construction and receipt binding (no GPU in CI). One real run on a 24 GB node from a short phone video, with timings in the PR.
