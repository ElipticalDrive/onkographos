📝 Walkthrough
Walkthrough
Introduces Gaussian smoothing support for isosurface geometry with a new sigma parameter. Adds EditableRangeSlider and HiddenRenderer JSON Forms components for range value editing and field visibility control. Implements isovalue range validation through new isovalue_min/isovalue_max fields. Backend applies Gaussian filtering on request and includes scipy dependency.
Changes
Cohort / File(s)
Summary
JSON Forms Renderers
frontend/src/components/jsonforms-renderers/EditableRangeSlider.tsx, frontend/src/components/jsonforms-renderers/HiddenRenderer.tsx
New custom renderers for JSON Forms: EditableRangeSlider enables inline editing of min/max/value with slider control; HiddenRenderer hides fields marked with x-hidden schema property.
Isosurface Model & Validation
src/zndraw/geometries/isosurface.py
Added isovalue_min, isovalue_max, and sigma fields to Isosurface model. Introduced post-validation hook to enforce range constraints (min ≤ max and value within bounds). Updated imports for validator support.
API & Sigma Parameter
src/zndraw/routes/isosurface.py, frontend/src/myapi/client.ts
Extended get_isosurface and fetchIsosurface with sigma parameter (range [0.0, 5.0]). Backend applies scipy.ndimage.gaussian_filter when sigma > 0 before mesh extraction.
Frontend Integration
frontend/src/components/three/Isosurface.tsx, frontend/src/utils/jsonforms.ts
Added sigma to IsosurfaceData interface and query propagation. Registered EditableRangeSlider and HiddenRenderer into custom renderers list with appropriate priorities.
Dependencies & Tests
pyproject.toml, tests/test_isosurface.py
Added scipy>=1.12.0 dependency. Comprehensive test suite covering default values, range validation, sigma validation, schema structure, smoothing behavior, and integration endpoints.
