Goals
Provide a renderer-independent screen-to-ray helper so deck.gl and Tangram integrations can share the same viewport and clip-space calculations.
Changes
Add unprojectScreenRay and associated types to @math.gl/geometry/culling.
Accept a caller-supplied column-major inverse clip matrix, top-origin viewport and pixel, with configurable clip-depth conventions.
Return an unnormalized finite near-to-far segment, reject invalid/degenerate matrices and coordinates or an interior homogeneous-w zero crossing, and allow off-viewport positions for callers that need them.
Document coordinate and intersection-distance conventions and test stereo viewport offsets, perspective division, output transforms and invalid inputs.
Validation
Focused Vitest suite: 4 tests passed; the full Node suite passed (22,385 tests).
yarn lint fix, yarn lint, and yarn build passed. The full browser suite passed before the review fix; the latest GitHub headless coverage and all other CI checks pass. A later local full run hit a Chromium request-interception timeout in an unrelated timezone mock; that test and the new helper pass in isolation.
Tangram can adopt this after a math.gl release; this PR does not change Tangram or publish packages.
