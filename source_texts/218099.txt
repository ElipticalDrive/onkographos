## 📌 Abstract
This repository contains the official implementation for synthesizing 3D Maximum Intensity Projection (MIP) Magnetic Resonance Angiography (MRA) directly from routine T1-weighted MRI scans using deep learning. This computational framework enables non-contrast-enhanced visualization and quantitative characterization of cerebrovascular structures and abnormalities.
