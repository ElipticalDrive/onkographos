Summary
A "Session 3" upgrade to Marcher — SDF Ray Marching Studio (projects/marcher-sdf-q9x3/) that reworks the renderer into a progressive path-tracing-style accumulation engine and clears five of the six remaining backlog items around it. All changes live inside the one project folder.
The headline is a real accumulation buffer: instead of repainting the canvas every frame, the renderer averages many jittered samples into a floating-point ping-pong target, resets the instant the view changes, and converges to a clean image while the scene sits still. That one piece of infrastructure unlocks depth-of-field, area-light soft shadows and temporal anti-aliasing at once.
What's new
Progressive temporal accumulation (src/gl/renderer.ts) — two RGBA16F ping-pong targets fold one jittered sample per frame into a running mean mix(prev, s, 1/(n+1)); a tiny present pass tonemaps it. A per-frame view hash (effective camera + sun + env + every animated node value; post excluded) resets the average the moment anything visible changes, so orbiting/animation stay live at 1 spp and stills refine to a maxSamples cap. Degrades gracefully to the original single-pass direct renderer when EXT_color_buffer_float/the FBO is unavailable or accumulation is off. Uniform locations are now cached per-program.
Depth of field — thin-lens aperture + focusDistance; each sample jitters the ray origin over the lens disc and re-aims at the focal plane → real bokeh.
Area-light soft shadows + temporal AA — a sun angle (angular radius) jitters the light per sample for physical penumbrae; a sub-pixel jitter anti-aliases every edge as it accumulates.
Emissive objects light the scene — emissive nodes act as coloured area lights (inverse-square falloff, N·L, optional visibility ray). World-panel toggle + strength + emissive shadows.
Two new domain modifiers — elongate (stretch per axis) and polar (kaleidoscopic N-sector fold), wired end to end (types → codegen → renderer packing → standalone export → inspector).
Scene JSON import/export to file — src/scene/io.ts (a versioned wrapper over the same sanitiser autosave uses) plus Save/Load toolbar buttons and a file picker.
Presets Aperture (DoF), Lantern (emissive lighting), Gearwork (polar + elongate); a live spp/convergence HUD; refreshed World/Inspector panels and Help overlay.
Testing
node scripts/verify-project.mjs marcher-sdf-q9x3 — scope + conformance + frozen install + lint + tsc + vite build + build-output all pass.
New headless Vitest suite (test/marcher.test.ts, pnpm test): 8 tests machine-check the three generated shader variants for brace/paren/bracket/#version/main balance across every preset, exercise every primitive × modifier codegen combination, assert each domain modifier is wired to its GLSL op, and round-trip scene JSON (wrapped / bare / partial / junk). Tests live outside the app tsconfig, so the build/lint gate is untouched.
See projects/marcher-sdf-q9x3/JOURNAL.md for the full plan and session log.
