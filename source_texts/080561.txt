Capability
A user can generate a tetrahedral volume mesh from a B-rep body in a simulation study and inspect the resulting mesh statistics.
Context
Research ID BL-MSH-01, tier v1. Source: CAD and CAE research, 2026-10-11; ADR-D5; ADR-D8.
Gmsh executed out-of-process via CLI subprocess to produce linear (C3D4) and quadratic (C3D10) tetrahedral volume meshes from B-rep geometry exchanged as STEP.
Audit run 20261017-112015 noted that meshing must be demonstrable with visible node and element statistics before full 3D mesh rendering in BL-MSH-05.
Scope
In scope:
Engine-neutral VolumeMesherProtocol and VolumeMesherActor running Gmsh out-of-process via CLI subprocess.
Binary resolution supporting environment variable MADE_GMSH_PATH, application bundle helper Contents/Helpers/gmsh, homebrew paths (/opt/homebrew/bin/gmsh, /usr/local/bin/gmsh), and $PATH.
Out-of-process execution with process-group isolation (setpgid) and clean two-stage cancellation (SIGTERM, escalating to SIGKILL).
Mesher execution: STEP B-rep export -> Gmsh invocation with element order (1 vs 2) and mesh size parameters -> MSH format parsing -> VolumeMesh structure with SimulationMeshStatistics.
Mesh artifact commitment to package cache (cache/results/<study-id>/mesh.msh).
User-visible trigger in InspectorSimulationMeshView ("Generate Mesh" button) and menu command with progress indicator, error reporting, and display of mesh statistics (node count, element count, tetrahedra count, duration).
License catalog updated with Gmsh license impact (GPL-2.0-or-later out-of-process mere aggregation).
Documentation updates to docs/feature-matrix.md and docs/test-plan.md for MSH-1.
Out of scope:
Global mesh controls (BL-MSH-02).
Mesh quality metrics (BL-MSH-04).
3D Viewport mesh rendering (BL-MSH-05 / BL-MSH-05 Mesh display #278).
Geometry-to-mesh boundary condition association (BL-MSH-06).
Shell and beam meshing (BL-MSH-07).
Hex and swept meshing (BL-MSH-08).
Definition of done
VolumeMesherProtocol and VolumeMesher actor implemented in MadeCore/Simulation/ running Gmsh out-of-process.
Binary resolution checks MADE_GMSH_PATH, app bundle helpers, Homebrew paths, and system PATH, reporting typed CAEErrorCode.mesherBinaryNotFound (or solverBinaryNotFound).
Process-group cancellation terminates Gmsh cleanly without orphan background processes.
MSH output parser converts Gmsh output (MSH 2.2 ASCII or MSH 4) into VolumeMesh and populates SimulationMeshStatistics.
WorkspaceModel exposes generateSimulationMesh(studyId:) and cancellation, persisting mesh.msh in package cache and updating study meshStatistics.
InspectorSimulationMeshView includes "Generate Mesh" action button, execution state feedback, and renders mesh statistics upon completion.
License impact recorded in docs/architecture/adr/ADR-D5-cae-solver-and-mesher-integration.md and LicenseCatalog.
Unit tests verify binary resolver, mesher execution, MSH parser, cancellation, and error cases using mock and fixture STEP files.
Edge cases enumerated below are handled and covered by tests.
swift build and swift test in macos/ are clean, with no new warnings under Swift 6 strict concurrency.
Full existing test suite stays green and no unrelated behavior changes.
No dead code, unreferenced views, or abandoned flags are introduced.
Usable on its own: a user can import/create geometry, add a simulation study, click Generate Mesh, and inspect the resulting mesh statistics.
Matching rows in docs/feature-matrix.md and docs/test-plan.md for MSH-1 are updated in the same change.
Edge cases
Gmsh executable not installed or not in PATH: typed error reported gracefully in UI and study status.
Invalid or empty STEP data: mesher reports CAEErrorCode.meshingFailed with captured stderr diagnostics.
Meshing timeout or user cancellation: process group terminated promptly with SIGTERM/SIGKILL; study status reset or marked cancelled.
Corrupted or unparseable MSH output: parsed gracefully with explicit error rather than crash or hang.
Quadratic (order 2) vs linear (order 1) element generation verified with proper node counts per element.
Zero-volume or degenerate geometry produces clear meshing failure without hanging.
Verification
Unit and integration tests in macos/Tests/MadeCoreTests/VolumeMesherTests.swift.
Model and UI tests in macos/Tests/MadeAppTests/SimulationStudyUITests.swift.
License tests in macos/Tests/MadeCoreTests/LicenseCatalogTests.swift.
Full test suite execution: swift test in macos/.
