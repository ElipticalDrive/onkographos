What this is
The later stages of indirect diffuse lighting after #1553, recorded so they keep one shape.
Version 2 is a world-space probe volume in the same second-order SH format, sampled by world position inside the existing indirectDiffuse(N, worldPos) shader slot. It is what lets interiors receive less sky than open ground. Probes can be baked against world geometry or refreshed by ray queries.
Version 3 is ray-traced or path-traced global illumination writing irradiance the same slot reads. It needs acceleration structure and ray query support in the GPU seam, which no backend has today, and the D3D11 backend never will.
This revisits the scope note in #54, which kept global illumination out without a concrete game pull. Grimhollow indoor lighting is that pull.
Design spec
docs/design/INDIRECT-DIFFUSE-DESIGN-2026-10-24.md, future stages section. Each stage needs its own spec before work starts.
What it is waiting on
Version 1 released and adopted by Grimhollow, then an owner call on when interiors need occlusion.
