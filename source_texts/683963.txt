以下の動画の様なCopernics(COP)上で
SDFをVDB化後、押し出して立体にする方法を解説していこうと思います。

HoudiniのCopernicusでは、画像だけでなくVDBを使った3D形状の処理も行えます。

ただ、VDBを理解するには、最初に**SDF（Signed Distance Field**)という考え方を知っておくと理解しやすくなります。
今回は、SDFの基本から説明していきます。

# SDFとは？
https://www.sidefx.com/ja/docs/houdini/nodes/dop/volume.html

SDFは **Signed Distance Field（符号付き距離フィールド）** の略です。

簡単にいうと、**空間上のある位置から、形状の表面までの最短距離を数値で表現する仕組み**です。

一般的なポリゴンは頂点や面によって形状を表現しますが、SDFでは空間上の位置ごとに距離の値を持つことで形状を表現します。

ここで重要なのは、距離にプラスとマイナスの符号が付いていることです。

| 値 | 意味 |
|---|---|
| マイナス（-） | 形状の内側 |
| 0 | 形状の表面・境界 |
| プラス（+） | 形状の外側 |

つまり、SDFの値を調べれば、その位置が形状の内側なのか、外側なのか、表面からどれくらい離れているのかを判断できます。

### 円を例に考えてみる

半径が2の円を考えます。

- 円の中心：`-2`
- 中心から1離れた内側の位置：`-1`
- 円の境界：`0`
- 円の外側で境界から1離れた位置：`+1`

円の中心からの距離を `r` とすると、この円のSDFは次の式で表現できます。

`SDF = r - 2`

円の内部では値がマイナスになり、円の外側ではプラスになります。

**重要なのは、SDFの値が0になる場所が形状の境界になることです。**

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4289681/16f6ae15-0946-472a-a6cf-fc48f46ab6f1.png)



### SDFは2Dでも3Dでも使える

SDFの考え方は2Dでも3Dでも基本的に同じです。

2Dの場合は円や四角形などの輪郭までの距離を表現します。

3Dの場合は球体や立方体などの表面までの距離を表現します。

例えば、2Dでは画像の各ピクセルにSDFの値を持たせることができ、3Dでは空間を構成するボクセルに値を持たせることができます。

このように、形状を距離の数値として扱えるため、SDFは形状の結合、切り取り、膨張、縮小などの処理に利用できます。

## SDFとVDBの違い

ここで混同しやすいのがSDFとVDBの違いです。

**SDFは形状を距離で表現する考え方で、VDBは3D空間のデータを効率よく格納するための仕組みです。**

VDBにはSDFだけでなく、煙の密度など、さまざまな値を格納できます。

Houdiniでは、SDFを格納したVDBをDistance VDB（SDF VDB）、密度を格納したVDBをFog VDBとして扱うことがあります。

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4289681/9dba58a6-064c-49d0-a46f-5480980eb136.png)


また、Copernicusの `SDF Shape` ノードは2DのSDFをMono画像レイヤとして生成します。これは3DのVDBとは別のデータ形式ですが、形状の境界を距離で表現するという基本的な考え方は同じです。

この違いを理解しておくと、Copernicusで2DのSDFを扱う操作と、3DのVDBを扱う操作を整理しやすくなります。

このノードが出力するのは Mono という形式の画像レイヤです。

Monoは1ピクセルにつき1つの浮動小数点値を保持できるデータ形式です。

通常の画像では、この数値を明るさなどに利用しますが、SDF Shape では形状の境界までの距離を格納します。

* 負の値：形状の内側

* 0：形状の境界

* 正の値：形状の外側

つまり、見た目は2D画像ですが、各ピクセルには距離情報が保存されています。

### Iso Offsetで形状の境界を変更する

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4289681/0c91c9f8-ea5a-48b4-8127-c32054702bd5.png)


SDFでは、形状の表面までの距離が数値として保存されています。

この距離情報を利用すると、形状の境界を簡単に変更できます。

Copernicusの `SDF to Mono` ノードには、`Iso Offset` というパラメータがあります。

`Iso Offset` は、**SDFのどの距離値を境界として扱うかを指定するもの**です。

通常、SDFでは値が `0` になる場所が形状の境界です。

しかし、`Iso Offset` を変更すると、0以外の値を新しい境界として扱えます。

| Iso Offset | 結果 |
|---|---|
| -0.2 | 境界が内側に移動して縮小 |
| 0 | 元の境界 |
| +0.2 | 境界が外側に移動して拡大 |

例えば、半径1の円のSDFは次の式になります。

`SDF = length(P) - 1`

このとき、Iso Offsetを適用した境界は次の条件で決まります。

`SDF = Iso Offset`

つまり、

- `Iso Offset = -0.2` → 半径0.8の円
- `Iso Offset = 0` → 半径1.0の円
- `Iso Offset = +0.2` → 半径1.2の円

となります。

※数値は距離がそのまま座標単位に対応する理想的なSDFを使った例です。

### なぜ形状が大きくなるのか？

SDFでは、境界の外側に正の距離値が保存されています。

例えば、元の境界から0.2だけ外側の場所には、SDF値として `+0.2` が格納されています。

`Iso Offset` を `+0.2` にすると、その位置を新しい境界として扱います。

結果として、形状が外側へ0.2だけ広がります。

反対に、`-0.2` にすると、元の境界から0.2だけ内側の場所が新しい境界になり、形状が縮小します。

### SDFの値自体が変わっているわけではない

ここは重要なポイントです。

`SDF to Mono` の `Iso Offset` では、**入力のSDFを変更せず、どの値を境界として描画するかを変更しています。**

一方、`SDF Adjust` ノードの `Iso Offset` を使うと、SDFフィールドの値そのものをオフセットできます。

元のSDFを `d`、オフセット量を `o` とすると、概念的には次の計算になります。

`d_new = d - o`

このため、新しいSDFで値が0になる場所が変わります。

SDFの距離情報を使うことで、ポリゴンの頂点を直接動かさなくても、形状の膨張・縮小を行うことができます。

この考え方は2DのSDFだけでなく、3DのDistance VDBにも応用できます。

## SDF Blendで形状を結合・切り取る

SDFの特徴の一つに、**距離の値を計算することで形状を結合したり、切り取ったりできる**というものがあります。

Copernicusでは、`SDF Blend` ノードを使うことで、こうした形状の演算が簡単に行えます。

今回は、円と四角形のSDFを使用して、`Union`（結合）と `Subtract`（切り取り）を試してみます。

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4289681/73d1421a-8d7d-4609-9245-71ad9b5fe7cc.png)

### 1. SDF Shapeを2つ作成する

まず、Copernicusで `SDF Shape` ノードを2つ作成します。

**SDF Shape A：円**

- `Shape Class`：Basic
- `Basic Shapes`：Circle

**SDF Shape B：四角形**

- `Shape Class`：Basic
- `Basic Shapes`：Rectangle
- `Round Corners`：0

四角形の `Transform > Translate` を調整し、円と四角形が一部重なる位置に配置します。

この時点では、それぞれのノードが独立した2DのSDFを出力しています。

### 2. SDF Blendに接続する

2つの `SDF Shape` を `SDF Blend` ノードに接続します。

| 入力 | 接続する形状 |
|---|---|
| `sdfA` | Circle（円） |
| `sdfB` | Rectangle（四角形） |

`SDF Blend` の `Fillet` は、まず `None` に設定します。

この状態で `Mode` を切り替えると、結果が変わります。

### 3. Union（結合）

`SDF Blend` の `Mode` を `Union` にします。

Unionは2つの形状を結合する演算です。

円と四角形のどちらかに含まれる領域が、最終的な形状になります。

ここで重要なのは、**SDFでは形状を結合するために距離の値を比較している**という点です。

SDFでは形状の内側が負、外側が正なので、Unionは次の式で表現できます。

`Union = min(dA, dB)`

`dA` は円のSDF値、`dB` は四角形のSDF値です。

`min()` は2つの値のうち、小さい値を返します。

例えば、

- 円のSDF値：`-0.3`
- 四角形のSDF値：`+0.2`

という位置があった場合、

`min(-0.3, 0.2) = -0.3`

となります。

結果が負なので、その位置は結合後の形状の内側になります。

つまり、**どちらか一方でも内側にあれば、結合後も内側になる**という仕組みです。

### 4. Subtract（切り取り）

次に `Mode` を `Subtract` に変更します。

Subtractは、最初の入力であるAから、2番目の入力であるBの形状を取り除く演算です。

今回の場合は、円から四角形の重なっている部分を取り除きます。

SDFでは、次の式で表現できます。

`Subtract = max(dA, -dB)`

`max()` は2つの値のうち、大きい値を返します。

ここでポイントになるのが、`-dB` です。

SDFの符号を反転すると、内側と外側の判定が逆転します。

例えば、

- 円のSDF値：`-0.3`
- 四角形のSDF値：`-0.2`

の場合、

`max(-0.3, 0.2) = 0.2`

となります。

結果が正になるので、元々は円の内側だった位置が、切り取り後には外側として扱われます。

このように、**四角形の内側にある部分を円から取り除くことができます。**

注意点として、Subtractは入力順によって結果が変わります。

- `A - B`：円から四角形を取り除く
- `B - A`：四角形から円を取り除く

Unionとは異なり、入力順が重要です。

### 5. SDF to Monoで結果を確認する

`SDF Blend` の出力を `SDF to Mono` ノードに接続します。

以下のように設定すると、計算結果を白黒の形状として確認できます。

| パラメータ | 値 |
|---|---|
| Draw Shape | On |
| Shape Value | 1 |
| Background Value | 0 |

白い部分が形状の内側、黒い部分が外側になります。

ここで注意したいのは、`SDF Blend` の出力も、まだ**距離情報を持ったMonoレイヤ**だということです。

`SDF to Mono` によって距離の数値を白黒のマスクに変換しています。

### 6. SDF BlendのRe-Normalizeについて

`SDF Blend` には `Re-Normalize` というパラメータもあります。

UnionやSubtractによってSDFを合成すると、生成された値が厳密な表面までの距離ではなくなる場合があります。

`Re-Normalize` を有効にすると、合成後の距離フィールドが再計算されます。

形状を結合・切り取りした後も、距離の値を使って処理したい場合に重要な機能です。
