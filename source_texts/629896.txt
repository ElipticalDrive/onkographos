Adds two recipes:
voxcity 1.9.0 (PyPI, GitHub): generates 3D voxel city models from open geospatial data and exports them to ENVI-met, PALM, OBJ and other formats. Pure Python, noarch: python. I am the upstream author. The test section imports the main modules and runs the voxcity console script.
py-vox-io 0.1 (PyPI, GitHub): a MagicaVoxel .vox reader/writer that voxcity depends on and that is not on conda-forge yet. Pure Python, no dependencies. The PyPI sdist ships no licence file, so the recipe includes the LICENSE (MIT) from the upstream repository. Note that upstream's setup.py still says license='BSD', but the repository's LICENSE file is MIT; I have taken the LICENSE file as authoritative.
Every other voxcity dependency is already on conda-forge. The voxcity build depends on py-vox-io from this same PR.
