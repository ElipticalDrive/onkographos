https://rdc.reed.edu/v1/resources/e0475853-403f-405c-baa0-48bcb46af172/thumb/128.jpgExploring novel worlds in virtual reality is endlessly compelling. To that end, this thesis explored methodology for generating infinite novel landscapes for VR exploration. Terrain generation was achieved using a parallelized implementation of the Marching Cubes algorithm in Unity using compute shaders written in HLSL. These terrains were then made navigable via hand-oriented smooth locomotion through the SteamVR API. The chapters herein are designed to work as a guide for others to build new procedural terrain techniques, for VR and otherwise, using similar methodology
