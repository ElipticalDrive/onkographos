# BlobWorks

![BlobWorks procedural creature cast](docs/screenshots/hero-cast.jpg)

**One shader shell. Infinite anatomy.** BlobWorks is an interactive procedural creature foundry built with React, TypeScript, Three.js, and a custom SDF raymarching shader.

Characters are assembled from spheres and capsules, then fused into a single seamless, toon-shaded surface on the GPU. One procedural motion system drives bipeds, quadrupeds, hexapods, legless hoppers, and winged creatures—without authored skeletons or keyframes.

## Highlights

- **Seamless SDF bodies** — smooth-union primitives produce a soft, unified silhouette instead of a visible pile of shapes.
- **Five body plans** — bipeds, quadrupeds, hexapods, hoppers, and flyers share one generation and animation framework.
- **Procedural motion** — analytical limb solving, gait phases, hops, hovering, flapping, glances, blinks, and waves.
- **Heavy game feel** — springy squash and stretch, landing bursts, footfall dust, camera impact, and poke interactions.
- **Mobile-aware rendering** — automatic compact-device settings plus switchable studio and performance raymarch budgets.
- **Seeded variation** — proportions, anatomy, colors, faces, tails, antennae, and movement emerge from generated parameters.

## Run locally

Requires a current Node.js LTS release and npm.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Drag to orbit, click a creature to poke it, tune the blend and juice controls, or generate a new cast.

For a production check:

```bash
npm run lint
npm run build
npm run preview
```

## How it works

Each creature stores a compact list of sphere and capsule primitives. The fragment shader raymarches their signed-distance fields and combines them with a smooth minimum, which creates the soft blend-shell. A lightweight CPU animation layer updates those primitive endpoints every frame; accessories such as eyes and wings follow the same squash transform so they stay attached to the animated body.

| Area | Responsibility |
| --- | --- |
| [`src/three/BlobWorks.ts`](src/three/BlobWorks.ts) | Renderer, camera, arena, spawning, input, and quality modes |
| [`src/three/Character.ts`](src/three/Character.ts) | Anatomy generation, locomotion, expressions, and animation |
| [`src/three/ShellMesh.ts`](src/three/ShellMesh.ts) | SDF part buffers and the raymarched proxy mesh |
| [`src/three/glsl.ts`](src/three/glsl.ts) | Blend-shell, lighting, outlines, toon bands, and shadows |
| [`src/three/Stage.ts`](src/three/Stage.ts) | The presentation arena and environmental styling |
| [`src/pages/Home.tsx`](src/pages/Home.tsx) | The responsive creature-foundry interface |
