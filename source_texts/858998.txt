Found the crash!
From using the VS debugger:
Breakpoint on the line that fill the Blocks array ( Blocks[GetBlockIndex(x, y, z)] = EBlock::Stone; ):
It starts filling in, up until reaching Position (0,0,4), which equals to index 4096, where it breaks. Same again at (0,0,5) equalling 5122, and so on.
Breakpoint on the line "Blocks.SetNum(Size.X * Size.Y * Size.Z);":
The Size integers always remain at 16, even if set at 32 in editor. Meaning that SetNum will always return 4096, not 32768 as expected, and and a result breaking everything else.
Moving the SetNum line into BeginPlay fixes the crash.
I'm still getting some wrong triangles on any scale above 16, so there might be some "hardcoded" behavior remaining:
edit
I forgot that I also had to do another fix: Mask.SetNum(Axis1Limit * Axis2Limit) apparently isn't enough space, as a result it sometimes crashes for me with chunk size 16 (depending on the size of the chunk), and always at 32. I just added some big integer as a temporary fix.
