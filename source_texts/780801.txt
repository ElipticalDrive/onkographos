Implementation Plan
Use Cases
Transposition ciphers — plaintext written row-by-row, read column-by-column (or vice versa)
Grid puzzles — read a letter grid in a different direction to reveal a message
Image/symbol grids — rotate to find the correct orientation
Route ciphers — read a grid along a specific path (spiral, zigzag, etc.)
puzzle-lib — Matrix Utilities (src/Matrix/)
Core type: string[][] (2D array of single characters/cells)
Transformation functions (matrix.ts):
rotateMatrix90(grid) — rotate clockwise 90°
rotateMatrix180(grid) — rotate 180°
rotateMatrix270(grid) — rotate clockwise 270° (= counter-clockwise 90°)
transposeMatrix(grid) — swap rows ↔ columns
mirrorMatrixH(grid) — flip horizontally (reverse each row)
mirrorMatrixV(grid) — flip vertically (reverse row order)
Parsing helpers:
parseMatrix(text: string): string[][] — split multiline text into a 2D grid (split by newlines, then characters)
formatMatrix(grid: string[][]): string — join back into multiline text
All pure functions, no mutation. Small module — each transform is 1-5 lines.
Tests: Verify each transform on small grids (e.g., 3×3), non-square grids, single row/column, empty input. Verify that 4× rotate90 = identity.
puzztool — Matrix Rotation Tool
Input panel:
Textarea for pasting a grid of text
Auto-parsed into a 2D grid on input
Transform buttons:
Rotate 90° / 180° / 270°
Transpose
Mirror H / Mirror V
Reset (back to original)
Output panel:
Live display of the transformed grid
Monospace font to preserve alignment
Copy-to-clipboard button
State: Redux slice tracking the original grid and current transformation chain (so Reset works)
Notes
Very small puzzle-lib module — ~6 pure functions, each a few lines
puzztool UI is straightforward — textarea + buttons + output
Could live under a "Solvers" or "Tools" route category
Low complexity, good candidate for a first contribution
