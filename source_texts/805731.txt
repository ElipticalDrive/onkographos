Reject degenerate meshes in both evaluator roles
This oracle only passes the degenerate mesh as reference, where _surface_normals_at happens to detect it. When the same mesh is passed as prediction against a valid reference, evaluate_surface_reconstruction accepts it and returns metrics because prediction faces are used only by _point_to_surface. Thus the newly Stable evaluator still produces potentially invalid distances for degenerate predicted surfaces; validate faces on both inputs and extend this test to cover both argument positions.
