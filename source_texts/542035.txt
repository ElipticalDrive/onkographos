Adds opt-in hiZTraversal: 'adaptive' for SSR with a Hi-Z input. The default linear/conservative paths retain their existing behavior. Adaptive traversal advances to cell exits or depth planes, descends for leaf acceptance, and uses a bounded quality-scaled budget. Standard/reversed depth uses affine projected math and hoisted reciprocals; log depth retains the general path. Both examples expose traversal, iteration-budget and minimum-mip controls plus URL presets.

The mirror view gains about 2.75× throughput, while GGX loses about 15%. Coarse leaves do not improve these views. This is an explicit speed/quality tradeoff, not a claim that Hi-Z universally accelerates SSR. GPU-completed five-second throughput windows include CPU submission; these are not isolated GPU timestamps.
Adaptive hits can differ: it starts one projected texel from the origin, caps iterations at quality × hiZMaxSteps (eight minimum, default full-quality budget 64), solves leaf planes directly, and bypasses legacy binary-refinement brackets. hiZMinMip > 0 may miss thin details. Original stepExponent/binaryRefine apply only to linear/conservative paths. A low-quality 65×49 mirror fixture changes 113 of 3,185 hit-mask pixels, with linear RGB RMSE 0.00821. The separate suite comparison is essential to assess whether differences improve or degrade reference fidelity.
Algorithm contracts, timings and reproduction details and raw timing data are committed. Fidelity integration PR adds eight mirror/GGX variants with matching-linear and path-tracer PSNR/delta images across nine diagnostic scenes. All 72 hardware captures completed. Conservative is losslessly identical in 18/18 controls. Adaptive mirror mean path-reference PSNR changes −0.038 dB (worst −0.144 dB); adaptive GGX changes −0.332 dB (worst −0.997 dB). Small whole-image losses hide visible stair-stepped reflection edges in the offscreen mirror fixture. This is an experimental speed/quality option, not a net fidelity improvement. All 72 suite timing windows completed (480×360, quality0.5, Chrome148): geometric-mean throughput ratios versus linear are mirror conservative0.877× / adaptive0.865× / coarse0.847× and GGX0.834× /0.819× /0.826×. Thus every alternate traversal regresses at this preset; the 1080p mirror gain is workload-specific. Full comparison report.
