# 3DGS Renderer Built from Scratch (C++/CUDA)
This repository contains a custom, high-performance 3D Gaussian Splatting rasterizer built entirely from scratch. This engine is fundamentally a learning project. I built it primarily to gain a deeper understanding of GPU programming, CUDA memory management and the raw mathematics of 3D projection.

Here is a breakdown of how this engine is built along with the insights I gained during the making of this project.

This documentation is divided into two core sections, detailing both the theoretical foundation and the hardware-level execution required to render millions of splats in real-time:
1. **The Mathematics of 3D Graphics and Gaussian Splatting:** A deep dive into the mathematical intricacies of the graphics pipeline, from projecting 3D Covariance matrices using jacobian approximations to the exponential falloff functions that drive alpha-blending.
2. **Systems & CUDA Implementation:** An exploration of the CUDA implementation covering kernel optimization, memory coalescing (AoS to SoA conversion), zero copy OpenGL/CUDA interoperability, and massively parallel tile-based Radix sorting.
