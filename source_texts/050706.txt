Issue body actions
Extract the 3D burning surface as a triangle mesh using marching cubes and render it interactively with PyVista. This is how we see and verify the 3D simulation results.
Why
In 3D, the burning surface is an isosurface at $\phi = 0$ embedded in the voxel grid. You can't just plot a contour line — you need to extract a triangle mesh that represents the surface in 3D space. Marching cubes is the standard algorithm for this: it examines each cube of 8 neighboring voxels, determines which edges the surface crosses, and generates triangles to approximate the isosurface.
Being able to visualize the 3D regression — and color the surface by local burn rate — is critical for verifying that erosive burning and topology changes work correctly in 3D.
Tasks
Implement extract_surface_3d(phi, grid_spacing) — wraps skimage.measure.marching_cubes to extract vertices, faces, and normals from the $\phi$ field. Must convert PyTorch tensor to NumPy for scikit-image, then back to tensor if needed.
Implement render3d.py with PyVista — create a rendering function that takes the extracted mesh and displays it interactively. Support camera controls, lighting, and surface coloring.
Add burn rate coloring — map the local speed field $F$ onto the surface vertices as a color. Regions of high erosive burn rate should appear as hot colors, uniform regions as cool colors. This is the most intuitive way to visualize erosive effects.
Add animation support — render the regression at multiple saved timesteps, either as a sequence of snapshots or an animated GIF. Watching a star grain's points merge in 3D is the marquee demo for this project.
Create examples/star_3d_visualization.py — full demo: set up a 3D star grain, run the simulation with erosive burning, extract surfaces at regular intervals, render an animation showing the regression.
