# SDF Ray-Marcher for TouchDesigner

A real-time GLSL ray-marcher with soft shadows, designed for use in TouchDesigner GLSL TOPs.

![Ray Marching](https://img.shields.io/badge/Rendering-Ray%20Marching-blue)
![GLSL](https://img.shields.io/badge/Language-GLSL-green)
![TouchDesigner](https://img.shields.io/badge/Platform-TouchDesigner-orange)

## Features

- **Ray Marching Engine**: Sphere-tracing based ray marcher with configurable quality settings
- **SDF Primitives**: Library of signed distance functions (sphere, box, torus, cylinder, plane, etc.)
- **SDF Operations**: Union, intersection, subtraction, and smooth blending operations
- **Soft Shadows**: Penumbra soft shadows using ray marching
- **Ambient Occlusion**: Screen-space ambient occlusion approximation
- **Materials & Lighting**: Phong lighting model with customizable materials
- **TouchDesigner Ready**: Designed for easy integration with TouchDesigner's GLSL TOP

## Modular Architecture

The shaders use a **prepend-based include system** for TouchDesigner:

```
Include order (prepend in GLSL TOP):
1. utils.glsl           → Math, rotation, noise, camera
2. sdf_primitives.glsl  → Shape functions (sphere, box, torus...)
3. sdf_operations.glsl  → Boolean & domain operations
4. lighting.glsl        → Shadows, AO, materials (optional)
5. scene_*.glsl         → Your scene file
```

This keeps scenes clean and utilities reusable across projects.
