Overview
We introduce a major upgrade to XII's graphics architecture, transforming the renderer into a modern GPU-driven rendering pipeline with physically-based lighting, advanced global illumination, hardware ray tracing, virtual shadow maps, volumetric rendering, and subsystem-oriented resource ownership.
The work focuses on scalability, rendering quality, platform portability, and long-term engine maintainability.
Major Features
Physically-Based Lighting
Added physical photometric light units.
Normalized light energy across rendering paths.
Added sphere and tube area lights.
Integrated IES light profile support.
Added calibrated sensor and physical exposure pipeline.
Added display output and color grading systems.
Advanced Direct Lighting
Implemented clustered lighting assignment.
Added ReSTIR Direct Illumination.
Improved finite-area emitter support.
Integrated emissive mesh lighting.
Added photometric profile weighting.
Global Illumination
Added Dynamic Diffuse Global Illumination (DDGI).
Implemented sparse voxel radiance structures.
Added ReSTIR GI reservoir generation and reuse.
Integrated screen-space global illumination.
Shadows
Added cascaded directional shadow rendering.
Stabilized cascade management.
Implemented PCSS directional shadows.
Added virtual shadow map residency, feedback, and invalidation systems.
Added GPU-driven shadow rendering.
Added local shadow atlas planning and sampling.
Added dynamic volumetric shadowing.
Reflections
Added clustered reflection probes.
Implemented hybrid reflection pipeline.
Added screen-space reflections.
Added hardware ray traced reflections.
Added fallback reflection tracing paths.
Hardware Ray Tracing
Added portable ray tracing infrastructure.
Added ray tracing scene management.
Added Vulkan ray tracing shader support.
Added BLAS/TLAS construction and management.
Implemented ray traced:
Reflections
Shadows
Ambient Occlusion
Near-field GI
Added temporal denoising and stability improvements.
Added material-aware ray hit shading and texture sampling.
Atmosphere and Volumetrics
Added physically-based atmosphere system.
Added aerial perspective rendering.
Added volumetric cloud authoring.
Added cloud shadow rendering.
Added streamed volumetric media hierarchy.
Added volumetric froxel lighting injection and integration.
Added temporal reprojection for volumetrics.
GPU-Driven Rendering
Added GPU visibility management.
Added GPU frustum culling.
Added occlusion culling.
Added extracted instance streaming.
Added indirect draw command generation.
Added GPU-driven shadow rendering workflows.

Materialized managed render passes.
