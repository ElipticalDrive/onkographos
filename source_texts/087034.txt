Congratulations on the grant, @m-schuetz!
There's a new computer graphics technique called 3D Gaussian Splatting which won best paper at this year's SIGGRAPH conference, which is a variation of the traditional oriented point splatting technique. It's basically a way to use machine learning (a differentiable renderer) to refine and augment a photogrammetry point cloud with a number of reference images, which produces very high quality renders.
I've written a basic implementation of a WebGL viewer here, and there are some impressive demos available from Luma and Polycam.
But right now all of these implementations are limited to fairly small scenes as every point is rendered on essentially every frame. However, it should be possible to take multiple splat scenes and concatenate them to create a vast navigable photorealistic world, where an octree representation like Potree would be essential.
