Contributor
This PR transforms the application from a fractal renderer into a dedicated SDF (Signed Distance Field) modeling application, making blob-tree.wgsl the default and primary shader.
Changes Made
Default Shader Update:
Changed default shader from "mandelbulb" to "blob-tree"
Added backward compatibility for existing URLs using ?fractal= parameter
New preferred parameter is ?shader= but both work seamlessly
Cleanup of Unused Shaders:
Removed 9 unused fractal shader files that were not part of the core rendering pipeline:
klein.wgsl, klein2.wgsl, klein2_revisited.wgsl
mandelbox.wgsl, mandelbulb.wgsl
menger.wgsl, mengermushroom.wgsl
sphere.wgsl, whatev.wgsl
Retained only essential shaders for the SDF modeling pipeline:
blob-tree.wgsl - Primary SDF shader for modeling
pass-through.wgsl - Vertex shader
upsample.wgsl - Upsampling pass
blit.wgsl - Final blit to canvas
Terminology Refactoring:
Replaced "fractal" terminology with more appropriate "shader" and "SDF" terms throughout main.ts
Updated variable names: fractal → shader, fractalBindGroup → shaderBindGroup, etc.
Updated pipeline labels and comments to reflect SDF modeling purpose
Result
The application now properly represents itself as an SDF modeling tool for creating 3D models using boolean operations on primitive shapes, rather than a fractal renderer. Users can interactively place spheres and combine them using CSG operations through the tree interface.
Fixes #12.
