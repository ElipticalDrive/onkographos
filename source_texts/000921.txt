Abstract
Publisher Summary
This chapter discusses efficiency improvements for hierarchy traversal in ray tracing. One common scheme for accelerating ray tracing is using a hierarchical set of bounding volumes. In this scheme, a tree structure is formed in which the root is a bounding volume enclosing all objects in the scene, and each child is an object or a bounding volume containing more objects or volumes. Such a hierarchy can be formed manually or by various algorithms. The hierarchy is accessed by testing a ray against the root volume. If it hits, the volume is opened up and the objects or volumes within are tested for intersection. This process continues until the entire tree is traversed, at which time the closest intersection is returned. This chapter also describes improved tree traversal techniques. One simple improvement is to use the current closest intersection distance as an upper bound on how far the ray travels.
