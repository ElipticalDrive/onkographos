# Voxel

Lightweight C++17 voxel sandbox prototype with chunked terrain, multithreaded generation, collision detection, frustum culling, Lua scripting, and simple ECS-style entities.

## Build

Requires CMake 3.20+ and a C++17 compiler. Lua 5.4 is optional for scripting.

```bash
cmake -S . -B build
cmake --build build
./build/voxel
```

## Features
- Chunk-based procedural terrain
- Parallel chunk generation with `std::async`
- Player AABB collision detection
- Chunk-level frustum culling
- Lightweight entity/component abstractions
- Optional Lua world scripting
