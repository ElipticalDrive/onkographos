Objective
With a reduced main pass resolution (as with DLSS), GPU occlusion culling tests meshes against the wrong part of the depth pyramid, so many hidden meshes are drawn anyway. This costs performance -- it doesn't cause artifacts. Changing the viewport between frames hits the same mismatch.
Solution
Build the depth pyramid from only the part of the depth buffer that the main pass renders to.
Testing
Tested with the scene in the showcase below, using DLSS on an RTX 5090 (Vulkan), with a readback of how many meshes the GPU drew. Also checked two cameras with offset viewports on the same render target, with and without MSAA.
Showcase
225 cubes behind a wall, with the camera moving side to side. The image looks the same either way. The difference is how many meshes get drawn, shown in the top left of each still.
