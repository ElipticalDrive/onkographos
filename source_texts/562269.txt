Write in version of rendering that allows pre-selection of the desired output plots (take in a tuple of named plot types for example), then generates those plots automatically throughout the program.
Will help improve user experience at greater ray counts as can enable real time rendering which will render parts of the image throughout propagation as each batch is completed, deleting the raw data afterwards and building up the resulting image instead - saving storage space.
Would require setting up an editable easily appendable format for plots, may also require transitioning to faster plotting module at greater ray counts. This would have to be generalised and run at the end of each ray batch completion (after propogation through the entire domain - not part if the domain is batched too).
