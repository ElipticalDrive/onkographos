This paper introduces a robust and real-time occupancy grid map (OGM) prediction algorithm that leverages aleatoric uncertainty and neural network acceleration algorithms. OGM prediction problem inherently involves aleatoric uncertainty, which, unlike epistemic uncertainty, cannot be reduced by collecting more data. This often leads to performance degradation in various scenarios. To address this issue, we exploit the correlation between occupancy grid cells, which can be modeled through aleatoric uncertainty, to enhance OGM prediction performance. Additionally, we accelerate the neural network using tensor decomposition and quantization for real-time operation on a mobile CPU. As a result, the proposed method achieves more robust prediction, suitable for real-time deployment on embedded systems
