Motivation
Replace the four placeholder projection panels with real 3D isosurface renderers so the UI shows semi-transparent volumetric geometry instead of static boxes.
Provide a controlled, inspectable fake 4D scalar field (ψ) sliced into 3D volumes to demonstrate isosurface extraction and visualization without implementing real 4D orbital math.
Make UI controls (isosurface level, opacity, resolution, live update) drive synchronized refresh of all four views and surface extraction for Phase 1 verification.
Description
Added a reusable ProjectionViewWidget (in ui_widgets.py) that embeds a pyvistaqt.QtInteractor, constructs a pyvista.UniformGrid from a numpy volume and produces positive/negative contours using grid.contour, rendering two semi-transparent meshes with fixed contrasting colors.
Implemented fake ψ evaluation and slice-volume creation in ui_main_window.py via _fake_psi and _create_volume to produce the four slice projections X/Y/Z/W (fixing the appropriate axis to zero) and added render_single_view / render_all_views to orchestrate rendering.
Hooked UI controls into the pipeline: Isosurface Level maps iso_percent → iso_value (percent of max(abs(vol))), Opacity maps to actor opacity, Resolution regenerates the grid size, Live Update triggers automatic renders, and a Render Now button forces manual refresh when live update is off.
Updated application state (app_state.py) to use iso_percent, opacity_percent, integer resolution and integral_samples, and added/updated requirements.txt to include numpy, pyvista, pyvistaqt, and scikit-image.
Testing
No automated tests were executed as this change targets a GUI rendering pipeline; the code was committed but automated test runs were not performed.
