Work in progress.
Still working out what the game should be and how it should feel etc.
Been working on traversal of a character and trying a bunch of rendering tecqniques.
I can get a pretty stable 60 fps with 258 million voxels at gbuffer level but specular occlusion, irradiance and volumetric lights need speedup.
Also, the temporal accumulation of passes and TAA is not working so well together yet.
The adventure continues.
I think the game will have something to do with dreams..... maybe
Tech stack: Rust, Bevy ECS, wgpu (Metal), WGSL compute shaders 🎮 Inspired by: Teardown, Celeste, MagicaVoxel, Motvind, Uncharted, AnotherWorld Features shown:
Compute-based voxel raymarcher (no rasterization)
Teardown-style deferred lighting (6 light types, stochastic shadows)
Volumetric fog with temporal denoising
Procedural character with Verlet rope limbs + foot IK
Celeste-style platforming (coyote time, jump buffering, air dash)
Gravity gun with terrain destruction
.vox level loading with PBR materials
Hierarchical mip-level DDA traversal (3-8x fewer ray steps)
Running on a MacBook with Metal. All code is custom.
