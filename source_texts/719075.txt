Working computational implementation
Real progressive Monte Carlo GPU path tracing (not a rendered animation or canvas mockup): intersections, path bounces, diffuse next-event lighting, mirrors, glass/refraction, Russian roulette, accumulation and GPU tonemapping.
Handwired Circuit emitted WGSL material-throughput multiplication is executed in every GPU bounce.
Interactive cameras, ray depth, emitter power, glass IOR, exposure, resolution and PNG export, with desktop/mobile layouts.
Adds /neural-light/ to GitHub Pages and links live scene previews to the eight-project gallery.
Verified reference and hardware
7 focused CPU reference tests and 429 assertions passed.
Independent ray geometry comparison on identified Intel UHD Graphics gen-12lp WebGPU: 136 GPU vs CPU intersections, including misses, mirror, glass and light, zero mismatches, worst ray parameter error ≈1.06e-5.
GPU multi-bounce radiance smoke: 12 spp × 19,200 pixels, no nonfinite output.
Actual screenshot: 200 spp at 240 × 180 desktop and 59 spp on mobile. PNGs and original JSON reports are in lab/frontiers/light/results/.
Strict TypeScript, strict lint and complete static site build passed locally. This PR triggers full GitHub CI.
Unfinished full project scope
This is a genuine first vertical slice, not a complete photorealistic renderer. BVH/generic meshes, GGX, MIS, denoising, full transport convergence, timestamp-query timing, comparable third-party benchmarks and cross-adapter testing remain open.
