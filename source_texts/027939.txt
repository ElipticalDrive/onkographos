Describe the bug
I recently noticed some odd behavior in the volumePlot tests. Basically, if you render a volume using the ray caster before rendering using the default renderer, you end up with a blank test result.
Helpful additional information
I have not been able to reproduce this behavior outside of the test suite, and it only occurs when ray casting before default rendering. Also, it only occurs on the first default rendering after the ray casting. After the first attempt, everything renders fine. Running the test with verbosity shows no errors.
To Reproduce
There are many ways to see this behavior, but here's a simple test:
Go to test/tests/plots/volumePlot.py
Edit TestVolumeScaling: before the "volumeScaling_01" test, render the image using RayCasting (no need to perform a test). After drawing, change the renderer back to Default, and let the test proceed as usual.
Run the test
Open up the html results, and you should see that "volumeScaling_01" is blank.
I tested this on RC3.0 only.
