This change refactors the terrain system's architecture to use C++ templates, allowing for different data types (like voxels vs. heightmaps) to be enforced between generators and renderers.
Key changes:
ITerrainRenderManager is now a base class, with a templated ITerrainRenderManagerT<T> adding the RegisterChunk method.
ITerrainGenerator is now a base class, with a templated ITerrainGeneratorT<T> adding a typed render manager setter.
TerrainGenerationResult was moved to a common interface header and updated to include world_offset.
TerrainGenerator, TerrainRenderManager, and VoxelTerrainRenderManager were all updated to use these new interfaces.
Runtime type safety is ensured via dynamic_pointer_cast when linking generic interfaces in Visualizer.
These changes lay the groundwork for more advanced voxel-based terrain systems that may require 3D density grids or other specialized data structures instead of the current 2D heightmap-derived meshes.
