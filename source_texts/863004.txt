```
Sort every GPU-prepared Gaussian record of a frame with a portable 8-bit
LSD radix sort over a 64-bit key. The high word inverts the authored sort
key so larger keys come first; the low word is a frame-global candidate
index assigned in ascending resource identity and particle order. The
result reproduces the CPU reference order exactly and never depends on
atomic compaction order.

Six Slang kernels (keys, digit-major histogram, block scan, scan add,
stable scatter, verification) use no subgroup operations and bind four
storage buffers, the Vulkan guaranteed minimum, so selection needs no
descriptor-limit preflight. Low-word passes the candidate count cannot
occupy are skipped, fixing the dispatch count from candidate and
resource counts.

The verification kernel checks strict key order, sentinel placement,
and each key against its prepared record; resolve fails the frame on any
violation or lost record. An order-sensitive identity checksum is
compared with the CPU reference and reported as a divergence counter.

Shader ABI v7 reflection-checks the sort layouts. The sort is selected
independently through RenderRequest::gpu_driven_gaussian_sort; Prefer
falls back when GPU preparation or the artifacts are unavailable and
Require rejects explicitly. Its output is not rasterized yet.

Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
```
