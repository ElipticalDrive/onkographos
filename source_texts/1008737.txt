This PR implements a new continuous light propagation voxel lighting model. Each frame, light is propagated along each individual axis. Propagation occurs in 2 passes with the forward and side blur propagation passes in separate compute shaders.
Changes:
Generate anisotropic voxels (6 directions) representing light propagation
Replace diffuse lighting with new O(1) lookup voxel grid
Reduced voxel grid dimensions by half to support new algorithm
Update tests to take screenshots 100+ frames in to include lighting
Allow image resources to be culled if they are never read
Allow reopening of an existing RenderGraph scope
Fix Wall Prefab generator script
