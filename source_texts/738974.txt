Contributor
Implements a Wolfenstein 3D/Doom-style first-person shooter using raycasting for pseudo-3D rendering without external dependencies.
Implementation
Game Engine (games/fps.js)
Raycasting algorithm for 3D wall rendering from 2D tile map
AI state machine (patrol → chase → attack) with cooldown-based combat
Canvas 2D rendering with distance-based shading and sprite rendering
Collision detection for 16×16 tile grid
Gameplay
WASD movement + mouse look (pointer lock API)
30-round magazine with 2s reload, 20 damage per shot
5 AI enemies: 100 HP, 8 damage/attack, 1.5s cooldown, 5s respawn
HUD: health, ammo, score, kills, reload progress, targeting crosshair
Integration
Added to existing single-page app navigation
Full-screen canvas with overlay HUD
Game over/replay flow
Technical Decisions
Raycasting over WebGL: Eliminates external dependencies (Three.js CDN was blocked), reduces complexity, and matches requested early 2000s aesthetic.
Attack timing fix: Initialized enemy.lastAttack to current timestamp instead of 0 to prevent instant damage on first frame due to epoch-time comparison.
Screenshots
Game showing raycasted 3D environment, AI enemies with health bars, HUD elements, and weapon view.
