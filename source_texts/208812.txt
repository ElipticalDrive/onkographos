Scope
Adds the executable CPU reference contract for feature-preserving manifold dual contouring over the same fixed 34 x 34 x 34 scalar page+halo representation used by planetary Transvoxel.
The reference follows the original Dual Contouring of Hermite Data and Manifold Dual Contouring construction:
derives multiple surface components per cell from the manifold regular-cell triangulation (not one vertex per active cube)
audits all 256 cases, 358 components, maximum 4 components/cell, and every neighboring face pairing (zero mismatches)
builds deterministic trilinear Hermite samples and a rank-aware bounded QEF solution
uses canonical page edge ownership with the existing one-sample halo
quantizes cell-local QEF offsets to the open 1/65536 dyadic grid for bit-identical page seams and no zero-sample vertex collapse
emits one oriented dual quad per owned sign-changing edge and deterministic triangulation
compacts unused halo components
exposes a reusable 2-manifold edge/link audit and an attribute-safe GpuTerrainVertex + indices export welded by (source QEF vertex, material)
rejects malformed sample and render-export inputs with typed errors
Worst-case reference bounds are explicit: 35,937 cells including negative halo, 143,748 geometric component vertices before compaction, 98,304 quads, 589,824 indices, and 393,216 attribute-safe GPU vertices.
This PR is the uniform-page CPU oracle only. GPU extraction, the paper's adaptive Euler/face-intersection clustering criterion, adversarial 2:1 topology, benchmarks, and the final extractor choice remain pending; issue #96 is not complete.
Validation
exhaustive regular-table face/component audit: 256 cases, 358 components, max 4/cell, zero face-pairing mismatches
all six existing extraction fixtures are deterministic, bounded, index-safe, nondegenerate 2-manifolds with boundary
closed sphere: closed 2-manifold, exactly two faces per edge, disk-like vertex links, no degenerate triangles
exact canonical halo-vertex parity across X/Y/Z adjacent pages
outward plane winding, two-material seam ownership, sharp-corner QEF placement within one quantization step
audit-negative tests for duplicate triangles and invalid indices
