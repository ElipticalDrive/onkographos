The viewer previously retained full-detail city geometry and material-rich query data even when much of it was too small or outside the useful view. This change selects mixed tile LODs, bounds streaming work, and stores compact occupancy and quad records.
Changes
Adaptive 1/2/4/8 m tile selection with hysteresis, camera/shadow visibility, atomic parent/child swaps, cancellation, retries, upload budgets, and eviction.
Compact occupancy intervals and 16-byte quad records, decoded in shaders; retain CPU buffers for WebGL context restoration.
F3 performance overlay: FPS graph, frame time, CPU payload, browser JS heap, estimated GPU geometry bytes, active/resident/frustum tile counts, and occupied voxel estimates.
F4 LOD tint visualization with a color legend, including foliage and newly streamed tiles.
Move tile-loading progress below the top-left controls and remove the “Viewer adapted” page attribution.
Measurements and tradeoffs
Desktop Chromium / GTX 1080 Ti, 1600×1000 DPR 1:
Overview mean frame time: 22.5 → 6.1 ms.
Overview logical geometry/query payload: 975.5 → 41.1 MiB.
Close-view mean frame time regressed approximately 9%, despite substantially lower memory.
Packed instanced quads save memory but reduce fixed-detail throughput on this GPU. ?lod=1&geometry=expanded remains available for comparison; packed indexed vertices or vertex pulling are the next experiment.
Memory figures exclude textures, worker/driver overhead, and duplicate GPU allocations. WebGL does not expose total VRAM. Voxel estimates count occupied cells at selected LODs, including buried cells; frustum estimates include whole intersecting tiles. Mobile checks use browser emulation, not physical mobile GPU benchmarks. Research measurements used the local dataset, which includes separately uncommitted vegetation changes; those data changes are excluded from this PR.
Validation
npm run build and TypeScript checks passed.
Differential checks: 1,304 tiles, 21,307,069 occupancy intervals, 344,010 quads, 20,000 query points, 100 raycasts, and eight selector views; occupied-cell count checks passed.
Packed/expanded pixel comparisons passed for day/night and raw/postprocessed rendering.
Streaming coverage, failed-request retry, cancellation, eviction, shadow invalidation, and WebGL context restoration checks passed.
Browser checks passed for desktop/mobile layout, F3 toggling, and F4 tint/restoration in packed and expanded modes, including foliage polygon offsets; no WebGL errors.
See feature plan and re-evaluation, research proposal, and the committed reports in artifacts/profiling/.
Includes commits 1034c95, fed96dd, and 1977328.
