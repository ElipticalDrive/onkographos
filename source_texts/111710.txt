Audit update (against dev-next, 2026-06-03)
Checked off the two GPU-driven items now implemented, which also completes their parent groups:
Hi-Z generation — hzb_generate_pass.cpp (+ depth_hzb_feature)
Hi-Z occlusion culling — meshlet_hiz_cull_pass.cpp
→ parents Core GPU-driven pipeline and Visibility & Depth are now fully complete.
Verified still-present (already checked): GPU frustum culling (coarse_instance_cull_pass), depth pre-pass, visibility buffer, deferred shading (deferred_lighting_pass), CSM + PCSS (shadow_map_pass, universal.vrg.json), RT TLAS/BLAS (raytracing_primary_pass), Gaussian splat rasterise/sort/LOD.
Partial groundwork (left unchecked):
GPU-driven shadow rendering — CSM/PCSS exist but no dedicated GPU-driven shadow pipeline yet.
Visibility buffer debug / GPU culling debug — the frame debugger (frame_debugger_system) provides general capture, but there are no dedicated visualisation passes.
Not found (unchanged): tile classification / light list / tile-cluster culling / Forward+; all GI (LPV/DDGI/SDFGI/VXGI); hybrid RT shadows/reflections; opacity micromap; denoising; light-tile/overdraw visualisations.
