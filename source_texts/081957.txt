# Dashcraft

A voxel sandbox built on [flutter_scene](https://pub.dev/packages/flutter_scene), the 3D rendering engine for Flutter. It exists to show what the engine can do and to find its rough edges by leaning on them.

Mine and place blocks across a streaming, biome-driven world with caves, trees, and plants; craft wooden and stone tools; and tune the sky, water, and post-processing live from an in-game panel.

## What it exercises

- Streaming voxel terrain generated and meshed on a worker isolate pool, batched into column groups to keep draw counts down
- Biome world generation (temperature, moisture, and ridge fields) with mountains, snow lines, deserts, caves, and plants
- A procedural water surface authored as a `.fmat` material, using the engine's scene color and depth inputs for refraction, Beer-Lambert absorption, foam, and an in-material screen-space reflection march
- Cut-out foliage that casts alpha-tested shadows, a cascaded shadow atlas, screen-space reflections, ambient occlusion, bloom, depth of field, and god rays
- Auto exposure metered by raycasting the voxel grid for sky, sunlight, and shadow
- A mipmapped block atlas with normal and metallic-roughness maps, packed offline from the source textures

## Running

Needs Flutter 3.47 or newer.

```sh
flutter run -d macos --enable-flutter-gpu
```

Other desktop platforms and web work the same way, though macOS is what gets exercised day to day. The build hook compiles the water material and the engine's shaders on first build, so expect the first run to take a while.

## Controls

| Input | Action |
| --- | --- |
| WASD | Move |
| Mouse | Look (click to capture, escape to release) |
| Space | Jump |
| Shift | Sprint |
| Left click (hold) | Mine the targeted block |
| Right click | Place the selected block |
| 1-9 | Select a hotbar slot |
| E | Open or close the inventory and crafting grid |
| F | Toggle fly (Q and E descend and ascend) |
| C | Toggle sphere dig |
| ` | Toggle the FPS graph |
| Escape | Pause, or close the inventory |

The settings panel from the pause menu tunes the sky, water, and post-processing stack live, and prints the tuned values so they can be pasted back as defaults.

## Tests

```sh
flutter test
```

The suite is pure Dart with no GPU, covering the mesher's face culling and layering, terrain and tree generation, the chunk worker protocol, and world edits.

## Assets

The block textures are packed offline from [Demon's Nation of Realism](https://github.com/darkyboys/demon-nation-of-realism-256x) (MIT); the tool and stick icons come from [ProgrammerArt](https://github.com/deathcap/ProgrammerArt) (CC-BY-4.0). Per-asset attribution lives next to each asset in `assets/textures/block_atlas_LICENSE.md` and `assets/icons/ICONS_LICENSE.md`. `tools/fetch_block_textures.sh` and `tools/pack_block_atlas.dart` rebuild the atlas from upstream.
