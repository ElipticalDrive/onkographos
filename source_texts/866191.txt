Collaborator
Colliders:
Chunks always have colliders when a physics object is in them (builds missing ones, not just prevents unload)
Collider greedy merge counts buried blocks — fewer, deeper boxes on terrain AND debris pieces
Boxes grow in both directions and overlap on slopes for wider coverage
Collision debug view shows debris collision shapes (cyan wireframes)
Volume tool:
Aims at physics objects (reuses shovel's debrisAim ray)
Corners track the piece as it moves (debrisSpot, same as shovel/creative tool)
Dragging works in the piece's local frame — box stretches along piece axes
Ghost aligns to piece orientation, redraws every frame
Fill adds blocks to the piece via placeOnDebris when corner 1 is anchored on one
Removed all toast popups from the volume tool workflow
Debris rendering:
Pieces only draw exposed faces (per-instance face mask + shader)
Placed/powder child blocks cull buried faces too
Fully buried children hidden entirely
Shadow pass respects the face mask (fallDepthMat)
Perf:
shedPowder cached by block count + direction, Set lookup instead of linear scan — fixes quadratic sand cost
Large physics objects no longer laggy
25 commits, ~250 insertions, ~150 deletions in web/index.html.

Debris pieces only render exposed faces like terrain
…

```
Each block instance carries a 6-bit mask of faces touching another
block in the same piece. A shader hook throws those faces off-screen
before rasterizing. Mask recalculated on spawn, cut, and place. Each
piece gets its own geometry copy to carry the per-instance mask,
freed when the piece is removed. Collision picking still uses full
cubes so block selection is unchanged.
```

```
Placed/powder child blocks never got face culling — they use separate
materials without the faceHide shader. debrisChildFaces reorders each
```

Fix large physics object lag
…
cb60018
```
Three per-frame costs that scaled with block count:
1. Shadow pass used a depth material without the face mask — drew all
   6 faces of every block into the shadow map. New fallDepthMat shares
   the face-hide shader.
2. shedPowder walked every block of every piece every frame and was
   quadratic for sand. Now cached by block count + down direction,
   with a Set lookup instead of lat.some.
3. Fully buried child blocks still got draw calls. debrisChildFaces
   now hides them entirely when all 6 faces are covered.
```
