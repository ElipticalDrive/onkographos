This PR fixes multiple issues with the current state of the voxel engine:
Broken Textures: Replaced the broken Craft GitHub texture URLs in the Lua script with dynamic dummyimage.com placeholders so the application does not print HTTP 404 errors when fetching assets.

Avoid treating chunk borders as air during face culling
get_voxel_safe returns air for every out-of-bounds lookup, so any solid voxel on a chunk edge always emits a face even when an adjacent chunk has a solid neighbor. In multi-chunk worlds this generates hidden internal seam faces (e.g., x=31 in one chunk vs x=0 in the next), increasing vertex/index counts and raster work and undermining the intended neighbor-culling behavior.
