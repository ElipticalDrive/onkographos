Motivation
Current '3D themes' for 2D fractals are normal-map Phong bump only — fake relief, no geometry, no cast shadows/AO, no volume. Two user-requested capabilities both need the same primitive: a Z axis for 2D fractals.
Idea
Treat the escape-potential / smooth-iteration field as a heightfield and raymarch it:
Real relief 3D (Q4b): raymarch the heightfield for true cast shadows, AO, silhouette — beyond the cheap normal-only Phong. Optionally mesh via marching-squares → extruded surface (pairs with Generalize marching-cubes mesh export to all DE raymarchers #101 exporter).
Volumetric fx (Q5): extrude the field into a pseudo-3D density slab → reuse the existing LightingFxData volumetric stack (VolumeSteps / fog / in-scatter / cloud-noise), which is currently raymarcher-only.
Cheaper alternatives to evaluate in the spike
Iteration-band depth fog (tint by iteration count as pseudo-distance) — low effort, partial look.
Buddhabrot / Nebulabrot are already genuine 2D orbit-density fields → fog/glow-able volumetrically with no invented geometry.
Deliverable
Spike doc under Docs/Technical/ + prototype on one 2D type (Mandelbrot). Decide honest heightfield-raymarch vs cheap fakes. Feeds both #101 (mesh) and the 2D volumetric ask.
Dependencies
Heightfield needs a clean potential/DE field — pairs with Approximate DE for antiholomorphic 2D fractals (Tricorn, Burning Ship, Glynn, TearDrop) #100 (DE for more 2D types).
Volumetric reuse shares LightingFxData with the raymarcher pipeline.

Phase 1 SHIPPED (feature/heightfield-spike-102).
Approach A productionised: HeightfieldRelief2D.Apply — hillshade (height-gradient normal) × sub-pixel horizon cast-shadow walk, multiplied into the themed colour. Wired into FractalRenderHost.UploadProcessedBuffer (single upload convergence), fed by the active 2D calculator's smooth-iteration height buffer stashed at calc completion. Opt-in via FractalParameters.Relief2D* + a "Relief 3D (2D heightfield)" UI section in EscapeTimeParamsView.
Covers Mandelbrot + the EscapeTimeCalculator family (Tricorn, Burning Ship, Julia, Multibrot, Phoenix, Magnet, Glynn, Spider) — so Tricorn now gets genuinely raised relief, not just emboss. Default off = bit-identical to before. Tests + visual verification (deep-zoom seahorse + MonoBand reads as clear raised relief).
Reads best on smooth themes + zoomed into filament structure. Whole-set shallow view is the least dramatic (flat exterior potential).
Remaining (Phase 2): full heightfield raymarch (oblique camera) + volumetric via the LightingFxData stack; generated-calculator coverage (GeneratedTricorn/BurningShip).
