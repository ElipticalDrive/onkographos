Owner
Replace the published 2D brain with a true volumetric WebGL ORA brain
This is a renderer replacement only. Knowledge IDs, saved memories, temporary Situations, area semantics, focus and actions remain unchanged.
Why this PR exists
The first published brain version was rejected after real-device review: it looked like a flat oversized outline / technical scan, not the luminous volumetric brain requested for ORA. The acceptance target is now explicit: a recognisable 3D human brain made of light and neural tissue, closer to a premium hologram than a wireframe diagram.
Renderer
WebGL / experimental-WebGL only; no Canvas2D fallback pretending to be 3D.
Perspective projection, depth buffer and real yaw/pitch rotation.
3,000 cortical surface vertices plus separate cerebellum and brain stem.
1,000 internal translucent tissue points.
100 sparse bright synaptic hotspots and a bright central neural core.
Hundreds of curved internal fibres; cortical wire geometry is deliberately subdued so it does not dominate the volume.
Multipass additive rendering: broad cyan bloom → translucent internal tissue → crisp cortical sparks → warm synaptic highlights.
Brain presentation scale increases on the expanded/tall surface, while the chat preview remains bounded.
Same 8 ORA area IDs and exact saved knowledge node IDs; functional regions live inside the brain volume.
Temporary memories remain red; spotlight / selected nodes receive a stronger 3D glow.
Interaction retained
exact node selection / touch;
drag rotation on two axes;
spotlight and automatic camera focus;
zoom and reset;
opening/reveal lifecycle;
reduced-motion / pause / background scheduling;
mobile WebView bridge;
existing authority/memory/API model untouched.
Web/native parity
scene.js is mirrored verbatim (minus the ES module export) into sceneSource.ts; CI tests the same renderer contract for web and native.
Visual acceptance
The mobile QA now retains a dedicated *-brain-expanded.png screenshot. Do not merge merely because CI is green: inspect the full-screen brain and reject it if it still reads primarily as wireframe/scanner rather than luminous 3D brain.
No backend schema, AI reasoning, permissions, memory semantics or routing changes.
