Canonical probe depth maps currently use 512 bytes per probe for RG32F moments. Store normalized mean and spread in RG16 UNORM with 16 bytes of FP32 ranges instead, bringing depth storage to 272 bytes per probe, a 46.9% reduction including the ranges.
The encoder uses precision curves for blocker-depth endpoints and small spreads. The shader reconstructs FP32 total variance from two native hardware gathers, preserving octahedral gutters. Colour compression and relocation metadata remain independent. Format 8 invalidates automatic bake caches; legacy version 6 raw moments and version 7 RG8/ASTC depth remain readable.
Reject GPU-packed encoder inputs before plane access and omit unused raw-depth staging. Add CPU codec, malformed-input, parallel encoding and production GPU upload/sampling regressions, and update the native cache integration test. No baked game assets are included.
Validation:
Windows incremental baker and relevant probe test builds passed. Existing warnings in unchanged sources/test helpers remain.
Focused CTest selection: 8/8 passed, including production Vulkan depth sampling with validation enabled for the test only.
Native automatic preparation integration: 17/17 passed, covering fresh/cached runs, format changes, missing/stale inputs, recovery, emission, water and reflections.
Python baker discovery: 165 tests, 47 native-only skips; those require explicit executable invocation. PAL/NTSC rendering host-hook parity: 2/2 passed.
Pinned clang-format 21.1.8 strict changed-line conventions, layering and changed-line clang-tidy passed.
Isolated Windows development package: fresh, cached and missing-asset bakes passed without Python, the checkout, Vulkan SDK or Embree on PATH; bundled development DLLs supplied alongside the baker.
Earlier baker-disabled player build passed asset decoding for raw/BC6H/ASTC colour with RG16 depth. NTSC Novalis and Pokitaru screenshots matched the baker-enabled RG16 build exactly.
Limits: Android hardware and macOS/Linux runtime checks have not been run locally, and supported PAL disc data was unavailable for gameplay verification. Sampled stable-reference visibility errors stayed below one percentage point on Novalis and Pokitaru; this is lossy storage, not a proof for all levels. Desktop timing estimates were small but clock-sensitive; no fixed-clock performance claim is made. Full probe residency is retained. Normal player startup does not enable the test's validation or captures.
CI follow-up: the initial run exposed an inline-only SPIR-V inspection assumption in renderer_shader. Commit 732a47d preserves the cached receiver atlas extent, avoids a redundant direction calculation, and follows the depth helper in the structural regression. Local renderer_shader_vulkan, probe_gpu_vulkan and probe_depth_gpu passed; renderer_shader completed its structural assertions but skipped rendering because the offscreen OpenGL EGL context was unavailable. Native baker CLI and paired water-source CTest checks also passed. All nine CI jobs passed for head 732a47d: repository checks, Windows/Linux/Android launcher checks, Windows native, headless, Fedora, OpenGL compatibility and enhanced Vulkan. The enhanced suite reported 100% passing across 275 tests; renderer_shader and probe_depth_gpu both ran and passed. Run: https://github.com/OpenRAC/OpenRAC/actions/runs/41510028733
