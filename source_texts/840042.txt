Corrects Gaussian Splatting extraction to match official HunyuanWorld-Mirror implementation.
Changes:
Extract gaussians from outputs['splats'] dictionary (not individual keys)
Support both 'sh' (spherical harmonics) and 'colors' keys
Fix intrinsics key: check 'camera_intrs' in addition to 'camera_intrinsics'
Add debug logging to show available model outputs
Add informative message about Gaussian availability
Technical details:
Official model outputs: predictions["splats"] = {means, scales, quats, opacities, sh/colors}
Splats are generated by GaussianSplatRenderer.render() when enable_gs=True
Each parameter is a tensor that needs reshape(-1, shape) for export
SH (spherical harmonics) provides view-dependent appearance
The model should now properly extract Gaussian Splatting outputs when available. Model configuration requirements:
enable_gs=True in WorldMirror initialization
Sufficient input views (model dependent)
Proper model weights including gs_head and gs_renderer layers
Example output log:
Model outputs: depth, normals, pts3d, camera_poses, camera_intrs, splats Gaussians: Generated successfully

Corrects Gaussian Splatting extraction to match official HunyuanWorld-Mirror implementation.

Changes:
1. Extract gaussians from outputs['splats'] dictionary (not individual keys)
2. Support both 'sh' (spherical harmonics) and 'colors' keys
3. Fix intrinsics key: check 'camera_intrs' in addition to 'camera_intrinsics'

Technical details:
- Official model outputs: predictions["splats"] = {means, scales, quats, opacities, sh/colors}
