What
Add an MLX systematic-resampling primitive that allocates integer parent counts to child bins using explicit uniform offsets. This advances #32; tree traversal and anchor generation remain open.
Why
Octree descent needs to split a variable number of points between child cells while conserving counts and following the original sampling distribution.
How
Clamp and normalize probability rows using the upstream rules, then use a fixed 24-step binary search over the FP32 systematic grid to find each bin boundary. This avoids allocating a grid per point. The caller supplies offsets and controls the random key. Validation synchronizes and limits counts to 2**24 - 1; no full-scale performance claim is made.
```
flowchart LR
  P[Child probabilities] --> N[Clamp and normalize]
  C[Parent counts] --> G[Systematic grid bounds]
  R[Explicit random offsets] --> G
  N --> B[Binary search bin boundaries]
  G --> B
  B --> O[Integer child counts]
```

Tests compare controlled offsets to upstream PyTorch, including zero rows, one-hot rows, negative and subunit probabilities, boundaries, varied counts, and batches. A 4096-row test checks independent offsets, exact controlled reference allocations and empirical frequencies; a separate large-count check verifies conservation.
