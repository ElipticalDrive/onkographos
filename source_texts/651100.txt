Summary
@volume (src/lib/volumes.ts, pure): uniform highp sampler3D u_<name>; // @volume <value> where value is a bundled sample id (suzanne) or a file name ending in .sdf.ktx2 ([\w.-] only — no paths/URLs). setVolumeValue rewrites one sampler's value.
Loading (src/hooks/useVolumes.ts): samples fetched from /frapx/playground/sdf/, local files via File.arrayBuffer(); both through loadSdfVolume(buffer, { zstd: fzstd }), cached by value. File names with other characters become _.
Preview: textures go in at creation and via setTexture only when a name's texture changes; uniforms(name) merged under the slider values.
Panel (src/components/VolumePanel.tsx): per sampler a select (samples + the current file), Open file…, and a note while loading / on error / when the named file isn't loaded (from a share URL) with Use Suzanne. Picking rewrites the source, so share URLs carry only the name (decision 33).
// @include sdfVolume; Baked SDF starter (Suzanne smooth-unioned with an orbiting sphere; blend / orbit / albedo controls).
Install code: loads the volume before creating the background — loadSdfVolume(…).then((bakedSdf) => …) (Promise.all for several) in HTML/Vanilla/Astro (no top-level await, so Astro/Vite default targets build), React 19 use() + <Suspense> with memoized textures (a new object would re-upload). fzstd import only when the file is known to be zstd (sample, or the decoder ran on load). HTML reads ./sdf/, the others /sdf/ with a comment to put the file in public/sdf/.
fzstd added to apps/playground only (approved in the 2026-11-02 grill). Growth plan decisions 29–34.
Verification
vitest 68: @volume parsing (valid, non-sampler3D, paths/URLs/other extensions ignored, duplicates), setVolumeValue, install-code snapshots with a zstd volume for all tabs, uncompressed (no fzstd), two volumes, and the generated vanilla body parses.
e2e (12, chained in root test:e2e): Baked SDF renders with no overlay; opening a file into a static slice shader changes the picture; opening a file rewrites @volume and the install code; a share URL naming a local file shows the note and Use Suzanne restores; a share URL with the sample restores it.
playwright-cli: Suzanne and the skull (r16f-zstd from PR Showcase demo: baked SDF skull (fusion and urchin morph) #107's branch, opened as a file) render; a non-KTX2 file shows Couldn't load the volume: … identifier mismatch and keeps the current volume.
Pasted each tab's Baked SDF output into fresh projects using the published packages (plain HTML + sdf/, Vite vanilla, Vite React 19, Astro 6, Suzanne in public/sdf/): all four render the same Suzanne, one canvas, aria-hidden.
pnpm typecheck, pnpm test, playground build (dist/sdf/Suzanne.r8-zstd.sdf.ktx2 present).
