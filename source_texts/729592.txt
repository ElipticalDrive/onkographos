Mesh primitives
Add native cylinder, cone, sphere, circle, and capsule tessellation.
Use chordal tolerance to determine segment counts.
Standardize primitive axes, winding, validation, and error handling.
Improve tessellation of revolved boundaries.
Update the corresponding Rust and Python APIs, plotting support, examples, and tests.
Mesh conversions and views
Add consuming conversions between MeshData3 and accelerated Mesh3.
Move buffers when converting into Mesh3, avoiding unnecessary copies where possible.
Add MeshView3, a borrowed mesh representation that allows file writers to accept Mesh3 and MeshData3 without copying their buffers.
Update binary mesh, LPTF3, PLY, STL, and tolerance-compressed serialization to use borrowed mesh views.
Mesh attributes
Replace the combined mesh attribute container with separate point and face attribute sets.
Preserve and validate attributes across construction, conversion, editing, filtering, subsets, appends, and transforms.
Clarify ownership and behavior of typed attributes versus open attribute maps.
Expand attribute tests and documentation.
Surface sampling
Overhaul mesh surface sampling with:
Dense sampling
Deterministic Poisson-disk sampling
Area-weighted uniform sampling
Optional face masks
Surface-point and point-cloud results
Make the sampling APIs available on both MeshData3 and Mesh3.
Update alignment, measurement, voxelization, and other callers.
Expose point-cloud sampling through Python.
Expand sampling tests and documentation.
Flat-domain coordinates
Replace the special-cased UvMapping implementation with persistent per-point point_flat attributes.
Add FlatDomain for bidirectional queries between mesh surfaces and flattened 2D charts.
Support projecting 3D points into a flat domain with signed depth.
Support lifting flat-domain points back to mesh surface locations.
Add raster mapping support for flattened charts.
Preserve flat coordinates through mesh operations, conversions, scaling, and PLY round trips.
Add the corresponding Python APIs.
Document self-overlapping charts, lifecycle requirements, and migration from UvMapping.
