README.md
Voxel Renderer for S/W DOOM
by Andrew Apted, 2023.
About
This is a voxel renderer for classic DOOM source ports, in particular
ones like Chocolate-Doom which use software rendering (there is no
support for OpenGL rendering here).
I have written this code completely from scratch, without looking at any
existing code (like in the BUILD or ZDoom engines). I starting with a
basic description of the KVX file format, generally available on the 'net,
and figured a few things out by trial-and-error.
This work was inspired by the incredible DOOM and DOOM II voxel pack
created by Cheello (Daniel Peterson). This code was designed for that pack,
and may not handle any other voxel models -- in particular only the KVX
format is supported here.
Cheello's pack is available here: https://www.moddb.com/mods/voxel-doom-ii/
Doomworld thread: https://www.doomworld.com/forum/topic/130853-voxel-doom/

Setting up
Download Cheello's voxel pack for DOOM II and extract the PK3 file.
This PK3 file is not supported as-is, but it must be unpacked so that
all the KVX files are in a single directory called voxels. On a Unix
system, this can be done by the unzip program, as follows:
```
    mkdir voxels
    cd voxels
    unzip -j /path/to/cheello_voxels_v2_1.pk3
```
The -j option means to "junk" (ignore) the paths in the ZIP or PK3 and
unpack everything into the current directory. Only the KVX files need to
be kept, everything else can be deleted. The filenames need to be fully
lowercase, but in the current pack they already are.
On Windows, you should be able to open the PK3 with Windows itself and
copy'n'paste all the KVX files into a new folder called voxels. There
are two directories in the PK3 archive containing the KVX files, one for
DOOM and one for DOOM II, so be sure to grab 'em all.

About this repository
The bulk of the voxel renderer is in two new source files:
```
    r_voxel.c
    r_voxel.h
```
The rest of this repository is a copy of my "Carob Doom" port, which is
a fork of Chocolate-Doom (version 3.0.0) stripped-down to be easier to
compile, with some stuff removed (like networking), and a few other
changes. It is not a source port intended for people to actually use,
it is just a playground for some (wacky) ideas I have.
