What
A browser-based interactive 3D Gaussian Splatting map viewer on the docs
site — visitors can grab and spin a LiDAR-primed map with no install and no GPU
— plus the .ply→.splat exporter that feeds it.
Live (after merge + Pages deploy): https://rsasaki0109.github.io/lidar_slam_ros2/3dgs-viewer.html
Why
The 3DGS quality-lever track is wrapped up; the next lever is showing it. A
static GIF tells; a viewer you can rotate is the "drive-on-your-map" pitch made
tangible for the star campaign. No GPU is needed — rendering is client-side WebGL.
Pieces
tools/gaussian_splatting/ply_to_splat.py — numpy-only INRIA .ply →
.splat converter (reuses render_path.load_gaussian_ply). 32 bytes/Gaussian
(band-0 colour, sigmoid opacity, exp scale, normalised quat), emitted in
descending volume*opacity so the viewer's progressive loader draws the most
significant splats first. Knobs: --max-points (size/detail), --min-opacity,
--max-scale (drop giant floaters that streak off-axis). 10 CPU tests,
ament_flake8 clean, registered in graph_based_slam/CMakeLists.txt.
docs/assets/3dgs-viewer/ — vendored antimatter15/splat
WebGL renderer (MIT, LICENSE included). Local mods, each tagged with a
comment and listed in README.txt: resolve ?url= against the docs site,
default to the bundled map, open at a training-view pose (first frame is
photoreal), and start the auto-fly carousel disabled.
koide_lidar_primed.splat — 300k-Gaussian (~9 MB) export of the koide
LiDAR-primed map (SH deg-1, 15k iters, ~25.5 dB).
docs/3dgs-viewer.md + mkdocs nav + README link.
Honest limitation
The bundled map is a single-bag close-range capture, so the viewer opens at a
known-good training pose and orbiting far from the recorded path shows the usual
view-dependent Gaussian smear (the same overfit documented in the flythrough
notes). The docs page sets that expectation. The export tool itself is
scene-agnostic — point it at a denser/higher-overlap map and the free-orbit
range improves.
Verification
10/10 new CPU tests pass; ament_flake8 clean.
mkdocs build --strict passes; assets ship to site/.
Rendered end-to-end in headless Chrome (SwiftShader WebGL2): context + 9.6 MB
fetch + worker sort + draw all confirmed, first frame photoreal.
```
python3 -m pytest graph_based_slam/test/test_gaussian_splatting_ply_to_splat.py -q
python3 -m mkdocs build --strict
```
