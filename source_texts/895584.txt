Problem
The "per-pixel PBR" shading is Blinn-Phong with a roughness→exponent remap (packages/engine-software/src/index.ts:744-747, 809-819) and no Fresnel — F0 is applied flat (index.ts:739-742), so there's no view-dependent grazing response. This is the main reason photoreal-ish frames read slightly plastic: metals lack colored edge falloff, dielectrics lack rim brightening, rough surfaces spread specular incorrectly.
Proposed fix
Standard single-scatter microfacet in the existing forward loop (~30 lines):
GGX/Trowbridge-Reitz NDF
Smith height-correlated visibility (or the Schlick-GGX approximation)
Fresnel-Schlick with F0 from metalness/IOR (dielectric F0 ≈ 0.04, metal F0 = albedo)
Energy-conserving diffuse term (multiply by (1-F), (1-metalness))
Notes:
Do after the true-sRGB/linear-mips issue so determinism goldens churn only once for color work.
Math.pow in Fresnel can use the standard (1-cos)^5 polynomial — no transcendental needed; GGX needs none either. This reduces implementation-defined math on the hot path (helps the cross-platform determinism issue).
Update engine-three material mapping if needed so the parity budget test stays green (three's MeshStandardMaterial is already GGX-based — this change moves the software engine toward parity).
Acceptance criteria
A metal/roughness sweep test scene (spheres grid) shows grazing-angle Fresnel and correct metal tinting.
Goldens regenerated once; parity budget (once it exists) improves or holds.
Effort: 1–2 days.
From the July 2026 architecture & animation review.
