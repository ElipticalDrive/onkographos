Abstract. Block-coder style data compression schemes, such as JPEG, ZFP
and SPERR, rely on de-correlating transformations in order to efficiently store
data with entropy encoding schemes. These de-correlating transformations
are typically reliant on a uniform spatiotemporal sampling of the transformations and/or the data. Thus, for nonuniform data which may include spatial
(and temporal) nonuniformity, such as those arising from partial differential
equations solveing over complex geometries and unstructured grids, there is
not an efficient de-correlating transformation nor a data compression pipeline
that sufficiently adapts to this nonuniformity. We presented the manifold harmonic basis (MHB) as a de-correlating transformation, and prod d a collocation
method over the nonuniform domain for solving the eigen problem that defines
the MHB. Additionally, we demonstrated a modified version of ZFP’s compression pipeline that adapted to the problems presented by nonuniformity in
a block-coder style compression scheme. This resulted in a state-of-the-art
spatial data compression technique for nonuniform data which we call MeshFloat-Zip (MFZ). We illustrated the performance of the proposed compression
strategy and compared its accuracy against ZFP and SZ compressors (applied
to both original and reshuffled data) on three scientific computing datasets.
1. Introduction. There is a broad array of lossy data compression techniques
for scientific datasets; see, e.g., [8, 11]. The most established methods are dataindependent methods like the SZ class of methods [10, 49] and the JPEG class of
methods [54], including its scientifically oriented successors such as ZFP [34] and
SPERR [32]. Another class of methods comprises the high compression (but high
loss) data-driven methods such as those built on neural networks as in implicit neural
representations (INR) [46, 23, 44] or convolutional neural networks (CNN) [18] and
their extensions to non-uniform data (QCNN) [13].
In this paper, we focus on the low-error and low-spatial-compression regime,
where methods often prioritize error guarantees, robustness, and the speed of compression and decompression, potentially sacrificing compression rate in the process.
The methods such as JPEG, ZFP, and SPERR are commonly referred to as block

entropy encoding. This makes it rigorous, interpretable, and error-bounded.

Block coder methods begin with two key steps: i) the partitioning of the data
into blocks and ii) the projection of these blocks onto a suitable spectrum. The
blocking of arbitrary meshes is already understood [29], but the generalization of
spectral transformation for data compression has not been explored and is the focus
of this paper. We establish a suitable generalization for the spectral encoding of
data on a mesh and create a compression tool which replicates the success of other
methods for these meshed datasets.
One contribution of this work is the use of the manifold harmonic basis (MHB)
[50] as a spectral transformation for data on a mesh, thereby improving data compression for an important class of scientific data. This is achieved via an extension

A high-level overview of our entire compression pipeline is as follows. First, we
take the full dataset and partition it into smaller blocks, taking into consideration
that blocks should be spatially contiguous and compact in order to maintain spatial correlations while isolating regions of highly compressible data from regions of
incompressible data. For uniform grids, this is straightforward as it can be accomplished by simply indexing into the array in which the data is stored, which leads
to a good spatial partition because the memory layout of the data often matches
the spatial layout of the data. For nonuniform grids it is not as trivial, but it is
still well-understood and there are a variety of software libraries to achieve this.
We choose to use METIS [29] in our work as it is a well established and fast graph
partitioning algorithm.
Second, we aim to replicate the effect of the spectral encoding on the blocks
of data. This is the focus of our contribution. We choose to apply the MHB,
which was first explored in [50]. The MHB is a generalization of the discrete cosine
(or sine) transform (DCT or DST), and we will use it to spatially de-correlate data
before entropy encoding. This basis has seen extensive usage in graphics processing,
frequently being used to perform operations such as low-pass filtering of noisy 2D
surfaces [53]. Usage is complicated by its definition, since it does not possess a closed
form solution over most domains. Rather, the MHB consists of eigenfunctions of

The continuous eigen problem in Eq. (1.1) takes on different spectral properties depending on the domain Ω. For a simple domain like Ω = R, we have a
continuous spectrum from [0, ∞), where each of the eigenfunctions is of the form
f (x) = sin(λx + c) for x ∈ R and c ∈ {0, π2 }. If, instead, we take the domain to
be Ω = R/Z, the spectrum is now {2πk : k ∈ N}, where again f (x) = sin(λx + c)
with x ∈ R and c ∈ {0, π2 }. In general, spectral analysis of the Laplace operator is
a deep and well-researched field, which is outside the scope of this work. Instead,
we refer the interested readers to [21].
If we take the domain of f to be R/Z with boundary conditions f 0 (0) = 0 and
f 0 (1) = 0, then discretizing the problem with uniformly spaced points over the
interval, we recover a DCT. For the appropriate change of boundary conditions
over this domain, we can in fact recover type I, II, III, or IV DCT (or DST) [48].
As we shall explain in Sec. 2, the MHB provides us with a generalization of these
common spectral transformations which can be applied to any mesh, provided we
can find one that is discretized on our domain in an appropriate fashion.
The solution of Eq. (1.1) is typically derived through a GEVP involving a finite
element (FE) discretization of the Laplace operator. We instead consider a collocation method based on [26] which satisfies the necessary conditions to create an
MHB and is simpler to implement in higher dimensions, e.g., 4D spatiotemporal
data. Our method also takes the form of a GEVP and requires no changes to work
in any dimensional space.

1.1. Motivation. The Shannon source coding theorem (Theorem 1.1) is concerned
with a random source, X, from which we can produce a sequence of i.i.d. variables
X1 , X2 , . . . , Xn . These variables take discrete values in a finite set of symbols X .
Theorem 1.1. Given a random source X with entropy H(X), it is possible to
encode the i.i.d. sequence X1 , X2 , . . . , Xn with n(H(X) + ) bits for  > 0. This
original sequence is then recoverable from the encoding with probability 1 − .
While Theorem 1.1 holds for i.i.d. random sequences, in practice, we are interested in compressing sequences that have a nontrivial covariance structure. We
don’t have optimal encoding schemes for data that is not i.i.d., and so in order
to best utilize tools such as Huffman encoding or asymmetric numerical systems,
we attempt to diagonalize the covariance structure of the data to make the data
uncorrelated (as a proxy for independence). The Karhunen-Loève transform [43] is
the transform that diagonalizes a covariance matrix (or, more precisely, function).
In our case, the data is a discrete sequence, and so the Karhunen-Loève transform
is given by applying the adjoint of the eigenvectors of the (empirical) covariance
matrix of the elements of the sequence. Specifically, using the covariance matrix

compression, as it is the spatial correlation structure that is assumed for ZFP [34]

This motivation is a heuristic that attempts to explain the effectiveness of the
DCT and DST transformations, which is ubiquitous in data compression. Our work
aims to use a generalization of the DCT and DST in order to provide a de-correlating
transform for nonuniform data. This transform, a projection onto the MHB [53],
allows us to more effectively de-correlate nonuniform data, and thus, provide better
compression for an important class of scientific data.

1.2. Related work. There are a number of efforts to develop high-efficiency, errorbounded data compression tools for scientific data. The two most significant efforts
are ZFP [34, 12, 16, 22, 35] and SZ [10, 56, 33, 37, 36]. Each effort has produced a
number of different versions of the software over the last 5+ years. In the following,
we aim to characterize the most significant aspects of these methods.
ZFP. ZFP is a block-coder style compression tool that is designed for data on a
uniform grid. Operating on 4 × · · · × 4 blocks of d-dimensional data, this algorithm
takes a block of data, and transforms it using a DCT to decorrelate the data. This
is followed by a sequence of bit-wise operations that convert the 4d numbers into a
different kind of floating point representation. The only lossy stage of this process
is a zeroing out of a number of low significance bits, based on a user provided
threshold for the resulting error. Finally, this is followed by an entropy encoding
of the bit-planes. The development of ZFP has highlighted its zero-mean error
distributions [35, 12] and its speed of compression [22]. Due to both the blocking
and the data transformation in ZFP, when compressing nonuniform meshes, only
the implicit spatial correlation that is contained in the memory layout of the data
is leveraged.
SZ. SZ is a predictor-corrector framework that was originally based on using curve
fitting to interpolate data, and encoding large errors explicitly [10]. Its most recent version, which sacrifices a small amount of speed for increased performance,
is SZ3 [33]. SZ3 is a framework of compression stages, beginning with preprocessing (blocking and data transformations), followed by prediction using neighboring
points [24] or deep neural networks [36], then quantization, encoding, and a lossless
compressor that captures any latent structure after encoding. SZ3 has a number
of options for each stage, and adaptively selects the most performant option. Since
SZ does not use explicit geometric information, only the implicit spatial correlation
that is contained in the memory layout of the data is leveraged.
SPERR. SPERR is a 2D or 3D compressor that creates 256×256 or 256×256×256
blocks, then performs a wavelet transform, followed by SPECK coding and an outlier
detection and coding scheme [32]. It focuses on production-level features (errorbounded, parallel implementation) and is generally slightly better at compression
but slightly slower in comparisons to ZFP and SZ. Similar to those methods, for
unstructured data, SPERR only exploits spatial information up to the extent of the
data layout.
Other approaches. We only give a brief survey of the many alternative approaches
as they are either not suitable for production implementations or not applicable
to nonuniform data. Tensor decomposition based methods such as [2, 27] and
TTHRESH [3] are promising but not sufficiently applicable for nonuniform mesh
data. MGARD [20] is a multigrid method which uses a multi-resolution decomposition of the data to make the retrieval of lower precision data much faster. This is
clearly applicable to nonuniform mesh data, but MGARD’s primary contribution
is the speed of its compression and decompression of data [9].
MHB. Aside from data compression, there is also related work involving the generation of the MHB. The MHB is used in mesh filtering, mesh compression, parameterization, and segmentation [28, 51, 47, 15]. This task is complicated by a
no-free-lunch theorem [55] for the discretization of Laplace operators, stating that

for 2D nonuniform meshes, Laplace discretizations cannot be simultaneously symmetric, strictly positive, locally defined, and vanish on linear functions. Each of
these properties may be important for different applications of the discretized operator. Initial attempts to generate these basis functions used symmetrized discrete
Laplacian operators [41], defined over a graph, and Galerkin projection [31]. Later,
the work of [53] offered a refined approach using the discrete exterior calculus to
correctly consider the symmetry and discretization of the continuous Laplace operator. Yet, other approaches have been applied to point clouds using Voronoi cells [38]
or Delaunay triangulation [5]. In the context of compression, these approaches can
be slow or may not generalize directly beyond two dimensions. In the present work,
our method is instead based on radial basis function (RBF) interpolation and avoids
the discretization of the Laplace operator, which allows for a faster construction of
the MHB that is applicable in all dimensions.
1.3. Contributions. Our contributions primarily fall into two categories: i) generation of the MHB and ii) the compression of spatial data discretized on a nonuniform grid (or mesh) or any non-Cartesian domain. We are unaware of any work
that uses the MHB for compression, other than [28], which employs the MHB to
compress the nodes of a mesh, an unrelated task.
MHB generation. The collocation method we use to generate the MHB is most
closely related to Kansa’s original RBF collocation method [26]. The equation on
which we are using this collocation method bears resemblance to the Helmholtz
equation (∆f = −κ2 f ), but we are not concerned with any particular solution for
a given κ. Furthermore, we seek real solutions since complex solutions make the
resulting basis inefficient for data compression.1 We will achieve this by solving a
GEVP. The considerations we make to guarantee that the GEVP produces a basis
of real eigenvectors is unique to our work. This is also the first MHB generation
method that is not dependent on the particular dimension the points are embedded
in, a consequence of the collocation technique.
Compression. The DCT has convenient properties that make the resulting compression chain slightly easier than when using the MHB. We have overcome these
challenges with small contributions to the block coder compression chain. The
MHB, unlike the DCT, is not guaranteed to contain the all-ones vector, 1 ∈ Rn . To
fix this, we simply subtract the mean from the data, and compress this scalar along
with the spectra of the mean-centered data. More significantly, the DCT on a 1D
grid produces a simple and convenient ordering for the spectra, via spatial frequencies of the cosines. For an element of the DCT, cos 2πλi x, with frequency λi , we can
order the spectrum according to the sorting of λi . In 2D, a reasonable (though not
strict) ordering based on kλk2 is also possible. In the MHB, however, the basis elements are not spatially uniform, and eigenvalues of the GEVP may have geometric
multiplicity. This makes the compression of the data spectrum more complicated,
as we cannot use the method ZFP [34] uses to compress trailing zeros of each bit
plane. Instead, we apply a range encoder whose compression performance is only
reliant on the entropy of the data, and not the ordering of the spectrum.

We perform numerical experiments to compare the MHB constructed using this
RBF collocation method with the traditional MHB construction via the FE method
(with bilinear, triangular elements). We focus on runtime since satisfying the eigen
problem to extremely high accuracy is not consequential for data compression. We
run the FE method at the same resolution as the discretized domain in each case
and note that, empirically, it produces a basis of real solutions. Fig. 2 shows that
the RBF is slightly faster than FE in the large n regime, while in the small n regime
the RBF method is slower, likely because it is dominated by the auto-differentiation
framework with which we implemented the GEVP system. This difference in speed
is insignificant to the compression task, since the MHB can be generated once and
used for compression over and over again, e.g., on spatio-temporal data. Note
that the RBF collocation approach is more straightforward to extend to higherdimensional data, e.g., 4D data, thus allowing the compression chain to exploit
spatial-temporal correlations.

Arithmetic range encoding. We apply a classical technique from the late 1970s
known as arithmetic range encoding to each bit plane in order to take further
advantage of the reduced entropy of the spectral representation of the data [40].
This approach encodes a stream of bits as a single number by using a model of the
probabilities that each symbol will occur. Our case is the simplest one, since our
alphabet consists of {0, 1}. Given a pair of probabilities {p0 , p1 } representing the
fraction of the data that is 0 and 1, respectively, and a range within which to encode
our symbols, we apply the algorithm symbol by symbol until the entire message is
encoded.
This encoding method relies on accurate probabilities and messages of sufficient
length to avoid the overhead cost from expanding the length of the message [30].
In the case where p0 = p1 = 0.5, no compression is possible. We utilize a 32-bit
integer for the encoding range via the python package constriction [4].
We expect the MHB transform to produce a few large coefficients and many
smaller coefficients, on average. Let the bit planes be indexed by k ∈ {23, 22, . . . , t}.
This means that as we move from the most significant bit plane (23) toward the
least significant bit plane (t), we expect the first few bit planes to contain a larger
proportion of zeros, relative to the least significant bit planes. We find the bit plane
in which we first see pk0 = 0.45, which acts as a threshold for when we no longer
expect to compress the following bit planes, and then find the true proportion of
zeros in the preceding bit planes. We then transmit two quantized numbers with

3.6. Discussion on improvements. There are several avenues for future improvements to MFZ.
484
KEVIN DOHERTY, STEPHEN BECKER AND ALIREZA DOOSTAN
A first issue is that we do not compress across blocks, time, nor channels. Compression across time is straightforward by using spatial-temporal blocks (e.g., of
dimension 3 or 4 for 2D or 3D spatial data), and lack of compression across blocks
is a fundamental drawback to block-based methods that is shared by other methods.
The largest area for improvement is compression across channels, which is naturally
handled by data-driven methods such as INR [46] and QCNN [13] but not easily
handled by block coders.
Another class of issues are the error-bounds and the distribution of the error. We
perform point-wise truncation in the spectral domain, leading to `∞ -norm guarantees on the spectral coefficients. This can give a bound on the `2 - or `∞ -norm of
the original data, but it is not tight; again, an issue shared by many block coders.
A related issue is structure in the error. A simple error bound may allow for a small
but coherent signal in the error, possibly leading to incorrect scientific deductions.
Some compression schemes focus on producing uncorrelated and normal distributions for the error, and these techniques could be extended to MFZ. We note that
in our numerical experiments, we did not see more coherent signal in the residuals
of MFZ compared to SZ and ZFP.
An issue with the coding step is that the 32-bit integer range we compress into
(during range encoding) is large for the message sizes since we may not be using
the entire information capacity of all of the 32-bit integers, but the convenience
of the constriction package has made implementation much easier. This leaves
some overhead in our lossless compression scheme. Another coding issue is that our
representation for all zero blocks is inefficient compared to something like ZFP. This
means that for data which contains a larger number of zero blocks, our performance
suffers slightly.
Finally, the code has been implemented in Python, which is slow compared to
state of the art compression software written in C++. For example, the MFZ compressor is 50× slower than ZFP, owing mostly to inefficiencies in array creation, type
casting, and bit string manipulation in Python. A better implementation of MFZ
could approach the performance of ZFP, aside from the MHB creation and a single
floating point matrix-vector multiplication (ZFP uses a special DCT, implemented
only with bit shifts). The MHB creation consists of many small generalized eigenvector problems, which can be parallelized and are only done once at the beginning
of a compression task. We believe that a better implementation would make this a
useful compression tool for scientists working with data over meshes.
4. Conclusion. We have presented a block coder data compression tool that has
been designed specifically for nonuniform grids and possibly non-Cartesian domains.
We accomplish this by partitioning the mesh with METIS, generating the MHB for
each block, and using a set of data compression steps that are used in ZFP [34].
This compressor shows a slight improvement over ZFP on slightly non-uniform
meshes in 2D, and a significant improvement on the 3D dataset, since there is
less natural spatial proximity in the data layout. We leverage an RBF collocation
method to generate the MHB that is simple and more convenient to extend to 4D
spatiotemporal data, as compared to alternative finite element methods. We also
use classical data compression tools to adapt to some of the changes the MHB
necessitates in the compression chain. This results in an advancement of the block
coder style compressors and an improvement in the compression of scientific data
on non-Cartesian domains.
