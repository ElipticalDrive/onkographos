The proposed method differs from the POT approach in [22]
in that a moving source instead of a moving receiver is considered
in this paper, which is the case where an interpolation method is
crucial. In addition, well motivated cost functions and dummy costs
are provided, which increase interpolation performance. The moving
source case is considered using optimal transport (OT) in [23], but
without explicitly modelling image sources, which is the key to the
proposed approach.
To effectively interpolate, the structure of the image source geometry should be exploited. In particular, when the physical source
moves, each image source moves the same distance in a direction depending on the unknown room geometry. In this paper, this structure
is encoded into a statistical model, from which a maximum likelihood estimator for the assignment is obtained. This is used to derive cost functions for the POT problem that exploit the geometric
structure. In addition, the statistical model is used for a principled
approach to determining which points should be discarded.
1. INTRODUCTION
2. BACKGROUND
ABSTRACT
In geometrical acoustics, room impulse responses (RIRs) can be represented by a set of image sources in free space. For a fixed source
position, the image sources allow for computing RIRs at arbitrary receiver positions. However, for a moving physical source, the image
sources also move, making interpolation more difficult. In this paper we develop an interpolation method for image source positions
of a moving source, given image source positions at the start and
end of the trajectory. The method exploits the fact that each image
source moves the same distance as the physical source. A statistical model is developed to derive cost functions and an appropriate
dummy cost used in the proposed partial optimal transport (POT)
approach. Through simulated experiments, POT using the proposed
cost functions is shown to be effective compared to the alternatives.
A room impulse response (RIR) represents the acoustic path from a
source to a receiver. Knowledge of RIRs is fundamental to a wide
range of applications in audio signal processing, including speech
enhancement and noise control [1–4]. Therefore, measuring and interpolating RIRs represents a key problem in acoustic signal processing [5, 6]. A popular approach is to represent RIRs in a region
by multiple sources in free space, making interpolation to other receiver positions straightforward [7–9].
In geometrical acoustics [10, 11], the RIR can be represented
by a set of image sources in free space, each corresponding to a
sequence of specular reflections. This is referred to as the imagesource method (ISM), proposed in [12] and later extended to model
the acoustics more accurately [13–16]. The image source positions
are independent of receiver position, and the model can therefore
be used for RIR interpolation and acoustical analysis of the room
[17]. However, image source positions depend on the position of the
physical source, therefore an interpolation method is required for a
moving source.
Without detailed knowledge of the wall geometry, which here
is assumed unavailable, the image source positions must be obtained
from collected sound data [18]. The visibility of an image source depends on both source and receiver position [19], meaning two measured sets of image sources will contain image sources not present in
the other. It is therefore essential to find an assignment between two
sets of image sources while discarding those without a good match,
a task well suited to partial optimal transport (POT) [20, 21].

5.3. Choosing dummy cost parameter ξ
For good performance, ξ has to be chosen appropriately, which
depends on the cost function. In (7), only mass between points
satisfying c(xi , yj ) ≤ 2ξ will be transported [25, Lemma 3.2].
Therefore, the parameter α is introduced, which is the probability that a matched pair falls outside the accepted region, i.e., that
c(xi , yπ−1 (i) ) > 2ξ. The parameter α is interpretable independently of the cost function.
Each cost function can be written in terms of r = ∥x − y∥2 ,
which according to the statistical model follows r ∼ σχ3 ( σγ ), where
χ3 is a non-central chi distribution with 3 degrees of freedom. Therefore, the cumulative distribution function of c(x, y) for each cost is
known, which can be used to solve Prob(c(x, y) > 2ξ) = α numerically [28, Ch. 3-5]. The density of r together with the accepted

6.2. Methods
The proposed method using the cost functions cML , cSI , and cEu , is
referred to as maximum likelihood, source-informed, and Euclidean
respectively. The following methods are considered for comparison.
Oracle uses the ground truth assignment π and performs interpolation according to Section 4.2 using the noisy position measurements. The method represents a ceiling for the methods using displacement interpolation, and indicates how much error is caused by
measurement noise and the fading of unmatched image sources.
Linear interpolation combines the measures linearly as µ̂τ =
(1 − τ )ν0 + τ ν1 . This is equivalent to applying linear interpolation
between RIRs as hµ̂τ = τ hν1 + (1 − τ )hν0 .
No transport is a baseline for the assignment error, which sets
M = 0, and transports all mass to the dummy points. It is also
indicative of how much mass should be transported by an ideal plan.
6.3. Data
Two types of data are considered in the experiments.
Statistical data is generated using the statistical model described
(0)
in Section 5. The true image source positions ri are sampled
with uniform distribution over a cube of volume V I0 , where V =
120 m3 , and I0 = I1 = 57, I01 = 49. The M = 16 receivers are
placed randomly with uniform distribution in a cube of volume V
that is centered in the larger cube. Each unmatched point changes
visibility at a random point along the trajectory τi ∼ U([0, 1]).
ISM data is generated as follows. With equal probability, the
number of faces is randomly selected W ∈ {6, . . . , 8}. The walls
are defined by a random convex polygon with W − 2 corners [29],
with parallel floor and ceiling. The physical source position s0 is
random with uniform distribution in the room, and s1 is randomly
chosen γ distance from the initial point with uniform distribution,
both positions are placed at least 0.5 m from the closest boundary.
Image sources up to order N = 3 are generated [30]. The M = 16
receivers are placed randomly with uniform distribution in the room.
6.4. Results
All results are presented in Fig. 2, where the mean result from 256
random trials is presented. The bandwidth is chosen as B = 250 Hz,
and the rejection probability as α = 0.001. Unless explicitly varied,
σ 2 = 10−3 and γ = 5.
First, the proportion of image sources detected in both ν0 and
ν1 was varied for statistical data. When this proportion is small, the
NMSE is similar between all methods, despite source-informed and
maximum likelihood attaining much lower assignment error. This
indicates a performance floor for the NMSE caused by mismatch
between the fading of image sources in (9) and their true behavior.
Then, the NMSE and assignment error are computed for different values of γ and σ, using both types of data. For statistical data,
Euclidean and linear interpolation perform significantly worse compared to source-informed and maximum likelihood, which almost
attain the oracle performance. For ISM data, the performance difference is smaller, with Euclidean only being slightly worse than maximum likelihood and source-informed. Note that source-informed
and maximum likelihood perform indistinguishably from the oracle
unless the noise variance is high. All POT methods perform significantly better compared to linear interpolation, except at very high
noise levels.
In the high-noise for ISM data, Euclidean performs better than
source-informed and maximum likelihood, which indicates that the
statistical model could be extended to capture more features of the
ISM data. The results indicate that source-informed is the overall
pragmatic choice, providing similar performance to maximum likelihood, while being simpler, as only the dummy cost ξ depends on σ
and not the cost itself, so ξ may also be set heuristically.
7. CONCLUSION
In this paper, an interpolation method for image sources based on
POT has been developed. By introducing a statistical model, appropriate cost functions could be derived, informed by the maximum likelihood estimator of the assignment between the data points.
Through simulated experiments using both statistical data and data
from the ISM for random rooms, the proposed POT approach is
shown to be more accurate than linear interpolation, with maximum
likelihood and source-informed costs being particularly effective.
