Contributor
Adds 3D Gaussian Splatting (3DGS) support, à la PlayCanvas SuperSplat: load gaussian-splat captures, project each gaussian to a screen-space ellipse with EWA splatting, depth-sort, and composite with alpha. Delivered as a new self-contained @infinite-canvas-tutorial/gsplat package (packages/plugin-gsplat), following the standalone plugin-particle precedent rather than editing core ECS MeshPipeline.
Data model & parsers
GsplatData — SoA store (centers, linear scales, (x,y,z,w) quats, RGBA color+opacity, captured SH degree) with bounds/centroid helpers and constructor validation.
.ply (INRIA/SuperSplat; ASCII + binary LE/BE) and .splat (compact 32-byte antimatter15) parsers. PLY decodes exp(scale), sigmoid(opacity), 0.5 + SH_C0·f_dc, (w,x,y,z) quats. Entry points parseGsplat() / inferGsplatFormat().
Rendering
GLSL 300 ES EWA splatting shaders (one transpile path → both WebGL2 & WebGPU via device-api): vert builds Σ = R S Sᵀ Rᵀ, projects through the perspective Jacobian, and expands an instanced quad along the ellipse axes; frag outputs premultiplied-alpha gaussian weight.
GsplatRenderer device-api class: instanced quads, interleaved per-instance buffer, premultiplied "over" blend (ONE / ONE_MINUS_SRC_ALPHA), cached per-frame byte views. Optionally renders into a caller-supplied RenderTarget (e.g. swap-chain on-screen texture); otherwise returns an offscreen texture.
```
const renderer = new GsplatRenderer(device);
renderer.setData(parseGsplat(buffer, { nameOrUrl: 'scene.ply' }));

const onscreen = device.createRenderTargetFromTexture(swapChain.getOnscreenTexture());
renderer.render({ viewMatrix, projectionMatrix, width, height }, onscreen);
onscreen.destroy();
```
Depth sorting
O(n) 16-bit counting sort by view-space depth (farthest-first); instance buffer uploaded in sorted order each frame for correct back-to-front compositing.
Tests, docs & example
Unit tests for parsers + math (covariance trace invariance, SH, sort ordering).
Package README, en/zh tutorial pages (format, EWA, sorting, WebGL/WebGPU differences) wired into nav, and a self-contained reference Gsplat.vue.
Scope & follow-ups
This MVP supports SH degree 0 (DC color) and CPU sort. The shader's GPU visual output is not yet verified in CI (no WebGPU/WebGL runtime in the sandbox); a gl+xvfb snapshot test is a recommended follow-up. The live demo component is included but not embedded in built docs.
Deferred: GPU radix sort (WebGPU compute) / WebGL worker sort; higher-order SH (degree 1–3); declarative gsplat node type in core ECS (serialize/deserialize/pick); editing (selection, transform, crop box).
