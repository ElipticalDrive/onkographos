Summary
SPLAT-FUSED (moonshot 12): 3D Gaussian splats, COPC LiDAR and DEM terrain are path-traced in one ReSTIR pass and shadow each other through one function, shadow_transmittance = T_splat · T_lidar · T_terrain. Behind the new splat-fusion Cargo feature, which the wheel enables.
src/splat/: GaussianSplatCloud (SoA, packed Σ⁻¹, memory-tracked) and 3DGS .ply loader; BVH/TLAS over splat pages, COPC nodes and terrain tiles; out-of-core page stores with a fixed GPU residency pool, LRU eviction, exact / progressive paging.
src/shaders/splat/gaussian_intersect.wgsl (analytic ray/Gaussian closest-hit and any-hit, 3σ proxy) and src/shaders/fusion/unified_occlusion.wgsl.
The fused kernel is a specialization of the existing hybrid ReSTIR kernel (shader_sources::fused_kernel()); the default kernel is byte-identical. The reservoir target calls shadow_transmittance.
src/path_tracing/fused_reference.rs: AEQUITAS wavefront path-traced reference over hard proxies, plus shadow IoU.
Python: forge3d.load_gaussian_splats, forge3d.render_fused, forge3d.splat.render_fused_reference, page-store helpers, splat.pyi, API contract lists. Both render entrypoints take certificate= / cache=.
Docs: docs/splat-fused.md, CHANGELOG.

Known limits
The reference traces hard proxies, so soft shadow built from many overlapping faint splats has no counterpart there; splat-on-terrain has the thinnest margin.
GPU splat colour uses SH bands 0–1; higher bands are evaluated on the CPU.
LRU eviction happens across views (render_fused_sequence, Rust only).

Limits remediation (follow-up commit)
Removes the ten limits found while producing the demo videos (plan and per-task evidence in docs/superpowers/plans/2026-10-03-splat-fused-limits*.md):
Resolution: seamless tiles (tile=) keep per-pixel GPU memory bounded by one tile. A 1920x1080 frame renders in 471 MiB, and tiled output is bit-identical to monolithic. return_aovs=False skips the AOV targets.
Terrain: a conservative f16 min-max pyramid halves terrain memory with unchanged output. An 8-bit sRGB colour map (FusedTerrain.albedo_map). Smooth shading normals (terrain_smooth_normals).
LiDAR: oriented surfels for planar returns (lidar_surfels). Small COPC nodes are packed into shared pages (Lauterbrunnen: 12,959 to 1,228 pages). COPC header bounds are read from the correct LAS 1.4 offsets.
Python: self-shadow bias kwargs and the self_bias AOV, GaussianSplatCloud.transformed, and render_fused_sequence/FusedView (one kernel, one page pool and one terrain upload per sequence).
Fix: mapped terrain no longer takes the base kernel's spectral-ReSTIR path, which bypassed shadow_transmittance.
The golden image was regenerated once, for smooth normals. Shadow IoU is unchanged or better: 0.9235 / 0.9928 / 0.9730 / 0.9701 / 0.9713.
