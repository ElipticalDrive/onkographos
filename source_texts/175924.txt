Projecting and rasterizing a mesh onto a 3D grid (voxel model)?
For a 2D screen, you have a projection matrix to transform a mesh and use the x and y coordinates of each vertex to determine which pixel lies inside a triangle (or line or point).
But what if you have a 3D voxel model, e.g. a human, instead of a 2D pixel grid? And you want to map another 3D model (not voxel) onto it?
The easiest method would be to use the closest point to the voxel on the textured mesh of the 3D model. However, this would result in similar artifacts as regular point sampling.
So I would like to use trilinear sampling. But how do I get the UV coordinates and gradient for each voxel?
I could move on the mesh by 1 cm (the size of the voxel) and compute the gradient from that. However, the samples would overlap in some places and leave gaps in other areas.
My ultimate goal is to map an armor texture onto multiple voxel characters (e.g. dwarves, elves, ...) so I won't have to adjust it for every single character. So I luckily have control over the shape of the meshes and they're not completely arbitrary. I also have to store the texture coordinates, not the color, so I can change the armor in the game.
One last idea I have would be to get the closest point to each voxel on the mesh and determine the "pixels" based on a voronoi diagram. But those regions will not be squares, so I guess I should just use the texture coordinates at the corners of the shapes and get the gradient from those?
Am I on the right track here?
Is there an existing technique similar to this?
