Security architecture risk: 🔵 Low · up to 8a0e5
The current integration does not automatically execute terrain generation or add a remote entrypoint. However, extreme dimensions can overflow the public size validator, breaking its promise to reject invalid shapes safely.
Retained concerns
Medium · reliability · inferred: The new bounded-volume contract uses unchecked products before comparing against MAX_CELLS and MAX_CHUNKS. For size (1073741824, 16, 1073741824) and chunk (1, 1, 1), both true counts are 2^64. Validation therefore panics with overflow checking, or wraps both counts to zero and accepts the shape without it. Construction then produces empty chunk and surface tables through further narrowed products, and an in-bounds read at the origin panics. GenSpec validation inherits this behavior, so malformed dimensions escape the advertised recoverable-error boundary. No lower-trust production caller was identified, limiting demonstrated exposure to explicit library consumers.
Security review details
Security Blast Radius
inferred — The demonstrated failure scope is an application or worker explicitly invoking the new library with malformed dimensions. Current registration does not automatically invoke generation, and the inspected caller relationships did not establish remote or content-driven generation execution. Remote denial of service is therefore not established.
Security Findings and Attack Paths
inferred — The dimension-overflow path crosses the intended validation-to-allocation control: malformed public API inputs can cause a panic instead of a recoverable rejection. This path is newly introduced with the crate; an attacker-controlled source reaching it has not been demonstrated.
Trust Boundaries and Controls
observed — Generation selects named, versioned function pointers registered by application code. Registry validation precedes dispatch, and the registry and palette remain immutably borrowed during generation. Naming a step does not itself grant the ability to supply executable callbacks.
Resilience and Maintainability Implications
inferred — Attempt-local ownership contains ordinary generation errors, but does not turn panics into retryable errors or roll back external effects performed by application-defined callbacks. The supported rollback boundary is the locally owned generated state.
Hardening Proposals
proposed — Make shape validation fail closed with checked multiplication or division-based cap checks, then derive allocation lengths only from validated counts. Arithmetic overflow should produce the same recoverable invalid-shape result as exceeding the documented limits.

On hold (draft). The game this was built for has changed its plan: it follows its design, not its old build. The design asks for a cube-built look (GDD §30.1) on regions of pre-made macro-tiles (GDD §10.1, TDD §21–23), and rules out a generated voxel world, voxel editing and destructible terrain (GDD §5, §10.1, §39). This crate's noise, generation steps and generation-time edits served a seed-generated voxel island, which the new plan drops.
When the world milestone is re-planned, we decide what tile-based worlds still need from this crate: a cell volume, the block palette, the mesher. Until then this PR stays open as a draft. The gate passed and the CodeRabbit comments are resolved.
