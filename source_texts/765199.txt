The cloud rendering system has been enhanced to provide more flexibility and control through the UI.
Cloud Raymarching Improvements:
Step Count: Configurable number of samples along the ray.
Extinction Factor: Controls how much light is absorbed/scattered per step.
Density Limits: Configurable minimum and maximum density accumulation per step.
Drop-off Rate: A smoothstep-based rate for culling low-density cloud regions.
Jitter Modes: Toggle between spatiotemporal blue noise and a stable 8x8 Bayer matrix for step-size jittering.
Cloud TAA Enhancements:
Toggleable TAA: Can be enabled or disabled via the UI.
Subpixel Jitter: Uses a Halton sequence (bases 2, 3) to improve temporal convergence when TAA is enabled; zeroed out when disabled.
Alpha Control: Configurable blend weight for history accumulation.
Variance Clamping: Adjustable gamma factor for neighborhood clamping to reduce ghosting.
System Updates:
Updated LightingUbo in include/light.h and shaders/types/lighting.glsl with proper std140 alignment.
Adjusted manual SH coefficient offsets in src/graphics.cpp.
Refined AtmosphereEffect::Apply to correctly propagate frames through the temporal pipeline even when TAA is disabled, preventing frozen clouds.
Added a new "Cloud Raymarching & TAA" section to the Environment UI widget.
All changes have been verified with glslangValidator and the project's test suite.

This commit introduces granular control over the cloud raymarching process
and the temporal anti-aliasing (TAA) system.

Key changes:
- Added `cloudStepCount`, `cloudExtinctionFactor`, `cloudMinDensity`,
  `cloudMaxDensity`, and `cloudMinDropOff` to cloud raymarching.
- Implemented a toggle between blue noise and 8x8 Bayer matrix for
  raymarch step jittering.
- Implemented Halton-sequence-based subpixel jitter for cloud TAA.
- Added UI controls for all new parameters in the Environment widget.
- Fixed a bug where disabling TAA would cause clouds to stop updating.
- Updated `LightingUbo` structure and alignment to accommodate new fields.
