Is a powerful, one-click tool that instantly transforms any 3D model in your scene into a MagicaVoxel (.vox) file. This tool seamlessly bridges the gap between traditional 3D meshes and voxel art.
Render pipeline compatibility
The Built-in Render Pipeline is Unity's default render pipeline. It is a general-purpose render pipeline that has limited options for customization. The Universal Render Pipeline (URP) is a Scriptable Render Pipeline that is quick and easy to customize, and lets you create optimized graphics across a wide range of platforms. The High Definition Render Pipeline (HDRP) is a Scriptable Render Pipeline that lets you create cutting-edge, high-fidelity graphics on high-end platforms.

Description
Turn your standard 3D models into beautiful voxel art in seconds! Mesh to VOX Converter is an intuitive, highly precise editor utility designed to read the geometry, materials, and textures of your Unity objects and translate them into a highly accurate voxel grid.
Perfect for voxel genres, retro-stylized games, or creating destructible terrain assets, this tool is designed for maximum flexibility. It works out-of-the-box with any render pipeline (Built-in, URP, or HDRP) and gracefully handles third-party assets or custom HLSL shaders.
Have an animated character? No problem! The tool can bake SkinnedMeshRenderer components, capturing the exact animation pose of your character at the moment of conversion.
Key Highlights:
Highly Customizable: Adjust the voxel size to balance between performance and high-fidelity detail.
Smart Interior Filling: Choose whether your voxel models should be hollow, filled with a solid color, or filled using an advanced "Nearest Shell Color" algorithm for solid destruction mechanics.
Robust Texture Detection: Automatically detects standard pipeline textures, with an option to specify custom texture properties to ensure compatibility with any custom shader.
Full Vertex Colors & Texture Blending Support: Allows the converter to read, sort, and mathematically interpolate vertex color data, applying smooth gradients directly to the generated voxels.
Note: The 3D models shown in the promotional images and videos are for demonstration purposes only and are not included in this package.
Technical details
Key Features:
Universal Conversion: Supports converting both static meshes (MeshFilter) and animated characters/objects (SkinnedMeshRenderer in their current pose).
Pipeline Agnostic: Fully compatible with Built-in, Universal Render Pipeline (URP), and High Definition Render Pipeline (HDRP).
Advanced Material Support: Automatically fetches _MainTex, _BaseMap, or _BaseColorMap. Supports comma-separated custom texture properties for complex or custom shaders.
Color & Palette Management: Automatically extracts colors from textures or base material properties and generates an optimized 256-color MagicaVoxel palette.
Alpha Clipping Support: Recognizes transparent textures (e.g., foliage, chainlink fences) via a customizable Alpha Threshold slider.
Interior Fill Modes: Includes 3 filling algorithms: None (Hollow), Solid Color (Optimized single-color core), and Nearest Shell Color (Calculates core colors based on the nearest exterior surface).
Shader Graph Workaround: Dealing with procedural materials that can't be read directly via CPU? Simply bake your custom shader results into the mesh's vertex colors, and the wizard will instantly generate the correct VOX palette.
Automatic Chunking for Large Models: Bypasses MagicaVoxel's 256³ voxel limit by intelligently slicing oversized models into a grid of uniform chunks. Each chunk is saved as an individual .vox file with spatial coordinates in its name, allowing for seamless reassembly in MagicaVoxel's World Mode.
High Precision: Uses custom symmetrical rounding and vertex sorting to prevent diagonal gaps and mathematical artifacts on flat surfaces.
Safe Error Handling: Gracefully falls back to vertex/material colors if textures are unreadable, without throwing internal engine console errors.
Format: Exports directly to the standard MagicaVoxel .vox format.
Clean Project: 100% Editor-only script. It will not bloat your final game build.
Engine Compatibility: This tool was natively developed using Unity 6 (6000.4) to ensure optimal performance with the latest engine features. It has also been thoroughly tested on Unity 2022.3 LTS to guarantee stable backward compatibility for your existing projects.
Created with AI
The C# editor script included in this package was developed with the assistance of an AI large language model (LLM) to help write, optimize, and debug the mathematical algorithms for voxel grid calculations and symmetric rounding logic. All AI-assisted code was manually reviewed, thoroughly tested, and modified by the publisher to ensure full functionality, safety, and compatibility with the Unity Editor.
