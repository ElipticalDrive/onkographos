Raytracing is deprecated—say hello to Raymarching! While raytracing has been the go-to technique for rendering realistic 3D environments for decades, raymarching introduces a more versatile, flexible, and powerful approach. With raymarching, not only can we achieve the stunning visuals of traditional raytracing, but we can also explore effects and geometries that were previously impossible. This includes smooth blending of objects, infinite repeating spaces, and intricate fractals, all with a highly optimized rendering pipeline.
In this post, I’ll walk you through my C++ project using OpenGL and GLSL shaders that leverages raymarching to render complex 3D scenes. I’ve designed a sleek, easy-to-use GUI that allows full control over the scene, including a 3D first-person fly-camera to navigate and explore the environments interactively.
What Makes Raymarching Unique?
Raymarching works differently from traditional raytracing by rendering 3D scenes using signed distance fields (SDFs). Rather than tracing rays until they hit a surface, raymarching steps along each ray incrementally and calculates the distance to the nearest object in the scene. This technique allows for smooth interpolation between shapes and can handle complex geometric transformations with ease. Some key advantages of raymarching include:
Fractal Rendering
One of the most visually striking features of raymarching is the ability to render fractals with ease. By defining recursive SDF functions, you can create incredibly detailed fractals like the Mandelbulb or Menger Sponge. These shapes are not only infinitely detailed but also inherently mathematical, allowing for zooming into intricate structures without losing resolution.
Real-Time Reflections
One of the core visual effects in raymarching is the ability to create smooth, accurate reflections. Using the properties of the SDF, rays are reflected off surfaces, and roughness is achieved by introducing randomness into the reflection vector. This allows for beautiful glossy surfaces and reflections that vary in smoothness, simulating materials from glass to rough metals.
Infinite Repeating Space
Raymarching enables the simulation of infinite repeating environments by mapping positions back into the scene using modular arithmetic. This means you can create endless corridors, repeating fractals, or tiled environments, all of which add a surreal sense of scale and immersion to the scene.
Smooth Shape Blending (Body Interpolation)
A hallmark of raymarching is the ability to smoothly blend between multiple objects using the smooth_min function. This creates a soft transition between overlapping shapes, which can be used to create organic, natural forms or artistic designs. Body interpolation allows the merging of multiple SDFs, enabling unique effects like smoothly connected surfaces, something traditional raytracing struggles with.
How it works
The application is written in C++ and utilizes GLSL shaders for real-time raymarching. Here’s a brief overview of the main components:
Raymarching Loop
The raymarching process involves stepping along each ray until it either hits a surface (i.e., when the distance is sufficiently small) or exceeds a maximum distance threshold, ensuring we don’t waste time on rays that won’t intersect an object.
```
vec2 marchRay(vec3 origin, vec3 direction){
    float dist = 0.0;
    vec2 distToObj = vec2(0.0, 0.0);
    for(int i = 0; i < u_MarchSteps; i++){
        vec3 marchPoint = origin + direction * dist;
        distToObj = map(marchPoint);
        dist += distToObj.x;
        if(dist > u_RenderDistance || distToObj.x < u_SurfaceDistance ){
            break;
        }
    }
    return vec2(dist, distToObj.y);
}
```
Reflection Handling
When a ray hits a surface, a reflection ray is cast based on the surface’s normal. For roughness effects, this reflection is randomized, scattering the ray based on the surface’s material properties. GLSL shaders handle the real-time lighting and shading, using Phong reflection for smooth surfaces and ambient occlusion for added realism. Multiple light sources can be defined, and soft shadows are calculated based on ray occlusion.
```
vec3 ComputePixel(vec3 rayOrigin, vec3 direction, int iter){
    vec3 color = vec3(0.0);
    vec3 sourcePosition = rayOrigin;
    vec3 rayDirection = direction;
    
    for(int i = 0; i < iter; i++){
        vec3 iterationColor = vec3(0.0);

        vec2 dist = marchRay(sourcePosition, rayDirection);
        if(dist.x > u_RenderDistance){
            iterationColor += mix(u_SkyLowerGradient, u_SkyUpperGradient, (dot(vec3(0.0, 1.0, 0.0), rayDirection) + 1) / 2);
            color += iterationColor * pow(u_Reflection, i);
            break;
        }

        vec3 surfacePoint = sourcePosition + rayDirection * dist.x;

        vec3 lightRay = normalize(u_SpotLightPos - surfacePoint);
        vec3 norm = normal(surfacePoint);

        // Diffuse
        vec3 albedo;
        if(dist.y < 0.0){
            float tile = mod(floor(surfacePoint.x), 2.0) * (1.0 - mod(floor(surfacePoint.z), 2.0)) + mod(1.0 - floor(surfacePoint.x), 2.0) * (mod(floor(surfacePoint.z), 2.0));
            albedo = (vec3(tile) + 0.5) / 2.0;
        }
        else{
            albedo = mapIntToRGB(int(dist.y));
        }

        vec3 diffuse = albedo * vec3(clamp(dot(norm, lightRay), 0.0, 1.0 - u_MinAlbedo));
        vec3 reflectDir = normalize(rayDirection - 2.0 * dot(rayDirection, norm) * norm);

        // Specular
        float specular = pow(max(dot(reflectDir, lightRay), 0.0), u_SpecularPower);

        vec3 surfacePointElevated = surfacePoint + norm * u_SurfaceDistance * 2.0;
        float distToLight = marchRay(surfacePointElevated, lightRay).x;
        if(distToLight < length(u_SpotLightPos - surfacePoint)){
            diffuse *= u_ShadowStrength;
        } 
        else{
            float shadow = softShadow(surfacePointElevated, lightRay, u_SoftShadow);
            diffuse *= clamp(shadow, u_ShadowStrength, 1.0);
            diffuse += vec3(specular) * shadow;
        }

        iterationColor +=  diffuse  + u_MinAlbedo * albedo;
        
        // Tail recursive step
        sourcePosition = surfacePointElevated;
        rayDirection = reflectDir + vec3((rand(vec2(surfacePoint.x)) * 2.0 - 1.0) / u_Roughness, (rand(vec2(surfacePoint.y)) * 2.0 - 1.0) / u_Roughness, (rand(vec2(surfacePoint.z)) * 2.0 - 1.0) / u_Roughness);
        
        color += iterationColor * pow(u_Reflection, i);   
    }

    return color;
}
```
