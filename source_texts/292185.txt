Repository: https://github.com/farisyahz/Project2-Stream-Compaction
Implemented features:
Reference CPU implementation for exclusive prefix sums
CPU stream compaction with and without scan
Naive CUDA scan using ping-pong device buffers
Work-efficient CUDA scan using Blelloch up-sweep/down-sweep passes
GPU stream compaction with map, scan, and scatter stages
Thrust-based exclusive scan
Reduced active work at deeper levels of the work-efficient scan
Signed 32-bit radix sort built from repeated scan-based partitions
Shared-memory Hillis–Steele scan
Shared-memory work-efficient Blelloch scan
Shared-memory bank-conflict reduction through padded addressing
Additional correctness tests for edge cases, non-power-of-two sizes, and large inputs
Benchmark tooling, performance plots, and analysis documented in the README
Nsight Systems profiling workflow and performance discussion
CUDA/MSVC CMake compatibility fix for /Zc:preprocessor
