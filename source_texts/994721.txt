The Godunov |∇φ| operator produced oscillations near inflow boundaries due to hard-threshold upwind selection and no regularization on near-zero gradients.
Changes
Epsilon regularization: eps = 1e-8 * min(dx[0], dx[1], dx[2]) — grid-aware, scales consistently across resolutions
max/min upwind selection: replaced ternary operators with explicit amrex::max/amrex::min clamps for GPU-friendly vectorization
Regularized sqrt: sqrt(gx + gy + gz + eps²) prevents degenerate near-zero gradient magnitudes at constant-extrapolation inflow boundaries
```
// Before
Real gx = (px_pos > 0.0 ? px_pos*px_pos : 0.0)
        + (px_neg < 0.0 ? px_neg*px_neg : 0.0);
return std::sqrt(gx + gy + gz);

// After
Real eps = Real(1.0e-8) * amrex::min(dx[0], amrex::min(dx[1], dx[2]));
Real px_p = amrex::max(px_pos, Real(0.0));
Real px_n = amrex::min(px_neg, Real(0.0));
Real gx = px_p*px_p + px_n*px_n;
return std::sqrt(gx + gy + gz + eps*eps);
```
The interface and additive Godunov upwinding structure are preserved.

Problem
The godunov_norm_grad_phi function (lines 19-45 in src/main.cpp) produces oscillations on inflow boundaries. This happens because:
The standard Godunov upwinding scheme amplifies numerical errors through squared gradient terms
No limiting or smoothing mechanisms are present
On inflow boundaries where constant extrapolation is used (line 171 in fill_boundary_extrap), sharp transitions create gradient discontinuities
Missing epsilon regularization for near-zero gradients
Solution Requirements
Make godunov_norm_grad_phi more numerically robust by:
Add epsilon regularization: Include a small epsilon term (proportional to grid spacing) to smooth the gradient magnitude calculation and prevent division-by-zero-like conditions
Implement gradient limiting: Add min/max clamping of the squared gradient components to prevent unphysical amplification, especially near boundaries
Smooth the upwind selection: Instead of hard thresholds (> 0.0, < 0.0), use a smoother transition for the Godunov upwind choices to reduce oscillations
Grid-aware smoothing: Scale the regularization parameter with the grid spacing to maintain consistency across different resolutions
Implementation Details
Modify the godunov_norm_grad_phi function to:
Compute epsilon as a small multiple of the minimum grid spacing (e.g., eps = 1e-8 * min(dx[0], dx[1], dx[2]))
Apply limiting to prevent squared gradients from becoming excessively large
Add epsilon to the final sqrt calculation: sqrt(gx + gy + gz + eps*eps)
Consider using max(0, ...) constructs more carefully or add small smoothing near zero
The modified function should maintain the same interface and overall Godunov upwinding philosophy while being more stable on inflow boundaries.
