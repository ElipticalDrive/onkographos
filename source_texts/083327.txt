The 3D viewer no longer uses JOGL. It calls the OpenGL driver directly through the Java Foreign Function & Memory API, so Weasis ships no OpenGL native library of its own.
Weasis owns a single offscreen OpenGL context (EGL on Linux, WGL on Windows, CGL on macOS), created and used on one dedicated thread; frames are read back into the Swing panel.
Uploads and deletions run on that thread with a current context, which removes the class of crashes seen when a 3D view was closed and reopened (3D viewer crashes on second open (Mesa/radeonsi): Preset textures reused across destroyed GLJPanel contexts #918).
A volume loading in the background no longer delays the display of other views.
Shaders are compiled in parallel when the driver supports it.
Volume rendering, cinematic lighting and path tracing run on the new layer.
