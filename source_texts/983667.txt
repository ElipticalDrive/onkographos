Goal
Generating seams that connect the chunks ( with different LODs )
Implementation
I initially tried to just push the existing octrees closer together, but I noticed that this approach would cause a lot of complications when trying to code a proper chunking system and also when trying to implement a LOD system
So instead :
For each chunk we collect all the seam nodes for that chunk, then collect the seam nodes from each of the neighbour chunks. At this point we have a collection of leaf nodes which make up the seam.
Then we construct a new octree upwards with the seam nodes we have.
Finally we run the Dual Contouring algorithm on the octree to construct the geometry for the seams
Visit this article for more details.
