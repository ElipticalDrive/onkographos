# Windows-Compatible CUDA Libraries CuMesh & O-Voxel

These are modified versions of **CuMesh** and **o-voxel** libraries with Windows/MSVC compatibility fixes. The original libraries only compile on Linux with GCC.

## Requirements

- Windows 10/11
- Python 3.11
- CUDA Toolkit 12.x
- PyTorch 2.6.0+ with CUDA support
- Visual Studio 2019/2022 with C++ build tools
- ninja (`pip install ninja`)
