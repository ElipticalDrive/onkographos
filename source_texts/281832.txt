# N-Point Stencil Figure Generator

A small utility to generate a publication-ready 3D visualization of a star-shaped **N-point stencil** on a voxel grid.

- Star stencil in 3D with radius `r` ⇒ **N = 1 + 6·r** (includes the center).
- Solid gray base grid (`nx × ny × nz`).
- Stencil voxels (center, ±X, ±Y at front slice `z=0`, and +Z) in yellow/orange.
- Red **ghost** column popping out toward the viewer (data `Z−`).
- Red **wireframe shell** (“continuation”) in front of the grid (only the outer surface).
- **Green highlight** is **always on** for the first `r` slices (`z=0..r−1`) for **non-stencil** voxels — useful to depict **read-only** vs. **update** regions.
- Exports **PNG** and **PDF** tightly cropped with minimal white margins.

Outputs are saved under the project’s `output/` directory (created automatically).

## Requirements

- Python 3.8+
- Packages: `numpy`, `matplotlib`

```bash
python3 -m pip install numpy matplotlib
````

---

## Installation

Place the script at the project root as:

```
generate-stencil-figure.py
```

---

## Quick Start

Default rendering (r=5 ⇒ N=31). Saves PNG + PDF into `output/border/31-point-stencil/`:

```bash
python3 generate-stencil-figure.py
```

Disable the red wireframe shell and save into the “borderless” tree:

```bash
python3 generate-stencil-figure.py --no-red
```

---

## Command-Line Usage

```bash
python3 generate-stencil-figure.py [options]
```

## Options

| Option                  | Type  |   Default | Description                                                                              |
| ----------------------- | ----- | --------: | ---------------------------------------------------------------------------------------- |
| `--nx`                  | int   |      `20` | Grid size along **x** (voxels).                                                          |
| `--ny`                  | int   |      `20` | Grid size along **y** (voxels).                                                          |
| `--nz`                  | int   |      `20` | Grid size along **z** (voxels).                                                          |
| `--radius`              | int   |       `5` | Stencil radius `r` (**N = 1 + 6·r**). Also sets green highlight depth `k=r` (always on). |
| `--elev`                | float |      `18` | 3D view elevation (degrees).                                                             |
| `--azim`                | float |     `-60` | 3D view azimuth (degrees).                                                               |
| `--grid_linewidth`      | float |     `0.6` | Line width for solid grid voxel edges.                                                   |
| `--outline_linewidth`   | float |     `1.2` | Line width for bold outline on front-face stencil squares.                               |
| `--highlight_color`     | hex   | `#5bb81c` | Color for the first-slices non-stencil highlight (green band).                           |
| `--wireframe_linewidth` | float |     `0.5` | Line width for the red wireframe shell (set to `0` via `--no-red`).                      |
| `--axis_label_size`     | int   |      `18` | Font size for axis labels (`x`, `z`, `y`).                                               |
| `--axis_label_pad`      | float |     `-12` | Label offset; negative draws labels closer to axes.                                      |
| `--no-red`              | flag  |       off | Disables the red wireframe shell and switches output path to `output/borderless/...`.    |

**Always-on behavior**

* The green highlight of the first `r` slices (`z=0..r-1`) for non-stencil voxels is always active.
* Both PNG and PDF are exported, tightly cropped.

## Output Layout & Naming

For a given `radius`, the script computes **N = 1 + 6·radius** and names files as:

```
{N}-point-stencil.png
{N}-point-stencil.pdf
```

Outputs are stored relative to the script directory:

* With red shell (default):

  ```
  output/border/{N}-point-stencil/{N}-point-stencil.png
  output/border/{N}-point-stencil/{N}-point-stencil.pdf
  ```

* With `--no-red`:

  ```
  output/borderless/{N}-point-stencil/{N}-point-stencil.png
  output/borderless/{N}-point-stencil/{N}-point-stencil.pdf
  ```

Example tree (r=5 ⇒ N=31):

```
output/
├─ border/
│  └─ 31-point-stencil/
│     ├─ 31-point-stencil.png
│     └─ 31-point-stencil.pdf
└─ borderless/
   └─ 31-point-stencil/
      ├─ 31-point-stencil.png
      └─ 31-point-stencil.pdf
```

## Examples

**1) Default (r=5, N=31):**

```bash
python3 generate-stencil-figure.py
```

**2) Larger stencil (r=7 ⇒ N=43) with default red shell:**

```bash
python3 generate-stencil-figure.py --radius 7
```

**3) No red shell (borderless output), r=6 ⇒ N=37:**

```bash
python3 generate-stencil-figure.py --radius 6 --no-red
```

**4) Non-cubic grid and custom camera:**

```bash
python3 generate-stencil-figure.py --nx 40 --ny 18 --nz 30 --radius 6 --elev 20 --azim -50
```

**5) Thinner shell and custom highlight color:**

```bash
python3 generate-stencil-figure.py --wireframe_linewidth 0.35 --highlight_color "#4CAF50"
```

**6) Adjust axis label size and distance:**

```bash
python3 generate-stencil-figure.py --axis_label_size 20 --axis_label_pad -14
```

---

## Axis Conventions

* Voxel data are indexed as `(x, y, z)`.
* For plotting, axes are labeled `x`, `z`, `y` (labels only; geometry orientation is unchanged).
* The red “ghost” column extends along data **Z−** (toward the viewer).
* The red wireframe shell is a transparent **outer surface** drawn in front of the grid.

---

## Tips & Constraints

* Keep the stencil within the grid:

  ```text
  radius <= min(nx//2, ny//2, nz-1)
  ```
* Residual margins are minimized with tight layout and zero padding; small variations can occur with perspective. Adjust `--elev`, `--azim`, or `--axis_label_pad` if needed.
* For reproducible raster output, you can pin a DPI:

  ```bash
  MPLBACKEND=Agg python3 generate-stencil-figure.py
  ```
