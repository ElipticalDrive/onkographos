Adds OpenGL 4.3+ compute shader-based GPU renderers for high-quality phyllotaxis torus visualization on Intel HD Graphics 630 and other integrated GPUs without CUDA dependency. Includes both a 3D SDF primitive renderer and an optimized UV-texture-based renderer with Jump Flood Algorithm for O(texels log texels) scaling.
Changes
SDF-based GPU Renderer (src/sdf_gpu_renderer.py)
SDFGPURenderer class for proper SDF primitive rendering
Uses true geometric primitives: torus, spheres, capsules
Boolean SDF operations: union, intersection, difference, smooth union
Renders ink lines as capsules on torus interior surface
Performance: N+E primitives (~1600 at N=1597)
Robust buffer management with proper cleanup
UV-texture-based GPU Renderer with Jump Flood Algorithm (src/uv_gpu_renderer.py) - OPTIMIZED
UVGPURenderer class with three-stage Jump Flood Algorithm
Stage 1 (Seed): Rasterizes primitives into UV seed buffer - O(primitives × primitive_pixels)
Stage 2 (JFA): Iterative distance propagation with ping-pong buffers - O(texels × log texels)
Stage 3 (Finalize): Converts seeds to metric SDF with torus surface metric - O(texels)
Pass B (Render): Ray marches inverted torus and samples ink texture
Performance: O(texels log texels) instead of O(texels × primitives)
Scales efficiently to N=10,000+ nodes
Jump Flood Algorithm Shaders
shaders/ink_seed.comp - Seed/splat primitives with Bresenham line rasterization
shaders/ink_jfa.comp - Jump Flood propagation with decreasing jump steps
shaders/ink_finalize.comp - Convert seeds to metric SDF using torus surface metric
shaders/raymarch_uv.comp - Ray march inverted torus and sample ink texture
Inverted Torus Rendering
"Outside is solid, only tube cavity is empty" architecture
Negated torus SDF for tunnel effect
Natural front-to-back occlusion
Eliminates donut-hole artifacts
Consistent Metric Scaling
Edge projection and distance use same metric (at query_v)
Proper torus surface metric: ds² = (R + r·cos(v))²·du² + r²·dv²
Uniform line thickness across torus surface
No "nearest edge" artifacts
Shared Geometry Computation (torus_net_gpu.py)
compute_phyllotaxis_geometry(): Computes node positions, colors, and UV coordinates
compute_edges_and_samples(): Builds edge list and sampled line points
Both CPU and GPU renderers share identical phyllotaxis placement and coloring logic
Eliminates code duplication and ensures consistency
Integration (torus_net_gpu.py)
--uv flag enables optimized UV-texture renderer with JFA (recommended for large datasets)
--sdf flag enables SDF-based renderer (good for medium datasets)
render_uv_gpu() converts geometry to UV coordinates with proper surface metric
render_sdf_gpu() builds edge list as endpoint pairs
Improved error handling with graceful cleanup and CPU fallback
Fixed white image issue by clamping node radii and hit_eps
GPU detection and info printing at startup
Code Quality Improvements
Removed unused code (common.glsl, unused functions, unused variables/imports)
Fixed resource cleanup (added missing buffers, made cleanup robust)
Fixed world_scale duplication
Added texture wrapping for seamless toroidal topology
All buffers/textures set to None after release for idempotent cleanup
Dependencies
Added moderngl for OpenGL 4.3+ bindings

Technical Details
Jump Flood Algorithm:
Stage 1: Seed primitives into 2D UV texture (R32I format)
Stage 2: Propagate nearest seeds with jump steps: texture_size/2, texture_size/4, ..., 1
Stage 3: Compute metric distance and subtract radius for final SDF
Complexity: O(texels × log(max_texture_dimension))
Inverted Torus:
Torus SDF negated: return -(d_ring - r)
Only tube cavity is empty space (negative SDF)
Everything else (donut hole, outside) is solid (positive SDF)
Ray marching naturally finds tube interior
Metric Consistency:
All distance calculations use metric at query point
metric_uu = (R + r * cos(query_v))²
metric_vv = r²
Ensures uniform line appearance across torus
The implementation fully supports Intel HD Graphics 630 and other OpenGL 4.3+ GPUs without CUDA dependency.

7. Shader Implementation Details
```
// Pseudo-code for compute shader
layout(local_size_x = 8, local_size_y = 8) in;

void main() {
    // Get pixel coordinates
    ivec2 pixel = ivec2(gl_GlobalInvocationID.xy);
    
    // Compute ray from camera through this pixel
    vec3 ray_origin = camera_pos;
    vec3 ray_dir = compute_ray_direction(pixel);
    
    // Ray march with smooth_min blending
    float t = 0.0;
    for (int step = 0; step < MAX_STEPS; step++) {
        vec3 pos = ray_origin + t * ray_dir;
        
        // Compute smooth_min SDF across all spheres
        float sdf = spheres_smooth_sdf(pos);
        
        if (sdf < hit_eps) {
            // Hit! Compute color with shading
            vec3 normal = estimate_normal(pos);
            vec3 color = phong_shade(normal, ...);
            imageStore(output_image, pixel, vec4(color, 1.0));
            return;
        }
        
        if (t > t_max) break;
        t += sdf; // Sphere tracing step
    }
    
    // Miss - output background
    imageStore(output_image, pixel, vec4(0.0));
}

float spheres_smooth_sdf(vec3 pos) {
    float result = spheres[0].dist(pos);
    for (int i = 1; i < numSpheres; i++) {
        result = smooth_min(result, spheres[i].dist(pos), smooth_k);
    }
    return result;
}

float smooth_min(float d1, float d2, float k) {
    float h = clamp(k - abs(d1 - d2), 0.0, k) / k;
    return min(d1, d2) - h * h * k / 6.0;
}
```

GOAL
Replace the current “lines = sampled spheres” approach with true SDF-based “ink lines on the inside surface of the torus” using boolean SDF operations, and make junctions at the N points smoothly rounded (no corners / no shading creases).
This should follow the same smooth union concept as Sebastian Lague’s ray marching project (smoothMin / smooth union of SDFs):
Reference repo: https://github.com/SebLague/Ray-Marching
The smoothMin function concept is the same as his (Inigo Quilez polynomial smooth min). You already have this in shaders/raymarch.comp.
CURRENT STATE (what to remove/avoid)
torus_net_gpu.py currently builds line_pts by sampling UV along each edge (line_samples_per_edge + 1), converts to 3D, then concatenates [line_pts, P] into a giant sphere list and uploads all to GPU. This creates 200k spheres at N1600 and is both slow and visually “blobby”.
shaders/raymarch.comp currently ray-marches ONLY spheres. Smooth blending is smooth_min across ALL spheres (spheres_smooth_sdf), which also causes junction artifacts and massive cost.
DESIRED NEW RENDERING MODEL (SDF scene primitives)
We want:
A torus surface (rendered as a thin shell so ray marching can hit it reliably).
“Ink lines” that lie on the inside surface of the torus:
Define an inside-only torus shell band (near the torus surface but only inside-facing).
Intersect that inside shell band with capsule tubes along each graph edge (step connections).
Node dots as spheres centered on the torus surface (these remain true 3D volumes).
Smooth junctions where edges meet nodes:
Use smooth union ONLY between the “ink network” and the “node spheres” (not a global smooth min across every primitive).
Boolean SDF ops reminder (d<0 means inside):
Union: min(a,b)
Intersection: max(a,b)
Difference: max(a, -b)
Complement: -a
IMPLEMENTATION PLAN
A) Build an EDGE LIST instead of sampling line_pts (Python)
Files likely involved:
torus_net_gpu.py
src/gpu_renderer.py

Stop building line_pts (stop UV sampling).

For i in [0..N-1], j=(i+s)%N (or your existing half-edge logic if you avoid duplicates)
A = P[i], B = P[j]
Keep node centers = P (already on torus surface).
Upload:
node centers + node colors + node radii (like today)
edge endpoints A,B (new)
edge color (either constant, or per-step, but start with constant)
edge radius (use existing scene.line_radius)
B) Extend GPU buffers + upload API (Python)

binding=4: EdgeA vec3[]

File: shaders/raymarch.comp

Add torus SDF:
float sdTorus(vec3 p, float R, float r) {
vec2 q = vec2(length(p.xz) - R, p.y);
return length(q) - r;
}

float sdShell(float dSurface, float thickness) { return abs(dSurface) - thickness; }

float sdCapsule(vec3 p, vec3 a, vec3 b, float r) {
vec3 pa = p - a;
vec3 ba = b - a;
float h = clamp(dot(pa, ba) / dot(ba, ba), 0.0, 1.0);
return length(pa - ba*h) - r;
}

shell band near surface: abs(dT) - torus_shell_thickness

float dInsideShell = max( abs(dT) - torus_shell_thickness, dT );

float dEdgeTube = sdCapsule(p, edgeA[i], edgeB[i], line_radius);
float dInkEdge = max(dInsideShell, dEdgeTube); // intersection
dInk = min(dInk, dInkEdge); // union across edges

float dNodes = min_over_nodes( sphere_sdf(p, nodeCenter[i], nodeRadius[i]) );
