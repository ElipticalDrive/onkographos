First visual output for wk-voxel. Adds a new demo binary crate wk-voxel-app (macroquad-based) that stamps a continental profile with the worldgen from PR #43 and renders each cell as a filled rectangle while tick() runs the physics from PRs #40/#41/#42.
Crate
crates/wk-voxel-app/:
Cargo.toml — depends on wk-voxel + wk-material + macroquad. Never on wk-world, wk-sim, wk-agents, wk-app, wk-io, wk-field.
Explicit guardrail comment in the Cargo.toml header and in every source file.
Registered in the workspace top-level Cargo.toml with the same "must not depend on column crates" note that wk-voxel carries.
Rendering
Each Cell drawn as a filled rectangle at PX_PER_CELL = 3.
Palette adapter (src/palette.rs) maps MaterialId → RGB via wk_material::MaterialRegistry::colour_rgb. Water is Air + sat = FULL in the voxel model; the adapter linearly blends Air's sky-blue toward Water's palette entry as sat rises so partially-wet Air cells (rain, splash) shade sensibly. Porous solid cells darken with sat for infiltration feedback.
Sky-blue empty Air cells skipped in the draw loop (background already paints them), which cuts draw calls hard on the large open sky region.
Hotkeys
Space — pause / resume ticks
R — reroll with a new seed
Arrow keys — pan the camera
Esc — quit

```
Adds a new demo binary crate `wk-voxel-app`. Depends on wk-voxel +
wk-material only (never on wk-world / wk-sim / wk-agents / wk-app /
wk-io / wk-field), so the isolation contract in
docs/VOXEL_MIGRATION.md still holds.

Rendering:
- Each Cell drawn as a filled rectangle at PX_PER_CELL = 3 px.
- Palette adapter (`src/palette.rs`) maps cell -> RGB via
  wk_material::MaterialRegistry::colour_rgb. Water is Air + sat=FULL
  in the voxel model; the adapter linearly blends Air's sky-blue
  toward Water's palette entry as sat rises so partially-wet Air
  cells (rain, splash) shade sensibly. Porous solids darken with
  sat to give visual feedback for infiltration.
- Sky-blue Air (sat=0) cells skipped in the draw loop — the
  clear_background already paints them, saving draw calls on the
  large open-sky region.
- Camera pans on arrow keys, R re-rolls with a new seed, Space
  pauses ticks, Esc quits.

Bootstrap:
- `Scene::new(params)` creates a World and stamps it with the
  worldgen from the previous PR.
- `tick()` runs every frame while unpaused.

Workspace:
- New crate `crates/wk-voxel-app/` registered in top-level
  Cargo.toml with an isolation comment matching the wk-voxel entry.
- Cargo.toml carries the same "MUST NOT depend on column crates"
  guardrail header as wk-voxel.

Tests:
- palette::tests (4): dry air = sky, saturated air = water, partial
  air lies in between, wet sand darker than dry sand.
- scene::tests (1): Scene::new is deterministic.
- Full workspace `cargo test` and `cargo build` pass with no new
  regressions.
```
