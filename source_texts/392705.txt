## Features

* Basic ray casting (spheres, planes, triangles)
* Lighting: Ambient, diffuse, and specular components
* Recursive reflections and refractions
* Shadows and soft shadows
* Camera and viewport configuration
* Material system (color, reflectivity, transparency)
* Optional: OBJ mesh loading
* Unit tests for core components
* Performance optimizations (e.g., bounding volume hierarchy)

## Configuration

You can configure the scene using a `.cfg` file:

```cfg
scene:
{
	camera:
	{
		origin = { x = 0; y = 50; z = -100; };
		resolution = { width = 1920; height = 1080; };
		rotation = { x = 0; y = 0; z = 0; };
		fov = 90.0;
	};

	primitives:
	{
		disks = (
			{ origin = { x = -30; y = 50; z = -40; }; r = 25;
			normal = { x = 0; y = 0; z = 1; };
			material = {
				rgba = { r = 1; g = 0; b = 0; a = 1; };
				roughness = 1;
				metallic = 0;
				specular = 0;
				ambient = 0;
				shininess = 0;
			}; }
		);

		planes = (
			{ origin = { x = 0; y = 0; z = 0; };
			normal = { x = 0; y = 1; z = 0; };
			material = {
				rgba = { r = 0; g = 0; b = 1; a = 1; };
				roughness = 1;
				metallic = 0;
				specular = 0;
				ambient = 0;
				shininess = 0;
			}; }
		);
	};

	lights:
	{
		ambiant = { rgb = { r = 1, g = 0.95; b = 0.9; }; power = 0.3; };

		point = (
			{ origin = { x = 0; y = 20; z = -100; };
			rgb = { r = 1, g = 0.95; b = 0.9; };
			constant = 1;
			linear = 0.0001;
			quadratic = 0.0001;}
		);
	};
};
```

## Concepts Implemented

This ray tracer implements key components of the Whitted-style rendering model:

* Rays & Intersections: Traces rays from the camera and finds the closest object hit.
* Shading: Computes lighting per pixel using Phong or Blinn-Phong models.
* Reflection/Refraction: Handles multiple bounces recursively.
* Anti-aliasing: Optional supersampling for smoother images.
