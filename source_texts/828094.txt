Introduces a new standalone shader demo, mix_shader.html, that combines bullet.html and perfect.html rendering approaches into a layered mixer. The new view lets users tune each effect’s opacity independently and rapidly recolor voxel content via an MS Paint-style palette.
Rendering composition
Adds a dual-layer shader pipeline that computes:
Bullet-style PBR lighting layer
Perfect-style Phong lighting layer
Composites both layers per voxel using independent alpha controls (bulletOpacity, perfectOpacity).
Layer control UI
Adds dedicated sliders for Bullet and Perfect layer opacities.
Keeps existing lighting/material controls (roughness, AO, transmission, specular, light position, rotation, layer view) in one panel for fast tuning.
MS Paint color workflow
Adds a full quick-pick palette modeled after classic MS Paint colors.
Adds a Recolor Voxels action to apply the selected palette color across existing voxels in one step.
Keeps per-layer draw/erase editing so recolor and sculpt flows can be combined.
```
<input type="range" min="0" max="1" step="0.01" value={bulletOpacity} onChange={e => setBulletOpacity(+e.target.value)} />
<input type="range" min="0" max="1" step="0.01" value={perfectOpacity} onChange={e => setPerfectOpacity(+e.target.value)} />

const mixed = compositeLayers([
  { ...bullet, a: bulletOpacity },
  { ...perfect, a: perfectOpacity }
]);
```
