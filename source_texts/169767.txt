Извлечение объема
Инструмент Volume Extract (Извлечение объема) в группе ленты Analysis (Анализ) на вкладке Prepare (Подготовка) позволяет создавать твердые тела на основании объемного пространства, отгороженного одним или несколькими телами (включая сети). В дереве структуры появляется твердое тело под названием Volume (Объем), а тела, с помощью которых создается объемное пространство, становятся прозрачными на время его создания.
Если поверхность пересекается со всеми ребрами, выбранными для изоляции зоны, она будет покрывать созданное объемное пространство. Можно создать более чистые покрытия, добавив поверхности к каждому из ребер, используемых для определения отгороженной зоны.
Если при использовании инструмента Volume Extract (Извлечение объема) ребро будет удалено, это ребро будет мигать красным цветом, а также отобразится предупреждающее сообщение. Это может произойти при выборе покрывающего ребра, которое будет удалено при объединении с остальной частью модели. Цветовое выделение указывает на наличие проблемы и необходимость выбора другого ребра.
Создание объемного тела
Щелкните инструмент Volume Extract (Извлечение объема) в группе Analysis (Анализ) на вкладке Prepare (Подготовка).
Щелкните направляющую инструмента Select Edges (Выбор ребер), чтобы выбрать реберные петли, отгораживающие объемную область.
С помощью двойного щелчка можно выбрать несколько смежных ребер. Также можно щелкнуть выбранное ребро, чтобы отменить его выбор. Выберите только те реберные петли, с помощью которых нужно изолировать объемную область. При наведении курсора на грань, содержащую внутренние реберные петли, они будут подсвечены. Щелкните грань для выбора подсвеченных реберных петель.
При необходимости щелкните направляющую инструмента Select Cap Faces (Выбор покрывающих граней), чтобы выбрать грань для покрытия.
(Дополнительно) Установите флажок Preview inside faces (Предварительный просмотр внутренних граней) для активации ползунка предварительного просмотра. Модель немедленно обновится для отображения предварительного просмотра внутренних граней, обозначенных красным цветом на 100%. Перетащите ползунок влево и вправо для предварительного просмотра граней и просмотра последовательности их фиксации.
Во время отображения предварительного просмотра граней все инструменты Select (Выбор), включая инструменты контекстного меню, а также параметры инструменты Volume Extract (Извлечение объема) отключены до тех пор, пока флажок предварительного просмотра не будет убран.
Щелкните параметр инструмента Select Seed Face (Выбор опорой грани) и выберите грань внутри объемной области. Направляющая инструмента Select Seed Face (Выбор опорой грани) предназначена для выбора грани, определяющей внутреннее пространство изолированного объемной области. Этот направляющая нужна только в том случае, если инструмент Volume Extract (Извлечение объема) не сможет правильно определить внутреннее пространство объемной области.
Щелкните направляющую инструмента Complete (Завершить).
SpaceClaim создаст поверхностную деталь на основании заданного объемного пространства.
Обновление объемного тела
Щелкните объемную деталь (называющуюся Volume (Объем) по умолчанию) правой кнопкой мыши в дереве структуры. Выберите одну из следующих команд:
Regenerate Volume Body as Created (Воспроизвести объемное тело как при создании) обновляет объемное тело на основании объектов, которые были видимыми во время его создания (независимо от их текущих настроек видимости). Этот вариант предназначен для простого воспроизведения.
Regenerate Volume Body in Context (Воспроизвести объемное тело в контексте) обновляет объемное тело на основании объектов, видимых в области конструкции в данный момент. Этот вариант предназначен для удаления тел из расчета объемного пространства.
Направляющие инструментов
Приведенные ниже направляющие инструментов помогают при выполнении процесса.
Направляющая инструмента Select Edges (Выбор ребер) позволяет выбрать реберные петли, отгораживающие зону. Ребра, исходящие наружу по отношению к граням и начинающиеся от выбранных опор, используются для остановки воспроизведения выбора граней.
Направляющая инструмента Select Faces (Выбор граней) включается по умолчанию при выборе инструмента Volume Extract (Извлечение объема) и позволяет выбрать грани, ребра которых изолируют отгороженную зону. Она представляет собой быстрый способ выбора всех ребер, обнаруженных на грани. Удерживая нажатой клавишу Ctrl, можно выбрать несколько опорных граней, а затем щелкнуть другую направляющую инструмента. После создания объемного пространства направляющая инструмента Select Faces (Выбор граней) сбрасывается по умолчанию.
Направляющая инструмента Select Cap Faces (Выбор покрывающих граней) позволяет выбрать дополнительные покрывающие грани. Это важно в тех случаях, когда внутреннюю реберную петлю трудно заполнить или когда нужно создать нестандартную заполняющую геометрическую форму.
Направляющая инструмента Select Seed Face (Выбор опорной грани) позволяет выбрать грань, расположенную внутри объемного пространства, которое нужно изолировать. Если эта направляющая не выбрана, SpaceClaim выбирает произвольную опорную грань и проверяет, создаются ли при этом ограниченные объемные пространства. При отсутствии таких пространств приложение автоматически выберет другую грань и перезапустит алгоритм. Чтобы не тратить время на повторение этой процедуры, выберите грань с помощью этой направляющей инструмента.
Направляющая инструмента Complete (Завершить) позволяет создать объемное твердое тело на основании выбранных ребер и опорной грани.
