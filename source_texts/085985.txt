Summary
Reworked per human direction: voxel text is now GUI text, not world-space titles. Each letter is a small isometric voxel block drawn on the GUI trixel canvas with its own colour per face (X / Y / Z), and letters sit side by side along screen-horizontal lines like ordinary text — only each letter is iso, the word never follows an iso path. The world-space builder (IRPrefab::VoxelText, IRText.createVoxel / removeVoxel, the yawed fixture rows and the IRCreationDefault titles) is removed.
Layout (engine/render/include/irreden/render/voxel_text.hpp): layoutVoxelText(text, VoxelTextStyle, layout, scratch) paints each glyph's unit voxels farthest-first into a per-glyph face map on the triangle lattice (top Z = diamond, X = left side, Y = right side, the roles a world voxel shows at yaw 0), lattice-scales it by voxelSize_, and covers it with same-face rectangles of at most one glyph cell (6×11). Three facings: CAMERA (upright, unsheared), X_FACE, Y_FACE (printed on that face, sheared); depth_ extrudes away from the camera. VoxelFaceColors + shadedVoxelFaceColors(top).
Rendering — no new shader: each rectangle is one GlyphDrawCommand over a solid cell appended to the font buffer (kSolidCellStart), so voxel text rides the existing GUI text compute dispatch on both backends. Large voxel text can exceed the 8192-command buffer (a size-8 "SCORE 120" lays out 10,252 runs). dispatchGlyphCommands therefore uploads and dispatches the command list in kMaxGlyphCommands chunks instead of truncating it, and TEXT_TO_TRIXEL and dispatchGuiText both use it. expandVoxelTextToCommands colours by face and aligns per line; flat text now shares the same alignedBlockOffset.
ECS: C_TextStyle gains voxel_ (VoxelTextStyle) and faceColors_; voxel_.voxelSize_ > 0 switches TEXT_TO_TRIXEL to voxel letters, so any creation that already shows free text gets voxel text with no pipeline change. C_TextStyle::voxel(colors, size, facing, depth) factory.
Lua: C_TextStyle.voxelSize / voxelDepth / voxelFacing / faceX / faceY / faceZ, style:shadeFaces(color), and the IRText.VoxelFacing enum table; out-of-range values raise.
Save format: C_TextStyle goes to version 3 (voxel style appended); version 2 rows migrate as flat text.
Kept from the first revision: the 5×7 voxel glyph set (voxel_font.hpp) and the C_FogRevealed binding fix-forward (IRCreationDefault crashed at startup on master without it).
Fixture: IRShapeDebug --voxel-text-sample — every facing, explicit RGB faces and shaded faces, sizes 1 and 2, a centred two-line block. New render-verify row voxel_text with its macOS reference.
Docs: docs/design/voxel-text.md rewritten as the GUI contract; one-line pointers in the render prefabs and script CLAUDE.mds.

Top: CAMERA size 2 with shaded gold faces. Middle: X_FACE / Y_FACE size 2 depth 2 with X red, Y green, Z blue. Then CAMERA size 1 shaded, and a centred CAMERA depth-2 block.

NEEDS-DESIGN
The review's only needs-fix item is acceptance criterion 6 of #4563. As written, the criterion cannot pass, so this PR has nothing to amend for it. A replacement criterion has to come from a ## Plan corrections comment on #4563, because review-acceptance grades only the issue's plan.
What contradicts the plan. Criterion 6 asks for fleet-run --timeout 15 IRCreationDefault to report RESULT=CLEAN. That cannot happen with this command:
IRCreationDefault is an interactive demo, and with no arguments it runs IREngine::gameLoop() until the window closes.
ir-run prints RESULT=CLEAN only when the program exits 0 by itself. A process that is still alive at the deadline always gets RESULT=ALIVE-TIMEOUT (engine/tools/bin/ir-run, the watchdog tail).
The engine has no exit-after-N-frames or exit-after-N-seconds argument or environment variable. The only self-terminating paths are the capture verbs (--auto-screenshot, --auto-record, --auto-profile).
So on master, on this head, and for any no-argument interactive demo, the command ends in ALIVE-TIMEOUT.
The literal command, measured on this head (00ebea55, macOS, fresh fleet-build --target IRCreationDefault):
```
$ fleet-run --timeout 15 IRCreationDefault

ir-run: RESULT=ALIVE-TIMEOUT exe=IRCreationDefault — ran for 15s without crashing, killed by watchdog
```
