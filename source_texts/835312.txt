Summary of Changes
Fix region boundary clipping (Fixes Random teleportation glitch #7):
Sets MAX_REGION_RADIUS = 22_000 blocks (~22 km) in EarthRegions.
Players and cameras flying beyond 22 km now cleanly enter the natural buffer zone between places (EarthRegions.at() returns null instead of snapping abruptly to a neighboring country grid cell at 25 km).
Bounded radial check applied across mod/, mod-26.2/, and mod-26.3/.
Parallel Voxelization via Worker Threads:
Added VoxelWorker and VoxelPool (service/src/voxel-pool.mjs and service/src/voxel-worker.mjs) using node:worker_threads.
Moves CPU-intensive mesh voxelization (voxelizeArea) off the main HTTP event loop, scaling across CPU cores and zero-copy transferring vox.buffer.
Supports configurable worker count (cfg.voxelWorkers), automatic thread scaling based on available CPUs, task queuing, auto-respawn, and graceful fallback to synchronous execution if worker threads are unavailable.
Added unit tests in service/test/voxel-pool.test.mjs. All 41 service tests pass.
