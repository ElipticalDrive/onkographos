This PR separates orbital-grid computation from desktop rendering, adds native compute modules for AMD, Intel and macOS, and provides a CPU fallback.
Share CPU scientific analysis across platforms, with cancellable grid computation and portable threading.
Extend CUDA builds to sm_60, sm_61, sm_70, sm_75, sm_80, sm_86, sm_89, sm_90, sm_100 and sm_120, with compute_120 PTX. Preserve direct OpenGL interoperability and use a bounded host transfer when it is unavailable.
Add AMD HIP/ROCm, Intel oneAPI DPC++/SYCL with Level Zero, and macOS Metal modules. Automatic selection tries native backends before CPU; WebGPU through pinned wgpu-native is opt-in.
Add portable file opening, shell-free formchk invocation, build presets, and English/Chinese build instructions. Windows accepts Unicode paths and starts without an extra console.
Keep WebGPU on Vulkan/DX12/Metal to preserve the viewer's OpenGL context. Avoid nonfinite GPU results from zero coefficients and underflowed radial factors.
OpenCL remains reserved for future work. The separate NBO/science changes in PR #5 are not included.
