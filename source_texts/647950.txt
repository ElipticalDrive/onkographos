# SDF（有符号距离场）通俗入门与原理

> 一句话先懂：**SDF 是一个函数，输入空间里的任意一点，输出这点到物体表面的“带符号的最短距离”**——在物体外为正、物体内为负、边界上为零。这样，形状不再是“点和面”的集合，而是一个处处可取样的**场**。([[SpringerLink](https://link.springer.com/content/pdf/10.1007/0-387-22746-6_2?utm_source=chatgpt.com)][1], [[MIT Mathematics](https://math.mit.edu/classes/18.086/2007/levelsetpres.pdf?utm_source=chatgpt.com)][2])

## 1）先用生活比喻把它“看见”

把物体想象成一座小山，**海拔 0 米**那一圈就是物体的边界；山外的海拔是**正数**，山体内部是**负数**。因此，一张“等高线地图”（距离等值线）就能把形状、厚薄、过渡、凹凸都描述出来。你也可以把它当成“**每个位置到围墙的距离**”：站在小区里的点，距离是负；走到墙外，距离变正；踩在墙上，距离刚好为 0。这个“处处都有答案”的特性，正是 SDF 的威力所在。([[MIT Mathematics](https://math.mit.edu/classes/18.086/2007/levelsetpres.pdf?utm_source=chatgpt.com)][2])

---

## 2）SDF 的严格定义（但超好懂）

令 $\Omega$ 为物体内部区域、$\partial\Omega$ 为其边界。**有符号距离函数** $\phi(\mathbf{x})$ 定义为：

* $\phi(\mathbf{x})<0$：$\mathbf{x}$ 在物体内部；
* $\phi(\mathbf{x})=0$：$\mathbf{x}$ 在边界；
* $\phi(\mathbf{x})>0$：$\mathbf{x}$ 在物体外部。
  理想的 SDF 在边界附近还满足 $|\nabla \phi|=1$，这能带来漂亮稳定的法线与数值行为。([[SpringerLink](https://link.springer.com/content/pdf/10.1007/0-387-22746-6_2?utm_source=chatgpt.com)][1])

---

## 3）从“圆和方块”开始的解析 SDF

在 2D / 3D 里，有许多**解析公式**可以直接给出到常见图元的距离。例如：

* **圆 / 球**：到中心的距离减半径
  $\text{sdCircle}(\mathbf{x})=\|\mathbf{x}-\mathbf{c}\|-r$（3D 同理是球）。
* **轴对齐矩形 / 盒子**：用 `max(abs()-size, 0)` 再取长度。
* **并、交、差**（CSG）：把不同形状的 SDF 用 `min / max` 组合（并集用 `min`，交集用 `max`，差集用 `max(a,-b)`）。

这些公式与运算可以像乐高一样叠出复杂形状，是距离场建模的基石。([[Computer Laboratory](https://www.cl.cam.ac.uk/teaching/1819/FGraphics/1.%20Ray%20Marching%20and%20Signed%20Distance%20Fields.pdf?utm_source=chatgpt.com)][3])

> 平滑布尔：把“并集的 min”换成**平滑最小值**（smooth min，常记 smin），可以让两个形状**自然融合**，适合做圆角与软过渡。([[GitHub](https://github.com/glslify/glsl-smooth-min?utm_source=chatgpt.com)][4])

---

## 4）距离场从哪儿来？

除了解析式，还有几条常见途径：

* **图像/体素 → 距离场（距离变换）**：对像素（或体素）计算到前景的最短欧氏距离，经典算法有 **Danielsson** 欧氏距离映射（CPU 友好）和 **Jump Flooding（JFA）**（GPU 友好，适合实时）。([[ScienceDirect](https://www.sciencedirect.com/science/article/pii/0146664X80900544?utm_source=chatgpt.com)][5], [[NUS Computing](https://www.comp.nus.edu.sg/~tants/jfa/i3d06.pdf?utm_source=chatgpt.com)][6])
* **相机深度 → TSDF**：在 3D 扫描/重建里常用\*\*截断 SDF（TSDF）\*\*聚合多帧深度，像 KinectFusion 就把 TSDF 当作体积地图来做实时建模与定位。([[Microsoft](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/02/ismar2011.pdf?utm_source=chatgpt.com)][7])

## 5）SDF 怎么“渲染出画面”？——Ray Marching / Sphere Tracing

渲染 SDF 最常见的是**沿射线前进（ray marching / sphere tracing）**：

1. 从相机发一条射线；
2. 在当前位置评估距离 $d=\phi(\mathbf{x})$；
3. **向前走恰好 $d$ 的步长**（因为最近表面肯定不小于这么远）；
4. 距离足够小就命中，否则步进到上限就视为未击中。

这个“步步不穿透”的策略由 **John C. Hart** 系统化提出，因 SDF 给了可靠的“安全步长”，既稳定又易实现。([[SpringerLink](https://link.springer.com/article/10.1007/s003710050084?utm_source=chatgpt.com)][8], [[Computer Laboratory](https://www.cl.cam.ac.uk/teaching/1819/FGraphics/1.%20Ray%20Marching%20and%20Signed%20Distance%20Fields.pdf?utm_source=chatgpt.com)][3])

* **法线**：直接用距离场的梯度 $\nabla\phi$ 归一化得到。
* **软阴影 / 环境遮蔽（AO）**：沿光线或法线方向**稀疏取样距离**，根据“前方有多快遇到几何体”估计遮蔽程度，成本低、效果柔和。([[Iquilezles](https://iquilezles.org/articles/nvscene2008/rwwtt.pdf?utm_source=chatgpt.com)][9], [[Computer Laboratory](https://www.cl.cam.ac.uk/teaching/1819/FGraphics/1.%20Ray%20Marching%20and%20Signed%20Distance%20Fields.pdf?utm_source=chatgpt.com)][3], [[Computer Science House](https://csh.rit.edu/~gman/PersonalWebpage/ao.html?utm_source=chatgpt.com)][10])

## 6）SDF 为什么这么实用？

1. **高清文字（TextMesh Pro 等）**
   Valve 在 2007 年把 SDF 引入文字放大与特效渲染：先对字形生成高分辨率距离场，再**低分辨率存储 + 片元内阈值**重建边界，可锐利缩放、轻松做描边/阴影。Unity 的 **TextMesh Pro** 就是典型工程化实现。**MSDF**（多通道 SDF）进一步改善尖角。([[Steam CDN](https://steamcdn-a.akamaihd.net/apps/valve/2007/SIGGRAPH2007_AlphaTestedMagnification.pdf?utm_source=chatgpt.com)][11], [[Unity Documentation](https://docs.unity3d.com/Packages/com.unity.textmeshpro%403.2/manual/FontAssetsSDF.html?utm_source=chatgpt.com)][12], [[PORTA](https://dcgi.fel.cvut.cz/publications/2018/sloup-cgf-msdf?utm_source=chatgpt.com)][13])

2. **形变动画 / 程序化建模**
   用解析 SDF + CSG + 平滑运算，把“捏、切、圆角、重复、旋转、拉伸”等操作**写成数学组合**，变形天然光滑连贯。Inigo Quilez 的工作与分享极具代表性。([[Iquilezles](https://iquilezles.org/articles/nvscene2008/rwwtt.pdf?utm_source=chatgpt.com)][9], [[San Francisco ACM SIGGRAPH](https://san-francisco.siggraph.org/2025/04/05/inigo-quilez-unlocking-creativity-with-signed-distance-fields/?utm_source=chatgpt.com)][14])

3. **序列帧动画柔和过渡**
   两帧图像先各自做距离变换，再在距离场上做插值/阈值回投，可得到**防锯齿、边缘保持**的过渡与混合。（工程上常与 MSDF/阈值渲染同理使用。）([[Steam CDN](https://steamcdn-a.akamaihd.net/apps/valve/2007/SIGGRAPH2007_AlphaTestedMagnification.pdf?utm_source=chatgpt.com)][11])

4. **碰撞检测**
   SDF 天生告诉你“**在内/在外**”与**最近距离/方向（梯度）**，因此对复杂网格可用 **SDF 碰撞体**做快速稳健碰撞；NVIDIA Omniverse/PhysX、以及基于 SDF 的接触点优化（Macklin 等）都有成熟方案与论文。([[Omniverse Docs](https://docs.omniverse.nvidia.com/kit/docs/omni_physics/latest/dev_guide/rigid_bodies_articulations/collision.html?utm_source=chatgpt.com)][15], [[Datalogisk Institut](https://di.ku.dk/english/research/groups/simulation/research-results/local-optimization-for-robust-signed-distance-field-collision/?utm_source=chatgpt.com)][16])

5. **软阴影（Soft Shadow）与** **环境遮蔽（AO）**
   基于距离的步进/取样能以极少采样估计遮挡，做出柔滑半影与局部遮蔽，是 SDF 渲染里的“物美价廉”特效。([[Iquilezles](https://iquilezles.org/articles/nvscene2008/rwwtt.pdf?utm_source=chatgpt.com)][9], [[Computer Laboratory](https://www.cl.cam.ac.uk/teaching/1819/FGraphics/1.%20Ray%20Marching%20and%20Signed%20Distance%20Fields.pdf?utm_source=chatgpt.com)][3])

## 7）从 2D 到复杂图案：一套“纯数学”搭积木

下面给出你能立刻上手的 2D 路线：

* **原子图元**：圆、矩形、线段、胶囊（线段的“加厚”）。每个都有解析 SDF。
* **空间操作**：平移、旋转、镜像、重复（**空间重复**常用 `mod` 技巧）。
* **集合运算**：并/交/差 + **平滑并**（smin）。
* **厚度/描边**：对 SDF 取等值带 $|\phi(\mathbf{x})|<w$。
* **抗锯齿/渐变**：把 $\phi$ 映射到 $[0,1]$ 可视化（例如 `smoothstep`），颜色或透明度随距离平滑过渡。

这些都能在一本“距离算子字典”里找到现成配方和推导。([[Computer Laboratory](https://www.cl.cam.ac.uk/teaching/1819/FGraphics/1.%20Ray%20Marching%20and%20Signed%20Distance%20Fields.pdf?utm_source=chatgpt.com)][3])

## 8）工程提示与常见坑

* **数值与速度**：SDF 要尽量满足 1-Lipschitz（$|\nabla\phi|\approx1$），步进才稳定；对离散栅格 SDF，插值与重采样可能破坏这个性质，必要时做归一化修正。([[Cescg](https://old.cescg.org/CESCG-2008/papers/TUBudapest-Liktor-Gabor.pdf?utm_source=chatgpt.com)][17])
* **带宽化 / 窄带 SDF**：很多应用只需要**边界附近**的一条“窄带”；在 3D 重建里常用**TSDF 截断**来控内存与噪声。([[Microsoft](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/02/ismar2011.pdf?utm_source=chatgpt.com)][7])
* **字体的尖角**：单通道 SDF 的描边在尖角处易圆钝，**MSDF** 用 RGB 三通道分别存储不同边，能保留尖角细节。([[PORTA](https://dcgi.fel.cvut.cz/publications/2018/sloup-cgf-msdf?utm_source=chatgpt.com)][13])
* **生成方式的取舍**：

  * 解析式 → 精准、可微、可组合；
  * 距离变换（EDT/JFA） → 适合图像/体素、实现简单；
  * 传感重建（TSDF） → 适合 SLAM/3D 扫描。([[ScienceDirect](https://www.sciencedirect.com/science/article/pii/0146664X80900544?utm_source=chatgpt.com)][5], [[NUS Computing](https://www.comp.nus.edu.sg/~tants/jfa/i3d06.pdf?utm_source=chatgpt.com)][6], [[Microsoft](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/02/ismar2011.pdf?utm_source=chatgpt.com)][7])

## 9）极简“口算版”公式卡（2D）

* **圆（半径 $r$，圆心 $\mathbf{c}$**）：$\;d(\mathbf{x})=\|\mathbf{x}-\mathbf{c}\|-r$（负在圆内）([[Almost looks like work](https://jasmcole.com/2019/10/03/signed-distance-fields/?utm_source=chatgpt.com)][18])
* **矩形（半边长 $\mathbf{s}$**）：$\;d(\mathbf{x})=\|\max(|\mathbf{x}|-\mathbf{s},\mathbf{0})\|$（在轴对齐局部坐标中）([Computer Laboratory][3])
* **并/交/差**：$\;\text{union}=\min(d_1,d_2)$，$\text{intersect}=\max(d_1,d_2)$，$\text{subtract}=\max(d_1,-d_2)$；**平滑并**：$\text{smin}(a,b,k)$（看作 $\min$ 的可控圆角版）。([[Computer Laboratory](https://www.cl.cam.ac.uk/teaching/1819/FGraphics/1.%20Ray%20Marching%20and%20Signed%20Distance%20Fields.pdf?utm_source=chatgpt.com)][3], [GitHub][4])

## 结语

SDF 的魅力，在于**一个函数统一了承载形状、着色、特效与物理**：

* 它让\*\*“在/外/上”**判断和**最近距离\*\*成为常数时间查询；
* 让**并、交、差、圆角**天然可组合；
* 让**渲染步进**与**AO/软阴影**变得简单优雅；
* 还能支撑**文字、建模、碰撞、重建**等多领域场景。
  从 2D 圆和矩形的距离公式出发，你就能用**纯数学**构造越来越复杂的图案与动画。如果你愿意，我可以把上面的“2D 小字典”做成一张**速查表**或一段可运行的示例（GLSL / HLSL / ShaderToy / WebGPU 任选）。
