Overview
This dataset contains 3D ocean physical field data used in the research on three-dimensional
structural feature extraction and spatiotemporally continuous visualization of internal waves in
the South China Sea. The raw time-series outputs from numerical simulation are extremely
large. The data provided in this repository demonstrates the data structure and the feature
extraction method described in the associated paper.
Targeted at reviewers and readers, this dataset is mainly used to:
• Validate the volume rendering pipeline and 3D structural feature extraction algorithm;
• Support analysis of the spatial continuity of internal waves;
• Reproduce the related results following the methods proposed in the paper.
2
Data Source and Simulation Configuration
• Data Source: Raw numerical simulation outputs are generated by the MITgcm model.
MITgcm is a primitive-equation ocean model with optional non-hydrostatic approximation, suitable for simulating oceanic and atmospheric dynamics at fine spatial and temporal
scales. In this study, non-hydrostatic MITgcm is adopted for high-resolution simulation
of the northern South China Sea. Main outputs include temperature, salinity, sea surface
height, horizontal velocity and vertical velocity.
• Initial Conditions: Initial temperature and salinity fields are derived from the WOA2013
climatological dataset (https://www.ncei.noaa.gov/access/); initial velocity is set to zero
(cold start).
• Boundary Conditions: The western boundary is forced by 11 barotropic tidal constituents (e.g., M2, S2), extracted from TPXO7.1 via the MATLAB Tidal Model Driver
1
(TMD). Sponge layers are applied at the eastern and western open boundaries to mitigate
internal wave reflection.
• Vertical Mixing: K-Profile Parameterization (KPP) scheme is used.
• Simulation Domain: Northern South China Sea, ranging from 116◦ E − 123◦ E, 18◦ N −
22.7◦ N (Figure 1).
– Horizontal grid: 1,932 × 651 grid points
– Vertical layers: 82 layers
– Output interval: 9 minutes; total simulation duration: 24 hours
• Contributing Institution: Key Laboratory of Physical Oceanography, Ministry of Education, Ocean University of China
• Spatial Extent:
– Longitude: 116◦ E − 123◦ E (1932 grid points)
– Latitude: 18◦ N − 22.7◦ N (651 grid points)
– Depth: 0 – 4840.5 m (82 layers, positive downward)
• Time Range of Released Dataset: 2021-11-08 06:00 – 06:18 UTC
• Temporal Resolution: 9 minutes

Data Processing
1. Storage: Data are saved in NetCDF-4 format with zlib compression (compression level
4) to reduce file size.
2. File Naming: Files follow the unified naming convention IW <variable name>.nc for
easy identification.
6
Usage Notes
• Reading Tools: The dataset can be accessed by any NetCDF-compatible software, e.g.,
Python (xarray, netCDF4), MATLAB, Panoply, ncview, CDO, NCO.
• Time Interpretation: The time variable takes values [0.0, 0.15, 0.30] with units hours
since 2021-11-08 06:00:00. Most software packages will automatically parse these
values to 2021-11-08 06:00, 06:09, 06:18 UTC.
• Missing Values: FillValue for floating-point variables is set to NaN. Please handle
NaN values properly during analysis and visualization.
• Vertical Coordinate: Depth increases downward. The 0-th layer corresponds to the sea
surface, and the 81st layer is the deepest level.
