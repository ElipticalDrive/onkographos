Summary
Extends the IceBridge G-buffer material path so Vulkan can reuse the same scalar packing as D3D12: optional roughness, metallic, and material type from .mtr definitions, wired through the existing depth-fill → glSurfaceRoughnessf / glSurfaceMetallicf / glMaterialTypef path.
Material keywords
pbrRoughness / roughness (0–1) — unchanged channel: normal RT alpha.
pbrMetallic / metallic (0–1) — when set, albedo alpha is encoded as 2 + metallic so it does not collide with ordinary texture alpha (≤ 1). Omitting metallic leaves texture alpha untouched.
pbrMaterialType / materialType — passed through existing glMaterialTypef.
Renderer
DrawCB / DrawConstants / BatchKey: add metallic float (default -1 = “no override”).
HLSL: PackAlbedoMetallic after fog; alpha-tested path tests alpha before packing metallic.
DXR (gl_d3d12raylight.cpp): decode metallic from albedo; blend specular mask toward conductor-like response; propagate metallic on G-buffer fetches and add a cheap metallic specular term on bounce lighting.
Docs
Short paragraph in readme.md under the Vulkan section.
Testing
Not run (Windows MSVC / DXR stack not available in this environment).

- Depth fill pushes values via glSurfaceRoughnessf / glSurfaceMetallicf / glMaterialTypef
- Extend DrawCB with gMetallic; pack optional metallic into albedo alpha (2+m) for DXR decode
- Path trace: decode metallic, modulate specular; bounce hits carry metallic through G-buffer fetch
- Declare glSurfaceRoughnessf and glMaterialTypef in opengl.h; document keywords in readme
