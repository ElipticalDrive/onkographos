Summary
Closes #50.
Implements an unopinionated, genre-agnostic volumetric voxel and deformable terrain subsystem via a standalone modular plugin crate (crates/plugins/voxel), adhering strictly to the Prime Directive in AGENTS.md with zero voxel logic hardcoded into core engine crates.
Key Changes
Crate crates/plugins/voxel (mmo-plugin-voxel):
coords.rs: VoxelCoord, VoxelChunkCoord, and Euclidean division/modulo (div_euclid(16), rem_euclid(16)) preventing negative coordinate panics. Maps cleanly to 64m discrete sectors (SectorCoord3D).
chunk.rs: Bit-packed palette-compressed PaletteChunk supporting dynamic bit-depths (0, 1, 2, 4, 8, 16 bits per voxel) with homogeneous 0-bit optimization and dynamic repacking.
codec.rs: Compact Run-Length Encoding (RLE) serialization with decompression bomb validation (enforces exact 4,096 decoded voxel sum).
mesh.rs: Culled boundary face mesh extraction producing WebGL-ready flat float vertex buffers ([x, y, z, nx, ny, nz, voxel_id]). Employs deadlock-free neighbor sampling and an unloaded-neighbor solid culling policy.
modify.rs: Authoritative player reach verification (max_reach + tolerance buffer), rate limiting (ExcavationRateLimiter), boundary voxel invalidation, and domain event dispatch (VoxelChangeEvent).
net.rs: Binary wire protocol registered on ModularPacketRouter under module ID 0x00A0 (VoxelChunkRequest, VoxelChunkData, VoxelDeltaBatch, VoxelModifyRequest, VoxelModifyResponse).
world.rs: High-concurrency spatial container (VoxelWorld) backed by DashMap and lock-isolated boundary mesh builders.
plugin.rs: Standalone VoxelTerrainPlugin implementing GameplayPlugin with packet routing and tick systems.
persistence.rs: Bounded write-behind chunk coalescing map protecting against memory exhaustion under DB latency spikes, with PostgreSQL/SQLite table schema.
Client WebAssembly Core (crates/client-wasm):
voxel.rs: Client-side WASM chunk decoder exposing decode_voxel_chunk_mesh and decode_voxel_chunk to JavaScript/WebGL with culled mesh generation.
Verification & Quality Gates:
Comprehensive unit tests in mmo-plugin-voxel (33 tests) and mmo-client-wasm (11 tests).
End-to-end integration tests in crates/plugins/voxel/tests/voxel_plugin_test.rs covering authoritative excavation, multi-chunk boundary propagation, and high-throughput write-behind persistence stress.
Passed cargo fmt --all -- --check, cargo clippy --workspace --all-targets -- -D warnings (zero warnings), and cargo test --workspace (all workspace crates passing).
