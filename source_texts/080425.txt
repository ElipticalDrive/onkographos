Közzététel: 2013. júl. 20.
Method: Mobile device makes wireless connection with rendering server. Device uses its touch screen to navigate visualization. Navigation data (coefficients of linear transfer matrix) is send to rendering server and server in response transmit rendered image.
Rendering method: volume rendering, texture- based algorithm with view aligned slices. Dynamic gradient computation, post classification. Implemented in XNA Framework 2.0 (managed code, C#, Direct X 9.0C).
Data: computed tomography angiography (DICOM), ~512^3 voxels.
The Laboratory of Cryptography and Cognitive Informatics, Chair of Computer Science and Computational Methods at the Pedagogical University in Krakow.
Website: http://www.cci.up.krakow.pl/
