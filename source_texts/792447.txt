English: Implement Point Cloud Parsers (PLY, LAS, LAZ)
Parent: #8
Description
Implement three parser modules that can load and parse PLY, LAS, and LAZ point cloud files, returning a unified data structure for the 3D scene.
Unified Return Type
All parsers should return: { positions: Float32Array, colors: Float32Array, count: number }
Checklist
parsePLY.ts
Create src/components/PointCloud/parsePLY.ts
Wrap Three.js PLYLoader to parse PLY files (both ASCII and binary formats)
Extract vertex positions and vertex colors from the parsed geometry
If no colors are present, generate default colors (e.g., white or position-based gradient)
Return unified { positions, colors, count } structure
parseLAS.ts
Create src/components/PointCloud/parseLAS.ts
Implement custom LAS 1.2/1.4 binary parser
Parse LAS header: version, point count, point format, offset to point data, scale/offset
Parse point records: extract XYZ coordinates (apply scale/offset), RGB colors (from bytes 20-22 in format 2/3)
Handle both little-endian and standard byte order
Return unified { positions, colors, count } structure
parseLAZ.ts
Create src/components/PointCloud/parseLAZ.ts
Use @loaders.gl/las to decompress LAZ bytes → raw LAS bytes
Delegate to parseLAS for parsing the decompressed data
Handle decompression errors gracefully with clear error messages
Return unified { positions, colors, count } structure
Scope
src/components/PointCloud/parsePLY.ts (new)
src/components/PointCloud/parseLAS.ts (new)
src/components/PointCloud/parseLAZ.ts (new)
中文：实现点云解析器（PLY、LAS、LAZ）
父级 Issue： #8
描述
实现三个解析器模块，用于加载和解析 PLY、LAS 和 LAZ 点云文件，返回统一的数据结构供 3D 场景使用。
统一返回类型
所有解析器应返回：{ positions: Float32Array, colors: Float32Array, count: number }
任务清单
parsePLY.ts
创建 src/components/PointCloud/parsePLY.ts
封装 Three.js PLYLoader 解析 PLY 文件（支持 ASCII 和二进制格式）
从解析的几何体中提取顶点位置和顶点颜色
如果没有颜色信息，生成默认颜色（例如白色或基于位置的渐变色）
返回统一的 { positions, colors, count } 结构
parseLAS.ts
创建 src/components/PointCloud/parseLAS.ts
实现自定义 LAS 1.2/1.4 二进制解析器
解析 LAS 头部：版本、点数量、点格式、点数据偏移、缩放/偏移参数
解析点记录：提取 XYZ 坐标（应用缩放/偏移）、RGB 颜色（格式 2/3 中字节 20-22）
处理小端序和标准字节序
返回统一的 { positions, colors, count } 结构
parseLAZ.ts
创建 src/components/PointCloud/parseLAZ.ts
使用 @loaders.gl/las 将 LAZ 字节解压为原始 LAS 字节
委托 parseLAS 解析解压后的数据
优雅处理解压错误，提供清晰的错误信息
返回统一的 { positions, colors, count } 结构
影响范围
src/components/PointCloud/parsePLY.ts（新建）
src/components/PointCloud/parseLAS.ts（新建）
