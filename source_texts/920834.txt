# Sky Map in 3D Gaussian Splatting

A complete pipeline for creating and rendering sky environments in 3D Gaussian Splatting (3DGS) scenes. This project addresses the common problem of missing or poorly reconstructed sky regions in 3DGS by projecting latitude-longitude sky maps into the Gaussian splat representation.

The pipeline covers every stage from COLMAP reconstruction to final evaluation: sky segmentation, sky map projection, Gaussian filtering, image rendering, and quantitative quality assessment.

> **Note:** The WebGL viewer used for real-time rendering lives in a separate fork: [eliaz02/splat](https://github.com/eliaz02/splat)

## Pipeline Overview

```
Input Images → COLMAP → Sky Segmentation → Sky Map Projection → Gaussian Filtering → Rendering → Evaluation
                           (SkyMask)            (Map)          (Post-processing)  (image_generation
                                                                                     / splat)
```
