Description
Add configurable sorting modes for Gaussian splat depth-ordering in the tiled camera sensor's ray tracer. The default sorting strategy (closest-approach distance in canonical space) can now be overridden with two alternatives — camera distance (projection of the Gaussian center onto the ray) and Z depth (camera-forward depth of the Gaussian center) — giving users control over compositing order for scenes where the default heuristic produces artifacts.
Changes
Gaussian.SortingMode enum (geometry/types.py): New nested IntEnum with DEFAULT, CAMERA_DISTANCE, and Z_DEPTH. Added as a parameter to Gaussian.__init__, stored in the Warp Data struct, and exposed via a sorting_mode property.
Sorting kernels (warp_raytrace/gaussians.py): Two new Warp functions — camera_distance_sorting and z_depth_sorting — applied conditionally in the shade function based on gaussian_data.sorting_mode.
Ray pipeline plumbing (warp_raytrace/raytrace.py, render.py): Computed camera_forward from the camera transform and threaded it through create_closest_hit_function and create_closest_hit_depth_only_function so the Z-depth sorting mode has access to the camera's forward vector.
USD ingestion (usd/utils.py): Reads the sortingModeHint attribute from USD Gaussian prims ("zDepth" / "cameraDistance") and maps it to the corresponding SortingMode.
Checklist
New or existing tests cover these changes
The documentation is up to date with these changes
CHANGELOG.md has been updated (if user-facing change)
Test plan
Verify the tiled camera sensor renders Gaussian splats correctly with each sorting mode (DEFAULT, CAMERA_DISTANCE, Z_DEPTH).
Load a USD scene with the sortingModeHint attribute set and confirm the correct mode is parsed.
Run existing sensor / Gaussian regression tests to confirm no regressions:

New Features
Configurable depth-sorting strategies for Gaussian rendering: ray-hit distance, camera-distance, and z-depth.
Sorting mode can be specified when loading USD assets and is applied end-to-end during rendering (camera-facing depth is now propagated into raytracing/shading).

📝 Walkthrough
Walkthrough
Adds a Gaussian depth-sorting mode enum (RAY_HIT_DISTANCE, CAMERA_DISTANCE, Z_DEPTH), stores it in GPU-visible Gaussian data, propagates camera_forward through the raytracing pipeline, updates Gaussian hit-distance computation to support three sorting modes, and reads a USD sortingModeHint to select the mode.
Changes
Cohort / File(s)
Summary
Type System & Gaussian Definition
newton/_src/geometry/types.py
Added Gaussian.SortingMode (RAY_HIT_DISTANCE=0, CAMERA_DISTANCE=1, Z_DEPTH=2). Extended Gaussian.Data Warp struct with sorting_mode: wp.int32. Constructor accepts sorting_mode (default RAY_HIT_DISTANCE), stored on instance, exposed via sorting_mode property; finalize(), __hash__, and __eq__ updated to include the mode.
Gaussian Shading & Sorting Helpers
newton/_src/sensors/warp_raytrace/gaussians.py
Renamed canonical_ray_hit_distance → sorting_mode_ray_hit_distance. Added sorting_mode_camera_distance and sorting_mode_z_depth @wp.func helpers. ray_gsplat_hit_response now accepts sorting_mode: wp.int32 and camera_forward: wp.vec3f; shade(...) gained camera_forward and uses gaussian_data.sorting_mode to choose hit-distance computation for insertion/sorting.
Raytracing Call Chain
newton/_src/sensors/warp_raytrace/raytrace.py
Added camera_forward: wp.vec3f parameter to closest_hit_shape, closest_hit, closest_hit_shape_depth_only, and closest_hit_depth_only. Propagated camera_forward into shade_gaussians(...) calls.
Render Kernel Invocation
newton/_src/sensors/warp_raytrace/render.py
Compute camera_forward by transforming camera-space (0,0,-1) to world space and pass it into raytrace_closest_hit / closest-hit pipeline.
USD Integration
newton/_src/usd/utils.py
get_gaussian() reads optional sortingModeHint string from USD prim, maps "zDepth"→Z_DEPTH, "cameraDistance"→CAMERA_DISTANCE, "rayHitDistance"→RAY_HIT_DISTANCE (defaults to RAY_HIT_DISTANCE), errors on unsupported values, and passes resolved sorting_mode into Gaussian(...).
Sequence Diagram(s)
```
sequenceDiagram
    participant Render as Render Kernel
    participant RT as Raytracing
    participant Hit as Closest Hit
    participant GaussianShade as Gaussian Shading
    participant Sort as Sorting Helper

    Render->>Render: compute camera_forward (transform (0,0,-1) to world)
    Render->>RT: raytrace_closest_hit(..., camera_forward)
    RT->>Hit: closest_hit(..., camera_forward)
    Hit->>Hit: BVH hit candidate found (initial hit_distance)
    alt sorting_mode == CAMERA_DISTANCE
        Hit->>Sort: sorting_mode_camera_distance(gaussian_center, ray)
        Sort-->>Hit: camera parametric distance
    else sorting_mode == Z_DEPTH
        Hit->>Sort: sorting_mode_z_depth(gaussian_center_world, camera_forward, ray_world)
        Sort-->>Hit: z-depth parametric distance
    else sorting_mode == RAY_HIT_DISTANCE
        Hit-->>Hit: use original ray hit distance
    end
    Hit->>GaussianShade: shade(..., sorting_mode, camera_forward)
    GaussianShade-->>Render: shaded result / attributes
```
