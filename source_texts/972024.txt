This document outlines changes in the Self-Organizing Map Program Package (SOM_PAK; Kohonen et al. 1996) designed to allow for large input data vectors. This change facilitates the production of time-evolving SOMs (Gu and Gervais, 2022) where input data vectors are three dimensional fields with both space and time dimensions. The original SOM_PAK is available at the following link: http://www.cis.hut.fi/research/som_lvq_pak.shtml. This document is associated a journal article (Gu and Gervais, 2022). Please cite both Kohonen et al. (1996) and Gu and Gervais (2022) when using this method. References: Kohonen, T. K., Hynninen, J., Kangas, J., & Laaksonen, J. (1996).
