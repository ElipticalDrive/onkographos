The current normal equations square the condition number and add an absolute ridge to intersection coordinates. This biases small-parallax intersections and makes arbitrary direction scales affect the geometry. Normalize each direction, solve the original system with the SVD pseudoinverse, and convert ray parameters back to the original direction units. Reject a zero direction explicitly.
Analytic intersections with independently varied direction scales, small parallax, skew-line midpoint and rigid frame transformations, broadcasts, noncontiguous/empty inputs, and two-, three-, and four-dimensional controls. No unique intersection is asserted for parallel lines.
For rank-deficient configurations, the pseudoinverse chooses the minimum-norm solution of the direction-normalized system. This replaces the previous absolute ridge convention; translation equivariance and a unique intersection are not claimed for parallel lines. The direction-normalized minimum-norm convention needs maintainer review.
On Windows with Python 3.12.10, NumPy 2.5.3, and PyTorch 2.14.1+cpu (CPU), the unchanged code reproduces 17 assertion failures and 0 error records across 5 failing methods; the identical frozen regression file passes all 5 methods after the patch, with zero skips/errors. Subtest records are not separate test-method counts. Validation imports the genuine complete package from each Git checkout. The repository has no formal unit suite; its root PLY benchmark, CUDA, rasterization, and downstream model runs were not executed.
