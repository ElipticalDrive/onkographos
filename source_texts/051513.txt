Query neighboring chunks before culling boundary faces
get_voxel_safe treats any out-of-bounds neighbor as air, so with the new 3x3 chunk generation path in State::new every solid voxel on a chunk border emits faces even when the adjacent chunk has a solid voxel too. That recreates interior seam faces (duplicated quads on shared borders), which needlessly increases vertex/index counts and degrades rendering performance as more chunks are loaded. Boundary culling needs neighbor-chunk visibility data instead of a blanket out-of-bounds-as-air fallback.

Compute signed terrain height before casting to usize
The terrain height expression casts the sine/cosine sum to usize before adding the base height, and in Rust negative floats cast to usize as 0. That means all negative wave values collapse to the same height (10), flattening valleys and breaking the intended sinusoidal terrain profile. Keep the wave value in signed/float form until after adding the base offset, then convert once.
