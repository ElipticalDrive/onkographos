Problem
Currently we only handle importing .grd assets from .qb files.
The main tool we use though, MagicaVoxel, uses the .vox format (https://github.com/ephtracy/voxel-model/blob/master/MagicaVoxel-file-format-vox.txt).
So, to import stuff into Cubos, we need to first export a .qb from MagicaVoxel, and only then convert the result into a .grd.
Thus, we end up with 3 different files for the same thing (a .vox, a .qb, and a .grd).
Solution
We should add support for directly importing .vox files.
To do this, we should rename the existing VoxelModelBridge to QubicleBridge, and add another MagicaVoxelBridge which loads VoxelModel assets from .vox files.
To reduce code duplication, and also implement this in quadrados, quadrados convert could maybe be changed to use these bridges instead of manually calling the loading functions.
Format documentation can be found here.
This format also supports animations and scene hierarchies, through this extension. It would be nice to later extend the bridge to also support these features.
