Summary
A global rendering toggle that renders any particle effect as a ray-marched fog/nebula instead of discrete dots — the app's first true 3D-volumetric look, and the prerequisite for the flagship Lattice effect that follows.
Volumetric OFF → dots. Volumetric ON → shaded, colored cloud.
Pipeline
Three GPU steps per frame, run inside ParticleSystem (the only place the private SoA particle buffers are reachable):
Scatter (volumetric_scatter.wgsl) — each alive particle atomicAdds fixed-point density into a u32 voxel grid; a stable Z is synthesized from a PCG hash of the particle index.
Resolve (volumetric_resolve.wgsl) — saturating-normalise + 3×3×3 blur into a samplable r32float 3D density texture.
Ray march (volumetric_raymarch.wgsl) — orbiting-camera ray march (inline ray, no matrix) with Beer-Lambert absorption, a self-shadow light march, FBM detail, and a cosine emission palette; Reinhard tone-mapped, composited premultiplied.
The density texture + marcher are the reusable core Lattice will feed directly (density_storage_view() exposed) — particle scatter is just one density producer.
Shading (tuned on the RTX 4090)
The initial build blew out to a flat white blob; corrected here:
Saturating density normalise (1 − e^(−gain·occupancy)) — bounded and particle-count-independent, so dense effects no longer white out.
Reinhard tone map — emission lifts brightness without clipping.
Soft envelope — fades density toward the cube faces, so a filled field reads as a cloud, not a lit box.
Self-shadow light march — dense regions cast shadows → real 3D form instead of flat uniform glow (this is what lets Emission go up without losing internal detail).
Controls
Volumetric (R3) side-panel section: enable + density / absorption / volume-depth / emission / detail / palette / cam yaw / cam pitch / orbit speed / march-steps sliders + Reset to defaults.
OSC: /phosphor/volumetric/enabled and /phosphor/volumetric/{param}.
Audio-reactive (beat pulses density, kick bursts emission, rms drives absorption) from the audio the particle system already carries — no new plumbing.
Verification
cargo fmt --check + clippy --all-targets -D warnings clean; 544 tests pass.
All three shaders validate against naga 27.0.3 (the version wgpu uses).
Visual look confirmed on the RTX 4090 across Murmur and Flux.
Deferred (R3 v2)
Separable 3D Gaussian blur, half-res + bilateral upsample, per-voxel colour accumulation, orbiting/tunable light direction, keyboard toggle, per-effect .pfx baking, multi-layer volumetric.

cam_yaw was hardcoded to 0.0 in build_uniforms, so stopping the orbit
(cam_orbit_speed = 0) froze the camera at yaw 0 with no way to choose a
viewing angle. Expose it as a VolumetricParams field + a Cam yaw slider
(0..TAU) and OSC param; the marcher already orbits at cam_yaw + time *
cam_orbit_speed, so this sets the static viewing angle when orbit is off.
