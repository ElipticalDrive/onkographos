What changed
add a shared Cook–Torrance GGX metallic/roughness BRDF
use the same direct-light BRDF in Forward/CSM and Deferred rendering
expand the G-buffer to three explicit MRTs: albedo+metallic, normal+roughness, emissive+AO
support base-colour, normal, metallic/roughness, AO and emissive texture bindings with automatic presence flags
preserve GPU skinning in the expanded G-buffer vertex path
expose the material attachment for renderer/editor diagnostics
update DeferredShadowDemo with dielectric, metal, glossy, rough and HDR-emissive variants plus HDR light intensities
document the serializable PBR material contract
Architecture
The PBR properties remain ordinary named material constants and texture units, so the existing MaterialSerializer can round-trip them and a future Material Editor does not need a parallel material API. CSM remains the directional-sun shadow system; local point lights remain independent and unshadowed.

C++11 syntax checks pass with -Wall -Wextra -Wformat for changed renderer translation units
C++11 syntax checks pass for DeferredShadowDemo and RenderPipelineDemo using SDL declaration stubs
git diff --check passes
the GitHub tree SHA matches the validated local tree exactly
runtime OpenGL shader compilation and visual tuning remain to be verified on the development machine
