Revamps the light ray visual effect to use a custom raytracing shader
via ray marching, producing soft, diffused, and realistic volumetric god
rays for each glass sphere. Removes additive cone mesh with MeshBasicMaterial
and replaces with a ShaderMaterial approach that simulates scattering
using few samples for real-time performance. Light rays color and
intensity now update via shader uniforms for more physical accuracy
and visual appeal. Adds time-based and noise-driven softness for a natural look.

Also expands the OrbitControls max zoom range so the user can zoom
out well beyond the bounds of the cube, allowing external views.

User experience and visual realism are both significantly improved. No breaking changes for existing controls or API.
