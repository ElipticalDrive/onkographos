# tiny-3dgs

A 3D Gaussian Splatting implementation built from scratch — every component written by hand to understand the full pipeline before combining it with differentiable physics.

## Status

- [ ] 01 — Gaussian representation + forward projection (NumPy)
- [ ] 02 — Tile-based rasterizer, forward (CUDA)
- [ ] 03 — Differentiable backward pass (CUDA)
- [ ] 04 — Training loop + adaptive density control
- [ ] 05 — Spherical harmonics (stretch)

## What's inside

```
01_gaussian_projection/   Gaussian dataclass, 3D→2D projection, screen-space covariance
02_rasterizer/            Tile-based CUDA rasterizer (forward)
03_backward/              Differentiable backward pass through the rasterizer
04_training/              Training loop, loss, adaptive density control
05_spherical_harmonics/   View-dependent color via SH basis functions
```

## Run

```bash
pip install -r requirements.txt

# Stage 1 — forward projection (CPU only)
python 01_gaussian_projection/gaussian.py
```

Stages 02 onward require a CUDA-capable GPU.

## Why

Building 3DGS from scratch is the cleanest way to own the pipeline before extending it with differentiable physics. The tile-based rasterizer is a direct extension of hand-written CUDA matmul kernels; the differentiable backward pass is the same chain-rule machinery as a scalar autodiff engine, applied to a rendering pipeline.
