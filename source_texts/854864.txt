Optional TriangleQuality now improves native ruled and torus grids using the placed f32 positions they will emit. It chooses valid cell diagonals and increases shared native-edge interval groups when a completed scan improves shape. Geometric accuracy remains separately bounded; adjacent faces retain the same boundary vertices.
Stacked on #193. The default accuracy-only path preserves all six benchmark mesh files byte-for-byte, with neutral-to-faster measured timings.

Geometric accuracy does not prevent long, thin triangles. Planar faces
and cylindrical strips already respond to `TriangleQuality`, but ruled
and torus grids retain accuracy-driven interval counts. Dense spline
boundaries can therefore miss a requested shape target even when their
chord error is small.

Plan optional grid refinement from the placed `f32` positions that will
be emitted. Choose a valid cell diagonal and increase shared native-edge
interval groups when a completed scan improves shape. Keep geometric
error bounds and boundary correspondence independent of that decision.

Bound planning with `max_grid_triangle_tests`, including discarded
candidates. Check storage before sampling, retain usable accuracy-driven
output when optional work stops, and report the final mesh's actual
shape. Include the new budget in compiler cache identity.

The weighted extrusion loses all 580 shape violations with one extra
ruling row. Tapered walls lose 779 violations; one existing planar-cap
violation remains visible. Accuracy-only output is byte-identical for
all six benchmark meshes.
