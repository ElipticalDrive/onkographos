Hello,
I've been experimenting with the meshToDistanceVolume function of the Python API to convert a mesh with face labels into a voxel object while retaining the face labels in the voxel map. However, I couldn't find a direct method to achieve this. Upon further exploration, I discovered that meshToDistanceVolume operates on mesh parts.
Consequently, I resorted to converting each set of face labels to face bitsets and processing the mesh part by part. While this approach produced results, there are noticeable artifacts at the transitions between face labels.
For instance, when visualizing the resulting voxel map generated from the input mesh (see screenshot below), the transitions between green and white labels appear jagged and lack the desired smoothness:
These artifacts become particularly apparent when rendering the points as a point cloud or converting the voxel map back into a mesh (see screenshots below):
For reference this is the code I ran:
```
def normalize_mesh(mesh:Mesh) -> Tuple[Mesh,np.ndarray,np.ndarray]:
    bounds = mesh.getBounds()
    b_min,b_max = bounds.min,bounds.max
    mesh.vertices -= b_min
    return mesh,b_min,b_max

def get_standard_params(b_min,b_max)->mrmesh.MeshToDistanceVolumeParams:
    params = mrmesh.MeshToDistanceVolumeParams()
    # params.signMode = mrmesh.SignDetectionMode.HoleWindingRules
    voxelSizes = mrmesh.Vector3f(0.1,0.1,0.1)
    params.voxelSize = voxelSizes
    numpy_voxelSizes = np.array([voxelSizes.x,voxelSizes.y,voxelSizes.z])
    mesh_dimentions = b_max - b_min
    dimention = (mesh_dimentions / numpy_voxelSizes).astype(int)+5
    dimention = mrmesh.Vector3i(dimention[0],dimention[1],dimention[2])
    params.dimensions = dimention
    # smoother pixels (less small holes) but pixels itself are less accurate
    params.maxDistSq = 0.03
    return params
def convert_mesh_to_voxels(mesh:Mesh):
    mesh,b_min,b_max = normalize_mesh(mesh)
    params = get_standard_params(b_min,b_max)
    mr_mesh: mrmesh.Mesh = mesh.toMrMesh()
    if mesh.faceLabels is None:
        mesh.convertPointToFaceLabels_()
    faceLabels = np.array(mesh.faceLabels)
    all_fc_lbs = getUniqueValues(faceLabels,return_zero=True)
    total_data = None
    total_labels = None
    for tooth_label in all_fc_lbs:
        faceLabel = tooth_label
        bin_faceLabels = faceLabels == faceLabel
        facebitSet = mrmeshnumpy.faceBitSetFromBools(bin_faceLabels)
        mesh_part = mrmesh.MeshPart(mr_mesh,facebitSet)
        volume = mrmesh.meshToDistanceVolume(mesh_part, params)
        npArray = mrmeshnumpy.getNumpy3Darray(volume)
        npArray[np.isnan(npArray)] = np.nanmin(npArray)
        # first iteration nothing set yet
        if total_data is None or total_labels is None:
            total_data = npArray
            total_labels = (npArray>0)*tooth_label
        else:
            mask = (npArray > total_data)&(npArray>0)
            total_data[mask] = npArray[mask]
            total_labels[mask] = tooth_label
    return total_data,total_labels
```

Hello!
meshToDistanceVolume fills voxel space with distances to the mesh, so each voxel value is closest distance to the mesh. Also, as I see you have open meshes, so you are generating Unsigned distances volume cannot be than converted back to mesh without offset (as far as all values are above zero, there is no iso transition over zero value), if you enable params.signMode = mrmesh.SignDetectionMode.HoleWindingRules you will get signed voxels.
Another issue that I see:
```
voxelSizes = mrmesh.Vector3f(0.1,0.1,0.1)
params.maxDistSq = 0.03 # maxDistance = 0.17
```
voxels further than 0.17 off surface has invalid values, it may have this effect on edges. I suggest changing this to
```
voxelSizes = mrmesh.Vector3f(0.1,0.1,0.1)
params.maxDistSq = 0.09 # 3 voxels squared 
```
To map voxel to face label you need to project voxel center to original mesh with findProjection function:
```
projection_result = mrmesh.findProjection( voxel_center_coord, mr_mesh, params.maxDistSq * 1.1 )
faceId = mr_mesh.topology.left( projection_result.mtp.e )
```
We could implement special volume that has information about closest face in each voxels, but it will require some time.
Hope it will help!
