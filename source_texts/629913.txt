Is your feature request related to a problem? Please describe.
Magicka Voxel has limits to chunk translation, or whatever the groups of voxels are called. If you voxelize using a model with larger than 1000 resolution for example, some chunks may clip to the bounds of the scene (or may even be missing entirely) which then requires manual adjustment if you want the model to look correct.
Describe the solution you'd like
One solution could be to section the VOX output into multiple different files and then define the section size and section coordinates in the file names for use.
Describe alternatives you've considered
If there's no guarantee of this being solved in the near future (because I think the solution I detailed is the most convenient for exporting very large voxel scenes), I am going to just split the .obj model itself into sections using an almost automatic process and then create a .bat file that does obj2vox on all the sections automatically.
Another solution that would be more limited is to somehow let the voxel output be centered in the VOX scene. What I mean is, it seems the VOX output always lies in the same octant in the scene (Im guessing positive on all axes), but if all 8 octants can be utilized then that would increase the size limit.
Additional context
I tried doing this myself but I can't clone the repository because it seems to me I don't have access rights to the repository or at least one of its dependencies. I'm not sure why this is happening because I am not very familiar with git
I appreciate any help whatsoever, maybe I am missing something and this modification is not required?
