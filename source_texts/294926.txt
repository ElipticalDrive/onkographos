# GPU Marching Cubes in Bevy (Main / 0.20)

A high-performance implementation of the **Marching Cubes algorithm** written in Rust using the **Bevy** game engine (targeting the main development branch / Bevy 0.20). This project leverages GPU compute shaders for parallelized voxel meshing alongside CPU readback mechanisms for precise mesh allocation.

---

---

## Core Features

* **GPU-Accelerated Voxel Meshing:** Offloads heavy volumetric data processing to the GPU using multi-pass compute shaders written in WGSL.
* **Precise Mesh Allocation via Readback:** Uses asynchronous GPU-to-CPU buffer mapping to determine exact vertex and index counts prior to allocating Bevy mesh assets, avoiding memory overhead.
* **Bevy 0.20 Compatibility:** Uses Bevy 0.20.0 features for access to wgpu
