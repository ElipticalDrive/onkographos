Objective
Automatically compile and store one bounded-complexity global overview mesh for each compiled world. The mesh will support a global 3D orientation inset without materializing the complete voxel world during replay.
This produces one final overview mesh, not a stored or runtime multi-level LOD hierarchy.
Requirements
Artifact contract
Add one optional immutable overview mesh to the compiled-world artifact.
Record schema version, mesh format/path, storage coordinate space, vertex/triangle counts, source type, generation parameters, and checksum in the manifest.
Include overview algorithm version and all output-affecting constants in compiled-world identity.
Publish and validate the overview atomically with the existing world artifact.
Keep older compiled worlds without an overview valid.
STL-derived worlds
Use the source surface mesh as overview input.
Apply exactly the same transform used during voxelization.
Simplify deterministically to the internal triangle budget when necessary.
Preserve exact alignment with storage coordinates and declared world bounds.
The replayer must not need the original STL.
Voxel-derived worlds
Build candidate coarse occupancies internally during compilation and store only the selected final mesh.
OR aggregation determines coarse-cell candidacy so thin structures remain represented.
At each candidate resolution, apply a deterministic bottom-up connected-component filter before propagating to the next coarser candidate.
Use 6-connectivity and fixed coordinate/neighbor traversal order.
Do not rely on hash-map iteration order.
Operate on sparse occupied-cell sets rather than allocating a dense world-sized grid.
Track occupied_source_voxels and represented_source_volume per coarse cell.
Keep a component when its cell count meets MIN_OVERVIEW_COMPONENT_CELLS or its source-density meets MIN_OVERVIEW_COMPONENT_DENSITY.
Extract exposed faces from the selected filtered occupancy and merge adjacent coplanar faces where practical.
Automatically select a result under a stable internal triangle budget.
Configuration boundary
Overview generation uses stable internal compiler constants with tests.
Do not add experiment, environment, training, evaluation, or replay YAML fields.
There is no YAML configuration for the replayer.
Tests
Deterministic identical output for identical inputs.
Isolated sparse noise is discarded.
A long one-cell-wide wall survives.
A small dense component survives through the density rule.
Edge- or corner-only contact remains separate under 6-connectivity.
Filtering affects subsequent coarser candidate resolutions.
STL transform alignment is preserved.
Triangle budget and integer/file bounds are enforced.
Checksum corruption and malformed overview metadata are rejected.
Older artifacts without overview metadata still load.
Non-goals
Runtime LOD selection or storing multiple overview levels.
Rendering discarded components as faint markers.
Episode overlay visualization.
Replay UI implementation.
