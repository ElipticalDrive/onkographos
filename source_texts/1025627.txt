Goal
Build the offline/startup texture generation pipeline for volumetric clouds. These textures are loaded by the GPU ray-marcher.
Textures to generate
Following clayjohn/realtime_clouds:
Weather map — 512×512 RGB:
R: coverage (multi-octave Perlin)
G: cloud type / density gradient selector
B: precipitation/erosion intensity
Perlin-Worley base shape — 128×128×128 RGBA:
R: Perlin-Worley
G/B/A: three octaves of Worley FBM
Worley erosion — 32×32×32 RGB:
Three Worley FBM octaves for high-frequency erosion.
Curl noise — 128×128 RGB (optional for Phase 1, can stub with zero).
Where to put it
crates/aether-engine/src/clouds/texture_gen.rs — CPU generation functions.
crates/aether-engine/src/clouds/mod.rs — module entry.
Generated textures written to tests/output/clouds/phase0/ as PNG/TGA/RGBA raw for inspection, and also uploaded to GPU as wgpu::Texture at runtime.
Tests (TDD)
Each texture generator produces non-empty, non-NaN data.
2D slices are saved and visually inspected.
GPU upload succeeds (use headless device in tests).
Texture dimensions match requested quality preset.
Acceptance criteria
cargo test -p aether-engine --lib passes.
Launcher can generate and upload all required textures without panic.
Files exist under tests/output/clouds/phase0/.
Depends on
