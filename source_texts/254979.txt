One small supplied-row TreeLayer garden: eight species, seasons, crown spread, wind, attached/fallen crops, lighting and owner picking. Uses public APIs and runs standalone or on the website.
The demo is 176 lines; the PR includes one rendering/controls/cleanup regression, minimal wiring/docs, and the existing private-hook schema-test correction. No comparison renderer, film, benchmark reports or large forest example.
Validation: root Yarn install/build/lint, strict API and demo type checks, website install/build, 2,018 Node tests, 38 first-party example tests, and the demo plus WebGL2/WebGPU TreeLayer rendering tests.
Stack: #808 → #809 (three removal) → #814 (scenes) → #815 (Coit) → #806 (streaming/World).
Note
Medium Risk
Changes core splat compositing and per-frame CPU/GPU sorting with extra framebuffer memory; TreeLayer canopy and wood LOD behavior change visibly for existing users.
Overview
Adds globally depth-sorted prepared Gaussian rendering to SplatLayer via transparency: 'sorted', replacing the previous hard error. SplatEffect collects eligible primitives, SplatSortedRenderer packs selected splats into a shared working buffer, sorts centers each frame (with wind/transforms), batches compatible draws, and composites the sorted target over the existing weighted accumulation pass.
TreeLayer switches canopy sublayers to sorted transparency and tightens woody LOD: near/far pick a single opaque mesh (no cross-skeleton dithering), with coarse banyan shells keeping aerial/stilt roots.
Also ships the TreeLayer garden demo (examples/layers/tree-lab) with species/season/crop/wind controls, website sidebar entry, and browser/regression tests (rendering, sorted batching, depth order, wood solidity, coverage fades). Docs and whats-new reflect sorted mode and the demo; playground registry tests skip host-owned _ default props.
