Why
Kinks at the nodes. The travel time at an event was the bilinear (2D) or trilinear (3D) interpolation of the eikonal table. That time is piecewise linear, with a kink at every node, where L-BFGS stops. In ADLoc and GaMMA, 19–38% of the event depths sat on a 0.3 km node (3% if uniform).
Outside the grid. The position was clamped, so the time stayed constant, while a pass-through clamp still gave a nonzero gradient. The gradient was therefore not the derivative of the time there.
What
adtomo/interp.py: one Catmull-Rom interpolation for 2D and 3D. Both models use it, and so do interp2d and interp3d (the examples' synthetic picks), so the synthetic data and the inversion share one forward model. The time and its derivatives are continuous across the nodes.
Outside the grid the time continues linearly from the nearest grid point c with the slope there: T(c) + grad T(c) · (x − c). Autograd gives its exact gradient, including the cross terms where c slides along a face. The gradient is continuous across the edge and never zero, so an event pushed outside is pulled back. The code comments explain each case.
The pass-through Clamp is gone.
The same lookup goes into GaMMA (Version 1.14.0: bicubic travel-time lookup, smooth across the table nodes GaMMA#80) and ADLoc (Version 1.1.0: global frames as GaMMA's, top at each event's highest station; bicubic travel times, four start depths ADLoc#8).
Checks
tests/test_interp.py (new):
gradcheck w.r.t. the table and the position, inside the grid and beyond every edge and corner, in 2D and 3D;
quadratic tables reproduced exactly;
gradient continuous across nodes and edges;
gradcheck through the eikonal op w.r.t. slowness and event position.
All 9 tests pass.
examples/layered2d.py, main → this branch: data misfit 0.759 → 0.758, Vs RMS error 0.061 → 0.055 km/s, Vp/Vs 1.7315 (true 1.73), 77 → 72 evaluations.
