# sml-bvh

[![CI](https://github.com/sjqtentacles/sml-bvh/actions/workflows/ci.yml/badge.svg)](https://github.com/sjqtentacles/sml-bvh/actions/workflows/ci.yml)

A **bounding-volume hierarchy (BVH)** for Standard ML: 3D axis-aligned bounding
box (AABB) primitives, ray/box intersection via the slab method (returning the
entry parameter `t`), and a real BVH tree with median-split construction, ray
traversal, and nearest-neighbour queries.

## API

```sml
type vec3 = real * real * real
type ray  = { origin : vec3, dir : vec3 }
type box  = { min : vec3, max : vec3 }

(* box primitives *)
val boxOfPoints   : vec3 list -> box
val merge         : box * box -> box
val boxCenter     : box -> vec3
val surfaceArea   : box -> real
val containsPoint : box -> vec3 -> bool

(* ray/box intersection *)
val hitBox  : box -> ray -> real option   (* SOME entry-t, 0 if origin inside *)
val hitAABB : (real * real) -> ray -> bool
val hitCube : ray -> bool                 (* the [-1,1]^3 cube *)

(* objects + tree *)
type 'a obj  = { id : 'a, bounds : box }
val boundsOf   : 'a obj -> box
type 'a tree
val build      : 'a obj list -> 'a tree
val treeBounds : 'a tree -> box
val depth      : 'a tree -> int
val count      : 'a tree -> int
val traverse   : 'a tree -> ray -> 'a list   (* ids whose box the ray hits *)
val nearest    : 'a tree -> vec3 -> 'a option
```

## Examples

```sml
fun cubeAt (id, (x,y,z)) =
  { id = id, bounds = { min=(x-0.5,y-0.5,z-0.5), max=(x+0.5,y+0.5,z+0.5) } }

val tree = Bvh.build (List.map cubeAt
             [(0,(0.0,0.0,0.0)), (1,(5.0,0.0,0.0)), (2,(0.0,5.0,0.0))])

(* which objects does this ray hit? *)
val hits = Bvh.traverse tree { origin=(~10.0,0.0,0.0), dir=(1.0,0.0,0.0) }

(* closest object to a point *)
val near = Bvh.nearest tree (4.9, 0.2, 0.0)   (* SOME 1 *)
```

## Example

`make example` builds and runs [`examples/demo.sml`](examples/demo.sml), which
builds a BVH over five boxes and exercises box math, ray traversal, nearest-
neighbour query, and single-box ray hit-testing (output is byte-identical
under MLton and Poly/ML):

```
count = 5
depth = 4
treeBounds: min=(0.00, 0.00, 0.00) max=(11.00, 11.00, 11.00)
boxOfPoints: min=(0.00, ~2.00, 0.00) max=(3.00, 4.00, 5.00)
surfaceArea(obj1) = 6.00
traverse hits: [1,2]
nearest to (5.50, 0.50, 0.90) = 2
hitBox(obj2, ray2) t = 5.00
```

## How it works

- `hitBox` intersects the ray with each of the three coordinate slabs, keeps the
  overlapping `[tmin, tmax]` interval, and returns the entry parameter (clamped
  to `0.0` when the origin is inside). Rays parallel to an axis are handled by
  the degenerate-slab check, so **direction matters** — a ray aimed away from
  the box misses.
- `build` recursively splits objects at the **median** along the longest axis of
  the centroid spread, producing a binary tree of nodes (interior boxes) and
  leaves (single objects).
- `traverse` prunes whole subtrees whose box the ray misses.
- `nearest` does a best-first-ish descent with box lower-bound pruning
  (`boxDist2`), comparing against object centers.

## Scope and limitations

- Split heuristic is a simple median split, not the full surface-area heuristic
  (SAH); good enough for moderate scenes, not tuned for production ray tracing.
- `nearest` compares to box **centers**, not the closest surface point of each
  object.
- `traverse` returns objects whose **bounding box** the ray hits; it does not
  test the underlying geometry or return hit distances/normals.
- Boxes are inclusive on both bounds; degenerate (zero-volume) boxes are allowed.

## Installing with smlpkg

```sh
smlpkg add github.com/sjqtentacles/sml-bvh
smlpkg sync
```

Reference from your `.mlb`:

```
lib/github.com/sjqtentacles/sml-bvh/bvh.mlb
```

## Building and testing

```sh
make test        # MLton
make test-poly   # Poly/ML
make all-tests   # both
make clean
```
