Rough planar reflections and rough refraction sample the small mip levels of a rendered texture, where the box filter shows blocks that flicker as the camera moves. This adds a Gaussian mipmap filter for textures whose mipmaps are generated from rendered content, uses it for planar reflections, and lets the scene color map opt into it. Planar reflections also sample their blurred levels with a bicubic filter.
Changes:
New mipmap filters for the mipmaps the GPU generates from content rendered to a texture, such as a render target with mipmaps. MIPMAPFILTER_GAUSSIAN approximates a Gaussian blur with 13 bilinear taps per texel of the previous level, on WebGL2 and WebGPU. It applies to 2D textures of formats that can be filtered; cubemaps, texture arrays, volume textures and mipmaps generated for uploaded data keep the box filter.
The scene color map of a camera (the grab pass used by dynamic refraction) can use the Gaussian filter, or skip mipmaps entirely where only sharp refraction is needed.
PlanarRenderer generates its mipmaps with the Gaussian filter by default, and copies the jitter of the scene camera, so its TAA antialiases the reflection as well.
Planar reflections sample the blurred mip levels with a bicubic B-spline, which removes the visible texels where a small mip level covers many pixels. The sharp top level is still sampled with a single bilinear tap, so mirror reflections keep their cost and sharpness. The level of detail is clamped to the levels the texture has, so reflection textures without mipmaps no longer sample levels which do not exist.
API Changes:
New constants MIPMAPFILTER_BOX (default) and MIPMAPFILTER_GAUSSIAN.
New Texture option and property mipmapFilter:
```
const texture = new Texture(device, {
    width: 1024,
    height: 1024,
    format: PIXELFORMAT_RGBA16F,
    mipmaps: true,
    mipmapFilter: MIPMAPFILTER_GAUSSIAN
});
```
New CameraComponent#sceneColorMapMipmapFilter (defaults to MIPMAPFILTER_BOX) and CameraComponent#sceneColorMapMipmaps (defaults to true):
```
// smoother rough refraction
entity.camera.sceneColorMapMipmapFilter = MIPMAPFILTER_GAUSSIAN;

// sharp refraction only, without generating mipmaps each frame
entity.camera.sceneColorMapMipmaps = false;
```
New PlanarRenderer script attribute mipmapFilter, 'box' or 'gaussian', defaulting to 'gaussian'.
Examples:
shaders/grab-pass redesigned: a frosted rounded glass cube in a full resolution street skydome, with the shapes behind it rising to be seen through it, and a toggle of the Gaussian mipmaps of the scene color map.
Performance:
Generating Gaussian mipmaps costs more than the box filter. On WebGL each level is rendered to a scratch texture and copied into the level, as a texture cannot be rendered to while it is sampled.
Rough planar reflections sample 4 to 8 texels instead of one. Mirror reflections are unchanged.
sceneColorMapMipmaps = false saves generating the mipmaps of the scene color map each frame, and about a third of its memory.

[P2] Flush pending sampler state before applying these overrides
The previous generate() leaves the sampling-property flags dirty via texture.propertyChanged(...). If the render target is rendered again before the texture is sampled elsewhere, device.draw() below calls setTexture(), which applies those pending properties and overwrites these temporary settings during the Gaussian pass. FILTER_LINEAR then reads level 0 instead of the previous mip, nearest filtering loses the bilinear taps, and repeat wrapping contaminates the edges. Reproduced by drawing identical content twice into a 16×16 RGBA8 Gaussian target with FILTER_LINEAR and clamp addressing: the last mip changes from [60,98,128,255] to [0,96,128,255], despite unchanged level 0. WebGPU stays unchanged, and flushing the pending parameters before generation restores the expected result. Apply pending texture state before these overrides, or isolate the generator's sampler so its own draw cannot replace them.

[P2] Refresh the mip limit when the reflection texture is resized
This uniform is refreshed only when the material is updated, but RenderTarget.resize() can change the same texture's numLevels without changing any material property. A stationary reflection target enlarged from 32×32 to 256×256 therefore keeps planarReflectionMaxLevel = 5 although the new maximum is 8, so rough reflections remain clamped to an unnecessarily sharp mip. Reproduced on both WebGL2 and WebGPU: after resizing and rendering the new texture, a zero-gloss reflection pixel is [86,59,128,255]; calling material.update() alone refreshes the limit to 8 and produces [61,99,128,255]. The previous shader obtained the limit from the texture dimensions and did not require a material update after resizing. Keep this derived uniform synchronized with texture mip-count changes rather than only material changes.

[P2] Preserve the explicit mip-count limit for shortened reflection chains
Deriving the maximum solely from dimensions assumes a full mip chain, but Texture({ width: 32, height: 32, numLevels: 4, mipmapFilter: MIPMAPFILTER_GAUSSIAN }) only regenerates levels 1–3. This calculation allows a zero-gloss reflection to sample level 5 instead. On WebGL that higher level was populated by the generator's one-time gl.generateMipmap() allocation and is never refreshed by subsequent Gaussian generations, so the reflection can freeze on old content. Reproduced by rendering a pattern and then solid red into that target: level 3 reads [255,0,0,255], but the reflection remains [64,96,128,255] from the pattern; WebGPU correctly changes to red. The previous numLevels - 1 clamp avoided this. Retain the actual/configured mip-count cap while allowing the dimension-derived limit to follow resizing, and add a shortened-chain redraw regression test.
