음... 걍 잘 모르겠어서 빠르게 날로 먹기 위해 서베이 논문을 찾음.
NeRF: Neural Radiance Field in 3D Vision, A Comprehensive Review (TPAMI 2022)
이 서베이 논문에 포함된 범위는 CVPR 2022, 그니까 2022년 6월까지의 내용을 담고 있다고함.
NeRF 첫 논문: ECCV 2020, Mildenhall et al.
xyz랑 viewing direction (theta, pi. 구면좌표계에 r=1, 나머지 수직,수평 각도) 을 넣으면 RGB와 density를 맞추도록 하는데, 이걸 MLP가지고 implicit하게 neural scene representation 배우도록 구현하는 아이디어를 냈음. 그니까 5차원 함수.
근데 3D Cartesian unit vector로 표현해서 (d_x, d_y, d_z)로 표기하기도함. 암튼 scene을 구성하는 것들은 밀도는 어디서 봐도 일정하겠지만 RGB는 보는곳에 따라 다르다는 특징이 있음. 그래서 xyz로 밀도 먼저 추정하고, 그담에 viewing direction을 같이 넣어서 RGB를 추정하게함. 암튼 카메라 위치에서부터 ray를 쏘고... 포인트 샘플링하고... 각 점의 밀도에 따라 해당 포인트의 중요도가 다른거니까 가중치합 구하면 새로운 viewpoint에서 특정 픽셀의 컬러가 나온다는거 쓰기 귀찮으니까 설명 넘어감. positional encoding... 대충 푸리에변환 생각할게요 쨌든 패스 귀찮아
NeRF 왜이리 인기가 많나요
self-supervised 라서. 3D, depth supervision 없어도 된다는 장점. 걍 이미지랑 pose만 알면 됨
근데 그 pose는 COLMAP같은 SfM 패키지를 통해서 추정할 수 있음.
photo-realistic함. NeRF 나오기 전에는 light field 키워드로 논문들 나오고 그랬었는데, NeRF original paper조차 얘네보다도 성능이 더 좋았다고함.
뭔 2년동안 인기가 이렇게 미친거임?
아카이브에 올라온 것만 거의 200편인데, 결국 이것들이 CVPR ICCV ECCV에 2021, 2022년에 게재되었음.
심지어 CVPR 2022년? NeRF 논문만 50편이 넘음
NeRF original paper가 2020년이라면서요. 벌써 1800번 인용됨
데이터셋, 평가 metric 등등 section2에 설명 되어있으니 넘어감

3.8.2 Human Body
사람 다루는거야 다른것들도 많은데 Neural Body를 적용한 NeRF에 해당하는 논문은 이 섹션에서 다룸. (위에 다섯개)
Input video를 통해 버텍스 기반 변형 가능한 인체 모델(SMPL)을 고정함.
각 vertex에 16차원 latent code Z를 둠. 이건 걍... 저자들이 넣은거임.
글고 Human pose parameter S(처음에는 학습중에 비디오에서 추정, 인퍼런스때 입력 가능)를 인체 모델을 변형하는 데 사용함. 이 모델은 grid로 voxelized 되어서 3D CNN 적용해서, 각 voxel에 대해 128차원 latent feature 뽑음. 모든 3D point는 SMPL 좌표계로 변환되면 interpolation을 통해서 128차원의 latent code phi가 뽑힘. 이걸 density MLP에 넣는대. color MLP는 density MLP 거친 것과 함꼐 positional encoding된 3차원 좌표, viewing direction, appearance latent code l_t (비디오에서 per frame difference를 고려하기 위함)를 입력으로 받음.
암튼 일반 NeRF는 움직이는 사람 배우는건 어려웠는데, 이렇게 Neural Body의 mesh deformation 기반의 방법으로 하니까 pose 및 frame간의 interpolation이 가능해졌음. 위에 5편의 논문 고른게 SOTA라고함
근데 NeuMan이 없네. 이 논문이 인용하고 있는것들 더 뽑아오면 되겠다
