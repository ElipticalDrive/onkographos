# 3DGS-Decimate

A Python implementation of radius-based spatial thinning and merging for 3D Gaussian Splatting (3DGS) data. Reduces Gaussian count while preserving visual quality through intelligent weighted merging.

![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)
![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)

## Features

- **Radius-based spatial thinning** — Merge nearby Gaussians using spatial distance constraints
- **Hash grid acceleration** — O(N log N) time complexity, suitable for million-scale datasets
- **Quality-preserving merges** — Weighted aggregation of position, color, opacity, scale, and rotation
- **Similarity filtering** — Only merge Gaussians with similar appearance (color/orientation)
- **Importance protection** — Preserve the most visually important Gaussians
- **Numerically stable** — No covariance decomposition or KL-divergence computation

```bash
pip install numpy plyfile
```

Or using the requirements file:

```bash
pip install -r requirements.txt
```

## Quick Start

```bash
# Auto-detect radius (recommended for unknown scenes)
python decimate.py input.ply output.ply --auto

# Manual radius for fine-tuning
python decimate.py input.ply output.ply --radius 0.01

# High quality preset
python decimate.py input.ply output.ply -r 0.005 -s 0.7 -m 4 -p 15 -v

# Aggressive compression
python decimate.py input.ply output.ply -r 0.02 -s 0.3 -m 12 -p 5
```

## Parameters

| Flag | Name | Default | Description |
|------|------|---------|-------------|
| `-a` | `--auto` | false | Auto-detect radius based on scene scale (recommended) |
| | `--auto-factor` | 2.0 | Multiplier for auto-radius. Higher = more aggressive |
| `-r` | `--radius` | 0.01 | Manual radius threshold. Larger = more aggressive merging |
| `-k` | `--scale-bound` | 2.0 | Scale inflation limit. Lower = less blurring |
| `-s` | `--similarity` | 0.5 | Similarity threshold (0-1). Higher = only merge very similar Gaussians |
| `-m` | `--max-merge` | 8 | Max Gaussians merged at once. Lower = finer detail preservation |
| `-p` | `--protect` | 10.0 | Protect top N% important Gaussians from merging |
| `-v` | `--verbose` | false | Print detailed progress |
| `-q` | `--quiet` | false | Suppress all output |
