# Neural Texture Compression

A deep learning system for compressing textures used in real-time rendering. Uses a convolutional autoencoder trained with perceptual loss functions to achieve high compression ratios while preserving visual quality.

![Dashboard](https://img.shields.io/badge/GUI-Flask_Dashboard-8b5cf6) ![PyTorch](https://img.shields.io/badge/Framework-PyTorch-ee4c2c) ![Python](https://img.shields.io/badge/Python-3.10+-3776ab)

## Features

- **Convolutional Autoencoder** — 4-block encoder/decoder with 24× baseline compression (256×256×3 → 16×16×32)
- **Perceptual Loss** — VGG-16 feature matching + SSIM + MSE combined loss
- **Advanced Upgrades** — VAE mode, U-Net skip connections, spatial attention gates
- **Baseline Comparison** — Benchmarks against JPEG and PNG at matched compression ratios
- **Web Dashboard** — Premium dark-mode GUI for uploading, compressing, and comparing textures

## Quick Start

```bash
# Clone
git clone https://github.com/<your-username>/neural-texture-compression.git
cd neural-texture-compression

# Install
pip install -r requirements.txt

# Generate training data (or use your own textures)
python data/generate_procedural.py --num 500

# Train
python run_train.py --data-dir data/processed/procedural --max-epochs 30

# Evaluate
python run_eval.py --visualize

# Launch GUI
python gui/app.py
# → open http://localhost:5050
```

## Architecture

```
Input (256×256×3)
  ↓ Conv2d(stride=2) + BN + ReLU  ×4
Bottleneck (16×16×32)  ← 24× compression
  ↓ ConvTranspose2d(stride=2) + BN + ReLU  ×4
Output (256×256×3)
```

**Optional upgrades** (enabled via CLI flags):
- `--use-vae` — Variational bottleneck with reparameterization trick
- `--use-skip` — U-Net skip connections from encoder to decoder
- `--use-attention` — Spatial attention gates in the decoder

## Training on Custom Data

Place your texture images (PNG/JPG) in any folder and point the trainer at it:

```bash
python run_train.py --data-dir path/to/your/textures --max-epochs 100
```

For the [DTD dataset](https://www.robots.ox.ac.uk/~vgg/data/dtd/) (5,640 textures):

```bash
python run_train.py --data-dir dtd/images --max-epochs 30
```

## Loss Function

| Term | Weight | Purpose |
|------|--------|---------|
| MSE | λ₁ = 1.0 | Pixel-level reconstruction |
| Perceptual (VGG) | λ₂ = 0.1 | Texture sharpness via feature matching |
| 1 - SSIM | λ₃ = 0.5 | Structural similarity |
| KL Divergence | λ₄ = 0.0001 | VAE regularization (optional) |
