## 3D Gaussian Splatting Data Compression via Adaptive Residual Quantization and Error Compensation

Chenyang Zhao1 , Yang Zhou1\*, Xiaofeng Huang1 , Haibing Yin1

1\*School of Communication Engineering, Hangzhou Dianzi University, Hangzhou, 310018, China.

\*Corresponding author(s). E-mail(s): zhouyang@hdu.edu.cn;

#### Abstract

3D Gaussian Splatting (3DGS) enables high-fidelity novel-view synthesis with real-time rendering, but high-quality scenes require many Gaussian primitives, incurring substantial storage overhead. Anchor-based representations reduce storage, yet high-dimensional anchor features remain a storage bottleneck, and their quantization errors can propagate through attribute prediction. Fixeddepth quantization cannot adapt to different rate–distortion requirements across anchors, while nearest-neighbor index assignment ignores coding costs. To address these limitations, we present a 3DGS compression framework based on Adaptive Residual Quantization and Error Compensation (ARQEC). We encode anchor features with three-stage residual vector quantization (RVQ) and adaptively select the quantization depth for each anchor. A Context Refiner uses spatial hash-grid context to compensate for feature residuals remaining after RVQ. An Attribute Adapter further refines the quantized offsets and scaling based on the recovered features, reducing the impact of quantization errors on Gaussian attribute prediction. Finally, a contextual entropy model estimates conditional code lengths for quantization depth and RVQ index symbols. A local rate–distortion criterion generates candidate assignments, followed by rendering-based calibration on held-out views. Extensive experiments on Mip-NeRF 360, Tanks and Temples, and Deep Blending show that our method achieves 47×–157× full-model compression over vanilla 3DGS while maintaining high rendering quality. Compared with Hash-grid Assisted Context (HAC), it achieves up to 1.53× additional compression in full-model size, yielding a competitive trade-off between model compactness and rendering fidelity.

Keywords: 3D Gaussian Splatting, anchor feature compression, residual vector quantization, spatial context refinement, rate–distortion optimization

#### 1 Introduction

Novel-view synthesis aims to render high-quality images from novel viewpoints given a set of input views, enabling applications in digital twins, immersive media, virtual reality, and 3D content creation. Neural Radiance Fields (NeRFs) [1] have greatly advanced novel-view synthesis, while subsequent work [2] has improved training and rendering efficiency by adopting more efficient scene representations. More recently, 3D Gaussian Splatting (3DGS) [3] represents scenes with explicit anisotropic Gaussian primitives and achieves high-quality real-time rendering. However, high-quality scenes often require millions of Gaussians and their associated attributes, resulting in substantial storage overhead. Existing 3DGS compression methods mainly reduce the number of Gaussians through pruning [4–6], reduce parameter precision through low-bit or codebook quantization [7–10], or further reduce storage through contextual entropy coding [11–13]. Scaffold-GS [14] introduces an anchor-based representation that groups nearby Gaussians and predicts their attributes from anchor features, providing a compact foundation for anchor-level compression. Building on Scaffold-GS, Hash-grid Assisted Context (HAC) [11] and ContextGS [12] exploit spatial or hierarchical context among anchors for more compact representations, while CompGS [7] demonstrates the effectiveness of vector quantization for Gaussian compression. SCAR-GS [15] further applies multi-stage residual vector quantization (RVQ) to anchor feature compression. However, assigning the same quantization depth to all anchors may introduce unnecessary coding costs, as the distortion reduction from an additional RVQ stage varies across anchors. Moreover, nearest-neighbor index assignment based only on Euclidean distance ignores context-dependent coding costs. These limitations motivate per-anchor depth allocation and index selection based on both distortion and coding cost.

Quantization introduces another challenge because errors in high-dimensional anchor features can affect the Gaussian attributes predicted from them, including color, opacity, scale, and rotation. Moreover, the anchor features, offsets, and scaling are quantized separately. As a result, the recovered features may no longer be well matched with the independently quantized offsets and scaling, which can further degrade rendering quality. The spatial dependencies exploited by context-based compression methods [11, 12] further suggest that spatial context can be used to compensate for feature residuals remaining after RVQ. However, reconstruction errors measured in feature or attribute space do not necessarily reflect the resulting rendering distortion, since the contribution of each Gaussian to the final image also depends on visibility and alpha compositing with other Gaussians. Therefore, compression decisions should ultimately be evaluated using rendering distortion in the image domain.

To address these challenges, we propose a 3DGS compression framework for anchorbased 3DGS representations that integrates Adaptive Residual vector Quantization, context-guided Error Compensation, and rendering-calibrated rate–distortion optimization, which we name ARQEC. Specifically, we adaptively select the quantization depth for each anchor according to the distortion reduction and coding cost. We further exploit spatial context to compensate for feature residuals after RVQ and refine the quantized offsets and scaling based on the recovered anchor features. Finally, we estimate the coding costs of quantization depth and RVQ index symbols with a contextual entropy model and calibrate candidate assignments through rendering on held-out views.

Our main contributions are summarized as follows:

- 1. We introduce per-anchor adaptive RVQ for high-dimensional anchor features, allowing different anchors to use different quantization depths according to their distortion reduction and coding cost. This avoids unnecessary RVQ index costs introduced by fixed-depth quantization.
- 2. We propose a quantization error compensation mechanism that uses spatial context to improve anchor feature reconstruction and refines the quantized offsets and scaling based on the recovered features, reducing the impact of quantization errors on Gaussian attribute prediction.
- 3. We formulate a rendering-calibrated rate–distortion strategy for RVQ index and depth selection, combining coding-cost-aware candidate selection with imagedomain rendering calibration.
- 4. Extensive experiments on Mip-NeRF 360, Tanks and Temples, and Deep Blending demonstrate that our method achieves approximately 47×–157× full-model compression over vanilla 3DGS while maintaining high rendering quality, and achieves approximately 1.22×–1.53× additional full-model compression relative to HAC.

The remainder of this paper is organized as follows: Sect. 2 reviews related work on 3DGS compression, anchor context, and discrete quantization; Sect. 3 presents the proposed method; Sect. 4 reports the experimental results and ablation studies; and Sect. 5 concludes the paper.

## 2 Related Work

#### 2.1 3DGS Compression and Post-Training Compression

Existing 3DGS compression methods mainly reduce storage by pruning redundant Gaussians, quantizing Gaussian attributes, or introducing more compact scene representations. Compact 3D Gaussian Representation [8] and Compressed 3DGS [9] combine pruning with quantization and compact attribute representations. Light-Gaussian [4] and Trimming the Fat [5] reduce the number of Gaussians through importance-based pruning, while ELMGS [16] and Reducing the Memory Footprint of 3D Gaussian Splatting [6] further reduce the storage of Gaussian attributes. Other methods improve representation efficiency through more effective sparsification [17– 19]. SizeGS [20] further searches for compression configurations under a prescribed model-size budget.

Another line of work focuses on compressing already trained 3DGS models. MesonGS [21] applies attribute transformation and quantization to pretrained Gaussian representations. FlexGaussian [22] combines attribute-aware pruning with mixedprecision quantization in a training-free setting, while MesonGS++ [23] searches for effective post-training compression configurations. These methods enable additional compression without retraining the scene representation from scratch. Our method also operates on a pretrained model, but focuses on further compressing the highdimensional anchor features of an anchor-based representation. In particular, we use adaptive residual quantization together with quantization error compensation to reduce feature storage while preserving rendering quality.

#### 2.2 Anchor Context, Feature Prediction, and Entropy Models

Scaffold-GS [14] introduces an anchor-based representation that groups nearby Gaussians and predicts their attributes from anchor features, providing a compact representation for subsequent anchor-level compression. Building on this representation, HAC [11] uses hash-grid features as spatial context to model the distributions of anchor attributes for entropy coding, while ContextGS [12] exploits dependencies among anchors by predicting finer-level anchors from already decoded coarser-level anchors. Other methods further improve context modeling and entropy coding for 3DGS. End-to-End Rate-Distortion Optimized 3D Gaussian Representation [13] jointly optimizes attribute probability models and rendering quality, while HAC++ [24] extends context modeling to both inter- and intra-anchor redundancy. CAT-3DGS [25] and TC-GS [26] explore tri-plane-based context for Gaussian compression. Other works improve entropy modeling through mixture-based probability models or hierarchical transforms [27–30].

Beyond entropy modeling, contextual information and learned priors have also been explored for feature prediction and reconstruction. FP-GS [31] and SC-GS [32] use spatial information to improve feature prediction, while FCGS [33] explores feed-forward 3DGS compression with contextual prediction. Learned Image Prior [34] further introduces a learned image prior to improve reconstruction under strong compression. These studies demonstrate that context can be used not only to improve entropy coding but also to predict information useful for reconstruction. Our method follows this latter direction by using spatial context to compensate for feature residuals remaining after RVQ, while further reducing the effect of feature quantization errors on Gaussian attribute prediction.

#### 2.3 Vector Quantization and Residual Representations

Vector quantization (VQ) represents continuous features with entries from a finite codebook and stores the corresponding codebook indices instead of the original highdimensional values. VQ-VAE [35] established a widely used framework for learning such discrete representations. In 3DGS compression, CompGS [7] applies vector quantization to Gaussian parameters and stores compact codebooks together with their assignment indices. Other works further explore vector quantization for compact Gaussian representations, including the independently developed CompGS [10], NSVQ [36], and ContraGS [37].

Residual vector quantization (RVQ) extends VQ by successively quantizing the residual left by preceding stages, allowing the reconstruction to be progressively refined with additional codewords. SCAR-GS [15] applies multi-stage RVQ to anchor feature compression in a progressive setting. In contrast to using the same number of RVQ stages for all anchors, our method adaptively selects the quantization depth for each anchor according to its distortion reduction and coding cost, avoiding unnecessary RVQ indices when additional stages provide limited benefit.

#### 2.4 Scalable and Codec-Based Compression

Progressive and scalable compression provides multiple reconstruction levels to accommodate different storage or transmission requirements. PCGS [38] develops a progressive bitstream for 3DGS, while GoDe [39] enables scalable scene representations through progressive levels of detail. These methods allow reconstruction quality to improve as additional information is decoded.

Another direction reorganizes Gaussian attributes or features into structured representations that can be compressed using established coding schemes. Representative approaches explore video-, point-cloud-, image-, or voxel-based representations for 3DGS compression [40–43]. By converting irregular Gaussian data into more regular structures, these methods facilitate the use of existing coding tools for compact storage and transmission. In contrast to progressive methods that provide multiple reconstruction levels, our method produces a single compressed anchor representation, with the RVQ depth determined separately for each anchor.

## 3 Method

As illustrated in Figure 1, our ARQEC compresses the high-dimensional anchor features of a pretrained anchor-based 3DGS representation. The framework consists of three stages. First, the anchor features are encoded using three-stage residual vector quantization, with the quantization depth selected separately for each anchor. Second, the Context Refiner compensates for feature residuals remaining after RVQ, and the Attribute Adapter refines the quantized offsets and scaling based on the recovered features. Third, a contextual entropy model estimates the conditional code lengths of the quantization depth and RVQ index symbols. A local rate–distortion search generates candidate index and depth assignments, which are further calibrated by rendering on held-out views before entropy coding.

For anchor i, we collect its attributes as

$$\mathcal{A}_i = \{\mathbf{x}_i, \mathbf{f}_i^{Tea}, \mathbf{s}_i^{Tea}, \mathbf{O}_i^{Tea}\}, \quad i \in \{1, \dots, N_a\}, \quad (1)$$

where xi ∈ R 3 is the anchor center, f T ea i ∈ R Df is the anchor feature before quantization, and Df denotes the feature dimension. The scaling is s T ea i ∈ R 6 , while OT ea i ∈ R K×3 contains K local offsets. The total number of anchors is denoted by Na. The superscripts T ea and Stu denote the pre-quantization teacher state and the compressed student state, respectively.

Our method primarily compresses the high-dimensional anchor feature f T ea i . The scaling s T ea i and offsets OT ea i follow the HAC [11] quantization pathway, producing sei and Oei , respectively. A tilde, e·, denotes a state quantized and decoded by the base quantizer, whereas a hat,b·, denotes a state that has been further recovered or adapted. The anchor position is unchanged during compression and is therefore denoted by xi throughout the following derivation.

## 3.1 Three-Stage RVQ and Per-Anchor Adaptive Depth

Given an anchor feature f T ea i , RVQ proceeds through three residual stages, starting from

$$\mathbf{r}_i^{(0)} = \mathbf{f}_i^{Tea}. \quad (2)$$

At stage l ∈ {1, 2, 3}, the nearest-neighbor index is obtained as

$$z_{i,\text{NN}}^{(l)} = \arg \min_{k \in \{1, \dots, M_l\}} \left\| \mathbf{r}_i^{(l-1)} - \mathbf{C}^{(l)}[k] \right\|_2^2, \quad (3)$$

where C(l) ∈ RMl×Df is the codebook at stage l, and Ml is the number of codewords. We initialize z (l) i with z (l) i,NN; the index may later be reselected by the rate–distortion search.

Codebook lookup with the selected index yields

$$\mathbf{q}_i^{(l)} = \mathbf{C}^{(l)} \begin{bmatrix} z_i^{(l)} \end{bmatrix}, \quad (4)$$

after which the residual is updated recursively as

$$\mathbf{r}_i^{(t)} = \mathbf{r}_i^{(t-1)} - \mathbf{q}_i^{(t)}. \quad (5)$$

The distortion reduction provided by an additional RVQ stage varies across anchors. We therefore assign each anchor a quantization depth di ∈ {1, 2, 3}. We encode the activation of stage l with the binary mask

$$m_i^{(i)} = \mathbb{I}[d_i \geq l], \quad (6)$$

where I[·] is the indicator function and m (l) i specifies whether stage l is active. The resulting RVQ reconstruction at depth di can be written as

$$\mathcal{f}_i^{RVQ}(d_i) = \sum_{l=1}^3 m_i^{(l)} \mathcal{C}^{(l)} \left[ z_i^{(l)} \right]. \quad (7)$$

Thus, di = 1, 2, or 3 uses the first one, two, or three RVQ codewords, respectively. Indices from inactive stages are not encoded and therefore incur no index code length. The depth symbol is encoded before the RVQ indices so that the decoder knows how many indices to read for each anchor.

#### 3.2 Context-Guided Feature Recovery and Attribute Adaptation

The Context Refiner reuses the spatial hash grid of the pretrained HAC representation. The spatial context at anchor i is interpolated from the hash grid according to

$$h_i = \text{Interp}(\mathbf{x}_i, \mathcal{H}), \quad (8)$$

where H is the decoded spatial hash grid shared by all anchors. The context feature hi is computed at the decoder and introduces no additional per-anchor storage.

The concatenated input to the Context Refiner takes the form

---

$$\mathbf{u}_i = \left[ m_i^{(1)} \mathbf{q}_i^{(1)}, m_i^{(2)} \mathbf{q}_i^{(2)}, m_i^{(3)} \mathbf{q}_i^{(3)}, \mathbf{h}_i, \mathbf{e}(d_i) \right], \quad (9)$$

where e(di) is the embedding of the selected RVQ depth.

The symbol σ(·) denotes the sigmoid function, ⊙ denotes element-wise multiplication, and βf bounds the correction magnitude. #### 3.3.1 Local rate–distortion cost

Coding cost alone favors high-probability symbols, whereas Euclidean distance only measures RVQ reconstruction error in feature space. We therefore evaluate each candidate (d, z) using the recovered feature and the adapted offsets and scaling.

For the teacher representation, we define s anchor,T ea i = ActScale(s T ea i ) and S pos,T ea i = 1K(s anchor,T ea i,1:3 ) T.

We quantify the feature reconstruction error with

$$E_i^f(d, \mathbf{z}) = \frac{1}{D_f} \left\| \mathbf{f}_i^{Tea} - \hat{\mathbf{f}}_i^{Stu}(d, \mathbf{z}) \right\|_1, \quad (16)$$

normalize the offset error by positional scale using


$$E_i^O(d, \mathbf{z}) = \frac{1}{3K} \left\| \left( \hat{\mathbf{O}}_i(d, \mathbf{z}) - \mathbf{O}_i^{Tea} \right) \otimes \left( \mathbf{S}_i^{\text{pos}, Tea} + \epsilon \right) \right\|_1, \quad (17)$$

and measure the scaling discrepancy in the logarithmic domain via


$$E_i^s(d, \mathbf{z}) = \frac{1}{6} \left\| \log(\hat{\mathbf{s}}_i^{\text{anchor}}(d, \mathbf{z}) + \epsilon) - \log(\mathbf{s}_i^{\text{anchor}, Tea} + \epsilon) \right\|_1, \quad (18)$$

where ϵ > 0 is a small constant for numerical stability.

These error terms are combined into the local proxy distortion

Dei(d, z) = λ where λ RD f , λO, and λs control the relative contributions of the feature, offset, and scaling errors.

$$\widehat{D}(d, z) = \lambda_f^{\text{RD}} E_i^{\text{f}}(d, z) + \lambda_O E_i^O(d, z) + \lambda_S E_i^S(d, z), \quad (19)$$

#### 3.3.2 Fixed-depth index search

For each depth d ∈ {1, 2, 3}, we search for the RVQ indices using stage-wise beam search. At stage l, candidate codewords are selected from the Kdist entries with the smallest Euclidean distance to the current residual and the Kprob entries with the highest conditional probability under Eq. \(14\). Their union is used to expand the current partial paths, and the beam is pruned at each stage to limit the search complexity.

After all d active stages have been processed, the retained complete index paths form the set Bi(d). The index path for depth d is then selected as

$$\mathbf{z}_{i,d} = \arg \min_{\mathbf{z} \in \mathcal{B}_i(d)} \left[ \tilde{D}_i(d, \mathbf{z}) + \lambda_{\text{assign}} R_i(d, \mathbf{z}) \right], \quad d \in \{1, 2, 3\}, \quad (20)$$

where Bi(d) denotes the set of complete index paths retained by beam search at depth d, and λassign controls the trade-off between local distortion and code length. This produces one candidate index path for each anchor at each depth.

#### 3.3.3 Depth candidate selection

Different anchors contribute differently to the rendered image. We therefore estimate an importance weight from the accumulated alpha-compositing contribution of each anchor in the teacher model.

We accumulate the raw importance over the optimization views and pixels according to

$$\bar{w}_i = \sum_{v \in \mathcal{V}_{\text{opt}}} \sum_{p \in \Omega_v} \sum_{k \in \mathcal{G}(i)} T_{i,k}^{v,p} \alpha_{i,k}^{v,p}, \quad (21)$$

where Vopt is the set of optimization views, Ωv is the pixel set of view v, and G(i) is the set of local Gaussians generated by anchor i. The quantity T v,p i,k denotes the accumulated transmittance before Gaussian (i, k) at pixel p, and α v,p i,k is its opacity contribution.

Normalization and clipping then produce the importance weight

$$w_i = \text{clip}\left(\frac{\bar{w}_i}{N_a^{-1} \sum_{j=1}^{N_a} \bar{w}_j + \epsilon_w}, w_{\min}, w_{\max}\right), \quad (22)$$

where ϵw > 0 is a small constant for numerical stability, while wmin and wmax bound the normalized importance weight.

$$\Delta R_i^{(l)} = R_i (l, z_{i,l}) - R_i (l-1, z_{i,l-1}). \quad (24)$$

#### 3.3.4 Rendering-based calibration

The local proxy does not explicitly model visibility, Gaussian overlap, or alphacompositing interactions in the image domain. We therefore evaluate the selected depth changes by rendering held-out calibration views. To limit the computational cost, the pending anchors are divided into candidate groups and evaluated sequentially.

We evaluate the average rendering distortion over the calibration views using

---

$$\mathcal{D}_{\text{cal}} \left( I^{Stu}, I^{GT} \right) = \frac{1}{|\mathcal{V}_{\text{cal}}|} \sum_{v \in \mathcal{V}_{\text{cal}}} \mathcal{L}_{\text{render}} \left( I_v^{Stu}, I_v^{GT} \right), \quad (26)$$

where Vcal is the set of calibration views and Lrender is defined in Eq. \(29\).

For candidate group b, the induced change in rendering distortion is computed as

$$\Delta \mathcal{D}_{\text{cal},b} = \mathcal{D}_{\text{cal}} \left( I_b^{\text{Stu,new}}, I^{GT} \right) - \mathcal{D}_{\text{cal}} \left( I^{\text{Stu,old}}, I^{GT} \right). \quad (27)$$

Combining the distortion and rate changes gives the rendering-based rate– distortion cost as

$$\Delta \mathcal{J}_b^{\text{cal}} = \Delta \mathcal{D}_{\text{cal},b} + \lambda_R \frac{\Delta \widetilde{R}_b^{\text{CDF}}}{N_a}, \quad (28)$$

where ∆ReCDF b is the change in code length computed from the integer CDFs after applying candidate group b, and λR controls the rate–distortion trade-off during calibration. The candidate update is accepted when ∆J cal b ≤ 0; otherwise, the previous state is retained. After all candidate groups have been evaluated, the final depths and RVQ indices are used to regenerate the arithmetic-coded bitstream.

## 3.4 Optimization and Bitstream Construction

We optimize the recovery modules to preserve rendering quality while reducing the errors introduced by feature and attribute quantization. Rendering supervision combines mean absolute error (MAE) and structural similarity according to


$$\mathcal{L}_{\text{render}}(I, I^{\text{ref}}) = (1 - \gamma_{\text{SSIM}}) \text{MAE}(I, I^{\text{ref}}) + \gamma_{\text{SSIM}} [1 - \text{SSIM}(I, I^{\text{ref}})], \quad (29)$$

where I ref ∈ {I GT , IT ea} denotes either the ground-truth image or the rendering of the teacher model before quantization, and γSSIM controls the relative contribution of the SSIM term.

Feature recovery is supervised by the average ℓ1 loss as follows:

$$\mathcal{L}_f = \frac{1}{N_a} \sum_{i=1}^{N_a} \left\| \mathbf{f}_i^{Tea} - \widehat{\mathbf{f}}_i^{Stu} \right\|_1. \quad (30)$$

To constrain the adapted offsets and scaling, let Avis denote the set of anchors visible in the current view. The explicit-attribute loss is defined as:

$$\mathcal{L}_{Os} = \frac{1}{|\mathcal{A}_{\text{vis}}|} \sum_{i \in \mathcal{A}_{\text{vis}}} (\lambda_O E_i^O + \lambda_s E_i^s), \quad (31)$$

where EO i and Es i are the offset and scaling errors defined in Eqs. \(17\) and \(18\), evaluated at the current quantized state.

Large Attribute Adapter corrections are penalized by

$$\mathcal{L}_{\text{adapter}} = \frac{1}{|\mathcal{A}_{\text{vis}}|} \sum_{i \in \mathcal{A}_{\text{vis}}} \left[ \frac{1}{3K} \left\| (\hat{\mathbf{O}}_i - \tilde{\mathbf{O}}_i) \otimes (\tilde{\mathbf{S}}_i^{\text{pos}} + \epsilon) \right\|_1 + \frac{1}{6} \left\| (\hat{\mathbf{s}}_i^{\text{anchor}} - \tilde{\mathbf{s}}_i^{\text{anchor}}) \otimes (\tilde{\mathbf{s}}_i^{\text{anchor}} + \epsilon) \right\|_1 \right], \quad (32)$$

where the first term normalizes the offset correction by the positional scale and the second term constrains the relative change in anchor scaling.

Combining these losses, the overall recovery-stage objective function can be expressed as follows:


$$\mathcal{L} = \mathcal{L}_{\text{render}} \left( I^{Stu}, I^{GT} \right) + \lambda_f^{\text{train}} \mathcal{L}_f + \mathcal{L}_{Os} + \lambda_{\text{distill}} \mathcal{L}_{\text{render}} \left( I^{Stu}, I^{Tea} \right) + \lambda_A \mathcal{L}_{\text{adapter}}, \quad (33)$$

where λ train f , λdistill, and λA control the feature-recovery, rendering-distillation, and adaptation-regularization terms, respectively.

Optimization proceeds in stages. We first initialize the three RVQ codebooks using residual K-means and optimize them to reconstruct the teacher anchor features. The Context Refiner is then trained with quantized anchor features while sampling different RVQ depths, allowing it to recover features from different reconstruction states. Next, we freeze the Context Refiner and optimize the Attribute Adapter to refine the quantized offsets and scaling based on the recovered features. Finally, with the nearestneighbor RVQ indices fixed, the RVQ codebooks, Context Refiner, and Attribute Adapter are jointly fine-tuned using Eq. \(33\).

After the recovery stage, the RVQ codebooks, Context Refiner, and Attribute Adapter are frozen. We then fit the contextual entropy model by minimizing the estimated code lengths in Eq. \(15\). The fixed-depth index search, per-anchor depth selection, and rendering-based calibration described in Section 3.3 are subsequently performed to determine the final discrete representation.

The final bitstream contains the three RVQ codebooks, spatial hash grid, anchor positions, HAC-based offset and scaling bitstreams, the parameters of the Context Refiner, Attribute Adapter, and contextual entropy model, per-anchor depth symbols, and the RVQ indices of the active stages.

## 4 Experiments and Analysis

## 4.1 Experimental Setup

#### 4.1.1 Datasets and Evaluation Metrics

We evaluate our method on three real-world datasets: Mip-NeRF 360 [44], Tanks and Temples [45], and Deep Blending [46]. All nine scenes from Mip-NeRF 360 are used for quantitative comparison and ablation studies. Tanks and Temples and Deep Blending are further used for cross-dataset evaluation.

Rendering quality is measured using peak signal-to-noise ratio (PSNR), SSIM [47], and learned perceptual image patch similarity (LPIPS) [48]. Higher PSNR and SSIM indicate better rendering quality, whereas lower LPIPS is preferred. For all methods, model size is measured from the complete model files produced by our experiments.

#### 4.1.2 Training Setup and Implementation Details

We adopt a post-training compression setting. A pretrained HAC anchor model [11] serves as the teacher model before quantization. Instead of retraining the scene representation from scratch, we further compress its high-dimensional anchor features using adaptive RVQ, the Context Refiner, and the Attribute Adapter, followed by a short recovery optimization.

Our implementation is built on HAC. The anchor feature dimension is Df = 50, and each anchor contains 10 local offsets. Each of the three RVQ stages uses a codebook with 1,024 entries. The Context Refiner, Attribute Adapter, and contextual entropy model are lightweight MLPs shared across anchors. We set γSSIM = 0.2, λ RD f = 0.02, and λ train f = 1/Df = 0.02. The offset and scaling weights are λO = λs = 1, while λdistill = 0.1 and λA = 10−3 . We set ηo = 0.1 and ηs = 0.05 for offset and scaling adaptation, respectively. For index selection, depth allocation, and rendering-based calibration, we use λassign = λdepth = λR = 5 × 10−4 .

At each RVQ stage, we select 16 codeword candidates with the smallest Euclidean distance to the current residual and 16 candidates with the highest conditional probability. Their union is used for beam search with a beam width of 8. All ablations use the same teacher model, anchor set, HAC-style offset and scaling quantization, and training views. After the recovery stage, the RVQ codebooks, Context Refiner, and Attribute Adapter are frozen. We then fit the contextual entropy model and perform fixed-depth index search, per-anchor depth selection, and rendering-based calibration as described in Section 3.3. All experiments are implemented in PyTorch and run on a single NVIDIA RTX 4080 GPU. All quantitative results reported in this section are obtained from our own experiments using the same evaluation protocol, while following the original training and compression settings of each method.

In addition to image-space metrics, we evaluate recovery errors of the anchor features, offsets, and scaling through normalized mean absolute error (NMAE)

$$\text{NMAE}(\mathbf{y}, \hat{\mathbf{y}}) = \frac{\sum_{j=1}^{D_y} |y_j - \hat{y}_j|}{\sum_{j=1}^{D_y} |y_j| + \epsilon}, \quad (34)$$

where y, yb ∈ R Dy denote the teacher and recovered quantities, respectively, Dy is the number of scalar components, and ϵ > 0 is a small constant for numerical stability.

Feature NMAE compares the teacher feature f T ea with the recovered feature fbStu . We aggregate the feature, offset, and scaling errors into the joint NMAE as

$$\text{NMAE}_{\text{joint}} = \frac{1}{3} \left[ \text{NMAE} \left( \mathbf{f}^{Tea}, \hat{\mathbf{f}}^{Stu} \right) + \text{NMAE} \left( \mathbf{O}^{Tea}, \hat{\mathbf{O}} \right) + \text{NMAE} \left( \mathbf{s}^{\text{anchor}, Tea}, \hat{\mathbf{s}}^{\text{anchor}} \right) \right]. \quad (35)$$

## 5 Conclusion

In this paper, we introduce ARQEC, a post-training framework for compressing highdimensional anchor attributes in anchor-based 3DGS. ARQEC compresses anchor features through a three-stage residual vector quantization process and adaptively determines the RVQ depth for each anchor. By incorporating a Context Refiner that exploits spatial hash-grid context to compensate for feature residuals resulting from RVQ, along with an Attribute Adapter that refines the quantized offsets and scaling based on the recovered features, ARQEC significantly reduces rendering distortion. Finally, we employ a contextual entropy model to estimate the coding costs associated with the quantization depth and RVQ indices, followed by a rendering-based calibration, which facilitates efficient compression. Our experiments demonstrate the effectiveness of ARQEC across various datasets, achieving compression ratios of 47×– 157× compared to the vanilla 3DGS while maintaining high rendering quality. In future work, we plan to explore the development of a plug-and-play compression module for anchor-based 3DGS representations.
