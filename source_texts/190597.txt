Task
ROADMAP M3.5 — Marching cubes on final density (threshold 0.5) + cleanup; Gate V3 property suite wired to run on optimizer output. One task per run; startup suite was green 12/12 before changes (no "restore green CI" override).
What changed
Marching cubes (core/src/mesh/mesh.cpp): classic Lorensen–Cline 256-case table over a grid-indexed scalar field. Samples at voxel centres, one-layer background padding so solids close at the grid boundary, vertices welded via a global edge→vertex map → closed, consistently-wound shells. New count_components (shared-edge adjacency) and keep_largest_component (the §5 "mesh cleanup": drop degenerate triangles + keep the largest shell).
Gate V3 suite (core/src/voxel/voxelize.cpp, voxel.hpp): check_v3(grid, density, iso=0.5) → V3Report with the four ARCHITECTURE §7 gates — watertight (closed/2-manifold), single connected component (of the cleaned mesh), Load/Fixture voxels retained ≥ 0.9, min feature size ≥ 2 voxels (min_feature_violations, a solid-2×2×2-block cover). Returns the cleaned TriangleMesh for downstream export.
Test (core/tests/property/test_v3.cpp, new property_v3, 33 checks) + CMake wiring (Eigen-gated, like the other optimizer tests).
ROADMAP M3.5 box checked; handoff docs/handoffs/018-M3.5-marching-cubes-gate-v3.md.
Diff is 690 insertions, 0 deletions across 5 files + the new test. No existing test/assertion/tolerance, fixture, materials.json, ARCHITECTURE.md, CI config, or /app/ touched.
Reviewer notes
Watertightness rides on the M3.3 density filter. The classic table is closed on smooth (filtered) fields; the only openers are diagonal/checkerboard corner patterns, which the filter suppresses. Verified empirically watertight + single-component on solid/holed/disjoint synthetic blocks and on real SIMP output. A hard guarantee for arbitrary inputs (asymptotic decider / MC33) is left for M6 export if needed.
Retention + min-feature are not asserted on raw optimizer output — deliberately, not a weakening. At M3.5 retention is emergent (simp_optimize doesn't pin Load/Fixture voxels; ROADMAP M3.7 makes them structural) and SIMP designs at 24×8×8 have 1-voxel struts. Both checks are instead covered by controlled synthetic pass/fail cases (incl. a genuine all-four-gates passes == true on a solid design); the end-to-end cantilever run asserts only the watertight + single-component gates and reports the rest.
Test evidence
Full suite green 13/13 locally (-DCMAKE_BUILD_TYPE=Release, Eigen + OCCT); dependency-light (Eigen-absent) build intact (4 tests, property_v3 correctly gated off); new sources clean under -Wall -Wextra -Wpedantic.
