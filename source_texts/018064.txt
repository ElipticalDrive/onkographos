The current implementation would benefit from a complete reconstruction of the chunking system into a Sparse Voxel Octree system, with octree nodes replacing current chunks.
Implementation of this feature will further benefit the system in other areas in terms of optimisation, such as voxel generation and voxel interactions being sped up.
A sparse system should be the suitable option for a large scale infinite style world.
On success of implementation:
Testing of performance gains from voxel generation and voxel interactions
Implementation of Raymarching for Occlusion Culling (A future ticket to be opened if SVO is implemented)
Usage for possible Ambient Occlusion and other lighting features to improve visuals (A future ticket to be opened if SVO is implemented)
