Implements a Minecraft/Roblox-style voxel game with procedural terrain generation, first-person controls, and block building mechanics.
Architecture
Rendering
Instanced mesh rendering for ~10K blocks with frustum culling
Procedural terrain using sine-based height maps
WebGL scene with directional shadows and fog
Game Loop
Player physics: gravity (-20 m/s²), AABB collision, jump mechanics
Block interaction: DDA-inspired raycasting (5m reach, 0.2m steps)
Input handling: WASD movement, pointer lock, keyboard block selection
Block System
5 block types: Grass, Dirt, Stone, Wood, Sand
World stored as Map<"x,y,z", blockType> for sparse representation
Mesh rebuilt on block changes (filtered to exposed faces only)
Key Optimizations

Tech Stack
Three.js 0.160.0 for 3D rendering
Vite 5.4.21 for dev server and bundling
Vanilla JS (no framework dependencies)
