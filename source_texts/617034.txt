Implements 5 core nodes from ROADMAP v3.0, advancing RageVFX from 161 to 166 nodes with production-grade VFX capabilities rivaling Nuke, Houdini, and Redshift.
New Nodes (2,920 LOC)
SmartVectorNode (450 LOC)
Motion-aware painting with motion vector tracking. Paint strokes follow tracked surfaces with sub-frame interpolation, temporal consistency, and configurable lifetime/blending.
VDBNode (530 LOC)
OpenVDB sparse volume implementation with level set operations (union/intersect/difference), particle-to-VDB conversion, filtering (Gaussian/median/Laplacian), and morphology operators.
WrangleNode (580 LOC)
VEX-style procedural expressions. Supports point/primitive/vertex/detail wrangles with @ attribute notation, built-in math/noise functions, and runtime JavaScript compilation.
```
// Example wrangle code
vector noise_offset = noise(@P * 2.0 + @Time) * 0.5;
@P += noise_offset;
@Cd = set(0.0, @P.y * 0.5 + 0.5, 0.0);
```
ProceduralCityNode (650 LOC)
Urban generation with 5 street algorithms (L-system/agent-based/grid/radial/organic), building footprint subdivision, facade generation, and infrastructure placement.
AdaptiveSamplerNode (710 LOC)
Variance-based adaptive sampling with progressive refinement, stratified sampling, firefly suppression, and denoising. Outputs sample/variance maps and convergence statistics.
UI Enhancements
