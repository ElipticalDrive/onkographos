Notes
It is highly recommended to compile this project in Release mode. BTW, you can choose either x86 or x64, but personally I prefer x64.
Because the data files for glossy objects are too large (300MB), we ignore them from git and you may need to generate them manually.
Since GLM version 0.9.9, GLM default initializes matrix types to a 0-initialized matrix, instead of the identity matrix. From that version it is required to initialize matrix types as: glm::mat4 mat=glm::mat4(1.0f).
