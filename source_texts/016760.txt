Hey folks, I built Kiln, a WebGPU-native out-of-core volume renderer for virtualized volumetric datasets.<p>Kiln is an end-to-end system for rendering large volumetric datasets in the browser using WebGPU.<p>It covers the full pipeline: data preprocessing, HTTP streaming, decompression, memory virtualization, and rendering — making multi-gigabyte CT scans and scientific volumes interactive in a standard browser tab using a contemporary tech stack.<p>The source code and docs are available here: <a href="https:&#x2F;&#x2F;github.com&#x2F;MPanknin&#x2F;kiln-render" rel="nofollow">https:&#x2F;&#x2F;github.com&#x2F;MPanknin&#x2F;kiln-render</a>
