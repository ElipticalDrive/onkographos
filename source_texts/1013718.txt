Opportunity and evidence
Prepared attribute declarations reduce CPU setup, but VP uploaders still decode/endian-convert and expand attributes into float4 slots on the CPU. The reference uses rsx_vertex_pack_ex to snapshot eligible raw ranges, deduplicate overlap, and batch GPU decoding into an existing shader-compatible output layout; unsupported/sparse inputs retain a CPU fallback.
Source: packed implementation and GPU decoder. The local fixture reports 512 snapshots and 12,288 bit-identical CPU-decoded vertices, including sparse gather and immutable bytes. It does not test HLSL or real GPU output.
Scope
Prototype an opt-in HLSL compute decoder emitting the existing DX12 vertex layout. Start with a small format set. Preserve current-register defaults, normalized/half semantics, big endian, divisors/modulo, base-index wrapping, and mappings. Capture immutable input at the original observation boundary. Fence staging/output lifetime and transition resources before drawing. Keep sparse gather separately gated; reference gameplay did not establish a gain, and Apple shared-memory performance does not predict discrete GPUs. Related: #129, #130, #223 and prepared/indexed-cache work.
Verification
Compare complete GPU output with the scalar reference, including all half/SNORM bit patterns for supported formats, mixed layouts, restart, split draws, and allocation failures. Mutants must reject wrong endian/default/divisor handling. Measure upload bytes, CPU preparation, GPU decode, and full frame time on identical input.
