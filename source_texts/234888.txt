# Install
Create environment
```bash
conda create -n InitGaussian python=3.10
conda activate InitGaussian
```
Install dependencies
```bash
cd InitGaussian
pip install -r requirements.txt
cd submodules
pip install ./diff-gaussian-rasterization
pip install ./simple-knn
pip install ./MVDream
cd ..
```

# Getting start
You need to provide a prompt
```bash
python main.py --prompt "A horse"
```

# Use for Text-to-3D Generation
Replace the initial pc of the generated framework with our pc (You can choose any framework based on 3D GS):
```bash
path = "outputs/{your_prompt}/xyz_rgb_sca3_rot4_opa1.pt"    # need to modify
data = torch.load(path).numpy()
coords = data[:, :3]
rgb = data[:, 3:6]
```
