# High-Performance CUDA N-Body Physics Engine

A real-time, interactive N-Body physics simulation built entirely in C++ and CUDA, demonstrating advanced GPU performance tuning and zero-copy rendering via OpenGL-CUDA interop.

This project was engineered to maximize Instruction-Level Parallelism (ILP) and memory bandwidth on modern NVIDIA architectures (Ampere `sm_86`+), achieving **>400 GFLOP/s** on consumer-grade hardware.

## 🚀 Key Technical Achievements

- **Advanced GPU Performance Tuning:** Implemented **Shared Memory Tiling** to bypass global memory bandwidth limits, and **Thread Coarsening (Register Tiling)** to maximize mathematical throughput.
- **Perfect Memory Coalescing:** Utilized 128-bit `float4` vectors to guarantee perfectly aligned and coalesced global memory accesses, fully saturating the GPU memory bus.

- **Zero-Copy GLSL Rendering:** Developed a native C++ OpenGL frontend using GLFW and GLAD. The engine uses `cudaGraphicsGLRegisterBuffer` to map the OpenGL Vertex Buffer Object (VBO) directly into CUDA space. The GPU computes physics and updates positions entirely in VRAM without a single byte ever being copied back to the CPU.
- **Hardware-Aware Profiling:** Configured for RTX architectures and analyzed using **NVIDIA Nsight Compute** (`ncu`).

## 📁 Repository Structure

- `nbody_opengl.cu` - The crowning achievement: C++ OpenGL Application with GLSL shaders and zero-copy CUDA interop.
- `nbody.cu` - The core physics benchmark containing Naive, Tiled, and Expert (Coarsened) kernel implementations.
- `profiler_report.txt` - Raw NVIDIA Nsight Compute (`ncu`) trace of the engine's L1/L2 cache hit rates and SM occupancy.
- `vendor_setup.py` - A lightweight script to automatically fetch C++ dependencies (GLFW/GLAD).
- `run_*.bat` - Windows batch scripts to easily compile via `nvcc` and MSVC.

## 🛠️ How to Build and Run (Windows)

Requires **Visual Studio (MSVC)** and the **CUDA Toolkit**.

1. Open your **x64 Native Tools Command Prompt**.
2. Run the dependency setup (requires Python to download GLFW headers):
   ```cmd
   python vendor_setup.py
   ```
3. Compile and launch the interactive OpenGL engine:
   ```cmd
   run_opengl.bat
   ```
