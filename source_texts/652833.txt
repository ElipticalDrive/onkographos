Summary
Adds procedural-3d-studio, an optional skill and pure Python procedural 3D mesh engine for synthesizing 3D models, low-poly game assets, and environment props with zero external dependencies (standard library only).
Key Features
Procedural Game Asset Generators:
tree: Stylized low-poly trees with parameterized trunk dimensions and tiered conical foliage.
rock: Deformed rock / boulder meshes with customizable facet roughness and displacement noise.
tower: Medieval castle towers with battlements / crenellations, ledges, and conical roofs.
sword: Fantasy weapon models with dual-beveled blades, crossguards, grips, and pommels.
dungeon: Modular 3D dungeon floor tiles with directional wall placement flags (nw, nesw).
crate: Low-poly cargo crates with corner reinforcement ribs.
terrain: Procedural heightmap terrain patches with altitude-based vertex coloring.
primitive: Parameterized cubes, UV spheres, cylinders, and cones with clean normal calculation.
Multi-Target Exporters:
Binary glTF 2.0 (.glb): Pure Python binary glTF packer that writes the 12-byte header, JSON chunk, and aligned binary buffer with PBR metallic-roughness materials and vertex colors.
Wavefront OBJ (.obj + .mtl): Standard geometry with vertex normals and RGB material definitions.
Godot 4 Scene (.tscn): Ready-to-import Godot 4 scene node tree referencing the generated .glb.
Interactive WebGL Preview (.html): Self-contained Three.js OrbitControls viewer for browser inspection without installing extra software.
Headless Blender Automation (.blender.py): Script generator for executing background Cycles/Eevee renders via blender --background --python <script>.
Zero Dependencies:
Uses Python stdlib only (math, struct, json, argparse, pathlib, os).
Verification
Added unit tests in tests/skills/test_procedural_3d_studio.py covering all geometric generators, glTF binary packing (header, version, JSON/BIN chunks), OBJ/MTL export, and scene generators.
Verified authoring standards via tests/skills/test_authoring_standards.py (all tests pass).
