Summary
Implement GPU-based Ray Casting volume rendering using VTK.
Traces to
SRS-FR-005: GPU-Accelerated Volume Rendering
PRD FR-002.1
Requirements
Primary Mapper: vtkGPUVolumeRayCastMapper
Fallback Mapper: vtkSmartVolumeMapper (CPU fallback)
Blend Modes: Composite (default), MIP
Automatic sampling distance
Performance Targets
512×512×300 volume: ≥ 30 FPS
Apply LOD during interaction
Implementation
```cpp
auto volumeMapper = vtkSmartPointer::New();
volumeMapper->SetInputConnection(imageData->GetOutputPort());
volumeMapper->SetBlendModeToComposite();
// GPU support check and fallback
if (!volumeMapper->IsRenderSupported(renderWindow, volumeProperty)) {
// CPU fallback
}
```
Acceptance Criteria
GPU Ray Casting implementation
CPU fallback when GPU not available
≥30 FPS for standard CT volume
LOD support for interaction
Technical Notes
Location: src/services/render/
Dependency: VTK RenderingVolumeOpenGL2
