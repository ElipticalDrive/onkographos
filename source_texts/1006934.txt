Refs #348. This adds a probe that measures what the original player samples for Point textures with their own anisoLevel above 1. It has not run in the VM yet; that waits for a granted slot. The Point rule is not changed here. That comes in a separate PR, after the result has been reviewed.
Why
TranslatedSourceProgram.SamplerConfiguration handles two Point cases without any recorded evidence:
A Point texture with anisoLevel above 1 gets nearest min/mag, linear mips and that anisotropy.
Point textures are left out of ForceEnable's minimum of 9.
D3D11 has no filter that combines point min/mag with anisotropy, because D3D11_FILTER_ANISOTROPIC is linear at every stage. So the player gets either point sampling or full anisotropic filtering, and our descriptor matches neither. The probe tells us which one it is.
What
Tools/reverse/fixtures/OriginalSamplerProbe.cs, a BepInEx plug-in for an isolated CharaStudio root.
It draws synthetic 256×256 textures only. The matrix is filter Point/Bilinear/Trilinear × anisoLevel 0/1/2/8/16 × mipmapped or single-level.
Each texture is drawn in a grazing view and a magnified 128×128 view. This happens first under the player's own anisotropicFiltering, then under the other two modes, so 90 cells in all.
Mip level l holds R = round(255 l / 8) and a one-texel checkerboard in G.
The mode and fog are restored in a finally block.
A control frame shows that nothing else reaches the probe camera.
One cell is drawn again after the restore and must come out byte-identical.
It records the quality level and level names, which covers Studio live source shaders sample with the player's ForceEnable #338's open quality-level point.
Survey, in the same run, read-only. It records each Texture2D's filter, aniso, mip count, size and wrap under abdata/chara, abdata/studio and abdata/map.
Every bundle the probe loads is unloaded with Unload(true).
A bundle the game already holds is read in place and left loaded.
It reads no pixels, and no cards, saves, scenes or mods.
Tools/reverse/original_sampler_probe.py, the driver.
run is a single prlctl exec built on the reload probe's transport. It refuses to start unless the errno-24 count equals the baseline, and records the count before and after. It scans the junctions before and after, writes -logFile into the private root, then removes the root and checks that no game process is left.
analyse reads the frames and decides, for each cell:
linear min/mag, when the magnified frame's G takes values strictly between 0 and 255;
linear mips, when the grazing frame's R falls between level values;
anisotropy, when its rows use finer levels than the aniso-0 cell, or for single-level textures when its checkerboard contrast is lower.
With --reference, analyse also names the nearest host Metal candidate for each cell and says whether SamplerConfiguration's prediction matches. Candidates the host renders identically count as a tie.
The survey goes into the report as counts only.
once_script gains allow_no_uploads=False. Existing callers behave exactly as before.
Docs: a new renderer.md section, "Player sampler probe (Renderer: Point textures with their own aniso > 1 sample anisotropic with linear mips (needs a capture check) #348)", and rows in the file index.
Checks
Compile. The plug-in compiles with Roslyn at -langversion:5, the guest's csc version, against the local CharaStudio managed copies and BepInEx core.
Tests.
Tools/reverse suite: 706 tests OK, 7 skipped.
The new test file has 16 mocked tests: the one-exec framing, the rule restatement, the frame metrics, analyse including ties, and the survey counts.
site/build.py --check passes.
Host reference. A scratch Swift script in .local renders 11 candidates × mipmapped/single-level × both views on the M2 Ultra.
The classifier separates the candidates cleanly. Magnified linear fraction is 0 for point and 0.996 for linear. The mip-blend fraction is 0 for point mips and 0.22–0.44 for linear mips. Anisotropic rows sit 0.44–1.0 levels finer than trilinear.
maxAnisotropy 9 and 16 render byte-identically there.
Dry run. analyse was run over the full 90-cell matrix, using host renders as a fake player that point-samples every Point texture. It flagged exactly the 12 Point cells with aniso above 1 under Enable and ForceEnable, each by a margin of 6.7–8.6, and flagged no other cell.
Not here
The VM run (main grants the slot).
The Point-branch rule change and the update of its pinned cases in liveSourceSamplerConfigurationPreservesTheDescriptorContract.
