The player arrow resampled its voxel silhouette at each heading and recentered each resulting image, making its blocks change shape as it turned. Build the silhouette in model coordinates, rotate the same blocks around a fixed pivot, and sort their faces together for rendering. Retain the existing 72 heading textures and asynchronous generation.
Use the existing crisp tile sampler at every zoom so the GPU chooses minification or magnification from the actual screen footprint, including GUI scaling. Mipmaps, tile resolution, baking, and draw counts remain unchanged.
This is a visual experiment kept separate from the marker-anchoring fixes in #135. The arrow design is still being compared against a flat compass alternative; no terrain-shading or layer-order changes are included.
Validation: Fabric 26.3 build and Fabric 1.20.1 compilation passed with these changes in the combined local checkout. Rendered all 72 headings for visual comparison and launched the normal client for manual review. Exact FPS has not been benchmarked.
