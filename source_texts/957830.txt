TOWARDS REAL-TIME DENSE 3D MAPPING WITH LIGHTWEIGHT
PORTABLE SENSORS
We are building a lightweight wearable system for constructing dense 3D maps in real-time
The current standard method for creating dense 3D map uses scanning Light Detection And Ranging (LiDAR) devices and Inertial Measurement Units (IMU), typically mounted on
wheeled rovers for stability. This setup allows a great mapping accuracy but is heavy, hard to navigate in non-flat environments, power-hungry and expensive. Here, we aim to
perform dense 3D SLAM using lightweight, portable sensors with a reduced power consumption. As a consequence, the sensing accuracy is decreased and the sensor motion is
much less stable. Therefore, we research ways of extending existing LiDAR-inertial SLAM methods for noisier measurements with a more complex motion model.
A word on SLAM
Simultaneous Localization And Mapping (SLAM) is the
generic task of constructing a map of an unknown
environment while simultaneously maintaining an
estimate of the agent’s localization within this map.
Dense 3D SLAM is one of the most important variants,
which aims to create dense 3D maps that can be used
for applications in fields such as civil engineering,
security, virtual reality or autonomous robotics.

We develop a probabilistic framework based on the Error-State Iterative Kalman Filter (ESIKF) for state estimation
Here, the state represents information such as the current orientation, position or velocity of the agent at each time step. The ESIKF allows us to perform state estimation using
the uncertainties on both IMU readings and 3D scans, which is critical since our sensors produce especially noisy outputs. The main steps of the ESIKF are:
- State propagation: the state estimate’s Gaussian distribution is evolved from the previous state each time new IMU data is read, integrating accelerometer and gyroscope
measurements with their respective bias and noise.
- State correction: whenever a new 3D scan is available, we perform a probabilistic 3D scan-to-map matching and an iterated state correction step. The Gaussian distribution
of the state is then updated, effectively performing tightly-coupled LiDAR-inertial state estimation.
Helmet-mounted 3D mapping system
Our hardware system has the following components:
- Platform:
Ops-Core helmet with mounting rails similar to those
used by the Belgian Special Force Group
- Sensors:
Intel Realsense L515 LiDAR camera and IMU
Mohoc wide angle camera (used for video monitoring,
not SLAM)
- Computer:
Nvidia Jetson AGX Xavier (not shown), fitted in the
backpack, running on a battery

Targeted applications
The goal of the system is to help military and
emergency services improve their situational
awareness, in order to better execute operations
and do better-informed decisions. In many
emergency situations (e.g. search and rescue,
fires, terror attacks), having a clear, up-to-date 3D
representation of the whereabouts is of critical
importance. Often, this information will not be
readily available, or simply outdated since the
event creating the emergency had a direct impact
on the 3D environment. Our system aims to allow
the generation of these 3D maps in a fast,
portable and reliable manner.
