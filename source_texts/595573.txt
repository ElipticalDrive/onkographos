This PR implements creative enhancements to the voxelizer:
Volumetric Gyroid Infill Generation: Introduces the ability to fill the interior of a solid mesh with a Gyroid lattice structure, while preserving a solid outer shell using new --gyroid <scale>,<thickness> and --shell-thickness <val> arguments.
SDF Heatmap Coloring for PLY Export: Enhances the PLY export format to visually map the Signed Distance Field (SDF) values to a color gradient (blue for deep inside, green/white near the surface, red for outside), making it much easier to visualize the generated volumes.

Reject negative gyroid thickness values
If a user passes a negative thickness such as --gyroid 1,-0.1, the parser accepts it and this comparison becomes true for every finite gyroid value because val.abs() is always non-negative. In non-surface mode that drops essentially all interior infill particles outside the preserved shell, which is a surprising empty/near-empty result for an invalid parameter; validate the thickness as finite and non-negative before voxelization.
