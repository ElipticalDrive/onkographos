S6 — froxel temporal reprojection (the last S6 tail)
The froxel volume is a stable 3D LUT, but the moment fog animates — drifting FBM noise,
pulsing density, moving lights — the single-frame volume flickers. Temporal
reprojection exponentially blends each frame's per-cell scatter + extinction with the
previous frame's before integration (Frostbite/Hillaire accumulation, on the
pre-integration grid so energy conservation holds) so animated fog reads as a stable
volume. Additive + gated + default off → byte-identical.
Pieces
FroxelHistory (new) — caller-owned previous-frame per-cell scatter+ext, grid-keyed
by dims + near/far. BlendAndStore mutates the current grid toward history
(out = current·(1-a) + history·a) then stores it as the new seed. First frame /
grid-key change (camera moved → near/far changed) → a=0 re-seed — the disocclusion
fallback temporal AA uses. Feedback clamped [0, 0.999]. Pure + deterministic.
FroxelVolumePass — refactored to fill a full per-cell scatter+ext grid then
integrate from it (was per-column streaming), enabling the pre-integration blend.
Populate(m) delegates to the temporal overload with a null history → byte-identical
to the pre-refactor path.
FroxelCameraVolume.Apply — temporal overload (history + feedback), keyed by the grid.
HeightfieldRaymarch2D — optional FroxelHistory param; temporal forces the CPU
froxel post-pass (the GPU froxel kernel stays single-frame) via a !froxelTemporal gate
on the GPU branch. FractalRenderHost owns one persistent FroxelHistory across renders.
Params + UI — Relief2DFroxelTemporal + Relief2DFroxelTemporalFeedback (0.9);
"Temporal reprojection" checkbox + feedback slider in the Relief 3D dialog (enabled under
Froxel volumetrics), persisted in the reset snapshot.
Tests / safety
11 tests (FroxelTemporalTests): blend math, key invalidation, feedback-0, reset,
single-frame byte-identity, first-frame == single-frame, animated-fog smoothing,
determinism; + a routing test (temporal forces CPU froxel even with GPU kernels).
Suite 1722/1722. --froxelgpu gate still PASS (the refactor preserved parity).
Follow-ups (documented)
Batch-video history persistence — a per-sequence FroxelHistory in the BatchRenderer
loop (temporal helps across frames; a single still is a no-op).
GPU temporal + sub-cell reprojection under continuous camera motion.
This closes out S6's GPU/volumetric work (D3D kernel #464 → host wiring #465 → Vulkan
#466 → temporal here).
