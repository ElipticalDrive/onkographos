📝 Summary
Summary by CodeRabbit
New Features
Added CUTLASS radix sort for keys and key/value pairs, with ascending or descending order, selected bit ranges, temporary storage, and blocked-to-striped output.
Added CUTLASS radix ranking with stable Int32 ranks and optional exclusive digit-prefix results.
Supports scalar, thread-data, and register-based inputs where applicable.
Added a runnable radix sorting and ranking example.
Documentation
Expanded guides, API references, examples, and support tables for radix sorting and ranking.
Documented supported inputs, limits, output layouts, ordering, and rank-prefix behavior.
Bug Fixes
Added consistent validation for unsupported types, ranges, layouts, and storage configurations.
The PR adds CUTLASS block radix sort and rank APIs, backed by CUB lowering. It adds common dispatch validation, type stubs and exports, a runnable example, documentation, and compiler, runtime, typing, and packaging checks.
Changes: CUTLASS Radix Operations

Added compile and GPU runtime coverage for sorting, pair sorting, ranking, prefixes, payload forms, bit ranges, and output layouts. Example tests check results against host references.
Documentation and executable example
docs/python/coop*, docs/python/coop/visualizations/radix.rst, docs/_static/coop-radix.js, python/cuda_coop/examples/cutlass/radix.py
Added CUTLASS radix API and guide documentation, updated backend support and output descriptions, and added an example that sorts keys, computes ranks, and checks digit prefixes.
Priority: ⬇️ Low

The only open feedback asks for more precise exception matching in one validation test, so no merge-blocking risk remains.
