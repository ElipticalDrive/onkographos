# Mip-NeRF 360 Garden Small Run

本项目在本地 Windows + RTX 3060 Laptop 6GB 上运行一个小型 Mip-NeRF 360 风格实验。

数据使用官方 Mip-NeRF 360 `garden` 场景的 `images_8` 低分辨率图片和稀疏 COLMAP 位姿。模型使用 Nerfstudio 的 `nerfacto`，因为它包含 Mip-NeRF 360 的核心思想：

- scene contraction
- proposal-network sampling
- distortion regularization

> 这是一次小型本地烟雾实验，不是论文完整复现。使用 `images_8` 的目的是适配 6GB 显存和 Windows WDDM。

## Project Layout

```text
configs/                       experiment settings
data/raw/garden/               official images_8 and sparse/0
data/processed/garden_small/   Nerfstudio transforms and images
outputs/                       checkpoints, TensorBoard and logs
results/                       metrics, test renders and video
scripts/                       setup/prepare/train/evaluate/render scripts
tools/                         Windows compatibility helpers
.vscode/                       VS Code tasks and interpreter settings
```

`data/`, `outputs/`, model weights and `.venv/` are ignored by Git.

## Environment

The local environment uses:

- Python 3.10
- PyTorch 2.14.0+cu126
- Nerfstudio 1.1.5
- RTX 3060 Laptop 6GB

Open the folder in VS Code and select:

```text
.venv\Scripts\python.exe
```

If recreating the environment, install CUDA PyTorch first, then run:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\setup_env.ps1
```

`fpsample` is omitted because it requires a C++ compiler on Windows. `tools/fpsample.py` provides a fallback for the Nerfacto workflow.

## VS Code Tasks

Use `Terminal -> Run Task` and choose:

- `MipNeRF360: Prepare Garden Data`
- `MipNeRF360: Train Garden Small`
- `MipNeRF360: Resume Garden Training`
- `MipNeRF360: Evaluate`
- `MipNeRF360: Render Test Images`
- `MipNeRF360: Render Video`
- `MipNeRF360: Run Full Pipeline`

## Training Configuration

```text
model: nerfacto
iterations: 5000
train rays per batch: 1024
eval rays per batch: 1024
eval rays per chunk: 1024
input: official garden images_8, 185 images
```

The prepared data has 185 official images. Nerfstudio uses a 90/10 split, producing 18 test images.

## Notes

The initial conversion preserved the original COLMAP dimensions (`5187x3361`) while the files were `648x420`. `scripts/fix_transforms.py` scales the intrinsics to the actual image resolution. Without this correction, evaluation creates an incorrect full-resolution ray tensor and can trigger a Windows GPU driver timeout.

## Data Source

The official Mip-NeRF 360 `garden` images and sparse poses were obtained from the Hugging Face mirror `mileleap/mipnerf360`.
