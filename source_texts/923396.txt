Adds a futuristic Voxel Atlas map layer designed to make Vault Spots and exploration feel more like a living world map rather than a technical utility.
Included:
local-first map memory with validation and bounded storage
saved places and Vault Spot markers
opt-in current-location saving
interactive MapLibre/MapTiler path when a public map key is configured
graceful fallback map when no provider key is configured
place selection and forgetting local spots
clear separation between location memory and on-chain ownership
mobile-first presentation consistent with the Voxel Vault visual shell
This is intentionally additive and does not replace the existing homepage layout.
