Summary
Implement a software-simulated MXFP8/NVFP4 quantize-dequantize pipeline using ordinary CUDA kernels. The baseline does not depend on native FP8/FP4 instructions, Tensor Cores, Transformer Engine, or Hopper/Blackwell-specific features.
Implementation
Read row-major FP16/FP32 QDAT matrices and write FP16/BF16/FP32 dequantized QDAT matrices.
Implement MXFP8 E4M3FN with E8M0 block/tensor scaling.
Implement NVFP4 E2M1 with E4M3 local scales and an FP32 tensor-level global scale.
Pack two NVFP4 elements per byte; one CUDA thread owns each packed byte to avoid write races.
Support nearest ties-to-even and reproducible stochastic rounding based on seed + element index.
Save packed values, scales, shape, format metadata, aligned section offsets, and checksum in QLOW files.
Reload and validate QLOW before CUDA dequantization.
Report max absolute error, MAE, MSE, payload/file compression ratios, CUDA event timings, and effective bandwidth in JSON/CSV.
Include CPU reference implementations for exact CPU/GPU differential checks.
Validation
5/5 CTest tests pass on NVIDIA GeForce RTX 5060 Ti under WSL2/CUDA 13.3.
Format tests cover E4M3/E2M1 encodings, E8M0 boundaries, and deterministic stochastic rounding.
Pipeline tests cover MXFP8/NVFP4, block/tensor scaling, nearest/stochastic rounding, and FP16/BF16/FP32 outputs.
Correctness runs cover element counts 1, 15, 16, 17, 31, 32, 33, including tail blocks and odd FP4 packing.
Benchmarks cover uniform, normal, and outlier 1024x1024 matrices with 10 warmups and 100 iterations.
```
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
ctest --test-dir build --output-on-failure
./scripts/run_correctness.sh
./scripts/run_benchmarks.sh
```
Notes
This is a software simulation path; no native FP8/FP4 hardware path is required.
E5M2 and native-library comparisons are outside the base requirements and are not included.
Detailed format definitions, formulas, file layouts, function descriptions, benchmark results, and limitations are documented in 02_quant_dequant/pekka/REPORT.md.
