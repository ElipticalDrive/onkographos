V10: Accelerate exact interactive ray picking
Replace RegionTopologyIndex::firstRayHit's global face walk with two-level immutable BVH acceleration: a balanced triangle BVH for each bounded face-owning partition, below a persistent eight-level 16-way directory with conservative merged bounding boxes.
No global rebuild per stamp: a validated RegionEdit gathers owners of changed faces and old/new faces incident to moved/inserted/deleted vertices, rebuilds only those small partition BVHs, and path-copies at most 9 directory nodes per affected owner. Initial import performs one full construction; old revisions and branches retain their own geometry without stale lookups.
Preserve the exact existing nearest-positive, double-sided Möller–Trumbore intersection predicates and tolerance values. Conservative AABB expansion ensures boundary hits aren't discarded.
The V9 Vulkan viewport already pins displayedIndex_; accelerated picking queries that displayed root, never a newer unpublished worker root. No changes to exact 4D Step sampling, input queueing, mouse-down semantics or draining.
Add picking diagnostics picking_boxes, picking_partitions, and picking_triangles, alongside existing picking time and backlog counters, to verify candidate pruning in live strokes.
Add sixteenth CPU suite comparing accelerated and independently brute-force hits/misses over numerous camera, backface and miss rays, dense sphere, immutable historical revisions/forks, local geometry changes, cross-partition splits/collapses, and no-op commits. Test local BVH rebuild/structural sharing and measured pruning.
Update DESIGN.md and todo.md, preserving V11 and V12 milestones.
Caveats
Top-level partition hierarchy groups by stable partition IDs, not an optimal global centroid tree. Initial spatial Morton grouping makes this efficient on typical meshes; extremely scattered meshes can visit more nodes but never return a different hit. GPU presentation still merits on-device checking, and V11 covers bounded retirement of old CPU/GPU revisions.
Validation
GCC, Clang, and MSVC warning-clean builds and all 16 CPU suites required to merge.
