Here is my modification process that allowed me to successfully resolve the issue. The fix primarily involved updating metrics.py to skip hidden directories generated in the file system, though I have not yet investigated the root cause of these hidden
Switching the "except" clause
Initially, the script used a bare except: statement, which suppressed specific error messages. Replacing it with:
```
except Exception as e:
    print("Unable to compute metrics for model", scene_dir)
    print("Error:", e)
```
allowed the code to print the actual error details.
Inspecting the error message
After running the updated script, the error message indicated an “[Errno 21] Is a directory” issue, meaning the code attempted to open a directory (.ipynb_checkpoints) as if it were an image.
Confirming the hidden folder
Checking the target directory indeed revealed that.
Identifying the core function
The issue originated in the readImages function, which scanned all entries in the folder, unintentionally including hidden directories.
Filtering hidden folders
Within readImages, adding conditions to skip entries starting with “.” or that are directories prevented .ipynb_checkpoints from being processed:
```
for fname in os.listdir(renders_dir):
    if fname.startswith('.') or (renders_dir / fname).is_dir():
        continue
    ...
```
Verifying the fix
After testing, the script successfully avoided "Unable to compute metrics for model" errors by properly ignoring hidden directories (.ipynb_checkpoints) and produced the expected output.
