Owner
Stacked on #4 (merge #4 first). Contains the single-scattering kernels (formerly #3) and wires them into the stream stage.
What this gives users: optional single scattering of light-source photons (Rayleigh and aerosol scattering towards each telescope), switched on with dlufd-propagate --scattering FILE. Off by default; output without the option is unchanged. Air-shower scattering is not included (future CORSIKA update).
New scattering table format (molecular/aerosol optical depths, aerosol albedo and asymmetry g; docs/scattering.md); Python dlufd.ScatteringTable, dlufd.scatter.
In the stage: primaries are scattered before their extinction; scattered photons go to their telescope's block, pass sky → ground and the efficiency envelope, and are not attenuated twice. Ledger factor scattering.
Checks (local): ctest 9/9, pytest 47 passed, pre-commit clean. Monte Carlo vs analytic single-scattering integral within 1.4σ; ls-beam formula vs integral 7e-5 relative. With scattering off, output is byte-identical to #4.
Limitations: the example scattering table is a toy exponential atmosphere; real MODTRAN-derived parameters still need to be added to the simulation models. One event is held in memory with scattering on.
