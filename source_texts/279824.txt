# CUDA GPU Performance Kernels

CUDA C++ implementations exploring progressive GPU optimization techniques — shared memory tiling, constant memory, unified memory, and warp-level primitives — benchmarked against CPU/naive baselines.

## Contents

| Folder | Problem | Techniques |
|---|---|---|
| `stencil-3d/` | 3D stencil computation (4 versions) | Naive global memory → shared-memory tiling with halo → loop unrolling → pinned host memory |
| `prefix-sum-scan/` | GPU prefix sum (Blelloch scan) | Block-level upsweep/downsweep, offset propagation, copy-then-execute vs. Unified Memory (`cudaMemAdvise`, `cudaMemPrefetchAsync`) |
| `grid-search-optimization/` | Large multi-parameter grid search (5 versions) | CPU → CUDA port, tiling, Thrust-based implementation |
| `stencil-2d-3d-constmem/` | 2D/3D averaging-filter stencils | Constant memory filter coefficients, shared-memory tiling, `#pragma unroll` |

Each folder contains multiple versions of the same kernel, moving from a naive implementation to an optimized one, with correctness checked against a CPU reference.

## Build

```bash
make          # builds all problems
make clean    # removes binaries
```

Requires the CUDA toolkit (`nvcc`) and a CUDA-capable GPU.

## Report

`report.pdf` documents the objective, design, and performance results for each problem.
