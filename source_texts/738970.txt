Original prompt
Overview
Create a comprehensive GitHub Pages documentation website to visualize and explain the Cub3D raycasting engine project. The website should be hosted at https://oualidobbad.github.io/cub3d_mandatory/.
Requirements
1. Create docs/index.html - Main Documentation Website
Create a modern, responsive single-page website with the following sections:
Header Section
Project title: "Cub3D - Raycasting Engine"
Subtitle: "42 School Project - A Wolfenstein 3D inspired game engine"
Navigation menu
Section 1: Introduction
Brief overview of what Cub3D is
Inspired by Wolfenstein 3D
Technologies used (C, MiniLibX, Math library)
Section 2: Raycasting Explained
Create detailed visual explanations with diagrams (using SVG or CSS):
What is raycasting vs raytracing
How rays are cast from player's position
Field of View (FOV) concept - show that the project uses 60° FOV
How distance affects wall height (perspective)
The fish-eye effect and how perpendicular distance fixes it
Include a visual diagram showing:
```
Player → Rays fanning out → Hitting walls → Rendered as vertical slices
```
Section 3: DDA Algorithm Deep Dive
Based on the actual project code in dda_algo/, explain:
3.1 Player Facing Direction Detection
Reference facing_player() function from dda_algo.c:
How ray angle determines facing direction (up/down/left/right)
The angle ranges:
Facing up: π < angle < 2π
Facing right: angle < π/2 OR angle > 3π/2
3.2 Horizontal Intersection
Reference hor_inter.c:
Step-by-step explanation with diagrams
Initial intersection calculation: y = floor(py / TILE_SIZE) * TILE_SIZE
X calculation using tangent: x = px + (y - py) / tan(angle)
Step increments: y_step = TILE_SIZE, x_step = TILE_SIZE / tan(angle)
Visual grid showing horizontal line intersections
3.3 Vertical Intersection
Reference ver_inter.c:
Similar step-by-step with diagrams
Initial: x = floor(px / TILE_SIZE) * TILE_SIZE
Y calculation: y = py + (x - px) * tan(angle)
Step increments: x_step = TILE_SIZE, y_step = tan(angle) * TILE_SIZE
3.4 Choosing the Closest Hit
Reference dda_algo() function:
Calculate distance for both horizontal and vertical hits
Use Euclidean distance formula: sqrt((x2-x1)² + (y2-y1)²)
Compare and select the shorter distance
Track is_hor flag to know which wall was hit
Include animated or interactive diagram showing rays stepping through the grid.
Section 4: Wall Rendering & Projection
Reference render3d.c:
4.1 Perpendicular Distance (Fish-eye Correction)
Formula: dist_perpo = distance * cos(ray_angle - player_angle)
Visual showing why this is necessary
4.2 Wall Height Calculation
Formula: wall_height = (TILE_SIZE / dist_perpo) * dist_proj_plan
Where dist_proj_plan = distance to projection plane
Closer walls appear taller, farther walls shorter
4.3 Wall Drawing
Calculate wall start: (WIN_HEIGHT / 2) - (wall_height / 2)
Calculate wall end: (WIN_HEIGHT / 2) + (wall_height / 2)
Clamp values to screen bounds
Section 5: Texture Selection & Mapping
Reference select_texture() function:
5.1 Which Texture to Use
Create a visual diagram showing:
If horizontal hit (is_hor = true):
Facing up → North texture (NO)
Facing down → South texture (SO)
If vertical hit (is_hor = false):
Facing left → West texture (WE)
Facing right → East texture (EA)
5.2 Texture Coordinate Calculation
tex_x = hit_position % TILE_SIZE (where along the wall we hit)
tex_y = (y - wall_start) * (64.0 / wall_height) (vertical texture mapping)
Include visual showing how 64x64 texture maps to different wall heights.
Section 6: Project Architecture
File structure diagram
Flow chart of the rendering loop:
```
Main Loop → Cast Rays → DDA Algorithm → Compute Wall → Select Texture → Draw
```
Section 7: Key Constants
Display project constants from header.h:
TILE_SIZE: 64
WIN_WIDTH: 1920
WIN_HEIGHT: 1080
NUM_RAYS: 1920
MOVE_SPEED: 2
ROTATION_SPEED: 0.02
Section 8: Code Snippets
Include syntax-highlighted code snippets from the actual project files with explanations.
2. Styling Requirements
Modern dark theme (similar to Wolfenstein aesthetic)
Responsive design (mobile-friendly)
Smooth scrolling
CSS animations for diagrams
Use CSS Grid/Flexbox for layouts
Custom fonts (use Google Fonts or similar)
3. Interactive Elements (Optional but Recommended)
Interactive 2D raycasting demo using HTML Canvas/JavaScript
Animated DDA algorithm visualization
Collapsible code sections
4. Assets
Create or include:
SVG diagrams for raycasting visualization
CSS-based grid visualizations for DDA
Favicon
5. GitHub Pages Configuration
Ensure the site works with GitHub Pages
Add appropriate <meta> tags for SEO
Include Open Graph tags for social sharing
