Contributor
Adds box/frustum query support to the octree: given a 3D region, return the pool indices of all objects whose AABBs overlap it.
Implementation
aabbOverlapsBox helper (module-level, octree.ts) — flat-buffer AABB vs. 6-scalar box overlap test, consistent with the existing rayIntersectsAABB pattern (direct typed-array access, no allocations).
Octree.queryBox(minX, minY, minZ, maxX, maxY, maxZ): number[] — iterative DFS reusing the pre-allocated _stack (zero GC). Early-exits if the query box misses the root; prunes child subtrees that don't overlap.
Tests (octree-box-query.test.ts)
Written first (TDD). Covers: empty tree, full containment, no overlap, partial overlap, multi-object filtering, root-miss early exit, full-bounds query, subdivided-tree traversal, and boundary-touch edge case.
Usage
```
const octree = new Octree(nodePool, aabbPool);
octree.setBounds(-50, -50, -50, 50, 50, 50);

const a = aabbPool.allocate(); aabbPool.set(a, 5, 5, 5, 6, 6, 6);
const b = aabbPool.allocate(); aabbPool.set(b, 30, 30, 30, 31, 31, 31);
octree.insert(a); octree.insert(b);

octree.queryBox(0, 0, 0, 10, 10, 10); // → [a]
octree.queryBox(-50, -50, -50, 50, 50, 50); // → [a, b]
```
