Summary
GLES-compatible projectionless composition-layer rendering path (controller rays, grab-bar, corner handles, background compositing) alongside the existing OpenXR pipeline.
GPU-accelerated depth inference (MiDaS/YOLO26 GPU delegates) with a benchmarked, table-driven AI-3D Auto mode that picks model/tier/resolution-cap per resolution class and passthrough state.
Fixes for real-world Apollo/Sunshine connection failures reported by users: pairing timeout (was capped at 120s, now waits indefinitely for PIN entry per protocol), a post-pairing TLS settle race, optional :port input support, and a host-selection bug where a server reachable via NAT port-forwarding through another host's IP could be mismatched against a different already-paired host.
Various stability/UX fixes accumulated along the way (composition-layer crashes, invisible cursor/status-bar under GLES, stuck latency readout, blurry video).
Test plan
On-device (Quest 3) manual pairing/streaming test against Apollo (VM) and Sunshine (desktop) sharing the same NAT-forwarded IP on different ports - confirmed the correct host now streams.
On-device verification of the pairing-timeout and TLS-settle-delay fixes against a real Apollo instance with live PIN entry.
Full AI-3D Auto-mode table verification across all resolution/passthrough combos per the design plan (in progress).
