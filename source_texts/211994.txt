Summary
Adds a "Solid Render" mode (fr-v4f) that gives the user's IFS attractor a raytraced look, mirroring the existing flame-render architecture:
src/fractal/voxel.ts — pure core: bounds pilot (trimmed-quantile sampling), chunked density-grid accumulation (reuses stepOrbit/plotPoint), RGBA8 3D-texture packing with log-density normalization.
src/app/voxel-worker-core.ts + voxel-worker.ts — a Web Worker session mirroring the flame renderer's chunking/OOM-guard/throttled-emit pattern, with a proactive+reactive memory guard and a resolution snapped to 32-voxel steps.
src/app/voxel-material.ts — a GLSL3 fullscreen-quad shader raymarching the log-density isosurface: gradient normals, a hard shadow ray, density-sampled AO, Lambert diffuse + Blinn-Phong specular.
src/app/scene.ts, state.ts, persist.ts, ui.ts, index.html — SolidParams, reducers, URL/localStorage persistence (absent block defaults quietly, malformed rejects, values clamp/snap), and the control panel (surface level, light angle/height, ambient, quality, detail).
src/app/main.ts — wires it all together: unlike the flame render (frozen camera, 2D image), the voxel grid is world-space, so the camera stays live while accumulation converges. Threshold/light/ambient are pure GPU uniforms (no worker round-trip); a genuine resolution change restarts accumulation in a fresh worker.
Verified in-browser via Playwright: the GLSL3 shader compiles with no console errors, the default preset renders a crisp lit/shadowed solid, the threshold/light/ambient sliders are live, orbiting works while the render is converging, "Back to Explorer" restores the point cloud, and the flame renderer still works unchanged. No default-value tuning was needed.
Filed a follow-up (fr-1kt) to support the fr-6us cosine-gradient palettes for voxel coloring.

Only 'By Transform' reached the solid render: accumulateVoxels
hard-coded the per-transform palette into the voxel color mean. Now the
bounds pilot also records the attractor's trimmed per-axis + radial
extents (VoxelBounds.color, the voxel counterpart of the cloud bounds
buildColors normalizes against), and the hot loop colors each plotted
point per the active ColorMode — height/radius via a 256-entry ramp LUT,
position via the normalized-xyz mapping, uniform as the flat cyan.

The ramp formulas and constants are extracted from buildColors into
shared single definitions in color.ts, with drift-guard tests pinning
the LUT to buildColors' output, plus a test that coloring never touches
the RNG (same seed => byte-identical geometry in every mode). Wired
through the voxel worker start command and enterSolidMode; browser-
verified (height gradient, uniform cyan, by-transform regression).
