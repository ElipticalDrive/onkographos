Pull request overview
This PR introduces a Numba-accelerated implementation of per-cell ray distance accumulation for Fibonacci-lattice lateral sampling, aiming to speed up SphericalMesh.ray_distances_per_region by avoiding a Python loop over rays.
Changes:
Add numba (and llvmlite) as dependencies and update lockfile metadata.
Add src/raytracer/_numba_tracing.py implementing parallel batch tracing for Fibonacci sampling.
Route SphericalMesh.ray_distances_per_region through the new batch tracer when sampling is FibonacciSphericalSampling, and add tests for the new tracing helpers.
