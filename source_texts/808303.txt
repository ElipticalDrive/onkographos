Hash the final patched model for scene-probe provenance
On a freshly prepared workspace, this hash is captured immediately after the scene probe is inserted, but _ensure_human_asset_finite_probe and _ensure_render_output_finite_probe subsequently modify the same model.py. The emitted value therefore does not identify the source actually used for training; moreover, a rerun returns the final file hash because the scene patch is then already present, making otherwise identical provenance depend on workspace history. Compute this value after all three model patches, or hash only the scene-probe payload.
