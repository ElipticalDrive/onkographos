Summary
F2 look round: real Doom-style light diminishing + authored dark sectors, a wall close-up detail pass, palette-style hurt tint, and the nav hint strip moved out of dead-centre.
Distance falloff + dark sectors (biggest critic gap): WORLD_FS now applies s * (1.6 - vDist * 0.115), banded to 24 steps like a colormap — a lit face reads ~60% at 10 tiles and near-black before the fog plane. computeLight detects pockets (dead-end cells with ≥3 solid neighbours and no authored light) and crushes them to 0.12 with a 0.7 fade on adjacent mouth cells; lamps never spawn in pockets, so closets/maintenance runs read genuinely dark in every mission without touching content files. World floor dropped to 0.05; sprite readability is untouched (enemy uFloor 0.85, item floor 0.45, glow band fullbright).
Gameplay-critical cells are never pocketed: exit cells and cells holding console/workstation/npc entities keep their light — a required terminal in a 3-wall nook can't be blackened. Pickup nooks still darken (items carry the 0.45 floor — the "glow in a dark closet" Doom look).
Keeps feel's F2 fire light: the uFire reach term still adds tool-coloured light after L = max(dim, uFloor), so muzzle/tool flashes genuinely light up the new dark sectors. Lowered monster pain-flash threshold (0.55) kept.
Luminance probe (new test hook): __cd.lightProbe(dist, withImages) renders a lit corridor and measures median floor-strip luma at ~2 vs ~10 tiles plus the darkest run's centre-band luma. npm run look:contrast gates far/near ≤ 0.7 and dark ≤ 70 — current: 0.45/0.41/0.41 ratios and dark 28.5–38.6 on m01/m06/m12. darkestLine prefers runs whose backdrop cell is also dark so probe sprites aren't measured against a lit doorway.
Wall close-up detail: new paint helpers (vShade gradient, seam, bolt, drip, cableDrop) applied per family — panel seams + bolt rows on wall-panel, deck seams + raceway cable drop on wall-tech, weld beads + drips on wall-ribs, cracks + patched block on wall-brick/wall-brick2, plus ceiling soot and floor-grime gradients everywhere. New wall-panel2 alt family (service plate + conduit column + SVC stencil) mixed into office/bullpen themes so adjacent faces vary.
Hurt tint: POST_FS remaps to a luminance-preserving red shift (mix(c, red, uHurt) where red keeps per-channel texel detail) instead of the flat monochrome wash — same peak/hold/decay timing from feel.ts, plus the directional edge burn.
Nav strip: ESC MENU - M MAP - L LOG is now a dim corner plate at the lower-left above the status bar, shown only for the first ~9 s of a mission (pause menu still lists all keys). Aim prompts are untouched.
Cross-path edits (all narrow / backward-compatible)
src/ui/hud.ts drawPrompt: footer moved from centred lines to corner plate (arsenal builder owns status-bar layout — this only touches the nav strip).
src/main.ts: prompt.footer window (first ~9 s, suppressed once a tool is switched or at mission end), __cd.lightProbe debug hook, and buildLevel(..., mission.entities) — optional trailing param so pocket dimming skips required interactables.
tools/look-contrast.mjs: added the light-probe gate rows (own tooling).
Gates
npm run verify (570 tests), npm run build, npm run e2e (8/8), npm run look:contrast (18/18 contrast rows + 3/3 light probes) all pass on top of current main (#38 feel, #41 levels, #40 enemies). Played in a real browser at 1920×1080 dsf 2 — M01, M06, M09, M12, dark-sector run, and a live worm hit for the hurt tint.
