This pull request implements a NeRF workflow alongside the existing Dust3r implementation.
Key features:
Pose Estimation: Leverages Dust3r's pairwise inference to estimate camera poses, which are then used to bootstrap the NeRF process.
NeRF Implementation: A C# VoxelGridNeRF class implements a discrete voxel grid optimization. It initializes from the Dust3r point cloud (occupancy masking) and refines color and density using a ray-marching approach.
CPU Optimization: The NeRF training loop is optimized for CPU using Parallel.For with thread-local storage to avoid locking overhead, ensuring it runs on any hardware (NVIDIA, AMD, CPU-only).
Mesh Extraction: Includes a custom Marching Cubes implementation to convert the optimized voxel grid into a standard mesh.
UI Integration: Adds a workflow selector to the main toolbar.
