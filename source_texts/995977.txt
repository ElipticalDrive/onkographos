Part of epic #3.
Size: M (relative).
References: ADR 0014: Procedural generation, ADR 0023: Fixed-point representation.
Acceptance criteria
Implement a Unity-independent 2D deterministic noise primitive in Core using an algorithm approved by the owner and integer or fixed-point arithmetic.
Specify the seed, coordinate, spatial-scale, interpolation, output-range, and lattice-boundary semantics so identical inputs produce identical outputs across supported runtimes.
Add dual-runner tests with fixed known-answer vectors and coverage for repeatability, seed/coordinate variation, negative coordinates, lattice boundaries, and output bounds.
Keep generation parameters data-driven and document the noise contract; do not expand scope to town/industry placement or a complete map-generation pipeline.
Notes
The owner selected fixed-point gradient noise (Perlin-style) and approved the Q32.32 sampling contract in ADR 0027. The implementation and dual-runner tests were verified on merged PR #91 (squash commit 1dd6c95fe1abd4bf34ce64e0d98dc61d6f1d34f8). This issue delivers a reusable noise primitive, not an integrated map generator. The owner wants to validate actual map-generation randomness and visual distribution later, after the primitive is wired into map generation.
