Description
Native NeRF Adam can return a finite pointwise RGB loss with nonfinite optimizer moments, or initialize partial native state before throwing. Reproduced on main 78dd7a6af with a real tiny NeRF: finite weight_decay=1e30 returns loss0.06261587 and8 nonfinite moment tensors; finite lr=1e38 throws after8 moment entries initialize. Actual #17808 ray source likewise returns finite rendered loss with10 nonfinite moments.
This admits complete owned point/direction/RGB observations and collection policy before native effects, checks native objective/derivatives and resulting registered state/moments, and reuses the existing optimizer-only recovery protocol. Exceptions/nonfinite candidates restore registered values/moments/prior gradients/mixed modes while retaining parameter objects and earlier accepted batches. Train/step/save/load share one native trainer lock. Native pointwise MSE/Adam formulas, cameras and volume law stay intact.
Assigned acceptance criteria
Admit complete owned finite compatible point/direction/RGB tensors and collection/batch/epoch/work policy before pointwise stochastic/native work; retain legacy pointwise RGB semantics and feat(nerf): learn density from explicit ray RGB observations (fixes #17807) #17808 named ray objective during actual-source compatibility checks.
Validate native Adam policy, finite objective/derivatives and resulting registered model/buffer/moment candidate; publish success only after the complete native update passes.
Recover ordinary exceptional/nonfinite native update failures to prior registered values/moments/gradients/mixed modes without replacing parameters; retain earlier accepted batches and allow corrected retry.
Serialize trainer-native training/save/load operations and verify independent native MSE/Adam weights/moments, real finite-policy overflow, partial native exception, observation ownership/late collection rejection and existing NeRF renderer/camera consumers.
Compatibility and limits
Actual-source #17808 integration preserves its differentiable rendered RGB objective, named metadata, owned ray data and route worker ownership; its native update is wrapped in this existing two-argument optimizer context and train_rays uses the same trainer lock. 156 tests pass, including independent native float32/64 rendered-ray recovery/retry references and prior worker cancellation/ordering controls. Shared trainer methods require deliberate merge resolution; no mechanical merge guarantee. Legacy batch_size=10000 route behavior remains admitted. See backend/ml/nerf/TRAINING_TRANSITIONS.md.
Bounds:100,000 points/batch rows,100 epochs,10,000,000 point-epochs; invocation bounds, not calibrated latency/full-memory guarantees. Snapshots add model/moment memory overhead. Ordinary native Adam/process-local trainer operations; no new clipping, ray-learning algorithm, checkpoint restore atomicity, external render/mutation ownership, RNG/whole-epoch/custom-hook/custom-optimizer/cross-process/fatal-device rollback, scene quality, real cameras or providers. CPU float32/64 tested; CUDA admitted untested.
