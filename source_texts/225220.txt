Produce gltf encoded meshes from label images with marching cubes. Avoid intermediate stardist representation (for speed and fidelity).
Pipeline:
```
Input: 3D label image labels of shape (Z, Y, X) (e.g. numpy.ndarray, integer labels).

Per label:

    Extract a binary mask for that label.

    Run marching cubes to get vertices and faces.

Build a mesh from vertices/faces.

Export to glTF (either one glTF per label or one glTF with multiple mesh primitives).
```
Consider using:
```
`scikit-image` for marching cubes

`trimesh` for mesh handling and glTF export
```
```
pip install numpy scikit-image trimesh pygltflib
```
```
import numpy as np
from skimage import measure
import trimesh

def label_to_mesh(label_volume, label_value, spacing=(1.0, 1.0, 1.0)):
    """
    Convert a single label in a 3D label image to a mesh using marching cubes.

    Parameters
    ----------
    label_volume : np.ndarray
        3D array of integer labels, shape (Z, Y, X).
    label_value : int
        Label to extract.
    spacing : tuple of float
        Voxel spacing in (Z, Y, X) order.

    Returns
    -------
    mesh : trimesh.Trimesh or None
        Mesh for the given label, or None if no voxels for that label.
    """
    mask = (label_volume == label_value)
    if not np.any(mask):
        return None

    # marching_cubes expects (z, y, x) volume; mask is already that
    # level=0.5 for binary mask (surface between 0 and 1)
    verts, faces, normals, values = measure.marching_cubes(
        mask.astype(np.float32),
        level=0.5,
        spacing=spacing
    )

    mesh = trimesh.Trimesh(vertices=verts, faces=faces, vertex_normals=normals, process=True)
    return mesh

def export_label_meshes_to_gltf(label_volume, labels=None, spacing=(1.0, 1.0, 1.0),
                                out_path="labels.gltf", separate_files=False):
    """
    Export meshes for labels in a 3D label image to glTF.

    Parameters
    ----------
    label_volume : np.ndarray
        3D label image (Z, Y, X).
    labels : list[int] or None
        Which labels to export. If None, uses all unique labels except 0.
    spacing : tuple[float]
        Voxel spacing (Z, Y, X).
    out_path : str
        Output path for combined glTF (if separate_files=False).
    separate_files : bool
        If True, writes one glTF per label (e.g. label_1.gltf, label_2.gltf).
        If False, writes a single glTF with multiple meshes.
    """
    if labels is None:
        labels = np.unique(label_volume)
        labels = labels[labels != 0]  # often 0 is background

    meshes = {}
    for lv in labels:
        mesh = label_to_mesh(label_volume, lv, spacing=spacing)
        if mesh is not None and len(mesh.faces) > 0:
            meshes[lv] = mesh

    if separate_files:
        # One glTF per label
        for lv, mesh in meshes.items():
            mesh.export(f"label_{lv}.gltf")
        return

    # Single glTF with multiple meshes: use a scene of multiple geometries
    # Trimesh can export a Scene to glTF.
    scene = trimesh.Scene()
    for lv, mesh in meshes.items():
        # Name each geometry by label
        mesh.visual = mesh.visual  # ensure visual exists
        scene.add_geometry(mesh, node_name=f"label_{lv}")

    scene.export(out_path)

# Example usage
if __name__ == "__main__":
    # Example: synthetic 3D label volume
    Z, Y, X = 64, 64, 64
    labels = np.zeros((Z, Y, X), dtype=np.int32)

    # Two simple labeled spheres
    zz, yy, xx = np.mgrid[0:Z, 0:Y, 0:X]
    sphere1 = (xx - 20)**2 + (yy - 20)**2 + (zz - 20)**2 < 10**2
    sphere2 = (xx - 40)**2 + (yy - 40)**2 + (zz - 40)**2 < 8**2

    labels[sphere1] = 1
    labels[sphere2] = 2

    # Voxel spacing (e.g. mm)
    spacing = (1.0, 1.0, 1.0)

    # Export all labels into a single glTF file
    export_label_meshes_to_gltf(labels, spacing=spacing, out_path="example_labels.gltf",
                                separate_files=False)
```
Tweaks
Spacing
If volume has physical spacing (dz, dy, dx) from e.g. NIfTI, DICOM, or TIFF metadata, pass that into spacing keeping the mesh in real‑world units.
Label selection
For processing subsets only, pass labels=[1, 3, 7] etc.
Smoothing / cleanup:
Post‑process each Trimesh (e.g. mesh.simplify_quadratic_decimation, mesh.remove_degenerate_faces) before exporting if the meshes are too dense or noisy.
