Closes #3.
Adds the greedy chunk mesher to core, exposed to the page through wasm. It takes a chunk plus a one-block border of its 26 neighbours and returns four meshes (opaque, cutout, glass, water) as flat arrays. Faces between two solid blocks are culled, coplanar faces of the same block merge into quads, and every vertex carries an ambient occlusion level. Details are in the new paragraph in docs/design.md.
Design calls
The mesher is given the neighbours' border blocks instead of other chunks, so it stays a pure function of one padded input and can run in a worker later.
A neighbour that is not loaded counts as "unloaded": a face looking into it is not drawn and it casts no occlusion. The caller decides when to re-mesh once a neighbour loads.
Faces merge only when block, tile and all four corner occlusion levels match, so merging never changes the shading.
Merged quads are longer than one tile; the shader repeats the tile across them. That shader change belongs to the worker-meshing PR (Meshing in a Web Worker #4).
Water's surface sits 0.12 blocks below the block top so shorelines read. Side faces follow it unless water is stacked above.
A quad is split along the darker diagonal of its four occlusion levels so a lone dark corner shades symmetrically.
Where there is no chunk (past the world edge) the caller supplies the border block; the mesher only knows loaded and unloaded.
Output is four meshes, one per draw pass, so the renderer can order opaque, cutout, glass and water without sorting.
Tests: 35 Rust tests in core (culling, merging, occlusion, borders, unloaded neighbours, per-pass output) and web/src/mesh.test.ts for the wasm boundary.
