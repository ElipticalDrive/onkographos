Outcome
This makes the image renderer explicitly forward-only and spends its complexity budget on runtime, image quality, and clear APIs. Geometry, constraints, and parameterized SDF evaluation remain JAX-native and differentiable.
replaces fixed-step closest-approach tracing with early-exit sphere tracing, a maximum view distance, and an explicit TraceResult
reconstructs narrow silhouette misses in screen space, removing hard hit/miss outlines without restoring differentiable visibility
removes render-time jax.grad, Newton/bisection gradient tricks, the AO pass, and the functionalize_render inverse-rendering API
uses symmetric central-difference normals, Cook–Torrance GGX lighting, improved single-ray soft shadows, reflections, refraction with traced Schlick-Fresnel reflections, and SSAA
filters environment maps bilinearly, uses them for ambient color, applies configurable exposure and ACES tone mapping, and offsets every secondary ray beyond the configured hit band
fixes grazing-angle glass rays re-hitting their exit surface, which caused concentric ringing and noisy refraction artifacts
caches the module-level JIT across renders while passing geometry/material parameters dynamically, so parameter edits stay correct without recompilation
introduces small Camera, Scene, and validated RenderSettings abstractions with draft, balanced, and high_quality presets
rewrites the render and renderer-profile notebooks around the forward path and removes the obsolete inverse-render fitting notebook
adds a forward-rendering guide and reproducible high-resolution gallery generator
Rendering modes
The panels below are generated by this branch using the public renderer API and the 3×3 high-quality preset. The glass lens sits in front of the red sphere and gold torus so the displaced geometry is visible through it.
Quality presets
draft: direct lighting, reconstructed silhouettes, one sample per pixel
balanced: soft shadows and 2×2 SSAA
high_quality: tighter surface precision, denser shadow sampling, and 3×3 SSAA

Compilation remains roughly 1–1.5 seconds on the first call. Repeated renders reuse the compiled renderer instead of constructing a new JIT closure for every public call. Balanced now traces four subpixel rays deliberately; despite that quality increase, it remains about 7× faster than the old default path.
Breaking changes
removes functionalize_render
removes the AO controls and differentiability-oriented fd_normals, trace_mode, and bisect_steps controls
replaces the old optimization-oriented Camera/Scene Fluent nodes with immutable forward scene data
_sphere_trace returns TraceResult with hit/step data plus closest-approach data used for contour reconstruction
The project already warns that its API is unstable; the new structured API is documented in the README, Quarto guide, API reference, and notebooks.
