Implements the stochastic Gaussian rendering algorithm from arXiv 2503.24366 as a pure-PyTorch drop-in replacement for the CUDA rasterizer, enabling gradient-based training without any C extensions.
Algorithm
Implements Listing 1 from the paper exactly. For each pixel, iterate over all overlapping Gaussians in unsorted order:
```
z ← ∞,  C ← background
for each Gaussian i in unsorted order do
    compute α_i and depth z_i
    sample u ~ U(0, 1)
    if u < α_i  AND  z_i < z  then
        C ← c_i ;  z ← z_i
    end if
end for
```
The winner is the stochastically-accepted Gaussian (u < α_i) with the minimum depth. This is an unbiased estimator of the standard alpha-compositing render — no depth sorting required. num_samples controls how many independent runs are averaged per pixel to reduce variance. num_samples ≤ 0 falls back to full deterministic depth-sorted alpha-compositing.

3D and 4D (temporal, rot_4d) Gaussian support; handles precomputed or raw scale/rotation covariances and SH/precomputed colours
