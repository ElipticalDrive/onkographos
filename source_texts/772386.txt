Why do we need this?
We lacked a way to replay recorded Unitree G1 SQLite datasets (g1_sf_office.db) onto live G1 sensor streams and reconstruct a colored 3D triangle mesh in real time from the RealSense RGB-D stream.
What is this feature?
RgbdMesh: Real-time RGB-D TSDF mesh module that pairs color_image and depth_image with ￹camera_info and tf, integrates them into spatially chunked Open3D ScalableTSDFVolume instances (with boundary padding so adjacent chunks ￹stitch without seams), and publishes chunks on mesh: Out[TriangleMesh]
How to manually run this
```
# defaults to `g1_sf_office.db` dataset
uv run dimos run unitree-g1-replay-mesh 
```
Or pass a path to any G1 recorded .db file thar shares the same topic structure as g1_sf_office.db bag.
```
uv run dimos --replay-db /path/to/recording.db run unitree-g1-replay-mesh 

# or via module config:
uv run dimos run unitree-g1-replay-mesh --g1replay.dataset ￹/path/to/recording.db
```
In Rerun, observe RGB-D TSDF mesh builds up in real-time as the G1 walks through the office.
