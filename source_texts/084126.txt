Goal
Generate BrainMirror's real IXI reference volume from 581 Kaggle-mounted T1 MRI scans after full P1 QC and brain masks. Never call an MNI152 template or synthetic phantom a 581-subject IXI average.
Implementation available
scripts/ixi_template_pipeline.py in phase/anatomy-workspace: read approved train-only manifest, use SimpleITK affine registration to a reviewed reference, mask overlap gate, streaming mean / SD / coverage NIfTI, private hashed audit receipt.
scripts/export_anatomy_preview.py: export reviewed brain-only reference to preview JSON (remain private until allowed), optional corresponding atlas labels.
UI already supports importing approved preview JSON or original NIfTI locally.
Blockers
Run actual P1 QC on 581 IXI T1 NIfTIs in the private Kaggle dataset.
Generate/review brain masks for all eligible train subjects; confirm source consent/license/provenance and anatomical registration reference.
Lock subject-level train/dev/test and provide private approved manifest.
Run affine candidate construction (or upgrade to unbiased nonlinear template), visual/quantitative QC and independent scientific review.
Transfer only reviewed, permissible brain-only reference to webpage; keep individual scans/identifiers off public GitHub.
Acceptance
Verified source cohort count, independent QC, training-only subject list, reproducible registration/quality report, template mean / SD / coverage, privacy review, IXI_TEMPLATE_BUILT=TRUE only after real computation. This issue remains open until actual Kaggle evidence exists.
