Integrator is a sequence of components to integrate radiance fields from selected dataset. Typically, Integrator can hold components such as:
Encoders
MLPs
Samplers
Renderers (& Losses)
This structure is highly inspired from nerfstudio's implementation. However, care must be taken to properly construct automatic differentiation graph of mlx. Due to the lack of tensor manipulation implementation in mlx (e.g., searchsorted not implemented, etc), those unimplemented features should be done via other tensor libraries (e.g., numpy, torch, etc), with casting mlx.arrays back and forth. mlx fails to construct computational graph whenever those array conversion is included in loss calculation function (which is fed into mlx.nn.value_and_grad), hence we have to properly separate the actual loss calculation function and the auxiliary functionalities.
In short,
We cast mx.array into torch.tensor to use torch.searchsorted, as there's no such implementation in mlx
If those conversion is included in the loss calculation, mlx throws error
This can be alleviated by changing typical NeRF loss calculation procedure
From:
```
@mx.compile
def loss(batch_rays, gt):
```
