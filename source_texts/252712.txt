I would like to render my volume using Standard Deviation Intensity Projection(something similar to average intensity projection), and I think it could be simply done if I can modify vtkVolumeFS.glsl.
In polydataMapper, I can easily replace Fragment Shader code like below :
```
       
        const mapperSpecificProp = mapper.getViewSpecificProperties();
        mapperSpecificProp['OpenGL'] = {
            ShaderReplacements: [],
            FragmentShaderCode:{some_fragment_shader_code}
        }; 
```
But I cannot find any way I can do this using vtkVolumeMapper.
Is there any way I can customize volume mapper shader code? or is there any simpler way I can implement standard deviation intensity projection using vtkVolume?
