What this adds
TextureGenerator returns deterministic 16×16 ImageTexture instances from block type + seed.
Organic/value-noise mode for grass, dirt, sand, log, and leaves with 3–4 color palettes and hard quantization.
Manual Worley/cellular mode for stone and iron ore to create chunky cell/flagstone structure.
Config-driven TextureBlockRegistry / TextureBlockConfig resources; adding a block is data-only.
Iron ore uses the stone cellular base plus sparse deterministic rust-colored speckles.
Labeled preview scene at scenes/texture_generator_preview.tscn.
Headless determinism/size/ore-speckle gate and preview artifact workflow.
Scope boundary
No chunk rendering, meshing, placement, world generation, or Android export files were changed.
Determinism
The gate generates each configured block twice with seed 734921 and byte-compares the resulting 16×16 image data. It also verifies that changing the seed changes dirt output.
Runtime choice
Generation is runtime-only and cached by (block_type, seed). A full preview is only 8 × 256 pixels of source image data, so avoiding generated asset files keeps the repository free of external/downloaded textures while making future block additions data-driven.
