Parent epic: #39
Goal
Reconstruct a stable scene-linear HDR image from current color and reprojected history while rejecting invalid or stale samples.
Implementation tasks
Implement a Slang temporal resolve that samples current color, velocity, depth, previous history, and optional validity/reactive inputs using the documented motion/jitter contract.
Reject off-screen, invalid clip/depth, first-frame, and disoccluded history in the correct previous-frame depth space; camera movement alone must not cause false depth mismatch.
Implement neighborhood bounds/variance clipping and configurable history weighting, with robust handling of bright HDR values and meaningful material/motion/reactivity signals.
Handle background/sky history according to the contract and keep optional masks well-defined when their producer is disabled or not implemented yet.
Match exposure/pre-exposure normalization so exposure changes do not blend incompatible radiance; keep tone mapping/display gamma outside the temporal accumulation.
Add reconstruction/filter controls without mandatory sharpening and make a current-frame-only fallback available for invalid history.
Acceptance criteria
Constant input remains constant; no-history and fully rejected history return the current image.
Known synthetic translation reprojects to the independently expected previous UV and depth; pure jitter does not appear as object movement.
A newly revealed bright surface and a moved occluder reject stale history instead of creating long persistent trails.
High-radiance, zero-depth/background, very fast motion, and invalid-vector inputs remain finite.
Document convergence, clipping/weight tradeoffs, and visual limitations rather than claiming perfect ghost-free output.
Relevant code and documentation
shaders/brdf_common.slang
shaders/post_process.slang
cmake/Shaders.cmake
src/renderer/core/RenderGraph.cpp
Validation evidence
Add small synthetic GPU cases for constant HDR, known motion, depth rejection, bright disocclusion, and exposure normalization; also capture thin edges and moving specular highlights. Keep math tests independent of implementation.
Engineering requirements
Use Vulkan 1.4 dynamic rendering/synchronization2, Vulkan-Hpp RAII for engine-owned Vulkan objects, VMA for allocations, and Slang for engine-owned shaders. Follow docs/coordinate-conventions.md: reverse-Z, a negative-height scene viewport, and column-major matrices. Preserve raster fallbacks and existing GPU indirect drawing. Keep feature resources in focused managers and use the render graph for ordering and declared resource access. Include meaningful validation evidence and document any supported-mode limitations.
Dependencies and delivery order
Blocked by #48, #51, #54. Implementation exploration can proceed earlier, but these contracts/resources must be available for completion.
Delivery phase: 3 of 5 for epic #39.
Implementation complete; awaiting merge
Implemented and pushed in PR #60, now ready for review. The Slang HDR resolve reconstructs current samples with Catmull-Rom, reprojects color/metadata onto their respective grids, rejects identity/expected-depth/reactivity/offscreen/invalid history, and applies bounded HDR variance clipping and configurable weights. Both quality budgets pass and actual GPU sign/stale/reset mutations are detected. Sky/deformation/layered refraction fallbacks and measured detail/ghost tradeoffs are documented; no mandatory sharpening is applied.
Measured report and reproduction commands · Captures and result JSON · Downloadable Windows preview
The implementation checklists are complete. This issue remains open until PR #60 merges; its closing reference is included in the PR. Initial support is native-resolution 1x TAA, with documented current-frame fallbacks for unsupported motion and layered transparency.
