Implements T05 — Visible voxel baseline (ENG-12). Owned paths: crates/spall_mesh, crates/spall_render.
Stacked on agent/t07 (a sibling of agent/t06): T05 depends only on T03 + T04, both present in this base. Retargets to main once the foundation stack lands. spall_mesh imports only spall_voxel + spall_jobs; it does not use spall_structure.
spall_mesh (CPU surface generation, no GPU)
culled — one unit quad per exposed cell face, the reference surface.
greedy — coplanar faces merged by material, facing, and a full four-corner AO tuple. The AO-aware merge rule is fixed before baking vertex AO so a merged quad's bilinear AO equals every unit face it replaced.
build_volume_mesh — meshes a whole volume with a one-cell halo across brick seams for culling and AO, and returns a spall_jobs::JobToken over every brick revision + missing-neighbour sentinel. A halo brick arriving makes the mesh stale → re-mesh drops the now-occluded seam.
Canonical face order (FaceDir → plane → v → u), representation-independent BLAKE3 mesh_digest, pinned fixture digests.
fixtures module: cube, tunnel, checkerboard, negative-coordinate, adjacent-bricks, open-topped hollow box.
spall_render (wgpu, basic)
One opaque WGSL pipeline: CCW front faces, Depth32Float, back-face cull; sun + sky + baked-AO shading, plus normal and linear-depth debug views.
Camera free-fly with view/projection targeting wgpu NDC (z in [0,1]) and Gribb–Hartmann frustum culling.
MeshUploader — one growing, reusable vertex/index buffer with an explicit byte budget (over-budget uploads are rejected).
capture_scene — offscreen render to Rgba8UnormSrgb + depth, read back, write PNGs, then return.
Tooling
cargo xtask capture → builds and runs a new sandbox-capture binary (behind sandbox/client), rendering each acceptance shape to <out>/<shape>/{shaded,normals,depth}.png + summary.json. Exit 3 when no GPU adapter. xtask gains no dependency — it shells out, like smoke.
docs/validation.md, docs/architecture.md (dependency graph + renderer step 1), docs/dependencies.md (T05 section) updated. No change to the T05 task text or acceptance criteria.
