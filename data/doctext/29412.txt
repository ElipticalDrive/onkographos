# 4D · Volumetric

### Turn any video into a living, renderable **4D Gaussian Splat**.

Upload a clip → reconstruct an animated 3D scene → orbit it and scrub through time, right in your browser.

</div>

---

## What it is

**4D** is a full-stack web app that transforms ordinary video into a renderable **Gaussian
Splat**. You upload a video, the backend reconstructs a cloud of millions of oriented
gaussians, and a custom WebGL renderer lets you fly the camera around the scene.

It is **camera-aware** — it recovers the camera trajectory and picks the right kind of
reconstruction automatically:

| Your clip | Detected as | What you get |
| --- | --- | --- |
| A pan / fly-**around** an object | **Orbit** | Every frame is a *view*. They're registered into one shared world, **fused into a single walk-around 3D model** (opacity-weighted voxel merge), then scrubbed by a **multi-view photo-consistency filter** that removes depth-lift ghosts. |
| A **still** camera, moving subject | **Motion** | A **spacetime gaussian model** — the way modern 4DGS systems represent video. The background is fused ONCE into a static canvas (the subject is removed and the scene behind it filled in from the frames that saw it); the moving parts become flow-tracked gaussian **trajectories** with birth/death windows. The viewer interpolates them **continuously in time** — no frame snapping, and file size stops scaling with clip length for everything that doesn't move. |
| Nothing moves at all | **Still** | The fused canvas alone: one crisp, dense 3D still. |

You can also force the mode (Auto / Orbit / Motion) per scene. It ships with two engines:

| Engine | Runs | Fidelity | Needs |
| --- | --- | --- | --- |
| **Local** (default) | On this machine, now | Real, lightweight (monocular + multi-view fusion) | `ffmpeg`; optional `pose`/`depth` extras |
| **Cloud** | Hosted GPU provider | Photoreal | an API key in Settings |

> The local engine performs a real monocular reconstruction. **Camera-pose estimation**
> (OpenCV, the `pose` extra) is what lets an orbit clip fuse into true 3D; without it, every
> clip falls back to the per-frame 4D path — never worse, just less. **Depth** auto-upgrades
> to a real model (Depth-Anything on Apple MPS) when `torch` is installed (the `depth` extra),
> otherwise a fast heuristic is used. Both are auto-detected at runtime; no config needed.

## Architecture

```
web/   Next.js + Three.js   — flagship UI, custom 4D Gaussian-splat WebGL viewer
api/   FastAPI + SQLite      — uploads, job worker, storage, live SSE progress
data/  (gitignored)          — sqlite db + per-project video/frames/splat files
```

## Quick start

```bash
# one command boots both servers (installs deps on first run)
./dev.sh
```

Then open **http://localhost:3000**.

Or run them separately:

```bash
# backend  → http://localhost:8000
cd api && uv sync && uv run uvicorn app.main:app --reload --port 8000

# frontend → http://localhost:3000
cd web && npm install && npm run dev
```

### Optional extras (auto-detected)

```bash
cd api && uv sync --extra depth     # torch + Depth-Anything (real monocular depth, Apple MPS)
cd api && uv sync --extra pose      # opencv → camera-pose estimation → orbit clips fuse to 3D
cd api && uv sync --extra dev       # pytest (run the suite with `uv run pytest`)
```

The local engine auto-detects each and upgrades; no config needed.

## How it works (local engine)

1. **probe** — `ffprobe` reads duration / fps / resolution
2. **extract** — `ffmpeg` pulls N evenly-spaced frames
3. **depth** — monocular depth for the whole clip (**batched** through the model),
   then cross-frame **scale+shift alignment** so depth doesn't "breathe"
4. **register** — recover per-frame camera pose (ORB + essential matrix, scaled by depth);
   measure parallax → classify **orbit** vs **motion**
5. **reconstruct**
   - *Orbit:* every view is lifted by its pose into one world, **voxel-fused**
     (opacity-weighted) and **photo-consistency-pruned** against the source views.
   - *Motion:* the clip is **stabilized** (phase-correlation + ECC), split into a
     **static canvas** (per-pixel temporal median of color+depth over the frames where
     that pixel is quiet, disocclusions inpainted) and **dynamic trajectories** —
     DIS optical flow chained frame-to-frame with forward/backward verification,
     each track lifted to a gaussian with per-control-point 3D positions and a
     temporal opacity window.
6. **refine** *(optional — the "Refine" button, or `params.refine`)* — the
   gaussians are **trained**: a differentiable splatter (pure PyTorch, runs on
   Apple MPS — no CUDA kernels) renders the model against the source frames and
   optimizes every parameter (position, scale, rotation, opacity, color) by
   gradient descent, exactly the optimization step that defines real gaussian
   splatting. Orbit scenes get multi-view supervision (floaters that photobomb
   other views fade and are pruned); motion scenes supervise the static canvas
   with moving pixels masked out of the loss. Minutes, not hours: ≈2.6 it/s at
   300k gaussians on an M-series GPU.
7. **pack** — a single `.4dsplat` v2 + `manifest.json` (with the camera path)
8. **render** — the browser viewer paints the static canvas the moment its bytes
   arrive, streams the trajectories, sorts on camera motion / control-point
   crossings only (4-byte index per splat), and interpolates motion **continuously
   on the GPU** — smooth at any display refresh rate

Long jobs are **cancelable** from the UI and resume cleanly across restarts.
Every capability degrades gracefully: no OpenCV ⇒ no stabilization/tracking
(single-frame tracks), no torch ⇒ heuristic depth — never worse, only less.

## The `.4dsplat` format

A compact, self-describing little-endian container (see `api/app/pipeline/splat_format.py`
and `web/components/Splat/loader.ts`).

**v2 (spacetime)** — written by the engine now:

```
header(60B) · static block  S × 32B   pos f32[3] · scale f32[3] · rgba u8[4] · quat i8[4]
           · track records D × 32B   scale · color · quat · birth u16 · death u16 · pos_offset u32 · flags u32
           · position stream P × 12B f32[3] per alive control point per track
```

The static scene is stored **once** regardless of clip length; each dynamic
gaussian stores its trajectory. Typical motion clips come out **2–10× smaller**
than v1 at *higher* static detail. **v1** (independent per-timestep blocks) is
still read everywhere, so old scenes keep working.

from __future__ import annotations

from collections.abc import Iterator

from sqlalchemy import create_engine
from sqlalchemy.orm import DeclarativeBase, Session, sessionmaker

from .config import DB_PATH, DB_URL

# Ensure the data dir exists before SQLite tries to open the file (covers any
# code path that touches the DB before the app lifespan runs ensure_dirs()).
DB_PATH.parent.mkdir(parents=True, exist_ok=True)


class Base(DeclarativeBase):
    pass


# check_same_thread=False: the worker thread-pool touches the DB too.
engine = create_engine(
    DB_URL,
    # worker thread-pool + request handlers share the engine; give SQLite a
    # generous busy timeout so concurrent writes don't raise "database is locked".
    connect_args={"check_same_thread": False, "timeout": 30},
    future=True,
)
SessionLocal = sessionmaker(bind=engine, autoflush=False, expire_on_commit=False, future=True)


def init_db() -> None:
    """Create tables. Imported here to avoid circular imports at module load."""
    from . import models  # noqa: F401  (registers mappers)

    Base.metadata.create_all(bind=engine)


def get_session() -> Iterator[Session]:
    """FastAPI dependency yielding a session."""
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()

### api/app/events.py
```
"""In-memory pub/sub used to stream live job progress to SSE clients.

A single-process broker: the worker publishes progress dicts keyed by project
id; each connected SSE client gets its own ``asyncio.Queue`` subscription.
Because the worker runs in a thread-pool, publishes are marshalled back onto
the main event loop via ``call_soon_threadsafe``.
"""
from __future__ import annotations

import asyncio
from collections import defaultdict
from typing import Any


class EventBroker:
    def __init__(self) -> None:
        self._subs: dict[str, set[asyncio.Queue]] = defaultdict(set)
        self._loop: asyncio.AbstractEventLoop | None = None
        # last-known payload per project so a late subscriber gets current state
        self._last: dict[str, dict[str, Any]] = {}

    def bind_loop(self, loop: asyncio.AbstractEventLoop) -> None:
        self._loop = loop

    def subscribe(self, project_id: str) -> asyncio.Queue:
        q: asyncio.Queue = asyncio.Queue(maxsize=256)
        self._subs[project_id].add(q)
        if project_id in self._last:
            q.put_nowait(self._last[project_id])
        return q

    def unsubscribe(self, project_id: str, q: asyncio.Queue) -> None:
        subs = self._subs.get(project_id)
        if subs and q in subs:
            subs.discard(q)
            if not subs:
                self._subs.pop(project_id, None)

    def publish(self, project_id: str, payload: dict[str, Any]) -> None:
        """Thread-safe publish (callable from worker threads)."""
        self._last[project_id] = payload
        loop = self._loop
        if loop is None:
            return
        loop.call_soon_threadsafe(self._deliver, project_id, payload)

    def _deliver(self, project_id: str, payload: dict[str, Any]) -> None:
        for q in list(self._subs.get(project_id, ())):
            try:
                q.put_nowait(payload)
            except asyncio.QueueFull:
                # drop oldest, then enqueue latest
                try:
                    q.get_nowait()
                    q.put_nowait(payload)
                except Exception:
                    pass


broker = EventBroker()
```

### api/app/models.py
```
"""Database models: Project (one reconstruction job) and Setting (key/value)."""
from __future__ import annotations

import uuid
from datetime import datetime, timezone

from sqlalchemy import JSON, DateTime, Float, Integer, String, Text
from sqlalchemy.orm import Mapped, mapped_column

from .db import Base


def _uuid() -> str:
    return uuid.uuid4().hex


def _now() -> datetime:
    return datetime.now(timezone.utc)


class Project(Base):
    """A single video → 4D-splat reconstruction and its lifecycle state."""

    __tablename__ = "projects"

    id: Mapped[str] = mapped_column(String(32), primary_key=True, default=_uuid)
    title: Mapped[str] = mapped_column(String(200), default="Untitled scene")

    # queued | processing | ready | failed | canceled
    status: Mapped[str] = mapped_column(String(20), default="queued", index=True)
    engine: Mapped[str] = mapped_column(String(20), default="local")
    quality: Mapped[str] = mapped_column(String(20), default="balanced")
    params: Mapped[dict] = mapped_column(JSON, default=dict)

    # live progress
    progress: Mapped[float] = mapped_column(Float, default=0.0)   # 0..1
    stage: Mapped[str] = mapped_column(String(40), default="queued")
    stage_message: Mapped[str] = mapped_column(String(300), default="")
    error: Mapped[str | None] = mapped_column(Text, nullable=True)

    # stored artifacts (paths relative to the project dir)
    video_name: Mapped[str | None] = mapped_column(String(300), nullable=True)
    video_path: Mapped[str | None] = mapped_column(String(500), nullable=True)
    thumb_path: Mapped[str | None] = mapped_column(String(500), nullable=True)
    splat_path: Mapped[str | None] = mapped_column(String(500), nullable=True)
    manifest: Mapped[dict | None] = mapped_column(JSON, nullable=True)

    # source/output metadata
    duration: Mapped[float | None] = mapped_column(Float, nullable=True)
    fps: Mapped[float | None] = mapped_column(Float, nullable=True)
    width: Mapped[int | None] = mapped_column(Integer, nullable=True)
    height: Mapped[int | None] = mapped_column(Integer, nullable=True)
    frame_count: Mapped[int | None] = mapped_column(Integer, nullable=True)
    gaussian_count: Mapped[int | None] = mapped_column(Integer, nullable=True)
    splat_bytes: Mapped[int | None] = mapped_column(Integer, nullable=True)

    created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), default=_now)
    updated_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), default=_now, onupdate=_now
    )

    def to_dict(self) -> dict:
        def _iso(dt: datetime | None) -> str | None:
            # SQLite round-trips tz-aware datetimes as naive; re-attach UTC so
            # the serialized ISO string carries an offset and clients parse it
            # as UTC (not local time).
            if dt is None:
                return None
            if dt.tzinfo is None:
                dt = dt.replace(tzinfo=timezone.utc)
            return dt.isoformat()

        return {
            "id": self.id,
            "title": self.title,
            "status": self.status,
            "engine": self.engine,
            "quality": self.quality,
            "params": self.params or {},
            "progress": self.progress,
            "stage": self.stage,
            "stage_message": self.stage_message,
            "error": self.error,
            "video_name": self.video_name,
            "has_thumb": bool(self.thumb_path),
            "has_splat": bool(self.splat_path),
            "manifest": self.manifest,
            "duration": self.duration,
            "fps": self.fps,
            "width": self.width,
            "height": self.height,
            "frame_count": self.frame_count,
            "gaussian_count": self.gaussian_count,
            "splat_bytes": self.splat_bytes,
            "created_at": _iso(self.created_at),
            "updated_at": _iso(self.updated_at),
        }


class Setting(Base):
    """Simple key/value store for app settings (cloud provider, API key, defaults)."""

    __tablename__ = "settings"

    key: Mapped[str] = mapped_column(String(80), primary_key=True)
    value: Mapped[str | None] = mapped_column(Text, nullable=True)
```

### api/app/settings_store.py
```
"""Tiny typed accessor over the Setting key/value table.

Security note: the cloud API key is read **env-first** (``FOURD_CLOUD_API_KEY``)
so it can be kept entirely out of the database. Keys entered through the UI are
persisted in the local SQLite file in plaintext — fine for a single-user local
app, but the env var is preferred for anything shared. The HTTP API never returns
the key (only a boolean ``cloud_api_key_set``), so it is masked on read.
"""
from __future__ import annotations

import os

from .db import SessionLocal
from .models import Setting

CLOUD_KEY_ENV = "FOURD_CLOUD_API_KEY"

DEFAULTS = {
    "cloud_provider": "replicate",
    "cloud_api_key": "",
    "cloud_model": "",
    "default_quality": "balanced",
    "default_engine": "local",
}


def get_setting(key: str, default: str | None = None) -> str | None:
    if key == "cloud_api_key":
        env = os.environ.get(CLOUD_KEY_ENV)
        if env:
            return env
    with SessionLocal() as db:
        row = db.get(Setting, key)
        if row is not None and row.value is not None:
            return row.value
    return default if default is not None else DEFAULTS.get(key)


def cloud_key_from_env() -> bool:
    return bool(os.environ.get(CLOUD_KEY_ENV))


def set_setting(key: str, value: str | None) -> None:
    with SessionLocal() as db:
        row = db.get(Setting, key)
        if row is None:
            row = Setting(key=key, value=value)
            db.add(row)
        else:
            row.value = value
        db.commit()


def cloud_key_set() -> bool:
    return bool(get_setting("cloud_api_key", ""))
```

def delete_project_dir(project_id: str) -> None:

    if d.exists():
        shutil.rmtree(d, ignore_errors=True)


def dir_size_bytes(path: Path) -> int:
    total = 0
    if not path.exists():
        return 0
    for p in path.rglob("*"):
        if p.is_file():
            try:
                total += p.stat().st_size
            except OSError:
                pass
    return total

### api/app/worker.py
```
"""Single-process async job worker.

Jobs are enqueued by id; a long-lived consumer pulls them and runs the (CPU /
IO-bound) engine in a thread-pool so the event loop stays responsive. Progress
is written to the DB and fanned out to SSE clients via the event broker.
"""
from __future__ import annotations

import asyncio
import logging
import threading
import time
import traceback
from functools import partial

from . import storage
from .db import SessionLocal
from .events import broker
from .models import Project
from .pipeline.base import JobCanceled, JobContext
from .pipeline.registry import get_engine

log = logging.getLogger("fourd.worker")

MAX_RESTARTS = 3  # interrupted jobs resumed at most this many times, then failed

# Throttle DB persistence of progress: the live value still streams to SSE every
# tick via the broker, but SQLite is only written at stage boundaries / ~1 Hz.
_PERSIST_INTERVAL = 1.0
_persist_state: dict[str, tuple[str, float]] = {}


def _project_dict(pid: str) -> dict | None:
    with SessionLocal() as db:
        p = db.get(Project, pid)
        return p.to_dict() if p else None


def _set_progress(pid: str, stage: str, progress: float, message: str) -> None:
    # Always stream live (cheap, in-memory); persist to SQLite only at stage
    # changes or ~1 Hz so the depth/lift loops don't hammer the DB.
    prev_stage, prev_t = _persist_state.get(pid, ("", 0.0))
    now = time.monotonic()
    if stage != prev_stage or (now - prev_t) >= _PERSIST_INTERVAL:
        _persist_state[pid] = (stage, now)
        with SessionLocal() as db:
            p = db.get(Project, pid)
            if p:
                p.status = "processing"
                p.stage = stage
                p.progress = float(progress)
                p.stage_message = message
                db.commit()
    broker.publish(
        pid,
        {
            "type": "progress",
            "id": pid,
            "status": "processing",
            "stage": stage,
            "progress": float(progress),
            "stage_message": message,
        },
    )


def _finish_ok(pid: str, result) -> None:
    _persist_state.pop(pid, None)
    with SessionLocal() as db:
        p = db.get(Project, pid)
        if not p:
            return
        p.status = "ready"
        p.stage = "ready"
        p.progress = 1.0
        p.stage_message = "Ready"
        p.error = None
        p.splat_path = str(result.splat_path)
        p.thumb_path = str(result.thumb_path) if result.thumb_path else None
        p.manifest = result.manifest
        p.gaussian_count = result.gaussian_count
        p.frame_count = result.frame_count
        p.fps = result.fps
        p.duration = result.duration
        p.width = result.width or p.width
        p.height = result.height or p.height
        p.splat_bytes = result.manifest.get("byte_size")
        db.commit()
        payload = p.to_dict()
    payload["type"] = "done"
    broker.publish(pid, payload)


def _finish_err(pid: str, message: str) -> None:
    _persist_state.pop(pid, None)
    with SessionLocal() as db:
        p = db.get(Project, pid)
        if not p:
            return
        p.status = "failed"
        p.stage = "failed"
        p.stage_message = "Failed"
        p.error = message
        db.commit()
        payload = p.to_dict()
    payload["type"] = "error"
    broker.publish(pid, payload)


def _finish_canceled(pid: str) -> None:
    _persist_state.pop(pid, None)
    with SessionLocal() as db:
        p = db.get(Project, pid)
        if not p:
            return
        p.status = "canceled"
        p.stage = "canceled"
        p.stage_message = "Canceled"
        p.progress = 0.0
        p.error = None
        db.commit()
        payload = p.to_dict()
    payload["type"] = "canceled"
    broker.publish(pid, payload)


class Worker:
    def __init__(self) -> None:
        self.queue: asyncio.Queue[str] = asyncio.Queue()
        self._task: asyncio.Task | None = None
        # canceled ids — read from the engine thread, written from request handlers
        self._canceled: set[str] = set()
        self._lock = threading.Lock()

    def start(self, loop: asyncio.AbstractEventLoop) -> None:
        broker.bind_loop(loop)
        self._task = loop.create_task(self._run())

    def submit(self, project_id: str) -> None:
        with self._lock:
            self._canceled.discard(project_id)
        self.queue.put_nowait(project_id)

    def cancel(self, project_id: str) -> None:
        """Request cancellation; the running engine stops at its next checkpoint."""
        with self._lock:
            self._canceled.add(project_id)

    def is_canceled(self, project_id: str) -> bool:
        with self._lock:
            return project_id in self._canceled

    async def _run(self) -> None:
        log.info("worker started")
        while True:
            pid = await self.queue.get()
            try:
                await self._process(pid)
            except JobCanceled:
                log.info("worker job %s canceled", pid)
                _finish_canceled(pid)
            except Exception:  # never let the loop die
                log.error("worker job %s crashed:\n%s", pid, traceback.format_exc())
                _finish_err(pid, "Internal worker error.")
            finally:
                with self._lock:
                    self._canceled.discard(pid)
                self.queue.task_done()

    async def _process(self, pid: str) -> None:
        if self.is_canceled(pid):  # canceled while still queued
            _finish_canceled(pid)
            return
        with SessionLocal() as db:
            p = db.get(Project, pid)
            if not p:
                return
            engine_id, quality, params = p.engine, p.quality, dict(p.params or {})
            video_path = p.video_path

        _set_progress(pid, "queued", 0.0, "Starting…")
        engine = get_engine(engine_id)

        def publish(stage: str, progress: float, message: str) -> None:
            _set_progress(pid, stage, progress, message)

        ctx = JobContext(pid, publish, is_canceled=lambda: self.is_canceled(pid))
        loop = asyncio.get_running_loop()
        try:
            result = await loop.run_in_executor(
                None,
                partial(
                    engine.reconstruct,
                    project_id=pid,
                    video_path=video_path,
                    quality=quality,
                    params=params,
                    ctx=ctx,
                ),
            )
            _finish_ok(pid, result)
            log.info("job %s ready (%s gaussians)", pid, result.gaussian_count)
        except JobCanceled:
            _finish_canceled(pid)
            log.info("job %s canceled mid-run", pid)
        except Exception as exc:
            log.error("job %s failed:\n%s", pid, traceback.format_exc())
            _finish_err(pid, str(exc) or exc.__class__.__name__)


worker = Worker()


def requeue_pending() -> None:
    """On startup, resume interrupted jobs — but bounded and clean.

    Jobs caught mid-run (queued / processing) are re-enqueued, with a restart
    counter persisted in ``params`` so a job that keeps interrupting eventually
    fails instead of looping forever. Any half-written splat from the previous run
    is cleared so a partial artifact is never served.
    """
    with SessionLocal() as db:
        rows = db.query(Project).filter(Project.status.in_(("queued", "processing"))).all()
        ids = []
        for p in rows:
            params = dict(p.params or {})
            attempts = int(params.get("_restart_attempts", 0)) + 1
            if attempts > MAX_RESTARTS:
                p.status = "failed"
                p.stage = "failed"
                p.stage_message = "Failed"
                p.error = "Reconstruction was interrupted too many times."
                continue
            params["_restart_attempts"] = attempts
            p.params = params
            p.status = "queued"
            p.stage = "queued"
            p.progress = 0.0
            p.stage_message = "Resuming…"
            # drop any partial output from the interrupted run
            for path in (storage.splat_path(p.id), storage.manifest_path(p.id)):
                try:
                    path.unlink()
                except OSError:
                    pass
            ids.append(p.id)
        db.commit()
    for pid in ids:
        worker.submit(pid)

  if (!res.ok) {

      /* ignore */

  return res.json() as Promise<T>;
}

export function formatBytes(n: number | null | undefined): string {
  if (!n) return "0 B";
  const units = ["B", "KB", "MB", "GB"];
  let i = 0;
  let v = n;
  while (v >= 1024 && i < units.length - 1) {
    v /= 1024;
    i++;
  }
  return `${v.toFixed(v >= 100 || i === 0 ? 0 : 1)} ${units[i]}`;
}

export function formatNumber(n: number | null | undefined): string {
  if (n == null) return "—";
  if (n >= 1_000_000) return `${(n / 1_000_000).toFixed(2)}M`;
  if (n >= 1_000) return `${(n / 1_000).toFixed(1)}k`;
  return String(n);
}

export function formatDuration(s: number | null | undefined): string {
  if (!s) return "—";
  const m = Math.floor(s / 60);
  const sec = Math.round(s % 60);
  return m > 0 ? `${m}m ${sec}s` : `${sec.toFixed(s < 10 ? 1 : 0)}s`;
}

export function timeAgo(iso: string | null | undefined): string {
  if (!iso) return "";
  const then = new Date(iso).getTime();
  const diff = Math.max(0, Date.now() - then) / 1000;
  if (diff < 60) return "just now";
  if (diff < 3600) return `${Math.floor(diff / 60)}m ago`;
  if (diff < 86400) return `${Math.floor(diff / 3600)}h ago`;
  return `${Math.floor(diff / 86400)}d ago`;
}

"""Engine interface shared by all reconstruction backends.

A future CUDA 4DGS trainer implements the same ``ReconstructionEngine`` and is
picked up by the registry with no other code changes.
"""
from __future__ import annotations

from abc import ABC, abstractmethod
from dataclasses import dataclass
from pathlib import Path
from typing import Callable


class JobCanceled(Exception):
    """Raised inside an engine when the user has canceled the job.

    Engines cooperate by calling ``ctx.check_canceled()`` at stage boundaries
    (and inside long poll loops); the worker treats this as a clean ``canceled``
    finish rather than a failure.
    """


@dataclass
class ReconstructResult:
    splat_path: Path
    manifest: dict
    gaussian_count: int
    frame_count: int
    fps: float
    duration: float
    width: int
    height: int
    thumb_path: Path | None = None


# publish(stage, progress[0..1], message)
ProgressFn = Callable[[str, float, str], None]


class JobContext:
    """Carries the live-progress callback (and cancel signal) into an engine run."""

    def __init__(
        self,
        project_id: str,
        publish: ProgressFn,
        is_canceled: Callable[[], bool] | None = None,
    ) -> None:
        self.project_id = project_id
        self._publish = publish
        self._is_canceled = is_canceled or (lambda: False)

    def progress(self, stage: str, progress: float, message: str = "") -> None:
        self._publish(stage, max(0.0, min(1.0, progress)), message)

    def canceled(self) -> bool:
        return bool(self._is_canceled())

    def check_canceled(self) -> None:
        if self._is_canceled():
            raise JobCanceled()


class ReconstructionEngine(ABC):
    id: str = "base"
    name: str = "Base"

    @abstractmethod
    def reconstruct(
        self,
        *,
        project_id: str,
        video_path: str,
        quality: str,
        params: dict,
        ctx: JobContext,
    ) -> ReconstructResult:
        ...

### api/app/pipeline/cloud_engine.py

"""Cloud reconstruction engine — submits to a hosted GPU provider for photoreal
3D/4D Gaussian Splatting, then ingests the result into our ``.4dsplat`` format.

This is the genuine "drop-in" path: it speaks the Replicate HTTP API (the
default provider) and converts a returned INRIA-style 3DGS ``.ply`` into a
single-timestep splat the viewer can render. It requires an API key + a model
configured in Settings; without those it stays disabled in the UI.

Because it depends on external paid GPU + network, it is not exercised by the
local test flow — but the code path is real, not a stub.
"""
from __future__ import annotations

import base64
import time
from pathlib import Path

import numpy as np

from .. import storage
from ..settings_store import get_setting
from .base import JobContext, ReconstructionEngine, ReconstructResult
from .splat_format import SplatFrame, write_4dsplat_v2, write_manifest

SH_C0 = 0.28209479177387814


def _sigmoid(x: np.ndarray) -> np.ndarray:
    return 1.0 / (1.0 + np.exp(-x))


def _parse_inria_ply(path: Path) -> SplatFrame:
    """Parse a standard 3D Gaussian Splatting (.ply, binary LE) into a frame."""
    import re

    with open(path, "rb") as fh:
        if fh.readline().strip() != b"ply":
            raise ValueError("not a ply file")
        fmt = fh.readline().strip()
        if b"binary_little_endian" not in fmt:
            raise ValueError(f"unsupported ply format: {fmt!r}")
        props: list[tuple[str, str]] = []
        count = 0
        while True:
            line = fh.readline().strip()
            if line.startswith(b"element vertex"):
                count = int(line.split()[-1])
            elif line.startswith(b"property"):
                _, ptype, pname = line.split()
                props.append((pname.decode(), ptype.decode()))
            elif line == b"end_header":
                break
        np_types = {
            "float": "<f4", "float32": "<f4", "double": "<f8",
            "uchar": "u1", "int": "<i4", "short": "<i2",
        }
        dtype = np.dtype([(n, np_types.get(t, "<f4")) for n, t in props])
        data = np.frombuffer(fh.read(count * dtype.itemsize), dtype=dtype, count=count)

    names = data.dtype.names
    pos = np.stack([data["x"], data["y"], data["z"]], axis=1).astype(np.float32)

    if {"f_dc_0", "f_dc_1", "f_dc_2"} <= set(names):
        dc = np.stack([data["f_dc_0"], data["f_dc_1"], data["f_dc_2"]], axis=1)
        rgb = np.clip(0.5 + SH_C0 * dc, 0, 1)
    elif {"red", "green", "blue"} <= set(names):
        rgb = np.stack([data["red"], data["green"], data["blue"]], axis=1) / 255.0
    else:
        rgb = np.full((count, 3), 0.6, np.float32)
    colors = (rgb * 255).astype(np.uint8)

    if "opacity" in names:
        opac = (_sigmoid(data["opacity"]) * 255).astype(np.uint8)
    else:
        opac = np.full(count, 255, np.uint8)

    scale_cols = sorted([n for n in names if re.fullmatch(r"scale_\d+", n)])
    if scale_cols:
        sc = np.exp(np.stack([data[c] for c in scale_cols[:3]], axis=1)).astype(np.float32)
        if sc.shape[1] < 3:
            sc = np.repeat(sc[:, :1], 3, axis=1)
    else:
        sc = np.full((count, 3), 0.01, np.float32)

    rot_cols = sorted([n for n in names if re.fullmatch(r"rot_\d+", n)])
    if len(rot_cols) >= 4:
        q = np.stack([data[c] for c in rot_cols[:4]], axis=1).astype(np.float32)
        q /= (np.linalg.norm(q, axis=1, keepdims=True) + 1e-8)
        # INRIA stores (w,x,y,z); our format wants (x,y,z,w)
        q = np.stack([q[:, 1], q[:, 2], q[:, 3], q[:, 0]], axis=1)
        rot = np.clip(q * 127, -127, 127).astype(np.int8)
    else:
        rot = None

    return SplatFrame(positions=pos, scales=sc, colors=colors, opacities=opac, rotations=rot)


class CloudEngine(ReconstructionEngine):
    id = "cloud"
    name = "Cloud · photoreal GPU"

    def reconstruct(
        self,
        *,
        project_id: str,
        video_path: str,
        quality: str,
        params: dict,
        ctx: JobContext,
    ) -> ReconstructResult:
        import httpx

        api_key = get_setting("cloud_api_key", "")
        model = get_setting("cloud_model", "")
        provider = get_setting("cloud_provider", "replicate")
        if not api_key:
            raise RuntimeError("Cloud engine needs an API key — set one in Settings.")
        if not model:
            raise RuntimeError("Cloud engine needs a model id — set 'cloud_model' in Settings.")
        if provider != "replicate":
            raise RuntimeError(f"Unsupported cloud provider: {provider}")

        ctx.progress("upload", 0.05, "Uploading video to GPU provider…")
        video_b64 = base64.b64encode(Path(video_path).read_bytes()).decode()
        data_url = f"data:application/octet-stream;base64,{video_b64}"

        headers = {"Authorization": f"Token {api_key}", "Content-Type": "application/json"}
        with httpx.Client(timeout=120) as client:
            ctx.progress("submit", 0.12, "Submitting reconstruction job…")
            resp = client.post(
                "https://api.replicate.com/v1/predictions",
                headers=headers,
                json={"version": model, "input": {"video": data_url}},
            )
            resp.raise_for_status()
            pred = resp.json()
            get_url = pred["urls"]["get"]

            # poll
            output = None
            for _ in range(600):  # up to ~20 min at 2s
                ctx.check_canceled()
                time.sleep(2)
                r = client.get(get_url, headers=headers)
                r.raise_for_status()
                pred = r.json()
                status = pred.get("status")
                if status == "succeeded":
                    output = pred.get("output")
                    break
                if status in ("failed", "canceled"):
                    raise RuntimeError(f"Provider job {status}: {pred.get('error')}")
                ctx.progress("training", 0.5, f"GPU reconstructing… ({status})")

            if not output:
                raise RuntimeError("Provider returned no output before timeout.")

            ctx.progress("ingest", 0.9, "Downloading & ingesting splat…")
            out_url = output[0] if isinstance(output, list) else output
            ply_bytes = client.get(out_url, headers=headers, timeout=300).content

        ply_path = storage.project_dir(project_id) / "cloud_output.ply"
        ply_path.write_bytes(ply_bytes)
        frame = _parse_inria_ply(ply_path)

        splat_file = storage.splat_path(project_id)

### api/app/pipeline/depth.py
```
"""Monocular depth estimation with graceful degradation.

``estimate_depth(rgb)`` returns a float32 HxW map in [0, 1] where **1 = near**
(closer to camera) and **0 = far**.

Backend selection is automatic:
  * If ``torch`` + ``transformers`` are importable, a Depth-Anything-V2 model is
    loaded lazily on first use (Apple MPS / CUDA / CPU) for real geometry.
  * Otherwise (or if the model fails to load), a fast luminance + local-contrast
    heuristic is used. Zero heavy dependencies; always works.
"""
from __future__ import annotations

import importlib.util
import os
import threading

import numpy as np
from PIL import Image, ImageFilter

# Higher-quality default than the Small model; override with FOURD_DEPTH_MODEL
# (e.g. depth-anything/Depth-Anything-V2-Large-hf for max geometry). Falls back
# down the chain on load failure.
_MODEL_CHAIN = [
    os.environ.get("FOURD_DEPTH_MODEL", "depth-anything/Depth-Anything-V2-Base-hf"),
    "depth-anything/Depth-Anything-V2-Small-hf",
]

_MODEL = None
_MODEL_TRIED = False
_LOCK = threading.Lock()
_BACKEND = None  # cached resolved name


def _torch_stack_available() -> bool:
    return bool(
        importlib.util.find_spec("torch")
        and importlib.util.find_spec("transformers")
    )


def depth_backend_name() -> str:
    """Best-effort report of which backend will be used (no model download)."""
    global _BACKEND
    if _BACKEND is not None:
        return _BACKEND
    _BACKEND = "depth-anything" if _torch_stack_available() else "heuristic"
    return _BACKEND


def _load_model():
    """Lazily load Depth-Anything; returns (pipe, device) or None on failure."""
    global _MODEL, _MODEL_TRIED, _BACKEND
    if _MODEL_TRIED:
        return _MODEL
    with _LOCK:
        if _MODEL_TRIED:
            return _MODEL
        _MODEL_TRIED = True
        try:
            import torch  # noqa
            from transformers import pipeline

            if torch.backends.mps.is_available():
                device = "mps"
            elif torch.cuda.is_available():
                device = "cuda"
            else:
                device = "cpu"

            pipe = None
            for model_id in _MODEL_CHAIN:
                try:
                    pipe = pipeline(task="depth-estimation", model=model_id, device=device)
                    break
                except Exception:
                    continue
            if pipe is None:
                raise RuntimeError("no depth model could be loaded")
            _MODEL = (pipe, device)
            _BACKEND = "depth-anything"
        except Exception:
            _MODEL = None
            _BACKEND = "heuristic"
        return _MODEL


def _normalize(x: np.ndarray) -> np.ndarray:
    # robust 2nd/98th percentile normalization (less sensitive to outliers /
    # specular spikes than min/max, which keeps depth ranges more consistent
    # frame-to-frame and reduces temporal "breathing").
    lo = float(np.percentile(x, 2))
    hi = float(np.percentile(x, 98))
    if hi - lo < 1e-6:
        return np.zeros_like(x, dtype=np.float32)
    return np.clip((x - lo) / (hi - lo), 0.0, 1.0).astype(np.float32)


def _heuristic_depth(rgb: np.ndarray) -> np.ndarray:
    """A pleasing pseudo-depth from monocular cues (no ML).

    Combines: luminance, local contrast / detail (in-focus → near), a mild
    center bias and a gentle vertical gradient. Produces a smooth relief that
    turns the frame into an animated 3D bas-relief.
    """
    h, w, _ = rgb.shape
    img = Image.fromarray(rgb)
    gray = np.asarray(img.convert("L"), dtype=np.float32) / 255.0

    # local contrast: |gray - blur(gray)|, then blurred → "detail energy"
    blur = np.asarray(
        img.convert("L").filter(ImageFilter.GaussianBlur(radius=max(2, w // 64))),
        dtype=np.float32,
    ) / 255.0
    detail = np.abs(gray - blur)
    detail_img = Image.fromarray((np.clip(detail * 4.0, 0, 1) * 255).astype(np.uint8))
    detail = np.asarray(
        detail_img.filter(ImageFilter.GaussianBlur(radius=max(3, w // 48))),
        dtype=np.float32,
    ) / 255.0

    # center bias (radial)
    yy, xx = np.mgrid[0:h, 0:w].astype(np.float32)
    cx, cy = (w - 1) / 2.0, (h - 1) / 2.0
    r = np.sqrt(((xx - cx) / max(cx, 1)) ** 2 + ((yy - cy) / max(cy, 1)) ** 2)
    center = 1.0 - np.clip(r, 0, 1)

    # vertical: lower in frame slightly nearer
    vertical = yy / max(h - 1, 1)

    depth = (
        0.45 * _normalize(detail)
        + 0.25 * _normalize(gray)
        + 0.20 * center
        + 0.10 * vertical
    )
    depth = _normalize(depth)

    # final smooth
    depth_img = Image.fromarray((depth * 255).astype(np.uint8))
    depth = np.asarray(
        depth_img.filter(ImageFilter.GaussianBlur(radius=max(2, w // 96))),
        dtype=np.float32,
    ) / 255.0
    return _normalize(depth)


def _model_output_to_depth(out, rgb: np.ndarray) -> np.ndarray:
    # prefer the raw predicted_depth tensor (more precision than the
    # 8-bit "depth" PIL). Depth-Anything outputs disparity → near = large.
    pd = out.get("predicted_depth") if isinstance(out, dict) else None
    if pd is not None:
        depth = pd.squeeze().detach().to("cpu").float().numpy()
    else:
        depth = np.asarray(out["depth"], dtype=np.float32)
    if depth.shape[:2] != rgb.shape[:2]:
        depth = np.asarray(
            Image.fromarray(depth.astype(np.float32)).resize(
                (rgb.shape[1], rgb.shape[0]), Image.BILINEAR
            ),
            dtype=np.float32,
        )
    return _normalize(depth)


def estimate_depth(rgb: np.ndarray) -> np.ndarray:
    """Return HxW float32 depth in [0,1], 1 = near. rgb is HxWx3 uint8."""
    if _torch_stack_available():
        model = _load_model()
        if model is not None:
            try:
                pipe, _device = model
                return _model_output_to_depth(pipe(Image.fromarray(rgb)), rgb)
            except Exception:
                pass  # fall through to heuristic
    return _heuristic_depth(rgb)


# batch size fed to the model in one forward pass (MPS/CUDA win; safe on CPU)
_BATCH = int(os.environ.get("FOURD_DEPTH_BATCH", "4"))


def estimate_depth_batch(rgbs: list[np.ndarray], progress=None) -> list[np.ndarray]:
    """Depth for a whole clip. Batches the model forward passes (a large speedup
    on MPS/CUDA where per-call overhead dominates at clip resolutions); falls
    back to the per-frame path on any failure. ``progress(done, total)``."""
    n = len(rgbs)
    out: list[np.ndarray] = []
    model = _load_model() if _torch_stack_available() else None
    if model is not None:
        pipe, _device = model
        while len(out) < n:
            chunk = rgbs[len(out) : len(out) + _BATCH]
            try:
                res = pipe([Image.fromarray(r) for r in chunk], batch_size=len(chunk))
                decoded = [_model_output_to_depth(o, r) for o, r in zip(res, chunk)]
            except Exception:
                break  # fall through to per-frame for the remainder
            out.extend(decoded)
            if progress:  # outside the try: cancellation must propagate
                progress(len(out), n)
    while len(out) < n:
        out.append(estimate_depth(rgbs[len(out)]))
        if progress:
            progress(len(out), n)
    return out

### api/app/pipeline/ffmpeg.py
```
"""Thin wrappers around the system ``ffmpeg`` / ``ffprobe`` binaries."""
from __future__ import annotations

import json
import shutil
import subprocess
from pathlib import Path


def ffmpeg_available() -> bool:
    return bool(shutil.which("ffmpeg") and shutil.which("ffprobe"))


def _run(cmd: list[str]) -> subprocess.CompletedProcess:
    return subprocess.run(cmd, capture_output=True, text=True, check=True)


def probe(video_path: str | Path) -> dict:
    """Return {duration, fps, width, height} for a video file."""
    cmd = [
        "ffprobe", "-v", "error",
        "-select_streams", "v:0",
        "-show_entries", "stream=width,height,avg_frame_rate,r_frame_rate:format=duration",
        "-of", "json", str(video_path),
    ]
    out = _run(cmd).stdout
    data = json.loads(out)
    stream = (data.get("streams") or [{}])[0]
    fmt = data.get("format") or {}

    def _parse_rate(rate: str | None) -> float:
        if not rate or rate == "0/0":
            return 0.0
        if "/" in rate:
            num, den = rate.split("/")
            den_f = float(den)
            return float(num) / den_f if den_f else 0.0
        try:
            return float(rate)
        except ValueError:
            return 0.0

    fps = _parse_rate(stream.get("avg_frame_rate")) or _parse_rate(stream.get("r_frame_rate"))
    duration = float(fmt.get("duration") or 0.0)
    width = int(stream.get("width") or 0)
    height = int(stream.get("height") or 0)
    return {
        "duration": duration,
        "fps": fps or 24.0,
        "width": width,
        "height": height,
    }


def extract_frames(
    video_path: str | Path,
    out_dir: str | Path,
    count: int,
    width: int,
    height: int,
    duration: float,
) -> list[Path]:
    """Extract ~``count`` evenly-spaced frames, scaled to (width, height).

    Frames are written as ``frame_%05d.png`` and returned sorted. We subsample
    via the ``fps`` filter (target_fps = count / duration) which is robust for
    arbitrary inputs, then keep at most ``count`` frames.
    """
    out_dir = Path(out_dir)
    out_dir.mkdir(parents=True, exist_ok=True)
    for old in out_dir.glob("frame_*.png"):
        old.unlink()

    target_fps = (count / duration) if duration and duration > 0 else float(count)
    target_fps = max(target_fps, 0.1)
    vf = f"fps={target_fps:.6f},scale={width}:{height}:flags=area"

    cmd = [
        "ffmpeg", "-v", "error", "-y",
        "-i", str(video_path),
        "-vf", vf,
        "-frames:v", str(count + 2),  # small slack; we trim below
        str(out_dir / "frame_%05d.png"),
    ]
    _run(cmd)

    frames = sorted(out_dir.glob("frame_*.png"))
    if len(frames) > count:
        # keep an evenly-spaced subset of exactly `count`
        idx = [round(i * (len(frames) - 1) / (count - 1)) for i in range(count)] if count > 1 else [0]
        keep = {frames[i] for i in idx}
        for f in frames:
            if f not in keep:
                f.unlink()
        frames = sorted(keep)
    return frames
```

### api/app/pipeline/local_engine.py
```
"""Local reconstruction engine — runs entirely on this machine.

Three regimes behind one path, chosen automatically from the recovered camera
motion (``motion.py``) and the clip's temporal structure (``spacetime.py``):

  * **Orbit / fly-around (camera moves, scene static)** → every frame is a new
    *view*. Each frame's oriented-gaussian cloud is lifted into a shared world
    using its estimated camera pose, voxel-fused (opacity-weighted) into one
    walk-around **3D model**, then scrubbed by a multi-view photo-consistency
    filter that removes floaters the fusion can't see.
  * **Static camera (subject moves)** → a **spacetime** model, the way modern
    4DGS systems represent video: the background is fused ONCE into a static
    gaussian canvas (temporal median color+depth, disocclusions filled from the
    frames that saw behind the subject), and the moving parts become gaussian
    **trajectories** — optical-flow-tracked positions per control point with
    birth/death windows — so the viewer interpolates motion continuously in
    time instead of snapping between per-frame clouds. Storage stops scaling
    with clip length for everything that doesn't move.
  * **Nothing moves at all** → the canvas alone: a single crisp 3D still.

All regimes share the same lift: real monocular depth (Depth-Anything, batched,
on MPS when available), perspective unprojection, surface-oriented gaussians,
occlusion-edge culling. Every capability degrades gracefully (no OpenCV ⇒
single-frame tracks; no torch ⇒ heuristic depth) — output is never worse than
the pre-spacetime engine, only, when the structure is real, far better.
"""
from __future__ import annotations

import math
import os

import numpy as np
from PIL import Image, ImageFilter

from .. import storage
from ..config import QUALITY_PRESETS
from . import ffmpeg
from .base import JobContext, ReconstructionEngine, ReconstructResult

    write_manifest,
)

Z_NEAR, Z_FAR = 1.2, 3.0   # camera-space depth range the [0,1] depth maps to

# spacetime path

def _even(n: int, lo: int = 16) -> int:
    n = max(lo, int(round(n)))
    return n - (n % 2)


def _model_resolution(src_w: int, src_h: int) -> tuple[int, int]:
    src_w, src_h = max(src_w, 2), max(src_h, 2)
    scale = min(1.0, MODEL_MAX / max(src_w, src_h))
    return _even(src_w * scale), _even(src_h * scale)


def _work_resolution(src_w: int, src_h: int, budget: int) -> tuple[int, int]:
    aspect = src_w / src_h
    h = math.sqrt(budget / aspect)
    w = h * aspect
    return max(_even(w), 32), max(_even(h), 32)


def _frames_to_quat(t1: np.ndarray, t2: np.ndarray, n: np.ndarray) -> np.ndarray:
    """Vectorized rotation-frame → quaternion (x,y,z,w). Columns are t1,t2,n."""
    m00, m10, m20 = t1[:, 0], t1[:, 1], t1[:, 2]
    m01, m11, m21 = t2[:, 0], t2[:, 1], t2[:, 2]
    m02, m12, m22 = n[:, 0], n[:, 1], n[:, 2]
    tr = m00 + m11 + m22
    N = t1.shape[0]
    qx = np.zeros(N, np.float32)
    qy = np.zeros(N, np.float32)
    qz = np.zeros(N, np.float32)
    qw = np.ones(N, np.float32)

    def case(mask, w, x, y, z):
        qw[mask], qx[mask], qy[mask], qz[mask] = w[mask], x[mask], y[mask], z[mask]

    c0 = tr > 0
    s = np.sqrt(np.maximum(tr + 1.0, 1e-8)) * 2.0
    case(c0, 0.25 * s, (m21 - m12) / s, (m02 - m20) / s, (m10 - m01) / s)

    rem = ~c0
    c1 = rem & (m00 >= m11) & (m00 >= m22)
    s = np.sqrt(np.maximum(1.0 + m00 - m11 - m22, 1e-8)) * 2.0
    case(c1, (m21 - m12) / s, 0.25 * s, (m01 + m10) / s, (m02 + m20) / s)

    rem = rem & ~c1
    c2 = rem & (m11 >= m22)
    s = np.sqrt(np.maximum(1.0 + m11 - m00 - m22, 1e-8)) * 2.0
    case(c2, (m02 - m20) / s, (m01 + m10) / s, 0.25 * s, (m12 + m21) / s)

    c3 = rem & ~c2
    s = np.sqrt(np.maximum(1.0 + m22 - m00 - m11, 1e-8)) * 2.0
    case(c3, (m10 - m01) / s, (m02 + m20) / s, (m12 + m21) / s, 0.25 * s)

    q = np.stack([qx, qy, qz, qw], axis=1)
    q /= np.linalg.norm(q, axis=1, keepdims=True) + 1e-8
    return q


def _orthonormal_frame(n: np.ndarray) -> tuple[np.ndarray, np.ndarray]:
    """Two in-plane tangents for each normal (N,3). Disc is round, so the
    in-plane rotation is arbitrary — just needs to be orthonormal."""
    helper = np.where(
        (np.abs(n[:, 2:3]) < 0.9), np.array([0.0, 0.0, 1.0]), np.array([1.0, 0.0, 0.0])
    )
    t1 = np.cross(helper, n)
    t1 /= np.linalg.norm(t1, axis=1, keepdims=True) + 1e-8
    t2 = np.cross(n, t1)
    return t1.astype(np.float32), t2.astype(np.float32)


def _denoise_depth(depth: np.ndarray) -> np.ndarray:
    img = Image.fromarray((np.clip(depth, 0, 1) * 255).astype(np.uint8))
    img = img.filter(ImageFilter.MedianFilter(size=3))
    return np.asarray(img, dtype=np.float32) / 255.0


def _align_depths(depths: list[np.ndarray]) -> list[np.ndarray]:
    """Put every frame's depth on a common scale, then lightly temporally smooth.

    Monocular depth is scale/shift-ambiguous *per frame*; left alone the range
    drifts frame-to-frame and the scene "breathes". We robustly map each frame's
    20th/80th percentile band onto the sequence mean (a 2-point scale+shift fit),
    which also gives the pose chain (motion.py) one consistent metric scale.
    """
    n = len(depths)
    if n < 2:
        return depths
    los = np.array([np.percentile(d, 20) for d in depths])
    his = np.array([np.percentile(d, 80) for d in depths])
    ref_lo, ref_hi = float(los.mean()), float(his.mean())
    out: list[np.ndarray] = []
    for d, lo, hi in zip(depths, los, his):
        a = (ref_hi - ref_lo) / max(hi - lo, 1e-4)
        b = ref_lo - a * lo
        out.append(np.clip(a * d + b, 0.0, 1.0).astype(np.float32))
    if n >= 3:  # residual jitter → 3-tap temporal smooth (endpoints held)
        stack = np.stack(out, axis=0)
        sm = 0.25 * np.roll(stack, 1, 0) + 0.5 * stack + 0.25 * np.roll(stack, -1, 0)
        sm[0], sm[-1] = stack[0], stack[-1]
        out = [sm[i] for i in range(n)]
    return out


def _z_cam(depth01: np.ndarray | float, strength: float) -> np.ndarray | float:
    """Normalized depth (1 = near) → camera-space distance (engine mapping)."""
    return Z_FAR - depth01 * (Z_FAR - Z_NEAR) * strength


def _voxel_fuse(frame: dict, target: int) -> dict:
    """Collapse overlapping multi-view samples onto a voxel grid.

    Position and color are merged as opacity-weighted means over each occupied
    voxel (multi-view denoising); shape (scale/rotation/opacity) comes from the
    most-opaque, best surface-facing member. Dedupes the overlap between views
    and bounds the gaussian count.
    """
    pos = frame["positions"]
    n = pos.shape[0]
    if n <= target:
        return frame
    mn = pos.min(axis=0)
    ext = np.maximum(pos.max(axis=0) - mn, 1e-6)

    def occupancy(voxel: float):
        ijk = np.floor((pos - mn) / voxel).astype(np.int64)
        dims = ijk.max(axis=0) + 1
        keys = (ijk[:, 0] * dims[1] + ijk[:, 1]) * dims[2] + ijk[:, 2]
        return keys, int(np.unique(keys).size)

    # Splats live on 2D surfaces inside the volume, so occupied voxels scale ~
    # voxel^-2. Search the voxel size that lands nearest the target count,
    # adjusting in *both* directions.
    voxel = float((ext.prod() / target) ** (1.0 / 3.0))
    best_voxel, best_err = voxel, float("inf")
    for _ in range(7):
        _, n_occ = occupancy(voxel)
        err = abs(n_occ - target)
        if err < best_err:
            best_err, best_voxel = err, voxel
        if 0.85 * target <= n_occ <= 1.2 * target:
            break
        voxel *= float(np.clip((n_occ / target) ** 0.5, 0.4, 2.5))
    keys, _ = occupancy(best_voxel)

    # representative = max opacity within each voxel (last after this sort)
    order = np.lexsort((frame["opacities"], keys))
    sk = keys[order]
    last = np.ones(sk.shape[0], dtype=bool)
    last[:-1] = sk[1:] != sk[:-1]
    rep = order[last]

    # opacity-weighted mean position + color per voxel
    uniq, inv = np.unique(keys, return_inverse=True)
    wts = frame["opacities"].astype(np.float64) + 1.0
    wsum = np.bincount(inv, weights=wts)
    out = {k: v[rep] for k, v in frame.items()}
    pos_mean = np.stack(
        [np.bincount(inv, weights=pos[:, c] * wts) / wsum for c in range(3)], axis=1
    )
    col_mean = np.stack(
        [
            np.bincount(inv, weights=frame["colors"][:, c].astype(np.float64) * wts) / wsum
            for c in range(3)
        ],
        axis=1,
    )
    # `rep` walks voxels in sorted-key order, matching np.unique's ordering
    out["positions"] = pos_mean.astype(np.float32)
    out["colors"] = np.clip(col_mean + 0.5, 0, 255).astype(np.uint8)
    return out


def _photo_prune(
    fused: dict,
    views: list[dict],
    fx: float,
    fy: float,
    cx: float,
    cy: float,
    strength: float,
) -> tuple[dict, int]:
    """Multi-view photo-consistency filter for the fused orbit model.

    Each gaussian is reprojected into up to PRUNE_VIEWS source views; where it
    lands unoccluded (validated against that view's own depth), its stored color
    is compared with what the camera actually saw. Gaussians that disagree with
    most of their observations are depth-lift ghosts — remove them.
    """
    n = fused["positions"].shape[0]
    if n == 0 or len(views) < PRUNE_MIN_VIEWS:
        return fused, 0
    step = max(1, len(views) // PRUNE_VIEWS)
    sel_views = views[::step][:PRUNE_VIEWS]

    P = fused["positions"]
    col = fused["colors"].astype(np.float32)
    err_sum = np.zeros(n, np.float32)
    err_cnt = np.zeros(n, np.int32)

    for v in sel_views:
        R, C = v["R"], v["C"]                       # camera→world
        h, w = v["z"].shape
        Xc = (P - C[None, :]) @ R                    # world→camera (R orthonormal)
        z = -Xc[:, 2]                                # camera looks −Z
        with np.errstate(divide="ignore", invalid="ignore"):
            u = cx + fx * Xc[:, 0] / z
            vpx = cy - fy * Xc[:, 1] / z
        ok = (z > 0.05) & (u >= 1) & (u < w - 2) & (vpx >= 1) & (vpx < h - 2)
        if not ok.any():
            continue
        ui = np.clip(u[ok].astype(np.int32), 0, w - 1)
        vi = np.clip(vpx[ok].astype(np.int32), 0, h - 1)
        zmap = v["z"][vi, ui]
        visible = z[ok] <= zmap + PRUNE_Z_TOL       # unoccluded in this view
        if not visible.any():
            continue
        idx = np.flatnonzero(ok)[visible]
        seen = v["rgb"][vi[visible], ui[visible]].astype(np.float32)
        err_sum[idx] += np.abs(seen - col[idx]).mean(axis=1)
        err_cnt[idx] += 1

    scored = err_cnt >= PRUNE_MIN_VIEWS
    if not scored.any():
        return fused, 0
    err = np.where(scored, err_sum / np.maximum(err_cnt, 1), 0.0)
    bad = scored & (err > PRUNE_ERR)
    max_drop = int(n * PRUNE_MAX_FRAC)
    if bad.sum() > max_drop:                        # keep the least-bad overflow
        thresh = np.partition(err[bad], -max_drop)[-max_drop]
        bad &= err >= thresh
    keep = ~bad
    return {k: v[keep] for k, v in fused.items()}, int(bad.sum())


def _save_thumbnail(rgb: np.ndarray, dst) -> None:
    img = Image.fromarray(rgb)
    img.thumbnail((640, 640), Image.LANCZOS)
    img.convert("RGB").save(dst, "JPEG", quality=86)


class LocalEngine(ReconstructionEngine):
    id = "local"
    name = "Local · on-device"

    def reconstruct(
        self,
        *,
        project_id: str,
        video_path: str,
        quality: str,
        params: dict,
        ctx: JobContext,
    ) -> ReconstructResult:
        preset = QUALITY_PRESETS.get(quality, QUALITY_PRESETS["balanced"])
        timesteps = min(int(params.get("timesteps") or preset["timesteps"]), MAX_TIMESTEPS)
        budget = int(params.get("budget") or preset["budget"])
        depth_strength = float(params.get("depth_strength") or DEFAULT_DEPTH_STRENGTH)
        forced = (params.get("capture_mode") or "auto").lower()
        forced_mode = forced if forced in ("orbit", "motion") else None
        refine_cfg: dict | None = None
        if params.get("refine"):
            refine_cfg = {
                "iterations": int(
                    params.get("refine_iterations") or REFINE_ITERS.get(quality, 240)
                ),
                "budget_s": float(params.get("refine_seconds") or REFINE_BUDGET_S),
            }

        ctx.progress("probe", 0.02, "Reading video…")
        info = ffmpeg.probe(video_path)
        duration = info["duration"] or (timesteps / max(info["fps"], 1.0))
        mw, mh = _model_resolution(info["width"] or 1280, info["height"] or 720)

        ctx.progress("extract", 0.05, f"Extracting {timesteps} frames…")
        frames_dir = storage.frames_dir(project_id)
        frame_paths = ffmpeg.extract_frames(video_path, frames_dir, timesteps, mw, mh, duration)
        if not frame_paths:
            raise RuntimeError("No frames could be extracted from the video.")
        n = len(frame_paths)
        backend = depth_backend_name()

        # ---- depth for every frame (batched, at model res) -------------------
        rgbs = [np.asarray(Image.open(fp).convert("RGB"), dtype=np.uint8) for fp in frame_paths]
        mid_rgb = rgbs[n // 2]

        def depth_progress(done: int, total: int) -> None:
            ctx.check_canceled()
            ctx.progress("depth", 0.06 + 0.36 * (done / total), f"Depth {done}/{total} · {backend}")

        depths = [_denoise_depth(d) for d in estimate_depth_batch(rgbs, progress=depth_progress)]
        ctx.check_canceled()

        # cross-frame depth alignment (de-breathing + consistent scale for poses)
        depths = _align_depths(depths)

        # ---- recover camera motion → orbit-fuse or spacetime 4D --------------
        ctx.progress("register", 0.44, "Recovering camera motion…")
        motion = estimate_motion(
            rgbs, depths, fov_deg=FOV_DEG, z_near=Z_NEAR, z_far=Z_FAR, forced_mode=forced_mode
        )
        ctx.check_canceled()

        camera_path: list[list[float]] = []
        if motion.fuse and motion.poses:
            static_raw, extras = self._reconstruct_orbit(
                rgbs, depths, motion.poses, budget, depth_strength, ctx, refine_cfg
            )
            tracks_raw: TrackSet | None = None
            num_cp = 1
            out_fps = 1.0
            camera_path = motion.camera_path
            capture_mode = "orbit"
        else:
            static_raw, tracks_raw, num_cp, extras = self._reconstruct_spacetime(
                rgbs, depths, mw, mh, budget, depth_strength, ctx, refine_cfg
            )
            out_fps = float(np.clip(n / max(duration, 0.1), 0.5, 60.0)) if num_cp > 1 else 1.0
            capture_mode = "motion"

        # ---- global normalize (consistent center + scale) ------------------
        pools = [static_raw["positions"]]
        if tracks_raw is not None:
            pools.append(tracks_raw.positions)
        all_pos = np.concatenate([p for p in pools if p.shape[0]], axis=0)
        if all_pos.shape[0] == 0:
            raise RuntimeError("Reconstruction produced no gaussians.")
        centroid = all_pos.mean(axis=0).astype(np.float32)
        extent = max(float(np.abs(all_pos - centroid).max()), 1e-6)
        gscale = 1.0 / extent  # fit into ~[-1,1]

        static_frame = SplatFrame(
            positions=((static_raw["positions"] - centroid) * gscale).astype(np.float32),
            scales=(static_raw["scales"] * gscale).astype(np.float32),
            colors=static_raw["colors"],
            opacities=static_raw["opacities"],
            rotations=static_raw["rotations"],
        )
        if tracks_raw is not None:
            tracks_raw.positions = ((tracks_raw.positions - centroid) * gscale).astype(np.float32)
            tracks_raw.scales = (tracks_raw.scales * gscale).astype(np.float32)
        norm_path = [
            ((np.asarray(c, np.float32) - centroid) * gscale).tolist() for c in camera_path
        ]

        ctx.progress("pack", 0.93, "Packing splat…")
        splat_file = storage.splat_path(project_id)
        manifest = write_4dsplat_v2(
            splat_file, static_frame, tracks_raw, num_cp=num_cp, fps=out_fps
        )
        manifest.update(
            {
                "engine": self.id,
                "quality": quality,
                "capture_mode": capture_mode,
                "motion_mode": motion.mode,
                "motion_score": round(motion.motion_score, 4),
                "pose_confidence": round(motion.confidence, 4),
                "pose_backend": pose_backend_name(),
                "views_fused": n if capture_mode == "orbit" else 0,
                "camera_path": norm_path,
                "source": {
                    "duration": duration,
                    "fps": info["fps"],
                    "width": info["width"],
                    "height": info["height"],
                },
                "depth_backend": backend,
                "oriented": True,
                **extras,
            }
        )
        write_manifest(storage.manifest_path(project_id), manifest)

        ctx.progress("finalize", 0.98, "Rendering poster…")
        thumb = storage.thumb_path(project_id)
        if mid_rgb is not None:
            _save_thumbnail(mid_rgb, thumb)

        if not params.get("keep_frames"):
            for fp in frame_paths:
                try:
                    fp.unlink()
                except OSError:
                    pass

        return ReconstructResult(
            splat_path=splat_file,
            manifest=manifest,
            gaussian_count=manifest["gaussian_count"],
            frame_count=num_cp,
            fps=info["fps"],
            duration=duration,
            width=info["width"],
            height=info["height"],
            thumb_path=thumb if thumb.exists() else None,
        )

    # ---------------------------------------------------------------- refine
    def _refine_static(
        self,
        static: dict,
        views: list[RefineView],
        ctx: JobContext,
        cfg: dict,
        lo: float,
        hi: float,
    ) -> tuple[dict, dict]:
        """Run the differentiable optimization pass over a static gaussian set."""
        if not views or static["positions"].shape[0] == 0:
            return static, {}
        ctx.progress("refine", lo, "Optimizing splats (differentiable pass)…")

        def cb(done: int, total: int, loss: float) -> None:
            ctx.check_canceled()
            ctx.progress(
                "refine", lo + (hi - lo) * (done / total),
                f"Refining {done}/{total} · L1 {loss:.3f}",
            )

        refined, stats = refine_gaussians(
            static, views,
            iterations=cfg["iterations"], time_budget_s=cfg["budget_s"], progress=cb,
        )
        return refined, stats.as_manifest()

    # ------------------------------------------------------------------ orbit
    def _reconstruct_orbit(
        self,
        rgbs: list[np.ndarray],
        depths: list[np.ndarray],
        poses: list[tuple[np.ndarray, np.ndarray]],
        budget: int,
        depth_strength: float,
        ctx: JobContext,
        refine_cfg: dict | None = None,
    ) -> tuple[dict, dict]:
        """Register every view into one world, fuse, then photo-consistency-prune."""
        n = len(rgbs)
        mh, mw = rgbs[0].shape[:2]
        ww, wh = _work_resolution(mw, mh, budget)
        fy = (wh / 2.0) / math.tan(math.radians(FOV_DEG) / 2.0)
        fx = fy
        cx, cy = ww / 2.0, wh / 2.0

        parts: list[dict] = []
        views: list[dict] = []
        for i in range(n):
            d_work = downsample_float(depths[i], (ww, wh))
            rgb_work = np.asarray(
                Image.fromarray(rgbs[i]).resize((ww, wh), Image.LANCZOS), dtype=np.uint8
            )
            R_w, C_w = poses[i]
            parts.append(
                self._lift(d_work, rgb_work, fx, fy, cx, cy, (Z_NEAR + Z_FAR) / 2.0,
                           depth_strength, R_world=R_w, C_world=C_w)
            )
            views.append(
                {
                    "rgb": rgb_work,
                    "z": _z_cam(d_work, depth_strength).astype(np.float32),
                    "R": np.asarray(R_w, np.float32),
                    "C": np.asarray(C_w, np.float32),
                }
            )
            ctx.progress("lift", 0.48 + 0.34 * ((i + 1) / n), f"Registering view {i + 1}/{n}")
            ctx.check_canceled()

        merged = {k: np.concatenate([p[k] for p in parts], axis=0) for k in parts[0]}
        target = min(int(budget * FUSE_BUDGET_MULT), FUSE_BUDGET_CAP)
        ctx.progress("fuse", 0.85, f"Fusing {merged['positions'].shape[0]:,} samples…")
        fused = _voxel_fuse(merged, target)
        ctx.check_canceled()

        ctx.progress("fuse", 0.9, "Photo-consistency filtering…")
        fused, pruned = _photo_prune(fused, views, fx, fy, cx, cy, depth_strength)
        extras = {
            "temporal_model": "static",
            "work_resolution": [ww, wh],
            "photo_pruned": pruned,
        }

        if refine_cfg and refine_available():
            # multi-view supervision: every pose is a training view
            rw, rh = render_resolution(ww, wh)
            fxr, fyr, cxr, cyr = scale_intrinsics(fx, fy, cx, cy, (ww, wh), (rw, rh))
            step = max(1, math.ceil(n / REFINE_MAX_VIEWS))
            rviews = [
                RefineView(
                    target=np.asarray(
                        Image.fromarray(v["rgb"]).resize((rw, rh), Image.LANCZOS),
                        dtype=np.uint8,
                    ),
                    R=v["R"], C=v["C"], fx=fxr, fy=fyr, cx=cxr, cy=cyr,
                )
                for v in views[::step]
            ]
            fused, rman = self._refine_static(fused, rviews, ctx, refine_cfg, 0.905, 0.92)
            extras.update(rman)
        elif refine_cfg:
            extras["refine_error"] = "torch unavailable"
        return fused, extras

    # -------------------------------------------------------------- spacetime
    def _reconstruct_spacetime(
        self,
        rgbs: list[np.ndarray],
        depths: list[np.ndarray],
        mw: int,
        mh: int,
        budget: int,
        depth_strength: float,
        ctx: JobContext,
        refine_cfg: dict | None = None,
    ) -> tuple[dict, TrackSet | None, int, dict]:
        """Static-canvas + trajectory reconstruction for a static-camera clip."""
        n = len(rgbs)
        static_budget = min(budget * STATIC_MULT, STATIC_CAP, mw * mh)
        ww, wh = _work_resolution(mw, mh, static_budget)
        fy = (wh / 2.0) / math.tan(math.radians(FOV_DEG) / 2.0)
        fx = fy
        cx, cy = ww / 2.0, wh / 2.0
        cam_z = (Z_NEAR + Z_FAR) / 2.0

        rgbs_w = [
            np.asarray(Image.fromarray(r).resize((ww, wh), Image.LANCZOS), dtype=np.uint8)
            for r in rgbs
        ]
        depths_w = [downsample_float(d, (ww, wh)) for d in depths]

        ctx.progress("register", 0.46, "Stabilizing…")
        rgbs_w, depths_w, stab = stabilize_frames(rgbs_w, depths_w)
        ctx.check_canceled()

        ctx.progress("decompose", 0.5, "Separating static scene from motion…")
        dec: Decomposition = decompose(rgbs_w, depths_w)
        ctx.check_canceled()

        # A near-stationary subject (someone standing at a counter) is too still for
        # the motion masks to catch, so the temporal median bakes them into the
        # static canvas as a frozen ghost. If subject segmentation is available,
        # mask the moving foreground and re-decompose: the subject drops out of the
        # canvas (its hole inpainted) and is carried by trajectories instead.
        subj_backend = "unavailable"
        subj_frac = 0.0
        if segment_available():
            ctx.progress("segment", 0.52, "Segmenting moving subject…")
            subj, sstats = subject_masks(rgbs_w, dec.masks)
            subj_backend, subj_frac = sstats["backend"], sstats["subject_frac"]
            if subj_frac > 0.0:
                dec = decompose(rgbs_w, depths_w, subject_masks=subj)
            ctx.check_canceled()

        extras: dict = {
            "work_resolution": [ww, wh],
            "dynamic_fraction": round(dec.dynamic_fraction, 4),
            "stabilized": stab.applied,
            "flow_backend": flow_backend_name(),
            "subject_backend": subj_backend,
            "subject_frac": subj_frac,
        }

        # a clip where nothing moves is a still — one crisp, dense 3D frame
        if dec.dynamic_fraction < MIN_DYNAMIC:
            static = self._lift_static(dec, fx, fy, cx, cy, cam_z, depth_strength)
            extras["temporal_model"] = "static"
            if refine_cfg and refine_available():
                rviews = self._frame_refine_views(rgbs_w, None, ww, wh, fx, fy, cx, cy, cam_z)
                static, rman = self._refine_static(static, rviews, ctx, refine_cfg, 0.6, 0.92)
                extras.update(rman)
            elif refine_cfg:
                extras["refine_error"] = "torch unavailable"
            return static, None, 1, extras

        # no usable background (handheld / global motion) → everything is
        # dynamic; tracks still fuse temporally where flow holds
        all_dynamic = dec.dynamic_fraction > MAX_DYNAMIC
        if all_dynamic:
            masks = [np.ones((wh, ww), np.float32) for _ in range(n)]
            static = {
                "positions": np.zeros((0, 3), np.float32),
                "scales": np.zeros((0, 3), np.float32),
                "colors": np.zeros((0, 3), np.uint8),
                "opacities": np.zeros((0,), np.uint8),
                "rotations": np.zeros((0, 4), np.int8),
            }
            track_budget = budget
        else:
            masks = dec.masks
            ctx.progress("decompose", 0.54, "Fusing static canvas…")
            static = self._lift_static(dec, fx, fy, cx, cy, cam_z, depth_strength)
            track_budget = budget

        def track_progress(done: int, total: int) -> None:
            ctx.check_canceled()
            ctx.progress("track", 0.56 + 0.3 * (done / total), f"Tracking motion {done}/{total}")

        tracks_px, tstats = build_tracks(
            rgbs_w, depths_w, masks, budget=track_budget, progress=track_progress
        )
        ctx.check_canceled()

        ctx.progress("assemble", 0.88, f"Lifting {len(tracks_px):,} trajectories…")
        track_set = self._lift_tracks(
            tracks_px, depths_w, masks, n, fx, fy, cx, cy, cam_z, depth_strength,
            stride=int(tstats.get("stride", 1)),
        )
        extras.update(
            {
                "temporal_model": "spacetime" if not all_dynamic else "spacetime-full",
                "flow_backend": tstats.get("flow", flow_backend_name()),
                "track_stride": tstats.get("stride"),
                "mean_track_len": round(float(tstats.get("mean_len", 0.0)), 2),
            }
        )

        if refine_cfg and not all_dynamic and static["positions"].shape[0]:
            if refine_available():
                # supervise the canvas against the real frames, moving pixels
                # masked out of the loss (they belong to the tracks, not to it)
                rviews = self._frame_refine_views(
                    rgbs_w, dec.masks, ww, wh, fx, fy, cx, cy, cam_z
                )
                static, rman = self._refine_static(static, rviews, ctx, refine_cfg, 0.885, 0.92)
                extras.update(rman)
            else:
                extras["refine_error"] = "torch unavailable"
        return static, track_set, n, extras

    @staticmethod
    def _frame_refine_views(
        rgbs_w: list[np.ndarray],
        masks: list[np.ndarray] | None,
        ww: int, wh: int,
        fx: float, fy: float, cx: float, cy: float, cam_z: float,
    ) -> list[RefineView]:
        """Identity-pose supervision views for the static canvas: each source
        frame is a target, with moving regions masked OUT of the loss."""
        rw, rh = render_resolution(ww, wh)
        fxr, fyr, cxr, cyr = scale_intrinsics(fx, fy, cx, cy, (ww, wh), (rw, rh))
        n = len(rgbs_w)
        idx = np.unique(np.linspace(0, n - 1, min(16, n)).round().astype(int))
        eye = np.eye(3, dtype=np.float32)
        C = np.array([0.0, 0.0, cam_z], np.float32)
        views: list[RefineView] = []
        for i in idx:
            target = np.asarray(
                Image.fromarray(rgbs_w[i]).resize((rw, rh), Image.LANCZOS), dtype=np.uint8
            )
            weight = None
            if masks is not None:
                weight = np.clip(1.0 - downsample_float(masks[i], (rw, rh)), 0.0, 1.0)
            views.append(RefineView(target=target, R=eye, C=C,
                                    fx=fxr, fy=fyr, cx=cxr, cy=cyr, weight=weight))
        return views

    def _lift_static(self, dec: Decomposition, fx, fy, cx, cy, cam_z, strength) -> dict:
        """Lift the fused background canvas once, confidence-weighted."""
        # low-confidence pixels (subject rarely moved off them / inpainted) get
        # softer opacity so guesses read as fill, not fact
        conf = np.clip(dec.static_conf * 1.6, 0.0, 1.0)
        opacity_map = (0.55 + 0.45 * conf).astype(np.float32)
        return self._lift(
            dec.static_depth, dec.static_rgb, fx, fy, cx, cy, cam_z, strength,
            opacity_map=opacity_map,
        )

    def _lift_tracks(
        self,
        tracks_px: list[PixelTrack],
        depths_w: list[np.ndarray],
        masks: list[np.ndarray],
        num_cp: int,
        fx: float,
        fy: float,
        cx: float,
        cy: float,
        cam_z: float,
        strength: float,
        *,
        stride: int,
    ) -> TrackSet | None:
        """Convert pixel trajectories into world-space gaussian tracks."""
        if not tracks_px:
            return None

        # bound file size: uniform thinning ≈ a coarser spawn grid
        rng = np.random.default_rng(7)
        if len(tracks_px) > TRACKS_MAX:
            keep = rng.choice(len(tracks_px), TRACKS_MAX, replace=False)
            tracks_px = [tracks_px[i] for i in sorted(keep)]
        total_pos = sum(len(t.xs) for t in tracks_px)
        if total_pos > POS_STREAM_MAX:
            frac = POS_STREAM_MAX / total_pos
            keep = rng.random(len(tracks_px)) < frac
            tracks_px = [t for t, k in zip(tracks_px, keep) if k]

        D = len(tracks_px)
        births = np.array([t.birth for t in tracks_px], dtype=np.int64)
        deaths = np.array([t.death for t in tracks_px], dtype=np.int64)
        lens = deaths - births + 1
        offsets = np.zeros(D, dtype=np.int64)
        np.cumsum(lens[:-1], out=offsets[1:])
        P = int(lens.sum())

        positions = np.empty((P, 3), np.float32)
        colors = np.empty((D, 3), np.uint8)
        scales = np.empty((D, 3), np.float32)
        rotations = np.empty((D, 4), np.int8)
        opacities = np.empty(D, np.uint8)

        h, w = depths_w[0].shape
        # unproject every stream sample analytically (identity pose)
        all_x = np.concatenate([np.asarray(t.xs, np.float32) for t in tracks_px])
        all_y = np.concatenate([np.asarray(t.ys, np.float32) for t in tracks_px])
        all_z01 = np.concatenate([np.asarray(t.zs, np.float32) for t in tracks_px])
        z = np.asarray(_z_cam(np.clip(all_z01, 0.0, 1.0), strength), np.float32)
        positions[:, 0] = (all_x - cx) / fx * z
        positions[:, 1] = (cy - all_y) / fy * z
        positions[:, 2] = cam_z - z

        # colors: robust median over each track's lifetime samples
        for i, t in enumerate(tracks_px):
            cs = np.asarray(t.colors, dtype=np.float32)
            colors[i] = np.clip(np.median(cs, axis=0) + 0.5, 0, 255).astype(np.uint8)

        # orientation / size / opacity from the birth-frame surface
        birth_x = np.array([t.xs[0] for t in tracks_px], np.float32)
        birth_y = np.array([t.ys[0] for t in tracks_px], np.float32)
        birth_z = z[offsets]
        for b in np.unique(births):
            sel = np.flatnonzero(births == b)
            d = depths_w[b]
            zb = np.asarray(_z_cam(d, strength), np.float32)
            # world-space point grid of the birth frame → normals at track px
            ys_g, xs_g = np.mgrid[0:h, 0:w].astype(np.float32)
            Xg = (xs_g - cx) / fx * zb
            Yg = (cy - ys_g) / fy * zb
            Pg = np.stack([Xg, Yg, cam_z - zb], axis=-1)
            gx = np.gradient(Pg, axis=1)
            gy = np.gradient(Pg, axis=0)
            normal = np.cross(gx, gy)
            nl = np.linalg.norm(normal, axis=-1, keepdims=True)
            normal = normal / (nl + 1e-8)
            xi = np.clip(birth_x[sel].astype(np.int32), 0, w - 1)
            yi = np.clip(birth_y[sel].astype(np.int32), 0, h - 1)
            nrm = normal[yi, xi]
            view = np.array([0.0, 0.0, cam_z], np.float32)[None, :] - positions[offsets[sel]]
            view /= np.linalg.norm(view, axis=1, keepdims=True) + 1e-8
            facing = np.sum(nrm * view, axis=1)
            nrm = np.where(facing[:, None] < 0, -nrm, nrm)
            facing = np.abs(facing)
            t1, t2 = _orthonormal_frame(nrm)
            quat = _frames_to_quat(t1, t2, nrm.astype(np.float32))
            rotations[sel] = np.clip(quat * 127.0, -127, 127).astype(np.int8)

            # splat radius covers the spawn grid; thin along the normal
            s = birth_z[sel] / fx * max(stride, 1) * 0.9
            scales[sel] = np.stack([s, s, s * 0.18], axis=1)

            # opacity: surface facing × frame-border feather × mask-core weight
            fxn = np.minimum(birth_x[sel], w - 1 - birth_x[sel]) / max(w * 0.12, 1.0)
            fyn = np.minimum(birth_y[sel], h - 1 - birth_y[sel]) / max(h * 0.12, 1.0)
            feather = np.clip(np.minimum(fxn, fyn), 0.0, 1.0)
            feather = feather * feather * (3.0 - 2.0 * feather)
            core = np.clip(masks[b][yi, xi], 0.0, 1.0)
            opac = (215.0 + 40.0 * facing) * feather * (0.55 + 0.45 * core)
            opacities[sel] = np.clip(opac, 30, 255).astype(np.uint8)

        flags = np.where(births > 0, TRACK_FADE_IN, 0) | np.where(
            deaths < num_cp - 1, TRACK_FADE_OUT, 0
        )
        return TrackSet(
            births=births,
            deaths=deaths,
            scales=scales,
            colors=colors,
            opacities=opacities,
            rotations=rotations,
            offsets=offsets.astype(np.uint32),
            flags=flags.astype(np.uint32),
            positions=positions,
        )

    def _lift(self, depth, rgb, fx, fy, cx, cy, cam_z, strength, *,
              R_world=None, C_world=None, opacity_map=None) -> dict:
        """Unproject one depth+rgb frame into oriented gaussians, in world space.

        With the default pose (identity rotation, camera at +cam_z) this reproduces
        the original single-view lift. Given an estimated camera→world pose, the
        point grid is rigidly transformed *before* normals are computed, so the
        oriented disc + quaternion come out correctly in the shared world frame.
        ``opacity_map`` optionally scales per-pixel opacity (confidence weighting).
        """
        h, w = depth.shape
        ys, xs = np.mgrid[0:h, 0:w].astype(np.float32)

        # edge feather: fade opacity toward the frame border so the frustum
        # doesn't read as a hard-cut slab (softer, render-like silhouette).
        fxn = np.minimum(xs, w - 1 - xs) / max(w * 0.12, 1.0)
        fyn = np.minimum(ys, h - 1 - ys) / max(h * 0.12, 1.0)
        feather = np.clip(np.minimum(fxn, fyn), 0.0, 1.0)
        feather = feather * feather * (3.0 - 2.0 * feather)  # smoothstep

        # perspective unprojection: distance in front of camera from [0,1] depth
        z_cam = Z_FAR - depth * (Z_FAR - Z_NEAR) * strength  # near(d=1)→Z_NEAR
        X = (xs - cx) / fx * z_cam
        Y = (cy - ys) / fy * z_cam
        Zc = -z_cam  # camera-local: camera at origin, forward −Z
        P = np.stack([X, Y, Zc], axis=-1).reshape(-1, 3)  # (h*w,3) camera-local

        if R_world is None:
            R_world = np.eye(3, dtype=np.float32)
        if C_world is None:
            C_world = np.array([0.0, 0.0, cam_z], dtype=np.float32)
        C_world = np.asarray(C_world, np.float32)
        P = (P @ np.asarray(R_world, np.float32).T + C_world).reshape(h, w, 3)

        # surface normals + per-pixel spacing from the (world-space) point grid
        gx = np.gradient(P, axis=1)  # d/dx (cols)
        gy = np.gradient(P, axis=0)  # d/dy (rows)
        normal = np.cross(gx, gy)
        nlen = np.linalg.norm(normal, axis=-1, keepdims=True)
        normal = normal / (nlen + 1e-8)

        # orient toward the camera *center* (view direction), in world space
        view = C_world.reshape(1, 1, 3) - P
        view = view / (np.linalg.norm(view, axis=-1, keepdims=True) + 1e-8)
        facing = np.sum(normal * view, axis=-1, keepdims=True)
        normal = np.where(facing < 0, -normal, normal)
        facing = np.abs(facing)

        step_x = np.linalg.norm(gx, axis=-1)
        step_y = np.linalg.norm(gy, axis=-1)
        spacing = np.maximum(step_x, step_y)
        expected = z_cam / fx  # expected world spacing of 1px at this depth

        # cull occlusion edges (rubber-sheet) + degenerate normals
        keep = (
            (spacing < EDGE_CULL_FACTOR * expected)
            & (nlen[..., 0] > 1e-6)
            & np.isfinite(spacing)
        )
        mask = keep.ravel()

        P = P.reshape(-1, 3)[mask]
        normal = normal.reshape(-1, 3)[mask]
        colors = rgb.reshape(-1, 3)[mask].astype(np.uint8)
        s = np.clip(spacing.reshape(-1)[mask] * 0.85, 1e-5, None)

        t1, t2 = _orthonormal_frame(normal)
        quat = _frames_to_quat(t1, t2, normal)
        rot = np.clip(quat * 127.0, -127, 127).astype(np.int8)

        # flat oriented discs (thin along the surface normal) so EWA projection
        # yields crisp surface splats; tangent radius ~1px for sharpness
        scales = np.stack([s * 0.95, s * 0.95, s * 0.16], axis=1).astype(np.float32)
        feather_m = feather.reshape(-1)[mask]
        facing_m = facing.reshape(-1)[mask]
        opac = np.clip((215 + 40 * facing_m) * feather_m, 40, 255)
        if opacity_map is not None:
            opac = opac * np.clip(opacity_map.reshape(-1)[mask], 0.0, 1.0)
        opac = np.clip(opac, 24, 255).astype(np.uint8)

        return {
            "positions": P.astype(np.float32),
            "scales": scales,
            "colors": colors,
            "opacities": opac,
            "rotations": rot,
        }
```

### api/app/pipeline/motion.py
```
"""Camera-motion estimation — the difference between a 2.5D relief and real 3D.

A pan/orbit around a *static* subject is a multi-**view** capture, not a
multi-**time** one: every frame sees the same object from a different angle.
The base pipeline ignores this and stacks every frame at the same camera pose,
so the back and sides never fill in. This module recovers the camera trajectory
so the engine can register all frames into one shared world and fuse them into a
genuine walk-around model.

Pipeline (per consecutive frame pair):
  * ORB features + ratio-test matching
  * essential matrix (RANSAC) with intrinsics from the assumed FOV → relative R,t
  * **scale the unit translation using monocular depth** of the matched points —
    the linchpin that turns a chain of up-to-scale hops into one metric trajectory
  * chain into global camera→world poses (frame 0 = world origin)

From the trajectory we measure *parallax* (baseline / scene depth) and classify
the clip as ``orbit`` (fuse to 3D), ``motion`` (keep per-frame 4D), or
``low-confidence`` (fall back to 4D). Everything degrades gracefully: no OpenCV,
a textureless clip, or a failed solve all fall back to the original behaviour, so
the result is never worse than before — only, when the motion is real, far better.

Coordinate conventions: OpenCV cameras look down +Z with +Y *down*; the engine's
lifted clouds use +Y *up*, forward −Z (OpenGL). We solve in OpenCV space and hand
the engine poses already converted to its convention (``F = diag(1, -1, -1)``).
"""
from __future__ import annotations

import importlib.util
import math
from dataclasses import dataclass, field

import numpy as np

# --- tunables ---------------------------------------------------------------
POSE_MAX = 720          # longest side fed to feature detection (speed)
ORB_FEATURES = 2500
MIN_MATCHES = 30        # below this a pair is considered unsolvable
MIN_INLIERS = 15        # below this the recovered pose is untrusted
RATIO = 0.75            # Lowe ratio test
# classification gates (conservative — only fuse when motion is unambiguous)
PARALLAX_FUSE = 0.12    # cumulative baseline/depth needed to call it an orbit
MIN_CONFIDENCE = 0.25   # mean inlier ratio below this ⇒ low-confidence ⇒ 4D
MIN_PAIR_FRAC = 0.5     # fraction of pairs that must solve cleanly

# OpenCV camera frame → engine frame (flip Y and Z).
_F = np.diag([1.0, -1.0, -1.0]).astype(np.float64)


@dataclass
class MotionResult:
    """Recovered trajectory + a verdict on how to reconstruct the clip."""

    backend: str                 # "opencv" | "unavailable"
    mode: str                    # "orbit" | "motion" | "low-confidence" | "unavailable"
    fuse: bool                   # engine should fuse into one 3D model
    # per-frame camera→world in *engine* convention: (R 3x3, C 3). None ⇒ 4D.
    poses: list[tuple[np.ndarray, np.ndarray]] | None
    camera_path: list[list[float]] = field(default_factory=list)  # world centers
    motion_score: float = 0.0    # ~0..1 normalized parallax
    confidence: float = 0.0      # mean inlier ratio over solved pairs
    n_pairs_ok: int = 0
    n_pairs: int = 0

    @property
    def available(self) -> bool:
        return self.backend == "opencv"


def pose_backend_name() -> str:
    """Best-effort report of the pose backend (no heavy import)."""
    return "opencv" if importlib.util.find_spec("cv2") else "unavailable"


def _intrinsics(w: int, h: int, fov_deg: float) -> np.ndarray:
    fy = (h / 2.0) / math.tan(math.radians(fov_deg) / 2.0)
    fx = fy
    return np.array([[fx, 0, w / 2.0], [0, fy, h / 2.0], [0, 0, 1.0]], dtype=np.float64)


def _depth_to_z(depth01: np.ndarray, z_near: float, z_far: float) -> np.ndarray:
    """Map normalized depth (1=near) to camera-space distance, matching the engine."""
    return z_far - np.clip(depth01, 0.0, 1.0) * (z_far - z_near)


def _rotation_angle_deg(R: np.ndarray) -> float:
    c = (np.trace(R) - 1.0) / 2.0
    return math.degrees(math.acos(max(-1.0, min(1.0, c))))


def estimate_motion(
    rgbs: list[np.ndarray],
    depths01: list[np.ndarray],
    *,
    fov_deg: float,
    z_near: float,
    z_far: float,
    forced_mode: str | None = None,
) -> MotionResult:
    """Estimate the camera trajectory and decide orbit-fuse vs per-frame 4D.

    ``rgbs`` / ``depths01`` are same-resolution per-frame arrays (uint8 HxWx3 and
    float32 HxW in [0,1], 1=near). ``forced_mode`` ∈ {auto, orbit, motion, None}.
    """
    n = len(rgbs)
    if forced_mode == "motion":
        return MotionResult(backend=pose_backend_name(), mode="motion", fuse=False, poses=None)
    if pose_backend_name() != "opencv" or n < 3:
        return MotionResult(backend="unavailable", mode="unavailable", fuse=False, poses=None)

    import cv2

    h0, w0 = rgbs[0].shape[:2]
    scale = min(1.0, POSE_MAX / max(h0, w0))
    pw, ph = int(round(w0 * scale)), int(round(h0 * scale))
    K = _intrinsics(pw, ph, fov_deg)
    fx, fy, cx, cy = K[0, 0], K[1, 1], K[0, 2], K[1, 2]

    # ---- per-frame features + depth (at pose resolution) --------------------
    orb = cv2.ORB_create(nfeatures=ORB_FEATURES)
    grays, kps, descs, zmaps = [], [], [], []
    for rgb, d in zip(rgbs, depths01):
        g = cv2.cvtColor(cv2.resize(rgb, (pw, ph), interpolation=cv2.INTER_AREA), cv2.COLOR_RGB2GRAY)
        k, de = orb.detectAndCompute(g, None)
        grays.append(g)
        kps.append(k)
        descs.append(de)
        zr = cv2.resize(d.astype(np.float32), (pw, ph), interpolation=cv2.INTER_LINEAR)
        zmaps.append(_depth_to_z(zr, z_near, z_far))

    bf = cv2.BFMatcher(cv2.NORM_HAMMING)

    def backproject(pts: np.ndarray, z: np.ndarray) -> np.ndarray:
        u = np.clip(pts[:, 0], 0, pw - 1).astype(int)
        v = np.clip(pts[:, 1], 0, ph - 1).astype(int)
        zz = z[v, u]
        X = (pts[:, 0] - cx) / fx * zz
        Y = (pts[:, 1] - cy) / fy * zz
        return np.stack([X, Y, zz], axis=1)  # OpenCV camera frame

    # ---- relative pose per consecutive pair ---------------------------------
    rels: list[tuple[np.ndarray, np.ndarray, float, float] | None] = []
    for i in range(n - 1):
        rels.append(_solve_pair(cv2, bf, kps[i], descs[i], kps[i + 1], descs[i + 1],
                                zmaps[i], zmaps[i + 1], K, backproject))

    solved = [r for r in rels if r is not None]
    n_pairs = n - 1
    n_ok = len(solved)
    if n_ok == 0:
        return MotionResult(backend="opencv", mode="low-confidence", fuse=False,
                            poses=None, n_pairs=n_pairs)

    confidence = float(np.mean([r[3] for r in solved]))

    # ---- chain into global camera→world poses (OpenCV frame) ----------------
    poses_cv: list[np.ndarray] = [np.eye(4)]
    cum_parallax = 0.0
    cum_rot = 0.0
    depth_ref = float(np.median([np.median(z) for z in zmaps])) or 1.0
    for i, r in enumerate(rels):
        M = poses_cv[-1]
        if r is None:  # carry the pose forward unchanged on a failed hop
            poses_cv.append(M.copy())
            continue
        R, t, s, _ = r
        T = np.eye(4)
        T[:3, :3] = R
        T[:3, 3] = s * t  # cam_i → cam_{i+1}
        poses_cv.append(M @ np.linalg.inv(T))
        cum_parallax += abs(s) / depth_ref
        cum_rot += _rotation_angle_deg(R)

    # convert camera→world to engine convention; recenter path on its centroid
    poses_engine: list[tuple[np.ndarray, np.ndarray]] = []
    centers = []
    for M in poses_cv:
        R_eng = _F @ M[:3, :3] @ _F
        C_eng = _F @ M[:3, 3]
        poses_engine.append((R_eng.astype(np.float32), C_eng.astype(np.float32)))
        centers.append(C_eng)
    centers = np.asarray(centers)

    motion_score = float(min(1.0, cum_parallax / 0.3))

    # ---- verdict ------------------------------------------------------------
    enough_pairs = n_ok >= max(2, int(MIN_PAIR_FRAC * n_pairs))
    trustworthy = confidence >= MIN_CONFIDENCE and enough_pairs
    is_orbit = cum_parallax >= PARALLAX_FUSE

    if forced_mode == "orbit":
        fuse, mode = True, "orbit"
    elif not trustworthy:
        fuse, mode = False, "low-confidence"
    elif is_orbit:
        fuse, mode = True, "orbit"
    else:
        fuse, mode = False, "motion"

    return MotionResult(
        backend="opencv",
        mode=mode,
        fuse=fuse,
        poses=poses_engine if fuse else None,
        camera_path=centers.tolist() if fuse else [],
        motion_score=motion_score,
        confidence=confidence,
        n_pairs_ok=n_ok,
        n_pairs=n_pairs,
    )


def _solve_pair(cv2, bf, k1, d1, k2, d2, z1, z2, K, backproject):
    """One frame pair → (R, t_unit, scale, inlier_ratio) or None if unsolvable."""
    if d1 is None or d2 is None or len(k1) < MIN_MATCHES or len(k2) < MIN_MATCHES:
        return None
    knn = bf.knnMatch(d1, d2, k=2)
    good = [m for pair in knn if len(pair) == 2 for m, nmatch in [pair] if m.distance < RATIO * nmatch.distance]
    if len(good) < MIN_MATCHES:
        return None

    pts1 = np.float32([k1[m.queryIdx].pt for m in good])
    pts2 = np.float32([k2[m.trainIdx].pt for m in good])
    E, mask = cv2.findEssentialMat(pts1, pts2, K, method=cv2.RANSAC, prob=0.999, threshold=1.0)
    if E is None or E.shape != (3, 3):
        return None
    _, R, t, mask2 = cv2.recoverPose(E, pts1, pts2, K, mask=mask)
    t = t.reshape(3)
    inl = (mask2.ravel() > 0)
    n_inl = int(inl.sum())
    if n_inl < MIN_INLIERS:
        return None
    ratio = n_inl / len(good)

    # metric scale from depth: x2 ≈ R·x1 + s·t  ⇒  s = median t·(x2 − R·x1)
    X1 = backproject(pts1[inl], z1)
    X2 = backproject(pts2[inl], z2)
    resid = X2 - (R @ X1.T).T
    s = float(np.median(resid @ t))
    if not math.isfinite(s):
        return None
    return R, t, s, ratio
```

### api/app/pipeline/refine.py
```
"""Differentiable splat refinement — the optimization pass of a real 3DGS.

The feed-forward pipeline lifts depth into gaussians; this module *trains* them.
Every gaussian parameter (position, scale, rotation, opacity, color) is made a
torch tensor and optimized to minimize photometric error against the actual
source frames, rendered through a differentiable splatter. It is what separates
"a clever lift" from an optimized gaussian splat: colors sharpen, mis-lifted
splats fade out (and are pruned), surviving splats settle onto the surfaces the
camera really saw.

The renderer is a pure-PyTorch approximation chosen to run WITHOUT custom CUDA
kernels (so it works on Apple MPS): each gaussian rasterizes a small P×P patch
around its projected center, contributions are accumulated into D depth-bin
buffers with ``index_add_``, bins composite front-to-back with a soft absorption
(within-bin order-independent — fine for refinement, where the initialization
is already near the answer). Measured ≈2.6 it/s at 300k gaussians / 320×180 on
an Apple-silicon MPS device; a refine pass is minutes, not hours.

Camera model matches the engine/viewer exactly: camera→world pose (R, C),
looking −Z, +Y up, ``u = cx + fx·x/d``, ``v = cy − fy·y/d`` with d the distance
in front of the camera. Everything degrades gracefully: no torch ⇒ the pass is
skipped; any runtime failure returns the input gaussians untouched.
"""
from __future__ import annotations

import math
import time
from dataclasses import dataclass, field

import numpy as np

from .depth import _torch_stack_available  # same gate as the depth model

# renderer geometry (validated by the throughput spike)
PATCH = 7                # rasterized window per gaussian (pixels)
DEPTH_BINS = 16          # soft-OIT depth slices
RENDER_MAX = 320         # long side of the supervision render
COV_DILATE = 0.3         # 2D covariance low-pass (matches viewer's + antialias)

# optimization
LR_POS_FRAC = 1.5e-4     # position lr as a fraction of scene extent
LR_LOG_SCALE = 4e-3
LR_COLOR = 1.2e-2
LR_OPACITY = 4e-2
LR_QUAT = 2e-3
OPACITY_REG = 0.008      # mean-opacity pull — lets wrong splats die
PRUNE_OPACITY = 0.03     # absolute floor: dead after training ⇒ removed
PRUNE_REL = 0.35         # …or faded to this fraction of its initial opacity:
                         # the photometric gradient vanishes as a splat fades,
                         # so an actively-killed splat asymptotes low but not
                         # at zero — the relative drop is the reliable signal
                         # (and it spares legitimately-faint feathered edges)
EVAL_VIEWS = 4           # PSNR measured on this many views before/after


@dataclass
class RefineView:
    """One supervision view at render resolution."""

    target: np.ndarray                    # (H, W, 3) uint8
    R: np.ndarray                         # (3, 3) camera→world rotation
    C: np.ndarray                         # (3,) camera center, world
    fx: float
    fy: float
    cx: float
    cy: float
    weight: np.ndarray | None = None      # (H, W) float in [0,1] — loss mask


@dataclass
class RefineStats:
    device: str = "unavailable"
    iterations: int = 0
    views: int = 0
    seconds: float = 0.0
    psnr_before: float = 0.0
    psnr_after: float = 0.0
    pruned: int = 0
    error: str | None = None

    def as_manifest(self) -> dict:
        out = {
            "refined": self.error is None and self.iterations > 0,
            "refine_device": self.device,
            "refine_iterations": self.iterations,
            "refine_views": self.views,
            "refine_seconds": round(self.seconds, 1),
            "refine_psnr_before": round(self.psnr_before, 2),
            "refine_psnr_after": round(self.psnr_after, 2),
            "refine_pruned": self.pruned,
        }
        if self.error:
            out["refine_error"] = self.error
        return out


def refine_available() -> bool:
    return _torch_stack_available()


def _device(torch):
    if torch.backends.mps.is_available():
        return "mps"
    if torch.cuda.is_available():
        return "cuda"
    return "cpu"


def _logit(x: np.ndarray, eps: float = 1e-4) -> np.ndarray:
    x = np.clip(x, eps, 1.0 - eps)
    return np.log(x / (1.0 - x))


def refine_gaussians(
    gaussians: dict,
    views: list[RefineView],
    *,
    iterations: int,
    time_budget_s: float = 300.0,
    progress=None,
    seed: int = 0,
) -> tuple[dict, RefineStats]:
    """Optimize a gaussian dict photometrically against ``views``.

    Returns (refined_gaussians, stats). On any internal failure the ORIGINAL
    gaussians come back with ``stats.error`` set — refinement never loses data.
    Cancellation raised from ``progress`` propagates (it is not a failure).
    """
    stats = RefineStats(views=len(views))
    n = int(gaussians["positions"].shape[0])
    if not refine_available():
        stats.error = "torch unavailable"
        return gaussians, stats
    if n == 0 or not views or iterations <= 0:
        stats.error = "nothing to refine"
        return gaussians, stats

    from .base import JobCanceled  # circular-safe: base has no pipeline imports

    try:
        return _refine_impl(gaussians, views, iterations, time_budget_s, progress, seed, stats)
    except JobCanceled:
        raise
    except Exception as exc:  # OOM, driver hiccups… keep the un-refined model
        stats.error = f"{exc.__class__.__name__}: {exc}"
        return gaussians, stats


def _refine_impl(gaussians, views, iterations, time_budget_s, progress, seed, stats):
    import torch

    dev = torch.device(_device(torch))
    stats.device = str(dev)
    torch.manual_seed(seed)
    rng = np.random.default_rng(seed)

    # ---- parameters ---------------------------------------------------------
    pos0 = gaussians["positions"].astype(np.float32)
    extent = float(np.abs(pos0 - pos0.mean(axis=0)).max()) or 1.0
    pos = torch.tensor(pos0, device=dev, requires_grad=True)
    log_scale = torch.tensor(
        np.log(np.clip(gaussians["scales"].astype(np.float32), 1e-6, None)),
        device=dev, requires_grad=True,
    )
    color = torch.tensor(
        _logit(gaussians["colors"].astype(np.float32) / 255.0), device=dev, requires_grad=True
    )
    opacity = torch.tensor(
        _logit(gaussians["opacities"].astype(np.float32) / 255.0), device=dev, requires_grad=True
    )
    quat = torch.tensor(
        gaussians["rotations"].astype(np.float32) / 127.0, device=dev, requires_grad=True
    )

    # ---- views to tensors ---------------------------------------------------
    tviews = []
    for v in views:
        h, w = v.target.shape[:2]
        weight = v.weight if v.weight is not None else np.ones((h, w), np.float32)
        tviews.append(
            {
                "target": torch.tensor(v.target.astype(np.float32) / 255.0, device=dev),
                "weight": torch.tensor(weight.astype(np.float32)[..., None], device=dev),
                # world→camera: Xc = Rᵀ (X − C)
                "Rt": torch.tensor(np.ascontiguousarray(v.R.T, dtype=np.float32), device=dev),
                "C": torch.tensor(v.C.astype(np.float32), device=dev),
                "fx": float(v.fx), "fy": float(v.fy),
                "cx": float(v.cx), "cy": float(v.cy),
                "h": h, "w": w,
            }
        )

    P = PATCH
    D = DEPTH_BINS
    ys, xs = torch.meshgrid(
        torch.arange(P, device=dev), torch.arange(P, device=dev), indexing="ij"
    )
    off_y = (ys - P // 2).reshape(-1).float()
    off_x = (xs - P // 2).reshape(-1).float()

    def quat_to_R(q):
        q = q / (q.norm(dim=1, keepdim=True) + 1e-8)
        x, y, z, w = q[:, 0], q[:, 1], q[:, 2], q[:, 3]
        return torch.stack(
            [
                1 - 2 * (y * y + z * z), 2 * (x * y - w * z), 2 * (x * z + w * y),
                2 * (x * y + w * z), 1 - 2 * (x * x + z * z), 2 * (y * z - w * x),
                2 * (x * z - w * y), 2 * (y * z + w * x), 1 - 2 * (x * x + y * y),
            ],
            dim=1,
        ).reshape(-1, 3, 3)

    # per-view depth range for binning, fixed from the initial model (positions
    # move by ~1e-2·extent during refinement; the 6% pad absorbs it)
    with torch.no_grad():
        for tv in tviews:
            Xc = (pos - tv["C"]) @ tv["Rt"].T
            d = (-Xc[:, 2]).clamp(min=1e-3)
            ds = d.sort().values  # (quantile is unreliable on MPS)
            lo = ds[int(0.02 * (ds.numel() - 1))].item()
            hi = ds[int(0.98 * (ds.numel() - 1))].item()
            pad = 0.06 * (hi - lo) + 1e-4
            tv["zlo"], tv["zhi"] = lo - pad, hi + pad

    CHUNK = 350_000  # bound peak memory of the scatter pass on big models

    def render(tv):
        h, w = tv["h"], tv["w"]
        n = pos.shape[0]
        buf = torch.zeros(D * h * w, 4, device=dev)
        for s in range(0, n, CHUNK):
            e = min(s + CHUNK, n)
            Xc = (pos[s:e] - tv["C"]) @ tv["Rt"].T         # (n,3) camera coords
            d = (-Xc[:, 2]).clamp(min=1e-3)
            x, y = Xc[:, 0], Xc[:, 1]
            u = tv["cx"] + tv["fx"] * x / d
            v = tv["cy"] - tv["fy"] * y / d

            R = quat_to_R(quat[s:e])
            S = torch.exp(log_scale[s:e])
            M = R * S[:, None, :]
            cov_w = M @ M.transpose(1, 2)                  # world covariance
            cov_c = tv["Rt"] @ cov_w @ tv["Rt"].T          # camera covariance

            J = torch.zeros(e - s, 2, 3, device=dev)
            J[:, 0, 0] = tv["fx"] / d
            J[:, 0, 2] = tv["fx"] * x / d ** 2
            J[:, 1, 1] = -tv["fy"] / d
            J[:, 1, 2] = -tv["fy"] * y / d ** 2
            cov2 = J @ cov_c @ J.transpose(1, 2)
            a = cov2[:, 0, 0] + COV_DILATE
            b = cov2[:, 0, 1]
            c = cov2[:, 1, 1] + COV_DILATE
            det = (a * c - b * b).clamp(min=1e-8)
            ia, ib, ic = c / det, -b / det, a / det

            # P×P patch of ACTUAL pixel centers around the projected mean; the
            # sub-pixel offset (px − u) keeps position gradients alive
            u0 = u.detach().round()
            v0 = v.detach().round()
            px = u0[:, None] + off_x[None, :]
            py = v0[:, None] + off_y[None, :]
            dx = px - u[:, None]
            dy = py - v[:, None]
            m = ia[:, None] * dx * dx + 2 * ib[:, None] * dx * dy + ic[:, None] * dy * dy
            alpha = torch.sigmoid(opacity[s:e])[:, None]
            wgt = torch.exp(-0.5 * m) * alpha              # (n, P²)

            inb = (px >= 0) & (px <= w - 1) & (py >= 0) & (py <= h - 1) & (d[:, None] > 1e-3)
            wgt = wgt * inb
            xi = px.long().clamp(0, w - 1)
            yi = py.long().clamp(0, h - 1)
            zb = ((d.detach() - tv["zlo"]) / (tv["zhi"] - tv["zlo"]) * D).long().clamp(0, D - 1)
            flat = (zb[:, None] * h + yi) * w + xi         # (n, P²)

            cols = torch.sigmoid(color[s:e])
            vals = torch.cat(
                [(wgt[..., None] * cols[:, None, :]).reshape(-1, 3), wgt.reshape(-1, 1)], dim=1
            )
            buf = buf.index_add(0, flat.reshape(-1), vals)
        buf = buf.reshape(D, h, w, 4)

        # front-to-back soft-absorption compositing over the depth bins
        out = torch.zeros(h, w, 3, device=dev)
        T = torch.ones(h, w, 1, device=dev)
        for k in range(D):
            Ssum = buf[k, ..., 3:4]
            A = 1 - torch.exp(-Ssum)
            Cc = buf[k, ..., :3] / (Ssum + 1e-6)
            out = out + T * A * Cc
            T = T * (1 - A)
        return out

    def view_loss(tv, render_out):
        werr = (render_out - tv["target"]).abs() * tv["weight"]
        return werr.sum() / (tv["weight"].sum() * 3.0 + 1e-6)

    def eval_psnr():
        with torch.no_grad():
            vals = []
            for tv in tviews[: min(EVAL_VIEWS, len(tviews))]:
                r = render(tv)
                mse = (((r - tv["target"]) ** 2) * tv["weight"]).sum() / (
                    tv["weight"].sum() * 3.0 + 1e-6
                )
                vals.append(-10.0 * math.log10(max(mse.item(), 1e-8)))
            return float(np.mean(vals))

    stats.psnr_before = eval_psnr()

    opt = torch.optim.Adam(
        [
            {"params": [pos], "lr": LR_POS_FRAC * extent},
            {"params": [log_scale], "lr": LR_LOG_SCALE},
            {"params": [color], "lr": LR_COLOR},
            {"params": [opacity], "lr": LR_OPACITY},
            {"params": [quat], "lr": LR_QUAT},
        ]
    )
    base_lrs = [g["lr"] for g in opt.param_groups]

    log_lo = math.log(1e-4 * extent)
    log_hi = math.log(0.08 * extent)

    t0 = time.time()
    order = rng.permutation(len(tviews))
    oi = 0
    done = 0
    for it in range(iterations):
        if time.time() - t0 > time_budget_s:
            break
        # cosine decay
        f = 0.5 * (1 + math.cos(math.pi * it / max(iterations, 1)))
        for g, lr0 in zip(opt.param_groups, base_lrs):
            g["lr"] = lr0 * (0.15 + 0.85 * f)

        tv = tviews[order[oi]]
        oi += 1
        if oi >= len(order):
            order = rng.permutation(len(tviews))
            oi = 0

        loss = view_loss(tv, render(tv)) + OPACITY_REG * torch.sigmoid(opacity).mean()
        loss.backward()
        opt.step()
        opt.zero_grad(set_to_none=True)
        with torch.no_grad():
            log_scale.clamp_(log_lo, log_hi)
        done = it + 1
        if progress and (done % 10 == 0 or done == iterations):
            progress(done, iterations, float(loss.item()))

    stats.iterations = done
    stats.psnr_after = eval_psnr()
    stats.seconds = time.time() - t0

    # ---- read back, prune, and re-quantize ----------------------------------
    with torch.no_grad():
        q = quat / (quat.norm(dim=1, keepdim=True) + 1e-8)
        op = torch.sigmoid(opacity)
        op_init = torch.tensor(
            gaussians["opacities"].astype(np.float32) / 255.0, device=dev
        ).clamp(min=1e-3)
        finite = (
            torch.isfinite(pos).all(dim=1)
            & torch.isfinite(log_scale).all(dim=1)
            & torch.isfinite(q).all(dim=1)
            & torch.isfinite(op)
        )
        keep = finite & (op > PRUNE_OPACITY) & (op > PRUNE_REL * op_init)
        stats.pruned = int((~keep).sum().item())

        def np_of(t):
            return t[keep].detach().to("cpu").numpy()

        out = {
            "positions": np_of(pos).astype(np.float32),
            "scales": np.exp(np_of(log_scale)).astype(np.float32),
            "colors": np.clip(np_of(torch.sigmoid(color)) * 255.0 + 0.5, 0, 255).astype(np.uint8),
            "opacities": np.clip(np_of(op) * 255.0 + 0.5, 1, 255).astype(np.uint8),
            "rotations": np.clip(np_of(q) * 127.0, -127, 127).astype(np.int8),
        }
    return out, stats

### api/app/pipeline/segment.py
```
"""Motion segmentation under a *moving* camera — the linchpin of the hybrid path.

When both the camera and the subject move (a handheld orbit around someone slicing
a banana), neither pure mode works: orbit-fusion smears the moving subject across
views, and the static-camera temporal median (``spacetime.decompose``) mistakes
camera-induced pixel change for motion. This module separates the two using the
geometry we already recover.

The idea is standard structure-from-motion reasoning: given a per-frame depth map
and the camera pose, the *rigid* scene induces a predictable optical flow between
two frames (back-project a pixel, reproject it into the next camera). Whatever the
real (measured) flow does *beyond* that prediction is motion the camera can't
explain — a moving object. So

    dynamic  ⇔  | measured_flow − rigid_flow |  ≫  (depth/pose noise floor)

Everything is in the engine's camera convention (camera→world ``(R, C)``, looking
−Z, +Y up; pixel ``u = cx + fx·x/d``, ``v = cy − fy·y/d`` with ``d`` the distance
in front of the camera), so the masks drop straight into the lift/fuse code.

Degrades gracefully: no OpenCV ⇒ no dense flow ⇒ empty masks (caller falls back to
a pose-fused still). The geometry (:func:`rigid_flow`, :func:`dynamic_mask`) is pure
numpy and unit-tested against synthetic ground truth.
"""
from __future__ import annotations

import importlib.util
from dataclasses import dataclass, field

import numpy as np

from .local_engine import Z_FAR, Z_NEAR

# --- tunables ----------------------------------------------------------------
RESID_K = 3.5           # residual must exceed this × the robust noise floor
RESID_FLOOR_PX = 0.75   # absolute floor (px) so a near-zero-noise frame still gates
GROW_ITERS = 2          # dilate the raw mask to cover motion-blur halo
SMOOTH_MIX = 0.8        # blend a pixel with its neighborhood (feather edges)


def flow_backend_name() -> str:
    return "opencv-dis" if importlib.util.find_spec("cv2") else "unavailable"


def _depth_to_z(depth01: np.ndarray) -> np.ndarray:
    """Normalized depth (1=near) → camera-space distance, matching the engine
    lift at strength 1.0 (the value the pose solver assumed)."""
    return Z_FAR - np.clip(depth01, 0.0, 1.0) * (Z_FAR - Z_NEAR)


def _reproject(
    xs: np.ndarray, ys: np.ndarray, z: np.ndarray,
    Ri: np.ndarray, Ci: np.ndarray,
    Rj: np.ndarray, Cj: np.ndarray,
    fx: float, fy: float, cx: float, cy: float,
) -> tuple[np.ndarray, np.ndarray, np.ndarray]:
    """Reproject pixels of frame i, at camera-distance ``z``, into frame j.

    Returns flat ``(u, v, front)`` where ``front`` marks points that land in
    front of camera j. Engine convention: forward −Z, +Y up, ``d = −Z_cam``.
    """
    Xc = (xs - cx) / fx * z
    Yc = (cy - ys) / fy * z
    Zc = -z
    Pc = np.stack([Xc, Yc, Zc], axis=-1).reshape(-1, 3)

    Ri = np.asarray(Ri, np.float32); Rj = np.asarray(Rj, np.float32)
    Ci = np.asarray(Ci, np.float32); Cj = np.asarray(Cj, np.float32)
    Pw = Pc @ Ri.T + Ci                       # camera i → world
    Pcj = (Pw - Cj) @ Rj                      # world → camera j (Rj^T on the right)
    d = -Pcj[:, 2]                            # distance in front of camera j
    front = d > 1e-4
    dd = np.where(front, d, 1.0)
    u = cx + fx * Pcj[:, 0] / dd
    v = cy - fy * Pcj[:, 1] / dd
    return u, v, front


def rigid_flow(
    depth01: np.ndarray,
    Ri: np.ndarray, Ci: np.ndarray,
    Rj: np.ndarray, Cj: np.ndarray,
    fx: float, fy: float, cx: float, cy: float,
) -> tuple[np.ndarray, np.ndarray]:
    """Optical flow that camera motion *alone* would induce from frame i to j.

    Back-projects every pixel of frame i (using its depth + pose i) to a world
    point, reprojects it through pose j, and returns the pixel displacement plus
    a validity mask (points that land behind camera j or off-frame are invalid).
    """
    h, w = depth01.shape
    ys, xs = np.mgrid[0:h, 0:w].astype(np.float32)
    z = _depth_to_z(depth01).astype(np.float32)
    u, v, front = _reproject(xs, ys, z, Ri, Ci, Rj, Cj, fx, fy, cx, cy)

    flow = np.stack([u - xs.reshape(-1), v - ys.reshape(-1)], axis=-1).reshape(h, w, 2)
    eps = 1e-3  # tolerate exact-boundary pixels (fp round-off at the frame edge)
    inb = (u >= -eps) & (u <= w - 1 + eps) & (v >= -eps) & (v <= h - 1 + eps)
    valid = (front & inb).reshape(h, w)
    flow = np.where(valid[..., None], flow, 0.0).astype(np.float32)
    return flow, valid


def epipolar_residual(
    measured_flow: np.ndarray,
    Ri: np.ndarray, Ci: np.ndarray,
    Rj: np.ndarray, Cj: np.ndarray,
    fx: float, fy: float, cx: float, cy: float,
) -> tuple[np.ndarray, np.ndarray]:
    """Depth-free motion evidence: distance from each measured correspondence to
    its epipolar line (pixels, in frame j).

    A static point lies on its epipolar line whatever its depth, so we build the
    line by reprojecting the pixel at two arbitrary depths (both land on the same
    line) and measure how far the *measured* correspondence strays from it. This
    needs no correct depth — only the camera pose — so it survives the noisy
    monocular depth that defeats the rigid-flow residual on casual captures.
    """
    h, w = measured_flow.shape[:2]
    ys, xs = np.mgrid[0:h, 0:w].astype(np.float32)
    xf, yf = xs.reshape(-1), ys.reshape(-1)

    # two points on each pixel's epipolar line (near + far assumed distance)
    zl = _depth_to_z(np.float32(0.85))       # nearer
    zf = _depth_to_z(np.float32(0.15))       # farther
    u1, v1, f1 = _reproject(xf, yf, np.full_like(xf, zl), Ri, Ci, Rj, Cj, fx, fy, cx, cy)
    u2, v2, f2 = _reproject(xf, yf, np.full_like(xf, zf), Ri, Ci, Rj, Cj, fx, fy, cx, cy)

    dx = u2 - u1
    dy = v2 - v1
    norm = np.hypot(dx, dy)
    valid = (f1 & f2 & (norm > 1e-3))        # near the epipole the line degenerates
    nx = np.where(valid, -dy / np.where(norm > 1e-3, norm, 1.0), 0.0)   # unit line normal
    ny = np.where(valid, dx / np.where(norm > 1e-3, norm, 1.0), 0.0)

    # measured correspondence in frame j
    xj = xf + measured_flow[..., 0].reshape(-1)
    yj = yf + measured_flow[..., 1].reshape(-1)
    dist = np.abs(nx * (xj - u1) + ny * (yj - v1))   # point-to-line distance
    dist = np.where(valid, dist, 0.0).reshape(h, w).astype(np.float32)
    return dist, valid.reshape(h, w)


def _threshold(resid: np.ndarray, valid: np.ndarray) -> np.ndarray:
    """Soft [0,1] mask from a residual field, gated by a robust per-frame floor.

    The floor is the static-dominated median plus a MAD-scaled margin, so it
    adapts to each clip's noise without a hand-tuned absolute threshold.
    """
    v = resid[valid]
    med = float(np.median(v)) if v.size else 0.0
    mad = float(np.median(np.abs(v - med))) if v.size else 0.0
    floor = max(med + RESID_K * (1.4826 * mad), RESID_FLOOR_PX)
    m = np.clip((resid - floor) / max(floor, 1e-3), 0.0, 1.0)
    return np.where(valid, m, 0.0).astype(np.float32)


def dynamic_mask(
    measured_flow: np.ndarray,
    depth01: np.ndarray,
    Ri: np.ndarray, Ci: np.ndarray,
    Rj: np.ndarray, Cj: np.ndarray,
    fx: float, fy: float, cx: float, cy: float,
) -> np.ndarray:
    """Soft [0,1] dynamism mask: where measured flow disagrees with rigid flow.

    Depth-based reference used by the synthetic tests; the real-data path uses the
    depth-free :func:`epipolar_residual`, which is far more robust to the noisy
    monocular depth of casual captures.
    """
    pred, valid = rigid_flow(depth01, Ri, Ci, Rj, Cj, fx, fy, cx, cy)
    resid = np.where(valid, np.linalg.norm(measured_flow - pred, axis=-1), 0.0)
    return _threshold(resid, valid)


def _box3(x: np.ndarray) -> np.ndarray:
    p = np.pad(x, 1, mode="edge")
    return (
        p[:-2, :-2] + p[:-2, 1:-1] + p[:-2, 2:]
        + p[1:-1, :-2] + p[1:-1, 1:-1] + p[1:-1, 2:]
        + p[2:, :-2] + p[2:, 1:-1] + p[2:, 2:]
    ) / 9.0


def _clean(m: np.ndarray) -> np.ndarray:
    """Kill speckle, grow to cover the blur halo, feather the edge."""
    strong = (m >= 0.5).astype(np.float32)
    support = _box3(strong)
    m = np.where((strong > 0) & (support < 2.5 / 9.0), m * 0.2, m)  # lone speckle
    for _ in range(GROW_ITERS):
        m = np.maximum(m, _box3(m) * 0.9)
    return np.clip(m * SMOOTH_MIX + _box3(m) * (1.0 - SMOOTH_MIX), 0.0, 1.0).astype(np.float32)


@dataclass
class SegmentStats:
    backend: str = "unavailable"
    dynamic_fraction: float = 0.0
    per_frame_dynamic: list[float] = field(default_factory=list)


def residual_flow_masks(
    rgbs: list[np.ndarray],
    depths01: list[np.ndarray],
    poses: list[tuple[np.ndarray, np.ndarray]],
    fx: float, fy: float, cx: float, cy: float,
    *,
    progress=None,
) -> tuple[list[np.ndarray], SegmentStats]:
    """Per-frame soft dynamism masks for a moving-camera clip.

    For each frame we measure dense flow to a neighbor, subtract the rigid flow
    the recovered pose predicts, and threshold the residual. Frame i uses the
    i→i+1 pair (the last frame reuses i−1→i). Without OpenCV every mask is empty.
    """
    n = len(rgbs)
    stats = SegmentStats(backend=flow_backend_name())
    if stats.backend == "unavailable" or n < 2 or len(poses) != n:
        return [np.zeros(d.shape, np.float32) for d in depths01], stats

    import cv2

    dis = cv2.DISOpticalFlow_create(cv2.DISOPTICAL_FLOW_PRESET_MEDIUM)
    dis.setFinestScale(0)
    grays = [cv2.cvtColor(r, cv2.COLOR_RGB2GRAY) for r in rgbs]

    masks: list[np.ndarray] = []
    for i in range(n):
        j = i + 1 if i + 1 < n else i - 1          # pair partner
        meas = dis.calc(grays[i], grays[j], None)
        Ri, Ci = poses[i]
        Rj, Cj = poses[j]
        resid, valid = epipolar_residual(meas, Ri, Ci, Rj, Cj, fx, fy, cx, cy)
        m = _clean(_threshold(resid, valid))
        masks.append(m)
        stats.per_frame_dynamic.append(float((m > 0.5).mean()))
        if progress:
            progress(i + 1, n)

    stats.dynamic_fraction = float(np.mean(stats.per_frame_dynamic)) if masks else 0.0
    return masks, stats
```

### api/app/pipeline/spacetime.py
```
"""Spacetime decomposition — the temporal model behind the flagship 4D path.

A static-camera clip is *not* N independent scenes: almost every pixel is the
same surface seen N times, and the rest is a subject sweeping through. Modern
4D gaussian systems (Spacetime Gaussians, deformation-field 4DGS) exploit this
with one shared representation plus per-gaussian motion. This module recovers
that structure from pixels:

  * **stabilize** — cancel small handheld drift (ECC euclidean to a reference
    frame) so "static camera" holds to sub-pixel and the median background is
    crisp instead of smeared.
  * **decompose** — per-pixel temporal median + robust noise floor → a per-frame
    *dynamism* mask, a fused **static canvas** (color + depth + confidence, with
    the subject removed and the hole behind it filled from the frames that saw
    it), and the clip's dynamic fraction.
  * **build_tracks** — chain dense optical flow (forward/backward-checked)
    through the dynamic region to produce gaussian **trajectories**: birth
    frame, per-frame sub-pixel position + depth samples, and a robust color.
    Where flow is untrustworthy a track simply dies and a new one is born —
    the failure mode is the old per-frame behavior, never worse.

Everything degrades gracefully: no OpenCV ⇒ no stabilization and single-frame
tracks (the decomposition itself is pure numpy). All arrays are work-resolution.
"""
from __future__ import annotations

import importlib.util
import math
import warnings
from dataclasses import dataclass, field

import numpy as np
from PIL import Image, ImageFilter

# --- tunables ----------------------------------------------------------------
STAB_MAX_SIDE = 360      # resolution for drift estimation (speed)
STAB_SKIP_PX = 0.35      # median |shift| below this ⇒ tripod ⇒ skip ECC
STAB_MAX_FAIL = 0.3      # ECC failure rate above this ⇒ leave clip untouched
MASK_LO_FLOOR = 8.0      # residual (0..255) where dynamism starts
MASK_HI_FLOOR = 22.0     # residual where a pixel is fully dynamic
MASK_SIGMA_LO = 2.5      # ... raised by the per-pixel noise floor
MASK_SIGMA_HI = 5.0
FB_MAX_ERR = 1.25        # forward/backward flow disagreement (px) that kills a track
TRACK_MIN_MASK = 0.15    # tracked point must stay at least this dynamic
SPAWN_MASK = 0.45        # mask level required to give birth to a track


def flow_backend_name() -> str:
    """Best-effort report of the optical-flow backend (no heavy import)."""
    return "opencv-dis" if importlib.util.find_spec("cv2") else "unavailable"


# ---------------------------------------------------------------------------
# stabilization
# ---------------------------------------------------------------------------

@dataclass
class StabilizeInfo:
    applied: bool = False
    max_shift_px: float = 0.0    # largest correction applied (work-res pixels)
    failed_frames: int = 0


def stabilize_frames(
    rgbs: list[np.ndarray], depths: list[np.ndarray]
) -> tuple[list[np.ndarray], list[np.ndarray], StabilizeInfo]:
    """Warp every frame onto the middle frame to cancel handheld drift.

    Returns (rgbs, depths, info) — the inputs unchanged when the clip is already
    steady, OpenCV is missing, or the solve is unreliable.
    """
    info = StabilizeInfo()
    n = len(rgbs)
    if flow_backend_name() == "unavailable" or n < 3:
        return rgbs, depths, info
    import cv2

    h, w = rgbs[0].shape[:2]
    s = min(1.0, STAB_MAX_SIDE / max(h, w))
    sw, sh = max(int(w * s), 16), max(int(h * s), 16)
    grays = [
        cv2.cvtColor(cv2.resize(r, (sw, sh), interpolation=cv2.INTER_AREA), cv2.COLOR_RGB2GRAY)
        for r in rgbs
    ]
    ref_i = n // 2
    ref = grays[ref_i].astype(np.float32)

    # cheap pre-check: phase-correlate a few frames against the reference; a
    # tripod clip shows sub-pixel shifts and we skip the (pricier) ECC pass.
    probes = sorted({0, n // 4, 3 * n // 4, n - 1})
    shifts = []
    win = cv2.createHanningWindow((sw, sh), cv2.CV_32F)
    for i in probes:
        (dx, dy), _resp = cv2.phaseCorrelate(ref, grays[i].astype(np.float32), win)
        shifts.append(math.hypot(dx, dy))
    if float(np.median(shifts)) < STAB_SKIP_PX * s:
        return rgbs, depths, info

    crit = (cv2.TERM_CRITERIA_EPS | cv2.TERM_CRITERIA_COUNT, 60, 1e-4)
    max_plausible = 0.15 * math.hypot(sw, sh)
    out_rgb: list[np.ndarray] = []
    out_d: list[np.ndarray] = []
    warps: list[np.ndarray | None] = []
    for i in range(n):
        if i == ref_i:
            warps.append(np.eye(2, 3, dtype=np.float32))
            continue
        # translation init from phase correlation (exact even where ECC's
        # gradient descent has no basin), then ECC refines rotation + residual
        (dx, dy), _resp = cv2.phaseCorrelate(ref, grays[i].astype(np.float32), win)
        if math.hypot(dx, dy) > max_plausible:
            warps.append(None)  # implausible — leave this frame untouched
            info.failed_frames += 1
            continue
        W = np.array([[1, 0, dx], [0, 1, dy]], dtype=np.float32)
        try:
            _cc, W = cv2.findTransformECC(
                ref, grays[i].astype(np.float32), W, cv2.MOTION_EUCLIDEAN, crit, None, 3
            )
        except cv2.error:
            pass  # keep the phase-correlation translation
        warps.append(W)
    if info.failed_frames > STAB_MAX_FAIL * n:
        return rgbs, depths, info

    for i in range(n):
        W = warps[i]
        if W is None or i == ref_i:
            out_rgb.append(rgbs[i])
            out_d.append(depths[i])
            continue
        # W maps ref → frame i at estimation scale; rescale translation to full res
        Wf = W.copy()
        Wf[:, 2] /= s
        corr = math.hypot(float(W[0, 2]), float(W[1, 2])) / s
        info.max_shift_px = max(info.max_shift_px, corr)
        flags = cv2.INTER_LINEAR | cv2.WARP_INVERSE_MAP
        out_rgb.append(cv2.warpAffine(rgbs[i], Wf, (w, h), flags=flags, borderMode=cv2.BORDER_REPLICATE))
        out_d.append(cv2.warpAffine(depths[i], Wf, (w, h), flags=flags, borderMode=cv2.BORDER_REPLICATE))
    info.applied = info.max_shift_px > 0.0
    return out_rgb, out_d, info

@dataclass
class Decomposition:
    masks: list[np.ndarray]        # per-frame float32 HxW dynamism in [0,1]
    static_rgb: np.ndarray         # uint8 HxWx3 — fused background canvas
    static_depth: np.ndarray       # float32 HxW in [0,1] (1 = near)
    static_conf: np.ndarray        # float32 HxW — fraction of frames seen static
    dynamic_fraction: float        # mean dynamic area over the clip


def _box3(x: np.ndarray) -> np.ndarray:
    """3x3 box filter with edge replication (pure numpy)."""
    p = np.pad(x, 1, mode="edge")
    return (
        p[:-2, :-2] + p[:-2, 1:-1] + p[:-2, 2:]
        + p[1:-1, :-2] + p[1:-1, 1:-1] + p[1:-1, 2:]
        + p[2:, :-2] + p[2:, 1:-1] + p[2:, 2:]
    ) / 9.0


def _fill_holes(img: np.ndarray, hole: np.ndarray, iters: int = 24) -> np.ndarray:
    """Diffusion fill of `hole` pixels from their surroundings (numpy fallback)."""
    out = img.astype(np.float32).copy()
    if img.ndim == 3:
        hole3 = hole[..., None]
        out = np.where(hole3, 0.0, out)
        w = np.where(hole, 0.0, 1.0)
        for _ in range(iters):
            num = np.stack([_box3(out[..., c]) for c in range(out.shape[-1])], axis=-1)
            den = _box3(w)
            fill = num / np.maximum(den[..., None], 1e-6)
            out = np.where(hole3 & (den[..., None] > 1e-6), fill, out)
            w = np.where(hole & (den > 1e-6), 1.0, w)
            hole = hole & (den <= 1e-6)
            if not hole.any():
                break
    else:
        out = np.where(hole, 0.0, out)
        w = np.where(hole, 0.0, 1.0)
        for _ in range(iters):
            num = _box3(out)
            den = _box3(w)
            out = np.where(hole & (den > 1e-6), num / np.maximum(den, 1e-6), out)
            w = np.where(hole & (den > 1e-6), 1.0, w)
            hole = hole & (den <= 1e-6)
            if not hole.any():
                break
    return out


def _inpaint(rgb: np.ndarray, depth: np.ndarray, hole: np.ndarray) -> tuple[np.ndarray, np.ndarray]:
    """Fill never-seen background (subject never moved off it)."""
    if not hole.any():
        return rgb, depth
    if flow_backend_name() != "unavailable":
        import cv2

        m = hole.astype(np.uint8) * 255
        rgb = cv2.inpaint(rgb, m, 5, cv2.INPAINT_TELEA)
        d8 = np.clip(depth * 255.0, 0, 255).astype(np.uint8)
        d8 = cv2.inpaint(d8, m, 5, cv2.INPAINT_TELEA)
        depth = np.where(hole, d8.astype(np.float32) / 255.0, depth)
        return rgb, depth
    rgb = np.clip(_fill_holes(rgb, hole.copy()), 0, 255).astype(np.uint8)
    depth = _fill_holes(depth, hole.copy()).astype(np.float32)
    return rgb, depth


def decompose(
    rgbs: list[np.ndarray],
    depths: list[np.ndarray],
    subject_masks: list[np.ndarray] | None = None,
) -> Decomposition:
    """Split the clip into a fused static canvas + per-frame dynamism masks.

    ``subject_masks`` (optional, per-frame [0,1]) marks a moving foreground subject
    that motion alone can miss when it holds still. It is ORed into the dynamism
    masks, so a near-stationary subject stops baking into the static canvas (its
    pixels are no longer "quiet") and is carried by trajectories instead.
    """
    n = len(rgbs)
    stack = np.stack(rgbs).astype(np.float32)                      # (n,H,W,3)
    med = np.median(stack, axis=0)                                 # background model
    resid = np.abs(stack - med[None]).max(axis=-1)                 # (n,H,W)

    # noise floor: the per-pixel median residual measures shimmer, but a pixel
    # that changes in MOST frames (constant motion) would read as "noise" and
    # go blind — so cap it by the global sensor-noise level (spatial median,
    # dominated by the static majority of the scene)
    sigma = np.median(resid, axis=0)
    sigma_g = float(np.median(sigma))
    sigma = np.minimum(sigma, 3.0 * sigma_g + 4.0)
    lo = np.maximum(MASK_LO_FLOOR, MASK_SIGMA_LO * sigma)
    hi = np.maximum(MASK_HI_FLOOR, MASK_SIGMA_HI * sigma)

    masks: list[np.ndarray] = []
    for t in range(n):
        m = np.clip((resid[t] - lo) / np.maximum(hi - lo, 1e-6), 0.0, 1.0)
        # kill isolated speckles without eroding thin movers: a strong pixel
        # survives if at least ~2 of its 3x3 neighborhood is strong too
        strong = (m >= 0.5).astype(np.float32)
        support = _box3(strong)
        m = np.where((strong > 0) & (support < 2.5 / 9.0), m * 0.25, m)
        m = np.maximum(m, _box3(m) * 0.8)           # soft halo so edges feather
        if subject_masks is not None:
            m = np.maximum(m, np.clip(subject_masks[t], 0.0, 1.0))
        masks.append(np.clip(m, 0.0, 1.0).astype(np.float32))

    mstack = np.stack(masks)
    dynamic_fraction = float((mstack > 0.5).mean())

    # static canvas: median over the frames where each pixel is quiet
    quiet = mstack < 0.4
    static_conf = quiet.mean(axis=0).astype(np.float32)
    big = np.where(quiet[..., None], stack, np.nan)
    with warnings.catch_warnings():
        # all-NaN pixels (never seen static) are expected — inpainted below
        warnings.simplefilter("ignore", category=RuntimeWarning)
        srgb = np.nanmedian(big, axis=0)
        sdepth = np.nanmedian(np.where(quiet, np.stack(depths), np.nan), axis=0)
    hole = ~np.isfinite(srgb).all(axis=-1) | ~np.isfinite(sdepth)
    srgb = np.where(np.isfinite(srgb), srgb, 0)
    sdepth = np.where(np.isfinite(sdepth), sdepth, 0)
    srgb8, sdepth = _inpaint(np.clip(srgb, 0, 255).astype(np.uint8), sdepth.astype(np.float32), hole)

    return Decomposition(
        masks=masks,
        static_rgb=srgb8,
        static_depth=np.clip(sdepth, 0.0, 1.0),
        static_conf=static_conf,
        dynamic_fraction=dynamic_fraction,
    )

@dataclass
class PixelTrack:
    """One dynamic gaussian's life in image space (engine lifts it to 3D)."""

    birth: int
    xs: list[float] = field(default_factory=list)   # per-cp sub-pixel position
    ys: list[float] = field(default_factory=list)
    zs: list[float] = field(default_factory=list)   # per-cp depth01 sample
    colors: list[np.ndarray] = field(default_factory=list)  # rgb samples (u8)

    @property
    def death(self) -> int:
        return self.birth + len(self.xs) - 1


def _bilinear(img: np.ndarray, xs: np.ndarray, ys: np.ndarray) -> np.ndarray:
    """Sample HxW or HxWxC `img` at float coords; clamps to the border."""
    h, w = img.shape[:2]
    x = np.clip(xs, 0.0, w - 1.001)
    y = np.clip(ys, 0.0, h - 1.001)
    x0 = x.astype(np.int32)
    y0 = y.astype(np.int32)
    fx = (x - x0).astype(np.float32)
    fy = (y - y0).astype(np.float32)
    if img.ndim == 3:
        fx = fx[:, None]
        fy = fy[:, None]
    p00 = img[y0, x0]
    p01 = img[y0, x0 + 1]
    p10 = img[y0 + 1, x0]
    p11 = img[y0 + 1, x0 + 1]
    top = p00 * (1 - fx) + p01 * fx
    bot = p10 * (1 - fx) + p11 * fx
    return top * (1 - fy) + bot * fy


def _spawn_points(mask: np.ndarray, stride: int, occupied_x: np.ndarray,
                  occupied_y: np.ndarray) -> tuple[np.ndarray, np.ndarray]:
    """Grid points on dynamic pixels whose stride-cell holds no live track."""
    h, w = mask.shape
    gw = (w + stride - 1) // stride
    gh = (h + stride - 1) // stride
    occ = np.zeros((gh, gw), dtype=bool)
    if occupied_x.size:
        gx = np.clip((occupied_x / stride).astype(np.int32), 0, gw - 1)
        gy = np.clip((occupied_y / stride).astype(np.int32), 0, gh - 1)
        occ[gy, gx] = True
    half = stride // 2
    ys, xs = np.mgrid[half:h:stride, half:w:stride]
    ys = ys.ravel()
    xs = xs.ravel()
    want = mask[ys, xs] >= SPAWN_MASK
    cell_free = ~occ[np.clip(ys // stride, 0, gh - 1), np.clip(xs // stride, 0, gw - 1)]
    sel = want & cell_free
    return xs[sel].astype(np.float32), ys[sel].astype(np.float32)


def _smooth_track_depth(zs: list[float]) -> list[float]:
    if len(zs) < 3:
        return zs
    a = np.asarray(zs, dtype=np.float32)
    sm = a.copy()
    sm[1:-1] = 0.25 * a[:-2] + 0.5 * a[1:-1] + 0.25 * a[2:]
    return sm.tolist()


def build_tracks(
    rgbs: list[np.ndarray],
    depths: list[np.ndarray],
    masks: list[np.ndarray],
    *,
    budget: int,
    progress=None,
) -> tuple[list[PixelTrack], dict]:
    """Chain optical flow through the dynamic region into gaussian trajectories.

    ``budget`` bounds the number of *concurrently alive* tracks; the spawn grid
    stride adapts to the clip's mean dynamic area. Without OpenCV, every dynamic
    grid point becomes a single-frame track (the pre-trajectory behavior).
    """
    n = len(rgbs)
    h, w = masks[0].shape
    mean_dyn_px = float(np.mean([(m > 0.5).sum() for m in masks]))
    stride = max(1, int(round(math.sqrt(max(mean_dyn_px, 1.0) / max(budget, 1)))))
    stats = {"stride": stride, "flow": flow_backend_name()}

    def sample_state(t: int, xs: np.ndarray, ys: np.ndarray):
        z = _bilinear(depths[t], xs, ys).astype(np.float32)
        c = np.clip(_bilinear(rgbs[t].astype(np.float32), xs, ys), 0, 255)
        return z, c.astype(np.uint8)

    tracks: list[PixelTrack] = []
    if flow_backend_name() == "unavailable" or n < 2:
        # fallback: per-frame single-cp tracks — never worse than the old path
        for t in range(n):
            xs, ys = _spawn_points(masks[t], stride, np.empty(0), np.empty(0))
            z, c = sample_state(t, xs, ys)
            for i in range(xs.size):
                tr = PixelTrack(birth=t)
                tr.xs.append(float(xs[i]))
                tr.ys.append(float(ys[i]))
                tr.zs.append(float(z[i]))
                tr.colors.append(c[i])
                tracks.append(tr)
            if progress:
                progress(t + 1, n)
        stats["mean_len"] = 1.0
        return tracks, stats

    import cv2

    dis = cv2.DISOpticalFlow_create(cv2.DISOPTICAL_FLOW_PRESET_MEDIUM)
    dis.setFinestScale(0)  # full-res finest level — small movers survive
    grays = [cv2.cvtColor(r, cv2.COLOR_RGB2GRAY) for r in rgbs]

    alive_idx: list[int] = []          # indices into `tracks`
    ax = np.empty(0, np.float32)       # current positions of alive tracks
    ay = np.empty(0, np.float32)

    def spawn(t: int) -> None:
        nonlocal ax, ay
        sx, sy = _spawn_points(masks[t], stride, ax, ay)
        if not sx.size:
            return
        z, c = sample_state(t, sx, sy)
        for i in range(sx.size):
            tr = PixelTrack(birth=t)
            tr.xs.append(float(sx[i]))
            tr.ys.append(float(sy[i]))
            tr.zs.append(float(z[i]))
            tr.colors.append(c[i])
            alive_idx.append(len(tracks))
            tracks.append(tr)
        ax = np.concatenate([ax, sx])
        ay = np.concatenate([ay, sy])

    spawn(0)
    for t in range(1, n):
        if ax.size:
            fwd = dis.calc(grays[t - 1], grays[t], None)
            bwd = dis.calc(grays[t], grays[t - 1], None)
            d = _bilinear(fwd, ax, ay)
            nx = ax + d[:, 0].astype(np.float32)
            ny = ay + d[:, 1].astype(np.float32)
            db = _bilinear(bwd, nx, ny)
            fb_err = np.hypot(d[:, 0] + db[:, 0], d[:, 1] + db[:, 1])
            inb = (nx >= 1) & (nx < w - 2) & (ny >= 1) & (ny < h - 2)
            still_dyn = _bilinear(masks[t], nx, ny) >= TRACK_MIN_MASK
            ok = (fb_err <= FB_MAX_ERR) & inb & still_dyn

            z, c = sample_state(t, nx[ok], ny[ok])
            kept: list[int] = []
            j = 0
            for i, tid in enumerate(alive_idx):
                if ok[i]:
                    tr = tracks[tid]
                    tr.xs.append(float(nx[i]))
                    tr.ys.append(float(ny[i]))
                    tr.zs.append(float(z[j]))
                    tr.colors.append(c[j])
                    kept.append(tid)
                    j += 1
            alive_idx = kept
            ax = nx[ok]
            ay = ny[ok]
        spawn(t)
        if progress:
            progress(t + 1, n)

    for tr in tracks:
        tr.zs = _smooth_track_depth(tr.zs)
    lens = [len(tr.xs) for tr in tracks]
    stats["mean_len"] = float(np.mean(lens)) if lens else 0.0
    return tracks, stats


def downsample_float(img: np.ndarray, size: tuple[int, int]) -> np.ndarray:
    """Bilinear-resize a float32 map without 8-bit quantization."""
    return np.asarray(
        Image.fromarray(img.astype(np.float32), mode="F").resize(size, Image.BILINEAR),
        dtype=np.float32,
    )


def gaussian_blur(img: np.ndarray, radius: float) -> np.ndarray:
    """float32 HxW gaussian blur via PIL (mode F, no quantization)."""
    return np.asarray(
        Image.fromarray(img.astype(np.float32), mode="F").filter(ImageFilter.GaussianBlur(radius)),
        dtype=np.float32,
    )

"""Read/write the ``.4dsplat`` container (versions 1 and 2).

Version 1 — independent per-timestep gaussian clouds (legacy):

    HEADER (44 bytes, little-endian)
        magic     char[4]  = "4DGS"
        version   uint32   = 1
        num_ts    uint32                 number of timesteps
        flags     uint32   = 0
        fps       float32                playback fps of the 4D animation
        bbox      float32[6]             min xyz, max xyz (over all timesteps)
    DIRECTORY
        counts    uint32[num_ts]         #gaussians in each timestep
        offsets   uint32[num_ts]         byte offset (from file start) of each block
    BLOCKS (one per timestep, 32 bytes / gaussian)
        position  float32[3]   scale float32[3]   color u8[4] (rgb+opacity)   rot i8[4]

Version 2 — **spacetime** layout: one shared static model + dynamic gaussian
*trajectories* (Spacetime-Gaussians-style). The static background is stored
once instead of per timestep, and each dynamic gaussian carries its motion as
per-control-point positions plus a temporal opacity window, so the viewer can
interpolate continuously in time:

    HEADER (60 bytes, little-endian)
        magic         char[4]  = "4DGS"
        version       uint32   = 2
        num_cp        uint32               temporal control points T (1 = still)
        flags         uint32   = 0
        fps           float32              control points per second
        bbox          float32[6]
        static_count  uint32               S
        track_count   uint32               D
        pos_count     uint32               P (total stream positions)
        reserved      uint32
    STATIC   @60            S × 32B, same record as v1
    TRACKS   @60+32S        D × 32B:
        scale float32[3] · color u8[4] (rgb+peak opacity) · rot i8[4]
        birth u16 · death u16            alive on control points [birth, death]
        pos_offset u32                   index into the position stream
        flags u32                        bit0 fade-in, bit1 fade-out
    STREAM   @60+32S+32D    P × 12B float32 xyz; track i owns
                            [pos_offset, pos_offset + (death - birth + 1))

The JS loader (web/components/Splat/loader.ts) parses both byte-for-byte.
"""
from __future__ import annotations

import json
import struct
from dataclasses import dataclass, field
from pathlib import Path

import numpy as np

MAGIC = b"4DGS"
VERSION = 1
VERSION2 = 2
STRIDE = 32  # bytes per gaussian / per track record
HEADER_SIZE = 44
HEADER2_SIZE = 60
TRACK_FADE_IN = 1
TRACK_FADE_OUT = 2

GAUSSIAN_DTYPE = np.dtype(
    [
        ("pos", "<f4", (3,)),
        ("scale", "<f4", (3,)),
        ("color", "u1", (4,)),
        ("rot", "i1", (4,)),
    ]
)
assert GAUSSIAN_DTYPE.itemsize == STRIDE, GAUSSIAN_DTYPE.itemsize

TRACK_DTYPE = np.dtype(
    [
        ("scale", "<f4", (3,)),
        ("color", "u1", (4,)),
        ("rot", "i1", (4,)),
        ("birth", "<u2"),
        ("death", "<u2"),
        ("pos_offset", "<u4"),
        ("flags", "<u4"),
    ]
)
assert TRACK_DTYPE.itemsize == STRIDE, TRACK_DTYPE.itemsize


@dataclass
class SplatFrame:
    """One static gaussian set (a v1 timestep, or the v2 static layer)."""

    positions: np.ndarray            # (N, 3) float32
    scales: np.ndarray               # (N, 3) float32
    colors: np.ndarray               # (N, 3) uint8
    opacities: np.ndarray            # (N,)  uint8
    rotations: np.ndarray | None = field(default=None)  # (N, 4) int8

    @property
    def count(self) -> int:
        return int(self.positions.shape[0])


@dataclass
class TrackSet:
    """Dynamic gaussian trajectories (v2). Arrays are parallel over D tracks."""

    births: np.ndarray               # (D,) int
    deaths: np.ndarray               # (D,) int — inclusive
    scales: np.ndarray               # (D, 3) float32
    colors: np.ndarray               # (D, 3) uint8
    opacities: np.ndarray            # (D,) uint8 — peak opacity
    rotations: np.ndarray            # (D, 4) int8
    offsets: np.ndarray              # (D,) uint32 into `positions`
    flags: np.ndarray                # (D,) uint32
    positions: np.ndarray            # (P, 3) float32 — concatenated streams

    @property
    def count(self) -> int:
        return int(self.births.shape[0])


def _pack_frame(frame: SplatFrame) -> bytes:
    n = frame.count
    rec = np.zeros(n, dtype=GAUSSIAN_DTYPE)
    rec["pos"] = frame.positions.astype("<f4", copy=False)
    rec["scale"] = frame.scales.astype("<f4", copy=False)
    rec["color"][:, :3] = frame.colors.astype("u1", copy=False)
    rec["color"][:, 3] = frame.opacities.astype("u1", copy=False)
    if frame.rotations is not None:
        rec["rot"] = frame.rotations.astype("i1", copy=False)
    else:
        # identity quaternion (0,0,0,1) -> (0,0,0,127)
        rec["rot"][:, 3] = 127
    return rec.tobytes()


def write_4dsplat(
    path: str | Path,
    frames: list[SplatFrame],
    fps: float,
    bbox: tuple[float, float, float, float, float, float] | None = None,
) -> dict:
    """Write a **v1** (per-timestep) file; returns its manifest dict."""
    path = Path(path)
    num_ts = len(frames)
    if num_ts == 0:
        raise ValueError("no frames to write")

    if bbox is None:
        mins = np.full(3, np.inf, dtype=np.float64)
        maxs = np.full(3, -np.inf, dtype=np.float64)
        for f in frames:
            if f.count:
                mins = np.minimum(mins, f.positions.min(axis=0))
                maxs = np.maximum(maxs, f.positions.max(axis=0))
        if not np.isfinite(mins).all():
            mins = np.zeros(3)
            maxs = np.zeros(3)
        bbox = (*mins.tolist(), *maxs.tolist())

    counts = [f.count for f in frames]
    directory_size = num_ts * 4 * 2  # counts + offsets
    first_offset = HEADER_SIZE + directory_size
    offsets: list[int] = []
    cursor = first_offset
    for c in counts:
        offsets.append(cursor)
        cursor += c * STRIDE

    header = struct.pack(
        "<4sIII f 6f",
        MAGIC, VERSION, num_ts, 0, float(fps),
        *[float(x) for x in bbox],
    )
    assert len(header) == HEADER_SIZE, len(header)

    with open(path, "wb") as fh:
        fh.write(header)
        fh.write(np.asarray(counts, dtype="<u4").tobytes())
        fh.write(np.asarray(offsets, dtype="<u4").tobytes())
        for frame in frames:
            fh.write(_pack_frame(frame))

    total = int(sum(counts))
    manifest = {
        "version": VERSION,
        "format": "4dsplat",
        "stride_bytes": STRIDE,
        "num_timesteps": num_ts,
        "fps": float(fps),
        "counts": counts,
        "gaussian_count": total,
        "bbox": [float(x) for x in bbox],
        "byte_size": path.stat().st_size,
    }
    return manifest


def write_4dsplat_v2(
    path: str | Path,
    static: SplatFrame,
    tracks: TrackSet | None,
    *,
    num_cp: int,
    fps: float,
) -> dict:
    """Write a **v2** (spacetime) file; returns its manifest dict."""
    path = Path(path)
    num_cp = max(1, int(num_cp))
    if num_cp > 65535:
        raise ValueError("num_cp exceeds u16 track window")
    S = static.count
    D = tracks.count if tracks is not None else 0
    P = int(tracks.positions.shape[0]) if tracks is not None else 0
    if S == 0 and D == 0:
        raise ValueError("empty splat")

    mins = np.full(3, np.inf)
    maxs = np.full(3, -np.inf)
    if S:
        mins = np.minimum(mins, static.positions.min(axis=0))
        maxs = np.maximum(maxs, static.positions.max(axis=0))
    if P:
        mins = np.minimum(mins, tracks.positions.min(axis=0))
        maxs = np.maximum(maxs, tracks.positions.max(axis=0))
    bbox = (*mins.tolist(), *maxs.tolist())

    header = struct.pack(
        "<4sIII f 6f III I",
        MAGIC, VERSION2, num_cp, 0, float(fps),
        *[float(x) for x in bbox],
        S, D, P, 0,
    )
    assert len(header) == HEADER2_SIZE, len(header)

    with open(path, "wb") as fh:
        fh.write(header)
        fh.write(_pack_frame(static))
        if tracks is not None and D:
            expected = tracks.deaths - tracks.births + 1
            lens = np.diff(np.append(tracks.offsets, P))
            if not np.array_equal(np.sort(tracks.offsets), tracks.offsets):
                raise ValueError("track offsets must be sorted")
            if not np.array_equal(lens, expected):
                raise ValueError("track stream lengths disagree with birth/death")
            rec = np.zeros(D, dtype=TRACK_DTYPE)
            rec["scale"] = tracks.scales.astype("<f4", copy=False)
            rec["color"][:, :3] = tracks.colors.astype("u1", copy=False)
            rec["color"][:, 3] = tracks.opacities.astype("u1", copy=False)
            rec["rot"] = tracks.rotations.astype("i1", copy=False)
            rec["birth"] = tracks.births.astype("<u2", copy=False)
            rec["death"] = tracks.deaths.astype("<u2", copy=False)
            rec["pos_offset"] = tracks.offsets.astype("<u4", copy=False)
            rec["flags"] = tracks.flags.astype("<u4", copy=False)
            fh.write(rec.tobytes())
            fh.write(tracks.positions.astype("<f4", copy=False).tobytes())

    manifest = {
        "version": VERSION2,
        "format": "4dsplat",
        "format_version": VERSION2,
        "stride_bytes": STRIDE,
        "num_timesteps": num_cp,
        "fps": float(fps),
        "gaussian_count": S + D,
        "static_count": S,
        "track_count": D,
        "pos_stream_len": P,
        "sections": {
            "static": [HEADER2_SIZE, S * STRIDE],
            "tracks": [HEADER2_SIZE + S * STRIDE, D * STRIDE],
            "positions": [HEADER2_SIZE + (S + D) * STRIDE, P * 12],
        },
        "bbox": [float(x) for x in bbox],
        "byte_size": path.stat().st_size,
    }
    return manifest


def read_4dsplat(path: str | Path) -> dict:
    """Version-aware reader (tests + tooling; the viewer has its own JS parser).

    v1 → {"version": 1, "fps", "bbox", "frames": [SplatFrame, ...]}
    v2 → {"version": 2, "num_cp", "fps", "bbox", "static": SplatFrame,
          "tracks": TrackSet | None}
    """
    raw = Path(path).read_bytes()
    if raw[:4] != MAGIC:
        raise ValueError("not a .4dsplat file")
    version = struct.unpack_from("<I", raw, 4)[0]

    def unpack_records(buf: bytes, off: int, n: int) -> SplatFrame:
        rec = np.frombuffer(buf, dtype=GAUSSIAN_DTYPE, count=n, offset=off)
        return SplatFrame(
            positions=rec["pos"].copy(),
            scales=rec["scale"].copy(),
            colors=rec["color"][:, :3].copy(),
            opacities=rec["color"][:, 3].copy(),
            rotations=rec["rot"].copy(),
        )

    if version == 1:
        num_ts = struct.unpack_from("<I", raw, 8)[0]
        fps = struct.unpack_from("<f", raw, 16)[0]
        bbox = struct.unpack_from("<6f", raw, 20)
        counts = np.frombuffer(raw, dtype="<u4", count=num_ts, offset=HEADER_SIZE)
        offsets = np.frombuffer(raw, dtype="<u4", count=num_ts, offset=HEADER_SIZE + 4 * num_ts)
        frames = [unpack_records(raw, int(o), int(c)) for o, c in zip(offsets, counts)]
        return {"version": 1, "fps": fps, "bbox": list(bbox), "frames": frames}

    if version == VERSION2:
        num_cp, _flags = struct.unpack_from("<II", raw, 8)
        fps = struct.unpack_from("<f", raw, 16)[0]
        bbox = struct.unpack_from("<6f", raw, 20)
        S, D, P, _res = struct.unpack_from("<IIII", raw, 44)
        static = unpack_records(raw, HEADER2_SIZE, S)
        tracks = None
        if D:
            rec = np.frombuffer(raw, dtype=TRACK_DTYPE, count=D, offset=HEADER2_SIZE + S * STRIDE)
            pos = np.frombuffer(
                raw, dtype="<f4", count=P * 3, offset=HEADER2_SIZE + (S + D) * STRIDE
            ).reshape(P, 3)
            tracks = TrackSet(
                births=rec["birth"].astype(np.int64),
                deaths=rec["death"].astype(np.int64),
                scales=rec["scale"].copy(),
                colors=rec["color"][:, :3].copy(),
                opacities=rec["color"][:, 3].copy(),
                rotations=rec["rot"].copy(),
                offsets=rec["pos_offset"].astype(np.int64),
                flags=rec["flags"].astype(np.int64),
                positions=pos.copy(),
            )
        return {
            "version": 2, "num_cp": num_cp, "fps": fps, "bbox": list(bbox),
            "static": static, "tracks": tracks,
        }

    raise ValueError(f"unsupported .4dsplat version {version}")


def write_manifest(path: str | Path, manifest: dict) -> None:

### api/app/pipeline/subject.py
```
"""Foreground-subject segmentation — keeps a near-stationary moving subject out of
the static canvas.

The spacetime decomposition builds its background by temporal median, which quietly
bakes in a subject that holds still long enough (a person standing at a counter):
their pixels are "the background" most of the time, so the median *is* them. Motion
can't rescue this — a still subject produces little optical flow, and flickering
light on the real background produces plenty. The reliable signal is *what the
thing is*: an instance segmenter finds the person/object directly.

This module returns a per-frame subject mask (the moving foreground). The engine
ORs it into the per-frame dynamism masks, after which the existing pipeline does the
right thing for free: subject pixels are no longer "quiet", so they drop out of the
static canvas (the hole is inpainted from real background), and they clear the spawn
threshold, so the subject is carried by trajectories instead.

Degrades gracefully: no torchvision ⇒ empty masks ⇒ prior behavior.
"""
from __future__ import annotations

import importlib.util

import numpy as np
from PIL import Image, ImageFilter

from .depth import _torch_stack_available

SEG_MAX_SIDE = 512      # inference resolution (speed); masks upsample to work-res
SCORE_MIN = 0.55        # instance confidence floor
PERSON = 1              # COCO label id
MOVER_OVERLAP = 0.10    # non-person instance must overlap this much motion to count
DILATE = 11             # odd: grow the mask past the subject's soft edge so the
                        # removed hole is bounded by clean background (its inpaint
                        # fills light, not with the subject's own dark edge pixels)

_model = None
_dev = None


def segment_available() -> bool:
    return _torch_stack_available() and importlib.util.find_spec("torchvision") is not None


def _load():
    global _model, _dev
    if _model is not None:
        return
    import torch
    from torchvision.models.detection import maskrcnn_resnet50_fpn, MaskRCNN_ResNet50_FPN_Weights

    _dev = torch.device(
        "mps" if torch.backends.mps.is_available()
        else "cuda" if torch.cuda.is_available() else "cpu"
    )
    _model = maskrcnn_resnet50_fpn(weights=MaskRCNN_ResNet50_FPN_Weights.DEFAULT).eval().to(_dev)


def subject_masks(
    rgbs: list[np.ndarray],
    motion_masks: list[np.ndarray] | None = None,
    *,
    progress=None,
) -> tuple[list[np.ndarray], dict]:
    """Per-frame float32 [0,1] masks of the moving foreground subject.

    A person instance always counts as subject; any other instance counts only if
    it overlaps the frame's motion (so we mask *moving* objects, not static ones).
    ``motion_masks`` (same resolution as ``rgbs``) supplies that motion cue.
    """
    n = len(rgbs)
    h, w = rgbs[0].shape[:2]
    empty = [np.zeros((h, w), np.float32) for _ in range(n)]
    stats = {"backend": "maskrcnn" if segment_available() else "unavailable", "subject_frac": 0.0}
    if not segment_available() or n == 0:
        return empty, stats

    import torch

    _load()
    s = min(1.0, SEG_MAX_SIDE / max(h, w))
    sw, sh = max(int(round(w * s)), 16), max(int(round(h * s)), 16)

    out: list[np.ndarray] = []
    covered = 0.0
    with torch.no_grad():
        for i, rgb in enumerate(rgbs):
            small = np.asarray(Image.fromarray(rgb).resize((sw, sh), Image.BILINEAR), np.uint8)
            t = torch.from_numpy(small).permute(2, 0, 1).float().div(255.0).to(_dev)
            pred = _model([t])[0]
            m = np.zeros((sh, sw), np.float32)
            mh = None
            if motion_masks is not None:
                mh = np.asarray(
                    Image.fromarray((np.clip(motion_masks[i], 0, 1) * 255).astype(np.uint8))
                    .resize((sw, sh), Image.BILINEAR), np.float32
                ) / 255.0
            masks = pred["masks"].squeeze(1).cpu().numpy()      # (k, sh, sw)
            labels = pred["labels"].cpu().numpy()
            scores = pred["scores"].cpu().numpy()
            for k in range(len(scores)):
                if scores[k] < SCORE_MIN:
                    continue
                inst = masks[k] > 0.5
                if not inst.any():
                    continue
                keep = labels[k] == PERSON
                if not keep and mh is not None:
                    keep = float(mh[inst].mean()) > MOVER_OVERLAP
                if keep:
                    m = np.maximum(m, (masks[k]).astype(np.float32))
            # binarize + dilate a margin so the removed hole clears the soft edge
            mb = Image.fromarray(((m > 0.5) * 255).astype(np.uint8))
            if DILATE > 1 and (m > 0.5).any():
                mb = mb.filter(ImageFilter.MaxFilter(DILATE))
            full = np.asarray(mb.resize((w, h), Image.BILINEAR), np.float32) / 255.0
            out.append(full)
            covered += float((full > 0.5).mean())
            if progress:
                progress(i + 1, n)
    stats["subject_frac"] = round(covered / max(n, 1), 4)
    return out, stats

### web/components/Splat/loader.ts
```
/**
 * Parser + progressive loader for the `.4dsplat` container produced by the
 * backend (api/app/pipeline/splat_format.py). Byte layout must stay in sync.
 *
 * Two on-disk versions:
 *  - v1 (legacy): independent per-timestep gaussian blocks. Streamed block by
 *    block; the viewer re-uploads textures on every timestep change.
 *  - v2 (spacetime): one static gaussian set + dynamic *trajectories* (birth /
 *    death / per-control-point positions). Parsed straight into texture-ready
 *    arrays: the static canvas paints as its bytes arrive, tracks activate when
 *    the stream completes, and playback interpolates continuously on the GPU.
 *
 * Both paths range-fetch a small header first and fall back to a single full
 * fetch if the server doesn't honor Range.
 */

export const TEX_WIDTH = 4096; // data-texture width; must match splatShader.ts

// ---------------------------------------------------------------------------
// v1 — legacy per-timestep clouds
// ---------------------------------------------------------------------------

export interface SplatTimestep {
  count: number;
  positions: Float32Array; // count * 3
  colors: Float32Array; // count * 4 (rgba, 0..1)
  scales: Float32Array; // count * 3
  rotations: Float32Array; // count * 4 (quaternion x,y,z,w)
}

export interface SplatMeta {
  version: number;
  numTimesteps: number;
  fps: number;
  bbox: [number, number, number, number, number, number];
  center: [number, number, number];
  radius: number;
  maxCount: number;
  counts: number[];
  offsets: number[];
  byteSize: number;
}

export interface SplatData extends SplatMeta {
  timesteps: SplatTimestep[];
}

const HEADER_SIZE = 44;
const HEADER2_SIZE = 60;
const STRIDE = 32; // bytes per gaussian / track record
// One read that comfortably covers header + directory for any realistic clip
// (8KB of directory ≈ 1000 timesteps). Larger ⇒ we fall back to a full parse.
const HEAD_PROBE = HEADER_SIZE + 8192;

function bboxDerived(bbox: SplatMeta["bbox"]) {
  const center: SplatMeta["center"] = [
    (bbox[0] + bbox[3]) / 2, (bbox[1] + bbox[4]) / 2, (bbox[2] + bbox[5]) / 2,
  ];
  const radius = 0.5 * Math.hypot(bbox[3] - bbox[0], bbox[4] - bbox[1], bbox[5] - bbox[2]);
  return { center, radius: radius || 1 };
}

function meta(dv: DataView, byteSize: number): SplatMeta {
  const magic = String.fromCharCode(dv.getUint8(0), dv.getUint8(1), dv.getUint8(2), dv.getUint8(3));
  if (magic !== "4DGS") throw new Error("Not a .4dsplat file");
  const version = dv.getUint32(4, true);
  if (version !== 1) throw new Error(`Not a v1 .4dsplat (version ${version})`);
  const numTimesteps = dv.getUint32(8, true);
  const fps = dv.getFloat32(16, true);
  const bbox: SplatMeta["bbox"] = [
    dv.getFloat32(20, true), dv.getFloat32(24, true), dv.getFloat32(28, true),
    dv.getFloat32(32, true), dv.getFloat32(36, true), dv.getFloat32(40, true),
  ];
  const counts: number[] = [];
  const offsets: number[] = [];
  let p = HEADER_SIZE;
  for (let i = 0; i < numTimesteps; i++) { counts.push(dv.getUint32(p, true)); p += 4; }
  for (let i = 0; i < numTimesteps; i++) { offsets.push(dv.getUint32(p, true)); p += 4; }
  const maxCount = counts.reduce((m, c) => Math.max(m, c), 0);
  return { version, numTimesteps, fps, bbox, ...bboxDerived(bbox), maxCount, counts, offsets, byteSize };
}

/** Decode one timestep block living at `base` within `buffer`. */
function parseTimestep(buffer: ArrayBuffer, base: number, count: number): SplatTimestep {
  const positions = new Float32Array(count * 3);
  const scales = new Float32Array(count * 3);
  const colors = new Float32Array(count * 4);
  const rotations = new Float32Array(count * 4);
  const f = new Float32Array(buffer, base, count * 8); // pos3, scale3, (color+rot packed)
  const u = new Uint8Array(buffer, base, count * STRIDE);
  const s8 = new Int8Array(buffer, base, count * STRIDE);
  for (let i = 0; i < count; i++) {
    const fb = i * 8;
    positions[i * 3] = f[fb]; positions[i * 3 + 1] = f[fb + 1]; positions[i * 3 + 2] = f[fb + 2];
    scales[i * 3] = f[fb + 3]; scales[i * 3 + 1] = f[fb + 4]; scales[i * 3 + 2] = f[fb + 5];
    const cb = i * STRIDE + 24;
    colors[i * 4] = u[cb] / 255; colors[i * 4 + 1] = u[cb + 1] / 255;
    colors[i * 4 + 2] = u[cb + 2] / 255; colors[i * 4 + 3] = u[cb + 3] / 255;
    const rb = i * STRIDE + 28;
    rotations[i * 4] = s8[rb] / 127; rotations[i * 4 + 1] = s8[rb + 1] / 127;
    rotations[i * 4 + 2] = s8[rb + 2] / 127; rotations[i * 4 + 3] = s8[rb + 3] / 127;
  }
  return { count, positions, colors, scales, rotations };
}

export interface ProgressiveHandlers {
  onMeta: (m: SplatMeta) => void;            // structure known → set up buffers + camera
  onTimestep: (index: number, ts: SplatTimestep) => void;  // a block is ready to render
  onProgress?: (loaded: number, total: number) => void;
}

/**
 * Stream a v1 `.4dsplat`: header → timestep 0 (first paint) → the rest.
 * Returns once every timestep has been delivered via `onTimestep`.
 */
export async function loadSplatProgressive(url: string, h: ProgressiveHandlers): Promise<void> {
  // 1) probe header + directory with a small range request
  const probe = await fetch(url, { headers: { Range: `bytes=0-${HEAD_PROBE - 1}` }, cache: "no-store" });
  if (!probe.ok && probe.status !== 206) throw new Error(`Failed to fetch splat (${probe.status})`);

  // server ignored Range (200) → we already hold the whole file: parse it all
  if (probe.status !== 206) {
    const buf = await probe.arrayBuffer();
    const m = meta(new DataView(buf), buf.byteLength);
    h.onMeta(m);
    for (let t = 0; t < m.numTimesteps; t++) {
      h.onTimestep(t, parseTimestep(buf, m.offsets[t], m.counts[t]));
      h.onProgress?.(m.offsets[t] + m.counts[t] * STRIDE, buf.byteLength);
    }
    return;
  }

  const total = parseInt((probe.headers.get("Content-Range") || "/0").split("/")[1], 10) || 0;
  const probeBuf = await probe.arrayBuffer();
  const dirEnd = HEADER_SIZE + new DataView(probeBuf).getUint32(8, true) * 8;
  if (dirEnd > probeBuf.byteLength) {
    // absurd timestep count — bail to a plain full fetch
    return loadFull(url, h);
  }
  const m = meta(new DataView(probeBuf), total);
  h.onMeta(m);

  const blockEnd = (t: number) => m.offsets[t] + m.counts[t] * STRIDE;

  // 2) timestep 0 — the first paint. Reuse the probe bytes if they already cover it.
  let ts0Buf: ArrayBuffer;
  let ts0Base = m.offsets[0];
  if (blockEnd(0) <= probeBuf.byteLength) {
    ts0Buf = probeBuf;
  } else {
    ts0Buf = await fetchRange(url, m.offsets[0], blockEnd(0) - 1);
    ts0Base = 0;
  }
  h.onTimestep(0, parseTimestep(ts0Buf, ts0Base, m.counts[0]));
  h.onProgress?.(blockEnd(0), total);
  if (m.numTimesteps === 1) return;

  // 3) the rest — one streamed range from timestep 1 to EOF, copied into a
  // single pre-allocated buffer (O(n)) and parsed block-by-block as it fills.
  const restStart = m.offsets[1];
  const restLen = total - restStart;
  const resp = await fetch(url, { headers: { Range: `bytes=${restStart}-${total - 1}` }, cache: "no-store" });
  const rest = new Uint8Array(restLen);
  let received = 0;
  let nextT = 1;

  const flush = () => {
    while (nextT < m.numTimesteps && blockEnd(nextT) - restStart <= received) {
      h.onTimestep(nextT, parseTimestep(rest.buffer, m.offsets[nextT] - restStart, m.counts[nextT]));
      nextT++;
    }
  };

  const reader = resp.body?.getReader();
  if (reader) {
    for (;;) {
      const { done, value } = await reader.read();
      if (done) break;
      rest.set(value, received);
      received += value.length;
      h.onProgress?.(restStart + received, total);
      flush();
    }
  } else {
    rest.set(new Uint8Array(await resp.arrayBuffer()), 0);
    received = restLen;
    h.onProgress?.(total, total);
  }
  flush();
}

async function fetchRange(url: string, start: number, end: number): Promise<ArrayBuffer> {
  const r = await fetch(url, { headers: { Range: `bytes=${start}-${end}` }, cache: "no-store" });
  if (!r.ok && r.status !== 206) throw new Error(`Range fetch failed (${r.status})`);
  return r.arrayBuffer();
}

async function loadFull(url: string, h: ProgressiveHandlers): Promise<void> {
  const res = await fetch(url, { cache: "no-store" });
  if (!res.ok) throw new Error(`Failed to fetch splat (${res.status})`);
  const buf = await res.arrayBuffer();
  const m = meta(new DataView(buf), buf.byteLength);
  h.onMeta(m);
  for (let t = 0; t < m.numTimesteps; t++) {
    h.onTimestep(t, parseTimestep(buf, m.offsets[t], m.counts[t]));
  }
  h.onProgress?.(buf.byteLength, buf.byteLength);
}

/** One-shot parse of a complete v1 buffer (used by tests and as a fallback). */
export function parseSplat(buffer: ArrayBuffer): SplatData {
  const m = meta(new DataView(buffer), buffer.byteLength);
  const timesteps = m.offsets.map((off, t) => parseTimestep(buffer, off, m.counts[t]));
  return { ...m, timesteps };
}

/** Full fetch + parse (kept for callers that want the whole thing at once). */
export async function loadSplat(
  url: string,
  onProgress?: (loaded: number, total: number) => void,
): Promise<SplatData> {
  const res = await fetch(url, { cache: "no-store" });
  if (!res.ok) throw new Error(`Failed to fetch splat (${res.status})`);
  const total = Number(res.headers.get("Content-Length") ?? 0);
  if (res.body && total > 0 && onProgress) {
    const reader = res.body.getReader();
    const chunks: Uint8Array[] = [];
    let loaded = 0;
    for (;;) {
      const { done, value } = await reader.read();
      if (done) break;
      chunks.push(value);
      loaded += value.length;
      onProgress(loaded, total);
    }
    const merged = new Uint8Array(loaded);
    let off = 0;
    for (const c of chunks) { merged.set(c, off); off += c.length; }
    return parseSplat(merged.buffer);
  }
  return parseSplat(await res.arrayBuffer());
}

export const TRACK_FADE_IN = 1;
export const TRACK_FADE_OUT = 2;

export interface SpacetimeMeta {
  version: 2;
  numCp: number;             // temporal control points (1 = still scene)
  fps: number;               // control points per second
  bbox: [number, number, number, number, number, number];
  center: [number, number, number];
  radius: number;
  staticCount: number;       // S — instances [0, S)
  trackCount: number;        // D — instances [S, S+D)
  posCount: number;          // P — stream positions
  instanceCount: number;     // S + D
  posTexels: number;         // S + P (static positions first, then the stream)
  byteSize: number;
}

/**
 * Texture-ready arrays, padded to TEX_WIDTH rows. Per instance i:
 *   attr   [posBase, birth, death, flags]  (static: [i, 0, 0, 0])
 *   scales [sx, sy, sz, –]
 *   colors rgba (opacity = peak; the shader applies the temporal envelope)
 *   rots   quaternion as (i8 + 128) — decode q = (v*255 − 128) / 127
 * Track i (≥ S) owns position texels [posBase, posBase + (death − birth + 1)).
 */
export interface SpacetimeData extends SpacetimeMeta {
  attr: Float32Array;
  scales: Float32Array;
  colors: Uint8Array;
  rots: Uint8Array;
  positions: Float32Array;   // posTexels * 4 (xyz + pad)
  aliveByCp: Uint32Array[];  // per integer cp: track instance ids possibly visible
}

export interface SpacetimeHandlers {
  onMeta: (d: SpacetimeData) => void;          // arrays allocated → set up GPU
  onStatic: (loaded: number) => void;          // static instances decoded so far
  onTracks: () => void;                        // trajectories complete → animate
  onProgress?: (loaded: number, total: number) => void;
}

function padRows(texels: number): number {
  return TEX_WIDTH * Math.max(1, Math.ceil(texels / TEX_WIDTH)) * 4;
}

function metaV2(dv: DataView, byteSize: number): SpacetimeMeta {
  const numCp = dv.getUint32(8, true);
  const fps = dv.getFloat32(16, true);
  const bbox: SpacetimeMeta["bbox"] = [
    dv.getFloat32(20, true), dv.getFloat32(24, true), dv.getFloat32(28, true),
    dv.getFloat32(32, true), dv.getFloat32(36, true), dv.getFloat32(40, true),
  ];
  const staticCount = dv.getUint32(44, true);
  const trackCount = dv.getUint32(48, true);
  const posCount = dv.getUint32(52, true);
  return {
    version: 2, numCp, fps, bbox, ...bboxDerived(bbox),
    staticCount, trackCount, posCount,
    instanceCount: staticCount + trackCount,
    posTexels: staticCount + posCount,
    byteSize,
  };
}

function allocSpacetime(m: SpacetimeMeta): SpacetimeData {
  return {
    ...m,
    attr: new Float32Array(padRows(m.instanceCount)),
    scales: new Float32Array(padRows(m.instanceCount)),
    colors: new Uint8Array(padRows(m.instanceCount)),
    rots: new Uint8Array(padRows(m.instanceCount)),
    positions: new Float32Array(padRows(m.posTexels)),
    aliveByCp: [],
  };
}

/** Decode static records [from, to) (indices) out of `bytes` at `base`. */
function decodeStatic(d: SpacetimeData, bytes: Uint8Array, base: number, from: number, to: number) {
  const dv = new DataView(bytes.buffer, bytes.byteOffset, bytes.byteLength);
  for (let i = from; i < to; i++) {
    const rec = base + i * STRIDE;
    const i4 = i * 4;
    d.positions[i4] = dv.getFloat32(rec, true);
    d.positions[i4 + 1] = dv.getFloat32(rec + 4, true);
    d.positions[i4 + 2] = dv.getFloat32(rec + 8, true);
    d.scales[i4] = dv.getFloat32(rec + 12, true);
    d.scales[i4 + 1] = dv.getFloat32(rec + 16, true);
    d.scales[i4 + 2] = dv.getFloat32(rec + 20, true);
    d.colors[i4] = bytes[rec + 24]; d.colors[i4 + 1] = bytes[rec + 25];
    d.colors[i4 + 2] = bytes[rec + 26]; d.colors[i4 + 3] = bytes[rec + 27];
    d.rots[i4] = (bytes[rec + 28] << 24 >> 24) + 128;
    d.rots[i4 + 1] = (bytes[rec + 29] << 24 >> 24) + 128;
    d.rots[i4 + 2] = (bytes[rec + 30] << 24 >> 24) + 128;
    d.rots[i4 + 3] = (bytes[rec + 31] << 24 >> 24) + 128;
    d.attr[i4] = i; // static: its own texel, alive forever (no fade flags)
    d.attr[i4 + 1] = 0; d.attr[i4 + 2] = 0; d.attr[i4 + 3] = 0;
  }
}

/** Decode all track records + the position stream (requires complete bytes). */
function decodeTracks(d: SpacetimeData, bytes: Uint8Array, tracksBase: number, streamBase: number) {
  const S = d.staticCount;
  const dv = new DataView(bytes.buffer, bytes.byteOffset, bytes.byteLength);
  for (let j = 0; j < d.trackCount; j++) {
    const rec = tracksBase + j * STRIDE;
    const i4 = (S + j) * 4;
    d.scales[i4] = dv.getFloat32(rec, true);
    d.scales[i4 + 1] = dv.getFloat32(rec + 4, true);
    d.scales[i4 + 2] = dv.getFloat32(rec + 8, true);
    d.colors[i4] = bytes[rec + 12]; d.colors[i4 + 1] = bytes[rec + 13];
    d.colors[i4 + 2] = bytes[rec + 14]; d.colors[i4 + 3] = bytes[rec + 15];
    d.rots[i4] = (bytes[rec + 16] << 24 >> 24) + 128;
    d.rots[i4 + 1] = (bytes[rec + 17] << 24 >> 24) + 128;
    d.rots[i4 + 2] = (bytes[rec + 18] << 24 >> 24) + 128;
    d.rots[i4 + 3] = (bytes[rec + 19] << 24 >> 24) + 128;
    const birth = dv.getUint16(rec + 20, true);
    const death = dv.getUint16(rec + 22, true);
    const posOffset = dv.getUint32(rec + 24, true);
    const flags = dv.getUint32(rec + 28, true);
    d.attr[i4] = S + posOffset;
    d.attr[i4 + 1] = birth;
    d.attr[i4 + 2] = death;
    d.attr[i4 + 3] = flags;
  }
  const f = new Float32Array(bytes.buffer, bytes.byteOffset + streamBase, d.posCount * 3);
  for (let p = 0; p < d.posCount; p++) {
    const t4 = (S + p) * 4;
    d.positions[t4] = f[p * 3];
    d.positions[t4 + 1] = f[p * 3 + 1];
    d.positions[t4 + 2] = f[p * 3 + 2];
  }
  buildAlive(d);
}

/** Per integer control point, which track instances could be visible
 * (their fade window ±1 cp). Bucketed once; the sorter walks these. */
function buildAlive(d: SpacetimeData) {
  const T = d.numCp;
  const S = d.staticCount;
  const sizes = new Uint32Array(T);
  for (let j = 0; j < d.trackCount; j++) {
    const a = d.attr[(S + j) * 4 + 1] - 1;
    const b = d.attr[(S + j) * 4 + 2] + 1;
    for (let cp = Math.max(0, a); cp <= Math.min(T - 1, b); cp++) sizes[cp]++;
  }
  const lists: Uint32Array[] = [];
  const cursors = new Uint32Array(T);
  for (let cp = 0; cp < T; cp++) lists.push(new Uint32Array(sizes[cp]));
  for (let j = 0; j < d.trackCount; j++) {
    const a = d.attr[(S + j) * 4 + 1] - 1;
    const b = d.attr[(S + j) * 4 + 2] + 1;
    for (let cp = Math.max(0, a); cp <= Math.min(T - 1, b); cp++) {
      lists[cp][cursors[cp]++] = S + j;
    }
  }
  d.aliveByCp = lists;
}

/** One-shot parse of a complete v2 buffer. */
export function parseSpacetime(buffer: ArrayBuffer): SpacetimeData {
  const m = metaV2(new DataView(buffer), buffer.byteLength);
  const d = allocSpacetime(m);
  const bytes = new Uint8Array(buffer);
  decodeStatic(d, bytes, HEADER2_SIZE, 0, m.staticCount);
  decodeTracks(
    d, bytes,
    HEADER2_SIZE + m.staticCount * STRIDE,
    HEADER2_SIZE + (m.staticCount + m.trackCount) * STRIDE,
  );
  return d;
}

const STATIC_CHUNK = 65536; // notify the viewer per this many decoded instances

/**
 * Stream a v2 `.4dsplat`: header → static canvas (first paint, chunked) →
 * trajectories. Resolves when everything has been decoded.
 */
export async function loadSpacetimeProgressive(url: string, h: SpacetimeHandlers): Promise<void> {
  const probe = await fetch(url, { headers: { Range: `bytes=0-${HEADER2_SIZE - 1}` }, cache: "no-store" });
  if (!probe.ok && probe.status !== 206) throw new Error(`Failed to fetch splat (${probe.status})`);

  if (probe.status !== 206) {
    // server ignored Range → whole file in hand
    const buf = await probe.arrayBuffer();
    const d = parseSpacetime(buf);
    h.onMeta(d);
    h.onStatic(d.staticCount);
    h.onTracks();
    h.onProgress?.(buf.byteLength, buf.byteLength);
    return;
  }

  const total = parseInt((probe.headers.get("Content-Range") || "/0").split("/")[1], 10) || 0;
  const head = new DataView(await probe.arrayBuffer());
  const m = metaV2(head, total);
  const d = allocSpacetime(m);
  h.onMeta(d);

  // one streamed range for the whole body, decoded incrementally
  const bodyStart = HEADER2_SIZE;
  const bodyLen = total - bodyStart;
  const resp = await fetch(url, { headers: { Range: `bytes=${bodyStart}-${total - 1}` }, cache: "no-store" });
  if (!resp.ok && resp.status !== 206) throw new Error(`Failed to fetch splat (${resp.status})`);
  const body = new Uint8Array(bodyLen);
  let received = 0;
  let staticDecoded = 0;
  let tracksDone = m.trackCount === 0;
  const staticBytes = m.staticCount * STRIDE;

  const flush = (final: boolean) => {
    // static records decode as their bytes land (chunked)
    const availStatic = Math.min(m.staticCount, Math.floor(received / STRIDE));
    if (
      availStatic > staticDecoded &&
      (final || availStatic - staticDecoded >= STATIC_CHUNK || availStatic === m.staticCount)
    ) {
      decodeStatic(d, body, 0, staticDecoded, availStatic);
      staticDecoded = availStatic;
      h.onStatic(staticDecoded);
    }
    // tracks + stream decode once fully present
    if (!tracksDone && received >= bodyLen) {
      decodeTracks(d, body, staticBytes, staticBytes + m.trackCount * STRIDE);
      tracksDone = true;
      h.onTracks();
    }
  };

  const reader = resp.body?.getReader();
  if (reader) {
    for (;;) {
      const { done, value } = await reader.read();
      if (done) break;
      body.set(value, received);
      received += value.length;
      h.onProgress?.(bodyStart + received, total);
      flush(false);
    }
  } else {
    const buf = new Uint8Array(await resp.arrayBuffer());
    body.set(buf, 0);
    received = buf.byteLength;
    h.onProgress?.(total, total);
  }
  flush(true);
  if (m.trackCount === 0) h.onTracks();
}

/**
 * Load either container version. Sniffs the header, then routes to the
 * matching progressive loader (both re-probe; the sniff itself is 8 bytes).
 */
export async function loadSplatAuto(
  url: string,
  v1: ProgressiveHandlers,
  v2: SpacetimeHandlers,
): Promise<void> {
  const probe = await fetch(url, { headers: { Range: "bytes=0-7" }, cache: "no-store" });
  if (!probe.ok && probe.status !== 206) throw new Error(`Failed to fetch splat (${probe.status})`);
  const buf = await probe.arrayBuffer();
  const dv = new DataView(buf);
  const magic = String.fromCharCode(dv.getUint8(0), dv.getUint8(1), dv.getUint8(2), dv.getUint8(3));
  if (magic !== "4DGS") throw new Error("Not a .4dsplat file");
  const version = dv.getUint32(4, true);

  if (probe.status !== 206 && buf.byteLength > HEADER2_SIZE) {
    // server ignored Range → we already hold the entire file
    if (version === 1) {
      const d = parseSplat(buf);
      v1.onMeta(d);
      d.timesteps.forEach((ts, t) => v1.onTimestep(t, ts));
      v1.onProgress?.(buf.byteLength, buf.byteLength);
    } else if (version === 2) {
      const d = parseSpacetime(buf);
      v2.onMeta(d);
      v2.onStatic(d.staticCount);
      v2.onTracks();
      v2.onProgress?.(buf.byteLength, buf.byteLength);
    } else {
      throw new Error(`Unsupported .4dsplat version ${version}`);
    }
    return;
  }

  if (version === 1) return loadSplatProgressive(url, v1);
  if (version === 2) return loadSpacetimeProgressive(url, v2);
  throw new Error(`Unsupported .4dsplat version ${version}`);
}

/**
 * Real EWA gaussian splatting (Kerbl et al. / Zwicker et al.) with a
 * spacetime twist: all per-gaussian data lives in data textures, the only
 * per-instance attribute is a sorted index, and dynamic gaussians carry
 * *trajectories* — the vertex shader fetches the two control-point positions
 * bracketing the current time, interpolates between them, and applies a
 * birth/death opacity envelope. Playback is therefore continuous in time and
 * a re-sort uploads 4 bytes per splat instead of the full attribute set.
 *
 * Texture layout (TEX_WIDTH-wide rows, see loader.ts):
 *   uPosTex   RGBA32F  xyz — static texel per static splat, then track streams
 *   uAttrTex  RGBA32F  posBase, birth, death, flags (1 = fade-in, 2 = fade-out)
 *   uScaleTex RGBA32F  scale xyz
 *   uColorTex RGBA8    rgb + peak opacity
 *   uRotTex   RGBA8    quaternion, stored (i8 + 128)
 *
 * Instances are pre-sorted back-to-front on the CPU and composited with
 * premultiplied alpha-over (no depth test). Requires WebGL2 (GLSL3).
 */

// quad spans ±RADIUS sigmas of the gaussian
const RADIUS = 3.0;
export const TEX_WIDTH = 4096;
const TEXW_MASK = TEX_WIDTH - 1;
const TEXW_SHIFT = Math.log2(TEX_WIDTH);

export const vertexShader = /* glsl */ `
  precision highp float;

  attribute float iIndex;  // sorted instance id → texel

  uniform highp sampler2D uPosTex;
  uniform highp sampler2D uAttrTex;
  uniform highp sampler2D uScaleTex;
  uniform sampler2D uColorTex;
  uniform sampler2D uRotTex;

  uniform vec2 uViewport;  // device pixels
  uniform float uFocal;    // pixels (fx = fy)
  uniform float uPointScale;
  uniform float uTimeCp;   // continuous time, in control-point units
  uniform float uFadeCp;   // envelope ramp length (control points)

  varying vec4 vColor;
  varying vec2 vPos;       // corner * RADIUS  → Mahalanobis coords

  const float RADIUS = ${RADIUS.toFixed(1)};

  ivec2 texAt(int i) {
    return ivec2(i & ${TEXW_MASK}, i >> ${TEXW_SHIFT});
  }

  mat3 quatToMat3(vec4 q) {
    float x = q.x, y = q.y, z = q.z, w = q.w;
    // column-major
    return mat3(
      1.0 - 2.0 * (y*y + z*z), 2.0 * (x*y + w*z),       2.0 * (x*z - w*y),
      2.0 * (x*y - w*z),       1.0 - 2.0 * (x*x + z*z), 2.0 * (y*z + w*x),
      2.0 * (x*z + w*y),       2.0 * (y*z - w*x),       1.0 - 2.0 * (x*x + y*y)
    );
  }

  void main() {
    int idx = int(iIndex + 0.5);
    vec4 A = texelFetch(uAttrTex, texAt(idx), 0);
    float birth = A.y;
    float death = A.z;
    int flags = int(A.w + 0.5);

    // temporal opacity envelope (static splats carry no fade flags → env = 1)
    float env = 1.0;
    if ((flags & 1) != 0) env *= smoothstep(birth - uFadeCp, birth, uTimeCp);
    if ((flags & 2) != 0) env *= 1.0 - smoothstep(death, death + uFadeCp, uTimeCp);
    if (env < 0.004) {                 // dead at this time → degenerate quad
      gl_Position = vec4(0.0, 0.0, 2.0, 1.0);
      return;
    }

    // trajectory: interpolate the two control points bracketing uTimeCp
    float cpF = clamp(uTimeCp, birth, death);
    float c0 = floor(cpF);
    float fr = cpF - c0;
    int base = int(A.x + 0.5);
    int rel = int(c0 - birth + 0.5);
    int span = int(death - birth + 0.5);
    vec3 p0 = texelFetch(uPosTex, texAt(base + rel), 0).xyz;
    vec3 p1 = texelFetch(uPosTex, texAt(base + min(rel + 1, span)), 0).xyz;
    vec3 iPos = mix(p0, p1, fr);

    vec4 col = texelFetch(uColorTex, texAt(idx), 0);
    vColor = vec4(col.rgb, col.a * env);

    vec4 cam = modelViewMatrix * vec4(iPos, 1.0);
    if (cam.z > -0.02) {            // behind / at camera → cull
      gl_Position = vec4(0.0, 0.0, 2.0, 1.0);
      return;
    }

    // 3D covariance Vrk = R S^2 R^T  (scale modulated by uPointScale)
    vec4 q = texelFetch(uRotTex, texAt(idx), 0) * (255.0 / 127.0) - (128.0 / 127.0);
    mat3 R = quatToMat3(q);
    vec3 sc = texelFetch(uScaleTex, texAt(idx), 0).xyz * uPointScale;
    mat3 M = R * mat3(sc.x, 0.0, 0.0,  0.0, sc.y, 0.0,  0.0, 0.0, sc.z);
    mat3 Vrk = M * transpose(M);

    // perspective Jacobian at cam (column-major)
    float z = cam.z;
    mat3 J = mat3(
      uFocal / z, 0.0, 0.0,
      0.0, uFocal / z, 0.0,
      -(uFocal * cam.x) / (z * z), -(uFocal * cam.y) / (z * z), 0.0
    );
    mat3 Rv = mat3(modelViewMatrix);     // view rotation (model = identity)
    mat3 T = J * Rv;
    mat3 cov = T * Vrk * transpose(T);

    // 2D covariance [[a,b],[b,c]] + small low-pass dilation (antialiasing).
    // Kept low for crisp splats — supersampling handles the aliasing.
    float a = cov[0][0] + 0.15;
    float b = cov[0][1];
    float c = cov[1][1] + 0.15;

    // eigen-decomposition
    float mid = 0.5 * (a + c);
    float rad = sqrt(max(mid * mid - (a * c - b * b), 0.0));
    float l1 = mid + rad;
    float l2 = max(mid - rad, 0.1);
    vec2 e1 = (abs(b) < 1e-6) ? vec2(1.0, 0.0) : normalize(vec2(b, l1 - a));
    vec2 e2 = vec2(-e1.y, e1.x);

    vec2 majorPx = RADIUS * sqrt(l1) * e1;
    vec2 minorPx = RADIUS * sqrt(l2) * e2;

    vec4 clip = projectionMatrix * cam;
    vec2 offsetPx = position.x * majorPx + position.y * minorPx;
    vec2 ndcOffset = (offsetPx / uViewport) * 2.0;

    vPos = position.xy * RADIUS;
    gl_Position = vec4(clip.xy + ndcOffset * clip.w, clip.z, clip.w);
  }
`;

export const fragmentShader = /* glsl */ `
  precision highp float;

  varying vec4 vColor;
  varying vec2 vPos;

  out vec4 fragColor;

  void main() {
    // Mahalanobis distance² (quad built in the covariance eigenbasis)
    float power = -0.5 * dot(vPos, vPos);
    float alpha = vColor.a * exp(power);
    if (alpha < 0.00392) discard;       // < 1/255
    alpha = min(alpha, 0.999);
    fragColor = vec4(vColor.rgb * alpha, alpha);   // premultiplied
  }
`;
