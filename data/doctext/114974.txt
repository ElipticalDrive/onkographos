# SeismicDataCompressor (SDC)

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23379711.svg)](https://doi.org/10.5281/zenodo.23379711)

Lossy and lossless compression of 3D seismic volumes (SEG-Y), with a classical closed-loop
DPCM codec, a **measured neural (autoencoder) hybrid codec**, a REST API, a web interface and a
**reproducible benchmark** that compares them with state-of-the-art scientific compressors
(ZFP, SZ3).

## Architecture

### Modules
- **`sdc-core`**: Core compression engine with preprocessing pipeline, quantization algorithms, and SDC container I/O (2D/3D support)
- **`sdc-ai`**: Neural hybrid codec — autoencoder prediction + bounded residual, trained with TensorFlow and executed in pure Java ([details](sdc-ai/README.md))
- **`sdc-cli`**: Command-line interface (Picocli) for compress/decompress/inspect operations
- **`sdc-svc`**: Spring Boot WebFlux microservice with RESTful API
- **`sdc-ui`**: Angular 18 web interface with Material Design components
- **`sdc-bench`**: Reproducible benchmark (deterministic synthetic SEG-Y dataset + measurement harness)

### REST API Endpoints

#### Compression/Decompression API (`/api/segy`)
- **POST** `/api/segy/compress` - Compress 2D SEG-Y file to SDC format
- **POST** `/api/segy/decompress` - Decompress SDC file to SEG-Y format
- **POST** `/api/segy/compress3d` - Compress 3D SEG-Y file with volume blocking
- **POST** `/api/segy/decompress3d` - Decompress 3D SDC file

#### Viewer API (`/api/viewer`)
- **POST** `/api/viewer/info` - Get SDC file metadata (dimensions, format, block structure)
- **POST** `/api/viewer/trace-slice` - Extract trace data slice (specified trace and sample ranges)
- **POST** `/api/viewer/volume-slice` - Extract 3D volume slice (inline/xline/time axis)
- **POST** `/api/viewer/trace-headers` - Retrieve trace header information
- **GET** `/api/viewer/cache-info?sdcPath={path}` - Get cache statistics
- **DELETE** `/api/viewer/cache-clear?sdcPath={path}` - Clear file cache

### Key Features
- Non-blocking reactive API using Spring WebFlux
- Intelligent volume block caching for fast 3D data access
- Support for both 2D and 3D seismic data
- Configurable compression profiles (quantization, preprocessing)

## Core Features

### sdc-core Module
- **Preprocessing**: Trace data normalization and conditioning
- **Quantization**: Closed-loop DPCM (the encoder predicts from reconstructed samples, so quantization error does not accumulate) with the bit depth stored in each payload
- **SDC Container**: Custom binary format with header and compressed blocks
- **2D Support**: Standard trace-by-trace compression
- **3D Support**: Volume-based blocking (inline/xline/time) for efficient random access
- **SEG-Y I/O**: Full SEG-Y Rev1 read/write support

### sdc-ai Module
- Convolutional autoencoder (32.7k parameters) trained with TensorFlow on synthetic sections; training script and model metadata in `sdc-ai/training` and `sdc-ai/models`
- Dependency-free `.sdcnn` model format and pure-Java inference, checked against TensorFlow outputs in the tests
- `NeuralHybridCodec`: int8 latents + uniformly quantized residual, so the maximum error is bounded (to within float32 rounding); a zero-prediction mode isolates what the network contributes
- TensorFlow Java runtime placeholder (`AeRuntime`), not required by the codec
- Limitations: trained and evaluated on synthetic data only; 25–90× slower to compress and 170–390× slower to decompress than the classical codecs (see [`sdc-ai/README.md`](sdc-ai/README.md))

### sdc-ai/training/segy_io.py
```
"""Minimal SEG-Y reader for the training pipeline (fixed-length traces, format 1 or 5,
inline at bytes 189-192 and crossline at 193-196) - the same layout SegyIO (Java) reads."""
import struct
import numpy as np


def ibm_to_float(words: np.ndarray) -> np.ndarray:
    words = words.astype(np.uint32)
    sign = np.where(words >> 31, -1.0, 1.0)
    exponent = ((words >> 24) & 0x7F).astype(np.int32) - 64
    mantissa = (words & 0x00FFFFFF).astype(np.float64) / float(1 << 24)
    return (sign * mantissa * np.power(16.0, exponent)).astype(np.float32)


def read_volume(path):
    """Returns a float32 array shaped (inlines, xlines, samples)."""
    with open(path, "rb") as f:
        f.seek(3200)
        binhdr = f.read(400)
        ns = struct.unpack(">H", binhdr[20:22])[0]
        fmt = struct.unpack(">H", binhdr[24:26])[0]
        if fmt not in (1, 5):
            raise ValueError(f"unsupported SEG-Y sample format {fmt}")
        raw = np.frombuffer(f.read(), dtype=np.uint8)
    trace_bytes = 240 + 4 * ns
    n = raw.size // trace_bytes
    raw = raw[: n * trace_bytes].reshape(n, trace_bytes)
    headers = raw[:, :240]
    il = headers[:, 188:192].copy().view(">i4").ravel()
    xl = headers[:, 192:196].copy().view(">i4").ravel()
    words = raw[:, 240:].copy().view(">u4")
    samples = words.view(">f4").astype(np.float32) if fmt == 5 else ibm_to_float(words)
    ils, xls = np.unique(il), np.unique(xl)
    vol = np.zeros((ils.size, xls.size, ns), dtype=np.float32)
    vol[np.searchsorted(ils, il), np.searchsorted(xls, xl)] = samples
    return vol
```

### sdc-ai/training/train_autoencoder.py
```
"""
Trains the SDC convolutional autoencoder used by the neural (hybrid) codec and exports it
to the dependency-free ".sdcnn" format that sdc-ai runs in pure Java.

The codec works on 2D seismic sections (crossline x time) of a volume normalized by its
peak absolute amplitude:

    encoder: conv3x3(c1) -> conv3x3/2(c2) -> conv3x3/2(c2) -> conv3x3/2(latent)   (factor 8)
    decoder: up2 -> conv3x3(c2) -> up2 -> conv3x3(c2) -> up2 -> conv3x3(c1) -> conv3x3(1)

Latents are rounded to integers by the codec, so training adds uniform noise U(-0.5, 0.5)
to the latents (the usual differentiable proxy for quantization) and penalizes their L1
norm, which keeps the integer latents small and cheap to entropy-code.

Data hygiene: the training/validation volumes come from SyntheticSegyGenerator with seeds
that never include the benchmark seed (20261012). See sdc-ai/README.md.

Usage:
    python train_autoencoder.py --train /data/train --val /data/val --out ../models/sdc-ae-v1.sdcnn
"""
import argparse
import glob
import hashlib
import json
import os
import struct
import time

import numpy as np
import tensorflow as tf

from segy_io import read_volume

MAGIC = b"SDCNN1\0\0"
LAYER_CONV, LAYER_LEAKY, LAYER_UP2 = 1, 2, 3
LEAKY_ALPHA = 0.1


def load_sections(folder):
    """Returns the list of normalized volumes found in the folder (*.sgy)."""
    vols = []
    for path in sorted(glob.glob(os.path.join(folder, "*.sgy"))):
        v = read_volume(path)
        v = v / max(float(np.abs(v).max()), 1e-12)
        vols.append(v.astype(np.float32))
        print(f"  {os.path.basename(path)} {v.shape}")
    return vols


def patch_dataset(vols, h, w, count, rng):
    """Random (h x w) crops from inline and crossline sections."""
    out = np.empty((count, h, w, 1), dtype=np.float32)
    for n in range(count):
        v = vols[rng.integers(len(vols))]
        ni, nj, nt = v.shape
        if rng.random() < 0.5:   # inline section: (xline, time)
            i = rng.integers(ni)
            j0, t0 = rng.integers(nj - h + 1), rng.integers(nt - w + 1)
            p = v[i, j0:j0 + h, t0:t0 + w]
        else:                    # crossline section: (inline, time)
            j = rng.integers(nj)
            i0, t0 = rng.integers(ni - h + 1), rng.integers(nt - w + 1)
            p = v[i0:i0 + h, j, t0:t0 + w]
        if rng.random() < 0.5:
            p = p[::-1, :]       # lateral flip (dips both ways)
        out[n, :, :, 0] = p
    return out


def conv(filters, stride=1, name=None):
    return tf.keras.layers.Conv2D(filters, 3, strides=stride, padding="same", name=name)


def build(c1, c2, latent):
    leaky = lambda: tf.keras.layers.LeakyReLU(negative_slope=LEAKY_ALPHA)
    enc = tf.keras.Sequential([
        tf.keras.Input((None, None, 1)),
        conv(c1), leaky(),
        conv(c2, 2), leaky(),
        conv(c2, 2), leaky(),
        conv(latent, 2),
    ], name="encoder")
    dec = tf.keras.Sequential([
        tf.keras.Input((None, None, latent)),
        tf.keras.layers.UpSampling2D(2), conv(c2), leaky(),
        tf.keras.layers.UpSampling2D(2), conv(c2), leaky(),
        tf.keras.layers.UpSampling2D(2), conv(c1), leaky(),
        conv(1),
    ], name="decoder")
    return enc, dec


class AE(tf.keras.Model):
    def __init__(self, enc, dec, l1):
        super().__init__()
        self.enc, self.dec, self.l1 = enc, dec, l1

    def call(self, x, training=False):
        y = self.enc(x)
        if training:
            y = y + tf.random.uniform(tf.shape(y), -0.5, 0.5)
        else:
            y = tf.round(y)
        return self.dec(y), y

    def train_step(self, x):
        with tf.GradientTape() as tape:
            xh, y = self(x, training=True)
            mse = tf.reduce_mean(tf.square(x - xh))
            rate = tf.reduce_mean(tf.abs(y))
            loss = mse + self.l1 * rate
        self.optimizer.apply_gradients(zip(tape.gradient(loss, self.trainable_variables), self.trainable_variables))
        return {"loss": loss, "mse": mse, "latent_l1": rate}

    def test_step(self, x):
        xh, y = self(x, training=False)
        return {"loss": tf.reduce_mean(tf.square(x - xh)), "latent_l1": tf.reduce_mean(tf.abs(y))}


def export_sdcnn(enc, dec, latent, path, meta):
    """Binary little-endian layout read by com.sdc.ai.nn.NeuralModel."""
    def layers_of(model):
        rows = []
        for layer in model.layers:
            if isinstance(layer, tf.keras.layers.Conv2D):
                k, b = layer.get_weights()          # k: (kh, kw, cin, cout) HWIO
                rows.append((LAYER_CONV, layer.strides[0], k, b))
            elif isinstance(layer, tf.keras.layers.LeakyReLU):
                rows.append((LAYER_LEAKY, LEAKY_ALPHA))
            elif isinstance(layer, tf.keras.layers.UpSampling2D):
                rows.append((LAYER_UP2,))
            else:
                raise ValueError(f"unsupported layer {layer}")
        return rows

    meta_json = json.dumps(meta, sort_keys=True).encode("utf-8")
    with open(path, "wb") as f:
        f.write(MAGIC)
        f.write(struct.pack("<iii", 1, latent, 8))       # format version, latent channels, factor
        f.write(struct.pack("<i", len(meta_json)))
        f.write(meta_json)
        for model in (enc, dec):
            rows = layers_of(model)
            f.write(struct.pack("<i", len(rows)))
            for r in rows:
                f.write(struct.pack("<i", r[0]))
                if r[0] == LAYER_CONV:
                    _, stride, k, b = r
                    kh, kw, cin, cout = k.shape
                    f.write(struct.pack("<iiiii", kh, kw, cin, cout, stride))
                    f.write(np.ascontiguousarray(k, dtype="<f4").tobytes())
                    f.write(np.ascontiguousarray(b, dtype="<f4").tobytes())
                elif r[0] == LAYER_LEAKY:
                    f.write(struct.pack("<f", r[1]))
    with open(path, "rb") as f:
        return hashlib.sha256(f.read()).hexdigest()


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--train", required=True)
    ap.add_argument("--val", required=True)
    ap.add_argument("--out", required=True)
    ap.add_argument("--c1", type=int, default=16)
    ap.add_argument("--c2", type=int, default=32)
    ap.add_argument("--latent", type=int, default=8)
    ap.add_argument("--l1", type=float, default=2e-5)
    ap.add_argument("--patch", type=int, nargs=2, default=[64, 128])
    ap.add_argument("--train-patches", type=int, default=24000)
    ap.add_argument("--val-patches", type=int, default=2000)
    ap.add_argument("--epochs", type=int, default=12)
    ap.add_argument("--batch", type=int, default=32)
    ap.add_argument("--seed", type=int, default=7)
    ap.add_argument("--fixture", help="write a parity fixture (input/latent/output) for the Java tests")
    args = ap.parse_args()

    tf.keras.utils.set_random_seed(args.seed)
    rng = np.random.default_rng(args.seed)
    print("train volumes:"); train_vols = load_sections(args.train)
    print("val volumes:"); val_vols = load_sections(args.val)
    h, w = args.patch
    xtr = patch_dataset(train_vols, h, w, args.train_patches, rng)
    xva = patch_dataset(val_vols, h, w, args.val_patches, rng)

    enc, dec = build(args.c1, args.c2, args.latent)
    model = AE(enc, dec, args.l1)
    sched = tf.keras.optimizers.schedules.CosineDecay(1e-3, args.epochs * (len(xtr) // args.batch))
    model.compile(optimizer=tf.keras.optimizers.Adam(sched))
    t0 = time.time()
    hist = model.fit(xtr, batch_size=args.batch, epochs=args.epochs, validation_data=(xva,), verbose=2, shuffle=True)
    train_seconds = time.time() - t0

    val_mse = float(hist.history["val_loss"][-1])
    signal = float(np.mean(np.square(xva)))
    meta = {
        "architecture": f"conv-ae c1={args.c1} c2={args.c2} latent={args.latent} factor=8 leaky={LEAKY_ALPHA}",
        "framework": f"tensorflow {tf.__version__}",
        "train_dir": os.path.basename(os.path.normpath(args.train)),
        "train_volumes": len(train_vols),
        "val_volumes": len(val_vols),
        "patch": [h, w],
        "train_patches": args.train_patches,
        "epochs": args.epochs,
        "l1": args.l1,
        "seed": args.seed,
        "val_mse_normalized": val_mse,
        "val_snr_db_rounded_latents": 10 * np.log10(signal / val_mse),
        "train_seconds": round(train_seconds, 1),
        "params": int(enc.count_params() + dec.count_params()),
    }
    os.makedirs(os.path.dirname(os.path.abspath(args.out)), exist_ok=True)
    sha = export_sdcnn(enc, dec, args.latent, args.out, meta)
    with open(os.path.splitext(args.out)[0] + ".json", "w") as f:
        json.dump({**meta, "sha256": sha}, f, indent=2)
    print(json.dumps({**meta, "sha256": sha}, indent=2))

    if args.fixture:
        x = xva[:1, :32, :48, :]
        y_raw = enc(x).numpy()
        y = np.round(y_raw)
        xh = dec(y).numpy()
        with open(args.fixture, "wb") as f:
            for arr in (x, y_raw, y, xh):
                f.write(struct.pack("<iiii", *arr.shape))
                f.write(np.ascontiguousarray(arr, dtype="<f4").tobytes())
        print("fixture written to", args.fixture)


if __name__ == "__main__":
    main()
```

### sdc-ui/src/app/app.component.ts
```
import { Component, OnInit } from '@angular/core';
import { ActivatedRoute, Router } from '@angular/router';
import { SdcViewerService, ViewerInfoResponse } from './services/sdc-viewer.service';

const VALID_TABS = new Set(['metadata', 'trace', 'volume', 'headers', 'compress']);

@Component({
  selector: 'app-root',
  templateUrl: './app.component.html',
  styleUrls: ['./app.component.scss']
})
export class AppComponent implements OnInit {
  title = 'SDC Viewer - Seismic Data Compressor';
  selectedFile: string | null = null;
  fileInfo: ViewerInfoResponse | null = null;
  loading = false;
  error: string | null = null;
  activeTab = 'metadata';

  constructor(
    private sdcViewerService: SdcViewerService,
    private route: ActivatedRoute,
    private router: Router
  ) {}

  ngOnInit() {
    this.route.queryParams.subscribe(params => {
      const tab = params['tab'];
      this.activeTab = VALID_TABS.has(tab) ? tab : 'metadata';

      const file = params['file'];
      if (file && file !== this.selectedFile) {
        this.selectedFile = file;
        this.loadFileInfo();
      }
    });
  }

  setTab(tab: string) {
    this.router.navigate([], {
      relativeTo: this.route,
      queryParams: { tab },
      queryParamsHandling: 'merge'
    });
  }

  onFileSelected(basename: string) {
    this.selectedFile = basename;
    this.router.navigate([], {
      relativeTo: this.route,
      queryParams: { file: basename },
      queryParamsHandling: 'merge'
    });
    this.loadFileInfo();
  }

  loadFileInfo() {
    if (!this.selectedFile) return;

    this.loading = true;
    this.error = null;

    this.sdcViewerService.getInfo({ sdcPath: this.selectedFile })
      .subscribe({
        next: (info) => {
          this.fileInfo = info;
          this.loading = false;
        },
        error: (err) => {
          this.error = 'Error loading file: ' + err.message;
          this.loading = false;
        }
      });
  }

  onViewResult(basename: string) {
    this.selectedFile = basename;
    this.setTab('metadata');
    this.loadFileInfo();
  }

  get isSdc2D(): boolean {
    return this.fileInfo ? this.fileInfo.version === 2 : false;
  }

  get isSdc3D(): boolean {
    return this.fileInfo ? this.fileInfo.version === 3 : false;
  }
}
```

```
import { HttpErrorResponse } from '@angular/common/http';

export type AppError =
  | { kind: 'client'; message: string }
  | { kind: 'server'; message: string }
  | { kind: 'network'; baseUrl: string };

export function parseHttpError(err: HttpErrorResponse, baseUrl: string): AppError {
  if (err.status === 0) return { kind: 'network', baseUrl };
  if (err.status < 500) return { kind: 'client', message: err.error?.message ?? err.message };
  return { kind: 'server', message: err.error?.message ?? 'Internal server error' };
}
```

```
    return this.http.post<ViewerInfoResponse>(`${this.apiUrl}/info`, request);
```

### sdc-ui/src/app/components/compress-tab/compress-tab.component.ts
```
import { Component, EventEmitter, OnInit, OnDestroy, Output } from '@angular/core';
import { Subject, EMPTY, Subscription } from 'rxjs';
import { switchMap, tap, catchError } from 'rxjs/operators';
import { SdcViewerService, CompressResponse } from '../../services/sdc-viewer.service';
import { AppError, parseHttpError } from '../../models/app-error';

export type CompressState = 'idle' | 'submitting' | 'success' | 'error';

@Component({
  selector: 'app-compress-tab',
  templateUrl: './compress-tab.component.html',
  styleUrls: ['./compress-tab.component.scss']
})
export class CompressTabComponent implements OnInit, OnDestroy {

  @Output() viewResult = new EventEmitter<string>();

  selectedSgy: string | null = null;
  selectedProfile: string = 'balanced';
  is3D: boolean = false;

  state: CompressState = 'idle';
  get submitting(): boolean { return this.state === 'submitting'; }

  result: CompressResponse | null = null;
  appError: AppError | null = null;
  elapsedMs: number = 0;

  private submitSubject = new Subject<void>();
  private subscription!: Subscription;

  constructor(private svc: SdcViewerService) {}

  ngOnInit(): void {
    this.subscription = this.submitSubject.pipe(
      switchMap(() => {
        this.state = 'submitting';
        this.result = null;
        this.appError = null;
        const start = Date.now();
        const req = { sgyFile: this.selectedSgy!, profile: this.selectedProfile };
        const obs = this.is3D ? this.svc.compress3d(req) : this.svc.compress(req);
        return obs.pipe(
          tap(res => {
            this.result = res;
            this.elapsedMs = Date.now() - start;
            this.state = 'success';
          }),
          catchError(err => {
            this.appError = parseHttpError(err, '/api/segy');
            this.state = 'error';
            return EMPTY;
          })
        );
      })
    ).subscribe();
  }

  ngOnDestroy(): void {
    this.subscription?.unsubscribe();
  }

  onSgySelected(basename: string): void {
    this.selectedSgy = basename;
  }

  submit(): void {
    if (!this.selectedSgy || this.submitting) return;
    this.submitSubject.next();
  }

  onRetry(): void {
    this.state = 'idle';
    this.appError = null;
    this.result = null;
  }

  viewResultClicked(): void {
    const outputBasename = this.result?.sdcPath ?? this.selectedSgy ?? '';
    this.viewResult.emit(outputBasename);
  }
}
```

```
import { Component, Input, Output, EventEmitter, OnInit, ViewChild, ElementRef } from '@angular/core';
import { SdcViewerService } from '../../services/sdc-viewer.service';

const RECENT_KEY = 'sdc.recentFiles';
const MAX_RECENT = 5;

@Component({
  selector: 'app-file-selector',
  templateUrl: './file-selector.component.html',
  styleUrls: ['./file-selector.component.scss']
})
export class FileSelectorComponent implements OnInit {

  @Input() extension: 'sdc' | 'sgy' = 'sdc';
  @Output() fileSelected = new EventEmitter<string>();

  @ViewChild('nativeFilePicker') nativeFilePicker!: ElementRef<HTMLInputElement>;

  availableFiles: string[] = [];
  recentFiles: string[] = [];
  selected: string = '';
  manualPath: string = '';
  fallbackMode: boolean = false;

  constructor(private viewerService: SdcViewerService) {}

  ngOnInit(): void {
    this.fetchFiles();
  }

  fetchFiles(): void {
    this.viewerService.getAvailableFiles(this.extension).subscribe({
      next: (response) => {
        const files = response.files ?? [];
        if (files.length === 0) {
          this.fallbackMode = true;
        } else {
          this.fallbackMode = false;
          this.availableFiles = files;
          this.recentFiles = this.loadRecentFiles(files);
        }
      },
      error: () => { this.fallbackMode = true; }
    });
  }

  onSelect(event: { value: string }): void {
    const basename = event.value;
    this.saveToRecent(basename);
    this.fileSelected.emit(basename);
  }

  onManualSubmit(): void {
    const path = this.manualPath.trim();
    if (path) {
      this.fileSelected.emit(path);
    }
  }

  openFilePicker(): void {
    this.nativeFilePicker.nativeElement.click();
  }

  onNativeFileSelected(event: Event): void {
    const file = (event.target as HTMLInputElement).files?.[0];
    if (file) {
      // Fill input with just the filename — backend resolves against dataRoot
      this.manualPath = file.name;
    }
    // Reset so same file can be re-picked
    (event.target as HTMLInputElement).value = '';
  }

  private loadRecentFiles(serverFiles: string[]): string[] {
    const stored = this.getStoredRecents();
    const valid = stored.filter(f => serverFiles.includes(f));
    this.persistRecents(valid);
    return valid.slice(0, MAX_RECENT);
  }

  private saveToRecent(basename: string): void {
    const recents = this.getStoredRecents().filter(f => f !== basename);
    recents.unshift(basename);
    const trimmed = recents.slice(0, MAX_RECENT);
    this.persistRecents(trimmed);
    this.recentFiles = trimmed;
  }

  private getStoredRecents(): string[] {
    try {
      const raw = localStorage.getItem(RECENT_KEY);
      if (!raw) return [];
      const parsed = JSON.parse(raw);
      return Array.isArray(parsed) ? parsed : [];
    } catch { return []; }
  }

  private persistRecents(recents: string[]): void {
    localStorage.setItem(RECENT_KEY, JSON.stringify(recents));
  }
}
```

```
import { Component, ElementRef, Input, OnInit, ViewChild } from '@angular/core';
import { SdcViewerService, TraceSliceResponse } from '../../services/sdc-viewer.service';

@Component({
  selector: 'app-trace-view',
  templateUrl: './trace-view.component.html',
  styleUrls: ['./trace-view.component.scss']
})
export class TraceViewComponent implements OnInit {
  @ViewChild('heatmapCanvas') heatmapCanvas!: ElementRef<HTMLCanvasElement>;
  @Input() sdcPath!: string;

  traceStart = 0;
  traceCount = 50;
  sampleStart = 0;
  sampleCount: number | null = null;

  sliceData: TraceSliceResponse | null = null;
  loading = false;
  error: string | null = null;

  constructor(private viewerService: SdcViewerService) {}

  ngOnInit() {
    this.loadSlice();
  }

  loadSlice() {
    this.loading = true;
    this.error = null;

    this.viewerService.getTraceSlice({
      sdcPath: this.sdcPath,
      traceStart: this.traceStart,
      traceCount: this.traceCount,
      sampleStart: this.sampleStart,
      sampleCount: this.sampleCount ?? undefined
    }).subscribe({
      next: (data) => {
        this.sliceData = data;
        this.loading = false;
        setTimeout(() => this.renderCanvas(), 100);
      },
      error: (err) => {
        this.error = 'Error loading traces: ' + (err.message || err);
        this.loading = false;
      }
    });
  }

  private renderCanvas() {
    if (!this.sliceData) return;

    const canvas = this.heatmapCanvas?.nativeElement;
    if (!canvas) return;

    const ctx = canvas.getContext('2d')!;
    const samples = this.sliceData.samples;
    const traceCount = samples.length;
    const sampleCount = samples[0]?.length || 0;

    if (traceCount === 0 || sampleCount === 0) return;

    canvas.width = traceCount * 2;
    canvas.height = sampleCount;

    // Simple heatmap rendering
    const imageData = ctx.createImageData(traceCount, sampleCount);
    const data = imageData.data;

    let min = Infinity;
    let max = -Infinity;
    for (let i = 0; i < traceCount; i++) {
      for (let j = 0; j < sampleCount; j++) {
        const v = samples[i][j];
        min = Math.min(min, v);
        max = Math.max(max, v);
      }
    }

    const range = max - min || 1;

    for (let i = 0; i < traceCount; i++) {
      for (let j = 0; j < sampleCount; j++) {
        const v = (samples[i][j] - min) / range;
        const idx = (j * traceCount + i) * 4;
        const color = Math.floor(v * 255);

        data[idx] = color;
        data[idx + 1] = color;
        data[idx + 2] = color;
        data[idx + 3] = 255;
      }
    }

    ctx.putImageData(imageData, 0, 0);
  }
}
```

```
package com.sdc.ai;

import com.sdc.ai.nn.NeuralModel;
import com.sdc.ai.nn.Tensor3;

import java.io.ByteArrayOutputStream;
import java.io.DataInputStream;
import java.io.DataOutputStream;
import java.io.IOException;
import java.util.Arrays;
import java.util.zip.DataFormatException;
import java.util.zip.Deflater;
import java.util.zip.Inflater;

/**
 * Hybrid neural codec for 3D seismic volumes: a learned autoencoder predicts each section, and
 * the prediction residual is uniformly quantized, so the maximum error is bounded.
 *
 * <pre>
 *   x_n   = x / s                      s = peak |x| of the volume (stored)
 *   y     = round(encoder(x_n))        per inline section (crossline x time), int8 latents
 *   p     = decoder(y)                 prediction, identical on encoder and decoder side
 *   q     = round((x_n - p) / step)    step = 1 / (2^(bits-1) - 1)
 *   x_hat = s * (p + q * step)         |x - x_hat| <= s * step / 2, up to float32 rounding (~1 ulp of x)
 * </pre>
 *
 * <p>Payload = deflate(latents) + deflate(residual indices, stored as byte planes). With {@link Predictor#NONE} the
 * prediction is zero, which turns the codec into plain uniform quantization + Deflate with the
 * same step: the difference in size between the two modes is exactly what the neural predictor
 * buys. With {@code residualBits = 0} only the latents are stored (neural-only, lowest rate, no
 * error bound).</p>
 */
public final class NeuralHybridCodec {

    private static final byte[] MAGIC = {'S', 'D', 'C', 'N'};
    private static final int VERSION = 1;

    public enum Predictor { NEURAL, NONE }

    public record Settings(Predictor predictor, int residualBits, int deflaterLevel) {
        public Settings {
            if (residualBits != 0 && (residualBits < 2 || residualBits > 16)) {
                throw new IllegalArgumentException("residualBits must be 0 (none) or 2..16");
            }
            if (predictor == Predictor.NONE && residualBits == 0) {
                throw new IllegalArgumentException("predictor NONE needs a residual");
            }
        }
    }

    /** Encoded payload plus the split of its size, for reporting. */
    public record Encoded(byte[] payload, int latentBytes, int residualBytes) {}

    private NeuralHybridCodec() {}

    /**
     * The neural part of the encoding (latents + prediction). It does not depend on the residual
     * bit depth, so a rate–distortion sweep can compute it once and reuse it for every bit depth.
     * {@code model == null} gives the zero prediction ({@link Predictor#NONE}).
     */
    public record Prediction(Predictor predictor, float scale, int ni, int nj, int nt,
                             byte[] latents, float[][][] normalizedPrediction, byte[] modelSha256) {}

    public static Prediction predict(float[][][] vol, NeuralModel model) {
        int ni = vol.length, nj = vol[0].length, nt = vol[0][0].length;
        float s = 0f;
        for (float[][] a : vol) for (float[] t : a) for (float v : t) s = Math.max(s, Math.abs(v));
        if (s == 0f) s = 1f;
        if (model == null) {
            return new Prediction(Predictor.NONE, s, ni, nj, nt, new byte[0], null, new byte[32]);
        }
        float inv = 1f / s;
        int f = model.factor();
        int ph = roundUp(nj, f), pw = roundUp(nt, f);
        int lh = ph / f, lw = pw / f, lc = model.latentChannels();
        byte[] latents = new byte[ni * lh * lw * lc];
        float[][][] pred = new float[ni][][];
        for (int i = 0; i < ni; i++) {
            Tensor3 x = new Tensor3(ph, pw, 1);
            for (int j = 0; j < nj; j++) {
                for (int k = 0; k < nt; k++) x.data[j * pw + k] = vol[i][j][k] * inv;
            }
            Tensor3 y = model.encode(x);
            Tensor3 yq = new Tensor3(y.h, y.w, y.c);
            int base = i * lh * lw * lc;
            for (int n = 0; n < y.data.length; n++) {
                int v = Math.round(y.data[n]);
                if (v > 127) v = 127;
                if (v < -127) v = -127;
                latents[base + n] = (byte) v;
                yq.data[n] = v;
            }
            pred[i] = crop(model.decode(yq), nj, nt);
        }
        return new Prediction(Predictor.NEURAL, s, ni, nj, nt, latents, pred, model.sha256());
    }

    public static Encoded encode(float[][][] vol, NeuralModel model, Settings st) {
        return encode(vol, predict(vol, st.predictor() == Predictor.NEURAL ? model : null), st);
    }

    public static Encoded encode(float[][][] vol, Prediction p, Settings st) {
        if (p.predictor() != st.predictor()) throw new IllegalArgumentException("prediction/settings mismatch");
        int ni = p.ni(), nj = p.nj(), nt = p.nt();
        float inv = 1f / p.scale();
        int[] q = null;
        if (st.residualBits() > 0) {
            float step = 1f / maxQ(st.residualBits());
            q = new int[ni * nj * nt];
            for (int i = 0; i < ni; i++) {
                float[][] pred = p.normalizedPrediction() == null ? null : p.normalizedPrediction()[i];
                int base = i * nj * nt;
                for (int j = 0; j < nj; j++) {
                    for (int k = 0; k < nt; k++) {
                        float pv = pred == null ? 0f : pred[j][k];
                        q[base + j * nt + k] = Math.round((vol[i][j][k] * inv - pv) / step);
                    }
                }
            }
        }
        boolean neural = p.predictor() == Predictor.NEURAL;
        byte[] latentZ = neural ? deflate(p.latents(), st.deflaterLevel()) : new byte[0];
        int width = q == null ? 0 : widthFor(q);
        byte[] residualZ = q == null ? new byte[0] : deflate(toBytes(q, width), st.deflaterLevel());

        ByteArrayOutputStream bos = new ByteArrayOutputStream(latentZ.length + residualZ.length + 64);
        try (DataOutputStream out = new DataOutputStream(bos)) {
            out.write(MAGIC);
            out.writeByte(VERSION);
            out.writeByte(st.predictor().ordinal());
            out.writeByte(st.residualBits());
            out.writeByte(width);
            out.writeInt(ni);
            out.writeInt(nj);
            out.writeInt(nt);
            out.writeFloat(p.scale());
            out.write(p.modelSha256());
            out.writeInt(latentZ.length);
            out.write(latentZ);
            out.writeInt(residualZ.length);
            out.write(residualZ);
        } catch (IOException e) {
            throw new IllegalStateException(e);
        }
        return new Encoded(bos.toByteArray(), latentZ.length, residualZ.length);
    }

    /**
     * Reconstruction that {@link #decode} would return for {@code encode(vol, p, residualBits)},
     * computed without the payload round trip (same arithmetic, so the result is bit-identical).
     * Used by rate–distortion sweeps; the benchmark checks the equality against a real decode.
     */
    public static float[][][] reconstruct(float[][][] vol, Prediction p, int residualBits) {
        int ni = p.ni(), nj = p.nj(), nt = p.nt();
        float s = p.scale(), inv = 1f / s;
        float step = residualBits == 0 ? 0f : 1f / maxQ(residualBits);
        float[][][] out = new float[ni][nj][nt];
        for (int i = 0; i < ni; i++) {
            float[][] pred = p.normalizedPrediction() == null ? null : p.normalizedPrediction()[i];
            for (int j = 0; j < nj; j++) {
                for (int k = 0; k < nt; k++) {
                    float pv = pred == null ? 0f : pred[j][k];
                    float r = 0f;
                    if (residualBits > 0) {
                        int q = Math.round((vol[i][j][k] * inv - pv) / step);
                        r = q * step;
                    }
                    out[i][j][k] = (pv + r) * s;
                }
            }
        }
        return out;
    }

    public static float[][][] decode(byte[] payload, NeuralModel model) throws IOException {
        DataInputStream in = new DataInputStream(new java.io.ByteArrayInputStream(payload));
        byte[] magic = in.readNBytes(4);
        if (!Arrays.equals(magic, MAGIC)) throw new IOException("not an SDC neural payload");
        int version = in.readUnsignedByte();
        if (version != VERSION) throw new IOException("unsupported neural payload version " + version);
        Predictor predictor = Predictor.values()[in.readUnsignedByte()];
        int bits = in.readUnsignedByte();
        int width = in.readUnsignedByte();
        int ni = in.readInt(), nj = in.readInt(), nt = in.readInt();
        float s = in.readFloat();
        byte[] sha = in.readNBytes(32);
        byte[] latentZ = in.readNBytes(in.readInt());
        byte[] residualZ = in.readNBytes(in.readInt());

        boolean neural = predictor == Predictor.NEURAL;
        if (neural) {
            if (model == null) throw new IOException("payload needs a neural model");
            if (!Arrays.equals(sha, model.sha256())) {
                throw new IOException("payload was encoded with a different model (sha256 mismatch)");
            }
        }
        int f = neural ? model.factor() : 1;
        int ph = roundUp(nj, f), pw = roundUp(nt, f);
        int lh = ph / f, lw = pw / f, lc = neural ? model.latentChannels() : 0;
        byte[] latents = neural ? inflate(latentZ, ni * lh * lw * lc) : null;
        int[] q = bits == 0 ? null : fromBytes(inflate(residualZ, ni * nj * nt * width), width);
        float step = bits == 0 ? 0f : 1f / maxQ(bits);

        float[][][] out = new float[ni][nj][nt];
        for (int i = 0; i < ni; i++) {
            float[][] pred = null;
            if (neural) {
                Tensor3 yq = new Tensor3(lh, lw, lc);
                int base = i * lh * lw * lc;
                for (int n = 0; n < yq.data.length; n++) yq.data[n] = latents[base + n];
                pred = crop(model.decode(yq), nj, nt);
            }
            int base = i * nj * nt;
            for (int j = 0; j < nj; j++) {
                for (int k = 0; k < nt; k++) {
                    float p = pred == null ? 0f : pred[j][k];
                    float r = q == null ? 0f : q[base + j * nt + k] * step;
                    out[i][j][k] = (p + r) * s;
                }
            }
        }
        return out;
    }

    // ---------------------------------------------------------------------------------------

    static int maxQ(int bits) {
        return (1 << (bits - 1)) - 1;
    }

    private static int roundUp(int n, int f) {
        return (n + f - 1) / f * f;
    }

    private static float[][] crop(Tensor3 t, int h, int w) {
        float[][] o = new float[h][w];
        for (int y = 0; y < h; y++) {
            for (int x = 0; x < w; x++) o[y][x] = t.data[(y * t.w + x) * t.c];
        }
        return o;
    }

    private static int widthFor(int[] q) {
        int m = 0;
        for (int v : q) m = Math.max(m, Math.abs(v));
        return m <= Byte.MAX_VALUE ? 1 : (m <= Short.MAX_VALUE ? 2 : 4);
    }

    /** Big-endian values split into byte planes (most significant plane first). */
    private static byte[] toBytes(int[] q, int width) {
        int n = q.length;
        byte[] b = new byte[n * width];
        for (int p = 0; p < width; p++) {
            int shift = (width - 1 - p) * 8;
            for (int i = 0; i < n; i++) b[p * n + i] = (byte) (q[i] >>> shift);
        }
        return b;
    }

    private static int[] fromBytes(byte[] b, int width) {
        int n = b.length / width;
        int[] q = new int[n];
        for (int i = 0; i < n; i++) {
            int v = b[i];                          // sign-extended most significant byte
            for (int p = 1; p < width; p++) v = (v << 8) | (b[p * n + i] & 0xFF);
            q[i] = v;
        }
        return q;
    }

    private static byte[] deflate(byte[] in, int level) {
        Deflater d = new Deflater(level);
        try {
            d.setInput(in);
            d.finish();
            ByteArrayOutputStream bos = new ByteArrayOutputStream(Math.max(64, in.length / 4));
            byte[] buf = new byte[1 << 16];
            while (!d.finished()) bos.write(buf, 0, d.deflate(buf));
            return bos.toByteArray();
        } finally {
            d.end();
        }
    }

    private static byte[] inflate(byte[] in, int expected) throws IOException {
        Inflater inf = new Inflater();
        try {
            inf.setInput(in);
            byte[] out = new byte[expected];
            int off = 0;
            while (off < expected && !inf.finished()) {
                int n = inf.inflate(out, off, expected - off);
                if (n == 0 && (inf.needsInput() || inf.needsDictionary())) break;
                off += n;
            }
            if (off != expected) throw new IOException("truncated stream: " + off + " of " + expected + " bytes");
            return out;
        } catch (DataFormatException e) {
            throw new IOException(e);
        } finally {
            inf.end();
        }
    }
}
```

```
    private static Result baseline(DatasetInfo info, String codec, byte[] raw, boolean shuffle, int level,
                                   int warmup, int iterations) throws Exception {
        byte[][] comp = new byte[1][];
        Timing c = Timing.measure(warmup, iterations, () -> comp[0] = deflate(shuffle ? shuffle4(raw) : raw, level));
        byte[][] dec = new byte[1][];
        Timing d = Timing.measure(warmup, iterations, () -> {
            byte[] inflated = inflate(comp[0], raw.length);
            dec[0] = shuffle ? unshuffle4(inflated) : inflated;
        });
        if (!Arrays.equals(raw, dec[0])) {
            throw new IllegalStateException(codec + " did not reproduce the original bytes");
        }
        Result r = new Result(info.name(), codec, "LOSSLESS", 32, level, raw.length, info.fileBytes(), comp[0].length,
                c, d, Quality.lossless(raw.length / 4), sha256(comp[0]));
        logResult(r);
        return r;
    }

    private static List<float[]> tracesFromVolume(SegyIO.SegyDataset ds, Sdc3DFileReader.Sdc3DVolume vol) {
        float[][] traces = new float[ds.traceCount()][];
        for (int ii = 0; ii < ds.traceGrid.inlineCount(); ii++) {
            for (int jj = 0; jj < ds.traceGrid.xlineCount(); jj++) {
                int idx = ds.traceGrid.traceIndexAt(ii, jj);
                if (idx >= 0) traces[idx] = vol.data[ii][jj];
            }
        }
        for (int i = 0; i < traces.length; i++) {
            if (traces[i] == null) throw new IllegalStateException("trace " + i + " missing from the 3D volume");
        }
        return Arrays.asList(traces);
    }

    private static NeuralModel loadModel(String spec) throws IOException {
        if (spec.equalsIgnoreCase("none")) return null;
        Path p = spec.equalsIgnoreCase("auto") ? Path.of("sdc-ai/models/sdc-ae-v1.sdcnn") : Path.of(spec);
        if (!Files.exists(p)) {
            if (spec.equalsIgnoreCase("auto")) {
                log("No neural model at %s: neural codecs skipped (use --model <file.sdcnn>)", p);
                return null;
            }
            throw new IllegalArgumentException("model not found: " + p);
        }
        NeuralModel m = NeuralModel.load(p);
        log("Neural model %s sha256=%s", p, m.sha256Hex());
        return m;
    }

    /** Volume as [inline][xline][time]; absent traces stay zero. */
    static float[][][] volumeOf(SegyIO.SegyDataset ds) {
        int ni = ds.traceGrid.inlineCount(), nj = ds.traceGrid.xlineCount();
        float[][][] vol = new float[ni][nj][];
        for (int i = 0; i < ni; i++) {
            for (int j = 0; j < nj; j++) {
                int idx = ds.traceGrid.traceIndexAt(i, j);
                vol[i][j] = idx >= 0 ? ds.traces.get(idx).samples().clone() : new float[ds.samplesPerTrace];
            }
        }
        return vol;
    }

    static List<float[]> tracesFromArray(SegyIO.SegyDataset ds, float[][][] vol) {
        float[][] traces = new float[ds.traceCount()][];
        for (int ii = 0; ii < ds.traceGrid.inlineCount(); ii++) {
            for (int jj = 0; jj < ds.traceGrid.xlineCount(); jj++) {
                int idx = ds.traceGrid.traceIndexAt(ii, jj);
                if (idx >= 0) traces[idx] = vol[ii][jj];
            }
        }
        return Arrays.asList(traces);
    }

    /**
     * Rate–distortion sweep (Deflate level 9 everywhere). sdc-3d points are real files written and
     * read back. For the neural codec the prediction is computed once; sizes come from real
     * encodes, and the reconstruction of the first bit depth is checked bit-for-bit against a
     * real decode before the cheaper {@link NeuralHybridCodec#reconstruct} is used for the rest.
     */
    private static List<RdPoint> rdSweep(DatasetInfo info, SegyIO.SegyDataset ds, Path work, int[] block,
                                         NeuralModel model, int[] bitsList) throws Exception {
        List<RdPoint> pts = new ArrayList<>();
        long raw = (long) ds.traceCount() * ds.samplesPerTrace * 4L;
        List<float[]> original = ds.traces.stream().map(TraceBlock::samples).collect(Collectors.toList());
        log("Rate-distortion sweep on %s, bits=%s", info.name(), Arrays.toString(bitsList));

        for (int bits : bitsList) {
            CompressionProfile profile = new CompressionProfile(bits, 9, 100.0);
            Path sdc = work.resolve(info.name() + "-rd-3d-" + bits + ".sdc");
            Sdc3DFileWriter.write3D(sdc, ds, profile, block[0], block[1], block[2]);
            Sdc3DFileReader.Sdc3DVolume v = Sdc3DFileReader.read3D(sdc, profile);
            long size = Files.size(sdc);
            pts.add(new RdPoint(info.name(), "sdc-3d", bits, raw, size, 0, size, Quality.compare(original, tracesFromVolume(ds, v))));
        }

        float[][][] vol = volumeOf(ds);
        List<NeuralHybridCodec.Prediction> preds = new ArrayList<>();
        preds.add(NeuralHybridCodec.predict(vol, null));
        if (model != null) {
            long t0 = System.nanoTime();
            preds.add(NeuralHybridCodec.predict(vol, model));
            log("  neural prediction computed in %.1f s", (System.nanoTime() - t0) / 1e9);
        }
        for (NeuralHybridCodec.Prediction p : preds) {
            String codec = p.predictor() == NeuralHybridCodec.Predictor.NEURAL ? "neural-hybrid" : "uniform-quant";
            boolean checked = false;
            for (int bits : bitsList) {
                NeuralHybridCodec.Settings st = new NeuralHybridCodec.Settings(p.predictor(), bits, 9);
                NeuralHybridCodec.Encoded e = NeuralHybridCodec.encode(vol, p, st);
                float[][][] rec = NeuralHybridCodec.reconstruct(vol, p, bits);
                if (!checked) {
                    float[][][] dec = NeuralHybridCodec.decode(e.payload(), model);
                    if (!Arrays.deepEquals(dec, rec)) {
                        throw new IllegalStateException(codec + ": reconstruct() differs from decode()");
                    }
                    checked = true;
                }
                pts.add(new RdPoint(info.name(), codec, bits, raw, e.payload().length, e.latentBytes(), e.residualBytes(),
                        Quality.compare(original, tracesFromArray(ds, rec))));
            }
            if (p.predictor() == NeuralHybridCodec.Predictor.NEURAL) {
                NeuralHybridCodec.Encoded e = NeuralHybridCodec.encode(vol, p,
                        new NeuralHybridCodec.Settings(p.predictor(), 0, 9));
                float[][][] dec = NeuralHybridCodec.decode(e.payload(), model);
                pts.add(new RdPoint(info.name(), "neural-only", 0, raw, e.payload().length, e.latentBytes(), 0,
                        Quality.compare(original, tracesFromArray(ds, dec))));
            }
        }
        for (RdPoint pt : pts) {
            log("  rd %-14s bits=%2d  %6.3f bits/sample  SNR=%6.2f dB", pt.codec(), pt.bits(), pt.bitsPerSample(), pt.quality().snrDb());
        }
        return pts;
    }

    private static byte[] rawSampleBytes(SegyIO.SegyDataset ds) {
        ByteBuffer bb = ByteBuffer.allocate(ds.traceCount() * ds.samplesPerTrace * 4); // big-endian
        for (TraceBlock tb : ds.traces) {
            for (float v : tb.samples()) bb.putFloat(v);
        }
        return bb.array();
    }

    /** Byte-shuffle (Blosc/HDF5 style): groups byte k of every float32 together. */
    static byte[] shuffle4(byte[] in) {
        int n = in.length / 4;
        byte[] out = new byte[in.length];
        for (int i = 0; i < n; i++) {
            for (int k = 0; k < 4; k++) out[k * n + i] = in[i * 4 + k];
        }
        return out;
    }

    static byte[] unshuffle4(byte[] in) {
        int n = in.length / 4;
        byte[] out = new byte[in.length];
        for (int i = 0; i < n; i++) {
            for (int k = 0; k < 4; k++) out[i * 4 + k] = in[k * n + i];
        }
        return out;
    }

    private static byte[] deflate(byte[] input, int level) {
        Deflater d = new Deflater(level);
        try {
            d.setInput(input);
            d.finish();
            ByteArrayOutputStream bos = new ByteArrayOutputStream(input.length / 2);
            byte[] buf = new byte[1 << 16];
            while (!d.finished()) {
                int n = d.deflate(buf);
                bos.write(buf, 0, n);
            }
            return bos.toByteArray();
        } finally {
            d.end();
        }
    }

    private static byte[] inflate(byte[] input, int expected) throws Exception {
        Inflater inf = new Inflater();
        try {
            inf.setInput(input);
            byte[] out = new byte[expected];
            int off = 0;
            while (!inf.finished() && off < expected) {
                off += inf.inflate(out, off, expected - off);
            }
            return out;
        } finally {
            inf.end();
        }
    }

    static String sha256(Path file) throws Exception {
        MessageDigest md = MessageDigest.getInstance("SHA-256");
        try (InputStream in = Files.newInputStream(file)) {
            byte[] buf = new byte[1 << 20];
            int n;
            while ((n = in.read(buf)) > 0) md.update(buf, 0, n);
        }
        return HexFormat.of().formatHex(md.digest());
    }

    private static String sha256(byte[] data) throws Exception {
        return HexFormat.of().formatHex(MessageDigest.getInstance("SHA-256").digest(data));
    }

    private static void deleteRecursively(Path dir) throws IOException {
        if (!Files.exists(dir)) return;
        try (var walk = Files.walk(dir)) {
            for (Path p : walk.sorted((a, b) -> b.getNameCount() - a.getNameCount()).toList()) {
                Files.deleteIfExists(p);
            }
        }
    }

    private static Map<String, List<String>> parseArgs(String[] args) {
        Map<String, List<String>> m = new LinkedHashMap<>();
        for (int i = 0; i < args.length; i++) {
            String a = args[i];
            if (!a.startsWith("--")) throw new IllegalArgumentException("unexpected argument: " + a);
            String key = a.substring(2);
            String value = "true";
            int eq = key.indexOf('=');
            if (eq >= 0) {
                value = key.substring(eq + 1);
                key = key.substring(0, eq);
            } else if (!key.equals("help") && i + 1 < args.length && !args[i + 1].startsWith("--")) {
                value = args[++i];
            }
            m.computeIfAbsent(key, k -> new ArrayList<>()).add(value);
        }
        return m;
    }

    private static String first(Map<String, List<String>> m, String key, String def) {
        List<String> v = m.get(key);
        return (v == null || v.isEmpty()) ? def : v.get(v.size() - 1);
    }
```

```
 */

    private CleanSignalCheck() {}

    public static void main(String[] args) throws Exception {
        SyntheticSegyGenerator.Spec noisy = SyntheticSegyGenerator.preset(args.length > 0 ? args[0] : "medium");
        NeuralModel model = NeuralModel.load(Path.of(args.length > 1 ? args[1] : "sdc-ai/models/sdc-ae-v1.sdcnn"));
        SyntheticSegyGenerator.Spec clean = new SyntheticSegyGenerator.Spec(noisy.name() + "-clean", noisy.inlines(),
                noisy.xlines(), noisy.samples(), noisy.sampleIntervalUs(), noisy.seed(), 0.0, null);

        Path dir = Files.createTempDirectory("sdc-clean-");
        Path n = dir.resolve("noisy.sgy"), c = dir.resolve("clean.sgy");
        SyntheticSegyGenerator.write(noisy, n);
        SyntheticSegyGenerator.write(clean, c);
        float[][][] x = BenchmarkRunner.volumeOf(SegyIO.read(n));
        float[][][] s = BenchmarkRunner.volumeOf(SegyIO.read(c));
        float[][][] r = NeuralHybridCodec.reconstruct(x, NeuralHybridCodec.predict(x, model), 0);

        System.out.printf("noisy input   vs clean signal: %6.2f dB%n", snr(s, x));
        System.out.printf("neural-only   vs noisy input:  %6.2f dB%n", snr(x, r));
        System.out.printf("neural-only   vs clean signal: %6.2f dB%n", snr(s, r));
        Files.delete(n);
        Files.delete(c);
        Files.delete(dir);
    }

    static double snr(float[][][] ref, float[][][] x) {
        double sig = 0, err = 0;
        for (int i = 0; i < ref.length; i++)
            for (int j = 0; j < ref[0].length; j++)
                for (int k = 0; k < ref[0][0].length; k++) {
                    double a = ref[i][j][k], d = a - x[i][j][k];
                    sig += a * a;
                    err += d * d;
                }
        return 10 * Math.log10(sig / err);
    }
}
```

### sdc-bench/src/main/java/com/sdc/bench/Quality.java
```
package com.sdc.bench;

import java.util.List;

/**
 * Fidelity metrics computed on the original (non-normalized) amplitudes.
 *
 *  - SNR  (dB) = 10·log10( Σx² / Σ(x−x̂)² )        — the usual metric in seismic compression
 *  - PSNR (dB) = 20·log10( (max−min) / RMSE )      — peak = dynamic range of the volume
 *  - NRMSE (%) = RMSE / RMS(x) · 100
 *  - maxAbsError = max |x − x̂|
 *
 * Zero error (lossless) gives SNR/PSNR = +∞ and NRMSE = 0.
 */
public record Quality(double snrDb, double psnrDb, double nrmsePercent, double maxAbsError,
                      long samples, long nonFiniteSamples) {

    public boolean lossless() {
        return nonFiniteSamples == 0 && maxAbsError == 0.0;
    }

    public static Quality lossless(long samples) {
        return new Quality(Double.POSITIVE_INFINITY, Double.POSITIVE_INFINITY, 0.0, 0.0, samples, 0);
    }

    public static Quality compare(List<float[]> original, List<float[]> reconstructed) {
        if (original.size() != reconstructed.size()) {
            throw new IllegalArgumentException("trace count mismatch: " + original.size() + " vs " + reconstructed.size());
        }
        double sumSq = 0.0;
        double sumErrSq = 0.0;
        double maxAbs = 0.0;
        double min = Double.POSITIVE_INFINITY;
        double max = Double.NEGATIVE_INFINITY;
        long n = 0;
        long nonFinite = 0;

        for (int t = 0; t < original.size(); t++) {
            float[] a = original.get(t);
            float[] b = reconstructed.get(t);
            if (a.length != b.length) {
                throw new IllegalArgumentException("sample count mismatch on trace " + t);
            }
            for (int i = 0; i < a.length; i++) {
                double x = a[i];
                double y = b[i];
                if (x < min) min = x;
                if (x > max) max = x;
                sumSq += x * x;
                n++;
                if (!Double.isFinite(y)) {
                    nonFinite++;
                    continue;
                }
                double d = x - y;
                sumErrSq += d * d;
                double ad = Math.abs(d);
                if (ad > maxAbs) maxAbs = ad;
            }
        }

        if (nonFinite > 0) {
            return new Quality(Double.NaN, Double.NaN, Double.NaN, Double.NaN, n, nonFinite);
        }
        if (sumErrSq == 0.0) {
            return lossless(n);
        }
        double rmse = Math.sqrt(sumErrSq / n);
        double rms = Math.sqrt(sumSq / n);
        double snr = 10.0 * Math.log10(sumSq / sumErrSq);
        double psnr = 20.0 * Math.log10((max - min) / rmse);
        double nrmse = rms > 0 ? rmse / rms * 100.0 : Double.POSITIVE_INFINITY;
        return new Quality(snr, psnr, nrmse, maxAbs, n, 0);
    }
}
```

### sdc-bench/src/main/java/com/sdc/bench/SyntheticSegyGenerator.java
```
package com.sdc.bench;

import java.io.BufferedOutputStream;
import java.io.DataOutputStream;
import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.Arrays;
import java.util.Random;

/**
 * Generates a synthetic, fully deterministic 3D SEG-Y volume.
 *
 * Geological model:
 *  - N reflectors dipping in inline/xline with a gentle sinusoidal fold
 *  - one planar normal fault (constant vertical throw)
 *  - fixed-frequency Ricker wavelet
 *  - exponential attenuation with time
 *  - additive Gaussian noise
 *
 * Reproducibility:
 *  - java.util.Random has a specified algorithm (48-bit LCG)
 *  - nextGaussian uses StrictMath since Java 17
 *  - all floating-point math uses StrictMath (bit-for-bit identical on any JVM/CPU)
 *  So the same Spec always produces exactly the same bytes, verifiable via SHA-256.
 *
 * SEG-Y layout (what SegyIO reads):
 *  - 3200-byte textual header (ASCII)
 *  - 400-byte binary header (dt, ns, format 5 = IEEE float32)
 *  - per trace: 240-byte header (inline at 189-192, xline at 193-196) + ns big-endian floats
 */
public final class SyntheticSegyGenerator {

    private SyntheticSegyGenerator() {}

    public static final int FIRST_INLINE = 1000;
    public static final int FIRST_XLINE = 2000;

    /**
     * @param expectedSha256 expected hash of the generated file (null = do not verify)
     */
    public record Spec(String name,
                       int inlines,
                       int xlines,
                       int samples,
                       int sampleIntervalUs,
                       long seed,
                       double noiseLevel,
                       String expectedSha256) {

        public int traceCount() {
            return inlines * xlines;
        }

        public long fileBytes() {
            return 3600L + (long) traceCount() * (240L + 4L * samples);
        }
    }

    public static final Spec TINY = new Spec("synthetic-tiny", 8, 8, 128, 4000, 20261012L, 0.02,
            "d18e727556b925d6edecfbd258b9b4b1990e427310a3a9e5959196e50717261c");

    public static final Spec SMALL = new Spec("synthetic-small", 32, 32, 500, 4000, 20261012L, 0.02,
            "0e6036582f8db53226e33c9b4b2e87a72204f6c3b974415d304fe2e8dc7401e7");

    public static final Spec MEDIUM = new Spec("synthetic-medium", 128, 128, 1000, 4000, 20261012L, 0.02,
            "0b6389d128a2a1a08ebd959fbb87ac583ed60beaf473fd3c3d122fa6fd139e26");

    public static Spec preset(String name) {
        return switch (name.trim().toLowerCase()) {
            case "tiny" -> TINY;
            case "small" -> SMALL;
            case "medium" -> MEDIUM;
            default -> throw new IllegalArgumentException("unknown preset: " + name + " (use tiny|small|medium)");
        };
    }

    private record Reflector(double t0, double rc, double dipI, double dipJ,
                             double foldAmp, double foldLenI, double foldLenJ, double foldPhase) {}

    public static void write(Spec spec, Path out) throws IOException {
        Random structure = new Random(spec.seed());
        Random noise = new Random(spec.seed() ^ 0x5DEECE66DL);

        int ns = spec.samples();
        double dtSec = spec.sampleIntervalUs() / 1_000_000.0;

        // ---- reflectors ----
        int reflectorCount = Math.max(8, ns / 25);
        Reflector[] reflectors = new Reflector[reflectorCount];
        double spacing = (double) ns / reflectorCount;
        for (int r = 0; r < reflectorCount; r++) {
            double t0 = (r + 0.5) * spacing + (structure.nextDouble() - 0.5) * spacing * 0.6;
            double rc = (structure.nextDouble() * 2.0 - 1.0) * 0.3;
            double dipI = (structure.nextDouble() * 2.0 - 1.0) * 0.15;   // samples per inline
            double dipJ = (structure.nextDouble() * 2.0 - 1.0) * 0.10;   // samples per xline
            double foldAmp = structure.nextDouble() * 4.0;               // samples
            double foldLenI = 20.0 + structure.nextDouble() * 60.0;
            double foldLenJ = 20.0 + structure.nextDouble() * 60.0;
            double foldPhase = structure.nextDouble() * 2.0 * StrictMath.PI;
            reflectors[r] = new Reflector(t0, rc, dipI, dipJ, foldAmp, foldLenI, foldLenJ, foldPhase);
        }

        // ---- Ricker wavelet (25 Hz), support half-width in samples ----
        double f = 25.0;
        double pf2 = StrictMath.PI * StrictMath.PI * f * f;
        int half = (int) StrictMath.ceil(0.08 / dtSec); // ±80 ms

        // ---- normal fault: plane i = a + b*j, block with i > plane is downthrown ----
        double faultA = spec.inlines() * 0.55;
        double faultB = 0.10;
        double faultThrow = 6.5; // samples

        double amplitudeScale = 1000.0;
        double noiseSigma = spec.noiseLevel() * amplitudeScale * 0.3;
        double attenuationTau = ns * 0.6; // samples

        Files.createDirectories(out.toAbsolutePath().getParent());
        try (DataOutputStream os = new DataOutputStream(
                new BufferedOutputStream(Files.newOutputStream(out), 1 << 20))) {

            os.write(textualHeader(spec));
            os.write(binaryHeader(spec));

            double[] trace = new double[ns];
            byte[] th = new byte[240];
            int seq = 0;

            for (int i = 0; i < spec.inlines(); i++) {
                for (int j = 0; j < spec.xlines(); j++) {
                    Arrays.fill(trace, 0.0);
                    double shift = (i > faultA + faultB * j) ? faultThrow : 0.0;

                    for (Reflector r : reflectors) {
                        double tr = r.t0 + r.dipI * i + r.dipJ * j + shift
                                + r.foldAmp * StrictMath.sin(2.0 * StrictMath.PI * i / r.foldLenI + r.foldPhase)
                                            * StrictMath.cos(2.0 * StrictMath.PI * j / r.foldLenJ);
                        int center = (int) StrictMath.floor(tr);
                        int k0 = Math.max(0, center - half);
                        int k1 = Math.min(ns - 1, center + half);
                        for (int k = k0; k <= k1; k++) {
                            double tau = (k - tr) * dtSec;
                            double a = pf2 * tau * tau;
                            trace[k] += r.rc * (1.0 - 2.0 * a) * StrictMath.exp(-a);
                        }
                    }

                    seq++;
                    fillTraceHeader(th, seq, FIRST_INLINE + i, FIRST_XLINE + j, spec);
                    os.write(th);
                    for (int k = 0; k < ns; k++) {
                        double gain = amplitudeScale * StrictMath.exp(-k / attenuationTau);
                        double v = trace[k] * gain + noise.nextGaussian() * noiseSigma;
                        os.writeInt(Float.floatToIntBits((float) v));
                    }
                }
            }
        }
    }

    private static byte[] textualHeader(Spec spec) {
        String[] lines = {
                "SDC BENCHMARK - SYNTHETIC 3D SEISMIC VOLUME (DETERMINISTIC)",
                "DATASET " + spec.name(),
                "INLINES " + spec.inlines() + " FIRST " + FIRST_INLINE + "  XLINES " + spec.xlines() + " FIRST " + FIRST_XLINE,
                "SAMPLES " + spec.samples() + "  DT(US) " + spec.sampleIntervalUs() + "  FORMAT 5 IEEE FLOAT32",
                "SEED " + spec.seed() + "  NOISE " + spec.noiseLevel(),
                "MODEL: DIPPING FOLDED REFLECTORS + NORMAL FAULT + RICKER 25HZ + GAUSSIAN NOISE",
                "INLINE BYTES 189-192  XLINE BYTES 193-196",
                "GENERATOR com.sdc.bench.SyntheticSegyGenerator",
        };
        byte[] out = new byte[3200];
        Arrays.fill(out, (byte) ' ');
        for (int l = 0; l < 40; l++) {
            String body = l < lines.length ? lines[l] : "";
            String line = String.format("C%02d %-76s", l + 1, body);
            byte[] b = line.substring(0, 80).getBytes(StandardCharsets.US_ASCII);
            System.arraycopy(b, 0, out, l * 80, 80);
        }
        return out;
    }

    private static byte[] binaryHeader(Spec spec) {
        byte[] b = new byte[400];
        putShort(b, 12, spec.xlines());          // traces per ensemble
        putShort(b, 16, spec.sampleIntervalUs()); // sample interval (us)
        putShort(b, 20, spec.samples());          // samples per trace
        putShort(b, 24, 5);                       // format 5 = IEEE float32
        putShort(b, 26, 1);                       // ensemble fold
        putShort(b, 28, 4);                       // sorting: horizontally stacked
        putShort(b, 54, 1);                       // units: meters
        putShort(b, 300, 0x0100);                 // SEG-Y rev 1
        putShort(b, 302, 1);                      // fixed-length traces
        return b;
    }

    private static void fillTraceHeader(byte[] th, int seq, int inline, int xline, Spec spec) {
        Arrays.fill(th, (byte) 0);
        putInt(th, 0, seq);                       // sequence within line
        putInt(th, 4, seq);                       // sequence within reel
        putInt(th, 8, inline);                    // field record
        putInt(th, 12, xline);                    // trace within field record
        putInt(th, 20, seq);                      // CDP
        putShort(th, 28, 1);                      // trace id code: seismic
        putShort(th, 70, 1);                      // coordinate scalar
        putInt(th, 72, xline * 25);               // source X
        putInt(th, 76, inline * 25);              // source Y
        putShort(th, 114, spec.samples());        // ns
        putShort(th, 116, spec.sampleIntervalUs());
        putInt(th, 180, xline * 25);              // CDP X
        putInt(th, 184, inline * 25);             // CDP Y
        putInt(th, 188, inline);                  // inline
        putInt(th, 192, xline);                   // crossline
    }

    private static void putShort(byte[] b, int off, int v) {
        b[off] = (byte) (v >>> 8);
        b[off + 1] = (byte) v;
    }

    private static void putInt(byte[] b, int off, int v) {
        b[off] = (byte) (v >>> 24);
        b[off + 1] = (byte) (v >>> 16);
        b[off + 2] = (byte) (v >>> 8);
        b[off + 3] = (byte) v;
    }
}
```

```
package com.sdc.bench;

import java.util.Arrays;

/**
 * Timing statistics for N measured iterations (warmups discarded).
 */
public record Timing(long[] nanos) {

    @FunctionalInterface
    public interface Task {
        void run() throws Exception;
    }

    /**
     * Runs {@code warmup} discarded iterations and {@code iterations} measured ones.
     * A System.gc() before each iteration reduces interference from pending collections.
     */
    public static Timing measure(int warmup, int iterations, Task task) throws Exception {
        for (int w = 0; w < warmup; w++) {
            task.run();
        }
        long[] ns = new long[iterations];
        for (int it = 0; it < iterations; it++) {
            System.gc();
            long t0 = System.nanoTime();
            task.run();
            ns[it] = System.nanoTime() - t0;
        }
        return new Timing(ns);
    }

    public double medianMs() {
        long[] s = nanos.clone();
        Arrays.sort(s);
        int n = s.length;
        double med = (n % 2 == 1) ? s[n / 2] : (s[n / 2 - 1] + s[n / 2]) / 2.0;
        return med / 1e6;
    }

    public double minMs() {
        return Arrays.stream(nanos).min().orElse(0) / 1e6;
    }

    public double maxMs() {
        return Arrays.stream(nanos).max().orElse(0) / 1e6;
    }

    public double meanMs() {
        return Arrays.stream(nanos).average().orElse(0) / 1e6;
    }

    public double stdevMs() {
        if (nanos.length < 2) return 0.0;
        double mean = Arrays.stream(nanos).average().orElse(0);
        double acc = 0.0;
        for (long v : nanos) acc += (v - mean) * (v - mean);
        return Math.sqrt(acc / (nanos.length - 1)) / 1e6;
    }

    /** Throughput in MiB/s over {@code bytes} (raw trace data), using the median. */
    public double throughputMiBs(long bytes) {
        double sec = medianMs() / 1e3;
        return sec > 0 ? (bytes / (1024.0 * 1024.0)) / sec : Double.POSITIVE_INFINITY;
    }
}
```

### sdc-core/src/main/java/com/sdc/core/ClosedLoopQuantizer.java
```
package com.sdc.core;

import java.io.ByteArrayOutputStream;

/**
 * Closed-loop (DPCM) quantization shared by the 2D and 3D codecs, plus the self-describing
 * payload format used since the "closed-loop" codec revision.
 *
 * <p>Why closed loop: the predictor must use the <em>reconstructed</em> samples on both sides.
 * The previous (open-loop) codecs predicted from the original samples while encoding and from
 * the reconstructed samples while decoding, so quantization error accumulated along the
 * prediction chain. Here the encoder runs the decoder's reconstruction internally, so the
 * error of every sample is bounded by half a quantization step, up to float rounding (plus the
 * rare overload case, which the loop corrects on the following samples).</p>
 *
 * <p>Payload layout (all codecs): {@code [FORMAT_CLOSED_LOOP][bits][deflate(stream)]} where the
 * stream holds one signed byte per sample when {@code bits <= 8}; otherwise each sample is a
 * 16-bit value stored as two byte planes (all high bytes, then all low bytes), which Deflate
 * compresses much better than interleaved shorts because the high bytes are mostly 0x00/0xFF. Legacy payloads are raw zlib streams, whose first byte is always {@code 0x78}
 * for {@link java.util.zip.Deflater}, so the two layouts cannot be confused.</p>
 */
public final class ClosedLoopQuantizer {

    /** First payload byte of the closed-loop format. */
    public static final byte FORMAT_CLOSED_LOOP = 0x01;

    private ClosedLoopQuantizer() {}

    /** Largest quantization index for the given bit depth (e.g. 16 bits -> 32767). */
    public static int maxQ(int bits) {
        if (bits < 2 || bits > 16) {
            throw new IllegalArgumentException("bits must be between 2 and 16, got " + bits);
        }
        return (1 << (bits - 1)) - 1;
    }

    /** Quantizes a residual expressed in normalized units ([-1,1] is the full step range). */
    public static int quantize(float residual, int maxQ) {
        int q = Math.round(residual * maxQ);
        if (q > maxQ) q = maxQ;
        if (q < -maxQ) q = -maxQ;
        return q;
    }

    /** Reconstructs a sample from prediction + dequantized residual, clamped to [-1,1]. */
    public static float reconstruct(float prediction, int q, float invMaxQ) {
        float r = prediction + q * invMaxQ;
        if (r > 1f) r = 1f;
        if (r < -1f) r = -1f;
        return r;
    }

    /** True if the payload uses the closed-loop format. */
    public static boolean isClosedLoop(byte[] payload) {
        return payload != null && payload.length >= 2 && payload[0] == FORMAT_CLOSED_LOOP;
    }

    /** Bit depth stored in a closed-loop payload. */
    public static int storedBits(byte[] payload) {
        return payload[1] & 0xFF;
    }

    /** Serializes quantization indices into a self-describing, deflated payload. */
    public static byte[] pack(int[] q, int bits, int deflaterLevel) {
        byte[] stream;
        if (bits <= 8) {
            stream = new byte[q.length];
            for (int i = 0; i < q.length; i++) stream[i] = (byte) q[i];
        } else {
            int n = q.length;
            stream = new byte[n * 2];
            for (int i = 0; i < n; i++) {
                stream[i] = (byte) (q[i] >>> 8);   // high-byte plane
                stream[n + i] = (byte) q[i];       // low-byte plane
            }
        }
        byte[] deflated = TraceBlockCodec.deflate(stream, deflaterLevel);
        ByteArrayOutputStream out = new ByteArrayOutputStream(deflated.length + 2);
        out.write(FORMAT_CLOSED_LOOP);
        out.write(bits);
        out.write(deflated, 0, deflated.length);
        return out.toByteArray();
    }

    /** Inverse of {@link #pack}: returns the quantization indices. */
    public static int[] unpack(byte[] payload, int expectedSamples) {
        if (!isClosedLoop(payload)) {
            throw new IllegalArgumentException("not a closed-loop payload");
        }
        int bits = storedBits(payload);
        maxQ(bits); // validates
        byte[] deflated = new byte[payload.length - 2];
        System.arraycopy(payload, 2, deflated, 0, deflated.length);
        byte[] stream = TraceBlockCodec.inflate(deflated);
        int[] q = new int[expectedSamples];
        if (bits <= 8) {
            if (stream.length != expectedSamples) {
                throw new IllegalStateException("expected " + expectedSamples + " samples but got " + stream.length);
            }
            for (int i = 0; i < q.length; i++) q[i] = stream[i];
        } else {
            if (stream.length != expectedSamples * 2) {
                throw new IllegalStateException("expected " + expectedSamples + " samples but got " + stream.length / 2);
            }
            int n = expectedSamples;
            for (int i = 0; i < n; i++) {
                int hi = stream[i];            // sign-extended
                int lo = stream[n + i] & 0xFF;
                q[i] = (short) ((hi << 8) | lo);
            }
        }
        return q;
    }
}
```

```
package com.sdc.core;

/**
 * Define o "perfil" de compressão:
 *  - effectiveBits: quantos bits efetivos manter na quantização (1..16)
 *  - deflaterLevel: nível de compressão do Deflater (0..9)
 *
 * Observação importante:
 *  - Mais bits -> mais fidelidade, menos compressão.
 *  - Menos bits -> mais perda, mais redundância, melhor compressão.
 */
public final class CompressionProfile {

    private final int effectiveBits;
    private final int deflaterLevel;
    private final double fidelityPercentRequested;

    public CompressionProfile(int effectiveBits, int deflaterLevel, double fidelityPercentRequested) {
        if (effectiveBits < 1 || effectiveBits > 16) {
            throw new IllegalArgumentException("effectiveBits must be between 1 and 16");
        }
        if (deflaterLevel < 0 || deflaterLevel > 9) {
            throw new IllegalArgumentException("deflaterLevel must be between 0 and 9");
        }
        this.effectiveBits = effectiveBits;
        this.deflaterLevel = deflaterLevel;
        this.fidelityPercentRequested = fidelityPercentRequested;
    }

    public int effectiveBits() {
        return effectiveBits;
    }

    public int deflaterLevel() {
        return deflaterLevel;
    }

    public double fidelityPercentRequested() {
        return fidelityPercentRequested;
    }

    // --------- FÁBRICAS ---------

    /** Perfil default: alta qualidade. */
    public static CompressionProfile defaultHighQuality() {
        return new CompressionProfile(16, 9, 100.0);
    }

    /** Perfil "balanceado". */
    public static CompressionProfile balanced() {
        return new CompressionProfile(12, 7, 90.0);
    }

    /** Perfil "alta compressão". */
    public static CompressionProfile highCompression() {
        return new CompressionProfile(8, 6, 75.0);
    }

    /**
     * Cria um profile a partir de um "percentual de fidelidade" de 0 a 100.
     * Ex.: 100% -> ~16 bits, 50% -> ~8-10 bits, 10% -> bem agressivo.
     *
     * Não é uma relação física perfeita, mas é um "knob" intuitivo:
     * mais fidelidade -> mais bits.
     */
    public static CompressionProfile fromFidelityPercent(double fidelityPercent) {
        double f = Double.isNaN(fidelityPercent) ? 100.0 : fidelityPercent;
        if (f < 0.0) f = 0.0;
        if (f > 100.0) f = 100.0;

        // Mapear 0..100% para 4..16 bits (mínimo 4 bits pra não virar ruído total)
        int minBits = 4;
        int maxBits = 16;
        int bits = (int) Math.round(minBits + (maxBits - minBits) * (f / 100.0));

        // Nível do deflater: para fidelidade menor, podemos aceitar nível menor (menos CPU).
        int level;
        if (f > 95.0) {
            level = 9;
        } else if (f > 80.0) {
            level = 7;
        } else if (f > 50.0) {
            level = 6;
        } else {
            level = 5;
        }

        return new CompressionProfile(bits, level, f);
    }

    /** A partir de um nome de profile textual. */
    public static CompressionProfile fromProfileName(String profileName) {
        if (profileName == null) return defaultHighQuality();
        String p = profileName.trim().toUpperCase();
        return switch (p) {
            case "HIGH_COMPRESSION" -> highCompression();
            case "BALANCED" -> balanced();
            case "HIGH_QUALITY", "HQ" -> defaultHighQuality();
            default -> defaultHighQuality();
        };
    }
}
```

```
package com.sdc.core;

public final class LinearQuantizer {

    private LinearQuantizer() {}

    // compat: usa profile default (16 bits)
    private static final CompressionProfile DEFAULT_PROFILE =
            CompressionProfile.defaultHighQuality();

    /** Versão antiga (compat) – assume profile default (16 bits) */
    public static short[] encode(float[] normalized) {
        return encode(normalized, DEFAULT_PROFILE);
    }

    /**
     * Quantização linear em [-1,1], respeitando o número de bits efetivos.
     * effectiveBits deve estar entre 2 e 16.
     */
    public static short[] encode(float[] normalized, CompressionProfile profile) {
        int bits = profile.effectiveBits();
        if (bits < 2 || bits > 16) {
            throw new IllegalArgumentException("effectiveBits must be between 2 and 16, got " + bits);
        }

        int maxQ = (1 << (bits - 1)) - 1; // exemplo: 16 bits -> 32767, 15 bits -> 16383
        short[] out = new short[normalized.length];

        for (int i = 0; i < normalized.length; i++) {
            float v = normalized[i];

            // clamp em [-1,1]
            if (v > 1f) v = 1f;
            if (v < -1f) v = -1f;

            int q = Math.round(v * maxQ);

            if (q > maxQ) q = maxQ;
            if (q < -maxQ) q = -maxQ;

            out[i] = (short) q;
        }
        return out;
    }

    /** Versão antiga (compat) – assume 16 bits */
    public static float[] decode(short[] quantized) {
        return decode(quantized, 16);
    }

    /**
     * Dequantização genérica: short -> float em [-1,1],
     * usando o mesmo número de bits da quantização.
     */
    public static float[] decode(short[] quantized, int bits) {
        if (bits < 2 || bits > 16) {
            throw new IllegalArgumentException("bits must be between 2 and 16, got " + bits);
        }
        int maxQ = (1 << (bits - 1)) - 1;
        float inv = 1.0f / (float) maxQ;

        float[] out = new float[quantized.length];
        for (int i = 0; i < quantized.length; i++) {
            out[i] = quantized[i] * inv;
        }
        return out;
    }

    // ---- MSE / PSNR permanecem iguais ----

    public static double mse(float[] a, float[] b) {
        if (a.length != b.length) {
            throw new IllegalArgumentException("arrays must have same length");
        }
        double acc = 0.0;
        for (int i = 0; i < a.length; i++) {
            double d = a[i] - b[i];
            acc += d * d;
        }
        return acc / a.length;
    }

    public static double psnr(float[] original, float[] reconstructed) {
        double mse = mse(original, reconstructed);
        if (mse == 0.0) return Double.POSITIVE_INFINITY;
        double max = 1.0; // assume [-1,1]
        return 10.0 * Math.log10((max * max) / mse);
    }
}
```

### sdc-core/src/main/java/com/sdc/core/Preprocessing.java
```
package com.sdc.core;

import java.util.Arrays;

/**
 * Rotinas básicas de pré-processamento de traços sísmicos.
 *
 * v0:
 *  - normalização para [-1, 1]
 *  - delta encoding simples (diferença entre amostras consecutivas)
 */
public final class Preprocessing {

    private Preprocessing() {}

    /** Calcula min e max de um vetor. */
    public static float[] minMax(float[] samples) {
        if (samples == null || samples.length == 0) {
            throw new IllegalArgumentException("samples must not be null/empty");
        }
        float min = samples[0];
        float max = samples[0];
        for (float v : samples) {
            if (v < min) min = v;
            if (v > max) max = v;
        }
        return new float[]{min, max};
    }

    /**
     * Normaliza um traço para o intervalo [-1, 1].
     * Retorna um novo array.
     */
    public static float[] normalizeToMinusOneToOne(float[] samples) {
        float[] mm = minMax(samples);
        float min = mm[0];
        float max = mm[1];

        // caso degenerado: tudo igual
        if (max == min) {
            float[] out = new float[samples.length];
            Arrays.fill(out, 0f);
            return out;
        }

        float[] out = new float[samples.length];
        float range = max - min;

        for (int i = 0; i < samples.length; i++) {
            float v = samples[i];
            float norm = ( (v - min) / range ) * 2f - 1f; // [0,1] -> [-1,1]
            out[i] = norm;
        }
        return out;
    }

    /**
     * Delta encoding simples: out[0] = samples[0], out[i] = samples[i] - samples[i-1].
     */
    public static float[] deltaEncode(float[] samples) {
        if (samples == null || samples.length == 0) {
            throw new IllegalArgumentException("samples must not be null/empty");
        }
        float[] out = new float[samples.length];
        out[0] = samples[0];
        for (int i = 1; i < samples.length; i++) {
            out[i] = samples[i] - samples[i - 1];
        }
        return out;
    }

    /**
     * Delta decoding inverso: reconstrói o sinal original.
     */
    public static float[] deltaDecode(float[] deltas) {
        if (deltas == null || deltas.length == 0) {
            throw new IllegalArgumentException("deltas must not be null/empty");
        }
        float[] out = new float[deltas.length];
        out[0] = deltas[0];
        for (int i = 1; i < deltas.length; i++) {
            out[i] = out[i - 1] + deltas[i];
        }
        return out;
    }

    /**
     * Desfaz a normalização de [-1,1] para o range [min, max].
     * Inverso aproximado do normalizeToMinusOneToOne.
     */
    public static float[] denormalizeFromMinusOneToOne(float[] normalized, float min, float max) {
        if (normalized == null || normalized.length == 0) {
            throw new IllegalArgumentException("normalized must not be null/empty");
        }
        float range = max - min;
        if (range == 0f) {
            float[] out = new float[normalized.length];
            Arrays.fill(out, min);
            return out;
        }
        float[] out = new float[normalized.length];
        for (int i = 0; i < normalized.length; i++) {
            float v = normalized[i];         // [-1,1]
            float zeroToOne = (v + 1f) / 2f; // [-1,1] -> [0,1]
            out[i] = min + zeroToOne * range;
        }
        return out;
    }

}
```

```
    public static Sdc3DVolume read3D(Path path, CompressionProfile profile) throws IOException {
        try (DataInputStream in = new DataInputStream(
                new BufferedInputStream(Files.newInputStream(path)))) {

            SdcHeader header = SdcHeader.read(in);
            if (header.version() != 3) {
                throw new IOException("Expected SDC version 3 for 3D volume, got " + header.version());
            }

            int inlineCount = in.readInt();
            int xlineCount  = in.readInt();
            int timeCount   = in.readInt();

            int blockInline = in.readInt();
            int blockXline  = in.readInt();
            int blockTime   = in.readInt();

            int blockCount = in.readInt();

            List<CubeIndexEntry> index = new ArrayList<>(blockCount);
            for (int b = 0; b < blockCount; b++) {
                int ii = in.readInt();
                int jj = in.readInt();
                int tt = in.readInt();
                int bi = in.readInt();
                int bj = in.readInt();
                int bt = in.readInt();
                float min = in.readFloat();
                float max = in.readFloat();
                int payloadSize = in.readInt();
                index.add(new CubeIndexEntry(ii, jj, tt, bi, bj, bt, min, max, payloadSize));
            }

            float[][][] volume = new float[inlineCount][xlineCount][timeCount];

            for (CubeIndexEntry e : index) {
                byte[] payload = in.readNBytes(e.payloadSize);

                // monta metadados do bloco
                float[][][] dummy = new float[e.inlineCount][e.xlineCount][e.timeCount];
                VolumeBlock3D meta = new VolumeBlock3D(
                        e.inlineStartIndex,
                        e.xlineStartIndex,
                        e.timeStartIndex,
                        dummy
                );

                VolumeBlock3DCompressor.CompressedVolumeBlock3D cb =
                        new VolumeBlock3DCompressor.CompressedVolumeBlock3D(meta, e.min, e.max, payload);

                float[][][] cubeData = VolumeBlock3DCompressor.decompressBlock(cb, profile);

                // copia pro volume global
                for (int di = 0; di < e.inlineCount; di++) {
                    int gi = e.inlineStartIndex + di;
                    for (int dj = 0; dj < e.xlineCount; dj++) {
                        int gj = e.xlineStartIndex + dj;
                        System.arraycopy(cubeData[di][dj], 0,
                                volume[gi][gj], e.timeStartIndex, e.timeCount);
                    }
                }
            }

            return new Sdc3DVolume(inlineCount, xlineCount, timeCount, volume);
        }
    }

    /**
     * Lê apenas uma fatia 2D do volume (.sdc v3), evitando carregar o volume inteiro.
     * axis: INLINE, XLINE, TIME.
     * start0/count0 e start1/count1 fazem paginacao dentro da fatia.

    /**
     * Lê apenas uma fatia 2D do volume (.sdc v3) com cache LRU opcional.
     */
    public static Sdc3DSlice readSlice(Path path,
                                       CompressionProfile profile,
                                       String axisInput,
                                       int indexInput,
                                       int start0Input,
                                       int count0Input,
                                       int start1Input,
                                       int count1Input,
                                       VolumeBlockCache cache) throws IOException {
        String axis = axisInput == null ? "TIME" : axisInput.trim().toUpperCase();

        try (DataInputStream in = new DataInputStream(
                new BufferedInputStream(Files.newInputStream(path)))) {

            SdcHeader header = SdcHeader.read(in);
            if (header.version() != 3) {
                throw new IOException("Expected SDC version 3 for 3D volume, got " + header.version());
            }

            int inlineCount = in.readInt();
            int xlineCount  = in.readInt();
            int timeCount   = in.readInt();

            int blockInline = in.readInt();
            int blockXline  = in.readInt();
            int blockTime   = in.readInt();

            int blockCount = in.readInt();

            List<CubeIndexEntry> index = new ArrayList<>(blockCount);
            for (int b = 0; b < blockCount; b++) {
                int ii = in.readInt();
                int jj = in.readInt();
                int tt = in.readInt();
                int bi = in.readInt();
                int bj = in.readInt();
                int bt = in.readInt();
                float min = in.readFloat();
                float max = in.readFloat();
                int payloadSize = in.readInt();
                index.add(new CubeIndexEntry(ii, jj, tt, bi, bj, bt, min, max, payloadSize));
            }

            int axisIndex;
            int dim0Total;
            int dim1Total;

            switch (axis) {
                case "INLINE" -> {
                    axisIndex = clamp(indexInput, 0, inlineCount - 1);
                    dim0Total = xlineCount;
                    dim1Total = timeCount;
                }
                case "XLINE" -> {
                    axisIndex = clamp(indexInput, 0, xlineCount - 1);
                    dim0Total = inlineCount;
                    dim1Total = timeCount;
                }
                case "TIME" -> {
                    axisIndex = clamp(indexInput, 0, timeCount - 1);
                    dim0Total = inlineCount;
                    dim1Total = xlineCount;
                }
                default -> throw new IllegalArgumentException("Axis invalido: " + axis);
            }

            int start0 = normalizeStart(start0Input, dim0Total);
            int start1 = normalizeStart(start1Input, dim1Total);
            int count0 = normalizeCount(count0Input, dim0Total - start0);
            int count1 = normalizeCount(count1Input, dim1Total - start1);

            float[][] slice = new float[count0][count1];

            for (CubeIndexEntry e : index) {
                if (!intersectsSlice(axis, axisIndex, start0, count0, start1, count1, e)) {
                    in.skipNBytes(e.payloadSize);
                    continue;
                }

                String cacheKey = cache != null ? VolumeBlockCache.key(path.toString(), e.inlineStartIndex, e.xlineStartIndex, e.timeStartIndex) : null;

                float[][][] cubeData = null;
                if (cache != null) {
                    cubeData = cache.get(cacheKey);
                }

                if (cubeData == null) {
                    byte[] payload = in.readNBytes(e.payloadSize);

                    float[][][] dummy = new float[e.inlineCount][e.xlineCount][e.timeCount];
                    VolumeBlock3D meta = new VolumeBlock3D(
                            e.inlineStartIndex,
                            e.xlineStartIndex,
                            e.timeStartIndex,
                            dummy
                    );

                    VolumeBlock3DCompressor.CompressedVolumeBlock3D cb =
                            new VolumeBlock3DCompressor.CompressedVolumeBlock3D(meta, e.min, e.max, payload);

                    cubeData = VolumeBlock3DCompressor.decompressBlock(cb, profile);

                    if (cache != null) {
                        cache.put(cacheKey, cubeData);
                    }
                } else {
                    in.skipNBytes(e.payloadSize);
                }

                copySlice(axis, axisIndex, start0, count0, start1, count1, e, cubeData, slice);
            }

            return new Sdc3DSlice(
                    inlineCount,
                    xlineCount,
                    timeCount,
                    axis,
                    axisIndex,
                    start0,
                    count0,
                    start1,
                    count1,
                    slice
            );
        }
    }

    private static boolean intersectsSlice(String axis,
                                           int axisIndex,
                                           int start0,
                                           int count0,
                                           int start1,
                                           int count1,
                                           CubeIndexEntry e) {
        int end0 = start0 + count0;
        int end1 = start1 + count1;

        return switch (axis) {
            case "TIME" -> {
                boolean timeHit = axisIndex >= e.timeStartIndex && axisIndex < e.timeStartIndex + e.timeCount;
                boolean inlineHit = rangesOverlap(start0, end0, e.inlineStartIndex, e.inlineStartIndex + e.inlineCount);
                boolean xlineHit = rangesOverlap(start1, end1, e.xlineStartIndex, e.xlineStartIndex + e.xlineCount);
                yield timeHit && inlineHit && xlineHit;
            }
            case "INLINE" -> {
                boolean inlineHit = axisIndex >= e.inlineStartIndex && axisIndex < e.inlineStartIndex + e.inlineCount;
                boolean xlineHit = rangesOverlap(start0, end0, e.xlineStartIndex, e.xlineStartIndex + e.xlineCount);
                boolean timeHit = rangesOverlap(start1, end1, e.timeStartIndex, e.timeStartIndex + e.timeCount);
                yield inlineHit && xlineHit && timeHit;
            }
            case "XLINE" -> {
                boolean xlineHit = axisIndex >= e.xlineStartIndex && axisIndex < e.xlineStartIndex + e.xlineCount;
                boolean inlineHit = rangesOverlap(start0, end0, e.inlineStartIndex, e.inlineStartIndex + e.inlineCount);
                boolean timeHit = rangesOverlap(start1, end1, e.timeStartIndex, e.timeStartIndex + e.timeCount);
                yield xlineHit && inlineHit && timeHit;
            }
            default -> false;
        };
    }

    private static void copySlice(String axis,
                                  int axisIndex,
                                  int start0,
                                  int count0,
                                  int start1,
                                  int count1,
                                  CubeIndexEntry e,
                                  float[][][] cube,
                                  float[][] out) {
        int end0 = start0 + count0;
        int end1 = start1 + count1;

        switch (axis) {
            case "TIME" -> {
                int tLocal = axisIndex - e.timeStartIndex;
                if (tLocal < 0 || tLocal >= e.timeCount) return;
                int iStart = Math.max(start0, e.inlineStartIndex);
                int iEnd = Math.min(end0, e.inlineStartIndex + e.inlineCount);
                int jStart = Math.max(start1, e.xlineStartIndex);
                int jEnd = Math.min(end1, e.xlineStartIndex + e.xlineCount);
                for (int i = iStart; i < iEnd; i++) {
                    int iLocal = i - e.inlineStartIndex;
                    int outI = i - start0;
                    for (int j = jStart; j < jEnd; j++) {
                        int jLocal = j - e.xlineStartIndex;
                        int outJ = j - start1;
                        out[outI][outJ] = cube[iLocal][jLocal][tLocal];
                    }
                }
            }
            case "INLINE" -> {
                int iLocal = axisIndex - e.inlineStartIndex;
                if (iLocal < 0 || iLocal >= e.inlineCount) return;
                int jStart = Math.max(start0, e.xlineStartIndex);
                int jEnd = Math.min(end0, e.xlineStartIndex + e.xlineCount);
                int tStart = Math.max(start1, e.timeStartIndex);
                int tEnd = Math.min(end1, e.timeStartIndex + e.timeCount);
                for (int j = jStart; j < jEnd; j++) {
                    int jLocal = j - e.xlineStartIndex;
                    int outJ = j - start0;
                    for (int t = tStart; t < tEnd; t++) {
                        int tLocal = t - e.timeStartIndex;
                        int outT = t - start1;
                        out[outJ][outT] = cube[iLocal][jLocal][tLocal];
                    }
                }
            }
            case "XLINE" -> {
                int jLocal = axisIndex - e.xlineStartIndex;
                if (jLocal < 0 || jLocal >= e.xlineCount) return;
                int iStart = Math.max(start0, e.inlineStartIndex);
                int iEnd = Math.min(end0, e.inlineStartIndex + e.inlineCount);
                int tStart = Math.max(start1, e.timeStartIndex);
                int tEnd = Math.min(end1, e.timeStartIndex + e.timeCount);
                for (int i = iStart; i < iEnd; i++) {
                    int iLocal = i - e.inlineStartIndex;
                    int outI = i - start0;
                    for (int t = tStart; t < tEnd; t++) {
                        int tLocal = t - e.timeStartIndex;
                        int outT = t - start1;
                        out[outI][outT] = cube[iLocal][jLocal][tLocal];
                    }
                }
            }
            default -> throw new IllegalArgumentException("Axis invalido: " + axis);
        }
    }

    private static boolean rangesOverlap(int aStart, int aEnd, int bStart, int bEnd) {
        return aStart < bEnd && bStart < aEnd;
    }

    private static int clamp(int v, int min, int max) {
        if (max < min) return min;
        if (v < min) return min;
        if (v > max) return max;
        return v;
    }

    private static int normalizeStart(int start, int max) {
        if (start < 0) return 0;
        if (start > max) return max;
        return start;
    }

    private static int normalizeCount(int count, int max) {
        if (count < 0) return max;
        if (count > max) return max;
        return count;
    }
}
```

```
package com.sdc.core;

import java.io.*;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.ArrayList;
import java.util.List;

public final class Sdc3DFileWriter {

    private Sdc3DFileWriter() {}

    /**
     * Gera um .sdc v3 em modo 3D:
     *
     * Layout simplificado:
     *  [SdcHeader version=3, traceCount, samplesPerTrace]
     *  [inlineCount][xlineCount][timeCount]
     *  [blockInline][blockXline][blockTime]
     *  [blockCount]
     *  Tabela de offsets por cubo (blockCount entradas):
     *    para cada cubo:
     *      [inlineStartIndex][xlineStartIndex][timeStartIndex]
     *      [inlineCount][xlineCount][timeCount]
     *      [payloadSize]
     *  Blocos comprimidos:
     *    para cada cubo:
     *      [payloadBytes...]
     */
    public static void write3D(Path target,
                               SegyIO.SegyDataset dataset,
                               CompressionProfile profile,
                               int blockInline,
                               int blockXline,
                               int blockTime) throws IOException {

        int inlineCount = dataset.traceGrid.inlineCount();
        int xlineCount  = dataset.traceGrid.xlineCount();
        int timeCount   = dataset.samplesPerTrace;

        if (blockInline <= 0) blockInline = 8;
        if (blockXline <= 0) blockXline = 8;
        if (blockTime <= 0 || blockTime > timeCount) blockTime = timeCount;

        List<VolumeBlock3DCompressor.CompressedVolumeBlock3D> compressedBlocks = new ArrayList<>();
        List<CubeIndexEntry> index = new ArrayList<>();

        // monta os cubos varrendo inline/xline/time (por enquanto time em blocos completos ou fatias)
        for (int ii = 0; ii < inlineCount; ii += blockInline) {
            int bi = Math.min(blockInline, inlineCount - ii);
            for (int jj = 0; jj < xlineCount; jj += blockXline) {
                int bj = Math.min(blockXline, xlineCount - jj);
                for (int tt = 0; tt < timeCount; tt += blockTime) {
                    int bt = Math.min(blockTime, timeCount - tt);

                    float[][][] cube = new float[bi][bj][bt];

                    for (int di = 0; di < bi; di++) {
                        for (int dj = 0; dj < bj; dj++) {
                            int globalInlineIdx = ii + di;
                            int globalXlineIdx  = jj + dj;
                            int traceIdx = dataset.traceGrid.traceIndexAt(globalInlineIdx, globalXlineIdx);
                            if (traceIdx < 0) {
                                // traço ausente -> preenche zeros
                                for (int k = 0; k < bt; k++) {
                                    cube[di][dj][k] = 0f;
                                }
                            } else {
                                float[] samples = dataset.traces.get(traceIdx).samples();
                                System.arraycopy(samples, tt, cube[di][dj], 0, bt);
                            }
                        }
                    }

                    VolumeBlock3D vb = new VolumeBlock3D(ii, jj, tt, cube);
                    VolumeBlock3DCompressor.CompressedVolumeBlock3D cb =
                            VolumeBlock3DCompressor.compressBlock(vb, profile);

                    compressedBlocks.add(cb);
                    index.add(new CubeIndexEntry(
                            ii, jj, tt,
                            bi, bj, bt,
                            cb.min,
                            cb.max,
                            cb.payload.length
                    ));
                }
            }
        }

        int blockCount = compressedBlocks.size();
        SdcHeader header = new SdcHeader(3, dataset.traceCount(), dataset.samplesPerTrace);

        try (DataOutputStream out = new DataOutputStream(
                new BufferedOutputStream(Files.newOutputStream(target)))) {

            header.write(out);

            // dim globais
            out.writeInt(inlineCount);
            out.writeInt(xlineCount);
            out.writeInt(timeCount);

            // dim bloco
            out.writeInt(blockInline);
            out.writeInt(blockXline);
            out.writeInt(blockTime);

            // qtde de blocos
            out.writeInt(blockCount);

            // tabela de offsets (coordenadas 3D + min/max + tamanho do payload)
            for (CubeIndexEntry e : index) {
                out.writeInt(e.inlineStartIndex);
                out.writeInt(e.xlineStartIndex);
                out.writeInt(e.timeStartIndex);
                out.writeInt(e.inlineCount);
                out.writeInt(e.xlineCount);
                out.writeInt(e.timeCount);
                out.writeFloat(e.min);
                out.writeFloat(e.max);
                out.writeInt(e.payloadSize);
            }

            // blocos comprimidos na mesma ordem
            for (VolumeBlock3DCompressor.CompressedVolumeBlock3D cb : compressedBlocks) {
                out.write(cb.payload);
            }

            out.flush();
        }
    }
}
```

```
 * Gera um arquivo .sdc v2 (comprimido) com alguns traços sintéticos
 * e imprime a razão de compressão aproximada.
 */
public final class SdcCompressedSampleGenerator {

    public static void main(String[] args) throws Exception {
        Path target = Path.of("sample-compressed.sdc");

        int traceCount = 8;
        int samplesPerTrace = 2048;
        List<TraceBlock> traces = new ArrayList<>(traceCount);

        for (int t = 0; t < traceCount; t++) {
            float[] s = new float[samplesPerTrace];
            for (int i = 0; i < samplesPerTrace; i++) {
                float x = (float) i / samplesPerTrace;
                // senoide com fase diferente por traço
                float v = (float) Math.sin(2 * Math.PI * (5 + t) * x);
                v += (float) (0.01 * Math.random());
                s[i] = v;
            }
            traces.add(new TraceBlock(t, s));
        }

        // tamanho bruto (float32 sem container)
        long rawBytes = (long) traceCount * samplesPerTrace * 4L;

        SdcFileWriter.writeCompressed(target, traces);

        long fileBytes = Files.size(target);

        double ratio = (double) fileBytes / rawBytes;

        System.out.println("Arquivo gerado: " + target.toAbsolutePath());
        System.out.println("Tamanho bruto (float32): " + rawBytes + " bytes");
        System.out.println("Tamanho .sdc v2:         " + fileBytes + " bytes");
        System.out.printf("Razão approx (.sdc / raw): %.3f%n", ratio);

        // leitura de volta e PSNR de um traço
        List<TraceBlock> rec = SdcFileReader.readAllCompressed(target);
        float[] orig = traces.get(0).samples();
        float[] dec = rec.get(0).samples();
        double psnr = LinearQuantizer.psnr(orig, dec);
```

```
        Objects.requireNonNull(path, "path");
        try (DataInputStream in = new DataInputStream(
                new BufferedInputStream(Files.newInputStream(path)))) {

            SdcHeader header = SdcHeader.read(in);
            List<TraceBlock> traces = new ArrayList<>(header.traceCount());

            for (int t = 0; t < header.traceCount(); t++) {
                int traceId = in.readInt();
                float[] samples = new float[header.samplesPerTrace()];
                for (int i = 0; i < samples.length; i++) {
                    samples[i] = in.readFloat();
                }
                traces.add(new TraceBlock(traceId, samples));
            }
            return traces;
        }
    }

     */
    public static java.util.List<TraceBlock> readAllCompressed(java.nio.file.Path path) throws java.io.IOException {
        java.util.Objects.requireNonNull(path, "path");
        try (java.io.DataInputStream in = new java.io.DataInputStream(
                new java.io.BufferedInputStream(java.nio.file.Files.newInputStream(path)))) {

            SdcHeader header = SdcHeader.read(in);
            if (header.version() != 2) {
                throw new java.io.IOException("Expected SDC version 2, got " + header.version());
            }

            java.util.List<TraceBlock> traces = new java.util.ArrayList<>(header.traceCount());

            for (int t = 0; t < header.traceCount(); t++) {
                int traceId = in.readInt();
                float min = in.readFloat();
                float max = in.readFloat();
                int payloadSize = in.readInt();
                byte[] payload = in.readNBytes(payloadSize);

                CompressedTraceBlock cb = new CompressedTraceBlock(
                        traceId, min, max, header.samplesPerTrace(), payload);

                TraceBlock tb = TraceBlockCodec.decompress(cb);
                traces.add(tb);
            }
            return traces;
        }
    }
}
```

```
package com.sdc.core;

import java.io.BufferedOutputStream;
import java.io.DataOutputStream;
import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.List;
import java.util.Objects;

/**
 * Escritor simples de arquivos .sdc v0:
 * header + traços (sem compressão ainda).
 */
public final class SdcFileWriter {

    private SdcFileWriter() {
        // utilitário estático
    }

    public static void write(Path target, List<TraceBlock> traces) throws IOException {
        Objects.requireNonNull(target, "target");
        Objects.requireNonNull(traces, "traces");

        if (traces.isEmpty()) {
            throw new IllegalArgumentException("traces must not be empty");
        }

        int traceCount = traces.size();
        int samplesPerTrace = traces.get(0).samples().length;

        // sanity: todos com o mesmo tamanho
        for (TraceBlock tb : traces) {
            if (tb.samples().length != samplesPerTrace) {
                throw new IllegalArgumentException("all traces must have same samplesPerTrace");
            }
        }

        SdcHeader header = new SdcHeader(1, traceCount, samplesPerTrace);

        try (DataOutputStream out = new DataOutputStream(
                new BufferedOutputStream(Files.newOutputStream(target)))) {

            header.write(out);

            for (TraceBlock tb : traces) {
                out.writeInt(tb.traceId());
                for (float v : tb.samples()) {
                    out.writeFloat(v);
                }
            }

            out.flush();
        }
    }

    public static void writeCompressed(java.nio.file.Path target, java.util.List<TraceBlock> traces)
            throws java.io.IOException {
        writeCompressed(target, traces, CompressionProfile.defaultHighQuality());
    }

    /**
     * Versão v2: grava traços comprimidos usando TraceBlockCodec e um perfil de compressão.
     * Layout:
     *  [MAGIC][version=2][traceCount][samplesPerTrace]
     *  repetido para cada traço:
     *    [traceId][min][max][payloadSize][payloadBytes...]
     */
    public static void writeCompressed(java.nio.file.Path target,
                                       java.util.List<TraceBlock> traces,
                                       CompressionProfile profile) throws java.io.IOException {

        java.util.Objects.requireNonNull(target, "target");
        java.util.Objects.requireNonNull(traces, "traces");
        java.util.Objects.requireNonNull(profile, "profile");
        if (traces.isEmpty()) throw new IllegalArgumentException("traces must not be empty");

        int traceCount = traces.size();
        int samplesPerTrace = traces.get(0).samples().length;
        for (TraceBlock tb : traces) {
            if (tb.samples().length != samplesPerTrace) {
                throw new IllegalArgumentException("all traces must have same samplesPerTrace");
            }
        }

        SdcHeader header = new SdcHeader(2, traceCount, samplesPerTrace);

        try (java.io.DataOutputStream out = new java.io.DataOutputStream(
                new java.io.BufferedOutputStream(java.nio.file.Files.newOutputStream(target)))) {

            header.write(out);

            for (TraceBlock tb : traces) {
                CompressedTraceBlock cb = TraceBlockCodec.compress(tb, profile);
                byte[] payload = cb.payload();

                out.writeInt(cb.traceId());
                out.writeFloat(cb.min());
                out.writeFloat(cb.max());
                out.writeInt(payload.length);
                out.write(payload);
            }
            out.flush();
        }
    }

}
```

```
package com.sdc.core;

import java.io.DataInputStream;
import java.io.DataOutputStream;
import java.io.IOException;
import java.util.Objects;

/**
 * Cabeçalho mínimo do container .sdc v0.
 */
public final class SdcHeader {

    public static final int MAGIC = 0x53444331; // 'S''D''C''1'

    private final int version;
    private final int traceCount;
    private final int samplesPerTrace;

    public SdcHeader(int version, int traceCount, int samplesPerTrace) {
        if (version <= 0) throw new IllegalArgumentException("version must be > 0");
        if (traceCount < 0) throw new IllegalArgumentException("traceCount must be >= 0");
        if (samplesPerTrace <= 0) throw new IllegalArgumentException("samplesPerTrace must be > 0");
        this.version = version;
        this.traceCount = traceCount;
        this.samplesPerTrace = samplesPerTrace;
    }

    public int version()         { return version; }
    public int traceCount()      { return traceCount; }
    public int samplesPerTrace() { return samplesPerTrace; }

    @Override
    public String toString() {
        return "SdcHeader{" +
                "version=" + version +
                ", traceCount=" + traceCount +
                ", samplesPerTrace=" + samplesPerTrace +
                '}';
    }

    // Serialização binária simples

    public void write(DataOutputStream out) throws IOException {
        Objects.requireNonNull(out, "out");
        out.writeInt(MAGIC);
        out.writeInt(version);
        out.writeInt(traceCount);
        out.writeInt(samplesPerTrace);
    }

    public static SdcHeader read(DataInputStream in) throws IOException {
        Objects.requireNonNull(in, "in");
        int magic = in.readInt();
        if (magic != MAGIC) {
            throw new IOException(String.format("Invalid SDC magic: 0x%08X", magic));
        }
        int version = in.readInt();
        int traceCount = in.readInt();
        int samplesPerTrace = in.readInt();
        return new SdcHeader(version, traceCount, samplesPerTrace);
    }
}
```

### sdc-core/src/main/java/com/sdc/core/SegyCompression.java
```
package com.sdc.core;

import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.List;

/**
 * Helpers de alto nível para:
 *  - SEG-Y -> .sdc (compressão)
 *  - .sdc -> SEG-Y (descompressão)
 *
 * Usa:
 *  - SegyIO (I/O SEG-Y)
 *  - TraceBlockCodec / SdcFileWriter / SdcFileReader
 */
public final class SegyCompression {

    private SegyCompression() {}

    public static final class CompressionResult {
        public final Path segyPath;
        public final Path sdcPath;

        public final long segyBytes;      // tamanho total do arquivo SEG-Y
        public final long sdcBytes;       // tamanho total do .sdc
        public final long rawDataBytes;   // apenas dados dos traços (ns * nTraces * 4)

        public final int traceCount;
        public final int samplesPerTrace;

        public final double ratioFile;    // sdcBytes / segyBytes
        public final double ratioData;    // sdcBytes / rawDataBytes
        public final double savingsPercent; // (1 - ratioFile) * 100

        public final double psnrFirstTrace;
        public final double psnrMean;
        public final double psnrMin;
        public final double psnrMax;

        public CompressionResult(Path segyPath,
                                Path sdcPath,
                                long segyBytes,
                                long sdcBytes,
                                long rawDataBytes,
                                int traceCount,
                                int samplesPerTrace,
                                double ratioFile,
                                double ratioData,
                                double savingsPercent,
                                double psnrFirstTrace,
                                double psnrMean,
                                double psnrMin,
                                double psnrMax) {
            this.segyPath = segyPath;
            this.sdcPath = sdcPath;
            this.segyBytes = segyBytes;
            this.sdcBytes = sdcBytes;
            this.rawDataBytes = rawDataBytes;
            this.traceCount = traceCount;
            this.samplesPerTrace = samplesPerTrace;
            this.ratioFile = ratioFile;
            this.ratioData = ratioData;
            this.savingsPercent = savingsPercent;
            this.psnrFirstTrace = psnrFirstTrace;
            this.psnrMean = psnrMean;
            this.psnrMin = psnrMin;
            this.psnrMax = psnrMax;
        }
    }

    public static CompressionResult compressSegyToSdc(Path segyPath, Path sdcPath) throws IOException {
        return compressSegyToSdc(segyPath, sdcPath, CompressionProfile.defaultHighQuality());
    }

    /**
     * Lê um SEG-Y, comprime os traços para .sdc v2 e retorna métricas.
     */
    public static CompressionResult compressSegyToSdc(Path segyPath,
                                                      Path sdcPath,
                                                      CompressionProfile profile) throws IOException {
        SegyIO.SegyDataset dataset = SegyIO.read(segyPath);
        List<TraceBlock> traceBlocks = dataset.traces;

        // Dump do SEG-Y original
        SegyDump.dumpFromDataset(segyPath, dataset);

        int traceCount = dataset.traceCount();
        int samplesPerTrace = dataset.samplesPerTrace;

        long segyBytes = Files.size(segyPath);
        long rawDataBytes = (long) traceCount * samplesPerTrace * 4L;

        // Usa o profile aqui
        SdcFileWriter.writeCompressed(sdcPath, traceBlocks, profile);

        long sdcBytes = Files.size(sdcPath);

        double ratioFile = (double) sdcBytes / (double) segyBytes;
        double ratioData = (double) sdcBytes / (double) rawDataBytes;
        double savingsPercent = (1.0 - ratioFile) * 100.0;

        double psnrFirst = Double.NaN;
        double psnrMean = Double.NaN;
        double psnrMin = Double.NaN;
        double psnrMax = Double.NaN;

        if (!traceBlocks.isEmpty()) {
            List<TraceBlock> rec = SdcFileReader.readAllCompressed(sdcPath);
            int n = Math.min(traceBlocks.size(), rec.size());

            double sum = 0.0;

            for (int i = 0; i < n; i++) {
                float[] orig = traceBlocks.get(i).samples();
                float[] dec  = rec.get(i).samples();
                double psnr = LinearQuantizer.psnr(orig, dec);

                if (i == 0) {
                    psnrFirst = psnr;
                    psnrMin = psnr;
                    psnrMax = psnr;
                } else {
                    if (psnr < psnrMin) psnrMin = psnr;
                    if (psnr > psnrMax) psnrMax = psnr;
                }
                sum += psnr;
            }
            psnrMean = sum / n;
        }

        return new CompressionResult(
                segyPath,
                sdcPath,
                segyBytes,
                sdcBytes,
                rawDataBytes,
                traceCount,
                samplesPerTrace,
                ratioFile,
                ratioData,
                savingsPercent,
                psnrFirst,
                psnrMean,
                psnrMin,
                psnrMax
        );
    }

    public static CompressionResult compressSegyToSdc3D(Path segyPath,
                                                    Path sdcPath,
                                                    CompressionProfile profile,
                                                    int blockInline,
                                                    int blockXline,
                                                    int blockTime) throws IOException {
        // Lê o SEG-Y original
        SegyIO.SegyDataset dataset = SegyIO.read(segyPath);

        int traceCount = dataset.traceCount();
        int samplesPerTrace = dataset.samplesPerTrace;

        long segyBytes = Files.size(segyPath);
        long rawDataBytes = (long) traceCount * samplesPerTrace * 4L;

        // Escreve .sdc v3 (3D)
        Sdc3DFileWriter.write3D(sdcPath, dataset, profile, blockInline, blockXline, blockTime);

        long sdcBytes = Files.size(sdcPath);

        double ratioFile = (double) sdcBytes / (double) segyBytes;
        double ratioData = (double) sdcBytes / (double) rawDataBytes;
        double savingsPercent = (1.0 - ratioFile) * 100.0;

        // PSNR: reconstruímos o volume 3D e comparamos com os traces originais
        double psnrFirst = Double.NaN;
        double psnrMean  = Double.NaN;
        double psnrMin   = Double.NaN;
        double psnrMax   = Double.NaN;

        if (traceCount > 0) {
            // Lê volume 3D do .sdc
            Sdc3DFileReader.Sdc3DVolume volume = Sdc3DFileReader.read3D(sdcPath, profile);

            // Reconstrói traces a partir do volume
            java.util.List<TraceBlock> reconTraces =
                    reconstructTracesFromVolume(dataset, volume);

            // Calcula PSNR trace a trace
            int n = Math.min(traceCount, reconTraces.size());
            double sum = 0.0;
            for (int i = 0; i < n; i++) {
                float[] orig = dataset.traces.get(i).samples();
                float[] rec  = reconTraces.get(i).samples();
                double psnr  = LinearQuantizer.psnr(orig, rec);

                if (i == 0) {
                    psnrFirst = psnr;
                    psnrMin = psnr;
                    psnrMax = psnr;
                } else {
                    if (psnr < psnrMin) psnrMin = psnr;
                    if (psnr > psnrMax) psnrMax = psnr;
                }
                sum += psnr;
            }
            if (n > 0) {
                psnrMean = sum / n;
            }
        }

        return new CompressionResult(
                segyPath,
                sdcPath,
                segyBytes,
                sdcBytes,
                rawDataBytes,
                traceCount,
                samplesPerTrace,
                ratioFile,
                ratioData,
                savingsPercent,
                psnrFirst,
                psnrMean,
                psnrMin,
                psnrMax
        );
    }


    /**
     * Lê um .sdc v2, descomprime todos os traços e escreve um novo SEG-Y.
     *
     * ATENÇÃO: usa o SEG-Y template para copiar headers (textual, binary, trace).
     * Idealmente, templateSegyPath aponta para o SEG-Y original.
     */
    public static void decompressSdcToSegy(Path sdcPath, Path templateSegyPath, Path outSegyPath) throws IOException {
        // Lê headers e metadados do SEG-Y template
        SegyIO.SegyDataset template = SegyIO.read(templateSegyPath);

        // Descomprime todos os traços do .sdc
        List<TraceBlock> traces = SdcFileReader.readAllCompressed(sdcPath);

        if (traces.size() != template.traceHeaders.size()) {
            throw new IOException("Número de traços no .sdc (" + traces.size() +
                    ") difere do template SEG-Y (" + template.traceHeaders.size() + ")");
        }

        // Escreve novo SEG-Y com headers originais e samples reconstruídos
        SegyIO.write(outSegyPath, template, traces);

        // Gera dump TXT + CSV do SEG-Y reconstruído
        SegyDump.dumpFromFile(outSegyPath);
    }

    public static void decompressSdcToSegy3D(Path sdcPath,
                                         Path templateSegyPath,
                                         Path outSegyPath,
                                         CompressionProfile profile) throws IOException {

        // Lê o template SEG-Y (headers + grid IL/XL)
        SegyIO.SegyDataset template = SegyIO.read(templateSegyPath);

        // Lê o volume 3D do .sdc v3
        Sdc3DFileReader.Sdc3DVolume volume = Sdc3DFileReader.read3D(sdcPath, profile);

        // Reconstrói os traços a partir do volume 3D usando o traceGrid
        java.util.List<TraceBlock> tracesReconstruidos =
                reconstructTracesFromVolume(template, volume);

        // Escreve novo SEG-Y usando os headers originais do template e os samples reconstruídos
        SegyIO.write(outSegyPath, template, tracesReconstruidos);
    }

    private static java.util.List<TraceBlock> reconstructTracesFromVolume(
        SegyIO.SegyDataset template,
        Sdc3DFileReader.Sdc3DVolume volume) throws IOException {

        int inlineCount = template.traceGrid.inlineCount();
        int xlineCount  = template.traceGrid.xlineCount();
        int timeCount   = template.samplesPerTrace;

        if (volume.inlineCount != inlineCount ||
            volume.xlineCount  != xlineCount ||
            volume.timeCount   != timeCount) {
            throw new IOException("Dimensões do volume 3D não batem com o template SEG-Y: " +
                    "volume=(" + volume.inlineCount + "," + volume.xlineCount + "," + volume.timeCount + "), " +
                    "template=(" + inlineCount + "," + xlineCount + "," + timeCount + ")");
        }

        int traceCount = template.traceCount();
        java.util.List<TraceBlock> recon = new java.util.ArrayList<>(traceCount);
        for (int i = 0; i < traceCount; i++) {
            recon.add(null);
        }

        for (int ii = 0; ii < inlineCount; ii++) {
            for (int jj = 0; jj < xlineCount; jj++) {
                int traceIndex = template.traceGrid.traceIndexAt(ii, jj);
                if (traceIndex < 0) {
                    continue; // célula vazia
                }
                float[] samples = new float[timeCount];
                System.arraycopy(volume.data[ii][jj], 0, samples, 0, timeCount);
                recon.set(traceIndex, new TraceBlock(traceIndex, samples));
            }
        }

        // valida que não sobrou null
        for (int i = 0; i < recon.size(); i++) {
            if (recon.get(i) == null) {
                throw new IOException("Reconstrução 3D: falta traço para índice " + i);
            }
        }

        return recon;
    }

}
```

```
package com.sdc.core;

import java.io.*;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.ArrayList;
import java.util.List;

/**
 * Leitura/escrita mínima de arquivos SEG-Y (assumindo:
 *  - 3200 bytes de header textual
 *  - 400 bytes de binary header
 *  - traços com 240 bytes de trace header + ns amostras float32 big-endian (formato 5)
 *
 * Esta implementação é intencionalmente simplificada e serve como MVP
 * para a pipeline SEG-Y -> .sdc -> SEG-Y.
 */
public final class SegyIO {

    private SegyIO() {}

    public static final class SegyDataset {
        public final byte[] textualHeader;
        public final byte[] binaryHeader;
        public final java.util.List<byte[]> traceHeaders;
        public final java.util.List<TraceBlock> traces;
        public final int samplesPerTrace;
        public final int sampleFormatCode;

        public final java.util.List<TraceMeta> traceMeta;
        public final TraceGrid traceGrid;

        public SegyDataset(byte[] textualHeader,
                        byte[] binaryHeader,
                        java.util.List<byte[]> traceHeaders,
                        java.util.List<TraceBlock> traces,
                        int samplesPerTrace,
                        int sampleFormatCode,
                        java.util.List<TraceMeta> traceMeta,
                        TraceGrid traceGrid) {
            this.textualHeader = textualHeader;
            this.binaryHeader = binaryHeader;
            this.traceHeaders = traceHeaders;
            this.traces = traces;
            this.samplesPerTrace = samplesPerTrace;
            this.sampleFormatCode = sampleFormatCode;
            this.traceMeta = traceMeta;
            this.traceGrid = traceGrid;
        }

        public int traceCount() {
            return traces.size();
        }
    }

    /**
     * Lê um SEG-Y simplificado com formato de amostra 5 (IEEE float32).
     */
    public static SegyDataset read(Path path) throws IOException {
        try (DataInputStream in = new DataInputStream(
                new BufferedInputStream(Files.newInputStream(path)))) {

            byte[] textualHeader = in.readNBytes(3200);
            if (textualHeader.length != 3200) {
                throw new IOException("Arquivo muito curto (textual header incompleto)");
            }

            byte[] binaryHeader = in.readNBytes(400);
            if (binaryHeader.length != 400) {
                throw new IOException("Arquivo muito curto (binary header incompleto)");
            }

            // Campos da binary header:
            // número de amostras por traço: bytes 20-21
            // formato da amostra: bytes 24-25
            int samplesPerTrace = readUnsignedShortBE(binaryHeader, 20);
            int formatCode      = readUnsignedShortBE(binaryHeader, 24);

            if (samplesPerTrace <= 0) {
                throw new IOException("samplesPerTrace inválido: " + samplesPerTrace);
            }

            if (formatCode != 1 && formatCode != 5) {
                throw new IOException("Formato de amostra não suportado neste MVP. formatCode=" + formatCode +
                        " (apenas 1=IBM float32 e 5=IEEE float32 são suportados)");
            }

            java.util.List<byte[]> traceHeaders = new java.util.ArrayList<>();
            java.util.List<TraceBlock> traces   = new java.util.ArrayList<>();
            java.util.List<TraceMeta> metaList  = new java.util.ArrayList<>();

            int traceIdx = 0;
            while (true) {
                byte[] traceHeader = in.readNBytes(240);
                if (traceHeader.length == 0) {
                    break;
                }
                if (traceHeader.length < 240) {
                    throw new EOFException("Trace header incompleto no trace " + traceIdx);
                }

                float[] samples = new float[samplesPerTrace];
                try {
                    for (int i = 0; i < samplesPerTrace; i++) {
                        int bits = in.readInt();
                        if (formatCode == 5) {
                            samples[i] = Float.intBitsToFloat(bits);
                        } else if (formatCode == 1) {
                            samples[i] = ibmToFloat(bits);
                        }
                    }
                } catch (EOFException eof) {
                    throw new EOFException("Samples incompletos no trace " + traceIdx);
                }

                traceHeaders.add(traceHeader);
                traces.add(new TraceBlock(traceIdx, samples));

                // Lê inline/xline do trace header
                int inline = readIntBE(traceHeader, 188); // bytes 189-192
                int xline  = readIntBE(traceHeader, 192); // bytes 193-196

                metaList.add(new TraceMeta(traceIdx, inline, xline));

                traceIdx++;
            }

            TraceGrid grid = buildTraceGrid(metaList);

            return new SegyDataset(textualHeader, binaryHeader, traceHeaders, traces,
                                samplesPerTrace, formatCode, metaList, grid);

        }
    }

    private static TraceGrid buildTraceGrid(java.util.List<TraceMeta> metaList) {
        java.util.Set<Integer> inlines = new java.util.HashSet<>();
        java.util.Set<Integer> xlines  = new java.util.HashSet<>();
        for (TraceMeta tm : metaList) {
            inlines.add(tm.inline);
            xlines.add(tm.xline);
        }

        int[] inlineValues = inlines.stream().sorted().mapToInt(Integer::intValue).toArray();
        int[] xlineValues  = xlines.stream().sorted().mapToInt(Integer::intValue).toArray();

        java.util.Map<Integer, Integer> inlineIndex = new java.util.HashMap<>();
        java.util.Map<Integer, Integer> xlineIndex  = new java.util.HashMap<>();
        for (int i = 0; i < inlineValues.length; i++) inlineIndex.put(inlineValues[i], i);
        for (int j = 0; j < xlineValues.length; j++) xlineIndex.put(xlineValues[j], j);

        int[][] grid = new int[inlineValues.length][xlineValues.length];
        for (int i = 0; i < inlineValues.length; i++) {
            java.util.Arrays.fill(grid[i], -1);
        }

        for (TraceMeta tm : metaList) {
            Integer ii = inlineIndex.get(tm.inline);
            Integer jj = xlineIndex.get(tm.xline);
            if (ii != null && jj != null) {
                grid[ii][jj] = tm.traceIndex;
            }
        }

        return new TraceGrid(inlineValues, xlineValues, grid);
    }

    private static int readIntBE(byte[] buf, int offset) {
        int b0 = buf[offset]   & 0xFF;
        int b1 = buf[offset+1] & 0xFF;
        int b2 = buf[offset+2] & 0xFF;
        int b3 = buf[offset+3] & 0xFF;
        return (b0 << 24) | (b1 << 16) | (b2 << 8) | b3;
    }

    /**
     * Escreve um SEG-Y a partir de headers e traços reconstruídos.
     *
     * Os headers (textual/binary/trace) são preservados exatamente iguais,
     * apenas os samples são escritos a partir dos TraceBlocks.
     */
    public static void write(Path path, SegyDataset template, List<TraceBlock> traces) throws IOException {
        if (template.traceHeaders.size() != traces.size()) {
            throw new IllegalArgumentException("Mismatch entre número de traceHeaders e traces");
        }
        int n = traces.size();
        int samplesPerTrace = template.samplesPerTrace;
        for (int i = 0; i < n; i++) {
            if (traces.get(i).samples().length != samplesPerTrace) {
                throw new IllegalArgumentException("Trace " + i + " tem samplesPerTrace diferente do header");
            }
        }

        try (DataOutputStream out = new DataOutputStream(
                new BufferedOutputStream(Files.newOutputStream(path)))) {

            out.write(template.textualHeader);
            out.write(template.binaryHeader);

            for (int t = 0; t < n; t++) {
                out.write(template.traceHeaders.get(t)); // 240 bytes
                float[] samples = traces.get(t).samples();
                for (float v : samples) {
                    int bits;
                    if (template.sampleFormatCode == 5) {
                        // IEEE float32
                        bits = Float.floatToIntBits(v);
                    } else if (template.sampleFormatCode == 1) {
                        // IBM float32
                        bits = floatToIbm(v);
                    } else {
                        throw new IOException("Formato de amostra não suportado na escrita: " + template.sampleFormatCode);
                    }
                    out.writeInt(bits); // big-endian
                }
            }
            out.flush();
        }
    }

    private static int readUnsignedShortBE(byte[] buf, int offset) {
        int hi = buf[offset]   & 0xFF;
        int lo = buf[offset+1] & 0xFF;
        return (hi << 8) | lo;
    }

    /**
     * Converte um float IBM 32-bit (formato SEG-Y 1) para float IEEE.
     */
    private static float ibmToFloat(int ibm) {
        if (ibm == 0) return 0.0f;

        int sign = (ibm >>> 31) & 0x1;
        int exponent = (ibm >>> 24) & 0x7F;
        int fraction = ibm & 0x00FFFFFF;

        if (fraction == 0) return 0.0f;

        double mant = fraction / (double) 0x01000000; // 24 bits
        double value = mant * Math.pow(16.0, exponent - 64);

        return sign == 0 ? (float) value : (float) -value;
    }

    /**
     * Converte float IEEE para IBM 32-bit (formato SEG-Y 1).
     * Aproximação suficiente para reconstrução e consumo por softwares SEG-Y.
     */
    private static int floatToIbm(float f) {
        if (f == 0.0f) return 0;

        int signBit = 0;
        double value = f;
        if (value < 0) {
            signBit = 1;
            value = -value;
        }

        int exponent = 64;

        // Normaliza para faixa [1/16, 1)
        while (value >= 1.0) {
            value /= 16.0;
            exponent++;
        }
        while (value < 1.0 / 16.0) {
            value *= 16.0;
            exponent--;
        }

        if (exponent <= 0) {
            // underflow para zero
            return 0;
        }

        int fraction = (int) Math.round(value * 0x01000000);
        if (fraction >= 0x01000000) {
            fraction = 0x00FFFFFF;
        }

        int ibm = (signBit << 31) | (exponent << 24) | (fraction & 0x00FFFFFF);
        return ibm;
    }

    public static final class TraceMeta {
        public final int traceIndex;  // índice na lista de traces
        public final int inline;      // valor de inline (do header)
        public final int xline;       // valor de crossline (do header)

        public TraceMeta(int traceIndex, int inline, int xline) {
            this.traceIndex = traceIndex;
            this.inline = inline;
            this.xline = xline;
        }

        @Override
        public String toString() {
            return "TraceMeta{" +
                    "traceIndex=" + traceIndex +
                    ", inline=" + inline +
                    ", xline=" + xline +
                    '}';
        }
    }

    public static final class TraceGrid {
        public final int[] inlineValues;  // valores únicos ordenados
        public final int[] xlineValues;   // valores únicos ordenados

        // grid[inlineIdx][xlineIdx] = traceIndex (ou -1 se não existe)
        public final int[][] grid;

        public TraceGrid(int[] inlineValues, int[] xlineValues, int[][] grid) {
            this.inlineValues = inlineValues;
            this.xlineValues = xlineValues;
            this.grid = grid;
        }

        public int inlineCount() { return inlineValues.length; }
        public int xlineCount()  { return xlineValues.length; }

        /** Retorna o índice de trace para (inlineIdx, xlineIdx) ou -1. */
        public int traceIndexAt(int inlineIdx, int xlineIdx) {
            return grid[inlineIdx][xlineIdx];
        }
    }

}
```

```
package com.sdc.core;

import java.io.ByteArrayOutputStream;
import java.io.IOException;
import java.util.zip.Deflater;
import java.util.zip.Inflater;

/**
 * Per-trace codec (2D container):
 *
 * Encode: min/max -> normalize to [-1,1] -> closed-loop DPCM (previous reconstructed sample as
 * predictor) -> quantization with the profile's bit depth -> Deflate. See {@link ClosedLoopQuantizer}
 * for the payload layout. Decode is the inverse and reads the bit depth from the payload.
 */
public final class TraceBlockCodec {

    private TraceBlockCodec() {}

    public static CompressedTraceBlock compress(TraceBlock tb) {
        return compress(tb, CompressionProfile.defaultHighQuality());
    }

    /**
     * Closed-loop DPCM along the time axis: each sample is predicted from the previous
     * <em>reconstructed</em> sample, and the residual is quantized with {@code profile.effectiveBits()}.
     * The bit depth is stored in the payload, so decoding needs no profile.
     */
    public static CompressedTraceBlock compress(TraceBlock tb, CompressionProfile profile) {
        float[] samples = tb.samples();
        int n = samples.length;

        float[] mm = Preprocessing.minMax(samples);
        float min = mm[0];
        float max = mm[1];
        float[] norm = Preprocessing.normalizeToMinusOneToOne(samples);

        int bits = profile.effectiveBits();
        int maxQ = ClosedLoopQuantizer.maxQ(bits);
        float inv = 1.0f / maxQ;
        int[] q = new int[n];
        float prev = 0f;
        for (int i = 0; i < n; i++) {
            q[i] = ClosedLoopQuantizer.quantize(norm[i] - prev, maxQ);
            prev = ClosedLoopQuantizer.reconstruct(prev, q[i], inv);
        }
        byte[] payload = ClosedLoopQuantizer.pack(q, bits, profile.deflaterLevel());
        return new CompressedTraceBlock(tb.traceId(), min, max, n, payload);
    }

    public static TraceBlock decompress(CompressedTraceBlock cb) {
        if (!ClosedLoopQuantizer.isClosedLoop(cb.payload())) {
            return decompressLegacy(cb);
        }
        int n = cb.samplesPerTrace();
        int bits = ClosedLoopQuantizer.storedBits(cb.payload());
        int[] q = ClosedLoopQuantizer.unpack(cb.payload(), n);
        float inv = 1.0f / ClosedLoopQuantizer.maxQ(bits);
        float[] norm = new float[n];
        float prev = 0f;
        for (int i = 0; i < n; i++) {
            prev = ClosedLoopQuantizer.reconstruct(prev, q[i], inv);
            norm[i] = prev;
        }
        float[] samples = Preprocessing.denormalizeFromMinusOneToOne(norm, cb.min(), cb.max());
        return new TraceBlock(cb.traceId(), samples);
    }

    /**
     * Decoder for payloads written before the closed-loop revision (raw zlib stream, open-loop
     * delta, 16-bit quantization). Kept so existing .sdc v2 files remain readable; files written
     * with fewer than 16 bits by that version cannot be decoded correctly because the bit depth
     * was never stored.
     */
    static TraceBlock decompressLegacy(CompressedTraceBlock cb) {
        byte[] rawBytes = inflate(cb.payload());
        short[] q = bytesToShorts(rawBytes, cb.samplesPerTrace());
        float[] deltasNorm = LinearQuantizer.decode(q);
        float[] norm = Preprocessing.deltaDecode(deltasNorm);
        float[] samples = Preprocessing.denormalizeFromMinusOneToOne(norm, cb.min(), cb.max());
        return new TraceBlock(cb.traceId(), samples);
    }

    // ---------- Helpers ----------

    static byte[] shortsToBytes(short[] data) {
        byte[] out = new byte[data.length * 2];
        int j = 0;
        for (short v : data) {
            out[j++] = (byte) (v >>> 8);
            out[j++] = (byte) (v);
        }
        return out;
    }

    static short[] bytesToShorts(byte[] data, int expectedSamples) {
        if (data.length % 2 != 0) {
            throw new IllegalArgumentException("invalid short-encoded buffer length: " + data.length);
        }
        int n = data.length / 2;
        if (expectedSamples > 0 && n != expectedSamples) {
            // em produção, talvez só logar; aqui vamos ser estritos
            throw new IllegalStateException("expected " + expectedSamples + " samples but got " + n);
        }
        short[] out = new short[n];
        int j = 0;
        for (int i = 0; i < n; i++) {
            int hi = data[j++] & 0xFF;
            int lo = data[j++] & 0xFF;
            out[i] = (short) ((hi << 8) | lo);
        }
        return out;
    }

    static byte[] deflate(byte[] input) {
        return deflate(input, java.util.zip.Deflater.BEST_COMPRESSION);
    }

    static byte[] deflate(byte[] input, int level) {
        java.util.zip.Deflater deflater = new java.util.zip.Deflater(level);
        deflater.setInput(input);
        deflater.finish();

        byte[] buffer = new byte[4096];
        try (java.io.ByteArrayOutputStream baos = new java.io.ByteArrayOutputStream(input.length)) {
            while (!deflater.finished()) {
                int count = deflater.deflate(buffer);
                baos.write(buffer, 0, count);
            }
            return baos.toByteArray();
        } catch (java.io.IOException e) {
            throw new RuntimeException("Unexpected IO error during deflate", e);
        } finally {
            deflater.end();
        }
    }


    static byte[] inflate(byte[] input) {
        Inflater inflater = new Inflater();
        inflater.setInput(input);

        byte[] buffer = new byte[4096];
        try (ByteArrayOutputStream baos = new ByteArrayOutputStream(input.length * 2)) {
            while (!inflater.finished()) {
                int count = inflater.inflate(buffer);
                if (count == 0) {
                    if (inflater.needsInput()) break;
                    // evita loop infinito em caso de dados corrompidos
                }
                baos.write(buffer, 0, count);
            }
            return baos.toByteArray();
        } catch (Exception e) {
            throw new RuntimeException("Error during inflate", e);
        } finally {
            inflater.end();
        }
    }

    
}
```

```
package com.sdc.core;

public final class VolumeBlock3DCodec {

    private VolumeBlock3DCodec() {}

    /**
     * Open-loop residual (kept for the legacy decoder): v - mean of the original neighbours
     * (i-1,j,k), (i,j-1,k), (i,j,k-1). Prefer {@link #closedLoopEncode}.
     */
    public static float[][][] residualEncode(float[][][] data) {
        int ni = data.length;
        int nj = data[0].length;
        int nt = data[0][0].length;

        float[][][] res = new float[ni][nj][nt];

        for (int i = 0; i < ni; i++) {
            for (int j = 0; j < nj; j++) {
                for (int k = 0; k < nt; k++) {

                    float v = data[i][j][k];
                    int count = 0;
                    float sum = 0f;

                    if (i > 0) { sum += data[i-1][j][k]; count++; }
                    if (j > 0) { sum += data[i][j-1][k]; count++; }
                    if (k > 0) { sum += data[i][j][k-1]; count++; }

                    float pred = (count > 0) ? (sum / count) : 0f;
                    res[i][j][k] = v - pred;
                }
            }
        }
        return res;
    }

    public static float[][][] residualDecode(float[][][] residual) {
        int ni = residual.length;
        int nj = residual[0].length;
        int nt = residual[0][0].length;

        float[][][] data = new float[ni][nj][nt];

        for (int i = 0; i < ni; i++) {
            for (int j = 0; j < nj; j++) {
                for (int k = 0; k < nt; k++) {

                    int count = 0;
                    float sum = 0f;

                    if (i > 0) { sum += data[i-1][j][k]; count++; }
                    if (j > 0) { sum += data[i][j-1][k]; count++; }
                    if (k > 0) { sum += data[i][j][k-1]; count++; }

                    float pred = (count > 0) ? (sum / count) : 0f;
                    data[i][j][k] = residual[i][j][k] + pred;
                }
            }
        }
        return data;
    }

    /**
     * Closed-loop 3D DPCM. Scan order is (i, j, k); the predictor is the mean of the already
     * <em>reconstructed</em> neighbours (i-1,j,k), (i,j-1,k), (i,j,k-1) — the same neighbourhood as
     * {@link #residualEncode}, but evaluated on reconstructed values so the encoder and decoder
     * stay in lock-step and quantization error does not accumulate.
     *
     * @return quantization indices in flatten order
     */
    public static int[] closedLoopEncode(float[][][] norm, int bits) {
        int ni = norm.length, nj = norm[0].length, nt = norm[0][0].length;
        int maxQ = ClosedLoopQuantizer.maxQ(bits);
        float inv = 1.0f / maxQ;
        float[][][] rec = new float[ni][nj][nt];
        int[] q = new int[ni * nj * nt];
        int idx = 0;
        for (int i = 0; i < ni; i++) {
            for (int j = 0; j < nj; j++) {
                for (int k = 0; k < nt; k++) {
                    float pred = predict(rec, i, j, k);
                    int qi = ClosedLoopQuantizer.quantize(norm[i][j][k] - pred, maxQ);
                    q[idx++] = qi;
                    rec[i][j][k] = ClosedLoopQuantizer.reconstruct(pred, qi, inv);
                }
            }
        }
        return q;
    }

    /** Inverse of {@link #closedLoopEncode}. Returns normalized samples in [-1,1]. */
    public static float[][][] closedLoopDecode(int[] q, int ni, int nj, int nt, int bits) {
        if (q.length != ni * nj * nt) {
            throw new IllegalArgumentException("index count mismatch");
        }
        float inv = 1.0f / ClosedLoopQuantizer.maxQ(bits);
        float[][][] rec = new float[ni][nj][nt];
        int idx = 0;
        for (int i = 0; i < ni; i++) {
            for (int j = 0; j < nj; j++) {
                for (int k = 0; k < nt; k++) {
                    float pred = predict(rec, i, j, k);
                    rec[i][j][k] = ClosedLoopQuantizer.reconstruct(pred, q[idx++], inv);
                }
            }
        }
        return rec;
    }

    private static float predict(float[][][] rec, int i, int j, int k) {
        int count = 0;
        float sum = 0f;
        if (i > 0) { sum += rec[i - 1][j][k]; count++; }
        if (j > 0) { sum += rec[i][j - 1][k]; count++; }
        if (k > 0) { sum += rec[i][j][k - 1]; count++; }
        return (count > 0) ? (sum / count) : 0f;
    }

    public static float[] flatten3D(float[][][] data) {
        int ni = data.length;
        int nj = data[0].length;
        int nt = data[0][0].length;
        float[] out = new float[ni * nj * nt];
        int idx = 0;
        for (int i = 0; i < ni; i++) {
            for (int j = 0; j < nj; j++) {
                System.arraycopy(data[i][j], 0, out, idx, nt);
                idx += nt;
            }
        }
        return out;
    }

    public static float[][][] unflatten3D(float[] flat, int ni, int nj, int nt) {
        if (flat.length != ni * nj * nt) {
            throw new IllegalArgumentException("flat length mismatch");
        }
        float[][][] data = new float[ni][nj][nt];
        int idx = 0;
        for (int i = 0; i < ni; i++) {
            for (int j = 0; j < nj; j++) {
                System.arraycopy(flat, idx, data[i][j], 0, nt);
                idx += nt;
            }
        }
        return data;
    }
}
```

```
package com.sdc.core;

import java.util.Arrays;

public final class VolumeBlock3DCompressor {

    private VolumeBlock3DCompressor() {}

    /**
     * Bloco comprimido:
     *  - metadata do cubo (posições e dimensões)
     *  - min/max (para normalização)
     *  - payload comprimido (shorts quantizados + Deflate)
     */
    public static final class CompressedVolumeBlock3D {
        public final VolumeBlock3D blockMeta;
        public final float min;
        public final float max;
        public final byte[] payload;

        public CompressedVolumeBlock3D(VolumeBlock3D blockMeta,
                                       float min,
                                       float max,
                                       byte[] payload) {
            this.blockMeta = blockMeta;
            this.min = min;
            this.max = max;
            this.payload = payload;
        }
    }

    /**
     * Compressão de um cubo 3D:
     *
     *  1) calcula min/max do cubo
     *  2) normaliza para [-1,1]
     *  3) closed-loop 3D DPCM, quantized with the profile's bit depth
     *  4) self-describing payload (bit depth stored) + Deflate with the profile's level
     */
    public static CompressedVolumeBlock3D compressBlock(VolumeBlock3D block,
                                                        CompressionProfile profile) {
        float[][][] data = block.samples;

        int ni = data.length;
        int nj = data[0].length;
        int nt = data[0][0].length;

        // 1) min/max do cubo inteiro
        float min = Float.POSITIVE_INFINITY;
        float max = Float.NEGATIVE_INFINITY;

        for (int i = 0; i < ni; i++) {
            for (int j = 0; j < nj; j++) {
                for (int k = 0; k < nt; k++) {
                    float v = data[i][j][k];
                    if (v < min) min = v;
                    if (v > max) max = v;
                }
            }
        }

        // 2) normaliza para [-1,1]
        float range = max - min;
        float[][][] norm = new float[ni][nj][nt];

        if (range == 0f) {
            // cubo todo constante
            for (int i = 0; i < ni; i++) {
                for (int j = 0; j < nj; j++) {
                    Arrays.fill(norm[i][j], 0f);
                }
            }
        } else {
            for (int i = 0; i < ni; i++) {
                for (int j = 0; j < nj; j++) {
                    for (int k = 0; k < nt; k++) {
                        float v = data[i][j][k];
                        float zeroToOne = (v - min) / range;   // [0,1]
                        norm[i][j][k] = zeroToOne * 2f - 1f;   // [-1,1]
                    }
                }
            }
        }

        // 3) closed-loop 3D DPCM + quantization (bit depth stored in the payload)
        int[] q = VolumeBlock3DCodec.closedLoopEncode(norm, profile.effectiveBits());

        // 4) self-describing payload + Deflate
        byte[] compressed = ClosedLoopQuantizer.pack(q, profile.effectiveBits(), profile.deflaterLevel());

        return new CompressedVolumeBlock3D(block, min, max, compressed);
    }

    /**
     * Descompressão de um cubo 3D:
     *
     *  closed-loop payloads: bit depth read from the payload (profile ignored)
     *  legacy payloads: open-loop residual decoded with the profile's bit depth
     *  then denormalize with min/max
     */
    public static float[][][] decompressBlock(CompressedVolumeBlock3D cb,
                                              CompressionProfile profile) {
        VolumeBlock3D meta = cb.blockMeta;

        int ni = meta.inlineCount;
        int nj = meta.xlineCount;
        int nt = meta.timeCount;

        float[][][] norm;
        if (ClosedLoopQuantizer.isClosedLoop(cb.payload)) {
            // bit depth comes from the payload; the profile argument is ignored
            int bits = ClosedLoopQuantizer.storedBits(cb.payload);
            int[] q = ClosedLoopQuantizer.unpack(cb.payload, ni * nj * nt);
            norm = VolumeBlock3DCodec.closedLoopDecode(q, ni, nj, nt, bits);
        } else {
            // legacy payload (open-loop residual, bit depth taken from the caller's profile)
            byte[] rawBytes = TraceBlockCodec.inflate(cb.payload);
            short[] q = TraceBlockCodec.bytesToShorts(rawBytes, ni * nj * nt);
            float[] flat = LinearQuantizer.decode(q, profile.effectiveBits());
            float[][][] residual = VolumeBlock3DCodec.unflatten3D(flat, ni, nj, nt);
            norm = VolumeBlock3DCodec.residualDecode(residual);
        }

        // 6) denormaliza para escala original
        float[][][] data = new float[ni][nj][nt];
        float min = cb.min;
        float max = cb.max;
        float range = max - min;

        if (range == 0f) {
            // cubo constante
            for (int i = 0; i < ni; i++) {
                for (int j = 0; j < nj; j++) {
                    Arrays.fill(data[i][j], min);
                }
            }
        } else {
            for (int i = 0; i < ni; i++) {
                for (int j = 0; j < nj; j++) {
                    for (int k = 0; k < nt; k++) {
                        float v = norm[i][j][k];     // [-1,1]
                        float zeroToOne = (v + 1f) / 2f; // [0,1]
                        data[i][j][k] = min + zeroToOne * range;
                    }
                }
            }
        }

        return data;
    }
}
```

```
package com.sdc.core;

import java.util.LinkedHashMap;
import java.util.Map;

/**
 * Cache LRU para blocos de volume 3D descomprimidos.
 * Evita re-decodificar o mesmo bloco múltiplas vezes durante navegação de slices.
 */
public final class VolumeBlockCache {

    private final int maxCapacity;
    private final LinkedHashMap<String, float[][][]> cache;

    public VolumeBlockCache(int maxCapacity) {
        if (maxCapacity < 1) {
            throw new IllegalArgumentException("maxCapacity must be >= 1");
        }
        this.maxCapacity = maxCapacity;
        this.cache = new LinkedHashMap<String, float[][][]>(maxCapacity, 0.75f, true) {
            @Override
            protected boolean removeEldestEntry(Map.Entry eldest) {
                return size() > VolumeBlockCache.this.maxCapacity;
            }
        };
    }

    /** Retorna a chave do bloco (coordenadas + arquivo). */
    public static String key(String filePath, int ii, int jj, int tt) {
        return filePath + "|" + ii + "," + jj + "," + tt;
    }

    /** Tenta obter bloco do cache. */
    public float[][][] get(String key) {
        synchronized (cache) {
            return cache.get(key);
        }
    }

    /** Armazena bloco no cache. */
    public void put(String key, float[][][] data) {
        synchronized (cache) {
            cache.put(key, data);
        }
    }

    /** Limpa o cache. */
    public void clear() {
        synchronized (cache) {
            cache.clear();
        }
    }

    /** Retorna tamanho atual do cache. */
    public int size() {
        synchronized (cache) {
            return cache.size();
        }
    }

    /** Retorna capacidade máxima. */
    public int capacity() {
        return maxCapacity;
    }
}
```

```
     */
    private Path resolveSdcPath(String sdcPath) {
        if (sdcPath == null || sdcPath.isBlank()) {
            throw new IllegalArgumentException("sdcPath must not be blank");
        }
        boolean isBasename = !sdcPath.contains("/") && !sdcPath.contains("\\");
        if (isBasename && (dataRoot == null || dataRoot.isBlank())) {
            throw new IllegalArgumentException(
                "Received basename '" + sdcPath + "' but sdc.data.root is not configured");
        }
        return isBasename ? Path.of(dataRoot).resolve(sdcPath) : Path.of(sdcPath);
    }

    /** Returns basenames of files with the given extension under dataRoot. Empty list if root is blank. */
    public List<String> listFiles(String ext) {
        if (dataRoot == null || dataRoot.isBlank()) {
            return Collections.emptyList();
        }
        Path root = Path.of(dataRoot);
        if (!Files.isDirectory(root)) {
            return Collections.emptyList();
        }
        String suffix = "." + ext.toLowerCase();
        try (var stream = Files.list(root)) {
            return stream
                    .filter(p -> !Files.isDirectory(p))
                    .map(p -> p.getFileName().toString())
                    .filter(name -> name.toLowerCase().endsWith(suffix))
                    .sorted()
                    .collect(Collectors.toList());
        } catch (IOException e) {
            return Collections.emptyList();
        }
    }

    public TraceSliceResponse traceSlice(TraceSliceRequest req) throws IOException {
        Path path = resolveSdcPath(req.sdcPath);
        try (DataInputStream in = new DataInputStream(
                new BufferedInputStream(Files.newInputStream(path)))) {

            SdcHeader header = SdcHeader.read(in);
            if (header.version() != 2) {
                throw new IOException("Trace slice requer .sdc v2 (got " + header.version() + ")");
            }

            int traceStart = req.traceStart == null ? 0 : Math.max(0, req.traceStart);
            int traceCountReq = req.traceCount == null ? 1 : req.traceCount;
            if (traceCountReq < 1) traceCountReq = 1;

            int traceEnd = Math.min(header.traceCount(), traceStart + traceCountReq);
            int traceCount = Math.max(0, traceEnd - traceStart);

            int sampleStart = req.sampleStart == null ? 0 : Math.max(0, req.sampleStart);
            int maxSampleCount = Math.max(0, header.samplesPerTrace() - sampleStart);
            int sampleCountReq = req.sampleCount == null ? maxSampleCount : req.sampleCount;
            if (sampleCountReq < 0) sampleCountReq = 0;
            int sampleCount = Math.min(sampleCountReq, maxSampleCount);

            TraceSliceResponse resp = new TraceSliceResponse();
            resp.sdcPath = req.sdcPath;
            resp.version = header.version();
            resp.traceStart = traceStart;
            resp.traceCount = traceCount;
            resp.sampleStart = sampleStart;
            resp.sampleCount = sampleCount;
            resp.traceIds = new int[traceCount];
            resp.samples = new float[traceCount][sampleCount];

            if (traceCount == 0 || sampleCount == 0) {
                return resp;
            }

            for (int t = 0; t < header.traceCount(); t++) {
                int traceId = in.readInt();
                float min = in.readFloat();
                float max = in.readFloat();
                int payloadSize = in.readInt();

                if (t < traceStart || t >= traceEnd) {
                    in.skipNBytes(payloadSize);
                    continue;
                }

                byte[] payload = in.readNBytes(payloadSize);
                CompressedTraceBlock cb = new CompressedTraceBlock(
                        traceId, min, max, header.samplesPerTrace(), payload);
                TraceBlock tb = TraceBlockCodec.decompress(cb);

                int outIdx = t - traceStart;
                resp.traceIds[outIdx] = traceId;
                System.arraycopy(tb.samples(), sampleStart, resp.samples[outIdx], 0, sampleCount);
            }

            return resp;
        }
    }

    public VolumeSliceResponse volumeSlice(VolumeSliceRequest req) throws IOException {
        CompressionProfile profile = resolveProfile(req.profile, req.fidelityPercent);

        Path resolvedPath = resolveSdcPath(req.sdcPath);
        String cacheKey = resolvedPath.toAbsolutePath().toString();
        VolumeBlockCache cache = cachesByPath.computeIfAbsent(
                cacheKey,
                k -> new VolumeBlockCache(cacheBlockCapacity)
        );

        String axis = req.axis == null ? "TIME" : req.axis.trim().toUpperCase();
        int index = req.index == null ? 0 : req.index;
        int start0 = req.start0 == null ? -1 : req.start0;
        int count0 = req.count0 == null ? -1 : req.count0;
        int start1 = req.start1 == null ? -1 : req.start1;
        int count1 = req.count1 == null ? -1 : req.count1;

        Sdc3DFileReader.Sdc3DSlice slice = Sdc3DFileReader.readSlice(
                resolvedPath,
                profile,
                axis,
                index,
                start0,
                count0,
                start1,
                count1,
                cache
        );

        float min = Float.POSITIVE_INFINITY;
        float max = Float.NEGATIVE_INFINITY;
        for (int i = 0; i < slice.count0; i++) {
            for (int j = 0; j < slice.count1; j++) {
                float v = slice.data[i][j];
                if (v < min) min = v;
                if (v > max) max = v;
            }
        }

        VolumeSliceResponse resp = new VolumeSliceResponse();
        resp.sdcPath = req.sdcPath;
        resp.version = 3;
        resp.axis = slice.axis;
        resp.index = slice.index;
        resp.inlineCount = slice.inlineCount;
        resp.xlineCount = slice.xlineCount;
        resp.timeCount = slice.timeCount;
        resp.dim0 = slice.count0;
        resp.dim1 = slice.count1;
        resp.data = slice.data;
        resp.start0 = slice.start0;
        resp.count0 = slice.count0;
        resp.start1 = slice.start1;
        resp.count1 = slice.count1;
        resp.min = min;
        resp.max = max;

        return resp;
    }

    private static CompressionProfile resolveProfile(String profileName, Double fidelityPercent) {
        if (fidelityPercent != null) {

        if (profileName != null) {

    public void clearCache(String sdcPath) {
        VolumeBlockCache cache = cachesByPath.remove(sdcPath);
        if (cache != null) {
            cache.clear();
        }
    }

    public CacheInfo getCacheInfo(String sdcPath) {
        VolumeBlockCache cache = cachesByPath.get(sdcPath);
        if (cache == null) {
            return new CacheInfo(0, cacheBlockCapacity);
        }

    public TraceHeadersResponse traceHeaders(TraceHeadersRequest req) throws IOException {
        Path path = resolveSdcPath(req.sdcPath);
        try (DataInputStream in = new DataInputStream(
                new BufferedInputStream(Files.newInputStream(path)))) {

            SdcHeader header = SdcHeader.read(in);

            TraceHeadersResponse resp = new TraceHeadersResponse();
            resp.sdcPath = req.sdcPath;
            resp.version = header.version();
            resp.traceCount = header.traceCount();

            // Ler headers dos traces do arquivo .sdc
            TraceHeader[] headers = new TraceHeader[header.traceCount()];

            if (header.version() == 2) {
                // Para .sdc v2, ler cada trace comprimido e extrair headers
                for (int i = 0; i < header.traceCount(); i++) {
                    int traceNum = in.readInt();
                    int inlineNum = in.readInt();
                    int xlineNum = in.readInt();

                    headers[i] = new TraceHeader(traceNum, inlineNum, xlineNum);

                    // Skip trace data (CompressedTraceBlock)
                    int dataSize = in.readInt();
                    in.skipBytes(dataSize);
                }
            } else if (header.version() == 3) {
                // Para .sdc v3, ler metadata de dimensões e blocos
                int inlineCount = in.readInt();
                int xlineCount = in.readInt();
                int timeCount = in.readInt();
                int blockInline = in.readInt();
                int blockXline = in.readInt();
                int blockTime = in.readInt();
                int blockCount = in.readInt();

                // Para 3D, gerar headers baseado na grid
                int traceIdx = 0;
                for (int inline = 0; inline < inlineCount && traceIdx < header.traceCount(); inline++) {
                    for (int xline = 0; xline < xlineCount && traceIdx < header.traceCount(); xline++) {
                        headers[traceIdx] = new TraceHeader(
                            traceIdx + 1,  // traceNumber (1-indexed)
                            inline + 1,     // inline (1-indexed)
                            xline + 1       // crossline (1-indexed)
                        );
                        traceIdx++;
                    }
                }
            }

            resp.headers = headers;
            return resp;
        }
    }

    public static final class CacheInfo {
        public final int blocksInCache;
        public final int blockCapacity;

        public CacheInfo(int blocksInCache, int blockCapacity) {
            this.blocksInCache = blocksInCache;
            this.blockCapacity = blockCapacity;
        }
    }
```

```
package com.sdc.ai.nn;

import java.util.stream.IntStream;

/**
 * 3x3 (or any k x k) 2D convolution with TensorFlow/Keras "same" padding semantics.
 *
 * <p>Weights are in Keras HWIO order: {@code w[((ky*kw + kx)*cin + ci)*cout + co]}.
 * For stride s and input size n the output size is ceil(n/s); the total padding is
 * {@code max((out-1)*s + k - n, 0)} with {@code floor(total/2)} on the leading side, which is
 * exactly what TensorFlow does.</p>
 *
 * <p>Rows are computed in parallel, but every output value is accumulated in a fixed order, so
 * results are bit-identical regardless of the number of threads — the codec relies on this
 * because the encoder and the decoder must reconstruct exactly the same prediction.</p>
 */
public final class Conv2D implements Layer {
    final int kh, kw, cin, cout, stride;
    final float[] weights;
    final float[] bias;

    public Conv2D(int kh, int kw, int cin, int cout, int stride, float[] weights, float[] bias) {
        if (weights.length != kh * kw * cin * cout) throw new IllegalArgumentException("weights size");
        if (bias.length != cout) throw new IllegalArgumentException("bias size");
        this.kh = kh;
        this.kw = kw;
        this.cin = cin;
        this.cout = cout;
        this.stride = stride;
        this.weights = weights;
        this.bias = bias;
    }

    static int outSize(int n, int s) {
        return (n + s - 1) / s;
    }

    static int padBefore(int n, int k, int s) {
        int out = outSize(n, s);
        int total = Math.max((out - 1) * s + k - n, 0);
        return total / 2;
    }

    @Override
    public Tensor3 apply(Tensor3 in) {
        if (in.c != cin) throw new IllegalArgumentException("expected " + cin + " channels, got " + in.c);
        int oh = outSize(in.h, stride), ow = outSize(in.w, stride);
        int pt = padBefore(in.h, kh, stride), pl = padBefore(in.w, kw, stride);
        Tensor3 out = new Tensor3(oh, ow, cout);
        IntStream.range(0, oh).parallel().forEach(oy -> {
            float[] acc = new float[cout];
            for (int ox = 0; ox < ow; ox++) {
                System.arraycopy(bias, 0, acc, 0, cout);
                for (int ky = 0; ky < kh; ky++) {
                    int iy = oy * stride + ky - pt;
                    if (iy < 0 || iy >= in.h) continue;
                    for (int kx = 0; kx < kw; kx++) {
                        int ix = ox * stride + kx - pl;
                        if (ix < 0 || ix >= in.w) continue;
                        int inBase = (iy * in.w + ix) * cin;
                        int wBase = (ky * kw + kx) * cin * cout;
                        for (int ci = 0; ci < cin; ci++) {
                            float v = in.data[inBase + ci];
                            if (v == 0f) continue;
                            int wb = wBase + ci * cout;
                            for (int co = 0; co < cout; co++) {
                                acc[co] += v * weights[wb + co];
                            }
                        }
                    }
                }
                System.arraycopy(acc, 0, out.data, (oy * ow + ox) * cout, cout);
            }
        });
        return out;
    }
}
```

```
/** f(x) = x for x >= 0, alpha*x otherwise (Keras LeakyReLU). */
public final class LeakyRelu implements Layer {
    final float alpha;

    public LeakyRelu(float alpha) {
        this.alpha = alpha;
    }

    @Override
    public Tensor3 apply(Tensor3 in) {
        float[] o = new float[in.data.length];
        for (int i = 0; i < o.length; i++) {
            float v = in.data[i];
            o[i] = v >= 0f ? v : alpha * v;
        }
        return new Tensor3(in.h, in.w, in.c, o);
    }
}
```

```
package com.sdc.ai.nn;

import java.io.IOException;
import java.io.InputStream;
import java.nio.ByteBuffer;
import java.nio.ByteOrder;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;

import java.security.NoSuchAlgorithmException;

import java.util.Arrays;

/**
 * A convolutional autoencoder exported by {@code sdc-ai/training/train_autoencoder.py} in the
 * dependency-free ".sdcnn" format, executed in pure Java (no TensorFlow runtime needed).
 *
 * <p>Format (little-endian): magic {@code "SDCNN1\0\0"}, int version (=1), int latentChannels,
 * int downsampleFactor, int metaLength, UTF-8 JSON metadata, then the encoder and the decoder,
 * each as {@code int layerCount} followed by layers: {@code int type} (1 = conv, 2 = leaky ReLU,
 * 3 = 2x upsample); conv: {@code int kh, kw, cin, cout, stride, float[kh*kw*cin*cout] weights
 * (HWIO), float[cout] bias}; leaky ReLU: {@code float alpha}.</p>
 *
 * <p>{@link #sha256()} identifies the exact weights; the neural codec stores it in every payload
 * so a file can never be decoded with a different model.</p>
 */
public final class NeuralModel {

    private static final byte[] MAGIC = "SDCNN1\0\0".getBytes(StandardCharsets.US_ASCII);

    private final int latentChannels;
    private final int factor;
    private final String metadataJson;
    private final List<Layer> encoder;
    private final List<Layer> decoder;
    private final byte[] sha256;

    private NeuralModel(int latentChannels, int factor, String metadataJson,
                        List<Layer> encoder, List<Layer> decoder, byte[] sha256) {
        this.latentChannels = latentChannels;
        this.factor = factor;
        this.metadataJson = metadataJson;
        this.encoder = encoder;
        this.decoder = decoder;
        this.sha256 = sha256;
    }

    public static NeuralModel load(Path path) throws IOException {
        return parse(Files.readAllBytes(path));
    }

    public static NeuralModel load(InputStream in) throws IOException {
        return parse(in.readAllBytes());
    }

    public static NeuralModel parse(byte[] bytes) throws IOException {
        ByteBuffer b = ByteBuffer.wrap(bytes).order(ByteOrder.LITTLE_ENDIAN);
        byte[] magic = new byte[MAGIC.length];
        b.get(magic);
        if (!Arrays.equals(magic, MAGIC)) throw new IOException("not an .sdcnn model");
        int version = b.getInt();
        if (version != 1) throw new IOException("unsupported .sdcnn version " + version);
        int latent = b.getInt();
        int factor = b.getInt();
        byte[] meta = new byte[b.getInt()];
        b.get(meta);
        List<Layer> enc = readLayers(b);
        List<Layer> dec = readLayers(b);
        if (b.hasRemaining()) throw new IOException("trailing bytes in model file");
        byte[] sha;
        try {
            sha = MessageDigest.getInstance("SHA-256").digest(bytes);
        } catch (NoSuchAlgorithmException e) {
            throw new IllegalStateException(e);
        }
        return new NeuralModel(latent, factor, new String(meta, StandardCharsets.UTF_8), enc, dec, sha);
    }

    private static List<Layer> readLayers(ByteBuffer b) throws IOException {
        int n = b.getInt();
        List<Layer> layers = new ArrayList<>(n);
        for (int i = 0; i < n; i++) {
            int type = b.getInt();
            switch (type) {
                case 1 -> {
                    int kh = b.getInt(), kw = b.getInt(), cin = b.getInt(), cout = b.getInt(), stride = b.getInt();
                    float[] w = new float[kh * kw * cin * cout];
                    b.asFloatBuffer().get(w);
                    b.position(b.position() + w.length * 4);
                    float[] bias = new float[cout];
                    b.asFloatBuffer().get(bias);
                    b.position(b.position() + bias.length * 4);
                    layers.add(new Conv2D(kh, kw, cin, cout, stride, w, bias));
                }
                case 2 -> layers.add(new LeakyRelu(b.getFloat()));
                case 3 -> layers.add(new UpSample2());
                default -> throw new IOException("unknown layer type " + type);
            }
        }
        return layers;
    }

    /** (H, W, 1) normalized section -> (H/factor, W/factor, latentChannels) real-valued latents. */
    public Tensor3 encode(Tensor3 x) {
        if (x.h % factor != 0 || x.w % factor != 0) {
            throw new IllegalArgumentException("input must be a multiple of " + factor + ": " + x.h + "x" + x.w);
        }
        return run(encoder, x);
    }

    /** Latents -> reconstructed (H, W, 1) section. */
    public Tensor3 decode(Tensor3 y) {
        return run(decoder, y);
    }

    private static Tensor3 run(List<Layer> layers, Tensor3 t) {
        for (Layer l : layers) t = l.apply(t);
        return t;
    }

    public int latentChannels() {
        return latentChannels;
    }

    public int factor() {
        return factor;
    }

    public String metadataJson() {
        return metadataJson;
    }

    public byte[] sha256() {
        return sha256.clone();
    }

    public String sha256Hex() {
        return HexFormat.of().formatHex(sha256);
    }
}
```

```
package com.sdc.ai.nn;

/** Dense float tensor in HWC layout (height, width, channels), row-major. */
public final class Tensor3 {
    public final int h;
    public final int w;
    public final int c;
    public final float[] data;

    public Tensor3(int h, int w, int c) {
        this(h, w, c, new float[h * w * c]);
    }

    public Tensor3(int h, int w, int c, float[] data) {
        if (data.length != h * w * c) {
            throw new IllegalArgumentException("data length " + data.length + " != " + h + "x" + w + "x" + c);
        }
        this.h = h;
        this.w = w;
        this.c = c;
        this.data = data;
    }

    public float get(int y, int x, int ch) {
        return data[(y * w + x) * c + ch];
    }
}
```

```
package com.sdc.ai.nn;

/** Nearest-neighbour 2x upsampling (Keras UpSampling2D(2), interpolation="nearest"). */
public final class UpSample2 implements Layer {
    @Override
    public Tensor3 apply(Tensor3 in) {
        Tensor3 out = new Tensor3(in.h * 2, in.w * 2, in.c);
        for (int y = 0; y < out.h; y++) {
            for (int x = 0; x < out.w; x++) {
                System.arraycopy(in.data, ((y / 2) * in.w + (x / 2)) * in.c, out.data, (y * out.w + x) * in.c, in.c);
            }
        }
        return out;
    }
}
```
