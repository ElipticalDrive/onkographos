# MRI3D

A local Windows MRI explorer with linked anatomical slices, volume rendering, user-guided tissue segmentation and physical-scale mesh export. Version 1.0.0 is for personal exploration.

## Run the Windows app

Open **`dist\MRI3D\MRI3D.exe`**. Keep the entire `MRI3D` folder together: its `_internal` folder contains the Python runtime and imaging dependencies. No separate Python installation, account, server or network connection is required. The executable is unsigned.

Choose **Import DICOM**, select a scan folder, select a compatible series and click **Open selected series**. The folder picker starts at `G:\Vibing\MRI3D\DICOMIMAGES`. It does not import or modify source files automatically.

## Explore and create a model

1. Adjust **Window** and **Level**, or use **Auto contrast**. Scroll over a slice to move through it. Ctrl + wheel zooms; right-drag pans. Clicking a slice moves all crosshairs and places a seed.
2. Rotate the 3D view by dragging; use the wheel to zoom. Volume opacity and clipping help reveal structures. This initial view represents MRI intensity, not automatically identified anatomy.
3. Scroll down the left panel to **Tissue layers**. Add a layer such as Bone, Muscle or a descriptive label. Each layer has its own color, visibility and opacity.
4. Click **Navigate / seed**, place a seed inside a region, read its intensity, and set lower and upper intensity limits. **Grow from seed** selects a connected region; **Select threshold range** selects matching voxels throughout the volume. MRI intensities have no universal tissue thresholds. Review the result in all planes.
5. Use **Brush** or **Erase** to refine the selection. Brush radius is measured in millimeters and applies to the current displayed slice. **Keep largest** removes disconnected components; **Fill holes** fills enclosed 3D cavities. Undo / redo retains up to 20 changes per layer.
6. **Generate / update surface** creates a mesh. Changing the mask or smoothing option invalidates its old surface. Smoothing affects the surface, never the saved mask. Rebuild before exporting.
7. **Save project** stores source references, masks, colors and display settings. **Export model** exports the selected generated surface as colored PLY or binary STL. Exports use DICOM LPS coordinates in millimeters. Clipping changes the display only; exported meshes remain complete.

**LPS axes:** +X points toward the patient's left, +Y posterior, +Z superior. Slice orientation letters describe the patient, not the screen. Exports include a companion JSON file documenting units, coordinates and bounds; STL itself does not encode units.

## Layouts, 3D tools and fusion

- **Layouts:** switch between Quad, 3D and single-plane layouts from the header, press Space to cycle, Esc to return to Quad, or double-click a view to maximize it. F1 lists all shortcuts.
- **3D view:** Top / Front / Side presets, **Orbit** (O) for a continuous turntable, **Scale** (C) for millimeter LPS cube axes, and **3D** for red/cyan anaglyph stereo. Each layer can be drawn as a shaded surface, wireframe or point cloud; the choice is saved in the project.
- **Contrast presets:** Auto, Soft Tissue, Bone and Full are starting points derived from the volume's intensity range, not calibrated tissue windows.
- **Segmentation helpers:** **Auto-fit limits** sets lower / upper limits to ±15% (at least ±20) around the seed intensity. **Filter noise** removes disconnected components smaller than 25 voxels.
- **Fusion:** select two or three orthogonal series (Ctrl-click, or **Auto-select orthogonal trio**) and click **Fuse**. Each series is resampled onto a shared isotropic LPS grid (0.25–0.6 mm, capped at 40 million voxels) and blended with gradient-weighted averaging (sharper in-plane detail counts more) after per-series intensity normalization. The result looks sharper than any single stack, but it is still interpolation and not acquired resolution; series from different sequences or with patient motion between them will not align. Fused projects store their component series and rebuild the fused volume when reopened.

## Projects and backups

A project consists of a `.mri3d` JSON manifest and its neighboring `.mri3d-data` folder containing compressed `.mha` masks. Keep both, along with the original DICOM scans. Saving commits the manifest atomically only after all new masks have been written. Previous mask generations are retained so interrupted saves cannot destroy the last saved project; repeated saves therefore consume additional disk space. A Save As to a new filename creates a compact current copy.

If source scans move, opening the project asks for their new folder. Relinking requires the same series and SOP instance identifiers and checks geometry before restoring masks. Save the project to keep updated source paths. Masks are tied to their source series; loading a different sequence does not carry labels across. Meshes are regenerated from masks after reopening, so a stale surface cannot be reused accidentally.

No scans, screenshots or projects are sent anywhere. Project files contain local paths and DICOM identifiers and should be treated as private. Test artifacts using your scans are excluded from Git and the application package.

## Supported inputs and limits

- Single-frame monochrome MRI DICOM stacks, including the supplied older implicit-VR files without a Part 10 preamble. JPEG / JPEG-LS and JPEG 2000 decoder plugins are bundled; availability also depends on the precise codec variant.
- Grouping uses series UID, orientation, dimensions, pixel spacing, echo, temporal position and image component. Slice order comes from physical positions. Scout/localizer groups are excluded; duplicate positions, nonuniform slice spacing and in-plane shifts are rejected with an explanation.
- Oblique stacks are resampled into a patient-aligned LPS working grid using linear interpolation. Original geometry is retained in projects. Label masks use the working grid. A 160-million-voxel safety limit applies to source and resampled volumes.
- Enhanced multiframe MRI, CT, registration between series (fusion assumes they are already aligned), anatomical AI, DICOM SEG export, PACS and clinical validation are outside this version.
- The supplied 320 files produce 18 geometry groups: 15 reconstructable sequences and three localizer orientations. Reconstructable slice spacing is approximately 2.7–4.6 mm. The gaps and thickness limit surface fidelity; interpolation is not recovered detail.
- Dark MRI regions near metal are not reliable screw geometry. User labels should describe visible evidence without asserting accurate implant shape. This app does not diagnose conditions or automatically reconstruct screws.
- Long operations run in workers. Cancel takes effect at the next safe processing point; some native decoder, file-write and mesh stages finish their current stage first. An already committed save or export reports success rather than pretending it was cancelled.

## Development

Use Python 3.11 x64 on Windows. From this directory:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\run.ps1
.\.venv\Scripts\python.exe -m pytest -q
.\build.ps1
```

Command-line entry points work from source or the packaged executable:

```powershell
.\dist\MRI3D\MRI3D.exe --folder 'G:\Vibing\MRI3D\DICOMIMAGES'
.\dist\MRI3D\MRI3D.exe --project 'C:\path\My MRI.mri3d'
.\dist\MRI3D\MRI3D.exe --folder 'G:\Vibing\MRI3D\DICOMIMAGES' --smoke-test artifacts\packaged-smoke
```

The smoke-test option creates a clearly labeled technical selection, exercises editing / undo, linked views, clipping, surface export, project roundtrip and rendering, writes screenshots and a JSON report, then exits. It does not claim its test selection is anatomical. Omitting `--folder` uses a synthetic volume and skips DICOM project roundtrip.

## Code organization

- `mri3d/imaging.py`: DICOM validation, reconstruction, LPS geometry and segmentation.
- `mri3d/models.py`, `projects.py`: layer history, surface generation, exports and atomic project saves.
- `mri3d/views.py`, `app.py`: slice canvases, VTK rendering, desktop workflow and background jobs.
- `tests/`: synthetic geometry, failure handling, segmentation, export and persistence checks.

class Worker(QObject):
    progress = Signal(int, str)
    result = Signal(object)
    error = Signal(str)
    finished = Signal()

    def __init__(self, fn):
        super().__init__()
        self.fn = fn
        self.job = Job(self.progress.emit)

    @Slot()
    def run(self):
        try:
            self.result.emit(self.fn(self.job))
        except Cancelled:
            self.error.emit("")
        except Exception as exc:
            if self.job.cancelled.is_set():
                self.error.emit("")
            else:
                traceback.print_exc()
                self.error.emit(str(exc))
        finally:
            self.finished.emit()

    def set_layout_mode(self, mode):
        self.layout_mode = mode
        if mode == "quad":
            for w in self.view_widgets:
                w.show()
            self.maximized_widget = None
        elif mode == "axial":
            self._show_only_view(self.panels[0])
        elif mode == "coronal":
            self._show_only_view(self.panels[1])
        elif mode == "sagittal":
            self._show_only_view(self.panels[2])
        elif mode == "3d":
            self._show_only_view(self.scene)
        self.update_layout_buttons()

    def _show_only_view(self, target):
        for w in self.view_widgets:
            w.setVisible(w is target)
        self.maximized_widget = target

    def toggle_maximize(self, target):
        if self.maximized_widget is target:
            self.set_layout_mode("quad")
        else:
            self._show_only_view(target)
            if target is self.panels[0]:
                self.layout_mode = "axial"
            elif target is self.panels[1]:
                self.layout_mode = "coronal"
            elif target is self.panels[2]:
                self.layout_mode = "sagittal"
            elif target is self.scene:
                self.layout_mode = "3d"
            self.update_layout_buttons()

    def cycle_layout(self):
        modes = ["quad", "3d", "axial", "coronal", "sagittal"]
        curr_idx = modes.index(self.layout_mode) if self.layout_mode in modes else 0
        next_mode = modes[(curr_idx + 1) % len(modes)]
        self.set_layout_mode(next_mode)

    def update_layout_buttons(self):
        if hasattr(self, "layout_buttons"):
            for mode, btn in self.layout_buttons.items():
                btn.blockSignals(True)
                btn.setChecked(mode == self.layout_mode)
                btn.blockSignals(False)

    def apply_contrast_preset(self, preset):
        if self.volume is None:
            return
        if preset == "auto":
            self.auto_contrast()
            return
        data = self.volume.data
        d_min = float(data.min())
        d_max = float(data.max())
        d_range = max(1.0, d_max - d_min)
        if preset == "soft":
            window = d_range * 0.4
            level = d_min + d_range * 0.3
        elif preset == "bone":
            window = d_range * 0.75
            level = d_min + d_range * 0.55
        elif preset == "full":
            window = d_range
            level = d_min + d_range / 2
        else:
            return
        self.window_spin.setValue(max(0.001, window))
        self.level_spin.setValue(level)

    def auto_fit_seed(self):
        if self.volume is None or self.seed is None:
            self.error("Click a slice to place a seed point first.")
            return
        val = float(self.volume.data[self.seed[2], self.seed[1], self.seed[0]])
        margin = max(20.0, abs(val) * 0.15)
        self.lower.setValue(max(float(self.volume.data.min()), val - margin))
        self.upper.setValue(min(float(self.volume.data.max()), val + margin))
        self.statusBar().showMessage(f"Bounds fit to seed: [{val - margin:.1f} .. {val + margin:.1f}]")

    def set_tool_index(self, index):
        self.tool.setCurrentIndex(index)

    def tool_index_changed(self, index):
        if hasattr(self, "tool_buttons") and 0 <= index < len(self.tool_buttons):
            self.tool_buttons[index].setChecked(True)
        names = ["Navigate / Seed", "Brush", "Erase"]
        if 0 <= index < len(names):
            self.statusBar().showMessage(f"Active tool: {names[index]}")

    def keyPressEvent(self, event):
        from PySide6.QtWidgets import QLineEdit, QAbstractSpinBox
        focus = QApplication.focusWidget()
        if isinstance(focus, (QLineEdit, QAbstractSpinBox)):
            super().keyPressEvent(event)
            return
        key = event.key()
        if key == Qt.Key.Key_V:
            self.set_tool_index(0)
            event.accept()
            return
        elif key == Qt.Key.Key_B:
            self.set_tool_index(1)
            event.accept()
            return
        elif key == Qt.Key.Key_E:
            self.set_tool_index(2)
            event.accept()
            return
        elif key == Qt.Key.Key_BracketLeft:
            self.radius.setValue(max(0.2, self.radius.value() - 1.0))
            event.accept()
            return
        elif key == Qt.Key.Key_BracketRight:
            self.radius.setValue(min(50.0, self.radius.value() + 1.0))
            event.accept()
            return
        elif key == Qt.Key.Key_Space:
            self.cycle_layout()
            event.accept()
            return
        elif key == Qt.Key.Key_Escape:
            self.set_layout_mode("quad")
            event.accept()
            return
        elif key == Qt.Key.Key_O:
            self.scene.toggle_turntable()
            event.accept()
            return
        elif key == Qt.Key.Key_C:
            self.scene.toggle_axes()
            event.accept()
            return
        super().keyPressEvent(event)

    def start_job(self, fn, success):
        if self.thread is not None:
            return
        self.success_callback = success
        self.thread = QThread(self)
        self.worker = Worker(fn)
        self.worker.moveToThread(self.thread)
        self.thread.started.connect(self.worker.run)
        self.worker.progress.connect(self.job_progress)
        self.worker.result.connect(self.job_result)
        self.worker.error.connect(self.job_error)
        self.worker.finished.connect(self.thread.quit)
        self.worker.finished.connect(self.worker.deleteLater)
        self.thread.finished.connect(self.job_finished)
        self.content.setEnabled(False)
        self.toolbar.setEnabled(False)
        self.progress.setValue(0)
        self.progress.show()
        self.cancel_button.setEnabled(True)
        self.cancel_button.show()
        self.thread.start()

    @Slot(int, str)
    def job_progress(self, value, message):
        self.progress.setValue(value)
        self.statusBar().showMessage(message)

    @Slot(object)
    def job_result(self, result):
        try:
            self.success_callback(result)
        except Exception as exc:
            traceback.print_exc()
            self.error(str(exc))

    @Slot(str)
    def job_error(self, message):
        if message:
            self.error(message)
        else:
            self.statusBar().showMessage("Cancelled · existing work retained")

    @Slot()
    def job_finished(self):
        self.thread.deleteLater()
        self.thread = None
        self.worker = None
        self.success_callback = None
        self.content.setEnabled(True)
        self.toolbar.setEnabled(True)
        self.progress.hide()
        self.cancel_button.hide()

    def cancel_job(self):
        if self.worker is not None:
            self.worker.job.cancelled.set()
            self.cancel_button.setEnabled(False)
            self.statusBar().showMessage("Cancelling at the next safe processing point…")

    def error(self, text):
        QMessageBox.warning(self, "MRI3D", text)

    def can_replace(self):
        if self.thread is not None:
            return False
        if not self.dirty:
            return True
        answer = QMessageBox.question(self, "Unsaved project", "This project has unsaved changes.\nSave it first to keep them, or discard them to continue.",
                                      QMessageBox.StandardButton.Discard | QMessageBox.StandardButton.Cancel,
                                      QMessageBox.StandardButton.Cancel)
        return answer == QMessageBox.StandardButton.Discard

    def mark_dirty(self):
        self.dirty = True
        name = Path(self.project_path).stem if self.project_path else "Untitled"
        self.setWindowTitle(f"MRI3D · {name} *")

    def import_folder(self):
        if self.thread is not None:
            return
        folder = QFileDialog.getExistingDirectory(self, "Import MRI DICOM folder", self.folder)
        if folder:
            self.scan(folder)

    def scan(self, folder):
        self.folder = str(folder)
        self.start_job(lambda job: scan_folder(folder, job), self.show_scan)

    def show_scan(self, scan):
        self.tree.clear()
        for series in scan.series:
            spacing = f"{series.pixel_spacing[1]:.3g} × {series.pixel_spacing[0]:.3g} × {series.spacing_z:.3g}"
            item = QTreeWidgetItem([series.description, str(len(series.slices)), spacing])
            item.setData(0, Qt.ItemDataRole.UserRole, series)
            item.setToolTip(0, "\n".join(series.issues) if series.issues else f"{series.columns} × {series.rows} pixels · thickness {series.thickness:g} mm")
            if not series.usable:
                item.setForeground(0, QColor("#c49b76"))
                item.setText(0, "[Excluded] " + series.description)
            self.tree.addTopLevelItem(item)
        usable = sum(s.usable for s in scan.series)
        self.series_info.setText(f"{len(scan.series)} groups · {usable} reconstructable · {scan.ignored} skipped")
        self.statusBar().showMessage(f"Import complete · {len(scan.series)} groups · {usable} reconstructable")

            self.error("Import a scan folder first.")

        desc_lower = curr_series.description.lower()
        key_tokens = [tok for tok in desc_lower.replace(":", " ").split() if tok not in ("axi", "cor", "sag", "axial", "coronal", "sagittal")]
        
        matches = []
        for i in range(self.tree.topLevelItemCount()):
            item = self.tree.topLevelItem(i)
            s = item.data(0, Qt.ItemDataRole.UserRole)
            if not s or not s.usable:

            if all(tok in s_desc for tok in key_tokens) or (":" in curr_series.description and s.description.startswith(curr_series.description.split(":")[0])):
                matches.append(item)
                
        if len(matches) < 2:
            self.statusBar().showMessage("Could not automatically find orthogonal partner series for this scan.")
            return

        for it in matches[:3]:

    def pick(self, axis, xyz, first):
        if self.volume is None or self.thread is not None:
            return
        tool = self.tool.currentIndex()
        layer = self.current_layer()
        if tool and layer is None:
            if first:
                self.error("Add a tissue layer before painting.")
            return
        if tool:
            if first:
                layer.remember()
                self.stroke_previous = None
            # Interpolate pointer motion to avoid gaps during fast strokes.
            previous = self.stroke_previous if self.stroke_previous is not None else xyz
            steps = max(1, max(abs(a - b) for a, b in zip(previous, xyz)))
            for t in np.linspace(0, 1, steps + 1):
                point = tuple(np.rint(np.array(previous) * (1 - t) + np.array(xyz) * t).astype(int))
                paint_mask(layer.mask, axis, point, self.radius.value(), self.volume.spacing, tool == 1)
            self.stroke_previous = xyz
            layer.mesh = None
            self.mark_dirty()
        else:
            self.seed = tuple(xyz)
            value = self.volume.data[xyz[2], xyz[1], xyz[0]]
            world = self.volume.world(xyz)
            self.seed_label.setText(f"Seed: {value:.1f} intensity\nLPS mm: {world[0]:.1f}, {world[1]:.1f}, {world[2]:.1f}")
        self.xyz = list(xyz)
        self.refresh()

class Cancelled(Exception):

class ImagingError(ValueError):

class Job:
    def __init__(self, report: Callable[[int, str], None] | None = None):
        self.cancelled = Event()
        self.report = report or (lambda value, message: None)

    def check(self):
        if self.cancelled.is_set():
            raise Cancelled("Operation cancelled")

    def progress(self, value: int, message: str):
        self.check()
        self.report(value, message)


@dataclass
class Slice:
    path: str
    position: tuple
    sop_uid: str


@dataclass
class Series:
    key: str
    uid: str
    description: str
    rows: int
    columns: int
    pixel_spacing: tuple
    orientation: tuple
    slices: list[Slice] = field(default_factory=list)
    thickness: float = 0.0
    issues: list[str] = field(default_factory=list)
    spacing_z: float = 0.0
    localizer: bool = False

    @property
    def usable(self):
        return not self.issues and len(self.slices) >= 2 and not self.localizer

    def validate(self):
        row, col = np.array(self.orientation).reshape(2, 3)
        if not (np.isclose(np.linalg.norm(row), 1, atol=1e-4) and
                np.isclose(np.linalg.norm(col), 1, atol=1e-4) and
                abs(np.dot(row, col)) < 1e-4):
            self.issues.append("Invalid direction cosines")
            return
        normal = np.cross(row, col)
        self.slices.sort(key=lambda s: np.dot(s.position, normal))
        if len(self.slices) < 2:
            self.issues.append("At least two parallel slices are needed")
            return
        positions = np.array([s.position for s in self.slices])
        differences = np.diff(positions @ normal)
        self.spacing_z = float(np.median(differences))
        if np.any(differences < 0.001):
            self.issues.append("Duplicate slice positions; select a single acquisition")
        if self.spacing_z > 0 and not np.allclose(differences, self.spacing_z, rtol=0.01, atol=0.01):
            self.issues.append("Irregular spacing or missing slices; cannot safely reconstruct")
        expected = positions[0] + np.outer((positions - positions[0]) @ normal, normal)
        if not np.allclose(positions, expected, atol=0.05):
            self.issues.append("In-plane slice shifts are unsupported")
        if self.localizer:
            self.issues.append("Localizer / scout: excluded from 3D reconstruction")


@dataclass
class Scan:
    series: list[Series]
    ignored: int
    warnings: list[str]


@dataclass
class Volume:
    image: sitk.Image
    data: np.ndarray
    series: Series
    source_geometry: dict
    invert: bool = False
    # Source series of a fused volume; None for a single-series volume.
    components: list[Series] | None = None

    @property
    def spacing(self):
        return self.image.GetSpacing()

    @property
    def origin(self):
        return self.image.GetOrigin()

    def world(self, xyz):
        return self.image.TransformContinuousIndexToPhysicalPoint(tuple(float(v) for v in xyz))


def geometry(image):
    return dict(size=list(image.GetSize()), spacing=list(image.GetSpacing()),
                origin=list(image.GetOrigin()), direction=list(image.GetDirection()))


def read_dicom(path, pixels=False):
    ds = pydicom.dcmread(path, stop_before_pixels=not pixels, force=True)
    # Some older scanner exports omit the Part 10 header entirely.
    if "TransferSyntaxUID" not in ds.file_meta:
        if ds.original_encoding != (True, True):
            raise ImagingError("DICOM without transfer syntax must use implicit little endian")
        ds.file_meta.TransferSyntaxUID = ImplicitVRLittleEndian
    return ds


def scan_folder(folder: str, job: Job | None = None) -> Scan:
    job = job or Job()
    root = Path(folder)
    if not root.is_dir():
        raise ImagingError("Choose an existing DICOM folder")
    files = []
    for path in root.rglob("*"):
        job.check()
        if path.is_file():
            files.append(path)
    groups = {}
    ignored = 0
    warnings = []
    for index, path in enumerate(files):
        job.progress(int(index * 95 / max(1, len(files))), f"Reading scan headers · {index + 1}/{len(files)}")
        try:
            ds = read_dicom(path)
            if not getattr(ds, "Modality", None):
                raise ImagingError("Missing DICOM modality")
            if getattr(ds, "Modality", None) != "MR":
                ignored += 1
                continue
            if int(getattr(ds, "NumberOfFrames", 1)) != 1:
                warnings.append("Enhanced / multiframe MRI is unsupported in this version")
                ignored += 1
                continue
            uid = str(ds.SeriesInstanceUID)
            orient = tuple(float(v) for v in ds.ImageOrientationPatient)
            spacing = tuple(float(v) for v in ds.PixelSpacing)
            pos = tuple(float(v) for v in ds.ImagePositionPatient)
            if len(orient) != 6 or len(spacing) != 2 or len(pos) != 3:
                raise ImagingError("Incomplete spatial metadata")
            if not np.isfinite(orient + spacing + pos).all() or min(spacing) <= 0:
                raise ImagingError("Invalid spatial metadata")
            group = (uid, int(ds.Rows), int(ds.Columns), tuple(round(v, 5) for v in orient),
                     tuple(round(v, 5) for v in spacing), str(getattr(ds, "EchoNumbers", "")),
                     str(getattr(ds, "TemporalPositionIdentifier", "")),
                     str(getattr(ds, "ComplexImageComponent", "")))
            if group not in groups:
                description = str(getattr(ds, "SeriesDescription", "Unnamed MRI series"))
                image_type = " ".join(getattr(ds, "ImageType", [])).upper()
                scout = any(s in (image_type + " " + description.upper()) for s in
                            ("LOCALIZER", "SCOUT", "3-PLANE", "3 PLANE"))
                groups[group] = Series(hashlib.sha256(repr(group).encode()).hexdigest()[:20], uid,
                                       description, int(ds.Rows), int(ds.Columns), spacing, orient,
                                       thickness=float(getattr(ds, "SliceThickness", 0)), localizer=scout)
            groups[group].slices.append(Slice(str(path.resolve()), pos, str(ds.SOPInstanceUID)))
        except Exception as exc:
            if isinstance(exc, Cancelled):
                raise
            ignored += 1
            if path.suffix.lower() == ".dcm":
                warnings.append("Unreadable DICOM or missing required metadata: " + type(exc).__name__)
    result = sorted(groups.values(), key=lambda s: (s.description.casefold(), s.key))
    for series in result:
        series.validate()
    job.progress(100, f"Found {len(result)} compatible series groups")
    return Scan(result, ignored, sorted(set(warnings)))


def canonicalize(image: sitk.Image, job: Job) -> sitk.Image:
    oriented = sitk.DICOMOrient(image, "LPS")
    if np.allclose(oriented.GetDirection(), np.eye(3).ravel(), atol=1e-6):
        oriented.SetDirection(tuple(np.eye(3).ravel()))
        return oriented
    corners = np.array([oriented.TransformContinuousIndexToPhysicalPoint(tuple(float(x) for x in corner))
                        for corner in product(*[(-0.5, n - 0.5) for n in oriented.GetSize()])])
    spacing = np.array(oriented.GetSpacing())
    low, high = corners.min(axis=0), corners.max(axis=0)
    size = np.ceil((high - low) / spacing).astype(int)
    if np.prod(size.astype(float)) > 160_000_000:
        raise ImagingError("Reoriented volume exceeds the 160 million voxel memory limit")
    filt = sitk.ResampleImageFilter()
    filt.SetSize([int(n) for n in size])
    filt.SetOutputSpacing(tuple(spacing))
    filt.SetOutputOrigin(tuple(low + spacing / 2))
    filt.SetOutputDirection(tuple(np.eye(3).ravel()))
    filt.SetInterpolator(sitk.sitkLinear)
    filt.SetDefaultPixelValue(float(sitk.GetArrayViewFromImage(image).min()))
    filt.AddCommand(sitk.sitkProgressEvent, lambda: filt.Abort() if job.cancelled.is_set() else None)
    result = filt.Execute(oriented)
    job.check()
    return result


def load_series(series: Series, job: Job | None = None) -> Volume:
    job = job or Job()
    job.check()
    if not series.usable:
        raise ImagingError("; ".join(series.issues) or "This series cannot be reconstructed")
    if series.rows * series.columns * len(series.slices) > 160_000_000:
        raise ImagingError("Series exceeds the 160 million voxel memory limit")
    arrays = []
    photometric = None
    for i, item in enumerate(series.slices):
        job.progress(int(i / len(series.slices) * 75), f"Decoding slice {i + 1}/{len(series.slices)}")
        ds = read_dicom(item.path, pixels=True)
        if str(ds.SOPInstanceUID) != item.sop_uid or str(ds.SeriesInstanceUID) != series.uid:
            raise ImagingError("Source DICOM changed after import; scan the folder again")
        if (not np.allclose(tuple(float(v) for v in ds.ImagePositionPatient), item.position, atol=1e-5, rtol=0)
                or not np.allclose(tuple(float(v) for v in ds.ImageOrientationPatient), series.orientation, atol=1e-4, rtol=0)
                or not np.allclose(tuple(float(v) for v in ds.PixelSpacing), series.pixel_spacing, atol=1e-5, rtol=0)):
            raise ImagingError("Source geometry changed after import; scan the folder again")
        if int(getattr(ds, "SamplesPerPixel", 1)) != 1 or getattr(ds, "PhotometricInterpretation", "") not in ("MONOCHROME1", "MONOCHROME2"):
            raise ImagingError("Only monochrome MRI pixel data is supported")
        if photometric is not None and photometric != ds.PhotometricInterpretation:
            raise ImagingError("Mixed photometric interpretations in one stack")
        photometric = ds.PhotometricInterpretation
        try:
            pixels = ds.pixel_array.astype(np.float32)
        except Exception as exc:
            raise ImagingError(f"Unable to decode pixel data. This transfer syntax may need another decoder. {exc}") from exc
        if pixels.shape != (series.rows, series.columns):
            raise ImagingError("Pixel dimensions do not match the series")
        pixels = pixels * float(getattr(ds, "RescaleSlope", 1)) + float(getattr(ds, "RescaleIntercept", 0))
        if not np.isfinite(pixels).all():
            raise ImagingError("Non-finite voxel values are unsupported")
        arrays.append(pixels)
    image = sitk.GetImageFromArray(np.stack(arrays))
    image.SetSpacing((series.pixel_spacing[1], series.pixel_spacing[0], series.spacing_z))
    image.SetOrigin(series.slices[0].position)
    row, col = np.array(series.orientation).reshape(2, 3)
    image.SetDirection(tuple(np.column_stack([row, col, np.cross(row, col)]).ravel()))
    source_geometry = geometry(image)
    job.progress(80, "Aligning views to patient LPS coordinates")
    image = canonicalize(image, job)
    data = sitk.GetArrayFromImage(image)
    job.progress(100, "Volume ready")
    return Volume(image, data, series, source_geometry, photometric == "MONOCHROME1")


def fuse_series(series_list: list[Series], job: Job | None = None) -> Volume:
    job = job or Job()
    job.check()
    if not series_list:
        raise ImagingError("Select at least one series to open or fuse")
    if len(series_list) == 1:
        return load_series(series_list[0], job)

    for s in series_list:
        if not s.usable:
            raise ImagingError(f"Series '{s.description}' cannot be reconstructed: {'; '.join(s.issues)}")

    # 1. Load and canonicalize each series
    volumes = []
    n_series = len(series_list)
    for idx, s in enumerate(series_list):
        job.progress(int(idx / n_series * 40), f"Decoding series {idx + 1}/{n_series}: {s.description}")
        vol = load_series(s, job)
        volumes.append(vol)

    job.progress(45, "Calculating unified physical LPS bounding box")
    bounds = []
    for vol in volumes:
        img = vol.image
        sz = np.array(img.GetSize())
        sp = np.array(img.GetSpacing())
        orig = np.array(img.GetOrigin())
        low = orig - sp / 2.0
        high = orig + (sz - 0.5) * sp
        bounds.append((low, high))

    all_lows = np.array([b[0] for b in bounds])
    all_highs = np.array([b[1] for b in bounds])
    union_low = all_lows.min(axis=0)
    union_high = all_highs.max(axis=0)

    # Determine target isotropic spacing based on finest in-plane resolution
    min_in_plane = min(min(s.pixel_spacing) for s in series_list)
    target_sp = float(np.clip(min_in_plane, 0.25, 0.6))
    
    extent = union_high - union_low
    target_size = np.ceil(extent / target_sp).astype(int)
    
    # Safety: clamp size so total voxel count <= 40 million voxels
    total_voxels = np.prod(target_size.astype(float))
    if total_voxels > 40_000_000:
        scale_factor = (total_voxels / 40_000_000) ** (1.0 / 3.0)
        target_sp *= scale_factor
        target_size = np.ceil(extent / target_sp).astype(int)

    ref = sitk.Image([int(n) for n in target_size], sitk.sitkFloat32)
    ref.SetSpacing((target_sp, target_sp, target_sp))
    ref.SetOrigin(tuple(union_low + target_sp / 2.0))
    ref.SetDirection(tuple(np.eye(3).ravel()))

    def get_taper_1d(length, margin=6):
        if length <= 2 * margin:
            return np.ones(length, dtype=np.float32)
        w = np.ones(length, dtype=np.float32)
        ramp = 0.5 * (1.0 - np.cos(np.linspace(0, np.pi, margin, dtype=np.float32)))
        w[:margin] = ramp
        w[-margin:] = ramp[::-1]
        return w

    job.progress(55, "Resampling orthogonal series onto isotropic grid")
    resampled_arrays = []
    gradient_arrays = []
    mask_arrays = []
    
    for idx, vol in enumerate(volumes):
        job.progress(55 + int(idx / n_series * 25), f"Resampling plane {idx + 1}/{n_series} ({vol.series.description})")
        sz = vol.image.GetSize()
        mx = min(6, max(1, sz[0] // 8))
        my = min(6, max(1, sz[1] // 8))
        mz = min(4, max(1, sz[2] // 6))
        wx = get_taper_1d(sz[0], mx)
        wy = get_taper_1d(sz[1], my)
        wz = get_taper_1d(sz[2], mz)
        taper_3d = (wz[:, None, None] * wy[None, :, None] * wx[None, None, :]).astype(np.float32)
        
        native_mask = sitk.GetImageFromArray(taper_3d)
        native_mask.CopyInformation(vol.image)

        resampler = sitk.ResampleImageFilter()
        resampler.SetReferenceImage(ref)
        resampler.SetInterpolator(sitk.sitkLinear)
        resampler.SetDefaultPixelValue(0.0)
        
        resampled_img = resampler.Execute(vol.image)
        resampled_mask = resampler.Execute(native_mask)
        
        arr = sitk.GetArrayFromImage(resampled_img).astype(np.float32)
        mask_arr = sitk.GetArrayFromImage(resampled_mask).astype(np.float32)
        mask_arr = np.clip(mask_arr, 0.0, 1.0)
        
        # Robust intensity normalization using voxels inside scan coverage
        core_voxels = arr[mask_arr > 0.6]
        if len(core_voxels) > 100:
            p2, p98 = np.percentile(core_voxels, [2, 98])
            if p98 > p2:
                arr = (arr - p2) / (p98 - p2) * 1000.0
                arr = np.clip(arr, 0.0, 2000.0)
        
        # Compute gradient on the resampled volume
        grad_img = sitk.GradientMagnitude(resampled_img)
        grad_arr = sitk.GetArrayFromImage(grad_img).astype(np.float32)
        
        # Suppress artificial boundary gradients at the FOV box edge
        grad_arr = grad_arr * mask_arr

        resampled_arrays.append(arr)
        gradient_arrays.append(grad_arr)
        mask_arrays.append(mask_arr)

    job.progress(85, "Performing gradient-weighted multi-planar fusion")
    # Dynamic weights: mask_arr ensures zero contribution outside FOV,
    # and gradient magnitude prioritizes sharp in-plane details inside the FOV.
    weights = [m * ((g ** 1.2) + 1.0) for m, g in zip(mask_arrays, gradient_arrays)]
    total_weight = sum(weights)
    
    # Avoid divide by zero in areas outside all scans
    safe_weight = np.maximum(total_weight, 1e-6)
    fused_arr = sum(w * a for w, a in zip(weights, resampled_arrays)) / safe_weight
    
    # Zero out background voxels where no scan had coverage
    no_coverage = (total_weight < 1e-3)
    fused_arr[no_coverage] = 0.0
    
    fused_image = sitk.GetImageFromArray(fused_arr)
    fused_image.CopyInformation(ref)

    labels = [s.description.split(':')[-1].strip() for s in series_list]
    desc = f"Fused Isotropic 3D ({len(series_list)} planes: {', '.join(labels)})"
    fused_series = Series(
        key=hashlib.sha256(desc.encode()).hexdigest()[:20],
        uid=series_list[0].uid,
        description=desc,
        rows=int(target_size[1]),
        columns=int(target_size[0]),
        pixel_spacing=(target_sp, target_sp),
        orientation=tuple(np.eye(3)[:2].ravel()),
        slices=[Slice("", (0, 0, 0), "") for _ in range(int(target_size[2]))],
        thickness=target_sp,
        spacing_z=target_sp,
    )
    
    source_geometry = geometry(fused_image)
    job.progress(100, "Multi-planar isotropic fusion complete")
    return Volume(fused_image, fused_arr, fused_series, source_geometry, invert=False, components=list(series_list))


def mask_image(mask: np.ndarray, volume: Volume):
    image = sitk.GetImageFromArray(mask.astype(np.uint8))
    image.CopyInformation(volume.image)
    return image


def segment(volume: Volume, operation: str, mask: np.ndarray, lower=0., upper=1., seed=None,
            job: Job | None = None):
    job = job or Job()
    job.progress(5, f"Processing {operation}")
    if operation in ("grow", "threshold") and lower > upper:
        raise ImagingError("Lower threshold must not exceed upper threshold")
    if operation == "threshold":
        result = (volume.data >= lower) & (volume.data <= upper)
    else:
        source = mask_image(mask, volume)
        if operation == "grow":
            if seed is None:
                raise ImagingError("Click a slice to place a seed first")
            x, y, z = map(int, seed)
            if not lower <= volume.data[z, y, x] <= upper:
                raise ImagingError("The seed intensity is outside the threshold range")
            source = volume.image
            filt = sitk.ConnectedThresholdImageFilter()
            filt.SetLower(float(lower))
            filt.SetUpper(float(upper))
            filt.SetSeedList([(x, y, z)])
        elif operation == "fill":
            filt = sitk.BinaryFillholeImageFilter()
            filt.SetForegroundValue(1)
        elif operation == "island":
            filt = sitk.ConnectedComponentImageFilter()
        else:
            raise ImagingError("Unknown segmentation operation")
        filt.AddCommand(sitk.sitkProgressEvent, lambda: filt.Abort() if job.cancelled.is_set() else None)
        image = filt.Execute(source)
        job.check()
        if operation == "island":
            image = sitk.RelabelComponent(image, sortByObjectSize=True) == 1
        result = sitk.GetArrayFromImage(image) > 0
    job.progress(100, "Selection ready")
    return result

from dataclasses import dataclass, field

@dataclass
class Layer:
    name: str
    color: tuple
    mask: np.ndarray
    id: str = field(default_factory=lambda: uuid.uuid4().hex)
    visible: bool = True
    opacity: float = 0.85
    smooth: bool = False
    representation: str = "surface"
    mesh: object = None
    undo: list = field(default_factory=list)
    redo: list = field(default_factory=list)

    def remember(self):
        self.undo.append(np.packbits(self.mask, axis=None))
        self.undo = self.undo[-20:]
        self.redo.clear()
        self.mesh = None

    def restore(self, redo=False):
        source, target = (self.redo, self.undo) if redo else (self.undo, self.redo)
        if not source:
            return False
        target.append(np.packbits(self.mask, axis=None))
        self.mask = np.unpackbits(source.pop(), count=self.mask.size).reshape(self.mask.shape).astype(bool)
        self.mesh = None
        return True


def vtk_image(data, spacing, origin):
    result = vtk.vtkImageData()
    result.SetDimensions(*data.shape[::-1])
    result.SetSpacing(*spacing)
    result.SetOrigin(*origin)
    result.GetPointData().SetScalars(numpy_to_vtk(np.ascontiguousarray(data).ravel(), deep=True))
    return result


def make_mesh(volume: Volume, mask: np.ndarray, smooth=False, job: Job | None = None):
    job = job or Job()
    job.progress(5, "Building surface in patient coordinates")
    if not mask.any():
        raise ImagingError("This layer is empty. Mark tissue before generating a surface.")
    # Padding closes surfaces that reach a volume boundary, without moving voxel centers.
    padded = np.pad(mask.astype(np.uint8), 1)
    origin = np.array(volume.origin) - np.array(volume.spacing)
    data = vtk_image(padded, volume.spacing, origin)
    contour = vtk.vtkFlyingEdges3D()
    contour.SetInputData(data)
    contour.SetValue(0, 0.5)
    contour.AddObserver("ProgressEvent", lambda o, e: o.SetAbortExecute(job.cancelled.is_set()))
    contour.Update()
    job.progress(65, "Finishing surface")
    output = contour.GetOutput()
    if smooth:
        smoothing = vtk.vtkWindowedSincPolyDataFilter()
        smoothing.SetInputData(output)
        smoothing.SetNumberOfIterations(15)
        smoothing.SetPassBand(0.1)
        smoothing.BoundarySmoothingOff()
        smoothing.FeatureEdgeSmoothingOff()
        smoothing.NormalizeCoordinatesOn()
        smoothing.AddObserver("ProgressEvent", lambda o, e: o.SetAbortExecute(job.cancelled.is_set()))
        smoothing.Update()
        output = smoothing.GetOutput()
    normals = vtk.vtkPolyDataNormals()
    normals.SetInputData(output)
    normals.SplittingOff()
    normals.ConsistencyOn()
    normals.Update()
    mesh = vtk.vtkPolyData()
    mesh.DeepCopy(normals.GetOutput())
    job.progress(100, "Surface ready")
    return mesh


def export_mesh(mesh, path, color):
    from pathlib import Path
    import json
    target = Path(path)
    if mesh is None or mesh.GetNumberOfPoints() == 0:

    }, indent=2), encoding="utf-8")


def slice_array(array, axis, xyz):
    x, y, z = map(int, xyz)
    if axis == 2:
        return array[z, :, :]
    if axis == 1:
        return array[:, y, :][::-1, :]
    return array[:, :, x][::-1, :]


def slice_to_voxel(axis, u, v, xyz, shape):
    x, y, z = map(int, xyz)
    if axis == 2:
        x, y = u, v
    elif axis == 1:
        x, z = u, shape[0] - 1 - v
    else:
        y, z = u, shape[0] - 1 - v
    return tuple(int(np.clip(a, 0, n - 1)) for a, n in zip((x, y, z), shape[::-1]))


def paint_mask(mask, axis, xyz, radius_mm, spacing, value):
    # A disk in the displayed physical plane; slice thickness never stretches the brush.
    plane = slice_array(mask, axis, xyz)
    x, y, z = xyz
    if axis == 2:
        u, v, su, sv = x, y, spacing[0], spacing[1]
    elif axis == 1:
        u, v, su, sv = x, mask.shape[0] - 1 - z, spacing[0], spacing[2]
    else:
        u, v, su, sv = y, mask.shape[0] - 1 - z, spacing[1], spacing[2]
    ur = int(np.ceil(radius_mm / su))
    vr = int(np.ceil(radius_mm / sv))
    x0, x1 = max(0, u - ur), min(plane.shape[1], u + ur + 1)
    y0, y1 = max(0, v - vr), min(plane.shape[0], v + vr + 1)
    yy, xx = np.ogrid[y0:y1, x0:x1]
    circle = ((xx - u) * su) ** 2 + ((yy - v) * sv) ** 2 <= radius_mm ** 2
    plane[y0:y1, x0:x1][circle] = value


def filter_clusters(mask: np.ndarray, min_voxels: int = 25) -> np.ndarray:
    """Remove disconnected voxel clusters smaller than min_voxels (cluster-extent thresholding)."""
    if not mask.any() or min_voxels <= 1:
        return mask.copy()
    img = sitk.GetImageFromArray(mask.astype(np.uint8))
    cc = sitk.ConnectedComponent(img)
    relabeled = sitk.RelabelComponent(cc, minimumObjectSize=int(min_voxels))
    return sitk.GetArrayFromImage(relabeled) > 0

def save_project(path, volume: Volume, layers: list[Layer], views: dict, job: Job | None = None):
    job = job or Job()
    path = Path(path).resolve()
    # A new generation keeps the old project usable even if saving is interrupted.
    generation = uuid.uuid4().hex
    assets = path.parent / (path.name + "-data") / generation
    assets.mkdir(parents=True, exist_ok=False)
    items = []
    for i, layer in enumerate(layers):
        job.progress(int(i * 85 / max(1, len(layers))), f"Saving layer {i + 1}/{len(layers)}")
        filename = f"{i}.mha"
        sitk.WriteImage(mask_image(layer.mask, volume), str(assets / filename), True)
        items.append(dict(id=layer.id, name=layer.name, color=list(layer.color), visible=layer.visible,
                          opacity=layer.opacity, smooth=layer.smooth,
                          representation=getattr(layer, "representation", "surface"),
                          mask=str((assets / filename).relative_to(path.parent))))
    manifest = dict(format="MRI3D", version=1, series=asdict(volume.series),
                    source_geometry=volume.source_geometry, working_geometry=geometry(volume.image),
                    layers=items, views=views, coordinates="LPS", units="mm")
    if volume.components:
        manifest["components"] = [asdict(s) for s in volume.components]
    temp = path.with_name(path.name + "." + generation + ".tmp")
    job.check()
    temp.write_text(json.dumps(manifest, indent=2), encoding="utf-8")
    job.check()
    os.replace(temp, path)
    # Once committed, report success even if cancellation arrives at this instant.
    job.report(100, "Project saved")
    return str(path)


def read_manifest(path):
    data = json.loads(Path(path).read_text(encoding="utf-8"))
    if data.get("format") != "MRI3D" or data.get("version") != 1:
        raise ImagingError("Unsupported project format or version")
    return data


def source_series(data):
    # Fused projects are rebuilt from their component series.
    return data.get("components") or [data["series"]]


def missing_sources(data):
    return any(not Path(s["path"]).is_file() for series in source_series(data) for s in series["slices"])


def series_from_dict(item):
    fields = dict(item)
    fields["slices"] = [Slice(**s) for s in fields["slices"]]
    return Series(**fields)


def open_project(path, relink=None, job: Job | None = None):
    job = job or Job()
    manifest = read_manifest(path)
    fused = bool(manifest.get("components"))
    series_list = [series_from_dict(item) for item in source_series(manifest)]
    if relink:
        found = scan_folder(relink, job)
        matched = []
        for series in series_list:
            match = next((s for s in found.series if s.key == series.key and
                          {f.sop_uid for f in s.slices} == {f.sop_uid for f in series.slices}), None)
            if match is None:
                raise ImagingError("That folder does not contain the same series and source images")
            matched.append(match)
        series_list = matched
    if any(not Path(s.path).is_file() for series in series_list for s in series.slices):
        raise ImagingError("Source scans have moved. Use Open project and relink the DICOM folder.")
    volume = fuse_series(series_list, job) if fused else load_series(series_list[0], job)
    current = geometry(volume.image)
    for key in ("size", "origin", "direction", "spacing"):
        if not np.allclose(current[key], manifest["working_geometry"][key], atol=1e-5, rtol=1e-6):
            raise ImagingError("Source geometry differs from the saved project; masks cannot be aligned")
    layers = []
    root = Path(path).resolve().parent
    for item in manifest["layers"]:
        job.check()
        mask_path = (root / item["mask"]).resolve()
        if not mask_path.is_relative_to(root):
            raise ImagingError("Invalid project mask path")
        image = sitk.ReadImage(str(mask_path))
        if image.GetDimension() != 3 or image.GetNumberOfComponentsPerPixel() != 1:
            raise ImagingError("Invalid segmentation image")
        for key, value in geometry(image).items():
            if not np.allclose(value, current[key], atol=1e-5, rtol=1e-6):
                raise ImagingError("Saved mask geometry does not match the source volume")
        color = tuple(int(c) for c in item["color"])
        if len(color) != 3 or any(c < 0 or c > 255 for c in color):
            raise ImagingError("Invalid layer color")
        layer = Layer(item["name"], color, sitk.GetArrayFromImage(image) > 0, id=item["id"],
                      visible=bool(item["visible"]), opacity=float(np.clip(item["opacity"], 0, 1)),
                      smooth=bool(item["smooth"]),
                      representation=str(item.get("representation", "surface")))
        layers.append(layer)
    job.progress(100, "Project opened")
    return volume, layers, manifest["views"]

"""Self-contained app smoke workflow; usable from the packaged executable."""
from pathlib import Path
import json
import sys
import time

def synthetic_volume():
    zz, yy, xx = np.mgrid[:40, :64, :64]
    distance = ((xx - 32) / 18) ** 2 + ((yy - 32) / 21) ** 2 + ((zz - 20) / 13) ** 2
    data = (np.exp(-distance * 2) * 1000).astype(np.float32)
    image = sitk.GetImageFromArray(data)
    image.SetSpacing((0.8, 0.8, 1.5))
    image.SetOrigin((-25, -25, -30))
    series = Series("synthetic", "synthetic", "Synthetic smoke volume", 64, 64, (0.8, 0.8), (1, 0, 0, 0, 1, 0), thickness=1.5, spacing_z=1.5)
    return Volume(image, data, series, geometry(image))


def run_smoke(window, output, folder=None):
    root = Path(output).resolve()
    root.mkdir(parents=True, exist_ok=True)
    report = {"packaged": bool(getattr(sys, "frozen", False)), "executable": sys.executable}
    started = time.perf_counter()
    timer = QTimer(window)
    timer.setInterval(100)
    window.smoke_timer = timer
    state = {"phase": 0}

    def fail(exc):
        timer.stop()
        report["error"] = str(exc)
        report["traceback"] = traceback.format_exc()
        (root / "smoke.json").write_text(json.dumps(report, indent=2), encoding="utf-8")
        window.dirty = False
        window.close()
        QApplication.exit(1)

    def loaded(volume):
        window.set_volume(volume)
        report["shape_zyx"] = list(volume.data.shape)
        report["spacing_xyz"] = list(volume.spacing)
        state["phase"] = 1

    def initial(job):
        if folder:
            scan = scan_folder(folder, job)
            report["series_groups"] = len(scan.series)
            report["usable_groups"] = sum(s.usable for s in scan.series)
            report["files"] = sum(len(s.slices) for s in scan.series)
            series = next((s for s in scan.series if s.usable and s.description == "Cor T1 FSE"), next(s for s in scan.series if s.usable))
            return load_series(series, job)
        return synthetic_volume()

    def tick():
        try:
            if time.perf_counter() - started > 180:
                raise RuntimeError("GUI smoke test timed out")
            if window.thread is not None:
                return
            volume = window.volume
            if state["phase"] == 1:
                # This is a technical selection fixture, not a claimed anatomical segmentation.
                mask = np.zeros(volume.data.shape, bool)
                xyz = tuple(n // 2 for n in volume.image.GetSize())
                layer = Layer("QA selection · not anatomical", (88, 216, 188), mask)
                window.layers.append(layer)
                window.refresh_layer_list(0)
                window.radius.setValue(8)
                window.tool.setCurrentIndex(1)
                window.pick(2, xyz, True)
                window.end_stroke()
                assert layer.mask.any()
                marked = layer.mask.copy()
                window.undo()
                assert not layer.mask.any()
                window.undo(True)
                assert np.array_equal(layer.mask, marked)
                # Add thickness for a useful closed test mesh.
                for dz in range(-2, 3):
                    paint_mask(layer.mask, 2, (xyz[0], xyz[1], xyz[2] + dz), 8, volume.spacing, True)
                report["brush_undo_redo"] = True
                window.generate()
                state["phase"] = 2
            elif state["phase"] == 2:
                layer = window.layers[0]
                assert layer.mesh is not None
                export_mesh(layer.mesh, str(root / "qa-surface.ply"), layer.color)
                export_mesh(layer.mesh, str(root / "qa-surface.stl"), layer.color)
                report["mesh_points"] = layer.mesh.GetNumberOfPoints()
                report["mesh_bounds_mm"] = list(layer.mesh.GetBounds())
                window.clip.setChecked(True)
                window.clip_axis.setCurrentIndex(1)
                window.clip_position.setValue(45)
                window.scene.reset_camera()
                camera = window.scene.renderer.GetActiveCamera()
                camera.Azimuth(25)
                camera.Elevation(10)
                window.scene.renderer.ResetCameraClippingRange()
                window.scene.render()
                for axis in range(3):
                    window.set_index(axis, volume.image.GetSize()[axis] // 2)
                report["linked_views_and_clipping"] = True
                if folder:
                    path = root / "qa-project.mri3d"
                    state["path"] = path
                    views = window.view_state()
                    window.start_job(lambda job: save_project(path, volume, window.layers, views, job), lambda result: None)
                state["phase"] = 3
            elif state["phase"] == 3:
                if folder:
                    def reopened(result):
                        restored, layers, views = result
                        assert np.array_equal(layers[0].mask, window.layers[0].mask)
                        assert np.array_equal(restored.data, window.volume.data)
                        report["project_roundtrip"] = True
                    window.start_job(lambda job: open_project(state["path"], job=job), reopened)
                state["phase"] = 4
            elif state["phase"] == 4:
                state["phase"] = 5
                # Wait a paint cycle before collecting the rendered app.
            elif state["phase"] == 5:
                window.sidebar.setMinimumWidth(300)
                window.grab().save(str(root / "app.png"))
                capture = vtk.vtkWindowToImageFilter()
                capture.SetInput(window.scene.widget.GetRenderWindow())
                capture.ReadFrontBufferOff()
                capture.Update()
                writer = vtk.vtkPNGWriter()
                writer.SetFileName(str(root / "scene.png"))
                writer.SetInputConnection(capture.GetOutputPort())
                writer.Write()
                durations = []
                for _ in range(10):
                    begin = time.perf_counter()
                    window.scene.renderer.GetActiveCamera().Azimuth(2)
                    window.scene.render()
                    durations.append(time.perf_counter() - begin)
                report["render_median_ms"] = float(np.median(durations) * 1000)
                report["elapsed_seconds"] = time.perf_counter() - started
                report["success"] = True
                (root / "smoke.json").write_text(json.dumps(report, indent=2), encoding="utf-8")
                timer.stop()
                window.dirty = False
                window.close()
                QApplication.exit(0)
        except Exception as exc:
            fail(exc)

    # Avoid modal error dialogs in unattended QA; report failures instead.
    window.error = lambda message: fail(RuntimeError(message))
    timer.timeout.connect(tick)
    window.start_job(initial, loaded)
    timer.start()

class SliceCanvas(QWidget):
    picked = Signal(int, object, bool)
    strokeEnded = Signal()
    stepped = Signal(int, int)

    def __init__(self, axis, parent=None):
        super().__init__(parent)
        self.axis = axis
        self.volume = None
        self.xyz = [0, 0, 0]
        self.layers = []
        self.level = 0

    def refresh(self, volume, xyz, layers, level, window, invert=False):
        self.volume, self.xyz, self.layers = volume, list(xyz), layers
        self.level, self.window, self.invert = level, max(0.001, window), invert
        if volume is not None:
            plane = slice_array(volume.data, self.axis, xyz)
            grey = np.clip((plane - (level - window / 2)) / self.window * 255, 0, 255).astype(np.uint8)
            if invert:
                grey = 255 - grey
            rgb = np.repeat(grey[:, :, None], 3, axis=2)
            for layer in layers:
                if layer.visible:
                    mask = slice_array(layer.mask, self.axis, xyz)
                    alpha = layer.opacity * 0.55
                    rgb[mask] = (rgb[mask] * (1 - alpha) + np.array(layer.color) * alpha).astype(np.uint8)
            rgb = np.ascontiguousarray(rgb)
            self.pix = QImage(rgb.data, rgb.shape[1], rgb.shape[0], rgb.strides[0], QImage.Format.Format_RGB888).copy()
        self.update()

    def reset_view(self):
        self.zoom = 1.0
        self.pan = QPointF()
        self.update()

    def paintEvent(self, event):
        p = QPainter(self)
        p.fillRect(self.rect(), QColor("#080f19"))
        if self.volume is None or self.pix is None:
            p.setPen(QColor("#73859a"))
            p.drawText(self.rect(), Qt.AlignmentFlag.AlignCenter, "Import a DICOM series to begin")
            return
        sx, sy, sz = self.volume.spacing
        su, sv = (sx, sy) if self.axis == 2 else ((sx, sz) if self.axis == 1 else (sy, sz))
        pw, ph = self.pix.width() * su, self.pix.height() * sv
        scale = min((self.width() - 44) / pw, (self.height() - 44) / ph) * self.zoom
        w, h = pw * scale, ph * scale
        self.target = QRectF((self.width() - w) / 2 + self.pan.x(), (self.height() - h) / 2 + self.pan.y(), w, h)
        p.setRenderHint(QPainter.RenderHint.SmoothPixmapTransform, True)
        p.drawImage(self.target, self.pix)
        x, y, z = self.xyz
        u, v = (x, y) if self.axis == 2 else ((x, self.volume.data.shape[0] - 1 - z) if self.axis == 1 else (y, self.volume.data.shape[0] - 1 - z))
        cx = self.target.left() + (u + 0.5) / self.pix.width() * w
        cy = self.target.top() + (v + 0.5) / self.pix.height() * h
        p.save()
        p.setClipRect(self.target)
        p.setPen(QPen(QColor(ACCENTS[self.axis]), 1, Qt.PenStyle.DashLine))
        p.drawLine(QPointF(cx, self.target.top()), QPointF(cx, self.target.bottom()))
        p.drawLine(QPointF(self.target.left(), cy), QPointF(self.target.right(), cy))
        p.restore()

            p.setBrush(QColor(12, 20, 32, 180))
            p.drawRoundedRect(r, 4, 4)
            p.setPen(QColor(ACCENTS[self.axis]))
            p.drawText(r, Qt.AlignmentFlag.AlignCenter, text)
            p.restore()

        if self.hover_val is not None:
            p.save()
            p.setPen(Qt.PenStyle.NoPen)
            p.setBrush(QColor(12, 20, 32, 200))
            badge_r = QRectF(8, 8, 80, 20)

    def voxel_at(self, point):
        if self.volume is None or not self.target.contains(point):
            return None
        u = int((point.x() - self.target.left()) / self.target.width() * self.pix.width())
        v = int((point.y() - self.target.top()) / self.target.height() * self.pix.height())
        return slice_to_voxel(self.axis, u, v, self.xyz, self.volume.data.shape)

    def mousePressEvent(self, event):
        if event.button() in (Qt.MouseButton.RightButton, Qt.MouseButton.MiddleButton):
            self.last_pan = event.position()
        elif event.button() == Qt.MouseButton.LeftButton:
            xyz = self.voxel_at(event.position())
            if xyz is not None:
                self.dragging = True
                self.picked.emit(self.axis, xyz, True)

    def mouseMoveEvent(self, event):
        if self.last_pan is not None:
            self.pan += event.position() - self.last_pan
            self.last_pan = event.position()
            self.update()
        elif self.dragging:
            xyz = self.voxel_at(event.position())
            if xyz is not None:
                self.picked.emit(self.axis, xyz, False)
        else:
            vox = self.voxel_at(event.position())
            if vox is not None and self.volume is not None:
                self.hover_val = float(self.volume.data[vox[2], vox[1], vox[0]])
            else:
                self.hover_val = None
            self.update()

    def leaveEvent(self, event):
        self.hover_val = None
        self.update()

    def mouseReleaseEvent(self, event):
        if self.dragging:
            self.strokeEnded.emit()
        self.dragging = False
        self.last_pan = None

    def wheelEvent(self, event):
        direction = 1 if event.angleDelta().y() > 0 else -1
        if event.modifiers() & Qt.KeyboardModifier.ControlModifier:
            self.zoom = float(np.clip(self.zoom * (1.15 ** direction), 0.2, 15))
            self.update()
        else:
            self.stepped.emit(self.axis, direction)
        event.accept()

    def toggle_turntable(self, enabled=None):
        if enabled is None:
            enabled = not self.turntable_timer.isActive()

        else:
            self.turntable_timer.stop()

            self.btn_orbit.blockSignals(False)
        return enabled

    def set_view_preset(self, preset):
        if self.volume is None:
            return
        camera = self.renderer.GetActiveCamera()
        center = self.volume.world((np.array(self.volume.image.GetSize()) - 1) / 2)
        camera.SetFocalPoint(*center)
        dist = 500
        if preset == "top":
            camera.SetPosition(center[0], center[1], center[2] + dist)
            camera.SetViewUp(0, 1, 0)
        elif preset == "front":
            camera.SetPosition(center[0], center[1] - dist, center[2])
            camera.SetViewUp(0, 0, 1)
        elif preset == "side":
            camera.SetPosition(center[0] + dist, center[1], center[2])
            camera.SetViewUp(0, 0, 1)
        self.renderer.ResetCameraClippingRange()
        self.render()

    def set_volume(self, volume):
        self.volume = volume
        if self.volume_actor:
            self.renderer.RemoveVolume(self.volume_actor)
        for actor in self.surface_actors.values():
            self.renderer.RemoveActor(actor)
        self.surface_actors.clear()
        image = vtk_image(volume.data, volume.spacing, volume.origin)
        self.mapper = vtk.vtkSmartVolumeMapper()
        self.mapper.SetInputData(image)
        self.mapper.SetInteractiveAdjustSampleDistances(True)
        self.mapper.SetInteractiveUpdateRate(20)
        self.mapper.SetBlendModeToComposite()
        self.mapper.SetMaxMemoryInBytes(768 * 1024 * 1024)
        self.property = vtk.vtkVolumeProperty()
        self.property.SetInterpolationTypeToLinear()
        self.property.ShadeOn()
        self.property.SetAmbient(0.2)
        self.property.SetDiffuse(0.7)
        self.property.SetSpecular(0.3)
        self.property.SetSpecularPower(20.0)
        self.volume_actor = vtk.vtkVolume()
        self.volume_actor.SetMapper(self.mapper)
        self.volume_actor.SetProperty(self.property)
        self.renderer.AddVolume(self.volume_actor)
        self.cursor.SetModelBounds(*image.GetBounds())
        self.cursor_actor.SetVisibility(True)
        self.cube_axes.SetBounds(*image.GetBounds())
        self.reset_camera()

    def reset_camera(self):
        camera = self.renderer.GetActiveCamera()
        if self.volume is not None:
            center = self.volume.world((np.array(self.volume.image.GetSize()) - 1) / 2)
            camera.SetFocalPoint(*center)
            camera.SetPosition(center[0], center[1] - 500, center[2] + 100)
            camera.SetViewUp(0, 0, 1)
        self.renderer.ResetCamera()
        self.render()

    def appearance(self, level, window, opacity, visible, invert=False):
        if self.volume_actor is None:
            return
        self.level, self.window, self.opacity = level, window, opacity
        low, high = level - window / 2, level + window / 2
        colors = vtk.vtkColorTransferFunction()
        palette = [(0.02, 0.04, 0.08), (0.4, 0.54, 0.64), (0.93, 0.86, 0.72)]
        if invert:
            palette.reverse()
        for t, color in zip([low, level, high], palette):
            colors.AddRGBPoint(t, *color)
        alpha = vtk.vtkPiecewiseFunction()
        alpha.AddPoint(low, 0)
        alpha.AddPoint(level, opacity * 0.15)
        alpha.AddPoint(high, opacity)
        self.property.SetColor(colors)
        self.property.SetScalarOpacity(alpha)
        self.property.SetScalarOpacityUnitDistance(min(self.volume.spacing))
        self.volume_actor.SetVisibility(visible)
        self.render()

    def set_cursor(self, xyz, render=True):
        if self.volume is not None:
            self.cursor.SetFocalPoint(*self.volume.world(xyz))
            if render:
                self.render()

    def sync_layers(self, layers):
        ids = {l.id for l in layers if l.mesh is not None}
        for ident in list(self.surface_actors):
            if ident not in ids:
                self.renderer.RemoveActor(self.surface_actors.pop(ident))
        for layer in layers:
            if layer.mesh is None:
                continue
            if layer.id not in self.surface_actors:
                mapper = vtk.vtkPolyDataMapper()
                mapper.ScalarVisibilityOff()
                actor = vtk.vtkActor()
                actor.SetMapper(mapper)
                self.renderer.AddActor(actor)
                self.surface_actors[layer.id] = actor
            actor = self.surface_actors[layer.id]
            actor.GetMapper().SetInputData(layer.mesh)
            prop = actor.GetProperty()
            rep = getattr(layer, "representation", "surface")
            if rep == "wireframe":
                prop.SetRepresentationToWireframe()
                prop.SetLineWidth(1.4)
            elif rep == "points":
                prop.SetRepresentationToPoints()
                prop.SetPointSize(3.0)
            else:
                prop.SetRepresentationToSurface()
            prop.SetColor(*[c / 255 for c in layer.color])
            prop.SetOpacity(layer.opacity)
            prop.SetAmbient(0.18)
            prop.SetDiffuse(0.75)
            prop.SetSpecular(0.35)
            prop.SetSpecularPower(25.0)
            actor.SetVisibility(layer.visible)
            actor.GetMapper().RemoveAllClippingPlanes()
            if self.clip_enabled:
                actor.GetMapper().AddClippingPlane(self.clip_plane)
        self.render()

    def clipping(self, enabled, axis, fraction, flipped, render=True):
        self.clip_enabled = enabled
        if self.volume is None:
            return
        normal = [0., 0., 0.]
        normal[axis] = -1 if flipped else 1
        self.clip_plane.SetNormal(*normal)
        size = np.array(self.volume.image.GetSize()) - 1
        xyz = size / 2.0
        xyz[axis] = size[axis] * fraction
        self.clip_plane.SetOrigin(*self.volume.world(xyz))
        for mapper in [self.mapper] + [a.GetMapper() for a in self.surface_actors.values()]:
            mapper.RemoveAllClippingPlanes()
            if enabled:
                mapper.AddClippingPlane(self.clip_plane)
        if render:
            self.render()

    def render(self):
        self.widget.GetRenderWindow().Render()

    def close(self):
        if hasattr(self, "turntable_timer"):
            self.turntable_timer.stop()
        self.axes.SetEnabled(0)
        self.widget.Finalize()
        super().close()
