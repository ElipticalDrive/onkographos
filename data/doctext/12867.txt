Implements T03 (ENG-10) from docs/tasks.md. Stacked on #3 (T02); retargets to main once #1–#3 merge.
Read-side queries and deterministic brush plans on top of T02's spall_voxel storage. No server loop, no graphics — CPU only.
transform.rs — RigidXform
Maps a volume's local cell space to world metres: local_cell → *cell_size_m → rotate → +translation. from_pose builds one from a replicated Pose (dequantise + renormalise the quaternion; reject a zero orientation). The stored rotation is normalised, so the conjugate is the exact inverse. Round-trips tested for identity, pure translation, and an arbitrary-axis 45° rotation at negative cell coordinates (1e-9), plus a looser pass through Pose quantisation.
query.rs — DDA ray traversal
cast_ray runs a 3D DDA (Amanatides & Woo) over a Volume in local cell space; cast_ray_world maps a metre-space ray through a RigidXform, traces, and reports t back in metres (face stays volume-local).

RayHit carries the struck cell, the entered Face (its normal() points back toward the origin), the placement_cell (cell + face.normal()), t, and steps.
brush.rs — integer brush → EditPlan
EditPlan::filled_box and EditPlan::sphere emit cell writes in canonical (z, y, x) order. The sphere uses only spall_core's fixed-point contains_cell_centre predicate over the shape's cell bounding box, so the write set and order are byte-stable — pinned BLAKE3 digests guard it, and a brute-force reference over a wider box confirms the set. Both brushes verified to touch exactly eight bricks when centred on the corner where eight meet; a cell centre exactly on the radius is included.
fixtures.rs — deterministic fixture worlds
Pure functions of a VolumeId — no RNG, no clock, no I/O:
flat_terrain — 2×2×2-brick bounded stone slab under a resident (not absent) air layer, all uniform storage
hollow_tower — 8-brick, 2-cell-thick stone shell straddling the origin (negative coordinates, cross-brick)
cross_brick_bridge — 2×2-cell beam spanning four X bricks (matches the bridge-cross-brick acceptance fixture)
sloped_terrain — small excavatable staircase with a dirt surface over stone
digest(&Volume) gives a platform-stable BLAKE3 over resident bricks in (z, y, x) order (coord, content hash, revision), pinned in tests. It is a local regression check, explicitly not the replicated spall.topology.v1 hash.
Other
volume.rs: Volume::resident_brick_coords() in canonical order.
New dependency glam 0.33.6 (f64 feature, no transitive deps) for the transform / ray math — the math crate named in README.md; recorded in docs/dependencies.md. Ray results are explicitly not required to be bit-identical across machines (hit validation is server-side); integer brush plans stay fully deterministic.

cargo xtask check — fmt clean, clippy -D warnings clean, 103 workspace tests pass (spall_voxel adds 29: transform 4, query 12, brush 8, fixtures 5). cargo xtask smoke --ticks 60 passes.
Acceptance vs. task

cuts spanning eight bricks — brush::box_edit_spanning_eight_bricks_touches_exactly_eight, sphere_edit_spanning_eight_bricks_touches_exactly_eight.

face normal / placement cell / zero direction / start-inside / finite range — the query behaviour table above, each with a test.
No graphics dependency — spall_voxel deps are blake3, glam (f64), spall_core, thiserror.
