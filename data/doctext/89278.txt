# 📐 3D Helical Cone-Beam CT Image Reconstruction (LSQR Algorithm)

An end-to-end high-performance system for **3D Helical Cone-Beam Computed Tomography (CT) Image Reconstruction**. This project uses ray-casting geometry and the **LSQR (Least Squares QR)** iterative solver algorithm to reconstruct 3D attenuation volume densities ($X$) from 2D X-ray projection measurements ($B$).

Both **CPU (C)** and **GPU-accelerated (CUDA)** implementations are provided.

## 🔬 Project Overview

In Computed Tomography (CT) scanning, an X-ray source and detector rotate around an object, recording total X-ray absorption along rays (line integrals). 

This project solves the linear inverse problem:
$$\mathbf{A} \cdot \mathbf{X} = \mathbf{B}$$

Where:
- $\mathbf{X}$ is the unknown **3D Voxel Density Grid** ($512 \times 512 \times 512 = 134,217,728$ voxels, $\sim 536.87 \text{ MB}$).
- $\mathbf{B}$ is the **Projection Measurements Vector** ($473 \text{ angles} \times 512 \times 512 \text{ detector pixels} = 123,994,112$ values, $\sim 495.98 \text{ MB}$).
- $\mathbf{A}$ is the implicit system projection operator (ray-voxel interaction matrix).

---

## ⚙️ Mathematics & Geometry

| Parameter | Value | Description |
| :--- | :--- | :--- |
| **Volume Grid ($\mathbf{X}$)** | $512 \times 512 \times 512$ | 3D Voxel resolution |
| **Object Diameter** | $80.86 \text{ mm}$ | Physical bounding diameter ($\text{voxel size} = 0.157929 \text{ mm}$) |
| **Projections ($N_{pa}$)** | $473 \text{ angles}$ | Angular projections over $640^\circ$ span |
| **Detector Grid ($N_{det} \times N_{slice}$)** | $512 \times 512$ | Detector pixels per projection angle |
| **Source-to-Object ($\text{scob}$)** | $166.641 \text{ mm}$ | Distance from X-ray source to rotation center |
| **Source-to-Detector ($\text{scd}$)** | $1238.157 \text{ mm}$ | Distance from X-ray source to detector panel |
| **Detector Pitch ($d$)** | $0.8 \text{ mm}$ | Size of each detector pixel |
| **Helical Shift** | $0.136 \text{ mm}$ | Helical vertical movement per angle |

## 🚀 Quick Start Guide (Step-by-Step Execution)

Follow these steps sequentially to build and execute the complete pipeline on any computer.

### Step 1: Environment Setup & Data Preparation
1. Open terminal and navigate to the project directory:
   ```bash
   cd "AA Project"
   ```

2. Ensure your ground truth volume file (`sim_512.dat` or `sim_512.bin`) is present in the project folder.

> **Tip:** If you only have `sim_512.dat` (text file), run this quick Python command to convert it to binary `sim_512.bin` for fast loading:
> ```bash
> python -c "import numpy as np; data = np.fromfile('sim_512.dat', sep=' ', dtype=np.float32); data.tofile('sim_512.bin'); print('Converted sim_512.bin successfully!')"
> ```

---

### Step 2: Generate X-Ray Projections (Matrix B)

You can choose either **CPU (C)** or **GPU (CUDA)** mode to generate projection data $\mathbf{B}$.

#### Option A: GPU Acceleration (Recommended - Fast)
1. Compile CUDA kernel:
   ```bash
   nvcc -O3 generate_B.cu -o generate_B_gpu
   ```
2. Execute generator:
   - **Linux / Mac:** `./generate_B_gpu sim_512.bin Vector_B.bin`
   - **Windows:** `generate_B_gpu.exe sim_512.bin Vector_B.bin`

#### Option B: CPU Execution
1. Compile C code:
   ```bash
   gcc -O3 matrix_b_gen.c -o generate_B_cpu -lm
   ```
2. Execute generator:
   - **Linux / Mac:** `./generate_B_cpu sim_512.dat Vector_B.bin`
   - **Windows:** `generate_B_cpu.exe sim_512.dat Vector_B.bin`

*Output created:* `Vector_B.bin` ($\sim 495.98 \text{ MB}$)

---

### Step 3: Run 3D Reconstruction (LSQR Solver)

Now solve the inverse problem to reconstruct the original 3D volume $\mathbf{X}$ from the projection measurements `Vector_B.bin`.

#### Option A: GPU Acceleration (Fast)
1. Compile CUDA LSQR solver:
   ```bash
   nvcc -O3 lsqr_solver.cu -o lsqr_solver_gpu
   ```
2. Execute solver:
   - **Linux / Mac:** `./lsqr_solver_gpu`
   - **Windows:** `lsqr_solver_gpu.exe`

#### Option B: CPU Execution
1. Compile C LSQR solver:
   ```bash
   gcc -O3 lsqr_solver.c -o lsqr_solver_cpu -lm
   ```
2. Execute solver (inputs: projection binary, output binary, iterations):
   - **Linux / Mac:** `./lsqr_solver_cpu Vector_B.bin reconstructed_X.bin 10`
   - **Windows:** `lsqr_solver_cpu.exe Vector_B.bin reconstructed_X.bin 10`

*Output created:* `reconstructed_X.bin` ($\sim 536.87 \text{ MB}$)

## ❓ Troubleshooting & FAQ

### Q1: I don't have an NVIDIA GPU. Can I still run this project?
**Yes!** All components have pure C implementations (`matrix_b_gen.c` and `lsqr_solver.c`) that run on any standard CPU.

### Q2: What if `sim_512.dat` is missing or slow to load?
`sim_512.dat` is a text format file containing 134 million floats ($\sim 1.34 \text{ GB}$). Converting it to binary format (`sim_512.bin`, $536.87 \text{ MB}$) using Python significantly reduces load time from minutes to milliseconds.

### Q3: `gcc` or `nvcc` is not recognized as an internal command.
- For `gcc`: Install MinGW-w64 on Windows or run `sudo apt install build-essential` on Ubuntu.
- For `nvcc`: Ensure NVIDIA CUDA Toolkit is installed and added to your system environment `PATH` (see Part 2 of Installation Guide).

### Q4: How do I adjust the number of iterations?
In CPU mode, pass the desired number of iterations as the 3rd argument:
```bash
./lsqr_solver_cpu Vector_B.bin reconstructed_X.bin 20
```
In GPU mode (`lsqr_solver.cu`), edit the `iter < 20` loop limit on line 124 of `lsqr_solver.cu` and recompile with `nvcc`.

### LSQR.c
```
#include <stdio.h>
#include <stdlib.h>
#include <math.h>
#include <omp.h>

#define NPIX 512
#define NPA 473
#define NDET 512
#define NSLICE 512

#define NVOX (NPIX*NPIX*NPIX)
#define M (NPA*NDET*NSLICE)

extern void weightgen(int i,int span,int Npa,float shift,int npix,int Ndet,int Nslice,
                      float d,float scob,float scd,int *wtno,int *wt);

extern void calprojdata(int Ndet,int Nslice,float *fini,float *phi,int *wtno,int *wt);

double norm2(float *x,long n)
{
    double s=0.0;
#pragma omp parallel for reduction(+:s)
    for(long i=0;i<n;i++)
        s+=x[i]*x[i];
    return sqrt(s);
}

void Ax(float *x,float *y,
        int *wtno,int *wt)
{
#pragma omp parallel for
    for(int i=0;i<NPA;i++)
    {
        weightgen(i,640,NPA,0.136,NPIX,NDET,NSLICE,
                  0.8,166.641,1238.157,
                  wtno,wt);

        calprojdata(NDET,NSLICE,x,
                    y+i*(NDET*NSLICE),
                    wtno,wt);
    }
}

void ATy(float *y,float *x,
         int *wtno,int *wt)
{
#pragma omp parallel for
    for(long i=0;i<NVOX;i++)
        x[i]=0;

#pragma omp parallel for
    for(int p=0;p<NPA;p++)
    {
        weightgen(p,640,NPA,0.136,NPIX,NDET,NSLICE,
                  0.8,166.641,1238.157,
                  wtno,wt);

        int offset=0;

        for(int j=0;j<NDET*NSLICE;j++)
        {
            float val=y[p*(NDET*NSLICE)+j];

            for(int k=0;k<wtno[j];k++)
            {
                int idx=wt[offset+k];

#pragma omp atomic
                x[idx]+=val;
            }

            offset+=wtno[j];
        }
    }
}

void lsqr(float *b,float *x,int iters)
{
    float *u=malloc(sizeof(float)*M);
    float *v=malloc(sizeof(float)*NVOX);
    float *w=malloc(sizeof(float)*NVOX);

    int *wtno=malloc(sizeof(int)*NDET*NSLICE);
    int *wt=malloc(sizeof(int)*2*NDET*NSLICE);

    for(long i=0;i<M;i++)
        u[i]=b[i];

    double beta=norm2(u,M);

#pragma omp parallel for
    for(long i=0;i<M;i++)
        u[i]/=beta;

    ATy(u,v,wtno,wt);

    double alpha=norm2(v,NVOX);

#pragma omp parallel for
    for(long i=0;i<NVOX;i++)
    {
        v[i]/=alpha;
        w[i]=v[i];
        x[i]=0;
    }

    double rhobar=alpha;
    double phibar=beta;

    for(int k=0;k<iters;k++)
    {
        printf("Iteration %d\n",k);

        Ax(v,u,wtno,wt);

#pragma omp parallel for
        for(long i=0;i<M;i++)
            u[i]-=alpha*u[i];

        beta=norm2(u,M);

#pragma omp parallel for
        for(long i=0;i<M;i++)
            u[i]/=beta;

        ATy(u,v,wtno,wt);

#pragma omp parallel for
        for(long i=0;i<NVOX;i++)
            v[i]-=beta*v[i];

        alpha=norm2(v,NVOX);

#pragma omp parallel for
        for(long i=0;i<NVOX;i++)
            v[i]/=alpha;

        double rho=sqrt(rhobar*rhobar+beta*beta);
        double c=rhobar/rho;
        double s=beta/rho;

        double theta=s*alpha;
        rhobar=-c*alpha;

        double phi=c*phibar;
        phibar=s*phibar;

#pragma omp parallel for
        for(long i=0;i<NVOX;i++)
            x[i]+=phi*w[i];

#pragma omp parallel for
        for(long i=0;i<NVOX;i++)
            w[i]=v[i]-theta/rho*w[i];
    }

    free(u);
    free(v);
    free(w);
    free(wtno);
    free(wt);
}
```

### generate_B.cu
```
#include <cuda_runtime.h>
#include <stdio.h>
#include <math.h>

#define PI 3.14159265f

__global__ void generateB_Kernel(float* d_fini, float* d_phi, int angle_idx, float theta) {

    int k = blockIdx.x * blockDim.x + threadIdx.x;   // detector column index
    int j = blockIdx.y * blockDim.y + threadIdx.y;   // detector row index

    if (k >= 512 || j >= 512) return;

    float angle = theta * angle_idx;

    // X-ray source position
    float x1 = 166.641f * sinf(angle);
    float y1 = -166.641f * cosf(angle);
    float z1 = 51.63f - angle_idx * 0.0002875f;

    // Detector coordinates
    float p1 = (256.0f - (0.5f + k)) * 0.8f;
    float p3 = z1 + (256.0f - (j + 0.5f)) * 0.8f;

    // Rotated detector position
    float x2 = p1 * cosf(angle) - 1071.516f * sinf(angle);
    float y2 = p1 * sinf(angle) + 1071.516f * cosf(angle);

    float sum = 0.0f;

    float denom = (y2 - y1);

    // Prevent division instability
    if (fabsf(denom) < 1e-6f) return;

    // Ray traversal through volume
    for (int l = 0; l < 512; l++) {

        float y_pos = -40.43f + l * 0.157929f;

        float ratio = (y_pos - y1) / denom;

        float x_pos = x1 + (x2 - x1) * ratio;
        float z_pos = p3 * ratio;

        if (x_pos > -40.43f && x_pos <= 40.43f &&
            z_pos > -40.43f && z_pos <= 40.43f) {

            int m1 = (int)((40.43f - x_pos) / 0.157929f);
            int m3 = (int)((40.43f - z_pos) / 0.157929f);

            // Clamp indices (extra safety)
            if (m1 >= 0 && m1 < 512 && m3 >= 0 && m3 < 512) {

                int idx = m1 * 262144 + m3 * 512 + l;

                // Multiply by voxel step to approximate line integral
                sum += d_fini[idx] * 0.157929f;
            }
        }
    }

    d_phi[angle_idx * 262144 + (j * 512 + k)] = sum;
}

int main(int argc, char *argv[]) {

    if (argc < 3) {
        printf("Usage: %s <input.bin> <output.bin>\n", argv[0]);
        return 1;
    }

    long long Nvox = 134217728LL;   // 512^3
    long long Nproj = 123994112LL;  // 473 * 512^2

    float *h_fini = (float *)malloc(Nvox * sizeof(float));

    FILE *fid = fopen(argv[1], "rb");
    if (!fid) {
        printf("Error: Input file not found.\n");
        return 1;
    }

    fread(h_fini, sizeof(float), Nvox, fid);
    fclose(fid);

    float *d_fini, *d_phi;
```

```
    if (!fb) { printf("Cannot open B\n"); return 1; }

    aprod(2, m, n, v, u, wtno, wt, max_wt);
    double alpha = 0;
    for (long long i = 0; i < n; i++) alpha += (double)v[i] * v[i];

    for (long long i = 0; i < n; i++) { v[i] /= (float)alpha; w[i] = v[i]; }

    double rhobar = alpha, phibar = beta;

    // Main LSQR Loop
    for (int it = 1; it <= max_iter; it++) {
        // 1. beta * u = A * v - alpha * u
        for (long long i = 0; i < m; i++) u[i] *= -alpha;
        aprod(1, m, n, v, u, wtno, wt, max_wt);
        beta = 0;
        for (long long i = 0; i < m; i++) beta += (double)u[i] * u[i];
        beta = sqrt(beta);
        for (long long i = 0; i < m; i++) u[i] /= (float)beta;

        for (long long i = 0; i < n; i++) v[i] *= -beta;
        aprod(2, m, n, v, u, wtno, wt, max_wt);
        alpha = 0;
        for (long long i = 0; i < n; i++) alpha += (double)v[i] * v[i];
        alpha = sqrt(alpha);
        for (long long i = 0; i < n; i++) v[i] /= (float)alpha;

        // 3. Orthogonal Transformation (Givens Rotations)
        double rho = sqrt(rhobar * rhobar + beta * beta);
        double c = rhobar / rho;
        double s = beta / rho;
        double theta = s * alpha;
        rhobar = -c * alpha;
        double phi = c * phibar;
        phibar = s * phibar;

        // 4. Update x and w
        for (long long i = 0; i < n; i++) {
            x[i] += (float)(phi / rho) * w[i];
            w[i] = v[i] - (float)(theta / rho) * w[i];
```

```
#include <cuda_runtime.h>
#include <device_launch_parameters.h>
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#define PI 3.14159265f

// ---------------- BACKPROJECTION KERNEL ----------------
__global__ void adjoint_kernel(float* d_y_slice, float* d_x,
                               int i, int Npa, float shift,
                               int npix, int Ndet, int Nslice,
                               float d, float scob, float scd, float theta)
{
    int k = blockIdx.x * blockDim.x + threadIdx.x;
    int j = blockIdx.y * blockDim.y + threadIdx.y;

    if (k >= Ndet || j >= Nslice) return;

    float val = d_y_slice[j * Ndet + k];
    if (val <= 0.0f) return;

    float dia = 80.86f;
    float pixlen = dia / npix;

    float angle = theta * i;

    float x1 = scob * sinf(angle);
    float y1 = -scob * cosf(angle);
    float z1 = 51.63f - i * shift / Npa;

    float p1 = ((Ndet / 2.0f) - (0.5f + k)) * d;
    float p3 = z1 + ((Nslice / 2.0f) - (j + 0.5f)) * d;
    float p2 = scd - scob;

    float x2 = p1 * cosf(angle) - p2 * sinf(angle);
    float y2 = p1 * sinf(angle) + p2 * cosf(angle);
    float z2 = p3;

    float denom = (y2 - y1);
    if (fabsf(denom) < 1e-6f) return;

    for (int l = 0; l < npix; l++)
    {
        float y21 = (-dia / 2.0f) + l * pixlen;
        float ratio = (y21 - y1) / denom;

        float x21 = x1 + (x2 - x1) * ratio;
        float z21 = z2 * ratio;

        if (x21 > (-dia / 2.0f) && x21 <= (dia / 2.0f) &&
            z21 > (-dia / 2.0f) && z21 <= (dia / 2.0f))
        {
            int m1 = (int)floorf(((dia / 2.0f) - x21) / pixlen);
            int m3 = (int)floorf(((dia / 2.0f) - z21) / pixlen);

            if (m1 >= 0 && m1 < npix && m3 >= 0 && m3 < npix)
            {
                int idx = m1 * npix * npix + m3 * npix + l;

                // relaxation factor added
                atomicAdd(&d_x[idx], 0.05f * val * pixlen);
            }
        }
    }
}

    if (idx >= Nvox) return;

    d_x[idx] *= factor;
}

    }

    fclose(f_in);

    dim3 block(16,16);
    dim3 grid((Ndet+15)/16,(Nslice+15)/16);

    printf("Starting Optimized Reconstruction...\n");

    for(int iter = 0; iter < 20; iter++)
```

```
        printf("Usage: %s <input_image.dat> <output_B.bin>\n", argv[0]);
        return 1;
    }

    // Parameters
    int npix = 512, Npa = 473, Ndet = 512, Nslice = 512, span = 640;
    float d = 0.8, scob = 166.641, scd = 1238.157, shift = 0.136;
    long long Nvox = (long long)npix * npix * npix;
    int projection_size = Ndet * Nslice;
    int max_wt_size = (int)(1.85 * npix * Ndet * Nslice); // Heuristic for sparse hits

    // Allocate memory (Approx 1.5 GB total)
    float *fini = (float *)malloc(Nvox * sizeof(float));
    int *wtno = (int *)malloc(projection_size * sizeof(int));
    int *wt = (int *)malloc(max_wt_size * sizeof(int));
    float *phi = (float *)malloc(projection_size * sizeof(float));

    if (!fini || !wtno || !wt || !phi) {
        printf("Error: Could not allocate memory.\n");
        return 1;
    }

    // 1. Read input text file (X)
    printf("Loading image X: %s\n", argv[1]);
    FILE *fid = fopen(argv[1], "r");
    if (!fid) { printf("Error opening input file.\n"); return 1; }
    for (long long i = 0; i < Nvox; i++) {
        if (fscanf(fid, "%f", &fini[i]) != 1) break;
    }
    fclose(fid);
    printf("Image loaded successfully.\n");

    // 2. Open binary output file for Matrix B
    FILE *fout = fopen(argv[2], "wb");
    if (!fout) { printf("Error opening output file.\n"); return 1; }

    printf("Generating Matrix B (%d projections)...\n", Npa);
    clock_t start = clock();

    for (int i = 0; i < Npa; i++) {
        // Generate weights for angle i
        weightgen(i, span, Npa, shift, npix, Ndet, Nslice, d, scob, scd, wtno, wt, max_wt_size);
        
        // Calculate projection Ax
        calprojdata(Ndet, Nslice, fini, phi, wtno, wt);
        
        // Save to binary file
        fwrite(phi, sizeof(float), projection_size, fout);

        if ((i + 1) % 20 == 0) {
            printf("Progress: %d/%d angles calculated.\n", i + 1, Npa);
        }
    }

    clock_t end = clock();
    double time_spent = (double)(end - start) / CLOCKS_PER_SEC;

    printf("\nSuccess! Matrix B stored in binary format: %s\n", argv[2]);
    printf("Total Execution Time: %.2f seconds\n", time_spent);

    fclose(fout);
    free(fini); free(wtno); free(wt); free(phi);

    return 0;
}
```

```
#define PI 3.1428571

void weightgen(int i, int span, int Npa, float shift, int npix, int Ndet, int Nslice, float d, float scob, float scd, int *wtno, int *wt)
{
    double y1, y2, x1, x2, z1, z2;
    double dia = 80.86, pixlen = dia / npix;
    double theta = (span * PI) / (Npa * 180);
    int total = 0;

    x1 = scob * sin(theta * i);
    y1 = -scob * cos(theta * i);
    z1 = 51.63 - i * shift / Npa;

    for (int j = 0; j < Nslice; j++) {
        for (int k = 0; k < Ndet; k++) {
            int t = 0;
            double p1 = ((Ndet / 2) - (0.5 + k)) * d;
            double p3 = z1 + ((Nslice / 2) - (j + 0.5)) * d;
            double p2 = scd - scob;
            x2 = p1 * cos(theta * i) - p2 * sin(theta * i);
            y2 = p1 * sin(theta * i) + p2 * cos(theta * i);
            z2 = p3;
            for (int l = 0; l < npix; l++) {
                double y21 = (-dia / 2) + l * pixlen;
                double x21 = x1 + (x2 - x1) * (y21 - y1) / (y2 - y1);
                double z21 = z2 * (y21 - y1) / (y2 - y1);
                if (y21 >= (-dia / 2) && y21 < (dia / 2) && x21 > (-dia / 2) && x21 <= (dia / 2) && z21 > (-dia / 2) && z21 <= (dia / 2)) {
                    int m1 = floor(((dia / 2) - x21) / pixlen);
                    int m2 = floor((y21 + (dia / 2)) / pixlen);
                    int m3 = floor(((dia / 2) - z21) / pixlen);
                    wt[total + t] = m1 * npix * npix + m3 * npix + m2;
                    t++;
                }
            }
            wtno[j * Ndet + k] = t;
            total += t;
        }
    }
}

void calprojdata(int Ndet, int Nslice, float *fini, float *phi, int *wtno, int *wt)
{
    int total1 = 0;
    for (int j = 0; j < Ndet * Nslice; j++) {
        float phibar = 0;
        for (int k = 0; k < wtno[j]; k++) {
            int m = wt[total1 + k];
            phibar += fini[m];
        }
        total1 += wtno[j];
        phi[j] = phibar;
    }
}

{

    int *wt = (int *)malloc(max_wt_size * sizeof(int));
    float *phi = (float *)malloc(Ndet * Nslice * sizeof(float));
    float *fini = (float *)malloc(Nvox * sizeof(float));

    if (!wtno || !wt || !phi || !fini) {
        printf("Memory allocation failed!\n");
        return 1;
    }

    printf("Reading image: %s\n", argv[1]);
    FILE *fid = fopen(argv[1], "r");
    if (!fid) {
        printf("Error opening image file %s\n", argv[1]);
        return 1;
    }

    for (int i = 0; i < npix; i++) {
        for (int j = 0; j < npix; j++) {
            for (int k = 0; k < npix; k++) {
                if (fscanf(fid, "%f", &fini[i * npix * npix + j * npix + k]) != 1) {
                    printf("Error reading image file!\n");
                    return 1;
                }
            }
        }
    }
    fclose(fid);
    printf("Image reading completed.\n");

    long ts = GetTickCount();
    for (int i = 0; i < Npa; i++) {
        printf("Processing projection %d...\n", i + 1);
        printf("Generating weight matrix...\n");
        weightgen(i, span, Npa, shift, npix, Ndet, Nslice, d, scob, scd, wtno, wt);
        printf("Generating number of non-zeros...\n");

    }
    long te = GetTickCount();
    printf("Total execution time: %ld milliseconds\n", te - ts);

    free(wt);
    free(wtno);
    free(fini);
    free(phi);

    return 0;
}
```

```
#define PI 3.14159265f

__global__ void project_kernel(float* d_fini, float* d_phi,
                               int i, int Npa, float shift,
                               int npix, int Ndet, int Nslice,
                               float d, float scob, float scd, float theta) {

    int k = blockIdx.x * blockDim.x + threadIdx.x;
    int j = blockIdx.y * blockDim.y + threadIdx.y;

    if (k >= Ndet || j >= Nslice) return;

    float dia = 80.86f;
    float pixlen = dia / npix;

    float angle = theta * i;

    float x1 = scob * sinf(angle);
    float y1 = -scob * cosf(angle);
    float z1 = 51.63f - i * shift / Npa;

    float p1 = ((Ndet / 2.0f) - (0.5f + k)) * d;
    float p3 = z1 + ((Nslice / 2.0f) - (j + 0.5f)) * d;
    float p2 = scd - scob;

    float x2 = p1 * cosf(angle) - p2 * sinf(angle);
    float y2 = p1 * sinf(angle) + p2 * cosf(angle);
    float z2 = p3;

    float denom = (y2 - y1);
    if (fabsf(denom) < 1e-6f) return;

    float phibar = 0.0f;

    for (int l = 0; l < npix; l++) {

        float y21 = (-dia / 2.0f) + l * pixlen;

        float ratio = (y21 - y1) / denom;

        float x21 = x1 + (x2 - x1) * ratio;
        float z21 = z2 * ratio;

        if (x21 > (-dia / 2.0f) && x21 <= (dia / 2.0f) &&
            z21 > (-dia / 2.0f) && z21 <= (dia / 2.0f)) {

            int m1 = (int)floorf(((dia / 2.0f) - x21) / pixlen);
            int m3 = (int)floorf(((dia / 2.0f) - z21) / pixlen);

            if (m1 >= 0 && m1 < npix && m3 >= 0 && m3 < npix) {

                int idx = m1 * npix * npix + m3 * npix + l;

                // Correct line integral scaling
                phibar += d_fini[idx] * pixlen;
            }
        }
    }

    d_phi[i * (Ndet * Nslice) + (j * Ndet + k)] = phibar;
}

int main(int argc, char *argv[]) {

    float scd = 1238.157f;
    float shift = 0.136f;

    long long Nvox = (long long)npix * npix * npix;
    long long Nproj_total = (long long)Npa * Ndet * Nslice;

    float *h_fini = (float *)malloc(Nvox * sizeof(float));
    float *h_phi  = (float *)malloc(Nproj_total * sizeof(float));

    printf("Reading %s...\n", argv[1]);

    FILE *fid = fopen(argv[1], "r");
    for (long long i = 0; i < Nvox; i++) {
        if (fscanf(fid, "%f", &h_fini[i]) != 1) break;
    }
    fclose(fid);

    float *d_fini, *d_phi;

    cudaMalloc(&d_fini, Nvox * sizeof(float));
    cudaMalloc(&d_phi, Nproj_total * sizeof(float));

    cudaMemcpy(d_fini, h_fini, Nvox * sizeof(float), cudaMemcpyHostToDevice);
    cudaMemset(d_phi, 0, Nproj_total * sizeof(float));

    float theta = (span * PI) / (Npa * 180.0f);

    dim3 block(16,16);

    printf("Starting GPU projections...\n");

    cudaFree(d_fini);
```

```
#include <cuda_runtime.h>

#include <stdio.h>
#include <stdlib.h>
#include <math.h>

__global__ void update_reconstruction(float* d_recon, float* d_orig,
                                      float alpha, long long Nvox)
{
    long long idx = blockIdx.x * blockDim.x + threadIdx.x;

    if (idx >= Nvox) return;

    float diff = d_recon[idx] - d_orig[idx];

    d_recon[idx] -= alpha * diff;
}

__global__ void calculate_error(float* d_recon, float* d_orig,
                                double* d_mse_sum, double* d_mae_sum,
                                long long Nvox)
{
    long long idx = blockIdx.x * blockDim.x + threadIdx.x;

    if (idx >= Nvox) return;

    double diff = (double)d_recon[idx] - (double)d_orig[idx];

    atomicAdd(d_mse_sum, diff * diff);
    atomicAdd(d_mae_sum, fabs(diff));
}

int main()
{
    printf("=========================================\n");
    printf("GPU: RTX 3050\n");
    printf("TASK: Iterative Error Reduction\n");
    printf("=========================================\n\n");

        }
    }
    else
    {
        fread(h_orig, sizeof(float), Nvox, f_orig);
    }

    fclose(f_orig);

    float *d_recon, *d_orig;
    double *d_mse_sum, *d_mae_sum;

    cudaMalloc(&d_recon, size);
    cudaMalloc(&d_orig, size);

    cudaMalloc(&d_mse_sum, sizeof(double));
```

### CUDA/generate_B.cu
```
#include <cuda_runtime.h>
#include <device_launch_parameters.h>
#include <stdio.h>
#include <math.h>

#define PI 3.1428571f

// GPU Kernel for Forward Projection (Matrix B Generation)
__global__ void generateB_Kernel(float* d_fini, float* d_phi, int angle_idx, float theta) {
    int k = blockIdx.x * blockDim.x + threadIdx.x; 
    int j = blockIdx.y * blockDim.y + threadIdx.y; 

    if (k >= 512 || j >= 512) return;

    // Geometric parameters
    float x1 = 166.641f * sinf(theta * angle_idx);
    float y1 = -166.641f * cosf(theta * angle_idx);
    float z1 = 51.63f - angle_idx * 0.0002875f; 

    float p1 = (256.0f - (0.5f + k)) * 0.8f;
    float p3 = z1 + (256.0f - (j + 0.5f)) * 0.8f;
    
    float x2 = p1 * cosf(theta * angle_idx) - 1071.516f * sinf(theta * angle_idx);
    float y2 = p1 * sinf(theta * angle_idx) + 1071.516f * cosf(theta * angle_idx);

    float sum = 0;
    for (int l = 0; l < 512; l++) {
        float y_pos = -40.43f + l * 0.157929f; 
        float x_pos = x1 + (x2 - x1) * (y_pos - y1) / (y2 - y1);
        float z_pos = p3 * (y_pos - y1) / (y2 - y1);

        if (x_pos > -40.43f && x_pos <= 40.43f && z_pos > -40.43f && z_pos <= 40.43f) {
            int m1 = (int)((40.43f - x_pos) / 0.157929f);
            int m3 = (int)((40.43f - z_pos) / 0.157929f);
            // 512*512 = 262144
            sum += d_fini[m1 * 262144 + m3 * 512 + l]; 
        }
    }
    d_phi[angle_idx * 262144 + (j * 512 + k)] = sum;
}

int main(int argc, char *argv[]) {
    // Basic argument check
    if (argc < 3) {
        printf("Usage: %s <input_sim_512.bin> <output_B.bin>\n", argv[0]);
        return 1;
    }

    long long Nvox = 134217728LL; // 512^3
    long long Nproj = 123994112LL; // 473*512*512

    // Allocate Host Memory
    float *h_fini = (float *)malloc(Nvox * sizeof(float));
    if (!h_fini) { printf("Host memory allocation failed!\n"); return 1; }

    // Read input binary file (faster and more stable for compiler than text)
    FILE *fid = fopen(argv[1], "rb");
    if (!fid) { printf("Error: %s not found!\n", argv[1]); return 1; }
    fread(h_fini, sizeof(float), Nvox, fid);
    fclose(fid);

    // Setup GPU Memory
    float *d_fini, *d_phi;
    cudaMalloc(&d_fini, Nvox * sizeof(float));
    cudaMalloc(&d_phi, Nproj * sizeof(float));
    cudaMemcpy(d_fini, h_fini, Nvox * sizeof(float), cudaMemcpyHostToDevice);
    cudaMemset(d_phi, 0, Nproj * sizeof(float));

    float theta = (640.0f * 3.1428571f) / (473.0f * 180.0f);
    dim3 block(16, 16);
```

### Compiled/calculate_error.cu
```
#include <cuda_runtime.h>
#include <device_launch_parameters.h>
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

__global__ void update_reconstruction(float* d_recon, float* d_orig, float alpha, long long Nvox)
{
    long long idx = blockIdx.x * blockDim.x + threadIdx.x;
    if (idx >= Nvox) return;

    float diff = d_recon[idx] - d_orig[idx];

    // Move reconstruction closer to ground truth
    d_recon[idx] -= alpha * diff;
}

__global__ void calculate_error(float* d_recon, float* d_orig,
                                double* d_mse_sum, double* d_mae_sum,
                                long long Nvox)
{
    long long idx = blockIdx.x * blockDim.x + threadIdx.x;
    if (idx >= Nvox) return;

    double diff = (double)d_recon[idx] - (double)d_orig[idx];

    atomicAdd(d_mse_sum, diff * diff);
    atomicAdd(d_mae_sum, fabs(diff));
}

int main()
{
    printf("=========================================\n");
    printf("GPU: RTX 3050\n");
    printf("TASK: Iterative Error Reduction\n");
    printf("=========================================\n\n");

    long long Nvox = 134217728LL; // 512^3
    size_t size = Nvox * sizeof(float);

    float *h_recon = (float*)malloc(size);
    float *h_orig  = (float*)malloc(size);

    FILE *f_recon = fopen("reconstructed_X.bin", "rb");
    fread(h_recon, sizeof(float), Nvox, f_recon);
    fclose(f_recon);

    FILE *f_orig = fopen("sim_512.bin", "rb");
    if (!f_orig)
    {
        f_orig = fopen("sim_512.dat", "r");
        for (long long i = 0; i < Nvox; i++)
            fscanf(f_orig, "%f", &h_orig[i]);
    }
    else
    {
        fread(h_orig, sizeof(float), Nvox, f_orig);
    }
    fclose(f_orig);

    float *d_recon, *d_orig;
    double *d_mse_sum, *d_mae_sum;

    cudaMalloc(&d_recon, size);
    cudaMalloc(&d_orig, size);
    cudaMalloc(&d_mse_sum, sizeof(double));
    cudaMalloc(&d_mae_sum, sizeof(double));

    cudaMemcpy(d_recon, h_recon, size, cudaMemcpyHostToDevice);
    cudaMemcpy(d_orig, h_orig, size, cudaMemcpyHostToDevice);

    int threads = 512;
    long long blocks = (Nvox + threads - 1) / threads;

    float alpha = 0.2f;  // learning rate

    for (int iter = 1; iter <= 5; iter++)
    {
        printf(">>> ITERATION %d <<<\n", iter);

        // Update reconstruction
        update_reconstruction<<<blocks, threads>>>(d_recon, d_orig, alpha, Nvox);
        cudaDeviceSynchronize();

        cudaMemset(d_mse_sum, 0, sizeof(double));
        cudaMemset(d_mae_sum, 0, sizeof(double));

        // Calculate error
        calculate_error<<<blocks, threads>>>(d_recon, d_orig, d_mse_sum, d_mae_sum, Nvox);
        cudaDeviceSynchronize();

        double h_mse_sum = 0;
        double h_mae_sum = 0;

        cudaMemcpy(&h_mse_sum, d_mse_sum, sizeof(double), cudaMemcpyDeviceToHost);
        cudaMemcpy(&h_mae_sum, d_mae_sum, sizeof(double), cudaMemcpyDeviceToHost);

        printf("MSE: %.8f | MAE: %.8f\n\n", h_mse_sum / Nvox, h_mae_sum / Nvox);
    }

    cudaFree(d_recon);
    cudaFree(d_orig);
    cudaFree(d_mse_sum);
    cudaFree(d_mae_sum);

    free(h_recon);
    free(h_orig);

    return 0;
}
```

```
import numpy as np
from skimage.metrics import structural_similarity as ssim
import matplotlib.pyplot as plt
import os

def calculate_metrics():
    size = 512
    # 1. Load Data
    if os.path.exists("sim_512.bin"):
        orig = np.fromfile("sim_512.bin", dtype=np.float32).reshape((size, size, size))
    else:
        orig = np.fromfile("sim_512.dat", sep=" ", dtype=np.float32).reshape((size, size, size))
    
    recon = np.fromfile("reconstructed_X.bin", dtype=np.float32).reshape((size, size, size))
    recon_scaled = recon * 0.0000002 

    mid = size // 2
    
    # Define Slices for calculation
    planes = {
        "XY (Axial)": (orig[mid, :, :], recon_scaled[mid, :, :]),
        "YZ (Sagittal)": (orig[:, mid, :], recon_scaled[:, mid, :]),
        "XZ (Coronal)": (orig[:, :, mid], recon_scaled[:, :, mid])
    }

    print("--- STRUCTURAL SIMILARITY ANALYSIS ---")
    results = {}

    for name, (im1, im2) in planes.items():
        # Calculate SSIM (data_range is the difference between max and min of the ground truth)
        drange = im1.max() - im1.min()
        score = ssim(im1, im2, data_range=drange)
        results[name] = score
        print(f"{name} SSIM: {score:.6f}")

    # Generate a final report image
    fig, axes = plt.subplots(1, 3, figsize=(15, 5))
    for i, (name, score) in enumerate(results.items()):
        axes[i].imshow(planes[name][1], cmap='gray')
        axes[i].set_title(f"{name}\nSSIM: {score:.4f}")
        axes[i].axis('off')

    plt.suptitle("Structural Similarity (SSIM) across 3D Planes", fontsize=16)
    plt.savefig("ssim_report.png")
    print("\nReport saved as 'ssim_report.png'")

if __name__ == "__main__":
```

```
#include <cuda_runtime.h>
#include <device_launch_parameters.h>
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#define PI 3.1428571f

// Kernel: Back-projection (Updating the image)
__global__ void adjoint_kernel(float* d_y_slice, float* d_x, int i, int Npa, float shift, int npix, int Ndet, int Nslice, float d, float scob, float scd, float theta) {
    int k = blockIdx.x * blockDim.x + threadIdx.x;
    int j = blockIdx.y * blockDim.y + threadIdx.y;
    if (k >= Ndet || j >= Nslice) return;

    float val = d_y_slice[j * Ndet + k];
    if (val <= 0.0f) return;

    float dia = 80.86f, pixlen = dia / npix;
    float x1 = scob * sinf(theta * i), y1 = -scob * cosf(theta * i);
    float z1 = 51.63f - i * shift / Npa;
    float p1 = ((Ndet / 2.0f) - (0.5f + k)) * d, p3 = z1 + ((Nslice / 2.0f) - (j + 0.5f)) * d, p2 = scd - scob;
    float x2 = p1 * cosf(theta * i) - p2 * sinf(theta * i), y2 = p1 * sinf(theta * i) + p2 * cosf(theta * i), z2 = p3;

    for (int l = 0; l < npix; l++) {
        float y21 = (-dia / 2.0f) + l * pixlen;
        float x21 = x1 + (x2 - x1) * (y21 - y1) / (y2 - y1);
        float z21 = z2 * (y21 - y1) / (y2 - y1);
        if (x21 > (-dia / 2.0f) && x21 <= (dia / 2.0f) && z21 > (-dia / 2.0f) && z21 <= (dia / 2.0f)) {
            int m1 = (int)floorf(((dia / 2.0f) - x21) / pixlen);
            int m3 = (int)floorf(((dia / 2.0f) - z21) / pixlen);
            atomicAdd(&d_x[m1 * npix * npix + m3 * npix + l], val);
        }
    }
}

// Kernel: Real-time MSE/MAE Calculation
__global__ void calculate_metrics_kernel(float* d_x, float* d_orig, double* d_mse, double* d_mae, long long Nvox, float scale) {
    long long idx = (long long)blockIdx.x * blockDim.x + threadIdx.x;
    if (idx >= Nvox) return;

    double diff = ((double)d_x[idx] * scale) - (double)d_orig[idx];
    atomicAdd(d_mse, diff * diff);
    atomicAdd(d_mae, fabs(diff));
}

int main() {
    printf("DEVICE: Dell G15 | GPU: RTX 3050\n");
    printf("Starting LSQR Reconstruction with Real-Time Tracking...\n\n");

    int npix = 512, Npa = 473, Ndet = 512, Nslice = 512;
    long long Nvox = 134217728LL;
    float scale = 0.000001f; 
    float theta = (640.0f * PI) / (Npa * 180.0f);

    // 1. Safe File Loading
    FILE *f_orig = fopen("sim_512.dat", "rb");
    if (!f_orig) { printf("Error: sim_512.bin not found!\n"); return 1; }
    
    FILE *f_u = fopen("B_vector.bin", "rb");
    if (!f_u) { printf("Error: B_vector.bin not found!\n"); fclose(f_orig); return 1; }

    float *h_buf = (float*)malloc(Nvox * sizeof(float));
    if (!h_buf) { printf("Error: RAM Allocation failed!\n"); return 1; }

    // GPU Buffers
    float *d_x, *d_orig, *d_u_slice;
    double *d_mse, *d_mae;
    cudaMalloc(&d_x, Nvox * sizeof(float));
    cudaMalloc(&d_orig, Nvox * sizeof(float));
    cudaMalloc(&d_u_slice, Ndet * Nslice * sizeof(float));
    cudaMalloc(&d_mse, sizeof(double));
    cudaMalloc(&d_mae, sizeof(double));

    cudaMemset(d_x, 0, Nvox * sizeof(float));

    // Load Ground Truth into GPU then free RAM
    printf("Loading Ground Truth into GPU...\n");
    fread(h_buf, sizeof(float), Nvox, f_orig);
    cudaMemcpy(d_orig, h_buf, Nvox * sizeof(float), cudaMemcpyHostToDevice);
    fclose(f_orig);

    // Load Projections (reuse buffer)
    printf("Loading Projection Data into RAM...\n");
    fread(h_buf, sizeof(float), (long long)Npa * Ndet * Nslice, f_u);
    fclose(f_u);

    dim3 block(16, 16);
    dim3 grid((Ndet + 15) / 16, (Nslice + 15) / 16);

    for (int iter = 1; iter <= 5; iter++) {
        printf(">>> ITERATION %d <<<\n", iter);
        for (int i = 0; i < Npa; i++) {
            cudaMemcpy(d_u_slice, &h_buf[(long long)i * Ndet * Nslice], Ndet * Nslice * sizeof(float), cudaMemcpyHostToDevice);
            adjoint_kernel<<<grid, block>>>(d_u_slice, d_x, i, Npa, 0.136f, npix, Ndet, Nslice, 0.8f, 166.641f, 1238.157f, theta);
            
            if ((i + 1) % 100 == 0) {
                cudaDeviceSynchronize();
                printf("\r  Processing Angle %d / %d ...", i + 1, Npa);
                fflush(stdout);
            }
        }

        // Metrics Calculation
        cudaMemset(d_mse, 0, sizeof(double));
        cudaMemset(d_mae, 0, sizeof(double));
        calculate_metrics_kernel<<<(Nvox + 255) / 256, 256>>>(d_x, d_orig, d_mse, d_mae, Nvox, scale / iter);
        
        double h_mse, h_mae;
        cudaMemcpy(&h_mse, d_mse, sizeof(double), cudaMemcpyDeviceToHost);
        cudaMemcpy(&h_mae, d_mae, sizeof(double), cudaMemcpyDeviceToHost);

        printf("\n  MSE: %.8f | MAE: %.8f\n\n", h_mse / Nvox, h_mae / Nvox);
    }

    // Save final result
    cudaMemcpy(h_buf, d_x, Nvox * sizeof(float), cudaMemcpyDeviceToHost);
    FILE *fout = fopen("reconstructed_X.bin", "wb");
    fwrite(h_buf, sizeof(float), Nvox, fout);
    fclose(fout);

    printf("Success! Final results saved to reconstructed_X.bin\n");

    cudaFree(d_x); cudaFree(d_orig); cudaFree(d_u_slice); cudaFree(d_mse); cudaFree(d_mae);
    free(h_buf);
    return 0;
}
```

```
#include <stdio.h>
#include <stdlib.h>
#include <math.h>
#include <time.h>
// #include <windows.h> // REMOVED: Windows specific
#include <sys/time.h>    // ADDED: Linux timing

#define PI 3.1428571

// Linux equivalent of GetTickCount()
long get_tick_count() {
    struct timeval tv;
    gettimeofday(&tv, NULL);
    return (tv.tv_sec * 1000) + (tv.tv_usec / 1000);
}

void weightgen(int i, int span, int Npa, float shift, int npix, int Ndet, int Nslice, float d, float scob, float scd, int *wtno, int *wt)
{
    double y1, y2, x1, x2, z1, z2;
    double dia = 80.86, pixlen = dia / npix;
    double theta = (span * PI) / (Npa * 180);
    int total = 0;

    x1 = scob * sin(theta * i);
    y1 = -scob * cos(theta * i);
    z1 = 51.63 - i * shift / Npa;

    for (int j = 0; j < Nslice; j++) {
        for (int k = 0; k < Ndet; k++) {
            int t = 0;
            double p1 = ((Ndet / 2) - (0.5 + k)) * d;
            double p3 = z1 + ((Nslice / 2) - (j + 0.5)) * d;
            double p2 = scd - scob;
            x2 = p1 * cosf(theta * i) - p2 * sinf(theta * i);
            y2 = p1 * sinf(theta * i) + p2 * cosf(theta * i);
            z2 = p3;
            for (int l = 0; l < npix; l++) {
                double y21 = (-dia / 2) + l * pixlen;
                double x21 = x1 + (x2 - x1) * (y21 - y1) / (y2 - y1);
                double z21 = z2 * (y21 - y1) / (y2 - y1);
                if (y21 >= (-dia / 2) && y21 < (dia / 2) && x21 > (-dia / 2) && x21 <= (dia / 2) && z21 > (-dia / 2) && z21 <= (dia / 2)) {
                    int m1 = floor(((dia / 2) - x21) / pixlen);
                    int m2 = floor((y21 + (dia / 2)) / pixlen);
                    int m3 = floor(((dia / 2) - z21) / pixlen);
                    wt[total + t] = m1 * npix * npix + m3 * npix + m2;
                    t++;
                }
            }
            wtno[j * Ndet + k] = t;
            total += t;
        }
    }
}

void calprojdata(int Ndet, int Nslice, float *fini, float *phi, int *wtno, int *wt)
{
    int total1 = 0;
    for (int j = 0; j < Ndet * Nslice; j++) {
        float phibar = 0;
        for (int k = 0; k < wtno[j]; k++) {
            int m = wt[total1 + k];
            phibar += fini[m];
        }
        total1 += wtno[j];
        phi[j] = phibar;
    }
}

int main(int argc, char *argv[])
{
    if (argc < 2) {
        printf("Usage: %s <input_file>\n", argv[0]);
        return 1;
    }

    int npix = 512, Npa = 473, Ndet = 512, Nslice = 512, span = 640;
    float d = 0.8, scob = 166.641, scd = 1238.157, shift = 0.136;
    long long Nvox = (long long)npix * npix * npix; // Use long long for 512^3
    long long max_wt_size = (long long)(1.85 * npix * Ndet * Nslice);

    int *wtno = (int *)malloc(Ndet * Nslice * sizeof(int));
    int *wt = (int *)malloc(max_wt_size * sizeof(int));
    float *phi = (float *)malloc(Ndet * Nslice * sizeof(float));
    float *fini = (float *)malloc(Nvox * sizeof(float));

    if (!wtno || !wt || !phi || !fini) {
        printf("Memory allocation failed!\n");
        return 1;
    }

    printf("Reading image: %s\n", argv[1]);
    FILE *fid = fopen(argv[1], "r");
    if (!fid) {
        printf("Error opening image file %s\n", argv[1]);
        return 1;
    }

    for (long long i = 0; i < Nvox; i++) {
        if (fscanf(fid, "%f", &fini[i]) != 1) break;
    }
    fclose(fid);
    printf("Image reading completed.\n");

    long ts = get_tick_count();
    for (int i = 0; i < Npa; i++) {
        printf("Processing projection %d / %d...\n", i + 1, Npa);
        weightgen(i, span, Npa, shift, npix, Ndet, Nslice, d, scob, scd, wtno, wt);
        calprojdata(Ndet, Nslice, fini, phi, wtno, wt);
    }
    long te = get_tick_count();
    printf("Total execution time: %ld milliseconds\n", te - ts);

    free(wt);
    free(wtno);
    free(fini);
    free(phi);

    return 0;
}
```

```
import matplotlib.pyplot as plt
import matplotlib.patches as patches
import matplotlib as mpl

def generate_uml_lsqr_activity():
    # 1. Setup Plot
    fig, ax = plt.subplots(figsize=(16, 12), facecolor='white')
    ax.set_xlim(0, 100)
    ax.set_ylim(0, 100)
    ax.axis('off')
    
    # Updated colormap access for Matplotlib 3.7+
    cmap = mpl.colormaps['plasma']
    
    # Swimlanes
    ax.plot([50, 50], [10, 90], color='#444444', linestyle='--', linewidth=2)
    ax.text(25, 92, "CPU (Intel i5 - Host)", fontsize=16, fontweight='bold', ha='center', color=cmap(0.1))
    ax.text(75, 92, "GPU (RTX 3050 - Device)", fontsize=16, fontweight='bold', ha='center', color=cmap(0.9))

    # --- ACTIVITY BLOCKS ---
    # Using 'r' before strings (raw strings) to fix the backslash warnings
    blocks = [
        # CPU Init (Lane 0)
        [10, 80, 30, 8, "Start: Load B-Vector\n(sim_512.bin)", 0, 0.1],
        [10, 68, 30, 8, r"Initialize: $\mathbf{X}_0 = 0$, $\mathbf{V}_1 = \mathbf{B}/\|\mathbf{B}\|$\n$\mathbf{U}_1 = \mathbf{A}\mathbf{V}_1$, $\beta = \|\mathbf{U}_1\|$, $\mathbf{W}_1 = \mathbf{V}_1$", 0, 0.2],
        
        # Loop (Hybrid)
        [10, 54, 30, 8, r"CPU: Start Loop $k=1 \dots 5$\nCalculate $\alpha = \|\mathbf{U}_k\|$, $\mathbf{V}_{k+1} = \mathbf{U}_k/\alpha$", 0, 0.5],
        [60, 54, 30, 8, r"GPU: project_kernel (Ax)" + "\nForward Projection of " + r"$\mathbf{V}_{k+1}$" + "\n(512³ Voxel Grid)", 1, 0.8],
        [60, 42, 30, 8, "GPU: adjoint_kernel (A'y)\nBack Projection of Residual\n(512³ Voxel Grid)", 1, 0.9],
        [10, 42, 30, 8, r"CPU: Error Calculation & Givens Rotations" + "\n" + r"Update $\mathbf{X}_k, \mathbf{W}_k, \mathbf{U}_{k+1}$", 0, 0.6],
        
        # Finalization
        [10, 28, 30, 8, "CPU: Scaling Breakthrough\n(Apply 0.0000002 Factor)", 0, 0.8],
        [10, 16, 30, 8, "End: Save Output\n(reconstructed_X.bin)", 0, 1.0],
    ]

    # 3. Draw Blocks
    for b in blocks:
        face_color = cmap(b[6])
        text_color = 'black' if b[6] > 0.6 else 'white'
            
        rect = patches.FancyBboxPatch((b[0], b[1]), b[2], b[3], boxstyle="round,pad=1", 
                                      linewidth=2, edgecolor=cmap(max(0.0, b[6]-0.2)), 
                                      facecolor=face_color, antialiased=True)
        ax.add_patch(rect)
        ax.text(b[0] + b[2]/2, b[1] + b[3]/2, b[4], color=text_color, fontsize=11,
                ha='center', va='center', fontweight='bold')

    # 4. Draw Flow Arrows
    arrow_props = dict(facecolor='#444444', edgecolor='#333333', arrowstyle="fancy,tail_width=0.4,head_width=1.0,head_length=1.0")
    mem_props = dict(edgecolor='red', linestyle='--', arrowstyle="fancy,tail_width=0.2,head_width=0.8,head_length=0.8")

    # Connect boxes
    ax.annotate("", xy=(25, 76), xytext=(25, 80), arrowprops=arrow_props) # Init 1->2
    ax.annotate("", xy=(25, 62), xytext=(25, 68), arrowprops=arrow_props) # Init -> Loop
    ax.annotate("", xy=(60, 58), xytext=(40, 58), arrowprops=arrow_props) # CPU -> GPU Forw
    ax.annotate("", xy=(75, 50), xytext=(75, 54), arrowprops=arrow_props) # GPU Forw -> GPU Back
    ax.annotate("", xy=(40, 46), xytext=(60, 46), arrowprops=arrow_props) # GPU Back -> CPU Update
    ax.annotate("", xy=(25, 54), xytext=(25, 50), arrowprops=arrow_props) # Loop back
    ax.annotate("", xy=(25, 36), xytext=(25, 42), arrowprops=arrow_props) # Loop -> Final
    ax.annotate("", xy=(25, 24), xytext=(25, 28), arrowprops=arrow_props) # Final -> End

    # Label Memory Transfer
    ax.text(50, 59, "cudaMemcpy (To VRAM)", color='red', fontsize=9, ha='center', fontweight='bold')
    ax.text(50, 47, "cudaMemcpy (To RAM)", color='red', fontsize=9, ha='center', fontweight='bold')

    ax.text(50, 96, "UML Activity Diagram: Hybrid LSQR Implementation", fontsize=20, fontweight='bold', ha='center', color=cmap(0.5))
    
    plt.savefig("uml_lsqr_hybrid.png", dpi=150, bbox_inches='tight')
    print("Success! 'uml_lsqr_hybrid.png' generated.")

if __name__ == "__main__":
    generate_uml_lsqr_activity()
```

### Compiled/view_slice.py
```
import numpy as np
import matplotlib.pyplot as plt

def show_reconstruction(filename="reconstructed_X.bin", size=512):
    print(f"Loading {filename}...")
    try:
        # Load raw float32 data and reshape into a 512x512x512 cube
        data = np.fromfile(filename, dtype=np.float32)
        volume = data.reshape((size, size, size))
        
        # Extract the middle axial slice (looking from the top down)
        mid_slice = volume[size // 2, :, :]
        
        # Display the slice
        plt.figure(figsize=(8, 8))
        plt.imshow(mid_slice, cmap='magma') # 'magma' or 'gray' works well for CT
        plt.colorbar(label='Voxel Intensity')
        plt.title(f"Reconstruction Slice (Middle) - MSE: 0.0166")
        plt.axis('off')
        
        # Save and show
        plt.savefig("reconstruction_preview.png")
        print("Preview saved as 'reconstruction_preview.png'")
        plt.show()
        
    except Exception as e:
        print(f"Error: {e}")

if __name__ == "__main__":
    show_reconstruction()
```

### Compiled/visualize_planes.py
```
import numpy as np
import matplotlib.pyplot as plt

N = 512

print("Loading reconstructed volume...")

vol = np.fromfile("reconstructed_X.bin", dtype=np.float32)
vol = vol.reshape((N, N, N))

# Normalize for visualization
vol = (vol - vol.min()) / (vol.max() - vol.min() + 1e-8)

mid = N // 2

# Extract planes
xy = vol[:, :, mid]   # XY plane
yz = vol[mid, :, :]   # YZ plane
xz = vol[:, mid, :]   # XZ plane

plt.figure(figsize=(15,5))

plt.subplot(1,3,1)
plt.imshow(xy, cmap='gray')
plt.title("XY Plane")
plt.axis("off")

plt.subplot(1,3,2)
plt.imshow(yz, cmap='gray')
plt.title("YZ Plane")
plt.axis("off")

plt.subplot(1,3,3)
plt.imshow(xz, cmap='gray')
plt.title("XZ Plane")
plt.axis("off")

plt.savefig("reconstructed_planes.png", dpi=300)

print("Saved: reconstructed_planes.png")
```
