Closes #127
Ports the three remaining level-surface extractors:
src/SurfaceExtractorCubes.ts — cube-based extraction with the vertex-edge
table and ear-clipping; the six face routines resolve the four-cut face
ambiguity by the sign of f00*f11 - f01*f10, adding a branch point in the
plus-sign (det == 0) case.
src/SurfaceExtractorTetrahedra.ts — 5-tetrahedra-per-cube extraction with
linear interpolation, covering all 81 sign patterns including the
zero-valued (degenerate) ones.
src/SurfaceExtractorMC.ts — Marching Cubes extraction over an Image3,
built on the already-ported MarchingCubes 256-entry table.
Port decisions (also recorded in the file headers):
SurfaceExtractorCubes/SurfaceExtractorTetrahedra derive from the ported
SurfaceExtractor base (B20): the upstream pure virtual
Extract(level, vertices&, triangles&) is extractRational(level), which
returns the two arrays.
Nested types are exported with the file-qualified names
SurfaceExtractorTetrahedraEdge and SurfaceExtractorMCMesh; the cubes
VETable/TVertex stay module-private.
SurfaceExtractorMC derives from MarchingCubes. The two upstream
Extract overloads become extractVoxel(level, perturb, F) (returning
{ valid, mesh }) and extract(level, perturb), per the precedent that
only the canonical query keeps the plain name.
The tetrahedra extractor replaces std::map<Vertex,int32_t> and
std::set<Edge>/std::set<Triangle> with Maps keyed by canonical
strings (rationals reduced to lowest terms). Vertex indices are assigned in
insertion order, as upstream; edges and triangles are sorted at the end by
the upstream operator< so the reported ordering matches std::set
iteration order. getEdges() exposes the edge set that upstream computes
but discards.
int64_t internal arithmetic maps onto IEEE doubles, exact while products
stay in the safe-integer range (the same constraint upstream has at 2^63).
Tests: 60 new cases across the three files. Structural validation of all 256
Marching Cubes entries (cut edges are exactly the sign-changing voxel edges,
j0 < j1, edges differ in one corner bit, triangles reference existing
distinct vertices, complementary entries cut the same edges, per-voxel
extraction agrees with the table for all 256 configurations); planar fields
give exactly flat output; sphere fields give vertices within half a voxel of
the true radius and a closed edge-manifold mesh; perturb == 0 vs nonzero on
a level that hits voxel values; the three cubes face-ambiguity resolutions
(det > 0, det < 0, det == 0 branch point) with the same cut edges in
all three; the tetrahedra degenerate level through grid values (including the
all-zero tetrahedron); gradient exactness on linear fields and zero outside
the image; orientation and unit-length normals; and cross-checks between the
cubes and tetrahedra extractors on the same level surface (they solve
2V - (2L+1) = 0 and V - L = 0 respectively, so doubling the voxels and
using level 2L+1 makes them extract the same surface).
Upstream bug suspects
SurfaceExtractorTetrahedra.h, GetGradient, odd-parity branch (~line 296).
The odd-parity cube is partitioned into four corner tetrahedra plus a central
one, selected by half-space tests:
```
if (dx - dy - dz >= (Real)0)        { /* 1205 */ }
else if (dx - dy + dz <= (Real)0)   { /* 3027 */ }
else if (dx + dy - dz <= (Real)0)   { /* 4750 */ }
else if (dx + dy + dz >= (Real)0)   { /* 6572 */ }
else                                { /* 0752 */ }
```
dx, dy, dz are the fractional offsets within the voxel, so
dx + dy + dz >= 0 is unconditionally true. The 6572 corner tetrahedron
therefore absorbs the central tetrahedron and the 0752 branch is
unreachable. The plane through (1,1,0), (1,0,1) and (0,1,1) that cuts
off the corner (1,1,1) is dx + dy + dz = 2; the even-parity branch
directly below uses the analogous cutting planes at 1 and is correct. The
port fixes this (dx + dy + dz >= 2), because the wrong gradient corrupts
orientTriangles results for every point of an odd-parity voxel that lies in
the central tetrahedron. The fix is documented in a code comment at the site
and is covered by the test
selects the correct tetrahedron in an odd-parity voxel.
