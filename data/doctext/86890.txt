# Marching-Cubes-Terrain  
Unity implementation of voxel terrain using **Marching Cubes**, **Signed Distance Functions**, and **indirect rendering**.  

Made by Jack Welfer.

**Watch the demo!**
[![Watch the demo](Images/DemoThumbnail.png)](https://www.youtube.com/watch?v=wEyjIHqGbDA)  

---

## Key Features
- GPU voxel evaluation with compute shaders  
- Marching Cubes fully on GPU (no CPU readback or stalls)  
- Indirect rendering with procedural draw calls  
- Chunk-based LOD with per-chunk AABB culling  
- Buffer pooling & manual resource management  
- Extensively Profiled to achieve render thread of ~1.5ms 

---

## Overview
Hello and thanks for checking out my repo!  
This project is part of a larger game I’m building called **Fight Game**. A big philosophy I’ve had since starting in February 2023 is removing as many “immersion breakers” as possible. One of the biggest immersion boosts is making terrain feel alive and dynamic, which is why I went down the rabbit hole of voxel terrain.  

At a high level:  
- Voxels give me a way to represent volume in 3D space.  
- Signed Distance Functions (SDFs) define shapes by returning the distance from a point to the surface.  
- Marching Cubes interpolates those voxel values into triangles via a lookup table.  
- Everything is computed and rendered on the GPU for speed.  

All in all, I'm very satisfied with the results. Comparing the performance to other popular solutions on the Unity Asset Store, I've achieved results that run 2-3x faster than most GPU-CPU approaches.

---
## What I learned & what I’ll change next time

- Small, verified steps work. Tight feedback loops kept regressions low.  

- The hard part was **readability vs. performance**. Hidden state and side effects made the top-level flow harder to follow.  

- Next time I’ll use a **functional core, imperative shell**:  
  - Keep hot paths (kernels/tight loops) optimized, but isolate them behind pure functions with explicit inputs/outputs.  
  - Push mutations to the edges (I/O, buffers), avoid shared globals, and pass a context struct instead.  




## The Algorithm (Step by Step)

### Chunking
The world is subdivided into chunks. Each chunk has a defined **ChunkDimensions** (world size) and **ChunkResolution** (grid count). This makes it easy to parallelize work and later assign LODs or cull chunks.  

![Chunks](Images/Chunks.png)  

### Voxels
Each chunk is then subdivided into voxels. A **VoxelResolution** defines how many voxels per dimension we sample.  

![Voxels](Images/Voxels.png)  

### SDF Sampling
Every voxel gets a value by sampling the SDF at its position. For a 12×12×12 chunk grid with ~41³ voxels each, that’s ~120 million evaluations! Doing this on the CPU would be a disaster, so I moved the entire process to **compute shaders**.  

### Marching Cubes
With voxels populated, Marching Cubes generates the mesh. Initially I had this on CPU (bad idea), then swapped to Keijiro’s GPU version. The problem was that Keijiro’s approach still read back to CPU, stalling performance. I rewired it to use **Indirect Rendering** so the GPU generates and renders everything directly.  

This massively improved performance — the RenderThread stays ~1.5ms even with terrain generation active. The tradeoff is no CPU mesh copy, so physics/collision will need a custom solution later.

    //SDFS
    public TerrainSDFFactory terrainSDFFactory;
    public TerrainSDFRegistry terrainSDFRegistry;
    // Debugging
    [Header("Debugging")]
    public bool displayChunks = true;
    public bool displayVoxels = true;

    public struct VoxelDebugData
    {
        public float[] voxels;
        public int3 resolution;
        public float3 gridMinCorner;
        public float3 voxelSize;
        public VoxelDebugData(float[] voxels, int3 res, float3 gridMinCorner, float3 voxelSize)
        {
            this.voxels = voxels;
            this.resolution = res;
            this.gridMinCorner = gridMinCorner;
            this.voxelSize = voxelSize;
        }
    }
    private List<VoxelDebugData> voxelDebugData;
    #region  Input Validation

    private void OnValidate()
    {
        
        //Validate Input
        if (ChunkDimensions.x != ChunkDimensions.y || ChunkDimensions.y != ChunkDimensions.z) { Debug.LogError("Keep Chunk Dimensions Cube-like."); }

        int lastLod = -1;
        foreach (TerrainLod terrainLod in terrainLods)
        {
            bool decreasingLOD = terrainLod.LOD < lastLod;
            bool outOfRange =  math.any(terrainLod.chunkRadius > ChunkResolution);
            bool evenVoxelResolution = terrainLod.VoxelResolution.x % 2 == 0 || terrainLod.VoxelResolution.y % 2 == 0 || terrainLod.VoxelResolution.z % 2 == 0;
            lastLod = terrainLod.LOD;

            if (decreasingLOD) Debug.LogError("Invalid LOD Ordering. Ensure LOD is in increasing order.");
            if (evenVoxelResolution) Debug.LogError("Invalid Voxel Resolution(s). Must be odd.");
            if (outOfRange) Debug.LogError("Invalid Voxel Range. Must be less than voxelResolution.");
        }

        if (!Player)                    Debug.LogError("Player cannot be null.");
        if (!MarchingCubesCompute)      Debug.LogError("Missing Marching Cubes Shader");
        if (!VoxelEvalShader)           Debug.LogError("Missing Voxel Evaluation Shader");
        if (!TerrainMaterial)           Debug.LogError("Missing Terrain Material");
    }
    #endregion
    #region MonoBehavior Lifecycle
    private void Awake()
    {
        Instance = this;

    
        //Init SDF collection
        terrainSDFRegistry = new TerrainSDFRegistry();
        terrainSDFFactory = new TerrainSDFFactory(terrainSDFRegistry);
        //terrainSDFFactory.Init_SphereSDF(40f, new Vector3(25, 80, 7), 0);
        //terrainSDFFactory.Init_TorusSDF(40f, 15f, new Vector3(0, -20f, 0), 0);
        terrainSDFFactory.Init_PlaneSDF(Vector3.up, -25, 0);

        terrainChunker = new TerrainChunker(this, playerPosition, ChunkResolution, ChunkDimensions, terrainLods);
        terrainChunkCollection = terrainChunker.TerrainChunkCollection;
        voxelDebugData = new();
      
    }
    private void OnDestroy()
    {
        terrainChunker.Dispose();
        GpuIndirectDrawRegistry.ClearFrame();
    }
    private void Update()
    {
        terrainChunker.UpdateChunks(playerPosition);
    }
    #endregion
    
    #region Debugging
    public void AddVoxelDebugData(VoxelDebugData data)
    {
        voxelDebugData.Add(data);
    }
    public void ClearVoxelDebugData()
    { 
        voxelDebugData.Clear();  
    }
    
    private void OnDrawGizmos()
    {

        if (terrainChunkCollection == null || !(terrainChunkCollection.TerrainChunks != null))
            return;


        var chunks = terrainChunkCollection.TerrainChunks;
        if (displayVoxels)
            foreach (VoxelDebugData voxelDebugDatum in voxelDebugData)
            {
                SDFVoxelGizmoVisualizer.DrawVoxelSDFGizmos(
                    voxelDebugDatum.voxels,
                    voxelDebugDatum.resolution,
                    voxelDebugDatum.gridMinCorner,
                    voxelDebugDatum.voxelSize
                );
            }

        if (displayChunks)
            for (int i = 0; i < chunks.Length; i++)
            {
                var chunk = chunks[i];

                Gizmos.color = (chunk.ChunkLOD.LOD == 1) ? Color.red : (chunk.ChunkLOD.LOD == 2) ? Color.blue : Color.green;
                float3 center = chunk.MinCornerWS + chunk.ChunkSize * 0.5f;
                Gizmos.DrawWireCube(center, chunk.ChunkSize);
            }
    }
    
    #endregion
}

public struct TerrainChunk_Val
{
    // Integer 3D index of the chunk in the chunk grid (e.g., [x, y, z])
    public readonly int3 ChunkIndex;

    // World-space position of the chunk's minimum corner (bottom-left-front)
    public readonly float3 MinCornerWS;

    // Size of the chunk in world units (assumed cubic or rectangular)
    public readonly float3 ChunkSize;
    public TerrainLod ChunkLOD;
    
    // Constructor for convenience
    public TerrainChunk_Val(int3 chunkIndex, float3 minCornerWS, float3 chunkSize)
    {
        ChunkIndex = chunkIndex;
        MinCornerWS = minCornerWS;
        ChunkSize = chunkSize;
        ChunkLOD = new TerrainLod() { LOD = -1};
      
    }
   

}
public class TerrainChunk_Ref
{
    // Integer 3D index of the chunk in the chunk grid (e.g., [x, y, z])
    public readonly int3 ChunkIndex;

    // World-space position of the chunk's minimum corner (bottom-left-front)
    public readonly float3 MinCornerWS;

    // Size of the chunk in world units (assumed cubic or rectangular)
    public readonly float3 ChunkSize;

    // Computed max corner of the chunk's AABB in world space
    public float3 MaxCornerWS => MinCornerWS + ChunkSize;
    public TerrainLod ChunkLOD;

using Unity.Mathematics;
using UnityEngine;
using System.Collections.Generic;
using System.Linq;
using Unity.Profiling;
using System.Runtime.CompilerServices;
using System;

/// <summary>
/// Responsible for creating and updating our terrain chunks
/// </summary>
public class TerrainChunker
{
    public static ProfilerMarker ChangedLods = new ProfilerMarker("Changed Lods");
    public static ProfilerMarker NewSDF = new ProfilerMarker("New SDF");

    /// <summary>
    /// Returns the number of cells filled by a manhattanfill of specified radius.
    /// </summary>
    /// <param name="radius"></param>
    /// <returns></returns>
    public static long ManhattanFloodFillCount3D(int radius)
    {
        long r = radius;
        // Centered octahedral number: N(R) = (4R^3 + 6R^2 + 8R)/3 + 1
        return ((4 * r * r * r + 6 * r * r + 8 * r) / 3) + 1;
    }
    // === Settings ===
    public TerrainChunkCollection TerrainChunkCollection;
    List<TerrainLod> AllLods;
    // === State Trackers ===
    bool initialized = false;
    int playerChunkIndex; //index of the chunk the player is in
    HashSet<int> chunksToUpdate; //indices of chunks with a mesh 
    Dictionary<int, uint> numberOfSDFSPerChunk; //# of sdfs in each chunk at present time 

    // === References ===
    TerrainMeshBuilderIndirect terrainMeshBuilder;
    TerrainPipeline terrainPipeline;
    VoxelsFactory voxelsFactory;
    #region Public API
    /// <summary>
    /// Constructor initializes chunks with ChunkDimensions as chunksize and ChunkResolution as number of chunks in each dimension.
    /// </summary>
    /// <param name="terrainPipeline"></param>
    /// <param name="playerPosition"></param>
    /// <param name="ChunkDimensions"></param>
    /// <param name="ChunkResolution"></param>
    /// <param name="lods"></param>
    public TerrainChunker (TerrainPipeline terrainPipeline, Vector3 playerPosition, int3 ChunkDimensions, int3 ChunkResolution, List<TerrainLod> lods)
    {
        this.terrainPipeline = terrainPipeline;
        terrainMeshBuilder = new TerrainMeshBuilderIndirect(lods[0].VoxelResolution.x * lods[0].VoxelResolution.y * lods[0].VoxelResolution.z, terrainPipeline.MarchingCubesCompute, terrainPipeline.IndirectArgumentAdjuster, terrainPipeline.TerrainMaterial, lods);
        AllLods = lods;
        chunksToUpdate = new();
        numberOfSDFSPerChunk = new Dictionary<int, uint>(); //default val 0 
        int n = ChunkResolution.x * ChunkResolution.y * ChunkResolution.z;
        numberOfSDFSPerChunk = new Dictionary<int, uint>(n);
        for (int i = 0; i < n; i++)
        {
            numberOfSDFSPerChunk.Add(i, 0u);
        }
        
        voxelsFactory = new VoxelsFactory(terrainPipeline, this, terrainPipeline.VoxelEvalShader, ChunkResolution, lods);
        CalculateChunks(ChunkDimensions, ChunkResolution);
    }
    public void Dispose()
    {
        voxelsFactory.Dispose();
        terrainMeshBuilder.Dispose();
    }
    int oldNumberOfSDFS = 0;
    /// <summary>
    /// Recalculates LOD for each chunk, recalculates voxels for chunks whose LOD has changed, and redraws meshes for voxels whose value changed WHEN any of the following condtions are met:
    /// 1) Player has changed chunk
    /// 2) #TODO Change made to SDF collection.
    /// </summary>
    /// <param name="playerPosition"></param>
    public void UpdateChunks(Vector3 playerPosition)
    {

        int oldPlayerChunkIndex = playerChunkIndex;
        playerChunkIndex = GetPlayerChunkIndex(playerPosition);
        bool playerChangedChunk = playerChunkIndex != oldPlayerChunkIndex;
        bool newSDFMade = terrainPipeline.terrainSDFRegistry.GetNewSDFS() != null;
        bool SDFRemoved = terrainPipeline.terrainSDFRegistry.GetRemovedSDFS() != null;

        if (playerChangedChunk || !initialized || newSDFMade || SDFRemoved)
        {

            terrainPipeline.ClearVoxelDebugData();
       
            if (newSDFMade || SDFRemoved)
            {
                voxelsFactory.SetSDFBuffer(terrainPipeline.terrainSDFRegistry);
            }

            if (playerChangedChunk || !initialized)
            {
                UpdateFrom_ChangedLOD();
            }

            if (newSDFMade || SDFRemoved)
            {
                UpdateFrom_ChangedSDF();
            }

            initialized = true;
        }

        oldNumberOfSDFS = terrainPipeline.terrainSDFRegistry.TerrainSDFS.Count;

    }

    void UpdateFrom_ChangedLOD()
    {

        using (ChangedLods.Auto())
        {
            RecalculateLOD();
            MainVoxelPass();
            foreach (int chunkIndex in chunksToUpdate)
            {
                CalculateMesh(chunkIndex);
            }
            foreach (TerrainLod lod in AllLods)
            {
                terrainMeshBuilder.BuildLOD(lod);
            }
        }
    }
    void UpdateFrom_ChangedSDF()
    {
        using (NewSDF.Auto())
        {
            List<int> newChunkIndiciesInBounds = GetIndicesInBounds();
            //UpdateNumSDFSPerChunk();
            HashSet<TerrainLod> lodsInBounds = MainVoxelPass(newChunkIndiciesInBounds);
            foreach (int chunkIndex in chunksToUpdate)
            {
                CalculateMesh(chunkIndex);
            }
            foreach (TerrainLod lod in AllLods)
            {
                terrainMeshBuilder.BuildLOD(lod);
            }
        }

        List<int> GetIndicesInBounds()
        {
            List<int> allIndiciesInBounds = new List<int>();
            List<TerrainSDF_GPU> sdfsMadeThisTick = terrainPipeline.terrainSDFRegistry.GetNewSDFS();
            List<TerrainSDF_GPU> sdfsRemovedThisTick = terrainPipeline.terrainSDFRegistry.GetRemovedSDFS();
           
            if (sdfsMadeThisTick != null)
                foreach (TerrainSDF_GPU sdf in sdfsMadeThisTick)
                {
                    AABB sdfBounds = TerrainSDFRegistry.ComputeBounds(sdf);
                    List<int> chunkIndiciesInBounds = TerrainChunkUtils.GetChunksOverlappingAABB(sdfBounds, TerrainChunkCollection.TerrainChunks[0].MinCornerWS, TerrainChunkCollection.TerrainChunks[0].ChunkSize, terrainPipeline.ChunkResolution);
                    allIndiciesInBounds.AddRange(chunkIndiciesInBounds);
                }
            if (sdfsRemovedThisTick != null)
                foreach (TerrainSDF_GPU sdf in sdfsRemovedThisTick)
                {
                    AABB sdfBounds = TerrainSDFRegistry.ComputeBounds(sdf);
                    List<int> chunkIndiciesInBounds = TerrainChunkUtils.GetChunksOverlappingAABB(sdfBounds, TerrainChunkCollection.TerrainChunks[0].MinCornerWS, TerrainChunkCollection.TerrainChunks[0].ChunkSize, terrainPipeline.ChunkResolution);
                    allIndiciesInBounds.AddRange(chunkIndiciesInBounds);
                }
            return allIndiciesInBounds;

        }
        void UpdateNumSDFSPerChunk()
        {
            List<int> allIndiciesInBounds = new List<int>();
            List<TerrainSDF_GPU> sdfsMadeThisTick = terrainPipeline.terrainSDFRegistry.GetNewSDFS();
            List<TerrainSDF_GPU> sdfsRemovedThisTick = terrainPipeline.terrainSDFRegistry.GetRemovedSDFS();
           
            if (sdfsMadeThisTick != null)
                foreach (TerrainSDF_GPU sdf in sdfsMadeThisTick)
                {
                    AABB sdfBounds = TerrainSDFRegistry.ComputeBounds(sdf);
                    List<int> chunkIndiciesInBounds = TerrainChunkUtils.GetChunksOverlappingAABB(sdfBounds, TerrainChunkCollection.TerrainChunks[0].MinCornerWS, TerrainChunkCollection.TerrainChunks[0].ChunkSize, terrainPipeline.ChunkResolution);
                    foreach (int chunkIndexInBounds in chunkIndiciesInBounds)
                    {
                        numberOfSDFSPerChunk[chunkIndexInBounds]++;
                    }
                }
            if (sdfsRemovedThisTick != null)
                foreach (TerrainSDF_GPU sdf in sdfsRemovedThisTick)
                {
                    AABB sdfBounds = TerrainSDFRegistry.ComputeBounds(sdf);
                    List<int> chunkIndiciesInBounds = TerrainChunkUtils.GetChunksOverlappingAABB(sdfBounds, TerrainChunkCollection.TerrainChunks[0].MinCornerWS, TerrainChunkCollection.TerrainChunks[0].ChunkSize, terrainPipeline.ChunkResolution);
                    foreach (int chunkIndexInBounds in chunkIndiciesInBounds)
                    {
                        numberOfSDFSPerChunk[chunkIndexInBounds]--;
                    }
                }

        }
    }
    /// <summary>
    /// Rebuilds mesh for a specified chunk and tracks it.
    /// </summary>
    /// <param name="index"></param>
    /// <param name="resolution"></param>
    /// <param name="voxelBuffer"></param>
    public void CalculateMesh(int chunkIndex)
    {
        TerrainChunk_Val chunk = TerrainChunkCollection.TerrainChunks[chunkIndex];
        int3 resolution = chunk.ChunkLOD.VoxelResolution;
        ComputeBuffer voxelBuffer = voxelsFactory.GetVoxelBuffer(chunkIndex);
        float voxelSize = (chunk.ChunkSize / ((float3)(resolution - new int3(1, 1, 1)))).x;
        //terrainMeshBuilder.UnloadMesh(chunkIndex);
        if (chunk.ChunkLOD.LOD == -1) return;
        terrainMeshBuilder.CalculateMesh(chunkIndex, voxelBuffer, voxelSize, resolution, chunk.MinCornerWS + chunk.ChunkSize * .5f, chunk.ChunkLOD);
    }
    /// <summary>
    /// Get the chunk index corresponding to the chunk containing the player
    /// </summary>
    /// <param name="playerPosition"></param>
    /// <returns></returns>
    public int GetPlayerChunkIndex(float3 playerPosition)
    {
        // Grid dimensions
        int chunksX = TerrainChunkCollection.Resolution.x;
        int chunksY = TerrainChunkCollection.Resolution.y;
        int chunksZ = TerrainChunkCollection.Resolution.z;
        float3 chunkSize = TerrainChunkCollection.ChunkDimension;

        // Compute world-space size of entire grid
        float3 totalGridSize = new float3(
            chunksX * chunkSize.x,
            chunksY * chunkSize.y,
            chunksZ * chunkSize.z
        );

        float3 gridCenter = TerrainChunkCollection.Origin;
        float3 gridMinCorner = TerrainChunkCollection.TerrainChunks[0].MinCornerWS;

        // Offset player position relative to this origin
        float3 localPos = playerPosition - gridMinCorner;

        // Find chunk coordinates
        int cx = (int)math.floor(localPos.x / chunkSize.x);
        int cy = (int)math.floor(localPos.y / chunkSize.y);
        int cz = (int)math.floor(localPos.z / chunkSize.z);

        // Clamp to grid bounds (optional)
        cx = math.clamp(cx, 0, chunksX - 1);
        cy = math.clamp(cy, 0, chunksY - 1);
        cz = math.clamp(cz, 0, chunksZ - 1);

        // Convert to 1D index
        int index = cx + cy * chunksX + cz * chunksX * chunksY;

        return index;
    }
    #endregion
    #region Private Methods
    void RecalculateLOD()
    {
        terrainPipeline.ClearVoxelDebugData();

        //Reset all AllLods
        for (int chunkIndex = 0; chunkIndex < TerrainChunkCollection.TerrainChunks.Length; chunkIndex++)
        {
            TerrainChunkCollection.TerrainChunks[chunkIndex].ChunkLOD.LOD = -1; //Set to not loaded by default
        }
            
        //Calc new AllLods
        CalculateLodsByManhattan(AllLods);

        voxelsFactory.UpdateVoxelBuffersForChunks();
    }

    void MainVoxelPass()
    {
        var chunks   = TerrainChunkCollection.TerrainChunks;   // contiguous
        var registry = terrainPipeline.terrainSDFRegistry;     // cache once

        for (int i = 0; i < chunks.Length; i++)
        {
            ref TerrainChunk_Val chunk = ref chunks[i];  // no copy
            if (chunk.ChunkLOD.LOD == -1) continue;
            //chunk culling
            //chunk culling
            bool culled = CullChunk(in chunk, registry);
            if (culled) chunksToUpdate.Add(i);
            if (!culled) chunksToUpdate.Remove(i);
            if (!culled) continue;


            // Prefer an overload that takes `in TerrainChunk_Val`
            voxelsFactory.EvaluateVoxelGroup(i, chunk, chunk.ChunkLOD);
        }
    }
    /// <summary>
    /// Takes as input a list of chunk indices corresponding to chunks that need updated voxels, outputs a set of AllLods which need to be rebuilt.
    /// </summary>
    /// <param name="chunkIndices"></param>
    /// <returns></returns>
    HashSet<TerrainLod> MainVoxelPass(List<int> chunkIndices)
    {
        var chunks = TerrainChunkCollection.TerrainChunks;   // contiguous
        var registry = terrainPipeline.terrainSDFRegistry;     // cache once

        HashSet<TerrainLod> lodsInBounds = new HashSet<TerrainLod>();  //output
        foreach (int chunkIndex in chunkIndices)
        {
            ref TerrainChunk_Val chunk = ref chunks[chunkIndex];  // no copy
            if (chunk.ChunkLOD.LOD == -1) continue;

            //chunk culling
            bool culled = CullChunk(in chunk, registry);
            if (culled) chunksToUpdate.Add(chunkIndex);
            if (!culled) chunksToUpdate.Remove(chunkIndex);
            if (!culled) continue;
 
            lodsInBounds.Add(chunk.ChunkLOD);
            // Prefer an overload that takes `in TerrainChunk_Val`
            voxelsFactory.EvaluateVoxelGroup(chunkIndex, chunk, chunk.ChunkLOD);
        }
        return lodsInBounds;
    }

    [MethodImpl(MethodImplOptions.AggressiveInlining)]
    static bool CullChunk(in TerrainChunk_Val chunk, TerrainSDFRegistry registry)
    {
        // Precompute once, keep on stack
        Vector3 half = chunk.ChunkSize * 0.5f;
        Vector3 center = (Vector3)chunk.MinCornerWS + half;
        float sdf = registry.EvaluateDistanceAt(center);

        // Avoid sqrt
        float halfDiagSq = half.sqrMagnitude;
        float sdfSq = sdf * sdf;
        bool culled = sdfSq < halfDiagSq;
        return culled;
    }
    void CalculateChunks(int3 resolution, int3 chunkDimension)
    {
        if (chunkDimension.x % 2 != 0 || chunkDimension.y % 2 != 0 || chunkDimension.z % 2 != 0)
        {
            Debug.LogError("Failed to calculate chunks. chunkDimension was odd.");
            return;
        }
        if (resolution.x % 2 != 0 || resolution.y % 2 != 0 || resolution.z % 2 != 0)
        {
            Debug.LogError("Failed to calculate chunks. resolution was odd.");
            return;
        }

        int totalSize = resolution.x * resolution.y * resolution.z;
        TerrainChunk_Val[] terrainChunks = new TerrainChunk_Val[totalSize];

        int resolutionXDiv2 = resolution.x / 2;
        int resolutionYDiv2 = resolution.y / 2;
        int resolutionZDiv2 = resolution.z / 2;
        int3 firstChunkPosition = new int3(-resolutionXDiv2 * chunkDimension.x + chunkDimension.x / 2,
                                           -resolutionYDiv2 * chunkDimension.y + chunkDimension.y / 2,
                                           -resolutionZDiv2 * chunkDimension.z + chunkDimension.z / 2);

        for (int x = 0; x < resolution.x; x++)
        {
            for (int y = 0; y < resolution.y; y++)
            {
                for (int z = 0; z < resolution.z; z++)
                {
                    int3 chunkPosition = firstChunkPosition + new int3(x * chunkDimension.x, y * chunkDimension.y, z * chunkDimension.z);
                    int3 chunkIndex = new int3(x, y, z);
                    TerrainChunk_Val terrainChunk = new TerrainChunk_Val(chunkIndex, chunkPosition, chunkDimension);
                    terrainChunks[x + y * resolution.x + z * resolution.x * resolution.y] = terrainChunk;
                }
            }
        }

        TerrainChunkCollection = new TerrainChunkCollection(resolution, chunkDimension, terrainChunks, float3.zero);

    }
    
    List<List<int>> CalculateLodsByManhattan(IReadOnlyList<TerrainLod> lods)
    {
        if (lods == null || lods.Count == 0)
            return null;

        // Prepare result buckets in the same order as input
        var results = Enumerable.Range(0, lods.Count)
                                .Select(_ => new List<int>())
                                .ToList();

        // Sort by radius for tier checks, but remember original indices
        var ordered = lods.Select((lod, idx) => (lod, idx))
                        .OrderBy(p => p.lod.chunkRadius)
                        .ToArray();

        int3 res = terrainPipeline.ChunkResolution;

        // Player chunk coords
        int cx = playerChunkIndex % res.x;
        int cy = (playerChunkIndex / res.x) % res.y;
        int cz = playerChunkIndex / (res.x * res.y);

        int maxRadius = ordered[^1].lod.chunkRadius;

        for (int dz = -maxRadius; dz <= maxRadius; dz++)
        {
            for (int dy = -maxRadius; dy <= maxRadius; dy++)
            {
                for (int dx = -maxRadius; dx <= maxRadius; dx++)
                {
                    int distance = math.abs(dx) + math.abs(dy) + math.abs(dz);
                    if (distance > maxRadius) continue;

                    int nx = cx + dx;
                    int ny = cy + dy;
                    int nz = cz + dz;

                    // Skip out-of-bounds
                    if (nx < 0 || ny < 0 || nz < 0 ||
                        nx >= res.x || ny >= res.y || nz >= res.z)
                        continue;

                    int index = nx + ny * res.x + nz * res.x * res.y;

                    // Find first LOD band whose radius includes this distance
                    for (int s = 0; s < ordered.Length; s++)
                    {
                        if (distance <= ordered[s].lod.chunkRadius)
                        {
                            results[ordered[s].idx].Add(index);
                            break;
                        }
                    }
                }
            }
        }

        //Set new Lods on Chunks
            int LodIndex = 0;
            foreach (List<int> indicesOfALod in results)
            {
                foreach (int chunkIndex in indicesOfALod)
                {
                TerrainChunkCollection.TerrainChunks[chunkIndex].ChunkLOD = AllLods[LodIndex];
                }
                //Update voxels on new Lods
                LodIndex++;
            }

        return results; // results[i] corresponds to lods[i]
    }
   
   

   
    #endregion

/// <summary>
/// Returns indices of all chunks that intersect the given AABB.
/// Indexing is x + Nx * (y + Ny * z).
/// </summary>
/// <param name="aabb">World-space bounds to test.</param>
/// <param name="gridMinWS">World-space min of the whole chunk grid (min corner of chunk (0,0,0)).</param>
/// <param name="chunkSizeWS">World-space size of one chunk along XYZ.</param>
/// <param name="chunksPerAxis">Number of chunks along each axis (Nx, Ny, Nz).</param>
/// <param name="result">List to fill (cleared). If null, a new list is created.</param>
public static List<int> GetChunksOverlappingAABB(
    AABB aabb,
    float3 gridMinWS,
    float3 chunkSizeWS,
    int3  chunksPerAxis,
    List<int> result = null)
{
    result ??= new List<int>(32);
    result.Clear();

    // Early-out for degenerate AABB
    if (math.any(aabb.Min > aabb.Max)) return result;

    // Clamp query to grid extents
    float3 gridMaxWS = gridMinWS + chunkSizeWS * (float3)chunksPerAxis;
    float3 qMin = math.max(aabb.Min, gridMinWS);
    float3 qMax = math.min(aabb.Max, gridMaxWS);

    // No overlap with grid at all
    if (math.any(qMin >= qMax)) return result;

    // Compute inclusive chunk coords for min/max.
    // Treat qMax as *exclusive* by nudging inward to avoid counting the next cell
    // when the max lies exactly on a chunk boundary.
    const float eps = 1e-5f;
    int3 minC = (int3)math.floor((qMin - gridMinWS) / chunkSizeWS);
    int3 maxC = (int3)math.floor(((qMax - new float3(eps)) - gridMinWS) / chunkSizeWS);

    // Clamp to valid index range
    int3 last = chunksPerAxis - 1;
    minC = math.clamp(minC, 0, last);
    maxC = math.clamp(maxC, 0, last);

    // If after clamping the box is outside, bail
    if (math.any(minC > maxC)) return result;

    // Enumerate all covered chunks
    for (int z = minC.z; z <= maxC.z; z++)
    for (int y = minC.y; y <= maxC.y; y++)
    for (int x = minC.x; x <= maxC.x; x++)
    {
        int idx = x + chunksPerAxis.x * (y + chunksPerAxis.y * z);
        result.Add(idx);
    }

    return result;
}

// Voxel value with calculated gradient
float4 VoxelValueWithGradient(uint3 i)
{
    uint3 i_n = max(i, 1) - 1;
    uint3 i_p = min(i + 1, Dims - 1);
    float v = VoxelValue(i.x, i.y, i.z);
    float v_nx = VoxelValue(i_n.x, i.y, i.z);
    float v_px = VoxelValue(i_p.x, i.y, i.z);
    float v_ny = VoxelValue(i.x, i_n.y, i.z);
    float v_py = VoxelValue(i.x, i_p.y, i.z);
    float v_nz = VoxelValue(i.x, i.y, i_n.z);
    float v_pz = VoxelValue(i.x, i.y, i_p.z);
    return float4(v_px - v_nx, v_py - v_ny, v_pz - v_nz, v);
}

// This must match one defined in Paul Bourke's article:
// http://paulbourke.net/geometry/polygonise/

uint3 CubeVertex(uint index)
{
    bool x = index & 1;
    bool y = index & 2;
    bool z = index & 4;
    return uint3(x ^ y, y, z);
}

uint2 EdgeVertexPair(uint index)
{
    // (0, 1) (1, 2) (2, 3) (3, 0)
    // (4, 5) (5, 6) (6, 7) (7, 4)
    // (0, 4) (1, 5) (2, 6) (3, 7)
    uint v1 = index & 7;
    uint v2 = index < 8 ? ((index + 1) & 3) | (index & 4) : v1 + 4;
    return uint2(v1, v2);
}
// Helper to emit one triangle
void EmitTri(float3 a, float3 b, float3 c, float3 aNrm, float3 bNrm, float3 cNrm, int useFlatNormals)
{
    // Flat-shaded normal
    float3 nFlat = normalize(cross(b - a, c - a));
    Triangle t;

    VertexGPU v0;
    VertexGPU v1;
    VertexGPU v2;

    if (useFlatNormals == 1)
    {
        v0.nrm = nFlat; v1.nrm = nFlat;  v2.nrm = nFlat;
    }
    else
    {
        v0.nrm = aNrm; v1.nrm = bNrm; v2.nrm = cNrm;
    }
        
    v0.pos = a; v0.uv = float2(0,0); 
    v1.pos = b; v1.uv = float2(1,0); 
    v2.pos = c; v2.uv = float2(0,1); 

    t.a = v0;
    t.b = v1;
    t.c = v2;
    
    g_Tris.Append(t);

}

[numthreads(4, 4, 4)]
void MeshReconstruction(uint3 id : SV_DispatchThreadID)
{
   
    // Boundary check
    if (any(id + 1 >= Dims.xyz)) return;

    // Voxel samples at each cube vertex
    float4 samples[8];
    for (uint i = 0; i < 8; i++)
        samples[i] = VoxelValueWithGradient(id + CubeVertex(i));

    // Cube configuration selector
    // (initialized as a bit field of vertex binary states)
    uint selector = 0;
    for (i = 0; i < 8; i++)
        selector |= (samples[i].w < Isovalue) << i;

    // Special case for empty cubes; Exit ealy if there is no intersection.
    if (selector == 0 || selector == 0xff) return;

    // Intersection points on each edge
    // We do this in a GPU-oriented way; Do the calculation on all the edges
    // including ones without an intersection.
    float3 vertices[12];
    float3 normals[12];
    for (i = 0; i < 12; i++)
    {
        uint2 pair = EdgeVertexPair(i);
        float4 sample1 = samples[pair.x];
        float4 sample2 = samples[pair.y];
        float3 vertex1 = id + CubeVertex(pair.x);
        float3 vertex2 = id + CubeVertex(pair.y);
        float param = (Isovalue - sample1.w) / (sample2.w - sample1.w);
        vertices[i] = TransformPoint(lerp(vertex1, vertex2, param));
        normals[i] = -normalize(lerp(sample1.xyz, sample2.xyz, param));
    }

    // Output triangles in the selected cube configuration.
    uint2 tri_data = TriangleTable[selector];
    for (i = 0; i < 15; i += 3)
    {
        uint e1 = EdgeIndexFromTriangleTable(tri_data, i);
        uint e2 = EdgeIndexFromTriangleTable(tri_data, i + 1);
        uint e3 = EdgeIndexFromTriangleTable(tri_data, i + 2);
        if (e1 == 15) return;

        /*
        //write triangle
        Triangle t;
        t.a = vertices[e1];
        t.b = vertices[e3];
        t.c = vertices[e2];
        VertexBuffer.Append(t);
        */
        //Write Gpu Vertices
        
        VertexGPU v0;  
        v0.pos = vertices[e1]; v0.nrm = normals[e1]; v0.uv = vertices[e1].xz * Scale;

        VertexGPU v1;  
        v1.pos = vertices[e2]; v1.nrm = normals[e2]; v1.uv = vertices[e2].xz * Scale;

        v2.pos = vertices[e3]; v2.nrm = normals[e3]; v2.uv = vertices[e3].xz * Scale;

using UnityEngine;
using Unity.Mathematics;

public static class TerrainPhysics
{

    public static class TerrainCollision
    {
        public struct Settings
        {
            public float mass;            // kg
            public float beta;            // 0..1, fraction of error fixed per step (e.g. 0.2)
            public float contactOffset;   // meters, contact shell (e.g. 0.006)
            public float slop;            // meters, ignore tiny errors (e.g. 0.002)
            public float frictionMu;      // Coulomb friction coefficient
            public float maxPushSpeed;    // m/s clamp on normal correction (e.g. 10)
                                          // (stiffness/damping not used by ERP)
        }

        /// <summary>
        /// ERP/Baumgarte collision resolve: removes a fraction of penetration per step and
        /// kills inward normal velocity. Uses SDF for depth and normal for direction.
        /// </summary>
        public static Vector3 Resolve(Vector3 pos, Vector3 vel, float sdfDistance, Vector3 sdfNormal, float dt, Settings s)
        {
            if (dt <= 0f) return vel;
            if (sdfNormal.sqrMagnitude < 1e-10f) return vel;

            Vector3 n = Vector3.Normalize(sdfNormal);

            // Treat contact as "inside" a shell at contactOffset.
            // Positive penetration means we want correction.
            float penetration = Mathf.Max(0f, (s.contactOffset - sdfDistance) - s.slop);
            if (penetration <= 0f) return vel;

            // Incoming normal velocity (positive = separating, negative = moving into surface)
            float vN = Vector3.Dot(vel, n);

            // Baumgarte/ERP velocity bias along the normal:
            //   - remove inward velocity (so we don't keep hitting the wall)
            //   - add a bias that removes beta * penetration distance per step
            float dvN = 0f;
            if (vN < 0f) dvN += -vN; // kill inward component
            dvN += s.beta * (penetration / Mathf.Max(1e-6f, dt));

            // Clamp the push-out to avoid explosive corrections
            dvN = Mathf.Min(dvN, s.maxPushSpeed);

            // Apply normal correction
            vel += n * dvN;

            // Non-penetration guard: do not end with inward normal velocity
            float vN2 = Vector3.Dot(vel, n);
            if (vN2 < 0f) vel -= n * vN2;

            // --- Tangential friction (Coulomb-like impulse cap) ---
            // Normal impulse magnitude Jn ≈ m * dvN
            float Jn = s.mass * Mathf.Max(0f, dvN);
            if (s.frictionMu > 0f && Jn > 0f)
            {
                Vector3 vT = vel - n * Vector3.Dot(vel, n);
                float vTmag = vT.magnitude;
                if (vTmag > 1e-6f)
                {
                    float JtMax = s.frictionMu * Jn;
                    float JtNeeded = s.mass * vTmag;
                    float Jt = Mathf.Min(JtNeeded, JtMax);
                    Vector3 dvT = (-Jt / s.mass) * (vT / vTmag);
                    vel += dvT;
                }
            }

            return vel;
        }
    }

        int oldDistanceInt = (int)oldDistance;
        int newDistanceInt = (int)newDistance;



        if (oldDistance > 0 && newDistance < 0 || oldDistance < 0 && newDistance > 0)
        {

    private static float3 EstimateGradient(TerrainSDFRegistry reg, float3 p, float eps = 1e-3f)
    {
        // central differences
        float dx = reg.EvaluateDistanceAt(p + new float3(eps, 0, 0)) - reg.EvaluateDistanceAt(p - new float3(eps, 0, 0));
        float dy = reg.EvaluateDistanceAt(p + new float3(0, eps, 0)) - reg.EvaluateDistanceAt(p - new float3(0, eps, 0));
        float dz = reg.EvaluateDistanceAt(p + new float3(0, 0, eps)) - reg.EvaluateDistanceAt(p - new float3(0, 0, eps));

        return math.normalize(new float3(dx, dy, dz));
    }

    /// <summary>
    /// Returns vector from point p to closest surface point (approx).
    /// </summary>
    public static float3 EvaluateVectorDistanceAt(TerrainSDFRegistry reg, float3 p)
    {
        float d = reg.EvaluateDistanceAt(p);         // signed distance
        float3 grad = EstimateGradient(reg, p); // surface normal (outward)
        return grad * d;                         // vector offset
    }

    public static bool Raycast(TerrainSDFRegistry reg, Vector3 direction, float distance, Vector3 origin)
    {
        direction.Normalize();
        float3 position = origin + (direction * distance);
        float d1 = reg.EvaluateDistanceAt(position);
        float d2 = reg.EvaluateDistanceAt(origin);
        if (d1 > 0 && d2 < 0 || d1 < 0 && d2 > 0)
        {
            return true;
        }
        return false;

    }

using System.Collections.Generic;
using Unity.Mathematics;
using static Unity.Mathematics.math;

public struct AABB
{
    public float3 Min;
    public float3 Max;

    public AABB(float3 min, float3 max)
    {
        Min = min;
        Max = max;
    }

    public static AABB Empty => new AABB(new float3(float.PositiveInfinity),
                                         new float3(float.NegativeInfinity));
    public static AABB Full => new AABB(new float3(float.NegativeInfinity),
                                         new float3(float.PositiveInfinity));

    public bool IsEmpty => Min.x > Max.x || Min.y > Max.y || Min.z > Max.z;

    public void Encapsulate(AABB other)
    {
        Min = math.min(Min, other.Min);
        Max = math.max(Max, other.Max);
    }

    public AABB Intersect(AABB other)
    {
        float3 min = math.max(Min, other.Min);
        float3 max = math.min(Max, other.Max);
        if (math.any(min > max)) // no overlap
            return Empty;
        return new AABB(min, max);
    }
}


public class TerrainSDFRegistry
{
    private List<TerrainSDF_GPU> terrainSDFs = new List<TerrainSDF_GPU>();
    public IReadOnlyList<TerrainSDF_GPU> TerrainSDFS => terrainSDFs;

    public void RegisterSDF(TerrainSDF_GPU terrainSDF_GPU) =>
        terrainSDFs.Add(terrainSDF_GPU);

    // ------------------ NEW: CPU distance evaluation ------------------

    /// <summary>
    /// Returns signed distance at world-space position <paramref name="p"/>,
    /// combining all registered SDFs with the same rules as the HLSL path.
    /// </summary>
    public float EvaluateDistanceAt(float3 p)
    {
        float acc = 1e9f; // large positive start (outside everything)

        foreach (var s in terrainSDFs)
        {
            float d = EvaluateOneCPU(s, p); // primitive distance

            switch ((TerrainSDFType)s.SDFType)
            {
                case TerrainSDFType.SphereSubtract:
                    // subtraction: acc = max(-d, acc)
                    acc = max(-d, acc);
                    break;

                case TerrainSDFType.Sphere:
                case TerrainSDFType.Box:
                case TerrainSDFType.Torus:
                case TerrainSDFType.Cylinder:
                case TerrainSDFType.Plane:
                    // union: acc = min(d, acc)
                    acc = min(d, acc);
                    break;
            }
        }

        return acc;
    }

    // ---- Primitive evaluators (match HLSL) ----
    private static float EvaluateOneCPU(in TerrainSDF_GPU s, float3 p)
    {
        switch ((TerrainSDFType)s.SDFType)
        {
            case TerrainSDFType.Sphere:
            case TerrainSDFType.SphereSubtract:
                return SdSphere(p, s.OriginWS.xyz, s.Radius);

            case TerrainSDFType.Box:
                return SdBox(p, s.OriginWS.xyz, s.HalfExtents.xyz);

            case TerrainSDFType.Torus:
                return SdTorus(p, s.OriginWS.xyz, s.TorusRadii.xy);

            case TerrainSDFType.Cylinder:
                return SdCylinderSegment(p, s.OriginWS.xyz, s.CylinderEnd.xyz, s.Radius);

            case TerrainSDFType.Plane:
                return SdPlaneY(p, s.PlaneNorm_YLevel.w);

            default:
                return 1e9f;
        }
    }

    private static float SdSphere(float3 p, float3 c, float r)
    {
        return length(p - c) - r;
    }

    private static float SdBox(float3 p, float3 c, float3 he)
    {
        float3 d = abs(p - c) - he;
        return length(max(d, 0)) + min(max(d.x, max(d.y, d.z)), 0);
    }

    private static float SdTorus(float3 p, float3 c, float2 kr) // kr = (ringR, tubeR)
    {
        float3 r = p - c;
        float2 q = float2(length(r.xz) - kr.x, r.y);
        return length(q) - kr.y;
    }

    private static float SdCylinderSegment(float3 p, float3 a, float3 b, float r)
    {
        float3 pa = p - a;
        float3 ba = b - a;
        float  h  = saturate(dot(pa, ba) / dot(ba, ba));
        return length(pa - ba * h) - r;
    }

    private static float SdPlaneY(float3 p, float yLevel)
    {
        return p.y - yLevel;
    }

    // ------------------ Existing bounds logic (unchanged) ------------------

    public AABB GetInnerBounds(AABB outerBounds)
    {
        AABB result = AABB.Empty;

        foreach (var sdf in terrainSDFs)
        {
            AABB sdfBounds = ComputeBounds(sdf);

            // intersect with outer bounds
            AABB clamped = sdfBounds.Intersect(outerBounds);

            if (!clamped.IsEmpty)
            {
                if (result.IsEmpty)
                    result = clamped;
                else
                    result.Encapsulate(clamped);
            }
        }

        if (result.Equals(AABB.Full))
        {
            return outerBounds;
        }
        return result;
    }

    private static AABB ComputeBounds(TerrainSDF_GPU sdf)
    {
        switch ((TerrainSDFType)sdf.SDFType)
        {
            case TerrainSDFType.Sphere:
            case TerrainSDFType.SphereSubtract:
            {
                float3 center = sdf.OriginWS.xyz;
                float3 r = new float3(sdf.Radius);
                return new AABB(center - r, center + r);
            }
            case TerrainSDFType.Box:
            {
                float3 center = sdf.OriginWS.xyz;
                float3 ext = sdf.HalfExtents.xyz;
                return new AABB(center - ext, center + ext);
            }
            case TerrainSDFType.Torus:
            {
                // crude bound: ring radius + tube radius in XZ plane, tube radius in Y
                float3 center = sdf.OriginWS.xyz;
                float R = sdf.TorusRadii.x;
                float r = sdf.TorusRadii.y;
                float3 ext = new float3(R + r, r, R + r);
                return new AABB(center - ext, center + ext);
            }
            case TerrainSDFType.Cylinder:
            {
                float3 a = sdf.OriginWS.xyz;
                float3 b = sdf.CylinderEnd.xyz;
                float r = sdf.Radius;
                float3 min = math.min(a, b) - new float3(r, r, r);
                float3 max = math.max(a, b) + new float3(r, r, r);
                return new AABB(min, max);
            }
            case TerrainSDFType.Plane:
            {
                return AABB.Full;
            }
            default:
                // Planes are infinite → return an empty bound
                return AABB.Empty;
        }
    }
}

#ifndef TERRAIN_SDF_INCLUDED

// Keep enum numeric values in sync with C#
static const uint TERRAIN_SDF_SphereSubtract = 0;
static const uint TERRAIN_SDF_Sphere         = 1;
static const uint TERRAIN_SDF_Box            = 2;
static const uint TERRAIN_SDF_Torus          = 3;
static const uint TERRAIN_SDF_Cylinder       = 4;
static const uint TERRAIN_SDF_Plane          = 5;

struct TerrainSDF
{
    // 16B
    uint  SDFType;   // enum
    float Radius;    // sphere/cylinder radius
    uint FlipNormals;
    float _pad0;    // keep 16B alignment

    // 16B each (xyz used, w is padding or specific param noted below)
    float4 OriginWS;           // xyz center
    float4 HalfExtents;        // xyz box half extents
    float4 TorusRadii;         // x = ring radius, y = tube radius, zw unused
    float4 CylinderEnd;        // xyz endpoint of cylinder segment
    float4 PlaneNorm_YLevel;   // xyz = plane normal (optional), w = yLevel
};

// ---- SDF primitives ----
inline float sdSphere(float3 p, float3 c, float r)
{
    return length(p - c) - r;
}

inline float sdBox(float3 p, float3 c, float3 he)
{
    float3 d = abs(p - c) - he;
    return length(max(d, 0)) + min(max(d.x, max(d.y, d.z)), 0);
}

inline float sdTorus(float3 p, float3 c, float2 kr)
{
    float3 r = p - c;
    float2 q = float2(length(r.xz) - kr.x, r.y);
    return length(q) - kr.y;
}

inline float sdCylinderSegment(float3 p, float3 a, float3 b, float r)
{
    float3 pa = p - a;
    float3 ba = b - a;
    float  h  = saturate(dot(pa, ba) / dot(ba, ba));
    return length(pa - ba * h) - r;
}

inline float sdPlaneY(float3 p, float yLevel)
{
    return p.y - yLevel;
}

// ---- Evaluate one SDF primitive (no boolean yet) ----
inline float EvaluateOne(const TerrainSDF s, float3 p)
{
    switch (s.SDFType)
    {
        case TERRAIN_SDF_Sphere:
            return sdSphere(p, s.OriginWS.xyz, s.Radius);
        case TERRAIN_SDF_SphereSubtract:
            return sdSphere(p, s.OriginWS.xyz, s.Radius);

        case TERRAIN_SDF_Box:
            return sdBox(p, s.OriginWS.xyz, s.HalfExtents.xyz);

        case TERRAIN_SDF_Torus:
            return sdTorus(p, s.OriginWS.xyz, s.TorusRadii.xy);

        case TERRAIN_SDF_Cylinder:
            return sdCylinderSegment(p, s.OriginWS.xyz, s.CylinderEnd.xyz, s.Radius);

        case TERRAIN_SDF_Plane:
            return sdPlaneY(p, s.PlaneNorm_YLevel.x); // yLevel in .w

        default:
            return 1e9; // large positive
    }
}

// ---- Combine into an accumulated field (matches your C# logic) ----
// Usage: float d = 1e9; AccumulateSDF(sdf[i], p, d); // d becomes union/subtract result
inline void AccumulateSDF(const TerrainSDF s, float3 p, inout float acc)
{
    const float d = EvaluateOne(s, p);

    switch (s.SDFType)
    {
        case TERRAIN_SDF_SphereSubtract:
            // subtract sphere from the current field
            acc = max(-d, acc);
            break;

        case TERRAIN_SDF_Sphere:
            acc = min(d, acc);
            break;
        case TERRAIN_SDF_Box:
            acc = min(d, acc);
                break;
        case TERRAIN_SDF_Torus:
            acc = min(d, acc);
            break;
        case TERRAIN_SDF_Cylinder:
            acc = min(d, acc);
            break;
        case TERRAIN_SDF_Plane:
            // union
            acc = min(d, acc);
            break;
    }
}

// ---- Evaluate a sequence from a StructuredBuffer ----
inline float EvaluateSDFSequence(StructuredBuffer<TerrainSDF> seq, uint count, float3 p)
{
    float acc = 1e9;
    [loop] for (uint i = 0; i < count; i++)
    {
        AccumulateSDF(seq[i], p, acc);
    }
    return acc;
}

#endif // TERRAIN_SDF_INCLUDED

int3 _InnerVoxelDims;  // the dimensions of the voxels in Bounds of the sdf

//extracting correct indices from bigger batch buffer

// Input / Output

// x-fast → y → z layout
uint OuterFlatFromInnerFlat(
    uint  startingIndex1D, // s_i
    uint  index,           // k in [0, Bx*By*Bw)
    uint3 outerDims,       // (Ax, Ay, Az)
    uint3 innerDims        // (Bx, By, Bz)
){
    const uint Ax = outerDims.x, Ay = outerDims.y;
    const uint Bx = innerDims.x, By = innerDims.y;

    const uint extraCols  = Ax * 1u - Bx;          // (Ax - Bx)
    const uint extraPlane = Ax * Ay - Bx * By;     // (Ax*Ay - Bx*By)

    const uint rowsInPlane = (index / Bx) % By;    // floor(k/Bx) mod By
    const uint planes      =  index / (Bx * By);   // floor(k/(Bx*By))

    return startingIndex1D
         + index
         + extraCols  * rowsInPlane
         + extraPlane * planes;
}


[numthreads(64,1,1)]
void CSMain(uint3 dtid : SV_DispatchThreadID)
{
    
    uint idx   = dtid.x;
    uint startingIndex = _StartingIndex;
    idx = OuterFlatFromInnerFlat(startingIndex, idx, _Res, _InnerVoxelDims);
    uint idxOriginal = idx;
    
    uint sizeX = _Res.x;
    uint sizeY = _Res.y;
    uint sizeZ = _Res.z;

    uint total = sizeX * sizeY * sizeZ;
    if (idx >= total) return;

    // Decode idx -> (x,y,z) with strides
    uint strideY = sizeX;
    uint strideZ = sizeX * sizeY;

    uint z = idx / strideZ;
    idx   -= z * strideZ;
    uint y = idx / strideY;
    uint x = idx - y * strideY;

    // Corner sampling (good for MC). For centers, add +0.5 * _VoxelSizeWS
    float3 pWS = _GridMinWS + float3(x, y, z) * _VoxelSizeWS; //+ 0.5 * _VoxelSizeWS;

    float sdf = EvaluateSDFSequence(_SDFs, _SDFCount, pWS);
    _Voxels[idxOriginal] = sdf;

}

using Unity.Mathematics;

public static class SDFVoxelGizmoVisualizer
{
    public static void DrawVoxelSDFGizmos(float[] voxels, int3 resolution, float3 gridMinCorner, float3 voxelSize)
    {
        if (voxels == null || voxels.Length == 0) return;

        for (int z = 0; z < resolution.z; z++)
        {
            for (int y = 0; y < resolution.y; y++)
            {
                for (int x = 0; x < resolution.x; x++)
                {
                    int index = z * resolution.x * resolution.y + y * resolution.x + x;
                    float sdfValue = voxels[index];

                    // Map sdf to color:
                    // red channel = for negative values from -10 to 0, remapped from 1 to 0
                    // green channel = for positive values from 0 to 10, remapped from 0 to 1
                    float red = 0f;
                    float green = 0f;

                    if (sdfValue < 0f)
                    {
                        // Clamp sdfValue to [-10,0], remap so -10 -> 1, 0 -> 0
                        red = math.clamp(1f - (sdfValue / -10f), 0f, 1f);
                    }
                    else if (sdfValue > 0f)
                    {
                        // Clamp sdfValue to [0,10], remap so 0 -> 0, 10 -> 1
                        green = math.clamp(sdfValue / 10f, 0f, 1f);
                    }

                    Color color = new Color(red, green, 0f, 1f); // Semi-transparent for visibility
                    Gizmos.color = color;

                    float3 voxelWorldPos = gridMinCorner + new float3(x * voxelSize.x, y * voxelSize.y, z * voxelSize.z);
                    if (sdfValue != 0f)
                        Gizmos.DrawCube(voxelWorldPos + voxelSize * .5f, voxelSize * 0.9f);
                }
            }
        }
    }

using UnityEngine;
using Unity.Mathematics;
using System.Collections.Generic;
using UnityEngine.Rendering;
using System.Linq;
using Unity.Profiling;
/// <summary>
/// Builds and updates groups of voxels for an entire chunk grid. 
/// </summary>
public class VoxelsFactory
{
    public static ProfilerMarker BufferStep = new ProfilerMarker("BufferStep");

    struct VoxelGroup
    {
        public ComputeBufferPool pool;
        public ComputeBuffer voxelBuffer;
        public int LOD;
    }
    class RetiredBuffer
    {
        public ComputeBuffer buffer;
        public float timeRetired;
        public int chunkIndex;
    }
    List<RetiredBuffer> retiredBuffers = new List<RetiredBuffer>();

    TerrainChunker terrainChunker;
    VoxelGroup[] voxelGroups;
    ComputeShader voxelEvaluatorShader;
    ComputeBuffer sdfs;
    TerrainSDFRegistry terrainSDFRegistry;
    int sdfCount = 0;
    #region Public API
    public VoxelsFactory(TerrainPipeline terrainPipeline, TerrainChunker terrainChunker, ComputeShader voxelEvaluatorShader, int3 ChunkResolution, List<TerrainLod> terrainLods)
    {
        this.terrainPipeline = terrainPipeline;
        this.terrainChunker = terrainChunker;
        this.voxelEvaluatorShader = voxelEvaluatorShader;
        ChunkResolution = terrainPipeline.ChunkResolution;
        voxelBufferPoolsByLod = new Dictionary<int, ComputeBufferPool>();

        terrainSDFRegistry = terrainPipeline.terrainSDFRegistry;
        //one group of voxels per chunk
        voxelGroups = new VoxelGroup[ChunkResolution.x * ChunkResolution.y * ChunkResolution.z];

        //init voxelbufferpools for different level of details
        //init sdfs
        sdfs = new ComputeBuffer(100, 16 * 6);
        
        InitializeVoxelPools(terrainLods);
        InitializeVoxelGroups();
        SetSDFBuffer(terrainSDFRegistry);
    }
    public void Dispose()
    {
        for (int i = 0; i < voxelGroups.Length; i++)
        { 
            voxelGroups[i].voxelBuffer?.Dispose();
            voxelGroups[i].voxelBuffer = default;

        }
        sdfs?.Dispose();
        sdfs = default;

        foreach (KeyValuePair<int, ComputeBufferPool> bufferPool in voxelBufferPoolsByLod)
            bufferPool.Value?.Dispose();
    }
    /// <summary>
    /// Dynamically reallocates and frees buffers for each chunk depending on LOD. 
    /// If chunk LOD switches, but is still loaded -> free old buffer and realloc new one
    /// If chunk goes from loaded to unloaded -> free old buffer
    /// If chunk goes from unloaded to loaded -> alloc buffer
    /// If chunk stays unloaded -> do nothing
    /// </summary>
    public void UpdateVoxelBuffersForChunks()
    {
        using (BufferStep.Auto())
        {
            for (int chunkIndex = 0; chunkIndex < voxelGroups.Length; chunkIndex++)
            {
                TerrainChunk_Val chunk = terrainChunker.TerrainChunkCollection.TerrainChunks[chunkIndex];
                ComputeBuffer voxelBuffer = voxelGroups[chunkIndex].voxelBuffer;
                int newLOD = chunk.ChunkLOD.LOD;
                int oldLOD = voxelGroups[chunkIndex].LOD;
                //if wasn't loaded before and not loaded now
                if (oldLOD == -1 && newLOD == -1)
                {
                    //Debug.Log("Case 0");
                    continue;
                }
                //if wasn't loaded before and is loaded now
                if (oldLOD == -1 && newLOD != -1)
                {
                    //Debug.Log("Case 1");
                    voxelBuffer = UpdateBuffer(chunkIndex, newLOD);
                }
                //if was loaded before and isn't loaded now
                else if (oldLOD != -1 && newLOD == -1)
                {
                    //Debug.Log("Case 2");
                    FreeBuffer(chunkIndex);
                }
                //if was loaded before and is loaded now with different lod
                else if (newLOD != voxelGroups[chunkIndex].LOD)
                {
                    //Debug.Log("Case 3");
                    FreeBuffer(chunkIndex);
                    voxelBuffer = UpdateBuffer(chunkIndex, newLOD);
                }
                //set result
                voxelGroups[chunkIndex].voxelBuffer = voxelBuffer;
                voxelGroups[chunkIndex].LOD = newLOD;
            }
        }
    }
    /// <summary>
    /// Evaluates a group of voxels corresponding to a chunk based on the current collection of Signed Distance Functions. Uses AABB culling to only recalculate voxels in bounds of the SDFs. Automatically enqueues chunk's mesh to be rebuilt, if neccessary.
    /// </summary>
    /// <param name="chunkIndex"></param>
    /// <param name="chunk"></param>
    public void EvaluateVoxelGroup(int chunkIndex, TerrainChunk_Val chunk, TerrainLod lod, bool cullVoxels = false)
    {
        
            /// This algo gets a little confusing so just remember these key points:
            /// 1) We subtract the -1 from voxelRes during voxel size so that our voxels will extend exactly one voxel beyond the chunk.
            /// These extra voxels act as a "halo", they are used to make sure that we dont get holes when the SDF is near the borders of the chunk. Remember, marching cubes needs 8 voxels in a cube for one sample, 
            /// meaning on the edges of chunk we need one voxel to stick out so that we can still get a full sample.

        ComputeBuffer voxelBuffer = voxelGroups[chunkIndex].voxelBuffer;

        int3 voxelRes = lod.VoxelResolution;
        float3 voxelSize = terrainPipeline.ChunkDimensions / (float3)(voxelRes - 1);
        int voxelCount = voxelRes.x * voxelRes.y * voxelRes.z;
        AABB chunkBounds = new AABB(chunk.MinCornerWS, chunk.MinCornerWS + chunk.ChunkSize);
        AABB voxelBounds = chunkBounds;
        int3 regionRes = voxelRes;
        int numVoxelsInSDFBounds = voxelCount;
        int3 startingIndex = int3.zero;

        if (cullVoxels)
        {
            Debug.LogWarning("Cull Voxels Enabled. Cull Voxels currently significant impacts CPU performance at the benefit of GPU (to a, estimated, minimal extent).");
            voxelBounds = terrainSDFRegistry.GetInnerBounds(chunkBounds);
            float3 boundsDiff = voxelBounds.Max - voxelBounds.Min;
            if (math.any(boundsDiff == float.NegativeInfinity) || math.any(boundsDiff == float.PositiveInfinity)) return;
            //+1 here because we want to include the extra "halo" of voxels
            regionRes = new int3(
                (int)math.ceil(boundsDiff.x / voxelSize.x + 1),
                (int)math.ceil(boundsDiff.y / voxelSize.y + 1),
                (int)math.ceil(boundsDiff.z / voxelSize.z + 1)
            );
            numVoxelsInSDFBounds = regionRes.x * regionRes.y * regionRes.z;
            if (numVoxelsInSDFBounds == 0) { return; }
            startingIndex = (int3)GetStartingIndex(voxelBounds.Min, chunk.MinCornerWS, voxelSize, voxelRes);

        }
            
            //Prepare dispatch
            voxelEvaluatorShader.SetInts("_Res", voxelRes.x, voxelRes.y, voxelRes.z);
            voxelEvaluatorShader.SetFloats("_VoxelSizeWS", voxelSize.x, voxelSize.y, voxelSize.z);
            voxelEvaluatorShader.SetFloats("_GridMinWS", chunk.MinCornerWS.x, chunk.MinCornerWS.y, chunk.MinCornerWS.z);
            voxelEvaluatorShader.SetInts("_StartingIndex", startingIndex.x, startingIndex.y, startingIndex.z);
            voxelEvaluatorShader.SetInts("_InnerVoxelDims", regionRes.x, regionRes.y, regionRes.z);
            voxelEvaluatorShader.SetBuffer(0, "_Voxels", voxelBuffer);
            voxelEvaluatorShader.SetInt("_SDFCount", sdfCount);
            voxelEvaluatorShader.SetBuffer(0, "_SDFs", sdfs);
            //Dispatch
            voxelEvaluatorShader.Dispatch(0, (numVoxelsInSDFBounds + 63) / 64, 1, 1);

            //Queue Mesh Creation
            //terrainChunker.CalculateMesh(chunkIndex, voxelRes, voxelBuffer);

            //Debugging
            if (terrainPipeline.displayVoxels)
                Debug.DrawLine(voxelBounds.Min, voxelBounds.Max, Color.yellow, 1000f);
            //Optional Async readback to get debugging info (Bad for performance)
            if (terrainPipeline.displayVoxels)
            {
                AsyncGPUReadback.Request(voxelBuffer, (AsyncGPUReadbackRequest) =>
                {

                    float[] voxels = AsyncGPUReadbackRequest.GetData<float>().ToArray();
                    TerrainPipeline.VoxelDebugData voxelDebugData = new TerrainPipeline.VoxelDebugData(voxels, voxelRes, chunk.MinCornerWS, voxelSize);

                    if (lod.LOD == 1)
                    {
                        terrainPipeline.AddVoxelDebugData(voxelDebugData);
                    }

                });
            }
    }
    public ComputeBuffer GetVoxelBuffer(int chunkIndex )
    { 
        return voxelGroups[chunkIndex].voxelBuffer;
    }
    #endregion
    #region Private Methods
    ComputeBuffer UpdateBuffer(int chunkIndex, int lod)
    {
        VoxelGroup voxelGroup = voxelGroups[chunkIndex];
        ComputeBufferPool computeBufferPool = voxelBufferPoolsByLod[lod];
        voxelGroup.voxelBuffer = computeBufferPool.TryGetBuffer();
        //Safety measure to ensure we always have a buffer, even tho this technically could lead to a crash
        if (voxelGroup.voxelBuffer == null) //TryGetBuffer() Failed
            voxelGroup.voxelBuffer = computeBufferPool.TryAddBuffer();
        voxelGroup.LOD = lod;
        voxelGroup.pool = computeBufferPool;
        numAllocated++;
        voxelGroups[chunkIndex] = voxelGroup;
        return voxelGroup.voxelBuffer;
    }
    void FreeBuffer(int chunkIndex)
    {
        VoxelGroup voxelGroup = voxelGroups[chunkIndex];
        ComputeBuffer voxelBuffer = voxelGroup.voxelBuffer;
        voxelGroup.pool.TryFreeBuffer(voxelBuffer);
        voxelGroup.voxelBuffer = null;
        voxelGroup.pool = null;
        voxelGroup.LOD = -1;
        numFreed++;
        voxelGroups[chunkIndex] = voxelGroup;
    }

    public void SetSDFBuffer(TerrainSDFRegistry SDFRegistry)
    {
        IReadOnlyDictionary<uint, TerrainSDF_GPU> terrainSDFs = SDFRegistry.TerrainSDFS;
        sdfCount = terrainSDFs?.Count ?? 0;
        
        if (sdfCount == 0) return;
        sdfs.SetData(terrainSDFs.Values.ToArray<TerrainSDF_GPU>());
    }
    void InitializeVoxelPools(List<TerrainLod> terrainLods)
    {
        foreach (TerrainLod lod in terrainLods)
        {
            ComputeBufferPool computeBufferPool = new ComputeBufferPool((int)TerrainChunker.ManhattanFloodFillCount3D(lod.chunkRadius + 1), lod.VoxelResolution.x * lod.VoxelResolution.y * lod.VoxelResolution.z * 2, sizeof(float), ComputeBufferType.Default);
            voxelBufferPoolsByLod.Add(lod.LOD, computeBufferPool);
        }
        voxelBufferPoolsByLod.Add(-1, null); // add this to represent the non loaded LOD (i.e: -1)
    }

    uint GetStartingIndex(float3 _VoxelMinBounds, float3 _GridMinWS, float3 _VoxelSizeWS, int3 _Res)
    {
        int3 startingVoxelIndex = (int3)((_VoxelMinBounds - _GridMinWS) / _VoxelSizeWS);
        uint startingVoxelIndex1D = (uint)(startingVoxelIndex.x + startingVoxelIndex.y * _Res.x + startingVoxelIndex.z * _Res.x * _Res.y);
        return startingVoxelIndex1D;
    }
