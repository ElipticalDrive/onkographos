Summary
External-survey round 7 — the algorithm-layer gaps (taxonomy leftovers are all intentionally out-of-scope: derive macro, hot reload, socket transport). Four additions, all integer-exact, all verified against independent oracles:
gridcast — Amanatides–Woo DDA ray traversal (grid_ray, ray_blocked_at, clear_los). Unlike geometry's Bresenham (one cell per column), this walks every cell a segment enters in entry order — needed for ballistic/LOS sweeps. All coordinates doubled (endpoints are cell centres, boundaries even), the tMaxX < tMaxY comparison cross-multiplied in i128. Corner exits (tMaxX == tMaxY) enter only the diagonal cell — the two side cells get zero-length intersection — which keeps the walk minimal and makes grid_ray(a,b) == rev(grid_ray(b,a)) exact.
graph — deterministic algorithms on u32 adjacency lists, all iterative (no recursion-depth limit): strongly_connected (Tarjan SCC, reverse-topo component order), articulation_points, bridges, topo_sort (Kahn + BinaryHeap<Reverse> = canonical lexicographic order, None on cycle), and UnionFind (path-halving + union-by-rank, smaller-index root on ties so representatives are pure functions of the union sequence — the structure voronoi::mst_edges used internally, now public). Edge case nailed down: the tree-edge skip tracks a per-frame par_skipped flag, so a parallel edge to the parent still lowers low — parallel edges are correctly never reported as bridges.
pack — skyline (bottom-left) rectangle bin packing (Jylänki, A Thousand Ways to Pack the Bin, 2010). pack_skyline(rects, bin_w, bin_h) drops each rect onto the lowest fitting skyline segment — input order is placement order, so output is a pure function of the slice. Texture atlases / inventory grids / dialog tiling.
hexgrid::hex_astar — hex-grid A* (redblobgames): the exact hex distance is a consistent heuristic, so nodes expand at most once and results are true shortest paths; (f, h, q, r) heap tie-break + ordered-map bookkeeping; max_steps bounds the search since the hex lattice is unbounded.
Verification
Every addition is oracle-tested rather than hand-verified:
grid_ray vs an independent slab-test (segment ∩ open cell box has positive length) over 500 random rays — plus symmetry, no-dup, 8-connected checks.
strongly_connected vs mutual-BFS-reachability; articulation_points/bridges vs remove-and-recount; topo_sort vs linear-extension validity + cycle rejection; UnionFind vs a reference set model.
pack_skyline invariants (no overlap, inside bin) over 200 random rect sets.
hex_astar vs BFS shortest-path length on random obstacle fields.
bash tools/gate.sh — all green: fmt, workspace tests, clippy 0 warnings, rustdoc clean, pinned determinism hashes unchanged (0xd1a9236e96a2c802 / 0x5286d1420200fe66 / kit_bridge 353498ec4fbcd160), all 30 examples reproduce byte-identically, both crates package.
