Summary
Implements issue 0010 (child of the M1 tracking issue 0001): convert a normalized MeshData (watertight assumed) into the solid voxel target that growAssembly consumes. Method was fixed in advance by the issue 0008 spike; no design decisions were open.
```
MeshData (mm / Z-up / grounded) → 6-direction majority vote (±X/±Y/±Z odd-even ray parity)
→ { voxels: Map<"i,j,k", colorId>, seed }  // voxel centers at (i,j,k)·voxelMm — grow.ts convention
```
Changes
src/domain/voxelize.ts — voxelizeSolid(mesh, voxelMm, colorId). Hand-rolled Möller–Trumbore ray-triangle intersection accelerated by per-axis uniform triangle grids (3 shared grids vs the spike's 6 — cheaper index construction). Majority threshold votes >= 3 (ties inside) — verified identical to the spike's measured baseline (Math.ceil(6/2)). Zero three.js dependency; colorId is a parameter so the domain layer stays palette-free (this deviates from the issue's originally drafted signature; the issue doc is updated accordingly).
src/domain/voxelize.test.ts — 6 tests with analytic ground truth.
Issue doc updated: contract signature + per-criterion evidence, marked done.
Acceptance criteria (measured)
Error rate ≤ 2% vs analytic solution — sphere 1.44% (r=20mm, 1280 faces), box 0.0047%
Interior is filled (solid, not shell) — central 3×3×3 block fully filled (sphere placed off-origin to avoid the axis-aligned ray degeneracy known from the spike)
Seed = filled voxel on lowest-k layer nearest the (i,j) bbox center (same policy as generator.cellsToVoxels)
40³-equivalent timing logged — ~75ms (20480-face icosphere, 32764 voxels; spike measured 85–103ms)

function pickSeed(minKCells: readonly [number, number][], minK: number): string | undefined {
if (minKCells.length === 0) return undefined
const is = minKCells.map((c) => c[0])
const js = minKCells.map((c) => c[1])
const cx = (Math.min(...is) + Math.max(...is)) / 2
const cy = (Math.min(...js) + Math.max(...js)) / 2
let best = minKCells[0]
let bestD = Infinity
for (const c of minKCells) {
const d = (c[0] - cx) ** 2 + (c[1] - cy) ** 2
if (d < bestD) {
bestD = d
best = c
}
}
return `${best[0]},${best[1]},${minK}`
}
