Summary
Make marching-cubes triangulation deterministic when the requested isosurface level equals a voxel value.
Root cause
The cube classification code compared each corner against zero after subtracting the isovalue, but left exact zero values unchanged. Adjacent cubes could therefore select incompatible face triangulations for the same shared face, producing holes in the mesh. The reference implementation resolves this tie by replacing values whose magnitude is below machine epsilon with a small positive value.
This change applies the same tie-breaking rule to all eight cube corners before calculating the lookup-table index. It keeps shared-face classifications consistent while preserving the existing interpolation path.
Validation
Added mirrored regression tests for the standard and skimage2 APIs using the reported 3 x 3 x 3 volume.

The new tie-break applies to nonzero residuals as well as exact ties, which makes marching cubes depend on the scalar-field magnitude. Each corner whose abs(value - level) is below np.spacing(1.0) is forced to positive epsilon, even when the corner is genuinely below the isosurface.
I reproduced this on exact head d448425e3c4498cb9210a28185d4dd2273f83fdf with a 2x2x2 planar field whose first layer is -scale, second layer is +scale, and level is zero. There are no level-equal voxels, and multiplying the field by a positive scale should leave the plane unchanged. Exact base cb1adbd63149f69e9b10be55e686b1fc457dd1a4 returns the same four vertices and two faces for every tested scale from 1 through 1e-20. This head does so through 1e-15, but at 2e-16, 1e-16, and 1e-20 it turns both layers positive and raises RuntimeError: No surface found at the given iso value. The result is identical through both the stable and experimental APIs. The current synthetic merge 26588a1fee300ba46ebd1711d299984c35b98c26 has byte-identical marching-cubes implementation and wrapper blobs, so the regression applies there unchanged.
Please restrict the deterministic tie-break to actual zero residuals (or otherwise preserve the sign of every nonzero residual), and add an intensity-scale regression with no exact-level samples. The intended exact-tie fix itself is demonstrated: the two submitted mirrored tests fail on base and pass on head, all 18 owning marching-cubes tests pass on head, and the full stable/experimental measure suites pass 1,336 tests with 4 optional-data skips.
