Visualization of Vector Fields Using
Seed LIC and Volume Rendering
Anders Helgeland, Member, IEEE, and Oyvind Andreassen
Abstract—Line Integral Convolution (LIC) is a powerful texture-based technique for visualizing vector fields. Due to the high
computational expense of generating the 3D textures and the difficulties of effectively displaying the result, LIC has most commonly
been used to depict vector fields in 2D or over a surface in 3D. Here, we propose new methods for more effective volume visualization
of three-dimensional vector fields using LIC: 1) We present a fast method for computing volume LIC textures that exploits the sparsity
of the input texture. 2) We propose the use of a shading technique, called limb darkening, to reveal the depth relations among the field
lines. The shading effect is obtained simply by using appropriate transfer functions and, therefore, avoids using expensive shading
techniques. 3) We demonstrate how two-field visualization techniques can be used to enhance the visual information describing a
vector field. The volume LIC textures are rendered using texture-based rendering techniques, which allows interactive exploration of a
vector field.
Index Terms—Vector field visualization, line integral convolution, direct volume rendering, multifield visualization.

INTRODUCTION
V
ECTOR fields play an important role in science and
engineering. They allow us to describe a wide variety
of phenomena like fluid flows and electromagnetic fields.
Large vector fields often exhibit complex structures, which
can be difficult to reveal using standard visualization
techniques. Visualization of vector fields is one of the current
challenges in scientific visualization and has been an active
field of research for some years. A number of sophisticated
methods have been proposed to tackle this problem.
Traditionally, vector data has been represented by arrows
and other geometric primitives indicating vector magnitude
and direction. More advanced methods include the display of
field lines, stream surfaces [1], and flow volumes [2].
However, large three-dimensional vector fields can be
difficult to visualize effectively using these techniques. Both
arrows and field lines can produce cluttered and confusing
images if placed densely in space. Furthermore, the limited
number of field lines that can be displayed without cluttering
the image makes the visualization strongly dependent on the
choice of “seed points,” which are the start positions of the
integrated lines. It is not obvious how to distribute the field
lines in space without missing important details of the field.
By using texture-based techniques [3], [4], [5], some of these
problems can be avoided.
A powerful texture-based visualization method is Line
Integral Convolution (LIC), proposed by Cabral and
Leedom [3]. Based on blurring of an input texture locally
along the field lines of a given vector field, the method
generates images that convey the directional information of

First, we present a new method for computing 3D or

2.1 Generation of an Appropriate Input Texture
When LIC is applied to a solid 3D input texture, the output
is a solid 3D LIC texture that is blurred along the direction
of the vector field. Such a solid texture can be challenging to
visualize clearly due to the perceptual difficulties encountered with dense 3D displays. Interrante and Grosch [18]
presented several strategies for effectively illustrating
3D flow with volume LIC. This includes strategies to define
an appropriate input texture by using ROI functions to
highlight important features of a vector field and sparse
input textures [23] to render a collection of densely placed
field lines instead of a solid object. Since texture-based
techniques allow the display of a large number of lines
simultaneously in an image, the positioning of individual
field lines becomes less important. This allows for the use of
statistical methods for distributing the seed points. We
adopt these strategies when generating the input texture.
We have tried different approaches for distributing the
seed points in the 3D texture. In the first approach, the idea
was to make a texture where the points were distributed after
the scalar value that was used in making the ROI mask.
Hence, we get output images where regions with high scalar
values are more emphasized than other regions with lower
values. As a consequence, the regions with the highest scalar
values become more cluttered than the regions with lower
scalar values. Another option is a more random approach.
This method leads to an LIC texture where the field lines are
more evenly distributed. Fig. 1 shows some examples of LIC
applied to input textures generated with different distribution functions using the same region of interest. In Fig. 1a, the
points in the input texture were distributed according to the
vorticity magnitude, while, in Fig. 1b and Fig. 1c, a random
approach was used. The visualized vector field shows the
vorticity field obtained from a simulation of shock waves [24].
The input textures ð594  394  194Þ were defined to be twice
as large as the vector field so that the details could be more
easily seen.

2.2 Seed LIC
For large 3D data sets (5123 or greater), even the Fast LIC
algorithm proposed by Stalling and Hege [7] is very
computationally intensive. Instead of using the Fast LIC
algorithm as in [18], we propose a new method that exploits
the sparsity of the input texture.
When using a sparse input texture that has been masked
by a region of interest, most of the voxels in the 3D input
texture are set to zero. When using the Fast LIC algorithm
on a texture like this, many unnecessary computations are
performed in areas that make no contribution to the final
image. In Fast LIC, a sufficient number of field lines are
calculated so that every voxel in the output texture is
covered, correlating the voxel values along these lines. But,
in cases where the field lines do not coincide with cells in
the input texture that contain the seed points (i.e., those
points initialized to 255), no additional information is
propagated to the voxels along them. The value in those
voxels will be the same in the input and output texture
(which is zero) and the computations in these cells are
unnecessary. By only calculating field lines from the voxels
containing the seed points, the number of computationally
intensive operations is reduced.

ALIASING
Aliasing can be a problem when using voxel graphics.
Representing a field line with voxels, as in volume LIC,
results typically in a “stair-stepped” appearance. Some of
the aliasing present in the output texture is removed by
trilinear interpolation during rendering.2 This is since LIC
applied to a sparse input texture generates a dense
collection of field lines that are mostly surrounded by
voxels containing zero values and interpolations between
these values and the core values result in smoother field
lines. Fig. 5a demonstrates the effect of the interpolation.
The figure shows that trilinear interpolation not only
reduces aliasing, but also, with an appropriate transfer
function, creates a halo effect which makes it easier to
separate the individual lines from one another. The halo
effect will be further discussed in Section 5.
Seed LIC is more affected by aliasing than Fast LIC and
therefore does not give quite as smooth a result as Fast LIC.
This is due to the fewer number of voxels calculated in the
Seed LIC algorithm. While Seed LIC only assigns values to the
voxels along the field lines from the seed points, Fast LIC also
assigns values to neighboring voxels, which leads to a

5.1 Limb Darkening
While geometric objects have reflective properties so that
the use of light sources emphasizes the 3D shape, a volume
could be thought of as emitting light, where the emitted
light expresses the data value of a particular voxel. Without
the use of light sources, one could then anticipate that
volume rendering would result in “flat” images with little
information about the depth relations in the volume. By
using a shading or “halo” technique called limb darkening
[24], we can generate images with a three-dimensional
appearance. The technique has its name because the effect
obtained is similar to what is well-known in astrophysics.
Looking at the sun with a small telescope, it is evident that
the center is brighter than the limb. This is due to the fact
that, when viewing the center of the sun, we see deeper into
its atmosphere where the temperature is higher than in the
layers we see closer to the edge. Since higher temperatures
are visible as brighter, we observe a relative darkening
effect at the limb (see Fig. 6).
Limb darkening can be utilized in volume visualization.
By assigning darker values and decreasing the opacity near
the edges of an “object” we obtain a deep three-dimensional
rendering. This is illustrated in Fig. 7a. The halo effect
created by limb darkening is obtained just by using
appropriate TFs. If we use the HSVA color model, we can
control the “temperature” or the intensity of the light

Shading is important for the spatial interpretation of
scientific data. Different methods have been used for the
rendering of volume LIC textures and for revealing 3D flow
structures. Interrante and Grosch [18] proposed a shading
method which involves the use of gaps to highlight the
depth discontinuities. In this method, two LIC textures are
computed: one for the field lines and one for an enclosing
set of halos. The final image is rendered during ray casting
volume rendering, taking both textures as inputs. Another
approach involves the use of the illumination model for
field lines [4] and was proposed in [20]. In this paper, we
propose the use of a shading technique called limb darkening
to reveal the 3D shape and depth relations among the field
lines traced by Seed LIC.

LIC AND VOLUME VISUALIZATION
Interactivity is important for understanding complex
3D vector field structures. In order to properly study a
three-dimensional vector field, the user must be able to rotate
the volume, zoom in and out, and pick subsets at an
interactive rate. Texture-based direct rendering [29], [30]
allows interactive visualization and manipulation of 3D data.
In order to ensure comprehensive and convenient
exploration of vector data, Rezk-Salama et al. [19] suggest
interactive functionalities such as transfer functions and clip
planes. Interactive manipulation of transfer functions
simplifies the process of finding appropriate color and
opacity values and ensures the quick production of a
meaningful visualization of a volume LIC texture, including
limb darkening. Since the halo effect created by limb
darkening is obtained simply by manipulating TFs, more
expensive shading techniques are avoided that could
interfere with the interactivity. The use of clip planes
allows the exploration of the interior structures of a vector
field. By interactively moving a clip plane inside a volume,
the user is able to follow the field lines in a volume LIC
texture more clearly. This significantly improves the spatial
understanding of the vector field. The best results are
achieved when using clip planes in conjunction with LIC
applied to sparse input textures.

TWO-FIELD VISUALIZATION
Texture-based direct volume rendering is very useful when
studying multiple fields at the same time and there exist
several methods for doing this. The rendering of two fields
can, for example, be achieved by using two independent sets
of color and opacity tables. Merging the two data sets is done
by applying a double set of sampling planes, one for each
field. This is useful when comparing two fields. Another
approach is to let one of the fields define the structure or the
“body” through opacity and the other field to define the color.
This method is useful for conveying information about
related scalar quantities obtained from a simulation.

[37]. As most of these techniques are able to generate realtime visualizations of steady and unsteady vector fields, it is
of interest to compare these methods against our proposed
Seed LIC method. Since Seed LIC is an instantaneous
method, the discussion is limited to visualization of field
lines in a three-dimensional vector field and includes

lines and voxel intensities in the output texture are calculated
simultaneously by Seed LIC, the Chameleon technique splits
this process into two stages. First, field lines are generated
from the 3D vector field. Various geometric properties of the
field lines are then extracted and converted into a volumetric
form through a voxelization process to generate a trace
volume. In the second phase, the trace volume is combined
with a desired appearance texture to create various visual
representations of the vector field. As the field line generation
is the only step in this algorithm without any hardwareassistance, this ensures real-time rendering when modifying
the appearance texture.
One important difference between the two algorithms is
in the distribution of the seed points. While Li et al. use the
method by [38] to select seed points randomly over the
entire domain or a user-specified ROI geometry, the input
texture in the Seed LIC method is often masked by an ROI
function (see Fig. 1). This strongly reduces the number of
field lines that have to be calculated compared to the
Chameleon method. If the seed points, in Seed LIC, are
distributed randomly over the whole domain, as was the
case in the computations in Table 1, both methods should
spend about the same time on field lines calculations
assuming that the same integration method and parameter
settings are used.3 However, when using a region of interest
function to highlight important features in large data sets,
the Seed LIC can be much faster compared to the method by
Li et al. One of the strong aspects of the Chameleon method
is that, once the trace volume is created, the user can
manipulate various parameters to create desired visualizations in real-time, including visual effects like shading,

CONCLUSION
In this paper, we have proposed new methods for more
effective volume visualization of three-dimensional vector
fields using LIC. First, we have presented a fast method for
computing volume LIC textures that can be used in an
interactive setting. With an appropriate input texture, this
method generates images that clearly and effectively reveal
the directional structures of a vector field. To reveal the
depth relation among the field lines, we have proposed the
use of a shading or halo technique called limb darkening. To
emphasize the halo effect and to reduce aliasing effects due
to the use of voxels to represent the field lines, the textures
are convolved with an isotropic 3  3  3 filter. This
approach smears the field lines outward, making the lines
in the output texture thicker and smoother, improving the
3D perception of the LIC texture. To obtain a finer and more
accurate representation of the field lines, the input texture
can be oversampled by a factor of 2 to 4 in each dimension
prior to the LIC computation. Finally, we have demonstrated how texture-based direct volume rendering,
together with volume LIC, can be used to display additional
information about related scalar quantities when visualizing vector fields. This is used to enhance the visual
information describing a vector field. We are continuing
to investigate methods for effective volume visualization of
three-dimensional time-dependent flows using Seed LIC.
