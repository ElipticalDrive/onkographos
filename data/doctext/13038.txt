This PR implements the first ray casting system using the DDA (Digital Differential Analyzer) algorithm along with mathematical trigonometry functions. The implementation adds fundamental ray casting functionality to render a 3D-like view from the 2D map.
Key changes include:
Implementation of DDA algorithm for ray casting with horizontal and vertical intersection calculations
Addition of ray direction detection and angle normalization utilities
Integration of map dimensions calculation and ray casting into the main game loop
