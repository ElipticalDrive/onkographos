# HZL-fluidEffectsStudio

A real-time, GPU-first fluid effects studio built with C++17, CUDA, and
OpenGL 4.6 for creating and rendering interactive smoke, fire, and volumetric
effects.

## Supported development environment

The primary development target is:

- Ubuntu 22.04 LTS on an X11 desktop session
- NVIDIA GeForce RTX 3080 (compute capability 8.6)
- A proprietary NVIDIA driver compatible with the installed CUDA Toolkit
- CUDA Toolkit 12.1
- GCC/G++ 11
- CMake 3.22 or newer
- Ninja
- Python 3.8 or newer (used by GLAD's build tools)
- OpenGL 4.6

Other recent Ubuntu, compiler, and CUDA versions may work, but this is the
baseline configuration used by the project. Wayland support is optional; X11
is the initial target for graphics debugging and future CUDA/OpenGL
interoperability work.

## Install dependencies

Install the native build and window-system dependencies:

```bash
sudo apt update
sudo apt install \
  build-essential \
  cmake \
  ninja-build \
  python3 \
  libgl1-mesa-dev \
  xorg-dev
```

Install the proprietary NVIDIA driver and CUDA Toolkit separately using
NVIDIA's Ubuntu installation instructions. The driver, CUDA compiler, and GPU
should be available before configuring the project:

```bash
nvidia-smi
nvcc --version
```

GLFW and GLAD are downloaded automatically by CMake during the first
configuration, so an internet connection is required for a clean build.

### Optional Wayland support

To build GLFW with Wayland support, install:

```bash
sudo apt install libwayland-dev wayland-protocols libxkbcommon-dev
```

## Configure and build

CMake presets provide consistent Debug, Release, and profiling builds. All
presets use Ninja, generate editor compile commands, and use GLFW's X11 backend:

```bash
cmake --preset debug
cmake --build --preset debug --parallel
```

The optimized and profiling-oriented configurations use separate build
directories. The profile preset retains debug information while enabling
compiler optimizations for tools such as NVIDIA Nsight Systems and Nsight
Compute:

```bash
cmake --preset release
cmake --build --preset release --parallel

cmake --preset profile
cmake --build --preset profile --parallel
```

## Run

Run the debug build from the repository root:

```bash
./build/debug/HZLFluidEffectsStudio
```

The program should open a window and print the detected OpenGL version and GPU
renderer. If window creation fails, confirm that the proprietary NVIDIA driver
is active and that the current desktop session provides an OpenGL 4.6 context.

### Camera controls

- Left-drag rotates the orbit camera.
- Middle-drag pans the orbit target.
- Scroll zooms in or out.
- `Tab` switches between orbit and fly modes.
- In fly mode, hold the right mouse button to look around.
- In fly mode, use `W`, `A`, `S`, and `D` to move, and `Q`/`E` to descend/ascend.
- Hold left `Shift` to fly faster.
- `F` resets and focuses the camera on the simulation origin.
- Hold `Ctrl` and left-drag in the viewport to paint smoke, heat, and velocity.
- `F5` recompiles and reloads the current GLSL shaders.
- `Escape` closes the application.

## Tests

The CUDA numerical tests validate trilinear interpolation, scalar advection,
pressure projection, smoke forces, painting, and simulation-field conversion:

```bash
ctest --test-dir build/debug --output-on-failure
```

The tests require access to an NVIDIA CUDA device.

## Editor integration

The Debug preset creates `build/debug/compile_commands.json`. C++ editors and
language servers should use that file to resolve generated GLAD headers and the
GLFW include paths. In VS Code with the Microsoft C/C++ extension, add the
following workspace setting if it is not detected automatically:

```json
{
  "C_Cpp.default.compileCommands": "${workspaceFolder}/build/debug/compile_commands.json"
}
```

## Common configuration errors

- `Could NOT find OpenGL`: install `libgl1-mesa-dev`.
- `No package 'xkbcommon' found`: either install the optional Wayland packages
  or configure with `-DGLFW_BUILD_WAYLAND=OFF`.
- Red include diagnostics after a successful build: restart the language server
  and confirm it uses `build/debug/compile_commands.json`.
- CUDA compiler detection fails: verify that `nvcc` is on `PATH` and that the
  installed host compiler is supported by the installed CUDA Toolkit.

### assets/shaders/volume.frag
```
#version 460 core

layout(location = 0) in vec2 textureCoordinate;
layout(location = 0) out vec4 fragmentColor;

uniform sampler3D densityTexture;
uniform sampler3D temperatureTexture;
uniform sampler3D fireTexture;
uniform sampler2D historyTexture;
uniform sampler2D sceneDepthTexture;
uniform mat4 inverseViewProjection;
uniform vec3 cameraPosition;
uniform float densityScale;
uniform float stepSize;
uniform int maximumSteps;
uniform int frameIndex;
uniform bool jitterEnabled;
uniform bool adaptiveSteppingEnabled;
uniform int fieldMode;
uniform vec3 lightDirection;
uniform float lightIntensity;
uniform float absorption;
uniform float emissionStrength;
uniform bool selfShadowingEnabled;
uniform bool temporalEnabled;
uniform float historyWeight;
uniform mat4 previousViewProjection;

float random(vec2 coordinate)
{
    vec3 value = fract(vec3(coordinate.xyx) * 0.1031);
    value += dot(value, value.yzx + 33.33 + float(frameIndex) * 0.01);
    return fract((value.x + value.y) * value.z);
}

vec2 intersectBox(vec3 rayOrigin, vec3 inverseRayDirection)
{
    vec3 first = (vec3(-1.0) - rayOrigin) * inverseRayDirection;
    vec3 second = (vec3(1.0) - rayOrigin) * inverseRayDirection;
    vec3 minimum = min(first, second);
    vec3 maximum = max(first, second);
    return vec2(
        max(max(minimum.x, minimum.y), minimum.z),
        min(min(maximum.x, maximum.y), maximum.z));
}

float lightTransmittance(vec3 position)
{
    if(!selfShadowingEnabled)
    {
        return 1.0;
    }
    vec3 direction = -normalize(lightDirection + vec3(0.0001));
    float opticalDepth = 0.0;
    const float shadowStep = 0.08;
    for(int index = 0; index < 20; ++index)
    {
        position += direction * shadowStep;
        if(any(greaterThan(abs(position), vec3(1.0))))
        {
            break;
        }
        opticalDepth += texture(densityTexture, position * 0.5 + 0.5).r * shadowStep;
    }
    return exp(-opticalDepth * absorption * densityScale * 3.0);
}

void main()
{
    vec2 clipPosition = textureCoordinate * 2.0 - 1.0;
    vec4 farPoint = inverseViewProjection * vec4(clipPosition, 1.0, 1.0);
    vec3 farWorld = farPoint.xyz / farPoint.w;
    vec3 rayDirection = normalize(farWorld - cameraPosition);

    vec2 intersection = intersectBox(cameraPosition, 1.0 / rayDirection);
    float distanceAlongRay = max(intersection.x, 0.0);

    float sceneDepth = texture(sceneDepthTexture, textureCoordinate).r;
    if(sceneDepth < 1.0)
    {
        vec4 scenePoint = inverseViewProjection
            * vec4(clipPosition, sceneDepth * 2.0 - 1.0, 1.0);
        vec3 sceneWorld = scenePoint.xyz / scenePoint.w;
        float sceneDistance = dot(sceneWorld - cameraPosition, rayDirection);
        intersection.y = min(intersection.y, sceneDistance);
    }

    if(intersection.y <= distanceAlongRay)
    {
        discard;
    }

    if(jitterEnabled)
    {
        distanceAlongRay += random(gl_FragCoord.xy) * stepSize;
    }

    vec4 accumulated = vec4(0.0);
    vec3 representativePosition = cameraPosition + rayDirection * distanceAlongRay;
    bool foundVolume = false;
    for(int index = 0; index < 768 && distanceAlongRay < intersection.y; ++index)
    {
        if(index >= maximumSteps)
        {
            break;
        }
        vec3 position = cameraPosition + rayDirection * distanceAlongRay;
        float fieldValue = texture(densityTexture, position * 0.5 + 0.5).r;
        float density = fieldValue;
        if(!foundVolume && density > 0.01)
        {
            representativePosition = position;
            foundVolume = true;
        }
        vec3 smokeColor;
        vec3 emittedLight = vec3(0.0);
        if(fieldMode == 0)
        {
            float temperature = texture(temperatureTexture, position * 0.5 + 0.5).r;
            float fire = texture(fireTexture, position * 0.5 + 0.5).r;
            float transmittance = lightTransmittance(position);
            vec3 ambient = vec3(0.12, 0.15, 0.20);
            vec3 direct = vec3(1.0, 0.88, 0.72) * lightIntensity * transmittance;
            smokeColor = mix(vec3(0.15, 0.18, 0.23), vec3(0.7),
                clamp(position.y * 0.35 + 0.55, 0.0, 1.0)) * (ambient + direct);
            vec3 flameColor = mix(vec3(1.0, 0.08, 0.005), vec3(1.0, 0.92, 0.45),
                clamp(temperature * 0.55, 0.0, 1.0));
            emittedLight = flameColor * fire * emissionStrength;
        }
        else if(fieldMode == 1)
        {
            smokeColor = mix(vec3(0.3, 0.04, 0.01), vec3(1.0, 0.65, 0.08), fieldValue);
        }
        else if(fieldMode == 2 || fieldMode == 3)
        {
            density = abs(fieldValue - 0.5) * 2.0;
            smokeColor = fieldValue >= 0.5
                ? vec3(1.0, 0.2, 0.08)
                : vec3(0.08, 0.35, 1.0);
        }
        else if(fieldMode == 4)
        {
            smokeColor = mix(vec3(0.02, 0.15, 0.2), vec3(0.1, 0.9, 1.0), fieldValue);
        }
        else if(fieldMode == 5)
        {
            smokeColor = mix(vec3(0.05, 0.15, 0.03), vec3(0.55, 1.0, 0.15), fieldValue);
        }
        else if(fieldMode == 6)
        {
            smokeColor = vec3(0.9);
        }
        else if(fieldMode == 7)
        {
            smokeColor = mix(vec3(0.6, 0.015, 0.002), vec3(1.0, 0.9, 0.25), fieldValue);
        }
        else
        {
            smokeColor = mix(
                vec3(0.18, 0.23, 0.32),
                vec3(0.72, 0.79, 0.88),
                clamp(position.y * 0.35 + 0.55, 0.0, 1.0));
        }
        float currentStep = stepSize;
        if(adaptiveSteppingEnabled && density < 0.004)
        {
            currentStep *= 4.0;
        }
        float opacity = 1.0 - exp(-density * densityScale * currentStep * absorption * 4.0);
        accumulated.rgb += (1.0 - accumulated.a)
            * (opacity * smokeColor + emittedLight * currentStep);
        accumulated.a += (1.0 - accumulated.a) * opacity;
        if(accumulated.a > 0.985)
        {
            break;
        }
        distanceAlongRay += currentStep;
    }

    if(accumulated.a < 0.002)
    {
        discard;
    }
    if(temporalEnabled && foundVolume)
    {
        vec4 previousClip = previousViewProjection * vec4(representativePosition, 1.0);
        vec2 previousUv = previousClip.xy / previousClip.w * 0.5 + 0.5;
        if(previousClip.w > 0.0 && all(greaterThanEqual(previousUv, vec2(0.0)))
            && all(lessThanEqual(previousUv, vec2(1.0))))
        {
            vec4 history = texture(historyTexture, previousUv);
            float responsiveWeight = historyWeight * (1.0 - abs(history.a - accumulated.a));
            accumulated = mix(accumulated, history, clamp(responsiveWeight, 0.0, 0.95));
        }
    }
    fragmentColor = accumulated;
}
```

```
#include "StudioApplication.h"

#include "core/FrameTiming.h"

#include "graphics/Buffer.h"

#include <glm/vec4.hpp>

#include <algorithm>
#include <array>
#include <chrono>
#include <cstdlib>
#include <filesystem>
#include <iomanip>
#include <sstream>
#include <stdexcept>

namespace

    bool calculatePaintPosition(
        const hzl::Camera& camera,
        float viewportU,
        float viewportV,
        hzl::SimulationVector& position)
    {
        const glm::mat4 inverseViewProjection = glm::inverse(
            camera.projectionMatrix() * camera.viewMatrix());
        const glm::vec4 farPoint = inverseViewProjection
            * glm::vec4{viewportU * 2.0F - 1.0F, viewportV * 2.0F - 1.0F, 1.0F, 1.0F};
        const glm::vec3 farWorld = glm::vec3(farPoint) / farPoint.w;
        const glm::vec3 origin = camera.position();
        const glm::vec3 direction = glm::normalize(farWorld - origin);
        const glm::vec3 inverseDirection = 1.0F / direction;
        const glm::vec3 first = (glm::vec3{-1.0F} - origin) * inverseDirection;
        const glm::vec3 second = (glm::vec3{1.0F} - origin) * inverseDirection;
        const glm::vec3 minimum = glm::min(first, second);
        const glm::vec3 maximum = glm::max(first, second);
        const float entry = std::max({minimum.x, minimum.y, minimum.z, 0.0F});
        const float exit = std::min({maximum.x, maximum.y, maximum.z});
        if(exit <= entry)
        {
            return false;
        }

        const glm::vec3 worldPosition = origin + direction * (entry + 0.35F * (exit - entry));
        position = {worldPosition.x, worldPosition.y, worldPosition.z};
        return true;
    }

    void glfwErrorCallback(int errorCode, const char* description)
    {
        hzl::log::error("GLFW error ", errorCode, ": ", description);
    }

    void APIENTRY openGlDebugCallback(
        GLenum,
        GLenum,
        GLuint messageId,
        GLenum severity,
        GLsizei,
        const GLchar* message,
        const void*)
    {
        if(severity == GL_DEBUG_SEVERITY_NOTIFICATION)
        {
            hzl::log::debug("OpenGL message ", messageId, ": ", message);
            return;
        }

        if(severity == GL_DEBUG_SEVERITY_HIGH)
        {
            hzl::log::error("OpenGL message ", messageId, ": ", message);
            return;
        }

        hzl::log::warning("OpenGL message ", messageId, ": ", message);
    }

    void validateGraphicsResources()
    {
        constexpr std::array<float, 9> triangle{
            -1.0F, -1.0F, 0.0F,
             1.0F, -1.0F, 0.0F,
             0.0F,  1.0F, 0.0F};

        hzl::Buffer vertexBuffer;
        vertexBuffer.allocate(sizeof(triangle), triangle.data());

        hzl::VertexArray vertexArray;
        vertexArray.setVertexBuffer(0, vertexBuffer, 0, 3 * sizeof(float));
        vertexArray.setAttribute(0, 0, 3, GL_FLOAT, 0);

        hzl::Texture colorTexture(GL_TEXTURE_2D);
        colorTexture.allocate2D(4, 4, GL_RGBA8);
        colorTexture.setFiltering(GL_LINEAR, GL_LINEAR);
        colorTexture.setWrap(GL_CLAMP_TO_EDGE);

        hzl::Framebuffer framebuffer;
        framebuffer.attachTexture(GL_COLOR_ATTACHMENT0, colorTexture);
        framebuffer.setDrawBuffer(GL_COLOR_ATTACHMENT0);
        framebuffer.requireComplete();

        hzl::Texture volumeTexture(GL_TEXTURE_3D);
        volumeTexture.allocate3D(4, 4, 4, GL_R16F);
        volumeTexture.setFiltering(GL_LINEAR, GL_LINEAR);
        volumeTexture.setWrap(GL_CLAMP_TO_EDGE);

        hzl::log::info("OpenGL resource wrappers validated successfully");
    }
}

hzl::StudioApplication::~StudioApplication()
{
    shutdown();
}

int hzl::StudioApplication::run()
{
    log::info("Starting HZL Fluid Effects Studio");
    initialize();
    mainLoop();
    shutdown();
    log::info("HZL Fluid Effects Studio stopped cleanly");
    return EXIT_SUCCESS;
}

void hzl::StudioApplication::initialize()
{
    glfwSetErrorCallback(glfwErrorCallback);

    if(glfwInit() != GLFW_TRUE)
    {
        throw std::runtime_error("Failed to initialize GLFW");
    }
    m_glfwInitialized = true;

    glfwWindowHint(GLFW_CONTEXT_VERSION_MAJOR, 4);    
    glfwWindowHint(GLFW_CONTEXT_VERSION_MINOR, 6);
    glfwWindowHint(GLFW_OPENGL_PROFILE, GLFW_OPENGL_CORE_PROFILE);
#ifndef NDEBUG
    glfwWindowHint(GLFW_OPENGL_DEBUG_CONTEXT, GLFW_TRUE);
#endif

    m_window = glfwCreateWindow(
        1280, 720, "HZL Fluid Effects Studio", nullptr, nullptr);

    if(m_window == nullptr)
    {
        throw std::runtime_error("Failed to create the GLFW window");
    }

    glfwMakeContextCurrent(m_window);

    const int version = gladLoadGL(glfwGetProcAddress);

    if(version == 0)
    {
        throw std::runtime_error("Failed to load OpenGL functions");
    }

#ifndef NDEBUG
    glEnable(GL_DEBUG_OUTPUT);
    glEnable(GL_DEBUG_OUTPUT_SYNCHRONOUS);
    glDebugMessageCallback(openGlDebugCallback, nullptr);
    glDebugMessageControl(
        GL_DONT_CARE,
        GL_DONT_CARE,
        GL_DEBUG_SEVERITY_NOTIFICATION,
        0,
        nullptr,
        GL_FALSE);
#endif

    log::info(
        "OpenGL ", GLAD_VERSION_MAJOR(version), '.', GLAD_VERSION_MINOR(version));
    log::info("OpenGL vendor: ", reinterpret_cast<const char*>(glGetString(GL_VENDOR)));
    log::info("GPU: ", reinterpret_cast<const char*>(glGetString(GL_RENDERER)));
    log::info(
        "GLSL: ", reinterpret_cast<const char*>(glGetString(GL_SHADING_LANGUAGE_VERSION)));
    m_cudaContext.initializeForOpenGL();
    log::info("Fixed update rate: 60 Hz");
    log::info(
        "Camera: orbit with left/middle mouse; Tab toggles fly mode; F resets view");

    m_input.attach(m_window);
    m_editor.initialize(m_window);
    m_editor.setCudaDeviceInfo(m_cudaContext.deviceInfo());
    validateGraphicsResources();

    const std::filesystem::path shaderDirectory{HZL_SHADER_DIRECTORY};
    m_foundationShader = std::make_unique<ShaderProgram>(
        std::vector<ShaderProgram::Stage>{
            {GL_VERTEX_SHADER, shaderDirectory / "foundation.vert"},
            {GL_FRAGMENT_SHADER, shaderDirectory / "foundation.frag"}});
    m_sceneRenderer.initialize();
    m_simulation.initialize(m_editor.gridResolution());
    m_sceneRenderer.setDensityResolution(m_simulation.resolution());
    m_sceneRenderer.updateSimulationFields(
        m_simulation.densityDevicePointer(),
        m_simulation.temperatureDevicePointer(),
        m_simulation.fireDevicePointer());
    m_editor.setSimulationDiagnostics(
        m_simulation.resolution(),
        m_simulation.allocatedBytes(),
        m_simulation.projectionDiagnostics());
    m_editor.setNumericalTestResults(m_simulation.runNumericalTests());
    log::info("Shader hot reload: F5");
    glfwSwapInterval(1);
}

void hzl::StudioApplication::mainLoop()
{
    using Clock = FrameTiming::Clock;
    FrameTiming timing;

    while(glfwWindowShouldClose(m_window) == GLFW_FALSE)
    {
        const Clock::time_point frameStart = Clock::now();
        timing.beginFrame();
        m_input.beginFrame();
        glfwPollEvents();
        m_editor.beginFrame();

        const Clock::time_point updateStart = Clock::now();
        const int viewportWidth = m_editor.viewportWidth();
        const int viewportHeight = m_editor.viewportHeight();
        if(m_editor.cameraInputEnabled())
        {
            m_cameraController.update(
                m_input, timing.frameDeltaSeconds(), viewportWidth, viewportHeight);
        }

        if(m_input.keyPressed(GLFW_KEY_ESCAPE))
        {
            glfwSetWindowShouldClose(m_window, GLFW_TRUE);
        }

        if(m_input.keyPressed(GLFW_KEY_F5) && m_foundationShader)
        {
            m_foundationShader->reload();
            m_sceneRenderer.reloadShaders();
        }

        std::size_t fixedUpdateCount = 0;
        while(
            timing.shouldRunFixedUpdate()
            && fixedUpdateCount < FrameTiming::maxFixedUpdatesPerFrame)
        {
            fixedUpdate(FrameTiming::fixedStepSeconds);
            timing.consumeFixedUpdate();
            ++fixedUpdateCount;
        }

        if(timing.discardExcessFixedTime())
        {
            log::warning("Fixed-update backlog discarded after a slow frame");
        }
        const Clock::time_point updateEnd = Clock::now();

        const Clock::time_point renderStart = Clock::now();
        render(timing.interpolationAlpha());
        const Clock::time_point renderEnd = Clock::now();

        glfwSwapBuffers(m_window);

        const auto snapshot = timing.endFrame(
            FrameTiming::Duration(Clock::now() - frameStart),
            FrameTiming::Duration(updateEnd - updateStart),
            FrameTiming::Duration(renderEnd - renderStart),
            fixedUpdateCount);

        if(snapshot)
        {
            m_performance = *snapshot;
            log::info(
                "Performance: ", std::fixed, std::setprecision(1),
                snapshot->framesPerSecond, " FPS | frame ",
                snapshot->averageFrameMilliseconds, " ms | update ",
                snapshot->averageUpdateMilliseconds, " ms | render ",
                snapshot->averageRenderMilliseconds, " ms | fixed updates ",
                snapshot->fixedUpdatesPerFrame, "/frame");

            std::ostringstream title;
            title << "HZL Fluid Effects Studio | " << std::fixed
                  << std::setprecision(1) << snapshot->framesPerSecond << " FPS | "
                  << snapshot->averageFrameMilliseconds << " ms";
            glfwSetWindowTitle(m_window, title.str().c_str());
        }
    }
}

void hzl::StudioApplication::fixedUpdate(double fixedDeltaSeconds)
{
    m_editor.advanceTimeline(static_cast<float>(fixedDeltaSeconds));
    const int requestedResolution = m_editor.gridResolution();
    if(requestedResolution != m_simulation.resolution())
    {
        m_simulation.resize(requestedResolution);
        m_sceneRenderer.setDensityResolution(requestedResolution);
        m_editor.setSimulationDiagnostics(
            m_simulation.resolution(),
            m_simulation.allocatedBytes(),
            m_simulation.projectionDiagnostics());
        m_editor.setNumericalTestResults(m_simulation.runNumericalTests());
    }

    m_simulation.setPressureIterations(m_editor.pressureIterations());
    m_simulation.setParameters(m_editor.simulationParameters());
    if(m_editor.paintActive())
    {
        PaintImpulse paint;
        if(calculatePaintPosition(
            m_cameraController.camera(), m_editor.paintU(), m_editor.paintV(), paint.position))
        {
            const glm::vec3 direction = m_cameraController.camera().forward();
            paint.active = true;
            paint.radius = m_editor.paintRadius();
            paint.density = m_editor.paintDensity();
            paint.temperature = m_editor.paintTemperature();
            paint.velocity = {
                direction.x * m_editor.paintVelocityStrength(),
                direction.y * m_editor.paintVelocityStrength(),
                direction.z * m_editor.paintVelocityStrength()};
            m_simulation.setPaintImpulse(paint);
        }
    }
    if(!m_editor.simulationPaused())
    {
        m_simulation.step(
            static_cast<float>(fixedDeltaSeconds) * m_editor.simulationTimeScale());
    }
}

void hzl::StudioApplication::render(double interpolationAlpha)
{
    static_cast<void>(interpolationAlpha);
    m_simulation.prepareVisualization(m_editor.visualizationField());
    m_sceneRenderer.updateSimulationFields(
        m_simulation.visualizationDevicePointer(),
        m_simulation.temperatureDevicePointer(),
        m_simulation.fireDevicePointer());
    m_sceneRenderer.setTemporalAccumulation(
        m_editor.temporalAccumulationEnabled(), m_editor.temporalHistoryWeight());
    m_sceneRenderer.render(
        m_cameraController.camera(),
        m_editor.viewportWidth(),
        m_editor.viewportHeight(),
        m_editor.densityScale(),
        m_editor.rayStepSize(),
        m_editor.maximumRaySteps(),
        m_editor.rayJitterEnabled(),
        m_editor.adaptiveSteppingEnabled(),
        static_cast<int>(m_editor.visualizationField()),
        m_editor.lightDirection(),
        m_editor.lightIntensity(),
        m_editor.volumeAbsorption(),
        m_editor.emissionStrength(),
        m_editor.selfShadowingEnabled());

    m_editor.setGpuTimings(
        m_simulation.lastGpuMilliseconds(), m_sceneRenderer.lastGpuMilliseconds());
    try
    {
        if(m_editor.consumeSnapshotSaveRequest())
        {
            std::filesystem::create_directories("exports");
            m_simulation.saveSnapshot("exports/simulation.hzls");
            m_editor.setExportStatus("Saved exports/simulation.hzls");
        }
        if(m_editor.consumeSnapshotLoadRequest())
        {
            m_simulation.loadSnapshot("exports/simulation.hzls");
            m_sceneRenderer.setDensityResolution(m_simulation.resolution());
            m_editor.setSimulationDiagnostics(
                m_simulation.resolution(), m_simulation.allocatedBytes(),
                m_simulation.projectionDiagnostics());
            m_editor.setExportStatus("Loaded exports/simulation.hzls");
        }
        if(m_editor.consumeMeshLoadRequest())
        {
            m_simulation.loadObstacleMesh("obstacle.obj");
            m_editor.setExportStatus("Voxelized obstacle.obj");
        }
        const int offlineSamples = m_editor.consumeOfflineRenderRequest();
        if(offlineSamples > 0)
        {
            m_sceneRenderer.beginOfflineAccumulation();
            for(int sample = 0; sample < offlineSamples; ++sample)
            {
                m_sceneRenderer.setTemporalAccumulation(
                    true, static_cast<float>(sample) / static_cast<float>(sample + 1));
                m_sceneRenderer.render(
                    m_cameraController.camera(), m_editor.viewportWidth(), m_editor.viewportHeight(),
                    m_editor.densityScale(), m_editor.rayStepSize(), m_editor.maximumRaySteps(),
                    true, m_editor.adaptiveSteppingEnabled(),
                    static_cast<int>(m_editor.visualizationField()), m_editor.lightDirection(),
                    m_editor.lightIntensity(), m_editor.volumeAbsorption(),
                    m_editor.emissionStrength(), m_editor.selfShadowingEnabled());
            }
            m_sceneRenderer.exportFrame("exports/offline_frame.ppm");
            m_editor.setExportStatus("Rendered exports/offline_frame.ppm");
        }
        if(m_editor.consumeFrameExportRequest() || m_editor.frameSequenceExportEnabled())
        {
            std::ostringstream path;
            path << "exports/frame_" << std::setfill('0') << std::setw(6)
                 << m_exportFrameIndex++ << ".ppm";
            m_sceneRenderer.exportFrame(path.str());
            m_editor.setExportStatus("Exported " + path.str());
        }
    }
    catch(const std::exception& exception)
    {
        m_editor.setExportStatus(std::string{"Export error: "} + exception.what());
    }

    int width = 0;
    int height = 0;
    glfwGetFramebufferSize(m_window, &width, &height);
    glViewport(0, 0, width, height);
    glClearColor(0.04f, 0.06f, 0.10f, 1.0f);
    glClear(GL_COLOR_BUFFER_BIT);
    m_editor.draw(
        m_performance, m_cameraController, m_sceneRenderer.colorTextureId());
    m_editor.endFrame();
}

    m_sceneRenderer.shutdown();
    m_simulation.shutdown();
    m_foundationShader.reset();
    m_editor.shutdown();

    if(m_window != nullptr)
    {
        glfwDestroyWindow(m_window);
        m_window = nullptr;
    }

    if(m_glfwInitialized)
    {
        m_cudaContext.shutdown();
        glfwTerminate();
        m_glfwInitialized = false;
    }
}
```

```
#include "FrameTiming.h"

#include <algorithm>
#include <cmath>

namespace
{
    constexpr double maxFrameDeltaSeconds = 0.25;
    constexpr double statisticsIntervalSeconds = 1.0;
    constexpr double millisecondsPerSecond = 1000.0;
}

void hzl::FrameTiming::beginFrame()
{
    const Clock::time_point now = Clock::now();

    if(!m_started)
    {
        m_previousFrameTime = now;
        m_started = true;
        m_frameDeltaSeconds = 0.0;
        return;
    }

    const double elapsedSeconds = Duration(now - m_previousFrameTime).count();
    m_previousFrameTime = now;
    m_frameDeltaSeconds = std::min(elapsedSeconds, maxFrameDeltaSeconds);
    m_accumulatorSeconds += m_frameDeltaSeconds;
}

bool hzl::FrameTiming::shouldRunFixedUpdate() const
{
    return m_accumulatorSeconds >= fixedStepSeconds;
}

void hzl::FrameTiming::consumeFixedUpdate()
{
    m_accumulatorSeconds -= fixedStepSeconds;
}

bool hzl::FrameTiming::discardExcessFixedTime()
{
    if(m_accumulatorSeconds < fixedStepSeconds)
    {
        return false;
    }

    m_accumulatorSeconds = std::fmod(m_accumulatorSeconds, fixedStepSeconds);
    return true;
}

double hzl::FrameTiming::frameDeltaSeconds() const
{
    return m_frameDeltaSeconds;
}

double hzl::FrameTiming::interpolationAlpha() const
{
    return m_accumulatorSeconds / fixedStepSeconds;
}

std::optional<hzl::PerformanceSnapshot> hzl::FrameTiming::endFrame(
    Duration frameDuration,
    Duration updateDuration,
    Duration renderDuration,
    std::size_t fixedUpdateCount)
{
    const double frameSeconds = frameDuration.count();
    m_statisticsSeconds += frameSeconds;
    m_totalFrameSeconds += frameSeconds;
    m_totalUpdateSeconds += updateDuration.count();
    m_totalRenderSeconds += renderDuration.count();
    ++m_frameCount;
    m_fixedUpdateCount += fixedUpdateCount;

    if(m_statisticsSeconds < statisticsIntervalSeconds)
    {
        return std::nullopt;
    }

    const double frameCount = static_cast<double>(m_frameCount);
    PerformanceSnapshot snapshot;
    snapshot.framesPerSecond = frameCount / m_totalFrameSeconds;
    snapshot.averageFrameMilliseconds =
        millisecondsPerSecond * m_totalFrameSeconds / frameCount;
    snapshot.averageUpdateMilliseconds =
        millisecondsPerSecond * m_totalUpdateSeconds / frameCount;
    snapshot.averageRenderMilliseconds =
        millisecondsPerSecond * m_totalRenderSeconds / frameCount;
    snapshot.fixedUpdatesPerFrame =
        static_cast<double>(m_fixedUpdateCount) / frameCount;

    m_statisticsSeconds = 0.0;
    m_totalFrameSeconds = 0.0;
    m_totalUpdateSeconds = 0.0;
    m_totalRenderSeconds = 0.0;
    m_frameCount = 0;
    m_fixedUpdateCount = 0;

    return snapshot;
}
```

```
        case hzl::log::Level::info: return "INFO";
        case hzl::log::Level::warning: return "WARN";

void hzl::log::detail::writeMessage(Level level, std::string_view message)
{
    const auto now = std::chrono::system_clock::now();
    const std::time_t time = std::chrono::system_clock::to_time_t(now);
    std::tm localTime{};

#ifdef _WIN32
    localtime_s(&localTime, &time);
#else
    localtime_r(&time, &localTime);
#endif

    std::lock_guard<std::mutex> lock(logMutex);
    std::ostream& output = level >= Level::error ? std::cerr : std::cout;
    output << '[' << std::put_time(&localTime, "%H:%M:%S") << "] ["
           << levelName(level) << "] " << message << std::endl;
}
```

```
void hzl::CudaContext::initializeForOpenGL()
{
    int deviceCount = 0;
    requireCuda(cudaGetDeviceCount(&deviceCount), "Failed to enumerate CUDA devices");
    if(deviceCount == 0)
    {
        throw std::runtime_error("No CUDA-capable GPU was found");
    }

    std::array<int, 8> interoperableDevices{};
    unsigned int interoperableCount = 0;
    requireCuda(
        cudaGLGetDevices(
            &interoperableCount,
            interoperableDevices.data(),
            static_cast<unsigned int>(interoperableDevices.size()),
            cudaGLDeviceListAll),
        "Failed to match CUDA devices to the OpenGL context");
    if(interoperableCount == 0)
    {
        throw std::runtime_error("The active OpenGL GPU does not support CUDA interoperability");
    }

    const int device = interoperableDevices[0];
    requireCuda(cudaSetDevice(device), "Failed to select the CUDA/OpenGL device");
    requireCuda(cudaFree(nullptr), "Failed to initialize the CUDA runtime");

    cudaDeviceProp properties{};
    requireCuda(cudaGetDeviceProperties(&properties, device), "Failed to query CUDA properties");

    std::size_t freeMemory = 0;
    std::size_t totalMemory = 0;
    requireCuda(cudaMemGetInfo(&freeMemory, &totalMemory), "Failed to query CUDA memory");

    int driverVersion = 0;
    int runtimeVersion = 0;
    requireCuda(cudaDriverGetVersion(&driverVersion), "Failed to query CUDA driver version");
    requireCuda(cudaRuntimeGetVersion(&runtimeVersion), "Failed to query CUDA runtime version");

    m_deviceInfo.name = properties.name;
    m_deviceInfo.deviceIndex = device;
    m_deviceInfo.computeMajor = properties.major;
    m_deviceInfo.computeMinor = properties.minor;
    m_deviceInfo.multiprocessorCount = properties.multiProcessorCount;
    m_deviceInfo.driverVersion = driverVersion;
    m_deviceInfo.runtimeVersion = runtimeVersion;
    m_deviceInfo.totalMemoryBytes = totalMemory;
    m_deviceInfo.freeMemoryBytes = freeMemory;
    m_initialized = true;

    constexpr double bytesPerGibibyte = 1024.0 * 1024.0 * 1024.0;
    log::info(
        "CUDA device ", device, ": ", properties.name,
        " | compute ", properties.major, '.', properties.minor,
        " | ", properties.multiProcessorCount, " SMs");
    log::info(
        "CUDA driver/runtime: ", versionString(driverVersion), '/',
        versionString(runtimeVersion), " | VRAM free ",
        static_cast<double>(freeMemory) / bytesPerGibibyte, " GiB / ",
        static_cast<double>(totalMemory) / bytesPerGibibyte, " GiB");
}
```

### src/cuda/CudaGlTexture3D.cu
```
#include "CudaGlTexture3D.h"

#include <cuda_gl_interop.h>
#include <cuda_runtime.h>

#include <GL/gl.h>

#include <stdexcept>
#include <string>

namespace
{
    void requireCuda(cudaError_t result, const char* operation)
    {
        if(result != cudaSuccess)
        {
            throw std::runtime_error(
                std::string(operation) + ": " + cudaGetErrorString(result));
        }
    }

    __device__ float saturate(float value)
    {
        return fminf(fmaxf(value, 0.0F), 1.0F);
    }

    __global__ void generateDensity(
        cudaSurfaceObject_t surface, int width, int height, int depth)
    {
        const int x = static_cast<int>(blockIdx.x * blockDim.x + threadIdx.x);
        const int y = static_cast<int>(blockIdx.y * blockDim.y + threadIdx.y);
        const int z = static_cast<int>(blockIdx.z * blockDim.z + threadIdx.z);
        if(x >= width || y >= height || z >= depth)
        {
            return;
        }

        const float px = 2.0F * static_cast<float>(x) / static_cast<float>(width - 1) - 1.0F;
        const float py = 2.0F * static_cast<float>(y) / static_cast<float>(height - 1) - 1.0F;
        const float pz = 2.0F * static_cast<float>(z) / static_cast<float>(depth - 1) - 1.0F;
        const float lowerCloud = expf(
            -4.5F * (px * px + pz * pz) - 2.2F * (py + 0.25F) * (py + 0.25F));
        const float upperX = px - 0.18F * sinf(4.0F * py);
        const float upperZ = pz - 0.12F * cosf(5.0F * py);
        const float upperCloud = expf(
            -8.0F * (upperX * upperX + upperZ * upperZ)
            - 3.5F * (py - 0.35F) * (py - 0.35F));
        const float detail = 0.68F + 0.20F * sinf(11.0F * px + 7.0F * py)
            * sinf(9.0F * pz - 5.0F * py)
            + 0.12F * sinf(23.0F * (px + pz));
        const float maximumCoordinate = fmaxf(fabsf(px), fmaxf(fabsf(py), fabsf(pz)));
        const float boundaryFade = saturate((1.0F - maximumCoordinate) * 8.0F);
        const float density = saturate(
            (0.85F * lowerCloud + 0.75F * upperCloud - 0.18F)
            * detail * boundaryFade);
        surf3Dwrite(density, surface, x * static_cast<int>(sizeof(float)), y, z);
    }
}

hzl::CudaGlTexture3D::~CudaGlTexture3D()
{
    unregister();
}

void hzl::CudaGlTexture3D::registerTexture(
    unsigned int textureId, int width, int height, int depth)
{
    unregister();
    requireCuda(
        cudaGraphicsGLRegisterImage(
            &m_resource,
            textureId,
            GL_TEXTURE_3D,
            cudaGraphicsRegisterFlagsSurfaceLoadStore),
        "Failed to register the OpenGL 3D texture with CUDA");
    m_width = width;
    m_height = height;
    m_depth = depth;
}

float hzl::CudaGlTexture3D::writeProceduralDensity()
{
    if(m_resource == nullptr)
    {
        throw std::logic_error("CUDA/OpenGL texture is not registered");
    }

    requireCuda(cudaGraphicsMapResources(1, &m_resource), "Failed to map CUDA/OpenGL texture");
    cudaArray_t array = nullptr;
    cudaError_t result = cudaGraphicsSubResourceGetMappedArray(&array, m_resource, 0, 0);

    cudaSurfaceObject_t surface = 0;
    if(result == cudaSuccess)
    {
        cudaResourceDesc description{};
        description.resType = cudaResourceTypeArray;
        description.res.array.array = array;
        result = cudaCreateSurfaceObject(&surface, &description);
    }

    if(result == cudaSuccess)
    {
        const dim3 threads{8, 8, 8};
        const dim3 blocks{
            static_cast<unsigned int>((m_width + 7) / 8),
            static_cast<unsigned int>((m_height + 7) / 8),
            static_cast<unsigned int>((m_depth + 7) / 8)};
        generateDensity<<<blocks, threads>>>(surface, m_width, m_height, m_depth);
        result = cudaGetLastError();
    }
    if(result == cudaSuccess)
    {
        result = cudaDeviceSynchronize();
    }

    float centerDensity = 0.0F;
    if(result == cudaSuccess)
    {
        cudaMemcpy3DParms copy{};
        copy.srcArray = array;
        copy.srcPos = make_cudaPos(
            static_cast<std::size_t>(m_width / 2),
            static_cast<std::size_t>(m_height / 2),
            static_cast<std::size_t>(m_depth / 2));
        copy.dstPtr = make_cudaPitchedPtr(&centerDensity, sizeof(float), 1, 1);
        copy.extent = make_cudaExtent(1, 1, 1);
        copy.kind = cudaMemcpyDeviceToHost;
        result = cudaMemcpy3D(&copy);
    }

    if(surface != 0)
    {
        cudaDestroySurfaceObject(surface);
    }
    const cudaError_t unmapResult = cudaGraphicsUnmapResources(1, &m_resource);
    requireCuda(result, "CUDA kernel failed while writing the shared 3D texture");
    requireCuda(unmapResult, "Failed to unmap CUDA/OpenGL texture");
    return centerDensity;
}

void hzl::CudaGlTexture3D::copyFromDevice(const void* sourceDevicePointer)
{
    if(m_resource == nullptr || sourceDevicePointer == nullptr)
    {
        throw std::logic_error("CUDA/OpenGL copy requires registered and source resources");
    }

    requireCuda(cudaGraphicsMapResources(1, &m_resource), "Failed to map CUDA/OpenGL texture");
    cudaArray_t array = nullptr;
    cudaError_t result = cudaGraphicsSubResourceGetMappedArray(&array, m_resource, 0, 0);
    if(result == cudaSuccess)
    {
        cudaMemcpy3DParms copy{};
        copy.srcPtr = make_cudaPitchedPtr(
            const_cast<void*>(sourceDevicePointer),
            static_cast<std::size_t>(m_width) * sizeof(float),
            static_cast<std::size_t>(m_width),
            static_cast<std::size_t>(m_height));
        copy.dstArray = array;
        copy.extent = make_cudaExtent(
            static_cast<std::size_t>(m_width),
            static_cast<std::size_t>(m_height),
            static_cast<std::size_t>(m_depth));
        copy.kind = cudaMemcpyDeviceToDevice;
        result = cudaMemcpy3D(&copy);
    }
    const cudaError_t unmapResult = cudaGraphicsUnmapResources(1, &m_resource);
    requireCuda(result, "Failed to copy simulated density into the OpenGL texture");
    requireCuda(unmapResult, "Failed to unmap CUDA/OpenGL texture");
}

void hzl::CudaGlTexture3D::unregister() noexcept
{
    if(m_resource != nullptr)
    {
        cudaGraphicsUnregisterResource(m_resource);
        m_resource = nullptr;
    }
    m_width = 0;
    m_height = 0;
    m_depth = 0;
}

bool hzl::CudaGlTexture3D::registered() const
{
    return m_resource != nullptr;
}
```

```
    io.ConfigFlags |= ImGuiConfigFlags_NavEnableKeyboard;
    io.ConfigFlags |= ImGuiConfigFlags_DockingEnable;

    ImGui::StyleColorsDark();
    ImGuiStyle& style = ImGui::GetStyle();
    style.WindowRounding = 3.0F;
    style.FrameRounding = 3.0F;

    if(!ImGui_ImplGlfw_InitForOpenGL(window, true))
    {
        ImGui::DestroyContext();
        throw std::runtime_error("Failed to initialize Dear ImGui GLFW backend");
    }

    if(!ImGui_ImplOpenGL3_Init("#version 460 core"))
    {
        ImGui_ImplGlfw_Shutdown();
        ImGui::DestroyContext();
        throw std::runtime_error("Failed to initialize Dear ImGui OpenGL backend");
    }

    m_window = window;
    m_initialized = true;
    log::info("Dear ImGui initialized with docking enabled");
}

void hzl::Editor::beginFrame()
{
    ImGui_ImplOpenGL3_NewFrame();
    ImGui_ImplGlfw_NewFrame();
    ImGui::NewFrame();
}

void hzl::Editor::draw(
    const PerformanceSnapshot& performance,
    const CameraController& camera,
    unsigned int viewportTexture)
{
    drawDockSpace();

    if(m_showViewport)
    {
        drawViewport(camera, viewportTexture);
    }
    else
    {
        m_viewportHovered = false;
        m_paintActive = false;
    }
    if(m_showHierarchy)
    {
        drawSceneHierarchy();
    }
    if(m_showSimulation)
    {
        drawSimulationControls();
    }
    if(m_showRenderer)
    {
        drawRendererSettings();
    }
    if(m_showDiagnostics)
    {
        drawDiagnostics(performance, camera);
    }
    drawTimeline();
}

{

    ImGui_ImplOpenGL3_RenderDrawData(ImGui::GetDrawData());
}

{
    if(!m_timelinePlaying)
    {
        return;
    }

    {
        m_timelineTime = m_timelineLooping ? 0.0F : m_timelineDuration;
        m_timelinePlaying = m_timelineLooping;
    }
    evaluateTimeline();
}

void hzl::Editor::drawDockSpace()
{
    ImGuiViewport* viewport = ImGui::GetMainViewport();
    ImGui::SetNextWindowPos(viewport->WorkPos);
    ImGui::SetNextWindowSize(viewport->WorkSize);
    ImGui::SetNextWindowViewport(viewport->ID);

    constexpr ImGuiWindowFlags hostFlags =
        ImGuiWindowFlags_MenuBar
        | ImGuiWindowFlags_NoDocking
        | ImGuiWindowFlags_NoTitleBar
        | ImGuiWindowFlags_NoCollapse
        | ImGuiWindowFlags_NoResize
        | ImGuiWindowFlags_NoMove
        | ImGuiWindowFlags_NoBringToFrontOnFocus
        | ImGuiWindowFlags_NoNavFocus;

    ImGui::PushStyleVar(ImGuiStyleVar_WindowRounding, 0.0F);
    ImGui::PushStyleVar(ImGuiStyleVar_WindowBorderSize, 0.0F);
    ImGui::PushStyleVar(ImGuiStyleVar_WindowPadding, ImVec2{0.0F, 0.0F});
    ImGui::Begin("HZLStudioDockSpace", nullptr, hostFlags);
    ImGui::PopStyleVar(3);

    if(ImGui::BeginMenuBar())
    {
        if(ImGui::BeginMenu("File"))
        {
            if(ImGui::MenuItem("Exit", "Esc"))
            {
                glfwSetWindowShouldClose(m_window, GLFW_TRUE);
            }
            ImGui::EndMenu();
        }

        if(ImGui::BeginMenu("View"))
        {
            ImGui::MenuItem("Viewport", nullptr, &m_showViewport);
            ImGui::MenuItem("Scene Hierarchy", nullptr, &m_showHierarchy);
            ImGui::MenuItem("Simulation", nullptr, &m_showSimulation);
            ImGui::MenuItem("Renderer", nullptr, &m_showRenderer);
            ImGui::MenuItem("Diagnostics", nullptr, &m_showDiagnostics);
            ImGui::EndMenu();
        }
        ImGui::EndMenuBar();
    }

    const ImGuiID dockSpaceId = ImGui::GetID("HZLStudioMainDockSpace");
    ImGui::DockSpace(dockSpaceId, ImVec2{0.0F, 0.0F});
    if(!m_defaultLayoutCreated)
    {
        createDefaultDockLayout(dockSpaceId);
        m_defaultLayoutCreated = true;
    }

    ImGui::End();
}

void hzl::Editor::createDefaultDockLayout(unsigned int dockSpaceId)
{
    ImGui::DockBuilderRemoveNode(dockSpaceId);
    ImGui::DockBuilderAddNode(dockSpaceId, ImGuiDockNodeFlags_DockSpace);
    ImGui::DockBuilderSetNodeSize(dockSpaceId, ImGui::GetMainViewport()->WorkSize);

    ImGuiID center = dockSpaceId;
    const ImGuiID left = ImGui::DockBuilderSplitNode(
        center, ImGuiDir_Left, 0.20F, nullptr, &center);
    const ImGuiID right = ImGui::DockBuilderSplitNode(
        center, ImGuiDir_Right, 0.25F, nullptr, &center);
    const ImGuiID bottom = ImGui::DockBuilderSplitNode(
        center, ImGuiDir_Down, 0.24F, nullptr, &center);

    ImGui::DockBuilderDockWindow("Viewport", center);
    ImGui::DockBuilderDockWindow("Scene Hierarchy", left);
    ImGui::DockBuilderDockWindow("Simulation", right);
    ImGui::DockBuilderDockWindow("Renderer", right);
    ImGui::DockBuilderDockWindow("Diagnostics", bottom);
    ImGui::DockBuilderFinish(dockSpaceId);
}

void hzl::Editor::drawViewport(
    const CameraController& camera, unsigned int viewportTexture)
{
    ImGui::Begin("Viewport", &m_showViewport);

    const ImVec2 available = ImGui::GetContentRegionAvail();
    if(available.x <= 0.0F || available.y <= 0.0F)
    {
        ImGui::End();
        return;
    }

    const ImGuiIO& io = ImGui::GetIO();
    m_viewportWidth = std::max(
        1, static_cast<int>(available.x * io.DisplayFramebufferScale.x));
    m_viewportHeight = std::max(
        1, static_cast<int>(available.y * io.DisplayFramebufferScale.y));

    ImGui::Image(
        static_cast<ImTextureID>(static_cast<intptr_t>(viewportTexture)),
        available,
        ImVec2{0.0F, 1.0F},
        ImVec2{1.0F, 0.0F});
    m_viewportHovered = ImGui::IsItemHovered();
    const ImVec2 minimum = ImGui::GetItemRectMin();
    if(m_viewportHovered && io.KeyCtrl && ImGui::IsMouseDown(ImGuiMouseButton_Left))
    {
        const ImVec2 mouse = ImGui::GetMousePos();
        m_paintU = std::clamp((mouse.x - minimum.x) / available.x, 0.0F, 1.0F);
        m_paintV = 1.0F - std::clamp((mouse.y - minimum.y) / available.y, 0.0F, 1.0F);
        m_paintActive = true;
    }
    else
    {
        m_paintActive = false;
    }
    ImGui::GetWindowDrawList()->AddText(
        ImVec2{minimum.x + 16.0F, minimum.y + 16.0F},
        IM_COL32(175, 190, 210, 255),
        camera.mode() == CameraMode::orbit ? "Camera: Orbit" : "Camera: Fly");
    ImGui::End();
}

void hzl::Editor::drawTimeline()
{
    ImGui::Begin("Timeline");
    if(ImGui::Button(m_timelinePlaying ? "Pause" : "Play"))
    {
        m_timelinePlaying = !m_timelinePlaying;
    }
    ImGui::SameLine();
    if(ImGui::Button("Stop"))
    {
        m_timelinePlaying = false;
        m_timelineTime = 0.0F;
        evaluateTimeline();
    }
    ImGui::SameLine();
    ImGui::Checkbox("Loop", &m_timelineLooping);
    if(ImGui::SliderFloat("Time", &m_timelineTime, 0.0F, m_timelineDuration, "%.2f s"))
    {
        evaluateTimeline();
    }
    ImGui::SliderFloat("Duration", &m_timelineDuration, 1.0F, 120.0F, "%.1f s");
    if(ImGui::Button("Add parameter keyframe"))
    {
        m_keyframes.push_back({m_timelineTime, m_simulationParameters});
        std::sort(m_keyframes.begin(), m_keyframes.end(),
            [](const ParameterKeyframe& a, const ParameterKeyframe& b) { return a.time < b.time; });
    }
    ImGui::SameLine();
    if(ImGui::Button("Clear keyframes"))
    {
        m_keyframes.clear();
    }
    ImGui::Text("Keyframes: %zu", m_keyframes.size());
    ImGui::SeparatorText("Project");
    if(ImGui::Button("Save fluid_project.json"))
    {
        saveProject("fluid_project.json");
    }
    ImGui::SameLine();
    if(ImGui::Button("Load fluid_project.json"))
    {
        loadProject("fluid_project.json");
    }
    if(!m_projectStatus.empty())
    {
        ImGui::TextWrapped("%s", m_projectStatus.c_str());
    }
    ImGui::End();
}

void hzl::Editor::evaluateTimeline()
{
    if(m_keyframes.empty())
    {
        return;
    }
    const auto upper = std::lower_bound(m_keyframes.begin(), m_keyframes.end(), m_timelineTime,
        [](const ParameterKeyframe& key, float time) { return key.time < time; });
    if(upper == m_keyframes.begin() || upper == m_keyframes.end())
    {
        m_simulationParameters = (upper == m_keyframes.begin() ? upper : std::prev(upper))->parameters;
        return;
    }
    const auto lower = std::prev(upper);
    const float alpha = (m_timelineTime - lower->time) / (upper->time - lower->time);
    auto blend = [alpha](float a, float b) { return a + (b - a) * alpha; };
    m_simulationParameters = lower->parameters;
    m_simulationParameters.emitterPosition.x = blend(lower->parameters.emitterPosition.x, upper->parameters.emitterPosition.x);
    m_simulationParameters.emitterPosition.y = blend(lower->parameters.emitterPosition.y, upper->parameters.emitterPosition.y);
    m_simulationParameters.emitterPosition.z = blend(lower->parameters.emitterPosition.z, upper->parameters.emitterPosition.z);
    m_simulationParameters.emitterRadius = blend(lower->parameters.emitterRadius, upper->parameters.emitterRadius);
    m_simulationParameters.densityEmissionRate = blend(lower->parameters.densityEmissionRate, upper->parameters.densityEmissionRate);
    m_simulationParameters.temperatureEmissionRate = blend(lower->parameters.temperatureEmissionRate, upper->parameters.temperatureEmissionRate);
    m_simulationParameters.fuelEmissionRate = blend(lower->parameters.fuelEmissionRate, upper->parameters.fuelEmissionRate);

void hzl::Editor::saveProject(const std::string& path)
{
    std::ofstream file(path);
    if(!file)
    {
        m_projectStatus = "Could not save " + path;
        return;
    }
    file << std::setprecision(9) << "{\n  \"version\": 1,\n"
         << "  \"gridResolution\": " << m_gridResolution << ",\n"
         << "  \"densityScale\": " << m_densityScale << ",\n"
         << "  \"stepSize\": " << m_stepSize << ",\n"
         << "  \"timelineDuration\": " << m_timelineDuration << ",\n"
         << "  \"emitterRadius\": " << m_simulationParameters.emitterRadius << ",\n"

         << "  \"temperatureEmissionRate\": " << m_simulationParameters.temperatureEmissionRate << ",\n"
         << "  \"fuelEmissionRate\": " << m_simulationParameters.fuelEmissionRate << ",\n"
         << "  \"buoyancyStrength\": " << m_simulationParameters.buoyancyStrength << ",\n"
         << "  \"vorticityStrength\": " << m_simulationParameters.vorticityStrength << ",\n"
         << "  \"keyframes\": [";
    for(std::size_t i = 0; i < m_keyframes.size(); ++i)
    {
        const auto& key = m_keyframes[i];
        file << (i == 0 ? "\n" : ",\n") << "    {\"time\": " << key.time
             << ", \"density\": " << key.parameters.densityEmissionRate
             << ", \"temperature\": " << key.parameters.temperatureEmissionRate
             << ", \"fuel\": " << key.parameters.fuelEmissionRate << "}";
    }
    file << "\n  ]\n}\n";
    m_projectStatus = "Saved " + path;
}

void hzl::Editor::loadProject(const std::string& path)
{
    std::ifstream file(path);
    if(!file)
    {
        m_projectStatus = "Could not open " + path;
        return;
    }
    const std::string json{std::istreambuf_iterator<char>(file), {}};
    auto number = [&json](const char* name, float& value)
    {
        const std::string key = std::string{"\""} + name + "\"";
        const std::size_t start = json.find(key);
        if(start == std::string::npos) return;
        const std::size_t colon = json.find(':', start + key.size());
        if(colon == std::string::npos) return;
        std::istringstream stream(json.substr(colon + 1));
        stream >> value;
    };
    float resolution = static_cast<float>(m_gridResolution);
    number("gridResolution", resolution);
    m_gridResolution = std::clamp(static_cast<int>(resolution), 32, 256);
    number("densityScale", m_densityScale);
    number("stepSize", m_stepSize);
    number("timelineDuration", m_timelineDuration);
    number("emitterRadius", m_simulationParameters.emitterRadius);
    number("densityEmissionRate", m_simulationParameters.densityEmissionRate);
    number("temperatureEmissionRate", m_simulationParameters.temperatureEmissionRate);
    number("fuelEmissionRate", m_simulationParameters.fuelEmissionRate);
    number("buoyancyStrength", m_simulationParameters.buoyancyStrength);
    number("vorticityStrength", m_simulationParameters.vorticityStrength);
    m_projectStatus = "Loaded " + path;
}
```

```
      m_sizeBytes(std::exchange(other.m_sizeBytes, 0))
{

hzl::Buffer& hzl::Buffer::operator=(Buffer&& other) noexcept
{
    if(this != &other)
    {
        release();
        m_id = std::exchange(other.m_id, 0);
        m_sizeBytes = std::exchange(other.m_sizeBytes, 0);
    }
    return *this;
}

void hzl::Buffer::allocate(
    std::size_t sizeBytes, const void* data, GLbitfield storageFlags)
{
    if(sizeBytes == 0)
    {
        throw std::invalid_argument("Buffer allocation size must be greater than zero");
    }
    if(m_sizeBytes != 0)
    {
        throw std::logic_error("Immutable buffer storage has already been allocated");
    }

    glNamedBufferStorage(
        m_id, static_cast<GLsizeiptr>(sizeBytes), data, storageFlags);
    m_sizeBytes = sizeBytes;
}

void hzl::Buffer::upload(
    std::size_t offsetBytes, std::size_t sizeBytes, const void* data)
{
    if(
        data == nullptr
        || offsetBytes > m_sizeBytes
        || sizeBytes > m_sizeBytes - offsetBytes)
    {
        throw std::out_of_range("Buffer upload is null or exceeds allocated storage");
    }

    glNamedBufferSubData(
        m_id,
        static_cast<GLintptr>(offsetBytes),
        static_cast<GLsizeiptr>(sizeBytes),
        data);
}

void hzl::Buffer::bindBase(GLenum target, GLuint bindingPoint) const
{
    glBindBufferBase(target, bindingPoint, m_id);
}

GLuint hzl::Buffer::id() const
{
    return m_id;
}

std::size_t hzl::Buffer::sizeBytes() const
{
    return m_sizeBytes;
}

void hzl::Buffer::release() noexcept
{
    if(m_id != 0)
    {
        glDeleteBuffers(1, &m_id);
        m_id = 0;
        m_sizeBytes = 0;
    }
}
```

```
void hzl::SceneRenderer::setDensityResolution(int resolution)
{
    if(resolution == m_densityResolution)
    {
        return;
    }
    if(m_densityInterop)
    {
        m_densityInterop->unregister();
    }
    if(m_temperatureInterop)
    {
        m_temperatureInterop->unregister();
    }
    if(m_fireInterop)
    {
        m_fireInterop->unregister();
    }
    m_densityInterop.reset();
    m_temperatureInterop.reset();
    m_fireInterop.reset();
    m_densityTexture.reset();
    m_temperatureTexture.reset();
    m_fireTexture.reset();

    m_densityResolution = resolution;
    createProceduralDensity();
}

void hzl::SceneRenderer::updateSimulationFields(
    const void* visualizationDevicePointer,
    const void* temperatureDevicePointer,
    const void* fireDevicePointer)
{
    if(!m_densityInterop || !m_temperatureInterop || !m_fireInterop)
    {
        throw std::logic_error("Density interoperability resource is not initialized");
    }
    m_densityInterop->copyFromDevice(visualizationDevicePointer);
    m_temperatureInterop->copyFromDevice(temperatureDevicePointer);
    m_fireInterop->copyFromDevice(fireDevicePointer);
}

void hzl::SceneRenderer::render(
    const Camera& camera,
    int width,
    int height,
    float densityScale,
    float stepSize,
    int maximumSteps,
    bool jitterEnabled,
    bool adaptiveSteppingEnabled,
    int fieldMode,
    const float* lightDirection,
    float lightIntensity,
    float absorption,
    float emissionStrength,
    bool selfShadowingEnabled)
{
    width = std::max(width, 1);
    height = std::max(height, 1);
    if(width != m_width || height != m_height)
    {
        resize(width, height);
    }

    if(m_gpuQueryIssued)
    {
        const int previous = 1 - m_gpuQueryIndex;
        GLint available = GL_FALSE;
        glGetQueryObjectiv(m_gpuQueries[previous], GL_QUERY_RESULT_AVAILABLE, &available);
        if(available == GL_TRUE)
        {
            GLuint64 nanoseconds = 0;
            glGetQueryObjectui64v(m_gpuQueries[previous], GL_QUERY_RESULT, &nanoseconds);
            m_lastGpuMilliseconds = static_cast<float>(nanoseconds) / 1000000.0F;
        }
    }
    glBeginQuery(GL_TIME_ELAPSED, m_gpuQueries[m_gpuQueryIndex]);
    m_framebuffer->bind();
    glViewport(0, 0, m_width, m_height);
    glEnable(GL_DEPTH_TEST);
    glDepthFunc(GL_LESS);
    glClearColor(0.025F, 0.035F, 0.055F, 1.0F);
    glClear(GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT);

    m_debugShader->bind();
    m_debugShader->setMat4(
        "viewProjection", camera.projectionMatrix() * camera.viewMatrix());
    m_debugVertexArray->bind();
    glDrawArrays(GL_LINES, 0, m_debugVertexCount);

    glCopyImageSubData(
        m_depthTexture->id(), GL_TEXTURE_2D, 0, 0, 0, 0,
        m_sceneDepthTexture->id(), GL_TEXTURE_2D, 0, 0, 0, 0,
        m_width, m_height, 1);

    glDisable(GL_DEPTH_TEST);
    glEnable(GL_BLEND);
    glBlendFunc(GL_ONE, GL_ONE_MINUS_SRC_ALPHA);
    m_volumeShader->bind();
    m_volumeShader->setMat4(
        "inverseViewProjection",
        glm::inverse(camera.projectionMatrix() * camera.viewMatrix()));
    m_volumeShader->setVec3("cameraPosition", camera.position());
    m_volumeShader->setInt("densityTexture", 0);
    m_volumeShader->setInt("sceneDepthTexture", 1);
    m_volumeShader->setInt("temperatureTexture", 2);
    m_volumeShader->setInt("fireTexture", 3);
    m_volumeShader->setInt("historyTexture", 4);
    m_volumeShader->setFloat("densityScale", densityScale);
    m_volumeShader->setFloat("stepSize", stepSize);
    m_volumeShader->setInt("maximumSteps", maximumSteps);
    m_volumeShader->setInt("frameIndex", static_cast<int>(m_frameIndex++));
    m_volumeShader->setInt("jitterEnabled", jitterEnabled ? 1 : 0);
    m_volumeShader->setInt(
        "adaptiveSteppingEnabled", adaptiveSteppingEnabled ? 1 : 0);
    m_volumeShader->setInt("fieldMode", fieldMode);
    m_volumeShader->setVec3(
        "lightDirection",
        glm::vec3{lightDirection[0], lightDirection[1], lightDirection[2]});
    m_volumeShader->setFloat("lightIntensity", lightIntensity);
    m_volumeShader->setFloat("absorption", absorption);
    m_volumeShader->setFloat("emissionStrength", emissionStrength);
    m_volumeShader->setInt("selfShadowingEnabled", selfShadowingEnabled ? 1 : 0);
    m_volumeShader->setInt("temporalEnabled", m_temporalEnabled && m_historyValid ? 1 : 0);
    m_volumeShader->setFloat("historyWeight", m_historyWeight);
    m_volumeShader->setMat4("previousViewProjection", m_previousViewProjection);
    m_densityTexture->bindUnit(0);
    m_sceneDepthTexture->bindUnit(1);

    m_historyTexture->bindUnit(4);
    m_fullscreenVertexArray->bind();
    glDrawArrays(GL_TRIANGLES, 0, 3);
    glCopyImageSubData(
        m_colorTexture->id(), GL_TEXTURE_2D, 0, 0, 0, 0,
        m_historyTexture->id(), GL_TEXTURE_2D, 0, 0, 0, 0,
        m_width, m_height, 1);
    m_historyValid = true;
    m_previousViewProjection = camera.projectionMatrix() * camera.viewMatrix();
    glDisable(GL_BLEND);
    glEndQuery(GL_TIME_ELAPSED);
    m_gpuQueryIssued = true;
    m_gpuQueryIndex = 1 - m_gpuQueryIndex;

    glBindVertexArray(0);
    glUseProgram(0);
    Framebuffer::bindDefault();
}

void hzl::SceneRenderer::exportFrame(const std::string& path) const
{
    if(!m_colorTexture) return;
    std::filesystem::path destination{path};
    if(destination.has_parent_path()) std::filesystem::create_directories(destination.parent_path());
    std::vector<unsigned char> rgba(static_cast<std::size_t>(m_width) * m_height * 4);
    glGetTextureImage(m_colorTexture->id(), 0, GL_RGBA, GL_UNSIGNED_BYTE,
        static_cast<GLsizei>(rgba.size()), rgba.data());
    std::ofstream file(destination, std::ios::binary);
    if(!file) throw std::runtime_error("Failed to export frame: " + path);
    file << "P6\n" << m_width << ' ' << m_height << "\n255\n";
    for(int y = m_height - 1; y >= 0; --y)
    {
        for(int x = 0; x < m_width; ++x)
        {
            const std::size_t index = 4 * (static_cast<std::size_t>(y) * m_width + x);
            file.write(reinterpret_cast<const char*>(rgba.data() + index), 3);
        }
    }
}

void hzl::SceneRenderer::shutdown() noexcept
{
    if(m_gpuQueries[0] != 0)
    {
        glDeleteQueries(2, m_gpuQueries);
        m_gpuQueries[0] = m_gpuQueries[1] = 0;
    }
    m_debugShader.reset();
    m_volumeShader.reset();
    if(m_densityInterop)
    {
        m_densityInterop->unregister();
    }
    if(m_temperatureInterop)
    {
        m_temperatureInterop->unregister();
    }
    if(m_fireInterop)
    {
        m_fireInterop->unregister();
    }
    m_densityInterop.reset();
    m_temperatureInterop.reset();
    m_fireInterop.reset();
    m_fullscreenVertexArray.reset();
    m_densityTexture.reset();
    m_temperatureTexture.reset();
    m_fireTexture.reset();
    m_debugVertexArray.reset();
    m_debugVertexBuffer.reset();
    m_framebuffer.reset();
    m_sceneDepthTexture.reset();
    m_historyTexture.reset();
    m_depthTexture.reset();
    m_colorTexture.reset();
    m_width = 0;
    m_height = 0;
    m_debugVertexCount = 0;
    m_densityResolution = 0;
}

void hzl::SceneRenderer::createProceduralDensity()
{
    const int resolution = m_densityResolution == 0 ? 128 : m_densityResolution;
    m_densityResolution = resolution;
    m_densityTexture = std::make_unique<Texture>(GL_TEXTURE_3D);
    m_densityTexture->allocate3D(resolution, resolution, resolution, GL_R32F);
    m_densityTexture->setFiltering(GL_LINEAR, GL_LINEAR);
    m_densityTexture->setWrap(GL_CLAMP_TO_BORDER);

    m_densityInterop = std::make_unique<CudaGlTexture3D>();
    m_densityInterop->registerTexture(
        m_densityTexture->id(), resolution, resolution, resolution);
    const float centerDensity = m_densityInterop->writeProceduralDensity();

    auto createAuxiliaryTexture = [resolution](
        std::unique_ptr<Texture>& texture,
        std::unique_ptr<CudaGlTexture3D>& interop)
    {
        texture = std::make_unique<Texture>(GL_TEXTURE_3D);
        texture->allocate3D(resolution, resolution, resolution, GL_R32F);
        texture->setFiltering(GL_LINEAR, GL_LINEAR);
        texture->setWrap(GL_CLAMP_TO_BORDER);
        const float zero = 0.0F;
        glClearTexImage(texture->id(), 0, GL_RED, GL_FLOAT, &zero);
        interop = std::make_unique<CudaGlTexture3D>();
        interop->registerTexture(texture->id(), resolution, resolution, resolution);
    };
    createAuxiliaryTexture(m_temperatureTexture, m_temperatureInterop);
    createAuxiliaryTexture(m_fireTexture, m_fireInterop);
    log::info(
        "CUDA/OpenGL shared density volume generated: 128^3 | center density ",
        centerDensity);
}

void hzl::SceneRenderer::createDebugGeometry()
{
    std::vector<DebugVertex> vertices;
    constexpr int gridHalfExtent = 10;
    constexpr float gridSpacing = 0.5F;
    const float gridExtent = static_cast<float>(gridHalfExtent) * gridSpacing;
    const glm::vec3 gridColor{0.16F, 0.20F, 0.27F};
    for(int index = -gridHalfExtent; index <= gridHalfExtent; ++index)
    {
        const float coordinate = static_cast<float>(index) * gridSpacing;
        addLine(vertices, {-gridExtent, 0.0F, coordinate},
            {gridExtent, 0.0F, coordinate}, gridColor);
        addLine(vertices, {coordinate, 0.0F, -gridExtent},
            {coordinate, 0.0F, gridExtent}, gridColor);
    }

    addLine(vertices, {0.0F, 0.0F, 0.0F}, {2.0F, 0.0F, 0.0F}, {0.95F, 0.2F, 0.2F});
    addLine(vertices, {0.0F, 0.0F, 0.0F}, {0.0F, 2.0F, 0.0F}, {0.2F, 0.95F, 0.3F});
    addLine(vertices, {0.0F, 0.0F, 0.0F}, {0.0F, 0.0F, 2.0F}, {0.2F, 0.45F, 1.0F});

    constexpr float minimum = -1.0F;
    constexpr float maximum = 1.0F;
    const glm::vec3 domainColor{0.25F, 0.8F, 0.95F};
    const glm::vec3 corners[] = {
        {minimum, minimum, minimum}, {maximum, minimum, minimum},
        {maximum, maximum, minimum}, {minimum, maximum, minimum},
        {minimum, minimum, maximum}, {maximum, minimum, maximum},
        {maximum, maximum, maximum}, {minimum, maximum, maximum}};
    constexpr int edges[][2] = {
        {0, 1}, {1, 2}, {2, 3}, {3, 0},
        {4, 5}, {5, 6}, {6, 7}, {7, 4},
        {0, 4}, {1, 5}, {2, 6}, {3, 7}};
    for(const auto& edge : edges)
    {
        addLine(vertices, corners[edge[0]], corners[edge[1]], domainColor);
    }

    m_debugVertexCount = static_cast<int>(vertices.size());
    m_debugVertexBuffer = std::make_unique<Buffer>();
    m_debugVertexBuffer->allocate(vertices.size() * sizeof(DebugVertex), vertices.data(), 0);
    m_debugVertexArray = std::make_unique<VertexArray>();
    m_debugVertexArray->setVertexBuffer(
        0, *m_debugVertexBuffer, 0, static_cast<GLsizei>(sizeof(DebugVertex)));
    m_debugVertexArray->setAttribute(
        0, 0, 3, GL_FLOAT, static_cast<GLuint>(offsetof(DebugVertex, position)));
    m_debugVertexArray->setAttribute(
        1, 0, 3, GL_FLOAT, static_cast<GLuint>(offsetof(DebugVertex, color)));
}

void hzl::SceneRenderer::resize(int width, int height)
{
    m_colorTexture = std::make_unique<Texture>(GL_TEXTURE_2D);
    m_colorTexture->allocate2D(width, height, GL_RGBA8);
    m_colorTexture->setFiltering(GL_LINEAR, GL_LINEAR);
    m_colorTexture->setWrap(GL_CLAMP_TO_EDGE);

    m_depthTexture = std::make_unique<Texture>(GL_TEXTURE_2D);
    m_depthTexture->allocate2D(width, height, GL_DEPTH_COMPONENT24);
    m_depthTexture->setFiltering(GL_NEAREST, GL_NEAREST);
    m_depthTexture->setWrap(GL_CLAMP_TO_EDGE);

    m_sceneDepthTexture = std::make_unique<Texture>(GL_TEXTURE_2D);
    m_sceneDepthTexture->allocate2D(width, height, GL_DEPTH_COMPONENT24);
    m_sceneDepthTexture->setFiltering(GL_NEAREST, GL_NEAREST);
    m_sceneDepthTexture->setWrap(GL_CLAMP_TO_EDGE);

    m_historyTexture = std::make_unique<Texture>(GL_TEXTURE_2D);
    m_historyTexture->allocate2D(width, height, GL_RGBA8);
    m_historyTexture->setFiltering(GL_LINEAR, GL_LINEAR);
    m_historyTexture->setWrap(GL_CLAMP_TO_EDGE);
    const float clear[4] = {};
    glClearTexImage(m_historyTexture->id(), 0, GL_RGBA, GL_FLOAT, clear);
    m_historyValid = false;

    m_framebuffer = std::make_unique<Framebuffer>();
    m_framebuffer->attachTexture(GL_COLOR_ATTACHMENT0, *m_colorTexture);
    m_framebuffer->attachTexture(GL_DEPTH_ATTACHMENT, *m_depthTexture);
    m_framebuffer->setDrawBuffer(GL_COLOR_ATTACHMENT0);
    m_framebuffer->requireComplete();

    m_width = width;
    m_height = height;
    log::debug("Scene viewport resized to ", width, 'x', height);
}
```

```
        glDeleteProgram(m_id);

        log::info("Shader program reloaded successfully (", m_id, ')');
        return true;
    }
    catch(const std::exception& exception)
    {
        log::error("Shader reload failed; keeping previous program: ", exception.what());
        return false;
    }
}

std::string hzl::ShaderProgram::readFile(const std::filesystem::path& path)
{
    std::ifstream file(path);
    if(!file)
    {
        throw std::runtime_error("Unable to open shader file: " + path.string());
    }

    std::ostringstream contents;
    contents << file.rdbuf();
    return contents.str();
}

GLuint hzl::ShaderProgram::compileStage(
    GLenum stage, const std::filesystem::path& path)
{
    const std::string source = readFile(path);
    const char* sourcePointer = source.c_str();
    const GLuint shader = glCreateShader(stage);
    glShaderSource(shader, 1, &sourcePointer, nullptr);
    glCompileShader(shader);

    GLint compiled = GL_FALSE;
    glGetShaderiv(shader, GL_COMPILE_STATUS, &compiled);
    if(compiled == GL_TRUE)
    {
        return shader;
    }

    GLint logLength = 0;
    glGetShaderiv(shader, GL_INFO_LOG_LENGTH, &logLength);
    std::string compileLog(static_cast<std::size_t>(logLength), '\0');
    glGetShaderInfoLog(shader, logLength, nullptr, compileLog.data());
    glDeleteShader(shader);
    throw std::runtime_error(
        "Shader compilation failed for " + path.string() + ":\n" + compileLog);
}

GLuint hzl::ShaderProgram::linkProgram(const std::vector<Stage>& stages)
{
    if(stages.empty())
    {
        throw std::invalid_argument("A shader program requires at least one stage");
    }

    const GLuint program = glCreateProgram();
    std::vector<GLuint> shaders;

    try
    {
        for(const auto& [stage, path] : stages)
        {
            const GLuint shader = compileStage(stage, path);
            shaders.push_back(shader);
            glAttachShader(program, shader);
        }

        glLinkProgram(program);
        GLint linked = GL_FALSE;
        glGetProgramiv(program, GL_LINK_STATUS, &linked);
        if(linked != GL_TRUE)
        {
            GLint logLength = 0;
            glGetProgramiv(program, GL_INFO_LOG_LENGTH, &logLength);
            std::string linkLog(static_cast<std::size_t>(logLength), '\0');
            glGetProgramInfoLog(program, logLength, nullptr, linkLog.data());
            throw std::runtime_error("Shader program link failed:\n" + linkLog);
        }
    }
    catch(...)
    {
        for(const GLuint shader : shaders)
        {
            glDeleteShader(shader);
        }
        glDeleteProgram(program);
        throw;
    }

    for(const GLuint shader : shaders)
    {
        glDetachShader(program, shader);
        glDeleteShader(shader);
    }
    return program;
}

GLint hzl::ShaderProgram::uniformLocation(std::string_view name)
{
    const std::string key(name);
    const auto existing = m_uniformLocations.find(key);
    if(existing != m_uniformLocations.end())
    {
        return existing->second;
    }

    const GLint location = glGetUniformLocation(m_id, key.c_str());
    m_uniformLocations.emplace(key, location);
    if(location < 0)
    {
        log::warning("Uniform not found or inactive: ", key);
    }
    return location;
}
```

```
        && m_mouseButtons[static_cast<std::size_t>(button)];

void hzl::Input::setCursorCaptured(bool captured)
{
    if(m_window == nullptr || captured == m_cursorCaptured)
    {
        return;
    }

    m_cursorCaptured = captured;
    m_hasMousePosition = false;
    glfwSetInputMode(
        m_window,
        GLFW_CURSOR,
        captured ? GLFW_CURSOR_DISABLED : GLFW_CURSOR_NORMAL);
}

bool hzl::Input::cursorCaptured() const
{
    return m_cursorCaptured;
}

void hzl::Input::keyCallback(GLFWwindow* window, int key, int, int action, int)
{
    Input* input = inputFrom(window);
    if(input == nullptr || !validIndex(key, input->m_keys.size()))
    {
        return;
    }

    const std::size_t index = static_cast<std::size_t>(key);
    if(action == GLFW_PRESS)
    {
        input->m_keys[index] = true;
        input->m_pressedKeys[index] = true;
    }
    else if(action == GLFW_RELEASE)
    {
        input->m_keys[index] = false;
    }
}

void hzl::Input::mouseButtonCallback(GLFWwindow* window, int button, int action, int)
{
    Input* input = inputFrom(window);
    if(input == nullptr || !validIndex(button, input->m_mouseButtons.size()))
    {
        return;
    }

    input->m_mouseButtons[static_cast<std::size_t>(button)] = action != GLFW_RELEASE;
}

void hzl::Input::cursorPositionCallback(GLFWwindow* window, double x, double y)
{
    Input* input = inputFrom(window);
    if(input == nullptr)
    {
        return;
    }

    if(input->m_hasMousePosition)
    {
        input->m_mouseDeltaX += x - input->m_lastMouseX;
        input->m_mouseDeltaY += y - input->m_lastMouseY;
    }

    input->m_lastMouseX = x;
    input->m_lastMouseY = y;
    input->m_hasMousePosition = true;
}

void hzl::Input::scrollCallback(GLFWwindow* window, double, double yOffset)
{
    if(Input* input = inputFrom(window))
    {
        input->m_scrollDeltaY += yOffset;
    }
}

void hzl::Input::focusCallback(GLFWwindow* window, int focused)
{
    Input* input = inputFrom(window);
    if(input != nullptr && focused == GLFW_FALSE)
    {
        input->m_keys.fill(false);
        input->m_mouseButtons.fill(false);
        input->setCursorCaptured(false);
    }
}
```

```
        std::sin(yaw) * std::cos(pitch)});
```

### src/scene/CameraController.cpp
```
#include "CameraController.h"

#include "input/Input.h"

#define GLFW_INCLUDE_NONE
#include <GLFW/glfw3.h>

#include <glm/geometric.hpp>

#include <algorithm>
#include <cmath>

namespace
{
    constexpr float mouseSensitivity = 0.15F;
    constexpr float orbitPanSensitivity = 0.002F;
}

hzl::CameraController::CameraController()
{
    reset();
}

void hzl::CameraController::update(
    Input& input, double deltaSeconds, int viewportWidth, int viewportHeight)
{
    if(viewportHeight > 0)
    {
        m_camera.setAspectRatio(
            static_cast<float>(viewportWidth) / static_cast<float>(viewportHeight));
    }

    if(input.keyPressed(GLFW_KEY_TAB))
    {
        m_mode = m_mode == CameraMode::orbit ? CameraMode::fly : CameraMode::orbit;
        input.setCursorCaptured(false);
    }

    if(input.keyPressed(GLFW_KEY_F))
    {
        reset();
    }

    const float frameDelta = static_cast<float>(std::min(deltaSeconds, 0.1));
    if(m_mode == CameraMode::orbit)
    {
        updateOrbit(input, frameDelta);
    }
    else
    {
        updateFly(input, frameDelta);
    }
}

const hzl::Camera& hzl::CameraController::camera() const
{
    return m_camera;
}

hzl::CameraMode hzl::CameraController::mode() const
{
    return m_mode;
}

void hzl::CameraController::reset()
{
    m_mode = CameraMode::orbit;
    m_orbitTarget = glm::vec3{0.0F};
    m_orbitDistance = 5.0F;
    m_yawDegrees = -90.0F;
    m_pitchDegrees = -15.0F;
    m_flySpeed = 4.0F;
    updateOrbitPosition();
}

void hzl::CameraController::updateOrbit(Input& input, float)
{
    const bool controlDown = input.keyDown(GLFW_KEY_LEFT_CONTROL)
        || input.keyDown(GLFW_KEY_RIGHT_CONTROL);
    if(input.mouseButtonDown(GLFW_MOUSE_BUTTON_LEFT) && !controlDown)
    {
        m_yawDegrees += static_cast<float>(input.mouseDeltaX()) * mouseSensitivity;
        m_pitchDegrees -= static_cast<float>(input.mouseDeltaY()) * mouseSensitivity;
        m_pitchDegrees = std::clamp(m_pitchDegrees, -89.0F, 89.0F);
    }

    if(input.mouseButtonDown(GLFW_MOUSE_BUTTON_MIDDLE))
    {
        const float panScale = orbitPanSensitivity * m_orbitDistance;
        m_orbitTarget -= m_camera.right()
            * static_cast<float>(input.mouseDeltaX()) * panScale;
        m_orbitTarget += m_camera.up()
            * static_cast<float>(input.mouseDeltaY()) * panScale;
    }

    m_orbitDistance *= std::exp(
        -static_cast<float>(input.scrollDeltaY()) * 0.12F);
    m_orbitDistance = std::clamp(m_orbitDistance, 0.1F, 200.0F);
    updateOrbitPosition();
}

void hzl::CameraController::updateFly(Input& input, float deltaSeconds)
{
    const bool looking = input.mouseButtonDown(GLFW_MOUSE_BUTTON_RIGHT);
    input.setCursorCaptured(looking);

    if(looking)
    {
        m_yawDegrees += static_cast<float>(input.mouseDeltaX()) * mouseSensitivity;
        m_pitchDegrees -= static_cast<float>(input.mouseDeltaY()) * mouseSensitivity;
        m_pitchDegrees = std::clamp(m_pitchDegrees, -89.0F, 89.0F);
        m_camera.setOrientation(m_yawDegrees, m_pitchDegrees);
    }

    float speed = m_flySpeed;
    if(input.keyDown(GLFW_KEY_LEFT_SHIFT))
    {
        speed *= 4.0F;
    }

    glm::vec3 movement{0.0F};
    movement += input.keyDown(GLFW_KEY_W) ? m_camera.forward() : glm::vec3{0.0F};
    movement -= input.keyDown(GLFW_KEY_S) ? m_camera.forward() : glm::vec3{0.0F};
    movement += input.keyDown(GLFW_KEY_D) ? m_camera.right() : glm::vec3{0.0F};
    movement -= input.keyDown(GLFW_KEY_A) ? m_camera.right() : glm::vec3{0.0F};
    movement += input.keyDown(GLFW_KEY_E) ? glm::vec3{0.0F, 1.0F, 0.0F} : glm::vec3{0.0F};
    movement -= input.keyDown(GLFW_KEY_Q) ? glm::vec3{0.0F, 1.0F, 0.0F} : glm::vec3{0.0F};

    if(glm::dot(movement, movement) > 0.0F)
    {
        m_camera.setPosition(
            m_camera.position() + glm::normalize(movement) * speed * deltaSeconds);
    }

    const float scroll = static_cast<float>(input.scrollDeltaY());
    m_flySpeed = std::clamp(m_flySpeed * std::exp(scroll * 0.1F), 0.1F, 100.0F);
}

void hzl::CameraController::updateOrbitPosition()
{
    m_camera.setOrientation(m_yawDegrees, m_pitchDegrees);
    m_camera.setPosition(m_orbitTarget - m_camera.forward() * m_orbitDistance);
}
```

```
    __host__ __device__ std::size_t voxelIndex(int x, int y, int z, int resolution)
    {
        return static_cast<std::size_t>(x)
            + static_cast<std::size_t>(resolution)
                * (static_cast<std::size_t>(y)
                    + static_cast<std::size_t>(resolution) * z);

    __device__ int clampCell(int value, int resolution)
    {
        return max(0, min(value, resolution - 1));
    }

    __device__ float lerpValue(float first, float second, float amount)
    {
        return first + (second - first) * amount;
    }

    __device__ float sampleScalar(
        const float* field, float x, float y, float z, int resolution)
    {
        x = fminf(fmaxf(x, 0.0F), static_cast<float>(resolution - 1));
        y = fminf(fmaxf(y, 0.0F), static_cast<float>(resolution - 1));
        z = fminf(fmaxf(z, 0.0F), static_cast<float>(resolution - 1));
        const int x0 = static_cast<int>(floorf(x));
        const int y0 = static_cast<int>(floorf(y));
        const int z0 = static_cast<int>(floorf(z));
        const int x1 = min(x0 + 1, resolution - 1);
        const int y1 = min(y0 + 1, resolution - 1);
        const int z1 = min(z0 + 1, resolution - 1);
        const float tx = x - static_cast<float>(x0);
        const float ty = y - static_cast<float>(y0);
        const float tz = z - static_cast<float>(z0);

        const float c00 = lerpValue(
            field[voxelIndex(x0, y0, z0, resolution)],
            field[voxelIndex(x1, y0, z0, resolution)], tx);
        const float c10 = lerpValue(
            field[voxelIndex(x0, y1, z0, resolution)],
            field[voxelIndex(x1, y1, z0, resolution)], tx);
        const float c01 = lerpValue(
            field[voxelIndex(x0, y0, z1, resolution)],
            field[voxelIndex(x1, y0, z1, resolution)], tx);
        const float c11 = lerpValue(
            field[voxelIndex(x0, y1, z1, resolution)],
            field[voxelIndex(x1, y1, z1, resolution)], tx);
        return lerpValue(lerpValue(c00, c10, ty), lerpValue(c01, c11, ty), tz);
    }

    __device__ float4 lerpVector(float4 first, float4 second, float amount)
    {
        return make_float4(
            lerpValue(first.x, second.x, amount),
            lerpValue(first.y, second.y, amount),
            lerpValue(first.z, second.z, amount),
            0.0F);
    }

    __device__ float4 sampleVelocity(
        const float4* field, float x, float y, float z, int resolution)
    {
        x = fminf(fmaxf(x, 0.0F), static_cast<float>(resolution - 1));
        y = fminf(fmaxf(y, 0.0F), static_cast<float>(resolution - 1));
        z = fminf(fmaxf(z, 0.0F), static_cast<float>(resolution - 1));
        const int x0 = static_cast<int>(floorf(x));
        const int y0 = static_cast<int>(floorf(y));
        const int z0 = static_cast<int>(floorf(z));
        const int x1 = min(x0 + 1, resolution - 1);
        const int y1 = min(y0 + 1, resolution - 1);
        const int z1 = min(z0 + 1, resolution - 1);
        const float tx = x - static_cast<float>(x0);
        const float ty = y - static_cast<float>(y0);
        const float tz = z - static_cast<float>(z0);

        const float4 c00 = lerpVector(
            field[voxelIndex(x0, y0, z0, resolution)],
            field[voxelIndex(x1, y0, z0, resolution)], tx);
        const float4 c10 = lerpVector(
            field[voxelIndex(x0, y1, z0, resolution)],
            field[voxelIndex(x1, y1, z0, resolution)], tx);
        const float4 c01 = lerpVector(
            field[voxelIndex(x0, y0, z1, resolution)],
            field[voxelIndex(x1, y0, z1, resolution)], tx);
        const float4 c11 = lerpVector(
            field[voxelIndex(x0, y1, z1, resolution)],
            field[voxelIndex(x1, y1, z1, resolution)], tx);
        return lerpVector(
            lerpVector(c00, c10, ty), lerpVector(c01, c11, ty), tz);
    }

    __global__ void initializeFields(
        float4* velocity,
        float* density,
        float* temperature,
        float* fuel,
        int resolution)
    {
        const int x = static_cast<int>(blockIdx.x * blockDim.x + threadIdx.x);
        const int y = static_cast<int>(blockIdx.y * blockDim.y + threadIdx.y);
        const int z = static_cast<int>(blockIdx.z * blockDim.z + threadIdx.z);
        if(x >= resolution || y >= resolution || z >= resolution)
        {
            return;
        }

        const float px = 2.0F * static_cast<float>(x) / (resolution - 1) - 1.0F;
        const float py = 2.0F * static_cast<float>(y) / (resolution - 1) - 1.0F;
        const float pz = 2.0F * static_cast<float>(z) / (resolution - 1) - 1.0F;
        const float radiusSquared = px * px + pz * pz;
        const float cloud = expf(-5.0F * radiusSquared - 3.0F * (py + 0.3F) * (py + 0.3F));
        const float detail = 0.72F + 0.28F * sinf(12.0F * px + 5.0F * py)
            * sinf(10.0F * pz - 4.0F * py);
        const std::size_t index = voxelIndex(x, y, z, resolution);
        density[index] = fminf(fmaxf((cloud - 0.12F) * detail, 0.0F), 1.0F);
        temperature[index] = density[index] * 0.5F;
        fuel[index] = density[index] * 0.25F;

        const float swirl = expf(-3.0F * (radiusSquared + py * py));
        const float maximumCoordinate = fmaxf(fabsf(px), fmaxf(fabsf(py), fabsf(pz)));
        const float boundaryFade = fminf(fmaxf(
            (1.0F - maximumCoordinate) * 8.0F, 0.0F), 1.0F);
        velocity[index] = make_float4(
            -pz * 5.0F * swirl * boundaryFade,
            (1.5F * cloud + 0.8F * py * swirl) * boundaryFade,
            px * 5.0F * swirl * boundaryFade,
            0.0F);
    }

    __global__ void advectVelocityKernel(
        const float4* source,
        float4* destination,
        const float* obstacles,
        float deltaSeconds,
        bool openBoundary,
        int resolution,
        const unsigned char* activeBricks,
        int brickResolution,
        bool sparseEnabled)
    {
        const int x = static_cast<int>(blockIdx.x * blockDim.x + threadIdx.x);
        const int y = static_cast<int>(blockIdx.y * blockDim.y + threadIdx.y);
        const int z = static_cast<int>(blockIdx.z * blockDim.z + threadIdx.z);
        if(x >= resolution || y >= resolution || z >= resolution)
        {
            return;
        }
        const std::size_t index = voxelIndex(x, y, z, resolution);
        if(sparseEnabled && activeBricks[(x / 8) + brickResolution
            * ((y / 8) + brickResolution * (z / 8))] == 0)
        {
            destination[index] = make_float4(0.0F, 0.0F, 0.0F, 0.0F);
            return;
        }
        if(obstacles[index] > 0.5F)
        {
            destination[index] = make_float4(0.0F, 0.0F, 0.0F, 0.0F);
            return;
        }

        const float4 velocity = source[index];
        const float backX = static_cast<float>(x) - deltaSeconds * velocity.x;
        const float backY = static_cast<float>(y) - deltaSeconds * velocity.y;
        const float backZ = static_cast<float>(z) - deltaSeconds * velocity.z;
        if(openBoundary && (backX < 0.0F || backY < 0.0F || backZ < 0.0F
            || backX > resolution - 1 || backY > resolution - 1 || backZ > resolution - 1))
        {
            destination[index] = make_float4(0.0F, 0.0F, 0.0F, 0.0F);
            return;
        }
        destination[index] = sampleVelocity(
            source, backX, backY, backZ, resolution);
    }

    __global__ void advectScalarKernel(
        const float* source,
        float* destination,
        const float4* velocity,
        const float* obstacles,
        float deltaSeconds,
        float dissipation,
        bool openBoundary,
        int resolution,
        const unsigned char* activeBricks,
        int brickResolution,
        bool sparseEnabled)
    {
        const int x = static_cast<int>(blockIdx.x * blockDim.x + threadIdx.x);
        const int y = static_cast<int>(blockIdx.y * blockDim.y + threadIdx.y);
        const int z = static_cast<int>(blockIdx.z * blockDim.z + threadIdx.z);
        if(x >= resolution || y >= resolution || z >= resolution)
        {
            return;
        }
        const std::size_t index = voxelIndex(x, y, z, resolution);
        if(sparseEnabled && activeBricks[(x / 8) + brickResolution
            * ((y / 8) + brickResolution * (z / 8))] == 0)
        {
            destination[index] = 0.0F;
            return;
        }
        if(obstacles[index] > 0.5F)
        {
            destination[index] = 0.0F;
            return;
        }

        const float4 flow = velocity[index];
        const float backX = static_cast<float>(x) - deltaSeconds * flow.x;
        const float backY = static_cast<float>(y) - deltaSeconds * flow.y;
        const float backZ = static_cast<float>(z) - deltaSeconds * flow.z;
        if(openBoundary && (backX < 0.0F || backY < 0.0F || backZ < 0.0F
            || backX > resolution - 1 || backY > resolution - 1 || backZ > resolution - 1))
        {
            destination[index] = 0.0F;
            return;
        }
        destination[index] = dissipation * sampleScalar(
            source, backX, backY, backZ, resolution);
    }

    __global__ void voxelizeObstacleKernel(
        float* obstacles, const float* meshObstacles,
        hzl::SimulationParameters parameters, int resolution)
    {
        const int x = static_cast<int>(blockIdx.x * blockDim.x + threadIdx.x);
        const int y = static_cast<int>(blockIdx.y * blockDim.y + threadIdx.y);
        const int z = static_cast<int>(blockIdx.z * blockDim.z + threadIdx.z);
        if(x >= resolution || y >= resolution || z >= resolution)
        {
            return;
        }
        bool solid = parameters.boundaryMode == hzl::BoundaryMode::closed
            && (x == 0 || y == 0 || z == 0
                || x == resolution - 1 || y == resolution - 1 || z == resolution - 1);
        const float px = 2.0F * static_cast<float>(x) / (resolution - 1) - 1.0F;
        const float py = 2.0F * static_cast<float>(y) / (resolution - 1) - 1.0F;
        const float pz = 2.0F * static_cast<float>(z) / (resolution - 1) - 1.0F;
        const float dx = px - parameters.obstaclePosition.x;
        const float dy = py - parameters.obstaclePosition.y;
        const float dz = pz - parameters.obstaclePosition.z;
        if(parameters.obstacleType == hzl::ObstacleType::sphere)
        {
            solid = solid || dx * dx + dy * dy + dz * dz
                <= parameters.obstacleRadius * parameters.obstacleRadius;
        }
        else if(parameters.obstacleType == hzl::ObstacleType::box)
        {
            solid = solid || (fabsf(dx) <= parameters.obstacleSize.x
                && fabsf(dy) <= parameters.obstacleSize.y
                && fabsf(dz) <= parameters.obstacleSize.z);
        }
        else if(parameters.obstacleType == hzl::ObstacleType::plane)
        {
            solid = solid || py <= parameters.obstaclePosition.y;
        }
        else if(parameters.obstacleType == hzl::ObstacleType::cylinder)
        {
            solid = solid || (dx * dx + dz * dz
                <= parameters.obstacleRadius * parameters.obstacleRadius
                && fabsf(dy) <= parameters.obstacleSize.y);
        }
        const std::size_t index = voxelIndex(x, y, z, resolution);
        solid = solid || meshObstacles[index] > 0.5F;
        obstacles[index] = solid ? 1.0F : 0.0F;
    }

    __global__ void buildActiveBricksKernel(
        const float* density, const float* temperature, const float* fuel,
        const float* fire, unsigned char* activeBricks, int brickResolution,
        hzl::SimulationParameters parameters, int resolution)
    {
        const int x = static_cast<int>(blockIdx.x * blockDim.x + threadIdx.x);
        const int y = static_cast<int>(blockIdx.y * blockDim.y + threadIdx.y);
        const int z = static_cast<int>(blockIdx.z * blockDim.z + threadIdx.z);
        if(x >= resolution || y >= resolution || z >= resolution) return;
        const std::size_t index = voxelIndex(x, y, z, resolution);
        const float px = 2.0F * x / (resolution - 1) - 1.0F;
        const float py = 2.0F * y / (resolution - 1) - 1.0F;
        const float pz = 2.0F * z / (resolution - 1) - 1.0F;
        const float dx = px - parameters.emitterPosition.x;
        const float dy = py - parameters.emitterPosition.y;
        const float dz = pz - parameters.emitterPosition.z;
        const bool source = parameters.emitterEnabled
            && dx * dx + dy * dy + dz * dz < parameters.emitterRadius * parameters.emitterRadius * 2.25F;
        if(density[index] > 0.0005F || temperature[index] > 0.0005F
            || fuel[index] > 0.0005F || fire[index] > 0.0005F || source)
        {
            const int bx = x / 8, by = y / 8, bz = z / 8;
            for(int oz = -1; oz <= 1; ++oz)
            for(int oy = -1; oy <= 1; ++oy)
            for(int ox = -1; ox <= 1; ++ox)
            {
                const int nx = bx + ox, ny = by + oy, nz = bz + oz;
                if(nx >= 0 && ny >= 0 && nz >= 0
                    && nx < brickResolution && ny < brickResolution && nz < brickResolution)
                    activeBricks[nx + brickResolution * (ny + brickResolution * nz)] = 1;
            }
        }
    }

    __global__ void applySourcesKernel(
        float4* velocity,
        float* density,
        float* temperature,
        float* fuel,
        hzl::SimulationParameters parameters,
        hzl::PaintImpulse paint,
        float deltaSeconds,
        int resolution)
    {
        const int x = static_cast<int>(blockIdx.x * blockDim.x + threadIdx.x);
        const int y = static_cast<int>(blockIdx.y * blockDim.y + threadIdx.y);
        const int z = static_cast<int>(blockIdx.z * blockDim.z + threadIdx.z);
        if(x >= resolution || y >= resolution || z >= resolution)
        {
            return;
        }

        const float px = 2.0F * static_cast<float>(x) / (resolution - 1) - 1.0F;
        const float py = 2.0F * static_cast<float>(y) / (resolution - 1) - 1.0F;
        const float pz = 2.0F * static_cast<float>(z) / (resolution - 1) - 1.0F;
        const std::size_t index = voxelIndex(x, y, z, resolution);

        if(parameters.emitterEnabled)
        {
            const float dx = px - parameters.emitterPosition.x;
            const float dy = py - parameters.emitterPosition.y;
            const float dz = pz - parameters.emitterPosition.z;
            const float distance = sqrtf(dx * dx + dy * dy + dz * dz);
            const float falloff = fmaxf(1.0F - distance / parameters.emitterRadius, 0.0F);
            const float smoothFalloff = falloff * falloff * (3.0F - 2.0F * falloff);
            density[index] += parameters.densityEmissionRate * deltaSeconds * smoothFalloff;
            temperature[index] += parameters.temperatureEmissionRate * deltaSeconds * smoothFalloff;
            fuel[index] += parameters.fuelEmissionRate * deltaSeconds * smoothFalloff;
        }

        if(paint.active)
        {
            const float dx = px - paint.position.x;
            const float dy = py - paint.position.y;
            const float dz = pz - paint.position.z;
            const float distance = sqrtf(dx * dx + dy * dy + dz * dz);
            const float falloff = fmaxf(1.0F - distance / paint.radius, 0.0F);
            const float smoothFalloff = falloff * falloff * (3.0F - 2.0F * falloff);
            density[index] += paint.density * deltaSeconds * smoothFalloff;
            temperature[index] += paint.temperature * deltaSeconds * smoothFalloff;
            velocity[index].x += paint.velocity.x * deltaSeconds * smoothFalloff;
            velocity[index].y += paint.velocity.y * deltaSeconds * smoothFalloff;
            velocity[index].z += paint.velocity.z * deltaSeconds * smoothFalloff;
        }
    }

    __global__ void combustionKernel(
        float* density,
        float* temperature,
        float* fuel,
        float* fire,
        const float* obstacles,
        hzl::SimulationParameters parameters,
        float deltaSeconds,
        int resolution)
    {
        const int x = static_cast<int>(blockIdx.x * blockDim.x + threadIdx.x);
        const int y = static_cast<int>(blockIdx.y * blockDim.y + threadIdx.y);
        const int z = static_cast<int>(blockIdx.z * blockDim.z + threadIdx.z);
        if(x >= resolution || y >= resolution || z >= resolution)
        {
            return;
        }
        const std::size_t index = voxelIndex(x, y, z, resolution);
        if(obstacles[index] > 0.5F)
        {
            density[index] = 0.0F;
            temperature[index] = 0.0F;
            fuel[index] = 0.0F;
            fire[index] = 0.0F;
            return;
        }

        fire[index] *= expf(-parameters.fireDissipation * deltaSeconds);
        if(temperature[index] < parameters.ignitionTemperature || fuel[index] <= 0.0F)
        {
            return;
        }
        const float ignitionFactor = fminf(
            fmaxf(temperature[index] - parameters.ignitionTemperature, 0.0F) + 0.15F,
            1.0F);
        const float burned = fminf(
            fuel[index], parameters.burnRate * ignitionFactor * deltaSeconds);
        fuel[index] -= burned;
        temperature[index] += burned * parameters.heatRelease;
        density[index] += burned * parameters.smokeYield;
        fire[index] = fminf(fire[index] + burned / fmaxf(deltaSeconds, 1.0e-5F), 1.0F);
    }

    __global__ void applyForcesKernel(
        float4* velocity,
        const float* density,
        float* temperature,
        const float* obstacles,
        hzl::SimulationParameters parameters,
        float simulationTime,
        float deltaSeconds,
        int resolution)
    {
        const int x = static_cast<int>(blockIdx.x * blockDim.x + threadIdx.x);
        const int y = static_cast<int>(blockIdx.y * blockDim.y + threadIdx.y);
        const int z = static_cast<int>(blockIdx.z * blockDim.z + threadIdx.z);
        if(x >= resolution || y >= resolution || z >= resolution)
        {
            return;
        }
        const std::size_t index = voxelIndex(x, y, z, resolution);
        if(obstacles[index] > 0.5F)
        {
            return;
        }

        float4 value = velocity[index];
        value.y += deltaSeconds * (
            parameters.buoyancyStrength * temperature[index]
            - parameters.smokeWeight * density[index]);
        value.x += parameters.wind.x * deltaSeconds;
        value.y += parameters.wind.y * deltaSeconds;
        value.z += parameters.wind.z * deltaSeconds;

        const float px = 2.0F * static_cast<float>(x) / (resolution - 1) - 1.0F;
        const float py = 2.0F * static_cast<float>(y) / (resolution - 1) - 1.0F;
        const float pz = 2.0F * static_cast<float>(z) / (resolution - 1) - 1.0F;
        const float scale = parameters.turbulenceScale;
        const float turbulence = parameters.turbulenceStrength * deltaSeconds;
        value.x += turbulence * sinf(scale * py + simulationTime)
            * cosf(scale * pz - 0.7F * simulationTime);
        value.y += turbulence * sinf(scale * pz + 1.3F * simulationTime)
            * cosf(scale * px + simulationTime);
        value.z += turbulence * sinf(scale * px - 0.8F * simulationTime)
            * cosf(scale * py + 0.6F * simulationTime);
        velocity[index] = value;
        temperature[index] *= expf(-parameters.coolingRate * deltaSeconds);
    }

    __global__ void curlKernel(
        const float4* velocity, float4* curl, int resolution)
    {
        const int x = static_cast<int>(blockIdx.x * blockDim.x + threadIdx.x);
        const int y = static_cast<int>(blockIdx.y * blockDim.y + threadIdx.y);
        const int z = static_cast<int>(blockIdx.z * blockDim.z + threadIdx.z);
        if(x >= resolution || y >= resolution || z >= resolution)
        {
            return;
        }
        const float4 left = velocity[voxelIndex(clampCell(x - 1, resolution), y, z, resolution)];
        const float4 right = velocity[voxelIndex(clampCell(x + 1, resolution), y, z, resolution)];
        const float4 down = velocity[voxelIndex(x, clampCell(y - 1, resolution), z, resolution)];
        const float4 up = velocity[voxelIndex(x, clampCell(y + 1, resolution), z, resolution)];
        const float4 back = velocity[voxelIndex(x, y, clampCell(z - 1, resolution), resolution)];
        const float4 front = velocity[voxelIndex(x, y, clampCell(z + 1, resolution), resolution)];
        curl[voxelIndex(x, y, z, resolution)] = make_float4(
            0.5F * ((up.z - down.z) - (front.y - back.y)),
            0.5F * ((front.x - back.x) - (right.z - left.z)),
            0.5F * ((right.y - left.y) - (up.x - down.x)),
            0.0F);
    }

    __device__ float vectorLength(float4 value)
    {
        return sqrtf(value.x * value.x + value.y * value.y + value.z * value.z);
    }

    __global__ void applyVorticityKernel(
        float4* velocity,
        const float4* curl,
        const float* obstacles,
        float strength,
        float deltaSeconds,
        int resolution)
    {
        const int x = static_cast<int>(blockIdx.x * blockDim.x + threadIdx.x);
        const int y = static_cast<int>(blockIdx.y * blockDim.y + threadIdx.y);
        const int z = static_cast<int>(blockIdx.z * blockDim.z + threadIdx.z);
        if(x <= 0 || y <= 0 || z <= 0
            || x >= resolution - 1 || y >= resolution - 1 || z >= resolution - 1)
        {
            return;
        }
        const std::size_t index = voxelIndex(x, y, z, resolution);
        if(obstacles[index] > 0.5F)
        {
            return;
        }

        float nx = 0.5F * (
            vectorLength(curl[voxelIndex(x + 1, y, z, resolution)])
            - vectorLength(curl[voxelIndex(x - 1, y, z, resolution)]));
        float ny = 0.5F * (
            vectorLength(curl[voxelIndex(x, y + 1, z, resolution)])
            - vectorLength(curl[voxelIndex(x, y - 1, z, resolution)]));
        float nz = 0.5F * (
            vectorLength(curl[voxelIndex(x, y, z + 1, resolution)])
            - vectorLength(curl[voxelIndex(x, y, z - 1, resolution)]));
        const float normalLength = sqrtf(nx * nx + ny * ny + nz * nz) + 1.0e-6F;
        nx /= normalLength;
        ny /= normalLength;
        nz /= normalLength;

        const float4 omega = curl[index];
        float4 value = velocity[index];
        value.x += strength * deltaSeconds * (ny * omega.z - nz * omega.y);
        value.y += strength * deltaSeconds * (nz * omega.x - nx * omega.z);
        value.z += strength * deltaSeconds * (nx * omega.y - ny * omega.x);
        velocity[index] = value;
    }

    __global__ void visualizeFieldKernel(
        float* output,
        const float* scalar,
        const float4* velocity,
        int field,
        int resolution)
    {
        const int x = static_cast<int>(blockIdx.x * blockDim.x + threadIdx.x);
        const int y = static_cast<int>(blockIdx.y * blockDim.y + threadIdx.y);
        const int z = static_cast<int>(blockIdx.z * blockDim.z + threadIdx.z);
        if(x >= resolution || y >= resolution || z >= resolution)
        {
            return;
        }
        const std::size_t index = voxelIndex(x, y, z, resolution);
        float value = scalar[index];
        if(field == static_cast<int>(hzl::SimulationField::pressure))
        {
            value = 0.5F + 0.5F * tanhf(value * 8.0F);
        }
        else if(field == static_cast<int>(hzl::SimulationField::divergence))
        {
            value = 0.5F + 0.5F * tanhf(value * 20.0F);
        }
        else if(field == static_cast<int>(hzl::SimulationField::velocity))
        {
            value = fminf(vectorLength(velocity[index]) * 0.2F, 1.0F);
        }
        output[index] = fminf(fmaxf(value, 0.0F), 1.0F);
    }

    __global__ void divergenceKernel(
        const float4* velocity,
        float* divergence,
        const float* obstacles,
        float* statistics,
        int resolution)
    {
        const int x = static_cast<int>(blockIdx.x * blockDim.x + threadIdx.x);
        const int y = static_cast<int>(blockIdx.y * blockDim.y + threadIdx.y);
        const int z = static_cast<int>(blockIdx.z * blockDim.z + threadIdx.z);
        if(x >= resolution || y >= resolution || z >= resolution)
        {
            return;
        }
        const std::size_t index = voxelIndex(x, y, z, resolution);
        if(obstacles[index] > 0.5F)
        {
            divergence[index] = 0.0F;
            return;
        }

        const int left = clampCell(x - 1, resolution);
        const int right = clampCell(x + 1, resolution);
        const int down = clampCell(y - 1, resolution);
        const int up = clampCell(y + 1, resolution);
        const int back = clampCell(z - 1, resolution);
        const int front = clampCell(z + 1, resolution);
        const float value = 0.5F * (
            velocity[voxelIndex(right, y, z, resolution)].x
            - velocity[voxelIndex(left, y, z, resolution)].x
            + velocity[voxelIndex(x, up, z, resolution)].y
            - velocity[voxelIndex(x, down, z, resolution)].y
            + velocity[voxelIndex(x, y, front, resolution)].z
            - velocity[voxelIndex(x, y, back, resolution)].z);
        divergence[index] = value;

        if(statistics != nullptr)
        {
            const float absoluteValue = fabsf(value);
            atomicAdd(&statistics[0], absoluteValue);
            atomicMax(
                reinterpret_cast<unsigned int*>(&statistics[1]),
                __float_as_uint(absoluteValue));
        }
    }

    __global__ void enforceVelocityBoundariesKernel(float4* velocity, int resolution)
    {
        const int x = static_cast<int>(blockIdx.x * blockDim.x + threadIdx.x);
        const int y = static_cast<int>(blockIdx.y * blockDim.y + threadIdx.y);
        const int z = static_cast<int>(blockIdx.z * blockDim.z + threadIdx.z);
        if(x >= resolution || y >= resolution || z >= resolution)
        {
            return;
        }
        if(x == 0 || y == 0 || z == 0
            || x == resolution - 1 || y == resolution - 1 || z == resolution - 1)
        {
            velocity[voxelIndex(x, y, z, resolution)] =
                make_float4(0.0F, 0.0F, 0.0F, 0.0F);
        }
    }

    __global__ void pressureJacobiKernel(
        const float* pressure,
        float* nextPressure,
        const float* divergence,
        const float* obstacles,
        int resolution)
    {
        const int x = static_cast<int>(blockIdx.x * blockDim.x + threadIdx.x);
        const int y = static_cast<int>(blockIdx.y * blockDim.y + threadIdx.y);
        const int z = static_cast<int>(blockIdx.z * blockDim.z + threadIdx.z);
        if(x >= resolution || y >= resolution || z >= resolution)
        {
            return;
        }
        const std::size_t index = voxelIndex(x, y, z, resolution);
        if(obstacles[index] > 0.5F)
        {
            nextPressure[index] = 0.0F;
            return;
        }

        const std::size_t left = voxelIndex(clampCell(x - 1, resolution), y, z, resolution);
        const std::size_t right = voxelIndex(clampCell(x + 1, resolution), y, z, resolution);
        const std::size_t down = voxelIndex(x, clampCell(y - 1, resolution), z, resolution);
        const std::size_t up = voxelIndex(x, clampCell(y + 1, resolution), z, resolution);
        const std::size_t back = voxelIndex(x, y, clampCell(z - 1, resolution), resolution);
        const std::size_t front = voxelIndex(x, y, clampCell(z + 1, resolution), resolution);
        const float centerPressure = pressure[index];
        const float sum =
            (obstacles[left] > 0.5F ? centerPressure : pressure[left])
            + (obstacles[right] > 0.5F ? centerPressure : pressure[right])
            + (obstacles[down] > 0.5F ? centerPressure : pressure[down])
            + (obstacles[up] > 0.5F ? centerPressure : pressure[up])
            + (obstacles[back] > 0.5F ? centerPressure : pressure[back])
            + (obstacles[front] > 0.5F ? centerPressure : pressure[front]);
        nextPressure[index] = (sum - divergence[index]) / 6.0F;
    }

    __global__ void projectVelocityKernel(
        float4* velocity,
        const float* pressure,
        const float* obstacles,
        int resolution)
    {
        const int x = static_cast<int>(blockIdx.x * blockDim.x + threadIdx.x);
        const int y = static_cast<int>(blockIdx.y * blockDim.y + threadIdx.y);
        const int z = static_cast<int>(blockIdx.z * blockDim.z + threadIdx.z);
        if(x >= resolution || y >= resolution || z >= resolution)
        {
            return;
        }
        const std::size_t index = voxelIndex(x, y, z, resolution);
        if(obstacles[index] > 0.5F)
        {
            velocity[index] = make_float4(0.0F, 0.0F, 0.0F, 0.0F);
            return;
        }

        float4 value = velocity[index];
        const float centerPressure = pressure[index];
        const std::size_t right = voxelIndex(clampCell(x + 1, resolution), y, z, resolution);
        const std::size_t left = voxelIndex(clampCell(x - 1, resolution), y, z, resolution);
        const std::size_t up = voxelIndex(x, clampCell(y + 1, resolution), z, resolution);
        const std::size_t down = voxelIndex(x, clampCell(y - 1, resolution), z, resolution);
        const std::size_t front = voxelIndex(x, y, clampCell(z + 1, resolution), resolution);
        const std::size_t back = voxelIndex(x, y, clampCell(z - 1, resolution), resolution);
        value.x -= 0.5F * (
            (obstacles[right] > 0.5F ? centerPressure : pressure[right])
            - (obstacles[left] > 0.5F ? centerPressure : pressure[left]));
        value.y -= 0.5F * (
            (obstacles[up] > 0.5F ? centerPressure : pressure[up])
            - (obstacles[down] > 0.5F ? centerPressure : pressure[down]));
        value.z -= 0.5F * (
            (obstacles[front] > 0.5F ? centerPressure : pressure[front])
            - (obstacles[back] > 0.5F ? centerPressure : pressure[back]));
        velocity[index] = value;
    }

    dim3 blockDimensions()
    {
        // 256-thread blocks provide better scheduler occupancy than 512-thread
        // cubes for the register-heavy advection kernels on Ampere GPUs.
        return dim3{8, 8, 4};
    }

    dim3 gridDimensions(int resolution)
    {
        return dim3{
            static_cast<unsigned int>((resolution + 7) / 8),
            static_cast<unsigned int>((resolution + 7) / 8),
            static_cast<unsigned int>((resolution + 3) / 4)};
    }
}

struct hzl::FluidSimulation::Impl
{
    ~Impl()
    {
        release();
    }

    template<typename T>
    void allocateField(T*& field)
    {
        requireCuda(cudaMalloc(&field, voxelCount * sizeof(T)), "Failed to allocate simulation field");
        allocatedBytes += voxelCount * sizeof(T);
    }

    void allocate(int newResolution)
    {
        resolution = newResolution;
        voxelCount = static_cast<std::size_t>(resolution) * resolution * resolution;
        allocateField(velocity);
        allocateField(nextVelocity);
        allocateField(curl);
        allocateField(density);
        allocateField(nextDensity);
        allocateField(temperature);
        allocateField(nextTemperature);
        allocateField(pressure);
        allocateField(nextPressure);
        allocateField(divergence);
        allocateField(fuel);
        allocateField(nextFuel);
        allocateField(fire);
        allocateField(nextFire);
        allocateField(obstacles);
        allocateField(meshObstacles);
        allocateField(visualization);
        brickResolution = (resolution + 7) / 8;
        totalBricks = brickResolution * brickResolution * brickResolution;
        requireCuda(cudaMalloc(&activeBricks, totalBricks), "Failed to allocate sparse brick mask");
        allocatedBytes += totalBricks;
        requireCuda(cudaMalloc(&statistics, 2 * sizeof(float)), "Failed to allocate diagnostics");
        allocatedBytes += 2 * sizeof(float);
        requireCuda(cudaEventCreate(&stepStart), "Failed to create CUDA timing event");
        requireCuda(cudaEventCreate(&stepEnd), "Failed to create CUDA timing event");
    }

    void release() noexcept
    {
        cudaFree(velocity);
        cudaFree(nextVelocity);
        cudaFree(curl);
        cudaFree(density);
        cudaFree(nextDensity);
        cudaFree(temperature);
        cudaFree(nextTemperature);
        cudaFree(pressure);
        cudaFree(nextPressure);
        cudaFree(divergence);
        cudaFree(fuel);
        cudaFree(nextFuel);
        cudaFree(fire);
        cudaFree(nextFire);
        cudaFree(obstacles);
        cudaFree(meshObstacles);
        cudaFree(activeBricks);
        cudaFree(visualization);
        cudaFree(statistics);
        if(stepStart) cudaEventDestroy(stepStart);
        if(stepEnd) cudaEventDestroy(stepEnd);
        stepStart = nullptr;
        stepEnd = nullptr;
        velocity = nullptr;
        nextVelocity = nullptr;
        curl = nullptr;
        density = nullptr;
        nextDensity = nullptr;
        temperature = nullptr;
        nextTemperature = nullptr;
        pressure = nullptr;
        nextPressure = nullptr;
        divergence = nullptr;
        fuel = nullptr;
        nextFuel = nullptr;
        fire = nullptr;
        nextFire = nullptr;
        obstacles = nullptr;
        meshObstacles = nullptr;
        activeBricks = nullptr;
        visualization = nullptr;
        statistics = nullptr;
    }

    void resetFields()
    {
        const std::size_t scalarBytes = voxelCount * sizeof(float);
        requireCuda(cudaMemset(nextVelocity, 0, voxelCount * sizeof(float4)), "Failed to clear velocity");
        requireCuda(cudaMemset(nextDensity, 0, scalarBytes), "Failed to clear density");
        requireCuda(cudaMemset(nextTemperature, 0, scalarBytes), "Failed to clear temperature");
        requireCuda(cudaMemset(pressure, 0, scalarBytes), "Failed to clear pressure");
        requireCuda(cudaMemset(nextPressure, 0, scalarBytes), "Failed to clear pressure temporary");
        requireCuda(cudaMemset(divergence, 0, scalarBytes), "Failed to clear divergence");
        requireCuda(cudaMemset(nextFuel, 0, scalarBytes), "Failed to clear fuel");
        requireCuda(cudaMemset(fire, 0, scalarBytes), "Failed to clear fire");
        requireCuda(cudaMemset(nextFire, 0, scalarBytes), "Failed to clear fire temporary");
        requireCuda(cudaMemset(obstacles, 0, scalarBytes), "Failed to clear obstacles");
        requireCuda(cudaMemset(meshObstacles, 0, scalarBytes), "Failed to clear mesh obstacles");
        requireCuda(cudaMemset(activeBricks, 1, totalBricks), "Failed to initialize sparse bricks");
        requireCuda(cudaMemset(curl, 0, voxelCount * sizeof(float4)), "Failed to clear curl");
        requireCuda(cudaMemset(visualization, 0, scalarBytes), "Failed to clear visualization");
        initializeFields<<<gridDimensions(resolution), blockDimensions()>>>(
            velocity, density, temperature, fuel, resolution);
        requireCuda(cudaGetLastError(), "Failed to initialize simulation fields");
        requireCuda(cudaDeviceSynchronize(), "Failed to synchronize field initialization");
    }

    std::pair<float, float> calculateDivergence(bool collectStatistics)
    {
        if(parameters.boundaryMode == hzl::BoundaryMode::closed)
        {
            enforceVelocityBoundariesKernel<<<gridDimensions(resolution), blockDimensions()>>>(
                velocity, resolution);
            requireCuda(cudaGetLastError(), "Velocity boundary kernel failed");
        }
        float* destinationStatistics = nullptr;
        if(collectStatistics)
        {
            requireCuda(cudaMemset(statistics, 0, 2 * sizeof(float)), "Failed to clear divergence statistics");
            destinationStatistics = statistics;
        }
        divergenceKernel<<<gridDimensions(resolution), blockDimensions()>>>(
            velocity, divergence, obstacles, destinationStatistics, resolution);
        requireCuda(cudaGetLastError(), "Divergence kernel failed");

        if(!collectStatistics)
        {
            return {0.0F, 0.0F};
        }
        float hostStatistics[2]{};
        requireCuda(
            cudaMemcpy(hostStatistics, statistics, sizeof(hostStatistics), cudaMemcpyDeviceToHost),
            "Failed to read divergence statistics");
        return {hostStatistics[0] / static_cast<float>(voxelCount), hostStatistics[1]};
    }

    void solvePressure()
    {
        requireCuda(cudaMemset(pressure, 0, voxelCount * sizeof(float)), "Failed to clear pressure");
        for(int iteration = 0; iteration < pressureIterations; ++iteration)
        {
            pressureJacobiKernel<<<gridDimensions(resolution), blockDimensions()>>>(
                pressure, nextPressure, divergence, obstacles, resolution);
            std::swap(pressure, nextPressure);
        }
        requireCuda(cudaGetLastError(), "Pressure solver kernel failed");
    }

    void projectVelocity()
    {
        projectVelocityKernel<<<gridDimensions(resolution), blockDimensions()>>>(
            velocity, pressure, obstacles, resolution);
        requireCuda(cudaGetLastError(), "Velocity projection kernel failed");
    }

    void advect(float deltaSeconds)
    {
        const dim3 grid = gridDimensions(resolution);
        const dim3 block = blockDimensions();
        if(parameters.sparseActiveRegions)
        {
            requireCuda(cudaMemset(activeBricks, 0, totalBricks), "Failed to clear sparse bricks");
            buildActiveBricksKernel<<<grid, block>>>(density, temperature, fuel, fire,
                activeBricks, brickResolution, parameters, resolution);
        }
        else
        {
            requireCuda(cudaMemset(activeBricks, 1, totalBricks), "Failed to enable dense bricks");
        }
        voxelizeObstacleKernel<<<grid, block>>>(obstacles, meshObstacles, parameters, resolution);
        const bool openBoundary = parameters.boundaryMode == hzl::BoundaryMode::open;
        advectVelocityKernel<<<grid, block>>>(
            velocity, nextVelocity, obstacles, deltaSeconds, openBoundary, resolution,
            activeBricks, brickResolution, parameters.sparseActiveRegions);
        std::swap(velocity, nextVelocity);
        advectScalarKernel<<<grid, block>>>(
            density, nextDensity, velocity, obstacles, deltaSeconds,
            expf(-parameters.densityDissipation * deltaSeconds), openBoundary, resolution,
            activeBricks, brickResolution, parameters.sparseActiveRegions);
        advectScalarKernel<<<grid, block>>>(
            temperature, nextTemperature, velocity, obstacles, deltaSeconds,
            expf(-parameters.temperatureDissipation * deltaSeconds), openBoundary, resolution,
            activeBricks, brickResolution, parameters.sparseActiveRegions);
        advectScalarKernel<<<grid, block>>>(
            fuel, nextFuel, velocity, obstacles, deltaSeconds, 0.999F,
            openBoundary, resolution, activeBricks, brickResolution, parameters.sparseActiveRegions);
        advectScalarKernel<<<grid, block>>>(
            fire, nextFire, velocity, obstacles, deltaSeconds, 1.0F,
            openBoundary, resolution, activeBricks, brickResolution, parameters.sparseActiveRegions);
        std::swap(density, nextDensity);
        std::swap(temperature, nextTemperature);
        std::swap(fuel, nextFuel);
        std::swap(fire, nextFire);
        requireCuda(cudaGetLastError(), "Advection kernel failed");
    }

    void applySourcesAndForces(float deltaSeconds)
    {
        const dim3 grid = gridDimensions(resolution);
        const dim3 block = blockDimensions();
        applySourcesKernel<<<grid, block>>>(
            velocity, density, temperature, fuel,
            parameters, pendingPaint, deltaSeconds, resolution);
        pendingPaint.active = false;
        combustionKernel<<<grid, block>>>(
            density, temperature, fuel, fire, obstacles,
            parameters, deltaSeconds, resolution);
        applyForcesKernel<<<grid, block>>>(
            velocity, density, temperature, obstacles,
            parameters, simulationTime, deltaSeconds, resolution);
        curlKernel<<<grid, block>>>(velocity, curl, resolution);
        applyVorticityKernel<<<grid, block>>>(
            velocity, curl, obstacles,
            parameters.vorticityStrength, deltaSeconds, resolution);
        requireCuda(cudaGetLastError(), "Smoke force kernel failed");
        simulationTime += deltaSeconds;
    }

    const float* scalarField(hzl::SimulationField field) const
    {
        switch(field)
        {
        case hzl::SimulationField::density: return density;
        case hzl::SimulationField::temperature: return temperature;
        case hzl::SimulationField::pressure: return pressure;
        case hzl::SimulationField::divergence: return divergence;
        case hzl::SimulationField::fuel: return fuel;
        case hzl::SimulationField::obstacles: return obstacles;
        case hzl::SimulationField::fire: return fire;
        case hzl::SimulationField::velocity: return density;
        }
        return density;
    }

    void prepareVisualization(hzl::SimulationField field)
    {
        visualizeFieldKernel<<<gridDimensions(resolution), blockDimensions()>>>(
            visualization, scalarField(field), velocity,
            static_cast<int>(field), resolution);
        requireCuda(cudaGetLastError(), "Field visualization kernel failed");
    }

    int resolution = 0;
    int pressureIterations = 80;
    std::size_t voxelCount = 0;
    std::size_t allocatedBytes = 0;
    float4* velocity = nullptr;
    float4* nextVelocity = nullptr;
    float4* curl = nullptr;
    float* density = nullptr;
    float* nextDensity = nullptr;
    float* temperature = nullptr;
    float* nextTemperature = nullptr;
    float* pressure = nullptr;
    float* nextPressure = nullptr;
    float* divergence = nullptr;
    float* fuel = nullptr;
    float* nextFuel = nullptr;
    float* fire = nullptr;
    float* nextFire = nullptr;
    float* obstacles = nullptr;
    float* meshObstacles = nullptr;
    unsigned char* activeBricks = nullptr;
    float* visualization = nullptr;
    float* statistics = nullptr;
    hzl::ProjectionDiagnostics diagnostics;
    hzl::SimulationParameters parameters;
    hzl::PaintImpulse pendingPaint;
    float simulationTime = 0.0F;
    cudaEvent_t stepStart = nullptr;
    cudaEvent_t stepEnd = nullptr;
    float lastGpuMilliseconds = 0.0F;
    bool timingStarted = false;
    int brickResolution = 0;
    int totalBricks = 0;
};

hzl::FluidSimulation::FluidSimulation() = default;
hzl::FluidSimulation::~FluidSimulation() = default;

void hzl::FluidSimulation::initialize(int resolution)
{
    resize(resolution);
}

void hzl::FluidSimulation::resize(int resolution)
{
    if(resolution < 16 || resolution > 512)
    {
        throw std::invalid_argument("Simulation resolution must be between 16 and 512");
    }
    if(m_impl && m_impl->resolution == resolution)
    {
        return;
    }

    auto replacement = std::make_unique<Impl>();
    replacement->pressureIterations = m_impl ? m_impl->pressureIterations : 80;
    if(m_impl)
    {
        replacement->parameters = m_impl->parameters;
    }
    replacement->allocate(resolution);
    replacement->resetFields();
    replacement->advect(1.0F / 60.0F);
    const auto before = replacement->calculateDivergence(true);
    replacement->solvePressure();
    replacement->projectVelocity();
    const auto after = replacement->calculateDivergence(true);
    replacement->diagnostics = {before.first, before.second, after.first, after.second};
    requireCuda(cudaDeviceSynchronize(), "Failed to finalize simulation allocation");
    m_impl = std::move(replacement);

    constexpr double bytesPerMebibyte = 1024.0 * 1024.0;
    log::info(
        "GPU simulation fields allocated: ", resolution, "^3 | ",
        static_cast<double>(m_impl->allocatedBytes) / bytesPerMebibyte, " MiB");
    log::info(
        "Projection validation: average divergence ", before.first, " -> ", after.first,
        " | maximum ", before.second, " -> ", after.second);
}

void hzl::FluidSimulation::reset()
{
    if(m_impl)
    {
        m_impl->resetFields();
    }
}

void hzl::FluidSimulation::step(float deltaSeconds)
{
    if(!m_impl || deltaSeconds <= 0.0F)
    {
        return;
    }
    if(m_impl->timingStarted && cudaEventQuery(m_impl->stepEnd) == cudaSuccess)
    {
        cudaEventElapsedTime(
            &m_impl->lastGpuMilliseconds, m_impl->stepStart, m_impl->stepEnd);
    }
    requireCuda(cudaEventRecord(m_impl->stepStart), "Failed to begin CUDA step timing");
    m_impl->timingStarted = true;
    m_impl->advect(deltaSeconds);
    m_impl->applySourcesAndForces(deltaSeconds);
    m_impl->calculateDivergence(false);
    m_impl->solvePressure();
    m_impl->projectVelocity();
    m_impl->calculateDivergence(false);
    requireCuda(cudaEventRecord(m_impl->stepEnd), "Failed to end CUDA step timing");
}

void hzl::FluidSimulation::shutdown() noexcept
{
    m_impl.reset();
}

}

hzl::NumericalTestResults hzl::FluidSimulation::runNumericalTests()
{
    constexpr int testResolution = 8;
    constexpr std::size_t testVoxelCount =
        static_cast<std::size_t>(testResolution) * testResolution * testResolution;
    float* scalar = nullptr;
    float* advected = nullptr;
    float* obstacles = nullptr;
    float* result = nullptr;
    float4* velocity = nullptr;

    try
    {
        requireCuda(cudaMalloc(&scalar, testVoxelCount * sizeof(float)), "Test allocation failed");
        requireCuda(cudaMalloc(&advected, testVoxelCount * sizeof(float)), "Test allocation failed");
        requireCuda(cudaMalloc(&obstacles, testVoxelCount * sizeof(float)), "Test allocation failed");
        requireCuda(cudaMalloc(&velocity, testVoxelCount * sizeof(float4)), "Test allocation failed");
        requireCuda(cudaMalloc(&result, sizeof(float)), "Test allocation failed");
        initializeNumericalTestFields<<<
            gridDimensions(testResolution), blockDimensions()>>>(
            scalar, velocity, obstacles, testResolution);
        sampleInterpolationTest<<<1, 1>>>(scalar, result);

        float interpolationValue = 0.0F;
        requireCuda(
            cudaMemcpy(&interpolationValue, result, sizeof(float), cudaMemcpyDeviceToHost),
            "Interpolation test readback failed");

        advectScalarKernel<<<gridDimensions(testResolution), blockDimensions()>>>(
            scalar, advected, velocity, obstacles, 1.0F, 1.0F, false, testResolution,
            nullptr, 0, false);
        constexpr std::size_t sampleIndex =
            4 + testResolution * (3 + testResolution * 2);
        float advectionValue = 0.0F;
        requireCuda(
            cudaMemcpy(
                &advectionValue,
                advected + sampleIndex,
                sizeof(float),
                cudaMemcpyDeviceToHost),
            "Advection test readback failed");

        NumericalTestResults tests;
        tests.interpolationError = std::abs(interpolationValue - 14.5F);
        tests.advectionError = std::abs(advectionValue - 15.0F);
        tests.interpolationPassed = tests.interpolationError < 1.0e-5F;
        tests.advectionPassed = tests.advectionError < 1.0e-5F;
        tests.projectionPassed = m_impl
            && m_impl->diagnostics.averageDivergenceAfter
                < m_impl->diagnostics.averageDivergenceBefore
            && m_impl->diagnostics.maximumDivergenceAfter
                < m_impl->diagnostics.maximumDivergenceBefore;

        cudaFree(scalar);
        cudaFree(advected);
        cudaFree(obstacles);
        cudaFree(velocity);
        cudaFree(result);
        log::info(
            "CUDA numerical tests: interpolation ",
            tests.interpolationPassed ? "PASS" : "FAIL",
            " | advection ", tests.advectionPassed ? "PASS" : "FAIL",
            " | projection ", tests.projectionPassed ? "PASS" : "FAIL");
        return tests;
    }
    catch(...)
    {
        cudaFree(scalar);
        cudaFree(advected);
        cudaFree(obstacles);
        cudaFree(velocity);
        cudaFree(result);
        throw;
    }
}

void hzl::FluidSimulation::saveSnapshot(const std::string& path) const
{
    if(!m_impl) return;
    std::ofstream file(path, std::ios::binary);
    if(!file) throw std::runtime_error("Failed to create simulation snapshot: " + path);
    const std::uint32_t magic = 0x485A4C53U;
    const std::uint32_t version = 1;
    const std::uint32_t resolution = static_cast<std::uint32_t>(m_impl->resolution);
    file.write(reinterpret_cast<const char*>(&magic), sizeof(magic));
    file.write(reinterpret_cast<const char*>(&version), sizeof(version));
    file.write(reinterpret_cast<const char*>(&resolution), sizeof(resolution));
    std::vector<float> scalar(m_impl->voxelCount);
    std::vector<float4> vectors(m_impl->voxelCount);
    requireCuda(cudaMemcpy(vectors.data(), m_impl->velocity,
        vectors.size() * sizeof(float4), cudaMemcpyDeviceToHost), "Snapshot velocity readback failed");
    file.write(reinterpret_cast<const char*>(vectors.data()), vectors.size() * sizeof(float4));
    for(const float* field : {m_impl->density, m_impl->temperature, m_impl->pressure,
        m_impl->fuel, m_impl->fire, m_impl->obstacles})
    {
        requireCuda(cudaMemcpy(scalar.data(), field, scalar.size() * sizeof(float),
            cudaMemcpyDeviceToHost), "Snapshot field readback failed");
        file.write(reinterpret_cast<const char*>(scalar.data()), scalar.size() * sizeof(float));
    }
}

void hzl::FluidSimulation::loadSnapshot(const std::string& path)
{
    std::ifstream file(path, std::ios::binary);
    std::uint32_t magic = 0, version = 0, resolution = 0;
    file.read(reinterpret_cast<char*>(&magic), sizeof(magic));
    file.read(reinterpret_cast<char*>(&version), sizeof(version));
    file.read(reinterpret_cast<char*>(&resolution), sizeof(resolution));
    if(!file || magic != 0x485A4C53U || version != 1 || resolution < 16 || resolution > 256)
        throw std::runtime_error("Invalid simulation snapshot: " + path);
    resize(static_cast<int>(resolution));
    std::vector<float4> vectors(m_impl->voxelCount);
    std::vector<float> scalar(m_impl->voxelCount);
    file.read(reinterpret_cast<char*>(vectors.data()), vectors.size() * sizeof(float4));
    requireCuda(cudaMemcpy(m_impl->velocity, vectors.data(), vectors.size() * sizeof(float4),
        cudaMemcpyHostToDevice), "Snapshot velocity upload failed");
    for(float* field : {m_impl->density, m_impl->temperature, m_impl->pressure,
        m_impl->fuel, m_impl->fire, m_impl->obstacles})
    {
        file.read(reinterpret_cast<char*>(scalar.data()), scalar.size() * sizeof(float));
        if(!file) throw std::runtime_error("Truncated simulation snapshot: " + path);
        requireCuda(cudaMemcpy(field, scalar.data(), scalar.size() * sizeof(float),
            cudaMemcpyHostToDevice), "Snapshot field upload failed");
    }
}

int hzl::FluidSimulation::activeBrickCount() const
{
    if(!m_impl) return 0;
    std::vector<unsigned char> mask(static_cast<std::size_t>(m_impl->totalBricks));
    requireCuda(cudaMemcpy(mask.data(), m_impl->activeBricks, mask.size(),
        cudaMemcpyDeviceToHost), "Sparse brick readback failed");
    return static_cast<int>(std::count(mask.begin(), mask.end(), static_cast<unsigned char>(1)));
}

int hzl::FluidSimulation::totalBrickCount() const
{
    return m_impl ? m_impl->totalBricks : 0;
}

void hzl::FluidSimulation::loadObstacleMesh(const std::string& path)
{
    if(!m_impl) return;
    std::ifstream file(path);
    if(!file) throw std::runtime_error("Failed to open OBJ obstacle: " + path);
    struct Vertex { float x, y, z; };
    struct Face { int a, b, c; };
    std::vector<Vertex> vertices;
    std::vector<Face> faces;
    std::string line;
    while(std::getline(file, line))
    {
        std::istringstream stream(line);
        std::string type;
        stream >> type;
        if(type == "v")
        {
            Vertex vertex{};
            if(stream >> vertex.x >> vertex.y >> vertex.z) vertices.push_back(vertex);
        }
        else if(type == "f")
        {
            Face face{};
            if(stream >> face.a)
            {
                stream.ignore(256, ' ');
                if(stream >> face.b) { stream.ignore(256, ' '); if(stream >> face.c) faces.push_back(face); }
            }
        }
    }
    if(vertices.empty() || faces.empty()) throw std::runtime_error("OBJ contains no triangle geometry");
    Vertex minimum = vertices.front(), maximum = vertices.front();
    for(const Vertex& v : vertices)
    {
        minimum.x = std::min(minimum.x, v.x); minimum.y = std::min(minimum.y, v.y); minimum.z = std::min(minimum.z, v.z);
        maximum.x = std::max(maximum.x, v.x); maximum.y = std::max(maximum.y, v.y); maximum.z = std::max(maximum.z, v.z);
    }
    const float extent = std::max({maximum.x - minimum.x, maximum.y - minimum.y, maximum.z - minimum.z, 1.0e-6F});
    const Vertex center{(minimum.x + maximum.x) * 0.5F, (minimum.y + maximum.y) * 0.5F, (minimum.z + maximum.z) * 0.5F};
    for(Vertex& v : vertices) { v.x = (v.x - center.x) * 1.6F / extent; v.y = (v.y - center.y) * 1.6F / extent; v.z = (v.z - center.z) * 1.6F / extent; }
    std::vector<float> mask(m_impl->voxelCount, 0.0F);
    auto mark = [&](const Vertex& p)
    {
        const int x = std::clamp(static_cast<int>((p.x * 0.5F + 0.5F) * (m_impl->resolution - 1)), 0, m_impl->resolution - 1);
        const int y = std::clamp(static_cast<int>((p.y * 0.5F + 0.5F) * (m_impl->resolution - 1)), 0, m_impl->resolution - 1);
        const int z = std::clamp(static_cast<int>((p.z * 0.5F + 0.5F) * (m_impl->resolution - 1)), 0, m_impl->resolution - 1);
        for(int oz = -1; oz <= 1; ++oz) for(int oy = -1; oy <= 1; ++oy) for(int ox = -1; ox <= 1; ++ox)
            if(x+ox >= 0 && y+oy >= 0 && z+oz >= 0 && x+ox < m_impl->resolution && y+oy < m_impl->resolution && z+oz < m_impl->resolution)
                mask[voxelIndex(x+ox, y+oy, z+oz, m_impl->resolution)] = 1.0F;
    };
    for(const Face& f : faces)
    {
        if(f.a <= 0 || f.b <= 0 || f.c <= 0 || f.a > static_cast<int>(vertices.size()) || f.b > static_cast<int>(vertices.size()) || f.c > static_cast<int>(vertices.size())) continue;
        const Vertex a = vertices[f.a-1], b = vertices[f.b-1], c = vertices[f.c-1];
        constexpr int samples = 48;
        for(int i = 0; i <= samples; ++i) for(int j = 0; j <= samples-i; ++j)
        {
            const float u = static_cast<float>(i)/samples, v = static_cast<float>(j)/samples, w = 1.0F-u-v;
            mark({a.x*w+b.x*u+c.x*v, a.y*w+b.y*u+c.y*v, a.z*w+b.z*u+c.z*v});
        }
    }
    requireCuda(cudaMemcpy(m_impl->meshObstacles, mask.data(), mask.size()*sizeof(float),
        cudaMemcpyHostToDevice), "OBJ voxel upload failed");
}
```
