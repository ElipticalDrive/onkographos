Step 1 of the perf plan: a faster exact shadow trace. Stacked on #38 (base perf/render-harness; retarget to main once #38 merges). No quality change: output must stay pixel-identical per cargo xtask visual.
Design
Second occupancy level: super-bricks of 4^3 bricks (32^3 cells) with a nonempty bitset appended after the brick mask. Grow-only occupied AABB in the header.
trace_shadow DDA: if the super-brick is empty, jump with skip_box(32); else if the brick is empty, skip_box(8); else the fine per-voxel DDA. skip_box uses the same crossing/tie logic as the fine DDA, so the visited-cell decision is identical.
Early-out: the ray is monotonic per axis, so once a cell is past the occupied box on an axis it is moving toward (step>=0 && cell>amax or step<=0 && cell<amin) it can never hit; an empty grid returns false immediately. Exact, not approximate.
Iteration cap (768) unchanged; skipping only reduces iterations per ray.
ABI: HEADER_WORDS 12 -> 20 (box min/max words 12-14 / 16-18, super-mask offset in word 7); buffer layout header, bricks, brick mask, super mask. Shader uniform layout test updated.
trace(..., skip=false) stays the pure fine reference for tests.
Evidence so far
fmt, clippy -D warnings (Linux, plus aarch64-apple-darwin render crate), cargo test --workspace --locked: pass.
Proptests compare the CPU mirror and WGSL transliteration (with skipping + early-out) against the fine DDA, including sparse 256^3 / 160^3 grids and tie cases; incremental updates vs rebuilt occupancy (box containment, super masks).
Lavapipe cargo xtask visual vs the harness goldens (autumn, sponge1m, terrain1m stills): bit-exact, max delta 0, 0.000000% pixels differing.
