# hologram-system

**Pick up a 3D model with your bare hands and turn it in mid-air.**

A volumetric display built on the Pepper's Ghost illusion: a phone lying flat
under a four-sided acrylic pyramid projects four synchronised views, and the
reflections converge into an object that appears to float inside the glass —
viewable from every side, with no headset, no glasses, and nothing worn.

Then you reach out and grab it. A webcam watches your hands, a gesture engine
turns that into rotate, scale and select, and the object responds in real time.
No mouse, no controller, no touchscreen. The interface is your hands and the
object is in the air between them.

```
  webcam ─▶ MediaPipe ─▶ gesture engine ─▶ WebSocket ─▶ phone ─▶ pyramid
           (13 ms)       (deltas only)     (70 B)      (4 views)
```

**Any glTF model loads**, which is what makes it more than a demo — export from
Fusion 360, SolidWorks, Blender or CAD and your own geometry is what you are
holding. The plugin pipeline means adding an object is a file, not a code
change.

### Where this goes

The interaction — *walk up, reach in, turn the thing over* — is the point, and
it transfers:

- **Engineering & CAD review** — put an assembly on the table and let the room
  walk around it, instead of four people crowded behind one monitor
- **Medical imaging & education** — anatomy and scan volumes you can rotate by
  hand while explaining them
- **Product & architectural presentation** — a physical object on a desk at a
  pitch, not another slide
- **Museums, retail and exhibitions** — an unattended display nobody has to be
  taught to use, because reaching for something is not a skill
- **Classrooms** — molecules, mechanisms and structures at the front of a room,
  turned by whoever is talking

### Measured, not estimated

Every number below comes from a timed run on the reference machine (Windows 11
laptop, RTX 3050, built-in 640×480 webcam, MediaPipe on CPU), using a monotonic
clock. Two scenarios: an empty frame, and an operator actually waving their
hands at it for 57 seconds.

| Stage | Empty scene | Hands tracking | p95 | Worst |
| --- | --- | --- | --- | --- |
| CV inference | **13.0 ms** | 12.5 ms | 20.1 ms | 23.1 ms |
| Camera → hand state | **14.9 ms** | 21.3 ms | 28.5 ms | 37.7 ms |
| Gesture engine + control loop | 0.38 ms | 1.55 ms | — | — |
| Control message on the wire | **70 bytes** | 70 bytes | — | — |
| Loopback round trip | **0.35 ms** | — | — | — |

| Throughput | |
| --- | --- |
| Capture / inference rate | **30.0 fps sustained**, 29.8 / 29.6 under load |
| Frames dropped | 18 of 1680 — **1.1 %**, the latest-wins policy working |
| Hands detected | **86 %** of frames, up to 2 tracked at once |
| Inference headroom | ~20 ms slack per 33 ms frame, roughly 2× |

**The camera is the bottleneck, not the model.** Inference costs 13 ms against
a 33 ms frame period, so the dominant term in the budget is simply how often the
sensor produces a frame. The single largest win in the whole project was a
config value: forcing manual exposure took the webcam from 7.5 fps to 30 fps and
cut worst-case hand staleness from ~148 ms to ~48 ms — a 4× reduction in the
largest term, from one line.

End-to-end photon-to-pixel over Wi-Fi is **projected at 65–85 ms** and is
deliberately listed as projected: the loopback path is measured, the wireless
leg to the phone is not yet. [docs/latency.md](docs/latency.md) has the full
budget, the methodology, and the two debug-viewer bugs that were inflating the
numbers before they were found.

### Built to be trusted in a room

Only compact state crosses the network — **70 bytes per frame**. No camera
frames, no rendered video, no cloud, and no internet after load. The webcam feed
never leaves the PC; the phone receives numbers and draws them itself. That is a
privacy property and a latency one at the same time: there is no upload to wait
for, and nothing to intercept.

## Gestures

| Gesture | Action |
|---------|--------|
| **Pinch + drag** | **grab and move** the object through space |
| **Thumb-index spread** (one hand, open) | **scale** bigger / smaller |
| Two-hand pinch, apart / together | scale (more precise) |
| Fist (held) | pause |
| Open palm (held) | resume |
| Point | select |

Objects **spin on their own** — there is no manual rotation binding. A
rotationally symmetric object barely appears to move when it spins, so in a
pyramid rotation is a poor way to show life. Translation is unmistakable, so
the grab gesture is spent on it.

All thresholds are ratios of **palm length**, not pixels, so a pinch is the
same gesture whether your hand is 30 cm or 80 cm from the camera. Tune them in
`pc/config/local.json` — see [docs/calibration.md](docs/calibration.md#gesture-tuning).

## Design rules

1. **Latest state wins.** Capture, inference and broadcast each use a single
   overwritten slot, never a queue. A backlog of stale frames is
   unrepresentable, not merely discouraged.
2. **Monotonic clocks only.** All timing is `perf_counter_ns()`.
3. **Deltas, never absolute pose.** A lost packet costs a fraction of a
   degree instead of a visible snap. The renderer owns object state.
4. **No MediaPipe past the vision layer.** Downstream code consumes
   `HandState` / `TrackingFrame`.
5. **Objects know nothing** about MediaPipe, the webcam, the WebSocket, the
   iPhone, or the UI.
6. **The UI framework is never in the control loop.** Phase 1 measured what
   happens when it is: `cv2.waitKey` alone added ~7 ms.
7. **No magic numbers in source.** Everything tunable is in
   `pc/config/default.json` or the calibration JSON.
8. **Measure, do not guess.** Every number in [docs/latency.md](docs/latency.md)
   is recorded output.

## Known constraints

* **MediaPipe's GPU delegate does not work on Windows** — it ships for
  Linux/Android only. Verified, not assumed. The RTX 3050 is not used for hand
  tracking; CPU inference at 13 ms leaves ~20 ms of headroom per frame.
* **iPhone Safari's Fullscreen API is unreliable** on iPhone, so the client
  does not depend on it. Use Share → Add to Home Screen for a chrome-free
  display.
* **Guest/public Wi-Fi will not work** — AP isolation blocks device-to-device
  traffic. Use a phone hotspot.
* **Capture rate is the latency floor.** At 30 fps the newest hand position
  can be up to ~48 ms old, which is larger than every other term combined.

```
/**
 * Entry point and mode router.
 *
 * Two modes share one bundle:
 *   dev       four-panel development UI (the PC)
 *   hologram  four-view output only (the iPhone)
 *
 * Mode is chosen by ?mode=hologram, by a saved preference, or from the
 * landing card. It is deliberately not chosen by user-agent sniffing --
 * the iPhone is a legitimate place to open the dev UI while setting up, and
 * the desktop is where the hologram output gets previewed.
 */

import './styles.css'
import { mountDevMode } from './ui/devMode'
import { mountHologramMode } from './ui/hologramMode'

const MODE_KEY = 'hologram.mode'

type Mode = 'dev' | 'hologram' | 'landing'

const app = document.getElementById('app')!
let unmount: (() => void) | null = null

function readMode(): Mode {
  const param = new URLSearchParams(location.search).get('mode')
  if (param === 'hologram' || param === 'dev') return param
  try {
    const saved = localStorage.getItem(MODE_KEY)
    if (saved === 'hologram' || saved === 'dev') return saved
  } catch {
    /* private browsing; fall through to the landing card */
  }
  return 'landing'
}

function remember(mode: Mode): void {
  try {
    localStorage.setItem(MODE_KEY, mode)
  } catch {
    /* not fatal -- the URL parameter still works */
  }
}

function show(mode: Mode): void {
  unmount?.()
  unmount = null

  if (mode === 'hologram') {
    remember('hologram')
    unmount = mountHologramMode(app, () => show('dev'))
  } else if (mode === 'dev') {
    remember('dev')
    unmount = mountDevMode(app, () => show('hologram'))
  } else {
    landing()
  }
}

function landing(): void {
  const isTouch = matchMedia('(pointer: coarse)').matches
  app.innerHTML = `
    <div class="landing">
      <div class="card">
        <h1>Hologram System</h1>
        <p>
          Pick a mode. The PC runs the development UI; the iPhone runs the
          hologram output and goes under the pyramid.
        </p>
        <button id="go-holo" class="primary">Enter hologram mode</button>
        <button id="go-dev">Open development UI</button>
        <p style="margin-top:18px;font-size:12px">
          ${isTouch
            ? 'Tip: use Share &gt; Add to Home Screen, then launch from the icon — that hides Safari’s bars completely, which the Fullscreen API cannot do reliably on iPhone.'
            : 'The hologram output is also previewed in panel 4 of the development UI.'}
        </p>
      </div>
    </div>`
  document.getElementById('go-holo')!.addEventListener('click', () => show('hologram'))
  document.getElementById('go-dev')!.addEventListener('click', () => show('dev'))
}

// Report anything that escapes, rather than failing to a black screen. A
// silent blank page on a phone under a pyramid is almost impossible to debug.
window.addEventListener('error', (e) => {
  console.error('[hologram] uncaught', e.error ?? e.message)
})
window.addEventListener('unhandledrejection', (e) => {
  console.error('[hologram] unhandled rejection', e.reason)
})

show(readMode())
```

### pc/hologram_pc/config.py

```
"""Configuration loading.

Layering, lowest precedence first:
    1. pc/config/default.json   (checked in, sane defaults)
    2. pc/config/local.json     (gitignored, per-machine overrides)
    3. explicit overrides passed by the caller / CLI flags

Nothing in this project reads a magic number out of source. Sections that
belong to later phases live in the JSON but are exposed via `Config.section()`
until they earn a typed dataclass.
"""

from __future__ import annotations

import copy
import json
import logging
from dataclasses import dataclass, fields
from pathlib import Path
from typing import Any, Dict, Optional

log = logging.getLogger(__name__)

# pc/hologram_pc/config.py -> pc/ -> repo root
PC_DIR = Path(__file__).resolve().parent.parent
REPO_ROOT = PC_DIR.parent
CONFIG_DIR = PC_DIR / "config"
DEFAULT_CONFIG = CONFIG_DIR / "default.json"
LOCAL_CONFIG = CONFIG_DIR / "local.json"


class ConfigError(RuntimeError):
    pass


@dataclass
class CameraConfig:
    index: int = 0
    backend: str = "dshow"          # dshow | msmf | any
    width: int = 640
    height: int = 480
    fps: int = 30
    fourcc: str = "MJPG"            # "" disables the fourcc request
    buffer_size: int = 1
    flip_horizontal: bool = True    # mirror, so moving right moves right
    autofocus: bool = False         # hunting autofocus adds latency spikes
    warmup_frames: int = 5
    open_timeout_s: float = 5.0
    # Auto-exposure lengthens integration time in dim rooms and the UVC driver
    # pays for it by quartering the frame rate (measured: 30 -> 7.5 fps).
    # Locking exposure is the single biggest latency win in the capture stage.
    auto_exposure: bool = False
    exposure: float = -5.0          # log2 seconds; -5 == 1/32 s
    low_light_warn_level: float = 12.0   # mean 0-255 below which we warn


@dataclass
class MediaPipeConfig:
    model_path: str = "models/hand_landmarker.task"
    num_hands: int = 2
    min_hand_detection_confidence: float = 0.5
    min_hand_presence_confidence: float = 0.5
    min_tracking_confidence: float = 0.5
    delegate: str = "auto"          # auto | cpu | gpu
    running_mode: str = "live_stream"

    def resolved_model_path(self) -> Path:
        p = Path(self.model_path)
        return p if p.is_absolute() else (REPO_ROOT / p)


@dataclass
class DiagnosticsConfig:
    fps_window: int = 60
    latency_window: int = 120
    stats_hz: float = 5.0
    log_level: str = "INFO"


@dataclass
class DebugConfig:
    draw_landmarks: bool = True
    draw_connections: bool = True
    draw_handedness: bool = True
    draw_stats: bool = True
    performance_mode: bool = False


@dataclass
class GestureConfig:
    # Schmitt-trigger band for the pinch, as a multiple of palm length.
    # Engaging lower than it releases stops the gesture chattering when the
    # measurement sits on the threshold.
    pinch_on_ratio: float = 0.45
    pinch_off_ratio: float = 0.60
    pinch_open_ratio: float = 1.60   # ratio treated as "fully open" for the 0-1 readout
    # One Euro filter tuning. Higher beta = less lag when moving fast.
    position_min_cutoff: float = 1.2
    position_beta: float = 0.03
    pinch_min_cutoff: float = 1.5
    pinch_beta: float = 0.02
    track_timeout_s: float = 0.35    # forget filter state after this gap
    # Fraction of the frame that maps to the full interaction range.
    active_region: tuple = (0.15, 0.85, 0.15, 0.85)
    rotate_gain: float = 3.2         # kept for objects that bind rotation
    rotate_deadzone: float = 0.004
    max_rotation_step: float = 0.35  # radians per frame, anti-teleport clamp
    # Grab-and-move: hand travel in interaction space -> object travel.
    translate_gain: float = 2.2
    translate_deadzone: float = 0.004
    max_translate_step: float = 0.25
    # One-hand thumb-index spread -> scale.
    spread_gain: float = 1.4         # applied to log(spread ratio)
    spread_deadzone: float = 0.012   # larger than the two-hand one: finger
                                     # spread is noisier than hand separation
    scale_min_confidence: float = 0.5
    scale_cooldown_s: float = 0.45   # ignore spread just after releasing a grab
    scale_gain: float = 1.0          # applied to log(span ratio)
    scale_deadzone: float = 0.006
    max_scale_step: float = 0.12
    min_scale_span: float = 0.05     # guard log() against a collapsing span
    pause_hold_frames: int = 3       # frames of fist before pausing
    resume_hold_frames: int = 4      # frames of open palm before resuming


@dataclass
class NetworkConfig:
    host: str = "0.0.0.0"
    port: int = 8080
    send_hz: float = 60.0
    idle_send_hz: float = 10.0       # heartbeat rate when nothing is happening
    stale_packet_ms: int = 120       # client discards commands older than this
    ping_interval_s: float = 5.0
    client_dist: str = "client/dist"

    def resolved_client_dist(self) -> Path:
        p = Path(self.client_dist)
        return p if p.is_absolute() else (REPO_ROOT / p)


@dataclass
class Config:
    camera: CameraConfig
    mediapipe: MediaPipeConfig
    diagnostics: DiagnosticsConfig
    debug: DebugConfig
    gesture: GestureConfig
    network: NetworkConfig
    raw: Dict[str, Any]

    def section(self, name: str) -> Dict[str, Any]:
        """Untyped access for config belonging to not-yet-built phases."""
        return self.raw.get(name, {})


def _deep_merge(base: Dict[str, Any], override: Dict[str, Any]) -> Dict[str, Any]:
    out = copy.deepcopy(base)
    for k, v in override.items():
        if isinstance(v, dict) and isinstance(out.get(k), dict):
            out[k] = _deep_merge(out[k], v)
        else:
            out[k] = v
    return out


def _build(cls, data: Dict[str, Any]):
    """Instantiate a config dataclass, ignoring unknown keys but warning."""
    known = {f.name for f in fields(cls)}
    unknown = set(data) - known
    if unknown:
        log.warning("%s: ignoring unknown config keys: %s", cls.__name__, sorted(unknown))
    return cls(**{k: v for k, v in data.items() if k in known})


def load_config(overrides: Optional[Dict[str, Any]] = None) -> Config:
    if not DEFAULT_CONFIG.exists():
        raise ConfigError(f"Missing default config: {DEFAULT_CONFIG}")
    try:
        raw = json.loads(DEFAULT_CONFIG.read_text(encoding="utf-8"))
    except json.JSONDecodeError as e:
        raise ConfigError(f"{DEFAULT_CONFIG} is not valid JSON: {e}") from e

    if LOCAL_CONFIG.exists():
        try:
            raw = _deep_merge(raw, json.loads(LOCAL_CONFIG.read_text(encoding="utf-8")))
            log.info("Applied local config overrides from %s", LOCAL_CONFIG)
        except json.JSONDecodeError as e:
            raise ConfigError(f"{LOCAL_CONFIG} is not valid JSON: {e}") from e

    if overrides:
        raw = _deep_merge(raw, overrides)

    gesture = _build(GestureConfig, raw.get("gesture", {}))
    # JSON has no tuples; normalise so downstream unpacking is safe.
    gesture.active_region = tuple(gesture.active_region)  # type: ignore[assignment]
    if len(gesture.active_region) != 4:
        raise ConfigError(
            "gesture.active_region must have exactly 4 values "
            f"[x_min, x_max, y_min, y_max], got {gesture.active_region!r}"
        )

    return Config(
        camera=_build(CameraConfig, raw.get("camera", {})),
        mediapipe=_build(MediaPipeConfig, raw.get("mediapipe", {})),
        diagnostics=_build(DiagnosticsConfig, raw.get("diagnostics", {})),
        debug=_build(DebugConfig, raw.get("debug", {})),
        gesture=gesture,
        network=_build(NetworkConfig, raw.get("network", {})),
        raw=raw,
    )
```

### pc/hologram_pc/pipeline.py
```
"""The real-time pipeline: camera -> landmarks -> gestures -> commands.

Runs on its own thread, deliberately **not** on the asyncio event loop. The
control loop must not be at the mercy of whatever else the loop is doing
(serving a file, accepting a socket), and Phase 1 measured what happens when
an unrelated subsystem gets into the loop: cv2.waitKey added ~7 ms of pickup
delay just by being called too often.

The server thread reads finished state out of single overwritten slots. As
everywhere else in this project, latest wins and nothing queues.
"""

from __future__ import annotations

import logging
import threading
import time
from dataclasses import dataclass
from typing import Optional, Tuple

import numpy as np

from .config import Config
from .diagnostics.metrics import PipelineMetrics
from .interaction.engine import InteractionEngine
from .interaction.types import InteractionFrame, InteractionKind
from .vision.camera import CameraError, CameraSource
from .vision.hand_landmarker import HandTracker, LandmarkerError
from .vision.types import TrackingFrame

log = logging.getLogger(__name__)


@dataclass
class PipelineStatus:
    running: bool = False
    error: Optional[str] = None
    camera_fps: float = 0.0
    inference_fps: float = 0.0
    cv_latency_ms: float = 0.0
    capture_to_hands_ms: float = 0.0
    dropped: int = 0
    brightness: float = 0.0
    low_light: bool = False
    camera_starved: bool = False
    hands: int = 0
    delegate: str = "cpu"
    width: int = 0
    height: int = 0


class Pipeline:
    """Owns the camera, the tracker and the interaction engine."""

    def __init__(self, cfg: Config) -> None:
        self._cfg = cfg
        self._camera = CameraSource(cfg.camera)
        self._tracker = HandTracker(cfg.mediapipe)
        self._engine = InteractionEngine(cfg.gesture)
        self._metrics = PipelineMetrics.create(cfg.diagnostics.latency_window)

        self._thread: Optional[threading.Thread] = None
        self._stop = threading.Event()
        self._lock = threading.Lock()

        self._interaction: Optional[InteractionFrame] = None
        self._interaction_seq = 0
        self._tracking: Optional[TrackingFrame] = None
        self._frame_bgr: Optional[np.ndarray] = None
        self._error: Optional[str] = None
        self._started = False

    # --------------------------------------------------------------- start

    def start(self) -> None:
        self._tracker.open()                     # raises LandmarkerError
        info = self._camera.open()               # raises CameraError
        self._camera.start()
        if info.height:
            self._engine.set_aspect(info.width / info.height)
        self._stop.clear()
        self._thread = threading.Thread(
            target=self._loop, name="pipeline", daemon=True)
        self._thread.start()
        self._started = True
        log.info("Pipeline running (%dx%d, delegate=%s)",
                 info.width, info.height, self._tracker.delegate_used)

    def _loop(self) -> None:
        while not self._stop.is_set():
            t0 = time.perf_counter()

            if self._camera.fatal_error:
                with self._lock:
                    self._error = self._camera.fatal_error
                return

            frame, is_new = self._camera.latest()
            if frame is None:
                time.sleep(0.002)
                continue

            if is_new:
                self._metrics.capture_fps.tick()
                self._tracker.submit(frame.image, frame.seq, frame.capture_ns)
                with self._lock:
                    self._frame_bgr = frame.image

            tracking, tracking_is_new = self._tracker.latest()
            if tracking_is_new and tracking is not None:
                self._metrics.inference_fps.tick()
                self._metrics.cv_latency_ms.add(tracking.stamps.inference_ms)
                self._metrics.capture_to_result_ms.add(
                    tracking.stamps.capture_to_result_ms)
                interaction = self._engine.process(tracking)
                with self._lock:
                    self._tracking = tracking
                    self._interaction = interaction
                    self._interaction_seq += 1

            self._metrics.loop_fps.tick()
            self._metrics.loop_ms.add((time.perf_counter() - t0) * 1000.0)

            if not is_new and not tracking_is_new:
                # Nothing to do; yield rather than spin a core at 100 %.
                time.sleep(0.001)

    # ---------------------------------------------------------------- read

    def latest_interaction(self) -> Tuple[Optional[InteractionFrame], int]:
        """Returns (frame, sequence). Compare sequence to detect newness."""
        with self._lock:
            return self._interaction, self._interaction_seq

    def latest_tracking(self) -> Optional[TrackingFrame]:
        with self._lock:
            return self._tracking

    def latest_frame_bgr(self) -> Optional[np.ndarray]:
        with self._lock:
            return self._frame_bgr

    def status(self) -> PipelineStatus:
        m = self._metrics
        info = self._camera.info
        with self._lock:
            tracking = self._tracking
            err = self._error
        return PipelineStatus(
            running=self._started and err is None,
            error=err,
            camera_fps=round(m.capture_fps.rate, 1),
            inference_fps=round(m.inference_fps.rate, 1),
            cv_latency_ms=round(m.cv_latency_ms.mean, 1),
            capture_to_hands_ms=round(m.capture_to_result_ms.mean, 1),
            dropped=self._camera.dropped_frames,
            brightness=round(self._camera.brightness, 1),
            low_light=self._camera.is_low_light,
            # A camera delivering far below the rate it negotiated almost
            # always means something else has the device open. Windows lets a
            # second process attach to a UVC webcam and then both get starved,
            # which is confusing to diagnose from the symptoms alone.
            camera_starved=(
                self._started
                and m.capture_fps.rate > 0
                and m.capture_fps.rate < self._cfg.camera.fps * 0.6
            ),
            hands=tracking.num_hands if tracking else 0,
            delegate=self._tracker.delegate_used,
            width=info.width if info else 0,
            height=info.height if info else 0,
        )

    # --------------------------------------------------------------- close

    def stop(self) -> None:
        self._stop.set()
        if self._thread is not None:
            self._thread.join(timeout=2.0)
            self._thread = None
        self._camera.close()
        self._tracker.close()
        self._started = False
```

### pc/scripts/check_env.py
```
"""Environment diagnostic. Run this first, and whenever something breaks.

Checks, in order, the things that actually go wrong on Windows:
  1. Python version vs MediaPipe wheel availability
  2. mediapipe / opencv / numpy import + versions
  3. the hand_landmarker.task model file
  4. which camera indices and backends actually deliver frames
  5. whether the GPU delegate can be constructed on this machine

Exit code is 0 if everything required for Phase 1 is present.

    python pc/scripts/check_env.py
"""

from __future__ import annotations

import sys
import time
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent.parent))

OK = "[ OK ]"
WARN = "[WARN]"
FAIL = "[FAIL]"

failures: list[str] = []
warnings: list[str] = []


def report(status: str, label: str, detail: str = "") -> None:
    line = f"{status} {label}"
    if detail:
        line += f"\n        {detail}"
    print(line)
    if status == FAIL:
        failures.append(label)
    elif status == WARN:
        warnings.append(label)


def section(title: str) -> None:
    print(f"\n--- {title} " + "-" * max(0, 56 - len(title)))


def main() -> int:
    print("=" * 64)
    print(" hologram-system :: Phase 1 environment check")
    print("=" * 64)

    # ------------------------------------------------------ 1. python
    section("Python")
    v = sys.version_info
    print(f"       {sys.version.splitlines()[0]}")
    print(f"       {sys.executable}")
    if (3, 9) <= (v.major, v.minor) <= (3, 12):
        report(OK, f"Python {v.major}.{v.minor} is a supported MediaPipe target")
    else:
        report(
            FAIL,
            f"Python {v.major}.{v.minor} has no MediaPipe wheels",
            "MediaPipe publishes wheels for CPython 3.9-3.12. Recreate the venv "
            "with Python 3.11:  py -3.11 -m venv .venv",
        )

    # ------------------------------------------------- 2. dependencies
    section("Dependencies")
    try:
        import numpy
        report(OK, f"numpy {numpy.__version__}")
    except Exception as e:                                   # noqa: BLE001
        report(FAIL, "numpy import failed", str(e))
    try:
        import cv2
        report(OK, f"opencv {cv2.__version__}")
    except Exception as e:                                   # noqa: BLE001
        report(FAIL, "opencv import failed", str(e))
        return _finish()
    try:
        import mediapipe as mp
        report(OK, f"mediapipe {mp.__version__}")
    except Exception as e:                                   # noqa: BLE001
        report(FAIL, "mediapipe import failed",
               f"{e}\n        pip install mediapipe==1.0.1")
        return _finish()

    # -------------------------------------------------------- 3. model
    section("MediaPipe model")
    from hologram_pc.config import load_config
    cfg = load_config()
    model = cfg.mediapipe.resolved_model_path()
    if not model.exists():
        report(FAIL, f"model missing: {model}",
               "Run:  python pc/scripts/download_model.py")
    elif model.stat().st_size < 1_000_000:
        report(FAIL, f"model truncated ({model.stat().st_size} bytes)",
               "Delete it and re-run pc/scripts/download_model.py")
    else:
        report(OK, f"hand_landmarker.task ({model.stat().st_size / 1e6:.1f} MB)",
               str(model))

    # ------------------------------------------------------ 4. cameras
    section("Cameras")
    import cv2
    backends = [("dshow", cv2.CAP_DSHOW), ("msmf", cv2.CAP_MSMF)]
    working: list[tuple[str, int]] = []
    for bname, bid in backends:
        for idx in range(3):
            cap = cv2.VideoCapture(idx, bid)
            if not cap.isOpened():
                cap.release()
                continue
            t0 = time.perf_counter()
            ok, frame = cap.read()
            dt = time.perf_counter() - t0
            if ok and frame is not None:
                w = int(cap.get(cv2.CAP_PROP_FRAME_WIDTH))
                h = int(cap.get(cv2.CAP_PROP_FRAME_HEIGHT))
                fps = cap.get(cv2.CAP_PROP_FPS)
                print(f"       {bname:5s} index {idx}: {w}x{h} @{fps:.0f}fps "
                      f"(first read {dt * 1000:.0f} ms)")
                working.append((bname, idx))
            cap.release()
    if working:
        report(OK, f"{len(working)} working camera/backend combination(s)")
        if (cfg.camera.backend, cfg.camera.index) not in working:
            report(WARN,
                   f"configured camera ({cfg.camera.backend} index "
                   f"{cfg.camera.index}) is not in the working list",
                   "Edit pc/config/local.json to pick one of the above.")
    else:
        report(FAIL, "no working camera found",
               "Settings > Privacy & security > Camera > allow desktop apps; "
               "and close Teams/Zoom/Camera.")

    # ----------------------------------------------- 5. GPU delegate
    section("MediaPipe delegate")
    if model.exists() and model.stat().st_size >= 1_000_000:
        from mediapipe.tasks import python as mp_python
        from mediapipe.tasks.python import vision as mp_vision
        for name, enum in (("CPU", mp_python.BaseOptions.Delegate.CPU),
                           ("GPU", mp_python.BaseOptions.Delegate.GPU)):
            try:
                lm = mp_vision.HandLandmarker.create_from_options(
                    mp_vision.HandLandmarkerOptions(
                        base_options=mp_python.BaseOptions(
                            model_asset_path=str(model), delegate=enum),
                        running_mode=mp_vision.RunningMode.IMAGE,
                    )
                )
                lm.close()
                report(OK, f"{name} delegate constructs")
            except Exception as e:                            # noqa: BLE001
                msg = str(e).splitlines()[0][:110]
                if name == "GPU":
                    report(WARN, "GPU delegate unavailable (expected on Windows)",
                           f"{msg}\n        MediaPipe ships the GPU delegate for "
                           "Linux/Android only; CPU inference is the supported path here.")
                else:
                    report(FAIL, "CPU delegate failed", msg)

    return _finish()


def _finish() -> int:
    print("\n" + "=" * 64)
    if failures:
        print(f" RESULT: {len(failures)} blocking problem(s):")
        for f in failures:
            print(f"   - {f}")
        print("=" * 64)
        return 1
    if warnings:
        print(f" RESULT: ready, with {len(warnings)} warning(s).")
    else:
        print(" RESULT: all checks passed. Phase 1 is ready to run.")
    print("   Next:  python pc/scripts/phase1_preview.py")
    print("=" * 64)
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

### pc/scripts/download_model.py
```
"""Download the MediaPipe Hand Landmarker model bundle.

    python pc/scripts/download_model.py [--variant float16|full|lite] [--force]

Variants (all are the same 21-landmark topology, different weights):
    float16  ~7.8 MB  recommended default; fastest on CPU
    full     ~11  MB  float32 weights
    lite     ~7.5 MB  smaller detector

The file is written to models/hand_landmarker.task, which is gitignored --
model binaries do not belong in the repo.
"""

from __future__ import annotations

import argparse
import sys
import urllib.error
import urllib.request
from pathlib import Path

REPO_ROOT = Path(__file__).resolve().parent.parent.parent
DEST = REPO_ROOT / "models" / "hand_landmarker.task"

BASE = "https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker"
VARIANTS = {
    "float16": f"{BASE}/float16/1/hand_landmarker.task",
    "full": f"{BASE}/float16/latest/hand_landmarker.task",
    "lite": f"{BASE}/float16/1/hand_landmarker.task",
}
MIN_BYTES = 1_000_000


def main() -> int:
    ap = argparse.ArgumentParser(description=__doc__,
                                 formatter_class=argparse.RawDescriptionHelpFormatter)
    ap.add_argument("--variant", choices=sorted(VARIANTS), default="float16")
    ap.add_argument("--force", action="store_true",
                    help="re-download even if the file already exists")
    args = ap.parse_args()

    if DEST.exists() and not args.force:
        size = DEST.stat().st_size
        if size >= MIN_BYTES:
            print(f"[ OK ] Model already present: {DEST} ({size / 1e6:.1f} MB)")
            print("       Use --force to re-download.")
            return 0
        print(f"[WARN] Existing model is only {size} bytes; re-downloading.")

    url = VARIANTS[args.variant]
    DEST.parent.mkdir(parents=True, exist_ok=True)
    tmp = DEST.with_suffix(".task.part")
    print(f"Downloading {args.variant} model")
    print(f"  from {url}")
    print(f"  to   {DEST}")

    try:
        def _progress(block_num: int, block_size: int, total: int) -> None:
            if total <= 0:
                return
            done = min(total, block_num * block_size)
            pct = 100.0 * done / total
            sys.stdout.write(f"\r  {pct:5.1f}%  {done / 1e6:5.1f} / {total / 1e6:.1f} MB")
            sys.stdout.flush()

        urllib.request.urlretrieve(url, tmp, _progress)
        print()
    except urllib.error.URLError as e:
        print(f"\n[FAIL] Download failed: {e.reason}")
        print("       Check your internet connection or a corporate proxy/firewall.")
        tmp.unlink(missing_ok=True)
        return 1

    size = tmp.stat().st_size
    if size < MIN_BYTES:
        print(f"[FAIL] Downloaded file is only {size} bytes -- that is not the model.")
        tmp.unlink(missing_ok=True)
        return 1

    tmp.replace(DEST)
    print(f"[ OK ] Saved {DEST} ({size / 1e6:.1f} MB)")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

### pc/scripts/phase1_preview.py
```
"""PHASE 1 -- webcam capture + MediaPipe hand tracking, with live telemetry.

This is the Phase 1 acceptance test. It exercises the whole vision layer
end to end and prints the latency numbers the rest of the system will be
budgeted against. There is no gesture logic, no 3D, and no networking here;
those are Phases 2, 3 and 5.

    python pc/scripts/phase1_preview.py                 # live window
    python pc/scripts/phase1_preview.py --headless -d 15 # no GUI, prints stats
    python pc/scripts/phase1_preview.py --camera-index 1 --backend msmf

Keys in the live window:
    q / ESC   quit            l  toggle landmark dots
    s         save snapshot   c  toggle skeleton lines
    p         performance mode (drops all overlay drawing)
"""

from __future__ import annotations

import argparse
import logging
import sys
import time
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent.parent))

import cv2

from hologram_pc.config import load_config
from hologram_pc.diagnostics.metrics import PipelineMetrics
from hologram_pc.vision.camera import CameraError, CameraSource
from hologram_pc.vision.hand_landmarker import HandTracker, LandmarkerError
from hologram_pc.vision.overlay import draw_hands, draw_text_block
from hologram_pc.vision.types import HandLandmarkIndex

log = logging.getLogger("phase1")
REPO_ROOT = Path(__file__).resolve().parent.parent.parent
WINDOW = "Phase 1 - hand tracking"


def build_overrides(args) -> dict:
    cam, mp_ = {}, {}
    if args.camera_index is not None:
        cam["index"] = args.camera_index
    if args.backend:
        cam["backend"] = args.backend
    if args.width:
        cam["width"] = args.width
    if args.height:
        cam["height"] = args.height
    if args.no_flip:
        cam["flip_horizontal"] = False
    if args.num_hands:
        mp_["num_hands"] = args.num_hands
    if args.delegate:
        mp_["delegate"] = args.delegate
    out = {}
    if cam:
        out["camera"] = cam
    if mp_:
        out["mediapipe"] = mp_
    return out


def main() -> int:
    ap = argparse.ArgumentParser(
        description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    ap.add_argument("--headless", action="store_true",
                    help="run without a GUI window (for CI / remote shells)")
    ap.add_argument("-d", "--duration", type=float, default=0.0,
                    help="stop after N seconds (0 = run until quit)")
    ap.add_argument("--camera-index", type=int, default=None)
    ap.add_argument("--backend", choices=["dshow", "msmf", "any"], default=None)
    ap.add_argument("--width", type=int, default=None)
    ap.add_argument("--height", type=int, default=None)
    ap.add_argument("--num-hands", type=int, default=None)
    ap.add_argument("--delegate", choices=["auto", "cpu", "gpu"], default=None)
    ap.add_argument("--no-flip", action="store_true",
                    help="disable the horizontal mirror")
    ap.add_argument("--snapshot", type=str, default=None,
                    help="write the last annotated frame to this path and exit")
    args = ap.parse_args()

    cfg = load_config(build_overrides(args))
    logging.basicConfig(
        level=getattr(logging, cfg.diagnostics.log_level.upper(), logging.INFO),
        format="%(levelname)-7s %(name)s: %(message)s",
    )

    metrics = PipelineMetrics.create(cfg.diagnostics.latency_window)
    perf_mode = cfg.debug.performance_mode
    show_landmarks = cfg.debug.draw_landmarks
    show_connections = cfg.debug.draw_connections

    # ------------------------------------------------------------- start up
    try:
        tracker = HandTracker(cfg.mediapipe)
        tracker.open()
    except LandmarkerError as e:
        print(f"\n[FAIL] {e}\n", file=sys.stderr)
        return 2

    try:
        camera = CameraSource(cfg.camera)
        info = camera.open()
        camera.start()
    except CameraError as e:
        print(f"\n[FAIL] {e}\n", file=sys.stderr)
        tracker.close()
        return 3

    print()
    print("=" * 62)
    print(" PHASE 1 :: camera + MediaPipe hand tracking")
    print("=" * 62)
    print(f"  camera     : index {info.index} via {info.backend}, "
          f"{info.width}x{info.height} @{info.fps:.0f}fps fourcc={info.fourcc or '?'}")
    print(f"  exposure   : {'auto' if cfg.camera.auto_exposure else f'manual {cfg.camera.exposure:g}'}"
          f"{'' if cfg.camera.auto_exposure else '  (manual keeps the sensor at full frame rate)'}")
    print(f"  mirrored   : {cfg.camera.flip_horizontal}")
    print(f"  landmarker : LIVE_STREAM, delegate={tracker.delegate_used}, "
          f"num_hands={cfg.mediapipe.num_hands}")
    print(f"  thresholds : det={cfg.mediapipe.min_hand_detection_confidence} "
          f"pres={cfg.mediapipe.min_hand_presence_confidence} "
          f"track={cfg.mediapipe.min_tracking_confidence}")
    print("=" * 62)
    if args.headless:
        print("  headless mode -- hold your hand in front of the webcam")
    else:
        print("  keys: q/ESC quit | l landmarks | c skeleton | p perf mode | s snapshot")
    print()

    started = time.perf_counter()
    last_report = started
    last_tracking = None
    last_annotated = None
    hud_lines: list = []
    last_hud_ns = 0
    hud_interval_ns = int(1e9 / max(0.5, cfg.diagnostics.stats_hz))
    frames_seen = 0
    frames_with_hands = 0
    max_hands_seen = 0
    exit_code = 0

    try:
        while True:
            loop_t0 = time.perf_counter()

            if camera.fatal_error:
                print(f"\n[FAIL] {camera.fatal_error}", file=sys.stderr)
                exit_code = 4
                break

            frame, is_new = camera.latest()
            if frame is None:
                time.sleep(0.002)
                continue

            if is_new:
                metrics.capture_fps.tick()
                frames_seen += 1
                tracker.submit(frame.image, frame.seq, frame.capture_ns)

            tracking, tracking_is_new = tracker.latest()
            if tracking_is_new and tracking is not None:
                last_tracking = tracking
                metrics.inference_fps.tick()
                metrics.cv_latency_ms.add(tracking.stamps.inference_ms)
                metrics.capture_to_result_ms.add(tracking.stamps.capture_to_result_ms)
                if tracking.num_hands:
                    frames_with_hands += 1
                    max_hands_seen = max(max_hands_seen, tracking.num_hands)

            # ------------------------------------------------------ display
            # Only rebuild the canvas when there is actually something new to
            # show. Redrawing on every iteration burns ~15 ms per loop and
            # delays the next latest() poll, which inflates measured
            # capture->hands latency for no visual benefit.
            should_render = is_new or tracking_is_new
            if (not args.headless or args.snapshot) and should_render:
                canvas = frame.image if perf_mode else frame.image.copy()
                if not perf_mode and last_tracking is not None:
                    draw_hands(
                        canvas, last_tracking.hands,
                        draw_connections=show_connections,
                        draw_landmarks=show_landmarks,
                        draw_handedness=cfg.debug.draw_handedness,
                    )
                    _draw_pinch_markers(canvas, last_tracking)
                if not perf_mode and cfg.debug.draw_stats:
                    # Statistics refresh slower than the control loop, per the
                    # latency rules -- recomputing them at frame rate is pure
                    # overhead and makes the numbers unreadable anyway.
                    now_ns = time.perf_counter_ns()
                    if now_ns - last_hud_ns >= hud_interval_ns:
                        last_hud_ns = now_ns
                        hud_lines = _hud_lines(
                            info, tracker, camera, metrics, last_tracking)
                    draw_text_block(canvas, hud_lines)
                last_annotated = canvas
                if not args.headless:
                    cv2.imshow(WINDOW, canvas)

            if not args.headless and should_render:
                # cv2.waitKey blocks for ~15 ms on the Windows HighGUI backend,
                # so it is called once per rendered frame (30 Hz) rather than
                # once per loop iteration. Calling it every iteration throttles
                # the whole loop to ~64 Hz and adds ~7 ms of average delay to
                # picking up a finished inference.
                key = cv2.waitKey(1) & 0xFF
                if key in (ord("q"), 27):
                    break
                if key == ord("l"):
                    show_landmarks = not show_landmarks
                elif key == ord("c"):
                    show_connections = not show_connections
                elif key == ord("p"):
                    perf_mode = not perf_mode
                    print(f"  performance mode: {'ON' if perf_mode else 'OFF'}")
                elif key == ord("s") and last_annotated is not None:
                    _save(last_annotated, REPO_ROOT / "docs" / "phase1_snapshot.png")
            elif not should_render:
                time.sleep(0.001)

            metrics.loop_fps.tick()
            metrics.loop_ms.add((time.perf_counter() - loop_t0) * 1000.0)

            now = time.perf_counter()
            if args.headless and (now - last_report) >= (1.0 / max(0.5, cfg.diagnostics.stats_hz)) * 5:
                last_report = now
                _print_stats_line(now - started, metrics, tracker, camera, last_tracking)

            if args.duration and (now - started) >= args.duration:
                break

    except KeyboardInterrupt:
        print("\n  interrupted")
    finally:
        camera.close()
        tracker.close()
        if not args.headless:
            cv2.destroyAllWindows()

    if args.snapshot and last_annotated is not None:
        _save(last_annotated, Path(args.snapshot))

    _print_summary(time.perf_counter() - started, metrics, tracker, camera,
                   frames_seen, frames_with_hands, max_hands_seen)
    return exit_code


def _draw_pinch_markers(canvas, tracking) -> None:
    """Draw the thumb-index span. Phase 2 turns this measurement into a gesture;
    here it only makes it visually obvious that fingertips are tracked well."""
    h, w = canvas.shape[:2]
    for hand in tracking.hands:
        thumb = hand.landmarks[HandLandmarkIndex.THUMB_TIP]
        index = hand.landmarks[HandLandmarkIndex.INDEX_TIP]
        p1 = (int(thumb[0] * w), int(thumb[1] * h))
        p2 = (int(index[0] * w), int(index[1] * h))
        cv2.line(canvas, p1, p2, (60, 230, 255), 1, cv2.LINE_AA)
        mid = ((p1[0] + p2[0]) // 2, (p1[1] + p2[1]) // 2)
        dist = float(((thumb[0] - index[0]) ** 2 + (thumb[1] - index[1]) ** 2) ** 0.5)
        cv2.putText(canvas, f"{dist:.3f}", (mid[0] + 6, mid[1] - 6),
                    cv2.FONT_HERSHEY_SIMPLEX, 0.45, (0, 0, 0), 3, cv2.LINE_AA)
        cv2.putText(canvas, f"{dist:.3f}", (mid[0] + 6, mid[1] - 6),
                    cv2.FONT_HERSHEY_SIMPLEX, 0.45, (60, 230, 255), 1, cv2.LINE_AA)


def _hud_lines(info, tracker, camera, metrics, tracking) -> list:
    hands_txt = "none"
    if tracking is not None and tracking.num_hands:
        hands_txt = ", ".join(
            f"{h.handedness}({h.handedness_score:.2f})" for h in tracking.hands)
    return [
        f"capture {metrics.capture_fps.rate:5.1f} fps   "
        f"infer {metrics.inference_fps.rate:5.1f} fps   "
        f"loop {metrics.loop_fps.rate:5.1f} fps",
        f"cv latency  {metrics.cv_latency_ms.mean:5.1f} ms avg  "
        f"{metrics.cv_latency_ms.percentile(95):5.1f} p95",
        f"cam->hands  {metrics.capture_to_result_ms.mean:5.1f} ms avg  "
        f"{metrics.capture_to_result_ms.percentile(95):5.1f} p95",
        f"delegate {tracker.delegate_used}   dropped {camera.dropped_frames}   "
        f"in-flight {tracker.in_flight}",
        f"brightness {camera.brightness:5.1f}"
        + ("  << LOW LIGHT, tracking will suffer" if camera.is_low_light else ""),
        f"hands: {hands_txt}",
    ]


def _print_stats_line(elapsed, metrics, tracker, camera, tracking) -> None:
    n = tracking.num_hands if tracking else 0
    print(f"  t={elapsed:5.1f}s  capture {metrics.capture_fps.rate:5.1f}fps  "
          f"infer {metrics.inference_fps.rate:5.1f}fps  "
          f"cv {metrics.cv_latency_ms.mean:5.1f}ms  "
          f"cam->hands {metrics.capture_to_result_ms.mean:5.1f}ms  "
          f"hands={n}  dropped={camera.dropped_frames}")


def _save(image, path: Path) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    cv2.imwrite(str(path), image)
    print(f"  saved {path}")


def _print_summary(elapsed, metrics, tracker, camera,
                   frames_seen, frames_with_hands, max_hands_seen) -> None:
    print()
    print("=" * 62)
    print(" PHASE 1 SUMMARY")
    print("=" * 62)
    print(f"  ran for            {elapsed:.1f} s")
    print(f"  frames captured    {camera.captured_frames}")
    print(f"  frames submitted   {tracker.submitted}")
    print(f"  results returned   {tracker.completed}")
```

```
def test_topology() -> None:

def test_live_stream() -> None:
    print("\n[2] HandTracker in LIVE_STREAM mode (async path)")
    cfg = load_config()
    bgr = cv2.imread(str(FIXTURE))
    if bgr is None:
        check("fixture readable", False, str(FIXTURE))
        return

    tracker = HandTracker(cfg.mediapipe)
    tracker.open()
    try:
        # Submit the same frame repeatedly with increasing timestamps, the way
        # the capture loop would. MediaPipe needs a few frames before its
        # tracking path settles.
        base = time.perf_counter_ns()
        for i in range(12):
            tracker.submit(bgr, frame_id=i, capture_ns=base + i * 33_000_000)
            time.sleep(0.035)

        deadline = time.perf_counter() + 5.0
        result = None
        while time.perf_counter() < deadline:
            tf, is_new = tracker.latest()
            if tf is not None and tf.num_hands:
                result = tf
                break
            time.sleep(0.01)

        if not check("async callback delivered a result with hands",
                     result is not None,
                     "no TrackingFrame with hands within 5s"):
            return

        check("detected 2 hands", result.num_hands == 2,
              f"got {result.num_hands}")
        check("submitted count matches completed",
              tracker.completed > 0,
              f"submitted={tracker.submitted} completed={tracker.completed}")
        check("no results left in flight after drain",
              tracker.in_flight <= 16)

        for hand in result.hands:
            tag = f"hand[{hand.index}] {hand.handedness}"
            check(f"{tag}: landmark array is (21,3) float32",
                  hand.landmarks.shape == (21, 3)
                  and hand.landmarks.dtype == np.float32,
                  f"{hand.landmarks.shape} {hand.landmarks.dtype}")
            xy = hand.landmarks[:, :2]
            check(f"{tag}: normalised x,y within [-0.2, 1.2]",
                  bool(np.all(xy > -0.2) and np.all(xy < 1.2)),
                  f"range {xy.min():.3f}..{xy.max():.3f}")
            check(f"{tag}: handedness is Left or Right",
                  hand.handedness in ("Left", "Right"), hand.handedness)
            check(f"{tag}: handedness score > 0.5",
                  hand.handedness_score > 0.5, f"{hand.handedness_score:.3f}")
            check(f"{tag}: world landmarks present and metric-ish",
                  hand.world_landmarks is not None
                  and 0.02 < float(np.ptp(hand.world_landmarks, axis=0).max()) < 0.5,
                  f"span {np.ptp(hand.world_landmarks, axis=0).round(3)}"
                  if hand.world_landmarks is not None else "None")
            # Geometric sanity: the middle fingertip should be further from the
            # wrist than the middle MCP knuckle is. If the landmark ordering
            # were wrong, this would fail.
            w = hand.landmarks[HandLandmarkIndex.WRIST]
            mcp = hand.landmarks[HandLandmarkIndex.MIDDLE_MCP]
            tip = hand.landmarks[HandLandmarkIndex.MIDDLE_TIP]
            check(f"{tag}: middle fingertip is distal to the knuckle",
                  float(np.linalg.norm(tip - w)) > float(np.linalg.norm(mcp - w)))

        stamps = result.stamps
        check("inference latency is positive and < 500 ms",
              0 < stamps.inference_ms < 500, f"{stamps.inference_ms:.1f} ms")
        check("capture->result >= inference time",
              stamps.capture_to_result_ms >= stamps.inference_ms)
    finally:
        tracker.close()


def test_timestamp_monotonicity() -> None:
    print("\n[3] Timestamp guard")
    cfg = load_config()
    bgr = cv2.imread(str(FIXTURE))
    tracker = HandTracker(cfg.mediapipe)
    tracker.open()
    try:
        base = time.perf_counter_ns()
        first = tracker.submit(bgr, 0, base)
        # Same millisecond -> must be refused, or the Tasks API would throw.
        same = tracker.submit(bgr, 1, base + 1000)          # +1 microsecond
        later = tracker.submit(bgr, 2, base + 50_000_000)   # +50 ms
        check("first submit accepted", first is True)
        check("sub-millisecond duplicate rejected (no API exception)",
              same is False)
        check("later timestamp accepted", later is True)
    finally:
        tracker.close()


def test_camera_latest_wins() -> None:
    print("\n[4] Camera latest-frame-wins semantics")
    cfg = load_config()
    cam = CameraSource(cfg.camera)
    try:
        cam.open()
    except Exception as e:                                   # noqa: BLE001
        print(f"  [SKIP] camera unavailable: {str(e).splitlines()[0]}")
        return
    try:
        cam.start()
        deadline = time.perf_counter() + 5.0
        while cam.captured_frames < 3 and time.perf_counter() < deadline:
            time.sleep(0.02)

        # A UVC webcam allows exactly one consumer. On Windows a second
        # opener can succeed and then receive nothing, which would show up
        # here as a confusing "no newer frame" failure rather than as the
        # resource conflict it actually is. Detect that and say so.
        before = cam.captured_frames
        time.sleep(0.3)
        if cam.captured_frames <= before:
            print("  [SKIP] camera opened but is not delivering frames.")
            print("         Another process is almost certainly holding it --")
            print("         stop pc/scripts/serve.py (or Teams/Zoom) and re-run.")
            return

        f1, new1 = cam.latest()
        check("first latest() returns a new frame", f1 is not None and new1)
        f2, new2 = cam.latest()
        check("immediate second latest() reports not-new",
              f2 is not None and not new2,
              "the same frame must not be reported as new twice")
        time.sleep(0.25)
        f3, new3 = cam.latest()
        check("after waiting, a newer frame arrives",
              f3 is not None and new3 and f3.seq > f1.seq,
              f"seq {f1.seq if f1 else '-'} -> {f3.seq if f3 else '-'}")
        check("frame carries a monotonic capture stamp",
              f3 is not None and f3.capture_ns > f1.capture_ns)
        check("frame is BGR HxWx3 uint8",
              f3 is not None and f3.image.ndim == 3
              and f3.image.shape[2] == 3 and f3.image.dtype == np.uint8)
    finally:
        cam.close()

L = HandLandmarkIndex


def synth_hand(pinch_gap: float = 1.8, curl: bool = False, point: bool = False,
               cx: float = 0.5, cy: float = 0.5, scale: float = 0.12):
    """Build a synthetic 21-landmark hand with a known palm length.

    pinch_gap is a multiple of palm length, so the expected pinch_ratio is
    exactly pinch_gap regardless of `scale`. That is what makes the
    scale-invariance assertion below meaningful.
    """
    lm = np.zeros((21, 3), dtype=np.float32)
    lm[L.WRIST] = (cx, cy + scale, 0)
    lm[L.MIDDLE_MCP] = (cx, cy, 0)
    ext = 1.4 if not curl else 0.25
    for mcp, pip, tip, dx in (
        (L.INDEX_MCP, L.INDEX_PIP, L.INDEX_TIP, -0.35),
        (L.MIDDLE_MCP, L.MIDDLE_PIP, L.MIDDLE_TIP, -0.1),
        (L.RING_MCP, L.RING_PIP, L.RING_TIP, 0.15),
        (L.PINKY_MCP, L.PINKY_PIP, L.PINKY_TIP, 0.4),
    ):
        e = ext
        if point:
            e = 1.4 if tip == L.INDEX_TIP else 0.25
        lm[mcp] = (cx + dx * scale, cy, 0)
        lm[pip] = (cx + dx * scale, cy - 0.45 * scale, 0)
        lm[tip] = (cx + dx * scale, cy - e * scale, 0)
    it = lm[L.INDEX_TIP]
    lm[L.THUMB_TIP] = (it[0] + pinch_gap * scale, it[1], 0)
    lm[L.THUMB_IP] = (cx + 0.6 * scale, cy - 0.2 * scale, 0)
    lm[L.THUMB_MCP] = (cx + 0.7 * scale, cy + 0.2 * scale, 0)
    lm[L.THUMB_CMC] = (cx + 0.6 * scale, cy + 0.5 * scale, 0)
    return lm


def _hand(lm, handed="Right", i=0):
    return HandState(i, handed, 0.99, lm, None)


def _tf(hands, fid=0):
    return TrackingFrame(fid, FrameStamps(capture_ns=time.perf_counter_ns()),
                         tuple(hands), 640, 480)


def test_measurements() -> None:
    print("\n[5] Scale-invariant hand measurements")
    open_lm = synth_hand(pinch_gap=1.8)
    pinch_lm = synth_hand(pinch_gap=0.25)
    check("palm length matches the synthetic scale",
          abs(palm_length(open_lm) - 0.12) < 0.005, f"{palm_length(open_lm):.4f}")
    check("open hand reads a high pinch ratio", pinch_ratio(open_lm) > 1.2,
          f"{pinch_ratio(open_lm):.3f}")
    check("pinched hand reads a low pinch ratio", pinch_ratio(pinch_lm) < 0.45,
          f"{pinch_ratio(pinch_lm):.3f}")

    # The reason every measurement is divided by palm length: the same gesture
    # at a different distance from the camera must give the same number.
    far = synth_hand(pinch_gap=0.25, scale=0.06)
    check("pinch ratio is invariant to hand distance",
          abs(pinch_ratio(pinch_lm) - pinch_ratio(far)) < 0.01,
          f"{pinch_ratio(pinch_lm):.4f} vs {pinch_ratio(far):.4f}")

    check("open hand: all fingers extended", all(fingers_extended(open_lm)))
    check("fist: no fingers extended (thumb ignored)",
          sum(fingers_extended(synth_hand(pinch_gap=1.8, curl=True))[1:]) == 0)
    ext = fingers_extended(synth_hand(pinch_gap=1.8, point=True))
    check("point: index only", ext[1] and not any(ext[2:]), str(ext))


def test_filters() -> None:
    print("\n[6] Filters")
    f = OneEuroFilter(min_cutoff=1.2, beta=0.03)
    t = 0.0
    out = None
    for _ in range(40):
        t += 1 / 30
        out = f(np.array([1.0, 2.0, 3.0]), t)
    check("One Euro converges on a constant signal",
          bool(np.allclose(out, [1.0, 2.0, 3.0], atol=0.01)), str(out))

    f2 = OneEuroFilter(min_cutoff=1.2, beta=0.03)
    t = 0.0
    outs = []
    for i in range(60):
        t += 1 / 30
        outs.append(float(f2(np.array([1.0 + 0.05 * ((-1) ** i)]), t)[0]))
    spread = max(outs[20:]) - min(outs[20:])
    check("One Euro attenuates jitter", spread < 0.05,
          f"output spread {spread:.4f} against input spread 0.10")

    h = Hysteresis(on_below=0.45, off_above=0.60)
    flips = 0
    prev = h.state
    for i in range(40):
        s = h.update(0.52 + 0.02 * np.sin(i * 1.7))
        if s != prev:
            flips += 1
        prev = s
    check("hysteresis does not chatter inside its band", flips == 0,
          f"{flips} state flips")
    check("hysteresis engages below the on threshold", h.update(0.2) is True)
    check("hysteresis holds between the thresholds", h.update(0.5) is True)
    check("hysteresis releases above the off threshold", h.update(0.7) is False)

    bad = False
    try:
        Hysteresis(on_below=0.6, off_above=0.4)
    except ValueError:
        bad = True
    check("an inverted hysteresis band is rejected", bad)


def test_gesture_engine() -> None:
    print("\n[7] Interaction engine")
    cfg = load_config().gesture
    eng = InteractionEngine(cfg)
    clock = {"t": 0.0}

    def step(hands, dt=1 / 30):
        clock["t"] += dt
        return eng.process(_tf(hands), clock["t"])

    cases = [
        ("open palm", synth_hand(pinch_gap=1.8),
         GestureKind.OPEN_PALM, InteractionKind.IDLE),
        ("fist", synth_hand(pinch_gap=1.8, curl=True),
         GestureKind.FIST, InteractionKind.PAUSED),
        ("point", synth_hand(pinch_gap=1.8, point=True),
         GestureKind.POINT, InteractionKind.SELECT),
        ("pinch", synth_hand(pinch_gap=0.25),
         GestureKind.PINCH, InteractionKind.TRANSLATE),
    ]
    fr = None
    for label, lm, want_g, want_i in cases:
        eng.reset()
        clock["t"] += 1.0
        for _ in range(6):
            fr = step([_hand(lm)])
        check(f"{label} classifies as {want_g.value}",
              fr.gestures[0].kind is want_g, fr.gestures[0].kind.value)
        check(f"{label} maps to {want_i.value}",
              fr.command.kind is want_i, fr.command.kind.value)

    # Grab-and-move: a pinched hand dragging sideways translates the object.
    eng.reset()
    clock["t"] += 1.0
    for _ in range(4):
        step([_hand(synth_hand(pinch_gap=0.25, cx=0.5))])
    total_x = 0.0
    for i in range(12):
        fr = step([_hand(synth_hand(pinch_gap=0.25, cx=0.5 + 0.012 * i))])
        total_x += fr.command.position_delta[0]
    check("dragging a pinch right moves the object +X", total_x > 0.05,
          f"{total_x:+.4f}")
    check("a drag emits no rotation any more",
          fr.command.rotation_delta == (0.0, 0.0, 0.0),
          str(fr.command.rotation_delta))

    eng.reset()
    clock["t"] += 1.0
    for _ in range(4):
        step([_hand(synth_hand(pinch_gap=0.25, cy=0.5))])
    total_y = 0.0
    for i in range(12):
        fr = step([_hand(synth_hand(pinch_gap=0.25, cy=0.5 + 0.012 * i))])
        total_y += fr.command.position_delta[1]
    check("dragging a pinch down moves the object -Y", total_y < -0.05,
          f"{total_y:+.4f}")
    check("translation never exceeds the per-frame clamp",
          abs(fr.command.position_delta[0]) <= cfg.max_translate_step + 1e-9)

    # One-hand two-finger spread scales.
    eng.reset()
    clock["t"] += 2.0
    for _ in range(5):
        step([_hand(synth_hand(pinch_gap=0.9))])
    # Stay below pinch_open_ratio: GestureState.pinch saturates at 1.0, and a
    # saturated control cannot be tested for reversibility.
    spread_total = 0.0
    for i in range(14):
        gap = 0.9 + 0.035 * i
        fr = step([_hand(synth_hand(pinch_gap=gap))])
        spread_total += fr.command.scale_delta
    check("opening thumb and index scales up", spread_total > 0.05,
          f"{spread_total:+.4f}")

    close_total = 0.0
    for i in range(14):
        gap = 0.9 + 0.035 * (13 - i)
        close_total += step([_hand(synth_hand(pinch_gap=gap))]).command.scale_delta
    check("closing thumb and index scales down", close_total < -0.05,
          f"{close_total:+.4f}")
    for _ in range(25):        # let the One Euro filter settle before judging
        close_total += step([_hand(synth_hand(pinch_gap=0.9))]).command.scale_delta
    check("two-finger spread is reversible",
          abs(spread_total + close_total) < 0.15,
          f"net {spread_total + close_total:+.4f}")

    # Releasing a grab opens the fingers, which must NOT be read as a
    # deliberate spread and inflate the object.
    eng.reset()
    clock["t"] += 2.0
    for _ in range(6):
        step([_hand(synth_hand(pinch_gap=0.25))])       # grabbing
    after_release = 0.0
    for i in range(8):
        gap = 0.25 + 0.2 * i                            # fingers springing open
        after_release += step([_hand(synth_hand(pinch_gap=gap))]).command.scale_delta
    check("releasing a grab does not scale the object",
          abs(after_release) < 1e-9, f"{after_release:+.4f}")

    eng.reset()
    clock["t"] += 1.0

    def two(d):
        return [_hand(synth_hand(pinch_gap=0.25, cx=0.40 - d), "Right", 0),
                _hand(synth_hand(pinch_gap=0.25, cx=0.60 + d), "Left", 1)]

    for _ in range(4):
        step(two(0))
    out_total = 0.0
    for i in range(12):
        fr = step(two(0.010 * i))
        out_total += fr.command.scale_delta
    check("hands moving apart scales up", out_total > 0.05, f"{out_total:+.4f}")
    check("two-hand pinch reports SCALE",
          fr.command.kind is InteractionKind.SCALE, fr.command.kind.value)

    back_total = 0.0
    for i in range(12):
        back_total += step(two(0.010 * (11 - i))).command.scale_delta
    for _ in range(25):                     # let the One Euro filter settle
        back_total += step(two(0)).command.scale_delta
    net = out_total + back_total
    # Deltas are log-space, so the gesture is reversible by construction; the
    # residual is deadzone loss, not drift.
    check("scale is reversible (out and back returns near the original size)",
          abs(net) < 0.12,
          f"net log delta {net:+.4f} -> factor {float(np.exp(net)):.3f}")

    eng.reset()
    clock["t"] += 1.0
    for _ in range(5):
        fr = step([_hand(synth_hand(pinch_gap=1.8, curl=True))])
    check("a held fist pauses",
          eng.paused and fr.command.kind is InteractionKind.PAUSED)
    for _ in range(5):
        fr = step([_hand(synth_hand(pinch_gap=0.25))])
    check("pinching while paused stays paused",
          fr.command.kind is InteractionKind.PAUSED, fr.command.kind.value)
    for _ in range(6):
        fr = step([_hand(synth_hand(pinch_gap=1.8))])
    check("a held open palm resumes", not eng.paused)

    eng.reset()
    fr = step([])
    check("no hands yields an idle command",
          fr.command.kind is InteractionKind.IDLE and fr.command.is_idle)


def test_spaces() -> None:
    print("\n[8] Coordinate spaces")
    space = CameraToInteraction(ActiveRegion(0.15, 0.85, 0.15, 0.85), aspect=1.0)
    cx, cy, _ = space.point((0.5, 0.5, 0.0))
    check("frame centre maps to the interaction origin",
          abs(cx) < 1e-6 and abs(cy) < 1e-6, f"({cx}, {cy})")
    rx, _, _ = space.point((0.85, 0.5, 0.0))
    check("right edge of the active region maps to +1",
          abs(rx - 1.0) < 1e-6, str(rx))
    _, ty, _ = space.point((0.5, 0.15, 0.0))
    check("image y is inverted, so the top of frame is +1",
          abs(ty - 1.0) < 1e-6, str(ty))

    check("deadzone zeroes sub-threshold motion",
          apply_deadzone(0.003, 0.01) == 0.0)
    check("deadzone rescales, so there is no step at the boundary",
          abs(apply_deadzone(0.0101, 0.01)) < 0.002,
          "a naive deadzone would jump straight to 0.0101")
    check("deadzone preserves sign", apply_deadzone(-0.5, 0.01) < 0)

    bad = False
    try:
        ActiveRegion(0.9, 0.1, 0.15, 0.85).validate()
    except ValueError:
        bad = True
    check("an inverted active region is rejected", bad)


def main() -> int:
    print("=" * 62)
    print(" hologram-system :: self-test")
    print("=" * 62)
    if not ensure_fixture():
        return 1
    test_topology()
    test_live_stream()
    test_timestamp_monotonicity()
    test_camera_latest_wins()
    test_measurements()
    test_filters()
    test_gesture_engine()
    test_spaces()
    print("\n" + "=" * 62)

    print("=" * 62)
    return 1 if failed else 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```
    python pc\\scripts\\serve.py
    python pc\\scripts\\serve.py --port 8080 --no-camera

Prints the LAN address to open on the iPhone.

from __future__ import annotations

import argparse
import logging
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent.parent))

from aiohttp import web

from hologram_pc.config import load_config
from hologram_pc.pipeline import Pipeline
from hologram_pc.server.app import build_app, local_ip
from hologram_pc.vision.camera import CameraError
from hologram_pc.vision.hand_landmarker import LandmarkerError


def main() -> int:
    ap = argparse.ArgumentParser(description=__doc__,
                                 formatter_class=argparse.RawDescriptionHelpFormatter)
    ap.add_argument("--port", type=int, default=None)
    ap.add_argument("--host", default=None)
    ap.add_argument("--camera-index", type=int, default=None)
    ap.add_argument("--backend", choices=["dshow", "msmf", "any"], default=None)
    ap.add_argument("--no-camera", action="store_true",
                    help="serve the client without starting the vision pipeline")
    args = ap.parse_args()

    overrides = {}
    if args.port or args.host:
        overrides["network"] = {}
        if args.port:
            overrides["network"]["port"] = args.port
        if args.host:
            overrides["network"]["host"] = args.host
    if args.camera_index is not None or args.backend:
        overrides["camera"] = {}
        if args.camera_index is not None:
            overrides["camera"]["index"] = args.camera_index
        if args.backend:
            overrides["camera"]["backend"] = args.backend

    cfg = load_config(overrides)
    logging.basicConfig(
        level=getattr(logging, cfg.diagnostics.log_level.upper(), logging.INFO),
        format="%(levelname)-7s %(name)s: %(message)s")

    pipeline = Pipeline(cfg)
    if not args.no_camera:
        try:
            pipeline.start()
        except LandmarkerError as e:
            print(f"\n[FAIL] {e}\n", file=sys.stderr)
            return 2
        except CameraError as e:
            print(f"\n[FAIL] {e}\n", file=sys.stderr)
            print("       Start without the camera using --no-camera to test "
                  "the client bundle alone.\n", file=sys.stderr)
            return 3

    app = build_app(cfg, pipeline)
    ip = local_ip()
    port = cfg.network.port

    print()

    print(" HOLOGRAM SYSTEM")
    print("=" * 62)
    print(f"  PC development UI :  http://localhost:{port}/")
    print(f"  iPhone hologram   :  http://{ip}:{port}/?mode=hologram")
    print()
    print("  On the iPhone:")
    print("   1. Join the same Wi-Fi network as this PC.")
    print(f"   2. Open Safari and go to  http://{ip}:{port}/")
    print("   3. Tap ENTER HOLOGRAM MODE.")
    print("   4. Place the phone under the pyramid, face up.")

    if not (Path(cfg.network.resolved_client_dist()) / "index.html").exists():

        print("           cd client && npm install && npm run build")

        print(f"\n[FAIL] Could not bind {cfg.network.host}:{port} -- {e}")
        print("       Another process may be using the port. Try --port 8081.")
        return 4
    except KeyboardInterrupt:
        pass
    return 0


if __name__ == "__main__":
```

```
"""End-to-end WebSocket protocol test against a running server.

    python pc\\scripts\\serve.py --port 8137      (in one terminal)
    python pc\\scripts\\test_protocol.py --port 8137

Verifies the whole PC-side network path that the iPhone depends on:
handshake, the 60 Hz control stream, opt-in debug stream, ping/pong RTT,
object switching, and that message sizes are actually small.
"""

from __future__ import annotations

import argparse
import asyncio
import json
import sys
import time
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent.parent))

import aiohttp

passed = 0
failed = 0


def check(label: str, ok: bool, detail: str = "") -> bool:
    global passed, failed
    if ok:
        passed += 1
        print(f"  [ OK ] {label}")
    else:
        failed += 1
        print(f"  [FAIL] {label}" + (f"\n         {detail}" if detail else ""))
    return ok


async def run(port: int, host: str) -> int:
    base = f"http://{host}:{port}"
    async with aiohttp.ClientSession() as session:

        print("\n[1] HTTP endpoints")
        async with session.get(f"{base}/api/status") as r:
            check("GET /api/status is 200", r.status == 200)
            status = await r.json()
        check("pipeline reports running", bool(status.get("running")),
              f"error={status.get('error')}")
        check("camera at or near 30 fps",
              status.get("camera_fps", 0) >= 25,
              f"got {status.get('camera_fps')}")
        check("object catalog is exposed", len(status.get("objects", [])) >= 2)

        async with session.get(f"{base}/") as r:
            body = await r.text()
            check("GET / serves the client bundle",
                  r.status == 200 and "<div id=\"app\">" in body)

        print("\n[2] WebSocket handshake")
        async with session.ws_connect(f"ws://{host}:{port}/ws") as ws:
            raw = await asyncio.wait_for(ws.receive_str(), timeout=5)
            hello = json.loads(raw)
            check("first message is hello", hello.get("t") == "hello", raw[:120])
            check("hello carries protocol version", hello.get("v") == 1)
            check("hello carries staleMs and sendHz",
                  "staleMs" in hello and "sendHz" in hello)
            check("hello lists objects", len(hello.get("objects", [])) >= 2)

            print("\n[3] Control stream")
            controls = []
            sizes = []
            deadline = time.perf_counter() + 4.0
            stats_seen = False
            while time.perf_counter() < deadline and len(controls) < 40:
                try:
                    raw = await asyncio.wait_for(ws.receive_str(), timeout=2)
                except asyncio.TimeoutError:
                    break
                msg = json.loads(raw)
                if msg.get("t") == "oc":
                    controls.append(msg)
                    sizes.append(len(raw))
                elif msg.get("t") == "stats":
                    stats_seen = True

            check("received object_control messages", len(controls) > 0,
                  f"got {len(controls)}")
            check("received stats messages", stats_seen)
            if controls:
                avg = sum(sizes) / len(sizes)
                check("control messages stay small (<250 bytes avg)", avg < 250,
                      f"avg {avg:.0f} bytes")
                print(f"         avg {avg:.0f} B, max {max(sizes)} B, "
                      f"{len(controls)} msgs")
                ts = [c["ts"] for c in controls]
                check("timestamps are strictly increasing",
                      all(b > a for a, b in zip(ts, ts[1:])),
                      "a client relying on stale-rejection would stall otherwise")
                required = {"t", "ts", "id", "ia", "g", "n"}
                check("every control has the required fields",
                      all(required <= set(c) for c in controls))
                idle = [c for c in controls if "r" not in c and "s" not in c]
                check("idle frames omit zero deltas", len(idle) > 0,
                      "zero fields should not be serialised")

            print("\n[4] Ping / pong")
            sent = time.perf_counter() * 1000
            await ws.send_str(json.dumps({"t": "ping", "cts": sent}))
            pong = None
            for _ in range(60):
                msg = json.loads(await asyncio.wait_for(ws.receive_str(), timeout=2))
                if msg.get("t") == "pong":
                    pong = msg
                    break
            check("pong received", pong is not None)
            if pong:
                check("pong echoes the client stamp", pong.get("cts") == sent)
                rtt = time.perf_counter() * 1000 - sent
                check("loopback RTT under 50 ms", rtt < 50, f"{rtt:.1f} ms")
                print(f"         loopback RTT {rtt:.2f} ms")

            print("\n[5] Debug stream is opt-in")
            got_debug = False
            for _ in range(30):
                msg = json.loads(await asyncio.wait_for(ws.receive_str(), timeout=2))
                if msg.get("t") == "hd":
                    got_debug = True
                    break
            check("no landmark stream before subscribing", not got_debug,
                  "the iPhone must never receive landmark payloads")

            await ws.send_str(json.dumps({"t": "subscribe", "debug": True}))
            debug_msg = None
            deadline = time.perf_counter() + 3.0
            while time.perf_counter() < deadline:
                msg = json.loads(await asyncio.wait_for(ws.receive_str(), timeout=2))
                if msg.get("t") == "hd":
                    debug_msg = msg
                    break
            check("landmark stream arrives after subscribing", debug_msg is not None)
            if debug_msg:
                check("debug carries frame dimensions",
                      debug_msg.get("w", 0) > 0 and debug_msg.get("h", 0) > 0)
                for hand in debug_msg.get("hands", []):
                    check("landmarks are a flat array of 63 numbers",
                          len(hand.get("lm", [])) == 63,
                          f"got {len(hand.get('lm', []))}")

            print("\n[6] Object switching")
            await ws.send_str(json.dumps({"t": "set_object", "object": "core"}))
            switched = None
            deadline = time.perf_counter() + 3.0
            while time.perf_counter() < deadline:
                msg = json.loads(await asyncio.wait_for(ws.receive_str(), timeout=2))
                if msg.get("t") == "object":
                    switched = msg
                    break
            check("object switch is broadcast", switched is not None
                  and switched.get("object") == "core")
            await ws.send_str(json.dumps({"t": "set_object", "object": "atom"}))

            print("\n[7] Bad input does not kill the connection")
            await ws.send_str("this is not json")
            await ws.send_str(json.dumps({"t": "nonsense", "x": 1}))
            await ws.send_str(json.dumps({"t": "set_object", "object": "does-not-exist"}))
            still_alive = False
            deadline = time.perf_counter() + 3.0
            while time.perf_counter() < deadline:
                try:
                    msg = json.loads(await asyncio.wait_for(ws.receive_str(), timeout=2))
                except asyncio.TimeoutError:
                    break
                if msg.get("t") in ("oc", "stats"):
                    still_alive = True
                    break
            check("server keeps streaming after malformed input", still_alive)

        print("\n[8] Multiple clients")
        async with session.ws_connect(f"ws://{host}:{port}/ws") as a, \
                   session.ws_connect(f"ws://{host}:{port}/ws") as b:
            ha = json.loads(await asyncio.wait_for(a.receive_str(), timeout=5))
            hb = json.loads(await asyncio.wait_for(b.receive_str(), timeout=5))
            check("both clients get hello",
                  ha.get("t") == "hello" and hb.get("t") == "hello")
            got_a = got_b = False
            deadline = time.perf_counter() + 3.0
            while time.perf_counter() < deadline and not (got_a and got_b):
                if not got_a:
                    m = json.loads(await asyncio.wait_for(a.receive_str(), timeout=2))
                    got_a = m.get("t") == "oc"
                if not got_b:
                    m = json.loads(await asyncio.wait_for(b.receive_str(), timeout=2))
                    got_b = m.get("t") == "oc"
            check("both clients receive the control stream", got_a and got_b)

        async with session.get(f"{base}/api/status") as r:
            after = await r.json()
        check("server counted the packets it sent",
              after.get("packets_sent", 0) > 0,
              f"packets_sent={after.get('packets_sent')}")

    print("\n" + "=" * 62)
    print(f" {passed} passed, {failed} failed")
    print("=" * 62)
    return 1 if failed else 0


def main() -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--port", type=int, default=8080)
    ap.add_argument("--host", default="127.0.0.1")
    args = ap.parse_args()
    print("=" * 62)
    print(f" Protocol test against {args.host}:{args.port}")
    print("=" * 62)
    try:
        return asyncio.run(run(args.port, args.host))
    except aiohttp.ClientConnectorError:
        print(f"\n[FAIL] Could not connect to {args.host}:{args.port}.")
        print("       Start the server first:  python pc\\scripts\\serve.py")
        return 2


if __name__ == "__main__":
    raise SystemExit(main())
```

```
/**
 * The render stage: owns the WebGL renderer, the scene, the active object,
 * and the requestAnimationFrame loop.
 *
 * Rules enforced here:
 *  - one rAF loop, never setTimeout/setInterval for rendering
 *  - no allocation inside the loop (the InteractionInput object is reused)
 *  - the object is told about interaction only when something arrived
 *  - dt is clamped, so returning from a backgrounded tab does not fling the
 *    object across a whole second of accumulated animation
 */

import { Scene, WebGLRenderer } from 'three'

import { FourViewCompositor } from '../hologram/FourViewCompositor'
import type { PyramidCalibration } from '../hologram/calibration'
import type { ViewName } from '../hologram/calibration'
import { createObject } from '../objects/registry'
import type { HologramObject, InteractionInput } from '../objects/HologramObject'
import { clearPending, hot, noteFrame } from '../state/realtime'
import { TestPattern } from '../hologram/testPattern'

export type StageMode = 'four-view' | 'single'

export class WebGLUnavailableError extends Error {}

export class Stage {
  readonly renderer: WebGLRenderer
  readonly scene = new Scene()
  readonly compositor: FourViewCompositor

  private object: HologramObject | null = null
  private objectId = ''
  private raf = 0
  private lastTime = 0
  private elapsed = 0
  private running = false
  private calibration: PyramidCalibration | null = null
  private testPattern: TestPattern | null = null
  private showTestPattern = false

  mode: StageMode = 'four-view'
  singleView: ViewName = 'front'
  performanceMode = false

  // Reused every frame: allocating this inside the loop would create ~60
  // short-lived objects per second and hand the GC work during animation.
  private readonly input: InteractionInput = {
    rotationDelta: [0, 0, 0],
    scaleDelta: 0,
    positionDelta: [0, 0, 0],
    interaction: 'idle',
    gesture: 'none',
    pinch: 1,
    hands: 0,
    confidence: 0,
  }

  constructor(canvas: HTMLCanvasElement, opts: { resolution?: number } = {}) {
    let renderer: WebGLRenderer
    try {
      renderer = new WebGLRenderer({
        canvas,
        antialias: true,
        alpha: false,
        powerPreference: 'high-performance',
        // The pyramid shows reflected light on black; preserving the buffer
        // is unnecessary and costs memory bandwidth on mobile GPUs.
        preserveDrawingBuffer: false,
      })
    } catch (err) {
      throw new WebGLUnavailableError(
        `WebGL is unavailable in this browser: ${String(err)}`,
      )
    }
    if (!renderer.getContext()) {
      throw new WebGLUnavailableError('WebGL context could not be created.')
    }

    this.renderer = renderer
    // Cap DPR at 2. iPhone reports 3, which would mean 9x the fragments for
    // no visible gain through acrylic.
    this.renderer.setPixelRatio(Math.min(window.devicePixelRatio || 1, 2))
    this.renderer.setClearColor(0x000000, 1)
    this.renderer.autoClear = false

    this.compositor = new FourViewCompositor(this.renderer, {
      resolution: opts.resolution ?? 512,
    })

    // Context loss is real on mobile Safari when the tab is backgrounded.
    canvas.addEventListener('webglcontextlost', (e) => {
      e.preventDefault()
      this.stop()
      console.warn('[stage] WebGL context lost')
    })
    canvas.addEventListener('webglcontextrestored', () => {
      console.warn('[stage] WebGL context restored')
      this.start()
    })
  }

  setObject(id: string): void {
    if (id === this.objectId) return
    this.object?.dispose()
    if (this.object) this.scene.clear()
    this.object = createObject(id)
    this.objectId = id
    hot.objectId = id
    this.scene.add(this.object.createScene())
    this.compositor.setObjectRadius(this.object.metadata.radius)
    if (this.testPattern) this.scene.add(this.testPattern.root)
  }

  getObjectId(): string {
    return this.objectId
  }

  setCalibration(cal: PyramidCalibration): void {
    this.calibration = cal
    this.compositor.applyCalibration(cal)
    this.renderer.setClearColor(cal.pyramid.background, 1)
  }

  setTestPattern(enabled: boolean): void {
    this.showTestPattern = enabled
    if (enabled && !this.testPattern) {
      this.testPattern = new TestPattern()
      this.scene.add(this.testPattern.root)
    }
    if (this.testPattern) this.testPattern.root.visible = enabled
    if (this.object) {
      // Hide the object during calibration so only the alignment marks show.
      this.scene.children.forEach((c) => {
        if (c !== this.testPattern?.root) c.visible = !enabled
      })
    }
  }

  setSize(width: number, height: number): void {
    this.renderer.setSize(width, height, false)
    this.compositor.setSize(width, height)
    if (this.calibration) this.compositor.applyCalibration(this.calibration)
  }

  setPerformanceMode(on: boolean): void {
    this.performanceMode = on
    // Halving render-target resolution quarters the fragment work for the
    // four scene passes, which is where the phone's time actually goes.
    this.compositor.setResolution(on ? 384 : 512)
    this.renderer.setPixelRatio(on ? 1 : Math.min(window.devicePixelRatio || 1, 2))
  }

  start(): void {
    if (this.running) return
    this.running = true
    this.lastTime = performance.now()
    const loop = (now: number) => {
      if (!this.running) return
      this.raf = requestAnimationFrame(loop)
      this.frame(now)
    }
    this.raf = requestAnimationFrame(loop)
  }

  stop(): void {
    this.running = false
    if (this.raf) cancelAnimationFrame(this.raf)
    this.raf = 0
  }

  private frame(now: number): void {
    // Clamp: a backgrounded tab can hand us a dt of many seconds.
    const dt = Math.min(0.1, (now - this.lastTime) / 1000)
    this.lastTime = now
    this.elapsed += dt

    if (this.object) {
      if (hot.hasPending) {
        const i = this.input
        i.rotationDelta[0] = hot.pendingRotation[0]
        i.rotationDelta[1] = hot.pendingRotation[1]
        i.rotationDelta[2] = hot.pendingRotation[2]
        i.scaleDelta = hot.pendingScale
        i.positionDelta[0] = hot.pendingPosition[0]
        i.positionDelta[1] = hot.pendingPosition[1]
        i.positionDelta[2] = hot.pendingPosition[2]
        i.interaction = hot.interaction
        i.gesture = hot.gesture
        i.pinch = hot.pinch
        i.hands = hot.hands
        i.confidence = hot.confidence
        this.object.handleInteraction(i)
        clearPending()
      }

      if (hot.energy > 0 || hot.speaking) {
        this.object.handleEnergy?.({
          amplitude: hot.amplitude,
          energy: hot.energy,
          speaking: hot.speaking,
          bands: [],
        })
      }

      this.object.update({ dt, elapsed: this.elapsed })
    }

    if (this.testPattern && this.showTestPattern) {
      this.testPattern.update(dt)
    }

    if (this.mode === 'four-view') {
      this.compositor.render(this.scene)
    } else {
      this.compositor.renderSingle(this.scene, this.singleView)
    }

    noteFrame(performance.now() - now)
  }

  dispose(): void {
    this.stop()
    this.object?.dispose()
    this.testPattern?.dispose()
    this.compositor.dispose()
    this.renderer.dispose()
  }
}
```

### client/src/hologram/FourViewCompositor.ts
```
/**
 * Four-view hologram compositor.
 *
 * Renders the same scene from four virtual cameras 90 degrees apart, then
 * arranges those four images around the screen centre in the layout the
 * physical pyramid needs.
 *
 * Implementation choice -- render targets plus textured quads, rather than
 * four scissored viewport passes:
 *
 *   A scissor pass can place a view, but it cannot rotate or mirror it. The
 *   brief requires per-view rotate 0/90/180/270 and independent mirror X/Y,
 *   because the reflection parity through the acrylic is not knowable in
 *   advance. Rotating via camera roll would work; mirroring via a negative
 *   scale flips triangle winding and silently breaks backface culling.
 *   Compositing textures sidesteps both problems: the transform is applied to
 *   a quad after the scene is already rasterised, so it cannot affect scene
 *   rendering at all.
 *
 * Cost is four scene passes plus one composite pass. On the phone the scene
 * is a handful of additive primitives, so this holds 60 fps comfortably.
 */

import {
  AdditiveBlending,
  LinearFilter,
  Mesh,
  MeshBasicMaterial,
  OrthographicCamera,
  PerspectiveCamera,
  PlaneGeometry,
  RGBAFormat,
  Scene,
  Vector3,
  WebGLRenderTarget,
  type WebGLRenderer,
} from 'three'

import { VIEW_NAMES, type PyramidCalibration, type ViewName } from './calibration'

/** Direction each camera sits in, and which screen edge its view maps to. */
const VIEW_LAYOUT: Record<ViewName, { azimuth: number; dir: [number, number] }> = {
  // azimuth: camera position around Y. dir: unit vector toward the screen edge.
  front: { azimuth: 0, dir: [0, -1] },
  right: { azimuth: Math.PI / 2, dir: [1, 0] },
  back: { azimuth: Math.PI, dir: [0, 1] },
  left: { azimuth: -Math.PI / 2, dir: [-1, 0] },
}

interface ViewSlot {
  name: ViewName
  camera: PerspectiveCamera
  target: WebGLRenderTarget
  quad: Mesh
  material: MeshBasicMaterial
}

export interface CompositorOptions {
  /** Edge length of each render target, in pixels. */
  resolution?: number
  /** Camera elevation above the object, in world units. */
  elevation?: number
  /** Camera distance from the object. */
  distance?: number
  fov?: number
}

export class FourViewCompositor {
  private renderer: WebGLRenderer
  private slots: ViewSlot[] = []
  private compositeScene = new Scene()
  private compositeCamera = new OrthographicCamera(-1, 1, 1, -1, -10, 10)
  private geometry = new PlaneGeometry(1, 1)
  private width = 1
  private height = 1
  private resolution: number
  private elevationDeg: number
  private distance: number
  private target = new Vector3(0, 0, 0)

  constructor(renderer: WebGLRenderer, opts: CompositorOptions = {}) {
    this.renderer = renderer
    this.resolution = opts.resolution ?? 512
    this.elevationDeg = opts.elevation ?? 12
    this.distance = opts.distance ?? 6.5

    for (const name of VIEW_NAMES) {
      const camera = new PerspectiveCamera(opts.fov ?? 42, 1, 0.1, 100)
      const target = new WebGLRenderTarget(this.resolution, this.resolution, {
        format: RGBAFormat,
        minFilter: LinearFilter,
        magFilter: LinearFilter,
        depthBuffer: true,
        stencilBuffer: false,
      })
      const material = new MeshBasicMaterial({
        map: target.texture,
        // Additive, not opaque.
        //
        // Four square views placed around the centre necessarily overlap at
        // their corners unless they are pushed a full view-width apart, which
        // would waste most of the screen. With opaque quads the last one drawn
        // paints its black corners over its neighbour's content -- visible as
        // a rectangular bite taken out of the adjacent view.
        //
        // Additive blending makes that impossible: the scene renders emissive
        // marks on black, and black adds nothing. Overlapping corners
        // contribute zero, so the views can sit edge-to-edge at the centre
        // exactly as the pyramid needs.
        transparent: true,
        blending: AdditiveBlending,
        depthTest: false,
        depthWrite: false,
      })
      const quad = new Mesh(this.geometry, material)
      quad.frustumCulled = false
      this.compositeScene.add(quad)
      this.slots.push({ name, camera, target, quad, material })
    }
    this.positionCameras()
  }

  /** Frame the cameras for an object of the given radius. */
  setObjectRadius(radius: number): void {
    // Fit the sphere of `radius` into the vertical FOV, with margin so the
    // glow does not clip at the frame edge.
    const slot = this.slots[0]
    const fov = (slot.camera.fov * Math.PI) / 180
    this.distance = (radius * 1.35) / Math.tan(fov / 2)
    this.positionCameras()
  }

  /** Virtual camera elevation, in degrees above the object's horizon. */
  setElevationDegrees(deg: number): void {
    this.elevationDeg = deg
    this.positionCameras()
  }

  private positionCameras(): void {
    const el = (this.elevationDeg * Math.PI) / 180
    // Keep the object the same size on screen as elevation changes: move the
    // camera along a sphere of constant distance rather than straight up.
    const horiz = Math.cos(el) * this.distance
    const vert = Math.sin(el) * this.distance
    for (const slot of this.slots) {
      const { azimuth } = VIEW_LAYOUT[slot.name]
      slot.camera.position.set(
        Math.sin(azimuth) * horiz,
        vert,
        Math.cos(azimuth) * horiz,
      )
      slot.camera.lookAt(this.target)
      slot.camera.updateProjectionMatrix()
    }
  }

  setSize(width: number, height: number): void {
    this.width = Math.max(1, width)
    this.height = Math.max(1, height)
    this.compositeCamera.left = -this.width / 2
    this.compositeCamera.right = this.width / 2
    this.compositeCamera.top = this.height / 2
    this.compositeCamera.bottom = -this.height / 2
    this.compositeCamera.updateProjectionMatrix()
  }

  /**
   * Apply calibration to the composited quads.
   *
   * View size is derived from the screen so a square view always fits: with
   * four views arranged around the centre, each may occupy at most half the
   * smaller screen dimension.
   */
  applyCalibration(cal: PyramidCalibration): void {
    if (cal.pyramid.cameraElevationDeg !== this.elevationDeg) {
      this.setElevationDegrees(cal.pyramid.cameraElevationDeg)
    }
    const base = Math.min(this.width, this.height) / 2
    const globalRot = (cal.pyramid.rotation * Math.PI) / 180

    for (const slot of this.slots) {
      const view = cal.views[slot.name]
      slot.quad.visible = view.enabled
      if (!view.enabled) continue

      const size = base * cal.pyramid.scale * view.scale
      const dist = size / 2 + cal.pyramid.gap

      const [dx, dy] = VIEW_LAYOUT[slot.name].dir
      // Rotate the placement direction by the global rotation so turning the
      // whole arrangement moves the views together rather than spinning each
      // in place.
      const cos = Math.cos(globalRot)
      const sin = Math.sin(globalRot)
      const px = (dx * cos - dy * sin) * dist
      const py = (dx * sin + dy * cos) * dist

      slot.quad.position.set(
        px + cal.pyramid.offsetX + view.offsetX,
        py + cal.pyramid.offsetY + view.offsetY,
        0,
      )
      slot.quad.scale.set(size, size, 1)
      slot.quad.rotation.z = globalRot + (view.rotation * Math.PI) / 180

      // Mirroring is done on the texture, not the quad, so it cannot affect
      // winding order or interact with the rotation above.
      const tex = slot.material.map
      if (tex) {
        tex.repeat.set(view.mirrorX ? -1 : 1, view.mirrorY ? -1 : 1)
        tex.offset.set(view.mirrorX ? 1 : 0, view.mirrorY ? 1 : 0)
        tex.needsUpdate = true
      }
    }
  }

  /** Render `scene` from all four cameras, then composite to the canvas. */
  render(scene: Scene): void {
    const previousTarget = this.renderer.getRenderTarget()
    for (const slot of this.slots) {
      if (!slot.quad.visible) continue
      this.renderer.setRenderTarget(slot.target)
      this.renderer.clear()
      this.renderer.render(scene, slot.camera)
    }
    this.renderer.setRenderTarget(previousTarget)
    this.renderer.clear()
    this.renderer.render(this.compositeScene, this.compositeCamera)
  }

  /** Render a single view full-screen. Used by the dev UI's clean object panel. */
  renderSingle(scene: Scene, view: ViewName = 'front'): void {
    const slot = this.slots.find((s) => s.name === view) ?? this.slots[0]
    const aspect = this.width / this.height
    if (slot.camera.aspect !== aspect) {
      slot.camera.aspect = aspect
      slot.camera.updateProjectionMatrix()
    }
    this.renderer.setRenderTarget(null)
    this.renderer.clear()
    this.renderer.render(scene, slot.camera)
    // Restore the square aspect the render targets need.
    slot.camera.aspect = 1
    slot.camera.updateProjectionMatrix()
  }

  /** Change render-target resolution at runtime (quality setting). */
  setResolution(resolution: number): void {
    if (resolution === this.resolution) return
    this.resolution = resolution
    for (const slot of this.slots) {
      slot.target.setSize(resolution, resolution)
    }
  }

  getCamera(view: ViewName): PerspectiveCamera {
    return (this.slots.find((s) => s.name === view) ?? this.slots[0]).camera
  }

  dispose(): void {
    for (const slot of this.slots) {
      slot.target.dispose()
      slot.material.dispose()
    }
    this.geometry.dispose()
    this.slots = []
    this.compositeScene.clear()
  }
}
```

### client/src/hologram/calibration.ts
```
/**
 * Pyramid calibration.
 *
 * No physical dimension is hard-coded in the renderer. Everything the acrylic
 * imposes -- how far each view sits from centre, which way it is rotated,
 * whether the reflection needs a mirror -- lives in this object, is editable
 * at runtime, and persists to localStorage.
 *
 * Why per-view mirroring is not optional: a pepper's-ghost pyramid shows the
 * viewer a *reflection*. Depending on which face is being viewed and how the
 * sheet is cut, that reflection may be parity-flipped. Getting it wrong looks
 * almost right, which is worse than looking obviously wrong -- text reads
 * backwards and rotation appears to run the wrong way. So each view carries
 * its own mirror flags rather than a single global setting.
 */

export type ViewName = 'front' | 'right' | 'back' | 'left'

export const VIEW_NAMES: ViewName[] = ['front', 'right', 'back', 'left']

export interface ViewCalibration {
  enabled: boolean
  /** degrees, applied to the composited quad: 0 | 90 | 180 | 270 */
  rotation: number
  mirrorX: boolean
  mirrorY: boolean
  /** multiplier on the view's edge length */
  scale: number
  /** pixel nudge from the computed position */
  offsetX: number
  offsetY: number
}

export interface PyramidCalibration {
  version: number
  pyramid: {
    /** Physical face angle of the acrylic. Recorded for the operator's notes. */
    angleDegrees: number
    /** Elevation of the four virtual cameras above the object, in degrees.
     *  This is the one that actually changes what you see: it decides how far
     *  "down onto" the object each pyramid face looks. Tune it to match how
     *  high above the pyramid you actually view from. */
    cameraElevationDeg: number
    /** Distance from screen centre to the inner edge of each view, in pixels. */
    gap: number
    /** Global multiplier on view size. */
    scale: number
    /** Global rotation of the whole arrangement, degrees. */
    rotation: number
    offsetX: number
    offsetY: number
    /** Background is pure black: any non-black pixel becomes visible light. */
    background: string
  }
  views: Record<ViewName, ViewCalibration>
}

const STORAGE_KEY = 'hologram.calibration.v1'

export function defaultCalibration(): PyramidCalibration {
  return {
    version: 1,
    pyramid: {
      angleDegrees: 45,
      cameraElevationDeg: 12,
      gap: 0,
      scale: 1,
      rotation: 0,
      offsetX: 0,
      offsetY: 0,
      background: '#000000',
    },
    views: {
      // Each view is rotated so its "down" points outward from the screen
      // centre, which is what puts the object upright on each pyramid face
      // when the phone lies flat with the pyramid apex at the centre.
      front: { enabled: true, rotation: 0, mirrorX: false, mirrorY: false, scale: 1, offsetX: 0, offsetY: 0 },
      right: { enabled: true, rotation: 90, mirrorX: false, mirrorY: false, scale: 1, offsetX: 0, offsetY: 0 },
      back: { enabled: true, rotation: 180, mirrorX: false, mirrorY: false, scale: 1, offsetX: 0, offsetY: 0 },
      left: { enabled: true, rotation: 270, mirrorX: false, mirrorY: false, scale: 1, offsetX: 0, offsetY: 0 },
    },
  }
}

/** Deep-merge a stored blob over the defaults so a partial or older save
 *  never leaves the renderer with an undefined field. */
export function normaliseCalibration(raw: unknown): PyramidCalibration {
  const base = defaultCalibration()
  if (!raw || typeof raw !== 'object') return base
  const input = raw as Partial<PyramidCalibration>
  const out: PyramidCalibration = {
    version: base.version,
    pyramid: { ...base.pyramid, ...(input.pyramid ?? {}) },
    views: { ...base.views },
  }
  for (const name of VIEW_NAMES) {
    out.views[name] = { ...base.views[name], ...((input.views ?? {})[name] ?? {}) }
    // Snap rotation to the four legal quarter turns.
    const r = ((Math.round(out.views[name].rotation / 90) * 90) % 360 + 360) % 360
    out.views[name].rotation = r
  }
  return out
}

export function loadCalibration(): PyramidCalibration {
  try {
    const raw = localStorage.getItem(STORAGE_KEY)
    if (!raw) return defaultCalibration()
    return normaliseCalibration(JSON.parse(raw))
  } catch {
    // Private browsing and blocked site data both throw here. A calibration
    // we cannot read is not a reason to fail to render.
    return defaultCalibration()
  }
}

export function saveCalibration(cal: PyramidCalibration): boolean {
  try {
    localStorage.setItem(STORAGE_KEY, JSON.stringify(cal))
    return true
  } catch {
    return false
  }
}

export function clearCalibration(): void {
  try {
    localStorage.removeItem(STORAGE_KEY)
  } catch {
    /* ignore */
  }
}

export function exportCalibration(cal: PyramidCalibration): string {
  return JSON.stringify(cal, null, 2)
}

export function importCalibration(json: string): PyramidCalibration {
  return normaliseCalibration(JSON.parse(json))
}
```

### client/src/hologram/testPattern.ts

```
/**
 * Physical alignment test pattern.
 *
 * Rendered *inside the scene*, so it goes through the same four virtual
 * cameras and the same compositor as the object does. That is the whole
 * point: a pattern drawn as a 2D overlay on the final canvas would prove the
 * canvas is aligned but say nothing about whether the view mapping is right.
 * Passing it through the real pipeline means if the pattern lines up on the
 * acrylic, the object will too.
 *
 * Contains everything the brief asks for: a large cross, FRONT/RIGHT/BACK/LEFT
 * labels, a centre point, a grid, and numbered corners.
 */

import {
  BufferGeometry,
  CanvasTexture,
  Float32BufferAttribute,
  Group,
  LineBasicMaterial,
  LineSegments,
  Mesh,
  MeshBasicMaterial,
  PlaneGeometry,
  SphereGeometry,
  Sprite,
  SpriteMaterial,
} from 'three'

const GRID_COLOR = 0x1e6f8f
const CROSS_COLOR = 0x39d0ff
const EXTENT = 2.4

export class TestPattern {
  readonly root = new Group()
  private disposables: Array<{ dispose(): void }> = []
  private spin = 0
  private marker?: Mesh

  constructor() {
    this.root.name = 'CalibrationTestPattern'
    this.buildGrid()
    this.buildCross()
    this.buildCentre()
    this.buildLabels()
    this.buildCorners()
  }

  private track<T extends { dispose(): void }>(x: T): T {
    this.disposables.push(x)
    return x
  }

  private buildGrid(): void {
    const pts: number[] = []
    const step = EXTENT / 4
    for (let i = -4; i <= 4; i++) {
      const v = i * step
      pts.push(-EXTENT, 0, v, EXTENT, 0, v)
      pts.push(v, 0, -EXTENT, v, 0, EXTENT)
    }
    const geo = this.track(new BufferGeometry())
    geo.setAttribute('position', new Float32BufferAttribute(pts, 3))
    const mat = this.track(new LineBasicMaterial({
      color: GRID_COLOR, transparent: true, opacity: 0.5,
    }))
    const grid = new LineSegments(geo, mat)
    grid.name = 'Grid'
    this.root.add(grid)
  }

  private buildCross(): void {
    const pts = [
      -EXTENT, 0, 0, EXTENT, 0, 0,
      0, 0, -EXTENT, 0, 0, EXTENT,
      0, -EXTENT * 0.6, 0, 0, EXTENT * 0.9, 0,
    ]
    const geo = this.track(new BufferGeometry())
    geo.setAttribute('position', new Float32BufferAttribute(pts, 3))
    const mat = this.track(new LineBasicMaterial({ color: CROSS_COLOR }))
    const cross = new LineSegments(geo, mat)
    cross.name = 'Cross'
    this.root.add(cross)
  }

  private buildCentre(): void {
    const geo = this.track(new SphereGeometry(0.08, 16, 16))
    const mat = this.track(new MeshBasicMaterial({ color: 0xffffff }))
    const dot = new Mesh(geo, mat)
    dot.name = 'CentrePoint'
    this.root.add(dot)

    // A slowly spinning marker: if the four views are consistent it sweeps
    // around all four faces in step. Inconsistent rotation shows up
    // immediately as the marker jumping between faces.
    const mGeo = this.track(new SphereGeometry(0.1, 12, 12))
    const mMat = this.track(new MeshBasicMaterial({ color: 0xffc451 }))
    this.marker = new Mesh(mGeo, mMat)
    this.marker.name = 'RotationMarker'
    this.root.add(this.marker)
  }

  private label(text: string, color: string): Sprite {
    // Canvas-drawn sprite: no font files to load, so the calibration pattern
    // works with no network access at all.
    const canvas = document.createElement('canvas')
    canvas.width = 256
    canvas.height = 128
    const ctx = canvas.getContext('2d')!
    ctx.fillStyle = 'rgba(0,0,0,0)'
    ctx.fillRect(0, 0, 256, 128)
    ctx.font = 'bold 56px system-ui, -apple-system, sans-serif'
    ctx.fillStyle = color
    ctx.textAlign = 'center'
    ctx.textBaseline = 'middle'
    ctx.fillText(text, 128, 64)
    const tex = this.track(new CanvasTexture(canvas))
    const mat = this.track(new SpriteMaterial({ map: tex, transparent: true }))
    const sprite = new Sprite(mat)
    sprite.scale.set(1.1, 0.55, 1)
    return sprite
  }

  private buildLabels(): void {
    // Each label sits on the side of the scene that the correspondingly named
    // camera looks from, so the FRONT camera sees the word FRONT.
    const specs: Array<[string, string, [number, number, number]]> = [
      ['FRONT', '#5ce1ff', [0, 0.35, EXTENT * 0.82]],
      ['RIGHT', '#7dff9b', [EXTENT * 0.82, 0.35, 0]],
      ['BACK', '#ffa1f0', [0, 0.35, -EXTENT * 0.82]],
      ['LEFT', '#ffd166', [-EXTENT * 0.82, 0.35, 0]],
    ]
    for (const [text, color, pos] of specs) {
      const sprite = this.label(text, color)
      sprite.position.set(pos[0], pos[1], pos[2])
      sprite.name = `Label_${text}`
      this.root.add(sprite)
    }
  }

  private buildCorners(): void {
    const corners: Array<[number, number]> = [[-1, -1], [1, -1], [1, 1], [-1, 1]]
    corners.forEach(([sx, sz], i) => {
      const sprite = this.label(String(i + 1), '#ffffff')
      sprite.scale.set(0.5, 0.5, 1)
      sprite.position.set(sx * EXTENT * 0.92, 0.12, sz * EXTENT * 0.92)
      sprite.name = `Corner${i + 1}`
      this.root.add(sprite)

      const geo = this.track(new PlaneGeometry(0.28, 0.28))
      const mat = this.track(new MeshBasicMaterial({ color: 0xffffff, transparent: true, opacity: 0.35 }))
      const pad = new Mesh(geo, mat)
      pad.rotation.x = -Math.PI / 2
      pad.position.set(sx * EXTENT * 0.92, 0, sz * EXTENT * 0.92)
      this.root.add(pad)
    })
  }

  update(dt: number): void {
    this.spin += dt * 0.6
    if (this.marker) {
      this.marker.position.set(
        Math.cos(this.spin) * EXTENT * 0.55,
        0.5,
        Math.sin(this.spin) * EXTENT * 0.55,
      )
    }
  }

  dispose(): void {
    for (const d of this.disposables) d.dispose()
    this.disposables = []
    this.root.clear()
  }
}
```

### client/src/net/client.ts
```
/**
 * WebSocket client with automatic reconnect, RTT measurement, and
 * stale-packet rejection.
 *
 * Stale rejection matters more than it sounds. Under Wi-Fi contention
 * messages can be delivered late but still in order, and a burst of queued
 * control frames applied all at once makes the object lurch. Every message
 * carries a timestamp; anything older than the newest already applied is
 * dropped outright.
 *
 * The clock skew problem: the PC's timeline and the phone's are unrelated, so
 * comparing `msg.ts` against `Date.now()` is meaningless. Instead the client
 * tracks the highest timestamp it has *seen* and rejects anything below it.
 * That needs no synchronised clock and is exactly the "discard obsolete
 * state" rule from the brief.
 */

import {
  decodeHandDebug,
  decodeObjectControl,
  type HandDebug,
  type ObjectControl,
  type WireHello,
  type WireMessage,
} from './protocol'

export type ConnectionState = 'connecting' | 'open' | 'closed' | 'error'

export interface ClientHandlers {
  onControl?(control: ObjectControl): void
  onHandDebug?(debug: HandDebug): void
  onHello?(hello: WireHello): void
  onStats?(stats: Record<string, unknown>): void
  onObjectSwitch?(objectId: string): void
  onEnergy?(e: { amplitude: number; energy: number; speaking: boolean; bands: number[] }): void
  onState?(state: ConnectionState, detail?: string): void
}

export interface ClientOptions {
  url?: string
  /** Ask the server for the landmark debug stream (dev UI only). */
  debug?: boolean
  pingIntervalMs?: number
}

export class HologramClient {
  private url: string
  private ws: WebSocket | null = null
  private handlers: ClientHandlers
  private wantDebug: boolean
  private pingIntervalMs: number
  private pingTimer: number | null = null
  private reconnectTimer: number | null = null
  private reconnectAttempt = 0
  private closedByUser = false

  /** Highest control timestamp applied so far; guards against stale frames. */
  private newestControlTs = -Infinity
  private newestDebugTs = -Infinity

  // Telemetry
  rtt = 0
  packets = 0
  dropped = 0
  lastMessageAt = 0
  state: ConnectionState = 'closed'

  constructor(handlers: ClientHandlers, opts: ClientOptions = {}) {
    this.handlers = handlers
    this.wantDebug = opts.debug ?? false
    this.pingIntervalMs = opts.pingIntervalMs ?? 2000
    this.url = opts.url ?? defaultWsUrl()
  }

  connect(): void {
    this.closedByUser = false
    this.setState('connecting')
    try {
      this.ws = new WebSocket(this.url)
    } catch (err) {
      this.setState('error', String(err))
      this.scheduleReconnect()
      return
    }

    this.ws.onopen = () => {
      this.reconnectAttempt = 0
      this.setState('open')
      this.send({ t: 'subscribe', debug: this.wantDebug })
      this.startPing()
    }

    this.ws.onmessage = (ev: MessageEvent<string>) => {
      this.packets++
      this.lastMessageAt = performance.now()
      let msg: WireMessage
      try {
        msg = JSON.parse(ev.data) as WireMessage
      } catch {
        return
      }
      this.dispatch(msg)
    }

    this.ws.onerror = () => {
      // The error event carries no useful detail in browsers; onclose follows.
      this.setState('error', 'socket error')
    }

    this.ws.onclose = (ev) => {
      this.stopPing()
      this.setState('closed', ev.reason || `code ${ev.code}`)
      if (!this.closedByUser) this.scheduleReconnect()
    }
  }

  private dispatch(msg: WireMessage): void {
    switch (msg.t) {
      case 'oc': {
        // Reject anything not newer than what we have already applied.
        if (msg.ts <= this.newestControlTs) {
          this.dropped++
          return
        }
        this.newestControlTs = msg.ts
        this.handlers.onControl?.(decodeObjectControl(msg))
        break
      }
      case 'hd': {
        if (msg.ts <= this.newestDebugTs) {
          this.dropped++
          return
        }
        this.newestDebugTs = msg.ts
        this.handlers.onHandDebug?.(decodeHandDebug(msg))
        break
      }
      case 'hello':
        this.handlers.onHello?.(msg)
        break
      case 'pong': {
        const sent = msg.cts
        if (typeof sent === 'number') {
          // Exponential average: a single congested packet should not make
          // the readout jump.
          const sample = performance.now() - sent
          this.rtt = this.rtt === 0 ? sample : this.rtt * 0.8 + sample * 0.2
        }
        break
      }
      case 'stats':
        this.handlers.onStats?.(msg as unknown as Record<string, unknown>)
        break
      case 'object':
        this.handlers.onObjectSwitch?.(msg.object)
        break
      case 'jv':
        this.handlers.onEnergy?.({
          amplitude: msg.a, energy: msg.e, speaking: msg.sp, bands: msg.b,
        })
        break
    }
  }

  setDebug(enabled: boolean): void {
    this.wantDebug = enabled
    this.send({ t: 'subscribe', debug: enabled })
  }

  setObject(objectId: string): void {
    this.send({ t: 'set_object', object: objectId })
  }

  send(payload: Record<string, unknown>): void {
    if (this.ws?.readyState === WebSocket.OPEN) {
      this.ws.send(JSON.stringify(payload))
    }
  }

  private startPing(): void {
    this.stopPing()
    this.pingTimer = window.setInterval(() => {
      this.send({ t: 'ping', cts: performance.now() })
    }, this.pingIntervalMs)
  }

  private stopPing(): void {
    if (this.pingTimer !== null) {
      clearInterval(this.pingTimer)
      this.pingTimer = null
    }
  }

  private scheduleReconnect(): void {
    if (this.reconnectTimer !== null) return
    // Capped exponential backoff: fast enough that walking back into Wi-Fi
    // range reconnects almost immediately, slow enough not to hammer a PC
    // that is genuinely off.
    const delay = Math.min(8000, 400 * 2 ** this.reconnectAttempt)
    this.reconnectAttempt++
    this.reconnectTimer = window.setTimeout(() => {
      this.reconnectTimer = null
      this.connect()
    }, delay)
  }

  private setState(state: ConnectionState, detail?: string): void {
    this.state = state
    this.handlers.onState?.(state, detail)
  }

  /** ms since the last message of any kind, or Infinity if never. */
  get sinceLastMessage(): number {
    return this.lastMessageAt === 0 ? Infinity : performance.now() - this.lastMessageAt
  }

  close(): void {
    this.closedByUser = true
    this.stopPing()
    if (this.reconnectTimer !== null) {
      clearTimeout(this.reconnectTimer)
      this.reconnectTimer = null
    }
    this.ws?.close()
    this.ws = null
  }
}

/**
 * Derive the socket URL from the page URL.
 *
 * Deliberately not hard-coded: the phone loads the page from the PC's LAN
 * address, so the socket must go back to that same host. Matching the page
 * scheme (ws for http, wss for https) also keeps it clear of mixed-content
 * blocking, which would silently kill the connection on iOS.
 */
export function defaultWsUrl(): string {
  const proto = location.protocol === 'https:' ? 'wss:' : 'ws:'
  return `${proto}//${location.host}/ws`
}
```

### client/src/net/protocol.ts
```
/**
 * Wire protocol types. Must stay in step with
 * pc/hologram_pc/networking/protocol.py -- that file is the source of truth.
 *
 * Keys are short because this runs at 60 Hz. Every field is optional on the
 * wire except the type tag: the PC omits zero-valued fields entirely and the
 * decoder below fills the defaults back in.
 */

export const PROTOCOL_VERSION = 1

export interface WireObjectControl {
  t: 'oc'
  ts: number
  id: number
  ia: string
  g: string
  n: number
  r?: [number, number, number]
  s?: number
  p?: [number, number, number]
  c?: number
  pn?: number
  tg?: string
}

export interface WireHandDebug {
  t: 'hd'
  ts: number
  id: number
  w: number
  h: number
  hands: Array<{ h: string; sc: number; lm: number[]; wl?: number[] }>
}

export interface WireJarvisVisual {
  t: 'jv'
  ts: number
  a: number
  e: number
  sp: boolean
  b: number[]
}

export interface WireHello {
  t: 'hello'
  v: number
  ts: number
  object: string
  objects: Array<{ id: string; name: string }>
  staleMs: number
  sendHz: number
}

export interface WirePong {
  t: 'pong'
  ts: number
  cts: number
}

export interface WireStats {
  t: 'stats'
  ts: number
  [key: string]: unknown
}

export interface WireObjectSwitch {
  t: 'object'
  ts: number
  object: string
}

export type WireMessage =
  | WireObjectControl
  | WireHandDebug
  | WireJarvisVisual
  | WireHello
  | WirePong
  | WireStats
  | WireObjectSwitch

/** Decoded control message with defaults restored. */
export interface ObjectControl {
  timestamp: number
  frameId: number
  interaction: string
  gesture: string
  hands: number
  rotationDelta: [number, number, number]
  scaleDelta: number
  positionDelta: [number, number, number]
  confidence: number
  pinch: number
  target?: string
}

const ZERO3: [number, number, number] = [0, 0, 0]

export function decodeObjectControl(m: WireObjectControl): ObjectControl {
  return {
    timestamp: m.ts,
    frameId: m.id,
    interaction: m.ia,
    gesture: m.g,
    hands: m.n,
```

### client/src/objects/HologramObject.ts

```
/**
 * The object plugin contract.
 *
 * A hologram object knows about Three.js and nothing else. It must not import
 * anything from ../net, ../ui, or ../hologram, and it never learns that
 * MediaPipe, a webcam, a WebSocket or an iPhone exist. Interaction reaches it
 * only as a neutral `InteractionInput`.
 *
 * That constraint is what makes new objects cheap to add: an object is a
 * self-contained folder that exports a factory and some metadata, and the
 * renderer never changes. See docs/adding-objects.md.
 */

import type { Group, Object3D } from 'three'

/** Neutral description of what the user is doing, with no transport in it. */
export interface InteractionInput {
  /** radians this frame */
  rotationDelta: [number, number, number]
  /** log-space scale delta; apply as scale *= Math.exp(scaleDelta) */
  scaleDelta: number
  /** normalised units this frame */
  positionDelta: [number, number, number]
  /** 'idle' | 'rotate' | 'scale' | 'translate' | 'select' | 'paused' */
  interaction: string
  /** 'none' | 'open_palm' | 'pinch' | 'fist' | 'point' | 'unknown' */
  gesture: string
  /** 0 = fully pinched, 1 = open. Useful for continuous affordances. */
  pinch: number
  /** number of hands currently tracked */
  hands: number
  confidence: number
  /** id of a sub-part the user is selecting, if any */
  target?: string
}

/** Per-frame timing handed to update(). */
export interface FrameContext {
  /** seconds since the previous frame, already clamped against tab-switch spikes */
  dt: number
  /** seconds since the object was created */
  elapsed: number
}

/**
 * Audio-reactive envelope from the Jarvis integration (Phase 19).
 *
 * Objects may ignore this entirely. It is delivered as a compact envelope
 * rather than audio, so no audio ever crosses the network.
 */
export interface VisualEnergy {
  amplitude: number
  energy: number
  speaking: boolean
  bands: number[]
}

export interface HologramObjectMetadata {
  id: string
  name: string
  description: string
  /** Suggested camera distance; the stage frames the object using this. */
  radius: number
  /** Optional named sub-parts a 'point' gesture could select. */
  selectable?: string[]
}

export interface HologramObject {
  readonly metadata: HologramObjectMetadata

  /** Build and return the root node. Called once, before the first update. */
  createScene(): Group | Object3D

  /** Advance animation. Called every rendered frame. */
  update(ctx: FrameContext): void

  /** Apply user interaction. Called when new input arrives, not every frame. */
  handleInteraction(input: InteractionInput): void

  /** Optional: react to the Jarvis audio envelope. */
  handleEnergy?(energy: VisualEnergy): void

  /** Release GPU resources. Geometries and materials are not GC'd for you. */
  dispose(): void
}

/** A registered object type: metadata plus a way to construct one. */
export interface HologramObjectFactory {
  metadata: HologramObjectMetadata
  create(): HologramObject
}
```

```
/**
 * Object registry.
 *
 * The application loads objects by id and never imports a concrete object
 * class. Adding a new hologram object is therefore a two-line change here
 * plus a new folder -- the rendering engine, the compositor, the networking
 * and the UI are all untouched.
 */

import type { HologramObject, HologramObjectFactory } from './HologramObject'
import { atomFactory } from './atom/Atom'
import { holographicCoreFactory } from './holographic-core/HolographicCore'
import { arcReactorFactory } from './arc-reactor/ArcReactor'

const registry = new Map<string, HologramObjectFactory>()

export function registerObject(factory: HologramObjectFactory): void {
  if (registry.has(factory.metadata.id)) {
    console.warn(`[registry] overwriting object id "${factory.metadata.id}"`)
  }
  registry.set(factory.metadata.id, factory)
}

export function createObject(id: string): HologramObject {
  const factory = registry.get(id)
  if (!factory) {
    const known = [...registry.keys()].join(', ') || '(none registered)'
    throw new Error(`Unknown hologram object "${id}". Registered: ${known}`)
  }
  return factory.create()
}

export function hasObject(id: string): boolean {
  return registry.has(id)
}

export function listObjects(): HologramObjectFactory[] {
  return [...registry.values()]
}

registerObject(holographicCoreFactory)
```

### client/src/state/realtime.ts
```
/**
 * Real-time state, deliberately outside any UI framework.
 *
 * The brief's rule: "Do not make the UI framework responsible for the 60 FPS
 * control loop" and "separate real-time state from UI state". This module is
 * how that separation is enforced.
 *
 * Two tiers:
 *
 *   hot   -- mutated on every incoming packet, read by the render loop.
 *            Plain mutable fields on one object, no events, no allocation.
 *   ui    -- sampled from `hot` at a low rate (default 6 Hz) and pushed to
 *            subscribers. Only this tier touches the DOM.
 *
 * A DOM write per landmark packet would be ~60 layout invalidations per
 * second for text nobody can read that fast. Sampling instead means the
 * control path never blocks on layout.
 */

import type { HandDebug, ObjectControl } from '../net/protocol'

export interface HotState {
  // Latest control input. Overwritten, never queued.
  interaction: string
  gesture: string
  hands: number
  pinch: number
  confidence: number
  frameId: number
  controlTs: number

  // Accumulated deltas awaiting the next render. The render loop drains
  // these, so several packets arriving inside one frame combine rather than
  // fighting each other.
  pendingRotation: [number, number, number]
  pendingScale: number
  pendingPosition: [number, number, number]
  hasPending: boolean

  // Latest landmark debug frame, dev UI only.
  handDebug: HandDebug | null

  // Audio-reactive envelope (Phase 19).
  energy: number
  amplitude: number
  speaking: boolean

  // Connection telemetry.
  connection: string
  rtt: number
  packets: number
  droppedStale: number
  sinceLastMessage: number

  // Render telemetry.
  fps: number
  frameMs: number
  objectId: string
}

export const hot: HotState = {
  interaction: 'idle',
  gesture: 'none',
  hands: 0,
  pinch: 1,
  confidence: 0,
  frameId: 0,
  controlTs: 0,
  pendingRotation: [0, 0, 0],
  pendingScale: 0,
  pendingPosition: [0, 0, 0],
  hasPending: false,
  handDebug: null,
  energy: 0,
  amplitude: 0,
  speaking: false,
  connection: 'closed',
  rtt: 0,
  packets: 0,
  droppedStale: 0,
  sinceLastMessage: Infinity,
  fps: 0,
  frameMs: 0,
  objectId: 'atom',
}

/** Fold an incoming control message into the hot state. */
export function applyControl(c: ObjectControl): void {
  hot.interaction = c.interaction
  hot.gesture = c.gesture
  hot.hands = c.hands
  hot.pinch = c.pinch
  hot.confidence = c.confidence
  hot.frameId = c.frameId
  hot.controlTs = c.timestamp

  // Accumulate rather than replace: two packets inside one animation frame
  // both represent real hand movement and both should count.
  hot.pendingRotation[0] += c.rotationDelta[0]
  hot.pendingRotation[1] += c.rotationDelta[1]
  hot.pendingRotation[2] += c.rotationDelta[2]
  hot.pendingScale += c.scaleDelta
  hot.pendingPosition[0] += c.positionDelta[0]
  hot.pendingPosition[1] += c.positionDelta[1]
  hot.pendingPosition[2] += c.positionDelta[2]
  hot.hasPending = true
}

/** Zero the accumulators. Called by the render loop after applying them. */
export function clearPending(): void {
  hot.pendingRotation[0] = 0
  hot.pendingRotation[1] = 0
  hot.pendingRotation[2] = 0
  hot.pendingScale = 0
  hot.pendingPosition[0] = 0
  hot.pendingPosition[1] = 0
  hot.pendingPosition[2] = 0
  hot.hasPending = false
}

// --- UI tier ----------------------------------------------------------------

type UiSubscriber = (state: Readonly<HotState>) => void

const subscribers = new Set<UiSubscriber>()
let uiTimer: number | null = null

export function subscribeUi(fn: UiSubscriber, hz = 6): () => void {
  subscribers.add(fn)
  if (uiTimer === null) {
    uiTimer = window.setInterval(() => {
      for (const s of subscribers) s(hot)
    }, 1000 / hz)
  }
  return () => {
    subscribers.delete(fn)
    if (subscribers.size === 0 && uiTimer !== null) {
      clearInterval(uiTimer)
      uiTimer = null
    }
  }
}

/** Rolling FPS, updated by the render loop. Cheap exponential average. */
export function noteFrame(frameMs: number): void {
  hot.frameMs = hot.frameMs === 0 ? frameMs : hot.frameMs * 0.9 + frameMs * 0.1
  hot.fps = hot.frameMs > 0 ? 1000 / hot.frameMs : 0
}
```

```
function num(v: unknown, digits = 1): string {
  return typeof v === 'number' ? v.toFixed(digits) : '—'
}

function fit(stage: Stage, canvas: HTMLCanvasElement): void {
  const parent = canvas.parentElement
  if (!parent) return
  const w = parent.clientWidth
  const h = parent.clientHeight
  if (w > 0 && h > 0) stage.setSize(w, h)
}

function sizeOverlay(canvas: HTMLCanvasElement): void {
  const parent = canvas.parentElement
  if (!parent) return
  canvas.width = parent.clientWidth
  canvas.height = parent.clientHeight
}

function clearCanvas(canvas: HTMLCanvasElement): void {
  const ctx = canvas.getContext('2d')
  ctx?.clearRect(0, 0, canvas.width, canvas.height)
}

const FINGER_COLORS = ['#ffb450', '#8cff8c', '#50d2ff', '#ff82c8', '#aa82ff']

function colorFor(b: number): string {
  if (b <= 4) return FINGER_COLORS[0]
  if (b <= 8) return FINGER_COLORS[1]
  if (b <= 12) return FINGER_COLORS[2]
  if (b <= 16) return FINGER_COLORS[3]
  return FINGER_COLORS[4]
}

/**
 * Draw the hand skeleton over the camera image.
 *
 * The MJPEG <img> is letterboxed by object-fit:contain, so landmark
 * coordinates (normalised to the source frame) must be mapped through the
 * same letterbox or the skeleton drifts away from the hand near the edges.
 */
function drawLandmarks(
  canvas: HTMLCanvasElement,
  debug: HandDebug,
  img: HTMLImageElement,
  annotate = false,
): void {
  const ctx = canvas.getContext('2d')
  if (!ctx) return
  ctx.clearRect(0, 0, canvas.width, canvas.height)
  if (!debug.hands.length) return

  const srcW = debug.width || img.naturalWidth || 640
  const srcH = debug.height || img.naturalHeight || 480
  const scale = Math.min(canvas.width / srcW, canvas.height / srcH)
  const dw = srcW * scale
  const dh = srcH * scale
  const ox = (canvas.width - dw) / 2
  const oy = (canvas.height - dh) / 2
  const px = (nx: number) => ox + nx * dw
  const py = (ny: number) => oy + ny * dh

  for (const hand of debug.hands) {
    const lm = hand.landmarks
    ctx.lineWidth = 2
    for (const [a, b] of HAND_CONNECTIONS) {
      ctx.strokeStyle = colorFor(b)
      ctx.beginPath()
      ctx.moveTo(px(lm[a * 3]), py(lm[a * 3 + 1]))
      ctx.lineTo(px(lm[b * 3]), py(lm[b * 3 + 1]))
      ctx.stroke()
    }
    ctx.fillStyle = '#ffffff'
    for (let i = 0; i < 21; i++) {
      const isTip = i === 4 || i === 8 || i === 12 || i === 16 || i === 20
      ctx.beginPath()
      ctx.arc(px(lm[i * 3]), py(lm[i * 3 + 1]), isTip ? 4 : 2.5, 0, Math.PI * 2)
      ctx.fill()
    }
    ctx.fillStyle = '#9fe8ff'
    ctx.font = '12px ui-monospace, monospace'
    ctx.fillText(
      `${hand.handedness} ${hand.score.toFixed(2)}`,
      px(lm[0]) - 24, py(lm[1]) + 20,
    )

    if (annotate) {
      // Panel 3 shows the pinch span, i.e. the measurement the gesture engine
      // is actually thresholding on.
      const tx = px(lm[4 * 3]), ty = py(lm[4 * 3 + 1])
      const ix = px(lm[8 * 3]), iy = py(lm[8 * 3 + 1])
      ctx.strokeStyle = '#ffd166'
      ctx.setLineDash([4, 4])
      ctx.beginPath(); ctx.moveTo(tx, ty); ctx.lineTo(ix, iy); ctx.stroke()
      ctx.setLineDash([])
      ctx.fillStyle = '#ffd166'
      ctx.beginPath()
      ctx.arc((tx + ix) / 2, (ty + iy) / 2, 5, 0, Math.PI * 2)
      ctx.fill()
    }
  }
}
```

```
/**
 * iPhone hologram mode: four-view output and nothing else.
 *
 * Fullscreen strategy, and why it is not simply `requestFullscreen()`:
 * iPhone Safari's Fullscreen API on non-video elements is flag-gated and
 * buggy (WebKit bug 212934). Relying on it would mean the primary display
 * mode of this project fails on the exact device it targets. So:
 *
 *   1. CSS fullscreen -- fixed inset:0, safe-area aware. Always works.
 *   2. requestFullscreen() if the browser genuinely has it (desktop, iPad).
 *   3. "Add to Home Screen" for a genuinely chrome-free standalone display on iPhone.
 *
 * Wake lock is requested but never required: it needs iOS 16.4+ and throws
 * in several situations. A hologram that stops rendering because the lock
 * failed would be a self-inflicted wound.
 */

import { Stage } from '../core/Stage'
import { loadCalibration } from '../hologram/calibration'
import { HologramClient } from '../net/client'
import { applyControl, hot, subscribeUi } from '../state/realtime'

export function mountHologramMode(root: HTMLElement, onExit: () => void): () => void {
  root.innerHTML = `
    <div class="holo">
      <canvas id="holo-canvas"></canvas>
      <div class="hud" id="holo-hud"><span class="status-dot"></span>connecting…</div>
      <button class="exit" id="holo-exit">exit</button>
    </div>`

  const canvas = root.querySelector<HTMLCanvasElement>('#holo-canvas')!
  const hud = root.querySelector<HTMLDivElement>('#holo-hud')!
  const exitBtn = root.querySelector<HTMLButtonElement>('#holo-exit')!

  let stage: Stage
  try {
    stage = new Stage(canvas)
  } catch (err) {
    root.innerHTML = `
      <div class="landing"><div class="card">
        <h1>WebGL unavailable</h1>
        <div class="error-box">${escapeHtml(String(err))}</div>
        <p>Safari needs WebGL for this. Check Settings &gt; Apps &gt; Safari &gt;
        Advanced and make sure WebGL is not disabled.</p>
      </div></div>`
    return () => {}
  }

  stage.mode = 'four-view'
  stage.setCalibration(loadCalibration())
  stage.setObject('atom')

  const resize = () => {
    // Square-ish output is what the pyramid wants, but we fill the screen and
    // let calibration place the views.
    stage.setSize(root.clientWidth, root.clientHeight)
  }
  resize()
  stage.start()

  const client = new HologramClient({
    onControl: (c) => applyControl(c),
    onObjectSwitch: (id) => stage.setObject(id),
    onEnergy: (e) => {
      hot.energy = e.energy
      hot.amplitude = e.amplitude
      hot.speaking = e.speaking
    },
    onState: (state, detail) => {
      hot.connection = state
      hud.innerHTML =
        `<span class="status-dot ${state}"></span>` +
        (state === 'open' ? 'connected' : `${state}${detail ? ` — ${detail}` : ''}`)
      hud.classList.remove('hidden')
      if (state === 'open') {
        // Fade the HUD away once connected; the pyramid should show only the
        // hologram, and any lit pixel is visible in the acrylic.
        window.setTimeout(() => hud.classList.add('hidden'), 2500)
      }
    },
  }, { debug: false })
  client.connect()

  const unsubscribe = subscribeUi(() => {
    hot.rtt = client.rtt
    hot.packets = client.packets
    hot.droppedStale = client.dropped
  }, 4)

  window.addEventListener('resize', resize)
  const orientationHandler = () => window.setTimeout(resize, 250)
  window.addEventListener('orientationchange', orientationHandler)

  // --- wake lock ------------------------------------------------------------
  let wakeLock: WakeLockSentinel | null = null
  const requestWakeLock = async () => {
    try {
      if ('wakeLock' in navigator) {
        wakeLock = await navigator.wakeLock.request('screen')
      }
    } catch {
      // iOS throws here when the battery is low or the page is not visible.
      // The hologram works fine without it; the screen just dims eventually.
    }
  }
  void requestWakeLock()
  const visibilityHandler = () => {
    // The lock is released automatically when the page hides, so reacquire.
    if (document.visibilityState === 'visible') void requestWakeLock()
  }
  document.addEventListener('visibilitychange', visibilityHandler)

  // --- exit -----------------------------------------------------------------
  // A triple tap anywhere also exits, because the corner button is nearly
  // invisible by design and the phone is under a pyramid.
  let taps = 0
  let tapTimer = 0
  const tapHandler = () => {
    taps++
    window.clearTimeout(tapTimer)
    tapTimer = window.setTimeout(() => { taps = 0 }, 600)
    if (taps >= 3) { taps = 0; cleanup(); onExit() }
  }
  canvas.addEventListener('pointerdown', tapHandler)
  exitBtn.addEventListener('click', () => { cleanup(); onExit() })

  function cleanup(): void {
    unsubscribe()
    window.removeEventListener('resize', resize)
    window.removeEventListener('orientationchange', orientationHandler)
    document.removeEventListener('visibilitychange', visibilityHandler)
    canvas.removeEventListener('pointerdown', tapHandler)
    void wakeLock?.release().catch(() => {})
    client.close()
    stage.dispose()
  }

  return cleanup
}

function escapeHtml(s: string): string {
  const d = document.createElement('div')
  d.textContent = s
  return d.innerHTML
}
```

```
"""Lightweight latency and rate telemetry.

Spec section 17: "Measure latency instead of guessing." Every stage stamps
a monotonic nanosecond time and the deltas land here.

Deliberately allocation-light: fixed-size deques, no pandas, no per-sample
objects. These are updated inside the real-time loop, so they must cost
approximately nothing.
"""

from __future__ import annotations

import time
from collections import deque
from dataclasses import dataclass
from typing import Deque, Optional


class RollingStat:
    """Fixed-window mean/min/max/percentile over a stream of floats."""

    __slots__ = ("_buf", "_name")

    def __init__(self, window: int = 120, name: str = "") -> None:
        self._buf: Deque[float] = deque(maxlen=max(1, window))
        self._name = name

    def add(self, value: float) -> None:
        self._buf.append(value)

    def __len__(self) -> int:
        return len(self._buf)

    @property
    def mean(self) -> float:
        return sum(self._buf) / len(self._buf) if self._buf else 0.0

    @property
    def last(self) -> float:
        return self._buf[-1] if self._buf else 0.0

    @property
    def min(self) -> float:
        return min(self._buf) if self._buf else 0.0

    @property
    def max(self) -> float:
        return max(self._buf) if self._buf else 0.0

    def percentile(self, p: float) -> float:
        """p in [0,100]. Nearest-rank; the window is small so sorting is cheap."""
        if not self._buf:
            return 0.0
        ordered = sorted(self._buf)
        k = min(len(ordered) - 1, max(0, int(round((p / 100.0) * len(ordered) + 0.5)) - 1))
        return ordered[k]

    def summary(self) -> str:
        if not self._buf:
            return f"{self._name}: --"
        return (f"{self._name}: {self.mean:5.1f} avg  "
                f"{self.percentile(95):5.1f} p95  {self.max:5.1f} max")


class RateCounter:
    """Events per second over a sliding time window."""

    __slots__ = ("_stamps", "_window_s")

    def __init__(self, window_s: float = 2.0) -> None:
        self._stamps: Deque[float] = deque()
        self._window_s = window_s

    def tick(self, now: Optional[float] = None) -> None:
        t = now if now is not None else time.perf_counter()
        self._stamps.append(t)
        cutoff = t - self._window_s
        while self._stamps and self._stamps[0] < cutoff:
            self._stamps.popleft()

    @property
    def rate(self) -> float:
        if len(self._stamps) < 2:
            return 0.0
        span = self._stamps[-1] - self._stamps[0]
        return (len(self._stamps) - 1) / span if span > 0 else 0.0


@dataclass
class PipelineMetrics:
    """All Phase 1 telemetry in one place.

    Stage names match the spec's telemetry list so later phases can extend it
    (gesture, websocket send/recv, render) without renaming anything.
    """

    capture_fps: RateCounter
    inference_fps: RateCounter
    loop_fps: RateCounter
    cv_latency_ms: RollingStat        # detect_async -> result_callback
    capture_to_result_ms: RollingStat  # camera grab -> hand state available
    loop_ms: RollingStat               # our own per-iteration cost

    @classmethod
    def create(cls, window: int = 120) -> "PipelineMetrics":
        return cls(
            capture_fps=RateCounter(),
            inference_fps=RateCounter(),
            loop_fps=RateCounter(),
            cv_latency_ms=RollingStat(window, "cv"),
            capture_to_result_ms=RollingStat(window, "e2e"),
            loop_ms=RollingStat(window, "loop"),
        )
```

### pc/hologram_pc/interaction/engine.py
```
"""The interaction engine: GestureState[] -> InteractionCommand.

Gesture bindings (all thresholds and gains live in config):

    open palm          idle (and resumes from pause)
    pinch + move       GRAB: translate the object through space
    two-finger spread  scale, from thumb-index distance on one hand
    fist               pause -- freezes interaction, holds pose
    point              select

Objects spin on their own; there is no manual rotation binding. That is
deliberate. A rotationally symmetric object -- an arc reactor, the atom's
nucleus -- barely appears to move when it spins, so rotation is a poor way to
show life in a pyramid. Translation is unmistakable, so the grab gesture is
spent on it.

Only *deltas* leave this module. The renderer owns absolute object state, so
a dropped packet costs a fraction of a unit rather than a visible snap.
"""

from __future__ import annotations

import time
from typing import List, Optional, Sequence, Tuple

import numpy as np

from .gestures import GestureRecognizer
from .spaces import ActiveRegion, CameraToInteraction, apply_deadzone
from .types import (
    GestureKind,
    GestureState,
    InteractionCommand,
    InteractionFrame,
    InteractionKind,
)


class InteractionEngine:
    """Stateful: remembers the anchor a drag started from."""

    def __init__(self, cfg, aspect: float = 4.0 / 3.0) -> None:
        self._cfg = cfg
        self._recognizer = GestureRecognizer(cfg)
        self._space = CameraToInteraction(
            ActiveRegion(*cfg.active_region), aspect=aspect)
        self._anchor: Optional[Tuple[float, float, float]] = None
        self._anchor_hand: Optional[str] = None
        self._span: Optional[float] = None
        self._pinch_ref: Optional[float] = None
        self._pinch_ref_hand: Optional[str] = None
        self._scale_cooldown = 0.0
        self._paused = False
        self._fist_frames = 0
        self._palm_frames = 0
        self._frames = 0

    # -------------------------------------------------------------- config

    def set_aspect(self, aspect: float) -> None:
        self._space.set_aspect(aspect)

    def reset(self) -> None:
        self._recognizer.reset()
        self._anchor = None
        self._anchor_hand = None
        self._span = None
        self._pinch_ref = None
        self._pinch_ref_hand = None
        self._scale_cooldown = 0.0
        self._paused = False
        self._fist_frames = 0
        self._palm_frames = 0

    @property
    def paused(self) -> bool:
        return self._paused

    # --------------------------------------------------------------- main

    def process(self, tracking, t: Optional[float] = None) -> InteractionFrame:
        now = time.perf_counter() if t is None else t
        hands = tracking.hands if tracking is not None else ()
        gestures = self._recognizer.classify(hands, now)
        command = self._command(gestures, now)
        self._frames += 1
        return InteractionFrame(
            frame_id=tracking.frame_id if tracking is not None else self._frames,
            capture_ns=tracking.stamps.capture_ns if tracking is not None else 0,
            gestures=tuple(gestures),
            command=command,
        )

    # ----------------------------------------------------------- commands

    def _command(self, gestures: Sequence[GestureState],
                 now: float) -> InteractionCommand:
        cfg = self._cfg

        # Pause latches on a held fist and releases on a held open palm.
        #
        # Both need a hold because a hand moving into a pinch passes through
        # a frame or two that classify as open palm while the pinch ratio
        # catches up. Releasing on a single such frame made pausing unreliable
        # in exactly the situation it exists for.
        if any(g.kind is GestureKind.FIST for g in gestures):
            self._fist_frames += 1
            self._palm_frames = 0
        elif any(g.kind is GestureKind.OPEN_PALM for g in gestures):
            self._palm_frames += 1
            self._fist_frames = 0
        else:
            self._fist_frames = 0
            self._palm_frames = 0

        if self._fist_frames >= cfg.pause_hold_frames:
            if not self._paused:
                self._paused = True
                self._drop_anchors()
        elif self._palm_frames >= cfg.resume_hold_frames:
            self._paused = False

        if self._paused:
            return InteractionCommand(InteractionKind.PAUSED, confidence=1.0)

        pinching = [g for g in gestures if g.is_pinching]

        # Two pinched hands still scale, by the distance between them. It is
        # the more precise of the two scale gestures and costs nothing to keep.
        if len(pinching) >= 2:
            self._drop_scale_ref()
            return self._scale_two_hand(pinching[:2])
        self._span = None

        # One pinched hand grabs and drags.
        if len(pinching) == 1:
            self._drop_scale_ref()
            # Releasing a grab means opening the fingers, which would otherwise
            # read as a deliberate two-finger spread and inflate the object.
            # Suppress the spread gesture briefly after any grab.
            self._scale_cooldown = now + cfg.scale_cooldown_s
            return self._translate(pinching[0])
        self._anchor = None
        self._anchor_hand = None

        # Otherwise, an unpinched hand's thumb-index spread drives scale.
        spread = self._scale_two_finger(gestures, now)
        if spread is not None:
            return spread

        pointing = [g for g in gestures if g.kind is GestureKind.POINT]
        if pointing:
            return InteractionCommand(
                InteractionKind.SELECT, confidence=pointing[0].confidence)

        return InteractionCommand(InteractionKind.IDLE)

    # --------------------------------------------------------- translation

    def _translate(self, g: GestureState) -> InteractionCommand:
        """Grab and move. Hand travel maps to object travel."""
        cfg = self._cfg
        p = self._space.point(g.position)

        # A new pinch, or a pinch that changed hands, starts a fresh drag.
        # Without this the object leaps by the whole gap between where the
        # last drag ended and where this one began.
        if self._anchor is None or self._anchor_hand != g.handedness:
            self._anchor = p
            self._anchor_hand = g.handedness
            return InteractionCommand(InteractionKind.TRANSLATE,
                                      confidence=g.confidence)

        dx = apply_deadzone(p[0] - self._anchor[0], cfg.translate_deadzone)
        dy = apply_deadzone(p[1] - self._anchor[1], cfg.translate_deadzone)
        self._anchor = p

        tx = float(np.clip(dx * cfg.translate_gain,
                           -cfg.max_translate_step, cfg.max_translate_step))
        ty = float(np.clip(dy * cfg.translate_gain,
                           -cfg.max_translate_step, cfg.max_translate_step))

        if tx == 0.0 and ty == 0.0:
            return InteractionCommand(InteractionKind.TRANSLATE,
                                      confidence=g.confidence)
        return InteractionCommand(
            kind=InteractionKind.TRANSLATE,
            position_delta=(tx, ty, 0.0),
            confidence=g.confidence,
        )

    # --------------------------------------------------------------- scale

    def _scale_two_finger(self, gestures: Sequence[GestureState],
                          now: float) -> Optional[InteractionCommand]:
        """Scale from one hand's thumb-index separation.

        `GestureState.pinch` is already the normalised 0-1 spread (0 fully
        closed, 1 fully open) and is palm-length relative, so it means the same
        thing at any distance from the camera.
        """
        cfg = self._cfg
        if now < self._scale_cooldown:
            return None

        # Only an open, tracked hand drives this -- not a fist, and not a
        # hand that is barely detected.
        candidates = [g for g in gestures
                      if g.kind in (GestureKind.OPEN_PALM, GestureKind.UNKNOWN)
                      and g.confidence >= cfg.scale_min_confidence]
        if not candidates:
            self._drop_scale_ref()
            return None
        g = candidates[0]

        spread = max(cfg.min_scale_span, g.pinch)
        if self._pinch_ref is None or self._pinch_ref_hand != g.handedness:
            self._pinch_ref = spread
            self._pinch_ref_hand = g.handedness
            return None

        # Log ratio, like the two-hand path: opening and closing the fingers
        # back to where they started restores the original size exactly.
        ratio = float(np.log(spread / self._pinch_ref))
        delta = apply_deadzone(ratio, cfg.spread_deadzone)
        self._pinch_ref = spread
        if delta == 0.0:
            return None

        s = float(np.clip(delta * cfg.spread_gain,
                          -cfg.max_scale_step, cfg.max_scale_step))
        return InteractionCommand(
            kind=InteractionKind.SCALE,
            scale_delta=s,
            confidence=g.confidence,
        )

    def _scale_two_hand(self, pair: Sequence[GestureState]) -> InteractionCommand:
        cfg = self._cfg
        a = self._space.point(pair[0].position)
        b = self._space.point(pair[1].position)
        span = float(np.hypot(a[0] - b[0], a[1] - b[1]))

        if self._span is None or self._span < cfg.min_scale_span:
            self._span = max(span, cfg.min_scale_span)
            return InteractionCommand(
                InteractionKind.SCALE,
                confidence=min(pair[0].confidence, pair[1].confidence))

        # Log of the span *ratio*, not the raw difference.
        #
        # A linear delta is not reversible: spreading the hands by 0.2 and
        # bringing them back by 0.2 does not restore the original size,
        # because the same absolute change means a different proportional
        # change at a different starting span. A log ratio is symmetric by
        # construction -- the client applies scale *= exp(delta), so any path
        # that returns the hands to their original separation returns the
        # object to its original size.
        span = max(span, cfg.min_scale_span)
        ratio = float(np.log(span / self._span))
        delta = apply_deadzone(ratio, cfg.scale_deadzone)
        self._span = span
        s = float(np.clip(delta * cfg.scale_gain,
                          -cfg.max_scale_step, cfg.max_scale_step))
        # Two pinches also cancel any single-hand drag in progress.
        self._anchor = None
        self._anchor_hand = None
        return InteractionCommand(
            kind=InteractionKind.SCALE,
            scale_delta=s,
            confidence=min(pair[0].confidence, pair[1].confidence),
        )

    # -------------------------------------------------------------- state

    def _drop_scale_ref(self) -> None:
        self._pinch_ref = None
        self._pinch_ref_hand = None

    def _drop_anchors(self) -> None:
        self._anchor = None
        self._anchor_hand = None
        self._span = None
        self._drop_scale_ref()
```

### pc/hologram_pc/interaction/filters.py
```
"""Smoothing that does not cost latency.

The brief is explicit: no large moving-average window, because a window of N
frames delays the signal by roughly N/2 frames. At 30 fps a 10-frame average
would add ~165 ms -- more than ten times the entire inference budget.

The One Euro filter is used instead. It is an adaptive low-pass whose cutoff
frequency rises with the signal's speed:

  * hand nearly still -> low cutoff -> jitter is removed
  * hand moving fast  -> high cutoff -> almost no lag

That is exactly the trade a direct-manipulation interface wants: precision
when placing, responsiveness when moving. A fixed EMA cannot do both, since
any alpha low enough to kill jitter also smears fast motion.

Reference: Casiez, Roussel & Vogel, "1 Euro Filter: A Simple Speed-based
Low-pass Filter for Noisy Input in Interactive Systems", CHI 2012.
"""

from __future__ import annotations

import math
from typing import Optional

import numpy as np


def _alpha(cutoff_hz: float, dt: float) -> float:
    """Low-pass coefficient for a given cutoff and timestep."""
    tau = 1.0 / (2.0 * math.pi * max(1e-6, cutoff_hz))
    return 1.0 / (1.0 + tau / max(1e-6, dt))


class OneEuroFilter:
    """Adaptive low-pass over a fixed-shape numpy array.

    min_cutoff  lower  -> more smoothing when the hand is still
    beta        higher -> less smoothing when the hand moves fast
    """

    __slots__ = ("_min_cutoff", "_beta", "_d_cutoff",
                 "_x_prev", "_dx_prev", "_t_prev")

    def __init__(self, min_cutoff: float = 1.2, beta: float = 0.03,
                 d_cutoff: float = 1.0) -> None:
        self._min_cutoff = float(min_cutoff)
        self._beta = float(beta)
        self._d_cutoff = float(d_cutoff)
        self._x_prev: Optional[np.ndarray] = None
        self._dx_prev: Optional[np.ndarray] = None
        self._t_prev: float = 0.0

    def reset(self) -> None:
        self._x_prev = None
        self._dx_prev = None
        self._t_prev = 0.0

    @property
    def initialised(self) -> bool:
        return self._x_prev is not None

    @property
    def velocity(self) -> Optional[np.ndarray]:
        """Smoothed derivative, in input-units per second."""
        return self._dx_prev

    def __call__(self, x: np.ndarray, t: float) -> np.ndarray:
        """Filter sample `x` taken at monotonic time `t` (seconds)."""
        x = np.asarray(x, dtype=np.float64)
        if self._x_prev is None:
            self._x_prev = x.copy()
            self._dx_prev = np.zeros_like(x)
            self._t_prev = t
            return x.copy()

        dt = t - self._t_prev
        if dt <= 0.0:
            # Duplicate or out-of-order sample: hold, do not divide by zero.
            return self._x_prev.copy()
        self._t_prev = t

        dx = (x - self._x_prev) / dt
        a_d = _alpha(self._d_cutoff, dt)
        self._dx_prev = a_d * dx + (1.0 - a_d) * self._dx_prev

        # Speed-dependent cutoff: the whole point of the filter.
        speed = np.abs(self._dx_prev)
        cutoff = self._min_cutoff + self._beta * speed
        # alpha is elementwise here, so each axis adapts independently.
        tau = 1.0 / (2.0 * np.pi * np.maximum(1e-6, cutoff))
        a = 1.0 / (1.0 + tau / dt)

        self._x_prev = a * x + (1.0 - a) * self._x_prev
        return self._x_prev.copy()


class ScalarOneEuro:
    """One Euro over a single float. Same maths, no array overhead."""

    __slots__ = ("_min_cutoff", "_beta", "_d_cutoff",
                 "_x_prev", "_dx_prev", "_t_prev")

    def __init__(self, min_cutoff: float = 1.2, beta: float = 0.03,
                 d_cutoff: float = 1.0) -> None:
        self._min_cutoff = float(min_cutoff)
        self._beta = float(beta)
        self._d_cutoff = float(d_cutoff)
        self._x_prev: Optional[float] = None
        self._dx_prev: float = 0.0
        self._t_prev: float = 0.0

    def reset(self) -> None:
        self._x_prev = None
        self._dx_prev = 0.0

    def __call__(self, x: float, t: float) -> float:
        if self._x_prev is None:
            self._x_prev = float(x)
            self._t_prev = t
            return float(x)
        dt = t - self._t_prev
        if dt <= 0.0:
            return self._x_prev
        self._t_prev = t
        dx = (x - self._x_prev) / dt
        a_d = _alpha(self._d_cutoff, dt)
        self._dx_prev = a_d * dx + (1.0 - a_d) * self._dx_prev
        cutoff = self._min_cutoff + self._beta * abs(self._dx_prev)
        a = _alpha(cutoff, dt)
        self._x_prev = a * x + (1.0 - a) * self._x_prev
        return self._x_prev


class Hysteresis:
    """Schmitt trigger for threshold-based gestures.

    A single threshold makes a gesture chatter on/off when the measurement
    sits near it -- a pinch flickering at 30 Hz is far worse than one that
    engages 20 ms late. Engaging and releasing at different levels removes
    that entirely.
    """

    __slots__ = ("_on_below", "_off_above", "_state")

    def __init__(self, on_below: float, off_above: float) -> None:
        if off_above <= on_below:
            raise ValueError(
                f"off_above ({off_above}) must exceed on_below ({on_below}); "
                "otherwise there is no hysteresis band."
            )
        self._on_below = on_below
        self._off_above = off_above
        self._state = False

    def update(self, value: float) -> bool:
        if self._state:
            if value > self._off_above:
                self._state = False
        else:
            if value < self._on_below:
                self._state = True
        return self._state

    @property
    def state(self) -> bool:
        return self._state

    def reset(self) -> None:
        self._state = False
```

### pc/hologram_pc/interaction/gestures.py
```
"""Gesture classification: HandState -> GestureState.

Every measurement here is **scale-invariant**. Raw landmark distances shrink
as the hand moves away from the lens, so a fixed pixel threshold would make a
pinch register at 40 cm and refuse to register at 70 cm. Distances are
therefore divided by the hand's own palm length, which makes a pinch the same
number wherever the hand is.

Per-hand state (filters, hysteresis) is keyed by handedness rather than by
MediaPipe's hand index, because the index can swap between frames when two
hands cross while handedness does not.
"""

from __future__ import annotations

import time
from typing import Dict, List, Optional, Sequence, Tuple

import numpy as np

from ..vision.types import HandLandmarkIndex as L
from ..vision.types import HandState
from .filters import Hysteresis, OneEuroFilter, ScalarOneEuro
from .types import GestureKind, GestureState

# (tip, pip) pairs used for the "is this finger extended" test.
_FINGER_JOINTS = (
    (L.THUMB_TIP, L.THUMB_IP),
    (L.INDEX_TIP, L.INDEX_PIP),
    (L.MIDDLE_TIP, L.MIDDLE_PIP),
    (L.RING_TIP, L.RING_PIP),
    (L.PINKY_TIP, L.PINKY_PIP),
)


def palm_length(landmarks: np.ndarray) -> float:
    """Wrist -> middle knuckle, the reference length for every ratio here.

    Chosen over hand width because it barely changes as fingers open and
    close, so ratios built on it do not drift during the very gestures they
    are meant to classify.
    """
    return float(np.linalg.norm(
        landmarks[L.MIDDLE_MCP][:2] - landmarks[L.WRIST][:2]))


def pinch_ratio(landmarks: np.ndarray) -> float:
    """Thumb-index separation as a multiple of palm length.

    Roughly: < 0.35 pinched, > 1.2 open. Independent of distance to camera.
    """
    scale = palm_length(landmarks)
    if scale < 1e-6:
        return 10.0
    d = float(np.linalg.norm(landmarks[L.THUMB_TIP][:2] - landmarks[L.INDEX_TIP][:2]))
    return d / scale


def fingers_extended(landmarks: np.ndarray) -> Tuple[bool, ...]:
    """Per-finger extension, thumb..pinky.

    A finger is extended when its tip is further from the wrist than its own
    PIP joint. This is orientation-independent, unlike the common
    'tip.y < pip.y' test which silently breaks the moment the hand is not
    upright -- and hands over a hologram pyramid are rarely upright.
    """
    wrist = landmarks[L.WRIST][:2]
    out: List[bool] = []
    for tip, pip in _FINGER_JOINTS:
        d_tip = float(np.linalg.norm(landmarks[tip][:2] - wrist))
        d_pip = float(np.linalg.norm(landmarks[pip][:2] - wrist))
        out.append(d_tip > d_pip * 1.05)
    return tuple(out)


class _HandTrack:
    """Per-hand persistent state: filters and the pinch Schmitt trigger."""

    __slots__ = ("position", "pinch", "grip", "last_seen")

    def __init__(self, cfg) -> None:
        self.position = OneEuroFilter(cfg.position_min_cutoff, cfg.position_beta)
        self.pinch = ScalarOneEuro(cfg.pinch_min_cutoff, cfg.pinch_beta)
        self.grip = Hysteresis(cfg.pinch_on_ratio, cfg.pinch_off_ratio)
        self.last_seen = 0.0


class GestureRecognizer:
    """Stateful classifier. One instance for the whole session."""

    def __init__(self, cfg) -> None:
        self._cfg = cfg
        self._tracks: Dict[str, _HandTrack] = {}

    def reset(self) -> None:
        self._tracks.clear()

    def _track(self, handedness: str) -> _HandTrack:
        t = self._tracks.get(handedness)
        if t is None:
            t = _HandTrack(self._cfg)
            self._tracks[handedness] = t
        return t

    def classify(self, hands: Sequence[HandState],
                 t: Optional[float] = None) -> List[GestureState]:
        now = time.perf_counter() if t is None else t
        out: List[GestureState] = []
        seen: set = set()

        for hand in hands:
            key = hand.handedness or f"idx{hand.index}"
            seen.add(key)
            track = self._track(key)

            # Drop stale filter state if this hand vanished for a while --
            # otherwise it re-appears with a velocity computed across the gap
            # and the object lurches.
            if track.last_seen and (now - track.last_seen) > self._cfg.track_timeout_s:
                track.position.reset()
                track.pinch.reset()
                track.grip.reset()
            track.last_seen = now

            lm = hand.landmarks
            raw_ratio = pinch_ratio(lm)
            # The Schmitt trigger sees the RAW ratio, not the filtered one.
            #
            # Filtering before the threshold added the filter's settling time
            # to every gesture transition: moving from a fist into a pinch
            # spent several frames with a stale high ratio, during which the
            # hand classified as an open palm and silently released pause.
            # Hysteresis is already the anti-chatter mechanism, so filtering
            # here bought nothing and cost responsiveness.
            gripping = track.grip.update(raw_ratio)
            # The filtered value drives only the continuous 0-1 readout, where
            # smoothness matters and a few ms of lag is invisible.
            ratio = track.pinch(raw_ratio, now)
            extended = fingers_extended(lm)

            # The pinch point is the thumb/index midpoint: the natural pivot
            # of a physical pinch, and steadier than either fingertip alone.
            raw_point = (lm[L.THUMB_TIP] + lm[L.INDEX_TIP]) * 0.5
            point = track.position(raw_point.astype(np.float64), now)
            vel = track.position.velocity
            velocity = (float(vel[0]), float(vel[1]), float(vel[2])) \
                if vel is not None else (0.0, 0.0, 0.0)

            kind, conf = self._kind(gripping, ratio, extended)
            out.append(GestureState(
                hand_index=hand.index,
                handedness=hand.handedness,
                kind=kind,
                confidence=conf * hand.handedness_score,
                pinch=float(np.clip(ratio / max(1e-6, self._cfg.pinch_open_ratio), 0.0, 1.0)),
                position=(float(point[0]), float(point[1]), float(point[2])),
                velocity=velocity,
                fingers_extended=extended,  # type: ignore[arg-type]
            ))

        for key in list(self._tracks):
            if key not in seen and (now - self._tracks[key].last_seen) > 2.0:
                del self._tracks[key]
        return out

    def _kind(self, gripping: bool, ratio: float,
              ext: Tuple[bool, ...]) -> Tuple[GestureKind, float]:
        n_ext = sum(ext[1:])       # ignore the thumb; it is unreliable curled
        cfg = self._cfg

        # Fist is tested BEFORE pinch. In a real closed fist the thumb wraps
        # across the curled fingers, so thumb-to-index distance is small and
        # the pinch ratio alone would happily call it a pinch. No extended
        # finger is the unambiguous signal, so it wins.
        if n_ext == 0:
            return GestureKind.FIST, 0.9

        if gripping:
            # Confidence rises the further inside the threshold we are.
            margin = (cfg.pinch_off_ratio - ratio) / max(1e-6, cfg.pinch_off_ratio)
            return GestureKind.PINCH, float(np.clip(0.6 + margin, 0.0, 1.0))

        if ext[1] and not any(ext[2:]):
            return GestureKind.POINT, 0.85

        if n_ext >= 3:
            return GestureKind.OPEN_PALM, float(np.clip(0.5 + 0.15 * n_ext, 0.0, 1.0))

        return GestureKind.UNKNOWN, 0.4


def two_hand_span(gestures: Sequence[GestureState]) -> Optional[float]:
    """Distance between two pinch points, or None if fewer than two pinches."""
    pinching = [g for g in gestures if g.is_pinching]
    if len(pinching) < 2:
        return None
    a = np.asarray(pinching[0].position[:2])
    b = np.asarray(pinching[1].position[:2])
    return float(np.linalg.norm(a - b))
```

### pc/hologram_pc/interaction/spaces.py
```
"""The coordinate chain: Camera -> Interaction -> Object -> Render.

    Camera space       normalised image coords from MediaPipe.
                       x,y in [0,1], origin top-left, y DOWN.
                       Already mirrored if camera.flip_horizontal is on.

    Interaction space   centred, y UP, aspect-corrected, x,y in [-1,1].
                        Only a configurable sub-rectangle of the camera frame
                        maps to that range, so the operator never has to reach
                        the very edge of the frame to reach the edge of the
                        interaction volume.

    Object space        deltas after gain, ready to apply to a scene object.

    Render space        lives on the client. The PC never computes it.

The layers exist because the physical pyramid will eventually be calibrated
against the camera. When that happens only `CameraToInteraction` changes;
gesture classification and object control are untouched. Coupling MediaPipe's
image coordinates straight to Three.js would have made that a rewrite.
"""

from __future__ import annotations

from dataclasses import dataclass
from typing import Tuple

import numpy as np


@dataclass(frozen=True)
class ActiveRegion:
    """The sub-rectangle of the camera frame that maps to [-1,1].

    Defaults to the middle 70 % of the frame. Hands are tracked poorly at the
    extreme edges anyway, so mapping the full frame would spend interaction
    range on the region where the data is worst.
    """

    x_min: float = 0.15
    x_max: float = 0.85
    y_min: float = 0.15
    y_max: float = 0.85

    def validate(self) -> None:
        if not (0.0 <= self.x_min < self.x_max <= 1.0):
            raise ValueError(f"bad x range: {self.x_min}..{self.x_max}")
        if not (0.0 <= self.y_min < self.y_max <= 1.0):
            raise ValueError(f"bad y range: {self.y_min}..{self.y_max}")


class CameraToInteraction:
    """Maps camera space to interaction space.

    This is the single place where image conventions are converted, and the
    only class that will need to change when the physical pyramid is
    calibrated against the camera.
    """

    def __init__(self, region: ActiveRegion, aspect: float = 1.0,
                 invert_y: bool = True) -> None:
        region.validate()
        self._r = region
        self._aspect = max(1e-6, aspect)
        self._invert_y = invert_y

    def set_aspect(self, aspect: float) -> None:
        self._aspect = max(1e-6, aspect)

    def point(self, p) -> Tuple[float, float, float]:
        """Map one camera-space point to interaction space."""
        r = self._r
        x = (float(p[0]) - r.x_min) / (r.x_max - r.x_min)
        y = (float(p[1]) - r.y_min) / (r.y_max - r.y_min)
        x = x * 2.0 - 1.0
        y = y * 2.0 - 1.0
        if self._invert_y:
            y = -y                      # image y is down, interaction y is up
        x *= self._aspect               # keep circles circular
        z = float(p[2]) if len(p) > 2 else 0.0
        return (x, y, z)

    def delta(self, d) -> Tuple[float, float, float]:
        """Map a camera-space *displacement*. No origin shift, only scale."""
        r = self._r
        dx = float(d[0]) / (r.x_max - r.x_min) * 2.0 * self._aspect
        dy = float(d[1]) / (r.y_max - r.y_min) * 2.0
        if self._invert_y:
            dy = -dy
        dz = float(d[2]) if len(d) > 2 else 0.0
        return (dx, dy, dz)


def apply_deadzone(value: float, deadzone: float) -> float:
    """Zero out sub-threshold motion, then rescale so there is no step.

    A naive deadzone (`if abs(v) < dz: return 0`) makes the object jump by
    `dz` the instant it engages. Rescaling the remainder keeps motion
    continuous across the boundary.
    """
    if deadzone <= 0.0:
        return value
    a = abs(value)
    if a <= deadzone:
        return 0.0
    return float(np.sign(value)) * (a - deadzone) / (1.0 - deadzone)
```

### pc/hologram_pc/interaction/types.py
```
"""Interaction-layer vocabulary.

The chain the brief asks for:

    HandState  ->  GestureState  ->  InteractionCommand

`HandState` is produced by the vision layer and knows about pixels.
`GestureState` is a classification: what the hand is *doing*.
`InteractionCommand` is what the object should *do about it* -- deltas only,
no absolute pose, so the renderer stays authoritative over object state.

Nothing here imports mediapipe, cv2, or any networking code.
"""

from __future__ import annotations

from dataclasses import dataclass, field
from enum import Enum
from typing import Optional, Sequence, Tuple


class GestureKind(str, Enum):
    """What a single hand is doing. Values are the wire representation."""

    NONE = "none"            # no hand present
    OPEN_PALM = "open_palm"  # tracked, deliberately not interacting
    PINCH = "pinch"          # thumb + index closed: the grab gesture
    FIST = "fist"            # all fingers curled: pause interaction
    POINT = "point"          # index extended, others curled: selection
    UNKNOWN = "unknown"      # tracked but not confidently classified


class InteractionKind(str, Enum):
    """What the interaction engine decided to do with the gesture(s)."""

    IDLE = "idle"
    ROTATE = "rotate"
    SCALE = "scale"
    TRANSLATE = "translate"
    SELECT = "select"
    PAUSED = "paused"


@dataclass(frozen=True)
class GestureState:
    """Classification of one hand at one instant."""

    hand_index: int
    handedness: str
    kind: GestureKind
    confidence: float
    # 0 = fully closed pinch, 1 = wide open. Continuous, so the client can
    # drive a visual affordance rather than only reacting to the threshold.
    pinch: float
    # Smoothed pinch-point position in interaction space, x/y in [0,1],
    # z is the hand's relative depth proxy.
    position: Tuple[float, float, float]
    # Per-second velocity in interaction space.
    velocity: Tuple[float, float, float]
    # Extended-finger flags, thumb..pinky. Useful for future gestures.
    fingers_extended: Tuple[bool, bool, bool, bool, bool] = (
        False, False, False, False, False)

    @property
    def is_pinching(self) -> bool:
        return self.kind is GestureKind.PINCH


@dataclass(frozen=True)
class InteractionCommand:
    """A frame's worth of object control. Deltas, never absolutes.

    Sending deltas rather than an absolute pose means a dropped or reordered
    packet degrades into a slightly smaller movement instead of a visible
    snap, and the renderer remains the single owner of object state.
    """

    kind: InteractionKind
    # radians this frame, applied in object space
    rotation_delta: Tuple[float, float, float] = (0.0, 0.0, 0.0)
    # multiplicative-ish scale delta; 0.0 means no change
    scale_delta: float = 0.0
    # normalised units this frame
    position_delta: Tuple[float, float, float] = (0.0, 0.0, 0.0)
    confidence: float = 0.0
    # id of whatever the user is pointing at, when kind is SELECT
    target: Optional[str] = None

    @property
    def is_idle(self) -> bool:
        return (
            self.kind in (InteractionKind.IDLE, InteractionKind.PAUSED)
            and self.rotation_delta == (0.0, 0.0, 0.0)
            and self.scale_delta == 0.0
            and self.position_delta == (0.0, 0.0, 0.0)
        )


@dataclass(frozen=True)
class InteractionFrame:
    """Everything the interaction layer produced for one tracking frame."""

    frame_id: int
    capture_ns: int
    gestures: Sequence[GestureState] = field(default_factory=tuple)
    command: InteractionCommand = field(
        default_factory=lambda: InteractionCommand(InteractionKind.IDLE))
```

### pc/hologram_pc/networking/protocol.py
```
"""The wire protocol. Small, versioned, and stale-tolerant.

Design rules taken from the brief:

* Send what the client *needs*, not what the CV stack *has*. The gesture
  engine has already reduced 21 landmarks x 2 hands into a handful of deltas,
  so the hot path ships those. Raw landmarks are available but off by default
  and only for the PC development UI, never for the iPhone.
* Every message carries a monotonic timestamp so the receiver can discard a
  packet that arrived after a newer one.
* Deltas, not absolute pose. A lost packet costs a fraction of a degree.

Message types, PC -> client:

    hello          once on connect: config the client needs
    object_control the hot path, ~60 Hz
    hand_debug     landmarks for the dev UI, opt-in per connection
    jarvis_visual  Phase 19 audio-reactive envelope (interface only for now)
    stats          low-rate telemetry for the diagnostics panel

Client -> PC:

    ping           latency probe, echoed back as pong
    subscribe      choose which streams this connection wants
    set_object     switch the active hologram object
"""

from __future__ import annotations

import json
import time
from dataclasses import asdict, dataclass, field
from typing import Any, Dict, List, Optional, Sequence

PROTOCOL_VERSION = 1

# Wall-clock epoch captured once, paired with a monotonic origin. Lets us emit
# a stable millisecond timeline that never goes backwards, even if the system
# clock is adjusted mid-session.
_T0_MONO_NS = time.perf_counter_ns()
_T0_WALL_MS = time.time() * 1000.0


def now_ms() -> float:
    """Monotonic milliseconds on a wall-clock-anchored timeline."""
    return _T0_WALL_MS + (time.perf_counter_ns() - _T0_MONO_NS) / 1e6


def stamp_from_ns(capture_ns: int) -> float:
    """Convert a capture perf_counter_ns stamp onto the same timeline."""
    return _T0_WALL_MS + (capture_ns - _T0_MONO_NS) / 1e6


def _r(v: float, n: int = 4) -> float:
    """Round for the wire.

    Full float64 repr costs ~17 bytes per number and the client cannot use
    the precision -- 4 decimals on a normalised delta is far below one pixel.
    Across 2 hands x 21 landmarks x 3 axes this is the difference between a
    ~2.5 KB and a ~1 KB frame.
    """
    return round(float(v), n)


@dataclass
class ObjectControl:
    """The hot-path message. Kept deliberately small."""

    timestamp: float
    frame_id: int
    interaction: str
    rotation_delta: Sequence[float] = (0.0, 0.0, 0.0)
    scale_delta: float = 0.0
    position_delta: Sequence[float] = (0.0, 0.0, 0.0)
    confidence: float = 0.0
    gesture: str = "none"
    pinch: float = 1.0
    hands: int = 0
    target: Optional[str] = None

    def to_wire(self) -> Dict[str, Any]:
        msg: Dict[str, Any] = {
            "t": "oc",                       # short key: this is the 60 Hz path
            "ts": _r(self.timestamp, 1),
            "id": self.frame_id,
            "ia": self.interaction,
            "g": self.gesture,
            "n": self.hands,
        }
        # Omit zero fields entirely; the client defaults them. On an idle
        # frame this halves the message.
        if any(self.rotation_delta):
            msg["r"] = [_r(v, 5) for v in self.rotation_delta]
        if self.scale_delta:
            msg["s"] = _r(self.scale_delta, 5)
        if any(self.position_delta):
            msg["p"] = [_r(v, 5) for v in self.position_delta]
        if self.confidence:
            msg["c"] = _r(self.confidence, 2)
        if self.pinch != 1.0:
            msg["pn"] = _r(self.pinch, 3)
        if self.target:
            msg["tg"] = self.target
        return msg


@dataclass
class HandDebug:
    """Landmarks for the PC development UI only.

    This is roughly 20x the size of an ObjectControl message, which is exactly
    why the iPhone never subscribes to it.
    """

    timestamp: float
    frame_id: int
    width: int
    height: int
    hands: List[Dict[str, Any]] = field(default_factory=list)

    def to_wire(self) -> Dict[str, Any]:
        return {
            "t": "hd",
            "ts": _r(self.timestamp, 1),
            "id": self.frame_id,
            "w": self.width,
            "h": self.height,
            "hands": self.hands,
        }


@dataclass
class JarvisVisual:
    """Phase 19 interface. Compact audio envelope, never raw audio.

    Defined now so the client can render against it and the contract is
    settled; the PC-side audio tap is not implemented in this version.
    """

    timestamp: float
    amplitude: float = 0.0          # 0-1 instantaneous
    energy: float = 0.0             # 0-1 smoothed
    speaking: bool = False
    bands: Sequence[float] = ()     # coarse FFT bands, 0-1 each

    def to_wire(self) -> Dict[str, Any]:
        return {
            "t": "jv",
            "ts": _r(self.timestamp, 1),
            "a": _r(self.amplitude, 3),
            "e": _r(self.energy, 3),
            "sp": self.speaking,
            "b": [_r(v, 3) for v in self.bands],
        }


def hello(object_id: str, objects: Sequence[Dict[str, Any]],
          stale_ms: int, send_hz: float) -> Dict[str, Any]:
    return {
        "t": "hello",
        "v": PROTOCOL_VERSION,
        "ts": _r(now_ms(), 1),
        "object": object_id,
        "objects": list(objects),
        "staleMs": stale_ms,
        "sendHz": send_hz,
    }


def stats(payload: Dict[str, Any]) -> Dict[str, Any]:
    return {"t": "stats", "ts": _r(now_ms(), 1), **payload}


def pong(client_ts: Any) -> Dict[str, Any]:
    """Echo the client's stamp so it can compute RTT without a shared clock."""
    return {"t": "pong", "ts": _r(now_ms(), 1), "cts": client_ts}


def encode(msg: Dict[str, Any]) -> str:
    # separators drop the spaces json.dumps adds by default -- a few percent
    # off every frame for free.
    return json.dumps(msg, separators=(",", ":"))


def hand_to_wire(hand, include_world: bool = False) -> Dict[str, Any]:
    """Serialise one HandState for the debug stream."""
    out: Dict[str, Any] = {
        "h": hand.handedness,
        "sc": _r(hand.handedness_score, 2),
        # Flat array, not [{x,y,z}...]: same numbers, ~40 % fewer bytes.
        "lm": [_r(v, 4) for v in hand.landmarks[:, :3].ravel().tolist()],
    }
    if include_world and hand.world_landmarks is not None:
        out["wl"] = [_r(v, 4) for v in hand.world_landmarks.ravel().tolist()]
    return out
```

```
"""aiohttp server: static client, WebSocket control channel, dev-UI camera feed.

Why aiohttp and not FastAPI: the brief warns against putting HTTP overhead in
the real-time path. The real-time path here is a WebSocket, and aiohttp serves
both the static bundle and the socket from one port with no ASGI layer, no
pydantic validation on the hot path, and one dependency. FastAPI would add a
stack we would then have to route around.

The broadcast task samples the pipeline's latest state at `send_hz`. It does
not consume a queue -- if the pipeline produced three frames since the last
tick, two are simply never sent. That is the correct behaviour for a control
stream: the newest hand position is the only one that matters.

The MJPEG endpoint is **development only**. The iPhone never touches it; it
exists so the PC dev UI can show Panel 1. Video is never sent to the phone.
"""

from __future__ import annotations

import asyncio
import json
import logging
import socket
from dataclasses import asdict
from pathlib import Path
from typing import Any, Dict, Optional, Set

import cv2
from aiohttp import WSMsgType, web

from ..config import REPO_ROOT, Config
from ..interaction.types import InteractionKind
from ..networking import protocol as P
from ..pipeline import Pipeline

log = logging.getLogger(__name__)

OBJECT_CATALOG = [
    {"id": "atom", "name": "Atom"},
    {"id": "core", "name": "Holographic Core"},
    {"id": "arcreactor", "name": "Arc Reactor"},
]


class Hub:
    """Tracks connected clients and what each has subscribed to."""

    def __init__(self) -> None:
        self.sockets: Set[web.WebSocketResponse] = set()
        self.wants_debug: Set[web.WebSocketResponse] = set()
        self.sent = 0
        self.object_id = "atom"

    def add(self, ws: web.WebSocketResponse) -> None:
        self.sockets.add(ws)

    def remove(self, ws: web.WebSocketResponse) -> None:
        self.sockets.discard(ws)
        self.wants_debug.discard(ws)

    async def broadcast(self, payload: str, only: Optional[Set] = None) -> None:
        targets = self.sockets if only is None else (self.sockets & only)
        if not targets:
            return
        dead = []
        for ws in list(targets):
            if ws.closed:
                dead.append(ws)
                continue
            try:
                await ws.send_str(payload)
                self.sent += 1
            except (ConnectionResetError, RuntimeError):
                dead.append(ws)
        for ws in dead:
            self.remove(ws)


def local_ip() -> str:
    """Best-effort LAN address. No packet is actually sent to 8.8.8.8 -- a
    UDP connect just makes the OS pick the outbound interface."""
    s = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    try:
        s.connect(("8.8.8.8", 80))
        return s.getsockname()[0]
    except OSError:
        return "127.0.0.1"
    finally:
        s.close()


# ------------------------------------------------------------------ routes

async def ws_handler(request: web.Request) -> web.WebSocketResponse:
    hub: Hub = request.app["hub"]
    cfg: Config = request.app["cfg"]
    ws = web.WebSocketResponse(heartbeat=cfg.network.ping_interval_s)
    await ws.prepare(request)
    hub.add(ws)
    peer = request.remote
    log.info("client connected: %s (%d total)", peer, len(hub.sockets))

    await ws.send_str(P.encode(P.hello(
        hub.object_id, OBJECT_CATALOG,
        cfg.network.stale_packet_ms, cfg.network.send_hz)))

    try:
        async for msg in ws:
            if msg.type is not WSMsgType.TEXT:
                continue
            try:
                data = json.loads(msg.data)
            except json.JSONDecodeError:
                continue
            kind = data.get("t")
            if kind == "ping":
                await ws.send_str(P.encode(P.pong(data.get("cts"))))
            elif kind == "subscribe":
                if data.get("debug"):
                    hub.wants_debug.add(ws)
                else:
                    hub.wants_debug.discard(ws)
            elif kind == "set_object":
                obj = str(data.get("object", "atom"))
                if any(o["id"] == obj for o in OBJECT_CATALOG):
                    hub.object_id = obj
                    await hub.broadcast(P.encode(
                        {"t": "object", "ts": P.now_ms(), "object": obj}))
    finally:
        hub.remove(ws)
        log.info("client disconnected: %s (%d left)", peer, len(hub.sockets))
    return ws


async def status_handler(request: web.Request) -> web.Response:
    pipeline: Pipeline = request.app["pipeline"]
    hub: Hub = request.app["hub"]
    st = asdict(pipeline.status())
    st["clients"] = len(hub.sockets)
    st["packets_sent"] = hub.sent
    st["object"] = hub.object_id
    st["objects"] = OBJECT_CATALOG
    return web.json_response(st)


async def mjpeg_handler(request: web.Request) -> web.StreamResponse:
    """Camera feed for the PC development UI only. Never used by the iPhone."""
    pipeline: Pipeline = request.app["pipeline"]
    response = web.StreamResponse(status=200, headers={
        "Content-Type": "multipart/x-mixed-replace; boundary=frame",
        "Cache-Control": "no-store, no-cache, must-revalidate",
        "Pragma": "no-cache",
    })
    await response.prepare(request)
    quality = [int(cv2.IMWRITE_JPEG_QUALITY), 70]
    try:
        while True:
            frame = pipeline.latest_frame_bgr()
            if frame is not None:
                ok, buf = cv2.imencode(".jpg", frame, quality)
                if ok:
                    await response.write(
                        b"--frame\r\nContent-Type: image/jpeg\r\n"
                        b"Content-Length: " + str(len(buf)).encode() +
                        b"\r\n\r\n" + buf.tobytes() + b"\r\n")
            # 20 fps is plenty for a debug panel and leaves the CPU to the
            # thing that actually matters.
            await asyncio.sleep(0.05)
    except (ConnectionResetError, asyncio.CancelledError):
        pass
    return response


# --------------------------------------------------------------- broadcast

async def broadcast_task(app: web.Application) -> None:
    """Sample pipeline state at send_hz and push it to every client."""
    cfg: Config = app["cfg"]
    pipeline: Pipeline = app["pipeline"]
    hub: Hub = app["hub"]

    period = 1.0 / max(1.0, cfg.network.send_hz)
    idle_period = 1.0 / max(0.5, cfg.network.idle_send_hz)
    last_seq = -1
    last_sent = 0.0
    stats_period = 1.0 / max(0.5, cfg.diagnostics.stats_hz)
    last_stats = 0.0

    try:
        while True:
            await asyncio.sleep(period)
            if not hub.sockets:
                continue

            now = asyncio.get_running_loop().time()
            frame, seq = pipeline.latest_interaction()
            if frame is None:
                continue

            is_new = seq != last_seq
            cmd = frame.command
            # Send on new state, or at the idle heartbeat rate so the client
            # can distinguish "nothing is happening" from "the link died".
            if not is_new and (now - last_sent) < idle_period:
                continue
            last_seq = seq
            last_sent = now

            primary = frame.gestures[0] if frame.gestures else None
            oc = P.ObjectControl(
                timestamp=P.stamp_from_ns(frame.capture_ns),
                frame_id=frame.frame_id,
                interaction=cmd.kind.value,
                rotation_delta=cmd.rotation_delta,
                scale_delta=cmd.scale_delta,
                position_delta=cmd.position_delta,
                confidence=cmd.confidence,
                gesture=primary.kind.value if primary else "none",
                pinch=primary.pinch if primary else 1.0,
                hands=len(frame.gestures),
                target=cmd.target,
            )
            await hub.broadcast(P.encode(oc.to_wire()))

            if hub.wants_debug:
                tracking = pipeline.latest_tracking()
                if tracking is not None:
                    hd = P.HandDebug(
                        timestamp=P.stamp_from_ns(tracking.stamps.capture_ns),
                        frame_id=tracking.frame_id,
                        width=tracking.frame_width,
                        height=tracking.frame_height,
                        hands=[P.hand_to_wire(h) for h in tracking.hands],
                    )
                    await hub.broadcast(P.encode(hd.to_wire()),
                                        only=hub.wants_debug)

            if (now - last_stats) >= stats_period:
                last_stats = now
                st = asdict(pipeline.status())
                st["clients"] = len(hub.sockets)
                await hub.broadcast(P.encode(P.stats(st)))
    except asyncio.CancelledError:
        pass


# ------------------------------------------------------------------ wiring

async def _on_startup(app: web.Application) -> None:
    app["broadcast"] = asyncio.create_task(broadcast_task(app))


async def _on_cleanup(app: web.Application) -> None:
    task = app.get("broadcast")
    if task:
        task.cancel()
        try:
            await task
        except asyncio.CancelledError:
            pass
    for ws in list(app["hub"].sockets):
        await ws.close(code=1001, message=b"server shutdown")
    app["pipeline"].stop()


def build_app(cfg: Config, pipeline: Pipeline) -> web.Application:
    app = web.Application()
    app["cfg"] = cfg
    app["pipeline"] = pipeline
    app["hub"] = Hub()

    app.router.add_get("/ws", ws_handler)
    app.router.add_get("/api/status", status_handler)
    app.router.add_get("/api/camera.mjpg", mjpeg_handler)

    # 3D model assets. Kept out of the client bundle deliberately: a 20 MB GLB
    # inside the JS bundle would be parsed by the bundler on every build and
    # re-downloaded whenever any code changed. Served as a plain static file it
    # is cached by the browser independently of the app.
    models_dir = REPO_ROOT / "models"
    if models_dir.exists():
        app.router.add_static("/models", models_dir, show_index=False)
        log.info("Serving models from %s", models_dir)

    dist = cfg.network.resolved_client_dist()
    if dist.exists():
        async def index(_request: web.Request) -> web.FileResponse:
            return web.FileResponse(dist / "index.html")

        app.router.add_get("/", index)
        app.router.add_static("/", dist, show_index=False)
        log.info("Serving client bundle from %s", dist)
    else:
        async def missing(_request: web.Request) -> web.Response:
            return web.Response(
                status=503,
                content_type="text/html",
                text=(
                    "<h1>Client bundle not built</h1>"
                    f"<p>Expected <code>{dist}</code>.</p>"
                    "<p>Run:</p><pre>cd client\nnpm install\nnpm run build</pre>"
                ),
            )
        app.router.add_get("/", missing)
        log.warning("Client bundle missing at %s -- serving a build hint page", dist)

    app.on_startup.append(_on_startup)
    app.on_cleanup.append(_on_cleanup)
    return app
```

### pc/hologram_pc/vision/camera.py

```
"""Low-latency webcam capture.

Design rule from the spec: "prefer dropping stale frames over building a
queue of old frames". This module enforces that structurally rather than by
convention -- a dedicated grab thread reads the camera as fast as the device
delivers, and overwrites a *single* slot. There is no queue, so a backlog of
stale frames is not merely discouraged, it is unrepresentable.

Consumers poll `latest()`. If the consumer is slower than the camera, frames
are silently dropped and the consumer always sees the newest one.
"""

from __future__ import annotations

import logging
import threading
import time
from dataclasses import dataclass
from typing import Optional, Tuple

import cv2
import numpy as np

log = logging.getLogger(__name__)

_BACKENDS = {
    "dshow": cv2.CAP_DSHOW,   # DirectShow: opens ~1s faster than MSMF on Windows
    "msmf": cv2.CAP_MSMF,
    "any": cv2.CAP_ANY,
}


class CameraError(RuntimeError):
    """Raised with an actionable message when the camera cannot be used."""


@dataclass(frozen=True)
class Frame:
    """A captured frame plus the monotonic instant it became available."""

    seq: int
    image: np.ndarray      # BGR, HxWx3 uint8
    capture_ns: int


@dataclass
class CameraInfo:
    index: int
    backend: str
    width: int
    height: int
    fps: float
    fourcc: str


class CameraSource:
    """Threaded latest-frame-wins camera reader."""

    def __init__(self, cfg) -> None:
        self._cfg = cfg
        self._cap: Optional[cv2.VideoCapture] = None
        self._thread: Optional[threading.Thread] = None
        self._stop = threading.Event()
        self._lock = threading.Lock()
        self._slot: Optional[Frame] = None
        self._seq = 0
        self._dropped = 0
        self._consumed_seq = -1
        self._read_failures = 0
        self._fatal: Optional[str] = None
        self._brightness = 0.0
        self._seq_since_bright = 0
        self.info: Optional[CameraInfo] = None

    # ---------------------------------------------------------------- open

    def open(self) -> CameraInfo:
        cfg = self._cfg
        backend_id = _BACKENDS.get(cfg.backend.lower())
        if backend_id is None:
            raise CameraError(
                f"Unknown camera backend {cfg.backend!r}. "
                f"Expected one of: {', '.join(sorted(_BACKENDS))}"
            )

        log.info("Opening camera index=%s backend=%s", cfg.index, cfg.backend)
        cap = cv2.VideoCapture(cfg.index, backend_id)
        if not cap.isOpened():
            cap.release()
            raise CameraError(
                f"Camera unavailable: could not open index {cfg.index} using the "
                f"'{cfg.backend}' backend.\n"
                "  - Check Settings > Privacy & security > Camera is enabled for desktop apps.\n"
                "  - Close any other app holding the webcam (Teams, Zoom, Camera).\n"
                "  - Run 'python pc/scripts/check_env.py' to list working camera indices."
            )

        # Request format *before* the first read; some UVC drivers latch on open.
        if cfg.fourcc:
            cap.set(cv2.CAP_PROP_FOURCC, cv2.VideoWriter_fourcc(*cfg.fourcc))
        cap.set(cv2.CAP_PROP_FRAME_WIDTH, cfg.width)
        cap.set(cv2.CAP_PROP_FRAME_HEIGHT, cfg.height)
        cap.set(cv2.CAP_PROP_FPS, cfg.fps)
        # Ask the driver for the shallowest possible internal buffer. Not all
        # backends honour it, which is exactly why the grab thread exists.
        cap.set(cv2.CAP_PROP_BUFFERSIZE, cfg.buffer_size)
        if not cfg.autofocus:
            # Autofocus hunting causes periodic multi-frame latency spikes.
            cap.set(cv2.CAP_PROP_AUTOFOCUS, 0)
        if not cfg.auto_exposure:
            # 0.25 is the DirectShow magic value for "manual exposure".
            # Measured on the reference machine: auto = 7.5 fps, manual = 30 fps,
            # at identical image brightness. See docs/latency.md.
            cap.set(cv2.CAP_PROP_AUTO_EXPOSURE, 0.25)
            cap.set(cv2.CAP_PROP_EXPOSURE, cfg.exposure)

        deadline = time.perf_counter() + cfg.open_timeout_s
        ok, probe = cap.read()
        while not ok and time.perf_counter() < deadline:
            time.sleep(0.05)
            ok, probe = cap.read()
        if not ok or probe is None:
            cap.release()
            raise CameraError(
                f"Camera at index {cfg.index} opened but delivered no frames within "
                f"{cfg.open_timeout_s:.0f}s. The device may be claimed by another "
                "process, or be a disconnected virtual camera."
            )

        for _ in range(max(0, cfg.warmup_frames)):
            cap.read()  # let auto-exposure settle before we report FPS

        fcc = int(cap.get(cv2.CAP_PROP_FOURCC))
        self._cap = cap
        self.info = CameraInfo(
            index=cfg.index,
            backend=cfg.backend,
            width=int(cap.get(cv2.CAP_PROP_FRAME_WIDTH)),
            height=int(cap.get(cv2.CAP_PROP_FRAME_HEIGHT)),
            fps=float(cap.get(cv2.CAP_PROP_FPS)),
            fourcc="".join(chr((fcc >> (8 * i)) & 0xFF) for i in range(4)).strip("\x00 "),
        )
        log.info(
            "Camera ready: %dx%d @%.1ffps fourcc=%s",
            self.info.width, self.info.height, self.info.fps, self.info.fourcc or "?",
        )
        if (self.info.width, self.info.height) != (cfg.width, cfg.height):
            log.warning(
                "Camera negotiated %dx%d instead of the requested %dx%d",
                self.info.width, self.info.height, cfg.width, cfg.height,
            )
        if cfg.fourcc and self.info.fourcc and self.info.fourcc != cfg.fourcc:
            # Harmless -- many UVC webcams expose only one pixel format. Worth
            # saying out loud so nobody chases a phantom MJPG speedup.
            log.info(
                "Camera ignored the %s request and is delivering %s; this device "
                "likely supports only one pixel format.", cfg.fourcc, self.info.fourcc,
            )
        return self.info

    # --------------------------------------------------------------- start

    def start(self) -> None:
        if self._cap is None:
            raise CameraError("start() called before open()")
        self._stop.clear()
        self._thread = threading.Thread(target=self._loop, name="camera-grab", daemon=True)
        self._thread.start()

    def _loop(self) -> None:
        cap = self._cap
        assert cap is not None
        flip = self._cfg.flip_horizontal
        while not self._stop.is_set():
            ok, img = cap.read()
            ts = time.perf_counter_ns()
            if not ok or img is None:
                self._read_failures += 1
                if self._read_failures >= 30:
                    self._fatal = (
                        "Camera stopped delivering frames (30 consecutive read "
                        "failures). It was probably unplugged or claimed by another app."
                    )
                    log.error("%s", self._fatal)
                    return
                time.sleep(0.01)
                continue
            self._read_failures = 0
            if flip:
                # Mirror so the operator's right hand appears on the right.
                img = cv2.flip(img, 1)
            self._seq_since_bright += 1
            if self._seq_since_bright >= 15:
                # Subsampled so the brightness probe costs ~1/64 of a full mean.
                self._seq_since_bright = 0
                self._brightness = float(img[::8, ::8].mean())
            with self._lock:
                if self._slot is not None and self._slot.seq > self._consumed_seq:
                    self._dropped += 1     # overwriting a frame nobody consumed
                self._seq += 1
                self._slot = Frame(seq=self._seq, image=img, capture_ns=ts)

    # ---------------------------------------------------------------- read

    def latest(self) -> Tuple[Optional[Frame], bool]:
        """Return (frame, is_new). Never blocks, never returns a stale queue."""
        with self._lock:
            frame = self._slot
            if frame is None:
                return None, False
            is_new = frame.seq != self._consumed_seq
            self._consumed_seq = frame.seq
            return frame, is_new

    @property
    def dropped_frames(self) -> int:
        return self._dropped

    @property
    def captured_frames(self) -> int:
        return self._seq

    @property
    def fatal_error(self) -> Optional[str]:
        return self._fatal

    @property
    def brightness(self) -> float:
        """Mean pixel value, 0-255, sampled every 15th frame."""
        return self._brightness

    @property
    def is_low_light(self) -> bool:
        return 0.0 < self._brightness < self._cfg.low_light_warn_level

    # --------------------------------------------------------------- close

    def close(self) -> None:
        self._stop.set()
        if self._thread is not None:
            self._thread.join(timeout=2.0)
            self._thread = None
        if self._cap is not None:
            self._cap.release()
            self._cap = None

    def __enter__(self) -> "CameraSource":
        self.open()
        self.start()
        return self

    def __exit__(self, *exc) -> None:
        self.close()
```

```
"""MediaPipe Hand Landmarker in LIVE_STREAM mode.

LIVE_STREAM is the asynchronous running mode: `detect_async` returns
immediately and MediaPipe invokes `result_callback` on its own worker thread
when inference finishes. That decouples our capture/render loop from
inference time, which is the whole point for a real-time control loop.

Two rules the Tasks API enforces, both handled here:
  * timestamps handed to detect_async must be strictly increasing
  * the callback runs on a MediaPipe thread, not ours

Verified against mediapipe 1.0.1. Note that 1.x removed the legacy
`mediapipe.python.solutions` package, so this is the only supported path.
"""

from __future__ import annotations

import logging
import threading
import time
from collections import OrderedDict
from typing import Optional

import numpy as np

import mediapipe as mp
from mediapipe.tasks import python as mp_python
from mediapipe.tasks.python import vision as mp_vision

from .types import FrameStamps, HandState, TrackingFrame

log = logging.getLogger(__name__)


class LandmarkerError(RuntimeError):
    """Raised with an actionable message when the landmarker cannot start."""


class HandTracker:
    """Async wrapper around MediaPipe HandLandmarker.

    Thread-safety: `submit()` is called from the capture/render loop;
    `_on_result()` is called from a MediaPipe worker thread. They meet at
    `self._slot`, guarded by `self._lock`. As with the camera there is a
    single slot and no queue -- the latest hand state is the only one that
    matters, so a slow consumer drops results instead of accumulating them.
    """

    def __init__(self, cfg) -> None:
        self._cfg = cfg
        self._landmarker: Optional[mp_vision.HandLandmarker] = None
        self._lock = threading.Lock()
        self._slot: Optional[TrackingFrame] = None
        self._consumed_id = -1
        # timestamp_ms -> (frame_id, capture_ns, submit_ns); bounded so a
        # dropped/never-returned inference cannot leak memory.
        self._pending: "OrderedDict[int, tuple]" = OrderedDict()
        self._last_ts_ms = -1
        self._t0_ns = time.perf_counter_ns()
        self._submitted = 0
        self._completed = 0
        self.delegate_used = "cpu"

    # ---------------------------------------------------------------- open

    def open(self) -> None:
        cfg = self._cfg
        model_path = cfg.resolved_model_path()
        if not model_path.exists():
            raise LandmarkerError(
                f"MediaPipe model missing: {model_path}\n"
                "  Download it with:  python pc/scripts/download_model.py\n"
                "  Or manually from https://storage.googleapis.com/mediapipe-models/"
                "hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task"
            )
        size = model_path.stat().st_size
        if size < 1_000_000:
            raise LandmarkerError(
                f"MediaPipe model at {model_path} is only {size} bytes -- the "
                "download was truncated. Delete it and re-run download_model.py."
            )

        requested = cfg.delegate.lower()
        order = {
            "auto": ["cpu"],   # see docstring below: GPU delegate is Linux/Android only
            "cpu": ["cpu"],
            "gpu": ["gpu", "cpu"],
        }.get(requested)
        if order is None:
            raise LandmarkerError(
                f"Unknown delegate {cfg.delegate!r}; expected auto, cpu or gpu."
            )

        last_error: Optional[Exception] = None
        for choice in order:
            try:
                self._landmarker = self._build(model_path, choice)
                self.delegate_used = choice
                log.info("HandLandmarker ready (delegate=%s, num_hands=%d)",
                         choice, cfg.num_hands)
                return
            except Exception as e:                     # noqa: BLE001 - report and fall back
                last_error = e
                log.warning("Delegate '%s' unavailable (%s); falling back.", choice, e)

        raise LandmarkerError(
            f"Could not create the HandLandmarker with any delegate in {order}. "
            f"Last error: {last_error}"
        )

    def _build(self, model_path, delegate: str) -> mp_vision.HandLandmarker:
        cfg = self._cfg
        delegate_enum = (
            mp_python.BaseOptions.Delegate.GPU if delegate == "gpu"
            else mp_python.BaseOptions.Delegate.CPU
        )
        options = mp_vision.HandLandmarkerOptions(
            base_options=mp_python.BaseOptions(
                model_asset_path=str(model_path),
                delegate=delegate_enum,
            ),
            running_mode=mp_vision.RunningMode.LIVE_STREAM,
            num_hands=cfg.num_hands,
            min_hand_detection_confidence=cfg.min_hand_detection_confidence,
            min_hand_presence_confidence=cfg.min_hand_presence_confidence,
            min_tracking_confidence=cfg.min_tracking_confidence,
            result_callback=self._on_result,
        )
        return mp_vision.HandLandmarker.create_from_options(options)

    # -------------------------------------------------------------- submit

    def submit(self, bgr: np.ndarray, frame_id: int, capture_ns: int) -> bool:
        """Hand a frame to MediaPipe. Returns False if the frame was skipped.

        Skipping happens only when the derived millisecond timestamp is not
        strictly greater than the previous one (i.e. two frames landed inside
        the same millisecond). Submitting those would make the Tasks API throw.
        """
        if self._landmarker is None:
            raise LandmarkerError("submit() called before open()")

        ts_ms = (capture_ns - self._t0_ns) // 1_000_000
        if ts_ms <= self._last_ts_ms:
            return False
        self._last_ts_ms = ts_ms

        rgb = np.ascontiguousarray(bgr[:, :, ::-1])   # BGR -> RGB without a copy of cvtColor's LUT path
        image = mp.Image(image_format=mp.ImageFormat.SRGB, data=rgb)

        submit_ns = time.perf_counter_ns()
        with self._lock:
            self._pending[ts_ms] = (frame_id, capture_ns, submit_ns, bgr.shape[1], bgr.shape[0])
            while len(self._pending) > 16:
                self._pending.popitem(last=False)
        self._submitted += 1
        self._landmarker.detect_async(image, ts_ms)
        return True

    # ------------------------------------------------------------ callback

    def _on_result(self, result, output_image, timestamp_ms: int) -> None:
        """Runs on a MediaPipe worker thread."""
        result_ns = time.perf_counter_ns()
        with self._lock:
            meta = self._pending.pop(timestamp_ms, None)
        if meta is None:
            # Result for a frame we already evicted; nothing useful to pair it to.
            return
        frame_id, capture_ns, submit_ns, width, height = meta

        hands = []
        for i, lm_list in enumerate(result.hand_landmarks):
            landmarks = np.asarray(
                [(lm.x, lm.y, lm.z) for lm in lm_list], dtype=np.float32
            )
            world = None
            if i < len(result.hand_world_landmarks):
                world = np.asarray(
                    [(lm.x, lm.y, lm.z) for lm in result.hand_world_landmarks[i]],
                    dtype=np.float32,
                )
            handed = result.handedness[i][0] if i < len(result.handedness) else None
            hands.append(
                HandState(
                    index=i,
                    handedness=handed.category_name if handed else "Unknown",
                    handedness_score=float(handed.score) if handed else 0.0,
                    landmarks=landmarks,
                    world_landmarks=world,
                )
            )

        tf = TrackingFrame(
            frame_id=frame_id,
            stamps=FrameStamps(
                capture_ns=capture_ns,
                mp_submit_ns=submit_ns,
                mp_result_ns=result_ns,
            ),
            hands=tuple(hands),
            frame_width=width,
            frame_height=height,
        )
        with self._lock:
            self._slot = tf
            self._completed += 1

    # ---------------------------------------------------------------- read

    def latest(self) -> tuple[Optional[TrackingFrame], bool]:
        """Return (tracking_frame, is_new). Latest-wins, never queued."""
        with self._lock:
            tf = self._slot
            if tf is None:
                return None, False
            is_new = tf.frame_id != self._consumed_id
            self._consumed_id = tf.frame_id
            return tf, is_new

    @property
    def in_flight(self) -> int:
        with self._lock:
            return len(self._pending)

    @property
    def submitted(self) -> int:
        return self._submitted

    @property
    def completed(self) -> int:
        return self._completed

    # --------------------------------------------------------------- close

    def close(self) -> None:
        if self._landmarker is not None:
            self._landmarker.close()
            self._landmarker = None

    def __enter__(self) -> "HandTracker":
        self.open()
        return self

    def __exit__(self, *exc) -> None:
        self.close()
```

```
"""Landmark drawing.

MediaPipe 1.x dropped `mediapipe.python.solutions.drawing_utils`, so the
skeleton overlay is drawn directly with OpenCV against the topology declared
in `types.HAND_CONNECTIONS`.

This module is debug-only. Nothing here runs in performance mode, and nothing
downstream depends on it -- it exists so a human can see what the tracker sees.
"""

from __future__ import annotations

from typing import Iterable, Sequence

import cv2
import numpy as np

from .types import HAND_CONNECTIONS, HandLandmarkIndex, HandState

# BGR. Per-finger colouring makes it obvious at a glance when the model
# mislabels a digit.
_FINGER_COLORS = {
    "thumb": (80, 180, 255),
    "index": (80, 255, 140),
    "middle": (255, 210, 80),
    "ring": (255, 130, 200),
    "pinky": (170, 120, 255),
    "palm": (200, 200, 200),
}

_CONNECTION_GROUP = {}
for _c in HAND_CONNECTIONS:
    _a, _b = _c
    if _b <= 4:
        _CONNECTION_GROUP[_c] = "thumb"
    elif _b <= 8:
        _CONNECTION_GROUP[_c] = "index"
    elif _b <= 12:
        _CONNECTION_GROUP[_c] = "middle"
    elif _b <= 16:
        _CONNECTION_GROUP[_c] = "ring"
    else:
        _CONNECTION_GROUP[_c] = "pinky"
_CONNECTION_GROUP[(0, 17)] = "palm"
_CONNECTION_GROUP[(5, 9)] = "palm"
_CONNECTION_GROUP[(9, 13)] = "palm"
_CONNECTION_GROUP[(13, 17)] = "palm"

_HANDEDNESS_COLOR = {"Left": (120, 200, 255), "Right": (140, 255, 160)}


def _to_pixels(landmarks: np.ndarray, width: int, height: int) -> np.ndarray:
    """Normalised (N,3) -> integer pixel (N,2), clipped to the frame."""
    pts = np.empty((landmarks.shape[0], 2), dtype=np.int32)
    pts[:, 0] = np.clip(landmarks[:, 0] * width, 0, width - 1).astype(np.int32)
    pts[:, 1] = np.clip(landmarks[:, 1] * height, 0, height - 1).astype(np.int32)
    return pts


def draw_hands(
    image: np.ndarray,
    hands: Sequence[HandState],
    *,
    draw_connections: bool = True,
    draw_landmarks: bool = True,
    draw_handedness: bool = True,
) -> np.ndarray:
    """Draw hand skeletons onto `image` in place. Returns the same array."""
    h, w = image.shape[:2]
    for hand in hands:
        pts = _to_pixels(hand.landmarks, w, h)

        if draw_connections:
            for conn in HAND_CONNECTIONS:
                a, b = conn
                color = _FINGER_COLORS[_CONNECTION_GROUP.get(conn, "palm")]
                cv2.line(image, tuple(pts[a]), tuple(pts[b]), color, 2, cv2.LINE_AA)

        if draw_landmarks:
            for i, (x, y) in enumerate(pts):
                is_tip = i in (4, 8, 12, 16, 20)
                cv2.circle(image, (int(x), int(y)), 5 if is_tip else 3,
                           (255, 255, 255), -1, cv2.LINE_AA)
                cv2.circle(image, (int(x), int(y)), 5 if is_tip else 3,
                           (30, 30, 30), 1, cv2.LINE_AA)

        if draw_handedness:
            wrist = pts[HandLandmarkIndex.WRIST]
            label = f"{hand.handedness} {hand.handedness_score:.2f}"
            color = _HANDEDNESS_COLOR.get(hand.handedness, (255, 255, 255))
            org = (int(wrist[0]) - 30, max(18, int(wrist[1]) + 24))
            cv2.putText(image, label, org, cv2.FONT_HERSHEY_SIMPLEX, 0.55,
                        (0, 0, 0), 3, cv2.LINE_AA)
            cv2.putText(image, label, org, cv2.FONT_HERSHEY_SIMPLEX, 0.55,
                        color, 1, cv2.LINE_AA)
    return image


def draw_text_block(
    image: np.ndarray,
    lines: Iterable[str],
    *,
    origin: tuple = (10, 10),
    line_height: int = 20,
    scale: float = 0.5,
    color: tuple = (230, 230, 230),
    bg: bool = True,
) -> np.ndarray:
    """Draw a small HUD panel of text with a dark backing plate."""
    lines = list(lines)
    if not lines:
        return image
    x, y = origin
    if bg:
        # Measure the real rendered width; a chars-times-constant estimate
        # under-sizes the plate and lets long stat lines spill off it.
        pad = 8
        widest = max(
            cv2.getTextSize(s, cv2.FONT_HERSHEY_SIMPLEX, scale, 1)[0][0]
            for s in lines
        )
        w = min(image.shape[1] - x, widest + pad * 2 + 8)
        h = min(image.shape[0] - y, line_height * len(lines) + pad * 2)
        overlay = image[y:y + h, x:x + w]
        if overlay.size:
            cv2.addWeighted(overlay, 0.35,
                            np.zeros_like(overlay), 0.65, 0, dst=overlay)
    for i, text in enumerate(lines):
        ty = y + 8 + line_height * (i + 1) - 4
        cv2.putText(image, text, (x + 8, ty), cv2.FONT_HERSHEY_SIMPLEX, scale,
                    (0, 0, 0), 3, cv2.LINE_AA)
        cv2.putText(image, text, (x + 8, ty), cv2.FONT_HERSHEY_SIMPLEX, scale,
                    color, 1, cv2.LINE_AA)
    return image
```

```
"""Vision-layer vocabulary.

This module is the boundary between MediaPipe and the rest of the system.
Nothing downstream (gesture engine, networking, renderer) should import
mediapipe directly -- it consumes these types instead. That keeps the
landmark backend swappable and keeps object code ignorant of the CV stack.
"""

from __future__ import annotations

from dataclasses import dataclass, field
from enum import IntEnum
from typing import Optional, Sequence, Tuple

import numpy as np


class HandLandmarkIndex(IntEnum):
    """Canonical MediaPipe 21-point hand topology indices."""

    WRIST = 0
    THUMB_CMC = 1
    THUMB_MCP = 2
    THUMB_IP = 3
    THUMB_TIP = 4
    INDEX_MCP = 5
    INDEX_PIP = 6
    INDEX_DIP = 7
    INDEX_TIP = 8
    MIDDLE_MCP = 9
    MIDDLE_PIP = 10
    MIDDLE_DIP = 11
    MIDDLE_TIP = 12
    RING_MCP = 13
    RING_PIP = 14
    RING_DIP = 15
    RING_TIP = 16
    PINKY_MCP = 17
    PINKY_PIP = 18
    PINKY_DIP = 19
    PINKY_TIP = 20


NUM_LANDMARKS = 21

# MediaPipe 1.x removed mediapipe.python.solutions (and with it the
# HAND_CONNECTIONS constant and drawing_utils), so the topology is declared
# here rather than imported. See docs/architecture.md.
HAND_CONNECTIONS: Tuple[Tuple[int, int], ...] = (
    # thumb
    (0, 1), (1, 2), (2, 3), (3, 4),
    # index
    (0, 5), (5, 6), (6, 7), (7, 8),
    # middle
    (5, 9), (9, 10), (10, 11), (11, 12),
    # ring
    (9, 13), (13, 14), (14, 15), (15, 16),
    # pinky
    (13, 17), (17, 18), (18, 19), (19, 20),
    # palm closure
    (0, 17),
)

FINGERTIPS: Tuple[int, ...] = (
    HandLandmarkIndex.THUMB_TIP,
    HandLandmarkIndex.INDEX_TIP,
    HandLandmarkIndex.MIDDLE_TIP,
    HandLandmarkIndex.RING_TIP,
    HandLandmarkIndex.PINKY_TIP,
)


@dataclass(frozen=True)
class HandState:
    """One tracked hand at one instant.

    landmarks:       (21, 3) float32, normalised image space.
                     x,y in [0,1] relative to frame width/height; z is depth
                     relative to the wrist, in roughly the same scale as x.
    world_landmarks: (21, 3) float32, metric-ish space in metres, origin at
                     the hand's approximate geometric centre. Camera-pose
                     independent, which is what the gesture engine wants for
                     scale-invariant measurements.
    """

    index: int
    handedness: str          # "Left" | "Right" (as reported by MediaPipe)
    handedness_score: float
    landmarks: np.ndarray
    world_landmarks: Optional[np.ndarray] = None

    def point(self, idx: int) -> np.ndarray:
        return self.landmarks[idx]


@dataclass(frozen=True)
class FrameStamps:
    """Monotonic nanosecond stamps for one frame's trip through the pipeline.

    All values come from time.perf_counter_ns() so they are immune to wall
    clock changes. Wall-clock time is never used for latency maths.
    """

    capture_ns: int              # frame grabbed off the camera
    mp_submit_ns: int = 0        # handed to MediaPipe detect_async
    mp_result_ns: int = 0        # result_callback fired

    @property
    def inference_ms(self) -> float:
        if not self.mp_result_ns or not self.mp_submit_ns:
            return 0.0
        return (self.mp_result_ns - self.mp_submit_ns) / 1e6

    @property
    def capture_to_result_ms(self) -> float:
        if not self.mp_result_ns:
            return 0.0
        return (self.mp_result_ns - self.capture_ns) / 1e6


@dataclass(frozen=True)
class TrackingFrame:
    """The complete output of the vision layer for one processed frame."""

    frame_id: int
    stamps: FrameStamps
    hands: Sequence[HandState] = field(default_factory=tuple)
    frame_width: int = 0
    frame_height: int = 0

    @property
    def num_hands(self) -> int:
        return len(self.hands)
```

### client/src/objects/arc-reactor/ArcReactor.ts
```
/**
 * Arc Reactor -- a downloaded glTF model, not procedural geometry.
 *
 * The model is a Sketchfab export: 140 meshes, ~188k triangles, 38 PBR
 * materials, 29 textures. Two consequences drive everything below.
 *
 * 1. PBR MATERIALS NEED LIGHT.
 *    Every other object in this project is unlit emissive geometry on black,
 *    so the scene has no lights at all. Dropped in unchanged this model would
 *    render pure black. The object therefore carries its own lights, added to
 *    its own group -- the Stage stays lighting-agnostic and the other objects
 *    are unaffected.
 *
 * 2. DARK PBR SHADING DISAPPEARS IN A PYRAMID.
 *    Pepper's ghost shows reflected *emitted* light, so mid-grey metal reads
 *    as nothing. On load every material gets its emissive channel lifted from
 *    its own base colour, which keeps the model's shape and colour while
 *    making it self-luminous enough to survive the acrylic.
 *
 * The model is loaded from /models/arc_reactor.glb, served by the PC as a
 * static file rather than bundled -- see server/app.py.
 */

import {
  AmbientLight,
  Box3,
  Color,
  DirectionalLight,
  Group,
  Mesh,
  MeshStandardMaterial,
  PointLight,
  Vector3,
} from 'three'
import { GLTFLoader } from 'three/examples/jsm/loaders/GLTFLoader.js'

import type {
  FrameContext,
  HologramObject,
  HologramObjectFactory,
  HologramObjectMetadata,
  InteractionInput,
  VisualEnergy,
} from '../HologramObject'

const MODEL_URL = './models/arc_reactor.glb'

// Tint the whole model toward arc-reactor blue rather than leaving it steel
// grey. The pyramid shows emitted light, so this colour IS the hologram's
// colour -- a neutral model reads as a white smudge in the acrylic.
const BODY_GLOW = 0x6fb4ff     // cool blue-white for the housing
const CORE_GLOW = 0x8ff2ff     // bright cyan for the glowing core

const METADATA: HologramObjectMetadata = {
  id: 'arcreactor',
  name: 'Arc Reactor',
  description: 'Downloaded glTF arc reactor model, relit for pyramid holography.',
  radius: 2.6,
}

class ArcReactor implements HologramObject {
  readonly metadata = METADATA

  private root = new Group()
  private spinner = new Group()
  private coreLight?: PointLight

  private targetScale = 1
  private currentScale = 1
  private targetPos = new Vector3()
  private energy = 0
  private paused = false
  private spin = 0
  private loaded = false

  createScene(): Group {
    this.root.name = 'ArcReactor'
    this.root.add(this.spinner)

    // Lights live inside this object's group. They light only what is in the
    // scene at the time, which is fine because one object is shown at a time.
    const ambient = new AmbientLight(0x5590d0, 0.7)
    const key = new DirectionalLight(0xcfe6ff, 1.5)
    key.position.set(3, 5, 4)
    const rim = new DirectionalLight(0x3b8fe0, 1.4)
    rim.position.set(-4, -2, -3)
    this.coreLight = new PointLight(0x66d9ff, 3.0, 12)
    this.root.add(ambient, key, rim, this.coreLight)

    this.load()
    return this.root
  }

  private load(): void {
    loadSharedModel()
      .then((template) => {
        // Clone per instance. The dev UI runs two Stages (clean object and
        // hologram output), each with its own ArcReactor, and without the
        // shared cache each would download the same 20.8 MB file separately.
        // clone(true) shares geometries and materials, so the clone is cheap.
        const model = template.clone(true)
        this.spinner.add(model)
        this.normalise(model)
        this.loaded = true
      })
      .catch((err) => {
        // A failed model load must not take the renderer down -- the rest of
        // the hologram keeps working and the console says why.
        console.error(
          `[ArcReactor] could not load ${MODEL_URL}.`,
          'Check the file exists in models/ and that the server is serving it.',
          err,
        )
      })
  }

  /**
   * Centre the model on the origin and scale it so its largest dimension
   * matches metadata.radius.
   *
   * Downloaded models arrive in arbitrary units and with arbitrary origins --
   * this one could be 0.01 units or 1000 units across, and pivoted anywhere.
   * Without this the object would be invisible or fill the entire view, and
   * would rotate around a point somewhere off-screen.
   */
  private normalise(model: Group): void {
    // Order matters. A node's matrix composes as T * R * S, so `position` is
    // applied in the PARENT frame, after rotation. Measuring the bounding box
    // first and then setting a rotation leaves the centring offset pointing
    // the wrong way, and the model drifts off the pivot.
    //
    // So: rotate first, flush the world matrices, THEN measure and centre.
    model.rotation.x = -Math.PI / 2
    model.scale.setScalar(1)
    model.position.set(0, 0, 0)
    model.updateMatrixWorld(true)

    const box = new Box3().setFromObject(model)
    const size = new Vector3()
    const centre = new Vector3()
    box.getSize(size)
    box.getCenter(centre)

    const largest = Math.max(size.x, size.y, size.z) || 1
    const scale = (METADATA.radius * 1.7) / largest
    model.scale.setScalar(scale)
    // centre was measured in the parent frame at scale 1, so scaling it here
    // is the correct compensation.
    model.position.copy(centre).multiplyScalar(-scale)
  }

  update(ctx: FrameContext): void {
    const rate = this.paused ? 0 : 1

    // Continuous spin. The reactor is rotationally symmetric, so its own
    // rotation is nearly invisible in the pyramid -- what makes motion
    // readable is translation. The spin is kept slow and constant.
    this.spin += ctx.dt * 0.55 * rate * (1 + this.energy * 1.5)
    this.spinner.rotation.z = this.spin

    if (this.coreLight) {
      this.coreLight.intensity = 3.0 + Math.sin(ctx.elapsed * 2.4) * 0.6
        + this.energy * 4
    }

    this.currentScale += (this.targetScale - this.currentScale)
      * Math.min(1, ctx.dt * 12)
    this.root.scale.setScalar(this.currentScale)

    // Ease toward the target position so hand jitter does not shake the model.
    this.root.position.lerp(this.targetPos, Math.min(1, ctx.dt * 14))
  }

  handleInteraction(input: InteractionInput): void {
    this.paused = input.interaction === 'paused'
    if (this.paused) return

    if (input.scaleDelta) {
      this.targetScale = clamp(
        this.targetScale * Math.exp(input.scaleDelta), 0.3, 3.5)
    }

    const [px, py, pz] = input.positionDelta
    if (px || py || pz) {
      this.targetPos.x = clamp(this.targetPos.x + px, -2.2, 2.2)
      this.targetPos.y = clamp(this.targetPos.y + py, -2.2, 2.2)
      this.targetPos.z = clamp(this.targetPos.z + pz, -2.2, 2.2)
    }
  }

  handleEnergy(e: VisualEnergy): void {
    this.energy = clamp(e.energy, 0, 1)
  }

  get isLoaded(): boolean {
    return this.loaded
  }

  dispose(): void {
    // Geometries and materials belong to the shared cached template and are
    // intentionally not disposed here -- another Stage may still be using
    // them, and the cache is meant to outlive individual instances.
    this.spinner.clear()
    this.root.clear()
  }
}

/**
 * Load the GLB once for the whole application.
 *
 * The dev UI runs two Stage instances, and each would otherwise fetch the
 * same 20.8 MB file. Switching objects back and forth would refetch again.
 * The cached template is relit once and cloned per instance; clones share
 * geometries and materials, so they are nearly free.
 *
 * Cached resources are deliberately never disposed -- they outlive any single
 * object instance by design, and disposing them from one instance would blank
 * the model in the other.
 */
let sharedModel: Promise<Group> | null = null

function loadSharedModel(): Promise<Group> {
  if (sharedModel) return sharedModel
  sharedModel = new Promise<Group>((resolve, reject) => {
    new GLTFLoader().load(
      MODEL_URL,
      (gltf) => {
        relightModel(gltf.scene)
        resolve(gltf.scene)
      },
      undefined,
      (err) => {
        sharedModel = null      // let a later attempt retry
        reject(err)
      },
    )
  })
  return sharedModel
}

/** Lift every material so it survives an unlit pyramid. Applied once. */
function relightModel(model: Group): void {
  model.traverse((child) => {
    const mesh = child as Mesh
    if (!mesh.isMesh) return
    const mats = Array.isArray(mesh.material) ? mesh.material : [mesh.material]
    for (const m of mats) {
      const mat = m as MeshStandardMaterial
      if (!mat) continue

      const wasEmissive = mat.emissive && mat.emissive.getHex() !== 0x000000
      if (!mat.emissive) mat.emissive = new Color(0x000000)

      if (wasEmissive) {
        // The already-emissive material is the glowing core. Drive it to
        // full cyan so it is unmistakably the brightest thing in the model.
        mat.emissive.set(CORE_GLOW)
        mat.emissiveIntensity = 2.4
      } else {
        // Self-illuminate through the BASE COLOUR TEXTURE, not the base
        // colour factor.
        //
        // 34 of this model's 38 materials have a white baseColorFactor and
        // carry all their detail in a texture. Deriving emissive from the
        // factor therefore produced flat white on almost every surface and
        // erased all 29 textures -- the reactor rendered as a white blob.
        // Using the map as the emissive map keeps every panel line and
        // shadow while still making the surface self-luminous.
        if (mat.map) mat.emissiveMap = mat.map
        mat.emissive.set(BODY_GLOW)
        mat.emissiveIntensity = 0.85
      }
      // Fully rough metal goes almost black without an environment map, and
      // there is no envmap here. Backing metalness off restores the form.
      if (typeof mat.metalness === 'number') mat.metalness = Math.min(mat.metalness, 0.45)
      if (typeof mat.roughness === 'number') mat.roughness = Math.min(mat.roughness, 0.65)
      mat.needsUpdate = true
    }
  })
}

function clamp(v: number, lo: number, hi: number): number {
  return v < lo ? lo : v > hi ? hi : v
}
```

```
/**
 * Stylised atom.
 *
 * Explicitly NOT a quantum-mechanically accurate visualisation -- the brief
 * asks for visual clarity, so this is the classical Bohr picture: a nucleus
 * of packed nucleons with electrons on tilted circular orbits.
 *
 * Scene graph, as specified:
 *
 *   Atom
 *   |- Nucleus
 *   |   |- Proton  x N
 *   |   \- Neutron x N
 *   |- ElectronOrbit1 -> Electron
 *   |- ElectronOrbit2 -> Electron
 *   \- ElectronOrbit3 -> Electron
 *
 * Everything is additively blended and emissive. That is a deliberate choice
 * for pyramid holography: the acrylic reflects light rather than blocking it,
 * so bright marks on black read as solid and dark pixels read as absent. A
 * conventionally lit model with dark shading would mostly disappear.
 */

import {
  AdditiveBlending,
  BackSide,
  Color,
  Group,
  IcosahedronGeometry,
  Mesh,
  MeshBasicMaterial,
  RingGeometry,
  SphereGeometry,
  TorusGeometry,
  Vector3,
} from 'three'

import type {
  FrameContext,
  HologramObject,
  HologramObjectFactory,
  HologramObjectMetadata,
  InteractionInput,
  VisualEnergy,
} from '../HologramObject'

const PROTON_COLOR = 0x9fe8ff
const NEUTRON_COLOR = 0x3fa2ff
const ELECTRON_COLOR = 0xd8feff
const ORBIT_COLOR = 0x39c4ff

interface Orbit {
  group: Group
  electron: Mesh
  speed: number
  radius: number
  phase: number
}

class Atom implements HologramObject {
  readonly metadata: HologramObjectMetadata = {
    id: 'atom',
    name: 'Atom',
    description: 'Stylised Bohr-model atom with a glowing nucleus and three electron orbits.',
    radius: 2.6,
    selectable: ['nucleus', 'electron1', 'electron2', 'electron3'],
  }

  private root = new Group()
  private nucleus = new Group()
  private orbits: Orbit[] = []
  private glow?: Mesh
  private disposables: Array<{ dispose(): void }> = []

  private targetScale = 1
  private currentScale = 1
  private pulse = 0
  private energy = 0
  private paused = false
  private selected: string | null = null
  private targetPos = new Vector3()

  createScene(): Group {
    this.root.name = 'Atom'

    this.buildNucleus()
    this.buildGlow()
    this.buildOrbit(1.35, 0.0, 0.0, 1.9)
    this.buildOrbit(1.75, Math.PI / 2.6, Math.PI / 3, -1.35)
    this.buildOrbit(2.15, -Math.PI / 3.2, -Math.PI / 4, 1.05)

    this.root.add(this.nucleus)
    return this.root
  }

  // ------------------------------------------------------------- building

  private track<T extends { dispose(): void }>(x: T): T {
    this.disposables.push(x)
    return x
  }

  private buildNucleus(): void {
    this.nucleus.name = 'Nucleus'
    // One geometry and two materials shared across every nucleon. Twelve
    // separate geometries would be twelve draw calls for identical spheres.
    const geo = this.track(new IcosahedronGeometry(0.17, 2))
    const protonMat = this.track(new MeshBasicMaterial({ color: PROTON_COLOR }))
    const neutronMat = this.track(new MeshBasicMaterial({ color: NEUTRON_COLOR }))

    // Deterministic quasi-uniform packing (golden-angle spiral). A random
    // arrangement would differ on every device showing the same hologram.
    const count = 12
    const golden = Math.PI * (3 - Math.sqrt(5))
    for (let i = 0; i < count; i++) {
      const y = 1 - (i / (count - 1)) * 2
      const r = Math.sqrt(Math.max(0, 1 - y * y))
      const theta = golden * i
      const isProton = i % 2 === 0
      const nucleon = new Mesh(geo, isProton ? protonMat : neutronMat)
      nucleon.name = isProton ? 'Proton' : 'Neutron'
      nucleon.position.set(
        Math.cos(theta) * r * 0.34,
        y * 0.34,
        Math.sin(theta) * r * 0.34,
      )
      this.nucleus.add(nucleon)
    }
  }

  private buildGlow(): void {
    // Back-side additive sphere: a cheap volumetric halo that costs one draw
    // call and no post-processing. Real bloom would mean an EffectComposer
    // pass per view, i.e. four times the cost on the phone.
    const geo = this.track(new SphereGeometry(0.85, 24, 24))
    const mat = this.track(new MeshBasicMaterial({
      color: new Color(0x4fc8ff),
      transparent: true,
      opacity: 0.30,
      blending: AdditiveBlending,
      side: BackSide,
      depthWrite: false,
    }))
    this.glow = new Mesh(geo, mat)
    this.glow.name = 'NucleusGlow'
    this.root.add(this.glow)
  }

  private buildOrbit(radius: number, tiltX: number, tiltZ: number, speed: number): void {
    const group = new Group()
    group.name = `ElectronOrbit${this.orbits.length + 1}`
    group.rotation.set(tiltX, 0, tiltZ)

    const ringGeo = this.track(new TorusGeometry(radius, 0.012, 8, 128))
    const ringMat = this.track(new MeshBasicMaterial({
      color: ORBIT_COLOR,
      transparent: true,
      opacity: 0.55,
      blending: AdditiveBlending,
      depthWrite: false,
    }))
    const ring = new Mesh(ringGeo, ringMat)
    ring.name = 'OrbitRing'
    group.add(ring)

    const eGeo = this.track(new SphereGeometry(0.085, 16, 16))
    const eMat = this.track(new MeshBasicMaterial({ color: ELECTRON_COLOR }))
    const electron = new Mesh(eGeo, eMat)
    electron.name = 'Electron'
    group.add(electron)

    const haloGeo = this.track(new RingGeometry(0.1, 0.2, 16))
    const haloMat = this.track(new MeshBasicMaterial({
      color: ELECTRON_COLOR,
      transparent: true,
      opacity: 0.35,
      blending: AdditiveBlending,
      depthWrite: false,
    }))
    const halo = new Mesh(haloGeo, haloMat)
    halo.name = 'ElectronHalo'
    electron.add(halo)

    this.root.add(group)
    this.orbits.push({
      group,
      electron,
      speed,
      radius,
      phase: this.orbits.length * 2.1,
    })
  }

  // -------------------------------------------------------------- runtime

  update(ctx: FrameContext): void {
    const rate = this.paused ? 0 : 1

    for (const orbit of this.orbits) {
      orbit.phase += orbit.speed * ctx.dt * rate
      orbit.electron.position.set(
        Math.cos(orbit.phase) * orbit.radius,
        0,
        Math.sin(orbit.phase) * orbit.radius,
      )
      // Keep the halo disc facing outward so it reads as a glow, not a coin.
      orbit.electron.lookAt(0, 0, 0)
    }

    this.pulse += ctx.dt * (1.6 + this.energy * 5)
    const breathe = 1 + Math.sin(this.pulse) * 0.045 + this.energy * 0.25
    this.nucleus.scale.setScalar(breathe)
    if (this.glow) {
      this.glow.scale.setScalar(breathe * (1 + this.energy * 0.5))
      const mat = this.glow.material as MeshBasicMaterial
      mat.opacity = 0.26 + this.energy * 0.35
    }

    // Ease toward the target scale instead of snapping. Gesture input is
    // noisy at the edges and an eased scale hides a dropped packet entirely.
    this.currentScale += (this.targetScale - this.currentScale) * Math.min(1, ctx.dt * 12)
    this.root.scale.setScalar(this.currentScale)

    // The atom spins on its own: there is no manual rotation binding any more,
    // and a static object in a pyramid reads as a photograph.
    this.root.rotation.y += ctx.dt * 0.35 * rate
    this.root.position.lerp(this.targetPos, Math.min(1, ctx.dt * 14))
  }

  handleInteraction(input: InteractionInput): void {
    this.paused = input.interaction === 'paused'
    if (this.paused) return


    if (input.scaleDelta) {
      // Scale arrives in log space, so exp() makes it exactly reversible:
      // any hand motion that returns to its starting separation restores the
      // original size. See pc/hologram_pc/interaction/engine.py::_scale.
      this.targetScale = clamp(this.targetScale * Math.exp(input.scaleDelta), 0.35, 4)
    }

    const [px, py, pz] = input.positionDelta
    if (px || py || pz) {
      this.targetPos.set(
        clamp(this.targetPos.x + px, -2.2, 2.2),
        clamp(this.targetPos.y + py, -2.2, 2.2),
        clamp(this.targetPos.z + pz, -2.2, 2.2),
      )
    }

    // A 'point' gesture selects; the nucleus brightens so the operator can
    // see the selection landed. Ray-picking individual electrons is a Phase 9
    // concern and needs the pointer ray, which the protocol does not carry yet.
    const selected = input.interaction === 'select' ? (input.target ?? 'nucleus') : null
    if (selected !== this.selected) {
      this.selected = selected
      if (this.glow) {
        (this.glow.material as MeshBasicMaterial).color.set(
          selected ? 0xbfefff : 0x4fc8ff)
      }
    }
  }

  handleEnergy(e: VisualEnergy): void {
    this.energy = clamp(e.energy, 0, 1)
  }

  dispose(): void {
    for (const d of this.disposables) d.dispose()
    this.disposables = []
    this.orbits = []
    this.root.clear()
    this.nucleus.clear()
  }
}

function clamp(v: number, lo: number, hi: number): number {
  return v < lo ? lo : v > hi ? hi : v
}

export const atomFactory: HologramObjectFactory = {
  metadata: {
    id: 'atom',
    name: 'Atom',
    description: 'Stylised Bohr-model atom with a glowing nucleus and three electron orbits.',
    radius: 2.6,
    selectable: ['nucleus', 'electron1', 'electron2', 'electron3'],
  },
  create: () => new Atom(),
}
```

```
/**
 * HolographicCore -- an original futuristic AI reactor core.
 *
 * Deliberately NOT modelled on any film asset: the design is concentric
 * geometry, counter-rotating rings, radial spokes and a pulsing energy
 * sphere, all built procedurally from primitives. No copied artwork.
 *
 * This is the object Jarvis will eventually drive (Phase 19). It already
 * implements `handleEnergy`, so once the PC-side audio tap exists the core
 * reacts to speech with no change here: quiet speech nudges the rings,
 * loud speech drives the whole assembly.
 */

import {
  AdditiveBlending,
  BackSide,
  BufferGeometry,
  Color,
  Float32BufferAttribute,
  Group,
  IcosahedronGeometry,
  Mesh,
  MeshBasicMaterial,
  Points,
  PointsMaterial,
  SphereGeometry,
  TorusGeometry,
  Vector3,
} from 'three'

import type {
  FrameContext,
  HologramObject,
  HologramObjectFactory,
  HologramObjectMetadata,
  InteractionInput,
  VisualEnergy,
} from '../HologramObject'

const CORE_COLOR = 0x7fe8ff
const RING_COLOR = 0x35b6ff
const SPOKE_COLOR = 0x9fd8ff

interface Ring {
  mesh: Mesh
  axis: 'x' | 'y' | 'z'
  speed: number
  baseScale: number
}

class HolographicCore implements HologramObject {
  readonly metadata: HologramObjectMetadata = {
    id: 'core',
    name: 'Holographic Core',
    description: 'Original glowing AI reactor core with counter-rotating rings; reacts to audio energy.',
    radius: 2.8,
  }

  private root = new Group()
  private rings: Ring[] = []
  private sphere?: Mesh
  private halo?: Mesh
  private spokes = new Group()
  private particles?: Points
  private disposables: Array<{ dispose(): void }> = []

  private t = 0
  private energy = 0
  private energyTarget = 0
  private targetScale = 1
  private currentScale = 1
  private paused = false
  private targetPos = new Vector3()

  createScene(): Group {
    this.root.name = 'HolographicCore'
    this.buildSphere()
    this.buildRings()
    this.buildSpokes()
    this.buildParticles()
    return this.root
  }

  private track<T extends { dispose(): void }>(x: T): T {
    this.disposables.push(x)
    return x
  }

  private buildSphere(): void {
    const geo = this.track(new IcosahedronGeometry(0.62, 3))
    const mat = this.track(new MeshBasicMaterial({
      color: new Color(CORE_COLOR),
      wireframe: true,
      transparent: true,
      opacity: 0.9,
      blending: AdditiveBlending,
      depthWrite: false,
    }))
    this.sphere = new Mesh(geo, mat)
    this.sphere.name = 'EnergySphere'
    this.root.add(this.sphere)

    const haloGeo = this.track(new SphereGeometry(1.05, 24, 24))
    const haloMat = this.track(new MeshBasicMaterial({
      color: new Color(CORE_COLOR),
      transparent: true,
      opacity: 0.16,
      blending: AdditiveBlending,
      side: BackSide,
      depthWrite: false,
    }))
    this.halo = new Mesh(haloGeo, haloMat)
    this.halo.name = 'CoreHalo'
    this.root.add(this.halo)
  }

  private buildRings(): void {
    const specs: Array<{ r: number; tube: number; axis: 'x' | 'y' | 'z'; speed: number }> = [
      { r: 1.25, tube: 0.028, axis: 'y', speed: 0.9 },
      { r: 1.6, tube: 0.022, axis: 'x', speed: -0.65 },
      { r: 1.95, tube: 0.018, axis: 'z', speed: 0.45 },
      { r: 2.3, tube: 0.014, axis: 'y', speed: -0.3 },
    ]
    for (const [i, s] of specs.entries()) {
      const geo = this.track(new TorusGeometry(s.r, s.tube, 8, 96))
      const mat = this.track(new MeshBasicMaterial({
        color: new Color(RING_COLOR),
        transparent: true,
        opacity: 0.75 - i * 0.1,
        blending: AdditiveBlending,
        depthWrite: false,
      }))
      const mesh = new Mesh(geo, mat)
      mesh.name = `Ring${i + 1}`
      // Offset each ring so they never sit coplanar, which would alias badly
      // at the small on-screen size each pyramid view gets.
      mesh.rotation.set(i * 0.4, i * 0.7, i * 0.25)
      this.root.add(mesh)
      this.rings.push({ mesh, axis: s.axis, speed: s.speed, baseScale: 1 })
    }
  }

  private buildSpokes(): void {
    this.spokes.name = 'RadialSpokes'
    const geo = this.track(new TorusGeometry(0.9, 0.008, 6, 24, Math.PI / 7))
    const mat = this.track(new MeshBasicMaterial({
      color: new Color(SPOKE_COLOR),
      transparent: true,
      opacity: 0.5,
      blending: AdditiveBlending,
      depthWrite: false,
    }))
    const count = 8
    for (let i = 0; i < count; i++) {
      const spoke = new Mesh(geo, mat)
      spoke.rotation.z = (i / count) * Math.PI * 2
      this.spokes.add(spoke)
    }
    this.root.add(this.spokes)
  }

  private buildParticles(): void {
    // A single Points cloud: one draw call for the whole particle field.
    const count = 220
    const positions = new Float32Array(count * 3)
    for (let i = 0; i < count; i++) {
      // Deterministic spiral shell, not Math.random(), so every device shows
      // the identical hologram.
      const t = i / count
      const phi = Math.acos(1 - 2 * t)
      const theta = Math.PI * (1 + Math.sqrt(5)) * i
      const r = 1.15 + (i % 7) * 0.14
      positions[i * 3] = Math.sin(phi) * Math.cos(theta) * r
      positions[i * 3 + 1] = Math.cos(phi) * r * 0.75
      positions[i * 3 + 2] = Math.sin(phi) * Math.sin(theta) * r
    }
    const geo = this.track(new BufferGeometry())
    geo.setAttribute('position', new Float32BufferAttribute(positions, 3))
    const mat = this.track(new PointsMaterial({
      color: new Color(CORE_COLOR),
      size: 0.035,
      transparent: true,
      opacity: 0.7,
      blending: AdditiveBlending,
      depthWrite: false,
      sizeAttenuation: true,
    }))
    this.particles = new Points(geo, mat)
    this.particles.name = 'CoreParticles'
    this.root.add(this.particles)
  }

  // -------------------------------------------------------------- runtime

  update(ctx: FrameContext): void {
    const rate = this.paused ? 0 : 1
    this.t += ctx.dt * rate

    // Ease energy toward its target so a burst of speech does not strobe.
    this.energy += (this.energyTarget - this.energy) * Math.min(1, ctx.dt * 9)
    const e = this.energy

    for (const ring of this.rings) {
      const spin = ring.speed * ctx.dt * rate * (1 + e * 2.5)
      if (ring.axis === 'x') ring.mesh.rotation.x += spin
      else if (ring.axis === 'y') ring.mesh.rotation.y += spin
      else ring.mesh.rotation.z += spin
      ring.mesh.scale.setScalar(ring.baseScale * (1 + e * 0.12))
    }

    const pulse = 1 + Math.sin(this.t * 2.2) * 0.06 + e * 0.4
    this.sphere?.scale.setScalar(pulse)
    this.sphere && (this.sphere.rotation.y += ctx.dt * 0.35 * rate)
    if (this.halo) {
      this.halo.scale.setScalar(pulse * 1.02)
      ;(this.halo.material as MeshBasicMaterial).opacity = 0.12 + e * 0.4
    }
    this.spokes.rotation.z += ctx.dt * 0.22 * rate
    if (this.particles) {
      this.particles.rotation.y -= ctx.dt * 0.18 * rate
      ;(this.particles.material as PointsMaterial).opacity = 0.45 + e * 0.5
    }

    this.currentScale += (this.targetScale - this.currentScale) * Math.min(1, ctx.dt * 12)
    this.root.scale.setScalar(this.currentScale)
    this.root.position.lerp(this.targetPos, Math.min(1, ctx.dt * 14))
  }

  handleInteraction(input: InteractionInput): void {
    this.paused = input.interaction === 'paused'
    if (this.paused) return
    const [px, py, pz] = input.positionDelta
    if (px || py || pz) {
      this.targetPos.set(
        clamp(this.targetPos.x + px, -2.2, 2.2),
        clamp(this.targetPos.y + py, -2.2, 2.2),
        clamp(this.targetPos.z + pz, -2.2, 2.2),
      )
    }
    if (input.scaleDelta) {
      this.targetScale = clamp(this.targetScale * Math.exp(input.scaleDelta), 0.35, 4)
    }
    // Pinching hard also charges the core, so the gesture has a visible
    // effect even before the user starts dragging.
    this.energyTarget = Math.max(this.energyTarget, (1 - input.pinch) * 0.5)
  }

  handleEnergy(e: VisualEnergy): void {
    this.energyTarget = clamp(e.energy, 0, 1)
  }

  dispose(): void {
    for (const d of this.disposables) d.dispose()
    this.disposables = []
    this.rings = []
    this.spokes.clear()
    this.root.clear()
  }
}

function clamp(v: number, lo: number, hi: number): number {
  return v < lo ? lo : v > hi ? hi : v
}

    description: 'Original glowing AI reactor core with counter-rotating rings; reacts to audio energy.',
```
