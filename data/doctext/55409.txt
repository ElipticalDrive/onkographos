One disadvantage of direct volume rendering is its heavy
computation cost. In the simple implementation,
O(n3) size
of data must be traversed for each view, where n is the volume resolution along each axis. Many studies have been
done to improve calculation efficiency. The common idea
among them is to make a sparse data set by compressing or
eliminating the cells which have uninteresting scalar values
and/or low gradient magnitudes [7,15]. Such an approach
is effective if the scalar values or gradient conditions of the
material are known and fixed (like bones in CT data, for
example). However, if a wide range of scalar values must be
examined (like a temperature distribution),
data cannot be
reduced efficiently.
Frequency domain computation

preprocess operation, image from any view angle can be obtained by slice extraction and 2D inverse Fourier transform
both of which take only O(n2 log n). However, such high
performance can be achieved only when modifying just ,the
view angle and lighting angle; heavy computation is necessary to reconstruct the 3D spectrum when the clipping plane
or mapping function F is changed.

calculation is processed either by object order (i.e. projecting each cell onto the image screen) [1,15,17], by image order
(i.e. ray casting for each pixel) [6,7], or by frequency [14].

Approach
There are two key ideas in the proposed method.
First,
scalar values are stored at hierarchically sampled points instead of voxels or mesh vertices. This allows us to control
the level of detail continuously.
Second, each point is rendered as a simple primitive such as a line segment(s) or polygon. These primitives can be efficiently rendered by graphics
workstations.
Figure 2 illustrates the difference between the conventional methods and the proposed method. For simplification,
2D examples are used. Figure 2(a) is the original volume
data. (b) and (c) are example results of conventional volume rendering, where darkness indicates opacity. In real 3D
case, colors and opacities must be blended along the depth
direction. (d) is an example of isosurface method. Line segments correspond to polygons in 3D case.
For the proposed method, volume data must be converted
to the form like (e). Here, scalar values and gradient (not
shown in this figure) at the irregularly sampled points are
calculated and stored. This sampling pattern is hierarchical. In other words, each point has a priority level - in
this example, points written in bold face have the higher
priority.
(f) and (g) are example results of the proposed
method, which corresponds to (b) and (c), respectively. At
each sampled point, a line segment is drawn. The direction
of each line segment indicates the tangent of the isosurface,
and the opacity is obtained with the same function of the
scalar value as (b) or (c). In 3D case, a polygon or a set of
lines can be drawn instead of single line segment. By using
simple primitives such as line segments, commercial hardware can effectively accelerate the drawing process. Also,
they can express certain geometric feature like the tangent
of isosurface. Since the sampling points are hierarchical, it is
possible to control the level of detail. For example, a rough
image (h) can be obtained by processing only the high priority points. If more priority levels are assigned, the level
of detail can be controlled smoothly, which can ensure the
constant frame rate rendering.

3D Sampling
Hierarchical 3D sampling creates a series of points which
satisfy the following feature.
Suppose a series of points
are distributed in a unit cube. Then, for
{PO,
A,
. . . . PN-~}
any subset from the beginning {PO, PI, .. . . Pn-l}, points are
evenly distributed and evenly spaced - in other words, point
density is uniform every where, and no two points are closer
than a minimum distance. Serial number k of each point
Pk can be called the priority number, where the smaller the
number, the higher the priority. The total number of points
n in the unit cube is the number of priority levels. In actual
usage, a periodic sampling pattern is used and the unit cube
is one period, so each face is treated the same as its opposite face. Notice that if the number of points n is too small,
regularity of the pattern becomes obvious.
The simplest example of hierarchical sampling is ordered
dithering.
2D ordered dithering is a well-known technique
for digital halftoning [4], and here it is directly extended to
3D. Figure 3 shows an example of 3D dithering. Though ordered dithering is simple, the regularity often haa correlation
with object surfaces or the screen coordinate. It creates severe aliasing artifacts. Therefore, an irregularly distributed
pattern is necessary for many applications.
Hierarchical Poisson-disk sampling proposed by McCool
and Fiume [9] creates irregular but hierarchical patterns.
In this method, points are placed sequentially by the dortthrowing algorithm. Each new point is irregularly placed and
compared to points already placed; if the distance to any
other point is less than a limit length, then the new point
is discarded and another new point is placed. If this procedure continues to fail many times (1000 times, for example),
which means that very few spaces are left, the limit length is
reduced by some fraction (0.99, for example). Figure 4 shows
one result of hierarchical Poisson-disk sampling. Although
this algorithm requires expensive computation, the sampled
points can be pre-computed and reused for any object.

Drawing
Order
In order to accumulate semi-transparent pixel values, rendering must proceed in either the back-to-front or front-to-back
order. This is not so easy, however, with the irregularly located points created by hierarchical Poisson-disk sampling.
A simple solution for this problem is to use bucket sorting. Sampled points are classified into coarse voxels. Primitive drawing proceeds from back-t&front
in the voxel order.
Within one voxel, the primitive drawing order is random.
Although it is not a complete solution, it does provide reasonable efficiency and quality.
If the opacity is controlled by point density only, i.e. if
each primitive is completely opaque, the simple z-buffer algorithm can be applied for hidden surface elimination.
In
this case, drawing order does not affect the resulting image.
Therefore, incremental drawing is realized if rendering proceeds under priority order. It can limit the total number
of primitives for quick response during interactive viewing
control, and once the user’s control is stopped, the drawing
process continues incrementally
until all candidate primitives are drawn or another viewing control action begins.

Conclusion
A new high-speed previewing technique for volume visualization was proposed. By drawing simple primitives at hierarchically sampled points, the user can control various viewing
parameters such as viewing angle, clipping plane, and isosurface value, in real-time or near real-time on commercial
graphics workstations.
The level of detail is automatically
adjusted to ensure constant frame rate. Simple primitives
that enhance geometric features help the viewers’ comprehension of 3D shapes with a limited number of primitives.
