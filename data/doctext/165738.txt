In recent years, Neural Radiance Fields (NeRF) have been used as a
map of 3D scene to estimate the 6-DoF pose of new observed images
—given an image, estimate the relative rotation and translation of a
camera using a trained NeRF. However, existing NeRF-based pose
estimation methods have a small convergence region and need to be
optimized iteratively over a given initial pose, which makes them
slow and sensitive to the initial pose. In this paper, we propose
PI-NeRF that directly outputs the pose of a given image without
pose initialization and iterative optimization. This is achieved by
integrating NeRF with invertible neural network (INN). Our method
employs INNs to establish a bijective mapping between the rays
and pixel features, which allows us to directly estimate the ray corresponding to each image pixel using the feature map extracted by
an image encoder. Based on these rays, we can directly estimate the
pose of the image using the PnP algorithm. Experiments conducted
on both synthetic and real-world datasets demonstrate that our
method is two orders of magnitude faster than existing NeRF-based
methods, while the accuracy is competitive without initial pose.
The accuracy of our method also outperforms NeRF-free absolute
pose regression methods by a large margin.

INTRODUCTION
The goal of camera pose estimation is to calculate the six degree-offreedom (6-DoF) camera pose from an image captured by the camera.
The 6-DoF pose includes the orientation 𝑹 and the 3D position 𝒕 of
the camera relative to a 3D scene. Camera pose estimation is the
basis of many tasks, including robot manipulationn[22, 33], simultaneous localization and mapping (SLAM)[6, 27, 37], autonomous
driving[9] and virtual reality[12]. Traditional approaches for camera pose estimation usually consist of the following steps: detecting
keypoints in the image and matching them with a map represented
by a set of images or image features in the 3D scene, and then estimating the 6-DoF pose through Perspective-n-Point (PnP)[10, 14].
However, such methods require a set of images or the pre-computed
image features to be stored as a map of the 3D scene, which requires a large amount of storage space and is sensitive to keypoint
detection and matching algorithms.
Neural Radiance Fields (NeRF) [23, 25] represents a 3D scene
using a multi-layer perceptron (MLP) based network, and has the
ability to synthesize the novel view image with a given pose. This
makes it possible to store a scene more efficiently and opens up the
possibility of using NeRF as a map for camera pose estimation[20].
Pose estimation is the inverse problem of view synthesis in NeRF,
and the key issue is how to utilize NeRF for solving this inverse
problem. Recently, there have been several attempts of using NeRF
for pose optimization[5, 16, 32, 42, 43, 49, 50], and they can be
divided into two categories. The first category iteratively optimizes
the pose by maximizing the similarity between the rendered image
from a trained NeRF and the given observed image[43, 48]. For
example, iNeRF[43] takes an initial pose as input and iteratively
optimizes the pose by minimizing the loss between the given image
and rendered image. The second category utilizes NeRF in the
Monte Carlo optimization framework[17, 20]. For example, LocNeRF[20] and pNeRF[17] use a trained NeRF to render images
around a given initial pose and weight the sampled poses by the

NeRF for pose estimation and instead they all rely on synthesizing
images from a number of poses, from which the optimal pose are
calculated. This brings two problems. First, a large number of image

In this paper, we "invert" NeRF for direct pose estimation. To
this end, we propose a framework that integrates NeRF with invertible neural network (INN) so that it can directly output the
pose of a given image. INN has been used to solve many inverse
problems[2, 19, 40], such as image rescaling[15, 40] and robot
localization[45]. Inspired by these works, we propose to integrate
INN into the existing NeRF process to make NeRF partial-invertible,
and the whole framework is denoted as PI-NeRF. In PI-NeRF, we
successfully invert the process of generating image from a given
pose and achieve the goal of directly estimating the pose from a
given image without iterative optimization or pose initialization.
Compared to existing methods[17, 20, 43] based on iterative optimization, PI-NeRF can achieve global camera pose estimation two
orders of magnitude faster.
Specifically, we first modify the existing NeRF[25], inspired by
[28, 35], which generates an RGB value at each pixel, to generate
a high-dimensional feature at each pixel. In the modified NeRF,
we use MLP to map each 3D point to a high-dimensional feature
instead of the original RGB color, and apply the volume rendering
function as a weighted feature aggregation method to a set of features along the ray, so as to obtain a high-dimensional feature for
each ray. We call this modified NeRF NeRF-Feat. Then we design
an Invertible Neural network Module (INM) consisting of two INNs
that can input and output in two directions. In the forward path of
INM, it takes the ray feature from NeRF-Feat and a representation
of the ray as input, and outputs a pixel feature. If this pixel feature
is fed into the reverse path of INM, it can recover the corresponding
ray feature and ray representation. In model training and inference,
we use ResUNet[35] to extract pixel features for the given observed
image whose pose is to be estimated, and feed these pixel features
into the reverse path of INM. During model training, we compute
the Barlow Twins (BT) loss[46] between the corresponding pixel
features produced by INM in the forward path and the features
extracted by ResUNet, so that the ResUNet can learn to generate
features suitable to be fed into INM in the reverse path to recover
the ray representations. During reference, we use ResUNet to extract a feature map from the observed image, and then sample a
set of features and feed them into INM in reverse path to obtain
ray representations. Based on these ray representations, we can
directly use the PnP algorithm to calculate the camera pose. Our
contributions can be summarized as follows:

• We utilized a high-dimensional NeRF that outputs a feature

Further experiments show that our method is more accurate
than existing learning-based absolute pose regression (APR)
methods.
2 RELATED WORKS
2.1 Neural Radiance Field (NeRF)
NeRF[25] is a milestone work that fits 3D scene into a continuous
5D (3D position and 2D direction) radiance field parameterized by
MLP, demonstrating excellent novel view synthesis and scene representation capabilities. Many subsequent works improved NeRF
in terms of rendering quality[4, 34, 39], training and rendering
speed[13, 26, 41] and generalization ability[18, 35, 44], etc. MipNeRF[4] proposes a new positional encoding method and renders
an anti-aliasing cone instead of a ray to prevent aliasing in NeRF
and improve its detail representation ability. Instant-NGP[26] accelerates the training and rendering speed of NeRF by using multiresolution hash encoding. GNT[35] uses Transformer to achieve
neural representation and rendering with cross-scene generalization ability. GNT generates a feature instead of physical properties
such as transparency and color for each point, based on the feature
maps from nearby view images and epipolar geometry, so that the
feature of each point contains more abundant information such
as material and lighting. Inspired by GNT, we propose NeRF-Feat
based on the original NeRF[25] to generate pixel features, which
will be introduced in detail in the Sec. 4.
2.2
Pose Estimation with NeRF
NeRF has achieved significant success in many fields, such as
novel view synthesis, object geometry representation[36], image
super-resolution[34], and deformable registration[38]. Recently,
some work has explored the possibility of utilizing NeRF for pose
estimation[5, 16, 20, 43]. iNeRF[43] is the earliest NeRF-based work
on pose estimation. It takes an initial pose as input, and updates the
pose parameters through backpropagation to minimize the same
photographic loss as in NeRF training[25] between the input image
and the image synthesized by the trained NeRF. iNeRF demonstrates
a mesh-free, RGB-only pose estimation method based on NeRF by
"inverting" it through gradient descent. Recent NeRF-based SLAM
studies such as iMAP[32] and NICE-SLAM[50] have used this gradient descent method to optimize the pose of the current frame based
on the poses of the previous frames. However, directly optimizing
the pose with gradient descent as in iNeRF has a small convergence
region, making it sensitive to initial poses. LATTITUE[48] proposed

An INN consists of several invertible blocks that have the same
dimension of input and output, enabling direct computation of the
input from the output. Based on this property, it can use a constant amount of memory to compute the gradients during training,
thus saving memory consumption when training wider and deeper
networks, such as Rev-ResNet[8], Rev-ViT[21]. Some works leverage the invertibility of INN to solve inverse problems[2, 40, 45].
Local_INN[45] is the one most related to our work, which regards
the task of estimating a robot’s pose from a radar scan as an inverse problem of obtaining a radar scan from a map with a given
pose. It utilizes an INN to provide implicit map representation in
the forward path and localization in the inverse path. The main
difference between Local_INN and our method is that Local_INN
uses INN to build a conditional normalized flow that directly builds
a map between pose and radar scan, resulting in a weak implicit
representation and requiring a large number of images to train a
scene. Our method, on the other hand, by introducing the idea of
ray rendering in NeRF and using INN to build a map between pixel
features and rays, can be trained with fewer samples compared to
Local_INN and has a good scene representation capability.

CONCLUSION
In this work, we propose PI-NeRF, which is the first NeRF-based
direct camera pose estimation framework. In PI-NeRF, we incorporate invertible neural networks with NeRF, distinguishing it from
existing NeRF-based methods that iteratively optimize pose using
gradient-based or Monte Carlo-based techniques. Experiments on
synthetic and real-world datasets demonstrate that our method
achieves pose estimation with comparable accuracy at a speed two
orders of magnitude faster than the existing NeRF-based methods.
In addition, our method achieves global pose estimation without the
need of initial pose, while existing NeRF-based methods requires an
initial pose and can only returned an optimized pose near the initialization. Further experiments show that our method outperforms
the absolute position regression methods in terms of accuracy. In
future work, we will validate the effectiveness of our method in
larger and more challenging scenarios (e.g., indoors) and integrate
this process into existing NeRF-based SLAM methods to improve
their real-time performance.
