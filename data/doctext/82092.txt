Fixes #9.
Adds the r=mesh renderer (sixth chip, WebGPU; WebGL2 falls back to ssf gracefully): per-frame GPU marching cubes over the tent-blurred density grid using the issue's sanctioned atomic-counter emission (no prefix sum) — one thread per cell computes the MC case, reserves vertex slots via atomicAdd on the indirect-draw args, and writes edge-interpolated positions + gradient normals into a 1.5M-vertex pool rendered by drawIndirect with vertex pulling, depth-tested against the raytraced scene. Shading: Fresnel over the analytic scene along one refracted ray, Beer–Lambert from interior density taps, momentum foam.
Novel bit: the MC triangle table is generated at load (marching-squares faces → closed loops → fan triangulation, rotation-invariant ambiguity rule) and validated by script against all 256 cases — crack-free by construction, no 4096-constant transcription. ?iso= now drives voxel AND mesh (stats-observable in both).
Verified: 64³–128³ WebGPU, WebGL2 fallback, occlusion angle, iso probes incl. garbage (stats-asserted), in-mode rebuild + chip-cycle + dbg harness, regressions of all five other modes after the shared-chunk refactor. Bench: 4.12 ms/frame at 128³/384².

Per issue #9, the atomic-counter variant: one compute thread per cell
classifies the tent-blurred density grid (shared with volume/voxel)
against the ?iso= threshold (shared with voxel), reserves vertex slots
with one atomicAdd directly on the indirect-draw args, and emits
edge-interpolated vertices with trilinear density-gradient normals into
a capped 1.5M-vertex pool (48 MB); a one-thread finalize kernel clamps
the count to the cap (whole triangles only, so overflow never draws
garbage). The mesh renders via drawIndirect with vertex pulling,
depth-tested in the same pass as the raytraced background, shaded as
glassy water: Fresnel over the analytic scene along one refracted ray,
Beer-Lambert from 6 interior density taps, momentum foam.

The MC triangle table is generated at load (src/mctables.js) instead of
transcribing the classic 256x16 constant: marching squares per cube
face -> closed loops -> fan triangulation, with ambiguous faces always
separating the diagonal (rotation-invariant, crack-free); validated
against the cut-edge set of every case (max 5 tris, matches classic).

The volume module's sampleD/ABSORB and traceScene are extracted into
shared chunks reused by the mesh module (no texture feedback). WebGL2
falls back to the ssf path for r=mesh (console note, chip enabled).
Stats line shows iso= in mesh mode; README + verify skill updated.

Bench (M-series, headless): 128^3/384^2 webgpu 4.12 ms/frame.

- wgsl.js interpolates the mcEmit CO/EA/EB literals from mctables.js's
  MC_CORNERS/MC_EDGES exports, so the JS table generator and the WGSL
  kernel literally cannot drift.
- mctables.js gains load-time asserts: maxLen == 15, case 1 == one
  triangle on edges {0,3,8}, and complementary checks (equal cut-edge
  sets for all cases; equal triangle counts for cases without an
  ambiguous face — full count symmetry deliberately does NOT hold for a
  face-consistent table, e.g. case 5 vs 250).
- Fallback observability: app.js marks an auto backend fallback as
  "webgl2 (fallback)" in the stats line, and backends expose
  effectiveMode() so an unimplemented mode reads "mesh→ssf" with the
  inert iso= readout suppressed. SKILL.md documents the evidence rule:
  WebGPU-only modes must pin ?api=webgpu and stats-assert both tokens.
- MC buffers (48 MB vertex pool + table + args) are created lazily on
  the first mesh-mode frame by ensureMeshResources(); init() only nulls
  the bind groups that reference per-config buffers.
- mcEmit treats out-of-range lattice samples as density 0, capping the
  isosurface against the walls (no more open backfaces where the pool
  meets a wall), and caches interpolated position+normal per unique cut
  edge instead of recomputing per triangle-corner.
- mcFinalize raises an overflow flag when the pre-clamp vertex count
  exceeds the cap — in args word 4 past the drawIndirect args, NOT
  firstInstance (non-zero firstInstance no-ops the indirect draw
  without the indirect-first-instance feature); readback hook deferred.
- Wall-extent const B hoisted into the shared WGSL common chunk (the
  g2p local it would shadow is renamed Bm).
