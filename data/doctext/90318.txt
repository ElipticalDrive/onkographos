# Noise Cloud（noise云）

> 项目创建者：南京大学智能化软件专业241880428沈逸文
>
> 最终版本：1.0.0
> 用途：UE5 体积云区域遮罩与 3D 云贴图的完全离线生成工具。

面向 Unreal Engine 5（UE5）体积云工作流的完全离线 Windows 桌面软件。现已提供区域遮罩生成，以及 3D 云贴图的 RG 体素生成和 PNG 切片图集交付。

## 快速开始（Windows 用户）

无需安装 Python。请在 GitHub 的 **Releases** 下载 `NoiseCloud-1.0.0-windows-x64.zip`，完整解压后双击 `NoiseCloud\NoiseCloud.exe`。不要单独移动 EXE，因为 `_internal` 目录包含运行所需库。首次使用请选择具有写入权限的输出目录；软件完全离线运行。

详细的交付说明见 [发布说明.md](发布说明.md)。

## 环境与运行

需安装 Python 3.11 或更高版本（Windows 安装器请勾选 **Add Python to PATH**）。在本目录执行：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m noise_cloud.app
```

若系统没有 `py` 启动器，可将第一条命令中的 `py -3.11` 改成已安装 Python 的完整路径。

## 测试

```powershell
.\.venv\Scripts\Activate.ps1
python -m unittest discover -s tests -v
```

测试覆盖固定云 ID、天气映射、区域遮罩编码，以及体积云的确定性、通道独立性、边界留白、雨层云覆盖与图集/元数据一致性。

## Windows 打包

```powershell
.\build_release.ps1 -SmokeTest
```

产物位于 `dist\NoiseCloud\NoiseCloud.exe`。构建依赖固定在 `requirements-build.lock.txt`；此应用不依赖运行时网络服务。

## 区域遮罩操作说明

1. 选择 512、1024 或 2048 分辨率，输入全局最低/最高高度（cm）。旁边的 km 仅为只读辅助换算。云的气象高度层保持为盒体锚点，体积盒高度会按旧版同次抽样扩大 4×；全局高度范围不足时会限制最大可用盒高。
2. 选择天气。除“其他天气”外，云类型由固定规则锁定；“其他天气”可多选类型。
3. 输入种子和覆盖率，点击“生成”。每个有云区是互不重叠的矩形 XY UV 区域，不绘制云轮廓；矩形的固定 G/B/A 将定义一个空间长方体，云形由其中采样的 3D 云贴图产生。阴天固定用 05 高层云整片覆盖天空；雨天固定用 06 雨层云整片覆盖天空，二者忽略覆盖率裁切。同一组参数与种子生成完全相同的像素数据；“重新随机”只改变种子。
4. 点击四张预览图可查看该像素的云类型及 G/B 解码高度。预览缩放不会修改导出数据。
5. 选择保存位置，再点击“保存 PNG + RectInfo EXR + JSON”。应用会输出原区域遮罩 PNG，以及同名 `_RegionRectInfo.exr`（RGBA16F：R/G=矩形左下 U/V，B/A=矩形宽/高）；两张图各有同名 JSON。UE 材质以连续 MaskUV 和矩形参数实时计算 LocalUV，避免 8-bit 局部UV放大后的方格。若任一主贴图已存在，应用会询问是否覆盖。

导出的 PNG 必须在 UE5 中以线性方式采样：按 **Masks** 导入并关闭 **sRGB**。详见 [数据格式与UE5对接.md](docs/数据格式与UE5对接.md)。

## 3D 云贴图操作说明

1. 选择一个固定 ID 云类型和低（64³）、中（128³）或高（256³）精度；页面会显示内存和耗时估算。
2. 调整种子、形状、细节和扰动强度后生成。每次只生成一种云；相同参数和种子得到完全一致的体素数据。
3. 在 R 密度和 G 扰动间切换，查看 XY、XZ、YZ 中央切片，并用 Z 滑块逐张检查。
4. 保存时会得到 RGBA PNG 图集、同名 JSON、6 张代表性 RGBA 检查切片。文件名以两位云类型 ID 开头，例如 `09_Cumulus_128x128x128_seed42_atlas.png`。

PNG 图集是 UE5 Volume Texture 的**源贴图交付格式**，不是 UE `.uasset`。UE5 先把 PNG 导入为 Texture2D 是正常行为；启用 `r.AllowVolumeTextureAssetCreation=1` 后，在图集上右键选择 **Create Volume Texture**，新资源才是 3D Volume Texture。每次导出附带同名转换说明，详见下方 UE5 对接文档。

应用内“贴图信息与 UE5 用法”可读取已导出 PNG 的同名 JSON、预览缩略图、复制节点说明并打开本地指南。完整流程见 [UE5使用指南.md](docs/UE5使用指南.md)。

项目总体流程、数据契约与技术实现见 [项目流程与技术文档.md](docs/项目流程与技术文档.md)。

```
from __future__ import annotations

import argparse
import json
import logging

import traceback

from PySide6.QtCore import Qt

def _placeholder(title: str, description: str, back_callback) -> QWidget:  # type: ignore[no-untyped-def]
    page = QWidget(); layout = QVBoxLayout(page); layout.addStretch()
    back = QPushButton("← 返回首页"); back.clicked.connect(back_callback); layout.addWidget(back)
    heading = QLabel(title); heading.setStyleSheet("font-size: 24px; font-weight: bold;"); heading.setAlignment(Qt.AlignmentFlag.AlignCenter)
    text = QLabel(description); text.setWordWrap(True); text.setAlignment(Qt.AlignmentFlag.AlignCenter)
    layout.addWidget(heading); layout.addWidget(text); layout.addStretch(); return page


class MainWindow(QMainWindow):
    def __init__(self) -> None:
        super().__init__()
        self.setWindowTitle("noise云 · UE5 体积云贴图生成器")
        self.resize(1250, 820)
        self.stack = QStackedWidget(); self.setCentralWidget(self.stack)
        self.home = self._build_home(); self.mask_page = RegionMaskPage()

        for page in (self.home, self.mask_page, self.cloud_page, self.help_page): self.stack.addWidget(page)
        self.mask_page.back_requested.connect(lambda: self.stack.setCurrentWidget(self.home))
        self.cloud_page.back_requested.connect(lambda: self.stack.setCurrentWidget(self.home))
        self.help_page.back_requested.connect(lambda: self.stack.setCurrentWidget(self.home))

    def _build_home(self) -> QWidget:
        page = QWidget(); layout = QVBoxLayout(page); layout.addStretch()
        title = QLabel("noise云"); title.setAlignment(Qt.AlignmentFlag.AlignCenter); title.setStyleSheet("font-size: 32px; font-weight: bold;")
        layout.addWidget(title)
        subtitle = QLabel("UE5 体积云贴图离线生成器"); subtitle.setAlignment(Qt.AlignmentFlag.AlignCenter); layout.addWidget(subtitle)
        for label, target in (("区域遮罩贴图生成", 1), ("3D 云贴图生成", 2), ("贴图信息与 UE5 用法", 3)):
            button = QPushButton(label); button.setMinimumHeight(48); button.clicked.connect(lambda _checked=False, index=target: self.stack.setCurrentIndex(index)); layout.addWidget(button)
        layout.addStretch(); return page


def main() -> int:
    parser = argparse.ArgumentParser(add_help=False)
    parser.add_argument("--smoke-test", metavar="OUTPUT_DIR")
    options, qt_args = parser.parse_known_args()
    if options.smoke_test:
        smoke_output = Path(options.smoke_test)
        try:
            return run_smoke_test(smoke_output)
        except Exception:
            smoke_output.mkdir(parents=True, exist_ok=True)
            (smoke_output / "smoke_test_error.txt").write_text(traceback.format_exc(), encoding="utf-8")
            return 1
    project_root = Path(sys.executable).resolve().parent if getattr(sys, "frozen", False) else Path(__file__).resolve().parents[1]
    try:
        log_dir = project_root / "logs"; log_dir.mkdir(exist_ok=True)
        logging.basicConfig(filename=log_dir / "noise_cloud.log", level=logging.INFO, encoding="utf-8", format="%(asctime)s %(levelname)s %(message)s")
    except OSError:
        logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(message)s")
    application = QApplication([sys.argv[0], *qt_args]); application.setApplicationName("noise云")
    window = MainWindow(); window.show()
    return application.exec()


def run_smoke_test(output_dir: Path) -> int:
    """供打包后的 EXE 验证完整本地工作流，不需要从源码启动。"""
    from noise_cloud.core.mask_generator import MaskParameters, generate_region_mask
    from noise_cloud.core.volume_generator import VolumeParameters, generate_volume_cloud
    from noise_cloud.io.mask_exporter import save_mask_bundle
    from noise_cloud.io.volume_exporter import save_volume_bundle, volume_base_filename

    output_dir.mkdir(parents=True, exist_ok=True)
    mask_result = generate_region_mask(MaskParameters(resolution=512, seed=505))
    mask_png, mask_json = save_mask_bundle(mask_result, output_dir / "区域遮罩_晴天_512.png")
    rect_info_exr = mask_png.with_name(f"{mask_png.stem}_RegionRectInfo.exr")
    volume_result = generate_volume_cloud(VolumeParameters(cloud_type_id=9, resolution=64, seed=505))
    volume_png, volume_json, slices = save_volume_bundle(volume_result, output_dir / f"{volume_base_filename(volume_result)}_atlas.png")
    # 实例化帮助页并真实读取两组文件，覆盖预览、JSON 校验和摘要链路。
    application = QApplication.instance() or QApplication([])
    helper = HelpPage(); helper.load_file(mask_png)
    if helper._texture is None or helper._texture.kind != "区域遮罩贴图":
        raise RuntimeError("烟雾测试未能在帮助页读取区域遮罩。")
    helper.load_file(rect_info_exr)
    if helper._texture is None or helper._texture.kind != "区域矩形参数贴图":
        raise RuntimeError("烟雾测试未能在帮助页读取 RegionRectInfo EXR。")
    helper.load_file(volume_png)
    if helper._texture is None or helper._texture.kind != "3D 云图集":
        raise RuntimeError("烟雾测试未能在帮助页读取 3D 云图集。")
    report = {
        "status": "passed", "mask_png": str(mask_png), "mask_json": str(mask_json), "rect_info_exr": str(rect_info_exr),
        "volume_atlas_png": str(volume_png), "volume_json": str(volume_json),
        "volume_check_slices": [str(path) for path in slices],
    }
    (output_dir / "smoke_test_report.json").write_text(json.dumps(report, ensure_ascii=False, indent=2), encoding="utf-8")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```
"""唯一的云类型编号和天气规则数据源。"""
from __future__ import annotations

from dataclasses import dataclass
from enum import Enum


@dataclass(frozen=True)
class CloudType:
    id: int
    chinese_name: str
    english_name: str
    altitude_layer: str
    typical_bottom_cm: int
    typical_top_cm: int
    default_allow_boundary_overlap: bool


# UE5 约定的唯一云类型表；不得在生成模块或 UI 中复制硬编码。
CLOUD_TYPES: tuple[CloudType, ...] = (
    CloudType(1, "卷云", "Cirrus", "高空", 600_000, 1_300_000, False),
    CloudType(2, "卷积云", "Cirrocumulus", "高空", 600_000, 1_200_000, False),
    CloudType(3, "卷层云", "Cirrostratus", "高空", 550_000, 1_100_000, True),
    CloudType(4, "高积云", "Altocumulus", "中空", 200_000, 600_000, False),
    CloudType(5, "高层云", "Altostratus", "中空", 250_000, 700_000, True),
    CloudType(6, "雨层云", "Nimbostratus", "低—中空", 80_000, 450_000, True),
    CloudType(7, "层积云", "Stratocumulus", "低空", 50_000, 250_000, True),
    CloudType(8, "层云", "Stratus", "低空", 10_000, 150_000, True),
    CloudType(9, "积云", "Cumulus", "低空", 60_000, 300_000, False),
    CloudType(10, "积雨云", "Cumulonimbus", "低—高空", 40_000, 1_100_000, False),
)
CLOUD_TYPE_BY_ID = {cloud.id: cloud for cloud in CLOUD_TYPES}


class Weather(str, Enum):
    CLEAR = "晴天"
    CLOUDY = "多云"
    OVERCAST = "阴天"
    LIGHT_MODERATE_RAIN = "小雨/中雨雨天"
    STORM = "暴雨/雷暴雨"
    OTHER = "其他天气"


WEATHER_ALLOWED_TYPES: dict[Weather, tuple[int, ...]] = {
    Weather.CLEAR: (1, 2, 9),
    Weather.CLOUDY: (4, 7, 9),
    Weather.OVERCAST: (3, 5, 7, 8),
    Weather.LIGHT_MODERATE_RAIN: (5, 6, 8),
    Weather.STORM: (6, 10),
    Weather.OTHER: tuple(cloud.id for cloud in CLOUD_TYPES),
}


def allowed_cloud_types(weather: Weather, selected_for_other: tuple[int, ...] | None = None) -> tuple[int, ...]:
    """返回天气下允许生成的云 ID；仅“其他天气”接受用户多选。"""
    if weather is Weather.OTHER and selected_for_other:
        valid = set(WEATHER_ALLOWED_TYPES[Weather.OTHER])
        return tuple(type_id for type_id in selected_for_other if type_id in valid)
    return WEATHER_ALLOWED_TYPES[weather]
```

```
"""帮助页内容；云 ID 与天气规则直接从共享模型生成。"""
from __future__ import annotations

from noise_cloud.core.cloud_catalog import CLOUD_TYPE_BY_ID, CLOUD_TYPES, WEATHER_ALLOWED_TYPES, Weather
from noise_cloud.io.metadata_reader import TextureMetadata


def cloud_rules_text() -> str:
    cloud_lines = "\n".join(f"{cloud.id:02d} · {cloud.chinese_name} / {cloud.english_name}（{cloud.altitude_layer}）" for cloud in CLOUD_TYPES)
    weather_lines = "\n".join(f"{weather.value}：{'、'.join(f'{type_id:02d}' for type_id in ids)}" for weather, ids in WEATHER_ALLOWED_TYPES.items())
    return f"固定云类型 ID（唯一数据源）\n{cloud_lines}\n\n天气允许类型\n{weather_lines}"


def region_mask_help_text() -> str:
    return """区域遮罩贴图（RGBA 8-bit 线性 PNG）

R：云可存在的矩形 XY UV 区域，0=无云、255=允许有云。
G：该矩形区域相对于本次导出全局高度范围归一化的固定云底高度。
B：该矩形区域相对于本次导出全局高度范围归一化的固定云顶高度，且云顶不小于云底。
A：8-bit 云类型 ID。R=0 时 A 必须为 0。

每个有云区域都是彼此不重叠的轴对齐矩形；它不是云的轮廓图。一个矩形连同其固定 G/B/A 值定义一个空间长方体：XY 来自该矩形 UV，Z 来自 G/B。应在这个长方体内采样匹配 A 类型的 3D 云贴图来形成云形。

常规天气可指定 1–500 个云区域；生成器会稳定输出该数量的互不重叠矩形。每一种云还可单独设置“空间盒中心高度范围”与“Top−Bottom 高度差区间”。界面会随全局高度范围显示当前算法参考值；重置按钮会把十种云恢复为这些参考值。未覆盖的高度范围由全局最低/最高高度限制。

阴天使用 ID 05 高层云的一个完整天空矩形；小雨/中雨与暴雨/雷暴雨使用 ID 06 雨层云的一个完整天空矩形。这三种天气会忽略覆盖率裁切。

所有高度单位都是 UE5 cm。材质解码公式：
BottomCm = lerp(GlobalMinCm, GlobalMaxCm, G)
TopCm = lerp(GlobalMinCm, GlobalMaxCm, B)
TypeId = round(A * 255)

UE5 导入：将贴图作为线性数据，关闭 sRGB；使用 Masks 或等效无 gamma 的合适压缩设置。Volume Domain 云材质中，以 R 选中矩形区域，以 G/B 重建该区域的云底和云顶，再以 round(A * 255) 读取云类型，并在对应空间长方体内采样匹配的 3D 图集。"""


def rect_info_help_text() -> str:
    return """RegionRectInfo（RGBA16F 线性 EXR）

它与同名区域遮罩一一对应，保存每个矩形的高精度参数；不保存云形、云类型或高度。有效矩形内的所有像素都存储同一组值，无云区为 0。

R：矩形左下角 U。
G：矩形左下角 V。
B：矩形宽度 U。
A：矩形高度 V。

UE5 中应以线性 HDR 数据导入，关闭 sRGB、MipMap，使用 Point/Nearest。区域遮罩仍以像素中心 UV 读取离散的 R/G/B/A；RegionRectInfo 也以该像素中心 UV 读取。随后用连续 MaskUV 的 U 和翻转后的 V 计算：
LocalUV = (float2(MaskUV.x, 1 - MaskUV.y) - RectInfo.RG) / RectInfo.BA

不要翻转 RegionMask 或 RegionRectInfo 的采样 UV；只在连续 LocalUV 计算中执行一次 `1-V`。导出器按左下 V 坐标写入 RectInfo.G；这样每个矩形会在任意大的世界空间中保持连续 UV，避免 8-bit LocalUV 量化造成的方格。"""


def volume_help_text(tile_columns: int | None = None, tile_rows: int | None = None) -> str:
    layout = "图集 tile 按从左到右、从上到下排列，z = row * tile_columns + column。"
    if tile_columns and tile_rows:
        layout = f"当前载入图集为 {tile_columns} 列 × {tile_rows} 行 tile；" + layout
    return f"""3D 云图集（RGBA 8-bit 线性 PNG）

{layout}
每个 tile 是一个 Z 切片；R=三维密度，G=独立连续的流动扰动噪声，B=0，A=255。PNG 图集是 Volume Texture 源数据，不能自动成为 UE .uasset。

UE5 使用流程：
1. 导入图集时关闭 sRGB，使用线性/Masks 或等效无 gamma 设置。
2. 依据 JSON 的 width、height、depth、tile_columns、tile_rows 将 tile 还原为 Z 切片，并在你的 UE5 版本或导入流程中创建/配置 Volume Texture。
3. 在 Volume Domain 材质中使用 Texture Sample Parameter Volume；R 接密度，G 用于随时间变化的采样坐标或密度扰动。

节点级公式：
UVW = (AbsoluteWorldPosition - BoxMin) / BoxSize
使用 BoxMask-3D（或等效范围遮罩）限制密度。
Extinction = DensityR * RegionMask * DensityMultiplier

动画仅偏移采样用的 UVW；区域遮罩始终以原始 AbsoluteWorldPosition 计算。因此云会流动，但不会越出区域遮罩边界。"""


def ue5_nodes_text() -> str:
    return region_mask_help_text() + "\n\n" + rect_info_help_text() + "\n\n" + volume_help_text() + "\n\n" + cloud_rules_text()


def metadata_summary(texture: TextureMetadata) -> str:
    data = texture.metadata
    lines = [f"类型：{texture.kind}", f"文件：{texture.image_path.name}", f"图像尺寸：{texture.image_size[0]} × {texture.image_size[1]}", f"编码版本：{data.get('encoding_version', '未知')}", f"生成时间（UTC）：{data.get('generated_at_utc', '未知')}", f"随机种子：{data.get('seed', '未知')}"]
    if texture.kind == "区域遮罩贴图":
        rect_info = data.get("rect_info_texture", {})
```

```
"""区域遮罩 RGBA 编码、解码和契约校验。"""
from __future__ import annotations

import numpy as np

ENCODING_VERSION = "ue5-mask-rgba-v1"
RECT_INFO_ENCODING_VERSION = "ue5-region-rect-info-rgba16f-exr-v2"


def encode_height_cm(height_cm: np.ndarray | float, global_min_cm: int, global_max_cm: int) -> np.ndarray:
    if global_max_cm <= global_min_cm:
        raise ValueError("最高高度必须大于最低高度。")
    normal = (np.asarray(height_cm, dtype=np.float64) - global_min_cm) / (global_max_cm - global_min_cm)
    return np.rint(np.clip(normal, 0.0, 1.0) * 255.0).astype(np.uint8)


def decode_height_cm(encoded: np.ndarray | int, global_min_cm: int, global_max_cm: int) -> np.ndarray:
    if global_max_cm <= global_min_cm:
        raise ValueError("最高高度必须大于最低高度。")
    return global_min_cm + (np.asarray(encoded, dtype=np.float64) / 255.0) * (global_max_cm - global_min_cm)


def validate_mask(mask: np.ndarray) -> None:
    """验证不可变 RGBA 契约，失败时给出可读错误。"""
    if mask.dtype != np.uint8 or mask.ndim != 3 or mask.shape[2] != 4:
        raise ValueError("区域遮罩必须是 H×W×4 的 8-bit RGBA 数组。")
    empty = mask[:, :, 0] == 0
    if np.any(mask[:, :, 3][empty] != 0):
        raise ValueError("无云像素（R=0）的 A 通道必须为 0。")
    occupied = ~empty
    if np.any(mask[:, :, 3][occupied] == 0):
        raise ValueError("有云像素（R=255）的 A 通道必须为云类型 ID。")
    if np.any(mask[:, :, 2][occupied] < mask[:, :, 1][occupied]):
        raise ValueError("有云像素的编码云顶不得小于云底。")


def validate_rect_info(rect_info: np.ndarray, mask: np.ndarray) -> None:
    """验证与区域遮罩一一对应的 RGBA16F 矩形参数贴图契约。"""
    if rect_info.dtype.kind != "f" or rect_info.ndim != 3 or rect_info.shape[2] != 4:
        raise ValueError("区域矩形参数贴图必须是 H×W×4 的浮点 RGBA 数组。")
    if rect_info.shape != mask.shape:
        raise ValueError("区域矩形参数贴图必须与区域遮罩具有相同尺寸。")
    occupied = mask[:, :, 0] == 255
    if not np.isfinite(rect_info).all() or np.any(rect_info < 0.0) or np.any(rect_info > 1.0):
        raise ValueError("区域矩形参数贴图的通道值必须是 0–1 之间的有限数。")
    if np.any(rect_info[~occupied] != 0.0):
        raise ValueError("区域矩形参数贴图的无云区域必须全部为 0。")
    if np.any(rect_info[:, :, 2][occupied] <= 0.0) or np.any(rect_info[:, :, 3][occupied] <= 0.0):
        raise ValueError("区域矩形参数贴图有效区的 B/A（宽/高）必须大于 0。")
    if np.any(rect_info[:, :, 0][occupied] + rect_info[:, :, 2][occupied] > 1.0001):
        raise ValueError("区域矩形参数贴图的 U 起点加宽度不能超出 1。")
    if np.any(rect_info[:, :, 1][occupied] + rect_info[:, :, 3][occupied] > 1.0001):
        raise ValueError("区域矩形参数贴图的 V 起点加高度不能超出 1。")
```

```
"""确定性的区域遮罩生成算法；不依赖 Qt。"""
from __future__ import annotations

from dataclasses import dataclass
from datetime import datetime, timezone
from typing import Callable

import numpy as np

from .cloud_catalog import CLOUD_TYPE_BY_ID, Weather, allowed_cloud_types
from .mask_codec import ENCODING_VERSION, RECT_INFO_ENCODING_VERSION, encode_height_cm, validate_mask, validate_rect_info

ProgressCallback = Callable[[int, str], None]
CancelCallback = Callable[[], bool]

# 气象高度层决定云盒的锚点；体积云贴图本身为近似立方体，需要显著更大的垂直空间。
# 该倍数相对于旧版同一随机抽样得到的实际云盒高度。
VOLUME_BOX_HEIGHT_MULTIPLIER = 4.0


@dataclass(frozen=True)
class CloudHeightRule:
    """单种云的空间盒中心高度和 Top-Bottom 高度差控制。"""

    type_id: int
    center_min_cm: int
    center_max_cm: int
    height_delta_min_cm: int
    height_delta_max_cm: int


@dataclass(frozen=True)
class MaskParameters:
    resolution: int = 1024
    global_min_cm: int = 0
    global_max_cm: int = 1_500_000
    weather: Weather = Weather.CLEAR
    seed: int = 20260826
    coverage_percent: int = 45
    cloud_region_count: int = 1
    selected_other_types: tuple[int, ...] = ()
    cloud_height_rules: tuple[CloudHeightRule, ...] = ()

    def validate(self) -> None:
        if self.resolution not in (512, 1024, 2048):
            raise ValueError("分辨率只能为 512、1024 或 2048。")
        if self.global_max_cm <= self.global_min_cm:
            raise ValueError("最高高度必须大于最低高度。")
        if not 0 <= self.coverage_percent <= 100:
            raise ValueError("覆盖率必须在 0–100% 之间。")
        if not 1 <= self.cloud_region_count <= 500:
            raise ValueError("云区域数量必须在 1–500 之间。")
        if not allowed_cloud_types(self.weather, self.selected_other_types):
            raise ValueError("请至少选择一种可生成的云类型。")
        known_ids: set[int] = set()
        global_span = self.global_max_cm - self.global_min_cm
        for rule in self.cloud_height_rules:
            if rule.type_id not in CLOUD_TYPE_BY_ID or rule.type_id in known_ids:
                raise ValueError("单云类型高度规则必须对应唯一且有效的云类型。")
            known_ids.add(rule.type_id)
            if not self.global_min_cm <= rule.center_min_cm <= rule.center_max_cm <= self.global_max_cm:
                raise ValueError(f"{CLOUD_TYPE_BY_ID[rule.type_id].chinese_name} 的中心高度范围必须位于全局高度范围内。")
            if not 1 <= rule.height_delta_min_cm <= rule.height_delta_max_cm <= global_span:
                raise ValueError(f"{CLOUD_TYPE_BY_ID[rule.type_id].chinese_name} 的高度差区间必须为 1 cm 到全局高度跨度之间。")


@dataclass(frozen=True)
class MaskResult:
    rgba: np.ndarray
    rect_info_rgba: np.ndarray
    metadata: dict


@dataclass(frozen=True)
class _MaskRegion:
    type_id: int
    x: int
    y: int
    width: int
    height: int


class GenerationCancelled(Exception):
    """后台任务被取消；上层不应保存任何不完整结果。"""


def _report(callback: ProgressCallback | None, percent: int, text: str) -> None:
    if callback:
        callback(percent, text)


def _check_cancel(cancel: CancelCallback | None) -> None:
    if cancel and cancel():
        raise GenerationCancelled("已取消生成。")


def _plan_rectangles(
    size: int, allowed: tuple[int, ...], coverage_percent: int, region_count: int,
    rng: np.random.Generator, cancel: CancelCallback | None,
) -> list[_MaskRegion]:
    """按指定数量规划不重叠轴对齐矩形；每块都是独立的 XY UV 容器。"""
    target_pixels = round(size * size * coverage_percent / 100)
    if target_pixels == 0:
        return []
    if target_pixels >= size * size and region_count == 1 and len(allowed) == 1:
        return [_MaskRegion(allowed[0], 0, 0, size, size)]
    if target_pixels < region_count:
        raise ValueError("当前覆盖率不足以为每个云区域至少分配一个遮罩像素。")

    # 以随机排列的网格单元作为互不重叠的容器。相较于反复碰撞尝试，它能在
    # 1–500 个区域、任意覆盖率下稳定地产生准确数量的矩形。
    columns = int(np.ceil(np.sqrt(region_count)))
    rows = int(np.ceil(region_count / columns))
    x_edges = np.rint(np.linspace(0, size, columns + 1)).astype(int)
    y_edges = np.rint(np.linspace(0, size, rows + 1)).astype(int)
    cells = [
        (int(x_edges[column]), int(y_edges[row]), int(x_edges[column + 1] - x_edges[column]), int(y_edges[row + 1] - y_edges[row]))
        for row in range(rows) for column in range(columns)
    ][:region_count]
    capacities = np.asarray([width * height for _x, _y, width, height in cells], dtype=np.int64)
    if np.any(capacities < 1) or target_pixels > int(capacities.sum()):
        raise ValueError("当前分辨率、覆盖率与云区域数量无法同时容纳。")

    # 每个区域至少一个像素，并按随机权重精确分配目标覆盖像素数。
    areas = np.ones(region_count, dtype=np.int64)
    remaining = target_pixels - region_count
    capacity_left = capacities - areas
    while remaining > 0:
        _check_cancel(cancel)
        weights = rng.random(region_count) * capacity_left
        total_weight = float(weights.sum())
        if total_weight <= 0:
            raise ValueError("当前云区域数量超过可用遮罩像素。")
        proposal = np.minimum(capacity_left, np.floor(weights / total_weight * remaining).astype(np.int64))
        used = int(proposal.sum())
        if used == 0:
            index = int(rng.choice(np.flatnonzero(capacity_left > 0)))
            proposal[index] = 1
            used = 1
        areas += proposal
        capacity_left -= proposal
        remaining -= used

    regions: list[_MaskRegion] = []
    for index, (cell_x, cell_y, cell_width, cell_height) in enumerate(cells):
        _check_cancel(cancel)
        desired = int(areas[index])
        aspect = float(rng.uniform(0.55, 1.8))
        width = min(cell_width, max(1, round(np.sqrt(desired * aspect))))
        height = min(cell_height, max(1, int(np.ceil(desired / width))))
        # 若第一轮被单元边界限制，优先扩展另一边，使实际面积尽可能接近目标。
        while width * height < desired and (width < cell_width or height < cell_height):
            if width < cell_width and (height >= cell_height or width <= height):
                width += 1
            elif height < cell_height:
                height += 1
        x = cell_x + int(rng.integers(0, cell_width - width + 1))
        y = cell_y + int(rng.integers(0, cell_height - height + 1))
        type_id = int(rng.choice(allowed))
        regions.append(_MaskRegion(type_id, x, y, width, height))
    return regions


def _profile_in_bounds(type_id: int, global_min: int, global_max: int) -> tuple[int, int]:
    profile = CLOUD_TYPE_BY_ID[type_id]
    low = max(global_min, profile.typical_bottom_cm)
    high = min(global_max, profile.typical_top_cm)
    if high > low:
        return low, high
    # 用户可导出任意高度范围；无交集时仍在所选范围内维持低/中/高层相对位置。
    layer_fraction = {"低空": (0.05, 0.32), "中空": (0.35, 0.65), "高空": (0.70, 0.95), "低—中空": (0.08, 0.62), "低—高空": (0.05, 0.92)}
    start, end = layer_fraction[profile.altitude_layer]
    span = global_max - global_min
    return int(global_min + span * start), int(global_min + span * end)


def reference_height_rule(type_id: int, global_min: int, global_max: int) -> CloudHeightRule:
    """返回当前全局高度下可直接作为 UI 初始值的单云类型参考规则。"""
    low, high = _profile_in_bounds(type_id, global_min, global_max)
    span = max(high - low, 1)
    # 参考值来自原算法的实际空间盒扩展区间；用户随后可按项目需求精确覆盖。
    legacy_min, legacy_max = (0.62, 0.92) if type_id == 10 else (0.22, 0.58)
    global_span = global_max - global_min
    delta_min = min(global_span, max(1, round(span * legacy_min * VOLUME_BOX_HEIGHT_MULTIPLIER)))
    delta_max = min(global_span, max(delta_min, round(span * legacy_max * VOLUME_BOX_HEIGHT_MULTIPLIER)))
    return CloudHeightRule(type_id, low, high, delta_min, delta_max)


def _region_height_range(type_id: int, params: MaskParameters, rng: np.random.Generator) -> tuple[float, float]:
    """以云的气象高度层为锚点，生成至少四倍旧版厚度的体积空间盒。"""
    configured_rule = next((rule for rule in params.cloud_height_rules if rule.type_id == type_id), None)
    if configured_rule is not None:
        center = float(rng.integers(configured_rule.center_min_cm, configured_rule.center_max_cm + 1))
        height = float(rng.integers(configured_rule.height_delta_min_cm, configured_rule.height_delta_max_cm + 1))
        bottom = float(np.clip(center - height * 0.5, params.global_min_cm, params.global_max_cm - height))
        return bottom, bottom + height

    low, high = _profile_in_bounds(type_id, params.global_min_cm, params.global_max_cm)
    span = max(high - low, 1)
    if type_id == 10:
        legacy_bottom = low + rng.random() * span * 0.18
        legacy_top = min(high, legacy_bottom + span * (0.62 + rng.random() * 0.30))
    else:
        legacy_bottom = low + rng.random() * span * 0.42
        legacy_top = min(high, legacy_bottom + span * (0.22 + rng.random() * 0.38))

    # 旧版的气象层范围被误用为体积云盒厚度，造成积云等明显扁平。
    # 以旧云层中心为锚点向上下扩展：若固定云底向上拉伸，高空云会大量
    # 同时撞到 global_max，从而失去不同云层的高度差异。
    legacy_height = max(legacy_top - legacy_bottom, 1.0)
    requested_height = legacy_height * VOLUME_BOX_HEIGHT_MULTIPLIER
    available_height = params.global_max_cm - params.global_min_cm
    box_height = min(requested_height, float(available_height))

    # 当上下空间不足时整体平移盒子，但优先保持云种的原始气象层中心。
    legacy_center = (legacy_bottom + legacy_top) * 0.5
    centered_bottom = legacy_center - box_height * 0.5
    bottom = float(np.clip(centered_bottom, params.global_min_cm, params.global_max_cm - box_height))
    top = bottom + box_height
    return bottom, top


def _build_rect_info_texture(size: int, regions: list[_MaskRegion]) -> np.ndarray:
    """构造高精度矩形参数：左下 UV 与宽高，而不是逐像素量化的 LocalUV。"""
    rect_info = np.zeros((size, size, 4), dtype=np.float32)
    for region in regions:
        y_slice = slice(region.y, region.y + region.height)
        x_slice = slice(region.x, region.x + region.width)
        # V 按 UE 逻辑 UV 的左下为原点：图像行 y=0 对应 V=1。
        rect_info[y_slice, x_slice, 0] = region.x / size
        rect_info[y_slice, x_slice, 1] = 1.0 - (region.y + region.height) / size
        rect_info[y_slice, x_slice, 2] = region.width / size
        rect_info[y_slice, x_slice, 3] = region.height / size
    return rect_info


def generate_region_mask(
    params: MaskParameters, progress: ProgressCallback | None = None, cancel: CancelCallback | None = None
) -> MaskResult:
    """生成符合 UE5 RGBA 契约的区域遮罩，给定相同参数时逐像素确定。"""
    params.validate()
    _report(progress, 2, "正在准备生成参数…")
    _check_cancel(cancel)
    rng = np.random.default_rng(params.seed)
    allowed = allowed_cloud_types(params.weather, params.selected_other_types)
    labels = np.zeros((params.resolution, params.resolution), dtype=np.uint8)
    bottoms = np.zeros(labels.shape, dtype=np.float64)
    tops = np.zeros(labels.shape, dtype=np.float64)
    # 单张 RGBA 遮罩的一个像素只能携带一个 A 类型。阴天以高层云作为整片天空的主云层；
    # 雨天以雨层云作为主云层。两者都是一个完整的矩形 UV 体积区域，覆盖率输入不参与裁切。
    full_sky_type = (
        5 if params.weather is Weather.OVERCAST
        else 6 if params.weather in (Weather.LIGHT_MODERATE_RAIN, Weather.STORM) and 6 in allowed
        else None
    )
    if full_sky_type is not None:
        labels.fill(full_sky_type)
        bottom, top = _region_height_range(full_sky_type, params, rng)
        bottoms.fill(bottom); tops.fill(top)
        regions = [_MaskRegion(full_sky_type, 0, 0, params.resolution, params.resolution)]
        description = "阴天高层云" if params.weather is Weather.OVERCAST else "雨层云"
        _report(progress, 42, f"已生成{description}整片天空覆盖区域。")
    else:
        regions = _plan_rectangles(
            params.resolution,
            allowed,
            params.coverage_percent,
            params.cloud_region_count,
            rng,
            cancel,
        )
        for index, region in enumerate(regions):
            _check_cancel(cancel)
            bottom, top = _region_height_range(region.type_id, params, rng)
            y_slice = slice(region.y, region.y + region.height)
            x_slice = slice(region.x, region.x + region.width)
            labels[y_slice, x_slice] = region.type_id
            bottoms[y_slice, x_slice] = bottom
            tops[y_slice, x_slice] = top
            _report(progress, 8 + round(42 * (index + 1) / max(1, len(regions))), f"正在规划 {CLOUD_TYPE_BY_ID[region.type_id].chinese_name} 的矩形 UV 区域…")
    _check_cancel(cancel)
    _report(progress, 55, "正在写入矩形区域的固定云底和云顶高度…")
    rgba = np.zeros((params.resolution, params.resolution, 4), dtype=np.uint8)
    occupied = labels > 0
    rgba[:, :, 0][occupied] = 255
    rgba[:, :, 1][occupied] = encode_height_cm(bottoms[occupied], params.global_min_cm, params.global_max_cm)
    rgba[:, :, 2][occupied] = encode_height_cm(tops[occupied], params.global_min_cm, params.global_max_cm)
    rgba[:, :, 3] = labels
    validate_mask(rgba)
    rect_info_rgba = _build_rect_info_texture(params.resolution, regions)
    validate_rect_info(rect_info_rgba, rgba)
    actual_types = sorted(int(value) for value in np.unique(labels) if value)
    metadata = {
        "encoding_version": ENCODING_VERSION,
        "generated_at_utc": datetime.now(timezone.utc).isoformat(),
        "unit": "cm",
        "global_min_cm": params.global_min_cm,
        "global_max_cm": params.global_max_cm,
        "weather": params.weather.value,
        "allowed_type_ids": list(allowed),
        "actual_type_ids": actual_types,
        "seed": params.seed,
        "resolution": [params.resolution, params.resolution],
        "coverage_percent": params.coverage_percent,
        "requested_cloud_region_count": params.cloud_region_count,
        "effective_coverage_percent": round(float(occupied.mean() * 100), 4),
        "volume_box_height_multiplier": VOLUME_BOX_HEIGHT_MULTIPLIER,
        "rect_info_encoding_version": RECT_INFO_ENCODING_VERSION,
        "rect_info_filename_suffix": "_RegionRectInfo",
        "rect_info_channels": {
            "R": "rectangle lower-left U normalized",
            "G": "rectangle lower-left V normalized",
            "B": "rectangle width normalized",
            "A": "rectangle height normalized",
        },
        "region_layout": "non_overlapping_axis_aligned_rectangles",
        "region_count": len(regions),
        "cloud_height_rules": [
            {
                "type_id": rule.type_id,
                "center_min_cm": rule.center_min_cm,
                "center_max_cm": rule.center_max_cm,
                "height_delta_min_cm": rule.height_delta_min_cm,
                "height_delta_max_cm": rule.height_delta_max_cm,
            }
            for rule in params.cloud_height_rules
        ],
        "regions": [
            {"x": region.x, "y": region.y, "width": region.width, "height": region.height, "type_id": region.type_id,
```

```
    """返回有限层状云的形状参数。

def _make_finite_edge_lobes(
    rng: np.random.Generator, center_x: float, center_y: float, type_id: int
) -> tuple[tuple[float, float, float, float, float, float, float], ...]:
    """为有限天气云区创建连通的三维宏观云瓣链，避免二维轮廓被沿 Z 轴拉成柱体。"""
    major_angle = float(rng.uniform(-np.pi, np.pi))
    direction = np.array((np.cos(major_angle), np.sin(major_angle)))
    perpendicular = np.array((-direction[1], direction[0]))
    major_length, cross_width = float(rng.uniform(0.45, 0.72)), float(rng.uniform(0.22, 0.46))
    profile_type_id = type_id if type_id in LAYER_CLOUD_TYPE_IDS else 5
    center_z, half_height, _, _, _, _, _ = _layer_shape_profile(profile_type_id)
    specs: list[tuple[float, float, float, float, float, float, float]] = []
    count = int(rng.integers(7, 13))
    positions_along = np.linspace(-0.88, 0.88, count) + rng.normal(0.0, 0.09, size=count)
    for position_along in positions_along:
        # 连续云瓣链避免脱离主体的小岛；横向扰动形成不规则、多方向的整体轮廓。
        along, cross = float(position_along * major_length), float(rng.normal(0.0, cross_width * 0.62))
        position = np.array((center_x, center_y)) + direction * along + perpendicular * cross
        radius_x, radius_y = float(rng.uniform(0.14, 0.30)), float(rng.uniform(0.12, 0.28))
        # 同一 XY 云瓣只在某个高度带最强：相邻瓣的中心、半径不同，侧缘因此自然起伏。
        lobe_z = float(center_z + rng.uniform(-0.48, 0.48) * half_height)
        lobe_z_radius = float(rng.uniform(0.58, 1.04) * half_height)
        specs.append((
            float(position[0]), float(position[1]), radius_x, radius_y, float(rng.uniform(0.54, 0.98)),
            lobe_z, lobe_z_radius,
        ))
    for _ in range(int(rng.integers(1, 3))):
        # 与主链重叠的侧向云瓣，保证云区不会退化为单一圆/椭圆形。
        along = float(rng.uniform(-0.58, 0.58) * major_length)
        cross = float(rng.choice((-1.0, 1.0)) * rng.uniform(0.60, 1.18) * cross_width)
        position = np.array((center_x, center_y)) + direction * along + perpendicular * cross
        radius_x, radius_y = float(rng.uniform(0.17, 0.31)), float(rng.uniform(0.15, 0.29))
        lobe_z = float(center_z + rng.uniform(-0.58, 0.58) * half_height)
        lobe_z_radius = float(rng.uniform(0.52, 0.94) * half_height)
        specs.append((
            float(position[0]), float(position[1]), radius_x, radius_y, float(rng.uniform(0.60, 1.02)),
            lobe_z, lobe_z_radius,
        ))
    return tuple(specs)


def _make_shape_variation(seed: int, type_id: int, cartoon_style: bool) -> _CloudShapeVariation:
    """创建非球形、可复现的基础云轮廓；卡通和写实模式使用不同随机序列。"""
    style_offset = 41_003 if cartoon_style else 31_009
    rng = np.random.default_rng(seed + type_id * 1_009 + style_offset)
    center_x, center_y = rng.uniform(-0.12, 0.12, size=2)
    # 除雨层云外，层状基础形状也会扩展到贴图绝大部分，只留下小边缘给材质扰动。
    layer_radius_x = float(rng.uniform(0.76, 0.90))
    layer_radius_y = float(rng.uniform(0.66, 0.86))
    angle = float(rng.uniform(-np.pi, np.pi))
    specs: list[tuple[float, float, float, float, float, float, float]] = []
    if type_id == 9:
        # 积云并不是上下对称的一组球：低处为宽而断续的云底，上方则在多个水平位置
        # 长出不同高度和尺度的云塔，形成真实积云常见的多峰、不规则顶部。
        for _ in range(int(rng.integers(3, 6))):
            cx = float(center_x + rng.uniform(-0.42, 0.42))
            cy = float(center_y + rng.uniform(-0.34, 0.34))
            cz = float(rng.uniform(-0.42, -0.16))
            rx, ry, rz = float(rng.uniform(0.27, 0.42)), float(rng.uniform(0.23, 0.37)), float(rng.uniform(0.14, 0.25))
            specs.append((cx, cy, cz, rx, ry, rz, float(rng.uniform(0.56, 0.86))))
        for _ in range(int(rng.integers(5, 10))):
            direction, radial = float(rng.uniform(-np.pi, np.pi)), float(rng.uniform(0.06, 0.52))
            cx = float(center_x + np.cos(direction) * radial)
            cy = float(center_y + np.sin(direction) * radial * rng.uniform(0.68, 1.0))
            cz = float(rng.uniform(-0.06, 0.54))
            rx, ry, rz = float(rng.uniform(0.17, 0.34)), float(rng.uniform(0.16, 0.32)), float(rng.uniform(0.18, 0.36))
            specs.append((cx, cy, cz, rx, ry, rz, float(rng.uniform(0.64, 1.05))))
        return _CloudShapeVariation(
            center_x, center_y, layer_radius_x, layer_radius_y, angle, tuple(specs), _make_finite_edge_lobes(rng, center_x, center_y, type_id)
        )

    lobe_count = 9 if type_id == 10 else (rng.integers(6, 10) if type_id == 7 else rng.integers(3, 6))
    for index in range(int(lobe_count)):
        if type_id == 10:
            # 积雨云从低层宽底座发展至顶部，半径和高度都不再是单一柱体。
            progress = index / max(1, int(lobe_count) - 1)
            cx = float(center_x + rng.normal(0.0, 0.13 + progress * 0.08))
            cy = float(center_y + rng.normal(0.0, 0.13 + progress * 0.08))
            cz = float(-0.58 + progress * 1.14 + rng.normal(0.0, 0.08))
            rx = float(rng.uniform(0.24, 0.34) + progress * 0.10)
            ry = float(rng.uniform(0.24, 0.34) + progress * 0.10)
            rz = float(rng.uniform(0.20, 0.34))
        else:
            radial = float(rng.uniform(0.03, 0.52))
            theta = float(rng.uniform(-np.pi, np.pi))
            cx = float(center_x + np.cos(theta) * radial)
            cy = float(center_y + np.sin(theta) * radial * rng.uniform(0.65, 1.0))
            cz = float(rng.uniform(-0.20, 0.20))
            rx = float(rng.uniform(0.23, 0.43))
            ry = float(rng.uniform(0.20, 0.40))
            rz = float(rng.uniform(0.18, 0.38))
        specs.append((cx, cy, cz, rx, ry, rz, float(rng.uniform(0.72, 1.12))))
    return _CloudShapeVariation(
        center_x, center_y, layer_radius_x, layer_radius_y, angle, tuple(specs), _make_finite_edge_lobes(rng, center_x, center_y, type_id)
    )

def _smoothstep(value: np.ndarray | float) -> np.ndarray:
    clipped = np.clip(value, 0.0, 1.0)
    return clipped * clipped * (3.0 - 2.0 * clipped)


def _safe_edge_fade(distance_to_edge: np.ndarray | float, empty_border: float, fade_width: float) -> np.ndarray:
    """连续边缘保护：不产生矩形空白带，仍保证最外体素为零。"""
    return _smoothstep((np.maximum(distance_to_edge - empty_border, 0.0)) / fade_width)


def _make_noise_lattices(seed: int, frequencies: tuple[int, ...]) -> tuple[np.ndarray, ...]:
    """创建可平铺的随机晶格；每个晶格小而稳定，避免固定方向的波纹。"""
    generator = np.random.default_rng(seed)
    return tuple(generator.random((frequency, frequency, frequency), dtype=np.float32) for frequency in frequencies)


def _fade(value: np.ndarray | float) -> np.ndarray:
    """Perlin 的五次平滑曲线，使晶格间过渡连续且无块状接缝。"""
    return value * value * value * (value * (value * 6.0 - 15.0) + 10.0)


def _value_noise_slice(lattice: np.ndarray, x: np.ndarray, y: np.ndarray, z: float) -> np.ndarray:
    """采样一个周期性 3D 值噪声切片；不包含任何方向性的条纹基函数。"""
    frequency = lattice.shape[0]
    px = (x + 1.0) * 0.5 * frequency
    py = (y + 1.0) * 0.5 * frequency
    pz = (z + 1.0) * 0.5 * frequency
    ix = np.floor(px).astype(np.intp) % frequency
    iy = np.floor(py).astype(np.intp) % frequency
    iz = np.floor(pz).astype(np.intp) % frequency
    fx, fy, fz = _fade(px - np.floor(px)), _fade(py - np.floor(py)), _fade(pz - np.floor(pz))
    ix1, iy1, iz1 = (ix + 1) % frequency, (iy + 1) % frequency, (iz + 1) % frequency
    c00 = lattice[iz, iy, ix] * (1.0 - fx) + lattice[iz, iy, ix1] * fx
    c10 = lattice[iz, iy1, ix] * (1.0 - fx) + lattice[iz, iy1, ix1] * fx
    c01 = lattice[iz1, iy, ix] * (1.0 - fx) + lattice[iz1, iy, ix1] * fx
    c11 = lattice[iz1, iy1, ix] * (1.0 - fx) + lattice[iz1, iy1, ix1] * fx
    lower = c00 * (1.0 - fy) + c10 * fy
    upper = c01 * (1.0 - fy) + c11 * fy
    return lower * (1.0 - fz) + upper * fz


def _fractal_value_noise(lattices: tuple[np.ndarray, ...], x: np.ndarray, y: np.ndarray, z: float, detail: float) -> np.ndarray:
    """多尺度、域扭曲且无固定方向周期条纹的可平铺值噪声。"""
    # 先用低频随机晶格作小幅域扭曲，再采样各尺度。所有坐标式仅含整数系数，
    # 跨越一个贴图周期时仍回到同一位置；不使用 sin/cos，因此不会重现斜向波纹。
    warp_strength = 0.12 + 0.08 * np.clip(detail, 0.0, 1.0)
    lattice_x = lattices[0]
    lattice_y = lattices[min(1, len(lattices) - 1)]
    lattice_z = lattices[min(2, len(lattices) - 1)]
    warp_x = _value_noise_slice(lattice_x, x + y, y - z, z + x) - 0.5
    warp_y = _value_noise_slice(lattice_y, 2.0 * x - y, x + z, y + z) - 0.5
    warp_z = _value_noise_slice(lattice_z, x - z, 2.0 * y + z, x + y - z) - 0.5
    warped_x, warped_y, warped_z = x + warp_strength * warp_x, y + warp_strength * warp_y, z + warp_strength * warp_z

    transforms = (
        (warped_x, warped_y, warped_z),
        (warped_x + warped_y, warped_y + warped_z, warped_z + warped_x),
        (2.0 * warped_x - warped_y, warped_x + 2.0 * warped_y, warped_z + warped_y),
        (warped_x - warped_z, 2.0 * warped_y + warped_z, warped_x + warped_y - warped_z),
        (2.0 * warped_x + warped_z, warped_y - warped_x, 2.0 * warped_z + warped_y),
    )
    samples = [
        _value_noise_slice(lattice, *transforms[index % len(transforms)])
        for index, lattice in enumerate(lattices)
    ]
    weights = [1.0]
    for index in range(1, len(samples)):
        # 细节强度只增加高频贡献，不会引入单一方向上的规则基波。
        weights.append((0.52 + detail * 0.16) ** index)
    total = sum(weight * sample for weight, sample in zip(weights, samples, strict=True))
    return np.clip(total / sum(weights), 0.0, 1.0)


def _make_cartoon_noise_set(seed: int) -> _CartoonNoiseSet:
    """创建卡通云专用噪声组；频率偏低且无正弦波，优先得到圆润不规则团块。"""
    return _CartoonNoiseSet(
        macro_lattices=_make_noise_lattices(seed + 20_101, (1, 2, 3)),
        body_lattices=_make_noise_lattices(seed + 20_503, (2, 3, 5)),
        edge_lattices=_make_noise_lattices(seed + 20_907, (3, 5, 7)),
        flow_lattices=_make_noise_lattices(seed + 21_301, (2, 3, 5, 8)),
    )


def _cartoon_noise_fields(
    noise_set: _CartoonNoiseSet, x: np.ndarray, y: np.ndarray, z: float, detail: float, disturbance: float
) -> tuple[np.ndarray, np.ndarray, np.ndarray, np.ndarray]:
    """返回卡通 R 所需的三组形状噪声与卡通 G 所需的独立流动噪声。"""
    macro = _fractal_value_noise(noise_set.macro_lattices, x, y, z, detail * 0.10)
    body = _fractal_value_noise(noise_set.body_lattices, x, y, z, detail * 0.30)
    edge = _fractal_value_noise(noise_set.edge_lattices, x, y, z, detail * 0.55)
    flow = _fractal_value_noise(noise_set.flow_lattices, x, y, z, disturbance * 0.25)
    return macro, body, edge, flow


def _rotated_xy(x: np.ndarray, y: np.ndarray, variation: _CloudShapeVariation) -> tuple[np.ndarray, np.ndarray]:
    """以随机中心和角度构造不同朝向的层状云与卷云轮廓。"""
    local_x, local_y = x - variation.center_x, y - variation.center_y
    cosine, sine = np.cos(variation.angle_radians), np.sin(variation.angle_radians)
    return cosine * local_x + sine * local_y, -sine * local_x + cosine * local_y


def _broad_footprint(x: np.ndarray, y: np.ndarray, variation: _CloudShapeVariation) -> np.ndarray:
    """大范围但不触边的圆润足迹，避免层状云被方形超椭圆边界束缚。"""
    local_x, local_y = _rotated_xy(x, y, variation)
    ellipse = (local_x / variation.layer_radius_x) ** 2 + (local_y / variation.layer_radius_y) ** 2
    return np.exp(-ellipse * 1.35)


def _natural_xy_edge_envelope(
    x: np.ndarray,
    y: np.ndarray,
    z: float,
    type_id: int,
    variation: _CloudShapeVariation,
    edge_noise: np.ndarray,
) -> np.ndarray:
    """构造有限层状云区的三维侧缘，而非把一张二维轮廓挤成柱体。"""
    local_x, local_y = _rotated_xy(x, y, variation)
    cosine, sine = np.cos(variation.angle_radians), np.sin(variation.angle_radians)
    lobe_field = np.zeros_like(x, dtype=np.float32)
    for center_x, center_y, radius_x, radius_y, weight, lobe_z, lobe_z_radius in variation.edge_lobe_specs:
        # 天气云瓣中心也在同一随机朝向下变换，不复用内部三维云球。
        offset_x, offset_y = center_x - variation.center_x, center_y - variation.center_y
        lobe_center_x, lobe_center_y = cosine * offset_x + sine * offset_y, -sine * offset_x + cosine * offset_y
        lobe = np.exp(-(((local_x - lobe_center_x) / (radius_x * 1.15)) ** 2 + ((local_y - lobe_center_y) / (radius_y * 1.15)) ** 2))
        # 边缘云瓣各自在不同高度有最强体积。厚广的云幕保留更多跨高度共同支撑，
        # 避免雨层云/高层云被误做成单个球体；层积云允许更明显的局部块状起伏。
        persistent_support = {3: 0.36, 5: 0.40, 6: 0.50, 7: 0.24, 8: 0.44}[type_id]
        vertical_presence = persistent_support + (1.0 - persistent_support) * np.exp(
            -((z - lobe_z) / max(lobe_z_radius, 0.001)) ** 2
        )
        lobe_field += np.float32(weight * vertical_presence) * lobe

    # 随机场会随 Z 切片缓慢变化，令侧缘有连贯的竖直起伏，而不是从底到顶完全笔直。
    # 靠近云层顶、底时横向范围逐渐收束；收束幅度由云型决定，雨层云保持厚重但不呈方柱。
    center_z, half_height, _, _, _, horizontal_taper, side_variation = _layer_shape_profile(type_id)
    normalized_height = abs(z - center_z) / max(half_height, 0.001)
    cap_taper = horizontal_taper * _smoothstep((normalized_height - 0.12) / 0.88)
    contour = lobe_field + (edge_noise - 0.5) * (0.62 + 0.30 * side_variation) - cap_taper
    organic = _smoothstep((contour - 0.30) / 0.48)
    # 极薄的最后保护只清除最外一两个体素；主体轮廓在到达这里以前已经自然归零。
    screen_distance = np.minimum.reduce((x + 1.0, 1.0 - x, y + 1.0, 1.0 - y))
    final_guard = _safe_edge_fade(screen_distance, 0.0, 0.045)
    return organic * final_guard


def _finite_layer_vertical_envelope(
    type_id: int,
    z: float,
    top_surface_noise: np.ndarray,
    bottom_surface_noise: np.ndarray,
    thickness_noise: np.ndarray,
) -> np.ndarray:
    """为不接触边界的层状云创建有起伏的顶、底面及局部厚薄。

    顶面、底面采用独立的低频随机高度场，避免同相移动造成整张云层像倾斜平板。
    厚薄变化会让侧视轮廓成为连贯的云系，而不是 XY 轮廓沿 Z 轴的直线外推。
    """
    center_z, half_height, top_wobble, bottom_wobble, thickness_variation, _, _ = _layer_shape_profile(type_id)
    # thickness_noise 只控制局部厚薄；限制其振幅，确保各处顶面始终高于底面。
    local_half_height = half_height * (0.84 + thickness_variation * thickness_noise)
    top = center_z + local_half_height + (top_surface_noise - 0.5) * top_wobble * 2.0
    bottom = center_z - local_half_height + (bottom_surface_noise - 0.5) * bottom_wobble * 2.0
    # 软过渡宽度同时跟随局部厚度，边缘是体积云的自然稀释而不是切面。
    feather = np.clip(local_half_height * 0.24, 0.045, 0.16)
    rise = _smoothstep((z - bottom) / feather)
    fall = 1.0 - _smoothstep((z - top) / feather)
    return np.clip(rise * fall, 0.0, 1.0)


def _fixed_layer_vertical_profile(type_id: int, z: float) -> float:
    """返回各云型旧基础公式中的固定 Z 曲线，用于有限云区时被随机表面取代。

    密度函数本身仍保留该曲线，以支持无缝平铺的默认模式。关闭边界接触后，若仅再乘
    一个随机包络，固定曲线仍会把可见顶、底压回水平层板；因此要先除去这一基线。
    """
    if type_id == 3:
        return float(np.exp(-((z + 0.04) / 0.13) ** 2))
    if type_id == 5:
        return float(np.exp(-((z + 0.03) / 0.25) ** 2))
    if type_id == 6:
        return float(np.exp(-((z + 0.03) / 0.43) ** 2))
    if type_id == 7:
        return float(np.exp(-((z + 0.28) / 0.23) ** 2))
    if type_id == 8:
        return float(np.exp(-((z + 0.37) / 0.16) ** 2))
    raise ValueError(f"云型 {type_id} 不是层状云。")


def _lobe_cluster(x: np.ndarray, y: np.ndarray, z: float, variation: _CloudShapeVariation) -> np.ndarray:
    """以平滑并集融合不规则多云瓣，避免 max 合并形成突兀的云球交界。"""
    field_sum = np.zeros_like(x, dtype=np.float32)
    for center_x, center_y, center_z, radius_x, radius_y, radius_z, weight in variation.lobe_specs:
        lobe = np.exp(
            -(
                ((x - center_x) / radius_x) ** 2
                + ((y - center_y) / radius_y) ** 2
                + ((z - center_z) / radius_z) ** 2
            )
        )
        field_sum += np.float32(weight) * lobe
    return np.clip(1.0 - np.exp(-field_sum * 1.18), 0.0, 1.0)


def _soft_union(*fields: np.ndarray) -> np.ndarray:
    """密度场的平滑并集：轮廓自然融合，且不会显示两个体积原语的硬分界。"""
    total = np.zeros_like(fields[0], dtype=np.float32)
    for field in fields:
        total += np.clip(field, 0.0, 1.0)
    return np.clip(1.0 - np.exp(-total * 1.12), 0.0, 1.0)


def _cumulus_base(x: np.ndarray, y: np.ndarray, z: float, variation: _CloudShapeVariation) -> np.ndarray:
    """积云的较低、扁平且圆润的云底；上部形态由横向分散的随机云塔主导。"""
    local_x, local_y = _rotated_xy(x, y, variation)
    horizontal = (local_x / (variation.layer_radius_x * 0.98)) ** 2 + (local_y / (variation.layer_radius_y * 0.86)) ** 2
    vertical = ((z + 0.30) / 0.31) ** 2
    return np.exp(-(horizontal * 1.10 + vertical * 1.38))


def _wisp_cluster(x: np.ndarray, y: np.ndarray, z: float, variation: _CloudShapeVariation) -> np.ndarray:
    """卷云的随机短云丝群。它由椭圆云瓣组成，不含会造成斜条纹的波函数。"""
    field_sum = np.zeros_like(x, dtype=np.float32)
    for center_x, center_y, center_z, radius_x, radius_y, radius_z, weight in variation.lobe_specs:
        # 将云瓣拉伸为短丝，位置仍采用同一随机云瓣集，保证种子可复现。
        lobe_x, lobe_y = _rotated_xy(x - center_x + variation.center_x, y - center_y + variation.center_y, variation)
        lobe = np.exp(-((lobe_x / (radius_x * 2.5)) ** 2 + (lobe_y / (radius_y * 0.34)) ** 2 + ((z - center_z * 0.22) / (radius_z * 0.28)) ** 2))
        field_sum += np.float32(weight) * lobe
    return np.clip(1.0 - np.exp(-field_sum * 1.10), 0.0, 1.0)


def _cartoon_density_slice(
    type_id: int,
    x: np.ndarray,
    y: np.ndarray,
    z: float,
    macro: np.ndarray,
    body: np.ndarray,
    edge: np.ndarray,
    variation: _CloudShapeVariation,
    finite_xy_boundary: bool,
    strength: float,
    detail: float,
) -> np.ndarray:
    """卡通云专用密度：大轮廓、主体团块和轮廓细节均来自独立卡通噪声组。"""
    broad = _smoothstep((macro - 0.27) / 0.52)
    puffs = _smoothstep((0.56 * macro + 0.44 * body - 0.37) / 0.38)
    rim = _smoothstep((edge - 0.33) / 0.48)
    fluffy = np.clip(0.62 * puffs + 0.23 * broad + 0.15 * rim, 0.0, 1.0)
    thin = np.exp(-((z + 0.04) / 0.13) ** 2)
    middle = np.exp(-((z + 0.10) / 0.30) ** 2)
    low = np.exp(-((z + 0.28) / 0.23) ** 2)
    footprint = np.ones_like(x, dtype=np.float32) if finite_xy_boundary else _broad_footprint(x, y, variation)
    cluster = _lobe_cluster(x, y, z, variation)
    wisps = _wisp_cluster(x, y, z, variation)

    if type_id == 1:  # 卷云：稀疏高空云丝，但轮廓仍来自随机团块而非条带波。
        density = thin * wisps * _smoothstep((0.72 * body + 0.28 * edge - 0.56) / 0.30)
    elif type_id == 2:  # 卷积云：高空细小、边界清晰的云团。
        density = thin * _soft_union(cluster, 0.55 * footprint) * fluffy**1.35
    elif type_id == 3:  # 卷层云：薄而连续的高空卡通云幕。
        density = thin * footprint * (0.58 + 0.42 * broad)
    elif type_id == 4:  # 高积云：中空成片大团块。
        density = middle * _soft_union(0.68 * footprint, cluster) * fluffy**1.05
    elif type_id == 5:  # 高层云：较厚连续云幕。
        density = np.exp(-((z + 0.03) / 0.25) ** 2) * footprint * (0.60 + 0.40 * broad)
    elif type_id == 6:  # 雨层云：全 XY 覆盖的厚层。
        density = np.exp(-((z + 0.03) / 0.43) ** 2) * (0.64 + 0.36 * broad)
    elif type_id == 7:  # 层积云：低空大块、带开阔空隙。
        density = low * _soft_union(cluster, 0.60 * footprint) * fluffy**0.82
    elif type_id == 8:  # 层云：平缓均匀的低空云层。
        density = np.exp(-((z + 0.37) / 0.16) ** 2) * footprint * (0.70 + 0.30 * broad)
    elif type_id == 9:  # 积云：由两个大体积云瓣组成，卡通团块只塑造内部和外缘。
        # 宽而不规则的云底使云团占据大部分局部空间；宏观噪声同时参与外缘，避免圆形底座显形。
        base = _cumulus_base(x, y, z, variation)
        surface = _smoothstep((0.58 * fluffy + 0.42 * broad - 0.20) / 0.70)
        density = _soft_union(cluster * (0.22 + 0.78 * fluffy), 0.68 * base * (0.30 + 0.70 * surface))
    else:  # 积雨云：垂直核心与顶部铁砧，并以卡通团块打破规则边界。
        anvil = footprint * np.exp(-((z - 0.48) / 0.16) ** 2)
        density = _soft_union(cluster, 0.82 * anvil) * (0.40 + 0.60 * fluffy)

    # 贴图主体保持连续密度，避免体积渲染显出同心球壳；卡通材质可在 HLSL 最后阶段按需量化。
    shaped = _smoothstep((density - 0.07) / 0.62)
    stepped = np.floor(np.clip(shaped, 0.0, 1.0) * 4.0 + 0.20) / 4.0
    return np.clip((0.12 * stepped + 0.88 * shaped) * strength * (0.94 + 0.06 * detail * rim), 0.0, 1.0)


def _cartoon_flow_noise(macro: np.ndarray, body: np.ndarray, flow: np.ndarray, strength: float) -> np.ndarray:
    """卡通 G 通道：低频连贯流动，和 R 的团块尺度相近但源晶格独立。"""
    coherent = np.clip(0.58 * flow + 0.27 * macro + 0.15 * body, 0.0, 1.0)
    return np.clip(0.5 + (coherent - 0.5) * strength, 0.0, 1.0)


def _density_slice(
    type_id: int, x: np.ndarray, y: np.ndarray, z: float, noise: np.ndarray, variation: _CloudShapeVariation,
    finite_xy_boundary: bool, strength: float, detail: float,
) -> np.ndarray:
    """根据云种类构造显著不同的密度形状，尚未施加通用边界淡出。"""
    thin = np.exp(-((z + 0.04) / 0.13) ** 2)
    middle = np.exp(-((z + 0.10) / 0.30) ** 2)
    broad_noise = np.clip((noise - 0.32) * 1.65, 0.0, 1.0)
    fine = np.clip((noise - 0.48) * 2.5, 0.0, 1.0)
    footprint = np.ones_like(x, dtype=np.float32) if finite_xy_boundary else _broad_footprint(x, y, variation)
    cluster = _lobe_cluster(x, y, z, variation)
    wisps = _wisp_cluster(x, y, z, variation)
    if type_id == 1:  # 卷云：由非周期高空细节形成的纤细云丝
        density = wisps * (0.22 + 0.78 * np.clip((noise - 0.52) * 2.8, 0.0, 1.0)) * thin * (0.32 + 0.68 * broad_noise)
    elif type_id == 2:  # 卷积云：细小颗粒状云块
        density = _soft_union(cluster, 0.50 * footprint) * fine**1.45 * thin * (0.50 + 0.50 * broad_noise)
    elif type_id == 3:  # 卷层云：高空薄幕
        density = thin * footprint * (0.50 + 0.44 * noise)
    elif type_id == 4:  # 高积云：中空成片小云团
        density = _soft_union(cluster, 0.62 * footprint) * broad_noise**1.20 * middle * (0.68 + 0.32 * fine)
    elif type_id == 5:  # 高层云：较厚、连续的中空云幕
        density = np.exp(-((z + 0.03) / 0.25) ** 2) * footprint * (0.50 + 0.42 * noise)
    elif type_id == 6:  # 雨层云：X/Y 整体覆盖的厚层；不使用左右边界淡出
        density = np.exp(-((z + 0.03) / 0.43) ** 2) * (0.56 + 0.34 * noise)
    elif type_id == 7:  # 层积云：低空大块、带空隙
        density = _soft_union(cluster, 0.58 * footprint) * broad_noise**0.85 * np.exp(-((z + 0.28) / 0.23) ** 2)
    elif type_id == 8:  # 层云：平缓均匀的低空云层
        density = np.exp(-((z + 0.37) / 0.16) ** 2) * footprint * (0.62 + 0.25 * noise)
    elif type_id == 9:  # 积云：居中的棉花团，带块状细节
        # 多个随机云瓣形成不规则云团，噪声只雕刻表面和内部，避免退化为单一球体。
        puffs = np.clip((noise - 0.34) / 0.46, 0.0, 1.0)
        base = _cumulus_base(x, y, z, variation)
        surface = _smoothstep((0.62 * puffs + 0.38 * broad_noise - 0.20) / 0.72)
        density = _soft_union(cluster * (0.24 + 0.76 * puffs), 0.50 * base * (0.18 + 0.82 * surface))
    else:  # 积雨云：居中柱状强烈垂直发展，并在顶端形成铁砧状扩展
        anvil = footprint * np.exp(-((z - 0.48) / 0.15) ** 2)
        density = _soft_union(cluster, 0.83 * anvil) * (0.44 + 0.56 * broad_noise)
    return np.clip(density * strength * (0.92 + detail * 0.08 * fine), 0.0, 1.0)


def generate_volume_cloud(
    params: VolumeParameters, progress: ProgressCallback | None = None, cancel: CancelCallback | None = None
) -> VolumeResult:
    """生成 R 密度与独立 G 扰动，逐 Z 切片计算以降低临时内存峰值。"""
    params.validate()
    cloud = CLOUD_TYPE_BY_ID[params.cloud_type_id]
    size = params.resolution
    _report(progress, 1, f"正在分配 {size}³ 体素缓冲区（预计峰值约 {estimate_memory_mb(size):.0f} MB）…")
    try:
        density = np.zeros((size, size, size), dtype=np.uint8)
        disturbance = np.zeros((size, size, size), dtype=np.uint8)
    except MemoryError as exc:
        raise VolumeMemoryPressureError("内存不足，无法分配体素缓冲区；请切换到较低精度。") from exc
    try:
        axis = np.linspace(-1.0, 1.0, size, dtype=np.float32)
        x, y = np.meshgrid(axis, axis, indexing="xy")
        # 写实模式的 R 与 G 分别使用独立随机晶格；R 的频率刻意保持中低，优先维护云的宏观形状。
        density_lattices = _make_noise_lattices(params.seed + 101, (2, 3, 5, 8, 13))
        flow_lattices = _make_noise_lattices(params.seed + 7_919, (2, 4, 7, 11))
        boundary_lattices = _make_noise_lattices(params.seed + 12_113, (1, 2, 3, 5))
        # 卡通模式绝不复用写实晶格，R/G 从该噪声组共同决定视觉尺度，但仍是独立随机源。
        cartoon_noise_set = _make_cartoon_noise_set(params.seed) if params.cartoon_style else None
        shape_variation = _make_shape_variation(params.seed, params.cloud_type_id, params.cartoon_style)
        uses_natural_finite_edge = (
            not params.resolved_allow_boundary_overlap
            and cloud.default_allow_boundary_overlap
            and params.cloud_type_id in LAYER_CLOUD_TYPE_IDS
        )
        # 连续层状云关闭边界超出时使用自然有限云区；离散云团保留自身轮廓，
        # 仅在最外体素施加极薄保护，避免产生与纹理边缘平行的方框裁切。
        # 有限层状云的上下表面来自三张独立的二维低频高度场；它们只在关闭
        # "允许接触边界" 时作用，保留默认平铺模式在相邻贴图间的连续性。
        top_surface_noise = _fractal_value_noise(boundary_lattices, x, y, -0.61, params.detail_strength * 0.22)
        bottom_surface_noise = _fractal_value_noise(boundary_lattices, x, y, 0.27, params.detail_strength * 0.26)
        thickness_noise = _fractal_value_noise(boundary_lattices, x, y, 0.83, params.detail_strength * 0.18)
        xy_distance = np.minimum.reduce((x + 1.0, 1.0 - x, y + 1.0, 1.0 - y))
        discrete_cloud_edge_guard = _safe_edge_fade(xy_distance, 0.0, 0.045)
        for z_index, z in enumerate(axis):
            _check_cancel(cancel)
            if params.cartoon_style:
                assert cartoon_noise_set is not None
                macro, body, edge, cartoon_flow = _cartoon_noise_fields(
                    cartoon_noise_set, x, y, float(z), params.detail_strength, params.disturbance_strength
                )
                raw = _cartoon_density_slice(
                    params.cloud_type_id, x, y, float(z), macro, body, edge, shape_variation,
                    uses_natural_finite_edge, params.shape_strength, params.detail_strength,
                )
                flow = _cartoon_flow_noise(macro, body, cartoon_flow, params.disturbance_strength)
            else:
                density_noise = _fractal_value_noise(density_lattices, x, y, float(z), params.detail_strength)
                flow_noise = _fractal_value_noise(flow_lattices, x, y, float(z), params.disturbance_strength)
                raw = _density_slice(
                    params.cloud_type_id, x, y, float(z), density_noise, shape_variation,
                    uses_natural_finite_edge, params.shape_strength, params.detail_strength,
                )
                flow = 0.5 + (flow_noise - 0.5) * params.disturbance_strength
            z_distance = min(float(z + 1.0), float(1.0 - z))
            z_fade = float(_safe_edge_fade(z_distance, SAFE_EMPTY_BORDER_Z, SAFE_FADE_WIDTH_Z))
            if uses_natural_finite_edge:
                # 每个 Z 切片均重算侧缘噪声；二维随机外轮廓会随高度产生连贯变化。
                side_edge_noise = _fractal_value_noise(
                    boundary_lattices,
                    x + float(z) * 0.16,
                    y - float(z) * 0.11,
                    float(z) * 1.75 + 0.19,
                    params.detail_strength * 0.42,
                )
                natural_xy_edge = _natural_xy_edge_envelope(
                    x, y, float(z), params.cloud_type_id, shape_variation, side_edge_noise
                )
                vertical_envelope = _finite_layer_vertical_envelope(
                    params.cloud_type_id, float(z), top_surface_noise, bottom_surface_noise, thickness_noise
                )
                # 各层状密度函数原本含固定 Z 高斯曲线。有限云区时以随机顶、底面
                # 取代它，避免固定曲线再次把起伏表面压成平整薄板。0.075 的下限
                # 仅防止在完全空切片除零，不会在最终 Z 淡出外制造密度。
                fixed_vertical = max(_fixed_layer_vertical_profile(params.cloud_type_id, float(z)), 0.075)
                raw *= natural_xy_edge * (vertical_envelope / fixed_vertical)
            elif not params.resolved_allow_boundary_overlap:
                raw *= discrete_cloud_edge_guard
            raw *= z_fade
            density[z_index] = np.rint(np.clip(raw, 0.0, 1.0) * 255.0).astype(np.uint8)
            # G 始终是连续、可平铺的体积扰动。卡通模式使用专属低频流动组；写实模式使用原流动组。
            disturbance[z_index] = np.rint(np.clip(flow, 0.0, 1.0) * 255.0).astype(np.uint8)
            if z_index % max(1, size // 30) == 0:
                _report(progress, 2 + round(94 * (z_index + 1) / size), f"正在生成第 {z_index + 1}/{size} 个 Z 切片…")
        _check_cancel(cancel)
        # UE5 的“Create Volume Texture”从 2D 图集推导深度。严格单行排列可确保
        # 图集高度就是单个切片高度，且不会因最后一行补齐 tile 产生黑色空切片。
        cols, rows = size, 1
        metadata = {
            "encoding_version": VOLUME_ENCODING_VERSION,
            "generated_at_utc": datetime.now(timezone.utc).isoformat(),
            "width": size, "height": size, "depth": size,
            "tile_columns": cols, "tile_rows": rows,
            "axis_order": "Z,Y,X",
            "cloud_type_id": cloud.id,
            "cloud_type_name": cloud.english_name,
            "precision": f"{size}³",
            "seed": params.seed,
            "shape_strength": params.shape_strength,
            "detail_strength": params.detail_strength,
            "disturbance_strength": params.disturbance_strength,
            "style": "cartoon" if params.cartoon_style else "realistic",
            "noise_profile": "cartoon-rounded-clusters-domain-warp-v4" if params.cartoon_style else "realistic-multiscale-domain-warp-v5",
            "shape_profile": "type-aware-diverse-lobes-cumulus-turrets-v3-undulating-layer-envelope",
            "allow_boundary_overlap_xy": params.resolved_allow_boundary_overlap,
            "boundary_overlap_source": "user" if params.allow_boundary_overlap is not None else "cloud-type-default",
            "safe_empty_border_fraction_xy": SAFE_EMPTY_BORDER_XY if not params.resolved_allow_boundary_overlap else 0.0,
            "safe_fade_width_fraction_xy": SAFE_FADE_WIDTH_XY if not params.resolved_allow_boundary_overlap else 0.0,
            "finite_edge_profile_xy": (
                "seeded-connected-3d-irregular-layer-envelope" if uses_natural_finite_edge
                else ("cloud-shape-with-thin-final-edge-guard" if not params.resolved_allow_boundary_overlap else "none-tileable-boundary-overlap")
            ),
            "safe_empty_border_fraction_z": SAFE_EMPTY_BORDER_Z,
            "noise_domain_warp": "low-frequency tiled random vector warp; no trigonometric basis",
            "noise_groups": (
                {
                    "R": "cartoon macro/body/edge: separate tiled value-noise lattices (1-7 cells), rounded cluster density",
                    "G": "cartoon flow: separate tiled value-noise lattices (2-8 cells), low-frequency coherent internal flow",
                }
                if params.cartoon_style
                else {
```

### noise_cloud/io/exr_io.py
```
"""最小化的无压缩 RGBA16F OpenEXR 读写器。

区域矩形数据需要高于 8-bit 的精度，但应用不依赖第三方 OpenEXR 绑定。
本模块只处理本应用写出的单层、无压缩、scanline RGBA half EXR 文件。
"""
from __future__ import annotations

import struct
from pathlib import Path

import numpy as np


class ExrError(ValueError):
    """EXR 不是本应用支持的无压缩 RGBA16F 数据贴图。"""


_MAGIC = 20000630
_VERSION = 2
# OpenEXR scanline payloads are ordered alphabetically by channel name.  This
# is intentionally separate from the public numpy RGBA component order.
_FILE_CHANNELS = ("A", "B", "G", "R")
_RGBA_CHANNELS = ("R", "G", "B", "A")


def _attribute(name: str, type_name: str, value: bytes) -> bytes:
    return name.encode("ascii") + b"\0" + type_name.encode("ascii") + b"\0" + struct.pack("<I", len(value)) + value


def _header(width: int, height: int) -> bytes:
    channels = b"".join(
        channel.encode("ascii") + b"\0" + struct.pack("<i", 1) + b"\0\0\0\0" + struct.pack("<ii", 1, 1)
        for channel in _FILE_CHANNELS
    ) + b"\0"
    box = struct.pack("<iiii", 0, 0, width - 1, height - 1)
    attributes = b"".join((
        _attribute("channels", "chlist", channels),
        _attribute("compression", "compression", b"\0"),
        _attribute("dataWindow", "box2i", box),
        _attribute("displayWindow", "box2i", box),
        _attribute("lineOrder", "lineOrder", b"\0"),
        _attribute("pixelAspectRatio", "float", struct.pack("<f", 1.0)),
        _attribute("screenWindowCenter", "v2f", struct.pack("<ff", 0.0, 0.0)),
        _attribute("screenWindowWidth", "float", struct.pack("<f", 1.0)),
    ))
    return struct.pack("<II", _MAGIC, _VERSION) + attributes + b"\0"


def write_rgba16f_exr(path: str | Path, rgba: np.ndarray) -> None:
    """写入线性、无压缩的 RGBA16F EXR，RGBA 形状为 H×W×4。"""
    if rgba.ndim != 3 or rgba.shape[2] != 4 or rgba.dtype.kind != "f":
        raise ExrError("RGBA16F EXR 数据必须是 H×W×4 的浮点数组。")
    height, width = rgba.shape[:2]
    if width < 1 or height < 1:
        raise ExrError("RGBA16F EXR 的宽高必须大于 0。")
    values = np.ascontiguousarray(rgba.astype("<f2", copy=False))
    header = _header(width, height)
    row_bytes = width * len(_FILE_CHANNELS) * 2
    first_block = len(header) + height * 8
    offsets = [first_block + index * (8 + row_bytes) for index in range(height)]
    output = bytearray(header)
    output.extend(b"".join(struct.pack("<Q", offset) for offset in offsets))
    for y in range(height):
        output.extend(struct.pack("<ii", y, row_bytes))
        # OpenEXR scanline 数据按字母序的通道平面连续存放，而不是交错 RGBA。
        # 之前按 R/G/B/A 写入会被标准读取器解释为 A/B/G/R，导致 UE 中的
        # RectInfo.RGBA 语义错位。
        for channel in _FILE_CHANNELS:
            output.extend(values[y, :, _RGBA_CHANNELS.index(channel)].tobytes())
    Path(path).write_bytes(output)


def _read_header(data: bytes) -> tuple[int, int, tuple[str, ...], int]:
    if len(data) < 9 or struct.unpack_from("<I", data, 0)[0] != _MAGIC:
        raise ExrError("文件不是 OpenEXR。")
    version = struct.unpack_from("<I", data, 4)[0]
    if version & 0xFF != _VERSION:
        raise ExrError("不支持的 OpenEXR 版本。")
    cursor = 8
    attrs: dict[str, tuple[str, bytes]] = {}
    while True:
        end = data.find(b"\0", cursor)
        if end < 0:
            raise ExrError("OpenEXR 文件头已损坏。")
        if end == cursor:
            cursor += 1
            break
        name = data[cursor:end].decode("ascii")
        cursor = end + 1
        end = data.find(b"\0", cursor)
        if end < 0:
            raise ExrError("OpenEXR 文件头已损坏。")
        type_name = data[cursor:end].decode("ascii")
        cursor = end + 1
        if cursor + 4 > len(data):
            raise ExrError("OpenEXR 文件头已损坏。")
        length = struct.unpack_from("<I", data, cursor)[0]
        cursor += 4
        if cursor + length > len(data):
            raise ExrError("OpenEXR 文件头已损坏。")
        attrs[name] = (type_name, data[cursor:cursor + length])
        cursor += length
    try:
        if attrs["compression"][1] != b"\0":
            raise ExrError("仅支持无压缩的 RGBA16F EXR。")
        x_min, y_min, x_max, y_max = struct.unpack("<iiii", attrs["dataWindow"][1])
    except (KeyError, struct.error) as exc:
        raise ExrError("OpenEXR 缺少有效的数据窗口。") from exc
    channels_raw = attrs.get("channels", ("", b""))[1]
    channels: list[str] = []
    channel_cursor = 0
    while channel_cursor < len(channels_raw) and channels_raw[channel_cursor] != 0:
        end = channels_raw.find(b"\0", channel_cursor)
        if end < 0 or end + 17 > len(channels_raw):
            raise ExrError("OpenEXR 通道描述无效。")
        channels.append(channels_raw[channel_cursor:end].decode("ascii"))
        pixel_type = struct.unpack_from("<i", channels_raw, end + 1)[0]
        if pixel_type != 1:
            raise ExrError("仅支持 half（16-bit float）EXR 通道。")
        channel_cursor = end + 17
    if set(channels) != set(_RGBA_CHANNELS):
        raise ExrError("仅支持 RGBA 四通道 EXR。")
    return x_max - x_min + 1, y_max - y_min + 1, tuple(channels), cursor


def read_rgba16f_exr(path: str | Path) -> np.ndarray:
    """读取本模块导出的无压缩 RGBA16F EXR，并返回 float32 H×W×4。"""
    data = Path(path).read_bytes()
    width, height, channels, header_end = _read_header(data)
    offset_start = header_end
    if offset_start + height * 8 > len(data):
        raise ExrError("OpenEXR 扫描线偏移表已损坏。")
    result = np.zeros((height, width, 4), dtype=np.float32)
    expected_row_bytes = width * len(channels) * 2
    for row_index in range(height):
        offset = struct.unpack_from("<Q", data, offset_start + row_index * 8)[0]
        if offset + 8 + expected_row_bytes > len(data):
            raise ExrError("OpenEXR 扫描线数据已损坏。")
        y, row_bytes = struct.unpack_from("<ii", data, offset)
        if row_bytes != expected_row_bytes or not 0 <= y < height:
            raise ExrError("OpenEXR 扫描线格式不受支持。")
        cursor = offset + 8
        for channel in channels:
            plane = np.frombuffer(data, dtype="<f2", count=width, offset=cursor).astype(np.float32)
            result[y, :, _RGBA_CHANNELS.index(channel)] = plane
            cursor += width * 2
    return result


def read_exr_size(path: str | Path) -> tuple[int, int]:
    """只读取 EXR 头部尺寸，供元数据校验使用。"""
    data = Path(path).read_bytes()
    width, height, _channels, _header_end = _read_header(data)
    return width, height
```

### noise_cloud/io/metadata_reader.py
```
"""读取并校验应用自身导出的贴图 JSON 元数据。"""
from __future__ import annotations

import json
from dataclasses import dataclass
from pathlib import Path
from typing import Any

from PIL import Image, UnidentifiedImageError

from noise_cloud.core.cloud_catalog import CLOUD_TYPE_BY_ID
from noise_cloud.core.mask_codec import ENCODING_VERSION, RECT_INFO_ENCODING_VERSION
from noise_cloud.io.exr_io import ExrError, read_exr_size
from noise_cloud.core.volume_generator import VOLUME_ENCODING_VERSION


class MetadataReadError(ValueError):
    """向界面提供的可读元数据错误。"""


@dataclass(frozen=True)
class TextureMetadata:
    image_path: Path
    json_path: Path
    kind: str
    image_size: tuple[int, int]
    metadata: dict[str, Any]


def _read_json(path: Path) -> dict[str, Any]:
    if not path.is_file():
        raise MetadataReadError(f"未找到同名 JSON 元数据：{path.name}。请同时选择应用导出的 PNG 与 JSON 文件。")
    try:
        value = json.loads(path.read_text(encoding="utf-8"))
    except UnicodeDecodeError as exc:
        raise MetadataReadError("JSON 元数据不是 UTF-8 编码，无法读取。") from exc
    except json.JSONDecodeError as exc:
        raise MetadataReadError(f"JSON 元数据已损坏：第 {exc.lineno} 行附近格式错误。") from exc
    if not isinstance(value, dict):
        raise MetadataReadError("JSON 元数据格式无效：根节点必须为对象。")
    return value


def read_texture_metadata(image_path: str | Path) -> TextureMetadata:
    """读取区域 PNG、RectInfo EXR 或云图集 PNG，并验证同名 JSON。"""
    path = Path(image_path)
    if not path.is_file():
        raise MetadataReadError(f"找不到贴图文件：{path}。")
    try:
        if path.suffix.lower() == ".exr":
            image_size = read_exr_size(path)
        else:
            with Image.open(path) as image:
                if image.format != "PNG":
                    raise MetadataReadError("仅支持读取 PNG 或本应用导出的 RGBA16F EXR 数据贴图。")
                image_size = image.size
    except (UnidentifiedImageError, ExrError) as exc:
        raise MetadataReadError("所选文件不是可读取的 PNG 或 RGBA16F EXR 图像。") from exc
    json_path = path.with_suffix(".json")
    metadata = _read_json(json_path)
    version = metadata.get("encoding_version")
    if version == ENCODING_VERSION:
        resolution = metadata.get("resolution")
        if not isinstance(resolution, list) or len(resolution) != 2:
            raise MetadataReadError("区域遮罩 JSON 缺少有效的 resolution 字段。")
        if tuple(resolution) != image_size:
            raise MetadataReadError("区域遮罩 PNG 尺寸与 JSON 的 resolution 不一致。")
        return TextureMetadata(path, json_path, "区域遮罩贴图", image_size, metadata)
    if version == RECT_INFO_ENCODING_VERSION:
        resolution = metadata.get("resolution")
        channels = metadata.get("channels")
        if not isinstance(resolution, list) or len(resolution) != 2:
            raise MetadataReadError("RegionRectInfo JSON 缺少有效的 resolution 字段。")
        if tuple(resolution) != image_size:
            raise MetadataReadError("RegionRectInfo EXR 尺寸与 JSON 的 resolution 不一致。")
        if not isinstance(channels, dict) or set(("R", "G", "B", "A")) - set(channels):
            raise MetadataReadError("RegionRectInfo JSON 缺少完整的 R/G/B/A 通道说明。")
        return TextureMetadata(path, json_path, "区域矩形参数贴图", image_size, metadata)
    if version == VOLUME_ENCODING_VERSION:
        required = ("width", "height", "depth", "tile_columns", "tile_rows", "cloud_type_id")
        if any(not isinstance(metadata.get(field), int) for field in required):
            raise MetadataReadError("3D 云图集 JSON 缺少有效的体素尺寸、图集布局或云类型字段。")
        expected = (metadata["width"] * metadata["tile_columns"], metadata["height"] * metadata["tile_rows"])
        if expected != image_size:
            raise MetadataReadError("3D 云图集 PNG 尺寸与 JSON 的 tile 行列/体素尺寸不一致。")
        if metadata["cloud_type_id"] not in CLOUD_TYPE_BY_ID:
            raise MetadataReadError("3D 云图集 JSON 中的云类型 ID 不受当前版本支持。")
        return TextureMetadata(path, json_path, "3D 云图集", image_size, metadata)
    if not version:
        raise MetadataReadError("JSON 缺少 encoding_version，无法识别贴图类型。")
    raise MetadataReadError(f"不支持的编码版本：{version}。请使用本应用当前版本导出的文件。")
```

```
"""将 3D RG 体素可靠导出为 PNG 切片图集、代表切片与 JSON。"""
from __future__ import annotations

import json
import os
from pathlib import Path
from typing import Callable

import numpy as np
from PIL import Image

from noise_cloud.core.volume_generator import VolumeResult
from noise_cloud.io.mask_exporter import ExportError

ProgressCallback = Callable[[int, str], None]


def _ue5_import_instructions(result: VolumeResult, atlas_path: Path) -> str:
    data = result.metadata
    return f"""# UE5 创建 Volume Texture

`{atlas_path.name}` 是 {data['width']}×{data['height']}×{data['depth']} 的切片图集源数据。PNG 图像格式只有二维像素，因此 UE5 首先将其识别为 **Texture2D**，这是正常现象，不是导出失败。

1. 在 UE 项目的 `DefaultEngine.ini` 的 `[Script/Engine.RendererSettings]` 中设置 `r.AllowVolumeTextureAssetCreation=1`，然后重启编辑器。
2. 将该 PNG 导入 Content Browser，关闭 **sRGB**，使用 **Masks** 或等效线性设置。
3. 在 Content Browser 中右键该 Texture2D，选择 **Create Volume Texture（创建体积纹理）**。新创建的资源才是 UE5 的 Volume Texture / Texture3D 资源。
4. 图集严格为 {data['tile_columns']} 列 × {data['tile_rows']} 行；从左到右依次对应 Z=0 到 Z={data['depth'] - 1}，没有黑色补齐 tile。详细布局见 `{atlas_path.with_suffix('.json').name}`。
5. 在 Volume Domain 材质用 `Texture Sample Parameter Volume` 采样：R 为密度，G 为流动扰动。

本说明对应 Unreal Engine 官方的“先从 Texture2D 创建 Volume Texture”工作流。
"""


def volume_base_filename(result: VolumeResult) -> str:
    metadata = result.metadata
    style_suffix = "_Cartoon" if metadata.get("style") == "cartoon" else ""
    return f"{metadata['cloud_type_id']:02d}_{metadata['cloud_type_name']}{style_suffix}_{metadata['width']}x{metadata['height']}x{metadata['depth']}_seed{metadata['seed']}"


def _atlas_rgba(result: VolumeResult) -> np.ndarray:
    depth, height, width = result.density.shape
    cols, rows = result.metadata["tile_columns"], result.metadata["tile_rows"]
    atlas = np.zeros((rows * height, cols * width, 4), dtype=np.uint8)
    atlas[:, :, 3] = 255
    for z_index in range(depth):
        row, column = divmod(z_index, cols)
        y0, x0 = row * height, column * width
        atlas[y0:y0 + height, x0:x0 + width, 0] = result.density[z_index]
        atlas[y0:y0 + height, x0:x0 + width, 1] = result.disturbance[z_index]
    return atlas


def save_volume_bundle(result: VolumeResult, atlas_path: str | Path, progress: ProgressCallback | None = None) -> tuple[Path, Path, list[Path]]:
    """原子写入必需图集和 JSON，并输出 6 张代表性 Z 切片。"""
    path = Path(atlas_path)
    if path.suffix.lower() != ".png": path = path.with_suffix(".png")
    try:
        path.parent.mkdir(parents=True, exist_ok=True)
    except OSError as exc:
        raise ExportError(f"无法创建保存目录：{path.parent}。请检查路径是否有效且具有写入权限。") from exc
    json_path = path.with_suffix(".json")
    guide_path = path.with_name(f"{path.stem}_UE5创建VolumeTexture说明.md")
    temp_png, temp_json = path.with_suffix(".png.tmp"), path.with_suffix(".json.tmp")
    written_slices: list[Path] = []
    try:
        if progress: progress(4, "正在组装 RGBA 切片图集…")
        atlas = _atlas_rgba(result)
        if progress: progress(28, "正在以线性 RGBA 写入图集 PNG…")
        Image.fromarray(atlas, mode="RGBA").save(temp_png, format="PNG", compress_level=6)
        if progress: progress(68, "正在导出 6 张代表性 Z 切片…")
        selected_z = sorted(set(int(round(index)) for index in np.linspace(0, result.density.shape[0] - 1, 6)))
        for order, z_index in enumerate(selected_z):
            slice_rgba = np.zeros((*result.density[z_index].shape, 4), dtype=np.uint8)
            slice_rgba[:, :, 0] = result.density[z_index]
            slice_rgba[:, :, 1] = result.disturbance[z_index]
            slice_rgba[:, :, 3] = 255
            slice_path = path.with_name(f"{path.stem}_slice_z{z_index:03d}.png")
            Image.fromarray(slice_rgba, mode="RGBA").save(slice_path, format="PNG", compress_level=6)
            written_slices.append(slice_path)
            if progress: progress(68 + round(22 * (order + 1) / len(selected_z)), f"已导出 Z={z_index} 检查切片。")
        temp_json.write_text(json.dumps(result.metadata, ensure_ascii=False, indent=2), encoding="utf-8")
        os.replace(temp_png, path); os.replace(temp_json, json_path)
        guide_path.write_text(_ue5_import_instructions(result, path), encoding="utf-8")
    except OSError as exc:
        raise ExportError(f"无法写入 3D 云图集：{path.name}。请检查保存位置是否可写、文件是否被占用。") from exc
    finally:
        temp_png.unlink(missing_ok=True); temp_json.unlink(missing_ok=True)
    if progress: progress(100, "图集、JSON 元数据与检查切片已保存。")
    return path, json_path, written_slices
```

```
from __future__ import annotations

from pathlib import Path

from PySide6.QtWidgets import QFileDialog, QWidget


def choose_png_save_path(parent: QWidget, title: str, default_path: str) -> str:

    dialog.setOption(QFileDialog.Option.DontUseNativeDialog, True)
    dialog.setAcceptMode(QFileDialog.AcceptMode.AcceptSave)
    dialog.setFileMode(QFileDialog.FileMode.AnyFile)

    if path.parent.is_dir():
```

```
class PreviewLabel(QLabel):
    """保持原始预览数据并将鼠标点映射回导出像素。"""
    pixel_clicked = Signal(int, int)

    def __init__(self, title: str) -> None:
        super().__init__(title)
        self.setAlignment(Qt.AlignmentFlag.AlignCenter)
        self.setMinimumSize(250, 190)
        self.setFrameShape(QFrame.Shape.StyledPanel)
        self.setStyleSheet("background: #20242b; color: #cfd6df;")
        self._source: QPixmap | None = None

        data = np.ascontiguousarray(rgb)
        image = QImage(data.data, data.shape[1], data.shape[0], data.strides[0], QImage.Format.Format_RGB888).copy()
        self._source = QPixmap.fromImage(image)
        self._shape = data.shape[:2]
        self._refresh()

    def _refresh(self) -> None:
        if self._source:
            self.setPixmap(self._source.scaled(self.size(), Qt.AspectRatioMode.KeepAspectRatio, Qt.TransformationMode.FastTransformation))

    def resizeEvent(self, event) -> None:  # type: ignore[no-untyped-def]
        super().resizeEvent(event)
        self._refresh()

    def mousePressEvent(self, event) -> None:  # type: ignore[no-untyped-def]
        if not self._source or not self._shape:
            return
        source_h, source_w = self._shape
        scale = min(self.width() / source_w, self.height() / source_h)
        draw_w, draw_h = source_w * scale, source_h * scale
        x0, y0 = (self.width() - draw_w) / 2, (self.height() - draw_h) / 2
        x, y = event.position().x(), event.position().y()
        if x0 <= x < x0 + draw_w and y0 <= y < y0 + draw_h:
            self.pixel_clicked.emit(min(source_w - 1, int((x - x0) / scale)), min(source_h - 1, int((y - y0) / scale)))
```

```
"""将纯核心操作置于后台线程，确保界面不冻结。"""
from __future__ import annotations

import threading
from pathlib import Path

from PySide6.QtCore import QThread, Signal

from noise_cloud.core.mask_generator import GenerationCancelled, MaskParameters, generate_region_mask
from noise_cloud.io.mask_exporter import save_mask_bundle
from noise_cloud.core.volume_generator import VolumeGenerationCancelled, VolumeParameters, generate_volume_cloud
from noise_cloud.io.volume_exporter import save_volume_bundle


class GenerationThread(QThread):
    progress = Signal(int, str)
    completed = Signal(object)
    cancelled = Signal()
    failed = Signal(str)

    def __init__(self, parameters: MaskParameters) -> None:
        super().__init__()
        self.parameters = parameters
        self._cancel_requested = threading.Event()

    def request_cancel(self) -> None:
        self._cancel_requested.set()

    def run(self) -> None:
        try:
            result = generate_region_mask(
                self.parameters,
                progress=lambda value, text: self.progress.emit(value, text),
                cancel=self._cancel_requested.is_set,
            )
            self.completed.emit(result)
        except GenerationCancelled:
            self.cancelled.emit()
        except Exception as exc:  # 呈现给用户，而非让 Qt 事件循环吞掉异常。
            self.failed.emit(str(exc) or "生成区域遮罩时发生未知错误。")


class SaveThread(QThread):
    progress = Signal(int, str)
    completed = Signal(str, str)
    failed = Signal(str)

    def __init__(self, result: object, destination: Path) -> None:
        super().__init__()
        self.result = result
        self.destination = destination

    def run(self) -> None:
        try:
            png_path, json_path = save_mask_bundle(
                self.result, self.destination, progress=lambda value, text: self.progress.emit(value, text)
            )
            self.completed.emit(str(png_path), str(json_path))
        except Exception as exc:
            self.failed.emit(str(exc) or "保存区域遮罩时发生未知错误。")


class VolumeGenerationThread(QThread):
    progress = Signal(int, str)
    completed = Signal(object)
    cancelled = Signal()
    failed = Signal(str)

    def __init__(self, parameters: VolumeParameters) -> None:
        super().__init__()
        self.parameters = parameters
        self._cancel_requested = threading.Event()

    def request_cancel(self) -> None:
        self._cancel_requested.set()

    def run(self) -> None:
        try:
            result = generate_volume_cloud(self.parameters, lambda value, text: self.progress.emit(value, text), self._cancel_requested.is_set)
            self.completed.emit(result)
        except VolumeGenerationCancelled:
            self.cancelled.emit()
        except Exception as exc:
            self.failed.emit(str(exc) or "生成 3D 云贴图时发生未知错误。")


class VolumeSaveThread(QThread):
    progress = Signal(int, str)
    completed = Signal(str, str, int)
    failed = Signal(str)

    def __init__(self, result: object, destination: Path) -> None:
        super().__init__()
        self.result = result
        self.destination = destination

    def run(self) -> None:
        try:
            png_path, json_path, slices = save_volume_bundle(self.result, self.destination, lambda value, text: self.progress.emit(value, text))
            self.completed.emit(str(png_path), str(json_path), len(slices))
        except Exception as exc:
            self.failed.emit(str(exc) or "保存 3D 云贴图时发生未知错误。")
```
