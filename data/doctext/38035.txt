Implements a frustum-aligned volumetric fog grid (froxels) in the Caustica path tracer, lit entirely by path tracing rather than a shadow map.
What it does
froxel.rgen (world raygen idx 2): each frustum voxel reconstructs its world position, computes height-falloff density, and casts the same visibility() NEE shadow ray the surfaces use, accumulating real per-channel Beer–Lambert transmittance through tinted glass/ice/water/entity dielectrics — so a magenta pane scatters magenta fog. In-scatter = σₛ · HG(phase) · illuminance · toLight plus an isotropic sky-ambient fill; stores float4(inscatter, density).
froxel.comp: per-pixel screen raymarch over the grid with analytic segment Beer–Lambert integration, stopped at the reversed-Z surface depth, composited as scene·T + fog·preExposure (same exposure seam as the path tracer).
Java: RtFroxel compute pipeline, RtContext.createStorageImage3D, RtPipeline WORLD_FROXEL binding + traceVolume 3D dispatch, RtComposite frame-graph wiring (light pass → barrier → raymarch → barrier before DLSS-RR), WorldPush froxel0/1/2, nearPlaneDistance().
Config: CausticaConfig.Rt.Fog — enabled/density/strength/phase-g/ambient/far/height-falloff, live-tunable via -Dcaustica.* or TOML.
Constraints honored
No shadow map — the grid's light is path-traced via the existing NEE ray, inheriting real color transmission through glass.
Reuses the pathtracer's ACEScg basis, dominantCelestialLight, and preExposure seam.
CI
Relies on the GitHub Actions gradlew build to compile the new Slang shaders and verify generated WorldPushData/RtBindings. Default fog density/falloff are plausible starting values pending runtime tuning.

Froxel: light fog from the real sky dome, not a flat uniform ambient
…
81a13a0
```
The volumetric fog read as a flat, featureless shell at a fixed distance
from the camera with no visible scattering. Root cause: the ambient term was
a huge isotropic constant (ambientFactor * luminance(illuminance) * tint),
uniform across every cell and independent of shadowing, which washed out the
directional sun scattering and flattened the volume.

Light each froxel with the actual sky radiance in the view direction by
sampling the frame's sky-view LUT (skyDome, moved into sky.slang and shared
with sky.rmiss). The fog now mirrors the real dome: it picks up the sun's Mie
glow toward the light, follows the day/night cycle, and varies with view
direction. The path-traced sun-shaft term is kept on top, and the old ambient
becomes a tiny isotropic night/ground floor so moonless shadows never clip.

skyDome takes the skyViewLut sampler as a parameter so sky.slang stays
decoupled from the world bindings.

Froxel: make the fog clearly visible with stronger default density
…
2516999
```
With DENSITY=0.0008/block the fog was ~99.6% transparent at a few blocks,
so it only ever appeared as a faint, distant band that followed the camera
and showed no visible scattering up close. Raise the default density to
0.005 and shorten FAR to 300: ~20% fog over 50 blocks and ~80% at the far
plane, so the sunlit volume (and its sky-dome glow + shadowed shafts) is
clearly visible in the near/mid field instead of only at the horizon. All
values remain live-tunable via -Dcaustica.rt.fogDensity / fog.far.
