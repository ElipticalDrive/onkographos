# 3D Model X-Ray: Marching Cubes Isosurface Extraction

A C/C++ implementation of the **Marching Cubes algorithm** for extracting 3D isosurfaces from volumetric data (e.g., CT scans, MRI data). This program converts 3D voxel data into VRML 1.0 mesh format for visualization.

## Overview

The Marching Cubes algorithm is a computer graphics technique for creating triangle meshes from 3D scalar fields (volumetric data). It processes each cubic cell (voxel) in a 3D grid and generates triangles at the surface where the data crosses a specified threshold value.

### Key Features

- Extracts isosurfaces from 3D volumetric datasets
- Outputs VRML 1.0 format for 3D visualization
- Reduces 256 cube configurations to 23 base cases using symmetry
- Includes demo skull dataset

## Usage

### Command Line Arguments

```
testmarch [input_file] [output_file] [threshold]
```

- **input_file**: Path to input volumetric data file (text format)
- **output_file**: Path to output VRML file
- **threshold**: Isosurface threshold value (float)

If no arguments are provided, defaults to:
- Input: `skull.txt`
- Output: `skull.wrl`
- Threshold: `70.0`

### Input File Format

The input file must be a text file with the following format:

```
<x_size> <y_size> <z_size>
<data_value_1>
<data_value_2>
...
<data_value_n>
```

- First line: three integers representing grid dimensions
- Following lines: integer values (0-255) representing density at each voxel
- Total data points: `x_size * y_size * z_size`

### Output Format

The output is a **VRML 1.0** file that can be viewed with:
- VRML viewers (e.g., view3dscene, FreeWRL)
- Legacy browsers with Cosmoplayer plugin
- Modern 3D software that supports VRML import

## Algorithm Overview

### Marching Cubes Steps

1. **Grid Traversal**: Iterate through each cube (8 vertices) in the 3D grid
2. **Configuration**: Determine which vertices are above/below the threshold (8 bits = 256 cases)
3. **Symmetry Reduction**: Use rotations to map 256 cases to 23 base cases
4. **Triangle Generation**: Create triangles at cube edges that cross the threshold
5. **Vertex Interpolation**: Calculate precise intersection points using linear interpolation
6. **Mesh Assembly**: Combine all triangles into a single mesh surface

### Configuration System

- Each cube has 8 corners (vertices)
- Each corner is either above (1) or below (0) the threshold
- This creates 2^8 = 256 possible configurations
- Using 24 rotations, these reduce to 23 unique base cases
- Dramatically reduces complexity and lookup table size

## Technical Details

### Memory Management
- Dynamic allocation for 3D data arrays
- Linked lists for triangle storage
- Manual memory management (C-style)

### Performance Considerations
- Algorithm complexity: O(n³) where n is grid dimension
- Memory usage: O(n³) for voxel storage + O(m) for triangles
- Optimizations: Configuration caching, edge point reuse

### Limitations
- Input data must be integers (0-255) in current version
- Uses legacy C++ features (may need updates for modern compilers)
- VRML 1.0 output (older format, but widely compatible)

## Troubleshooting

### Compilation Errors

**Error: `fstream.h: No such file or directory`**
- Solution: Use `-std=c++98` or update headers to modern C++ (`<fstream>`)

**Undefined reference to `sqrt`/`pow`**
- Solution: Add `-lm` flag (link math library)

**Windows: `ios::nocreate` not found**
- Solution: This is legacy C++, remove `ios::nocreate` or use older compiler

### Runtime Issues

**"Error opening file"**
- Ensure `skull.txt` is in the same directory as the executable
- Check file permissions

**Empty output file**
- Verify input file format matches specification
- Try different threshold values

#include "Configuration.h"

Configuration Configuration_Configuration8(MH_BOOL AC0, MH_BOOL AC1, MH_BOOL AC2, MH_BOOL AC3,
	MH_BOOL AC4, MH_BOOL AC5, MH_BOOL AC6, MH_BOOL AC7)
{
	Configuration tmp;
	Configuration_reset8(&tmp,AC0, AC1, AC2, AC3, AC4, AC5, AC6, AC7);
	return tmp;
}

Configuration Configuration_Configuration2(MH_BOOL AC[8])
{
	Configuration tmp;
	int i;
	for (i=0 ; i<8 ; i++)
		tmp.C[i] = AC[i];
	return tmp;
}

Configuration Configuration_Configuration1(int ByteConfig)
{
	Configuration tmp;
	Configuration_reset1(&tmp,ByteConfig);
	return tmp;
}

void Configuration_reset8(Configuration *This, MH_BOOL AC0, MH_BOOL AC1, MH_BOOL AC2, MH_BOOL AC3,
	MH_BOOL AC4, MH_BOOL AC5, MH_BOOL AC6, MH_BOOL AC7)
{
	This->C[0] = AC0; This->C[1] = AC1; This->C[2] = AC2; This->C[3] = AC3;
	This->C[4] = AC4; This->C[5] = AC5; This->C[6] = AC6; This->C[7] = AC7;
}

void Configuration_reset1(Configuration *This, int ByteConfig)
{
	int i;

	int mask [8];
	mask[0]=1;mask[1]=2;mask[2]=4;mask[3]=8;
	mask[4]=16;mask[5]=32;mask[6]=64;mask[7]=128;
	for (i=0; i<8 ; i++)
		This->C[i] = (ByteConfig & mask[i])!=0;
}

void Configuration_eq (Configuration *This, Configuration *AConfig)
{
	int i;
	for (i=0 ; i<8 ; i++)
		This->C[i] = AConfig->C[i];
}

int Configuration_IsSame(Configuration *This, Configuration *AConfig)
{
	return (
		This->C[0] == AConfig->C[0] && This->C[1] == AConfig->C[1] &&
		This->C[2] == AConfig->C[2] && This->C[3] == AConfig->C[3] &&
		This->C[4] == AConfig->C[4] && This->C[5] == AConfig->C[5] &&
		This->C[6] == AConfig->C[6] && This->C[7] == AConfig->C[7]
	);
}

void Configuration_Apply(Configuration *This, Rotation *ARotation)
{
	MH_BOOL tmp[8];
	int i;
	for (i=0 ; i<8 ; i++)
	{
		tmp[ARotation->r[i]] = This->C[i];
	}
	for (i=0 ; i<8 ; i++)
	{
		This->C[i] = tmp[i];
	}
}

int Configuration_ToInt(Configuration *This)
{
	int i;
	int tmp = 0;
	int BitValue = 1;
	for (i=0 ; i<8 ; i++)
	{
		if (This->C[i]) tmp+= BitValue;
		BitValue *= 2;
	}
	return tmp;
}

Point3D DataArray::ReverseInterpolate(int i1, int j1, int k1, int i2, int j2, int k2)
{
	float V1 = GetValue(i1,j1,k1);
	float V2 = GetValue(i2,j2,k2);
	double factor1 = fabs((MyT-V2)/(V2-V1));
	double factor2 = fabs((MyT-V1)/(V2-V1));
	Point3D P1;
	Point3D P2;
	P1 = GetCoord(i1, j1, k1);
	P2 = GetCoord(i2, j2, k2);
	Point3D tmp;
	tmp.x = (P1.x*factor1 + P2.x*factor2);
	tmp.y = (P1.y*factor1 + P2.y*factor2);
	tmp.z = (P1.z*factor1 + P2.z*factor2);
	//tmp = (P1*0.5 + P2*0.5);
	if (V1==V2 || factor1>1 || factor2>1)//temporary
	{
		int bobo = 3;
		bobo += 1;
		return P1;
	}
	return tmp;
}

int DataArray::GetXEdgePoint(int i, int j, int k)
{
	Point3D tmp;
	DataElt *ADataElt = &data[i+XDimention*j+YDimention*XDimention*k];
	if (ADataElt->XEdgePoint == -1) //this point has not been used yet
	{
		//add this point and give it a new index:
		ADataElt->XEdgePoint = NbPoints; //set the edge point index to new value
		NbPoints++;	//one more point in list
		tmp = ReverseInterpolate(i,j,k,i+1,j,k);
		VRMLobject_AddPoint(MyVRMLobject,&tmp); //add the right point
	}
	//else
	return ADataElt->XEdgePoint;
}

	//initialise the MapToBase array
	for (i=0 ; i<256 ; i++)
	//for each possible case
	{
		This->MapToBase[i].BaseCase = -1; //so that the case is -1 if not found
		Configuration_reset1(&CurrentConfig,i);	//set CurrentConfig to configuration #i
		found = 0;
		j=0;
		while (j<23 && !found)
		//for each possible base configuration
		{
			k=0;
			while (k<24 && !found)
			//for each possible rotation
			{
				RotatedBCase = This->BaseConfig[j];
				Configuration_Apply(&RotatedBCase,&(This->BaseRotat[k]));
				if (Configuration_IsSame(&RotatedBCase,&CurrentConfig))
				{
					This->MapToBase[i].Rot = k;
					This->MapToBase[i].BaseCase = j;
					found = 1;
				}
				k++;
			}
			j++;
		}
	}
