# 🌍 TerraForge

### Procedural Voxel Terrain System for Godot 4

**Smooth Marching Cubes terrain. Threaded chunk streaming. Caves. Mountains. Runtime digging. Biome-based textured materials.**

**TerraForge** is a technical prototype for generating smooth, destructible voxel terrain in **Godot 4**.

It uses **seed-based procedural generation**, **Marching Cubes**, chunk-based world streaming, multi-threaded terrain generation, procedural caves, mountains, paths, biome materials, runtime terrain editing, and textured terrain rendering.

Each world is generated from configurable seeds, allowing different terrain layouts, cave networks, biome distribution, mountain shapes, desert regions, sulfur fields, and path layouts to be reproduced or randomized.

## Technical Highlights

### Marching Cubes Terrain

Each chunk stores voxel density values and material IDs.
The mesh is generated from those density values using the **Marching Cubes** algorithm, producing smoother terrain than block-based voxel worlds.

```text
Density Field → Marching Cubes → Mesh Arrays → ArrayMesh → Collision
```

---

### Threaded Chunk Generation

Chunk data and mesh arrays can be generated on worker threads before being applied on the main thread.

This helps keep runtime generation smoother while chunks stream around the player or debug camera.

```text
Chunk Request
    ↓
Worker Thread Builds Density + Materials + Mesh Arrays
    ↓
Main Thread Applies Mesh + Collision
```

---

### Chunk Streaming

The world loads chunks around the active streaming center and unloads distant chunks.

The active streaming center can be:

* a player
* a debug free camera
* any node added to the `streaming_center` group

This allows the world to expand around the player without loading the entire world at once.

---

### Procedural Caves

Caves are generated using connected cave paths, tunnel carving, and cave room placement.

The cave system supports:

* long cave tunnels
* cave rooms
* underground networks
* cave entrances
* different underground materials

---

### Runtime Digging

Terrain can be modified at runtime using spherical edits.

When the player digs, the affected voxel densities are changed and the chunk mesh is rebuilt.

```text
Dig Position + Radius + Strength
    ↓
Modify Density Values
    ↓
Rebuild Chunk Mesh
    ↓
Update Collision
```

## Main Systems

### `voxel_world.gd`

Handles:

* world generation
* chunk loading/unloading
* threaded chunk building
* cave generation
* path generation
* biome/material selection
* terrain height sampling
* terrain edit history
* collision update queues

---

### `voxel_chunk.gd`

Handles:

* density storage
* material storage
* mesh application
* collision shape generation
* runtime sphere edits
* terrain material assignment

---

### `voxel_mesher.gd`

Handles:

* Marching Cubes mesh generation
* vertex creation
* triangle index creation
* material-to-vertex-color encoding
* smooth normal calculation

---

### `voxel_tables.gd`

Contains the Marching Cubes lookup data:

* corner offsets
* edge connections
* edge table
* triangle table

---

### `terrain_voxel.gdshader`

Decodes terrain material IDs from vertex colors and renders textured biome materials.

Supported material types include:

```text
Grass
Clay
Stone
Iron
Path
Sand
Sulfur
Volcanic Stone
```

## Why This Project Exists

I wanted to build a terrain system that could support survival, mining, exploration, and sandbox mechanics.

Instead of using blocky Minecraft-style terrain, this prototype uses **Marching Cubes** to create smoother terrain while still keeping the core voxel idea of editable density fields.

The result is a procedural terrain foundation with caves, mountains, biomes, chunk streaming, and runtime digging.

### Voxels/Shaders/terrain_voxel.gdshader
```
shader_type spatial;

render_mode cull_back, diffuse_lambert, specular_disabled;

uniform sampler2D grass_albedo : source_color, repeat_enable;
uniform sampler2D dirt_albedo : source_color, repeat_enable;
uniform sampler2D clay_albedo : source_color, repeat_enable;
uniform sampler2D sand_albedo : source_color, repeat_enable;
uniform sampler2D stone_albedo : source_color, repeat_enable;

uniform float texture_scale = 0.08;
uniform float terrain_brightness = 1.0;
uniform float texture_detail_strength = 0.65;
uniform float slope_darkening = 0.08;
uniform float large_variation_strength = 0.10;


float hash(vec2 p) {
	p = fract(p * vec2(123.34, 456.21));
	p += dot(p, p + 45.32);
	return fract(p.x * p.y);
}


float value_noise(vec2 p) {
	vec2 i = floor(p);
	vec2 f = fract(p);

	float a = hash(i);
	float b = hash(i + vec2(1.0, 0.0));
	float c = hash(i + vec2(0.0, 1.0));
	float d = hash(i + vec2(1.0, 1.0));

	vec2 u = f * f * (3.0 - 2.0 * f);

	return mix(a, b, u.x)
		+ (c - a) * u.y * (1.0 - u.x)
		+ (d - b) * u.x * u.y;
}


float fbm(vec2 p) {
	float value = 0.0;
	float amp = 0.5;

	for (int i = 0; i < 4; i++) {
		value += value_noise(p) * amp;
		p *= 2.0;
		amp *= 0.5;
	}

	return value;
}


float get_material_id_from_color(vec4 m) {
	// sulfur
	if (m.r > 0.95 && m.g > 0.95 && m.b < 0.10 && m.a > 0.95) {
		return 7.0;
	}

	// volcanic stone
	if (
		m.r > 0.35 && m.r < 0.65 &&
		m.g > 0.35 && m.g < 0.65 &&
		m.b > 0.35 && m.b < 0.65 &&
		m.a > 0.95
	) {
		return 8.0;
	}

	// sand
	if (m.r > 0.95 && m.g > 0.35 && m.g < 0.75 && m.b < 0.10 && m.a < 0.10) {
		return 6.0;
	}

	// path / dirt
	if (m.r > 0.95 && m.g > 0.95 && m.b < 0.10 && m.a < 0.10) {
		return 5.0;
	}

	float clay_weight = m.r;
	float grass_weight = m.g;
	float stone_weight = m.b;
	float iron_weight = m.a;

	if (clay_weight > grass_weight && clay_weight > stone_weight && clay_weight > iron_weight) {
		return 2.0;
	}

	if (stone_weight > grass_weight && stone_weight > iron_weight) {
		return 3.0;
	}

	if (iron_weight > grass_weight) {
		return 4.0;
	}

	return 1.0;
}


float tex_luma(sampler2D tex, vec2 uv) {
	vec3 t = texture(tex, uv).rgb;
	return dot(t, vec3(0.299, 0.587, 0.114));
}


vec3 apply_texture_detail(vec3 base_color, sampler2D tex, vec2 uv, float strength) {
	vec3 tex_color = texture(tex, uv).rgb;
	vec3 tinted_texture = tex_color * base_color * 2.0;

	return mix(base_color, tinted_texture, strength);
}


vec3 get_material_color(float id, vec2 uv, vec3 world_pos) {
	float broad = fbm(world_pos.xz * 0.025);
	float fine = fbm(world_pos.xz * 0.18);

	if (id < 1.5) {
		vec3 base = vec3(0.24, 0.48, 0.20);
		return apply_texture_detail(base, grass_albedo, uv, texture_detail_strength);
	}

	if (id < 2.5) {
		vec3 base = vec3(0.55, 0.32, 0.22);
		return apply_texture_detail(base, clay_albedo, uv, texture_detail_strength);
	}

	if (id < 3.5) {
		vec3 base = vec3(0.44, 0.45, 0.43);
		return apply_texture_detail(base, stone_albedo, uv, texture_detail_strength);
	}

	if (id < 4.5) {
		vec3 base = vec3(0.42, 0.28, 0.20);
		return apply_texture_detail(base, stone_albedo, uv, texture_detail_strength * 0.8);
	}

	if (id < 5.5) {
		vec3 base = vec3(0.34, 0.25, 0.16);
		return apply_texture_detail(base, dirt_albedo, uv, texture_detail_strength);
	}

	if (id < 6.5) {
		vec3 base = vec3(0.68, 0.58, 0.38);
		return apply_texture_detail(base, sand_albedo, uv, texture_detail_strength);
	}

	if (id < 7.5) {
		vec3 base = vec3(0.62, 0.56, 0.18);
		return apply_texture_detail(base, sand_albedo, uv, texture_detail_strength * 0.6);
	}

	vec3 base = vec3(0.22, 0.21, 0.19);
	return apply_texture_detail(base, stone_albedo, uv, texture_detail_strength);
}


void fragment() {
	vec3 world_pos = (INV_VIEW_MATRIX * vec4(VERTEX, 1.0)).xyz;
	vec3 world_normal = normalize((INV_VIEW_MATRIX * vec4(NORMAL, 0.0)).xyz);

	vec2 uv = world_pos.xz * texture_scale;

	float material_id = get_material_id_from_color(COLOR);

	vec3 color = get_material_color(material_id, uv, world_pos);

	float large_variation = fbm(world_pos.xz * 0.018);
	color *= 1.0 + (large_variation - 0.5) * large_variation_strength;

	float up_amount = clamp(world_normal.y, 0.0, 1.0);
	float steepness = 1.0 - up_amount;
	color *= 1.0 - steepness * slope_darkening;

	color *= terrain_brightness;

	ALBEDO = clamp(color, vec3(0.0), vec3(1.0));
	ROUGHNESS = 0.95;
}
```
