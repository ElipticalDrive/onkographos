Pull request overview
This PR adds a new Marching Tetrahedra (MT) surface-extraction path to the InVesalius mesh-generation pipeline, implemented in Rust and exposed through the invesalius_rs Python API and the GUI surface-method selector.
Changes:
Added a Rust Marching Tetrahedra extractor with edge memoization and a PyO3 binding returning (vertices, faces) arrays.
Exposed marching_tetrahedra in the Python wrapper + type stubs, and registered it in the Rust extension module.
Integrated MT into the surface-generation pipeline (VTK conversion + world-space transform) and added GUI options for “Marching Cubes” vs “Marching Tetrahedra”.
