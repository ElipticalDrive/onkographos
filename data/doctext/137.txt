More... __hostdev__ int nextAxis () const Detailed Description template<typename RayT, typename CoordT = Coord, int Dim = 1> class nanovdb::DDA< RayT, CoordT, Dim > A Digital Differential Analyzer. Unlike HDDA (defined above) this DDA uses a fixed step-size defined by the template parameter Dim! Note The Ray template class is expected to have the following methods: test(time), t0(), t1(), invDir(), and operator()(time). See the example Ray class above for their definition.
