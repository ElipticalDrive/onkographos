# VolumeSegmenter

An end-to-end proof of concept for filtering large RAW volumes into compact, spatially mapped bricks, organizing them into selectable logical groups, and rendering them in WebGL2.

## Results first

The pipeline substantially reduced stored and GPU-resident voxel data in all five measured datasets. Rendering speed did not consistently improve: the grouped representation was slightly faster for Bonsai, but slower for Foot, Engine, and Kingsnake because sparse lookup and ray-marching overhead can outweigh memory savings.

Measurements were collected on an Apple M4 with 16 GiB unified memory at 640 × 480, sample step 1, and three fixed camera views. Each view used five warmups and 20 asynchronous GPU timer queries. The table reports the median of the three per-view medians. Source and grouped modes ran sequentially with the same transfer function and display cutoff.

| Dataset | Source MiB | Grouped files MiB | Storage reduction | Grouped GPU MiB | Source / grouped GPU ms | Image check |
| --- | ---: | ---: | ---: | ---: | --- | --- |
| Bonsai | 16.00 | 2.65 | 83.5% | 2.73 | 3.41 / 3.23 | 3/3 exact |
| Foot | 16.00 | 4.08 | 74.5% | 4.14 | 3.55 / 3.99 | 3/3 exact |
| Engine | 8.00 | 1.72 | 78.5% | 1.80 | 1.96 / 4.01 | 3/3 exact |
| Kingsnake | 795.00 | 360.39 | 54.7% | 362.06 | 8.47 / 9.65 | 3/3 exact |
| Woodbranch | 16,384.00 | 719.48 | 95.6% | 745.94 | skipped / 11.78 | MIP only |

The exact image checks compare the source and grouped renderers after applying the same extraction cutoff. They prove that grouping, compact encoding, coordinate reconstruction, and rendering preserve every retained voxel for those views and settings. They do not prove that thresholded-out voxels were semantically unimportant.

Woodbranch demonstrates the main use case: its 16 GiB source volume exceeded the experiment's 1 GiB monolithic allocation budget, while the grouped representation rendered with about 746 MiB of GPU texture data. The source allocation was skipped before execution, so this row is not a measured out-of-memory failure and has no source GPU time.

## What the pipeline does

```mermaid
flowchart TD
    A[RAW + dimensions + type + spacing] --> B[Chunked input]
    B --> C[Explicit intensity cutoff]
    C --> D[Compact bricks + source coordinates]
    D --> E[Median-intensity bands + 6-neighbor components]
    E --> F[Selectable logical groups]
    F --> G[Dense crop or occupancy-mask encoding]
    G --> H[Values + masks + indices + metadata]
    H --> I[Independent decode verification]
    I --> J[Upload selected groups and release old textures]
    J --> K[WebGL2 rendering + reference comparison + GPU timing]
```

1. **Read:** RAW slices or OME-Zarr chunks are processed in batches so the full input and a full label volume do not have to coexist in memory.
2. **Filter:** The large-volume path applies an explicit intensity cutoff. This is the only lossy step.
3. **Partition:** Each nonempty brick stores only its local range plus its coordinates in the source volume. Bricks are never expanded back to the full width, height, and depth.
4. **Group:** Bricks are assigned to median-intensity bands and joined through six-neighbor adjacency. The nine largest components stay separate; smaller components are explicitly pooled by band. Every brick belongs to exactly one group.
5. **Encode:** The exporter chooses the smaller of a dense crop and an occupancy-mask representation. Masks omit interior empty positions without quantizing or deleting additional retained voxels.
6. **Verify:** Independent readers check hashes, coordinates, ownership, values, histograms, and three maximum-intensity projections.
7. **Render:** Logical parent AABBs reference their member bricks. Selecting groups rebuilds resident textures and releases the previous selection. Demand paging, a cache, and level of detail are not implemented yet.

Logical groups are spatial/intensity candidates, not validated tissue classes. Brick-graph connectivity also does not guarantee voxel-level connectivity. The original Skull experiment uses a separate SLIC-candidate path and remains as an algorithm baseline.

## Process your own RAW volume

The workflow processes files offline and then loads the results in the browser. It does not upload RAW data through the web page. Determine the following values first because RAW files do not carry them:

| Parameter | Requirement |
| --- | --- |
| Width, height, depth | Exact voxel dimensions |
| Data type | `uint8` or little-endian `uint16` (`<u2`) |
| Layout | X changes fastest, then Y, then Z |
| Spacing | Physical X/Y/Z voxel spacing; use 1 only when proportions are unknown |
| Byte size | Must equal width × height × depth × bytes per voxel |

Example for a 256³ `uint8` volume:

```bash
source .venv/bin/activate

python - <<'PY'
from pipeline.large_volume import RawSource, export
from pipeline.group_large_volume import group_volume

source = RawSource(
    path="data/my_volume.raw",
    shape=(256, 256, 256),       # D, H, W
    dtype="uint8",              # Use "<u2" for little-endian uint16.
    spacing=(1, 1, 1),          # Z, Y, X
    name="my_volume",
)

export(
    source,
    output="experiments/large-volumes/my_volume32",
    cutoff=32,                   # Retain source values > 32.
    save_original=True,          # Saves a full reference and uses more disk space.
)

group_volume(
    directory="experiments/large-volumes/my_volume32",
    output="experiments/large-volumes/my_volume-groups",
    edges=[96, 160],             # Tune median-intensity bands for the dataset.
)
PY

python -m pipeline.verify_large_volume experiments/large-volumes/my_volume32
python -m pipeline.verify_large_groups \
  experiments/large-volumes/my_volume-groups \
  experiments/large-volumes/my_volume32
```

Cutoffs and intensity-band edges are dataset-specific exploratory parameters. Edges must be strictly increasing, unique, greater than the cutoff, and no greater than the data maximum. Use a new empty output directory for every export because the programs do not overwrite existing results.

After starting the server, open:

```text
http://127.0.0.1:8765/web/large_volume.html?manifest=../experiments/large-volumes/my_volume-groups/metadata.json
```

The standalone viewer switches between the source and grouped representations, changes color presets, rotates the camera, and measures three fixed views. Custom datasets are not added automatically to the comparison-page menu. URL parameters such as `manifest`, `input`, and `base` resolve relative to the `web/` directory.

```
"""Five controlled extraction experiments; timings exclude reconstruction/metrics."""
import argparse
import json
import platform
import sys
from pathlib import Path
import numpy as np
import sklearn
from pipeline.extractVolume import extract, read_volume, reconstruct


def run(input_path, shape, output):
    output = Path(output)
    original = read_volume(input_path, shape)
    rows = []
    cutoff = None
    for name, mode, factor in [('original', 'original', 1), ('crop', 'crop', 1),
                                ('partition', 'partition', 1), ('lossy', 'partition', 2),
                                ('decimated', 'crop', 2)]:
        meta = extract(input_path, output / name, shape, mode=mode, downsample=factor, threshold=cutoff)
        if name == 'crop':
            cutoff = meta['parameters']['threshold']
        restored, coverage = reconstruct(output / name)
        reference = original if mode == 'original' else np.where(original > cutoff, original, 0)
        delta = restored.astype(np.float32) - reference.astype(np.float32)
        rows.append(dict(experiment=name, **{k: meta[k] for k in ['output_bytes', 'processing_seconds', 'retained_nonzero']},
                         component_count=len(meta['components']),
                         bounding_boxes_disjoint=all(
                             any(a['origin_xyz'][axis] + a['extent_xyz'][axis] <= b['origin_xyz'][axis]
                                 or b['origin_xyz'][axis] + b['extent_xyz'][axis] <= a['origin_xyz'][axis]
                                 for axis in range(3))
                             for i, a in enumerate(meta['components']) for b in meta['components'][i + 1:]),
                         reduction_percent=100 * (1 - meta['output_bytes'] / original.nbytes),
                         threshold=meta['parameters']['threshold'],
                         mae_vs_retained=float(np.abs(delta).mean()),
                         mae_vs_original=float(np.abs(restored.astype(np.float32) - original).mean()),
                         retained_voxels_missing=int(np.count_nonzero((reference > 0) & (restored == 0))),
                         introduced_nonzero_voxels=int(np.count_nonzero((reference == 0) & (restored > 0))),
                         overlapping_nonzero_voxels=int(np.count_nonzero(coverage > 1))))
    report = dict(input_file=Path(input_path).name, input_sha256=meta['input_sha256'], dimensions_xyz=shape,
                  original_bytes=original.nbytes, environment=dict(python=sys.version, platform=platform.platform(),
                  numpy=np.__version__, scikit_learn=sklearn.__version__),
                  methodology='Single run per variant, sequential. Processing includes file IO, hashing and extraction; excludes reconstruction and metrics. MiB = 1048576 bytes. Not network compression. No peak RAM claim.', results=rows)
    (output / 'report.json').write_text(json.dumps(report, indent=2) + '\n')
    print(json.dumps(report, indent=2))


if __name__ == '__main__':
    p = argparse.ArgumentParser(description=__doc__)
    p.add_argument('--input', default='data/skull_256x256x256_uint8.raw')
    p.add_argument('--shape', type=int, nargs=3, default=[256, 256, 256])
    p.add_argument('--output', default='experiments/spatial')
    args = p.parse_args()
    run(args.input, args.shape, args.output)
```

### pipeline/extractVolume.py
```
"""Reproducible uint8 volume extraction. Arrays are ZYX; metadata is XYZ.

The default is tightly cropped, disjoint spatial partitioning, not anatomical segmentation. Every
retained voxel is assigned once before optional, explicitly lossy decimation.
"""
import argparse
import hashlib
import json
import time
from pathlib import Path

import numpy as np
from scipy import ndimage as ndi
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler
from threadpoolctl import threadpool_limits


def read_volume(path, shape_xyz):
    if len(shape_xyz) != 3 or any(int(n) != n or n <= 0 for n in shape_xyz):
        raise ValueError('Shape must contain three positive integers (X Y Z)')
    expected = int(np.prod(shape_xyz))
    if Path(path).stat().st_size != expected:
        raise ValueError(f'Expected exactly {expected} bytes for uint8 {shape_xyz}')
    return np.fromfile(path, dtype=np.uint8).reshape(tuple(reversed(shape_xyz)))


def background_threshold(volume, seed=42):
    """Fit two intensity populations on a bounded, seeded sample of nonzero data."""
    values = volume[volume > 0]
    if not values.size:
        return 0.0
    rng = np.random.default_rng(seed)
    sample = values[rng.choice(values.size, min(10000, values.size), replace=False)]
    if np.unique(sample).size < 2:
        return 0.0  # Keep constant-valued foreground, including tiny fixtures.
    model = KMeans(n_clusters=2, n_init=3, random_state=seed).fit(sample[:, None])
    return round(float(model.cluster_centers_.min()), 6)


def select_foreground(volume, threshold, cleanup='none', min_region_voxels=512):
    """Explicit intensity/size heuristics, not a semantic definition of importance.

    Connected filtering preserves all voxels of retained six-connected regions,
    including thin branches. Opening removes thin features. Legacy reproduces
    the original three-voxel border removal and background dilation for audit.
    """
    if cleanup not in ('none', 'connected', 'opening', 'legacy'):
        raise ValueError('Unknown cleanup method')
    if not isinstance(min_region_voxels, int) or min_region_voxels < 1:
        raise ValueError('Minimum region size must be a positive integer')
    mask = volume > threshold
    threshold_count = int(mask.sum())
    regions_before = regions_after = None
    if cleanup == 'legacy':
        margin = min(3, min(volume.shape) // 10)
        if margin:
            for axis in range(3):
                edge = [slice(None)] * 3
                edge[axis] = slice(0, margin)
                mask[tuple(edge)] = False
                edge[axis] = slice(-margin, None)
                mask[tuple(edge)] = False
        if min(volume.shape) > 10:
            mask = ndi.binary_erosion(mask, structure=np.ones((3, 3, 3)))
    elif cleanup in ('connected', 'opening'):
        if cleanup == 'opening':
            mask = ndi.binary_opening(mask, structure=np.ones((3, 3, 3)))
        labels, regions_before = ndi.label(mask)  # Six-neighbor connectivity.
        sizes = np.bincount(labels.ravel())
        keep = sizes >= min_region_voxels
        keep[0] = False
        mask = keep[labels]
        regions_after = int(keep.sum())
    metrics = dict(threshold_nonzero=threshold_count, retained_nonzero=int(mask.sum()),
                   cleanup_removed_voxels=threshold_count - int(mask.sum()),
                   regions_before=regions_before, regions_after=regions_after,
                   intensity_survival={})
    for level in (60, 120):
        reference = volume > level
        count = int(reference.sum())
        removed = int(np.count_nonzero(reference & ~mask))
        metrics['intensity_survival'][str(level)] = dict(original_voxels=count,
            removed_voxels=removed, retained_fraction=(count - removed) / count if count else None)
    return mask, metrics


def kmeans_partition(volume, components=8, seed=42, spatial_weight=0.5, batch_size=100000):
    """Fit on a bounded sample; predict ALL foreground voxels in bounded batches."""
    foreground = np.flatnonzero(volume)
    labels = np.zeros(volume.size, dtype=np.uint8)
    if not foreground.size:
        return labels.reshape(volume.shape)

    def features(indices):
        z, y, x = np.unravel_index(indices, volume.shape)
        return np.column_stack((x, y, z, volume.ravel()[indices])).astype(np.float32)

    rng = np.random.default_rng(seed)
    sample = rng.choice(foreground, min(30000, foreground.size), replace=False)
    scaler = StandardScaler().fit(features(sample))
    weights = np.array([spatial_weight] * 3 + [1 - spatial_weight], dtype=np.float32)
    train = scaler.transform(features(sample)) * weights
    count = min(components, len(np.unique(train, axis=0)))
    model = KMeans(n_clusters=count, n_init=3, random_state=seed, max_iter=100).fit(train)
    for start in range(0, foreground.size, batch_size):
        indices = foreground[start:start + batch_size]
        labels[indices] = model.predict(scaler.transform(features(indices)) * weights) + 1
    return labels.reshape(volume.shape)


def spatial_partition(volume, components=8):
    """Greedy axis-aligned splits with tight child crops; boxes never overlap.

    Try quarter/mid/three-quarter planes on each axis. Prefer the greatest
    reduction in stored bounding-box voxels, breaking ties by smaller largest
    child. This is a bounded heuristic, not a globally minimal partition.
    """
    def tight(lo, hi):
        block = volume[tuple(slice(a, b) for a, b in zip(lo, hi))]
        bounds = []
        for axis in range(3):
            occupied = np.flatnonzero(np.any(block, axis=tuple(i for i in range(3) if i != axis)))
            if not occupied.size:
                return None
            bounds.append((occupied[0], occupied[-1] + 1))
        return (lo + np.array([a for a, b in bounds]),
                lo + np.array([b for a, b in bounds]))

    def size(box):
        return int(np.prod(box[1] - box[0]))

    def surface(box):
        z, y, x = box[1] - box[0]
        return int(x * y + y * z + z * x)

    root = tight(np.zeros(3, dtype=int), np.array(volume.shape))
    if root is None:
        return np.zeros(volume.shape, dtype=np.uint8)
    leaves = [root]
    while len(leaves) < components:
        best = None
        for index, box in enumerate(leaves):
            lo, hi = box
            for axis in range(3):
                length = hi[axis] - lo[axis]
                for offset in sorted(set(int(length * f) for f in (0.25, 0.5, 0.75))):
                    if not 0 < offset < length:
                        continue
                    middle = lo[axis] + offset
                    left_hi, right_lo = hi.copy(), lo.copy()
                    left_hi[axis], right_lo[axis] = middle, middle
                    left, right = tight(lo, left_hi), tight(right_lo, hi)
                    if left is None or right is None:
                        continue
                    score = (size(box) - size(left) - size(right),
                             size(box) - max(size(left), size(right)),
                             -surface(left) - surface(right))
                    if best is None or score > best[0]:
                        best = (score, index, left, right)
        if best is None:
            break
        _, index, left, right = best
        leaves[index:index + 1] = [left, right]
    labels = np.zeros(volume.shape, dtype=np.uint8)
    for identifier, (lo, hi) in enumerate(leaves, 1):
        region = tuple(slice(a, b) for a, b in zip(lo, hi))
        labels[region] = np.where(volume[region] > 0, identifier, 0)
    return labels


@threadpool_limits.wrap(limits=1)
def extract(input_path, output_dir, shape_xyz, *, mode='partition', threshold=None,
            components=8, seed=42, spatial_weight=0.5, downsample=1, strategy="spatial",
            cleanup="none", min_region_voxels=512):
    if strategy not in ('spatial', 'kmeans'):
        raise ValueError('Unknown partition strategy')
    if mode == 'original' and cleanup != 'none':
        raise ValueError('Original mode does not accept foreground cleanup')
    if mode not in ('original', 'crop', 'partition'):
        raise ValueError('Unknown mode')
    if not 1 <= components <= 15 or not 0 <= spatial_weight <= 1 or downsample < 1 or int(downsample) != downsample:
        raise ValueError('Require 1–15 components, weight in [0,1], integer downsample >= 1')
    if threshold is not None and not 0 <= threshold <= 255:
        raise ValueError('Threshold must be in [0,255]')
    output = Path(output_dir)
    output.mkdir(parents=True, exist_ok=True)
    if list(output.glob('component_*.raw')) or (output / 'metadata.json').exists():
        raise ValueError(f'Output already contains results: {output}; choose a new directory')
    start = time.perf_counter()
    original = read_volume(input_path, shape_xyz)
    cutoff = 0.0 if mode == 'original' else (background_threshold(original, seed) if threshold is None else float(threshold))
    mask, foreground_metrics = select_foreground(original, cutoff, cleanup, min_region_voxels)
    retained = np.where(mask, original, 0).astype(np.uint8)
    if mode == 'partition':
        labels = (spatial_partition(retained, components) if strategy == 'spatial'
                  else kmeans_partition(retained, components, seed, spatial_weight))
    else:
        labels = (retained > 0).astype(np.uint8)
    ids = np.unique(labels[labels > 0]) if mode != 'original' else [1]
    records = []
    for identifier in ids:
        if mode == 'original':
            lo, hi = np.zeros(3, dtype=int), np.array(original.shape)
            data = original.copy()
        else:
            coords = np.where(labels == identifier)
            lo = np.array([c.min() for c in coords])
            hi = np.array([c.max() + 1 for c in coords])
            slices = tuple(slice(a, b) for a, b in zip(lo, hi))
            data = np.where(labels[slices] == identifier, retained[slices], 0).astype(np.uint8)
        data = data[::downsample, ::downsample, ::downsample].copy()
        filename = f'component_{int(identifier)}.raw'
        data.tofile(output / filename)
        records.append(dict(file=filename, dimensions_xyz=list(map(int, data.shape[::-1])),
                            origin_xyz=list(map(int, lo[::-1])), spacing_xyz=[downsample] * 3,
                            extent_xyz=list(map(int, (hi - lo)[::-1])), bytes=data.nbytes,
                            sha256=hashlib.sha256(data.tobytes()).hexdigest()))
    metadata = dict(schema_version=2, dtype='uint8', array_order='ZYX', coordinate_order='XYZ',
                    input_file=Path(input_path).name, input_sha256=hashlib.sha256(original.tobytes()).hexdigest(),
                    dimensions_xyz=list(shape_xyz), original_bytes=original.nbytes,
                    parameters=dict(mode=mode, threshold=cutoff, seed=seed, components=components,
                                    spatial_weight=spatial_weight, downsample=downsample, strategy=strategy,
                                    cleanup=cleanup, min_region_voxels=min_region_voxels),
                    foreground_metrics=foreground_metrics,
                    original_nonzero=int(np.count_nonzero(original)), retained_nonzero=int(np.count_nonzero(retained)),
                    components=records, output_bytes=sum(c['bytes'] for c in records),
                    processing_seconds=time.perf_counter() - start,
                    reconstruction='nearest block expansion, clipped to original component extent')
    (output / 'metadata.json').write_text(json.dumps(metadata, indent=2) + '\n')
    return metadata


def reconstruct(directory):
    """Reference reconstruction in original voxel coordinates; max merges lossy overlaps."""
    directory = Path(directory)
    meta = json.loads((directory / 'metadata.json').read_text())
    result = np.zeros(meta['dimensions_xyz'][::-1], dtype=np.uint8)
    coverage = np.zeros(result.shape, dtype=np.uint8)
    for comp in meta['components']:
        block = read_volume(directory / comp['file'], comp['dimensions_xyz'])
        for axis, spacing in enumerate(comp['spacing_xyz'][::-1]):
            block = np.repeat(block, spacing, axis=axis)
        extent = comp['extent_xyz'][::-1]
        block = block[tuple(slice(0, n) for n in extent)]
        origin = comp['origin_xyz'][::-1]
        target = tuple(slice(a, a + n) for a, n in zip(origin, extent))
        np.maximum(result[target], block, out=result[target])
        coverage[target] += block > 0
    return result, coverage

    parser.add_argument('--input', required=True)
    parser.add_argument('--output', required=True)
    parser.add_argument('--shape', type=int, nargs=3, required=True, metavar=('X', 'Y', 'Z'))
```

```
"""Group compact bricks by median-intensity bands and six-neighbor connectivity.

Bricks are owned exactly once. This is a bounded brick graph, not voxel SLIC.
Small disconnected regions are explicitly pooled by band for manageable UI.
"""
import argparse
import hashlib
import json
from pathlib import Path
import numpy as np

def group_volume(directory, output, edges, keep=9, masked=None):
    root=Path(directory).resolve();out=Path(output).resolve()
    if out.exists() and any(out.iterdir()):raise ValueError('Choose an empty directory')
    out.mkdir(parents=True,exist_ok=True)
    m=json.loads((root/'metadata.json').read_text());dtype=np.dtype(m['dtype'])
    if keep<1 or edges!=sorted(set(edges)) or any(e<=m['cutoff'] or e>m['value_max'] for e in edges):raise ValueError('Require sorted distinct in-range band edges and keep >=1')
    grid=tuple(m['grid_xyz'][::-1]);pages=np.fromfile(root/m['pages_file'],'<u4').reshape(-1,4)
    source=np.memmap(root/m['density_file'],dtype=dtype,mode='r') if m['density_bytes'] else np.array([],dtype=dtype)
    cells=np.flatnonzero(pages[:,0]);n=len(cells)
    bands=np.empty(n,np.int32);counts=np.empty(n,np.int64);sizes=np.empty(n,np.int64)
    medians=np.empty(n,np.float64)
    for i,cell in enumerate(cells):
        base,_,packed,_=map(int,pages[cell]);shape=[(packed>>s)&63 for s in (0,6,12)]
        a=source[base-1:base-1+int(np.prod(shape))];values=a[a>m['cutoff']]
        medians[i]=np.median(values);bands[i]=np.searchsorted(edges,medians[i],side='right')
        counts[i]=values.size;sizes[i]=a.size
    if masked is None:masked=bool((counts.sum()*dtype.itemsize+((sizes+31)//32).sum()*8)<m['density_bytes'])
    parent=np.arange(n);rank=np.zeros(n,np.uint8)
    def find(i):
        while parent[i]!=i:parent[i]=parent[parent[i]];i=parent[i]
        return i
    def union(a,b):
        a,b=find(a),find(b)
        if a==b:return
        if rank[a]<rank[b]:a,b=b,a
        parent[b]=a
        if rank[a]==rank[b]:rank[a]+=1
    lookup=np.full(len(pages),-1,np.int32);lookup[cells]=np.arange(n)
    zyx=np.column_stack(np.unravel_index(cells,grid))
    for axis,stride in enumerate((grid[1]*grid[2],grid[2],1)):
        valid=zyx[:,axis]>0
        for i in np.flatnonzero(valid):
            j=lookup[cells[i]-stride]
            if j>=0 and bands[i]==bands[j]:union(i,j)
    roots=np.array([find(i) for i in range(n)])
    components={}
    for i,r in enumerate(roots):components.setdefault(int(r),[]).append(i)
    ordered=sorted(components.values(),key=lambda v:int(counts[v].sum()),reverse=True)
    buckets=[(v,False) for v in ordered[:keep]]
    for band in range(len(edges)+1):
        v=[i for component in ordered[keep:] for i in component if bands[i]==band]
        if v:buckets.append((v,True))
    groups=[]
    for gid,(indices,residual) in enumerate(buckets,1):
        label=int(bands[indices[0]]);lo=m['cutoff']+1 if label==0 else edges[label-1]
        hi=m['value_max'] if label==len(edges) else edges[label]-1
        entries=[];offset=0;maskoffset=0;masks=[];h=hashlib.sha256();voxels=0
        lower=np.array(m['dimensions_xyz']);upper=np.zeros(3,int)
        with (out/f'group-{gid}.raw').open('wb') as f:
            for i in indices:
                cell=int(cells[i]);base,origin,shape,_=map(int,pages[cell]);a=source[base-1:base-1+sizes[i]]
                if masked:
                    valid=a>m['cutoff'];padded=np.zeros(((a.size+31)//32)*32,np.uint8);padded[:a.size]=valid
                    bits=np.packbits(padded.reshape(-1,32),axis=1,bitorder='little').copy().view('<u4').reshape(-1)
                    numbers=padded.reshape(-1,32).sum(axis=1,dtype=np.uint32)
                    prefix=np.r_[np.uint32(0),np.cumsum(numbers[:-1],dtype=np.uint32)]+offset
                    masks.append(np.column_stack((prefix,bits)).astype('<u4'))
                    entries.append([cell,maskoffset+1,origin,shape]);maskoffset+=len(bits)
                    a=a[valid]
                else:entries.append([cell,offset+1,origin,shape])
                raw=a.tobytes();f.write(raw);h.update(raw)
                offset+=a.size;voxels+=int(counts[i])
                xyz=zyx[i][::-1]*m['brick_xyz']+np.array([(origin>>s)&31 for s in (0,5,10)])
                size=np.array([(shape>>s)&63 for s in (0,6,12)])
                lower=np.minimum(lower,xyz);upper=np.maximum(upper,xyz+size)
        entry_bytes=np.array(entries,dtype='<u4').tobytes();(out/f'group-{gid}-index.raw').write_bytes(entry_bytes)
        maskbytes=b''.join(v.tobytes() for v in masks)
        if masked:(out/f'group-{gid}-mask.raw').write_bytes(maskbytes)
        groups.append(dict(mask_bytes=len(maskbytes),mask_file=f'group-{gid}-mask.raw',mask_sha256=hashlib.sha256(maskbytes).hexdigest(),id=gid,name=f'Median intensity {lo}–{hi} · '+('pooled residual components' if residual else f'connected component {gid}'),
            band=label,median_range=[lo,hi],bricks=len(indices),selected_voxels=voxels,
            components=len(set(roots[indices].tolist())),pooled=residual,
            density_bytes=offset*dtype.itemsize,index_bytes=len(entry_bytes),
            density_file=f'group-{gid}.raw',density_sha256=h.hexdigest(),
            index_file=f'group-{gid}-index.raw',index_sha256=hashlib.sha256(entry_bytes).hexdigest(),
            bounds_xyz=dict(lo=lower.tolist(),hi=upper.tolist())))
    assert sum(g['density_bytes'] for g in groups)==(m['selected_voxels']*dtype.itemsize if masked else m['density_bytes'])
    assert sum(g['selected_voxels'] for g in groups)==m['selected_voxels']
    m.update(storage_encoding='masked32' if masked else 'dense-crops',pre_mask_density_bytes=m['density_bytes'],density_bytes=sum(g['density_bytes'] for g in groups),mask_bytes=sum(g['mask_bytes'] for g in groups),groups=groups,group_edges=edges,group_components=len(components),
             grouping='Six-neighbor brick components with same selected-voxel median intensity band. Largest components separate; remainder explicitly pooled per band. Not anatomical labels or voxel SLIC.',
             group_ownership='disjoint bricks; each payload stored once',group_index_bytes=sum(g['index_bytes'] for g in groups),
             original_file=str((root/m['original_file']).resolve()) if m.get('original_file') else None)
    # URLs resolve from the grouped manifest, not the HTTP root.
    import os
    if m['original_file']:m['original_file']=os.path.relpath(Path.cwd()/m['original_file'],out)
    m['density_file']=os.path.relpath(root/'density.raw',out);m['pages_file']=os.path.relpath(root/'pages.raw',out)
    (out/'metadata.json').write_text(json.dumps(m,separators=(',',':'))+'\n')
    print(json.dumps({k:m[k] for k in ['name','bricks','density_bytes','group_components','group_index_bytes']}))
    for g in groups:print(g['name'],g['density_bytes']/2**20,g['components'])
    return m

if __name__=='__main__':
    p=argparse.ArgumentParser();p.add_argument('directory');p.add_argument('output');p.add_argument('--edges',type=int,nargs='+',required=True);p.add_argument('--keep',type=int,default=9)
```

```
"""Bounded-memory OME-Zarr v3 -> cropped bricks. Intensity baseline, NOT SLIC.

Supports the public Open SciVis bytes+zstd, unsharded ZYX uint8/uint16
arrays. Raw precision and full resolution are retained. Only values <= cutoff
are discarded. Files are streamed; no full volume or full label array exists.
"""
import argparse
from concurrent.futures import ThreadPoolExecutor
from contextlib import nullcontext
import hashlib
import itertools
import json
import resource
from pathlib import Path
import time
import urllib.request
import urllib.error

import numpy as np
import zstandard

BASE = 'https://ome-zarr-scivis.s3.us-east-1.amazonaws.com/v0.5/96x2'


def fetch(url):
    for attempt in range(4):
        try:
            with urllib.request.urlopen(url, timeout=60) as response:
                return response.read()
        except (OSError, urllib.error.URLError) as error:
            if isinstance(error, urllib.error.HTTPError) and error.code == 404: raise
            if attempt == 3:
                raise
            time.sleep(1 + attempt)


class Source:
    def __init__(self, name, scale=0):
        self.name, self.scale = name, scale
        # The public 96x2 Kingsnake mirror has stale chunk metadata (96^3 payloads
        # declared as 100x128x128). The alternative mirror also needs per-chunk
        # validation; use the original RAW for the full-resolution Kingsnake run.
        base = BASE.replace('/96x2','/64x2') if name == 'kingsnake' else BASE
        self.base = f'{base}/{name}.ome.zarr'
        self.root = json.loads(fetch(self.base+'/zarr.json'))
        self.path = f'scale{scale}/{name}'
        self.meta = self.root['consolidated_metadata']['metadata'][self.path]
        m = self.meta
        if m['data_type'] not in ('uint8', 'uint16') or [c['name'] for c in m['codecs']] != ['bytes', 'zstd']:
            raise ValueError('Only unsharded uint8/16 bytes+zstd sources are supported')
        if m['codecs'][0].get('configuration', {}).get('endian', 'little') != 'little':
            raise ValueError('Require little endian')
        self.dtype = np.dtype('u1' if m['data_type'] == 'uint8' else '<u2')
        self.shape = tuple(m['shape'])
        self.chunks = tuple(m['chunk_grid']['configuration']['chunk_shape'])
        transforms = self.root['attributes']['ome']['multiscales'][0]['datasets'][scale]['coordinateTransformations']
        self.spacing = next(t['scale'] for t in transforms if t['type'] == 'scale')
        self.grid = tuple((n+c-1)//c for n,c in zip(self.shape,self.chunks))

    def chunk(self, index):
        url = self.base+'/'+self.path+'/c/'+'/'.join(map(str,index))
        # Zarr specifies missing chunk keys as fill_value; only HTTP 404 qualifies.
        try:
            compressed = fetch(url)
            raw = zstandard.ZstdDecompressor().decompress(compressed, max_output_size=int(np.prod(self.chunks))*self.dtype.itemsize)
        except urllib.error.HTTPError as error:
            if error.code != 404: raise
            compressed = b''
            raw = np.full(self.chunks, self.meta['fill_value'], dtype=self.dtype).tobytes()
        if len(raw) != int(np.prod(self.chunks))*self.dtype.itemsize:
            raise ValueError('Invalid decompressed chunk size')
        array = np.frombuffer(raw, self.dtype).reshape(self.chunks)
        origin = tuple(i*c for i,c in zip(index,self.chunks))
        valid = tuple(slice(0,min(c,n-o)) for c,n,o in zip(self.chunks,self.shape,origin))
        return origin, array[valid], len(compressed), hashlib.sha256(raw).hexdigest()

    def blocks(self, workers=4):
        # Bound futures/results to one batch; executor.map can retain the whole dataset.
        indices = iter(itertools.product(*(range(n) for n in self.grid)))
        with ThreadPoolExecutor(max_workers=workers) as pool:
            while batch := list(itertools.islice(indices, workers)):
                yield from pool.map(self.chunk, batch)


class RawSource:
    """Sequential slab reads: no full input mmap or full-sized working arrays."""
    def __init__(self,path,shape,dtype,spacing,name):
        self.file=Path(path);self.name=name;self.scale=0;self.shape=tuple(shape);self.dtype=np.dtype(dtype)
        self.spacing=list(spacing);self.chunks=(16,self.shape[1],self.shape[2]);self.grid=((self.shape[0]+15)//16,1,1)
        if self.file.stat().st_size!=int(np.prod(shape))*self.dtype.itemsize:raise ValueError('RAW byte length mismatch')
        self.base='http://klacansky.com/open-scivis-datasets/'+name+'/'
        self.root=dict(raw_file=self.file.name,shape_zyx=shape,dtype=dtype,spacing_zyx=spacing,source_url=self.base)
    def blocks(self,workers=1):
        with self.file.open('rb') as f:
            for z in range(0,self.shape[0],16):
                shape=(min(16,self.shape[0]-z),*self.shape[1:]);raw=f.read(int(np.prod(shape))*self.dtype.itemsize)
                yield (z,0,0),np.frombuffer(raw,self.dtype).reshape(shape),0,hashlib.sha256(raw).hexdigest()


def crop_bricks(array, origin, brick, cutoff):
    """Disjoint, globally aligned rectangular cells; partial boundary cells valid."""
    if any(o % b for o,b in zip(origin,brick)):
        raise ValueError('Source chunk origins must align with brick grid')
    mask = array > cutoff
    padded_shape = tuple(((n+b-1)//b)*b for n,b in zip(array.shape,brick))
    padded = np.zeros(padded_shape, bool)
    padded[tuple(slice(0,n) for n in array.shape)] = mask
    nz,ny,nx = (n//b for n,b in zip(padded_shape,brick)); bz,by,bx = brick
    occupied = padded.reshape(nz,bz,ny,by,nx,bx).any(axis=(1,3,5))
    for iz,iy,ix in np.argwhere(occupied):
        local = (int(iz)*bz,int(iy)*by,int(ix)*bx)
        sl = tuple(slice(o,o+b) for o,b in zip(local,brick))
        submask = mask[sl]
        coords = np.where(submask)
        lo = tuple(int(c.min()) for c in coords); hi = tuple(int(c.max())+1 for c in coords)
        crop = tuple(slice(a,b) for a,b in zip(lo,hi))
        data = np.where(submask[crop],array[sl][crop],0).astype(array.dtype)
        cell = tuple((o+l)//b for o,l,b in zip(origin,local,brick))
        yield cell, lo, data, int(submask.sum())


def profile(source):
    hist = np.zeros(65536 if source.dtype.itemsize == 2 else 256, np.int64)
    for _,a,_,_ in source.blocks():
        hist += np.bincount(a.ravel(),minlength=len(hist))
    from skimage.filters import threshold_otsu
    threshold = int(threshold_otsu(hist=(hist,np.arange(len(hist)))))
    cdf = hist.cumsum()
    return dict(shape_zyx=source.shape,dtype=str(source.dtype),scale=source.scale,
                otsu=threshold, nonzero=int(hist[1:].sum()), voxels=int(hist.sum()),
                quantiles={str(p):int(np.searchsorted(cdf,cdf[-1]*p)) for p in [.5,.9,.95,.98,.99,.995]},
                histogram=hist.tolist())


def export(source, output, cutoff, brick=None, workers=4, save_original=False):
    start=time.perf_counter(); out=Path(output)
    if out.exists() and any(out.iterdir()):raise ValueError('Choose an empty export directory')
    out.mkdir(parents=True,exist_ok=True)
    # Largest divisor <=16: Kingsnake source chunks are 100×128×128.
    brick = tuple(brick or [max(b for b in range(4,17) if c%b==0) for c in source.chunks])
    if any(b>32 or b<1 for b in brick) or not 0<=cutoff<np.iinfo(source.dtype).max:
        raise ValueError('Invalid brick or cutoff')
    grid=tuple((n+b-1)//b for n,b in zip(source.shape,brick))
    pages=np.zeros((*grid,4),dtype='<u4')
    hist=np.zeros(1<<(8*source.dtype.itemsize),np.int64)
    offset=0; selected=0; bricks=0; compressed_bytes=0; full_brick_voxels=0
    payload_hash=hashlib.sha256(); input_chunks_hash=hashlib.sha256()
    bounds_lo=np.array(source.shape);bounds_hi=np.zeros(3,dtype=int)
    mips=[np.zeros(tuple(n for j,n in enumerate(source.shape) if j!=axis),source.dtype) for axis in range(3)]
    total=int(np.prod(source.grid))
    original=(out/'original.raw').open('wb') if save_original else None
    if original: original.truncate(int(np.prod(source.shape))*source.dtype.itemsize)
    with (original if original else nullcontext()), (out/'density.raw').open('wb') as target:
        for index,(origin,array,received,chunk_hash) in enumerate(source.blocks(workers)):
            if original:
                oz,oy,ox=origin; nz,ny,nx=array.shape; _,height,width=source.shape
                for z in range(nz):
                    for y in range(ny):
                        original.seek(((oz+z)*height*width+(oy+y)*width+ox)*source.dtype.itemsize)
                        original.write(array[z,y].tobytes())
            compressed_bytes+=received; input_chunks_hash.update(bytes.fromhex(chunk_hash))
            hist+=np.bincount(array.ravel(),minlength=len(hist))
            for axis in range(3):
                sl=tuple(slice(o,o+n) for j,(o,n) in enumerate(zip(origin,array.shape)) if j!=axis)
                np.maximum(mips[axis][sl],array.max(axis=axis),out=mips[axis][sl])
            for cell,lo,data,count in crop_bricks(array,origin,brick,cutoff):
                if offset+data.size>=2**32:raise ValueError('Packed element address exceeds uint32')
                # Packed metadata: base+1, local XYZ origin (5 bits/axis), XYZ size (6 bits/axis).
                xyz=lo[::-1]; dims=data.shape[::-1]
                pages[cell]=(offset+1,xyz[0]|xyz[1]<<5|xyz[2]<<10,dims[0]|dims[1]<<6|dims[2]<<12,0)
                raw=data.tobytes();target.write(raw);payload_hash.update(raw)
                p=np.array(cell)*brick+lo; bounds_lo=np.minimum(bounds_lo,p);bounds_hi=np.maximum(bounds_hi,p+data.shape)
                offset+=data.size;selected+=count;bricks+=1;full_brick_voxels+=int(np.prod(brick))
            if index%32==0 or index+1==total:
                print(json.dumps(dict(chunks=index+1,total=total,selected_voxels=selected,packed_MiB=round(offset*source.dtype.itemsize/2**20,2),seconds=round(time.perf_counter()-start,1))),flush=True)
    if original: original.close()
    for axis,mip in enumerate(mips):
        np.save(out/f'original-mip-{axis}.npy',mip)
        np.save(out/f'threshold-mip-{axis}.npy',np.where(mip>cutoff,mip,0).astype(source.dtype))
    pages.tofile(out/'pages.raw')
    meta=dict(schema_version=4,format='compact-cropped-bricks',name=source.name,source_url=source.base,
              source_scale=source.scale,original_file='original.raw' if save_original else None,dimensions_xyz=list(source.shape[::-1]),spacing_xyz=source.spacing[::-1],
              dtype=source.dtype.name,bytes_per_voxel=source.dtype.itemsize,brick_xyz=list(brick[::-1]),grid_xyz=list(grid[::-1]),
              cutoff=cutoff,value_max=int(np.flatnonzero(hist)[-1]),selected_voxels=selected,bricks=bricks,
```

### pipeline/supervolume.py
```
"""SLIC candidates -> constrained graph selection -> cropped sparse bricks.

XYZ externally, ZYX arrays; uint8 scalar values, not calibrated tissue classes.
The analysis cache is optional working data. Export contains selected data only.
"""
import argparse
from collections import deque
import hashlib
import json
from pathlib import Path
import time

import numpy as np
from skimage.segmentation import slic
from threadpoolctl import threadpool_limits
from pipeline.extractVolume import read_volume


def digest(data):
    return hashlib.sha256(data).hexdigest()


def fresh(path):
    p = Path(path)
    if p.exists() and any(p.iterdir()):
        raise ValueError(f'Choose an empty output directory: {p}')
    p.mkdir(parents=True, exist_ok=True)
    return p


def region_graph(volume, labels):
    """Exact uint8 histograms and face-adjacent contact/contrast statistics."""
    n = int(labels.max()) + 1
    hist = np.zeros((n, 256), dtype=np.int64)
    # Bound temporary indexing arrays instead of building an Nx256 one-hot array.
    for z in range(volume.shape[0]):
        key = labels[z].ravel().astype(np.int64) * 256 + volume[z].ravel()
        hist += np.bincount(key, minlength=n*256).reshape(n, 256)
    edges = {}
    for axis in range(3):
        a, b = [slice(None)]*3, [slice(None)]*3
        a[axis], b[axis] = slice(None, -1), slice(1, None)
        left, right = labels[tuple(a)], labels[tuple(b)]
        different = left != right
        lo, hi = np.minimum(left[different], right[different]), np.maximum(left[different], right[different])
        key = lo.astype(np.int64)*n + hi
        unique, inverse, counts = np.unique(key, return_inverse=True, return_counts=True)
        delta = np.abs(volume[tuple(a)][different].astype(np.int16)-volume[tuple(b)][different])
        sums = np.bincount(inverse, weights=delta, minlength=len(unique))
        for k, count, total in zip(unique, counts, sums):
            pair = (int(k//n), int(k % n))
            c, s = edges.get(pair, (0, 0.0))
            edges[pair] = (c+int(count), s+float(total))
    return hist, [dict(a=a, b=b, contacts=c, mean_boundary_delta=s/c)
                  for (a, b), (c, s) in sorted(edges.items())]


@threadpool_limits.wrap(limits=1)
def analyze(source, shape, output, region_size=16, compactness=0.08, spacing=(1, 1, 1)):
    if not isinstance(region_size, int) or region_size < 2 or not np.isfinite(compactness) or compactness <= 0:
        raise ValueError('Require region_size >=2 and finite compactness >0')
    if len(spacing) != 3 or any(not np.isfinite(x) or x <= 0 for x in spacing):
        raise ValueError('Spacing must contain three positive finite values')
    volume = read_volume(source, shape)
    out = fresh(output); start = time.perf_counter()
    labels = slic(volume.astype(np.float32)/255, n_segments=max(1, round(volume.size/region_size**3)),
                  compactness=compactness, sigma=0, spacing=spacing[::-1], channel_axis=None,
                  convert2lab=False, enforce_connectivity=True, min_size_factor=0.1,
                  max_size_factor=3, start_label=1).astype(np.uint32)
    hist, edges = region_graph(volume, labels)
    counts = hist.sum(axis=1)
    cdf = hist.cumsum(axis=1)
    regions = []
    for i in range(1, len(hist)):
        if not counts[i]:
            continue
        regions.append(dict(id=i, voxels=int(counts[i]), mean=float(hist[i]@np.arange(256)/counts[i]),
                            p10=int(np.searchsorted(cdf[i], counts[i]*.1)),
                            median=int(np.searchsorted(cdf[i], counts[i]*.5)),
                            p90=int(np.searchsorted(cdf[i], counts[i]*.9)),
                            histogram=hist[i].tolist()))
    labels.astype('<u4').tofile(out/'labels.u32')
    report = dict(schema_version=1, dimensions_xyz=list(shape), input_sha256=digest(volume.tobytes()),
                  parameters=dict(method='3D SLIC', region_size=region_size, compactness=compactness,
                                  spacing_xyz=list(spacing), smoothing=0, connectivity='face'),
                  regions=regions, edges=edges, processing_seconds=time.perf_counter()-start)
    (out/'analysis.json').write_text(json.dumps(report, separators=(',', ':'))+'\n')
    return report


def select_groups(volume, labels, analysis, config):
    """Fixed target distributions prevent transitive intensity drift.

    Seeded graph growth never enters an ineligible region. Histogram support and
    boundary contrast operate at region level; final range clipping is explicit.
    Groups own disjoint voxels: earlier config entries have priority on overlap.
    """
    groups = config.get('groups', [])
    if not 1 <= len(groups) <= 255:
        raise ValueError('Require 1–255 groups')
    regions = analysis['regions']; n = int(labels.max())+1
    h = np.zeros((n, 256), dtype=np.float64)
    for r in regions:
        h[r['id']] = r['histogram']
    counts = h.sum(axis=1)
    adjacency = [[] for _ in range(n)]
    for e in analysis['edges']:
        adjacency[e['a']].append((e['b'], e['mean_boundary_delta']))
        adjacency[e['b']].append((e['a'], e['mean_boundary_delta']))
    owner = np.zeros(volume.shape, dtype=np.uint8)
    summaries = []
    for gid, g in enumerate(groups, 1):
        low, high = g['intensity_range']
        fraction = g.get('min_fraction', .1)
        boundary = g.get('max_boundary_delta', 255)
        if not (0 <= low <= high <= 255 and int(low)==low and int(high)==high):
            raise ValueError('Intensity ranges must be integer inclusive bounds in [0,255]')
        if not 0 <= fraction <= 1 or not 0 <= boundary <= 255:
            raise ValueError('Invalid support fraction or boundary contrast')
        low, high = int(low), int(high)
        support = h[:, low:high+1].sum(axis=1)
        eligible = (counts > 0) & (support > 0) & (support >= fraction*counts)
        seeds = set(g.get('region_ids', []))
        for xyz in g.get('seeds_xyz', []):
            if len(xyz)!=3 or any(int(x)!=x or x<0 or x>=s for x, s in zip(xyz, volume.shape[::-1])):
                raise ValueError('Seed outside original XYZ volume')
            seeds.add(int(labels[tuple(int(v) for v in xyz[::-1])]))
        mode = g.get('mode', 'seeded')
        if mode not in ('seeded', 'all_candidates'):
            raise ValueError('mode must be seeded or all_candidates')
        if mode == 'seeded' and not seeds:
            raise ValueError('Seeded selection requires seeds_xyz or region_ids')
        if any(not isinstance(i, int) or i<=0 or i>=n or not eligible[i] for i in seeds):
            raise ValueError('Seed region fails the fixed target range/support rule')
        distance = g.get('max_seed_histogram_distance')
        if distance is not None:
            if not seeds or not 0 <= distance <= 1:
                raise ValueError('Histogram distance requires seeds and a value in [0,1]')
            # Total variation distance to the fixed pooled SEED histogram.
            reference = h[sorted(seeds)].sum(axis=0); reference /= reference.sum()
            distributions = h / np.maximum(counts[:, None], 1)
            eligible &= .5*np.abs(distributions-reference).sum(axis=1) <= distance
            eligible[list(seeds)] = True
        chosen = np.zeros(n, dtype=bool)
        if mode == 'all_candidates':
            chosen = eligible.copy()
        else:
            queue = deque(sorted(seeds)); chosen[list(seeds)] = True
            while queue:
                i = queue.popleft()
                for j, delta in adjacency[i]:
                    if eligible[j] and not chosen[j] and delta <= boundary:
                        chosen[j] = True; queue.append(j)
        mask = chosen[labels]
        if g.get('clip_to_range', True):
            mask &= (volume >= low) & (volume <= high)
        # Zero intensity is the sparse background; zero-valued semantic labels are not exported.
        mask &= volume > 0
        overlap = int(np.count_nonzero(mask & (owner > 0)))
        owner[mask & (owner == 0)] = gid
        summaries.append(dict(id=gid, name=g.get('name', f'Group {gid}'), rule=g,
                              eligible_regions=int(eligible.sum()), selected_region_ids=np.flatnonzero(chosen).tolist(),
                              overlap_voxels_assigned_to_earlier_groups=overlap,
                              selected_voxels=int(np.count_nonzero(owner == gid))))
    return owner, summaries


def tight(mask):
    coords = np.where(mask)
    if not coords[0].size:
        return None
    lo = [int(c.min()) for c in coords]; hi = [int(c.max())+1 for c in coords]
    return lo, hi


def build_tree(bricks, ids):
    """Spatial BVH over leaf references. Internal nodes allocate NO voxel array."""
    if not ids:
        return None
    lo = np.min([bricks[i]['origin_xyz'] for i in ids], axis=0)
    hi = np.max([np.array(bricks[i]['origin_xyz'])+bricks[i]['dimensions_xyz'] for i in ids], axis=0)
    node = dict(origin_xyz=lo.tolist(), extent_xyz=(hi-lo).tolist())
    if len(ids) <= 8:
        node['brick_ids'] = ids
    else:
        axis = int(np.argmax(hi-lo))
        ids = sorted(ids, key=lambda i: bricks[i]['origin_xyz'][axis]+bricks[i]['dimensions_xyz'][axis]/2)
        middle = len(ids)//2
        node['children'] = [build_tree(bricks, ids[:middle]), build_tree(bricks, ids[middle:])]
    return node


def export_bricks(volume, owner, groups, output, brick_size=16, provenance=None):
    if brick_size not in (8, 16, 32):
        raise ValueError('brick_size must be 8,16,32')
    if owner.shape != volume.shape or owner.dtype != np.uint8:
        raise ValueError('Owner map must match volume as uint8')
    out = fresh(output); records = []; offset = 0
    with (out/'density.raw').open('wb') as density, (out/'owners.raw').open('wb') as owners:
        for z in range(0, volume.shape[0], brick_size):
            for y in range(0, volume.shape[1], brick_size):
                for x in range(0, volume.shape[2], brick_size):
                    cell = (slice(z,z+brick_size),slice(y,y+brick_size),slice(x,x+brick_size))
                    bounds = tight(owner[cell]>0)
                    if bounds is None:
                        continue
                    lo, hi = bounds; local = tuple(slice(a,b) for a,b in zip(lo,hi))
                    labels = owner[cell][local].copy()
                    values = np.where(labels, volume[cell][local], 0).astype(np.uint8)
                    raw = values.tobytes(); density.write(raw); owners.write(labels.tobytes())
                    origin = (np.array([z,y,x])+lo)[::-1].tolist()
                    records.append(dict(id=len(records), cell_xyz=[x//brick_size,y//brick_size,z//brick_size],
                                        origin_xyz=origin, dimensions_xyz=list(values.shape[::-1]),
                                        offset=offset, bytes=len(raw), groups=np.unique(labels[labels>0]).tolist()))
                    offset += len(raw)
    for g in groups:
        ids = [b['id'] for b in records if g['id'] in b['groups']]
        g['tree'] = build_tree(records, ids)
        bounds = tight(owner == g['id'])
        g['aabb'] = None if bounds is None else dict(origin_xyz=bounds[0][::-1], extent_xyz=(np.array(bounds[1])-bounds[0])[::-1].tolist())
    selected = np.where(owner, volume, 0).astype(np.uint8)
    metrics = {}
    for level in (0, 60, 120):
        reference = volume > level
        metrics[str(level)] = dict(original_voxels=int(reference.sum()),
```

```
import json
```

```
def file_hash(path):
    h=hashlib.sha256()
    with path.open('rb') as f:
        while b:=f.read(8*1024*1024):h.update(b)
    return h.hexdigest()


def verify(path):

        for cell in np.argwhere(pages[...,0]):
            base,origin,shape,_=map(int,pages[tuple(cell)])
            lo=[(origin>>shift)&31 for shift in (10,5,0)];size=[(shape>>shift)&63 for shift in (12,6,0)]

            assert all(0<s and l+s<=b and a+s<=d for l,s,b,a,d in zip(lo,size,brick,p,dims))
            f.seek(offset);a=np.frombuffer(f.read(n*dtype.itemsize),dtype).reshape(size)
            assert not np.any((a>0)&(a<=m['cutoff']))
            if original is not None:
                src=original[tuple(slice(o,o+n) for o,n in zip(p,size))]
                np.testing.assert_array_equal(a,np.where(src>m['cutoff'],src,0))
            intervals.append((base-1,base-1+n));hist+=np.bincount(a.ravel(),minlength=len(hist))

    cursor=0

                exact_selected_intensity_histogram=True,stored_voxels_checked_against_raw=original is not None,
                orthogonal_mip_checks=checks,limitations='MIP equality is not a DVR framebuffer comparison. Threshold preservation is not anatomical validation.')
    (path/'verification.json').write_text(json.dumps(result,indent=2)+'\n');print(json.dumps(result))
    return result
```

```
        if (query) {
            try {
                const deadline = performance.now() + 5000;
                while (!gl.getQueryParameter(query, gl.QUERY_RESULT_AVAILABLE)) {
                    if (performance.now() > deadline) throw Error('GPU query timed out');
                    await frame();
                }
                if (!gl.getParameter(ext.GPU_DISJOINT_EXT)) gpu.push(gl.getQueryParameter(query, gl.QUERY_RESULT) / 1e6);
            } finally { gl.deleteQuery(query); }
        }
    }
    return { ...accounting(), mode: meta.parameters.mode, downsample: meta.parameters.downsample,
        strategy: meta.parameters.strategy, gpu_median_ms: median(gpu), gpu_samples_ms: gpu,
        cpu_submit_and_finish_median_ms: median(wall), resolution: [canvas.width, canvas.height],
        camera: [+$('rx').value, +$('ry').value, +$('zoom').value], step: +$('step').value, cutoff: +$('cutoff').value };
}
async function action(fn) {
    if (loading || measuring) return;
    loading = true; lock(true);
    try { await fn(); } catch (error) { status(error.message); }
    finally { loading = false; lock(false); }
}

            }

            if (m.parameters.downsample === 1) cases.push({name: `${name}/monolith_all`, dataset: `${name}_monolith`});
        }

    try {
        for (let round = 0; round < 3; round++) {

            }
        }
        const results = cases.map(c => {
            const group = runs.filter(r => r.case === c.name);
            const samples = group.flatMap(r => r.gpu_samples_ms);
            return {case: c.name, resident_texture_payload_bytes: group[0].resident_texture_payload_bytes,
                visible_texture_payload_bytes: group[0].visible_texture_payload_bytes,
                gpu_median_ms: median(samples), round_medians_ms: group.map(r => r.gpu_median_ms), valid_gpu_samples: samples.length};
        });
        suite = {schema_version: 1, input_sha256: partition.input_sha256, partition_components: partition.components,
            environment: {user_agent: navigator.userAgent, renderer: gl.getParameter(gl.RENDERER)},
            methodology: 'Three seeded-shuffled rounds, five warmups and 20 timed frames per case per round; fixed 1280x720, camera 90/0/1.8, step 1, cutoff 60. Upload and network time excluded.             results, order, runs};

    } finally {
        fixedResolution = null; clip = null;

    }
}
```
