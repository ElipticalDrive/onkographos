# Projective TSDF Fusion

Also called: Depth-based TSDF Integration, TSDF Fusion from Depth Images

## Overview
Projective TSDF Fusion is a method to compute signed distance values for voxels from calibrated depth images by projecting voxel centers into the camera frame and comparing projected depth with observed depth [S1]. It differs from static TSDF integration by supporting dynamic scale allocation within a multi-resolution octree, ensuring that distant voxels are not allocated as contiguous blocks and that the voxel size remains proportional to the camera distance [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A global TSDF volume (initialized to empty or previous fusion), a set of calibrated depth images $D(u,v)$, camera intrinsics $\mathbf{K} = \{f_x, f_y, c_x, c_y\}$, and camera poses $(R, \mathbf{t})$ relative to the global frame.
*   **Outputs:** Updated global TSDF volume with fused signed distance values and weights.

**Data Structures:**
*   **TSDF Volume:** A 3D grid where each voxel stores a truncated signed distance value $s(\mathbf{p})$ and an accumulated weight $w(\mathbf{p})$. The truncation limits are typically $d_{min}$ and $d_{max}$ [S2].
*   **Depth Image:** A 2D array where each element $(u,v)$ contains the observed depth $\hat{z}$.

**Steps:**
1.  **Iterate** over all voxels $\mathbf{p}$ in the global TSDF volume that are within the viewing frustum of the current camera.
2.  **Transform** the voxel center $\mathbf{p}$ from the global frame to the camera frame:
    $$ \mathbf{p}_c = R^\top (\mathbf{p} - \mathbf{t}) = (x, y, z)^\top $$
    Here $R$ is the rotation matrix, $\mathbf{t}$ is the translation vector, $\mathbf{p}$ is the global voxel center, and $\mathbf{p}_c$ is the camera-frame coordinates [S1].
3.  **Project** the camera-frame coordinates $(x, y, z)$ to 2D image coordinates $(u, v)$ using the pinhole camera model:
    $$ u = f_x \frac{x}{z} + c_x, \quad v = f_y \frac{y}{z} + c_y $$
    Here $f_x, f_y$ are focal lengths, $c_x, c_y$ are principal points [S1].
4.  **Validate** the projection:
    *   Check if $z > 0$.
    *   Check if $(u, v)$ lies inside the image boundaries.
    *   If valid, read the observed depth $\hat{z} = D(u, v)$.
5.  **Compute** the projective signed distance:
    $$ s(\mathbf{p}) = \hat{z} - z $$
    Here $\hat{z}$ is the observed depth at pixel $(u,v)$, and $z$ is the depth of the voxel center in the camera frame [S1].
6.  **Truncate** the signed distance:
    *   If $|s(\mathbf{p})| \le d_{max}$, the measurement is valid.
    *   If $s(\mathbf{p}) < d_{min}$, set $s(\mathbf{p}) = d_{min}$.
    *   If $s(\mathbf{p}) > d_{max}$, set $s(\mathbf{p}) = d_{max}$.
    *   If $|s(\mathbf{p})| > d_{max}$, the measurement is invalid for this voxel [S2].
7.  **Fuse** the measurement into the global TSDF volume using weighted averaging [S1]:
    *   Let $w_{new}(\mathbf{p})$ be the weight of the current measurement (e.g., 1.0).
    *   Let $w_{old}(\mathbf{p})$ be the accumulated weight in the global volume.
    *   Update the TSDF value:
        $$ s_{new}(\mathbf{p}) = \frac{w_{old}(\mathbf{p}) \cdot s_{old}(\mathbf{p}) + w_{new}(\mathbf{p}) \cdot s(\mathbf{p})}{w_{old}(\mathbf{p}) + w_{new}(\mathbf{p})} $$
    *   Update the weight:
        $$ w_{new}(\mathbf{p}) = w_{old}(\mathbf{p}) + w_{new}(\mathbf{p}) $$

**Parameters:**
*   **Truncation Limits:** $d_{min} = -0.04$, $d_{max} = 0.1$ [S2].
*   **Intrinsics:** $f_x, f_y, c_x, c_y$ [S1].
*   **Pose:** $R, \mathbf{t}$ [S1].

**Edge Cases and Pitfalls:**
*   **Invalid Depth:** If the projected pixel has no valid depth (e.g., occlusion or sensor noise), the measurement is skipped [S1].
*   **Precision:** Floating-point precision in depth calculation and projection can affect accuracy, especially at large distances [G].
*   **Boundaries:** Voxels near the image boundary may have partial visibility; standard projective fusion assumes full visibility within the pixel footprint [G].

## Subtopics

### [Single Layer TSDF Update](13744-single-layer-tsdf-update.md)
Single Layer TSDF Update is the core integration step in Projective TSDF Fusion that computes a signed distance field (SDF) sample for a specific voxel from a new depth measurement and merges it into the global map using a weighted average. It differs from static TSDF integration by supporting dynamic scale allocation within a multi-resolution octree, ensuring that distant voxels are not allocated as contiguous blocks and that the voxel size remains proportional to the camera distance.

### TSDF Sub-volume Sampling and Preprocessing
This variant involves fusing sequences of depth images into a Truncated Signed Distance Field (TSDF) using truncation limits $d_{min} = -0.04$ and $d_{max} = 0.1$ [S2]. Sub-volumes of size $16 \times 16 \times 16$ voxels are sampled from the TSDF at every eight voxels along each spatial dimension [S2]. The indexing order along each axis is permuted for every sample to generate five additional reflections at each location [S2]. Distance values are mapped from the interval $[d_{min}, d_{max}]$ to $[0, 1]$ and saved [S2]. Sub-volumes where the mean sum of normalized distances (in $[0, 1]$) is below 0.85 are discarded to avoid disproportionate empty space samples, and a small proportion of empty samples is explicitly included to balance the dataset [S2]. The input data structure is $X \in \{ \mathbb{R}^{m \times n} \mid 0 \le x_{i,j} \le 1 \}$, where $m$ is the number of samples and $n$ is the dimensionality of each sub-volume ($n=4096$) [S2]. The dataset size is $m=200,000$ samples [S2].

## Operating characteristics
*   **Time Complexity:** $O(V \cdot N)$, where $V$ is the number of voxels in the viewing frustum and $N$ is the number of views. Each voxel is processed once per view.
*   **Memory Complexity:** $O(V_{total})$, where $V_{total}$ is the total number of voxels in the global TSDF volume.
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Scales linearly with the number of voxels and views. Multi-resolution octrees can reduce memory usage for large scenes [S1].
*   **Strengths:** Efficient integration of depth data; robust to noise via truncation and weighted averaging; supports dynamic resolution [S1].
*   **Limitations:** Requires calibrated depth images; sensitive to camera pose errors; may suffer from aliasing at large distances if voxel size is not adjusted [S1].
*   **When to Use:** Real-time 3D reconstruction from depth cameras (e.g., KinectFusion, voxel hashing) [S1].
*   **When Not to Use:** When only explicit geometry (meshes/point clouds) is available without depth images; when high-precision global alignment is required without pose correction [S1].

## Background
Projective TSDF fusion was introduced in volumetric fusion systems such as KinectFusion [Newcombe et al. 2011] and voxel hashing systems [Nießner et al. 2013] [S1]. It builds on the weighted TSDF integration method by Curless and Levoy [Curless and Levoy 1996] [S1].
