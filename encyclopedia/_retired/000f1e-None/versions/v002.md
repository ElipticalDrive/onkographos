# Macro-Cell Trimming

Also called: Culling Empty Cap-Level Macrocells

## Overview
Macro-cell trimming is an optimization that reduces the number of local rays by trimming each macro-cell to the smallest cuboid containing its portions of the iso-surfaces, rather than projecting the entire macro-cell [S1, unofficial]. It operates on axis-aligned bounding boxes derived from cell occupancy rather than explicit mesh geometry, and focuses on pre-projection culling of the pixel footprint rather than adaptive step sizing during traversal [G].

## How it works
**Inputs:**
- A macro-cell containing a grid of cells (typically at the finest available octree depth, i.e., cap nodes) [S2, unofficial].
- An isovalue threshold defining the iso-surface [G].
- The spatial bounds of the macro-cell [G].

**Outputs:**
- A trimmed bounding cuboid (axis-aligned bounding box) that tightly encloses all cells within the macro-cell intersecting the isovalue [G].
- A reduced set of pixels (u,v slice extents) for ray casting [G].

**Data Structures:**
- **Macro-cell Grid:** A 3D array of cells. Each cell contains a scalar value (density or field value) [G].
- **Trimmed Cuboid:** Defined by minimum and maximum coordinates $(x_{min}, y_{min}, z_{min})$ and $(x_{max}, y_{max}, z_{max})$. Initialized to an invalid or zero-size state [G].

**Steps:**
1. **Initialize Cuboid:** Set the trimmed cuboid to a size of zero or an invalid state [S1, unofficial].
2. **Iterate Cells:** Loop through all cells within the macro-cell [S1, unofficial].
3. **Check Iso-surface Intersection:** For each cell, determine if it contains the isovalue (i.e., if the cell's value crosses the threshold) [S2, unofficial].
4. **Extend Cuboid:** If a cell contains the isovalue, calculate its spatial bounds and update the trimmed cuboid's min/max coordinates to include the cell's bounds, maintaining the smallest necessary size [S1, unofficial].
5. **Cull Empty Macro-cells:** If the macro-cell is empty (no cells contain the isovalue), omit it from extent computation entirely [S2, unofficial].
6. **Compute Slice Extents:** If the macro-cell is not empty, compute the u,v slice extents based on the minimum and maximum u,v coordinates of the macro-cell or trimmed region [S2, unofficial].
7. **Project:** Project the resulting trimmed cuboid onto the image plane instead of the full macro-cell [S1, unofficial].
8. **Cast Rays:** Cast local rays only for pixels covered by the projected trimmed cuboid [S1, unofficial].

**Pseudocode:**
```python
def trim_macro_cell(cells, isovalue):
    # Initialize cuboid bounds to None (zero-size state) [S1, unofficial]
    x_min = None; x_max = None; y_min = None; y_max = None
    z_min = None; z_max = None
    # Initialize u,v slice extents [S2, unofficial]
    u_min = None; u_max = None; v_min = None; v_max = None

    # Iterate through all cells in the macro-cell [S1, unofficial]
    for cell in cells:
        # Check if cell contains the isovalue [S2, unofficial]
        if cell['value'] > isovalue: # Standard threshold check [G]
            # Calculate spatial bounds of the cell [G]
            cx_min, cx_max, cy_min, cy_max, cz_min, cz_max = cell['bounds']
            # Get cell u,v coordinates [G]
            cu_min, cu_max, cv_min, cv_max = cell['uv_bounds']

            # Update cuboid min/max to smallest necessary size [S1, unofficial]
            if x_min is None or cx_min < x_min: x_min = cx_min
            if x_max is None or cx_max > x_max: x_max = cx_max
            if y_min is None or cy_min < y_min: y_min = cy_min
            if y_max is None or cy_max > y_max: y_max = cy_max
            if z_min is None or cz_min < z_min: z_min = cz_min
            if z_max is None or cz_max > z_max: z_max = cz_max

            # Update u,v slice extents based on minimum and maximum u,v coordinates [S2, unofficial]
            if u_min is None or cu_min < u_min: u_min = cu_min
            if u_max is None or cu_max > u_max: u_max = cu_max
            if v_min is None or cv_min < v_min: v_min = cv_min
            if v_max is None or cv_max > v_max: v_max = cv_max

    # If no cells contained the isovalue, the macro-cell is empty [S2, unofficial]
    if x_min is None:
        return None

    # Project the resulting cuboid/slice extents onto the image plane [S1, unofficial]
    # Standard camera projection maps u,v bounds to screen pixel coordinates [G]
    screen_u_min, screen_v_min, screen_u_max, screen_v_max = project_to_screen(u_min, u_max, v_min, v_max)

    return (screen_u_min, screen_u_max, screen_v_min, screen_v_max)
```

**Edge Cases and Pitfalls:**
- **Empty Macro-cells:** Must be detected and omitted to avoid unnecessary processing [S2, unofficial].
- **Boundary Conditions:** The cuboid must be initialized correctly to handle the first surface cell encountered [S1, unofficial].

## Operating characteristics
- **Performance:** Macro-cell trimming saves about 28 percent of overall rendering time on average [S1, unofficial].
- **Dependency:** The time gain is very much dependent on the data set and the position of the view point [S1, unofficial].
- **Complexity:** The trimming step adds a linear scan over the macro-cell cells, but this is offset by the reduction in ray casting operations [G].
- **Strengths:** Reduces unnecessary calculations and octree lookups by focusing only on relevant pixels [S1, S2, unofficial].
- **Limitations:** Effectiveness varies with data set topology and viewpoint [S1, unofficial].

## Background
Macro-cell trimming was introduced as part of cell-based first-hit ray casting techniques to optimize volume rendering performance [S1, unofficial]. It is also referred to as "Culling empty cap-level macrocells" in the context of interactive ray tracing of implicit surfaces [S2, unofficial]. The method leverages the coherence of octree structures to efficiently cull empty regions before ray casting begins [S2, unofficial].
