# Ray Marching with Secant Refinement
## Overview
A procedure to detect surface points along rays by evaluating a neural decoder at proposal points, identifying sign changes in occupancy logits, and refining the depth using a root-finding method [S1, unofficial]. It sets itself apart from its siblings by combining coarse uniform sampling with a specific sign-change detection logic that identifies negative-to-positive transitions, followed by the Secant Method for Surface Depth Refinement to pinpoint the zero-crossing [S1, unofficial]. It builds on [Secant Method for Surface Depth Refinement](996-secant-method-for-surface-depth-refinement.md) [G].
## How it works
**Inputs:**
- `ray0`: Origin points, shape $(B, N, 1, 3)$.
- `ray_direction`: Direction vectors, shape $(B, N, 1, 3)$.
- `c`: Latent codes or context, shape $(B, N, D_c)$.
- `decoder`: Neural network function evaluating occupancy.
- `depth_range`: Tuple $(d_{min}, d_{max})$ defining the search interval.
- `tau`: Probability threshold for occupancy.
- `n_steps`: Tuple $(n_{min}, n_{max})$ for sampling the number of steps.
- `max_points`: Integer limit for GPU memory management.
- `check_cube_intersection`: Boolean flag.

**Outputs:**
- `pt_pred`: Final 3D surface points, shape $(B, N, 1, 3)$.
- `d_pred`: Refined depth values, shape $(B, N, 1, 1)$.
- `mask`: Boolean mask indicating valid detections, shape $(B, N, 1, 1)$.

**Data Structures:**
- `d_proposal`: Tensor of shape $(B, N, n_{steps}, 1)$ containing linearly spaced depth values.
- `val`: Tensor of shape $(B, N, n_{steps}, 1)$ containing the signed distance/occupancy logit minus threshold.
- `sign_matrix`: Tensor of shape $(B, N, n_{steps})$ indicating sign changes.
- `cost_matrix`: Tensor of shape $(B, N, n_{steps})$ used for finding the first sign change.

**Steps:**

1.  **Threshold Conversion:** Convert the probability threshold $\tau$ to a logit threshold:
    $$ logit\_tau = \text{get\_logits\_from\_prob}(\tau) $$
    [S1, unofficial] [G] `get_logits_from_prob` is the inverse sigmoid function: $\log(\frac{\tau}{1-\tau})$.

2.  **Step Sampling:** Sample the number of steps $n_{steps}$ uniformly from the integer range $[n_{steps}[0], n_{steps}[1]]$ [S1, unofficial].

3.  **Proposal Generation:** Create linearly spaced depth proposals $d_{proposal}$ from $depth\_range[0]$ to $depth\_range[1]$ with $n_{steps}$ points, shaped $(B, N, n_{steps}, 1)$ [S1, unofficial].

4.  **Cube Intersection (Optional):** If `check_cube_intersection` is true, compute intersection with the unit cube and replace $d_{proposal}$ values inside the cube with cube-intersection depths [S1, unofficial].

5.  **Point Computation:** Compute 3D proposal points:
    $$ p_{proposal} = ray0 + ray\_direction \cdot d_{proposal} $$
    [S1, unofficial]

6.  **Decoder Evaluation:** Evaluate the decoder at all proposal points in parallel, splitting into chunks of size `max_points` / `batch_size` to manage GPU memory. Compute:
    $$ val = decoder(p, c, only\_occupancy=True) - logit\_tau $$
    [S1, unofficial]

7.  **Initial Occupancy Mask:** Create a mask for rays where the first point is not occupied:
    $$ mask\_0\_not\_occupied = val[:, :, 0] < 0 $$
    [S1, unofficial]

8.  **Sign Change Detection:**
    - Compute the sign change matrix:
      $$ sign\_matrix = [\text{sign}(val[:, :, :-1] \cdot val[:, :, 1:]), 1] $$
      [S1, unofficial]
    - Compute the cost matrix to prioritize earlier sign changes:
      $$ cost\_matrix = sign\_matrix \cdot [n_{steps}, n_{steps}-1, ..., 1] $$
      [S1, unofficial]

9.  **First Sign Change Index:** Find the first sign change index:
    $$ (values, indices) = \text{argmin}(cost\_matrix) $$
    [S1, unofficial] Identify valid sign changes:
    $$ mask\_sign\_change = values < 0 $$
    [S1, unofficial]

10. **Transition Verification:** Identify negative-to-positive transitions:
    $$ mask\_neg\_to\_pos = val[batch\_indices, point\_indices, indices] < 0 $$
    [S1, unofficial]

11. **Combined Mask:** Combine masks for valid depth detection:
    $$ mask = mask\_sign\_change \land mask\_neg\_to\_pos \land mask\_0\_not\_occupied $$
    [S1, unofficial]

12. **Bracket Extraction:** Extract bracketing depths and function values for valid rays:
    - $d_{low}, f_{low}$ at `indices`
    - $d_{high}, f_{high}$ at `indices + 1` (clamped to $n_{steps}-1$)
    [S1, unofficial]

13. **Refinement:** Apply the Secant Method for Surface Depth Refinement on the masked rays using $(d_{low}, f_{low})$ and $(d_{high}, f_{high})$ to get $d_{pred}$ [S1, unofficial].

14. **Final Point Computation:** Compute final 3D points:
    $$ pt_{pred}[mask] = ray0_{masked} + d_{pred} \cdot ray\_direction_{masked} $$
    [S1, unofficial]

**Pseudocode:**

```python
import torch

def ray_marching_with_secant_refinement(
    ray0, ray_direction, decoder, latent_codes, 
    depth_range, tau, n_steps_range, max_points, 
    check_cube_intersection=False
):
    """
    ray0: (B, N, 1, 3)
    ray_direction: (B, N, 1, 3)
    latent_codes: (B, N, D_c)
    depth_range: (d_min, d_max)
    tau: float
    n_steps_range: (n_min, n_max)
    max_points: int
    """
    B, N, _, _ = ray0.shape
    device = ray0.device
    
    # 1. Threshold Conversion
    logit_tau = torch.log(tau / (1 - tau))
    
    # 2. Step Sampling
    n_steps = torch.randint(n_steps_range[0], n_steps_range[1] + 1, (1,)).item()
    
    # 3. Proposal Generation
    depths = torch.linspace(depth_range[0], depth_range[1], n_steps, device=device)
    d_proposal = depths.view(1, 1, -1, 1).expand(B, N, -1, 1)
    
    # 4. Cube Intersection (Optional)
    if check_cube_intersection:
        # [Comment] Compute intersection with unit cube and replace d_proposal
        # values inside the cube with cube-intersection depths.
        pass 
        
    # 5. Point Computation
    p_proposal = ray0.unsqueeze(2) + ray_direction.unsqueeze(2) * d_proposal
    
    # 6. Decoder Evaluation
    chunk_size = max_points // B
    val_chunks = []
    for i in range(0, n_steps, chunk_size):
        end_i = min(i + chunk_size, n_steps)
        p_chunk = p_proposal[:, :, i:end_i, :]
        p_flat = p_chunk.view(B * N, end_i - i, 3)
        c_flat = latent_codes.view(B * N, -1).unsqueeze(1).expand(-1, end_i - i, -1)
        occ_logit = decoder(p_flat, c_flat)
        occ_logit = occ_logit.view(B, N, end_i - i, 1)
        val_chunks.append(occ_logit - logit_tau)
    val = torch.cat(val_chunks, dim=2)
    
    # 7. Initial Occupancy Mask
    mask_0_not_occupied = val[:, :, 0, 0] < 0
    
    # 8. Sign Change Detection
    product = val[:, :, :-1, 0] * val[:, :, 1:, 0]
    sign_product = torch.sign(product)
    ones = torch.ones(B, N, 1, device=device)
    sign_matrix = torch.cat([sign_product, ones], dim=2)
    weights = torch.arange(n_steps, 0, -1, device=device).float()
    cost_matrix = sign_matrix * weights.unsqueeze(0).unsqueeze(0)
    
    # 9. First Sign Change Index
    values, indices = torch.min(cost_matrix, dim=2)
    mask_sign_change = values < 0
    
    # 10. Transition Verification
    batch_indices = torch.arange(B).unsqueeze(1).expand(B, N)
    point_indices = torch.arange(N).unsqueeze(0).expand(B, N)
    f_low = val[batch_indices, point_indices, indices, 0]
    mask_neg_to_pos = f_low < 0
    
    # 11. Combined Mask
    mask = mask_sign_change & mask_neg_to_pos & mask_0_not_occupied
    
    # 12. Bracket Extraction
    d_low = d_proposal[batch_indices, point_indices, indices, 0]
    d_high_indices = (indices + 1).clamp(max=n_steps - 1)
    d_high = d_proposal[batch_indices, point_indices, d_high_indices, 0]
    f_high = val[batch_indices, point_indices, d_high_indices, 0]
    
    # 13. Refinement (Secant Step)
    denom = f_high - f_low
    denom = torch.where(denom == 0, torch.ones_like(denom), denom)
    d_pred = d_high - f_high * (d_high - d_low) / denom
    d_pred = d_pred.masked_fill(~mask, 0.0)
    
    # 14. Final Point Computation
    pt_pred = torch.zeros_like(ray0)
    pt_pred[mask] = ray0[mask] + ray_direction[mask] * d_pred[mask].unsqueeze(-1)
    
    return pt_pred, d_pred.view(B, N, 1, 1), mask.view(B, N, 1, 1)
```

**Parameters:**
- `max_points`: Integer, maximum number of points loaded to GPU memory per batch to prevent OOM. Typical value: 3,500,000 [S1, unofficial].
- `n_steps`: Tuple of integers defining the range for sampling the number of evaluation steps. Typical value: [128, 129] [S1, unofficial].
- `depth_range`: Tuple of floats defining the range of possible depth values. Typical value: [0.0, 2.4] [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Precision:** The sign change detection relies on the product of adjacent values. If values are very close to zero, floating-point precision issues may cause false negatives or positives [G].
- **Boundaries:** The `d_high` index is clamped to $n_{steps}-1$ to prevent out-of-bounds access [S1, unofficial].
- **Degenerate Input:** If no sign change is detected, the mask will be false, and no point will be returned for that ray [S1, unofficial].

## Subtopics

### [Differentiable Depth Function Forward/Backward Pass](1047-differentiable-depth-function-forward-backward-pass.md)
A PyTorch Autograd Function that wraps the ray marching process, allowing gradients to flow through the depth prediction to the decoder parameters and latent code. It sets itself apart by enabling end-to-end training of the neural decoder via backpropagation through the ray marching steps. Choose it when training a neural implicit surface representation [G].

## Operating characteristics
- **Time Complexity:** Dominated by the decoder evaluation at $n_{steps}$ points per ray. $O(B \cdot N \cdot n_{steps})$ [G].
- **Memory Complexity:** $O(B \cdot N \cdot n_{steps})$ for storing proposal points and values [G].
- **Measured Performance:** Not given in the sources [S1, unofficial].
- **Scaling:** Scales linearly with the number of rays and steps. Memory usage is controlled by `max_points` [S1, unofficial].
- **Strengths:** Efficient detection of surface crossings using sign changes; refinement provides high accuracy [G].
- **Limitations:** Requires a continuous occupancy function; sensitive to the choice of $n_{steps}$ and depth range [G].
- **When to use:** When extracting surfaces from neural implicit representations where the decoder provides occupancy logits [S1, unofficial].
- **When not:** When the surface is not defined by a zero-crossing of a scalar field [G].

## Background
Originated in the context of differentiable volumetric rendering for 3D shape reconstruction [G]. It is used in generating meshes from occupancy processes by detecting surface points along rays [S1, unofficial].
