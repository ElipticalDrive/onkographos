# FastFDK

Also called: CPU Reference FDK Reconstruction, Cone-Beam FDK, FDK, FDK Algorithm, Feldkamp-Davis-Kress

## Overview
FastFDK is a CPU-based implementation of the Feldkamp-Davis-Kress (FDK) algorithm, a filtered backprojection method for reconstructing a 3D volume from a stack of 2D cone-beam projection images [S1, S3, unofficial]. It solves the inverse problem of computed tomography by applying geometric weighting and a ramp filter to projections before backprojecting them into a 3D grid [S1, S3, unofficial]. It is distinguished from iterative methods like [SIRT](3101-sirt-simultaneous-iterative-reconstruction-technique.md) or [General Numerical Optimization Framework for Tomography](3251-general-numerical-optimization-framework-for-tomography.md) by its direct, non-iterative closed-form solution, and from GPU-accelerated variants by its explicit, unoptimized CPU reference design intended for accuracy validation [S1, S3, unofficial].

## How it works
**Inputs:** A stack of `m_id` 2D projection images of size `m_iw` x `m_ih`, and scanner geometry parameters: pixel size `m_ps`, source-to-origin distance `m_sd`, origin-to-detector distance `m_yd`, volume dimensions `m_vw` x `m_vw` x `m_vd`, voxel size `m_vs`, and angular span `m_na` [S1, S3, unofficial].
**Outputs:** A 3D volume `m_vol` of type `float` with dimensions `(m_vw, m_vw, m_vd)` [S1, S3, unofficial].

**Data Structures:**
*   `m_vol`: Output volume, shape `(m_vw, m_vw, m_vd)` [S1, S3, unofficial].
*   `m_img`: Temporary storage for filtered projections, shape `(m_id, m_ih, m_iw)` [S1, S3, unofficial].
*   `m_w0`: Precomputed initial image weighting array, shape `(m_ih, m_iw)` [S1, S3, unofficial].
*   `m_flt`: Precomputed convolution filter coefficients, size `m_nf = m_iw // 2` [S1, S3, unofficial].
*   `m_k`: Center filter coefficient, scalar [S1, S3, unofficial].
*   `m_buf`: Temporary buffer for row processing, size `m_iw` [S1, S3, unofficial].
*   `m_cyl`: Cylinder mask, boolean array of size `m_vw * m_vw`, indicating voxels inside the reconstruction cylinder [S1, S3, unofficial].

**Parameters:**
*   `m_ps`: Pixel size in mm. Adjusted in constructor: `m_ps = m_ps * m_sd / (m_sd + m_yd)` [S1, S3, unofficial].
*   `m_sd`: Source-to-origin distance in mm [S1, S3, unofficial].
*   `m_iw`, `m_ih`: Image width and height in pixels [S1, S3, unofficial].
*   `m_vw`, `m_vd`: Volume width and depth in voxels [S1, S3, unofficial].
*   `m_vs`: Voxel size in mm [S1, S3, unofficial].
*   `m_id`: Number of projections [S1, S3, unofficial].
*   `m_na`: Angular span in degrees [S1, S3, unofficial].

**Steps:**

1.  **Precomputation (Constructor):**
    *   Adjust `m_ps` as defined above [S1, S3, unofficial].
    *   Compute `m_w0[i, j] = m_sd / sqrt( ((i + 0.5 - m_iw/2) * m_ps)^2 + ((m_ih/2 - 0.5 - j) * m_ps)^2 + m_sd^2 )` for all `i, j` [S1, S3, unofficial].
    *   Compute `m_k = 1 / (4 * m_ps^2)` [S1, S3, unofficial].
    *   Compute `m_flt[k] = -1 / ( (M_PI * m_ps * (2*k + 1))^2 )` for `k` from `0` to `m_nf - 1` [S1, S3, unofficial].
    *   Compute `m_cyl[i, j] = True` if `(2*i - m_vw)^2 + (2*j - m_vw)^2 < m_vw^2`, else `False` [S1, S3, unofficial].

2.  **Filtering:**
    *   For each projection image `img` in the input stack:
        *   For each row `j` from `0` to `m_ih - 1`:
            *   Copy row `img[:, j]` to `m_buf` [S1, S3, unofficial].
            *   Apply weighting: `m_buf[i] *= m_w0[j, i]` for all `i` [S1, S3, unofficial].
            *   Apply convolution:
                *   For each pixel `i` from `0` to `m_iw - 1`:
                    *   `val = m_buf[i] * m_k` [S1, S3, unofficial].
                    *   For `k` from `0` to `m_nf - 1`:
                        *   `l = 2*k + 1` [S1, S3, unofficial].
                        *   If `i - l >= 0` and `i + l < m_iw`: `val += (m_buf[i - l] + m_buf[i + l]) * m_flt[k]` [S1, S3, unofficial].
                        *   Else if `i - l >= 0`: `val += m_buf[i - l] * m_flt[k]` [S1, S3, unofficial].
                        *   Else if `i + l < m_iw`: `val += m_buf[i + l] * m_flt[k]` [S1, S3, unofficial].
                        *   Else: break [S1, S3, unofficial].
                    *   Store `val` in `outImg[i, j]` [S1, S3, unofficial].

3.  **Backprojection:**
    *   Initialize `m_vol` to zero [S1, S3, unofficial].
    *   Compute angle step: `angStep = -m_na * M_PI / (m_id * 180)` [S1, S3, unofficial].
    *   For each projection index `n` from `0` to `m_id - 1`:
        *   `ang = n * angStep` [S1, S3, unofficial].
        *   `ca = cos(ang)`, `sa = sin(ang)` [S1, S3, unofficial].
        *   `k1 = m_sd / m_ps` [S1, S3, unofficial].
        *   For each volume row `j` from `0` to `m_vw - 1`:
            *   `vy = (m_vw/2 - 0.5 - j) * m_vs` [S1, S3, unofficial].
            *   For each volume column `i` from `0` to `m_vw - 1`:
                *   `l = j * m_vw + i` [S1, S3, unofficial].
                *   If `!m_cyl[l]`, continue [S1, S3, unofficial].
                *   `vx = (i + 0.5 - m_vw/2) * m_vs` [S1, S3, unofficial].
                *   `vvx = vx * ca - vy * sa` [S1, S3, unofficial].
                *   `vvy = vy * ca + vx * sa` [S1, S3, unofficial].
                *   `k2 = k1 / (vvy + m_sd)` [S1, S3, unofficial].
                *   `u = vvx * k2 + m_iw/2 - 0.5` [S1, S3, unofficial].
                *   `iu = floor(u)`; if `u < 0`, `iu -= 1` [S1, S3, unofficial].
                *   `du = u - iu` [S1, S3, unofficial].
                *   For each volume depth `k` from `0` to `m_vd - 1`:
                    *   `vz = (m_vd/2 - 0.5 - k) * m_vs` [S1, S3, unofficial].
                    *   `v = m_ih/2 - vz * k2 - 0.5` [S1, S3, unofficial].
                    *   `iv = floor(v)`; if `v < 0`, `iv -= 1` [S1, S3, unofficial].
                    *   `dv = v - iv` [S1, S3, unofficial].
                    *   `val = bilinear_interpolation(img, iu, iv, du, dv)` [S1, S3, unofficial].
                    *   `k3 = m_sd / (m_sd + vvy)` [S1, S3, unofficial].
                    *   `val *= k3 * k3` [S1, S3, unofficial].
                    *   `m_vol[i, j, k] += (val - m_vol[i, j, k]) / (n + 1)` [S1, S3, unofficial].

4.  **Normalization:**
    *   For each voxel `p` in `m_vol`:
        *   If `abs(p) < epsilon` and `p != 0`, set `p = 0` [S1, S3, unofficial].
        *   Else, `p /= 2` [S1, S3, unofficial].

**Pseudocode:**

```python
import math

def fastfdk(projections, params):
    """
    projections: list of 2D arrays, shape (m_ih, m_iw)
    params: dict with keys: m_iw, m_ih, m_id, m_ps, m_yd, m_sd, m_vw, m_vd, m_vs, m_na
    """
    m_iw = params['m_iw']
    m_ih = params['m_ih']
    m_id = params['m_id']
    m_ps = params['m_ps'] * params['m_sd'] / (params['m_sd'] + params['m_yd'])
    m_sd = params['m_sd']
    m_vw = params['m_vw']
    m_vd = params['m_vd']
    m_vs = params['m_vs']
    m_na = params['m_na']
    
    # Precomputation
    m_w0 = [[0.0] * m_iw for _ in range(m_ih)]
    for j in range(m_ih):
        v = (m_ih / 2 - 0.5 - j) * m_ps
        k1 = m_sd**2 + v**2
        for i in range(m_iw):
            u = (i + 0.5 - m_iw / 2) * m_ps
            m_w0[j][i] = m_sd / math.sqrt(u**2 + k1)
            
    m_nf = m_iw // 2
    m_k = 1.0 / (4.0 * m_ps**2)
    m_flt = [0.0] * m_nf
    for k in range(m_nf):
        l = 2 * k + 1
        tmp = math.pi * m_ps * l
        m_flt[k] = -1.0 / (tmp**2)
        
    m_cyl = [[False] * m_vw for _ in range(m_vw)]
    for i in range(m_vw):
        for j in range(m_vw):
            if (2*i - m_vw)**2 + (2*j - m_vw)**2 < m_vw**2:
                m_cyl[j][i] = True
                
    # Filtering
    filtered_projs = []
    for img in projections:
        out_img = [[0.0] * m_iw for _ in range(m_ih)]
        for j in range(m_ih):
            buf = img[j][:] # Copy row
            for i in range(m_iw):
                buf[i] *= m_w0[j][i]
            for i in range(m_iw):
                val = buf[i] * m_k
                for k in range(m_nf):
                    l = 2 * k + 1
                    if i - l >= 0 and i + l < m_iw:
                        val += (buf[i - l] + buf[i + l]) * m_flt[k]
                    elif i - l >= 0:
                        val += buf[i - l] * m_flt[k]
                    elif i + l < m_iw:
                        val += buf[i + l] * m_flt[k]
                    else:
                        break
                out_img[j][i] = val
        filtered_projs.append(out_img)
        
    # Backprojection
    volume = [[[0.0] * m_vd for _ in range(m_vw)] for _ in range(m_vw)]
    ang_step = -m_na * math.pi / (m_id * 180)
    
    for n in range(m_id):
        ang = n * ang_step
        ca = math.cos(ang)
        sa = math.sin(ang)
        k1 = m_sd / m_ps
        img = filtered_projs[n]
        
        for j in range(m_vw):
            vy = (m_vw / 2 - 0.5 - j) * m_vs
            for i in range(m_vw):
                if not m_cyl[j][i]:
                    continue
                vx = (i + 0.5 - m_vw / 2) * m_vs
                vvx = vx * ca - vy * sa
                vvy = vy * ca + vx * sa
                k2 = k1 / (vvy + m_sd)
                u = vvx * k2 + m_iw / 2 - 0.5
                iu = int(math.floor(u))
                if u < 0:
                    iu -= 1
                du = u - iu
                
                for k in range(m_vd):
                    vz = (m_vd / 2 - 0.5 - k) * m_vs
                    v = m_ih / 2 - vz * k2 - 0.5
                    iv = int(math.floor(v))
                    if v < 0:
                        iv -= 1
                    dv = v - iv
                    
                    # Bilinear interpolation
                    def get_pixel(img, x, y):
                        if 0 <= x < m_iw and 0 <= y < m_ih:
                            return img[int(y)][int(x)]
                        return 0.0
                        
                    v1 = get_pixel(img, iu, iv)
                    v2 = get_pixel(img, iu + 1, iv)
                    v3 = get_pixel(img, iu, iv + 1)
                    v4 = get_pixel(img, iu + 1, iv + 1)
                    val = (v1 + du * (v2 - v1)) + dv * ((v3 + du * (v4 - v3)) - (v1 + du * (v2 - v1)))
                    
                    k3 = m_sd / (m_sd + vvy)
                    val *= k3 * k3
                    volume[j][i][k] += (val - volume[j][i][k]) / (n + 1)
                    
    # Normalization
    for j in range(m_vw):
        for i in range(m_vw):
            for k in range(m_vd):
                val = volume[j][i][k]
                if abs(val) < 1e-6 and val != 0:
                    volume[j][i][k] = 0.0
                else:
                    volume[j][i][k] /= 2.0
                    
    return volume
```

## Subtopics

### [Filtered Back-Projection for Volume Rendering](3399-filtered-back-projection-for-volume-rendering.md)
A volume rendering technique that reconstructs density values at arbitrary sample points along a ray directly from 2D projections, avoiding the intermediate step of creating a 3D rectilinear grid. It uses Filtered Back-Projection to compute density and gradients.

## Operating characteristics
*   **Time Complexity:** $O(m_{id} \cdot m_{vw}^2 \cdot m_{vd})$ for backprojection, plus $O(m_{id} \cdot m_{ih} \cdot m_{iw})$ for filtering [S1, S3, unofficial].
*   **Memory Complexity:** $O(m_{id} \cdot m_{ih} \cdot m_{iw})$ for storing filtered projections, plus $O(m_{vw}^2 \cdot m_{vd})$ for the output volume [S1, S3, unofficial].
*   **Performance:** As a CPU reference implementation, it is significantly slower than GPU-accelerated versions (e.g., GPU-Buffer, GPU-Image, GPU-Full) but provides a baseline for accuracy validation [S3, unofficial].
*   **Strengths:** Simple implementation, deterministic results, easy to debug and validate against GPU implementations [S1, S3, unofficial].
*   **Limitations:** Slow for large volumes or high-resolution projections, does not handle missing wedge artifacts or noise regularization inherently [S1, S3, unofficial].
*   **When to use:** For validation of GPU implementations, small-scale problems, or when hardware acceleration is unavailable [S1, S3, unofficial].
*   **When not to use:** For real-time reconstruction or large-scale clinical datasets where performance is critical [S3, unofficial].

## Background
The FDK algorithm was introduced by Feldkamp, Davis, and Kress in 1984 for cone-beam CT reconstruction [S1, S3, unofficial]. FastFDK is a specific CPU-based reference implementation by Christophe Meessen (2009), designed for accuracy validation of GPU paths [S1, S3, unofficial]. It is used in academic and industrial settings to verify the correctness of accelerated reconstruction pipelines [S3, unofficial].
