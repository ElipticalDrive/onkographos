# Explicit Radiance Fields

Also called: Explicit Radiance Fields Reconstruction via Gauss-Newton, Non-linear least-squares volumetric reconstruction, PERF (Performant Explicit Radiance Fields), PERF reconstruction, Volumetric reconstruction with explicit voxels

## Overview
Explicit Radiance Fields (also known as PERF) is a method for image-based 3D reconstruction of 360° scenes that formulates volumetric reconstruction as a non-linear least-squares problem solved explicitly without neural networks [S1]. It uses a voxel grid for the foreground and a hierarchical set of environment maps for the background, minimizing the sum of squared differences between accumulated ray colors and actual pixel colors [S1]. Unlike [Plenoxels](1501-plenoxels.md) which uses fixed hierarchical structures, or [Direct Voxel Grid Optimization](4694-direct-voxel-grid-optimization.md) which uses gradient descent, PERF employs a Gauss-Newton solver with Preconditioned Conjugate Gradient, achieving 2-3 orders of magnitude faster convergence than neural network-based methods like NERF [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of images of a scene with known camera poses.
*   **Outputs:** A voxel grid containing color and differential opacity values, and a set of environment maps containing color and opacity values.

**Data Structures:**
1.  **Voxel Grid:** A 3D grid where each cell contains three color channels $C = \{c_r, c_g, c_b\}$ and differential opacity $\sigma$ [S1]. Stored in a 3D surface for CUDA implementation [S1].
2.  **Environment Maps:** A hierarchical set of cubemap environment maps surrounding the object of interest, centered around it. Each texel contains color and opacity [S1]. Their distance increases with the square of the distance to the voxel grid [S1]. Stored in cube maps [S1].
3.  **Backing Storage:** For kernels using atomics, backing storage is copied to regular memory, as atomics are not supported for surfaces [S1]. CUDA texture objects are bound to surfaces for hardware trilinear interpolation [S1].

**Parameters:**
*   $\alpha$: Geometrical decimation factor for line search, set to 0.7 [S1].
*   $\lambda$: Weight for the auxiliary opacity penalty term, set to 0.1 [S1].
*   Hierarchical Levels: Typically 4-5 levels. Resolution doubles per level. Initial resolution: $32^3$ for voxel grid, $32 \times 32$ for cubemaps [S1].
*   Iterations per level: $N=30$ [S1].
*   PCG Iterations: Typically 1-3 iterations [S1].
*   Opacity Threshold: During rendering of converged scene, if $(1.0 - \hat{T}) < 0.7$, volume is considered fully transparent [S1].
*   Final Grid Resolution: Typically $256^3$ or $512^3$ [S1].
*   Environment Maps Resolution: $256^2$ or $512^2$ per cubemap face [S1].
*   Image Resolution: Synthetic scenes run at half image resolution. 360° scenes run at quarter image resolution [S1].

**Steps:**

1.  **Initialization:** Start with a low-resolution voxel grid ($32^3$) and environment maps ($32 \times 32$). Initialize with random colors and low opacity [S1].
2.  **Hierarchical Optimization Loop:** For each hierarchical level:
    a.  **Ray Integration (Voxel Grid):** For each pixel, generate a ray. Ray origin jittering: Position within pixel chosen randomly using two uniformly distributed floats [S1]. Ray sample jittering: Randomize position of samples within half a raymarch step before and after uniform steps along the ray [S1]. Ray-march through the voxel grid using step length equal to the shortest side of a voxel cell. Compute accumulated color $\hat{H}$ using the discrete volume rendering equation [S1].
    b.  **Ray Integration (Environment Maps):** After exiting the voxel grid, perform intersection tests with environment maps in order from inner to outer. Accumulate contribution similarly to the voxel grid [S1].
    c.  **Residual Calculation:** Compute residuals $r_i$ for each pixel. Each pixel has 3 residuals (one per color channel), defined as the difference between pixel color $C$ and accumulated color $\hat{H}$ [S1].
    d.  **Auxiliary Term:** Compute auxiliary penalty $L = \lambda [-4(\hat{T} - 0.5)^2 + 1]$, where $\hat{T}$ is accumulated opacity. This penalizes opacity deviations from 0 or 1 to mitigate view-dependent highlight artifacts [S1].
    e.  **Derivative Computation:** Compute partial derivatives of the first degree analytically using the iterative algorithm described below [S1].
    f.  **Gauss-Newton Update:** Solve the linear system $A x = b$ where $A = J_r^T J_r$, $x = \Delta$, and $b = -J_r^T r$. Use Preconditioned Conjugate Gradient (PCG) to solve for $\Delta$. Update $x_{i+1} = x_i + \Delta$ [S1].
    g.  **Line Search:** Apply backtracking line search to scale the step size $\gamma$ by $\alpha = 0.7$ if the error increases [S1].
    h.  **Level Completion:** When a level completes (after $N=30$ iterations), store result temporarily, reallocate buffers, populate new buffers with old data via linear interpolation, and resume optimization at the new level [S1].

**Formulas:**
*   **Discrete Volume Rendering Equation:**
    $$ \hat{H} = \sum_{t=t_n}^{t_f} \hat{T}(t)(1 - e^{-\sigma(t)\delta(t)})c(t) $$
    where $\hat{T}(t) = e^{-\sum_{s=t}^{t_f} \sigma(s)\delta(s)}$ [S1].
    Expanded form:
    $$ \hat{H} = e^{-\sum_{j=1}^N \sigma_j \delta_j} (1 - e^{-\sigma_1 \delta_1}) c_1 + e^{-\sigma_1 \delta_1} (1 - e^{-\sigma_2 \delta_2}) c_2 + \dots + e^{-\sum_{j=1}^{N-1} \sigma_j \delta_j} (1 - e^{-\sigma_N \delta_N}) c_N $$
    [S1].

*   **Objective Function:**
    $$ F[c(t), \sigma(t)] = 0.5 \sum_{t=t_n}^{t_f} \sum_{i=1}^{3} (\hat{H}_i[c_i(t), \sigma(t)] - C_i)^2 $$
    [S1].

*   **Non-linear Least-Squares General Form:**
    $$ S(x) = 0.5 \sum_{i=1}^{m} r_i(x)^2 $$
    where $r_i$ are residuals [S1].

*   **Gauss-Newton Update:**
    $$ x_{i+1} = x_i - (J_r^T J_r)^{-1} J_r^T r(x_i) = x_i + \Delta $$
    [S1].

*   **PCG System:**
    $$ A p = J_r^T J_r p = \sum_i \nabla r_i (\nabla r_i^T p) $$
    [S1].

*   **Auxiliary Penalty:**
    $$ L = \lambda [-4(\hat{T} - 0.5)^2 + 1] $$
    [S1].

**Pseudocode:**

```python
# Algorithm 1: Iterative algorithm for computation of partial derivatives
def compute_derivatives(sigma, delta, c, N):
    # sigma, delta, c are arrays of length N for the ray samples
    # Returns dH_dc and dH_dsigma for each sample
    V = exp(-sum(sigma[i] * delta[i] for i in range(N)))
    G = 0.0
    dH_dc = [0.0] * N
    dH_dsigma = [0.0] * N
    
    for i in range(N - 1, -1, -1):
        V = V - sigma[i] * delta[i]
        dH_dc[i] = exp(-V) * (1 - exp(-sigma[i] * delta[i]))
        dH_dsigma[i] = G + exp(-V) * (1 - exp(-sigma[i] * delta[i])) * c[i]
        G = exp(-V) * delta[i] * exp(-sigma[i] * delta[i]) * c[i] - delta[i] * G
        
    return dH_dc, dH_dsigma

# Algorithm 2: Preconditioned Conjugate Gradient
def pcg_solve(A_p_function, b, M_inv, x0, eps=1e-6, max_iter=3):
    r = b - A_p_function(x0)
    R_prev = dot(r, r)
    z = M_inv(r)
    p = z
    k = 0
    
    while True:
        Ap = A_p_function(p)
        alpha_k = dot(r, z) / dot(p, Ap)
        x_next = x0 + alpha_k * p
        r_next = r - alpha_k * Ap
        R = dot(r_next, r_next)
        
        if R < eps or R / R_prev > 0.85:
            return x_next
        
        R_prev = R
        z_next = M_inv(r_next)
        beta_k = dot(r_next, z_next) / dot(r, z)
        p = z_next + beta_k * p
        r = r_next
        x0 = x_next
        k += 1
        if k >= max_iter:
            return x_next

# Algorithm 3: Backtracking Line Search
def line_search(gamma, alpha, error_function):
    gamma_curr = gamma
    mu_prev = float('inf')
    
    while True:
        mu = error_function(gamma_curr)
        if mu > mu_prev:
            return gamma_curr / alpha
        gamma_curr = alpha * gamma_curr
        mu_prev = mu

# Main Optimization Step
def gauss_newton_step(x, rays, images, voxel_grid, env_maps):

    residuals = []
    gradients = [] # Sum of J_r^T r

        # Residuals (3 per pixel)

        # Compute derivatives using Algorithm 1

        # Accumulate gradient J_r^T r
        # Note: In practice, this is done efficiently by accumulating into global buffers
        # Here we show the conceptual accumulation
        for i in range(len(r)):
            gradients[i] += -r[i] * dH_dc[i] # Simplified for color channels
            
        residuals.append(r)
        
    # 2. Solve Ax = b using PCG
    # A = J_r^T J_r, b = -J_r^T r
    # M_inv is diagonal Jacobi preconditioner: diag(J_r^T J_r)
    
    # Define A_p function: Ap = sum_i grad_r_i * (grad_r_i^T p)
    def A_p(p):
        Ap = zeros_like(p)
        for ray in rays:
            # Compute grad_r_i for this ray
            grad_r = compute_gradient_for_ray(ray, p)
            Ap += grad_r * dot(grad_r, p)
        return Ap
        
    # Preconditioner M_inv
    def M_inv(v):
        # Diagonal Jacobi: 1 / diag(A)
        diag_A = compute_diagonal_A()
        return v / diag_A
        
    b = gradients # -J_r^T r
    x0 = x
    delta = pcg_solve(A_p, b, M_inv, x0)
    
    # 3. Line Search
    gamma = 1.0
    alpha = 0.7
    new_x = x + gamma * delta
    error_new = compute_error(new_x)
    error_old = compute_error(x)
    
    if error_new > error_old:

        new_x = x + gamma * delta
        
    return new_x
```

**Edge Cases and Pitfalls:**
*   **Sparsity:** $J_r$ is very sparse because only a fraction of voxels/texels are hit by a given ray. This sparsity is exploited to avoid explicit matrix inversion [S1].
*   **View-Dependence:** The method does not consider view-dependent effects, which can lead to smoke-like artifacts [S1].
*   **Precision:** The matrix $A$ is too large to form explicitly (e.g., 4TB for a $32^3$ grid) [S1].
*   **Boundaries:** Environment maps are used to handle rays exiting the voxel grid, ensuring clean separation of foreground and background for 360° scenes [S1].

## Operating characteristics
*   **Time Complexity:** 2-3 orders of magnitude faster than NERF reference. Example: Pinecone 24m:54s (Ours) vs 23h:21m (NERF) on $512^3$ grid [S1].
*   **Memory Complexity:** The matrix $A$ is too large to form explicitly. The method uses iterative solvers and sparse operations to manage memory [S1].
*   **Measured Performance:** On Nvidia Titan V GPU. Synthetic scenes run at half image resolution. 360° scenes run at quarter image resolution [S1].
*   **Scaling:** Uses a hierarchical scheme with 4-5 levels, doubling resolution per level. Initial resolution $32^3$, final $256^3$ or $512^3$ [S1].
*   **Strengths:** Fast convergence due to Gauss-Newton solver. Real-time rendering possible during training. Clean separation of foreground and background for 360° scenes [S1].
*   **Limitations:** Does not consider view-dependent effects. Quality is comparable to NERF without view-dependence but lower than full NERF or SNeRG [S1].
*   **When to use:** When fast reconstruction of 360° scenes is required and view-dependent effects are not critical.
*   **When not to use:** When high-fidelity view-dependent effects are required.

## Background
Explicit Radiance Fields (PERF) was presented by Sverker Rasmuson, Erik Sintorn, and Ulf Assarsson from Chalmers University of Technology in 2022 [S1]. The method formulates volumetric reconstruction as a non-linear least-squares problem, solving it explicitly without neural networks. This allows the use of solvers with higher convergence rates than standard Stochastic Gradient Descent used for neural networks [S1]. The work builds on the NERF formulation but replaces the MLP and ADAM optimizer with explicit voxel/environment map representation and Gauss-Newton solver [S1].
