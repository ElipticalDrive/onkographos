# SDF Onion

Also called: Onion, Onion SDF, SDF Absolute Value Offset, SDF Shell

## Overview
The SDF Onion operation creates a hollow shell or layered structure from a solid Signed Distance Field (SDF) primitive by taking the absolute value of the distance and subtracting a specified radius [S1, unofficial][S2, unofficial]. It is a specific application of [SDF Rounding](1829-sdf-rounding.md) that inverts the interior of the shape to create a void [S2, unofficial].

## How it works
**Inputs:**
1. `sdf`: A callable returning the signed distance $d$ for a query point $p$ [G].
2. `radius`: A scalar float $r \ge 0$ defining the shell offset [S2, unofficial].

**Outputs:**
* A callable returning the signed distance to the shell surface [G].

**Data Structures:**
* No complex data structures are required; the operation is a point-wise mathematical transformation applied to the output of the parent SDF [G].

**Steps:**
1. Evaluate the parent SDF at the query coordinates to obtain the signed distance $d = \text{sdf}(p)$ [S2, unofficial].
2. Compute the absolute value of the signed distance: $d_{abs} = |d|$ [S1, unofficial][S2, unofficial].
3. Subtract the radius $r$ from the absolute distance: $d_{onion} = d_{abs} - r$ [S2, unofficial].
4. Return $d_{onion}$ [S2, unofficial].

**Formula:**
$$ d_{onion}(p) = |\text{sdf}(p)| - r $$

Where:
* $p$ is the 3D query point [G].
* $\text{sdf}(p)$ is the signed distance from $p$ to the original solid shape [G].
* $r$ is the shell radius/thickness [S2, unofficial].

**Parameters:**
* `radius` ($r$): The shell thickness. Typical values depend on the scale of the parent primitive [G].

**Edge Cases and Pitfalls:**
* **Zero Thickness:** If $r=0$, the result is $|d|$, representing the unsigned distance to the surface [G].
* **Large Radius:** If $r$ exceeds the distance from the center to the nearest surface of the parent shape, the resulting SDF may be positive everywhere inside the original volume, creating a large void [G].
* **Degenerate Shapes:** For shapes with zero volume or thin surfaces, the absolute value operation combined with subtraction may produce artifacts if the radius is not carefully chosen relative to the shape's curvature [G].

**Pseudocode:**
```python
def sdf_onion(sdf_func, radius):
    """
    Creates an SDF for a hollow shell from a solid SDF.
    
    Args:
        sdf_func: A callable that takes a 3D point p and returns the signed distance.
        radius: The thickness of the shell (r >= 0).
        
    Returns:
        A callable that returns the signed distance to the shell surface.
    """
    def onion_sdf(p):
        d = sdf_func(p)
        d_abs = abs(d)
        d_onion = d_abs - radius
        return d_onion
    return onion_sdf
```

## Operating characteristics
The operation requires $O(1)$ time per query point, involving only absolute value and subtraction arithmetic on top of the parent SDF evaluation [G]. Memory complexity is $O(1)$ as no additional data structures are stored [G]. It is computationally cheap and effective for creating hollow objects, but produces uniform shell thickness and cannot generate variable thickness without more complex operations [G]. The interior of the shell is empty, which may require additional ray marching logic if the ray must stop at the inner surface [G]. Use this when a hollow version of a solid primitive is required, and avoid it when variable thickness or complex internal structures are needed [G].

## Background
The SDF Onion operation is used in ray marching and implicit surface rendering to create hollow objects [S1, unofficial][S2, unofficial]. The onion function can be applied recursively to a sphere with different radii to create layered structures [S1, unofficial].
