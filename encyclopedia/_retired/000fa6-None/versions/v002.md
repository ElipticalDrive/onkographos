# Sample Streaming Payload Ray Computation

Also called: Ray Direction Computation, SampleStreamingPayload

## Overview
Sample Streaming Payload Ray Computation regenerates ray geometry (origins and directions) from discrete pixel indices and stored camera parameters for streaming or deferred rendering pipelines [S1, S3, unofficial]. It solves the problem of resuming ray tracing or computing shadow rays by mapping pixel coordinates to world space using either a direct pinhole camera model or an NDC unprojection approach [S1, S3, unofficial]. It differs from [NDC Ray Transformation](905-ndc-ray-transformation.md) by explicitly handling the payload context (such as shadow vs. main view) and from [Stochastic Jittering](924-stochastic-jittering.md) by generating deterministic primary or shadow rays without noise injection [S1, S3, unofficial].

## How it works
The method supports two distinct computational paths depending on the ray type: **Main View Ray** reconstruction and **Shadow Ray** computation [S1, unofficial]. Both rely on the `SampleStreamingPayload` structure, which stores the pixel index and necessary camera parameters to regenerate the ray [S1, unofficial].

### Inputs and Outputs
**Inputs:**
*   `pixel_index`: Integer identifier for the pixel (or frame buffer index) [S1, unofficial].
*   `params`: A configuration object containing:
    *   `frame_size_x`, `frame_size_y`: Image dimensions $W$ and $H$ [S1, unofficial].
    *   `camera_position`: Camera origin $\mathbf{p}_{cam}$ [S1, unofficial].
    *   `camera_direction`, `camera_horizontal`, `camera_vertical`: Camera basis vectors $\mathbf{f}_{cam}$, $\mathbf{h}$, $\mathbf{v}$ [S1, unofficial].
    *   `light_directional_dir`: Direction of the light source (for shadow rays) [S1, unofficial].
    *   `wto`: World-to-object transformation matrix [S1, unofficial].
    *   `payload_org`, `payload_alpha`, `payload_color`: Stored ray attributes (for shadow rays) [S1, unofficial].
**Outputs:**
*   `Ray` structure containing:
    *   `org`: Ray origin $\mathbf{o}$ (target space) [S1, unofficial].
    *   `dir`: Ray direction $\mathbf{d}$ (normalized, target space) [S1, unofficial].
    *   `alpha`: Float payload value (for shadow rays) [S1, unofficial].
    *   `color`: Vector payload value (for shadow rays) [S1, unofficial].

### Data Structures
The `SampleStreamingPayload` typically contains:
*   `pixel_index`: `int` [S1, unofficial].
*   `org`: `vec3` (optional, used for shadow rays) [S1, unofficial].
*   `alpha`: `float` (optional) [S1, unofficial].
*   `color`: `vec3` (optional) [S1, unofficial].
The `Ray` structure contains:
*   `org`: `vec3` [S1, unofficial].
*   `dir`: `vec3` [S1, unofficial].
*   `alpha`: `float` [S1, unofficial].
*   `color`: `vec3` [S1, unofficial].

### Main View Ray Computation
This path reconstructs the primary view ray for a given pixel index [S1, unofficial].
1.  **Pixel Coordinate Extraction**:
    Compute the integer pixel coordinates $(i_x, i_y)$ from the `pixel_index` (often `fbIndex`) [S1, unofficial]:
    $$ i_x = \text{pixel\_index} \pmod W $$
    $$ i_y = \lfloor \text{pixel\_index} / W \rfloor $$
    where $W$ is the frame width [S1, unofficial].
2.  **Screen Position Normalization**:
    Compute the normalized screen position $\mathbf{s}$ in the range $[0, 1]$ by adding a $0.5$ offset for pixel centering:
    $$ s_x = \frac{i_x + 0.5}{W}, \quad s_y = \frac{i_y + 0.5}{H} $$
    [S1, unofficial].
3.  **Camera Basis Transformation**:
    Retrieve the world-to-object transformation matrix `wto` [S1, unofficial].
    *   **Origin**: Transform the camera position $\mathbf{p}_{cam}$ to the target space:
        $$ \mathbf{o} = \text{xfmPoint}(wto, \mathbf{p}_{cam}) $$
        [S1, unofficial].
    *   **Direction**: Compute the direction vector in camera space using the horizontal $\mathbf{h}$ and vertical $\mathbf{v}$ basis vectors and the camera's forward direction $\mathbf{f}_{cam}$:
        $$ \mathbf{d}_{cam} = \mathbf{f}_{cam} + (s_x - 0.5)\mathbf{h} + (s_y - 0.5)\mathbf{v} $$
        [S1, unofficial].
    *   **Target Space Direction**: Transform and normalize:
        $$ \mathbf{d} = \text{normalize}(\text{xfmVector}(wto, \mathbf{d}_{cam})) $$
        [S1, unofficial].

### Shadow Ray Computation
This path generates rays for shadow testing, often reusing a stored origin [S1, unofficial].
1.  **Transformations**: Get `wto` [S1, unofficial].
2.  **Origin**: Set $\mathbf{o}$ to the stored `org` from the payload [S1, unofficial].
3.  **Direction**: Compute the direction towards the light:
    $$ \mathbf{d} = \text{xfmVector}(wto, \text{normalize}(\text{params.light\_directional\_dir})) $$
    [S1, unofficial].
4.  **Payload**: Set `ray.alpha` and `ray.color` from the payload [S1, unofficial].

### Pseudocode
The following Python-like pseudocode combines the Main View and Shadow ray logic [S1, S3, unofficial].

```python
import numpy as np

def transform_point(mat, point):
    """Transform a 3D point by a 4x4 matrix."""
    p = np.append(point, 1.0)
    res = mat @ p
    return res[:3] / res[3]

def transform_vector(mat, vec):
    """Transform a 3D vector by the rotation part of a 4x4 matrix."""
    return mat[:3, :3] @ vec

def compute_rays(pixel_index, params, ray_type='main'):
    """
    Reconstructs ray geometry from a streaming payload.
    Args:
        pixel_index (int): The index of the pixel in the frame buffer.
        params (dict): Camera and scene parameters.
        ray_type (str): 'main' or 'shadow'.
    Returns:
        dict: Ray bundle with 'org' (vec3) and 'dir' (vec3).
    """
    W = params['frame_size_x']
    H = params['frame_size_y']
    wto = params['wto']
    
    if ray_type == 'shadow':
        # Shadow Ray Computation [S1, unofficial]
        org = params['payload_org']
        light_dir = params['light_directional_dir']
        dir_world = transform_vector(wto, light_dir / np.linalg.norm(light_dir))
        return {'org': org, 'dir': dir_world, 'alpha': params.get('payload_alpha', 1.0), 'color': np.zeros(3)}
    
    elif ray_type == 'main':
        # Main View Ray Computation [S1, unofficial]
        ix = pixel_index % W
        iy = pixel_index // W
        screen_x = (ix + 0.5) / W
        screen_y = (iy + 0.5) / H
        
        cam_pos = params['camera_position']
        forward = params['camera_direction']
        right = params['camera_horizontal']
        up = params['camera_vertical']
        
        org = transform_point(wto, cam_pos)
        dir_cam = forward + (screen_x - 0.5) * right + (screen_y - 0.5) * up
        dir_world = transform_vector(wto, dir_cam / np.linalg.norm(dir_cam))
        return {'org': org, 'dir': dir_world}
```
