# Specular Reflections via Polynomial Expansion

Also called: Fourier Projection-Slice Phong, Polynomial Phong Shading, Specular Reflections via Polynomial Approximation

## Overview
This method extends the Fourier Projection-Slice volume rendering technique to support Phong specular reflections by expanding the specular term $|N \cdot H|^n$ into a polynomial using hemispherical illumination [S1]. It solves the problem of computing view-dependent specular highlights in participating media without per-voxel shading, allowing the specular contribution to be evaluated via linear combinations of precomputed Fourier spectra [S1]. It differs from [Phong Shading](1853-phong-shading.md) by deferring the dot product evaluation to the projection domain, and from [Blinn-Phong Shading Model](2239-blinn-phong-shading-model.md) by using the exact Phong half-vector formulation expanded via the multinomial theorem [S1, S2].

## How it works
**Inputs and Outputs:**
- Input: Volume dataset $I_\Omega$, viewing direction $V$, light direction $L$, surface normal field $N$, specular exponent $n$ [S1, S2].
- Output: Rendered image $I$ [S2].

**Data Structures:**
- Precomputed Spectra: A set of 3D Fourier transforms of the volume data, indexed by the polynomial terms of the expansion. The number of spectra $K$ is determined by the multinomial theorem [S1].
- Polynomial Coefficients: Vectors $H_n$ and $N_n$ containing the combinatorial factors from the expansion of $(N \cdot H)^n$ [S2].

**Steps:**
1. **Polynomial Expansion:** Expand the term $(N \cdot H)^n$ into a sum of monomials using the multinomial theorem. Let $H_n$ be the vector of coefficients for the view/light dependent terms and $N_n$ be the vector of coefficients for the normal dependent terms [S2].
2. **Precomputation:** Compute the Fourier projection-slice spectra for the volume. For each monomial term in the expansion, a specific linear combination of the volume's Fourier transform is precomputed. The number of required spectra equals the number of terms in the expansion [S1].
3. **Per-View Rendering:**
   a. Extract the necessary slices from the precomputed spectra corresponding to the current view $V$ and light $L$ [S2].
   b. Apply the Inverse Fourier Transform to these slices to obtain spatial domain images [S2].
   c. Weight these images by the corresponding components of $H_n$ and $N_n$ [S2].
   d. Sum the weighted images to produce the final specular contribution [S2].

**Formulas:**
The integral for a viewing ray $P(t)$ is defined as [S1, S2]:
$$ I_P = \int_a^b I_\Omega(P(t)) \left[ \frac{\pi}{2} + \frac{\pi}{2} (N(P(t)) \cdot H)^n \right] dt $$
where $H$ is the halfway vector between $L$ and $V$, and $n$ is the specular exponent [S1, S2].

After factoring and applying the Fourier projection operator $\Pi_V$, the output image $I$ is [S2]:
$$ I = H_n \cdot \Pi_V \left[ \left(\frac{\pi}{2} + \frac{\pi}{2} N_n(x,y,z)\right) I_\Omega(x,y,z) \right] + c_4 \Pi_V [I_\Omega(x,y,z)] $$
where $c_4$ is a constant derived from the expansion, and $H_n, N_n$ contain the list of factors in the polynomial $(N \cdot H)^n$ [S2].

**Parameters:**
- $n$: Specular exponent. Typical value is 10 [S1].

**Edge Cases and Pitfalls:**
- Boundaries: The method assumes hemispherical illumination to avoid the absolute value operator in $|N \cdot H|$ [S1].
- Scale: The number of required spectra grows combinatorially with $n$, quickly exceeding practical limits for large exponents [S1].

**Pseudocode:**
```python
def specular_reflection_polynomial(volume, V, L, n):
    # 1. Determine polynomial terms
    # Number of spectra K is given by the multinomial theorem for degree n in 3 variables
    # K = (n+1)(n+2)(n+3)/6. For n=10, K=286 [S1]
    K = (n + 1) * (n + 2) * (n + 3) // 6
    
    # 2. Precomputed Spectra
    # spectra is a list of K precomputed Fourier projection-slice spectra
    # corresponding to the monomial terms of (N.H)^n
    spectra = volume.compute_fourier_spectra(n)
    
    # 3. Extract and Transform
    spatial_images = []
    for i in range(K):
        # Extract slice from the i-th spectrum along the current view V and light L
        slice_data = spectra[i].extract_slice_along(V, L)
        # Apply Inverse Fourier Transform to obtain spatial domain image
        img = inverse_fourier_transform(slice_data)
        spatial_images.append(img)
        
    # 4. Weight and Sum
    # H_n and N_n are vectors of coefficients for the polynomial expansion of (N.H)^n
    H_n = compute_view_light_coefficients(V, L, n)
    N_n = compute_normal_coefficients(n)
    
    result = 0.0
    for i in range(K):
        weight = H_n[i] * N_n[i]
        result += weight * spatial_images[i]
        
    # Add constant term c_4 * projection of volume
    c_4 = compute_constant_c4(n)
    result += c_4 * inverse_fourier_transform(spectra[0].extract_slice_along(V, L))
    
    return result

def inverse_fourier_transform(data):
    # Standard operation: compute the inverse discrete Fourier transform
    return [complex_val.real for complex_val in data]

def compute_view_light_coefficients(V, L, n):
    # Standard operation: compute view/light dependent factors from (N.H)^n expansion
    H = [(V[j] + L[j]) / 2.0 for j in range(3)]
    return generate_multinomial_H(n, H)

def compute_normal_coefficients(n):
    # Standard operation: generate normal dependent factors
    return generate_multinomial_N(n)

def compute_constant_c4(n):
    # Standard operation: compute constant from expansion
    return 0.5 - 0.5 * sum(generate_multinomial_N(n))
```

## Subtopics

### Polynomial Depth Cueing
Polynomial Depth Cueing is an adaptation of the specular reflection method to provide non-linear depth cueing, such as inverse square law falloff, by replacing the normal $N$ and halfway vector $H$ with the depth vector $D$ and view vector $V$ in the polynomial expansion [S2]. For an inverse square law falloff using $(D \cdot V)^2$, 10 slices from 10 precomputed spectra are required [S2].

### [Simple Reflections](1234-simple-reflections.md)
Simple Reflections is a local illumination technique that calculates a reflected ray direction off a surface normal and raymarches along it, blending the result with the surface color.

## Operating characteristics
- **Time Complexity:** The rendering time is proportional to the number of precomputed spectra, which grows combinatorially with $n$ according to the multinomial theorem [S1].
- **Memory Complexity:** Requires storing $K$ precomputed spectra, where $K$ is the number of terms in the polynomial expansion [S1].
- **Measured Performance:** For $n=10$, 286 precomputed spectra are needed, making this extension slower than conventional volume rendering even for very large volumes [S1].
- **Strengths:** Allows view-dependent specular highlights in volume rendering without per-voxel shading [S1].
- **Limitations:** High memory and computational cost for large $n$; limited to polynomial approximations of the specular term [S1].
- **When to use:** When view-dependent specular highlights are critical and computational resources allow for precomputation of many spectra [G].
- **When not to use:** For real-time applications or when $n$ is large, due to the high number of required spectra [G].

## Background
This method extends the basic Fourier projection-slice volume rendering technique to include Phong-like shading models [S1]. The approach leverages the linearity of the Fourier projection operator to decompose the non-linear specular term into a sum of linear terms [S2].
