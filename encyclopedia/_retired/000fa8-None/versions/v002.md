# Polynomial Depth Cueing

Also called: Specular Reflections via Polynomial Depth Cueing, Specular Shading, Fourier Projection-Slice with Polynomial Depth Cueing

## Overview
Polynomial Depth Cueing is an extension of the Fourier projection-slice volume rendering method that replaces linear attenuation with non-linear depth cues, such as inverse square law falloff, or models specular reflections using the Phong illumination model [S1, S2, unofficial]. It sets itself apart from standard linear attenuation by allowing steeper intensity falloff to disambiguate depth relationships in high-complexity scenes, but at the cost of requiring a large number of precomputed spectra determined by the multinomial theorem [S1, unofficial].

## How it works
**Inputs:**
*   Volume dataset $V(\mathbf{x}, \mathbf{y}, \mathbf{z})$ containing scalar values [G].
*   View direction vector $\mathbf{V}$ [S1, unofficial].
*   Light direction vector $\mathbf{L}$ [S1, unofficial].
*   Surface normal field $\mathbf{N}(\mathbf{x}, \mathbf{y}, \mathbf{z})$ [S1, unofficial].
*   Specular exponent $n$ (integer $\ge 1$) [S1, unofficial].
*   Source intensity $I_s$ and opacity function $\Omega$ [S1, unofficial].

**Outputs:**
*   Rendered image intensity $I$ [S1, unofficial].

**Data Structures:**
*   **Precomputed Spectra:** A set of $K$ 2D Fourier spectra, where $K$ is the number of terms in the polynomial expansion [S1, unofficial].
*   **Weighting Vectors:** $\mathbf{H}_n$ and $\mathbf{N}_n$ (or $\mathbf{D}_n$) containing the coefficients and vector components derived from the polynomial expansion [S1, unofficial].

**Steps:**
1.  **Determine Polynomial Expansion:** Expand the term $(\mathbf{N} \cdot \mathbf{H})^n$ into a polynomial using the multinomial theorem, where $\mathbf{H}$ is the halfway vector between $\mathbf{L}$ and $\mathbf{V}$ [S1, unofficial]. For polynomial depth cueing, replace $\mathbf{N}$ with the viewing ray direction $\mathbf{D}$ and $\mathbf{H}$ with $\mathbf{V}$ to model non-linear attenuation [S1, S2, unofficial].
2.  **Precompute Spectra:** Compute the 2D Fourier spectra for each term in the expanded polynomial [S1, unofficial]. The number of spectra $K$ corresponds to the number of terms [S1, unofficial]. For $n=10$, $K=286$ [S1, unofficial]. For inverse square law falloff $(\mathbf{D} \cdot \mathbf{V})^2$, $K=10$ spectra are required [S2, unofficial].
3.  **Apply Fourier Projection-Slice Theorem:** Apply the Fourier projection operator $\Pi_V$ along the view direction $\mathbf{V}$ to each precomputed spectrum [S1, unofficial].
4.  **Compute Final Intensity:** Combine the projections into a weighted sum [S1, unofficial]. For specular reflections:
    $$I = \mathbf{H}_n \cdot \Pi_V\left(\frac{\pi}{2} + \frac{\pi}{2} \mathbf{N}_n(\mathbf{x}, \mathbf{y}, \mathbf{z})\right) I_s \Omega(\mathbf{x}, \mathbf{y}, \mathbf{z}) + c_4 \Pi_V[I_s \Omega(\mathbf{x}, \mathbf{y}, \mathbf{z})]$$
    where $\mathbf{H}_n$ and $\mathbf{N}_n$ contain the factors from the polynomial expansion of $(\mathbf{N} \cdot \mathbf{H})^n$, and $c_4$ is a suitable constant [S1, unofficial]. For depth cueing, replace $\mathbf{N}$ and $\mathbf{H}$ with $\mathbf{D}$ and $\mathbf{V}$ in the weighting equations and adjust constants accordingly [S1, S2, unofficial].

**Pseudocode:**
```python
def polynomial_depth_cueing(volume, V, L, N, n, Is, Omega):
    # 1. Determine polynomial expansion and number of spectra K
    # For specular: expand (N . H)^n using multinomial theorem
    # For depth cueing: replace N with D (ray direction), H with V
    # K = number of terms from multinomial theorem [S1, unofficial]
    K = compute_multinomial_terms(n)
    
    # 2. Precompute K 2D Fourier spectra [S1, unofficial]
    spectra = []
    for term in polynomial_terms(n, mode='specular'): # or 'depth'
        # Compute 2D FFT of the term's spatial distribution [G]
        spec = fft2d(term)
        spectra.append(spec)
        
    # 3. Apply Fourier projection operator Pi_V along view direction V [S1, unofficial]
    projections = []
    for spec in spectra:
        # Slice theorem: inverse 1D FFT of the 2D spectrum slice along V [G]
        proj = ifft1d(slice_along_axis(spec, axis=V))
        projections.append(proj)
        
    # 4. Compute final image as weighted sum [S1, unofficial]
    # For specular: I = H_n . Pi_V(pi/2 + pi/2 N_n) Is Omega + c4 Pi_V[Is Omega]
    # For depth cueing: replace N_n with D_n, adjust constants [S1, S2, unofficial]
    image = zeros_like(volume)
    for i in range(K):
        image += weights[i] * projections[i]
        
    return image
```

**Parameters:**
*   $n$: Specular exponent or polynomial degree. Typical value $n=10$ [S1, unofficial].
*   $I_s$: Source intensity [S1, unofficial].
*   $\Omega$: Opacity function [S1, unofficial].

**Pitfalls:**
*   **Performance:** The number of required spectra grows rapidly with $n$. For $n=10$, 286 spectra are needed, making the method significantly slower than conventional volume rendering, even for large volumes [S1, unofficial].
*   **Precision:** High-degree polynomials may suffer from numerical instability if not carefully implemented [G].
*   **Boundary Conditions:** Ensure that vectors $\mathbf{N}, \mathbf{H}, \mathbf{D}, \mathbf{V}$ are properly normalized before dot products to avoid incorrect intensity scaling [G].

## Operating characteristics
*   **Time Complexity:** $O(K \cdot N \log N)$, where $K$ is the number of spectra (dependent on $n$) and $N$ is the number of voxels, dominated by the FFT per spectrum [G].
*   **Memory Complexity:** $O(K \cdot N)$ to store the precomputed spectra and intermediate projections [G].
*   **Strengths:** Provides non-linear depth cues (e.g., inverse square law) to disambiguate depth in high-complexity scenes, and models Phong specular reflections [S1, S2, unofficial].
*   **Limitations:** High computational cost due to the large number of required spectra for high-degree polynomials [S1, unofficial].
*   **When to Use:** When visual quality of specular reflections or depth cueing is critical and performance is not the primary constraint [G].
*   **When Not to Use:** For real-time applications or scenes with limited computational resources, especially if high $n$ values are required [G].

## Background
Polynomial Depth Cueing was introduced by Marc Levoy in his 1992 paper "Volume Rendering using the Fourier Projection-Slice Theorem" as an extension to handle specular reflections and non-linear depth attenuation [S1, S2, unofficial]. It builds on the Fourier projection-slice method by incorporating the Phong specular model and multinomial expansion [S1, unofficial]. The method was demonstrated on CT scan data of a human skull [S1, S2, unofficial].
