# MultiPlane NeRF

Also called: MultiPlaneNeRF, MultiPlane GAN decoder

## Overview
MultiPlane NeRF is a radiance field representation that replaces trainable 3D latent structures (such as voxels or feature grids) with a fixed set of $n$ pre-existing 2D images [S1]. It solves the problem of parameter efficiency in neural rendering by enabling a small implicit decoder to reconstruct 3D scenes without optimizing a volumetric representation [S1]. Unlike [TriPlane](15530-triplane.md) which uses trainable feature planes, MultiPlane NeRF uses non-trainable RGB images, resulting in an explicit representation with fewer parameters [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $n$ training images $I_i$ for $i=1, \dots, n$, each with resolution $N \times N \times 3$ [S1]. A 3D point $x = (x, y, z) \in \mathbb{R}^3$ and a viewing direction $d$ [S1]. For generalization tasks, camera positions $P(I_i)$ associated with each image are also provided [S1].
*   **Outputs:** RGB color $c \in \mathbb{R}^3$ and volume density $\sigma \in \mathbb{R}$ [S1].

**Data Structures:**
The representation consists of $n$ static 2D images $I_i$. These images are stored with the model weights and are not updated during training [S1]. The implicit decoder $F_{\text{MultiPlaneNeRF}}$ contains approximately 0.5 million parameters [S1].

**Algorithm:**
1.  **Projection:** For each image $I_i$, project the 3D point $x$ onto the 2D image plane to obtain 2D coordinates $z_{I_i}$ [S1]:
    $$ \text{Pr}(x, I_i) = z_{I_i} \in \mathbb{R}^2 $$
    where $z_{I_i}$ represents the point in $\mathbb{R}^2$ created by projecting $x$ on image $I_i$ [S1].

2.  **Color Sampling:** Sample the RGB color from each image $I_i$ at the projected coordinates $z_{I_i}$ using linear interpolation to handle rays that do not cross pixel centers [S1]:
    $$ \text{Color}_i = I_i[z_{I_i}] \in \mathbb{R}^3 $$

3.  **Feature Aggregation:** Construct the input vector $Z$ for the implicit decoder by concatenating the sampled colors and projected coordinates for all $n$ images [S1]:
    $$ Z(x, y, z) = [I_1[z_{I_1}], z_{I_1}, \dots, I_n[z_{I_n}], z_{I_n}] \in \mathbb{R}^{5n} $$
    where $I_i[z_{I_i}] \in \mathbb{R}^3$ is the RGB color and $z_{I_i} \in \mathbb{R}^2$ is the projected position [S1].

    *For generalization tasks:* Include the camera position $P(I_i)$ for each image in the input vector [S1]:
    $$ Z(x, y, z) = [I_1[z_{I_1}], z_{I_1}, P(I_1), \dots, I_n[z_{I_n}], z_{I_n}, P(I_n)] \in \mathbb{R}^{8n} $$
    where $P(I_i)$ is the position of the camera dedicated to image $I_i$ [S1].

4.  **Decoding:** Pass the aggregated input $Z$ to the implicit decoder $F_{\text{MultiPlaneNeRF}}$ to produce the output color $c$ and density $\sigma$ [S1]:
    $$ F_{\text{MultiPlaneNeRF}}(x, d, I_1, \dots, I_n; \Theta) = (c, \sigma) $$
    or for generalization:
    $$ F_{\text{MultiPlaneNeRF}}(x, d; \Theta, I_1, P(I_1), \dots, I_n, P(I_n)) = (c, \sigma) $$
    where $\Theta$ are the decoder parameters [S1].

5.  **Rendering:** Use the standard NeRF volume rendering procedure and loss function [S1].

    n = len(images)

        # I_i[z_I_i]
        color_i = sample_image_linear(images[i], z_i)
        
        # Step 3: Concatenate color and coordinates
        # z_I_i is (2,), color_i is (3,)
        features.append(color_i)

**Parameters:**
*   $n$: Number of input images. Performance improves with increasing $n$ [S1].
*   $N$: Resolution of input images. Results are best when training image resolution matches expected render resolution (e.g., $800 \times 800$) [S1].
*   Training epochs: 40,000 [S1].

**Edge Cases and Pitfalls:**
*   **Ray Intersection:** Rays may not cross pixel centers; linear interpolation is required to avoid artifacts [S1].
*   **Generalization:** Camera positions $P(I_i)$ are only necessary for generalization tasks (unseen objects/classes); they do not change rendering results for single-object training [S1].
*   **Storage:** The $n$ images are part of the architecture and must be stored with the model weights [S1].

## Operating characteristics
*   **Complexity:** The implicit decoder uses $\sim 0.5$M parameters, significantly fewer than hybrid methods like NSVF which require different data structures optimized during training [S1].
*   **Performance:** MultiPlane NeRF achieves better results than auto-encoder based methods (e.g., Points2NeRF) on test sets [S1]. In generalization tasks (MultiPlaneGAN), it achieves second-best scores on FFHQ and ShapeNet Cars, slightly worse than EG3D GAN but with interpretable 2D image representations [S1].
*   **Scaling:** PSNR improves as the number of images $n$ increases [S1].
*   **Strengths:** Efficient parameter count, interpretable representation (2D images), no trainable 3D representation scheme [S1].
*   **Limitations:** Requires pre-existing 2D images; performance depends on image resolution matching render resolution [S1].

## Background
MultiPlane NeRF was introduced as a step toward efficient and expressive 3D object representation, building on the NeRF framework [S1]. It was used as a decoder in the EG3D GAN architecture, replacing the TriPlane representation to create MultiPlaneGAN [S1]. The method was evaluated on Diffuse Synthetic 360° and Realistic Synthetic 360° datasets, as well as the Points2NeRF dataset for generalization tasks [S1].
