# Full Propagator Approximation for Multiply-Scattered Radiance

Also called: Approximate G_s, Multiply-Scattered Radiance Formula

## Overview
The Full Propagator Approximation computes the radiance contribution from multiple scattering events by approximating the path integral over a reduced subset of paths surrounding the Most Probable Path (MPP) [S1]. It replaces the intractable integration over complete path space with an integration over a Gaussian support perpendicular to the MPP [S1].

## How it works
**Inputs:**
*   $s$: Total path length [S1].
*   $\mathbf{x}$: Position on the view ray [S1].
*   $\vec{\omega}$: View direction [S1].
*   $\vec{\omega}'$: Incoming direction from a directional light source [S1].
*   $b(\mathbf{x}') L_0(\mathbf{x}', \vec{\omega}')$: Singly scattered radiance source term [S1].
*   $c(\cdot)$: Extinction coefficient function [S1].
*   $P_{MS}(\cdot)$: Multiply-scattered phase function [S1].
*   $w(s)$: Gaussian width function [S1].
*   $C$: Normalization constant [S1].

**Outputs:**
*   $L(s, \mathbf{x}, \vec{\omega})$: Multiply-scattered radiance [S1].

**Data Structures:**
*   **MPP (Most Probable Path):** A geometric path defined by the start point, end point, and curvature parameters for total length $s$, serving as the center of the Gaussian distribution [S1].
*   **Gaussian Support:** A plane perpendicular to the MPP at position $\mathbf{x}$ over which the source integration occurs [S1].

**Steps:**
1.  Use the singly scattered radiance $b(\mathbf{x}') L_0(\mathbf{x}', \vec{\omega}')$ as the source $Q$ for multiply scattered light [S1].
2.  Replace the integral over complete path space with an integral over only paths surrounding the MPP [S1].
3.  Treat the first term (absorption) in the propagator equation as approximately constant for all paths in the reduced space and extract it from the path integral [S1].
4.  Express the second term (action) and extract $\exp(-A_c(\text{MPP}_s))$ from the path integral [S1].
5.  Approximate the remaining path integral fraction using the multiply-scattered phase function $P_{MS}(\vec{\omega} - \vec{\omega}')$, which gives the probability of light being scattered by a given angle after a given number of scattering events [S1]. This assumes single scattered light is strongly forward peaked and ignores angular spreading from single scattering [S1].
6.  Integrate only over the support of the Gaussian (plane perpendicular to MPP) [S1].
7.  Combine extracted attenuation, action, phase function, and integrated source term [S1].

**Formula:**
The final expression for multiply-scattered radiance is:

$$ L(s, \mathbf{x}, \vec{\omega}) = \exp \left( - \int_0^s c(\text{MPP}_s(s')) ds' \right) \exp(-A_c(\text{MPP}_s)) \times P_{MS}(\vec{\omega} - \vec{\omega}') \int_{plane\perp \text{MPP}} gauss(\mathbf{x}', w(s)) b(\mathbf{x}') L_0(\mathbf{x}', \vec{\omega}') d\mathbf{x}' $$

Where:
*   $gauss(\mathbf{x}', w(s))$ is a Gaussian function of width $w(s)$ applied at position $\mathbf{x}$ [S1].
*   $A_c$ represents the curvature part of the action function [S1].
*   $C$ is a normalization constant included in the derivation of the general propagator $G_s$ but absorbed into the phase function and Gaussian definitions in the final radiance equation [S1].

**Pseudocode:**
```python
import math

def compute_multiply_scattered_radiance(s, x, omega, omega_prime, b_L0_func, c_func, mpp_path, w_s, P_MS_func):
    """
    Computes L(s, x, omega) using the Full Propagator Approximation.
    mpp_path: list of 3D points along the Most Probable Path.
    """
    # 1. Integrate extinction coefficient along the MPP
    attenuation_integral = 0.0
    for i in range(len(mpp_path) - 1):
        p_curr, p_next = mpp_path[i], mpp_path[i+1]
        segment_len = math.sqrt(sum((p_next[k] - p_curr[k])**2 for k in range(3)))
        attenuation_integral += c_func(p_curr) * segment_len
    attenuation_factor = math.exp(-attenuation_integral)

    # 2. Evaluate action (curvature) factor at MPP
    # [G] Assuming mpp_path stores the cumulative curvature action at each point
    action_factor = math.exp(-mpp_path[-1].curvature_action)

    # 3. Evaluate phase function probability
    phase_prob = P_MS_func(omega - omega_prime)

    # 4. Integrate source term over Gaussian support plane perpendicular to MPP
    # [G] Define a local 2D coordinate system on the plane perpendicular to MPP at x
    # For implementation, we sample a grid on this plane
    source_integral = 0.0
    grid_step = 0.01  # [G] numerical integration step size
    grid_radius = 5   # [G] number of steps in each direction
    for u in range(-grid_radius, grid_radius + 1):
        for v in range(-grid_radius, grid_radius + 1):
            # Construct point x' on the plane
            x_prime = [x[k] + u * grid_step * (1 if k == 0 else 0) + v * grid_step * (1 if k == 1 else 0) for k in range(3)]
            dist_to_center = math.sqrt(sum((x_prime[k] - x[k])**2 for k in range(3)))
            gaussian_weight = math.exp(-0.5 * (dist_to_center / w_s)**2)
            source_integral += gaussian_weight * b_L0_func(x_prime) * (grid_step ** 2)

    # 5. Combine all factors
    radiance = attenuation_factor * action_factor * phase_prob * source_integral
    return radiance
```

**Parameters:**
*   $C$: Normalization constant [S1].
*   $w(s)$: Gaussian width [S1].

**Edge Cases and Pitfalls:**
*   **Forward Peaking Assumption:** The method assumes single scattered light is strongly forward peaked and ignores angular spreading from single scattering [S1].
*   **Integration Bounds:** The integration is strictly limited to the Gaussian support plane perpendicular to the MPP [S1].

## Operating characteristics
*   **Time Complexity:** Depends on evaluating the MPP, the action function, and the 2D plane integration, which is cheaper than full path space integration [S1].
*   **Memory Complexity:** Requires storing the MPP and associated parameters [S1].
*   **Strengths:** Provides a deterministic approximation for multiple scattering that retains directional information via the phase function [S1].
*   **Limitations:** Approximation errors arise from the Gaussian assumption and forward-peaking assumption [S1].
*   **When to Use:** When multiple scattering is significant, full path tracing is too expensive, and the medium exhibits forward-peaked scattering [S1].

## Background
The method is described in the paper "Practical Rendering of Multiple Scattering Effects in Participating Media" by Raviraj Pajarala et al. [S1]. It builds upon the concept of the Most Probable Path (MPP) and approximates the path integral for the multiply-scattered propagator $G_s$ [S1].
