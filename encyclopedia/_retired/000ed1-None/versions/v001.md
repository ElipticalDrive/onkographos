# Full Propagator Approximation for Multiply-Scattered Radiance

Also called: Approximate G_s, Multiply-Scattered Radiance Formula

## Overview
The Full Propagator Approximation computes the radiance contribution from multiple scattering events by approximating the path integral over a reduced subset of paths surrounding the Most Probable Path (MPP). It solves the problem of efficiently estimating the energy transfer in participating media where single scattering is insufficient, by replacing the intractable integration over complete path space with an integration over a Gaussian support perpendicular to the MPP. It differs from the [Diffusion Approximation](2372-diffusion-approximation.md) by retaining directional phase function information rather than assuming isotropic diffusion, and from the [Monte Carlo Method for Multiple Scattering](1940-monte-carlo-method-for-multiple-scattering.md) by using a deterministic approximation of the path space rather than stochastic sampling.

## How it works
**Inputs:**
*   Position $s$ along the view ray.
*   Position $\mathbf{x}$ on the view ray.
*   View direction $\vec{\omega}$.
*   Incoming direction $\vec{\omega}'$ (assumed from directional light source).
*   Singly scattered radiance source term $b(\mathbf{x}') L_0(\mathbf{x}', \vec{\omega}')$.
*   Extinction coefficient function $c(\cdot)$.
*   Multiply-scattered phase function $P_{MS}(\cdot)$.
*   Gaussian width function $w(s)$.
*   Normalization constant $C$.

**Outputs:**
*   Multiply-scattered radiance $L(s, \mathbf{x}, \vec{\omega})$.

**Data Structures:**
*   **MPP (Most Probable Path):** A geometric path $\text{MPP}_s$ defined by the start point, end point, and curvature parameters for a total length $s$. It serves as the center of the Gaussian distribution.
*   **Gaussian Support:** A plane perpendicular to the MPP at position $\mathbf{x}$. Integration occurs over this 2D plane.

**Steps:**
1.  **Identify the Source:** Use the singly scattered radiance $b(\mathbf{x}') L_0(\mathbf{x}', \vec{\omega}')$ as the source term $Q$ for the multiple scattering calculation.
2.  **Define the Path Space Reduction:** Replace the integral over the complete path space with an integral over paths surrounding the MPP.
3.  **Approximate Absorption:** Treat the first term of the general propagator equation (standard single path attenuation) as approximately constant for all paths in the reduced space and extract it from the integral. This term is evaluated along the MPP:
    $$ \exp \left( - \int_0^s c(\text{MPP}_s(s')) ds' \right) $$
4.  **Approximate Action/Probability:** Extract the exponential of the action function $A_c$ (curvature part) evaluated at the MPP from the integral:
    $$ \exp(-A_c(\text{MPP}_s)) $$
5.  **Apply Phase Function:** The remaining path integral represents the fraction of paths satisfying boundary conditions. This is approximated by the multiply-scattered phase function $P_{MS}(\vec{\omega} - \vec{\omega}')$, which gives the probability of light being scattered by the angle $\vec{\omega} - \vec{\omega}'$ after the given number of scattering events. This assumes single scattered light is strongly forward peaked and ignores angular spreading from single scattering.
6.  **Integrate over Gaussian Support:** Perform the integration only over the support of the Gaussian distribution centered on the MPP. The Gaussian $gauss(\mathbf{x}', w(s))$ is defined with width $w(s)$ at position $\mathbf{x}$.
7.  **Combine Terms:** Multiply the extracted attenuation, action, phase function, and the integrated source term.

**Formula:**
The final expression for multiply-scattered radiance is:

$$ L(s, \mathbf{x}, \vec{\omega}) = \exp \left( - \int_0^s c(\text{MPP}_s(s')) ds' \right) \exp(-A_c(\text{MPP}_s)) \times P_{MS}(\vec{\omega} - \vec{\omega}') \int_{plane\perp \text{MPP}} gauss(\mathbf{x}', w(s)) b(\mathbf{x}') L_0(\mathbf{x}', \vec{\omega}') d\mathbf{x}' $$

Where:
*   $gauss(\mathbf{x}', w(s))$ is a Gaussian function of width $w(s)$ applied at position $\mathbf{x}$.
*   $A_c$ represents the curvature part of the action function.
*   $C$ is a normalization constant included in the derivation of the general propagator $G_s$ but absorbed or handled within the $P_{MS}$ and Gaussian definitions in the final radiance equation as presented in the source.

**Pseudocode:**
```python
def compute_multiply_scattered_radiance(s, x, omega, omega_prime, b_L0_func, c_func, mpp_s, w_s, P_MS_func):
    """
    Computes L(s, x, omega) using the Full Propagator Approximation.
    
    Args:
        s: Total path length.
        x: Position on the view ray.
        omega: View direction.
        omega_prime: Incoming light direction.
        b_L0_func: Function returning b(x') * L_0(x', omega_prime).
        c_func: Extinction coefficient function c(x).
        mpp_s: The Most Probable Path object for length s.
        w_s: Gaussian width at position s.
        P_MS_func: Multiply-scattered phase function P_MS(omega - omega_prime).
        
    Returns:
        Radiance value.
    """
    # Step 1: Compute attenuation along the MPP
    # Integral of extinction coefficient along the MPP path
    attenuation_integral = integrate_along_path(mpp_s, c_func)
    attenuation_factor = exp(-attenuation_integral)
    
    # Step 2: Compute action (curvature) factor at MPP
    # A_c is the curvature part of the action function evaluated at MPP
    action_factor = exp(-mpp_s.curvature_action())
    
    # Step 3: Get phase function probability
    phase_prob = P_MS_func(omega - omega_prime)
    
    # Step 4: Integrate source term over Gaussian support
    # The support is the plane perpendicular to the MPP at position x
    # gauss(x', w(s)) is the Gaussian weight
    # b_L0_func(x') is the singly scattered source
    
    def integrand(x_prime):
        # Gaussian centered on MPP with width w_s
        # Distance from x_prime to the MPP center line at this cross-section
        dist = distance_to_mpp_plane(x_prime, mpp_s, x)
        gaussian_weight = gaussian(dist, w_s)
        
        source = b_L0_func(x_prime)
        return gaussian_weight * source

    # Integrate over the 2D plane perpendicular to MPP
    # Note: The exact bounds and integration method depend on the specific 
    # implementation of "plane_perp_mpp". For a local approximation, 
    # this might be a small patch or the entire plane if the Gaussian decays fast.
    source_integral = integrate_over_plane(integrand, mpp_s, x)
    
    # Step 5: Combine all factors
    radiance = attenuation_factor * action_factor * phase_prob * source_integral
    
    return radiance
```

**Parameters:**
*   $C$: Normalization constant. [S1, unofficial]
*   $w(s)$: Gaussian width. [S1, unofficial]

**Edge Cases and Pitfalls:**
*   **Forward Peaking Assumption:** The method assumes single scattered light distribution is strongly forward peaked. If the phase function is not forward peaked, the approximation of ignoring angular spreading may introduce errors. [S1, unofficial]
*   **MPP Construction:** The accuracy depends heavily on the correct construction of the Most Probable Path (MPP) for the given length $s$. [S1, unofficial]
*   **Integration Bounds:** The integration is limited to the support of the Gaussian. If the Gaussian width is too large or too small, the approximation may miss significant contributions or include negligible ones. [S1, unofficial]

## Operating characteristics
*   **Time Complexity:** Depends on the cost of evaluating the MPP, the action function, and the integration over the Gaussian support. The integration is over a 2D plane, which is cheaper than the full path space.
*   **Memory Complexity:** Requires storing the MPP and associated parameters.
*   **Strengths:** Provides a deterministic approximation for multiple scattering that is more efficient than full Monte Carlo path tracing for multiple bounces. Retains directional information via the phase function.
*   **Limitations:** Approximation errors arise from the Gaussian assumption and the forward-peaking assumption. Not suitable for highly anisotropic or backward-scattering media without modification.
*   **When to Use:** When multiple scattering effects are significant, but full path tracing is too expensive, and the medium exhibits forward-peaked scattering.

## Background
The method is described in the paper "Practical Rendering of Multiple Scattering Effects in Participating Media" by Raviraj Pajarala et al. [S1, unofficial]. It builds upon the concept of the Most Probable Path (MPP) and approximates the path integral for the multiply-scattered propagator $G_s$.
