# Forward Linear Inclusion Function
Also called: Linear Bounding Function, Linear Inclusion Function

## Overview
The Forward Linear Inclusion Function computes a conservative interval bound for a scalar field $f$ along a ray, ensuring that the true function value lies within the calculated bounds for all points ahead of the current sample. It solves the problem of determining a safe maximum step size for sphere tracing by intersecting these linear bounds with the zero-level threshold. It sets itself apart from its siblings, such as the [Improved Quadratic Taylor Inclusion Function](1902-improved-quadratic-taylor-inclusion-function.md), by using first-order linear approximations rather than second-order quadratic ones, making it computationally cheaper but potentially less tight for highly curved fields [S1].

## How it works
**Inputs and Outputs**
*   **Input:** The current sample location on the ray $t_0$, the function value at that location $f(t_0)$, and the Lipschitz constant $\lambda$ for the function $f$ over the domain of interest.
*   **Output:** An interval $[f](t) = [f_-(t), f_+(t)]$ for $t > t_0$, and the computed step size $\Delta t$ to the next safe sample point.

**Data Structures**
No complex data structures are required. The method relies on scalar values for $t_0$, $f(t_0)$, and $\lambda$.

**Steps**
1.  **Evaluate Function:** Compute the scalar field value $v = f(t_0)$ at the current ray position $t_0$.
2.  **Define Bounds:** Construct the lower bound $f_-(t)$ and upper bound $f_+(t)$ as linear functions starting from $v$ at $t_0$. The slope of the upper bound is $\lambda$ and the lower bound is $-\lambda$.
    $$ f_-(t) = f(t_0) - \lambda(t - t_0) $$
    $$ f_+(t) = f(t_0) + \lambda(t - t_0) $$
    This forms a "bounding cone" originating at $(t_0, f(t_0))$ [S1].
3.  **Compute Step Size:** Determine the distance to the zero-level set (or threshold $v_{th}$, typically 0) by finding the intersection of the bounding lines with the threshold. Since the bounds are symmetric around $f(t_0)$, the step size is determined by the magnitude of the function value divided by the Lipschitz constant:
    $$ \Delta t = \frac{|f(t_0)|}{\lambda} $$
    If $f(t_0) = 0$, the surface is hit exactly, and $\Delta t = 0$ [S1].
4.  **Advance Ray:** Update the ray position to $t_{new} = t_0 + \Delta t$.

**Pseudocode**
```python
def forward_linear_inclusion_step(f, t0, lambda_val):
    """
    Computes the next step size for sphere tracing using forward linear inclusion.
    
    Args:
        f: A callable that evaluates the scalar field f(t) at position t.
        t0: The current position on the ray (scalar).
        lambda_val: The Lipschitz constant for f (scalar, >= 0).
        
    Returns:
        delta_t: The safe step size to advance along the ray.
    """
    # Evaluate the scalar field at the current position
    f_t0 = f(t0)
    
    # Handle exact hit
    if f_t0 == 0.0:
        return 0.0
    
    # Compute step size: distance to zero crossing of the linear bound
    # The bound is f(t0) +/- lambda * (t - t0)
    # Intersection with 0: 0 = f(t0) + lambda * (t - t0) => t - t0 = -f(t0)/lambda
    # We take the absolute value for the forward step size
    delta_t = abs(f_t0) / lambda_val
    
    return delta_t
```

**Parameters**
*   $\lambda$: The Lipschitz constant. It must be an upper bound on the magnitude of the gradient of $f$ ($\|\nabla f\| \leq \lambda$). Typical values depend on the specific noise or implicit function being rendered. If $\lambda$ is too small, the bound is invalid and the ray may tunnel through the surface. If $\lambda$ is too large, the step size becomes unnecessarily small, reducing performance [S1].

**Edge Cases and Pitfalls**
*   **Zero Lipschitz Constant:** If $\lambda = 0$ and $f(t_0) \neq 0$, division by zero occurs. This implies the function is constant, which is a degenerate case for surface rendering. [G] Implementers should check for $\lambda < \epsilon$ and handle it as an error or infinite step.
*   **Inaccurate Lipschitz Constant:** The method assumes $\lambda$ is a valid global or local Lipschitz constant. If the actual gradient exceeds $\lambda$, the inclusion property is violated, leading to visual artifacts (tunneling).
*   **Precision:** For very small $|f(t_0)|$, floating-point precision errors in the division may result in tiny step sizes. [G] A minimum step size threshold may be applied to prevent infinite loops in flat regions.

## Subtopics

### [Improved Quadratic Taylor Inclusion Function](1902-improved-quadratic-taylor-inclusion-function.md)
Uses second-order Taylor expansion to provide tighter bounds for functions with significant curvature, switching to linear bounds when the quadratic derivative exceeds the first-order limit. Choose this when the scalar field has high curvature and $\lambda$ is large relative to the second derivative, allowing for larger steps than the linear method.

## Operating characteristics
**Time and Memory Complexity**
*   **Time:** $O(1)$ per step. The calculation involves one function evaluation, one absolute value, and one division.
*   **Memory:** $O(1)$. No additional memory is required beyond the scalar values.

**Measured Performance**
*   The method is the baseline for sphere tracing performance. It is faster than quadratic methods but may require more steps if the Lipschitz constant is loose. [S1]

**Strengths and Limitations**
*   **Strengths:** Simple to implement, computationally inexpensive, and provides a rigorous guarantee of no tunneling if $\lambda$ is valid.
*   **Limitations:** The bounds are often loose for functions with high curvature, leading to smaller step sizes than necessary. It does not account for the second derivative of the function.

**When to Use**
*   Use when computational resources are limited or when the scalar field is relatively linear over the step size. It is also useful as a fallback or comparison baseline for more complex inclusion functions.

## Background
The concept of forward inclusion functions was formalized in the context of sphere tracing for procedural volumetric noise. The specific formulation of the forward linear inclusion function is attributed to [AZ23] as cited in [S1]. It builds upon the general theory of interval arithmetic and Lipschitz continuity applied to ray marching.
