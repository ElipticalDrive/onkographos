# Bilinear Interpolation

Also called: 2D Bilinear Sampling, Bilinear Image Sampling, Bilinear Image Sampling at XY Grid, F.grid_sample with bilinear mode, Grid Sample Bilinear, Grid with Bilinear Interpolation, Tri-linear Interpolation on GPU

## Overview
Bilinear interpolation estimates values at arbitrary 2D coordinates using the four nearest grid points [S3]. In volume rendering, it samples image colors at arbitrary 2D coordinates [S2]. It sets itself apart from nearest neighbor interpolation by providing continuous gradients [G].

## How it works
**Inputs and Outputs:**
*   **Input:** A 2D grid of values (e.g., an image or texture) with dimensions $H \times W$ and $C$ channels, and a set of query coordinates $(x, y)$ [S2][S3].
*   **Output:** The interpolated value $V(x,y)$ at the query coordinates, preserving the channel count $C$ [S2].

**Data Structures:**
*   **Layout:** The source data is stored in a 1D contiguous array `values` of size `resX * resY` [S3]. The element at integer coordinates $(x, y)$ is stored at index $x \cdot resY + y$ [S3].
*   **Tensor Format:** In deep learning frameworks, inputs are shaped as $[batch\_size, H, W, C]$ [S2].

**Formulas:**
Let the query coordinate be $(x, y)$.
1.  Compute integer bounds:
    $$x_1 = \lfloor x \rfloor, \quad y_1 = \lfloor y \rfloor$$
    For negative coordinates, the floor is computed as $x_1 = -\text{int}(-x) - 1$ [S3].
2.  Compute fractional offsets:
    $$d_x = x - x_1, \quad d_y = y - y_1$$
    where $d_x, d_y \in [0, 1)$ [S3].
3.  Identify the four surrounding grid points:
    *   $V_{00} = Grid(x_1, y_1)$
    *   $V_{10} = Grid(x_1 + 1, y_1)$
    *   $V_{01} = Grid(x_1, y_1 + 1)$
    *   $V_{11} = Grid(x_1 + 1, y_1 + 1)$ [S3]
4.  Calculate the interpolated value:
    $$V(x,y) = V_{00}(1-d_x)(1-d_y) + V_{10}d_x(1-d_y) + V_{01}(1-d_x)d_y + V_{11}d_x d_y$$ [S3]

**Parameters:**
*   **Alignment:** When using library implementations, `align_corners=True` maps pixel centers to grid boundaries, affecting coordinate scaling [S2].
*   **Buffer Size:** In out-of-core implementations, a `BufferSize` parameter controls memory paging (default 64 elements), trading I/O frequency for memory usage [S3].
*   **Blending Factors:** In frequency domain rendering, blending factors are derived from texture coordinates $C$ and resolution $R$ as $F = C \times R - \lfloor C \times R \rfloor$ [S4].

**Steps:**
1.  **Coordinate Normalization:** Convert pixel coordinates to the expected range. In PyTorch's `grid_sample`, coordinates are negated and reshaped to $[N, H_{out}, W_{out}, 2]$ [S2].
2.  **Boundary Handling:** Determine if query coordinates fall within the valid grid range. If wrapping is enabled, apply modulo arithmetic. *Pitfall:* Incorrect modulo operations on negative numbers cause artifacts; specifically, using `resY` instead of `resX` for x-axis wrapping is a known bug in some implementations [S3].
3.  **Nearest Neighbor Fetch:** Retrieve the four values $V_{00}, V_{10}, V_{01}, V_{11}$ from the grid using the 1D layout [S3].
4.  **Interpolation:** Apply the bilinear formula to compute the final value [S3].
5.  **Output Formatting:** Permute and flatten the output tensor to match the expected batch and channel layout [S2].

**Pseudocode:**
```python
def bilinear_interpolate(grid_1d, x, y, resX, resY, wrap=False):
    # 1. Compute integer bounds with correct floor for negatives [S3]
    if x < 0:
        x1 = -int(-x) - 1
    else:
        x1 = int(x)
    if y < 0:
        y1 = -int(-y) - 1
    else:
        y1 = int(y)

    # 2. Boundary wrapping [S3]
    if wrap:
        if x1 < 0 or x1 >= resX:
            x1 = x1 % resX
            if x1 < 0: x1 += resX
        if y1 < 0 or y1 >= resY:
            y1 = y1 % resY
            if y1 < 0: y1 += resY

    # 3. Compute fractional offsets [S3]
    dx = x - x1
    dy = y - y1

    # 4. Fetch neighbors using 1D layout [S3]
    v00 = grid_1d[x1 * resY + y1]
    v10 = grid_1d[(x1 + 1) * resY + y1]
    v01 = grid_1d[x1 * resY + (y1 + 1)]
    v11 = grid_1d[(x1 + 1) * resY + (y1 + 1)]

    # 5. Bilinear formula [S3]
    return v00 * (1 - dx) * (1 - dy) + v10 * dx * (1 - dy) + v01 * (1 - dx) * dy + v11 * dx * dy

def grid_sample_bilinear(images, xy_grid):
    # Inputs: images [batch_size, H, W, C], xy_grid [batch_size, H_out, W_out, 2] [S2]
    batch_size, H, W, C = images.shape
    _, H_out, W_out, _ = xy_grid.shape

    # 1. Reshape xy_grid to [batch_size, -1, 1, 2] and negate [S2]
    xy_grid_flat = xy_grid.view(batch_size, -1, 1, 2)
    xy_grid_neg = -xy_grid_flat

    # 2. Permute images to [batch_size, C, H, W] [S2]
    images_nchw = images.permute(0, 3, 1, 2)

    # 3. Apply bilinear sampling per pixel [S2]
    sampled_nchw = []
    for b in range(batch_size):
        batch_samples = []
        for h in range(H_out):
            row_samples = []
            for w in range(W_out):
                coord = xy_grid_neg[b, h, w, :]
                # Map normalized coordinates to grid indices [G]
                x_idx = (coord[0] + 1) * 0.5 * (W - 1)
                y_idx = (coord[1] + 1) * 0.5 * (H - 1)
                ch_samples = []
                for c in range(C):
                    ch_flat = images_nchw[b, c, :, :].flatten()
                    val = bilinear_interpolate(ch_flat, x_idx, y_idx, W, H)
                    ch_samples.append(val)
                row_samples.append(ch_samples)
            batch_samples.append(row_samples)
        sampled_nchw.append(batch_samples)

    # 4. Permute back to [batch_size, H_out, W_out, C] and flatten [S2]
    sampled_hwc = permute_back(sampled_nchw, batch_size, H_out, W_out, C)
    return sampled_hwc.view(batch_size, -1, C)
```

## Subtopics

### Optimized Trilinear Reconstruction
Trilinear interpolation is the 3D extension of bilinear interpolation. Optimized variants use SIMD extensions (MMX, SSE, 3DNow!) to accelerate memory copying and interpolation speed, often operating on 16-bit unsigned integers for color and opacity [S5]. On MMX-only processors, certain line equation tests cannot be performed, leading to minor visual artifacts [S5].

## Background
Bilinear interpolation is implemented in deep learning frameworks such as PyTorch's `grid_sample` [S2, unofficial]. It is utilized in frequency domain volume rendering, where blending factors are derived from texture coordinates to approximate interpolation in the frequency domain [S4]. Optimized variants for trilinear reconstruction use SIMD extensions to improve performance [S5].
