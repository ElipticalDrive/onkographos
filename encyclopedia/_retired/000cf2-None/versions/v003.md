# Leaf Collection

Also called: Rendered Feedback Information, Node List Construction

## Overview
Leaf Collection is a feedback mechanism used during hierarchical volume rendering traversal to identify which nodes require data updates or further subdivision [S1, unofficial]. It solves the problem of maintaining data coherence between the GPU renderer and the CPU data manager by collecting indices of visited nodes into a compact list [S1, unofficial]. Unlike sibling methods that focus solely on traversal speed or memory residency, Leaf Collection specifically targets the *selection* of nodes for streaming or caching decisions based on their rendering status (empty, full, leaf, or needing subdivision) [S1, unofficial].

## How it works
Leaf Collection operates during the ray-tree traversal phase. It builds a list of node indices that the renderer has accessed or determined need attention. This list is subsequently compacted and sent to the CPU to trigger data updates [S1, unofficial].

**Inputs:**
- The hierarchical tree structure (e.g., Octree).
- Ray parameters (origin, direction).
- Current traversal state (node pointer, depth, coordinates).
- Level-of-Detail (LOD) requirements.

**Outputs:**
- A `node-list` containing indices of relevant nodes.
- Flags indicating whether a node needs subdivision.

**Data Structures:**
- **Node List:** A dynamic array or FIFO buffer storing node indices.
- **Node Metadata:** Each node in the tree contains a flag bit indicating if it requires further subdivision [S1, unofficial].

**Steps:**
1. **Traversal Initiation:** Begin ray traversal from the root.
2. **LOD Check:** For the current node, check if the required LOD data is present [S1, unofficial].
3. **Node Classification:**
   - If the node is **Empty**, **Full**, or a **Leaf**:
     - Push its coordinates and depth to the result vector [S2, unofficial].
     - Add its index to the `node-list` [S1, unofficial].
   - If the node is a **Branch**:
     - Iterate through its 8 children [S2, unofficial].
     - For each child, recursively call the collection function with updated coordinates:
       $$ cx_{new} = cx \times 2 + octant\_bit $$
       $$ cy_{new} = cy \times 2 + octant\_bit $$
       $$ cz_{new} = cz \times 2 + octant\_bit $$
       where $octant\_bit$ is the child's index (0-7) [S2, unofficial].
     - Increment depth [S2, unofficial].
4. **Subdivision Logic:**
   - If the appropriate LOD is missing OR the node is terminal (no more refined data):
     - Add the node index to the `node-list` [S1, unofficial].
     - Set a specific bit in the node metadata to indicate it needs further subdivision [S1, unofficial].
   - If the node has data but needs further subdivision (not terminal):
     - Add the node index to the `node-list` [S1, unofficial].
     - Set the subdivision bit [S1, unofficial].
   - *Constraint:* Limit subdivisions to one request per ray to prevent excessive updates [S1, unofficial].
5. **FIFO Management:**
   - Push rendered nodes into a FIFO buffer [S1, unofficial].
   - Apply window limits to control bandwidth:
     - Frame 1: Stop pushing after 48 elements [S1, unofficial].
     - Frame 2: Stop pushing after 96 elements [S1, unofficial].
   - Shift the 48-element window over subsequent frames to increase retrievable nodes [S1, unofficial].
6. **Compaction:** Before sending the list to the CPU, compact the node-list to reduce bandwidth usage [S1, unofficial].

**Pseudocode:**
```python
def collect_leaf_nodes(node, ray, depth, coordinates, node_list, fifo, frame_count):
    """
    Recursively traverse the tree and collect nodes for feedback.
    """
    # Check if node is terminal or has required data
    has_data = node.has_required_lod_data()
    is_terminal = node.is_terminal()
    is_branch = node.is_branch()
    
    # Determine if we need to record this node
    record_node = False
    needs_subdivision = False
    
    if not has_data or is_terminal:
        # Missing data or terminal node: record and mark for subdivision if needed
        record_node = True
        if not is_terminal:
            # If not terminal but missing data, it needs subdivision
            needs_subdivision = True
        else:
            # Terminal node: no further subdivision possible, but still record for caching
            needs_subdivision = False
    elif is_branch:
        # Branch with data: record and mark for subdivision request
        record_node = True
        needs_subdivision = True
    else:
        # Leaf, Empty, or Full: record for caching
        record_node = True
        needs_subdivision = False

    if record_node:
        node_list.append(node.index)
        # Set the subdivision bit in the node metadata if needed
        if needs_subdivision:
            node.set_subdivision_flag(True)
        
        # Push to FIFO for temporal coherence
        if len(fifo) < get_fifo_limit(frame_count):
            fifo.append(node.index)

    if is_branch:
        # Iterate through 8 children
        for octant in range(8):
            child = node.get_child(octant)
            if child is None:
                continue
            
            # Update coordinates
            cx = coordinates.x * 2 + (octant & 1)
            cy = coordinates.y * 2 + ((octant >> 1) & 1)
            cz = coordinates.z * 2 + ((octant >> 2) & 1)
            
            # Recursive call
            collect_leaf_nodes(child, ray, depth + 1, Vector(cx, cy, cz), node_list, fifo, frame_count)

def get_fifo_limit(frame_count):
    """
    Returns the FIFO limit based on the frame number.
    Frame 1: 48, Frame 2: 96.
    """
    if frame_count == 1:
        return 48
    elif frame_count == 2:
        return 96
    else:
        # Shift window logic implies increasing capacity or sliding window
        # For implementation, assume it grows or slides. 
        # Source says "shifted over a small set of frames", 
        # so we might return a value based on frame_count or a sliding window size.
        # To be safe and simple, we return a larger value or the max.
        return 96 
```

**Edge Cases and Pitfalls:**
- **Bandwidth:** Sending the raw node-list to CPU causes enormous bandwidth usage. Compaction is essential [S1, unofficial].
- **Precision:** Coordinate updates use integer arithmetic for octant bits to avoid floating-point errors [S2, unofficial].
- **Degenerate Input:** If a node has no children (terminal), the subdivision bit should not be set, but the node should still be recorded for caching [S1, unofficial].

## Subtopics

### Leaf Node Representation
A specific implementation detail where leaf nodes are represented as 4-byte RGBA blocks [S3, unofficial].
- **Validity:** A leaf node is valid if `rgba[3] != 0x00` [S3, unofficial].
- **Color Update:** The `set_color(pixel, lightness)` function multiplies RGB channels by lightness but does not modify alpha [S3, unofficial].
- **Equality:** Equality checks use bitwise comparison of the entire 4-byte RGBA block, not element-wise comparison [S3, unofficial].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of nodes visited during traversal [S1, unofficial]. The FIFO limit caps the number of nodes processed per frame.
- **Memory Complexity:** Proportional to the number of nodes in the `node-list` and `fifo`. The FIFO size is bounded (48-96 elements) [S1, unofficial].
- **Performance:** Improves reactivity in regions with high node density by ensuring information output in each frame [S1, unofficial]. No penalization due to temporal coherence [S1, unofficial].
- **Strengths:** Efficiently manages data streaming by focusing on nodes actually used in rendering. Reduces CPU-GPU bandwidth via compaction [S1, unofficial].
- **Limitations:** Requires additional metadata (subdivision bit) in nodes. Compaction adds CPU overhead [S1, unofficial].

## Background
Leaf Collection is part of the Ray-Guided Streaming framework for efficient and detailed voxel rendering [S1, unofficial]. It was introduced to address the challenge of keeping the CPU informed about which parts of the sparse voxel octree need to be streamed or updated, leveraging both spatial and temporal coherence [S1, unofficial].
