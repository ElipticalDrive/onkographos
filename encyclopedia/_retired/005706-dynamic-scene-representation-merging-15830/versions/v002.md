# Dynamic Scene Representation

Also called: 4D Gaussian Splatting, Dynamic 3DGS

## Overview
Dynamic Scene Representation methods extend static 3D Gaussian Splatting to handle temporal variations, enabling the rendering of novel views from video sequences or time-varying scenes [14584-explicit-4d-gaussian-splatting.md]. Unlike static representations, these methods model the evolution of Gaussian attributes (position, rotation, scale) over time to capture rigid and non-rigid motion [15458-gaussian-deformation-field-gaufre.md]. They are distinguished from static siblings by their ability to interpolate or deform primitives across a temporal domain, solving the problem of rendering coherent video content from sparse or dense input views [14584-explicit-4d-gaussian-splatting.md].

## Shared principles
All methods in this family operate on a set of $N$ 3D Gaussian primitives, extending the static definition with temporal dependencies. Each primitive $i$ is defined by learnable parameters describing its geometry, appearance, and position, now functions of time $t$ [14584-explicit-4d-gaussian-splatting.md][15458-gaussian-deformation-field-gaufre.md].

**Temporal Domain:**
The scene is defined over a time interval $t \in [0, T]$ [14584-explicit-4d-gaussian-splatting.md]. Rendering requires evaluating Gaussian attributes at a specific timestamp $t$ [15458-gaussian-deformation-field-gaufre.md].

**Attribute Evolution:**
While the core rendering equation (alpha compositing of projected Gaussians) remains identical to the static case [14584-explicit-4d-gaussian-splatting.md], the attributes $\mu_i(t), q_i(t), s_i(t)$ are no longer constant [15458-gaussian-deformation-field-gaufre.md]. Methods generally separate the scene into static and dynamic components to optimize memory and accuracy [14584-explicit-4d-gaussian-splatting.md][15458-gaussian-deformation-field-gaufre.md].

**Rendering Pipeline:**
1.  **Time Evaluation:** Compute time-dependent attributes for each Gaussian at query time $t$ [14584-explicit-4d-gaussian-splatting.md][15458-gaussian-deformation-field-gaufre.md].
2.  **Projection:** Project the 3D covariance $\Sigma_i(t)$ to 2D using the standard Jacobian $J$ [14584-explicit-4d-gaussian-splatting.md].
3.  **Rasterization:** Perform standard back-to-front alpha blending [14584-explicit-4d-gaussian-splatting.md].

## Subtopics

### [Explicit 4D Gaussian Splatting](14584-explicit-4d-gaussian-splatting.md)
Explicitly interpolates Gaussian attributes between sparse keyframes using cubic Hermite and spherical linear interpolation. It separates Gaussians into static (linear motion) and dynamic (keyframed) categories. Choose this when motion is sparse or discrete and high throughput is required without neural inference overhead [14584-explicit-4d-gaussian-splatting.md].

### [Gaussian Deformation Field (GauFRe)](15458-gaussian-deformation-field-gaufre.md)
Augments 3DGS with a neural deformation field that outputs deltas for position, rotation, and scale in a canonical space conditioned on time. It explicitly separates static and deformable Gaussians. Choose this for complex non-rigid motion where continuous deformation is preferred over keyframe interpolation [15458-gaussian-deformation-field-gaufre.md].

### [Light-weight 4D Gaussian Splatting (LGS)](15777-light-weight-4d-gaussian-splatting-lgs.md)
A memory-efficient method using knowledge distillation from an uncompressed "teacher" model to a compressed "student" model. It employs Deformation-Aware Pruning, Gaussian-Attribute Pruning, and Feature Field Condensation. Choose this when VRAM is limited, such as in surgical endoscopy, accepting potential trade-offs in detail compared to full deformation fields [15777-light-weight-4d-gaussian-splatting-lgs.md].

## Background
3D Gaussian Splatting was introduced for static scene representation . Dynamic extensions emerged to handle video data. Explicit 4D Gaussian Splatting (Ex4DGS) was proposed to address memory inefficiencies in dynamic scenes by using explicit keyframes [14584-explicit-4d-gaussian-splatting.md]. GauFRe introduced a forward-warping deformation field to handle non-rigid motion more continuously [15458-gaussian-deformation-field-gaufre.md]. LGS was developed specifically for resource-constrained applications like surgical endoscopy, focusing on compression techniques [15777-light-weight-4d-gaussian-splatting-lgs.md].
