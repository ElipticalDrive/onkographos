# Rational Bézier Deblocking Filter

Also called: Deblocking Filter (Rational Bézier), Deblocking filter based on projecting voxel scalar values onto rational Bézier curves, Rational Bézier filtering

## Overview
The Rational Bézier Deblocking Filter is a post-processing technique for GPU volume rendering that reduces blocking artifacts at block boundaries in compressed volumetric data without requiring prior knowledge of the compression algorithm or modification of the encoded data [S1, unofficial][S2, unofficial]. It distinguishes itself from standard deblocking methods by projecting voxel scalar values onto rational Bézier curves, where adjustable weights based on local gradient magnitude allow for adaptive filtering that preserves sharp features while smoothing discontinuities [S1, unofficial][S2, unofficial]. Unlike simple averaging or standard Bézier filtering, this method provides a more accurate approximation of the uncompressed signal by weighting control points according to feature importance [S1, unofficial][S2, unofficial].

## How it works
The filter operates on a volumetric scalar field $V$ that has been subdivided into blocks, compressed, and decompressed [S1, unofficial]. It is a block-aware, data-dependent filter applied sequentially along the three main axes (X, Y, Z) [S1, unofficial][S2, unofficial].

### Inputs and Outputs
*   **Input:** A decompressed volumetric scalar field $V = f(x)$ where $x \in \mathbb{R}^3$, subdivided into a set of blocks $B$ [S1, unofficial].
*   **Output:** A filtered volumetric scalar field with modified voxel intensities $I_f$ at block boundaries [S1, unofficial][S2, unofficial].

### Data Structures
*   **Volumetric Field $V$:** A 3D array of scalar values representing the decompressed volume [S1, unofficial].
*   **Blocks $B$:** The volume is partitioned into fixed-size blocks [S1, unofficial].
*   **Gradient Field:** A 3D array storing the gradient magnitude $|\nabla v|$ for each voxel $v$, computed via central differences [S1, unofficial][S2, unofficial].

### Parameters
*   $\lambda$: A user-defined parameter controlling the intensity of the filtering and the trade-off between artifact removal and feature preservation, typically set to $3$ [S1, unofficial].

### Algorithm Steps

1.  **Feature Detection:** Compute the gradient magnitude $|\nabla s_i|$ for every voxel $s_i$ in the volume $V$ using the central differences method [S1, unofficial][S2, unofficial].
2.  **Weight Calculation:** For each voxel $s_i$, compute the weight $\omega_i$ using the exponential function:
    $$ \omega_i = e^{\lambda(1 - |\nabla s_i|)} $$
    This assigns higher weights to voxels with low gradient magnitudes (homogeneous regions) and lower weights to voxels with high gradient magnitudes (features) [S1, unofficial][S2, unofficial].
3.  **Axis-Aligned Filtering:** Apply the filter sequentially along the X, Y, and Z axes [S1, unofficial][S2, unofficial]. For each axis direction:
    *   Identify pairs of adjacent blocks $b_i$ and $b_{i+1}$ along the current axis [S1, unofficial][S2, unofficial].
    *   For each boundary between $b_i$ and $b_{i+1}$, extract sets of axis-aligned samples $S$ that traverse the boundary [S1, unofficial][S2, unofficial]. Each set $S$ consists of voxels from $b_i$ and $b_{i+1}$ aligned along the filtering direction [S1, unofficial][S2, unofficial].
    *   For each sample $s \in S$, determine its position $t_s \in [0, 1]$ within the set $S$, where $t_s=0$ corresponds to the first control point and $t_s=1$ to the last [S1, unofficial][S2, unofficial].
    *   Compute the filtered intensity $I_f(t_s)$ using the rational Bézier formula:
        $$ I_f(t_s) = \frac{\sum_{j=0}^{n} \binom{n}{j} t_s^j (1 - t_s)^{n-j} I(s_j) \omega_j}{\sum_{j=0}^{n} \binom{n}{j} t_s^j (1 - t_s)^{n-j} \omega_j} $$
        where $n$ is the number of samples in $S$, $I(s_j)$ is the compressed intensity of the $j$-th control point, and $\omega_j$ is its weight [S1, unofficial][S2, unofficial].
    *   Update the intensity of the voxels closer to the border (half the voxels of each block adjacent to the boundary) with the computed filtered values [S1, unofficial][S2, unofficial].
4.  **Final Intensity:** For each voxel $v$, compute the final intensity $I_f(v)$ as the average of the three filtered values obtained from the X, Y, and Z passes [S1, unofficial][S2, unofficial].

### Pseudocode

```python
import math

def compute_gradient_magnitude(volume):
    """Computes gradient magnitude for each voxel using central differences."""
    dims = volume.shape
    grad_mag = [[[0.0 for _ in range(dims[2])] for _ in range(dims[1])] for _ in range(dims[0])]
    for z in range(dims[2]):
        for y in range(dims[1]):
            for x in range(dims[0]):
                dx = (volume[min(x+1, dims[0]-1)][y][z] - volume[max(x-1, 0)][y][z]) / (2.0 if 0 < x < dims[0]-1 else 1.0)
                dy = (volume[x][min(y+1, dims[1]-1)][z] - volume[x][max(y-1, 0)][z]) / (2.0 if 0 < y < dims[1]-1 else 1.0)
                dz = (volume[x][y][min(z+1, dims[2]-1)] - volume[x][y][max(z-1, 0)]) / (2.0 if 0 < z < dims[2]-1 else 1.0)
                grad_mag[x][y][z] = math.sqrt(dx*dx + dy*dy + dz*dz)
    return grad_mag

def compute_weight(grad_mag, lambda_param):
    """Computes weight omega_i = exp(lambda * (1 - grad_mag))."""
    return math.exp(lambda_param * (1.0 - grad_mag))

def rational_bezier_filter(samples, weights):
    """Projects samples onto a rational Bézier curve."""
    n = len(samples)
    filtered = []
    for i in range(n):
        t = i / (n - 1) if n > 1 else 0.0
        numerator = 0.0
        denominator = 0.0
        for j in range(n):
            binom = math.comb(n, j)
            basis = binom * (t ** j) * ((1 - t) ** (n - j))
            numerator += basis * samples[j] * weights[j]
            denominator += basis * weights[j]
        filtered.append(numerator / denominator if denominator != 0 else samples[i])
    return filtered

def deblock_volume(volume, block_size, lambda_param):
    """Applies the Rational Bézier Deblocking Filter to the entire volume."""
    dims = volume.shape
    grad_mag = compute_gradient_magnitude(volume)
    weights = [[[compute_weight(grad_mag[x][y][z], lambda_param) for z in range(dims[2])] for y in range(dims[1])] for x in range(dims[0])]
    
    # Initialize intermediate volumes with original values
    vol_x = [[[volume[x][y][z] for z in range(dims[2])] for y in range(dims[1])] for x in range(dims[0])]
    vol_y = [[[volume[x][y][z] for z in range(dims[2])] for y in range(dims[1])] for x in range(dims[0])]
    vol_z = [[[volume[x][y][z] for z in range(dims[2])] for y in range(dims[1])] for x in range(dims[0])]
    
    # X-axis pass
    for z in range(dims[2]):
        for y in range(dims[1]):
            for bx in range(0, dims[0], block_size):
                ex = min(bx + block_size, dims[0])
                if ex > dims[0]: continue
                samples_bi = [volume[x][y][z] for x in range(bx, ex)]
                samples_bi1 = [volume[x][y][z] for x in range(ex, min(ex + block_size, dims[0]))]
                if not samples_bi1: continue
                samples_S = samples_bi + samples_bi1
                weights_S = [weights[x][y][z] for x in range(bx, ex)] + [weights[x][y][z] for x in range(ex, min(ex + block_size, dims[0]))]
                filtered_S = rational_bezier_filter(samples_S, weights_S)
                half_bi = block_size // 2
                half_bi1 = len(samples_bi1) // 2
                for i in range(half_bi):
                    vol_x[ex - half_bi + i][y][z] = filtered_S[block_size - half_bi + i]
                for i in range(half_bi1):
                    vol_x[ex + i][y][z] = filtered_S[block_size + i]
                    
    # Y-axis pass
    for z in range(dims[2]):
        for x in range(dims[0]):
            for by in range(0, dims[1], block_size):
                ey = min(by + block_size, dims[1])
                if ey > dims[1]: continue
                samples_bi = [vol_x[x][y][z] for y in range(by, ey)]
                samples_bi1 = [vol_x[x][y][z] for y in range(ey, min(ey + block_size, dims[1]))]
                if not samples_bi1: continue
                samples_S = samples_bi + samples_bi1
                weights_S = [weights[x][y][z] for y in range(by, ey)] + [weights[x][y][z] for y in range(ey, min(ey + block_size, dims[1]))]
                filtered_S = rational_bezier_filter(samples_S, weights_S)
                half_bi = block_size // 2
                half_bi1 = len(samples_bi1) // 2
                for i in range(half_bi):
                    vol_y[x][ey - half_bi + i][z] = filtered_S[block_size - half_bi + i]
                for i in range(half_bi1):
                    vol_y[x][ey + i][z] = filtered_S[block_size + i]
                    
    # Z-axis pass
    for y in range(dims[1]):
        for x in range(dims[0]):
            for bz in range(0, dims[2], block_size):
                ez = min(bz + block_size, dims[2])
                if ez > dims[2]: continue
                samples_bi = [vol_y[x][y][z] for z in range(bz, ez)]
                samples_bi1 = [vol_y[x][y][z] for z in range(ez, min(ez + block_size, dims[2]))]
                if not samples_bi1: continue
                samples_S = samples_bi + samples_bi1
                weights_S = [weights[x][y][z] for z in range(bz, ez)] + [weights[x][y][z] for z in range(ez, min(ez + block_size, dims[2]))]
                filtered_S = rational_bezier_filter(samples_S, weights_S)
                half_bi = block_size // 2
                half_bi1 = len(samples_bi1) // 2
                for i in range(half_bi):
                    vol_z[x][y][ez - half_bi + i] = filtered_S[block_size - half_bi + i]
                for i in range(half_bi1):
                    vol_z[x][y][ez + i] = filtered_S[block_size + i]
                    
    # Final average
    result = [[[0.0 for _ in range(dims[2])] for _ in range(dims[1])] for _ in range(dims[0])]
    for z in range(dims[2]):
        for y in range(dims[1]):
            for x in range(dims[0]):
                result[x][y][z] = (vol_x[x][y][z] + vol_y[x][y][z] + vol_z[x][y][z]) / 3.0
    return result
```

### Edge Cases and Pitfalls
*   **Precision:** The computation involves binomial coefficients and powers, which can lead to numerical instability for large $n$ (block sizes) [G].
*   **Boundaries:** The filter is applied only at internal block boundaries. Voxels in the interior of blocks are not modified in the respective axis pass [S1, unofficial][S2, unofficial].
*   **Homogeneous Regions:** In homogeneous regions, gradient magnitudes are low, resulting in weights close to $e^\lambda$ [S1, unofficial][S2, unofficial]. This leads to subtle filtering, preserving the original signal closely [S1, unofficial][S2, unofficial].
*   **High Gradient Regions:** In regions with high gradients, weights are low, allowing more smoothing to remove artifacts while preserving the feature shape [S1, unofficial][S2, unofficial].

## Operating characteristics
*   **Time Complexity:** The filter is computationally intensive due to the per-voxel gradient computation and the rational Bézier projection for each block boundary [S1, unofficial]. It achieves interactive frame rates on standard graphics PCs but requires optimization for speed [S1, unofficial].
*   **Memory Complexity:** Not given in the sources. [G] Requires storage for the original volume, gradient magnitude field, and intermediate filtered volumes for the three axis passes.
*   **Performance:** Provides SSIM gains of 5–7% for K-SVD compression and 6–11% for HVQ compression. MS-SSIM gains are 2–8% for K-SVD and 4–6% for HVQ [S1, unofficial].
*   **Strengths:** Works without knowledge of the compression technique; does not require modifying the compressed data format; preserves local features better than simple averaging or standard Bézier filtering [S1, unofficial][S2, unofficial].
*   **Limitations:** Computationally intensive; effectiveness depends on the choice of $\lambda$ [S1, unofficial].

## Background
The Rational Bézier Deblocking Filter was introduced by F. Marton, José A. Iglesias Guitián, Jose Díaz, and Enrico Gobbetti in the paper "Real-time Deblocked GPU Rendering of Compressed Volumes" (2014) [S1, unofficial][S2, unofficial]. It was developed to address the visual quality degradation caused by blocking artifacts in compressed volumetric data during real-time GPU rendering [S1, unofficial]. The method extends deferred filtering architectures to support adaptive multi-resolution data loading and levels of detail [S1, unofficial].
