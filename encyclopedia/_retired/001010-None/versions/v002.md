# Algebraic Surface Raycasting

Also called: Implicit Surface Raycasting via Polynomial Composition, Polynomial Raycasting

## Overview
Algebraic Surface Raycasting is an image-order rendering technique that computes the first intersection of a viewing ray with an isosurface defined by a trivariate polynomial function [S1]. It solves the problem of rendering implicit surfaces from volumetric data by transforming the 3D field evaluation into a 1D rootfinding problem along each ray [S1]. It is distinguished from [Cell-Based First-Hit Ray Casting](1039-cell-based-first-hit-ray-casting.md) by its global polynomial composition approach rather than local cell traversal [S1].

## How it works
The method consists of two core phases: composition (transforming the trivariate field into a univariate polynomial along the ray) and rootfinding (identifying the first positive root of the polynomial minus the isovalue) [S1].

### Inputs and Outputs
- **Input**:
  - Ray origin $\mathbf{p}$ and direction $\mathbf{v}$ (normalized) [S1].
  - Scalar field function $f(x, y, z)$ defined as a trivariate polynomial of degree $d$ in each dimension [S1].
  - Isovalue $c$ [S1].
  - Ray bounds $[t_{min}, t_{max}]$ (typically $t_{min}=0$) [G].
- **Output**:
  - Intersection parameter $t^*_0$ (the smallest root $> t_{min}$) [S1].
  - Intersection point $\mathbf{x}^* = \mathbf{p} + t^*_0 \mathbf{v}$ [S1].

### Data Structures
The scalar field is represented by its coefficients in power basis form [S1]. For a polynomial of degree $d$ in $x, y, z$:
$$ f(x, y, z) = \sum_{i=0}^{d} \sum_{j=0}^{d} \sum_{k=0}^{d} f_{ijk} x^i y^j z^k $$
The coefficients $f_{ijk}$ are stored in a 3D array of size $(d+1) \times (d+1) \times (d+1)$ [S1]. Common interpolation schemes (e.g., tri-linear, tri-cubic) map voxel grid values to these coefficients [S1].

### Steps

1. **Ray Definition**:
   Define the ray equation:
   $$ \mathbf{r}(t) = \mathbf{p} + t \cdot \mathbf{v} $$
   where $\mathbf{p} = (p_x, p_y, p_z)$ and $\mathbf{v} = (v_x, v_y, v_z)$ [S1].

2. **Composition**:
   Substitute $\mathbf{r}(t)$ into $f(x, y, z)$ to obtain a univariate polynomial $P(t)$ of degree $D = 3d$ (for tri-linear, $d=1, D=3$; for tri-cubic, $d=3, D=9$):
   $$ P(t) = f(p_x + t v_x, p_y + t v_y, p_z + t v_z) $$
   $$ P(t) = \sum_{n=0}^{D} a_n t^n $$
   The coefficients $a_n$ are computed by expanding the trivariate polynomial [S1]. Optimized composition algorithms reduce the operation count compared to naive substitution [S1].

3. **Isovalue Subtraction**:
   Define the rootfinding polynomial $Q(t)$:
   $$ Q(t) = P(t) - c = \sum_{n=0}^{D} a_n t^n - c $$
   The constant term becomes $a_0 - c$ [S1].

4. **Rootfinding**:
   Find the smallest real root $t^*_0$ of $Q(t) = 0$ such that $t^*_0 > t_{min}$ [S1].
   - For low degrees ($D \le 4$), closed-form solutions (quadratic, cubic, quartic formulas) can be used [S2].
   - For higher degrees, numerical methods such as Bézier clipping are employed to iteratively converge toward the first root or reject root-free intervals [S2].
   - The rootfinder must isolate the first root within $[t_{min}, t_{max}]$ [S1].

5. **Intersection Point**:
   Compute $\mathbf{x}^* = \mathbf{p} + t^*_0 \mathbf{v}$ [S1].

6. **Shading**:
   Compute the surface normal $\mathbf{n} = \nabla f(\mathbf{x}^*)$ using the gradient of the trivariate polynomial, then apply lighting models [G].

### Pseudocode

```python
import math
from math import comb

def algebraic_surface_cast(p, v, coeffs, c, t_min, t_max):
    """
    Cast a ray against an algebraic isosurface.
    
    Args:
        p: Ray origin (vec3)
        v: Ray direction (vec3, normalized)
        coeffs: 3D array of shape (d+1, d+1, d+1) containing f_ijk
        c: Isovalue
        t_min: Minimum ray parameter
        t_max: Maximum ray parameter
        
    Returns:
        t_star: First intersection parameter, or infinity if no hit
    """
    d = coeffs.shape[0] - 1
    
    # Step 1: Composition
    a = compose_univariate(p, v, coeffs, d)
    
    # Step 2: Subtraction
    a[0] -= c
    
    # Step 3: Rootfinding
    D = 3 * d
    roots = solve_polynomial(a, D)
    
    # Filter roots
    valid_roots = [t for t in roots if t > t_min and t <= t_max]
    
    if not valid_roots:
        return float('inf')
    
    # Return the first (smallest) intersection
    return min(valid_roots)

def compose_univariate(p, v, coeffs, d):
    """
    Compute coefficients a_n of the univariate polynomial P(t) = f(p + t*v).
    f(x,y,z) = sum_{i,j,k} f_ijk * x^i * y^j * z^k
    x = p_x + t*v_x, etc.
    
    Returns array a of size 3*d + 1
    """
    max_degree = 3 * d
    a = [0.0] * (max_degree + 1)
    
    for i in range(d + 1):
        for j in range(d + 1):
            for k in range(d + 1):
                coeff = coeffs[i, j, k]
                # Expand (p_x + t*v_x)^i * (p_y + t*v_y)^j * (p_z + t*v_z)^k
                # Using binomial expansion: (A + t*B)^n = sum_{m=0}^n C(n,m) * A^(n-m) * B^m * t^m
                for m_x in range(i + 1):
                    for m_y in range(j + 1):
                        for m_z in range(k + 1):
                            n = m_x + m_y + m_z
                            cx = comb(i, m_x)
                            cy = comb(j, m_y)
                            cz = comb(k, m_z)
                            term = coeff * cx * cy * cz
                            term *= (p[0] ** (i - m_x)) * (v[0] ** m_x)
                            term *= (p[1] ** (j - m_y)) * (v[1] ** m_y)
                            term *= (p[2] ** (k - m_z)) * (v[2] ** m_z)
                            a[n] += term
    return a

def solve_polynomial(a, D):
    """
    Solve polynomial sum(a_n * t^n) = 0.
    Handles degree reduction and closed-form/numerical fallbacks.
    """
    # Reduce degree if leading coefficient is near zero to prevent division by zero
    while D > 0 and abs(a[D]) < 1e-12:
        D -= 1
        
    if D == 0:
        return []
    if D == 1:
        return [-a[0] / a[1]]
    if D == 2:
        A, B, C = a[2], a[1], a[0]
        disc = B * B - 4 * A * C
        if disc < 0: return []
        sqrt_disc = disc ** 0.5
        return [(-B - sqrt_disc) / (2 * A), (-B + sqrt_disc) / (2 * A)]
    if D == 3:
        return solve_cubic(a)
    if D == 4:
        return solve_quartic(a)
    # For D > 4, use companion matrix eigenvalues [G]
    return solve_companion_matrix(a, D)

def solve_cubic(a):
    """Cardano's method for cubic polynomials."""
    A, B, C, D = a[3], a[2], a[1], a[0]
    p = (3 * A * C - B ** 2) / (3 * A ** 2)
    q = (2 * B ** 3 - 9 * A * B * C + 27 * A ** 2 * D) / (27 * A ** 3)
    disc = (q ** 2 / 4) + (p ** 3 / 27)
    if disc > 0:
        u = (-q / 2 + disc ** 0.5) ** (1 / 3)
        v = (-q / 2 - disc ** 0.5) ** (1 / 3)
        return [u + v - B / (3 * A)]
    elif disc == 0:
        if p == 0: return [-B / (3 * A)]
        u = (-q / 2) ** (1 / 3)
        return [2 * u - B / (3 * A), -u - B / (3 * A)]
    else:
        r = (-p / 3) ** 0.5
        theta = math.acos(-q / (2 * r ** 3))
        return [2 * r * math.cos(theta / 3) - B / (3 * A),
                2 * r * math.cos((theta + 2 * math.pi) / 3) - B / (3 * A),
                2 * r * math.cos((theta + 4 * math.pi) / 3) - B / (3 * A)]

def solve_quartic(a):
    """Ferrari's method for quartic polynomials."""
    A, B, C, D, E = a[4], a[3], a[2], a[1], a[0]
    p = (8 * A * C - 3 * B ** 2) / (8 * A ** 2)
    q = (B ** 3 - 4 * A * B * C + 8 * A ** 2 * D) / (8 * A ** 3)
    r = (-3 * B ** 4 + 256 * A ** 3 * E - 128 * A ** 2 * C + 16 * A * B ** 2 * C - 64 * A ** 2 * B * D) / (256 * A ** 4)
    # Solve resolvent cubic for m
    m_coeffs = [1, 0, p / 2 - r, -p * r / 2 + q ** 2 / 8]
    m_roots = solve_cubic(m_coeffs)
    real_m = [m for m in m_roots if m >= 0]
    if not real_m:
        return []
    m = real_m[0]
    # Factor into two quadratics
    disc1 = m ** 2 - 4 * (C - m * A)
    disc2 = m ** 2 - 4 * (D - m * B + m ** 2 * A)
    if disc1 < 0 or disc2 < 0:
        return []
    sqrt1 = disc1 ** 0.5
    sqrt2 = disc2 ** 0.5
    roots = []
    roots.extend([(-m - sqrt1) / (2 * A), (-m + sqrt1) / (2 * A)])
    roots.extend([(-m - sqrt2) / (2 * A), (-m + sqrt2) / (2 * A)])
    return [r for r in roots if r >= 0]

def solve_companion_matrix(a, D):
    """
    Solve polynomial of degree D > 4 using companion matrix eigenvalues.
    Returns real roots only.
    """
    # Construct companion matrix
    n = D
    M = [[0.0] * n for _ in range(n)]
    for i in range(n - 1):
        M[i][i + 1] = 1.0
    for i in range(n):
        M[n - 1][i] = -a[i] / a[n]
    # Compute eigenvalues (power iteration or QR algorithm [G])
    # For brevity, we return a placeholder for the standard numerical routine
    # In practice, use a robust eigenvalue solver and filter real parts
    return [] # Standard companion matrix eigenvalue solver [G]
```

### Parameters and Edge Cases
- **Degree $d$**: Typically 1 (tri-linear) or 3 (tri-cubic) [S1].
- **Precision**: Floating-point errors in composition can affect root accuracy. Use double precision for critical applications [G].
- **Degenerate Input**: If $f_{ijk}$ are all zero, the field is constant [G].
- **No Root**: If $Q(t)$ has no real roots in $[t_{min}, t_{max}]$, the ray misses the isosurface [S1].

## Subtopics

### Hermite Polynomial Approximation for Convolution Surfaces
A method for rendering convolution surfaces (implicit surfaces defined by the summation of kernel functions around primitives) where the field is approximated by piecewise polynomials along the ray [S2]. It subdivides the ray interval intersecting a primitive, samples Hermite data (value and derivative) at boundaries, and constructs cubic polynomial approximations [S2]. Roots are computed analytically [S2]. It is chosen when rendering smooth, organic shapes defined by skeletal primitives [S2]. Pitfalls include poor approximation with few intervals and Runge's phenomenon with higher-degree approximations [S2].

### [Polynomial Root Finding (Compact Kernel)](4022-polynomial-root-finding-compact-kernel.md)
A technique for point primitives defined by compact polynomial kernels where the field along the ray is a piecewise polynomial. For degrees $\le 4$, closed-form roots are used. For higher degrees, the Bézier clipping algorithm is employed to iteratively converge to the first root or reject root-free intervals.

## Operating characteristics
- **Time Complexity**: Composition is $O(d^4)$ for naive expansion, though optimized composition reduces this significantly [S1]. Rootfinding is $O(1)$ for closed-form (low degree) or $O(\log(1/\epsilon))$ for iterative methods [S2]. Overall per-pixel cost is dominated by composition for high degrees [S1].
- **Memory Complexity**: $O(d^3)$ to store coefficients [S1].
- **Performance**: Faster than marching cubes for high-resolution data as it avoids grid traversal and interpolation overhead [S1]. However, high-degree polynomials are expensive to compose [S1].
- **Strengths**: Exact intersection points (up to rootfinding precision), smooth shading via analytical gradients, no discretization artifacts from voxel grids [G].
- **Limitations**: High computational cost for high-degree polynomials. Numerical instability in rootfinding for high degrees. Not suitable for non-polynomial fields without approximation [G].
- **When to use**: High-quality offline rendering, medical visualization with tri-cubic interpolation, smooth implicit surfaces [S1].
- **When not to use**: Real-time rendering with very high degrees, non-polynomial fields, or when memory bandwidth is limited [G].

## Background
The method originates from the need to render isosurfaces from volumetric data more accurately than voxel-based methods [S1]. It is embedded in frameworks that handle piecewise algebraic surfaces, such as wavelet-based multiresolution rendering where polynomial approximations of the field enable efficient composition and rootfinding [S1]. The approach leverages the algebraic nature of polynomial interpolation (e.g., tri-linear, tri-cubic) to transform the 3D implicit surface query into a 1D polynomial root problem [S1]. Variants for convolution surfaces extend the method to point-based and skeletal implicit representations [S2].
