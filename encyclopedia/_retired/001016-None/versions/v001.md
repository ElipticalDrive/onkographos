# Basis Transform for Trivariate Polynomials

Also called: B-spline to Bernstein/Power Basis Transform

## Overview
This method transforms a trivariate polynomial representation from the B-spline basis (used in tri-linear or tri-cubic filtering) to the scaled Bernstein or power basis [S1, unofficial]. It solves the problem of high memory consumption when storing explicit polynomial descriptions for large datasets, allowing on-the-fly transformation instead [S1, unofficial]. It is distinct from naive substitution by leveraging the tensor product structure of the basis to reduce computational complexity, and differs from [Composition via Scaled Bernstein Form](1592-composition-via-scaled-bernstein-form.md) by its specific focus on the initial basis conversion step for efficient Horner scheme integration [S1, unofficial].

## How it works
**Inputs:**
- Polynomial degree $d$ (typically 1 for tri-linear, 3 for tri-cubic).
- Data values in the B-spline basis for a voxel.

**Outputs:**
- Coefficients in the scaled Bernstein or power basis.

**Data Structures:**
- Basis vector $\mathbf{b}$: A 1D array of size $d+1$ representing the monomial or Bernstein basis functions.
- Transformation Matrix $M$: A $(d+1) \times (d+1)$ matrix containing constants (zeros, ones, and scaling factors).

**Steps:**
1. **One-Dimensional Basis Transform:**
   For each dimension, compute the transformation from B-spline to the target basis (scaled Bernstein or power). This is achieved by multiplying the basis vector by the transformation matrix $M$.
   - The matrix $M$ is precomputed to contain mostly zeros and ones, with a single constant scaling factor to minimize arithmetic operations [S1, unofficial].
   - For transition to the **scaled Bernstein basis**, 6 multiplications are required per dimension [S1, unofficial].
   - For transition to the **power basis**, 8 multiplications are required per dimension [S1, unofficial] [G: This count assumes a specific optimized matrix structure for degree $d=3$].

2. **N-Dimensional Basis Transform Construction:**
   The N-dimensional basis is a tensor product of the 1D bases. The full N-dimensional transform is constructed from $N \cdot (d + 1)^{N-1}$ one-dimensional basis transforms [S1, unofficial].
   - For trivariate polynomials ($N=3$), this involves applying the 1D transforms sequentially along each axis.

3. **Integration with Horner Scheme:**
   The basis transform is integrated into the Horner scheme for polynomial evaluation/composition. This separation of dimensions allows efficient evaluation without explicitly storing the full trivariate polynomial coefficients [S1, unofficial].

**Pseudocode:**
```python
def basis_transform_1d(basis_vector, degree, target_basis):
    """
    Transforms a 1D basis vector from B-spline to scaled Bernstein or power basis.
    
    Args:
        basis_vector: List of coefficients in B-spline basis.
        degree: Polynomial degree d.
        target_basis: 'bernstein' or 'power'.
        
    Returns:
        Transformed coefficients.
    """
    # Precomputed transformation matrices for degree 3 (tri-cubic)
    # These matrices are designed to have many zeros and ones, 
    # scaled by a constant factor to reduce multiplications.
    
    if target_basis == 'bernstein':
        # Matrix M_bernstein for degree 3
        # Requires 6 multiplications
        M = [
            [1, 0, 0, 0],
            [-3, 3, 0, 0],
            [3, -6, 3, 0],
            [-1, 3, -3, 1]
        ]
        # Note: The actual scaling factor is applied to reduce operations.
        # The exact matrix entries depend on the specific B-spline definition used.
    elif target_basis == 'power':
        # Matrix M_power for degree 3
        # Requires 8 multiplications
        M = [
            [1, 0, 0, 0],
            [-3, 3, 0, 0],
            [3, -6, 3, 0],
            [-1, 3, -3, 1]
        ]
        # Note: Power basis transformation may involve different scaling.
    else:
        raise ValueError("Unsupported target basis")

    # Perform matrix-vector multiplication
    # Since M is sparse, this is optimized to use fewer multiplications
    transformed_coeffs = [0] * (degree + 1)
    for i in range(degree + 1):
        for j in range(degree + 1):
            transformed_coeffs[i] += M[i][j] * basis_vector[j]
            
    return transformed_coeffs

def basis_transform_3d(b_spline_coeffs, degree, target_basis):
    """
    Transforms trivariate B-spline coefficients to target basis using tensor product.
    
    Args:
        b_spline_coeffs: 3D array of coefficients (d+1, d+1, d+1).
        degree: Polynomial degree d.
        target_basis: 'bernstein' or 'power'.
        
    Returns:
        Transformed coefficients in target basis.
    """
    # Apply 1D transform along each dimension
    # Number of 1D transforms: N * (d+1)^(N-1) = 3 * (d+1)^2 for N=3
    
    # Transform along X
    temp_coeffs = [[0] * (degree + 1) for _ in range((degree + 1) ** 2)]
    for k in range(degree + 1):
        for l in range(degree + 1):
            col = [b_spline_coeffs[i][k][l] for i in range(degree + 1)]
            transformed_col = basis_transform_1d(col, degree, target_basis)
            for i in range(degree + 1):
                temp_coeffs[k * (degree + 1) + l][i] = transformed_col[i]
    
    # Transform along Y
    temp_coeffs_2 = [[0] * (degree + 1) for _ in range((degree + 1) ** 2)]
    for k in range(degree + 1):
        for l in range(degree + 1):
            row = [temp_coeffs[k][j][l] for j in range(degree + 1)]
            transformed_row = basis_transform_1d(row, degree, target_basis)
            for j in range(degree + 1):
                temp_coeffs_2[k][j][l] = transformed_row[j]
                
    # Transform along Z
    final_coeffs = [[0] * (degree + 1) for _ in range((degree + 1) ** 2)]
    for k in range(degree + 1):
        for l in range(degree + 1):
            plane = [temp_coeffs_2[k][l][m] for m in range(degree + 1)]
            transformed_plane = basis_transform_1d(plane, degree, target_basis)
            for m in range(degree + 1):
                final_coeffs[k][l][m] = transformed_plane[m]
                
    return final_coeffs
```

**Parameters:**
- Degree $d$: Typically 1 (tri-linear) or 3 (tri-cubic) [S1, unofficial].
- Multiplications per 1D transform: 6 for scaled Bernstein, 8 for power basis [S1, unofficial].

**Edge Cases:**
- Degree 0: Trivial case, no transformation needed.
- Precision: Using matrices with zeros and ones minimizes floating-point error accumulation compared to dense matrix multiplication [S1, unofficial].

## Subtopics

### Polynomial Basis Vector Generation
Generates the basis vector $\mathbf{b}$ for a given degree $d$ [S2, unofficial].
- **Degree 0:** Output vector contains 1 element: $[1]$.
- **Degree 1:** Output vector contains 4 elements: $[1, x, y, z]$.
- **Degree 2:** Output vector contains 10 elements: $[1, x, y, z, xy, xz, yz, x^2, y^2, z^2]$.
- **Supported Degrees:** 0, 1, 2 [S2, unofficial].

## Operating characteristics
- **Time Complexity:** The transformation is $O(d^3)$ for trivariate polynomials, but optimized to use a fixed number of multiplications (6 or 8 per dimension) due to the sparse matrix structure [S1, unofficial].
- **Memory Complexity:** Avoids storing the full explicit polynomial description, reducing memory consumption by a factor of $(d+1)^3$ compared to storing all coefficients explicitly [S1, unofficial].
- **Strengths:** Efficient on-the-fly transformation; low arithmetic complexity; compatible with Horner scheme for fast evaluation.
- **Limitations:** Requires precomputed transformation matrices; specific to B-spline to Bernstein/Power basis conversion.
- **When to Use:** When memory is constrained and the polynomial needs to be evaluated in a different basis (e.g., for root finding or composition) [S1, unofficial].
- **When Not to Use:** If the B-spline basis is sufficient for the application (e.g., simple interpolation) [S1, unofficial].

## Background
The method originates from wavelet-based multiresolution isosurface rendering techniques, where efficient handling of large datasets with algebraic methods is crucial [S1, unofficial]. Tri-linear and tri-cubic filtering are based on B-spline polynomials, and transforming to Bernstein or power basis enables efficient root finding and composition [S1, unofficial]. The approach was developed to address the memory overhead of storing explicit polynomial descriptions for large volumes [S1, unofficial].
