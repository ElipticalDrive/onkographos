# Hierarchical Sampling with Occupancy Grid

Also called: FLASH Renderer, NeRF Hierarchical Sampling

## Overview
Hierarchical Sampling with Occupancy Grid is a two-stage volume rendering method that accelerates Neural Radiance Field (NeRF) training and inference by combining empty-space skipping with importance-based sample refinement [S1, unofficial]. It uses an occupancy grid to skip empty regions during coarse sampling, then employs hierarchical sampling to refine sample positions based on coarse weights, combining coarse and fine samples for the final render [S1, unofficial]. This approach distinguishes itself from siblings like [Distance Map Acceleration](972-distance-map-acceleration.md) by using a binary occupancy structure rather than distance fields, and from [Two-stage Ray Marching with Empty-Space Skipping](2985-two-stage-ray-marching-with-empty-space-skipping.md) by explicitly weighting fine samples against coarse transmittance rather than just skipping empty intervals [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** Ray origins `rays_o` (shape `[num_rays, 3]`), ray directions `rays_d` (shape `[num_rays, 3]`), near/far clipping planes `near` (float, default 2.0) and `far` (float, default 6.0) [S1, unofficial]. Optional `occupancy_grid` structure [S1, unofficial]. Coarse model `model_coarse` and fine model `model_fine` (typically the same network with shared weights or a merged state) [S1, unofficial].
- **Outputs:** Rendered RGB `rgb_fine`, depth `depth_fine`, accumulated opacity `acc_fine`, and fine weights `weights_fine` [S1, unofficial].

**Data Structures:**
- **OccupancyGrid:**
  - `resolution` (int): Grid dimension $N \times N \times N$.
  - `aabb_min` (tensor `[3]`): Minimum corner of the axis-aligned bounding box.
  - `aabb_max` (tensor `[3]`): Maximum corner of the axis-aligned bounding box.
  - `density_threshold` (float): Threshold for marking a voxel as occupied.
  - `grid` (bool tensor `[resolution, resolution, resolution]`): Binary occupancy status of each voxel.
  - `voxel_size` (tensor `[3]`): Size of each voxel in world units [S1, unofficial].

**Numbered Steps:**

1. **Normalize Ray Directions:**
   Normalize input ray directions to unit length:
   $$ \mathbf{d}_{norm} = \frac{\mathbf{d}}{\|\mathbf{d}\|} $$
   [S1, unofficial]

2. **Coarse Sampling:**
   If `occupancy_grid` is present, call `occupancy_grid.sample_occupied_regions(rays_o, rays_d, near, far, num_coarse_samples, randomize)` to generate coarse t-values `t_coarse` [S1, unofficial]. Otherwise, call `sample_stratified_batch(near, far, num_coarse_samples, randomize)` [S1, unofficial].
   - `num_coarse_samples` (int, default 32) [S1, unofficial].
   - `randomize` (bool): If true, add jitter to samples [S1, unofficial].

3. **Render Coarse Samples:**
   Evaluate the coarse model at positions derived from `t_coarse` to get `rgb_coarse` and `density_coarse`. Compute transmittance and weights:
   - Compute distances between samples:
     $$ \text{dists}_i = t_{i+1} - t_i $$
     Append a large value ($10^{10}$) to the end of `dists` to handle the last segment [S1, unofficial].
   - Compute alpha:
     $$ \alpha_i = 1 - \exp(-\text{density}_i \cdot \text{dists}_i) $$
     [S1, unofficial]
   - Compute transmittance:
     $$ T_i = \prod_{j=0}^{i-1} (1 - \alpha_j + \epsilon) $$
     where $\epsilon = 10^{-10}$ for numerical stability, and $T_0 = 1$ [S1, unofficial].
   - Compute weights:
     $$ w_i = T_i \cdot \alpha_i $$
     [S1, unofficial]
   - Integrate RGB:
     $$ \text{rgb}_{integrated} = \sum_i w_i \cdot \text{rgb}_i $$
     [S1, unofficial]
   - Compute depth and accumulation:
     $$ \text{depth} = \sum_i w_i \cdot t_i $$
     $$ \text{acc} = \sum_i w_i $$
     [S1, unofficial]
   - Apply background:
     $$ \text{rgb}_{final} = \text{rgb}_{integrated} + (1 - \text{acc}) \cdot \text{bg\_color} $$
     where `bg_color` is white (1.0) if `white_background` is True, else 0.0 [S1, unofficial].

4. **Compute Midpoints and Bins:**
   Calculate midpoints between coarse samples:
   $$ t_{mid, i} = \frac{t_{coarse, i} + t_{coarse, i+1}}{2} $$
   [S1, unofficial]
   Construct bins by concatenating the start of the ray, midpoints, and end of the ray:
   $$ \text{bins} = [t_{coarse, 0}, t_{mid, 0}, \dots, t_{mid, N-2}, t_{coarse, N-1}] $$
   [S1, unofficial]

5. **Hierarchical Fine Sampling:**
   Sample fine t-values `t_fine` within the bins using the coarse weights `weights_coarse` (detached from the computation graph) as importance probabilities [S1, unofficial].
   - `num_fine_samples` (int, default 64) [S1, unofficial].
   - `deterministic` (bool): If true, use stratified sampling; otherwise, use random sampling [S1, unofficial].

6. **Combine and Sort:**
   Concatenate coarse and fine t-values:
   $$ t_{combined} = \text{sort}([t_{coarse}, t_{fine}]) $$
   [S1, unofficial]

7. **Render Combined Samples:**
   Evaluate the fine model at `t_combined` positions. Repeat the volume rendering integration steps (3) using `t_combined`, `rgb_fine`, and `density_fine` to produce the final output [S1, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn.functional as F

def hierarchical_render_with_occupancy(
    rays_o, rays_d, near, far, 
    model, occupancy_grid, 
    num_coarse_samples=32, num_fine_samples=64,
    white_background=True, randomize=True
):
    """
    Renders a batch of rays using hierarchical sampling with occupancy grid skipping.
    
    Args:
        rays_o: Tensor [num_rays, 3], ray origins.
        rays_d: Tensor [num_rays, 3], ray directions.
        near: Float, near clipping plane.
        far: Float, far clipping plane.
        model: Neural network model returning (rgb, density).
        occupancy_grid: OccupancyGrid object with sample_occupied_regions method.
        num_coarse_samples: Int, number of coarse samples.
        num_fine_samples: Int, number of fine samples.
        white_background: Bool, if True, add white background to unoccupied space.
        randomize: Bool, if True, add jitter to samples.
        
    Returns:
        rgb_fine: Tensor [num_rays, 3]
        depth_fine: Tensor [num_rays]
        acc_fine: Tensor [num_rays]
    """
    num_rays = rays_o.shape[0]
    
    # Step 1: Normalize rays
    rays_d = F.normalize(rays_d, dim=-1)
    
    # Step 2: Coarse Sampling
    if occupancy_grid is not None:
        t_coarse = occupancy_grid.sample_occupied_regions(
            rays_o, rays_d, near, far, num_coarse_samples, randomize
        )
    else:
        # Fallback to stratified sampling if no grid
        t_coarse = sample_stratified_batch(near, far, num_coarse_samples, randomize)
        
    # Step 3: Render Coarse
    positions_coarse = rays_o.unsqueeze(1) + t_coarse.unsqueeze(2) * rays_d.unsqueeze(1)
    positions_coarse_flat = positions_coarse.reshape(-1, 3)
    directions_coarse_flat = rays_d.unsqueeze(1).expand(-1, num_coarse_samples, -1).reshape(-1, 3)
    
    # Handle model input compatibility: if model expects directions but we only need density, pass zeros
    # This is a pitfall guard [G]
    rgb_coarse_flat, density_coarse_flat = model(positions_coarse_flat, directions_coarse_flat)
    
    rgb_coarse = rgb_coarse_flat.reshape(num_rays, num_coarse_samples, 3)
    density_coarse = density_coarse_flat.reshape(num_rays, num_coarse_samples)
    
    # Compute distances
    dists = t_coarse[:, 1:] - t_coarse[:, :-1]
    dists = torch.cat([dists, torch.full((num_rays, 1), 1e10, device=dists.device)], dim=-1)
    
    # Compute Alpha
    alpha_coarse = 1.0 - torch.exp(-density_coarse * dists)
    
    # Compute Transmittance
    # Add epsilon for stability [S1, unofficial]
    transmittance_coarse = torch.cumprod(
        torch.cat([torch.ones((num_rays, 1), device=alpha_coarse.device), 1.0 - alpha_coarse + 1e-10], dim=-1), 
        dim=-1
    )[:, :-1]
    
    # Compute Weights
    weights_coarse = transmittance_coarse * alpha_coarse
    
    # Integrate RGB
    rgb_integrated_coarse = torch.sum(weights_coarse.unsqueeze(-1) * rgb_coarse, dim=1)
    
    # Step 4: Compute Bins
    t_mid = 0.5 * (t_coarse[:, :-1] + t_coarse[:, 1:])
    bins = torch.cat([t_coarse[:, :1], t_mid, t_coarse[:, -1:]], dim=-1)
    
    # Step 5: Hierarchical Fine Sampling
    # Sample from bins weighted by coarse weights
    t_fine = sample_hierarchical(bins, weights=weights_coarse.detach(), num_fine_samples, deterministic=not randomize)
    
    # Step 6: Combine and Sort
    t_combined = torch.cat([t_coarse, t_fine], dim=-1)
    t_combined, _ = torch.sort(t_combined, dim=-1)
    
    # Step 7: Render Combined
    positions_combined = rays_o.unsqueeze(1) + t_combined.unsqueeze(2) * rays_d.unsqueeze(1)
    positions_combined_flat = positions_combined.reshape(-1, 3)
    directions_combined_flat = rays_d.unsqueeze(1).expand(-1, t_combined.shape[1], -1).reshape(-1, 3)
    
    rgb_combined_flat, density_combined_flat = model(positions_combined_flat, directions_combined_flat)
    
    rgb_combined = rgb_combined_flat.reshape(num_rays, t_combined.shape[1], 3)
    density_combined = density_combined_flat.reshape(num_rays, t_combined.shape[1])
    
    dists_combined = t_combined[:, 1:] - t_combined[:, :-1]
    dists_combined = torch.cat([dists_combined, torch.full((num_rays, 1), 1e10, device=dists_combined.device)], dim=-1)
    
    alpha_combined = 1.0 - torch.exp(-density_combined * dists_combined)
    transmittance_combined = torch.cumprod(
        torch.cat([torch.ones((num_rays, 1), device=alpha_combined.device), 1.0 - alpha_combined + 1e-10], dim=-1), 
        dim=-1
    )[:, :-1]
    
    weights_combined = transmittance_combined * alpha_combined
    
    rgb_integrated = torch.sum(weights_combined.unsqueeze(-1) * rgb_combined, dim=1)
    depth = torch.sum(weights_combined * t_combined, dim=-1)
    acc = torch.sum(weights_combined, dim=-1)
    
    # Background
    if white_background:
        rgb_final = rgb_integrated + (1.0 - acc.unsqueeze(-1))
    else:
        rgb_final = rgb_integrated
        
    return rgb_final, depth, acc
```

**Parameters:**
- `near`: Float, default 2.0. Near clipping plane distance [S1, unofficial].
- `far`: Float, default 6.0. Far clipping plane distance [S1, unofficial].
- `num_coarse_samples`: Int, default 32. Number of coarse samples per ray [S1, unofficial].
- `num_fine_samples`: Int, default 64. Number of fine samples per ray [S1, unofficial].
- `occupancy_grid`: Optional `OccupancyGrid` object. Used to skip empty regions [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Division by Zero in Ray-AABB Intersection:** When computing ray-AABB intersections for the occupancy grid, add $10^{-8}$ to ray directions to prevent division by zero [S1, unofficial].
- **Numerical Stability in Transmittance:** Add $10^{-10}$ to $(1 - \alpha)$ before computing `cumprod` to prevent NaNs when $\alpha \approx 1$ [S1, unofficial].
- **Model Input Compatibility:** If the model requires direction inputs but only density is needed for the coarse stage (or vice versa), dummy zero directions may be passed to satisfy input requirements [S1, unofficial].

## Subtopics

### [Distance Map Acceleration](972-distance-map-acceleration.md)
Uses distance fields to skip empty space. Choose when smooth distance information is available and beneficial for early ray termination.

### [Two-stage Ray Marching with Empty-Space Skipping](2985-two-stage-ray-marching-with-empty-space-skipping.md)
Skips empty intervals but does not use hierarchical importance sampling. Choose when simplicity is preferred over adaptive refinement.

## Operating characteristics
- **Time Complexity:** $O(N_{rays} \cdot (N_{coarse} + N_{fine}))$ per frame, where $N_{coarse}$ and $N_{fine}$ are the number of samples. The occupancy grid lookup is $O(1)$ per ray if implemented with hash maps or efficient 3D indexing.
- **Memory Complexity:** $O(N_{grid}^3)$ for the occupancy grid, where $N_{grid}$ is the resolution. The grid is typically sparse, but the boolean tensor is dense.
- **Measured Performance:** On a single GPU, FLASH achieves training times of 10-15 minutes for 5000 iterations on synthetic datasets (e.g., Lego), compared to 5+ hours for vanilla NeRF [S1, unofficial]. On CPU, it takes ~25 minutes [S1, unofficial].
- **Strengths:** Significantly faster training and inference than vanilla NeRF. Effective empty-space skipping reduces the number of samples needed. Hierarchical sampling improves image quality by concentrating samples in high-weight regions.
- **Limitations:** Requires an occupancy grid to be pre-computed or maintained. Performance depends on the quality of the occupancy grid. The method is specific to NeRF-like architectures and may not generalize to other volume rendering methods without modification.
- **When to Use:** When training NeRFs on limited hardware or time budgets, and when the scene has significant empty space.
- **When Not to Use:** When the scene is fully dense (no empty space to skip) or when the overhead of maintaining the occupancy grid outweighs the benefits.

## Background
Hierarchical Sampling with Occupancy Grid is an experimental implementation of Instant-NGP for Neural Radiance Fields, presented in the FLASH project [S1, unofficial]. It was developed to enable high-performance NeRF training in 10-15 minutes on a single GPU, leveraging multi-resolution hash encoding and occupancy grids for acceleration [S1, unofficial]. The method builds on the principles of Instant-NGP, which introduced hash encoding for fast feature lookup, and combines it with hierarchical sampling and occupancy grids for efficient ray marching [S1, unofficial].
