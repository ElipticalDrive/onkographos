# Hierarchical Sampling with Occupancy Grid

Also called: FLASH Renderer, NeRF Hierarchical Sampling

## Overview
Hierarchical Sampling with Occupancy Grid is a two-stage volume rendering method that accelerates Neural Radiance Field (NeRF) training and inference by combining empty-space skipping with importance-based sample refinement [S1, unofficial]. It uses an occupancy grid to skip empty regions during coarse sampling, then employs hierarchical sampling to refine sample positions based on coarse weights, combining coarse and fine samples for the final render [S1, unofficial]. This approach distinguishes itself from siblings like [Distance Map Acceleration](972-distance-map-acceleration.md) by using discrete occupancy flags rather than continuous distance bounds, and from [Two-stage Ray Marching with Empty-Space Skipping](2985-two-stage-ray-marching-with-empty-space-skipping.md) by explicitly integrating the coarse and fine stages into a single unified rendering pass with sorted combined samples.

## How it works

### Inputs and Outputs
**Inputs:**
- Ray origins $O$ and normalized directions $D$ for a batch of rays.
- Near ($n$) and far ($f$) clipping distances.
- Number of coarse samples ($N_c$) and fine samples ($N_f$).
- An occupancy grid structure (optional, see [Occupancy Grid and Map-Based Empty Space Skipping](3852-occupancy-grid-and-map-based-empty-space-skipping.md)).
- A neural network model (MLP) that takes 3D positions and view directions as input and outputs RGB color and density.

**Outputs:**
- Integrated RGB color.
- Depth.
- Accumulated alpha (accumulation).

### Data Structures

**OccupancyGrid:**
- `resolution` (int): The side length of the cubic grid.
- `aabb_min` (tensor [3]): Minimum coordinates of the axis-aligned bounding box (AABB) covering the scene.
- `aabb_max` (tensor [3]): Maximum coordinates of the AABB.
- `density_threshold` (float): Threshold used to determine if a voxel is occupied.
- `grid` (bool tensor [resolution, resolution, resolution]): Binary occupancy map.
- `voxel_size` (tensor [3]): Size of each voxel in world units.

### Parameters
- `near`: float, default 2.0. Near clipping plane.
- `far`: float, default 6.0. Far clipping plane.
- `num_coarse_samples`: int, default 32.
- `num_fine_samples`: int, default 64.
- `randomize`: bool, default True. Whether to add jitter to sample positions.

### Steps

1.  **Normalize Ray Directions:**
    Ensure ray directions are unit vectors.
    $$ D = \text{normalize}(D) $$

2.  **Coarse Sampling:**
    Generate $N_c$ sample positions along each ray.
    - If an `OccupancyGrid` is present, use it to skip empty regions. The ray is queried against the grid, and samples are only generated in occupied blocks or using stratified sampling within occupied intervals [S1, unofficial].
    - If no occupancy grid is present, use stratified sampling between $n$ and $f$ [S1, unofficial].
    Let the resulting t-values be $t_{\text{coarse}} \in \mathbb{R}^{B \times N_c}$, where $B$ is the batch size.

3.  **Coarse Rendering:**
    Evaluate the model at coarse positions $P_{\text{coarse}} = O + t_{\text{coarse}} \cdot D$ to get RGB and density. Compute transmittance, weights, and integrated color/depth using the standard volume rendering equations (see Formulas below).
    - Compute distances between samples: $d_i = t_{i+1} - t_i$. Handle the last sample by setting $d_{N_c} = 10^{10}$ (effectively infinite) [S1, unofficial].
    - Compute alpha: $\alpha_i = 1 - \exp(-\sigma_i \cdot d_i)$.
    - Compute transmittance: $T_i = \prod_{j=0}^{i-1} (1 - \alpha_j)$. Use numerical stability term $10^{-10}$ in the product [S1, unofficial].
    - Compute weights: $w_i = T_i \cdot \alpha_i$.
    - Compute coarse color: $C_{\text{coarse}} = \sum w_i c_i$.
    - Compute coarse depth: $Z_{\text{coarse}} = \sum w_i t_i$.
    - Compute coarse accumulation: $A_{\text{coarse}} = \sum w_i$.

4.  **Construct Bins for Hierarchical Sampling:**
    Create bins based on the cumulative weight distribution of the coarse samples.
    - Compute midpoints: $t_{\text{mid}, i} = 0.5 (t_{\text{coarse}, i} + t_{\text{coarse}, i+1})$ for $i=0 \dots N_c-2$.
    - Construct bins tensor: $B_{\text{bins}} = [t_{\text{coarse}, 0}, t_{\text{mid}, 0}, \dots, t_{\text{mid}, N_c-2}, t_{\text{coarse}, N_c-1}]$. This results in $2N_c - 1$ bin edges [S1, unofficial].

5.  **Fine Sampling:**
    Sample $N_f$ points within the bins defined above, weighted by the coarse weights $w_{\text{coarse}}$. This concentrates samples in regions where the object is likely present (high alpha) [S1, unofficial].
    - Use inverse CDF sampling based on the cumulative sum of $w_{\text{coarse}}$ to select bins and then uniform samples within those bins.
    - Let the resulting t-values be $t_{\text{fine}} \in \mathbb{R}^{B \times N_f}$.

6.  **Combine and Sort Samples:**
    Concatenate coarse and fine t-values and sort them along the sample dimension.
    $$ t_{\text{combined}} = \text{sort}(\text{concat}(t_{\text{coarse}}, t_{\text{fine}})) $$
    The total number of samples is $N_c + N_f$.

7.  **Final Rendering:**
    Evaluate the model at all combined positions $P_{\text{combined}} = O + t_{\text{combined}} \cdot D$.
    - Compute distances, alpha, transmittance, and weights for the combined samples.
    - Compute final color: $C_{\text{final}} = \sum w_i c_i$.
    - If a white background is assumed, add the background contribution: $C_{\text{final}} = C_{\text{final}} + (1 - A_{\text{final}}) \cdot 1.0$, where $A_{\text{final}} = \sum w_i$ [S1, unofficial].
    - Compute final depth: $Z_{\text{final}} = \sum w_i t_i$.

### Formulas

**Alpha:**
$$ \alpha_i = 1 - \exp(-\sigma_i \cdot d_i) $$
where $\sigma_i$ is the predicted density and $d_i$ is the distance between adjacent samples.

**Transmittance:**
$$ T_i = \prod_{j=0}^{i-1} (1 - \alpha_j + \epsilon) $$
where $\epsilon = 10^{-10}$ for numerical stability [S1, unofficial].

**Weights:**
$$ w_i = T_i \cdot \alpha_i $$

**Integrated Color:**
$$ C = \sum_{i} w_i c_i $$

**Depth:**
$$ Z = \sum_{i} w_i t_i $$

**Accumulation:**
$$ A = \sum_{i} w_i $$

**Final Color (White Background):**
$$ C_{\text{final}} = C + (1 - A) $$

### Pseudocode

```python
import torch

def hierarchical_rendering_with_occupancy_grid(
    rays_o, rays_d, near, far, num_coarse, num_fine, 
    occupancy_grid, model, white_background=True
):
    """
    rays_o: [B, 3] ray origins
    rays_d: [B, 3] ray directions (assumed normalized)
    near, far: float
    num_coarse, num_fine: int
    occupancy_grid: Optional OccupancyGrid object
    model: callable (positions, directions) -> (rgb, density)
    """
    # 1. Normalize rays
    rays_d = torch.nn.functional.normalize(rays_d, dim=-1)
    
    # 2. Coarse Sampling
    if occupancy_grid is not None:
        # Use occupancy grid to skip empty regions
        # This function should return t_coarse of shape [B, num_coarse]
        t_coarse = occupancy_grid.sample_occupied_regions(
            rays_o, rays_d, near, far, num_coarse, randomize=True
        )
    else:
        # Fallback to stratified sampling
        t_coarse = sample_stratified_batch(near, far, num_coarse, randomize=True)
        
    # 3. Coarse Rendering
    # Expand dimensions for broadcasting: rays_o [B,1,3], t_coarse [B,Nc,1], rays_d [B,1,3]
    positions_coarse = rays_o.unsqueeze(1) + t_coarse.unsqueeze(2) * rays_d.unsqueeze(1)
    positions_flat = positions_coarse.reshape(-1, 3)
    directions_flat = rays_d.unsqueeze(1).expand(-1, num_coarse, -1).reshape(-1, 3)
    
    rgb_coarse, density_coarse = model(positions_flat, directions_flat)
    rgb_coarse = rgb_coarse.reshape(-1, num_coarse, 3)
    density_coarse = density_coarse.reshape(-1, num_coarse)
    
    # Compute distances
    dists = t_coarse[:, 1:] - t_coarse[:, :-1]
    # Append a large value for the last segment
    dists = torch.cat([dists, torch.full((dists.shape[0], 1), 1e10, device=dists.device)], dim=-1)
    
    # Compute alpha, transmittance, weights
    alpha = 1.0 - torch.exp(-density_coarse * dists)
    # Numerical stability: add epsilon to 1-alpha
    one_minus_alpha = 1.0 - alpha + 1e-10
    transmittance = torch.cumprod(torch.cat([torch.ones_like(one_minus_alpha[:, :1]), one_minus_alpha[:, :-1]], dim=-1), dim=-1)[:, :-1]
    weights = transmittance * alpha
    
    # Coarse color and depth
    rgb_integrated = torch.sum(weights.unsqueeze(-1) * rgb_coarse, dim=1)
    acc = torch.sum(weights, dim=1)
    
    # 4. Construct Bins
    # Midpoints between coarse samples
    t_mid = 0.5 * (t_coarse[:, :-1] + t_coarse[:, 1:])
    # Bins: [first_sample, midpoints..., last_sample]
    bins = torch.cat([t_coarse[:, :1], t_mid, t_coarse[:, -1:]], dim=-1)
    
    # 5. Fine Sampling
    # Sample from bins weighted by coarse weights
    t_fine = sample_hierarchical(bins, weights=weights.detach(), num_samples=num_fine, deterministic=not True)
    
    # 6. Combine and Sort
    t_combined = torch.cat([t_coarse, t_fine], dim=1)
    t_combined, _ = torch.sort(t_combined, dim=1)
    
    # 7. Final Rendering
    positions_combined = rays_o.unsqueeze(1) + t_combined.unsqueeze(2) * rays_d.unsqueeze(1)
    positions_flat = positions_combined.reshape(-1, 3)
    directions_flat = rays_d.unsqueeze(1).expand(-1, t_combined.shape[1], -1).reshape(-1, 3)
    
    rgb_combined, density_combined = model(positions_flat, directions_flat)
    rgb_combined = rgb_combined.reshape(-1, t_combined.shape[1], 3)
    density_combined = density_combined.reshape(-1, t_combined.shape[1])
    
    dists_combined = t_combined[:, 1:] - t_combined[:, :-1]
    dists_combined = torch.cat([dists_combined, torch.full((dists_combined.shape[0], 1), 1e10, device=dists_combined.device)], dim=-1)
    
    alpha_combined = 1.0 - torch.exp(-density_combined * dists_combined)
    one_minus_alpha_combined = 1.0 - alpha_combined + 1e-10
    transmittance_combined = torch.cumprod(torch.cat([torch.ones_like(one_minus_alpha_combined[:, :1]), one_minus_alpha_combined[:, :-1]], dim=-1), dim=-1)[:, :-1]
    weights_combined = transmittance_combined * alpha_combined
    
    rgb_final = torch.sum(weights_combined.unsqueeze(-1) * rgb_combined, dim=1)
    acc_final = torch.sum(weights_combined, dim=1)
    
    if white_background:
        rgb_final = rgb_final + (1.0 - acc_final.unsqueeze(-1))
        
    depth_final = torch.sum(weights_combined * t_combined, dim=1)
    
    return rgb_final, depth_final, acc_final
```

### Edge Cases and Pitfalls
- **Division by Zero in Ray-AABB Intersection:** When computing ray-box intersections for the occupancy grid, add a small epsilon ($10^{-8}$) to the ray direction components to prevent division by zero if the ray is parallel to a box face [S1, unofficial].
- **Numerical Stability in Transmittance:** Add $10^{-10}$ to $(1 - \alpha)$ before computing the cumulative product to prevent underflow and NaN values [S1, unofficial].
- **Model Input Compatibility:** If the model requires both position and direction inputs but only density is needed for the occupancy grid check, dummy zero directions may be passed to satisfy the input signature [S1, unofficial].

## Subtopics

### Distance Map Acceleration
- **What it is:** Uses a distance field to determine how far a ray can travel in empty space.
- **Difference:** Uses continuous distance values rather than binary occupancy flags.
- **When to choose:** When smooth transitions between empty and filled space are needed or when the scene has large empty regions with gradual density changes.
- **Link:** [Distance Map Acceleration](972-distance-map-acceleration.md)

### Two-stage Ray Marching with Empty-Space Skipping
- **What it is:** A generic two-stage approach where the first stage skips empty space and the second stage refines samples.
- **Difference:** Does not necessarily use hierarchical sampling based on coarse weights; may use fixed refinement strategies.
- **When to choose:** When hierarchical sampling is not required or when the scene structure is better suited for fixed-step refinement.
- **Link:** [Two-stage Ray Marching with Empty-Space Skipping](2985-two-stage-ray-marching-with-empty-space-skipping.md)

### Empty Space Filtering (Training-Time Bounding Box)
- **What it is:** Filters out rays that do not intersect the scene's bounding box during training.
- **Difference:** A preprocessing step rather than a runtime sampling optimization; does not skip empty space within the bounding box.
- **When to choose:** When the scene is sparse and most rays miss the object entirely.
- **Link:** [Empty Space Filtering (Training-Time Bounding Box)](6752-empty-space-filtering-training-time-bounding-box.md)

## Operating characteristics

**Time Complexity:**
- Coarse sampling: $O(N_c)$ per ray.
- Fine sampling: $O(N_f)$ per ray.
- Total sampling: $O(N_c + N_f)$ per ray.
- The occupancy grid lookup is $O(1)$ per ray segment.

**Memory Complexity:**
- Occupancy Grid: $O(R^3)$ where $R$ is the grid resolution.
- Model: Depends on the MLP size and hash encoding table size.
- Samples: $O(B \cdot (N_c + N_f))$ for intermediate tensors.

**Measured Performance:**
- FLASH achieves training times of 10-15 minutes on a single GPU for synthetic scenes (e.g., Lego), compared to 5+ hours for vanilla NeRF [S1, unofficial].
- This speedup is attributed to the combination of Instant-NGP's hash encoding and the occupancy grid acceleration.

**Strengths:**
- Significant speedup in training and inference.
- Effective empty-space skipping reduces unnecessary model evaluations.
- Hierarchical sampling improves image quality by concentrating samples in relevant regions.

**Limitations:**
- Occupancy grid construction requires preprocessing.
- Memory usage increases with grid resolution.
- Performance depends on the sparsity of the scene; dense scenes benefit less from empty-space skipping.

**When to use:**
- When training NeRFs quickly is a priority.
- When the scene has significant empty space.
- When hardware resources allow for the occupancy grid storage.

**When not to use:**
- When memory is extremely constrained.
- When the scene is very dense with little empty space.
- When high precision in empty-space boundaries is critical (binary occupancy may be too coarse).

## Background

**Origin:**
- The method is part of the FLASH project, an experimental implementation of Instant-NGP for Neural Radiance Fields [S1, unofficial].
- Instant-NGP was originally introduced by Müller et al. in "Instant Neural Graphics Primitives with a Multiresolution Hash Encoding" (2022) [S1, unofficial].
- FLASH adapts these concepts with an occupancy grid for empty-space skipping and hierarchical sampling for refinement.

**History and Development:**
- FLASH is a learning project aimed at demonstrating fast NeRF training (10-15 minutes) [S1, unofficial].
- It builds upon the Instant-NGP architecture, which uses multi-resolution hash encoding for fast feature lookup.
- The occupancy grid and hierarchical sampling are added to further optimize the rendering pipeline.

**Usage:**
- Used in research and educational contexts for fast NeRF training.
- Suitable for applications requiring rapid prototyping of 3D scenes from 2D images.
