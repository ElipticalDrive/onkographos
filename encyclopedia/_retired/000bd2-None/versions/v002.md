# Hierarchical Sampling with Occupancy Grid

Also called: FLASH Renderer, NeRF Hierarchical Sampling

## Overview
Hierarchical Sampling with Occupancy Grid is a two-stage volume rendering method that accelerates Neural Radiance Field (NeRF) training and inference by combining empty-space skipping with importance-based sample refinement [S1, unofficial]. It uses a precomputed occupancy grid to skip empty regions during coarse sampling, then uses hierarchical sampling to refine sample positions based on coarse weights, combining coarse and fine samples for the final render [S1, unofficial]. It sets itself apart from siblings like [Distance Map Acceleration](972-distance-map-acceleration.md) by using a binary occupancy flag rather than distance metrics for skipping, and from [Two-stage Ray Marching with Empty-Space Skipping](2985-two-stage-ray-marching-with-empty-space-skipping.md) by explicitly integrating the coarse and fine samples into a single sorted list for the final compositing pass rather than just using fine samples [S1, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
- Ray origins $O$ and normalized directions $D$ for each pixel.
- Near ($near$) and far ($far$) clipping distances [S1, unofficial].
- Occupancy Grid structure (optional) [S1, unofficial].
- Neural network model (coarse and fine, or shared) [S1, unofficial].
- Number of coarse samples ($N_c$) and fine samples ($N_f$) [S1, unofficial].

**Outputs:**
- Rendered RGB color, depth, accumulated alpha, and weights for each ray [S1, unofficial].

### Data Structures
**OccupancyGrid:**
- `resolution`: Integer, the dimension of the cubic grid $d_{\text{occ}}$ [S1, unofficial].
- `aabb_min`: Tensor of shape $[3]$, minimum bounds of the scene [S1, unofficial].
- `aabb_max`: Tensor of shape $[3]$, maximum bounds of the scene [S1, unofficial].
- `density_threshold`: Float, threshold for determining occupancy [S1, unofficial].
- `grid`: Boolean tensor of shape $[resolution, resolution, resolution]$, storing occupancy flags [S1, unofficial].
- `voxel_size`: Tensor of shape $[3]$, size of each voxel [S1, unofficial].

### Steps
1. **Normalize Ray Directions:** Normalize ray directions to unit length [S1, unofficial].
   $$ D = \frac{D}{\|D\|} $$
2. **Coarse Sampling:**
   - If an Occupancy Grid is present, sample $N_c$ points along the ray, skipping empty regions defined by the grid. This involves checking the occupancy flag at the current position and jumping to the next occupied block boundary if empty [S1, unofficial].
   - If no Occupancy Grid is present, use stratified sampling between $near$ and $far$ [S1, unofficial].
   - Let the coarse sample positions be $t_{\text{coarse}} = [t_0, t_1, \dots, t_{N_c-1}]$ [S1, unofficial].
3. **Coarse Rendering:**
   - Evaluate the coarse model at positions $P_{\text{coarse}} = O + t_{\text{coarse}} \cdot D$ to get RGB and density [S1, unofficial].
   - Compute distances between samples: $d_i = t_{i+1} - t_i$ for $i=0 \dots N_c-2$, and $d_{N_c-1} = far - t_{N_c-1}$ (or a large value if not defined) [S1, unofficial].
   - Compute alpha: $\alpha_i = 1 - \exp(-\sigma_i \cdot d_i)$ [S1, unofficial].
   - Compute transmittance: $T_i = \prod_{j=0}^{i-1} (1 - \alpha_j)$ with $T_0 = 1$ [S1, unofficial].
   - Compute weights: $w_i = T_i \cdot \alpha_i$ [S1, unofficial].
   - Compute coarse RGB: $C_{\text{coarse}} = \sum w_i C_i$ [S1, unofficial].
4. **Hierarchical Sampling:**
   - Compute midpoints of coarse intervals: $m_i = \frac{t_i + t_{i+1}}{2}$ for $i=0 \dots N_c-2$ [S1, unofficial].
   - Construct bins: $bins = [t_0, m_0, m_1, \dots, m_{N_c-2}, t_{N_c-1}]$ [S1, unofficial].
   - Sample $N_f$ points from these bins using the coarse weights $w$ as probabilities [S1, unofficial].
   - Let the fine sample positions be $t_{\text{fine}}$ [S1, unofficial].
5. **Combine and Sort:**
   - Combine coarse and fine samples: $t_{\text{combined}} = \text{sort}(t_{\text{coarse}} \cup t_{\text{fine}})$ [S1, unofficial].
6. **Fine Rendering:**
   - Evaluate the fine model at positions $P_{\text{combined}} = O + t_{\text{combined}} \cdot D$ [S1, unofficial].
   - Compute distances $d_i$ between sorted samples [S1, unofficial].
   - Compute alpha, transmittance, and weights using the same formulas as step 3 [S1, unofficial].
   - Compute final RGB: $C_{\text{final}} = \sum w_i C_i$ [S1, unofficial].
   - If white background is assumed, add $(1 - \sum w_i)$ to the RGB [S1, unofficial].

import torch

def hierarchical_sampling_with_occupancy_grid(rays_o, rays_d, near, far, 
                                            num_coarse_samples, num_fine_samples,
                                            occupancy_grid, model_coarse, model_fine):
    """
    rays_o: [num_rays, 3]
    rays_d: [num_rays, 3]
    near: float
    far: float
    num_coarse_samples: int
    num_fine_samples: int
    occupancy_grid: OccupancyGrid object or None
    model_coarse: Coarse NeRF model
    model_fine: Fine NeRF model
    """
    # 1. Normalize Ray Directions
    rays_d = torch.nn.functional.normalize(rays_d, dim=-1)
    
    # 2. Coarse Sampling
    if occupancy_grid is not None:
        # Use occupancy grid to skip empty regions
        # This is a simplified representation; actual implementation depends on grid structure
        t_coarse = sample_occupied_regions(rays_o, rays_d, near, far, num_coarse_samples, occupancy_grid)
    else:
        # Stratified sampling
        t_coarse = sample_stratified_batch(near, far, num_coarse_samples)
        
    # 3. Coarse Rendering
    # Expand dimensions for batch processing
    # rays_o: [num_rays, 1, 3], rays_d: [num_rays, 1, 3], t_coarse: [num_rays, num_coarse_samples]
    positions_coarse = rays_o.unsqueeze(1) + t_coarse.unsqueeze(2) * rays_d.unsqueeze(1)
    positions_flat = positions_coarse.view(-1, 3)
    directions_flat = rays_d.unsqueeze(1).expand(-1, num_coarse_samples, -1).view(-1, 3)
    
    rgb_coarse_flat, density_coarse_flat = model_coarse(positions_flat, directions_flat)
    
    # Reshape back
    rgb_coarse = rgb_coarse_flat.view(rays_o.shape[0], num_coarse_samples, 3)
    density_coarse = density_coarse_flat.view(rays_o.shape[0], num_coarse_samples)
    
    # Compute distances
    dists = t_coarse[:, 1:] - t_coarse[:, :-1]
    dists = torch.cat([dists, torch.full((dists.shape[0], 1), 1e10, device=dists.device)], dim=-1)
    
    # Compute alpha, transmittance, weights
    alpha = 1.0 - torch.exp(-density_coarse * dists)
    # Add small epsilon for numerical stability
    transmittance = torch.cumprod(torch.cat([torch.ones((dists.shape[0], 1), device=alpha.device), 1.0 - alpha + 1e-10], dim=-1), dim=-1)[:, :-1]
    weights = transmittance * alpha
    
    # 4. Hierarchical Sampling
    # Compute midpoints
    t_mid = 0.5 * (t_coarse[:, :-1] + t_coarse[:, 1:])
    # Construct bins
    bins = torch.cat([t_coarse[:, :1], t_mid, t_coarse[:, -1:]], dim=-1)
    
    # Sample fine t-values based on weights
    t_fine = sample_hierarchical(bins, weights=weights.detach(), num_fine_samples)
    
    # 5. Combine and Sort
    t_combined = torch.cat([t_coarse, t_fine], dim=-1)
    t_combined, _ = torch.sort(t_combined, dim=-1)
    
    # 6. Fine Rendering
    positions_combined = rays_o.unsqueeze(1) + t_combined.unsqueeze(2) * rays_d.unsqueeze(1)
    positions_flat_combined = positions_combined.view(-1, 3)
    directions_flat_combined = rays_d.unsqueeze(1).expand(-1, t_combined.shape[1], -1).view(-1, 3)
    
    rgb_fine_flat, density_fine_flat = model_fine(positions_flat_combined, directions_flat_combined)
    
    rgb_fine = rgb_fine_flat.view(rays_o.shape[0], t_combined.shape[1], 3)
    density_fine = density_fine_flat.view(rays_o.shape[0], t_combined.shape[1])
    
    # Compute distances for combined samples
    dists_combined = t_combined[:, 1:] - t_combined[:, :-1]
    dists_combined = torch.cat([dists_combined, torch.full((dists_combined.shape[0], 1), 1e10, device=dists_combined.device)], dim=-1)
    
    alpha_combined = 1.0 - torch.exp(-density_fine * dists_combined)
    transmittance_combined = torch.cumprod(torch.cat([torch.ones((dists_combined.shape[0], 1), device=alpha_combined.device), 1.0 - alpha_combined + 1e-10], dim=-1), dim=-1)[:, :-1]
    weights_combined = transmittance_combined * alpha_combined
    
    # Compute final RGB
    rgb_integrated = torch.sum(weights_combined.unsqueeze(-1) * rgb_fine, dim=1)
    acc = torch.sum(weights_combined, dim=-1)
    
    # White background assumption
    rgb_final = rgb_integrated + (1.0 - acc.unsqueeze(-1))
    
    return rgb_final, acc

### Parameters
- `near`: Float, default 2.0. The near clipping plane distance for ray sampling [S1, unofficial].
- `far`: Float, default 6.0. The far clipping plane distance for ray sampling [S1, unofficial].
- `num_coarse_samples`: Int, default 32. Number of samples taken along each ray in the coarse stage [S1, unofficial].
- `num_fine_samples`: Int, default 64. Number of samples taken along each ray in the fine stage [S1, unofficial].
- `occupancy_grid`: Optional OccupancyGrid. An optional grid structure used to skip empty regions during sampling [S1, unofficial].

### Edge Cases and Pitfalls
- **Division by Zero in Ray-AABB Intersection:** Use `rays_d + 1e-8` to prevent division by zero when computing ray-AABB intersections [S1, unofficial].
- **Numerical Stability in Transmittance:** Add `1e-10` to `(1 - alpha)` before `cumprod` to ensure numerical stability [S1, unofficial].
- **Model Input Compatibility:** If the model lacks a `forward_with_density_only` method, dummy zero directions are passed to satisfy input requirements [S1, unofficial].

## Operating characteristics
- **Time Complexity:** The coarse stage is $O(N_c)$ and the fine stage is $O(N_c + N_f)$. The occupancy grid lookup is $O(1)$ per sample. Overall, it is faster than uniform sampling for sparse scenes due to empty-space skipping.
- **Memory Complexity:** The occupancy grid requires $O(d_{\text{occ}}^3)$ memory, where $d_{\text{occ}}$ is the resolution of the grid. The model memory is independent of the sampling strategy.
- **Measured Performance:** FLASH achieves training times of 10-15 minutes on a single GPU for 5000 iterations, compared to 5 hours 12 minutes for vanilla NeRF [S1, unofficial].
- **Strengths:** Fast training and inference, effective empty-space skipping, improved sample distribution via hierarchical sampling.
- **Limitations:** Requires precomputation of the occupancy grid, which can be memory-intensive for large scenes. The quality of the occupancy grid affects the performance of the empty-space skipping.
- **When to Use:** When training NeRFs on large, sparse scenes where empty-space skipping provides significant speedups.
- **When Not to Use:** When memory is constrained and the occupancy grid cannot fit, or when the scene is dense and empty-space skipping provides little benefit.

## Background
Hierarchical Sampling with Occupancy Grid is an experimental implementation of Instant-NGP for Neural Radiance Fields (NeRF), known as FLASH [S1, unofficial]. It was developed to enable fast learning for accurate scene hashing, allowing 3D scenes to be trained from 2D images in 10-15 minutes on a single GPU [S1, unofficial]. The method combines techniques from Instant-NGP, such as multi-resolution hash encoding, with hierarchical sampling and occupancy grid-based empty-space skipping to achieve significant speedups over vanilla NeRF [S1, unofficial].
