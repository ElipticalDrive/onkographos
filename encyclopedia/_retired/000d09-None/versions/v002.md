# Semi-Analytical Volume Rendering with Trilinear Interpolation

Also called: Analytical Integration with Trilinear Reconstruction, Semi-Analytical Preintegration for Hexahedral Cells, Semi-Analytical Volume Rendering, Trilinear Preintegration

## Overview
Semi-analytical volume rendering with trilinear interpolation is a direct volume ray casting technique for hexahedral cells that eliminates topological artifacts (discontinuities, holes) in isosurfaces by analytically determining optimal sampling points along the ray [S1]. It sets itself apart from standard trilinear interpolation [1531-trilinear-interpolation.md] by replacing uniform sampling with a piecewise-linear approximation over monotonic intervals defined by the analytical extrema of the reconstructed signal, ensuring no isovalue is missed [S1].

## How it works
**Inputs:**
- Scalar field values $s_{ijk}$ at the 8 corners $(i,j,k) \in \{0,1\}^3$ of a hexahedral cell [S1].
- Ray entry point $(x_0, y_0, z_0)$ and exit point $(x_1, y_1, z_1)$ in normalized cell coordinates $[0,1]^3$ [S1].
- Transfer functions: color $c(s)$ and opacity $\tau(s)$ [S1].

**Outputs:**
- Accumulated color intensity $I$ for the ray segment traversing the cell [S1].

**Data Structures:**
- Coefficients $a, b, c, d$ of the cubic polynomial $s(t)$ [S1].
- List of valid extrema $R = \{r_1, r_2, \dots\}$ within $[0,1]$ [S1].
- Monotonic intervals defined by sorted sampling points $T = \{0, r_1, r_2, 1\}$ [S1].

**Steps:**

1. **Ray Parametrization:**
   Compute the direction vector components as differences between exit and entry coordinates:
   $$v_x = x_1 - x_0, \quad v_y = y_1 - y_0, \quad v_z = z_1 - z_0$$
   The ray is parametrized as $x(t) = x_0 + t v_x$, $y(t) = y_0 + t v_y$, $z(t) = z_0 + t v_z$ for $t \in [0,1]$ [S1].

2. **Signal Reconstruction (Cubic Polynomial):**
   Substitute the ray parametrization into the trilinear interpolation formula to obtain $s(t) = a t^3 + b t^2 + c t + d$ [S1]. The coefficients are linear combinations of the corner values $s_{ijk}$ and ray parameters:
   $$a = (s_{100} - s_{000} + s_{010} + s_{001} + s_{111} - s_{110} - s_{011} - s_{101}) v_x v_y v_z$$
   $$b = (-x_0 v_y v_z - v_x y_0 v_z - v_x v_y z_0 + v_x v_z) s_{101} + (x_0 v_y v_z + v_x y_0 v_z + v_x v_y z_0) s_{111} + (v_y v_z - x_0 v_y v_z - v_x y_0 v_z - v_x v_y z_0) s_{011} + (-v_x v_z + v_x v_y z_0 - v_y v_z + x_0 v_y v_z + v_x y_0 v_z) s_{001} + (-v_x v_z + v_x y_0 v_z + v_x v_y z_0 - v_x v_y + x_0 v_y v_z) s_{100} + (-v_x y_0 v_z - x_0 v_y v_z + v_x v_y z_0) s_{110} + (-x_0 y_0 v_z - v_x y_0 z_0 - x_0 v_y z_0 + v_x v_y z_0) s_{010} + (-y_0 z_0 - x_0 y_0 + y_0 + x_0 y_0 z_0) s_{010} + (-y_0 - z_0 - x_0 y_0 z_0 + x_0 z_0 + y_0 z_0) s_{001}$$
   Coefficients $c$ and $d$ are derived similarly by collecting terms of $t^1$ and $t^0$ respectively, resulting in sums of 8 terms each involving $s_{ijk}$ multiplied by products of $x_0, y_0, z_0$ and $v_x, v_y, v_z$ [S1].

3. **Extrema Calculation:**
   Compute the derivative $s'(t) = 3a t^2 + 2b t + c$ [S1]. Find the roots of this quadratic equation:
   $$t = \frac{-2b \pm \sqrt{4b^2 - 12ac}}{6a}$$
   If $a=0$, solve the linear equation $2b t + c = 0$. If $a=0$ and $b=0$, the function is constant (no extrema) [G].

4. **Pruning and Sorting:**
   - Discard any roots $t$ such that $t < 0$ or $t > 1$ [S1].
   - Sort the remaining valid extrema $r_i$ in ascending order [S1].
   - Define the sampling points $T = [0, r_1, r_2, \dots, 1]$ [S1].

5. **Interval Approximation:**
   For each consecutive pair of sampling points $t_i, t_{i+1}$ in $T$, approximate the signal $s(t)$ as a linear interpolation between the values at the endpoints:
   $$s_{lin}(t') = (1-t') s(t_i) + t' s(t_{i+1}), \quad t' \in [0,1]$$
   where $t'$ is the local parameter within the interval $[t_i, t_{i+1}]$ [S1].

6. **Preintegration:**
   Compute the contribution of each interval using preintegration functions $C$ and $\alpha$.
   Let $L_i = t_{i+1} - t_i$ be the length of the interval.
   $$C(a, b, L) = \int_0^1 c((1-t') a + t' b) L e^{-\int_0^{t'} \tau((1-u) a + u b) L du} dt'$$
   $$\alpha(a, b, L) = 1 - e^{-\int_0^1 \tau((1-t') a + t' b) L dt'}$$
   The total intensity is accumulated using front-to-back alpha compositing:
   $$I = C(s(0), s(r_1), L_0) + (1 - \alpha(s(0), s(r_1), L_0)) C(s(r_1), s(r_2), L_1) + \dots$$

def semi_analytical_trilinear_render(s_corners, x0, y0, z0, x1, y1, z1, c_func, tau_func):
    """
    s_corners: list of 8 floats [s000, s100, s010, s001, s101, s011, s110, s111]
    x0,y0,z0: entry point in [0,1]^3
    x1,y1,z1: exit point in [0,1]^3
    c_func: color transfer function (returns RGB tuple)
    tau_func: opacity transfer function (returns float)
    """
    # 1. Ray direction
    vx = x1 - x0
    vy = y1 - y0
    vz = z1 - z0

    # 2. Compute cubic coefficients a, b, c, d for s(t) = a*t^3 + b*t^2 + c*t + d
    a, b, c, d = compute_cubic_coefficients(s_corners, x0, y0, z0, vx, vy, vz)

    # 3. Find extrema of s(t)
    # s'(t) = 3a*t^2 + 2b*t + c
    roots = solve_quadratic(3*a, 2*b, c)
    valid_extrema = sorted([r for r in roots if 0.0 <= r <= 1.0])

    # 4. Define sampling points
    sampling_points = [0.0] + valid_extrema + [1.0]

    # 5. Accumulate intensity using front-to-back compositing
    accumulated_alpha = 0.0
    accumulated_color = [0.0, 0.0, 0.0]

    for i in range(len(sampling_points) - 1):
        t_start = sampling_points[i]
        t_end = sampling_points[i+1]
        L = t_end - t_start

        s_start = eval_cubic(a, b, c, d, t_start)
        s_end = eval_cubic(a, b, c, d, t_end)

        # Preintegration over this interval
        interval_color, interval_alpha = preintegrate_interval(s_start, s_end, L, c_func, tau_func)

        # Front-to-back compositing
        accumulated_color = [accumulated_color[k] + (1.0 - accumulated_alpha) * interval_color[k] for k in range(3)]
        accumulated_alpha += (1.0 - accumulated_alpha) * interval_alpha

    return accumulated_color, accumulated_alpha

        for j in range(2):

                s_val = s_corners[i*4 + j*2 + k]
                # Basis polynomial coefficients for (1-x)^{1-i} x^i
                if i == 0:
                    cx = [1-x0, -vx, 0.0, 0.0]
                else:
                    cx = [x0, vx, 0.0, 0.0]
                if j == 0:
                    cy = [1-y0, -vy, 0.0, 0.0]
                else:
                    cy = [y0, vy, 0.0, 0.0]
                if k == 0:
                    cz = [1-z0, -vz, 0.0, 0.0]
                else:
                    cz = [z0, vz, 0.0, 0.0]
                # Convolve cx, cy, cz to get coefficients for t^0, t^1, t^2, t^3
                pc = [0.0]*4
                for m in range(4):
                    for n in range(4):
                        if m+n < 4: pc[m+n] += cx[m]*cy[n]
                p = [0.0]*4
                for m in range(4):
                    for n in range(4):
                        if m+n < 4: p[m+n] += pc[m]*cz[n]
                a += s_val * p[3]
                b += s_val * p[2]
                c += s_val * p[1]
                d += s_val * p[0]
    return a, b, c, d

def eval_cubic(a, b, c, d, t):

**Subtopics:**
### [Local Phong Shading with Semi-Analytical Integration](1345-local-phong-shading-with-semi-analytical-integration.md)
This method extends semi-analytical volume rendering by incorporating local Phong diffuse shading into the integration process. It solves the problem of accurate lighting in volume rendering by reconstructing the shading function as a quadratic polynomial along the ray, allowing for analytical integration of the light contribution. It sets itself apart from scalar-only semi-analytical methods by requiring at most one additional sampling point per cell to capture the shading extremum, while maintaining the topological accuracy of the underlying trilinear interpolation.

### AMR Cell Splitting for Continuity
A technique to handle hybrid cells in Adaptive Mesh Refinement (AMR) by propagating cell splits from the lower level cell to the higher level cell to ensure continuity across cell faces [S1]. It identifies hybrid cells (sharing an edge/face with a different level cell) and propagates splits by adding 'source split points' (using the higher-level cell's value) and 'destination split points' (using bilinearly interpolated values from a shared face) to the lower-level cell [S1]. This ensures continuity across cell faces either by using the neighbor's value or by matching the interpolation scheme of the neighbor cell, avoiding artifacts [S1].

## Operating characteristics
- **Time Complexity:** The method requires solving a quadratic equation and evaluating preintegration functions for each monotonic interval. The number of intervals is small (at most 3), making it faster than high-frequency uniform sampling for preserving topology [S1].
- **Memory Complexity:** Requires storage for preintegration tables (if used) or numerical quadrature routines [G].
- **Performance:** Efficient on current graphics hardware when combined with a hybrid CPU-GPU mesh traversal technique [S1].
- **Strengths:** Guarantees topological accuracy of isosurfaces; avoids missing isovalues; handles arbitrary transfer functions [S1].
- **Limitations:** As the topology is consistent from one frame to another, the only remaining kind of artifacts is wobbling of the surfaces and structures inside the cells as the viewpoint changes [S1]. Complex coefficient calculation for the cubic polynomial [S1].
- **When to use:** High-quality visualization of AMR datasets with hexahedral cells where topological accuracy is critical [S1].

## Background
Originated in a 2009 paper by [S1] titled "High-Quality, Semi-Analytical Volume Rendering for AMR...", this method was developed to address the challenges of visualizing Adaptive Mesh Refinement (AMR) datasets. It builds on the need for view-order cell traversal and high-quality rendering of hexahedral cells in AMR meshes, which often suffer from discontinuities in isosurfaces due to piecewise linear approximations [S1]. The method extends standard trilinear interpolation by leveraging the analytical properties of the reconstructed signal to determine sampling points [S1].
