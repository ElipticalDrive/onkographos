# Evans' Normal Modification

Also called: Ambient Occlusion with Normal Modification, Evans Normal Modification AO, Normal perturbation AO

## Overview
Evans' Normal Modification is a variant of ambient occlusion (AO) calculation that influences the surface point normal at each sample step to better approximate sky visibility effects [S1, unofficial][S2, unofficial]. It differs from its sibling [Quilez Ambient Occlusion](1117-quilez-ambient-occlusion.md) by modifying the ray direction (normal) at each step and changing the accumulation base from 2 to 1.1 [S1, unofficial][S2, unofficial]. It builds on [Evans Ambient Occlusion](1083-evans-ambient-occlusion.md) by perturbing the normal vector to simulate the effect of the sky dome more accurately than standard ray marching [S1, unofficial][S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Surface point $x$, initial normal $n$, scene distance field function $f(r)$, upward unit vector $u$, maximum steps $k_{max}$, step size $\Delta t$, scale parameter $s$, and normal modification parameter $\alpha$ [S1, unofficial][S2, unofficial].
*   **Output:** Final occlusion value in $[0, 1]$ [S1, unofficial][S2, unofficial].

**Data Structures:**
*   $k$: Integer loop counter.
*   $d$: Float distance value.
*   $occlusion$: Float accumulator.
*   $r$: Float3 sample position.
*   $n$: Float3 current normal vector [S1, unofficial][S2, unofficial].

**Parameters:**
*   $\alpha$: Normal modification strength. Evans used $0.5$ [S1, unofficial][S2, unofficial].
*   $u$: Upward pointing unit vector of the scene (e.g., $(0, 1, 0)$) [S1, unofficial][S2, unofficial].
*   $k_{max}$: Maximum number of sample steps [S1, unofficial][S2, unofficial].
*   $\Delta t$: Step size for ray marching [S1, unofficial][S2, unofficial].
*   $s$: Scale variable determining the darkening intensity [S1, unofficial][S2, unofficial].

**Algorithm:**
1.  Initialize $k = 1$, $d = 0$, $occlusion = 0$ [S1, unofficial][S2, unofficial].
2.  Loop while $k < k_{max}$:
    a. Calculate sample point position: $r = x + \Delta t \cdot k \cdot n$ [S1, unofficial][S2, unofficial].
    b. Calculate distance: $d = f(r)$ [S1, unofficial][S2, unofficial].
    c. Update occlusion accumulator:
       $$ occlusion = 1.1^k \cdot (k \cdot \|n\| \cdot \Delta t_k - d) $$
       The term $\Delta t_k$ refers to the step size used at iteration $k$ [S1, unofficial][S2, unofficial]. In standard implementations where $\Delta t$ is constant, $\Delta t_k = \Delta t$ [S1, unofficial][S2, unofficial]. The term $\|n\|$ is the Euclidean length of the current normal vector [S1, unofficial][S2, unofficial].
    d. Modify the normal vector:
       $$ n = n + \alpha u $$
       [S1, unofficial][S2, unofficial]
    e. Increment loop counter: $k = k + 1$ [S1, unofficial][S2, unofficial].
3.  Return final occlusion value:
    $$ 1 - \text{clamp}(s \cdot occlusion, 0, 1) $$
    [S1, unofficial][S2, unofficial]

**Pseudocode:**
```python
import math

def evans_normal_modification_ao(x, n, f, u, k_max, delta_t, s, alpha):
    k = 1
    occlusion = 0.0
    current_n = n  # Work on a copy to avoid mutating the original if needed
    
    while k < k_max:
        # Calculate sample point position along the current normal
        r = x + delta_t * k * current_n
        
        # Query distance field
        d = f(r)
        
        # Accumulate occlusion using the modified base 1.1
        # delta_t_k is the step size at iteration k (constant delta_t here)
        norm_n = math.sqrt(current_n[0]**2 + current_n[1]**2 + current_n[2]**2)
        term = k * norm_n * delta_t - d
        occlusion = (1.1 ** k) * term
        
        # Modify the normal vector to tilt towards the sky
        current_n = current_n + alpha * u
        
        k = k + 1
        
    # Final result
    result = 1.0 - max(0.0, min(1.0, s * occlusion))
    return result
```

**Edge Cases and Pitfalls:**
*   **Robustness:** The method is not robust; parameters do not have obvious default settings and must be adjusted for each scene or geometry type [S1, unofficial][S2, unofficial].
*   **Exaggerated Occlusion:** Using the modified algorithm globally can cause exaggerated occlusion or incorrect highlighting (e.g., a box appearing highlighted near the top) when shapes are in near vicinity, requiring different parameters than those used for isolated shapes like spheres [S1, unofficial][S2, unofficial].
*   **Hybrid Usage:** The method may need to be combined with the standard Evans AO algorithm. For example, Algorithm 3.4 (standard) is used for ground points while Algorithm 3.7 (modified) is used for sphere points to avoid incorrect shading interactions [S1, unofficial][S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of sample steps $k_{max}$. Each step involves a distance field query and vector arithmetic [S1, unofficial][S2, unofficial].
*   **Memory Complexity:** Constant $O(1)$ auxiliary memory, as only a few scalar and vector variables are maintained [S1, unofficial][S2, unofficial].
*   **Strengths:** Better approximates sky visibility effects compared to standard ray marching AO, making sphere-traced images resemble reference images more closely for curved surfaces like spheres [S1, unofficial][S2, unofficial].
*   **Limitations:** Not robust across different geometries; requires manual tuning of parameters ($\alpha$, $s$, $k_{max}$) for different scene types. Can produce artifacts like incorrect highlighting on box-like structures if applied uniformly [S1, unofficial][S2, unofficial].
*   **When to use:** When rendering curved surfaces (e.g., spheres) where sky visibility is important and the geometry is isolated or can be handled with specific parameters [S1, unofficial][S2, unofficial].
*   **When not to use:** For ground planes or box-like structures where standard AO performs better, or when a robust, parameter-free solution is required [S1, unofficial][S2, unofficial].

## Background
*   **Origin:** The method is based on work by Evans [Eva06a], who suggested influencing the surface point normal to better approximate sky effects [S1, unofficial][S2, unofficial].
*   **History:** It is presented as Algorithm 3.7 in the source material, modifying the earlier Algorithm 3.4 (standard Evans AO) [S1, unofficial][S2, unofficial]. The changes include adding the normal modification step, changing the accumulation base from 2 to 1.1, and explicitly showing the ray equation [S1, unofficial][S2, unofficial].
*   **Usage:** Used in GPU ray marching of distance fields for ambient occlusion, particularly in contexts where visual fidelity for curved surfaces is prioritized over robustness across all geometry types [S1, unofficial][S2, unofficial].
