# SVO Node Location
## Overview
SVO Node Location is a ray traversal algorithm that determines the specific octree node (internal or leaf) intersected by a ray at a given position, typically the ray origin or a point along the ray. It solves the problem of mapping a continuous 3D ray position to a discrete Sparse Voxel Octree (SVO) node index, enabling subsequent shading or payload retrieval. It differs from [Octree Node Lookup by Voxel](5120-octree-node-lookup-by-voxel.md) by explicitly handling ray geometry (intersection testing against child bounding boxes) to select the correct child branch, whereas the latter maps discrete voxel coordinates directly to node indices without ray-based intersection logic. It builds on [Sparse Voxel Octree Ray Traversal](2451-sparse-voxel-octree-ray-traversal.md) by providing the foundational step of identifying the active node during traversal.
## How it works
### Inputs and outputs
- **Inputs**:
  - `raypos`: 3D vector, the position of the ray origin or query point in world space [S1, S2, unofficial].
  - `raydir`: 3D vector, the direction of the ray (used for intersection testing) [S1, unofficial].
  - `address_space`: Memory buffer containing the SVO node data (payloads, child pointers) [S1, unofficial].
  - `root_lower`: 3D vector, the lower bound of the root node in world space [S1, unofficial].
  - `root_scale`: Scalar, the side length of the root node [S1, unofficial].
  - `max_depth`: Integer, maximum traversal depth. If 0, traverse until leaf [S1, unofficial].
  - `stack`: Stack data structure to record the traversal path for later reconstruction/backtracking [S1, unofficial].
- **Outputs**:
  - `located_node`: A structure containing the node index/info and its lower bound in world space, or a null indicator if the ray is outside bounds or the node has no children [S1, unofficial].

### Data structures
- **`first_node_t`**: Structure returned by child selection.
  - `node_info`: Contains `root_cd_goffset` (global offset in address space) and `best_corner` (octant index 0-7) [S1, unofficial].
  - `lower`: 3D vector, the lower bound of the selected child node [S1, unofficial].
- **Stack**: Parallel array or dynamic list storing `node_info` and bounds for backtracking [S1, unofficial].

### Steps
1. **Initialization**:
   - Set `pos = raypos` [S1, unofficial].
   - Set `lower = root_lower` [S1, unofficial].
   - Set `upper = root_lower + root_scale` [S1, unofficial].
   - Set `center = lower + 0.5 * root_scale` [S1, unofficial].
   - Set `scale = root_scale / 2.0` [S1, unofficial].
   - Set `depth = 0` [S1, unofficial].
   - Initialize `stack` as empty [S1, unofficial].

2. **Select First Child**:
   - Call `svo_select_first_node_f3` with `pos`, `raydir`, `lower`, `scale`, `root_cd_goffset` (initially root offset) [S1, unofficial].
   - This function iterates through all 8 children to find the one intersected by the ray closest to the origin (see *SVO First Node Selection* below).
   - Let the result be `first_node`.
   - Update `current_node = first_node.node_info` [S1, unofficial].
   - Update `lower = first_node.lower` [S1, unofficial].
   - Update `upper = lower + scale` [S1, unofficial].
   - Update `center = lower + 0.5 * scale` [S1, unofficial].

3. **Traversal Loop**:
   - While `(max_depth == 0 || depth < max_depth)`:
     - **Check for Leaf**: If `current_node` has no children (is a leaf), break loop [S1, unofficial].
     - **Determine Corner**:
       - Calculate child corner indices based on `pos` relative to `center`:
         ```python
         xcorneridx = 0 if pos.x < center.x else 1
         ycorneridx = 0 if pos.y < center.y else 1
         zcorneridx = 0 if pos.z < center.z else 1
         ```
       - Combine into a single octant index `corner = (xcorneridx << 2) | (ycorneridx << 1) | zcorneridx` [S1, S2, unofficial].
     - **Get Child Info**:
       - Retrieve child node info from `address_space` using `current_node` and `corner` [S1, unofficial].
       - If child does not exist (empty space), break loop [S1, S2, unofficial].
     - **Push to Stack**:
       - Push `current_node` onto `stack` [S1, unofficial].
     - **Update State**:
       - Increment `depth` [S1, unofficial].
       - Update `current_node` to the child node [S1, unofficial].
       - Update `lower`, `upper`, `center` for the new child (scale halves each level) [S1, unofficial].

4. **Return**:
   - Return `current_node` and its `lower` bound [S1, unofficial].

### Pseudocode
```python
def svo_locate_node(raypos, raydir, address_space, root_lower, root_scale, max_depth, stack):
    # Initialization
    pos = raypos
    lower = root_lower
    upper = root_lower + vec3(root_scale)
    center = lower + vec3(root_scale * 0.5)
    scale = root_scale / 2.0
    depth = 0
    
    # Select first child (root's child)
    # Note: root_cd_goffset is assumed to be 0 or passed separately; 
    # here we assume a helper gets the root's global offset.
    first_node = svo_select_first_node_f3(
        raypos=raypos, 
        raydir=raydir, 
        lower=lower, 
        scale=scale, 
        root_cd_goffset=0 # Placeholder for root offset
    )
    
    if first_node is null:
        return null # Ray outside root bounds or no intersection

    current_node = first_node.node_info
    lower = first_node.lower
    upper = lower + vec3(scale)
    center = lower + vec3(scale * 0.5)

    while max_depth == 0 or depth < max_depth:
        # Check if leaf
        if not has_children(current_node, address_space):
            break

        # Determine child corner
        xcorneridx = 0 if pos.x < center.x else 1
        ycorneridx = 0 if pos.y < center.y else 1
        zcorneridx = 0 if pos.z < center.z else 1
        corner = (xcorneridx << 2) | (ycorneridx << 1) | zcorneridx

        # Get child node info
        child_node = get_child_node(current_node, corner, address_space)
        
        # If child doesn't exist, we are in empty space
        if child_node is null:
            break

        # Push current to stack
        stack.push(current_node)

        # Update for next iteration
        depth += 1
        current_node = child_node
        scale /= 2.0
        lower = lower + vec3(corner * scale) # corner is 0-7, but needs component-wise offset
        # More precise lower update based on corner bits:
        # lower.x += (corner & 1) * scale
        # lower.y += ((corner >> 1) & 1) * scale
        # lower.z += ((corner >> 2) & 1) * scale
        # Re-calculate center and upper
        center = lower + vec3(scale * 0.5)
        upper = lower + vec3(scale)

    return current_node, lower

def svo_select_first_node_f3(raypos, raydir, lower, scale, root_cd_goffset):
    best_corner = null_corner
    best_distance = infinity
    best_child_lower = lower
    
    child_scale = scale / 2.0
    
    for corneri in range(0, 8):
        # Calculate child bounds
        # corner_offset is derived from corneri bits
        corner_offset = vec3(
            (corneri & 1),
            ((corneri >> 1) & 1),
            ((corneri >> 2) & 1)
        )
        child_lower = lower + corner_offset * child_scale
        child_upper = child_lower + vec3(child_scale)
        
        # Check intersection
        if not svo_fast_forward_intersects_f3(raypos, raydir, child_lower, child_upper):
            continue
            
        # Calculate exit point
        dir_bounds_upper = child_upper - raypos # Relative upper bound
        # Calculate t1 (exit distance) and outface
        t1, outface = calculate_t1_f3(raypos, raydir, dir_bounds_upper)
        
        if outface is null: # No valid intersection
            continue
            
        distance = t1 # Distance from ray origin to exit point
        
        if distance < best_distance:
            best_distance = distance
            best_corner = corneri
            best_child_lower = child_lower
            
    if best_corner is null_corner:
        return null
        
    node_info = create_node_info(root_cd_goffset, best_corner)
    return first_node_t(node_info=node_info, lower=best_child_lower)
```

### Parameters
- `max_depth`: Typical values depend on SVO depth. 0 implies full traversal to leaf [S1, unofficial].
- `root_scale`: Depends on scene bounding box. Typically 1.0 for normalized coordinates [S1, unofficial].

### Edge cases and pitfalls
- **Ray outside root bounds**: If `raypos` is not contained within `[root_lower, root_upper]`, return null [S1, unofficial].
- **Empty children**: If the selected child node does not exist (empty space in SVO), the traversal stops, and the current node (parent) is returned or a null indicator is used depending on implementation [S1, S2, unofficial].
- **Null exit face**: If `calculate_t1_f3` returns a null exit face (e.g., ray origin inside the box but no forward intersection, or degenerate geometry), skip that child [S1, unofficial].
- **Precision**: Floating-point comparisons for `pos < center` must handle edge cases where `pos` is exactly on the boundary [S1, unofficial].

## Subtopics

### SVO First Node Selection
This variant focuses on the initial step of selecting the correct child node of the current octree node that the ray intersects. It differs from standard point-based lookup by using ray-box intersection tests (`svo_fast_forward_intersects_f3`) to determine which of the 8 children the ray enters. It is chosen when the ray origin is not guaranteed to be inside a specific voxel or when precise entry point calculation is needed for shading. It calculates the exit point `t1` for each child and selects the one with the minimum positive distance [S1, unofficial].

### SVO Point Location
This method traverses the SVO from root to find the leaf node containing a given 3D position, without using ray direction. It differs from SVO Node Location by using simple binary mapping (front=1, back=0 for X/Y/Z) based on the position relative to the node center, rather than ray intersection tests. It is chosen for point queries, neighbor lookups, or when the ray direction is irrelevant. It returns `INDEX_NONE` if the position is outside volume bounds or if a child does not exist at the calculated path [S2, unofficial].

## Operating characteristics
- **Time Complexity**: $O(D)$, where $D$ is the depth of the SVO. Each step involves constant-time arithmetic and array lookups [S1, S2, unofficial].
- **Memory Complexity**: $O(D)$ for the stack if backtracking is required, otherwise $O(1)$ [S1, unofficial].
- **Performance**: Fast for sparse structures as it skips empty space. Performance degrades if the ray traverses many empty nodes without early termination [S1, unofficial].
- **Strengths**: Precise node identification for ray-based rendering; handles arbitrary ray origins [S1, unofficial].
- **Limitations**: Requires ray-box intersection calculations for each step; sensitive to floating-point precision at boundaries [S1, unofficial].

## Background
SVO Node Location is a fundamental component of ray marching and ray tracing through Sparse Voxel Octrees. It was implemented in the `landscapes` project by realazthat for real-time SVO rendering [S1, unofficial]. The concept of locating nodes by position is also used in pathfinding contexts, such as in UE5 tutorials for SVO-based pathfinding, where it is referred to as `FindLeaf` [S2, unofficial].
