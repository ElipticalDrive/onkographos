# Symmetry-aware Sparse Voxel DAG (SSVDAG)


## Overview
SSVDAG is a compact, lossless volume representation that merges subtrees identical through reflective symmetries (planar reflections along principal grid axes) and employs variable bit-rate encoding for child pointers to minimize memory footprint while maintaining GPU-friendly traversal performance [S1, unofficial]. It differs from its parent [Sparse Voxel Directed Acyclic Graph (SVDAG)](962-sparse-voxel-directed-acyclic-graph-svdag.md) by recognizing geometric similarity via transformations rather than requiring exact node identity, and from [Symmetry-aware Sparse Voxel DAG (SSVDAG)](1285-symmetry-aware-sparse-voxel-dag-ssvdag.md) by explicitly detailing the binary layout and tagged pointer encoding [1349-ssvdag-node-layout-and-tagged-pointer-encoding.md].

## How it works
**Inputs:** A Sparse Voxel Octree (SVO) or an existing SVDAG.
**Outputs:** A Symmetry-aware Sparse Voxel DAG (SSVDAG) stored in a compressed binary format.

**Data Structures:**
1.  **Indexing Structure:** Contains the maximum level $L$ and three 32-bit offsets indicating the start of each level in the inner level array [S1, unofficial].
2.  **Inner Node Header:** A 16-bit header containing a 2-bit code for each of the 8 potential children [S1, unofficial].
    *   Tag `00`: Reserved for null pointers (not stored).
    *   Tag `01`: Child pointer is 16 bits.
    *   Tag `10`: Child pointer is 32 bits.
    *   Tag `11`: Child pointer is 32 bits.
3.  **Child Pointer Formats:**
    *   **Tag 01 (16 bits):** Leftmost 3 bits encode the transformation $T$ (reflection codes). Remaining 13 bits encode the offset in number of level-words from the beginning of the next level [S1, unofficial]. A level-word is 2 bytes for an inner level and 8 bytes for the leaf level. This allows encoding reflections and references to nodes in the first $2^{14}$ bytes of an inner level or first $2^{16}$ bytes of the leaf level [S1, unofficial].
    *   **Tag 10/11 (32 bits):** Leftmost 3 bits encode the transformation $T$. Remaining 29 bits encode the lowest 29 bits of the offset. The highest bit of the offset is stored in the header or a subsequent byte (implementation detail not fully specified in sources, but implied by "highest bit of the offset is..." cut-off) [S1, unofficial].

**Algorithm Steps:**
The construction is a bottom-up external-memory process that reduces an SVO to a minimal SSVDAG by alternating phases at each level, starting from the finest level $L-1$ up to the root at level 0 [S1, unofficial].

1.  **Leaf Grouping (Coarsening):** The construction graph is coarsened by one level. $4^3$ grids are encoded as simple grids in a single array of bricks, each occupying 64 bits. This is done by grouping the $2^3$ leaves from the bottom-up process into $4^3$ inner nodes at level $L-2$ without performing new matches [S1, unofficial].

2.  **Leaf Node Clustering:**
    *   Each small voxel grid $G$ of size $2^3$ is represented by a binary number $B(G)$ by concatenating occupancy bits [S1, unofficial].
    *   The canonical representation $G^?$ is defined as $G^? = T_{x,y,z}(G)$ where $T_{x,y,z} = \arg \max_{T_{x,y,z}} B(T_{x,y,z}(G))$. This is the reflection with the largest integer value [S1, unofficial].
    *   Two leaf nodes are similar if their canonical representations are identical [S1, unofficial].
    *   A precomputed table of 256 entries maps all possible $2^3$ voxel combinations to the canonical transformation and the unique canonical representation (one of 46 possible ones) [S1, unofficial].

3.  **Inner Node Clustering:**
    *   Inner nodes $n_1$ and $n_2$ are merged if they represent the same subtrees under a transformation $T$ [S1, unofficial].
    *   First, sort inner nodes by the lexicographically sorted set of child pointers [S1, unofficial].
    *   During a streaming pass, verify similarity: for every tagged pointer $(tag, p)$ of $n_1$, it must map to $(T(tag), p)$ in $n_2$ if $p$ is not invariant to $T$, or to $(T(tag) \neg T(tag), p)$ if $p$ is invariant [S1, unofficial].
    *   Repeat for all 8 reflection combinations, stopping at the first match [S1, unofficial].
    *   Replace pointers to the clustered nodes in the immediately higher level with tagged pointers to the single representative, where the tag encodes the specific transformation required to recover the original subtree [S1, unofficial].

4.  **Frequency-based Pointer Compaction:**
    *   Nodes at each level are reordered by reference count (most referenced first) [S1, unofficial].
    *   Pointers are replaced by offsets from the beginning of the level array [S1, unofficial].
    *   The number of bits for each offset is chosen as the smallest available in the encoded format (16-bit or 32-bit based on the tag) [S1, unofficial].

**Pseudocode:**

```python
def build_ssvdag(svo):
    # Start from finest level L-1 up to root level 0
    for level in range(L - 1, -1, -1):
        # Phase 1: Clustering
        # Group nodes into clusters of self-similar nodes
        clusters = []
        for node in nodes_at_level(level):
            if node not in processed:
                cluster = [node]
                processed.add(node)
                # Find all nodes similar to 'node' under any reflection T
                for other_node in nodes_at_level(level):
                    if other_node not in processed:
                        if is_similar(node, other_node):
                            cluster.append(other_node)
                            processed.add(other_node)
                clusters.append(cluster)
        
        # Replace clusters with a single representative
        representatives = []
        for cluster in clusters:
            rep = cluster[0]
            # Calculate transformation T for each other node in cluster relative to rep
            for other in cluster[1:]:
                T = get_transformation(rep, other)
                # Store tagged pointer in parent level later
                # For now, mark other as pointing to rep with tag T
                other.parent.pointers[other.index_in_parent] = (T, rep)
            representatives.append(rep)
            
        # Phase 2: Sorting and Encoding
        # Reorder representatives by reference count (descending)
        representatives.sort(key=lambda n: n.reference_count, reverse=True)
        
        # Replace pointers with offsets and encode
        for i, rep in enumerate(representatives):
            rep.offset = i
            rep.header = encode_header(rep.children)
            rep.pointers = encode_pointers(rep.children, rep.offset)
            
    # Phase 3: Leaf Coarsening (Post-processing)
    # Group 2^3 leaves into 4^3 bricks
    bricks = []
    for brick in range(num_bricks):
        leaf_nodes = get_leaves_for_brick(brick)
        brick_data = pack_64_bits(leaf_nodes)
        bricks.append(brick_data)
        
    return SSVDAG(index=build_index(), inner_nodes=representatives, leaves=bricks)

def is_similar(node1, node2):
    # Check if node1 and node2 are similar under any of the 8 reflections
    for T in REFLECTIONS:
        match = True
        for i in range(8):
            tag1, ptr1 = node1.children[i]
            tag2, ptr2 = node2.children[i]
            
            # Check if pointers map correctly under T
            # If ptr1 is invariant to T, it must map to (T(tag1) ^ T(tag1), ptr1) in node2?
            # Source says: (T(tag) neg T(tag), p) if invariant. 
            # Assuming 'neg' means bitwise NOT or specific invariant flag handling.
            # Simplified logic based on source description:
            expected_tag2 = apply_tag_transform(tag1, T)
            
            # Check pointer equality and tag consistency
            if ptr1 != ptr2:
                # If pointers are same, check if subtree is invariant
                if not is_invariant(ptr1, T):
                    match = False
                    break
            else:
                if expected_tag2 != tag2:
                    match = False
                    break
        if match:
            return True
    return False

def get_transformation(rep, other):
    # Find T such that other == T(rep)
    for T in REFLECTIONS:
        if apply_transform(rep, T) == other:
            return T
    return None

def encode_header(children):
    header = 0
    for i in range(8):
        tag, ptr = children[i]
        if ptr is None:
            code = 0 # Null
        else:
            # Determine bit width needed for offset
            offset = ptr.offset
            if offset < 2**13: # Fits in 13 bits (16-bit total format)
                code = 1
            else:
                code = 2 # 32-bit format
        header |= (code << (2 * i))
    return header
```

**Parameters:**
*   **Symmetry Transforms:** Planar reflections along the main grid directions (X, Y, Z) [S1, unofficial].
*   **Leaf Size for Construction:** $2^3$ voxels [S1, unofficial].
*   **Transformation Encoding:** 3 bits corresponding to reflections along the X, Y, and Z axes [S1, unofficial]. The transformation $T_{x,y,z}$ is its own inverse: $T_{x,y,z}^{-1} = T_{x,y,z}$ [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Invariant Pointers:** When checking similarity, if a child pointer $p$ is invariant to the transformation $T$, the tag mapping logic differs from non-invariant pointers. The source specifies mapping to $(T(tag) \neg T(tag), p)$ if invariant, requiring careful implementation of the invariant check [S1, unofficial].
*   **Precision:** The method relies on exact bitwise comparison of canonical representations for leaves and exact pointer matching for inner nodes. Floating point errors are not applicable as it operates on discrete voxel grids and integer offsets.

## Subtopics

### [SSVDAG Node Layout and Tagged Pointer Encoding](1349-ssvdag-node-layout-and-tagged-pointer-encoding.md)
Defines the binary layout of inner nodes, replacing fixed-size child pointers with variable-length tagged pointers (2 or 4 bytes) that embed transformation codes, solving the memory overhead problem of standard SVDAGs where all pointers are fixed at 4 bytes.

## Operating characteristics
*   **Compression:** In the PowerPlant scene (64K$^3$ resolution, ~6 billion non-empty voxels), SSVDAG stores data in <86MB (0.123 bits/voxel), compared to 16.2GB for SVO (without pointers) and 167MB for SVDAG [S1, unofficial].
*   **Performance:** Real-time GPU in-core visualization with shading and shadows is achieved for the full Boeing 777 model at sub-millimetric precision [S1, unofficial]. The tracing overhead for SSVDAG compared to standard SVO/SVDAG is less than 15% [S1, unofficial].
*   **Memory Distribution:** In the Powerplant dataset, the most common 10% of nodes account for nearly 90% of references at level 14 and nearly 50% at level 11, justifying the frequency-based pointer compaction [S1, unofficial].
*   **Strengths:** High compression ratio for scenes with reflective symmetry; transparent to standard ray-casting algorithms; GPU-friendly traversal [S1, unofficial].
*   **Limitations:** Construction is complex and requires external-memory processing; limited to reflective symmetries (other similarity transforms not supported) [S1, unofficial].

## Background
SSVDAG was introduced by Alberto Jaspe Villanueva, Fabio Marton, and Enrico Gobbetti from CRS4 in 2016 [S1, unofficial]. It extends the concept of Sparse Voxel DAGs (SVDAGs) by incorporating symmetry-aware merging, building on prior work in DAG compression for SVOs [S1, unofficial].
