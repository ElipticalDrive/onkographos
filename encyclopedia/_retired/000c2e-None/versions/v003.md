# Error-Based Model Generation (Bottom-Up Fusion)

Also called: DP Removal, Tetrahedra Fusion

## Overview
This method performs a bottom-up simplification of the Multi-Tetra Framework to approximate high-resolution volume data with fewer tetrahedra, thereby reducing rendering time [S1]. It merges two child tetrahedra into their parent if fusion criteria are met, starting from the leaf nodes and ascending [S1].

## How it works

### Inputs and Outputs
*   **Input**: A Multi-Tetra binary tree representing the volume data, an error threshold, and the vertex values associated with the tree nodes [S1].
*   **Output**: A simplified set of tetrahedra (nodes) that approximate the original data within the error bound [S1].

### Data Structures
The implementation relies on three specific structures defined in the source [S1]:

1.  **Binary Tree Array**: Each item corresponds to a node, storing only vertex indices [S1]. Children addresses are not stored but calculated via simple arithmetic [S1].
2.  **Dividing Point Structure**: Stores addresses of tetrahedra sharing the dividing point and the maximum approximation error [S1].
3.  **Dividing Point Table**: Contains head pointers to chains [S1]. Each chain corresponds to a tree level [S1]. Each item in the chain is a Dividing Point Structure [S1].

### Algorithm Steps

1.  **Initialization**: Construct the Dividing Point Table [S1]. Populate the chains with Dividing Point Structures for all unique dividing points in the volume [S1]. For each structure, identify all tetrahedra sharing that point and store their addresses [S1].
2.  **Bottom-Up Error Calculation**: Calculate maximum approximation errors starting from the highest level in a bottom-to-up order [S1]. Visit only the dividing point table, not the tree nodes directly [S1]. For each dividing point, compute the current level error as the maximum among the errors of all tetrahedra pairs sharing the corresponding dividing point [S1]. Update the dividing point's stored error to be the maximum of the current level error and the error already stored from its children [S1]. After processing a dividing point, update its parent's error [S1]. Ascend to the next immediate level after all dividing points are processed [S1]. If children cannot be fused or any pair sharing the point cannot be fused, the current fusion fails [S1].
3.  **Model Generation**: Generate the approximate model by selecting nodes whose approximation errors are less than a given error threshold, while their parents' errors exceed the threshold [S1].

### Pseudocode

```python
def error_based_model_generation(dividing_point_table, tree_array, error_threshold):
    """
    Simplifies the Multi-Tetra framework using bottom-up fusion.
    
    Args:
        dividing_point_table: List of lists of DividingPoint objects, 
                              indexed by tree level from root to leaves.
        tree_array: List of node objects, each containing vertex indices.
        error_threshold: Maximum allowed approximation error.
        
    Returns:
        List of node indices to keep.
    """
    # 1. Bottom-Up Error Calculation
    # Process levels from highest (leaves) to root
    for level in range(len(dividing_point_table) - 1, -1, -1):
        for dp in dividing_point_table[level]:
            # [G] Compute current level error as maximum among errors of 
            # tetrahedra pairs sharing this dividing point.
            current_level_error = 0.0
            for tet_idx in dp.tetrahedra:
                # [G] Approximation error formula not given in the sources; 
                # implement standard metric for tetrahedron density/value deviation.
                tet_error = compute_approximation_error(tree_array[tet_idx])
                if tet_error > current_level_error:
                    current_level_error = tet_error
                    
            # Update stored error: max of current level error and error already stored from children
            dp.error = max(current_level_error, dp.error)
            
            # Update parent's error
            if dp.parent_dp is not None:
                dp.parent_dp.error = max(dp.parent_dp.error, dp.error)
                
    # 2. Model Generation
    kept_nodes = []
    for node_idx, node in enumerate(tree_array):
        # Node error is the max error of its dividing points
        node_error = 0.0
        for v in node.vertices:
            if v in dp_lookup and dp_lookup[v].error > node_error:
                node_error = dp_lookup[v].error
                
        # Find parent index using standard binary tree array arithmetic
        parent_idx = (node_idx - 1) // 2 if node_idx > 0 else None
        
        if parent_idx is not None:
            parent_error = 0.0
            for v in tree_array[parent_idx].vertices:
                if v in dp_lookup and dp_lookup[v].error > parent_error:
                    parent_error = dp_lookup[v].error
                    
            if node_error < error_threshold and parent_error > error_threshold:
                kept_nodes.append(node_idx)
        else:
            if node_error < error_threshold:
                kept_nodes.append(node_idx)
                
    return kept_nodes
```

### Parameters
*   **Error Threshold**: A precision value used to determine which nodes are included in the final model [S1]. Nodes with error $< \epsilon$ are kept if parent error $> \epsilon$ [S1].

### Edge Cases and Pitfalls
*   **Boundaries**: Dividing points on boundaries have fewer shared tetrahedra, simplifying the local fusion check and ensuring no widespread global effect on complexity [S1].
*   **Precision**: The approximation error calculation must be robust to ensure correct fusion decisions [S1].
*   **Degenerate Input**: Not given in the sources [S1].

## Subtopics

### Progressive Hierarchy with Multi-triangulation
A dynamic Level-of-Detail (LOD) technique based on creating a progressive hierarchy of tetrahedra stored in a multi-triangulation data structure [S2, unofficial]. It creates the multi-triangulation model by encoding all edge-collapse operations required to reduce the number of tetrahedra to a base mesh, then selectively refines the mesh to a given LOD using selection heuristics [S2, unofficial].

## Operating characteristics

*   **Time Complexity**: Proportional to the number of dividing points and tetrahedra [S1]. Visiting the dividing point table level by level avoids traversing the entire tree structure repeatedly, reducing rendering time geometrically [S1].
*   **Memory Complexity**: Requires storage for the binary tree array, the dividing point table, and the dividing point structures [S1]. The binary tree array stores only vertex indices, saving memory compared to storing explicit child pointers [S1].
*   **Strengths**: Reduces rendering time significantly by decreasing the number of tetrahedra [S1]. Bottom-up approach ensures fusion decisions are based on accumulated local errors [S1]. Local fusion does not have a widespread global effect on complexity, making the process efficient [S1].
*   **Limitations**: Requires pre-computation of errors for all dividing points [S1]. Accuracy depends on the approximation error metric [S1].

## Background

*   **Origin**: The method is part of the Multi-Tetra Framework for visualizing regular volume data [S1].
*   **History**: It builds on the idea of merging tetrahedra to reduce rendering time [S1]. The bottom-up approach is similar to techniques in [LH91] referenced in the source [S1].
*   **Usage**: Used for isosurface extraction and visualization of regular volume data, particularly where efficient rendering is required [S1].
