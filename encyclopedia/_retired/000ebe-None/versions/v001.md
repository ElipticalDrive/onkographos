# CSG Difference
Also called: SDF Difference, Subtraction of SDFs

## Overview
CSG Difference is a Constructive Solid Geometry (CSG) operator that combines two Signed Distance Fields (SDFs) to create a shape representing the volume of the second object minus the volume of the first. It solves the problem of creating complex geometries with holes or cutouts by defining a single implicit field where the interior is defined by the presence of object B and the absence of object A. It differs from simple union or intersection by specifically implementing the set-theoretic difference $B \setminus A$, ensuring the resulting surface normal and distance are consistent with the remaining material.

## How it works
The method takes two SDF functions, $S_a$ (the subtractor) and $S_b$ (the base), and a query point $p$. It outputs a new SDF value $S(p)$ representing the distance to the nearest surface of the combined shape, and optionally the gradient for shading.

**Inputs:**
- $S_a(p)$: Scalar distance to object A at point $p$.
- $S_b(p)$: Scalar distance to object B at point $p$.
- $V_a(p)$: Vector gradient (normal) of $S_a$ at $p$.
- $V_b(p)$: Vector gradient (normal) of $S_b$ at $p$.

**Data Structures:**
- Scalar fields: Single floating-point values per point.
- Vector fields: 3D vectors $(x, y, z)$ representing the gradient.

**Steps:**
1. Evaluate the scalar distance for both objects at the query point $p$:
   $$d_a = S_a(p)$$
   $$d_b = S_b(p)$$
2. Compute the combined scalar distance using the maximum function. The logic is that a point is inside the result if it is inside $B$ ($d_b < 0$) AND outside $A$ ($d_a > 0$). The distance is the minimum of the distance to $B$'s surface and the negated distance to $A$'s surface (treating $A$'s interior as "negative space" to be removed):
   $$S(p) = \max(d_b, -d_a)$$ [S1]
3. Compute the combined vector gradient (normal). The gradient of the difference is the maximum of the gradient of $B$ and the negated gradient of $A$. This preserves the correct surface orientation for ray marching and shading:
   $$V(p) = \max(V_b(p), -V_a(p))$$ [S1]
   *Note: The vector max operation is performed component-wise or via vector magnitude logic depending on implementation, but typically implies selecting the vector corresponding to the active surface closest to the zero-crossing.*

**Pseudocode:**
```python
def csg_difference_scalar(S_a, S_b, p):
    """
    Computes the scalar SDF value for the difference of A from B.
    S_a: function returning distance to A
    S_b: function returning distance to B
    p: query point
    """
    d_a = S_a(p)
    d_b = S_b(p)
    # Result is inside if inside B and outside A
    return max(d_b, -d_a)

def csg_difference_vector(V_a, V_b, p):
    """
    Computes the vector gradient for the difference of A from B.
    V_a: function returning gradient of A
    V_b: function returning gradient of B
    p: query point
    """
    g_a = V_a(p)
    g_b = V_b(p)
    # Gradient is max of B's gradient and negated A's gradient
    # Component-wise max for vector normals in this context
    return max(g_b, -g_a)
```

**Parameters:**
- None for the standard hard difference.

**Edge Cases:**
- If $d_a$ and $d_b$ are both positive, the point is outside both, and the distance is determined by the closer surface (standard min behavior for outside, but here handled by the max of negatives).
- Precision issues may arise when $d_a \approx 0$ or $d_b \approx 0$ near the boundary of the cutout.

## Subtopics

### Smooth Subtraction
A smooth approximation of the boolean subtraction operation for two SDFs, controlled by a blending parameter $k$. It is chosen when a sharp CSG cutout is undesirable and a gradual transition or filleted edge is preferred. It differs from the hard difference by using a smooth minimum-like blending function. The formula is:
$$\text{subtraction}(d_1, d_2, k) = \text{mix}(d_2, -d_1, h) + k \cdot h \cdot (1 - h)$$
where $h = \text{clamp}(0.5 - 0.5 \cdot \frac{d_2 + d_1}{k}, 0., 1.)$ and $\text{mix}(a, b, t) = a \cdot (1 - t) + b \cdot t$ [S2].
- $d_1$: Distance to object A (subtractor).
- $d_2$: Distance to object B (base).
- $k$: Blending radius or smoothness parameter [S2].

## Operating characteristics
- **Time Complexity:** $O(1)$ per sample, requiring two SDF evaluations and basic arithmetic.
- **Memory Complexity:** $O(1)$, no additional storage required beyond the two input fields.
- **Strengths:** Efficiently creates complex shapes with holes; compatible with standard ray marching.
- **Limitations:** The hard difference can produce sharp internal corners which may require smaller step sizes in ray marching to avoid overshooting the zero-crossing. Smooth subtraction introduces a parameter $k$ that must be tuned for visual quality.

## Background
CSG operations are fundamental in implicit modeling and SDF-based rendering. The specific scalar and vector formulations for difference are documented in implementations of isosurface rendering from SDFs. The smooth variant is utilized in differentiable rendering pipelines, such as those using PyTorch3D, to allow gradient-based optimization of scene parameters.
