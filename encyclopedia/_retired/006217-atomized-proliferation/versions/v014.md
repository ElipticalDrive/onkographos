# Atomized Proliferation

Also called: Atom Gaussian Densification

## Overview
Atomized Proliferation is a training optimization strategy for 3D Gaussian Splatting that enhances geometric precision by constraining Gaussians representing fine details into "Atom Gaussians" (isotropic spheroids with uniform size) and prioritizing their proliferation to align with scene geometry, followed by pruning to merge large smooth surfaces [S1, unofficial]. It sets itself apart from standard 3DGS densification by using a warm-up phase that aggressively densifies initially and then merges, leading to a declining and stabilizing trend in Gaussian count, whereas standard 3DGS struggles to stabilize densification [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ 3D Gaussians $\{G_i\}_{i=1}^N$ with properties Mean ($\boldsymbol{\mu}$), Covariance ($\boldsymbol{\Sigma}$), Color ($\mathbf{c}$), and Opacity ($\alpha$); input SfM (Structure from Motion) point cloud distances $d$; hyperparameters $\tau_c, \tau_s, \varepsilon, S, t_a, t_w$.
*   **Outputs:** An updated set of Gaussians with refined geometry and optimized parameters.

**Data Structures:**
*   **Gaussian Set:** A collection of objects containing fields $\boldsymbol{\mu}_i \in \mathbb{R}^3$, $\boldsymbol{\Sigma}_i \in \mathbb{R}^{3 \times 3}$, $\mathbf{c}_i \in \mathbb{R}^3$ (or SH coefficients), and $\alpha_i \in [0, 1]$.
*   **Atom Scale ($S$):** A scalar value derived from the input SfM points.

**Parameters:**
*   **Clone Threshold ($\tau_c$):** Threshold for cloning based on loss gradient. Typical value: $0.002$ [S1, unofficial].
*   **Split Threshold ($\tau_s$):** Base threshold for splitting. Typical value: $0.002$ [S1, unofficial].
*   **Prune Threshold ($\varepsilon$):** Opacity threshold for pruning. Typical value: $0.005$ (or $0.5$ for DTU dataset) [S1, unofficial].
*   **Atom Scale ($S$):** Defined as the $i$-th percentile of ordered distances from input SfM points, $S = P_i(d)$. Typically $P_1(d)$ (first percentile) [S1, unofficial].
*   **Atomized Proliferation Duration ($t_a$):** Iteration limit for atomization. Typical value: $7000$ [S1, unofficial].
*   **Warm-Up Duration ($t_w$):** Iteration limit for the warm-up phase. Typical value: $7000$ [S1, unofficial].
*   **Final Proportion ($p$):** The final proportion of the initial scale $S$ [S1, unofficial].

**Algorithm Steps:**
1.  **Initialization:** Calculate the Atom Scale $S$ from the input SfM points using the specified percentile $i$ (typically $i=1$). Initialize iteration counter $i=0$.
2.  **Iteration Loop:** For each training iteration $i$ from $0$ to total iterations:
    a.  **Atom Scale Update:** If $i < t_a$, update the effective atom scale $S_i$ using geometric progression:
        $$ S_i = S_{i-1} \cdot r_{i-1} $$
        where $r = p^{1/t_a}$ is the decay rate per iteration, and $S_0 = S$ [S1, unofficial].
    b.  **Process Each Gaussian:** For each Gaussian $G_k$ in the current set:
        i.  **Pruning:** If $\alpha_k < \varepsilon$ OR the covariance $\boldsymbol{\Sigma}_k$ is excessively large (determined by `IsTooLarge` function, typically based on trace or determinant thresholds not explicitly defined in sources [G]), remove $G_k$ from the set.
        ii. **Cloning:** If the loss gradient with respect to the Gaussian position $\nabla_{\boldsymbol{\mu}} L \ge \tau_c$, clone $G_k$ to bridge geometry gaps.
        iii. **Splitting:** If the loss gradient $\nabla_{\boldsymbol{\mu}} L \ge \min\left(\frac{i}{t_w}\tau_s, \tau_s\right)$ AND the maximum norm of the covariance $\|\boldsymbol{\Sigma}_k\|_{\max} > S_i$, split $G_k$ into smaller Gaussians. This condition applies during the warm-up phase ($i < t_w$) using a linearly increasing threshold [S1, unofficial].
        iv. **Atomization:** If the minimum norm of the covariance $\|\boldsymbol{\Sigma}_k\|_{\min} \le S_i$ AND $i < t_a$, designate $G_k$ as an Atom Gaussian. Set its size to $s = \sqrt[3]{S_i}$ (implying isotropic scale $s_1=s_2=s_3=\sqrt[3]{S_i}$). Fix its scale parameters to prevent backpropagation optimization; instead, update its scale via the geometric progression defined in step 2a [S1, unofficial].
3.  **Opacity Resetting:** Increase the frequency of opacity resetting during training to merge Gaussians depicting large, simple surfaces [S1, unofficial].

        tau_c: Clone threshold.
        tau_s: Split threshold.

    index = int(percentile_i / 100.0 * len(sorted_distances))
    S_initial = sorted_distances[index]
    
    # Calculate decay rate r
    # r = p^(1/ta)
    r = p ** (1.0 / ta)
    
    current_S = S_initial

**Edge Cases and Pitfalls:**
*   **Precision:** The geometric progression for scale update requires careful handling of floating-point precision over many iterations to avoid underflow [S1, unofficial].
*   **Boundaries:** The `IsTooLarge` function is not explicitly defined in the sources, which may lead to inconsistent pruning behavior across implementations [G].
*   **Degenerate Input:** If the SfM point cloud is sparse or has large gaps, the percentile-based Atom Scale $S$ may not accurately represent fine details, leading to poor atomization [S1, unofficial].
*   **Dataset Specifics:** For object-centered datasets like DTU, the Prune Threshold $\varepsilon$ should be increased to $0.5$ and Atom Scale $S$ to $P_{10}(d)$ to avoid over-pruning [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Similar to standard 3DGS, but with additional overhead for atomization checks and scale updates. Training time on Mip-NeRF360 is 0.28 hours vs 0.40 hours for standard 3DGS [S1, unofficial].
*   **Memory Complexity:** Model size is 749MB vs 869MB for standard 3DGS on Mip-NeRF360, indicating better compression due to merging of smooth surfaces [S1, unofficial].
*   **Scaling:** The method scales well with scene complexity due to the merging of large surfaces, reducing the total number of Gaussians needed [S1, unofficial].
*   **Strengths:** Improved geometric precision, faster convergence, and reduced model size [S1, unofficial].
*   **Limitations:** Requires careful tuning of hyperparameters (e.g., $\varepsilon$, $S$) for different datasets [S1, unofficial].
*   **When to Use:** When high-fidelity geometry is required, especially for scenes with intricate details [S1, unofficial].
*   **When Not to Use:** When computational resources are extremely limited and standard 3DGS performance is sufficient [S1, unofficial].

## Background
Atomized Proliferation was introduced in the paper "AtomGS: Atomizing Gaussian Splatting for High-Fidelity Radiance Field" by Liu, Xu, Hu, Chen, and Feng [S1, unofficial]. It addresses the issue of standard 3DGS struggling to stabilize densification and producing noisy meshes or blurry artifacts [S1, unofficial]. The method was developed to enhance geometric precision by constraining Gaussians into Atom Gaussians and prioritizing their proliferation [S1, unofficial].
