# Regularised Gaussian Fitting Loss

Also called: L1+Regularization Loss for Gaussians, Regularised Loss Function for Gaussian Fitting

## Overview
The Regularised Gaussian Fitting Loss is a composite objective function used to optimize Gaussian splat representations for volume rendering [S1, unofficial]. It combines an L1 reconstruction error with explicit regularization terms for splat amplitude and spatial extent [S1, unofficial]. It distinguishes itself from standard photometric losses by penalizing the magnitude and spread of the Gaussian parameters directly, rather than relying solely on pixel-wise fidelity, which helps stabilize optimization in early-stopped, capacity-constrained scenarios [S1, unofficial].

## How it works
**Inputs:**
- Predicted volume field generated by $K$ Gaussian splats.
- Target volume field (ground truth).
- Optimization hyperparameters: learning rate $lr$, amplitude regularization weight $\lambda_a$, extent regularization weight $\lambda_d$, and optional boundary weight $\lambda_b$.
- Model parameters per splat $k$: amplitude $a_k$, diagonal covariance entries $L_{k,ii}$ (softplus-activated), and center $\mu_{k,i}$.
- Volume extent $S_i$ along dimension $i$.
- Truncation threshold $\tau$.
- Minimum covariance floor $\sigma_{min}$.

**Outputs:**
- Scalar loss value $L$ to be minimized.

**Data Structures:**
- Splat parameters are stored in tensors of shape $(K, D)$ for covariance and $(K)$ for amplitude, where $D$ is the spatial dimensionality (e.g., 3).
- The diagonal covariance entries $L_{k,ii}$ are the raw optimized variables. The actual variance is $\max(\sigma_{min}, \text{softplus}(L_{k,ii}))$.

**Formulas:**
The total loss is defined as:
$$ L = L_{recon} + \lambda_a \sum_{k=1}^{K} |a_k| + \lambda_d \sum_{k=1}^{K} \sum_{i=1}^{D} |L_{k,ii} - \sigma_{min}| $$

Where:
- $L_{recon}$ is the L1 reconstruction loss between the predicted and target volumes.
- $|a_k|$ is the absolute amplitude of splat $k$.
- $|L_{k,ii} - \sigma_{min}|$ is the deviation of the diagonal covariance parameter from the minimum floor $\sigma_{min}$. Note that the source specifies the penalty is evaluated on the softplus-activated parameters above the floor, but the formula explicitly subtracts $\sigma_{min}$ from the parameter $L_{k,ii}$ inside the absolute value, implying the regularization acts on the raw parameter relative to the floor [S1, unofficial].
- $\lambda_a = 0.1 \times lr$.
- $\lambda_d = 0.01 \times lr$.

**Optional Boundary Term:**
An optional boundary-containment term can be added:
$$ L_{boundary} = \sum_{k=1}^{K} \sum_{i=1}^{D} \left[ \max(0, r_{k,i} - \mu_{k,i})^2 + \max(0, r_{k,i} - (S_i - 1 - \mu_{k,i}))^2 \right] $$
$$ r_{k,i} = \tau \sqrt{\sum_{j} L_{k,ij}} $$
Where $r_{k,i}$ is the effective radius of splat $k$ along dimension $i$ at truncation threshold $\tau$. This term penalizes splats whose effective radius extends beyond the volume boundaries $[0, S_i-1]$ [S1, unofficial].

**Parameters:**
- $\lambda_a$: Amplitude regularization weight. Typical value: $10^{-3}$ (assuming $lr=0.01$) [S1, unofficial].
- $\lambda_d$: Extent regularization weight. Typical value: $10^{-4}$ (assuming $lr=0.01$) [S1, unofficial].
- $\lambda_b$: Boundary weight. Disabled ($\lambda_b = 0$) in reported benchmarks [S1, unofficial].
- $lr$: Learning rate. Typical value: $0.01$ [S1, unofficial].

**Pseudocode:**
```python
def regularised_gaussian_fitting_loss(
    predicted_volume, 
    target_volume, 
    amplitudes,       # Shape: (K,)
    covariances_diag, # Shape: (K, D), raw parameters L_k,ii
    centers,          # Shape: (K, D)
    sigma_min,        # Scalar
    volume_extent,    # Shape: (D,)
    tau,              # Scalar, truncation threshold
    lr,               # Scalar, learning rate
    lambda_b=0.0      # Scalar, boundary weight
):
    # 1. L1 Reconstruction Loss
    # Assuming predicted_volume and target_volume are aligned tensors
    l_recon = torch.mean(torch.abs(predicted_volume - target_volume))
    
    # 2. Amplitude Regularization
    # Sum of absolute amplitudes over K splats
    l_amp = torch.sum(torch.abs(amplitudes))
    
    # 3. Extent Regularization
    # Sum of absolute deviations of diagonal covariance parameters from sigma_min
    # Note: Source specifies evaluation before amplitude clamp, on softplus-activated params above floor.
    # The formula uses |L_k,ii - sigma_min|. We assume covariances_diag are the raw L_k,ii.
    l_extent = torch.sum(torch.abs(covariances_diag - sigma_min))
    
    # 4. Boundary Containment (Optional)
    l_boundary = 0.0
    if lambda_b > 0:
        # Calculate effective radius r_k,i = tau * sqrt(sum_j L_k,ij)
        # Since covariances_diag are diagonal, sum_j L_k,ij is just the sum of the diagonal for that splat?
        # Wait, the formula says r_k,i = tau * sqrt(sum_j L_k,ij). 
        # If L is diagonal, L_k,ij is 0 for i!=j. So sum_j L_k,ij = L_k,ii.
        # Thus r_k,i = tau * sqrt(L_k,ii).
        # However, the source text says "sum_j L_k,ij". If L is the full covariance, this is the trace.
        # But the regularization term uses diagonal entries. 
        # Let's look closely: "r_k,i = tau sqrt(sum_j L_k,ij)". 
        # If L is diagonal, sum_j L_k,ij = L_k,ii.
        # So r_k,i = tau * sqrt(L_k,ii).
        
        # Effective radius for each splat and dimension
        # L_k,ii must be > 0. Softplus ensures positivity if raw params are used, 
        # but here we use covariances_diag directly in the boundary formula?
        # The source says r_k,i is calculated from L_k,ij. 
        # We assume covariances_diag contains the values to be used.
        # To be safe, we take the diagonal values.
        effective_radii = tau * torch.sqrt(covariances_diag) # Shape: (K, D)
        
        # Boundary penalties
        # Term 1: max(0, r - mu)^2
        # Term 2: max(0, r - (S - 1 - mu))^2
        term1 = torch.clamp(effective_radii - centers, min=0.0) ** 2
        term2 = torch.clamp(effective_radii - (volume_extent - 1 - centers), min=0.0) ** 2
        l_boundary = torch.sum(term1 + term2)
        
    # 5. Combine Losses
    # lambda_a = 0.1 * lr
    # lambda_d = 0.01 * lr
    lambda_a = 0.1 * lr
    lambda_d = 0.01 * lr
    
    total_loss = l_recon + lambda_a * l_amp + lambda_d * l_extent + lambda_b * l_boundary
    
    return total_loss
```

**Edge Cases and Pitfalls:**
- **Precision:** The regularization weights are scaled by the learning rate. If $lr$ changes, $\lambda_a$ and $\lambda_d$ must be adjusted proportionally to maintain the same regularization strength relative to the gradient scale [S1, unofficial].
- **Boundaries:** The boundary term is disabled in standard benchmarks. If enabled, ensure $S_i$ matches the grid dimensions exactly [S1, unofficial].
- **Covariance Floor:** The regularization term $|L_{k,ii} - \sigma_{min}|$ assumes $L_{k,ii}$ is the parameter above the floor. If the optimizer updates raw parameters that are then softplused, the penalty should be applied to the value above $\sigma_{min}$ [S1, unofficial].

A strategy where a nominal splat budget is distributed across sequential passes, fitting residuals left by frozen earlier passes. It is an alternative to single-pass fitting within this framework, evaluated for SSIM improvements despite higher wall time and marginal PSNR gains [3185-progressive-multi-pass-fitting.md].

## Operating characteristics
- **Time Complexity:** The loss computation is $O(K \cdot D)$ for the regularization terms and $O(N)$ for the reconstruction loss, where $N$ is the number of voxels/pixels. The optimization uses Adam, which has constant memory overhead per parameter [S1, unofficial].
- **Memory Complexity:** Memory usage is dominated by the splat parameters ($K \cdot D$) and the volume fields. The fixed-pool relocation mechanism keeps optimizer tensor shapes constant [S1, unofficial].
- **Performance:** L1 reconstruction loss outperforms MSE on held-out PSNR for 11 of 17 tested volumes, with gains between +0.20 and +7.78 dB, and never trails by more than 0.28 dB [S1, unofficial].
- **Strengths:** Stabilizes optimization in early-stopped scenarios; prevents excessive amplitude or spread of splats; L1 is robust to outliers compared to MSE.
- **Limitations:** Requires careful tuning of $\lambda_a$ and $\lambda_d$ relative to $lr$; boundary term adds complexity but is rarely used [S1, unofficial].
- **When to Use:** When optimizing Gaussian splats for volume rendering with limited iterations or fixed capacity, especially when L1 fidelity is preferred over MSE.
- **When Not to Use:** If MSE is strictly required for downstream metrics, or if boundary containment is critical and the optional term is not implemented.

## Background
The Regularised Gaussian Fitting Loss was introduced in the Luxar project for Gaussian splatting in microscopy and scalable web visualization of multidimensional scientific data [S1, unofficial]. It was developed to address the need for stable optimization of Gaussian representations in scientific volume data, where resolution varies and capacity is constrained. The method was benchmarked across 17 volumes, demonstrating the superiority of L1 loss combined with amplitude and extent regularization over MSE and Poisson deviance [S1, unofficial].
