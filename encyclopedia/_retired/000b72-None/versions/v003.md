# Differentiable Adaptive Stepsize Rendering

Also called: finite-difference stepsize backprop

## Overview
Differentiable Adaptive Stepsize Rendering is a PyTorch `torch.autograd.Function` that computes the forward pass of adaptive stepsize volume rendering and approximates the backward pass using finite differences to enable gradient-based optimization of stepsize maps [S1, unofficial]. It replaces the C++ autograd layer by routing between forward and backward C++ operations while handling gradient requirements [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Forward Input:** Step size tensor $S$ and settings containing viewport coordinates $[viewStartX, viewStartY, viewEndX, viewEndY]$, internal renderer resolution, and `valueScaling` [S1, unofficial].
- **Forward Output:** Rendered tensor $O$ [S1, unofficial].
- **Backward Input:** Upstream gradient tensor $\frac{\partial L}{\partial O}$ [S1, unofficial].
- **Backward Output:** Gradient tensor $\frac{\partial L}{\partial S}$ [S1, unofficial].

**Data Structures:**
- **Stepsize Map:** Tensor containing the adaptive step sizes [S1, unofficial]. The internal renderer expects this tensor to be padded with $1.0$ along the edges to match the full internal resolution before rendering [S1, unofficial].
- **Viewport:** List of four integers $[viewStartX, viewStartY, viewEndX, viewEndY]$ defining the rendering region used to crop and pad tensors to match the internal renderer resolution [S1, unofficial].
- **valueScaling:** Float retrieved from settings and passed to the renderer update; its exact mathematical role is not specified in the sources [S1, unofficial].

**Algorithm Steps:**
1. **Forward Pass:** Retrieve the viewport settings and internal resolution [S1, unofficial]. Assert that the input stepsize tensor shape matches the viewport dimensions [S1, unofficial]. Pad the stepsize tensor with a value of $1.0$ along the edges to match the full internal resolution required by the CUDA kernel [S1, unofficial]. Call the custom CUDA operation `render_adaptive_stepsize` on the padded stepsize tensor to compute the full rendered output [S1, unofficial]. Crop the full output to the viewport coordinates to obtain the final output [S1, unofficial]. Stack outputs and return [S1, unofficial].
2. **Backward Pass (Finite Difference Approximation):** Retrieve the saved original stepsize tensor and the forward output from the forward pass context [S1, unofficial]. For each batch item, add a perturbation $\epsilon$ to the stepsize tensor and pad the perturbed tensor with $1.0$ [S1, unofficial]. Render the perturbed stepsize tensor via the CUDA operation [S1, unofficial]. Crop the perturbed output to the viewport [S1, unofficial]. Compute the finite difference by subtracting the original output from the perturbed output and dividing by $\epsilon$ [S1, unofficial]. Multiply the result by the upstream gradient for the batch item and sum over channels [S1, unofficial]. Stack the batch gradients and return [S1, unofficial].

**Formula:**
$$s' = c' \cdot \frac{f(s+\epsilon) - f(s)}{\epsilon}$$
where $s$ is the original stepsize, $f(s)$ is the rendered output, $c'$ is the upstream gradient, $\epsilon$ is the perturbation magnitude, and $\cdot$ denotes element-wise multiplication followed by summation [S1, unofficial].

**Parameters:**
- **$\epsilon$ (epsilon):** Perturbation magnitude for the finite difference approximation, typically $10^{-3}$ (used in `torch.autograd.gradcheck` calls) [S1, unofficial].
- **Viewport:** Defines the rendering region as $[viewStartX, viewStartY, viewEndX, viewEndY]$, used to crop and pad tensors to match the internal renderer resolution [S1, unofficial].
- **valueScaling:** Retrieved from settings and passed to the renderer update; exact mathematical role not specified in the sources [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Boundary Conditions:** The stepsize map must be padded with $1.0$ along the edges to match the internal resolution [S1, unofficial].
- **Degenerate Input:** Not given in the sources.
- **Precision:** The source uses $\epsilon = 10^{-3}$, validated via `torch.autograd.gradcheck` [S1, unofficial].

**Pseudocode:**
```python
def forward(S, settings):
    viewport = settings.viewport  # [viewStartX, viewStartY, viewEndX, viewEndY]
    internal_w = settings.internal_width
    internal_h = settings.internal_height
    # Assert stepsizes shape matches viewport dimensions [S1, unofficial]
    assert S.shape[-1] <= internal_w and S.shape[-2] <= internal_h
    # Pad with 1.0 along edges to match full internal resolution [S1, unofficial]
    pad_left = internal_w - S.shape[-1]
    pad_right = 0
    pad_top = internal_h - S.shape[-2]
    pad_bottom = 0
    S_pad = torch.nn.functional.pad(S, (pad_left, pad_right, pad_top, pad_bottom), value=1.0)
    # Custom CUDA op: render_adaptive_stepsize(S_pad) [S1, unofficial]
    O_full = render_adaptive_stepsize(S_pad)
    # Crop output to viewport coordinates [S1, unofficial]
    O = O_full[:, :, viewport[1]:viewport[3], viewport[0]:viewport[2]]
    return O

def backward(grad_output, saved_tensors):
    S, O, settings = saved_tensors
    epsilon = 1e-3
    viewport = settings.viewport
    internal_w = settings.internal_width
    internal_h = settings.internal_height
    pad_left = internal_w - S.shape[-1]
    pad_right = 0
    pad_top = internal_h - S.shape[-2]
    pad_bottom = 0
    grad_S = []
    for b in range(S.shape[0]):
        # Pad perturbed stepsizes (s + epsilon) with 1.0 [S1, unofficial]
        S_perturbed = S[b] + epsilon
        S_perturbed_pad = torch.nn.functional.pad(S_perturbed, (pad_left, pad_right, pad_top, pad_bottom), value=1.0)
        # Render perturbed stepsizes via CUDA op [S1, unofficial]
        O_perturbed_full = render_adaptive_stepsize(S_perturbed_pad)
        # Crop perturbed output to viewport [S1, unofficial]
        O_e = O_perturbed_full[:, :, viewport[1]:viewport[3], viewport[0]:viewport[2]]
        # Compute finite difference, multiply by upstream gradient, sum over channels [S1, unofficial]
        grad_b = torch.sum(grad_output[b] * ((O_e - O[b]) / epsilon), dim=0, keepdim=True)
        grad_S.append(grad_b)
    return torch.stack(grad_S)
```

## Operating characteristics
- **Time Complexity:** The backward pass requires one additional forward render per batch item using a single perturbation added to the entire stepsize map [S1, unofficial].
- **Memory Complexity:** Requires storing the forward output and the original stepsize for the backward pass, plus temporary memory for the perturbed render [S1, unofficial].
