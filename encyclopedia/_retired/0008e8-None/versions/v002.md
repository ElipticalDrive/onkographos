# PSF-based Multiple Scattering Rendering

Also called: PSF convolution method, Point Spread Function method

## Overview
PSF-based Multiple Scattering Rendering is a practical method for rendering volumetric multiple scattering effects by treating the participating medium as a point spread function (PSF) that blurs incident radiance, thereby avoiding the costly direct numerical simulation of the radiative transfer equation [S1]. Unlike diffusion approximation, which is valid only for optically dense homogeneous media and assumes uniform angular distribution, this method handles spatially varying general materials and highly directional effects [S1]. Unlike the method by Narasimhan and Nayar, which is restricted to homogeneous isotropic media, this rendering algorithm allows for spatially varying participating media and accounts for anisotropic sources and visibility effects [S1].

## How it works
The core principle is that light transport in volumes can be formalized as a convolution of incident illumination and the PSF of the medium, where the PSF measures the spreading of incident radiance due to scattering events [S1]. The method relies on the mathematical path integration framework introduced by Tesfa [Tes87] and Perez et al. [PAS03] to describe multiple scattering effects in terms of spatial and angular blurring [S1].

### Inputs and Outputs
*   **Inputs**:
    *   Incident illumination field (light volume) [G].
    *   Medium optical properties: scattering coefficients and phase function [S1].
    *   Medium geometry and spatial variation data [G].
*   **Outputs**:
    *   Rendered image or volume radiance field including multiple scattering contributions [G].

### Data Structures
The method utilizes a multi-level light volume representation [S1].
*   **Light Volume**: A 3D grid or texture storing incident radiance [G].
*   **Blurred Levels**: A set of pre-computed blurred versions of the light volume, each corresponding to a different kernel size representing different degrees of scattering spreading [S1].

### Parameters
*   **Scattering Coefficients**: Basic optical properties of the medium used to express the PSF [S1].
*   **Phase Function**: Basic optical property of the medium used to express the PSF [S1].
*   **Kernel Sizes**: Different sizes of blurring kernels applied to the light volume [S1].

### Steps
1.  **Compute Reduced Intensity**: Calculate the amount of light available for redistribution due to multiple scattering by computing the simple attenuation of the incident illumination [S1].
2.  **Pre-compute Blurred Light Volume**: Apply the point spread function to the light volume by blurring it with kernels of different sizes. Store the light volume at various levels of detail corresponding to these blurs [S1].
3.  **Rendering Lookup**: During rendering, at every point in the volume, compute the amount of spreading (blurring) occurring due to multiple scattering. Look up the result from the pre-computed blurred representation of the light volume based on the computed spreading [S1].

### Pseudocode
```python
import math

def gaussian_kernel_3d(size, sigma):
    """Generates a normalized 3D Gaussian kernel for blurring [G]."""
    k = size * 2 + 1
    kernel = [[[0.0] * k for _ in range(k)] for _ in range(k)]
    center = size
    total = 0.0
    for x in range(k):
        for y in range(k):
            for z in range(k):
                w = math.exp(-((x - center)**2 + (y - center)**2 + (z - center)**2) / (2 * sigma**2))
                kernel[x][y][z] = w
                total += w
    return [[[[w / total for w in row_z] for row_z in col_y] for col_y in plane_x] for plane_x in kernel]

def convolve_3d(volume, kernel):
    """Performs 3D convolution for precomputation [G]."""
    v_size = len(volume)
    k_size = len(kernel) // 2
    result = [[[0.0] * v_size for _ in range(v_size)] for _ in range(v_size)]
    for i in range(v_size):
        for j in range(v_size):
            for k in range(v_size):
                acc = 0.0
                for ki in range(-k_size, k_size + 1):
                    for kj in range(-k_size, k_size + 1):
                        for kk in range(-k_size, k_size + 1):
                            ni, nj, nk = i + ki, j + kj, k + kk
                            if 0 <= ni < v_size and 0 <= nj < v_size and 0 <= nk < v_size:
                                acc += volume[ni][nj][nk] * kernel[ki + k_size][kj + k_size][kk + k_size]
                result[i][j][k] = acc
    return result

def precompute_light_volume(incident_light_volume, scattering_coefficients, phase_function):
    """Step 1 & 2: Compute reduced intensity and apply PSF via multi-level blurring [S1]."""
    # Step 1: Compute reduced intensity due to simple attenuation
    # [G] Using Beer-Lambert law; distance is normalized or in world units
    reduced_intensity = [[[incident_light_volume[i][j][k] * math.exp(-scattering_coefficients * d) 
                          for k in range(len(incident_light_volume[0][0]))] 
                          for j in range(len(incident_light_volume[0]))] 
                          for i in range(len(incident_light_volume))]
    
    # Step 2: Apply PSF by blurring with different kernel sizes
    blurred_levels = []
    kernel_sizes = [1, 3, 5] # [G] Typical sizes representing different scattering spreads
    for size in kernel_sizes:
        kernel = gaussian_kernel_3d(size, sigma=size)
        blurred = convolve_3d(reduced_intensity, kernel)
        blurred_levels.append(blurred)
    return blurred_levels

def render_volume(origin, direction, step_size, max_dist, blurred_levels, scattering_coefficients):
    """Step 3: Ray march, compute spreading, lookup blurred volume, accumulate [S1]."""
    accumulated_radiance = [0.0, 0.0, 0.0, 0.0] # RGBA
    transmittance = 1.0
    t = 0.0
    while t < max_dist:
        pos = [origin[i] + direction[i] * t for i in range(3)]
        # [G] Check volume bounds; assume 0..1 normalized coordinates
        if not (0 <= pos[0] < 1 and 0 <= pos[1] < 1 and 0 <= pos[2] < 1):
            break
        
        # Compute spreading width based on distance traveled and optical properties
        # [G] Approximate spatial spreading width as proportional to distance and scattering coefficient
        spreading_width = math.sqrt(2.0 * scattering_coefficients * t)
        
        # Select appropriate blurred level based on spreading width
        level_idx = min(int(spreading_width), len(blurred_levels) - 1)
        blurred_vol = blurred_levels[level_idx]
        
        # Sample radiance from the blurred light volume
        # [G] Trilinear interpolation for smooth lookup
        sample_idx = [int(p * 99) for p in pos] # Assuming 100x100x100 grid
        radiance = blurred_vol[sample_idx[0]][sample_idx[1]][sample_idx[2]]
        
        # Accumulate with standard volume rendering equation
        # [G] Assuming constant extinction for simplicity
        step_transmittance = math.exp(-scattering_coefficients * step_size)
        accumulated_radiance[0] += radiance[0] * transmittance * (1.0 - step_transmittance)
        accumulated_radiance[1] += radiance[1] * transmittance * (1.0 - step_transmittance)
        accumulated_radiance[2] += radiance[2] * transmittance * (1.0 - step_transmittance)
        transmittance *= step_transmittance
        
        t += step_size
    
    accumulated_radiance[3] = 1.0 # Opaque alpha for demonstration
    return accumulated_radiance
```

### Edge Cases and Pitfalls
*   **Computational Cost of Alternatives**: Volumetric Monte Carlo and finite element techniques are computationally expensive, with solution times ranging from a few hours to a few days, making them impractical for usual computer graphics imagery [S1]. This method aims to avoid such costs.
*   **Homogeneous vs. Inhomogeneous**: The method is designed to handle inhomogeneous media, unlike diffusion approximation which is limited to homogeneous media [S1].
*   **Directional Effects**: The method accounts for highly directional effects and visibility, which are not easily handled by simpler analytic models restricted to homogeneous media [S1].

## Operating characteristics
*   **Time Complexity**: The pre-computation phase involves blurring the light volume with multiple kernels, which is generally faster than full radiative transfer simulation [S1]. The rendering phase involves lookups and interpolations, which are efficient [G].
*   **Memory Complexity**: Requires storing multiple levels of blurred light volumes, increasing memory usage compared to a single light volume [S1].
*   **Strengths**: Handles spatially varying participating media, anisotropic sources, and visibility effects [S1]. More practical than Monte Carlo methods for real-time or near-real-time applications [G].
*   **Limitations**: Relies on the accuracy of the PSF approximation. May not capture all complex scattering phenomena as accurately as full simulation [G].
*   **When to Use**: When realistic multiple scattering effects are needed in spatially varying volumes, and full simulation is too slow [S1].
*   **When Not to Use**: When extreme accuracy is required and computational resources are sufficient for Monte Carlo methods, or when the medium is optically dense and homogeneous (diffusion approximation might be simpler) [S1].

## Background
The mathematical path integration framework used to describe multiple scattering effects was introduced by Tesfa [Tes87] and Perez et al. [PAS03] [S1]. The method was presented as a practical approach to computing lighting and volumetric effects in spatially varying inhomogeneous scattering media, taking directionally-varying lighting effects into account [S1]. It addresses the limitation of previous analytic models that were restricted to homogeneous and/or optically dense media [S1].
