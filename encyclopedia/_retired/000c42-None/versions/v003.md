# Exact Projection First Contact

Also called: FHC, First Hit, First-Hit Compositing
## Overview
Exact Projection First Contact is a volume rendering technique that identifies the first voxel along a ray whose density value falls within a specified valid range, then applies shading and occlusion to that specific point [S1, S2, unofficial]. It differs from standard volume ray casting by discarding all subsequent samples after the first valid hit, effectively treating the volume as an opaque surface defined by the threshold [S1, S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Ray origin (`startPos`), ray direction (`rayDir`), near plane (`tNear`), far plane (`tFar`), volume texture (`volumeTexture`), color map texture (`colorMap`), minimum density threshold (`minDensityThreshold`), maximum density threshold (`maxDensityThreshold`), lighting flags (`enableLighting`, `enableAO`, `enableShadow`), and volume dimensions (`volumeDimensions`) [S1, unofficial].
*   **Outputs:** Final fragment color (`FragColor`).

**Data Structures:**
*   `volumeTexture`: 3D texture storing scalar density values [S1, unofficial].
*   `colorMap`: 1D or 2D texture mapping density values to RGBA colors [S1, unofficial].
*   `firstContactVal`: Float, stores the density value of the first hit. Initialized to `0.0` [S1, unofficial].
*   `firstContactPos`: Vec3, stores the 3D position of the first hit. Initialized to `startPos` [S1, unofficial].
*   `samplePos`: Vec3, current sampling position.
*   `t`: Float, current ray parameter.
*   `iterations`: Integer, loop counter.
*   `MAX_ITERATIONS`: Integer, safety limit (e.g., 2000) [S1, unofficial].

**Steps:**
1.  Normalize the ray direction: `rayDir = normalize(rayDir)` [S3, unofficial].
2.  Compute the entry (`tNear`) and exit (`tFar`) distances of the ray intersecting the unit cube `[0,1]^3` using the slab method [S3, unofficial].
3.  Clamp the entry distance to be at least `0.0` to ensure the starting point is in front of the camera [S3, unofficial].
4.  Initialize `firstContactVal = 0.0` and `firstContactPos = startPos` [S1, unofficial].
5.  Set `t = tNear` and `iterations = 0` [S1, unofficial].
6.  Loop while `t < tFar` and `iterations < MAX_ITERATIONS`:
    a.  Calculate `samplePos = startPos + rayDir * t` [S1, unofficial].
    b.  Compute step size `dt` for marching through the volume grid based on the inverse of the volume dimensions and the absolute ray direction components [S3, unofficial].
    c.  Sample density: `val = texture(volumeTexture, samplePos).r` [S1, unofficial].
    d.  Check range: `isInRange = (val >= minDensityThreshold && val <= maxDensityThreshold)` [S1, unofficial].
    e.  If `isInRange` is true: compute linear interpolation factor `alpha = (u_renderthreshold - valueN0) / (valueN1 - valueN0)`, set `firstContactPos = mix(pointN0, pointN1, alpha)`, `firstContactVal = mix(valueN0, valueN1, alpha)`, and break the loop [S3, unofficial].
    f.  Advance `t += dt` and increment `iterations` [S1, unofficial].
7.  If `firstContactVal <= 0.0f`, output `FragColor = vec4(0.0f)` and return [S1, unofficial].
8.  Map value to color: `baseColor = texture(colorMap, firstContactVal)` [S1, unofficial].
9.  Calculate lighting: If `enableLighting` is true, compute the surface normal via gradient estimation, then compute `shadedColor` using a local lighting model; else `shadedColor = baseColor.rgb` [S1, unofficial].
10. Calculate ambient occlusion: `occlusion = enableAO ? calculateOcclusion(firstContactPos) : 1.0f` [S1, unofficial].
11. Calculate shadow: `shadow = enableShadow ? calculateShadow(firstContactPos) : 1.0f` [S1, unofficial].
12. Output final color: `FragColor = vec4(shadedColor * occlusion * shadow, 1.0f)` [S1, unofficial].

**Pseudocode:**
```python
def exact_projection_first_contact(startPos, rayDir, tNear, tFar, volumeTexture, colorMap, minDensityThreshold, maxDensityThreshold, enableLighting, enableAO, enableShadow, volumeDimensions):
    # 1. Normalize ray direction [S3, unofficial]
    rayDir = rayDir / length(rayDir)
    
    # 2. Slab method for unit cube intersection [S3, unofficial]
    tMin = -float('inf')
    tMax = float('inf')
    for axis in range(3):
        if abs(rayDir[axis]) > 1e-6:
            t1 = (0.0 - startPos[axis]) / rayDir[axis]
            t2 = (1.0 - startPos[axis]) / rayDir[axis]
            if t1 > t2: t1, t2 = t2, t1
            tMin = max(tMin, t1)
            tMax = min(tMax, t2)
        else:
            if startPos[axis] < 0.0 or startPos[axis] > 1.0:
                return vec4(0.0, 0.0, 0.0, 1.0)
    if tMin > tMax:
        return vec4(0.0, 0.0, 0.0, 1.0)
        
    # 3. Clamp entry distance [S3, unofficial]
    tNear = max(0.0, tMin)
    tFar = min(tFar, tMax)
    if tNear >= tFar:
        return vec4(0.0, 0.0, 0.0, 1.0)
        
    # 4. Initialize [S1, unofficial]
    firstContactVal = 0.0
    firstContactPos = startPos
    t = tNear
    MAX_ITERATIONS = 2000
    iterations = 0
    prevPos = startPos
    prevVal = 0.0
    
    while t < tFar and iterations < MAX_ITERATIONS:
        currPos = startPos + rayDir * t
        
        # 5. Compute step size dt [S3, unofficial]
        voxelPos = currPos * volumeDimensions
        dt = float('inf')
        for axis in range(3):
            if abs(rayDir[axis]) > 1e-4:
                nextVoxel = floor(voxelPos[axis]) + 1.0 if rayDir[axis] > 0 else floor(voxelPos[axis])
                dtAxis = (nextVoxel - voxelPos[axis]) / (rayDir[axis] * volumeDimensions[axis])
                if dtAxis > 0:
                    dt = min(dt, dtAxis)
        dt = max(dt, 1e-4)
        
        # 6. Sample and check range [S1, unofficial]
        currVal = sample_volume(currPos) # [G] texture lookup
        isInRange = (currVal >= minDensityThreshold and currVal <= maxDensityThreshold)
        
        if isInRange:
            # 7. Linear interpolation refinement [S3, unofficial]
            if currVal != prevVal:
                alpha = (minDensityThreshold - prevVal) / (currVal - prevVal)
                firstContactPos = prevPos + alpha * (currPos - prevPos)
                firstContactVal = prevVal + alpha * (currVal - prevVal)
            else:
                firstContactPos = currPos
                firstContactVal = currVal
            break
            
        prevPos = currPos
        prevVal = currVal
        t += dt
        iterations += 1
        
    # 8. No hit check [S1, unofficial]
    if firstContactVal <= 0.0:
        return vec4(0.0, 0.0, 0.0, 1.0)
        
    # 9. Map to color [S1, unofficial]
    baseColor = sample_color_map(firstContactVal) # [G] color map lookup
        
    # 10. Lighting [S1, unofficial]
    if enableLighting:
        eps = vec3(1.0 / volumeDimensions[0], 1.0 / volumeDimensions[1], 1.0 / volumeDimensions[2])
        normal = normalize(vec3(
            sample_volume(firstContactPos + vec3(eps[0], 0, 0)) - sample_volume(firstContactPos - vec3(eps[0], 0, 0)),
            sample_volume(firstContactPos + vec3(0, eps[1], 0)) - sample_volume(firstContactPos - vec3(0, eps[1], 0)),
            sample_volume(firstContactPos + vec3(0, 0, eps[2])) - sample_volume(firstContactPos - vec3(0, 0, eps[2]))
        ))
        shadedColor = apply_lighting(normal, -rayDir, firstContactPos, baseColor.rgb) # [G] local lighting model
    else:
        shadedColor = baseColor.rgb
        
    # 11. Occlusion and Shadow [S1, unofficial]
    occlusion = compute_occlusion(firstContactPos) if enableAO else 1.0 # [G]
    shadow = compute_shadow(firstContactPos) if enableShadow else 1.0 # [G]
        
    # 12. Output [S1, unofficial]
    return vec4(shadedColor * occlusion * shadow, 1.0)
```

**Parameters:**
*   `minDensityThreshold`, `maxDensityThreshold`: Define the valid density range [S1, unofficial].
*   `MAX_ITERATIONS`: 2000 [S1, unofficial].
*   `stepSize`/`dt`: Determined by voxel traversal logic based on the inverse of the volume dimensions and the absolute ray direction components [S3, unofficial].

**Edge Cases and Pitfalls:**
*   **No Hit:** If no voxel in the ray path falls within the density range, the function outputs black [S1, unofficial].
*   **Precision:** Floating-point precision in `t` advancement can cause missed voxels or double sampling. Voxel traversal logic mitigates this [S1, unofficial].
*   **Boundaries:** Rays starting outside the volume or exiting early must be handled by the bounds check [S1, unofficial].
*   **Ray Direction:** The ray direction may not be normalized after interpolation from the vertex shader; it must be explicitly normalized before use [S3, unofficial].
