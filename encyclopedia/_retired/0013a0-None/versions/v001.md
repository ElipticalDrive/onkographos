# Voxelization of Lines and Planes

Also called: Slab-based Voxelization, N-separating Voxelization, 6-separating voxelization, 26-separating voxelization, 6-Separating Plane Voxelization, 26-Separating Plane Voxelization

## Overview
This method generates a discrete, topologically correct representation of 2D lines and 3D planes by defining a thickness parameter based on the surface normal and grid resolution. It guarantees **N-separability** (no N-connected holes) and **N-minimality** (no redundant voxels) for $N \in \{4, 6, 8, 26\}$ [S2]. Unlike rasterization-based approaches [Rasterization-based Voxelization] which may produce gaps, or interior fill methods [Interior Voxelize] which do not guarantee boundary topology, this analytic slab method ensures that 26-connected or 6-connected ray paths cannot penetrate the original separating surface [S1, unofficial][S2]. It is primarily used for surface discretization where topological integrity is critical for ray casting or marching cubes [S1, unofficial].

## How it works
**Inputs:**
- A geometric primitive: a 2D line or a 3D plane.
- Grid resolution $L$ (voxel width/size).
- Desired separability type $N \in \{4, 6, 8, 26\}$.

**Outputs:**
- A set of voxel/pixel indices $\tilde{S}$ marked as "black" (occupied).

**Data Structures:**
- A 3D grid (or 2D for lines) of boolean values or integer flags.
- For mesh extensions, voxels are classified into Vertex Voxels, Edge Voxels, and Body Voxels [S2].

**Formulas and Parameters:**
The plane equation is defined as:
$$ A_p X + B_p Y + C_p Z + D_p = 0 $$
The normal vector $(A_p, B_p, C_p)$ is normalized such that:
$$ \sqrt{A_p^2 + B_p^2 + C_p^2} = 1 $$
*(Note: Source text contains a typo $\frac{A_p^2 + B_p^2 + C_p^2}{2} = 1$, but standard normalization and context imply unit length [S2]).*

The thickness threshold $t_N$ determines the slab boundaries. A voxel at center $(x, y, z)$ is included if:
$$ -t_N \leq A_p x + B_p y + C_p z + D_p \leq t_N $$

The values for $t_N$ are derived geometrically:
- **26-separability (3D):** $t_{26} = \frac{L}{2 \sqrt{3} \cos \alpha}$, where $\alpha$ is the angle between the voxel diagonal and the plane normal [S2].
- **6-separability (3D):** $t_{6} = \frac{L}{2 \cos \beta}$, where $\beta$ is the angle between the face normal and the plane normal [S2].
- **8-separability (2D):** $t_{8} = \frac{L}{2 \sqrt{2} \cos \alpha}$, where $\alpha$ is the angle between the pixel diagonal and the line normal [S2].
- **4-separability (2D):** $t_{4} = \frac{L}{2 \cos \beta}$, where $\beta$ is the angle between the pixel edge normal and the line normal [S2].

**Steps:**
1. **Normalize:** Compute the unit normal $(A_p, B_p, C_p)$ for the plane (or $(A_p, B_p)$ for the line).
2. **Calculate Thickness:** Compute $t_N$ based on the chosen separability $N$, grid size $L$, and the angle between the normal and the grid's diagonal/edge vectors.
3. **Iterate Voxels:** For each voxel $(x, y, z)$ in the bounding volume:
   a. Calculate the signed distance value: $val = A_p x + B_p y + C_p z + D_p$.
   b. Check if $-t_N \leq val \leq t_N$.
   c. If true, mark the voxel as occupied (1); otherwise, mark as empty (0).
4. **Handle Degeneracies:** If the surface passes exactly through a corner or edge, apply infinitesimal perturbation to ensure intersection occurs strictly inside a voxel, avoiding ambiguous boundary cases [S1, unofficial].

**Pseudocode:**

def voxelize_plane(plane_normal, plane_d, grid_size, separability):
    """
    Voxelize a plane defined by normal (Ap, Bp, Cp) and distance Dp.
    plane_normal: tuple (Ap, Bp, Cp)
    plane_d: float Dp
    grid_size: float L (voxel width)
    separability: int, one of 6 or 26
    """
    Ap, Bp, Cp = plane_normal
    # Ensure normalization
    norm = sqrt(Ap**2 + Bp**2 + Cp**2)
    Ap, Bp, Cp = Ap/norm, Bp/norm, Cp/norm
    
    # Calculate thickness t
    if separability == 26:
        # Angle between voxel diagonal (1,1,1) and normal
        # cos(alpha) = (Ap*1 + Bp*1 + Cp*1) / (sqrt(3) * 1)
        cos_alpha = (Ap + Bp + Cp) / sqrt(3)
        # Handle potential numerical issues with cos_alpha near 0
        if abs(cos_alpha) < 1e-9:
            t = grid_size # Fallback, though geometrically unlikely for valid normal
        else:
            t = grid_size / (2 * sqrt(3) * abs(cos_alpha))
    elif separability == 6:
        # Angle between face normal (e.g., 1,0,0) and plane normal

        # Actually, t6 is derived from the angle with the face normal.

        # Beta is angle between N and normal to face.
        # To guarantee 6-separation, we must consider the worst-case face.
        # However, the source implies a single t6 derived from the normal.
        # Standard interpretation for 6-sep slab: t = L/2 is often used for axis-aligned,
        # but for arbitrary normals, the source specifies t6 = L / (2 * cos(beta)).
        # Since beta varies by face, and the source uses a single t for the slab,
        # we use the maximum cos(beta) across the 3 axes to be safe, 
        # or simply the definition provided.
        # Let's stick to the source formula: t6 = L / (2 * cos(beta)).
        # cos(beta) for x-face is |Ap|, y-face |Bp|, z-face |Cp|.
        # The source does not specify which beta, but implies a single threshold.
        # Given the proof relies on the distance to the plane being <= t,
        # and minimality requires t to be tight, we use the specific geometric derivation.
        # For implementation, we assume the source's t6 formula applies to the specific orientation.
        # A robust implementation might use t = L/2 for 6-sep if axis aligned, 
        # but for general, we calculate based on the normal's alignment.
        # The source text: "t6 = L / (2 cos beta)".
        # We will use the maximum component of the normal to determine the tightest bound?
        # No, the source defines a single slab. 
        # Let's assume the standard 6-separating slab thickness is L/2 for simplicity 
        # unless the angle is critical. However, the source explicitly gives a formula.
        # We will calculate cos_beta as the max absolute component of the normal,
        # representing the "closest" face normal alignment.
        cos_beta = max(abs(Ap), abs(Bp), abs(Cp))
        if abs(cos_beta) < 1e-9:
            t = grid_size
        else:
            t = grid_size / (2 * abs(cos_beta))
    else:
        raise ValueError("Only 6 and 26 separability are implemented in this snippet.")

    # which depends on the plane's extent.

                # Center of voxel
                cx, cy, cz = x, y, z 
                # Signed distance

## Subtopics

### 4-Separating Line Voxelization
A 2D variant for lines that guarantees 4-separability (no 4-holes) and 4-minimality. It uses a slab thickness $t_4 = \frac{L}{2 \cos \beta}$, where $\beta$ is the angle between the line normal and the pixel edge normal. If the threshold is miscalculated, 4-holes may form [S2].

### 8-Separating Line Voxelization
A 2D variant for lines that guarantees 8-separability (no 8-holes) and 8-minimality. It uses a slab thickness $t_8 = \frac{L}{2 \sqrt{2} \cos \alpha}$, where $\alpha$ is the angle between the line normal and the pixel diagonal. It is proven that excluding an intersected pixel leads to a contradiction regarding the distance from the center to the line [S2].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of voxels in the bounding volume. The source notes that a non-optimized scan conversion implementation was used, and an efficient incremental algorithm is needed for faster performance [S2].
- **Memory Complexity:** Linear with respect to the number of occupied voxels. For mesh voxelization, linked lists are used to manage voxel data, and efficiency (VPM - Voxels per millisecond) decreases as the number of voxels increases due to list maintenance costs [S2].
- **Performance:** 6-separating voxelization is faster and produces fewer voxels than 26-separating voxelization, particularly in Vertex and Edge voxels, while Body voxel counts are similar [S2]. Visually, 6- and 26-separating models are indistinguishable [S2].
- **Strengths:** Guarantees topological correctness (separability and minimality) which rasterization methods often lack. Eliminates artifacts at edges and vertices [S2].
- **Limitations:** Requires calculation of angles and thicknesses. Non-incremental implementations can be slow for high resolutions (e.g., 256x256x256) [S2].

## Background
The method originates from work on accurate polygon mesh voxelization that guarantees both separability and minimality, addressing gaps in earlier scan-conversion algorithms [S2]. It builds on the topological analysis of voxelization by Cohen-Or and Kaufman [S1, unofficial]. The technique was extended to handle polygon meshes by classifying voxels into vertex, edge, and body sets [S2]. It is used in surface graphics for creating discrete volume models from polygonal data [S2].
