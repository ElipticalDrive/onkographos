# Depth-Guided Supersampling
## Overview
Depth-Guided Supersampling generates sample positions along a ray by perturbing a depth estimate with Gaussian noise [S1, unofficial].
## How it works
**Inputs:**
- `rays`: Tensor containing ray origins, directions, and near/far bounds [S1, unofficial].
- `depth`: Tensor of estimated depth values for each ray, shape `[batch_size]` or `[batch_size, 1]` [S1, unofficial].
- `n_samples`: Integer, number of samples per ray [S1, unofficial].
- `start_sigma`: Float, initial standard deviation for noise (default 0.1) [S1, unofficial].

**Outputs:**
- `zvals`: Tensor of sample depths along the ray, shape `[batch_size, n_samples]` [S1, unofficial].

**Data Structures:**
- `zvals`: Float tensor [S1, unofficial].
- `mean`: Tensor of shape `[batch_size, n_samples]`, initialized with the depth estimate [S1, unofficial].
- `sigma`: Tensor of shape `[1, n_samples]`, initialized to `start_sigma` [S1, unofficial].
- `noise`: Tensor of shape `[batch_size, n_samples]`, drawn from $\mathcal{N}(0, 1)$ [S1, unofficial].

**Steps:**
1. Extract `near`, `far`, and `depth` from the ray data [S1, unofficial].
2. Set `mean` to `depth` (cloned and detached) [S1, unofficial].
3. Set `sigma` to a tensor of ones multiplied by `start_sigma`, shape `[1, n_samples]` [S1, unofficial].
4. Generate `noise` from $\mathcal{N}(0, 1)$ with shape `[batch_size, n_samples]` [S1, unofficial].
5. Compute `zvals_0_level` as `noise * sigma + mean` [S1, unofficial].
6. For rays with `depth == 0`, replace `zvals_0_level` with random points uniformly distributed between `near` and `far` [S1, unofficial].

**Pseudocode:**
```python
import torch

def depth_guided_supersampling(rays, depth, n_samples, start_sigma=0.1):
    """
    Generate sample positions along a ray guided by a depth estimate.
    
    Args:
        rays: Tensor or object containing .near and .far attributes of shape [B].
        depth: Tensor of shape [B] or [B, 1] with depth estimates.
        n_samples: int, number of samples per ray.
        start_sigma: float, standard deviation of noise.
        
    Returns:
        zvals: Tensor of shape [B, n_samples] with sample depths.
    """
    near = rays.near
    far = rays.far
    
    if depth.dim() == 2:
        depth = depth.squeeze(1)
        
    mean = depth.clone().detach().unsqueeze(1)
    sigma = torch.ones(1, n_samples, device=depth.device) * start_sigma
    noise = torch.randn(mean.shape[0], n_samples, device=depth.device)
    
    zvals = noise * sigma + mean
    
    zero_depth_mask = (depth == 0)
    
    if zero_depth_mask.any():
        uniform_noise = torch.rand(mean.shape[0], n_samples, device=depth.device)
        near_expanded = near.unsqueeze(1).expand(-1, n_samples)
        far_expanded = far.unsqueeze(1).expand(-1, n_samples)
        uniform_zvals = near_expanded + uniform_noise * (far_expanded - near_expanded)
        zvals[zero_depth_mask] = uniform_zvals[zero_depth_mask]
        
    return zvals
```

**Parameters:**
- `start_sigma`: Float, default 0.1. Controls the spread of noise around the depth estimate [S1, unofficial].

**Edge Cases:**
- If `depth == 0`, the method falls back to uniform sampling between `near` and `far` [S1, unofficial].

## Subtopics

### Depth-Centric Sampling
Samples $K_{fd}$ positions around a specified depth value with Gaussian noise, clamped to ray bounds [S2, unofficial]. It repeats the input depth tensor of shape $(B,)$ along dimension 1 to shape $(B, K_{fd})$, adds Gaussian noise with standard deviation `depth_std`, and clamps the resulting values between `near` and `far` bounds from the rays [S2, unofficial].
