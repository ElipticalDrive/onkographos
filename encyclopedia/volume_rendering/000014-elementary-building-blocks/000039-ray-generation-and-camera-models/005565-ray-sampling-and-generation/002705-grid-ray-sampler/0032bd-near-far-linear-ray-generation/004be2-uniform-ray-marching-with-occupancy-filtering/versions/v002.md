# Uniform Ray Marching with Occupancy Filtering

Also called: SPC Ray Raymarching

## Overview
Uniform Ray Marching with Occupancy Filtering is a raymarching strategy that samples a fixed number of points along each ray globally, then filters out samples that fall outside of occupied Sparse Point Cloud (SPC) cells [S1, unofficial]. It builds on [Near-Far Linear Ray Generation](6841-near-far-linear-ray-generation.md) by applying a global uniform grid and discarding empty-space samples via occupancy queries [S1, unofficial].

## How it works
**Inputs:**
- `origins`: Tensor of ray origins, shape $(N, 3)$.
- `directions`: Tensor of normalized ray directions, shape $(N, 3)$.
- `dist_min`: Scalar or tensor of near-plane distances for each ray.
- `dist_max`: Scalar or tensor of far-plane distances for each ray.
- `num_samples`: Integer, the number of base samples to generate per ray.
- `spc`: The Sparse Point Cloud acceleration structure supporting point index queries.

**Outputs:**
- `samples`: Filtered 3D coordinates, shape $(M, 3)$, where $M \le N \times \text{num\_samples}$.
- `depths`: Filtered depths along rays, shape $(M,)$.
- `deltas`: Filtered step sizes between consecutive samples, shape $(M,)$.
- `ray_indices`: Indices mapping each sample back to its originating ray, shape $(M,)$.
- `pack_boundaries`: Boolean mask marking the start of each ray's sample pack in the flattened output.

**Data Structures:**
- The SPC structure maps 3D coordinates to integer point indices (`pidx`) [S1, unofficial].
- `mask`: Boolean tensor of length $N \times \text{num\_samples}$, true where `pidx > -1` [S1, unofficial].

**Steps:**
1. **Generate Base Depths:** Create linearly spaced depths in $[0, 1]$ and add jitter [S1, unofficial].
   $$ d_{\text{base}} = \text{linspace}(0, 1.0, \text{num\_samples}) $$
   $$ d_{\text{jitter}} = \text{rand}(0, 1, \text{num\_samples}) / \text{num\_samples} $$
   $$ d_{\text{norm}} = d_{\text{base}} + d_{\text{jitter}} $$
   [G] The jitter ensures stratification within each uniform interval.

2. **Normalize to Ray Range:** Map normalized depths to the ray's $[dist\_min, dist\_max]$ range [S1, unofficial].
   $$ d_{\text{final}} = d_{\text{norm}} \times (dist\_max - dist\_min) + dist\_min $$
   Shape: $(N, \text{num\_samples})$.

3. **Compute Sample Coordinates:** Calculate 3D positions using origins, directions, and depths [S1, unofficial].
   $$ \text{samples} = \text{origins} + d_{\text{final}} \times \text{directions} $$
   Shape: $(N, \text{num\_samples}, 3)$.

4. **Query Occupancy:** Query the SPC structure for all sample coordinates to get point indices [S1, unofficial].
   $$ \text{pidx} = \text{SPC.query}(\text{samples}) $$
   Shape: $(N, \text{num\_samples})$.

5. **Create Occupancy Mask:** Identify samples inside occupied cells [S1, unofficial].
   $$ \text{mask} = (\text{pidx} > -1) $$
   Shape: $(N, \text{num\_samples})$.

6. **Compute Depth Deltas:** Calculate distances between consecutive samples and prepend the near plane [S1, unofficial].
   $$ \Delta d = \text{diff}(d_{\text{final}}, \text{axis}=1) $$
   $$ \Delta d_{\text{full}} = [dist\_min, \Delta d_{0}, \Delta d_{1}, \dots] $$
   Shape: $(N, \text{num\_samples})$.

7. **Filter Samples:** Flatten tensors and filter using the mask [S1, unofficial].
   $$ \text{flat\_samples} = \text{flatten}(\text{samples}) $$
   $$ \text{flat\_depths} = \text{flatten}(d_{\text{final}}) $$
   $$ \text{flat\_deltas} = \text{flatten}(\Delta d_{\text{full}}) $$
   $$ \text{flat\_ray\_idx} = \text{repeat}(0..N-1, \text{num\_samples}) $$
   $$ \text{flat\_mask} = \text{flatten}(\text{mask}) $$
   Apply `fast_filter_method` to keep only elements where `flat_mask` is true [S1, unofficial].
   $$ \text{out\_samples} = \text{flat\_samples}[\text{flat\_mask}] $$
   $$ \text{out\_depths} = \text{flat\_depths}[\text{flat\_mask}] $$
   $$ \text{out\_deltas} = \text{flat\_deltas}[\text{flat\_mask}] $$
   $$ \text{out\_ray\_idx} = \text{flat\_ray\_idx}[\text{flat\_mask}] $$

8. **Mark Pack Boundaries:** Identify the start of each ray's samples in the filtered output [S1, unofficial].
   [G] Boundaries are marked where the ray index changes or at the first element.

**Parameters:**
- `num_samples`: Number of samples generated per ray [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Empty Occupancy:** If `NUM_HIT_SAMPLES` (the count of true values in `mask`) is 0, the output tensors will be empty [S1, unofficial].
- **Precision:** Jitter addition must be performed carefully to avoid precision loss when `dist_max - dist_min` is very large or very small [G].
- **Boundary Conditions:** The first delta is explicitly set to `dist_min` [S1, unofficial]. Ensure `dist_min` is correctly passed for rays that may have varying near planes [G].

```python
import torch

def uniform_ray_marching_with_occupancy_filter(
    origins: torch.Tensor,
    directions: torch.Tensor,
    dist_min: torch.Tensor,
    dist_max: torch.Tensor,
    num_samples: int,
    spc_query_func
) -> dict:
    """
    Performs uniform ray marching with occupancy filtering.
    
    Args:
        origins: (N, 3) Ray origins.
        directions: (N, 3) Normalized ray directions.
        dist_min: (N,) or scalar Near plane distance.
        dist_max: (N,) or scalar Far plane distance.
        num_samples: int Number of samples per ray.
        spc_query_func: Callable that takes (N * num_samples, 3) coordinates and returns (N * num_samples,) pidx.
        
    Returns:
        Dictionary containing filtered samples, depths, deltas, ray_indices, and pack_boundaries.
    """
    N = origins.shape[0]
    
    # 1. Generate base depths with jitter
    base_depths = torch.linspace(0.0, 1.0, num_samples, device=origins.device)
    jitter = torch.rand(num_samples, device=origins.device) / num_samples
    norm_depths = base_depths + jitter  # (num_samples,)
    
    # 2. Normalize to ray range
    norm_depths = norm_depths.unsqueeze(0)  # (1, num_samples)
    dist_min_exp = dist_min.unsqueeze(1) if dist_min.dim() == 1 else dist_min
    dist_max_exp = dist_max.unsqueeze(1) if dist_max.dim() == 1 else dist_max
    
    depths = norm_depths * (dist_max_exp - dist_min_exp) + dist_min_exp  # (N, num_samples)
    
    # 3. Compute sample coordinates
    depths_3d = depths.unsqueeze(2)  # (N, num_samples, 1)
    samples = origins.unsqueeze(1) + depths_3d * directions.unsqueeze(1)  # (N, num_samples, 3)
    
    # 4. Query SPC
    flat_samples = samples.reshape(-1, 3)  # (N * num_samples, 3)
    pidx = spc_query_func(flat_samples)  # (N * num_samples,)
    
    # 5. Create mask
    mask = pidx > -1  # (N * num_samples,)
    
    # 6. Compute deltas
    deltas_diff = torch.diff(depths, dim=1)  # (N, num_samples - 1)
    deltas = torch.cat([dist_min_exp, deltas_diff], dim=1)  # (N, num_samples)
    
    # 7. Filter
    flat_depths = depths.reshape(-1)
    flat_deltas = deltas.reshape(-1)
    flat_ray_indices = torch.arange(N, device=origins.device).repeat_interleave(num_samples)
    
    valid_samples = flat_samples[mask]
    valid_depths = flat_depths[mask]
    valid_deltas = flat_deltas[mask]
    valid_ray_indices = flat_ray_indices[mask]
    
    # 8. Mark pack boundaries
    shifted_ray_indices = torch.roll(valid_ray_indices, 1)
    shifted_ray_indices[0] = -1
    pack_boundaries = valid_ray_indices != shifted_ray_indices
    
    return {
        "samples": valid_samples,
        "depths": valid_depths,
        "deltas": valid_deltas,
        "ray_indices": valid_ray_indices,
        "pack_boundaries": pack_boundaries
    }
```

## Subtopics

### SPC Uniform Raymarching
A raymarching strategy that intersects rays with SPC cells and samples points at uniform distances determined by the cell geometry [S1, unofficial]. It calls `raytrace(rays, level, with_exit=True)` to get intersection depths [S1, unofficial]. It calculates `step_size` as $2\sqrt{3} / \text{num\_samples}$, scales it to an integer scale, and normalizes `step_size` to $1.0/\text{scale}$ [S1, unofficial]. It calculates interval counts for each intersection by scaling depth intervals and taking the ceiling difference [S1, unofficial]. It filters out intersections with zero interval counts [S1, unofficial]. It computes an inclusive sum of interval counts for indexing [S1, unofficial]. It calls `uniform_sample_cuda` kernel with scale, filtered indices, depths, and inclusive sum [S1, unofficial]. It computes deltas as constant `step_size` for all samples [S1, unofficial]. It computes sample coordinates using ray origins, directions, and depth samples [S1, unofficial]. Parameter: `num_samples` determines the uniform step distance, calculated as $2\sqrt{3}/\text{num\_samples}$ initially [S1, unofficial]. Pitfall: `NUM_INTERSECTIONS` can be 0 [S1, unofficial].

### SPC Voxel Raymarching
A raymarching strategy that first intersects rays with Sparse Point Cloud (SPC) cells, then samples a fixed number of points within each intersected cell [S1, unofficial]. It calls `raytrace(rays, level, with_exit=True)` to get ray indices (`ridx`), point indices (`pidx`), and depth intervals (`depth`) for each intersection [S1, unofficial]. It generates depth samples within each interval by calling `sample_from_depth_intervals(depth, num_samples)` and appending a dimension [S1, unofficial]. It computes depth deltas by taking the difference of `depth_samples` along the last dimension, prepending the start depth of the interval [S1, unofficial]. It computes sample coordinates by adding the product of ray origins/directions and depth samples using `torch.addcmul` [S1, unofficial]. It creates a boundary mask marking the start of each sample pack by expanding the first-hit mask of each intersection [S1, unofficial]. It flattens `ridx`, samples, and `depth_samples` to a single list of size `num_intersections * num_samples` [S1, unofficial]. Parameter: `num_samples` is the number of samples generated per voxel intersection [S1, unofficial]. Pitfall: `NUM_INTERSECTIONS` can be 0, meaning no cells were hit by any ray [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N \cdot S)$ for generating samples and querying the SPC, where $N$ is the number of rays and $S$ is `num_samples`. Filtering is $O(N \cdot S)$. The SPC query cost depends on the structure [S1, unofficial].
- **Memory Complexity:** $O(N \cdot S)$ for storing intermediate tensors before filtering. The output size is variable but bounded by $N \cdot S$ [S1, unofficial].
- **Performance:** Efficient for scenes with high occupancy where most samples are valid. In sparse scenes, the filtering step discards many samples, but the initial generation cost remains [S1, unofficial].
- **Strengths:** Simple to implement; provides uniform sampling density in space; jitter reduces banding [S1, unofficial].
- **Limitations:** Wastes computation on empty space if the scene is sparse; `num_samples` must be chosen to balance coverage and performance; potential for `NUM_HIT_SAMPLES = 0` in empty scenes [S1, unofficial].
- **When to use:** When a uniform sampling distribution is desired and the scene has significant occupied volume [S1, unofficial].
- **When not to use:** In very sparse scenes where most rays hit empty space, as the filtering overhead may not justify the uniform sampling benefit; consider [SPC Voxel Raymarching](11413-spc-voxel-raymarching.md) instead [S1, unofficial].

This method is part of the NVIDIA Kaolin-Wisp framework, specifically within the `wisp.tracers` module, designed for efficient neural radiance field rendering [S1, unofficial]. It builds on the concept of uniform ray sampling but integrates occupancy filtering via Sparse Point Cloud (SPC) structures to optimize computation in sparse environments [S1, unofficial].
