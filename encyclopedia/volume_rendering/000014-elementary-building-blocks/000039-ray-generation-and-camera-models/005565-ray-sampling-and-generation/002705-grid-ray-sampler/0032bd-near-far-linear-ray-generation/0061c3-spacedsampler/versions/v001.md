# SpacedSampler

Also called: Spaced Ray Sampler

## Overview
The SpacedSampler is a base class for sampling points along a ray according to a user-defined spacing function and its inverse [S1, unofficial]. It generalizes linear, disparity, and logarithmic sampling by mapping Euclidean distances to a "spacing space," performing uniform stratified sampling in that space, and mapping the results back to Euclidean space [S1, unofficial]. It builds on [Near-Far Linear Ray Generation](6841-near-far-linear-ray-generation.md) by allowing arbitrary non-linear spacing functions rather than just linear interpolation [S1, unofficial].

## How it works
**Inputs:**
- `near`: Tensor of shape `(num_rays,)` containing near-plane distances.
- `far`: Tensor of shape `(num_rays,)` containing far-plane distances.
- `num_samples`: Integer, number of samples per ray.
- `spacing_fn`: Callable mapping Euclidean distance $d$ to spacing coordinate $s$.
- `spacing_fn_inv`: Callable mapping spacing coordinate $s$ back to Euclidean distance $d$.
- `train_stratified`: Boolean, default `True`.
- `single_jitter`: Boolean, default `False`.

**Outputs:**
- `RaySamples` object containing:
  - `starts`: Tensor of shape `(num_rays, num_samples)` with Euclidean start positions.
  - `ends`: Tensor of shape `(num_rays, num_samples)` with Euclidean end positions.
  - `spacing_starts`: Tensor of shape `(num_rays, num_samples)` with spacing-space start positions.
  - `spacing_ends`: Tensor of shape `(num_rays, num_samples)` with spacing-space end positions.
  - `spacing_to_euclidean_fn`: Helper function for interpolation.

**Data Structures:**
- `bins`: Tensor of shape `(num_rays, num_samples + 1)` in spacing space.
- `bin_centers`: Tensor of shape `(num_rays, num_samples)` in spacing space.
- `bin_lower`, `bin_upper`: Tensors of shape `(num_rays, num_samples)` in spacing space.
- `t_rand`: Random jitter tensor.

**Steps:**
1. Compute uniform bins in spacing space:
   $$ \text{bins} = \text{linspace}(0.0, 1.0, \text{num\_samples} + 1) $$
   Shape: `(num_rays, num_samples + 1)`.

2. Generate stratified jitter if training and stratified sampling is enabled:
   - If `single_jitter` is `True`: `t_rand` has shape `(num_rays, 1)`.
   - Otherwise: `t_rand` has shape `(num_rays, num_samples + 1)`.
   - Values are drawn from a uniform distribution $U(0, 1)$.

3. Calculate bin centers in spacing space:
   $$ \text{bin\_centers} = \frac{\text{bins}[:, 1:] + \text{bins}[:, :-1]}{2.0} $$
   Shape: `(num_rays, num_samples)`.

4. Construct bin lower and upper bounds in spacing space:
   $$ \text{bin\_lower} = \text{concat}([\text{bins}[:, :1], \text{bin\_centers}], \text{axis}=-1) $$
   $$ \text{bin\_upper} = \text{concat}([\text{bin\_centers}, \text{bins}[:, -1:]], \text{axis}=-1) $$
   Shapes: `(num_rays, num_samples)`.

5. Apply stratified jitter to bins:
   $$ \text{bins} = \text{bin\_lower} + (\text{bin\_upper} - \text{bin\_lower}) \times \text{t\_rand} $$
   Shape: `(num_rays, num_samples)`.

6. Transform ray near and far distances into spacing space:
   $$ s_{\text{near}} = \text{spacing\_fn}(\text{near}) $$
   $$ s_{\text{far}} = \text{spacing\_fn}(\text{far}) $$
   Shapes: `(num_rays,)`.

7. Define helper function for mapping spacing-space interpolation to Euclidean space:
   $$ \text{spacing\_to\_euclidean\_fn}(x) = \text{spacing\_fn\_inv}(x \cdot s_{\text{far}} + (1 - x) \cdot s_{\text{near}}) $$
   This function interpolates linearly in spacing space between $s_{\text{near}}$ and $s_{\text{far}}$, then maps the result back to Euclidean distance.

8. Map the spacing-space bins to Euclidean space:
   $$ \text{euclidean\_bins} = \text{spacing\_to\_euclidean\_fn}(\text{bins}) $$
   Shape: `(num_rays, num_samples)`.

9. Create `RaySamples` using:
   - `starts`: `euclidean_bins`
   - `ends`: `euclidean_bins` shifted by one index (or computed similarly for bin ends)
   - `spacing_starts`: `bins`
   - `spacing_ends`: `bins` shifted by one index
   - `spacing_to_euclidean_fn`: The helper function defined in step 7.

**Pseudocode:**
```python
import torch

def spaced_sampler(near, far, num_samples, spacing_fn, spacing_fn_inv, train_stratified=True, single_jitter=False):
    """
    Samples points along a ray using a user-defined spacing function.
    
    Args:
        near: Tensor of shape (num_rays,) with near-plane distances.
        far: Tensor of shape (num_rays,) with far-plane distances.
        num_samples: Integer, number of samples per ray.
        spacing_fn: Callable mapping Euclidean distance to spacing coordinate.
        spacing_fn_inv: Callable mapping spacing coordinate to Euclidean distance.
        train_stratified: Boolean, default True.
        single_jitter: Boolean, default False.
        
    Returns:
        RaySamples object with starts, ends, spacing_starts, spacing_ends, and spacing_to_euclidean_fn.
    """
    num_rays = near.shape[0]
    
    # Step 1: Compute uniform bins in spacing space
    # bins shape: (num_rays, num_samples + 1)
    bins = torch.linspace(0.0, 1.0, num_samples + 1, device=near.device).unsqueeze(0).expand(num_rays, -1)
    
    # Step 2: Generate stratified jitter
    if train_stratified:
        if single_jitter:
            t_rand = torch.rand(num_rays, 1, device=near.device)
        else:
            t_rand = torch.rand(num_rays, num_samples + 1, device=near.device)
    else:
        t_rand = torch.zeros_like(bins)
        
    # Step 3: Calculate bin centers
    # bin_centers shape: (num_rays, num_samples)
    bin_centers = (bins[:, 1:] + bins[:, :-1]) / 2.0
    
    # Step 4: Construct bin lower and upper bounds
    # bin_lower, bin_upper shape: (num_rays, num_samples)
    bin_lower = torch.cat([bins[:, :1], bin_centers], dim=-1)
    bin_upper = torch.cat([bin_centers, bins[:, -1:]], dim=-1)
    
    # Step 5: Apply stratified jitter to bins
    # bins shape: (num_rays, num_samples)
    bins = bin_lower + (bin_upper - bin_lower) * t_rand
    
    # Step 6: Transform ray near and far distances into spacing space
    # s_near, s_far shape: (num_rays,)
    s_near = spacing_fn(near)
    s_far = spacing_fn(far)
    
    # Step 7: Define helper function
    def spacing_to_euclidean_fn(x):
        # x shape: (num_rays, num_samples)
        # Interpolate in spacing space and map back to Euclidean
        # s_near, s_far need to be broadcasted to (num_rays, num_samples)
        s_near_expanded = s_near.unsqueeze(-1)
        s_far_expanded = s_far.unsqueeze(-1)
        s_interp = x * s_far_expanded + (1 - x) * s_near_expanded
        return spacing_fn_inv(s_interp)
    
    # Step 8: Map the spacing-space bins to Euclidean space
    # euclidean_bins shape: (num_rays, num_samples)
    euclidean_bins = spacing_to_euclidean_fn(bins)
    
    # Step 9: Create RaySamples
    # Note: The source describes creating RaySamples with starts, ends, spacing_starts, spacing_ends.
    # For simplicity, we assume starts/ends are the bin centers or bin edges.
    # The source says "Create RaySamples using the Euclidean bin starts and ends".
    # We will use bin_centers as the sample points, and bin_lower/bin_upper as the intervals.
    # However, RaySamples typically expects start and end of each interval.
    # Let's assume the samples are the intervals defined by bin_lower and bin_upper in spacing space,
    # mapped to Euclidean space.
    
    # Euclidean starts and ends for each sample interval
    euclidean_starts = spacing_to_euclidean_fn(bin_lower)
    euclidean_ends = spacing_to_euclidean_fn(bin_upper)
    
    # Spacing starts and ends
    spacing_starts = bin_lower
    spacing_ends = bin_upper
    
    return {
        'starts': euclidean_starts,
        'ends': euclidean_ends,
        'spacing_starts': spacing_starts,
        'spacing_ends': spacing_ends,
        'spacing_to_euclidean_fn': spacing_to_euclidean_fn
    }
```

**Parameters:**
- `spacing_fn`: A callable that maps Euclidean distance to spacing coordinate [S1, unofficial].
- `spacing_fn_inv`: A callable that maps spacing coordinate back to Euclidean distance [S1, unofficial].
- `train_stratified`: Boolean flag, default `True`, to use stratified sampling during training [S1, unofficial].
- `single_jitter`: Boolean flag, default `False`, to use a single random jitter value for all samples along a ray instead of one per sample [S1, unofficial].

**Edge Cases and Pitfalls:**
- Precision: When `spacing_fn` or `spacing_fn_inv` involve logarithms or square roots, ensure inputs are positive to avoid NaNs or complex numbers [G].
- Boundaries: Ensure `near` and `far` are positive and `near < far` [G].
- Degenerate Input: If `num_samples` is 0, the method should return empty tensors [G].

## Subtopics

### UniformLinDispPiecewiseSampler
A piecewise sampler that allocates the first half of samples uniformly and the second half using linearly in disparity spacing [S1, unofficial]. It uses the spacing function $s(x) = x/2$ if $x < 1$ else $1 - 1/(2x)$ and its inverse $s^{-1}(s) = 2s$ if $s < 0.5$ else $1/(2 - 2s)$ [S1, unofficial]. Parameters: `num_samples`, `train_stratified` (default `True`), `single_jitter` (default `False`) [S1, unofficial].

### UniformSampler
Samples points uniformly along a ray in Euclidean space [S1, unofficial]. It initializes `SpacedSampler` with `spacing_fn = lambda x: x` and `spacing_fn_inv = lambda x: x` [S1, unofficial].

### LinearDisparitySampler
Samples points linearly in disparity (inverse depth) along a ray [S1, unofficial]. It initializes `SpacedSampler` with `spacing_fn = lambda x: 1/x` and `spacing_fn_inv = lambda x: 1/x` [S1, unofficial].

### SqrtSampler
Samples points using a square root spacing function along a ray [S1, unofficial]. It initializes `SpacedSampler` with `spacing_fn = torch.sqrt` and `spacing_fn_inv = lambda x: x**2` [S1, unofficial].

### LogSampler
Samples points using a logarithmic spacing function along a ray [S1, unofficial]. It initializes `SpacedSampler` with `spacing_fn = torch.log` and `spacing_fn_inv = torch.exp` [S1, unofficial].

## Background
The SpacedSampler is part of the nerfstudio project, a collaboration-friendly studio for NeRFs [S1, unofficial]. It was introduced as part of the nerfstudio codebase to provide a flexible way to sample points along rays for volume rendering [S1, unofficial].
