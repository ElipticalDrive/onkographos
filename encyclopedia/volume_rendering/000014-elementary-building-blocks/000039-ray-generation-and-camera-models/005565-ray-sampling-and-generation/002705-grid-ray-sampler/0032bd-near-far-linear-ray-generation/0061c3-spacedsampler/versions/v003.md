# SpacedSampler
## Overview
The SpacedSampler samples points along a ray according to a user-defined spacing function and its inverse [S1, unofficial]. It generalizes linear and disparity sampling by performing uniform stratified sampling in a transformed spacing space and mapping the results back to Euclidean space [S1, unofficial]. It builds on [Near-Far Linear Ray Generation](6841-near-far-linear-ray-generation.md) by allowing arbitrary non-linear spacing functions rather than restricting interpolation to linear distance [S1, unofficial].

## How it works
**Inputs:**
- `near`: Tensor of shape `(num_rays,)` containing near-plane distances [S1, unofficial].
- `far`: Tensor of shape `(num_rays,)` containing far-plane distances [S1, unofficial].
- `num_samples`: Integer, number of samples per ray [S1, unofficial].
- `spacing_fn`: Callable mapping Euclidean distance to spacing coordinate [S1, unofficial].
- `spacing_fn_inv`: Callable mapping spacing coordinate back to Euclidean distance [S1, unofficial].
- `train_stratified`: Boolean, default `True` [S1, unofficial].
- `single_jitter`: Boolean, default `False` [S1, unofficial].

**Outputs:**
- `RaySamples` object containing:
  - `starts`: Tensor of shape `(num_rays, num_samples)` with Euclidean start positions [S1, unofficial].
  - `ends`: Tensor of shape `(num_rays, num_samples)` with Euclidean end positions [S1, unofficial].
  - `spacing_starts`: Tensor of shape `(num_rays, num_samples)` with spacing-space start positions [S1, unofficial].
  - `spacing_ends`: Tensor of shape `(num_rays, num_samples)` with spacing-space end positions [S1, unofficial].
  - `spacing_to_euclidean_fn`: Helper function for interpolation [S1, unofficial].

**Data Structures:**
- `bins`: Tensor of shape `(num_rays, num_samples + 1)` in spacing space [S1, unofficial].
- `bin_centers`: Tensor of shape `(num_rays, num_samples)` in spacing space [S1, unofficial].
- `bin_lower`, `bin_upper`: Tensors of shape `(num_rays, num_samples)` in spacing space [S1, unofficial].
- `t_rand`: Random jitter tensor [S1, unofficial].

**Steps:**
1. Compute uniform bins in spacing space: `bins = linspace(0.0, 1.0, num_samples + 1)` [S1, unofficial].
2. Generate stratified jitter if training and stratified sampling is enabled: `t_rand` is drawn from a uniform distribution $U(0, 1)$ [S1, unofficial]. If `single_jitter` is `True`, `t_rand` has shape `(num_rays, 1)`; otherwise `t_rand` has shape `(num_rays, num_samples + 1)` [S1, unofficial].
3. Calculate bin centers in spacing space: `bin_centers = (bins[..., 1:] + bins[..., :-1]) / 2.0` [S1, unofficial].
4. Construct bin lower and upper bounds in spacing space: `bin_lower = cat([bins[..., :1], bin_centers], -1)` and `bin_upper = cat([bin_centers, bins[..., -1:]], -1)` [S1, unofficial].
5. Apply stratified jitter to bins: `bins = bin_lower + (bin_upper - bin_lower) * t_rand` [S1, unofficial].
6. Transform ray near and far distances into spacing space: `s_near = spacing_fn(near)` and `s_far = spacing_fn(far)` [S1, unofficial].
7. Define helper function `spacing_to_euclidean_fn(x) = spacing_fn_inv(x * s_far + (1 - x) * s_near)` to interpolate in spacing space and map back to Euclidean [S1, unofficial].
8. Map the spacing-space bins to Euclidean space: `euclidean_bins = spacing_to_euclidean_fn(bins)` [S1, unofficial].
9. Create `RaySamples` using the Euclidean bin starts and ends, and the spacing bin starts and ends, along with the helper function [S1, unofficial].

**Formulas:**
- Uniform bins: $\text{bins} = \text{linspace}(0.0, 1.0, \text{num\_samples} + 1)$ [S1, unofficial].
- Bin centers: $\text{bin\_centers} = \frac{\text{bins}[:, 1:] + \text{bins}[:, :-1]}{2.0}$ [S1, unofficial].
- Bin bounds: $\text{bin\_lower} = \text{cat}([\text{bins}[:, :1], \text{bin\_centers}], \text{axis}=-1)$, $\text{bin\_upper} = \text{cat}([\text{bin\_centers}, \text{bins}[:, -1:]], \text{axis}=-1)$ [S1, unofficial].
- Stratified jitter: $\text{bins} = \text{bin\_lower} + (\text{bin\_upper} - \text{bin\_lower}) \times \text{t\_rand}$ [S1, unofficial].
- Spacing transformation: $s_{\text{near}} = \text{spacing\_fn}(\text{near})$, $s_{\text{far}} = \text{spacing\_fn}(\text{far})$ [S1, unofficial].
- Spacing-to-Euclidean mapping: $\text{spacing\_to\_euclidean\_fn}(x) = \text{spacing\_fn\_inv}(x \cdot s_{\text{far}} + (1 - x) \cdot s_{\text{near}})$ [S1, unofficial].

**Parameters:**
- `spacing_fn`: A callable that maps Euclidean distance to spacing coordinate [S1, unofficial].
- `spacing_fn_inv`: A callable that maps spacing coordinate back to Euclidean distance [S1, unofficial].
- `train_stratified`: Boolean flag, default `True`, to use stratified sampling during training [S1, unofficial].
- `single_jitter`: Boolean flag, default `False`, to use a single random jitter value for all samples along a ray instead of one per sample [S1, unofficial].

**Edge Cases and Pitfalls:**
- Precision: When `spacing_fn` or `spacing_fn_inv` involve logarithms or square roots, ensure inputs are positive to avoid NaNs or complex numbers [G].
- Boundaries: Ensure `near` and `far` are positive and `near < far` [G].
- Degenerate Input: If `num_samples` is 0, the method should return empty tensors [G].

**Pseudocode:**
```python
import torch

def spaced_sampler(near, far, num_samples, spacing_fn, spacing_fn_inv, train_stratified=True, single_jitter=False):
    """
    Samples points along a ray using a user-defined spacing function.
    
    Args:
        near: Tensor of shape (num_rays,) with near-plane distances.
        far: Tensor of shape (num_rays,) with far-plane distances.
        num_samples: Integer, number of samples per ray.
        spacing_fn: Callable mapping Euclidean distance to spacing coordinate.
        spacing_fn_inv: Callable mapping spacing coordinate to Euclidean distance.
        train_stratified: Boolean, default True.
        single_jitter: Boolean, default False.
        
    Returns:
        Dictionary with starts, ends, spacing_starts, spacing_ends, and spacing_to_euclidean_fn.
    """
    num_rays = near.shape[0]
    
    # Step 1: Compute uniform bins in spacing space
    bins = torch.linspace(0.0, 1.0, num_samples + 1, device=near.device).unsqueeze(0).expand(num_rays, -1)
    
    # Step 2: Generate stratified jitter
    if train_stratified:
        if single_jitter:
            t_rand = torch.rand(num_rays, 1, device=near.device)
        else:
            t_rand = torch.rand(num_rays, num_samples + 1, device=near.device)
    else:
        t_rand = torch.zeros_like(bins)
        
    # Step 3: Calculate bin centers
    bin_centers = (bins[..., 1:] + bins[..., :-1]) / 2.0
    
    # Step 4: Construct bin lower and upper bounds
    bin_lower = torch.cat([bins[..., :1], bin_centers], dim=-1)
    bin_upper = torch.cat([bin_centers, bins[..., -1:]], dim=-1)
    
    # Step 5: Apply stratified jitter to bins
    bins = bin_lower + (bin_upper - bin_lower) * t_rand
    
    # Step 6: Transform ray near and far distances into spacing space
    s_near = spacing_fn(near)
    s_far = spacing_fn(far)
    
    # Step 7: Define helper function
    def spacing_to_euclidean_fn(x):
        s_near_expanded = s_near.unsqueeze(-1)
        s_far_expanded = s_far.unsqueeze(-1)
        s_interp = x * s_far_expanded + (1 - x) * s_near_expanded
        return spacing_fn_inv(s_interp)
    
    # Step 8: Map the spacing-space bins to Euclidean space
    euclidean_bins = spacing_to_euclidean_fn(bins)
    
    # Step 9: Create RaySamples
    euclidean_starts = spacing_to_euclidean_fn(bin_lower)
    euclidean_ends = spacing_to_euclidean_fn(bin_upper)
    spacing_starts = bin_lower
    spacing_ends = bin_upper
    
    return {
        'starts': euclidean_starts,
        'ends': euclidean_ends,
        'spacing_starts': spacing_starts,
        'spacing_ends': spacing_ends,
        'spacing_to_euclidean_fn': spacing_to_euclidean_fn
    }
```

## Subtopics

### UniformLinDispPiecewiseSampler
A piecewise sampler that allocates the first half of samples uniformly and the second half using linearly in disparity spacing [S1, unofficial]. It uses the spacing function $s(x) = x/2$ if $x < 1$ else $1 - 1/(2x)$ and its inverse $s^{-1}(s) = 2s$ if $s < 0.5$ else $1/(2 - 2s)$ [S1, unofficial]. Parameters: `num_samples`, `train_stratified` (default `True`), `single_jitter` (default `False`) [S1, unofficial].

### UniformSampler
Samples points uniformly along a ray in Euclidean space [S1, unofficial]. It initializes `SpacedSampler` with `spacing_fn = lambda x: x` and `spacing_fn_inv = lambda x: x` [S1, unofficial].

### LinearDisparitySampler
Samples points linearly in disparity (inverse depth) along a ray [S1, unofficial]. It initializes `SpacedSampler` with `spacing_fn = lambda x: 1/x` and `spacing_fn_inv = lambda x: 1/x` [S1, unofficial].

### SqrtSampler
Samples points using a square root spacing function along a ray [S1, unofficial]. It initializes `SpacedSampler` with `spacing_fn = torch.sqrt` and `spacing_fn_inv = lambda x: x**2` [S1, unofficial].

### LogSampler
Samples points using a logarithmic spacing function along a ray [S1, unofficial]. It initializes `SpacedSampler` with `spacing_fn = torch.log` and `spacing_fn_inv = torch.exp` [S1, unofficial].
