# Dataset-Specific Near/Far Bound Calculation

Also called: Dataset-dependent Near/Far Clipping, Near/Far Bound Calculation per Dataset, Scene Normalization, Scene contraction strategy

## Overview
Computes the near and far clipping planes for ray sampling based on the dataset type and Normalized Device Coordinates (NDC) configuration [S2, unofficial]. It ensures that the ray sampler operates within a geometrically valid range appropriate for the scene's scale and projection model, serving as the parameterization layer for [Near-Far Linear Ray Generation](6841-near-far-linear-ray-generation.md) [G].

## How it works
**Inputs:**
- `dataset_type`: String identifier for the dataset ('llff', 'blender', 'deepvoxels') [S2, unofficial].
- `no_ndc`: Boolean flag. If `True`, disables NDC projection for non-forward-facing scenes [S2, unofficial].
- `bds`: Array of bounding box min/max values derived from camera poses [S2, unofficial].
- `poses`: Array of camera transformation matrices [S2, unofficial].

**Outputs:**
- `near`: Float, the near clipping plane distance.
- `far`: Float, the far clipping plane distance.

**Data Structures:**
- `bds`: Shape `[3]` or `[num_cameras, 3]` containing min/max extents. In LLFF loading, `bds` is rescaled by `bd_factor` (default 0.75) if provided [S2, unofficial].
- `poses`: Shape `[num_cameras, 4, 4]` or `[num_cameras, 3, 4]` representing camera extrinsics [S2, unofficial].

**Steps:**
1. **LLFF Dataset (`dataset_type == 'llff'`):**
   - If `no_ndc` is `True`: Calculate `near = min(bds) * 0.9` and `far = max(bds) * 1.0` [S2, unofficial].
   - If `no_ndc` is `False`: Set `near = 0.0` and `far = 1.0` [S2, unofficial].
2. **Blender Dataset (`dataset_type == 'blender'`):**
   - Set `near = 2.0` and `far = 6.0` [S2, unofficial].
3. **DeepVoxels Dataset (`dataset_type == 'deepvoxels'`):**
   - Compute `hemi_R = mean(norm(poses[:, :3, -1]))` [S2, unofficial].
   - Calculate `near = hemi_R - 1.0` and `far = hemi_R + 1.0` [S2, unofficial].
4. **Scene Normalization (Unbounded Scenes):**
   - Calculate the maximum distance $D_{max}$ between any two camera positions in the training log [S1].
   - Determine sphere diameter $D_{sphere} = D_{max} + 50$ meters [S1].
   - Model the scene of interest with a sphere of this diameter for scene contraction [S1].

**Pitfalls:**
- **LLFF NDC vs. Non-NDC:** Using fixed [0, 1] bounds for LLFF when `no_ndc=True` causes incorrect sampling ranges because the physical scale is not normalized [S2, unofficial]. Conversely, using physical bounds with `no_ndc=False` breaks the NDC assumption [S2, unofficial].
- **Pose Extraction:** Ensure `poses[:, :3, -1]` correctly extracts the translation component from the transformation matrix [S2, unofficial].

**Pseudocode:**
```python
def compute_near_far(dataset_type, no_ndc, bds, poses):
    """
    Compute near and far clipping planes based on dataset type.
    
    Args:
        dataset_type (str): 'llff', 'blender', or 'deepvoxels'.
        no_ndc (bool): If True, disable NDC projection.
        bds (list or array): Bounding box min/max values.
        poses (list or array): Camera poses.
        
    Returns:
        float: near
        float: far
    """
    if dataset_type == 'llff':
        if no_ndc:
            near = min(bds) * 0.9
            far = max(bds) * 1.0
        else:
            near = 0.0
            far = 1.0
    elif dataset_type == 'blender':
        near = 2.0
        far = 6.0
    elif dataset_type == 'deepvoxels':
        translations = [pose[:3, -1] for pose in poses]
        norms = [sum(t**2 for t in trans)**0.5 for trans in translations]
        hemi_R = sum(norms) / len(norms)
        near = hemi_R - 1.0
        far = hemi_R + 1.0
    else:
        raise ValueError(f"Unsupported dataset_type: {dataset_type}")
    return near, far
```

- **Limitations:** Hardcoded for specific dataset types [S2, unofficial]. Does not generalize to arbitrary unstructured point clouds without scene normalization (contraction) [S1].

## Background
This method originates from the implementation details of early NeRF variants and their derivatives [G]. The LLFF and Blender bounds are standard conventions established in the original NeRF paper and subsequent repositories [S2, unofficial]. The DeepVoxels approach adapts to spherical camera trajectories [S2, unofficial]. The scene normalization strategy (sphere diameter + 50m) is introduced in LidaRF to handle unbounded street scenes using scene contraction [S1].
