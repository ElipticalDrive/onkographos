# Stratified Cosine-Weighted Diffuse Ray Generation

Also called: Stratified Cosine-Weighted Diffuse Ray Generation for One-Bounce Voxel GI, bounded one-bounce voxel GI ray gen

## Overview
This method generates stratified cosine-weighted diffuse rays for bounded one-bounce voxel global illumination, sampling from primary hit positions [S1, unofficial]. It builds on [Grid Ray Sampler](3930-grid-ray-sampler.md) and differs from its siblings by specifically targeting the second bounce in a voxel-based pipeline and restricting rays to a fixed maximum distance [S1, unofficial].

## How it works
**Inputs:**
- `globalIndex`: The unique compute dispatch thread ID [S1, unofficial].
- `primary_buffer`: An array of primary hit results indexed by pixel [S1, unofficial].
- `activeSamples`: The number of active samples per pixel for the current frame [S1, unofficial].
- `kMaximumGiSamples`: The maximum number of GI samples per pixel [S1, unofficial].
- `gGiFrameSeed`: The seed for the PCG random number generator [S1, unofficial].
- `gGlobalIlluminationMaxDistanceMeters`: The maximum ray distance in meters [S1, unofficial].
- `gShadowBiasMeters`: The shadow bias in meters [S1, unofficial].
- `voxel_scale`: The conversion factor from meters to voxel units [G].
- `totalCapacity`: The total number of threads dispatched [G].

**Outputs:**
- `output_buffer`: An array of `TraceRay` structures containing the generated GI rays [S1, unofficial].

**Data Structures:**
- `TraceRay`: Contains fields `hit` (uint, 0 if miss, non-zero if hit), `origin` (float3), `direction` (float3), `maxDistance` (float), and `id` (uint) [G].
- `randomPair`: A pair of floats `(u, v)` representing the stratified sample coordinates [S1, unofficial].

**Numbered Steps & Formulas:**
1. Map the dispatch thread ID to pixel and sample indices: `pixelIndex = globalIndex // kMaximumGiSamples` and `sampleIndex = globalIndex % kMaximumGiSamples` [S1, unofficial]. If `globalIndex >= totalCapacity`, return an empty `TraceRay` [S1, unofficial].
2. Fetch the primary trace result for `pixelIndex` [S1, unofficial]. If `primary.hit == 0` or `sampleIndex >= activeSamples`, return an empty `TraceRay` [S1, unofficial].
3. Compute the stratified sample coordinates: `hashVal = PcgHash(pixelIndex ^ gGiFrameSeed)` and `randomPair = RotatedHammersley2D(sampleIndex, activeSamples, hashVal)` [S1, unofficial].
4. Set the ray direction using cosine-weighted hemisphere sampling relative to the surface normal at the primary hit point: `ray.direction = CosineWeightedHemisphereSample(primary.normal, randomPair)` [S1, unofficial].
5. Set `ray.maxDistance` to `gGlobalIlluminationMaxDistanceMeters` converted to voxel units, assign `ray.id = globalIndex`, and write the result to `output_buffer` [S1, unofficial].

**Parameters:**
- `kMaximumGiSamples`: Fixed at 16 [S1, unofficial].
- `gGiPrimaryRayCount`: Number of primary rays processed in the previous pass [S1, unofficial].
- `gGiFrameSeed`: Seed for the PCG random number generator [S1, unofficial].
- `gGlobalIlluminationMode`: Controls GI activation; GI is active when equal to `kGlobalIlluminationVoxelOneBounce` [S1, unofficial].
- `gGlobalIlluminationSamples`: User-requested number of GI samples per pixel [S1, unofficial].
- `gShadowBiasMeters`: Shadow bias in meters, converted to voxel units for ray origin offset [S1, unofficial].
- `gGlobalIlluminationMaxDistanceMeters`: Maximum distance for GI rays in meters, converted to voxel units [S1, unofficial].

**Edge Cases and Pitfalls:**
- If `activeSamples` is less than `sampleIndex`, the ray is discarded [S1, unofficial].
- Precision issues may arise if `gShadowBiasMeters` is too small relative to `voxel_scale`, causing self-intersection [G].
- Non-unit cell sizes require explicit `voxel_scale` multiplication for distance and bias values [G].
- Degenerate surface normals (zero length) must be normalized before hemisphere sampling [G].

**Pseudocode:**
```python
import math

class TraceRay:
    def __init__(self, hit, origin, direction, maxDistance, id):
        self.hit = hit
        self.origin = origin
        self.direction = direction
        self.maxDistance = maxDistance
        self.id = id

def generate_gi_ray(global_index, primary_buffer, active_samples, k_maximum_gi_samples, g_gi_frame_seed, g_shadow_bias_meters, g_global_illumination_max_distance_meters, voxel_scale, total_capacity):
    # Step 1: Map thread ID
    pixel_index = global_index // k_maximum_gi_samples
    sample_index = global_index % k_maximum_gi_samples
    
    if global_index >= total_capacity:
        return TraceRay(hit=0, origin=(0.0, 0.0, 0.0), direction=(0.0, 0.0, 0.0), maxDistance=0.0, id=0)
    
    # Step 2: Fetch primary result
    primary = primary_buffer[pixel_index]
    
    if primary.hit == 0 or sample_index >= active_samples:
        return TraceRay(hit=0, origin=(0.0, 0.0, 0.0), direction=(0.0, 0.0, 0.0), maxDistance=0.0, id=0)
    
    # Step 3: Compute stratified sample
    hash_val = pcg_hash(pixel_index ^ g_gi_frame_seed)
    random_pair = rotated_hammersley_2d(sample_index, active_samples, hash_val)
    
    # Step 4: Sample direction
    ray_direction = cosine_weighted_hemisphere_sample(primary.normal, random_pair)
    
    # Step 5: Set ray properties
    max_distance_voxel = g_global_illumination_max_distance_meters * voxel_scale
    origin_offset = primary.normal * g_shadow_bias_meters * voxel_scale
    ray_origin = (primary.origin[0] + origin_offset[0], primary.origin[1] + origin_offset[1], primary.origin[2] + origin_offset[2])
    
    return TraceRay(hit=1, origin=ray_origin, direction=ray_direction, maxDistance=max_distance_voxel, id=global_index)

def pcg_hash(x):
    # Standard PCG32 state transformation [G]
    x = ((x >> 16) ^ x) * 0x45d9f3b
    x = ((x >> 16) ^ x) * 0x45d9f3b
    x = (x >> 16) ^ x
    return x

def rotated_hammersley_2d(sample_idx, active_samples, seed):
    # Standard Hammersley sequence with simple hash rotation [G]
    u = (sample_idx + 0.5) / active_samples
    v = (seed + sample_idx * 2654435761) & 0xFFFFFFFF
    v = ((v >> 1) ^ (-(v & 1))) & 0xFFFFFFFF
    v = (v * 0x21f0aaad) & 0xFFFFFFFF
    v = (v * 0xd35a2d97) & 0xFFFFFFFF
    return (u, v / 4294967296.0)

def cosine_weighted_hemisphere_sample(normal, random_pair):
    # Cosine-weighted hemisphere sampling [G]
    u1, u2 = random_pair
    x = math.sqrt(1.0 - u1) * math.cos(2.0 * math.pi * u2)
    y = math.sqrt(1.0 - u1) * math.sin(2.0 * math.pi * u2)
    z = math.sqrt(u1)
    # Construct orthonormal basis from normal
    if abs(normal[2]) < 0.9999:
        up = (0.0, 0.0, 1.0)
    else:
        up = (1.0, 0.0, 0.0)
    tangent = math_normalize(math_cross(up, normal))
    bitangent = math_cross(normal, tangent)
    return (tangent[0]*x + bitangent[0]*y + normal[0]*z, tangent[1]*x + bitangent[1]*y + normal[1]*z, tangent[2]*x + bitangent[2]*y + normal[2]*z)

def math_normalize(v):
    length = math.sqrt(v[0]**2 + v[1]**2 + v[2]**2)
    return (v[0]/length, v[1]/length, v[2]/length)

def math_cross(a, b):
    return (a[1]*b[2] - a[2]*b[1], a[2]*b[0] - a[0]*b[2], a[0]*b[1] - a[1]*b[0])
```
