# Orthographic Projection

Also called: Parallel Projection, Size-Preserving Projection

## Overview
Orthographic projection is a size-preserving mapping that flattens a 3D scene onto a 2D plane such that objects in the foreground occupy the same screen space as identical objects in the background, and parallel lines in 3D remain parallel in the projection [S1, unofficial]. It differs from perspective projection, which creates depth by scaling objects smaller with distance [S2]. In the context of volume rendering, it serves as the final transformation step after ray generation, defining the view volume via six clipping planes [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Six clipping plane coordinates defining the view volume: `fleft`, `fright` (left/right), `fdown`, `fup` (bottom/top), `fnear`, `ffar` (near/far) [S1, unofficial].
*   **Outputs:** A projection matrix or transformed coordinates that map 3D world coordinates to the 2D viewport, discarding geometry outside the defined box [S1, unofficial].

**Data Structures:**
The view volume is defined as an axis-aligned box (in the camera's local space) bounded by the six planes [S1, unofficial].

**Steps:**
1.  Define the six clipping parameters: `fleft`, `fright`, `fdown`, `fup`, `fnear`, `ffar` [S1, unofficial].
2.  Construct the orthographic projection matrix. While the specific matrix elements are not detailed in the sources, the standard OpenGL function `glOrtho` is used to implement this transformation [S1, unofficial].
3.  Apply the matrix to vertex coordinates. Points outside the box defined by the clipping planes are clipped and not drawn [S1, unofficial].

**Pseudocode:**
The sources reference the OpenGL API `glOrtho` but do not provide the explicit matrix multiplication formula. The implementation relies on the graphics API's internal matrix generation.

```python
# The sources cite the following API call for implementation:
# glOrtho((double)fleft, (double)fright, (double)fdown, (double)fup, (double)fnear, (double)ffar)
#
# The explicit matrix construction is not provided in the sources.
# [G] Standard OpenGL orthographic matrix M is typically:
# M = [
#   [2/(fright-fleft), 0,              0,              -(fright+fleft)/(fright-fleft)],
#   [0,                2/(fup-fdown),  0,              -(fup+fdown)/(fup-fdown)    ],
#   [0,                0,              -2/(ffar-fnear), -(ffar+fnear)/(ffar-fnear)  ],
#   [0,                0,              0,              1                            ]
# ]
# Coordinates are transformed by v' = M * v.
```

**Parameters:**
*   `fleft`, `fright`: Left and right clipping plane x-coordinates [S1, unofficial].
*   `fdown`, `fup`: Bottom and top clipping plane y-coordinates [S1, unofficial].
*   `fnear`, `ffar`: Near and far clipping plane z-coordinates [S1, unofficial].

**Edge Cases:**
*   Clipping: Drawing does not occur outside the 3D region defined by the six clipping planes [S1, unofficial].
*   Additional clipping: Up to six additional clipping planes parallel to the x, y, and z axes may be activated to hide geometry [S1, unofficial].

## Subtopics

### Perspective Projection
A projection method that creates an illusion of depth by causing objects in the background to take up less screen space than the same sized object drawn in the foreground [S1, unofficial]. It is selected via the View section of the Motion/View dialog box in Smokeview [S2]. It uses `glFrustum` with the same six clipping plane parameters (`fleft`, `fright`, `fdown`, `fup`, `fnear`, `ffar`) to define a truncated pyramid view frustum [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Size-preserving; objects maintain consistent screen space regardless of depth, making it suitable for technical visualization where scale accuracy is critical [S1, unofficial][S2].
*   **Limitations:** Lacks the depth cues provided by perspective scaling [S2].
*   **When to use:** When visualizing data where relative sizes at different depths must remain accurate (e.g., fire dynamics simulation data) [S1, unofficial][S2].
*   **When not to use:** When a realistic illusion of depth is required [S2].

## Background
Orthographic projection is a standard technique in computer graphics, implemented in OpenGL via `glOrtho` [S1, unofficial]. It is used in Smokeview, a tool for visualizing Fire Dynamics Simulation (FDS) data, to allow users to toggle between perspective and size-preserving views via the Motion/View dialog box [S1, unofficial][S2]. The implementation relies on the six clipping plane parameters to define the view volume [S1, unofficial].
