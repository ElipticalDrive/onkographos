# Voxel Initialization via PI3

Also called: PI3-based Voxel Initialization

## Overview
Voxel Initialization via PI3 establishes a geometrically accurate Signed Distance Field (SDF) prior for volume rendering or reconstruction tasks using unposed images [S1, unofficial]. It initializes sparse voxel grids by leveraging the PI3 visual geometry model to estimate 3D points in world coordinates, transforming these points to ground truth camera poses via Umeyama’s method, and allocating voxels with SDF values computed from the minimum distance to the transformed points [S1, unofficial]. It differs from sibling methods like [Depth Map to Absolute Camera Coordinates](7984-depth-map-to-absolute-camera-coordinates.md) by explicitly handling camera pose misalignment through Umeyama’s alignment and relying on PI3’s world-coordinate estimates rather than direct backprojection from known poses [S1, unofficial].

## How it works
**Inputs:**
*   Unposed images or depth maps derived from them [S1, unofficial].
*   PI3 model outputs: point maps in world coordinates ($P_{world}$) [S1, unofficial].
*   Ground truth camera poses to align with [S1, unofficial].
*   Voxel grid parameters: corner position $v_{min}$ and side length $v_l$ [S1, unofficial].

**Outputs:**
*   Initialized sparse voxel grid with SDF values [S1, unofficial].

**Data Structures:**
*   **Voxel:** Parameterized by corner SDF values, defined by its corner closest to the world origin $v_{min}$ and side length $v_l$ [S1, unofficial].
*   **Point Map:** Set of 3D points $p$ in world coordinates [S1, unofficial].

**Steps:**
1.  **Estimate World Points:** Use the PI3 model to estimate 3D points in world coordinates from the unposed images [S1, unofficial]. Let this set be $P_{world}$.
2.  **Transform to Ground Truth Poses:** Transform the points $P_{world}$ into the coordinate system of the ground truth camera poses using Umeyama’s method [S1, unofficial]. Let the transformed points be $P_{transformed}$.
3.  **Allocate Voxels:** Allocate voxels in the sparse grid at the locations of $P_{transformed}$ [S1, unofficial].
4.  **Compute SDF:** For each allocated voxel, compute the SDF value by calculating the minimum Euclidean distance from the voxel to the points in $P_{transformed}$ [S1, unofficial].

**Formulas:**
The local coordinate $q$ of a point $p$ within a voxel $v$ is defined as [S1, unofficial]:
$$ q = \frac{p - v_{min}}{v_l} $$
where $v_{min}$ is the voxel corner closest to the world origin and $v_l$ is the voxel side length [S1, unofficial]. The SDF value for each voxel is derived from the minimum distance from the transformed points to the voxel geometry [S1, unofficial].

**Parameters:**
*   $v_{min}$: Voxel corner position [S1, unofficial].
*   $v_l$: Voxel side length [S1, unofficial].
*   PI3 Model: Visual geometry model for 3D point estimation [S1, unofficial].
*   Umeyama’s Method: Rigid body transformation estimation [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision:** The accuracy of the initialization depends heavily on the PI3 model's ability to estimate correct world coordinates and the precision of Umeyama’s transformation [S1, unofficial].
*   **Boundaries:** Voxels are only allocated at transformed points; empty space is not explicitly initialized via free-space carving in this specific PI3-based step, relying on the SDF formulation for convergence [S1, unofficial].
*   **Degenerate Input:** If PI3 fails to estimate points or Umeyama’s method encounters degenerate configurations, the initialization will be incomplete or incorrect [S1, unofficial].

**Pseudocode:**
```python
import math

def initialize_voxels_via_pi3(unposed_images, ground_truth_poses, pi3_model, umeyama_transform, voxel_config):
    """
    Initialize voxels using PI3 and Umeyama's method.
    
    Args:
        unposed_images: List of unposed images or depth maps.
        ground_truth_poses: Ground truth camera poses.
        pi3_model: PI3 visual geometry model.
        umeyama_transform: Function to apply Umeyama's method.
        voxel_config: Configuration for voxel grid (v_min, v_l).
        
    Returns:
        voxel_grid: Initialized sparse voxel grid with SDF values.
    """
    # Step 1: Estimate 3D points in world coordinates using PI3
    points_world = pi3_model.estimate_3d_points(unposed_images)
    
    # Step 2: Transform points to ground truth camera poses using Umeyama's method
    transformed_points = umeyama_transform(points_world, ground_truth_poses)
    
    # Step 3: Allocate voxels at the transformed points
    voxel_grid = {}
    v_min = voxel_config['v_min']
    v_l = voxel_config['v_l']
    
    for point in transformed_points:
        voxel_key = tuple(math.floor((point - v_min) / v_l))
        if voxel_key not in voxel_grid:
            voxel_grid[voxel_key] = float('inf')
            
    # Step 4: Compute SDF for each allocated voxel
    for voxel_key in voxel_grid:
        voxel_center = v_min + (voxel_key + 0.5) * v_l
        min_dist = float('inf')
        for point in transformed_points:
            dist = math.sqrt(sum((c - p)**2 for c, p in zip(voxel_center, point)))
            if dist < min_dist:
                min_dist = dist
        voxel_grid[voxel_key] = min_dist
        
    return voxel_grid
```

## Subtopics

### Testing Points Generation
A method to generate testing points $P_{t\{i\}}$ from $P_{v\{i\}}$ and a sensor origin to update distance information for voxels within the current sensor field of view, improving efficiency over conventional free-space carving [S2]. It ray-casts from the sensor origin to each voxel in $P_{v\{i\}}$, queries only voxels with previous surface measurements in the field of view, and generates voxels along surface normals up to a certain distance even outside the frustum to handle sensor rays close to being parallel to the observed surface [S2]. For each testing point $x^*$ in $P_{t\{i\}}$, it finds the closest node in the local Gaussian Process Distance Field (L-GPDF) and uses the node's Gaussian Process to compute the distance inference $\hat{d}_t(x^*)$, surface property inference $\hat{c}_t(x^*)$, and variances $\hat{v}_t(x^*)$ and $\hat{w}_t(x^*)$ [S2]. It also computes the distance sign given the sensor origin [S2].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Provides a stable and physically meaningful initialization, enabling faster and more efficient convergence by directly utilizing rich geometric priors from the beginning [S1, unofficial]. Handles unposed images effectively [S1, unofficial].
*   **Limitations:** Relies on the accuracy of PI3 and Umeyama’s method. Does not explicitly handle free-space carving in the initialization step [S1, unofficial].
*   **When to Use:** When initializing SDF-based reconstruction from unposed images is required, and a geometric prior is beneficial for convergence [S1, unofficial].
*   **When Not to Use:** When ground truth poses are not available for Umeyama’s alignment, or when PI3 is not suitable for the scene [S1, unofficial].

## Background
Originated in SVRecon, which uses PI3, a visual geometry model, to estimate 3D points in world coordinates from unposed images, transforming them via Umeyama’s method to initialize SDF-based voxel grids [S1, unofficial]. It is used in sparse voxel rasterization for surface reconstruction [S1, unofficial].
