# Global Scene Point Cloud Construction

Also called: Global Point Cloud Construction, Multi-view Point Cloud Generation

## Overview
Global Scene Point Cloud Construction aggregates metric depth maps from multiple calibrated views into a unified 3D point cloud in world coordinates [S1]. It solves the redundancy and inconsistency of primitives that arise when unprojecting overlapping depth maps independently [S1]. It differs from [Depth to 3D Points Conversion](7929-depth-to-3d-points-conversion.md) by handling multi-view accumulation and cleaning, and from [Point Cloud Generation and Refinement](8042-point-cloud-generation-and-refinement.md) by focusing on the initial assembly and noise removal [S1].

## How it works
**Inputs:**
- $N$ RGB images $\{I_n\}_{n=1}^N$.
- $N$ metric depth maps $\{D_n\}_{n=1}^N$.
- Intrinsic matrices $\{K_n\}_{n=1}^N$.
- Extrinsic matrices $\{T_n = [R_n | t_n]\}_{n=1}^N$, where $R_n$ is rotation and $t_n$ is translation [S1].

**Outputs:**
- A global scene point cloud $\mathcal{P} \in \mathbb{R}^{N_p \times 3}$ in world coordinates [S1].

**Data Structures:**
- Raw point cloud $P_{\text{raw}}$: List or array of 3D points [S1].
- Filtered point cloud $P_{\text{final}}$: List or array of 3D points [S1].

**Steps:**
1. **Unprojection:** For each view $n \in \{1, \dots, N\}$, unproject the depth map $D_n$ using $I_n, D_n, T_n, K_n$ to obtain local 3D points [S1].
2. **Accumulation:** Union all local point clouds:
   $$ \mathcal{P} = \bigcup_{n=1}^N \pi^{-1}(I_n, D_n, T_n, K_n) $$
   where $\pi^{-1}$ denotes the pixel unprojection operation [S1].
3. **Uniform Filtering:** Apply a uniform filter in 3D space to $P_{\text{raw}}$ to delete duplicate primitives while keeping the scene structure [S1].
4. **Statistical Filtering:** Apply a statistical filter to remove floaters (noise) [S1].

**Pseudocode:**
```python
def global_point_cloud_construction(images, depths, intrinsics, extrinsics):
    raw_points = []
    for n in range(len(images)):
        K = intrinsics[n]
        T = extrinsics[n]
        K_inv = invert_4x4(K)  # Standard linear algebra [G]
        T_inv = invert_4x4(T)  # Standard linear algebra [G]
        h, w = depths[n].shape
        for y in range(h):
            for x in range(w):
                d = depths[n][y, x]
                if d <= 0:
                    continue
                u, v = float(x) + 0.5, float(y) + 0.5
                cam_dir = mat_vec_mul(K_inv, [u, v, 1.0])
                cam_pos = [c * d for c in cam_dir]
                world_pos = mat_vec_mul(T_inv, cam_pos + [1.0])
                raw_points.append(world_pos[:3])
    # Uniform filter radius not given in sources [S1]
    filtered = uniform_filter_3d(raw_points, voxel_size=0.01)
    # Statistical filter k and std ratio not given in sources [S1]
    final = statistical_filter_3d(filtered, k=50, std_ratio=2.0)
    return final

def uniform_filter_3d(points, voxel_size=0.01):
    grid = {}
    result = []
    for p in points:
        key = (int(p[0] / voxel_size), int(p[1] / voxel_size), int(p[2] / voxel_size))
        if key not in grid:
            grid[key] = p
            result.append(p)
    return result

def statistical_filter_3d(points, k=50, std_ratio=2.0):
    distances = []
    for i, p in enumerate(points):
        dists = sorted([euclidean_dist(p, q) for j, q in enumerate(points) if i != j])[:k]
        if len(dists) < k:
            continue
        mean_dist = sum(dists) / len(dists)
        distances.append(mean_dist)
    if not distances:
        return points
    global_mean = sum(distances) / len(distances)
    global_std = (sum((d - global_mean)**2 for d in distances) / len(distances))**0.5
    threshold = global_mean + std_ratio * global_std
    return [p for p, d in zip(points, distances) if d <= threshold]

def mat_vec_mul(M, v):
    return [sum(M[i][j] * v[j] for j in range(len(v))) for i in range(len(M))]

def euclidean_dist(a, b):
    return ((a[0]-b[0])**2 + (a[1]-b[1])**2 + (a[2]-b[2])**2)**0.5

def invert_4x4(M):

```

**Parameters:**
- Uniform filter radius: Not given in the sources [S1].
- Statistical filter $k$ and standard deviation ratio: Not given in the sources [S1].

**Edge Cases and Pitfalls:**
- Overlapping regions generate redundant primitives; uniform filtering is required [S1].
- Noise/floaters remain after uniform filtering; statistical filtering is required [S1].
- Dynamic objects may receive invalid depth supervision if not temporally aligned; LiDAR measurements are used as ground truth only at the camera recording time [S2].

## Subtopics

### Scene Bounds Computation from LiDAR
Computes scene bounds by filtering LiDAR sweeps to retain only points within 80 meters of the ego-vehicle, registering them in the global world frame using ego-vehicle poses, and computing bounds from the resulting point cloud [S2]. Maximum distance per sweep is 80 meters [S2].

## Operating characteristics
Time and memory complexity are not given in the sources [S1]. The method requires accurate calibration and is sensitive to depth errors [S1]. It is used when constructing a global scene representation from multiple calibrated views [S1].

## Background
Originated in urban environment modeling and neural scene representations [S1, S2]. [S1] introduces the method for initializing sparse neural volumes in Gaussian Splatting [S1]. [S2] adapts the accumulation pipeline for dynamic urban environments using LiDAR for scene bounds [S2].
