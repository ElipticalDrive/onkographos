# Optimized 3D to 2D Projection

Also called: 3D to 2D Projection, Screen Space Transform

## Overview
This method transforms 3D world-space vertices of geometric primitives (specifically cube faces) into 2D screen-space coordinates using a simplified perspective projection model. It solves the problem of determining which faces are visible on the screen by combining coordinate transformation, perspective division, and visibility culling (backface, near-plane, and screen-boundary checks). It differs from general-purpose graphics pipelines by operating on raw vertex arrays with explicit yaw/pitch rotations and a custom visibility mask calculation, rather than relying on a full view-projection matrix multiplication.

## How it works
**Inputs:**
- `verts`: Array of shape `(num_faces, 4, 3)` containing 3D world coordinates for the 4 vertices of each face.
- `origin`: 3D vector representing the camera position in world space.
- `yaw`: Float, rotation angle around the Y-axis (radians).
- `pitch`: Float, rotation angle around the Z-axis (radians).
- `settings`: Object containing `NEAR_PLANE` (float), `FOV` (float), `WIDTH` (int), `HEIGHT` (int).
- `constants`: Object containing `HALF_WIDTH`, `HALF_HEIGHT`.

**Outputs:**
- `proj_points`: Array of shape `(num_faces, 4, 2)` containing integer screen coordinates $(x, y)$.
- `depth_per_face`: Array of shape `(num_faces,)` containing the average depth of each face.
- `visibility_mask`: Boolean array of shape `(num_faces,)` indicating visible faces.

**Data Structures:**
- Vertices are stored as contiguous float32 arrays.
- Screen coordinates are packed as int32.
- Depth is stored as float32.

**Parameters:**
- `NEAR`: `settings.NEAR_PLANE` [S1, unofficial].
- `FOV_VAL`: `settings.FOV` [S1, unofficial].
- `_AREA_EPSILON`: `1e-6` [S1, unofficial].

**Steps:**

1. **Translation**: Translate vertices relative to the camera origin.
   $$ v_{local} = verts - origin $$
   Reshape `verts` to `(num_faces * 4, 3)` for vectorized subtraction.

2. **Yaw Rotation (XY Plane)**: Rotate the local X and Y components around the Y-axis.
   $$ rx_y = v_x \cos(yaw) - v_y \sin(yaw) $$
   $$ ry_{temp} = v_x \sin(yaw) + v_y \cos(yaw) $$
   Where $v_x, v_y$ are the X and Y components of $v_{local}$.

3. **Pitch Rotation (YZ Plane)**: Rotate the temporary Y and Z components around the Z-axis.
   $$ ry_p = v_z \sin(pitch) + ry_{temp} \cos(pitch) $$
   $$ rz_p = v_z \cos(pitch) - ry_{temp} \sin(pitch) $$
   Where $v_z$ is the Z component of $v_{local}$.
   Resulting coordinates are $(rx_y, ry_p, rz_p)$.

4. **Perspective Projection**:
   Clamp depth to prevent division by zero or negative depth artifacts:
   $$ depth_{safe} = \max(ry_p, NEAR) $$
   Calculate screen coordinates:
   $$ screen_x = \left( \frac{HALF\_WIDTH + rx_y \cdot \frac{FOV\_VAL}{depth_{safe}}}{1} \right)_{int32} $$
   $$ screen_y = \left( \frac{HALF\_HEIGHT - rz_p \cdot \frac{FOV\_VAL}{depth_{safe}}}{1} \right)_{int32} $$
   Note: The source implementation uses `np.maximum` for clamping and explicit casting to `np.int32` [S1, unofficial].

5. **Pack Projections**:
   Reshape `screen_x` and `screen_y` back to `(num_faces, 4, 2)`.
   Calculate average depth per face:
   $$ depth_{per\_face} = \text{mean}(ry_p, \text{axis}=1) $$

6. **Visibility Mask Calculation**:
   Compute a boolean mask for each face based on four criteria:
   - **Behind Near Plane**: Face is behind the camera if all vertices have depth $< NEAR$.
     $$ is\_behind = \text{all}(depths < NEAR, \text{axis}=1) $$
   - **Off Screen X**: Face is off-screen if all vertices are outside horizontal bounds.
     $$ is\_off\_x = \text{all}(screen_x < 0) \lor \text{all}(screen_x > WIDTH) $$
   - **Off Screen Y**: Face is off-screen if all vertices are outside vertical bounds.
     $$ is\_off\_y = \text{all}(screen_y < 0) \lor \text{all}(screen_y > HEIGHT) $$
   - **Backface Culling**: Use the Shoelace formula on screen-space vertices to determine orientation.
     $$ dx_1 = sx_1 - sx_0, \quad dy_1 = sy_1 - sy_0 $$
     $$ dx_2 = sx_2 - sx_0, \quad dy_2 = sy_2 - sy_0 $$
     $$ area = (dx_1 \cdot dy_2) - (dy_1 \cdot dx_2) $$
     $$ is\_backface = area > -\_AREA\_EPSILON $$
     A face is considered a backface if the signed area is non-negative (or close to zero) [S1, unofficial].

   Final mask:
   $$ visibility\_mask = \neg (is\_behind \lor is\_off\_x \lor is\_off\_y \lor is\_backface) $$

**Pseudocode:**

```python
import numpy as np

def optimized_3d_to_2d_projection(
    verts: np.ndarray,  # Shape: (num_faces, 4, 3)
    origin: np.ndarray, # Shape: (3,)
    yaw: float,
    pitch: float,
    settings: dict,
    constants: dict
) -> tuple:
    """
    Transforms 3D face vertices to 2D screen space and calculates visibility.
    """
    num_faces = verts.shape[0]
    if num_faces == 0:
        return (
            np.empty((0, 4, 2), dtype=np.int32),
            np.empty((0,), dtype=np.float32),
            np.empty((0,), dtype=np.bool_)
        )

    NEAR = settings['NEAR_PLANE']
    FOV_VAL = settings['FOV']
    WIDTH = settings['WIDTH']
    HEIGHT = settings['HEIGHT']
    HALF_WIDTH = constants['HALF_WIDTH']
    HALF_HEIGHT = constants['HALF_HEIGHT']
    AREA_EPSILON = 1e-6

    # 1. Translation
    # Reshape to (num_faces * 4, 3) for broadcasting
    verts_flat = verts.reshape(-1, 3)
    v_local = verts_flat - origin

    # Extract components
    vx = v_local[:, 0]
    vy = v_local[:, 1]
    vz = v_local[:, 2]

    # 2. Yaw Rotation (XY Plane)
    cos_y = np.cos(yaw)
    sin_y = np.sin(yaw)
    rx_y = (vx * cos_y) - (vy * sin_y)
    ry_temp = (vx * sin_y) + (vy * cos_y)

    # 3. Pitch Rotation (YZ Plane)
    cos_p = np.cos(pitch)
    sin_p = np.sin(pitch)
    ry_p = (vz * sin_p) + (ry_temp * cos_p)
    rz_p = (vz * cos_p) - (ry_temp * sin_p)

    # 4. Perspective Projection
    depth_safe = np.maximum(ry_p, NEAR)
    
    # Calculate screen coordinates
    # Note: Source uses integer casting directly
    screen_x = (HALF_WIDTH + (rx_y * FOV_VAL / depth_safe)).astype(np.int32)
    screen_y = (HALF_HEIGHT - (rz_p * FOV_VAL / depth_safe)).astype(np.int32)

    # 5. Pack Projections
    # Reshape back to (num_faces, 4, 2)
    proj_points = np.stack([screen_x, screen_y], axis=1).reshape(num_faces, 4, 2)
    
    # Calculate depth per face (mean of ry_p for the 4 vertices)
    depth_per_face = ry_p.reshape(num_faces, 4).mean(axis=1)

    # 6. Visibility Mask
    # Reshape for per-face checks
    sx_f = screen_x.reshape(num_faces, 4)
    sy_f = screen_y.reshape(num_faces, 4)
    depths = ry_p.reshape(num_faces, 4)

    # Behind near plane: all vertices behind near plane
    is_behind = np.all(depths < NEAR, axis=1)

    # Off screen X: all vertices outside [0, WIDTH]
    is_off_x = np.all(sx_f < 0, axis=1) | np.all(sx_f > WIDTH, axis=1)

    # Off screen Y: all vertices outside [0, HEIGHT]
    is_off_y = np.all(sy_f < 0, axis=1) | np.all(sy_f > HEIGHT, axis=1)

    # Backface culling using Shoelace formula
    # Vertices are assumed to be ordered 0, 1, 2, 3
    # Use vertices 0, 1, 2 for triangle area calculation
    sx0 = sx_f[:, 0]
    sx1 = sx_f[:, 1]
    sx2 = sx_f[:, 2]
    sy0 = sy_f[:, 0]
    sy1 = sy_f[:, 1]
    sy2 = sy_f[:, 2]

    dx1 = sx1 - sx0
    dy1 = sy1 - sy0
    dx2 = sx2 - sx0
    dy2 = sy2 - sy0

    area = (dx1 * dy2) - (dy1 * dx2)
    is_backface = area > -AREA_EPSILON

    visibility_mask = ~(is_behind | is_off_x | is_off_y | is_backface)

    return proj_points, depth_per_face, visibility_mask
```

**Edge Cases and Pitfalls:**
- **Zero Faces**: If `num_faces` is 0, the function returns empty arrays immediately [S1, unofficial].
- **Depth Clamping**: Using `np.maximum` with `NEAR` prevents division by zero and negative depth issues, but may cause z-fighting if `NEAR` is too large [S1, unofficial].
- **Backface Orientation**: The Shoelace formula assumes a specific vertex winding order (counter-clockwise or clockwise). The source defines backfaces as those with area $> -1e-6$, implying a specific winding convention [S1, unofficial].
- **Integer Overflow**: Screen coordinates are cast to `int32`. If FOV or world coordinates are extremely large, overflow may occur [S1, unofficial].

## Operating characteristics
- **Time Complexity**: $O(N)$ where $N$ is the number of faces. All operations are vectorized numpy operations.
- **Memory Complexity**: $O(N)$ for storing intermediate arrays and outputs.
- **Performance**: Highly optimized for bulk processing of voxel faces. The use of vectorized numpy operations avoids Python loops.
- **Strengths**: Simple, fast, and explicit. No matrix library dependencies.
- **Limitations**: Limited to perspective projection with fixed FOV. Not suitable for complex camera models (e.g., fisheye, orthographic). Backface culling is approximate due to epsilon [S1, unofficial].

## Background
This method is derived from the `pyvorengi-sdk-demo` project, an unofficial SDK for a voxel-based game engine. It implements a simplified screen-space transform for rendering voxel chunks. The approach is tailored for real-time voxel rendering where performance is critical and complex camera models are unnecessary.
