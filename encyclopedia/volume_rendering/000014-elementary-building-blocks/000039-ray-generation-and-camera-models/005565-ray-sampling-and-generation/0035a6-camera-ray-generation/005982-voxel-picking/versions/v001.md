# Voxel Picking

Also called: BrainGazer picking, Bruckner et al. method, Contribution-Based Picking, voglPick

## Overview
Voxel Picking is a volume rendering interaction technique that selects a specific position along a camera ray based on the sample that contributes most significantly to the final pixel color [S1]. Unlike methods that select the maximum data value or opacity threshold [S1], this approach targets the sample with the highest accumulated contribution to the rendered image. It is distinct from [Camera Ray Generation](7456-camera-ray-generation.md) by adding a selection criterion to the generated ray, and differs from [Orthographic (Parallel) Camera Ray Generation](1319-orthographic-parallel-camera-ray-generation.md) by focusing on contribution-based selection rather than geometric projection alone.

## How it works
**Inputs and Outputs:**
*   **Input:** A 2D screen coordinate (cursor position) and the current volume rendering state (ray, transfer function, accumulation buffer).
*   **Output:** A 3D voxel position along the ray that maximizes the contribution to the pixel color.

**Data Structures:**
Not given in the sources.

**Steps:**
1.  **Ray Generation:** Generate a 3D ray originating from the camera eye position and passing through the 2D cursor coordinates on the screen [S2]. This builds on [Camera Ray Generation](7456-camera-ray-generation.md).
2.  **Sampling:** Traverse the volume along the generated ray, sampling voxel values at regular intervals [S2].
3.  **Contribution Calculation:** For each sample $i$ along the ray, calculate its contribution $C_i$ to the final pixel color. The contribution is typically defined by the product of the sample's opacity $\alpha_i$ and the accumulated transmittance $T_i$ from the eye to that sample:
    $$ C_i = \alpha_i \cdot T_i $$
    where $T_i = \prod_{j=0}^{i-1} (1 - \alpha_j)$ [S1].
4.  **Selection:** Identify the sample index $k$ that maximizes the contribution:
    $$ k = \arg \max_i (C_i) $$
5.  **Output:** Return the 3D position of the voxel at index $k$ [S1].

**Parameters:**
*   Ray step size: Not given in the sources.
*   Transfer function: Depends on the specific rendering technique (e.g., BrainGazer system) [S1].

**Edge Cases and Pitfalls:**
*   **Visibility vs. Contribution:** The sample contributing most to the final pixel does not necessarily belong to the most visible object (the group of samples contributing most to the final pixel) [S1].
*   **Arbitrary Positioning:** Because the method considers only one sample, the resulting position may lie at an arbitrary location within a perceivable structure rather than at the front or center of the perceived structure [S1].
*   **Interaction:** In the voglPick implementation, the user selects the line of sight by pressing the right mouse button [S2].

**Pseudocode:**
```python
def voxel_pick(cursor_x, cursor_y, volume, transfer_function):
    # 1. Generate ray from camera through cursor
    # Assumes camera ray generation is handled by parent module
    ray_origin, ray_direction = generate_camera_ray(cursor_x, cursor_y)
    
    max_contribution = -1.0
    best_position = None
    accumulated_transmittance = 1.0
    
    # 2. Traverse volume along ray
    # Step size and bounds depend on volume implementation [G]
    step_size = 0.1
    for t in range(0, volume.max_distance, step_size):
        position = ray_origin + ray_direction * t
        
        # Check if position is within volume bounds
        if not volume.contains(position):
            break
            
        # 3. Sample voxel value
        voxel_value = volume.sample(position)
        
        # 4. Calculate opacity and contribution
        # Transfer function maps value to color and opacity
        color, opacity = transfer_function(voxel_value)
        
        contribution = opacity * accumulated_transmittance
        
        # 5. Track maximum contribution
        if contribution > max_contribution:
            max_contribution = contribution
            best_position = position
            
        # Update transmittance for next sample
        accumulated_transmittance *= (1.0 - opacity)
        
    return best_position
```

## Subtopics

### BrainGazer Picking
The specific implementation used in the BrainGazer system, noted for working well with the special volume rendering technique employed there [S1].

### voglPick
An example implementation in the SGI Volumizer suite that illustrates picking individual voxels by drawing a signal of voxel values along the selected line of sight at the bottom of the screen [S2].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of samples along the ray, $O(N)$, where $N$ is the number of steps taken during traversal.
*   **Memory Complexity:** $O(1)$ auxiliary memory, as only the current contribution and best position need to be tracked.
*   **Strengths:** Directly targets the most visually significant part of the ray in terms of color contribution [S1].
*   **Limitations:** May select positions that are not at the front or center of a structure, leading to potentially unintuitive user feedback [S1]. It is sensitive to the transfer function and may not correspond to the "most visible" object if that object has low opacity but high color intensity [S1].
*   **When to use:** When the goal is to identify the voxel that most strongly influences the pixel's color in the final image.
*   **When not to use:** When precise localization to the surface or center of a structure is required, or when the most visible object has low opacity [S1].

## Background
Voxel Picking was introduced by Bruckner et al. in the context of the BrainGazer system [S1]. The technique was designed to work with the specific volume rendering method used in that system [S1]. It is also referenced in the WYSIWYP (What You See Is What You Pick) paper, which critiques the method for its potential to select arbitrary positions within structures rather than intuitive ones like the front or center [S1]. An early example of similar functionality is found in the SGI Volumizer's `voglPick` utility, which allows users to select a line of sight and view a signal of voxel values along that line [S2].
