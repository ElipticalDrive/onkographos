# Voxel Picking

Also called: BrainGazer picking, Bruckner et al. method, Contribution-Based Picking, voglPick

## Overview
Voxel Picking is a volume rendering interaction technique that selects a specific position along a camera ray based on the sample that contributes most significantly to the final pixel color [S1]. Unlike methods that select the maximum data value or opacity threshold [S1], this approach targets the sample with the highest accumulated contribution to the rendered image [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 2D screen coordinate (cursor position), the volume data, and a transfer function [S2].
*   **Output:** A 3D voxel position along the ray that maximizes the contribution to the pixel color [S1].

**Data Structures:**
Not given in the sources.

**Steps:**
1.  **Ray Generation:** Generate a 3D ray originating from the camera eye position and passing through the 2D cursor coordinates on the screen [S2].
2.  **Sampling:** Sample voxel values along the line of sight defined by the ray [S2].
3.  **Contribution Calculation:** For each sample along the ray, calculate its contribution to the final pixel color [S1]. The contribution is derived from the sample's opacity and the accumulated transmittance from the eye to that sample [G].
4.  **Selection:** Identify the sample index that maximizes the contribution [S1].
5.  **Output:** Return the 3D position of the voxel at the selected index [S1].

**Parameters:**
*   Ray step size: Not given in the sources.
*   Transfer function: Depends on the specific rendering technique (e.g., BrainGazer system) [S1].

**Edge Cases and Pitfalls:**
*   **Visibility vs. Contribution:** The sample contributing most to the final pixel does not necessarily belong to the most visible object (the group of samples contributing most to the final pixel) [S1].
*   **Arbitrary Positioning:** Because the method considers only one sample, the resulting position may lie at an arbitrary location within a perceivable structure rather than at the front or center of the perceived structure [S1].
*   **Interaction:** In the voglPick implementation, the user selects the line of sight by pressing the right mouse button [S2].

**Pseudocode:**
```python
def voxel_pick(ray_origin, ray_direction, volume_sample_func, transfer_func, max_distance, step_size):
    max_contribution = -1.0
    best_position = None
    accumulated_transmittance = 1.0
    
    # March along the ray from origin to max_distance
    # The exact traversal bounds and step size are not specified in the sources [G]
    num_steps = int(max_distance / step_size)
    for i in range(num_steps):
        t = i * step_size
        position = (ray_origin[0] + ray_direction[0] * t,
                    ray_origin[1] + ray_direction[1] * t,
                    ray_origin[2] + ray_direction[2] * t)
        
        # Check if position is within volume bounds
        if not volume_sample_func.is_inside(position):
            continue
            
        # Sample voxel value
        voxel_value = volume_sample_func(position)
        
        # Calculate opacity and contribution
        color, opacity = transfer_func(voxel_value)
        contribution = opacity * accumulated_transmittance
        
        # Track maximum contribution
        if contribution > max_contribution:
            max_contribution = contribution
            best_position = position
            
        # Update transmittance for next sample
        accumulated_transmittance *= (1.0 - opacity)
        
    return best_position
```

## Operating characteristics
*   **Strengths:** Directly targets the most visually significant part of the ray in terms of color contribution [S1].
*   **Limitations:** May select positions that are not at the front or center of a structure, leading to potentially unintuitive user feedback [S1]. It is sensitive to the transfer function and may not correspond to the "most visible" object if that object has low opacity but high color intensity [S1].

## Background
Voxel Picking was introduced by Bruckner et al. in the context of the BrainGazer system [S1]. The technique was designed to work with the specific volume rendering method used in that system [S1]. It is also referenced in the WYSIWYP (What You See Is What You Pick) paper, which critiques the method for its potential to select arbitrary positions within structures rather than intuitive ones like the front or center [S1]. An early example of similar functionality is found in the SGI Volumizer's `voglPick` utility, which allows users to select a line of sight and view a signal of voxel values along that line [S2].
