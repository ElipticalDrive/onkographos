# Learning Multiple-Scattering Solutions for Sphere-Tracing

Also called: CVAE-based sphere-tracing, CVAE-based subsurface scattering, Data-driven sphere-tracing, Learning-based path tracing

## Overview
This method accelerates volumetric path tracing by learning a geometric approximation of random light paths in homogeneous volumes to determine absorption and direct lighting contributions, bypassing lengthy internal scattering processes by summarizing many scattering events into a single sphere-tracing step [S1]. It differs from shell tracing by using neural networks to model statistical distributions rather than discretized transition probability arrays, and from analytic models by avoiding assumptions of planar surfaces or isotropic transport [S1]. It builds on [Anisotropic Scattering via CVAE Sampling](19952-anisotropic-scattering-via-cvae-sampling.md) by extending the CVAE approach to jointly model the number of scattering events, absorption, exit position, and direction within a sphere [S1].

## How it works
**Inputs:**
*   Current ray position $x$ and incoming direction $\omega_{in}$ [S1].
*   Optical properties of the homogeneous volume: extinction coefficient $\sigma_t$, scattering albedo $\varphi$, and anisotropy parameter $g$ [S1].
*   A pre-computed 3D Signed Distance Function (SDF) of the geometry [S1].

**Outputs:**
*   Exit position $x$ on the sphere shell [S1].
*   Outgoing direction $\omega$ [S1].
*   Number of scattering events $N$ [S1].
*   Absorption indicator $A$ (1 if terminated, 0 if not) [S1].
*   Additional ray statistics $\Sigma$ for in-scattering approximation [S1].

**Data Structures:**
1.  **Signed Distance Field (SDF):** A 3D voxel grid where each voxel stores the conservative shortest Chebyshev distance to the object's surface [S1].
2.  **CVAE Model:** Consists of an Encoder $Enc(x, c)$ and a Decoder $Dec(z, c)$ [S1].
    *   **Condition Vector $c$:** Contains optical properties $[\sigma_t, g, \varphi]$ [S1].
    *   **Latent Space $Z$:** Dimension $L$, following prior distribution $\mathcal{N}(0, I_Z)$ [S1].
    *   **Encoder Output:** Mean $\mu_{Enc}(x, c)$ and diagonal covariance $\Sigma_{Enc}(x, c)$ for latent distribution $q_{Enc}(z|x, c) = \mathcal{N}(\mu_{Enc}, \Sigma_{Enc})$ [S1].
    *   **Decoder Output:** Mean $\mu_{Dec}(z, c)$ and diagonal covariance $\Sigma_{Dec}(z, c)$ for data distribution $p_{Dec}(x|z, c) = \mathcal{N}(\mu_{Dec}, \Sigma_{Dec})$ [S1].
    *   **Network Architecture:** Shallow networks with up to three layers and no more than 16 nodes per layer [S1].

**Formulas:**
*   **Henyey-Greenstein Phase Function:**
    $$ \rho_g(\omega', \omega) = \frac{1-g^2}{2\pi (1+g^2-2g \cos(\omega, \omega'))^{3/2}} $$
    where $g$ is the anisotropy parameter (expected cosine between ray directions before and after scattering) [S1].
*   **Distance between scattering events (Ground Truth Generation):**
    $$ l = -\frac{\log(1 - \xi)}{\sigma_t} $$
    where $\xi$ is a uniform random number between 0 and 1 [S1].
*   **Conditional Probability Density Function:**
    $$ p(N, A, x, \omega, \Sigma | \sigma_t, g, \varphi) $$
    This PDF is modeled by the sequence of three CVAEs [S1].

**Parameters:**
*   **Training Geometry:** Spherical geometry with unitary radius [S1].
*   **Training Variable:** Interior density $\sigma_t$, which varies to simulate different scattering conditions [S1].
*   **Latent Space Dimension $L$:** Not explicitly specified in sources, but implied by the network architecture [S1].
*   **Anisotropy $g$:** $g > 0$ results in a strong forward lobe of scattering [S1].

**Algorithm Steps:**

1.  **Pre-processing:**
    *   Discretize the object's bounding volume into a 3D voxel grid [S1].
    *   Compute the conservative shortest Chebyshev distance to the surface for each voxel to create the SDF [S1].

2.  **Rendering Loop (Per Ray):**
    *   **Step 1: Sphere Radius Calculation.** At the current ray position $x$, query the SDF to compute the radius $r$ of the largest sphere centered at $x$ that does not intersect the geometry [S1].
    *   **Step 2: CVAE Inference.** Construct the condition vector $c = [\sigma_t, g, \varphi]$ [S1].
        *   **CVAE 1 (Absorption/Events):** Sample $N$ (number of scattering events) and $A$ (absorption indicator) [S1]. This determines if the ray is absorbed [S1].
        *   **CVAE 2 (Exit State):** Conditioned on $N$, sample the exit position $x$ on the sphere shell and the outgoing direction $\omega$ [S1].
        *   **CVAE 3 (In-scattering):** Generate a representative sample of photon position and direction along the path to approximate direct illumination contribution [S1].
        *   *Inference Detail:* Draw latent vector $z \sim \mathcal{N}(0, I)$ and pass through the Decoder with condition $c$ to generate samples [S1].
    *   **Step 3: Path Update.** If $A=1$ (absorbed), terminate the path [S1]. If $A=0$, update the ray position to $x$ and direction to $\omega$ [S1]. Proceed using delta tracking until the next collision event is determined [S1].
    *   **Step 4: Recursion.** Repeat Steps 2-3 until the path leaves the volume [S1].

        z = random_normal_vector()

        n_scatterings, is_absorbed = cvae_1_infer(z, c)

        if is_absorbed:

            radiance += throughput * in_scatter_contrib
            break

        # CVAE 2: Predict exit position and direction conditioned on N
        exit_pos, exit_dir = cvae_2_infer(z, c)

        # CVAE 3: Generate representative sample for in-scattering approximation
        in_scatter_sample = cvae_3_infer(z, c)

        # Update throughput with transmittance
        transmittance = math.exp(-optical_properties['sigma_t'] * radius)
        throughput *= transmittance

        # Add in-scattering contribution
        radiance += throughput * in_scatter_sample

        # Step 3: Move ray
        current_pos = exit_pos
        current_dir = exit_dir

        # Step 4: Check if ray left the volume
        if query_sdf(sdf_grid, current_pos) < 0:
            break

        # Russian Roulette for path termination
        if throughput < 0.01:
            p = max(throughput, 0.01)
            if random.random() > p:
                break
            throughput /= p

    return radiance

## Operating characteristics
*   **Time Complexity:** Significantly faster than standard Monte Carlo path tracing for dense volumes because it bypasses multiple scattering events in a single step [S1]. Performance gains are demonstrated for various scenarios [S1].
*   **Memory Complexity:** Low memory footprint due to shallow networks (up to 3 layers, 16 nodes) [S1]. Requires storage for the 3D SDF voxel grid [S1].
*   **Hardware:** Implemented in GPU shaders using short programs and matrix multiplication instructions [S1]. Implemented using NVIDIA’s RTX ray tracing interface through the DirectX Raytracing API (DXR) for efficient tracing against polygonal boundary surfaces [S1].
*   **Strengths:** Efficient for translucent materials like wax or skin; handles anisotropic scattering; avoids explicit encoding of local surface geometry; generalizes spatio-directional separability [S1].
*   **Limitations:** Assumes homogeneous volume within the sphere; requires offline training of CVAEs; approximation error introduced by data-driven simulation [S1].
*   **When to use:** When rendering translucent solids with multiple scattering events where performance is critical and volumes are homogeneous [S1].
*   **When not to use:** For heterogeneous volumes where density varies significantly within the sphere, or when exact analytical solutions are required without approximation error [G].

## Background
*   **Origin:** Proposed by L. Leonard, K. Höhlein, and R. Westermann [S1].
*   **Paper:** "Learning Multiple‐Scattering Solutions for Sphere‐Tracing of Volumetric Subsurface Effects" [S1].
*   **History:** Builds on the idea of "bypassing a potentially lengthy internal scattering process" [S1]. Combines shell tracing with network-based learning of long-distance light transport [S1].
*   **Usage:** Used for realistic rendering of translucent solid materials such as wax or skin [S1].
