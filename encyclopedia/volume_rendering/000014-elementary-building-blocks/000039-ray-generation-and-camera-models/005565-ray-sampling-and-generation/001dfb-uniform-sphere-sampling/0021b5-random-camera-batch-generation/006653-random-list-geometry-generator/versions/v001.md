# Random List Geometry Generator
## Overview
Generates a batch of $k$ random rays for a $D$-dimensional scanning volume, where origins are placed on the volume boundary and directions are adjusted to point inward. It differs from [Random Camera Batch Generation](2595-random-camera-batch-generation.md) by constraining ray origins to the volume boundary rather than sampling camera positions on a sphere, ensuring all rays intersect the interior.
## How it works
**Inputs:**
- $k$: Number of rays to generate.
- $D$: Dimensionality of the volume (typically 3).
- $v[0]$: The side length of the cubic volume, assumed to be $[0, v[0]]^D$.
- `precision`: Standard deviation for the Gaussian distribution (default 100.0) [S1, unofficial].

**Outputs:**
- A `geometry::list` object containing $k$ ray definitions, with dimensions $\{k, 1\}$ [S1, unofficial].

**Data Structures:**
- `origin`: Vector of size $D$, representing the ray origin coordinates.
- `direction`: Normalized vector of size $D$, representing the ray direction.
- `source`: Vector of size $D$, calculated as `origin - direction`.
- `detector`: Vector of size $D$, calculated as `source + direction * sqrt(D) * 2.0 * direction` [S1, unofficial]. Note: The source code multiplies `direction` by `direction` again, which is likely a logical error, but is implemented as written [S1, unofficial].

**Steps:**
1. Initialize random number engines: `std::random_device r` and `std::default_random_engine e(r())` [S1, unofficial].
2. For each of the $k$ rays:
    a. **Generate Origin:**
        i. Choose a random dimension $d \in [0, D-1]$ using `rand_int % D` [S1, unofficial].
        ii. Choose a plane $p \in \{0, 1\}$ using `rand_int % 2` [S1, unofficial].
        iii. Set `origin[d]` to $0.0$ if $p=0$, or $v[0]$ if $p=1$ [S1, unofficial].
        iv. Set all other components `origin[i]` ($i \neq d$) to a random value in $[0.5, v[0]-0.5]$ [S1, unofficial].
    b. **Generate Direction:**
        i. Generate $D$ Gaussian random variables with mean 0 and standard deviation `precision` [S1, unofficial].
        ii. Normalize the resulting vector to unit length [S1, unofficial].
        iii. Check if the direction points outward: if `direction[d]` has the opposite sign of the chosen plane (i.e., if $p=0$ and `direction[d] < 0`, or if $p=1$ and `direction[d] > 0`), flip the sign of `direction[d]` to ensure it points inward [S1, unofficial].
    c. **Construct Ray:**
        i. `source = origin - direction` [S1, unofficial].
        ii. `detector = source + direction * sqrt(D) * 2.0 * direction` [S1, unofficial].
3. Create a `geometry::list` object with the generated lines and set its dimensions to $\{k, 1\}$ [S1, unofficial].

**Pseudocode:**
```python
import random
import math

def generate_random_list_geometry(k, D, v0, precision=100.0):
    rays = []
    for _ in range(k):
        # 1. Generate Origin
        d = random.randint(0, D - 1)
        plane = random.randint(0, 1)
        
        origin = [0.0] * D
        origin[d] = 0.0 if plane == 0 else v0
        
        for i in range(D):
            if i != d:
                origin[i] = random.uniform(0.5, v0 - 0.5)
        
        # 2. Generate Direction
        # Generate D Gaussian random variables
        direction = [random.gauss(0, precision) for _ in range(D)]
        
        # Normalize
        norm = math.sqrt(sum(x * x for x in direction))
        if norm == 0:
            direction = [0.0] * D # Guard against zero vector
        else:
            direction = [x / norm for x in direction]
        
        # Ensure inward pointing
        # If plane is 0 (origin at 0), direction[d] should be >= 0
        # If plane is 1 (origin at v0), direction[d] should be <= 0
        if (plane == 0 and direction[d] < 0) or (plane == 1 and direction[d] > 0):
            direction[d] = -direction[d]
        
        # 3. Construct Ray
        source = [origin[i] - direction[i] for i in range(D)]
        
        # Note: Source code has logical error: direction * direction
        # Copied as is per source [S1, unofficial]
        scale = math.sqrt(D) * 2.0
        detector = [source[i] + direction[i] * scale * direction[i] for i in range(D)]
        
        rays.append({'source': source, 'detector': detector})
    
    return rays
```

**Edge Cases and Pitfalls:**
- The `detector` calculation contains a logical error in the source code (`direction * direction` instead of a scalar length) [S1, unofficial].
- If the Gaussian vector is zero (extremely unlikely), normalization fails [G].
- The volume is assumed to be a cube $[0, v[0]]^D$ [S1, unofficial].
- The random range for non-fixed dimensions is $[0.5, v[0]-0.5]$, which may exclude boundary regions if $v[0]$ is small [S1, unofficial].
