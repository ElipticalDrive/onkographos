# Fixed-size initialization from RGB-D backprojection

Also called: Explicit Geometry Recovery, RGB-D backprojection initialization, RGBD Backprojection

## Overview
This method generates a fixed-size, colored 3D point cloud initialization for volume rendering primitives by backprojecting RGB-D data [S1, unofficial]. It differs from its parent [Depth to 3D Points Conversion](7929-depth-to-3d-points-conversion.md) by applying explicit downsampling factors and stride ratios to control point density [S1, unofficial], and from its sibling [Point Cloud Generation and Refinement](8042-point-cloud-generation-and-refinement.md) by relying on direct geometric backprojection rather than implicit field refinement [S2].

## How it works
**Inputs:** Training RGB-D images, camera intrinsics (focal lengths, principal point), camera extrinsics (rotation, translation), downsampling factor $ds$, and stride ratio [S1, unofficial].
**Outputs:** A colored point cloud with a fixed number of primitives (e.g., $\sim 1.1$ billion, $\sim 102$ million, or $\sim 25$ million) [S1, unofficial].
**Data Structures:** A point cloud storing 3D coordinates and RGB colors per primitive, and 2D depth maps aligned with input images [G].
**Steps:**
1. Downsample input RGB-D images by factor $ds$ to reduce point density [S1, unofficial].
2. Backproject valid depth points into 3D space using camera intrinsics and extrinsics to form a colored point cloud [S1, unofficial].
3. Uniformly subsample the valid backprojected points using the stride ratio to regulate point count [S1, unofficial].
4. Derive smaller initializations (e.g., 102M or 25M points) by uniformly downsampling the largest generated cloud (e.g., 1.1B points), ensuring all scales share the same underlying geometry distribution [S1, unofficial].
**Parameters:** $ds$: Image downsampling factor applied during projection to reduce point density [S1, unofficial]. Typical value: Not given in the sources. [G] Stride ratio: Uniform subsampling stride applied to valid depth points to regulate point count [S1, unofficial]. Typical value: Not given in the sources. [G]
**Pseudocode:**
```python
def downsample_image(image, factor):
    return image[::factor, ::factor]

def fixed_size_initialization(rgb_d_images, intrinsics, extrinsics, ds, stride_ratio):
    all_points = []
    all_colors = []
    fx = intrinsics[0][0]
    fy = intrinsics[1][1]
    cx = intrinsics[0][2]
    cy = intrinsics[1][2]
    for rgb_img, depth_img, pose in rgb_d_images:
        rgb_down = downsample_image(rgb_img, ds)
        depth_down = downsample_image(depth_img, ds)
        h, w = len(rgb_down), len(rgb_down[0])
        for y in range(h):
            for x in range(w):
                z = depth_down[y][x]
                if z > 0:
                    px = (x - cx) * z / fx
                    py = (y - cy) * z / fy
                    pz = z
                    R = [row[:3] for row in pose[:3]]
                    t = [row[3] for row in pose[:3]]
                    wx = R[0][0]*px + R[0][1]*py + R[0][2]*pz + t[0]
                    wy = R[1][0]*px + R[1][1]*py + R[1][2]*pz + t[1]
                    wz = R[2][0]*px + R[2][1]*py + R[2][2]*pz + t[2]
                    all_points.append((wx, wy, wz))
                    all_colors.append(rgb_down[y][x])
    points = all_points[::stride_ratio]
    colors = all_colors[::stride_ratio]
    return points, colors

def derive_smaller_scale(points, colors, target_count):
    step = len(points) // target_count
    return points[::step][:target_count], colors[::step][:target_count]
```

## Background
This method originates from the TideGS paper, which trains over one billion 3D Gaussian Splatting primitives using out-of-core optimization on the MatrixCity BigCity/Aerial training split (51,623 images) [S1, unofficial]. It is also applied in neural rendering for stereo 3D reconstruction of deformable tissues in robotic surgery, where optimized radiance fields are rendered to RGB-D maps, smoothed via bilateral filtering, and backprojected into point clouds based on calibrated endoscope intrinsics [S2].
