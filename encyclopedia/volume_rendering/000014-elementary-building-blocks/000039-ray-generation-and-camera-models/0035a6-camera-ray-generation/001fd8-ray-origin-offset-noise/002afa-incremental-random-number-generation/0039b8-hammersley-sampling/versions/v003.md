# Hammersley Sampling
Also called: Hammersley Sequence
## Overview
Hammersley Sampling generates 2D low-discrepancy samples by combining a linear sequence for one coordinate with a radical inverse in base 2 for the other [S1, unofficial]. It differs from its parent [Incremental Random Number Generation](4898-incremental-random-number-generation.md) by providing structured 2D stratification rather than a 1D stream, and from [Rotated Halton Sampling](8922-rotated-halton-sampling.md) by using base 2 specifically for the second dimension, which simplifies implementation at the cost of potential correlation in higher dimensions [S1, unofficial].
## How it works
**Inputs:**
- $N$: Total number of samples, required to be a perfect square $N = A_{depth}^2$ [S1, unofficial].
- Base offset: $(x_0, y_0)$, the base position for the sample grid [S1, unofficial].

**Outputs:**
- A set of $N$ 2D points $(x_k, y_k)$ distributed over the unit square relative to the base offset [S1, unofficial].

**Data Structures:**
- No persistent state is required beyond the index $k$ [G]. The method is stateless per sample, though often iterated sequentially [G].

**Steps:**
1. Compute $N = A_{depth}^2$ [S1, unofficial].
2. Loop $ax$ from $0$ to $A_{depth}-1$ and $ay$ from $0$ to $A_{depth}-1$ [S1, unofficial].
3. Compute linear index $k = ax \times A_{depth} + ay$ [S1, unofficial].
4. Compute first coordinate $x_k = k / N$ [S1, unofficial].
5. Compute second coordinate $y_k = \phi_2(k)$, the radical inverse in base 2 [S1, unofficial].
6. Final sample position is $(x_0 + x_k, y_0 + y_k)$ [S1, unofficial].

**Formulas:**
$$ x = \frac{k}{N}, \quad y = \phi_2(k) $$
where $\phi_2$ is the radical inverse in base 2 [S1, unofficial]. To compute $\phi_2(k)$, write $k$ in binary as $k = \sum_{i=0}^{m} b_i 2^i$, where $b_i \in \{0, 1\}$, then reverse the bits after the binary point: $\phi_2(k) = \sum_{i=0}^{m} b_i 2^{-(i+1)}$ [G]. This is equivalent to bit-reversing the integer $k$ and dividing by $2^m$ (where $2^m$ is the smallest power of 2 greater than $k$) [G].

**Pseudocode:**
```python
def radical_inverse_base2(k: int) -> float:
    v = 0.0
    denom = 2.0
    n = k
    while n > 0:
        v += (n & 1) / denom
        n >>= 1
        denom *= 2.0
    return v

def generate_hammersley_samples(A_depth: int, x_offset: float, y_offset: float) -> list[tuple[float, float]]:
    samples = []
    N = A_depth * A_depth
    for ax in range(A_depth):
        for ay in range(A_depth):
            k = ax * A_depth + ay
            x = k / N
            y = radical_inverse_base2(k)
            samples.append((x_offset + x, y_offset + y))
    return samples
```

**Parameters:**
- $N$: Must be a perfect square to ensure uniform grid coverage in the linear dimension [S1, unofficial].
- Base 2: Fixed for the second dimension [S1, unofficial].

**Edge Cases:**
- Precision: Floating-point errors in bit reversal can occur for very large $k$ if not handled with integer arithmetic before conversion to float [G].

## Subtopics          

### [Rotated Halton Sampling](8922-rotated-halton-sampling.md)
A stratified sampling technique that generates low-discrepancy Halton sequences for multiple dimensions while avoiding sequence correlation by rotating the sequence per stream and dimension. It falls back to white noise for high dimensions. It builds on Hammersley Sampling by generalizing the radical inverse concept to arbitrary dimensions and introducing a rotation hash to decorrelate streams.
