# Camera Intrinsic Matrix Construction
Also called: Camera Intrinsic Extraction for Open3D, Intrinsic Matrix Construction, K matrix construction, camera intrinsic matrix
## Overview
Constructs the 3x3 camera intrinsic matrix $K$ from focal length and image dimensions, serving as the bridge between pixel coordinates and normalized device coordinates (NDC) for ray generation. It differs from [Pinhole Camera Ray Generation](5058-pinhole-camera-ray-generation.md) by explicitly building the calibration matrix $K$ rather than assuming a canonical pinhole model with unit focal length and center at the image center.
## How it works
**Inputs:**
- `focal`: Focal length in pixels.
- `H`: Image height in pixels.
- `W`: Image width in pixels.

**Outputs:**
- `K`: A 3x3 numpy array (or equivalent tensor) of dtype `float32` representing the intrinsic matrix.

**Data Structures:**
- `K`: 3x3 matrix.
  - $K_{0,0}$: $f_x$ (focal length in x)
  - $K_{1,1}$: $f_y$ (focal length in y)
  - $K_{0,2}$: $c_x$ (principal point x)
  - $K_{1,2}$: $c_y$ (principal point y)
  - $K_{2,2}$: 1.0
  - All other entries: 0.0

**Steps:**
1. Initialize a 3x3 matrix $K$ with zeros.
2. Set $K_{0,0} = \text{focal}$.
3. Set $K_{1,1} = \text{focal}$.
4. Set $K_{0,2} = 0.5 \times W$.
5. Set $K_{1,2} = 0.5 \times H$.
6. Set $K_{2,2} = 1.0$.
7. Return $K$.

**Alternative Derivation (from NDC):**
Some implementations derive $K$ by converting from NDC to pixel coordinates.
1. Construct the NDC-to-pixel transformation matrix $T_{\text{ndc2pix}}$:
   $$
   T_{\text{ndc2pix}} = \begin{bmatrix}
   W/2 & 0 & 0 & (W-1)/2 \\
   0 & H/2 & 0 & (H-1)/2 \\
   0 & 0 & 0 & 1 \\
   0 & 0 & 0 & 1
   \end{bmatrix}
   $$
2. If a projection matrix $P$ is available, compute $K$ as the top-left 3x3 submatrix of $P \times T_{\text{ndc2pix}}$, transposed:
   $$
   K = (P \times T_{\text{ndc2pix}})[0:3, 0:3]^T
   $$
   [S2, unofficial]

**Pseudocode:**
```python
import numpy as np

def construct_intrinsic_matrix(focal: float, H: int, W: int) -> np.ndarray:
    """
    Construct the 3x3 camera intrinsic matrix K.
    
    Args:
        focal: Focal length in pixels.
        H: Image height.
        W: Image width.
        
    Returns:
        K: 3x3 numpy array, dtype float32.
    """
    K = np.zeros((3, 3), dtype=np.float32)
    K[0, 0] = focal
    K[1, 1] = focal
    K[0, 2] = 0.5 * W
    K[1, 2] = 0.5 * H
    K[2, 2] = 1.0
    return K
```

**Parameters:**
- `focal`: Focal length in pixels. [S1, unofficial]
- `H`: Image height. [S1, unofficial]
- `W`: Image width. [S1, unofficial]

**Edge Cases:**
- If `focal` is 0, the matrix is singular and ray directions become undefined.
- If `W` or `H` is 0, the principal point calculation fails.
- Precision: Use `float32` for consistency with typical GPU ray generation pipelines. [S1, unofficial]

## Operating characteristics
- **Time Complexity:** $O(1)$ constant time.
- **Memory Complexity:** $O(1)$ constant space (9 floats).
- **Strengths:** Simple, fast, and standard for NERF-like pipelines.
- **Limitations:** Assumes square pixels and zero skew. Does not account for lens distortion.
- **When to use:** When constructing rays from a known focal length and image size.
- **When not to use:** When lens distortion parameters are needed or when using non-square pixels.

## Background
This method is commonly used in neural radiance fields (NeRF) and 3D Gaussian Splatting pipelines to convert pixel coordinates into camera-space ray directions. The specific formulation with principal point at $(W/2, H/2)$ is standard for images centered at the origin in NDC space. [S1, unofficial]
