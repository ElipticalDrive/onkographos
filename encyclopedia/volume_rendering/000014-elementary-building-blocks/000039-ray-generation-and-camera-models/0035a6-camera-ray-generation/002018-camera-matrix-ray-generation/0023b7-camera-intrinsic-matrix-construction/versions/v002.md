# Camera Intrinsic Matrix Construction
Also called: Camera Intrinsic Extraction for Open3D, Intrinsic Matrix Construction, K matrix construction, camera intrinsic matrix
## Overview
Builds a 3x3 camera intrinsic matrix $K$ from focal length and image dimensions [S1, unofficial].
## How it works
**Inputs:**
- `focal`: Focal length in pixels [S1, unofficial].
- `H`: Image height [S1, unofficial].
- `W`: Image width [S1, unofficial].

**Outputs:**
- `K`: A 3x3 matrix of dtype `float32` representing the intrinsic matrix [S1, unofficial].

**Data Structures:**
- `K`: 3x3 matrix.
  - $K_{0,0}$: $f_x$ (focal length in x)
  - $K_{1,1}$: $f_y$ (focal length in y)
  - $K_{0,2}$: $c_x$ (principal point x)
  - $K_{1,2}$: $c_y$ (principal point y)
  - $K_{2,2}$: 1.0
  - All other entries: 0.0

**Steps:**
1. Initialize a 3x3 matrix $K$ with zeros.
2. Set $K_{0,0} = \text{focal}$.
3. Set $K_{1,1} = \text{focal}$.
4. Set $K_{0,2} = 0.5 \times W$.
5. Set $K_{1,2} = 0.5 \times H$.
6. Set $K_{2,2} = 1.0$.
7. Return $K$ [S1, unofficial].

**Alternative Derivation (from NDC):**
Construct the NDC-to-pixel transformation matrix $T_{\text{ndc2pix}}$ using image width $W$ and height $H$:
$$
T_{\text{ndc2pix}} = \begin{bmatrix}
W/2 & 0 & 0 & (W-1)/2 \\
0 & H/2 & 0 & (H-1)/2 \\
0 & 0 & 0 & 1
\end{bmatrix}
$$
If a projection matrix $P$ is available, compute $K$ as the top-left 3x3 submatrix of $P \times T_{\text{ndc2pix}}$, transposed:
$$
K = (P \times T_{\text{ndc2pix}})[0:3, 0:3]^T
$$
where $P$ is a 4x4 projection matrix [S2, unofficial].

**Pseudocode:**
```python
import numpy as np

def construct_intrinsic_matrix(focal: float, H: int, W: int) -> np.ndarray:
    """
    Construct the 3x3 camera intrinsic matrix K.
    
    Args:
        focal: Focal length in pixels.
        H: Image height.
        W: Image width.
        
    Returns:
        K: 3x3 numpy array, dtype float32.
    """
    K = np.zeros((3, 3), dtype=np.float32)
    K[0, 0] = focal
    K[1, 1] = focal
    K[0, 2] = 0.5 * W
    K[1, 2] = 0.5 * H
    K[2, 2] = 1.0
    return K
```

**Parameters:**
- `focal`: Focal length in pixels [S1, unofficial].
- `H`: Image height [S1, unofficial].
- `W`: Image width [S1, unofficial].
