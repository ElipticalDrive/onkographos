# Sampling-rate-based lens

Also called: Free-form Lens Optics, Sampling-rate lens

## Overview
The sampling-rate-based lens modifies the spatial density of rays cast into a volume to achieve focus+context magnification without altering ray directions [S2]. Unlike the parent [Magnifier](6754-magnifier.md), which changes ray directions to pass through a virtual focal point, this method keeps rays parallel but varies their start positions on the image plane to create dense sampling in the center and coarse sampling at the boundary [S2]. It differs from the sibling [Feature-based lens](7436-feature-based-lens.md) by relying on a user-defined or arbitrary sampling function rather than feature detection to determine ray distribution [S2].

## How it works
**Inputs:**
- A volume dataset.
- A sampling rate function $sr(r)$, where $r$ is the distance from the lens center. The function defines the instantaneous sampling rate (reciprocal of local sample distance) [S1, book].
- Lens radius $l_r$ [S2].
- Normal sampling rate $sr_{normal}$ (implied as the baseline where $sr(r)$ returns to normal) [S2].

**Outputs:**
- Rendered image with non-uniform magnification.

**Data Structures:**
- **Sampling Rate Function:** Defined as a curve where the vertical axis is $sr$ and the horizontal axis is distance from the lens center [S1, book].
- **Coefficient $C$:** A precomputed scalar satisfying the integral equation to ensure the total number of rays is conserved (magnification balanced by minification) [S2].

**Steps:**

1.  **Define Sampling Distance Function:**
    Calculate the sampling distance function $sd(s)$ as the reciprocal of the sampling rate:
    $$ sd(s) = \frac{1}{sr(s)} $$
    where $s$ is the distance from the lens center [S2].

2.  **Compute Coefficient $C$:**
    Precompute $C$ such that the integral of the scaled sampling distance over the lens radius equals the lens radius. This ensures the transition region plus the magnification region equals the lens region [S2]. The equation is:
    $$ \int_{0}^{l_r} C \cdot sd(s) \, ds = l_r $$
    Solve for $C$ [S2].

3.  **Calculate Ray Start Points:**
    For each ray $j$, determine its real start point distance from the lens center, $distance(j)$, using the discrete sum of the scaled sampling distances. This replaces the original pixel position [S2]:
    $$ distance(j) = \sum_{i=0}^{steps} C \cdot sd(i) $$
    where $steps$ corresponds to the discretization of the sampling function [S2]. The start point is not the original pixel but depends on this calculated distance and the sampling rate [S2].

4.  **Ray Casting:**
    Cast rays from the computed start points. Ray directions are never changed; they remain orthogonal/parallel to the image plane [S2].

5.  **Rendering Passes (GPU Implementation):**
    Use four fragment program passes [S2]:
    -   **Pass 1* (RayStartPoints):** Computes the ray start points using the method above.
    -   **Pass 2 (RayTfrontback):** Computes intersections with the volume bounding box.
    -   **Pass 3 (RayCasting):** Casts the ray and composites color.
    -   **Pass 4 (Rendering):** Outputs to the frame buffer [S2].

**Parameters:**
-   $l_r$: Radius of the lens [S2].
-   $sr$: Sampling rate, inversely proportional to the distance between sampling rays [S2].
-   $C$: Integral coefficient [S2].

**Edge Cases and Pitfalls:**
-   **Integral Balance:** The total curve integrals of the sampling rate function above and below the x-axis (relative to normal sampling) must approximately match to balance magnification and minification [S1, book].
-   **Transition Region:** The distance from the cutting point (where sampling rate returns to normal) to the lens center must equal $l_r$ [S2].
-   **Depth Independence:** The magnification factor remains constant along any ray for different depth values [S1, book].

## Operating characteristics
-   **Time Complexity:** Linear with respect to the number of rays and volume samples, similar to standard ray casting, but with additional overhead for computing start points [S2].
-   **Memory Complexity:** Requires storage for the volume data and the sampling rate function [S2].
-   **Performance:** On a GPU, the method uses four fragment program passes. Performance varies by dataset size. For example, on a 256x256x256 dataset (aneurism), it renders in 186 ms (5.4 fps) compared to 158 ms (6.3 fps) for simple ray casting [S2].
-   **Strengths:** Allows arbitrary lens functions via free-form drawing; provides non-uniform magnification (highest at center, decreasing towards boundary) [S1, book][S2].
-   **Limitations:** Magnification is depth-independent (constant along any ray) [S1, book]. Requires careful balancing of the sampling rate function to avoid visual artifacts from mismatched integrals [S1, book].

## Background
The sampling-rate-based lens is part of the "Magic Volume Lens" framework, introduced by Mueller et al. [S2]. It is described in the book "Illustrative Focus+Context Approaches in Interactive Volume Visualization" [S1, book]. The method was developed to provide more flexible focus+context visualization compared to standard lenses, allowing users to define arbitrary magnification profiles [S1, book][S2].
