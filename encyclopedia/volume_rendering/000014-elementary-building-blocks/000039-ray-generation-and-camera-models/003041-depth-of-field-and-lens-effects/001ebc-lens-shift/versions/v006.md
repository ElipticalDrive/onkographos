# Lens Shift

Also called: Aperture Transformation, Lens Shift Sampling

## Overview
Lens shift is a path construction technique that transfers a sampled interaction from a base camera's lens aperture to a target camera's lens aperture by reusing random numbers [S1]. Unlike [Thin Lens Depth of Field](4922-thin-lens-depth-of-field.md) which generates defocus blur, or [Magnifier](6754-magnifier.md) which scales the view, lens shift specifically handles the geometric correspondence between two distinct camera apertures [S1].

## How it works
**Inputs and Outputs:**
*   Input: base lens interaction point $x_{\text{lens}}$ (a 2D point on the base aperture), base aperture radius $r$, and target aperture radius $r'$ [S1].
*   Output: transformed lens interaction point $x'_{\text{lens}}$ and the Jacobian determinant [S1].

**Data Structures:**
*   $x_{\text{lens}}$ is a 2D vector representing the offset from the aperture center [S1].
*   $r$ and $r'$ are scalar floating-point values for the base and target radii [S1].

**Steps:**
1.  Retrieve the base lens interaction point $x_{\text{lens}}$ sampled from the base camera's aperture distribution [S1].
2.  Compute the scaling factor as the ratio of the target aperture radius to the base aperture radius [S1].
3.  Apply the scaling factor to $x_{\text{lens}}$ to obtain the target lens point $x'_{\text{lens}}$ [S1].
4.  Compute the Jacobian determinant for the importance sampling weight adjustment [S1].

**Formulas:**
The transformation maps the point $x_{\text{lens}}$ on the base disk to $x'_{\text{lens}}$ on the target disk:
$$x'_{\text{lens}} = \frac{r'}{r} \cdot x_{\text{lens}}$$
The Jacobian determinant of this transformation is:
$$\left| S'_{i \rightarrow j}(x_{\text{lens}}) \right| = \frac{r^2}{r'^2}$$
Where:
*   $r$ is the radius of the base camera lens aperture [S1].
*   $r'$ is the radius of the target camera lens aperture [S1].
*   The multiplication $\frac{r'}{r} \cdot x_{\text{lens}}$ is a scalar-vector multiplication [G].

**Parameters:**
Not given in the sources.

**Pseudocode:**
```python
def lens_shift(x_lens, r_base, r_target):
    """
    Shifts a lens interaction point from a base aperture to a target aperture.
    
    Args:
        x_lens: 2D vector (u, v) representing the base lens interaction point.
        r_base: Float, radius of the base aperture.
        r_target: Float, radius of the target aperture.
        
    Returns:
        x_prime: 2D vector, the transformed lens interaction point.
        jacobian: Float, the determinant of the transformation Jacobian.
    """
    scale = r_target / r_base
    x_prime = scale * x_lens
    jacobian = (r_base / r_target) ** 2
    return x_prime, jacobian
```

**Edge Cases and Pitfalls:**
*   **Zero Radius:** If $r$ or $r'$ is zero, the division is undefined; aperture radii must be strictly positive [G].
*   **Precision:** When $r$ and $r'$ differ significantly in magnitude, floating-point precision errors may accumulate in the scaling factor [G].
*   **Aperture Shape:** The formula assumes disk-shaped apertures; non-circular apertures require different handling [S1].

## Subtopics

### Shutter Time Shift
Shutter time shift reuses the base shutter time sampled within the camera shutter interval for the target camera [S1]. The transformation is defined as $x'_{\text{time}} = x_{\text{time}}$ [S1]. The Jacobian of this shift is exactly 1, i.e., $\left| S'_{i \rightarrow j}(x_{\text{time}}) \right| = 1$ [S1]. This approach avoids the computational cost of re-evaluating occlusions and shading for moving geometry, which would be required if the time were resampled [S1].

## Background
The technique is used within volumetric multi-view rendering to construct paths at fixed time, avoiding the cost of re-evaluating occlusions and shading on moving geometry [S1]. It reuses random numbers that sampled the base lens interaction, building upon earlier work in path tracing and lens sampling [KSKAC02, HGP*19], and was similarly applied by Schwarzhaupt [Sch19] and Fraboni et al. [FINB19] [S1].
