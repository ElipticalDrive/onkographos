# Binocular Depth Estimation (Stereo Matching)
Also called: Disparity computation, Stereo depth
## Overview
Binocular depth estimation estimates scene depth from a pair of rectified left and right images by computing a disparity map, which is inversely proportional to depth. It solves the problem of recovering 3D structure from 2D imagery using geometric constraints between two viewpoints. Unlike monocular depth estimation, which relies on learned priors from single images, this method leverages explicit pairwise multi-view consistency, making it more effective for scenes with weak texture or repetitive patterns where local photometric costs are ambiguous [S1]. It builds on [Dense Depth Estimation via Plane Sweep](10850-dense-depth-estimation-via-plane-sweep.md) by providing the foundational cost-volume-based approach that plane sweep generalizes to multiple views.
## How it works
The method follows a four-stage pipeline: feature extraction, cost volume construction, cost aggregation, and disparity computation [S1].

**Inputs and Outputs:**
- Input: Left image $I_l$ and right image $I_r$, both rectified and of identical resolution.
- Output: Disparity map $d$, where each pixel value represents the horizontal shift between corresponding points in $I_l$ and $I_r$.

**Data Structures:**
- Feature maps: Dense tensors output by the feature extraction network, typically sharing spatial dimensions with the input images but with a higher channel depth.
- Cost volume: A 4D tensor with dimensions (Height, Width, Disparity Range, Feature Channels). Each entry $(u, v, d)$ stores the similarity cost between the left feature at $(u, v)$ and the right feature at $(u-d, v)$.

**Steps:**
1. **Feature Extraction**: Encode $I_l$ and $I_r$ into feature representations using a shared-weight convolutional neural network $f_\theta$. This network extracts local descriptors that are robust to illumination changes.
   $$ F_l = f_\theta(I_l), \quad F_r = f_\theta(I_r) $$
2. **Cost Volume Construction**: Compute the similarity between features from the left and right views. For each pixel $(u, v)$ in the left image and each candidate disparity $d$, match $F_l(u, v)$ with $F_r(u-d, v)$. The cost is typically the absolute difference or dot product of the feature vectors.
   $$ C(u, v, d) = \partial(F_l(u, v), F_r(u-d, v)) $$
   where $\partial$ denotes the cost construction operation.
3. **Cost Aggregation**: Smooth the cost volume to resolve ambiguities and enforce consistency. This step aggregates costs from neighboring pixels and disparities to suppress noise and handle occlusions. The aggregated cost volume is denoted as $\delta(C)$.
4. **Disparity Computation**: Extract the final disparity map from the aggregated cost volume. This is typically done by selecting the disparity $d$ that minimizes the cost for each pixel, often followed by a differentiable argmin operation or soft-argmin for gradient-based training.
   $$ d(u, v) = \eta(\delta(C)(u, v)) $$

**Formula:**
The entire process is represented as:
$$ d = \eta(\delta(\partial(f_\theta(I_l), f_\theta(I_r)))) $$
where:
- $I_l, I_r$: Input left and right images.
- $f_\theta$: Feature extraction network with parameters $\theta$.
- $\partial$: Cost volume construction operator.
- $\delta$: Cost aggregation operator.
- $\eta$: Disparity computation operator.

**Parameters:**
- Disparity range: The maximum expected disparity, determined by the baseline and minimum depth.
- Network architecture: Representative methods include CFNet [47] and PCWNet [48] [S1].

**Edge Cases and Pitfalls:**
- Occlusions: Pixels visible in one image but not the other create invalid disparities. [G] Standard practice involves left-right consistency checks to identify and mask occluded regions.
- Repetitive textures: Ambiguities in cost volume minima can lead to incorrect disparity assignments. [S1]
- Precision: Sub-pixel accuracy is often required, necessitating interpolation in the disparity computation step.

## Operating characteristics
- **Time Complexity**: Dominated by the convolutional operations in feature extraction and cost aggregation. The cost volume construction is $O(H \cdot W \cdot D)$, where $H, W$ are image dimensions and $D$ is the disparity range.
- **Memory Complexity**: The cost volume requires significant memory, scaling linearly with the disparity range. [S1]
- **Strengths**: High accuracy in textured regions; robust to illumination changes when using learned features.
- **Limitations**: Computationally expensive due to large cost volumes; struggles with untextured regions without aggregation.
- **When to use**: When high-precision depth is needed from calibrated stereo pairs and computational resources allow for deep learning inference.
- **When not to use**: For real-time systems with strict memory constraints or uncalibrated cameras.
## Background
Originated from the fundamental principles of stereo vision, where depth is derived from triangulation of corresponding points. Modern deep learning approaches have replaced hand-crafted features with learned representations. The pipeline described is standard in current deep stereo matching methods [S1]. Representative networks like CFNet and PCWNet have been widely evaluated on datasets such as KITTI and Argoverse [S1].
