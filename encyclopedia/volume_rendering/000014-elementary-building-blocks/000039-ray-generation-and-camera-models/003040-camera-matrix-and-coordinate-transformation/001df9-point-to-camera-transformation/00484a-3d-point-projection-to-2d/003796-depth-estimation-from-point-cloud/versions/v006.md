# Depth Estimation from Point Cloud
Also called: Closest Point Depth Estimation

## Overview
This method generates a depth map for a novel camera viewpoint by projecting an existing 3D point cloud onto the 2D image plane and resolving occlusions [S1]. It solves the problem of converting sparse or implicit 3D geometry into an explicit per-pixel depth buffer, distinguishing itself from volumetric rendering by relying on discrete point proximity rather than ray-marching through a density field.

## How it works
**Inputs:**
- A 3D point cloud $P = \{p_1, p_2, \dots, p_N\}$, where each $p_i \in \mathbb{R}^3$ is a point in world coordinates.
- A target camera defined by its intrinsic matrix $K$ and extrinsic matrix $[R|t]$ (rotation and translation from world to camera coordinates).

**Outputs:**
- A depth image $D$ of resolution $W \times H$, where $D(u,v)$ is the distance from the camera center to the closest surface point at pixel $(u,v)$.

**Data Structures:**
- A 2D array `depth_map` of size $H \times W$, initialized to zero or infinity.
- A list of projected points for each pixel to resolve conflicts.

**Steps:**
1. **Coordinate Transformation**: Transform each 3D point $p_i$ from world coordinates to camera coordinates $p'_i$:
   $$ p'_i = R p_i + t $$
   Let $p'_i = (X_i, Y_i, Z_i)$.

2. **Projection**: Project each transformed point $p'_i$ onto the image plane using the intrinsic matrix $K$. For a pinhole camera model:
   $$ u_i = \frac{f_x X_i}{Z_i} + c_x $$
   $$ v_i = \frac{f_y Y_i}{Z_i} + c_y $$
   where $f_x, f_y$ are focal lengths and $c_x, c_y$ are principal point coordinates.

3. **Validation**: Check if the projected pixel $(u_i, v_i)$ lies within the image boundaries $[0, W-1] \times [0, H-1]$ and if the depth $Z_i > 0$ (point is in front of the camera). Discard points failing these checks.

4. **Occlusion Resolution**: For each valid pixel $(u, v)$, collect all points $p_i$ that project to this pixel. Select the point $p_{closest}$ with the minimum depth value $Z_{min} = \min \{Z_i\}$.

5. **Depth Assignment**: Set the depth value for pixel $(u, v)$ to the depth of the closest point:
   $$ D(u, v) = Z_{min} $$

6. **Hole Handling**: Pixels with no projected points remain at their initial value (typically 0 or undefined), representing background or missing surface information [S1].

**Pseudocode:**
```python
def estimate_depth_from_point_cloud(point_cloud, camera_intrinsics, camera_extrinsics, image_width, image_height):
    """
    point_cloud: List of 3D points (N, 3) in world coordinates.
    camera_intrinsics: Matrix K (3, 3).
    camera_extrinsics: Matrix [R|t] (3, 4).
    image_width, image_height: Dimensions of the output depth map.
    """
    # Initialize depth map with zeros (indicating no data)
    depth_map = np.zeros((image_height, image_width))
    
    # Extract camera parameters
    R = camera_extrinsics[:, :3]
    t = camera_extrinsics[:, 3]
    K = camera_intrinsics
    
    # Transform points to camera coordinates
    # p_world is (N, 3), p_cam is (N, 3)
    p_cam = (R @ point_cloud.T).T + t
    
    # Project to 2D
    # X, Y, Z are (N,) arrays
    X = p_cam[:, 0]
    Y = p_cam[:, 1]
    Z = p_cam[:, 2]
    
    # Avoid division by zero
    valid_depth = Z > 1e-5
    
    # Calculate pixel coordinates
    u = (K[0, 0] * X / Z) + K[0, 2]
    v = (K[1, 1] * Y / Z) + K[1, 2]
    
    # Filter valid points: in front of camera and within image bounds
    valid_u = (u >= 0) & (u < image_width)
    valid_v = (v >= 0) & (v < image_height)
    valid_indices = np.where(valid_depth & valid_u & valid_v)[0]
    
    # Get valid coordinates
    u_valid = u[valid_indices]
    v_valid = v[valid_indices]
    z_valid = Z[valid_indices]
    
    # Round to integer pixel coordinates
    u_int = u_valid.astype(int)
    v_int = v_valid.astype(int)
    
    # Find closest point for each pixel
    # We need to keep only the minimum Z for each (u, v)
    # Create a mask or use a dictionary/array to store min depth
    min_depths = np.full((image_height, image_width), np.inf)
    
    # Iterate through valid points and update minimum depth
    for idx in range(len(valid_indices)):
        u_p = u_int[idx]
        v_p = v_int[idx]
        z_p = z_valid[idx]
        
        if z_p < min_depths[v_p, u_p]:
            min_depths[v_p, u_p] = z_p
            
    # Replace inf with 0 for background/holes
    min_depths[np.isinf(min_depths)] = 0
    
    return min_depths
```

**Parameters:**
- $N$: Number of points in the cloud. Typical values depend on the generation method (e.g., $N=8$ views used in source [S1] for generation, but $N$ points in cloud vary).
- $\alpha$: Weighting factor in related generation steps, not directly used in projection [S1].

**Edge Cases:**
- **Holes**: Pixels with no projected points result in zero depth. The source notes that these holes cannot be automatically distinguished from background areas without additional context [S1].
- **Precision**: Floating-point errors in projection may cause slight misalignments. Integer rounding of $(u,v)$ is required for array indexing.

## Subtopics

### [Triangulation for Closest Point](9933-triangulation-for-closest-point.md)
Computes 3D position by finding the closest intersection to multiple camera rays, using least-squares optimization and visibility masks. Choose when multi-view consistency is required.

### [Dense Depth Estimation via Plane Sweep](10850-dense-depth-estimation-via-plane-sweep.md)
Reconstructs dense depth by evaluating photo-consistency across depth planes. Choose for textureless regions or when explicit point clouds are unavailable.

## Operating characteristics
- **Time Complexity**: $O(N)$ for projection and $O(W \cdot H)$ for depth map initialization and hole filling. The bottleneck is typically the projection of $N$ points.
- **Memory Complexity**: $O(N)$ to store the point cloud and $O(W \cdot H)$ for the depth map.
- **Performance**: The source reports a PSNR of 31.44 dB on the Pavillon dataset using this method, compared to 30.27 dB for standard MVS [S1].
- **Strengths**: Simple, fast, and directly utilizes existing 3D points.
- **Limitations**: Produces sparse depth maps with holes if the point cloud is incomplete. Cannot infer depth in regions without 3D points.

## Background
This method is used in the test stage of neural radiance field improvements that incorporate point cloud generation [S1]. It serves as a bridge between implicit/explicit 3D representations and explicit 2D depth buffers for novel view synthesis.
