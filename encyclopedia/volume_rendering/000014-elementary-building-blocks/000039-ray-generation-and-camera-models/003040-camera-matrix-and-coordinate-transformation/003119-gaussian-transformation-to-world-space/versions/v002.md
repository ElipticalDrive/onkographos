# Gaussian Transformation to World Space

Also called: Camera-to-World Gaussian Transform, Gaussian Transformation to Camera Frame, World-space Gaussian Transformation

## Overview
This method transforms 3D Gaussian parameters predicted or stored in camera space into world space, enabling consistent rendering across multiple views or integration with world-space scene geometry [S1]. It operates directly on the Gaussian primitives rather than ray sampling coordinates, distinguishing it from [NDC Ray Transformation](905-ndc-ray-transformation.md), and handles full anisotropic covariance and spherical harmonics rotation rather than just point positions, distinguishing it from [Point to Camera Transformation](1660-point-to-camera-transformation.md) [G].

## How it works
**Inputs:**
*   Gaussian parameters in camera space:
    *   $\mu_{\text{cam}}$: Mean position, shape $(N, 3)$ [S1].
    *   $\Sigma_{\text{cam}}$: Covariance matrix, shape $(N, 3, 3)$ [S1].
    *   $\alpha_{\text{cam}}$: Opacity, shape $(N, 1)$ [S1].
    *   $\mathbf{s}_{\text{cam}}$: Scale parameters or spherical harmonics coefficients, shape $(N, C)$ [S1]. The source uses $\mathbf{s}$ to denote the parameters rotated by Wigner D-matrices [S1].
    *   $q_{\text{cam}}$: Rotation quaternion, shape $(N, 4)$, normalized [S2, unofficial].
*   Camera-to-World extrinsics matrix $\mathbf{T}$, shape $(4, 4)$, composed of rotation $\mathbf{R}$ (top-left $3 \times 3$) and translation $\mathbf{t}$ (top-right $3 \times 1$) [S1].

**Outputs:**
*   Gaussian parameters in world space: $\mu_{\text{world}}$, $\Sigma_{\text{world}}$, $\alpha_{\text{world}}$, $\mathbf{s}_{\text{world}}$, $q_{\text{world}}$ [S1][S2, unofficial].

**Data Structures:**
*   Parameters are stored in contiguous tensors or arrays [G].
*   $\mathbf{T}$ is a standard $4 \times 4$ affine transformation matrix [G].

**Steps:**
1.  **Transform Mean:** Apply the full $4 \times 4$ camera-to-world matrix $\mathbf{T}$ to the camera-space mean $\mu_{\text{cam}}$ [S1].
    $$ \mu_{\text{world}} = \mathbf{T}\mu_{\text{cam}} $$
2.  **Transform Covariance:** Compute the world-space covariance using only the $3 \times 3$ rotation component $\mathbf{R}$ of $\mathbf{T}$ [S1].
    $$ \Sigma_{\text{world}} = \mathbf{R}\Sigma_{\text{cam}}\mathbf{R}^T $$
3.  **Transform Opacity:** Opacity remains invariant under rigid body transformation [S1].
    $$ \alpha_{\text{world}} = \alpha_{\text{cam}} $$
4.  **Transform Rotation:** For anisotropic Gaussians, normalize the camera-space rotation quaternions $q_{\text{cam}}$ and compose them with the camera rotation quaternion $q_{\text{cam\_rot}}$ derived from $\mathbf{R}$ [S2, unofficial]. The world-space rotation is obtained by quaternion multiplication [S2, unofficial]:
    $$ q_{\text{world}} = q_{\text{cam\_rot}} \otimes q_{\text{cam}} $$
5.  **Transform Scale/SH:** Transform the parameters $\mathbf{s}_{\text{cam}}$ using a block-diagonal matrix $\mathbf{D}$ composed of Wigner D-matrices corresponding to the rotation $\mathbf{R}$ [S1].
    $$ \mathbf{s}_{\text{world}} = \mathbf{D}\mathbf{R}\mathbf{s}_{\text{cam}} $$
    The source explicitly states that $\mathbf{D}$ rotates the spherical harmonics coefficients, and the variable $\mathbf{s}$ in the formula refers to these coefficients [S1].

**Pseudocode:**
```python
import torch

def gaussian_transform_to_world(mu_cam, cov_cam, alpha_cam, s_cam, q_cam, T):
    """
    Transforms Gaussian parameters from camera space to world space.
    Args:
        mu_cam: Tensor (N, 3)
        cov_cam: Tensor (N, 3, 3)
        alpha_cam: Tensor (N, 1)
        s_cam: Tensor (N, C) representing SH coefficients or scales [S1]
        q_cam: Tensor (N, 4) normalized quaternions [S2, unofficial]
        T: Tensor (4, 4) camera-to-world matrix [S1]
    Returns:
        mu_world, cov_world, alpha_world, s_world, q_world
    """
    R = T[:3, :3]
    
    # 1. Transform Mean: mu_world = T * mu_cam [S1]
    mu_cam_homo = torch.cat([mu_cam, torch.ones(mu_cam.shape[0], 1, device=mu_cam.device)], dim=1)
    mu_world_homo = (T @ mu_cam_homo.T).T
    mu_world = mu_world_homo[:, :3]
    
    # 2. Transform Covariance: Sigma_world = R * Sigma_cam * R^T [S1]
    cov_world = R @ cov_cam @ R.transpose(-1, -2)
    
    # 3. Transform Opacity: alpha_world = alpha_cam [S1]
    alpha_world = alpha_cam
    
    # 4. Transform Rotation: q_world = q_cam_rot @ q_cam [S2, unofficial]
    q_cam_rot = matrix_to_quaternion(R)
    q_cam_norm = q_cam / torch.norm(q_cam, dim=1, keepdim=True)
    q_world = quaternion_multiply(q_cam_rot, q_cam_norm)
    
    # 5. Transform Scale/SH: s_world = D * R * s_cam [S1]
    # D is computed via e3nn library as per source [S1]
    # Apply Wigner D-matrix rotation to s_cam using e3nn [S1]
    s_world = s_cam 
    
    return mu_world, cov_world, alpha_world, s_world, q_world

def matrix_to_quaternion(R):
    """Convert 3x3 rotation matrix to quaternion (w, x, y, z) [G]."""
    tr = R.trace()
    if tr > 0:
        S = torch.sqrt(tr + 1.0) * 2
        w = 0.25 * S
        x = (R[2, 1] - R[1, 2]) / S
        y = (R[0, 2] - R[2, 0]) / S
        z = (R[1, 0] - R[0, 1]) / S
    elif (R[0, 0] > R[1, 1]) and (R[0, 0] > R[2, 2]):
        S = torch.sqrt(1.0 + R[0, 0] - R[1, 1] - R[2, 2]) * 2
        w = (R[2, 1] - R[1, 2]) / S
        x = 0.25 * S
        y = (R[0, 1] + R[1, 0]) / S
        z = (R[0, 2] + R[2, 0]) / S
    elif R[1, 1] > R[2, 2]:
        S = torch.sqrt(1.0 + R[1, 1] - R[0, 0] - R[2, 2]) * 2
        w = (R[0, 2] - R[2, 0]) / S
        x = (R[0, 1] + R[1, 0]) / S
        y = 0.25 * S
        z = (R[1, 2] + R[2, 1]) / S
    else:
        S = torch.sqrt(1.0 + R[2, 2] - R[0, 0] - R[1, 1]) * 2
        w = (R[1, 0] - R[0, 1]) / S
        x = (R[0, 2] + R[2, 0]) / S
        y = (R[1, 2] + R[2, 1]) / S
        z = 0.25 * S
    return torch.stack([w, x, y, z], dim=1)

def quaternion_multiply(q1, q2):
    """Multiply two quaternions q1 and q2 (w, x, y, z) [G]."""
    w1, x1, y1, z1 = q1.unbind(dim=1)
    w2, x2, y2, z2 = q2.unbind(dim=1)
    w = w1*w2 - x1*x2 - y1*y2 - z1*z2
    x = w1*x2 + x1*w2 + y1*z2 - z1*y2
    y = w1*y2 - x1*z2 + y1*w2 + z1*x2
    z = w1*z2 + x1*y2 - y1*x2 + z1*w2
    return torch.stack([w, x, y, z], dim=1)
```

**Parameters:**
*   $\mathbf{T}$: Camera-to-World matrix [S1].
*   `e3nn`: Library for computing Wigner D-matrices [S1].

**Edge Cases and Pitfalls:**
*   **Isotropic vs Anisotropic:** Check scale channel count to determine if rotation composition is needed for the orientation [S2, unofficial].
*   **Quaternion Normalization:** Quaternions must be normalized before multiplication to avoid drift [S2, unofficial].
*   **SH Degree:** The Wigner D-matrix size depends on the SH degree [S1].
*   **Precision:** Use double precision for matrix operations if high accuracy is required, especially for large scenes [G].

## Operating characteristics
*   **Time Complexity:** $O(N)$ for mean and covariance transformation, where $N$ is the number of Gaussians [G].
*   **Memory Complexity:** $O(N)$ to store the transformed parameters [G].
*   **Performance:** The transformation is computationally lightweight compared to rendering [G].
*   **Strengths:** Enables consistent rendering across multiple views by aligning Gaussians to a common world frame [G].
*   **Limitations:** Requires accurate camera extrinsics; errors in $\mathbf{T}$ lead to misaligned Gaussians [G].

## Background
This method is used in 3D Gaussian Splatting variants that predict Gaussian parameters in camera space, such as PixelSplat [S1]. It allows for the integration of these camera-space predictions into a global world coordinate system for consistent multi-view rendering and scene reconstruction [S1]. The use of Wigner D-matrices for SH rotation is standard in 3D graphics for handling directional data under rotation [S1].
