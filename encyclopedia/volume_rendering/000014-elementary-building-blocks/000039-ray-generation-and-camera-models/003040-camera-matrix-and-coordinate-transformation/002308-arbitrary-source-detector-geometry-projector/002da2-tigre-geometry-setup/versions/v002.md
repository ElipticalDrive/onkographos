# TIGRE Geometry Setup
Also called: TIGRE Geometry Configuration, TIGRE Scanner Mode Setup
## Overview
Configures a TIGRE geometry object from a configuration dictionary, setting detector, voxel, and offset parameters for cone or parallel beam modes [S1, unofficial]. It provides the geometry specification required by the arbitrary source-detector projector [S1, unofficial].
## How it works
**Inputs and Outputs:**
- Input: Configuration dictionary `cfg`.
- Output: Geometry object `geo` with populated fields.
**Data Structures:**
The `geo` object stores scanner parameters [S1, unofficial]:
- `geo.mode`: Scanner mode, either `"parallel"` or `"cone"` [S1, unofficial].
- `geo.DSD`: Source-to-detector distance [S1, unofficial].
- `geo.DSO`: Source-to-origin distance [S1, unofficial].
- `geo.nDetector`: Number of detector elements [S1, unofficial].
- `geo.sDetector`: Size of a single detector element [S1, unofficial].
- `geo.dDetector`: Total detector size [S1, unofficial].
- `geo.nVoxel`: Number of voxels [S1, unofficial].
- `geo.sVoxel`: Size of a single voxel [S1, unofficial].
- `geo.dVoxel`: Total voxel size [S1, unofficial].
- `geo.offset`: Offset for origin and detector [S1, unofficial].
- `geo.accuracy`: Accuracy setting for forward projection [S1, unofficial].
- `geo.filter`: Reconstruction filter type [S1, unofficial].
**Steps:**
1. Initialize `geo` based on `cfg["mode"]` ("parallel" or "cone") [S1, unofficial].
2. Set `geo.nVoxel` from `cfg` [S1, unofficial].
3. Set `geo.DSD` and `geo.DSO` [S1, unofficial].
4. Set `geo.nDetector`, `geo.sDetector`, and `geo.dDetector` [S1, unofficial].
5. Set `geo.nVoxel`, `geo.sVoxel`, and `geo.dVoxel` [S1, unofficial].
6. Set offsets for origin and detector [S1, unofficial].
7. Store `cfg["accuracy"]` and `cfg["filter"]` [S1, unofficial].
**Pseudocode:**
```python
def setup_tigre_geometry(cfg):
    geo = {}
    # 1. Initialize geometry based on mode
    geo["mode"] = cfg["mode"]
    # 2. Set nVoxel from config
    geo["nVoxel"] = cfg["nVoxel"]
    # 3. Set source-detector and source-origin distances
    geo["DSD"] = cfg["DSD"]
    geo["DSO"] = cfg["DSO"]
    # 4. Set detector parameters
    geo["nDetector"] = cfg["nDetector"]
    geo["sDetector"] = cfg["sDetector"]
    geo["dDetector"] = cfg["dDetector"]
    # 5. Set image/voxel parameters
    geo["nVoxel"] = cfg["nVoxel"]
    geo["sVoxel"] = cfg["sVoxel"]
    geo["dVoxel"] = cfg["dVoxel"]
    # 6. Set offsets for origin and detector
    geo["offset"] = cfg["offset"]
    # 7. Store additional configuration parameters
    geo["accuracy"] = cfg["accuracy"]
    geo["filter"] = cfg["filter"]
    return geo
```

### TIGRE DRR Generation
A technique to prepare 2D X-ray images from collected CT volumes to create paired datasets for training, overcoming the impracticality of collecting paired clinical data [S2]. It uses the TIGRE tomography toolbox to generate 50 X-ray images for each volume by covering 360° views [S2].

## Background
The method configures geometry parameters for the TIGRE tomography toolbox [S1, unofficial]. It is used in workflows that generate digital reconstruction radiography (DRR) from CT volumes for medical image reconstruction and neural radiance field training [S2].
