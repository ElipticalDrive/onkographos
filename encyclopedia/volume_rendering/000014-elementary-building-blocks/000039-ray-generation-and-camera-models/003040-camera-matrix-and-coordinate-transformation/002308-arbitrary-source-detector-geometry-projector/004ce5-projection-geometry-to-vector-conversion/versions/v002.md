# Projection Geometry to Vector Conversion


## Overview
This method converts a dictionary-based projection geometry specification into a flat 12-element vector array for each projection angle, supporting both cone and parallel3D beam geometries [S1, unofficial]. It distinguishes itself from higher-level setup utilities by directly producing the exact numerical arrays expected by the projection engine [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A dictionary `proj_geom` containing the geometry definition [S1, unofficial].
*   **Output:** A dictionary containing metadata and a numpy array `Vectors` of shape `(n_angles, 12)` [S1, unofficial].

**Data Structures**
The input dictionary `proj_geom` must contain the following keys:
*   `type`: String, either `'cone'` or `'parallel3d'` [S1, unofficial].
*   `ProjectionAngles`: Array of angles [S1, unofficial].
*   `DistanceOriginSource` ($D_{OS}$): Distance from origin to source [S1, unofficial].
*   `DistanceOriginDetector` ($D_{OD}$): Distance from origin to detector center [S1, unofficial].
*   `DetectorSpacingX` ($D_{DX}$): Physical spacing of detector pixels in the X direction [S1, unofficial].
*   `DetectorSpacingY` ($D_{DY}$): Physical spacing of detector pixels in the Y direction [S1, unofficial].
*   `DetectorRowCount`: Integer, number of detector rows [S1, unofficial].
*   `DetectorColCount`: Integer, number of detector columns [S1, unofficial].

The output dictionary contains:
*   `type`: String, copied from input [S1, unofficial].
*   `DetectorRowCount`: Integer, copied from input [S1, unofficial].
*   `DetectorColCount`: Integer, copied from input [S1, unofficial].
*   `Vectors`: Numpy array of shape `(n_angles, 12)` [S1, unofficial].
*   `DetectorSpacingY`: Float, copied from input [S1, unofficial].
*   `DetectorSpacingX`: Float, copied from input [S1, unofficial].

**Algorithm Steps**
1.  Initialize an empty array `Vectors` of shape `(len(ProjectionAngles), 12)` [S1, unofficial].
2.  Iterate through each angle $\theta$ in `ProjectionAngles` with index $i$ [S1, unofficial].
3.  Determine the geometry type from `proj_geom['type']` [S1, unofficial].
4.  **If type is 'cone':**
    *   Compute Source position $S$:
        $$ S_x = \sin(\theta) D_{OS} $$
        $$ S_y = -\cos(\theta) D_{OS} $$
        $$ S_z = 0 $$
    *   Compute Detector Center $D$:
        $$ D_x = -\sin(\theta) D_{OD} $$
        $$ D_y = \cos(\theta) D_{OD} $$
        $$ D_z = 0 $$
    *   Compute Detector X-axis basis vector $U$:
        $$ U_x = \cos(\theta) D_{DX} $$
        $$ U_y = \sin(\theta) D_{DX} $$
        $$ U_z = 0 $$
    *   Compute Detector Y-axis basis vector $V$:
        $$ V_x = 0 $$
        $$ V_y = 0 $$
        $$ V_z = D_{DY} $$
5.  **If type is 'parallel3d':**
    *   Compute Ray Direction $R$:
        $$ R_x = \sin(\theta) $$
        $$ R_y = -\cos(\theta) $$
        $$ R_z = 0 $$
    *   Compute Detector Center $D$:
        $$ D_x = 0 $$
        $$ D_y = 0 $$
        $$ D_z = 0 $$
    *   Compute Detector X-axis basis vector $U$:
        $$ U_x = \cos(\theta) D_{DX} $$
        $$ U_y = \sin(\theta) D_{DX} $$
        $$ U_z = 0 $$
    *   Compute Detector Y-axis basis vector $V$:
        $$ V_x = 0 $$
        $$ V_y = 0 $$
        $$ V_z = D_{DY} $$
6.  Store the computed values in `Vectors[i, :]` in the order: $S_x, S_y, S_z, D_x, D_y, D_z, U_x, U_y, U_z, V_x, V_y, V_z$ [S1, unofficial]. For `'parallel3d'`, the ray direction $R$ occupies the first three slots [S1, unofficial].
7.  Return the dictionary with `Vectors`, `type`, `DetectorRowCount`, `DetectorColCount`, `DetectorSpacingX`, and `DetectorSpacingY` [S1, unofficial].

**Pseudocode**
```python
import numpy as np

def projection_geometry_to_vector(proj_geom):
    """
    Converts a dictionary-based projection geometry into a 12-element vector array.
    
    Args:
        proj_geom (dict): Dictionary containing geometry parameters.
        
    Returns:
        dict: Dictionary with 'Vectors', 'type', 'DetectorRowCount', 'DetectorColCount', 
              'DetectorSpacingX', 'DetectorSpacingY'.
    """
    angles = proj_geom['ProjectionAngles']
    n_angles = len(angles)
    vectors = np.zeros((n_angles, 12))
    
    D_OS = proj_geom['DistanceOriginSource']
    D_OD = proj_geom['DistanceOriginDetector']
    D_DX = proj_geom['DetectorSpacingX']
    D_DY = proj_geom['DetectorSpacingY']
    
    geom_type = proj_geom['type']
    
    for i, theta in enumerate(angles):
        sin_t = np.sin(theta)
        cos_t = np.cos(theta)
        
        if geom_type == 'cone':
            # Source Position
            vectors[i, 0] = sin_t * D_OS
            vectors[i, 1] = -cos_t * D_OS
            vectors[i, 2] = 0.0
            
            # Detector Center
            vectors[i, 3] = -sin_t * D_OD
            vectors[i, 4] = cos_t * D_OD
            vectors[i, 5] = 0.0
            
            # Detector X-axis
            vectors[i, 6] = cos_t * D_DX
            vectors[i, 7] = sin_t * D_DX
            vectors[i, 8] = 0.0
            
            # Detector Y-axis
            vectors[i, 9] = 0.0
            vectors[i, 10] = 0.0
            vectors[i, 11] = D_DY
            
        elif geom_type == 'parallel3d':
            # Ray Direction (stored in first 3 slots)
            vectors[i, 0] = sin_t
            vectors[i, 1] = -cos_t
            vectors[i, 2] = 0.0
            
            # Detector Center
            vectors[i, 3] = 0.0
            vectors[i, 4] = 0.0
            vectors[i, 5] = 0.0
            
            # Detector X-axis
            vectors[i, 6] = cos_t * D_DX
            vectors[i, 7] = sin_t * D_DX
            vectors[i, 8] = 0.0
            
            # Detector Y-axis
            vectors[i, 9] = 0.0
            vectors[i, 10] = 0.0
            vectors[i, 11] = D_DY
            
        else:
            raise ValueError(f"Unsupported geometry type: {geom_type}")
            
    return {
        'type': geom_type,
        'DetectorRowCount': proj_geom['DetectorRowCount'],
        'DetectorColCount': proj_geom['DetectorColCount'],
        'Vectors': vectors,
        'DetectorSpacingX': D_DX,
        'DetectorSpacingY': D_DY
    }
```

**Parameters**
*   `proj_geom`: Dictionary containing geometry parameters [S1, unofficial].
*   `ProjectionAngles`: Array of floats [S1, unofficial].
*   `DistanceOriginSource`: Float [S1, unofficial].
*   `DistanceOriginDetector`: Float [S1, unofficial].
*   `DetectorSpacingX`: Float [S1, unofficial].
*   `DetectorSpacingY`: Float [S1, unofficial].
*   `DetectorRowCount`: Integer [S1, unofficial].
*   `DetectorColCount`: Integer [S1, unofficial].

**Edge Cases and Pitfalls**
*   Not given in the sources.

## Operating characteristics
*   **Time Complexity:** $O(N)$, where $N$ is the number of projection angles [S1, unofficial].
*   **Memory Complexity:** $O(N)$, storing the 12-element vector for each angle [S1, unofficial].
*   **Strengths:** Simple, fast, and deterministic conversion from high-level parameters to low-level vectors [S1, unofficial].
*   **Limitations:** Only supports specific rotation axes and geometry types (cone and parallel3d) [S1, unofficial].
*   **When to use:** When implementing a differentiable projector that requires explicit source, detector center, and basis vectors for each angle [S1, unofficial].
*   **When not to use:** For complex geometries not covered by the cone/parallel3d models, or when using a library that handles geometry internally [S1, unofficial].

## Background
This method originates from the ShapeFromProjections framework [S1, unofficial]. It is used in differentiable tomography pipelines to bridge high-level geometric parameters and low-level vector representations [S1, unofficial].
