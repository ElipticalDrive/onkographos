# Camera Setup and Projection Matrix Construction

Also called: CamSetup, Camera View and Projection Setup

## Overview
This method initializes camera parameters for volume rendering or training, handling downscaling, view matrix construction, and projection matrix calculation [S1, unofficial]. It differs from generic graphics pipelines by explicitly managing intrinsic scaling for multi-resolution training and constructing a specific projection matrix tailored for the near/far plane constraints of the rendering engine [S1, unofficial].

## How it works
**Inputs:**
- Camera intrinsic parameters: focal lengths $f_x, f_y$, principal points $c_x, c_y$, original image width $W$, height $H$ [S1, unofficial].
- Camera extrinsic parameters: 4x4 row-major matrix $C_{world}$ (camera-to-world) [S1, unofficial].
- Rendering parameters: near plane $n = 0.001$, far plane $f = 1000.0$, downscale factor $s_f$ derived from `step` [S1, unofficial].
- Optional: Camera position, front, up vectors, zoom [S2, unofficial].

**Outputs:**
- View matrix $V$ (4x4) [S1, S2, unofficial].
- Projection matrix $P$ (4x4) [S1, S2, unofficial].
- Combined Proj-View matrix $PV = P \times V$ [S1, unofficial].
- Cached camera position and FOV values [S1, unofficial].

**Data Structures:**
- `Camera` struct containing:
  - `width`, `height`: int [S1, unofficial].
  - `fx`, `fy`, `cx`, `cy`: float [S1, unofficial].
  - `camToWorld[16]`: float array, 4x4 row-major [S1, unofficial].
  - `cachedViewMat`, `cachedProjViewMat`: cached matrices [S1, unofficial].
  - `cachedCamPos[3]`: float array [S1, unofficial].
  - `cachedFovX`, `cachedFovY`: float [S1, unofficial].
  - `ori_*` members for initial parameters [S2, unofficial].

**Steps:**

1. **Calculate Downscale and New Intrinsics:**
   Let $s_f$ be the downscale factor derived from `step`.
   Calculate new dimensions:
   $$ W' = W / s_f $$
   $$ H' = H / s_f $$
   Calculate new intrinsics by dividing original intrinsics by $s_f$:
   $$ f_x' = f_x / s_f $$
   $$ f_y' = f_y / s_f $$
   $$ c_x' = c_x / s_f $$
   $$ c_y' = c_y / s_f $$
   [S1, unofficial]

2. **Calculate Field of View (FOV):**
   Compute horizontal and vertical FOV in radians:
   $$ \text{fov}_X = 2.0 \cdot \arctan\left(\frac{W'}{2.0 \cdot f_x'}\right) $$
   $$ \text{fov}_Y = 2.0 \cdot \arctan\left(\frac{H'}{2.0 \cdot f_y'}\right) $$
   [S1, unofficial]

3. **Construct View Matrix ($V$):**
   If the view matrix is not cached or FOV has changed:
   Extract rotation $R$ (3x3) and translation $T$ (3x1) from $C_{world}$ using row-major indexing: $R$ consists of elements $C_{world}[i \cdot 4 + j]$ for $i,j \in \{0,1,2\}$, and $T$ consists of elements $C_{world}[i \cdot 4 + 3]$ for $i \in \{0,1,2\}$ [S1, unofficial].
   Compute inverse rotation $R^{-1} = R^T$ (transpose) [G].
   Compute inverse translation $T^{-1} = -R^{-1} T$ [G].
   Construct $V$ (4x4):
   $$ V = \begin{bmatrix} R^{-1} & T^{-1} \\ 0 & 1 \end{bmatrix} $$
   [S1, unofficial]
   Alternatively, compute $V$ using a standard look-at function with camera position, target $(0,0,0)$, and up vector [S2, unofficial].

4. **Construct Projection Matrix ($P$):**
   Define near plane $n = 0.001$ and far plane $f = 1000.0$ [S1, unofficial].
   Calculate intermediate values:
   $$ r_p = n \cdot \tan\left(\frac{\text{fov}_X}{2}\right) $$
   $$ t_p = n \cdot \tan\left(\frac{\text{fov}_Y}{2}\right) $$
   [S1, unofficial]
   Construct $P$ (4x4, row-major indices $0..15$):
   $$ P[0] = \frac{n}{r_p} $$
   $$ P[5] = \frac{n}{t_p} $$
   $$ P[10] = \frac{f + n}{f - n} $$
   $$ P[14] = \frac{-f \cdot n}{f - n} $$
   Unspecified elements are $0$ or $1$ as required for standard perspective projection [G].

5. **Compute Combined Matrix and Cache:**
   $$ PV = P \times V $$
   Cache $V$, $PV$, camera position, and FOV values [S1, unofficial].

6. **Additional Setup:**
   Set `degreesToUse = min(step / shDegreeInterval, shDegree)` [S1, unofficial].
   Determine degree from `featuresRest` size [S1, unofficial].
   Calculate `tileBounds` from $W'$, $H'$ and block sizes `BLOCK_X`, `BLOCK_Y` [S1, unofficial].
   Set cached camera position from extrinsic parameters [S1, unofficial].

**Pseudocode:**

```python
import math

def mat4_mul(A, B):
    C = [[0.0]*4 for _ in range(4)]
    for i in range(4):
        for j in range(4):
            for k in range(4):
                C[i][j] += A[i][k] * B[k][j]
    return C

def setup_camera(camera, step, sh_degree_interval, sh_degree, features_rest_size, block_x, block_y):
    # 1. Downscale
    sf = step
    new_width = camera.width / sf
    new_height = camera.height / sf
    
    fx = camera.fx / sf
    fy = camera.fy / sf
    cx = camera.cx / sf
    cy = camera.cy / sf
    
    # 2. FOV
    fov_x = 2.0 * math.atan(new_width / (2.0 * fx))
    fov_y = 2.0 * math.atan(new_height / (2.0 * fy))
    
    # 3. View Matrix
    fov_changed = (camera.cached_fov_x != fov_x or camera.cached_fov_y != fov_y)
    
    if not camera.cached_view_mat or fov_changed:
        # Extract R and T from camera.camToWorld (4x4 row-major)
        R = [[camera.camToWorld[i*4 + j] for j in range(3)] for i in range(3)]
        T = [camera.camToWorld[i*4 + 3] for i in range(3)]
        
        # Inverse Rotation (Transpose)
        R_inv = [[R[j][i] for j in range(3)] for i in range(3)]
        
        # Inverse Translation: -R_inv * T
        T_inv = [-sum(R_inv[i][k] * T[k] for k in range(3)) for i in range(3)]
        
        # Construct View Matrix (4x4)
        V = [
            R_inv[0] + [T_inv[0]],
            R_inv[1] + [T_inv[1]],
            R_inv[2] + [T_inv[2]],
            [0.0, 0.0, 0.0, 1.0]
        ]
        camera.cached_view_mat = V
        
        # 4. Projection Matrix
        n = 0.001
        f = 1000.0
        r_p = n * math.tan(0.5 * fov_x)
        t_p = n * math.tan(0.5 * fov_y)
        
        P = [[0.0]*4 for _ in range(4)]
        P[0][0] = n / r_p
        P[1][1] = n / t_p
        P[2][2] = (f + n) / (f - n)
        P[3][2] = -f * n / (f - n)
        P[3][3] = -1.0  # Standard OpenGL perspective w-component [G]
        
        # 5. Combined Matrix
        camera.cached_proj_view_mat = mat4_mul(P, V)
        
        # Cache FOV and Position
        camera.cached_fov_x = fov_x
        camera.cached_fov_y = fov_y
        camera.cached_cam_pos = T  # Derived from extrinsics [S1, unofficial]
        
    # 6. Additional Setup
    degrees_to_use = min(step / sh_degree_interval, sh_degree)
    # Determine degree from featuresRest size (exact mapping not provided in sources)
    degree = min(features_rest_size, degrees_to_use) [G]
    # Calculate tileBounds from width/height and BLOCK_X/BLOCK_Y (exact logic not provided in sources)
    tile_bounds = [0, 0, new_width, new_height] [G]
    
    return V, P, camera.cached_proj_view_mat
```

**Edge Cases and Pitfalls:**
- **Precision:** Use float32 for intrinsics and matrices as specified [S1, unofficial].
- **Boundaries:** Ensure $s_f \ge 1$ to avoid invalid dimensions [G].
- **Degenerate Input:** If $f_x$ or $f_y$ is $0$, FOV calculation will fail [G].
- **Caching:** View matrix must be recomputed if FOV changes [S1, unofficial].

## Subtopics

### View Matrix Construction
Focuses on the transformation from camera space to world space using rotation and translation [S1, S2, unofficial].

### Projection Matrix Construction
Focuses on mapping 3D points to 2D screen coordinates using FOV and near/far planes [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(1)$ for matrix construction, assuming fixed-size matrices [G].
- **Memory Complexity:** $O(1)$ for storing matrices and cached values [G].
- **Strengths:** Handles multi-resolution training via downscaling; explicit control over near/far planes [S1, unofficial].
- **Limitations:** Specific to the Metal/OpenGL context described; may not generalize to all projection types without modification [S1, S2, unofficial].

## Background
Originated in the context of 3D Gaussian Splatting training [S1, unofficial]. The method is implemented in projects such as Msplat [S1, unofficial].
