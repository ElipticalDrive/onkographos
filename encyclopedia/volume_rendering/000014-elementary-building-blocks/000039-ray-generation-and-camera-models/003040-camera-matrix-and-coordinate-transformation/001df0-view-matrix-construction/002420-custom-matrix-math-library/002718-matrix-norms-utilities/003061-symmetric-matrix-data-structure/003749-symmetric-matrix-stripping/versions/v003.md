# Symmetric Matrix Stripping

Also called: Covariance Matrix Stripping, Lower-Diagonal Matrix Stripping, Symmetric Matrix Lower Triangular Packing, Symmetric Matrix to Vector Conversion

## Overview
Symmetric Matrix Stripping extracts the 6 unique elements from the lower triangular part of a batch of 3x3 symmetric matrices (typically covariance matrices) into a flat tensor of shape `(N, 6)` [S2, unofficial][S3, unofficial][S4, unofficial]. It solves the problem of efficiently storing and transmitting symmetric matrices by eliminating redundant upper-triangular elements, leveraging the property that $M_{ij} = M_{ji}$ [S5, unofficial]. This method is distinct from general matrix flattening as it assumes symmetry and follows a specific row-major lower-diagonal ordering [S4, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A tensor $L$ of shape $(N, 3, 3)$, where $N$ is the batch size. Each $3 \times 3$ slice represents a symmetric matrix [S2, unofficial][S3, unofficial][S4, unofficial].
- Output: A tensor $V$ of shape $(N, 6)$, where each row contains the 6 unique lower-diagonal elements [S1, unofficial][S2, unofficial][S3, unofficial].

**Data Structure Layout:**
The output vector $V$ for each matrix is indexed as follows [S2, unofficial][S3, unofficial][S4, unofficial]:
- $V[:, 0] \leftarrow L[:, 0, 0]$
- $V[:, 1] \leftarrow L[:, 0, 1]$
- $V[:, 2] \leftarrow L[:, 0, 2]$
- $V[:, 3] \leftarrow L[:, 1, 1]$
- $V[:, 4] \leftarrow L[:, 1, 2]$
- $V[:, 5] \leftarrow L[:, 2, 2]$

**Steps:**
1. Initialize an output tensor $V$ of zeros with shape $(N, 6)$ on the target device [S2, unofficial][S3, unofficial].
2. Map the elements of $L$ to $V$ according to the layout defined above [S2, unofficial][S3, unofficial].
3. Return $V$ [S2, unofficial][S3, unofficial].

**Pseudocode:**
```python
def strip_symmetric(L):
    """
    Extracts the 6 unique elements from the lower triangular part of a batch of 3x3 symmetric matrices.
    
    Args:
        L: Array-like of shape (N, 3, 3) representing N symmetric matrices.
        
    Returns:
        V: Array-like of shape (N, 6) containing the lower-diagonal elements.
    """
    N = L.shape[0]
    V = [[0.0] * 6 for _ in range(N)]
    for i in range(N):
        V[i][0] = L[i][0][0]
        V[i][1] = L[i][0][1]
        V[i][2] = L[i][0][2]
        V[i][3] = L[i][1][1]
        V[i][4] = L[i][1][2]
        V[i][5] = L[i][2][2]
    return V
```

**Parameters:**
- No additional parameters are required. The method is deterministic based on the input tensor layout [S2, unofficial][S3, unofficial].

**Edge Cases and Pitfalls:**
- **Symmetry Assumption:** The method assumes the input matrix is symmetric. If $L_{ij} \neq L_{ji}$, the upper triangular elements are ignored [S1, unofficial].
- **Batch Size:** If $N=0$, the output is an empty tensor of shape $(0, 6)$ [S2, unofficial][S3, unofficial].

### Stress Tensor Representation

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the batch size, as each of the 6 elements is copied once [S2, unofficial][S3, unofficial].
- **Memory Complexity:** $O(N)$ for the output tensor, reducing storage from $9N$ elements to $6N$ elements [S5, unofficial].
- **Performance:** Not given in the sources.
- **Strengths:** Reduces storage and optimization parameters [S5, unofficial].
- **Limitations:** Not given in the sources.

## Background
Symmetric Matrix Stripping is used in 3D Gaussian Splatting and related rendering techniques to efficiently handle covariance matrices for Gaussian primitives [S1, unofficial][S2, unofficial][S3, unofficial][S4, unofficial]. The function `strip_symmetric` is an alias that calls `strip_lowerdiag`, assuming the input is symmetric [S1, unofficial].
