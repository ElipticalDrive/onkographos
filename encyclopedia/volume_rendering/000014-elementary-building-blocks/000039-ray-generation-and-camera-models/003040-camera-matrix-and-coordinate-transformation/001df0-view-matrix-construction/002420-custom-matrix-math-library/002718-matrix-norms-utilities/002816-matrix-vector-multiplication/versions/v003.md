# Matrix-Vector Multiplication
Also called: operator* (Mat4, Vec4)
## Overview
Computes the product of a 4x4 matrix and a 4D vector, yielding a transformed 4D vector [S1]. It performs a linear combination of the matrix columns weighted by the vector components [G].
## How it works
**Inputs:**
- `m`: A 4x4 matrix [S1].
- `v`: A 4D vector [S1].
**Outputs:**
- `result`: A 4D vector representing $m \times v$ [S1].
**Data Structures:**
The exact memory layout and bit packing of the matrix and vector are not given in the sources. Standard implementations store the matrix as a 4x4 grid of elements $m_{ij}$ and the vector as a 4-element array $v_j$ [G].
**Steps:**
1. Initialize a 4D result vector `r`.
2. For each row index $i$ from 0 to 3:
3. Compute the dot product of the $i$-th row of `m` and the vector `v`.
4. Store the result in `r[i]`.
5. Return `r`.
**Formula:**
The result vector $r$ is computed as:
$$ r_i = \sum_{j=0}^{3} m_{ij} v_j $$
where $i \in \{0, 1, 2, 3\}$ is the row index, $j \in \{0, 1, 2, 3\}$ is the column/component index, $m_{ij}$ is the element at row $i$ and column $j$ of the matrix, and $v_j$ is the $j$-th component of the vector [G].
**Pseudocode:**
```python
def matrix_vector_multiply(m, v):
    r = [0.0, 0.0, 0.0, 0.0]
    for i in range(4):
        acc = 0.0
        for j in range(4):
            acc += m[i][j] * v[j]
        r[i] = acc
    return r
```
**Parameters:**
- `T`: The numeric type (e.g., `float`, `double`). Not given in the sources.
**Edge Cases and Pitfalls:**
- Precision: Accumulation of floating-point errors in the summation may occur. Not given in the sources.
- Homogeneous Coordinates: If `v` represents a point, the resulting `w` component (index 3) may not be 1.0, requiring perspective division in subsequent steps. Not given in the sources.
- Degenerate Input: If the matrix is singular, the transformation may collapse dimensions. Not given in the sources.
## Subtopics

### [Scalar-Vector Multiplication](6274-scalar-vector-multiplication.md)
Multiplies a scalar by a 4-dimensional vector. It uniformly scales the vector's magnitude without altering its direction [G]. Choose it when only uniform scaling is required, as it avoids the overhead of a full matrix transformation.

## Operating characteristics
- Time Complexity: $O(1)$ for fixed 4x4 matrix and 4D vector, involving 16 multiplications and 12 additions. Not given in the sources.
- Memory Complexity: $O(1)$ auxiliary space. Not given in the sources.
- Measured Performance: Not given in the sources.
