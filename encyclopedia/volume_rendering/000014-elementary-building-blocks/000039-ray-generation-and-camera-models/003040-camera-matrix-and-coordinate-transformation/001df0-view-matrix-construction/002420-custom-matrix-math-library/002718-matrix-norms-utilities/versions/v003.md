# Matrix Norms & Utilities

Also called: MatUtils

## Overview
Provides fundamental arithmetic operations for 3x3 and 4x4 matrices and vectors, including norm calculations, transposition, and multiplication variants. These utilities support the linear algebra requirements of volume rendering camera models and transformation pipelines [S1, S2, unofficial][S3]. Unlike high-level graphics libraries, this implementation focuses on explicit, low-level operations suitable for custom math libraries [S1, S2, unofficial].

## How it works

### Data Structures

**Mat3 (3x3 Matrix)**
A structure containing 9 floating-point values in row-major order [S1, unofficial]:
- Fields: `m00, m01, m02, m10, m11, m12, m20, m21, m22`
- Layout: `[m00, m01, m02, m10, m11, m12, m20, m21, m22]` [S1, unofficial]

**SMat3 (Symmetric 3x3 Matrix)**
A structure storing only the upper triangle of a symmetric matrix, assuming $m_{ij} = m_{ji}$ [S1, unofficial]:
- Fields: `m00, m01, m02, m11, m12, m22`
- Layout: `[m00, m01, m02, m11, m12, m22]` [S1, unofficial]
- Initialization: `setSymmetric(m00, m01, m02, m11, m12, m22)` sets all 6 fields [S1, unofficial].

### Norms

**Frobenius Norm (3x3)**
Calculates the square root of the sum of squared elements [S1, unofficial]:
$$||A||_F = \sqrt{\sum_{i,j} a_{ij}^2}$$
Implementation sums all 9 squared elements of `Mat3` [S1, unofficial].

**Frobenius Norm (Symmetric 3x3)**
Optimized for `SMat3` by accounting for symmetry ($a_{ij} = a_{ji}$) [S1, unofficial]:
$$||A||_F = \sqrt{a_{00}^2 + 2a_{01}^2 + 2a_{02}^2 + a_{11}^2 + 2a_{12}^2 + a_{22}^2}$$
Implementation uses the 6 stored coefficients with appropriate multipliers [S1, unofficial].

**Off-Diagonal Norm (3x3)**
Measures the magnitude of non-diagonal elements [S1, unofficial]:
$$\text{off}(A) = \sqrt{a_{01}^2 + a_{02}^2 + a_{10}^2 + a_{12}^2 + a_{20}^2 + a_{21}^2}$$
Implementation sums the squares of the 6 off-diagonal elements [S1, unofficial].

**Off-Diagonal Norm (Symmetric 3x3)**
Optimized for `SMat3` [S1, unofficial]:
$$\text{off}(A) = \sqrt{2(a_{01}^2 + a_{02}^2 + a_{12}^2)}$$
Implementation uses the 3 stored off-diagonal coefficients with a multiplier of 2 [S1, unofficial].

### Matrix Multiplication

**3x3 Matrix Multiplication**
Computes $C = AB$ for two 3x3 matrices [S1, unofficial]:
$$c_{ij} = \sum_{k=0}^2 a_{ik} b_{kj}$$
Implemented explicitly for 3x3 matrices [S1, unofficial].

**Compute $A^T A$**
Computes the product of a matrix transpose and the matrix itself, storing the result in a symmetric structure `Out` [S1, unofficial]:
- `Out.m00 = a.m00^2 + a.m10^2 + a.m20^2`
- `Out.m01 = a.m00*a.m01 + a.m10*a.m11 + a.m20*a.m21`
- `Out.m02 = a.m00*a.m02 + a.m10*a.m12 + a.m20*a.m22`
- `Out.m11 = a.m01^2 + a.m11^2 + a.m21^2`
- `Out.m12 = a.m01*a.m02 + a.m11*a.m12 + a.m21*a.m22`
- `Out.m22 = a.m02^2 + a.m12^2 + a.m22^2`
This exploits symmetry to reduce computation and storage [S1, unofficial].

**Vector Magnitude**
Computes the Euclidean norm of a 4D vector [S2, unofficial]:
$$\|u\| = \sqrt{\sum_{i=0}^{3} u_i^2}$$
Implementation: `Math.sqrt(this.dot(this))` [S2, unofficial].

### Transposition

**4x4 Matrix Transpose**
Returns the transpose of a 4x4 matrix [S2, unofficial]:
1. Initialize 4x4 matrix `mat`.
2. Loop `i` from 0 to 3, `j` from 0 to 3.
3. Set `mat[i][j] = this[j][i]`.
4. Return `mat` [S2, unofficial].

**3x3 Matrix Transpose**
Multiplies the transpose of a 3x3 matrix by a 3D vector [S3]:
- Formula: `result = mat^T x xyz`
- Supports 32-bit (`float`) and 64-bit (`double`) arithmetic [S3].
- Parameters: `mat` (pointer to array of floats/doubles), `xyz` (input vector) [S3].

### Pseudocode

```python
def mat3_frobenius_norm(m):
    """Computes Frobenius norm of a 3x3 matrix."""
    sum_sq = (m.m00**2 + m.m01**2 + m.m02**2 +
              m.m10**2 + m.m11**2 + m.m12**2 +
              m.m20**2 + m.m21**2 + m.m22**2)
    return sum_sq**0.5

def smat3_frobenius_norm(m):
    """Computes Frobenius norm of a symmetric 3x3 matrix."""
    sum_sq = (m.m00**2 + 2*m.m01**2 + 2*m.m02**2 +
              m.m11**2 + 2*m.m12**2 + m.m22**2)
    return sum_sq**0.5

def mat3_off_diagonal_norm(m):
    """Computes off-diagonal norm of a 3x3 matrix."""
    sum_sq = (m.m01**2 + m.m02**2 + m.m10**2 +
              m.m12**2 + m.m20**2 + m.m21**2)
    return sum_sq**0.5

def smat3_off_diagonal_norm(m):
    """Computes off-diagonal norm of a symmetric 3x3 matrix."""
    sum_sq = 2 * (m.m01**2 + m.m02**2 + m.m12**2)
    return sum_sq**0.5

def mat3_multiply(a, b):
    """Computes C = A * B for 3x3 matrices."""
    c = Mat3()
    for i in range(3):
        for j in range(3):
            c[i][j] = a[i][0]*b[0][j] + a[i][1]*b[1][j] + a[i][2]*b[2][j]
    return c

def mat3_at_a(m):
    """Computes A^T * A and stores result in SMat3."""
    out = SMat3()
    out.m00 = m.m00**2 + m.m10**2 + m.m20**2
    out.m01 = m.m00*m.m01 + m.m10*m.m11 + m.m20*m.m21
    out.m02 = m.m00*m.m02 + m.m10*m.m12 + m.m20*m.m22
    out.m11 = m.m01**2 + m.m11**2 + m.m21**2
    out.m12 = m.m01*m.m02 + m.m11*m.m12 + m.m21*m.m22
    out.m22 = m.m02**2 + m.m12**2 + m.m22**2
    return out

def vec4_magnitude(v):
    """Computes Euclidean norm of a 4D vector."""
    return (v.x**2 + v.y**2 + v.z**2 + v.w**2)**0.5

def mat4_transpose(m):
    """Returns the transpose of a 4x4 matrix."""
    out = Mat4()
    for i in range(4):
        for j in range(4):
            out[i][j] = m[j][i]
    return out

def mat3_transpose_vec(m, xyz):
    """Multiplies transposed 3x3 matrix by 3D vector."""
    # result = m^T * xyz
    res_x = m.m00*xyz.x + m.m10*xyz.y + m.m20*xyz.z
    res_y = m.m01*xyz.x + m.m11*xyz.y + m.m21*xyz.z
    res_z = m.m02*xyz.x + m.m12*xyz.y + m.m22*xyz.z
    return Vec3(res_x, res_y, res_z)
```

## Subtopics

### [Matrix-Vector Multiplication](4208-matrix-vector-multiplication.md)
Computes the product of a 4x4 transformation matrix and a 4D vector, yielding a transformed 4D vector. This operation is the fundamental arithmetic step for applying affine transformations (rotation, translation, scaling, shear) to points and directions in volume rendering camera models. It differs from scalar-vector multiplication by altering direction and position via linear combination of basis vectors, rather than uniform scaling.

### Matrix Transpose (3x3)
Returns the transpose of a 4x4 matrix [S2, unofficial]. Implementation initializes a new 4x4 matrix and swaps indices `mat[i][j] = this[j][i]` for all $i, j \in [0, 3]$ [S2, unofficial].

### Matrix Transpose (3x3)
Multiplies the transpose of a 3x3 matrix by a 3D vector using 32-bit or 64-bit floating point arithmetic [S3]. Formula: `result = mat^T x xyz` [S3]. Parameters include a pointer to the 3x3 matrix array and the input 3D vector [S3]. Corresponds to an inverse linear mapping (e.g., inverse scaling, inverse rotation) [S3].

### Matrix Multiplication (2x3 by 3x3)
Multiplies a 2x3 matrix by a 3x3 matrix, resulting in a 2x3 matrix [S3]. Also supports multiplying a 3x3 matrix by a 2x3 matrix, resulting in a 2x3 matrix [S3]. Parameters are the left-hand side (lhs) and right-hand side (rhs) matrices [S3].

### Matrix Multiplication (3x2 by 2x3)
Multiplies a 3x2 matrix by a 2x3 matrix, resulting in a 3x3 matrix [S3]. Parameters are the 3x2 lhs and 2x3 rhs matrices [S3].

### Vector Magnitude
Computes the Euclidean norm (length) of a 4D vector [S2, unofficial]. Formula: $\|u\| = \sqrt{\sum_{i=0}^{3} u_i^2}$ [S2, unofficial]. Implementation returns `Math.sqrt(this.dot(this))` [S2, unofficial].

### Symmetric Matrix Data Structure
A data structure `SMat3` with 6 public float fields: `m00, m01, m02, m11, m12, m22` [S1, unofficial]. Represents a 3x3 symmetric matrix where $m_{01}=m_{10}$, $m_{02}=m_{20}$, and $m_{12}=m_{21}$ [S1, unofficial]. Initialization is handled via `setSymmetric` which sets all 6 fields from parameters [S1, unofficial].

## Operating characteristics

Time complexity for norms is $O(1)$ for fixed-size matrices (3x3 or 4x4). Matrix multiplication is $O(n^3)$ for $n \times n$ matrices, but here specialized for small fixed sizes (3x3, 4x4, 2x3, 3x2). Memory usage is minimal, storing only necessary coefficients (6 for symmetric matrices vs 9 for full matrices) [S1, unofficial]. Performance is hardware-dependent but benefits from reduced arithmetic operations in symmetric variants [S1, unofficial][S3]. Strengths include explicit control and low overhead; limitations include lack of generalization to arbitrary sizes [S1, S2, unofficial][S3]. Use for small, fixed-size linear algebra in custom rendering pipelines [S1, S2, unofficial][S3].

## Background

Originated in custom implementations for volume rendering and dual contouring, specifically in the `DualContouringCSharp` repository [S1, unofficial] and `volume_rendering` WebGL utilities [S2, unofficial]. Additional variants are found in OpenVDB's `nanovdb::math` namespace [S3]. Used in contexts requiring native 3D transformations without external libraries [S1, S2, unofficial].
