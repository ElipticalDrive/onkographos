# Matrix Norms & Utilities

Also called: MatUtils

## Overview
Provides fundamental arithmetic operations, norms, and data structures for 3x3 and 4x4 matrices used in volume rendering transformations. It distinguishes itself by offering specialized handling for symmetric matrices (via `SMat3`) to optimize storage and computation for covariance-like operations, alongside standard Frobenius and off-diagonal norms for error analysis.

## How it works
### Inputs and Outputs
- **Inputs**: Matrix structures (`Mat3`, `SMat3`, `Mat4`), vectors (`Vec3`, `Vec4`), and scalar values.
- **Outputs**: Transformed vectors, computed norms, resulting matrices from multiplication.

### Data Structures
**`Mat3` (3x3 Matrix)**
- Layout: 9 floats in row-major order.
- Fields: `m00, m01, m02, m10, m11, m12, m20, m21, m22`.
- Indexing: `m[i*3 + j]` corresponds to row `i`, column `j`.

**`SMat3` (Symmetric 3x3 Matrix)**
- Layout: 6 floats representing the upper triangle.
- Fields: `m00, m01, m02, m11, m12, m22`.
- Constraint: $m_{ij} = m_{ji}$. Implicitly, $m_{10}=m_{01}$, $m_{20}=m_{02}$, $m_{21}=m_{12}$.

### Norms and Utilities

**Frobenius Norm**
Measures the magnitude of a matrix.
- For `Mat3` [S1, unofficial]:
  $$||A||_F = \sqrt{\sum_{i=0}^{2}\sum_{j=0}^{2} a_{ij}^2}$$
  Implementation sums all 9 squared elements.
- For `SMat3` [S1, unofficial]:
  $$||A||_F = \sqrt{a_{00}^2 + 2a_{01}^2 + 2a_{02}^2 + a_{11}^2 + 2a_{12}^2 + a_{22}^2}$$
  Implementation accounts for symmetry by doubling the off-diagonal terms.

**Off-Diagonal Norm**
Measures the magnitude of non-diagonal elements.
- For `Mat3` [S1, unofficial]:
  $$\text{off}(A) = \sqrt{a_{01}^2 + a_{02}^2 + a_{10}^2 + a_{12}^2 + a_{20}^2 + a_{21}^2}$$
- For `SMat3` [S1, unofficial]:
  $$\text{off}(A) = \sqrt{2(a_{01}^2 + a_{02}^2 + a_{12}^2)}$$

**Matrix Multiplication ($C = AB$)**
- For 3x3 matrices [S1, unofficial]:
  $$c_{ij} = \sum_{k=0}^{2} a_{ik} b_{kj}$$
- For `A^T A` (Symmetric Result) [S1, unofficial]:
  Computes $B = A^T A$. Since $B$ is symmetric, it stores only the upper triangle in `SMat3`.
  - `Out.m00 = a.m00^2 + a.m10^2 + a.m20^2`
  - `Out.m01 = a.m00*a.m01 + a.m10*a.m11 + a.m20*a.m21`
  - `Out.m02 = a.m00*a.m02 + a.m10*a.m12 + a.m20*a.m22`
  - `Out.m11 = a.m01^2 + a.m11^2 + a.m21^2`
  - `Out.m12 = a.m01*a.m02 + a.m11*a.m12 + a.m21*a.m22`
  - `Out.m22 = a.m02^2 + a.m12^2 + a.m22^2`

**Vector Magnitude**
- For 4D vector $u$ [S2, unofficial]:
  $$\|u\| = \sqrt{\sum_{i=0}^{3} u_i^2}$$
  Implementation: `Math.sqrt(this.dot(this))`.

### Pseudocode

```python
def mat3_frobenius_norm(m):
    """
    Computes Frobenius norm of a 3x3 matrix.
    m: list of 9 floats [m00, m01, m02, m10, m11, m12, m20, m21, m22]
    """
    sum_sq = 0.0
    for val in m:
        sum_sq += val * val
    return math.sqrt(sum_sq)

def smat3_frobenius_norm(m):
    """
    Computes Frobenius norm of a symmetric 3x3 matrix.
    m: list of 6 floats [m00, m01, m02, m11, m12, m22]
    """
    # m[0]=m00, m[1]=m01, m[2]=m02, m[3]=m11, m[4]=m12, m[5]=m22
    sum_sq = (m[0]**2 + m[3]**2 + m[5]**2) + 2 * (m[1]**2 + m[2]**2 + m[4]**2)
    return math.sqrt(sum_sq)

def mat3_off_diagonal_norm(m):
    """
    Computes off-diagonal norm of a 3x3 matrix.
    """
    # Indices: 0,4,8 are diagonal. 1,2,3,5,6,7 are off-diagonal.
    sum_sq = (m[1]**2 + m[2]**2 + m[3]**2 + m[5]**2 + m[6]**2 + m[7]**2)
    return math.sqrt(sum_sq)

def smat3_off_diagonal_norm(m):
    """
    Computes off-diagonal norm of a symmetric 3x3 matrix.
    """
    # Off-diagonals are m01, m02, m12 (indices 1, 2, 4)
    sum_sq = 2 * (m[1]**2 + m[2]**2 + m[4]**2)
    return math.sqrt(sum_sq)

def mat3_multiply(a, b):
    """
    Multiplies two 3x3 matrices.
    a, b: lists of 9 floats.
    Returns: list of 9 floats.
    """
    c = [0.0] * 9
    for i in range(3):
        for j in range(3):
            s = 0.0
            for k in range(3):
                s += a[i*3 + k] * b[k*3 + j]
            c[i*3 + j] = s
    return c

def mat3_transpose_multiply_aTa(a):
    """
    Computes A^T * A for a 3x3 matrix A, storing result in symmetric layout.
    a: list of 9 floats.
    Returns: list of 6 floats [m00, m01, m02, m11, m12, m22].
    """
    # Extract elements for clarity
    m00, m01, m02 = a[0], a[1], a[2]
    m10, m11, m12 = a[3], a[4], a[5]
    m20, m21, m22 = a[6], a[7], a[8]
    
    out = [0.0] * 6
    out[0] = m00**2 + m10**2 + m20**2
    out[1] = m00*m01 + m10*m11 + m20*m21
    out[2] = m00*m02 + m10*m12 + m20*m22
    out[3] = m01**2 + m11**2 + m21**2
    out[4] = m01*m02 + m11*m12 + m21*m22
    out[5] = m02**2 + m12**2 + m22**2
    return out

def vec4_magnitude(v):
    """
    Computes Euclidean norm of a 4D vector.
    v: list of 4 floats.
    """
    sum_sq = sum(x**2 for x in v)
    return math.sqrt(sum_sq)
```

### Edge Cases and Pitfalls
- **Symmetry Enforcement**: When constructing `SMat3`, ensure $m_{ij} = m_{ji}$ is strictly maintained. Using a full `Mat3` calculation without symmetry constraints will produce incorrect norms for `SMat3` functions.
- **Precision**: `matMultT` supports both 32-bit and 64-bit floating point arithmetic [S3]. Choose based on required precision vs. performance.
- **Empty Input**: Norms of zero matrices return 0.0.

## Subtopics

### [Matrix-Vector Multiplication](4208-matrix-vector-multiplication.md)
Computes the product of a 4x4 matrix and a 4D vector, yielding a transformed 4D vector. It performs a linear combination of the matrix columns weighted by the vector components [G].

### [Symmetric Matrix Data Structure](6259-symmetric-matrix-data-structure.md)
The Symmetric Matrix Data Structure is a compact memory layout for 3x3 symmetric matrices, storing only the 6 unique elements to eliminate redundancy. It differs from a full 9-element matrix by enforcing $m_{ij} = m_{ji}$, reducing storage and computation costs for operations like covariance analysis or stress tensor representation.

### Matrix Transpose (3x3)
Returns the transpose of a 4x4 matrix [S2, unofficial].
- **Step**: Initialize 4x4 matrix `mat`. Loop `i` from 0 to 3, `j` from 0 to 3. Set `mat[i][j] = this[j][i]`. Return `mat`.

### Matrix Transpose (3x3)
Multiplies the transpose of a 3x3 matrix by a 3d vector using 32-bit or 64-bit floating point arithmetic [S3].
- **Formula**: `result = mat^T x xyz`
- **Parameters**: `mat` (pointer to array of floats/doubles), `xyz` (input vector).

### Matrix Multiplication (2x3 by 3x3)
Multiplies a 2x3 matrix by a 3x3 matrix, result is a 2x3 matrix [S3]. Also supports 3x3 by 2x3 [S3].
- **Parameters**: `lhs` (2x3 or 3x3), `rhs` (3x3 or 2x3).

### Matrix Multiplication (3x2 by 2x3)
Multiplies a 3x2 matrix by a 2x3 matrix, result is a 3x3 matrix [S3].
- **Parameters**: `lhs` (3x2), `rhs` (2x3).

## Operating characteristics
- **Time Complexity**: Matrix-vector multiplication is $O(N^2)$ for $N \times N$ matrices. Norm calculations are $O(N^2)$ for full matrices, $O(N)$ for symmetric upper triangle.
- **Memory Complexity**: `SMat3` uses 6 floats vs 9 for `Mat3`, a 33% reduction.
- **Strengths**: Optimized storage for symmetric operations; explicit handling of off-diagonal norms for error analysis.
- **Limitations**: Limited to 3x3 and 4x4 sizes in the provided utilities; no general $N \times N$ support.

## Background
Originates from custom implementations in volume rendering and dual contouring projects [S1, S2, unofficial]. The symmetric matrix utilities are particularly relevant for quadratic error function (QEF) minimization in mesh generation [S1, unofficial]. The 3x3 transpose multiplication is part of broader linear algebra libraries like OpenVDB's nanovdb [S3].
