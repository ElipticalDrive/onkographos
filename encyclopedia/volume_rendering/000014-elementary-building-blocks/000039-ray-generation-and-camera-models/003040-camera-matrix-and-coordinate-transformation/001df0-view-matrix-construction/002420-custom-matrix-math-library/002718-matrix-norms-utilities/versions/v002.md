# Matrix Norms & Utilities

Also called: MatUtils

## Overview
Provides fundamental linear algebra operations for 3x3 and 4x4 matrices, including norms, transposition, and multiplication variants [S1, unofficial][S2, unofficial][S3]. It serves as the computational core for [Custom Matrix Math Library](3216-custom-matrix-math-library.md), enabling the construction of view matrices and ray generation logic without external dependencies [G]. It distinguishes itself by offering explicit, unoptimized implementations for small fixed-size matrices, prioritizing clarity and correctness over performance [G].

## How it works

**Inputs and Outputs**
Inputs are 3x3 or 4x4 matrices and 3D/4D vectors stored as arrays of floating-point numbers [S1, unofficial][S2, unofficial][S3]. Outputs are scalar norms, transformed matrices, or transformed vectors [S1, unofficial][S2, unofficial][S3].

**Data Structures**
`Mat3` stores a general 3x3 matrix as 9 floats in row-major order: `m00, m01, m02, m10, m11, m12, m20, m21, m22` [S1, unofficial]. `SMat3` stores a symmetric 3x3 matrix as 6 floats representing the upper triangle: `m00, m01, m02, m11, m12, m22`, with implicit symmetry `m10 = m01`, `m20 = m02`, `m21 = m12` [S1, unofficial].

**Numbered Steps**
1. Initialize `Mat3` or `SMat3` structures with input values [S1, unofficial].
2. Compute norms by summing squared elements and applying a square root [S1, unofficial].
3. Compute matrix products by iterating row and column indices to calculate dot products [S1, unofficial].
4. Compute $A^T A$ by mapping the result directly to an `SMat3` structure to exploit symmetry [S1, unofficial].

**Formulas**
Frobenius norm for a general `Mat3` $A$:
$$ ||A||_F = \sqrt{\sum_{i=0}^{2}\sum_{j=0}^{2} a_{ij}^2} = \sqrt{a_{00}^2 + a_{01}^2 + a_{02}^2 + a_{10}^2 + a_{11}^2 + a_{12}^2 + a_{20}^2 + a_{21}^2 + a_{22}^2} $$ [S1, unofficial]

Frobenius norm for a symmetric `SMat3` $A$:
$$ ||A||_F = \sqrt{a_{00}^2 + 2a_{01}^2 + 2a_{02}^2 + a_{11}^2 + 2a_{12}^2 + a_{22}^2} $$ [S1, unofficial]

Off-diagonal norm for a general `Mat3` $A$:
$$ \text{off}(A) = \sqrt{a_{01}^2 + a_{02}^2 + a_{10}^2 + a_{12}^2 + a_{20}^2 + a_{21}^2} $$ [S1, unofficial]

Off-diagonal norm for a symmetric `SMat3` $A$:
$$ \text{off}(A) = \sqrt{2(a_{01}^2 + a_{02}^2 + a_{12}^2)} $$ [S1, unofficial]

3x3 matrix multiplication $C = AB$:
$$ c_{ij} = \sum_{k=0}^{2} a_{ik} b_{kj} $$ [S1, unofficial]

Compute $A^T A$ for symmetric output `Out`:
$$ \text{Out}.m_{00} = a_{00}^2 + a_{10}^2 + a_{20}^2, \quad \text{Out}.m_{01} = a_{00}a_{01} + a_{10}a_{11} + a_{20}a_{21}, \quad \text{Out}.m_{02} = a_{00}a_{02} + a_{10}a_{12} + a_{20}a_{22} $$ [S1, unofficial]
$$ \text{Out}.m_{11} = a_{01}^2 + a_{11}^2 + a_{21}^2, \quad \text{Out}.m_{12} = a_{01}a_{02} + a_{11}a_{12} + a_{21}a_{22}, \quad \text{Out}.m_{22} = a_{02}^2 + a_{12}^2 + a_{22}^2 $$ [S1, unofficial]

**Parameters**
Matrix elements $a_{ij}$ and $b_{ij}$ are 32-bit or 64-bit floating-point numbers [S1, unofficial][S3]. Vector components $xyz$ are 32-bit or 64-bit floating-point numbers [S3].

**Edge Cases and Pitfalls**
Operations assume fixed-size matrices and vectors [G]. Precision loss in squared sums is not addressed in the sources [G]. Boundary conditions for degenerate or zero matrices are not specified [G].

**Pseudocode**
```python
import math

class Mat3:
    def __init__(self, m00=0.0, m01=0.0, m02=0.0, m10=0.0, m11=0.0, m12=0.0, m20=0.0, m21=0.0, m22=0.0):
        self.m00, self.m01, self.m02 = m00, m01, m02
        self.m10, self.m11, self.m12 = m10, m11, m12
        self.m20, self.m21, self.m22 = m20, m21, m22

class SMat3:
    def __init__(self, m00=0.0, m01=0.0, m02=0.0, m11=0.0, m12=0.0, m22=0.0):
        self.m00, self.m01, self.m02 = m00, m01, m02
        self.m11, self.m12, self.m22 = m11, m12, m22

def mat3_frobenius_norm(m):
    sum_sq = m.m00**2 + m.m01**2 + m.m02**2 + m.m10**2 + m.m11**2 + m.m12**2 + m.m20**2 + m.m21**2 + m.m22**2
    return math.sqrt(sum_sq)

def mat3_symmetric_frobenius_norm(m):
    sum_sq = m.m00**2 + 2*m.m01**2 + 2*m.m02**2 + m.m11**2 + 2*m.m12**2 + m.m22**2
    return math.sqrt(sum_sq)

def mat3_off_diagonal_norm(m):
    sum_sq = m.m01**2 + m.m02**2 + m.m10**2 + m.m12**2 + m.m20**2 + m.m21**2
    return math.sqrt(sum_sq)

def mat3_symmetric_off_diagonal_norm(m):
    sum_sq = 2 * (m.m01**2 + m.m02**2 + m.m12**2)
    return math.sqrt(sum_sq)

def mat3_multiply(a, b):
    c = Mat3()
    c.m00 = a.m00*b.m00 + a.m01*b.m10 + a.m02*b.m20
    c.m01 = a.m00*b.m01 + a.m01*b.m11 + a.m02*b.m21
    c.m02 = a.m00*b.m02 + a.m01*b.m12 + a.m02*b.m22
    c.m10 = a.m10*b.m00 + a.m11*b.m10 + a.m12*b.m20
    c.m11 = a.m10*b.m01 + a.m11*b.m11 + a.m12*b.m21
    c.m12 = a.m10*b.m02 + a.m11*b.m12 + a.m12*b.m22
    c.m20 = a.m20*b.m00 + a.m21*b.m10 + a.m22*b.m20
    c.m21 = a.m20*b.m01 + a.m21*b.m11 + a.m22*b.m21
    c.m22 = a.m20*b.m02 + a.m21*b.m12 + a.m22*b.m22
    return c

def mat3_at_a(m):
    out = SMat3()
    out.m00 = m.m00**2 + m.m10**2 + m.m20**2
    out.m01 = m.m00*m.m01 + m.m10*m.m11 + m.m20*m.m21
    out.m02 = m.m00*m.m02 + m.m10*m.m12 + m.m20*m.m22
    out.m11 = m.m01**2 + m.m11**2 + m.m21**2
    out.m12 = m.m01*m.m02 + m.m11*m.m12 + m.m21*m.m22
    out.m22 = m.m02**2 + m.m12**2 + m.m22**2
    return out
```

## Subtopics

### Matrix Transpose (3x3)
Returns the transpose of a 4x4 matrix. It initializes a 4x4 matrix and iterates through indices $i, j \in [0, 3]$, setting `mat[i][j] = this[j][i]` [S2, unofficial].

### Matrix Transpose (3x3)
Multiplies the transpose of a 3x3 matrix by a 3D vector using 32-bit or 64-bit floating point arithmetic. The operation is defined as $\text{result} = \text{mat}^T \times \text{xyz}$ [S3].

### Matrix Multiplication (2x3 by 3x3)
Multiplies a 2x3 matrix by a 3x3 matrix, resulting in a 2x3 matrix. It also supports the reverse order (3x3 by 2x3), which also yields a 2x3 result [S3].

### Matrix Multiplication (3x2 by 2x3)
Multiplies a 3x2 matrix by a 2x3 matrix, resulting in a 3x3 matrix [S3].

### Vector Magnitude
Computes the Euclidean norm (length) of a 4D vector. The formula is $\|u\| = \sqrt{\sum_{i=0}^{3} u_i^2}$ [S2, unofficial].

## Operating characteristics

**Time and Memory Complexity**
All operations are $O(1)$ with respect to input size, as they operate on fixed-size matrices (3x3 or 4x4) [G]. Memory usage is minimal, requiring only the storage of the input and output matrices/vectors [G].

**Strengths and Limitations**
Explicit implementations avoid library overhead and dependencies [G]. Symmetric optimizations reduce computation for $A^T A$ and symmetric norms [S1, unofficial]. The implementations are not optimized for large matrices or batch operations [G]. The lack of SIMD instructions in the basic JavaScript/Python-like pseudocode may lead to performance bottlenecks in high-throughput scenarios compared to optimized C++ libraries [G].

**When to Use**
Use for small-scale transformations in custom rendering engines or educational implementations where dependency management is critical [G]. Avoid for large-scale scientific computing or real-time rendering with massive vertex buffers where hardware-accelerated or SIMD-optimized libraries are preferred [G].

## Background

The `MatUtils` module originates from custom implementations in WebGL-based volume rendering projects [S2, unofficial] and C++ dual contouring libraries [S1, unofficial]. The specific 3x3 symmetric matrix operations and norms are documented in the OpenVDB `nanovdb::math` namespace, which provides high-performance math primitives for volumetric data [S3]. The 4x4 transpose and vector magnitude operations are found in generic WebGL utility libraries [S2, unofficial].
