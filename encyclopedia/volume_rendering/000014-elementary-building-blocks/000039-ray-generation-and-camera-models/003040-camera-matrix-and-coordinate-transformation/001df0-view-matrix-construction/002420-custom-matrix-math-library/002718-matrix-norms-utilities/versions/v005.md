# Matrix Norms & Utilities

Also called: MatUtils

## Overview
Matrix Norms & Utilities provides the fundamental arithmetic operations for 3x3 and 4x4 matrices and vectors used in volume rendering camera models and transformations [S1, S2, unofficial][S3]. It solves the problem of applying affine and linear transformations (rotation, scaling, shear) to points and directions by implementing explicit matrix-vector multiplication, transposition, and norm calculations [S1, unofficial][S3]. It differs from high-level graphics libraries by exposing the raw arithmetic steps, allowing for custom implementations in environments like JavaScript or embedded C++ without external dependencies [S2, unofficial][S3].

## How it works
**Inputs and Outputs:**
The module operates on 3x3 matrices (`Mat3`), symmetric 3x3 matrices (`SMat3`), 4x4 matrices (`Mat4`), and 3D/4D vectors (`Vec3`, `Vec4`) [S1, S2, unofficial][S3]. Inputs are raw floating-point arrays or struct fields; outputs are transformed vectors, new matrices, or scalar norm values [S1, S2, unofficial][S3].

**Data Structures:**
*   `Mat3`: 9 floats in row-major order: `m00, m01, m02, m10, m11, m12, m20, m21, m22` [S1, unofficial].
*   `SMat3`: 6 floats representing the symmetric upper triangle: `m00, m01, m02, m11, m12, m22` [S1, unofficial].
*   `Mat4`: 16 floats (standard 4x4 layout implied by 4x4 operations) [S2, unofficial][S3].
*   `Vec3`: 3 floats [S3].
*   `Vec4`: 4 floats [S2, unofficial].

**Formulas:**
*   **Frobenius Norm (3x3):** $||A||_F = \sqrt{\sum_{i,j} a_{ij}^2}$ [S1, unofficial].
*   **Frobenius Norm (Symmetric 3x3):** $||A||_F = \sqrt{a_{00}^2 + 2a_{01}^2 + 2a_{02}^2 + a_{11}^2 + 2a_{12}^2 + a_{22}^2}$ [S1, unofficial].
*   **Off-diagonal Norm (3x3):** $\text{off}(A) = \sqrt{a_{01}^2 + a_{02}^2 + a_{10}^2 + a_{12}^2 + a_{20}^2 + a_{21}^2}$ [S1, unofficial].
*   **Off-diagonal Norm (Symmetric 3x3):** $\text{off}(A) = \sqrt{2(a_{01}^2 + a_{02}^2 + a_{12}^2)}$ [S1, unofficial].
*   **Matrix Multiplication ($C = AB$):** $c_{ij} = \sum_{k=0}^2 a_{ik} b_{kj}$ for 3x3 matrices [S1, unofficial].
*   **Transpose Product ($A^T A$):** For symmetric output `Out`, `Out.m00 = a.m00^2 + a.m10^2 + a.m20^2`, `Out.m01 = a.m00*a.m01 + a.m10*a.m11 + a.m20*a.m21`, etc. [S1, unofficial].
*   **Vector Magnitude:** $\|u\| = \sqrt{\sum_{i=0}^{3} u_i^2}$ [S2, unofficial].

**Pseudocode:**

```python
def mat3_frobenius_norm(m):
    """
    Computes the Frobenius norm of a 3x3 matrix.
    m: list of 9 floats [m00, m01, m02, m10, m11, m12, m20, m21, m22]
    """
    sum_sq = 0.0
    for val in m:
        sum_sq += val * val
    return sum_sq ** 0.5

def smat3_frobenius_norm(m):
    """
    Computes the Frobenius norm of a symmetric 3x3 matrix.
    m: list of 6 floats [m00, m01, m02, m11, m12, m22]
    """
    # m00, m11, m22 appear once; off-diagonals appear twice in sum of squares
    sum_sq = (m[0] ** 2) + (m[3] ** 2) + (m[5] ** 2)
    sum_sq += 2 * ((m[1] ** 2) + (m[2] ** 2) + (m[4] ** 2))
    return sum_sq ** 0.5

def mat3_off_diagonal_norm(m):
    """
    Computes the off-diagonal norm of a 3x3 matrix.
    m: list of 9 floats [m00, m01, m02, m10, m11, m12, m20, m21, m22]
    """
    # Sum squares of indices where i != j
    sum_sq = (m[1] ** 2) + (m[2] ** 2) + (m[3] ** 2) + (m[5] ** 2) + (m[6] ** 2) + (m[7] ** 2)
    return sum_sq ** 0.5

def smat3_off_diagonal_norm(m):
    """
    Computes the off-diagonal norm of a symmetric 3x3 matrix.
    m: list of 6 floats [m00, m01, m02, m11, m12, m22]
    """
    # Off-diagonals are m01, m02, m12. In symmetric storage, these are indices 1, 2, 4.
    # Formula: sqrt(2 * (m01^2 + m02^2 + m12^2))
    sum_sq = 2 * ((m[1] ** 2) + (m[2] ** 2) + (m[4] ** 2))
    return sum_sq ** 0.5

def mat3_multiply(a, b):
    """
    Multiplies two 3x3 matrices.
    a, b: lists of 9 floats each
    Returns: list of 9 floats for result matrix C
    """
    c = [0.0] * 9
    for i in range(3):
        for j in range(3):
            sum_val = 0.0
            for k in range(3):
                sum_val += a[i * 3 + k] * b[k * 3 + j]
            c[i * 3 + j] = sum_val
    return c

def mat3_at_a(a):
    """
    Computes A^T * A for a 3x3 matrix A, storing result in a symmetric matrix structure.
    a: list of 9 floats [m00, m01, m02, m10, m11, m12, m20, m21, m22]
    Returns: list of 6 floats [out00, out01, out02, out11, out12, out22]
    """
    out = [0.0] * 6
    # out.m00 = a.m00^2 + a.m10^2 + a.m20^2
    out[0] = a[0]**2 + a[3]**2 + a[6]**2
    # out.m11 = a.m01^2 + a.m11^2 + a.m21^2
    out[3] = a[1]**2 + a[4]**2 + a[7]**2
    # out.m22 = a.m02^2 + a.m12^2 + a.m22^2
    out[5] = a[2]**2 + a[5]**2 + a[8]**2
    # out.m01 = a.m00*a.m01 + a.m10*a.m11 + a.m20*a.m21
    out[1] = a[0]*a[1] + a[3]*a[4] + a[6]*a[7]
    # out.m02 = a.m00*a.m02 + a.m10*a.m12 + a.m20*a.m22
    out[2] = a[0]*a[2] + a[3]*a[5] + a[6]*a[8]
    # out.m12 = a.m01*a.m02 + a.m11*a.m12 + a.m21*a.m22
    out[4] = a[1]*a[2] + a[4]*a[5] + a[7]*a[8]
    return out

def vec4_magnitude(v):
    """
    Computes the Euclidean norm of a 4D vector.
    v: list of 4 floats
    """
    sum_sq = 0.0
    for val in v:
        sum_sq += val * val
    return sum_sq ** 0.5

def mat4_transpose(mat):
    """
    Returns the transpose of a 4x4 matrix.
    mat: list of 16 floats (row-major)
    Returns: list of 16 floats (row-major)
    """
    # Initialize result
    res = [0.0] * 16
    # Loop i from 0 to 3, j from 0 to 3
    for i in range(4):
        for j in range(4):
            # Set res[i][j] = mat[j][i]
            # Index calculation: row * 4 + col
            res[i * 4 + j] = mat[j * 4 + i]
    return res

def mat3_transpose_vec3(mat, xyz):
    """
    Multiplies the transpose of a 3x3 matrix by a 3D vector.
    mat: list of 9 floats [m00, m01, m02, m10, m11, m12, m20, m21, m22]
    xyz: list of 3 floats [x, y, z]
    Returns: list of 3 floats
    """
    # result = mat^T x xyz
    # result_i = sum_j (mat^T)_{ij} * xyz_j = sum_j mat_{ji} * xyz_j
    res = [0.0, 0.0, 0.0]
    for i in range(3):
        sum_val = 0.0
        for j in range(3):
            sum_val += mat[j * 3 + i] * xyz[j]
        res[i] = sum_val
    return res
```

**Edge Cases and Pitfalls:**
*   **Symmetry Assumption:** The `SMat3` formulas assume the input matrix is strictly symmetric. If the input is not symmetric, the `SMat3` norms will yield incorrect results compared to the full `Mat3` norms [S1, unofficial].
*   **Precision:** The library supports both 32-bit and 64-bit floating-point arithmetic for matrix-vector multiplication, which should be selected based on the required precision for the volume rendering task [S3].
*   **Boundary Conditions:** When computing norms, ensure no overflow occurs for very large matrix elements; however, standard IEEE 754 floats handle typical rendering scales without issue [S1, S2, unofficial].

## Subtopics

### [Matrix-Vector Multiplication](4208-matrix-vector-multiplication.md)
Computes the product of a 4x4 transformation matrix and a 4D vector, yielding a transformed 4D vector. This operation is the fundamental arithmetic step for applying affine transformations (rotation, translation, scaling, shear) to points and directions in volume rendering camera models. It differs from scalar-vector multiplication by altering direction and position via linear combination of basis vectors, rather than uniform scaling. See [Matrix-Vector Multiplication](4208-matrix-vector-multiplication.md).

### [Symmetric Matrix Data Structure](6259-symmetric-matrix-data-structure.md)
A compact storage format for 3x3 symmetric matrices, reducing the required memory from nine values to six by exploiting the property $M_{ij} = M_{ji}$. It serves as the foundational data structure for representing covariance matrices in Gaussian Splatting variants and stress tensors in scientific visualization, eliminating redundant storage and ensuring symmetry constraints are maintained by construction. See [Symmetric Matrix Data Structure](6259-symmetric-matrix-data-structure.md).

### Matrix Transpose (3x3)
Returns the transpose of a 4x4 matrix. The implementation initializes a 4x4 matrix and loops `i` from 0 to 3 and `j` from 0 to 3, setting `mat[i][j] = this[j][i]` [S2, unofficial].

### Matrix Transpose (3x3)
Multiplies the transpose of a 3x3 matrix by a 3D vector using 32-bit or 64-bit floating-point arithmetic. The formula is `result = mat^T x xyz`. It corresponds to an inverse linear mapping, such as inverse scaling or inverse rotation [S3].

### Matrix Multiplication (2x3 by 3x3)
Multiplies a 2x3 matrix by a 3x3 matrix, resulting in a 2x3 matrix. It also supports multiplying a 3x3 matrix by a 2x3 matrix, resulting in a 2x3 matrix [S3].

### Matrix Multiplication (3x2 by 2x3)
Multiplies a 3x2 matrix by a 2x3 matrix, resulting in a 3x3 matrix [S3].

### Vector Magnitude
Computes the Euclidean norm (length) of a 4D vector. The implementation returns `Math.sqrt(this.dot(this))`, corresponding to the formula $\|u\| = \sqrt{\sum_{i=0}^{3} u_i^2}$ [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Matrix-vector multiplication is $O(N^2)$ for $N \times N$ matrices. For 3x3, this is constant time $O(1)$ with 9 multiplications and 6 additions. For 4x4, it is $O(1)$ with 16 multiplications and 12 additions.
*   **Memory Complexity:** $O(1)$ for fixed-size matrices. `SMat3` uses 6 floats vs 9 for `Mat3`, reducing memory footprint by 33% [S1, unofficial].
*   **Performance:** Explicit implementations avoid function call overhead and library dependencies, making them suitable for JavaScript environments or embedded systems [S2, unofficial][S3].
*   **Strengths:** Full control over arithmetic precision (32/64-bit), no external dependencies, compact storage for symmetric matrices [S1, S2, unofficial][S3].
*   **Limitations:** No built-in optimization for sparse matrices or large-scale batch operations; manual implementation of all variants required [S3].
*   **When to use:** When implementing custom rendering engines in constrained environments (e.g., WebGL without libraries) or when specific arithmetic control (like symmetric matrix storage) is needed [S1, S2, unofficial].

## Background
The methods are derived from implementations in dual contouring and volume rendering projects. The `MatUtils` functionality is found in the `DualContouringCSharp` repository, which provides C# implementations for mesh generation and octree visualization [S1, unofficial]. The JavaScript variants are sourced from a volume rendering repository using WebGL utilities [S2, unofficial]. The C++ template-based operations are documented in the OpenVDB `nanovdb::math` namespace, which provides high-performance math utilities for volumetric data [S3].
