# Scaling Matrix Construction

Also called: Mat.scale, Scaling Matrix

## Overview
Creates a 4x4 scaling matrix for a scalar or 4D vector `s` [S1, unofficial].

## How it works
**Inputs:**
- `s`: A scalar number or a 4D vector (or 3D vector) [S1, unofficial].

**Outputs:**
- `mat`: A 4x4 matrix [S1, unofficial].

**Data Structure:**
The matrix is stored as a 4x4 array where scaling factors occupy the diagonal elements `[0][0]`, `[1][1]`, and `[2][2]` [S1, unofficial].

**Steps:**
1. Initialize a 4x4 matrix `mat` [S1, unofficial].
2. If `s` is a number, set `mat[0][0] = s`, `mat[1][1] = s`, `mat[2][2] = s` [S1, unofficial].
3. If `s` is a PV (vector), set `mat[0][0] = s[0]`, `mat[1][1] = s[1]`, `mat[2][2] = s[2]` [S1, unofficial].
4. Else throw an error [S1, unofficial].
5. Return `mat` [S1, unofficial].

**Pseudocode:**
```python
def construct_scaling_matrix(s):
    # Initialize 4x4 matrix to zeros [G]
    mat = [[0.0] * 4 for _ in range(4)]
    if isinstance(s, (int, float)):
        mat[0][0] = s
        mat[1][1] = s
        mat[2][2] = s
    elif hasattr(s, '__len__') and len(s) >= 3:
        mat[0][0] = s[0]
        mat[1][1] = s[1]
        mat[2][2] = s[2]
    else:
        raise ValueError("s must be a scalar or a vector with at least 3 components")
    return mat
```

## Subtopics

### Scaling and Rotation Matrix Construction
Constructs a 3x3 transformation matrix by combining scaling and rotation [S2, unofficial]. It creates a diagonal scaling matrix $L$ and multiplies it by a rotation matrix $R$ [S2, unofficial]. Implemented on CUDA for batched operations, it initializes a zero matrix $L$ of shape `(s.shape[0], 3, 3)`, computes $R$ using `build_rotation(r)`, and sets the diagonal elements of $L$ via `L[:,0,0] = s[:,0]`, `L[:,1,1] = s[:,1]`, `L[:,2,2] = s[:,2]` [S2, unofficial].
