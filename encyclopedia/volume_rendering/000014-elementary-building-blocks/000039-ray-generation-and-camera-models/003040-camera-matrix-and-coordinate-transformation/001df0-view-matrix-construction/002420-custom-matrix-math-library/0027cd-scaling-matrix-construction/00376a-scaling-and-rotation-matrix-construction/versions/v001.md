# Scaling and Rotation Matrix Construction
Also called: combined scaling-rotation matrix, S*R matrix construction

## Overview
Constructs a 3x3 transformation matrix by combining anisotropic scaling and rotation. It creates a diagonal scaling matrix $L$ and multiplies it by a rotation matrix $R$. This method is distinct from pure scaling or pure rotation constructions by explicitly fusing these two operations into a single linear transform, typically used in differentiable rendering pipelines where scale and rotation are optimized parameters [S1, unofficial].

## How it works
**Inputs:**
- `s`: A tensor of shape $(N, 3)$ containing $N$ sets of 3D scale factors.
- `r`: A tensor of shape $(N, 3)$ containing $N$ sets of rotation parameters (typically Euler angles or axis-angle, passed to `build_rotation`).

**Outputs:**
- `M`: A tensor of shape $(N, 3, 3)$ containing the combined transformation matrices.

**Data Structures:**
- `L`: Diagonal scaling matrix tensor of shape $(N, 3, 3)$.
- `R`: Rotation matrix tensor of shape $(N, 3, 3)$, output of `build_rotation`.
- `M`: Result tensor of shape $(N, 3, 3)$.

**Steps:**
1. Initialize a zero tensor `L` of shape $(N, 3, 3)$ on the target device (e.g., CUDA).
2. Compute the rotation matrix `R` by calling `build_rotation(r)`.
3. Assign the scale factors to the diagonal elements of `L`:
   - $L_{i,0,0} = s_{i,0}$
   - $L_{i,1,1} = s_{i,1}$
   - $L_{i,2,2} = s_{i,2}$
   for all $i \in [0, N-1]$.
4. Compute the final matrix $M$ as the matrix product $L \times R$.

**Pseudocode:**
```python
def build_scaling_rotation(s, r):
    """
    Constructs a 3x3 transformation matrix by combining scaling and rotation.
    
    Args:
        s: Tensor of shape (N, 3) with scale factors.
        r: Tensor of shape (N, 3) with rotation parameters.
        
    Returns:
        M: Tensor of shape (N, 3, 3) with combined transformation matrices.
    """
    # Initialize zero matrix L of shape (N, 3, 3)
    L = torch.zeros(s.shape[0], 3, 3, device=s.device)
    
    # Compute rotation matrix R using build_rotation(r)
    # Note: build_rotation is assumed to be defined elsewhere in the pipeline
    R = build_rotation(r)
    
    # Set diagonal elements of L
    L[:, 0, 0] = s[:, 0]
    L[:, 1, 1] = s[:, 1]
    L[:, 2, 2] = s[:, 2]
    
    # Compute final matrix M = L @ R
    M = torch.bmm(L, R)
    
    return M
```

**Edge Cases and Pitfalls:**
- **Degenerate Scales:** If any scale factor is zero, the resulting matrix is singular. This may cause issues in inverse transformations or normal calculations [G].
- **Rotation Parameterization:** The correctness of `R` depends entirely on the implementation of `build_rotation`. Ensure `r` matches the expected format (e.g., XYZ Euler angles) [S1, unofficial].
- **Precision:** Matrix multiplication on GPU may introduce small floating-point errors. For high-precision requirements, consider using double precision if supported [G].

## Operating characteristics
- **Time Complexity:** $O(N)$ for diagonal assignment and $O(N)$ for matrix multiplication (since 3x3 is constant size). Total $O(N)$.
- **Memory Complexity:** $O(N)$ for storing the output tensor.
- **Performance:** Efficient on GPU due to parallelizable tensor operations. The use of `torch.bmm` (batched matrix multiplication) ensures optimized execution [S1, unofficial].
- **Strengths:** Simple, differentiable, and integrates well with PyTorch-based optimization pipelines.
- **Limitations:** Does not include translation; requires a separate `build_rotation` function.

## Background
This method is part of the InstantSplat pipeline by NVlabs, used in 3D Gaussian Splatting training. It combines scaling and rotation to form the covariance matrix components for Gaussian primitives [S1, unofficial].
