# Scaling and Rotation Matrix Construction
## Overview
Constructs a 3x3 transformation matrix by combining scaling and rotation [S1, S2, S3, unofficial]. It creates a diagonal scaling matrix $L$ and multiplies it by a rotation matrix $R$ [S1, S2, S3, unofficial]. It is distinguished from [Scaling Matrix Construction](4126-scaling-matrix-construction.md) by the inclusion of rotational degrees of freedom, and from [Transformation Matrix Construction](12879-transformation-matrix-construction.md) by the exclusion of translation [G].
## How it works
**Inputs:**
- `s`: Tensor of scale factors. Shape is `(N, 3)` for batched inputs or `(3,)` for a single primitive [S1, S2, S3, unofficial].
- `r`: Rotation parameters passed to `build_rotation` [S1, S2, S3, unofficial].

**Outputs:**
- `M`: 3x3 transformation matrix of shape `(N, 3, 3)` or `(3, 3)` [S1, S2, S3, unofficial].

**Data Structures:**
- `L`: Diagonal scaling matrix of shape `(N, 3, 3)` [S1, S2, unofficial].
- `R`: Rotation matrix of shape `(N, 3, 3)` [S1, S2, S3, unofficial].

**Steps:**
1. Initialize `L` as a zero tensor of shape `(s.shape[0], 3, 3)` on CUDA [S1, S2, unofficial].
2. Set the diagonal elements of `L`: `L[:,0,0] = s[:,0]`, `L[:,1,1] = s[:,1]`, `L[:,2,2] = s[:,2]` [S1, S2, S3, unofficial].
3. Compute the rotation matrix `R` using `build_rotation(r)` [S1, S2, S3, unofficial].
4. Return the product `L @ R` [S1, S3, unofficial].

**Pseudocode:**
```python
import torch

def build_scaling_rotation(s, r):
    # Step 1: Initialize diagonal scaling matrix L
    # L shape: (N, 3, 3)
    L = torch.zeros(s.shape[0], 3, 3, device=s.device, dtype=s.dtype)
    
    # Step 2: Set diagonal elements
    L[:, 0, 0] = s[:, 0]
    L[:, 1, 1] = s[:, 1]
    L[:, 2, 2] = s[:, 2]
    
    # Step 3: Compute rotation matrix R
    R = build_rotation(r)
    
    # Step 4: Multiply L and R
    M = L @ R
    return M

def build_rotation(r):
    # [G] Standard quaternion to rotation matrix conversion.
    # Assumes r is a tensor of shape (N, 4) with quaternion components (w, x, y, z).
    w, x, y, z = torch.unbind(r, dim=-1)
    N = r.shape[0]
    R = torch.zeros(N, 3, 3, device=r.device, dtype=r.dtype)
    R[:, 0, 0] = 1 - 2 * (y**2 + z**2)
    R[:, 0, 1] = 2 * (x * y - z * w)
    R[:, 0, 2] = 2 * (x * z + y * w)
    R[:, 1, 0] = 2 * (x * y + z * w)
    R[:, 1, 1] = 1 - 2 * (x**2 + z**2)
    R[:, 1, 2] = 2 * (y * z - x * w)
    R[:, 2, 0] = 2 * (x * z - y * w)
    R[:, 2, 1] = 2 * (y * z + x * w)
    R[:, 2, 2] = 1 - 2 * (x**2 + y**2)
    return R
```
