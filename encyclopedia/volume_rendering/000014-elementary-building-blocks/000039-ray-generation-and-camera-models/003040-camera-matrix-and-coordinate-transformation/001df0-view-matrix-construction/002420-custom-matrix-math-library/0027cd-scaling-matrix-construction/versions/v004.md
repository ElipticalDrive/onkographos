# Scaling Matrix Construction

Also called: Mat.scale, Scaling Matrix

## Overview
Creates a 4x4 scaling matrix for a scalar or 4D vector `s` [S1, unofficial]. It applies uniform or non-uniform scaling to 3D coordinates within a homogeneous coordinate system [G]. It is distinguished from [Scaling and Rotation Matrix Construction](7986-scaling-and-rotation-matrix-construction.md) by excluding rotational degrees of freedom, and from [Transformation Matrix Construction](12879-transformation-matrix-construction.md) by excluding translation [G].

## How it works
**Inputs:**
- `s`: A scalar number or a vector.
- `mat`: A 4x4 matrix structure.

**Outputs:**
- The modified `mat` representing the scaling transformation [S1, unofficial].

**Data Structures:**
- `mat`: 4x4 matrix. Indices `mat[i][j]` or `mat[i*4+j]` correspond to row `i`, column `j` [G].

**Steps:**
1. Initialize `mat` as a 4x4 matrix [S1, unofficial].
2. Extract scale factors: if `s` is a number, $s_x = s_y = s_z = s$; if `s` is a vector, $s_x = s[0]$, $s_y = s[1]$, $s_z = s[2]$ [S1, unofficial].
3. Set the diagonal elements: $mat[0][0] = s_x$, $mat[1][1] = s_y$, $mat[2][2] = s_z$ [S1, unofficial].
4. Leave the fourth row and column unchanged (standard homogeneous coordinates set $mat[3][3]=1$ and others to 0) [G].
5. Return `mat` [S1, unofficial].

**Formulas:**
$$
mat[0][0] = s_x, \quad mat[1][1] = s_y, \quad mat[2][2] = s_z
$$
where $s_x, s_y, s_z$ are the scale factors derived from `s` [S1, unofficial].

**Parameters:**
Not given in the sources.

**Edge Cases:**
- If `s` is neither a number nor a vector, an error is thrown [S1, unofficial].

**Pseudocode:**
```python
def construct_scaling_matrix(s):
    # Initialize 4x4 matrix with zeros
    mat = [[0.0 for _ in range(4)] for _ in range(4)]
    
    # Extract scale factors from input s
    if isinstance(s, (int, float)):
        sx, sy, sz = s, s, s
    elif len(s) >= 3:
        sx, sy, sz = s[0], s[1], s[2]
    else:
        raise ValueError("s must be a number or a vector with at least 3 components")
        
    # Set diagonal elements as specified
    mat[0][0] = sx
    mat[1][1] = sy
    mat[2][2] = sz
    
    # Set homogeneous component to 1 for valid transformation [G]
    mat[3][3] = 1.0
    
    return mat
```

## Subtopics

### [Scaling and Rotation Matrix Construction](7986-scaling-and-rotation-matrix-construction.md)
Constructs a 3x3 transformation matrix by combining scaling and rotation. It is distinguished from this method by the inclusion of rotational degrees of freedom. Choose when orientation changes are needed alongside size changes.

### [Transformation Matrix Construction](12879-transformation-matrix-construction.md)
Constructs a full 4x4 transformation matrix. It is distinguished from this method by the inclusion of translation [G]. Choose when position changes are also required.

## Operating characteristics
- **Time Complexity:** $O(1)$, constant number of assignments [G].
- **Memory Complexity:** $O(1)$, fixed 4x4 matrix [G].
- **Measured Performance:** Not given in the sources.
- **Strengths:** Simple, fast, standard for uniform/non-uniform scaling [G].
- **Limitations:** Does not handle rotation or translation [G].
