# Self-Calibration via Absolute Dual Quadric

Also called: Linear Self-Calibration, Projective Self-Calibration

## Overview
This method recovers metric reconstruction (camera intrinsics and 3D structure) from a projective reconstruction by imposing linear constraints on the absolute dual quadric $\Omega^*$ [S1, unofficial]. It differs from non-linear bundle adjustment by formulating the calibration as a linear system solvable via Singular Value Decomposition (SVD), requiring at least three views for a unique solution [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $m$ projective camera matrices $P_i$ ($i=1 \dots m$) obtained from projective factorization.
*   **Output:** The calibration matrix $H$ (transforming projective space to metric space) and the metric reconstruction.

**Data Structures:**
*   **Absolute Dual Quadric ($\Omega^*$):** A $4 \times 4$ symmetric matrix representing the dual of the absolute quadric in 3D projective space [S1, unofficial].
*   **Dual Image of the Absolute Conic ($\omega_i^*$):** A $3 \times 3$ symmetric matrix derived from $\Omega^*$ and the camera projection matrix $P_i$ [S1, unofficial].

**Assumptions:**
To generate linear constraints, the following intrinsic parameter assumptions are made for all views [S1, unofficial]:
1.  Principal point is at the center of the image plane: $\varpi_{13}^* = \varpi_{23}^* = 0$.
2.  Zero skew: $\varpi_{12}^* = 0$.
3.  Aspect ratio equal to 1: $\varpi_{11}^* = \varpi_{22}^*$.

These assumptions leave only the focal length as a variable parameter [S1, unofficial].

**Formulas:**
The relationship between the dual image of the absolute conic $\omega_i^*$ and the absolute dual quadric $\Omega^*$ is given by [S1, unofficial]:

$$ \omega_i^* = P_i \Omega^* P_i^T $$

Expanding this for the $i$-th view, where $K_i$ is the upper-left $3 \times 3$ intrinsic matrix and $p_i$ is the camera center, we have [S1, unofficial]:

$$ \begin{bmatrix} K_i K_i^T & -K_i K_i^T p_i \\ -p_i^T K_i K_i^T & p_i^T K_i K_i^T p_i \end{bmatrix} = \begin{bmatrix} \varpi_1^* & -\varpi_1^* p_i \\ -p_i^T \varpi_1^* & p_i^T \varpi_1^* p_i \end{bmatrix} $$

where $\varpi^*$ represents the elements of $\omega_i^*$ [S1, unofficial].

**Steps:**
1.  For each view $i = 1 \dots m$, compute the dual image of the absolute conic $\omega_i^*$ using the projective camera matrix $P_i$ and the unknown $\Omega^*$:
    $$ \omega_i^* = P_i \Omega^* P_i^T $$
2.  Extract the elements of $\omega_i^*$ (denoted $\varpi_{jk}^*$) [S1, unofficial].
3.  Apply the linear constraints based on the assumptions:
    *   $\varpi_{13}^{*(i)} = 0$
    *   $\varpi_{23}^{*(i)} = 0$
    *   $\varpi_{12}^{*(i)} = 0$
    *   $\varpi_{11}^{*(i)} - \varpi_{22}^{*(i)} = 0$
4.  Each view provides 4 linear equations on the 10 unique elements of $\Omega^*$. Form an overdetermined linear system $A \mathbf{x} = \mathbf{0}$ of size $4m \times 10$, where $\mathbf{x}$ is the vectorized form of $\Omega^*$ [S1, unofficial].
5.  Solve the system using Singular Value Decomposition (SVD). The solution is the right singular vector corresponding to the smallest singular value. A unique solution exists for $m \ge 3$ [S1, unofficial].
6.  Reconstruct $\Omega^*$ from the solution vector $\mathbf{x}$ [S1, unofficial].
7.  Determine the calibration matrix $H$ by decomposing $\Omega^*$ [S1, unofficial].
8.  Back-substitute $H$ into the projective camera matrices $P_i$ to compute the final metric reconstruction (intrinsic matrix $K$ and extrinsic parameters $R, t$) [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def self_calibration_linear(projective_cameras):
    """
    projective_cameras: List of m 3x4 projection matrices P_i.
    Returns: Calibration matrix H (4x4) transforming projective to metric space.
    """
    m = len(projective_cameras)
    if m < 3:
        raise ValueError("At least 3 views are required for a unique solution.")

    # Map index j in 0..9 to (k, l) with k <= l for the upper triangle of Omega_star
    indices = [(0,0), (0,1), (0,2), (0,3), (1,1), (1,2), (1,3), (2,2), (2,3), (3,3)]
    
    A = []
    
    for i in range(m):
        P = projective_cameras[i] # 3x4 matrix
        
        # Generate 4 constraints for this view
        # Constraint 1: omega_i_star[0, 2] = 0
        A.append(_get_constraint_row(P, 0, 2))
        # Constraint 2: omega_i_star[1, 2] = 0
        A.append(_get_constraint_row(P, 1, 2))
        # Constraint 3: omega_i_star[0, 1] = 0
        A.append(_get_constraint_row(P, 0, 1))
        # Constraint 4: omega_i_star[0, 0] - omega_i_star[1, 1] = 0
        A.append(_get_constraint_row(P, 0, 0) - _get_constraint_row(P, 1, 1))

    A = np.array(A)
    
    # Solve Ax = 0 using SVD
    U, S, Vt = np.linalg.svd(A)
    x = Vt[-1, :]
    
    # Reconstruct Omega_star
    Omega_star = np.zeros((4, 4))
    for idx, (r, c) in enumerate(indices):
        val = x[idx]
        Omega_star[r, c] = val
        Omega_star[c, r] = val
        
    # Decompose Omega_star to find H
    # Omega_star = H * diag(1,1,1,0) * H^T
    # The upper-left 3x3 block of Omega_star equals H_3x3 * H_3x3^T
    Omega_upper = Omega_star[:3, :3]
    
    # Cholesky decomposition to get H_3x3
    try:
        H_3x3 = np.linalg.cholesky(Omega_upper)
    except np.linalg.LinAlgError:
        # Fallback to eigenvalue decomposition if not positive definite
        eigenvalues, eigenvectors = np.linalg.eigh(Omega_upper)
        eigenvalues = np.maximum(eigenvalues, 1e-10)
        H_3x3 = eigenvectors @ np.diag(np.sqrt(eigenvalues))
        
    H = np.eye(4)
    H[:3, :3] = H_3x3
    
    return H

def _get_constraint_row(P, r, c):
    """Compute the row in A corresponding to omega_i_star[r, c] = 0."""
    row = np.zeros(10)
    for idx, (k, l) in enumerate(indices):
        if k == l:
            row[idx] += P[r, k] * P[c, k]
        else:
            row[idx] += P[r, k] * P[c, l] + P[r, l] * P[c, k]
    return row
```

**Parameters:**
*   $m$: Number of views. Minimum value required for a unique solution is 3 [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision:** The linear solution is sensitive to noise; results are typically refined with non-linear optimization [S1, unofficial].
*   **Degenerate Input:** Pure translation or insufficient motion may prevent unique focal length determination.
*   **Assumptions Violation:** Incorrect principal point, non-zero skew, or non-unit aspect ratio will invalidate the linear constraints [S1, unofficial].

## Subtopics

### Non-linear Bundle Adjustment
Refines the metric reconstruction by minimizing reprojection error between observed and predicted image points, jointly optimizing 3D structure, camera pose, and calibration [S1, unofficial].

### Projective Factorization
Provides the prerequisite projective camera matrices $P_i$ and 3D points, recovering the scene up to a projective transformation [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(m)$ for constraint generation and $O(1)$ for SVD on the fixed $4m \times 10$ system. Very fast compared to non-linear methods.
*   **Memory Complexity:** $O(m)$ to store constraints.
*   **Strengths:** Closed-form linear solution, simple to implement, computationally efficient.
*   **Limitations:** Relies on strict intrinsic assumptions (fixed principal point, zero skew, unit aspect ratio). Sensitive to noise and does not handle varying intrinsics across views without modification.
*   **When to use:** Quick initial calibration estimate when intrinsic assumptions hold approximately.
*   **When not to use:** High precision is required or intrinsic assumptions are violated; use non-linear bundle adjustment instead.

## Background
Developed within projective geometry to recover metric structure from uncalibrated views by exploiting the invariance of the absolute dual quadric $\Omega^*$ under camera motion. The linear SVD formulation is applied in accelerated volumetric reconstruction pipelines [S1, unofficial].
