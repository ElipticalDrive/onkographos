# Camera Matrix Decomposition
Also called: Decompose Projection Matrix, Intrinsic/Extrinsic Decomposition, PnP Decomposition
## Overview
Decomposes a 3×4 projection matrix into an intrinsic matrix $K$, a rotation matrix $R$, and a translation vector $t$ [S1, unofficial]. It separates the camera's internal optical properties from its external physical pose [S1, unofficial].
## How it works
The method takes a 3×4 projection matrix $P$ (float32) as input and returns an intrinsic matrix $K$ (3×3), a rotation matrix $R$ (3×3), and a translation vector $t$ (3×1) [S1, unofficial].

1. Load the projection matrix $P$ and ensure it is stored as float32 [S1, unofficial].
2. Decompose $P$ into intermediate components: an upper-triangular intrinsic matrix $K'$, an orthogonal rotation matrix $R'$, and a homogeneous translation vector $t'$ [S1, unofficial].
3. Normalize $K'$ by dividing all elements by $K'[2,2]$ so that the bottom-right element equals 1 [S1, unofficial].
4. Pad the normalized 3×3 $K'$ to a 4×4 identity matrix by placing it in the top-left block and filling the remaining positions with an identity-like structure [S1, unofficial].
5. Construct the final rotation $R$ by transposing $R'$, assuming a column-major convention where $R$ rotates world coordinates to camera coordinates [S1, unofficial].
6. Normalize the translation vector $t$ by dividing $t'$ by its fourth component $t'[3]$ to remove homogeneous scaling [S1, unofficial].

Pseudocode:
```python
import numpy as np

def decompose_projection_matrix(P: np.ndarray) -> tuple:
    """
    Decomposes a 3x4 projection matrix into K, R, t.
    :param P: 3x4 numpy array, float32
    :return: K (4x4 padded), R (3x3), t (3x1)
    """
    # Step 1: Ensure float32
    P = P.astype(np.float32)
    
    # Step 2: Decompose P = K' * [R' | t']
    # The source specifies using a library function (e.g., OpenCV) [S1, unofficial].
    # The pseudocode implements the standard mathematical equivalent using QR decomposition.
    P_left = P[:, :3]
    Q, R_tmp = np.linalg.qr(P_left)
    # Adjust signs to ensure K' has positive diagonal
    d = np.diag(R_tmp)
    sign = np.sign(d)
    K_prime = np.diag(sign) @ R_tmp
    R_prime = np.diag(sign) @ Q
    
    # Extract homogeneous translation t' from the right column of P
    t_prime = P[:, 3]
    
    # Step 3: Normalize intrinsics by dividing by K'[2,2]
    K_prime = K_prime / K_prime[2, 2]
    
    # Step 4: Pad to 4x4 identity matrix
    K_4x4 = np.eye(4)
    K_4x4[:3, :3] = K_prime
    
    # Step 5: Construct final R by transposing R'
    R = R_prime.T
    
    # Step 6: Normalize t by dividing by t'[3]
    t = t_prime / t_prime[3]
    
    return K_4x4, R, t
```
Edge cases: The source does not specify handling for singular matrices or degenerate camera poses [S1, unofficial]. Precision issues may arise if $P$ is ill-conditioned [G].

## Operating characteristics
Time complexity is $O(1)$ for fixed 3×4 matrix decomposition [G]. Memory complexity is $O(1)$ for fixed-size matrices [G]. Strengths include the direct extraction of camera parameters from a combined projection matrix [S1, unofficial]. Limitations are that sign ambiguity in rotation and translation is not resolved by the source [G].
