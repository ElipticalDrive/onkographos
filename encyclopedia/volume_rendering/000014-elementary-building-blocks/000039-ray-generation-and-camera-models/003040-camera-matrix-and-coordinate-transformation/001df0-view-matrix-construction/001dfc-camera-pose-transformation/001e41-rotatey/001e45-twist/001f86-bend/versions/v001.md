# Bend
Also called: Simple Brush Deformation
## Overview
Bend is a geometric deformation operation for Signed Distance Fields (SDFs) that curves a shape around the X-axis [S1, S3, unofficial]. It solves the problem of creating organic, curved variations of rigid primitives, such as bending a cylinder into an arc [S3, unofficial]. Unlike [Twist](1722-twist.md), which rotates geometry around the Y-axis with a linear or angular progression, Bend applies a spatially varying rotation around the X-axis, creating a smooth arc [S1, S3, unofficial].
## How it works
**Inputs and Outputs:**
- Input: A point $p$ in 3D space, an SDF primitive function $S$, and a bend degree parameter $k$ (float) [S1, S3, unofficial].
- Output: The deformed SDF value at $p$ [S1, unofficial].

**Data Structures:**
- No persistent data structures. The operation is point-wise and stateless [S1, S2, unofficial].

**Steps:**
1.  **Coordinate Transformation:** Transform the point $p$ into the local space of the deformation. According to [S1, unofficial], this involves rotating the point by the transpose of a rotation matrix $R$ around the X-axis. The rotation angle is determined by $k \cdot p_x$.
    - Calculate $c = \cos(k \cdot p_x)$ and $s = \sin(k \cdot p_x)$ [S1, unofficial].
    - Construct the 2D rotation matrix $M$ for the YZ plane:
      $$ M = \begin{bmatrix} c & -s \\ s & c \end{bmatrix} $$
    - Apply $M$ to the Y and Z components of $p$ to get $p'$ [S1, unofficial].
    - The X component remains unchanged: $p'_x = p_x$.
2.  **SDF Evaluation:** Evaluate the original SDF primitive at the transformed point: $d = S(p')$ [S1, unofficial].
3.  **Result:** Return $d$ [S1, unofficial].

*Note on Source Disagreement:*
[S1, unofficial] describes a standard rotational bending where the rotation angle is proportional to the X-coordinate. The rotation is applied to the YZ plane, effectively bending the shape along the X-axis.
[S2, unofficial] describes a "Simple Brush Deformation" using a Gaussian falloff based on a force vector. This appears to be a different implementation or a more general deformation class. Given the parent [Twist](1722-twist.md) and sibling [RotateY](1721-rotatey.md) context, the rotational definition from [S1, unofficial] and [S3, unofficial] is the primary definition for "Bend" in this family. [S2, unofficial] is likely a separate brush-based deformation tool.
[S3, unofficial] confirms the X-axis bending and the use of a float parameter for degree.

**Pseudocode:**
```python
import math

def bend(p, sdf, k):
    """
    Bends the SDF around the X-axis by degree k.
    :param p: vec3, input point
    :param sdf: function, the base SDF primitive
    :param k: float, bend degree
    :return: float, deformed SDF value
    """
    # Step 1: Calculate rotation components based on X coordinate
    angle = k * p.x
    c = math.cos(angle)
    s = math.sin(angle)
    
    # Step 2: Construct rotation matrix for YZ plane and apply to p
    # Original p.y, p.z
    # Rotated p'_y, p'_z
    p_prime_y = c * p.y - s * p.z
    p_prime_z = s * p.y + c * p.z
    
    # X component remains unchanged
    p_prime_x = p.x
    
    # Step 3: Evaluate SDF at transformed point
    p_prime = (p_prime_x, p_prime_y, p_prime_z)
    d = sdf(p_prime)
    
    return d
```

**Parameters:**
- $k$: Bend degree. A float input determining the intensity of the bend [S3, unofficial]. Typical values are small floats (e.g., 0.1 to 1.0) depending on the scale of the scene [S3, unofficial].

**Edge Cases and Pitfalls:**
- Precision: For large $k$ or large $p_x$, the rotation angle can become large, potentially causing self-intersection or folding of the SDF if the primitive is not convex or if the bend is too severe [G].
- Boundary: The bend is applied globally to the entire space. If the primitive is bounded, the deformation may extend beyond the intended object bounds if not clamped [G].

## Operating characteristics
- Time Complexity: $O(1)$ per point evaluation, as it involves a constant number of trigonometric operations and one SDF evaluation.
- Memory Complexity: $O(1)$, no additional memory required.
- Strengths: Simple to implement, computationally cheap, effective for creating curved organic shapes.
- Limitations: Can cause self-intersection if the bend degree is too high relative to the object's thickness. Not suitable for creating complex, non-uniform deformations without additional control points.
- When to use: When you need to curve a straight primitive (like a cylinder or box) into an arc.
- When not to use: When you need a twist or torsion effect (use [Twist](1722-twist.md)) or a simple rigid rotation (use [RotateX](1720-rotatex.md)).

## Background
Bend is a standard geometric operation in raymarching and SDF-based rendering, often used in procedural modeling and real-time graphics [S3, unofficial]. It was popularized in the context of real-time raymarching shaders, such as those found in the "seasquid" demo and various SDF tutorials [S3, unofficial]. The operation is a fundamental building block for creating more complex organic shapes by combining simple primitives with deformations [S3, unofficial].
