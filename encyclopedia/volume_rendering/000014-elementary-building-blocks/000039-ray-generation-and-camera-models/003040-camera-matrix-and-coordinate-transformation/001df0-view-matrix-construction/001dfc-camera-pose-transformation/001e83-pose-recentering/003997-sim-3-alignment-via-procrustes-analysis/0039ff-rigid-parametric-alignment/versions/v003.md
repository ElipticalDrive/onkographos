# Rigid Parametric Alignment

Also called: Closed-form Rigid Alignment, Rigid Alignment via SVD

## Overview
Rigid Parametric Alignment is a differentiable solver that estimates a 3D rigid transformation $T \in SE(3)$ from point correspondences by minimizing the reprojection error in a closed form using Singular Value Decomposition (SVD) [S1]. It builds on [Sim(3) Alignment via Procrustes Analysis](8526-sim-3-alignment-via-procrustes-analysis.md) by restricting the transformation group to rigid motions (rotation and translation only), thereby removing the scale component [G]. Unlike [Test-time Optimization with Sim(3) Initialization](8565-test-time-optimization-with-sim-3-initialization.md), which uses optimization-based approaches, this method provides an analytical solution [S1].

## How it works
**Inputs:**
- A set of $N$ corresponding 3D points in the source frame, denoted as $\{x^j\}_{j=1}^N$ [G].
- A set of $N$ corresponding 3D points in the target frame, denoted as $\{y^j\}_{j=1}^N$ [G].
- The current estimated transformation $T = [R|t] \in SE(3)$, where $R \in SO(3)$ and $t \in \mathbb{R}^3$ [S1].

**Outputs:**
- The optimal rotation matrix $R \in SO(3)$ [S1].
- The optimal translation vector $t \in \mathbb{R}^3$ [S1].
- The composite rigid transformation $T = [R|t]$ [S1].

**Data Structures:**
- Points $x^j$ and $y^j$ are stored as $3 \times N$ matrices or lists of 3D vectors [G].
- The cross-covariance matrix $H$ is a $3 \times 3$ matrix [G].
- SVD components $U, S, V$ are $3 \times 3$ matrices [G].

**Steps:**
1. Compute the centroid of the source points:
   $$ \bar{x} = \frac{1}{N} \sum_{j=1}^N x^j $$
   [G]
2. Compute the centroid of the target points:
   $$ \bar{y} = \frac{1}{N} \sum_{j=1}^N y^j $$
   [G]
3. Construct the cross-covariance matrix $H$:
   $$ H = \sum_{j=1}^N (x^j - \bar{x})(y^j - \bar{y})^T $$
   [S1, G] (Note: The source text [S1] Eq. (12) contains a typographical error $T^j x^j - T\bar{x}$; the standard Procrustes formulation uses centered target points [G].)
4. Perform Singular Value Decomposition (SVD) on $H$:
   $$ H = U S V^T $$
   [S1]
5. Compute the optimal rotation $R$:
   $$ R = V U^T $$
   [S1] (A determinant check $d = \text{sign}(\det(V U^T))$ is applied to $V$ to ensure $R \in SO(3)$ rather than $O(3)$ [G].)
6. Compute the optimal translation $t$:
   $$ t = \bar{y} - R \bar{x} $$
   [S1, G] (Corrects the source note's ambiguous formula $t = -R\bar{x} + T\bar{x}$ [S1].)

**Pseudocode:**
```python
import numpy as np

def rigid_parametric_alignment(points_source, points_target):
    """
    Computes the rigid transformation T = [R|t] that aligns points_source to points_target.
    
    Args:
        points_source: numpy array of shape (N, 3)
        points_target: numpy array of shape (N, 3)
        
    Returns:
        R: numpy array of shape (3, 3)
        t: numpy array of shape (3,)
    """
    # 1. Compute centroids
    centroid_source = np.mean(points_source, axis=0)
    centroid_target = np.mean(points_target, axis=0)
    
    # 2. Center the points
    x_centered = points_source - centroid_source
    y_centered = points_target - centroid_target
    
    # 3. Compute cross-covariance matrix H
    H = x_centered.T @ y_centered
    
    # 4. SVD of H
    U, S, Vt = np.linalg.svd(H)
    V = Vt.T
    
    # 5. Compute Rotation R with determinant check for proper rotation [G]
    d = np.sign(np.linalg.det(V @ U.T))
    R = V @ np.diag([1, 1, d]) @ U.T
    
    # 6. Compute Translation t
    t = centroid_target - R @ centroid_source
    
    return R, t
```

**Parameters:**
- The warp neural field $f_W$ uses a ReLU MLP with six 256-dimensional hidden units for the rigid alignment experiment [S1].
- The multiplier $\lambda$ of the global alignment objective is set to $1 \times 10^2$ [S1].

**Edge Cases and Pitfalls:**
- If the point set is degenerate (e.g., all points are collinear or coincident), the matrix $H$ may be rank-deficient, leading to ambiguous rotation solutions [G].
- The source formula for $t$ contains a typo; implementation must use the centroid of the target points [S1, G].

## Subtopics

### [Iterative Closest Point (ICP)](10563-iterative-closest-point-icp.md)
Iterative Closest Point (ICP) is a registration algorithm used to align two point sets, typically a reconstructed point cloud and a ground truth mesh, by finding an optimal rigid transformation. It builds on [Rigid Parametric Alignment](8609-rigid-parametric-alignment.md) by iteratively refining the transformation estimate through correspondence matching, rather than solving for a transformation from pre-established correspondences in a single step [G]. Unlike differentiable renderers which optimize pose via gradient descent on pixel errors, ICP operates directly in geometric space.

### Homography Parametric Alignment
A differentiable solver that estimates a 2D homography transformation $T \in SL(3)$ from point correspondences by solving a homogeneous linear least squares problem via SVD [S1]. The homography constraint in homogeneous coordinates is formulated as:
$$ \begin{bmatrix} 0 & x^j_1 & x^j_2 & 1 \end{bmatrix} = T \begin{bmatrix} x^j_1 \\ x^j_2 \\ 1 \end{bmatrix} $$
This is rearranged into the linear system $A_j h = 0$, where $h$ is the vectorized form of $T$ [S1]. Unlike rigid alignment, this operates in 2D projective space [G].

## Operating characteristics
- Time complexity is dominated by the SVD of a $3 \times 3$ matrix, which is $O(1)$ constant time [G].
- Memory complexity is $O(N)$ to store the point correspondences and $O(1)$ for the transformation matrices [G].
- Strengths include providing a closed-form, deterministic solution without iterative optimization, making it computationally efficient and stable for small to medium datasets [G].
- Limitations include assuming exact correspondences are known, sensitivity to outliers in the point correspondences, and inability to handle scale changes unlike Sim(3) [G].
- It should be used when a rigid transformation is sufficient and correspondences are available [G].
- It should not be used when scale variation is present (use Sim(3)) or when correspondences are unknown or outlier-heavy (use ICP or RANSAC) [G].

## Background
Rigid Parametric Alignment is used in the context of Local-to-Global Registration for Bundle-Adjusting Neural Radiance Fields (L2G-NeRF) [S1]. It was introduced by the authors of L2G-NeRF to allow the local-to-global process to shift focus from flexible pixel-wise alignment to constrained parametric alignment [S1]. The method leverages the mathematical properties of Procrustes analysis to solve for the rigid component of the camera pose transformation [S1].
