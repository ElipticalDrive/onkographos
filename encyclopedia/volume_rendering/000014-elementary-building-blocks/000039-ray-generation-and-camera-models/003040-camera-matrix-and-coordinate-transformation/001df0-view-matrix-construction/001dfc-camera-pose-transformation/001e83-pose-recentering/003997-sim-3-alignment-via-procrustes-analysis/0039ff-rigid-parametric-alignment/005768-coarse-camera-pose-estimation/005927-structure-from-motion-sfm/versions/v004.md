# Structure-from-Motion (SfM)

Also called: COLMAP SfM, Camera Pose Estimation using SfM, HLOC SfM, LocalRF SfM

## Overview
Structure-from-Motion (SfM) is a photogrammetric technique that recovers camera poses (extrinsics), camera calibration parameters (intrinsics), and a sparse 3D point cloud from a set of uncalibrated photographs [S2, unofficial]. It serves as the foundational preprocessing step for modern neural rendering pipelines, such as NeRF and Gaussian Splatting, by providing the necessary geometric context (camera positions and orientations) required to optimize scene representations against source images [S1][S2, unofficial]. Unlike incremental methods that build the scene sequentially, global variants solve for all parameters simultaneously to avoid drift, while deep learning-based variants replace traditional feature matching with neural networks to improve robustness in textureless or repetitive regions [S2, unofficial][S4].

## How it works
The standard SfM pipeline consists of feature extraction, matching, geometric verification, incremental reconstruction, and bundle adjustment [S2, unofficial].

### Inputs and Outputs
*   **Input:** A set of $N$ images $\{I_1, \dots, I_N\}$, optionally with EXIF metadata (focal length, principal point, lens distortion).
*   **Output:**
    *   Camera poses: Rotation matrices $R_i \in SO(3)$ and translation vectors $t_i \in \mathbb{R}^3$ for each image $i$.
    *   Intrinsics: Focal length $f$, principal point $(c_x, c_y)$, and distortion coefficients $k_1, k_2, \dots$ [S2, unofficial].
    *   Sparse 3D points: A set of points $P_j \in \mathbb{R}^3$ with associated 2D projections in the images [S2, unofficial].

### Data Structures
*   **Keypoint:** A structure containing $(u, v)$ coordinates, scale, orientation, and a descriptor vector $d \in \mathbb{R}^D$ (e.g., 128 dimensions for SIFT) [S2, unofficial].
*   **Match:** A pair of keypoint indices $(k_a, k_b)$ from images $I_a$ and $I_b$ with a distance metric (e.g., Euclidean distance between descriptors) [S2, unofficial].
*   **Camera Model:** Pinhole model with optional radial/tangential distortion. Intrinsics are often treated as unknowns to be optimized [S2, unofficial].

### Algorithm Steps

1.  **Feature Detection:** Detect distinctive keypoints (corners, spots, texture) in each image.
    *   *Method:* Use SIFT (Scale-Invariant Feature Transform) or learned detectors like SuperPoint [S1][S2, unofficial][S4].
    *   *Note:* SIFT is monochrome, discarding hue and saturation [S2, unofficial].
    *   *Output:* Set of keypoints $K_i$ for each image $I_i$.

2.  **Descriptor Computation:** Compute a descriptor vector for each keypoint that summarizes surrounding pixels, surviving rotation, scale, and brightness changes [S2, unofficial].
    *   *Method:* SIFT descriptors or SuperPoint descriptors [S1][S2, unofficial][S4].

3.  **Pairwise Matching:** Compare descriptors between images to find candidate matches.
    *   *Method:* For small sets, compare all $N^2$ pairs. For large sets, use a vocabulary tree to avoid $O(N^2)$ comparisons [S2, unofficial].
    *   *Deep Alternative:* Use LightGlue to match descriptors extracted by SuperPoint [S4].

4.  **Geometric Verification:** Discard incorrect matches using RANSAC (Random Sample Consensus) [S2, unofficial].
    *   *Method:*
        1.  Randomly select a minimal subset of matches (e.g., 5 points for the 5-point algorithm).
        2.  Estimate the fundamental matrix $F$ (uncalibrated) or essential matrix $E$ (calibrated) [S2, unofficial].
        3.  Check if remaining matches satisfy the epipolar constraint: $x'^T F x = 0$ [S2, unofficial].
        4.  Count inliers (matches with reprojection error below a threshold).
        5.  Keep the model with the most inliers [S2, unofficial].

5.  **Incremental Reconstruction:** Build the scene incrementally [S2, unofficial].
    *   **Step 5.1: Initialization:** Select a good starting pair of images with a wide baseline and many verified matches.
    *   **Step 5.2: Triangulation:** Reconstruct the two camera poses and triangulate 3D points from the matched features.
        *   *Triangulation Formula:* Given two camera matrices $P_1 = [I | 0]$ and $P_2 = [R | t]$, and corresponding 2D points $x_1, x_2$, the 3D point $X$ is found by minimizing the algebraic distance or using linear triangulation via SVD [S2, unofficial].
    *   **Step 5.3: Registration:** For each new image, find matches with already reconstructed points.
    *   **Step 5.4: PnP:** Solve the Perspective-n-Point (PnP) problem to estimate the new camera pose given known 3D points and their 2D projections [S2, unofficial].
    *   **Step 5.5: Triangulation:** Triangulate new 3D points from the newly registered camera and existing points [S2, unofficial].
    *   **Step 5.6: Iteration:** Repeat Steps 5.3–5.5 until all images are registered [S2, unofficial].

6.  **Bundle Adjustment (BA):** Minimize the total reprojection error by optimizing all camera poses and 3D points simultaneously [S2, unofficial].
    *   *Objective Function:*
        $$ E = \sum_{i} \sum_{j} \| x_{ij} - \pi(P_i, X_j) \|^2 $$
        where $x_{ij}$ is the observed 2D projection of 3D point $X_j$ in image $i$, $P_i$ is the camera matrix for image $i$, and $\pi$ is the projection function including distortion [S2, unofficial].
    *   *Self-Calibration:* Intrinsics (focal length, principal point) are treated as unknowns and optimized alongside poses and points, assuming shared intrinsics for images from the same camera [S2, unofficial].

### Pseudocode

```python
def structure_from_motion(images):
    """
    Perform Structure-from-Motion to recover camera poses, intrinsics, and 3D points.
    """
    # Step 1 & 2: Feature Detection and Descriptor Computation
    keypoints = {}
    descriptors = {}
    for i, img in enumerate(images):
        keypoints[i], descriptors[i] = detect_features(img) # e.g., SIFT or SuperPoint
    
    # Step 3: Pairwise Matching
    matches = {}
    for i in range(len(images)):
        for j in range(i + 1, len(images)):
            # Match descriptors between image i and j
            candidate_matches = match_descriptors(descriptors[i], descriptors[j])
            matches[(i, j)] = candidate_matches
            
    # Step 4: Geometric Verification (RANSAC)
    verified_matches = {}
    for (i, j), candidates in matches.items():
        # Estimate Fundamental Matrix using RANSAC
        inliers, F = ransac_fundamental_matrix(candidates)
        if len(inliers) > MIN_MATCHES:
            verified_matches[(i, j)] = inliers
            
    # Step 5: Incremental Reconstruction
    # Initialize with the pair having the most verified matches
    init_pair = max(verified_matches, key=lambda k: len(verified_matches[k]))
    i0, j0 = init_pair
    
    # Reconstruct initial cameras and points
    cameras = {i0: init_camera_pose(), j0: init_camera_pose()}
    points_3d = triangulate_points(cameras[i0], cameras[j0], verified_matches[(i0, j0)])
    registered_images = {i0, j0}
    
    # Register remaining images
    while len(registered_images) < len(images):
        # Find unregistered image with most matches to registered images
        best_img = None
        best_matches = []
        for img_idx in range(len(images)):
            if img_idx not in registered_images:
                current_matches = []
                for reg_img in registered_images:
                    pair = (min(img_idx, reg_img), max(img_idx, reg_img))
                    if pair in verified_matches:
                        current_matches.extend(verified_matches[pair])
                if len(current_matches) > len(best_matches):
                    best_matches = current_matches
                    best_img = img_idx
        
        if best_img is None:
            break # Cannot register more images
            
        # Step 5.4: PnP
        # Match best_img keypoints to known 3D points
        pnp_matches = match_to_3d_points(keypoints[best_img], points_3d)
        R, t = solve_pnp(pnp_matches)
        cameras[best_img] = create_camera_matrix(R, t)
        registered_images.add(best_img)
        
        # Step 5.5: Triangulate new points
        for reg_img in registered_images:
            if reg_img == best_img: continue
            pair = (min(best_img, reg_img), max(best_img, reg_img))
            if pair in verified_matches:
                new_points = triangulate_points(cameras[best_img], cameras[reg_img], verified_matches[pair])
                points_3d.update(new_points)
                
    # Step 6: Bundle Adjustment
    # Optimize all camera poses, intrinsics, and 3D points
    cameras, points_3d, intrinsics = bundle_adjustment(cameras, points_3d, verified_matches, images)
    
    return cameras, intrinsics, points_3d

def triangulate_points(cam1, cam2, matches):
    """
    Triangulate 3D points from two camera views and matched 2D points.
    """
    points_3d = {}
    for match in matches:
        # Linear triangulation using SVD
        # Construct matrix A such that A * X = 0
        # A = [x1 * P1[3,:] - P1[0,:]; x1 * P1[2,:] - P1[1,:]; ...]
        # X is the first 3 components of the null space vector
        X = linear_triangulation(cam1, cam2, match.u1, match.u2)
        points_3d[match.id] = X
    return points_3d

def bundle_adjustment(cameras, points_3d, matches, images):
    """
    Non-linear least squares optimization to minimize reprojection error.
    """
    # Initialize parameters
    params = pack_parameters(cameras, points_3d)
    
    # Define residual function
    def residual(params):
        unpacked = unpack_parameters(params)
        residuals = []
        for (i, j), match_list in matches.items():
            cam_i = unpacked.cameras[i]
            cam_j = unpacked.cameras[j]
            for match in match_list:
                # Project 3D point to image i
                proj_i = project(unpacked.points_3d[match.id], cam_i)
                # Project 3D point to image j
                proj_j = project(unpacked.points_3d[match.id], cam_j)
                # Compute error
                err_i = match.u1 - proj_i
                err_j = match.u2 - proj_j
                residuals.extend([err_i[0], err_i[1], err_j[0], err_j[1]])
        return residuals
    
    # Optimize using Levenberg-Marquardt or similar
    optimized_params = optimize(residual, params)
    return unpack_parameters(optimized_params)
```

### Parameters
*   **Feature Detector:** SIFT (default in COLMAP) or SuperPoint [S1][S2, unofficial][S4].
*   **Matcher:** Brute-force or LightGlue [S1, S4].
*   **RANSAC Threshold:** Distance threshold for epipolar geometry verification [S2, unofficial].
*   **Intrinsics:** Treated as unknowns; shared across images from the same camera [S2, unofficial].

### Edge Cases and Pitfalls
*   **Zooming:** If photos are taken with zooming, intrinsics change, violating the shared-intrinsics assumption [S2, unofficial].
*   **Rolling Shutter:** Fast motion with rolling-shutter sensors smears geometry, violating the pinhole model [S2, unofficial].
*   **Cropped/Resized Images:** Invalidate principal point and focal length relative to the original sensor [S2, unofficial].
*   **Motion Blur:** Smears feature points, causing bad matches. Mitigation: drop blurriest frames or shoot at high shutter speeds [S2, unofficial].
*   **Tiny Baselines:** Processing too many nearly-identical video frames wastes compute and provides little new triangulation information [S2, unofficial].

## Subtopics

### Canonical Frame Estimation via Facial Landmarks
A method to estimate a canonical frame of reference for selfie and full-body captures using facial landmarks, enabling automatic generation of novel view trajectories [S3]. It computes 2D facial landmarks using MediaPipe’s face mesh, triangulates them in 3D using SfM camera poses, and sets a canonical coordinate frame centered at the facemesh with +y up, +x right, -z into the face, scaled so the interpupillary distance is 6 cm [S3]. This is only correct if the subject is static, but works sufficiently well even with head rotation [S3].

### Deep Image Matching Initialization
An initialization pipeline that replaces traditional sparse SfM methods with a deep learning framework to construct a robust initial point cloud [S4]. It uses SuperPoint for feature extraction and LightGlue for feature matching [S4]. This approach offers better robustness, efficiency, and scalability compared to traditional SfM/MVS methods [S4].

## Operating characteristics
*   **Time Complexity:** Incremental SfM is generally $O(N^2)$ for matching, but can be reduced with vocabulary trees. Bundle adjustment is iterative and depends on the number of points and cameras.
*   **Measured Performance:**
    *   For 310 frames: COLMAP takes 00:08:26, HLOC takes 01:08:39, LocalRF takes 23:20:52 [S1].
    *   For 1392 frames: COLMAP takes 00:49:29, HLOC takes 21:51:34, LocalRF takes 75:10:54 [S1].
    *   For 2784 frames: COLMAP takes 04:32:53 [S1].
    *   COLMAP is 8x faster than HLOC for 310 frames and 26.5x faster for 1392 frames [S1].
*   **Strengths:** COLMAP is the de facto standard, robust, and produces compatible output [S2, unofficial]. GLOMAP solves globally and is faster on large sets [S2, unofficial].
*   **Limitations:** HLOC and LocalRF have long running times [S1]. LocalRF is unsuitable for large frame counts due to extensive running time [S1]. COLMAP performs well only with dense views (2784 frames), while HLOC is better for sparse views (310, 1392 frames) [S1].
*   **When to Use:** Use COLMAP for dense views and standard pipelines. Use HLOC for sparse views. Use LocalRF for long-range trajectories and unbounded scenes if time permits [S1]. Use Deep Image Matching (SuperPoint+LightGlue) for improved robustness in challenging textures [S4].

## Background
Structure-from-Motion is a classic technique in photogrammetry and computer vision, predating Gaussian Splatting by decades [S2, unofficial]. COLMAP, developed by Schönberger and Frahm (CVPR 2016), is the de facto standard open-source SfM and Multi-View Stereo package [S2, unofficial]. It is widely used to generate camera poses and sparse point clouds for NeRF and Gaussian Splatting training [S1][S2, unofficial]. Recent developments include GLOMAP for global reconstruction [S2, unofficial] and deep learning-based methods like HLOC and LocalRF for improved robustness and scalability [S1, S4].
