# Absolute Trajectory Error Computation

Also called: ATE, Absolute Trajectory Error Measurement, Ego-Motion Estimation Evaluation

## Overview
Absolute Trajectory Error (ATE) computes the integrated distance between all aligned estimated pose positions relative to a ground truth trajectory [S2, unofficial]. It measures ego-motion estimation performance [S1]. Unlike local metrics that evaluate frame-to-frame consistency, ATE quantifies cumulative drift along the full path [G].

## How it works
**Inputs:**
1. Aligned ground truth trajectory: $P_{gt} = \{T_{gt, i}, R_{gt, i}\}$ for $i=1 \dots N$, where $T$ is translation and $R$ is rotation [S2, unofficial].
2. Aligned estimated trajectory: $P_{es} = \{T_{es, i}, R_{es, i}\}$ for $i=1 \dots N$ [S2, unofficial].
*(Note: Alignment via Sim(3) Procrustes analysis is a prerequisite step [G].)*

**Outputs:**
1. Translation error magnitude $e_{trans}$ [S2, unofficial].
2. Rotation error magnitude $e_{rot}$ [S2, unofficial].
3. Euler angle errors $e_{ypr}$ [S2, unofficial].
4. Scale drift percentage $e_{scale\_perc}$ [S2, unofficial].

**Data Structures:**
* $T_{gt}, T_{es}$: Arrays of shape $(N, 3)$ containing 3D coordinates [S2, unofficial].
* $R_{gt}, R_{es}$: Arrays of shape $(N, 3, 3)$ containing rotation matrices derived from input quaternions [S2, unofficial].
* $e_{trans}, e_{rot}$: Arrays of shape $(N)$ containing scalar errors [S2, unofficial].
* $e_{ypr}$: Array of shape $(N, 3)$ containing Euler angles [S2, unofficial].
* $e_{scale\_perc}$: Array of shape $(N-1)$ containing scale drift percentages [S2, unofficial].

**Steps:**
1. **Translation Error:** Compute the difference vector $e_{trans\_vec, i} = T_{gt, i} - T_{es, i}$ and its magnitude $e_{trans, i} = \sqrt{\sum_{j=1}^{3} (e_{trans\_vec, i, j})^2}$ [S2, unofficial].
2. **Rotation Error:** Compute the error rotation matrix $e_{R, i} = R_{es, i} R_{gt, i}^{-1} = R_{es, i} R_{gt, i}^\top$ [S2, unofficial]. Extract Euler angles $e_{ypr, i}$ using a `rzyx` convention [S2, unofficial]. Compute the rotation error magnitude $e_{rot, i} = \frac{180}{\pi} \| \log(e_{R, i}) \|_2$, where $\log(\cdot)$ maps the rotation matrix to the Lie algebra $\mathfrak{so}(3)$ [S2, unofficial].
3. **Scale Drift:** Compute motion vectors $motion_{gt, i} = T_{gt, i} - T_{gt, i-1}$ and $motion_{es, i} = T_{es, i} - T_{es, i-1}$ for $i=2 \dots N$ [S2, unofficial]. Compute distances $dist_{gt, i} = \| motion_{gt, i} \|_2$ and $dist_{es, i} = \| motion_{es, i} \|_2$ [S2, unofficial]. Calculate percentage error $e_{scale\_perc, i} = \left| \frac{dist_{es, i}}{dist_{gt, i}} - 1 \right| \times 100$ [S2, unofficial].

**Pseudocode:**
```python
import numpy as np
from scipy.spatial.transform import Rotation

def compute_ate(T_gt, R_gt, T_es, R_es):
    """
    Compute Absolute Trajectory Error metrics.
    
    Args:
        T_gt: (N, 3) aligned ground truth translations.
        R_gt: (N, 3, 3) aligned ground truth rotation matrices.
        T_es: (N, 3) aligned estimated translations.
        R_es: (N, 3, 3) aligned estimated rotation matrices.
        
    Returns:
        e_trans: (N,) translation error magnitudes.
        e_rot: (N,) rotation error magnitudes in degrees.
        e_ypr: (N, 3) Euler angle errors (rzyx convention).
        e_scale_perc: (N-1) scale drift percentages.
    """
    N = T_gt.shape[0]
    e_trans = np.zeros(N)
    e_rot = np.zeros(N)
    e_ypr = np.zeros((N, 3))
    e_scale_perc = np.zeros(N - 1)
    
    # Step 1: Translation Error
    e_trans_vec = T_gt - T_es
    e_trans = np.sqrt(np.sum(e_trans_vec**2, axis=1))
    
    # Step 2: Rotation Error
    e_R = R_es @ R_gt.transpose(0, 2, 1)
    
    # Compute rotation error magnitude: norm of axis-angle vector (logmap)
    rot_vecs = np.array([Rotation.from_matrix(e_R[i]).as_rotvec() for i in range(N)])
    e_rot = np.degrees(np.linalg.norm(rot_vecs, axis=1))
    
    # Extract Euler angles (rzyx convention)
    e_ypr = np.array([Rotation.from_matrix(e_R[i]).as_euler('rzyx') for i in range(N)])
    
    # Step 3: Scale Drift
    motion_gt = np.diff(T_gt, axis=0)
    motion_es = np.diff(T_es, axis=0)
    dist_gt = np.linalg.norm(motion_gt, axis=1)
    dist_es = np.linalg.norm(motion_es, axis=1)
    e_scale_perc = np.abs((np.divide(dist_es, dist_gt) - 1.0) * 100.0)
    
    return e_trans, e_rot, e_ypr, e_scale_perc
```

## Operating characteristics
* Measured Performance: On the original data baseline (Gaussian blur $9 \times 9 \times 9$, $\sigma=4/3$), the Mean ATE is $0.10 \pm 0.17$ m and the Median ATE is $0.038$ m [S1].

## Background
ATE is used to evaluate reconstruction fidelity and ego-motion estimation reliability on RGB-D datasets, such as the freiburg-1 collection [S1]. The metric relies on ground truth poses provided by an independent external camera-tracking system [S1].
