# Rigid Parametric Alignment

Also called: Closed-form Rigid Alignment, Rigid Alignment via SVD

## Overview
Rigid Parametric Alignment is a differentiable solver that estimates a 3D rigid transformation $T \in SE(3)$ from point correspondences by minimizing the reprojection error in a closed form using Singular Value Decomposition (SVD) [S1]. It builds on [Sim(3) Alignment via Procrustes Analysis](8526-sim-3-alignment-via-procrustes-analysis.md) by restricting the transformation group to rigid motions (rotation and translation only), thereby removing the scale component [S1]. Unlike [Test-time Optimization with Sim(3) Initialization](8565-test-time-optimization-with-sim-3-initialization.md), which refines poses via iterative gradient descent, this method provides an instantaneous, analytical update for the pose parameters [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $N$ corresponding 3D points in the source frame $\{x^j\}_{j=1}^N$ and their target positions $\{Tx^j\}_{j=1}^N$ (where $T$ is the unknown transformation). In practice, these are often camera centers or feature points derived from image correspondences [S1].
*   **Output:** The optimal rigid transformation matrix $T = [R|t] \in SE(3)$, where $R \in SO(3)$ is the rotation matrix and $t \in \mathbb{R}^3$ is the translation vector [S1].

**Data Structures:**
*   **Point Sets:** Two arrays of size $N \times 3$ containing the coordinates of the source points $x^j$ and the target points $y^j = Tx^j$.
*   **Covariance Matrix:** A $3 \times 3$ matrix $H$ computed from the centered point sets.

**Steps:**
1.  **Compute Centroids:** Calculate the mean of the source points $\bar{x}$ and the target points $\bar{y}$ (denoted as $T\bar{x}$ in the source notation, representing the mean of the transformed points) [S1]:
    $$ \bar{x} = \frac{1}{N} \sum_{j=1}^N x^j $$
    $$ \bar{y} = \frac{1}{N} \sum_{j=1}^N y^j $$

2.  **Center the Points:** Subtract the centroids from the respective point sets to obtain centered coordinates:
    $$ \tilde{x}^j = x^j - \bar{x} $$
    $$ \tilde{y}^j = y^j - \bar{y} $$

3.  **Compute Covariance Matrix:** Calculate the $3 \times 3$ covariance matrix $H$ [S1]:
    $$ H = \sum_{j=1}^N \tilde{x}^j (\tilde{y}^j)^T $$
    *Note: The source [S1] defines $H$ in Eq. (12) as $\sum (x^j - \bar{x})(Tx^j - T\bar{x})^T$. This is equivalent to the standard Procrustes covariance matrix formulation.*

4.  **Singular Value Decomposition (SVD):** Perform SVD on $H$ [S1]:
    $$ H = U S V^T $$
    where $U$ and $V$ are orthogonal matrices and $S$ is a diagonal matrix of singular values.

5.  **Compute Rotation:** Calculate the optimal rotation matrix $R$ [S1]:
    $$ R = V U^T $$
    *Guard:* To ensure a proper rotation (determinant +1) and avoid reflection, if $\det(R) = -1$, multiply the last column of $V$ by $-1$ before computing $R$ [G]. This is a standard requirement for $SO(3)$ that ensures the transformation is rigid rather than improper.

6.  **Compute Translation:** Calculate the translation vector $t$ using the centroids and the computed rotation [S1]:
    $$ t = \bar{y} - R \bar{x} $$
    *Note: The source [S1] writes this as $t = -R\bar{x} + T\bar{x}$, where $T\bar{x}$ represents the centroid of the target points $\bar{y}$.*

7.  **Construct Transformation:** Assemble the final rigid transformation matrix $T \in SE(3)$ [S1]:
    $$ T = \begin{bmatrix} R & t \\ 0 & 1 \end{bmatrix} $$

**Parameters:**
*   In the context of neural field alignment (e.g., L2G-NeRF), the rigid alignment is often parameterized by a warp neural field $f_W$. A typical implementation uses a ReLU MLP with six 256-dimensional hidden units [S1].

**Edge Cases and Pitfalls:**
*   **Degenerate Input:** If all points are collinear or coincident, the covariance matrix $H$ will be rank-deficient, leading to ambiguous rotation solutions.
*   **Reflection:** As noted in step 5, failing to check the determinant of $R$ can result in a reflection (improper rotation), which is not a valid rigid body transformation in $SE(3)$.
*   **Precision:** SVD is generally numerically stable, but floating-point errors in $H$ can propagate. Using double precision for the SVD step is recommended for high-accuracy applications [G].

## Subtopics

### Homography Parametric Alignment
A differentiable solver that estimates a 2D homography transformation $T \in SL(3)$ from point correspondences by solving a homogeneous linear least squares problem via SVD [S1]. Unlike the 3D rigid case which solves for rotation and translation separately, this method solves for a $3 \times 3$ matrix directly. The homography constraint in homogeneous coordinates is formulated as:
$$ \begin{bmatrix} 0 & x^j_1 & x^j_2 & 1 \end{bmatrix} = T \begin{bmatrix} x^j_1 & x^j_2 & 1 \end{bmatrix} $$
This is rearranged into a linear system $A_j h = 0$, where $h$ is the vectorized form of $T$ [S1]. It is used when the transformation is planar or when projecting 3D points onto a 2D plane with perspective distortion.

## Operating characteristics
*   **Time Complexity:** Dominated by the SVD of a $3 \times 3$ matrix, which is $O(1)$ constant time. The overall complexity is linear with respect to the number of points $N$ for computing the covariance matrix $H$.
*   **Memory Complexity:** $O(N)$ to store the point sets and $O(1)$ for the covariance matrix and SVD intermediates.
*   **Strengths:** Provides a closed-form, differentiable solution that can be integrated into neural network training pipelines (e.g., as a layer in a warp field) without iterative optimization steps [S1]. It is computationally efficient and robust to noise compared to iterative methods for small correspondences.
*   **Limitations:** Only applicable to rigid transformations (no scale or shear). Requires known correspondences between points. Sensitive to outliers in the input point sets; robust variants (like RANSAC) are needed if correspondences are noisy [G].
*   **When to use:** When aligning camera poses or point clouds where the transformation is known to be rigid and correspondences are available. It serves as a fast initialization or differentiable layer in neural rendering frameworks.
*   **When not to use:** When the transformation involves scale changes (use Sim(3) Alignment) or when correspondences are unknown or highly ambiguous (use ICP or feature-based methods).

## Background
Rigid Parametric Alignment originates from the field of computer vision and geometric registration, specifically the Procrustes analysis framework. In the context of neural rendering, it was adapted by [S1] (L2G-NeRF) to enable differentiable global registration of Neural Radiance Fields. The method allows the network to learn a rigid transformation that aligns local neural fields to a global coordinate system by minimizing reprojection errors analytically. This approach was introduced to improve upon coarse-to-fine strategies like BARF by providing a differentiable, closed-form alignment mechanism that can be backpropagated through the pose parameters [S1].
