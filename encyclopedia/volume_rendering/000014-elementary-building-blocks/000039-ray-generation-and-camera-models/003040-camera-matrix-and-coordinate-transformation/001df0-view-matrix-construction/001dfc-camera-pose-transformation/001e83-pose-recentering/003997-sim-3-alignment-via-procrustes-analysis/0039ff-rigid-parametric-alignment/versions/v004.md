# Rigid Parametric Alignment

Also called: Closed-form Rigid Alignment, Rigid Alignment via SVD

## Overview
Rigid Parametric Alignment is a differentiable solver that estimates a 3D rigid transformation $T \in SE(3)$ from point correspondences by minimizing the reprojection error in a closed form using Singular Value Decomposition (SVD) [S1]. It differs from its parent [Sim(3) Alignment via Procrustes Analysis](8526-sim-3-alignment-via-procrustes-analysis.md) by restricting the transformation to the Special Euclidean group $SE(3)$, thereby excluding scaling and shear components, and from [Test-time Optimization with Sim(3) Initialization](8565-test-time-optimization-with-sim-3-initialization.md) by providing an analytical solution rather than an iterative gradient-based optimization [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $N$ corresponding 3D points in the source frame $\{x^j\}_{j=1}^N$ and the target frame $\{T^* x^j\}_{j=1}^N$, where $T^*$ is the ground truth or reference transformation [S1].
*   **Output:** The optimal rigid transformation $T = [R|t] \in SE(3)$, where $R \in SO(3)$ is the rotation matrix and $t \in \mathbb{R}^3$ is the translation vector [S1].

**Data Structures:**
*   **Centroids:** $\bar{x}$ and $\bar{T}$, computed as the mean of the source and target point sets respectively.
*   **Covariance Matrix:** $H \in \mathbb{R}^{3 \times 3}$, computed from the centered points.
*   **SVD Result:** $U, S, V^T$ from the decomposition of $H$.

**Steps:**
1.  Compute the centroids of the source points $\bar{x} = \frac{1}{N} \sum_{j=1}^N x^j$ and the target points $\bar{T} = \frac{1}{N} \sum_{j=1}^N T^* x^j$ [S1].
2.  Compute the covariance matrix $H$ using the centered points:
    $$ H = \sum_{j=1}^N (x^j - \bar{x})(T^* x^j - \bar{T})^T $$
    [S1, Eq. 12]
3.  Perform Singular Value Decomposition (SVD) on $H$:
    $$ H = U S V^T $$
    [S1, Eq. 13]
4.  Compute the optimal rotation $R$:
    $$ R = V U^T $$
    [S1, Eq. 14]
5.  Compute the optimal translation $t$:
    $$ t = -R\bar{x} + \bar{T} $$
    [S1, Eq. 14]
6.  Construct the rigid transformation matrix $T$:
    $$ T = [R|t] \in SE(3) $$
    [S1]

**Pseudocode:**
```python
import numpy as np

def rigid_parametric_alignment(points_source, points_target):
    """
    Computes the rigid transformation T = [R|t] aligning points_source to points_target.
    
    Args:
        points_source: np.ndarray of shape (N, 3), source 3D points.
        points_target: np.ndarray of shape (N, 3), target 3D points.
        
    Returns:
        R: np.ndarray of shape (3, 3), rotation matrix.
        t: np.ndarray of shape (3,), translation vector.
    """
    # Step 1: Compute centroids
    mean_source = np.mean(points_source, axis=0)
    mean_target = np.mean(points_target, axis=0)
    
    # Step 2: Center the points
    centered_source = points_source - mean_source
    centered_target = points_target - mean_target
    
    # Step 3: Compute covariance matrix H
    # H = sum (x_centered * T_centered^T)
    H = np.dot(centered_source.T, centered_target)
    
    # Step 4: SVD of H
    U, S, Vt = np.linalg.svd(H)
    
    # Step 5: Compute Rotation R
    # R = V * U^T
    R = np.dot(Vt.T, U.T)
    
    # Step 6: Compute Translation t
    # t = -R * mean_source + mean_target
    t = -np.dot(R, mean_source) + mean_target
    
    return R, t
```

**Parameters:**
*   In the context of the L2G-NeRF implementation, the warp neural field $f_W$ used for rigid alignment experiments employs a ReLU MLP with six 256-dimensional hidden units [S1].
*   The multiplier $\lambda$ for the global alignment objective is set to $1 \times 10^2$ [S1].

**Edge Cases and Pitfalls:**
*   **Degenerate Input:** If the point correspondences are collinear or coplanar, the covariance matrix $H$ may be rank-deficient, leading to ambiguous rotation solutions. The sources do not specify a regularization strategy for this case [S1].
*   **Reflection:** The formula $R = V U^T$ can result in a reflection (determinant -1) if the SVD does not enforce proper rotation. The sources do not explicitly mention a correction step (e.g., checking $\det(R)$ and flipping the last column of $V$ if necessary) [S1].

## Subtopics

### [Iterative Closest Point (ICP)](10563-iterative-closest-point-icp.md)
Iterative Closest Point (ICP) is a registration algorithm used to align two point sets, typically a reconstructed point cloud and a ground truth mesh, by finding an optimal rigid transformation. It builds on [Rigid Parametric Alignment](8609-rigid-parametric-alignment.md) by iteratively refining the transformation estimate through correspondence matching, rather than solving for a transformation from pre-established correspondences in a single step [G]. Unlike differentiable renderers which optimize pose via gradient descent on pixel errors, ICP operates directly in geometric space.

### [Coarse Camera Pose Estimation](15954-coarse-camera-pose-estimation.md)
Coarse Camera Pose Estimation initializes the camera pose for a target image by establishing 2D-3D correspondences between the target image and a registered reference image using a scene regressor, then solving for the pose via Direct Linear Transform (DSAC) and Perspective-n-Point (PnP) with RANSAC. It differs from [Iterative Closest Point (ICP)](10563-iterative-closest-point-icp.md) by relying on learned semantic or geometric features from a neural scene regressor rather than iterative point-cloud alignment, and from [Rigid Parametric Alignment](8609-rigid-parametric-alignment.md) by providing the initial seed for incremental training rather than refining an existing estimate via closed-form SVD.

### Homography Parametric Alignment
Homography Parametric Alignment is a differentiable solver that estimates a 2D homography transformation $T \in SL(3)$ from point correspondences by solving a homogeneous linear least squares problem via SVD [S1]. The homography constraint in homogeneous coordinates is:
$$ \begin{bmatrix} 0 & x^j_1 & x^j_2 & 1 \end{bmatrix} = T \begin{bmatrix} x^j_1 \\ x^j_2 \\ 1 \end{bmatrix} $$
which is rearranged into the linear system $A_j h = 0$ [S1].

## Operating characteristics
**Time and Memory Complexity:**
The method relies on SVD, which has a time complexity of $O(N)$ for computing the covariance matrix and $O(1)$ for the $3 \times 3$ SVD decomposition, making it computationally efficient and suitable for real-time or differentiable training pipelines [S1].

**Strengths and Limitations:**
*   **Strengths:** Provides a closed-form, differentiable solution for rigid alignment, allowing gradients to flow through the transformation parameters to the underlying neural fields (e.g., $f_W$) [S1].
*   **Limitations:** Restricted to rigid transformations ($SE(3)$), making it unsuitable for scenes with non-rigid deformations or scaling changes, which require the parent [Sim(3) Alignment via Procrustes Analysis](8526-sim-3-alignment-via-procrustes-analysis.md) [S1].

**When to Use:**
Use when aligning camera poses or point clouds where the relative transformation is known to be rigid (rotation and translation only) and a differentiable, closed-form solution is preferred over iterative optimization [S1].

## Background
Rigid Parametric Alignment was introduced in the context of Local-to-Global Registration for Bundle-Adjusting Neural Radiance Fields (L2G-NeRF) [S1]. It serves as a differentiable layer within the neural rendering pipeline to align local neural fields to a global coordinate system [S1]. The method leverages the mathematical properties of Procrustes analysis specifically for the rigid case, utilizing SVD to minimize the reprojection error analytically [S1].
