# Coarse Camera Pose Estimation


## Overview
Coarse Camera Pose Estimation estimates initial extrinsic parameters for unposed target images relative to a registered reference image using a learned scene regressor [S1, unofficial]. It initializes camera poses in neural radiance field training by converting predicted 3D points into 2D-3D correspondences and solving for the pose via Perspective-n-Point (PnP) [S1, unofficial]. It differs from [Iterative Closest Point (ICP)](10563-iterative-closest-point-icp.md) by relying on a neural scene representation to provide dense 3D structure rather than iterative point-to-point alignment, and from [Structure-from-Motion (SfM)](16341-structure-from-motion-sfm.md) by operating incrementally on a learned regressor rather than globally on feature matches [S1, unofficial].

## How it works
**Inputs:**
- Registered reference image $I_{ref}$ (or $I_i$) [S1, unofficial].
- Target image $I_k$ to be registered [S1, unofficial].
- Camera intrinsic matrix $K$ [G].
- Inlier threshold $s_{inlier}$ (set to 5,000) [S1, unofficial].
- Reprojection error threshold (set to $\le 6$ pixels) [S1, unofficial].

**Outputs:**
- Coarse camera pose $T_{coarse}$ for $I_k$ [S1, unofficial].
- Inlier count $S_k$ [S1, unofficial].

**Data Structures:**
- Scene Regressor $f_{SCR}$: A neural network that takes $I_{ref}$ and $I_k$ and outputs a set of 3D points $\{X_k\}$ in the global coordinate frame [S1, unofficial].
- Pixel Coordinates $\{u_k\}$: 2D coordinates of pixels in $I_k$ [G].
- 3D Points $\{X_k\}$: Predicted 3D coordinates corresponding to $\{u_k\}$ [S1, unofficial].

**Steps:**
1. **Scene Regression:** Pass $I_{ref}$ and $I_k$ to the scene regressor $f_{SCR}$ to obtain the set of 3D points $\{X_k\}$ in the global coordinate frame [S1, unofficial].
   $$ \{X_k\} = f_{SCR}(I_{ref}, I_k) $$
2. **Correspondence Generation:** Construct 2D-3D correspondences $\{(u_k, X_k)\}$ using the pixel coordinates $\{u_k\}$ from $I_k$ and the predicted 3D points $\{X_k\}$ [S1, unofficial].
3. **Pose Solving:** Solve for the coarse camera pose $T_{coarse}$ using a PnP solver with RANSAC (specifically DSAC, modified for non-square focal lengths) [S1, unofficial].
   $$ T_{coarse}, S_k = \text{PnP}(K, \{(u_k, X_k)\}) $$
   where $S_k$ is the number of inliers [S1, unofficial].
4. **Validation:** Add the target image $I_k$ to the training buffer only if $S_k > s_{inlier}$ [S1, unofficial].

**Parameters:**
- $s_{inlier}$: Inlier threshold. Set to 5,000 [S1, unofficial].
- Reprojection error threshold: Set to $\le 6$ pixels [S1, unofficial].
- DSAC Modification: Supports different focal lengths for the image x-axis and y-axis [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Gauge Ambiguity:** The camera pose of the seed image is fixed during optimization to resolve gauge ambiguity [S1, unofficial].
- **Scale Ambiguity:** The scaling factor between the seed image and its most similar adjacent image is fixed [S1, unofficial].
- **Pose Accuracy:** Coarse poses may be inaccurate if the scene regressor has not seen the target images; a separate MLP pose refiner was found ineffective for transformer-based regressors [S1, unofficial].
- **Initialization:** The seed image is selected as the reference image. Subsequent reference images are selected from registered images that connect to the most unregistered images [S1, unofficial].

**Pseudocode:**
```python
def coarse_camera_pose_estimation(I_ref, I_k, K, s_inlier=5000, reproj_thresh=6.0):
    # Step 1: Predict 3D points {X_k} in global frame using scene regressor [S1, unofficial]
    X_k = neural_network_forward(I_ref, I_k)

    # Step 2: Extract 2D pixel coordinates {u_k} from target image [G]
    H, W = I_k.shape[:2]
    u_k = [(y, x) for y in range(H) for x in range(W)]

    # Step 3: Form 2D-3D correspondences [S1, unofficial]
    correspondences = list(zip(u_k, X_k))

    # Step 4: Solve for coarse pose and inlier count using PnP with RANSAC [S1, unofficial]
    best_pose = None
    best_inliers = 0
    for _ in range(1000): # Standard RANSAC iterations [G]
        sample = random.sample(correspondences, 3) # Minimal sample for PnP [G]
        # DSAC modified for non-square focal lengths [S1, unofficial]
        pose = compute_pose_svd(K, sample)
        inliers = 0
        for (u, X) in correspondences:
            # Project X using pose and K, compute reprojection error
            X_cam = pose[:3, :] @ X + pose[:3, 3]
            u_proj = K @ X_cam
            u_proj = u_proj[:2] / u_proj[2]
            err = ((u[0] - u_proj[0])**2 + (u[1] - u_proj[1])**2)**0.5
            if err <= reproj_thresh:
                inliers += 1
        if inliers > best_inliers:
            best_inliers = inliers
            best_pose = pose

    S_k = best_inliers
    # Step 5: Validate registration [S1, unofficial]
    if S_k > s_inlier:
        return best_pose, True
    return None, False
```

## Subtopics

### [Structure-from-Motion (SfM)](16341-structure-from-motion-sfm.md)
SfM recovers poses globally from uncalibrated photos, providing the geometric constraints for radiance fields. It differs from Coarse Camera Pose Estimation by not relying on a sequential learned regressor but on feature matching and triangulation [G].

## Operating characteristics
- **Time Complexity:** Depends on the inference time of the scene regressor $f_{SCR}$ and the PnP solver [S1, unofficial].
- **Memory Complexity:** Requires storing the scene regressor parameters and the 3D points $\{X_k\}$ for the current batch [S1, unofficial].
- **Performance:** The method relies on the accuracy of the scene regressor; poses are inaccurate if the regressor has not seen the images [S1, unofficial].
- **Strengths:** Enables training from unposed images without traditional SfM pipelines [S1, unofficial]. Incremental registration repeats until all images are registered, allowing scaling to large datasets [S1, unofficial].
- **Limitations:** Requires a trained scene regressor [S1, unofficial]. The fixed threshold of 5,000 inliers may not be optimal for all scenes [S1, unofficial].
- **When to use:** When initializing neural radiance field training from unposed images and a scene regressor is available [S1, unofficial].
- **When not to use:** When high-precision initial poses are required without further refinement, or when computational resources for the regressor are limited [S1, unofficial].

## Background
Coarse Camera Pose Estimation is part of the ZeroGS pipeline, which trains 3D Gaussian Splatting from unposed images [S1, unofficial]. It was introduced in the paper "ZeroGS: Training 3D Gaussian Splatting from Unposed Images" [S1, unofficial]. The method builds on the idea of using a learned scene regressor to predict 3D structure, which is then used to solve for camera poses via PnP [S1, unofficial]. It addresses the limitation of previous methods that required posed images or relied on less accurate pose refinement techniques [S1, unofficial].
