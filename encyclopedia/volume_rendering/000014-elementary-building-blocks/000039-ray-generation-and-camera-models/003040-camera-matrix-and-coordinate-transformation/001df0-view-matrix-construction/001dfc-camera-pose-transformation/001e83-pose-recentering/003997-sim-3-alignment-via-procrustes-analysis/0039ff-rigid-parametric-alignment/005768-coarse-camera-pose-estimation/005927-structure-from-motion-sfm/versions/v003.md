# Structure-from-Motion (SfM)

Also called: COLMAP SfM, Camera Pose Estimation using SfM, HLOC SfM, LocalRF SfM

## Overview
Structure-from-Motion (SfM) estimates the 3D structure of a scene and the camera poses for a set of input images by identifying corresponding features across views [S1]. In the context of volume rendering pipelines, it provides the essential geometric initialization (camera extrinsics and intrinsics) required for training Neural Radiance Fields (NeRFs) or other implicit representations [S1]. It is distinguished from its siblings by its reliance on feature matching and bundle adjustment to recover pose, whereas methods like LocalRF [S1] or deep initialization [S3] may use different optimization strategies or learning-based matching.

## How it works
**Inputs:** A set of $n_{frame}$ extracted video frames or images.
**Outputs:** A set of $n_{pose}$ camera poses (extrinsics) and potentially a sparse point cloud, where $n_{pose} \le n_{frame}$ depending on the method's success rate [S1].

The general pipeline involves feature extraction, matching, and pose estimation. Specific implementations vary:

### COLMAP SfM
1.  **Feature Extraction:** Detect and describe keypoints using Scale-Invariant Feature Transform (SIFT) [S1].
2.  **Matching:** Match descriptors between image pairs [S1].
3.  **Pose Estimation:** Estimate camera poses using the matched features [S1].
    *   *Note:* COLMAP performs well only with dense views (e.g., $n_{frame} = 2784$) but may fail or yield fewer poses ($n_{pose} < n_{frame}$) with sparse views [S1].

### HLOC SfM
1.  **Feature Extraction:** Use SuperPoint to detect keypoints and compute descriptors [S1].
2.  **Matching:** Use SuperGlue to match descriptors between images [S1].
3.  **Pose Estimation:** Utilize COLMAP's backend for pose estimation given the SuperPoint/SuperGlue matches [S1].
    *   *Note:* HLOC demonstrates better effectiveness than COLMAP on sparse views ($n_{frame} = 310, 1392$) [S1].

### LocalRF SfM
1.  **Initialization:** Initialize camera poses and structure [S1].
2.  **Optimization:** Optimize poses to handle long-range camera trajectories and large unbounded scenes [S1].
3.  **Ray Sampling Constraint:** Restrict ray sampling solely to valid color pixels during internal processing to improve robustness [S1].
    *   *Note:* LocalRF estimates all camera poses ($n_{pose} = n_{frame}$) but has extensive running times, making it unsuitable for large frame counts in resource-constrained contexts [S1].

**Parameters:**
*   **COLMAP:** Uses SIFT features [S1].
*   **HLOC:** Uses SuperPoint (extraction) and SuperGlue (matching) [S1].
*   **LocalRF:** No specific feature parameters given, but relies on valid color pixel masking [S1].

**Edge Cases and Pitfalls:**
*   **Sparsity:** COLMAP fails to estimate all poses on sparse datasets ($n_{frame}=310, 1392$), returning only a subset ($n_{pose} < n_{frame}$) [S1].
*   **Performance:** LocalRF is computationally prohibitive for large datasets ($n_{frame}=2784$) [S1].
*   **Static Assumption:** If SfM is used for downstream tasks like canonical frame estimation, the assumption of a static subject is critical for accurate 3D triangulation of landmarks [S2].

## Subtopics

### Canonical Frame Estimation via Facial Landmarks
A method that uses SfM camera poses to triangulate 2D facial landmarks (computed via MediaPipe’s face mesh) into 3D, establishing a canonical coordinate frame centered at the face mesh with +y up, +x right, and -z into the face [S2]. The scale is set so the interpupillary distance matches 6 cm [S2]. This enables automatic generation of novel view trajectories (e.g., figure-eight paths) for selfie or full-body captures [S2]. It is chosen when a subject-centric canonical frame is required for deformable NeRFs (Nerfies) [S2]. A pitfall is that 3D triangulation is strictly correct only if the subject is static; however, it remains sufficiently accurate even with head rotation [S2].

### Deep Image Matching Initialization
An initialization pipeline that replaces traditional sparse SfM methods with a deep learning framework to construct a robust initial point cloud [S3]. It uses SuperPoint for feature extraction and LightGlue for feature matching [S3]. It is chosen when traditional SfM/MVS methods lack robustness, efficiency, or scalability for the target scene [S3].

## Operating characteristics
**Time Complexity and Performance:**
Performance varies significantly by method and input density [S1]. Measurements were taken on a machine with a single RTX A6000 GPU and 128 GB RAM [S1].

*   **310 Frames:**
    *   COLMAP: 00:08:26 (estimates 62 poses) [S1].
    *   HLOC: 01:08:39 (estimates 43 poses) [S1].
    *   LocalRF: 23:20:52 (estimates 310 poses) [S1].
    *   COLMAP is 8x faster than HLOC [S1].
*   **1392 Frames:**
    *   COLMAP: 00:49:29 (estimates 376 poses) [S1].
    *   HLOC: 21:51:34 (estimates 647 poses) [S1].
    *   LocalRF: 75:10:54 (estimates 1392 poses) [S1].
    *   COLMAP is 26.5x faster than HLOC [S1].
*   **2784 Frames:**
    *   COLMAP: 04:32:53 (estimates 2667 poses) [S1].
    *   HLOC and LocalRF were not executed due to time constraints [S1].

**Scaling:**
COLMAP scales well with dense views but loses efficiency (in terms of pose coverage) on sparse views [S1]. HLOC scales better on sparse views but becomes prohibitively slow as frame count increases [S1]. LocalRF does not scale to large frame counts due to extensive running time [S1].

**Strengths and Limitations:**
*   **COLMAP:** Fast and robust for dense views; poor coverage on sparse views [S1].
*   **HLOC:** Better effectiveness on sparse views; slower than COLMAP [S1].
*   **LocalRF:** Handles long-range trajectories and unbounded scenes; estimates all poses; extremely slow [S1].

**When to use:**
*   Use **COLMAP** for dense datasets where speed is prioritized [S1].
*   Use **HLOC** for sparse datasets where pose coverage is critical [S1].
*   Use **LocalRF** for sparse views with long-range trajectories where complete pose estimation is required and time is not a constraint [S1].

## Background
Structure-from-Motion is a fundamental technique in computer vision for reconstructing 3D scenes from 2D image sequences [S1]. In the context of NeRF training, it serves as the pre-processing step to determine camera poses for extracted video frames, providing the geometric input for models like those trained with Nerfstudio [S1]. Variants like HLOC integrate modern deep learning feature extractors (SuperPoint) and matchers (SuperGlue) into the traditional COLMAP pipeline [S1]. LocalRF adapts SfM concepts for large unbounded scenes [S1]. Deep image matching initialization represents a shift towards learning-based feature matching to replace traditional sparse SfM for robustness [S3].
