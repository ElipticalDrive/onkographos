# Coarse Camera Pose Estimation

Also called: DSAC-based Pose Estimation, RANSAC-PnP Registration

## Overview
Coarse Camera Pose Estimation initializes the camera extrinsics for a target image by establishing 2D-3D correspondences between the target and a registered reference image, then solving for the pose using Direct Linear Transform (DSAC) and Perspective-n-Point (PnP) with RANSAC [S1, unofficial]. It differs from [Iterative Closest Point (ICP)](10563-iterative-closest-point-icp.md) by relying on learned semantic 3D reconstruction rather than geometric surface matching, and from [Rigid Parametric Alignment](8609-rigid-parametric-alignment.md) by providing the initial seed pose rather than refining a known correspondence set via SVD [S1, unofficial].

## How it works
**Inputs:**
- Registered reference image $I_{ref}$ (or $I_i$).
- Target image $I_k$ to be registered.
- Camera intrinsic matrix $K$ (supporting distinct focal lengths $f_x, f_y$) [S1, unofficial].
- Inlier threshold $s_{inlier} = 5,000$ [S1, unofficial].
- Reprojection error threshold $\epsilon_{reproj} = 6$ pixels [S1, unofficial].

**Outputs:**
- Coarse camera pose $T_{coarse}$ (extrinsics) for $I_k$.
- Inlier count $S_k$.
- Boolean flag indicating if $I_k$ is added to the training buffer.

**Data Structures:**
- Scene Regressor $f_{SCR}$: A neural network (e.g., Transformer-based) mapping $(I_{ref}, I_k)$ to a set of 3D points $\{X_k\}$ in the global coordinate frame [S1, unofficial].
- Pixel coordinates $\{u_k\}$: 2D image coordinates for $I_k$.
- 2D-3D Correspondences: Set $\{(u_k, X_k)\}$ derived from $\{u_k\}$ and $\{X_k\}$ [S1, unofficial].

**Steps:**
1. **3D Point Regression:** Pass $I_{ref}$ and $I_k$ to $f_{SCR}$ to obtain the set of 3D points $\{X_k\}$ in the global coordinate frame [S1, unofficial].
   $$ \{X_k\} = f_{SCR}(I_{ref}, I_k) $$
2. **Correspondence Generation:** Construct 2D-3D correspondences $\{(u_k, X_k)\}$ using the pixel coordinates $\{u_k\}$ of $I_k$ and the regressed 3D points $\{X_k\}$ [S1, unofficial].
3. **Pose Estimation (DSAC + PnP):** Solve for the camera pose $T_{coarse}$ and inlier count $S_k$ using DSAC and PnP:
   $$ T_{coarse}, S_k = \text{PnP}(K, \{(u_k, X_k)\}) $$
   The implementation uses a modified DSAC that supports distinct focal lengths for the x and y axes [S1, unofficial].
4. **Inlier Validation:** Check if $S_k > s_{inlier}$ [S1, unofficial].
5. **Buffer Update:** If $S_k > s_{inlier}$, add $I_k$ to the training buffer and select it as a reference for future registrations [S1, unofficial].

**Formulas:**
The optimization within DSAC minimizes the reprojection error:
$$ \sum_{i,k} \rho(\| d_{i,k} \cdot \nu_{i,k} - (X_i - C_k) \|_2) $$
Where:
- $C_k$ is the camera center for image $I_k$.
- $X_i$ is a 3D point.
- $d_{i,k}$ is the scaling factor between $X_i$ and $C_k$.
- $\nu_{i,k}$ is the ray direction between $X_i$ and $C_k$.
- $\rho(\cdot)$ is the loss function [S1, unofficial].

**Parameters:**
- $s_{inlier} = 5,000$ [S1, unofficial].
- Reprojection error threshold = 6 pixels [S1, unofficial].

**Edge Cases:**
- **Gauge Ambiguity:** The camera pose of the seed image is fixed during optimization [S1, unofficial].
- **Scale Ambiguity:** The scaling factor between the seed image and its most similar adjacent image is fixed [S1, unofficial].
- **Inaccuracy:** Poses may be inaccurate if the scene regressor has not seen the target images; however, a separate MLP pose refiner was found ineffective for transformer-based regressors [S1, unofficial].

## Subtopics

## Operating characteristics
- **Time Complexity:** Dominated by the inference of the scene regressor $f_{SCR}$ and the RANSAC iterations in DSAC.
- **Memory Complexity:** Requires storing the 3D points $\{X_k\}$ and the training buffer of registered images.
- **Strengths:** Provides robust initialization for unposed images using learned semantic features rather than explicit geometry.
- **Limitations:** Accuracy depends on the quality of $f_{SCR}$; poses may require refinement if the regressor has not encountered similar views.
- **When to use:** Initial stage of incremental training for Neural Radiance Fields or 3D Gaussian Splatting from unposed images.
- **When not to use:** When high-precision initial poses are available or when the scene lacks semantic features learnable by the regressor.

## Background
Originated in [ZeroGS](https://doi.org/10.48550/arxiv.2411.15779) (2024) as a method to train 3D Gaussian Splatting from unposed images [S1, unofficial]. It builds on [Rigid Parametric Alignment](8609-rigid-parametric-alignment.md) by providing the initial $T_{coarse}$ that subsequent differentiable solvers or refinements may improve. It addresses the problem of initializing camera poses without prior calibration or structure-from-motion pipelines.
