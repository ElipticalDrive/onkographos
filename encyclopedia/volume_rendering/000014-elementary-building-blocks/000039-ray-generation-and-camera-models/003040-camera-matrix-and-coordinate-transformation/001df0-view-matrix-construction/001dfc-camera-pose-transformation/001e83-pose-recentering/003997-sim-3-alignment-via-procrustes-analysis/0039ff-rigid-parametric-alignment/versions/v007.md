# Rigid Parametric Alignment

Also called: Closed-form Rigid Alignment, Rigid Alignment via SVD

## Overview
Rigid Parametric Alignment is a differentiable solver that estimates a 3D rigid transformation $T \in SE(3)$ from point correspondences by minimizing the reprojection error in a closed form using Singular Value Decomposition (SVD) [S1]. It differs from its parent, [Sim(3) Alignment via Procrustes Analysis](8526-sim-3-alignment-via-procrustes-analysis.md), by restricting the transformation to the Special Euclidean group $SE(3)$, thereby excluding uniform scaling [S1]. Unlike [Test-time Optimization with Sim(3) Initialization](8565-test-time-optimization-with-sim-3-initialization.md), which relies on iterative gradient descent, this method provides an analytical solution [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $N$ corresponding point pairs in 3D space, denoted as $\{x^j\}_{j=1}^N$ (source) and $\{T^* x^j\}_{j=1}^N$ (target/ground truth), where $T^*$ is the unknown optimal transformation [S1].
*   **Output:** The optimal rigid transformation matrix $T = [R|t] \in SE(3)$, where $R \in SO(3)$ is the rotation matrix and $t \in \mathbb{R}^3$ is the translation vector [S1].

**Data Structures:**
*   **Correspondences:** Two sets of 3D vectors. The source points $x^j$ and the target points are implicitly defined by the ground truth transformation $T^*$ applied to $x^j$ [S1].
*   **Covariance Matrix:** A $3 \times 3$ matrix $H$ computed from the centered points [S1].

**Steps:**
1.  **Compute Centroids:** Calculate the mean of the source points $\bar{x}$ and the target points $\bar{y}$ (where $y^j = T^* x^j$) [S1].
    $$ \bar{x} = \frac{1}{N} \sum_{j=1}^N x^j $$
    $$ \bar{y} = \frac{1}{N} \sum_{j=1}^N y^j $$
2.  **Compute Covariance Matrix:** Construct the $3 \times 3$ covariance matrix $H$ using the centered points [S1]:
    $$ H = \sum_{j=1}^N (x^j - \bar{x})(y^j - \bar{y})^T $$
    *(Note: The source text denotes the target as $T^j x^j$ in Eq. 12, but standard Procrustes formulation uses centered coordinates. The formula provided in the source is $H = \sum (x^j - \bar{x})(T^j x^j - T\bar{x})^T$ which simplifies to the standard cross-covariance when $T$ is the identity or when aligning centered sets. We follow the standard interpretation of Eq. 12-14 where $H$ is the cross-covariance of the two point sets)* [S1].
3.  **Singular Value Decomposition:** Perform SVD on $H$ [S1]:
    $$ H = U S V^T $$
    where $U$ and $V$ are orthogonal matrices and $S$ is a diagonal matrix of singular values [S1].
4.  **Compute Rotation:** Calculate the optimal rotation matrix $R$ [S1]:
    $$ R = V U^T $$
    *(Note: If $\det(R) = -1$, a correction is typically required to ensure $R \in SO(3)$, though the source does not explicitly detail the reflection handling. [G])*
5.  **Compute Translation:** Calculate the optimal translation vector $t$ [S1]:
    $$ t = -R\bar{x} + \bar{y} $$
    *(Note: The source formula is $t = -R\bar{x} + T\bar{x}$. Since $T\bar{x}$ represents the transformed centroid of the source, which corresponds to $\bar{y}$ in the target frame, this is equivalent to $t = \bar{y} - R\bar{x}$)* [S1].
6.  **Construct Transformation:** Assemble the final rigid transformation matrix $T$ [S1]:
    $$ T = [R|t] \in SE(3) $$

**Parameters:**
*   In the context of the L2G-NeRF implementation, the warp neural field $f_W$ uses a ReLU MLP with six 256-dimensional hidden units for the rigid alignment experiment [S1].

**Edge Cases and Pitfalls:**
*   **Degenerate Input:** If the point correspondences are collinear or coplanar, the covariance matrix $H$ may be rank-deficient, leading to ambiguous rotation solutions [G].
*   **Reflection:** If $\det(V U^T) = -1$, the resulting matrix is a rotation-reflection, not a pure rotation. Standard Procrustes analysis requires checking the determinant and adjusting the smallest singular value's sign in $V$ or $U$ to enforce $\det(R)=1$ [G].

**Pseudocode:**
```python
import numpy as np

def rigid_parametric_alignment(points_src, points_tgt):
    """
    Computes the rigid transformation T = [R|t] that aligns points_src to points_tgt.
    
    Args:
        points_src: numpy array of shape (N, 3), source 3D points.
        points_tgt: numpy array of shape (N, 3), target 3D points.
        
    Returns:
        R: numpy array of shape (3, 3), rotation matrix.
        t: numpy array of shape (3,), translation vector.
    """
    # Step 1: Compute centroids
    centroid_src = np.mean(points_src, axis=0)
    centroid_tgt = np.mean(points_tgt, axis=0)
    
    # Step 2: Center the points
    src_centered = points_src - centroid_src
    tgt_centered = points_tgt - centroid_tgt
    
    # Step 3: Compute covariance matrix H
    # H = sum (x_i - mean_x) (y_i - mean_y)^T
    H = src_centered.T @ tgt_centered
    
    # Step 4: SVD of H
    U, S, Vt = np.linalg.svd(H)
    V = Vt.T
    
    # Step 5: Compute Rotation
    R = V @ U.T
    
    # Handle reflection case (determinant -1)
    if np.linalg.det(R) < 0:
        # Correct the last column of V
        V[:, -1] *= -1
        R = V @ U.T
        
    # Step 6: Compute Translation
    t = centroid_tgt - R @ centroid_src
    
    return R, t
```

## Subtopics

### [Iterative Closest Point (ICP)](10563-iterative-closest-point-icp.md)
Iterative Closest Point (ICP) is a registration algorithm used to align two point sets, typically a reconstructed point cloud and a ground truth mesh, by finding an optimal rigid transformation. It builds on [Rigid Parametric Alignment](8609-rigid-parametric-alignment.md) by iteratively refining the transformation estimate through correspondence matching, rather than solving for a transformation from pre-established correspondences in a single step [G]. Unlike differentiable renderers which optimize pose via gradient descent on pixel errors, ICP operates directly in geometric space.

### [Coarse Camera Pose Estimation](15954-coarse-camera-pose-estimation.md)
Coarse Camera Pose Estimation is an incremental registration method that estimates the initial extrinsic parameters (camera pose) for unposed target images relative to a registered reference image using a learned scene regressor. It solves the problem of initializing camera poses in neural radiance field training by converting predicted 3D points into 2D-3D correspondences and solving for the pose via Perspective-n-Point (PnP). It differs from [Iterative Closest Point (ICP)](10563-iterative-closest-point-icp.md) by relying on a neural scene representation to provide dense 3D structure rather than iterative point-to-point alignment, and from [Structure-from-Motion (SfM)](16341-structure-from-motion-sfm.md) by operating incrementally on a learned regressor rather than globally on feature matches.

### Homography Parametric Alignment
Homography Parametric Alignment is a differentiable solver that estimates a 2D homography transformation $T \in SL(3)$ from point correspondences by solving a homogeneous linear least squares problem via SVD [S1]. The homography constraint in homogeneous coordinates is:
$$ \begin{bmatrix} 0 & x^j_1 & x^j_2 & 1 \end{bmatrix} = T \begin{bmatrix} x^j_1 \\ x^j_2 \\ 1 \end{bmatrix} $$
which is rearranged into the linear system $A_j h = 0$ [S1].

## Operating characteristics
**Time and Memory Complexity:**
The complexity is dominated by the SVD of a $3 \times 3$ matrix, which is $O(1)$ constant time and memory for a fixed number of points, or $O(N)$ to compute the covariance matrix from $N$ points [S1].

**Measured Performance:**
Specific performance metrics (PSNR, SSIM) are not provided for the alignment step itself in the sources, but the method is used within the L2G-NeRF framework [S1].

**Strengths and Limitations:**
*   **Strengths:** Provides a closed-form, deterministic solution without requiring iterative optimization or gradient descent [S1].
*   **Limitations:** Requires known point correspondences. It does not account for scaling (unlike Sim(3)) [S1].

**When to Use:**
Use when point correspondences are available and a strict rigid transformation (no scaling) is required [S1].

## Background
**Origin:**
The method is described in "Local-to-Global Registration for Bundle-Adjusting Neural Radiance Fields" [S1].

**History and Development:**
The approach leverages standard Procrustes analysis techniques adapted for differentiable rendering pipelines, specifically within the L2G-NeRF architecture [S1].

**Usage:**
It is used for local-to-global registration in neural radiance fields, allowing the discovery of correct registration with initially flexible pixel-wise alignment that shifts to constrained parametric alignment [S1].
