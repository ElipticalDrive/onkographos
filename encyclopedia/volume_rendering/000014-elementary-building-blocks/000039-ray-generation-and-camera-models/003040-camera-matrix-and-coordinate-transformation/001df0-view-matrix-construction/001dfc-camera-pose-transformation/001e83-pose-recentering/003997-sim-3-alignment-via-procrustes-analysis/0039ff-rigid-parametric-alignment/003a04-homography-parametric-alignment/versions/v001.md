# Homography Parametric Alignment

Also called: Camera Space to SLM Space Homography, Camera-to-SLM Homography, SLM Camera Homography

## Overview
Homography Parametric Alignment estimates a 2D projective transformation $T \in SL(3)$ from point correspondences by solving a homogeneous linear least squares problem via Singular Value Decomposition (SVD) [S1]. It is specifically employed in camera-in-the-loop optimization to map captured camera coordinates to Spatial Light Modulator (SLM) pattern coordinates, ensuring the captured wavefront and SLM pattern reside in the same coordinate system [S2]. Unlike [Rigid Parametric Alignment](8609-rigid-parametric-alignment.md), which estimates a 3D rigid transformation in $SE(3)$, this method operates in 2D homogeneous space to handle planar or perspective distortions between the sensor and the display plane [S1, S2].

## How it works
**Inputs:**
- A set of $N$ point correspondences $\{x^j\}_{j=1}^N$, where each $x^j$ consists of a source point in camera space and a target point in SLM space.
- The source points $x^j$ are detected centers of dots on the sensor in camera coordinates.
- The target points are the known centers of the same dots in SLM space, derived from the target image used to generate the dot grid [S2].

**Outputs:**
- A $3 \times 3$ homography matrix $T$ representing the affine/projective transform mapping camera space to SLM space [S2].

**Data Structures:**
- The homography matrix $T$ is a $3 \times 3$ matrix with elements $T_{ij}$ for $i,j \in \{1,2,3\}$ [S1].
- The unknown parameter vector $h$ contains the 9 elements of $T$ stacked into a column vector [S1].

**Steps:**
1.  **Generate Reference Pattern:** Calculate an SLM pattern that produces a grid of dots [S2].
2.  **Capture and Detect:** Capture the wavefront on the sensor. Detect the dots and estimate their centers in camera space coordinates [S2].
3.  **Define Correspondences:** Establish correspondences between the detected camera-space centers and the known SLM-space centers of the dot grid [S2].
4.  **Construct Linear System:** For each correspondence $j$, construct the constraint equation in homogeneous coordinates. The transformation is defined as:
    $$ \begin{bmatrix} 0 & x^j_1 & x^j_2 & 1 \end{bmatrix} = T \begin{bmatrix} x^j_1 & x^j_2 & 1 \end{bmatrix} $$
    *Note: The source text presents this constraint in a specific rearranged form leading to $A_j h = 0$. The standard homography constraint $x' \sim T x$ implies $x'_1 (T_{31} x_1 + T_{32} x_2 + T_{33}) = T_{11} x_1 + T_{12} x_2 + T_{13}$ and $x'_2 (T_{31} x_1 + T_{32} x_2 + T_{33}) = T_{21} x_1 + T_{22} x_2 + T_{23}$. The source explicitly cites Eq. (15) as the basis for $A_j h = 0$ [S1].*
5.  **Aggregate System:** Stack the constraints from all $N$ points into a global linear system $A h = 0$, where $A$ is a $2N \times 9$ matrix [S1].
6.  **Solve via SVD:** Perform Singular Value Decomposition on $A$ (or the covariance matrix $H = A^T A$) to find the null space vector corresponding to the smallest singular value. This vector $h$ forms the optimal transformation matrix $T$ that minimizes the algebraic error [S1].
7.  **Reshape:** Reshape the vector $h$ into the $3 \times 3$ matrix $T$ [S1].

**Pseudocode:**
```python
import numpy as np

def compute_homography(camera_points, slm_points):
    """
    Computes the 3x3 homography matrix T mapping camera_points to slm_points.
    camera_points: Nx2 array of (x, y) in camera space.
    slm_points: Nx2 array of (x, y) in SLM space.
    Returns: 3x3 matrix T.
    """
    N = camera_points.shape[0]
    A = np.zeros((2 * N, 9))
    
    for j in range(N):
        x, y = camera_points[j]
        u, v = slm_points[j]
        
        # Construct rows for the linear system Ah = 0
        # Based on the constraint: u = (T11*x + T12*y + T13) / (T31*x + T32*y + T33)
        # and v = (T21*x + T22*y + T23) / (T31*x + T32*y + T33)
        # Rearranged to linear form:
        # T11*x + T12*y + T13 - T31*x*u - T32*y*u - T33*u = 0
        # T21*x + T22*y + T23 - T31*x*v - T32*y*v - T33*v = 0
        
        # Row 1 (for u)
        A[2*j, 0] = x
        A[2*j, 1] = y
        A[2*j, 2] = 1
        A[2*j, 3] = 0
        A[2*j, 4] = 0
        A[2*j, 5] = 0
        A[2*j, 6] = -x * u
        A[2*j, 7] = -y * u
        A[2*j, 8] = -u
        
        # Row 2 (for v)
        A[2*j+1, 0] = 0
        A[2*j+1, 1] = 0
        A[2*j+1, 2] = 0
        A[2*j+1, 3] = x
        A[2*j+1, 4] = y
        A[2*j+1, 5] = 1
        A[2*j+1, 6] = -x * v
        A[2*j+1, 7] = -y * v
        A[2*j+1, 8] = -v

    # Solve Ah = 0 using SVD
    # The solution is the right singular vector corresponding to the smallest singular value
    U, S, Vt = np.linalg.svd(A)
    h = Vt[-1, :] # Last row of V^T corresponds to smallest singular value
    
    # Reshape into 3x3 matrix
    T = h.reshape(3, 3)
    
    return T
```

**Parameters:**
- A unique homography is calculated for each depth location and color channel [S2].

**Edge Cases:**
- Degenerate configurations (e.g., collinear points) may result in a singular matrix $A$, making the SVD solution unstable or ambiguous [G].
- Precision issues may arise if the coordinates are not normalized before solving the linear system [G].

## Subtopics

### Iterative Closest Point (ICP)
An iterative algorithm for registering two point clouds by minimizing the distance between corresponding points. It differs from Homography Parametric Alignment by operating in 3D and using iterative optimization rather than a closed-form SVD solution for 2D homographies. Choose ICP for general 3D rigid registration when correspondences are not known a priori. [Iterative Closest Point (ICP)](10563-iterative-closest-point-icp.md)

### Coarse Camera Pose Estimation
Estimates the initial camera pose from image features. It serves as a precursor to fine alignment methods. Choose it when an initial guess is needed before applying parametric alignment. [Coarse Camera Pose Estimation](15954-coarse-camera-pose-estimation.md)

## Operating characteristics
- **Time Complexity:** The SVD of a $2N \times 9$ matrix is $O(N)$, making it very fast for typical numbers of dots ($N$).
- **Memory Complexity:** $O(N)$ to store the matrix $A$.
- **Strengths:** Closed-form solution ensures deterministic results; differentiable, allowing gradient flow for optimization [S1].
- **Limitations:** Only models 2D projective transformations; assumes planar correspondence or negligible depth variation within the field of view.
- **When to use:** When mapping between two 2D planes (camera sensor and SLM) with known point correspondences.
- **When not to use:** When 3D rigid body motion is the primary concern (use [Rigid Parametric Alignment](8609-rigid-parametric-alignment.md)) or when correspondences are unknown and require iterative matching (use [Iterative Closest Point (ICP)](10563-iterative-closest-point-icp.md)).

## Background
The method originates from research on local-to-global registration for Neural Radiance Fields (NeRF) and simultaneous color computer-generated holography [S1, S2]. It was introduced to enable camera-in-the-loop optimization by aligning captured wavefronts with SLM patterns [S2]. The mathematical foundation relies on solving homogeneous linear systems via SVD, a standard technique in computer vision for homography estimation [S1].
