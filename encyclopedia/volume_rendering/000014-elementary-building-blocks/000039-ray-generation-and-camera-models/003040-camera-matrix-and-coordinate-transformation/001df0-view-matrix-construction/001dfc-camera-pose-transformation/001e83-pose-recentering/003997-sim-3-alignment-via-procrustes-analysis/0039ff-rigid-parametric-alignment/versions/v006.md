# Rigid Parametric Alignment

Also called: Closed-form Rigid Alignment, Rigid Alignment via SVD

## Overview
Rigid Parametric Alignment is a differentiable solver that estimates a 3D rigid transformation $T \in SE(3)$ from point correspondences by minimizing the reprojection error in a closed form using Singular Value Decomposition (SVD) [S1]. It differs from its parent [Sim(3) Alignment via Procrustes Analysis](8526-sim-3-alignment-via-procrustes-analysis.md) by restricting the transformation group to rigid motions (rotation and translation only), excluding scaling [S1]. Unlike [Test-time Optimization with Sim(3) Initialization](8565-test-time-optimization-with-sim-3-initialization.md) which uses iterative gradient-based optimization, this method provides an analytical solution [S1].

## How it works
**Inputs:**
- A set of $N$ corresponding 3D points in the source frame, denoted $\{x^j\}_{j=1}^N$.
- A set of $N$ corresponding 3D points in the target frame, denoted $\{T^* x^j\}_{j=1}^N$, where $T^*$ is the ground truth or reference transformation [S1].
- Note: In the context of L2G-NeRF, these points are often derived from camera poses or 3D points transformed into world coordinates [S1].

**Outputs:**
- The optimal rigid transformation $T = [R|t] \in SE(3)$, where $R \in SO(3)$ is the rotation matrix and $t \in \mathbb{R}^3$ is the translation vector [S1].

**Data Structures:**
- Matrix $H \in \mathbb{R}^{3 \times 3}$: The cross-covariance matrix of the point sets.
- Matrices $U, V \in \mathbb{R}^{3 \times 3}$ and diagonal matrix $S \in \mathbb{R}^{3 \times 3}$: Result of the SVD of $H$.
- Vectors $\bar{x}, \overline{T^*x} \in \mathbb{R}^3$: Centroids of the source and target point sets.

**Steps:**
1. Compute the centroids of the source and target point sets:
   $$ \bar{x} = \frac{1}{N} \sum_{j=1}^N x^j $$
   $$ \overline{T^*x} = \frac{1}{N} \sum_{j=1}^N T^* x^j $$
   [S1]

2. Construct the cross-covariance matrix $H$:
   $$ H = \sum_{j=1}^N (x^j - \bar{x})(T^* x^j - \overline{T^*x})^T $$
   [S1]
   *Note: The source text writes this as $H = \sum (x^j - \bar{x})(T^j x^j - T\bar{x})^T$ in Eq. 12, but Eq. 14 clarifies the translation term uses the target centroid. The standard Procrustes formulation uses the centered target points.*

3. Perform Singular Value Decomposition (SVD) on $H$:
   $$ H = U S V^T $$
   [S1]

4. Compute the optimal rotation $R$:
   $$ R = V U^T $$
   [S1]
   *Implementation Note: To ensure $R$ is a proper rotation (determinant +1) and not a reflection (determinant -1), if $\det(V U^T) = -1$, one must flip the sign of the last column of $V$ (or $U$) before computing $R$. This is a standard SVD-based rigid alignment guard [G].*

5. Compute the optimal translation $t$:
   $$ t = -R \bar{x} + \overline{T^*x} $$
   [S1]

6. Construct the transformation matrix $T$:
   $$ T = [R|t] \in SE(3) $$
   [S1]

**Parameters:**
- The method itself is parameter-free regarding the alignment calculation. However, in the L2G-NeRF implementation, the warp neural field $f_W$ that parametrizes the alignment uses a ReLU MLP with six 256-dimensional hidden units [S1].

**Edge Cases and Pitfalls:**
- **Degenerate Input:** If the point set is collinear or coplanar, $H$ may be rank-deficient, leading to ambiguous rotations. SVD handles this numerically, but the resulting rotation may be unstable [G].
- **Reflection:** As noted, $V U^T$ can yield a reflection. The determinant check is required for strict $SE(3)$ compliance [G].

## Subtopics

### Homography Parametric Alignment
A differentiable solver that estimates a 2D homography transformation $T \in SL(3)$ from point correspondences by solving a homogeneous linear least squares problem via SVD [S1]. Unlike the 3D rigid alignment which solves for $SE(3)$, this variant operates in 2D projective space [S1]. The homography constraint in homogeneous coordinates is formulated as:
$$ \begin{bmatrix} 0 & x^j_1 & x^j_2 & 1 \end{bmatrix} = T \begin{bmatrix} x^j_1 & x^j_2 & 1 \end{bmatrix} $$
which is rearranged into the linear system $A_j h = 0$ [S1]. This is used when the transformation is assumed to be planar or when working with 2D image alignments rather than 3D scene registrations [S1].

## Operating characteristics
- **Time Complexity:** Dominated by the SVD of a $3 \times 3$ matrix, which is $O(1)$ constant time.
- **Memory Complexity:** $O(N)$ to store the point correspondences and compute the covariance matrix.
- **Strengths:** Provides a closed-form, deterministic solution without the need for iterative optimization or gradient descent, making it computationally efficient and stable for small to medium point sets [S1].
- **Limitations:** Only applicable to rigid transformations (no scaling). Sensitive to outliers in correspondences; requires clean or pre-processed correspondences [S1].
- **When to use:** When a fast, analytical estimate of rigid alignment is needed from known correspondences, such as initializing pose registration in neural radiance fields [S1].

## Background
Rigid Parametric Alignment was introduced in the context of Local-to-Global Registration for Bundle-Adjusting Neural Radiance Fields (L2G-NeRF) [S1]. The method leverages the classical Procrustes analysis solution for rigid body transformation, adapted into a differentiable framework for use in neural field training [S1]. It builds on the mathematical foundation of SVD-based rotation estimation [S1].
