# SE2 Lie Group Implementation

Also called: SE2, Special Euclidean Group 2D

## Overview
The SE2 Lie group implementation provides a parameterization for 2D rigid body transformations, combining rotation and translation in the plane. It solves the problem of representing and composing 2D poses efficiently for applications such as camera pose estimation and geometric optimization. It is distinguished from [Quaternion Rotation](2302-quaternion-rotation.md) by operating in 2D rather than 3D, and from [2D Rotation](3357-2d-rotation.md) by including translation components to form the full special Euclidean group.

## How it works
**Inputs and Outputs:**
The method takes standard 2D pose parameters $(x, y, \theta)$ or tangent vectors $(v_x, v_y, \omega)$ and outputs an SE2 transformation object, which can be converted to a $3 \times 3$ homogeneous matrix.

**Data Structures:**
The `SE2` class stores internal parameters in a field `unit_complex_xy`.
- **Type:** `onpt.NDArray[onp.floating]` (NumPy/JAX array).
- **Shape:** At least 4 elements.
- **Layout:** `[cos, sin, x, y]`, representing the rotation components as a unit complex number and the translation components.

**Steps:**

1.  **Construction from Pose $(x, y, \theta)$:**
    Compute $c = \cos(\theta)$ and $s = \sin(\theta)$. Construct the array `[c, s, x, y]` and return `SE2(unit_complex_xy=array)`.

2.  **Construction from SO2 and Translation:**
    Given an SO2 rotation object with `unit_complex` $[c, s]$ and a 2D translation vector $[t_x, t_y]$, concatenate them into `[c, s, t_x, t_y]` and return `SE2(unit_complex_xy=array)`.

3.  **Conversion to Homogeneous Matrix:**
    Unpack `unit_complex_xy` into $c, s, x, y$. Return the matrix:
    $$
    M = \begin{bmatrix}
    c & -s & x \\
    s & c & y \\
    0.0 & 0.0 & 1.0
    \end{bmatrix}
    $$

4.  **Exponential Map $\exp(\xi)$:**
    Input: Tangent vector $\xi = [v_x, v_y, \theta]$.
    Let $\epsilon$ be a small threshold (e.g., $10^{-6}$).
    
    If $|\theta| < \epsilon$:
    - Compute Taylor approximations:
      $$ \text{sin\_over\_theta} = 1.0 - \frac{\theta^2}{6.0} $$
      $$ \text{one\_minus\_cos\_over\_theta} = 0.5\theta - \frac{\theta^3}{24.0} $$
    [G] Use a safe value for $\theta$ (e.g., $\epsilon$) in the denominator if implementing numerically to avoid division by zero, though the Taylor series itself does not divide by $\theta$.
    
    Else:
    - Compute:
      $$ \text{sin\_over\_theta} = \frac{\sin(\theta)}{\theta} $$
      $$ \text{one\_minus\_cos\_over\_theta} = \frac{1 - \cos(\theta)}{\theta} $$
    
    Construct matrix $V$:
    $$
    V = \begin{bmatrix}
    \text{sin\_over\_theta} & \text{one\_minus\_cos\_over\_theta} \\
    -\text{one\_minus\_cos\_over\_theta} & \text{sin\_over\_theta}
    \end{bmatrix}
    $$
    
    Compute rotation $R = \text{SO2}(\theta)$ and translation $t = V \cdot [v_x, v_y]^T$.
    Return `SE2.from_rotation_and_translation(rotation=R, translation=t)`.

5.  **Logarithm Map $\log(g)$:**
    Input: SE2 transformation $g$.
    Extract $\theta$ from the rotation component.
    Compute $c_{-1} = \cos(\theta) - 1.0$.
    
    If $|c_{-1}| < \epsilon$:
    - Compute Taylor approximation:
      $$ \text{half\_theta\_over\_tan\_half\_theta} = 1.0 - \frac{\theta^2}{12.0} $$
    
    Else:
    - Compute:
      $$ \text{half\_theta\_over\_tan\_half\_theta} = -\frac{(\theta/2) \sin(\theta)}{c_{-1}} $$
    
    Construct $V_{inv}$:
    $$
    V_{inv} = \begin{bmatrix}
    \text{half\_theta\_over\_tan\_half\_theta} & -\text{half\_theta\_over\_tan\_half\_theta} \\
    \text{half\_theta\_over\_tan\_half\_theta} & \text{half\_theta\_over\_tan\_half\_theta}
    \end{bmatrix}
    $$
    [G] Note: The standard inverse of the V matrix in SE2 log map involves specific trigonometric identities. The source describes constructing $V_{inv}$ implicitly via the scalar factor. The translation part of the tangent vector is $V_{inv} \cdot \text{translation}$.
    
    Compute $t_{xy} = V_{inv} \cdot \text{translation}$.
    Return tangent vector $[t_{xy}[0], t_{xy}[1], \theta]$.

6.  **Adjoint Matrix $\text{Ad}_g$:**
    Unpack `unit_complex_xy` into $c, s, x, y$. Return:
    $$
    \text{Ad}_g = \begin{bmatrix}
    c & -s & y \\
    s & c & -x \\
    0.0 & 0.0 & 1.0
    \end{bmatrix}
    $$

**Parameters:**
- $\epsilon$: Threshold for Taylor approximation switch. Value not given in sources, typically $10^{-6}$ or similar small float.

**Edge Cases and Pitfalls:**
- **NaNs in AD:** When using JAX reverse-mode automatic differentiation with `onp.where`, branches taken for Taylor approximations can cause NaNs in non-Taylor branches during gradient computation. To fix this, use a "shim" value of 1.0 for `safe_theta` and `safe_cos_minus_one` when the Taylor branch is taken, ensuring non-zero denominators in the non-Taylor branches [S1, unofficial].
- **Small Angles:** Direct division by $\theta$ or $\cos(\theta)-1$ causes numerical instability for small angles. Taylor approximations must be used.

**Pseudocode:**

```python
import numpy as np

def se2_exp(tangent):
    """
    Compute the exponential map for SE2.
    tangent: array-like [vx, vy, theta]
    Returns: SE2 object
    """
    vx, vy, theta = tangent[0], tangent[1], tangent[2]
    
    # Safe theta for AD
    safe_theta = np.where(np.abs(theta) < 1e-6, 1.0, theta)
    
    if np.abs(theta) < 1e-6:
        sin_over_theta = 1.0 - theta**2 / 6.0
        one_minus_cos_over_theta = 0.5 * theta - theta**3 / 24.0
    else:
        sin_over_theta = np.sin(theta) / safe_theta
        one_minus_cos_over_theta = (1.0 - np.cos(theta)) / safe_theta
        
    V = np.array([
        [sin_over_theta, one_minus_cos_over_theta],
        [-one_minus_cos_over_theta, sin_over_theta]
    ])
    
    translation = V @ np.array([vx, vy])
    rotation = so2_exp(theta)
    
    return SE2.from_rotation_and_translation(rotation, translation)

def se2_log(se2_obj):
    """
    Compute the logarithm map for SE2.
    se2_obj: SE2 object
    Returns: array [vx, vy, theta]
    """
    theta = se2_obj.rotation.theta
    translation = se2_obj.translation
    
    cos_minus_one = np.cos(theta) - 1.0
    safe_cos_minus_one = np.where(np.abs(cos_minus_one) < 1e-6, 1.0, cos_minus_one)
    half_theta = theta / 2.0
    
    if np.abs(cos_minus_one) < 1e-6:
        half_theta_over_tan_half_theta = 1.0 - theta**2 / 12.0
    else:
        half_theta_over_tan_half_theta = -(half_theta * np.sin(theta)) / safe_cos_minus_one
        
    V_inv = np.array([
        [half_theta_over_tan_half_theta, -half_theta_over_tan_half_theta],
        [half_theta_over_tan_half_theta, half_theta_over_tan_half_theta]
    ])
    
    t_xy = V_inv @ translation
    return np.concatenate([t_xy, [theta]])

def se2_to_matrix(se2_obj):
    """
    Convert SE2 to 3x3 homogeneous matrix.
    """
    c, s, x, y = se2_obj.unit_complex_xy
    return np.array([
        [c, -s, x],
        [s, c, y],
        [0.0, 0.0, 1.0]
    ])

def se2_adjoint(se2_obj):
    """
    Compute the adjoint matrix for SE2.
    """
    c, s, x, y = se2_obj.unit_complex_xy
    return np.array([
        [c, -s, y],
        [s, c, -x],
        [0.0, 0.0, 1.0]
    ])

class SE2:
    def __init__(self, unit_complex_xy):
        self.unit_complex_xy = np.array(unit_complex_xy)
        
    @staticmethod
    def from_pose(x, y, theta):
        c = np.cos(theta)
        s = np.sin(theta)
        return SE2([c, s, x, y])
        
    @staticmethod
    def from_rotation_and_translation(rotation, translation):
        # rotation is SO2 object with .unit_complex [c, s]
        # translation is array [tx, ty]
        c, s = rotation.unit_complex
        return SE2([c, s, translation[0], translation[1]])
        
    @property
    def rotation(self):
        c, s = self.unit_complex_xy[0], self.unit_complex_xy[1]
        return SO2([c, s])
        
    @property
    def translation(self):
        return self.unit_complex_xy[2:4]

class SO2:
    def __init__(self, unit_complex):
        self.unit_complex = np.array(unit_complex)
        
    @property
    def theta(self):
        return np.arctan2(self.unit_complex[1], self.unit_complex[0])
        
    @staticmethod
    def from_radians(theta):
        return SO2([np.cos(theta), np.sin(theta)])

def so2_exp(theta):
    return SO2.from_radians(theta)
```

## Operating characteristics
- **Time Complexity:** $O(1)$ for all operations (construction, exp, log, matrix conversion, adjoint).
- **Memory Complexity:** $O(1)$, storing 4 floats internally.
- **Strengths:** Efficient representation of 2D rigid motions; differentiable via automatic differentiation (with care for AD stability); compact storage.
- **Limitations:** Only applicable to 2D; requires careful handling of numerical stability for small angles to avoid NaNs in gradients.
- **When to use:** When optimizing 2D camera poses or rigid body transformations in 2D space.
- **When not to use:** For 3D transformations (use SE3 or Quaternion Rotation) or pure rotation without translation (use SO2).

## Background
The SE2 Lie group is a fundamental concept in robotics and computer vision for representing 2D rigid body transformations. The implementation described here is derived from code used in 3D Gaussian Splatting frameworks, specifically in the context of camera pose estimation and optimization [S1, unofficial]. The use of tangent space parameterization and exponential/logarithm maps allows for efficient optimization on the manifold.
