# 2D Rotation


## Overview
2D Rotation rotates a 2D vector by a specified angle in the plane perpendicular to a specified axis [S1, unofficial]. It differs from [Quaternion Rotation](2302-quaternion-rotation.md) and [SE2 Lie Group Implementation](3144-se2-lie-group-implementation.md) by operating directly on the two vector components rather than constructing a full 3×3 matrix or quaternion representation [G].

## How it works
**Inputs:**
- `p`: A 2D vector $(p_x, p_y)$ to be rotated [S1, unofficial].
- `a`: The rotation angle in radians [S1, unofficial].

**Outputs:**
- `p'`: The rotated 2D vector $(p'_x, p'_y)$ [S1, unofficial].

**Data Structures:**
- Standard 2D floating-point vectors for input and output [G].

**Steps:**
1. Compute $c = \cos(a)$ and $s = \sin(a)$ [G].
2. Update the vector components using the rotation formula [S1, unofficial].

**Formula:**
The rotated vector is calculated as:
$$
p' = \cos(a)p + \sin(a)(p_y, -p_x)
$$
Expanding into components:
$$
p'_x = p_x \cos(a) + p_y \sin(a)
$$
$$
p'_y = p_y \cos(a) - p_x \sin(a)
$$
The source explicitly defines the operation as `cos(a)*p + sin(a)*vec2(p.y, -p.x)` [S1, unofficial].

**Pseudocode:**
```python
def rotate_2d(p_x, p_y, angle):
    c = cos(angle)
    s = sin(angle)
    new_x = c * p_x + s * p_y
    new_y = c * p_y - s * p_x
    return new_x, new_y
```

## Subtopics

### [Givens Rotation](3986-givens-rotation.md)
A Givens rotation is a 2D rotation applied to a 3×3 matrix to zero out or transform specific elements. It operates on a single plane defined by two axes while leaving the third axis invariant, allowing for targeted element elimination in matrix factorization.
