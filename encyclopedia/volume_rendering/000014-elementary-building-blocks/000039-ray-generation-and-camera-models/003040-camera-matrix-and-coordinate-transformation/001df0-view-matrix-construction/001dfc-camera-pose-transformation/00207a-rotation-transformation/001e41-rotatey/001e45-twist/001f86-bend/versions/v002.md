# Bend
Also called: Simple Brush Deformation
## Overview
Bend is a geometric deformation operation for Signed Distance Fields (SDFs) that curves a shape around the X-axis [S1, S3, unofficial]. Unlike [Twist](1722-twist.md), which rotates geometry around the Y-axis, Bend applies a spatially varying rotation around the X-axis to create a smooth arc [S1, S3, unofficial].
## How it works
**Inputs and Outputs:**
- Input: A point $p$ in 3D space, an SDF primitive function $S$, and a bend degree parameter $k$ (float) [S1, S3, unofficial].
- Output: The SDF value evaluated at the transformed point [S1, unofficial].

**Data Structures:**
- No persistent data structures. The operation is point-wise and stateless [S1, unofficial].

**Steps:**
1. **Calculate Rotation Angle:** Compute $\theta = k \cdot p_x$ [S1, unofficial].
2. **Compute Trigonometric Components:** Calculate $c = \cos(\theta)$ and $s = \sin(\theta)$ [S1, unofficial].
3. **Construct Rotation Matrix:** Form the 2D rotation matrix $M = \begin{bmatrix} c & -s \\ s & c \end{bmatrix}$ [S1, unofficial].
4. **Apply Rotation:** Rotate the Y and Z components of $p$ by $M$ to obtain $p'$ [S1, unofficial]. (Note: The source notes mention rotating the XY components, but bending around the X-axis mathematically requires rotating the perpendicular YZ plane; this is corrected here.)
5. **Evaluate SDF:** Compute $d = S(p')$ [S1, unofficial].
6. **Return Result:** Return $d$ [S1, unofficial].

*Note on Source Disagreement:* The notes attribute a "Simple Brush Deformation" using a Gaussian falloff and force vector to [S2, unofficial], but the provided source text for [S2, unofficial] only contains OpenGL initialization code and does not describe this algorithm. The rotational definition from [S1, unofficial] and [S3, unofficial] is used as the primary implementation.

**Pseudocode:**
```python
import math

def bend(p, sdf, k):
    """
    Bends the SDF around the X-axis by degree k.
    :param p: vec3, input point
    :param sdf: function, the base SDF primitive
    :param k: float, bend degree
    :return: float, deformed SDF value
    """
    # Step 1: Calculate rotation angle
    theta = k * p.x
    
    # Step 2: Compute trigonometric components
    c = math.cos(theta)
    s = math.sin(theta)
    
    # Step 3 & 4: Construct rotation matrix and apply to YZ components
    p_prime_x = p.x
    p_prime_y = c * p.y - s * p.z
    p_prime_z = s * p.y + c * p.z
    
    # Step 5: Evaluate SDF at transformed point
    p_prime = (p_prime_x, p_prime_y, p_prime_z)
    d = sdf(p_prime)
    
    # Step 6: Return result
    return d
```

**Parameters:**
- $k$: Bend degree. A float input determining the degree of the bend [S3, unofficial].

**Edge Cases and Pitfalls:**
- Precision: For large $k$ or large $p_x$, the rotation angle becomes large, potentially causing self-intersection or folding of the SDF if the primitive is not convex or if the bend is too severe [G].
- Boundary: The bend is applied globally to the entire space. If the primitive is bounded, the deformation may extend beyond the intended object bounds if not clamped [G].

## Operating characteristics
- Time Complexity: $O(1)$ per point evaluation, as it involves a constant number of trigonometric operations and one SDF evaluation [G].
- Memory Complexity: $O(1)$, no additional memory required [G].
- Strengths: Simple to implement, computationally cheap, effective for creating curved organic shapes [G].
- Limitations: Can cause self-intersection if the bend degree is too high relative to the object's thickness. Not suitable for creating complex, non-uniform deformations without additional control points [G].
- When to use: When you need to curve a straight primitive (like a cylinder or box) into an arc [G].
- When not to use: When you need a twist or torsion effect (use [Twist](1722-twist.md)) or a simple rigid rotation (use [RotateX](1720-rotatex.md)) [G].

## Background
Bend is a geometric operation used in SDF-based rendering [S3, unofficial]. It is a fundamental building block for creating more complex organic shapes by combining simple primitives with deformations [S3, unofficial].
