# Rotation Matrix Computation
Also called: Rodrigues' Rotation Formula
## Overview
Computes a 3x3 rotation matrix from a rotation axis and angle [S1, unofficial]. It provides a direct algebraic solution for orientation, distinct from sequential axis rotations or quaternion conversions.
## How it works
**Inputs:** Unit axis vector $\mathbf{n} = [n_x, n_y, n_z]^T$ and rotation angle $\theta$ (radians).
**Output:** 3x3 rotation matrix $R$.

1. Compute $c = \cos(\theta)$ and $s = \sin(\theta)$ [S1, unofficial].
2. Compute the outer product term $n_i n_j (1 - c)$ [S1, unofficial].
3. Compute the skew-symmetric cross-product matrix term $\epsilon_{ijk} n_k s$ [S1, unofficial].
4. Add the identity term $\delta_{ij} c$ [S1, unofficial].
5. Sum components to form $R_{ij}$ [S1, unofficial].

Formula:
$$R_{ij} = n_i n_j (1 - c) + \epsilon_{ijk} n_k s + \delta_{ij} c$$

Where $\epsilon_{ijk}$ is the Levi-Civita symbol and $\delta_{ij}$ is the Kronecker delta [S1, unofficial].

```python
import numpy as np

def rotation_matrix_from_axis_angle(axis, angle):
    """
    Compute rotation matrix using Rodrigues' formula.
    :param axis: 3D vector [nx, ny, nz]
    :param angle: Rotation angle in radians
    :return: 3x3 rotation matrix
    """
    # Normalize axis [G]
    n = axis / np.linalg.norm(axis)
    nx, ny, nz = n
    
    c = np.cos(angle)
    s = np.sin(angle)
    one_minus_c = 1.0 - c
    
    # Rodrigues' formula components
    # R = I*cos(theta) + (1-cos(theta))*n*n^T + sin(theta)*[n]x
    # Expanded element-wise as per [S1, unofficial]
    
    # Diagonal elements
    r00 = nx*nx*one_minus_c + c
    r11 = ny*ny*one_minus_c + c
    r22 = nz*nz*one_minus_c + c
    
    # Off-diagonal elements
    # epsilon_012 = 1, epsilon_021 = -1, etc.
    r01 = nx*ny*one_minus_c - nz*s
    r02 = nx*nz*one_minus_c + ny*s
    r10 = ny*nx*one_minus_c + nz*s
    r12 = ny*nz*one_minus_c - nx*s
    r20 = nz*nx*one_minus_c - ny*s
    r21 = nz*ny*one_minus_c + nx*s
    
    return np.array([
        [r00, r01, r02],
        [r10, r11, r12],
        [r20, r21, r22]
    ])
```

**Edge Cases:** If $\mathbf{n}$ is zero, the axis is undefined [G]. If $\theta$ is 0, $R$ is identity.

### Combined Rotation Matrix
Generates individual rotation matrices for X, Y, and Z axes using angles phi, theta, and psi, then combines them by multiplying in Z-Y-X order: `result = rz @ ry @ rx` [S2, unofficial].

## Operating characteristics
Time complexity is $O(1)$ for fixed 3x3 output. Memory is minimal (9 floats). Precision issues may arise if axis is not normalized [G].
## Background
Rodrigues' formula is a classical result in rigid body dynamics. Implemented in various graphics repositories [S1, unofficial][S2, unofficial].
