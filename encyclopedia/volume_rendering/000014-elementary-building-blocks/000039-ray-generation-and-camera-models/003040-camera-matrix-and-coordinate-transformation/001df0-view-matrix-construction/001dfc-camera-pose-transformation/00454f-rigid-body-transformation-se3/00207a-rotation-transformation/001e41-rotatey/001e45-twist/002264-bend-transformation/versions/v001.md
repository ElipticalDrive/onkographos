# Bend Transformation

Also called: Bend

## Overview
The Bend Transformation bends 3D space along the X-axis around the Y-axis, creating a curvature effect on the coordinate system [S1, unofficial]. It is distinct from its sibling [Bend](2044-bend.md) and parent [Twist](1722-twist.md) by its specific axis of rotation (Y) and the linear dependency of the rotation angle on the X-coordinate, rather than the Z-coordinate or a global twist [S1, unofficial].

## How it works
**Inputs:**
- `p`: Input 3D position vector $(x, y, z)$.
- `k`: Bend strength parameter (scalar).

**Outputs:**
- `p'`: Transformed 3D position vector $(x', y', z')$.

**Data Structures:**
- `Vec3`: A structure containing three floating-point fields `x`, `y`, `z`.

**Steps:**
1. Calculate the rotation angle based on the X-coordinate and the bend strength:
   $$ \theta = k \cdot p.x $$
2. Compute the sine and cosine of the angle:
   $$ c = \cos(\theta) $$
   $$ s = \sin(\theta) $$
3. Apply the 2D rotation matrix to the X and Y components, leaving Z unchanged:
   $$ p'.x = c \cdot p.x - s \cdot p.y $$
   $$ p'.y = s \cdot p.x + c \cdot p.y $$
   $$ p'.z = p.z $$

**Pseudocode:**
```python
def bend_transformation(p: Vec3, k: float) -> Vec3:
    # Calculate angle based on X coordinate and bend strength
    angle = k * p.x
    
    # Compute trigonometric values
    cos_a = math.cos(angle)
    sin_a = math.sin(angle)
    
    # Apply rotation to X and Y components
    new_x = cos_a * p.x - sin_a * p.y
    new_y = sin_a * p.x + cos_a * p.y
    new_z = p.z
    
    return Vec3(new_x, new_y, new_z)
```

**Parameters:**
- `k`: Bend strength. Typical values depend on the desired curvature radius. Not given in the sources.

**Edge Cases and Pitfalls:**
- **Precision:** Standard floating-point precision is sufficient for typical scene scales.
- **Boundaries:** The transformation is unbounded in X and Y, but the curvature increases linearly with X. Large X values or large `k` can result in extreme rotations.
- **Degenerate Input:** None specific, as the operation is a standard rotation.

## Subtopics

### XYZ Transform
The XYZ Transform is a general module that modifies 3D coordinate space before it reaches a 3D Mask [S2]. It can perform operations such as moving, rotating, repeating, folding, wrapping, bending, twisting, or distorting (noise, sine) the coordinates [S2]. Unlike the specific Bend Transformation, XYZ Transform is a broader category of coordinate manipulation [S2]. It is used when multiple types of coordinate modifications are needed or when the specific bend logic is abstracted into a reusable module [S2]. The 3D Mask receives the transformed coordinates and calculates the shape in its own space, resulting in modified outputs (e.g., many spheres instead of one if repeated) [S2].

## Operating characteristics
**Time and Memory Complexity:**
- Time: $O(1)$ per point.
- Memory: $O(1)$ auxiliary space.

**Measured Performance:**
- Not given in the sources.

**Scaling:**
- The transformation scales linearly with the number of points processed.

**Strengths and Limitations:**
- **Strengths:** Simple to implement, computationally inexpensive, creates smooth curvature effects.
- **Limitations:** Limited to bending around the Y-axis with linear angle dependency. Not suitable for complex non-linear deformations without additional steps.

**When to Use:**
- Use when a simple curvature effect along the X-axis is required.

**When Not to Use:**
- Use [Twist](1722-twist.md) if the rotation should depend on the Z-axis.
- Use [Bend](2044-bend.md) if a different axis or bending logic is required.

## Background
The Bend Transformation is defined in the context of Signed Distance Field (SDF) math libraries [S1, unofficial]. It is part of a set of coordinate transformations used to manipulate 3D space for procedural shape generation. The specific implementation is found in the `sdf-math-rs` repository [S1, unofficial].
