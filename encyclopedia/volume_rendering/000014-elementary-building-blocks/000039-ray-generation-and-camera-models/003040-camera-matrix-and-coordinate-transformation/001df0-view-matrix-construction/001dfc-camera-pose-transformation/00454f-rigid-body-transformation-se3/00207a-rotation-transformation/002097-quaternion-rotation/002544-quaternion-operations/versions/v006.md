# Quaternion Operations

Also called: Quaternion Conjugate, Quaternion Multiplication, Rotate vector by quaternion

## Overview
Computes quaternion conjugation, multiplication, and vector rotation for 3D graphics [S1, unofficial]. It provides the algebraic primitives required by [Quaternion Rotation](2302-quaternion-rotation.md) and differs from [Quaternion to SO3 Conversion](2305-quaternion-to-so3-conversion.md) by operating directly on quaternion components rather than converting to rotation matrices [S1, unofficial].

## How it works
### Inputs and Outputs
- **Inputs**: Two quaternions $q_0 = (x_0, y_0, z_0, w_0)$ and $q_1 = (x_1, y_1, z_1, w_1)$, or a single quaternion $q$ and a 3D vector $\mathbf{v}$ [S1, unofficial].
- **Outputs**: A resulting quaternion $q_{res}$, or a rotated 3D vector $\mathbf{v}'$ [S1, unofficial].

### Data Structures
Quaternions are stored as 4-component vectors in the layout $(x, y, z, w)$, where $x, y, z$ are the imaginary components and $w$ is the scalar (real) component [S1, unofficial].

### Formulas
**1. Quaternion Conjugate**
The conjugate $q^*$ of a quaternion $q = (x, y, z, w)$ negates the vector part [S1, unofficial]:
$$ q^* = (-x, -y, -z, w) $$

**2. Quaternion Multiplication**
The product $q = q_0 \otimes q_1$ is computed component-wise [S1, unofficial]:
$$
\begin{aligned}
x &= w_0 x_1 + x_0 w_1 + y_0 z_1 - z_0 y_1 \\
y &= w_0 y_1 - x_0 z_1 + y_0 w_1 + z_0 x_1 \\
z &= w_0 z_1 + x_0 y_1 - y_0 x_1 + z_0 w_1 \\
w &= w_0 w_1 - x_0 x_1 - y_0 y_1 - z_0 z_1
\end{aligned}
$$

**3. Rotate Vector by Quaternion**
To rotate a 3D vector $\mathbf{v} = (v_x, v_y, v_z)$ by a quaternion $q$:
1. Treat $\mathbf{v}$ as a pure quaternion $q_v = (v_x, v_y, v_z, 0.0)$ [S1, unofficial].
2. Compute the intermediate quaternion $q_{temp} = q_v \otimes q^*$ [S1, unofficial].
3. Compute the result quaternion $q_{ret} = q \otimes q_{temp}$ [S1, unofficial].
4. Extract the vector part $(x, y, z)$ of $q_{ret}$ as the result $\mathbf{v}'$ [S1, unofficial].

### Pseudocode
```python
def quaternion_conjugate(q):
    """Computes the conjugate of q = [x, y, z, w]. Returns [-x, -y, -z, w]."""
    return [-q[0], -q[1], -q[2], q[3]]

def quaternion_multiply(q0, q1):
    """Multiplies two quaternions q0 and q1 = [x, y, z, w]. Returns q0 * q1."""
    x0, y0, z0, w0 = q0[0], q0[1], q0[2], q0[3]
    x1, y1, z1, w1 = q1[0], q1[1], q1[2], q1[3]
    
    x = w0 * x1 + x0 * w1 + y0 * z1 - z0 * y1
    y = w0 * y1 - x0 * z1 + y0 * w1 + z0 * x1
    z = w0 * z1 + x0 * y1 - y0 * x1 + z0 * w1
    w = w0 * w1 - x0 * x1 - y0 * y1 - z0 * z1
    
    return [x, y, z, w]

def rotate_vector_by_quaternion(v, q):
    """Rotates a 3D vector v by a quaternion q. Returns rotated vector as [x, y, z]."""
    q_v = [v[0], v[1], v[2], 0.0]
    q_conj = quaternion_conjugate(q)
    q_temp = quaternion_multiply(q_v, q_conj)
    q_result = quaternion_multiply(q, q_temp)
    return [q_result[0], q_result[1], q_result[2]]
```

### Parameters and Edge Cases
- **Normalization**: The rotation formula assumes $q$ is a unit quaternion ($|q|=1$) to preserve vector magnitude [G].
- **Precision**: Standard floating-point arithmetic is used; accumulated errors in repeated multiplications may require re-normalization of quaternions over time [G].
- **Degenerate Input**: The multiplication and conjugate operations are defined for all quaternions [S1, unofficial]. The rotation operation is valid for any vector [S1, unofficial].

## Subtopics

### Quaternion Möbius Transformations
Conformal transformations of 3D space formalized as quaternion Möbius transformations generated by translations, rotations, dilations, reflections, and geometric inversions [S2]. The transformation is defined as $L_H(q) = (aq+b)(cq+d)^{-1}$, where $q, a, b, c, d \in \mathbb{H}$ (quaternions) [S2]. Elementary transformations are represented by $2 \times 2$ quaternionic matrices. Types include Identity $L(q)=q$, Dilation $L(q)=sq$ ($s \in \mathbb{R}$), Translation $L(q)=q+v$ ($v \in \mathbb{H}_0$), Inversion $L(q)=rq^{-1}$, Reflection $L(q)=-iq$, and Inversion $L(q)=q^{-1}$ [S2]. The composition of two Möbius transformations is also a Möbius transformation, with coefficients obtainable as a matrix product [S2].

### Index-to-World Clipping Plane Generation
A method for generating clipping planes for volume rendering based on an index-to-world transformation matrix [S3, unofficial]. It extracts the rotation quaternion from the transformation matrix using `mat4.getRotation` [S3, unofficial]. It defines a vector rotation helper `rotateVec` that transforms 3D vectors by this quaternion [S3, unofficial]. It parses input `ijkPlanes` bounds `[iMin, iMax, jMin, jMax, kMin, kMax]` [S3, unofficial]. It instantiates six `vtkPlane` objects: min planes use the origin and rotated positive unit vectors as normals; max planes use the corner and rotated negative unit vectors as normals [S3, unofficial]. These planes are applied to the volume mapper by clearing existing planes and adding the new ones [S3, unofficial].

## Background
Quaternion operations are fundamental to 3D geometry processing [S1, unofficial]. The specific multiplication and conjugate formulas are standard in computer graphics literature [S1, unofficial]. The application of quaternion Möbius transformations to conformal sphere tracing was introduced in the context of volume rendering to handle complex geometries [S2]. The use of quaternions for clipping plane generation in web-based volume rendering applications using VTK is documented in unofficial repositories [S3, unofficial]. The implementation details in [S1, unofficial] are from a Taichi-based 3D Gaussian Splatting project.
