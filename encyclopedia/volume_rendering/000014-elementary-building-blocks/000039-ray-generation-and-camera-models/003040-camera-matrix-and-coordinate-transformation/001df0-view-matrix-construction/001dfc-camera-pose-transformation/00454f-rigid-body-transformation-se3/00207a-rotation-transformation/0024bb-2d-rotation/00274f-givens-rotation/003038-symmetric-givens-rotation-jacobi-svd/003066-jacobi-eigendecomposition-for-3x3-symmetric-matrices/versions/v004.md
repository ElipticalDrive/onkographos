# Jacobi Eigendecomposition for 3x3 Symmetric Matrices

Also called: Eigenanalysis, Hessian Eigenvalue Computation via Jacobi's Method, Jacobi method, Jacobi's Method, Tensor Diagonalization, Tensor Eigenvalue Decomposition, Tensor Eigenvalue Equation

## Overview
The Jacobi eigendecomposition method computes the eigenvalues and eigenvectors of a 3x3 symmetric matrix by iteratively applying Givens rotations to zero out off-diagonal elements [S2, unofficial]. It transforms the input matrix $A$ into a diagonal matrix via an orthogonal similarity transformation $U^T A U = \text{diag}(\lambda_1, \lambda_2, \lambda_3)$, where the diagonal entries are the eigenvalues and the columns of $U$ are the corresponding eigenvectors [S1, book]. It is preferred over explicit cubic polynomial solutions because the latter are more complex to implement [S3]. It is primarily used in volume rendering for tensor field analysis, such as stress tensor visualization, where the principal directions and magnitudes are critical [S1, book][S4, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A 3x3 symmetric matrix $A$ where $A_{ij} = A_{ji}$ for $i,j = 1,2,3$ [S4, unofficial]. The input matrix is destroyed during computation [S2, unofficial].
- Output: An array $d$ of 3 eigenvalues, sorted by decreasing modulus [S2, unofficial]. An orthogonal matrix $V$ (3x3) containing the corresponding eigenvectors as columns [S2, unofficial].

**Data Structures:**
- Matrix $A$: 3x3 array of floats. Layout: `A[0][0]`, `A[0][1]`, `A[0][2]`, `A[1][1]`, `A[1][2]`, `A[2][2]` (upper triangular) or full 3x3.
- Eigenvalues $d$: Array of 3 floats.
- Eigenvectors $V$: 3x3 array of floats. Initialized to Identity matrix $I$.

**Parameters:**
- `TOLERANCE`: Convergence threshold for the iterative method. Typical value: $0.0001$ [S2, unofficial].
- `MAX_ITERATIONS`: Maximum number of sweeps to prevent infinite loops in degenerate cases. Not given in the sources. [G]

**Algorithm Steps:**
1. **Initialization:** Copy input matrix $A$ to a working matrix $a$ [G]. Initialize eigenvector matrix $V$ to the 3x3 identity matrix [G]. Initialize eigenvalue array $d$ with the diagonal elements of $a$ [G].
2. **Iteration Loop:** Repeat the following sweeps until convergence or max iterations reached [G].
   a. Calculate the sum of squared off-diagonal elements: $S = \sum_{i \neq j} a_{ij}^2$ [G].
   b. If $S < \text{TOLERANCE}$, terminate [G].
   c. Perform a sweep over all unique off-diagonal pairs $(p, q)$ where $0 \le p < q \le 2$ [G].
   d. For each pair $(p, q)$:
      i. Compute the rotation angle $\theta$ to zero out $a_{pq}$ [G].
      ii. Construct the Givens rotation matrix $G(p, q, \theta)$ [G].
      iii. Update the working matrix: $a \leftarrow G^T a G$ [G].
      iv. Update the eigenvector matrix: $V \leftarrow V G$ [G].
3. **Sorting:** Sort the eigenvalues in $d$ in descending order of magnitude [S2, unofficial]. The eigenvector matrix $V$ is reordered correspondingly to maintain the pairing of eigenvalues and eigenvectors [G].

**Formulas:**
The core operation is the Givens rotation on indices $p$ and $q$. Let $a_{pp}, a_{qq}, a_{pq}$ be the relevant elements.
The rotation parameters are determined by:
$$ \tau = \frac{a_{qq} - a_{pp}}{2 a_{pq}} $$
$$ t = \text{sign}(\tau) \frac{1}{|\tau| + \sqrt{1 + \tau^2}} $$
$$ c = \frac{1}{\sqrt{1 + t^2}}, \quad s = t c $$

The matrix $a$ is updated as follows (for $i \neq p, q$):
$$ a_{ip} \leftarrow c a_{ip} + s a_{iq} $$
$$ a_{iq} \leftarrow -s a_{ip} + c a_{iq} $$
$$ a_{pi} \leftarrow a_{ip} $$
$$ a_{qi} \leftarrow a_{iq} $$
And for the diagonal and off-diagonal elements of the rotated block:
$$ a_{pp} \leftarrow c^2 a_{pp} - 2sc a_{pq} + s^2 a_{qq} $$
$$ a_{qq} \leftarrow s^2 a_{pp} + 2sc a_{pq} + c^2 a_{qq} $$
$$ a_{pq} \leftarrow 0 $$
$$ a_{qp} \leftarrow 0 $$

The eigenvector matrix $V$ is updated by applying the same rotation to its columns $p$ and $q$:
$$ v_{ip} \leftarrow c v_{ip} + s v_{iq} \quad \forall i $$
$$ v_{iq} \leftarrow -s v_{ip} + c v_{iq} \quad \forall i $$

**Pseudocode:**
```python
def jacobi_eigen_3x3(a):
    """
    Computes eigenvalues and eigenvectors of a 3x3 symmetric matrix.
    Input: a (3x3 list of lists), symmetric.
    Output: d (list of 3 floats, sorted desc), v (3x3 list of lists, eigenvectors as columns).
    """
    # Initialize working matrix and eigenvector matrix
    m = [row[:] for row in a]  # Copy input [G]
    v = [[1.0 if i == j else 0.0 for j in range(3)] for i in range(3)]  # Identity [G]
    
    tolerance = 1e-4  # [S2, unofficial]
    max_sweeps = 100  # [G]
    sweep = 0
    
    while sweep < max_sweeps:
        # Calculate sum of squared off-diagonal elements [G]
        off_diag_sum = 0.0
        for i in range(3):
            for j in range(i + 1, 3):
                off_diag_sum += m[i][j] ** 2
        
        if off_diag_sum < tolerance:
            break  # [G]
            
        # Sweep over pairs (0,1), (0,2), (1,2) [G]
        pairs = [(0, 1), (0, 2), (1, 2)]
        for p, q in pairs:
            # Skip if element is already zero or negligible [G]
            if abs(m[p][q]) < 1e-10:
                continue
                
            # Calculate rotation parameters [G]
            apq = m[p][q]
            app = m[p][p]
            aqq = m[q][q]
            
            tau = (aqq - app) / (2.0 * apq)
            t = 1.0 / (abs(tau) + (1.0 + tau**2)**0.5)
            if tau < 0:
                t = -t
            
            c = 1.0 / (1.0 + t**2)**0.5
            s = t * c
            
            # Update matrix m [G]
            for i in range(3):
                if i == p or i == q:
                    continue
                m_ip = m[i][p]
                m_iq = m[i][q]
                m[i][p] = c * m_ip + s * m_iq
                m[p][i] = m[i][p]
                m[i][q] = -s * m_ip + c * m_iq
                m[q][i] = m[i][q]
            
            # Update diagonal and off-diagonal elements p,q [G]
            m_pp = c**2 * app - 2 * c * s * apq + s**2 * aqq
            m_qq = s**2 * app + 2 * c * s * apq + c**2 * aqq
            m[p][p] = m_pp
            m[q][q] = m_qq
            m[p][q] = 0.0
            m[q][p] = 0.0
            
            # Update eigenvector matrix v [G]
            for i in range(3):
                v_ip = v[i][p]
                v_iq = v[i][q]
                v[i][p] = c * v_ip + s * v_iq
                v[i][q] = -s * v_ip + c * v_iq

        sweep += 1

    # Extract eigenvalues from diagonal [G]
    d = [m[0][0], m[1][1], m[2][2]]
    
    # Sort eigenvalues in descending order and permute v [G]
    for i in range(3):
        for j in range(i + 1, 3):
            if d[j] > d[i]:
                d[i], d[j] = d[j], d[i]
                # Swap columns i and j in v
                for k in range(3):
                    v[k][i], v[k][j] = v[k][j], v[k][i]
                    
    return d, v
```

**Edge Cases and Pitfalls:**
- **Symmetry Violation:** The tensor must be symmetric ($A_{ij} = A_{ji}$) to guarantee real eigenvalues and orthogonal eigenvectors forming a 3D orthogonal coordinate system [S4, unofficial].
- **Degenerate Eigenvalues:** If two eigenvalues are equal, the corresponding eigenvectors are not unique [G].
- **Precision:** Floating-point errors can accumulate during iterative rotations. Using double precision is recommended for high-accuracy applications [G].

## Subtopics

### 3x3 Symmetric Matrix Pseudo-Inverse via SVD
A variant that computes the pseudo-inverse of a 3x3 symmetric matrix using SVD via Givens rotations, specifically for solving Quadratic Error Function (QEF) systems in dual contouring [S5, unofficial]. It differs from standard eigendecomposition by inverting singular values to solve linear systems $A x = b$ [S5, unofficial]. It operates on a 6-element array representing the triangular matrix, initializes $V$ as identity, computes $V^T A V$, and performs 4 Givens rotation sweeps on pairs (0,1), (0,2), (1,2) [S5, unofficial]. The rotation coefficients are calculated to zero out off-diagonal elements, and singular values below $10^{-6}$ are treated as zero during pseudo-inverse computation [S5, unofficial].

## Background
The method is a classic algorithm for symmetric eigenvalue problems [G]. In volume rendering, it is used for tensor field visualization, such as stress tensor analysis, where the principal directions and magnitudes are critical [S1, book][S4, unofficial].
