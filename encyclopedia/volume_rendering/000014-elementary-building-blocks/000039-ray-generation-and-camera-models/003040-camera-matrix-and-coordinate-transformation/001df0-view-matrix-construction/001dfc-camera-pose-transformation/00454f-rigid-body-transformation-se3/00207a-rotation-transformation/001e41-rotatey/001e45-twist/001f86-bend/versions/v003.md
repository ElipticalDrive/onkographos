# Bend
Also called: Simple Brush Deformation
## Overview
Bend is a geometric deformation operation for Signed Distance Fields that curves a shape around the X-axis [S1, S3, unofficial]. Unlike [Twist](1722-twist.md), which rotates geometry around the Y-axis, Bend applies a spatially varying rotation around the X-axis to create a smooth arc [S1, S3, unofficial].
## How it works
**Inputs and Outputs:**
- Input: A point $p$ in 3D space, an SDF primitive function $S$, and a bend degree parameter $k$ (float) [S1, S3, unofficial].
- Output: The transformed point $p'$ [S1, unofficial].

**Data Structures:**
- No persistent data structures. The operation is point-wise and stateless [S1, unofficial].

**Steps:**
1. **Calculate Rotation Angle:** Compute $\theta = k \cdot p_x$ [S1, unofficial].
2. **Compute Trigonometric Components:** Calculate $c = \cos(\theta)$ and $s = \sin(\theta)$ [S1, unofficial].
3. **Construct Rotation Matrix:** Form the 2D rotation matrix $M = \begin{bmatrix} c & -s \\ s & c \end{bmatrix}$ [S1, unofficial].
4. **Apply Rotation:** Rotate the XY components of $p$ by $M$ to obtain $p'$ [S1, unofficial]. (Note: The evidence explicitly specifies rotating the XY components, which differs from the standard YZ rotation for X-axis bending; this implementation follows the source exactly.)
5. **Return Transformed Point:** Return $p'$ [S1, unofficial].

**Pseudocode:**
```python
import math

def bend(p, sdf, k):
    """
    Bends the SDF around the X-axis by degree k.
    :param p: vec3, input point
    :param sdf: function, the base SDF primitive
    :param k: float, bend degree
    :return: vec3, transformed point
    """
    # Step 1: Calculate rotation angle
    theta = k * p.x
    
    # Step 2: Compute trigonometric components
    c = math.cos(theta)
    s = math.sin(theta)
    
    # Step 3 & 4: Construct rotation matrix and apply to XY components
    p_prime_x = c * p.x - s * p.y
    p_prime_y = s * p.x + c * p.y
    p_prime_z = p.z
    
    # Step 5: Return transformed point
    p_prime = (p_prime_x, p_prime_y, p_prime_z)
    return p_prime
```

**Parameters:**
- $k$: Bend degree. A float input which determines the degree of the bend [S3, unofficial].

**Edge Cases and Pitfalls:**
- Not given in the sources.

## Operating characteristics
- Time Complexity: $O(1)$ per point evaluation, involving a constant number of trigonometric operations and one SDF evaluation [G].
- Memory Complexity: $O(1)$, no additional memory required [G].
- Strengths: Simple to implement and computationally cheap [G].
- Limitations: Not given in the sources.
- When to use: When you need to curve a straight primitive into an arc [G].
- When not to use: When you need a twist or torsion effect (use [Twist](1722-twist.md)) or a simple rigid rotation (use [RotateX](1720-rotatex.md)) [G].

## Background
Bend is a geometric deformation operation defined for Signed Distance Fields [S3, unofficial]. It is listed alongside RotateX, RotateY, RotateZ, and Twist as a basic transformation in raymarching projects [S3, unofficial]. The operation is used in SDF-based rendering to create curved geometry [S3, unofficial].
