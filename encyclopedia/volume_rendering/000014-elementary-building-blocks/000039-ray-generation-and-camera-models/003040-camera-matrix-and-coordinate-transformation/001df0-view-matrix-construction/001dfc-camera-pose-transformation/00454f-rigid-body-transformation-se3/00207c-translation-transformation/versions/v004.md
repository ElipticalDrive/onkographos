# Translation Transformation

Also called: Translation

## Overview
A geometric transformation that moves a shape or point by a given vector [S1, unofficial]. It is the translational component of a rigid body transformation, distinct from rotation and scaling. In the context of camera pose transformation, it defines the position of the camera center in world space relative to the origin.

## How it works
**Inputs:**
- Point $p$ (3D vector).
- Translation vector $t$ (3D vector).

**Outputs:**
- Translated point $p'$ (3D vector).

**Data Structures:**
- Points and vectors are represented as 3D Cartesian coordinates $(x, y, z)$.

**Steps:**
1. Compute the translated point $p'$ by subtracting the translation vector $t$ from the point $p$.
   $$ p' = p - t $$
   Note: The source [S1, unofficial] explicitly states "Subtract the translation vector t from the point p." This implies a specific convention where $t$ represents the offset to be removed or the vector from the target to the source, or potentially a typo in the source for standard addition $p' = p + t$. However, adhering strictly to the source text:
   $$ p'_x = p_x - t_x $$
   $$ p'_y = p_y - t_y $$
   $$ p'_z = p_z - t_z $$

**Parameters:**
- The second argument is the translation vector [S1, unofficial].

**Edge Cases:**
- None specified in sources.

**Pseudocode:**
```python
def translation_transformation(p: Vector3, t: Vector3) -> Vector3:
    """
    Transforms point p by translation vector t.
    Based on source [S1, unofficial]: Subtract the translation vector t from the point p.
    """
    # p' = p - t
    return Vector3(p.x - t.x, p.y - t.y, p.z - t.z)
```

Time complexity: $O(1)$. Memory complexity: $O(1)$. Strengths: Simple, computationally inexpensive. Limitations: Only handles positional shifts, not orientation changes.
