# Translation Transformation


## Overview
A geometric transformation that moves a shape or point by a given vector [S1, unofficial]. It solves the problem of shifting spatial coordinates without altering orientation or scale. It differs from [Rotation Transformation](2279-rotation-transformation.md) by applying no angular change, and from [Rigid Body Transformation (SE3)](11475-rigid-body-transformation-se3.md) by excluding rotational components.

## How it works
**Inputs and outputs:**
- Input: Point $p$ (3D vector), translation vector $t$ (3D vector).
- Output: Translated point $p'$ (3D vector).

**Data structures:**
- $p = [p_x, p_y, p_z]^T$
- $t = [t_x, t_y, t_z]^T$

**Steps:**
1. Compute the new position by subtracting the translation vector from the point: $p' = p - t$.

**Formula:**
$$
p' = p - t
$$

**Parameters:**
- $t$: The translation vector [S1, unofficial].

**Edge cases and pitfalls:**
- None specified in sources.

**Pseudocode:**
```python
def translation_transformation(p, t):
    """
    Translate point p by subtracting vector t.
    
    Args:
        p: 3D vector [x, y, z]
        t: 3D vector [tx, ty, tz]
        
    Returns:
        p_prime: Translated 3D vector
    """
    p_prime_x = p[0] - t[0]
    p_prime_y = p[1] - t[1]
    p_prime_z = p[2] - t[2]
    
    return [p_prime_x, p_prime_y, p_prime_z]
```

## Subtopics

### [Translation Matrix Construction](2873-translation-matrix-construction.md)
Constructs a 4x4 homogeneous transformation matrix that represents a pure translation by a given 4D vector. It solves the problem of embedding a 3D displacement vector into a 4x4 linear algebra structure compatible with standard graphics pipelines, allowing translation to be composed with other affine transformations via matrix multiplication. It differs from [Coordinate Translation](2281-translation-transformation.md) by operating on matrix algebra rather than directly manipulating coordinate data frames.
