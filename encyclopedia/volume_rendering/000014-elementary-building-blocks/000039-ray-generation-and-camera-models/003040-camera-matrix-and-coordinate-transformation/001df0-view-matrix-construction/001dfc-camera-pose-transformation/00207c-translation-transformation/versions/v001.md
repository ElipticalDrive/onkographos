# Translation Transformation
Also called: Translation
## Overview
A geometric transformation that moves a shape or coordinate system by a given vector [S1, unofficial]. In the context of camera pose transformation, it adjusts the origin of the view space relative to the world space [S1, unofficial]. It is distinct from rotation transformations, which change orientation but not position [S1, unofficial].
## How it works
**Inputs and outputs:**
- Input: A point $p$ (or ray origin) and a translation vector $t$.
- Output: The translated point $p'$.

**Data structures:**
- Point $p$: 3D vector $(p_x, p_y, p_z)$.
- Translation vector $t$: 3D vector $(t_x, t_y, t_z)$.

**Steps:**
1. Subtract the translation vector $t$ from the point $p$ to obtain the new position $p'$.
   $$p' = p - t$$
   [S1, unofficial]

**Parameters:**
- $t$: The translation vector [S1, unofficial].

**Edge cases and pitfalls:**
- If $t$ is zero, the point remains unchanged.
- Precision issues may arise if $p$ and $t$ have vastly different magnitudes.

**Pseudocode:**
```python
def translate_point(p: Vector3, t: Vector3) -> Vector3:
    """
    Translates point p by vector t.
    According to [S1, unofficial], the step is to subtract t from p.
    """
    return p - t
```

## Subtopics

### Translation Matrix Construction
Creates a 4x4 translation matrix for a given 4D vector $v$ [S2, unofficial].
- **Definition:** Constructs a homogeneous transformation matrix where the translation components are placed in the last column [S2, unofficial].
- **Steps:**
    1. Validate that $v$ is a 4D vector (projective vector, PV) [S2, unofficial].
    2. Initialize a 4x4 identity matrix `mat` [S2, unofficial].
    3. Set `mat[0][3] = v[0]`, `mat[1][3] = v[1]`, `mat[2][3] = v[2]` [S2, unofficial].
    4. Return `mat` [S2, unofficial].
- **When to choose:** Use when applying translation to points in homogeneous coordinates via matrix multiplication, rather than direct vector subtraction [S2, unofficial].

## Operating characteristics
- **Time complexity:** $O(1)$ for vector subtraction. $O(1)$ for matrix construction (fixed 4x4).
- **Memory complexity:** $O(1)$ for vector; $O(1)$ for matrix (16 floats).
- **Strengths:** Simple, computationally inexpensive.
- **Limitations:** Does not handle rotation or scaling. Requires homogeneous coordinates for matrix form.
- **When to use:** When only positional offset is needed.
- **When not:** When orientation changes are required (use Rotation Transformation).

## Background
Originating from basic linear algebra and computer graphics, translation is a fundamental affine transformation. It is widely used in camera pose estimation and ray generation to position the camera origin in world space [S1, unofficial]. The matrix form is standard in OpenGL and WebGL pipelines [S2, unofficial].
