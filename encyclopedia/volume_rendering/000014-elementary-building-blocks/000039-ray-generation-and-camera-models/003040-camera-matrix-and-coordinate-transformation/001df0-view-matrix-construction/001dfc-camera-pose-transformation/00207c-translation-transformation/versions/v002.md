# Translation Transformation
Also called: Translation
## Overview
A geometric transformation that moves a shape by a given vector [S1, unofficial]. It adjusts positional offsets without altering orientation, distinguishing it from rotation transformations [G].
## How it works
**Inputs and outputs:**
- Input: A point $p$ and a translation vector $t$.
- Output: The translated point $p'$.

**Data structures:**
- Point $p$: 3D vector $(p_x, p_y, p_z)$ [G].
- Translation vector $t$: 3D vector $(t_x, t_y, t_z)$ [G].

**Steps:**
1. Subtract the translation vector $t$ from the point $p$ to obtain the new position $p'$.
   $$p' = p - t$$
   [S1, unofficial]

**Parameters:**
- $t$: The translation vector [S1, unofficial].

**Edge cases and pitfalls:**
- If $t$ is zero, the point remains unchanged [G].
- Precision issues may arise if $p$ and $t$ have vastly different magnitudes [G].

**Pseudocode:**
```python
def translate_point(p: list, t: list) -> list:
    """
    Translates point p by subtracting vector t.
    Implements step from [S1, unofficial].
    """
    return [p[i] - t[i] for i in range(3)]
```
## Subtopics

### Translation Matrix Construction
Creates a 4x4 translation matrix for a given 4D vector $v$ [S2, unofficial].
- **Definition:** Constructs a homogeneous transformation matrix where the translation components are placed in the last column [S2, unofficial].
- **Steps:**
    1. Validate $v$ is a projective vector (PV) [S2, unofficial].
    2. Initialize a 4x4 matrix `mat` [S2, unofficial].
    3. Set `mat[0][3] = v[0]`, `mat[1][3] = v[1]`, `mat[2][3] = v[2]` [S2, unofficial].
    4. Return `mat` [S2, unofficial].
- **When to choose:** Use when applying translation to points in homogeneous coordinates via matrix multiplication, rather than direct vector subtraction [S2, unofficial].
