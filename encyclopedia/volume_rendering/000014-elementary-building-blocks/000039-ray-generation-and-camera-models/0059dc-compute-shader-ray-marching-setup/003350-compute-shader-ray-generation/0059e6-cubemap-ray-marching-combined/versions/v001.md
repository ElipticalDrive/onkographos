# Cubemap Ray Marching (Combined)


## Overview
Cubemap Ray Marching (Combined) is a compute shader-based method for rendering volumetric effects by casting rays into a cube map environment, typically to capture volumetric shadows or lighting from a single light source in all directions [S1, unofficial]. It differs from single-direction ray marching by utilizing a CubeCamera approach to cover the full sphere, overcoming the limited coverage of a standard directional light camera [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** Per-object data, per-frame data, sample resolution (`CB_SAMPLE_RES`), grid size (`m_gridSize`), cube map LOD (`m_cubeMapLOD`), cube face count (`m_cubeFaceCount`), color SRV, optional spherical harmonic coefficients SRV (`m_coeffSH`), and optional cube face culling CBV [S1, unofficial].
- **Outputs:** A bound UAV for the cube map at the specified LOD [S1, unofficial].

**Data Structures:**
- `m_gridSize`: A 3D vector defining the simulation grid dimensions [S1, unofficial].
- `m_cubeMapLOD`: An integer defining the LOD level for the cube map [S1, unofficial].
- `m_cubeFaceCount`: An integer defining the number of cube map faces to process [S1, unofficial].
- `CB_SAMPLE_RES`: A constant buffer containing sample resolution parameters [S1, unofficial].

**Steps:**
1. Set the compute shader to `CS_RAY_MARCH` [S1, unofficial].
2. Bind the UAV for the cube map at the specific LOD `m_cubeMapLOD` [S1, unofficial].
3. Bind Constant Buffer Views (CBVs) for per-object, per-frame, and sample resolution (`CB_SAMPLE_RES`) [S1, unofficial].
4. Conditionally bind a CBV for cube face culling or a list, based on the `_CPU_CUBE_FACE_CULL_` macro (values 1 or 2) [S1, unofficial].
5. Bind the Shader Resource View (SRV) for colors at index 0 [S1, unofficial].
6. If `m_coeffSH` is present, bind the SRV for spherical harmonic coefficients at index 1 [S1, unofficial].
7. Bind a `LINEAR_CLAMP` sampler [S1, unofficial].
8. Calculate the dispatch grid size:
   - $x_{dispatch} = \lfloor m\_gridSize.x \gg m\_cubeMapLOD \rfloor / 8$
   - $y_{dispatch} = \lfloor m\_gridSize.y \gg m\_cubeMapLOD \rfloor / 8$
   - $z_{dispatch} = m\_cubeFaceCount$
   *(Note: The source describes shifting `m_gridSize.x` right by `m_cubeMapLOD` and then dividing by 8 for x and y group counts, while z is directly `m_cubeFaceCount`)* [S1, unofficial].
9. Dispatch the compute shader with the calculated group counts $(x_{dispatch}, y_{dispatch}, z_{dispatch})$ [S1, unofficial].

**Pseudocode:**
```python
# Pseudocode for the dispatch setup based on [S1, unofficial]
def setup_cubemap_ray_marching():
    # 1. Set Compute Shader
    set_compute_shader("CS_RAY_MARCH")

    # 2. Bind UAV for cube map
    bind_uav(cube_map_uav, lod=m_cubeMapLOD)

    # 3. Bind CBVs
    bind_cbv(per_object_cbv)
    bind_cbv(per_frame_cbv)
    bind_cbv(cb_sample_res_cbv)

    # 4. Conditionally bind face culling CBV
    if _CPU_CUBE_FACE_CULL_ in [1, 2]:
        bind_cbv(cube_face_culling_cbv)

    # 5. Bind SRV for colors
    bind_srv(color_srv, index=0)

    # 6. Bind SRV for SH coefficients if present
    if m_coeffSH is not None:
        bind_srv(sh_coefficients_srv, index=1)

    # 7. Bind Sampler
    bind_sampler(linear_clamp_sampler)

    # 8. Calculate dispatch dimensions
    # Source: "Calculate grid size for dispatch by shifting m_gridSize.x right by m_cubeMapLOD"
    # and "Dispatch ... with group counts: x and y divided by 8, z is m_cubeFaceCount"
    x_raw = m_gridSize.x >> m_cubeMapLOD
    y_raw = m_gridSize.y >> m_cubeMapLOD
    
    x_groups = x_raw // 8
    y_groups = y_raw // 8
    z_groups = m_cubeFaceCount

    # 9. Dispatch
    dispatch(x_groups, y_groups, z_groups)
```

**Parameters:**
- `m_gridSize.x`, `m_gridSize.y`: Grid dimensions [S1, unofficial].
- `m_cubeMapLOD`: Cube map LOD level [S1, unofficial].
- `m_cubeFaceCount`: Number of cube faces [S1, unofficial].
- `_CPU_CUBE_FACE_CULL_`: Macro controlling face culling behavior (1 or 2) [S1, unofficial].

**Edge Cases:**
- If `m_coeffSH` is not present, the SRV for spherical harmonic coefficients is not bound [S1, unofficial].
- The face culling CBV is only bound if the macro `_CPU_CUBE_FACE_CULL_` is set to 1 or 2 [S1, unofficial].

## Subtopics

### [Cube Camera Volumetric Shadows](17333-cube-camera-volumetric-shadows.md)
A method to cast volumetric shadows in all directions from a single light source by using a CubeCamera to capture depth from six directions, overcoming the limitation of a single directional light camera. Unlike the single-direction light camera approach which requires the light camera to point at the viewer to maximize shadow map coverage, the cube camera captures shadows in all directions but is considered a 'hack' with lower quality than other examples.
