# Ray Sampling and Neural Rendering Pipeline
Also called: Ray Bundle Generation

## Overview
This method generates camera rays from pixel coordinates, passes them through an implicit neural renderer, and extracts rendered features (such as color or geometry) into image tensors [S1, unofficial]. It differs from the parent [Grid Ray Sampler](3930-grid-ray-sampler.md) by handling the complete inference pipeline—transforming pixel grids into ray bundles, executing the neural network forward pass, and reshaping the output—rather than just sampling ray origins and directions [S1, unofficial].

## How it works
**Inputs:**
- Camera parameters (intrinsic/extrinsic matrices, image size) [S1, unofficial].
- Light location (optional, for lighting calculations) [S1, unofficial].
- Neural model instance (implicit renderer) [S1, unofficial].
- Feature key (`feat`): specifies the output channel to render, typically `'color'` or `'geometry'` [S1, unofficial].

**Outputs:**
- Rendered image tensor of shape `[height, width, 3]` containing RGB values or geometry data [S1, unofficial].

**Data Structures:**
- `RayBundle`: Contains `origins` (shape `[num_rays, 3]`) and `directions` (shape `[num_rays, 3]`) [S1, unofficial].
- `out`: Dictionary-like output from the model, where `out['color']` or `out['geometry']` has shape `[batch_size, num_rays, 3]` [S1, unofficial].

**Steps:**
1. **Initialize Model:** Set the neural model to evaluation mode and move to the target device (e.g., GPU) [S1, unofficial].
   $$ \text{model} \leftarrow \text{Model}(\text{cfg}) $$
   $$ \text{model} \leftarrow \text{model.to}(\text{device}) $$
   $$ \text{model}.\text{eval}() $$
2. **Compute Light Direction (Optional):** If lighting is required, compute the direction from the light source to the scene origin. This assumes the object is centered at the origin [S1, unofficial].
   $$ \mathbf{d}_{\text{light}} = \mathbf{l}_{\text{loc}} - \mathbf{o}_{\text{origin}} $$
   $$ \mathbf{d}_{\text{light}} = \frac{\mathbf{d}_{\text{light}}}{\|\mathbf{d}_{\text{light}}\|} $$
   *Note: The source code flags a potential issue if the object is not at the origin [S1, unofficial].*
3. **Generate Pixel Grid:** Create a grid of pixel coordinates corresponding to the target image resolution [S1, unofficial].
   $$ \mathbf{G}_{\text{xy}} = \text{get\_pixels\_from\_image}(\text{image\_size}, \text{camera}) $$
4. **Generate Ray Bundle:** Convert pixel coordinates into 3D ray origins and directions using the camera parameters [S1, unofficial].
   $$ \mathbf{R}_{\text{bundle}} = \text{get\_rays\_from\_pixels}(\mathbf{G}_{\text{xy}}, \text{image\_size}, \text{camera}) $$
5. **Forward Pass:** Execute the neural model with the ray bundle. If light direction is provided, pass it as an argument [S1, unofficial].
   $$ \mathbf{O} = \text{model}(\mathbf{R}_{\text{bundle}}, \mathbf{d}_{\text{light}}) $$
6. **Reshape Output:** Extract the specified feature tensor and reshape it from `[batch_size, num_rays, 3]` to `[height, width, 3]` [S1, unofficial].
   $$ \mathbf{I} = \mathbf{O}[\text{feat}].\text{view}(\text{height}, \text{width}, 3) $$
7. **Save Image (Optional):** Convert the tensor to a NumPy array and save to disk if requested [S1, unofficial].

**Pseudocode:**
```python
import torch
import numpy as np
import matplotlib.pyplot as plt

def render_pipeline(model, cfg, camera, light_location=None, feat='color', save_path=None):
    # 1. Initialize model
    model.eval()
    device = next(model.parameters()).device

    # 2. Compute light direction if provided
    light_dir = None
    if light_location is not None:
        origin = torch.tensor([0.0, 0.0, 0.0], device=device)
        light_dir = light_location - origin
        light_dir = torch.nn.functional.normalize(light_dir, dim=-1).view(-1, 3)

    # 3. Generate pixel grid
    image_size = cfg.data.image_size  # [width, height]
    xy_grid = get_pixels_from_image(image_size, camera)

    # 4. Generate ray bundle
    ray_bundle = get_rays_from_pixels(xy_grid, image_size, camera)

    # 5. Forward pass
    out = model(ray_bundle, light_dir)

    # 6. Reshape output
    output_tensor = out[feat].view(image_size[1], image_size[0], 3)

    # 7. Convert to numpy
    image = output_tensor.detach().cpu().numpy()

    # 8. Save if requested
    if save_path is not None:
        plt.imsave(save_path, image)

    return image
```
