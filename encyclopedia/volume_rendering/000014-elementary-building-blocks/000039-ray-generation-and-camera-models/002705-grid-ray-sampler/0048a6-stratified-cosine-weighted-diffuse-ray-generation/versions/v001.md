# Stratified Cosine-Weighted Diffuse Ray Generation

Also called: Stratified Cosine-Weighted Diffuse Ray Generation for One-Bounce Voxel GI, bounded one-bounce voxel GI ray gen

## Overview
This method generates stratified cosine-weighted diffuse rays for bounded one-bounce voxel global illumination, sampling from primary hit positions [S1, unofficial]. It differs from its siblings by specifically targeting the second bounce (GI) in a voxel-based pipeline, using stratified sampling to reduce variance compared to pure random generation, while restricting rays to a fixed maximum distance for performance [S1, unofficial].

## How it works
**Inputs:**
- `globalIndex`: The unique thread ID in the compute dispatch.
- `primaryHitBuffer`: An array of `TraceRay` structures containing the result of the primary ray trace pass.
- `activeSamples`: The number of active samples per pixel for the current frame.
- `pixelIndex`: Derived from `globalIndex`.
- `sampleIndex`: Derived from `globalIndex`.

**Outputs:**
- `giRayBuffer`: An array of `TraceRay` structures containing the generated GI rays.

**Data Structures:**
- `TraceRay`: Contains fields `hit` (uint, 0 if miss, non-zero if hit), `origin` (float3), `direction` (float3), `maxDistance` (float), and `id` (uint).
- `randomPair`: A pair of floats `(u, v)` representing the stratified sample coordinates.

**Parameters:**
- `kMaximumGiSamples`: Fixed at 16 [S1, unofficial].
- `gGiFrameSeed`: Seed for the PCG random number generator [S1, unofficial].
- `gShadowBiasMeters`: Shadow bias in meters, converted to voxel units for ray origin offset [S1, unofficial].
- `gGlobalIlluminationMaxDistanceMeters`: Maximum distance for GI rays in meters, converted to voxel units [S1, unofficial].
- `gGlobalIlluminationMode`: Controls GI activation. GI is active when equal to `kGlobalIlluminationVoxelOneBounce` [S1, unofficial].

**Steps:**
1. **Map Thread ID:** Calculate `pixelIndex = globalIndex / kMaximumGiSamples` and `sampleIndex = globalIndex % kMaximumGiSamples`. If `globalIndex >= totalCapacity`, return an empty `TraceRay` [S1, unofficial].
2. **Fetch Primary Result:** Retrieve the primary trace result for `pixelIndex` and `sampleIndex`. If `primary.hit == 0u` or `sampleIndex >= activeSamples`, return an empty `TraceRay` [S1, unofficial].
3. **Compute Stratified Sample:** Generate a deterministic random pair using a rotated Hammersley sequence: `randomPair = RotatedHammersley2D(sampleIndex, activeSamples, PcgHash(pixelIndex ^ gGiFrameSeed))` [S1, unofficial].
4. **Sample Direction:** Compute the ray direction using cosine-weighted hemisphere sampling relative to the surface normal at the primary hit point: `ray.direction = CosineWeightedHemisphereSample(normal, randomPair)` [S1, unofficial].
5. **Set Ray Properties:** Set `ray.maxDistance` to `gGlobalIlluminationMaxDistanceMeters` (converted to voxel units) and assign a unique `ray.id`. Write the result to `giRayBuffer` [S1, unofficial].

**Pseudocode:**
```python
def generate_gi_ray(global_index, primary_hit_buffer, active_samples, k_maximum_gi_samples, g_gi_frame_seed, g_shadow_bias_meters, g_global_illumination_max_distance_meters, voxel_scale):
    # Step 1: Map thread ID
    pixel_index = global_index // k_maximum_gi_samples
    sample_index = global_index % k_maximum_gi_samples
    
    # Check capacity
    total_capacity = len(primary_hit_buffer) * k_maximum_gi_samples
    if global_index >= total_capacity:
        return empty_trace_ray()
    
    # Step 2: Fetch primary trace result
    primary_hit = primary_hit_buffer[pixel_index][sample_index]
    
    if primary_hit.hit == 0 or sample_index >= active_samples:
        return empty_trace_ray()
    
    # Step 3: Compute stratified sample
    # PcgHash is a pseudo-random number generator hash function
    hash_value = pcg_hash(pixel_index ^ g_gi_frame_seed)
    random_pair = rotated_hammersley_2d(sample_index, active_samples, hash_value)
    
    # Step 4: Sample direction
    # CosineWeightedHemisphereSample uses the surface normal from primary_hit
    ray_direction = cosine_weighted_hemisphere_sample(primary_hit.normal, random_pair)
    
    # Step 5: Set ray properties
    # Convert max distance to voxel units
    max_distance_voxel = g_global_illumination_max_distance_meters * voxel_scale
    
    # Apply shadow bias to origin
    origin_offset = primary_hit.normal * g_shadow_bias_meters * voxel_scale
    ray_origin = primary_hit.origin + origin_offset
    
    # Create and return the GI ray
    return TraceRay(
        hit=1,
        origin=ray_origin,
        direction=ray_direction,
        maxDistance=max_distance_voxel,
        id=global_index
    )

def empty_trace_ray():
    return TraceRay(hit=0, origin=(0,0,0), direction=(0,0,0), maxDistance=0, id=0)
```

**Edge Cases and Pitfalls:**
- If `activeSamples` is less than `sampleIndex`, the ray is discarded [S1, unofficial].
- Precision issues may arise if `gShadowBiasMeters` is too small relative to voxel scale, causing self-intersection [G].
- The `RotatedHammersley2D` function must be implemented to ensure low discrepancy properties [G].

## Operating characteristics
- **Time Complexity:** O(1) per ray, as it involves constant-time arithmetic and hashing operations [S1, unofficial].
- **Memory Complexity:** O(N) where N is the number of pixels times `kMaximumGiSamples` [S1, unofficial].
- **Performance:** Performance depends on the efficiency of the `RotatedHammersley2D` and `CosineWeightedHemisphereSample` functions [S1, unofficial].
- **Strengths:** Reduces variance through stratification, suitable for one-bounce GI [S1, unofficial].
- **Limitations:** Fixed sample count limits accuracy, and cosine-weighted sampling may not be optimal for all surface types [G].
- **When to Use:** When one-bounce voxel GI is required and variance reduction is needed [S1, unofficial].
- **When Not to Use:** When multi-bounce GI or importance sampling is required [G].
