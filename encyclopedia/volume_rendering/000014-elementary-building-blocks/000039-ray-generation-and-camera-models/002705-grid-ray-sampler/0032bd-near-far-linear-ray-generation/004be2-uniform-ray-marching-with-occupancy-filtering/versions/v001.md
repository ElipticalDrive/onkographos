# Uniform Ray Marching with Occupancy Filtering

Also called: SPC Ray Raymarching

## Overview
Uniform Ray Marching with Occupancy Filtering is a raymarching strategy that samples a fixed number of points along each ray globally, then filters out samples that fall outside of occupied Sparse Point Cloud (SPC) cells [S1, unofficial]. It differs from its sibling [SPC Uniform Raymarching](11412-spc-uniform-raymarching.md), which calculates step sizes based on cell geometry, and [SPC Voxel Raymarching](11413-spc-voxel-raymarching.md), which samples a fixed number of points *within* each intersected cell. This method prioritizes a uniform global sampling density, using the SPC structure solely as a validity mask to discard empty-space samples [S1, unofficial].

## How it works
**Inputs:**
- `origins`: Tensor of ray origins, shape $(N, 3)$.
- `directions`: Tensor of normalized ray directions, shape $(N, 3)$.
- `dist_min`: Scalar or tensor of near-plane distances for each ray.
- `dist_max`: Scalar or tensor of far-plane distances for each ray.
- `num_samples`: Integer, the number of base samples to generate per ray.
- `spc`: The Sparse Point Cloud acceleration structure supporting point index queries.

**Outputs:**
- `samples`: Filtered 3D coordinates, shape $(M, 3)$, where $M \le N \times \text{num\_samples}$.
- `depths`: Filtered depths along rays, shape $(M,)$.
- `deltas`: Filtered step sizes between consecutive samples, shape $(M,)$.
- `ray_indices`: Indices mapping each sample back to its originating ray, shape $(M,)$.
- `pack_boundaries`: Boolean mask or indices marking the start of each ray's sample pack in the flattened output.

**Data Structures:**
- The SPC structure maps 3D coordinates to integer point indices (`pidx`). Invalid locations return $-1$.
- `mask`: Boolean tensor of length $N \times \text{num\_samples}$, true where `pidx > -1`.

**Steps:**
1. **Generate Base Depths:** Create linearly spaced depths in $[0, 1]$ and add jitter.
   $$ d_{base} = \text{linspace}(0, 1.0, \text{num\_samples}) $$
   $$ d_{jitter} = \text{random}(0, 1, \text{num\_samples}) / \text{num\_samples} $$
   $$ d_{norm} = d_{base} + d_{jitter} $$
   [G] The jitter ensures stratification within each uniform interval.

2. **Normalize to Ray Range:** Map normalized depths to the ray's $[dist\_min, dist\_max]$ range.
   $$ d_{final} = d_{norm} \times (dist\_max - dist\_min) + dist\_min $$
   Shape: $(N, \text{num\_samples})$.

3. **Compute Sample Coordinates:** Calculate 3D positions.
   $$ \text{samples} = \text{origins} + d_{final} \times \text{directions} $$
   Using element-wise multiplication (`torch.addcmul` logic):
   $$ \text{samples}_i = \text{origins}_i + d_{final, i} \cdot \text{directions}_i $$
   Shape: $(N, \text{num\_samples}, 3)$.

4. **Query Occupancy:** Query the SPC structure for all sample coordinates to get point indices.
   $$ \text{pidx} = \text{SPC.query}(\text{samples}) $$
   Shape: $(N, \text{num\_samples})$. Values are $-1$ if the point is not in an occupied cell.

5. **Create Occupancy Mask:**
   $$ \text{mask} = (\text{pidx} > -1) $$
   Shape: $(N, \text{num\_samples})$.

6. **Compute Depth Deltas:** Calculate distances between consecutive samples.
   $$ \Delta d = \text{diff}(d_{final}, \text{axis}=1) $$
   Prepend $dist\_min$ to the first position.
   $$ \Delta d_{full} = [dist\_min, \Delta d_{0}, \Delta d_{1}, \dots] $$
   Shape: $(N, \text{num\_samples})$.

7. **Filter Samples:** Flatten tensors and filter using the mask.
   $$ \text{flat\_samples} = \text{flatten}(\text{samples}) $$
   $$ \text{flat\_depths} = \text{flatten}(d_{final}) $$
   $$ \text{flat\_deltas} = \text{flatten}(\Delta d_{full}) $$
   $$ \text{flat\_ray\_idx} = \text{repeat}(0..N-1, \text{num\_samples}) $$
   $$ \text{flat\_mask} = \text{flatten}(\text{mask}) $$
   Apply `fast_filter_method` (e.g., `torch.nonzero` or boolean indexing) to keep only elements where `flat_mask` is true.
   $$ \text{out\_samples} = \text{flat\_samples}[\text{flat\_mask}] $$
   $$ \text{out\_depths} = \text{flat\_depths}[\text{flat\_mask}] $$
   $$ \text{out\_deltas} = \text{flat\_deltas}[\text{flat\_mask}] $$
   $$ \text{out\_ray\_idx} = \text{flat\_ray\_idx}[\text{flat\_mask}] $$

8. **Mark Pack Boundaries:** Identify the start of each ray's samples in the filtered output.
   $$ \text{is\_first} = (\text{out\_ray\_idx} \neq \text{shifted\_out\_ray\_idx}) $$
   [G] The first sample of the first ray is always a boundary.

**Parameters:**
- `num_samples`: Number of base samples generated per ray. Typical values depend on the desired visual fidelity and performance budget, often ranging from 128 to 1024 in neural rendering contexts [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Empty Occupancy:** If `NUM_HIT_SAMPLES` (the count of true values in `mask`) is 0, the output tensors will be empty. The renderer must handle this case to avoid division by zero or invalid memory access [S1, unofficial].
- **Precision:** Jitter addition must be performed carefully to avoid precision loss when `dist_max - dist_min` is very large or very small.
- **Boundary Conditions:** The first delta is explicitly set to `dist_min`. Ensure `dist_min` is correctly passed for rays that may have varying near planes.

```python
import torch

def uniform_ray_marching_with_occupancy_filter(
    origins: torch.Tensor,
    directions: torch.Tensor,
    dist_min: torch.Tensor,
    dist_max: torch.Tensor,
    num_samples: int,
    spc_query_func
) -> dict:
    """
    Performs uniform ray marching with occupancy filtering.
    
    Args:
        origins: (N, 3) Ray origins.
        directions: (N, 3) Normalized ray directions.
        dist_min: (N,) or scalar Near plane distance.
        dist_max: (N,) or scalar Far plane distance.
        num_samples: int Number of samples per ray.
        spc_query_func: Callable that takes (N * num_samples, 3) coordinates and returns (N * num_samples,) pidx.
        
    Returns:
        Dictionary containing filtered samples, depths, deltas, ray_indices, and pack_boundaries.
    """
    N = origins.shape[0]
    
    # 1. Generate base depths with jitter
    # linspace(0, 1.0, num_samples)
    base_depths = torch.linspace(0.0, 1.0, num_samples, device=origins.device)
    # random jitter divided by num_samples
    jitter = torch.rand(num_samples, device=origins.device) / num_samples
    norm_depths = base_depths + jitter  # (num_samples,)
    
    # 2. Normalize to ray range
    # Expand dims for broadcasting: (1, num_samples)
    norm_depths = norm_depths.unsqueeze(0)
    dist_min_exp = dist_min.unsqueeze(1) if dist_min.dim() == 1 else dist_min
    dist_max_exp = dist_max.unsqueeze(1) if dist_max.dim() == 1 else dist_max
    
    depths = norm_depths * (dist_max_exp - dist_min_exp) + dist_min_exp  # (N, num_samples)
    
    # 3. Compute sample coordinates
    # origins: (N, 3), directions: (N, 3), depths: (N, num_samples, 1) for broadcasting
    depths_3d = depths.unsqueeze(2)  # (N, num_samples, 1)
    samples = origins.unsqueeze(1) + depths_3d * directions.unsqueeze(1)  # (N, num_samples, 3)
    
    # 4. Query SPC
    # Flatten samples to query all points at once
    flat_samples = samples.reshape(-1, 3)  # (N * num_samples, 3)
    pidx = spc_query_func(flat_samples)  # (N * num_samples,)
    
    # 5. Create mask
    mask = pidx > -1  # (N * num_samples,)
    
    # 6. Compute deltas
    # Diff along the last dimension (num_samples)
    # diff returns (N, num_samples - 1)
    deltas_diff = torch.diff(depths, dim=1)  # (N, num_samples - 1)
    # Prepend dist_min
    # dist_min_exp shape: (N, 1)
    deltas = torch.cat([dist_min_exp, deltas_diff], dim=1)  # (N, num_samples)
    
    # 7. Filter
    flat_depths = depths.reshape(-1)
    flat_deltas = deltas.reshape(-1)
    flat_ray_indices = torch.arange(N, device=origins.device).repeat_interleave(num_samples)
    
    # Apply mask
    valid_samples = flat_samples[mask]
    valid_depths = flat_depths[mask]
    valid_deltas = flat_deltas[mask]
    valid_ray_indices = flat_ray_indices[mask]
    
    # 8. Mark pack boundaries
    # A boundary is where the ray index changes or it's the first element
    # Shift ray indices by 1
    shifted_ray_indices = torch.roll(valid_ray_indices, 1)
    shifted_ray_indices[0] = -1  # Ensure first is always a boundary
    
    pack_boundaries = valid_ray_indices != shifted_ray_indices
    
    return {
        "samples": valid_samples,
        "depths": valid_depths,
        "deltas": valid_deltas,
        "ray_indices": valid_ray_indices,
        "pack_boundaries": pack_boundaries
    }
```

## Subtopics

### SPC Uniform Raymarching
A variant that intersects rays with SPC cells and samples points at uniform distances determined by the cell geometry [S1, unofficial]. It calculates a `step_size` based on `num_samples` (initially $2\sqrt{3}/\text{num\_samples}$) and scales it to intersect cells. It computes interval counts for each intersection and filters out zero-count intersections. Unlike the parent method, it does not generate a fixed global grid of samples but rather samples proportional to the cell size. Pitfall: `NUM_INTERSECTIONS` can be 0 [S1, unofficial].

### SPC Voxel Raymarching
A variant that intersects rays with SPC cells and samples a fixed number of points *within* each intersected cell [S1, unofficial]. It uses `raytrace` to get depth intervals, then generates `num_samples` points per interval. It computes deltas as the difference between these intra-cell samples. Unlike the parent method, the sampling density is local to the cell intersection, not global. Pitfall: `NUM_INTERSECTIONS` can be 0 [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N \cdot S)$ for generating samples and querying the SPC, where $N$ is the number of rays and $S$ is `num_samples`. Filtering is $O(N \cdot S)$. The SPC query cost depends on the structure (e.g., $O(\log C)$ for tree-based SPC).
- **Memory Complexity:** $O(N \cdot S)$ for storing intermediate tensors before filtering. The output size is variable but bounded by $N \cdot S$.
- **Performance:** Efficient for scenes with high occupancy where most samples are valid. In sparse scenes, the filtering step discards many samples, but the initial generation cost remains. The jitter helps reduce aliasing artifacts compared to pure uniform sampling.
- **Strengths:** Simple to implement; provides uniform sampling density in space; jitter reduces banding.
- **Limitations:** Wastes computation on empty space if the scene is sparse; `num_samples` must be chosen to balance coverage and performance; potential for `NUM_HIT_SAMPLES = 0` in empty scenes.
- **When to use:** When a uniform sampling distribution is desired and the scene has significant occupied volume.
- **When not to use:** In very sparse scenes where most rays hit empty space, as the filtering overhead may not justify the uniform sampling benefit; consider [SPC Voxel Raymarching](11413-spc-voxel-raymarching.md) instead.

## Background
This method is part of the NVIDIA Kaolin-Wisp framework, specifically within the `wisp.tracers` module, designed for efficient neural radiance field rendering [S1, unofficial]. It builds on the concept of uniform ray sampling but integrates occupancy filtering via Sparse Point Cloud (SPC) structures to optimize computation in sparse environments. The approach aligns with strategies used in modern neural rendering pipelines that leverage acceleration structures to skip empty space.
