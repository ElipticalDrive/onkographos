# Ray Casting
## Overview
Ray casting is a method for displaying a 3D scene by determining the color of each pixel on a screen (viewport) by sending rays from a camera through the screen surface into the scene [S1, unofficial]. The algorithm calculates intersection points of all rays with all objects, picks the closest intersection point, and calculates the distance to the camera to determine pixel color [S1, unofficial]. It is distinguished from its siblings by its reliance on analytical intersection formulas for primitive surfaces rather than iterative marching or hierarchical acceleration structures [S1, unofficial].
## Shared principles
The core mechanism involves defining a ray and an object surface, then solving for the intersection parameter $t$.

**Ray Equation:**
A ray is defined by a starting point $A$ and a direction vector defined by a second point $B$. Any point $P$ on the ray is given by:
$$P = A + t * (B - A)$$
where $t$ is a scalar [S1, unofficial].

**Intersection Logic:**
To find the intersection of a ray with an object, the ray formula is inserted into the object's surface formula, and the equation is solved for $t$ [S1, unofficial]. The closest intersection point (smallest positive $t$) is selected for shading [S1, unofficial].

**Sphere Intersection Example:**
For a sphere with center $C$ and radius $r$, the surface is defined by $|P - C| = r$. Substituting the ray equation:
$$|A + t * (B - A) - C| = r$$
Squaring both sides yields a quadratic equation in $t$:
$$(A - C)^2 + 2 * t * (A - C) * (B - A) + t^2 * (B - A)^2 = r^2$$
This is solved using the standard quadratic formula [S1, unofficial].

## Background
Ray casting was introduced as a fundamental technique in computer graphics for rendering 3D scenes. It is described in early coding tutorials and scene.org Hugi magazines, which detail the basic implementation of sending rays from a viewport to intersect with primitive objects like spheres [S1, unofficial]. The method is often contrasted with ray marching, which avoids analytical intersection calculations by stepping along the ray [S1, unofficial].
