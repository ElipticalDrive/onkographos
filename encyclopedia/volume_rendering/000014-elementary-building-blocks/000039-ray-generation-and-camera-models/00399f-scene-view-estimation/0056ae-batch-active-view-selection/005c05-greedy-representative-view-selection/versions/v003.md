# Greedy Representative View Selection


## Overview
Greedy Representative View Selection is a greedy scheme to select a set of views that show information not captured in the best view, avoiding similar information under different directions [S1]. It differs from global maximization approaches by yielding similar results with linear cost instead of quadratic cost in the number of views [S1].

## How it works
**Inputs and Outputs:**
- **Input:** A set of candidate views, a distance metric $d(X, Y)$ between two views, and the desired number of representative views $M$ [S1].
- **Output:** A subset of $M$ representative views [S1].

**Data Structures:**
Not given in the sources.

**Similarity Metric:**
The distance $d(X, Y)$ between two views is computed using the Normalized Compression Distance (NCD) [S1]. NCD is chosen because simple image metrics like Mean Squared Error are sensitive to transformations such as rotation or translation [S1].

**Algorithm Steps:**
1. Select the best view $B_0$ with an adaptive algorithm [S1].
2. Measure the distances from $B_0$ to the remaining views [S1].
3. Select the next representer view $B_1$ as the one at the highest distance from $B_0$ [S1].
4. For subsequent views, compute distances from remaining views against all previously selected views and choose the view $X$ that maximizes the geometric average of the distances to the selected views [S1].

**Parameters:**
- $M$: Number of representative views. Usually three or four are enough for most models [S1].

**Pseudocode:**
```python
def greedy_representative_views(candidates, dist_func, m):
    """
    Select m representative views from candidates using greedy geometric average distance.
    
    Args:
        candidates: List of view identifiers.
        dist_func: Function d(X, Y) returning distance between two views.
        m: Number of representative views to select.
        
    Returns:
        List of selected view identifiers.
    """
    if not candidates:
        return []
    
    # Step 1: Select B0 using an adaptive algorithm [S1].
    # Source does not specify the adaptive algorithm for B0 selection [G].
    b0 = candidates[0]
    selected = [b0]
    remaining = [v for v in candidates if v != b0]
    
    if m == 1:
        return selected
        
    # Step 2: Measure distances from B0 to remaining views [S1].
    # Step 3: Select B1 as the view furthest from B0 [S1].
    max_dist = -1.0
    b1 = None
    for v in remaining:
        d = dist_func(b0, v)
        if d > max_dist:
            max_dist = d
            b1 = v
            
    selected.append(b1)
    remaining = [v for v in remaining if v != b1]
    
    if m == 2:
        return selected
        
    # Step 4: Iteratively select remaining views by maximizing geometric average distance to selected views [S1].
    for k in range(2, m):
        best_view = None
        max_geo_avg = -1.0
        
        for v in remaining:
            product = 1.0
            for b in selected:
                product *= dist_func(v, b)
            
            geo_avg = product ** (1.0 / len(selected))
            
            if geo_avg > max_geo_avg:
                max_geo_avg = geo_avg
                best_view = v
                
        selected.append(best_view)
        remaining = [v for v in remaining if v != best_view]
        
    return selected
```

## Subtopics

### Random large-angle view supervision
A supervision strategy for 3D Gaussian Splatting that favors target cameras with optical axes significantly different from input cameras to constrain Gaussian scales and orientations [S2, unofficial]. It prunes Gaussians with opacity below $\tau_\alpha$ from the voxel-based scene $G_{vox}$ to yield $G^0 = \{(\mu^0_m, \xi^0_m)\}_{m=1}^M$ [S2, unofficial]. Candidate target views $v$ are scored by their angular separation from the nearest input direction $i \in C$: $a(v, C) = \min_{i \in C} \arccos(f_v^\top f_i)$, where $f_v = R_v^\star (0, 0, 1)^\top$ is the unit optical axis in the common reference frame [S2, unofficial]. The target set $T$ is sampled with a bias toward larger scores $a(v, C)$ [S2, unofficial]. Supervision is applied to renderings of $G^0$ from both input views and $T$, using GT-depth warp masks to restrict loss to valid regions with depth-consistent support [S2, unofficial]. Opacity pruning threshold $\tau_\alpha$ values tested include 0.01, 0.02, and 0.05 [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of views, as the comparison process is the most costly part, but each step only compares remaining views against the fixed set of selected views [S1]. Global maximization has a quadratic cost in the number of views [S1].
- **Memory Complexity:** Not given in the sources [S1].
- **Strengths:** Avoids redundant information capture; computationally efficient compared to global optimization; robust to image transformations via NCD [S1].
- **Limitations:** Greedy approach may not find the globally optimal set of views; relies on the quality of the similarity metric [S1].
- **When to use:** When a small, diverse set of views is needed for volume model representation or initialization, and computational resources are limited [S1].
- **When not to use:** When the globally optimal view set is required and computational cost is not a constraint [S1].

## Background
The method was proposed in the context of generating representative views and paths for volume models, aiming to avoid preprocessing steps like segmentation [S1]. It was developed to address the limitations of simple image metrics (like MSE) which are sensitive to rotations and translations, and to improve upon methods like those by Bordoloi and Shen which use Jensen-Shannon divergence but do not exploit dataset symmetry [S1].
