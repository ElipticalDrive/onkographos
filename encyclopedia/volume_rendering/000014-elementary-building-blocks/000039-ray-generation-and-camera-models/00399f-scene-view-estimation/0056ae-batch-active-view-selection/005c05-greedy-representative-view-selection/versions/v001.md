# Greedy Representative View Selection

Also called: Greedy view selection, Representative view selection

## Overview
Greedy Representative View Selection is a method for selecting a small, diverse subset of camera views to represent a 3D scene, ensuring that selected views capture information not present in previously chosen ones. It solves the problem of redundant view selection by maximizing geometric diversity among a candidate set. It differs from global maximization approaches by offering a linear-time approximation that yields similar results with significantly lower computational cost [S1].

## How it works
The method selects a set of $M$ representative views from a candidate pool using a greedy strategy based on view similarity distances.

**Inputs and Outputs:**
- **Input:** A set of candidate views $V_{cand}$, a similarity metric $d(X, Y)$ between two views, and the desired number of representative views $M$.
- **Output:** A subset $R = \{B_0, B_1, \dots, B_{M-1}\} \subset V_{cand}$.

**Data Structures:**
- $V_{cand}$: List of candidate view indices or identifiers.
- $R$: List of selected view indices.
- $D_{rem}$: List of remaining candidate views not yet selected.

**Similarity Metric:**
The distance $d(X, Y)$ between two views $X$ and $Y$ is typically computed using the Normalized Compression Distance (NCD) [S1]. NCD is chosen because it is robust to image transformations such as rotation and translation, which simple metrics like Mean Squared Error (MSE) are sensitive to [S1].

**Algorithm Steps:**
1. **Initialization:** Select the first representative view $B_0$ using an adaptive algorithm or by choosing the view with the highest information content from $V_{cand}$ [S1].
2. **First Selection:** Compute the distance $d(B_0, v)$ for all $v \in V_{cand} \setminus \{B_0\}$. Select $B_1$ as the view with the maximum distance from $B_0$ [S1].
3. **Iterative Selection:** For $k = 2$ to $M-1$:
   a. For each remaining candidate view $v \in V_{cand} \setminus R$, compute the geometric average of its distances to all currently selected views $B_0, \dots, B_{k-1}$:
      $$ G(v) = \left( \prod_{j=0}^{k-1} d(v, B_j) \right)^{\frac{1}{k}} $$
   b. Select $B_k$ as the view $v$ that maximizes $G(v)$ [S1].
   c. Add $B_k$ to $R$.

**Parameters:**
- $M$: Number of representative views. Typically, 3 or 4 views are sufficient for most models [S1].

**Pseudocode:**
```python
def greedy_representative_views(candidates, similarity_func, m):
    """
    Select m representative views from candidates using greedy geometric average distance.
    
    Args:
        candidates: List of view identifiers.
        similarity_func: Function d(X, Y) returning distance between two views.
        m: Number of representative views to select.
        
    Returns:
        List of selected view identifiers.
    """
    if not candidates:
        return []
    
    # Step 1: Select B0 using an adaptive algorithm or heuristic.
    # Note: The specific adaptive algorithm for B0 is not detailed in the source.
    # [G] Assuming B0 is selected as the first candidate or via a separate metric.
    # Here we assume a placeholder selection for B0. In practice, this might be
    # the view with highest entropy or a predefined "best" view.
    b0 = candidates[0] # Placeholder for adaptive selection logic
    selected = [b0]
    remaining = [v for v in candidates if v != b0]
    
    if m == 1:
        return selected
        
    # Step 2: Select B1 as the view furthest from B0
    max_dist = -1
    b1 = None
    for v in remaining:
        dist = similarity_func(b0, v)
        if dist > max_dist:
            max_dist = dist
            b1 = v
            
    selected.append(b1)
    remaining = [v for v in remaining if v != b1]
    
    if m == 2:
        return selected
        
    # Step 3: Iteratively select remaining views
    for k in range(2, m):
        best_view = None
        max_geo_avg = -1
        
        for v in remaining:
            # Compute geometric average of distances to all selected views
            product = 1.0
            for b in selected:
                product *= similarity_func(v, b)
            
            # Geometric average
            geo_avg = product ** (1.0 / len(selected))
            
            if geo_avg > max_geo_avg:
                max_geo_avg = geo_avg
                best_view = v
                
        selected.append(best_view)
        remaining = [v for v in remaining if v != best_view]
        
    return selected
```

**Edge Cases and Pitfalls:**
- **Precision:** The geometric average can suffer from underflow if distances are small. Log-space computation ($\frac{1}{k} \sum \log d(v, B_j)$) is recommended for numerical stability [G].
- **Boundary:** If $M > |V_{cand}|$, the algorithm cannot proceed. The sources do not specify handling for this case [S1].
- **Degenerate Input:** If multiple views have identical distances to selected views, the selection is arbitrary. The sources do not specify a tie-breaking rule [S1].

## Subtopics

### Random large-angle view supervision
A supervision strategy for 3D Gaussian Splatting that favors target cameras with optical axes significantly different from input cameras to constrain Gaussian scales and orientations [S2, unofficial]. It prunes Gaussians with opacity below $\tau_\alpha$ from the voxel-based scene $G_{vox}$ to yield $G^0$. Candidate target views $v$ are scored by their angular separation from the nearest input direction $i \in C$: $a(v, C) = \min_{i \in C} \arccos(f_v^\top f_i)$, where $f_v = R_v^\star (0, 0, 1)^\top$ is the unit optical axis in the common reference frame [S2, unofficial]. The target set $T$ is sampled with a bias toward larger scores $a(v, C)$. Supervision is applied to renderings from input views and $T$, using GT-depth warp masks to restrict loss to valid regions [S2, unofficial]. Opacity pruning threshold $\tau_\alpha$ values tested include 0.01, 0.02, and 0.05 [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of views, as the comparison process is the most costly part, but each step only compares remaining views against the fixed set of selected views [S1]. Global maximization has a quadratic cost in the number of views [S1].
- **Memory Complexity:** Not given in the sources.
- **Strengths:** Avoids redundant information capture; computationally efficient compared to global optimization; robust to image transformations via NCD [S1].
- **Limitations:** Greedy approach may not find the globally optimal set of views; relies on the quality of the similarity metric [S1].
- **When to use:** When a small, diverse set of views is needed for volume model representation or initialization, and computational resources are limited [S1].
- **When not to use:** When the globally optimal view set is required and computational cost is not a constraint [S1].

## Background
The method was proposed in the context of generating representative views and paths for volume models, aiming to avoid preprocessing steps like segmentation [S1]. It was developed to address the limitations of simple image metrics (like MSE) which are sensitive to rotations and translations, and to improve upon methods like those by Bordoloi and Shen which use Jensen-Shannon divergence but do not exploit dataset symmetry [S1].
