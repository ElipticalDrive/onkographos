# Rejection Sampling for Uniform Sphere Sampling

Also called: Cube Rejection Sampling, Random Sampling Utilities, Random Unit Vector Generation, Rejection Sampling for Ball, Rejection Sampling for Uniform Sphere/Disk Sampling, Uniform Ball Sampling, Unit Disk Sampling, Unit Sphere Sampling

## Overview
Rejection sampling generates uniformly distributed points within a unit ball or on its surface by sampling from a bounding cube and discarding outliers [S3, S2, unofficial]. It differs from spherical coordinate conversion [Uniform Sphere Sampling](1669-uniform-sphere-sampling.md) by avoiding trigonometric functions, relying instead on simple arithmetic and normalization [G].

## How it works
**Inputs:** A source of independent uniform random numbers $u \in [0, 1)$ [G].
**Outputs:** A vector $\mathbf{p}$ uniformly distributed in the unit ball ($|\mathbf{p}| \le 1$) or on the unit sphere surface ($|\mathbf{p}| = 1$) [S3, S2, unofficial].

**Data Structures:**
*   `vec3`: A 3D vector with components $(x, y, z)$.
*   `float`: 32-bit or 64-bit floating point number.

**Algorithm:**
1. Generate three independent random values $x, y, z$ uniformly in $[-1, 1]$ [S3, unofficial].
2. Compute squared length $L = x^2 + y^2 + z^2$ [S1, S3, unofficial].
3. For the unit ball: if $L \le 1.0$, return $\mathbf{p} = (x, y, z)$ [S3, unofficial].
4. For the unit sphere: if $10^{-160} \le L < 1.0$, normalize $\mathbf{p} = \frac{1}{\sqrt{L}}(x, y, z)$ and return [S1, S2, unofficial]. Otherwise, repeat from step 1 [S1, S2, unofficial].

**Parameters:**
*   $\epsilon = 10^{-160}$: Lower bound for squared length to prevent division by zero or near-zero normalization errors [S1, unofficial].

**Pseudocode:**
```python
import random
import math

def sample_unit_ball():
    """Generate a point uniformly distributed inside the unit ball."""
    while True:
        x = random.uniform(-1.0, 1.0)
        y = random.uniform(-1.0, 1.0)
        z = random.uniform(-1.0, 1.0)
        lensq = x * x + y * y + z * z
        if lensq <= 1.0:
            return (x, y, z)

def sample_unit_sphere():
    """Generate a point uniformly distributed on the unit sphere surface."""
    while True:
        x = random.uniform(-1.0, 1.0)
        y = random.uniform(-1.0, 1.0)
        z = random.uniform(-1.0, 1.0)
        lensq = x * x + y * y + z * z
        if 1e-160 <= lensq < 1.0:
            inv_sqrt = 1.0 / math.sqrt(lensq)
            return (x * inv_sqrt, y * inv_sqrt, z * inv_sqrt)
```

## Operating characteristics
*   **Time Complexity:** Expected $O(1)$ iterations [G].
*   **Memory Complexity:** $O(1)$ [G].
*   **Acceptance Rate:** Not given in the sources.
*   **Strengths:** Avoids trigonometric functions; relies on simple arithmetic and normalization [G].
*   **Limitations:** Rejection loop introduces variable iteration counts; normalization adds computational cost [G].
*   **When to use:** When implementation simplicity is prioritized or when generating points for volumetric density sampling where a ball distribution is acceptable [G].
