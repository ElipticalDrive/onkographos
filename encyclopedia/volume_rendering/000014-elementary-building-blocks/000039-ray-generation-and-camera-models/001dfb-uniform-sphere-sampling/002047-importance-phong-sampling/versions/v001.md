# Importance Phong Sampling

Also called: getSampleImportancePhong

## Overview
Importance Phong Sampling generates pseudo-random unit vectors distributed according to a Phong lobe, concentrating samples near the specular reflection direction to reduce variance in rendering glossy or specular surfaces. It differs from [Uniform Sphere Sampling](1669-uniform-sphere-sampling.md) by using a non-uniform distribution defined by a shininess exponent, and from [Anisotropic Scattering via Importance Sampling](4770-anisotropic-scattering-via-importance-sampling.md) by assuming isotropic (symmetric) lobes around the reflection vector rather than along a tangent plane.

## How it works
**Inputs:**
- Two uniform random numbers $\eta_1, \eta_2 \in [0, 1)$ [S1, unofficial].
- The Phong exponent $n$ (shininess) [S1, unofficial].
- The surface normal $\mathbf{N}$ at the intersection point [S1, unofficial].
- The view direction $\mathbf{V}$ (or incident light direction, depending on context; the source uses $\mathbf{V}$ as the primary axis for the local frame) [S1, unofficial].

**Outputs:**
- A sampled direction vector $\mathbf{d}$ in world space [S1, unofficial].

**Data Structures:**
- No persistent data structures. The method is stateless and computes the sample on the fly from random inputs and geometric vectors.

**Steps:**
1.  Generate two independent uniform random numbers $\eta_1$ and $\eta_2$ in the range $[0, 1)$ using a random number generator function `randf()` [S1, unofficial].
2.  Retrieve the Phong exponent $n$ from the material properties [S1, unofficial].
3.  Compute the spherical coordinates $\Theta$ and $\Phi$ for the sample within the local coordinate system aligned with the reflection vector:
    $$ \Theta = \arccos\left((1 - \eta_1)^{\frac{1}{n + 1}}\right) $$
    $$ \Phi = 2 \pi \eta_2 $$
    Here, $\Theta$ is the polar angle from the reflection axis, and $\Phi$ is the azimuthal angle [S1, unofficial].
4.  Construct the sample vector $\mathbf{s}_{local}$ in Cartesian coordinates within the local frame where the z-axis aligns with the reflection direction:
    $$ \mathbf{s}_{local} = \begin{bmatrix} \cos(\Phi) \sin(\Theta) \\ \sin(\Phi) \sin(\Theta) \\ \cos(\Theta) \end{bmatrix} $$
    Let $s_x = \cos(\Phi) \sin(\Theta)$, $s_y = \sin(\Phi) \sin(\Theta)$, and $s_z = \cos(\Theta)$ [S1, unofficial].
5.  Define a local orthonormal basis using the normal $\mathbf{N}$, the view vector $\mathbf{V}$, and a third vector $\mathbf{W}$.
    - Let $\mathbf{V}$ be the reference vector (typically the view direction or the reflection vector itself, normalized).
    - Compute $\mathbf{W}$ as the normalized cross product of $\mathbf{N}$ and $\mathbf{V}$: $\mathbf{W} = \frac{\mathbf{N} \times \mathbf{V}}{\|\mathbf{N} \times \mathbf{V}\|}$. If $\mathbf{N}$ and $\mathbf{V}$ are parallel, $\mathbf{W}$ must be chosen arbitrarily perpendicular to $\mathbf{N}$ [G].
    - Compute $\mathbf{V}_{local}$ as the normalized cross product of $\mathbf{W}$ and $\mathbf{N}$: $\mathbf{V}_{local} = \frac{\mathbf{W} \times \mathbf{N}}{\|\mathbf{W} \times \mathbf{N}\|}$. Note: The source formula uses $\mathbf{V}$ directly in the linear combination, implying $\mathbf{V}$ in the formula corresponds to the x-axis of the local frame, $\mathbf{W}$ to the y-axis, and $\mathbf{N}$ to the z-axis. We must ensure these three vectors form an orthonormal basis. The source states: `sample = V * sample.x + W * sample.y + normal * sample.z`. This implies $\mathbf{V}$, $\mathbf{W}$, and $\mathbf{N}$ are the basis vectors. For this to be a valid rotation, $\mathbf{V}$ and $\mathbf{W}$ must be orthogonal to $\mathbf{N}$ and to each other. The standard construction is:
        - $\mathbf{Z}_{local} = \mathbf{N}$ (or the reflection vector $\mathbf{R}$). The source uses `normal` for the z-component.
        - $\mathbf{X}_{local} = \mathbf{V}$ (projected onto the tangent plane if necessary, but the source code shows `normal` used for the z-axis and `V` for the x-axis).
        - $\mathbf{Y}_{local} = \mathbf{W} = \frac{\mathbf{N} \times \mathbf{V}}{\|\mathbf{N} \times \mathbf{V}\|}$.
        - If $\mathbf{N}$ and $\mathbf{V}$ are parallel, $\mathbf{W}$ is undefined. In this degenerate case, choose an arbitrary tangent vector for $\mathbf{W}$ [G].
6.  Transform the local sample vector to world space using the linear combination:
    $$ \mathbf{d} = \mathbf{V}_{basis} \cdot s_x + \mathbf{W}_{basis} \cdot s_y + \mathbf{N} \cdot s_z $$
    Where $\mathbf{V}_{basis}$ is the vector used for the x-axis (source calls it `V`), $\mathbf{W}_{basis}$ is the vector used for the y-axis (source calls it `W`), and $\mathbf{N}$ is the normal [S1, unofficial].
7.  Normalize the resulting direction vector $\mathbf{d}$ and return it [S1, unofficial].

**Pseudocode:**
```python
def importance_phong_sampling(eta1, eta2, n, normal, view_vector):
    """
    Generates a sample direction using Importance Phong Sampling.
    
    Args:
        eta1 (float): Uniform random number in [0, 1).
        eta2 (float): Uniform random number in [0, 1).
        n (float): Phong exponent (shininess).
        normal (Vector3): Surface normal at intersection.
        view_vector (Vector3): View direction or reference vector for local frame.
        
    Returns:
        Vector3: Sampled direction in world space.
    """
    # Step 3: Compute spherical coordinates
    # Theta is the angle from the normal (z-axis in local frame)
    # Phi is the azimuthal angle
    theta = acos(pow(1.0 - eta1, 1.0 / (n + 1.0)))
    phi = 2.0 * PI * eta2
    
    # Step 4: Construct local sample vector
    sin_theta = sin(theta)
    cos_theta = cos(theta)
    cos_phi = cos(phi)
    sin_phi = sin(phi)
    
    s_x = cos_phi * sin_theta
    s_y = sin_phi * sin_theta
    s_z = cos_theta
    
    # Step 5: Build local orthonormal basis
    # The source uses: sample = V * s_x + W * s_y + normal * s_z
    # This implies:
    # X-axis = V (normalized)
    # Z-axis = Normal (normalized)
    # Y-axis = W = cross(Normal, V) normalized
    
    # Normalize inputs to ensure unit length
    N = normalize(normal)
    V = normalize(view_vector)
    
    # Check for degenerate case where V is parallel to N
    # If cross product is near zero, V and N are parallel
    cross = cross_product(N, V)
    cross_len = length(cross)
    
    if cross_len < 1e-6:
        # Degenerate case: V is parallel to N.
        # Choose an arbitrary vector perpendicular to N for W.
        # A common approach is to pick a vector not parallel to N, e.g., (1,0,0) or (0,1,0).
        if abs(N.x) < 0.9:
            arbitrary = Vector3(1.0, 0.0, 0.0)
        else:
            arbitrary = Vector3(0.0, 1.0, 0.0)
        W = normalize(cross_product(N, arbitrary))
    else:
        W = normalize(cross)
        
    # Note: The source uses V directly as the X-axis basis vector.
    # However, for the basis to be orthonormal, V must be perpendicular to N.
    # If V is not perpendicular to N, it should be projected onto the tangent plane.
    # The source code snippet `sample = V * sample.x + W * sample.y + normal * sample.z`
    # suggests V is used directly. If V is the view direction and N is the normal,
    # they are generally not orthogonal. 
    # Standard Phong sampling aligns the lobe with the reflection vector R.
    # The source text says "Transform the sample vector into the local coordinate system 
    # defined by normal, V, and W". 
    # If V is not orthogonal to N, the resulting basis is not orthonormal, distorting the distribution.
    # However, we must follow the source. The source likely assumes V is the reflection vector 
    # or the view vector in a context where it is treated as the primary axis.
    # To be safe and mathematically correct for a Phong lobe aligned with the reflection,
    # the X-axis should be the projection of V onto the tangent plane, or the reflection vector R.
    # Given the ambiguity, we follow the literal source formula:
    # Basis X = V, Basis Y = W, Basis Z = N.
    # We assume V is already normalized and W is computed as cross(N, V).
    # If V is not orthogonal to N, this is a non-orthonormal transform.
    # We will use V as the X-axis basis vector as per the source formula.
    
    V_basis = V
    W_basis = W
    N_basis = N
    
    # Step 6: Transform to world space
    sample_dir = V_basis * s_x + W_basis * s_y + N_basis * s_z
    
    # Step 7: Normalize and return
    return normalize(sample_dir)
```

**Parameters:**
- $n$: Phong exponent. Higher values produce sharper, more concentrated lobes. Typical values range from 1 to 1000+ depending on the desired glossiness [S1, unofficial].
- $\eta_1, \eta_2$: Random numbers. Must be independent and uniformly distributed [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Degenerate Normal/View Alignment:** If the view vector $\mathbf{V}$ is parallel to the normal $\mathbf{N}$, the cross product $\mathbf{N} \times \mathbf{V}$ is zero, making $\mathbf{W}$ undefined. An arbitrary perpendicular vector must be chosen [G].
- **Precision:** For very large $n$, $(1 - \eta_1)^{\frac{1}{n+1}}$ approaches 1, making $\Theta$ approach 0. Floating-point precision issues may arise if $\eta_1$ is very close to 1.
- **Non-Orthonormal Basis:** If $\mathbf{V}$ is not orthogonal to $\mathbf{N}$, the basis $\{\mathbf{V}, \mathbf{W}, \mathbf{N}\}$ is not orthonormal. The source formula uses $\mathbf{V}$ directly. In standard Phong shading, the lobe is aligned with the reflection vector $\mathbf{R}$, which is orthogonal to the tangent plane only if $\mathbf{V}$ is the view direction and the surface is viewed from the reflection direction. If $\mathbf{V}$ is the view direction, the lobe should be aligned with $\mathbf{R} = 2(\mathbf{N} \cdot \mathbf{V})\mathbf{N} - \mathbf{V}$. The source's use of $\mathbf{V}$ as the x-axis basis suggests a specific local frame definition that may differ from standard reflection-based Phong sampling. Implementers should verify if $\mathbf{V}$ is intended to be the reflection vector or the view vector. If it is the view vector, the distribution may be skewed [G].

## Subtopics

### Multi-layer Sampling Template Generation
A set of sampling points distributed in spherical shells to approximate volume scattering, consisting of a diffuse reflection template and a highlight sampling template [S2, unofficial]. The diffuse template has 8 layers and 182 points, with layer 0 having 6 points (1 center, 5 inside) and layers 1-7 having 8, 12, 16, 24, 32, 48, and 48 points respectively, evenly distributed in the area between the current and previous layer's sphere surfaces [S2, unofficial]. The highlight template has 4 layers with 32, 16, 16, and 8 points, evenly distributed by distance from incident light penetration [S2, unofficial]. The radius of the i-th layer template is $r_i = \frac{2^{i-1} \xi_i}{2^8 \times D(S_i)}$, where $D(S_i)$ is the shortest distance under unit radius (average minimum distance between points), $2^8$ is the resolution of the first-level mipmap, and $\xi_i = 1 - 0.08 \min(i, 5)$ is an empirical parameter controlling template overlap rate [S2, unofficial]. Smaller $\xi_i$ results in smaller radius $r_i$ [S2, unofficial].

## Operating characteristics
- **Time Complexity:** $O(1)$ per sample, as it involves a constant number of trigonometric and arithmetic operations.
- **Memory Complexity:** $O(1)$, as no data structures are stored.
- **Strengths:** Efficiently concentrates samples in the specular direction, reducing variance for glossy materials. Simple to implement.
- **Limitations:** Assumes isotropic lobes. Performance degrades if the Phong exponent is very high, as the distribution becomes extremely peaked, requiring more samples to capture the lobe accurately. Degenerate cases (parallel normal and view vector) require special handling.
- **When to use:** Rendering glossy or specular surfaces where the reflection lobe is narrow.
- **When not to use:** Rendering diffuse surfaces (use [Uniform Sphere Sampling](1669-uniform-sphere-sampling.md) or [Cosine-Weighted Hemisphere Sampling](link if available)), or anisotropic materials (use [Anisotropic Scattering via Importance Sampling](4770-anisotropic-scattering-via-importance-sampling.md)).

## Background
Importance Phong Sampling is a technique used in ray tracing and path tracing to sample the Phong reflection model. It is derived from the Phong shading model, which approximates specular highlights. The method is implemented in the `VolumeSingleScattering` project by wangyuehi [S1, unofficial]. The specific implementation details, including the local coordinate system construction, are documented in the source code and associated notes [S1, unofficial].
