# Importance Phong Sampling

Also called: getSampleImportonePhong

## Overview
Importance Phong Sampling generates pseudo-random unit vectors distributed according to a Phong lobe, concentrating samples near a reference direction to reduce variance in rendering glossy or specular surfaces [S1, unofficial]. It differs from [Uniform Sphere Sampling](1669-uniform-sphere-sampling.md) by using a non-uniform distribution defined by a shininess exponent, and from [Anisotropic Scattering via Importance Sampling](4770-anisotropic-scattering-via-importance-sampling.md) by assuming isotropic (symmetric) lobes around the reference vector rather than along a tangent plane [G].

## How it works
**Inputs:**
- Two uniform random numbers $\eta_1, \eta_2 \in [0, 1)$ [S1, unofficial].
- The Phong exponent $n$ [S1, unofficial].
- The surface normal $\mathbf{N}$ at the intersection point [S1, unofficial].
- The reference vector $\mathbf{V}$ (typically the view or reflection direction) [S1, unofficial].

**Outputs:**
- A sampled direction vector $\mathbf{d}$ in world space [S1, unofficial].

**Data Structures:**
- None; the method is stateless and computes the sample on the fly from random inputs and geometric vectors [G].

**Steps:**
1. Generate two independent uniform random numbers $\eta_1$ and $\eta_2$ in the range $[0, 1)$ using a random number generator function `randf()` [S1, unofficial].
2. Retrieve the Phong exponent $n$ from the material properties [S1, unofficial].
3. Compute the spherical angles $\Theta$ and $\Phi$ for the sample within the local coordinate system aligned with the reference direction:
   $$ \Theta = \arccos\left((1 - \eta_1)^{\frac{1}{n + 1}}\right) $$
   $$ \Phi = 2 \pi \eta_2 $$ [S1, unofficial].
4. Construct the sample vector $\mathbf{s}_{local}$ in Cartesian coordinates within the local frame where the z-axis aligns with the reference direction:
   $$ s_x = \cos(\Phi) \sin(\Theta) $$
   $$ s_y = \sin(\Phi) \sin(\Theta) $$
   $$ s_z = \cos(\Theta) $$ [S1, unofficial].
5. Define a local coordinate system using the normal $\mathbf{N}$, the reference vector $\mathbf{V}$, and a third vector $\mathbf{W}$ [S1, unofficial]. Let $\mathbf{V}$ be the reference vector (normalized) [S1, unofficial]. Compute $\mathbf{W}$ as the normalized cross product of $\mathbf{N}$ and $\mathbf{V}$: $\mathbf{W} = \frac{\mathbf{N} \times \mathbf{V}}{\|\mathbf{N} \times \mathbf{V}\|}$ [G]. If $\mathbf{N}$ and $\mathbf{V}$ are parallel, $\mathbf{W}$ is undefined; choose an arbitrary vector perpendicular to $\mathbf{N}$ for $\mathbf{W}$ [G]. The source formula uses $\mathbf{V}$ directly for the x-axis, $\mathbf{W}$ for the y-axis, and $\mathbf{N}$ for the z-axis [S1, unofficial].
6. Transform the local sample vector to world space using the linear combination: $\mathbf{d} = \mathbf{V} \cdot s_x + \mathbf{W} \cdot s_y + \mathbf{N} \cdot s_z$ [S1, unofficial].
7. Normalize the resulting direction vector $\mathbf{d}$ and return it [S1, unofficial].

**Pseudocode:**
```python
import math

def cross(a, b):
    return (a[1]*b[2] - a[2]*b[1], a[2]*b[0] - a[0]*b[2], a[0]*b[1] - a[1]*b[0])

def length(v):
    return math.sqrt(v[0]**2 + v[1]**2 + v[2]**2)

def normalize(v):
    l = length(v)
    if l < 1e-8:
        return (0.0, 0.0, 1.0)
    return (v[0]/l, v[1]/l, v[2]/l)

def importance_phong_sampling(eta1, eta2, n, normal, view_vector):
    # Step 3: Compute spherical coordinates
    theta = math.acos((1.0 - eta1) ** (1.0 / (n + 1.0)))
    phi = 2.0 * math.pi * eta2

    # Step 4: Construct local sample vector
    sin_theta = math.sin(theta)
    cos_theta = math.cos(theta)
    cos_phi = math.cos(phi)
    sin_phi = math.sin(phi)

    s_x = cos_phi * sin_theta
    s_y = sin_phi * sin_theta
    s_z = cos_theta

    # Step 5: Build local coordinate system
    N = normalize(normal)
    V = normalize(view_vector)

    # Compute W = cross(N, V)
    cross_vec = cross(N, V)
    cross_len = length(cross_vec)

    if cross_len < 1e-6:
        # Degenerate case: V is parallel to N.
        # Choose an arbitrary vector perpendicular to N for W [G].
        arbitrary = (1.0, 0.0, 0.0) if abs(N[0]) < 0.9 else (0.0, 1.0, 0.0)
        W = normalize(cross(N, arbitrary))
    else:
        W = normalize(cross_vec)

    # Step 6: Transform to world space using source formula: sample = V * x + W * y + normal * z
    sample_dir = (
        V[0]*s_x + W[0]*s_y + N[0]*s_z,
        V[1]*s_x + W[1]*s_y + N[1]*s_z,
        V[2]*s_x + W[2]*s_y + N[2]*s_z
    )

    # Step 7: Normalize and return
    return normalize(sample_dir)
```

**Parameters:**
- $n$: Phong exponent. Higher values produce sharper, more concentrated lobes [S1, unofficial].
- $\eta_1, \eta_2$: Random numbers. Must be independent and uniformly distributed [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Degenerate Normal/View Alignment:** If the view vector $\mathbf{V}$ is parallel to the normal $\mathbf{N}$, the cross product $\mathbf{N} \times \mathbf{V}$ is zero, making $\mathbf{W}$ undefined [G]. An arbitrary perpendicular vector must be chosen [G].
- **Precision:** For very large $n$, $(1 - \eta_1)^{\frac{1}{n+1}}$ approaches 1, making $\Theta$ approach 0 [G]. Floating-point precision issues may arise if $\eta_1$ is very close to 1 [G].
- **Non-Orthonormal Basis:** The source uses $\mathbf{V}$ directly as the x-axis basis vector [S1, unofficial]. If $\mathbf{V}$ is not orthogonal to $\mathbf{N}$, the basis $\{\mathbf{V}, \mathbf{W}, \mathbf{N}\}$ is not strictly orthonormal, which may skew the distribution [G]. Implementers should verify if $\mathbf{V}$ is intended to be the reflection vector or the view vector [G].

## Subtopics

### Multi-layer Sampling Template Generation
A set of sampling points distributed in spherical shells to approximate volume scattering, consisting of a diffuse reflection template and a highlight sampling template [S2, unofficial]. The diffuse template has 8 layers and 182 points total, with layer 0 having 6 points (1 center, 5 inside) and layers 1-7 having 8, 12, 16, 24, 32, 48, and 48 points respectively, evenly distributed in the area between the current and previous layer's sphere surfaces [S2, unofficial]. The highlight template has 4 layers with 32, 16, 16, and 8 points, evenly distributed by distance from incident light penetration [S2, unofficial]. The radius of the i-th layer template is $r_i = \frac{2^{i-1} \xi_i}{2^8 \times D(S_i)}$, where $D(S_i)$ is the shortest distance under unit radius (average minimum distance between points), $2^8$ is the resolution of the first-level mipmap, and $\xi_i = 1 - 0.08 \min(i, 5)$ is an empirical parameter controlling template overlap rate [S2, unofficial]. Smaller $\xi_i$ results in smaller radius $r_i$ [S2, unofficial].

## Operating characteristics
- **Time Complexity:** $O(1)$ per sample, as it involves a constant number of trigonometric and arithmetic operations [G].
- **Memory Complexity:** $O(1)$, as no data structures are stored [G].
- **Strengths:** Efficiently concentrates samples in the specular direction, reducing variance for glossy materials [G]. Simple to implement [G].
- **Limitations:** Assumes isotropic lobes [G]. Performance degrades if the Phong exponent is very high, as the distribution becomes extremely peaked, requiring more samples to capture the lobe accurately [G]. Degenerate cases (parallel normal and view vector) require special handling [G].
- **When to use:** Rendering glossy or specular surfaces where the reflection lobe is narrow [G].
- **When not to use:** Rendering diffuse surfaces (use [Uniform Sphere Sampling](1669-uniform-sphere-sampling.md) or [Cosine-Weighted Hemisphere Sampling](link if available)), or anisotropic materials (use [Anisotropic Scattering via Importance Sampling](4770-anisotropic-scattering-via-importance-sampling.md)) [G].

## Background
Importance Phong Sampling is a technique used in ray tracing and path tracing to sample the Phong reflection model [G]. It is derived from the Phong shading model, which approximates specular highlights [G]. The method is documented in the source code and associated notes of the referenced repository [S1, unofficial].
