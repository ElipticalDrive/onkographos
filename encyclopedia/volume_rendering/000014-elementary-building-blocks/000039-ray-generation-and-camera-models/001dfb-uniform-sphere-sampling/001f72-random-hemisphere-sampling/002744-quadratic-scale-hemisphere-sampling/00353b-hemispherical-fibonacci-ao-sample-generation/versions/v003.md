# Hemispherical Fibonacci AO Sample Generation

Also called: AO Sample Buffer Generation

## Overview
Generates a fixed set of 3D direction vectors for ambient occlusion sampling using a hemispherical Fibonacci mapping, stored in a compute buffer [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: `AmbientOcclusionSamples` (integer, range [1, 32], default 5) [S1, unofficial].
- Output: A `ComputeBuffer` containing `AmbientOcclusionSamples * 360` direction vectors [S1, unofficial].

**Data Structures:**
- **AO Sample Buffer**: A `ComputeBuffer` with element count `AmbientOcclusionSamples * 360`, stride 12 bytes (3 floats), and contiguous `Vector3` layout [S1, unofficial].

**Parameters:**
- `samplesPerStep`: Fixed at 360 [S1, unofficial].
- `AmbientOcclusionSamples`: Number of AO sample steps/iterations [S1, unofficial].

**Steps:**
1. Initialize `samplesPerStep = 360` [S1, unofficial].
2. Calculate `sampleCount = AmbientOcclusionSamples * samplesPerStep` [S1, unofficial].
3. Allocate a `ComputeBuffer` of size `sampleCount` with stride 12 bytes [S1, unofficial].
4. Initialize an index counter `c = 0`.
5. Loop `i` from 0 to `AmbientOcclusionSamples - 1`:
    a. Loop `deg` from 0 to 359:
        i. Update `deg` by multiplying by `360 / samplesPerStep` (effectively 1, yielding integer degrees 0-359) [S1, unofficial].
        ii. Convert `deg` to radians: `rad = deg * Mathf.Deg2Rad` [S1, unofficial].
        iii. Compute sample direction using `Utils.Sampling.HemisphericalFibonacciMapping(i, AmbientOcclusionSamples, rad)` [S1, unofficial].
        iv. Store the resulting `Vector3` in the buffer array at index `c` [S1, unofficial].
        v. Increment `c`.
6. Upload the `samples` array to the compute buffer using `SetData` [S1, unofficial].

**Formulas:**
- `rad = deg * Mathf.Deg2Rad` [S1, unofficial].
- `deg = deg * (360 / samplesPerStep)` [S1, unofficial].

**Pseudocode:**
```python
import math

DEG_TO_RAD = math.pi / 180.0

def generate_hemispherical_fibonacci_ao_samples(ambient_occlusion_samples: int) -> list:
    samples_per_step = 360
    sample_count = ambient_occlusion_samples * samples_per_step
    samples = []
    c = 0
    
    for i in range(ambient_occlusion_samples):
        for deg in range(360):
            # [S1, unofficial] Source code redundantly multiplies deg by 360/samplesPerStep (1.0).
            rad = deg * DEG_TO_RAD
            
            # [G] Standard Fibonacci hemisphere mapping implementation.
            theta = i * 2.399963229728653
            phi = rad
            x = math.cos(phi) * math.cos(theta)
            y = math.sin(theta)
            z = math.sin(phi) * math.cos(theta)
            sample = (x, y, z)
            
            samples.append(sample)
            c += 1
            
    return samples
```

**Edge Cases and Pitfalls:**
- The inner loop modifies `deg` in-place (`deg *= ...`), which is redundant since `samplesPerStep` is 360 and the loop increments by 1. This yields exact integer degree steps 0-359 [S1, unofficial].
