# Cosine-Weighted Hemisphere Sampling

Also called: Cosine Hemisphere Sampling, Cosine-Weighted Hemisphere Sampling for GI, Cosine-Weighted Solid Angle Sampling, Indirect Radiance with Cosine-Weighted Hemisphere Sampling, Lambertian Sampling, cosineSampleHemisphere, getSampleCosineWeighted

## Overview
Cosine-Weighted Hemisphere Sampling generates a random direction on a hemisphere oriented around a normal vector $\mathbf{n}$, weighted by the cosine of the polar angle [S3, unofficial][S4, unofficial][S5, unofficial]. It is used to compute the indirect lighting contribution at a surface point by sampling the hemisphere above the surface normal and recursively tracing rays [S2, unofficial]. It sets itself apart from its parent [Random Hemisphere Sampling](2034-random-hemisphere-sampling.md) by biasing samples toward the normal, which matches the cosine lobe of a Lambertian BRDF [S2, unofficial][S4, unofficial][S5, unofficial].

## How it works
**Inputs:**
- Surface normal $\mathbf{n}$ (unit vector) [S2, unofficial][S3, unofficial][S4, unofficial][S5, unofficial].
- Two uniform random numbers $r_1, r_2 \in [0, 1)$ [S2, unofficial][S3, unofficial][S5, unofficial].

**Outputs:**
- A unit direction vector $\mathbf{w}_i$ in the hemisphere defined by $\mathbf{n}$ [S1, unofficial][S2, unofficial][S3, unofficial][S4, unofficial][S5, unofficial].
- The probability density function (PDF) value for the sampled direction [S2, unofficial].

**Data Structures:**
- No specific complex data structures are required [S2, unofficial][S3, unofficial][S4, unofficial][S5, unofficial].

**Steps:**
1. Generate two decorrelated random numbers $r_1$ and $r_2$ using a hash function on pixel position, seed, and sample index [S1, unofficial].
2. Compute local spherical coordinates: $\phi = 2\pi r_1$, $\cos\theta = \sqrt{1 - r_2}$, $\sin\theta = \sqrt{r_2}$ [S2, unofficial]. Alternatively, compute Cartesian components directly: $x = \cos(\phi)\sqrt{r_1}$, $y = \sin(\phi)\sqrt{r_1}$, $z = \sqrt{1 - r_1}$ [S3, unofficial][S5, unofficial].
3. Construct a local orthonormal basis $(\mathbf{t}, \mathbf{b}, \mathbf{n})$ from $\mathbf{n}$ [S2, unofficial][S4, unofficial]. If $\mathbf{n}.x \neq 0.0$, set $\mathbf{t} = \text{normalize}(\mathbf{n}.y, -\mathbf{n}.x, 0.0)$, else set $\mathbf{t} = \text{normalize}(0.0, -\mathbf{n}.z, \mathbf{n}.y)$ [S2, unofficial][S4, unofficial]. Compute $\mathbf{b} = \text{cross}(\mathbf{t}, \mathbf{n})$ [S2, unofficial][S4, unofficial].
4. Transform to world space: $\mathbf{w}_i = \mathbf{t} \cdot x + \mathbf{b} \cdot y + \mathbf{n} \cdot z$ [S2, unofficial][S4, unofficial]. Normalize the result to ensure it is a unit vector [S3, unofficial].
5. Compute PDF: $p(\mathbf{w}_i) = \frac{\cos\theta}{\pi}$ [S2, unofficial].

**Formulas:**
- $\phi = 2\pi r_1$ [S2, unofficial]
- $\cos\theta = \sqrt{1 - r_2}$ [S2, unofficial]
- $\sin\theta = \sqrt{r_2}$ [S2, unofficial]
- $x = \cos(\phi)\sqrt{r_1}$, $y = \sin(\phi)\sqrt{r_1}$, $z = \sqrt{1 - r_1}$ [S3, unofficial][S5, unofficial]
- $p(\mathbf{w}_i) = \frac{\cos\theta}{\pi}$ [S2, unofficial]
- $\mathbf{w}_i = \mathbf{t} \cdot x + \mathbf{b} \cdot y + \mathbf{n} \cdot z$ [S2, unofficial][S4, unofficial]

**Parameters:**
- $r_1, r_2$: Uniform random numbers in $[0, 1)$ [S2, unofficial][S3, unofficial][S5, unofficial].
- $\pi$: Mathematical constant, approximately $3.14159265$ [S2, unofficial][S3, unofficial].

**Edge Cases and Pitfalls:**
- **Degenerate Basis:** If the normal is parallel to the world up vector, the cross product used to generate the tangent may result in a zero vector [S2, unofficial][S4, unofficial]. The conditional branch in step 3 avoids this by checking the absolute components of $\mathbf{n}$ and selecting an appropriate reference axis [S2, unofficial][S4, unofficial].
- **Precision:** Ensure $1 - r_2$ (or $1 - r_1$ in the Cartesian variant) is non-negative before taking the square root to avoid NaNs due to floating-point errors [S5, unofficial].

**Pseudocode:**
```python
import math

def cosine_weighted_hemisphere_sampling(normal, r1, r2):
    """
    Generates a cosine-weighted direction in the hemisphere defined by normal.
    
    Args:
        normal (tuple): (nx, ny, nz) unit normal vector.
        r1 (float): Uniform random number in [0, 1).
        r2 (float): Uniform random number in [0, 1).
        
    Returns:
        tuple: (direction, pdf)
            direction (tuple): (dx, dy, dz) unit direction vector.
            pdf (float): Probability density value.
    """
    # Step 1: Compute local spherical coordinates [S2, unofficial]
    phi = 2.0 * math.pi * r1
    cos_theta = math.sqrt(max(0.0, 1.0 - r2))
    sin_theta = math.sqrt(max(0.0, r2))
    
    # Step 2: Compute local Cartesian components [S3, unofficial][S5, unofficial]
    x_local = math.cos(phi) * sin_theta
    y_local = math.sin(phi) * sin_theta
    z_local = cos_theta
    
    # Step 3: Construct local basis [S2, unofficial][S4, unofficial]
    nx, ny, nz = normal
    if nx != 0.0:
        # Normal is not parallel to X axis
        tx, ty, tz = ny, -nx, 0.0
    else:
        # Normal is parallel to X axis, use alternative axis [S2, unofficial][S4, unofficial]
        tx, ty, tz = 0.0, -nz, ny
        
    len_t = math.sqrt(tx*tx + ty*ty + tz*tz)
    if len_t == 0:
        # Fallback for exact degeneracy [G]
        tx, ty, tz = 1.0, 0.0, 0.0
        len_t = 1.0
    tangent = (tx/len_t, ty/len_t, tz/len_t)
    
    # Bitangent = cross(tangent, normal) [S2, unofficial][S4, unofficial]
    bx = tangent[1] * nz - tangent[2] * ny
    by = tangent[2] * nx - tangent[0] * nz
    bz = tangent[0] * ny - tangent[1] * nx
    bitangent = (bx, by, bz)
    
    # Step 4: Transform to world space [S2, unofficial][S4, unofficial]
    dx = tangent[0] * x_local + bitangent[0] * y_local + normal[0] * z_local
    dy = tangent[1] * x_local + bitangent[1] * y_local + normal[1] * z_local
    dz = tangent[2] * x_local + bitangent[2] * y_local + normal[2] * z_local
    
    # Normalize [S3, unofficial]
    len_d = math.sqrt(dx*dx + dy*dy + dz*dz)
    if len_d > 0:
        dx /= len_d
        dy /= len_d
        dz /= len_d
    direction = (dx, dy, dz)
    
    # Step 5: Compute PDF [S2, unofficial]
    pdf = cos_theta / math.pi
    
    return direction, pdf
```
