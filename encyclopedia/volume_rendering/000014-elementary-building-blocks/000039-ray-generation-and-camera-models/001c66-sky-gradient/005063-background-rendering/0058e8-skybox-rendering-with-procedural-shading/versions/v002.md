# Skybox Rendering with Procedural Shading

Also called: Procedural Sky, Shader-based Sky

## Overview
A procedural sky rendered on a back-face culled sphere using a custom shader material, combining horizon/zenith gradients, ground reflection, tiling noise clouds, and a sun disk with glow [S1, unofficial]. It differs from kernel-based forward rendering by computing the background color per-fragment via analytical functions and noise sampling rather than precomputing or accumulating contributions in a separate pass [S1, unofficial].

## How it works
**Inputs and outputs:**
- Input: Camera view direction vector $\mathbf{dir}$ (normalized) [S1, unofficial].
- Input: Sun direction vector $\mathbf{sunDir}$ (normalized) [S1, unofficial].
- Input: Cloud texture (2D noise map) [S1, unofficial].
- Input: Color constants for horizon, zenith, ground, and sun [S1, unofficial].
- Output: Final background color $\mathbf{col}$ [S1, unofficial].

**Data structures:**
- Sphere geometry: Radius $R = 440$ units, resolution $32 \times 16$ segments, render order $-1000$ (renders behind everything), depth write disabled, fog disabled, frustum culling disabled [S1, unofficial].

**Parameters:**
- Horizon blend exponent: $0.55$ [S1, unofficial].
- Ground blend threshold: $0.25$ (smoothstep range start) [S1, unofficial].
- Cloud UV scale: $0.22$ [S1, unofficial].
- Cloud UV offset: $(0.31, 0.17)$ [S1, unofficial].
- Cloud noise threshold: $0.5$ to $0.78$ [S1, unofficial].
- Cloud vertical fade: $0.02$ to $0.22$ [S1, unofficial].
- Cloud opacity multiplier: $0.85$ [S1, unofficial].
- Cloud color mix threshold: $0.55$ to $0.9$ [S1, unofficial].
- Sun glow exponents: $12$ (weight $0.25$), $220$ (weight $0.6$) [S1, unofficial].
- Sun disk smoothstep: $0.99935$ to $0.9997$ [S1, unofficial].
- Sun disk intensity multiplier: $18$ [S1, unofficial].
- Cloud masking factor for sun: $0.8$ [S1, unofficial].

**Steps:**
1. Calculate normalized camera direction $\mathbf{dir}$ [S1, unofficial].
2. Compute vertical component $y = \mathbf{dir}.y$ [S1, unofficial].
3. Determine sun direction $\mathbf{sunDir}$ [S1, unofficial].
4. Calculate horizon blend factor $up = \max(y, 0)$ [S1, unofficial].
5. Mix horizon and zenith colors: $\mathbf{col} = \text{mix}(\text{color}(\text{HORIZON}), \text{color}(\text{ZENITH}), \text{pow}(up, 0.55))$ [S1, unofficial].
6. Blend with ground color based on negative $y$: $\mathbf{col} = \text{mix}(\mathbf{col}, \text{color}(\text{GROUND}), \text{smoothstep}(0, 0.25, -y))$ [S1, unofficial].
7. Generate cloud layer by projecting direction onto a high plane. Calculate UVs: $\mathbf{cuv} = (\mathbf{dir}.xz / (y + 0.12)) \times 0.22 + (0.31, 0.17)$ [S1, unofficial].
8. Sample tiling noise texture $n = \text{texture}(\text{cloudTexture}, \mathbf{cuv}).r$ [S1, unofficial].
9. Compute cloud opacity: $\mathbf{cloud} = \text{smoothstep}(0.5, 0.78, n) \times \text{smoothstep}(0.02, 0.22, y) \times 0.85$ [S1, unofficial].
10. Compute cloud color based on noise: $\mathbf{cloudCol} = \text{mix}((0.82, 0.86, 0.93), (1.15, 1.15, 1.15), \text{smoothstep}(0.55, 0.9, n))$ [S1, unofficial].
11. Blend cloud into sky: $\mathbf{col} = \text{mix}(\mathbf{col}, \mathbf{cloudCol}, \mathbf{cloud})$ [S1, unofficial].
12. Render sun disk and glow. Calculate dot product $s = \max(\mathbf{dir} \cdot \mathbf{sunDir}, 0)$ [S1, unofficial].
13. Compute glow using power functions: $\mathbf{glow} = \text{pow}(s, 12) \times 0.25 + \text{pow}(s, 220) \times 0.6$ [S1, unofficial].
14. Compute disk using smoothstep threshold: $\mathbf{disk} = \text{smoothstep}(0.99935, 0.9997, s) \times (1 - \mathbf{cloud} \times 0.8) \times 18$ [S1, unofficial].
15. Add sun color to sky: $\mathbf{col} = \mathbf{col} + \text{color}(\text{SUN\_COLOR}) \times (\mathbf{glow} + \mathbf{disk})$ [S1, unofficial].

**Pitfalls:**
- Sun disk must be masked by clouds to avoid rendering through them. Implemented by multiplying disk intensity by $1 - \mathbf{cloud} \times 0.8$ [S1, unofficial].
- Precision issues may arise near the horizon due to the $y+0.12$ term in cloud UV calculation; ensure $y$ does not cause division by zero or extreme UV stretching [G].
- The sphere must be rendered with depth write disabled and behind all other geometry (render order -1000) to avoid z-fighting with foreground objects [S1, unofficial].

**Pseudocode:**
```python
def render_skybox(dir_x, dir_y, dir_z, sunDir_x, sunDir_y, sunDir_z, cloud_sample_fn):
    # Constants from [S1, unofficial]
    HORIZON = (0.5, 0.7, 0.9)
    ZENITH = (0.1, 0.3, 0.6)
    GROUND = (0.4, 0.3, 0.2)
    SUN_COLOR = (1.0, 0.9, 0.7)

    def mix(a, b, t): return tuple(ai + (bi - ai) * t for ai, bi in zip(a, b))
    def smoothstep(e0, e1, x):
        t = max(0.0, min(1.0, (x - e0) / (e1 - e0)))
        return t * t * (3.0 - 2.0 * t)
    def dot(a, b): return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]

    y = dir_y
    up = max(y, 0.0)
    col = mix(HORIZON, ZENITH, up ** 0.55)
    col = mix(col, GROUND, smoothstep(0.0, 0.25, -y))

    uv_x = dir_x / (y + 0.12) * 0.22 + 0.31
    uv_y = dir_z / (y + 0.12) * 0.22 + 0.17
    n = cloud_sample_fn(uv_x, uv_y)

    cloud = smoothstep(0.5, 0.78, n) * smoothstep(0.02, 0.22, y) * 0.85
    cloud_col = mix((0.82, 0.86, 0.93), (1.15, 1.15, 1.15), smoothstep(0.55, 0.9, n))
    col = mix(col, cloud_col, cloud)

    sunDir = (sunDir_x, sunDir_y, sunDir_z)
    s = max(dot((dir_x, dir_y, dir_z), sunDir), 0.0)
    glow = (s ** 12) * 0.25 + (s ** 220) * 0.6
    disk = smoothstep(0.99935, 0.9997, s) * (1.0 - cloud * 0.8) * 18.0
    col = tuple(ci + SUN_COLOR[i] * (glow + disk) for i, ci in enumerate(col))

    return col
```
