# Background Rendering


## Overview
Background Rendering composites a distant environment field onto rays that have transmitted through the primary volume, handling the transition from finite geometry to an infinite or skybox-like backdrop [S4, unofficial]. It differs from [Sky Gradient](1262-sky-gradient.md) by modeling the background as a volumetric 3D grid sampled along concentric spheres rather than a simple 2D color interpolation, and from [SkyboxRendering](2619-skyboxrendering.md) by using a structured, density-based traversal that supports volumetric effects like light shafts and sun glow within the background layer itself [S4, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs**:
    *   `ray.origin`, `ray.dir`: Ray origin and direction vectors.
    *   `grid.background_data`: A 3D grid of shape `(background_reso * 2, background_reso, background_nlayers)` containing 4 channels per voxel: 3 for color (RGB) and 1 for density ($\sigma$) [S4, unofficial].
    *   `grid.background_reso`: Resolution of the equirectangular texture mapping [S2, unofficial].
    *   `grid.background_nlayers`: Number of radial layers in the background volume [S2, unofficial].
    *   `log_transmit`: Logarithmic transmittance from the foreground volume rendering pass [S4, unofficial].
    *   `opt`: Configuration object containing `step_size`, `stop_thresh`, and `background_brightness` [S4, unofficial].
*   **Outputs**:
    *   `out`: Accumulated background color (RGB) and updated transmittance state [S4, unofficial].

**Data Structures**
*   **Background Grid**: Stored as a flat array or 3D tensor. Each voxel holds 4 floats: $C_r, C_g, C_b, \sigma$.
*   **Ray Spec**: Contains `origin`, `dir`, and computed `pos` (position along ray) and `l` (integer lattice indices) [S4, unofficial].

**Parameters**
*   `inner_radius`: Minimum sampling radius, calculated as $\max(\text{dist}(\text{ray.origin}, \text{ray.dir}) + 10^{-3}, 1.0)$ [S4, unofficial].
*   `n_steps`: Number of sampling steps, calculated as $\lfloor \text{grid.background\_nlayers} / \text{opt.step\_size} \rfloor + 2$ [S4, unofficial].
*   `stop_thresh`: Threshold for early termination, typically $e^{-25}$ (checked via `log_transmit < -25`) [S4, unofficial].

**Algorithm Steps**

1.  **Initialization**:
    *   Extract background transmittance from the last sample of the foreground pass: $T_{bg} = \text{transmittance}[:, -1, :]$ [S1, unofficial].
    *   Check for early exit: If $\text{log\_transmit} < -25$, the ray is fully opaque; return the foreground color without background computation [S4, unofficial].
    *   Initialize output color accumulator `outv` to zeros [S4, unofficial].
    *   Set `invr_last` to infinity (or a sufficiently large value representing the start of the background volume) [S4, unofficial].

2.  **Sampling Loop** (for $i$ from $0$ to $n\_steps - 1$):
    *   **Calculate Radius**: Compute the sampling radius $r$ for the current step using non-linear spacing:
        $$ r = \frac{n\_steps}{n\_steps - i - 0.5} $$
        This places samples denser near the origin and sparser at infinity [S4, unofficial].
    *   **Intersection Check**: If $r < \text{inner\_radius}$, skip this step [S4, unofficial].
    *   **Ray Position**: Calculate the position `ray.pos` on the sphere of radius $r$:
        $$ \text{ray.pos}[j] = \text{fma}(t, \text{ray.dir}[j], \text{ray.origin}[j]) $$
        where $t$ is the intersection distance with the sphere of radius $r$ [S4, unofficial].
    *   **Coordinate Conversion**:
        *   Convert `ray.pos` to equirectangular coordinates for texture lookup [S4, unofficial].
        *   Compute the integer lattice indices `ray.l` from `ray.pos` and clamp them to valid bounds:
            *   $l_x \in [0, \text{background\_reso} \times 2 - 1]$
            *   $l_y \in [0, \text{background\_reso} - 1]$
            *   $l_z \in [0, \text{background\_nlayers} - 2]$ [S4, unofficial].
        *   Compute fractional offsets: $\text{ray.pos}[j] \leftarrow \text{ray.pos}[j] - \text{ray.l}[j]$ [S4, unofficial].
        *   Set the depth coordinate (layer index) based on inverse radius:
            $$ \text{ray.pos}[2] = \text{clamp}\left( (1.0 - \frac{1}{r}) \times \text{background\_nlayers} - 0.5, 0.0, \text{background\_nlayers} - 1 \right) $$
            (Note: Sources describe this as mapping the inverse radius to the layer index) [S4, unofficial].
    *   **Trilinear Interpolation**:
        *   Sample density $\sigma$ from `grid.background_data` using `trilerp_bg_one` with indices `ray.l` and fractional `ray.pos` [S4, unofficial].
        *   Sample color $C$ for each channel $i \in \{0, 1, 2\}$ from `grid.background_data` [S4, unofficial].
    *   **Weight Calculation**:
        *   Calculate optical depth increment:
            $$ \text{pcnt} = (\text{invr\_last} - \frac{1}{r}) \times \text{ray.world\_step} \times \sigma $$
            (Note: `ray.world_step` scales the radial distance to world units) [S4, unofficial].
        *   Calculate contribution weight:
            $$ w = e^{\text{log\_transmit}} \times (1 - e^{-\text{pcnt}}) $$
        *   Update log transmittance: $\text{log\_transmit} \leftarrow \text{log\_transmit} - \text{pcnt}$ [S4, unofficial].
    *   **Accumulation**:
        *   Scale color by SH DC factor $C_0$ (if applicable) and add bias: $C' = \max(C \times C_0 + 0.5, 0.0)$ [S4, unofficial].
        *   Accumulate color: $\text{outv}[i] \leftarrow \text{outv}[i] + w \times C'$ [S4, unofficial].
    *   **Termination Check**:
        *   If $e^{\text{log\_transmit}} < \text{opt.stop\_thresh}$, break loop [S4, unofficial].
    *   **Update State**:
        *   $\text{invr\_last} \leftarrow \frac{1}{r}$ [S4, unofficial].

3.  **Final Composition**:
    *   Add ambient/background brightness term scaled by remaining transmittance:
        $$ \text{out}[i] = \text{outv}[i] + e^{\text{log\_transmit}} \times \text{opt.background\_brightness} $$
    *   Merge with foreground: $\text{rgb}_{final} = \text{rgb}_{fg} + T_{bg} \times \text{out}$ [S1, unofficial].

**Pseudocode**

```python
def render_background_forward(grid, ray, log_transmit, opt):
    """
    Renders the background for a single ray using concentric sphere sampling.
    
    Args:
        grid: Object containing background_data, background_reso, background_nlayers.
        ray: Object with origin, dir, and world_step.
        log_transmit: Current log transmittance from foreground volume.
        opt: Configuration with step_size, stop_thresh, background_brightness.
        
    Returns:
        outv: Accumulated background color (3 floats).
        new_log_transmit: Updated log transmittance.
    """
    # Constants
    inner_radius = max(dist_ray_to_origin(ray.origin, ray.dir) + 1e-3, 1.0)
    n_steps = int(grid.background_nlayers / opt.step_size) + 2
    
    # Early exit for fully opaque rays
    if log_transmit < -25.0:
        return [0.0, 0.0, 0.0], log_transmit

    outv = [0.0, 0.0, 0.0]
    invr_last = float('inf') # Represents 1/r_start
    
    for i in range(n_steps):
        # Non-linear radius spacing
        r = n_steps / (n_steps - i - 0.5)
        
        if r < inner_radius:
            continue
            
        # Calculate position on sphere of radius r
        # t is the distance along ray.dir to reach radius r from origin
        # For a ray starting at origin, t = r. For offset origin, solve quadratic.
        # Simplified for origin-centered assumption or pre-computed t:
        t = r # Assuming ray.origin is near center or t is pre-calculated intersection
        ray_pos = [ray.origin[j] + t * ray.dir[j] for j in range(3)]
        
        # Convert to equirectangular/grid indices
        # 1. Integer lattice indices
        l_x = clamp(int(ray_pos[0] * grid.background_reso * 2), 0, grid.background_reso * 2 - 1)
        l_y = clamp(int(ray_pos[1] * grid.background_reso), 0, grid.background_reso - 1)
        
        # 2. Fractional offsets for trilinear interpolation
        frac_x = ray_pos[0] * grid.background_reso * 2 - l_x
        frac_y = ray_pos[1] * grid.background_reso - l_y
        
        # 3. Depth coordinate (layer) based on inverse radius
        # Map (1 - 1/r) to [0, background_nlayers]
        depth_val = (1.0 - 1.0 / r) * grid.background_nlayers - 0.5
        l_z = clamp(int(depth_val), 0, grid.background_nlayers - 2)
        frac_z = depth_val - l_z
        
        # Sample density and color from grid
        # trilerp_bg_one accesses grid.background_data at (l_x, l_y, l_z) with fractions (frac_x, frac_y, frac_z)
        sigma = trilerp_bg_one(grid.background_data, l_x, l_y, l_z, frac_x, frac_y, frac_z, channel=3)
        
        if sigma > 0.0:
            # Calculate optical depth
            # world_step scales the radial delta to world units
            dr = invr_last - (1.0 / r)
            pcnt = dr * ray.world_step * sigma
            
            # Calculate weight
            weight = exp(log_transmit) * (1.0 - exp(-pcnt))
            
            # Update log transmittance
            log_transmit -= pcnt
            
            # Sample color channels
            C0 = 1.0 # SH DC factor placeholder
            for c in range(3):
                color = trilerp_bg_one(grid.background_data, l_x, l_y, l_z, frac_x, frac_y, frac_z, channel=c)
                # Scale and bias
                color_val = max(color * C0 + 0.5, 0.0)
                outv[c] += weight * color_val
            
            # Termination check
            if exp(log_transmit) < opt.stop_thresh:
                break
        
        invr_last = 1.0 / r

    # Add ambient term
    for c in range(3):
        outv[c] += exp(log_transmit) * opt.background_brightness
        
    return outv, log_transmit
```

## Subtopics

### [Background Rendering Kernel (Forward)](14913-background-rendering-kernel-forward.md)
A CUDA kernel implementation that serves as the final compositing stage, accumulating color from background layers and adding a constant ambient term. It uses concentric spheres to mitigate aliasing compared to standard equirectangular sampling.

### [Skybox Rendering with Procedural Shading](16291-skybox-rendering-with-procedural-shading.md)
A procedural approach using a back-face culled sphere and custom shaders for sky gradients, sun glow, and noise clouds, differing from the kernel-based accumulation by computing color per-fragment analytically.

## Operating characteristics
*   **Time Complexity**: $O(N)$ where $N$ is the number of sampling steps ($n\_steps$). $N$ scales linearly with `background_nlayers` and inversely with `opt.step_size` [S4, unofficial].
*   **Memory Complexity**: $O(\text{background\_reso}^2 \times \text{background\_nlayers})$ to store the background grid [S4, unofficial].
*   **Performance**: The concentric sphere sampling provides structured traversal which helps mitigate aliasing artifacts common in naive equirectangular sampling [S1, unofficial].
*   **Strengths**: Handles infinite distance backgrounds naturally; supports volumetric effects (light shafts, sun glow) within the background layer; efficient early termination for opaque rays [S4, unofficial].
*   **Limitations**: Requires pre-computation or training of the background grid; numerical instability if `log_transmit` is not managed correctly (mitigated by the -25 threshold) [S4, unofficial].
*   **When to use**: When the background needs to interact with volumetric lighting (e.g., god rays) or when a high-resolution, layered environment is required beyond simple sky gradients [S4, unofficial].

## Background
Background Rendering in the context of neural volume rendering (specifically svox2) was introduced to handle the "infinite" background in a way that is consistent with the volumetric rendering equation [S4, unofficial]. It builds on the concept of concentric sphere sampling to provide a structured way to traverse the environment field [S1, unofficial]. The method is part of the svox2 framework, which extends neural voxels to support complex scene representations including backgrounds [S4, unofficial].
