## How it works
**Inputs:**
- `time_budget` (float): Target render time in seconds or milliseconds [S1, unofficial].
- `num_samples` (int): Number of initialization and iteration points for the Bayesian optimizer [S1, unofficial].
- `default_lod_params` (List[float]): Default Level-of-Detail parameters, typically `[1.0, 1.0, 1.0, 1.0]` [S1, unofficial].
- `sampler_params`: Object containing `min_point` and `max_point` defining the spatial bounds for camera positions [S1, unofficial].

**Outputs:**
- Best position and rotation parameters extracted from the optimizer's maximum result [S1, unofficial].

**Data Structures:**
- Search bounds `pbounds`: Dictionary mapping parameter names to `(min, max)` tuples for position $(x, y, z)$ and rotation Euler angles $(r_x, r_y, r_z)$ [S1, unofficial].
- State object: Contains `pos` (position vector) and quaternion representation of rotation [S1, unofficial].

**Steps:**
1. Define search bounds `pbounds` for position coordinates $(x, y, z)$ and rotation Euler angles $(r_x, r_y, r_z)$ using `sampler_params.min_point` and `sampler_params.max_point` [S1, unofficial].
2. Initialize a Bayesian optimizer with a loss function $L = |t_{\text{render}} - t_{\text{budget}}|$ [S1, unofficial].
3. For each candidate pose $(x, y, z, r_x, r_y, r_z)$:
   a. Set position $p = (x, y, z)$ [S1, unofficial].
   b. Convert Euler angles to a quaternion $q_{xyzw} = \text{Rotation.from\_euler}("XYZ", [r_x, r_y, r_z]).\text{as\_quat}()$ [S1, unofficial].
   c. Reorder quaternion components from $[x, y, z, w]$ to $[w, x, y, z]$ to match the engine's expected format [S1, unofficial].
   d. Predict LOD parameters using `default_lod_params` if not specified [S1, unofficial].
   e. Measure the actual render time $t_{\text{render}}$ [S1, unofficial].
4. Run the optimization loop with `init_points=num_samples` and `n_iter=num_samples` [S1, unofficial].
5. Extract the best position and rotation from the optimizer's result, filtering keys starting with `p_` and `r_` [S1, unofficial].

**Pitfalls:**
- Quaternion component ordering differs between libraries. The implementation explicitly reorders $[x, y, z, w]$ to $[w, x, y, z]$ before passing to the engine [S1, unofficial].

```python
from scipy.spatial.transform import Rotation

def active_learning_scene_sampling(time_budget, num_samples, default_lod_params, sampler_params):
    # Define search bounds for position and rotation
    pbounds = {
        'p_x': (sampler_params.min_point[0], sampler_params.max_point[0]),
        'p_y': (sampler_params.min_point[1], sampler_params.max_point[1]),
        'p_z': (sampler_params.min_point[2], sampler_params.max_point[2]),
        'r_x': (-180, 180),
        'r_y': (-180, 180),
        'r_z': (-180, 180)
    }

    def loss_function(p_x, p_y, p_z, r_x, r_y, r_z):
        # Set position
        pos = [p_x, p_y, p_z]
        # Convert Euler angles to quaternion [x, y, z, w]
        quat_xyzw = Rotation.from_euler("XYZ", [r_x, r_y, r_z]).as_quat()
        # Reorder to [w, x, y, z] for engine
        w, x, y, z = quat_xyzw[3], quat_xyzw[0], quat_xyzw[1], quat_xyzw[2]
        quat_engine = (w, x, y, z)
        # Predict LOD parameters
        lod_params = default_lod_params
        # Sources do not provide the engine.sample() implementation.
        render_time = 0.0
        # Return negative loss (optimizer maximizes)
        return -abs(render_time - time_budget)

    # Sources do not specify the exact Bayesian optimization library initialization.
    optimizer = None
    optimizer.maximize(f=loss_function, pbounds=pbounds, init_points=num_samples, n_iter=num_samples)
    best_params = optimizer.max['params']
    best_pos = [best_params['p_x'], best_params['p_y'], best_params['p_z']]
    best_rot = [best_params['r_x'], best_params['r_y'], best_params['r_z']]
    return best_pos, best_rot
```
