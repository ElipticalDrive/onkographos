# Random Camera Sampling

Also called: Camera Sampling

## Overview
Random Camera Sampling selects a fixed number of cameras from a predefined viewpoint stack by uniformly sampling indices without replacement [S1, unofficial]. It differs from its sibling, [Random Pose Selection](8187-random-pose-selection.md), which typically generates continuous pose parameters, by operating on a discrete set of existing viewpoints [S1, unofficial]. This method ensures diversity in the selected subset by preventing duplicate selections within a single sampling run.

## How it works
**Inputs:**
- `my_viewpoint_stack`: A list of camera objects representing available viewpoints.
- `num_cams`: An integer specifying the number of cameras to sample. In the reference implementation, this is fixed at 10 [S1, unofficial].

**Outputs:**
- `camlist`: A list of `num_cams` camera objects, popped from the original stack.

**Data Structures:**
- `my_viewpoint_stack`: A dynamic list (array) of camera objects.
- `camlist`: A dynamic list (array) of camera objects.

**Steps:**
1. Initialize `num_cams` to 10 [S1, unofficial].
2. Initialize an empty list `camlist` [S1, unofficial].
3. Loop `num_cams` times:
    a. Generate a random integer `loc` uniformly distributed in the range $[0, \text{len}(my\_viewpoint\_stack) - 1]$ [S1, unofficial].
    b. Remove the camera object at index `loc` from `my_viewpoint_stack` [S1, unofficial].
    c. Append the removed camera object to `camlist` [S1, unofficial].
4. Return `camlist` [S1, unofficial].

**Pseudocode:**
```python
import random

def random_camera_sampling(my_viewpoint_stack, num_cams=10):
    """
    Samples a fixed number of cameras from a viewpoint stack without replacement.
    
    Args:
        my_viewpoint_stack (list): List of camera objects.
        num_cams (int): Number of cameras to sample. Default is 10.
        
    Returns:
        list: A list of sampled camera objects.
    """
    camlist = []
    
    # Ensure we do not sample more cameras than available
    actual_num_cams = min(num_cams, len(my_viewpoint_stack))
    
    for _ in range(actual_num_cams):
        # Generate random index in the current valid range
        loc = random.randint(0, len(my_viewpoint_stack) - 1)
        
        # Pop the camera at the random index and append to result list
        camera = my_viewpoint_stack.pop(loc)
        camlist.append(camera)
        
    return camlist
```

**Parameters:**
- `num_cams`: Fixed at 10 in the source implementation [S1, unofficial].
- `my_viewpoint_stack`: The source list of viewpoints [S1, unofficial].

**Edge Cases and Pitfalls:**
- If `num_cams` exceeds the length of `my_viewpoint_stack`, the algorithm must handle the shortage. The pseudocode above caps the sampling at the available stack size to prevent index errors [G].
- The method modifies the input `my_viewpoint_stack` by popping elements. If the original stack must be preserved, a copy should be made before sampling [G].

## Subtopics

### [Active Learning Scene Sampling](15489-active-learning-scene-sampling.md)
Active Learning Scene Sampling finds optimal camera poses (position and rotation) that minimize the deviation of median render time from a target time budget using Bayesian optimization. It differs from its parent, Random Camera Sampling, by intelligently selecting viewpoints based on performance feedback rather than uniform random selection.

## Operating characteristics
**Time Complexity:** $O(K)$, where $K$ is `num_cams`. Each iteration involves a random number generation and a list pop operation. In Python, `list.pop(index)` is $O(N)$ where $N$ is the current length of the list, making the total complexity $O(K \cdot N)$ in the worst case if the list is large and indices are near the beginning [G].
**Memory Complexity:** $O(K)$ for storing the output list `camlist`. The input stack is modified in place.
**Strengths:** Simple to implement; guarantees no duplicate cameras in the sample; ensures uniform probability for each remaining camera at each step.
**Limitations:** Modifies the input data structure; performance degrades if the stack is very large and many samples are drawn due to $O(N)$ pop operations.

## Background
This method is documented in the FastGS repository, which implements efficient Gaussian Splatting training routines [S1, unofficial]. It is used to select a subset of viewpoints for rendering during the optimization process.
