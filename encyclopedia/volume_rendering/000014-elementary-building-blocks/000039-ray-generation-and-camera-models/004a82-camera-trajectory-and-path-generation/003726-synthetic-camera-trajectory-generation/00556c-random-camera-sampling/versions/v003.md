# Random Camera Sampling

Also called: Camera Sampling

## Overview
Random Camera Sampling is a method for generating a fixed set of camera poses by uniformly selecting from a pre-existing stack of viewpoints [S1, unofficial]. It solves the problem of initializing training views for neural rendering or 3D reconstruction when a diverse set of source images is available but no specific trajectory is required. It differs from its sibling [Random Pose Selection](8187-random-pose-selection.md) by drawing from a discrete, finite list of existing cameras rather than generating continuous poses from a parametric distribution [S1, unofficial].

## How it works
**Inputs:**
- `my_viewpoint_stack`: A list of camera objects representing available viewpoints.
- `num_cams`: An integer specifying the number of cameras to sample (typically 10) [S1, unofficial].

**Outputs:**
- `camlist`: A list of `num_cams` camera objects, sampled without replacement from `my_viewpoint_stack` [S1, unofficial].

**Data Structures:**
- `my_viewpoint_stack`: A dynamic array (list) of camera objects.
- `camlist`: A dynamic array (list) of camera objects.

**Steps:**
1. Initialize an empty list `camlist`.
2. Set a counter `i` to 0.
3. While `i` is less than `num_cams`:
    a. Generate a random integer `loc` uniformly distributed in the range $[0, \text{len}(my\_viewpoint\_stack) - 1]$.
    b. Retrieve the camera object at index `loc` from `my_viewpoint_stack`.
    c. Remove the camera object at index `loc` from `my_viewpoint_stack` (pop operation).
    d. Append the retrieved camera object to `camlist`.
    e. Increment `i` by 1.
4. Return `camlist`.

**Pseudocode:**
```python
def random_camera_sampling(my_viewpoint_stack, num_cams=10):
    camlist = []
    for _ in range(num_cams):
        # Generate random index in current valid range
        loc = random.randint(0, len(my_viewpoint_stack) - 1)
        # Pop ensures sampling without replacement
        camera = my_viewpoint_stack.pop(loc)
        camlist.append(camera)
    return camlist
```

**Parameters:**
- `num_cams`: The number of cameras to sample. The source code fixes this value at 10 [S1, unofficial].
- `my_viewpoint_stack`: The source list of viewpoints. It is modified in-place (consumed) during sampling [S1, unofficial].

**Edge Cases and Pitfalls:**
- If `num_cams` exceeds the length of `my_viewpoint_stack`, the loop will fail when attempting to generate a random index for an empty or insufficient list. The source does not specify a guard for this condition [G].
- Sampling is without replacement, meaning each camera in the stack can be selected at most once [S1, unofficial].

## Subtopics

### [Active Learning Scene Sampling](15489-active-learning-scene-sampling.md)
Active Learning Scene Sampling finds optimal camera poses (position and rotation) that minimize the deviation of median render time from a target time budget using Bayesian optimization. It differs from its parent, Random Camera Sampling, by intelligently selecting viewpoints based on performance feedback rather than uniform random selection.

### [Elliptic Cylinder Sampled Views](17402-elliptic-cylinder-sampled-views.md)
Elliptic Cylinder Sampled Views is a camera trajectory generation method that creates random viewpoints directed at a scene center for computing SDS (Score Distillation Sampling) loss, using an elliptical cylinder that fits the training view positions. It differs from its sibling [Active Learning Scene Sampling](15489-active-learning-scene-sampling.md) by relying on a geometric fit of existing views rather than an active learning loop, and from [Warped Views](#warped-views) by generating novel, uncorrelated positions rather than rotating existing ones.

## Operating characteristics
**Time Complexity:** $O(N)$ where $N$ is `num_cams`, assuming list pop operations are $O(1)$ or $O(K)$ where $K$ is the remaining stack size. In Python lists, `pop(index)` is $O(M)$ where $M$ is the number of elements after the index. Thus, worst-case time is $O(N \cdot M)$ where $M$ is the initial stack size [G].
**Memory Complexity:** $O(N)$ to store the output `camlist`. The input stack is modified in-place [S1, unofficial].
**Strengths:** Simple to implement; ensures diversity by sampling without replacement from a known set of valid viewpoints [S1, unofficial].
**Limitations:** Limited to the viewpoints present in the input stack; does not generate novel poses [S1, unofficial].
**When to use:** When a fixed set of high-quality source images is available and no specific trajectory is needed [S1, unofficial].
**When not to use:** When novel viewpoints outside the source set are required, or when the source stack is too small [G].

## Background
Random Camera Sampling is used in the context of Gaussian Splatting training pipelines, specifically within the FastGS repository [S1, unofficial]. It is employed to select a subset of cameras for rendering operations, likely for efficiency or specific training stages [S1, unofficial].
