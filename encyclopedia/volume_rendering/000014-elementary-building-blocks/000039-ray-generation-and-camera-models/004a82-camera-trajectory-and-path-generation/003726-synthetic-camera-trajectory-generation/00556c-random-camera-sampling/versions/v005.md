# Random Camera Sampling

Also called: Camera Sampling

## Overview
Random Camera Sampling selects a fixed number of cameras from a predefined viewpoint stack by uniformly sampling indices without replacement [S1, unofficial]. It solves the problem of generating a diverse set of training views for 3D reconstruction or novel view synthesis when a limited pool of existing captures is available [S1, unofficial]. It differs from its sibling [Random Pose Selection](8187-random-pose-selection.md) by drawing exclusively from a discrete, existing list of poses rather than generating continuous pose parameters from a distribution [S1, unofficial].

## How it works
**Inputs:**
- `my_viewpoint_stack`: A list of camera objects or pose data structures representing available viewpoints.
- `num_cams`: An integer specifying the number of cameras to sample.

**Outputs:**
- `camlist`: A list of `num_cams` camera objects, ordered by selection time.

**Data Structures:**
- `my_viewpoint_stack`: A dynamic array (list) of camera poses.
- `camlist`: A dynamic array (list) of selected camera poses.

**Parameters:**
- `num_cams`: The count of cameras to extract. The source implementation fixes this value at 10 [S1, unofficial].

**Steps:**
1. Initialize `num_cams` to 10 [S1, unofficial].
2. Initialize `camlist` as an empty list [S1, unofficial].
3. Loop `num_cams` times:
    a. Generate a random integer `loc` uniformly distributed in the range $[0, \text{len}(my\_viewpoint\_stack) - 1]$ [S1, unofficial].
    b. Remove the camera at index `loc` from `my_viewpoint_stack` using a pop operation [S1, unofficial].
    c. Append the removed camera to `camlist` [S1, unofficial].
4. Return `camlist` [S1, unofficial].

**Pseudocode:**
```python
import random

def random_camera_sampling(my_viewpoint_stack, num_cams=10):
    """
    Samples num_cams cameras from my_viewpoint_stack without replacement.
    
    Args:
        my_viewpoint_stack: List of camera pose objects.
        num_cams: Number of cameras to sample (default 10).
        
    Returns:
        List of sampled camera pose objects.
    """
    camlist = []
    
    for _ in range(num_cams):
        if len(my_viewpoint_stack) == 0:
            raise ValueError("Stack exhausted before requested cameras were sampled.")
        
        # Generate random index in [0, len(stack) - 1]
        loc = random.randint(0, len(my_viewpoint_stack) - 1)
        
        # Pop camera at loc and append to result list
        camera = my_viewpoint_stack.pop(loc)
        camlist.append(camera)
        
    return camlist
```

**Edge Cases and Pitfalls:**
- **Stack Exhaustion:** If `num_cams` exceeds the initial length of `my_viewpoint_stack`, the loop will raise an error. A guard is required [G].
- **Replacement:** The `pop` operation ensures sampling without replacement, preventing duplicate cameras in the output list [S1, unofficial].
- **Index Bounds:** `randint` is inclusive on both ends, correctly covering $[0, \text{len} - 1]$ for zero-indexed arrays [G].

## Subtopics

### [Active Learning Scene Sampling](15489-active-learning-scene-sampling.md)
Active Learning Scene Sampling finds optimal camera poses (position and rotation) that minimize the deviation of median render time from a target time budget using Bayesian optimization. It differs from its parent, Random Camera Sampling, by intelligently selecting viewpoints based on performance feedback rather than uniform random selection.

### [Elliptic Cylinder Sampled Views](17402-elliptic-cylinder-sampled-views.md)
Elliptic Cylinder Sampled Views is a camera trajectory generation method that creates random viewpoints directed at a scene center for computing SDS (Score Distillation Sampling) loss, using an elliptical cylinder that fits the training view positions. It differs from its sibling [Warped Views](17410-warped-views.md) by generating novel, uncorrelated positions on a fitted cylinder rather than rotating existing camera poses.

### [Structured Camera Batch Generation](17801-structured-camera-batch-generation.md)
Structured Camera Batch Generation generates a deterministic list of camera samples (positions) for a 3D dataset, distributing them between close-up views and general views based on a specified ratio, and sampling directions uniformly or within a hemisphere. It differs from its parent [Random Camera Sampling](15470-random-camera-sampling.md) by enforcing a structured ratio of close-up to general views rather than purely random selection, and from siblings like [Elliptic Cylinder Sampled Views](17402-elliptic-cylinder-sampled-views.md) by using spherical radius constraints rather than elliptic cylinder geometry.

### Random Camera Pose Generation
Random Camera Pose Generation generates random camera poses within a scaled and recentered bounding volume, targeting a computed focal depth [S2, unofficial].

## Background
Random Camera Sampling is a technique used in Gaussian Splatting and 3D reconstruction pipelines to select training viewpoints [S1, unofficial]. It is implemented in the FastGS repository, which provides optimized tools for training 3D Gaussian Splatting models [S1, unofficial]. The method is often used in conjunction with other sampling strategies like Structured Camera Batch Generation to ensure balanced dataset creation [S2, unofficial].
