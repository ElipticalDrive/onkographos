# Streamline Approximation via Iterative B-spline Fitting

Also called: Data reduction scheme for B-splines, Iterative curve fitting

## Overview
This method computes a B-spline curve $\gamma(u)$ that approximates a set of input samples $X$, specifically designed to avoid the oscillations ("wriggles") introduced by standard interpolation or least-squares approximation [S1]. These artifacts are problematic for generating tubular geometry and ambient occlusion in volume rendering [S1]. It sets itself apart from [Least-squares approximation](link) by leveraging Schönberg’s approximation properties to prevent new perturbations, and from [Interpolation](link) by strictly avoiding the introduction of features not present in the original data [S1].

## How it works
**Inputs:**
- $X = \{x_1, \dots, x_n\}$: A set of $n$ 3D points representing a sampled streamline or path.
- $\epsilon$: User-specified accuracy threshold for termination.

**Outputs:**
- $\gamma(u)$: A cubic ($C^2$ continuous) B-spline curve approximating $X$.
- $k$: The number of iterations performed in the data reduction scheme.

**Data Structures:**
- **B-spline Curve $\gamma_i(u)$**: Defined by a set of control points (coefficients). For a cubic B-spline, the curve is a linear combination of basis functions weighted by these coefficients.
- **Sample Set $X_i$**: A list of points generated by evaluating the previous curve $\gamma_{i-1}(u)$.

**Parameters:**
- $\epsilon$: Termination threshold. Typical value: $10^{-4}$ [S1].
- $n$: Initial number of samples in $X$ [S1].

**Algorithm Steps:**

1.  **Initialization (Schönberg’s Approximation):**
    Construct an initial cubic B-spline curve $\gamma_1(u)$ using the input samples $X$ directly as its control point coefficients. This step relies on the variation diminishing property of B-splines to approximate $X$ without introducing new perturbations [S1].

2.  **Iterative Data Reduction:**
    Repeat the following steps for $i = 2, 3, \dots$ until termination:
    
    a. **Calculate Sample Count:**
       Compute the number of samples $m_i$ for the current iteration:
       $$ m_i = \left\lfloor \frac{n}{2^{i-1}} \right\rfloor $$
       At each step, the number of samples is halved [S1].
       
    b. **Construct New Sample Set $X_i$:**
       Generate $X_i$ by regularly sampling the parameter space of the previous curve $\gamma_{i-1}(u)$. The $j$-th sample in $X_i$ is obtained by evaluating $\gamma_{i-1}$ at parameter value $u_j = \frac{j-1}{m_i-1}$:
       $$ x'_j = \gamma_{i-1}\left( \frac{j-1}{m_i-1} \right), \quad j = 1, \dots, m_i $$
       This process samples a $C^2$ curve, smoothing out high-frequency features [S1].
       
    c. **Iterative Curve Fitting:**
       Compute the new curve $\gamma_i(u)$ by applying an iterative curve fitting algorithm to the sample set $X_i$. The coefficients of $\gamma_i(u)$ are updated so that the curve moves closer to the samples in $X_i$ until a user-specified accuracy is achieved. The specific details of this iterative update and its convergence properties are defined in [14] (see Sources) [S1].
       
    d. **Error Check:**
       Calculate the maximum error $\epsilon_{\max}$ between the original samples $X$ and the current curve $\gamma_i(u)$. The error is defined as:
       $$ \epsilon_{\max} := \max_{1 \le j \le n} \| x'_j - x_j \|_2 $$
       where $x_j \in X$ and $x'_j$ is the projection of $x_j$ onto the current curve $\gamma_i(u)$ [S1].
       
    e. **Termination:**
       If $\epsilon_{\max} \le \epsilon$, terminate. The final curve is $\gamma(u) := \gamma_i(u)$ and $k = i$. Otherwise, increment $i$ and repeat.

```python
def streamline_approximation(X, epsilon):
    """
    Approximates a set of points X using iterative B-spline fitting.
    
    Args:
        X: List of n 3D points (samples).
        epsilon: Termination threshold (e.g., 1e-4).
        
    Returns:
        gamma: Final B-spline curve object.
        k: Number of iterations.
    """
    n = len(X)
    
    # Step 1: Initialize with Schönberg's approximation
    # Construct cubic B-spline gamma_1 using X as control points
    gamma_prev = create_cubic_b_spline(control_points=X)
    
    i = 1
    
    while True:
        i += 1
        
        # Step 2a: Calculate number of samples
        m_i = floor(n / (2 ** (i - 1)))
        
        # Step 2b: Construct new sample set X_i by sampling gamma_prev
        X_i = []
        for j in range(1, m_i + 1):
            u = (j - 1) / (m_i - 1)
            point = evaluate_b_spline(gamma_prev, u)
            X_i.append(point)
            
        # Step 2c: Iterative curve fitting to get gamma_i
        # Note: The specific iterative update algorithm is detailed in [14].
        # This function updates coefficients of gamma_prev to fit X_i.
        gamma_curr = iterative_fit_b_spline(X_i, gamma_prev)
        
        # Step 2d: Calculate max error against original samples X
        # x'_j is the projection of x_j onto gamma_curr
        max_error = 0.0
        for x_j in X:
            # Projection of a point onto a B-spline curve
            # This typically involves finding the parameter u that minimizes distance
            # or using the closest point on the curve.
            x_prime_j = project_point_onto_curve(x_j, gamma_curr)
            dist = l2_norm(x_prime_j - x_j)
            if dist > max_error:
                max_error = dist
                
        # Step 2e: Termination check
        if max_error <= epsilon:
            return gamma_curr, i
        
        # Prepare for next iteration
        gamma_prev = gamma_curr
```

**Edge Cases and Pitfalls:**
- **Division by Zero:** If $m_i = 1$, the parameter calculation $\frac{j-1}{m_i-1}$ involves division by zero. This occurs if $n < 2^{i-1}$. The algorithm assumes $n$ is sufficiently large such that $m_i \ge 2$ for all relevant iterations. If $m_i < 2$, the sampling step is undefined.
- **Projection Cost:** Calculating the projection $x'_j$ of each original sample onto the curve can be computationally expensive if not optimized.
- **Convergence:** The iterative fitting step (Step 2c) relies on the algorithm from [14]. If this sub-algorithm fails to converge or oscillates, the overall method may not terminate or may produce unstable curves [S1].

## Operating characteristics
- **Time Complexity:** The method involves $k$ iterations. In each iteration, the number of samples is halved. The iterative fitting step (Step 2c) is non-trivial and depends on the specific algorithm from [14]. The error calculation requires projecting $n$ points onto the curve.
- **Memory Complexity:** Requires storing the control points for the current and previous curves, and the sample sets $X_i$.
- **Performance:** For the data sets shown in the source, $k < 4$ with $\epsilon = 10^{-4}$ [S1].
- **Strengths:** Effectively reduces wriggles and oscillations compared to least-squares approximation, leading to cleaner tubular geometry and ambient occlusion [S1].
- **Limitations:** Requires the iterative fitting algorithm from [14] to be implemented correctly. The projection step can be costly.

## Background
This method was proposed in the context of visualizing streamlines and generating stream tubes for volume rendering, where visual artifacts from curve approximation can significantly impact the quality of ambient occlusion [S1]. It builds on Schönberg’s approximation properties and the iterative curve fitting algorithm described in [14] [S1].
