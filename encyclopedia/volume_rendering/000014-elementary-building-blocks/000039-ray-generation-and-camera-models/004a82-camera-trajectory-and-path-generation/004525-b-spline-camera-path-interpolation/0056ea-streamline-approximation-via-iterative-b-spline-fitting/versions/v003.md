# Streamline Approximation via Iterative B-spline Fitting

Also called: Data reduction scheme for B-splines, Iterative curve fitting

## Overview
This method computes a B-spline curve $\gamma(u)$ that approximates a set of input samples $X$, specifically designed to avoid the oscillations ("wriggles") introduced by standard interpolation or least-squares approximation [S1]. These artifacts are problematic for generating tubular geometry and ambient occlusion in volume rendering [S1]. It sets itself apart from [Least-squares approximation](link) by leveraging Schönberg’s approximation properties to prevent new perturbations, and from [Interpolation](link) by strictly avoiding the introduction of features not present in the original data [S1].

## How it works
**Inputs:**
- $X = \{x_1, \dots, x_n\}$: A set of $n$ 3D points representing a sampled streamline or path [S1].
- $\epsilon$: User-specified accuracy threshold for termination [S1].

**Outputs:**
- $\gamma(u)$: A cubic ($C^2$ continuous) B-spline curve approximating $X$ [S1].
- $k$: The number of iterations performed in the data reduction scheme [S1].

**Data Structures:**
- **B-spline Curve $\gamma_i(u)$**: Defined by a set of control points (coefficients) [S1]. For implementation, the curve is evaluated as a linear combination of cubic B-spline basis functions weighted by these coefficients [G].
- **Sample Set $X_i$**: A list of $m_i$ points generated by evaluating the previous curve $\gamma_{i-1}(u)$ at uniformly spaced parameters [S1].

**Parameters:**
- $\epsilon$: Termination threshold. Typical value: $10^{-4}$ [S1].
- $n$: Initial number of samples in $X$ [S1].

**Algorithm Steps:**

1. **Initialization (Schönberg’s Approximation):**
   Construct an initial cubic B-spline curve $\gamma_1(u)$ using the input samples $X$ directly as its control point coefficients [S1]. This step relies on the variation diminishing property of B-splines to approximate $X$ without introducing new perturbations [S1].

2. **Iterative Data Reduction:**
   Repeat the following steps for $i = 2, 3, \dots$ until termination:
   
   a. **Calculate Sample Count:**
      Compute the number of samples $m_i$ for the current iteration:
      $$ m_i = \left\lfloor \frac{n}{2^{i-1}} \right\rfloor $$
      At each step, the number of samples is halved [S1].
      
   b. **Construct New Sample Set $X_i$:**
      Generate $X_i$ by regularly sampling the parameter space of the previous curve $\gamma_{i-1}(u)$ [S1]. The $j$-th sample in $X_i$ is obtained by evaluating $\gamma_{i-1}$ at parameter value $u_j = \frac{j-1}{m_i-1}$:
      $$ x'_j = \gamma_{i-1}\left( \frac{j-1}{m_i-1} \right), \quad j = 1, \dots, m_i $$
      This process samples a $C^2$ curve, smoothing out high-frequency features [S1].
      
   c. **Iterative Curve Fitting:**
      Compute the new curve $\gamma_i(u)$ by applying an iterative curve fitting algorithm to the sample set $X_i$ [S1]. The coefficients of $\gamma_i(u)$ are updated so that the curve moves closer to the samples in $X_i$ until a user-specified accuracy is achieved [S1]. The specific iterative update rules and convergence properties are detailed in [14] [G].
      
   d. **Error Check:**
      Calculate the maximum error $\epsilon_{\max}$ between the original samples $X$ and the current curve $\gamma_i(u)$ [S1]. The error is defined as:
      $$ \epsilon_{\max} := \max_{1 \le j \le n} \| x'_j - x_j \|_2 $$
      where $x_j \in X$ and $x'_j$ is the projection of $x_j$ onto the current curve $\gamma_i(u)$ [S1].
      
   e. **Termination:**
      If $\epsilon_{\max} \le \epsilon$, terminate [S1]. The final curve is $\gamma(u) := \gamma_i(u)$ and $k = i$ [S1]. Otherwise, increment $i$ and repeat.

import math

def streamline_approximation(X, epsilon):
    """
    Approximates a set of points X using iterative B-spline fitting.
    
    Args:
        X: List of n 3D points (samples).
        epsilon: Termination threshold (e.g., 1e-4).
        
    Returns:
        gamma: Final B-spline control points.
        k: Number of iterations.
    """
    n = len(X)
    gamma_prev = list(X)  # Control points for gamma_1
    i = 1

    while True:
        i += 1
        m_i = math.floor(n / (2 ** (i - 1)))
        
        # Guard against division by zero if m_i < 2 [G]
        if m_i < 2:
            break

        # Step 2b: Construct X_i by sampling gamma_prev
        X_i = []
        for j in range(1, m_i + 1):
            u = (j - 1) / (m_i - 1)
            X_i.append(evaluate_cubic_b_spline(gamma_prev, u))

        # Step 2c: Iterative curve fitting
        # The specific iterative coefficient update rules to fit X_i

        gamma_curr = iterative_fit_b_spline(X_i, gamma_prev)

        # Step 2d: Calculate max error against original samples X
        max_error = 0.0
        for x_j in X:
            x_prime_j = project_point_onto_curve(gamma_curr, x_j)
            dist = math.sqrt(sum((a - b) ** 2 for a, b in zip(x_prime_j, x_j)))
            if dist > max_error:
                max_error = dist

        # Step 2e: Termination check
        if max_error <= epsilon:
            return gamma_curr, i

        gamma_prev = gamma_curr

def evaluate_cubic_b_spline(control_points, u):
    """Evaluate a uniform cubic B-spline at parameter u [G]."""
    if len(control_points) < 4:
        return control_points[0]
    n = len(control_points) - 1
    u_clamped = max(0.0, min(u, n))
    idx = int(u_clamped)
    t = u_clamped - idx
    b0 = (1 - t)**3 / 6.0
    b1 = (3*t**3 - 6*t**2 + 4) / 6.0
    b2 = (-3*t**3 + 3*t**2 + 3*t + 1) / 6.0
    b3 = t**3 / 6.0
    p0 = control_points[idx]
    p1 = control_points[idx+1]
    p2 = control_points[idx+2]
    p3 = control_points[idx+3]
    return (b0*p0 + b1*p1 + b2*p2 + b3*p3)

def project_point_onto_curve(control_points, point):
    """Find closest point on cubic B-spline curve to given point [G]."""
    min_dist = float('inf')
    best_u = 0.0
    steps = 100
    for k in range(steps + 1):
        u = k / steps
        curve_pt = evaluate_cubic_b_spline(control_points, u)
        dist = math.sqrt(sum((a-b)**2 for a, b in zip(curve_pt, point)))
        if dist < min_dist:
            min_dist = dist
            best_u = u
    return evaluate_cubic_b_spline(control_points, best_u)

**Edge Cases and Pitfalls:**
- **Division by Zero:** If $m_i = 1$, the parameter calculation $\frac{j-1}{m_i-1}$ involves division by zero. A guard clause is required to terminate or handle cases where $n < 2^{i-1}$ [G].
- **Projection Cost:** Calculating the projection $x'_j$ of each original sample onto the curve can be computationally expensive if not optimized [G].
- **Convergence:** The iterative fitting step relies on the algorithm from [14]. The source states the method terminates when the error threshold is met, implying designed convergence [S1].

## Operating characteristics
- **Time Complexity:** Not given in the sources [G].
- **Memory Complexity:** Not given in the sources [G].
- **Performance:** For the data sets shown in the source, $k < 4$ with $\epsilon = 10^{-4}$ [S1].
- **Strengths:** Effectively reduces wriggles and oscillations compared to least-squares approximation, leading to cleaner tubular geometry and ambient occlusion [S1].
- **Limitations:** Requires the iterative fitting algorithm from [14] to be implemented correctly. The projection step can be costly [G].

## Background
This method was proposed in the context of visualizing streamlines and generating stream tubes for volume rendering, where visual artifacts from curve approximation can significantly impact the quality of ambient occlusion [S1]. It builds on Schönberg’s approximation properties and the iterative curve fitting algorithm described in [14] [S1].
