# Elongated Structure Camera Trajectory Generation

Also called: Elongated-structure trajectory generator, PCA-based Camera Path Generation, PCA-based multi-view trajectory generation, Principal Axis Camera Trajectory

## Overview
This method generates multi-view camera poses for elongated structures (e.g., walls, ancient city fortifications) from a 3D point cloud by fitting a principal axis via Principal Component Analysis (PCA), sampling stations along it, and validating positions against a density grid [S1, unofficial]. It replaces indoor room-centric hardcoded poses with a data-driven approach suitable for large-scale outdoor scenes [S1, unofficial]. Unlike [Orbit Camera Path Generation](7811-orbit-camera-path-generation.md) which assumes a central object, this method aligns the camera path with the dominant linear feature of the scene [S1, unofficial].

## How it works
**Inputs:**
- `xyz`: A tensor of shape $[N, 3]$ containing 3D point cloud coordinates in world space (Z-up convention assumed) [S1, unofficial].
- `config`: A configuration object containing parameters (see below) [S1, unofficial].

**Outputs:**
- A list of `CameraPose` objects, each containing:
  - `extrinsics`: A $4 \times 4$ world-to-camera transformation matrix [S1, unofficial].
  - `intrinsics`: A vector $[f_x, f_y, c_x, c_y]$ [S1, unofficial].
  - `position`: The camera center $(c_x, c_y, c_z)$ in world space [S1, unofficial].
  - `target`: The look-at target point in world space [S1, unofficial].
  - `pitch_deg`: The pitch angle used [S1, unofficial].

**Data Structures:**
- **Density Grid**: A 2D tensor of shape $[grid\_nx, grid\_ny]$ initialized to zeros. It is populated by bucketizing point XY coordinates into bins and accumulating counts [S1, unofficial].
- **CameraPose**: A data class holding the pose components [S1, unofficial].

**Parameters:**
- `num_stations`: int, default 10. Number of camera stations along the principal axis [S1, unofficial].
- `distance`: float, default 15.0. Primary distance from the wall surface in metres [S1, unofficial].
- `far_distance`: float, default 0.0. Optional farther distance for wide-coverage views. If set, generates an additional set of views [S1, unofficial].
- `pitch_angles_deg`: Tuple[float], default $(-30.0, 0.0, 30.0)$. List of pitch angles in degrees (0 = horizontal, positive = camera looks downward) [S1, unofficial].
- `fov_y_deg`: float, default 60.0. Vertical field of view in degrees [S1, unofficial].
- `image_width`: int, default 640. Output image resolution in pixels [S1, unofficial].
- `image_height`: int, default 480. Output image resolution in pixels [S1, unofficial].
- `view_both_sides`: bool, default True. Whether to place cameras on both sides of the wall [S1, unofficial].
- `margin_factor`: float, default 1.1. Extra margin beyond actual point cloud bounds (1.0 = exact bounds, 1.1 = 10% extra) [S1, unofficial].

**Steps:**

1. **Compute OBB and Principal Axis**:
   - Extract XY coordinates from `xyz`.
   - Compute the centroid $\mathbf{c}_{xy}$ of the XY points.
   - Compute the covariance matrix of the XY points and perform Eigenvalue Decomposition. Sort eigenvalues in descending order to get the principal axis $\mathbf{a}_1$ (main elongation direction) and secondary axis $\mathbf{a}_2$ (perpendicular) [S1, unofficial].
   - Project all XY points onto the axes to find the actual projected min/max ranges: $\text{proj}_{min}$ and $\text{proj}_{max}$ [S1, unofficial].
   - Determine the global bounding box limits: $x_{min}, x_{max}, y_{min}, y_{max}, z_{min}, z_{max}$ [S1, unofficial].
   - Compute $z_{centre} = (z_{min} + z_{max}) / 2.0$ [S1, unofficial].

2. **Compute Intrinsics**:
   - Calculate focal length: $f = \frac{height}{2.0 \cdot \tan(\frac{fov_y}{2.0})}$, where $fov_y$ is in radians [S1, unofficial].
   - Set intrinsics vector: $[f, f, \frac{width}{2.0}, \frac{height}{2.0}]$ [S1, unofficial].

3. **Sample Stations**:
   - Calculate extent bounds: $extent_{min} = \text{proj}_{min}[0] \cdot margin\_factor$, $extent_{max} = \text{proj}_{max}[0] \cdot margin\_factor$ [S1, unofficial].
   - For each station index $i \in [0, num\_stations - 1]$:
     - Compute parameter $t = extent_{min} + (extent_{max} - extent_{min}) \cdot \frac{i}{\max(num\_stations - 1, 1)}$ [S1, unofficial].
     - Compute position on axis: $\mathbf{p}_{wall} = \mathbf{c}_{xy} + t \cdot \mathbf{a}_1$ [S1, unofficial].
     - Clamp $\mathbf{p}_{wall}$ to the actual point cloud XY bounds $[x_{min}, x_{max}]$ and $[y_{min}, y_{max}]$ to get $(sx, sy)$ [S1, unofficial].
     - Store $(sx, sy)$ as a station [S1, unofficial].

4. **Build Density Grid**:
   - Determine grid resolution $grid\_res = 5.0$ metres/bin [S1, unofficial].
   - Calculate padding: $grid\_pad = max\_dist + 2.0 \cdot grid\_res$, where $max\_dist = \max(distance, far\_distance)$ if $far\_distance > 0$ else $distance$ [S1, unofficial].
   - Calculate grid dimensions: $grid\_nx = \max(3, \lceil \frac{x_{max} - x_{min} + 2 \cdot grid\_pad}{grid\_res} \rceil)$, $grid\_ny = \max(3, \lceil \frac{y_{max} - y_{min} + 2 \cdot grid\_pad}{grid\_res} \rceil)$ [S1, unofficial].
   - Create bin edges $x\_bins$ and $y\_bins$ spanning from $x_{min} - grid\_pad$ to $x_{min} - grid\_pad + grid\_nx \cdot grid\_res$ (and similarly for Y) [S1, unofficial].
   - Bucketize point XY coordinates into grid indices $(x\_idx, y\_idx)$ [S1, unofficial].
   - Accumulate counts into the `density` grid using `index_put_` with accumulation [S1, unofficial].

5. **Generate Poses**:
   - Define distances: $distances = [distance]$. If $far\_distance > 0$ and $far\_distance \neq distance$, append $far\_distance$ [S1, unofficial].
   - Define sides: $sides = [1.0, -1.0]$ if $view\_both\_sides$ is True, else $[1.0]$ [S1, unofficial].
   - For each $dist$ in $distances$:
     - For each $side\_sign$ in $sides$:
       - For each $(sx, sy)$ in stations:
         - Compute camera position:
           - $cam\_x = sx + perp\_axis[0] \cdot dist \cdot side\_sign$
           - $cam\_y = sy + perp\_axis[1] \cdot dist \cdot side\_sign$
           - $cam\_z = z_{centre}$ [S1, unofficial].
         - **Validation**: Check if any points exist within radius $r = \max(15.0, dist \cdot 0.5)$ metres of $(cam\_x, cam\_y)$ using the density grid. If not, skip this pose [S1, unofficial].
         - For each $pitch\_deg$ in $pitch\_angles\_deg$:
           - Convert $pitch\_deg$ to radians: $pitch\_rad$ [S1, unofficial].
           - Compute target Z: $target\_z = cam\_z - \tan(pitch\_rad) \cdot dist$ [S1, unofficial].
           - Target X/Y are $(cam\_x, cam\_y)$ (looking straight down the Z-axis relative to the camera's local frame, but the pitch adjusts the Z component of the target in world space) [S1, unofficial]. *Note: The source code implies the target is directly "in front" at distance dist, but the pitch modifies the Z coordinate of the target to achieve the angle.* Specifically, the target vector is $(0, 0, -dist)$ in camera space, which maps to world space. The source code calculates `target_z` explicitly. The target position is $(cam\_x, cam\_y, target\_z)$ [S1, unofficial].
           - Construct the camera-to-world rotation matrix $R_{c2w}$ using `_look_at_cv(campos, target)` [S1, unofficial].
           - Construct the world-to-camera extrinsics matrix:
             - $R_{w2c} = R_{c2w}^T$
             - $t = -R_{w2c} \cdot \mathbf{c}_{am}$
             - $extr[:3, :3] = R_{w2c}$, $extr[:3, 3] = t$ [S1, unofficial].
           - Create `CameraPose` with `extrinsics`, `intrinsics`, `position`, `target`, and `pitch_deg` [S1, unofficial].

**Pseudocode:**

```python
import math
import torch

def generate_trajectory(xyz: torch.Tensor, config: dict) -> list:
    """
    Generate camera poses for elongated structures.
    xyz: [N, 3] tensor
    config: dict with keys: num_stations, distance, far_distance, 
            pitch_angles_deg, fov_y_deg, image_width, image_height, 
            view_both_sides, margin_factor
    """
    # 1. Compute OBB and Principal Axis
    xy = xyz[:, :2]
    centre_xy = xy.mean(dim=0)
    
    # Covariance and PCA
    cov = torch.cov(xy.T)
    eigenvalues, eigenvectors = torch.linalg.eigh(cov)
    # Sort descending
    eigenvalues = eigenvalues.flip(0)
    eigenvectors = eigenvectors.flip(1)
    
    axes = eigenvectors.T  # [2, 2], rows are axes
    main_axis = axes[0]
    perp_axis = axes[1]
    
    # Ensure consistent orientation
    if perp_axis[0] < 0:
        perp_axis = -perp_axis
        main_axis = -main_axis
        
    # Projected ranges
    proj = xy @ axes.T
    proj_min = proj.min(dim=0).values
    proj_max = proj.max(dim=0).values
    
    # Global bounds
    x_min, x_max = xyz[:, 0].min(), xyz[:, 0].max()
    y_min, y_max = xyz[:, 1].min(), xyz[:, 1].max()
    z_min, z_max = xyz[:, 2].min(), xyz[:, 2].max()
    z_centre = (z_min + z_max) / 2.0
    
    # 2. Intrinsics
    fov_y = math.radians(config['fov_y_deg'])
    focal = config['image_height'] / (2.0 * math.tan(fov_y / 2.0))
    intrinsics = torch.tensor([focal, focal, config['image_width']/2.0, config['image_height']/2.0])
    
    # 3. Sample Stations
    margin = config['margin_factor']
    extent_min = float(proj_min[0]) * margin
    extent_max = float(proj_max[0]) * margin
    
    stations_xy = []
    num_stations = config['num_stations']
    for i in range(num_stations):
        t = extent_min + (extent_max - extent_min) * i / max(num_stations - 1, 1)
        on_wall = centre_xy + t * main_axis
        sx = float(torch.clamp(on_wall[0], x_min, x_max))
        sy = float(torch.clamp(on_wall[1], y_min, y_max))
        stations_xy.append((sx, sy))
        
    # 4. Build Density Grid
    distances = [config['distance']]
    if config['far_distance'] > 0 and config['far_distance'] != config['distance']:
        distances.append(config['far_distance'])
    max_dist = max(distances)
    
    grid_res = 5.0
    grid_pad = max_dist + 2.0 * grid_res
    grid_nx = max(3, int((x_max - x_min + 2 * grid_pad) / grid_res))
    grid_ny = max(3, int((y_max - y_min + 2 * grid_pad) / grid_res))
    
    x_bins = torch.linspace(x_min - grid_pad, x_min - grid_pad + grid_nx * grid_res, grid_nx + 1)
    y_bins = torch.linspace(y_min - grid_pad, y_min - grid_pad + grid_ny * grid_res, grid_ny + 1)
    
    x_idx = torch.bucketize(xyz[:, 0], x_bins) - 1
    y_idx = torch.bucketize(xyz[:, 1], y_bins) - 1
    valid = (x_idx >= 0) & (x_idx < grid_nx) & (y_idx >= 0) & (y_idx < grid_ny)
    x_idx, y_idx = x_idx[valid], y_idx[valid]
    
    density = torch.zeros(grid_nx, grid_ny)
    density.index_put_((x_idx, y_idx), torch.ones(x_idx.shape[0]), accumulate=True)
    
    # Helper to check density
    def has_points_near(cx, cy, radius):
        # Find grid cell indices
        gx = int((cx - (x_min - grid_pad)) / grid_res)
        gy = int((cy - (y_min - grid_pad)) / grid_res)
        # Check neighbors within radius
        # Simplified: check if any point in the grid within radius exists
        # For implementation, one would iterate over grid cells within radius
        # Here we assume a simplified check or pre-computed neighbor lookup
        # Since we don't have the exact neighbor lookup code, we mark this as [G]
        # In the source, it likely checks the density grid values in a window
        return True # Placeholder for actual density check logic [G]

    # 5. Generate Poses
    poses = []
    sides = [1.0, -1.0] if config['view_both_sides'] else [1.0]
    
    for dist in distances:
        for side_sign in sides:
            for sx, sy in stations_xy:
                cam_x = sx + float(perp_axis[0]) * dist * side_sign
                cam_y = sy + float(perp_axis[1]) * dist * side_sign
                cam_z = float(z_centre)
                
                radius = max(15.0, dist * 0.5)
                if not has_points_near(cam_x, cam_y, radius):
                    continue
                    
                for pitch_deg in config['pitch_angles_deg']:
                    pitch_rad = math.radians(pitch_deg)
                    target_z = cam_z - math.tan(pitch_rad) * dist
                    target = torch.tensor([cam_x, cam_y, target_z])
                    campos = torch.tensor([cam_x, cam_y, cam_z])
                    
                    extrinsics = _make_extrinsics(campos, target)
                    poses.append({
                        'extrinsics': extrinsics,
                        'intrinsics': intrinsics,
                        'position': (cam_x, cam_y, cam_z),
                        'target': (float(target[0]), float(target[1]), float(target[2])),
                        'pitch_deg': pitch_deg
                    })
    return poses

def _make_extrinsics(campos, target):
    forward = target - campos
    forward = forward / (forward.norm() + 1e-12)
    up = torch.tensor([0.0, 0.0, 1.0])
    
    cos_angle = torch.abs(torch.dot(forward, up))
    if cos_angle > 0.999:
        ref_axis = torch.tensor([1.0, 0.0, 0.0])
    else:
        ref_axis = up
        
    right = torch.linalg.cross(ref_axis, forward)
    right = right / (right.norm() + 1e-12)
    up_corrected = torch.linalg.cross(forward, right)
    up_corrected = up_corrected / (up_corrected.norm() + 1e-12)
    
    R_c2w = torch.stack([right, up_corrected, forward], dim=1)
    R_w2c = R_c2w.T
    extr = torch.eye(4)
    extr[:3, :3] = R_w2c
    extr[:3, 3] = -(R_w2c @ campos)
    return extr
```

**Edge Cases and Pitfalls:**
- **Singularity**: When the forward vector is nearly parallel to the world up vector (e.g., overhead cameras looking straight down), the cross product for the right vector vanishes. This is handled by checking if $|\cos(\theta)| > 0.999$. If true, the reference axis is switched to world X $[1, 0, 0]$ to compute the right and up vectors via cross products [S1, unofficial].
- **Division by Zero**: When `num_stations` is 1, the denominator in station interpolation becomes 0. This is handled by using $\max(num\_stations - 1, 1)$ in the denominator [S1, unofficial].

## Operating characteristics
- **Time Complexity**: Dominated by PCA ($O(N)$ for covariance, constant for 2D) and grid bucketization ($O(N)$). Pose generation is $O(num\_stations \cdot num\_distances \cdot num\_sides \cdot num\_pitches)$.
- **Memory Complexity**: $O(N)$ for the point cloud and $O(grid\_nx \cdot grid\_ny)$ for the density grid.
- **Strengths**: Adapts to the geometry of elongated structures, ensuring cameras are placed parallel to the feature of interest. The density validation prevents placing cameras in empty space.
- **Limitations**: Assumes the structure is roughly linear and extends in the XY plane. Not suitable for spherical or compact objects.
- **When to use**: Large-scale outdoor scenes with elongated features like walls, roads, or rivers.
- **When not to use**: Indoor scenes with room-centric layouts or objects with no dominant linear axis.
