# Ray Marching with Secant Refinement


## Overview
A procedure to detect surface points along rays by evaluating a neural decoder at proposal points, identifying sign changes in occupancy logits, and refining the depth using a root-finding method [S1, unofficial]. It sets itself apart from its siblings by combining coarse uniform sampling with a specific sign-change detection logic that identifies negative-to-positive transitions, followed by the Secant Method for Surface Depth Refinement to pinpoint the zero-crossing [S1, unofficial]. It builds on [Secant Method for Surface Depth Refinement](996-secant-method-for-surface-depth-refinement.md).

## How it works
**Inputs:**
- `ray0`: Origin points, shape $(B, N, 1, 3)$.
- `ray_direction`: Direction vectors, shape $(B, N, 1, 3)$.
- `c`: Latent codes or context, shape $(B, N, D_c)$.
- `decoder`: Neural network function evaluating occupancy.
- `depth_range`: Tuple $(d_{min}, d_{max})$ defining the search interval.
- `tau`: Probability threshold for occupancy.
- `n_steps`: Tuple $(n_{min}, n_{max})$ for sampling the number of steps.
- `max_points`: Integer limit for GPU memory management.
- `check_cube_intersection`: Boolean flag.

**Outputs:**
- `pt_pred`: Final 3D surface points, shape $(B, N, 1, 3)$.
- `d_pred`: Refined depth values, shape $(B, N, 1, 1)$.
- `mask`: Boolean mask indicating valid detections, shape $(B, N, 1, 1)$.

**Data Structures:**
- `d_proposal`: Tensor of shape $(B, N, n_{steps}, 1)$ containing linearly spaced depth values.
- `val`: Tensor of shape $(B, N, n_{steps}, 1)$ containing the signed distance/occupancy logit minus threshold.
- `sign_matrix`: Tensor of shape $(B, N, n_{steps})$ indicating sign changes.
- `cost_matrix`: Tensor of shape $(B, N, n_{steps})$ used for finding the first sign change.

**Steps:**

1.  **Threshold Conversion:** Convert the probability threshold $\tau$ to a logit threshold:
    $$ logit\_tau = \text{get\_logits\_from\_prob}(\tau) $$
    [G] `get_logits_from_prob` is the inverse sigmoid function: $\log(\frac{\tau}{1-\tau})$.

2.  **Step Sampling:** Sample the number of steps $n_{steps}$ uniformly from the integer range $[n_{steps}[0], n_{steps}[1]]$.

3.  **Proposal Generation:** Create linearly spaced depth proposals $d_{proposal}$ from $depth\_range[0]$ to $depth\_range[1]$ with $n_{steps}$ points. Shape: $(B, N, n_{steps}, 1)$.

4.  **Cube Intersection (Optional):** If `check_cube_intersection` is true, compute intersection with the unit cube and replace $d_{proposal}$ values inside the cube with cube-intersection depths.

5.  **Point Computation:** Compute 3D proposal points:
    $$ p_{proposal} = ray0 + ray\_direction \cdot d_{proposal} $$

6.  **Decoder Evaluation:** Evaluate the decoder at all proposal points in parallel. To manage GPU memory, split the evaluation into chunks of size `max_points` / `batch_size`. Compute:
    $$ val = decoder(p, c, only\_occupancy=True) - logit\_tau $$
    Shape of `val`: $(B, N, n_{steps}, 1)$.

7.  **Initial Occupancy Mask:** Create a mask for rays where the first point is not occupied:
    $$ mask\_0\_not\_occupied = val[:, :, 0] < 0 $$

8.  **Sign Change Detection:**
    - Compute the sign change matrix:
      $$ sign\_matrix = [\text{sign}(val[:, :, :-1] \cdot val[:, :, 1:]), 1] $$
      Note: The last element is padded with 1 to maintain dimensions.
    - Compute the cost matrix to prioritize earlier sign changes:
      $$ cost\_matrix = sign\_matrix \cdot [n_{steps}, n_{steps}-1, ..., 1] $$
      The weights are a decreasing sequence from $n_{steps}$ to 1.

9.  **First Sign Change Index:** Find the first sign change index:
    $$ (values, indices) = \text{argmin}(cost\_matrix) $$
    Identify valid sign changes:
    $$ mask\_sign\_change = values < 0 $$

10. **Transition Verification:** Identify negative-to-positive transitions:
    $$ mask\_neg\_to\_pos = val[batch\_indices, point\_indices, indices] < 0 $$
    [G] `batch_indices` and `point_indices` are the batch and ray indices corresponding to the argmin result. This ensures the function crosses from negative (outside) to positive (inside).

11. **Combined Mask:** Combine masks for valid depth detection:
    $$ mask = mask\_sign\_change \land mask\_neg\_to\_pos \land mask\_0\_not\_occupied $$

12. **Bracket Extraction:** Extract bracketing depths and function values for valid rays:
    - $d_{low}, f_{low}$ at `indices`
    - $d_{high}, f_{high}$ at `indices + 1` (clamped to $n_{steps}-1$)

13. **Refinement:** Apply the Secant Method for Surface Depth Refinement on the masked rays using $(d_{low}, f_{low})$ and $(d_{high}, f_{high})$ to get $d_{pred}$.

14. **Final Point Computation:** Compute final 3D points:
    $$ pt_{pred}[mask] = ray0_{masked} + d_{pred} \cdot ray\_direction_{masked} $$

    # 3. Proposal Generation
    depths = torch.linspace(depth_range[0], depth_range[1], n_steps, device=device)
    # Shape: (n_steps,) -> (B, N, n_steps, 1)

    # Expand ray_direction for broadcasting
    ray_dir_exp = ray_direction.unsqueeze(2) # (B, N, 1, 3)
    d_proposal_exp = d_proposal.unsqueeze(3) # (B, N, n_steps, 1) -> (B, N, n_steps, 1)
    
    # p_proposal: (B, N, n_steps, 3)
    p_proposal = ray0.unsqueeze(2) + ray_dir_exp * d_proposal_exp
    
    # 6. Decoder Evaluation

        # Evaluate decoder

        # Reshape back

        # Subtract threshold

        val_chunks.append(val_chunk)

    sign_product = torch.sign(product) # (B, N, n_steps-1)
    
    # Pad with 1 at the end

    sign_matrix = torch.cat([sign_product, ones], dim=2) # (B, N, n_steps)
    
    # Cost matrix weights

    values, indices = torch.min(cost_matrix, dim=2) # values: (B, N), indices: (B, N)

    mask_neg_to_pos = f_low < 0
    
    # 11. Combined Mask

    # 12. Bracket Extraction

    d_high_indices = (indices + 1).clamp(max=n_steps - 1)

**Parameters:**
- `max_points`: Integer, maximum number of points loaded to GPU memory per batch to prevent OOM. Typical value: 3,500,000 [S1, unofficial].
- `n_steps`: Tuple of integers defining the range for sampling the number of evaluation steps. Typical value: [128, 129] [S1, unofficial].
- `depth_range`: Tuple of floats defining the range of possible depth values. Typical value: [0.0, 2.4] [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Precision:** The sign change detection relies on the product of adjacent values. If values are very close to zero, floating-point precision issues may cause false negatives or positives.
- **Boundaries:** The `d_high` index is clamped to $n_{steps}-1$ to prevent out-of-bounds access.
- **Degenerate Input:** If no sign change is detected, the mask will be false, and no point will be returned for that ray.

## Subtopics

### [Differentiable Depth Function Forward/Backward Pass](1047-differentiable-depth-function-forward-backward-pass.md)
A PyTorch Autograd Function that wraps the ray marching process, allowing gradients to flow through the depth prediction to the decoder parameters and latent code. It sets itself apart by enabling end-to-end training of the neural decoder via backpropagation through the ray marching steps. Choose it when training a neural implicit surface representation.

## Operating characteristics
- **Time Complexity:** Dominated by the decoder evaluation at $n_{steps}$ points per ray. $O(B \cdot N \cdot n_{steps})$.
- **Memory Complexity:** $O(B \cdot N \cdot n_{steps})$ for storing proposal points and values. Managed by chunking with `max_points`.
- **Measured Performance:** Not given in the sources.
- **Scaling:** Scales linearly with the number of rays and steps. Memory usage is controlled by `max_points`.
- **Strengths:** Efficient detection of surface crossings using sign changes; refinement provides high accuracy.
- **Limitations:** Requires a continuous occupancy function; sensitive to the choice of $n_{steps}$ and depth range.
- **When to use:** When extracting surfaces from neural implicit representations where the decoder provides occupancy logits.
- **When not:** When the surface is not defined by a zero-crossing of a scalar field.

## Background
Originated in the context of differentiable volumetric rendering for 3D shape reconstruction. The method is part of the `differentiable_volumetric_rendering` repository by autonomousvision [S1, unofficial]. It is used in generating meshes from occupancy processes by detecting surface points along rays.
