# Compute Shader Kernel

Also called: CSMain

## Overview
A Compute Shader Kernel is a GPU compute shader entry point that executes a user-defined function in parallel across a grid of threads [S1, unofficial]. It serves as a basic example of GPU parallel execution by writing a gradient texture based on thread IDs [S1, unofficial].

## How it works
**Inputs and Outputs:**
The kernel receives a dispatch grid defined by the host application [S1, unofficial]. It writes results to a writable 2D texture [S1, unofficial].

**Data Structures:**
*   **Output Buffer:** `RWTexture2D<float4> Result`, a writable 2D texture of 4-component floats [S1, unofficial].
*   **Thread ID:** The global thread index within the dispatch grid, accessed via hardware/runtime built-in variables [S1, unofficial].

**Parameters:**
*   **Resolution:** A float variable used to normalize thread IDs to the $[0, 1]$ range [S1, unofficial].
*   **Thread Group Size:** $8 \times 8 \times 1$ threads per group [S1, unofficial].

**Steps:**
1.  Retrieve the global thread ID `id` [S1, unofficial].
2.  Calculate normalized x coordinate: $x = \frac{id.x}{\text{Resolution}}$ [S1, unofficial].
3.  Calculate normalized y coordinate: $y = \frac{id.y}{\text{Resolution}}$ [S1, unofficial].
4.  Write the result to the texture at `id.xy` with RGB values $(x, y, 0.0)$ and alpha $0.0$ [S1, unofficial].

**Pseudocode:**
```python
def compute_kernel(thread_id, resolution, output_texture):
    id_x = thread_id.x
    id_y = thread_id.y
    x = id_x / resolution
    y = id_y / resolution
    color = (x, y, 0.0, 0.0)
    output_texture[id_y, id_x] = color
```
