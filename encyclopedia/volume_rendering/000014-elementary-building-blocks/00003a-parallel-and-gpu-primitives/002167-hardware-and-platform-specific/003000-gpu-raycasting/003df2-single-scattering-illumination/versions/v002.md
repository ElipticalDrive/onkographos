# Single Scattering Illumination

Also called: Direct Single Scattering (DSS), Indirect Single Scattering (ISS), Single Scattering Illumination Model

## Overview
Single Scattering Illumination is a volumetric lighting model that computes the radiance contribution of light undergoing exactly one scattering event within a participating medium [S1, unofficial]. It distinguishes between light scattered along the view ray (Direct Single Scattering, DSS) and light scattered along illumination rays from scene points (Indirect Single Scattering, ISS) [S1, unofficial]. Unlike basic volume rendering that often ignores volumetric shadows, this method provides an analytic formulation for both contributions, including occlusion handling via shadow volumes, enabling real-time hardware rendering [S1, unofficial].

## How it works
The method computes the total radiance observed along a view ray by summing direct single scattering, attenuated surface radiance, ambient/multiple scattering, and object indirect single scattering [S1, unofficial].

### Inputs and Outputs
**Inputs:**
- View ray direction $\vec{u}$ and origin [S1, unofficial].
- Scene geometry for surface radiance $L(P)$ and occlusion checks [S1, unofficial].
- Light source parameters: position, intensity $I_S$, solid angle $\Omega$, and type (point/directional) [S1, unofficial][S2].
- Medium properties: extinction coefficient $k_t$ and phase function $p(\cdot)$ [S1, unofficial].
- Surface properties: Phong exponent $n$ and specular coefficient $k_s$ [S1, unofficial].
- Precomputed 2D table for $\Gamma(\lambda, \gamma)$ [S1, unofficial].

**Outputs:**
- Total radiance $L_{\vec{u}\vec{P}}$ for each sample point $P$ along the view ray [S1, unofficial].

### Data Structures
1.  **Gamma Table**: A 2D lookup table storing values of $\Gamma(\lambda, \gamma)$ [S1, unofficial].
    -   Dimensions: Determined by the discretization of $\lambda$ (distance parameter) and $\gamma$ (angular parameter) [S1, unofficial].
    -   Content: Numerical integration results of the phase function weighted by attenuation [S1, unofficial].
    -   Access: Bilinear interpolation is used for continuous parameters [G].

### Formulas and Definitions

**1. Total Radiance Equation**
The radiance $L_{\vec{u}\vec{P}}$ observed along a view ray from point $P$ is:
$$ L_{\vec{u}\vec{P}} = L_{dss}(\vec{u}\vec{P}) + e^{-k_tOP} L(P) + L_a e^{-k_tOP} + L_{oiss}(\vec{u}\vec{P}) \quad (1) $$
Where:
-   $L_{dss}$: Direct single scattering contribution [S1, unofficial].
-   $OP$: Distance from the camera/view origin to point $P$ [S1, unofficial].
-   $L(P)$: Radiance of point $P$ (surface or volume) [S1, unofficial].
-   $L_a$: Constant radiance from emission or multiple scattering [S1, unofficial].
-   $L_{oiss}$: Object indirect single scattering [S1, unofficial].

**2. Point Radiance Equation**
The radiance $L(P)$ at a point $P$ is composed of:
$$ L(P) = L_{iss}(P) + e^{-k_t S^P} L_d(P) + L_a e^{-k_t S^P} \quad (2) $$
Where:
-   $L_{iss}(P)$: Indirect single scattering received at $P$ [S1, unofficial].
-   $S^P$: Distance along the illumination ray from the light source to $P$ [S1, unofficial].
-   $L_d(P)$: Direct illumination at $P$ (e.g., Phong model) [S1, unofficial].

**3. The Gamma Function**
A 2D function $\Gamma$ depending only on the phase function shape:
$$ \Gamma(\lambda, \gamma) = \int_0^\gamma p\left(\alpha + \frac{\pi}{2}\right) e^{-k_t \lambda \frac{\sin(\alpha) + 1}{\cos(\alpha)}} d\alpha \quad (3) $$
Where:
-   $\lambda$: Distance parameter [S1, unofficial].
-   $\gamma$: Angular parameter [S1, unofficial].
-   $p$: Phase function [S1, unofficial].
-   $\alpha$: Integration variable [S1, unofficial].

**4. Direct Single Scattering (DSS) - Totally Lit Ray**
For a view ray with no occlusions:
$$ L_{dss}(d, \phi) = \frac{k_t^2 \Omega S}{4\pi} \frac{e^{-k_t t}}{k_t h} \left[ \Gamma\left(k_t h, \text{atan}\left(\frac{d-t}{h}\right)\right) - \Gamma\left(k_t h, \text{atan}\left(\frac{-t}{h}\right)\right) \right] \quad (4) $$
Where:
-   $d$: Distance along the view ray [S1, unofficial].
-   $t$: Distance to the light source [S1, unofficial].
-   $h$: Height parameter (geometry of light/view relative to medium) [S1, unofficial].
-   $S$: Source size/area factor [S1, unofficial].
-   $\Omega$: Solid angle of the light source [S1, unofficial].

**5. Indirect Single Scattering (ISS)**
Using the single scattering Phong model:
$$ L_{iss}(P) = \frac{k_t^2 \Omega I_S}{4\pi} \frac{k_s}{k_t l} \Gamma_P(k_t l) \quad (5) $$
Where:
-   $I_S$: Source intensity [S1, unofficial].
-   $k_s$: Scattering coefficient [S1, unofficial].
-   $l$: Distance parameter [S1, unofficial].
-   $\Gamma_P$: Precomputed function for ISS [S1, unofficial].

The function $\Gamma_P$ is defined as:
$$ \Gamma_P(\phi', \lambda) = \int_0^{2\pi} \int_0^\pi \int_{\phi' - \frac{\pi}{2}}^{\frac{\pi}{2}} p\left(\alpha + \frac{\pi}{2}\right) e^{-\lambda \frac{\cos(\alpha - \phi') + 1}{\cos(\alpha)}} \cos^n \theta(\phi) d\alpha \quad (6) $$
Where:
-   $\phi'$: Angle parameter [S1, unofficial].
-   $\lambda$: Distance parameter [S1, unofficial].
-   $n$: Phong exponent [S1, unofficial].
-   $\theta$: Angle related to the Phong model [S1, unofficial].

**6. Direct Single Scattering (DSS) - With Occlusions**
Using the Laplace formula to handle occluders:
$$ L_{dss}(d, \phi) = \frac{k_t^2 \Omega I_S}{4\pi} e^{-k_t t} \left[ \Gamma(k_t h, \gamma_P) - \Gamma(k_t h, \gamma_B) + \Gamma(k_t h, \gamma_A) - \Gamma(k_t h, \gamma_O) \right] \quad (7) $$
Where:
-   $\gamma_P, \gamma_B, \gamma_A, \gamma_O$: Angular limits defined by the geometry of occluders relative to the view ray and light source [S1, unofficial].

### Parameters
-   **Ambience**: Slider controlling the constant radiance $L_a$ contribution [S2].
-   **Specularity**: Slider controlling the glossiness (Phong exponent $n$) of surfaces [S2].
-   **Light Source**: Can be point or directional [S2].
-   **Head Light**: Option that parents the light source to the camera position; transforming it causes it to pop back to the camera position [S2].

    return total_radiance

### Edge Cases and Pitfalls
-   **Occlusion Complexity**: Equation (7) requires accurate calculation of angular limits $\gamma_P, \gamma_B, \gamma_A, \gamma_O$ for arbitrary occluders [S1, unofficial].
-   **Precomputation**: The $\Gamma$ and $\Gamma_P$ functions are purely numerical and depend on the phase function; they must be precomputed and stored in tables [S1, unofficial].
-   **Performance**: Computing $\Gamma_P$ involves a triple integral (Equation 6), which is expensive and typically precomputed or approximated [S1, unofficial].
-   **Head Light**: When the "Head Light" option is enabled, the light source position is parented to the camera; transforming it causes it to pop back to the camera position [S2].

## Operating characteristics
-   **Time Complexity**: The core DSS computation is $O(1)$ per sample if $\Gamma$ is precomputed and looked up [S1, unofficial]. ISS computation is more expensive due to the triple integral in $\Gamma_P$, often requiring precomputation or approximation [S1, unofficial].
-   **Memory Complexity**: Requires storage for the $\Gamma$ 2D table and potentially the $\Gamma_P$ table [S1, unofficial].
-   **Strengths**: Provides physically plausible single scattering effects including volumetric shadows and indirect lighting contributions [S1, unofficial].
-   **Limitations**: Single scattering approximation breaks down in highly participating media where multiple scattering is significant [S1, unofficial].
-   **When to use**: Suitable for real-time rendering of participating media where single scattering dominates (e.g., fog, smoke, thin clouds) and volumetric shadows are desired [S1, unofficial].
-   **When not to use**: Not suitable for dense media where multiple scattering is significant, or when full global illumination is required [S1, unofficial].

## Background
The Single Scattering Illumination model was introduced in the paper "Single Scattering Effects for Computer Games" [S1, unofficial]. The work focuses on real-time hardware rendering of volumetric lighting effects, specifically introducing the concept of indirect single scattering (ISS) alongside direct single scattering (DSS) [S1, unofficial]. The method uses an angular formulation of the radiative transfer equation and precomputed 2D tables to enable efficient computation [S1, unofficial]. The model is applied in the ray casting implementation of the VStudio framework for interactive volume visualization [S2].
