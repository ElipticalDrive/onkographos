# Single-Event Upset (SEU) Fault Injection in 3DGS

Also called: Bit-flip injection, Single-bit upset injection

## Overview
Single-Event Upset (SEU) fault injection in 3D Gaussian Splatting (3DGS) simulates transient bit flips in GPU memory to measure rendering corruption from hardware errors [S1, unofficial]. It differs from neural network weight perturbation because 3DGS primitives are spatially localized and redundant, whereas network weights are shared globally; this method quantifies whether such redundancy provides robustness or concentrates risk into rare catastrophic failures [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A trained 3DGS model with $N$ primitives stored in GPU memory, a set of $K$ held-out camera views, and a fault site tuple $(field, primitive, component, bit)$ [S1, unofficial].
*   **Output:** Corruption metrics (peak pixel error, LPIPS, SSIM, PSNR, non-finite flag, corruption footprint) for the rendered views [S1, unofficial].

**Data Structures**
A trained 3DGS model consists of $N$ primitives [S1, unofficial]. Primitive $i$ stores six fields in memory [S1, unofficial]:
1.  Mean $\mu_i \in \mathbb{R}^3$
2.  Logarithmic scale $s_i \in \mathbb{R}^3$ (renderer applies $\exp$) [S1, unofficial]
3.  Quaternion $q_i \in \mathbb{R}^4$ (normalized at render time) [S1, unofficial]
4.  Opacity logit $o_i \in \mathbb{R}$ (renderer applies logistic $\sigma$) [S1, unofficial]
5.  DC color term $c_{0i} \in \mathbb{R}^3$
6.  Higher-order spherical harmonic coefficients $c_{Ni} \in \mathbb{R}^{((\ell+1)^2-1) \times 3}$ [S1, unofficial]

**IEEE-754 Bit Layouts**
The bit positions determine the impact of a flip [S1, unofficial]:
*   **fp32:** Sign is bit 31, exponent is bits 23–30, mantissa is bits 0–22.
*   **fp16:** 5-bit exponent, 10-bit mantissa.
*   **bf16:** 8-bit exponent (from fp32), 7-bit mantissa.

**Algorithm Steps**
1.  **Reinterpret:** Cast the stored floating-point value at the fault site to an unsigned integer of the matching width [S1, unofficial].
2.  **Flip:** XOR the integer with a mask having a single bit set at the target position [S1, unofficial].
3.  **Restore:** Reinterpret the modified integer back to the original floating-point format [S1, unofficial].
4.  **Render:** Render the $K$ held-out views using the corrupted parameter [S1, unofficial].
5.  **Measure:** Compute metrics on the GPU [S1, unofficial].
6.  **Cleanup:** Restore the original value to the working copy [S1, unofficial].

**Pseudocode**
```python
import struct
import numpy as np

def flip_bit(value: float, bit_index: int, width_bits: int) -> float:
    # Reinterpret float as unsigned integer of matching width
    if width_bits == 32:
        bits = struct.unpack('I', struct.pack('f', value))[0]
    elif width_bits == 16:
        bits = struct.unpack('H', struct.pack('e', value))[0]
    else:
        raise ValueError("Unsupported width")
        
    # Flip the bit using XOR
    bits ^= (1 << bit_index)
    
    # Reinterpret back to float
    if width_bits == 32:
        return struct.unpack('f', struct.pack('I', bits))[0]
    else:
        return struct.unpack('e', struct.pack('H', bits))[0]

def inject_seu(model_params, fault_site, cameras, renderer, clean_images):
    field_name, prim_idx, comp_idx, bit_idx = fault_site
    width_bits = 32 if model_params.dtype == 'fp32' else 16
    
    # 1. Get clean value
    clean_value = model_params[field_name][prim_idx][comp_idx]
    
    # 2. Inject fault
    corrupted_value = flip_bit(clean_value, bit_idx, width_bits)
    
    # 3. Write to working copy
    model_params[field_name][prim_idx][comp_idx] = corrupted_value
    
    # 4. Render K views in a single batched call
    corrupted_images = renderer(model_params, cameras)
    
    # 5. Compute metrics on GPU
    diff = corrupted_images - clean_images
    peak_error = np.max(np.abs(diff))
    footprint = np.mean(np.abs(diff) > (1.0 / 255.0))
    psnr = 10 * np.log10(1.0 / np.mean(diff**2))
    is_non_finite = np.any(np.isnan(corrupted_images)) or np.any(np.isinf(corrupted_images))
    
    # 6. Restore value
    model_params[field_name][prim_idx][comp_idx] = clean_value
    
    return {
        'peak_error': peak_error,
        'footprint': footprint,
        'psnr': psnr,
        'non_finite': is_non_finite
    }
```

**Parameters and Typical Values**
*   **Precision:** fp32 is the baseline; fp16 and bf16 are tested by casting clean parameters to the target format before injection [S1, unofficial].
*   **Views ($K$):** Multiple held-out views are averaged to compute the corruption footprint [S1, unofficial].
*   **Catastrophic Threshold:** An upset is catastrophic if the corruption footprint exceeds 1% of the frame or produces non-finite values [S1, unofficial].

**Edge Cases and Pitfalls**
*   **Exponent Overflow:** Flipping high exponent bits in fp32 can cause overflow to non-finite values [S1, unofficial].
*   **Scale Sign Flip:** For the scale field, the activation is $\phi = \exp$. A sign flip on a typical log scale $\theta \approx -3$ changes it to $+3$, multiplying the primitive size by $e^6 \approx 4 \times 10^2$ [S1, unofficial].
*   **Global Metrics:** Full-frame PSNR is a poor discriminator for single upsets in large scenes because a single corrupted primitive among hundreds of thousands barely moves the global average [S1, unofficial].

## Subtopics

### Perturbation Bound Analysis
Analyzes the mathematical impact of bit flips on specific fields [S1, unofficial]. For the scale field, the relative change is $|\Delta s|/s = |\Delta \theta|$, meaning a mantissa flip changes scale by a fixed relative amount $2^{b-p}$ independent of the exponent $e$ [S1, unofficial]. For a normal fp32 value $\theta = (-1)^\epsilon 2^e (1+m)$, flipping mantissa bit $b$ changes the value by $|\Delta \theta| = 2^{e+b-p}$ [S1, unofficial]. Flipping the sign bit gives $\Delta \theta = -2\theta$, and flipping exponent bit $j$ multiplies magnitude by $2^{\pm 2^j}$ [S1, unofficial].

## Operating characteristics
**Time and Memory Complexity**
*   **Time:** The parallel injection engine keeps the GPU busy with a stream of independent corrupted renders, saturating device throughput [S1, unofficial].
*   **Memory:** Clean parameters remain resident on the GPU; only one working copy is modified at a time [S1, unofficial].

**Measured Performance**
*   **Redundancy Scaling:** For a converged model of $N$ primitives, the typical (median) image error of one uniform-random single-bit upset scales as $\sigma^2(N) = \Theta(N^{-\alpha})$ for a scene-dependent exponent $\alpha > 0$ [S1, unofficial].
*   **Dose Budget:** Under $k$ independent uniform single-bit upsets, the expected squared image error is $E\|\Delta I\|^2 = k \sigma^2(N)$ [S1, unofficial]. The dose $k_\tau$ at which error exceeds threshold $\tau$ scales as $k_\tau = \Theta(N^\alpha \tau)$ [S1, unofficial].

**Strengths and Limitations**
*   **Strengths:** Directly measures hardware vulnerability; identifies critical bit positions (e.g., scale sign bit) [S1, unofficial].
*   **Limitations:** Full-frame PSNR is insensitive to local corruption; catastrophic upsets are rare but dominant in mean error [S1, unofficial].

**When to Use**
*   Use for evaluating robustness of 3DGS deployments against hardware errors [S1, unofficial].

## Background
Originated from the paper "Single-Event Upsets in 3D Gaussian Splatting Rendering: Bit-Level Criticality, Spatial Extent, and a Parallel Support Guard" [S1, unofficial]. It addresses the gap in understanding whether the redundancy of 3DGS primitives provides robustness against transient faults, contrasting with extensive prior work on neural network weight perturbation [S1, unofficial].
