# Tile-Based Alpha Compositing

Also called: Tsplat compositing

## Overview
Tile-Based Alpha Compositing is a rendering technique that blends multiple semi-transparent primitives (such as 2D Gaussians or splats) into a final image by processing them in depth order from nearest to farthest within disjoint tiles [S1, unofficial]. It is distinguished from back-to-front compositing by its tile-based parallelization, which allows independent processing of each tile without synchronization [G].

## How it works
**Inputs and Outputs:**
*   **Input:** A list of splats, each defined by a 2D center $(s_x, s_y)$, an inverse 2D covariance matrix $cov2d\_inv$, an opacity $\alpha_{splat}$, and a color $C_{splat}$ [S1, unofficial].
*   **Output:** A framebuffer containing accumulated color $C_{accum}$ and accumulated opacity $\alpha_{accum}$ for each pixel [S1, unofficial].

**Data Structures:**
*   **Framebuffer:** Parallel arrays or a 2D array of structs for $C_{accum}$ (RGB floats) and $\alpha_{accum}$ (float) [G]. Initialized to $(0, 0, 0)$ and $0$ respectively [G].
*   **Splat:** Struct containing:
    *   $s_x, s_y$: Float center coordinates in pixel space [S1, unofficial].
    *   $cov2d\_inv$: 2x2 inverse covariance matrix represented by elements $a, b, d$ where $cov2d\_inv = \begin{bmatrix} a & b \\ b & d \end{bmatrix}$ [S1, unofficial].
    *   $\alpha_{splat}$: Float opacity [S1, unofficial].
    *   $C_{splat}$: RGB color vector [S1, unofficial].

**Steps:**
1.  **Initialization:** Initialize the framebuffer's $C_{accum}$ to $(0, 0, 0)$ and $\alpha_{accum}$ to $0$ for all pixels [G].
2.  **Sorting:** Sort all splats by depth (distance from camera) in descending order (front-to-back) [G].
3.  **Tile Processing:** Divide the image into disjoint tiles [G]. For each tile:
4.  **Splat Rasterization:** For each splat overlapping the tile:
5.  **Bounding Box:** Compute the axis-aligned bounding box (AABB) of the splat's 2D Gaussian projection within the tile [G].
6.  **Pixel Loop:** Iterate over each pixel $(p_x, p_y)$ within the AABB:
7.  **Displacement:** Calculate $dx = p_x - s_x$ and $dy = p_y - s_y$ [S1, unofficial].
8.  **Optimization:** For a fixed row $p_y$, $dy$ is constant. Precompute coefficients for the quadratic form in $dx$ to optimize the inner loop [S1, unofficial].
9.  **Gaussian Evaluation:** Compute the power term:
    $$ power = -\frac{1}{2} (a \cdot dx^2 + 2b \cdot dx \cdot dy + d \cdot dy^2) $$
    where $a = cov2d\_inv.x\_axis.x$, $b = cov2d\_inv.x\_axis.y$, $d = cov2d\_inv.y\_axis.y$ [S1, unofficial].
10. **Alpha Calculation:** Compute the splat's alpha at this pixel:
    $$ \alpha = \alpha_{splat} \cdot \exp(power) $$
    [S1, unofficial].
11. **Clamping:** Clamp $\alpha$ to $[0, 1]$ [G].
12. **Compositing:** Update the framebuffer using front-to-back alpha blending:
    $$ T = 1 - \alpha_{accum} $$
    $$ contrib = T \cdot \alpha $$
    $$ C_{accum} += contrib \cdot C_{splat} $$
    $$ \alpha_{accum} += contrib $$
    [S1, unofficial].

**Pseudocode:**
```python
import math

def tile_based_alpha_compositing(splats, width, height, tile_size=16):
    # Initialize framebuffer [G]
    accum_color = [[(0.0, 0.0, 0.0) for _ in range(width)] for _ in range(height)]
    accum_alpha = [[0.0 for _ in range(width)] for _ in range(height)]
    
    # Sort splats front-to-back [G]
    sorted_splats = sorted(splats, key=lambda s: s.depth, reverse=True)
    
    # Process tiles [G]
    for ty in range(0, height, tile_size):
        for tx in range(0, width, tile_size):
            tile_end_y = min(ty + tile_size, height)
            tile_end_x = min(tx + tile_size, width)
            
            for splat in sorted_splats:
                # Compute bounding box from covariance [G]
                # Approximate 3-sigma bounds from inverse covariance eigenvalues
                trace = splat.cov2d_inv[0][0] + splat.cov2d_inv[1][1]
                det = splat.cov2d_inv[0][0] * splat.cov2d_inv[1][1] - splat.cov2d_inv[0][1] ** 2
                if det <= 0:
                    continue
                sqrt_disc = math.sqrt(trace * trace - 4 * det)
                lambda1 = (trace + sqrt_disc) / 2
                lambda2 = (trace - sqrt_disc) / 2
                radius = 3.0 * math.sqrt(1.0 / min(lambda1, lambda2))
                x_min, x_max = int(splat.sx - radius), int(splat.sx + radius)
                y_min, y_max = int(splat.sy - radius), int(splat.sy + radius)
                
                # Clip to tile bounds
                clip_x_min = max(tx, x_min)
                clip_x_max = min(tile_end_x, x_max)
                clip_y_min = max(ty, y_min)
                clip_y_max = min(tile_end_y, y_max)
                
                if clip_x_min >= clip_x_max or clip_y_min >= clip_y_max:
                    continue
                    
                a = splat.cov2d_inv[0][0]
                b = splat.cov2d_inv[0][1]
                d = splat.cov2d_inv[1][1]
                
                for py in range(clip_y_min, clip_y_max):
                    dy = py - splat.sy
                    term1 = d * dy * dy
                    term2 = 2.0 * b * dy
                    
                    for px in range(clip_x_min, clip_x_max):
                        # Skip if pixel is already fully opaque [G]
                        if accum_alpha[py][px] >= 1.0:
                            continue
                            
                        dx = px - splat.sx
                        power = -0.5 * (a * dx * dx + term2 * dx + term1)
                        alpha = splat.opacity * math.exp(power)
                        alpha = max(0.0, min(1.0, alpha))
                        
                        if alpha < 1e-6:
                            continue
                            
                        T = 1.0 - accum_alpha[py][px]
                        contrib = T * alpha
                        
                        r, g, b_val = accum_color[py][px]
                        cr, cg, cb = splat.color
                        accum_color[py][px] = (r + contrib * cr, g + contrib * cg, b_val + contrib * cb)
                        accum_alpha[py][px] += contrib
```

## Subtopics

### [Front-to-Back Alpha Compositing](4213-front-to-back-alpha-compositing.md)
Front-to-Back Alpha Compositing is a rendering technique that blends multiple semi-transparent primitives (such as 2D Gaussians or splats) into a final image by processing them in depth order from nearest to farthest, ensuring correct occlusion where near primitives paint over far ones. It is distinguished from back-to-front compositing by its ability to use early termination: once the accumulated transmittance drops below a threshold, the pixel is considered fully opaque and remaining splats are skipped, providing a significant computational speedup.

## Operating characteristics
*   **Time Complexity:** $O(N \cdot K)$ where $N$ is the number of splats and $K$ is the average number of pixels per splat's bounding box [G].
*   **Memory Complexity:** $O(W \cdot H)$ for the framebuffer, where $W, H$ are image dimensions [G].
*   **Strengths:** Parallelizable across tiles; no synchronization needed between tiles; effective on CPU architectures [G].
*   **Limitations:** Requires sorting splats by depth; performance depends on splat density and overlap [G].
*   **When to use:** Real-time rendering of large numbers of semi-transparent primitives, especially on CPU or GPU where tile-based parallelism is beneficial [G].
*   **When not to use:** Scenes with very low opacity where early termination is ineffective; when strict back-to-front order is required for specific artistic effects [G].

## Background
Tile-Based Alpha Compositing is implemented in the Tsplat renderer [S1, unofficial]. The method leverages the spatial coherence of splats and the efficiency of tile-based processing to minimize overhead and maximize throughput [G].
