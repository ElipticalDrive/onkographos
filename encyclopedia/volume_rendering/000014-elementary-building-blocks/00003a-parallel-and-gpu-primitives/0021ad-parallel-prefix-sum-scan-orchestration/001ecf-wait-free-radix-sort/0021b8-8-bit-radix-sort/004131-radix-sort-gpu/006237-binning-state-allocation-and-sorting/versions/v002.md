# Binning State Allocation and Sorting

Also called: Radix Sort on Point List Keys

## Overview
This method allocates and initializes the `BinningState` structure and performs a radix sort on point list keys [S1, unofficial]. It serves as a specialized orchestration step within GPU-based volume rendering pipelines to reorder point cloud data [G].

## How it works
**Inputs:** `P` (number of points), `binning` (context holding `BinningState` fields).
**Outputs:** Sorted `binning.point_list_keys` and permuted `binning.point_list`.

**Data Structures:**
The `BinningState` is a struct containing pointers to device memory [S2, unofficial]. Its fields are allocated via `obtain` [S1, unofficial]. The layout is:
- `point_list`: `uint32_t*`, size `P` [S2, unofficial].
- `point_list_unsorted`: `uint32_t*`, size `P` [S2, unofficial].
- `point_list_keys`: `uint32_t*`, size `P` [S2, unofficial].
- `point_list_keys_unsorted`: `uint32_t*`, size `P` [S2, unofficial].
- `list_sorting_space`: `char*`, dynamic size from sort [S1, S2, unofficial].

**Steps:**
1. Allocate the `BinningState` structure and its device memory buffers using `obtain` [S1, S2, unofficial].
2. Initialize `point_list_keys_unsorted` and `point_list_unsorted` with raw point data [G].
3. Perform radix sort on pairs of keys and indices using `cub::DeviceRadixSort::SortPairs` [S1, unofficial].
4. The sort reorders `point_list_keys` in ascending order and permutes `point_list` accordingly [S1, unofficial].

**Pseudocode:**
```python
def allocate_device_memory(size, dtype):
    return [0] * size

def radix_sort_pairs(tmp_storage, tmp_storage_bytes, keys_in, keys_out, values_in, values_out, num_items):
    indices = sorted(range(num_items), key=lambda i: keys_in[i])
    for i in range(num_items):
        keys_out[i] = keys_in[indices[i]]
        values_out[i] = values_in[indices[i]]

def binning_state_allocation_and_sorting(P, binning):
    # Step 1: Allocate BinningState fields via obtain
    binning.point_list = allocate_device_memory(P, 'uint32_t')
    binning.point_list_unsorted = allocate_device_memory(P, 'uint32_t')
    binning.point_list_keys = allocate_device_memory(P, 'uint32_t')
    binning.point_list_keys_unsorted = allocate_device_memory(P, 'uint32_t')
    # Temporary space size is dynamic; exact formula not given in sources [G]
    sorting_size = P * 4
    binning.list_sorting_space = allocate_device_memory(sorting_size, 'char')
    binning.sorting_size = sorting_size

    # Step 2: Initialize unsorted arrays with raw point data [G]
    # binning.point_list_keys_unsorted[:] = raw_keys
    # binning.point_list_unsorted[:] = raw_indices

    # Step 3: Perform radix sort on pairs of keys and indices
    radix_sort_pairs(
        tmp_storage=None,
        tmp_storage_bytes=binning.sorting_size,
        keys_in=binning.point_list_keys_unsorted,
        keys_out=binning.point_list_keys,
        values_in=binning.point_list_unsorted,
        values_out=binning.point_list,
        num_items=P
    )
```
