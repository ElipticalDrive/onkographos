# GPU Buffer Upload via Transfer Buffer

Also called: CPU Asynchronous Streaming with PBOs, CPU Asynchronous streaming, PBO Implementation, SDL_MapGPUTransferBuffer Upload, WebGPU Transfer Buffer Upload

## Overview
This method performs asynchronous data transfer from CPU to GPU using Pixel Buffer Objects (PBOs) with ping-pong buffering to overlap data download with rendering [S2, unofficial]. It solves the problem of CPU blocking during volume texture updates on discrete GPUs by decoupling the upload phase from the draw phase, allowing the CPU to prepare the next frame's data while the GPU renders the current frame [S2, unofficial]. It differs from synchronous streaming by eliminating CPU stalls and from modern GPU Asynchronous Streaming by relying on OpenGL PBOs rather than dedicated copy engines or separate contexts [S2, unofficial].

## How it works
**Inputs:**
- Source volume data: `m_pVolume`, an array of `numTimesteps` pointers to contiguous memory blocks of size `width * height * depth * sizeof(GLubyte)` [S2, unofficial].
- Texture dimensions: `dimx`, `dimy`, `dimz` [S2, unofficial].
- OpenGL context and extensions: `GL_PIXEL_UNPACK_BUFFER_ARB` support [S2, unofficial].

**Outputs:**
- A 3D texture (`texID`) updated with the latest volume slice [S2, unofficial].
- Two PBOs (`m_nPBOIds[0]`, `m_nPBOIds[1]`) used for ping-pong buffering [S2, unofficial].

**Data Structures:**
- `m_nPBOIds`: Array of two buffer object IDs [S2, unofficial].
- `m_curTimeStep`: Integer index tracking the current volume timestep, modulo `m_pVolume.size()` [S2, unofficial].
- `curPBO`: Integer (0 or 1) tracking which PBO is currently bound for the texture upload (GPU reads from it) [S2, unofficial].

**Steps:**

1. **Initialization:**
   - Create two PBOs using `glGenBuffersARB(2, m_nPBOIds)` [S2, unofficial].
   - For each PBO `i` in `{0, 1}`:
     - Bind `GL_PIXEL_UNPACK_BUFFER_ARB` to `m_nPBOIds[i]` [S2, unofficial].
     - Allocate memory using `glBufferDataARB` with size `width * height * depth * sizeof(GLubyte)`, data pointer `NULL`, and usage `GL_STREAM_DRAW_ARB` [S2, unofficial].
     - Unbind the buffer [S2, unofficial].
   - Initialize the 3D texture `texID` [S2, unofficial].

2. **Per-Frame Upload and Draw:**
   - Increment `m_curTimeStep` modulo `m_pVolume.size()` [S2, unofficial].
   - Bind the 3D texture `texID` [S2, unofficial].
   - **Phase 1: Upload from PBO to Texture (GPU reads):**
     - Bind the current PBO `m_nPBOIds[curPBO]` to `GL_PIXEL_UNPACK_BUFFER_ARB` [S2, unofficial].
     - Call `glTexSubImage3D` with target `GL_TEXTURE_3D`, level `0`, offsets `0,0,0`, dimensions `dimx,dimy,dimz`, format `GL_LUMINANCE`, type `GL_UNSIGNED_BYTE`, and data pointer `NULL` (indicating data resides in the bound PBO) [S2, unofficial].
   - **Phase 2: Prepare Next PBO (CPU writes):**
     - Bind the next PBO `m_nPBOIds[1-curPBO]` to `GL_PIXEL_UNPACK_BUFFER_ARB` [S2, unofficial].
     - Reallocate memory with `glBufferDataARB` using the same size and `GL_STREAM_DRAW_ARB` to prevent synchronization issues if the GPU is still reading the previous PBO [S2, unofficial].
     - Map the buffer for writing using `glMapBufferARB` with access `GL_WRITE_ONLY_ARB` [S2, unofficial].
     - Copy source data from `m_pVolume[m_curTimeStep]` into the mapped pointer using `std::memcpy` with size `width * height * depth` [S2, unofficial].
     - Unmap the buffer using `glUnmapBufferARB` [S2, unofficial].
   - **Phase 3: Cleanup and Swap:**
     - Unbind the PBO (`GL_PIXEL_UNPACK_BUFFER_ARB` bound to `0`) [S2, unofficial].
     - Toggle `curPBO` to `1 - curPBO` [S2, unofficial].
   - **Phase 4: Render:**
     - Execute drawing code using the updated texture [S2, unofficial].

**Pseudocode:**

```python
# Standard graphics API operations (self-contained, no library internals)
def create_buffer_ids(count):
    """Returns a list of `count` unique buffer object IDs."""
    return [next_id() for _ in range(count)]

def bind_buffer(target, id):
    """Binds `id` to the given `target` (e.g., GL_PIXEL_UNPACK_BUFFER_ARB)."""
    pass

def allocate_buffer_memory(target, id, size, data_pointer, usage):
    """Allocates `size` bytes in the bound buffer. `data_pointer` is NULL for empty allocation."""
    pass

def map_buffer(target, id, access):
    """Returns a writable host pointer to the bound buffer."""
    pass

def copy_memory(dest, src, count):
    """Copies `count` bytes from `src` to `dest`."""
    pass

def unmap_buffer(target, id):
    """Flushes and unmaps the previously mapped buffer."""
    pass

def bind_texture(target, id):
    """Binds `id` to the given texture target."""
    pass

def copy_buffer_to_texture(target, level, xoff, yoff, zoff, width, height, depth, format, type, data_pointer):
    """Copies texture data from the bound buffer (data_pointer=None) to the bound texture."""
    pass

def draw_scene():
    """Executes the rendering pass using the currently bound texture."""
    pass

# Initialization (called once)
def init_pbo_streaming(width, height, depth, num_timesteps, volume_data):
    global m_nPBOIds, texID, m_curTimeStep, curPBO, m_pVolume
    
    m_pVolume = volume_data
    m_curTimeStep = 0
    curPBO = 0
    buffer_size = width * height * depth  # sizeof(GLubyte) == 1

    # Allocate 2 PBOs
    m_nPBOIds = create_buffer_ids(2)
    for i in range(2):
        bind_buffer(GL_PIXEL_UNPACK_BUFFER_ARB, m_nPBOIds[i])
        allocate_buffer_memory(GL_PIXEL_UNPACK_BUFFER_ARB, m_nPBOIds[i], buffer_size, data_pointer=None, usage=GL_STREAM_DRAW_ARB)
        bind_buffer(GL_PIXEL_UNPACK_BUFFER_ARB, 0)

    texID = create_3d_texture(width, height, depth)

# Per-frame loop
def frame_loop():
    global m_curTimeStep, curPBO
    
    # 1. Advance timestep
    m_curTimeStep = (m_curTimeStep + 1) % len(m_pVolume)
    
    # 2. Bind texture
    bind_texture(GL_TEXTURE_3D, texID)
    
    # 3. Upload from current PBO to Texture (GPU reads)
    bind_buffer(GL_PIXEL_UNPACK_BUFFER_ARB, m_nPBOIds[curPBO])
    copy_buffer_to_texture(
        target=GL_TEXTURE_3D, level=0, xoff=0, yoff=0, zoff=0,
        width=width, height=height, depth=depth,
        format=GL_LUMINANCE, type=GL_UNSIGNED_BYTE, data_pointer=None
    )
    
    # 4. Prepare next PBO for CPU write
    next_pbo_idx = 1 - curPBO
    bind_buffer(GL_PIXEL_UNPACK_BUFFER_ARB, m_nPBOIds[next_pbo_idx])
    allocate_buffer_memory(GL_PIXEL_UNPACK_BUFFER_ARB, m_nPBOIds[next_pbo_idx], buffer_size, data_pointer=None, usage=GL_STREAM_DRAW_ARB)
    
    # Map and copy data
    mapped_ptr = map_buffer(GL_PIXEL_UNPACK_BUFFER_ARB, m_nPBOIds[next_pbo_idx], access=GL_WRITE_ONLY_ARB)
    assert mapped_ptr is not None
    src_data = m_pVolume[m_curTimeStep]
    copy_memory(dest=mapped_ptr, src=src_data, count=width * height * depth)
    unmap_buffer(GL_PIXEL_UNPACK_BUFFER_ARB, m_nPBOIds[next_pbo_idx])
    
    # 5. Unbind PBO and swap
    bind_buffer(GL_PIXEL_UNPACK_BUFFER_ARB, 0)
    curPBO = next_pbo_idx
    
    # 6. Render
    draw_scene()
```

**Parameters:**
- Buffer usage: `GL_STREAM_DRAW_ARB` [S2, unofficial].
- Map access: `GL_WRITE_ONLY_ARB` [S2, unofficial].
- Texture format: `GL_LUMINANCE` with `GL_UNSIGNED_BYTE` [S2, unofficial].

**Edge Cases and Pitfalls:**
- **Synchronization:** Reallocating the next PBO with `glBufferDataARB` is critical to prevent the GPU from accessing stale or invalid memory if it is still reading from the previous PBO [S2, unofficial].
- **Blocking:** `glMapBufferARB` may block if the GPU is still processing the previous frame, as PBO downloads share the draw thread on older hardware [S2, unofficial].
- **Data Format:** Data must be in GPU native format (e.g., `GL_LUMINANCE`) to avoid implicit conversion overhead [S2, unofficial].

## Operating characteristics
- **Time Complexity:** O(1) per frame for upload logic, but dependent on PCIe bandwidth and GPU copy engine speed [S2, unofficial].
- **Memory Complexity:** O(2 * Volume_Size) for PBO storage [S2, unofficial].
- **Performance:** Avoids CPU blocking by overlapping download and rendering [S2, unofficial]. Throughput is optimal with ping-pong buffering [S2, unofficial].
- **Strengths:** Simple implementation using standard OpenGL extensions; effective overlap on hardware without dedicated copy engines [S2, unofficial].
- **Limitations:** Still subject to driver synchronization overhead; less efficient than dedicated copy engines on modern GPUs [S2, unofficial].
- **When to use:** When targeting older OpenGL hardware or when a simple, single-threaded upload mechanism is preferred over complex multi-context setups [S2, unofficial].
- **When not to use:** When maximum throughput is required on modern GPUs with copy engines; use GPU Asynchronous Streaming instead [S2, unofficial].

## Background
Originated from NVIDIA's GTC 2009 presentation on GPU Asynchronous Streaming, this method was developed to optimize volume rendering on discrete GPUs with independent memory [S2, unofficial]. It predates the widespread adoption of dedicated copy engines and is a foundational technique for asynchronous texture updates in OpenGL [S2, unofficial]. Modern variants of this approach replace PBOs with transfer buffers and explicit command buffers to achieve fully asynchronous uploads [S1, unofficial].
