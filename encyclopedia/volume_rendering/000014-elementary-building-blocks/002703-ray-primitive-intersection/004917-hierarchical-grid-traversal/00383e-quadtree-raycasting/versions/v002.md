# Quadtree Raycasting

Also called: raycast2

## Overview
Quadtree Raycasting is a recursive ray-quadtree intersection algorithm that traverses a 2D quadtree to find the first hit node [S1, unofficial]. It handles ray direction flipping via a mask to ensure consistent traversal order regardless of ray direction [S1, unofficial]. It differs from uniform grid raycasting by adapting traversal to hierarchical node boundaries, and operates on axis-aligned square quadrants rather than tetrahedra or implicit surfaces.

## How it works
**Inputs and Outputs**
*   **Input:** Ray origin $\mathbf{s}$ (Vec2), ray direction $\mathbf{d}$ (Vec2), and a root Quadtree node.
*   **Output:** The first solid leaf node intersected by the ray and the hit distance, or `None` if no intersection is found [S1, unofficial].

**Data Structures**
The quadtree node layout is defined as:
*   `is_full`: Boolean flag indicating if the node is entirely solid.
*   `children`: Optional array of 4 child nodes (`Option<[Box<QuadtreeNode>; 4]>`). `None` indicates a leaf.
*   `size`: Integer width/height of the node's spatial extent.
*   `position`: 2D integer coordinates (`IVec2`) of the node's bottom-left corner.

**Algorithm Steps**
1.  **Initialization:** Calculate the initial intersection interval $[t_{min}, t_{max}]$ for the root node.
    *   Compute boundary distances:
        $$tx_0 = \frac{pos.x - s.x}{|d.x|}, \quad ty_0 = \frac{pos.y - s.y}{|d.y|}$$
        $$tx_1 = \frac{pos.x + size - s.x}{|d.x|}, \quad ty_1 = \frac{pos.y + size - s.y}{|d.y|}$$
    *   Determine interval: $t_{min} = \max(tx_0, ty_0)$, $t_{max} = \min(tx_1, ty_1)$.
    *   If $t_{min} \ge t_{max}$, return `None` [S1, unofficial].
2.  **Traversal Setup:** Initialize a bitmask `mask = 0`.
    *   If $d.x < 0$, flip the start x-coordinate logic: $s.x = 2 \cdot pos.x + size - s.x$, and set bit 0 of `mask` [S1, unofficial].
    *   If $d.y < 0$, flip the start y-coordinate logic: $s.y = 2 \cdot pos.y + size - s.y$, and set bit 1 of `mask` [S1, unofficial].
    *   Call the recursive helper `proc_subtree` with the root node and initial bounds $(tx_0, ty_0, tx_1, ty_1)$ [S1, unofficial].
3.  **Recursive Traversal (`proc_subtree`):**
    *   **Pruning:** If $tx_1 < 0$ or $ty_1 < 0$, the ray has passed the current node's back face; return `None` [S1, unofficial].
    *   **Leaf Check:** If the node is a leaf:
        *   If `is_full` is true, return the node and hit distance $t = \max(tx_0, ty_0)$ [S1, unofficial].
        *   If not full, return `None`.
    *   **Internal Node:**
        *   Calculate midpoints: $tx_m = (tx_0 + tx_1) / 2$, $ty_m = (ty_0 + ty_1) / 2$ [S1, unofficial].
        *   Determine the first child index to visit using `first_node(tx0, ty0, txm, tym)` [S1, unofficial].
        *   Iterate through children using a while loop until `curr_node == 4` [S1, unofficial].
        *   For each child, apply the mask to the index: `child_idx = curr_node ^ mask` [S1, unofficial].
        *   Recurse into the corresponding child with updated bounds:
            *   Child 0 (Bottom-Left): $(tx_0, ty_0, tx_m, ty_m)$
            *   Child 1 (Bottom-Right): $(tx_m, ty_0, tx_1, ty_m)$
            *   Child 2 (Top-Left): $(tx_0, ty_m, tx_m, ty_1)$
            *   Child 3 (Top-Right): $(tx_m, ty_m, tx_1, ty_1)$
        *   If recursion returns a hit, propagate it up [S1, unofficial].
        *   If no hit, continue to next child [S1, unofficial].
        *   If loop completes without hit, return `None` [S1, unofficial].

**Pseudocode**
```python
def quadtree_raycast(start: Vec2, dir: Vec2, root: QuadtreeNode) -> Optional[Tuple[QuadtreeNode, float]]:
    # Compute boundary distances
    tx0 = (root.position.x - start.x) / abs(dir.x)
    ty0 = (root.position.y - start.y) / abs(dir.y)
    tx1 = (root.position.x + root.size - start.x) / abs(dir.x)
    ty1 = (root.position.y + root.size - start.y) / abs(dir.y)
    
    t_min = max(tx0, ty0)
    t_max = min(tx1, ty1)
    
    if t_min >= t_max:
        return None

    # Initialize mask for direction flipping
    mask = 0
    if dir.x < 0:
        start.x = 2.0 * root.position.x + root.size - start.x
        mask |= 1
    if dir.y < 0:
        start.y = 2.0 * root.position.y + root.size - start.y
        mask |= 2
        
    return proc_subtree(root, tx0, ty0, tx1, ty1, mask)

def proc_subtree(node: QuadtreeNode, tx0: float, ty0: float, tx1: float, ty1: float, mask: int) -> Optional[Tuple[QuadtreeNode, float]]:
    # Pruning: if the back face is behind the ray origin (in t-space)
    if tx1 < 0 or ty1 < 0:
        return None

    if node.is_leaf():
        if node.is_full:
            return (node, max(tx0, ty0))
        return None

    # Internal node: calculate midpoints in t-space
    txm = (tx0 + tx1) / 2.0
    tym = (ty0 + ty1) / 2.0

    # first_node and next_node determine traversal order based on ray direction relative to sub-regions [S1, unofficial]
    curr = first_node(tx0, ty0, txm, tym)
    while curr < 4:
        child_idx = curr ^ mask
        child = node.children[child_idx]

        # Bounds for each spatial quadrant
        if child_idx == 0: # Bottom-Left
            hit = proc_subtree(child, tx0, ty0, txm, tym, mask)
        elif child_idx == 1: # Bottom-Right
            hit = proc_subtree(child, txm, ty0, tx1, tym, mask)
        elif child_idx == 2: # Top-Left
            hit = proc_subtree(child, tx0, tym, txm, ty1, mask)
        else: # Top-Right
            hit = proc_subtree(child, txm, tym, tx1, ty1, mask)

        if hit is not None:
            return hit
        curr = next_node(curr)

    return None

# Standard helpers to determine traversal order based on ray direction relative to sub-regions [G]
def first_node(tx0: float, ty0: float, txm: float, tym: float) -> int:
    if tx0 < 0 and ty0 < 0: return 0
    if txm < 0 and ty0 < 0: return 1
    if tx0 < 0 and tym < 0: return 2
    return 3

def next_node(curr: int) -> int:
    return curr + 1
```

**Parameters**
*   `start`: Ray origin in world space (Vec2).
*   `dir`: Ray direction vector (Vec2).
*   `mask`: Bitmask (u8) to invert child indices. Bit 0 set if $d.x < 0$, Bit 1 set if $d.y < 0$ [S1, unofficial].

**Edge Cases and Pitfalls**
*   **Direction Flipping:** The algorithm relies on the `mask` to ensure consistent traversal order regardless of ray direction [S1, unofficial]. The mask ensures that the logical child index corresponds to the correct spatial quadrant regardless of ray direction [S1, unofficial].
*   **Precision:** Division by zero occurs if $d.x$ or $d.y$ is exactly 0. The source assumes non-zero components or handles them via the `signum` logic in the DDA variant, but the recursive `proc_subtree` method requires absolute values in denominators [S1, unofficial].
*   **Degenerate Input:** If $t_{min} \ge t_{max}$, the ray misses the bounding box. This check is performed at the root and implicitly in children via the $tx_1 < 0$ pruning [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(\log N)$ on average for sparse data, where $N$ is the number of leaf nodes, as it skips empty subtrees. In the worst case (fully dense or ray traverses many nodes), it approaches $O(N)$.
*   **Memory Complexity:** $O(N)$ to store the quadtree structure.
*   **Strengths:** Efficient for sparse 2D volumes; adaptive resolution allows high detail in dense regions and low detail in empty regions.
*   **Limitations:** Recursive nature may cause stack overflow for very deep trees; not directly parallelizable per-ray without careful synchronization; 2D only.
*   **When to use:** Sparse 2D volume rendering, collision detection in hierarchical 2D maps.
*   **When not to use:** Dense 3D volumes (use [Ray-Tetrahedron Intersection](2525-ray-tetrahedron-intersection.md) or voxel grids), uniform grids (use [Ray-box intersection](776-ray-box-intersection.md)).

## Background
The method is documented in the `quadtree-raycast` repository by Musta-Kissa [S1, unofficial]. It builds on the principles of ray-primitive intersection, adapting the traversal logic to the quadtree's recursive structure. It is often referred to as `proc_subtree` or `raycast2` in the context of these specific implementations.
