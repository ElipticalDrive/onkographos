# Ray Filtering

Also called: Filtering Rays, Ray Culling, Ray-Volume and Bounding Box Intersection, TensorBase Ray Filtering

## Overview
Ray filtering reduces computational load by discarding rays that do not intersect with the scene's geometry or alpha mask before expensive volume rendering steps [S1, S2, unofficial]. It distinguishes itself from sibling methods by operating as a pre-processing culling stage on a batch of rays, often integrating alpha-mask density checks alongside axis-aligned bounding box (AABB) intersection tests [S1, S2, unofficial].

## How it works
**Inputs and Outputs**
- **Inputs**: A batch of rays defined by origins $\mathbf{o} \in \mathbb{R}^{N \times 3}$ and directions $\mathbf{d} \in \mathbb{R}^{N \times 3}$; an AABB defined by minimum corner $\mathbf{min} \in \mathbb{R}^3$ and maximum corner $\mathbf{max} \in \mathbb{R}^3$; an optional alpha mask volume for density-based culling; a boolean flag `bbox_only`.
- **Outputs**: A boolean mask `valid_mask` of size $N$ indicating which rays intersect the scene; optionally, filtered ray origins and directions.

**Data Structures**
- **AABB**: Two 3D vectors, `aabb[0]` (min) and `aabb[1]` (max).
- **Alpha Mask**: A 3D tensor sampled at query points, returning scalar alpha values.

**Steps**
1. **Compute Ray-AABB Intersection Intervals**:
   For each ray $i$, compute the intersection parameter range $[t_{min}, t_{max}]$ with the AABB.
   Calculate inverse direction components:
   $$ \text{rate}_a = \frac{\mathbf{aabb}[1] - \mathbf{o}}{\mathbf{d}} $$
   $$ \text{rate}_b = \frac{\mathbf{aabb}[0] - \mathbf{o}}{\mathbf{d}} $$
   Compute the entry and exit distances along the ray:
   $$ t_{min} = \max(\min(\text{rate}_a), \min(\text{rate}_b)) $$
   $$ t_{max} = \min(\max(\text{rate}_a), \max(\text{rate}_b)) $$
   A ray intersects the box if $t_{max} > t_{min}$ and $t_{max} > 0$ (assuming rays start at $t=0$) [S1, unofficial].

2. **Determine Initial Mask**:
   Set `mask_inbbox` to true for rays where $t_{max} > t_{min}$ [S1, unofficial].

3. **Alpha Mask Filtering (Optional)**:
   If `bbox_only` is false, sample points along the rays within the bounding box interval. Check if any sample point has an alpha value $> 0$ in the alpha mask. Update `mask_inbbox` to true only if the ray intersects the box AND passes through a non-zero alpha region [S1, S2, unofficial].

4. **Batch Processing**:
   Split the ray batch into chunks if memory constraints require it. Apply the above logic per chunk [S2, unofficial].

5. **Update State**:
   Reinitialize the ray sampler with the filtered ray count to ensure subsequent rendering steps only process valid rays [S1, unofficial].

**Pseudocode**
```python
def filter_rays(rays_o, rays_d, aabb_min, aabb_max, alpha_mask=None, bbox_only=False):
    """
    Filter rays based on AABB intersection and optionally alpha mask density.
    
    Args:
        rays_o: (N, 3) ray origins
        rays_d: (N, 3) ray directions (assumed normalized)
        aabb_min: (3,) minimum corner of AABB
        aabb_max: (3,) maximum corner of AABB
        alpha_mask: Optional 3D tensor or sampling function for alpha values
        bbox_only: Boolean, if True skip alpha mask check
        
    Returns:
        valid_mask: (N,) boolean mask of valid rays
    """
    # Step 1: Compute intersection intervals
    # rate_a and rate_b are (N, 3)
    rate_a = (aabb_max - rays_o) / rays_d
    rate_b = (aabb_min - rays_o) / rays_d
    
    # t_min is the max of the mins, t_max is the min of the maxs
    # torch.minimum and torch.maximum operate element-wise
    t_min = torch.maximum(torch.minimum(rate_a, rate_b), dim=1).values
    t_max = torch.minimum(torch.maximum(rate_a, rate_b), dim=1).values
    
    # Step 2: Initial bbox mask
    # Ray intersects if t_max > t_min and t_max > 0 (ray enters box in front of origin)
    mask_inbbox = (t_max > t_min) & (t_max > 0)
    
    # Step 3: Alpha mask filtering
    if not bbox_only and alpha_mask is not None:
        # Sample points along rays within the bbox interval
        # This step requires implementing ray sampling within [t_min, t_max]
        # For simplicity, we assume a helper function `sample_rays` exists
        # which returns sampled points and a mask of points inside the bbox
        
        # Generate sample points
        # N_samples is a hyperparameter
        N_samples = 64
        t_vals = torch.linspace(0, 1, N_samples, device=rays_o.device)
        # Map t_vals to actual distances [t_min, t_max]
        # Handle rays where t_min might be negative (origin inside box)
        # Clamp t_min to 0 for sampling start if necessary
        start_t = torch.clamp(t_min, min=0.0)
        end_t = t_max
        
        # Interpolate t values for each ray
        # t_sampled shape: (N, N_samples)
        t_sampled = start_t.unsqueeze(1) + t_vals.unsqueeze(0) * (end_t.unsqueeze(1) - start_t.unsqueeze(1))
        
        # Compute 3D coordinates
        # xyz_sampled shape: (N, N_samples, 3)
        xyz_sampled = rays_o.unsqueeze(1) + rays_d.unsqueeze(1) * t_sampled.unsqueeze(2)
        
        # Sample alpha mask at these points
        # alpha_values shape: (N, N_samples)
        alpha_values = alpha_mask.sample(xyz_sampled)
        
        # Check if any point has alpha > 0
        mask_inalpha = (alpha_values > 0).any(dim=1)
        
        # Combine masks
        mask_inbbox = mask_inbbox & mask_inalpha
        
    return mask_inbbox
```

**Parameters**
- `bbox_only`: Boolean. If `True`, only AABB intersection is checked. If `False`, alpha mask density is also checked [S1, S2, unofficial].
- `N_samples`: Number of points sampled along each ray for alpha mask checking. Not given in the sources.

**Edge Cases and Pitfalls**
- **Degenerate Rays**: Rays with zero direction components cause division by zero in `rate_a` and `rate_b`. Handle by checking for zero direction or using large constants for inverse direction [G].
- **Origin Inside Box**: If the ray origin is inside the AABB, $t_{min}$ may be negative. Ensure sampling starts at $\max(0, t_{min})$ to avoid sampling behind the camera [G].
- **Precision**: Floating-point errors in $t_{max} > t_{min}$ comparisons can lead to incorrect culling. Use a small epsilon if necessary [G].

## Subtopics

### Ray-box intersection
Standard AABB intersection test. Used as the primary culling step. [Ray-box intersection](776-ray-box-intersection.md)

### Ray-Volume Intersection (Face Distance Method)
Alternative to AABB for non-box volumes. Not used in this method. [Ray-Volume Intersection (Face Distance Method)](2381-ray-volume-intersection-face-distance-method.md)

## Operating characteristics
- **Time Complexity**: $O(N)$ for AABB intersection, where $N$ is the number of rays. Alpha mask sampling adds $O(N \cdot S)$, where $S$ is the number of samples per ray [S1, S2, unofficial].
- **Memory Complexity**: $O(N \cdot S)$ for storing sampled points and alpha values if alpha mask filtering is enabled [S1, S2, unofficial].
- **Performance**: Significantly reduces rendering time by eliminating rays that do not contribute to the final image. The reduction depends on the scene's sparsity and the tightness of the AABB [S1, S2, unofficial].
- **Strengths**: Simple to implement, effective for sparse scenes, reduces memory bandwidth for subsequent rendering steps [S1, S2, unofficial].
- **Limitations**: Requires pre-computed alpha mask or AABB. Alpha mask sampling adds overhead if the scene is dense [S1, S2, unofficial].

## Background
Ray filtering is a common optimization in volume rendering and neural radiance fields (NeRF) to improve training and inference efficiency. It is used in TensorBase [S1, unofficial] and Collaborative NeRF [S2, unofficial] to cull rays outside the bounding box or alpha mask. The method is typically applied during training iterations when the alpha mask is updated [S1, unofficial].
