# 2D Axis-Aligned Bounding Box (AABB) Intersection

Also called: Rect, Rect Intersection, Rectangle Overlap Test

## Overview
This method determines whether two 2D axis-aligned bounding boxes (AABBs) overlap [S1, unofficial], extending the 3D slab approach of [Ray-box intersection](776-ray-box-intersection.md) to a single plane.

## How it works
**Inputs and Outputs:**
- Input: Two AABBs, $R_1$ and $R_2$ [S1, unofficial].
- Output: Boolean `true` if they overlap, `false` otherwise [S1, unofficial].

**Data Structures:**
An AABB is represented by a struct containing two 2D integer vectors: `min` and `max` [S1, unofficial]. The coordinates are inclusive [S1, unofficial]. The width and height are calculated as:
$$ width = max.x - min.x + 1 $$
$$ height = max.y - min.y + 1 $$
[S1, unofficial]

**Algorithm:**
The intersection test returns `true` if the rectangles overlap on both axes, which is equivalent to the negation of the separation condition: `!(r1.max.x < r2.min.x || r1.max.y < r2.min.y || r1.min.x > r2.max.x || r1.min.y > r2.max.y)` [S1, unofficial].

**Pseudocode:**
```python
def intersects(r1, r2):
    # Returns true if r1 and r2 overlap on both axes
    if r1.max.x < r2.min.x:
        return False
    if r1.max.y < r2.min.y:
        return False
    if r1.min.x > r2.max.x:
        return False
    if r1.min.y > r2.max.y:
        return False
    return True
```

**Edge Cases:**
- **Touching Edges:** Since coordinates are inclusive, boxes that share an edge or corner (e.g., $R_1.max.x == R_2.min.x$) are considered overlapping [S1, unofficial].
- **Degenerate Boxes:** Not given in the sources [G].

## Subtopics

### [AABB Ray Distance](5309-aabb-ray-distance.md)
Computes the distance along a ray direction from a given point to the nearest intersection with an axis-aligned bounding box (AABB). It returns -1 if the starting point is inside the box or if the ray does not intersect the box. It differs from standard intersection tests by returning a scalar distance value rather than a boolean or hit point, which is useful for sorting or early-out optimizations in volume rendering pipelines.
