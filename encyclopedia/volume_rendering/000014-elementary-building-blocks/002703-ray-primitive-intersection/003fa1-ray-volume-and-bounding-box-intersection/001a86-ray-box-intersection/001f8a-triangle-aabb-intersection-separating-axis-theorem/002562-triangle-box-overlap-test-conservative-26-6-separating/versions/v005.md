# Triangle / Box Overlap Test (Conservative 26/6-separating)

Also called: 26-separating and 6-separating Triangle-Box Test, Conservative Triangle-AABB Overlap, Conservative Triangle/Voxel Overlap Test

## Overview
This method determines if a triangle overlaps an axis-aligned box (voxel) for conservative surface voxelization, ensuring that any voxel partially or merely touched by a triangle is marked as occupied [S1, S2]. It differs from standard rasterization, which only sets voxels if the triangle overlaps the voxel center, by using linear edge functions evaluated at critical points to guarantee gap-free coverage [S1]. Unlike the Separating Axis Theorem (SAT) approach [2050-triangle-aabb-intersection-separating-axis-theorem.md], which projects onto 15 axes, this test reduces the problem to a plane overlap check and three 2D projection checks, requiring fewer instructions and registers on GPU hardware [S1].

## How it works
The test decomposes the 3D overlap problem into a plane intersection check and three 2D box-triangle overlap checks (one for each coordinate plane: xy, xz, yz) [S1]. It separates computation into a **Setup Phase** (dependent only on the triangle and voxel size) and an **Actual Test Phase** (dependent on the specific voxel position) [S1, S2].

### Inputs and Outputs
*   **Inputs:**
    *   Triangle vertices $\mathbf{v}_0, \mathbf{v}_1, \mathbf{v}_2 \in \mathbb{R}^3$ [S1].
    *   Box minimum corner $\mathbf{p} \in \mathbb{R}^3$ [S1].
    *   Box extent $\Delta \mathbf{p} = (\Delta p_x, \Delta p_y, \Delta p_z) \in \mathbb{R}^3_{>0}$ [S1].
    *   (Optional for 6-separating) Dominant axis of the triangle normal [S2].
*   **Output:** Boolean `true` if the triangle overlaps the box, `false` otherwise [S1].

### Data Structures
The setup phase precomputes the following values per triangle:
1.  Triangle normal $\mathbf{n} = (\mathbf{v}_1 - \mathbf{v}_0) \times (\mathbf{v}_2 - \mathbf{v}_0)$ [S1].
2.  Plane constants $d_1, d_2$ (see formulas below) [S1].
3.  For each edge $i \in \{0, 1, 2\}$ and each coordinate plane $P \in \{xy, xz, yz\}$:
    *   2D edge normal $\mathbf{n}_{e_i}^P$ [S1].
    *   2D edge function offset $d_{e_i}^P$ [S1].
4.  (Optional for 6-separating optimization) The dominant axis index of $\mathbf{n}$ and the normalized plane coefficients [S2].

### Formulas and Definitions

**1. Plane Overlap Check**
The triangle plane overlaps the box if the box corners lie on opposite sides of the plane or on the plane [S1].
Let $\mathbf{c}$ be the critical point:
$$ \mathbf{c} = \left( \begin{cases} \Delta p_x & \text{if } n_x > 0 \\ 0 & \text{otherwise} \end{cases}, \begin{cases} \Delta p_y & \text{if } n_y > 0 \\ 0 & \text{otherwise} \end{cases}, \begin{cases} \Delta p_z & \text{if } n_z > 0 \\ 0 & \text{otherwise} \end{cases} \right) $$
Compute:
$$ d_1 = \langle \mathbf{n}, \mathbf{c} - \mathbf{v}_0 \rangle $$
$$ d_2 = \langle \mathbf{n}, (\Delta \mathbf{p} - \mathbf{c}) - \mathbf{v}_0 \rangle $$
The plane overlaps the box if:
$$ (\langle \mathbf{n}, \mathbf{p} \rangle + d_1) \cdot (\langle \mathbf{n}, \mathbf{p} \rangle + d_2) \leq 0 \quad [S1] $$

**2. 2D Edge Normal and Offset (Setup Phase)**
For a specific plane (e.g., $xy$), let $\mathbf{e}_i = \mathbf{v}_{i+1 \mod 3} - \mathbf{v}_i$ be the edge vector [S1].
The 2D edge normal $\mathbf{n}_{e_i}^{xy}$ is computed by rotating the edge vector and orienting it based on the triangle normal's $z$-component [S2]:
$$ \mathbf{n}_{e_i}^{xy} = (-\mathbf{e}_{i,y}, \mathbf{e}_{i,x}) \cdot \text{sgn}(n_z) \quad [S2] $$
*Note: For $xz$ and $yz$ planes, the rotation and sign logic follow the same principle relative to the missing axis.*

The offset $d_{e_i}^{xy}$ incorporates the box extent to test the "most interior" point of the box projection [S1, S2]:
$$ d_{e_i}^{xy} = -\langle \mathbf{n}_{e_i}^{xy}, \mathbf{v}_{i,xy} \rangle + \max\{0, \Delta p_x n_{e_i,x}^{xy}\} + \max\{0, \Delta p_y n_{e_i,y}^{xy}\} \quad [S1] $$
This uses the standard half-space definition $\langle \mathbf{n}, \mathbf{p} \rangle + d \geq 0$ [S1].

To optimize the per-voxel test, precompute scaled normals for integer grid coordinates $(u, v, w)$ where the box is $\mathbf{p} + (u,v,w)\Delta \mathbf{p}$:
$$ n_i^x = \mathbf{n}_{e_i}^{xy}_x \cdot \Delta p_x $$
$$ n_i^y = \mathbf{n}_{e_i}^{xy}_y \cdot \Delta p_y \quad [S2] $$

**3. 2D Overlap Condition (Actual Test Phase)**
For a voxel with integer coordinates $(u, v)$ in the $xy$ plane, the projection overlaps if:
$$ \bigwedge_{i=0}^2 \left( d_{e_i}^{xy} + v \cdot n_i^y + u \cdot n_i^x \geq 0 \right) \quad [S2] $$
This condition must hold for all three coordinate planes ($xy, xz, yz$) [S1].

**4. Bounding Box Check**
Because the evaluation points for the edge functions differ from the box center, a standard AABB-AABB overlap test between the triangle's bounding box and the voxel box is required as a necessary precondition [S1].

### Pseudocode

```python
def triangle_box_overlap(v0, v1, v2, grid_origin, delta_p, u, v, w):
    """
    Determines if triangle T overlaps box B.
    v0, v1, v2: Triangle vertices (tuples/lists of 3 floats)
    grid_origin: Origin of the voxel grid (tuple/list of 3 floats)
    delta_p: Box extent (tuple/list of 3 floats)
    u, v, w: Integer grid coordinates of the voxel's minimum corner
    Returns: Boolean
    """
    
    # Helper definitions
    def dot(a, b):
        return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]
    
    def cross(a, b):
        return (a[1]*b[2] - a[2]*b[1],
                a[2]*b[0] - a[0]*b[2],
                a[0]*b[1] - a[1]*b[0])

    # --- Setup Phase (Compute once per triangle) ---
    
    # 1. Triangle Normal
    e0 = (v1[0]-v0[0], v1[1]-v0[1], v1[2]-v0[2])
    e1 = (v2[0]-v1[0], v2[1]-v1[1], v2[2]-v1[2])
    e2 = (v0[0]-v2[0], v0[1]-v2[1], v0[2]-v2[2])
    n = cross(e0, e2)
    
    # 2. Plane Overlap Constants
    # Critical point c
    cx = delta_p[0] if n[0] > 0 else 0.0
    cy = delta_p[1] if n[1] > 0 else 0.0
    cz = delta_p[2] if n[2] > 0 else 0.0
    c = (cx, cy, cz)
    
    d1 = dot(n, (c[0]-v0[0], c[1]-v0[1], c[2]-v0[2]))
    d2 = dot(n, (delta_p[0]-c[0]-v0[0], delta_p[1]-c[1]-v0[1], delta_p[2]-c[2]-v0[2]))
    
    # 3. 2D Edge Normals and Offsets for all 3 planes
    setup_data = {}
    
    for plane, axis1, axis2, axis3 in [('xy', 0, 1, 2), ('xz', 0, 2, 1), ('yz', 1, 2, 0)]:
        perp_axis = axis3
        n_perp = n[perp_axis]
        sgn = 1.0 if n_perp >= 0 else -1.0
        
        edge_normals_2d = []
        d_offsets = []
        
        for i, edge in enumerate([e0, e1, e2]):
            ex = edge[axis1]
            ey = edge[axis2]
            
            # Rotate 90 degrees: (-ey, ex)
            nx_2d = -ey * sgn
            ny_2d = ex * sgn
            
            # Precompute scaled normals for integer grid steps
            n_x = nx_2d * delta_p[axis1]
            n_y = ny_2d * delta_p[axis2]
            
            # Compute offset d
            vi = [v0, v1, v2][i]
            vi_x = vi[axis1]
            vi_y = vi[axis2]
            
            term1 = -(nx_2d * vi_x + ny_2d * vi_y)
            term2 = max(0.0, delta_p[axis1] * nx_2d)
            term3 = max(0.0, delta_p[axis2] * ny_2d)
            d_val = term1 + term2 + term3
            
            edge_normals_2d.append((n_x, n_y))
            d_offsets.append(d_val)
            
        setup_data[plane] = {
            'normals': edge_normals_2d,
            'd': d_offsets
        }

    # --- Actual Test Phase (Per Voxel) ---
    
    # 1. Bounding Box Overlap Check
    t_min = (min(v0[0], v1[0], v2[0]), min(v0[1], v1[1], v2[1]), min(v0[2], v1[2], v2[2]))
    t_max = (max(v0[0], v1[0], v2[0]), max(v0[1], v1[1], v2[1]), max(v0[2], v1[2], v2[2]))
    
    voxel_min = (grid_origin[0] + u*delta_p[0], grid_origin[1] + v*delta_p[1], grid_origin[2] + w*delta_p[2])
    voxel_max = (voxel_min[0] + delta_p[0], voxel_min[1] + delta_p[1], voxel_min[2] + delta_p[2])
    
    if t_min[0] > voxel_max[0] or t_max[0] < voxel_min[0]: return False
    if t_min[1] > voxel_max[1] or t_max[1] < voxel_min[1]: return False
    if t_min[2] > voxel_max[2] or t_max[2] < voxel_min[2]: return False
    
    # 2. Plane Overlap Check
    p_dot_n = dot(n, voxel_min)
    val1 = p_dot_n + d1
    val2 = p_dot_n + d2
    
    if val1 * val2 > 0: return False
    
    # 3. 2D Projection Checks
    # Check XY plane
    for i in range(3):
        nx, ny = setup_data['xy']['normals'][i]
        d = setup_data['xy']['d'][i]
        if d + v * ny + u * nx < 0: return False
        
    # Check XZ plane
    for i in range(3):
        nx, nz = setup_data['xz']['normals'][i]
        d = setup_data['xz']['d'][i]
        if d + w * nz + u * nx < 0: return False
        
    # Check YZ plane
    for i in range(3):
        ny, nz = setup_data['yz']['normals'][i]
        d = setup_data['yz']['d'][i]
        if d + w * nz + v * ny < 0: return False
        
    return True
```

### Parameters and Edge Cases
*   **Degenerate Triangles:** If the triangle area is zero (normal $\mathbf{n} = \mathbf{0}$), the plane test is undefined [G]. Implementers should handle degenerate triangles by falling back to a line/point-box test or skipping them if the application guarantees non-degenerate input [G].
*   **Precision:** The use of `max(0, ...)` in the offset calculation ensures that the edge function is evaluated at the correct corner of the box [S1]. Floating-point errors near the boundary of the box may cause a voxel to be missed or included incorrectly [G]. A small epsilon tolerance may be added to the comparisons ($\geq -\epsilon$) to handle boundary cases robustly, though this changes the strictness of the "merely touched" criterion [G].
*   **6-Separating Variant:** For thin voxelization, only the 2D projection along the dominant axis of the triangle normal is checked [S2]. This reduces the number of 2D tests from 3 to 1 [S2].

## Subtopics

### [6-Separating Surface Voxelization](9105-6-separating-surface-voxelization.md)
A variant of the overlap test used for "thin" voxelization. Instead of checking all three 2D projections (26-separating), it checks only the projection along the dominant axis of the triangle normal. This produces a thinner set of voxels while remaining gap-free and 6-connected (connected via faces) [9105-6-separating-surface-voxelization.md]. It is chosen when memory bandwidth is critical and a slightly less conservative (but still gap-free) result is acceptable.

### Cone Overlap Test (Mesh Level)
A pruning test for mesh-level nodes in hierarchical structures [S3]. It extends the sub-triangle cone overlap test by using a 3D position bounding box instead of a 2D triangle [S3]. It is used to quickly cull nodes that cannot possibly contribute to the view or shading calculation [S3].

## Operating characteristics
*   **Time Complexity:** Setup is $O(1)$ per triangle [S2]. The per-voxel test is $O(1)$, involving 3 FMAs and 3 comparisons per 2D plane (9 total) plus the plane and bounding box checks [S2]. With scanline optimization, the cost per voxel can be reduced to 3 FMULs and 3 comparisons per scanline step, eliminating the per-voxel FMA cost [S2].
*   **Memory Complexity:** Setup requires storing 9 floating-point values per triangle (3 edges $\times$ 3 planes $\times$ 1 offset, plus normals) [S2].
*   **Performance:** Significantly faster than SAT-based methods on GPUs due to fewer instructions and registers [S1]. The scanline optimization eliminates unnecessary voxel tests entirely for non-intersecting scanlines [S2].
*   **Strengths:** Exact conservative coverage, efficient GPU implementation, supports parallel processing [S1].
*   **Limitations:** Requires precomputation per triangle [S1]. Degenerate triangles require special handling [G].

## Background
The method extends the linear edge function approach by Pineda [1988] and the 2D box overlap extension by Akenine-Möller and Aila [2005] [S1]. It was formalized for 3D surface voxelization by Schwarz and Seidel [2010] to provide a fast, gap-free conservative voxelization algorithm suitable for real-time GPU applications [S1, S2]. It addresses the gaps caused by standard rasterization, which only samples the pixel/voxel center [S1].
