# Face-in-Hexahedron Containment Test


## Overview
Determines if a triangle face is fully contained within a voxel's bounding box (hexahedron) by verifying plane overlap and checking for separation along multiple axes [S1, unofficial]. It serves as a strict containment check, distinct from the parent [AABB Face Normal Test](2053-aabb-face-normal-test.md) which performs a broader intersection test; this method returns true only if the entire triangle lies inside the box.

## How it works
**Inputs:**
- `face`: Array of 3 vertices, each a 3D vector $(x, y, z)$.
- `voxel_center`: 3D vector representing the center of the axis-aligned bounding box (AABB).
- `half_box_size`: 3D vector representing the half-extents of the AABB along each axis.

**Outputs:**
- Boolean: `true` if the triangle is fully contained within the hexahedron, `false` otherwise.

**Data Structures:**
- Vectors are standard 3D Cartesian coordinates. No special bit-packing is required for the inputs.

**Steps:**

1.  **Plane Test:**
    Compute edge vectors:
    $$e_1 = \text{face}[2] - \text{face}[1]$$
    $$e_2 = \text{face}[0] - \text{face}[2]$$
    Compute the triangle normal:
    $$n = e_1 \times e_2$$
    Define the triangle plane equation $n \cdot p + d = 0$, where:
    $$d = -n \cdot \text{face}[0]$$
    Check if the triangle plane overlaps with the AABB. If the plane does not overlap the box (i.e., the entire box lies on one side of the plane), return `false` [S1, unofficial].

2.  **X-Axis Edge Tests:**
    Compute edge $e_0 = \text{face}[1] - \text{face}[0]$.
    Perform separation tests along axes derived from $e_0, e_1, e_2$ projected onto the X-axis. The specific helper functions `axis_test_x02`, `axis_test_x01`, etc., check for separation along axes perpendicular to the edges in the YZ, ZY, and YZ planes respectively [S1, unofficial].
    - If `axis_test_x02(e0)` returns true (separation found), return `false`.
    - If `axis_test_x02(e1)` returns true, return `false`.
    - If `axis_test_x01(e2)` returns true, return `false`.

3.  **Y-Axis Edge Tests:**
    - If `axis_test_y02(e0)` returns true, return `false`.
    - If `axis_test_y02(e1)` returns true, return `false`.
    - If `axis_test_z01(e2)` returns true, return `false`.
    *(Note: The source lists `axis_test_z01(e2)` in the Y-axis block, which appears to be a typo in the source or a specific naming convention for a Y-related test. Based on standard SAT, this likely refers to a test involving the Z-axis projection or a specific edge-normal axis. We follow the source order strictly.)*

4.  **Z-Axis Edge Tests:**
    - If `axis_test_z12(e0)` returns true, return `false`.
    - If `axis_test_z01(e1)` returns true, return `false`.
    - If `axis_test_z12(e2)` returns true, return `false`.

5.  **Max Coordinate Bounds Check:**
    Compute the maximum extent of the box:
    $$\text{max} = \text{voxel\_center} + \text{half\_box\_size}$$
    Check if all X coordinates of the triangle vertices are greater than or equal to `max.x`, OR all Y coordinates are $\ge$ `max.y`, OR all Z coordinates are $\ge$ `max.z`.
    If any of these conditions are true, the triangle is completely outside the box on the positive side. Return `false` [S1, unofficial].

6.  **Min Coordinate Bounds Check:**
    Compute the minimum extent of the box:
    $$\text{min} = \text{voxel\_center} - \text{half\_box\_size}$$
    Check if all X coordinates of the triangle vertices are less than or equal to `min.x`, OR all Y coordinates are $\le$ `min.y`, OR all Z coordinates are $\le$ `min.z`.
    If any of these conditions are true, the triangle is completely outside the box on the negative side. Return `false` [S1, unofficial].

7.  **Conclusion:**
    If all tests pass, return `true` [S1, unofficial].

**Pseudocode:**

```python
def face_in_hexahedron(face, voxel_center, half_box_size):
    # Step 1: Plane Test
    e1 = face[2] - face[1]
    e2 = face[0] - face[2]
    normal = cross(e1, e2)
    d = -dot(normal, face[0])
    
    # Check plane-box overlap. 
    # Implementation detail: The source assumes a helper `plane_box_overlap` exists.
    # This helper typically checks if the box center is within distance 
    # (half_box_size dot |normal|) from the plane.
    if not plane_box_overlap(normal, d, voxel_center, half_box_size):
        return False

    # Step 2: X-Axis Edge Tests
    e0 = face[1] - face[0]
    if axis_test_x02(e0): return False
    if axis_test_x02(e1): return False
    if axis_test_x01(e2): return False

    # Step 3: Y-Axis Edge Tests
    if axis_test_y02(e0): return False
    if axis_test_y02(e1): return False
    if axis_test_z01(e2): return False # Source lists this here; likely a specific SAT axis test

    # Step 4: Z-Axis Edge Tests
    if axis_test_z12(e0): return False
    if axis_test_z01(e1): return False
    if axis_test_z12(e2): return False

    # Step 5: Max Bounds Check
    max_extent = voxel_center + half_box_size
    if all_greater_equal_than([face[0].x, face[1].x, face[2].x], max_extent.x):
        return False
    if all_greater_equal_than([face[0].y, face[1].y, face[2].y], max_extent.y):
        return False
    if all_greater_equal_than([face[0].z, face[1].z, face[2].z], max_extent.z):
        return False

    # Step 6: Min Bounds Check
    min_extent = voxel_center - half_box_size
    if all_smaller_equal_than([face[0].x, face[1].x, face[2].x], min_extent.x):
        return False
    if all_smaller_equal_than([face[0].y, face[1].y, face[2].y], min_extent.y):
        return False
    if all_smaller_equal_than([face[0].z, face[1].z, face[2].z], min_extent.z):
        return False

    # Step 7: All tests passed
    return True

# Helper functions assumed to be defined elsewhere or standard:
# plane_box_overlap, axis_test_*, all_greater_equal_than, all_smaller_equal_than
# Note: The specific logic for axis_test_* functions is not detailed in the source,
# but they represent Separating Axis Theorem checks for specific edge projections.
```

**Edge Cases and Pitfalls:**
- **Degenerate Triangles:** If the triangle is degenerate (area zero), the normal vector will be zero. The plane test may behave unpredictably depending on the implementation of `plane_box_overlap`. [G] A guard for zero-length normal should be added.
- **Precision:** Floating-point comparisons in bounds checks (`all_greater_equal_than`) may suffer from precision errors near the box boundaries. [G] Epsilon tolerance is often required in practice.
- **Source Ambiguity:** The source lists `axis_test_z01(e2)` in the Y-axis block and `axis_test_z12` in the Z-axis block. The naming convention suggests the first letter indicates the axis of separation or projection, but the source's grouping is specific. Implementers should verify the exact separating axes intended by the original author if high precision is required.

## Operating characteristics
- **Time Complexity:** Constant time $O(1)$ relative to the triangle size (fixed 3 vertices) and box size. The number of operations is fixed based on the number of edge tests and bounds checks.
- **Memory Complexity:** $O(1)$ auxiliary space.
- **Measured Performance:** Not given in the sources.
- **Strengths:** Provides a strict containment check, which is useful for voxelization where only fully contained geometry needs to be processed or marked.
- **Limitations:** More computationally expensive than a simple AABB-triangle intersection test because it checks for full containment rather than just overlap.
- **When to use:** When the application requires determining if a triangle is completely inside a voxel (e.g., for conservative rasterization or specific voxelization algorithms).
- **When not to use:** When a simple intersection test (overlap) is sufficient, or when performance is critical and approximate containment is acceptable.
