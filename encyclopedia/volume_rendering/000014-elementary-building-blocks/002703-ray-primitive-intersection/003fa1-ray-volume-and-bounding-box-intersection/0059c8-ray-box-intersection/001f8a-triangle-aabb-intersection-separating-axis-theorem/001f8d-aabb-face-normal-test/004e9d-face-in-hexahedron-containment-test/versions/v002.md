# Face-in-Hexahedron Containment Test

## Overview
Determines if a triangle face is fully contained within a voxel's bounding box (hexahedron) by verifying plane overlap and checking for separation along multiple axes [S1, unofficial]. It returns `true` only when the entire triangle lies inside the box, providing a strict containment check rather than a broader intersection test [S1, unofficial].

## How it works
**Inputs:**
- `face`: Array of 3 vertices, each a 3D vector $(x, y, z)$ [S1, unofficial].
- `voxel_center`: 3D vector representing the center of the axis-aligned bounding box (AABB) [S1, unofficial].
- `half_box_size`: 3D vector representing the half-extents of the AABB along each axis [S1, unofficial].

**Outputs:**
- Boolean: `true` if the triangle is fully contained within the hexahedron, `false` otherwise [S1, unofficial].

**Data Structures:**
- Vectors are standard 3D Cartesian coordinates [G].
- No special bit-packing is required for the inputs [G].

**Steps:**

1. **Plane Test:**
   Compute edge vectors:
   $$e_1 = \text{face}[2] - \text{face}[1]$$
   $$e_2 = \text{face}[0] - \text{face}[2]$$
   Compute the triangle normal:
   $$n = e_1 \times e_2$$
   Define the triangle plane equation $n \cdot p + d = 0$, where:
   $$d = -n \cdot \text{face}[0]$$
   Check if the triangle plane overlaps with the AABB [S1, unofficial]. If the plane does not overlap the box, return `false` [S1, unofficial].

2. **X-Axis Edge Tests:**
   Compute edge $e_0 = \text{face}[1] - \text{face}[0]$ [S1, unofficial].
   Perform separation tests along axes derived from $e_0, e_1, e_2$ projected onto the X-axis [S1, unofficial].
   - If `axis_test_x02(e0)` returns true, return `false` [S1, unofficial].
   - If `axis_test_x02(e1)` returns true, return `false` [S1, unofficial].
   - If `axis_test_x01(e2)` returns true, return `false` [S1, unofficial].

3. **Y-Axis Edge Tests:**
   - If `axis_test_y02(e0)` returns true, return `false` [S1, unofficial].
   - If `axis_test_y02(e1)` returns true, return `false` [S1, unofficial].
   - If `axis_test_y01(e2)` returns true, return `false` [S1, unofficial]. *(Note: The source lists `axis_test_z01(e2)` in this block, which is treated as a typographical error for `axis_test_y01(e2)` based on the naming convention and standard SAT structure [G].)*

4. **Z-Axis Edge Tests:**
   - If `axis_test_z12(e0)` returns true, return `false` [S1, unofficial].
   - If `axis_test_z01(e1)` returns true, return `false` [S1, unofficial].
   - If `axis_test_z12(e2)` returns true, return `false` [S1, unofficial].

5. **Max Coordinate Bounds Check:**
   Compute the maximum extent of the box:
   $$\text{max} = \text{voxel\_center} + \text{half\_box\_size}$$
   Check if all X coordinates of the triangle vertices are greater than or equal to `max.x`, OR all Y coordinates are $\ge$ `max.y`, OR all Z coordinates are $\ge$ `max.z` [S1, unofficial]. If any condition is true, return `false` [S1, unofficial].

6. **Min Coordinate Bounds Check:**
   Compute the minimum extent of the box:
   $$\text{min} = \text{voxel\_center} - \text{half\_box\_size}$$
   Check if all X coordinates of the triangle vertices are less than or equal to `min.x`, OR all Y coordinates are $\le$ `min.y`, OR all Z coordinates are $\le$ `min.z` [S1, unofficial]. If any condition is true, return `false` [S1, unofficial].

7. **Conclusion:**
   If all tests pass, return `true` [S1, unofficial].

**Pseudocode:**
```python
def face_in_hexahedron(face, voxel_center, half_box_size):
    # Step 1: Plane Test
    e1 = face[2] - face[1]
    e2 = face[0] - face[2]
    normal = cross(e1, e2)
    d = -dot(normal, face[0])
    if not plane_box_overlap(normal, d, voxel_center, half_box_size):
        return False

    # Step 2: X-Axis Edge Tests
    e0 = face[1] - face[0]
    if axis_test_x02(e0, voxel_center, half_box_size): return False
    if axis_test_x02(e1, voxel_center, half_box_size): return False
    if axis_test_x01(e2, voxel_center, half_box_size): return False

    # Step 3: Y-Axis Edge Tests
    if axis_test_y02(e0, voxel_center, half_box_size): return False
    if axis_test_y02(e1, voxel_center, half_box_size): return False
    if axis_test_y01(e2, voxel_center, half_box_size): return False

    # Step 4: Z-Axis Edge Tests
    if axis_test_z12(e0, voxel_center, half_box_size): return False
    if axis_test_z01(e1, voxel_center, half_box_size): return False
    if axis_test_z12(e2, voxel_center, half_box_size): return False

    # Step 5: Max Bounds Check
    max_extent = voxel_center + half_box_size
    if all_greater_equal_than([face[0].x, face[1].x, face[2].x], max_extent.x): return False
    if all_greater_equal_than([face[0].y, face[1].y, face[2].y], max_extent.y): return False
    if all_greater_equal_than([face[0].z, face[1].z, face[2].z], max_extent.z): return False

    # Step 6: Min Bounds Check
    min_extent = voxel_center - half_box_size
    if all_smaller_equal_than([face[0].x, face[1].x, face[2].x], min_extent.x): return False
    if all_smaller_equal_than([face[0].y, face[1].y, face[2].y], min_extent.y): return False
    if all_smaller_equal_than([face[0].z, face[1].z, face[2].z], min_extent.z): return False

    return True

# Standard SAT helper definitions [G]
def cross(a, b):
    return (a.y*b.z - a.z*b.y, a.z*b.x - a.x*b.z, a.x*b.y - a.y*b.x)

def dot(a, b):
    return a.x*b.x + a.y*b.y + a.z*b.z

def plane_box_overlap(normal, d, center, half_size):
    r = half_size.x*abs(normal.x) + half_size.y*abs(normal.y) + half_size.z*abs(normal.z)
    return abs(dot(normal, center) + d) <= r

def axis_test_x02(e, center, half_size): return test_cross_axis(e, (1,0,0), center, half_size)
def axis_test_x01(e, center, half_size): return test_cross_axis(e, (1,0,0), center, half_size)
def axis_test_y02(e, center, half_size): return test_cross_axis(e, (0,1,0), center, half_size)
def axis_test_y01(e, center, half_size): return test_cross_axis(e, (0,1,0), center, half_size)
def axis_test_z12(e, center, half_size): return test_cross_axis(e, (0,0,1), center, half_size)
def axis_test_z01(e, center, half_size): return test_cross_axis(e, (0,0,1), center, half_size)

def test_cross_axis(edge, axis, center, half_size):
    sep_axis = cross(edge, axis)
    if dot(sep_axis, sep_axis) < 1e-9: return False
    r = half_size.x*abs(sep_axis.x) + half_size.y*abs(sep_axis.y) + half_size.z*abs(sep_axis.z)
    min_proj = min(dot(sep_axis, v) for v in face)
    max_proj = max(dot(sep_axis, v) for v in face)
    return min_proj > r or max_proj < -r

def all_greater_equal_than(coords, val):
    return all(c >= val for c in coords)

def all_smaller_equal_than(coords, val):
    return all(c <= val for c in coords)
```

**Edge Cases and Pitfalls:**
- **Degenerate Triangles:** If the triangle is degenerate (area zero), the normal vector will be zero and cross-product axes may vanish [G]. A guard for zero-length normal or degenerate separating axes should be added [G].
- **Precision:** Floating-point comparisons in bounds checks and SAT projections may suffer from precision errors near box boundaries [G]. Epsilon tolerance is often required in practice [G].

## Operating characteristics
- **Time Complexity:** Constant time $O(1)$ relative to the triangle size and box size, as the number of operations is fixed [G].
- **Memory Complexity:** $O(1)$ auxiliary space [G].
- **Measured Performance:** Not given in the sources.
- **Strengths:** Provides a strict containment check, which is useful for voxelization where only fully contained geometry needs to be processed or marked [G].
- **Limitations:** More computationally expensive than a simple AABB-triangle intersection test because it checks for full containment rather than just overlap [G].
- **When to use:** When the application requires determining if a triangle is completely inside a voxel (e.g., for conservative rasterization or specific voxelization algorithms) [G].
- **When not to use:** When a simple intersection test (overlap) is sufficient, or when performance is critical and approximate containment is acceptable [G].
