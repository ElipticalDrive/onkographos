# Silhouette-Based Bounding Box Estimation

Also called: Visual Hull, shape-from-silhouette

## Overview
Silhouette-Based Bounding Box Estimation computes a 3D volume that strictly encloses a target object by intersecting the back-projected foreground regions from multiple binary segmentation masks [S1, unofficial]. It differs from [Octree-based Bounding Volume Computation](6270-octree-based-bounding-volume-computation.md) by relying solely on 2D image masks rather than hierarchical spatial partitioning [S1, unofficial].

## How it works
**Inputs:**
*   `train_cameras`: Array of camera poses (extrinsics) and intrinsics for $N$ training views [S2, unofficial].
*   `masks`: Array of binary foreground-background segmentation masks, one per view [S1, unofficial].
*   `silhouetteRadius`: Scalar expansion radius for the final bounds [S2, unofficial].
*   `skipIndex`/`skips`: Optional indices and strides for subsampling views [S2, unofficial].

**Outputs:**
*   `scene.bbox_depth_min/max`, `scene.bbox_width_min/max`, `scene.bbox_height_min/max`: The final axis-aligned bounding box coordinates [S2, unofficial].

**Data Structures:**
*   **Mask**: Binary array of size $H \times W$, where 1 indicates foreground and 0 indicates background [S1, unofficial].
*   **Camera Pose**: $4 \times 4$ matrix containing rotation and translation; S2 uses camera-to-world or world-to-camera conventions [S2, unofficial].
*   **Voxel Grid**: Optional intermediate representation; S1 uses a $400 \times 400 \times 400$ voxel grid to store the hull [S1, unofficial].

**Steps:**
1.  **Initialize Bounds**: Set global minimums ($x_{min}, y_{min}, z_{min}$) to $+\infty$ and maximums ($x_{max}, y_{max}, z_{max}$) to $-\infty$ [S2, unofficial].
2.  **Iterate Views**: Loop through each training view, applying `skipIndex`/`skips` if provided [S2, unofficial].
3.  **Extract Mask**: Retrieve the binary mask $M_i$ for view $i$ [S1, unofficial]. Masks are derived from alpha channels if available, or via background separation (e.g., OpenCV for white backgrounds) or segmentation models [S1, unofficial].
4.  **Backproject Silhouette**: For each pixel $(u, v)$ in $M_i$ where $M_i[u, v] == 1$, construct the ray $r$ originating from the camera center $C_i$ and passing through the pixel using camera intrinsics [S1, unofficial]. The ray represents a cone of possible object locations [S1, unofficial].
5.  **Accumulate Volume**: Backproject mask pixels into 3D space and accumulate 3D points or mark voxels along the rays [S2, unofficial]. S1 implements this by casting rays into a coarse voxel grid and marking intersected voxels as occupied [S1, unofficial].
6.  **Compute Min/Max**: Determine the bounding box enclosing all accumulated 3D points or occupied voxels along the X, Y, and Z axes [S2, unofficial].
7.  **Expand Bounds**: Apply `silhouetteRadius` to the computed bounds to account for discretization and ensure the object is fully contained [S2, unofficial].
8.  **Store**: Write the final bounds to `scene.bbox_depth_min/max`, `scene.bbox_width_min/max`, `scene.bbox_height_min/max` [S2, unofficial].

**Pseudocode:**
```python
def compute_silhouette_bbox(train_cameras, masks, silhouette_radius, max_depth=10.0, skip_index=None):
    """
    Computes a bounding box enclosing the visual hull of an object.
    Args:
        train_cameras: List of dicts with 'intrinsics' (3x3), 'extrinsics' (4x4 W2C).
        masks: List of 2D binary arrays (H, W).
        silhouette_radius: Float expansion factor.
        max_depth: Float, maximum ray length for point accumulation.
        skip_index: Optional list of view indices.
    Returns:
        dict: {'bbox_min': [x, y, z], 'bbox_max': [x, y, z]}
    """
    global_min = [float('inf'), float('inf'), float('inf')]
    global_max = [float('-inf'), float('-inf'), float('-inf')]
    
    indices = skip_index if skip_index is not None else range(len(train_cameras))
    
    for i in indices:
        cam = train_cameras[i]
        mask = masks[i]
        
        K = cam['intrinsics']
        R = [row[:3] for row in cam['extrinsics']]
        t = [cam['extrinsics'][j][3] for j in range(3)]
        
        # Camera center in world space: C_w = -R^T * t
        C_w = [-sum(R[j][k] * t[k] for k in range(3)) for j in range(3)]
        inv_K = invert_3x3(K)
        
        foreground_pixels = [(u, v) for v in range(len(mask)) for u in range(len(mask[0])) if mask[v][u] > 0]
        
        for u, v in foreground_pixels:
            # Ray direction in camera space: d_cam = inv_K * [u, v, 1]
            d_cam = [
                inv_K[0][0]*u + inv_K[0][1]*v + inv_K[0][2],
                inv_K[1][0]*u + inv_K[1][1]*v + inv_K[1][2],
                inv_K[2][0]*u + inv_K[2][1]*v + inv_K[2][2]
            ]
            
            # Transform direction to world space: d_w = R^T * d_cam
            d_w = [
                R[0][0]*d_cam[0] + R[1][0]*d_cam[1] + R[2][0]*d_cam[2],
                R[0][1]*d_cam[0] + R[1][1]*d_cam[1] + R[2][1]*d_cam[2],
                R[0][2]*d_cam[0] + R[1][2]*d_cam[1] + R[2][2]*d_cam[2]
            ]
            
            # Normalize direction
            norm = (d_w[0]**2 + d_w[1]**2 + d_w[2]**2)**0.5
            d_w = [d / norm for d in d_w]
            
            # Accumulate points along the ray up to max_depth
            for depth in range(1, int(max_depth) + 1):
                point = [C_w[j] + depth * d_w[j] for j in range(3)]
                for j in range(3):
                    if point[j] < global_min[j]: global_min[j] = point[j]
                    if point[j] > global_max[j]: global_max[j] = point[j]
                    
    global_min = [m - silhouette_radius for m in global_min]
    global_max = [m + silhouette_radius for m in global_max]
    
    return {'bbox_min': global_min, 'bbox_max': global_max}

def invert_3x3(M):
    inv_det = 1.0 / (M[0][0]*(M[1][1]*M[2][2]-M[1][2]*M[2][1]) - M[0][1]*(M[1][0]*M[2][2]-M[1][2]*M[2][0]) + M[0][2]*(M[1][0]*M[2][1]-M[1][1]*M[2][0]))
    return [
        [(M[1][1]*M[2][2]-M[1][2]*M[2][1])*inv_det, (M[0][2]*M[2][1]-M[0][1]*M[2][2])*inv_det, (M[0][1]*M[1][2]-M[0][2]*M[1][1])*inv_det],
        [(M[1][2]*M[2][0]-M[1][0]*M[2][2])*inv_det, (M[0][0]*M[2][2]-M[0][2]*M[2][0])*inv_det, (M[0][2]*M[1][0]-M[0][0]*M[1][2])*inv_det],
        [(M[1][0]*M[2][1]-M[1][1]*M[2][0])*inv_det, (M[0][1]*M[2][0]-M[0][0]*M[2][1])*inv_det, (M[0][0]*M[1][1]-M[0][1]*M[1][0])*inv_det]
    ]
```

**Parameters:**
*   `silhouetteRadius`: Expansion radius to ensure the object is fully contained [S2, unofficial]. Typical value: Not given in the sources.
*   `skipIndex`: Indices of views to skip for subsampling [S2, unofficial].
*   `voxelResolution`: S1 uses $400 \times 400 \times 400$ [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Non-Convex Shapes**: The visual hull cannot restore dented parts (undercuts) of non-convex shapes, but it never overcuts and contains 100% of the object [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: $O(N \cdot P)$, where $N$ is the number of views and $P$ is the number of foreground pixels or voxels processed [S1, unofficial]. S1 notes it can fit 100 images in about 10 seconds using JAX [S1, unofficial].
*   **Memory Complexity**: $O(V)$ for voxel-based implementation, where $V$ is the number of voxels (e.g., $400^3$) [S1, unofficial].
*   **Performance**: Provides a 2-8x speedup in NeRF training by eliminating unnecessary network evaluations outside the hull [S1, unofficial].
*   **Strengths**: Fast, simple, guarantees the object is fully contained (100% recall) [S1, unofficial].
*   **Limitations**: Cannot represent concavities; requires accurate segmentation masks [S1, unofficial].

## Background
*   **Origin**: Visual Hull is a classic 3D reconstruction technique based on shape-from-silhouette [S1, unofficial].
*   **History**: It predates NeRF and has been applied in many classic 3D reconstruction contexts [S1, unofficial].
*   **Usage**: Recently revisited in VaxNeRF to accelerate NeRF training by providing a coarse in-out field separation [S1, unofficial].
