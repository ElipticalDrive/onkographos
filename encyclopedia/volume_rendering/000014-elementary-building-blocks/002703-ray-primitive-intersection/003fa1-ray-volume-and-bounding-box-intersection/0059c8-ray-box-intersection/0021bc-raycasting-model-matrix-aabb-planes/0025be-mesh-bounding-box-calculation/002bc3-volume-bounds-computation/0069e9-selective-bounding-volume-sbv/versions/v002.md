# Selective Bounding Volume (SBV)
## Overview
Selective Bounding Volume (SBV) is a 3D extension of the 2D bounding box method used to identify and extract a Volume of Interest (VOI) from a 3D medical image by ignoring blank slices and confining coordinates to active portions [S1]. It sets itself apart from shape-adaptive methods by refusing to discard any active portions in any slices, thereby preserving clinically significant background details that other methods might remove [S1].
## How it works
**Inputs and Outputs:**
- Input: A 3D medical image $X$ with dimensions $[x, y, z]$ (width, height, depth) [S1].
- Output: An extracted sub-volume $VOI$ containing only the active region [S1].

**Data Structures:**
- `temp_coordinates`: An array of 4 integers $[x_1, x_2, x_3, x_4]$ initialized to zero. These store the bounding box coordinates $(min\_row, min\_col, max\_row, max\_col)$ for each non-blank slice [S1].
- `RowMin`, `ColumnMin`, `RowMax`, `ColumnMax`: Integer variables storing the global minimum and maximum coordinates across all active slices [S1].
- `z1`, `z2`: Integer indices marking the first and last non-zero slices [S1].

**Steps:**
1. **Get Dimensions:** Determine the size of the input image $X$ as $[x, y, z]$ [S1].
2. **Initialize:** Declare `RowMin`, `ColumnMin`, `RowMax`, `ColumnMax` as integers [S1]. Initialize `temp_coordinates` $[x_1, x_2, x_3, x_4]$ to $[0, 0, 0, 0]$ [S1].
3. **Identify Active Z-Range:** Iterate through all $z$-slices to search for zero-intensity (blank) slices [S1]. Identify $z_1$ as the index of the first non-zero slice and $z_2$ as the index of the last non-zero slice [S1]. Blank slices at the foremost and end of the volume are ignored to prevent them from affecting the bounding volume calculation [S1].
4. **Compute Slice Bounding Boxes:** For each slice $z$ from $z_1$ to $z_2$: Apply 2D bounding box operations on the slice to find its local active region [S1]. Update `temp_coordinates` with the local bounding box coordinates $[x_1, x_2, x_3, x_4]$ for that slice [S1].
5. **Compute Global Bounds:** Determine the global bounding box by taking the minimum and maximum of the accumulated coordinates: $RowMin = \min(x_1)$, $ColumnMin = \min(x_2)$, $RowMax = \max(x_3)$, $ColumnMax = \max(x_4)$, where the min/max functions operate over all slices from $z_1$ to $z_2$ [S1].
6. **Extract VOI:** Iterate through the volume using the global bounds: For $k$ from $z_1$ to $z_2$, for $i$ from $RowMin$ to $RowMax$, for $j$ from $ColumnMin$ to $ColumnMax$, assign $VOI \leftarrow X(i, j, k)$ [S1].

**Pseudocode:**
```python
def selective_bounding_volume(X):
    # X is a 3D array of shape (depth, height, width)
    # Step 1: Get dimensions
    z_dim, y_dim, x_dim = len(X), len(X[0]), len(X[0][0])

    # Step 2: Initialize
    # temp_coordinates stores [min_row, min_col, max_row, max_col] for each active slice
    temp_coordinates = []
    z1 = None
    z2 = None

    # Step 3: Identify active Z-range
    for k in range(z_dim):
        if not is_blank_slice(X[k]):
            if z1 is None:
                z1 = k
            z2 = k

    if z1 is None:
        return None

    # Step 4: Compute slice bounding boxes
    for k in range(z1, z2 + 1):
        box = compute_2d_bounding_box(X[k])
        temp_coordinates.append(box)

    # Step 5: Compute global bounds
    # x1=min_row, x2=min_col, x3=max_row, x4=max_col
    all_x1 = [b[0] for b in temp_coordinates]
    all_x2 = [b[1] for b in temp_coordinates]
    all_x3 = [b[2] for b in temp_coordinates]
    all_x4 = [b[3] for b in temp_coordinates]

    RowMin = min(all_x1)
    ColumnMin = min(all_x2)
    RowMax = max(all_x3)
    ColumnMax = max(all_x4)

    # Step 6: Extract VOI
    out_z = z2 - z1 + 1
    out_y = RowMax - RowMin + 1
    out_x = ColumnMax - ColumnMin + 1
    VOI = [[[0 for _ in range(out_x)] for _ in range(out_y)] for _ in range(out_z)]

    for k in range(z1, z2 + 1):
        for i in range(RowMin, RowMax + 1):
            for j in range(ColumnMin, ColumnMax + 1):
                VOI[k - z1][i - RowMin][j - ColumnMin] = X[k][i][j]

    return VOI

def is_blank_slice(slice_2d):
    return all(val == 0 for row in slice_2d for val in row)

def compute_2d_bounding_box(slice_2d):
    rows, cols = [], []
    for r, row in enumerate(slice_2d):
        for c, val in enumerate(row):
            if val != 0:
                rows.append(r)
                cols.append(c)
    if not rows:
        return [0, 0, 0, 0]
    return [min(rows), min(cols), max(rows), max(cols)]
```

**Edge Cases and Pitfalls:**
- **Blank Slices:** The method explicitly ignores blank slices (null image slices) at the foremost and end of the volume [S1]. If the entire volume is blank, the algorithm should handle the case where $z_1$ is never set [S1].
- **Active Portions:** Unlike shape-adaptive methods, SBV does not discard any active portions in any slices [S1]. This preserves clinically significant background details but may result in a larger bounding volume if the object is sparse within the active slices [S1].

## Background
**Origin:**
- The Selective Bounding Volume (SBV) method was proposed in the paper "On a hybrid lossless compression technique for three‐dimensional medical images" [S1].

**History and Development:**
- The method is described as a 3D extension of the Bounding Box method [S1]. It was developed to overcome issues with existing techniques that discarded non-object details [S1].

**Where it is Used:**
- 3D medical imaging, specifically for object detection and as a preprocessing step for lossless compression [S1].
