# Ray Point Sampling

Also called: Points Sampling

## Overview
Ray Point Sampling generates query points along camera rays for volume rendering by distributing samples within a defined spatial region, typically the scene's bounding box [S1][S2, unofficial]. It solves the problem of discretizing continuous ray paths into discrete evaluation locations for neural radiance fields or voxel grids [S1][S2, unofficial]. Unlike [Background Point Sampling](6423-background-point-sampling.md) which targets infinite space outside the scene, or [Uncertainty-guided Point Sampling](13488-uncertainty-guided-point-sampling.md) which targets high-error regions, this method provides a baseline uniform or importance-weighted distribution within the foreground volume [S1, S4]. It builds on [Ray-Bounding Box Intersection and Sampling Preparation](2364-ray-bounding-box-intersection-and-sampling-preparation.md) which computes the intersection bounds and step distances [S2, unofficial].

## How it works
**Inputs:**
- `rays_o`: Ray origins, shape $(N, 3)$, contiguous [S2, unofficial].
- `rays_d`: Ray directions, shape $(N, 3)$, contiguous [S2, unofficial].
- `xyz_min`: Bounding box minimum, shape $(3)$ [S2, unofficial].
- `xyz_max`: Bounding box maximum, shape $(3)$ [S2, unofficial].
- `near`: Near clipping distance, scalar [S2, unofficial].
- `far`: Far clipping distance, scalar. Set to $10^9$ [S2, unofficial].
- `stepsize`: Base step size, scalar [S2, unofficial].
- `voxel_size`: Voxel grid resolution size, scalar [S2, unofficial].
- `is_unbounded`: Boolean flag indicating if the scene is unbounded (e.g., DTU dataset) [S1].

**Outputs:**
- `ray_pts`: Sample points, shape $(N_{total}, 3)$ [S2, unofficial].
- `ray_id`: Ray indices for each point, shape $(N_{total})$ [S2, unofficial].
- `step_id`: Step indices for each point, shape $(N_{total})$ [S2, unofficial].
- `mask_inbbox`: Boolean mask for points inside the bounding box [S2, unofficial].

**Data Structures:**
- Points are stored in a flat array `ray_pts` with fields `x, y, z` (float32).
- `ray_id` and `step_id` are integer arrays mapping each point to its source ray and sequential step index.

**Parameters:**
- `stepdist = stepsize * voxel_size` [S2, unofficial].
- Uniform samples per ray: 64 [S1].
- Importance samples per ray: 32 [S1].
- Unbounded extra samples: 32 [S1].
- Maximum batch size: $512 \times 64 \times 32$ points [S1].

**Steps:**
1. Ensure `rays_o` and `rays_d` are contiguous in memory [S2, unofficial].
2. Calculate the effective step distance:
   $$ stepdist = stepsize \times voxel\_size $$
3. Sample points using a CUDA kernel `sample_pts_on_rays` with inputs `rays_o`, `rays_d`, `xyz_min`, `xyz_max`, `near`, `far`, and `stepdist` [S2, unofficial]. This kernel returns:
   - `ray_pts`: Raw sample positions.
   - `mask_outbbox`: Boolean mask for points outside the bounding box.
   - `ray_id`: Ray identifiers.
   - `step_id`: Step identifiers.
   - `N_steps`: Number of steps per ray.
   - `t_min`, `t_max`: Intersection distances [S2, unofficial].
4. Filter points inside the bounding box:
   $$ mask\_inbbox = \neg mask\_outbbox $$
5. Apply `mask_inbbox` to `ray_pts`, `ray_id`, and `step_id` to discard out-of-bounds points [S2, unofficial].
6. Return the filtered `ray_pts`, `ray_id`, and `step_id` [S2, unofficial].

**Pseudocode:**
```python
def ray_point_sampling(rays_o, rays_d, xyz_min, xyz_max, near, far, stepsize, voxel_size, is_unbounded):
    # Ensure contiguous memory layout for CUDA kernel
    rays_o = torch.as_tensor(rays_o, dtype=torch.float32, device='cuda').contiguous()
    rays_d = torch.tensor(rays_d, dtype=torch.float32, device='cuda').contiguous()
    
    # Calculate effective step distance
    stepdist = stepsize * voxel_size
    
    # Call CUDA kernel to sample points
    # Returns: ray_pts, mask_outbbox, ray_id, step_id, N_steps, t_min, t_max
    ray_pts, mask_outbbox, ray_id, step_id, N_steps, t_min, t_max = \
        sample_pts_on_rays_cuda(rays_o, rays_d, xyz_min, xyz_max, near, far, stepdist)
    
    # Filter points inside bounding box
    mask_inbbox = ~mask_outbbox
    
    # Apply mask
    ray_pts = ray_pts[mask_inbbox]
    ray_id = ray_id[mask_inbbox]
    step_id = step_id[mask_inbbox]
    
    return ray_pts, ray_id, step_id
```

**Edge Cases:**
- If the scene is unbounded (e.g., DTU), 32 additional points are sampled in contracted space [S1].
- Precision issues may arise if `far` is set too large ($10^9$) relative to `near`, affecting depth precision [S2, unofficial].

## Subtopics

### Fine-stage Points Sampling
Filters out rays that do not intersect known free space. Adjusts near- and far-bounds ($t_{near}, t_{far}$) to the endpoints of the ray-box intersection. Does not adjust $t_{near}$ if the ray origin $x_0$ is already inside the BBox [S3].

### Edge Sample Retrieval
Retrieves samples lying on an edge defined by two vertices by filtering samples based on their distance from the ray origin. Calculates distances from vertices $v_1, v_2$ to ray origin. Iterates through samples, adding those where $dist(v_1, R.origin) \le dist(s.position, R.origin) \le dist(v_2, R.origin)$ [S4].

### [Random Point Sampling in Bounds](3914-random-point-sampling-in-bounds.md)
Generates uniformly distributed random points within a specified 3D AABB. Solves the problem of initializing ray origins or query points for volume rendering and neural field training by ensuring spatial coverage without bias. Unlike Background Point Sampling or Uncertainty-guided Point Sampling, this method provides a baseline uniform distribution.

### [Background Point Sampling](6423-background-point-sampling.md)
Generates sample points along rays for background regions (outside the scene's bounding box). Employs a non-uniform sampling distribution controlled by a `bg_preserve` parameter to balance between uniform angular and radial sampling. Distinct from sibling methods by targeting the infinite background region with a distribution adapting to ray geometry.

### [Uncertainty-guided Point Sampling](13488-uncertainty-guided-point-sampling.md)
Selects 2D coordinates within bounding boxes by prioritizing regions of high prediction uncertainty. Oversamples points randomly, selects a fraction via an uncertainty function, and fills the remainder with random points.

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of rays and samples per ray. The CUDA kernel `sample_pts_on_rays` is parallelized across rays [S2, unofficial].
- **Memory Complexity:** Proportional to the total number of sample points. Maximum batch size is $512 \times 64 \times 32$ points [S1].
- **Performance:** Efficient for large-scale volume rendering due to GPU acceleration [S2, unofficial].
- **Strengths:** Simple, uniform coverage of the foreground volume [S1].
- **Limitations:** May waste samples in empty space if not combined with free-space skipping [S3].

## Background
Originated in the context of neural radiance fields and volume rendering, specifically in implementations like ref-dvgo [S2, unofficial] and Volumetric Surfaces [S1]. The method is used to discretize rays for querying neural networks or voxel grids [S1][S2, unofficial].
