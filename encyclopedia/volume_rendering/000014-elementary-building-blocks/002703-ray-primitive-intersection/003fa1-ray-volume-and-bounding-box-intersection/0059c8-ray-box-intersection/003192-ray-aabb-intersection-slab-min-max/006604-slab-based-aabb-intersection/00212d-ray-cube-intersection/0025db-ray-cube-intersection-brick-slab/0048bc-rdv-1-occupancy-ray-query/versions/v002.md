# RDV-1 Occupancy Ray Query

Also called: occupancy-only ray query, toroidal brick buffer ray march

## Overview
The RDV-1 Occupancy Ray Query is an occupancy-only ray tracing method designed for a toroidal brick buffer voxel grid [S1, unofficial]. It traces a ray through the voxel space to locate the first occupied voxel, returning the voxel coordinates, surface normal, distance, and step counts [S1, unofficial]. It operates across the entire grid rather than a single brick, and supports arbitrary ray origins and distances outside the brick boundary [G].

## How it works
**Inputs and Outputs**
*   **Input:** A `BbvRay` struct containing `origin` (`float3`), `maxDistance` (`float`), `direction` (`float3`), and `rayId` (`uint`) [S1, unofficial].
*   **Output:** A `BbvResult` struct containing `voxel` (`int3`), `hit` (`uint`), `normal` (`int3`), `padding` (`uint`), `distance` (`float`), `voxelSteps` (`uint`), `brickLookups` (`uint`), and `padding2` (`uint`) [S1, unofficial].

**Data Structures**
The method relies on global constants and specific struct layouts [S1, unofficial]:
*   `gMinimumBrick` (`int3`): Minimum brick coordinate in the grid [S1, unofficial].
*   `gGridDimensions` (`int3`): Dimensions of the brick grid [S1, unofficial].
*   `gToroidalOffset` (`int3`): Offset applied for toroidal wrapping of brick indices [S1, unofficial].
*   `gMaximumSteps` (`uint`): Maximum number of voxel steps allowed per ray trace [S1, unofficial].
*   `gRayCount` (`uint`): Total number of rays dispatched to the kernel [S1, unofficial].
*   **Brick Buffer Layout:** Each brick occupies exactly 64 bytes [S1, unofficial]. The occupancy data uses DVE's authoritative indexing scheme `x + 8*y + 64*z` rather than InstantRDV's subbrick/Morton wire format [S1, unofficial].

**Algorithm Steps**
1.  **Validation:** Compute the magnitude of the ray direction [S1, unofficial]. If `magnitude <= 0.0f` or `maxDistance < 0.0f`, return an empty `BbvResult` and exit [S1, unofficial].
2.  **Normalization and Bounds:** Normalize the direction [S1, unofficial]. Compute grid bounds: `gridMin = float3(gMinimumBrick) * 8.0f` and `gridMax = float3(gMinimumBrick + gGridDimensions) * 8.0f` [S1, unofficial]. Initialize `entry = 0.0f`, `exit = ray.maxDistance`, and `normal = int3(0,0,0)` [S1, unofficial].
3.  **Axis Intersection:** For each axis ($x, y, z$): if `direction[axis] == 0.0f`, check if `origin[axis]` is outside `[gridMin[axis], gridMax[axis])`; if outside, return an empty result, otherwise continue [S1, unofficial]. Compute $t_0$ and $t_1$ slab intersections [S1, unofficial]. Update `entry`: if $\min(t_0, t_1) > \text{entry}$, set `entry = min(t0, t1)` and set `normal[axis]` to $-1$ or $1$ based on the sign of `direction[axis]` [S1, unofficial]. Update `exit`: set `exit = max(t0, t1)` [S1, unofficial].
4.  **Entry Validation and Offset:** If `entry > exit`, return an empty result [S1, unofficial]. Compute the sample offset: `sampleT = entry + max(abs(entry) * 1.1920929e-7f, 1.0e-5f)` if `entry > 0.0f`, else `0.0f` [S1, unofficial]. Clamp the sample position: `p = clamp(ray.origin + direction * sampleT, gridMin, gridMax - 1.0e-4f)` [S1, unofficial]. Set the initial voxel: `voxel = int3(floor(p))` [S1, unofficial].
5.  **Ray Marching Loop:** Initialize `t = entry` [S1, unofficial]. Loop up to `min(gMaximumSteps, 65536u)` iterations while `t <= exit` [S1, unofficial]. Increment `voxelSteps` [S1, unofficial]. If `voxel` is outside grid bounds, break [S1, unofficial]. Call `IsOccupied(voxel, result.brickLookups)` [S1, unofficial]. If occupied, set `result.hit = 1`, `result.voxel = voxel`, `result.normal = normal`, `result.distance = t`, and break [S1, unofficial]. Compute next boundary crossings `nextT` [S1, unofficial]. Find the axis with the minimum `nextT` [S1, unofficial]. If `next > exit` or `next + 1.0e-5f < t`, break [S1, unofficial]. Update `t = max(t, next)` [S1, unofficial]. Advance `voxel[axis]` by $\delta$ ($1$ or $-1$) [S1, unofficial]. Update `normal` for the new axis [S1, unofficial].

**Formulas**
*   **Grid Bounds:** $\text{gridMin} = \text{float3}(gMinimumBrick) \times 8.0$, $\text{gridMax} = \text{float3}(gMinimumBrick + gGridDimensions) \times 8.0$ [S1, unofficial].
*   **Sample Offset:** $\text{sampleT} = \begin{cases} \text{entry} + \max(|\text{entry}| \times 1.1920929 \times 10^{-7}, 1.0 \times 10^{-5}) & \text{if } \text{entry} > 0.0 \\ 0.0 & \text{otherwise} \end{cases}$ [S1, unofficial].
*   **Brick Index:** $\text{logical} = \text{key} - gMinimumBrick$, $\text{physical} = \text{logical} + gToroidalOffset$, $\text{index} = \text{physical}.x + gGridDimensions.x \times (\text{physical}.y + gGridDimensions.y \times \text{physical}.z)$ [S1, unofficial].
*   **Bit Position:** $\text{local} = \text{voxel} - \text{key} \times 8$, $\text{bit} = \text{local}.x + 8 \times \text{local}.y + 64 \times \text{local}.z$ [S1, unofficial].
*   **Occupancy Test:** $\text{word} = gBbvBricks.\text{Load}(\text{index} \times 64 + (\text{bit} \gg 5) \times 4)$, return $(\text{word} \ \& \ (1 \ll (\text{bit} \ \& \ 31))) \neq 0$ [S1, unofficial].
*   **Next Boundary:** $\text{NextBoundary}(o, d, v) = \begin{cases} \frac{v + 1 - o}{d} & \text{if } d > 0 \\ \frac{v - o}{d} & \text{if } d < 0 \end{cases}$ [G].

**Parameters**
*   `gMinimumBrick`: Not given in the sources.
*   `gGridDimensions`: Not given in the sources.
*   `gToroidalOffset`: Not given in the sources.
*   `gMaximumSteps`: Not given in the sources.
*   `gRayCount`: Not given in the sources.

**Edge Cases and Pitfalls**
*   **Zero Direction Components:** If a direction component is zero, explicit bounds checking is required for that axis; otherwise the ray may incorrectly pass through the grid or cause division by zero [S1, unofficial].
*   **Precision at Origin:** The entry point offset uses `max(abs(entry) * 1.1920929e-7f, 1.0e-5f)` to avoid self-intersection or precision issues when the ray starts inside or very close to a voxel [S1, unofficial].
*   **Infinite Loops:** The step advancement includes a check `next + 1.0e-5f < t` to prevent infinite loops or stuck steps due to floating-point rounding errors at voxel boundaries [S1, unofficial].

**Pseudocode**
```python
def rdv1_occupancy_query(ray, gMinimumBrick, gGridDimensions, gToroidalOffset, gMaximumSteps, gBbvBricks):
    # 1. Validation
    mag = ray.direction.length()
    if mag <= 0.0 or ray.maxDistance < 0.0:
        return BbvResult()

    # 2. Normalization and Bounds
    dir = ray.direction.normalized()
    gridMin = Vec3(gMinimumBrick) * 8.0
    gridMax = Vec3(gMinimumBrick + gGridDimensions) * 8.0
    entry = 0.0
    exit_t = ray.maxDistance
    normal = Int3(0, 0, 0)

    # 3. Axis Intersection
    for axis in (0, 1, 2):
        if dir[axis] == 0.0:
            if not (gridMin[axis] <= ray.origin[axis] < gridMax[axis]):
                return BbvResult()
            continue
        t0 = (gridMin[axis] - ray.origin[axis]) / dir[axis]
        t1 = (gridMax[axis] - ray.origin[axis]) / dir[axis]
        if t0 > t1:
            t0, t1 = t1, t0
        if t0 > entry:
            entry = t0
            normal[axis] = 1 if dir[axis] > 0 else -1
        if t1 < exit_t:
            exit_t = t1

    # 4. Entry Validation and Offset
    if entry > exit_t:
        return BbvResult()

    sampleT = entry + max(abs(entry) * 1.1920929e-7, 1.0e-5) if entry > 0.0 else 0.0
    p = clamp(ray.origin + dir * sampleT, gridMin, gridMax - 1.0e-4)
    voxel = Int3(floor(p.x), floor(p.y), floor(p.z))

    # 5. Ray Marching Loop
    t = entry
    result = BbvResult()
    result.brickLookups = 0
    max_iter = min(gMaximumSteps, 65536)

    for _ in range(max_iter):
        result.voxelSteps += 1
        if not (gridMin.x <= voxel.x < gridMax.x and gridMin.y <= voxel.y < gridMax.y and gridMin.z <= voxel.z < gridMax.z):
            break

        result.brickLookups += 1
        if is_occupied(voxel, gMinimumBrick, gGridDimensions, gToroidalOffset, gBbvBricks):
            result.hit = 1
            result.voxel = voxel
            result.normal = normal
            result.distance = t
            return result

        # Next boundary crossings
        nextT = Vec3(0.0, 0.0, 0.0)
        for axis in (0, 1, 2):
            if dir[axis] == 0.0:
                nextT[axis] = float('inf')
            else:
                boundary = voxel[axis] + (1.0 if dir[axis] > 0 else 0.0)
                nextT[axis] = (boundary - ray.origin[axis]) / dir[axis]

        min_axis = nextT.argmin()
        next_val = nextT[min_axis]

        if next_val > exit_t or next_val + 1.0e-5 < t:
            break

        t = max(t, next_val)
        voxel[min_axis] += 1 if dir[min_axis] > 0 else -1
        normal[min_axis] = 1 if dir[min_axis] > 0 else -1

    return result

def is_occupied(voxel, gMinimumBrick, gGridDimensions, gToroidalOffset, gBbvBricks):
    key = Int3(voxel.x // 8, voxel.y // 8, voxel.z // 8)
    logical = key - gMinimumBrick
    physical = logical + gToroidalOffset
    index = physical.x + gGridDimensions.x * (physical.y + gGridDimensions.y * physical.z)
    local = voxel - key * 8
    bit = local.x + 8 * local.y + 64 * local.z
    word = gBbvBricks.load(index * 64 + (bit >> 5) * 4)
    return (word & (1 << (bit & 31))) != 0
```

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of voxels traversed, capped by `gMaximumSteps` and 65536 [S1, unofficial].
*   **Memory Complexity:** Constant relative to traversal depth, dependent on the brick buffer size determined by `gGridDimensions` [S1, unofficial].
*   **Measured Performance:** Not given in the sources.
*   **Strengths:** Efficient for sparse grids due to occupancy-only checks; toroidal wrapping simplifies boundary handling for certain grid topologies [S1, unofficial].
*   **Limitations:** Limited to occupancy queries (no shading or density integration); not used by production render passes yet [S1, unofficial].
*   **When to Use:** When only the first hit in a voxel grid is needed, and the grid uses the DVE brick buffer format [S1, unofficial].
*   **When Not to Use:** When density values, normals from geometry, or full ray-marching integration are required [G].

## Background
The RDV-1 Occupancy Ray Query is part of the Destructible Voxel Engine (DVE) implementation [S1, unofficial]. It is an independent kernel, opt-in, and was not used by production render passes at the time of the source documentation [S1, unofficial]. It builds on the principles of ray-box intersection and Amanatides-Woo DDA, adapted for a toroidal brick buffer layout [G].
