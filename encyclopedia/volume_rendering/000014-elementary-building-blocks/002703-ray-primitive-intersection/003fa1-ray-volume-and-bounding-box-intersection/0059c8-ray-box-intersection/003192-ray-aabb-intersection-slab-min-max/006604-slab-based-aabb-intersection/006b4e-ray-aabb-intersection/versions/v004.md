# Ray-AABB Intersection

Also called: Slab Method, Min-Max Method, AABB Ray Intersection

## Overview
The AABB Ray Intersection method computes the entry ($t_{min}$) and exit ($t_{max}$) distances of a ray against an Axis-Aligned Bounding Box (AABB), returning a boolean hit status [S3, S8, unofficial]. It solves the fundamental problem of determining whether a ray intersects a volume primitive and, if so, the interval along the ray parameter $t$ where the intersection occurs [S3, unofficial]. It is distinguished from its siblings by its reliance on the "slab" method (computing intersections with min/max planes per axis) [S6] and its common implementation as a batched kernel for GPU acceleration [S1, unofficial], whereas [Ray-Bounding Box Intersection and Sampling Preparation](2364-ray-bounding-box-intersection-and-sampling-preparation.md) focuses on sampling preparation and [Ray-Cube Intersection](2466-ray-cube-intersection.md) assumes unit cubes.

## How it works
**Inputs and Outputs:**
*   **Inputs:**
    *   Ray origins: $\mathbf{o} \in \mathbb{R}^{N \times 3}$ [S1, S3, unofficial].
    *   Ray directions: $\mathbf{d} \in \mathbb{R}^{N \times 3}$ [S1, S3, unofficial].
    *   AABBs: $\mathbf{B} \in \mathbb{R}^{M \times 6}$, where each row is $[x_{min}, y_{min}, z_{min}, x_{max}, y_{max}, z_{max}]$ [S1, S3, unofficial].
*   **Outputs:**
    *   $t_{min} \in \mathbb{R}^{N \times M}$: Entry distances.
    *   $t_{max} \in \mathbb{R}^{N \times M}$: Exit distances.
    *   $hit \in \{0, 1\}^{N \times M}$: Boolean intersection mask [S1, unofficial].

**Data Structures:**
*   **VolumeRange (Optional):** A data structure containing fields $t_0$ (entry), $t_1$ (exit), and $intersected$ (boolean mask), all with shape $[batch\_size, *shape, 1]$ [S3, unofficial].

**Parameters:**
*   $\epsilon$: Small value to prevent division by zero (default $10^{-6}$) [S3, unofficial].
*   $min\_dist$: Minimum allowed value for $t_0$ (default $0.0$) [S3, unofficial].
*   $min\_t\_range$: Minimum step size for valid intersection (default $10^{-3}$) [S3, unofficial].
*   $near\_plane$: Clamping lower bound for $t_{min}$ (often $0.0$ during inference) [S2, unofficial].

**Steps:**
1.  **Compute Direction Fractions:** To avoid division by zero, compute the reciprocal of the ray direction components:
    $$ \mathbf{f} = \frac{1}{\mathbf{d} + \epsilon} $$
    where $\epsilon$ is a small constant (e.g., $10^{-6}$) [S2, unofficial].
2.  **Compute Slab Intersections:** For each axis $i \in \{x, y, z\}$, calculate the intersection distances with the min and max planes of the AABB. Let $\mathbf{B}_{min} = [x_{min}, y_{min}, z_{min}]$ and $\mathbf{B}_{max} = [x_{max}, y_{max}, z_{max}]$.
    $$ t_{i,1} = (\mathbf{B}_{min}[i] - \mathbf{o}[i]) \cdot \mathbf{f}[i] $$
    $$ t_{i,2} = (\mathbf{B}_{max}[i] - \mathbf{o}[i]) \cdot \mathbf{f}[i] $$
    This yields six values per ray-AABB pair: $t_{x,1}, t_{x,2}, t_{y,1}, t_{y,2}, t_{z,1}, t_{z,2}$ [S2, unofficial].
3.  **Determine Entry and Exit:**
    *   The entry distance $t_{min}$ is the maximum of the minimums along each axis:
        $$ t_{min} = \max_{i \in \{x,y,z\}} (\min(t_{i,1}, t_{i,2})) $$
    *   The exit distance $t_{max}$ is the minimum of the maximums along each axis:
        $$ t_{max} = \min_{i \in \{x,y,z\}} (\max(t_{i,1}, t_{i,2})) $$
    [S2, S3, unofficial].
4.  **Apply Constraints and Clamping:**
    *   Clamp $t_{min}$ to be at least $min\_dist$ (typically $0.0$) to handle rays starting inside the box or behind the origin [S3, unofficial].
    *   Clamp $t_{min}$ to the $near\_plane$ [S2, unofficial].
    *   Ensure $t_{max} > t_{min}$ by at least a small margin (e.g., $10^{-6}$) to prevent degenerate intervals [S2, unofficial].
    *   If a lower bound $t_{0,lower}$ is provided (e.g., from a previous traversal step), update $t_{min} = \max(t_{min}, t_{0,lower})$ [S3, unofficial].
5.  **Determine Hit Status:**
    *   A ray intersects if $t_{min} + min\_t\_range < t_{max}$ [S3, unofficial].
    *   If not intersected, set $t_{min}$ and $t_{max}$ to a miss value (e.g., $-\infty$ or a specific flag) [S1, S5, unofficial].

**Edge Cases and Pitfalls:**
*   **Zero Direction Component:** If $d_i = 0$, the ray is parallel to the slab planes. Adding $\epsilon$ prevents division by zero, and the min/max operations correctly handle the resulting large values for axis-aligned boxes [S2, S8, unofficial].
*   **Ray Origin Inside Box:** If the ray starts inside the AABB, $t_{min}$ becomes negative. Clamping to $min\_dist \ge 0$ treats the entry point as the origin offset [S3, unofficial].
*   **Miss Condition:** If $t_{min} > t_{max}$, the ray passes through the gap between slabs and misses the box [S7, unofficial].
*   **Precision:** Degenerate intersections occur when $t_{max} \le t_{min} + \epsilon$. Enforcing a minimum step range ($min\_t\_range$) prevents invalid sampling intervals [S3, unofficial].

**Pseudocode:**

```python
def ray_aabb_intersect(rays_o, rays_d, aabbs, epsilon=1e-6, min_dist=0.0, min_t_range=1e-3):
    """
    rays_o: list of [N, 3]
    rays_d: list of [N, 3]
    aabbs: list of [M, 6] -> [x_min, y_min, z_min, x_max, y_max, z_max]
    Returns: t_min [N, M], t_max [N, M], hit [N, M]
    """
    N = len(rays_o)
    M = len(aabbs)
    t_min = [[0.0] * M for _ in range(N)]
    t_max = [[0.0] * M for _ in range(N)]
    hit = [[False] * M for _ in range(N)]

    for i in range(N):
        o = rays_o[i]
        d = rays_d[i]
        inv_d = [1.0 / (d[j] + epsilon) for j in range(3)]
        for k in range(M):
            b = aabbs[k]
            b_min = b[:3]
            b_max = b[3:]
            # Compute slab intersections
            t1 = [(b_min[j] - o[j]) * inv_d[j] for j in range(3)]
            t2 = [(b_max[j] - o[j]) * inv_d[j] for j in range(3)]
            # Entry: max of mins along each axis
            entry = max(t1[j] if t1[j] < t2[j] else t2[j] for j in range(3))
            # Exit: min of maxs along each axis
            exit_dist = min(t1[j] if t1[j] > t2[j] else t2[j] for j in range(3))
            # Clamp entry to min_dist
            entry = entry if entry > min_dist else min_dist
            # Ensure valid interval margin
            exit_dist = exit_dist if exit_dist > entry + 1e-6 else entry + 1e-6
            # Check hit status
            is_hit = (entry + min_t_range < exit_dist)
            hit[i][k] = is_hit
            t_min[i][k] = entry if is_hit else -1e10
            t_max[i][k] = exit_dist if is_hit else -1e10
    return t_min, t_max, hit
```

## Subtopics

### [Ray-AABB Intersection (PyTorch)](14346-ray-aabb-intersection-pytorch.md)
A pure PyTorch implementation of the slab method that computes near and far clipping distances for rays against a scene box. It is functionally identical to the CUDA-accelerated version but executes slower on CPU or via PyTorch's autograd engine. It serves as the fallback or training-compatible intersection primitive in neural rendering pipelines where GPU kernel compilation is unavailable or dynamic shapes require eager execution.

## Operating characteristics
*   **Performance:** Highly parallelizable on GPUs. Batched implementations (e.g., processing chunks of rays) are used to avoid out-of-memory errors when $N$ is large [S4, unofficial].
*   **Strengths:** Fast, branchless when implemented with vector operations, handles arbitrary AABB sizes [S6].
*   **Limitations:** Does not handle rotated boxes. Precision issues can arise if ray directions are near-zero without epsilon handling [S2, unofficial].
*   **Complexity:** Not given in the sources.

## Background
The method is used in neural rendering pipelines (NeRF, SDFStudio) for ray-box intersection [S1, unofficial][S3, unofficial]. Batching strategies to limit memory usage are adapted from implementations in [S4, unofficial].
