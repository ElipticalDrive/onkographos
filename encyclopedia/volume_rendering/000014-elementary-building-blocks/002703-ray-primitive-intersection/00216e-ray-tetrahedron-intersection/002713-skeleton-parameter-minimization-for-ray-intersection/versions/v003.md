# Skeleton Parameter Minimization for Ray Intersection

Also called: Inverted Minima Computation, Rational Function Root Finding for SCALIS

## Overview
This method computes the intersection of a ray with a Scale-Invariant Integral Surface (SCALIS) by minimizing the squared distance from the ray to the skeleton curve, normalized by the local radius, rather than solving the implicit surface equation directly [S1]. It replaces complex sphere-cone intersection logic with a robust root-finding procedure on a rational function, offering superior numerical stability and computational efficiency [S1].

## How it works
**Inputs:**
*   Ray origin $\mathbf{o}$ and direction $\mathbf{d}$ (unit vector) [S1].
*   Skeleton segment defined by endpoints $\mathbf{p}_0$ and $\mathbf{p}_1$, with radii $\tau_0$ and $\tau_1$ [S1].
*   Skeleton length $L = \|\mathbf{p}_1 - \mathbf{p}_0\|$ [S1].

**Outputs:**
*   The ray parameter $t_{min}$ corresponding to the closest intersection point [S1].
*   The skeleton parameter $s_{min} \in [0, L]$ where the minimum occurs [S1].

**Data Structures:**
*   Vectors $\mathbf{m}, \mathbf{u}, \mathbf{d}, \mathbf{m}_{\perp}, \mathbf{u}_{\perp}$ are 3D floating-point vectors [S1].
*   Scalars $b, c, s_{cand}, s_{min}, t_{min}, \tau(s)$ are floating-point numbers [S1].

**Definitions:**
*   $\mathbf{u} = \mathbf{p}_1 - \mathbf{p}_0$ is the skeleton direction vector [S1].
*   $\Delta \tau = \tau_1 - \tau_0$ is the radius change along the segment [S1].
*   $\mathbf{m} = \mathbf{p}_0 - \mathbf{o}$ is the vector from the ray origin to the skeleton start point [S1].
*   The skeleton point at parameter $s$ is $\mathbf{p}(s) = \mathbf{p}_0 + \frac{s}{L}\mathbf{u}$ [S1].
*   The radius at parameter $s$ is $\tau(s) = \tau_0 + \frac{s}{L}\Delta \tau$ [S1].
*   $d_{\mathbf{r}}(\mathbf{p}(s))$ is the perpendicular distance from the ray to the point $\mathbf{p}(s)$ [S1].

**Steps:**

1.  **Precompute Geometric Terms:**
    Compute the projection of $\mathbf{m}$ onto the ray direction $\mathbf{d}$:
    $$ \mathbf{m}_{\perp} = \mathbf{m} - (\mathbf{m}^T \mathbf{d}) \mathbf{d} $$
    This vector $\mathbf{m}_{\perp}$ represents the component of $\mathbf{m}$ orthogonal to the ray [S1].

2.  **Compute Coefficients for the Linear Equation:**
    Calculate the coefficients $b$ and $c$ for the linear equation $bs + c = 0$, which arises from setting the derivative of the objective function to zero [S1]:
    $$ b = \tau_0 L^2 (1 - (\mathbf{u}^T \mathbf{d})^2) - \Delta \tau L \mathbf{u}^T \mathbf{m}_{\perp} $$
    $$ c = \Delta \tau \|\mathbf{m}_{\perp}\|^2 + \tau_0 L \mathbf{u}^T \mathbf{m}_{\perp} $$

3.  **Find Candidate Minimum:**
    If $|b| > \epsilon$ (where $\epsilon$ is a small tolerance for numerical stability, e.g., $10^{-9}$), solve for the critical point $s_{cand}$:
    $$ s_{cand} = -\frac{c}{b} $$
    If $|b| \le \epsilon$, the derivative does not vanish within the interval (or is constant), so no internal critical point exists [S1]. Set $s_{cand}$ to `None`.

4.  **Evaluate Candidates:**
    The global minimum of the objective function $f(s) = \frac{d_{\mathbf{r}}^2(\mathbf{p}(s))}{\tau(s)^2}$ must occur either at the boundaries $s=0$ or $s=L$, or at the internal critical point $s_{cand}$ if it lies within $[0, L]$ [S1].
    
    Define the objective function value at any $s$:
    $$ f(s) = \frac{\|\mathbf{m}_{\perp} + \frac{s}{L}\mathbf{u}_{\perp}\|^2}{\tau(s)^2} $$
    where $\mathbf{u}_{\perp} = \mathbf{u} - (\mathbf{u}^T \mathbf{d}) \mathbf{d}$ is the component of the skeleton direction orthogonal to the ray [S1]. Note that $\|\mathbf{m}_{\perp} + \frac{s}{L}\mathbf{u}_{\perp}\|^2$ is the squared distance from the ray to $\mathbf{p}(s)$ [S1].
    
    Evaluate $f(s)$ at:
    *   $s=0$
    *   $s=L$
    *   $s=s_{cand}$ (only if $0 \le s_{cand} \le L$) [S1].
    
    Select the $s$ value that yields the minimum $f(s)$ [S1]. Let this be $s_{min}$.

5.  **Compute Ray Intersection Parameter:**
    The closest point on the skeleton is $\mathbf{p}(s_{min})$ [S1]. The ray parameter $t_{min}$ is found by projecting $\mathbf{p}(s_{min})$ onto the ray:
    $$ t_{min} = (\mathbf{p}(s_{min}) - \mathbf{o}) \cdot \mathbf{d} $$
    [S1].

**Pseudocode:**

```python
def dot(a, b):
    return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]

def norm(v):
    return (v[0]**2 + v[1]**2 + v[2]**2)**0.5

def skeleton_param_minimization(ray_o, ray_d, p0, p1, tau0, tau1):
    """
    Finds the ray parameter t_min for intersection with a SCALIS primitive
    defined by a linear skeleton segment.
    
    Args:
        ray_o: 3D vector, ray origin
        ray_d: 3D vector, ray direction (assumed unit length)
        p0: 3D vector, skeleton start point
        p1: 3D vector, skeleton end point
        tau0: float, radius at p0
        tau1: float, radius at p1
        
    Returns:
        t_min: float, ray parameter of closest intersection
        s_min: float, skeleton parameter of closest point
    """
    L = norm(p1 - p0)
    if L < 1e-9:
        # Degenerate skeleton (point) [G]
        m = p0 - ray_o
        proj = dot(m, ray_d)
        return proj, 0.0

    u = p1 - p0
    delta_tau = tau1 - tau0
    m = p0 - ray_o
    
    u_dot_d = dot(u, ray_d)
    m_dot_d = dot(m, ray_d)
    
    u_perp = u - u_dot_d * ray_d
    m_perp = m - m_dot_d * ray_d
    
    u_dot_m_perp = dot(u, m_perp)
    
    term1 = tau0 * (L**2) * (1 - (u_dot_d**2))
    term2 = delta_tau * L * u_dot_m_perp
    b = term1 - term2
    
    m_perp_norm_sq = dot(m_perp, m_perp)
    term3 = delta_tau * m_perp_norm_sq
    term4 = tau0 * L * u_dot_m_perp
    c = term3 + term4
    
    s_min = 0.0
    min_f = float('inf')
    
    def eval_f(s):
        tau_s = tau0 + (s / L) * delta_tau
        if tau_s < 1e-9:
            return float('inf') [G]
        p_s = p0 + (s / L) * u
        m_s = p_s - ray_o
        m_s_perp = m_s - dot(m_s, ray_d) * ray_d
        dist_sq = dot(m_s_perp, m_s_perp)
        return dist_sq / (tau_s**2)

    f0 = eval_f(0.0)
    if f0 < min_f:
        min_f = f0
        s_min = 0.0
        
    fL = eval_f(L)
    if fL < min_f:
        min_f = fL
        s_min = L
        
    if abs(b) > 1e-9:
        s_cand = -c / b
        if 0.0 <= s_cand <= L:
            fcand = eval_f(s_cand)
            if fcand < min_f:
                min_f = fcand
                s_min = s_cand
                
    p_s_min = p0 + (s_min / L) * u
    t_min = dot(p_s_min - ray_o, ray_d)
    
    return t_min, s_min
```

**Edge Cases and Pitfalls:**
*   **Degenerate Skeleton:** If $L \approx 0$, the skeleton is a point [G].
*   **Zero Radius:** If $\tau(s) \approx 0$, the objective function diverges [G].
*   **Numerical Stability:** The source notes that this approach is more numerically stable than solving the implicit equation directly, which involves finding scaling factors for sphere-cone intersections [S1].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per primitive [S1].
*   **Memory Complexity:** $O(1)$ auxiliary space [G].
*   **Strengths:** Avoids iterative root-finding or complex geometric primitives (spheres/cones) [S1].
*   **Limitations:** Assumes linear skeleton segments and linearly varying radii [S1].
*   **When to use:** When rendering SCALIS fields with linear skeleton primitives [S1].

## Background
This method was introduced in the context of ray tracing Scale-Invariant Integral Surfaces (SCALIS) [S1]. SCALIS fields are defined by a skeleton curve and a radius field, representing smooth, tubular structures [S1]. The method inverts the order of minimization: instead of finding the ray parameter $t$ for a fixed skeleton parameter $s$, it finds the skeleton parameter $s$ that minimizes the normalized distance, then derives $t$ [S1]. This avoids the complexity of handling sphere-cone intersections inherent in the direct formulation [S1].
