# Skeleton Parameter Minimization for Ray Intersection

Also called: Inverted Minima Computation, Rational Function Root Finding for SCALIS

## Overview
This method computes the intersection of a ray with a Scale-Invariant Integral Surface (SCALIS) primitive by minimizing the squared distance from the ray to the skeleton curve, normalized by the local radius, rather than solving the implicit surface equation directly [S1]. It sets itself apart from direct sphere-cone intersection approaches by reducing the problem to finding the root of a linear equation, offering superior numerical stability and lower computational cost [S1].

## How it works
**Inputs and Outputs**
*   **Input:** Ray origin $\mathbf{o}$, ray direction $\mathbf{d}$ (normalized), skeleton segment endpoints $\mathbf{p}_0, \mathbf{p}_1$, skeleton segment radius at start $\tau_0$, and radius change $\Delta \tau$ over the segment length $L = \|\mathbf{p}_1 - \mathbf{p}_0\|$.
*   **Output:** The ray parameter $t_{min}$ corresponding to the closest intersection point on the SCALIS surface.

**Data Structures**
No complex data structures are required. The method operates on scalar values and 3D vectors.

**Steps**
1.  **Define Geometry:**
    Let $\mathbf{u} = \mathbf{p}_1 - \mathbf{p}_0$ be the skeleton direction vector.
    Let $\mathbf{m} = \mathbf{p}_0 - \mathbf{o}$ be the vector from the ray origin to the skeleton start point.
    The skeleton point at parameter $s \in [0, L]$ is $\mathbf{p}(s) = \mathbf{p}_0 + s \frac{\mathbf{u}}{L}$.
    The radius at parameter $s$ is $\tau(s) = \tau_0 + s \frac{\Delta \tau}{L}$.

2.  **Define Objective Function:**
    Minimize the rational function $f(s)$ representing the squared distance from the ray to the skeleton point, normalized by the squared radius:
    $$ f(s) = \frac{d_{\mathbf{r}}^2(\mathbf{p}(s))}{\tau(s)^2} $$
    where $d_{\mathbf{r}}(\mathbf{p})$ is the perpendicular distance from point $\mathbf{p}$ to the ray. The squared distance is given by:
    $$ d_{\mathbf{r}}^2(\mathbf{p}(s)) = \| (\mathbf{m} + s \frac{\mathbf{u}}{L}) - ((\mathbf{m} + s \frac{\mathbf{u}}{L})^T \mathbf{d}) \mathbf{d} \|^2 $$

3.  **Compute Derivative Coefficients:**
    Find the critical points by setting the derivative $f'(s) = 0$. This results in a linear equation $b s + c = 0$. The coefficients $b$ and $c$ are calculated as follows:
    $$ b = \tau_0 L^2 (1 - (\mathbf{u}^T \mathbf{d})^2) - \Delta \tau L \mathbf{u}^T (\mathbf{m} - (\mathbf{m}^T \mathbf{d}) \mathbf{d}) $$
    $$ c = \Delta \tau \|\mathbf{m} - (\mathbf{m}^T \mathbf{d}) \mathbf{d}\|^2 + \tau_0 L \mathbf{u}^T (\mathbf{m} - (\mathbf{m}^T \mathbf{d}) \mathbf{d}) $$
    *Note: The term $\mathbf{m} - (\mathbf{m}^T \mathbf{d}) \mathbf{d}$ represents the projection of $\mathbf{m}$ onto the plane perpendicular to $\mathbf{d}$.*

4.  **Solve for Candidate Minimum:**
    If $b \neq 0$, compute the candidate parameter:
    $$ s_{cand} = -\frac{c}{b} $$
    If $b = 0$, there is no internal critical point (the function is monotonic or constant), so $s_{cand}$ is undefined.

5.  **Determine Global Minimum:**
    Evaluate $f(s)$ at the boundaries $s=0$ and $s=L$.
    If $s_{cand}$ exists and $0 < s_{cand} < L$, evaluate $f(s_{cand})$.
    Select the $s_{min}$ that yields the smallest value of $f(s)$ among the valid candidates (boundaries and internal critical point).

6.  **Compute Ray Parameter:**
    Calculate the skeleton point $\mathbf{p}(s_{min})$.
    Project $\mathbf{p}(s_{min})$ orthogonally onto the ray to find $t_{min}$:
    $$ t_{min} = \mathbf{p}(s_{min})^T \mathbf{d} $$
    [G] Ensure $t_{min}$ is non-negative if the ray is treated as a half-ray; otherwise, clamp or reject based on application requirements.

**Pseudocode**
```python
def skeleton_param_minimization(ray_o, ray_d, p0, p1, tau0, delta_tau):
    """
    ray_o: 3D vector, ray origin
    ray_d: 3D vector, normalized ray direction
    p0: 3D vector, skeleton start point
    p1: 3D vector, skeleton end point
    tau0: float, radius at p0
    delta_tau: float, change in radius from p0 to p1
    """
    L = length(p1 - p0)
    if L == 0:
        return None  # Degenerate segment

    u = (p1 - p0) / L  # Unit skeleton direction
    m = p0 - ray_o     # Vector from ray origin to skeleton start

    # Precompute projection of m onto plane perpendicular to ray_d
    # proj_m_perp = m - (m . d) * d
    m_dot_d = dot(m, ray_d)
    m_perp = m - ray_d * m_dot_d

    # Precompute projection of u onto plane perpendicular to ray_d
    # proj_u_perp = u - (u . d) * d
    u_dot_d = dot(u, ray_d)
    u_perp = u - ray_d * u_dot_d

    # Coefficient b
    # b = tau0 * L^2 * (1 - (u . d)^2) - delta_tau * L * (u . m_perp)
    term1 = tau0 * (L ** 2) * (1 - (u_dot_d ** 2))
    term2 = delta_tau * L * dot(u, m_perp)
    b = term1 - term2

    # Coefficient c
    # c = delta_tau * ||m_perp||^2 + tau0 * L * (u . m_perp)
    norm_m_perp_sq = dot(m_perp, m_perp)
    term3 = delta_tau * norm_m_perp_sq
    term4 = tau0 * L * dot(u, m_perp)
    c = term3 + term4

    # Evaluate f(s) helper
    # f(s) = ||m_perp + s * u_perp||^2 / (tau0 + s * delta_tau/L)^2
    def f(s):
        radius = tau0 + s * (delta_tau / L)
        if radius == 0:
            return float('inf')
        dist_sq = length_sq(m_perp + u_perp * s)
        return dist_sq / (radius ** 2)

    # Find s_min
    s_candidates = [0.0, L]
    
    if abs(b) > 1e-9: # Avoid division by zero
        s_cand = -c / b
        if 0 < s_cand < L:
            s_candidates.append(s_cand)
    
    # Evaluate and pick minimum
    best_s = s_candidates[0]
    min_val = f(best_s)
    
    for s in s_candidates[1:]:
        val = f(s)
        if val < min_val:
            min_val = val
            best_s = s

    # Compute intersection point on skeleton
    p_min = p0 + u * best_s
    
    # Project p_min onto ray to get t_min
    t_min = dot(p_min, ray_d)
    
    return t_min
```

**Parameters**
*   $L$: Length of the skeleton segment.
*   $\tau_0$: Radius at the start of the segment.
*   $\Delta \tau$: Total radius change over the segment.

**Edge Cases and Pitfalls**
*   **Degenerate Segment:** If $L=0$, the method is undefined. [G] Return early or handle as a sphere intersection.
*   **Zero Radius:** If $\tau(s) = 0$ within $[0, L]$, the function $f(s)$ has a pole. The sources state poles are not in the range of interest for valid SCALIS primitives, but numerically, if $\tau(s)$ approaches zero, precision issues may arise. [G] Check for near-zero radii and handle appropriately (e.g., clamp or reject).
*   **Numerical Stability:** The linear equation approach is preferred over solving the implicit surface equation (Equation 16 in [S1]) because the latter involves finding scaling factors for sphere-cone intersections, which is computationally heavier and less numerically stable [S1].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per primitive. The method involves a constant number of vector operations and a single linear solve.
*   **Memory Complexity:** $O(1)$ auxiliary memory.
*   **Strengths:** Numerically stable, computationally efficient, avoids complex geometric logic for sphere-cone intersections [S1].
*   **Limitations:** Specific to SCALIS primitives defined by linear skeleton segments with linearly varying radii. Not directly applicable to general implicit surfaces without adaptation.
*   **When to use:** When rendering SCALIS volumes where performance and stability are critical.
*   **When not to use:** For primitives that do not fit the SCALIS model or when higher-order skeleton curves are used.

## Background
This method originates from the work on Fast Ray Tracing of Scale-Invariant Integral Surfaces (SCALIS) [S1]. It was developed to address the computational cost and numerical instability associated with direct intersection methods for SCALIS primitives, which involve sphere-cone intersections. The approach inverts the minimization order, focusing on the skeleton parameter first.
