# Monocular Depth Predictor with Distribution Sampling

Also called: DepthPredictorMonocular

## Overview
A neural network module that predicts a depth distribution for each ray from image features, sampling discrete depth values and probability density function (PDF) values to represent surface geometry [S1, unofficial]. It explicitly models multiple surfaces and uses a distribution sampler for stochastic depth estimation, building on the differentiable forward/backward pass of [Differentiable Depth Function Forward/Backward Pass](1047-differentiable-depth-function-forward-backward-pass.md) [G].

## How it works
**Inputs:**
- `features`: Tensor of shape `(batch, view, ray, channel)` representing image features [S1, unofficial].
- `near`: Tensor of shape `(batch, view)` specifying the near plane distance [S1, unofficial].
- `far`: Tensor of shape `(batch, view)` specifying the far plane distance [S1, unofficial].
- `deterministic`: Boolean flag controlling sampling behavior [S1, unofficial].
- `gaussians_per_pixel`: Integer specifying the number of Gaussian samples per pixel [S1, unofficial].

**Outputs:**
- `depth`: Tensor of shape `(batch, view, ray, surface, sample)` containing sampled depth values [S1, unofficial].
- `pdf`: Tensor of shape `(batch, view, ray, surface, sample)` containing the probability density values for the sampled depths [S1, unofficial].

**Data Structures:**
The class `DepthPredictorMonocular` contains the following fields:
- `projection`: An `nn.Sequential` module [S1, unofficial].
- `sampler`: A `DistributionSampler` instance [S1, unofficial].
- `num_samples`: Integer, number of depth samples per surface [S1, unofficial].
- `num_surfaces`: Integer, number of distinct surfaces to model [S1, unofficial].
- `use_transmittance`: Boolean flag for transmittance usage [S1, unofficial].

**Steps:**
1. Initialize `self.projection` as an `nn.Sequential` containing `nn.ReLU()` followed by `nn.Linear(d_in, 2 * num_samples * num_surfaces)`, where `d_in` is the input channel dimension of `features` [S1, unofficial].
2. Initialize `self.sampler` as a `DistributionSampler` instance [S1, unofficial].
3. Initialize `self.to_pdf` as `nn.Softmax(dim=-1)` and `self.to_offset` as `nn.Sigmoid()` [S1, unofficial].
4. In the forward pass, pass `features` through `self.projection` to get raw logits of shape `(batch, view, ray, 2 * num_samples * num_surfaces)` [S1, unofficial].
5. Rearrange the projected features from shape `... (dpt srf c)` to `c ... srf dpt` where `c=2`, separating `pdf_raw` and `offset_raw`, with `dpt=num_samples` and `srf=num_surfaces` [S1, unofficial].
6. Apply softmax to `pdf_raw` along the last dimension to get normalized PDF values [S1, unofficial].
7. Apply sigmoid to `offset_raw` to get intra-bucket offsets [S1, unofficial].
8. Sample depth indices and PDF values using `self.sampler.sample(pdf, deterministic, gaussians_per_pixel)` [S1, unofficial].
9. Gather intra-bucket offsets corresponding to the sampled indices and compute final depth using near/far bounds and offsets [G].

**Pseudocode:**
```python
import torch
import torch.nn as nn

class DistributionSampler:
    def __init__(self):
        pass

    def sample(self, pdf, deterministic, gaussians_per_pixel):
        if deterministic:
            indices = torch.argmax(pdf, dim=-1, keepdim=True)
            sampled_pdf = pdf.gather(-1, indices)
        else:
            indices = torch.multinomial(pdf, gaussians_per_pixel, replacement=True)
            sampled_pdf = pdf.gather(-1, indices)
        return indices, sampled_pdf

class DepthPredictorMonocular(nn.Module):
    def __init__(self, d_in, num_samples, num_surfaces, use_transmittance=False):
        super().__init__()
        self.num_samples = num_samples
        self.num_surfaces = num_surfaces
        self.use_transmittance = use_transmittance
        self.projection = nn.Sequential(
            nn.ReLU(),
            nn.Linear(d_in, 2 * num_samples * num_surfaces)
        )
        self.sampler = DistributionSampler()
        self.to_pdf = nn.Softmax(dim=-1)
        self.to_offset = nn.Sigmoid()

    def forward(self, features, near, far, deterministic=False, gaussians_per_pixel=1):
        raw_logits = self.projection(features)
        b, v, r, c = raw_logits.shape
        raw_logits = raw_logits.view(b, v, r, 2, self.num_surfaces, self.num_samples)
        raw_logits = raw_logits.permute(3, 0, 1, 2, 4, 5)

        pdf_raw = raw_logits[0]
        offset_raw = raw_logits[1]

        pdf = self.to_pdf(pdf_raw)
        offset = self.to_offset(offset_raw)

        indices, sampled_pdf = self.sampler.sample(pdf, deterministic, gaussians_per_pixel)
        # [G] Gather intra-bucket offsets corresponding to sampled indices.
        offset = offset.gather(-1, indices)
        depth = near[..., None, None, None] + (far[..., None, None, None] - near[..., None, None, None]) * (indices.float() / self.num_samples) + offset

        return depth, sampled_pdf
```

**Parameters:**
- `num_samples`: Number of depth samples per surface [S1, unofficial].
- `num_surfaces`: Number of distinct surfaces to model [S1, unofficial].
- `use_transmittance`: Boolean flag for transmittance usage [S1, unofficial].
