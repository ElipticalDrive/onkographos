# Secant Method for Surface Depth Refinement

Also called: Linear Interpolation Root Finding for SDF, Secant Refinement

## Overview
The Secant Method for Surface Depth Refinement is an iterative root-finding algorithm used to refine the depth value $d$ where a signed distance function (SDF) or occupancy logit crosses a threshold [S1, unofficial]. It estimates the next intersection point using linear interpolation between two bracketing points, offering a faster convergence rate than bisection for smooth functions [S1, unofficial]. It sets itself apart from its sibling [Bisection Method for Surface Depth Refinement](1033-bisection-method-for-surface-depth-refinement.md) by using the slope between two points rather than the midpoint, and from [Neubauer's Ray-Voxel Intersection Algorithm](975-neubauer-s-ray-voxel-intersection-algorithm.md) by operating on continuous neural field evaluations rather than discrete voxel traversal [S1, unofficial].

## How it works
**Inputs:**
- $ray0$: Origin point of the ray (3D vector).
- $ray\_direction$: Direction vector of the ray (normalized).
- $d_{low}$: Array of lower bound depths (floats).
- $d_{high}$: Array of upper bound depths (floats).
- $f_{low}$: Array of function values at $d_{low}$ (floats).
- $f_{high}$: Array of function values at $d_{high}$ (floats).
- $n_{secant\_steps}$: Number of refinement iterations (integer).
- $decoder$: Function evaluating the neural field.
- $c$: Camera parameters or context for the decoder.
- $logit\_tau$: Threshold value for the occupancy logit.

**Outputs:**
- $d_{pred}$: Refined depth values where the root is estimated.

**Data Structures:**
- Arrays $d_{low}, d_{high}, f_{low}, f_{high}, d_{pred}$ are parallel vectors of size $N$ (number of rays), supporting batched processing.

**Steps:**
1. **Initialization**: Compute the initial prediction $d_{pred}$ for all rays using linear interpolation between the bracketing points:
   $$ d_{pred} = - f_{low} \cdot \frac{d_{high} - d_{low}}{f_{high} - f_{low}} + d_{low} $$
   [S1, unofficial]

2. **Iteration**: For each iteration $i$ from $0$ to $n_{secant\_steps} - 1$:
   a. **Ray Casting**: Compute the 3D point $p_{mid}$ for each ray:
      $$ p_{mid} = ray0 + d_{pred} \cdot ray\_direction $$
      [S1, unofficial]
   b. **Evaluation**: Evaluate the function $f_{mid}$ at $p_{mid}$. This involves calling the decoder with the point and context, subtracting the threshold, and disabling gradient tracking:
      $$ f_{mid} = decoder(p_{mid}, c, only\_occupancy=True) - logit\_tau $$
      [S1, unofficial]
   c. **Bracket Update**: Identify indices where $f_{mid} < 0$ as $ind_{low}$.
      - If $ind_{low}$ contains any true values, update the lower bracket:
        $$ d_{low}[ind_{low}] = d_{pred}[ind_{low}] $$
        $$ f_{low}[ind_{low}] = f_{mid}[ind_{low}] $$
        [S1, unofficial]
      - Identify indices where $f_{mid} \ge 0$ (i.e., $ind_{low} == 0$). If these exist, update the upper bracket:
        $$ d_{high}[ind_{low}==0] = d_{pred}[ind_{low}==0] $$
        $$ f_{high}[ind_{low}==0] = f_{mid}[ind_{low}==0] $$
        [S1, unofficial]
   d. **Recalculation**: Update $d_{pred}$ using the new bracketing values:
      $$ d_{pred} = - f_{low} \cdot \frac{d_{high} - d_{low}}{f_{high} - f_{low}} + d_{low} $$
      [S1, unofficial]

**Pseudocode:**
```python
def secant_refinement(ray0, ray_direction, d_low, d_high, f_low, f_high, 
                      n_secant_steps, decoder, c, logit_tau):
    """
    Refine surface depth using the Secant Method.
    
    Args:
        ray0: Tensor of shape (N, 3), ray origins.
        ray_direction: Tensor of shape (N, 3), ray directions.
        d_low: Tensor of shape (N,), lower depth bounds.
        d_high: Tensor of shape (N,), upper depth bounds.
        f_low: Tensor of shape (N,), function values at d_low.
        f_high: Tensor of shape (N,), function values at d_high.
        n_secant_steps: int, number of iterations.
        decoder: Function(p, c, only_occupancy=True) -> Tensor(N).
        c: Context/camera parameters.
        logit_tau: float, threshold.
        
    Returns:
        d_pred: Tensor of shape (N,), refined depths.
    """
    # Step 1: Initialize prediction
    # Avoid division by zero if f_high == f_low, though typically f_low < 0 < f_high
    denom = f_high - f_low
    # Guard against zero denominator [G]
    denom = torch.where(denom == 0, torch.ones_like(denom) * 1e-8, denom)
    d_pred = -f_low * ((d_high - d_low) / denom) + d_low
    
    for _ in range(n_secant_steps):
        # Step 2a: Compute 3D points
        p_mid = ray0 + d_pred.unsqueeze(1) * ray_direction.unsqueeze(0) # Broadcasting for (N, 3)
        
        # Step 2b: Evaluate function without gradients
        with torch.no_grad():
            f_mid = decoder(p_mid, c, only_occupancy=True) - logit_tau
            
        # Step 2c: Update brackets
        ind_low = f_mid < 0
        
        # Update lower bracket where f_mid < 0
        d_low[ind_low] = d_pred[ind_low]
        f_low[ind_low] = f_mid[ind_low]
        
        # Update upper bracket where f_mid >= 0
        ind_high = ~ind_low
        d_high[ind_high] = d_pred[ind_high]
        f_high[ind_high] = f_mid[ind_high]
        
        # Step 2d: Recalculate prediction
        denom = f_high - f_low
        denom = torch.where(denom == 0, torch.ones_like(denom) * 1e-8, denom)
        d_pred = -f_low * ((d_high - d_low) / denom) + d_low
        
    return d_pred
```

**Parameters:**
- $n_{secant\_steps}$: Integer specifying the number of refinement iterations. Typical value: 8 [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Division by Zero**: If $f_{high} == f_{low}$, the denominator in the interpolation formula becomes zero. A small epsilon or fallback to bisection is required [G].
- **Non-Bracketing**: The method assumes $f_{low} < 0$ and $f_{high} > 0$ (or vice versa). If the initial segment does not bracket a root, the method may diverge or converge to a non-root extremum [G].
- **Discontinuities**: The method assumes continuity. If the field function is discontinuous, the linear interpolation may yield inaccurate results compared to methods designed for discontinuities [S2, unofficial].

## Subtopics

### [Ray Marching with Secant Refinement](1042-ray-marching-with-secant-refinement.md)
A procedure to detect surface points along rays by evaluating a neural decoder at proposal points, identifying sign changes in occupancy logits, and refining the depth using the Secant Method for Surface Depth Refinement. It sets itself apart from its siblings by combining coarse uniform sampling with a specific sign-change detection logic that identifies negative-to-positive transitions, followed by the Secant Method for Surface Depth Refinement to pinpoint the zero-crossing. It builds on [Secant Method for Surface Depth Refinement](996-secant-method-for-surface-depth-refinement.md) [G].

### False Position Algorithm
A root-finding algorithm combining linear interpolation and the midpoint algorithm. It finds the exact intersection point even if the field function is not continuous [S2, unofficial]. Implementation is in `IsoMesher::intersect_xaxis()`, `IsoMesher::intersect_yaxis()`, and `IsoMesher::intersect_zaxis()`. The algorithm used is determined by the preprocessor symbol `FALSE_POSITION` [S2, unofficial]. It is no worse than the midpoint algorithm in terms of iterations and usually better, making it the preferred choice for finding exact intersection points [S2, unofficial].

## Operating characteristics
- **Time Complexity**: $O(n_{secant\_steps} \cdot N)$, where $N$ is the number of rays. Each step involves a decoder evaluation and vector operations.
- **Memory Complexity**: $O(N)$ for storing the bracketing arrays and intermediate points.
- **Performance**: Converges faster than bisection for smooth functions due to superlinear convergence, but slower convergence than Newton's method if derivatives are unavailable [S1, unofficial].
- **Strengths**: Simple to implement, robust for monotonic functions, no derivative calculation required.
- **Limitations**: Can fail if the function is not continuous or if the initial brackets do not contain a root. Sensitive to the choice of initial brackets [S1, unofficial].
- **When to Use**: When a fast, derivative-free root-finding method is needed for smooth implicit surfaces or neural fields.
- **When Not to Use**: When the function is discontinuous (use False Position or Bisection) or when high precision is required with minimal iterations (use Newton's method if derivatives are available).

## Background
The Secant Method is a classical root-finding algorithm that approximates the derivative using finite differences. In the context of volume rendering and neural fields, it is used to refine the depth of surface intersections detected during ray marching [S1, unofficial]. The method is particularly relevant in differentiable volumetric rendering where precise surface localization is required for gradient-based optimization [S1, unofficial].
