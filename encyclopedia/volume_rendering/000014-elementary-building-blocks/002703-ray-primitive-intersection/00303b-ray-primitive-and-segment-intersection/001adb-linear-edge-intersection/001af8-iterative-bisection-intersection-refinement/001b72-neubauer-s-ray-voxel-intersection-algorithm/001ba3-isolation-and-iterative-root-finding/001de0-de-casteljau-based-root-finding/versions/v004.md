# de Casteljau-based root finding

Also called: Root Finding: de Casteljau Subdivision (LR81), de Casteljau Subdivision

## Overview
A root finding algorithm for polynomials in Bernstein form that finds the first intersection of a viewing ray with an isosurface by subdividing the control polygon using the de Casteljau algorithm at its intersection with the zero axis [S1]. It differs from knot insertion methods like [MR07] by providing quadratic convergence speed and constant memory usage without index operations, making it significantly faster on GPU architectures [S1].

## How it works
**Inputs and outputs:** The method takes a polynomial $P(t)$ in Bernstein basis of degree $n$ defined by control points $\mathbf{b}_0, \dots, \mathbf{b}_n$, and an isovalue $c$ [S1]. It solves $f(t) = P(t) - c = 0$ for $t \in [0, 1]$ [S1]. The output is the parameter $t$ corresponding to the first root [S1].

**Data structures:** The algorithm operates on the Bernstein control polygon and can be implemented with constant memory usage and without index operations [S1].

**Steps:**
1. Subdivide the control polygon using the de Casteljau algorithm at the intersection of the control polygon with the zero axis [S1].
2. Repeat the subdivision step for a fixed number of iterations $k$ (typically 3 to 7, depending on the interpolation type) [S1].
3. After $k$ iterations, the remaining control polygon is sufficiently small to approximate the root [S1].

**Formulas:** The de Casteljau algorithm for a parameter $t$ and control points $\mathbf{b}_i^{(0)} = \mathbf{b}_i$ computes the left sub-polygon control points as:
$$ \mathbf{b}_i^{(r)} = (1-t) \mathbf{b}_{i-1}^{(r-1)} + t \mathbf{b}_i^{(r-1)} $$
for $r=1, \dots, n$ and $i=r, \dots, n$ [G]. The intersection parameter $t_{\text{split}}$ between adjacent control points $\mathbf{b}_i$ and $\mathbf{b}_{i+1}$ is found via linear interpolation: $t_{\text{split}} = t_{\text{start}} + (t_{\text{end}} - t_{\text{start}}) \frac{|\mathbf{b}_i|}{|\mathbf{b}_i| + |\mathbf{b}_{i+1}|}$ [G].

**Parameters:** Number of iterations $k$: 3 to 7 [S1].

**Edge cases and pitfalls:** The method assumes the root is isolated or that the first root is sought [S1]. For isolated roots, simpler methods like regula falsi or binary search can be used, but the isolation step causes diverging branches on CUDA architectures [S1]. The Bernstein form offers a control polygon with a variation diminishing property [S1].

**Pseudocode:**
```python
def de_casteljau_root_finding(control_points, isovalue, num_iterations):
    """
    Find the root of P(t) - isovalue = 0 using de Casteljau subdivision.
    """
    cp = list(control_points)
    t_start, t_end = 0.0, 1.0
    n = len(cp) - 1

    for _ in range(num_iterations):
        # Find intersection of control polygon with zero axis
        t_split = 0.5  # Fallback if no crossing found
        for i in range(n):
            if cp[i] * cp[i+1] < 0:
                t_split = t_start + (t_end - t_start) * (abs(cp[i]) / (abs(cp[i]) + abs(cp[i+1])))
                break
        
        # Compute de Casteljau triangle to extract left control polygon
        left_cp = [cp[0]]
        b = list(cp)
        for r in range(1, n + 1):
            new_b = []
            for i in range(len(b) - 1):
                new_b.append((1 - t_split) * b[i] + t_split * b[i+1])
            b = new_b
            left_cp.append(b[0])
        
        # Update to the left segment for the first root
        cp = left_cp
        t_end = t_split

    return (t_start + t_end) / 2
```

## Subtopics

### Knot insertion root finding
A root finding algorithm based on knot insertion with linear convergence speed and linear complexity per step [S1]. It requires index operations and memory usage grows with every iteration step, limiting the maximum number of iterations [S1]. For degree 9 (tri-cubic), it has a relative execution time of 1.0, MSE of 0.034, and max error of 0.85 [S1]. It is more than 10 times slower than de Casteljau-based root finding [S1].

### Regula Falsi with De Casteljau
A root finding method using Regula Falsi combined with De Casteljau subdivision for root isolation [S1]. While the second phase (Regula Falsi) can outperform de Casteljau-based root finding for isolated roots, the isolation step is not well suited for CUDA due to diverging branches [S1].

## Operating characteristics
- **Time Complexity:** Quadratic complexity per step due to the de Casteljau algorithm [S1].
- **Convergence:** Quadratic convergence speed [S1].
- **Memory:** Constant memory usage, no index operations required [S1].
- **Performance:** For degree 9 (tri-cubic), relative execution time is 0.076, MSE is 0.003, and max error is 0.66 [S1]. It is more than 10 times faster than the MR07 knot insertion algorithm [S1].
- **Strengths:** Fast, constant memory, suitable for GPU (CUDA) due to lack of diverging branches and index operations [S1].
- **Limitations:** Fixed number of iterations required; not optimal for isolated roots where simpler methods like Regula Falsi could be faster in the refinement phase [S1].

## Background
Originated from the work cited as [LR81] in the context of volume rendering using wavelet-based multiresolution isosurface rendering [S1]. It is used as a primary root finding method in GPU-based volume rendering pipelines due to its efficiency and suitability for parallel architectures [S1].
