# Isolation and Iterative Root Finding

Also called: Isolation method, New intersection algorithm

## Overview
Isolation and Iterative Root Finding is a ray-voxel intersection algorithm designed to locate the first intersection of a viewing ray with an iso-surface within a voxel. It solves the problem of balancing computational speed with numerical correctness, addressing the inaccuracies of Neubauer's method and the slowness of Schwarze's method. It sets itself apart by first isolating the root interval using polynomial extrema analysis, guaranteeing exactly one root in the final interval, and then applying iterative refinement. This approach is roughly three times faster than Schwarze's method while providing the same correctness guarantees and better numerical stability.

## How it works
The method operates on a cubic polynomial $f(t)$ representing the density along the ray segment $[t_{in}, t_{out}]$. The algorithm consists of two phases: root isolation via extrema analysis, followed by iterative root finding.

**Inputs:**
- Ray segment endpoints $t_{in}$ and $t_{out}$.
- Polynomial coefficients $A, B, C, D$ for $f(t) = At^3 + Bt^2 + Ct + D$.
- Iso-value threshold (implicitly handled by evaluating $f(t)$ against the threshold, or assuming $f(t)$ is already shifted by the threshold).

**Outputs:**
- Intersection parameter $t_{hit}$ or "NO HIT".

**Data Structures:**
- Floating-point variables for $t, f, e$ (extrema).
- Quadratic solver for $f'(t)$.

**Steps:**

1.  **Initialization:**
    Set $t_0 = t_{in}$, $t_1 = t_{out}$.
    Evaluate $f_0 = f(t_0)$ and $f_1 = f(t_1)$.

2.  **Extrema Analysis:**
    Compute the derivative $f'(t) = 3At^2 + 2Bt + C$.
    Solve the quadratic equation $f'(t) = 0$ for real roots.
    Let the roots be $e_0$ and $e_1$ with $e_0 \le e_1$. If no real roots exist, skip to Step 4.

3.  **Interval Isolation:**
    Iterate through the extrema to narrow the search interval $[t_0, t_1]$ to a segment containing exactly one root.
    
    For each extremum $e \in \{e_0, e_1\}$:
    - If $e$ is not in $[t_0, t_1]$, continue to the next extremum.
    - If $e$ is in $[t_0, t_1]$:
        - Evaluate $f(e)$.
        - If $\text{sign}(f(e)) == \text{sign}(f_0)$:
            - The extremum is on the same side of the iso-surface as the start of the current segment. Advance the start of the segment:
              $t_0 := e$
              $f_0 := f(e)$
        - Else:
            - The extremum is on the opposite side. The root lies between the previous start and this extremum. Set the end of the segment:
              $t_1 := e$
              $f_1 := f(e)$
    
    *Note: The algorithm processes $e_0$ then $e_1$. If $e_0$ splits the interval, the subsequent check for $e_1$ operates on the new $[t_0, t_1]$.*

4.  **Hit Check:**
    If $\text{sign}(f_0) == \text{sign}(f_1)$, return "NO HIT".
    Otherwise, the interval $[t_0, t_1]$ contains exactly one root.

5.  **Iterative Refinement:**
    Use repeated linear interpolation (regula falsi) to find the root within $[t_0, t_1]$.
    Loop $i$ from 1 to $N$ (typically $N=2$ or $3$):
    - Compute candidate $t$:
      $$ t = t_0 + (t_1 - t_0) \frac{-f_0}{f_1 - f_0} $$
    - Evaluate $f(R(t))$ (where $R(t)$ is the ray position at $t$).
    - If $\text{sign}(f(R(t))) == \text{sign}(f_0)$:
      $t_0 := t$
      $f_0 := f(R(t))$
    - Else:
      $t_1 := t$
      $f_1 := f(R(t))$

6.  **Return Result:**
    Return $t_{hit} = t_0 + (t_1 - t_0) \frac{-f_0}{f_1 - f_0}$.

**Pseudocode:**

```python
def isolation_and_iterative_root_finding(t_in, t_out, A, B, C, D):
    # f(t) = A*t^3 + B*t^2 + C*t + D
    def f(t):
        return A*t*t*t + B*t*t + C*t + D

    t0 = t_in
    t1 = t_out
    f0 = f(t0)
    f1 = f(t1)

    # Find extrema by solving f'(t) = 3At^2 + 2Bt + C = 0
    a_quad = 3 * A
    b_quad = 2 * B
    c_quad = C
    
    discriminant = b_quad*b_quad - 4*a_quad*c_quad
    
    if discriminant < 0:
        # No real extrema, proceed with initial interval
        pass
    else:
        sqrt_disc = math.sqrt(discriminant)
        e0 = (-b_quad - sqrt_disc) / (2 * a_quad)
        e1 = (-b_quad + sqrt_disc) / (2 * a_quad)
        
        # Process extrema in order
        extrema = [e0, e1]
        
        for e in extrema:
            if t0 <= e <= t1:
                f_e = f(e)
                if math.copysign(1, f_e) == math.copysign(1, f0):
                    # Advance to next segment
                    t0 = e
                    f0 = f_e
                else:
                    # Root is in [previous_t0, e]
                    t1 = e
                    f1 = f_e
        
        # If sign(f0) == sign(f1), no root in the remaining interval
        if math.copysign(1, f0) == math.copysign(1, f1):
            return None # NO HIT

    # Iterative refinement using repeated linear interpolation
    # Typically 2-3 iterations
    for i in range(1, 4):
        # Avoid division by zero
        if f1 == f0:
            break
            
        t = t0 + (t1 - t0) * (-f0) / (f1 - f0)
        f_t = f(t)
        
        if math.copysign(1, f_t) == math.copysign(1, f0):
            t0 = t
            f0 = f_t
        else:
            t1 = t
            f1 = f_t

    # Final estimate
    if f1 != f0:
        t_hit = t0 + (t1 - t0) * (-f0) / (f1 - f0)
    else:
        t_hit = t0
        
    return t_hit
```

**Parameters:**
- Number of iterations $N$: Typically 2 or 3. A fixed number is usually faster than an adaptive termination criterion [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Three Intersections:** Neubauer's method can falsely return the last intersection if three intersections are contained within a voxel and two are in the first segment. Isolation and Iterative Root Finding avoids this by explicitly isolating the first root interval using extrema, ensuring the returned root is the first one [S1, unofficial].
- **Precision:** The method relies on evaluating the polynomial. Since coefficients are known, this avoids costly trilinear interpolation during refinement, improving speed and stability [S1, unofficial].
- **No Real Extrema:** If the discriminant is negative, the polynomial is monotonic in the interval, and the initial $[t_{in}, t_{out}]$ is used directly.

## Subtopics

### [de Casteljau-based root finding](1596-de-casteljau-based-root-finding.md)
An algorithm to find the intersection of a control polygon with the zero axis, implemented with constant memory usage and without index operations. It uses the de Casteljau algorithm to subdivide the control polygon. It exhibits quadratic convergence speed and quadratic complexity for each step. It is suggested as the best overall root-finder among variants due to its balance of performance and stability, especially for volume rendering where a fixed number of 3 to 7 iterations is often used.

## Operating characteristics
- **Time Complexity:** Roughly a factor of three faster than Schwarze's method [S1, unofficial]. The cost is dominated by solving the quadratic equation for extrema and evaluating the polynomial.
- **Memory Complexity:** Low. Requires storing only a few floating-point variables for the interval and extrema. The Sturm Series variant (a sibling approach) has high memory consumption as it keeps the whole series in memory, but the primary Isolation method does not [S2, unofficial].
- **Measured Performance:** For degree 9 (tri-cubic) polynomials, the method (referred to as "RF" or Regula Falsi in comparisons) shows relative execution time of 0.062-0.077 compared to Schwarze's 1.0, with low Mean Squared Error (0.003-0.016) and max error (0.66-1.0) [S2, unofficial].
- **Strengths:** Correctness guarantees similar to Schwarze's method; better numerical stability than Neubauer's; well-suited for SIMD parallel implementation due to little branching and regular control flow [S1, S2, unofficial].
- **Limitations:** Requires computing polynomial coefficients and extrema upfront. Numerical problems inherent to power form implementations can become more severe with more iterations if using Sturm Series variants, though the primary isolation method mitigates this by isolating the root first [S2, unofficial].
- **When to use:** When high performance is required but correctness cannot be compromised, such as in real-time volume rendering of smooth iso-surfaces.
- **When not to use:** If the overhead of computing coefficients is prohibitive and lower precision is acceptable.

## Background
The method was derived by Wald et al. in 2004 as a response to the trade-offs between existing ray-voxel intersection techniques. It aims to combine the speed of Neubauer's method with the correctness of Schwarze's method. The approach leverages the fact that repeated linear interpolation is fast and reliable if the start interval contains exactly one root, which is guaranteed by the prior extrema analysis [S1, unofficial]. It is particularly effective for SIMD implementations, as demonstrated by Wald et al., who showed that modern SIMD instruction sets can significantly improve performance for this algorithm due to its data-parallel nature and lack of complex control flow [S1, unofficial].
