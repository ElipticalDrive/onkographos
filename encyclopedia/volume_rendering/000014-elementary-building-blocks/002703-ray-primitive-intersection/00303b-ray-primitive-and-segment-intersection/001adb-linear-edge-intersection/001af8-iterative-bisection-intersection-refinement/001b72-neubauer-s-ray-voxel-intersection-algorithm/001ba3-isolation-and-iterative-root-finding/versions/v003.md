# Isolation and Iterative Root Finding

Also called: Isolation method, New intersection algorithm

## Overview
Isolation and Iterative Root Finding is a ray-voxel intersection algorithm designed to locate the first intersection of a viewing ray with an iso-surface within a voxel [S1, unofficial]. It solves the problem of balancing computational speed with numerical correctness, addressing the inaccuracies of Neubauer's method and the slowness of Schwarze's method [S1, unofficial]. It sets itself apart by first isolating the root interval using polynomial extrema analysis, guaranteeing exactly one root in the final interval, and then applying iterative refinement [S1, unofficial]. This approach is roughly three times faster than Schwarze's method while providing the same correctness guarantees and better numerical stability [S1, unofficial].

## How it works
The method operates on a cubic polynomial $f(t)$ representing the density along the ray segment $[t_{in}, t_{out}]$ [S1, unofficial]. The algorithm consists of two phases: root isolation via extrema analysis, followed by iterative root finding [S1, unofficial].

**Inputs:**
- Ray segment endpoints $t_{in}$ and $t_{out}$ [S1, unofficial].
- Polynomial coefficients $A, B, C, D$ for $f(t) = At^3 + Bt^2 + Ct + D$ [S1, unofficial].
- Iso-value threshold (implicitly handled by evaluating $f(t)$ against the threshold, or assuming $f(t)$ is already shifted by the threshold) [S1, unofficial].

**Outputs:**
- Intersection parameter $t_{hit}$ or "NO HIT" [S1, unofficial].

**Data Structures:**
- Floating-point variables for $t, f, e$ (extrema) [S1, unofficial].
- Quadratic solver for $f'(t)$ [S1, unofficial].

**Steps:**

1.  **Initialization:**
    Set $t_0 = t_{in}$, $t_1 = t_{out}$ [S1, unofficial].
    Evaluate $f_0 = f(t_0)$ and $f_1 = f(t_1)$ [S1, unofficial].

2.  **Extrema Analysis:**
    Compute the derivative $f'(t) = 3At^2 + 2Bt + C$ [S1, unofficial].
    Solve the quadratic equation $f'(t) = 0$ for real roots [S1, unofficial].
    Let the roots be $e_0$ and $e_1$ with $e_0 \le e_1$ [S1, unofficial]. If no real roots exist, skip to Step 4 [S1, unofficial].

3.  **Interval Isolation:**
    Iterate through the extrema to narrow the search interval $[t_0, t_1]$ to a segment containing exactly one root [S1, unofficial].
    
    For each extremum $e \in \{e_0, e_1\}$:
    - If $e$ is not in $[t_0, t_1]$, continue to the next extremum [S1, unofficial].
    - If $e$ is in $[t_0, t_1]$:
        - Evaluate $f(e)$ [S1, unofficial].
        - If $\text{sign}(f(e)) == \text{sign}(f_0)$:
            - The extremum is on the same side of the iso-surface as the start of the current segment [S1, unofficial]. Advance the start of the segment:
              $t_0 := e$
              $f_0 := f(e)$ [S1, unofficial].
        - Else:
            - The extremum is on the opposite side [S1, unofficial]. The root lies between the previous start and this extremum [S1, unofficial]. Set the end of the segment:
              $t_1 := e$
              $f_1 := f(e)$ [S1, unofficial].
    
    *Note: The algorithm processes $e_0$ then $e_1$. If $e_0$ splits the interval, the subsequent check for $e_1$ operates on the new $[t_0, t_1]$ [S1, unofficial].*

4.  **Hit Check:**
    If $\text{sign}(f_0) == \text{sign}(f_1)$, return "NO HIT" [S1, unofficial].
    Otherwise, the interval $[t_0, t_1]$ contains exactly one root [S1, unofficial].

5.  **Iterative Refinement:**
    Use repeated linear interpolation (regula falsi) to find the root within $[t_0, t_1]$ [S1, unofficial].
    Loop $i$ from 1 to $N$ (typically $N=2$ or $3$):
    - Compute candidate $t$:
      $$ t = t_0 + (t_1 - t_0) \frac{-f_0}{f_1 - f_0} $$
    - Evaluate $f(R(t))$ (where $R(t)$ is the ray position at $t$) [S1, unofficial].
    - If $\text{sign}(f(R(t))) == \text{sign}(f_0)$:
      $t_0 := t$
      $f_0 := f(R(t))$ [S1, unofficial].
    - Else:
      $t_1 := t$
      $f_1 := f(R(t))$ [S1, unofficial].

6.  **Return Result:**
    Return $t_{hit} = t_0 + (t_1 - t_0) \frac{-f_0}{f_1 - f_0}$ [S1, unofficial].

**Pseudocode:**

```python
import math

def isolation_and_iterative_root_finding(t_in, t_out, A, B, C, D):
    # f(t) = A*t^3 + B*t^2 + C*t + D
    def f(t):
        return A*t**3 + B*t**2 + C*t + D

    t0 = t_in
    t1 = t_out
    f0 = f(t0)
    f1 = f(t1)

    # Find extrema by solving f'(t) = 3At^2 + 2Bt + C = 0
    a_quad = 3 * A
    b_quad = 2 * B
    c_quad = C
    discriminant = b_quad**2 - 4 * a_quad * c_quad

    if discriminant >= 0:
        sqrt_disc = math.sqrt(discriminant)
        e0 = (-b_quad - sqrt_disc) / (2 * a_quad)
        e1 = (-b_quad + sqrt_disc) / (2 * a_quad)
        extrema = [e0, e1] if e0 <= e1 else [e1, e0]

        for e in extrema:
            if t0 <= e <= t1:
                f_e = f(e)
                if math.copysign(1, f_e) == math.copysign(1, f0):
                    # Advance to next segment
                    t0 = e
                    f0 = f_e
                else:
                    # Root is in [previous_t0, e]
                    t1 = e
                    f1 = f_e

    # If sign(f0) == sign(f1), no root in the remaining interval
    if math.copysign(1, f0) == math.copysign(1, f1):
        return None  # NO HIT

    # Iterative refinement using repeated linear interpolation
    # Typically 2-3 iterations
    for _ in range(3):
        denom = f1 - f0
        if abs(denom) < 1e-12:  # Guard against division by zero [G]
            break
        t = t0 + (t1 - t0) * (-f0) / denom
        f_t = f(t)
        if math.copysign(1, f_t) == math.copysign(1, f0):
            t0 = t
            f0 = f_t
        else:
            t1 = t
            f1 = f_t

    # Final estimate
    denom = f1 - f0
    if abs(denom) < 1e-12:
        t_hit = t0
    else:
        t_hit = t0 + (t1 - t0) * (-f0) / denom
    return t_hit
```

**Parameters:**
- Number of iterations $N$: Typically 2 or 3 [S1, unofficial]. A fixed number is usually faster than an adaptive termination criterion [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Three Intersections:** Neubauer's method can falsely return the last intersection if three intersections are contained within a voxel and two are in the first segment [S1, unofficial]. Isolation and Iterative Root Finding avoids this by explicitly isolating the first root interval using extrema, ensuring the returned root is the first one [S1, unofficial].
- **Precision:** The method relies on evaluating the polynomial [S1, unofficial]. Since coefficients are known, this avoids costly trilinear interpolation during refinement, improving speed and stability [S1, unofficial].
- **No Real Extrema:** If the discriminant is negative, the polynomial is monotonic in the interval, and the initial $[t_{in}, t_{out}]$ is used directly [S1, unofficial].
- **Division by Zero:** If $f_1$ converges to $f_0$ during refinement, the denominator $f_1 - f_0$ becomes zero; the implementation guards against this by checking the denominator magnitude before division [G].
