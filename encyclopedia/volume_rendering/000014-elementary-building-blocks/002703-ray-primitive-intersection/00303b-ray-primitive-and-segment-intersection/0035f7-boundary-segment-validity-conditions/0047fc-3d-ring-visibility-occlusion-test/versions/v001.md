# 3D Ring Visibility & Occlusion Test

Also called: ring depth test, ring raster validation

## Overview
The 3D Ring Visibility & Occlusion Test is a screen-space rasterization technique used to determine which voxels are visible or occluded by the boundary segments of a 3D ring primitive. It projects ring segments to screen space, computes depth via inverse-linear interpolation, and validates visibility against a voxel depth buffer. It differs from sibling methods like [Change of Integration Variable for Boundary Segments](8107-change-of-integration-variable-for-boundary-segments.md) by operating in screen space using rasterization primitives rather than analytical integration in world space.

## How it works
**Inputs:**
- Ring center position $\mathbf{c}$ (world space).
- Eye position $\mathbf{e}$ (world space).
- Ring radius $r$.
- Camera parameters: near plane distance $n$, focal length $f$, screen width $w$, screen height $h$, and basis vectors $\mathbf{right}, \mathbf{up}, \mathbf{forward}$.
- Voxel depth buffer.

**Outputs:**
- Updated voxel masks: `support`, `visible`, `definite`, `possible`, `edge`, `contact`.

**Data Structures:**
- The ring is discretized into 3 segments (indices 0..2) and 32 sub-segments per ring (indices 0..31).
- Each sub-segment is defined by two endpoints in screen space.

**Steps:**
1. Iterate over ring index $k \in \{0, 1, 2\}$ and segment index $i \in \{0, \dots, 31\}$.
2. Compute angle $\theta = i \times 0.1963495408$.
3. Compute displacement vector $\mathbf{\delta}$ based on ring index $k$:
   - Let $c = r \cos(\theta)$, $s = r \sin(\theta)$.
   - If $k=0$, $\mathbf{\delta} = (c, s, 0)$.
   - If $k=1$, $\mathbf{\delta} = (c, 0, s)$.
   - If $k=2$, $\mathbf{\delta} = (0, c, s)$.
4. Compute world direction vector $\mathbf{d} = \mathbf{c} + \mathbf{\delta} - \mathbf{e}$.
5. Project $\mathbf{d}$ to camera space components:
   - $a_x = \mathbf{d} \cdot \mathbf{right}$
   - $a_y = \mathbf{d} \cdot \mathbf{up}$
   - $a_z = \mathbf{d} \cdot \mathbf{forward}$
   *(Note: The source implies a segment between two points, so let $\mathbf{a}$ and $\mathbf{b}$ be the camera-space coordinates of the two endpoints of the segment.)*
6. If $\max(a_z, b_z) < n$, skip the segment.
7. If $\min(a_z, b_z) < n$, clip the segment to the near plane.
8. Project endpoints to screen coordinates:
   - $p_x = \frac{w}{2} + f \frac{a_x}{a_z}$
   - $p_y = \frac{h}{2} - f \frac{a_y}{a_z}$
   *(Similarly for $q$ from $\mathbf{b}$)*.
9. Compute bounding box $[x_{min}, x_{max}] \times [y_{min}, y_{max}]$ covering the segment.
10. For each pixel $(xx, yy)$ in the bounding box:
    - Compute projection parameter $t$:
      $$ t = \text{clip}\left( \frac{(xx + 0.5 - p_x)\Delta_x + (yy + 0.5 - p_y)\Delta_y}{\Delta_x^2 + \Delta_y^2}, 0, 1 \right) $$
      where $\Delta_x = q_x - p_x$, $\Delta_y = q_y - p_y$.
    - Compute distance to segment.
    - If distance $\le 0.75$, mark as `stroke`.
11. Compute depth $z$ at parameter $t$ using inverse-linear interpolation:
    $$ z = \frac{1}{\frac{1}{a_z} + t \left(\frac{1}{b_z} - \frac{1}{a_z}\right)} $$
12. Compute normalized depth:
    $$ \text{depth} = 1 - \frac{n}{\max(n, z - 0.0001)} $$
13. Update voxel masks (`support`, `visible`, `definite`, `possible`, `edge`, `contact`) based on depth comparison and stroke status.

**Pitfalls:**
- Degenerate segments (squared length < $10^{-6}$) are skipped.
- Near clipping is handled by checking min/max z against the near plane and interpolating the cut point.
- Division by zero in depth calculation is avoided by using $\max(\text{near}, \dots)$.
