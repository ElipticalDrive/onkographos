# ERP/Baumgarte Collision Resolution
Also called: SDF Physics Collision, Terrain Collision Resolve
## Overview
ERP/Baumgarte Collision Resolution is a collision resolution method that uses Signed Distance Fields (SDF) to determine depth and normal for correcting object penetration [S1, unofficial]. It removes a fraction of penetration per step via Baumgarte stabilization and kills inward normal velocity [S1, unofficial].

## How it works
**Inputs:**
- `pos`: Current object position (vector).
- `oldPos`: Previous frame object position (vector).
- `vel`: Current object velocity (vector).
- `mass`: Object mass (scalar).
- `contactOffset`: SDF distance threshold for collision detection (scalar).
- `slop`: Allowed penetration depth before resolution triggers (scalar).
- `beta`: Baumgarte stabilization factor (scalar).
- `frictionMu`: Coefficient of friction (scalar).
- `dt`: Time step duration (scalar).

**Outputs:**
- `newVel`: Updated velocity after collision resolution (vector).

**Data Structures:**
The method operates on standard vector and scalar types. It queries the terrain SDF via `SDF(pos)` for distance and `EstimateGradient(pos)` for the surface normal gradient at the old position [S1, unofficial].

**Steps:**
1. **Early Exit:** If `dt <= 0` or the magnitude of the SDF normal is near zero ($< 10^{-10}$), return `vel` unchanged [S1, unofficial].
2. **Surface Normal:** Normalize the SDF gradient at the old position to get the surface normal $\mathbf{n}$ [S1, unofficial].
3. **Penetration Depth:** Calculate penetration as `penetration = max(0, (contactOffset - sdfDistance) - slop)`, where `sdfDistance` is the SDF value at `pos` [S1, unofficial]. If `penetration <= 0`, return `vel` unchanged [S1, unofficial].
4. **Collision Detection:** A collision is detected if the object crossed the surface boundary: `(oldDistance > 0 && newDistance < 0) || (oldDistance < 0 && newDistance > 0)` [S1, unofficial]. If no collision occurred, return `vel` unchanged [S1, unofficial].
5. **Velocity Bias:** Calculate incoming normal velocity $v_N = \mathbf{vel} \cdot \mathbf{n}$ [S1, unofficial]. Calculate velocity bias $\Delta v_N$: if $v_N < 0$, set $\Delta v_N = -v_N + \beta \cdot \frac{\text{penetration}}{\max(10^{-6}, dt)}$; otherwise $\Delta v_N = 0$ [S1, unofficial]. Apply the bias: $\mathbf{vel} \leftarrow \mathbf{vel} + \Delta v_N \mathbf{n}$ [S1, unofficial].
6. **Inward Velocity Guard:** If $\mathbf{vel} \cdot \mathbf{n} < 0$, subtract the inward component: $\mathbf{vel} \leftarrow \mathbf{vel} - (\mathbf{vel} \cdot \mathbf{n}) \mathbf{n}$ [S1, unofficial].
7. **Tangential Friction:** Calculate normal impulse $J_n = \text{mass} \cdot \max(0, \Delta v_N)$ [S1, unofficial]. If `frictionMu > 0` and $J_n > 0$, calculate tangential velocity $\mathbf{v}_T = \mathbf{vel} - (\mathbf{vel} \cdot \mathbf{n}) \mathbf{n}$ [S1, unofficial]. If $\|\mathbf{v}_T\| > 10^{-6}$, calculate max friction impulse $J_{t,\max} = \text{frictionMu} \cdot J_n$ and needed impulse $J_{t,\text{needed}} = \text{mass} \cdot \|\mathbf{v}_T\|$ [S1, unofficial]. Apply friction impulse magnitude $J_t = \min(J_{t,\text{needed}}, J_{t,\max})$ as a velocity change: $\mathbf{vel} \leftarrow \mathbf{vel} - \frac{\mathbf{v}_T}{\|\mathbf{v}_T\|} \frac{J_t}{\text{mass}}$ [S1, unofficial].

**Pseudocode:**
```python
def resolve_collision(pos, old_pos, vel, mass, contact_offset, slop, beta, friction_mu, dt):
    if dt <= 0:
        return vel

    grad = estimate_gradient(old_pos)
    grad_mag = (grad[0]**2 + grad[1]**2 + grad[2]**2)**0.5

    if grad_mag < 1e-10:
        return vel

    n = [grad[0]/grad_mag, grad[1]/grad_mag, grad[2]/grad_mag]

    new_dist = sdf_distance(pos)
    old_dist = sdf_distance(old_pos)

    if not ((old_dist > 0 and new_dist < 0) or (old_dist < 0 and new_dist > 0)):
        return vel

    penetration = max(0.0, (contact_offset - new_dist) - slop)

    if penetration <= 0:
        return vel

    v_n = vel[0]*n[0] + vel[1]*n[1] + vel[2]*n[2]

    dv_n = 0.0
    if v_n < 0:
        dv_n = -v_n + beta * (penetration / max(1e-6, dt))

    vel = [vel[0] + dv_n*n[0], vel[1] + dv_n*n[1], vel[2] + dv_n*n[2]]

    dot_vn = vel[0]*n[0] + vel[1]*n[1] + vel[2]*n[2]
    if dot_vn < 0:
        vel = [vel[0] - dot_vn*n[0], vel[1] - dot_vn*n[1], vel[2] - dot_vn*n[2]]

    j_n = mass * max(0.0, dv_n)

    if friction_mu > 0 and j_n > 0:
        v_t = [vel[0] - dot_vn*n[0], vel[1] - dot_vn*n[1], vel[2] - dot_vn*n[2]]
        v_t_mag = (v_t[0]**2 + v_t[1]**2 + v_t[2]**2)**0.5

        if v_t_mag > 1e-6:
            j_t_max = friction_mu * j_n
            j_t_needed = mass * v_t_mag
            j_t_magnitude = min(j_t_needed, j_t_max)

            inv_v_t_mag = 1.0 / v_t_mag
            vel = [vel[0] - v_t[0]*inv_v_t_mag*(j_t_magnitude/mass),
                   vel[1] - v_t[1]*inv_v_t_mag*(j_t_magnitude/mass),
                   vel[2] - v_t[2]*inv_v_t_mag*(j_t_magnitude/mass)]

    return vel
```
