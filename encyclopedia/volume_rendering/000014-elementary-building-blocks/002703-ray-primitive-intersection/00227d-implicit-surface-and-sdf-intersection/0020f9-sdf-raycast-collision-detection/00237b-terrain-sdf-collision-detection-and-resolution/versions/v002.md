# Terrain SDF Collision Detection and Resolution

Also called: SDF Collision Detection, SDF Sign Change Collision

## Overview
This method detects collisions between a moving object and a terrain represented by a Signed Distance Field (SDF) by evaluating the distance at the object's previous and current positions [S1, unofficial]. It identifies collisions via sign changes in the distance values and estimates the surface normal to resolve penetration [S1, unofficial].

## How it works
**Inputs:**
- `terrainSDFS`: The terrain SDF evaluator.
- `oldPosition`: The object's position at the start of the time step.
- `currentPosition`: The object's position at the end of the time step.
- `currentVelocity`: The object's velocity vector.

**Outputs:**
- `justCollided`: Boolean flag indicating if a collision occurred.
- `resolution`: A velocity correction vector to resolve the collision.

**Data Structures:**
- `float`: Signed distance value. Positive values indicate outside the terrain and negative values indicate inside [G].
- `Vec3`: 3D position and normal vectors.

**Parameters:**
- `beta`: Damping factor for collision resolution, typical value 0.1–0.3 [S1, unofficial].
- `contactOffset`: Contact offset distance, typical value 3–10 mm [S1, unofficial].
- `slop`: Slop distance, typical value 1–3 mm [S1, unofficial].
- `frictionMu`: Friction coefficient, typical value 0.6f [S1, unofficial].

**Steps:**
1. Evaluate the signed distance at the old position:
   $$ d_{\text{old}} = \text{terrainSDFS}.\text{EvaluateDistanceAt}(\text{oldPosition}) $$
2. Evaluate the signed distance at the current position:
   $$ d_{\text{new}} = \text{terrainSDFS}.\text{EvaluateDistanceAt}(\text{currentPosition}) $$
3. Check for collision by detecting a sign change:
   $$ \text{collision} = (d_{\text{old}} > 0 \land d_{\text{new}} < 0) \lor (d_{\text{old}} < 0 \land d_{\text{new}} > 0) $$
4. If a collision is detected:
   a. Estimate the surface normal at the old position:
      $$ \mathbf{n} = \text{EstimateGradient}(\text{terrainSDFS}, \text{oldPosition}) $$
   b. If the new distance is positive (object is now outside), invert the normal:
      $$ \text{if } d_{\text{new}} > 0: \mathbf{n} = -\mathbf{n} $$
   c. Set `justCollided = true`.
   d. Return the resolution result:
      $$ \text{resolution} = -1 \times \text{currentVelocity} $$
5. If no collision is detected:
   a. Set `justCollided = false`.
   b. Return $\mathbf{0}$.

**Pseudocode:**
```python
class Vec3:
    def __init__(self, x, y, z):
        self.x, self.y, self.z = x, y, z
    def __add__(self, other): return Vec3(self.x + other.x, self.y + other.y, self.z + other.z)
    def __sub__(self, other): return Vec3(self.x - other.x, self.y - other.y, self.z - other.z)
    def __mul__(self, scalar): return Vec3(self.x * scalar, self.y * scalar, self.z * scalar)
    def __neg__(self): return Vec3(-self.x, -self.y, -self.z)
    def __truediv__(self, scalar): return Vec3(self.x / scalar, self.y / scalar, self.z / scalar)
    def length(self): return (self.x**2 + self.y**2 + self.z**2)**0.5
    def normalized(self):
        l = self.length()
        return self / l if l > 0 else Vec3(0, 0, 0)
    @staticmethod
    def zero(): return Vec3(0, 0, 0)

def TerrainSDFCollisionDetectionAndResolution(terrainSDFS, oldPosition, currentPosition, currentVelocity):
    oldDistance = terrainSDFS.EvaluateDistanceAt(oldPosition)
    newDistance = terrainSDFS.EvaluateDistanceAt(currentPosition)
    
    if (oldDistance > 0 and newDistance < 0) or (oldDistance < 0 and newDistance > 0):
        justCollided = True
        surfaceNormal = EstimateGradient(terrainSDFS, oldPosition)
        if newDistance > 0:
            surfaceNormal = -surfaceNormal
        resolution = -1 * currentVelocity
        return justCollided, resolution
    else:
        justCollided = False
        return justCollided, Vec3.zero()

def EstimateGradient(terrainSFS, position):
    # [G] Standard central difference approximation for gradient
    epsilon = 0.001
    dx = terrainSFS.EvaluateDistanceAt(position + Vec3(epsilon, 0, 0)) - terrainSFS.EvaluateDistanceAt(position - Vec3(epsilon, 0, 0))
    dy = terrainSFS.EvaluateDistanceAt(position + Vec3(0, epsilon, 0)) - terrainSFS.EvaluateDistanceAt(position - Vec3(0, epsilon, 0))
    dz = terrainSFS.EvaluateDistanceAt(position + Vec3(0, 0, epsilon)) - terrainSFS.EvaluateDistanceAt(position - Vec3(0, 0, epsilon))
    return Vec3(dx, dy, dz) / (2 * epsilon)
```
