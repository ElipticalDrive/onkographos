# Bisection Ray Tracing with Interval Inclusion

Also called: Interval/Affine Arithmetic Ray Tracing, IsoRay bisection tracer

## Overview
Bisection Ray Tracing with Interval Inclusion is a robust ray-surface intersection algorithm that guarantees finding the nearest intersection of an implicit surface with a ray without missing fine features [S1, unofficial]. It solves the problem of precision loss and feature skipping inherent in fixed-step ray marching by using interval arithmetic to prune intervals that cannot contain a root, followed by bisection to narrow down the interval containing the sign change of the implicit function $f$ [S1, unofficial]. Unlike standard bisection which processes rays independently, this method processes rays in batches and uses front-to-back pruning to discard intervals that are behind already found hits, improving efficiency for scenes with multiple surfaces or occlusion [S1, unofficial]. It builds on [Kalra & Barr Implicit Surface Intersection](1278-kalra-barr-implicit-surface-intersection.md) by providing a specific batched, interval-arithmetic-based implementation strategy.

## How it works
**Inputs:**
- `origins`: Array of shape $(R, 3)$, ray origins.
- `directions`: Array of shape $(R, 3)$, ray directions (normalized).
- `t_min`: Array of shape $(R)$, near plane distances.
- `t_max`: Array of shape $(R)$, far plane distances.
- `hit_mask`: Boolean array of shape $(R)$, rays that intersect the bounding volume.
- `inclusion`: An inclusion function object (e.g., `SamplingInclusion`) capable of evaluating bounds on the implicit field $f$ over an interval $[t_{lo}, t_{hi}]$.
- `f`: The implicit surface function.
- `max_depth`: Maximum number of bisection iterations (default 40) [S1, unofficial].
- `threshold`: Convergence width threshold (default $10^{-5}$) [S1, unofficial].

**Outputs:**
- `result`: A `TraceResult` dataclass containing:
  - `hit`: Boolean array $(R)$, true if a surface was found.
  - `t`: Float64 array $(R)$, distance to the closest hit.
  - `position`: Float64 array $(R, 3)$, hit position ($origin + t \cdot direction$).
  - `normal`: Float64 array $(R, 3)$, surface normal (zeros if not hit).
  - `depth_count`: Int32 array $(R)$, number of bisection steps taken.
  - `t_lo`: Float64 array $(R)$, lower bound of the final interval.
  - `t_hi`: Float64 array $(R)$, upper bound of the final interval.

**Data Structures:**
The algorithm maintains active intervals for rays. Key arrays include:
- `ray_idx`: Indices of active rays.
- `iv_t_lo`: Lower bounds of intervals for active rays.
- `iv_t_hi`: Upper bounds of intervals for active rays.
- `result_t`: Array storing the closest hit distance found so far for each ray (initialized to `t_max` or infinity).
- `result_hit`: Boolean array tracking if a hit has been recorded.

**Steps:**

1. **Initialization:**
   - Initialize `result_t` with `t_max` (or a large value) for all rays.
   - Initialize `result_hit` to `False`.
   - Initialize `result_depth` to 0.
   - Identify valid rays: `valid_ray = hit_mask`.
   - Set initial intervals: `iv_t_lo = t_min`, `iv_t_hi = t_max` for valid rays.
   - `ray_idx` contains indices of valid rays.

2. **Bisection Loop:**
   - While `len(ray_idx) > 0` and current `depth < max_depth`:
     a. **Front-to-Back Pruning:**
        - Remove intervals that are entirely beyond the closest known hit.
        - `keep = iv_t_lo[ray_idx] < result_t[ray_idx]`
        - Update `ray_idx`, `iv_t_lo`, `iv_t_hi` using the `keep` mask.
        - If `len(ray_idx) == 0`, break loop.
     
     b. **Clip Far End:**
        - Ensure intervals do not extend past the closest known hit.
        - `iv_t_hi[ray_idx] = min(iv_t_hi[ray_idx], result_t[ray_idx])`
     
     c. **Interval Evaluation & Sign Change Detection:**
        - For each active interval $[t_{lo}, t_{hi}]$, use the inclusion function to compute bounds on $f(t)$.
        - Identify intervals where the sign change occurs (i.e., the interval bounds contain 0, or $f(t_{lo})$ and $f(t_{hi})$ have opposite signs, depending on the specific inclusion function implementation).
        - `sign_change = inclusion.contains_zero(iv_t_lo[ray_idx], iv_t_hi[ray_idx])`
        - `valid_ray = ray_idx[sign_change]`
        - `valid_t_lo = iv_t_lo[sign_change]`
        - `valid_t_hi = iv_t_hi[sign_change]`
        - If no sign changes, break loop (no more hits to find).
     
     d. **Convergence Check:**
        - Check if interval width is below threshold: `converged = (valid_t_hi - valid_t_lo) < threshold`.
        - If converged, record hit:
          - `result_hit[valid_ray] = True`
          - `result_t[valid_ray] = (valid_t_lo + valid_t_hi) * 0.5`
          - `result_t_lo[valid_ray] = valid_t_lo`
          - `result_t_hi[valid_ray] = valid_t_hi`
          - `result_depth[valid_ray] = depth + 1`
        - Mark these rays as converged to remove them from further bisection.
     
     e. **Bisect Step:**
        - For non-converged valid rays:
          - `t_mid = (valid_t_lo + valid_t_hi) * 0.5`
          - Create new intervals:
            - `new_ray_idx = [valid_ray, valid_ray]`
            - `new_t_lo = [valid_t_lo, t_mid]`
            - `new_t_hi = [t_mid, valid_t_hi]`
          - Update `iv_t_lo`, `iv_t_hi`, `ray_idx` with these new intervals.
        - Increment `depth`.

3. **Post-Processing (Optional Newton Refinement):**
   - For rays marked as hit, optional Newton refinement can be applied to converge the hit point to machine precision [S1, unofficial]. This involves evaluating $f$ and its gradient $\nabla f$ at the hit position and iterating $t_{new} = t_{old} - f(t_{old}) / (\nabla f(t_{old}) \cdot direction)$ [S1, unofficial].

**Pseudocode:**

```python
import numpy as np

def bisect_trace(origins, directions, t_min, t_max, hit_mask, inclusion, f, 
                 max_depth=40, threshold=1e-5):
    R = len(origins)
    result_t = np.full(R, t_max)
    result_hit = np.zeros(R, dtype=bool)
    result_t_lo = np.zeros(R)
    result_t_hi = np.zeros(R)
    result_depth = np.zeros(R, dtype=np.int32)
    
    # Active intervals
    ray_idx = np.where(hit_mask)[0]
    iv_t_lo = t_min[ray_idx]
    iv_t_hi = t_max[ray_idx]
    
    for depth in range(max_depth):
        if len(ray_idx) == 0:
            break
            
        # Front-to-back pruning: remove intervals beyond closest hit
        # Note: result_t[ray_idx] might be t_max if no hit yet
        keep = iv_t_lo < result_t[ray_idx]
        ray_idx = ray_idx[keep]
        iv_t_lo = iv_t_lo[keep]
        iv_t_hi = iv_t_hi[keep]
        
        if len(ray_idx) == 0:
            break
            
        # Clip far end to closest hit
        iv_t_hi = np.minimum(iv_t_hi, result_t[ray_idx])
        
        # Evaluate inclusion function for sign change
        # inclusion.contains_zero returns boolean array
        sign_change = inclusion.contains_zero(iv_t_lo, iv_t_hi)
        valid_ray = ray_idx[sign_change]
        valid_t_lo = iv_t_lo[sign_change]
        valid_t_hi = iv_t_hi[sign_change]
        
        if len(valid_ray) == 0:
            break
            
        # Check convergence
        converged = (valid_t_hi - valid_t_lo) < threshold
        
        # Record hits for converged intervals
        hit_indices = valid_ray[converged]
        if len(hit_indices) > 0:
            mid_t = (valid_t_lo[converged] + valid_t_hi[converged]) * 0.5
            result_hit[hit_indices] = True
            result_t[hit_indices] = mid_t
            result_t_lo[hit_indices] = valid_t_lo[converged]
            result_t_hi[hit_indices] = valid_t_hi[converged]
            result_depth[hit_indices] = depth + 1
            
        # Prepare next iteration for non-converged intervals
        not_converged = ~converged
        if np.any(not_converged):
            valid_ray_nc = valid_ray[not_converged]
            valid_t_lo_nc = valid_t_lo[not_converged]
            valid_t_hi_nc = valid_t_hi[not_converged]
            
            t_mid = (valid_t_lo_nc + valid_t_hi_nc) * 0.5
            
            # Concatenate new intervals
            new_ray_idx = np.concatenate([valid_ray_nc, valid_ray_nc])
            new_t_lo = np.concatenate([valid_t_lo_nc, t_mid])
            new_t_hi = np.concatenate([t_mid, valid_t_hi_nc])
            
            # Update active intervals
            # Note: We need to merge with any rays that didn't have sign changes?
            # The algorithm description implies we only process rays with sign changes.
            # Rays without sign changes are discarded (no root in interval).
            ray_idx = new_ray_idx
            iv_t_lo = new_t_lo
            iv_t_hi = new_t_hi
        else:
            ray_idx = np.array([], dtype=int)
            
    # Compute positions
    positions = origins + result_t[:, np.newaxis] * directions
    
    # Compute normals (placeholder logic, actual implementation varies)
    normals = np.zeros_like(directions)
    hit_positions = positions[result_hit]
    if len(hit_positions) > 0:
        # Evaluate gradient at hit positions
        # grad = f.gradient(hit_positions) # Implementation dependent
        # norms = np.linalg.norm(grad, axis=1, keepdims=True)
        # norms = np.maximum(norms, 1e-12)
        # normals[result_hit] = grad / norms
        pass # Placeholder for gradient computation
        
    return TraceResult(
        hit=result_hit,
        t=result_t,
        position=positions,
        normal=normals,
        depth_count=result_depth,
        t_lo=result_t_lo,
        t_hi=result_t_hi
    )
```

**Parameters:**
- `max_depth`: Maximum number of bisection iterations allowed per ray. Default value is 40 [S1, unofficial].
- `threshold`: The convergence width threshold for the bisection interval. The loop terminates when $(t_{hi} - t_{lo}) < threshold$. Default value is $10^{-5}$ [S1, unofficial].
- `batch_size`: Number of rays to process per batch. `None` processes all rays at once. Positive integer splits rays into batches to limit peak memory usage [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Precision/Convergence:** The algorithm uses a threshold (default $10^{-5}$) to determine convergence. If the interval width is below this threshold, the ray is considered converged and removed from further processing [S1, unofficial].
- **Smooth Blends:** Reduced efficiency in the presence of shapes with many smooth blends, as interval evaluations may remain wide for many iterations [S2].
- **Self-Intersection:** The algorithm handles self-intersecting surfaces (e.g., Whitney Umbrella) by finding the nearest intersection [S1, unofficial].

## Subtopics

### Batched Bisection Ray Tracing
Splits ray tracing into batches to limit peak memory usage. Processes each batch independently and merges results. If `batch_size` is `None` or $\ge R$, process all rays in a single call to `bisect_trace`. Otherwise, loop over `start` in `range(0, R, batch_size)`, `end = min(start + batch_size, R)`. Slice `origins`, `directions`, `t_min`, `t_max`, `hit_mask`. Call `bisect_trace` on the slice. Apply Newton refinement if `newton_iter > 0`. Merge results into global result arrays [S1, unofficial]. Parameter: `batch_size`: Number of rays to process per batch. `None` processes all rays at once. Positive integer splits rays into batches [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(R \cdot D)$, where $R$ is the number of rays and $D$ is the average number of bisection steps. Each step involves interval evaluation and bisection.
- **Memory Complexity:** $O(R)$ for storing active intervals and results. Batched processing reduces peak memory usage to $O(B)$, where $B$ is the batch size [S1, unofficial].
- **Measured Performance:** Not given in the sources.
- **Scaling:** Scales linearly with the number of rays. Batched processing allows handling larger scenes with limited memory.
- **Strengths:** Guarantees no surface features are missed, unlike fixed-step ray marching which can skip thin features or high-frequency detail [S1, unofficial]. Robust for arbitrary function-based field definitions [S2].
- **Limitations:** Reduced efficiency in the presence of shapes with many smooth blends [S2]. Interval arithmetic can be computationally expensive compared to direct evaluation.
- **When to Use:** When robustness and feature preservation are critical, and performance is secondary. Suitable for high-frequency surfaces, thin shells, and complex CAD meshes [S1, unofficial].
- **When Not to Use:** When performance is critical and the surface is simple or smooth. When memory is extremely constrained and batched processing is not feasible.

## Background
Originated from the need for robust ray tracing of implicit surfaces. The method relies on iterative interval refinement and interval/affine arithmetics to compute bounds on field variation [S2]. It was implemented in the `iso-surface-rendering` library by narnia-ai-mason [S1, unofficial]. The approach is discussed in the context of fast ray tracing of scale-invariant integral surfaces, where it is noted as a robust alternative to sphere tracing for arbitrary function-based field definitions [S2].
