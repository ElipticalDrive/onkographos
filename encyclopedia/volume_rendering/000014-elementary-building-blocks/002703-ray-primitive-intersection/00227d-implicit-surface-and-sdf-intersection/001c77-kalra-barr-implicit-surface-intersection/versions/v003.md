# Kalra & Barr Implicit Surface Intersection
Also called: Kalra-Barr method, LG-implicit surface intersection [S1, unofficial]

## Overview
Kalra & Barr Implicit Surface Intersection is a robust algorithm for finding the nearest intersection between a ray and an implicit surface $f(\mathbf{x}) = 0$ [S1, unofficial]. It solves the problem of missing fine surface details or grazing intersections inherent in standard discrete ray marching by guaranteeing numerical convergence to the nearest root without requiring fine-tuning or human choice of interactive parameters [S1, unofficial]. It distinguishes itself from other methods by providing a specific mathematical framework for "LG-implicit surfaces" that ensures no features are missed [S1, unofficial].

## How it works
**Inputs:**
- Ray origin $\mathbf{o}$ and direction $\mathbf{d}$ (normalized) [G].
- Implicit surface function $f: \mathbb{R}^3 \to \mathbb{R}$ [G].
- Upper bound $L$: limits the net rate of change of $f$ [S1, unofficial].
- Upper bound $G$: limits the rate of change of the gradient $\nabla f$ [S1, unofficial].
- Search interval $[t_{min}, t_{max}]$ along the ray [G].

**Outputs:**
- Intersection distance $t^*$ if a root exists in $[t_{min}, t_{max}]$ [G].
- Failure status if no root is found [G].

**Data Structures:**
- Interval $[t_a, t_b]$ representing the current search segment along the ray [G].
- Function value $f(\mathbf{x})$ and gradient $\nabla f(\mathbf{x})$ at query points [G].

**Steps:**
1. **Initialization:** Set current interval $[t_a, t_b] = [t_{min}, t_{max}]$ [G].
2. **Evaluation:** Evaluate $f(\mathbf{x}_a)$ and $f(\mathbf{x}_b)$ where $\mathbf{x}_a = \mathbf{o} + t_a \mathbf{d}$ and $\mathbf{x}_b = \mathbf{o} + t_b \mathbf{d}$ [G].
3. **Root Isolation:** Check for a sign change or use interval arithmetic to bound the function over $[t_a, t_b]$ [G].
4. **Refinement:** Iteratively bisect the interval $[t_a, t_b]$ and evaluate the midpoint until the interval width falls below a precision threshold $\delta$ [G].

**Pseudocode:**
```python
def kalra_barr_intersect(o, d, f, L, G, t_min, t_max, delta):
    # The specific interval bounding and step-size logic using L and G is not provided in the sources [G].
    # Standard approach uses L and G to bound function variation over intervals to prevent skipping roots.
    t_a, t_b = t_min, t_max
    while t_b - t_a > delta:
        t_m = (t_a + t_b) / 2.0
        x_m = o + t_m * d
        f_m = f(x_m)
        if abs(f_m) < 1e-6:
            return t_m
        x_a = o + t_a * d
        f_a = f(x_a)
        if f_a * f_m < 0:
            t_b = t_m
        else:
            t_a = t_m
    return (t_a + t_b) / 2.0
```

Choose it when occlusion handling and batched interval arithmetic improve performance in multi-surface scenes.

## Background
The algorithm was presented by Devendra Kalra and Alan Barr in July 1989 [S1, unofficial]. It significantly extends the ability to intersect rays with implicit surfaces in a guaranteed fashion, addressing limitations of existing schemes that worked only for limited sets of implicit functions or were ad-hoc [S1, unofficial].
