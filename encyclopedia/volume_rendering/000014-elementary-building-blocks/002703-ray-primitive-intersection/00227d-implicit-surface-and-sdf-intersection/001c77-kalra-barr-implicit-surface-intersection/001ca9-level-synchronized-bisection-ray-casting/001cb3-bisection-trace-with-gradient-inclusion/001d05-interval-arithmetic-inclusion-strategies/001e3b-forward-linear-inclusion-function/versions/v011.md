# Forward Linear Inclusion Function
Also called: Linear Bounding Function, Linear Inclusion Function

## Overview
The Forward Linear Inclusion Function computes a valid, linear interval bound for a scalar field function $f$ along a ray, ensuring the true function value lies within the computed interval. It solves the problem of determining a safe maximum step size in sphere tracing by finding the intersection of these linear bounds with the zero threshold. It sets itself apart from its siblings, such as the [Improved Quadratic Taylor Inclusion Function](1902-improved-quadratic-taylor-inclusion-function.md), by using first-order linear approximations rather than second-order quadratic ones, making it computationally cheaper but potentially less tight for functions with significant curvature.

## How it works
**Inputs and Outputs:**
- Input: The current sample location on the ray $t_0$, the function value at that location $f(t_0)$, and the Lipschitz constant $\lambda$ of the function $f$ [S1].
- Output: A pair of linear bounding functions $f_-(t)$ and $f_+(t)$, or equivalently, the maximum safe step size $s$ [S1].

**Data Structures:**
No complex data structures are required. The method relies on scalar values for $t_0$, $f(t_0)$, and $\lambda$.

**Steps:**
1.  Evaluate the scalar field function $f$ at the current ray position $t_0$ to obtain $f(t_0)$ [S1].
2.  Define the forward linear inclusion function $[f](t)$ for $t > t_0$. The function must be exact at $t_0$, meaning $f(t_0) = f_-(t_0) = f_+(t_0)$ [S1].
3.  Construct the upper bound $f_+(t)$ and lower bound $f_-(t)$ using the Lipschitz constant $\lambda$ [S1]:
    $$ f_+(t) = f(t_0) + \lambda(t - t_0) $$
    $$ f_-(t) = f(t_0) - \lambda(t - t_0) $$
    This creates a "bounding cone" starting at $f(t_0)$ with slopes $\pm \lambda$ [S1].
4.  To determine the step size for sphere tracing, solve for the intersection of the bounding lines with the zero axis (threshold $v=0$) [S1].
5.  The step size $s$ is given by:
    $$ s = \frac{f(t_0)}{\lambda} $$
    This assumes $f(t_0) > 0$ and we are moving in the direction of increasing $t$ [S1].

**Pseudocode:**
```python
def forward_linear_inclusion_step(f, t0, lambda_val):
    """
    Computes the safe step size for sphere tracing using the Forward Linear Inclusion Function.
    
    Args:
        f: A callable that evaluates the scalar field function at a given t.
        t0: The current position on the ray.
        lambda_val: The Lipschitz constant of the function f.
        
    Returns:
        The maximum safe step size s.
    """
    # Evaluate the function at the current position
    f_t0 = f(t0)
    
    # Calculate the step size by intersecting the linear bound with the zero axis
    # The bound is f(t0) + lambda * (t - t0) = 0 => t - t0 = -f(t0) / lambda
    # Since we want the distance to the surface (where f=0) and f(t0) > 0,
    # the step size is f(t0) / lambda.
    step_size = f_t0 / lambda_val
    
    return step_size
```

**Edge Cases and Pitfalls:**
- If $\lambda = 0$, division by zero occurs. This implies a constant function, which should be handled separately [S1].
- The Lipschitz constant $\lambda$ must be a valid upper bound on the gradient magnitude $|\nabla f|$ for the inclusion property to hold. If $\lambda$ is too small, the bound may not contain the true function value, leading to missed intersections [S1].
- The method assumes the function is differentiable and Lipschitz continuous in the neighborhood of $t_0$ [S1].

## Subtopics

## Operating characteristics
- **Time Complexity:** $O(1)$ per evaluation, as it involves only basic arithmetic operations [S1].
- **Memory Complexity:** $O(1)$, requiring only scalar storage for $f(t_0)$ and $\lambda$ [S1].
- **Performance:** It is computationally efficient compared to higher-order inclusion functions like the [Improved Quadratic Taylor Inclusion Function](1902-improved-quadratic-taylor-inclusion-function.md) [S1]. However, the bounds are generally looser, potentially resulting in smaller step sizes and more sampling points than tighter methods [S1].
- **Strengths:** Simplicity, low computational overhead, and guaranteed safety if $\lambda$ is correct [S1].
- **Limitations:** Less tight bounds for functions with high curvature, leading to reduced performance in sphere tracing compared to quadratic methods [S1].

## Background
The Forward Linear Inclusion Function is a formalization of the step size calculation used in classic sphere tracing [S1]. It provides a rigorous interval arithmetic framework for bounding the scalar field function along a ray, ensuring that the computed step size is safe (i.e., does not overshoot the surface) [S1]. The concept is rooted in the use of Lipschitz constants to bound function variation, a technique common in numerical analysis and interval arithmetic [S1].
