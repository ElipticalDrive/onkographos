# Forward Linear Inclusion Function
Also called: Linear Bounding Function, Linear Inclusion Function

## Overview
The Forward Linear Inclusion Function computes a valid, linear interval bound for a scalar field function $f$ along a ray, ensuring the true function values remain within the calculated bounds. It solves the problem of determining a safe maximum step size for sphere tracing by finding the intersection of these linear bounds with the zero threshold. It sets itself apart from its siblings by providing a computationally inexpensive, first-order approximation that is exact at the current sample point, contrasting with the tighter but more expensive [Improved Quadratic Taylor Inclusion Function](1902-improved-quadratic-taylor-inclusion-function.md) or the black-box [GradientInclusion](1410-interval-arithmetic-inclusion-strategies.md) strategies.

## How it works
**Inputs and Outputs:**
- Input: The scalar field function $f$, the current sample location on the ray $t_0$, the function value $f(t_0)$, and the Lipschitz constant $\lambda$ for the domain.
- Output: An interval $[f](t) = [f_-(t), f_+(t)]$ for $t > t_0$, and the computed step size $\Delta t$.

**Data Structures:**
No complex data structures are required. The method relies on scalar values for $t_0$, $f(t_0)$, and $\lambda$.

**Steps:**
1.  **Evaluate Function:** Compute the value of the implicit function at the current ray position: $v = f(t_0)$.
2.  **Define Bounds:** Construct the lower bound $f_-(t)$ and upper bound $f_+(t)$ as linear functions starting at $v$ at $t_0$. The slope of the upper bound is $\lambda$ and the lower bound is $-\lambda$.
    $$ f_-(t) = f(t_0) - \lambda(t - t_0) $$
    $$ f_+(t) = f(t_0) + \lambda(t - t_0) $$
    This forms a "bounding cone" originating at $(t_0, f(t_0))$ [S1].
3.  **Compute Step Size:** Solve for the intersection of the upper bound $f_+(t)$ with the zero axis (threshold $v=0$). Since $f_-(t)$ is symmetric and $f_+(t)$ is the limiting factor for positive steps when $f(t_0) > 0$, the step size is:
    $$ \Delta t = \frac{f(t_0)}{\lambda} $$
    If $f(t_0) < 0$, the step size is similarly derived from the lower bound intersection, or the absolute value is used for distance [S1].
4.  **Advance Ray:** Update the ray position: $t_{new} = t_0 + \Delta t$.

**Formulas:**
- Inclusion Function: $[f](t) = f(t_0) \pm \lambda(t - t_0)$ for $t > t_0$ [S1].
- Step Size: $\Delta t = |f(t_0)| / \lambda$ [S1].

**Parameters:**
- $\lambda$: The Lipschitz constant. Must be known or estimated for the function $f$ in the vicinity of $t_0$. Typical values depend on the specific noise or SDF function being traced.

**Edge Cases and Pitfalls:**
- **Lipschitz Constant Accuracy:** If $\lambda$ is underestimated, the bound may not contain the true function value, violating the inclusion property and causing the ray to step through the surface (popping artifacts). If $\lambda$ is overestimated, the step size becomes smaller than necessary, reducing performance [S1].
- **Zero Value:** If $f(t_0) = 0$, the step size is 0. The algorithm must handle this to avoid infinite loops, typically by terminating or switching to a different intersection method.
- **Non-Lipschitz Functions:** The method assumes $f$ is Lipschitz continuous. For functions with discontinuities or infinite derivatives, $\lambda$ may not exist or be finite.

**Pseudocode:**
```python
def forward_linear_inclusion_step(f, t0, lambda_val):
    """
    Compute the next step size for sphere tracing using the Forward Linear Inclusion Function.
    
    Args:
        f: Function evaluating the scalar field.
        t0: Current position on the ray.
        lambda_val: Lipschitz constant for f.
        
    Returns:
        delta_t: The safe step size to advance the ray.
    """
    # Evaluate the function at the current point
    f_val = f(t0)
    
    # Handle exact intersection
    if abs(f_val) < 1e-6:
        return 0.0
        
    # Compute step size based on the linear bound intersection with zero
    # The bound is f(t0) +/- lambda * (t - t0)
    # Intersection with 0: 0 = f(t0) + lambda * delta_t  => delta_t = -f(t0)/lambda
    # For distance, we take the absolute value
    delta_t = abs(f_val) / lambda_val
    
    return delta_t
```

## Subtopics

### [Improved Quadratic Taylor Inclusion Function](1902-improved-quadratic-taylor-inclusion-function.md)
A second-order variant that enforces both first-order ($\lambda$) and second-order ($\gamma$) Lipschitz constraints. It provides tighter bounds than the linear function, preventing the bound from growing too fast when the quadratic derivative exceeds the first-order limit. Choose this when higher accuracy is needed and the second derivative is available or estimable.

## Operating characteristics
- **Time Complexity:** $O(1)$ per step. It requires one function evaluation and basic arithmetic operations.
- **Memory Complexity:** $O(1)$. No additional memory is required beyond the scalar values.
- **Performance:** It is the fastest inclusion strategy among the linear and quadratic variants because it avoids the overhead of computing gradients or higher-order terms. However, it may result in smaller step sizes compared to quadratic methods if the function curvature is significant, potentially leading to more sampling steps.
- **Strengths:** Simplicity, low computational cost, easy to implement.
- **Limitations:** Loose bounds compared to quadratic methods, leading to potentially slower convergence for highly curved surfaces. Requires a valid Lipschitz constant.
- **When to use:** When computational resources are limited, or when the function is relatively linear over the step size.
- **When not to use:** When the function has high curvature and a tighter bound is available via [Improved Quadratic Taylor Inclusion Function](1902-improved-quadratic-taylor-inclusion-function.md).

## Background
The Forward Linear Inclusion Function is a fundamental concept in interval arithmetic applied to ray tracing. It formalizes the step size calculation in sphere tracing by using linear bounding functions. The approach is rooted in the work on fast sphere tracing of procedural volumetric noise, where it serves as a baseline for more advanced inclusion strategies [S1]. The concept of using Lipschitz constants to bound function variation is well-established in numerical analysis and interval arithmetic.
