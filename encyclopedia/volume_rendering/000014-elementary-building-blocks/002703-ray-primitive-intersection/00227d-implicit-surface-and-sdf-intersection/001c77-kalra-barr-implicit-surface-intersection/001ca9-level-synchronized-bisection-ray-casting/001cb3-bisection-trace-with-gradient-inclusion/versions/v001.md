# Bisection Trace with Gradient Inclusion

Also called: Level-Synchronized Interval Bisection

## Overview
Bisection Trace with Gradient Inclusion is a robust ray casting algorithm that renders the zero-level-set of an implicit function $f: \mathbb{R}^3 \to \mathbb{R}$ by combining level-synchronized bisection with gradient-based inclusion functions [S1, unofficial]. It solves the problem of missing surface features during ray traversal by using interval arithmetic to guarantee that no zero-crossings are pruned incorrectly [S1, unofficial]. It distinguishes itself from standard bisection by using a Lipschitz constant derived from gradient norms to tighten the inclusion bounds, offering a configurable trade-off between generality and bound tightness [S1, unofficial].

## How it works
**Inputs:** Ray origins $\mathbf{o}$, directions $\mathbf{d}$, near/far clip planes $t_{min}, t_{max}$, implicit function $f(\mathbf{x})$, maximum bisection depth $D_{max}$, convergence threshold $\tau$, and Lipschitz constant $L$ (or 'auto').
**Outputs:** Hit mask, hit distances $t$, and surface normals.

**Data Structures:**
*   **Ray Batch:** Arrays of shape $(N, 3)$ for origins and directions, $(N,)$ for $t_{min}, t_{max}$, and hit status.
*   **Interval Box:** Defined by lower bound $\mathbf{lo}$ and upper bound $\mathbf{hi}$, both shape $(N, 3)$.
*   **Inclusion Function:** Implements `evaluate(lo, hi)` returning conservative bounds $[f_{min}, f_{max}]$ for $f$ over the box.

**Steps:**
1.  **Initialize Inclusion Function:** Create `GradientInclusion(f, lipschitz=L)`. If $L$ is 'auto', estimate it by sampling gradient norms $\|\nabla f\|$ over the bounding box using automatic differentiation [S1, unofficial].
2.  **Batch Processing:** Divide rays into batches of size $B$ (default: process all if $B=None$) to manage memory [S1, unofficial].
3.  **Bisection Loop:** For each active ray in the batch:
    a.  Define current interval $[t_{curr\_min}, t_{curr\_max}]$ along the ray.
    b.  Construct axis-aligned box in $\mathbb{R}^3$ corresponding to the ray segment.
    c.  Evaluate inclusion function: $[f_{min}, f_{max}] = \text{Inclusion}(\text{box})$.
    d.  **Pruning:** If $0 \notin [f_{min}, f_{max}]$, the interval cannot contain a zero crossing. Mark ray as miss or prune [S1, unofficial].
    e.  **Bisection:** If $0 \in [f_{min}, f_{max}]$, compute midpoint $t_{mid} = (t_{curr\_min} + t_{curr\_max}) / 2$.
    f.  **Refinement:** Evaluate $f$ at $\mathbf{x}_{mid} = \mathbf{o} + t_{mid}\mathbf{d}$.
    g.  **Convergence:** If $|f(\mathbf{x}_{mid})| < \tau$ or interval width $< \tau$, record hit at $t_{mid}$ [S1, unofficial].
    h.  **Update:** If not converged, update $t_{curr\_min}$ or $t_{curr\_max}$ based on sign of $f(\mathbf{x}_{mid})$ to maintain zero crossing [S1, unofficial].
    i.  **Depth Check:** If iteration count $> D_{max}$, terminate with best estimate [S1, unofficial].
4.  **Newton Iteration (Optional):** Apply $k$ Newton steps for refinement if enabled [S1, unofficial].

**Parameters:**
*   `max_depth`: Maximum bisection iterations. Typical: 10-20 [S1, unofficial].
*   `threshold`: Convergence tolerance $\tau$. Typical: $10^{-4}$ to $10^{-6}$ [S1, unofficial].
*   `lipschitz`: Lipschitz constant $L$. If 'auto', estimated via gradient sampling [S1, unofficial].
*   `batch_size`: Number of rays per batch. None for all [S1, unofficial].

class GradientInclusion:
    """Inclusion function using gradient bounds."""
    def __init__(self, f_func, lipschitz):
        self.f_func = f_func
        self.L = lipschitz
        
    def evaluate(self, lo, hi):
        """Compute conservative range of f over box [lo, hi]."""
        # Evaluate f at corners or use mean value form [G]
        # f(x) = f(c) + grad(f)(xi) . (x - c)
        # Conservative bound: [f(c) - L*radius, f(c) + L*radius]

        center = 0.5 * (lo + hi)
        radius = np.max(hi - lo, axis=-1) / 2.0 # Half-diagonal length approximation [G]
        
        f_center = self.f_func(center)
        
        # Conservative bounds
        f_min = f_center - self.L * radius
        f_max = f_center + self.L * radius

### [Interval Arithmetic Inclusion Strategies](1410-interval-arithmetic-inclusion-strategies.md)
Computes conservative bounds on $f$ over spatial domains. Distinguishes itself by offering a configurable trade-off between generality and bound tightness, spanning sampling-based estimates to analytic arithmetic.

## Operating characteristics
*   **Time Complexity:** $O(N \cdot D \cdot C)$, where $N$ is number of rays, $D$ is max depth, and $C$ is cost of function evaluation. Gradient estimation adds initial overhead [S1, unofficial].
*   **Memory Complexity:** $O(N)$ for ray state and batch processing [S1, unofficial].
*   **Strengths:** Robust against missing features due to interval pruning; configurable accuracy via Lipschitz constant [S1, unofficial].
*   **Limitations:** Slower than standard bisection due to inclusion function evaluation; requires gradient computation for 'auto' Lipschitz estimation [S1, unofficial].
*   **When to Use:** High-quality rendering of complex implicit surfaces where robustness is critical [S1, unofficial].
*   **When Not to Use:** Real-time applications with strict latency constraints or simple surfaces where standard bisection suffices [S1, unofficial].
