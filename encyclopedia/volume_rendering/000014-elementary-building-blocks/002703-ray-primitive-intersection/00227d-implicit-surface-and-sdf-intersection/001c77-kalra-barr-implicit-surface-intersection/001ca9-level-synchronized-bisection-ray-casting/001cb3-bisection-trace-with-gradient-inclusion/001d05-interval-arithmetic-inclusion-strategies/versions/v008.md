# Interval Arithmetic Inclusion Strategies

Also called: InclusionFunction strategies

## Overview
Interval Arithmetic Inclusion Strategies provide the mathematical mechanism to bound the range of an implicit function $f$ over a 3D bounding box $\mathcal{B}$, ensuring that any zero-crossing within the box is detected during ray casting. They solve the problem of determining whether a ray segment intersects the surface without missing thin features or cusps, which is critical for robust bisection-based rendering. What sets this family apart from its siblings, such as [Lipschitz Constant Estimation](1572-lipschitz-constant-estimation.md) and [Forward Linear Inclusion Function](1714-forward-linear-inclusion-function.md), is the variety of approximation techniques used to compute these bounds, ranging from black-box sampling to analytic interval arithmetic, allowing a trade-off between computational tightness and the availability of symbolic function information.

## Shared principles
All inclusion strategies in this family compute an interval $[f](\mathcal{B})$ such that for all $\mathbf{x} \in \mathcal{B}$, $f(\mathbf{x}) \in [f](\mathcal{B})$. If $0 \notin [f](\mathcal{B})$, the box $\mathcal{B}$ is guaranteed not to contain a zero-level set intersection and can be pruned. If $0 \in [f](\mathcal{B})$, the box may contain an intersection and requires further subdivision or evaluation.

The strategies are categorized by the information they require about the implicit function $f$:
1.  **Black-box access:** Only point evaluations $f(\mathbf{x})$ are available.
2.  **Gradient access:** The gradient $\nabla f(\mathbf{x})$ is available.
3.  **Analytic access:** The symbolic formula of $f$ is available, allowing the use of interval arithmetic operators.

The choice of strategy affects the tightness of the bound $[f](\mathcal{B})$. Tighter bounds reduce the number of bisection steps required to converge to the surface, improving performance. However, tighter bounds often require more complex computations or specific function properties.

## Subtopics

### [Lipschitz Constant Estimation](1572-lipschitz-constant-estimation.md)
Computes the maximum rate of change (gradient magnitude) of an implicit function $f$ over a domain to determine a safe stepping distance for ray marching. It solves the problem of ensuring that sphere tracing or bisection steps do not overshoot the zero-level set, which would cause visual artifacts or convergence failure. It differs from its sibling [Forward Linear Inclusion Function](1714-forward-linear-inclusion-function.md) by focusing on the scalar bound $\lambda$ required for step-size calculation rather than constructing the full interval inclusion function $[f](\mathcal{B})$ directly, although both rely on gradient information. [Lipschitz Constant Estimation](1572-lipschitz-constant-estimation.md)

### [Forward Linear Inclusion Function](1714-forward-linear-inclusion-function.md)
The Forward Linear Inclusion Function computes a valid, linear interval bound for a scalar field function $f$ along a ray, ensuring that the true function value at any point $t > t_0$ lies within the calculated interval. It solves the problem of determining a safe step size for sphere tracing by providing a conservative estimate of the distance to the zero-level set. It sets itself apart from its siblings, such as the [Improved Quadratic Taylor Inclusion Function](1902-improved-quadratic-taylor-inclusion-function.md), by using first-order linear bounds rather than second-order quadratic approximations, making it simpler but potentially less tight for functions with significant curvature. [Forward Linear Inclusion Function](1714-forward-linear-inclusion-function.md)

### Parallel Tape Reduction
A method that simplifies the SDF expression in specific regions of space by coupling pruning and rendering, using interval arithmetic to evaluate nodes. It relies on well-defined interval arithmetic queries for each node in the construction tree to determine pruning eligibility. It differs from Lipschitz pruning by using interval arithmetic instead of 1-Lipschitz bounds, requiring explicit interval queries per node rather than treating primitives as black boxes [S2].

## Background
The concept of using interval arithmetic for robust geometric queries in computer graphics was pioneered by researchers such as Martin Held and others in the context of constructive solid geometry (CSG) and implicit surface rendering. The specific application of interval arithmetic to ray casting for robust iso-surface rendering, particularly for black-box functions, has been popularized in recent years by libraries such as `isoray` [S1, unofficial]. The use of hierarchical pruning with interval arithmetic, known as parallel tape reduction, has been explored in the context of large-scale SDF scenes to handle thousands of nodes efficiently [S2]. These methods address the limitations of traditional ray marching, which can miss thin features or fail to converge on complex surfaces due to discretization errors or insufficient step size control.
