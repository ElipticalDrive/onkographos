# Lipschitz Constant Estimation


## Overview
Estimates the global Lipschitz constant $\lambda$ for an implicit function $f: \mathbb{R}^d \rightarrow \mathbb{R}$, which represents the maximum rate of change (maximum gradient magnitude) of the function. This constant is a prerequisite for interval inclusion strategies, specifically [SamplingInclusion](1410-interval-arithmetic-inclusion-strategies.md), to compute safe bounding intervals for pruning. It distinguishes itself from [GradientInclusion](1410-interval-arithmetic-inclusion-strategies.md) by providing a single scalar bound for the entire domain rather than local gradient-based bounds, and from [AffineInclusion](1410-interval-arithmetic-inclusion-strategies.md) by being a pre-computation step rather than an analytic propagation technique.

## How it works
**Inputs:**
- Implicit function $f(\mathbf{x})$.
- Bounding box $\mathcal{B}$ of the region of interest.
- Sampling resolution $N$ (number of points per dimension).
- Mode: "auto" (estimate) or fixed float $\lambda$.

**Outputs:**
- Scalar Lipschitz constant $\lambda$.

**Data Structures:**
- `gradients`: Array of shape $(N^d, d)$ storing gradient vectors at sampled points.

**Steps:**
1. If mode is fixed float, return $\lambda$.
2. Sample the gradient $\nabla f(\mathbf{x})$ at $N^d$ points uniformly distributed within $\mathcal{B}$ [S2, unofficial].
3. Compute the Euclidean norm $\|\nabla f(\mathbf{x})\|$ for each sample.
4. Set $\lambda = \max_{\mathbf{x} \in \text{samples}} \|\nabla f(\mathbf{x})\|$ [S2, unofficial].

**Formula:**
The Lipschitz constant is defined as the supremum of the difference quotient [S1]:
$$
Lip(f) = \max_{\mathbf{x}, \mathbf{y} \in \mathcal{B}, \mathbf{x} \neq \mathbf{y}} \frac{|f(\mathbf{x}) - f(\mathbf{y})|}{\|\mathbf{x} - \mathbf{y}\|}
$$
For differentiable functions, this is equivalent to the maximum norm of the gradient [S1]:
$$
\lambda = \max_{\mathbf{x} \in \mathcal{B}} \|\nabla f(\mathbf{x})\|
$$

**Parameters:**
- `lipschitz`: Can be a float value or the string "auto". If "auto", the constant is estimated automatically [S2, unofficial].
- `N`: Sampling resolution. Not given in the sources.

**Edge Cases:**
- If $f$ is not differentiable, the gradient-based estimation may fail or require subgradient approximations [G].
- Sparse sampling may underestimate $\lambda$ if the maximum gradient occurs between sample points [G].

**Pseudocode:**
```python
import numpy as np

def estimate_lipschitz(f, bounding_box, resolution=10, mode="auto"):
    """
    Estimate the Lipschitz constant for implicit function f over bounding_box.
    
    Args:
        f: Implicit function taking (x, y, z) and returning float.
        bounding_box: Tuple of ((min_x, min_y, min_z), (max_x, max_y, max_z)).
        resolution: Number of samples per dimension.
        mode: "auto" to estimate, or float for fixed value.
        
    Returns:
        float: Estimated Lipschitz constant.
    """
    if mode != "auto":
        return float(mode)
    
    min_coords, max_coords = bounding_box
    dims = 3
    
    # Generate grid points
    coords = []
    for i in range(dims):
        coords.append(np.linspace(min_coords[i], max_coords[i], resolution))
    
    grid = np.meshgrid(*coords, indexing='ij')
    points = np.vstack([g.flatten() for g in grid]).T  # Shape (N^3, 3)
    
    # Compute gradients using centered differences
    # Note: This assumes f is differentiable. For non-differentiable functions, 
    # this may need adjustment [G].
    eps = 1e-5
    gradients = np.zeros_like(points)
    
    for i in range(dims):
        points_plus = points.copy()
        points_minus = points.copy()
        points_plus[:, i] += eps
        points_minus[:, i] -= eps
        
        f_plus = np.array([f(p[0], p[1], p[2]) for p in points_plus])
        f_minus = np.array([f(p[0], p[1], p[2]) for p in points_minus])
        
        gradients[:, i] = (f_plus - f_minus) / (2 * eps)
        
    # Compute norms
    norms = np.linalg.norm(gradients, axis=1)
    
    # Return max norm
    return float(np.max(norms))
```

## Subtopics

## Operating characteristics
- **Time Complexity:** $O(N^d \cdot d)$ for gradient estimation, where $N$ is resolution and $d$ is dimension. Each gradient evaluation requires $2d$ function evaluations.
- **Memory Complexity:** $O(N^d \cdot d)$ to store gradients.
- **Strengths:** Simple to implement; works for black-box functions where symbolic derivatives are unavailable.
- **Limitations:** Sampling may miss local maxima of the gradient, leading to underestimation and incorrect pruning (false negatives) or overly conservative bounds if the estimate is too high. Computationally expensive for high-resolution sampling.
- **When to use:** When symbolic derivatives are unavailable and a global bound is required for [SamplingInclusion](1410-interval-arithmetic-inclusion-strategies.md).
- **When not to use:** When tighter bounds are needed (use [GradientInclusion](1410-interval-arithmetic-inclusion-strategies.md) or [AffineInclusion](1410-interval-arithmetic-inclusion-strategies.md)) or when the function is analytic (use [NaturalIntervalInclusion](1410-interval-arithmetic-inclusion-strategies.md)).

## Background
The concept of Lipschitz continuity is fundamental in analysis and numerical methods. In volume rendering, it was introduced for sphere tracing by [Har96] to guarantee safe stepping distances. The specific estimation via gradient sampling is used in modern implicit surface rendering pipelines to enable robust interval arithmetic-based pruning [S2, unofficial]. The hierarchical variant for procedural models was developed to handle complex implicit constructions [S1].
