# Forward Linear Inclusion Function

Also called: Linear Bounding Function, Linear Inclusion Function

## Overview
The Forward Linear Inclusion Function computes valid, conservative bounds for a scalar field $f(t)$ along a ray, ensuring the true function value lies within the calculated interval. It solves the problem of determining a safe step size for sphere tracing by intersecting these linear bounds with the zero threshold. It sets itself apart from its siblings, such as the [Improved Quadratic Taylor Inclusion Function](1902-improved-quadratic-taylor-inclusion-function.md), by using first-order linear approximations rather than second-order quadratic ones, prioritizing computational simplicity over bound tightness [S1].

## How it works
**Inputs and Outputs**
- **Input**: The current sample location on the ray $t_0$, the scalar field value at that location $f(t_0)$, and the Lipschitz constant $\lambda$ for the function in the neighborhood of $t_0$.
- **Output**: An interval $[f](t)$ representing the lower bound $f_-(t)$ and upper bound $f_+(t)$ for any $t > t_0$, and the computed step size $d$ to the next sample point.

**Data Structures**
No complex data structures are required. The method operates on scalar values:
- $t_0$: Current ray parameter (float).
- $f(t_0)$: Scalar field value at $t_0$ (float).
- $\lambda$: Lipschitz constant (float, $\lambda \geq 0$).
- $[f](t)$: Interval bounds, defined by $f_-(t)$ and $f_+(t)$.

**Numbered Steps**
1. **Evaluate Field**: Compute the scalar field value $f(t_0)$ at the current ray position.
2. **Determine Lipschitz Constant**: Obtain $\lambda$, the upper bound on the magnitude of the gradient of $f$ in the vicinity of $t_0$. This value must be known or estimated beforehand (e.g., via [Lipschitz Constant Estimation](1572-lipschitz-constant-estimation.md)).
3. **Construct Bounds**: Define the forward linear inclusion function for $t > t_0$. The function is exact at $t_0$, meaning $f_-(t_0) = f_+(t_0) = f(t_0)$. The bounds are linear functions extending from $t_0$:
   $$ f_-(t) = f(t_0) - \lambda(t - t_0) $$
   $$ f_+(t) = f(t_0) + \lambda(t - t_0) $$
   This forms a "bounding cone" starting at $f(t_0)$ [S1].
4. **Compute Step Size**: To find the next sample point, solve for the intersection of the upper bound $f_+(t)$ with the zero threshold (assuming $f(t_0) > 0$ and seeking the surface where $f(t)=0$). The step size $d$ is the distance $t - t_0$ such that $f_+(t) = 0$:
   $$ f(t_0) + \lambda(d) = 0 \implies d = \frac{f(t_0)}{\lambda} $$
   If $f(t_0) < 0$, the lower bound $f_-(t)$ is intersected with zero, yielding $d = \frac{|f(t_0)|}{\lambda}$. Generally, the step size is:
   $$ d = \frac{|f(t_0)|}{\lambda} $$
5. **Advance Ray**: Update the ray parameter: $t_{new} = t_0 + d$.

**Formulas**
- **Inclusion Function**:
  $$ [f](t) = f(t_0) \pm \lambda(t - t_0), \quad \forall t > t_0 $$
  Where:
  - $[f](t)$ is the interval containing all possible values of $f(t)$.
  - $f(t_0)$ is the exact function value at the query point.
  - $\lambda$ is the Lipschitz constant.
  - $t$ is the ray parameter.
- **Step Size**:
  $$ d = \frac{|f(t_0)|}{\lambda} $$

**Parameters**
- $\lambda$: The Lipschitz constant. Typical values depend on the specific scalar field (e.g., noise functions). It must be a valid upper bound on the gradient magnitude; underestimating $\lambda$ leads to invalid bounds and missed intersections [S1].

**Edge Cases and Pitfalls**
- **Zero Lipschitz Constant**: If $\lambda = 0$, division by zero occurs. This implies a constant function, where no intersection exists unless $f(t_0)=0$ [G].
- **Inaccurate $\lambda$**: If $\lambda$ is too small, the bound $f_+(t)$ may cross zero before the actual function $f(t)$ does, causing the algorithm to step too far and miss the surface. If $\lambda$ is too large, the step size is conservative, leading to more samples and reduced performance [S1].
- **Sign of $f(t_0)$**: The step size calculation must use the absolute value to ensure the step is always positive and directed towards the zero crossing [S1].

    """

## Subtopics

## Operating characteristics
- **Time Complexity**: $O(1)$ per step. The calculation involves a few arithmetic operations (absolute value, division).
- **Memory Complexity**: $O(1)$. No additional memory is required beyond the scalar values.
- **Measured Performance**: The method is computationally inexpensive, making it suitable for real-time rendering. However, the bounds are generally looser than quadratic methods, resulting in smaller step sizes and more samples per ray [S1].
- **Scaling**: Performance scales linearly with the number of samples. The accuracy of the step size depends heavily on the tightness of $\lambda$.
- **Strengths**: Simple to implement, analytically solvable, and robust if $\lambda$ is correctly bounded.
- **Limitations**: Less efficient than higher-order inclusion functions (like the [Improved Quadratic Taylor Inclusion Function](1902-improved-quadratic-taylor-inclusion-function.md)) because the linear bounds diverge faster from the true function, leading to more conservative (smaller) step sizes [S1].
- **When to use**: When computational simplicity is prioritized, or when the Lipschitz constant is already known and tight.
- **When not to use**: When high performance is critical and the scalar field allows for tighter quadratic bounds, or when $\lambda$ is difficult to estimate tightly.

## Background
The Forward Linear Inclusion Function is a foundational concept in interval arithmetic applied to ray tracing. It formalizes the step size calculation in classic sphere tracing [Har96] using the language of inclusion functions [S1]. The specific terminology and formalization of "forward linear inclusion functions" in the context of procedural volumetric noise and large-scale scenes are discussed in [S1].
