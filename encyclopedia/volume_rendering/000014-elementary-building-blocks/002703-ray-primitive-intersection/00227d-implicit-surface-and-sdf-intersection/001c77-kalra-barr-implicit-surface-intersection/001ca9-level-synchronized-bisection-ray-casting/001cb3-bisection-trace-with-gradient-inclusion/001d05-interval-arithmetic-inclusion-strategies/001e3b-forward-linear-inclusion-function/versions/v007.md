# Forward Linear Inclusion Function

Also called: Linear Bounding Function, Linear Inclusion Function

## Overview
The Forward Linear Inclusion Function computes a valid interval bound for a scalar field function $f$ along a ray, ensuring the true function values are contained within the calculated range. It solves the problem of determining a safe maximum step size for sphere tracing by intersecting linear bounding lines with the zero threshold. It sets itself apart from its siblings, such as the [Improved Quadratic Taylor Inclusion Function](1902-improved-quadratic-taylor-inclusion-function.md), by using first-order linear bounds rather than second-order quadratic approximations, making it suitable when only a Lipschitz constant is available or when tighter quadratic bounds are not required.

## How it works
**Inputs and Outputs:**
- Input: The current sample location on the ray $t_0$, the function value at that location $f(t_0)$, and the Lipschitz constant $\lambda$ for the function $f$ in the neighborhood of $t_0$.
- Output: An interval $[f](t)$ for $t > t_0$, and the computed step size $\Delta t$ to the next sample point.

**Data Structures:**
No complex data structures are required. The method operates on scalar values representing the ray parameter $t$ and the function value $f$.

**Steps:**
1.  **Evaluate Function:** Compute the value of the implicit function at the current ray position $t_0$, denoted as $f(t_0)$.
2.  **Define Bounds:** Construct the lower bound $f_-(t)$ and upper bound $f_+(t)$ using the forward linear inclusion formula. The bounds must be exact at $t_0$, meaning $f_-(t_0) = f_+(t_0) = f(t_0)$.
    $$
    f_-(t) = f(t_0) - \lambda (t - t_0)
    $$
    $$
    f_+(t) = f(t_0) + \lambda (t - t_0)
    $$
    where $\lambda$ is the Lipschitz constant satisfying $|f(\mathbf{x}) - f(\mathbf{y})| \leq \lambda \|\mathbf{x} - \mathbf{y}\|$ for all $\mathbf{x}, \mathbf{y}$ in the domain.
3.  **Compute Step Size:** Determine the intersection of the bounding lines with the zero axis (or threshold $v=0$). Since the function value $f(t_0)$ indicates the distance to the surface (in standard sphere tracing), the step size is derived from the upper bound if $f(t_0) > 0$ (outside) or the lower bound if $f(t_0) < 0$ (inside), ensuring the step does not overshoot the surface.
    $$
    \Delta t = \frac{|f(t_0)|}{\lambda}
    $$
4.  **Update Ray:** Advance the ray position by $\Delta t$.

**Pseudocode:**
```python
def forward_linear_inclusion_function(f, t0, lambda_val):
    """
    Computes the step size for sphere tracing using a forward linear inclusion function.
    
    Args:
        f: A callable that evaluates the scalar field function at a point.
        t0: The current position on the ray (scalar).
        lambda_val: The Lipschitz constant for the function f.
        
    Returns:
        delta_t: The safe step size to advance along the ray.
    """
    # Evaluate the function at the current ray position
    f_t0 = f(t0)
    
    # Calculate the step size based on the linear bound intersection with zero
    # The bound is f(t0) +/- lambda * (t - t0)
    # Intersection with 0 gives t - t0 = -f(t0) / lambda (for upper bound if f(t0)>0)
    # The magnitude is |f(t0)| / lambda
    if lambda_val == 0:
        # Guard against division by zero; if lambda is 0, the function is constant.
        # If f(t0) is not 0, no intersection exists (infinite step or error).
        # If f(t0) is 0, we are on the surface.
        if f_t0 == 0:
            return 0.0
        else:
            # Not given in the sources how to handle non-zero constant function with lambda=0.
            # [G] Return a small epsilon or handle as error to prevent infinite loop.
            return 1e-6 
            
    delta_t = abs(f_t0) / lambda_val
    
    return delta_t
```

**Edge Cases and Pitfalls:**
- **Lipschitz Constant Accuracy:** The step size is directly proportional to $1/\lambda$. If $\lambda$ is overestimated, the step size becomes smaller than necessary, reducing performance. If $\lambda$ is underestimated, the inclusion property is violated, potentially causing the ray to overshoot the surface and miss intersections.
- **Zero Lipschitz Constant:** If $\lambda = 0$, the function is locally constant. If $f(t_0) \neq 0$, the surface is not nearby, and the concept of a finite step size to the surface via this method is undefined.
- **Precision:** Standard floating-point arithmetic is sufficient, but care should be taken when $f(t_0)$ is very small to avoid numerical instability in the division.

## Subtopics

### [Improved Quadratic Taylor Inclusion Function](1902-improved-quadratic-taylor-inclusion-function.md)
Uses second-order Taylor expansion with both first and second-order Lipschitz constraints to provide tighter bounds than linear functions, especially for smooth functions. Choose this when higher accuracy is needed and second derivatives or second-order Lipschitz constants are available.

## Operating characteristics
- **Time Complexity:** $O(1)$ per evaluation, involving one function evaluation and basic arithmetic operations.
- **Memory Complexity:** $O(1)$, requiring storage for $t_0$, $f(t_0)$, and $\lambda$.
- **Performance:** The linear bound is generally looser than quadratic bounds, potentially resulting in smaller step sizes and more samples per ray compared to higher-order methods. However, it is computationally cheaper per step if derivative information is not readily available.
- **Strengths:** Simple to implement, requires only the Lipschitz constant (first-order derivative bound), and guarantees no overshoot if $\lambda$ is valid.
- **Limitations:** Less efficient than quadratic methods for smooth functions where tighter bounds can be computed. Requires a valid global or local Lipschitz constant.

## Background
The forward linear inclusion function is a fundamental concept in interval arithmetic applied to ray tracing, formalized in the context of sphere tracing. It is described in [S1] as a method to formalize step size calculation by finding intersections of bounding functions with the threshold. The approach builds on the general principles of interval arithmetic inclusion strategies, where the goal is to enclose the function range within a valid interval.
