# Lipschitz Constant Estimation


## Overview
Lipschitz Constant Estimation computes the maximum rate of change (gradient magnitude) of an implicit function $f$ over a domain to determine a safe stepping distance for ray marching. It solves the problem of ensuring that sphere tracing or bisection steps do not overshoot the zero-level set, which would cause visual artifacts or convergence failure. It differs from its sibling [Forward Linear Inclusion Function](1714-forward-linear-inclusion-function.md) by focusing on the scalar bound $\lambda$ required for step-size calculation rather than constructing the full interval inclusion function $[f](\mathcal{B})$ directly, although both rely on gradient information.

## How it works
**Inputs:**
- Implicit function $f: \mathbb{R}^3 \rightarrow \mathbb{R}$.
- Bounding box $\mathcal{B}$ (or specific segment $\mathbf{e}$ for hierarchical variants).
- Parameter `lipschitz`: Either a pre-computed float $\lambda$ or the string `"auto"`.

**Outputs:**
- Lipschitz constant $\lambda$ such that $\forall \mathbf{x}, \mathbf{y} \in \mathcal{B}, \frac{|f(\mathbf{x}) - f(\mathbf{y})|}{\|\mathbf{x} - \mathbf{y}\|} \leq \lambda$.

**Data Structures:**
- Gradient vector $\nabla f(\mathbf{x}) = [\frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}, \frac{\partial f}{\partial z}]$.
- Norm $\|\nabla f(\mathbf{x})\| = \sqrt{(\frac{\partial f}{\partial x})^2 + (\frac{\partial f}{\partial y})^2 + (\frac{\partial f}{\partial z})^2}$.

**Steps:**
1. If `lipschitz` is a float, return it as $\lambda$ [S2, unofficial].
2. If `lipschitz` is `"auto"`, estimate $\lambda$ by sampling the gradient norm over the domain:
   a. Define a sampling grid over $\mathcal{B}$. The sources do not specify the resolution or sampling pattern (e.g., uniform, random, or corner-only) [G].
   b. For each sample point $\mathbf{x}_i$:
      i. Compute the gradient $\nabla f(\mathbf{x}_i)$ using central differences or analytical derivatives if available [S2, unofficial].
      ii. Compute the norm $g_i = \|\nabla f(\mathbf{x}_i)\|$.
   c. Set $\lambda = \max_i (g_i)$.
3. Use $\lambda$ to compute safe step sizes. For sphere tracing, the step size $t$ at position $\mathbf{x}$ is often bounded by $t \leq \frac{|f(\mathbf{x})|}{\lambda}$ [S1].

**Formula:**
The Lipschitz constant is defined as the supremum of the difference quotient:
$$ Lip(f) = \max_{\mathbf{x}, \mathbf{y} \in \mathcal{B}, \mathbf{x} \neq \mathbf{y}} \frac{|f(\mathbf{x}) - f(\mathbf{y})|}{\|\mathbf{x} - \mathbf{y}\|} $$
For differentiable functions, this is equivalent to the maximum gradient magnitude:
$$ \lambda = \max_{\mathbf{x} \in \mathcal{B}} \|\nabla f(\mathbf{x})\| $$
where $\nabla f(\mathbf{x})$ is the gradient of $f$ at $\mathbf{x}$ [S1].

**Parameters:**
- `lipschitz`: `float` or `"auto"`. Default is often `1.0` in example implementations, but `"auto"` triggers estimation [S2, unofficial].

**Edge Cases and Pitfalls:**
- **Non-differentiable points:** If $f$ has discontinuities or non-differentiable regions (e.g., sharp Boolean intersections), the gradient norm may be undefined or infinite. Sampling-based estimation might miss these peaks if they occur between sample points [G].
- **Underestimation:** If the sampling grid is too coarse, the estimated $\lambda$ may be smaller than the true maximum, leading to steps that cross the surface and causing artifacts [G].
- **Overestimation:** A conservative global bound (e.g., assuming maximum possible gradient for noise) is safe but reduces performance by forcing smaller steps [S1].

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the number of sample points used for estimation. Each sample requires evaluating $f$ and its derivatives.
- **Memory Complexity:** $O(1)$ if computed on-the-fly during rendering, or $O(N)$ if pre-computed and stored.
- **Performance:** Tighter bounds (accurate $\lambda$) allow larger steps, reducing the number of function evaluations per ray. Looser bounds increase evaluation count.
- **Strengths:** Provides a rigorous guarantee for step safety in sphere tracing.
- **Limitations:** Requires gradient computation. For black-box functions without derivatives, finite differences are needed, increasing cost.

## Background
The concept originates from Lipschitz continuity in analysis, applied to ray tracing by Williams [Har96] for sphere tracing. The specific implementation of estimating $\lambda$ via gradient sampling is detailed in recent work on procedural volumetric noise [S1] and robust iso-surface rendering [S2, unofficial].
