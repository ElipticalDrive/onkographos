# Forward Linear Inclusion Function

Also called: Linear Bounding Function, Linear Inclusion Function

## Overview
The Forward Linear Inclusion Function is a method for computing valid, linear interval bounds for a scalar field function $f(t)$ along a ray, used to determine safe step sizes in sphere tracing. It sets itself apart from its siblings, such as the [Improved Quadratic Taylor Inclusion Function](1902-improved-quadratic-taylor-inclusion-function.md), by using first-order Lipschitz constraints to define a bounding cone, which is simpler to compute but potentially looser than higher-order approximations.

## How it works
**Inputs and Outputs**
- Input: The scalar field function $f$, a query point $t_0$ on the ray, and the Lipschitz constant $\lambda$ for the domain.
- Output: An interval $[f](t) = [f_-(t), f_+(t)]$ for $t > t_0$, and the computed step size to the next sample.

**Data Structures**
No complex data structures are required. The method relies on the scalar value $f(t_0)$ and the scalar constant $\lambda$.

**Steps**
1. Evaluate the scalar field at the current ray position $t_0$:
   $$ v_0 = f(t_0) $$
2. Define the forward linear inclusion function bounds for $t > t_0$. The function is exact at $t_0$, meaning $f_-(t_0) = f_+(t_0) = v_0$. The bounds are linear functions with slopes determined by the Lipschitz constant $\lambda$:
   $$ f_-(t) = v_0 - \lambda(t - t_0) $$
   $$ f_+(t) = v_0 + \lambda(t - t_0) $$
   Thus, the inclusion function is:
   $$ [f](t) = v_0 \pm \lambda(t - t_0) $$
3. To find the safe step size, compute the intersection of the upper bound $f_+(t)$ with the zero threshold (assuming $v_0 > 0$ and seeking the first zero crossing). Solve for $t$ where $f_+(t) = 0$:
   $$ 0 = v_0 + \lambda(t - t_0) $$
   $$ t - t_0 = -\frac{v_0}{\lambda} $$
   Since we are looking for a forward step ($t > t_0$) and assuming the standard sphere tracing context where we move in the direction of the ray and $v_0$ represents distance to surface (positive inside, negative outside, or vice versa depending on convention), the magnitude of the step is:
   $$ \Delta t = \frac{|v_0|}{\lambda} $$
   If $v_0$ is the signed distance, the step is $v_0 / \lambda$ if $v_0 > 0$.

**Parameters**
- $\lambda$: The Lipschitz constant of the function $f$. This must be known or estimated for the domain. Typical values depend on the specific noise or implicit function being evaluated.

**Edge Cases and Pitfalls**
- If $\lambda = 0$, the function is constant, and the step size calculation involves division by zero. This implies no variation, so the ray never intersects (or is always inside/outside).
- The bound is only valid if $\lambda$ is a true global Lipschitz constant for the region. If $\lambda$ is too small, the bound may not contain the true function values, leading to missed intersections.
- The linear bound is exact only at $t_0$. As $t$ moves away from $t_0$, the gap between the bound and the true function grows, potentially leading to smaller, inefficient step sizes compared to tighter bounds like quadratic ones.

**Pseudocode**
```python
def forward_linear_inclusion_step(f, t0, lambda_val):
    """
    Computes the safe step size for sphere tracing using forward linear inclusion.
    
    Args:
        f: Function evaluating the scalar field.
        t0: Current position on the ray.
        lambda_val: Lipschitz constant for the scalar field.
        
    Returns:
        step_size: The distance to the next sample point.
    """
    v0 = f(t0)
    
    # Handle case where we are exactly on the surface
    if abs(v0) < 1e-6:
        return 0.0
        
    # Calculate step size based on the intersection of the upper bound with zero
    # The upper bound is f(t) = v0 + lambda * (t - t0)
    # Setting f(t) = 0 gives t - t0 = -v0 / lambda
    # The step size is the magnitude of this difference
    step_size = abs(v0 / lambda_val)
    
    return step_size
```

## Subtopics

### [Improved Quadratic Taylor Inclusion Function](1902-improved-quadratic-taylor-inclusion-function.md)
Uses second-order derivatives to provide tighter bounds, switching to linear when necessary. Choose this when higher accuracy is needed and second derivatives are available.

## Operating characteristics
- **Time Complexity**: $O(1)$ per step, involving one function evaluation and basic arithmetic.
- **Memory Complexity**: $O(1)$, storing only $v_0$ and $\lambda$.
- **Performance**: Simple and fast, but the linear bound is generally looser than quadratic bounds, potentially resulting in smaller step sizes and more samples.
- **Strengths**: Easy to implement, requires only first-order Lipschitz information.
- **Limitations**: Less tight bounds than higher-order methods, leading to potentially slower convergence in complex scenes.

## Background
The concept of forward inclusion functions for sphere tracing was formalized in the context of procedural volumetric noise rendering [S1]. It provides a rigorous mathematical framework for determining safe step sizes by bounding the scalar field function.
