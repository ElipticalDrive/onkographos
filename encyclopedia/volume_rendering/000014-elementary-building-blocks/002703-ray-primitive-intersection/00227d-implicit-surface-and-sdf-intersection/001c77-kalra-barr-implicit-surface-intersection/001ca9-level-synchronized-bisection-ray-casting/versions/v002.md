# Level-synchronized bisection ray casting

Also called: Batch bisection, Iso-surface bisection, Ray Subdivision and Interval Processing

## Overview
Level-synchronized bisection ray casting is a robust algorithm for rendering the zero-level-set of an implicit function $f: \mathbb{R}^3 \to \mathbb{R}$ by processing all active rays in lockstep using interval arithmetic to guarantee no surface features are missed [S1, unofficial]. It solves the problem of missing fine surface details or grazing intersections inherent in standard discrete ray marching by bounding the function value over continuous segments and iteratively bisecting intervals until convergence [S1, unofficial]. It builds on [Kalra & Barr Implicit Surface Intersection](1278-kalra-barr-implicit-surface-intersection.md) and differs from [Bisection Ray Tracing with Interval Inclusion](1314-bisection-ray-tracing-with-interval-inclusion.md) by its specific implementation of level-synchronized processing and Hermite-based root estimation [S1, unofficial][S2].

## How it works
**Inputs:**
- Ray origins $\mathbf{o} \in \mathbb{R}^R$, directions $\mathbf{d} \in \mathbb{R}^R$ (normalized) [S1, unofficial].
- Scene bounds $[\mathbf{b}_{min}, \mathbf{b}_{max}] \subset \mathbb{R}^3$ [S1, unofficial].
- Implicit function $f(\mathbf{p})$ and an `InclusionFunction` object providing bounds over 3D axis-aligned boxes [S1, unofficial].
- Parameters: `max_depth` (integer, default 40), `threshold` (float, default $10^{-5}$) [S1, unofficial].

**Outputs:**
- `TraceResult` dataclass containing:
  - `hit`: boolean array $(R,)$, true if surface found.
  - `t`: float64 array $(R,)$, distance to hit.
  - `position`: float64 array $(R, 3)$, world position of hit.
  - `normal`: float64 array $(R, 3)$, surface normal at hit.
  - `depth_count`: int array $(R,)$, number of bisection steps.
  - `t_lo`, `t_hi`: float64 arrays $(R,)$, final interval bounds [S1, unofficial].

**Data Structures:**
- `ray_idx`: Array of active ray indices [S1, unofficial].
- `iv_t_lo`, `iv_t_hi`: Arrays of interval endpoints for active rays [S1, unofficial].
- `hit_mask`: Boolean mask identifying rays intersecting the scene AABB [S1, unofficial].

**Steps:**

1. **Initialization:**
   - Initialize `result_hit` to `False`, `result_t` to `inf`, `result_t_lo` to `inf`, `result_t_hi` to `inf`, `result_depth` to `0` [S1, unofficial].
   - Compute ray-AABB intersection for all rays [S1, unofficial].
   - Identify active rays where intersection exists and $t_{max} > t_{min}$ [S1, unofficial].
   - Set `ray_idx` to indices of active rays [S1, unofficial].
   - Set `iv_t_lo` to $t_{min}$ and `iv_t_hi` to $t_{max}$ for active rays [S1, unofficial].

2. **Ray Subdivision (Pre-processing):**
   - Subdivide the ray parameter space $[t_{min}, t_{max}]$ into intervals [S2].
   - Subdivide further when switching between areas overlapped by primitive supports and areas not overlapped by any primitive support to avoid processing empty areas [S2].
   - For each resulting interval $[t_{begin}, t_{end}]$, proceed to interval processing [S2].

3. **Level-Synchronized Bisection Loop:**
   - Iterate `depth` from $0$ to `max_depth` [S1, unofficial].
   - If `len(ray_idx) == 0`, break.
   - **Convert to 3D Boxes:** For each active ray $i$, compute 3D axis-aligned boxes corresponding to the current interval $[iv\_t\_lo[i], iv\_t\_hi[i]]$:
     $$ \mathbf{p}_0 = \mathbf{o}_i + iv\_t\_lo[i] \cdot \mathbf{d}_i $$
     $$ \mathbf{p}_1 = \mathbf{o}_i + iv\_t\_hi[i] \cdot \mathbf{d}_i $$
     $$ \mathbf{lo}_{3d} = \min(\mathbf{p}_0, \mathbf{p}_1) $$
     $$ \mathbf{hi}_{3d} = \max(\mathbf{p}_0, \mathbf{p}_1) $$
   - **Inclusion Test:** Evaluate inclusion bounds using `inclusion_fn.evaluate(lo_3d, hi_3d)` to get $[f_{lo}, f_{hi}]$ [S1, unofficial].
   - **Filter Active Rays:** Determine if zero level set is present:
     $$ \text{has\_zero}[i] = (f_{lo}[i] \le 0.0) \land (f_{hi}[i] \ge 0.0) $$
     Update `ray_idx`, `iv_t_lo`, `iv_t_hi` to keep only rays where `has_zero` is true [S1, unofficial].
   - If `len(ray_idx) == 0`, break.

4. **Interval Processing (Per Active Ray):**
   - For each active ray interval $[t_{begin}, t_{end}]$ with Hermite data $\mathbf{h}_b$ at $t_{begin}$ and $\mathbf{h}_e$ at $t_{end}$:
     - Initialize $n \leftarrow 0$, `saved` $\leftarrow$ `None` [S2].
     - While $n < 32$:
       - $n \leftarrow n + 1$.
       - Estimate root $t_{root} \leftarrow \text{Oracle}(t_{begin}, t_{end}, i)$ using quadratic interpolation of Hermite data [S2].
       - If $t_{root} = \infty$ and `saved` is `None`, return `false, \infty` (no hit in this interval) [S2].
       - If $t_{root} < \infty$:
         - Evaluate Hermite data at root: $\mathbf{h}_r \leftarrow \text{HermiteData}(t_{root})$ [S2].
         - If $|\mathbf{h}_r.\text{val}| < \varepsilon$, return `true, t_{root}` (hit found) [S2].
         - Determine primitive sign change: $b_{prim} \leftarrow (\mathbf{h}_r.\text{prim} > 0) \land (\mathbf{h}_b.\text{prim} < 0)$ [S2].
         - If `saved` is `None` and $\mathbf{h}_r.\text{val} \ge 0$ and $\mathbf{h}_e.\text{val} < 0$ and $b_{prim}$, store potential backtrack: `saved` $\leftarrow [(t_{root}, \mathbf{h}_r), (t_{end}, \mathbf{h}_e)]$ [S2].
         - Update interval: If $\mathbf{h}_r.\text{val} < 0$ or $b_{prim}$, set $t_{end}, \mathbf{h}_e \leftarrow t_{root}, \mathbf{h}_r$; else set $t_{begin}, \mathbf{h}_b \leftarrow t_{root}, \mathbf{h}_r$ [S2].
       - Else if `saved` is not `None`:
         - Restore interval: $(t_{begin}, \mathbf{h}_b), (t_{end}, \mathbf{h}_e) \leftarrow \text{saved}$, `saved` $\leftarrow$ `None` [S2].
     - If loop completes without hit, return `false, \infty` [S2].

5. **Result Update:**
   - For each valid hit with distance $t_{valid}$:
     - If $t_{valid} < \text{result\_t}[\text{ray\_idx}[i]]$:
       - $\text{result\_hit}[\text{ray\_idx}[i]] \leftarrow \text{True}$ [S1, unofficial]
       - $\text{result\_t}[\text{ray\_idx}[i]] \leftarrow t_{valid}$ [S1, unofficial]
       - $\text{result\_t\_lo}[\text{ray\_idx}[i]] \leftarrow t_{lo}$ [S1, unofficial]
       - $\text{result\_t\_hi}[\text{ray\_idx}[i]] \leftarrow t_{hi}$ [S1, unofficial]
   - This ensures front-to-back rendering by keeping only the closest hit [S1, unofficial].

**Pseudocode:**

```python
import numpy as np
from dataclasses import dataclass

@dataclass
class TraceResult:
    hit: np.ndarray
    t: np.ndarray
    position: np.ndarray
    normal: np.ndarray
    depth_count: np.ndarray
    t_lo: np.ndarray
    t_hi: np.ndarray

def level_synchronized_bisection_cast(origins, directions, bounds_min, bounds_max, 
                                      inclusion_fn, max_depth=40, threshold=1e-5):
    R = origins.shape[0]
    
    # Initialize results
    result_hit = np.zeros(R, dtype=bool)
    result_t = np.full(R, np.inf, dtype=np.float64)
    result_t_lo = np.full(R, np.inf, dtype=np.float64)
    result_t_hi = np.full(R, np.inf, dtype=np.float64)
    result_depth = np.zeros(R, dtype=np.int32)
    
    # Ray-AABB intersection
    safe_dirs = np.where(directions == 0, 1.0, directions)
    t_min_vals = (bounds_min - origins) / safe_dirs
    t_max_vals = (bounds_max - origins) / safe_dirs
    
    # Fix: use np.max/min over axis=1 to get scalar t_min/t_max per ray
    t_min_arr = np.max(t_min_vals, axis=1)
    t_max_arr = np.min(t_max_vals, axis=1)
    
    hit_mask = (t_min_arr < t_max_arr) & (t_max_arr > 0)
    
    ray_idx = np.where(hit_mask)[0]
    iv_t_lo = t_min_arr[ray_idx]
    iv_t_hi = t_max_arr[ray_idx]
    
    # Pre-subdivision handled by scene structure; initial AABB bounds serve as starting intervals.
    
    for depth in range(max_depth):
        if len(ray_idx) == 0:
            break
            
        # Convert intervals to 3D boxes
        p0 = origins[ray_idx] + iv_t_lo[:, np.newaxis] * directions[ray_idx]
        p1 = origins[ray_idx] + iv_t_hi[:, np.newaxis] * directions[ray_idx]
        
        lo_3d = np.minimum(p0, p1)
        hi_3d = np.maximum(p0, p1)
        
        # Evaluate inclusion bounds
        f_lo, f_hi = inclusion_fn.evaluate(lo_3d, hi_3d)
        
        # Filter active rays: has_zero if f_lo <= 0 <= f_hi
        has_zero = (f_lo <= 0.0) & (f_hi >= 0.0)
        
        ray_idx = ray_idx[has_zero]
        iv_t_lo = iv_t_lo[has_zero]
        iv_t_hi = iv_t_hi[has_zero]
        
        if len(ray_idx) == 0:
            break
            
        valid_hits = []
        valid_ray_indices = []
        valid_t_lo = []
        valid_t_hi = []
        
        for i in range(len(ray_idx)):
            t_begin = iv_t_lo[i]
            t_end = iv_t_hi[i]
            
            h_b = inclusion_fn.get_hermite_data(origins[ray_idx[i]] + t_begin * directions[ray_idx[i]])
            h_e = inclusion_fn.get_hermite_data(origins[ray_idx[i]] + t_end * directions[ray_idx[i]])
            
            saved = None
            hit_found = False
            hit_t = np.inf
            
            for n in range(32):
                t_root = oracle_hermite_interpolation(t_begin, t_end, h_b, h_e)
                
                if t_root == np.inf:
                    if saved is None:
                        break
                    else:
                        (t_begin, h_b), (t_end, h_e) = saved
                        saved = None
                        continue
                
                p_root = origins[ray_idx[i]] + t_root * directions[ray_idx[i]]
                h_r = inclusion_fn.get_hermite_data(p_root)
                
                if abs(h_r.val) < threshold:
                    hit_found = True
                    hit_t = t_root
                    break
                
                b_prim = (h_r.prim > 0) and (h_b.prim < 0)
                
                if saved is None and h_r.val >= 0 and h_e.val < 0 and b_prim:
                    saved = [(t_root, h_r), (t_end, h_e)]
                
                if h_r.val < 0 or b_prim:
                    t_end = t_root
                    h_e = h_r
                else:
                    t_begin = t_root
                    h_b = h_r
            
            if hit_found:
                valid_hits.append(hit_t)
                valid_ray_indices.append(ray_idx[i])
                valid_t_lo.append(t_begin)
                valid_t_hi.append(t_end)
        
        if valid_hits:
            valid_hits = np.array(valid_hits)
            valid_ray_indices = np.array(valid_ray_indices)
            valid_t_lo = np.array(valid_t_lo)
            valid_t_hi = np.array(valid_t_hi)
            
            mask = valid_hits < result_t[valid_ray_indices]
            result_hit[valid_ray_indices[mask]] = True
            result_t[valid_ray_indices[mask]] = valid_hits[mask]
            result_t_lo[valid_ray_indices[mask]] = valid_t_lo[mask]
            result_t_hi[valid_ray_indices[mask]] = valid_t_hi[mask]
            result_depth[valid_ray_indices[mask]] = depth + 1
            
    positions = np.zeros((R, 3))
    normals = np.zeros((R, 3))
    hit_indices = np.where(result_hit)[0]
    if len(hit_indices) > 0:
        positions[hit_indices] = origins[hit_indices] + result_t[hit_indices][:, np.newaxis] * directions[hit_indices]
        normals[hit_indices] = inclusion_fn.get_normals(positions[hit_indices])
        
    return TraceResult(
        hit=result_hit,
        t=result_t,
        position=positions,
        normal=normals,
        depth_count=result_depth,
        t_lo=result_t_lo,
        t_hi=result_t_hi
    )

def oracle_hermite_interpolation(t_begin, t_end, h_b, h_e):
    dt = t_end - t_begin
    if dt == 0:
        return np.inf
        
    c = h_b.val
    b = h_b.prim * dt
    a = 2 * (h_e.val - h_b.val) - (h_b.prim + h_e.prim) * dt
    
    if abs(a) < 1e-12:
        if abs(b) < 1e-12:
            return np.inf
        t = -c / b
    else:
        discriminant = b*b - 4*a*c
        if discriminant < 0:
            return np.inf
        sqrt_disc = np.sqrt(discriminant)
        t1 = (-b - sqrt_disc) / (2*a)
        t2 = (-b + sqrt_disc) / (2*a)
        
        if 0 <= t1 <= 1:
            t = t1
        elif 0 <= t2 <= 1:
            t = t2
        else:
            return np.inf
            
    return t_begin + t * dt
```

**Parameters:**
- `max_depth`: Maximum number of bisection iterations allowed per ray. Default value is 40 in the tracer, but examples use 48 or 52 [S1, unofficial].
- `threshold`: Convergence width threshold. The bisection stops when the interval width ($t_{hi} - t_{lo}$) is less than this value. Default value is $10^{-5}$ [S1, unofficial].
- `inclusion_fn`: An `InclusionFunction` object that implements the `evaluate(lo, hi)` method. It takes 3D axis-aligned boxes and returns interval bounds $(f_{lo}, f_{hi})$ for the implicit function over that box. Used to determine if the zero level set exists within the interval [S1, unofficial].

**Edge Cases and Pitfalls:**
- **False Positives from Interval Arithmetic:** The inclusion test $(f_{lo} \le 0 \le f_{hi})$ may return true even if the function does not cross zero within the interval (e.g., if the function stays positive but the interval bound is loose). This is handled by the sign-change verification step ($v_{lo} * v_{hi} \le 0.0$) which checks actual function values at the interval endpoints [S1, unofficial].
- **Missing Hits due to Tangent Intersections:** Standard ray marching may miss surfaces if the ray grazes the surface. Interval arithmetic ensures robustness by enclosing the ray segment in a box and evaluating bounds over that box, guaranteeing detection of zero crossings even for near-tangent intersections [S1, unofficial].
- **Precision Issues:** High-frequency surfaces or thin shells may require tighter inclusion bounds or higher `max_depth` to converge within `threshold` [S1, unofficial].

## Subtopics

### [Bisection Trace with Gradient Inclusion](1320-bisection-trace-with-gradient-inclusion.md)
Bisection Trace with Gradient Inclusion is a robust ray casting algorithm that renders the zero-level-set of an implicit function $f: \mathbb{R}^3 \to \mathbb{R}$ by combining level-synchronized bisection with gradient-based inclusion functions. It solves the problem of missing surface features during ray traversal by using interval arithmetic to guarantee that no zero-crossings are pruned incorrectly. It distinguishes itself from standard bisection by using a Lipschitz constant derived from gradient norms to tighten the inclusion bounds, offering a configurable trade-off between generality and bound tightness.

## Operating characteristics
- **Time Complexity:** $O(R \cdot D \cdot K)$, where $R$ is the number of rays, $D$ is the maximum bisection depth (`max_depth`), and $K$ is the cost of inclusion function evaluation and Hermite data computation per interval. The level-synchronized approach allows for efficient batch processing, reducing overhead per ray.
- **Memory Complexity:** $O(R)$ for storing ray states and results. The batch processing minimizes memory fragmentation compared to per-ray processing.
- **Measured Performance:** Performance depends heavily on the efficiency of the `inclusion_fn`. Black-box `SamplingInclusion` is slower but more general, while `NaturalIntervalInclusion` and `AffineInclusion` are faster for analytic functions [S1, unofficial].
- **Scaling:** Scales well with the number of rays due to batch processing. Performance on GPU is significantly better than CPU due to parallel evaluation of inclusion bounds and Hermite data.
- **Strengths:** Guaranteed robustness against missed features, handles arbitrary implicit functions, supports black-box functions, provides sub-pixel accuracy with Newton refinement.
- **Limitations:** Slower than standard ray marching due to interval arithmetic overhead. Requires careful tuning of `max_depth` and `threshold` for high-frequency surfaces.
- **When to Use:** When robustness is critical, e.g., for thin shells, cusps, high-frequency surfaces, or near-tangent intersections. When working with black-box implicit functions.
- **When Not to Use:** When performance is the primary concern and the implicit function is simple and well-behaved. When analytic gradients are not available and black-box evaluation is too slow.

## Background
Level-synchronized bisection ray casting is a method for robust iso-surface rendering via interval-arithmetic ray casting for arbitrary implicit geometries [S1, unofficial]. It was developed as part of the `isoray` library, which targets black-box functions where only point evaluations are available [S1, unofficial]. The method builds on the principles of interval arithmetic and bisection, extending them to a batch-synchronized framework for efficient ray tracing [S1, unofficial]. It is used in research and applications requiring robust rendering of complex implicit surfaces, such as medical imaging, CAD, and scientific visualization [S1, unofficial].
