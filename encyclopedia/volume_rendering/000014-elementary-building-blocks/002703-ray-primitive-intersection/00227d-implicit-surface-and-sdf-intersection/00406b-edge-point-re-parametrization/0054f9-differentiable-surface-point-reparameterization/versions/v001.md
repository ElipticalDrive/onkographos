# Differentiable Surface Point Reparameterization

Also called: Differentiable surface point, Reparameterized surface intersection

## Overview
This method reparameterizes the surface intersection equation to ensure the computed surface point is differentiable with respect to the parameters of the implicit Signed Distance Function (SDF) MLP [S1]. It solves the problem of non-differentiable surface locations in inverse rendering and optimization, where standard root-finding or ray-marching yields points that do not propagate gradients back to the network weights [S1]. It differs from standard ray-marching by explicitly correcting the intersection point using the surface normal, and from discontinuity handling methods by focusing on the smooth zero-set case [S1, S2].

## How it works
**Inputs:**
*   $x$: The 3D point on the ray (typically the last sample before or at the estimated intersection).
*   $\Theta_g$: The parameters of the SDF MLP.
*   $S_{\Theta_g}(x)$: The SDF value at $x$.

**Outputs:**
*   $x_{\Theta_g}$: The reparameterized surface point, differentiable w.r.t. $\Theta_g$.

**Data Structures:**
*   No persistent data structures. The method is a point-wise operation.

**Steps:**
1.  Compute the surface normal $n$ at point $x$ by evaluating the gradient of the SDF:
    $$ n = \nabla S_{\Theta_g}(x) $$
    [S1]
2.  Compute the reparameterized surface point $x_{\Theta_g}$ using the following equation:
    $$ x_{\Theta_g} = x - \frac{S_{\Theta_g}(x)}{\|n\|^2} n $$
    [S1]
    *Note: The source [S1] presents the formula as $x - \frac{S_{\Theta_g}(x)}{n} n$ where $n$ is the normal vector. In vector calculus, division by a vector is undefined. The standard Newton-Raphson step for finding the root of $f(t)=0$ along the normal direction is $x_{new} = x - \frac{f(x)}{\nabla f(x) \cdot \hat{n}} \hat{n}$. If $n$ is the unit normal, $\|n\|=1$. If $n$ is the raw gradient, the denominator is the squared norm. The source notation $n$ in the denominator likely implies the dot product or normalization. Given $n = \nabla S$, the standard differentiable correction is $x - \frac{S(x)}{\|\nabla S(x)\|^2} \nabla S(x)$. We implement the standard differentiable form.*
3.  Return $x_{\Theta_g}$.

**Pseudocode:**
```python
def reparameterize_surface_point(x, sdf_mlp_params):
    """
    Computes the differentiable surface point from a ray sample x.
    
    Args:
        x: torch.Tensor, shape (3,), the 3D point on the ray.
        sdf_mlp_params: The parameters of the SDF MLP.
        
    Returns:
        torch.Tensor, shape (3,), the reparameterized surface point.
    """
    # 1. Evaluate SDF value and gradient
    # S_val is a scalar
    S_val, grad_S = sdf_mlp_params(x, compute_gradient=True)
    
    # 2. Compute the squared norm of the gradient
    # Using a small epsilon for numerical stability if needed, though not specified in source
    grad_norm_sq = torch.dot(grad_S, grad_S)
    
    # 3. Apply the reparameterization formula
    # x_new = x - (S_val / ||grad_S||^2) * grad_S
    # This corresponds to one step of Newton's method towards the zero set
    # along the gradient direction.
    correction = (S_val / grad_norm_sq) * grad_S
    x_new = x - correction
    
    return x_new
```

**Parameters:**
*   None explicitly defined. The method relies on the SDF MLP parameters $\Theta_g$.

**Edge Cases and Pitfalls:**
*   **Zero Gradient:** If $\nabla S_{\Theta_g}(x) \approx 0$, the denominator becomes zero, causing numerical instability. This occurs at critical points of the SDF (minima, maxima, saddles) which are not on the surface. [G] A guard should check for $\|n\|^2 < \epsilon$ and fall back to $x$ or handle the error.
*   **Non-unit Normal:** The formula assumes the correction is along the gradient. If the gradient is not normalized, the step size is scaled by the gradient magnitude. The formula in [S1] is ambiguous regarding normalization. The implementation above uses the squared norm to ensure correct scaling for non-unit gradients.

## Subtopics

### Implicit Function Theorem for Discontinuities
A method to differentiate discontinuities caused by object silhouettes or interior edges in implicitly defined geometry, extending the implicit function theorem from points on the zero set to discontinuities [S2]. It is chosen when the geometry involves non-smooth features like silhouettes or interior edges where standard differentiability fails [S2]. Unlike the smooth reparameterization, this method does not explicitly compute the discontinuity location $x_d$ in the forward pass; instead, the compiler expands a ray marching loop to approach the zero set, and in the backward pass, it samples the discontinuity by evaluating Boolean conditions and applies the implicit function theorem based on whether the ray intersects locally $C^1$ smooth geometry or not [S2].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per sample, assuming the SDF evaluation and gradient computation are $O(1)$ (dependent on MLP depth).
*   **Memory Complexity:** $O(1)$ additional memory.
*   **Strengths:** Enables end-to-end differentiable optimization of SDF parameters in inverse rendering tasks [S1].
*   **Limitations:** Only applicable to smooth surfaces (zero set of SDF). Does not handle discontinuities without the extension described in Subtopics [S2]. Sensitive to gradient magnitude near critical points.

## Background
The method originates from work on Photometric Inverse Rendering with Shading Cues, specifically in the context of optimizing SDF-based representations for material decoupling and surface reconstruction [S1]. It builds on previous works [76, 85] cited in [S1] for differentiable surface point computation. The extension to discontinuities via the Implicit Function Theorem is motivated by [Yariv et al. 2020] and [Li et al. 2020], and extends results from [Gargallo et al. 2007] which were limited to $C^1$ continuous geometry [S2].
