# Ellipsoid Reflector Ray Casting

Also called: castRayAgainstSystem

## Overview
Casts a ray through a system of ellipsoidal reflectors, performing up to 10 bounces to find the closest valid intersection within bounds for each bounce [S1, unofficial]. It extends [Ray-Ellipsoid Intersection](3463-ray-ellipsoid-intersection.md) by handling multiple reflectors and recursive reflection logic.

## How it works
**Inputs and Outputs:**
- Input: Ray origin $O$, ray direction $D$ (normalized), list of $N$ ellipsoidal reflectors. Each reflector $i$ has parameters for [Ray-Ellipsoid Intersection](3463-ray-ellipsoid-intersection.md) (rotation $R_i$, translation $t_i$, scale $S_i$), bounding box min $B_{min,i}$, and bounding box max $B_{max,i}$.
- Output: Final ray origin and direction after up to 10 bounces, and the first hit point if any.

**Data Structures:**
- `Reflectors`: Array of size $N$. Each element contains ellipsoid parameters and bounding box limits.
- `hit`: Boolean flag, initialized to `false`.
- `leastT`: Float, initialized to $1000.0$.
- `bestOrigin`: Vector3, initialized to $O$.
- `bestDirection`: Vector3, initialized to $D$.
- `hitThisBounce`: Boolean, initialized to `false`.
- `firstHit`: Vector3, stores the origin of the first valid reflection.

**Numbered Steps:**
1. Initialize `hit = false`, `leastT = 1000.0`, `bestOrigin = O`, `bestDirection = D`, `hitThisBounce = false`, `firstHit = O`.
2. Loop for `_bounce` from 0 to 9 (inclusive):
   a. Set `hitThisBounce = false`.
   b. For each reflector `i` from 0 to $N-1$:
      i. Call `intersectRayEllipsoid(O, D, reflector[i])` assuming outside origin (`IsInside = -1.0`). Get intersection point $P_{temp}$ and world normal $N_{world}$.
      ii. Check if $P_{temp}$ is within the bounding box $[B_{min,i}, B_{max,i}]$.
      iii. If $P_{temp}$ is not within bounds, call `intersectRayEllipsoid(O, D, reflector[i])` assuming inside origin (`IsInside = 1.0`). Get new $P_{temp}$ and $N_{world}$.
      iv. Check if this new $P_{temp}$ is within bounds.
      v. Let $t$ be the distance to $P_{temp}$. If $t < leastT$ and $t > 0.0$ and $P_{temp}$ is within bounds:
         - Set `hitThisBounce = true`.
         - Update `leastT = t - 1e-7`.
         - Update `bestOrigin = O + D * (t - 1e-6)`.
         - Update `bestDirection = reflect(D, N_{world})`.
         - If `hit` is `false`, set `firstHit = bestOrigin`.
   c. If `hitThisBounce` is `true`:
      - Update $O = bestOrigin$.
      - Update $D = bestDirection$.
      - Set `hit = true`.
   d. Else, break the bounce loop.
3. Return `firstHit`, `bestOrigin`, `bestDirection`.

**Formulas:**
- Reflection: $D' = D - 2(D \cdot N)N$
- Offset Origin: $O' = O + D \cdot (t - \epsilon)$ where $\epsilon = 10^{-6}$

**Parameters:**
- Max bounces: 10
- Epsilon for offset: $10^{-6}$
- Epsilon for t comparison: $10^{-7}$

**Edge Cases and Pitfalls:**
- Self-intersection: The small epsilon offset prevents the ray from immediately re-colliding with the same surface [S1, unofficial].
- Inside/Outside: The method attempts to handle both inside and outside intersections by checking bounds and re-intersecting if the first attempt fails the bounds check [S1, unofficial].

## Subtopics

## Operating characteristics
- Time Complexity: $O(B \cdot N)$ where $B$ is max bounces (10) and $N$ is number of reflectors.
- Memory Complexity: $O(N)$ for storing reflector data.
- Strengths: Handles complex multi-reflector systems with bounded regions.
- Limitations: Limited to 10 bounces; performance degrades with many reflectors.
