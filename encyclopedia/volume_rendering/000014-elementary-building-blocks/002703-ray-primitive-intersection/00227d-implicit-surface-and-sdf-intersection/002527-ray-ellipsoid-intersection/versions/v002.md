# Ray-Ellipsoid Intersection

Also called: Ellipsoid Ray Intersection

## Overview
Computes the intersection of a ray with an ellipsoid defined by a rotation matrix, translation vector, and scale factors. It transforms the ray into the ellipsoid's local space, solves the resulting quadratic equation for a unit sphere, and maps the result back to world space. It is distinguished from general implicit surface methods by providing a closed-form analytical solution for ellipsoids, avoiding iterative refinement, and is specifically optimized for the Gaussian Splatting rendering pipeline where ellipsoids represent 3D Gaussians.

## How it works
**Inputs:**
- Ray origin $\mathbf{o}$ (world space, 3D vector).
- Ray direction $\mathbf{d}$ (world space, 3D vector).
- Ellipsoid center $\mathbf{t}$ (world space, 3D vector).
- Ellipsoid rotation matrix $\mathbf{R}$ (3x3 matrix, columns are principal axes).
- Ellipsoid scale vector $\mathbf{S} = [S_x, S_y, S_z]$ (positive scalars).
- Numerical epsilon $\epsilon$ (default $10^{-5}$).

**Outputs:**
- Boolean indicating intersection existence.
- Intersection point $\mathbf{p}$ in world space (if intersection exists).

**Data Structures:**
- Standard 3D vectors and 3x3 matrices. No complex spatial structures are required for a single ellipsoid.

**Steps:**
1.  **Construct Inverse Transform:** Compute the matrix that transforms world coordinates to the ellipsoid's local space. This involves scaling by the inverse of the axes and rotating by the transpose of the rotation matrix (since $\mathbf{R}$ is orthogonal, $\mathbf{R}^{-1} = \mathbf{R}^T$).
    $$ \mathbf{M}_{inv} = \text{diag}\left(\frac{1}{S_x}, \frac{1}{S_y}, \frac{1}{S_z}\right) \mathbf{R}^T $$
2.  **Transform Ray:** Transform the ray origin and direction into the ellipsoid's local space.
    $$ \mathbf{o}' = \mathbf{M}_{inv} (\mathbf{o} - \mathbf{t}) $$
    $$ \mathbf{d}' = \mathbf{M}_{inv} \mathbf{d} $$
3.  **Formulate Quadratic:** The intersection with a unit sphere in local space is found by solving $|\mathbf{o}' + t\mathbf{d}'|^2 = 1$. This expands to $At^2 + Bt + C = 0$, where:
    $$ A = \mathbf{d}' \cdot \mathbf{d}' $$
    $$ B = 2 (\mathbf{o}' \cdot \mathbf{d}') $$
    $$ C = \mathbf{o}' \cdot \mathbf{o}' - 1 $$
4.  **Handle Degeneracy:** If $A$ is near zero (ray direction is effectively zero in local space), clamp it to $\epsilon$ to prevent division by zero.
    $$ \text{if } |A| < \epsilon, \text{ set } A = \epsilon $$
5.  **Compute Discriminant:**
    $$ \Delta = B^2 - 4AC $$
    If $\Delta < 0$, there is no intersection.
6.  **Handle Near-Zero Discriminant:** If $|\Delta| < \epsilon$, set $\Delta = 0$ to avoid numerical instability in the square root.
7.  **Solve for Roots:**
    $$ \sqrt{\Delta} = \sqrt{\Delta} $$
    $$ t_1 = \frac{-B - \sqrt{\Delta}}{2A} $$
    $$ t_2 = \frac{-B + \sqrt{\Delta}}{2A} $$
8.  **Select Valid Intersection:**
    - If both $t_1 < 0$ and $t_2 < 0$, the intersection is behind the ray origin; return no intersection.
    - If $|t_1 - t_2| < \epsilon$, the ray is tangent; set $t_{intersect} = \min(t_1, t_2)$.
    - Otherwise, select the smallest non-negative root:
      $$ t_{intersect} = \begin{cases} t_1 & \text{if } t_1 \ge 0 \\ t_2 & \text{otherwise} \end{cases} $$
9.  **Compute Intersection Point:** Calculate the point in local space.
    $$ \mathbf{p}' = \mathbf{o}' + t_{intersect} \mathbf{d}' $$
10. **Transform Back to World Space:** Construct the forward transformation matrix $\mathbf{M}_{fwd} = \mathbf{R} \, \text{diag}(S_x, S_y, S_z)$ and apply it.
    $$ \mathbf{p} = \mathbf{M}_{fwd} \mathbf{p}' + \mathbf{t} $$

**Pseudocode:**
```python
def ray_ellipsoid_intersection(o, d, t, R, S, eps=1e-5):
    # 1. Compute inverse transform matrix: inv_transform = diag(1/S) @ R.T
    inv_scale = [1.0 / S[0], 1.0 / S[1], 1.0 / S[2]]
    
    # Helper to apply inv_transform to a vector v
    def transform_to_local(v):
        # v_local = R.T @ (v - t)
        # Then scale
        v_shifted = [v[0] - t[0], v[1] - t[1], v[2] - t[2]]
        # Matrix-vector multiplication: R.T @ v_shifted
        # R is 3x3, R.T[i][j] = R[j][i]
        rt_v = [
            R[0][0]*v_shifted[0] + R[1][0]*v_shifted[1] + R[2][0]*v_shifted[2],
            R[0][1]*v_shifted[0] + R[1][1]*v_shifted[1] + R[2][1]*v_shifted[2],
            R[0][2]*v_shifted[0] + R[1][2]*v_shifted[1] + R[2][2]*v_shifted[2]
        ]
        # Scale
        return [rt_v[0]*inv_scale[0], rt_v[1]*inv_scale[1], rt_v[2]*inv_scale[2]]

    # 2. Transform ray origin and direction
    o_prime = transform_to_local(o)
    d_prime = transform_to_local(d) # Note: direction transformation does not subtract t

    # 3. Compute quadratic coefficients
    # A = d' . d'
    A = d_prime[0]**2 + d_prime[1]**2 + d_prime[2]**2
    # B = 2 * (o' . d')
    B = 2.0 * (o_prime[0]*d_prime[0] + o_prime[1]*d_prime[1] + o_prime[2]*d_prime[2])
    # C = o' . o' - 1
    C = o_prime[0]**2 + o_prime[1]**2 + o_prime[2]**2 - 1.0

    # 4. Handle degenerate A
    if abs(A) < eps:
        A = eps

    # 5. Compute discriminant
    discriminant = B*B - 4*A*C

    # 6. Handle near-zero discriminant
    if abs(discriminant) < eps:
        discriminant = 0.0

    # If discriminant is negative, no intersection
    if discriminant < 0:
        return False, None

    # 7. Compute roots
    sqrt_disc = discriminant ** 0.5
    t1 = (-B - sqrt_disc) / (2.0 * A)
    t2 = (-B + sqrt_disc) / (2.0 * A)

    # 8. Check if both roots are negative
    if t1 < 0 and t2 < 0:
        return False, None

    # Select valid t
    if abs(t1 - t2) < eps:
        t_intersect = min(t1, t2)
    else:
        if t1 >= 0:
            t_intersect = t1
        else:
            t_intersect = t2

    # 9. Compute intersection point in transformed space
    p_prime = [
        o_prime[0] + t_intersect * d_prime[0],
        o_prime[1] + t_intersect * d_prime[1],
        o_prime[2] + t_intersect * d_prime[2]
    ]

    # 10. Transform back to world space
    # M_fwd = R @ diag(S)
    # p = M_fwd @ p_prime + t
    # First apply diag(S) to p_prime
    p_scaled = [p_prime[0]*S[0], p_prime[1]*S[1], p_prime[2]*S[2]]
    # Then apply R
    p_world = [
        R[0][0]*p_scaled[0] + R[0][1]*p_scaled[1] + R[0][2]*p_scaled[2] + t[0],
        R[1][0]*p_scaled[0] + R[1][1]*p_scaled[1] + R[1][2]*p_scaled[2] + t[1],
        R[2][0]*p_scaled[0] + R[2][1]*p_scaled[1] + R[2][2]*p_scaled[2] + t[2]
    ]

    return True, p_world
```

**Edge Cases and Pitfalls:**
- **Degenerate Direction:** If the ray direction $\mathbf{d}$ is zero or nearly zero, $A$ becomes zero. The code clamps $A$ to $\epsilon$ [S1, unofficial].
- **Numerical Stability:** Near-tangent rays produce discriminants close to zero. Clamping the discriminant to zero prevents NaNs from square roots of small negative numbers due to floating-point error [S1, unofficial].
- **Behind Origin:** Intersections with $t < 0$ are ignored. If both roots are negative, the ray does not intersect the ellipsoid in the forward direction [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(1)$. The method involves a constant number of arithmetic operations and matrix-vector multiplications.
- **Memory Complexity:** $O(1)$. No auxiliary data structures are allocated.
- **Strengths:** Exact analytical solution; no iterative refinement required; computationally very cheap.
- **Limitations:** Only applicable to ellipsoids. Does not handle general implicit surfaces.
- **When to use:** When rendering scenes composed of ellipsoidal primitives, such as 3D Gaussian Splatting.
- **When not to use:** For general implicit surfaces, spheres (use simpler sphere intersection), or non-ellipsoidal shapes.

## Background
This method is implemented in the context of 3D Gaussian Splatting, where 3D Gaussians are represented as ellipsoids in world space. The intersection logic is used to determine visibility and contribution of Gaussians to the image plane. The specific implementation details, including the transformation matrices and numerical stability checks, are derived from an unofficial implementation of 3D Gaussian Splatting in the Taichi framework [S1, unofficial].
