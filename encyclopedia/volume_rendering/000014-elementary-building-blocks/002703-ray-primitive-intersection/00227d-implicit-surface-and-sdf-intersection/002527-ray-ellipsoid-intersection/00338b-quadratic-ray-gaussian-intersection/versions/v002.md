# Quadratic Ray-Gaussian Intersection

Also called: Gaussian Ellipsoid Intersection

## Overview
The Quadratic Ray-Gaussian Intersection method approximates the intersection of a ray with a 3D Gaussian distribution by computing the intersection with the ellipsoid defined by one standard deviation of that distribution [S1]. It serves as a numerically stable alternative to the Cubic Ray-Gaussian Intersection Solver, avoiding the NaN instability inherent in cubic solvers while providing a discriminant to verify intersection existence, which the Linear Ray-Gaussian Intersection lacks [S1]. It yields the lowest depth and mask errors among the three primary methods but is slower than the linear approach [S1].

## How it works
The method solves for the intersection parameter $t$ of a ray $r(t) = o + tv$ with the boundary of a Gaussian defined by mean $\mu$ and covariance $\Sigma$. The boundary is defined as the set of points where the Mahalanobis distance squared equals 1: $(x - \mu)^T \Sigma^{-1} (x - \mu) = 1$ [S1].

**Inputs:**
- Ray origin $o$ (3D vector).
- Ray direction $v$ (3D vector, assumed normalized).
- Gaussian mean $\mu$ (3D vector).
- Gaussian covariance matrix $\Sigma$ (3x3 symmetric positive-definite matrix).

**Outputs:**
- Intersection parameters $t_1, t_2$ (scalars), representing the entry and exit points of the ray through the ellipsoid. If no intersection, returns empty or null.

**Data Structures:**
- $\Sigma^{-1}$: The inverse of the covariance matrix. Precomputed or computed on the fly.
- Intermediate vectors: $u = \Sigma^{-1} v$ and $w = \Sigma^{-1} \mu$.

**Steps:**
1. Compute the inverse covariance matrix $\Sigma^{-1}$.
2. Compute the vector $u = \Sigma^{-1} v$.
3. Compute the vector $w = \Sigma^{-1} \mu$.
4. Calculate the quadratic coefficients $a, b, c$:
   - $a = v^T u = v^T \Sigma^{-1} v$
   - $b = -2 (v^T w) = -2 v^T \Sigma^{-1} \mu$
   - $c = (\mu^T w) - 1 = \mu^T \Sigma^{-1} \mu - 1$
5. Compute the discriminant $\Delta = b^2 - 4ac$.
6. If $\Delta < 0$, the ray misses the ellipsoid. Clip $\Delta$ to 0 to produce reasonable results for miss cases [S1].
7. Compute the square root $D = \sqrt{\Delta}$.
8. Compute the intersection parameters:
   - $t_1 = \frac{-b - D}{2a}$
   - $t_2 = \frac{-b + D}{2a}$
9. Return $t_1$ and $t_2$.

**Pseudocode:**
```python
def quadratic_ray_gaussian_intersection(ray_origin, ray_direction, gaussian_mean, gaussian_covariance):
    # 1. Inverse covariance
    # Note: In practice, Sigma is often decomposed (e.g., via Cholesky) for stability.
    # Here we assume a generic inverse function.
    inv_sigma = inverse(gaussian_covariance)
    
    # 2. Precompute matrix-vector products
    # u = Sigma^-1 * v
    u = mat_vec_mul(inv_sigma, ray_direction)
    
    # w = Sigma^-1 * mu
    w = mat_vec_mul(inv_sigma, gaussian_mean)
    
    # 3. Coefficients
    # a = v^T * Sigma^-1 * v
    a = dot(ray_direction, u)
    
    # b = -2 * v^T * Sigma^-1 * mu
    b = -2.0 * dot(ray_direction, w)
    
    # c = mu^T * Sigma^-1 * mu - 1
    c = dot(gaussian_mean, w) - 1.0
    
    # 4. Discriminant
    discriminant = b * b - 4.0 * a * c
    
    # 5. Handle miss case by clipping
    if discriminant < 0:
        discriminant = 0.0
        
    sqrt_discriminant = sqrt(discriminant)
    
    # 6. Solve quadratic
    # t = (-b +/- sqrt(D)) / 2a
    # Ensure a is not zero (ray direction orthogonal to all axes in transformed space is degenerate)
    if a == 0:
        return None
        
    t1 = (-b - sqrt_discriminant) / (2.0 * a)
    t2 = (-b + sqrt_discriminant) / (2.0 * a)
    
    return t1, t2
```

**Parameters:**
- No tunable parameters. The method is deterministic based on the Gaussian definition.

**Edge Cases and Pitfalls:**
- **Ray Miss:** When the ray misses the ellipsoid, the discriminant $b^2 - 4ac$ becomes negative. The source specifies clipping this value to be non-negative to produce reasonable results [S1].
- **Precision:** While more stable than the cubic solver, it still operates in floating point. However, it does not suffer from the high NaN rate of the cubic solver [S1].
- **Degenerate Covariance:** If $\Sigma$ is singular, $\Sigma^{-1}$ is undefined. The method assumes a valid, positive-definite covariance matrix [S1].

## Subtopics

### Cubic Ray-Gaussian Intersection Solver
Solves for the intersection of a ray with a Gaussian distribution by finding the roots of a cubic polynomial derived from the Gaussian's quadratic form. It provides the most accurate surface representation but suffers from numerical instability. The cubic equation is derived by setting the gradient of the Gaussian density to zero. Defining $m = \Sigma \mu$ and $r = \Sigma v$, the equation is:
$$ 0 = - t^3 (r^T r) (v^T r) + t^2 \left[ (m^T r + r^T m) (v^T r) + (r^T r) (v^T m) \right] - t \left[ (m^T m) (v^T r) + (m^T r + r^T m) (v^T m) - r^T r \right] + (m^T m) (v^T m) - r^T m $$
In 32-bit floating point precision, even a numerically stable cubic solver produces NaNs at a rate of approximately 1 in 1,000 pixels, which breaks backpropagation [S1]. It takes twice as long as the linear method for a forward pass [S1].

### Linear Ray-Gaussian Intersection
Approximates the Gaussian surface intersection using a linear method. It produces smooth surfaces and is the most numerically stable and fastest method, used for all evaluations outside the specific intersection comparison section [S1]. It is the fastest method for a forward pass [S1].

## Operating characteristics
- **Time Complexity:** The quadratic method takes 50% longer than the linear method for a forward pass [S1]. The cubic method takes twice as long as the linear method [S1].
- **Accuracy:** In 3D evaluation on objects, the quadratic method has the lowest errors in depth and mask compared to linear and cubic methods [S1]. The linear method produces smooth surfaces, while the quadratic method shows individual ellipsoids protruding from the object surface [S1].
- **Stability:** The quadratic method is numerically stable and avoids the NaN issues of the cubic solver [S1]. Due to its stability and speed, the linear method is used for all evaluations outside the specific intersection comparison section [S1].
- **When to use:** Use when accuracy (lowest depth/mask error) is prioritized over speed and stability is required compared to the cubic solver. Use the linear method for general evaluation due to its speed and stability [S1].

## Background
The method is described in "Approximate Differentiable Rendering with Algebraic Surfaces" by Leonid Keselman and Martial Hebert [S1]. The paper compares three methods for ray-Gaussian intersection: Linear, Quadratic, and Cubic. The quadratic method is introduced as an approximation of the cubic method that avoids numerical instability [S1].
