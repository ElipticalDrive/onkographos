# Bounding Box Node Intersection

Also called: BBNode::intersect

## Overview
A recursive ray traversal algorithm for a binary bounding box tree (BBNode) that determines the closest surface intersection by testing the node's bounding box, then recursing into left and right children, and finally comparing hit distances [S1, unofficial]. It differs from [Hierarchical Bounding Volumes (HBV)](13475-hierarchical-bounding-volumes-hbv.md) in that HBV is the general algorithmic framework for any bounding volume hierarchy, whereas this method describes a specific recursive traversal implementation for binary bounding box trees.

## How it works
**Inputs:** A ray (origin, direction), a root `BBNode` pointer.
**Outputs:** The closest intersection distance $t$ or -1 if no intersection.

**Data Structures:**
*   `BBNode`:
    *   `min`: `Vec3` (minimum corner of bounding box)
    *   `max`: `Vec3` (maximum corner of bounding box)
    *   `child_l`: `SceneObject*` (left child)
    *   `child_r`: `SceneObject*` (right child)
    *   `getType()`: Returns `NODE` or leaf type.

**Parameters:**
*   `epsilon`: Small constant for floating-point precision handling in hit distance comparison. Value: `0.001f` [S1, unofficial].

**Steps:**
1.  Initialize `closest_t` to infinity.
2.  If `child_l` exists:
    *   If `child_l` is a `NODE`, cast to `BBNode` and call `intersect` recursively.
    *   Otherwise, call `child_intersect` on `child_l`.
    *   Update `closest_t` if a hit is found.
3.  If `child_r` exists:
    *   If `child_r` is a `NODE`, cast to `BBNode` and call `intersect` recursively.
    *   Otherwise, call `child_intersect` on `child_r`.
    *   Update `closest_t` if a hit is found.
4.  Compare hit distances using `epsilon` to handle floating-point precision issues [S1, unofficial].
5.  Return `closest_t`.

**Pseudocode:**
```python
def BBNode_intersect(ray, node):
    closest_t = infinity
    
    # Process left child
    if node.child_l is not None:
        if node.child_l.getType() == NODE:
            t_left = BBNode_intersect(ray, node.child_l)
        else:
            t_left = child_intersect(ray, node.child_l)
        
        if t_left != -1:
            if closest_t == infinity or t_left < closest_t:
                closest_t = t_left

    # Process right child
    if node.child_r is not None:
        if node.child_r.getType() == NODE:
            t_right = BBNode_intersect(ray, node.child_r)
        else:
            t_right = child_intersect(ray, node.child_r)
            
        if t_right != -1:
            # Handle floating-point precision in hit distance comparison
            if closest_t == infinity or (t_right + 0.001f) < closest_t:
                closest_t = t_right

    return closest_t
```

**Edge Cases and Pitfalls:**
*   Floating-point precision in hit distance comparison is handled by adding `epsilon` (0.001f) to the left hit distance before comparing [S1, unofficial].
