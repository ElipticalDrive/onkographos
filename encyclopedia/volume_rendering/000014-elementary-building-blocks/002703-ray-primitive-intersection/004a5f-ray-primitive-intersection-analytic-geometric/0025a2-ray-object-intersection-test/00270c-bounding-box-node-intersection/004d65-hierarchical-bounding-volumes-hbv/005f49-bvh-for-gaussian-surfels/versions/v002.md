# BVH for Gaussian Surfels

Also called: BVH over ellipses representing Gaussians, Gaussian Surfels BVH, Indirect illumination via BVH ray tracing, Physically-based Illumination with Raytracing

## Overview
This method accelerates physically-based indirect illumination computation for Gaussian splatting representations by treating Gaussians as ellipsoidal surfels organized in a Bounding Volume Hierarchy (BVH) [S1]. It replaces unnatural indirect lighting from unconstrained spherical harmonic methods with physically constrained ray tracing through the learned radiance field [S1]. Unlike screen-space rasterization, it explicitly traces rays to compute visibility and accumulated radiance for inverse rendering and relighting [S1].

## How it works
**Inputs:**
- A set of $N$ Gaussians, each defined by center $\mathbf{x}$, covariance matrix (defining ellipse shape/orientation), color $c$, and transparency $\alpha$ [S1].
- Visibility threshold $\epsilon = 0.8$ [S1].
- Sampling count $K$ for directions [S1].
- View direction $\omega_o$ and environment map for direct illumination [S1].

**Outputs:**
- Outgoing radiance $L_o(\mathbf{x}, \omega_o)$ per Gaussian vertex [S1].

**Data Structures:**
- **BVH:** A hierarchical tree where each node contains an axis-aligned bounding box (AABB) enclosing its children, and leaf nodes store the Gaussian surfels. Exact layout and bit-packing details are Not given in the sources.
- **Gaussian Representation:** Each Gaussian is treated as an ellipse for intersection purposes [S1]. The axis lengths of these ellipses are scaled by a factor of three to ensure robust intersection testing [S1].

**Steps:**

1. **BVH Construction:** Construct a BVH over the set of Gaussians. Represent each Gaussian as an ellipse and scale its axis lengths by a factor of three before insertion [S1].
2. **Hemisphere Definition:** For each Gaussian vertex $\mathbf{x}$ with geometry normal $\mathbf{n}$, define the upper hemisphere $\Omega$ relative to $\mathbf{n}$ [S1].
3. **Direction Sampling:** Uniformly sample $K$ directions $\{\omega_{ik}\}_{k=1}^K$ within $\Omega$ [S1].
4. **Ray Emission:** For each sampled direction $\omega_{ik}$, emit a ray $R(t) = \mathbf{x} + t\omega_{ik}$ starting from the Gaussian center $\mathbf{x}$ [S1].
5. **BVH Query:** Query the BVH to find intersecting Gaussians along the ray [S1].
6. **Accumulation:** Accumulate transmittance $T$ and indirect radiance $L_i^{ind}$ as the ray traverses the scene [S1].
7. **Visibility:** Compute visibility $V(\mathbf{x}, \omega_i)$:
   $$
   V(\mathbf{x}, \omega_i) = \begin{cases} 
   0 & \text{if } T \le \epsilon \\
   1 & \text{if } T > \epsilon 
   \end{cases}
   $$
   where $\epsilon = 0.8$ [S1].
8. **Indirect Radiance:** Compute indirect incoming radiance $L_i^{ind}(\mathbf{x}, \omega_i)$ by summing contributions of intersected Gaussians:
   $$
   L_i^{ind}(\mathbf{x}, \omega_i) = \sum_{l=0}^{n} c_l \alpha_l T_l
   $$
   where $c_l$ is color, $\alpha_l$ is transparency, and $T_l$ is transmittance up to Gaussian $l$ [S1].
9. **Total Incoming Radiance:** Compute $L_i(\mathbf{x}, \omega_i) = L_i^{dir}(\mathbf{x}, \omega_i)V(\mathbf{x}, \omega_i) + L_i^{ind}(\mathbf{x}, \omega_i)$, where $L_i^{dir}$ is direct illumination from the environment map [S1].
10. **Outgoing Radiance:** Compute $L_o(\mathbf{x}, \omega_o)$ using the rendering equation:
    $$
    L_o(\mathbf{x}, \omega_o) = \int_{\Omega} f(\mathbf{x}, a, r, \omega_i, \omega_o) L_i(\mathbf{x}, \omega_i) (\omega_i \cdot \mathbf{n}) d\omega_i
    $$
    where $f$ is the Disney Principled BRDF, $a$ is albedo, $r$ is roughness, and $\omega_o$ is the view direction [S1]. This integral is approximated by the sum over the $K$ sampled directions [S1].

**Pseudocode:**

```python
import math
import numpy as np

def sample_hemisphere(normal, k):
    """Uniformly sample k directions on the upper hemisphere defined by normal [G]."""
    directions = []
    # Construct orthonormal basis from normal
    v = np.array([0.0, 0.0, 1.0]) if abs(normal[2]) < 0.9 else np.array([1.0, 0.0, 0.0])
    u = np.cross(normal, v)
    u /= np.linalg.norm(u)
    v = np.cross(normal, u)
    v /= np.linalg.norm(v)
    
    for _ in range(k):
        phi = 2.0 * math.pi * np.random.uniform(0, 1)
        cos_theta = np.random.uniform(0, 1)
        sin_theta = math.sqrt(1.0 - cos_theta**2)
        local_dir = np.array([sin_theta * math.cos(phi), sin_theta * math.sin(phi), cos_theta])
        directions.append(u * local_dir[0] + v * local_dir[1] + normal * local_dir[2])
    return directions

def ray_ellipse_intersection(ray_o, ray_d, ellipse):
    """Analytic intersection of ray with ellipse. Returns t or None [G]."""
    c = ellipse.center
    S = ellipse.shape_matrix
    A = np.dot(ray_d, np.dot(S, ray_d))
    B = 2.0 * np.dot(ray_d, np.dot(S, ray_o - c))
    C = np.dot(ray_o - c, np.dot(S, ray_o - c)) - 1.0
    disc = B*B - 4*A*C
    if disc < 0: return None
    sqrt_d = math.sqrt(disc)
    t1 = (-B - sqrt_d) / (2*A)
    t2 = (-B + sqrt_d) / (2*A)
    t = t1 if t1 > 0 else (t2 if t2 > 0 else None)
    return t

def trace_ray(ray_o, ray_d, bvh, epsilon):
    """Trace ray through BVH, return visibility V and indirect radiance L_ind [S1]."""
    hits = bvh.query(ray_o, ray_d)
    hits.sort(key=lambda x: x[1])
    transmittance = 1.0
    L_ind = 0.0
    for g, t in hits:
        L_ind += g.color * g.alpha * transmittance
        transmittance *= (1.0 - g.alpha)
        if transmittance < 1e-6: break
    V = 0.0 if transmittance <= epsilon else 1.0
    return V, L_ind

def compute_global_illumination(gaussians, bvh, K, epsilon, omega_o, env_map):
    """Compute outgoing radiance for all Gaussians [S1]."""
    results = []
    for g in gaussians:
        center = g.center
        normal = g.normal
        directions = sample_hemisphere(normal, K)
        L_o_sum = 0.0
        for omega_i in directions:
            V, L_ind = trace_ray(center, omega_i, bvh, epsilon)
            L_dir = env_map.sample(omega_i)
            L_i = L_dir * V + L_ind
            f = disney_brdf(g.albedo, g.roughness, omega_i, omega_o, normal)
            dot = max(0.0, np.dot(omega_i, normal))
            L_o_sum += f * L_i * dot
        L_o = L_o_sum / K
        results.append(L_o)
    return results
```

**Edge Cases and Pitfalls:**
- The visibility threshold $\epsilon = 0.8$ is a fixed heuristic [S1].
- Axis scaling by a factor of three is required for robust intersection testing [S1].
- Precision issues may arise when accumulating transmittance for highly transparent regions.

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Strengths:** Enables physically-based indirect illumination and relighting, which is not possible with standard SH-based Gaussian splatting [S1]. The BVH acceleration makes ray tracing through the Gaussian field feasible [S1].
- **Limitations:** Computationally expensive due to ray tracing and sampling [S1]. The visibility threshold $\epsilon=0.8$ is a heuristic [S1].
- **When to use:** When physically-based inverse rendering and relighting are required for Gaussian splatting scenes [S1].
- **When not to use:** Not given in the sources.

## Background
The method was introduced in "SVG-IR: Spatially-Varying Gaussian Splatting for Inverse Rendering" [S1]. It addresses the limitation of previous unconstrained SH-based methods which produce unnatural indirect lighting [S1]. By introducing physically-based illumination via ray tracing through a learned radiance field represented by Gaussians, it enforces physical constraints [S1]. The BVH over ellipses is used to accelerate ray tracing [S1].
