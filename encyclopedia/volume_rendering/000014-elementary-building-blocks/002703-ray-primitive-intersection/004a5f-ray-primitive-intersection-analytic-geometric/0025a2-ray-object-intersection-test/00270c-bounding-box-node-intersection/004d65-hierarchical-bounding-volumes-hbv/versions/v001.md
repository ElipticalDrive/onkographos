# Hierarchical Bounding Volumes (HBV)
Also called: Bounding Volume Hierarchy
## Overview
Hierarchical Bounding Volumes (HBV) is a spatial acceleration structure for ray tracing that organizes scene primitives into a tree of nested bounding volumes [S1, unofficial]. It solves the problem of inefficient linear primitive testing by allowing rays to skip large portions of the scene that do not intersect the root or intermediate bounding volumes. Unlike flat acceleration structures, HBV leverages the containment property of its hierarchy to enable recursive traversal, offering a flexible compromise between build time and traversal speed that is preferred by many practitioners [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of scene primitives and a ray $r(t) = O + tD$, where $O$ is the origin, $D$ is the direction, and $t \in [t_{min}, t_{max}]$.
*   **Output:** A list of hit distances or primitive IDs stored in `hits`.

**Data Structures:**
The structure is a tree where each node contains a bounding volume (typically an Axis-Aligned Bounding Box, AABB) that encloses all primitives in its subtree.
*   **Node:** Contains a bounding volume `bound` and a flag indicating if it is a leaf.
*   **Leaf Node:** Contains a list of primitives `prims`.
*   **Internal Node:** Contains a list of child nodes.
*   **Bounding Volume:** Defined by minimum and maximum extents, supporting a standard intersection test `intersectp(bound, ray)` which returns true if the ray intersects the volume within the current $t$ range.

**Creation Preprocess:**
The tree can be constructed via two primary methods [S1, unofficial]:
1.  **From Model Hierarchy:** Utilizing existing scene graph structures.
2.  **Automatic Clustering:** Grouping primitives spatially and recursively splitting them until a leaf criterion is met.

**Traversal Algorithm:**
The search is performed via a recursive inorder traversal [S1, unofficial]. The algorithm tests the ray against the current node's bounding volume. If there is no intersection, the subtree is pruned. If there is an intersection, the algorithm recurses into the children. For leaf nodes, it performs the actual primitive intersection tests.

**Pseudocode:**
```python
def intersect(node, ray, hits):
    # Test if the ray intersects the node's bounding volume
    if not intersectp(node.bound, ray):
        return

    # If leaf node, test contained primitives
    if node.is_leaf:
        intersect(node.prims, ray, hits)
    else:
        # Recurse into children
        for child in node.children:
            intersect(child, ray, hits)
```

**Edge Cases and Pitfalls:**
*   **Degenerate Bounding Volumes:** If clustering results in zero-volume nodes, intersection tests may fail due to precision issues.
*   **Traversal Order:** The order of child traversal affects performance. Visiting the closer child first can allow early termination if the closest hit is found, though the basic pseudocode above visits all children.

## Operating characteristics
*   **Time Complexity:** Build time depends on the clustering strategy (often $O(N \log N)$ for balanced trees). Traversal time is $O(\log N)$ on average for well-balanced trees, but can degrade to $O(N)$ for poorly constructed hierarchies.
*   **Memory Complexity:** $O(N)$, storing bounding volumes for each node in the tree.
*   **Strengths:** Flexible construction; good compromise between build time and traversal speed; widely supported and understood [S1, unofficial].
*   **Limitations:** Build time can be high for automatic clustering; performance is sensitive to the quality of the hierarchy (balance and tightness of bounds).
*   **When to use:** General-purpose ray tracing acceleration, especially when scene geometry is static or changes infrequently.
*   **When not to use:** Highly dynamic scenes where rebuild overhead is prohibitive, or when simpler structures (like uniform grids) suffice for sparse scenes.

## Background
HBV is a foundational technique in ray tracing acceleration, often associated with the work of Kaplan, Arvo, and Jansen in the context of ray traversal algorithms [S1, unofficial]. It is closely related to and often compared with Hierarchical Grids, which are also noted as a good compromise preferred by many practitioners [S1, unofficial]. The structure is a specific instance of a Bounding Volume Hierarchy (BVH) where the bounding volumes are typically bounding boxes.
