# BVH with 8-bit Quantized Bounds and Indirect Interior Storage

Also called: bvh8-q8-ci, bvh8i, qbvh8i

## Overview
This method defines an 8-ary Bounding Volume Hierarchy (BVH) layout optimized for memory efficiency and traversal speed by storing interior node bounds in a separate indirect array and quantizing child bounding boxes to 8-bit integers [S1]. It solves the problem of high memory bandwidth consumption and cache pressure during ray traversal by reducing the footprint of interior nodes and leveraging SIMD-friendly integer arithmetic for intersection tests [S1]. It differs from its sibling [BVH for Gaussian Surfels](17858-bvh-for-gaussian-surfels.md) by targeting triangle primitives with a specific 8-ary topology, and from [Heuristic BVH Construction (Top-Down with Plane-Sweep)](18008-heuristic-bvh-construction-top-down-with-plane-sweep.md) by defining the storage layout and quantization scheme rather than the construction heuristic [S1]. It extends [Hierarchical Bounding Volumes (HBV)](13475-hierarchical-bounding-volumes-hbv.md) by introducing indirect interior storage and 8-bit quantization [S1].

## How it works
**Inputs:** A set of geometric primitives (specifically triangles) and a target BVH topology (8-ary) [S1].
**Outputs:** A serialized BVH structure containing a primitive array and an indirect interior array, along with a root index [S1].

### Data Structures
The layout is defined by two main groups: `Interiors` and the main indexed group [S1].

1.  **Global Header:**
    *   `primitive_count`: `u32`
    *   `primitives`: Array of `Triangle` of size `primitive_count`
    *   `interior_count`: `u32`

2.  **Indirect Interior Group (`Interiors`):**
    *   Size: `interior_count`
    *   Fields per node:
        *   `mlo`: `f32x3` (Merged Low bounds of children)
        *   `mex`: `f32x3` (Merged Extent of children, $mhi - mlo$)
        *   `child_bounds`: `qbox3x8` (Quantized bounds for 8 children)
        *   `children`: `u32x8` (Pointers/indices to children)
    *   Derived fields (for traversal logic):
        *   $lo = \text{dequantize\_bounds\_lo}(mlo, mex, child\_bounds)$ [S1]
        *   $hi = \text{dequantize\_bounds\_hi}(mlo, mex, child\_bounds)$ [S1]

3.  **Main Indexed Group (indexed by `I`):**
    *   Default root index `I` is 1 [S1].
    *   The index `I` is a 32-bit integer split as follows:
        *   Bit 0: Tag bit. `1` indicates an Interior node; `0` indicates a Leaf node [S1].
        *   Bits 1-31: Payload.
            *   If Tag is `1` (Interior): Bits 2-31 store the index into the `Interiors` array [S1].
            *   If Tag is `0` (Leaf): Bits 7-31 store the primitive offset `O` [S1]. Bits 2-6 store `nprims - 1` [S1].

4.  **Quantized Box (`qbox3`):**
    *   Represents a 3D bounding box quantized to 8 bits per axis [S1].
    *   Fields: `lo`: `u8x3`, `hi`: `u8x3` [S1].
    *   Values are clamped to $[0, 255]$ [S1].

5.  **Quantized Box Array (`qbox3x8`):**
    *   Array of 8 `qbox3` structures, one for each child of an interior node [S1].

### Algorithms and Formulas

**1. Quantization of Child Bounds**
For each interior node with 8 children, the bounds are quantized relative to the merged bounds of all children [S1].

*   **Merged Bounds:**
    $$mlo = \min_i(low_i)$$
    $$mhi = \max_i(high_i)$$
    $$mex = mhi - mlo$$
    Where $i \in [0, 7]$ indexes the children [S1].

*   **Reciprocal:**
    $$rcp = \frac{255.0}{mex}$$ [S1]

*   **Quantization Function:**
    For each child $i$ and axis $d \in \{x, y, z\}$:
    $$q_{lo}^{(i,d)} = \text{tfloor}((low_i^{(d)} - mlo^{(d)}) \times rcp^{(d)})$$
    $$q_{hi}^{(i,d)} = \text{tceil}((high_i^{(d)} - mlo^{(d)}) \times rcp^{(d)})$$
    
    Where $\text{tfloor}(v)$ and $\text{tceil}(v)$ clamp the result to $[0, 255]$ [S1].

*   **Dequantization (for intersection tests):**
    $$lo^{(i,d)} = mlo^{(d)} + (q_{lo}^{(i,d)} \times rcp^{(d)}) \times mex^{(d)}$$
    $$hi^{(i,d)} = mlo^{(d)} + (q_{hi}^{(i,d)} \times rcp^{(d)}) \times mex^{(d)}$$
    The formula in the notes is $\text{lo} = \text{mlo} + (\text{bound.lo} \times \text{rcp}) \times \text{mex}$ [S1]. This implies the stored `bound.lo` is the integer index, and it is scaled back to float space [S1].

**2. Index Packing**
*   **Interior Node Index:**
    $$I = (\text{interior\_array\_index} \ll 2) \mid 1$$ [S1]
*   **Leaf Node Index:**
    $$I = (\text{primitive\_offset} \ll 7) \mid ((\text{nprims} - 1) \ll 2) \mid 0$$ [S1]

**3. Build Procedure**
The build process constructs the tree bottom-up or via a specified topology, generating the packed indices [S1].

```python
import math

def tfloor(v):
    """Floor and clamp to [0, 255]"""
    return max(0, min(int(math.floor(v)), 255))

def tceil(v):
    """Ceil and clamp to [0, 255]"""
    return max(0, min(int(math.ceil(v)), 255))

def compute_merged_low(lows):
    """Compute element-wise minimum across 8 children's low bounds."""
    mlo = list(lows[0])
    for i in range(1, 8):
        for d in range(3):
            if lows[i][d] < mlo[d]:
                mlo[d] = lows[i][d]
    return mlo

def compute_merged_extent(lows, highs):
    """Compute max(high) - min(low) across 8 children."""
    mlo = compute_merged_low(lows)
    mhi = list(highs[0])
    for i in range(1, 8):
        for d in range(3):
            if highs[i][d] > mhi[d]:
                mhi[d] = highs[i][d]
    return [mhi[d] - mlo[d] for d in range(3)]

def quantize_bounds(lows, highs):
    """Quantize 8 children's bounds to 8-bit integers."""
    mlo = compute_merged_low(lows)
    mex = compute_merged_extent(lows, highs)
    rcp = [255.0 / mex[d] for d in range(3)]
    
    child_bounds = []
    for i in range(8):
        q_lo = [tfloor((lows[i][d] - mlo[d]) * rcp[d]) for d in range(3)]
        q_hi = [tceil((highs[i][d] - mlo[d]) * rcp[d]) for d in range(3)]
        child_bounds.append({'lo': q_lo, 'hi': q_hi})
    return child_bounds

def build_interior_node(children_indices, lows, highs, interiors_array):
    """
    Build an interior node.
    Returns the packed index for this node.
    """
    mlo = compute_merged_low(lows)
    mex = compute_merged_extent(lows, highs)
    child_bounds = quantize_bounds(lows, highs)
    
    interior_index = len(interiors_array)
    interiors_array.append({
        'mlo': mlo,
        'mex': mex,
        'child_bounds': child_bounds,
        'children': children_indices
    })
    
    return (interior_index << 2) | 1

def build_leaf_node(primitives, nprims, primitive_array):
    """
    Build a leaf node.
    Returns the packed index for this node.
    """
    offset = len(primitive_array)
    for i in range(nprims):
        primitive_array.append(primitives[i])
        
    return (offset << 7) | ((nprims - 1) << 2) | 0
```

**4. Intersection Method**
For the quantized layout, the Möller-Trumbore algorithm is used for ray-triangle intersection [S1]. The dequantized bounds are used for the BVH traversal step (AABB intersection), and the quantized bounds may be used for early rejection or SIMD optimization if the hardware supports integer AABB tests [S1].

### Edge Cases and Pitfalls
*   **Zero Extent:** If `mex` is zero (degenerate bounding box), division by zero occurs in `rcp` [S1]. The implementation must handle this, likely by treating the extent as a small epsilon or skipping quantization [G].
*   **Quantization Error:** Quantization to 8 bits introduces error [S1]. The dequantized bounds are an approximation [S1]. This may lead to false negatives in intersection tests if the approximation is too coarse, though the source notes that Möller-Trumbore is used for the final primitive test, mitigating this risk for correctness [S1].
*   **Index Overflow:** The leaf index packs `nprims - 1` into 5 bits (bits 2-6), limiting `nprims` to 32 primitives per leaf [S1]. The interior index is stored in 30 bits (bits 2-31), allowing for $2^{30}$ interior nodes [S1].

## Operating characteristics
*   **Memory Footprint:** Significantly reduced compared to unquantized layouts (e.g., `bvh8i`) because child bounds are stored as 8-bit integers instead of 32-bit floats, and interior nodes are stored in a separate compact array [S1]. The source notes that `qbvh8i` uses less memory than `bvh8i` [S1].
*   **Traversal Speed:** The use of 8-bit quantization and integer arithmetic can improve SIMD performance [S1]. The source notes that `qbvh8i` has lower latency per ray than `bvh8i` in some configurations [S1].
*   **Construction Time:** The build procedure involves additional floating-point operations for quantization and dequantization setup [S1]. The source notes that fully replicating Embree's construction strategy is impractical, implying construction is complex [S1].
*   **Scalability:** The 8-ary tree structure reduces tree height, potentially improving cache locality [S1]. The indirect interior storage allows for better memory layout optimization [S1].
*   **Limitations:** Limited to 32 primitives per leaf [S1]. Quantization error may affect precision, though the final primitive test is accurate [S1].

## Background
This layout is part of Intel Embree's 8-ary BVH layouts, specifically `qbvh8i` for quantized representations [S1]. It represents over a decade of production engineering effort by domain experts [S1]. It is used in production rendering systems for its balance of memory efficiency and traversal speed [S1]. The source "Decoupling Data Layouts from Bounding Volume Hierarchies" compares this layout with other BVH implementations [S1].
