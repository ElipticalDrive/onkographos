# Ray-Object Intersection Test

Also called: Child Ray Intersection with Transformation, Ray Intersection Update, Ray-Object Intersection, raytrace

## Overview
The Ray-Object Intersection Test is the fundamental geometric primitive used to determine if and where a ray intersects a specific scene object, returning the closest valid intersection distance or a failure indicator [S1, unofficial]. It serves as the core decision unit in ray tracing and volume rendering pipelines, filtering out non-intersections and self-intersections via epsilon thresholds to ensure robustness [S2, unofficial][S4, unofficial]. Unlike sibling primitives that solve for specific analytic shapes (e.g., [Sphere Intersection](1620-sphere-intersection.md)), this test is a generic interface that may involve coordinate space transformations to handle arbitrary object orientations and positions [S5, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A ray defined by origin $\mathbf{o}$ and direction $\mathbf{d}$, and an object $\mathbf{o}_b$ (potentially with a transformation matrix $\mathbf{M}$).
*   **Output:** A distance $t$ to the closest intersection point, or $-1$ (or infinity) if no valid intersection exists.

**Data Structures**
The ray state is typically maintained in a structure containing:
*   `origin`: Vector3D $(x, y, z)$
*   `direction`: Vector3D $(x, y, z)$, typically normalized.
*   `t`: Float, the current closest hit distance.
*   `hit`: Boolean, indicating if a valid hit has been recorded.
*   `normal`: Vector3D, the surface normal at the hit point (computed post-intersection) [S2, unofficial].

**Steps**
1.  **Transformation (Optional):** If the object $\mathbf{o}_b$ is defined in a local coordinate system with a transformation matrix $\mathbf{M}$, transform the ray into the object's local space [S5, unofficial].
    *   New origin: $\mathbf{o}' = \mathbf{M} \cdot [\mathbf{o}, 1]^T$
    *   New direction: $\mathbf{d}' = \mathbf{M} \cdot [\mathbf{d}, 0]^T$
2.  **Intersection Solve:** Solve the system of equations representing the ray and the object's surface geometry to find potential intersection parameters $t_{obj}$ [S1, unofficial].
3.  **Filtering:** Check if the computed $t_{obj}$ is valid:
    *   $t_{obj} > \epsilon$ (where $\epsilon$ is a small positive constant, e.g., $10^{-5}$ or $0.001$) to prevent self-intersection or near-origin artifacts [S2, unofficial][S4, unofficial][S5, unofficial].
    *   $t_{obj} < t_{current}$ (if tracking the closest hit among multiple objects) [S3, unofficial].
4.  **Update:** If valid, update the ray's hit state:
    *   Set `hit` = true.
    *   Set `t` = $t_{obj}$.
    *   (Optional) Compute and store the normal $\mathbf{n}$ by transforming the local normal back to world space: $\mathbf{n}_{world} = \text{normalize}(\mathbf{M}^{-T} \cdot \mathbf{n}_{local})$ [S5, unofficial].
5.  **Return:** Return the boolean hit status or the distance $t$.

**Formulas**
*   Ray Equation: $\mathbf{p}(t) = \mathbf{o} + t\mathbf{d}, \quad t \in \mathbb{R}^+$ [S1, unofficial].
*   Unit Sphere Surface: $\{(x, y, z) \mid x^2 + y^2 + z^2 = 1\}$ [S1, unofficial].
*   Optimization Criterion: Find object $o$ that minimizes $t$ such that $t = \text{intersection test}(\mathbf{r}, o)$ and $t > 0$ [S1, unofficial].

**Parameters**
*   $\epsilon$ (SMALLEST_DIST): Minimum distance threshold to accept a hit. Typical values are $1.0 \times 10^{-5}$ [S4, unofficial] or $0.001$ [S5, unofficial]. This prevents z-fighting and self-intersection.

**Edge Cases and Pitfalls**
*   **Self-Intersection:** Intersections very close to the ray origin or previous hit point ($t \le \epsilon$) must be discarded to avoid artifacts [S4, unofficial].
*   **Degenerate Rays:** If $\mathbf{d}$ is not normalized, $t$ does not represent Euclidean distance.
*   **Transformation Precision:** Inverse matrix operations for normal transformation must use the inverse-transpose of the model matrix to preserve orthogonality under non-uniform scaling [S5, unofficial].

**Pseudocode**
```python
def ray_object_intersection(ray, objects, epsilon=1e-5):
    """
    Finds the closest intersection between a ray and a list of objects.
    
    Args:
        ray: Object with attributes 'origin' (Vector3), 'direction' (Vector3).
        objects: List of object definitions, each potentially having a 'transform' matrix.
        epsilon: Minimum distance threshold to ignore hits.
        
    Returns:
        tuple: (closest_t, object_index) or (inf, -1) if no intersection.
    """
    closest_t = float('inf')
    hit_index = -1
    
    for index, obj in enumerate(objects):
        # Transform ray to object's local space if necessary
        if hasattr(obj, 'transform'):
            # Transform origin (point)
            local_o = obj.transform.transform_point(ray.origin)
            # Transform direction (vector)
            local_d = obj.transform.transform_vector(ray.direction)
        else:
            local_o = ray.origin
            local_d = ray.direction
            
        # Solve intersection for local ray and object geometry
        # This step is object-specific (e.g., sphere, plane, triangle)
        # Returns distance t_obj or None if no intersection
        t_obj = solve_intersection(local_o, local_d, obj.geometry)
        
        if t_obj is not None:
            # Filter: must be in front of ray origin and further than epsilon
            if t_obj > epsilon and t_obj < closest_t:
                closest_t = t_obj
                hit_index = index
                
    return closest_t, hit_index

def update_ray_hit(ray, t, obj):
    """
    Updates the ray's hit state if a closer valid intersection is found.
    
    Args:
        ray: Ray state object.
        t: Distance to new intersection.
        obj: The intersected object.
        
    Returns:
        bool: True if hit was updated, False otherwise.
    """
    # Check if new hit is closer than current and valid
    if t < ray.t and t > 1e-5: # Using standard epsilon
        ray.t = t
        ray.hit = True
        
        # Compute normal in local space, then transform to world
        local_normal = compute_normal(obj.geometry, t)
        if hasattr(obj, 'transform'):
            # Inverse-transpose for normal transformation
            world_normal = obj.transform.inverse_transpose().transform_vector(local_normal)
            ray.normal = normalize(world_normal)
        else:
            ray.normal = normalize(local_normal)
            
        return True
    return False
```

## Subtopics

### [Bounding Box Node Intersection](3958-bounding-box-node-intersection.md)
A recursive ray traversal algorithm for a binary bounding box tree (BBNode) that determines the closest surface intersection by testing the node's bounding box, then recursing into left and right children, and finally comparing hit distances. It differs from generic hierarchical bounding volume searches by enforcing a strict binary split and specific epsilon-based precision handling for distance comparisons.

## Operating characteristics
*   **Time Complexity:** $O(1)$ per object for analytic primitives (spheres, planes, triangles) [S1, unofficial]. $O(N)$ for a naive test against $N$ objects [S3, unofficial].
*   **Memory Complexity:** $O(1)$ auxiliary space per test [S2, unofficial].
*   **Strengths:** Simple to implement for basic primitives; forms the basis for all ray-traced rendering [S1, unofficial].
*   **Limitations:** Naive linear search does not scale to large scenes; requires acceleration structures (BVH, Octree) for performance [S1, unofficial].
*   **When to use:** For small scenes, debugging, or as the leaf node test in acceleration structures.
*   **When not to use:** For large-scale rendering without acceleration; for complex CSG operations without decomposition.

## Background
The concept originates from early ray tracing algorithms, where the intersection of a ray with primitive shapes (spheres, planes) was solved analytically [S1, unofficial]. The term "raytrace" in this context refers to the iterative process of casting rays and updating intersection states [S4, unofficial]. The use of epsilon thresholds to prevent self-intersection is a standard practice in computer graphics to handle floating-point precision errors [S4, unofficial].
