# Fast Convex Polygon Wrapper (FCPW) Accelerator

Also called: Mesh Handler Implementation, MeshQueryHandler

## Overview
The Fast Convex Polygon Wrapper (FCPW) Accelerator is a geometric query structure used within the `MeshQueryHandler` to process polygonal meshes [S1, unofficial]. It provides accelerated queries for finding ray-tetrahedron edge intersections and computing closest-point projections on mesh surfaces [S1, unofficial]. It sets itself apart from sibling methods by wrapping convex polygonal geometry into a single structure that supports both intersection finding and closest-point queries, which is utilized by the [Convex Polygon Falloff Function](10023-convex-polygon-falloff-function.md) [S1, unofficial].

## How it works
The FCPW accelerator is constructed from a set of polygons and their vertex positions [S1, unofficial]. It provides two primary query operations: finding the single intersection of a ray with tetrahedron edges, and finding the closest point on the mesh surface to a query point [S1, unofficial].

**Inputs and Outputs:**
- **Construction Input:** `polygons` (list of vertex indices defining faces), `positions` (3D coordinates of vertices) [S1, unofficial].
- **Intersection Query Input:** `tet_positions` (vertices of the tetrahedron), `accel` (the FCPW structure), `useRobust` (boolean flag), `recordNormals` (boolean flag) [S1, unofficial].
- **Intersection Query Output:** Arrays for intersection times and normals [S1, unofficial].
- **Closest Point Query Input:** `q` (query point in 3D space), `accel` (the FCPW structure) [S1, unofficial].
- **Closest Point Query Output:** `closest_point` (3D coordinate), `normal` (surface normal at closest point) [S1, unofficial].

**Data Structures:**
Not given in the sources.

**Steps:**
1. **Acceleration Structure Construction:** Initialize the accelerator using the polygon soup.
   $$ \text{accel} = \text{get\_fcpw\_accel}(\text{polygons}, \text{positions}) $$
2. **Ray-Tetrahedron Edge Intersection:** Find intersections between a ray and the edges of a tetrahedron defined by `tet_positions`.
   $$ \text{find\_single\_tet\_edge\_intersections\_fcpw}(\text{tet\_positions}, \text{accel}, \text{t\_out}, \text{n\_out}, \text{useRobust}, \text{recordNormals}) $$
   The function writes intersection parameters to `t_out` and normals to `n_out` [S1, unofficial].
3. **Closest Point Projection:** Find the closest point on the mesh to a query point $q$.
   $$ \text{closest\_point\_fcpw}(q, \text{accel}, \text{closest\_point}, \text{normal}) $$
   This computes the projection of $q$ onto the mesh surface and the associated surface normal [S1, unofficial].

**Parameters:**
- `useRobust`: Boolean flag enabling robust intersection calculations [S1, unofficial].
- `recordNormals`: Boolean flag controlling whether surface normals are computed and written to output [S1, unofficial].

## Subtopics

### [Convex Polygon Falloff Function](10023-convex-polygon-falloff-function.md)
Computes a scalar occlusion weight based on distance from a convex polygon. It uses the FCPW accelerator to efficiently rasterize ambient occlusion volumes by leveraging the closest-point and intersection capabilities of the wrapper. Choose this when smooth, monotonic falloff for arbitrary convex polygons is required.

## Background
The FCPW Accelerator is part of the `subgrid-marching` project, developed by H. Baktash [S1, unofficial]. It is implemented as part of the `MeshQueryHandler` class, which serves as an alternative to CGAL-based query handlers for geometric operations on polygonal meshes [S1, unofficial]. The method is used in the context of generating subgrid meshes and computing geometric properties for visualization and further processing [S1, unofficial].
