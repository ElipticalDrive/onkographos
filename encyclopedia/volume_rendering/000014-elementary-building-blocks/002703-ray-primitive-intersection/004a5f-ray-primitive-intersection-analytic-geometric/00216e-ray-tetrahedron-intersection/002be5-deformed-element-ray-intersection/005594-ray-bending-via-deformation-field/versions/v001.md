# Ray Bending via Deformation Field

Also called: Barycentric interpolation ray displacement, Discrete deformation field ray bending

## Overview
Ray Bending via Deformation Field is a technique for rendering deformed radiance fields by correcting the sampling coordinates of rays cast through a deformed tetrahedral mesh. It solves the problem of visual inconsistency that arises when a neural radiance field (NeRF) is associated with a static geometry but the underlying physical object undergoes non-linear deformation. Unlike standard volume rendering which assumes a fixed spatial mapping, this method uses a discrete deformation field derived from a tetrahedral mesh to map sampled points back to their original "effective space" before querying the neural network. It builds on [Deformed element ray intersection](5148-deformed-element-ray-intersection.md) to handle the non-linear mapping from standard element shapes to physical space.

## How it works
**Inputs:**
- A deformed tetrahedral mesh $T'$ representing the current state of the object.
- A reference (undeformed) tetrahedral mesh $T$ representing the original geometry.
- A correspondence mapping between vertices of $T$ and $T'$.
- A trained neural network $\zeta$ (e.g., a NeRF) that maps coordinates and view directions to density $\sigma$ and color $c$.
- Ray origin $o$ and direction $d$.

**Outputs:**
- Density $\sigma$ and color $c$ for each sample point along the ray.

**Data Structures:**
- **Tetrahedral Mesh ($T, T'$):** Defined by a set of vertices $V$ and a set of tetrahedra. Each tetrahedron is defined by 4 vertex indices. The correspondence is stored as a mapping $M: V' \rightarrow V$, where $M(v')$ is the index of the corresponding vertex in the undeformed mesh for a vertex $v'$ in the deformed mesh.
- **Displacement Field:** Implicitly stored as the vector difference between corresponding vertices: $\Delta v = v_{undeformed} - v_{deformed}$.

**Steps:**
1. **Ray Casting:** Cast rays from the camera into the space containing the deformed tetrahedral mesh $T'$.
2. **Point Location:** For each sampled point $p$ along the ray, determine which tetrahedron $t \in T'$ contains $p$. If $p$ is not inside any tetrahedron in $T'$, the point is considered outside the object.
3. **Vertex Displacement Retrieval:** For the tetrahedron $t$ containing $p$, retrieve the four vertices $v'_1, v'_2, v'_3, v'_4$ from the deformed mesh $T'$. Using the correspondence mapping, find the corresponding undeformed vertices $v_1, v_2, v_3, v_4$ from mesh $T$. Calculate the displacement for each vertex: $\Delta v_i = v_i - v'_i$.
4. **Barycentric Interpolation:** Calculate the barycentric coordinates $(\lambda_1, \lambda_2, \lambda_3, \lambda_4)$ of point $p$ with respect to the deformed tetrahedron $t$. Compute the interpolated displacement $\Delta p$:
   $$ \Delta p = \sum_{i=1}^{4} \lambda_i \Delta v_i $$
5. **Coordinate Correction:** Add the displacement to the sampled point coordinate to obtain the corrected coordinate $p_{corr}$ in the effective space:
   $$ p_{corr} = p + \Delta p $$
6. **Neural Query:** Query the neural network $\zeta$ with the corrected coordinate and the view direction $d$ to predict density and color:
   $$ (\sigma, c) = \zeta(p_{corr}, d) $$

**Formula:**
The final prediction for a sample point $p$ with view direction $d$ is given by:
$$ (\sigma, c) = \zeta(p + \Delta p, d) $$
Where:
- $p$ is the sampled point coordinate in the deformed space.
- $\Delta p$ is the interpolated displacement vector.
- $\zeta$ is the neural network (e.g., MLP).
- $d$ is the view direction.

**Parameters:**
- **Sampling Density:** Number of samples per ray. Not given in the sources.
- **Neural Network Architecture:** Not given in the sources.

**Edge Cases and Pitfalls:**
- **Outside Mesh:** Sampled points that are not within the tetrahedral mesh $T'$ are not moved. The part of the ray outside the tetrahedral mesh will not be bent, and the original coordinate $p$ is used for querying $\zeta$ [S1].
- **Precision:** Barycentric coordinate calculation must be robust to ensure $\sum \lambda_i = 1$ and $\lambda_i \ge 0$ for points inside the tetrahedron.
- **Degenerate Tetrahedra:** If the deformed tetrahedron has zero volume (degenerate), barycentric coordinates are undefined. This is not explicitly handled in the sources [G].

**Pseudocode:**
```python
def ray_bending(p_sample, ray_direction, deformed_mesh, undeformed_mesh, correspondence_map, neural_network):
    """
    Calculate density and color for a sample point using ray bending.
    
    Args:
        p_sample: 3D coordinate of the sample point in deformed space.
        ray_direction: View direction vector.
        deformed_mesh: Tetrahedral mesh T' with vertices V' and tetrahedra.
        undeformed_mesh: Tetrahedral mesh T with vertices V.
        correspondence_map: Dictionary mapping vertex index in T' to vertex index in T.
        neural_network: Function or model to query for (sigma, color).
        
    Returns:
        sigma: Density.
        color: RGB color.
    """
    # Step 2: Find containing tetrahedron in deformed mesh
    tet_idx = find_containing_tetrahedron(p_sample, deformed_mesh)
    
    if tet_idx is None:
        # Point is outside the mesh; no bending
        p_corrected = p_sample
    else:
        # Step 3: Get vertices and displacements
        # Get indices of the 4 vertices of the tetrahedron in deformed mesh
        v_prime_indices = deformed_mesh.tetrahedra[tet_idx]
        v_primes = [deformed_mesh.vertices[i] for i in v_prime_indices]
        
        # Get corresponding undeformed vertices
        v_indices = [correspondence_map[v_idx] for v_idx in v_prime_indices]
        v_undeformed = [undeformed_mesh.vertices[i] for i in v_indices]
        
        # Calculate vertex displacements: v_undeformed - v_deformed
        displacements = [v_u - v_p for v_u, v_p in zip(v_undeformed, v_primes)]
        
        # Step 4: Barycentric interpolation
        # Calculate barycentric coordinates of p_sample relative to v_primes
        lambdas = compute_barycentric_coordinates(p_sample, v_primes)
        
        # Interpolate displacement
        delta_p = sum(l * d for l, d in zip(lambdas, displacements))
        
        # Step 5: Coordinate correction
        p_corrected = p_sample + delta_p
        
    # Step 6: Neural query
    sigma, color = neural_network(p_corrected, ray_direction)
    
    return sigma, color

def compute_barycentric_coordinates(p, vertices):
    """
    Compute barycentric coordinates of point p relative to a tetrahedron defined by 4 vertices.
    Returns a tuple (lambda1, lambda2, lambda3, lambda4).
    """
    v0, v1, v2, v3 = vertices
    # Vector from v0 to p
    v0p = p - v0
    # Vectors from v0 to other vertices
    v0v1 = v1 - v0
    v0v2 = v2 - v0
    v0v3 = v3 - v0
    
    # Compute dot products
    d00 = dot(v0v1, v0v1)
    d01 = dot(v0v1, v0v2)
    d02 = dot(v0v1, v0v3)
    d11 = dot(v0v2, v0v2)
    d12 = dot(v0v2, v0v3)
    d22 = dot(v0v3, v0v3)
    
    dvp0 = dot(v0p, v0v1)
    dvp1 = dot(v0p, v0v2)
    dvp2 = dot(v0p, v0v3)
    
    # Solve linear system for barycentric coordinates
    # This is a simplified representation; in practice, solve the 3x3 system
    # [d00 d01 d02] [l1]   [dvp0]
    # [d01 d11 d12] [l2] = [dvp1]
    # [d02 d12 d22] [l3]   [dvp2]
    # l0 = 1 - l1 - l2 - l3
    
    # Placeholder for actual linear solver
    l1, l2, l3 = solve_linear_system([[d00, d01, d02], [d01, d11, d12], [d02, d12, d22]], [dvp0, dvp1, dvp2])
    l0 = 1.0 - l1 - l2 - l3
    
    return (l0, l1, l2, l3)
```

## Subtopics

### [Tensor Field Ray Bending](23804-tensor-field-ray-bending.md)
Tensor Field Ray Bending is a visualization method where parallel rays are issued toward a tensor field and bent by a transforming force derived from the local tensor value. It solves the problem of visual clutter inherent in glyph-based methods by projecting the integrated effects of the tensor field onto a 2D receiving plane or by rendering bent ray tubes, revealing spatially continuous deformation patterns. Unlike path tracing which renders 1D line glyphs, this method uses image distortion or photon distribution to show 2D features and continuous changes through image deformation. It differs from Hesselink's hyperstreamline algorithm by not requiring symmetric tensors and by providing flexibility to control path traces via a scaling parameter.

## Operating characteristics
- **Time Complexity:** The method requires finding the containing tetrahedron for each sample point, which is $O(\log N)$ or $O(N)$ depending on the spatial acceleration structure used (e.g., BVH, grid). Barycentric interpolation is $O(1)$. Neural network query is $O(D)$ where $D$ is the network depth/width.
- **Memory Complexity:** Requires storing the deformed and undeformed tetrahedral meshes and the correspondence map. Memory usage is proportional to the number of vertices and tetrahedra.
- **Strengths:** Allows for non-rigid editing of NeRFs by leveraging geometric deformation fields. It maintains the visual quality of the original NeRF while adapting to the new geometry.
- **Limitations:** Only bends rays within the tetrahedral mesh. Points outside the mesh are not bent, which may cause artifacts at the boundaries if the deformation is significant. The quality depends on the accuracy of the tetrahedral mesh and the correspondence mapping.
- **When to use:** When rendering deformed objects represented by a tetrahedral mesh and a pre-trained NeRF.
- **When not to use:** When the deformation is not well-represented by a tetrahedral mesh or when the object is not enclosed by a mesh.

## Background
The method was introduced in "NeRF-Editing: Geometry Editing of Neural Radiance Fields" [S1]. It addresses the challenge of editing NeRFs by incorporating geometric deformations. The approach utilizes discrete transformations from a deformed tetrahedral mesh to bend casting rays, allowing for the editing of NeRFs of general models. The method was tested on synthetic data and real scenes, demonstrating its ability to edit objects into different poses and render them under different views.
