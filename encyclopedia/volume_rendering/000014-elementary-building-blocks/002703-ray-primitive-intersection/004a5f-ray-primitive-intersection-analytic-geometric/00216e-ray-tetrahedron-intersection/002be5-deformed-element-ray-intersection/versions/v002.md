# Deformed element ray intersection

Also called: Wiley et al. method for deformed quadratic tetrahedra

## Overview
This method determines the ray segments that intersect deformed finite elements, addressing the problem where the mapping from a standard element shape to physical simulation space is non-linear [S1, book]. It is distinct from linear tetrahedron intersection methods because it handles higher-order polynomial mappings, requiring the calculation of multiple intersection segments and an approximate inverse mapping to evaluate scalar functions [S1, book].

## How it works
**Inputs and Outputs**
*   **Input:** A ray defined by origin $\mathbf{o}$ and direction $\mathbf{d}$; a deformed finite element (specifically a quadratic tetrahedron) defined by its control points in physical space and their corresponding coordinates in the standard reference element [S1, book].
*   **Output:** A set of ray parameter intervals $[t_{\text{start}}, t_{\text{end}}]$ representing the segments of the ray that lie within the deformed element [S1, book].

**Data Structures**
The deformed element is represented by its vertices and the non-linear mapping function $\mathbf{x}(\mathbf{u})$ that transforms a point $\mathbf{u}$ from the standard reference tetrahedron to physical space $\mathbf{x}$ [S1, book].

**Steps**
1.  **Cast Ray:** Define the ray as $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ [G].
2.  **Determine Intersection Segments:** Find the parameter values $t$ where the ray enters and exits the deformed element. For deformed quadratic tetrahedra, Wiley et al. provide the method to determine these segments [S1, book].
3.  **Approximate Inverse Mapping:** For any point $\mathbf{x}$ on a valid ray segment, compute the corresponding coordinates $\mathbf{u}$ in the standard reference element. Since an analytical inverse may not exist, it is approximated along the ray segments using polynomial splines [S1, book].
4.  **Evaluate Scalar Function:** Evaluate the scalar function defined on the standard reference element at the mapped coordinates $\mathbf{u}$ [S1, book].

**Formulas**
*   Ray: $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$
*   Deformed Element Mapping: $\mathbf{x}(\mathbf{u})$, where $\mathbf{u}$ are coordinates in the reference tetrahedron [S1, book].
*   Inverse Mapping Approximation: $\mathbf{u} \approx S(\mathbf{x})$, where $S$ is a polynomial spline approximation along the ray segment [S1, book].

**Parameters**
*   Polynomial degree: Determined by the finite element order (e.g., quadratic for quadratic tetrahedra) [S1, book].
*   Integration method: After segments are found, integration can use equally spaced sampling or Gaussian integration for smoothly varying transfer functions [S1, book].

**Edge Cases and Pitfalls**
*   **Multiple Segments:** A ray can intersect a deformed element in more than one segment due to non-linear deformation [S1, book].
*   **Inverse Mapping Requirement:** An inverse map is strictly required before the scalar function can be evaluated at a point on the ray, as the function is defined on the standard element [S1, book].
*   **Numerical Precision:** Solving for intersections and approximating inverse mappings with splines requires careful handling of numerical stability [G].

    """
    Determines ray segments intersecting a deformed quadratic tetrahedron.
    """
    # Step 1: Determine intersection segments for deformed quadratic tetrahedra [S1, book]
    # [Comment] The exact polynomial solving method is provided by Wiley et al. [S1, book]
    intersection_params = element.find_ray_segments(ray_origin, ray_direction)
    
    # Step 2: Filter and sort valid segments
    valid_params = sorted([t for t in intersection_params if t > 0])
    segments = []
    for i in range(0, len(valid_params) - 1, 2):
        segments.append((valid_params[i], valid_params[i+1]))
    return segments

def evaluate_scalar_at_ray_point(ray_origin, ray_direction, t, element):
    """
    Evaluates the scalar function at a point on the ray within a deformed element.
    """
    point_physical = ray_origin + t * ray_direction

## Subtopics

### Ray Bending via Deformation Field
This variant is used in NeRF editing contexts where a deformed tetrahedral mesh $T'$ corresponds to an original mesh $T$ [S2]. It bends casting rays by calculating the displacement of sampled points via barycentric interpolation [S2]. Rays are cast to the space containing the deformed mesh $T'$ [S2]. For each sampled point, the tetrahedron in $T'$ containing it is identified [S2]. Using the correspondence between $T$ and $T'$, the displacement $\Delta p$ from the deformed vertices to the original vertices is obtained via barycentric interpolation of the four vertices of the containing tetrahedron [S2]. The displacement $\Delta p$ is added to the sampled point's coordinate $p$ to predict density and RGB values using a network $\zeta$: $(\zeta(p + \Delta p), \zeta(d)) \rightarrow (\sigma, c)$ [S2]. A pitfall is that sampled points outside the tetrahedral mesh $T'$ are not moved, meaning parts of the ray outside the mesh are not bent [S2].

## Operating characteristics
*   **Complexity:** The complexity is dominated by solving intersection equations and evaluating multiple segments [S1, book].
*   **Performance:** Gaussian integration improves accuracy for smoothly varying transfer functions [S1, book].
*   **Strengths:** Handles non-linear deformations accurately [S1, book].
*   **Limitations:** Requires complex inverse mapping approximations; multiple intersection segments increase computational cost [S1, book].
*   **When to use:** Visualizing data on deformed finite element meshes where linear approximations are insufficient [S1, book].

## Background
The method was introduced by Wiley et al. [57] for determining ray segments intersecting deformed quadratic tetrahedra [S1, book]. It addresses the challenges of volume rendering with finite elements where the mapping to physical space is non-linear [S1, book].
