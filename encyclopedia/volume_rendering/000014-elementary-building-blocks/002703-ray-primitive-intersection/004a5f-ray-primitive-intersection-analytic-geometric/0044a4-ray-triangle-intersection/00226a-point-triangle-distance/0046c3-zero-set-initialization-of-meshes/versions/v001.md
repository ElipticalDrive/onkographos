# Zero Set Initialization of Meshes

Also called: Zero Set Initialization for Triangle Meshes

## Overview
Zero Set Initialization of Meshes is a method for initializing the signed distance field (SDF) of a triangular mesh by identifying samples that lie on or near the mesh surface (the "zero set") and assigning them initial signs. It solves the problem of establishing an accurate initial distance field from a polygonal mesh without relying on global topological information. It differs from its sibling [Unsigned Triangle Distance](3587-unsigned-triangle-distance.md) by computing signed distances and from [Mesh SDF Sampling](7159-mesh-sdf-sampling.md) by focusing specifically on the initialization phase for distance transforms rather than general sampling. It builds on [Point-Triangle Distance](2776-point-triangle-distance.md) to determine geometric proximity.

## How it works
**Inputs:** A triangular mesh (list of triangles), a 3D grid of samples, and `cell-width` (the distance between adjacent samples in x, y, and z directions).
**Outputs:** A set of samples marked as part of the zero set, each with an associated sign and a flag indicating if it is queued.

**Data Structures:**
*   `Sample`: Represents a grid point. Fields: `position` (3D vector), `distance` (scalar, initialized to infinity), `sign` (scalar, +1 or -1), `queued` (boolean, default false), `ambiguous` (boolean, default false).
*   `Triangle`: Defined by three vertices $v_0, v_1, v_2$ and normal $n$.

**Steps:**
1.  **Bounding Box Adjustment:** For every triangle $T$ in the mesh:
    *   Compute the axis-aligned bounding box (AABB) of $T$: $(x_{min}, y_{min}, z_{min})$ to $(x_{max}, y_{max}, z_{max})$.
    *   Expand the box by `cell-width`:
        $$ x'_{min} = x_{min} - \text{cell-width}, \quad x'_{max} = x_{max} + \text{cell-width} $$
        (Similarly for $y$ and $z$).
2.  **Sample Evaluation:** For each sample $s$ within the adjusted bounding box:
    *   Compute the closest point $cp(s)$ on triangle $T$ to $s$ using [Point-Triangle Distance](2776-point-triangle-distance.md).
    *   Determine the type of closest point: `face`, `edge`, or `vertex`.
    *   Calculate the distance $\delta = \| cp(s) - s \|$.
    *   If $\delta \le \sqrt{3} \cdot \text{cell-width}$ and $\delta < s.distance$:
        *   Place $s$ on the zero set queue.
        *   Set $s.queued = \text{true}$ to prohibit duplication.
        *   Update $s.distance = \delta$.
        *   Compute $s.sign$ based on the closest point type (see Sign Computation below).
        *   If the closest point is a `vertex` and signs are ambiguous, set $s.ambiguous = \text{true}$ and $s.sign = 0$.

**Sign Computation:**
The sign determines whether the sample is inside or outside the mesh.
*   **Face Case:** If $cp(s)$ lies on the face of $T$, the sign is determined by the dot product of the triangle normal $n'$ and the vector $v = s - cp(s)$:
    $$ \text{sign} = \text{sign}(n' \cdot v) $$
    where $\text{sign}(x)$ is $+1$ if $x \ge 0$ and $-1$ if $x < 0$.
*   **Edge Case:** If $cp(s)$ lies on an edge shared by two triangles $T_1$ and $T_2$, compute dot products $d_1 = n_1 \cdot v$ and $d_2 = n_2 \cdot v$. The sign is taken from the triangle with the larger absolute dot product:
    $$ \text{sign} = \text{sign}(d_i) \quad \text{where } |d_i| = \max(|d_1|, |d_2|) $$
*   **Vertex Case:** If $cp(s)$ coincides with a vertex shared by multiple triangles, compute dot products for all adjacent triangles. If the dot products have mixed signs (some positive, some negative), the sample is marked as **ambiguous**. No sign is propagated initially ($s.sign = 0$).

**Post-Processing for Ambiguity:**
After the initial pass and any subsequent distance transform steps, ambiguous samples are revisited. The signs of the 26-neighbors of the ambiguous sample are examined. The sign of the majority of the neighbors is assigned to the ambiguous sample.

**Pseudocode:**
```python
def zero_set_initialization(mesh, grid, cell_width):
    for triangle in mesh:
        # 1. Compute and expand bounding box
        bbox_min, bbox_max = triangle.bounding_box()
        expanded_min = bbox_min - cell_width
        expanded_max = bbox_max + cell_width
        
        # 2. Iterate samples in expanded box
        for s in grid.samples_in_box(expanded_min, expanded_max):
            if s.queued:
                continue
                
            # Compute closest point using Point-Triangle Distance logic
            cp, cp_type = point_triangle_distance(triangle, s.position)
            delta = distance(cp, s.position)
            
            # Check threshold and update distance
            if delta <= sqrt(3) * cell_width and delta < s.distance:
                s.queued = True
                s.distance = delta
                
                # Compute sign
                if cp_type == 'face':
                    v = s.position - cp
                    s.sign = 1 if dot(triangle.normal, v) >= 0 else -1
                elif cp_type == 'edge':
                    v = s.position - cp
                    # Identify adjacent triangles for the edge
                    t1, t2 = triangle.adjacent_triangles(cp)
                    d1 = dot(t1.normal, v)
                    d2 = dot(t2.normal, v)
                    if abs(d1) > abs(d2):
                        s.sign = 1 if d1 >= 0 else -1
                    else:
                        s.sign = 1 if d2 >= 0 else -1
                elif cp_type == 'vertex':
                    v = s.position - cp
                    adjacent = triangle.adjacent_triangles_at_vertex(cp)
                    signs = [1 if dot(t.normal, v) >= 0 else -1 for t in adjacent]
                    if all(s > 0 for s in signs) or all(s < 0 for s in signs):
                        s.sign = signs[0]
                    else:
                        s.ambiguous = True
                        s.sign = 0
```

## Subtopics

### Closest Point Baseline
A naive baseline method that builds correspondence between an extracted triangular mesh and continuous volume space by finding the closest point on the mesh surface for each sampled point and using its displacement directly as the sampled point's displacement [S2]. Unlike Zero Set Initialization, it does not explicitly manage a queue or sign propagation for distance transforms, serving as a simpler geometric proxy.

## Operating characteristics
*   **Time Complexity:** $O(N \cdot M)$, where $N$ is the number of triangles and $M$ is the number of samples within the expanded bounding boxes of all triangles. In practice, spatial indexing (e.g., voxelization) is often used to limit $M$.
*   **Memory Complexity:** $O(G)$, where $G$ is the number of grid samples, to store distance, sign, and queue flags.
*   **Strengths:** Efficiently identifies the zero set without requiring complex topological data structures or adjacency information for the entire mesh [S1]. It is robust for local curvature regions.
*   **Limitations:** Vertex ambiguity requires post-processing. The $\sqrt{3} \cdot \text{cell-width}$ threshold is heuristic; tighter bounds may miss samples, while looser bounds increase computational cost. It does not guarantee a globally consistent sign field without the neighbor-heuristic resolution.
*   **When to use:** When initializing SDFs for distance transforms on triangle meshes where topological information is unavailable or expensive to compute.
*   **When not to use:** When high precision is required without post-processing ambiguity resolution, or when the mesh has complex non-manifold geometry where vertex ambiguity is frequent.

## Background
The method was introduced in the context of multiresolution distance volumes for progressive surface compression [S1]. It is designed to operate on individual triangles without using edge or vertex adjacency information, making it suitable for compressed or simplified mesh representations. The technique is noted as being very similar to the method proposed by Huang et al. [S1, Ref 12 in original paper], though the cited source does not provide details on Huang's algorithm. It is primarily used in computer graphics for generating signed distance fields from polygonal meshes for rendering and simulation.
