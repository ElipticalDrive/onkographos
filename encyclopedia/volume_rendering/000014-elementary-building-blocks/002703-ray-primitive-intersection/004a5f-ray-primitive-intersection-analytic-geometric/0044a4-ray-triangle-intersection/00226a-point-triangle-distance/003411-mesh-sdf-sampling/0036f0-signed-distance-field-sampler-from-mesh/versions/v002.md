# Signed Distance Field Sampler from Mesh

Also called: createMeshInstanceSdfSampler

## Overview
This method constructs a signed distance field (SDF) query function from a `THREE.Mesh` instance, enabling efficient point-to-surface distance evaluation in world space. It serves as a high-level wrapper that validates the input object, ensures the mesh's world transformation matrix is current, and delegates the actual geometric sampling logic to a geometry-specific sampler. Unlike raw ray-triangle intersection which requires a direction vector, this method directly computes the scalar signed distance for arbitrary points, distinguishing it from [Surface Distance Query](13843-surface-distance-query.md) by providing a continuous field approximation rather than a discrete search result.

## How it works
The method operates by validating the input, updating the transformation state, and delegating to a lower-level geometry sampler.

**Inputs:**
- `instance`: A `THREE.Mesh` object containing geometry and material properties.

**Outputs:**
- A function `sdfSampler(x, y, z)` returning a `number`.
- The returned value is the shortest signed distance from the world-space coordinate $(x, y, z)$ to the mesh surface.
- Sign convention: Negative values indicate the point is inside the mesh; positive values indicate the point is outside [S1, unofficial].

**Data Structures:**
- The method relies on the internal structure of `THREE.Mesh` and `THREE.BufferGeometry`.
- `instance.matrixWorld`: A 4x4 transformation matrix representing the mesh's position, rotation, and scale in world space.
- `instance.geometry`: The underlying vertex and index data defining the mesh topology.

**Steps:**
1. **Validation**: Check if the provided `instance` is an instance of `THREE.Mesh`. If not, raise an error with the message "Expected a THREE.Mesh instance" [S1, unofficial].
2. **Matrix Update**: Call `instance.updateMatrixWorld(true)` to ensure the mesh's world matrix reflects any pending local transformations or parent hierarchy changes [S1, unofficial].
3. **Delegation**: Invoke `createGeometrySdfSampler(instance.geometry, instance.matrixWorld)` to generate the actual distance computation function [S1, unofficial].

**Pseudocode:**
```python
def createMeshInstanceSdfSampler(instance):
    # Step 1: Validate input type
    if not isinstance(instance, THREE.Mesh):
        raise Error("Expected a THREE.Mesh instance")
    
    # Step 2: Update world matrix to reflect current transforms
    instance.updateMatrixWorld(true)
    
    # Step 3: Delegate to geometry-specific sampler
    # The geometry sampler handles the actual point-to-triangle distance logic
    # using the provided geometry and world matrix.
    return createGeometrySdfSampler(instance.geometry, instance.matrixWorld)
```

**Edge Cases and Pitfalls:**
- **Non-Mesh Input**: Passing a `THREE.Object3D` or other non-mesh object will trigger a validation error.
- **Stale Transforms**: If the mesh's local transform changes but `updateMatrixWorld` is not called, the SDF will be computed against an outdated world position, leading to incorrect distances [S1, unofficial].
- **Nested Hierarchies**: The `true` argument in `updateMatrixWorld(true)` ensures that the entire descendant hierarchy is updated, which is critical if the mesh is part of a complex scene graph [S1, unofficial].

## Subtopics

## Operating characteristics
- **Time Complexity**: The construction time is $O(1)$ relative to the mesh size, as it only performs validation and matrix updates. The query time complexity depends on the underlying `createGeometrySdfSampler` implementation, which typically involves iterating over triangles or using spatial acceleration structures.
- **Memory Complexity**: $O(1)$ for the wrapper itself. The memory usage is dominated by the geometry data and any acceleration structures created by the delegated sampler.
- **Strengths**: Simple API for integrating mesh-based SDFs into volume rendering pipelines; automatic handling of world transformations.
- **Limitations**: Relies on the performance of the underlying geometry sampler; does not provide built-in spatial acceleration (e.g., BVH) unless the delegated sampler implements it.
- **When to use**: When a quick, robust SDF query is needed for a single mesh or a small number of meshes in a scene.
- **When not to use**: For large-scale scenes with many meshes where a global acceleration structure is required; consider [Surface Distance Query](13843-surface-distance-query.md) for discrete surface aggregation.

## Background
This method is part of the `three.js-volume-renderer` library, an unofficial implementation for volume rendering using Three.js. It was developed to provide convenient access to signed distance fields for mesh-based objects within a WebGL context. The method abstracts the complexity of matrix transformations and geometry access, allowing developers to focus on the rendering logic.
