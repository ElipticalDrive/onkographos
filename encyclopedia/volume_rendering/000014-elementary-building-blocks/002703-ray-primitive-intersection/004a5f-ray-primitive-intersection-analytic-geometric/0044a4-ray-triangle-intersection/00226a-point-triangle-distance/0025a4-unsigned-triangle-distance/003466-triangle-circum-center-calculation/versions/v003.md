# Triangle Circum-Center Calculation

Also called: Circum-center, Circumcircle Center

## Overview
Computes the center and radius of the unique circle passing through three non-collinear vertices $a, b, c$ in 3D space. It is primarily used in volume rendering to define bounding spheres for triangle-based leaf nodes (e.g., in TetSplat) or for quality metrics in isosurface extraction. It differs from [Unsigned Triangle Distance](3587-unsigned-triangle-distance.md) by providing a bounding volume rather than a distance metric, and from [Tetrahedron Circum-Center Calculation](7292-tetrahedron-circum-center-calculation.md) by operating on three points in 3D rather than four.

## How it works
**Inputs:** Three vertices $a, b, c \in \mathbb{R}^3$.
**Outputs:** Circum-center $C \in \mathbb{R}^3$ and circum-radius $R \in \mathbb{R}$.

**Data Structures:**
- Vectors $a, b, c$: 3-component floating-point vectors.

**Steps:**
1. **Compute Edge Vectors:**
   Let $u = b - a$ and $v = c - a$.
2. **Compute Normal Vector:**
   Let $n = u \times v$. This vector is perpendicular to the triangle plane.
3. **Check for Degeneracy:**
   If $|n|^2 \approx 0$ (vertices are collinear), the triangle is degenerate. Handle as specified in [Pitfalls].
4. **Compute Relative Circum-Center:**
   Calculate the circum-center relative to vertex $a$ using the formula:
   $$ m_{tri} = \frac{|v|^2 (n \times u) + |u|^2 (v \times n)}{2 |n|^2} $$
   Where:
   - $|u|^2 = u \cdot u$
   - $|v|^2 = v \cdot v$
   - $|n|^2 = n \cdot n$
   - $\times$ denotes the cross product.
5. **Compute Absolute Circum-Center:**
   $$ C = a + m_{tri} $$
6. **Compute Circum-Radius:**
   $$ R = |m_{tri}| $$

**Pitfalls:**
- **Degeneracy:** The denominator $2|n|^2$ vanishes when vertices are collinear. The sources recommend collapsing degenerate tetrahedra first, then extracting triangles. For remaining obtuse triangles, approximate the circum-center as the midpoint of the longest edge and the radius as half that edge's length [S1, unofficial].
- **Numerical Stability:** The formula uses coordinate differences rather than absolute values, which helps stability when coordinates are small [S1, unofficial].

**Pseudocode:**
```python
import math

def triangle_circum_center(a, b, c):
    """
    Computes the circum-center and radius of a triangle defined by vertices a, b, c.
    Returns (center, radius).
    """
    # Edge vectors relative to a
    u = [b[i] - a[i] for i in range(3)]
    v = [c[i] - a[i] for i in range(3)]
    
    # Normal vector n = u x v
    n = [
        u[1]*v[2] - u[2]*v[1],
        u[2]*v[0] - u[0]*v[2],
        u[0]*v[1] - u[1]*v[0]
    ]
    
    # Squared magnitude of normal
    n_sq = n[0]**2 + n[1]**2 + n[2]**2
    
    # Handle degenerate case (collinear vertices)
    if n_sq < 1e-12: # Threshold [G]
        # Approximate as midpoint of longest edge
        len_ab = math.sqrt((b[0]-a[0])**2 + (b[1]-a[1])**2 + (b[2]-a[2])**2)
        len_bc = math.sqrt((c[0]-b[0])**2 + (c[1]-b[1])**2 + (c[2]-b[2])**2)
        len_ca = math.sqrt((a[0]-c[0])**2 + (a[1]-c[1])**2 + (a[2]-c[2])**2)
        
        if len_ab >= len_bc and len_ab >= len_ca:
            center = [(a[0]+b[0])/2, (a[1]+b[1])/2, (a[2]+b[2])/2]
            radius = len_ab / 2
        elif len_bc >= len_ab and len_bc >= len_ca:
            center = [(b[0]+c[0])/2, (b[1]+c[1])/2, (b[2]+c[2])/2]
            radius = len_bc / 2
        else:
            center = [(c[0]+a[0])/2, (c[1]+a[1])/2, (c[2]+a[2])/2]
            radius = len_ca / 2
        return center, radius

    # Squared magnitudes of edges
    u_sq = u[0]**2 + u[1]**2 + u[2]**2
    v_sq = v[0]**2 + v[1]**2 + v[2]**2
    
    # Cross products for numerator
    # term1 = |v|^2 * (n x u)
    n_cross_u = [
        n[1]*u[2] - n[2]*u[1],
        n[2]*u[0] - n[0]*u[2],
        n[0]*u[1] - n[1]*u[0]
    ]
    term1 = [v_sq * n_cross_u[i] for i in range(3)]
    
    # term2 = |u|^2 * (v x n)
    v_cross_n = [
        v[1]*n[2] - v[2]*n[1],
        v[2]*n[0] - v[0]*n[2],
        v[0]*n[1] - v[1]*n[0]
    ]
    term2 = [u_sq * v_cross_n[i] for i in range(3)]
    
    # Sum terms
    sum_terms = [term1[i] + term2[i] for i in range(3)]
    
    # Divide by 2 * |n|^2
    denom = 2.0 * n_sq
    m_tri = [sum_terms[i] / denom for i in range(3)]
    
    # Absolute center
    center = [a[i] + m_tri[i] for i in range(3)]
    
    # Radius
    radius = math.sqrt(m_tri[0]**2 + m_tri[1]**2 + m_tri[2]**2)
    
    return center, radius
```

## Subtopics

### [Tetrahedron Circum-Center Calculation](7292-tetrahedron-circum-center-calculation.md)
Computes the circum-sphere of a tetrahedron (4 vertices). Choose this when working with tetrahedral meshes or 3D volumetric primitives. It extends the 2D triangle concept to 3D space.

## Operating characteristics
- **Time Complexity:** $O(1)$ constant time operations (vector arithmetic).
- **Memory Complexity:** $O(1)$ auxiliary space.
- **Strengths:** Analytic solution; robust for non-degenerate triangles; uses coordinate differences for stability.
- **Limitations:** Numerically unstable for degenerate (collinear) or near-degenerate triangles. Requires handling obtuse triangles via approximation as per [S1, unofficial].
- **When to use:** When defining bounding spheres for triangle-based splats or leaf nodes in volume rendering.
- **When not to use:** For degenerate triangles without pre-processing; for distance queries (use [Unsigned Triangle Distance](3587-unsigned-triangle-distance.md)).

## Background
Originated in the context of real-time rendering and volume clipping of large datasets, specifically in the TetSplat method by Museth and Lombeyda (2004) [S1, unofficial]. The method allows triangles to be used as geometric primitives to derive leaf nodes for hierarchical data structures. It is expressed in differences of coordinates to handle potentially small absolute values [S1, unofficial].
