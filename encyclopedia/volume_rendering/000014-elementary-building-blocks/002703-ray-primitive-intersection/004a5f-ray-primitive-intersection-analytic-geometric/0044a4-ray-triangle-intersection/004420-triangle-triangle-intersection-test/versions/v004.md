# Triangle-Triangle Intersection Test

Also called: SAT Triangle Intersection, Separating Axis Theorem (SAT) for triangles, testIntersection

## Overview
The Triangle-Triangle Intersection Test determines whether two triangles in 3D space intersect (share any common points) using the Separating Axis Theorem (SAT) [S1, S2, S3, unofficial]. It solves the problem of detecting collisions between triangular primitives, which is a fundamental building block for mesh intersection, voxelization, and constructive solid geometry [S1, S2, S3, unofficial]. Unlike [Ray-Triangle Intersection](11312-ray-triangle-intersection.md), which tests a ray against a single triangle, this method tests two arbitrary triangles against each other without a predefined viewing direction. It is distinct from [General Ray-Triangle Intersection (Plücker Coordinates)](909-general-ray-triangle-intersection-pl-cker-coordinates.md) in that it relies on interval projection rather than line-plane duality, and from [Point-Triangle Distance](2776-point-triangle-distance.md) as it returns a boolean intersection status rather than a distance metric.

## How it works
### Inputs and Outputs
**Input:** Two triangles, $T_1$ and $T_2$. Each triangle is defined by three vertices in 3D space.
**Output:** A boolean value: `true` (or 1) if the triangles intersect, `false` (or 0) if they do not.

### Data Structures
The triangles are represented by their vertex coordinates. A standard layout is:
```python
class Triangle:
    vt: list of 3 vectors  # Each vector is a 3D float array [x, y, z]
```
Vertices are indexed $0, 1, 2$.

### Algorithm Steps
The test projects both triangles onto a set of potential separating axes. If the projections (intervals) on any axis are disjoint, the triangles do not intersect. If all tested axes show overlap, the triangles intersect.

1.  **Compute Edge Vectors:**
    For each triangle $T_i$ ($i \in \{1, 2\}$), compute the three edge vectors:
    $$
    \begin{aligned}
    e_{i,0} &= T_i.vt[1] - T_i.vt[0] \\
    e_{i,1} &= T_i.vt[2] - T_i.vt[1] \\
    e_{i,2} &= T_i.vt[0] - T_i.vt[2]
    \end{aligned}
    $$

2.  **Compute Face Normals:**
    Compute the unnormalized face normals for both triangles:
    $$
    n_1 = e_{1,0} \times e_{1,1}
    $$
    $$
    n_2 = e_{2,0} \times e_{2,1}
    $$
    [S1, S2, S3, unofficial]

3.  **Check for Co-planarity:**
    Compute the cross product of the two face normals:
    $$
    n = n_1 \times n_2
    $$
    If $n$ is the zero vector (i.e., $|n_x| < \epsilon, |n_y| < \epsilon, |n_z| < \epsilon$ for a small tolerance $\epsilon$), the triangles are co-planar [S1, S2, S3, unofficial].
    
    *   **Co-planar Case:**
        1.  Check if the triangles lie in the same plane. Compute the dot product of $n_1$ with a vertex from each triangle (e.g., $T_1.vt[0]$ and $T_2.vt[0]$). If $n_1 \cdot T_1.vt[0] \neq n_1 \cdot T_2.vt[0]$, the planes are distinct, and the triangles do not intersect. Return `false` [S1, S3, unofficial].
        2.  If they are in the same plane, test separation along the 6 edge normals: $n_1 \times e_{1,i}$ for $i \in \{0,1,2\}$ and $n_2 \times e_{2,i}$ for $i \in \{0,1,2\}$ [S1, S3, unofficial].
        3.  If any axis separates the triangles, return `false`. Otherwise, return `true` [S1, S3, unofficial].
        *Note:* Some implementations use a hack where co-planar triangles are immediately considered non-intersecting to avoid degenerate cases, but the full SAT test is more robust [S1, S2, S3, unofficial].

    *   **Non-Co-planar Case:**
        1.  Test separation along the face normals $n_1$ and $n_2$. If either axis separates the triangles, return `false` [S1, S3, unofficial].
        2.  Test separation along the 9 cross products of every edge of $T_1$ with every edge of $T_2$:
            $$
            axis_{i,j} = e_{1,i} \times e_{2,j} \quad \text{for } i,j \in \{0,1,2\}
            $$
            If any of these 9 axes separates the triangles, return `false` [S1, S3, unofficial].
        3.  If no axis separates the triangles, return `true` [S1, S3, unofficial].

4.  **Projection and Separation Check:**
    For each candidate axis $A$:
    1.  Project all vertices of $T_1$ onto $A$ to find the interval $[min_1, max_1]$:
        $$
        \begin{aligned}
        min_1 &= A \cdot T_1.vt[0] \\
        max_1 &= min_1 \\
        \text{for } k \in \{1, 2\}: \\
        \quad temp &= A \cdot T_1.vt[k] \\
        \quad min_1 &= \min(min_1, temp) \\
        \quad max_1 &= \max(max_1, temp)
        \end{aligned}
        $$
    2.  Project all vertices of $T_2$ onto $A$ to find the interval $[min_2, max_2]$ similarly [S2, unofficial].
    3.  Check for separation:
        $$
        \text{if } min_1 \ge max_2 \text{ or } min_2 \ge max_1 \text{ then return } false
        $$
        [S1, S2, S3, unofficial]
        *Note:* To handle floating-point precision, a small epsilon $\epsilon$ (e.g., $0.00001$) is often added to the separation condition: $min_1 > max_2 + \epsilon$ or $min_2 > max_1 + \epsilon$ [S2, S3, unofficial].

### Pseudocode
```python
def triangle_triangle_intersect(t1: Triangle, t2: Triangle, epsilon: float = 1e-5) -> bool:
    # 1. Compute edge vectors
    e1 = [t1.vt[1] - t1.vt[0], t1.vt[2] - t1.vt[1], t1.vt[0] - t1.vt[2]]
    e2 = [t2.vt[1] - t2.vt[0], t2.vt[2] - t2.vt[1], t2.vt[0] - t2.vt[2]]

    # 2. Compute face normals
    n1 = cross(e1[0], e1[1])
    n2 = cross(e2[0], e2[1])

    # 3. Check co-planarity
    n = cross(n1, n2)
    if is_zero_vector(n, epsilon):
        # Co-planar case
        # Check if planes are distinct
        if dot(n1, t1.vt[0]) != dot(n1, t2.vt[0]):
            return False
        
        # Test 6 edge-edge axes: n1 x e1[i] and n2 x e2[i]
        axes = []
        for i in range(3):
            axes.append(cross(n1, e1[i]))
            axes.append(cross(n2, e2[i]))
        
        for axis in axes:
            if test_separation(axis, t1, t2, epsilon):
                return False
        return True
    else:
        # Non-co-planar case
        # Test face normals
        if test_separation(n1, t1, t2, epsilon):
            return False
        if test_separation(n2, t1, t2, epsilon):
            return False
        
        # Test 9 edge-edge axes
        for i in range(3):
            for j in range(3):
                axis = cross(e1[i], e2[j])
                if test_separation(axis, t1, t2, epsilon):
                    return False
        return True

def test_separation(axis, t1, t2, epsilon):
    # Project t1
    min1 = dot(axis, t1.vt[0])
    max1 = min1
    for k in range(1, 3):
        proj = dot(axis, t1.vt[k])
        if proj < min1: min1 = proj
        if proj > max1: max1 = proj
        
    # Project t2
    min2 = dot(axis, t2.vt[0])
    max2 = min2
    for k in range(1, 3):
        proj = dot(axis, t2.vt[k])
        if proj < min2: min2 = proj
        if proj > max2: max2 = proj
        
    # Check overlap
    if min1 > max2 + epsilon or min2 > max1 + epsilon:
        return True # Separated
    return False # Overlapping

def is_zero_vector(v, epsilon):
    return abs(v.x) < epsilon and abs(v.y) < epsilon and abs(v.z) < epsilon
```

### Parameters
- **Epsilon:** A small floating-point tolerance (e.g., $0.00001$) used to handle numerical instability in separation checks and zero-vector detection [S2, S3, unofficial].

### Edge Cases and Pitfalls
- **Co-planar Triangles:** Handling co-planar triangles correctly is critical. Some simplified implementations (e.g., those using bounding boxes) may return `false` for all co-planar triangles as a hack to avoid degenerate cases [S1, S2, S3, unofficial]. The full SAT test requires testing the 6 edge normals in the co-planar case [S1, S3, unofficial].
- **Numerical Precision:** Floating-point errors can cause false negatives or positives. Using an epsilon in the separation check ($min_1 > max_2 + \epsilon$) helps mitigate this [S2, S3, unofficial].
- **Degenerate Triangles:** If a triangle has zero area (collinear vertices), its normal is zero. The algorithm assumes non-degenerate triangles. Degenerate inputs may require pre-validation [G].

## Subtopics

### Bounding Box Pre-check
An early-out optimization where the axis-aligned bounding boxes (AABBs) of the two triangles are tested for intersection. If the AABBs do not intersect, the triangles do not intersect. This is an $O(1)$ check that can save the more expensive SAT test [S2, unofficial].

### Triangle-Triangle Overlap Area
An extension of the intersection test that computes the area of intersection between two triangles, useful for rendering and physics [G].

## Operating characteristics
- **Time Complexity:** $O(1)$ per pair of triangles. The algorithm tests at most 12 axes (2 face normals + 9 edge-edge cross products) for non-co-planar triangles, and up to 6 axes for co-planar triangles [S2, unofficial].
- **Memory Complexity:** $O(1)$. Only a few temporary vectors and scalars are required.
- **Measured Performance:** The SAT method is generally fast and robust for single pair tests. It is widely used in collision detection systems due to its simplicity and lack of division operations (unlike ray-triangle intersection) [S1, S2, S3, unofficial].
- **Strengths:** No division by zero issues (unlike some ray-triangle methods); handles all relative orientations; robust with epsilon tuning.
- **Limitations:** Does not provide the intersection curve or area; co-planar cases require special handling; less efficient than bounding volume hierarchies for large scenes.
- **When to Use:** When testing a small number of triangle pairs, or as a leaf-node test in a spatial partitioning structure.
- **When Not to Use:** For large-scale scene intersection, use a BVH or grid-based approach. For ray-triangle intersection, use [Ray-Triangle Intersection](11312-ray-triangle-intersection.md).

## Background
The Triangle-Triangle Intersection Test using SAT is a standard technique in computational geometry and computer graphics. It is implemented in various open-source dual contouring and mesh processing libraries, such as those by Tao Ju [S1, S2, S3, unofficial]. The method relies on the Separating Axis Theorem, which states that two convex objects are disjoint if and only if there exists a plane (axis) onto which their projections do not overlap. For triangles, the potential separating axes are the face normals and the cross products of their edges.
