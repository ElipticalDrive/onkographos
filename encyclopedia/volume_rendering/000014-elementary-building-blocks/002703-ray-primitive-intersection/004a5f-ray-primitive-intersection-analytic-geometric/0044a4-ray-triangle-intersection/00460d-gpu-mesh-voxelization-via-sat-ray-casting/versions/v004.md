# GPU Mesh Voxelization via SAT Ray Casting

Also called: Ray-Triangle Intersection for Voxelization, UnityGPUMeshVoxelizer, VoxelizeMesh

## Overview
This method converts a triangle mesh into a 3D voxel grid by dispatching a compute shader where each thread corresponds to a voxel cell [S1, unofficial]. It determines voxel solidity by testing each cell against every mesh triangle using a Separating Axis Theorem (SAT) broad-phase test followed by a Möller-Trumbore ray-triangle intersection [S1, unofficial][S2, unofficial]. It differs from hierarchical voxelization by using a brute-force per-voxel, per-triangle approach, making it simple to implement but computationally expensive for high-resolution grids or complex meshes [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A triangle mesh defined by vertex positions and triangle indices [S1, unofficial].
*   **Input:** Voxel grid dimensions ($W, H, D$) and cell size ($s$) [S1, unofficial].
*   **Input:** World-space bounds of the voxelization volume [S1, unofficial].
*   **Output:** A structured buffer of voxels, each containing a position and a boolean `isSolid` flag [S1, unofficial].

**Data Structures:**
The implementation uses the following structures in HLSL/C#:

1.  **Voxel:**
    ```hlsl
    struct Voxel {
        Vector3 position;
        float isSolid;
    };
    ```
    Stored in a `RWStructuredBuffer<Voxel>` [S1, unofficial].

2.  **Triangle:**
    ```hlsl
    struct Triangle {
        float3 a, b, c;
    };
    ```
    Triangles are not stored as a single struct buffer but are fetched from vertex and index buffers [S1, unofficial].

3.  **Mesh Buffers:**
    *   `_MeshVertices`: `StructuredBuffer<float3>`, size $N_v$ (number of vertices) [S1, unofficial].
    *   `_MeshTriangleIndices`: `StructuredBuffer<int>`, size $N_t \times 3$ (number of triangles $\times$ 3) [S1, unofficial].

4.  **Grid Parameters:**
    *   `_GridWidth`, `_GridHeight`, `_GridDepth`: Integers defining the voxel count per axis [S1, unofficial].
    *   `_CellHalfSize`: Float, half the side length of a voxel (default 0.05f) [S1, unofficial].
    *   `_BoundsMin`: Float3, minimum corner of the voxel grid in world space [S1, unofficial].
    *   `_WorldToLocalMatrix`: Matrix, transforms world coordinates to local mesh coordinates [S1, unofficial].
    *   `_TriangleCount`: Integer, total number of triangles [S1, unofficial].

**Algorithm Steps:**

1.  **Grid Initialization:**
    Calculate grid dimensions from the mesh collider bounds and `_CellHalfSize` [S1, unofficial].
    $$ W = \lceil \text{bounds.extents.x} / \text{_CellHalfSize} \rceil $$
    $$ H = \lceil \text{bounds.extents.y} / \text{_CellHalfSize} \rceil $$
    $$ D = \lceil \text{bounds.extents.z} / \text{_CellHalfSize} \rceil $$
    Allocate `_voxelsBuffer` of size $W \times H \times D$ [S1, unofficial].

2.  **Buffer Upload:**
    Upload mesh vertices to `_MeshVertices` and indices to `_MeshTriangleIndices` [S1, unofficial].

3.  **Compute Dispatch:**
    Dispatch the `VoxelizeMesh` kernel with thread groups:
    $$ \text{Groups}_x = \lceil W / \text{GroupSize} \rceil, \quad \text{Groups}_y = \lceil H / \text{GroupSize} \rceil, \quad \text{Groups}_z = \lceil D / \text{GroupSize} \rceil $$
    [S1, unofficial].

4.  **Voxelization Kernel (`VoxelizeMesh`):**
    For each thread with global ID $(id.x, id.y, id.z)$:
    a.  **Bounds Check:** If $id.x \ge W$ or $id.y \ge H$ or $id.z \ge D$, return [S1, unofficial].
    b.  **Compute Cell Center:**
        $$ \text{cellSize} = \text{_CellHalfSize} \times 2.0 $$
        $$ \text{centerPos} = (id.x \times \text{cellSize} + \text{_CellHalfSize} + \text{_BoundsMin}.x, \dots) $$
        (Repeat for y and z components) [S1, unofficial].
    c.  **Initialize Solidity:** Set `isSolid = 0` [S1, unofficial].
    d.  **Triangle Iteration:** Iterate through all triangles $i$ from $0$ to `_TriangleCount` - 1 [S1, unofficial].
        i.  Fetch vertices $A, B, C$ from `_MeshVertices` using indices from `_MeshTriangleIndices` [S1, unofficial].
        ii. **SAT Broad-Phase:** Test if the voxel AABB (centered at `centerPos`, extents `_CellHalfSize`) intersects the triangle's AABB [S1, unofficial].
        iii. **Ray-Triangle Intersection:** If SAT passes, cast a ray from `centerPos` towards the triangle centroid [S1, unofficial]. If a hit is found, set `isSolid = 1` and break [S1, unofficial].
    e.  **Write Output:** Write the voxel to `_voxelsBuffer[id.z * W * H + id.y * W + id.x]` [S1, unofficial].

5.  **Fill Volume (Optional):**
    Dispatch a subsequent kernel to propagate solidity to neighboring empty voxels if a "filled" volume is required rather than a surface shell [S1, unofficial].

**Pseudocode:**

```python
EPSILON = 0.0000001

def dot(a, b):
    return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]

def cross(a, b):
    return (a[1]*b[2] - a[2]*b[1], a[2]*b[0] - a[0]*b[2], a[0]*b[1] - a[1]*b[0])

def ray_triangle_intersect(ray_origin, ray_direction, tri_a, tri_b, tri_c):
    ab = (tri_b[0]-tri_a[0], tri_b[1]-tri_a[1], tri_b[2]-tri_a[2])
    ac = (tri_c[0]-tri_a[0], tri_c[1]-tri_a[1], tri_c[2]-tri_a[2])
    h = cross(ray_direction, ac)
    a = dot(ab, h)
    if a > -EPSILON and a < EPSILON:
        return False
    f = 1.0 / a
    s = (ray_origin[0]-tri_a[0], ray_origin[1]-tri_a[1], ray_origin[2]-tri_a[2])
    u = f * dot(s, h)
    if u < 0.0 or u > 1.0:
        return False
    q = cross(s, ab)
    v = f * dot(ray_direction, q)
    if v < 0.0 or u + v > 1.0:
        return False
    t = f * dot(ac, q)
    if t <= EPSILON:
        return False
    return True

def sat_test(voxel_center, voxel_extents, tri_a, tri_b, tri_c):
    axes = [
        (1, 0, 0), (0, 1, 0), (0, 0, 1),
        cross((tri_b[0]-tri_a[0], tri_b[1]-tri_a[1], tri_b[2]-tri_a[2]),
              (tri_c[0]-tri_a[0], tri_c[1]-tri_a[1], tri_c[2]-tri_a[2]))
    ]
    for axis in axes:
        p0 = dot(tri_a, axis)
        p1 = dot(tri_b, axis)
        p2 = dot(tri_c, axis)
        maxP = max(p0, max(p1, p2))
        minP = min(p0, min(p1, p2))
        r = voxel_extents[0]*abs(axis[0]) + voxel_extents[1]*abs(axis[1]) + voxel_extents[2]*abs(axis[2])
        if max(-maxP, minP) > r:
            return False
    return True

def voxelize_mesh_kernel(id_x, id_y, id_z, grid_w, grid_h, grid_d, cell_half_size, bounds_min, mesh_vertices, mesh_indices, triangle_count, voxels_buffer):
    if id_x >= grid_w or id_y >= grid_h or id_z >= grid_d:
        return
    cell_size = cell_half_size * 2.0
    center_pos = (
        id_x * cell_size + cell_half_size + bounds_min[0],
        id_y * cell_size + cell_half_size + bounds_min[1],
        id_z * cell_size + cell_half_size + bounds_min[2]
    )
    is_solid = 0.0
    voxel_extents = (cell_half_size, cell_half_size, cell_half_size)
    for i in range(triangle_count):
        idx0 = mesh_indices[i * 3]
        idx1 = mesh_indices[i * 3 + 1]
        idx2 = mesh_indices[i * 3 + 2]
        tri_a = mesh_vertices[idx0]
        tri_b = mesh_vertices[idx1]
        tri_c = mesh_vertices[idx2]
        if not sat_test(center_pos, voxel_extents, tri_a, tri_b, tri_c):
            continue
        centroid = ((tri_a[0]+tri_b[0]+tri_c[0])/3.0, (tri_a[1]+tri_b[1]+tri_c[1])/3.0, (tri_a[2]+tri_b[2]+tri_c[2])/3.0)
        direction = (centroid[0]-center_pos[0], centroid[1]-center_pos[1], centroid[2]-center_pos[2])
        len_sq = direction[0]**2 + direction[1]**2 + direction[2]**2
        if len_sq > 0.0:
            len_sq_inv = 1.0 / (len_sq ** 0.5)
            direction = (direction[0]*len_sq_inv, direction[1]*len_sq_inv, direction[2]*len_sq_inv)
        else:
            direction = (0.0, 0.0, 1.0)
        if ray_triangle_intersect(center_pos, direction, tri_a, tri_b, tri_c):
            is_solid = 1.0
            break
    voxels_buffer[id_z * grid_w * grid_h + id_y * grid_w + id_x] = (center_pos, is_solid)
```

**Parameters:**
*   `_CellHalfSize`: Default 0.05f. Determines voxel resolution [S1, unofficial].
*   `_GridWidth`, `_GridHeight`, `_GridDepth`: Derived from mesh bounds and `_CellHalfSize` [S1, unofficial].
*   `_BoundsMin`: World-space minimum corner of the voxelization volume [S1, unofficial].
*   `_WorldToLocalMatrix`: Used if mesh vertices are in local space and need transformation to world space for intersection tests [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Ray Parallel to Triangle:** If the ray direction is parallel to the triangle plane, the denominator $a$ in Möller-Trumbore becomes zero. Handled by checking `if (a > -epsilon && a < epsilon) return false;` [S1, unofficial].
*   **Barycentric Coordinates:** If $u$ or $v$ are outside $[0, 1]$ or $u+v > 1$, the ray misses the triangle. Handled by explicit bounds checks [S1, unofficial].
*   **Back-facing/Degenerate Hits:** Hits with $t \le \epsilon$ are rejected to avoid self-intersection or degenerate cases. Handled by `return t > epsilon;` [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(V \times T)$, where $V$ is the total number of voxels ($W \times H \times D$) and $T$ is the number of triangles. Each voxel thread iterates over all triangles [S1, unofficial].
*   **Memory Complexity:** $O(V + V_{mesh} + T_{mesh})$, where $V$ is the voxel buffer size, $V_{mesh}$ is the vertex buffer size, and $T_{mesh}$ is the index buffer size [S1, unofficial].
*   **Performance:** Performance degrades linearly with grid resolution and triangle count. Suitable for real-time visualization of moderate-resolution grids on modern GPUs [S1, unofficial].
*   **Strengths:** Simple implementation, no complex data structures required, fully parallelizable [S1, unofficial].
*   **Limitations:** No spatial acceleration, leading to poor performance on dense meshes or high-resolution grids [S1, unofficial].

## Background
This method is implemented in the Unity engine using ComputeShaders and `Graphics.DrawProceduralIndirect` / `Graphics.DrawMeshInstancedIndirect` for visualization [S1, unofficial]. It is part of the "UnityGPUMeshVoxelizer" project series [S1, unofficial].
