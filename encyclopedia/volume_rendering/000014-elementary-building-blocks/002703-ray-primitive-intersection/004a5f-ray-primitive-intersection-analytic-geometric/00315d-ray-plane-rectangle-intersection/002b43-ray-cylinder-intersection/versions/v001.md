# Ray-Cylinder Intersection

Also called: Cylinder-Ray Intersection, Ray-Cylinder Hit Test

## Overview
Computes the entry and exit distances for a ray intersecting a cylinder defined by `geomSize`, composed of front/back rectangles, top/bottom faces, and a lateral curved surface. It differs from [Ray-box intersection](776-ray-box-intersection.md) by handling the curved lateral surface via quadratic solving, and from [Ray-Tetrahedron Intersection](2525-ray-tetrahedron-intersection.md) by supporting infinite or capped cylindrical geometry with specific axis-aligned caps.

## How it works
**Inputs:** Ray origin `rayOrig` (float3), ray direction `rayVect` (float3), cylinder geometry size `geomSize` (float3, where `x` is radius, `y` is height, `z` is depth/width in the source's coordinate system).
**Outputs:** Entry distance `inAbs`, exit distance `outAbs` (floats). Returns `true` if intersection exists.

**Data Structures:**
- `geomSize`: `float3` representing dimensions. `x` = radius, `y` = height, `z` = width/depth.
- `inAbsVal`, `outAbsVal`: `float`, initialized to 0.
- `inAbsFound`, `outAbsFound`: `bool`, initialized to `false`.

**Steps:**

1. **Initialize:** Set `inAbsVal = 0`, `outAbsVal = 0`, `inAbsFound = false`, `outAbsFound = false`.
2. **Front Rectangle:**
   - Define points: $P_0 = (0, 0, 0)$, $P_1 = (geomSize.x, 0, 0)$, $P_2 = (0, geomSize.z, 0)$.
   - Compute normal $n = (P_1 - P_0) \times (P_2 - P_0)$.
   - Compute $d = n \cdot rayVect$.
   - If $d \neq 0$:
     - Compute $s = \frac{n \cdot (P_0 - rayOrig)}{d}$.
     - Compute intersection point $P = rayOrig + s \cdot rayVect$.
     - Check bounds: $P.x \ge 0$ and $P.x \le geomSize.x$ and $P.y \ge 0$ and $P.y \le geomSize.z$.
     - If in bounds:
       - If $d > 0$: Update `outAbsVal` with $s$ (maximize if already found). Set `outAbsFound = true`.
       - If $d < 0$: Update `inAbsVal` with $s$ (minimize if already found). Set `inAbsFound = true`.
3. **Back Rectangle:**
   - Define $lastPoint = cylToCart(geomSize)$.
   - Define points: $P_0 = (lastPoint.x, 0, lastPoint.z)$, $P_1 = (0, 0, 0)$, $P_2 = (0, geomSize.z, 0)$.

   - Compute $d = n \cdot rayVect$.

     - Compute projected coordinate $x = \frac{P \cdot (P_0 - P_1)}{|P_0 - P_1|}$.
     - Check bounds: $x \ge 0$ and $x \le geomSize.x$ and $P.y \ge 0$ and $P.y \le geomSize.z$.
     - If in bounds:
       - If $d > 0$: Update `outAbsVal` with $s$. Set `outAbsFound = true`.
       - If $d < 0$: Update `inAbsVal` with $s$. Set `inAbsFound = true`.
4. **Top Face:**
   - Define $P_0 = (0, geomSize.z, 0)$, normal $n = (0, 1, 0)$.
   - Compute $d = n \cdot rayVect$.
   - If $d \neq 0$:
     - Compute $s = \frac{n \cdot (P_0 - rayOrig)}{d}$.
     - Compute $P = rayOrig + s \cdot rayVect$.
     - Convert $P$ to cylindrical coordinates $P_{cyl} = cartToCyl(P)$.
     - Check bounds: $P_{cyl}.x \le geomSize.x$ and $P_{cyl}.y \le geomSize.y$.
     - If in bounds:
       - If $d > 0$: Update `outAbsVal` with $s$. Set `outAbsFound = true`.
       - If $d < 0$: Update `inAbsVal` with $s$. Set `inAbsFound = true`.
5. **Bottom Face:**
   - Define $P_0 = (0, 0, 0)$, normal $n = (0, -1, 0)$.
   - Compute $d = n \cdot rayVect$.
   - If $d \neq 0$:
     - Compute $s = \frac{n \cdot (P_0 - rayOrig)}{d}$.
     - Compute $P = rayOrig + s \cdot rayVect$.
     - Convert $P$ to cylindrical coordinates $P_{cyl} = cartToCyl(P)$.
     - Check bounds: $P_{cyl}.x \le geomSize.x$ and $P_{cyl}.y \le geomSize.y$.
     - If in bounds:
       - If $d > 0$: Update `outAbsVal` with $s$. Set `outAbsFound = true`.
       - If $d < 0$: Update `inAbsVal` with $s$. Set `inAbsFound = true`.
6. **Lateral Face:**

**Parameters:**
- `geomType`: Character indicating geometry type. If `geomType == 'c'`, use this method [S1, unofficial].

**Edge Cases and Pitfalls:**
- Degenerate cases where only entry or only exit is found are handled by extending the intersection length by $2 \cdot radius / |rayVect|$ [S1, unofficial].
- Precision issues with quadratic solving for the lateral face.
- Boundary checks for rectangular faces use specific coordinate projections [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Constant time, involving a fixed number of plane intersections and one quadratic solve.
- **Memory Complexity:** Constant space.
- **Strengths:** Exact intersection for cylindrical primitives.
- **Limitations:** Specific to cylindrical geometry. Requires handling of multiple face types.
- **When to use:** When rendering or intersecting cylindrical volumes or primitives.
