# Infinite Plane Ray Intersection

Also called: Analytical ray-plane intersection, Infinite Ground Plane, InfinitePlan::rayIntersect, InfinitePlan::rayIntersectP, Matrix-Based Plane Intersection, Ray-Plane Intersection, planeIntr

## Overview
Computes the intersection of a ray with an infinite plane defined by a point and a normal, returning the intersection distance and point, or rejecting if the ray is parallel or outside the valid segment bounds [S2, S3, unofficial]. It is commonly used for ground planes kept separate from the scene's BVH [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input**: Ray origin $\mathbf{o}$, ray direction $\mathbf{d}$, plane point $\mathbf{P}$, plane normal $\mathbf{N}$, minimum distance $t_{min}$, maximum distance $t_{max}$ [S2, S3, unofficial].
*   **Output**: Boolean success flag, intersection distance $t$, intersection point $\mathbf{p}$, and plane normal $\mathbf{N}$ [S2, unofficial].

**Data Structures**
No complex data structures are required. The plane is defined by point $\mathbf{P}$ and normal $\mathbf{N}$ [S2, S3, unofficial]. The ray is defined by origin $\mathbf{o}$ and direction $\mathbf{d}$ [G].

**Steps**
1.  Compute the denominator $D = \mathbf{N} \cdot \mathbf{d}$ [S2, S3, unofficial].
2.  Check for parallelism: If $|D| < \epsilon$, the ray is parallel to the plane. Return failure [S2, S3, unofficial].
3.  Compute the intersection distance $t$:
    $$ t = \frac{\mathbf{N} \cdot (\mathbf{P} - \mathbf{o})}{\mathbf{N} \cdot \mathbf{d}} $$
    [S3, unofficial]
4.  Check bounds: If $t < t_{min}$ or $t > t_{max}$, the intersection is outside the valid ray segment. Return failure [S2, unofficial].
5.  Compute the intersection point:
    $$ \mathbf{p} = \mathbf{o} + t \mathbf{d} $$
    [S2, unofficial]
6.  Return success with $t$, $\mathbf{p}$, and $\mathbf{N}$ [S2, unofficial].

**Pseudocode**
```python
def dot(a, b):
    return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]

def intersect_infinite_plane(ray_o, ray_d, plane_p, plane_n, t_min, t_max, epsilon=1e-6):
    denominator = dot(plane_n, ray_d)
    if abs(denominator) < epsilon:
        return False, 0.0, (0.0, 0.0, 0.0)
    t = dot((plane_p[0]-ray_o[0], plane_p[1]-ray_o[1], plane_p[2]-ray_o[2]), plane_n) / denominator
    if t < t_min or t > t_max:
        return False, 0.0, (0.0, 0.0, 0.0)
    p = (ray_o[0] + t*ray_d[0], ray_o[1] + t*ray_d[1], ray_o[2] + t*ray_d[2])
    return True, t, p
```

**Parameters**
*   `epsilon`: Threshold for parallel ray/plane test. Value not specified in sources [S2, unofficial].

**Edge Cases and Pitfalls**
*   **Parallel Rays**: If the ray direction is perpendicular to the plane normal, the denominator is zero, causing division by zero. This must be checked to avoid invalid results [S2, S3, unofficial].

## Subtopics

### Bounded Plane Intersection
Intersects a ray with a finite plane segment [G]. It is distinct from the infinite plane method by requiring additional bounds tests to ensure the intersection point lies within the segment [G]. Choose it when the plane has finite extent [G]. See [Axis-Aligned Rectangle Hit Test](5279-axis-aligned-rectangle-hit-test.md).

### Infinite Ground Plane
A specific application of the infinite plane intersection used as a scene base [S1, unofficial]. It is distinct by being kept separate from the scene's BVH for performance [S1, unofficial]. Choose it for ground planes in path tracers [S1, unofficial]. See [Infinite Ground Plane](#).

## Operating characteristics
Time complexity: $O(1)$ constant time, requiring only a few dot products and a division [G]. Memory complexity: $O(1)$ constant space, requiring no additional data structures [G]. Measured performance with hardware, resolution, and scene: Not given in the sources. Scaling: Not given in the sources. Strengths: Extremely fast and simple to implement [G]. Limitations: Only works for infinite planes [G]. When to use: Ideal for ground planes or sky domes in path tracers [S1, unofficial]. When not to use: When the plane has finite bounds or when the scene contains many planes that can be efficiently accelerated with a BVH [G].

## Background
The analytical ray-plane intersection is a fundamental technique in computer graphics [G]. It is widely used in path tracers and real-time renderers for its simplicity and speed [G]. The infinite ground plane pattern is commonly used in offline renderers, where it is kept separate from the BVH for efficiency [S1, unofficial].
