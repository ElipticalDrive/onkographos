# Plane-Cube Intersection

Also called: Plane-Cube Intersection Volume, Volume from a plane slicing a cube

## Overview
This method computes the volume of the irregular polyhedron formed by the intersection of a plane and a cube [S1, unofficial]. It targets applications in computational astrophysics, such as determining the fraction of a cell that is partially ionized or covered by a burning front [S1, unofficial]. It extends the approach of Salama & Kolb (2005) by explicitly constructing an ordered list of face vertices to calculate the volume of the resulting inscribed irregular polyhedron [S1, unofficial].

## How it works
**Inputs and Outputs**
- **Inputs**: A unit cube defined by 8 vertices $\mathbf{V}_1$ through $\mathbf{V}_8$ [S1, unofficial]. A plane defined by a normal ray length $dl$ and spherical angles $\theta$ and $\phi$ [S1, unofficial].
- **Outputs**: The volume of the intersection polyhedron [S1, unofficial].

**Data Structures**
- **Vertices**: The cube vertices are enumerated and ordered as specified in the source figure [S1, unofficial]. The coordinates follow a standard unit cube layout [G].
- **Edges**: Defined by pairs of vertices $(\mathbf{V}_i, \mathbf{V}_j)$ [S1, unofficial].
- **Intersection Points**: A list of points $\mathbf{P}$ where the plane intersects the cube edges [S1, unofficial].

**Steps**
1. **Define the Plane**: Calculate the Cartesian coordinates of the normal ray $\mathbf{n}$ using the spherical angles [S1, unofficial]:
   $$ \mathbf{n} = [dl \cos(\theta), \ dl \sin(\theta)\sin(\phi), \ dl \cos(\phi) ] $$
   Compute the unit normal vector $\mathbf{\hat{n}} = \mathbf{n} / \|\mathbf{n}\|$ [G]. The plane equation is $dl = \mathbf{\hat{n}} \cdot \mathbf{x}$, where $\mathbf{x}$ is any point on the plane [S1, unofficial].
2. **Iterate Over Edges**: For each edge $E_{i \rightarrow j}$ connecting vertex $\mathbf{V}_i$ to $\mathbf{V}_j$, define the line segment $E_{i \rightarrow j} = \mathbf{V}_i + \lambda (\mathbf{V}_j - \mathbf{V}_i)$ [S1, unofficial]. Calculate the intersection parameter:
   $$ \lambda = \frac{ dl - \mathbf{\hat{n}} \cdot \mathbf{V}_i }{\mathbf{\hat{n}} \cdot (\mathbf{V}_j - \mathbf{V}_i ) } $$
   An intersection exists only if $0 \le \lambda \le 1$ [S1, unofficial]. If valid, compute the intersection point $\mathbf{P} = \mathbf{V}_i + \lambda (\mathbf{V}_j - \mathbf{V}_i)$ and store it [S1, unofficial].
3. **Construct Ordered List**: Build an ordered list of the face vertices for the polyhedron [S1, unofficial]. The specific ordering algorithm is not provided in the sources [Comment].
4. **Compute Volume**: Calculate the volume of the irregular polyhedron defined by the ordered vertices [S1, unofficial]. The specific volume formula is not provided in the sources [Comment].

**Parameters**
- $dl$: Length of the normal ray [S1, unofficial].
- $\theta$: Spherical angle, $0 \le \theta \le 2\pi$ [S1, unofficial].
- $\phi$: Spherical angle, $0 \le \phi \le \pi$ [S1, unofficial].

**Edge Cases and Pitfalls**
- **Degenerate Plane**: If $dl=0$, the normal vector $\mathbf{n}$ becomes a zero vector and $\mathbf{\hat{n}}$ is undefined [G].
- **Parallel Edges**: If $\mathbf{\hat{n}} \cdot (\mathbf{V}_j - \mathbf{V}_i) = 0$, the denominator is zero, indicating the edge is parallel to the plane [G].
- **Boundary Conditions**: The condition $0 \le \lambda \le 1$ ensures the intersection lies strictly within the cube edge [S1, unofficial].

**Pseudocode**
```python
import math

def plane_cube_intersection(dl, theta, phi, cube_vertices):
    # Step 1: Define the plane normal
    nx = dl * math.cos(theta)
    ny = dl * math.sin(theta) * math.sin(phi)
    nz = dl * math.cos(phi)
    
    norm_length = math.sqrt(nx**2 + ny**2 + nz**2)
    if norm_length == 0:
        raise ValueError("Normal vector is zero. dl=0 is degenerate.")
    
    n_hat_x = nx / norm_length
    n_hat_y = ny / norm_length
    n_hat_z = nz / norm_length
    
    # Step 2: Iterate over edges and find intersections
    intersection_points = []
    # Explicitly define the 12 edges of a unit cube as pairs of vertex indices
    edges = [
        (0, 1), (1, 2), (2, 3), (3, 0),
        (4, 5), (5, 6), (6, 7), (7, 4),
        (0, 4), (1, 5), (2, 6), (3, 7)
    ]
    
    for i, j in edges:
        V_i = cube_vertices[i]
        V_j = cube_vertices[j]
        
        dx = V_j[0] - V_i[0]
        dy = V_j[1] - V_i[1]
        dz = V_j[2] - V_i[2]
        
        denom = n_hat_x * dx + n_hat_y * dy + n_hat_z * dz
        
        if abs(denom) < 1e-9:
            continue # Edge is parallel to plane
        
        dot_Vi = n_hat_x * V_i[0] + n_hat_y * V_i[1] + n_hat_z * V_i[2]
        lambda_val = (dl - dot_Vi) / denom
        
        if 0 <= lambda_val <= 1:
            P_x = V_i[0] + lambda_val * dx
            P_y = V_i[1] + lambda_val * dy
            P_z = V_i[2] + lambda_val * dz
            intersection_points.append((P_x, P_y, P_z))
            
    # Step 3: Construct ordered list of vertices
    # Not given in the sources: ordering algorithm for vertices
    ordered_vertices = [] 
    
    # Step 4: Compute volume
    # Not given in the sources: volume calculation formula
    volume = 0.0
    
    return volume, intersection_points
```

## Operating characteristics
- **Time Complexity**: Constant, as the cube has a fixed number of 12 edges [S1, unofficial].
- **Memory Complexity**: Bounded, storing up to 6 intersection points and the resulting polyhedron vertices [S1, unofficial].
- **Strengths**: Provides an exact geometric solution for the intersection volume [S1, unofficial].
- **Limitations**: The number of vertices of the intersecting polygon varies between 3 and 6, creating complex patterns in the $\theta-\phi$ parameter space [S1, unofficial]. The source does not provide the vertex ordering or volume calculation algorithms [Comment].
