# Axis-Aligned Plane Intersection
## Overview
Intersects a ray with an axis-aligned plane defined by an anchor point, extent, and direction index `d` [S1, unofficial]. It returns the intersection distance `t` and barycentric-like coordinates `u, v` [S1, unofficial]. The method uses a direction index to permute coordinate axes, aligning the plane normal with a single axis to simplify the intersection calculation [S1, unofficial].

## How it works
**Inputs:**
- `ray`: Ray defined by origin `O` and direction `D` (3D vectors).
- `anchor`: Corner of the plane/rectangle (3D vector).
- `extent`: Size of the plane/rectangle along its local axes (3D vector).
- `d`: Integer direction index (0–5) selecting the plane orientation.
- `frame`: Context object providing `eye_near` (near clip distance `w` and origin `xyz`).

**Outputs:**
- `t`: Intersection distance along the ray.
- `u, v`: Local coordinates on the plane, normalized to `[0, 1]`.
- Boolean success flag.

**Data Structures:**
- Vectors are 3D floats.
- `d` is an integer index mapping to specific axis permutations.

**Steps:**
1. **Axis Permutation:** Select eye, origin, and ray components based on `d` to align the plane normal with the X-axis of the permuted space [S1, unofficial].
   - If `d < 2`: Use axes `(x, y, z)`.
   - If `2 <= d < 4`: Use axes `(y, x, z)`.
   - If `d >= 4`: Use axes `(z, x, y)`.
   Specifically: `eye = appearance_axes(frame.eye_near.xyz, d)`, `origin = appearance_axes(anchor, d)`, `delta = appearance_axes(ray, d)` [S1, unofficial].
2. **Plane Constant:** Compute the plane offset along the normal [S1, unofficial].
   $$ plane = origin.x + (1.0 \text{ if } (d \& 1) \text{ else } 0.0) $$
3. **Distance Numerator:**
   $$ distance = plane - eye.x $$
4. **Parallel Check:** If `delta.x` is zero, the ray is parallel to the plane. Return false [S1, unofficial].
5. **Intersection Distance:**
   $$ t = \frac{distance}{delta.x} $$
6. **Local Coordinates Numerator:** Compute unnormalized local coordinates using the Y and Z components of the permuted space [G].
   $$ uNumerator = eye.y + t \cdot delta.y - origin.y $$
   $$ vNumerator = eye.z + t \cdot delta.z - origin.z $$
7. **Normalization:**
   $$ u = \frac{uNumerator}{extent.x} $$
   $$ v = \frac{vNumerator}{extent.y} $$
   (Note: `extent.x` and `extent.y` refer to the U and V dimensions in the permuted coordinate space.)
8. **Validity Checks:** If `t` is NaN or Inf, or if `t < frame.eye_near.w` (near clip), return false [S1, unofficial].

**Pseudocode:**
```python
def axis_aligned_plane_intersection(ray_origin, ray_dir, anchor, extent, d, eye_near_w):
    import math
    
    # Permutation mapping based on d
    if d < 2:
        perm = (0, 1, 2)
    elif d < 4:
        perm = (1, 0, 2)
    else:
        perm = (2, 0, 1)
    
    # Extract components in permuted order
    eye_x = ray_origin[perm[0]]
    eye_y = ray_origin[perm[1]]
    eye_z = ray_origin[perm[2]]
    
    delta_x = ray_dir[perm[0]]
    delta_y = ray_dir[perm[1]]
    delta_z = ray_dir[perm[2]]
    
    origin_x = anchor[perm[0]]
    origin_y = anchor[perm[1]]
    origin_z = anchor[perm[2]]
    
    # Plane constant
    plane = origin_x + (1.0 if (d & 1) else 0.0)
    
    distance = plane - eye_x
    
    # Parallel check
    if delta_x == 0.0:
        return False, None, None
    
    t = distance / delta_x
    
    # Validity checks
    if math.isnan(t) or math.isinf(t) or t < eye_near_w:
        return False, None, None
    
    # Local coordinates
    uNumerator = eye_y + t * delta_y - origin_y
    vNumerator = eye_z + t * delta_z - origin_z
    
    # Normalize (extent.x and extent.y correspond to permuted U and V dimensions)
    u = uNumerator / extent[perm[1]]
    v = vNumerator / extent[perm[2]]
    
    return True, t, u, v
```

## Subtopics

### Voxel Cell Lookup
Determines the 3D integer voxel cell coordinate and the 3D intersection point given the ray intersection with an axis-aligned plane [S1, unofficial]. It builds on `axis_aligned_plane_intersection` [S1, unofficial].
1. Call `axis_aligned_plane_intersection` to get `t, u, v`. If it fails, return false [S1, unofficial].
2. Compute local coordinates in world units: `localU = u * extent.x`, `localV = v * extent.y` [S1, unofficial].
3. Compute cell offset: `offset = clamp(floor(vec2(localU, localV)), vec2(0.0), extent - 1.0)` [S1, unofficial].
4. Initialize cell with anchor: `cell = uvec3(anchor)` [S1, unofficial].
5. Add offset to cell based on direction `d`: if `d < 2`, add to `cell.y` and `cell.z`; if `2 <= d < 4`, add to `cell.x` and `cell.z`; if `d >= 4`, add to `cell.x` and `cell.y` [S1, unofficial].
6. Compute 3D point: `point = frame.eye_near.xyz + ray * t` [S1, unofficial].

## Operating characteristics
- **Time Complexity:** O(1). Fixed number of arithmetic operations and comparisons [G].
- **Memory Complexity:** O(1). No dynamic allocation [G].
- **Strengths:** Extremely fast; avoids branching on face normal by using a direction index; handles all 6 faces of an AABB uniformly [S1, unofficial].
- **Limitations:** Only works for axis-aligned planes; requires pre-computed direction index `d`; precision issues may occur if `t` is very large or `delta_x` is very small [G].
- **When to use:** Ray casting against voxel grids, AABBs, or any set of axis-aligned planes where the face index is known or easily derived [G].

## Background
Originated in the `bend-voxel` project [S1, unofficial]. The method leverages axis-aligned properties to simplify intersection tests, a common optimization in volume rendering and voxel-based rendering [G].
