# Inverse Transforming Spheres

Also called: Inverse Möbius Transformation of Spheres, Inverse Quaternion Möbius Transform for Spheres

## Overview
Inverse Transforming Spheres computes the coefficients $(\alpha', \beta', \gamma')$ of a sphere in kernel space given the coefficients $(\alpha, \beta, \gamma)$ of that sphere in world space after a quaternionic Möbius transformation [S1]. This allows a ray tracer to test if a world-space sphere intersects a kernel distance function by transforming the sphere into kernel space and performing a standard ray-sphere intersection [S1]. It differs from forward transformation by solving for the pre-image coefficients directly via algebraic expansion of the quaternionic Möbius map, avoiding iterative root-finding [S1].

## How it works
**Inputs and Outputs:**
- Inputs: Sphere coefficients in world space $\alpha \in \mathbb{R}$, $\beta \in \mathbb{H}_0$ (pure quaternion), $\gamma \in \mathbb{R}$, and Möbius transformation matrix coefficients $a, b, c, d \in \mathbb{H}$ [S1].
- Outputs: Sphere coefficients in kernel space $\alpha' \in \mathbb{R}$, $\beta' \in \mathbb{H}_0$, $\gamma' \in \mathbb{R}$ [S1].

**Data Structures:**
- Quaternions are represented as 4-component tuples $(w, x, y, z)$ [G].
- $\mathbb{H}_0$ denotes pure quaternions where the scalar part $w$ is zero [G].
- $\bar{q}$ denotes the quaternion conjugate $(w, -x, -y, -z)$ [G].
- $q\bar{q}$ denotes the squared norm $w^2+x^2+y^2+z^2$ [G].
- $\text{Re}(q)$ denotes the scalar part $w$ [G].

**Numbered Steps:**
1. Compute conjugates $\bar{a}, \bar{b}, \bar{c}, \bar{d}, \bar{\beta}$ [S1].
2. Compute scalar products $a\bar{a}$, $c\bar{c}$, $b\bar{b}$, and $d\bar{d}$ [S1].
3. Compute quaternion products $\bar{c}\beta a$, $\bar{b}a$, $\bar{d}\beta a$, $\bar{b}\bar{\beta}c$, $\bar{d}\bar{c}$, and $\bar{d}\beta b$ [S1].
4. Extract real parts of $\bar{c}\beta a$ and $\bar{d}\beta b$ [S1].
5. Assemble $\alpha'$, $\beta'$, and $\gamma'$ using the linear combinations of the computed terms [S1].

**Formulas:**
The implicit equation of a sphere or plane in quaternion space is:
$$ \alpha(q\bar{q}) + \beta q + \bar{q}\bar{\beta} + \gamma = 0 $$
where $q \in \mathbb{H}$ [S1]. For a sphere of radius $\rho$ centered at $\kappa$, the coefficients are $\alpha = 1$, $\beta = \kappa$, and $\gamma = |\kappa|^2 - \rho^2$ [S1]. The Möbius transformation is defined as $\mathcal{L}(q) = (aq+b)(cq+d)^{-1}$ [S1]. Substituting $\mathcal{L}(q)$ into the sphere equation and clearing denominators by multiplying by $(cq+d)$ from the left and $(cq+d)$ from the right yields the original sphere coefficients [S1]:
$$ \alpha' = \alpha a \bar{a} + 2 \text{Re}(\bar{c} \beta a) + \gamma \bar{c} c $$
$$ \beta' = \alpha \bar{b} a + \bar{d} \beta a + \bar{b} \bar{\beta} c + \gamma \bar{d} \bar{c} $$
$$ \gamma' = \alpha b \bar{b} + 2 \text{Re}(\bar{d} \beta b) + \gamma d \bar{d} $$ [S1].

**Parameters:**
Typical values are not given in the sources.

**Edge Cases and Pitfalls:**
- Numerical precision: Quaternion multiplication involves multiple floating-point operations, and accumulated error may affect the accuracy of the intersection test in kernel space [G].
- Pure quaternion constraint: $\beta$ and $\beta'$ must be pure quaternions (scalar part 0). Numerical errors might introduce a small scalar component in $\beta'$, which should be zeroed out [G].
- Boundaries and degenerate input: Not given in the sources.

**Pseudocode:**
```python
def inverse_transform_sphere(alpha, beta, gamma, a, b, c, d):
    """
    Computes the coefficients (alpha_prime, beta_prime, gamma_prime) of the 
    original sphere in kernel space, given world-space coefficients and 
    Möbius matrix elements a, b, c, d.
    
    Inputs:
    - alpha, gamma: float (real numbers)
    - beta: tuple (w, x, y, z) representing a pure quaternion (w=0)
    - a, b, c, d: tuple (w, x, y, z) representing quaternions
    
    Outputs:
    - alpha_prime: float
    - beta_prime: tuple (w, x, y, z) representing a pure quaternion
    - gamma_prime: float
    """
    
    # Helper: Quaternion conjugate
    def conj(q):
        return (q[0], -q[1], -q[2], -q[3])
    
    # Helper: Quaternion multiplication
    def qmul(q1, q2):
        w1, x1, y1, z1 = q1
        w2, x2, y2, z2 = q2
        return (
            w1*w2 - x1*x2 - y1*y2 - z1*z2,
            w1*x2 + x1*w2 + y1*z2 - z1*y2,
            w1*y2 - x1*z2 + y1*w2 + z1*x2,
            w1*z2 + x1*y2 - y1*x2 + z1*w2
        )
    
    # Helper: Real part of quaternion
    def re(q):
        return q[0]
    
    # Helper: Scalar multiplication of quaternion
    def smul(s, q):
        return (s * q[0], s * q[1], s * q[2], s * q[3])
    
    # Helper: Add two quaternions
    def qadd(q1, q2):
        return (q1[0]+q2[0], q1[1]+q2[1], q1[2]+q2[2], q1[3]+q2[3])
    
    # Conjugates
    a_bar = conj(a)
    b_bar = conj(b)
    c_bar = conj(c)
    d_bar = conj(d)
    beta_bar = conj(beta)
    
    # Calculate alpha'
    # alpha' = alpha * a * a_bar + 2 * Re(c_bar * beta * a) + gamma * c_bar * c
    scalar_aa = qmul(a, a_bar)[0]
    term2_alpha_q = qmul(c_bar, qmul(beta, a))
    scalar_cc = qmul(c_bar, c)[0]
    alpha_prime = alpha * scalar_aa + 2 * re(term2_alpha_q) + gamma * scalar_cc
    
    # Calculate beta'
    # beta' = alpha * b_bar * a + d_bar * beta * a + b_bar * beta_bar * c + gamma * d_bar * c_bar
    term1_beta = smul(alpha, qmul(b_bar, a))
    term2_beta = qmul(d_bar, qmul(beta, a))
    term3_beta = qmul(b_bar, qmul(beta_bar, c))
    term4_beta = smul(gamma, qmul(d_bar, c_bar))
    beta_prime = qadd(qadd(qadd(term1_beta, term2_beta), term3_beta), term4_beta)
    
    # Calculate gamma'
    # gamma' = alpha * b * b_bar + 2 * Re(d_bar * beta * b) + gamma * d * d_bar
    scalar_bb = qmul(b, b_bar)[0]
    term2_gamma_q = qmul(d_bar, qmul(beta, b))
    scalar_dd = qmul(d, d_bar)[0]
    gamma_prime = alpha * scalar_bb + 2 * re(term2_gamma_q) + gamma * scalar_dd
    
    return alpha_prime, beta_prime, gamma_prime
```

## Operating characteristics
- Time Complexity: Constant time $O(1)$ per sphere, involving a fixed number of quaternion multiplications and additions [G].
- Memory Complexity: $O(1)$ auxiliary space [G].
- Strengths: Exact algebraic solution; no iterative approximation; enables efficient culling of spheres against kernel distance functions [S1].
- Limitations: Requires the Möbius transformation to be invertible; only applicable to spheres/planes; quaternion arithmetic is more expensive than standard 3D vector math [G].
- When to use: When rendering Kernel-Reflection Sequences (KRS) or other conformally transformed implicit surfaces where spheres need to be tested against the kernel [S1].
- When not to use: For non-spherical primitives or when the transformation is not a Möbius transformation [G].

## Background
The method originates from the work on Kernel-Reflection Sequences (KRS) [S1]. It was introduced to allow efficient ray tracing of complex natural scenes by conformally distorting expansion levels [S1]. The technique leverages the properties of quaternionic Möbius transformations to map spheres in world space to spheres (or planes) in kernel space, enabling the use of standard ray-sphere intersection algorithms [S1].
