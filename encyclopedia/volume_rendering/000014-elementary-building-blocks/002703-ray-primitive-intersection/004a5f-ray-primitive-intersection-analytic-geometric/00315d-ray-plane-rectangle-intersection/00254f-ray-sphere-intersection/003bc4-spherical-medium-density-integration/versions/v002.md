# Spherical Medium Density Integration

Also called: Quadratic Spherical Density, Spherical Density Integration

## Overview
Spherical Medium Density Integration computes the optical depth along a ray segment passing through a sphere where density decreases quadratically from the center to the edge [S1, unofficial]. It solves the problem of analytically integrating a spatially varying density function within a spherical volume, avoiding numerical sampling [G]. It differs from its parent [Ray-Sphere Intersection](3539-ray-sphere-intersection.md) by providing the accumulated density value rather than just geometric hit points, and from siblings like [Ray-Splat Intersection](7123-ray-splat-intersection-sphere-approximation.md) by using an exact quadratic falloff rather than a Gaussian or constant approximation [G].

## How it works
**Inputs:** Ray origin $\mathbf{c} \in \mathbb{R}^3$, ray direction $\boldsymbol{\omega} \in \mathbb{R}^3$ (normalized), ray maximum distance $D > 0$, sphere center $\mathbf{o} \in \mathbb{R}^3$, sphere radius $R > 0$, density factor $\varrho' \ge 0$ [S1, unofficial].

**Outputs:** Integrated density (optical depth) $P(\mathbf{x}_{2D})$ [S1, unofficial].

**Data Structures:** No complex structures are required; the method relies on scalar arithmetic and vector dot products [G].

**Steps:**
1. **Compute Intersection Parameters:** Calculate $B = \langle \boldsymbol{\omega}, \mathbf{c} - \mathbf{o} \rangle$ and $C = \|\mathbf{c} - \mathbf{o}\|^2 - R^2$ [S1, unofficial]. Calculate discriminant $\Delta = B^2 - C$. If $\Delta < 0$, the ray does not intersect the sphere; return $P = 0$ [S1, unofficial]. Calculate bounds $t_1 = \max(0, -B - \sqrt{\Delta})$ and $t_2 = \min(D, -B + \sqrt{\Delta})$ [S1, unofficial]. If $t_1 \ge t_2$, the ray misses the sphere or is tangent; return $P = 0$ [G].
2. **Integrate Density:** The density function is $\varrho(\mathbf{x}') = \varrho' \cdot (1 - \|\mathbf{x}' - \mathbf{o}\|^2/R^2)$ if $\|\mathbf{x}' - \mathbf{o}\| \leq R$, else $0$ [S1, unofficial]. The integrated density is $P(\mathbf{x}_{2D}) = -\varrho' \cdot R^{-2} \cdot \left( \frac{t_2^3 - t_1^3}{3} + B(t_2^2 - t_1^2) + C(t_2 - t_1) \right)$ [S1, unofficial].

**Pseudocode:**
```python
def spherical_medium_density_integration(c, omega, D, o, R, rho_prime):
    # Vector subtraction: c - o
    diff = [c[i] - o[i] for i in range(3)]
    
    # B = <omega, c - o>
    B = omega[0]*diff[0] + omega[1]*diff[1] + omega[2]*diff[2]
    
    # C = ||c - o||^2 - R^2
    C = diff[0]**2 + diff[1]**2 + diff[2]**2 - R**2
    
    # Discriminant
    delta = B**2 - C
    
    # No intersection
    if delta < 0:
        return 0.0
    
    sqrt_delta = delta**0.5
    
    # Intersection bounds
    t1 = max(0.0, -B - sqrt_delta)
    t2 = min(D, -B + sqrt_delta)
    
    # No valid segment inside sphere
    if t1 >= t2:
        return 0.0
    
    # Integrate density
    term1 = (t2**3 - t1**3) / 3.0
    term2 = B * (t2**2 - t1**2)
    term3 = C * (t2 - t1)
    
    P = -rho_prime * (1.0 / (R**2)) * (term1 + term2 + term3)
    
    return P
```

**Parameters:** $R$: Radius of the sphere. Must be $> 0$ [S1, unofficial]. $\mathbf{o}$: Center of the sphere [S1, unofficial]. $\varrho'$: Density factor. Must be $\ge 0$ [S1, unofficial].

**Edge Cases and Pitfalls:** Precision: Clamp $\Delta$ to $0$ if slightly negative (e.g., $< -10^{-9}$) to avoid domain errors in square root [G]. Boundary: The formula assumes the ray segment is clipped to $[0, D]$; if the sphere is entirely behind the camera ($t_2 < 0$), $t_1 = \max(0, \dots)$ handles it correctly [G]. Sign Consistency: $B$ must be defined as $\langle \boldsymbol{\omega}, \mathbf{c} - \mathbf{o} \rangle$ consistently in both intersection and integration steps [S1, unofficial].

## Subtopics

### Soft White Sphere Density
A variant where the density function is $\rho(x) = \frac{1 - r^2}{|x|^2}$ if $1 - r^2 > 0$, else $0$, where $r = |x|$ is the distance from the center [S2, unofficial]. This creates a sphere with soft edges where density tapers at the edges [S2, unofficial]. The color is constant white $\mathbf{c}(x) = (1, 1, 1)$ [S2, unofficial].

## Operating characteristics
**Time Complexity:** $O(1)$; the method involves a constant number of arithmetic operations (dot products, square root, polynomial evaluation) [G].
**Memory Complexity:** $O(1)$; no additional memory is allocated [G].
**Performance:** Significantly faster than numerical integration (e.g., quadrature) or ray marching, as it provides an exact analytical solution [G].
**Strengths:** Exact result; no aliasing artifacts from sampling; efficient for real-time rendering [G].
**Limitations:** Only applicable to spherical volumes with quadratic density falloff; cannot handle complex shapes or non-quadratic density functions [G].
**When to use:** When rendering participating media confined to spherical volumes with smooth, quadratic density gradients [G].
**When not to use:** For non-spherical volumes, or when the density function does not match the quadratic model [G].

## Background
The method derives from the analytical integration of participating media for spherical volumes with quadratic density falloff, originally derived by Quílez [2015] [S1, unofficial]. It appears in Tomás Ize's thesis "Real-Time Light Transport in Analytically Integrable Participating Media" (2015) [S1, unofficial]. The "Soft White Sphere" variant appears in production volume rendering contexts, such as Clemson University's production volume rendering reports [S2, unofficial].
