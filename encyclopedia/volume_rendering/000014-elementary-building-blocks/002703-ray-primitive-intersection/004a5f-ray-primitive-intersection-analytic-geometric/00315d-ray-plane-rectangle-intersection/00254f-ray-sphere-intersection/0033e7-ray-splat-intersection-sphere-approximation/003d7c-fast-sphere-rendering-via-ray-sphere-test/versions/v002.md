# Fast Sphere Rendering via Ray-Sphere Test
Also called: Projected sphere rendering
## Overview
A method to render spheres using only their radii and centers, avoiding polygon tessellation [S1]. It renders a rectangular region tightly fitting the perspective-projected sphere on the screen and performs a ray-sphere intersection test in the fragment shader [S1].
## How it works
**Inputs and Outputs:**
- Input: Sphere center $\mathbf{c}$, sphere radius $r$, viewing ray origin $\mathbf{o}$, viewing ray direction $\mathbf{d}$, and the previous intersection parameter $t_{\text{prev}}$ from the depth peeling pass [S1].
- Output: Fragment color or depth; the fragment is discarded if no valid intersection exists [S1].

**Data Structures:**
- Not given in the sources [S1].

**Steps:**
1. In the vertex shader, specify the rectangular region that tightly fits the perspective-projected sphere on the screen [S1].
2. For each fragment in this region, perform an intersection test for the viewing ray and the sphere in the fragment shader [S1].
3. Discard the fragment if there is no intersection [S1].
4. Render only the front or back face of the sphere, whichever is farther away from the previous intersection point, as depth peeling does not require both [S1].

**Formulas:**
- Ray-sphere intersection: Given ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ and sphere center $\mathbf{c}$ with radius $r$, solve for $t$ in $|\mathbf{o} + t\mathbf{d} - \mathbf{c}|^2 = r^2$ [S1].

**Pseudocode:**
```python
def ray_sphere_test(ray_origin, ray_direction, sphere_center, sphere_radius, prev_t):
    oc = ray_origin - sphere_center
    a = dot(ray_direction, ray_direction)
    b = 2.0 * dot(oc, ray_direction)
    c = dot(oc, oc) - sphere_radius * sphere_radius
    discriminant = b * b - 4 * a * c

    if discriminant < 0:
        return None  # Discard fragment

    sqrt_disc = sqrt(discriminant)
    t1 = (-b - sqrt_disc) / (2 * a)
    t2 = (-b + sqrt_disc) / (2 * a)

    # Select the face farther from the previous intersection point
    candidates = []
    if t1 > prev_t:
        candidates.append(t1)
    if t2 > prev_t:
        candidates.append(t2)

    if not candidates:
        return None  # Discard fragment

    return max(candidates)
```
