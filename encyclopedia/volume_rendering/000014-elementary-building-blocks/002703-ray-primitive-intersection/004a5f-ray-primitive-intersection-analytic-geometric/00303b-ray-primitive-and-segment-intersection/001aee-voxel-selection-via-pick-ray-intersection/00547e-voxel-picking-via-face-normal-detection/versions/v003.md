# Voxel Picking via Face Normal Detection

Also called: CEWBS handlePick, Voxel Face Picking, handlePick, raycast voxel coordinate extraction

## Overview
This method determines the voxel coordinates intersected by a pick ray by transforming the intersection point into the mesh's local space and identifying the hit face based on which axis has a zero fractional offset [S1, unofficial]. It builds on [Voxel selection via pick ray intersection](893-voxel-selection-via-pick-ray-intersection.md) to resolve the exact voxel index from a continuous raycast hit [S1, unofficial]. Unlike [Reverse Index Map for Voxel Location](1097-reverse-index-map-for-voxel-location.md) which uses spatial hashing, or [BrushController](2362-brushcontroller.md) which manages brush volumes, this method relies on geometric face detection [S1, unofficial]. It differs from [Ray-Box Intersection for Interaction](2638-ray-box-intersection-for-interaction.md) by explicitly using the fractional part of the local coordinates to determine surface orientation rather than just entering/exiting the volume [S1, unofficial].

## How it works
**Inputs:**
- `point`: The 3D intersection point in world space, returned by the raycasting engine [S1, unofficial].
- `mesh`: The voxel mesh object containing the world matrix and voxel data [S1, unofficial].
- `dimensions`: An array `[dimX, dimY, dimZ]` representing the voxel grid size [S1, unofficial].

**Outputs:**
- `pickResult`: An object containing:
  - `over`: The coordinates `[x, y, z]` of the surface voxel (the one hit by the ray) [S1, unofficial].
  - `under`: The coordinates `[x, y, z]` of the adjacent subsurface voxel (inward along the hit normal) [S1, unofficial].

**Data Structures:**
- `dimensions`: Array of 3 integers [S1, unofficial].
- `voxelData`: Object containing `dimensions` and a flat array `voxels` of size `dimX * dimY * dimZ` [S1, unofficial].
- `pickResult`: Object with `over` and `under` fields, each being an array of 3 integers [S1, unofficial].

**Steps:**

1.  **Transform to Local Space**:
    Compute the inverse of the mesh's world matrix [S1, unofficial]. Transform the world-space intersection `point` into local space to get `v` [S1, unofficial].
    $$ v = M_{world}^{-1} \cdot point $$

2.  **Compute Fractional Offsets**:
    Calculate the fractional part of each coordinate in `v` [S1, unofficial]. To handle floating-point precision errors near voxel boundaries, snap near-zero values to exactly 0 by rounding to 4 decimal places [S1, unofficial].
    $$ offsetX = \text{round}(v_x - \text{round}(v_x), 4) $$
    $$ offsetY = \text{round}(v_y - \text{round}(v_y), 4) $$
    $$ offsetZ = \text{round}(v_z - \text{round}(v_z), 4) $$

3.  **Identify Hit Face**:
    Determine which axis corresponds to the hit face by checking which offset is exactly zero [S1, unofficial].
    - If $offsetX = 0$, the ray intersects an X-face [S1, unofficial].
    - If $offsetY = 0$, the ray intersects a Y-face [S1, unofficial].
    - If $offsetZ = 0$, the ray intersects a Z-face [S1, unofficial].

4.  **Compute Voxel Indices**:
    Based on the hit face, compute the integer voxel coordinates $[x, y, z]$ [S1, unofficial].
    - **X-face hit**:
      $$ x = \text{round}(v_x) $$
      $$ y = \lfloor v_y \rfloor $$
      $$ z = \lfloor v_z \rfloor $$
    - **Y-face hit**:
      $$ x = \lfloor v_x \rfloor $$
      $$ y = \text{round}(v_y) $$
      $$ z = \lfloor v_z \rfloor $$
    - **Z-face hit**:
      $$ x = \lfloor v_x \rfloor $$
      $$ y = \lfloor v_y \rfloor $$
      $$ z = \text{round}(v_z) $$

5.  **Clamp Indices**:
    Ensure the computed indices are within the valid range $[0, dimensions[i]-1]$ [S1, unofficial]. If a rounded index equals the dimension size, clamp it to `dimensions[i] - 1` [S1, unofficial].
    - If $x \ge dimX$, set $x = dimX - 1$.
    - If $y \ge dimY$, set $y = dimY - 1$.
    - If $z \ge dimZ$, set $z = dimZ - 1$.

6.  **Determine Surface and Subsurface Voxels**:
    Define `voxel1` as the computed coordinates $[x, y, z]$ [S1, unofficial]. Define `voxel2` as the adjacent voxel inward along the hit axis (e.g., $[x-1, y, z]$ for an X-face hit) [S1, unofficial].

7.  **Query Voxel Existence**:
    Check if `voxel1` contains a voxel using `mesh.getVoxelAt(voxel1)` [S1, unofficial].
    - If `voxel1` is empty (null/false):
      - `pickResult.over` = `voxel1`
      - `pickResult.under` = `voxel2`
    - If `voxel1` is occupied:
      - `pickResult.over` = `voxel2`
      - `pickResult.under` = `voxel1`

**Pseudocode:**

```python
import math

def transform_vector(v, m):
    # [G] Standard affine transformation for a 4x4 column-major matrix
    return [sum(m[i*4+j]*v[j] for j in range(3)) + m[i*4+3] for i in range(3)]

def voxel_picking_face_normal(point, mesh, dimensions):
    # 1. Transform to local space
    inv_matrix = mesh.get_world_matrix_inverse()
    v = transform_vector(point, inv_matrix)
    vx, vy, vz = v
    
    # 2. Compute fractional offsets with precision snapping
    offset_x = round(vx - round(vx), 4)
    offset_y = round(vy - round(vy), 4)
    offset_z = round(vz - round(vz), 4)
    
    # 3 & 4. Identify hit face and compute indices
    x, y, z = 0, 0, 0
    hit_axis = None
    
    if offset_x == 0:
        hit_axis = 'X'
        x = round(vx)
        y = math.floor(vy)
        z = math.floor(vz)
    elif offset_y == 0:
        hit_axis = 'Y'
        x = math.floor(vx)
        y = round(vy)
        z = math.floor(vz)
    elif offset_z == 0:
        hit_axis = 'Z'
        x = math.floor(vx)
        y = math.floor(vy)
        z = round(vz)
    else:
        # Not handled in the source
        return None
        
    # 5. Clamp indices
    dim_x, dim_y, dim_z = dimensions
    if x >= dim_x: x = dim_x - 1
    if y >= dim_y: y = dim_y - 1
    if z >= dim_z: z = dim_z - 1
        
    # 6. Determine surface and subsurface voxels
    voxel1 = [x, y, z]
    if hit_axis == 'X': voxel2 = [x - 1, y, z]
    elif hit_axis == 'Y': voxel2 = [x, y - 1, z]
    elif hit_axis == 'Z': voxel2 = [x, y, z - 1]
        
    # 7. Query voxel existence
    voxel_at_1 = mesh.get_voxel_at(voxel1)
    if voxel_at_1 is None or not voxel_at_1:
        return {'over': voxel1, 'under': voxel2}
    else:
        return {'over': voxel2, 'under': voxel1}
```

**Parameters:**
- Precision threshold: 4 decimal places (hardcoded in source via `.toFixed(4)`) [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Floating-point precision**: Coordinates very close to voxel boundaries may result in non-zero fractional offsets due to rounding errors. The use of `.toFixed(4)` (or equivalent rounding) snaps these near-zero values to exactly 0, ensuring correct face detection [S1, unofficial].
- **Boundary Clamping**: `Math.round` can push a coordinate exactly on a boundary to the next voxel index. If this index equals the dimension size, it would cause an out-of-bounds access. Clamping prevents this [S1, unofficial].
- **Degenerate Input**: If the ray does not hit a face (e.g., passes through a corner or edge where multiple offsets are near zero), the logic may fail to identify a unique hit axis. The source does not specify behavior for this case [S1, unofficial].
