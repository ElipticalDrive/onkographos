# 3D Ring Visibility & Occlusion Test

Also called: ring depth test, ring raster validation

## Overview
The 3D Ring Visibility & Occlusion Test is a screen-space rasterization technique that projects 3D ring boundary segments to screen space, computes depth via inverse-linear interpolation, and validates visibility against a voxel depth buffer [S1, unofficial]. It differs from sibling methods like [Change of Integration Variable for Boundary Segments](8107-change-of-integration-variable-for-boundary-segments.md) by operating in screen space using rasterization primitives rather than analytical integration in world space [S1, unofficial].

## How it works
**Inputs:** Ring center $\mathbf{c}$, eye position $\mathbf{e}$, radius $r$, near plane distance $n$, focal length $f$, screen width $w$, screen height $h$, camera basis vectors $\mathbf{right}, \mathbf{up}, \mathbf{forward}$, and a voxel depth buffer [S1, unofficial].
**Outputs:** Updated voxel masks (`support`, `visible`, `definite`, `possible`, `edge`, `contact`) [S1, unofficial].
**Data Structures:** The ring is discretized into 3 orientations (indices 0..2) and 32 sub-segments per orientation (indices 0..31) [S1, unofficial]. Each sub-segment connects two consecutive angular positions [G].

**Steps:**
1. Iterate ring index $k \in \{0, 1, 2\}$ and segment index $i \in \{0, \dots, 31\}$ [S1, unofficial].
2. Compute angle $\theta = i \times 0.1963495408$ [S1, unofficial].
3. Compute displacement vectors $\mathbf{\delta}_1$ and $\mathbf{\delta}_2$ for angles $\theta$ and $\theta + 0.1963495408$ using the ring-specific layout: $(c, s, 0)$, $(c, 0, s)$, or $(0, c, s)$ where $c = r \cos(\theta)$, $s = r \sin(\theta)$ [S1, unofficial].
4. Compute world direction vectors $\mathbf{d}_1 = \mathbf{c} + \mathbf{\delta}_1 - \mathbf{e}$ and $\mathbf{d}_2 = \mathbf{c} + \mathbf{\delta}_2 - \mathbf{e}$ [S1, unofficial].
5. Project to camera space: $\mathbf{a} = [\mathbf{d}_1 \cdot \mathbf{right}, \mathbf{d}_1 \cdot \mathbf{up}, \mathbf{d}_1 \cdot \mathbf{forward}]$ and $\mathbf{b} = [\mathbf{d}_2 \cdot \mathbf{right}, \mathbf{d}_2 \cdot \mathbf{up}, \mathbf{d}_2 \cdot \mathbf{forward}]$ [S1, unofficial].
6. If $\max(a_z, b_z) < n$, skip the segment [S1, unofficial].
7. If $\min(a_z, b_z) < n$, clip the segment to the near plane by interpolating the cut point [S1, unofficial].
8. Project endpoints to screen coordinates: $p_x = \frac{w}{2} + f \frac{a_x}{a_z}$, $p_y = \frac{h}{2} - f \frac{a_y}{a_z}$ (and similarly for $q$ from $\mathbf{b}$) [S1, unofficial].
9. Compute bounding box $[x_{\min}, x_{\max}] \times [y_{\min}, y_{\max}]$ covering the segment [S1, unofficial].
10. For each pixel $(xx, yy)$ in the bounding box:
    - Compute screen-space delta $\Delta = (q_x - p_x, q_y - p_y)$ and squared length $L^2 = \Delta_x^2 + \Delta_y^2$ [S1, unofficial].
    - If $L^2 < 10^{-6}$, skip the pixel [S1, unofficial].
    - Compute projection parameter $t = \text{clip}\left( \frac{(xx + 0.5 - p_x)\Delta_x + (yy + 0.5 - p_y)\Delta_y}{L^2}, 0, 1 \right)$ [S1, unofficial].
    - Compute 2D distance from pixel center to the segment [G].
    - If distance $\le 0.75$, mark as `stroke` [S1, unofficial].
11. Compute depth $z$ at parameter $t$ using inverse-linear interpolation: $z = \frac{1}{\frac{1}{a_z} + t \left(\frac{1}{b_z} - \frac{1}{a_z}\right)}$ [S1, unofficial].
12. Compute normalized depth: $\text{depth} = 1 - \frac{n}{\max(n, z - 0.0001)}$ [S1, unofficial].
13. Update voxel masks based on `stroke` status and computed depth [S1, unofficial].

**Pseudocode:**
```python
import math

def ring_visibility_test(center, eye, radius, near, focal, width, height, right, up, forward):
    angle_step = 0.1963495408
    epsilon = 0.0001
    
    for ring_idx in range(3):
        for seg_idx in range(32):
            angle = seg_idx * angle_step
            c1 = radius * math.cos(angle)
            s1 = radius * math.sin(angle)
            c2 = radius * math.cos(angle + angle_step)
            s2 = radius * math.sin(angle + angle_step)
            
            if ring_idx == 0:
                delta1 = (c1, s1, 0)
                delta2 = (c2, s2, 0)
            elif ring_idx == 1:
                delta1 = (c1, 0, s1)
                delta2 = (c2, 0, s2)
            else:
                delta1 = (0, c1, s1)
                delta2 = (0, c2, s2)
            
            d1 = (center[0] + delta1[0] - eye[0], center[1] + delta1[1] - eye[1], center[2] + delta1[2] - eye[2])
            d2 = (center[0] + delta2[0] - eye[0], center[1] + delta2[1] - eye[1], center[2] + delta2[2] - eye[2])
            
            a = (d1[0]*right[0] + d1[1]*right[1] + d1[2]*right[2],
                 d1[0]*up[0] + d1[1]*up[1] + d1[2]*up[2],
                 d1[0]*forward[0] + d1[1]*forward[1] + d1[2]*forward[2])
            b = (d2[0]*right[0] + d2[1]*right[1] + d2[2]*right[2],
                 d2[0]*up[0] + d2[1]*up[1] + d2[2]*up[2],
                 d2[0]*forward[0] + d2[1]*forward[1] + d2[2]*forward[2])
            
            if max(a[2], b[2]) < near:
                continue
            if min(a[2], b[2]) < near:
                t_clip = (near - a[2]) / (b[2] - a[2])
                a = (a[0] + t_clip * (b[0] - a[0]), a[1] + t_clip * (b[1] - a[1]), near)
            
            px = width / 2.0 + focal * a[0] / a[2]
            py = height / 2.0 - focal * a[1] / a[2]
            qx = width / 2.0 + focal * b[0] / b[2]
            qy = height / 2.0 - focal * b[1] / b[2]
            
            x_min, x_max = int(math.floor(min(px, qx))), int(math.ceil(max(px, qx)))
            y_min, y_max = int(math.floor(min(py, qy))), int(math.ceil(max(py, qy)))
            
            dx = qx - px
            dy = qy - py
            squared = dx * dx + dy * dy
            if squared < 1e-6:
                continue
                
            for xx in range(x_min, x_max + 1):
                for yy in range(y_min, y_max + 1):
                    t = max(0.0, min(1.0, ((xx + 0.5 - px) * dx + (yy + 0.5 - py) * dy) / squared))
                    proj_x = px + t * dx
                    proj_y = py + t * dy
                    dist = math.sqrt((xx + 0.5 - proj_x)**2 + (yy + 0.5 - proj_y)**2)
                    if dist <= 0.75:
                        z = 1.0 / (1.0 / a[2] + t * (1.0 / b[2] - 1.0 / a[2]))
                        depth = 1.0 - near / max(near, z - epsilon)
                        # Update masks (support, visible, definite, possible, edge, contact) based on depth and stroke status [G]
```

**Pitfalls:** Degenerate segments (squared length $< 10^{-6}$) are skipped. Near clipping is handled by checking min/max $z$ against the near plane and interpolating the cut point. Division by zero in depth calculation is avoided by $\max(\text{near}, \dots)$ [S1, unofficial].
