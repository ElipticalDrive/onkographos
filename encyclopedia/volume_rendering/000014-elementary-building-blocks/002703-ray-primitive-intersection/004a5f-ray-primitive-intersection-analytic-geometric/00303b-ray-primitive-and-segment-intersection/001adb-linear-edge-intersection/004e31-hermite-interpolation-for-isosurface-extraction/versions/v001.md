# Hermite Interpolation for Isosurface Extraction

Also called: Hermite contouring, Hermite interpolation

## Overview
Hermite interpolation for isosurface extraction determines the precise position of an isovertex along an edge where the scalar field value equals a specific threshold, utilizing both function values and gradients (Hermite data) to perform higher-order interpolation. It solves the problem of reconstruction artifacts caused by non-linear implicit functions, which linear interpolation (as used in [Linear Edge Intersection](868-linear-edge-intersection.md)) fails to capture accurately. By incorporating gradient information, it provides a more accurate isosurface representation for implicit functions that are not piecewise linear.

## How it works

### Inputs and Outputs
**Inputs:**
- Two edge endpoints: $\mathbf{x}_0$ and $\mathbf{x}_1$.
- Scalar field values at endpoints: $v_0 = F(\mathbf{x}_0)$ and $v_1 = F(\mathbf{x}_1)$.
- Gradient vectors at endpoints: $\nabla F_0 = \nabla F(\mathbf{x}_0)$ and $\nabla F_1 = \nabla F(\mathbf{x}_1)$.
- Target isovalue (typically 0 for zero-crossing edges).

**Outputs:**
- The normalized parameter $t \in [0, 1]$ representing the isovertex position along the edge.

### Data Structures
No complex data structures are required beyond the scalar values and vectors provided by the parent method or grid sampling. The core computation relies on solving polynomial equations.

### Steps

1.  **Calculate Directional Derivatives:**
    Compute the directional derivative of the implicit function along the edge direction at each endpoint. Let $\mathbf{e} = \mathbf{x}_1 - \mathbf{x}_0$. The directional derivative $f'$ is calculated as:
    $$ f' = \frac{\langle \nabla F, \mathbf{e} \rangle}{\|\mathbf{e}\|^2} $$
    If the edge is axis-aligned, $f'$ is simply the corresponding component of the gradient $\nabla F$.

2.  **Scale Derivatives:**
    To formulate the interpolation in a uniform setting, scale the interval between $\mathbf{x}_0$ and $\mathbf{x}_1$ to $[0, 1]$. This requires scaling the directional derivatives by the edge length $\|\mathbf{x}_0 - \mathbf{x}_1\|$. Let $d_0$ and $d_1$ be the scaled derivatives:
    $$ d_0 = f'_0 \cdot \|\mathbf{x}_1 - \mathbf{x}_0\| $$
    $$ d_1 = f'_1 \cdot \|\mathbf{x}_1 - \mathbf{x}_0\| $$

3.  **Define Hermite Constraints:**
    The interpolation polynomial $p(t)$ must satisfy four constraints at $t=0$ and $t=1$:
    $$ p(0) = v_0, \quad p'(0) = d_0 $$
    $$ p(1) = v_1, \quad p'(1) = d_1 $$

4.  **Solve for Isovertex Position:**
    Depending on the chosen variant (see Subtopics), solve the resulting polynomial equation $p(t) = 0$ for $t$.
    - For **Cubic Hermite Interpolation**, find all real roots of the cubic polynomial and select the "middle" root.
    - For **Quadratic Hermite Interpolation (Least-Squares Derivatives)**, solve the quadratic equation derived from value-interpolating and derivative-fitting constraints.

### Formulas

**Cubic Hermite Coefficients:**
For $p(t) = a_0 + a_1 t + a_2 t^2 + a_3 t^3$:
$$ a_0 = v_0 $$
$$ a_1 = d_0 $$
$$ a_2 = 3v_1 - 3v_0 - 2d_0 - d_1 $$
$$ a_3 = 2v_0 - 2v_1 + d_0 + d_1 $$

**Quadratic Hermite Coefficients (Least-Squares Derivatives):**
For $p(t) = a_0 + a_1 t + a_2 t^2$:
$$ a_0 = v_0 $$
$$ a_1 = \frac{d_0 - d_1}{2} + v_1 - v_0 $$
$$ a_2 = \frac{d_1 - d_0}{2} $$

### Pseudocode

```python
import math

def solve_cubic_roots(a, b, c, d):
    """
    Solves ax^3 + bx^2 + cx + d = 0.
    Returns a list of real roots in [0, 1].
    """
    # Normalize to monic polynomial
    if a == 0:
        # Fall back to quadratic if cubic term is zero
        if b == 0:
            if c == 0:
                return []
            return [-d / c] if -d / c >= 0 and -d / c <= 1 else []
        # Quadratic: bx^2 + cx + d = 0
        disc = c**2 - 4*b*d
        if disc < 0:
            return []
        sqrt_disc = math.sqrt(disc)
        r1 = (-c + sqrt_disc) / (2*b)
        r2 = (-c - sqrt_disc) / (2*b)
        roots = []
        if 0 <= r1 <= 1: roots.append(r1)
        if 0 <= r2 <= 1: roots.append(r2)
        return roots

    # Cubic solver (Cardano's method or similar robust implementation)
    # For brevity, assuming a robust solver exists or implementing standard cubic root finding
    # Here we use a simplified approach for demonstration, but a production implementation
    # should use a robust numerical method for cubic roots.
    
    # Normalize
    b /= a
    c /= a
    d /= a
    
    # Depressed cubic t^3 + pt + q = 0 with x = t - b/3
    p = c - b**2 / 3
    q = 2*b**3 / 27 - b*c / 3 + d
    
    disc = q**2 / 4 + p**3 / 27
    
    roots = []
    if disc > 0:
        # One real root
        u = -q/2 + math.sqrt(disc)
        v = -q/2 - math.sqrt(disc)
        u = math.cbrt(u) if u >= 0 else -math.cbrt(-u)
        v = math.cbrt(v) if v >= 0 else -math.cbrt(-v)
        t = u + v
        x = t - b/3
        if 0 <= x <= 1:
            roots.append(x)
    elif disc == 0:
        # Multiple roots
        if p == 0 and q == 0:
            x = -b/3
            if 0 <= x <= 1: roots.append(x)
        else:
            u = math.cbrt(-q/2)
            t1 = 2*u
            t2 = -u
            x1 = t1 - b/3
            x2 = t2 - b/3
            if 0 <= x1 <= 1: roots.append(x1)
            if 0 <= x2 <= 1: roots.append(x2)
    else:
        # Three real roots (trigonometric solution)
        r = math.sqrt(-p**3 / 27)
        theta = math.acos(-q / (2*r))
        m = 2 * math.cbrt(r)
        t1 = m * math.cos(theta / 3)
        t2 = m * math.cos((theta + 2*math.pi) / 3)
        t3 = m * math.cos((theta + 4*math.pi) / 3)
        x1 = t1 - b/3
        x2 = t2 - b/3
        x3 = t3 - b/3
        if 0 <= x1 <= 1: roots.append(x1)
        if 0 <= x2 <= 1: roots.append(x2)
        if 0 <= x3 <= 1: roots.append(x3)
        
    return sorted(roots)

def hermite_interpolation_cubic(v0, v1, d0, d1):
    """
    Cubic Hermite Interpolation for isosurface extraction.
    """
    a0 = v0
    a1 = d0
    a2 = 3*v1 - 3*v0 - 2*d0 - d1
    a3 = 2*v0 - 2*v1 + d0 + d1
    
    # Solve a3*t^3 + a2*t^2 + a1*t + a0 = 0
    roots = solve_cubic_roots(a3, a2, a1, a0)
    
    if not roots:
        return None # No root found in [0,1]
    
    # Select the "middle" root
    # If there are 3 roots, pick the median. If 1, pick it. If 2, pick the median of the two.
    roots.sort()
    if len(roots) == 1:
        return roots[0]
    elif len(roots) == 2:
        return (roots[0] + roots[1]) / 2
    else:
        return roots[1]

def hermite_interpolation_quadratic_ls(v0, v1, d0, d1):
    """
    Quadratic Hermite Interpolation with Least-Squares Derivatives.
    """
    a0 = v0
    a1 = (d0 - d1) / 2 + v1 - v0
    a2 = (d1 - d0) / 2
    
    # Solve a2*t^2 + a1*t + a0 = 0
    if a2 == 0:
        if a1 == 0:
            return None
        t = -a0 / a1
        return t if 0 <= t <= 1 else None
    
    disc = a1**2 - 4*a2*a0
    if disc < 0:
        return None
    
    sqrt_disc = math.sqrt(disc)
    t1 = (-a1 + sqrt_disc) / (2*a2)
    t2 = (-a1 - sqrt_disc) / (2*a2)
    
    roots = []
    if 0 <= t1 <= 1: roots.append(t1)
    if 0 <= t2 <= 1: roots.append(t2)
    
    if not roots:
        return None
    
    # Select the middle root (median)
    roots.sort()
    return roots[len(roots)//2]
```

### Parameters and Edge Cases
- **Parameters:** The method relies on the accuracy of the gradient $\nabla F$. If gradients are not available, they can be approximated using finite differences [S1].
- **Edge Cases:**
    - **No Roots:** If the polynomial has no real roots in $[0, 1]$, the edge does not contain an isovertex according to the interpolant, even if the original function $F$ had a zero-crossing. This is a known limitation of the least-squares quadratic variant if not constrained properly [S1].
    - **Multiple Roots:** Cubic polynomials can have up to three real roots. The location and count of these roots may be sensitive to small perturbations of the function coefficients [S1]. The "middle" root is selected to uniquely define the isovertex position [S1].
    - **Linear Function:** If the implicit function is locally linear ($d_0 = d_1$), the second-order term in the quadratic variant vanishes, reducing to linear interpolation [S1].

## Subtopics

### Cubic Hermite Interpolation
A cubic polynomial $p(x) = a_0 + a_1 x + a_2 x^2 + a_3 x^3$ used to interpolate the four Hermite constraints (two values, two derivatives). It is chosen when higher-order accuracy is desired and the implicit function is not known to be quadratic. It is selected when the user prioritizes smoothness and accuracy over computational simplicity. [S1]

### Quadratic Hermite Interpolation (Least-Squares Derivatives)
A quadratic polynomial $p(x) = a_0 + a_1 x + a_2 x^2$ used when the implicit function is known to be quadratic (e.g., PSR with B-splines). It interpolates function values exactly and fits derivatives in a least-squares sense. It is chosen when the implicit function is known to be quadratic or when a guaranteed root exists along the edge is critical. [S1]

## Operating characteristics

- **Time Complexity:** $O(1)$ per edge, involving a constant number of arithmetic operations and solving a low-degree polynomial.
- **Memory Complexity:** $O(1)$ auxiliary memory.
- **Performance:** Provides clear quality improvements over linear interpolation, reducing visible reconstruction artifacts [S1].
- **Strengths:** Handles non-linear implicit functions more accurately than linear methods. Works even when gradients are approximated [S1].
- **Limitations:** Cubic interpolation can have multiple roots, requiring selection logic. Least-squares quadratic interpolation does not guarantee a root if the standard least-squares solution for all four constraints is used (hence the specific value-interpolating variant) [S1].
- **When to Use:** When the implicit function is non-linear and gradient data is available.
- **When Not to Use:** When computational resources are extremely limited and linear accuracy is sufficient, or when gradient data is unavailable and finite difference approximation is too noisy.

## Background
The method was proposed in "Accurate Isosurface Interpolation with Hermite Data" [S1]. It addresses the limitations of linear interpolation in contouring algorithms like Marching Cubes, where non-linear implicit functions lead to inaccurate isosurfaces. The work compares several interpolation methods, demonstrating the effectiveness of higher-order interpolants using Hermite data.
