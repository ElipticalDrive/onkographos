# Hermite Interpolation for Isosurface Extraction

Also called: Hermite contouring, Hermite interpolation

## Overview
Hermite interpolation for isosurface extraction determines the precise position of an isovertex along a zero-crossing edge by utilizing both scalar field values and gradient information (Hermite data) at the edge endpoints [S1]. Unlike [Linear Edge Intersection](868-linear-edge-intersection.md), which assumes linear variation and produces artifacts on non-linear implicit functions, this method fits higher-order polynomials to the local field behavior, significantly improving surface accuracy [S1]. It is primarily used in contouring algorithms like Marching Cubes where gradient data is available or can be approximated [S1].

## How it works

### Inputs and Outputs
**Inputs:**
- Edge endpoints: $\mathbf{x}_0, \mathbf{x}_1 \in \mathbb{R}^3$.
- Scalar field values at endpoints: $v_0 = F(\mathbf{x}_0)$, $v_1 = F(\mathbf{x}_1)$.
- Gradient vectors at endpoints: $\nabla F_0 = \nabla F(\mathbf{x}_0)$, $\nabla F_1 = \nabla F(\mathbf{x}_1)$.
- Target isovalue: $T$ (typically 0 for zero-level sets).

**Outputs:**
- Isovertex position $\mathbf{x}_{iso}$ along the edge such that $F(\mathbf{x}_{iso}) \approx T$.

### Data Structures
No complex data structures are required beyond standard vector and scalar types. The method operates on a per-edge basis.

### Steps

1.  **Normalize the Edge Interval:**
    Map the physical edge segment $[\mathbf{x}_0, \mathbf{x}_1]$ to the parametric interval $[0, 1]$. Let $e = \mathbf{x}_1 - \mathbf{x}_0$. The length is $L = \|e\|$.
    [G] If $L \approx 0$, the edge is degenerate; return $\mathbf{x}_0$ or handle as an error.

2.  **Compute Directional Derivatives:**
    Calculate the derivative of the scalar field along the direction of the edge at each endpoint. The directional derivative $f'$ is the projection of the gradient onto the edge direction, normalized by the squared length of the edge to account for the parametric scaling [S1].
    $$ f'_0 = \frac{\nabla F_0 \cdot e}{\|e\|^2} $$
    $$ f'_1 = \frac{\nabla F_1 \cdot e}{\|e\|^2} $$
    [S1] If the edge is axis-aligned, $f'$ is simply the corresponding component of $\nabla F$.

3.  **Scale Derivatives for Unit Interval:**
    To fit a polynomial $p(t)$ where $t \in [0, 1]$, the derivatives must be scaled by the edge length $L$ because $p'(t) = \frac{dF}{dt} = \frac{dF}{ds} \frac{ds}{dt} = f' \cdot L$ [S1].
    $$ d_0 = f'_0 \cdot L = \nabla F_0 \cdot \frac{e}{\|e\|} $$
    $$ d_1 = f'_1 \cdot L = \nabla F_1 \cdot \frac{e}{\|e\|} $$
    [G] Note: $d_0$ and $d_1$ represent the rate of change with respect to the parametric coordinate $t$.

4.  **Adjust Values for Target Isovalue:**
    The interpolation targets the zero-crossing of the shifted function. Define the target values $v_0, v_1$ relative to the isovalue $T$.
    $$ v_0 \leftarrow v_0 - T $$
    $$ v_1 \leftarrow v_1 - T $$

5.  **Select Interpolation Order and Solve:**
    Choose between Cubic or Quadratic Hermite interpolation based on the nature of the implicit function.

    **Option A: Cubic Hermite Interpolation (General Case)**
    Fit a cubic polynomial $p(t) = a_0 + a_1 t + a_2 t^2 + a_3 t^3$ satisfying:
    $$ p(0) = v_0, \quad p'(0) = d_0, \quad p(1) = v_1, \quad p'(1) = d_1 $$
    The coefficients are uniquely determined [S1]:
    $$ a_0 = v_0 $$
    $$ a_1 = d_0 $$
    $$ a_2 = 3v_1 - 3v_0 - 2d_0 - d_1 $$
    $$ a_3 = 2v_0 - 2v_1 + d_0 + d_1 $$
    Solve $p(t) = 0$ for $t \in [0, 1]$. Since $p(t)$ is cubic, it may have up to three real roots. Select the root that lies within $[0, 1]$. If multiple roots exist, select the one closest to the midpoint or consistent with the sign change [S1].

    **Option B: Quadratic Hermite Interpolation (Least-Squares Derivatives)**
    Use this if the implicit function is known to be quadratic (e.g., PSR with B-splines) [S1]. Fit $p(t) = a_0 + a_1 t + a_2 t^2$.
    Interpolate values exactly:
    $$ a_0 = v_0 $$
    $$ a_0 + a_1 + a_2 = v_1 \implies a_2 = v_1 - v_0 - a_1 $$
    Fit derivatives in a least-squares sense to minimize $(a_1 - d_0)^2 + (a_1 + 2a_2 - d_1)^2$ [S1].
    Substituting $a_2$:
    $$ a_1 = \frac{d_0 - d_1}{2} + v_1 - v_0 $$
    $$ a_2 = \frac{d_1 - d_0}{2} $$
    Solve the quadratic equation $a_2 t^2 + a_1 t + a_0 = 0$ for $t \in [0, 1]$ [S1].

6.  **Compute Isovertex Position:**
    $$ \mathbf{x}_{iso} = \mathbf{x}_0 + t \cdot e $$

### Pseudocode

```python
import math

def hermite_isovertex(x0, x1, v0, v1, grad0, grad1, T=0.0):
    """
    Calculate isovertex position using Hermite interpolation.
    
    Args:
        x0, x1: Endpoints of the edge (vectors).
        v0, v1: Scalar field values at endpoints.
        grad0, grad1: Gradient vectors at endpoints.
        T: Target isovalue.
        
    Returns:
        x_iso: Position of the isovertex.
    """
    # 1. Edge vector and length
    e = x1 - x0
    L_sq = dot(e, e)
    
    # Handle degenerate edge
    if L_sq < 1e-12:
        return x0
        
    L = math.sqrt(L_sq)
    
    # 2. Directional derivatives (projected onto edge direction)
    # f' = (grad . e) / ||e||^2
    df0 = dot(grad0, e) / L_sq
    df1 = dot(grad1, e) / L_sq
    
    # 3. Scale derivatives for unit interval [0, 1]
    # d = df * L
    d0 = df0 * L
    d1 = df1 * L
    
    # 4. Adjust values for target isovalue
    v0_adj = v0 - T
    v1_adj = v1 - T
    
    # 5. Solve for t
    # Using Cubic Hermite as the general robust method
    a0 = v0_adj
    a1 = d0
    a2 = 3 * v1_adj - 3 * v0_adj - 2 * d0 - d1
    a3 = 2 * v0_adj - 2 * v1_adj + d0 + d1
    
    # Solve cubic a3*t^3 + a2*t^2 + a1*t + a0 = 0
    t = solve_cubic_root_in_range(a3, a2, a1, a0, 0.0, 1.0)
    
    if t is None:
        # Fallback to linear if cubic fails to find root in range
        # Linear interpolation: t = -v0 / (v1 - v0)
        denom = v1_adj - v0_adj
        if abs(denom) < 1e-12:
            return x0
        t = -v0_adj / denom
        t = max(0.0, min(1.0, t))
        
    # 6. Compute position
    x_iso = x0 + t * e
    return x_iso

def solve_cubic_root_in_range(a3, a2, a1, a0, low, high):
    """
    Finds a real root of a3*t^3 + a2*t^2 + a1*t + a0 = 0 within [low, high].
    Returns the root or None if no root exists in range.
    """
    # Use standard cubic formula or numerical solver
    # For implementation simplicity, we assume a robust cubic solver exists
    # or implement Cardano's method. Here we outline the logic.
    
    roots = []
    
    # Normalize if a3 is 0 (quadratic)
    if abs(a3) < 1e-12:
        if abs(a2) < 1e-12:
            # Linear: a1*t + a0 = 0
            if abs(a1) > 1e-12:
                t = -a0 / a1
                if low <= t <= high:
                    return t
            return None
        else:
            # Quadratic: a2*t^2 + a1*t + a0 = 0
            disc = a1*a1 - 4*a2*a0
            if disc < 0:
                return None
            sqrt_disc = math.sqrt(disc)
            t1 = (-a1 + sqrt_disc) / (2 * a2)
            t2 = (-a1 - sqrt_disc) / (2 * a2)
            if low <= t1 <= high: return t1
            if low <= t2 <= high: return t2
            return None
            
    # Cubic case
    # Convert to depressed cubic u^3 + pu + q = 0
    # t = u - a2/(3*a3)
    p = (3*a3*a1 - a2*a2) / (3*a3*a3)
    q = (2*a2*a2*a2 - 9*a3*a2*a1 + 27*a3*a3*a0) / (27*a3*a3*a3)
    
    # Discriminant
    delta = (q*q/4 + p*p*p/27)
    
    if delta > 0:
        # One real root
        sqrt_delta = math.sqrt(delta)
        u = cbrt(-q/2 + sqrt_delta) + cbrt(-q/2 - sqrt_delta)
        t = u - a2 / (3 * a3)
        if low <= t <= high:
            return t
    elif delta == 0:
        # Multiple roots
        if p == 0 and q == 0:
            t = -a2 / (3 * a3) # Triple root
            if low <= t <= high: return t
        else:
            u = cbrt(-q/2)
            t1 = 2*u - a2/(3*a3)
            t2 = -u - a2/(3*a3)
            if low <= t1 <= high: return t1
            if low <= t2 <= high: return t2
    else:
        # Three real roots (casus irreducibilis)
        r = math.sqrt(-p*p*p/27)
        theta = math.acos(-q / (2 * r))
        m = 2 * math.cbrt(r)
        t1 = m * math.cos(theta/3) - a2/(3*a3)
        t2 = m * math.cos((theta + 2*math.pi)/3) - a2/(3*a3)
        t3 = m * math.cos((theta + 4*math.pi)/3) - a2/(3*a3)
        
        candidates = [t1, t2, t3]
        for t in candidates:
            if low <= t <= high:
                return t
                
    return None

def cbrt(x):
    if x >= 0:
        return x ** (1/3)
    else:
        return -((-x) ** (1/3))
```

### Parameters
- **Target Isovalue ($T$):** Typically 0.
- **Interpolation Order:** Cubic is the default for general implicit functions; Quadratic is used for known quadratic fields (e.g., B-splines) [S1].

### Edge Cases and Pitfalls
- **Degenerate Edges:** If $\|\mathbf{x}_0 - \mathbf{x}_1\| \approx 0$, the derivative calculation involves division by zero. Guard against this by returning one of the endpoints [G].
- **Multiple Roots:** A cubic polynomial can have up to three real roots. The method must select the root corresponding to the actual zero-crossing of the implicit function. In a zero-crossing edge, there is an odd number of roots. If multiple roots fall in $[0, 1]$, additional context or higher-order analysis may be needed, but typically the root closest to the linear estimate or the one consistent with the sign change is chosen [S1].
- **Least-Squares Pitfall:** Do not use the standard least-squares solution for all four constraints (values and derivatives) in the quadratic case. This solution does not guarantee that the polynomial $p(t)$ has a root along the edge even if $F(t)$ does [S1]. The value-interpolating, derivative-least-squares approach described above is preferred [S1].
- **Gradient Availability:** Hermite data (gradients) may not be available in all datasets. In such cases, gradients can be approximated using finite differences, though accuracy may decrease [S1].

## Subtopics

### [Cubic Hermite Interpolation](13715-cubic-hermite-interpolation.md)
Cubic Hermite Interpolation fits a cubic polynomial to the four Hermite constraints (two values, two derivatives). It is the general-purpose method for non-linear implicit functions, offering higher accuracy than linear interpolation by reducing artifacts. It requires solving a cubic equation, which may yield up to three roots, necessitating a strategy to select the correct isovertex. Choose this when the implicit function is not known to be quadratic and high accuracy is required. See [Cubic Hermite Interpolation](13715-cubic-hermite-interpolation.md).

### Quadratic Hermite Interpolation (Least-Squares Derivatives)
This variant fits a quadratic polynomial that interpolates the endpoint values exactly and fits the endpoint derivatives in a least-squares sense [S1]. It is specifically designed for implicit functions known to be quadratic, such as those represented by linear combinations of second-order B-splines (e.g., PSR) [S1]. It is computationally cheaper than cubic interpolation (solving a quadratic vs. cubic equation) and avoids the multiple-root ambiguity of cubics [S1]. Choose this when the underlying field is known to be quadratic.

## Operating characteristics

- **Time Complexity:** $O(1)$ per edge. Cubic interpolation involves solving a cubic equation (constant number of operations). Quadratic interpolation involves solving a quadratic equation (constant number of operations).
- **Memory Complexity:** $O(1)$ per edge. No additional storage is required beyond the input values and gradients.
- **Measured Performance:** Not given in the sources.
- **Scaling:** Scales linearly with the number of edges in the mesh.
- **Strengths:** Significantly reduces reconstruction artifacts compared to linear interpolation for non-linear implicit functions [S1]. Provides mathematically precise isovertex positions given gradient data.
- **Limitations:** Requires gradient data (Hermite data), which may need to be computed via finite differences if not available, adding overhead and potential noise [S1]. Cubic interpolation can have multiple roots, requiring careful selection logic [S1].
- **When to Use:** When high-quality isosurfaces are required for non-linear implicit functions and gradient information is available or can be efficiently approximated.
- **When Not to Use:** When gradient data is unavailable and finite difference approximation is too expensive or noisy, or when the implicit function is strictly linear (linear interpolation is sufficient and faster).

## Background

Hermite interpolation for isosurface extraction was proposed to address the inaccuracies of linear interpolation in contouring algorithms like Marching Cubes when applied to non-linear implicit functions [S1]. The method utilizes the gradient of the implicit function to generate more accurate isosurfaces by means of higher-order interpolation techniques [S1]. The approach was demonstrated to provide clear quality improvements, even when Hermite data is not directly available and gradients are approximated using finite differences [S1].
