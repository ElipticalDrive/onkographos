# Joint Root-Finding

Also called: Joint Root-Finding for Ray-Surface Intersection, Simultaneous Ray-Surface and Correspondence Search

## Overview
Joint Root-Finding is a hybrid algorithm for simultaneous ray-surface intersection search and canonical correspondence search in articulated implicit surface representations [S1]. It solves for the precise intersection point $\hat{\mathbf{x}}$ and depth $d$ in a single Newton iteration, avoiding the high memory and runtime costs of alternating sphere tracing and root finding [S1].

## How it works
**Inputs:**
- Camera ray defined by center $\mathbf{c}$ and unit direction vector $\mathbf{v}$ [S1].
- Canonical Signed Distance Function (SDF) network $\sigma_f$ evaluating $f_{\sigma_f}(\hat{\mathbf{x}})$ [S1].
- Forward Linear Blend Skinning (LBS) network $\sigma_\omega$ evaluating $LBS_{\sigma_\omega}(\hat{\mathbf{x}})$ [S1].
- Initial rough estimation of canonical point $\hat{\mathbf{x}}_0$ and depth $d_0$ [S1].

**Outputs:**
- Converged canonical point $\hat{\mathbf{x}}^*$ and depth $d^*$ [S1].

**Data Structures:**
- State vector $\mathbf{u}_k = [\hat{\mathbf{x}}_k, d_k]^T \in \mathbb{R}^4$ (for 3D space) [S1].
- Residual vector $\mathbf{g}(\mathbf{u}_k) \in \mathbb{R}^4$ [S1].
- Jacobian matrix $\mathbf{J}_k$ (a $4 \times 4$ block matrix for 3D space) [S1].

**Formulas:**
The system to solve is defined as [S1]:
$$
g_{\sigma_f, \sigma_\omega}(\hat{\mathbf{x}}, d) = \begin{bmatrix} f_{\sigma_f}(\hat{\mathbf{x}}) \\ LBS_{\sigma_\omega}(\hat{\mathbf{x}}) - (\mathbf{c} + \mathbf{v} \cdot d) \end{bmatrix} = \mathbf{0}
$$
where:
- $f_{\sigma_f}(\hat{\mathbf{x}})$ is the scalar SDF value at canonical point $\hat{\mathbf{x}}$ [S1].
- $LBS_{\sigma_\omega}(\hat{\mathbf{x}})$ is the 3D position in observation space predicted by forward skinning from canonical point $\hat{\mathbf{x}}$ [S1].
- $\mathbf{c} + \mathbf{v} \cdot d$ is the 3D position on the camera ray at depth $d$ [S1].

The Jacobian matrix $\mathbf{J}_k$ at iteration $k$ is [S1]:
$$
\mathbf{J}_k = \begin{bmatrix} \frac{\partial f_{\sigma_f}}{\partial \hat{\mathbf{x}}}(\hat{\mathbf{x}}_k) & 0 \\ \frac{\partial LBS_{\sigma_\omega}}{\partial \hat{\mathbf{x}}}(\hat{\mathbf{x}}_k) & -\mathbf{v} \end{bmatrix}
$$
where $\frac{\partial f_{\sigma_f}}{\partial \hat{\mathbf{x}}}$ is the gradient of the SDF (1×3 row), $\frac{\partial LBS_{\sigma_\omega}}{\partial \hat{\mathbf{x}}}$ is the Jacobian of the skinning function (3×3 matrix), and $-\mathbf{v}$ is the negative ray direction vector (3×1 column) [S1].

**Pseudocode:**
The implementation uses Broyden’s method to approximate the Jacobian inverse, avoiding explicit computation of $\mathbf{J}_k$ at each iteration [S1].

```python
def joint_root_finding(c, v, sigma_f, sigma_w, x_init, d_init, max_iter=10):
    # c: camera center (3,), v: ray direction unit vector (3,)
    # sigma_f: returns scalar f(x_hat)
    # sigma_w: returns 3D vector LBS(x_hat)
    x = list(x_init)
    d = d_init
    max_iter = max_iter

    # Helper: vector operations
    def vec_add(a, b): return [a[i] + b[i] for i in range(3)]
    def vec_sub(a, b): return [a[i] - b[i] for i in range(3)]
    def vec_scale(a, s): return [a[i] * s for i in range(3)]
    def dot(a, b): return sum(a[i] * b[i] for i in range(len(a)))
    def outer(a, b): return [[a[i]*b[j] for j in range(len(b))] for i in range(len(a))]
    def mat_vec(M, v): return [dot(M[i], v) for i in range(len(M))]
    def mat_add(A, B): return [[A[i][j] + B[i][j] for j in range(4)] for i in range(4)]
    def mat_scale(M, s): return [[M[i][j] * s for j in range(4)] for i in range(4)]

    # Compute initial residual g = [f(x), LBS(x) - (c + v*d)]
    f_val = sigma_f(x)
    lbs_val = sigma_w(x)
    ray_pos = vec_add(c, vec_scale(v, d))
    g = [f_val] + vec_sub(lbs_val, ray_pos)  # 4 elements

    # Compute initial Jacobian J (4x4)
    # grad_f is 1x3, grad_LBS is 3x3, -v is 3x1
    grad_f = compute_gradient_sigma_f(x)  # [G] Standard automatic differentiation or finite difference
    grad_LBS = compute_jacobian_sigma_w(x)  # [G] Standard automatic differentiation for vector field
    J = [[0.0]*4 for _ in range(4)]
    for j in range(3): J[0][j] = grad_f[j]
    J[0][3] = 0.0
    for i in range(3):
        for j in range(3): J[i+1][j] = grad_LBS[i][j]
        J[i+1][3] = -v[i]

    # Invert J (4x4) using a standard routine [G]
    J_inv = invert_4x4(J)

    for k in range(max_iter):
        # Step: s = -J_inv * g
        Jg = mat_vec(J_inv, g)
        s = [-Jg[i] for i in range(4)]

        # Update state
        x_new = vec_sub(x, s[:3])
        d_new = d - s[3]

        # Check convergence
        if dot(s, s) < 1e-12:
            return x_new, d_new

        x, d = x_new, d_new

        # Compute new residual g_new
        f_val_new = sigma_f(x)
        lbs_val_new = sigma_w(x)
        ray_pos_new = vec_add(c, vec_scale(v, d))
        g_new = [f_val_new] + vec_sub(lbs_val_new, ray_pos_new)

        # Broyden update: y = g_new - g
        y = vec_sub(g_new, g)

        # J_inv = J_inv + (s - J_inv @ y) @ s^T / (s^T @ s)
        Jy = mat_vec(J_inv, y)
        term = vec_sub(s, Jy)
        denom = dot(s, s)
        if abs(denom) < 1e-12:
            break  # Guard against singular update [G]
        update_mat = mat_scale(outer(term, s), 1.0 / denom)
        J_inv = mat_add(J_inv, update_mat)

        g = g_new

    return x, d
```

**Parameters:**
- `max_iter`: Typically small, as the method converges quadratically [S1].
- Initialization: A single initialization is sufficient; multiple initializations incur drastic overhead without noticeable improvement [S1]. The rough estimation is obtained by combining approximate backward mapping (inverse of linearly combined forward bone transforms) with sphere tracing [S1].

**Edge Cases and Pitfalls:**
- **Initialization Quality:** The method relies on a rough estimation from inverse transformations using SMPL skinning weights rather than rigid bone transformations [S1].
- **Singular Jacobian:** If the Jacobian is singular, Broyden's update may fail; a guard against zero denominator in `s^T @ s` is required [G].
- **Multiple Initializations:** Adding more initializations incurs drastic memory and runtime overhead without noticeable improvements [S1].

## Subtopics

### Ray Marching with Secant Refinement
An iterative method that refines depth using the secant method after ray marching. It requires solving a root-finding problem from scratch for each secant step, resulting in superlinear convergence. Choose when simplicity is prioritized over speed. [Ray Marching with Secant Refinement](1042-ray-marching-with-secant-refinement.md)

### Parabolic Root-Finding with Gradients
An iterative method that uses second-order (parabolic) approximation for faster convergence. It requires explicit gradient computation. Choose when higher-order convergence is needed and gradients are available. [Parabolic Root-Finding with Gradients](8906-parabolic-root-finding-with-gradients.md)

## Operating characteristics
- **Time Complexity**: Amortized complexity is $O(M)$ where $M$ is the number of root-finding steps [S1]. Naive alternation between sphere-tracing and root-finding is $O(MN)$ where $N$ is sphere-tracing steps [S1].
- **Measured Performance**: Results in approximately 5× speedup compared to naive alternation between sphere-tracing and root-finding [S1].
- **Convergence**: Quadratic convergence theoretically, compared to superlinear convergence for secant-method-based root-finding [S1].
- **Strengths**: Efficient simultaneous search for intersection and correspondence; generalizes well to unseen poses; avoids high memory/runtime cost of alternating methods [S1].
- **Limitations**: Requires differentiable SDF and LBS networks; relies on good initialization from inverse transformations [S1].
- **When to Use**: When rendering articulated human avatars with detailed geometry and pose-dependent appearance from sparse multi-view RGB videos [S1].
- **When Not to Use**: When rigid geometry is assumed (simpler methods suffice); when computational resources are extremely limited and initialization quality is poor [S1].

## Background
Originated in the paper "ARAH: Animatable Volume Rendering of Articulated Human SDFs" [S1]. The method addresses the challenge of rendering clothed human avatars with detailed geometry that generalizes well to out-of-distribution poses [S1]. It combines articulated implicit surface representation with volume rendering [S1]. The joint root-finding algorithm enables efficient point sampling and accurate point canonicalization [S1]. It is used in the context of 3D Computer Vision, Clothed Human Modeling, and Cloth Motion Capture [S1].
