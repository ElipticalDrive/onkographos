# Parabolic Root-Finding with Gradients

Also called: Gradient-based parabola interpolation, Least-squares parabolic root finding

## Overview
Parabolic root-finding with gradients is an iterative refinement technique that estimates the zero-crossing of a scalar field $F(x)$ along a line segment by fitting a parabola to the function values and directional derivatives (gradients) at the endpoints [S1]. It solves for the root of this parabola to determine the intersection depth [S1]. It sets itself apart from its sibling, the [Secant Method for Surface Depth Refinement](996-secant-method-for-surface-depth-refinement.md), by utilizing gradient information to model curvature, thereby avoiding the need for an additional function evaluation to estimate the second derivative, while offering higher accuracy for non-linear fields [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Two endpoints $x_1$ and $x_2$ on the ray, the scalar field values $F(x_1)$ and $F(x_2)$, and the gradients $\nabla F(x_1)$ and $\nabla F(x_2)$ at these points [S1].
*   **Output:** The parameter $t \in [0, 1]$ representing the position of the root along the segment $x(t) = x_1 + t(x_2 - x_1)$ [S1].

**Data Structures:** Not given in the sources.

**Steps:**
1.  **Define the Line Segment:** Parameterize the segment between $x_1$ and $x_2$ as $v(t) = x_1 + t(x_2 - x_1)$ for $t \in [0, 1]$ [S1].
2.  **Compute Directional Derivatives:** Calculate the directional derivative of $F$ along the vector $(x_2 - x_1)$ at both endpoints. The directional derivative is defined as $D_{x_2-x_1} F(x) = \nabla F(x) \cdot (x_2 - x_1)$ [S1]. Let $d_1 = D_{x_2-x_1} F(x_1)$ and $d_2 = D_{x_2-x_1} F(x_2)$ [S1].
3.  **Fit Parabola Coefficients:** Define the parabola $F(t)$ interpolating the endpoints: $F(t) = F(x_1) + (F(x_2) - F(x_1) - b)t + bt^2$ [S1]. The derivative of this parabola is $F'(t) = F(x_2) - F(x_1) - b + 2bt$ [S1]. Determine the coefficient $b$ by minimizing the least-squares error between the parabola's derivatives and the actual directional derivatives. The system of equations for the derivatives is $d_1 \approx F(x_2) - F(x_1) - b$ and $d_2 \approx F(x_1) - F(x_2) + b$ [S1]. Solving for $b$ by averaging the two estimates yields $b = \frac{d_1 - d_2}{2}$ [S1].
4.  **Solve for Root:** Solve $F(t) = 0$ using the quadratic formula [S1]. The equation is $bt^2 + (F(x_2) - F(x_1) - b)t + F(x_1) = 0$ [S1].
    $$t = \frac{-(F(x_2) - F(x_1) - b) \pm \sqrt{(F(x_2) - F(x_1) - b)^2 - 4bF(x_1)}}{2b}$$
    Select the root $t$ that lies within the interval $[0, 1]$. The source guarantees exactly one root in this interval for valid zero-crossings [S1].
5.  **Handle Degeneracy:** If $d_1 = d_2$, then $b=0$. The method degenerates to the linear secant method [S1]. In this case, use linear interpolation:
    $$t = \frac{-F(x_1)}{F(x_2) - F(x_1)}$$

**Pseudocode:**
```python
import math

def parabolic_root_finding_with_gradients(x1, x2, f1, f2, grad1, grad2):
    """
    Finds the root t in [0, 1] along the segment x1->x2.
    x1, x2: 3D vectors (endpoints)
    f1, f2: scalar field values at x1, x2
    grad1, grad2: gradient vectors at x1, x2
    """
    # 1. Direction vector
    dir_vec = [x2[i] - x1[i] for i in range(len(x1))]
    
    # 2. Directional derivatives: D = grad . dir_vec
    d1 = sum(g * d for g, d in zip(grad1, dir_vec))
    d2 = sum(g * d for g, d in zip(grad2, dir_vec))
    
    # 3. Compute parabola coefficient b: b = (d1 - d2) / 2
    b = (d1 - d2) / 2.0
    
    # 4. Solve quadratic equation: b*t^2 + (f2 - f1 - b)*t + f1 = 0
    a_coeff = b
    b_coeff = f2 - f1 - b
    c_coeff = f1
    
    # Handle linear case (degeneracy) when b is effectively zero
    if abs(a_coeff) < 1e-9:
        # Linear interpolation (Secant method)
        if abs(b_coeff) < 1e-9:
            return 0.5  # Fallback if both f1 and f2 are effectively equal and flat
        t = -c_coeff / b_coeff
        # Clamp to [0, 1] to handle numerical noise
        return max(0.0, min(1.0, t))
    
    # Quadratic formula
    discriminant = b_coeff**2 - 4 * a_coeff * c_coeff
    
    # Clamp negative discriminant due to floating-point precision
    if discriminant < 0:
        discriminant = 0.0
        
    sqrt_disc = math.sqrt(discriminant)
    
    # Two possible roots
    t1 = (-b_coeff + sqrt_disc) / (2 * a_coeff)
    t2 = (-b_coeff - sqrt_disc) / (2 * a_coeff)
    
    # Select the root in [0, 1]
    if 0.0 <= t1 <= 1.0:
        return t1
    elif 0.0 <= t2 <= 1.0:
        return t2
    else:
        # Not given in the sources: fallback behavior when no root is in [0, 1]
        return 0.5
```

**Parameters:** Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Equal Gradients:** If $d_1 = d_2$, $b=0$, and the quadratic formula fails. The method must fall back to linear interpolation [S1].
*   **Precision:** If the discriminant is slightly negative due to floating-point errors, it should be clamped to zero [G].
*   **No Root in Interval:** If neither root lies in $[0, 1]$, the segment does not contain a zero-crossing (or the field is not monotonic/convex in a way that guarantees one) [G].

## Subtopics

### Least-Squares Derivatives (LSDERIV)
A quadratic interpolation method that guarantees a root along an edge if the implicit function has a root, by interpolating function values and least-squares fitting derivatives [S2]. It enforces value constraints $a_0 = v_0$ and $a_0 + a_1 + a_2 = v_1$, and minimizes $(a_1 - d_0)^2 + (a_1 + 2a_2 - d_1)^2$ [S2]. The resulting coefficients are $a_1 = \frac{d_0 - d_1}{2} + v_1 - v_0$ and $a_2 = \frac{d_1 - d_0}{2}$ [S2]. The second order term $a_2$ vanishes if the implicit function is locally linear ($d_0 = d_1$) [S2]. This solution is equivalent to the Third Order Elimination with additive offset [S2].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per segment, involving a few arithmetic operations and a square root [G].
*   **Memory Complexity:** $O(1)$, requiring storage for the two endpoints, function values, and gradients [G].
*   **Strengths:** Higher accuracy than linear interpolation for curved surfaces; avoids the cost of an additional function evaluation compared to 3-point parabolic fitting [G].
*   **Limitations:** Requires gradient information, which may not always be available or cheap to compute. Degenerates to linear interpolation if gradients are equal [G].
*   **When to use:** When gradients are available (e.g., from pre-computed textures or analytic implicit functions) and high accuracy is needed with minimal extra function evaluations [G].
*   **When not to use:** When gradients are unavailable and computing them is expensive, or when the field is known to be linear [G].

## Background
The method was introduced in "Real-Time Isosurface Extraction Using the GPU Programmable Geometry Pipeline" [S1]. It leverages the fact that gradients are often already computed for shading or are easily available in static volume textures [S1]. It is used in real-time isosurface extraction to refine intersection points on GPU pipelines [S1].
