# Monocular Depth Predictor with Distribution Sampling

Also called: Depth Prediction via Discrete Distribution Sampling, DepthPredictorMonocular

## Overview
A neural network module that predicts a depth distribution for each ray from image features by discretizing the depth range into buckets, predicting a probability density function (PDF) and intra-bucket offsets, and sampling from this distribution to determine depth values [S1, unofficial]. It differs from the sibling [DepthPredictor](4097-depthpredictor.md) by explicitly modeling the depth uncertainty via a discrete probability distribution over sampled buckets rather than predicting a single deterministic depth value [S1, unofficial]. This method builds on [Differentiable Depth Function Forward/Backward Pass](1047-differentiable-depth-function-forward-backward-pass.md) to allow gradients to flow through the sampling process to the decoder parameters [S1, unofficial].

## How it works
**Inputs:**
- `features`: Tensor of shape `(batch, view, ray, surface, depth, 2)` containing projected features. The last dimension has 2 channels: raw PDF logits and raw offset logits [S1, unofficial].
- `near`: Tensor of shape `(batch, view)` specifying the near plane distance [S1, unofficial].
- `far`: Tensor of shape `(batch, view)` specifying the far plane distance [S1, unofficial].
- `deterministic`: Boolean flag controlling whether sampling is deterministic (argmax) or stochastic [S1, unofficial].
- `gaussians_per_pixel`: Integer specifying the number of samples (buckets) to draw from the depth distribution [S1, unofficial].
- `use_transmittance`: Boolean flag determining whether opacity is computed via the transmittance formula or taken directly from the PDF density [S1, unofficial].

**Outputs:**
- `depth`: Tensor of shape `(batch, view, ray, surface, sample)` containing the predicted absolute depth values [S1, unofficial].
- `opacity`: Tensor of shape `(batch, view, ray, surface, sample)` containing the predicted opacity values [S1, unofficial].
- `pdf`: Tensor of shape `(batch, view, ray, surface, sample)` containing the sampled PDF values [S1, unofficial].

**Data Structures:**
The module `DepthPredictorMonocular` contains:
- `projection`: An `nn.Sequential` module consisting of `nn.ReLU()` followed by `nn.Linear(d_in, 2 * num_samples * num_surfaces)` [S1, unofficial].
- `sampler`: A `DistributionSampler` instance responsible for sampling indices and gathering offsets [S1, unofficial].
- `to_pdf`: `nn.Softmax(dim=-1)` hook to normalize raw logits into a valid PDF [S1, unofficial].
- `to_offset`: `nn.Sigmoid()` hook to normalize raw logits into the range $[0, 1]$ [S1, unofficial].
- `num_samples`: Integer, the number of depth samples (buckets) per surface [S1, unofficial].
- `num_surfaces`: Integer, the number of distinct surfaces to model [S1, unofficial].

**Parameters:**
- `num_samples`: Number of depth samples per surface. Not given in the sources.
- `num_surfaces`: Number of distinct surfaces to model. Not given in the sources.
- `gaussians_per_pixel`: Number of samples to draw. Not given in the sources.

**Steps:**
1. Project input features through `self.projection` to obtain raw logits of shape `(batch, view, ray, surface, depth, 2)` where the last dimension corresponds to `pdf_raw` and `offset_raw` [S1, unofficial].
2. Rearrange the projected features from shape `... (dpt srf c)` to `c ... srf dpt` where $c=2$, separating `pdf_raw` and `offset_raw` tensors [S1, unofficial].
3. Apply `self.to_pdf` (Softmax) to `pdf_raw` along the last dimension (depth dimension) to obtain normalized PDF values `pdf` [S1, unofficial].
4. Apply `self.to_offset` (Sigmoid) to `offset_raw` to obtain intra-bucket offsets `offset` in the range $[0, 1]$ [S1, unofficial].
5. Sample depth indices and corresponding PDF densities from the distribution using `self.sampler.sample(pdf, deterministic, gaussians_per_pixel)`. This returns `index` (sampled bucket indices) and `pdf_i` (PDF values at sampled indices) [S1, unofficial].
6. Gather the intra-bucket offsets corresponding to the sampled indices: `offset = self.sampler.gather(index, offset)` [S1, unofficial].
7. Calculate the relative disparity for each sample:
   $$relative\_disparity = \frac{index + offset}{s}$$
   where $s$ is `num_samples` (the number of buckets) [S1, unofficial].
8. Convert relative disparity to absolute depth using the near and far plane values: `depth = relative_disparity_to_depth(relative_disparity, near, far)` [S1, unofficial].
9. Compute opacity based on the `use_transmittance` flag:
   - If `use_transmittance` is true:
     a. Calculate the cumulative sum of the PDF along the depth dimension: `partial = pdf.cumsum(dim=-1)` [S1, unofficial].
     b. Shift the cumulative sum to align with the previous bucket's transmittance: `partial = torch.cat((torch.zeros_like(partial[..., :1]), partial[..., :-1]), dim=-1)` [S1, unofficial].
     c. Compute opacity using the PDF and the shifted cumulative sum (approximating transmittance):
        $$opacity = \frac{pdf}{1 - partial + 10^{-10}}$$
        The epsilon $10^{-10}$ is added for numerical stability in the denominator [S1, unofficial].
     d. Gather the computed opacity values for the sampled indices: `opacity = self.sampler.gather(index, opacity)` [S1, unofficial].
   - If `use_transmittance` is false:
     a. Set opacity directly to the sampled PDF density: `opacity = pdf_i` [S1, unofficial].

## Subtopics

### DepthPredictor
Predicts a single deterministic depth value per ray. Choose when uncertainty modeling is not required. [Link](4097-depthpredictor.md)

## Operating characteristics
- **Time Complexity**: Dominated by the linear projection and the sampling/gathering operations. The sampling step is $O(N \cdot G)$ where $N$ is the number of buckets and $G$ is `gaussians_per_pixel`.
- **Memory Complexity**: Stores the full PDF distribution for all buckets, $O(N \cdot B \cdot V \cdot R \cdot S)$.
- **Strengths**: Provides a probabilistic estimate of depth, allowing for uncertainty quantification and multi-modal surface prediction (via `num_surfaces`).
- **Limitations**: Requires careful tuning of `num_samples` and `gaussians_per_pixel`. Numerical stability must be handled in opacity calculation.
- **When to use**: When depth uncertainty is important or when multiple surfaces need to be predicted per ray.
- **When not to use**: When a single deterministic depth estimate is sufficient and computational efficiency is critical.

## Background
The method originates from the PixelSplat project, which uses monocular depth prediction for novel view synthesis [S1, unofficial]. It was developed to handle the ambiguity in monocular depth estimation by modeling depth as a distribution rather than a point estimate.
