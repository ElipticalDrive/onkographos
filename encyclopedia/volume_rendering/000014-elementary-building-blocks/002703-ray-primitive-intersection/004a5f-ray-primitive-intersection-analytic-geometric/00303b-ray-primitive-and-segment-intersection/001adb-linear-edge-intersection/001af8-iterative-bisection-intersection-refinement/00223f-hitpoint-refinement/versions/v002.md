# Hitpoint Refinement


## Overview
Hitpoint Refinement is an iterative technique to achieve higher quality in detecting surface intersections without reducing rendering speed [S1, unofficial]. It allows for coarser initial sampling steps to increase rendering speed, refining the detected intersection point through a specific heuristic procedure [S1, unofficial]. It sets itself apart from its siblings by using a "half-step back, then check direction" adjustment rather than standard bisection or secant methods, enabling significant speedups when paired with large initial sampling distances [S1, unofficial].

## How it works
**Inputs and outputs:**
- Input: A ray, a surface function evaluating to a scalar (e.g., distance to surface or threshold crossing indicator), and an initial coarse intersection estimate found via sparse sampling [S1, unofficial].
- Output: A refined intersection parameter [S1, unofficial].

**Data structures:**
- Not given in the sources.

**Numbered steps:**
1. Sample along the ray with a relatively small sampling rate (large steps between sampling points) to detect a rough intersection [S1, unofficial].
2. Upon detecting an intersection, step back by half a step [S1, unofficial].
3. Check if moving closer to the target value or further away [S1, unofficial].
4. If closer, move back another half-step (quarter step total) [S1, unofficial]. If further, move forward one such step [S1, unofficial].
5. Repeat steps 3–4 five to six times [S1, unofficial].

**Formulas:**
Let $t$ be the ray parameter and $\Delta t$ be the current step size.
- Initial coarse hit: $t_0$, coarse step: $\Delta t_0$.
- Backstep: $t_1 = t_0 - \frac{\Delta t_0}{2}$, $\Delta t_1 = \frac{\Delta t_0}{2}$ [S1, unofficial].
- Iteration $i = 1$ to $k$ (where $k \in \{5, 6\}$):
  - Evaluate surface at $t_i$. Compare absolute error to target.
  - If closer: $t_{i+1} = t_i - \frac{\Delta t_i}{2}$, $\Delta t_{i+1} = \frac{\Delta t_i}{2}$ [S1, unofficial].
  - If further: $t_{i+1} = t_i + \Delta t_i$, $\Delta t_{i+1} = \frac{\Delta t_i}{2}$ [S1, unofficial].
- Final refined parameter: $t_{k+1}$ [S1, unofficial].

**Parameters:**
- Initial sampling distance: Can be increased to 400% or 500% of the original fine sampling distance when Hitpoint Refinement is used [S1, unofficial].
- Iteration count: 5 to 6 times [S1, unofficial].

**Edge cases and pitfalls:**
- Not given in the sources.

**Pseudocode:**
```python
def hitpoint_refinement(t_init, dt_coarse, surface_func, target=0.0, iterations=6):
    """
    Refines a coarse intersection point t_init found with step size dt_coarse.
    
    Args:
        t_init: Initial coarse intersection estimate.
        dt_coarse: Step size used during initial coarse sampling.
        surface_func: Function f(t) returning scalar value (e.g., distance to surface).
        target: Target scalar value for intersection (e.g., 0.0 for zero-crossing).
        iterations: Number of refinement steps (typically 5-6).
        
    Returns:
        Refined intersection parameter t.
    """
    # Step 2: Step back by half a step
    t_curr = t_init - dt_coarse / 2.0
    dt_curr = dt_coarse / 2.0
    
    # Evaluate current position
    val_curr = surface_func(t_curr)
    err_curr = abs(val_curr - target)
    
    # Steps 3-4: Refinement loop
    for _ in range(iterations):
        # Tentative backstep
        t_next = t_curr - dt_curr / 2.0
        val_next = surface_func(t_next)
        err_next = abs(val_next - target)
        
        if err_next < err_curr:
            # Closer to target: move back, halve step size
            t_curr = t_next
            val_curr = val_next
            err_curr = err_next
            dt_curr /= 2.0
        else:
            # Further away: move forward by one current step size, halve step size
            t_curr = t_curr + dt_curr
            val_curr = surface_func(t_curr)
            err_curr = abs(val_curr - target)
            dt_curr /= 2.0
            
    return t_curr
```

## Operating characteristics
- **Time complexity:** $O(k)$ where $k$ is the number of iterations (typically 5–6) [S1, unofficial].
- **Memory complexity:** Not given in the sources.
- **Measured performance:** Using Hitpoint Refinement allows the initial sampling distance to be increased to 400% or 500% of the original, significantly increasing rendering speed [S1, unofficial]. The refinement yields a 64-fold better intersection accuracy compared to the initially chosen point [S1, unofficial].
- **Strengths:** High accuracy with minimal additional cost; allows for coarser initial sampling [S1, unofficial].
- **Limitations:** Not given in the sources.

## Background
Hitpoint Refinement was introduced as an optimization technique for raycasters to improve intersection detection quality without sacrificing rendering speed [S1, unofficial]. It is described in the context of volume raycasting optimization [S1, unofficial].
