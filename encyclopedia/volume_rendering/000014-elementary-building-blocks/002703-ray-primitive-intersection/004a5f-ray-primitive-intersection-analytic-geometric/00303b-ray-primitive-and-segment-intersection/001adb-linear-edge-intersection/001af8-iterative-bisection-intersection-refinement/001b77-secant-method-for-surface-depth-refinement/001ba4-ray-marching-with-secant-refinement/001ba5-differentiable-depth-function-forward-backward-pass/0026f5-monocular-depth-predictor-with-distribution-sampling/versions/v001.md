# Monocular Depth Predictor with Distribution Sampling

Also called: DepthPredictorMonocular

## Overview
A neural network module that predicts a depth distribution for each ray from image features, sampling discrete depth values and probability density function (PDF) values to represent surface geometry [S1, unofficial]. It differs from the standard [DepthPredictor](4097-depthpredictor.md) by explicitly modeling multiple surfaces and using a distribution sampler to handle the stochastic nature of depth estimation, building on the differentiable forward/backward pass of [Differentiable Depth Function Forward/Backward Pass](1047-differentiable-depth-function-forward-backward-pass.md).

## How it works
**Inputs:**
- `features`: Tensor of shape `(batch, view, ray, channel)` representing image features.
- `near`: Tensor of shape `(batch, view)` specifying the near plane distance.
- `far`: Tensor of shape `(batch, view)` specifying the far plane distance.
- `deterministic`: Boolean flag controlling sampling behavior.
- `gaussians_per_pixel`: Integer specifying the number of Gaussian samples per pixel.

**Outputs:**
- `depth`: Tensor of shape `(batch, view, ray, surface, sample)` containing sampled depth values.
- `pdf`: Tensor of shape `(batch, view, ray, surface, sample)` containing the probability density values for the sampled depths.

**Data Structures:**
The class `DepthPredictorMonocular` contains the following fields:
- `projection`: An `nn.Sequential` module.
- `sampler`: A `DistributionSampler` instance.
- `num_samples`: Integer, number of depth samples per surface.
- `num_surfaces`: Integer, number of distinct surfaces to model.
- `use_transmittance`: Boolean flag for transmittance usage.

**Steps:**
1. Initialize `self.projection` as an `nn.Sequential` containing `nn.ReLU()` followed by `nn.Linear(d_in, 2 * num_samples * num_surfaces)`, where `d_in` is the input channel dimension of `features` [S1, unofficial].
2. Initialize `self.sampler` as a `DistributionSampler` instance [S1, unofficial].
3. Initialize `self.to_pdf` as `nn.Softmax(dim=-1)` and `self.to_offset` as `nn.Sigmoid()` as hooks [S1, unofficial].
4. In the forward pass, pass `features` through `self.projection` to get raw logits of shape `(batch, view, ray, 2 * num_samples * num_surfaces)` [S1, unofficial].
5. Rearrange the projected features from shape `... (dpt srf c)` to `c ... srf dpt` where `c=2`, separating `pdf_raw` and `offset_raw`. The dimension `dpt` corresponds to `num_samples` and `srf` to `num_surfaces` [S1, unofficial].
6. Apply softmax to `pdf_raw` along the last dimension to get normalized PDF values [S1, unofficial].
7. Apply sigmoid to `offset_raw` to get intra-bucket offsets [S1, unofficial].
8. Sample depth indices and PDF values using `self.sampler.sample(pdf, deterministic, gaussians_per_pixel)` [S1, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn as nn

class DepthPredictorMonocular(nn.Module):
    def __init__(self, d_in, num_samples, num_surfaces, use_transmittance=False):
        super().__init__()
        self.num_samples = num_samples
        self.num_surfaces = num_surfaces
        self.use_transmittance = use_transmittance
        # Initialize projection: ReLU followed by Linear
        self.projection = nn.Sequential(
            nn.ReLU(),
            nn.Linear(d_in, 2 * num_samples * num_surfaces)
        )
        # Initialize sampler [G]
        self.sampler = DistributionSampler()
        # Initialize hooks
        self.to_pdf = nn.Softmax(dim=-1)
        self.to_offset = nn.Sigmoid()

    def forward(self, features, near, far, deterministic=False, gaussians_per_pixel=1):
        # features shape: (batch, view, ray, channel)
        # near shape: (batch, view)
        # far shape: (batch, view)
        
        # Project features to raw logits
        # Output shape: (batch, view, ray, 2 * num_samples * num_surfaces)
        raw_logits = self.projection(features)
        
        # Rearrange to separate pdf_raw and offset_raw
        # Target shape for processing: (2, batch, view, ray, num_surfaces, num_samples)
        # The last dimension of raw_logits is 2 * num_samples * num_surfaces
        # We reshape to group the 2 channels, then move them to the front
        b, v, r, c = raw_logits.shape
        raw_logits = raw_logits.view(b, v, r, 2, self.num_surfaces, self.num_samples)
        raw_logits = raw_logits.permute(3, 0, 1, 2, 4, 5) # Shape: (2, b, v, r, srf, dpt)
        
        pdf_raw = raw_logits[0]
        offset_raw = raw_logits[1]
        
        # Apply softmax to pdf_raw
        pdf = self.to_pdf(pdf_raw)
        
        # Apply sigmoid to offset_raw
        offset = self.to_offset(offset_raw)
        
        # Sample depth indices and PDF values
        # [G] The sampler likely uses near/far to map indices to depth values
        # and combines pdf with offset. The exact implementation of DistributionSampler
        # is not provided in the source, so we assume it returns depth and pdf tensors.
        depth, pdf_out = self.sampler.sample(pdf, deterministic, gaussians_per_pixel)
        
        # [G] The output shapes are specified as (batch, view, ray, surface, sample)
        # The sampler output might need reshaping to match this if it returns a different layout.
        # Assuming sampler returns tensors compatible with the expected output shape.
        
        return depth, pdf
```

**Parameters:**
- `num_samples`: Number of depth samples per surface [S1, unofficial].
- `num_surfaces`: Number of distinct surfaces to model [S1, unofficial].
- `use_transmittance`: Boolean flag for transmittance usage [S1, unofficial].

**Edge Cases and Pitfalls:**
- Precision issues may arise when `num_samples` or `num_surfaces` are large, leading to high memory consumption.
- Boundary conditions for `near` and `far` must be handled correctly by the sampler to ensure valid depth values.
- Degenerate input features (e.g., all zeros) may result in uniform PDFs, leading to non-informative samples.

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of features, samples, and surfaces. The dominant operation is the linear projection and the sampling process.
- **Memory Complexity:** Proportional to the product of batch size, view, ray, surface, and sample dimensions for storing the output tensors.
- **Strengths:** Explicitly models multiple surfaces, allowing for more complex geometry representation. The use of a distribution sampler provides flexibility in handling uncertainty.
- **Limitations:** Requires careful tuning of `num_samples` and `num_surfaces` to balance accuracy and computational cost. The stochastic nature of sampling may introduce variance in the output.
- **When to use:** Suitable for applications requiring detailed depth estimation with multiple surfaces, such as 3D reconstruction from monocular images.
- **When not to use:** Not ideal for real-time applications with strict latency constraints due to the computational overhead of sampling and multiple surface modeling.

## Background
The method originates from the `pixelsplat` project by dcharatan [S1, unofficial]. It is designed to enhance monocular depth prediction by incorporating a probabilistic approach, allowing for the representation of ambiguous or multi-modal depth distributions. This approach is particularly useful in scenarios where a single depth value is insufficient to describe the scene geometry.
