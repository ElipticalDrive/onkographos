# Isolation and Iterative Root Finding

Also called: Isolation method, New intersection algorithm

## Overview
Isolation and Iterative Root Finding is a ray-voxel intersection algorithm for iso-surfaces that combines root isolation via derivative extrema with iterative refinement to achieve both the speed of Neubauer's method and the correctness guarantees of Schwarze's method [S1, unofficial]. It solves the problem of finding the first intersection of a ray with a trivariate polynomial within a voxel by ensuring the search interval contains exactly one root before applying repeated linear interpolation [S1, unofficial]. It sets itself apart from its siblings by explicitly isolating the root interval using the polynomial's extrema, thereby avoiding the false positives that can occur in Neubauer's method when multiple intersections exist within a single segment [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Ray segment parameter range $[t_{in}, t_{out}]$, polynomial coefficients $A, B, C, D$ for $f(t) = At^3 + Bt^2 + Ct + D$, and isovalue $\rho_{iso}$.
*   **Output:** Intersection parameter $t_{hit}$ or "NO HIT".

**Data Structures:**
*   Scalar variables $t_0, t_1, f_0, f_1, e_0, e_1$.
*   No complex data structures; minimal register usage suitable for SIMD [S1, unofficial].

**Steps:**
1.  **Initialization:** Set $t_0 = t_{in}$, $t_1 = t_{out}$. Compute $f_0 = f(t_0) - \rho_{iso}$ and $f_1 = f(t_1) - \rho_{iso}$ [S1, unofficial].
2.  **Extrema Calculation:** Solve the quadratic derivative equation $f'(t) = 3At^2 + 2Bt + C = 0$ [S1, unofficial].
    *   Calculate discriminant $\Delta = (2B)^2 - 4(3A)(C) = 4B^2 - 12AC$.
    *   If $\Delta < 0$, there are no real extrema; proceed to root finding with the initial interval.
    *   If $\Delta \ge 0$, compute roots:
        $$ e_0 = \frac{-2B - \sqrt{\Delta}}{6A} $$
        $$ e_1 = \frac{-2B + \sqrt{\Delta}}{6A} $$
        where $e_0 \le e_1$ [S1, unofficial].
3.  **Root Isolation:** Iterate through the extrema to isolate the first segment containing a root [S1, unofficial].
    *   **Check $e_0$:** If $e_0 \in [t_0, t_1]$:
        *   Compute $f(e_0) = f(e_0) - \rho_{iso}$.
        *   If $\text{sign}(f(e_0)) == \text{sign}(f_0)$: The function does not cross zero between $t_0$ and $e_0$. Advance to the next segment: $t_0 := e_0$, $f_0 := f(e_0)$.
        *   Else: The function crosses zero between $t_0$ and $e_0$. The root is in $[t_0, e_0]$. Set $t_1 := e_0$, $f_1 := f(e_0)$.
    *   **Check $e_1$:** If $e_1 \in [t_0, t_1]$ (note: $t_0$ may have been updated):
        *   Compute $f(e_1) = f(e_1) - \rho_{iso}$.
        *   If $\text{sign}(f(e_1)) == \text{sign}(f_0)$: Advance to the next segment: $t_0 := e_1$, $f_0 := f(e_1)$.
        *   Else: The root is in $[t_0, e_1]$. Set $t_1 := e_1$, $f_1 := f(e_1)$.
4.  **No Hit Check:** If $\text{sign}(f_0) == \text{sign}(f_1)$, return "NO HIT" [S1, unofficial].
5.  **Iterative Refinement:** Use repeated linear interpolation (regula falsi) to find the root in $[t_0, t_1]$ [S1, unofficial].
    *   Loop $i$ from 1 to $N$ (typically $N=2$ or $3$):
        *   Compute candidate $t$:
            $$ t = t_0 + (t_1 - t_0) \frac{-f_0}{f_1 - f_0} $$
        *   Compute $f(R(t)) = f(t) - \rho_{iso}$.
        *   If $\text{sign}(f(R(t))) == \text{sign}(f_0)$:
            *   $t_0 := t$
            *   $f_0 := f(R(t))$
        *   Else:
            *   $t_1 := t$
            *   $f_1 := f(R(t))$
6.  **Return:** Return $t_{hit} = t_0 + (t_1 - t_0) \frac{-f_0}{f_1 - f_0}$ [S1, unofficial].

**Parameters:**
*   $N$: Number of iterations. Typical values are 2 or 3. A fixed number is preferred over adaptive termination for performance [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Degenerate Quadratic:** If $A=0$, the polynomial is quadratic. The derivative is linear. The algorithm must handle the case where $3A=0$ separately to avoid division by zero in the quadratic formula [G].
*   **Multiple Roots:** The isolation step guarantees exactly one root in the final interval $[t_0, t_1]$ because the interval is bounded by extrema where the derivative is zero, preventing multiple crossings within the interval [S1, unofficial].
*   **Numerical Stability:** The method provides better numerical stability than Neubauer's method [S1, unofficial].

**Pseudocode:**
```python
def isolation_and_iterative_root_finding(t_in, t_out, A, B, C, D, rho_iso):
    # Step 1: Initialization
    t0 = t_in
    t1 = t_out
    f0 = A * t0**3 + B * t0**2 + C * t0 + D - rho_iso
    f1 = A * t1**3 + B * t1**2 + C * t1 + D - rho_iso

    # Step 2: Find extrema
    # f'(t) = 3At^2 + 2Bt + C = 0
    if A == 0:
        # Linear derivative, one extremum at t = -C / (2B) if B != 0
        if B != 0:
            e0 = -C / (2 * B)
            e1 = float('inf') # No second extremum
        else:
            e0 = float('inf')
            e1 = float('inf')
    else:
        delta = 4 * B**2 - 12 * A * C
        if delta < 0:
            e0 = float('inf')
            e1 = float('inf')
        else:
            sqrt_delta = math.sqrt(delta)
            e0 = (-2 * B - sqrt_delta) / (6 * A)
            e1 = (-2 * B + sqrt_delta) / (6 * A)

    # Step 3: Root Isolation
    # Check e0
    if math.isfinite(e0) and t0 <= e0 <= t1:
        f_e0 = A * e0**3 + B * e0**2 + C * e0 + D - rho_iso
        if math.copysign(1, f_e0) == math.copysign(1, f0):
            # Advance to second segment
            t0 = e0
            f0 = f_e0
        else:
            # Root is in [t0, e0]
            t1 = e0
            f1 = f_e0

    # Check e1
    if math.isfinite(e1) and t0 <= e1 <= t1:
        f_e1 = A * e1**3 + B * e1**2 + C * e1 + D - rho_iso
        if math.copysign(1, f_e1) == math.copysign(1, f0):
            # Advance to third segment
            t0 = e1
            f0 = f_e1
        else:
            # Root is in [t0, e1]
            t1 = e1
            f1 = f_e1

    # Step 4: No Hit Check
    if math.copysign(1, f0) == math.copysign(1, f1):
        return None # NO HIT

    # Step 5: Iterative Refinement
    N = 3 # Typical value
    for i in range(N):
        # Avoid division by zero if f1 == f0
        if f1 == f0:
            break
        t = t0 + (t1 - t0) * (-f0) / (f1 - f0)
        f_t = A * t**3 + B * t**2 + C * t + D - rho_iso
        if math.copysign(1, f_t) == math.copysign(1, f0):
            t0 = t
            f0 = f_t
        else:
            t1 = t
            f1 = f_t

    # Step 6: Return
    if f1 == f0:
        return t0
    return t0 + (t1 - t0) * (-f0) / (f1 - f0)
```

## Subtopics

### [de Casteljau-based root finding](1596-de-casteljau-based-root-finding.md)
A root finding algorithm for polynomials in Bernstein form that isolates and refines the first intersection of a viewing ray with an isosurface by subdividing the control polygon using the de Casteljau algorithm at its intersection with the zero axis. It sets itself apart from knot insertion methods like [MR07] by offering quadratic convergence speed and constant memory usage without index operations, making it significantly faster for GPU architectures. See [de Casteljau-based root finding](1596-de-casteljau-based-root-finding.md).

### [Neubauer Iterative Root Finder](2422-neubauer-iterative-root-finder.md)
The Neubauer Iterative Root Finder is a numerical method for locating the first positive root of the ray-volume intersection polynomial within a voxel cell. It solves the problem of determining the precise entry point of a ray into an implicit surface defined by a scalar field, specifically within the context of octree-based volume rendering. It is distinguished from analytical solvers (such as Schwarze’s cubic solver) by its reliance on iterative bisection and re-parameterization, offering slightly higher performance and robust single-precision numerical stability. See [Neubauer Iterative Root Finder](2422-neubauer-iterative-root-finder.md).

### Sturm Series root finding
A root finding approach based on Sturm Series working in power form. It uses the Sturm Series to count multiplicities of roots in a given interval and employs binary subdivision of the search interval. The Sturm Series is computed once at the beginning and evaluated once per iteration. It offers exponential convergence with constant memory consumption during iteration, but high overall memory consumption as the whole series must be kept in memory. Numerical problems inherent to power form implementations become more severe with more iterations. For degree 9 (tri-cubic), it has a relative execution time of 0.077, MSE of 0.003, and max error of 1.0 [S2].

## Operating characteristics
*   **Time Complexity:** Roughly a factor of three faster than Schwarze's method [S1, unofficial]. The cost is dominated by solving the quadratic for extrema and evaluating the cubic polynomial.
*   **Memory Complexity:** Minimal. Only scalar variables are needed, making it well-suited for SIMD implementations [S1, unofficial].
*   **Performance:** Provides the same guarantees on correctness as Schwarze's method but with better numerical stability [S1, unofficial].
*   **Strengths:** Correctness guarantees (isolates the root interval), speed, SIMD friendliness.
*   **Limitations:** Requires computing polynomial coefficients and extrema. Not suitable if the polynomial degree is too high for efficient coefficient computation.
*   **When to use:** When both speed and correctness are required, and the ray segment is within a voxel containing a trivariate polynomial.
*   **When not to use:** When the polynomial degree is very high, or when the overhead of computing extrema is not justified by the need for extreme precision (though it is generally robust).

## Background
The method was introduced by Wald et al. in 2004 as a new intersection algorithm aiming to combine the speed of Neubauer's method with the correctness of Schwarze's method [S1, unofficial]. It was developed in the context of fast and accurate ray-voxel intersection techniques for iso-surface ray rendering. The approach leverages the fact that repeated linear interpolation is fast and reliable if the start interval contains exactly one root, which is ensured by isolating roots via extrema [S1, unofficial].
