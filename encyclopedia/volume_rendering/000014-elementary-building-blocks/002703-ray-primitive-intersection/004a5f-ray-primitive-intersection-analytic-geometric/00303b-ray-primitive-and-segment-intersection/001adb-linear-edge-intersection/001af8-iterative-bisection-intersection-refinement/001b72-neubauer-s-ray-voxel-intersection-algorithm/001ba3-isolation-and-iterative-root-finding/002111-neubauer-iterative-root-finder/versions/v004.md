# Neubauer Iterative Root Finder

Also called: Neubauer's method

## Overview
The Neubauer Iterative Root Finder is a numerical method for finding the intersection of a ray with an implicit surface within a voxel cell [S1][S2, unofficial]. It determines the parameter $t$ along the ray where the implicit function $f(t)$ equals zero [S2, unofficial]. It sets itself apart from analytical solvers like Schwarze’s cubic solver by using iterative re-parameterization into sub-intervals, which yields single-precision, numerically stable results and is slightly faster in practice [S1][S2, unofficial]. It builds on [Isolation and Iterative Root Finding](1041-isolation-and-iterative-root-finding.md) by isolating roots via sign changes within sub-intervals [S1][S2, unofficial].

## How it works
**Inputs:**
- Ray origin $\mathbf{o}$ and direction $\mathbf{d}$ [S1].
- Implicit surface function $f(t)$, where $t$ is the ray parameter [S1].
- Initial search interval $[t_{min}, t_{max}]$ (typically the entry and exit parameters of the current voxel/cell) [S1].
- Convergence tolerance $\epsilon$ and maximum number of iterations $N_{max}$ [S3, unofficial].

**Outputs:**
- The smallest positive root $t^* \in [t_{min}, t_{max}]$ such that $f(t^*) \approx 0$ [S1].

**Data Structures:**
- Standard floating-point variables for interval bounds and function evaluations [G].

**Steps:**
1. **Evaluate Endpoints:** Compute $f_{min} = f(t_{min})$ and $f_{max} = f(t_{max})$ [S1].
2. **Check for Sign Change:** If $f_{min}$ and $f_{max}$ have the same sign, no root is guaranteed in this interval [S1].
3. **Iterative Refinement:** Initialize $t_{left} = t_{min}$, $t_{right} = t_{max}$, $f_{left} = f_{min}$, $f_{right} = f_{max}$ [S1]. Loop until convergence or $N_{max}$: calculate midpoint $t_{mid} = \frac{t_{left} + t_{right}}{2}$, evaluate $f_{mid} = f(t_{mid})$ [S1]. If $|t_{right} - t_{left}| < \epsilon$ or $|f_{mid}| < \epsilon$, return $t_{mid}$ [S3, unofficial]. If $f_{left} \cdot f_{mid} < 0$, set $t_{right} = t_{mid}$, $f_{right} = f_{mid}$; else set $t_{left} = t_{mid}$, $f_{left} = f_{mid}$ [S1].
4. **Return Result:** Return $t_{mid}$ or the final interval midpoint [S1].

**Pseudocode:**
```python
def neubauer_root_finder(f, t_min, t_max, epsilon=4.0e-3, max_iter=50):
    """
    Finds the root of f(t) in [t_min, t_max] using iterative bisection.
    f: callable, returns scalar value for parameter t.
    """
    f_left = f(t_min)
    f_right = f(t_max)
    
    # Check if a root exists in the interval
    if f_left * f_right > 0:
        return None  # No sign change, root not guaranteed
    
    # Handle exact zero at boundaries
    if abs(f_left) < epsilon:
        return t_min
    if abs(f_right) < epsilon:
        return t_max

    t_left = t_min
    t_right = t_max
    
    for _ in range(max_iter):
        t_mid = (t_left + t_right) / 2.0
        f_mid = f(t_mid)
        
        # Check convergence based on interval width or function value
        if abs(t_right - t_left) < epsilon or abs(f_mid) < epsilon:
            return t_mid
            
        # Bisection step
        if f_left * f_mid < 0:
            t_right = t_mid
            f_right = f_mid
        else:
            t_left = t_mid
            f_left = f_mid
            
    return (t_left + t_right) / 2.0  # Return best estimate if max iter reached
```

**Parameters:**
- $\epsilon$: Convergence threshold. Typical value: $4.0 \cdot 10^{-3}$ [S3, unofficial].
- $N_{max}$: Maximum iterations. Typical value: 50 [S3, unofficial].

**Edge Cases and Pitfalls:**
- **No Sign Change:** If the ray grazes the surface or misses it, $f(t_{min})$ and $f(t_{max})$ may have the same sign [S1].
- **Multiple Roots:** The basic bisection finds one root; handling multiple intersections requires additional logic not covered by the core method [G].
- **Precision:** Single-precision arithmetic is numerically stable, unlike some analytical cubic solvers which may suffer from catastrophic cancellation [S1][S2, unofficial].

## Subtopics

### Newton–Raphson Voxel Intersection
A voxel intersection method using the Newton–Raphson iterative solver [S3, unofficial]. It uses the polynomial split from Marmitt et al. [2004] but replaces repeated linear interpolation with Newton–Raphson iteration [S3, unofficial]. Maximum number of iterations: 50. Epsilon threshold for convergence: $\epsilon = 4.0 \cdot 10^{-3}$; iteration stops if the difference between two subsequent $t$-values is less than this value [S3, unofficial].

### Boundary Intersection Handling
Handling the case where the line between entry point $g_{In}$ and exit point $g_{Out}$ intersects the boundary of the volume block, which can cause surface approximation to miss intersections in tessellation [S4]. Handling spline degeneracies where the Jacobian $J_\phi$ is singular at the entry point $g_{In}$, causing linear systems in root finding and ODE methods to have singular matrices [S4]. For Explicit Runge-Kutta methods, clamp the approximated solution values to remain in parameter domain $P$ [S4]. Find the new entry point $\tilde{p}_{In}$ in parameter domain $P$ using the root finding method with a different starting point for Newton-Raphson iterations: $x_0 = p_{In} + \epsilon \frac{p_{Out} - p_{In}}{\|p_{Out} - p_{In}\|_{L2}}$, with an appropriately chosen $\epsilon$ [S4]. For Implicit Euler and Root Finding methods, the Newton-Raphson method fails to converge and repeatedly tries to exit the parameter domain $P$; detect this behavior and step along the boundary of the parameter domain until the view-ray is within the domain again [S4].

## Background
Proposed by Marmitt et al. [13] (also cited as [75] in [S2, unofficial]), based on the Neubauer iterative root finder [S1][S2, unofficial]. It was used in the context of interactive isosurface ray tracing of large octree volumes [S1][S2, unofficial]. The method was compared against analytical solvers like Schwarze's cubic solver [S1][S2, unofficial].
