# Recursive Short-Stack Bézier Clipping

Also called: Modified Bézier Clipping, Optimized Bézier Clipping

## Overview
Recursive Short-Stack Bézier Clipping is a GPU-optimized algorithm for finding the intersection of a ray with a Bézier curve or surface parameterized as a curve in the clipping dimension [S1]. It solves the problem of efficiently locating roots of a polynomial function defined by Bézier control points while minimizing register usage and avoiding expensive convex hull intersection tests [S1]. It distinguishes itself from standard iterative Bézier Clipping by using a fixed-size stack to limit recursion depth and by aggressively splitting the control polygon when sign changes exceed two, thereby reducing the number of expensive geometric tests required [S1].

## How it works
**Inputs:**
- A set of Bézier control points $P_0, P_1, \dots, P_n$ defining the curve segment [G].
- A convergence threshold $\epsilon$ (typically $10^{-4}$) [S1].
- A maximum stack size $S_{\text{max}}$ (typically 3) [S1].

**Outputs:**
- The parameter $t \in [0, 1]$ where the curve intersects the axis (zero-crossing), or an indication that no intersection exists within the segment [G].

**Data Structures:**
- **Stack:** A fixed-size array of control point sets with capacity $S_{\text{max}}$. The stack stores sub-segments of the control polygon that require further processing [G].
- **Control Points:** Represented as scalar values along the axis of interest (e.g., signed distance from the ray to the surface, or polynomial value) [G].

**Algorithm Steps:**
1. Count the number of sign changes $k$ in the sequence of control point values along the axis.
2. If $k = 0$, the convex hull does not intersect the axis; discard the segment and do not solve [S1].
3. If $k > 2$, split the control polygon into two halves beforehand; push both resulting sub-segments onto the stack [S1].
4. If $k = 1$, perform the relatively expensive intersection test between the convex hull and the axis to find the root [S1].
5. Push control points onto the stack only after ensuring their convex hull intersects the axis [S1].
6. Repeat until the stack is empty or a root is found within $\epsilon$.

**Formulas:**
- **Sign Change Count:** For a sequence $v_0, v_1, \dots, v_n$, the number of sign changes is the count of indices $i$ such that $v_i \cdot v_{i+1} < 0$ [G].
- **Subdivision (de Casteljau):** To split a Bézier curve at parameter $t$, the new control points $Q_i$ are computed recursively:
  $$ Q_i^{(0)} = P_i, \quad Q_i^{(r)} = (1-t)Q_i^{(r-1)} + tQ_{i+1}^{(r-1)} $$
  The left sub-curve control points are the first elements of each iteration level, and the right sub-curve control points are the last elements of each iteration level [G].
- **Convergence:** The segment width is measured as $\max(P) - \min(P)$. Iteration stops when width $\le \epsilon$ [G].

**Parameters:**
- Convergence threshold: $10^{-4}$ [S1].
- Stack size: 3 [S1].

**Edge Cases and Pitfalls:**
- **Precision:** Floating-point precision errors may cause sign changes to be detected incorrectly near zero. Robust handling of zero values (e.g., treating them as positive or skipping) is required [G].
- **Degenerate Input:** If all control points are zero, the curve lies on the axis. The algorithm should handle this by returning the midpoint or a valid range [G].
- **Stack Overflow:** The fixed stack size limits recursion depth. The method assumes a stack size of 3 is sufficient for typical cases [S1].

**Pseudocode:**
```python
def recursive_short_stack_bezier_clipping(control_points, epsilon=1e-4, stack_size=3):
    """
    Finds the root of a Bézier curve defined by control_points.
    control_points: list of scalar values representing control points along the axis.
    epsilon: convergence threshold.
    stack_size: maximum size of the stack.
    Returns: t (float) or None if no intersection found.
    """
    stack = [control_points]
    
    while stack:
        current_points = stack.pop()
        n = len(current_points) - 1
        
        # Count sign changes
        sign_changes = 0
        for i in range(n):
            if current_points[i] * current_points[i+1] < 0:
                sign_changes += 1
        
        if sign_changes == 0:
            # No intersection
            continue
        elif sign_changes > 2:
            # Split the polygon into two halves
            left_points, right_points = de_casteljau_subdivide(current_points, 0.5)
            if len(stack) < stack_size:
                stack.append(left_points)
                stack.append(right_points)
        elif sign_changes == 1:
            # Perform expensive intersection test between convex hull and axis
            t = convex_hull_axis_intersection(current_points)
            if t is not None:
                # Check convergence
                width = max(current_points) - min(current_points)
                if width <= epsilon:
                    return t
                else:
                    # Split at t and push sub-segments
                    left_points, right_points = de_casteljau_subdivide(current_points, t)
                    if len(stack) < stack_size:
                        stack.append(left_points)
                        stack.append(right_points)
    
    return None

def de_casteljau_subdivide(points, t):
    """
    Subdivides a Bézier curve at parameter t using de Casteljau's algorithm.
    Returns (left_control_points, right_control_points).
    """
    n = len(points) - 1
    left = []
    right = []
    current_level = points[:]
    
    for _ in range(n + 1):
        left.append(current_level[0])
        right.append(current_level[-1])
        next_level = []
        for j in range(len(current_level) - 1):
            next_level.append((1 - t) * current_level[j] + t * current_level[j + 1])
        current_level = next_level
        
    return left, right

def convex_hull_axis_intersection(points):
    """
    Finds the intersection of the convex hull of the control points with the axis.
    Since sign_changes == 1, exactly one pair of adjacent points straddles zero.
    Returns t in [0, 1] or None.
    """
    for i in range(len(points) - 1):
        if points[i] * points[i+1] < 0:
            # Linear interpolation between the straddling control points
            t = points[i] / (points[i] - points[i+1])
            return t
    return None
```

## Operating characteristics
- **Time Complexity:** The algorithm reduces the number of iterations significantly compared to standard Bézier Clipping. Pabst et al.'s method used 16.4 iterations on average (max 29), while this method uses 2.3 iterations on average (max 8) [S1].
- **Memory Complexity:** Uses a fixed-size stack of size 3, minimizing register usage on the GPU [S1].
- **Performance:** Achieves approximately double the overall speedup of standard Bézier Clipping [S1].
- **Strengths:** Efficient on GPU due to fixed stack size and reduced intersection tests. Robust against degenerate cases where the convex hull barely intersects the axis [S1].
- **Limitations:** The fixed stack size may require careful handling if the recursion depth exceeds the limit, though the source claims a size of 3 is sufficient [S1].

## Background
The method is presented in [S1]. It builds on the iterative Bézier Clipping method by Pabst et al. [PSS∗06] and the recursive algorithm by Nishita et al. [NSK90]. The key innovation is the modification of the splitting strategy to occur early when sign changes exceed two, addressing a flaw pointed out by Campagna et al. [CSS97] where the convex hull barely intersects the axis. The method was tested on an NVIDIA GeForce 8800 Ultra graphics card using Wyvill et al.'s degree-six polynomial for metaballs [WMW86].
