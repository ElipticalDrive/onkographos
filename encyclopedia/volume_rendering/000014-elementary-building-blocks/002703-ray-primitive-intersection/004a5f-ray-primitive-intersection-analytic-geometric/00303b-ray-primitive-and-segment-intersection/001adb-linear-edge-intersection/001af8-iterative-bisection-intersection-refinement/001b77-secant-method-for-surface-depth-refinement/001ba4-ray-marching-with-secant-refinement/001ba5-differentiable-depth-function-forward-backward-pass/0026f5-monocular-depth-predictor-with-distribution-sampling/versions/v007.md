# Monocular Depth Predictor with Distribution Sampling

Also called: Depth Prediction via Discrete Distribution Sampling, DepthPredictorMonocular

## Overview
A neural network module that predicts a depth distribution for each ray from image features by discretizing the depth range into buckets, predicting a probability density function (PDF) and intra-bucket offsets, and sampling from this distribution to determine depth values [S1, unofficial]. It differs from standard cost volume aggregation by explicitly modeling the uncertainty of depth hypotheses via a learnable projection and sampling mechanism, allowing for differentiable depth extraction and direct integration into ray marching pipelines [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** `features` tensor of shape `[batch, view, ray, surface, depth, 2]` containing raw logits for PDF and offset [S1, unofficial].
*   **Input:** `near` tensor of shape `[batch, view]` specifying the near plane distance [S1, unofficial].
*   **Input:** `far` tensor of shape `[batch, view]` specifying the far plane distance [S1, unofficial].
*   **Input:** `deterministic` boolean flag controlling sampling behavior [S1, unofficial].
*   **Input:** `gaussians_per_pixel` integer specifying the number of samples to draw from the depth distribution [S1, unofficial].
*   **Input:** `use_transmittance` boolean flag determining opacity calculation method [S1, unofficial].
*   **Output:** `depth` tensor of shape `[batch, view, ray, surface, sample]` containing the sampled absolute depths [S1, unofficial].
*   **Output:** `pdf` tensor of shape `[batch, view, ray, surface, sample]` containing the sampled PDF densities [S1, unofficial].
*   **Output:** `opacity` tensor of shape `[batch, view, ray, surface, sample]` containing the computed opacities [S1, unofficial].

**Data Structures:**
The core component is the `DepthPredictorMonocular` class, which maintains the following state:
*   `projection`: An `nn.Sequential` module containing a `ReLU` activation followed by a `Linear` layer mapping input dimension `d_in` to `2 * num_samples * num_surfaces` [S1, unofficial].
*   `sampler`: A `DistributionSampler` instance responsible for discrete sampling and gathering [S1, unofficial].
*   `to_pdf`: An `nn.Softmax` layer applied along the last dimension to normalize PDF values [S1, unofficial].
*   `to_offset`: An `nn.Sigmoid` layer to bound offset values to $[0, 1]$ [S1, unofficial].
*   `num_samples`: Integer defining the number of depth buckets per surface [S1, unofficial].
*   `num_surfaces`: Integer defining the number of distinct surfaces to model [S1, unofficial].
*   `use_transmittance`: Boolean flag for opacity computation [S1, unofficial].

**Steps:**
1.  **Projection:** Pass the input `features` through `self.projection` to obtain raw logits. The output shape is rearranged from `... (dpt srf c)` to `c ... srf dpt` where $c=2$, separating `pdf_raw` and `offset_raw` [S1, unofficial].
2.  **Normalization:**
    *   Apply `self.to_pdf` (Softmax) to `pdf_raw` along the last dimension to produce a valid probability distribution `pdf` [S1, unofficial].
    *   Apply `self.to_offset` (Sigmoid) to `offset_raw` to produce intra-bucket offsets `offset` in the range $[0, 1]$ [S1, unofficial].
3.  **Sampling:** Use `self.sampler.sample(pdf, deterministic, gaussians_per_pixel)` to draw `index` (integer bucket indices) and `pdf_i` (PDF densities) from the distribution [S1, unofficial].
4.  **Offset Gathering:** Gather the intra-bucket offsets corresponding to the sampled indices: `offset = self.sampler.gather(index, offset)` [S1, unofficial].
5.  **Relative Disparity Calculation:** Compute the relative disparity for each sample using the formula:
    $$relative\_disparity = \frac{index + offset}{s}$$
    where $s$ is the total number of samples (buckets), i.e., `num_samples` [S1, unofficial].
6.  **Depth Conversion:** Convert relative disparity to absolute depth using the `near` and `far` planes via `relative_disparity_to_depth(relative_disparity, near, far)` [S1, unofficial].
7.  **Opacity Calculation:**
    *   If `use_transmittance` is true:
        *   Calculate the cumulative sum of the PDF along the depth dimension: `partial = pdf.cumsum(dim=-1)` [S1, unofficial].
        *   Shift the cumulative sum to align with the previous bucket's transmittance: `partial = torch.cat((torch.zeros_like(partial[..., :1]), partial[..., :-1]), dim=-1)` [S1, unofficial].
        *   Compute opacity using the PDF and the shifted cumulative sum (approximating transmittance):
            $$opacity = \frac{pdf}{1 - partial + 10^{-10}}$$
            The epsilon $10^{-10}$ is added for numerical stability [S1, unofficial].
        *   Gather the computed opacity values for the sampled indices: `opacity = self.sampler.gather(index, opacity)` [S1, unofficial].
    *   If `use_transmittance` is false:
        *   Set opacity directly to the sampled PDF density: `opacity = pdf_i` [S1, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn as nn

class DepthPredictorMonocular(nn.Module):
    def __init__(self, d_in, num_samples, num_surfaces, use_transmittance=True):
        super().__init__()
        self.num_samples = num_samples
        self.num_surfaces = num_surfaces
        self.use_transmittance = use_transmittance
        
        # Projection layer: maps input features to raw PDF and offset logits
        # Output dimension: 2 * num_samples * num_surfaces
        self.projection = nn.Sequential(
            nn.ReLU(),
            nn.Linear(d_in, 2 * num_samples * num_surfaces)
        )
        
        # Normalization hooks
        self.to_pdf = nn.Softmax(dim=-1)
        self.to_offset = nn.Sigmoid()
        
        # Sampler instance (assumed to handle discrete sampling and gathering)
        self.sampler = DistributionSampler()

    def forward(self, features, near, far, deterministic=False, gaussians_per_pixel=None, use_transmittance=None):
        """
        Args:
            features: Float[Tensor, "batch view ray surface depth 2"]
            near: Float[Tensor, "batch view"]
            far: Float[Tensor, "batch view"]
            deterministic: bool
            gaussians_per_pixel: int (optional, defaults to num_samples if not provided)
            use_transmittance: bool (optional, defaults to self.use_transmittance)
            
        Returns:
            depth: Float[Tensor, "batch view ray surface sample"]
            pdf: Float[Tensor, "batch view ray surface sample"]
            opacity: Float[Tensor, "batch view ray surface sample"]
        """
        if gaussians_per_pixel is None:
            gaussians_per_pixel = self.num_samples
        if use_transmittance is None:
            use_transmittance = self.use_transmittance

        # Step 1: Project features
        # features shape: (batch, view, ray, surface, depth, 2)
        # projection output shape: (batch, view, ray, surface, depth, 2 * num_samples * num_surfaces)
        projected = self.projection(features)
        
        # Step 2: Rearrange and Normalize
        # Rearrange to separate PDF and Offset channels
        # New shape: (2, batch, view, ray, surface, depth, num_samples)
        # Note: The source describes rearranging "... (dpt srf c) -> c ... srf dpt"
        # Assuming 'depth' in input corresponds to 'dpt' in rearrange and 'num_samples' is the bucket count.
        # The source implies the last dimension of projected is split into c=2, srf=num_surfaces, dpt=num_samples.
        # However, input 'features' has 'depth' dim. Let's assume 'depth' in input is the bucket index dimension.
        # Rearrangement logic from source: pdf_raw, offset_raw = rearrange(features, "... (dpt srf c) -> c ... srf dpt", c=2, srf=self.num_surfaces)
        # This implies the input to rearrange has shape ending in (num_samples * num_surfaces * 2).
        # Let's assume the 'depth' dimension in 'features' is actually the bucket dimension 'num_samples'.
        
        # Reshape projected to group the last dimensions correctly for rearrange
        # projected shape: (..., depth, 2 * num_samples * num_surfaces)
        # We need to reshape the last dim to (num_samples, num_surfaces, 2) then permute
        b, v, r, s, d, _ = projected.shape
        # Reshape last dim to (num_samples, num_surfaces, 2)
        projected = projected.view(b, v, r, s, d, self.num_samples, self.num_surfaces, 2)
        # Permute to (2, b, v, r, s, d, num_samples) -> (2, b, v, r, s, num_samples, d) ?
        # Source says: c ... srf dpt. c=2. ... is batch view ray. srf=num_surfaces. dpt=num_samples.
        # So output should be (2, batch, view, ray, num_surfaces, num_samples)
        # But input 'features' has 'depth' dim. Let's assume 'depth' in input is 'num_samples'.
        # So d = num_samples.
        
        # Let's stick to the source's rearrange signature directly on the projected tensor if it matches.
        # If features input is (batch, view, ray, surface, depth, 2), and we project to (..., 2*srf*dpt),
        # then rearrange(... (dpt srf c) -> c ... srf dpt) expects the last dim to be dpt*srf*c.
        # Here dpt=num_samples, srf=num_surfaces, c=2.
        # So we reshape projected to (batch, view, ray, num_samples, num_surfaces, 2)
        projected = projected.view(b, v, r, self.num_samples, self.num_surfaces, 2)
        # Now rearrange
        # pdf_raw, offset_raw shape: (2, batch, view, ray, num_surfaces, num_samples)
        pdf_raw, offset_raw = torch.unbind(projected, dim=-1) # Split last dim 2 into 2 tensors
        # pdf_raw: (batch, view, ray, num_surfaces, num_samples)
        # offset_raw: (batch, view, ray, num_surfaces, num_samples)
        
        # Apply Softmax to pdf_raw along the last dimension (num_samples)
        pdf = self.to_pdf(pdf_raw)
        # Apply Sigmoid to offset_raw
        offset = self.to_offset(offset_raw)
        
        # Step 3: Sample
        # sampler.sample returns index and pdf_i
        # index shape: (batch, view, ray, num_surfaces, gaussians_per_pixel)
        # pdf_i shape: (batch, view, ray, num_surfaces, gaussians_per_pixel)
        index, pdf_i = self.sampler.sample(pdf, deterministic, gaussians_per_pixel)
        
        # Step 4: Gather Offsets
        # Gather offsets for the sampled indices
        # offset shape: (batch, view, ray, num_surfaces, num_samples)
        # index shape: (batch, view, ray, num_surfaces, gaussians_per_pixel)
        # Gathered offset shape: (batch, view, ray, num_surfaces, gaussians_per_pixel)
        offset = self.sampler.gather(index, offset)
        
        # Step 5: Relative Disparity
        # s = num_samples
        s = self.num_samples
        relative_disparity = (index + offset) / s
        
        # Step 6: Depth Conversion
        # relative_disparity_to_depth is a helper function
        depth = relative_disparity_to_depth(relative_disparity, near, far)
        
        # Step 7: Opacity
        if use_transmittance:
            # Cumsum along the depth dimension (num_samples)
            partial = pdf.cumsum(dim=-1)
            # Shift partial
            zeros = torch.zeros_like(partial[..., :1])
            partial = torch.cat((zeros, partial[..., :-1]), dim=-1)
            # Compute opacity
            # pdf shape: (batch, view, ray, num_surfaces, num_samples)
            # partial shape: (batch, view, ray, num_surfaces, num_samples)
            opacity_raw = pdf / (1 - partial + 1e-10)
            # Gather opacity
            opacity = self.sampler.gather(index, opacity_raw)
        else:
            opacity = pdf_i
            
        return depth, pdf, opacity

def relative_disparity_to_depth(relative_disparity, near, far):
    """
    Converts relative disparity to absolute depth.
    Formula: depth = 1 / ( (1/near) * (1 - relative_disparity) + (1/far) * relative_disparity )
    Or similar inverse depth interpolation.
    Source does not give explicit formula for this helper, but standard inverse depth interpolation is:
    inv_depth = (1 - rd) / near + rd / far
    depth = 1 / inv_depth
    """
    inv_near = 1.0 / near
    inv_far = 1.0 / far
    inv_depth = (1.0 - relative_disparity) * inv_near + relative_disparity * inv_far
    return 1.0 / inv_depth

class DistributionSampler:
    def sample(self, pdf, deterministic, gaussians_per_pixel):
        """
        Samples indices and PDF values from the distribution.
        pdf shape: (..., num_samples)
        Returns:
            index: (..., gaussians_per_pixel)
            pdf_i: (..., gaussians_per_pixel)
        """
        if deterministic:
            # e.g., top-k or argmax
            # For simplicity, assume top-gaussians_per_pixel
            k = gaussians_per_pixel
            values, indices = torch.topk(pdf, k, dim=-1)
            return indices, values
        else:
            # Categorical sampling
            # pdf is already normalized
            indices = torch.multinomial(pdf.view(-1, pdf.shape[-1]), gaussians_per_pixel, replacement=True)
            # Reshape indices back
            indices = indices.view(*pdf.shape[:-1], gaussians_per_pixel)
            # Gather PDF values
            # pdf_i = pdf.gather(-1, indices)
            # Using advanced indexing
            pdf_i = torch.gather(pdf, -1, indices)
            return indices, pdf_i

    def gather(self, index, tensor):
        """
        Gathers values from tensor along the last dimension using index.
        tensor shape: (..., num_samples)
        index shape: (..., gaussians_per_pixel)
        Returns: (..., gaussians_per_pixel)
        """
        return torch.gather(tensor, -1, index)
```

**Edge Cases and Pitfalls:**
*   **Numerical Stability:** When computing opacity via transmittance, a small epsilon ($10^{-10}$) is added to the denominator to prevent division by zero [S1, unofficial].
*   **Boundary Conditions:** The `near` and `far` planes must be positive and `near < far`. If `near` is not provided, the implementation defaults to projecting at zero depth, handling origins at the camera position by using the direction vector [S1, unofficial].
*   **Degenerate Input:** If the origin's depth is within epsilon of zero and it is not at the camera position, the projection is marked invalid [S1, unofficial].

## Subtopics

### [Depth Probability Volume Estimation](8538-depth-probability-volume-estimation.md)
Constructs a 3D representation where each voxel encodes the probability density of surface depth along a ray, derived from multi-view feature consistency. It differs from standard cost volume aggregation by explicitly modeling uncertainty via a 3D CNN, enabling differentiable depth extraction. Choose this when robust depth estimation in multi-view stereo is required.

## Operating characteristics
*   **Time Complexity:** Dominated by the linear projection and softmax operations, which are $O(N \cdot D \cdot S)$ where $N$ is the number of pixels/rays, $D$ is the number of depth buckets, and $S$ is the number of surfaces. Sampling is $O(N \cdot S \cdot G)$ where $G$ is the number of gaussians per pixel.
*   **Memory Complexity:** Requires storing the projected logits and the PDF distribution for all buckets and surfaces, $O(N \cdot D \cdot S)$.
*   **Strengths:** Differentiable end-to-end learning of depth distributions; handles multi-surface scenes; provides uncertainty estimates via PDF.
*   **Limitations:** Discretization error depends on the number of buckets; sampling can introduce noise if not deterministic.
*   **When to use:** When predicting depth from monocular images in a differentiable rendering pipeline, especially when multi-surface or uncertainty modeling is needed.
*   **When not to use:** When real-time performance is critical and the overhead of distribution sampling is prohibitive, or when a single deterministic depth map is sufficient without uncertainty.

## Background
The method originates from the PixelSplat framework, which uses a neural network to predict depth distributions for ray marching in novel view synthesis [S1, unofficial]. It builds on the concept of differentiable depth functions, allowing gradients to flow through the depth prediction to the decoder parameters and latent code [S1, unofficial].
