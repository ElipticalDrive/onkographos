# Inverse Linear Interpolation

Also called: Linear Interpolation Position

## Overview
Inverse Linear Interpolation calculates the non-integer position $x$ corresponding to a specific scalar value $v$ between two known values $v_1$ and $v_2$ at positions $x_1$ and $x_2$, assuming linear variation [S1, unofficial]. It is primarily used for finding iso-surface intersections or specific density levels within a volume [S1, unofficial]. Unlike [Linear Edge Intersection](868-linear-edge-intersection.md), which computes the exact intersection on a grid edge, this method provides the general algebraic inversion of linear interpolation [S1, unofficial].

## How it works
**Inputs:**
- $v$: The target scalar value (e.g., isovalue).
- $v_1$: The scalar value at position $x_1$.
- $v_2$: The scalar value at position $x_2$.
- $x_1$: The position of the first sample point.
- $x_2$: The position of the second sample point.

**Outputs:**
- $x$: The interpolated position where the scalar value equals $v$.

**Data Structures:**
- Standard floating-point variables for positions and values. No complex structures are required.

**Steps:**
1. Calculate the difference in positions: $\Delta x = x_2 - x_1$.
2. Calculate the difference in values: $\Delta v = v_2 - v_1$.
3. Compute the fractional distance along the segment: $f = \frac{v - v_1}{\Delta v}$.
4. Compute the final position: $x = x_1 + \Delta x \times f$.

**Formula:**
$$x = x_1 + (x_2 - x_1) \times \frac{v - v_1}{v_2 - v_1}$$

**Parameters:**
- Not given in the sources.

**Edge Cases and Pitfalls:**
- **Division by Zero:** If $v_1 = v_2$, the denominator is zero. This occurs when the scalar field is constant between the two points. The method is undefined in this case [S1, unofficial].
- **Precision:** Standard floating-point arithmetic is used. No specific precision requirements are noted beyond standard double precision in the source implementation [S1, unofficial].

**Pseudocode:**
```python
def inverse_linear_interpolation(v, v1, v2, x1, x2):
    """
    Calculates the position x where the scalar value is v,
    given values v1 at x1 and v2 at x2.
    """
    # Calculate denominator
    denom = v2 - v1
    
    # Handle division by zero if values are identical
    if denom == 0:
        # Undefined behavior; return midpoint or handle as error
        # [G] Implementation choice: return midpoint to avoid NaN
        return (x1 + x2) / 2.0
        
    # Calculate fractional distance
    fraction = (v - v1) / denom
    
    # Calculate position
    x = x1 + (x2 - x1) * fraction
    
    return x
```

## Subtopics

### Approximate Projection
A variant used in point-based rendering (Iso-splatting) that projects a sample point onto an isosurface using a single step of the Newton-Raphson method [S2].

**Steps:**
1. Calculate the scalar function value $f(x_0)$ and its gradient $\nabla f(x_0)$ at the sample point $x_0$ (where $x_0 = p_\lambda$) [S2].
2. Compute the displacement parameter $t$ [S2]:
   - For univariate functions: $t = \frac{f_I - f(x_0)}{f'(x_0)f'(x_0)}$ [S2].
   - For trivariate functions: $t = \frac{f_I - f(x_0)}{\nabla f(x_0) \cdot \nabla f(x_0)}$ [S2].
3. Compute the projected point $p'_\lambda = x_0 + t \nabla f(x_0)$ [S2].
4. Apply a displacement criterion: if the distance between $p'_\lambda$ and $x_0$ exceeds $\Delta d$, discard the point [S2].

**Formula:**
- Univariate: $t = \frac{f_I - f(x_0)}{f'(x_0)^2}$ [S2].
- Trivariate: $t = \frac{f_I - f(x_0)}{\|\nabla f(x_0)\|^2}$ [S2].

**Parameters:**
- Displacement threshold $\Delta d$: The maximum allowed distance for a valid projection. It is determined by cell dimensions $s_x, s_y, s_z$ as $\Delta d = \frac{1}{2} \sqrt{s_x^2 + s_y^2 + s_z^2}$ [S2].

**Pitfalls:**
- The Newton-Raphson method may converge to roots far away from the desired root if the initial guess $x_0$ is near a local maximum or minimum [S2]. The displacement criterion is used to mitigate this [S2].

## Operating characteristics
- **Time Complexity:** $O(1)$ per interpolation.
- **Memory Complexity:** $O(1)$.
- **Strengths:** Simple, fast, and exact for linear fields.
- **Limitations:** Assumes linear variation between sample points; inaccurate for highly non-linear fields. Sensitive to division by zero if values are identical.
- **When to use:** When linear interpolation is a valid assumption for the scalar field between two points.
- **When not to use:** When the field is non-linear or when $v_1 \approx v_2$.

## Background
Inverse Linear Interpolation is a fundamental technique in volume rendering and computer graphics for determining positions along a line segment based on scalar values. It is derived directly from the definition of linear interpolation. The method is implemented in various educational and research codebases for volume rendering, such as the CT viewer by Josh Codd [S1, unofficial]. The Approximate Projection variant is described in the context of Iso-splatting, a point-based alternative to isosurface visualization [S2].
