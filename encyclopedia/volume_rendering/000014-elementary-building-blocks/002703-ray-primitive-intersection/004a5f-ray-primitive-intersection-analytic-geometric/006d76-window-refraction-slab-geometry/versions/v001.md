# Window Refraction (Slab Geometry)
Also called: Slab Refraction, Parallel-Sided Window Refraction

## Overview
This method models the propagation of light rays through a parallel-sided glass slab (such as a window), calculating refraction at the first interface, linear propagation through the medium, and refraction at the second interface [S1, unofficial]. It distinguishes itself from simple transmission or single-surface refraction by explicitly handling the displacement and angular change caused by traversing a finite thickness of material with a different refractive index [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs**: Incident rays defined by origin $\mathbf{o}$ and direction $\mathbf{d}$ (normalized); slab geometry defined by two parallel planes (left and right interfaces); refractive indices $n_{ext}$ (external) and $n_{glass}$ (internal).
*   **Outputs**: Refracted rays with updated origins (exit points), updated directions, and transmission coefficients.

**Data Structures**
Rays are represented as tensors containing:
*   `origins`: $(N, 3)$ tensor of 3D coordinates.
*   `directions`: $(N, 3)$ tensor of normalized direction vectors.
*   `luminosities`: $(N,)$ tensor of intensity values.
*   `meta`: Additional metadata (e.g., wavelength, ID).

**Parameters**
*   $n_{ext}$: Refractive index of the external medium.
*   $n_{glass}$: Refractive index of the slab material.
*   $\mu = n_{glass} / n_{ext}$: Relative refractive index ratio [S1, unofficial].

**Steps**
1.  **Interface Intersection**: Calculate the intersection parameter $t$ for the ray with both the left and right interfaces of the slab. Let $t_{left}$ and $t_{right}$ be these values [S1, unofficial].
2.  **Entry Point Selection**: Determine the entry point $t_{entry}$ as the minimum of $t_{left}$ and $t_{right}$, excluding invalid intersections (e.g., rays originating inside or behind the slab). If an intersection is invalid, set $t$ to NaN [S1, unofficial].
3.  **Masking**: Create a boolean mask `valid_mask` identifying rays that successfully intersect the first interface ($t_{entry}$ is not NaN) [S1, unofficial].
4.  **Internal Ray Construction**: For valid rays, compute the entry point $\mathbf{p}_{entry} = \mathbf{o} + t_{entry} \mathbf{d}$ and the surface normal $\mathbf{n}$ at the entry interface [S1, unofficial].
5.  **First Refraction**: Compute the refracted direction $\mathbf{d}_{glass}$ inside the slab using Snell's Law [S1, unofficial]:
    $$ c = \mathbf{n} \cdot \mathbf{d} $$
    $$ \text{tmp} = 1 - \mu^2 (1 - c^2) $$
    $$ \mathbf{d}_{glass} = \sqrt{\text{tmp}} \mathbf{n} + \mu (\mathbf{d} - c \mathbf{n}) $$
    *Note: If $\text{tmp} < 0$, total internal reflection occurs, and the ray is considered lost or reflected (not refracted through the slab) [G].*
6.  **Exit Intersection**: Calculate the intersection parameter $t_{exit}$ for the internal ray (origin $\mathbf{p}_{entry}$, direction $\mathbf{d}_{glass}$) with the second interface [S1, unofficial].
7.  **Validity Check**: Update the mask. If $t_{exit}$ is NaN (ray misses the second interface or total internal reflection occurred), the ray is discarded from the refracted output [S1, unofficial].
8.  **Exit Point and Second Refraction**: For rays passing the validity check:
    *   Compute exit point: $\mathbf{p}_{exit} = \mathbf{p}_{entry} + t_{exit} \mathbf{d}_{glass}$ [S1, unofficial].
    *   Compute exit normal $\mathbf{n}_{exit}$ (parallel to $\mathbf{n}$ but pointing outward).
    *   Compute final refracted direction $\mathbf{d}_{out}$ using Snell's Law with ratio $1/\mu$ [G].
9.  **Transmission Coefficient**: Calculate the transmission coefficient $T$ using the Fresnel equations based on the incident angle at the first interface [S1, unofficial]:
    $$ T = \text{fresnel\_transmission}(\arccos(c), n_{ext}, n_{glass}) $$
10. **Output Assembly**: Return new rays with:
    *   Origin: $\mathbf{p}_{exit}$
    *   Direction: $\mathbf{d}_{out}$
    *   Luminosity: $L_{out} = L_{in} \times T$

**Pseudocode**
```python
import torch
import math

def window_refraction_slab(
    origins: torch.Tensor,      # (N, 3)
    directions: torch.Tensor,   # (N, 3), normalized
    luminosities: torch.Tensor, # (N,)
    n_ext: float,
    n_glass: float,
    get_ray_intersection_left_interface, # Function returning t for left plane
    get_ray_intersection_right_interface, # Function returning t for right plane
    get_rays_inside_window # Function returning (ray_in_glass, normal)
):
    """
    Models refraction through a parallel-sided slab.
    """
    # 1. Calculate intersection times with left and right interfaces
    t_left = get_ray_intersection_left_interface(origins, directions)
    t_right = get_ray_intersection_right_interface(origins, directions)
    
    # 2. Select minimum t; set inf/invalid to NaN
    # Assuming get_ray_intersection returns NaN for no intersection
    t_entry = torch.where(t_right < t_left, t_right, t_left)
    
    # 3. Filter rays that intersect the first interface
    mask = ~torch.isnan(t_entry)
    
    if not mask.any():
        return origins, directions, luminosities, mask # No valid rays
        
    # 4. Compute rays inside the window
    # This helper typically computes entry point and normal
    # Returns: (origins_inside, directions_inside, normals)
    origins_inside, directions_inside, normals = get_rays_inside_window(
        origins[mask], directions[mask], t_entry[mask]
    )
    
    # 5. Calculate intersection with second interface
    # get_t_min finds the smallest positive t for the second plane
    t_exit = get_t_min(origins_inside, directions_inside)
    
    # 6. Update mask for rays that hit the second interface
    valid_exit = ~torch.isnan(t_exit)
    final_mask = mask & valid_exit
    
    # 7. Compute refracted properties for valid rays
    # Extract valid data
    v_origins = origins[final_mask]
    v_dirs = directions[final_mask]
    v_lum = luminosities[final_mask]
    v_normals = normals[valid_exit] # Corresponding normals for valid exit rays
    
    # Relative refractive index
    mu = n_glass / n_ext
    
    # Snell's Law components
    # c = n . d (dot product of normal and incident direction)
    c = torch.sum(v_normals * v_dirs, dim=1)
    
    # tmp = 1 - mu^2 * (1 - c^2)
    tmp = 1.0 - (mu ** 2) * (1.0 - (c ** 2))
    
    # Handle total internal reflection (tmp < 0)
    # In this specific slab implementation, if tmp < 0, the ray doesn't refract
    # We assume get_rays_inside_window or t_exit logic already handles
    # rays that don't propagate, but we safeguard here.
    valid_refraction = tmp >= 0
    final_mask = final_mask & valid_refraction
    
    # Refracted direction inside glass
    # d_glass = sqrt(tmp) * n + mu * (d - c * n)
    d_glass = torch.sqrt(tmp.unsqueeze(1)) * v_normals + mu * (v_dirs - c.unsqueeze(1) * v_normals)
    
    # Exit point calculation
    # t_exit is already computed for the internal ray
    # p_exit = p_entry + t_exit * d_glass
    # Note: origins_inside are the entry points
    p_exit = origins_inside[valid_refraction] + t_exit[valid_refraction].unsqueeze(1) * d_glass[valid_refraction]
    
    # Second refraction (Glass to External)
    # Normal at exit is same as entry normal but pointing outward? 
    # For parallel slab, normal vector direction relative to ray matters.
    # Assuming normals passed are consistent with entry.
    # For exit, we refract from n_glass to n_ext. Ratio is 1/mu.
    mu_exit = 1.0 / mu
    
    # Dot product with exit normal (assuming normal points out of glass)
    # If normals are stored as entry normals, we might need to flip them for exit calculation
    # depending on convention. Assuming get_rays_inside_window provides normals 
    # oriented for the internal propagation context or we handle sign.
    # Standard Snell's law vector form for exit:
    # c_exit = n_exit . d_glass
    # If n_exit is parallel to n_entry, and d_glass is entering the second surface:
    c_exit = torch.sum(v_normals[valid_refraction] * d_glass[valid_refraction], dim=1)
    
    tmp_exit = 1.0 - (mu_exit ** 2) * (1.0 - (c_exit ** 2))
    valid_exit_refraction = tmp_exit >= 0
    final_mask = final_mask & valid_exit_refraction
    
    d_out = torch.sqrt(tmp_exit.unsqueeze(1)) * v_normals[valid_refraction] + mu_exit * (d_glass[valid_refraction] - c_exit.unsqueeze(1) * v_normals[valid_refraction])
    
    # Transmission coefficient
    # Incident angle theta_i = acos(c)
    theta_i = torch.acos(torch.clamp(c[valid_refraction], -1.0, 1.0))
    trans_coeff = fresnel_coeff(theta_i, n_glass, n_ext)
    
    # Update luminosities
    new_luminosities = v_lum[valid_refraction] * trans_coeff
    
    # Return new Rays
    new_origins = p_exit[valid_refraction]
    new_directions = d_out[valid_refraction]
    
    return new_origins, new_directions, new_luminosities, final_mask

def fresnel_coeff(theta_i, n1, n2):
    """
    Simplified transmission coefficient calculation.
    Uses Fresnel equations for unpolarized light.
    """
    # Snell's law: n1 sin(theta_i) = n2 sin(theta_t)
    sin_theta_t = (n1 / n2) * torch.sin(theta_i)
    cos_theta_t = torch.sqrt(1.0 - sin_theta_t ** 2)
    
    # Fresnel transmission for unpolarized light
    # T = 0.5 * (T_s + T_p)
    # T_s = 1 - ((n1 cos(theta_i) - n2 cos(theta_t)) / (n1 cos(theta_i) + n2 cos(theta_t)))^2
    # T_p = 1 - ((n1 cos(theta_t) - n2 cos(theta_i)) / (n1 cos(theta_t) + n2 cos(theta_i)))^2
    
    cos_theta_i = torch.cos(theta_i)
    
    num_s = n1 * cos_theta_i - n2 * cos_theta_t
    den_s = n1 * cos_theta_i + n2 * cos_theta_t
    T_s = 1.0 - (num_s / den_s) ** 2
    
    num_p = n1 * cos_theta_t - n2 * cos_theta_i
    den_p = n1 * cos_theta_t + n2 * cos_theta_i
    T_p = 1.0 - (num_p / den_p) ** 2
    
    return 0.5 * (T_s + T_p)
```

## Operating characteristics
*   **Time Complexity**: $O(N)$ where $N$ is the number of rays. The cost is dominated by a constant number of vector operations and trigonometric functions per ray.
*   **Memory Complexity**: $O(N)$ to store ray attributes and intermediate tensors.
*   **Strengths**: Physically accurate for parallel-sided transparent objects; handles batched ray processing efficiently on GPUs.
*   **Limitations**: Assumes ideal parallel planes; does not account for dispersion (wavelength-dependent refraction) unless extended; total internal reflection results in ray loss unless handled by a reflection model.
*   **When to use**: Simulating windows, glass panes, or planar optical elements in ray tracing.
*   **When not to use**: Curved glass surfaces (use Sphere Intersection or general mesh intersection) or when dispersion is critical.

## Background
This method is implemented in the `gradoptics` library, part of the MAGIS (Matter-gravity Interferometer with Atomic Sensing) project infrastructure, used for simulating optical systems in precision measurement experiments [S1, unofficial]. It provides a specialized primitive for ray-tracing through planar dielectric interfaces.
