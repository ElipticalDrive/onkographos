# Parabolic Ray Tracing in Heterogeneous Media

Also called: Non-linear ray tracing, Piecewise polynomial ray tracing

## Overview
Parabolic Ray Tracing computes light ray trajectories in media with spatially varying Refractive Index Fields (RIF) by modeling the squared RIF as a linear function within tetrahedral cells, yielding second-order polynomial ray paths [S1]. It solves the problem of exact intersection computation with cell boundaries, which is otherwise difficult when trajectories involve transcendental functions, by reducing boundary crossings to solving quadratic equations [S1]. It differs from linear ray tracing by accounting for continuous curvature within cells, and from general non-linear solvers by providing closed-form analytical solutions for the trajectory [S1].

## How it works
**Inputs:**
*   A tetrahedral mesh defining the spatial domain [S1].
*   A Refractive Index Field (RIF) $\eta(\mathbf{x})$ defined per cell [S1].
*   A ray origin $\mathbf{x}_0$ and initial direction $\mathbf{p}_0$ satisfying the Eikonal equation [S1].

**Outputs:**
*   The trajectory of the ray as it traverses the medium [S1].
*   Intersection points with cell boundaries [S1].

**Data Structures:**
*   **Cell Coefficients:** For each tetrahedral cell, the squared RIF is defined as a linear function:
    $$ \eta^2(\mathbf{x}) = A_0 + A_1 \mathbf{x}_x + A_2 \mathbf{x}_y + A_3 \mathbf{x}_z = A_0 + \boldsymbol{\gamma} \cdot \mathbf{x} $$
    where $\boldsymbol{\gamma} = [A_1, A_2, A_3]^T$ is the constant gradient of the squared RIF, and $A_0$ is a scalar offset [S1].
*   **Ray State:** Position $\mathbf{x}(\tau)$ and direction $\mathbf{p}(\tau)$ at parameter $\tau$ [S1].

**Algorithm Steps:**

1.  **Initialize Ray State:**
    Set initial position $\mathbf{x}_0$ and initial direction $\mathbf{p}_0$ [S1]. Ensure $\|\mathbf{p}_0\| = \eta(\mathbf{x}_0)$ to satisfy the Eikonal equation [S1].

2.  **Determine Current Cell:**
    Identify the tetrahedral cell containing the current ray position $\mathbf{x}(\tau)$ [G].

3.  **Compute Cell Coefficients:**
    Retrieve $\boldsymbol{\gamma}$ and $A_0$ for the current cell based on the RIF definition [S1].

4.  **Compute Ray Trajectory within Cell:**
    The ray trajectory $\mathbf{x}(\tau)$ and direction $\mathbf{p}(\tau)$ are second-order polynomials in the parameter $\tau$:
    $$ \mathbf{x}(\tau) = \frac{1}{4}\boldsymbol{\gamma} \tau^2 + \mathbf{p}_0\tau + \mathbf{x}_0 $$
    $$ \mathbf{p}(\tau) = \frac{1}{2}\boldsymbol{\gamma} \tau + \mathbf{p}_0 $$
    where $\tau$ is a parameter related to arc length $s$ by $ds = \eta d\tau$ [S1].

5.  **Intersect with Cell Boundary:**
    Intersect the polynomial ray subsection with a cell boundary by solving a quadratic equation exactly [S1].
    *   Let the cell boundary be defined by a plane equation $\mathbf{n} \cdot \mathbf{x} + d = 0$ [G].
    *   Substitute $\mathbf{x}(\tau)$ into the plane equation:
        $$ \mathbf{n} \cdot \left( \frac{1}{4}\boldsymbol{\gamma} \tau^2 + \mathbf{p}_0\tau + \mathbf{x}_0 \right) + d = 0 $$
    *   Rearrange into standard quadratic form $a\tau^2 + b\tau + c = 0$:
        $$ a = \frac{1}{4} (\mathbf{n} \cdot \boldsymbol{\gamma}) $$
        $$ b = \mathbf{n} \cdot \mathbf{p}_0 $$
        $$ c = \mathbf{n} \cdot \mathbf{x}_0 + d $$
    *   Solve for $\tau$ using the quadratic formula [G]. Select the smallest positive $\tau$ that corresponds to the exit point from the current cell [S1].

6.  **Update Ray State:**
    *   Update position: $\mathbf{x}_{new} = \mathbf{x}(\tau_{exit})$ [S1].
    *   Update direction: $\mathbf{p}_{new} = \mathbf{p}(\tau_{exit})$ [S1].
    *   Reset $\tau$ to 0 for the next cell, adjusting $\mathbf{x}_0$ and $\mathbf{p}_0$ accordingly [S1].

7.  **Traverse to Next Cell:**
    Move to the adjacent tetrahedral cell sharing the exit face and repeat steps 2-6 until the ray exits the medium or reaches a termination condition [S1].

8.  **Intersect Scene Geometry (SDF):**
    For intersecting the panel's signed distance field (SDF), step naively along the computed parabolic ray trajectory, similar to regular sphere tracing [S1].

**Pseudocode:**

```python
import math

def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

def norm(a):
    return math.sqrt(dot(a, a))

def solve_quadratic(a, b, c):
    """Solve a*x^2 + b*x + c = 0. Returns smallest positive root or None [G]."""
    if abs(a) < 1e-12:
        if abs(b) < 1e-12:
            return None
        root = -c / b
        return root if root > 0 else None
    discriminant = b * b - 4 * a * c
    if discriminant < 0:
        return None
    sqrt_disc = math.sqrt(discriminant)
    root1 = (-b - sqrt_disc) / (2 * a)
    root2 = (-b + sqrt_disc) / (2 * a)
    roots = [r for r in [root1, root2] if r > 0]
    return min(roots) if roots else None

def point_in_tetrahedron(v0, v1, v2, v3, p):
    """Check if point p is inside tetrahedron defined by 4 vertices using barycentric coordinates [G]."""
    v0v1 = [v1[i]-v0[i] for i in range(3)]
    v0v2 = [v2[i]-v0[i] for i in range(3)]
    v0v3 = [v3[i]-v0[i] for i in range(3)]
    v0p = [p[i]-v0[i] for i in range(3)]
    d00 = dot(v0v1, v0v1)
    d01 = dot(v0v1, v0v2)
    d02 = dot(v0v1, v0v3)
    d11 = dot(v0v2, v0v2)
    d12 = dot(v0v2, v0v3)
    d22 = dot(v0v3, v0v3)
    d30 = dot(v0p, v0v1)
    d31 = dot(v0p, v0v2)
    d32 = dot(v0p, v0v3)
    denom = d00 * d11 - d01 * d01
    if abs(denom) < 1e-12:
        return False
    b0 = (d11 * d22 - d12 * d12) * d30 + (d02 * d12 - d01 * d22) * d31 + (d01 * d12 - d02 * d11) * d32
    b1 = (d00 * d22 - d02 * d02) * d31 + (d12 * d02 - d00 * d22) * d30 + (d00 * d12 - d01 * d02) * d32
    b2 = (d00 * d11 - d01 * d01) * d32 + (d01 * d02 - d00 * d11) * d31 + (d11 * d02 - d01 * d12) * d30
    b3 = 1.0 - (b0 + b1 + b2) / denom
    return b0 >= 0 and b1 >= 0 and b2 >= 0 and b3 >= 0

def get_adjacent_tetrahedron(tet_mesh, current_tet_idx, exit_face_idx):
    """Return index of tetrahedron sharing exit_face_idx with current_tet_idx [G]."""
    # Assumes tet_mesh stores adjacency or face-to-tet mapping.
    # Standard mesh traversal: look up neighbor via face index.
    return tet_mesh[current_tet_idx].adjacent[exit_face_idx]

def parabolic_ray_trace(ray_origin, ray_direction, tet_mesh, rif_function):
    """
    Trace a ray through a tetrahedral mesh with a piecewise linear squared RIF.
    
    Args:
        ray_origin: Initial position x0.
        ray_direction: Initial direction p0.
        tet_mesh: List of tetrahedra, each with vertices, faces, and adjacency list.
        rif_function: Function returning (gamma, A0) for a given position.
        
    Returns:
        List of intersection points.
    """
    x = list(ray_origin)
    p = list(ray_direction)
    intersections = []
    
    # Ensure initial direction satisfies Eikonal equation [S1]
    gamma_init, A0_init = rif_function(x)
    eta_init = math.sqrt(A0_init + dot(gamma_init, x))
    p_norm = norm(p)
    p = [val * (eta_init / p_norm) for val in p]
    
    # Find initial tetrahedron [G]
    current_tet_idx = None
    for i, tet in enumerate(tet_mesh):
        if point_in_tetrahedron(*tet.vertices, x):
            current_tet_idx = i
            break
            
    while current_tet_idx is not None:
        current_tet = tet_mesh[current_tet_idx]
        gamma, A0 = rif_function(x)
        
        # Find exit point from current tetrahedron
        min_tau = float('inf')
        exit_face_idx = None
        
        for face_idx, face in enumerate(current_tet.faces):
            n = face.normal
            d = -dot(n, face.vertices[0])
            
            # Coefficients for quadratic equation
            a = 0.25 * dot(n, gamma)
            b = dot(n, p)
            c = dot(n, x) + d
            
            tau = solve_quadratic(a, b, c)
            
            if tau is not None and tau < min_tau:
                min_tau = tau
                exit_face_idx = face_idx
        
        if min_tau == float('inf'):
            break
            
        # Compute exit position and direction
        exit_x = [0.25 * gamma[i] * (min_tau ** 2) + p[i] * min_tau + x[i] for i in range(3)]
        exit_p = [0.5 * gamma[i] * min_tau + p[i] for i in range(3)]
        
        intersections.append(exit_x)
        
        # Update state for next cell (reset tau to 0 implicitly by using new x, p) [S1]
        x = exit_x
        p = exit_p
        
        # Find next tetrahedron [G]
        current_tet_idx = get_adjacent_tetrahedron(tet_mesh, current_tet_idx, exit_face_idx)
        
    return intersections
```

**Edge Cases and Pitfalls:**
*   **Eikonal Equation:** The initial direction must satisfy $\|\mathbf{p}_0\| = \eta(\mathbf{x}_0)$ to ensure physical correctness [S1].
*   **SDF Intersection:** Stepping naively along the parabolic trajectory for SDF intersection requires careful step sizing to avoid missing geometry, similar to standard sphere tracing [S1].
*   **Degenerate Cells:** If a tetrahedron is degenerate (zero volume), the barycentric test fails and the ray may escape the mesh; mesh quality checks are required [G].

## Operating characteristics
*   **Time Complexity:** Linear in the number of cells traversed, with constant time per cell for intersection computation (solving a quadratic equation) [G].
*   **Memory Complexity:** Linear in the size of the tetrahedral mesh and RIF data [G].
*   **Strengths:** Exact intersection computation with cell boundaries; analytical solutions for ray trajectories within cells [S1].
*   **Limitations:** Limited to media where the squared RIF can be approximated as a linear function within tetrahedral cells; may require fine mesh resolution for accurate RIF representation [S1].
*   **When to Use:** When accurate ray tracing in heterogeneous media with smooth refractive index variations is required, and the medium can be discretized into tetrahedral cells with linear squared RIF profiles [S1].
*   **When Not to Use:** When the RIF varies rapidly or non-linearly within cells, or when the medium is not naturally represented as a tetrahedral mesh [S1].

## Background
Parabolic Ray Tracing was introduced in the context of seismic wave propagation, where Virieux and Farra demonstrated that a well-chosen expression for the slowness profile within tetrahedral cells yields simple second-order polynomial solutions for ray trajectories [S1]. This approach was later adapted for computer graphics to model light propagation in heterogeneous media, such as old glass, by assembling multiple tetrahedral cells and tracing piecewise polynomial rays [S1]. It generalizes the concept of ray differentials used in computer graphics for building two-point tracing methods [S1].
