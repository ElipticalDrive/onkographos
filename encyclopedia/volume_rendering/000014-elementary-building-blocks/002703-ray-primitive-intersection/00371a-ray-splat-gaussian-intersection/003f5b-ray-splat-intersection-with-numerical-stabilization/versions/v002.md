# Ray-splat Intersection with Numerical Stabilization

Also called: Linear Fallback for Ray-Gaussian Intersection, Stable Ray-Gaussian Intersection

## Overview
This method computes the intersection depths between camera rays and quadric splats, providing a numerically stable solution when the quadratic coefficient is near zero [S1]. It differs from standard quadratic solvers by detecting degenerate cases where the quadric surface is nearly flat or the ray is nearly perpendicular to the principal axes, switching to a linear approximation to prevent floating-point overflow [S1]. It builds on [Ray-Splat/gaussian Intersection](7916-ray-splat-gaussian-intersection.md) by handling the specific numerical instability inherent in second-order primitives [S1].

## How it works
**Inputs and Outputs**
- **Inputs**: Ray origin $\hat{\mathbf{o}} = [\hat{o}^1, \hat{o}^2, \hat{o}^3]^T$, ray direction $\hat{\mathbf{r}} = [\hat{r}^1, \hat{r}^2, \hat{r}^3]^T$, and quadric parameters $s_1, s_2, s_3$ defining the surface geometry in the Gaussian local coordinate system [S1].
- **Outputs**: Intersection depths $t_{n,f}$ [S1].

**Data Structures**
The method operates on scalar values derived from the ray and quadric parameters, requiring no complex data structures beyond standard floating-point variables [G].

**Steps**
1. **Compute Quadratic Coefficients**: Calculate the coefficients $A$, $B$, and $C$ for the quadratic equation $At^2 + Bt + C = 0$ using the ray and quadric parameters [S1]:
   $$A = \frac{\text{sign}(s_1)}{s_1^2} (\hat{r}^1)^2 + \frac{\text{sign}(s_2)}{s_2^2} (\hat{r}^2)^2$$
   $$B = \frac{\text{sign}(s_1)}{s_1^2} 2\hat{o}^1\hat{r}^1 + \frac{\text{sign}(s_2)}{s_2^2} 2\hat{o}^2\hat{r}^2 - \frac{1}{s_3}\hat{r}^3$$
   $$C = \frac{\text{sign}(s_1)}{s_1^2} (\hat{o}^1)^2 + \frac{\text{sign}(s_2)}{s_2^2} (\hat{o}^2)^2 - \frac{1}{s_3}\hat{o}^3$$
2. **Check for Numerical Stability**: Evaluate the magnitude of $A$ [S1]. If $|A| < \epsilon$ (where $\epsilon = 10^{-6}$), the quadratic term is negligible [S1].
3. **Solve Linear Equation (Fallback)**: If $|A| < \epsilon$, solve the linear equation $Bt + C = 0$ [S1]:
   $$t = -\frac{C}{B}$$
   This solution corresponds to the intersection with the tangent plane at the point where the perpendicular from the camera center meets the quadric surface [S1].
4. **Solve Quadratic Equation (Standard)**: If $|A| \ge \epsilon$, solve the quadratic equation using the stable formula [S1]:
   $$t_{n,f} = \frac{-B \pm \text{sign}(A) \cdot \sqrt{B^2 - 4AC}}{2A}$$

**Pseudocode**
```python
import math

def ray_splat_intersection_stable(o, r, s1, s2, s3):
    """
    Compute intersection depths with numerical stabilization.
    
    Args:
        o: Ray origin [o1, o2, o3]
        r: Ray direction [r1, r2, r3]
        s1, s2, s3: Quadric parameters
        
    Returns:
        t1, t2: Intersection depths (near, far)
    """
    sign_s1 = 1.0 if s1 > 0 else -1.0
    sign_s2 = 1.0 if s2 > 0 else -1.0
    
    A = (sign_s1 / (s1**2)) * (r[0]**2) + (sign_s2 / (s2**2)) * (r[1]**2)
    B = (sign_s1 / (s1**2)) * 2 * o[0] * r[0] + (sign_s2 / (s2**2)) * 2 * o[1] * r[1] - (1.0 / s3) * r[2]
    C = (sign_s1 / (s1**2)) * (o[0]**2) + (sign_s2 / (s2**2)) * (o[1]**2) - (1.0 / s3) * o[2]
    
    epsilon = 1e-6
    
    if abs(A) < epsilon:
        if abs(B) < epsilon:
            return float('inf'), float('inf')
        t = -C / B
        return t, t
    else:
        discriminant = B**2 - 4 * A * C
        if discriminant < 0:
            return float('inf'), float('inf')
        
        sqrt_disc = math.sqrt(discriminant)
        sign_A = 1.0 if A > 0 else -1.0
        
        t1 = (-B + sign_A * sqrt_disc) / (2 * A)
        t2 = (-B - sign_A * sqrt_disc) / (2 * A)
        
        return t1, t2
```

**Parameters**
- $\epsilon = 10^{-6}$: Threshold for determining when $A$ is negligible [S1].

**Edge Cases and Pitfalls**
- **Numerical Overflow**: When $|A|$ is very small, the standard quadratic formula can cause floating-point overflow, resulting in NaN or Inf values, particularly during backpropagation [S1]. The linear fallback prevents this [S1].
- **Degenerate Geometry**: If both $A$ and $B$ are near zero, the ray is parallel to the surface or the geometry is invalid [G].
- **No Real Intersection**: If the discriminant $B^2 - 4AC < 0$, there are no real intersection points [G].

## Operating characteristics
- **Time Complexity**: $O(1)$ per ray-splat intersection [G]. The linear fallback is slightly faster than the quadratic solution due to the absence of square root and division by $2A$ [G].
- **Memory Complexity**: $O(1)$ additional memory [G].
- **Strengths**: Prevents numerical instability during training and rendering, especially for flat splats or rays nearly perpendicular to the principal axes [S1]. Ensures stable gradients during backpropagation [S1].
- **Limitations**: The linear approximation is less accurate than the quadratic solution when $A$ is small but not negligible [G]. The choice of $\epsilon$ affects the transition between linear and quadratic solutions [G].
- **When to Use**: Use this method for ray-splat intersection in Gaussian Splatting variants that use quadric primitives, especially when training or when numerical stability is prioritized over exact quadratic precision [G].
- **When Not to Use**: Not applicable; this is a robust general-purpose method for the specified intersection problem [G].
