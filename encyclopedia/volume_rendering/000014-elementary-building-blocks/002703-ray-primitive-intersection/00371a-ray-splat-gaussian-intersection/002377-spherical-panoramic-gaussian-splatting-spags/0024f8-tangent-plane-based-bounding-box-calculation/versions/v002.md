# Tangent Plane-Based Bounding Box Calculation

Also called: SPaGS Bounding Box, Two-Stage Bounding Box

## Overview
A two-stage method to calculate an axis-aligned screen-space bounding box for 3D Gaussians in spherical panoramas, addressing deformation caused by omnidirectional pixel distribution and non-linear spherical projection [S1]. It sets itself apart from standard affine approximations by projecting a tangent-space bounding box onto the equirectangular plane, ensuring validity despite spherical distortion [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D Gaussian splat parameters (mean $\mathbf{m}$ in camera space, covariance $\Sigma$), camera intrinsic parameters (focal length $f$), and equirectangular image dimensions $(W, H)$ [S1].
*   **Output:** Axis-aligned bounding box $(p_{x,\min}, p_{x,\max}, p_{y,\min}, p_{y,\max})$ in equirectangular pixel coordinates [S1].

**Data Structures:**
*   **Tangent Space Basis:** Vectors $\hat{\mathbf{t}}$ (tangent), $\hat{\mathbf{b}}$ (bitangent), $\hat{\mathbf{n}}$ (normal) in $\mathbb{R}^3$ [S1].
*   **Tangent Box:** Rectangle defined by $t_{x,\min}, t_{x,\max}, t_{y,\min}, t_{y,\max}$ in tangent space [S1].
*   **Camera Space Box:** Derived from tangent box via transformation [S1].

**Steps:**

1.  **Define Tangent Space:**
    For a splat with mean $\mathbf{m}$ in camera space, determine the reference vector $\mathbf{r}_{\text{ref}}$ to avoid pole singularities [S1]. The mean $\mathbf{m}$ is used as the reference, except when the splat lies on the vector of the two poles, in which case $\mathbf{r}_{\text{ref}}$ is used to avoid singularity [S1]. Compute the normal $\hat{\mathbf{n}} = \mathbf{m} / \|\mathbf{m}\|$ [S1]. Compute the tangent $\hat{\mathbf{t}} = \text{normalize}(\mathbf{r}_{\text{ref}} \times \hat{\mathbf{n}})$ [S1]. Compute the bitangent $\hat{\mathbf{b}} = \hat{\mathbf{n}} \times \hat{\mathbf{t}}$ [S1]. The tangent plane is defined as $z=1$ with origin at the camera space origin [S1].

2.  **Transform to Tangent Space:**
    Construct the transformation matrix $M$ from camera space to tangent space. The columns of $M$ are $\hat{\mathbf{t}}, \hat{\mathbf{b}}, \hat{\mathbf{n}}$ [S1]. Transform the Gaussian covariance $\Sigma$ to tangent space: $\Sigma_t = M^T \Sigma M$ [S1]. Calculate the 2D bounding box $(t_{x,\min}, t_{x,\max}, t_{y,\min}, t_{y,\max})$ on the tangent plane using the standard 2D Gaussian projection method (e.g., as in HTGS [HFW*25]), treating the tangent space as a local Euclidean plane [S1].

3.  **Project to Camera Space:**
    Map the tangent box corners back to camera space. A point in tangent space is $\mathbf{t} = (t_x, t_y, 1)^T$ [S1]. The corresponding point in camera space $\mathbf{c}$ is calculated using Eq. (17), where $c_x$ and $c_y$ are derived from the tangent coordinates [S1].

4.  **Project to Equirectangular Plane (Stage 2):**
    Convert camera space coordinates to spherical angles (longitude $\phi$, latitude $\lambda$) or directly to equirectangular coordinates $(p_x, p_y)$ [S1]. The equirectangular coordinates are proportional to $\phi$ and $\lambda$ [S1]. Due to the non-linear nature of $\text{atan2}$ and $\text{asin}$, the bounding box in equirectangular space is not simply the projection of the tangent box corners [S1].

5.  **Calculate $p_y$ Bounds:**
    Since $\text{asin}$ is monotonically increasing, the minimum and maximum $p_y$ are found by evaluating the function at the extreme values of the argument derived from the tangent box combinations [S1]. Calculate the range of $c_y / \|\mathbf{c}\|$ based on $t_{x,\min/max}$ and $t_{y,\min/max}$ [S1]. The bounds are computed using Eqs. (15), (16), and the monotonicity properties in Eqs. (22)-(23) [S1].

6.  **Calculate $p_x$ Bounds:**
    Directly using $\text{atan2}$ is problematic due to discontinuity at the pole cut [S1]. Instead, calculate a maximized differential angle [S1]. Compute the range of longitude $\phi$ covered by the box [S1]. The bounds are derived using Eqs. (24)-(25) to handle the wrap-around and singularity [S1].

7.  **Handle Pole Coverage:**
    Check if the projected bounding box covers the north or south pole [S1]. If it covers a pole: Set $p_{x,\min} = 0$ and $p_{x,\max} = W$ (full image width) [S1]. Recalculate $p_{y,\min}$ and $p_{y,\max}$ relative to the projection center on the respective sphere [S1]. If the projection center is exactly on a pole: Use the simplified calculation with negligible overhead [S1].

8.  **Load Balancing:**
    Apply a load balancing scheme similar to Radl et al. [RSP*24] to mitigate the impact of occasional large bounding boxes on Gaussian/tile instance creation [S1].

**Pseudocode:**

```python
import math
import numpy as np

def tangent_plane_bounding_box(mean_cam, cov_cam, W, H):
    """
    Calculate the equirectangular bounding box for a 3D Gaussian splat.
    
    Args:
        mean_cam: numpy array (3,), camera space mean of the Gaussian.
        cov_cam: numpy array (3,3), camera space covariance matrix.
        W: int, image width.
        H: int, image height.
        
    Returns:
        tuple: (px_min, px_max, py_min, py_max) in pixel coordinates.
    """
    # 1. Define Tangent Space
    m = mean_cam
    norm_m = np.linalg.norm(m)
    if norm_m < 1e-8:
        return (0.0, 0.0, 0.0, 0.0)
    
    n_hat = m / norm_m
    
    # Reference vector to avoid singularity at poles
    if abs(n_hat[2]) > 0.9:
        r_ref = np.array([1.0, 0.0, 0.0])
    else:
        r_ref = np.array([0.0, 0.0, 1.0])
        
    t_hat = np.cross(r_ref, n_hat)
    t_hat = t_hat / np.linalg.norm(t_hat)
    b_hat = np.cross(n_hat, t_hat)
    
    # Transformation matrix M (columns are t_hat, b_hat, n_hat)
    M = np.column_stack((t_hat, b_hat, n_hat))
    
    # 2. Transform Covariance to Tangent Space
    cov_tan = M.T @ cov_cam @ M
    
    # 3. Calculate 2D Bounding Box in Tangent Space (HTGS approach)
    sigma_2d = cov_tan[:2, :2]
    eigenvalues, eigenvectors = np.linalg.eigh(sigma_2d)
    k = 3.0  # 3-sigma coverage
    extents = k * np.sqrt(eigenvalues)
    v1, v2 = eigenvectors[:, 0], eigenvectors[:, 1]
    
    dx = math.sqrt((v1[0] * extents[0])**2 + (v2[0] * extents[1])**2)
    dy = math.sqrt((v1[1] * extents[0])**2 + (v2[1] * extents[1])**2)
    
    # Center in tangent space (projection of mean onto z=1 plane)
    m_proj = m / m[2]
    m_tan = M.T @ m_proj
    tx_min, tx_max = m_tan[0] - dx, m_tan[0] + dx
    ty_min, ty_max = m_tan[1] - dy, m_tan[1] + dy
    
    # 4. Project to Camera Space
    def tan_to_cam(tx, ty):
        t = np.array([tx, ty, 1.0])
        c = M @ t
        return c[0], c[1], c[2]
        
    # 5. Calculate py Bounds (arcsin monotonicity)
    def get_py(tx, ty):
        cx, cy, cz = tan_to_cam(tx, ty)
        return math.asin(cy / math.sqrt(cx**2 + cy**2 + cz**2))
        
    py_candidates = [get_py(tx, ty) for tx in [tx_min, tx_max] for ty in [ty_min, ty_max]]
    py_min = min(py_candidates)
    py_max = max(py_candidates)
    
    # 6. Calculate px Bounds (maximized differential angle)
    def get_px(tx, ty):
        cx, cy, cz = tan_to_cam(tx, ty)
        return math.atan2(cx, cz)
        
    px_candidates = [get_px(tx, ty) for tx in [tx_min, tx_max] for ty in [ty_min, ty_max]]
    px_min = min(px_candidates)
    px_max = max(px_candidates)
    
    # Handle atan2 discontinuity by checking differential angles
    # [G] Standard wrap-around handling for spherical coordinates
    if px_max - px_min > math.pi:
        px_min = px_max - math.pi
    elif px_min - px_max > math.pi:
        px_max = px_min + math.pi
        
    # 7. Handle Pole Coverage
    # Check if latitude exceeds threshold
    max_abs_lat = max(abs(math.asin(cy / math.sqrt(cx**2 + cy**2 + cz**2))) 
                      for cx, cy, cz in [tan_to_cam(tx, ty) for tx in [tx_min, tx_max] for ty in [ty_min, ty_max]])
                      
    if max_abs_lat > math.pi/2 - 1e-6:
        px_min = 0.0
        px_max = float(W)
        # Recalculate py for projection center on respective sphere
        # [G] Simplified clamping to hemisphere range
        py_min = 0.0
        py_max = float(H)
    else:
        # Convert angles to pixel coordinates
        px_min = (px_min / (2 * math.pi) + 0.5) * W
        px_max = (px_max / (2 * math.pi) + 0.5) * W
        py_min = (py_min / math.pi + 0.5) * H
        py_max = (py_max / math.pi + 0.5) * H
        
    # 8. Load Balancing
    # [S1] Apply load balancing scheme similar to Radl et al. [RSP*24]
    # [G] In practice, clamp box dimensions to tile sizes or cap instance counts here
    
    return (px_min, px_max, py_min, py_max)
```

## Subtopics

### Bounding Box and T-matrix Computation
Computes the screen-space bounding rectangle of a projected surfel by finding clip-space planes tangent to the unit sphere under the mapping $\bar{h} = T^T h$, using the inverse-transpose of the T-matrix for numerical stability with degenerate surfels [S2, unofficial]. It stores the three non-degenerate rows of $T$ as vectors $T_1, T_2, T_4 \in \mathbb{R}^3$ and computes the screen-space center and half-extents using a closed-form expression involving dot products among these vectors [S2, unofficial]. This method is particularly useful for handling degenerate (infinitesimally thin) surfels where tangent scales become very small during optimization [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per splat for the bounding box calculation, involving a constant number of matrix-vector multiplications and trigonometric functions [S1].
*   **Memory Complexity:** $O(1)$ per splat, storing only the basis vectors and box coordinates [S1].
*   **Performance:** The method is designed for real-time rendering, avoiding the need for iterative intersection tests [S1]. The load balancing scheme helps mitigate the performance impact of large bounding boxes [S1].
*   **Strengths:** Handles spherical projection distortion accurately; numerically stable at poles; valid bounding boxes even with significant deformation [S1].
*   **Limitations:** The calculation of $p_x$ bounds requires careful handling of the $\text{atan2}$ discontinuity and pole coverage, which can be complex to implement correctly [S1].

## Background
The method was introduced in the SPaGS paper [S1] to enable real-time rendering of 3D Gaussian splats on spherical panoramas. It addresses the limitations of standard 3DGS rasterization, which assumes a local affine approximation that fails under non-linear spherical projections. The approach builds on the tangent space formulation used in HTGS [HFW*25] and extends it to the equirectangular domain.
