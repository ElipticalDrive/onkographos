# Tight Bounding Box Calculation for Quadric Gaussians

Also called: QGS Bounding Box, Quadric Gaussian Bounding Box

## Overview
This method computes a tight 2D axis-aligned bounding box (AABB) for Quadratic Gaussian Splatting (QGS) primitives by approximating the primitive's boundary with tangent planes, avoiding the loose approximation of projecting 3D bounding box vertices [S1]. It addresses the inefficiency caused by QGS concave cases and the lack of an elementary inverse for the geodesic distance function, which makes analytical determination of the rendered portion difficult [S1]. It builds on [Tangent Plane-Based Bounding Box Calculation](3425-tangent-plane-based-bounding-box-calculation.md) [G].

## How it works
**Inputs:**
- Quadratic coefficient $a$ of the geodesic function [S1].
- Variance $\sigma_0(\theta)$ of the Gaussian distribution along the major axis ($\theta=0$) and minor axis ($\theta=\pi/2$) [S1].

**Outputs:**
- 2D AABB dimensions defined by $x_1$ and $x_2$ (half-widths/heights in the tangent plane projection) [S1].

**Data Structures:**
- No complex data structures required; calculation is analytical/algebraic [G].

**Steps:**

1.  **Approximate Geodesic Function:**
    Scale the geodesic function $l(a, \rho)$ to a quadratic polynomial approximation $\hat{l}(a, \rho)$ [S1]:
    $$ \hat{l}(a, \rho) = \frac{4|a|\rho^2 + 6\rho}{7} $$
    where $\rho$ is the horizontal distance from the primitive's vertex [S1].

2.  **Solve for Horizontal Distance ($\rho$):**
    For a given direction $\theta_0$ with variance $\sigma_0(\theta_0)$, solve $\hat{l}(a, \rho) - \sigma_0 = 0$ for $\rho$ [S1]. The quadratic formula yields two roots:
    $$ \rho_{0,1} = \frac{-6 \pm \sqrt{36 + 112|a|\sigma_0}}{8|a|} $$
    Since the function passes through the origin, take the positive root to represent the horizontal distance [S1].

3.  **Compute Major and Minor Axis Distances:**
    Calculate $\rho_1$ for the major axis ($\theta = 0$) and $\rho_2$ for the minor axis ($\theta = \pi/2$) using the variance $\sigma_0(0)$ and $\sigma_0(\pi/2)$ respectively [S1].

4.  **Define Quadric Points:**
    Obtain four points on the quadric surface in the local coordinate system: $(\pm\rho_1, 0, \rho_1^2)$ and $(0, \pm\rho_2, \rho_2^2)$ [S1].

5.  **Compute Tangent Plane Intersections:**
    Compute the intersection of the tangent planes at these four points with the plane $z=0$ to determine the bounding box extents $x_1$ and $x_2$ [S1].
    
    Let $s_1$ and $s_2$ be the slopes of the tangent planes at the points corresponding to $\rho_1$ and $\rho_2$ respectively [S1]. The intersections are calculated as [S1]:
    $$ x_1 = \pm \frac{\rho_1 s_1 - \rho_1^2}{s_1}, \quad x_2 = \pm \frac{\rho_2 s_2 - \rho_2^2}{s_2} $$
    
    The resulting 3D shape is a truncated pyramid with top dimensions $\rho_1 \times \rho_2$, bottom dimensions $x_1 \times x_2$, and height determined by the z-coordinate of the tangent plane intersections [S1].

**Pseudocode:**

```python
import math

def compute_qgs_bounding_box(a, sigma_major, sigma_minor):
    """
    Computes the tight bounding box extents x1 and x2 for a Quadratic Gaussian.
    
    Args:
        a (float): Quadratic coefficient of the geodesic function.
        sigma_major (float): Variance along the major axis (theta=0).
        sigma_minor (float): Variance along the minor axis (theta=pi/2).
        
    Returns:
        tuple: (x1, x2) representing the half-width and half-height of the AABB.
    """
    abs_a = abs(a)
    
    # Step 1 & 2: Solve for rho using the positive root of the quadratic approximation
    # rho = (-6 + sqrt(36 + 112 * |a| * sigma)) / (8 * |a|)
    
    # Calculate rho1 for major axis
    discriminant_1 = 36 + 112 * abs_a * sigma_major
    rho1 = (-6 + math.sqrt(discriminant_1)) / (8 * abs_a)
    
    # Calculate rho2 for minor axis
    discriminant_2 = 36 + 112 * abs_a * sigma_minor
    rho2 = (-6 + math.sqrt(discriminant_2)) / (8 * abs_a)
    
    # Step 4 & 5: Compute tangent plane intersections
    # The source defines x1 and x2 using slopes s1 and s2.
    # For the quadric points (±ρ1, 0, ρ1^2) and (0, ±ρ2, ρ2^2), the surface is z = ρ^2.
    # The slope of the tangent plane in the radial direction is s = dz/dρ = 2ρ [G].
    s1 = 2 * rho1
    s2 = 2 * rho2
    
    # Avoid division by zero if slope is zero
    if abs(s1) < 1e-9:
        x1 = rho1
    else:
        x1 = (rho1 * s1 - rho1**2) / s1
        
    if abs(s2) < 1e-9:
        x2 = rho2
    else:
        x2 = (rho2 * s2 - rho2**2) / s2
        
    return abs(x1), abs(x2)
```

**Edge Cases and Pitfalls:**
- QGS includes concave cases, which complicates the analytical determination of the rendered portion during preprocessing [S1].
- The geodesic function lacks an elementary inverse, requiring numerical or approximate solutions for the equipotential $\rho(\theta_0) = \{l^{-1}(l_0) : l_0 = \sigma(\theta_0)\}$ [S1].
- Even with an analytical solution, equipotential lines in non-Euclidean space may not fully enclose the primitive, requiring extra boundary calculations [S1].
- Precision issues may arise if $a$ is very small, leading to division by near-zero values in the root calculation or slope determination [G].

## Operating characteristics
- **Time Complexity:** The calculation involves basic arithmetic operations and square roots, making it $O(1)$ per primitive [G].
- **Memory Complexity:** $O(1)$ auxiliary memory [G].
- **Performance:** On the Mip-NeRF360 dataset, QGS with this tight bounding box (QGS w/ TB) achieved 14.15 FPS compared to 7.92 FPS for standard QGS, with reduced storage (641MB vs 688MB) [S1]. On the TNT dataset, it achieved 25.36 FPS vs 13.27 FPS [S1].
- **Strengths:** Significantly tighter bounding box than projecting 3D vertices, leading to higher rendering FPS and lower storage overhead [S1].
- **Limitations:** Relies on the accuracy of the quadratic approximation of the geodesic function [S1].

## Background
- **Origin:** Introduced in "Quadratic Gaussian Splatting: High Quality Surface Reconstruction with Second-Order Geometric Primitives" (ICCV 2025) [S1].
- **Development:** Developed to address the limitations of 2DGS/3DGS where Gaussian primitives are convex, making bounding box computation straightforward [S1]. QGS introduces concave cases and non-Euclidean geodesic distances, necessitating a more sophisticated bounding box calculation [S1].
- **Usage:** Used in high-quality surface reconstruction with second-order geometric primitives [S1].
