# Azimuthal Hit Detection

Also called: azimuthalHit

## Overview
Azimuthal Hit Detection determines whether a ray intersects an azimuthal section within a spherical voxel grid, where these sections are defined in the XZ plane [S1, unofficial]. It serves as a specialized primitive intersection test for volume rendering algorithms that traverse spherical coordinate systems, distinguishing itself from general ray-primitive tests by leveraging the geometric constraints of azimuthal boundaries to compute intersection parameters efficiently [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs**:
    *   `grid`: The spherical voxel grid structure containing boundary definitions and center coordinates.
    *   `ray`: The ray being tested, providing origin, direction, and segment endpoints.
    *   `current_azimuthal_voxel`: The integer index of the current azimuthal voxel being traversed.
    *   `ray_segment`: A segment representation of the ray, providing `P1()` (start point) and `vector()` (direction/delta).
    *   `collinear_times`, `t`, `max_t`: Parameters for tracking intersection distances and bounds.
    *   `grid.sphereCenter().z()`: The Z-coordinate of the sphere center.
    *   `grid.pMaxAzimuthal()`: Accessor for maximum azimuthal bounds.
*   **Outputs**:
    *   `HitParameters` (or boolean/struct indicating hit status and intersection distance `t`), returned by the underlying `angularHit` function.

**Data Structures**
*   `BoundVec3`: A 3D vector structure. For azimuthal calculations, the Y component is fixed at 0.0, as azimuthal sections lie in the XZ plane.
*   `grid.centerToAzimuthalBound(v)`: Returns a pointer to a `BoundVec3` representing the center-to-bound vector for voxel `v`.
*   `grid.pMaxAzimuthal(v)`: Returns a structure with fields `P1` and `P2`, representing the azimuthal boundary coordinates for voxel `v`.

**Steps**
1.  **Define Boundary Points**:
    *   Calculate `p_one`: A `BoundVec3` where `x = grid.pMaxAzimuthal(current_azimuthal_voxel).P1`, `y = 0.0`, and `z = grid.pMaxAzimuthal(current_azimuthal_voxel).P2`.
    *   Calculate `p_two`: A `BoundVec3` where `x = grid.pMaxAzimuthal(current_azimuthal_voxel + 1).P1`, `y = 0.0`, and `z = grid.pMaxAzimuthal(current_azimuthal_voxel + 1).P2`.

2.  **Retrieve Center Vectors**:
    *   Set `u_min` pointer to `&grid.centerToAzimuthalBound(current_azimuthal_voxel)`.
    *   Set `u_max` pointer to `&grid.centerToAzimuthalBound(current_azimuthal_voxel + 1)`.

3.  **Calculate Relative Vectors**:
    *   Calculate `w_min = p_one - ray_segment.P1()`.
    *   Calculate `w_max = p_two - ray_segment.P1()`.

4.  **Compute Perpendicular Components (Cross Products in 2D XZ)**:
    The algorithm computes scalar cross products (perpendicular dot products) for the XZ plane components. Let $v_x$ and $v_z$ be the x and z components of vector $v$. The 2D cross product is $v_x w_z - v_z w_x$.
    *   `perp_uv_min` = $u_{min,x} \cdot ray\_segment.vector_z - u_{min,z} \cdot ray\_segment.vector_x$
    *   `perp_uv_max` = $u_{max,x} \cdot ray\_segment.vector_z - u_{max,z} \cdot ray\_segment.vector_x$
    *   `perp_uw_min` = $u_{min,x} \cdot w_{min,z} - u_{min,z} \cdot w_{min,x}$
    *   `perp_uw_max` = $u_{max,x} \cdot w_{max,z} - u_{max,z} \cdot w_{max,x}$
    *   `perp_vw_min` = $ray\_segment.vector_x \cdot w_{min,z} - ray\_segment.vector_z \cdot w_{min,x}$
    *   `perp_vw_max` = $ray\_segment.vector_x \cdot w_{max,z} - ray\_segment.vector_z \cdot w_{max,x}$

5.  **Invoke Angular Hit Logic**:
    *   Call `angularHit` with the computed perpendicular components, the ray segment, collision time trackers, and grid parameters. The specific internal logic of `angularHit` is not detailed in the source notes, but it uses these values to determine the intersection [S1, unofficial].

**Pseudocode**
```python
def azimuthalHit(grid, ray, current_azimuthal_voxel, ray_segment, collinear_times, t, max_t):
    # 1. Define boundary points in XZ plane (y=0)
    p_one_x = grid.pMaxAzimuthal(current_azimuthal_voxel).P1
    p_one_z = grid.pMaxAzimuthal(current_azimuthal_voxel).P2
    p_one = BoundVec3(p_one_x, 0.0, p_one_z)

    p_two_x = grid.pMaxAzimuthal(current_azimuthal_voxel + 1).P1
    p_two_z = grid.pMaxAzimuthal(current_azimuthal_voxel + 1).P2
    p_two = BoundVec3(p_two_x, 0.0, p_two_z)

    # 2. Retrieve center vectors
    u_min = grid.centerToAzimuthalBound(current_azimuthal_voxel)
    u_max = grid.centerToAzimuthalBound(current_azimuthal_voxel + 1)

    # 3. Calculate relative vectors from ray start
    ray_p1 = ray_segment.P1()
    ray_vec = ray_segment.vector()
    
    w_min_x = p_one_x - ray_p1.x
    w_min_z = p_one_z - ray_p1.z
    w_min = BoundVec3(w_min_x, 0.0, w_min_z)

    w_max_x = p_two_x - ray_p1.x
    w_max_z = p_two_z - ray_p1.z
    w_max = BoundVec3(w_max_x, 0.0, w_max_z)

    # 4. Compute 2D cross products (XZ plane)
    # perp_uv
    perp_uv_min = u_min.x * ray_vec.z - u_min.z * ray_vec.x
    perp_uv_max = u_max.x * ray_vec.z - u_max.z * ray_vec.x

    # perp_uw
    perp_uw_min = u_min.x * w_min.z - u_min.z * w_min.x
    perp_uw_max = u_max.x * w_max.z - u_max.z * w_max.x

    # perp_vw
    perp_vw_min = ray_vec.x * w_min.z - ray_vec.z * w_min.x
    perp_vw_max = ray_vec.x * w_max.z - ray_vec.z * w_max.x

    # 5. Call underlying angular hit detector
    # Note: The exact signature and internal logic of angularHit are implementation-specific.
    # This call passes the precomputed geometric primitives.
    return angularHit(
        grid, ray, 
        perp_uv_min, perp_uv_max, 
        perp_uw_min, perp_uw_max, 
        perp_vw_min, perp_vw_max, 
        ray_segment, collinear_times, t, max_t, 
        ray.direction().z(), 
        grid.sphereCenter().z(), 
        grid.pMaxAzimuthal(), 
        current_azimuthal_voxel
    )
```

**Parameters and Edge Cases**
*   **Precision**: The calculation relies on floating-point arithmetic for cross products. Degenerate cases where the ray is parallel to the azimuthal boundaries (resulting in zero cross products) must be handled by the `angularHit` function, potentially using epsilon comparisons [S1, unofficial].
*   **Boundaries**: The method assumes `current_azimuthal_voxel` and `current_azimuthal_voxel + 1` are valid indices within the grid. Out-of-bounds access must be prevented by the caller or the grid structure [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: $O(1)$ per voxel traversal step, as it involves a fixed number of arithmetic operations and array lookups.
*   **Memory Complexity**: $O(1)$ auxiliary space.
*   **Strengths**: Highly optimized for spherical grids by reducing 3D intersection to 2D geometric primitives in the azimuthal plane.
*   **Limitations**: Specific to azimuthal sections in spherical coordinate systems; not applicable to Cartesian or other coordinate systems without transformation.
*   **When to use**: When rendering volumes using spherical voxel grids and traversing azimuthal boundaries.

## Background
Azimuthal Hit Detection is part of the Spherical Volume Rendering (SVR) algorithm, implemented in the `svr-algorithm` repository [S1, unofficial]. It is designed to handle the specific geometry of spherical voxels, where azimuthal sections are defined by angular divisions in the XZ plane. The method relies on mathematical principles similar to those found in Graphics Gems for line-sphere intersection, adapted for the discrete voxel grid structure [S1, unofficial].
