# Ray Subtraction

Also called: RaySubstraction

## Overview
Ray subtraction is a boolean operation that removes material from a target ray (Ray A) using a source ray (Ray B) [S1]. It solves the problem of sculpting or editing volumetric data by allowing users to delete specific regions, such as removing a sphere from a cube [S1]. It differs from [Ray Union](13991-ray-union.md) by inverting the normals of the source samples before merging, which causes the [MergeRegion](13991-region-nesting-merge.md) procedure to treat the source region as an "inside" void rather than an added volume [S1].

## How it works
**Inputs and Outputs:**
*   Input: Ray A (target), Ray B (source). Both contain a list of samples sorted by depth.
*   Output: Ray A modified in place to represent the material of A minus B.

**Data Structures:**
*   `Ray.list`: A list of samples. Each sample `s` contains at least a position (implied by sorting) and a `normal` vector.
*   `Ray.direction`: The viewing direction vector.

**Algorithm Steps:**
1.  Iterate through every sample `s` in `Ray B.list`.
2.  Negate the normal of sample `s`: $s.normal \leftarrow -s.normal$.
3.  Append the modified sample `s` to `Ray A.list`.
4.  Sort `Ray A.list` by depth (typically z-value or distance along the ray) [S1].
5.  Call `MergeRegion` on `Ray A` to remove inner regions based on the inverted normals [S1].

**Pseudocode:**
```python
def RaySubstraction(Ray A, Ray B):
    # Step 1-3: Invert normals and merge
    for s in B.list:
        s.normal = -s.normal
        A.list.append(s)
    
    # Step 4: Sort by depth (z-value)
    # Implementation note: Sorts samples based on their position along the ray direction
    A.list.sort(key=lambda sample: dot(sample.position, A.direction))
    
    # Step 5: Remove inner regions
    MergeRegion(A)
```

**MergeRegion Logic (Required Context):**
The `MergeRegion` procedure tracks a nesting `level`. It iterates through the sorted list. If the dot product of the sample's normal and the ray direction is negative, it decrements the level; otherwise, it increments it. Samples are kept only when the level transitions from 0 to 1 (entering a region) or when the level is 0 and the normal points with the ray (entering a region from outside) [S1]. Specifically:
*   If $Dot(s.normal, R.direction) < 0$:
    *   $level \leftarrow level - 1$
    *   If $level == 0$, keep sample $s$.
*   Else:
    *   If $level == 0$, keep sample $s$.
    *   $level \leftarrow level + 1$

**Parameters:**
*   Not given in the sources.

**Edge Cases and Pitfalls:**
*   Precision errors in sorting or dot products may lead to incorrect nesting levels if samples are coplanar or nearly parallel to the ray [G].
*   The method assumes the input rays are valid representations of volumetric boundaries.

## Subtopics

### Shape Removal with Occlusion Handling
A procedure for handling occlusion when removing an object part that is in front of another one [S2]. Instead of simple boolean subtraction, it zeros out the first mode of density along the ray [S2]. The first mode of density is defined as starting at the first point with non-zero density up to the first subsequent point with zero density [S2]. This procedure is effective but can be slow and may leave artifacts of incomplete removal [S2].

### Volume Carving
A technique to remove occluding structures by skipping ray integration steps that intersect with a specified geometric shape (e.g., sphere, cone, cylinder) [S3]. It uses an Init shader to compute start and stopping coordinates of the carving shape [S3]. If the ray intersects the shape, the integration start position (`currentDistance`) is adjusted to the intersection point [S3].

**Parameters:**
*   `interactionPoint1`: A user-defined 3D coordinate used to determine the center of the carving shape (e.g., sphere) [S3].
*   `currentDistance`: A built-in variable specifying the next integration position along the ray [S3].
*   `sphereRadius`: The radius of the carving sphere [S3].

**Pseudocode (Volume Carving Init Shader):**
```python
# Determine if ray is intersecting the sphere
centerDir = interactionPoint1 - rayStart
centerProjDist = dot(centerDir, rayDir)
centerProj = rayStart + rayDir * centerProjDist
distCenterProjCenter = length(centerProj - interactionPoint1)

# if we have an intersection, adjust ray integration start
if distCenterProjCenter < sphereRadius:
    dcpc2 = distCenterProjCenter * distCenterProjCenter
    sr2 = sphereRadius * sphereRadius
    intersectDistance = centerProjDist + sqrt(sr2 - dcpc2)
    if intersectDistance > 0.0:
        currentDistance = intersectDistance
```

## Operating characteristics
*   **Time Complexity:** Dominated by the sorting step, $O(N \log N)$ where $N$ is the total number of samples in both rays, plus the linear scan of `MergeRegion`, $O(N)$ [S1].
*   **Memory Complexity:** $O(N)$ to store the merged list [S1].
*   **Strengths:** Simple to implement; leverages existing union and merge logic [S1].
*   **Limitations:** The basic boolean subtraction does not handle occlusion well (e.g., removing a front object while keeping a back object) without additional density zeroing techniques [S2]. The volume carving variant can be slow and may leave artifacts [S2].
*   **When to use:** When performing boolean sculpting on volumetric meshes or ray lists where topological correctness is required [S1].
*   **When not to use:** When occlusion handling is critical and performance is constrained, or when the geometry is complex enough that simple ray list manipulation fails to capture the visual intent [S2].

## Background
The method originates from work on detail sculpting using cubical marching squares [S1]. It was introduced as Algorithm 3 in the paper "Detail sculpting using cubical marching squares" [S1]. The technique is similar to Ray Union but relies on normal inversion to achieve subtraction semantics [S1]. Variants like Volume Carving were later explored in the context of interactive GPU volume rendering shaders using frameworks like PRISM [S3], and occlusion-aware removal was discussed in the context of editing Conditional Radiance Fields [S2].
