# Region Nesting Merge

Also called: MergeRegion

## Overview
Region Nesting Merge is a post-processing step for topological ray operations that removes nested inner regions from a sorted list of ray samples [S1]. It solves the problem of redundant or invalid geometry resulting from boolean unions or subtractions, where one volumetric region is contained entirely within another [S1]. It differs from [Ray Crossing Count](915-ray-crossing-count-winding-number.md) by relying on the orientation of surface normals relative to the ray direction to determine nesting depth, rather than counting geometric intersections [S1]. It is a core component of [Ray Union](13991-region-nesting-merge.md) and [Ray Subtraction](14029-ray-subtraction.md) [S1].

## How it works
**Inputs and Outputs**
The input is a ray $R$ containing a list of samples $R.list$ sorted by position along the ray [S1]. Each sample $s$ contains a position and a normal vector $s.normal$ [S1]. The ray contains a direction vector $R.direction$ [S1]. The output updates $R.list$ to contain only the samples defining the outermost boundaries of the volumetric regions, effectively removing any samples that define regions strictly inside other regions [S1].

**Data Structures**
The ray structure holds a direction vector and a list of samples [S1]. Each sample structure holds a position and a normal vector [S1]. A temporary list $T$ is allocated to accumulate the surviving samples [S1].

**Algorithm**
The procedure iterates through the sorted samples while maintaining a nesting level counter [S1]. The logic treats a sample with a normal pointing against the ray direction as an entry into a volume, and a normal pointing with the ray direction as an exit [S1]. 
1. Initialize a nesting level counter $level = 0$ [S1].
2. Initialize an empty output list $T$ [S1].
3. For each sample $s$ in the sorted input list $R.list$:
   a. Calculate the dot product $D = \mathbf{n}_s \cdot \mathbf{d}_R$ [S1].
   b. If $D < 0$ (normal opposes ray direction, entering a region): decrement $level$ by 1 [S1]. If $level == 0$, add $s$ to $T$ [S1].
   c. Else ($D \ge 0$, normal aligns with ray direction, leaving a region): if $level == 0$, add $s$ to $T$ [S1]. Increment $level$ by 1 [S1].
4. Replace $R.list$ with $T$ [S1].

**Pseudocode**
```python
def MergeRegion(R):
    level = 0
    T = []
    for s in R.list:
        dot_product = dot(s.normal, R.direction)
        if dot_product < 0:
            level = level - 1
            if level == 0:
                T.append(s)
        else:
            if level == 0:
                T.append(s)
            level = level + 1
    R.list = T
```

**Parameters**
$R.direction$ is the direction vector of the ray [S1]. $s.normal$ is the normal vector of the sample [S1]. The normals must be consistent with the topological definition of the volume, typically outward-facing for standard union logic [G].

**Edge Cases and Pitfalls**
The input list $R.list$ must be strictly sorted by position along the ray, otherwise the nesting logic fails [S1]. The algorithm relies on the convention that normals pointing against the ray direction denote entry, which must be maintained across all samples [S1]. In [Ray Subtraction](14029-ray-subtraction.md), the normals of the subtracted volume are inverted before merging to satisfy this convention for the subtraction logic [S1]. If the list is empty, the output is empty [G]. If the nesting level does not return to 0 at the end of the list, the input data is topologically inconsistent (e.g., an unpaired entry or exit) [G].

## Operating characteristics
The time complexity is $O(N)$, where $N$ is the number of samples in $R.list$, as the algorithm performs a single pass through the list [G]. The memory complexity is $O(N)$ in the worst case, as a new list $T$ is created [G]. The method is simple, efficient, and robust for boolean operations on ray-based volumetric representations [G]. It assumes a specific normal orientation convention and requires pre-sorted input [G]. It does not handle complex self-intersections or non-manifold geometry that violates the entry/exit pairing assumption [G].

## Background
Region Nesting Merge was introduced in the context of detail sculpting using cubical marching squares [S1]. It serves as the core mechanism for resolving topological conflicts in ray-based boolean operations [S1]. The method is part of a family of topological inside tests that use normal orientation to determine volumetric inclusion [S1].
