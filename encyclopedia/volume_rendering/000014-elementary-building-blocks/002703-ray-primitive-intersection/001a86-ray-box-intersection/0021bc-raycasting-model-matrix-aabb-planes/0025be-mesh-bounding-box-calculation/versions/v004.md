# Mesh Bounding Box Calculation

Also called: axis-aligned bounding box, min-max vertex bounds

## Overview
Computes the axis-aligned bounding box (AABB) of a mesh by determining the minimum and maximum coordinates across all vertices [S1, unofficial]. It differs from [Character Bounding Box Initialization](4016-character-bounding-box-initialization.md) by processing explicit vertex buffers rather than parametric curves, and from [Volume Bounds Computation](5114-volume-bounds-computation.md) by operating on structured mesh geometry rather than arbitrary point clouds [S1, unofficial].

## How it works
**Inputs:** A list of 3D vertices $V = \{v_0, v_1, \dots, v_{n-1}\}$, where each $v_i$ has components $(x_i, y_i, z_i)$.
**Outputs:** An AABB defined by minimum vector $\mathbf{min}$ and maximum vector $\mathbf{max}$.

**Data Structures:**
- `Vec3`: A structure containing three floating-point components (e.g., `m_x`, `m_y`, `m_z`) [S1, unofficial].
- `mn`, `mx`: `Vec3` instances storing the current bounds.

**Steps:**
1. **Initialize:** Set `mn` and `mx` to the coordinates of the first vertex $v_0$.
   $$ \mathbf{mn} = v_0, \quad \mathbf{mx} = v_0 $$
2. **Iterate:** For each vertex $v_i$ from index $1$ to $n-1$:
   - For each dimension $d \in \{0, 1, 2\}$ (representing X, Y, Z):
     $$ \mathbf{mn}[d] = \min(\mathbf{mn}[d], v_i[d]) $$
     $$ \mathbf{mx}[d] = \max(\mathbf{mx}[d], v_i[d]) $$

**Pitfalls:**
- **Empty Input:** The method assumes $n \ge 1$. Accessing $v_0$ on an empty vertex list causes undefined behavior [S1, unofficial]. A guard check for empty input is required before initialization [G].

**Pseudocode:**
```python
def compute_mesh_aabb(vertices):
    """
    Computes the AABB for a mesh given a list of 3D vertices.
    
    Args:
        vertices: List of tuples or objects with x, y, z attributes.
        
    Returns:
        (min_vec, max_vec): Tuples of (x, y, z) floats.
        
    Raises:
        ValueError: If vertices list is empty.
    """
    if not vertices:
        raise ValueError("Vertex list cannot be empty")
        
    # Initialize min and max with the first vertex
    first = vertices[0]
    mn = (first.x, first.y, first.z)
    mx = (first.x, first.y, first.z)
    
    # Iterate through remaining vertices
    for i in range(1, len(vertices)):
        v = vertices[i]
        # Update min and max for each dimension
        mn = (
            min(mn[0], v.x),
            min(mn[1], v.y),
            min(mn[2], v.z)
        )
        mx = (
            max(mx[0], v.x),
            max(mx[1], v.y),
            max(mx[2], v.z)
        )
        
    return mn, mx
```

## Subtopics

### Bounding Cube Creation
Creates a cubic bounding box (AABox) from a mesh's AABB by expanding the smaller dimensions to match the largest axis length, padding equally on both sides [S2, unofficial]. It is chosen when a uniform spatial scale is required for voxelization or grid-based operations [S2, unofficial]. The layout is an `AABox<vec3>` structure with `min` and `max` vec3 coordinates [S2, unofficial]. Steps: 1. Compute mesh AABB min/max. 2. Calculate axis lengths $L_i = \text{max}_i - \text{min}_i$. 3. Find $L_{max} = \max(L_x, L_y, L_z)$. 4. For each axis $i$, compute $\delta = L_{max} - L_i$. 5. Update $\text{min}_i \leftarrow \text{min}_i - \delta/2$ and $\text{max}_i \leftarrow \text{max}_i + \delta/2$ [S2, unofficial].

### AABB Vertex Coordinate Encoding
Determines the coordinates of any of the 8 AABB vertices using a vertex index $i \in [0, 7]$ and bit manipulation, avoiding floating-point arithmetic for coordinate selection [S3, unofficial]. It is used when checking plane intersections or other geometric tests requiring explicit vertex access [S3, unofficial]. Rules: Bit 0 corresponds to X, Bit 1 to Y, Bit 2 to Z. If the bit is 0, the coordinate is the min value; if 1, it is the max value [S3, unofficial]. Formula for vertex $i$:
$$ v_x = \text{min}_x \text{ if } (i \& 1) == 0 \text{ else } \text{max}_x $$
$$ v_y = \text{min}_y \text{ if } (i \& 2) == 0 \text{ else } \text{max}_y $$
$$ v_z = \text{min}_z \text{ if } (i \& 4) == 0 \text{ else } \text{max}_z $$
Implementation uses bit masking and shifting: `vertex_i_xyz = [aabb.x_minmax[(i & 1) >> 0], aabb.y_minmax[(i & 2) >> 1], aabb.z_minmax[(i & 4) >> 2]]` [S3, unofficial].

### AABB Enclosure (Union)
Computes the AABB enclosing two input AABBs ($b_0$ and $b_1$) by taking the component-wise minimum of their mins and the component-wise maximum of their maxs [S3, unofficial]. It is used to merge spatial bounds efficiently [S3, unofficial]. Formula:
$$ \text{enclosing\_aabb}.min = (\min(b_0.min_x, b_1.min_x), \min(b_0.min_y, b_1.min_y), \min(b_0.min_z, b_1.min_z)) $$
$$ \text{enclosing\_aabb}.max = (\max(b_0.max_x, b_1.max_x), \max(b_0.max_y, b_1.max_y), \max(b_0.max_z, b_1.max_z)) $$
Implementation:
```python
def enclosing_aabb(b0, b1):
    return {
        'min': (min(b0['min'][0], b1['min'][0]), min(b0['min'][1], b1['min'][1]), min(b0['min'][2], b1['min'][2])),
        'max': (max(b0['max'][0], b1['max'][0]), max(b0['max'][1], b1['max'][1]), max(b0['max'][2], b1['max'][2]))
    }
```
[S3, unofficial].

## Operating characteristics
- **Time Complexity:** $O(n)$, where $n$ is the number of vertices. Each vertex requires a constant number of comparisons.
- **Memory Complexity:** $O(1)$ auxiliary space, storing only two 3D vectors.
- **Strengths:** Simple, fast, and robust for static meshes.
- **Limitations:** Does not account for mesh orientation (requires axis-aligned space); sensitive to floating-point precision for very large or very small coordinates [S1, unofficial].
- **When to use:** Pre-processing step for raycasting, collision detection, or spatial partitioning.
- **When not to use:** When oriented bounding boxes (OBB) are required for tighter fits, or when dealing with dynamic meshes where incremental updates are needed (though this method can be adapted).

## Background
The method is a fundamental geometric primitive in computer graphics, often used as a first step in ray-primitive intersection tests. It is cited in the context of voxelization and raycasting implementations [S1, S2, S3, unofficial]. The specific bit-manipulation trick for vertex encoding is noted as a common but rarely explicitly documented optimization [S3, unofficial].
