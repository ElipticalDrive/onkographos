# Plane-AABB Overlap Test
Also called: Plane vs Bounds Intersection, Plane-AABB Intersection Test, Plane-Box Overlap Test, planeBoxOverlapCUDA

## Overview
Determines if an axis-aligned bounding box (AABB) overlaps with a plane defined by a normal vector and a point, or by a normal and a signed distance [S1, unofficial][S2, unofficial]. It is used in voxelization to determine which voxels intersect with a triangle's plane [S2, unofficial][S4].

## How it works
**Inputs:**
- `plane_normal`: A 3D vector $(n_x, n_y, n_z)$ representing the plane's normal [S2, unofficial][S4].
- `plane_d`: A scalar signed distance from the origin to the plane [S2, unofficial][S4].
- `aabb_center`: A 3D vector $(c_x, c_y, c_z)$ representing the center of the AABB [S4].
- `aabb_extents`: A 3D vector $(e_x, e_y, e_z)$ representing the half-widths of the AABB along each axis [S4].

**Outputs:**
- Boolean: `true` if the AABB intersects or touches the plane; `false` otherwise [S2, unofficial][S4].

**Data Structures:**
- `Vector3`: A struct with fields `x`, `y`, `z` of type `float` [S2, unofficial][S4].
- `Plane`: A struct with fields `normal` (Vector3) and `distance` (float) [S4].
- `Bounds`: A struct with fields `center` (Vector3) and `max` (Vector3) [S4]. Extents are derived as $\mathbf{e} = \mathbf{max} - \mathbf{center}$ [S4].

**Formulas:**
1. **Signed Distance to Center ($s$):** The signed distance from the plane to the AABB center [S4].
   $$s = \mathbf{n} \cdot \mathbf{c} - d$$
2. **Projected Radius ($r$):** The maximum extent of the AABB projected onto the plane normal [S4].
   $$r = e_x |n_x| + e_y |n_y| + e_z |n_z|$$
3. **Overlap Condition:**
   $$|s| \le r$$ [S4].

**Steps:**
1. Calculate the signed distance $s$ from the plane to the AABB center using the dot product of the normal and center, minus the plane's distance parameter [S4].
2. Calculate the projected radius $r$ by summing the products of each AABB extent component and the absolute value of the corresponding normal component [S4].
3. Return `true` if the absolute value of $s$ is less than or equal to $r$; otherwise, return `false` [S4].

**Pseudocode:**
```python
def plane_aabb_overlap(plane_normal, plane_d, aabb_center, aabb_extents):
    """
    plane_normal: (nx, ny, nz)
    plane_d: float, signed distance from origin to plane
    aabb_center: (cx, cy, cz)
    aabb_extents: (ex, ey, ez)
    """
    # Calculate signed distance from plane to AABB center
    s = plane_normal.x * aabb_center.x + \
        plane_normal.y * aabb_center.y + \
        plane_normal.z * aabb_center.z - plane_d

    # Calculate projected radius of AABB onto plane normal
    r = (aabb_extents.x * abs(plane_normal.x) +
         aabb_extents.y * abs(plane_normal.y) +
         aabb_extents.z * abs(plane_normal.z))

    # Check if distance is within projected radius
    return abs(s) <= r
```

**Alternative Implementation (Corner Projection):**
Some implementations compute the minimum and maximum projections of the box corners onto the normal explicitly [S2, unofficial].
```python
def plane_aabb_overlap_corners(plane_normal, plane_d, aabb_center, aabb_extents):
    """
    Alternative method using explicit corner projection.
    Returns true if overlap exists.
    """
    vmin = [0.0, 0.0, 0.0]
    vmax = [0.0, 0.0, 0.0]

    for dim in range(3):
        if plane_normal[dim] > 0.0:
            vmin[dim] = aabb_center[dim] - aabb_extents[dim]
            vmax[dim] = aabb_center[dim] + aabb_extents[dim]
        else:
            vmin[dim] = aabb_center[dim] + aabb_extents[dim]
            vmax[dim] = aabb_center[dim] - aabb_extents[dim]

    dot_vmin = (plane_normal.x * vmin.x +
                plane_normal.y * vmin.y +
                plane_normal.z * vmin.z)
    
    dot_vmax = (plane_normal.x * vmax.x +
                plane_normal.y * vmax.y +
                plane_normal.z * vmax.z)

    # The plane equation is dot(n, x) + d = 0.
    # If dot_vmin + d > 0, the entire box is on the positive side (no overlap).
    if dot_vmin + plane_d > 0.0:
        return False
    
    # If dot_vmax + d >= 0, the box intersects or touches the plane.
    if dot_vmax + plane_d >= 0.0:
        return True

    return False
```

**Edge Cases and Pitfalls:**
- **Precision:** When $|s| \approx r$, floating-point inaccuracies may cause false negatives or positives. Using `>=` and `<=` with a small epsilon is recommended for robustness [G].
- **Degenerate Box:** If extents are zero, the test reduces to checking if the center lies on the plane [G].
- **Normal Normalization:** The normal vector must be normalized for the distance $s$ and radius $r$ calculations to be geometrically correct. If the normal is not normalized, $r$ must be scaled by $1/|\mathbf{n}|$ or $s$ by $|\mathbf{n}|$ [G].

## Operating characteristics
- **Time Complexity:** $O(1)$. Requires a constant number of arithmetic operations (dot products, absolute values, comparisons) [G].
- **Memory Complexity:** $O(1)$. No auxiliary data structures required [G].
- **Performance:** Extremely fast [G].
- **Strengths:** Simple, robust, and efficient. Handles arbitrary plane orientations [G].
- **Limitations:** Only tests against a single plane. Does not provide intersection points or normals [G].
- **When to use:** Voxelization of triangles, frustum culling, clipping volumes [S2, unofficial][S4].
- **When not to use:** When ray-box intersection distances are needed, or when testing against multiple planes (use frustum culling instead) [G].

## Background
The plane-AABB overlap test is used in GPU-based voxelizers to determine which voxels intersect with a triangle's plane [S2, unofficial][S4]. It is derived from the separating axis theorem (SAT), where the plane normal serves as the separating axis [G].
