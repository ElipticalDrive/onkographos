# Random Point Sampling in Bounds

Also called: Uniform Random Point Sampling, sampleCell

## Overview
Generates uniformly distributed random points within a specified 3D bounding box or voxel volume [S1, S2, unofficial]. It differs from structured grid sampling by providing stochastic coverage, which is essential for Monte Carlo integration in volume rendering and neural field training [S1, unofficial]. Unlike spherical sampling methods, this approach assumes an axis-aligned cubic domain, making it computationally cheaper but potentially non-uniform if the underlying geometry is non-cubic [S2, unofficial].

## How it works
**Inputs:**
- `num_points`: Integer specifying the number of random points to generate [S1, unofficial].
- `bounds`: A tuple or list containing two elements: `min_bound` (array of 3 floats) and `max_bound` (array of 3 floats) defining the axis-aligned bounding box [S1, unofficial].
- `device`: The computational device (e.g., 'cpu', 'cuda') for tensor operations [S1, unofficial].

**Outputs:**
- A tensor of shape `(num_points, 3)` containing the sampled 3D coordinates [S1, unofficial].

**Data Structures:**
- Tensors are used for `min_bound`, `max_bound`, and the output points. The bounds are converted to tensors on the specified device and expanded with a batch dimension if necessary for broadcasting [S1, unofficial].

**Steps:**
1. Convert `min_bound` and `max_bound` to tensors on the specified `device` [S1, unofficial].
2. Generate `num_points` random values from a uniform distribution $\mathcal{U}[0, 1)$ for each of the 3 dimensions, resulting in a tensor of shape `(num_points, 3)` [S1, unofficial].
3. Calculate the volume span: $\Delta = \text{max\_bound} - \text{min\_bound}$ [S1, unofficial].
4. Scale the random values by $\Delta$ to map the range $[0, 1)$ to $[0, \Delta)$ [S1, unofficial].
5. Add `min_bound` to the scaled random values to shift the range to $[\text{min\_bound}, \text{max\_bound})$ [S1, unofficial].

**Alternative Voxel-Centric Formulation:**
Some implementations define the sampling relative to a voxel center $c$ and size $s$ [S2, unofficial]. In this case:
1. Generate three independent uniform random values $\mathbf{r} \sim \mathcal{U}(-1, 1)^3$ [S2, unofficial].
2. Scale $\mathbf{r}$ by the voxel size vector $s$ [S2, unofficial].
3. Add the result to the voxel center $c$ to obtain the point $p$ [S2, unofficial].
   $$ p = c + \mathbf{r} \cdot s $$
   where $\mathbf{r}$ is a vector of random values in $(-1, 1)$ and $s$ is the voxel dimension vector [S2, unofficial].

**Parameters:**
- `num_points`: Typical values depend on the training batch size or ray count [S1, unofficial].
- `bounds`: Defined by the scene geometry or voxel grid resolution [S1, S2, unofficial].

**Edge Cases and Pitfalls:**
- **Non-Cubic Voxels:** If the voxel is not a cube (i.e., $s_x \neq s_y \neq s_z$), the sampling density remains uniform in the axis-aligned box, but the geometric representation may distort if spherical symmetry is assumed [S2, unofficial].
- **Precision:** Using floating-point arithmetic for large bounding boxes may introduce precision errors; ensure the device supports sufficient precision for the coordinate range [S1, unofficial].
- **Boundary Conditions:** The distribution is typically half-open $[min, max)$, meaning points exactly on the maximum boundary are excluded [S1, unofficial].

**Pseudocode:**
```python
import torch

def random_point_sampling_in_bounds(num_points, bounds, device):
    """
    Generate uniformly distributed random points within a 3D bounding box.
    
    Args:
        num_points (int): Number of points to sample.
        bounds (tuple): (min_bound, max_bound) as tensors or arrays of shape (3,).
        device (str): Target device ('cpu', 'cuda', etc.).
        
    Returns:
        torch.Tensor: Sampled points of shape (num_points, 3).
    """
    min_bound, max_bound = bounds
    
    # Convert to tensors on the specified device
    min_tensor = torch.tensor(min_bound, dtype=torch.float32, device=device)
    max_tensor = torch.tensor(max_bound, dtype=torch.float32, device=device)
    
    # Generate random numbers in [0, 1)
    # Shape: (num_points, 3)
    random_vals = torch.rand(num_points, 3, device=device)
    
    # Calculate bounds span
    span = max_tensor - min_tensor
    
    # Scale and shift
    # Broadcasting: span (1, 3) or (3,) scales random_vals (num_points, 3)
    points = min_tensor + random_vals * span
    
    return points
```

## Subtopics

### Structured Grid Sampling
Generates points on a fixed lattice. Use when deterministic coverage is required. [Link](2383-structured-grid-sampling.md)

### Spherical Sampling
Generates points uniformly on a sphere or within a sphere. Use when rotational symmetry is needed. [Link](2384-spherical-sampling.md)

## Operating characteristics
- **Time Complexity**: $O(N)$, where $N$ is `num_points`, as it involves generating $3N$ random numbers and basic arithmetic operations [S1, unofficial].
- **Memory Complexity**: $O(N)$ to store the output tensor [S1, unofficial].
- **Performance**: Highly efficient on GPUs due to parallel random number generation and vectorized operations [S1, unofficial].
- **Strengths**: Simple to implement, fast, and provides uniform coverage of the axis-aligned volume [S1, S2, unofficial].
- **Limitations**: Does not account for non-cubic voxel shapes or spherical symmetry, which may lead to biased sampling in those contexts [S2, unofficial].
- **When to Use**: Monte Carlo integration, neural field training, and volume rendering where axis-aligned bounding boxes are sufficient [S1, S2, unofficial].
- **When Not to Use**: When spherical symmetry is required or when the domain is not axis-aligned [S2, unofficial].

## Background
The method is commonly used in neural surface and volume rendering pipelines, such as those found in the Neural Surfaces repository [S1, unofficial]. It is also employed in level-of-detail training schemes for 3D Gaussian Splatting variants, where random points within voxel bounds are sampled for densification or pruning decisions [S2, unofficial]. The technique relies on basic uniform random number generation, a standard primitive in computer graphics and scientific computing.
