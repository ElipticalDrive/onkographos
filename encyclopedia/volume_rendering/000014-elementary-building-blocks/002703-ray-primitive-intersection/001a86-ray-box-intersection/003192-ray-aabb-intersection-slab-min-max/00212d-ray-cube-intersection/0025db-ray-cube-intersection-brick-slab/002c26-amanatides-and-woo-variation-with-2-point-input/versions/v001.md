# Amanatides and Woo Variation with 2-Point Input

Also called: 2-Point Voxel Traversal, Improved Amanatides and Woo

## Overview
This method traverses a voxel grid by accepting two explicit 3D points (start and end) rather than a ray origin and direction vector. It is designed to handle edge cases such as zero coordinate deltas, exact edge hits, negative traversal, and non-0-based block centers with higher precision than standard face-to-face traversal [S1, unofficial]. It builds on the Amanatides and Woo DDA logic but adapts the initialization and comparison logic to operate directly on point pairs [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: `pointA` (start position, `Vector3`), `pointB` (end position, `Vector3`).
- Output: An iterable sequence of `Vector3` coordinates representing the integer voxel centers (or grid indices) intersected by the line segment.

**Data Structures:**
- `x, y, z`: Current voxel coordinates (floats, initialized to rounded `pointA`).
- `tMaxX, tMaxY, tMaxZ`: Distance along the segment to the next voxel boundary in each axis.
- `tDeltaX, tDeltaY, tDeltaZ`: Distance between consecutive voxel boundaries in each axis.
- `stepX, stepY, stepZ`: Direction signs (+1 or -1) for traversal.
- `lineLength`: Total Euclidean length of the segment `pointB - pointA`.

**Formulas and Definitions:**
- `delta = pointB - pointA`
- `deltaNormal = delta / |delta|` (Normalized direction vector).
- `dx, dy, dz`: Components of `deltaNormal`.
- `Signum(v)`: Returns 1 if $v > 0$, -1 if $v < 0$, and 0 if $v == 0$.
- `Intbound(s, ds)`: Calculates the distance to the next integer boundary.
  - If $ds < 0$ and $s$ is an integer, return 0.
  - Else, let $s' = s \pmod 1$ (using `Mod(v, m) = (v \% m + m) \% m`).
  - If $ds > 0$, return $(\lceil s' \rceil - s') / |ds|$. Note: $\lceil s' \rceil$ returns 1 if $s' == 0$, otherwise standard ceiling.
  - If $ds < 0$, return $(s' - \lfloor s' \rfloor) / |ds|$.
- `Precision5(val)`: Rounds `val` to 5 decimal places using integer arithmetic: `((int)(100000 * val)) / 100000.0f`. This mitigates floating-point precision issues during comparisons [S1, unofficial].

**Step Functions:**
Each step function checks if the current `tMax` exceeds `lineLength`. If so, traversal ends (returns `true`). Otherwise, it increments the voxel coordinate by `step` and adds `tDelta` to `tMax` (returns `false`).
- `StepX()`: If `tMaxX >= lineLength` return `true`. Else `x += stepX`, `tMaxX += tDeltaX`, return `false`.
- `StepY()`: Analogous for Y.
- `StepZ()`: Analogous for Z.

**Algorithm Steps:**
1. **Initialization:**
   - Set `x = round(pointA.X)`, `y = round(pointA.Y)`, `z = round(pointA.Z)`.
   - Compute `delta`, `deltaNormal`, `dx, dy, dz`.
   - Compute `stepX, stepY, stepZ` using `Signum`.
   - Compute `tMaxX, tMaxY, tMaxZ` using `Intbound(pointA.X - 0.5f, deltaNormal.x)`, etc. The `-0.5f` offset accounts for blocks being centered at 0.5-based coordinates rather than 0-based [S1, unofficial].
   - Compute `tDeltaX = stepX / dx` (handle division by zero if `dx=0` by setting `tDeltaX` to infinity or skipping, though the source implies `dx` is non-zero when `stepX` is non-zero).
   - Compute `lineLength = |delta|`.
   - Initialize result list with `(x, y, z)`.

2. **Iteration:**
   The iteration logic depends on which steps are non-zero. The source provides specific logic for the 3D case (all steps non-zero) and mentions separate loops for 2D/1D cases.

   **3D Case (`stepX != 0 && stepY != 0 && stepZ != 0`):**
   Loop while `true`:
   - Compute `tX = Precision5(tMaxX)`, `tY = Precision5(tMaxY)`, `tZ = Precision5(tMaxZ)`.
   - Compare `tX, tY, tZ`:
     - If `tX < tY`:
       - If `tX < tZ`: `res = StepX()`
       - Else if `tZ < tX`: `res = StepZ()`
       - Else (`tZ == tX`): `res = StepZ() || StepX()` (Execute both, result is true if either ends traversal).
     - Else if `tY < tX`:
       - If `tY < tZ`: `res = StepY()`
       - Else if `tZ < tY`: `res = StepZ()`
       - Else (`tZ == tY`): `res = StepY() || StepZ()`
     - Else (`tX == tY`):
       - If `tY < tZ`: `res = StepX() || StepY()`
       - Else if `tZ < tY`: `res = StepZ()`
       - Else (`tZ == tY`): `res = StepX() || StepY() || StepZ()`
   - Add current `(x, y, z)` to result list.
   - If `res` is `true`, break loop.

   **2D/1D Cases:**
   Separate `while` loops handle cases where one or two steps are zero. The logic compares only the relevant `tMax` values. For example, if `stepX != 0 && stepY == 0 && stepZ == 0`, only `StepX()` is called in a loop until it returns `true`.

**Pseudocode:**

```python
import math

def signum(v):
    if v > 0: return 1
    if v < 0: return -1
    return 0

def mod(v, m):
    return (v % m + m) % m

def intbound(s, ds):
    # If ds < 0 and s is integer, return 0
    if ds < 0 and s == math.floor(s):
        return 0
    # s = Mod(s, 1)
    s_mod = mod(s, 1.0)
    if ds > 0:
        # Ceil(s_mod) returns 1 if s_mod == 0, else ceil
        if s_mod == 0:
            ceil_s = 1.0
        else:
            ceil_s = math.ceil(s_mod)
        return (ceil_s - s_mod) / abs(ds)
    else:
        # ds < 0
        floor_s = math.floor(s_mod)
        return (s_mod - floor_s) / abs(ds)

def precision5(val):
    return ((int)(100000 * val)) / 100000.0

def get_intersected_world_blocks(pointA, pointB):
    line = []
    
    # Initialization
    x = math.floor(pointA[0] + 0.5) # Round
    y = math.floor(pointA[1] + 0.5)
    z = math.floor(pointA[2] + 0.5)
    
    line.append((x, y, z))
    
    dx_raw = pointB[0] - pointA[0]
    dy_raw = pointB[1] - pointA[1]
    dz_raw = pointB[2] - pointA[2]
    
    length = math.sqrt(dx_raw**2 + dy_raw**2 + dz_raw**2)
    
    if length == 0:
        return line
        
    dx = dx_raw / length
    dy = dy_raw / length
    dz = dz_raw / length
    
    stepX = signum(dx)
    stepY = signum(dy)
    stepZ = signum(dz)
    
    # Intbound with -0.5f offset
    tMaxX = intbound(pointA[0] - 0.5, dx)
    tMaxY = intbound(pointA[1] - 0.5, dy)
    tMaxZ = intbound(pointA[2] - 0.5, dz)
    
    # Handle division by zero for tDelta if step is 0
    tDeltaX = (stepX / dx) if dx != 0 else float('inf')
    tDeltaY = (stepY / dy) if dy != 0 else float('inf')
    tDeltaZ = (stepZ / dz) if dz != 0 else float('inf')
    
    def step_x():
        nonlocal x, tMaxX
        if tMaxX >= length:
            return True
        x += stepX
        tMaxX += tDeltaX
        return False

    def step_y():
        nonlocal y, tMaxY
        if tMaxY >= length:
            return True
        y += stepY
        tMaxY += tDeltaY
        return False

    def step_z():
        nonlocal z, tMaxZ
        if tMaxZ >= length:
            return True
        z += stepZ
        tMaxZ += tDeltaZ
        return False

    # Iteration based on active steps
    active_x = stepX != 0
    active_y = stepY != 0
    active_z = stepZ != 0
    
    while True:
        res = False
        
        if active_x and active_y and active_z:
            tX = precision5(tMaxX)
            tY = precision5(tMaxY)
            tZ = precision5(tMaxZ)
            
            if tX < tY:
                if tX < tZ:
                    res = step_x()
                elif tZ < tX:
                    res = step_z()
                else:
                    res = step_z() or step_x()
            elif tY < tX:
                if tY < tZ:
                    res = step_y()
                elif tZ < tY:
                    res = step_z()
                else:
                    res = step_y() or step_z()
            else: # tX == tY
                if tY < tZ:
                    res = step_x() or step_y()
                elif tZ < tY:
                    res = step_z()
                else:
                    res = step_x() or step_y() or step_z()
                    
        elif active_x and not active_y and not active_z:
            res = step_x()
        elif not active_x and active_y and not active_z:
            res = step_y()
        elif not active_x and not active_y and active_z:
            res = step_z()
        elif active_x and active_y and not active_z:
            tX = precision5(tMaxX)
            tY = precision5(tMaxY)
            if tX < tY:
                res = step_x()
            elif tY < tX:
                res = step_y()
            else:
                res = step_x() or step_y()
        elif active_x and not active_y and active_z:
            tX = precision5(tMaxX)
            tZ = precision5(tMaxZ)
            if tX < tZ:
                res = step_x()
            elif tZ < tX:
                res = step_z()
            else:
                res = step_x() or step_z()
        elif not active_x and active_y and active_z:
            tY = precision5(tMaxY)
            tZ = precision5(tMaxZ)
            if tY < tZ:
                res = step_y()
            elif tZ < tY:
                res = step_z()
            else:
                res = step_y() or step_z()
        else:
            # All zero steps, should not happen if length > 0
            break
            
        line.append((x, y, z))
        if res:
            break
            
    return line
```

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of voxels traversed. The number of steps is proportional to the length of the segment in voxel units.
- **Memory Complexity:** Linear with respect to the number of voxels traversed, as all intersected voxels are stored in the output list.
- **Strengths:** Handles edge cases (zero deltas, exact edge hits, negative traversal) more robustly than standard implementations. The `Precision5` helper reduces floating-point comparison errors.
- **Limitations:** The source notes it "might (and probably will) be slower" than standard face-to-face traversal due to the overhead of precision rounding and complex branching logic for equality cases [S1, unofficial].
- **When to use:** When high precision is required for voxel selection, especially with non-0-based block centers or when dealing with degenerate rays (zero length or axis-aligned).

## Background
This method is described as a variation of the Amanatides and Woo algorithm, adapted for a voxel game context where blocks are centered at 0.5-based coordinates. It was shared on GameDev Stack Exchange in 2013 to address specific edge cases not handled by existing code [S1, unofficial].
