# Point-Triangle Distance

Also called: Closest Point on Triangle, Point to Triangle Distance, closestPointOnTriangleToPoint, pointToTriangleDistSqr

## Overview
Computes the closest point on a triangle to a query point and returns the squared distance, handling all edge and vertex cases via Voronoi-region decomposition. It differs from [Ray-primitive intersection](769-ray-primitive-intersection.md) by solving a static point-to-mesh query rather than a ray-scene traversal, and from [General Ray-Triangle Intersection (Plücker Coordinates)](909-general-ray-triangle-intersection-pl-cker-coordinates.md) by returning the geometric closest point rather than an intersection parameter.

## How it works
**Inputs:** Triangle vertices $v_0, v_1, v_2$ (3D vectors); query point $p$ (3D vector).
**Outputs:** Barycentric coordinates $t_0, t_1$ of the closest point relative to $v_0$, and the squared distance $d^2$.
**Data Structures:** No persistent structures; local scalar and vector variables.

**Steps:**
1.  Compute edge vectors: $e_0 = v_1 - v_0$, $e_1 = v_2 - v_0$.
2.  Compute vector from vertex to point: $v_0 = v_0 - p$.
3.  Compute dot products:
    $$a = e_0 \cdot e_0$$
    $$b = e_0 \cdot e_1$$
    $$c = e_1 \cdot e_1$$
    $$d = e_0 \cdot v_0$$
    $$e = e_1 \cdot v_0$$
4.  Compute determinant and barycentric numerators:
    $$det = a \cdot c - b \cdot b$$
    $$s = b \cdot e - c \cdot d$$
    $$t = b \cdot d - a \cdot e$$
5.  Determine region based on $s + t$ relative to $det$:
    *   **Case 1: $s + t \le det$** (Closest point is in the region of vertex $v_0$ or on an adjacent edge/face interior).
        *   If $s < 0$ and $t < 0$:
            *   If $d < 0$: $s = \text{clamp}(-d/a, 0, 1)$, $t = 0$.
            *   Else: $s = 0$, $t = \text{clamp}(-e/c, 0, 1)$.
        *   Else if $s < 0$: $s = \text{clamp}(-d/a, 0, 1)$, $t = 0$.
        *   Else if $t < 0$: $s = 0$, $t = \text{clamp}(-e/c, 0, 1)$.
    *   **Case 2: $s + t > det$** (Closest point is outside the edge opposite $v_0$).
        *   Compute $tmp_0 = b + d$, $tmp_1 = c + e$.
        *   If $s < 0$:
            *   If $tmp_1 > tmp_0$: $s = \text{clamp}((tmp_1 - tmp_0) / (a - 2b + c), 0, 1)$, $t = 1 - s$.
            *   Else: $s = 0$, $t = \text{clamp}(-e/c, 0, 1)$.
        *   Else if $t < 0$:
            *   If $a + d > b + e$: $s = \text{clamp}((c + e - b - d) / (a - 2b + c), 0, 1)$, $t = 1 - s$.
            *   Else: $s = \text{clamp}(-e/c, 0, 1)$, $t = 0$.
6.  Compute closest point: $closest = v_0 + s \cdot e_0 + t \cdot e_1$.
7.  Return squared distance: $d^2 = \|closest - p\|^2$.

**Pseudocode:**
```python
def point_to_triangle_dist_sqr(v0, v1, v2, p):
    # Edge vectors
    e0 = v1 - v0
    e1 = v2 - v0
    # Vector from v0 to p
    v0_vec = v0 - p
    
    # Dot products
    a = dot(e0, e0)
    b = dot(e0, e1)
    c = dot(e1, e1)
    d = dot(e0, v0_vec)
    e = dot(e1, v0_vec)
    
    # Determinant and barycentric coordinates
    det = a * c - b * b
    s = b * e - c * d
    t = b * d - a * e
    
    # Clamp function
    def clamp(val, min_val, max_val):
        return max(min_val, min(val, max_val))
    
    # Region checks
    if s + t <= det:
        if s < 0 and t < 0:
            if d < 0:
                s = clamp(-d / a, 0, 1)
                t = 0
            else:
                s = 0
                t = clamp(-e / c, 0, 1)
        elif s < 0:
            s = clamp(-d / a, 0, 1)
            t = 0
        elif t < 0:
            s = 0
            t = clamp(-e / c, 0, 1)
    else:
        tmp0 = b + d
        tmp1 = c + e
        if s < 0:
            if tmp1 > tmp0:
                denom = a - 2 * b + c
                s = clamp((tmp1 - tmp0) / denom, 0, 1)
                t = 1 - s
            else:
                s = 0
                t = clamp(-e / c, 0, 1)
        elif t < 0:
            if a + d > b + e:
                denom = a - 2 * b + c
                s = clamp((c + e - b - d) / denom, 0, 1)
                t = 1 - s
            else:
                s = clamp(-e / c, 0, 1)
                t = 0
                
    # Closest point
    closest = v0 + s * e0 + t * e1
    
    # Squared distance
    return dot(closest - p, closest - p)
```

**Parameters:**
*   $v_0, v_1, v_2$: Triangle vertices.
*   $p$: Query point.
*   `Vec3T`: Any vector type supporting arithmetic and dot product [S1].

**Edge Cases:**
*   Degenerate triangles (zero area, collinear, or coincident vertices) are handled implicitly: the face-interior test fails, and the code falls through to the nearest edge or vertex result [S1].
*   Division by zero in `clamp(-d/a)` or `clamp(-e/c)` occurs if $a=0$ or $c=0$ (degenerate edges). [G] In practice, if $a \approx 0$, $v_0 \approx v_1$, so $s$ should be 0. If $c \approx 0$, $v_0 \approx v_2$, so $t$ should be 0. The sources do not explicitly guard against this, relying on the logic that $d$ or $e$ will also be small, but division by zero is a risk [S1][S2, unofficial].

## Subtopics

### Unsigned Quadrilateral Distance
Computes the unsigned distance from a point to a quadrilateral defined by four vertices $a, b, c, d$. It checks if the point is inside the projected quad to decide between edge distance and plane distance [S3, unofficial]. If the point is inside the quad (sum of signs < 3), it returns the minimum squared distance to the four edges. Otherwise, it returns the squared distance to the plane containing the quad [S3, unofficial]. Edge distance uses projection: $\text{proj}_{ba}(pa) = ba \cdot \text{clamp}(\frac{ba \cdot pa}{\|ba\|^2}, 0, 1)$ [S3, unofficial]. Parameters: $a, b, c, d$ are vec3 vertices in order [S3, unofficial].

### Unsigned Triangle Distance
Computes the unsigned distance from a point to a triangle defined by three vertices $a, b, c$. It checks if the point is inside the projected triangle to decide between edge distance and plane distance [S3, unofficial]. If the point is inside the triangle (sum of signs < 2), it returns the minimum squared distance to the three edges. Otherwise, it returns the squared distance to the plane containing the triangle [S3, unofficial]. Edge distance uses projection: $\text{proj}_{ba}(pa) = ba \cdot \text{clamp}(\frac{ba \cdot pa}{\|ba\|^2}, 0, 1)$ [S3, unofficial]. Parameters: $a, b, c$ are vec3 vertices [S3, unofficial].

## Operating characteristics
Time complexity is $O(1)$ with a constant number of arithmetic operations. Memory complexity is $O(1)$. Performance is hardware-independent but sensitive to branch divergence in SIMD implementations due to the region checks. Strengths include robustness to degenerate triangles and exact handling of edge/vertex cases. Limitations include lack of explicit normalization for degenerate edges, which may cause division by zero if not guarded [G]. Use for collision detection, point cloud fitting, and SDF generation. Do not use for ray-triangle intersection where parameter $t$ along a ray is required.

## Background
Originated from Ericson's "Real-Time Collision Detection" (Sec. 5.1.5) [S1]. Implemented in OpenVDB's `nanovdb::math` namespace [S1] and various voxelization tools [S2, unofficial]. Used in volume rendering for point-to-mesh distance queries in SDF-based rendering and collision handling.
