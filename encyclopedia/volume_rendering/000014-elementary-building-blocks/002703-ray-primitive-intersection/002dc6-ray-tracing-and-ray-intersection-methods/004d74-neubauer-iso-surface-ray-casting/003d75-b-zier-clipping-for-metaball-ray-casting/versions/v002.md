# Bézier Clipping for Metaball Ray Casting

Also called: Nishita et al. method, Ray-isosurface test using Bézier form

## Overview
This method computes the ray-isosurface intersection for metaballs by representing the scalar density field along a viewing ray as a polynomial in Bézier form and applying Bézier clipping to find the root [S1]. It builds on [Neubauer Iso-surface Ray Casting](7024-neubauer-iso-surface-ray-casting.md) [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A viewing ray defined by origin and direction; a set of $N$ metaballs (spheres) with centers $(x_i, y_i, z_i)$ and effective radii $R_i$ in the viewing coordinate system; a target isosurface value $\tau$; and a parameter interval $s \in [0, 1]$ representing the ray segment [S1].
*   **Output:** The intersection point(s) on the isosurface, or null if no intersection exists in the interval [S1].

**Data Structures:**
*   **Bézier Coefficients:** For each metaball $i$, a set of coefficients $\{d_m^i\}$ representing the density function $f_i(s)$ of degree $M$ [S1].
*   **Combined Density:** The sum of individual metaball densities, also represented in Bézier form [S1].

**Step-by-Step Method:**

1.  **Ray-Sphere Intersection Test:**
    For each metaball $i$, determine if the ray intersects the sphere [S1]. Calculate the determinant $D_i$ of the quadratic equation for the ray-sphere intersection [S1]. If no intersection, skip the metaball [S1]. Define the parameter $a_i$ as:
    $$ a_i = \frac{D_i}{R_i} $$
    where $R_i$ is the effective radius of metaball $i$ [S1].

2.  **Compute Bézier Coefficients for Single Metaball:**
    Calculate the coefficients $\{d_m^i\}$ for the density function $f_i(s)$ of degree $M$ based on the polynomial degree used for the metaball definition [S1].
    
    *   **For Quartic Polynomial (Degree 4):**
        $$ d_0^i = d_1^i = d_3^i = d_4^i = 0 $$
        $$ d_2^i = \frac{8}{3} a_i^2 $$
        
    *   **For Degree-Six Polynomial (Degree 6):**
        $$ d_0^i = d_1^i = d_5^i = d_6^i = 0 $$
        $$ d_2^i = d_4^i = \frac{16}{27} a_i^2 $$
        $$ d_3^i = \frac{8(8a_i + 5)a_i^2}{45} $$

3.  **Clipping for Combined Density:**
    For $N$ metaballs intersecting the ray in the given interval, compute the coefficients of the total density function [S1]. The total density is the sum of individual densities [S1]. To maintain the Bézier form and enable clipping, apply de Casteljau's algorithm to clip the Bézier curve defined by $\{d_m^i\}$ for each metaball to the current interval, then sum the resulting control points [S1]. Let the combined Bézier coefficients be $\{D_m\}$ [S1].

4.  **Ray-Isosurface Test:**
    Substitute the combined density function in Bézier form into the ray-isosurface test equation to obtain the equation for the ray-isosurface test at that interval [S1]. This yields a polynomial equation in Bézier form representing the distance from the isosurface [S1].

5.  **Bézier Clipping:**
    Apply Bézier clipping to the resulting polynomial to isolate roots within $s \in [0, 1]$ [S1]. This involves iteratively clipping the domain based on the convex hull property of the Bézier curve until the root is found or the interval is discarded [S1].

**Bounding Rectangle Calculation (Culling):**
To efficiently cull metaballs that do not intersect the screen, calculate the bounding rectangle of the sphere's projection on the screen [S1]. Let $(x_i, y_i, z_i)$ be the center of sphere $i$ in the viewing coordinate system, $R_i$ its radius, and $z_{\text{screen}}$ the distance from the viewpoint to the screen [S1]. The x and y coordinates of the bounding rectangle are:

$$ x = \frac{z_{\text{screen}}(x_i z_i \pm R_i \sqrt{x_i^2 + z_i^2 - R_i^2})}{z_i^2 - R_i^2} $$
$$ y = \frac{z_{\text{screen}}(y_i z_i \pm R_i \sqrt{y_i^2 + z_i^2 - R_i^2})}{z_i^2 - R_i^2} $$

Render squares covering this region using point sprites for visualization or culling purposes [S1].

**Pseudocode:**

```python
import math

def bezier_clipping_metaball_ray_cast(ray_origin, ray_direction, metaballs, isosurface_threshold, z_screen):
    """
    ray_origin: (ox, oy, oz)
    ray_direction: (dx, dy, dz)
    metaballs: list of dicts with 'center' (cx, cy, cz) and 'radius' R
    isosurface_threshold: float
    z_screen: float
    """
    # 1. Culling and Setup
    candidates = []
    for ball in metaballs:
        cx, cy, cz = ball['center']
        R = ball['radius']
        denom_x = cz * cz - R * R
        if abs(denom_x) < 1e-9:
            continue
        rad_term_x = R * math.sqrt(cx * cx + cz * cz - R * R)
        x_min = (z_screen * (cx * cz - rad_term_x)) / denom_x
        x_max = (z_screen * (cx * cz + rad_term_x)) / denom_x
        denom_y = cz * cz - R * R
        if abs(denom_y) < 1e-9:
            continue
        rad_term_y = R * math.sqrt(cy * cy + cz * cz - R * R)
        y_min = (z_screen * (cy * cz - rad_term_y)) / denom_y
        y_max = (z_screen * (cy * cz + rad_term_y)) / denom_y
        candidates.append(ball)

    # 2. Ray-Sphere Intersection and Coefficient Calculation
    combined_bezier_coeffs = [0.0] * 7  # Max degree 6 + 1

    for ball in candidates:
        cx, cy, cz = ball['center']
        R = ball['radius']
        Lx = ray_origin[0] - cx
        Ly = ray_origin[1] - cy
        Lz = ray_origin[2] - cz
        a = 1.0
        b = 2.0 * (ray_direction[0] * Lx + ray_direction[1] * Ly + ray_direction[2] * Lz)
        c = Lx * Lx + Ly * Ly + Lz * Lz - R * R
        discriminant = b * b - 4 * a * c
        if discriminant < 0:
            continue
        D_i = discriminant
        a_i = D_i / R
        d = [0.0] * 7
        d[2] = (16.0 / 27.0) * (a_i ** 2)
        d[3] = (8.0 * (8.0 * a_i + 5.0) * (a_i ** 2)) / 45.0
        d[4] = (16.0 / 27.0) * (a_i ** 2)
        for m in range(7):
            combined_bezier_coeffs[m] += d[m]

    # 3. Ray-Isosurface Test: F(s) - tau = 0
    # In Bézier form, subtracting a constant tau from the curve means
    # subtracting tau from all control points.
    for m in range(7):
        combined_bezier_coeffs[m] -= isosurface_threshold

    # 4. Bézier Clipping (Standard implementation [G])
    def bezier_clip(coeffs, u, v):
        # Iteratively clip the interval [u, v] based on convex hull bounds
        while v - u > 1e-6:
            min_cp = min(coeffs)
            max_cp = max(coeffs)
            if max_cp < 0 or min_cp > 0:
                return None  # No root in interval
            # Find clipping parameter t where hull crosses 0
            t_left = 0.0
            t_right = 1.0
            for i in range(len(coeffs) - 1):
                if coeffs[i] <= 0 <= coeffs[i+1]:
                    t = coeffs[i] / (coeffs[i] - coeffs[i+1])
                    t_left = max(t_left, t)
                elif coeffs[i+1] <= 0 <= coeffs[i]:
                    t = coeffs[i] / (coeffs[i] - coeffs[i+1])
                    t_right = min(t_right, t)
            if t_left >= t_right:
                return None
            u = u + t_left * (v - u)
            v = u + t_right * (v - u)
        return u

    root_s = bezier_clip(combined_bezier_coeffs, 0.0, 1.0)
    if root_s is None:
        return None
    return ray_origin[0] + root_s * ray_direction[0], ray_origin[1] + root_s * ray_direction[1], ray_origin[2] + root_s * ray_direction[2]
```

## Operating characteristics
*   **Time Complexity:** Depends on the degree of the polynomial and the number of clipping iterations [S1].
*   **Memory Complexity:** Linear in the number of metaballs $N$ for storing coefficients [S1].
*   **Strengths:** Robust against multiple intersections; no derivative calculation required; handles high-degree density functions naturally [S1].
*   **Limitations:** Requires careful handling of the Bézier clipping implementation; potential numerical instability if coefficients are large or small [S1].
*   **When to use:** When rendering large numbers of metaballs with high-quality isosurfaces and robust intersection testing is required [S1].

## Background
Originating from Nishita et al. [NN94], this method was adapted for GPU-based fast ray casting for metaballs [S1]. It leverages the properties of Bézier curves to perform robust root finding for the implicit surface defined by the metaball density field [S1].
