# Binary Search IsoSurface Extraction

Also called: Bisection Isosurface Extraction, Isovalue Stepping, RayEvaluationSteppingIso

## Overview
Binary Search IsoSurface Extraction is a ray-tracing method that locates the intersection of a ray with an isosurface by iteratively halving the interval between two sample points whose scalar field values bracket the target isovalue [S1, unofficial]. It relies on discrete sampling and bisection [S2, unofficial].

## How it works
**Inputs:**
- `left`: 3D position vector where the scalar field value is less than or equal to the isovalue [S1, unofficial].
- `right`: 3D position vector where the scalar field value is greater than the isovalue [S1, unofficial].
- `iso`: The target isovalue (scalar or batched tensor) [S2, unofficial].
- `texVol`: Volume texture object for sampling scalar values [S1, unofficial].
- `rec_depth`: Number of binary search iterations (typically 5) [S1, unofficial].

**Outputs:**
- `surf`: 3D position vector approximating the isosurface intersection [S1, unofficial].

**Data Structures:**
The method operates on 3D vectors (`vec3`) and scalar values (`float`) [G]. In GPU implementations (e.g., CUDA), parameters may be packed into a struct for constant memory access [S2, unofficial]:
```cpp
struct Parameters {
    scalar_t stepsize;
    int binarySearchSteps;
    scalar_t isovalue; // or Tensor1Read accessor if batched
    scalar_t isocontourRange;
    cudaTextureObject_t isocontourTexture;
};
```

**Algorithm Steps:**
1. Initialize `left` and `right` such that `value(left) <= iso` and `value(right) > iso` [S1, unofficial]. This bracketing is typically established by a preceding ray-marching or traversal step [G].
2. Loop `iter` from 0 to `rec_depth - 1`:
   a. Compute midpoint: `mid = (left + right) / 2.0` [S1, unofficial].
   b. Sample the volume scalar value at `mid`: `curIso = texture(texVol, mid).x` [S1, unofficial].
   c. If `curIso <= iso`, the surface lies in the right half; update `left = mid` [S1, unofficial].
   d. Else (`curIso > iso`), the surface lies in the left half; update `right = mid` [S1, unofficial].
3. After the loop, compute the final surface position: `surf = (left + right) / 2.0` [S1, unofficial].

**Pseudocode:**
```python
def binary_search_isosurface(left: vec3, right: vec3, iso: float, texVol: Texture, rec_depth: int = 5) -> vec3:
    """
    Finds the isosurface intersection between left and right using binary search.
    
    Args:
        left: Start point where scalar <= iso.
        right: End point where scalar > iso.
        iso: Target isovalue.
        texVol: Volume texture for sampling.
        rec_depth: Number of bisection iterations.
        
    Returns:
        surf: Approximate intersection point.
    """
    for iter in range(rec_depth):
        mid = (left + right) / 2.0
        curIso = texVol.sample(mid).x  # Sample scalar value at mid
        if curIso <= iso:
            left = mid
        else:
            right = mid
    surf = (left + right) / 2.0
    return surf
```

**Parameters:**
- `rec_depth`: Fixed number of bisection iterations. Default is 5 [S1, unofficial].
- `iso`: The isovalue. Can be a single double or a batched tensor [S2, unofficial].
- `binarySearchSteps`: In some implementations, this controls the refinement steps. Range 0-20. Default 0 [S2, unofficial].
- `isocontourRange`: Range of values for surface feature mapping. Default 5.0f [S2, unofficial].

**Edge Cases and Pitfalls:**
- **Bracketing Failure:** The method assumes `left` and `right` correctly bracket the isovalue [G]. If the initial interval does not contain the surface, the binary search will converge to an incorrect location [G].
- **Precision:** The accuracy is limited by `rec_depth`. With 5 iterations, the interval size is reduced by a factor of $2^5 = 32$ [G].

## Subtopics

### [Surface Location via Segment Endpoint Values](3756-surface-location-via-segment-endpoint-values.md)
This method locates isosurface intersections as a function of the scalar field values at the segment endpoints along a ray. It is used within binary search isosurface extraction to eliminate coverage gaps between sampling points that cause aliasing artifacts. Unlike methods that rely on intermediate sampling or fixed-step traversal, it leverages the monotonicity of the field between endpoints to determine surface presence without intermediate checks, provided the binary search interval is sufficiently small.

### [Isocontour Shading with Curvature](3819-isocontour-shading-with-curvature.md)
A shading method for isosurfaces that uses surface features including first curvature ($k_1$), second curvature ($k_2$), mean curvature ($(k_1+k_2)/2$), Gaussian curvature ($k_1*k_2$), or a curvature texture. This is often combined with binary search extraction to enhance visual detail.

### [Multi-Stage Rasterization for Shaded Isosurfaces](5394-multi-stage-rasterization-for-shaded-isosurfaces.md)
An adaptation of the Fast Shaded Isosurfaces method for PC hardware using multi-stage rasterization and 2D-textures, enabling efficient rendering of shaded isosurfaces.
- **Definition:** Computes voxel gradients and writes them to RGB components of 2D-textures, with intensity in the alpha component.
- **Step:** Uses two general combiner stages. Combiner 0 interpolates intermediate slices. Combiner 1 computes the dot product $A \cdot B$, where $A$ is the interpolated gradient $\tilde{n}$ and $B$ is the light vector $\tilde{l}$.
- **Layout:** Input A is RGB output of Combiner 0. Input B is constant color register 2 (light vector). Alpha-component is not modified by Combiner 1.

## Operating characteristics
- **Time Complexity:** $O(\log_2(1/\epsilon))$ per ray, where $\epsilon$ is the desired precision [G]. With fixed `rec_depth`, it is $O(1)$ per ray [G].
- **Memory Complexity:** $O(1)$ auxiliary memory per ray, plus the volume texture storage [G].
- **Performance:** Fast for simple isosurfaces, but may require more samples than analytical methods for high-frequency details [G].
- **Limitations:** Less precise than analytical methods (e.g., Trilinear Isosurface Intersection) for the same computational cost [G].

## Background
Binary Search IsoSurface Extraction is a fundamental technique in volume rendering, particularly in ray-tracing based approaches [S2, unofficial].
