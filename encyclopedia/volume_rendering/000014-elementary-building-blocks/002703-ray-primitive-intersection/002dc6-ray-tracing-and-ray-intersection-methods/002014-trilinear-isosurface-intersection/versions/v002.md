# Trilinear Isosurface Intersection

Also called: Cubic root finding for isosurface, Dual Isosurfacing using Ray Intersection, Isosurface Intersection via Cubic Polynomial, Ray Intersection for Dual Isosurfacing, Ray-Isosurface Intersection Method, isoCrossing

## Overview
Trilinear Isosurface Intersection detects if a ray crosses an isosurface defined by a threshold value within a hexahedral cell of a structured grid [S1, S2, S3]. It solves for the ray position where the trilinear interpolation of the eight cell corner values yields the desired isovalue [S2, S3]. Unlike Dual Contouring which requires Hermite data (normals) to determine point placement, this method computes intersection points directly using cell diagonals or arbitrary rays, relying solely on vertex scalar values [S4].

## How it works
**Inputs:**
* Ray origin $\mathbf{O}$ and direction $\mathbf{D}$ [S4].
* Eight scalar values $v_{ijk}$ at the cell corners $(i,j,k) \in \{0,1\}^3$ [S4].
* Isosurface threshold value $I$ (default 0.0f) [S1].

**Outputs:**
* Boolean indicating intersection.
* Parameter $t$ of the first positive root [S2, S3].
* Output value $v$ at the crossing point [S1].

**Data Structures:**
The cell is represented in parametric coordinates $(u,v,w) \in [0,1]^3$ with vertices at $(0,0,0)$ to $(1,1,1)$ [S4]. The scalar field is defined by the corner values [S4].

**Steps:**

1.  **Pre-check:** Compute the minimum and maximum of the eight corner values. If the isovalue $I$ is not within $[min, max]$, no intersection exists in this cell [S2, S3].
2.  **Formulate Trilinear Equation:** Define the trilinear interpolant $f(u,v,w)$ such that $f(u,v,w) = I$ [S4].
    The parametric form is:
    $$ f(u, v, w) = \sum_{i=0}^1 \sum_{j=0}^1 \sum_{k=0}^1 (1 - U_i)(1 - V_j)(1 - W_k) v_{ijk} $$
    where $U_i = |u - u_i|$, $V_j = |v - v_j|$, and $W_k = |w - w_k|$ [S4].
    Alternatively, using local coordinates relative to the cell minimum $(x_{min}, y_{min}, z_{min})$:
    $$ f(x, y, z) = \left( \sum_{i, j, k=\{0,1\}} x_i y_j z_k v_{ijk} \right) - I = 0 $$
    where $x_0 = x_{min} - x$, $x_1 = x - x_{min}$ (and similarly for $y, z$) [S5, unofficial].
3.  **Substitute Ray:** Represent the ray as $\mathbf{r}(t) = \mathbf{O} + t\mathbf{D}$ [S4]. Substitute the parametric ray coordinates into the trilinear equation to form a cubic polynomial in $t$:
    $$ G_3 t^3 + G_2 t^2 + G_1 t + G_0 = 0 $$
    The coefficients $G_0, G_1, G_2, G_3$ are derived from the corner values and ray parameters [S4].
4.  **Solve Cubic:** Determine the real roots of the polynomial in the interval $t \in [0, 1]$ [S4].
    *   If $G_3 = 0$, solve the quadratic $G_2 t^2 + G_1 t + G_0 = 0$ using discriminant $D_2 = G_1^2 - 4G_2G_0$ [S4].
    *   If $G_3 \neq 0$, compute the discriminant $D_3$ to determine root nature [S4]:
        $$ \delta^2 = \frac{G_2^2 - 3G_3G_1}{9G_3^2} $$
        $$ (x_N, y_N) = \left( -\frac{G_2}{3G_3}, G_3x_N^3 + G_2^2x_N^2 + G_1x_N + G_0 \right) $$
        $$ D_3 = y_N^2 - 4G_3^2 \delta^3 $$
        *   $D_3 > 0$: 1 real, 2 imaginary.
        *   $D_3 = 0$: 3 equal real (if $y_N=0$) or 1 distinct real, 2 equal real (if $y_N \neq 0$).
        *   $D_3 < 0$: 3 distinct real roots [S4].
    *   **Root Finding Strategy:** Sources differ on the optimal solver. Parker et al. use an analytical solver based on Schwarze's method [S2, S3][S5, unofficial]. Marmitt et al. and subsequent implementations (e.g., [S2, S3][S5, unofficial]) use the Neubauer iterative root finder, which iteratively re-parameterizes the ray into sub-intervals until a sign change is detected. The iterative method is cited as slightly faster and numerically stable in single precision [S2, S3][S5, unofficial].
5.  **Select Hit:** Evaluate the ray $\mathbf{r}(t)$ at the smallest positive root $t$ to find the intersection point [S2, S3][S5, unofficial].

**Pseudocode:**
```python
def trilinear_isosurface_intersection(ray_origin, ray_dir, corner_values, isovalue):
    """
    ray_origin: (ox, oy, oz) in parametric space [0,1]^3
    ray_dir: (dx, dy, dz) in parametric space
    corner_values: list of 8 floats, indexed by (i,j,k) where i,j,k in {0,1}
    isovalue: float
    Returns: (hit: bool, t: float)
    """
    # 1. Pre-check
    min_val = min(corner_values)
    max_val = max(corner_values)
    if not (min_val <= isovalue <= max_val):
        return False, 0.0

    # 2. Compute Cubic Coefficients G3, G2, G1, G0
    # Ray in parametric space: u(t) = ox + t*dx, v(t) = oy + t*dy, w(t) = oz + t*dz
    # Trilinear basis: b0(u) = 1-u, b1(u) = u
    # Polynomial: sum_{i,j,k} b_i(u) b_j(v) b_k(w) * v_ijk - isovalue = 0
    G0, G1, G2, G3 = 0.0, 0.0, 0.0, 0.0
    for i in (0, 1):
        for j in (0, 1):
            for k in (0, 1):
                val = corner_values[i][j][k]
                # Basis coefficients for u
                u0 = 1.0 - ray_origin[0] if i == 0 else ray_origin[0]
                u1 = -ray_dir[0] if i == 0 else ray_dir[0]
                # Basis coefficients for v
                v0 = 1.0 - ray_origin[1] if j == 0 else ray_origin[1]
                v1 = -ray_dir[1] if j == 0 else ray_dir[1]
                # Basis coefficients for w
                w0 = 1.0 - ray_origin[2] if k == 0 else ray_origin[2]
                w1 = -ray_dir[2] if k == 0 else ray_dir[2]
                
                # Expand (u0 + u1*t)(v0 + v1*t)(w0 + w1*t)
                G0 += val * u0 * v0 * w0
                G1 += val * (u1*v0*w0 + u0*v1*w0 + u0*v0*w1)
                G2 += val * (u1*v1*w0 + u1*v0*w1 + u0*v1*w1)
                G3 += val * u1 * v1 * w1
                
    G0 -= isovalue

    # 3. Solve for roots
    roots = solve_cubic_roots(G3, G2, G1, G0)

    # 4. Select smallest positive root
    valid_roots = [t for t in roots if 0.0 < t <= 1.0]
    if valid_roots:
        t_hit = min(valid_roots)
        return True, t_hit
    else:
        return False, 0.0

def solve_cubic_roots(G3, G2, G1, G0):
    """Analytical cubic solver based on Cardan's method [S4]. Neubauer iterative method is preferred for stability [S2, S3]."""
    roots = []
    if abs(G3) < 1e-9:
        # Quadratic or linear
        if abs(G2) < 1e-9:
            if abs(G1) > 1e-9:
                roots.append(-G0 / G1)
        else:
            D2 = G1**2 - 4 * G2 * G0
            if D2 >= 0:
                sqrt_D2 = D2**0.5
                roots.append((-G1 + sqrt_D2) / (2 * G2))
                roots.append((-G1 - sqrt_D2) / (2 * G2))
    else:
        # Cubic case
        delta_sq = (G2**2 - 3 * G3 * G1) / (9 * G3**2)
        x_N = -G2 / (3 * G3)
        y_N = G3 * x_N**3 + G2**2 * x_N**2 + G1 * x_N + G0
        delta = delta_sq**0.5
        D3 = y_N**2 - 4 * G3**2 * delta**3
        
        if D3 > 0:
            # 1 real, 2 imaginary
            u = (-y_N/2 + (D3**0.5)/2)**(1/3)
            v = (-y_N/2 - (D3**0.5)/2)**(1/3)
            roots.append(u + v - G2/(3*G3))
        elif D3 == 0:
            if y_N == 0:
                roots.append(-G2/(3*G3)) # 3 equal real
            else:
                roots.append(-G2/(3*G3)) # 1 distinct real
                roots.append(-G2/(3*G3) + 3*G1/(2*G2)) # 2 equal real
        else: # D3 < 0
            # 3 distinct real roots using trigonometric form
            r = (G3 * delta**3)**0.5
            theta = math.acos(-y_N / (2 * r))
            roots.append(2 * r**0.5 * math.cos(theta/3) - G2/(3*G3))
            roots.append(2 * r**0.5 * math.cos((theta + 2*math.pi)/3) - G2/(3*G3))
            roots.append(2 * r**0.5 * math.cos((theta + 4*math.pi)/3) - G2/(3*G3))
    return roots
```

## Subtopics

### No-Body-Saddle Midpoint Transformation
A normalization technique for cubes with no body saddles, mapping the theoretical saddle point $m$ into the block via linear scaling and analyzing gradients to constrain topology [S6]. It computes the theoretical midpoint $m = (-c/a - d/a, -b/a)$ [S6]. If $m$ is outside the block, linear transformations are applied to scale the block so $m$ is inside [S6]. It assumes $T_{mmm} = 0$ and that gradients along midpoint lines are constant [S6]. This variant is used to resolve topological ambiguities in the absence of body saddles by constraining the possible face saddle configurations [S6].

### Smooth Trilinear Isosurface
A rendering technique that uses fast trilinear interpolation for ray intersection search but uses the gradient from tricubic interpolation for normal calculation to avoid visual discontinuities at node boundaries [S7]. It performs ray intersection search using the trilinear interpolant, which is faster than tricubic [S7]. Tricubic coefficients are stored only at nodes containing the isosurface [S7]. Surface normals are calculated using the gradient of the tricubic interpolant instead of the trilinear gradient [S7]. This avoids the grid pattern visual discontinuities caused by trilinear gradient discontinuities [S7].

## Operating characteristics
*   **Time Complexity:** Solving the cubic equation is $O(1)$ per cell intersection [G]. The Neubauer iterative method [S2, S3][S5, unofficial] is cited as slightly faster than analytical solvers like Schwarze's method [S2, S3][S5, unofficial].
*   **Memory Complexity:** $O(1)$ per cell, requiring storage of 8 corner values and ray parameters [G].
*   **Performance:** Single-precision implementations are numerically stable [S2, S3][S5, unofficial].
*   **Strengths:** Does not require Hermite data (normals) [S4]; handles multiple intersections per cell (up to 3) [S4]; topologically correct via look-up tables for cell configurations [S4].
*   **Limitations:** Trilinear interpolation lacks gradient continuity, causing visual artifacts if normals are derived from it [S7]. Ambiguous faces require additional analysis (asymptotic decider) [S4].
*   **When to use:** When Hermite data is unavailable or expensive to compute, and exact trilinear intersection is required [S4].
*   **When not to use:** When smooth shading is critical and tricubic normals are not available [S7].

## Background
The method originates from the need to extract isosurfaces from scalar fields defined on hexahedral grids without relying on vertex normals [S4]. It is based on the trilinear Lagrangian interpolant [S5, unofficial]. The formulation of the cubic equation from ray substitution is detailed in [S4][S5, unofficial]. The use of cell diagonals as rays and the classification of cells/edges based on vertex signs are described in [S4]. The iterative root finder (Neubauer) was proposed by Marmitt et al. [S2, S3][S5, unofficial] as an alternative to analytical solvers [S2, S3][S5, unofficial]. The topological analysis using look-up tables for 31 configurations is based on Lopes and Brodlie (2003) [S4].
