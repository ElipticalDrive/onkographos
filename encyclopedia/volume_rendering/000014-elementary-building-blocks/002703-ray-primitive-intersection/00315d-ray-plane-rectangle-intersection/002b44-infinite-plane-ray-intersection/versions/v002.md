# Infinite Plane Ray Intersection

Also called: Analytical ray-plane intersection, Infinite Ground Plane, InfinitePlan::rayIntersect, InfinitePlan::rayIntersectP, Ray-Plane Intersection, planeIntr

## Overview
Computes the intersection of a ray with an infinite plane defined by a point and a normal, returning the intersection distance and filling an intersection structure, or rejecting if the ray is parallel or outside the ray segment [S2, unofficial]. It is typically used as a ground plane kept separate from the scene's BVH for ray intersection testing [S1, unofficial].

## How it works
**Inputs:**
- Ray origin $\mathbf{o}$ (world space).
- Ray direction $\mathbf{d}$ (world space).
- Plane point $\mathbf{P}$ (world space).
- Plane normal $\mathbf{N}$ (world space).
- Ray segment bounds $t_{min}$ and $t_{max}$.
- Epsilon $\epsilon$ for parallelism check.

**Outputs:**
- Intersection distance $t_{hit}$.
- Intersection point $\mathbf{p}$.
- Intersection normal $\mathbf{n}$.
- Boolean success flag.

**Data Structures:**
- `Intersection` struct:
  - `itsPoint`: vector3 (intersection point).
  - `normal`: vector3 (plane normal).
  - `shape`: reference to the plane object.
  - `tHit`: float (distance along ray).

**Steps:**
1. Compute the denominator: $denom = \mathbf{N} \cdot \mathbf{d}$ [S2, unofficial].
2. Check for parallelism: If $|denom| < \epsilon$, the ray is parallel to the plane; return failure [S2, unofficial].
3. Compute the intersection distance: $t = \frac{\mathbf{N} \cdot (\mathbf{P} - \mathbf{o})}{\mathbf{N} \cdot \mathbf{d}}$ [S3, unofficial].
4. Check segment bounds: If $t < t_{min}$ or $t > t_{max}$, return failure [S2, unofficial].
5. Compute intersection point: $\mathbf{p} = \mathbf{o} + \mathbf{d} \cdot t$ [S2, unofficial].
6. Fill intersection details: `its.itsPoint` = $\mathbf{p}$, `its.normal` = $\mathbf{N}$, `its.shape` = this plane, `its.tHit` = $t$ [S2, unofficial].
7. Update ray bounds: Set $t_{max} = t$ to cull further intersections [S2, unofficial].

**Pseudocode:**
```python
class Vector3:
    def __init__(self, x, y, z):
        self.x, self.y, self.z = x, y, z
    def __add__(self, other): return Vector3(self.x + other.x, self.y + other.y, self.z + other.z)
    def __sub__(self, other): return Vector3(self.x - other.x, self.y - other.y, self.z - other.z)
    def __mul__(self, scalar): return Vector3(self.x * scalar, self.y * scalar, self.z * scalar)

def dot(a, b):
    return a.x * b.x + a.y * b.y + a.z * b.z

def ray_plane_intersect(ray_o, ray_d, plane_p, plane_n, t_min, t_max, epsilon):
    denom = dot(plane_n, ray_d)
    if abs(denom) < epsilon:
        return False, 0.0, Vector3(0, 0, 0), Vector3(0, 0, 0)
    numerator = dot(plane_n, plane_p - ray_o)
    t_hit = numerator / denom
    if t_hit < t_min or t_hit > t_max:
        return False, 0.0, Vector3(0, 0, 0), Vector3(0, 0, 0)
    p_hit = ray_o + ray_d * t_hit
    return True, t_hit, p_hit, plane_n
```

**Parameters:**
- $\epsilon$: Threshold for parallel ray/plane test. Value not specified in the sources [S2, unofficial].

**Edge Cases and Pitfalls:**
- **Parallel Ray:** If the ray direction is perpendicular to the plane normal (dot product is zero), the ray never intersects the plane. This is handled by the epsilon check [S2, unofficial].
- **Precision:** Floating-point precision issues may arise when the ray is nearly parallel to the plane; using a small epsilon is necessary but the exact value is not specified [S2, unofficial].

## Subtopics

### Infinite Ground Plane
An infinite ground plane kept separate from the scene's BVH for ray intersection testing, often used for shadowing and ground reflections [S1, unofficial]. It is chosen when a simple, unbounded surface is needed for the scene base.

## Operating characteristics

## Background
The method is used in path tracers and ray tracers to handle ground planes. It is mentioned in the context of adding a sun, a uniform sky, and an infinite ground plane to a renderer [S1, unofficial]. The analytical solution for ray-plane intersection is a fundamental building block in computer graphics, often taught in introductory graphics courses [G].
