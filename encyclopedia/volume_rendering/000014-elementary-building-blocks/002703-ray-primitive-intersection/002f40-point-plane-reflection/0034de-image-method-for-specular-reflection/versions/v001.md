# Image Method for Specular Reflection

Also called: Image Method (IM), Method of Images, Unfolded reflection

## Overview
The Image Method (IM) is a geometric technique that determines the specular hit point and path length on a planar surface by mirroring the receiver (or source) across the reflecting plane, thereby converting the broken emitter–surface–receiver path into a straight line [S1, unofficial]. Unlike angle search methods, IM provides a deterministic, closed-form solution for the hit point and angles without iterative optimization [S1, unofficial]. It is limited to specular reflections on planar surfaces, whereas methods like Fermat-Path-Tracing (FPT) and Min-Path-Tracing (MPT) can simulate arbitrary numbers of diffractions or reflections [S2].

## How it works
**Inputs and Outputs**
*   **Inputs:**
    *   Source position $S = (x_S, y_S)$ [S1, unofficial].
    *   Receiver position $R = (x_R, y_R)$ [S1, unofficial].
    *   Reflecting plane defined by height $h$ (for a horizontal plane at $y=h$) [S1, unofficial]. In the general case, the plane is defined by a normal vector and offset, but the primary formula provided assumes a horizontal wall [S1, unofficial].
    *   Horizontal distance $\Delta x = |x_R - x_S|$ [S1, unofficial].
*   **Outputs:**
    *   Hit point $x_B$ on the surface [S1, unofficial].
    *   Path length $\ell(h)$ [S1, unofficial].
    *   Incident/Reflected angle $\theta_i = \theta_r$ [S1, unofficial].

**Data Structures**
No complex data structures are required. The method operates on scalar coordinates and basic geometric primitives.

**Steps**
1.  **Mirror the Receiver:** Reflect the receiver position $R$ across the plane to obtain the image point $R'$. For a horizontal plane at height $h$, the vertical coordinate of the image is $y_{R'} = 2h - y_R$ [S1, unofficial]. The horizontal coordinate remains $x_{R'} = x_R$ [S1, unofficial].
2.  **Construct Straight Line:** Form a straight line segment from the source $S$ to the image $R'$ [S1, unofficial].
3.  **Calculate Path Length:** The path length $\ell(h)$ is the Euclidean distance between $S$ and $R'$ [S1, unofficial]:
    $$ \ell(h) = \sqrt{\Delta x^2 + (2h - y_S - y_R)^2} $$
    where $\Delta x = |x_R - x_S|$ [S1, unofficial].
4.  **Determine Hit Point:** The specular hit point $x_B$ is the intersection of the line segment $S \to R'$ with the plane $y=h$ [S1, unofficial]:
    $$ x_B = x_S + \frac{(h - y_S)(x_R - x_S)}{2h - y_S - y_R} $$
    [S1, unofficial].
5.  **Calculate Angles:** The incident and reflected angles are equal and determined by the geometry [S1, unofficial]:
    $$ \theta_i = \theta_r = \arctan\left( \frac{|x_R - x_S|}{|2h - y_S - y_R|} \right) $$
    [S1, unofficial].

**Pseudocode**
```python
def image_method_specular_reflection(x_s, y_s, x_r, y_r, h):
    """
    Calculate specular reflection hit point and path length using the Image Method.
    
    Args:
        x_s, y_s: Source coordinates.
        x_r, y_r: Receiver coordinates.
        h: Height of the horizontal reflecting plane.
        
    Returns:
        x_b: Hit point x-coordinate on the plane.
        path_length: Total path length S -> Surface -> R.
        angle: Incident/reflected angle in radians.
    """
    # Horizontal distance
    delta_x = abs(x_r - x_s)
    
    # Vertical term in the unfolded path
    # This represents the vertical distance between source and mirrored receiver
    vertical_diff = 2 * h - y_s - y_r
    
    # Path length: Euclidean distance from S to R' (mirrored R)
    path_length = (delta_x**2 + vertical_diff**2)**0.5
    
    # Hit point x-coordinate
    # Intersection of line S->R' with y=h
    # Avoid division by zero if source and receiver are at same vertical level relative to plane center
    if vertical_diff == 0:
        # Degenerate case: source and receiver are symmetric with respect to the plane height
        # The hit point is the midpoint horizontally
        x_b = (x_s + x_r) / 2.0
    else:
        x_b = x_s + ((h - y_s) * (x_r - x_s)) / vertical_diff
        
    # Angle of incidence/reflection
    # atan2 handles the quadrant correctly, but here we use absolute values for magnitude
    # The angle is with respect to the normal (vertical) or surface? 
    # The formula uses atan(|dx|/|dy|), which is the angle with the normal if dy is vertical.
    # Standard definition: angle with normal.
    angle = abs(atan2(delta_x, abs(vertical_diff)))
    
    return x_b, path_length, angle
```

**Parameters and Typical Values**
*   $h$: Plane height. Must be such that the hit point lies on the physical surface if the surface is bounded.
*   $\Delta x$: Horizontal separation.

**Edge Cases and Pitfalls**
*   **Derivative Validity:** The derivative $\frac{\partial \ell}{\partial h} = \frac{2(2h - y_S - y_R)}{\ell(h)}$ applies only to a nonzero-length path while the same valid reflection branch is retained [S1, unofficial]. If the path topology changes (e.g., the hit point moves off the surface), the derivative is invalid [S1, unofficial].
*   **Degenerate Input:** If $2h - y_S - y_R = 0$, the denominator in the hit point calculation becomes zero. This corresponds to the source and receiver being symmetric with respect to the plane's height, resulting in a horizontal path segment parallel to the plane's normal projection? No, it means the source and mirrored receiver have the same y-coordinate, so the line connecting them is horizontal. If the plane is horizontal, they never intersect unless they are on the plane. In this case, the hit point is the midpoint [S1, G, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(1)$, as it involves a constant number of arithmetic operations.
*   **Memory Complexity:** $O(1)$, requiring only a few scalar variables.
*   **Strengths:** Deterministic, closed-form solution; no iterative optimization required; differentiable with respect to geometric parameters [S1, unofficial].
*   **Limitations:** Limited to specular reflections on planar surfaces [S2]. Cannot handle multiple reflections or diffractions directly [S2].
*   **When to Use:** When simulating single specular reflections on flat surfaces where performance and differentiability are critical [S1, unofficial].
*   **When Not to Use:** For complex scenes with multiple reflections, diffractions, or non-planar surfaces [S2].

## Background
The Image Method is a classical technique in electromagnetics and optics for solving boundary value problems [S1, unofficial][S2]. In the context of differentiable ray tracing, it has been adapted to provide analytical gradients for path lengths and hit points, facilitating optimization of geometry and material parameters in radio network simulations [S1, unofficial]. It is implemented in frameworks like Sionna RT for differentiable ray tracing [S1, unofficial].
