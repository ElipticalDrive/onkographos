# Mirror

Also called: Mirroring tool

## Overview
The Mirror method copies volumetric data from a source region to a target region across a user-defined reflection plane, designed for structures with bilateral symmetry such as the human head [S1]. It differs from general symmetry analysis by acting as an interactive editing tool that modifies the volume data directly, rather than just visualizing symmetry [S1].

## How it works
**Inputs and Outputs:**
- **Input:** A 3D volume texture (`VolumeTex`), a reflection plane defined by position and orientation (normal and offset), and a visibility mask (`SculptMap`) indicating which voxels are editable or contain existing material [S1].
- **Output:** The modified volume where voxels in the target region are filled with data from the corresponding reflected coordinates in the source region, respecting visibility constraints [S1].

**Data Structures:**
- **Reflection Plane:** Defined by a normal vector $\mathbf{n}$ and a point $\mathbf{p}_0$ on the plane, or equivalently by normal $\mathbf{n}$ and offset $d$ such that $\mathbf{n} \cdot \mathbf{x} + d = 0$ [S1]. The direction of mirroring (arrow) determines which side is the target and which is the source [S1].
- **SculptMap:** A 3D texture acting as a mask. It stores visibility information in the alpha channel ($A$) and inserted material information in the blue channel ($B$) [S1].
- **VolumeTex:** The 3D texture containing the scalar or color data of the volume [S1].

**Steps:**
1. **User Selection:** The user interactively selects the position and orientation of the reflection plane. The direction of mirroring defines the target area (where data is written) and the source area (where data is read) [S1].
2. **Voxel Reflection:** For each voxel $V$ in the selected target part of the volume, calculate the reflected coordinates $V'$ across the plane [S1].
   - Let $V$ be the position of the current voxel.
   - Let the plane be defined by normal $\mathbf{n}$ (unit length) and distance $d$ from origin.
   - The signed distance from $V$ to the plane is $dist = \mathbf{n} \cdot V + d$.
   - The reflected point $V'$ is calculated as:
     $$ V' = V - 2 \cdot dist \cdot \mathbf{n} $$
3. **Data Access and Copy:** Access the voxel at $V'$ in the source region [S1].
4. **Visibility Check:** Copy the content from $V'$ to $V$ only if visible material exists at $V'$ and the target voxel $V$ does not already contain existing material that should be preserved [S1]. The tool does not overwrite existing material [S1].
   - Let $M_V$ be the mask value at $V$ (specifically the alpha channel $A$ of `SculptMap`).
   - Let $M_{V'}$ be the mask value at $V'$ (specifically the alpha channel $A$ of `SculptMap`).
   - Let $Vol_{V'}$ be the volume data at $V'$ (specifically the red channel $R$ of `VolumeTex`, representing material presence) [S1].
   - The condition for copying is:
     $$ \text{If } (Vol_{V'} == 0.0) \lor (M_V == 0.0) \text{ then copy } Vol_{V'} \text{ to } Vol_V $$

    """
    volume: 3D array of floats, representing the volume data.
    mask: 3D array of floats, representing the visibility mask (alpha channel).
    plane_normal: 3D vector, unit normal of the reflection plane.
    plane_offset: float, distance from origin to plane (n . x + d = 0).
    target_mask: 3D array of bools, indicating which voxels are in the target region.
    
    Returns:
    modified_volume: 3D array, the volume with mirrored data.
    """
    modified_volume = copy(volume)

    for V in all_voxels:

        if not target_mask[V]:
            continue
            
        # Calculate reflected coordinates V'
        # Signed distance from V to plane
        dist = dot(plane_normal, V) + plane_offset
        
        # Reflected point
        V_prime = V - 2 * dist * plane_normal
        
        # Check if V_prime is within volume bounds
        if not is_inside_volume(V_prime):

        # "Visible material" implies the voxel at V_prime is not background
        # Assuming background is 0.0 in volume data
        if volume[V_prime] == 0.0:

**Parameters:**
- **Reflection Plane:** Defined by user interaction. No fixed typical values [S1].
- **Visibility Mask:** Stored in `SculptMap` alpha channel [S1].

**Edge Cases and Pitfalls:**
- **Boundary Conditions:** If $V'$ falls outside the volume bounds, the copy operation is skipped [S1].
- **Precision:** Floating-point precision in calculating $V'$ may lead to slight misalignments, but the sources do not specify tolerance values [S1].
- **Symmetry Assumption:** The method assumes the structure has symmetry. Applying it to non-symmetric structures will produce artifacts [S1].

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the number of voxels in the target region. Each voxel requires a reflection calculation and a texture lookup [S1].
- **Memory Complexity:** $O(V)$, where $V$ is the total number of voxels in the volume, to store the volume and mask data [S1].
- **Performance:** Implemented using fragment shaders on a proxy geometry, allowing for GPU acceleration [S1].
- **Strengths:** Interactive, fast editing for symmetric structures [S1].
- **Limitations:** Only works for structures with symmetry; requires user to define the plane correctly [S1].

## Background
The Mirror tool was developed as part of a volume sculpting system based on geometric tools, integrating with texture-based volume rendering [S1].
