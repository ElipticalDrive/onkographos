# Eye-Tracking Position Adaptive Display (Parallax Barrier Variant)
Also called: Adaptive Parallax Barrier with Eye-Tracking

## Overview
An autostereoscopic display technique that uses a parallax barrier combined with multiple parallel strip backlight sources to direct light specifically to a viewer's eye positions [S1, unofficial]. It solves the fixed viewing zone limitation of static parallax barriers by dynamically selecting active light sources based on real-time eye tracking, ensuring correct image formation for the left and right eyes [S1, unofficial]. It differs from its parent [Directional Backlight Autostereoscopic Rendering](22651-directional-backlight-autostereoscopic-rendering.md) by using a physical barrier structure with segmented backlights rather than time-multiplexed directional emission, and from [Adaptive Parallax Barrier with Subbarriers](#adaptive-parallax-barrier-with-subbarriers) by using full strip sources rather than subbarrier adjustments.

## How it works
**Inputs:**
- Viewer’s left eye position $(x_L, y_L)$ and right eye position $(x_R, y_R)$, detected by an eye-tracking system [S1, unofficial].
- Display panel resolution and geometry [S1, unofficial].
- Configuration of multiple parallel strip backlight sources [S1, unofficial].

**Outputs:**
- Activated backlight strips corresponding to the viewer’s eye positions [S1, unofficial].
- Image data rendered for the left and right eyes directed through the selected strips [S1, unofficial].

**Data Structures:**
- **Eye Position Data:** A pair of 2D coordinates $(x, y)$ for each eye. Not given in the sources.
- **Backlight Source Map:** A list or array of parallel strip identifiers, each associated with a specific angular emission zone or spatial region [S1, unofficial]. Not given in the sources.

**Steps:**
1. **Eye Tracking:** Detect the current 2D position of the viewer’s left eye $(x_L, y_L)$ and right eye $(x_R, y_R)$ using an eye-tracking camera or sensor [S1, unofficial].
2. **Source Selection:** An adaptive controller determines which parallel strip backlight sources are aligned with the detected eye positions [S1, unofficial].
3. **Activation:** The controller turns on the properly selected light source(s) to form images directed to the viewer’s left eye position and right eye position [S1, unofficial].
4. **Rendering:** Render the appropriate left-eye and right-eye views through the activated strips [S1, unofficial].

**Pseudocode:**
```python
def update_display(eye_left_pos, eye_right_pos, backlight_strips):
    """
    Select and activate backlight strips based on eye positions.
    
    Args:
        eye_left_pos: Tuple (x, y) of left eye position.
        eye_right_pos: Tuple (x, y) of right eye position.
        backlight_strips: List of backlight strip objects, each with a method 
                          is_aligned_to(eye_pos) returning True if the strip 
                          directs light to the eye.
    
    Returns:
        List of activated strip identifiers.
    """
    activated_strips = []
    
    # Select strip for left eye
    for strip in backlight_strips:
        if strip.is_aligned_to(eye_left_pos):
            activated_strips.append(strip.id)
            break # Assume one primary strip per eye or handle multiple
    
    # Select strip for right eye
    for strip in backlight_strips:
        if strip.is_aligned_to(eye_right_pos):
            activated_strips.append(strip.id)
            break
            
    return activated_strips
```

**Parameters:**
- Number of parallel strip backlight sources: Not given in the sources.
- Eye-tracking latency: Not given in the sources.

**Edge Cases:**
- If the viewer moves outside the range of available backlight strips, no optimal source may be selected [S1, unofficial].
- Precision of eye-tracking affects the accuracy of source selection [S1, unofficial].

## Subtopics

### Adaptive Parallax Barrier with Subbarriers
An eye-tracking method that uses multiple subbarriers to adjust the viewing zone location based on detected eye positions [S1, unofficial]. It differs from the main variant by using subbarriers for finer adjustment of the viewing zone rather than selecting from distinct parallel strip backlight sources [S1, unofficial]. Choose this when finer spatial control of the viewing zone is required [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Depends on the number of backlight strips and eye-tracking update rate. Not given in the sources.
- **Memory Complexity:** Depends on the number of backlight strips and eye position storage. Not given in the sources.
- **Measured Performance:** Not given in the sources.
- **Strengths:** Provides autostereoscopic 3D without glasses, adapts to viewer position [S1, unofficial].
- **Limitations:** Requires eye-tracking hardware, limited by the number of backlight strips [S1, unofficial].
- **When to use:** Single-user or limited multi-user scenarios where eye position is known and tracked [S1, unofficial].
- **When not to use:** When eye-tracking is unavailable or when multiple users are at widely different positions [S1, unofficial].

## Background
Originated from attempts to make dynamic changes in the optical and electronic design of 3D display systems to adaptively optimize them based on the current position of the viewer’s eyes [S1, unofficial]. Wang et al. [S1, unofficial] designed a parallax-barrier-type autostereoscopic display device with multiple parallel strip backlight sources and an eye-tracking technique. Wu et al. [S1, unofficial] proposed an adaptive parallax barrier scheme using multiple subbarriers. These developments aim to fulfill the needs of providing autostereoscopic 3D display functionality for single-user application scenarios [S1, unofficial].
