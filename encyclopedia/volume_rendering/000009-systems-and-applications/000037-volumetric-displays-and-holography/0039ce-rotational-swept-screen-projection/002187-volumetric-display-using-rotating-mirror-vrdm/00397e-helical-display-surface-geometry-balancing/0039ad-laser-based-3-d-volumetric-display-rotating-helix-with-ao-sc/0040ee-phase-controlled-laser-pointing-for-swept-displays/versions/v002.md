# Phase-Controlled Laser Pointing for Swept Displays

Also called: Joystick-controlled depth pointing, Phase-controlled laser pointing

## Overview
Phase-controlled laser pointing is an interaction method for swept volumetric displays that resolves the ambiguity of laser pointers projecting continuous lines across the volume. By synchronizing the laser pulse frequency with the display's sweep frequency and adjusting the phase offset via an analog joystick, the user can position a discrete laser dot at a specific height (z-coordinate) on the helical display surface [S1]. This method serves as an alternative to distance-controlled depth pointing, offering precise manual control over the selection ray's position rather than relying on physical proximity [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Analog joystick position (phase control), display sweep frequency (typically 30 Hz).
*   **Output:** A laser dot appearing at a specific vertical position on the rotating helical surface.

**Data Structures and Hardware Layout:**
The implementation relies on a specific hardware configuration [S1]:
*   **Microcontroller:** Arduino Nano running Timer 1 at 16 MHz resolution.
*   **Power:** 9V rechargeable battery.
*   **Laser:** 1 mW red laser diode.
*   **Driver:** 2N2222 transistor used to switch the laser diode.
*   **Interface:** Analog joystick for phase adjustment.

**Parameters:**
*   **Default Frequency:** 30 Hz [S1].
*   **Clock Resolution:** 16 MHz (Timer 1 on Arduino Nano) [S1].
*   **Drift Rate:** 5 mm per minute on a Voxon VX1 display under default conditions [S1].

**Steps:**
1.  **Synchronization Verification:** The user observes the laser dot. If the dot is static and does not drift, the pointer is synchronized with the display's oscillation [S1].
2.  **Frequency Configuration:** The laser is configured to pulse at the same frequency as the display's oscillation. This frequency is typically set to 30 Hz but can be adjusted once per display using a button to enter "adjust mode" [S1].
3.  **Phase Adjustment:** The user moves the analog joystick to change the phase of the laser pulse relative to the display's sweep cycle. This phase shift determines the vertical position (height) of the laser dot on the helical surface [S1].
4.  **Complex Patterns (Optional):** More complex timing patterns, such as a dashed line with a dot at the pointing position, can be generated by modifying the pulse train logic [S1].

**Pseudocode:**
```python
# Constants
DISPLAY_FREQ_HZ = 30
TIMER_CLOCK_MHZ = 16
# Timer 1 prescaler settings for 16MHz to achieve 30Hz interrupt
# Period = 1 / 30 seconds. 
# Assuming a standard CTC mode or similar timer setup on Arduino Nano.
# The exact timer register values depend on the prescaler.
# For 16MHz, to get 30Hz:
# Count = (16,000,000 / Prescaler) / 30
# If Prescaler = 64, Count = 8333.33 -> OCR1A = 8333

def setup():
    initialize_timer_1_for_frequency(DISPLAY_FREQ_HZ)
    initialize_laser_driver()
    initialize_joystick_adc()

def loop():
    # Read joystick position (0 to 1023 for 10-bit ADC)
    joystick_val = read_analog_joystick()
    
    # Map joystick value to phase offset
    # Phase offset determines when the laser fires within the 30Hz cycle
    phase_offset_ms = map(joystick_val, 0, 1023, 0, 1000 / DISPLAY_FREQ_HZ)
    
    # Schedule laser pulse with phase offset
    # The laser fires once per cycle at the calculated phase offset
    schedule_laser_pulse(phase_offset_ms)

def schedule_laser_pulse(phase_offset_ms):
    # Wait for the timer interrupt corresponding to the phase offset
    # Then trigger the 2N2222 transistor to turn on the 1mW laser diode
    wait_until_timer_reaches(phase_offset_ms)
    turn_on_laser()
    turn_off_laser() # Pulse duration is typically very short to create a dot
```

**Edge Cases and Pitfalls:**
*   **Frequency Drift:** If the microcontroller clock is not perfectly stable, frequency drift occurs, causing the laser dot to drift vertically. The specified hardware (Arduino Nano at 16 MHz) exhibits a drift rate of 5 mm per minute on a Voxon VX1 display [S1].
*   **Calibration:** Frequency adjustment is required only once per display, not per session [S1].

## Subtopics

### [Distance-Controlled Depth Pointing](10531-distance-controlled-depth-pointing.md)
Distance-Controlled Depth Pointing is an interaction method where the depth of the laser dot is determined by the physical distance between the pointer device and the display surface, creating a "lock ray" illusion. It uses an ultrasonic range sensor (HC-SR04) to measure distance and triggers the laser accordingly. It is chosen when a natural "point-and-shoot" interaction is preferred over manual phase adjustment, though it may interfere with other ultrasonic devices. See [Distance-Controlled Depth Pointing](10531-distance-controlled-depth-pointing.md).

### Surface Detection Pointer
A hardware interaction technique that automatically projects a laser onto the first visible surface in the line of sight by combining a light detector, laser, and dichroic optics [S1]. It routes incoming light through an aperture and lens to a detector, amplifies the signal via an op-amp, and triggers the laser when light is detected. An analog joystick controls the time offset (to project above/below the surface) and sensor sensitivity. It fails on sparse volumetric graphics or surfaces composed of multiple small slices and requires manual light level adaptation per application [S1].

### Multiple Pointers for Swept Displays
A deployment strategy allowing simultaneous use of multiple independent laser pointers on a single swept volumetric display without display-side communication [S1]. It enables single-user two-handed gestures (e.g., pinching for rotation) and multi-user role swapping. It supports lasers of different colors. However, multiple devices using ultrasonic distance measurement will interfere with each other [S1].

## Operating characteristics
*   **Time Complexity:** Real-time interaction; latency is dominated by the display's sweep frequency (30 Hz) and the microcontroller's timer resolution.
*   **Memory Complexity:** Minimal; requires only timer registers and ADC readings.
*   **Performance:** The default 30 Hz configuration results in a vertical drift of 5 mm per minute on a Voxon VX1 display [S1].
*   **Strengths:** Provides precise manual control over the z-coordinate; simple hardware implementation; works with existing displays without modification.
*   **Limitations:** Requires manual synchronization verification; susceptible to clock drift; frequency adjustment is needed per display type.
*   **When to use:** When precise, manual control of the selection point's height is required, or when the user prefers a "joystick" interface over distance-based interaction.
*   **When not to use:** When automatic surface detection is preferred, or when multiple users require independent distance-based tracking without interference.

## Background
This method was introduced in the paper "PointerVol: A Laser Pointer for Swept Volumetric Displays" presented at UIST ’24 (October 13–16, 2024, Pittsburgh, PA, USA) [S1]. It addresses the problem of depth ambiguity in swept volumetric displays where a standard laser pointer creates a visible line across the volume. The method is inspired by the "depth ray" and "lock ray" techniques used in other volumetric display systems [S1].
