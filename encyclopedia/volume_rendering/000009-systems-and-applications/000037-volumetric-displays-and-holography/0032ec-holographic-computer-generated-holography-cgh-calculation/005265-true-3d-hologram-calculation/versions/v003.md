# True 3D Hologram Calculation

Also called: Fresnel holography with phase correction

## Overview
True 3D Hologram Calculation generates a hologram where scene elements are positioned at their actual 3D coordinates, providing accurate depth cues and parallax [S1]. It differs from planar hologram methods by explicitly correcting the object phase to maintain consistency across the hologram plane, preventing the noise and artifacts that arise when using a constant object phase for objects at varying depths [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A point cloud of object points $\mathbf{o}$ derived from color and depth buffers, with occluded points culled from the viewer's eye position [S1]. The wavelength $\lambda$ of the reconstruction light [G]. The position of the hologram plane [G].
*   **Outputs:** A phase-only or complex amplitude hologram pattern ready for upload to a Spatial Light Modulator (SLM) [G].

**Data Structures:**
*   **Point Cloud:** A list of 3D coordinates $\mathbf{o} = (x_o, y_o, z_o)$ and associated color/intensity values [S1].
*   **Hologram Plane:** A 2D grid of pixels $(x, y)$ at a specific depth $z_h$ [G].

**Method Steps:**
1.  **Point Cloud Generation:** Form a point cloud from the viewer's eye position using standard rendering pipeline color and depth buffers. Cull occluded points to ensure only visible surfaces contribute to the hologram [S1].
2.  **Phase Correction Calculation:** For each object point $\mathbf{o}$, calculate the corrected object phase $\phi_o$. This correction ensures that the phase contribution is consistent across the sub-hologram associated with that point, mitigating the wide variation in phase that occurs with true 3D depth [S1].
3.  **Hologram Synthesis:** Calculate the total complex amplitude at each hologram pixel by summing the contributions of all object points, using the corrected phase $\phi_o$ and the actual 3D position of each point in the wave propagation model [S1].

**Formulas:**
The corrected object phase $\phi_o$ is calculated as [S1]:

$$ \phi_o = -\frac{2\pi}{\lambda} \left( k|\mathbf{p}_c^o - \mathbf{o}| - k|\mathbf{p}_c^o - \mathbf{r}| \right) $$

Where:
*   $\lambda$ is the wavelength of the reconstruction light [G].
*   $k$ is the wavenumber ($2\pi/\lambda$) [G].
*   $\mathbf{o}$ is the 3D position of the object point [S1].
*   $\mathbf{p}_c^o$ is the center point of the sub-hologram corresponding to object point $\mathbf{o}$ [S1].
*   $\mathbf{r}$ is a reference point (often on the optical axis) used to define the phase reference distance [G]. *Note: The source text uses $\mathbf{k}$ in the term $|\mathbf{p}_c^o - \mathbf{k}|$, which reuses the symbol $k$ for both wavenumber and a reference position vector; this is corrected here to $\mathbf{r}$ to avoid ambiguity [S1].*

**Pseudocode:**
```python
import math
import cmath

def calculate_true_3d_hologram(point_cloud, wavelength, hologram_pixels, sub_hologram_centers, reference_point):
    """
    Calculate a true 3D hologram with phase correction.
    
    Args:
        point_cloud: List of objects with attributes .pos (3D tuple) and .intensity (float).
        wavelength: Float, lambda of reconstruction light.
        hologram_pixels: List of 3D pixel coordinates (x, y, z_h).
        sub_hologram_centers: Dict mapping object index to 3D center point p_c^o.
        reference_point: 3D tuple for the reference position r.
        
    Returns:
        hologram: List of complex amplitudes corresponding to hologram_pixels.
    """
    k = 2.0 * math.pi / wavelength
    hologram = [0.0 + 0.0j] * len(hologram_pixels)
    
    for idx, obj in enumerate(point_cloud):
        pc_o = sub_hologram_centers[idx]
        
        # Euclidean distance from sub-hologram center to object point
        dist_obj = math.sqrt(sum((a - b)**2 for a, b in zip(pc_o, obj.pos)))
        # Euclidean distance from sub-hologram center to reference point
        dist_ref = math.sqrt(sum((a - b)**2 for a, b in zip(pc_o, reference_point)))
        
        # Corrected object phase
        phi_o = -(2.0 * math.pi / wavelength) * (k * dist_obj - k * dist_ref)
        
        for px_idx, px in enumerate(hologram_pixels):
            # Distance from object point to hologram pixel
            dist = math.sqrt(sum((a - b)**2 for a, b in zip(px, obj.pos)))
            
            # Propagation phase
            phi_prop = k * dist
            
            # Total phase at pixel
            total_phase = phi_o + phi_prop
            
            # Amplitude from point cloud data
            A_o = obj.intensity
            
            # Add contribution to hologram
            hologram[px_idx] += A_o * cmath.exp(1j * total_phase)
            
    return hologram
```

**Edge Cases and Pitfalls:**
*   **Constant Phase Error:** Using a constant object phase $\phi_o$ for true 3D holograms results in widely varying object phase at the hologram plane, producing poor quality results with high noise [S1].
*   **Intra-pupil Effects:** The method assumes view-dependent effects are handled by head-tracked rendering. It does not account for intra-pupil view-dependent effects (e.g., differences in occlusion between the left and right edges of the eye pupil) [S1].

## Subtopics

### [Holographic Defocus Blur Matching](15055-holographic-defocus-blur-matching.md)
Holographic Defocus Blur Matching calculates the maximum propagation distance $\Delta z$ and the diameter of the blur circle of a human eye $CoC_{eye}$ in display pixels. It ensures that the holographic defocus blur matches the optical defocus blur of the human eye. It sets itself apart by linking SLM and lens array optical constraints to the physiological limits of the human pupil, allowing for the determination of rendering camera aperture sizes that produce perceptually correct depth cues.

### [Longitudinally Engineered Metasurface for 3D Vectorial Holography](18693-longitudinally-engineered-metasurface-for-3d-vectorial-holog.md)
This method achieves full 3D vectorial holography by decomposing a target 3D optical field into an array of quasi-non-diffracting beams, each with independently programmable axial intensity and polarization profiles. Unlike conventional holographic approaches using spatial light modulators (SLMs) or digital micromirror devices (DMDs), which are often restricted to 2D vectorial holography or lack depth control, this method coordinates the modulation of amplitude, depth, and polarization across an entire volume using longitudinally engineered beam arrays.

### [Aberration-Space Holography](20632-aberration-space-holography.md)
Aberration-space holography is a method for generating computer-generated holograms (CGH) that simultaneously corrects spatially varying (anisoplanatic) aberrations across an entire Nyquist-limited volume or field of view. Unlike isoplanatic correction, which optimizes phase for a single local patch and fails outside it, this technique combines individual propagation kernels—each tailored to negate local aberration at a specific target point—into a single spatial light modulator (SLM) hologram. This enables diffraction-limited control of multiple optical beams in parallel across 2D fields and 3D volumes, overcoming the anisoplanatic limit that restricts parallel steering to small regions.

### Digital 3D display system based on image synthesizing technology
A processing method that captures 2D elemental images via a micro lens array, calculates holograms using a corrected Iterative Fourier Transform Algorithm (IFTA), uploads them to an SLM, and reconstructs a 3D image using output-side micro lens array imaging [S2]. Implemented by Choi et al. (2005) to construct a full-parallax wide-viewing-angle 3D holographic display system [S2]. Steps: 1. Capture 2D elemental images of a 3D object using a CCD and input micro lens array. 2. Calculate the hologram of the elemental images using a corrected IFTA. 3. Upload the calculated hologram to an SLM. 4. Reconstruct the 3D image using image formation from the output micro lens array [S2].

### Off-axis Holography
This geometry separates the desired reconstruction from unwanted terms (twin images) by shifting them into different diffraction orders, enabling clean three-dimensional holograms [S3, unofficial]. The reference beam meets the object beam at an angle [S3, unofficial]. Developed by Emmett Leith and Juris Upatnieks after the availability of coherent laser sources [S3, unofficial].

## Operating characteristics
*   **Complexity:** The calculation scales with the number of object points and hologram pixels. For true 3D, every point contributes to every pixel, leading to $O(N \cdot M)$ complexity where $N$ is points and $M$ is hologram pixels [G].
*   **Performance:** Achieving good results with phase-only modulation is difficult without phase correction. The phase correction method allows for high-quality holograms with widely varying depth, but requires careful computation of the reference distances [S1].
*   **Strengths:** Provides accurate 3D depth cues and parallax. Corrects for phase inconsistencies inherent in naive true 3D Fresnel holography [S1].
*   **Limitations:** Computationally expensive. Does not account for intra-pupil view-dependent effects [S1].

## Background
The method is described in the context of holographic near-eye displays for virtual and augmented reality. It addresses the challenge of generating high-quality true 3D holograms using phase-only modulation, where naive approaches fail due to phase variation across the hologram plane [S1]. The phase correction formula was introduced to improve consistency on the hologram plane [S1].
