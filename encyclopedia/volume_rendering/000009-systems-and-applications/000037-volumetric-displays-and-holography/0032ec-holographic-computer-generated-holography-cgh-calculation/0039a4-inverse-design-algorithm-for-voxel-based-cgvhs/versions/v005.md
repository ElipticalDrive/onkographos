# Inverse Design Algorithm for Voxel-based CGVHs

Also called: Iterative Propagation Algorithm (IPA) for mode conversion

## Overview
The Inverse Design Algorithm for Voxel-based Computer-Generated Volume Holograms (CGVHs) is a method for designing 3D refractive index structures that convert $N$ mutually incoherent transverse input modes $\{u_n\}$ into $N$ target modes $\{v_n\}$ with a one-to-one mapping [S1, unofficial]. It solves the problem of optimizing discrete voxel distributions in a finite volume to maximize mode conversion efficiency. It differs from direct superposition methods by using an iterative forward-backward propagation scheme to locally optimize voxel choices based on overlap integrals, rather than calculating holograms from first principles for each point source [S1, unofficial].

## How it works
**Inputs:**
*   $N$ input mode fields $\{u_n\}$ defined at plane $z_{in} = z_1$.
*   $N$ target mode fields $\{v_n\}$ defined at plane $z_{out} = z_{K+1}$.
*   Wavelengths $\lambda_n$ associated with each mode pair $(u_n, v_n)$.
*   Bulk refractive index $n_n$ at wavelength $\lambda_n$.
*   A library of $D$ transverse voxel distributions $\{\Delta RI_d\}_{1 \le d \le D}$ representing relative refractive index changes compared to the bulk index. $\Delta RI_0$ denotes no modification.
*   Sub-volume grid dimensions: $I \times J \times K$ sub-volumes $v_{ijk}$ with extensions $D_x, D_y, D_z$.
*   Simulation resolutions: $dx, dy, dz$.

**Outputs:**
*   The optimal selection of voxel distribution index $d_{ijk}$ for each sub-volume $v_{ijk}$ in the grid.

**Data Structures:**
*   **Grid:** A 3D array of indices $d_{ijk}$ where $1 \le i \le I, 1 \le j \le J, 1 \le k \le K$. Initialized to $0$ (null distribution).
*   **Field Storage:** A 3D array of complex fields $U_{ijk}^n$ storing the propagated input modes at plane $z_k$ for each mode $n$ and sub-volume layer $k$. Size: $I \times J \times K \times N$.
*   **Voxel Library:** A lookup table mapping index $d$ to the complex phase profile $\phi_{ijk}(\lambda_n)$ or refractive index change $\Delta RI_{ijk}^d(\lambda_n)$.

**Formulas:**
1.  **Phase Multiplication Model:** Crossing a layer of thickness $dz$ with voxel distribution $d$ applies a local phase shift [S1, unofficial]:
    $$ \phi_{ijk}(\lambda_n) = \exp\left(i \frac{2\pi}{\lambda_n} \Delta RI_{ijk}^d(\lambda_n) dz\right), \quad 0 \le d \le D $$
2.  **Global Error Metric (Minimization):** The squared $L_2$ distance between input and target modes at $z_{out}$ [S1, unofficial]:
    $$ O_{min} = \min \sum_{n=1}^{N} \| u_n - v_n \|_2^2 = \min \left\{ \sum_{n=1}^{N} \int_{z_{out}} |u_n - v_n|^2 \right\} $$
3.  **Global Overlap Criterion (Maximization):** For lossless designs where $\|u_n\|^2$ and $\|v_n\|^2$ are conserved, the minimization is equivalent to maximizing the real part of the overlap integral [S1, unofficial]:
    $$ O_{max} = \max_{\Delta RI_{ijk}^d} \left\{ \sum_{n=1}^{N} \int_{z_{out}} \Re(v_n^* u_n) \right\} $$
4.  **Local Selection Criterion:** For a specific sub-volume $v_{ijk}$ at layer $k$, the optimal distribution index $d$ maximizes the local overlap between the backpropagated target mode and the forward-propagated input mode [S1, unofficial]:
    $$ O_{ijk}^{max} = \max_{d} \left\{ \sum_{n=1}^{N} \int_{z_{k+1}} \Re\left( (u_{ijk+1}^n(d))^* u_{ijk+1}^n(d) \right) \right\} $$
    *Note: The source text uses $v_{ijk+1}^n$ in the integral but defines $u_{ijk+1}^n(d)$ as the propagated input. Based on the IPA context and Eq (6), the criterion maximizes the correlation between the field arriving at $z_{k+1}$ from the input side (propagated through the chosen voxel) and the field arriving at $z_{k+1}$ from the target side (backpropagated). The source notation $v_{ijk+1}^n$ in Eq (7) likely refers to the target mode component at that plane, or the notation implies $u$ represents the field in the forward pass and $v$ in the backward pass. We interpret the integral as the overlap between the forward-propagated input mode $u_{forward}$ and the backpropagated target mode $u_{backward}$ (denoted $v$ in source Eq 7 context).*
    *Correction based on source Eq 7:* The source writes $\Re((v_{ijk+1}^n)^* u_{ijk+1}^n(d))$. Here $v_{ijk+1}^n$ is the target mode distribution at $z_{k+1}$ obtained by backpropagation, and $u_{ijk+1}^n(d)$ is the input mode distribution at $z_{k+1}$ obtained by forward propagation through the candidate voxel $d$.

**Algorithm Steps:**

1.  **Initialization:** Set all voxel selections $d_{ijk} = 0$ (null distribution $\Delta RI_0$).
2.  **Forward Propagation:** Propagate all input modes $\{u_n\}$ from $z_1$ to $z_{K+1}$ using the Split-Step Fourier Beam Propagation Method (BPM).
    *   For each layer $k$ from $1$ to $K$:
        *   Store the transverse field distributions $\{u_{ijk}^n\}$ at plane $z_k$ for all $i,j,n$.
        *   Apply the phase mask corresponding to the current selection $d_{ijk}$ for each sub-volume $v_{ijk}$.
        *   Propagate through the layer thickness $dz$.
3.  **Convergence Check:** Compute the global overlap criterion $O_{max}$ (Eq. 6) at $z_{out}$. If the value is satisfactory or has stagnated, terminate and output the current voxel grid.
4.  **Backward Propagation and Voxel Selection:**
    *   Initialize the target modes $\{v_n\}$ at $z_{K+1}$.
    *   For each layer $k$ from $K$ down to $1$:
        *   For each sub-volume $v_{ijk}$ in layer $k$:
            *   For each candidate distribution index $d$ from $1$ to $D$:
                *   Calculate the forward propagation of the stored input field $u_{ijk}^n$ from $z_k$ to $z_{k+1}$ through the candidate voxel $\Delta RI_{ijk}^d$. Let this result be $u_{ijk+1}^n(d)$.
                *   Calculate the local criterion value: $C_d = \sum_{n=1}^{N} \int_{z_{k+1}} \Re\left( (v_{ijk+1}^n)^* u_{ijk+1}^n(d) \right)$.
            *   Select the index $d^*$ that maximizes $C_d$.
            *   Update the voxel selection: $d_{ijk} = d^*$.
        *   Backpropagate the target modes $\{v_n\}$ from $z_{k+1}$ to $z_k$ through the *selected* voxels in layer $k$ to update the fields for the next iteration of the backward pass.
5.  **Iteration:** Repeat steps 2–4 until convergence.

**Pseudocode:**

```python
def inverse_design_cgvh(N, modes_u, modes_v, wavelengths, bulk_indices, 
                        voxel_library, grid_dims_I, grid_dims_J, grid_dims_K,
                        Dz, dx, dy, dz, max_iterations, tolerance):
    """
    N: int, number of modes
    modes_u: list of complex arrays, input modes at z1
    modes_v: list of complex arrays, target modes at zK+1
    wavelengths: list of floats, lambda_n
    bulk_indices: list of floats, n_n
    voxel_library: dict mapping d -> complex phase array phi_d
    grid_dims_I, J, K: int
    Dz: float, sub-volume length
    dx, dy, dz: float, simulation resolution
    """
    
    # Initialize voxel grid with null distribution (index 0)
    voxel_grid = np.zeros((grid_dims_I, grid_dims_J, grid_dims_K), dtype=int)
    
    # Precompute phase masks for all voxels and wavelengths
    # phi[d][n] is the phase array for voxel d at wavelength n
    phase_masks = {}
    for d, phi_d in voxel_library.items():
        phase_masks[d] = {}
        for n_idx, lam in enumerate(wavelengths):
            # phi = exp(i * 2pi / lambda * dRI * dz)
            # voxel_library provides dRI or phi directly? 
            # Source says phi = exp(i 2pi/lambda dRI dz). 
            # Assuming voxel_library provides dRI or we compute phi from it.
            # Let's assume voxel_library provides dRI_d.
            dRI = voxel_library[d] # shape (H, W)
            phase = np.exp(1j * 2 * np.pi / lam * dRI * dz)
            phase_masks[d][n_idx] = phase

    for iteration in range(max_iterations):
        # Step 1: Forward Propagation
        # Store fields at each plane z_k
        # U_forward[k][i][j][n] stores field at plane z_k for sub-volume (i,j) and mode n
        U_forward = np.zeros((grid_dims_K + 1, grid_dims_I, grid_dims_J, N), dtype=complex)
        
        current_fields = modes_u # List of N arrays at z1
        
        for k in range(1, grid_dims_K + 1):
            # Store fields at plane z_k (before crossing sub-volumes in layer k)
            # Note: Source says "saved before crossing each sub-volume". 
            # So U_forward[k] is the field arriving at the start of layer k.
            for n in range(N):
                U_forward[k, :, :, n] = current_fields[n]
            
            # Propagate through layer k
            next_fields = []
            for i in range(grid_dims_I):
                for j in range(grid_dims_J):
                    d_idx = voxel_grid[i, j, k-1] # 0-indexed array, k is 1-indexed layer
                    # Apply phase mask for each mode
                    for n in range(N):
                        phase = phase_masks[d_idx][n]
                        # Apply phase to the field at (i,j) for mode n
                        # Propagation through homogeneous medium is handled by BPM step
                        # Here we assume the BPM propagation function handles the homogeneous part
                        # and we just multiply by the local phase
                        current_fields[n][i, j] *= phase
                    
                    # Propagate through the layer thickness dz using BPM
                    # This updates current_fields[n][i,j] to the field at z_{k+1}
                    # Note: BPM usually operates on the whole plane. 
                    # For voxel-based, we might propagate the whole plane but apply phase locally.
                    # Simplified: Propagate the entire plane for each mode.
                    pass 
            
            # Re-structure current_fields for next iteration
            # In a real implementation, BPM propagates the whole 2D plane.
            # The voxel selection is local to sub-volumes.
            # We must propagate the full plane containing all sub-volumes.
            
            # Let's assume a function `bpm_propagate(field, dz, n_idx)`
            # We need to apply the phase masks for the current layer k to the whole plane
            # before calling BPM.
            
            # Construct the full phase mask for layer k
            full_phase_mask = np.zeros((H, W), dtype=complex)
            for i in range(grid_dims_I):
                for j in range(grid_dims_J):
                    d_idx = voxel_grid[i, j, k-1]
                    # Map sub-volume (i,j) to pixel coordinates
                    # This requires knowing the pixel mapping of sub-volumes
                    # Assume sub-volumes are contiguous blocks
                    y_start, y_end = j * Dy_pixels, (j+1) * Dy_pixels
                    x_start, x_end = i * Dx_pixels, (i+1) * Dx_pixels
                    full_phase_mask[y_start:y_end, x_start:x_end] = phase_masks[d_idx][n_idx] # Wait, phase depends on n
            
            # Correct approach:
            # For each mode n, create a full plane phase mask for layer k
            for n in range(N):
                full_phase_mask_n = np.zeros((H, W), dtype=complex)
                for i in range(grid_dims_I):
                    for j in range(grid_dims_J):
                        d_idx = voxel_grid[i, j, k-1]
                        y_start, y_end = j * Dy_pixels, (j+1) * Dy_pixels
                        x_start, x_end = i * Dx_pixels, (i+1) * Dx_pixels
                        full_phase_mask_n[y_start:y_end, x_start:x_end] = phase_masks[d_idx][n]
                
                # Apply phase and propagate
                current_fields[n] *= full_phase_mask_n
                current_fields[n] = bpm_propagate(current_fields[n], dz, wavelengths[n])
            
            # Store results for next layer start
            # U_forward[k+1] is the field at z_{k+1}
            for n in range(N):
                U_forward[k+1, :, :, n] = current_fields[n]

        # Step 2: Convergence Check
        # Compute global overlap at z_{K+1}
        # O_max = sum Re(v_n* * u_n)
        overlap = 0
        for n in range(N):
            overlap += np.sum(np.real(np.conj(modes_v[n]) * U_forward[grid_dims_K+1, :, :, n]))
        
        if iteration > 0 and abs(overlap - prev_overlap) < tolerance:
            break
        prev_overlap = overlap

        # Step 3: Backward Propagation and Voxel Selection
        # Start with target modes at z_{K+1}
        current_fields_back = modes_v
        
        for k in range(grid_dims_K, 0, -1):
            # We need to select voxels for layer k
            # The criterion uses u_{ijk+1}^n(d) (forward propagated through d)
            # and v_{ijk+1}^n (backpropagated target)
            
            # First, we need the backpropagated target fields at z_{k+1}
            # These are currently in current_fields_back
            # But we need to backpropagate them through layer k to get to z_k
            # However, the selection depends on the forward field at z_{k+1}
            
            # Let's separate the backpropagation step
            # 1. Select voxels for layer k using current backpropagated fields at z_{k+1}
            # 2. Backpropagate through the SELECTED voxels to get fields at z_k
            
            # Get backpropagated fields at z_{k+1}
            V_at_k_plus_1 = current_fields_back
            
            # Select voxels for layer k
            for i in range(grid_dims_I):
                for j in range(grid_dims_J):
                    best_d = 0
                    best_score = -np.inf
                    
                    # Get forward fields at z_k for this sub-volume
                    U_at_k = U_forward[k, i, j, :] # Shape (N,)
                    
                    for d in range(1, len(voxel_library)): # Try all non-null distributions
                        # Propagate U_at_k through voxel d to z_{k+1}
                        # This is a local propagation for the sub-volume
                        # We need to simulate the propagation of the field at (i,j) through dz with phase d
                        
                        # Create a local field for the sub-volume
                        # Assuming we can propagate a small patch
                        U_at_k_plus_1_d = propagate_local(U_at_k, phase_masks[d], dz, wavelengths)
                        
                        # Calculate local criterion
                        score = 0
                        for n in range(N):
                            # V_at_k_plus_1[i,j,n] is the backpropagated target mode at z_{k+1}
                            # U_at_k_plus_1_d[n] is the forward propagated input mode through voxel d
                            score += np.sum(np.real(np.conj(V_at_k_plus_1[i, j, n]) * U_at_k_plus_1_d[n]))
                        
                        if score > best_score:
                            best_score = score
                            best_d = d
                    
                    voxel_grid[i, j, k-1] = best_d
            
            # Now backpropagate the target modes through the SELECTED voxels in layer k
            # to update current_fields_back for the next iteration (k-1)
            # We need to backpropagate the entire plane
            for n in range(N):
                # Construct full phase mask for layer k using selected voxels
                full_phase_mask_n = np.zeros((H, W), dtype=complex)
                for i in range(grid_dims_I):
                    for j in range(grid_dims_J):
                        d_idx = voxel_grid[i, j, k-1]
                        y_start, y_end = j * Dy_pixels, (j+1) * Dy_pixels
                        x_start, x_end = i * Dx_pixels, (i+1) * Dx_pixels
                        full_phase_mask_n[y_start:y_end, x_start:x_end] = phase_masks[d_idx][n]
                
                # Backpropagate: conjugate phase, reverse propagation
                # Backpropagation is equivalent to forward propagation with conjugated phase and reversed direction
                # Or simply using the adjoint of the forward operator
                # For lossless, backpropagate through the same phase mask but in reverse
                current_fields_back[n] *= np.conj(full_phase_mask_n)
                current_fields_back[n] = bpm_backpropagate(current_fields_back[n], dz, wavelengths[n])

    return voxel_grid
```

**Edge Cases and Pitfalls:**
*   **Precision:** The simulation resolution $dx, dy, dz$ must be much finer than the sub-volume dimensions to accurately model the phase accumulation. Typical values are $dx=dy=0.25\mu m, dz=0.5\mu m$ for $D_z=10\mu m$ [S1, unofficial].
*   **Boundary Conditions:** The algorithm assumes a finite extent sample. Edge effects in the BPM propagation must be handled with appropriate padding or boundary conditions.
*   **Lossless Assumption:** The equivalence between minimization and maximization (Eq. 5 to Eq. 6) holds only if the mode norms are conserved. If there is loss, the criterion must be adjusted [S1, unofficial].
*   **Discrete Voxel Library:** The performance depends on the diversity and quality of the available voxel distributions $\{\Delta RI_d\}$. If the library is too coarse, the optimization may get stuck in local minima.

## Operating characteristics
*   **Time Complexity:** The algorithm is iterative. Each iteration involves $K$ forward propagation steps and $K$ backward propagation steps. The voxel selection step for each sub-volume $v_{ijk}$ requires trying $D$ distributions. Thus, the complexity per iteration is $O(K \cdot I \cdot J \cdot D \cdot \text{BPM\_cost})$. BPM cost is typically $O(M \log M)$ for $M$ pixels.
*   **Memory Complexity:** Requires storing the field distributions at each plane $z_k$ for all modes and sub-volumes, $O(K \cdot I \cdot J \cdot N \cdot M)$.
*   **Strengths:** Allows for the design of complex 3D structures for multi-mode conversion. The iterative nature allows for local optimization, which can be more efficient than global optimization.
*   **Limitations:** Computationally expensive due to the large number of forward/backward propagations and voxel trials. Convergence is not guaranteed and depends on the initial guess and the voxel library.
*   **When to use:** When designing CGVHs for mode sorting or conversion where high efficiency and specific mode mapping are required, and computational resources are available.

## Background
The algorithm was proposed in the context of designing computer-generated volume holograms in glass for mode conversion [S1, unofficial]. It builds on the Iterative Propagation Algorithm (IPA) concept, where the global optimization problem is decomposed into local optimizations at each propagation plane. The method relies on the split-step Fourier Beam Propagation Method (BPM) for accurate wave propagation modeling.
