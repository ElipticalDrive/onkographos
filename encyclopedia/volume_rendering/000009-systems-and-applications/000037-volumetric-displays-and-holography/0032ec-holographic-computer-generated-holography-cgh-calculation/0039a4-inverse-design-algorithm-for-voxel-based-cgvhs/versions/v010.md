# Inverse Design Algorithm for Voxel-based CGVHs

Also called: Iterative Propagation Algorithm (IPA) for mode conversion

## Overview
The Inverse Design Algorithm for Voxel-based Computer-Generated Volume Holograms (CGVHs) is a method for designing holographic structures that convert $N$ mutually incoherent transverse input modes $\{u_n\}$ into $N$ target modes $\{v_n\}$ with a one-to-one mapping [S1, unofficial]. It solves the problem of optimizing the refractive index distribution within a 3D volume to achieve specific mode conversion efficiencies. Unlike direct forward calculation methods, this algorithm uses an iterative approach to select voxel distributions that maximize the overlap between propagated fields and target modes [S1, unofficial]. It is distinguished from sibling methods by its reliance on a split-step Fourier Beam Propagation Method (BPM) and a local multi-objective criterion to select from a discrete set of pre-defined transverse voxel profiles [S1, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
*   $N$: Number of input/target mode pairs.
*   $\{u_n\}_{n=1}^N$: Input mode field distributions defined at plane $z_{in} = z_1$.
*   $\{v_n\}_{n=1}^N$: Target mode field distributions defined at plane $z_{out} = z_{K+1}$.
*   $\lambda_n$: Wavelength associated with mode pair $n$.
*   $n_n$: Bulk refractive index of the sample at wavelength $\lambda_n$.
*   $D$: Number of available transverse voxel distributions $\{\Delta RI_d\}_{d=0}^D$. $\Delta RI_0$ is the null modification.
*   $I, J, K$: Grid dimensions of the sample volume.
*   $D_x, D_y, D_z$: Spatial extensions of sub-volumes $v_{ijk}$.
*   $dx, dy, dz$: Simulation spatial resolutions.

**Outputs:**
*   Selected voxel distribution $\Delta RI_{ijk}^*$ for each sub-volume $v_{ijk}$ ($1 \le i \le I, 1 \le j \le J, 1 \le k \le K$).

### Data Structures
The sample volume is virtually split into sub-volumes $v_{ijk}$ acting as placeholders for elementary voxel distributions.
*   **Grid:** 3D array of indices $(i, j, k)$.
*   **Sub-volume $v_{ijk}$:** Defined by spatial extent $D_x \times D_y \times D_z$.
*   **Voxel Distributions:** A discrete set of $D+1$ transverse refractive index change profiles $\Delta RI_d(x,y)$. These are relative to the bulk index $n_n$.
*   **Field Storage:** Complex 2D arrays storing transverse field distributions $u_{ijk}^n$ and $v_{ijk}^n$ at each plane $z_k$.

### Parameters
*   **Elementary Length:** $D_z = 10 \mu m$ (typical) [S1, unofficial].
*   **Simulation Resolution:** $dx = dy = 0.25 \mu m$, $dz = 0.5 \mu m$ (typical) [S1, unofficial].
*   **Coordinate System:** Rectangular $(O, x, y, z)$, with $z$ as the propagation direction [S1, unofficial].

### Algorithm Steps

1.  **Initialization:** Set all sub-volumes $v_{ijk}$ to the null distribution $\Delta RI_0$.
2.  **Forward Propagation:** Propagate input modes $\{u_n\}$ from $z_1$ to $z_{K+1}$ using the split-step Fourier BPM.
    *   For each layer $k$ from 1 to $K$:
        *   Save the transverse field distribution $u_{ijk}^n$ at plane $z_k$ before crossing $v_{ijk}$.
        *   Cross $v_{ijk}$ using the current selected distribution $\Delta RI_{ijk}^d$.
        *   The phase multiplication for crossing a layer of thickness $dz$ is:
            $$ \phi_{ijk}(\lambda_n) = \exp\left(i \frac{2\pi}{\lambda_n} \Delta RI_{ijk}^d(\lambda_n) dz\right) $$
            for $0 \le d \le D$ [S1, unofficial].
3.  **Convergence Check:** Compute the final overlap criterion $O_{max}$ (see Formula below). If satisfactory or stagnant, exit.
4.  **Backward Propagation and Voxel Selection:**
    *   Start from $k = K$ down to 1.
    *   For each sub-volume $v_{ijk}$ at layer $k$:
        *   The target modes $\{v_{ijk+1}^n\}$ are known at plane $z_{k+1}$ (from backpropagation or initial target).
        *   The input modes $\{u_{ijk}^n\}$ are known at plane $z_k$ (from forward pass storage).
        *   Select the distribution $d$ that maximizes the local multi-objective criterion $O_{ijk}^{max}$:
            $$ O_{ijk}^{max} = \max_{d} \left\{ \sum_{n=1}^{N} \int_{z_{k+1}} \Re\left( (v_{ijk+1}^n)^* u_{ijk+1}^n(d) \right) \right\} $$
            where $u_{ijk+1}^n(d)$ is the field propagated from $z_k$ to $z_{k+1}$ through $\Delta RI_{ijk}^d$ [S1, unofficial].
        *   To find the optimal $d$, try all distributions $\{\Delta RI_{ijk}^d\}$ for the fixed sub-volume.
        *   Set $\Delta RI_{ijk}^* = \Delta RI_{ijk}^d$ for the maximizing $d$.
        *   Backpropagate the target modes $\{v_{ijk+1}^n\}$ from $z_{k+1}$ to $z_k$ through the selected $\Delta RI_{ijk}^*$ to obtain $\{v_{ijk}^n\}$ for the next iteration step.
    *   Repeat until $k=1$.
5.  **Iteration:** Repeat steps 2-4 until convergence.

### Pseudocode

```python
def inverse_design_CGVH(N, modes_u, modes_v, wavelengths, n_bulk, 
                        voxel_distributions, I, J, K, Dz, dx, dy, dz):
    """
    Inverse design algorithm for voxel-based CGVHs.
    
    Args:
        N: Number of mode pairs.
        modes_u: List of N complex 2D arrays (input modes at z1).
        modes_v: List of N complex 2D arrays (target modes at z_{K+1}).
        wavelengths: List of N wavelengths.
        n_bulk: Bulk refractive index (scalar or wavelength-dependent).
        voxel_distributions: List of D+1 transverse refractive index profiles.
                             Index 0 is null (all zeros).
        I, J, K: Grid dimensions.
        Dz: Elementary length in z.
        dx, dy, dz: Simulation resolutions.
        
    Returns:
        selected_voxels: 3D array (I, J, K) of indices d.
    """
    
    # Initialize all sub-volumes to null distribution (index 0)
    selected_voxels = np.zeros((I, J, K), dtype=int)
    
    # Storage for fields at each plane z_k
    # u_fields[k][n] stores u_{ijk}^n at plane z_k for all i,j
    u_fields = [np.zeros((I, J, N, H, W), dtype=complex) for _ in range(K + 1)]
    
    # Helper: Split-step Fourier BPM propagation through one layer
    def propagate_layer(field_in, dz, delta_ri, wavelength, n_b):
        """
        Propagate field through a layer of thickness dz with refractive index change delta_ri.
        Uses split-step Fourier method.
        """
        # 1. Propagation in homogeneous medium (phase shift in frequency domain)
        # This is a simplified representation; actual BPM involves FFT/IFFT steps
        # and handling of the homogeneous medium phase.
        # For the purpose of this algorithm description, we assume a standard BPM function exists.
        field_prop = split_step_bpm(field_in, dz, n_b, wavelength)
        
        # 2. Local phase multiplication due to voxel
        # phi = exp(i * 2*pi/lambda * delta_ri * dz)
        phase = np.exp(1j * 2 * np.pi / wavelength * delta_ri * dz)
        field_out = field_prop * phase
        
        return field_out

    # Helper: Backpropagation (reverse of forward propagation)
    def backpropagate_layer(field_in, dz, delta_ri, wavelength, n_b):
        """
        Backpropagate field through a layer.
        """
        # Reverse the phase multiplication
        phase = np.exp(-1j * 2 * np.pi / wavelength * delta_ri * dz)
        field_prop = field_in * phase
        
        # Reverse homogeneous propagation
        field_out = reverse_split_step_bpm(field_prop, dz, n_b, wavelength)
        return field_out

    # Helper: Compute local criterion
    def compute_local_criterion(u_in, v_target_next, delta_ri_candidate, wavelength, n_b, dz):
        """
        Compute the overlap integral for a candidate voxel distribution.
        O = Re( integral( conj(v_target_next) * u_propagated ) )
        """
        # Propagate u_in through the candidate voxel to get u_next
        u_next = propagate_layer(u_in, dz, delta_ri_candidate, wavelength, n_b)
        
        # Compute overlap
        overlap = np.sum(np.conj(v_target_next) * u_next)
        return np.real(overlap)

    # Main Loop
    max_iterations = 100
    for iteration in range(max_iterations):
        
        # Step 1: Forward Propagation
        # Initialize u_fields[0] with input modes
        for n in range(N):
            u_fields[0][:, :, n, :, :] = modes_u[n]
            
        for k in range(1, K + 1):
            for i in range(I):
                for j in range(J):
                    d = selected_voxels[i, j, k-1] # Index of selected voxel for v_{ijk}
                    delta_ri = voxel_distributions[d]
                    
                    for n in range(N):
                        # Save field before crossing
                        u_fields[k-1][i, j, n, :, :] = u_fields[k-1][i, j, n, :, :] # Already saved from previous step or init
                        
                        # Propagate through sub-volume v_{ijk}
                        # Note: The algorithm saves u_{ijk}^n BEFORE crossing.
                        # So u_fields[k-1] holds u_{ijk}^n.
                        # We propagate to get u_{ijk+1}^n which goes into u_fields[k]
                        
                        # Propagate from z_k to z_{k+1}
                        u_fields[k][i, j, n, :, :] = propagate_layer(
                            u_fields[k-1][i, j, n, :, :], 
                            dz, delta_ri, wavelengths[n], n_bulk
                        )
        
        # Step 2: Convergence Check
        # Compute final overlap criterion O_max
        # O_max = sum_n Re( integral( conj(v_n) * u_n(z_out) ) )
        total_overlap = 0.0
        for n in range(N):
            overlap = np.sum(np.conj(modes_v[n]) * u_fields[K][:, :, n, :, :])
            total_overlap += np.real(overlap)
            
        # Check convergence (simplified)
        if iteration > 0 and abs(total_overlap - prev_overlap) < 1e-6:
            break
        prev_overlap = total_overlap
        
        # Step 3: Backward Propagation and Voxel Selection
        # Initialize v_fields[K] with target modes
        for n in range(N):
            v_fields[K][:, :, n, :, :] = modes_v[n]
            
        for k in range(K, 0, -1):
            for i in range(I):
                for j in range(J):
                    best_d = 0
                    best_criterion = -np.inf
                    
                    # Get stored input field at z_k
                    u_in = u_fields[k-1][i, j, :, :, :] # Shape (N, H, W)
                    
                    # Get target field at z_{k+1}
                    v_target = v_fields[k][i, j, :, :, :] # Shape (N, H, W)
                    
                    # Try all distributions
                    for d in range(len(voxel_distributions)):
                        delta_ri = voxel_distributions[d]
                        
                        # Compute criterion for each mode and sum
                        local_criterion = 0.0
                        for n in range(N):
                            # Propagate u_in[n] through candidate voxel
                            u_next = propagate_layer(
                                u_in[n, :, :], 
                                dz, delta_ri, wavelengths[n], n_bulk
                            )
                            # Compute overlap with v_target[n]
                            overlap = np.real(np.sum(np.conj(v_target[n, :, :]) * u_next))
                            local_criterion += overlap
                            
                        if local_criterion > best_criterion:
                            best_criterion = local_criterion
                            best_d = d
                    
                    # Select best voxel
                    selected_voxels[i, j, k-1] = best_d
                    
                    # Backpropagate target modes from z_{k+1} to z_k
                    delta_ri_best = voxel_distributions[best_d]
                    for n in range(N):
                        v_fields[k-1][i, j, n, :, :] = backpropagate_layer(
                            v_target[n, :, :], 
                            dz, delta_ri_best, wavelengths[n], n_bulk
                        )

    return selected_voxels
```

### Edge Cases and Pitfalls
*   **Precision:** The simulation resolution $dx, dy, dz$ must be much smaller than the feature size to ensure numerical accuracy. Typical values are $dx=dy=0.25 \mu m$ and $dz=0.5 \mu m$ [S1, unofficial].
*   **Boundary Conditions:** The algorithm assumes a finite extent sample. Boundary effects in the BPM propagation must be handled appropriately (e.g., PML layers) to avoid reflections [S1, G, unofficial].
*   **Degenerate Input:** If input modes are not orthogonal or if the target modes are not achievable with the available voxel distributions, the algorithm may not converge to a perfect solution. The convergence criterion should monitor the stagnation of the overlap metric [S1, unofficial].
*   **Wavelength Dependence:** The voxel distributions $\Delta RI_d$ may be wavelength-dependent. The algorithm must use the correct $\Delta RI_d(\lambda_n)$ for each mode $n$ [S1, unofficial].

## Operating characteristics
*   **Complexity:** The algorithm is iterative. Each iteration involves $K$ forward propagation steps and $K$ backward propagation steps. In each step, for each sub-volume, all $D$ voxel distributions are tested. Thus, the complexity per iteration is $O(K \cdot I \cdot J \cdot D \cdot N \cdot \text{BPM\_Cost})$. BPM cost is typically $O(H \cdot W \log(H \cdot W))$ per mode per layer.
*   **Memory:** Requires storing fields at all $K+1$ planes for all $N$ modes, plus the voxel distributions. Memory complexity is $O(K \cdot I \cdot J \cdot N \cdot H \cdot W)$.
*   **Strengths:** Allows for the design of complex 3D structures for multi-mode conversion. It is efficient compared to global optimization methods because it uses a local selection criterion [S1, unofficial].
*   **Limitations:** The solution is dependent on the initial guess (all null) and the set of available voxel distributions. It may get stuck in local optima. The assumption of lossless design limits its applicability to systems with significant absorption [S1, unofficial].

## Background
The algorithm was proposed in the context of designing computer-generated volume holograms (CGVHs) in glass for mode conversion [S1, unofficial]. It is based on the Iterative Propagation Algorithm (IPA) [50], which maximizes the overlap integral between propagated fields and target fields. The method was developed to address the need for efficient mode sorters and converters in optical communications and quantum photonic chips [S1, unofficial].
