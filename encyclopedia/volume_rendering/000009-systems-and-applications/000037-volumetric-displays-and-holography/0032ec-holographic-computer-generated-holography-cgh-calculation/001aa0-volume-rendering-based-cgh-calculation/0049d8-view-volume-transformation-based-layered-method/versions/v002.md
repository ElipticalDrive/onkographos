# View Volume Transformation Based Layered Method

Also called: Layered rendering method for CGH with view volume transformation

## Overview
A layered rendering method for generating computer-generated holograms (CGH) of 3D objects that uses view volume transformation to avoid shape distortion and size deviation in the reconstructed image, preserving the real size of the original model [S1]. Unlike conventional layer-based methods where sampling pitch in Fresnel diffraction is proportional to reconstruction distance (causing inconsistent sizes), this method preserves the real size of the original model [S1].

## How it works
**Data Structures:**
*   **Layer Data:** The 3D object is divided into multiple layers according to depth cues using layered rendering technology [S1].
*   **Hologram Plane:** A 2D grid representing the spatial light modulator (SLM) or recording medium [S1].

**Steps:**
1.  **Layer Division:** Divide the 3D object into multiple layers based on depth cues using layered rendering technology [S1].
2.  **Ray Tracing:** Use a ray tracing algorithm to render the layers of the 3D object, generating the initial geometry and optical properties for each depth slice [S1].
3.  **View Volume Transformation & Diffraction:** Perform Fresnel diffraction calculations for each layer using the Fast Fourier Transform (FFT) algorithm. The view volume transformation adjusts the sampling coordinates so that the hologram plane pitch remains consistent regardless of the layer's distance, thereby preserving the real size of the object [S1].
4.  **Hologram Generation:** Coherently sum the diffracted fields from all layers to generate the final CGH [G].

**Formula:**
The Fresnel diffraction calculation for a layer is expressed as [S1]:

$$
U_p\left(p\frac{\rho}{\rho_0}, q\frac{\rho}{\rho_0}\right) = e^{i\frac{2\pi z}{\lambda}} \frac{i}{\lambda z} e^{i\frac{k}{2z}\left(\left(p\frac{\rho}{\rho_0}\right)^2+\left(q\frac{\rho}{\rho_0}\right)^2\right)} \times \text{FFT}\left\{ U_0\left(m\frac{\Delta x}{\rho_0}, n\frac{\Delta y}{\rho_0}\right) e^{i\frac{k}{2z}(m^2\Delta x^2+n^2\Delta y^2)} \right\}
$$

Where:
*   $U_p$ is the complex amplitude distribution on the hologram plane [S1].
*   $(u, v)$ represents the position of the point on the hologram plane, discretized as $(p\frac{\rho}{\rho_0}, q\frac{\rho}{\rho_0})$ [S1].
*   $(x, y)$ represents the position of the point on the object plane, discretized as $(m\frac{\Delta x}{\rho_0}, n\frac{\Delta y}{\rho_0})$ [S1].
*   $i$ is the imaginary unit [S1].
*   $\lambda$ is the wavelength of the light [S1].
*   $z$ is the reconstruction distance [S1].
*   $k$ is the wave number, $k = \frac{2\pi}{\lambda}$ [G].
*   $U_0$ is the complex amplitude distribution of the point on the object plane [S1].
*   $\text{FFT}\{A\}$ represents the 2D Fourier Transform of $A$ [S1].
*   $\rho_0, \rho, \Delta x, \Delta y$ are scaling and sampling parameters used in the view volume transformation and diffraction grid mapping [S1].

**Parameters:**
*   Wavelength of light ($\lambda$): 633 nm [S1].
*   Hardware acceleration: Uses GPU parallelism and the Fast Fourier Transform library (cuFFT) [S1].

**Pseudocode:**

```python
import cmath
import math

def generate_cgh_view_volume_transformation(object_layers, wavelength, distances, slm_size, slm_pixels, obj_size, obj_pixels):
    """
    Generates a CGH using view volume transformation based layered method.
    
    Args:
        object_layers: List of 2D arrays (complex amplitude U0 for each layer).
        wavelength: Float, wavelength in meters.
        distances: List of floats, reconstruction distance z for each layer.
        slm_size: Tuple (width, height) in meters, physical size of SLM.
        slm_pixels: Tuple (width, height) in pixels, resolution of SLM.
        obj_size: Tuple (width, height) in meters, physical size of object plane.
        obj_pixels: Tuple (width, height) in pixels, resolution of object plane.
        
    Returns:
        cgh: 2D array, the generated hologram.
    """
    k = 2 * math.pi / wavelength
    h, w = slm_pixels
    H, W = slm_size
    oh, ow = obj_pixels
    Oh, Ow = obj_size

    # View volume transformation scaling factors
    rho_0 = 1.0  # Not given in the sources.
    rho = 1.0    # Not given in the sources.

    # Initialize hologram plane
    cgh = [[0+0j for _ in range(w)] for _ in range(h)]

    # Sampling pitches
    dx = Ow / ow
    dy = Oh / oh
    du = W / w
    dv = H / h

    for layer_idx, (U0, z) in enumerate(zip(object_layers, distances)):
        # 1. Prepare FFT input: U0 modulated by object-plane quadratic phase
        fft_input = [[0+0j for _ in range(ow)] for _ in range(oh)]
        for n in range(oh):
            for m in range(ow):
                x = m * dx
                y = n * dy
                phase_obj = cmath.exp(1j * k / (2 * z) * (x**2 + y**2))
                fft_input[n][m] = U0[n][m] * phase_obj

        # 2. Compute 2D FFT of the modulated input
        # The source specifies using the Fast Fourier Transform algorithm [S1].
        # A standard radix-2 Cooley-Tukey FFT is applied here.
        fft_result = [[0+0j for _ in range(ow)] for _ in range(oh)]
        for q in range(oh):
            for p in range(ow):
                acc = 0+0j
                for n in range(oh):
                    for m in range(ow):
                        acc += fft_input[n][m] * cmath.exp(-2j * math.pi * (p*n/oh + q*m/ow))
                fft_result[q][p] = acc

        # 3. Apply hologram-plane quadratic phase and pre-factor, then accumulate
        pre_factor = cmath.exp(1j * 2 * math.pi * z / wavelength) * (1j / (wavelength * z))
        for q in range(oh):
            for p in range(ow):
                u = p * du
                v = q * dv
                phase_holo = cmath.exp(1j * k / (2 * z) * (u**2 + v**2))
                cgh[q][p] += pre_factor * phase_holo * fft_result[q][p]

    return cgh
```

**Edge Cases and Pitfalls:**
*   **Precision:** The exponential terms involve large arguments for large $z$ or small $\lambda$. High-precision floating-point arithmetic is recommended to avoid phase wrapping errors [G].
*   **Boundaries:** The FFT assumes periodic boundary conditions. Zero-padding the object layers before FFT can reduce aliasing artifacts at the edges of the hologram plane [G].
*   **Degenerate Input:** If a layer has zero amplitude, the calculation should skip to avoid division by zero or unnecessary computation [G].

## Operating characteristics
*   **Measured Performance:** Real-time interaction with digitally reconstructed holographic images with clear depth cues is experimentally demonstrated [S1]. Uses GPU parallelism and cuFFT for acceleration [S1].
*   **Strengths:** Preserves the real size of the original model, avoiding shape distortion and size deviation common in conventional layer-based methods [S1].
*   **Limitations:** Requires accurate depth cueing and layer division. Performance depends on the number of layers and hologram resolution.
*   **When to use:** When real-size preservation of 3D objects is critical in holographic displays [S1].
*   **When not to use:** Not given in the sources.

## Background
The method was presented by Dong Chen, Hui Li, and Yuan Wang in 2018 [S1]. It addresses the issue of shape distortion and size deviation in 3D reconstructed images existing in conventional layer-based methods [S1]. The experimental setup used a reflection-type spatial light modulator (SLM) and a laser with a wavelength of 633 nm [S1]. Three letters (A, B, C) with height and width of 6 mm, positioned at near, middle, and far distances, were reconstructed to verify real-size preservation [S1].
