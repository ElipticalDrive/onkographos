# View Volume Transformation Based Layered Method

Also called: Layered rendering method for CGH with view volume transformation

## Overview
A layered rendering method for generating computer-generated holograms (CGH) of 3D objects that uses view volume transformation to avoid shape distortion and size deviation in the reconstructed image, preserving the real size of the original model [S1]. Unlike conventional layer-based methods where sampling pitch in Fresnel diffraction is proportional to reconstruction distance (causing inconsistent sizes), this method preserves the real size of the original model [S1].

## How it works
**Inputs:** 3D object data (voxels or mesh), wavelength of light ($\lambda$), reconstruction distance ($z$).
**Outputs:** Computer-Generated Hologram (CGH) intensity/phase pattern.

**Data Structures:**
*   **Layer Data:** The 3D object is divided into multiple layers according to depth cues. Each layer contains the complex amplitude distribution of the object points at that specific depth.
*   **Hologram Plane:** A 2D grid representing the spatial light modulator (SLM) or recording medium.

**Steps:**
1.  **Layer Division:** Divide the 3D object into multiple layers based on depth cues using layered rendering technology [S1].
2.  **Ray Tracing:** Use a ray tracing algorithm to render the layers of the 3D object, determining the complex amplitude distribution $U_0$ for each layer [S1].
3.  **View Volume Transformation & Diffraction:** Perform Fresnel diffraction calculations for each layer using the Fast Fourier Transform (FFT) algorithm. The view volume transformation ensures that the sampling pitch on the hologram plane remains consistent regardless of the layer's distance, thereby preserving the real size of the object [S1].
4.  **Hologram Generation:** Combine the diffracted fields from all layers to generate the final CGH [S1].

**Formula:**
The Fresnel diffraction calculation for a layer is expressed as [S1]:

$$
U_p\left(\frac{p\rho}{\rho_0}, q\frac{\rho}{\rho_0}\right) = e^{i\frac{2\pi z}{\lambda}} \frac{i}{\lambda z} e^{i\frac{k}{2z}\left(\left(p\frac{\rho}{\rho_0}\right)^2+\left(q\frac{\rho}{\rho_0}\right)^2\right)} \times \text{FFT}\left\{ U_0\left(m\frac{\Delta x}{\rho_0}, n\frac{\Delta y}{\rho_0}\right) e^{i\frac{k}{2z}(m\Delta x^2+n\Delta y^2)} \right\}
$$

Where:
*   $U_p$ is the complex amplitude distribution on the hologram plane.
*   $(u, v)$ represents the position of the point on the hologram plane, discretized as $(p\frac{\rho}{\rho_0}, q\frac{\rho}{\rho_0})$ [S1]. Note: The source text uses $u,v$ in the description but $p,q$ in the formula arguments; the formula explicitly maps indices $p,q$ to physical coordinates via scaling factors.
*   $(x, y)$ represents the position of the point on the object plane, discretized as $(m\Delta x, n\Delta y)$ [S1].
*   $i$ is the imaginary unit.
*   $\lambda$ is the wavelength of the light.
*   $z$ is the reconstruction distance.
*   $k$ is the wave number, $k = \frac{2\pi}{\lambda}$.
*   $U_0$ is the complex amplitude distribution of the point on the object plane.
*   $\text{FFT}\{A\}$ represents the 2D Fourier Transform of $A$ [S1].
*   $\rho_0, \rho, \Delta x, \Delta y$ are scaling and sampling parameters related to the view volume transformation [S1].

**Parameters:**
*   Wavelength of light ($\lambda$): 633 nm [S1].
*   Hardware acceleration: Uses GPU parallelism and the Fast Fourier Transform library (cuFFT) [S1].

**Pseudocode:**

```python
def generate_cgh_view_volume_transformation(object_layers, wavelength, distances, slm_size, slm_pixels):
    """
    Generates a CGH using view volume transformation based layered method.
    
    Args:
        object_layers: List of complex amplitude distributions U0 for each layer.
                       Each U0 is a 2D array (height, width).
        wavelength: Float, wavelength of light in meters.
        distances: List of floats, reconstruction distance z for each layer.
        slm_size: Tuple (width, height) in meters, physical size of SLM.
        slm_pixels: Tuple (width, height) in pixels, resolution of SLM.
        
    Returns:
        cgh: 2D array, the generated hologram.
    """
    k = 2 * pi / wavelength
    h, w = slm_pixels
    H, W = slm_size
    
    # Initialize hologram plane
    cgh = np.zeros((h, w), dtype=complex)
    
    # Calculate sampling pitches
    # Note: The exact mapping of rho_0 and rho from the source is abstract.
    # We assume a standard FFT-based Fresnel propagation where the view volume
    # transformation adjusts the effective sampling to preserve size.
    # Standard Fresnel FFT propagation parameters:
    dx = W / w
    dy = H / h
    
    for layer_idx, (U0, z) in enumerate(zip(object_layers, distances)):
        # 1. Ray tracing/rendering step is assumed to have produced U0
        # U0 is the complex amplitude on the object plane
        
        # 2. Apply quadratic phase factor for Fresnel diffraction
        # Coordinates on object plane
        x = np.linspace(-W/2, W/2, w, endpoint=False)
        y = np.linspace(-H/2, H/2, h, endpoint=False)
        X, Y = np.meshgrid(x, y)
        
        # Quadratic phase term: exp(i * k / (2z) * (x^2 + y^2))
        quadratic_phase_obj = np.exp(1j * k / (2 * z) * (X**2 + Y**2))
        
        # Multiply U0 by quadratic phase
        U0_modulated = U0 * quadratic_phase_obj
        
        # 3. Perform 2D FFT
        # FFT{U0 * exp(...)}
        fft_result = np.fft.fft2(U0_modulated)
        
        # 4. Apply quadratic phase factor for propagation to hologram plane
        # Coordinates on hologram plane
        u = np.linspace(-W/2, W/2, w, endpoint=False)
        v = np.linspace(-H/2, H/2, h, endpoint=False)
        U, V = np.meshgrid(u, v)
        
        # Quadratic phase term: exp(i * k / (2z) * (u^2 + v^2))
        # Note: The source formula includes a pre-factor exp(i * 2*pi*z/lambda) * i / (lambda * z)
        # and the quadratic phase on the output side.
        quadratic_phase_holo = np.exp(1j * k / (2 * z) * (U**2 + V**2))
        
        # Pre-factor
        pre_factor = np.exp(1j * 2 * pi * z / wavelength) * (1j / (wavelength * z))
        
        # Combine
        U_p = pre_factor * quadratic_phase_holo * fft_result
        
        # 5. Add to total CGH
        # In a layered method, fields are typically summed coherently
        cgh += U_p
        
    return cgh
```

**Edge Cases and Pitfalls:**
*   **Precision:** The exponential terms involve large arguments for large $z$ or small $\lambda$. High-precision floating-point arithmetic is recommended to avoid phase wrapping errors [G].
*   **Boundaries:** The FFT assumes periodic boundary conditions. Zero-padding the object layers before FFT can reduce aliasing artifacts at the edges of the hologram plane [G].
*   **Degenerate Input:** If a layer has zero amplitude, the calculation should skip to avoid division by zero or unnecessary computation [G].

## Subtopics

### Fresnel Diffraction CGH
Uses the Fresnel approximation for diffraction calculations. Suitable for near-field holography. Faster than angular spectrum for large distances but less accurate for very near fields. [Link to Fresnel Diffraction CGH](fresnel-diffraction-cgh.md)

### Angular Spectrum CGH
Uses the angular spectrum method for exact diffraction calculations. Suitable for both near-field and far-field holography. More computationally intensive than Fresnel for large distances. [Link to Angular Spectrum CGH](angular-spectrum-cgh.md)

### Layered Rendering CGH
General approach of dividing 3D objects into layers and calculating holograms for each layer. May suffer from size distortion if not using view volume transformation. [Link to Layered Rendering CGH](layered-rendering-cgh.md)

## Operating characteristics
*   **Time Complexity:** Dominated by the FFT operations. For $N$ layers and hologram size $M \times M$, complexity is $O(N \cdot M^2 \log M)$.
*   **Memory Complexity:** $O(N \cdot M^2)$ to store the complex amplitude distributions for all layers.
*   **Measured Performance:** Real-time interaction with digitally reconstructed holographic images with clear depth cues is experimentally demonstrated [S1]. Uses GPU parallelism and cuFFT for acceleration [S1].
*   **Strengths:** Preserves the real size of the original model, avoiding shape distortion and size deviation common in conventional layer-based methods [S1].
*   **Limitations:** Requires accurate depth cueing and layer division. Performance depends on the number of layers and hologram resolution.
*   **When to use:** When real-size preservation of 3D objects is critical in holographic displays.
*   **When not to use:** When computational resources are extremely limited and real-time performance is not required, or when far-field holography is needed and angular spectrum might be more appropriate.

## Background
The method was presented by Dong Chen, Hui Li, and Yuan Wang in 2018 [S1]. It addresses the issue of shape distortion and size deviation in 3D reconstructed images existing in conventional layer-based methods [S1]. The experimental setup used a reflection-type spatial light modulator (SLM) and a laser with a wavelength of 633 nm [S1]. Three letters (A, B, C) with height and width of 6 mm, positioned at near, middle, and far distances, were reconstructed to verify real-size preservation [S1].
