# One Step Phase Retrieval (OSPR)
Also called: Temporal averaging

## Overview
One Step Phase Retrieval (OSPR) is a technique for generating phase-only holograms by replacing iterative phase optimization with random phase assignment, relying on temporal averaging to recover the target image intensity [S1]. It differs from standard amplitude discard methods by explicitly managing the resulting high-frequency noise through the rapid playback of multiple randomized sub-frames, rather than attempting to minimize noise within a single static hologram [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Target complex-valued object wave $O(x, y; c)$, where $x, y$ are spatial coordinates and $c$ is the color channel index.
*   **Output:** A sequence of $N$ phase-only hologram sub-frames $H_1, H_2, \dots, H_N$.

**Data Structures:**
Each sub-frame $H_k$ is a 2D array of phase values. Following the shared principles of the parent family, phase values are quantized to $L=256$ discrete levels using a uniform mid-rise quantizer $Q$:
$$
Q(\phi) = \text{round}\left( \frac{L}{2\pi} \phi \right) \cdot \frac{2\pi}{L}
$$
where $\phi$ is the continuous phase angle [S1].

**Algorithm Steps:**
1.  **Randomize Phase:** For the target object wave $O(x, y; c)$, extract the amplitude $A(x, y; c) = |O(x, y; c)|$ and the original phase $\Phi_o(x, y; c) = \arg(O(x, y; c))$. Instead of optimizing $\Phi_o$, replace it with a set of random phase values $\Phi_k(x, y; c)$ for each sub-frame $k$. The source notes that $\Phi_k$ are drawn from a uniform distribution [S1].
2.  **Construct Complex Wave:** For each sub-frame $k$, construct a complex wave $W_k(x, y; c)$ using the original target amplitude $A(x, y; c)$ and the randomized phase $\Phi_k(x, y; c)$:
    $$
    W_k(x, y; c) = A(x, y; c) \cdot e^{i \Phi_k(x, y; c)}
    $$
    Note: The source states that if object phase values are randomized, the required amplitude on the hologram plane becomes a pseudo-random uniform noise pattern [S1]. However, the implementation step implies retaining the *target* amplitude $A$ while randomizing the phase to generate different noise realizations upon amplitude discard.
3.  **Generate Hologram:** Compute the phase-only hologram $H_k$ for sub-frame $k$ by discarding the amplitude of $W_k$ and quantizing the phase:
    $$
    H_k(x, y; c) = Q\left( \arg(W_k(x, y; c)) \right)
    $$
    This results in a hologram that carries only phase information, quantized to $L$ levels [S1].
4.  **Playback:** Display the sequence $H_1, \dots, H_N$ in random succession on a high-speed spatial light modulator (SLM) [S1].
5.  **Temporal Averaging:** The human eye or a low-pass filter integrates the intensity of these sub-frames over time. The target image is perceived as the noise averages out [S1].

**Parameters:**
*   **Number of sub-frames ($N$):** Not given in the sources. Several hologram sub-frames must be calculated for each image frame [S1].
*   **SLM Switching Speed:** Must be high enough to support the required bandwidth for $N$ sub-frames per image frame [S1].

**Edge Cases and Pitfalls:**
*   **Low Contrast:** The low contrast of the noisy hologram sub-frames cannot be recovered by temporal averaging [S1].
*   **Noise Contamination:** If the amplitude is discarded on playback without sufficient averaging, the target image is heavily contaminated with noise [S1].

## Operating characteristics
*   **Time Complexity:** Requires calculating $N$ hologram sub-frames for each image frame, increasing computational load compared to single-frame methods [S1].
*   **Hardware Requirements:** Requires high bandwidth and switching speed from the display (SLM) [S1].
*   **Strengths:** Avoids the high-frequency noise or speckle often included in numerically accurate, iteratively optimized holograms [S1].
*   **Limitations:** The primary downside is that the low contrast of the noisy hologram sub-frames cannot be recovered by temporal averaging [S1].
*   **When to use:** When high-speed SLMs are available and iterative optimization is too slow or produces excessive speckle [S1].
*   **When not to use:** When the SLM switching speed is insufficient or when high contrast is critical and cannot be tolerated in the sub-frames [S1].

## Background
The method is known as One Step Phase Retrieval (OSPR) [Cable et al. 2004]. It is described as a method to obtain amplitude in a phase-only device by playing back several holograms with randomized object phases in random succession, allowing noise to average out [S1].
