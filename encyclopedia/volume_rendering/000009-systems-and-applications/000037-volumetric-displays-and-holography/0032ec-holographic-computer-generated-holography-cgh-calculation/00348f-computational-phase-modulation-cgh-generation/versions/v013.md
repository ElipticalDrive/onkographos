# Computational Phase Modulation (CGH Generation)
Also called: Fresnel Holography, Lens Phase Function Method, ORA method, Optimization with Random Phase Algorithm

## Overview
Computational Phase Modulation generates Computer-Generated Holograms (CGH) by calculating the complex wavefield required to reconstruct a target 3D scene or intensity pattern on a Spatial Light Modulator (SLM) [S1, S2]. It solves the problem of mapping discrete scene elements (voxels or points) to a 2D phase-only modulator by superposing individual "lens phase functions" for each object point [S2]. Unlike sibling methods that may rely on iterative Fourier transforms or layer-based approximations, this approach explicitly constructs the hologram via point-wise integration of sub-holograms, often combined with the Optimization with Random Phase Algorithm (ORA) to enforce uniform intensity in the reconstruction plane [S1, S2].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $N$ object points $\{\vec{o}_j\}$ with desired intensities $\{a_j\}$, the wavelength $\lambda$, and the SLM pixel grid coordinates $\vec{p} = (x,y)$.
*   **Output:** A complex-valued hologram pattern $H(\vec{p})$ or its phase component $\phi_h(x,y)$ to be displayed on the SLM.

**Data Structures:**
*   **Object Point List:** Array of structures containing 3D coordinates $(x_o, y_o, z_o)$ and intensity weight $a_j$.
*   **Hologram Plane:** 2D array of complex numbers or phase values corresponding to SLM pixels.
*   **Sub-hologram Mask:** A binary or Gaussian mask defining the local region for each object point to limit spatial frequencies [S2].

**Method Steps:**

1.  **Define Sub-hologram Regions:**
    For each object point $\vec{o}_j$, define a local region (sub-hologram) on the SLM plane. The size of this region is constrained such that the maximum spatial frequency of the lens phase function does not exceed the SLM's Nyquist limit [S2]. If sub-holograms overlap, their contributions are summed [S2].

2.  **Calculate Lens Phase Function:**
    For each pixel $\vec{p}$ within the sub-hologram of object point $\vec{o}_j$, compute the complex lens phase function $f_j(\vec{p})$ [S2]:
    $$ f_j(\vec{p}) = \exp\left(i \left( \phi_{o,j} + \frac{2\pi}{\lambda} \|\vec{p} - \vec{o}_j\| \right) \right) $$
    where:
    *   $\lambda$ is the wavelength of the reconstruction light.
    *   $\|\vec{p} - \vec{o}_j\|$ is the Euclidean distance from the SLM pixel to the object point.
    *   $\phi_{o,j}$ is a phase offset factor (typically set to 0 for initial calculation, or optimized later) [S2].

3.  **Superpose Contributions (Point-wise Integration):**
    Compute the total complex hologram $H(\vec{p})$ by summing the weighted lens phase functions for all object points $j$ whose sub-holograms cover pixel $\vec{p}$ [S2]:
    $$ H(\vec{p}) = \sum_{j \in sp(\vec{p})} a_j f_j(\vec{p}) $$
    where $sp(\vec{p})$ is the set of object points defined at pixel $\vec{p}$, and $a_j$ is the desired intensity (amplitude) of object point $j$ [S2].

4.  **Extract Phase (Phase-Only Constraint):**
    If the SLM is phase-only, extract the phase from the complex hologram $H(\vec{p}) = A(\vec{p})e^{i\phi_h(\vec{p})}$:
    $$ \phi_h(\vec{p}) = \arg(H(\vec{p})) $$
    *Note:* Simple amplitude discard may reduce efficiency. For uniform intensity spot arrays, the Optimization with Random Phase Algorithm (ORA) is applied (see Step 5) [S1].

5.  **Iterative Optimization (ORA Method) [S1]:**
    To achieve uniform intensity in the reconstruction plane, iterate the following until convergence:
    
    a. **Forward Propagation:** Calculate the reconstruction complex amplitude $U_r^{(i)}$ at the target plane from the current hologram phase $\phi_h^{(i)}$. This is typically done via Fourier Transform:
    $$ U_r^{(i)}(\nu_x, \nu_y) = \mathcal{F}\{ \exp(i \phi_h^{(i)}(x,y)) \} $$
    where $\mathcal{F}$ denotes the Fourier transform [S1].
    
    b. **Intensity Error Calculation:** Compare the reconstructed intensity $I_r^{(i)} = |U_r^{(i)}|^2$ with the desired intensity $I_r^{(d)}$. Update the weighting factor $\omega_r^{(i)}$ for each target pixel $r$ [S1]:
    $$ \omega_r^{(i)} = \omega_r^{(i-1)} \left( \frac{I_r^{(d)}}{I_r^{(i)}} \right)^\alpha $$
    where $\alpha$ is a constant (typically $\alpha=1$ or similar) [S1].
    
    c. **Backward Propagation & Phase Update:** Calculate the phase variation $\Delta\phi_h^{(i)}$ to add to the hologram. Define sums $S_1$ and $S_2$ over all target pixels $r$ [S1]:
    $$ S_1 = \sum_r \omega_r^{(i)} a_h \cos(\phi_r^{(i)} - \phi_{hr} - \phi_h^{(i)}) $$
    $$ S_2 = \sum_r \omega_r^{(i)} a_h \sin(\phi_r^{(i)} - \phi_{hr} - \phi_h^{(i)}) $$
    where:
    *   $a_h$ is the constant amplitude of the illumination plane wave [S1].
    *   $\phi_r^{(i)}$ is the phase of the reconstruction at pixel $r$.
    *   $\phi_{hr}$ is the phase contribution from pixel $h$ to target pixel $r$ (propagation phase) [S1].
    *   $\phi_h^{(i)}$ is the current phase of the hologram pixel $h$ [S1].
    
    Compute the phase update:
    $$ \Delta\phi_h^{(i)} = \tan^{-1}\left( \frac{S_2}{S_1} \right) $$
    
    d. **Update Hologram Phase:**
    $$ \phi_h^{(i+1)} = \phi_h^{(i)} + \Delta\phi_h^{(i)} $$
    
    Repeat steps 5a-5d until $I_r^{(i)} \approx I_r^{(d)}$ [S1].

6.  **Axial Focusing Control (Optional) [S1]:**
    To control the focal depth (Z-axis), add a phase Fresnel lens pattern to the hologram phase $\phi_h$:
    $$ \phi_p(x,y) = \frac{k(x^2 + y^2)}{2f} $$
    where $k = 2\pi/\lambda$ and $f$ is the desired focal length [S1]. The minimum focal length is determined by the SLM's spatial resolution [S1].

**Parameters:**
*   $\lambda$: Wavelength of light (e.g., 532 nm for green laser).
*   $f$: Focal length for axial control.
*   $\alpha$: Convergence constant in ORA (Not given in sources, typically small positive constant).
*   $a_h$: Amplitude of illumination (constant, uniform plane wave) [S1].

**Edge Cases and Pitfalls:**
*   **Spatial Frequency Limit:** If a sub-hologram is too large, the spatial frequencies of the lens phase function will exceed the SLM's support, causing aliasing or loss of diffraction efficiency. Sub-holograms must be sized to contain only supported frequencies [S2].
*   **Overlap:** Sub-holograms for different points may overlap. The method handles this by simple superposition (summing complex amplitudes) [S2].
*   **Precision:** Iterative ORA requires careful handling of phase wrapping ($\pm \pi$) to ensure convergence [S1].

## Operating characteristics
*   **Complexity:** The naive point-wise integration scales linearly with the number of object points $M$ and hologram pixels $P$ ($O(M \cdot P)$) [G]. If ORA is used, complexity increases by a factor of $I$ (iterations) and includes FFTs ($O(P \log P)$) [S1].
*   **Performance:** High-quality reconstruction is achievable, but iterative methods (ORA) are computationally expensive for real-time applications [S1].
*   **Strengths:** Explicit control over object point positions and intensities; handles 3D volumes directly [S2].
*   **Limitations:** SLM spatial frequency limits restrict sub-hologram size and thus the density of object points per unit area; overlap management is complex [S2].
*   **When to use:** When precise 3D positioning of discrete voxels is required and computational resources allow for integration or iterative optimization.

## Background
The method originates from Fresnel holography principles, where light propagation is modeled via phase alterations [S2]. The specific application to volumetric displays using LCSLMs and the ORA algorithm was detailed by Hayasaki et al. in 2015 [S1]. The "Lens Phase Function" and "Point-wise Integration" terminology was formalized in the context of holographic near-eye displays by Maimone et al. in 2017 [S2].
