# Perceptual Loss Function for Color Holography

Also called: Filtered RGB Loss, Opponent Color Space Loss

## Overview
This method replaces standard pixel-wise RGB loss functions with a perceptual loss that operates in opponent color space and applies frequency-dependent low-pass filtering. It solves the problem of high-frequency noise and color inaccuracies in holograms generated via end-to-end optimization by de-prioritizing error components that are imperceptible to the human visual system (HVS). It sets itself apart from standard RGB loss by shifting error into imperceptible regions of the opponent color space, resulting in visually less noisy holograms with better color fidelity [S1].

## How it works
The method transforms the simulated hologram intensities and target image intensities from RGB space into an opponent color space, applies channel-specific low-pass filters in the Fourier domain to mimic human contrast sensitivity, and computes the loss based on the filtered channels.

### Inputs and Outputs
*   **Inputs:**
    *   $I$: The simulated hologram image (RGB).
    *   $\hat{I}$: The target image (RGB).
    *   $k_1, k_2, k_3$: Low-pass filter kernels for luminance, red-green chrominance, and blue-yellow chrominance, respectively.
*   **Outputs:**
    *   $L_{perceptual}$: The scalar loss value to be minimized.

### Data Structures
*   **Image Arrays:** $I$ and $\hat{I}$ are 2D arrays of shape $(H, W, 3)$, representing intensity values for Red ($\lambda_r$), Green ($\lambda_g$), and Blue ($\lambda_b$) channels. Values are typically normalized to $[0, 1]$ or $[0, 255]$.
*   **Filter Kernels:** $k_i$ are 2D frequency-domain masks (or spatial kernels) corresponding to low-pass filters. In implementation, these are often defined as circular masks in the Fourier domain.

### Numbered Steps
1.  **Compute Opponent Color Channels:** Transform the RGB intensities of both the target $\hat{I}$ and the simulated hologram $I$ into three opponent color channels: luminance ($O_1$), red-green chrominance ($O_2$), and blue-yellow chrominance ($O_3$).
2.  **Apply Low-Pass Filters:** Convolve each opponent color channel with its corresponding low-pass filter kernel in the Fourier domain. This step mimics the contrast sensitivity functions of the human visual system.
3.  **Compute Loss:** Calculate the pixel-wise loss (e.g., Mean Squared Error) between the filtered target channels and the filtered simulated channels for all three opponent color components.
4.  **Aggregate:** Sum the losses from the three channels to produce the final perceptual loss value.

### Formulas
The opponent color channels are computed as [S1]:

$$
O_1 = 0.299 \cdot I_{\lambda_r} + 0.587 \cdot I_{\lambda_g} + 0.114 \cdot I_{\lambda_b}
$$

$$
O_2 = I_{\lambda_r} - I_{\lambda_g}
$$

$$
O_3 = I_{\lambda_b} - I_{\lambda_r} - I_{\lambda_g}
$$

Where:
*   $O_1$ is the luminance channel.
*   $O_2$ is the red-green chrominance channel.
*   $O_3$ is the blue-yellow chrominance channel.
*   $I_{\lambda_r}, I_{\lambda_g}, I_{\lambda_b}$ are the intensity values for the red, green, and blue wavelengths, respectively.

The optimized loss is defined as [S1]:

$$
\arg\min_s \sum_{i=1}^3 L(\hat{O}_i * k_i, O_i * k_i)
$$

Where:
*   $*$ represents 2D convolution.
*   $k_i$ is the low-pass filter for the $i$-th channel in opponent color space.
*   $\hat{O}_i$ and $O_i$ are the $i$-th opponent color channels of the target $\hat{I}$ and simulated hologram $I$, respectively.
*   $L(\cdot, \cdot)$ is a pixel-wise loss function, typically Mean Squared Error (MSE).

### Parameters
*   **Chrominance Filter Cutoff:** A low-pass filter applied to chrominance channels ($O_2, O_3$) with a width of 45% of the Fourier space width [S1].
*   **Luminance Filter Cutoff:** A low-pass filter applied to the luminance channel ($O_1$) with a width of 75% of the Fourier space width [S1].
*   **Spatial Frequency Cutoffs:** In a system with a 36.6 mm focal length eyepiece, the filter cutoffs correspond to 30 cycles/deg for luminance and 18 cycles/deg for chrominance [S1]. These values are approximately matched to human vision [S1].

### Pseudocode

```python
def perceptual_loss(I_sim, I_target, filter_width_chrom, filter_width_lum):
    """
    Computes the perceptual loss for color holography.
    
    Args:
        I_sim: Simulated hologram image (H, W, 3) with channels [R, G, B].
        I_target: Target image (H, W, 3) with channels [R, G, B].
        filter_width_chrom: Width of the low-pass filter for chrominance channels 
                            as a fraction of Fourier space width (e.g., 0.45).
        filter_width_lum: Width of the low-pass filter for luminance channel 
                          as a fraction of Fourier space width (e.g., 0.75).
    
    Returns:
        loss: Scalar perceptual loss value.
    """
    # Step 1: Compute Opponent Color Channels
    # O1: Luminance
    O1_sim = 0.299 * I_sim[:,:,0] + 0.587 * I_sim[:,:,1] + 0.114 * I_sim[:,:,2]
    O1_target = 0.299 * I_target[:,:,0] + 0.587 * I_target[:,:,1] + 0.114 * I_target[:,:,2]
    
    # O2: Red-Green Chrominance
    O2_sim = I_sim[:,:,0] - I_sim[:,:,1]
    O2_target = I_target[:,:,0] - I_target[:,:,1]
    
    # O3: Blue-Yellow Chrominance
    O3_sim = I_sim[:,:,2] - I_sim[:,:,0] - I_sim[:,:,1]
    O3_target = I_target[:,:,2] - I_target[:,:,0] - I_target[:,:,1]
    
    # Step 2: Apply Low-Pass Filters in Fourier Domain
    # Create frequency domain masks
    H, W = I_sim.shape[0], I_sim.shape[1]
    u, v = np.meshgrid(np.arange(W), np.arange(H))
    # Center the coordinates for Fourier transform
    u_centered = u - W // 2
    v_centered = v - H // 2
    # Distance from center in Fourier space
    dist = np.sqrt(u_centered**2 + v_centered**2)
    max_dist = np.sqrt((W//2)**2 + (H//2)**2)
    
    # Normalize distance to [0, 1] relative to max possible distance
    dist_norm = dist / max_dist
    
    # Create low-pass filters (circular masks)
    # Filter for chrominance channels (O2, O3)
    mask_chrom = (dist_norm <= filter_width_chrom).astype(float)
    
    # Filter for luminance channel (O1)
    mask_lum = (dist_norm <= filter_width_lum).astype(float)
    
    # Apply filters via FFT
    def apply_filter(channel, mask):
        # FFT shift to center zero frequency
        fft_channel = np.fft.fft2(channel)
        fft_shifted = np.fft.fftshift(fft_channel)
        # Apply mask
        fft_filtered = fft_shifted * mask
        # Inverse FFT
        ifft_filtered = np.fft.ifftshift(fft_filtered)
        filtered_channel = np.real(np.fft.ifft2(ifft_filtered))
        return filtered_channel

    O1_sim_filt = apply_filter(O1_sim, mask_lum)
    O1_target_filt = apply_filter(O1_target, mask_lum)
    
    O2_sim_filt = apply_filter(O2_sim, mask_chrom)
    O2_target_filt = apply_filter(O2_target, mask_chrom)
    
    O3_sim_filt = apply_filter(O3_sim, mask_chrom)
    O3_target_filt = apply_filter(O3_target, mask_chrom)
    
    # Step 3 & 4: Compute Loss and Aggregate
    # Using Mean Squared Error (MSE)
    loss_lum = np.mean((O1_sim_filt - O1_target_filt)**2)
    loss_chrom1 = np.mean((O2_sim_filt - O2_target_filt)**2)
    loss_chrom2 = np.mean((O3_sim_filt - O3_target_filt)**2)
    
    total_loss = loss_lum + loss_chrom1 + loss_chrom2
    
    return total_loss
```

### Edge Cases and Pitfalls
*   **Precision:** Ensure that the FFT operations handle the data type correctly to avoid precision loss, especially if intensities are not normalized.
*   **Boundaries:** The circular mask in the Fourier domain assumes periodic boundary conditions. If the image has sharp edges, artifacts may appear. Padding or windowing functions can mitigate this [G].
*   **Degenerate Input:** If the input images are grayscale, the chrominance channels will be zero or near-zero, and the loss will primarily depend on the luminance channel.

## Operating characteristics
*   **Time Complexity:** The additional computational cost is dominated by the FFT operations for filtering. Since the filters are fixed and can be precomputed, the per-iteration cost is minimal compared to the forward simulation of the hologram.
*   **Memory Complexity:** Requires storing the FFT of the images and the filter masks. This is $O(HW)$ per channel.
*   **Measured Performance:** The perceptual loss function yields an average PSNR increase of 6.4 dB and an average SSIM increase of 0.266 across a test set of 294 images compared to standard RGB loss [S1].
*   **Strengths:** Visually less noisy holograms with better color fidelity. The optimizer better matches low-frequency color, which is what is perceivable by the human visual system [S1].
*   **Limitations:** The improvement in PSNR/SSIM does not necessarily correlate with perceptual quality in all cases, but the method is designed to align with human vision [S1].
*   **When to use:** When visual quality is more important than strict pixel-wise fidelity, and when the holographic display system is viewed by humans.
*   **When not to use:** When the hologram is intended for machine vision or when strict quantitative metrics (PSNR/SSIM) are the primary evaluation criteria without perceptual validation.

## Background
The method was introduced in the paper "Simultaneous Color Computer Generated Holography" [S1]. It builds on the concept of opponent color space, which is a standard model in color science for representing human color perception. The specific filter cutoffs (45% for chrominance, 75% for luminance) are based on the contrast sensitivity functions of the human visual system, as documented by Mullen [S1]. The method is used in the context of end-to-end optimization for holographic displays, where the goal is to generate a single SLM pattern that produces a full RGB image when illuminated by simultaneous RGB light sources.
