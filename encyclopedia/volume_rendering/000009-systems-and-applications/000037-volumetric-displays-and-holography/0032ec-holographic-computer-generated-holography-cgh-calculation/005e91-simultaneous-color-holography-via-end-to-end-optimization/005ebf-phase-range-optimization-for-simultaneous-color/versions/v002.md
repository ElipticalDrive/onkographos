# Phase Range Optimization for Simultaneous Color

Also called: Differentiated Phase Range RGB Holography, RGB Phase Range Optimization, SLM Phase Range Optimization

## Overview
This method determines the optimal phase modulation range for each color channel (Red, Green, Blue) in a simultaneous color holography system to overcome the depth-wavelength ambiguity inherent in the Angular Spectrum Method (ASM) kernel [S1]. It ensures that the holographic patterns for each wavelength are sufficiently distinct to reconstruct unique color channels, while minimizing the phase range to preserve effective bit depth and refresh rate [S1]. It builds on [Simultaneous Color Holography via End-to-End Optimization](17688-simultaneous-color-holography-via-end-to-end-optimization.md) by explicitly optimizing the phase excursion magnitude per channel rather than relying on field-sequential or multi-SLM approaches.

## How it works
**Inputs:** Target RGB image $I_{\text{target}}$, wavelengths $\lambda_R, \lambda_G, \lambda_B$, propagation distance $z$, SLM pixel pitch $p$, SLM resolution $N \times N$ [S1].
**Outputs:** Optimal phase ranges $\Phi_R, \Phi_G, \Phi_B$ and the optimized SLM phase pattern $\Phi_{\text{SLM}}$ [S1].
**Parameters:** $\Phi_R$ fixed at $2\pi$ [S1]. $\Phi_B$ searched in $[2\pi, 8\pi]$ [S1]. $\Phi_G = (\Phi_R + \Phi_B)/2$ [S1]. Loss function is the L2 norm between target and simulated hologram [S1].

**Algorithm:**
1. Initialize $\Phi_R = 2\pi$ and $\Phi_B = 2\pi$.
2. Compute $\Phi_G = (\Phi_R + \Phi_B) / 2$.
3. For the current phase ranges, optimize the SLM pattern $\Phi_{\text{SLM}}$ using gradient descent with a naive ASM forward model [S1].
4. Compute the L2 norm loss $L = \| I_{\text{target}} - I_{\text{sim}} \|_2^2$ between the target image and the ASM-simulated hologram [S1].
5. If $L$ falls below an empirical quality threshold, record the current $\Phi_B$ and terminate the search [S1].
6. Increment $\Phi_B$ by a step (e.g., $0.1\pi$) and repeat steps 2–5 until $\Phi_B$ reaches $8\pi$ [S1].
7. Select the smallest $\Phi_B$ that met the quality threshold. For unnatural images (highly unique color channels), a minimum $\Phi_B$ of $5\pi$ is sufficient [S1]. For natural images (similar color channels), a phase difference of $4\pi$ (i.e., $\Phi_B = 6\pi$) is adequate [S1].

**Pseudocode:**
```python
import math
import numpy as np

def angular_spectrum_propagation(field, wavelength, distance, pitch):
    """Standard ASM propagation using FFT [G]."""
    N = field.shape[0]
    fx = np.fft.fftfreq(N, pitch)
    fy = np.fft.fftfreq(N, pitch)
    fx, fy = np.meshgrid(fx, fy)
    H = np.exp(1j * 2 * math.pi * distance * np.sqrt((1/wavelength)**2 - fx**2 - fy**2))
    H[fx**2 + fy**2 > (1/wavelength)**2] = 0
    return np.abs(np.fft.ifft2(np.fft.fft2(field) * H))**2

def optimize_phase_range(target_image, wavelengths, distance, pitch, resolution, image_type="natural"):
    """
    Determines optimal phase ranges for R, G, B channels via experimental search [S1].
    """
    phi_R = 2 * math.pi
    phi_B_min = 2 * math.pi
    phi_B_max = 8 * math.pi
    step = 0.1 * math.pi

    # Empirical L2 loss thresholds for acceptable quality [S1]
    # Exact values depend on scene complexity; natural images tolerate higher loss.
    threshold = 0.05 if image_type == "natural" else 0.05

    best_phi_b = phi_B_max
    best_slm_pattern = None

    phi_B = phi_B_min
    while phi_B <= phi_B_max:
        phi_G = (phi_R + phi_B) / 2

        # Inner optimization: Gradient descent to minimize L2 loss [S1]
        slm_phase = np.zeros((resolution, resolution))
        learning_rate = 0.01
        epochs = 1000 # [G] Standard iteration count for convergence

        for _ in range(epochs):
            # Phase modulation constrained to each channel's range
            phase_R = np.clip(slm_phase, 0, phi_R)
            phase_G = np.clip(slm_phase, 0, phi_G)
            phase_B = np.clip(slm_phase, 0, phi_B)

            # Simulate ASM reconstruction for each channel [G]
            U_R = angular_spectrum_propagation(np.exp(1j * phase_R), wavelengths[0], distance, pitch)
            U_G = angular_spectrum_propagation(np.exp(1j * phase_G), wavelengths[1], distance, pitch)
            U_B = angular_spectrum_propagation(np.exp(1j * phase_B), wavelengths[2], distance, pitch)

            # Incoherent intensity sum for color holography [G]
            I_sim = U_R + U_G + U_B

            # L2 norm loss [S1]
            loss = np.sum((target_image - I_sim)**2)

            # [G] The sources do not specify the exact gradient formula; standard backpropagation applies.
            grad = 2 * (I_sim - target_image) * (U_R + U_G + U_B) / (resolution**2)
            slm_phase -= learning_rate * grad

        # Evaluate quality
        if loss < threshold:
            best_phi_b = phi_B
            best_slm_pattern = slm_phase
            break

        phi_B += step

    phi_G_final = (phi_R + best_phi_b) / 2
    return phi_R, phi_G_final, best_phi_b, best_slm_pattern
```

## Operating characteristics
- **Time Complexity:** The method requires iterative gradient descent for each candidate phase range, making it computationally intensive but necessary to resolve the depth-wavelength ambiguity [S1].
- **Memory Complexity:** Requires storing the SLM phase map and intermediate complex fields for three wavelengths.
- **Performance:** Larger phase ranges degrade image quality by reducing effective bit depth and tend to have slower refresh rates on physical SLMs [S1].
- **Strengths:** Overcomes depth-wavelength ambiguity; provides a systematic way to select SLMs or configure phase ranges for simultaneous color [S1].
- **Limitations:** Requires empirical tuning or simulation to determine the "minimal" range; unnatural images require significantly larger phase ranges ($5\pi$) than natural images ($4\pi$ difference) [S1].
- **When to use:** When using an SLM with extended phase range capability for simultaneous RGB holography, or when selecting an SLM for such a system [S1].

## Background
This method originates from research into Simultaneous Color Computer Generated Holography (CGH) [S1]. It addresses the specific challenge that the Angular Spectrum Method (ASM) kernel introduces depth-wavelength ambiguity, meaning different wavelengths can produce similar diffraction patterns for different depths. By ensuring the phase ranges are sufficiently different, unique holograms are produced for each color channel [S1]. The experimental procedure was detailed in studies involving Holoeye Pluto SLMs (Red: $2.4\pi$, Green: $5.9\pi$, Blue: $7.4\pi$) and standard simulated SLMs (Red: $2\pi$, Green: $2.7\pi$, Blue: $3.4\pi$), comparing performance against depth division and bit division methods [S1].
