# Physics-Informed Deep Learning Framework for Multi-Plane CGH

Also called: Multi-Plane Neural CGH with Physics-Informed Self-Supervision, Neural Multi-Plane CGH, Physics-Informed Neural Holography

## Overview
This method generates phase-only computer-generated holograms (CGH) for multi-plane 3D targets by mapping spatial intensity distributions to depth-dependent reconstructions using a trainable Fourier transform layer [S1]. It explicitly addresses axial crosstalk (unwanted intensity diffraction from adjacent planes) by combining a physics-informed training strategy with a specialized network architecture that expands the receptive field [S1]. Unlike traditional iterative optimization methods, it achieves significant speedups while maintaining structural fidelity in sparse 3D volumes [S1].

## How it works

### Inputs and Outputs
*   **Input:** A discretized 3D target volume $I_{tar}$ with dimensions $m \times m \times p$, where $m$ is the lateral resolution (matching the SLM pixel grid) and $p$ is the number of axial depth planes [S1]. The input is a binary or sparse intensity stack representing the desired focal spots at each depth $Z_k$ [S1].
*   **Output:** A phase-only hologram $\phi_{SLM}(x, y)$ defined on the SLM plane, where $x, y$ are lateral coordinates [S1].

### Data Structures
The network processes the input as a tensor of shape $(p, m, m)$ or $(m, m, p)$ depending on channel ordering, but logically represents $p$ channels of $m \times m$ intensity values [S1]. The internal feature maps utilize space-to-depth (interleave) operations to reshape spatial regions into channel groups, effectively increasing the channel dimension while reducing spatial resolution to expand the receptive field [S1].

### Network Architecture
The model is a U-Net-style encoder-decoder architecture [S1]:
1.  **Encoder:** Consists of six convolutional blocks. Instead of standard max-pooling, it uses **space-to-depth** (interleave) operations to preserve high-frequency fringe details and expand the receptive field for global diffraction modeling [S1].
2.  **Bottleneck:** A central structure that reduces feature map channels to enhance computational efficiency [S1].
3.  **Decoder:** Uses two up-sampling stages and **depth-to-space** (deinterleave) operations to restore spatial resolution [S1].
4.  **Output Layer:** Produces the complex optical field at the focal plane $Z=0$, denoted as $U(X, Y; 0)$ [S1].

### Physics Model
The framework integrates a differentiable physics model within the training loop to constrain solutions to wave optics [S1].
1.  **SLM Field:** The complex field immediately after the SLM is defined as:
    $$ U_{SLM}(x, y) = \exp[i \phi_{SLM}(x, y)] $$
    where the input beam has unit amplitude [S1].
2.  **Propagation:** The field at image space depth $Z$ is calculated. In the far-field regime (valid when $Z \ge f$, where $f$ is the focal length of the focusing lens), the field is expressed using the 2D Fourier transform $\mathcal{F}$:
    $$ U(X, Y; Z) = A_0 \times \mathcal{F}\{U_{SLM}\} $$
    where the amplitude factor is:
    $$ A_0 = \frac{\exp(ikZ)\exp\left(\frac{ik(X^2+Y^2)}{2Z}\right)}{i\lambda Z} $$
    Here, $k = 2\pi/\lambda$ is the wavenumber and $\lambda$ is the wavelength [S1].
3.  **Intensity:** The reconstructed intensity at each depth plane is:
    $$ I(X, Y; Z) = |U(X, Y; Z)|^2 $$
    [S1].

### Training Strategy
The training involves a two-phase strategy to balance initialization and physical consistency [S1]:
1.  **Phase 1 (Supervised):** Reference holograms are computed using an angular spectrum-based CGH algorithm for the target volumes. These serve as supervisory targets for the network output during initial epochs [S1].
2.  **Phase 2 (Self-Supervised):** The reference targets are gradually phased out. The loss is evaluated directly on the reconstructed intensity volumes $I_{recon}$ generated by the physics model [S1].

### Loss Function
The primary loss is the **cosine similarity loss**, which is scale-invariant and emphasizes structural similarity over absolute intensity [S1]:
$$ L = 1 - \frac{\langle I_{tar}, I_{recon} \rangle}{|I_{tar}| |I_{recon}|} $$
where $\langle \cdot \rangle$ is the inner product and $|\cdot|$ is the modulus, computed across all pixels and all $p$ depth planes [S1].
*   **Regularization:** A regularization term is applied to the reconstructed background lying outside a narrow mask defined around the target points to suppress background noise [S1].

import torch
import torch.nn as nn
import torch.nn.functional as F

class SpaceToDepth(nn.Module):
    """Reshuffles local spatial regions into separate channel groups."""
    def __init__(self, block_size=2):
        super().__init__()
        self.block_size = block_size

    def forward(self, x):
        # x shape: (B, C, H, W)
        b, c, h, w = x.size()
        bs = self.block_size
        # Reshape to (B, C, H//bs, bs, W//bs, bs)
        x = x.view(b, c, h // bs, bs, w // bs, bs)
        # Permute to (B, C, H//bs, W//bs, bs, bs)
        x = x.permute(0, 1, 3, 5, 2, 4).contiguous()
        # View to (B, C * bs^2, H//bs, W//bs)
        x = x.view(b, c * bs * bs, h // bs, w // bs)
        return x

class DepthToSpace(nn.Module):
    """Inverse of SpaceToDepth."""
    def __init__(self, block_size=2):
        super().__init__()
        self.block_size = block_size

    def forward(self, x):
        # x shape: (B, C, H, W)
        b, c, h, w = x.size()
        bs = self.block_size
        # Reshape to (B, C, H, W) -> (B, C, H, W)
        # We need to reverse the view logic
        # From (B, C_out, H, W) where C_out = C_in * bs^2
        # View to (B, C_in, bs, bs, H, W)
        c_in = c // (bs * bs)
        x = x.view(b, c_in, bs, bs, h, w)
        # Permute to (B, C_in, H, bs, W, bs)
        x = x.permute(0, 1, 4, 2, 5, 3).contiguous()
        # View to (B, C_in, H*bs, W*bs)
        x = x.view(b, c_in, h * bs, w * bs)
        return x

class PhysicsInformedMultiPlaneCGH(nn.Module):
    def __init__(self, m, p, kernel_size=3):
        """
        Args:
            m: Lateral dimension of the SLM/target (m x m).
            p: Number of depth planes.
        """
        super().__init__()
        self.m = m
        self.p = p
        
        # Encoder
        self.enc1 = nn.Conv2d(p, 64, kernel_size, padding=1)
        self.sto1 = SpaceToDepth()
        self.enc2 = nn.Conv2d(64 * 4, 128, kernel_size, padding=1) # 4x channels due to ST
        
        # Bottleneck
        self.bottleneck = nn.Conv2d(128 * 4, 256, kernel_size, padding=1)
        
        # Decoder
        self.d2 = nn.Conv2d(256, 128, kernel_size, padding=1)
        self.dto2 = DepthToSpace()
        self.d1 = nn.Conv2d(128, 64, kernel_size, padding=1)
        self.dto1 = DepthToSpace()
        
        # Output layer: predicts complex field at Z=0
        # Output is complex, so 2 channels (real, imag)
        self.out_conv = nn.Conv2d(64, 2, kernel_size, padding=1)
        
        # Initialize weights using He initialization
        self._init_weights()

    def _init_weights(self):
        for m in self.modules():
            if isinstance(m, nn.Conv2d):
                nn.init.kaiming_normal_(m.weight, mode='fan_out', nonlinearity='relu')

    def forward(self, target_volume):
        """
        Args:
            target_volume: Tensor of shape (B, p, m, m) representing I_tar
        Returns:
            phi_slm: Tensor of shape (B, m, m) representing phase hologram
        """
        # Encoder
        x = self.enc1(target_volume)
        x = F.relu(x)
        x = self.sto1(x)
        x = self.enc2(x)
        x = F.relu(x)
        
        # Bottleneck
        x = self.bottleneck(x)
        x = F.relu(x)
        
        # Decoder
        x = self.d2(x)
        x = F.relu(x)
        x = self.dto2(x)
        x = self.d1(x)
        x = F.relu(x)
        x = self.dto1(x)
        
        # Output complex field at focal plane Z=0
        complex_field_z0 = self.out_conv(x) # Shape (B, 2, m, m)
        
        # The network outputs the estimated complex field U(X,Y;0)
        # We need to back-propagate to SLM plane via Inverse Fourier Transform
        # Note: In a fully differentiable PyTorch implementation, 
        # we would compute the loss in the physical domain.
        # However, the network *directly* outputs the hologram in some variants,
        # but the source states: "Once trained, the network establishes an end-to-end mapping... 
        # to a physically realizable approximation of the complex optical field at the focal plane... 
        # This estimated field is subsequently back-propagated to the SLM plane via an inverse 2D Fourier transform"
        
        # Therefore, the network output is U_z0. We must compute phi_slm here 
        # if this is the inference step, or keep U_z0 for loss calculation during training.
        
        # For the final output of the method (the hologram):
        # 1. Get U_z0 from network
        # 2. Compute U_slm = F_inv(U_z0 / A0)
        # 3. Extract phase
        
        # Since A0 depends on Z, and here Z=0, A0 is singular in the formula provided 
        # for Z>0. However, the source says "at the focal plane... Z=0".
        # The source Eq 4: U_SLM = F^{-1}{U(X,Y;Z)/A0}.
        # If Z=0, we assume the network learns the field distribution that, 
        # when propagated, matches targets. 
        # The source implies the network outputs U at Z=0, then we inverse propagate.
        
        # Let's assume the network outputs U_z0.
        # To get phi_slm, we perform the inverse physics step.
        
        # Reconstruct SLM field from Focal Plane Field
        # U_slm = F_inv(U_z0)  (Assuming A0 normalization is handled or A0=1 at Z=0 limit for the mapping)
        # The source says: "U_SLM = F^{-1}{U(X,Y;Z)/A0}". 
        # For Z=0, we treat the propagation as identity or use the specific far-field inverse.
        # Given the "trainable Fourier transform layer" description, we assume the 
        # network output is processed by an inverse FFT.
        
        # Extract real and imaginary parts
        u_real = complex_field_z0[:, 0, :, :]
        u_imag = complex_field_z0[:, 1, :, :]
        u_z0 = torch.complex(u_real, u_imag)
        
        # Inverse Fourier Transform to get SLM field
        # torch.fft.ifft2 expects complex input
        u_slm = torch.fft.ifft2(u_z0)
        
        # Extract phase
        phi_slm = torch.angle(u_slm)
        
        return phi_slm

    complex_field_z0 = network(target_volume) # Shape (B, 2, m, m)
    
    # 2. Propagate to all target planes Z_k
    # The network only outputs Z=0. We must propagate to Z_0... Z_p-1 using the physics model.
    # This requires a differentiable propagation function.
    # U(X,Y;Z) = A0(Z) * FFT(U_SLM)
    # But we have U_Z0. We need to propagate U_Z0 to other Zs?
    # The source says: "trainable Fourier transform layer... maps the optical field from the hologram plane 
    # to target reconstruction planes".
    # This implies the network might output U_SLM directly? 
    # Contradiction check: Source says "network... mapping... to... complex optical field at the focal plane U(X,Y;Z=0)".
    # Then "back-propagated to the SLM plane".
    # If the network outputs U_Z0, how do we get U at other planes?
    # We must propagate U_Z0 to other Zs. This is a free-space propagation.
    # However, the source emphasizes the "trainable Fourier transform layer" mapping Hologram -> Targets.
    # It is more likely the network outputs U_SLM, or the "Focal Plane" is the input to the inverse transform

    # Let's stick to the text: "network... mapping... to... U(X,Y;Z=0)... back-propagated to SLM... phi_SLM".
    # And "Loss... applied to 3D intensity volumes".
    # This implies we need to simulate the forward propagation from SLM to all Z_k to compute loss.
    
    # Step A: Get U_SLM from Network Output (U_Z0)
    u_real = complex_field_z0[:, 0, :, :]
    u_imag = complex_field_z0[:, 1, :, :]
    u_z0 = torch.complex(u_real, u_imag)
    u_slm = torch.fft.ifft2(u_z0) # Approximation of inverse propagation
    
    # Step B: Propagate U_SLM to all target planes Z_k
    # This requires the physics model.
    # For far-field: U(Z) = A0(Z) * FFT(U_SLM)
    # We need the Z coordinates for each plane.
    z_coords = get_z_coordinates(p) # List of Z values
    
    reconstructed_intensities = []
    for z in z_coords:
        # Compute A0 for this Z
        # A0 = exp(ikZ) * exp(ik(X^2+Y^2)/2Z) / (i * lambda * Z)
        # This requires coordinate grids X, Y
        X, Y = get_coordinate_grids(m)
        k = 2 * torch.pi / 532e-9 # lambda = 532nm
        lam = 532e-9
        A0 = torch.exp(1j * k * z) * torch.exp(1j * k * (X**2 + Y**2) / (2 * z)) / (1j * lam * z)
        
        # FFT of SLM field
        U_slm_fft = torch.fft.fft2(u_slm)
        
        # Field at Z
        U_z = A0 * U_slm_fft
        
        # Intensity
        I_z = torch.abs(U_z)**2
        reconstructed_intensities.append(I_z)
        
    I_recon = torch.stack(reconstructed_intensities, dim=1) # Shape (B, p, m, m)
    
    # 3. Compute Loss
    # Cosine Similarity Loss
    # L = 1 - <I_tar, I_recon> / (|I_tar| |I_recon|)
    
    # Flatten spatial dimensions
    I_tar_flat = target_volume.view(target_volume.size(0), -1)
    I_recon_flat = I_recon.view(I_recon.size(0), -1)
    
    # Inner product
    dot_product = torch.sum(I_tar_flat * I_recon_flat, dim=1)
    
    # Modulus (L2 norm)
    norm_tar = torch.norm(I_tar_flat, dim=1)
    norm_recon = torch.norm(I_recon_flat, dim=1)
    
    # Cosine similarity
    cosine_sim = dot_product / (norm_tar * norm_recon + 1e-8)
    
    loss = 1 - cosine_sim.mean()
    
    # Regularization for background (outside target mask)
    # This requires a mask M. If not provided, we assume it's part of the target volume 
    # or a separate input. The source mentions "narrow mask defined around target points".
    # For simplicity, we assume I_tar has zeros in background, so the loss naturally penalizes 
    # non-zero I_recon in those areas due to the inner product structure if I_tar is sparse.
    # However, explicit regularization is mentioned.
    # L_reg = lambda * || I_recon * (1 - Mask) ||^2
    # We will skip the exact mask implementation as it depends on specific target geometry [G].
    
    loss.backward()
    optimizer.step()
    
    return loss.item()

### Edge Cases and Pitfalls
*   **Sparse vs. Dense:** The framework is optimized for sparse 3D structures (point clouds). Reconstruction of dense, continuous grayscale images may fail to preserve surface continuity and texture [S1].
*   **Noise Sensitivity:** The cosine similarity loss is scale-invariant and does not explicitly model noise. Performance may degrade in the presence of speckle or optical imperfections unless domain randomization with simulated speckle is incorporated [S1].
*   **Far-Field Assumption:** The Fourier transform layer relies on the far-field approximation ($Z \ge f$). If target planes are too close to the lens (near-field), the physics model becomes inaccurate [S1].

## Operating characteristics

### Time and Memory Complexity
*   **Time:** The method is significantly faster than iterative optimization. For a five-plane hologram, the proposed method takes **0.13s** compared to **1.38s** for Gerchberg-Saxton (GS) and **14.40s** for Iterative-SGD [S1].
*   **Memory:** The U-Net architecture with bottleneck reduces feature map channels, enhancing computational efficiency [S1]. Specific VRAM usage is not given [S1].

### Measured Performance
*   **Hardware:** Phase-only SLM (1920x1080 pixels, 8µm pixel size) at $\lambda=532$nm, NA=0.1, 10mm axial interval [S1].
*   **Metrics (5-plane holograms):**
    *   **Proposed Method:** PSNR 30.35 dB, SSIM 0.59, Time 0.13s [S1].
    *   **Gerchberg-Saxton (50 iters):** PSNR 33.57 dB, SSIM 0.85, Time 1.38s [S1].
    *   **Iterative-SGD:** PSNR 27.47 dB, SSIM 0.13, Time 14.40s [S1].
*   **Crosstalk:** Simulated and experimental results show bright, well-localized focal spots with minimal inter-plane leakage (axial crosstalk) [S1].

### Strengths and Limitations
*   **Strengths:** Orders-of-magnitude acceleration in computation compared to iterative methods; effective suppression of axial crosstalk for sparse targets; end-to-end differentiable physics integration [S1].
*   **Limitations:** Not suitable for dense, continuous grayscale images without loss function adaptation; sensitive to noise without explicit noise modeling in training [S1].
