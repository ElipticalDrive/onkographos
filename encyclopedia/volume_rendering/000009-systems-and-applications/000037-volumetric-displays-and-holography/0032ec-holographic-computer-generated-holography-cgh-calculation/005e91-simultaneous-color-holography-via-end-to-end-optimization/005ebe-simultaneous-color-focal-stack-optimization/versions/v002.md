# Simultaneous Color Focal Stack Optimization

Also called: Learned Wave Propagation SLM Optimization, Multi-plane Focal Stack Optimization

## Overview
Simultaneous Color Focal Stack Optimization is a method for generating computer-generated holograms that reconstruct a full-color image across multiple depth planes using a single spatial light modulator pattern illuminated simultaneously by red, green, and blue light sources [S1]. It extends [Simultaneous Color Holography via End-to-End Optimization](17688-simultaneous-color-holography-via-end-to-end-optimization.md) by jointly optimizing the SLM pattern for a stack of target intensities at different depths rather than a single plane [S1]. Unlike single-plane optimization, it iteratively propagates the optical field through a learned wave propagation model for each depth plane to compute gradients and update the pattern [S1].

## How it works
**Inputs:**
*   Learned wave propagation model $Holo(\cdot)$ for the unfiltered holography system [S1].
*   Initial SLM pattern $P_{SLM}$ [S1].
*   Target intensity images $I_{target}[d]$ for each depth plane $d$ in the focal stack [S1].

**Outputs:**
*   Optimized SLM pattern $P_{SLM}$ [S1].
*   Captured simultaneous color focal stack $FocalStack$ [S1].

**Data Structures:**
*   $P_{SLM}$: The phase or complex pattern on the SLM [S1].
*   $I_{target}[d]$: A 2D array representing the desired intensity at depth $d$ [S1].
*   $FocalStack$: A list of captured images, one for each depth plane [S1].

**Algorithm:**
1. Load the learned wave propagation model [S1].
2. Initialize $P_{SLM}$ and define $I_{target}$ for each depth plane in the focal stack [S1].
3. Iterate while $P_{SLM}$ has not converged [S1].
4. For each depth plane $d$ in the focal stack hologram:
    a. Clear previous gradients with respect to $P_{SLM}$ [S1].
    b. Generate the field from the current $P_{SLM}$ and propagate it to depth plane $d$ using the learned model:
        $$ Field_{out} = Holo(P_{SLM}, \text{depth}=d) $$
        [S1]
    c. Compute loss using a custom perceptual loss function:
        $$ Loss = LossFunc(Field_{out}, I_{target}[d]) $$
        [S1]
    d. Backpropagate the gradient of $Loss$ with respect to $P_{SLM}$ [S1].
    e. Update $P_{SLM}$ using the calculated gradients [S1].
5. After convergence, capture the simultaneous color focal stack by moving the camera to each plane and capturing the image [S1].

**Pseudocode:**
```python
def SimultaneousColorFocalStackOptimization(learned_model, initial_p_slm, target_intensities):
    """
    Optimizes an SLM pattern for a multi-plane focal stack using a learned wave propagation model.
    
    Args:
        learned_model: A callable Holo(P_SLM, depth) that propagates the field to a specific depth.
        initial_p_slm: The initial SLM pattern (tensor/array).
        target_intensities: A list or dictionary of target intensity images I_target[d] for each depth plane d.
        
    Returns:
        optimized_p_slm: The optimized SLM pattern.
        focal_stack: A list of captured images for each depth plane.
    """
    p_slm = initial_p_slm
    focal_stack = []
    
    # 1. Optimization Loop
    while not _check_convergence(p_slm):
        for d in target_intensities:
            # 2. Clear gradients
            _clear_gradients(p_slm)
            
            # 3. Forward propagation
            field_out = learned_model(p_slm, depth=d)
            
            # 4. Compute loss
            loss = _perceptual_loss(field_out, target_intensities[d])
            
            # 5. Backpropagation
            loss.backward()
            
            # 6. Update SLM pattern
            _update_parameters(p_slm)
            
    # 7. Capture (Experimental Step)
    for d in target_intensities:
        _move_camera_to_depth(d)
        hologram = _capture_image()
        focal_stack.append(hologram)
        
    return p_slm, focal_stack

    """Resets the gradient accumulator for the tensor."""
    tensor.grad = None

    return sum((abs(field_out) - target) ** 2) / len(field_out)
```

## Subtopics

### [Physics-Informed Deep Learning Framework for Multi-Plane CGH](18363-physics-informed-deep-learning-framework-for-multi-plane-cgh.md)
This method generates phase-only computer-generated holograms for multi-plane 3D targets by mapping spatial intensity distributions to depth-dependent reconstructions using a trainable Fourier transform layer. It explicitly addresses axial crosstalk by combining a physics-informed training strategy with a specialized network architecture that expands the receptive field. Unlike traditional iterative optimization methods, it achieves significant speedups while maintaining structural fidelity in sparse 3D volumes.

### Source Power Optimization
An active camera-in-the-loop iterative process to optimize the power of each color channel of the SLED source for color fidelity [S1]. It is chosen when precise color balance is required and the source power cannot be perfectly calibrated beforehand [S1]. It sets the source power to an arbitrary value less than 100% across all three color channels [S1]. A baseline reference image is captured, debayered, and mapped to SLM space [S1]. Three learnable weighting parameters (one per color channel) are initialized to unity and applied to the captured reference image as a proxy for source power [S1]. The process iteratively captures an image, debayers it, maps it to SLM space, calculates loss against the target, and backpropagates through the weighting parameters' computational graph [S1]. The initial source power is updated by multiplying it by the updated weighting parameters, and the loop restarts with a new image capture [S1]. It repeats until the color weighting parameters converge, typically taking between 15 and 30 iterations [S1]. If convergence fails or the product of initial source power and weighting function exceeds 100%, the exposure time is increased and the optimization restarted [S1].

### SLM Bit Depth Analysis
An analysis defining the effective bit depth as the number of bits contained in a $2\pi$ interval of the extended phase range [S1]. It determines the minimum quantization level required for adequate image quality [S1]. It simulates holograms by optimizing with gradient descent and then quantizing to the target bit depth [S1]. A significant drop-off in PSNR and SSIM is observed between 5 and 6 bits [S1]. The minimum effective bit depth required is 6 bits [S1]. For a 6-bit SLM simulation, PSNR is 31.00 and SSIM is 0.856; for an 8-bit SLM simulation, PSNR is 34.98 and SSIM is 0.943 [S1]. No image quality improvement is achieved for simultaneous color holograms once each color channel has a bit depth of at least 6 bits across a $2\pi$ phase range [S1].

## Background
The method was introduced by Markley et al. in "Simultaneous Color Computer Generated Holography" [S1]. It addresses the challenges of near-eye holographic displays and volumetric imaging by enabling simultaneous color reconstruction across multiple depth planes [S1]. The approach relies on a learned wave propagation model for the unfiltered holography system, which accounts for system-specific aberrations and filtering effects [S1]. The research highlights the importance of source power optimization and SLM bit depth analysis for achieving high-fidelity color holograms [S1].
