# Complex Magnitude Extraction & Histogram Enhancement

Also called: Histogram Enhancement of Complex Magnitude

## Overview
This method post-processes the complex wavefield reconstructed by [Digital Hologram Numerical Reconstruction](13998-digital-hologram-numerical-reconstruction.md) to improve visual contrast and dynamic range. It extracts the intensity magnitude from the complex field and applies linear histogram stretching, optionally preceded by clipping extreme values. It differs from adaptive methods like CLAHE by applying global linear scaling rather than local region-based equalization.

## How it works
**Inputs:**
*   Reconstructed complex wavefield $U_z(x,y)$ from the parent method.
*   Clipping percentile $p$ (user-defined, typically between 1 and 99).

**Outputs:**
*   Enhanced intensity image $I_{enhanced}(x,y)$.

**Data Structures:**
*   $U_z$: 2D array of complex numbers (real and imaginary parts).
*   $M$: 2D array of floating-point values representing magnitude.
*   $I_{raw}$: 2D array of floating-point values representing intensity.
*   $I_{clip}$: 2D array of floating-point values representing clipped intensity.
*   $I_{enhanced}$: 2D array of floating-point values representing final enhanced intensity.

**Steps:**

1.  **Magnitude Extraction:** Compute the magnitude of the complex wavefield.
    $$ M(x,y) = |U_z(x,y)| = \sqrt{\text{Re}(U_z(x,y))^2 + \text{Im}(U_z(x,y))^2} $$
    [G] Note: Some implementations may skip the square root and use intensity $I = |U_z|^2$ directly for histogram calculation, but magnitude is the standard physical quantity for amplitude visualization.

2.  **Intensity Calculation:** Compute the intensity image.
    $$ I_{raw}(x,y) = M(x,y)^2 $$
    [G] If step 1 used magnitude, square it. If step 1 used intensity directly, $I_{raw} = M$.

3.  **Clipping:** Determine clipping thresholds based on the percentile $p$.
    *   Find the lower threshold $T_{low}$ such that $p/2$ percent of pixels have intensity $\le T_{low}$.
    *   Find the upper threshold $T_{high}$ such that $100 - p/2$ percent of pixels have intensity $\le T_{high}$.
    *   Clip the intensity image:
        $$ I_{clip}(x,y) = \begin{cases} T_{low} & \text{if } I_{raw}(x,y) < T_{low} \\ I_{raw}(x,y) & \text{if } T_{low} \le I_{raw}(x,y) \le T_{high} \\ T_{high} & \text{if } I_{raw}(x,y) > T_{high} \end{cases} $$

4.  **Linear Histogram Stretching:** Map the clipped intensity range $[T_{low}, T_{high}]$ to the full display range $[0, 1]$ (or $[0, 255]$ for 8-bit).
    $$ I_{enhanced}(x,y) = \frac{I_{clip}(x,y) - T_{low}}{T_{high} - T_{low}} $$
    [G] If $T_{high} = T_{low}$, set $I_{enhanced}(x,y) = 0.5$ or handle as a special case to avoid division by zero.

5.  **Normalization:** Scale the result to the desired output bit depth (e.g., multiply by 255 and cast to uint8 for PNG).

**Pseudocode:**

```python
import numpy as np

def complex_magnitude_extraction_and_histogram_enhancement(U_z, percentile=1.0):
    """
    Extracts complex magnitude and applies histogram enhancement.
    
    Args:
        U_z: 2D numpy array of complex numbers (reconstructed wavefield).
        percentile: Float, percentage of extreme values to clip (e.g., 1.0 for 1%).
        
    Returns:
        I_enhanced: 2D numpy array of uint8 values (0-255).
    """
    # Step 1 & 2: Magnitude and Intensity
    # Using intensity directly as it is monotonic with magnitude and standard for holography
    I_raw = np.abs(U_z) ** 2
    
    # Step 3: Clipping
    # Calculate thresholds based on the specified percentile
    # percentile is the total percentage to clip from both ends
    lower_percentile = percentile / 2.0
    upper_percentile = 100.0 - (percentile / 2.0)
    
    T_low = np.percentile(I_raw, lower_percentile)
    T_high = np.percentile(I_raw, upper_percentile)
    
    # Clip the intensity values
    I_clip = np.clip(I_raw, T_low, T_high)
    
    # Step 4: Linear Histogram Stretching
    # Avoid division by zero if all values are identical or range is zero
    range_val = T_high - T_low
    if range_val == 0:
        I_enhanced_float = np.zeros_like(I_raw)
    else:
        I_enhanced_float = (I_clip - T_low) / range_val
        
    # Step 5: Normalization to 8-bit
    I_enhanced = (I_enhanced_float * 255).astype(np.uint8)
    
    return I_enhanced
```

**Parameters:**
*   `percentile`: Threshold percentage for clipping extreme intensity values before histogram stretching. Typical values are 1-5% to remove noise spikes and saturation outliers.

**Edge Cases and Pitfalls:**
*   **Division by Zero:** If $T_{high} = T_{low}$ (e.g., uniform image), the stretching formula fails. Handle by setting output to a constant (e.g., 128) or checking range.
*   **Dynamic Range Compression:** Clipping removes extreme values, which may discard valid high-intensity details if the percentile is too high.
*   **Noise Amplification:** In low-signal regions, histogram stretching can amplify noise. Pre-filtering may be required.

## Subtopics

### CLAHE
Contrast-Limited Adaptive Histogram Equalization (CLAHE) is a variant applied to holograms to solve domain shift contrast problems. Unlike global histogram stretching, CLAHE divides the hologram into non-overlapping regions and applies conventional contrast enhancement to small regions [S2]. It is used in pipelines involving Tensor Holography to enhance the contrast of reproduced images [S2]. The operation is defined as $E u = P(E h)$, where $h$ is the hologram, $P$ is the propagation operator, $u$ is the complex amplitude of the reproduced image, and $E$ is the contrast enhancement operator [S2]. This method enhances local contrast but may introduce blockiness if tile size is not chosen carefully.

## Operating characteristics
*   **Time Complexity:** $O(N^2)$ for magnitude extraction and intensity calculation. Histogram calculation and clipping are $O(N^2)$ due to sorting or histogram binning. Linear stretching is $O(N^2)$. Overall complexity is linear with respect to the number of pixels.
*   **Memory Complexity:** $O(N^2)$ to store the intermediate intensity and clipped images.
*   **Strengths:** Simple to implement; computationally efficient; effective for removing global dynamic range issues; removes extreme outliers (noise/saturation).
*   **Limitations:** Global method may not enhance local details as effectively as adaptive methods (e.g., CLAHE); sensitive to the choice of percentile; may amplify noise in low-intensity regions.
*   **When to use:** When the reconstructed hologram has a narrow dynamic range or is dominated by extreme outliers; when computational resources are limited.
*   **When not to use:** When local contrast enhancement is required; when the hologram has significant local variations in intensity that global stretching cannot address.

## Background
This method is part of the post-processing pipeline for Digital Hologram Numerical Reconstruction. It is commonly used in computer-generated holography (CGH) and holographic display systems to prepare reconstructed images for visualization. The technique of linear histogram stretching with percentile clipping is a standard image processing technique applied to holographic reconstructions to improve visual quality [S1]. CLAHE is a classical contrast enhancement algorithm applied to holograms predicted from Tensor Holography to enhance the contrast of reproduced images [S2].
