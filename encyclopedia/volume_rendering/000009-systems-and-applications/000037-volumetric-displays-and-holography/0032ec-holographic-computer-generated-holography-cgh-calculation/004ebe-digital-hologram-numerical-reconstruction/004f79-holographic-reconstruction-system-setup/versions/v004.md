# Holographic Reconstruction System Setup

Also called: Experimental setup for holographic reconstruction, Optical setup for holographic reconstruction, Phase-Only Holographic Display

## Overview
This article describes the physical optical apparatus required to reconstruct a complex wavefield computed numerically (see [Digital Hologram Numerical Reconstruction](13798-digital-hologram-numerical-reconstruction.md)) into a visible image [S1, S2]. It converts digital hologram matrices into optical fields using spatial light modulators (SLMs), handling phase-only or amplitude-only modulation constraints, and filtering diffraction artifacts [S1, S2]. It differs from pure numerical reconstruction by introducing physical components (lasers, lenses, SLMs, cameras) and their empirical calibration [S1, S2].

## How it works
The system converts a digital hologram into a physical wavefront using coherent illumination, spatial light modulation, and optical filtering [S1, S2].

**Inputs and Outputs:**
*   **Input:** Digital hologram matrix (complex or real-valued), system parameters (wavelength, pixel pitch, distance) [S1, S2].
*   **Output:** Reconstructed wavefront captured by a camera or viewed by an eye [S1, S2].

**Data Structures:**
*   **Hologram Matrix:** 2D array of complex numbers $U_h(x,y)$ or real-valued intensity/phase maps [S1, S2].
*   **SLM Pixel Map:** 2D array of values mapped to SLM physical pixels [S1, S2].

**Steps:**

1.  **Illumination Preparation:**
    *   Filter the illumination laser beam by a pinhole and collimate it by a lens [S1].
    *   To remove speckles caused by laser coherence, rotate a holographic diffuser at the focused spot of the laser beams [S2].

2.  **Hologram Encoding (if Phase-Only SLM):**
    *   If the SLM is phase-only but the hologram is complex-valued, use the Burch encoding method to project the complex wave field onto real values [S2].
    *   For off-axis holograms, set the grating period to 0.25 of its maximum period to avoid unwanted noise [S2].

3.  **SLM Modulation:**
    *   Upload the encoded hologram to the SLM [S1].
    *   If using an LCoS SLM with small pixel pitch, put the same pixel value in 2x2 nearest pixels to minimize pixel crosstalk [S2].
    *   Calibrate the amplitude by measuring output values for each input pixel value, as modulated intensity nonlinearly depends on assigned pixel values [S2].

4.  **Optical Propagation and Filtering:**
    *   Illuminate the SLM with the collimated laser beam [S1].
    *   Form the Fourier plane using a first lens group [S2].
    *   Block zeroth order and higher order diffractions using an adjustable 2D slit [S2].

5.  **Reconstruction and Capture:**
    *   The reconstructed wavefront modulated by the CGH on the SLM is captured by a digital camera [S1].
    *   The camera is placed at shooting distances of 155, 160, 165, and 170 mm [S1].
    *   Alternatively, view directly with the human eye or a near-eye display system [G].

**Parameters:**
*   **Wavelength ($\lambda$):** Must match the recording or intended reconstruction wavelength. Common values: 638, 515, and 460 nm sequentially illuminated on the LCoS [S2]. Single wavelength example: 532 nm [S1].
*   **Pixel Pitch ($\Delta x$):** Determines spatial frequency sampling. Example: 3.6 $\mu$m for IRIS-U62 LCoS, effectively 7.2 $\mu$m when upsampled [S2]. Example: 3.74 $\mu$m [S1].
*   **Reconstruction Distance ($z$):** Axial distance from SLM to camera/eye. Examples: 155, 160, 165, 170 mm [S1]. Minimum required: > 1.7 mm to avoid excessive defocus blur from pixel pitch diffraction [S2].
*   **Grating Period:** For off-axis holograms, set to 0.25 of maximum period [S2].

**Edge Cases and Pitfalls:**
*   **Pixel Crosstalk:** Small pixel pitch on LCoS SLMs causes crosstalk. Mitigation: upsample by 2x2 [S2].
*   **Diffraction Orders:** Zeroth and higher orders create noise. Mitigation: use a 2D slit at the Fourier plane [S2].
*   **Speckle:** Caused by laser coherence. Mitigation: rotate holographic diffuser [S2].
*   **Defocus Blur:** Pixel pitch diffraction causes blur. At 2 mm propagation, dispersion diameters are 25 pixels (red), 20 (green), 18 (blue) [S2]. If max defocus blur diameter is 15 pixels, propagation must be > 1.7 mm [S2].
*   **Nonlinear Response:** SLM intensity response is nonlinear. Calibration is required [S2].

    """

    # 1. Illumination Preparation

        "method": "burch_encoding",
        "grating_period_ratio": 0.25,
        "hologram_type": "off-axis"
    }

    # 3. SLM Modulation
    # Put same pixel value in 2x2 nearest pixels to minimize crosstalk [S2]
    # Calibrate amplitude: measure output intensity for each input pixel value [S2]
    slm_config = {
        "upsample_factor": 2,
        "amplitude_calibration": "measure_output_for_each_input_pixel"
    }

    # 4. Optical Propagation and Filtering
    # Form Fourier plane using first lens group [S2]
    # Block zeroth order and higher order diffractions using adjustable 2D slit [S2]
    filtering = {
        "fourier_plane_lens": True,
        "slit_filter": "adjustable_2d_slit"
    }

    # 5. Capture Setup
    # Capture reconstructed wavefront with digital camera at shooting distance [S1]
    capture = {
        "camera_type": "digital_camera",
        "shooting_distances": [155, 160, 165, 170] # mm [S1]

        "capture": capture

## Subtopics

### [Calibration via Coefficient Adjustment](14598-calibration-via-coefficient-adjustment.md)
A user-driven calibration method for correcting aberrations in holographic near-eye displays. The display presents a single object point $o_i$ to the user, represented in the hologram as $f_z(\rho, \theta)_{o_i}$. The user adjusts the coefficients $a_{jo}$ of $f_z(\rho, \theta)_{o_i}$ until the most tightly focused spot is seen. This is repeated for additional object points. For true 3D holograms, calibration is performed for a small number of focal positions (e.g., four) and coefficients are interpolated over the complete focal range. For highly aberrated systems, 15 measured points are sufficient; for displays without significant aberrations, a single object point at the center is sufficient. It is impractical to measure for all millions of object points, so interpolation is used.

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** In one experiment, shooting distances of 155, 160, 165, and 170 mm were used to achieve 3D effects [S1].
*   **Scaling:** Propagation distance must be adjusted to avoid defocus blur from pixel pitch diffraction. Minimum distance > 1.7 mm for 2 mm depth range [S2].
*   **Strengths:** Allows physical reconstruction of complex wavefields; calibration can correct for system-specific aberrations.
*   **Limitations:** Requires precise optical alignment; sensitive to laser coherence (speckle); nonlinear SLM response requires calibration; diffraction orders must be filtered.
*   **When to Use:** When physical holographic reconstruction is needed for volumetric displays or near-eye displays.
*   **When Not to Use:** When purely numerical simulation is sufficient.

## Background
Holographic reconstruction systems have been developed for various applications, including 2D-to-3D rendering and near-eye displays for VR/AR [S1]. Early systems used phase-only SLMs with Gaea-2 systems [S1]. More recent developments include diffraction-engineered holography using LCoS SLMs to overcome depth representation limits [S2]. Calibration techniques using user feedback have been proposed for correcting aberrations in holographic near-eye displays [S1].
