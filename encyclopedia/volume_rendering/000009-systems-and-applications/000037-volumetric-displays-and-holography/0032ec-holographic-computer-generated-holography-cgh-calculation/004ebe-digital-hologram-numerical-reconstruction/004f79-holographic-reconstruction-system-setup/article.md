# Holographic Reconstruction System Setup

Also called: Phase-Only Holographic Display

## Overview
This method defines the physical hardware configuration and calibration procedures required to reconstruct a computer-generated hologram (CGH) into a visible 3D image. It bridges the gap between the digital hologram matrix produced by [Digital Hologram Numerical Reconstruction](13798-digital-hologram-numerical-reconstruction.md) and the optical output observed by a user or sensor. It is distinguished from pure numerical methods by its reliance on physical optical components (SLM, lenses, cameras) and empirical calibration of system aberrations rather than purely mathematical propagation models.

## How it works
The setup involves configuring the optical path for illumination, capturing the reconstructed wavefront, and calibrating the system to correct for optical aberrations.

### Inputs and Outputs
*   **Inputs**:
    *   CGH matrix $H(x,y)$ generated by the parent method.
    *   Optical parameters: Wavelength $\lambda$, pixel pitch $\Delta x$, SLM resolution.
    *   Calibration coefficients $a_{jo}$ for aberration correction.
*   **Outputs**:
    *   Captured intensity distribution $|U(x,y)|$ on the sensor.
    *   Corrected hologram data ready for display.

### Data Structures
*   **Configuration File**: Stores $\lambda$, $\Delta x$, and reconstruction distance $z$ to avoid re-declaration [S1].
*   **Calibration Map**: A sparse set of coefficients $a_{jo}$ associated with specific object points $o_i$ and focal positions [S2].

### Steps

1.  **Illumination Preparation**: Filter the illumination laser beam using a pinhole to remove spatial noise, then collimate it using a lens to ensure a plane wavefront illuminates the Spatial Light Modulator (SLM) [S1].
2.  **Hologram Upload**: Upload the calculated CGH matrix $H(x,y)$ to the phase-only SLM [S1].
3.  **Wavefront Capture**: Position a digital camera at a specific shooting distance $z$ from the SLM. Capture the wavefront modulated by the CGH [S1].
4.  **Aberration Calibration (Coefficient Adjustment)**:
    *   Present a single object point $o_i$ to the user, represented in the hologram as $f_z(\rho, \theta)_{o_i}$ [S2].
    *   The user adjusts the coefficients $a_{jo}$ of $f_z(\rho, \theta)_{o_i}$ until the most tightly focused spot is observed [S2].
    *   Repeat for a sparse set of object points $o_i$ [S2].
    *   For true 3D holograms, perform calibration for a small number of focal positions (e.g., four) and interpolate coefficients over the complete focal range [S2].
    *   Interpolate coefficients for remaining points, as aberrations vary smoothly [S2].

### Parameters
*   **Wavelength ($\lambda$)**: 532 nm [S1].
*   **Pixel Pitch ($\Delta x$)**: 3.74 µm [S1].
*   **SLM Resolution**: 2000 × 2000 pixels [S1].
*   **Shooting Distances ($z$)**: 155, 160, 165, and 170 mm [S1].
*   **Calibration Points**:
    *   Highly aberrated systems: 15 measured points [S2].
    *   Non-aberrated systems: 1 object point at the center [S2].

### Edge Cases and Pitfalls
*   **Focus Shift**: As shooting distance $z$ varies, the focus position of the reconstruction changes. At 155 mm, the nearest part of the reconstruction is clear while distant parts are blurred [S1].
*   **Calibration Complexity**: It is impractical to measure $f_z(\rho, \theta)_{o_i}$ for all object points (millions expected) [S2]. Interpolation is required [S2].

## Subtopics

### Calibration via Coefficient Adjustment
A method where optical aberrations are corrected by empirically adjusting coefficients $a_{jo}$ of the hologram function $f_z(\rho, \theta)$ for sparse object points. It relies on user feedback to achieve the tightest focus. It is chosen when the display optics introduce significant, non-linear aberrations that cannot be modeled analytically. It is efficient because aberrations vary smoothly, allowing interpolation from a small set of measured points (e.g., 15 points for highly aberrated systems) rather than measuring all millions of object points [S2].

## Operating characteristics
*   **Time Complexity**: Calibration is interactive and slow, requiring user adjustment for each selected point. Hologram calculation for 2 million points on a high-end GPU takes 1–10 seconds [S2].
*   **Memory Complexity**: Requires storage for the CGH matrix (2000×2000 complex/phase values) and the sparse calibration coefficient map [S1, S2].
*   **Strengths**: Corrects for real-world optical imperfections (aberrations) that numerical models ignore. Simple 2D-to-3D rendering effect achieved by varying shooting distance [S1].
*   **Limitations**: Requires precise mechanical alignment. Calibration is tedious and requires a user. Not suitable for real-time dynamic scenes without pre-computed holograms [S2].

## Background
Originated in practical applications of holographic 3D displays using phase-only SLMs. The specific setup described (Gaea-2 VIS system, Holoeye SLM) was detailed in 2021 for 2D-to-3D rendering using depth maps [S1]. The calibration technique via coefficient adjustment was developed for near-eye holographic displays in VR/AR contexts, addressing the aggregate effect of display and eye optics through user feedback [S2].
