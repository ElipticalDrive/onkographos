# Layer-Based Holographic Algorithm

Also called: Layer-Based Hologram Calculation, Layer-based CGH Calculation

## Overview
The Layer-Based Holographic Algorithm calculates Computer-Generated Holograms (CGHs) by slicing a 3D scene into discrete parallel depth layers and numerically propagating their wavefields to the hologram plane [S1, S2]. It distinguishes itself from point-cloud or volume-rendering methods by leveraging 2D Fourier transforms to efficiently compute the superposition of these layers, enabling real-time binocular color holography [S1, S2]. Unlike continuous depth methods, it introduces visible separation artifacts at layer boundaries when applied to scenes with continuous depth ranges [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D model represented as an 8-bit Computer Generated Depth Map (CGDM), where depth values range from 0 to 255 [S2]. The model is sliced into $L=256$ parallel layers [S2].
*   **Output:** A complex amplitude distribution $E_{com}(x,y)$ on the holographic plane, which is subsequently quantized to a phase-only distribution $E_p(x,y)$ for display on a Spatial Light Modulator (SLM) [S2].

**Data Structures:**
*   **Layer Amplitude Map $U_l(x,y)$:** A 2D array representing the amplitude of the $l$-th depth layer.
*   **Random Phase Map $r(x,y)$:** A 2D array of random phase values superposed on each layer to simulate the diffusive effect of the object surface [S2].
*   **Layer Distance $z_l$:** The scalar distance between the $l$-th layer and the holographic plane [S2].

**Parameters:**
*   $L = 256$: Number of layers, derived from the 8-bit CGDM [S2].
*   $\lambda$: Wavelength of the reconstruction light [S2].
*   $u, v$: Spatial frequencies defined as $u = \frac{\cos \alpha}{\lambda}$ and $v = \frac{\cos \beta}{\lambda}$, where $\alpha$ and $\beta$ are the angles between the incident wave and the x- and y-directions, respectively [S2].
*   $FT$: Fourier Transform operator [S2].
*   $FT^{-1}$: Inverse Fourier Transform operator [S2].

**Algorithm Steps:**
1.  **Slicing:** Divide the 3D model into 256 parallel layers based on the 8-bit CGDM [S2].
2.  **Phase Superposition:** For each layer $l$, superpose a random phase $r(x,y)$ onto the layer's amplitude $U_l(x,y)$ to simulate surface diffusion [S2].
3.  **Propagation Calculation:** Compute the complex amplitude distribution $E_{com}(x,y)$ on the holographic plane by summing the contributions of all layers. The contribution of each layer is calculated by transforming the modulated layer amplitude to the frequency domain, applying a phase shift term representing propagation, and transforming back [S2]:

    $$ E_{com}(x,y) = \sum_{l=0}^{255} FT^{-1} \left\{ FT \left\{ U_l(x,y) \exp[i r(x,y)] \right\} \exp \left[ i \frac{2\pi}{z_l} \left( 1 - \lambda u - \frac{\lambda v}{\lambda} \right) \right] \right\} $$

    *Note: The source formula contains the term $\frac{\lambda v}{\lambda}$ which simplifies to $v$. The term $\left( 1 - \lambda u - \frac{\lambda v}{\lambda} \right)$ appears in the source [S2].*

4.  **Phase Extraction:** Extract the phase-only distribution $E_p(x,y)$ from the complex amplitude $E_{com}(x,y)$ for use with a phase-only SLM [S2].

**Pseudocode:**

```python
def layer_based_hologram(layers, z_l, lambda_wavelength, alpha, beta):
    """
    Calculate hologram using layer-based algorithm.
    
    Args:
        layers: List of 2D arrays U_l(x,y) for l in 0..255.
        z_l: List of distances z_l for each layer.
        lambda_wavelength: Scalar wavelength lambda.
        alpha: Angle between incident wave and x-direction.
        beta: Angle between incident wave and y-direction.
        
    Returns:
        E_p: Phase-only hologram distribution.
    """
    # Constants
    L = 256
    u = cos(alpha) / lambda_wavelength
    v = cos(beta) / lambda_wavelength
    
    # Initialize complex amplitude sum
    E_com = zeros_like(layers[0], dtype=complex)
    
    for l in range(L):
        U_l = layers[l]
        z = z_l[l]
        
        # Generate random phase map r(x,y) for this layer
        # [G] In practice, r(x,y) is typically generated per layer or globally.
        # The source implies superposition on each layer.
        r = random_phase_map(shape=U_l.shape)
        
        # Modulate amplitude with random phase
        modulated_layer = U_l * exp(1j * r)
        
        # Forward Fourier Transform
        freq_domain = FT(modulated_layer)
        
        # Propagation phase shift
        # Source formula: exp[i * (2*pi/z_l) * (1 - lambda*u - lambda*v/lambda)]
        # Note: lambda*v/lambda simplifies to v.
        phase_shift = exp(1j * (2 * pi / z) * (1 - lambda_wavelength * u - v))
        
        # Apply phase shift
        propagated_freq = freq_domain * phase_shift
        
        # Inverse Fourier Transform
        propagated_space = FT_inverse(propagated_freq)
        
        # Sum contributions
        E_com += propagated_space
        
    # Extract phase-only distribution
    E_p = angle(E_com)
    
    return E_p
```

**Edge Cases and Pitfalls:**
*   **Continuous Depth Artifacts:** When applied to VR scenes with continuous depth ranges, the discrete layering creates visible separation artifacts at layer boundaries [S1]. This makes the method suitable for AR content with isolated 3D models but not ideal for continuous VR scenes [S1].
*   **Optical Misalignment:** Experimental prototypes may suffer from reduced imaging quality due to optical component misalignment, geometric aberrations, and chromatic aberrations [S1].

## Subtopics

### [Layer-based diffraction](14010-layer-based-diffraction.md)
Computes left and right holograms by propagating light waves from compensated depth layers to the hologram plane using 2D IFFTs. Distinguished by its specific reliance on 2D IFFTs for high-resolution binocular color holography on hardware accelerators.

## Operating characteristics
*   **Performance:** Capable of computing binocular color holograms at over 35 frames per second on an NVIDIA Jetson AGX Orin embedded platform for a resolution of $2048 \times 1024$ [S1].
*   **Strengths:** Enables real-time, standalone holographic near-eye displays with full-color reconstruction and accurate focus cues [S1]. Reduces speckle noise when combined with SLED illumination [S1].
*   **Limitations:** Not suitable for scenes with continuous depth extents due to layer boundary artifacts [S1]. Limited field-of-view remains a challenge for holographic near-eye displays [S1]. Imaging quality may be lower than consumer stereoscopic displays due to optical imperfections [S1].

## Background
The method is described as a real-time hologram calculation technique for binocular color holograms [S1]. It employs an 8-bit CGDM to slice 3D models into 256 parallel layers [S2]. The approach is utilized in holographic near-eye displays and 3D display systems using depth maps generated by 2D-to-3D rendering [S1, S2].
