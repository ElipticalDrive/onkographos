# Layer-Based Holographic Algorithm

Also called: Layer-Based Hologram Calculation, Layer-based CGH Calculation

## Overview
The Layer-Based Holographic Algorithm calculates Computer-Generated Holograms (CGHs) by decomposing a 3D scene into discrete parallel depth layers and computing the hologram plane wavefield as the superposition of contributions from each layer [S1, S2]. It differs from point-based methods by processing spatially coherent planar slices rather than individual voxels, and from full volume rendering approaches by restricting propagation to a fixed set of discrete depths [S1, S2]. This method is particularly suited for real-time embedded systems and AR applications with isolated models, though it introduces visible separation artifacts in scenes with continuous depth ranges [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D model represented as an 8-bit Computer Generated Depth Map (CGDM), defining $L=256$ discrete depth layers [S2]. For each layer $l$, the input is the amplitude distribution $U_l(x,y)$ [S2]. In the diffraction variant, inputs include compensated layer depths $\hat{z}_i$ and color wavelengths $\lambda_c$ [S1].
*   **Output:** The complex amplitude distribution $E_{com}(x,y)$ on the hologram plane [S2], or an amplitude-only hologram $H(x,y;c)$ for each color channel $c$ [S1].

**Data Structures:**
*   **Layer Stack:** A list of $L$ layers. Each layer $l$ contains:
    *   $U_l(x,y)$: 2D amplitude array of size $W \times H$ (hologram resolution) [S2].
    *   $z_l$: Scalar depth distance from the layer to the hologram plane [S2].
    *   $\hat{z}_i$: Compensated depth distance (used in diffraction variant) [S1].
*   **Parameters:**
    *   $\lambda$: Wavelength of reconstruction light [S2].
    *   $\lambda_c$: Wavelength for color channel $c$ [S1].
    *   $L$: Number of layers (typically 256 for 8-bit depth) [S1, S2].
    *   $r(x,y)$: Random phase map for surface diffusion simulation [S2].
    *   $\alpha, \beta$: Angles between the incident wave and x/y directions [S2].

**Steps:**

1.  **Layer Slicing:** Slice the 3D model into $L$ parallel layers based on the 8-bit CGDM [S2]. Assign amplitude $U_l(x,y)$ to each layer [S2].
2.  **Phase Modulation (Optional):** Superpose a random phase $r(x,y)$ onto each layer $U_l(x,y)$ to simulate the diffusive effect of the object surface [S2].
    $$ U'_l(x,y) = U_l(x,y) \exp(i r(x,y)) $$
3.  **Propagation Calculation:** Compute the contribution of each layer to the hologram plane. Two variants exist:

    *   **Fourier-Based Variant [S2]:**
        Calculate spatial frequencies $u$ and $v$:
        $$ u = \frac{\cos \alpha}{\lambda}, \quad v = \frac{\cos \beta}{\lambda} $$
        Compute the complex amplitude $E_{com}(x,y)$ by summing the inverse Fourier transforms of the phase-shifted layer spectra:
        $$ E_{com}(x,y) = \sum_{l=0}^{255} \mathcal{F}^{-1} \left\{ \mathcal{F} \{ U_l(x,y) \exp[i r(x,y)] \} \exp \left[ i \frac{2\pi}{z_l} \left( 1 - \lambda u - \lambda v \right) \right] \right\} $$
        Where $\mathcal{F}$ is the Fourier transform and $\mathcal{F}^{-1}$ is the inverse Fourier transform [S2].

    *   **Diffraction-Based Variant [S1]:**
        Numerically propagate light waves from compensated depth layers $\hat{z}_i$ towards the hologram plane. For each color channel $c$, compute the object wave $O(x,y;c)$:
        $$ O(x,y;c) = \sum_{i=0}^{N_z-1} P_{\hat{z}_i} \{ U_i \} (x,y;c) $$
        The propagation operator $P_{\hat{z}_i}$ is defined as:
        $$ P_{\hat{z}_i} \{ U_i \} = \frac{\exp(j \lambda_c \hat{z}_i)}{j \lambda_c \hat{z}_i} \mathcal{F} \left\{ U_i(\xi,\eta;c) \exp \left( j \frac{\pi (\xi^2+\eta^2)}{\lambda_c \hat{z}_i} \right) \exp \left( -j \frac{\pi (x^2+y^2)}{\lambda_c \hat{z}_i} \right) \right\} $$
        Where $\mathcal{F}$ is the forward Fourier transform, and $\xi, \eta$ are spatial coordinates in the layer plane [S1].

4.  **Hologram Extraction:**
    *   For phase-only SLMs, extract the phase-only distribution $E_p(x,y)$ from $E_{com}(x,y)$ [S2].
    *   For amplitude-only LCoS displays, obtain the hologram $H(x,y;c)$ by shifting, scaling, and quantizing the real part of $O(x,y;c)$ onto $L=256$ discrete levels [S1]:
        $$ H(x,y;c) = Q(\Re \{ O(x,y;c) \}, L, \Delta) $$
        Where $Q$ is the quantization function and $\Re$ denotes the real part [S1].

**Pseudocode:**
```python
def layer_based_cgh(layers, wavelength, hologram_width, hologram_height):
    """
    Calculate hologram using the Fourier-based layer-based algorithm.
    
    Args:
        layers: List of tuples (U_l, z_l, r_xy)
                U_l: 2D array (WxH) amplitude of layer l
                z_l: float, distance from layer l to hologram plane
                r_xy: 2D array (WxH) random phase map
        wavelength: float, lambda
        hologram_width: int, W
        hologram_height: int, H
        
    Returns:
        hologram: 2D array (WxH), complex amplitude E_com
    """
    # Initialize complex amplitude accumulator
    E_com = np.zeros((hologram_height, hologram_width), dtype=complex)
    
    # Precompute spatial frequencies (assuming normal incidence alpha=beta=0 for simplicity, 
    # or passed as params)
    # u = cos(alpha) / wavelength
    # v = cos(beta) / wavelength
    # Note: Exact alpha/beta values depend on setup. Assuming 0 for standard setup if not provided.
    u = 1.0 / wavelength 
    v = 1.0 / wavelength
    
    for l in range(len(layers)):
        U_l, z_l, r_xy = layers[l]
        
        # Step 2: Apply random phase for diffusion
        U_modulated = U_l * np.exp(1j * r_xy)
        
        # Step 3a: Fourier Transform of the modulated layer
        # FT is computed over the layer dimensions
        U_ft = np.fft.fft2(U_modulated)
        
        # Step 3b: Phase shift in frequency domain
        # Exponent term: i * (2*pi / z_l) * (1 - lambda*u - lambda*v)
        phase_shift = 1j * (2 * np.pi / z_l) * (1 - wavelength * u - wavelength * v)
        shift_factor = np.exp(phase_shift)
        
        # Apply shift (scalar multiplication in this specific formulation [S2])
        # Note: The source [S2] formula implies a scalar phase shift dependent on z_l, 
        # not a spatial frequency shift, based on the term structure.
        U_shifted = U_ft * shift_factor
        
        # Step 3c: Inverse Fourier Transform
        layer_contribution = np.fft.ifft2(U_shifted)
        
        # Accumulate
        E_com += layer_contribution
        
    return E_com

def diffraction_variant(layers, color_wavelengths, compensated_depths, hologram_width, hologram_height):
    """
    Calculate hologram using the diffraction-based layer-based algorithm.
    
    Args:
        layers: List of 2D arrays U_i(xi, eta)
        color_wavelengths: Dict or list of lambda_c for each color channel
        compensated_depths: List of float z_hat_i
        hologram_width: int
        hologram_height: int
        
    Returns:
        holograms: Dict of 2D arrays H(x,y) for each color channel
    """
    holograms = {}
    
    for c, lambda_c in color_wavelengths.items():
        O_total = np.zeros((hologram_height, hologram_width), dtype=complex)
        
        for i, z_hat_i in enumerate(compensated_depths):
            U_i = layers[i]
            
            # Propagation operator P_z_hat_i
            # Prefactor
            prefactor = np.exp(1j * lambda_c * z_hat_i) / (1j * lambda_c * z_hat_i)
            
            # Quadratic phase term for input plane (xi, eta)
            # Create meshgrid for xi, eta
            xi, eta = np.meshgrid(np.arange(hologram_width), np.arange(hologram_height))
            input_phase = np.exp(1j * np.pi * (xi**2 + eta**2) / (lambda_c * z_hat_i))
            
            # Quadratic phase term for output plane (x, y) - applied after FT in some formulations, 
            # but source [S1] Eq 9 shows it inside the FT argument or as a multiplier.
            # Eq 9: F { U * exp(j*pi*(xi^2+eta^2)/...) * exp(-j*pi*(x^2+y^2)/...) }
            # This implies the output phase is part of the kernel or applied post-FT.
            # Standard angular spectrum/Fresnel often separates these. 
            # Following [S1] strictly: The term exp(-j*pi*(x^2+y^2)/...) is inside the F operator?
            # Actually, Eq 9 structure: F { A * B * C }. If C depends on x,y, it's outside F.
            # However, standard FFT implementation requires the quadratic phase to be in the spatial domain 
            # before FT or applied after. 
            # Let's assume standard Fresnel propagation structure implied by the formula components:
            # 1. Multiply U_i by input quadratic phase.
            # 2. FFT.
            # 3. Multiply by output quadratic phase.
            # 4. Multiply by prefactor.
            
            U_input_phase = U_i * input_phase
            U_ft = np.fft.fft2(U_input_phase)
            
            # Output phase term (x, y)
            x, y = np.meshgrid(np.arange(hologram_width), np.arange(hologram_height))
            output_phase = np.exp(-1j * np.pi * (x**2 + y**2) / (lambda_c * z_hat_i))
            
            # Combine
            O_i = prefactor * output_phase * U_ft
            
            O_total += O_i
            
        # Quantize real part
        real_part = np.real(O_total)
        # Quantize to L=256 levels
        # Q(real, L, Delta) -> scale and quantize
        # Assuming Delta is a scaling factor or step size. 
        # Standard quantization: floor((real - min) / step) * step
        # Source doesn't specify Delta value. [G] Assuming standard linear quantization to 256 levels.
        min_val = np.min(real_part)
        max_val = np.max(real_part)
        if max_val == min_val:
            H_c = np.zeros_like(real_part)
        else:
            normalized = (real_part - min_val) / (max_val - min_val)
            quantized = np.floor(normalized * 255)
            H_c = quantized.astype(float)
            
        holograms[c] = H_c
        
    return holograms
```

**Edge Cases and Pitfalls:**
*   **Continuous Depth Artifacts:** In VR scenes with continuous depth ranges, the discrete layer separation creates visible artifacts at layer boundaries [S1]. This makes the method less suitable for VR compared to AR with isolated models [S1].
*   **Precision:** Numerical propagation requires careful handling of phase wrapping and floating-point precision, especially for large $z_l$ [S1, S2].
*   **Quantization:** Discarding amplitude information for phase-only SLMs requires specific encoding (e.g., detour phase) to mitigate twin-image artifacts, which is not inherent to the basic layer calculation [S1, S2].

## Subtopics

### Layer-based diffraction
Computes left and right holograms by numerically propagating light waves from compensated depth layers towards the hologram plane and summing them [S1]. It uses a specific propagation formula involving quadratic phase terms and Fourier transforms for each color channel [S1]. Choose this variant when high-fidelity diffraction effects are required for near-eye displays, particularly when compensating for optical system parameters like exit pupil position [S1].

## Operating characteristics
*   **Time Complexity:** The naive complexity is $O(L \cdot N)$, where $L$ is the number of layers and $N$ is the number of hologram pixels, due to the summation over layers and Fourier transforms [S1, S2].
*   **Performance:** Achieved over 35 frames per second on an NVIDIA Jetson AGX Orin embedded platform for a resolution of $2048 \times 1024$ [S1].
*   **Memory Complexity:** Requires storage for $L$ layers of size $W \times H$ and intermediate Fourier transform buffers [S1, S2].
*   **Strengths:** Enables real-time computation on embedded hardware; suitable for AR with isolated models [S1].
*   **Limitations:** Visible separation artifacts in continuous depth scenes (VR); limited imaging quality compared to consumer stereoscopic displays due to optical misalignment and aberrations [S1].

## Background
The method was proposed for holographic near-eye displays to enable real-time embedded rendering [S1]. It was implemented on a prototype headset using amplitude-only LCoS microdisplays and SLED illumination to reduce speckle noise [S1]. The approach was evaluated on synthetic scenes (Animals, Circuit, Village) to demonstrate its suitability for AR versus VR [S1]. Another application involves calculating CGHs for 3D displays using 2D-to-3D rendered depth maps with an 8-bit CGDM [S2].
