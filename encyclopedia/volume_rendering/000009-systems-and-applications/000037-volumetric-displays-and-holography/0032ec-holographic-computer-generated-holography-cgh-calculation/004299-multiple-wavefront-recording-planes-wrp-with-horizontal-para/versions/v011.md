# Multiple Wavefront Recording Planes (WRP) with Horizontal Parallax Only (HPO)

Also called: Fast CGH method for point clouds, HPO WRP method

## Overview
This method generates computer-generated holograms (CGH) for point clouds by distributing the calculation across multiple parallel wavefront recording planes (WRPs) to handle occlusion and reduce computational load, specifically adapted for Horizontal Parallax Only (HPO) displays [S1]. It differs from full-parallax WRP methods by computing point contributions to 1D hololines rather than the full 2D plane, and from naive point-source summation by using pre-computed look-up tables (LUTs) and band-limited angular spectrum propagation to manage the high spatial bandwidth product (SBP) required for wide viewing angles [S1].

## How it works
**Inputs:**
*   Point cloud data: Set of $M$ points, each with 3D coordinates $(x_i, y_i, z_i)$ and RGB color values [S1].
*   Display parameters: Pixel pitch $p_x, p_y$, resolution $N_x, N_y$, wavelength $\lambda$, and number of WRPs [S1].
*   Hologram geometry: HPO configuration where diffraction is computed only along horizontal lines (hololines) [S1].

**Outputs:**
*   Complex-valued hologram data for the HPO display [S1].

**Data Structures:**
*   **Point Cloud:** Array of structures containing position $(x, y, z)$ and color $(R, G, B)$ [S1].
*   **Look-Up Table (LUT):** Pre-computed complex propagation kernels for a specific distance $z$ [S1]. The LUT stores the complex amplitude $H(u, v; z)$ in the frequency domain, modified by a random phase mask for diffuse reflection modeling [S1].
*   **Wavefront Recording Planes (WRPs):** A set of parallel planes positioned between the object (point cloud) and the hologram plane [S1]. Each WRP holds a complex field representing the wavefront at that depth [S1].
*   **Hololines:** 1D arrays representing the hologram data for a single vertical row of the display [S1].

**Parameters:**
*   $\lambda$: Wavelength of reconstruction light (e.g., 640 nm) [S1].
*   $p_x, p_y$: Horizontal and vertical pixel pitches (e.g., 0.55 µm, 23.4 µm) [S1].
*   $N_x, N_y$: Resolution of the hologram plane (e.g., 32,768 × 768) [S1].
*   $z_{min}$: Minimum object-to-hologram distance to satisfy Shannon criterion, calculated as $z_{min} = \frac{N p^2}{\lambda}$ [S1].
*   $\theta$: Maximum diffraction angle, determined by $\sin \theta = \frac{\lambda}{2p}$ [S1].

**Steps:**

1.  **Point Volume Attribution:**
    Assign a Gaussian distribution profile to each point in the point cloud to model a continuous volume rather than a singular point [S1]. This generates smoother, continuous surface reconstructions [S1]. The amplitude $A_i$ of point $i$ at a distance $r$ from its center is modeled as:
    $$ A_i(r) = A_{0,i} \exp\left(-\frac{r^2}{2\sigma^2}\right) $$
    where $\sigma$ controls the spread [G: $\sigma$ is typically chosen based on the desired surface smoothness and pixel pitch; not explicitly defined in sources, but implied by "Gaussian distribution profile"].

2.  **LUT Generation (Source Plane to First WRP):**
    Pre-compute the propagation kernel from the point source plane to the first WRP distance $z_{LUT}$ [S1]. Calculate the angular spectrum transfer function $H(u, v; z_{LUT})$ using the Band-Limited Angular Spectrum Method (BL-ASM) [S1]. Apply a random phase mask to the LUT content to account for diffuse reflections, scattering light over a wide angular range [S1]. Store the complex kernel $H_{LUT}(u, v)$ in the LUT [S1].

3.  **Inter-WRP Propagation:**
    Propagate the wavefield from one WRP to the next parallel WRP using BL-ASM [S1]. For each WRP pair separated by distance $\Delta z$, compute the transfer function $H(u, v; \Delta z)$ [S1]. Apply BL-ASM constraints: double the calculation window area in the source plane by padding with zeros, perform FFT, multiply by the transfer function, and IFFT, then crop the output to the original window size to avoid edge errors from circular convolution [S1].

4.  **HPO Hololine Computation:**
    Adapt the standard WRP method for HPO by computing contributions only to 1D hololines [S1]. For each point $i$, determine its contribution to the hololines on the hologram plane [S1]. Instead of propagating to the full 2D hologram plane, propagate the wavefield from the last WRP to the hologram plane along the horizontal direction only [S1]. Use inverted Gaussian filters during propagation to model occlusions, locally blocking light from points behind others [S1].

5.  **Superposition:**
    Sum the complex contributions from all points $i$ onto the respective hololines of the hologram plane [G: Standard superposition principle for CGH].

6.  **Color Channel Handling:**
    For colour holograms, compute the hologram for a single reference wavelength (e.g., red, 640 nm) but assign RGB intensity values to the points [S1]. The final hologram consists of three channels computed with the same wavelength but different intensities per point to maintain colour information and wide viewing angle [S1].

7.  **Quantization (Optional):**
    If using a phase-only SLM, quantize the complex field $U_h(x, y)$ to phase values $0$ to $2\pi$ [G: Standard phase-only encoding techniques such as detour phase or error diffusion may be applied, but specific algorithm details are not provided in the source].

**Pseudocode:**

```python
import numpy as np

def compute_transfer_function(distance, wavelength, px, Ny, Nx):
    """Compute the band-limited angular spectrum transfer function H(u,v;z)."""
    u = np.fft.fftfreq(Nx, d=px)
    v = np.fft.fftfreq(Ny, d=px)
    U, V = np.meshgrid(u, v)
    
    # w calculation: w = (lambda^-2 - u^2 - v^2)^0.5
    w_sq = (1.0 / wavelength**2) - U**2 - V**2
    w = np.zeros_like(w_sq)
    w[w_sq >= 0] = np.sqrt(w_sq[w_sq >= 0])
    
    H = np.exp(1j * 2 * np.pi * w * distance)
    
    # Band-limiting: H'(u,v;z) = H(u,v;z) * rect(u/2u_limit) * rect(v/2v_limit)
    u_limit = 1.0 / (2 * px)
    v_limit = 1.0 / (2 * px)
    rect_u = np.abs(U) <= u_limit
    rect_v = np.abs(V) <= v_limit
    H = H * rect_u * rect_v
    
    return H

def propagate_bl_asm_2d(field, transfer_func, wavelength, px, Ny, Nx):
    """Band-Limited Angular Spectrum propagation with zero-padding and cropping."""
    # Double the calculation window area by padding with zeros
    Ny_pad, Nx_pad = 2 * Ny, 2 * Nx
    field_padded = np.zeros((Ny_pad, Nx_pad), dtype=complex)
    field_padded[:Ny, :Nx] = field
    
    # Resize transfer function to match padded grid spacing
    u_pad = np.fft.fftfreq(Nx_pad, d=px / 2)
    v_pad = np.fft.fftfreq(Ny_pad, d=px / 2)
    U_pad, V_pad = np.meshgrid(u_pad, v_pad)
    w_sq_pad = (1.0 / wavelength**2) - U_pad**2 - V_pad**2
    w_pad = np.zeros_like(w_sq_pad)
    w_pad[w_sq_pad >= 0] = np.sqrt(w_sq_pad[w_sq_pad >= 0])
    H_pad = np.exp(1j * 2 * np.pi * w_pad * transfer_func.shape[0] / Ny) # Scale distance proportionally
    u_limit = 1.0 / (2 * (px / 2))
    v_limit = 1.0 / (2 * (px / 2))
    H_pad = H_pad * (np.abs(U_pad) <= u_limit) * (np.abs(V_pad) <= v_limit)
    
    # FFT, multiply, IFFT
    F = np.fft.fft2(field_padded)
    G = F * H_pad
    field_out_padded = np.fft.ifft2(G)
    
    # Crop to original window size
    return field_out_padded[:Ny, :Nx]

def propagate_bl_asm_1d(field_row, distance, wavelength, px, Nx):
    """1D BL-ASM propagation for HPO hololines."""
    u = np.fft.fftfreq(Nx, d=px)
    U = u.reshape(1, -1)
    w_sq = (1.0 / wavelength**2) - U**2
    w = np.zeros_like(w_sq)
    w[w_sq >= 0] = np.sqrt(w_sq[w_sq >= 0])
    H = np.exp(1j * 2 * np.pi * w * distance)
    
    # Band-limiting
    u_limit = 1.0 / (2 * px)
    H = H * (np.abs(U) <= u_limit)
    
    F = np.fft.fft(field_row)
    G = F * H
    return np.fft.ifft(G)

def apply_inverted_gaussian_occlusion(field, center_x, center_y, sigma):
    """Locally block light using an inverted Gaussian filter to model occlusions."""
    Ny, Nx = field.shape
    y, x = np.mgrid[0:Ny, 0:Nx]
    dist_sq = (x - center_x)**2 + (y - center_y)**2
    occlusion = 1.0 - np.exp(-dist_sq / (2 * sigma**2))
    return field * occlusion

def generate_hpo_wrp_cgh(points, display_params, wrp_distances, lut_distance):
    """
    Generate HPO CGH using Multiple WRP method.
    
    Args:
        points: List of dicts with keys 'x', 'y', 'z', 'r', 'g', 'b'.
        display_params: Dict with 'lambda', 'px', 'py', 'Nx', 'Ny'.
        wrp_distances: List of z-distances for each WRP plane.
        lut_distance: Distance for LUT generation.
        
    Returns:
        hologram: 2D array (Ny, Nx) of complex values.
    """
    wavelength = display_params['lambda']
    px = display_params['px']
    Nx = display_params['Nx']
    Ny = display_params['Ny']
    
    # Initialize hologram plane
    hologram = np.zeros((Ny, Nx), dtype=complex)
    
    # Step 1 & 2: LUT Generation
    lut = compute_transfer_function(lut_distance, wavelength, px, Ny, Nx)
    random_phase = np.exp(1j * 2 * np.pi * np.random.rand(Ny, Nx))
    lut *= random_phase
    
    # Initialize WRPs
    wrp_fields = [np.zeros((Ny, Nx), dtype=complex) for _ in range(len(wrp_distances))]
    
    # Step 1: Project points to first WRP
    for point in points:
        dz = wrp_distances[0] - point['z']
        if dz <= 0:
            continue
            
        # Map point to grid indices
        ix = int(point['x'] / px)
        iy = int(point['y'] / px)
        sigma = px  # [G: Typical spread relative to pixel pitch]
        
        # Create sparse source field with Gaussian attribution
        source_field = np.zeros((Ny, Nx), dtype=complex)
        y, x = np.mgrid[0:Ny, 0:Nx]
        dist_sq = (x - ix)**2 + (y - iy)**2
        amp = point['r'] * np.exp(-dist_sq * px**2 / (2 * sigma**2))
        source_field = amp
        
        # Propagate to first WRP using LUT (BL-ASM)
        wrp_fields[0] += propagate_bl_asm_2d(source_field, lut, wavelength, px, Ny, Nx)
        
    # Step 3: Inter-WRP Propagation
    for i in range(len(wrp_distances) - 1):
        dz = wrp_distances[i+1] - wrp_distances[i]
        h = compute_transfer_function(dz, wavelength, px, Ny, Nx)
        wrp_fields[i+1] = propagate_bl_asm_2d(wrp_fields[i], h, wavelength, px, Ny, Nx)
        
    # Step 4: HPO Hololine Computation & Step 5: Superposition
    dz_final = display_params['z_hologram'] - wrp_distances[-1]
    for y in range(Ny):
        field_row = wrp_fields[-1][y, :]
        # 1D BL-ASM propagation to hologram plane
        hologram_row = propagate_bl_asm_1d(field_row, dz_final, wavelength, px, Nx)
        
        # Apply inverted Gaussian occlusion filter if needed
        # [G: Occlusion centers would be derived from point cloud depth ordering]
        hologram_row = apply_inverted_gaussian_occlusion(hologram_row, Nx//2, 0, px)
        
        hologram[y, :] += hologram_row
        
    return hologram
```

## Subtopics

### [Phase-Only Wave Field Reconstruction/Propagation (POS-WRP)](12886-phase-only-wave-field-reconstruction-propagation-pos-wrp.md)
POS-WRP is a rendering pipeline that encodes mesh-based 3D scenes into complex-valued wave fields with fine-grained textures, photo-realistic shadings, and perspective depth cues. It solves the problem of maintaining continuous depth cues and realistic illumination when projecting from perspective scene space to the orthogonal space of a Spatial Light Modulator (SLM). Unlike standard wave propagation which assumes paraxial orthogonal propagation, POS-WRP explicitly transforms mesh coordinates and textures to correct for projection discrepancies, delivering high-fidelity data with reduced speckle artifacts.

## Operating characteristics
**Time Complexity:**
Not given in the sources.

**Memory Complexity:**
Requires storage for the point cloud, $K$ WRP fields, and the LUT [S1]. Each WRP field is $O(N)$ complex numbers [S1]. The LUT is $O(N)$ [S1]. Total memory is $O(K \cdot N + N)$ [S1]. For high-resolution holograms (e.g., 32,768 × 768), this can be significant [S1].

**Measured Performance:**
Demonstrated on a Holografika HoloVizio 722RC light field display with 32,768 × 768 pixel resolution, 0.55 µm horizontal pitch, and 640 nm wavelength [S1]. The method supports a viewing angle of 70° [S1].

**Strengths:**
*   Handles occlusion naturally through the WRP structure and inverted Gaussian filters [S1].
*   High-quality reconstructions with smooth surfaces due to Gaussian volume attribution [S1].
*   Wide field of view achieved through diffuse reflection modeling (random phase LUTs) [S1].
*   Efficient for HPO by reducing 2D propagation to 1D hololines [S1].

**Limitations:**
*   HPO results in constrained viewing zones and astigmatic output due to diminished vertical resolution [S1].
*   Small pixel pitch leads to strong light field diffusion beyond computation window borders, requiring BL-ASM and zero-padding, which increases computational overhead [S1].
*   Aperiodic functions cause edge errors in FFT, mitigated by BL-ASM but not eliminated [S1].
*   Limited to point clouds; mesh-based scenes require different handling (see POS-WRP) [S1].

**When to Use:**
Use for point cloud data on HPO displays requiring wide viewing angles and high resolution [S1].

**When Not to Use:**
Avoid for full-parallax holography, mesh-based scenes with complex textures (use POS-WRP), or when computational resources are too limited for BL-ASM overhead [S1].

## Background
The Multiple WRP method was originally proposed for fast computation of holograms supporting full parallax [S1]. It was adapted for HPO displays to leverage the specific constraints of light field displays, such as the Holografika HoloVizio 722RC [S1]. The method builds on the Angular Spectrum method for wave propagation and incorporates Band-Limited Angular Spectrum (BL-ASM) to handle the high spatial bandwidth product of modern holographic displays [S1].
