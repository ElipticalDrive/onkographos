# Inkjet Printing-Based Volumetric Display

Also called: Fluorescent Ink Volumometric Display, Volumetric Display via Inkjet Printing

## Overview
This method constructs a physical volumetric display by printing photoreactive luminescent materials (fluorescent inks) onto stacked transparent films using a commercial inkjet printer. It solves the problem of creating full-colour 3D images with motion parallax by physically distributing volume elements (voxels) in 3D space, where each voxel is defined by the ink deposition on a specific layer. It differs from sibling methods like [Quantum-Dot-Based Volumetric Display](6943-quantum-dot-based-volumetric-display.md) by relying on pre-printed static layers rather than dynamic optical addressing or volumetric scattering within a single bulk medium.

## How it works
**Inputs:**
*   3D object data or 2D patterns to be projected.
*   Printer resolution settings.
*   Stack configuration parameters (layer count, spacing).

**Outputs:**
*   A physical stack of transparent films containing printed fluorescent patterns.
*   A 3D image visible when excited by UV light.

**Data Structures:**
The display consists of a stack of $L$ layers. Each layer $l$ (where $l=0 \dots L-1$) is a 2D grid of pixels.
*   **Film:** A transparent polyester sheet (e.g., 0.1 mm thick).
*   **Pixel:** A physical dot of fluorescent ink.
*   **Voxel:** The 3D volume element corresponding to a pixel at layer $l$. The 3D position is $(x, y, z_l)$, where $z_l = l \times \Delta z$.

**Algorithm for Single 3D Image:**
1.  **Slicing:** Convert the 3D object into a series of 2D cross-sectional images. Each image corresponds to one layer of the stack.
2.  **Printing:** Print each 2D image onto a separate transparent film using an inkjet printer. The inks used are typically europium complex (red), $\beta$-quinophthalone (green), and coumarin dyes (blue) [S1].
3.  **Stacking:** Stack the printed films at regular vertical intervals $\Delta z$ to form the volumetric display [S1].

**Algorithm for Multi-Directional Projection:**
To project multiple different 2D patterns from different viewing angles, a design algorithm determines the voxel values for the 3D structure [S1].
1.  **Define Projection Axes:** Select $K$ viewing directions (e.g., perpendicular and $\pm 30^\circ$ around the Y-axis) [S1].
2.  **Back-Projection:** For each target 2D pattern $P_k$ at angle $\theta_k$, project the pattern back onto the 3D volume grid.
3.  **Voxel Optimization:** Determine the ink color and intensity for each voxel $(x,y,z)$ such that the superposition of emissions from all layers, when viewed from direction $\theta_k$, approximates pattern $P_k$. This involves solving an inverse problem where the observed intensity at a pixel in the 2D projection is the sum of contributions from voxels along the line of sight [S1].
4.  **Printing:** Print the resulting 3D voxel data onto the films as described in the Single 3D Image algorithm [S1].

**Excitation and Viewing:**
1.  **Excitation:** Irradiate the stack with ultraviolet light (peak wavelength 365 nm) [S1].
2.  **Emission:** The fluorescent inks absorb UV light and emit visible light (red, green, blue) [S1].
3.  **Viewing:** Observe the emitted light from the desired direction. The brain integrates the 2D projections from different layers to perceive a 3D image [S1].

**Parameters:**
*   **Film Material:** Polyester transparent film (e.g., 'BG-32' from Folex imaging Inc.) [S1].
*   **Film Thickness:** 0.1 mm [S1].
*   **Layer Spacing:** 0.5 mm [S1].
*   **Printer Resolution:** Up to 5,760 × 1,440 dpi [S1].
*   **Ink Types:** Europium complex (Red), $\beta$-quinophthalone (Green), Coumarin dyes (Blue) [S1].
*   **Excitation Wavelength:** 365 nm UV light [S1].
*   **Rendering Space:** Example dimensions 35 mm × 35 mm × 12.5 mm [S1].
*   **Original Pattern Resolution:** 512 × 512 pixels, 3 channels (RGB), 256 gradations per channel [S1].

**Edge Cases and Pitfalls:**
*   **UV Attenuation:** UV light is absorbed by the transparent films. The transmittance of the film at 365 nm is 82% [S1]. If $N_{UV}$ is the number of films between the UV source and the printed layer, the intensity drops exponentially. For $N_{UV}=20$, intensity is ~2%; for $N_{UV}=25$, it is <1% [S1].
*   **Mitigation:** Use UV light sources on both the top and bottom of the display to reduce attenuation effects [S1].
*   **Visible Light Attenuation:** Visible light emitted by the inks is also attenuated by films above it, but less severely (transmittance ~90%) [S1].
*   **Image Quality Degradation:** Images viewed from diagonal directions (e.g., $\theta = \pm 30^\circ$) are blurred compared to the perpendicular view ($\theta = 0^\circ$), although motion parallax is preserved [S1].
*   **Cross-talk:** In multi-pattern projections, signals from other patterns can interfere (cross-talk), but the original patterns remain recognizable [S1].

## Subtopics

### Multi-Directional Projection
A variant where the 3D structure is designed to project different 2D patterns from different angles. It differs from standard volumetric displays by optimizing voxel values for multiple viewing axes simultaneously. Choose this when interactive or multi-viewpoint information display is required. See [Inkjet Printing-Based Volumetric Display](7615-inkjet-printing-based-volumetric-display.md).

### Full-Color Volumetric Display
The base method using RGB fluorescent inks to create full-color 3D images. Choose this for high-fidelity color representation. See [Inkjet Printing-Based Volumetric Display](7615-inkjet-printing-based-volumetric-display.md).

## Operating characteristics
*   **Time Complexity:** The fabrication time is dominated by the inkjet printing process. Printing a 300x300 pixel layer at high resolution takes significant time, but the method is batch-processable. The design algorithm for multi-directional projection involves solving an inverse problem, which can be computationally intensive depending on the number of layers and patterns [S1].
*   **Memory Complexity:** The data structure size is proportional to the number of layers and the resolution per layer. For a 20-layer, 300x300 pixel display, the data is manageable.
*   **Measured Performance:**
    *   **Resolution:** Limited by printer DPI (5,760 dpi) and layer spacing (0.5 mm). The vertical resolution is significantly lower than horizontal resolution.
    *   **Brightness:** Limited by UV attenuation through the stack. Brightness decreases exponentially with depth [S1].
    *   **Viewing Angle:** Best quality at perpendicular view ($\theta = 0^\circ$). Quality degrades at diagonal angles ($\theta = \pm 30^\circ$) due to blurring [S1].
*   **Strengths:**
    *   Uses commercially available inkjet printers and materials.
    *   Capable of full-color 3D images.
    *   Supports motion parallax.
    *   Can project multiple different patterns from different directions [S1].
*   **Limitations:**
    *   Static display (cannot change content dynamically).
    *   Limited vertical resolution due to layer spacing.
    *   UV light attenuation limits the maximum number of layers.
    *   Image quality degrades at oblique viewing angles [S1].
*   **When to Use:** For static, high-quality, full-color 3D displays where dynamic updating is not required, and where motion parallax is beneficial (e.g., digital signage, art installations).
*   **When Not to Use:** For dynamic content, high vertical resolution requirements, or environments where UV safety is a concern.

## Background
This method was introduced by Hirayama et al. in 2017 [S1]. It builds on the principles of volumetric displays by using physical layers to represent 3D space. The use of fluorescent inks allows for passive emission (no need for active matrix addressing per voxel), simplifying the hardware. The extension to multi-directional projection demonstrates the flexibility of the design algorithm. The method leverages widely deployed inkjet printing technology to fabricate novel information display devices [S1].
