# Gradient-Aware Color Table Filtering

Also called: Gradient-Based Color Table Filtering (Hart et al.)

## Overview
Gradient-Aware Color Table Filtering is a refinement of color table filtering that uses the local noise gradient to improve accuracy. It addresses the problem of aliasing in procedural noise by estimating the range of noise values over a filter footprint using derivative information. It sets itself apart from its sibling [Variance-Based Color Table Filtering](16457-variance-based-color-table-filtering.md) by relying on local gradient estimation rather than analytical variance loss.

## How it works
**Inputs:**
- Noise function $N(u)$ and its gradient $\nabla N(u)$.
- Color table $C(u)$.
- Filter size (determining the footprint).

**Outputs:**
- Filtered color value.

**Data Structures:**
- The color table $C$ is typically implemented as a 1D texture to allow for MIP-mapping.

**Steps:**
1. Evaluate the noise value $N(u)$ and its local gradient $\nabla N(u)$ at the sample point.
2. Compute the interval size $\delta$ based on the filter size and the maximum gradient of the color table $C$ with respect to $u$, incorporating the local noise gradient.
3. Define the noise value interval as $[N(u) - \delta, N(u) + \delta]$.
4. Evaluate the color over this interval using MIP-mapping on the 1D color table.

**Formulas:**
The interval is defined as:
$$ [N(u) - \delta, N(u) + \delta] $$
The size $\delta$ is computed from the filter size and the maximum gradient of $C$ with respect to $u$, refined by the local noise gradient.

**Parameters:**
- Filter size: Determines the footprint.
- Gradient computation: Can be done via finite differencing or analytically.

**Edge Cases and Pitfalls:**
- A source of error is that the noise value and gradient are evaluated on the unfiltered noise [S1, S2].

**Pseudocode:**
```python
def gradient_aware_color_table_filtering(noise_func, color_table, u, filter_size):
    # Evaluate noise and its gradient at u
    # Gradient can be computed via finite differencing or analytically
    n_val = noise_func(u)
    n_grad = compute_gradient(noise_func, u)
    
    # Compute delta based on filter size, color table gradient, and noise gradient
    # Specific formula for delta is not detailed in sources, but relies on max gradient of C wrt u
    delta = compute_delta(filter_size, color_table, n_grad)
    
    # Define interval
    min_val = n_val - delta
    max_val = n_val + delta
    
    # Evaluate color over interval using MIP-mapping
    # This step assumes color_table supports MIP-mapping for range queries
    color = color_table.sample_range(min_val, max_val)
    
    return color
```

## Subtopics

### Variance-Based Color Table Filtering
Uses loss in noise variance due to filtering to estimate the noise value range. More accurate when analytical noise variance is available. See [Variance-Based Color Table Filtering](16457-variance-based-color-table-filtering.md).

## Operating characteristics
- **Time Complexity**: Depends on gradient computation and MIP-mapping lookup.
- **Memory Complexity**: Requires storage for the color table and potentially gradient data.
- **Strengths**: Improves accuracy over basic color table filtering by incorporating local noise behavior.
- **Limitations**: Error arises from evaluating noise and gradient on unfiltered noise.

## Background
Originated from Hart et al. [HCK99] as a refinement of color table filtering. It builds on the idea of evaluating color over a small interval using MIP-mapping, incorporating local noise gradient information.
