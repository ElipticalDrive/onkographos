# Gradient-Aware Color Table Filtering

Also called: Gradient-Based Color Table Filtering (Hart et al.)

## Overview
Gradient-Aware Color Table Filtering is a refinement of color table filtering that uses the local noise gradient to improve accuracy [S2]. It addresses the problem of aliasing in procedural noise by estimating the range of noise values over a filter footprint using derivative information [S1]. It sets itself apart from its sibling [Variance-Based Color Table Filtering](16457-variance-based-color-table-filtering.md) by relying on local gradient estimation rather than analytical variance loss [S1, S2].

## How it works
**Inputs:** Noise function $N(u)$, color table $C(u)$, and filter size [S1, S2].
**Outputs:** Filtered color value [S2].
**Data Structures:** The color table $C$ is typically implemented as a 1D texture to allow for MIP-mapping [S2].
**Steps:**
1. Evaluate the noise value $N(u)$ and its local gradient $\nabla N(u)$ at the sample point [S1].
2. Compute the interval size $\delta$ based on the filter size and the maximum gradient of the color table $C$ with respect to $u$, refined by the local noise gradient [S2].
3. Define the noise value interval as $[N(u) - \delta, N(u) + \delta]$ [S2].
4. Evaluate the color over this interval using MIP-mapping on the 1D color table [S2].
**Formulas:** The interval is defined as $[N(u) - \delta, N(u) + \delta]$ [S2]. The size $\delta$ is computed from the filter size and the maximum gradient of $C$ with respect to $u$, refined by the local noise gradient [S2].
**Parameters:** Filter size determines the footprint [S2]. Gradient computation can be done via finite differencing or analytically [S1].
**Edge Cases and Pitfalls:** A source of error is that the noise value and gradient are evaluated on the unfiltered noise [S1, S2].
**Pseudocode:**
```python
def gradient_aware_color_table_filtering(noise_func, color_table, u, filter_size):
    # Evaluate noise value and its local gradient at the sample point
    # Gradient computation can be done via finite differencing or analytically [S1]
    n_val = noise_func(u)
    epsilon = 1e-6
    n_grad = (noise_func(u + epsilon) - noise_func(u - epsilon)) / (2 * epsilon)
    
    # Compute delta based on filter size and color table gradient, refined by noise gradient
    # Exact formula for delta is not given in the sources [S1, S2]
    delta = compute_delta(filter_size, n_grad)
    
    # Define interval
    min_val = n_val - delta
    max_val = n_val + delta
    
    # Evaluate color over interval using MIP-mapping on the 1D color table [S2]
    color = color_table.sample_range(min_val, max_val)
    
    return color

def compute_delta(filter_size, noise_gradient):
```

## Operating characteristics
- **Time Complexity:** Depends on gradient computation and MIP-mapping lookup [S1, S2].
- **Memory Complexity:** Requires storage for the color table and potentially gradient data [S2].
- **Strengths:** Improves accuracy over basic color table filtering by incorporating local noise behavior [S2].
- **Limitations:** Error arises from evaluating noise and gradient on unfiltered noise [S1, S2].

## Background
Originated from Hart et al. [HCK99] as a refinement of color table filtering [S2]. It builds on the idea of evaluating color over a small interval using MIP-mapping, incorporating local noise gradient information [S1, S2].
