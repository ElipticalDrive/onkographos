# Colormap Application for Visualization

Also called: Colormap Visualization, Depth Colormap Application, Render Net Image

## Overview
This method extracts and formats a specific render item (alpha, normal, depth, edge, curvature, or render) from a render package for visualization [S1, unofficial]. It applies colormaps to accumulation and depth outputs for visualization purposes [S2, unofficial].

## How it works
**Inputs:**
- `render_items`: Dictionary or object containing render outputs (`rend_alpha`, `rend_normal`, `surf_depth`, `render`).
- `render_mode`: String specifying the output type.
- `colormap`: Function or lookup table mapping scalar values to RGB.
- `gradient_map`: Function or lookup table for edge/curvature visualization.
- `accumulation`: Accumulation output used for depth normalization.

**Outputs:**
- `net_image`: Visualization result.

**Data Structures:** Not given in the sources [G].

**Steps:**
1. Get output mode string from `render_items[render_mode].lower()` [S1, unofficial].
2. If `mode == 'alpha'`: set `net_image = rend_alpha` [S1, unofficial].
3. If `mode == 'normal'`: set `net_image = rend_normal`, then normalize from $[-1, 1]$ to $[0, 1]$ via `net_image = (net_image + 1) / 2` [S1, unofficial].
4. If `mode == 'depth'`: set `net_image = surf_depth` [S1, unofficial].
5. If `mode == 'edge'`: set `net_image = render`, then apply `gradient_map` to `net_image` [S1, unofficial].
6. If `mode == 'curvature'`: set `net_image = rend_normal`, normalize to $[0, 1]$, then apply `gradient_map` [S1, unofficial].
7. Else: set `net_image = render` [S1, unofficial].
8. If `net_image` has a single channel (`shape[0] == 1`), apply `colormap` to `net_image` [S1, unofficial].
9. Return `net_image` [S1, unofficial].

**Formulas:**
- Normalization for normal/curvature: $$ \text{net\_image} = \frac{\text{net\_image} + 1}{2} $$ [S1, unofficial].

**Parameters:**
- `render_mode`: Typical values are `'alpha'`, `'normal'`, `'depth'`, `'edge'`, `'curvature'` [S1, unofficial].
- `colormap` and `gradient_map`: Standard mapping functions [S1, S2, unofficial].

**Edge Cases and Pitfalls:**
- Normal and curvature modes require normalization from $[-1, 1]$ to $[0, 1]$ before further processing or colormap application [S1, unofficial].
- Depth visualization uses the accumulation output for normalization [S2, unofficial].

**Pseudocode:**
```python
def apply_colormap_visualization(render_items, render_mode, colormap, gradient_map):
    """
    Extracts a render item and applies a colormap for visualization.
    
    Args:
        render_items: Dict containing 'rend_alpha', 'rend_normal', 'surf_depth', 'render'.
        render_mode: String indicating the type of visualization.
        colormap: Function mapping scalar [0,1] to RGB.
        gradient_map: Function mapping input to RGB for edges/curvature.
        
    Returns:
        net_image: Visualization tensor.
    """
    # 1. Get mode
    mode = render_items[render_mode].lower()
    
    # 2-7. Select base data and apply mode-specific processing
    if mode == 'alpha':
        net_image = render_items['rend_alpha']
    elif mode == 'normal':
        net_image = render_items['rend_normal']
        net_image = (net_image + 1.0) / 2.0
    elif mode == 'depth':
        net_image = render_items['surf_depth']
    elif mode == 'edge':
        net_image = render_items['render']
        net_image = gradient_map(net_image)
    elif mode == 'curvature':
        net_image = render_items['rend_normal']
        net_image = (net_image + 1.0) / 2.0
        net_image = gradient_map(net_image)
    else:
        net_image = render_items['render']
        
    # 8. Apply colormap if single channel
    if net_image.shape[0] == 1:
        net_image = colormap(net_image)
        
    # 9. Return result
    return net_image
```
