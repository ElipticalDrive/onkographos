# Histogram Matching

Also called: Color Alignment

## Overview
Histogram Matching aligns the color distribution of a target image (or volume) to that of a reference image by mapping their cumulative distribution functions (CDFs) [S1]. It solves the problem of color discrepancies arising from different sensors or lighting conditions, ensuring that the target adopts the chromatic characteristics of the reference while preserving its structural luminance [S1]. Unlike statistical mean/std matching, it preserves the full shape of the reference color distribution rather than just its first two moments [S1].

## How it works
**Inputs:**
*   Reference image $I_m$ (or volume) with RGB channels.
*   Target image $I_w$ (or volume) with RGB channels.
*   Discretization levels $L$ (typically 256 for 8-bit per channel).

**Outputs:**
*   Transformed target image $I'_w$ with colors aligned to $I_m$.

**Data Structures:**
*   Histograms $H_m, H_w$: Arrays of size $L^3$ (or per-channel size $L$) storing frequency counts for each color bin.
*   Cumulative Distribution Functions $S_m, S_w$: Arrays of size $L^3$ (or $L$) where $S(v) = \sum_{c \le v} H(c)$.
*   Mapping Table $M$: Array of size $L^3$ (or $L$) where $M[v_i] = v_k$.

**Steps:**
1.  **Compute Histograms:** For each color channel (or for the combined RGB space if treating as a single distribution), calculate the histogram $H$. For an input image, the frequency $n_i$ of color $v_i$ is counted. The histogram value is $h(v_i) = \frac{n_i}{N}$, where $N$ is the total number of pixels/voxels [S1].
2.  **Compute CDFs:** Calculate the cumulative distribution function for the reference $S_m$ and target $S_w$. For a discrete level $v$, $S(v) = \sum_{c \le v} h(c)$ [S1].
3.  **Build Mapping:** For each level $i$ in the target histogram (value $v_i$), find the corresponding level $k$ in the reference histogram (value $v_k$) such that the cumulative probabilities match:
    $$ S_w(v_i) = S_m(v_k) $$
    If an exact match does not exist, the closest $k$ is selected [S1].
4.  **Apply Transformation:** Replace each pixel/voxel color $v_i$ in the target with the mapped color $v_k$ [S1].

**Pseudocode:**
```python
def histogram_match(target_rgb, reference_rgb, levels=256):
    """
    Matches the histogram of target_rgb to reference_rgb.
    Args:
        target_rgb: numpy array (H, W, 3) or (D, H, W, 3)
        reference_rgb: numpy array (H, W, 3) or (D, H, W, 3)
        levels: number of discrete bins per channel
    Returns:
        matched_rgb: numpy array with same shape as target_rgb
    """
    import numpy as np
    
    # Flatten images to 1D arrays of pixels/voxels
    target_flat = target_rgb.reshape(-1, 3)
    ref_flat = reference_rgb.reshape(-1, 3)
    
    matched_flat = np.zeros_like(target_flat)
    
    # Process each channel independently
    for c in range(3):
        t_channel = target_flat[:, c]
        r_channel = ref_flat[:, c]
        
        # 1. Compute histograms
        # Use np.histogram to get counts and bin edges
        t_hist, t_edges = np.histogram(t_channel, bins=levels, range=(0, levels-1))
        r_hist, r_edges = np.histogram(r_channel, bins=levels, range=(0, levels-1))
        
        # Normalize to probabilities
        t_hist = t_hist.astype(float) / len(t_channel)
        r_hist = r_hist.astype(float) / len(r_channel)
        
        # 2. Compute CDFs
        t_cdf = np.cumsum(t_hist)
        r_cdf = np.cumsum(r_hist)
        
        # 3. Build mapping
        # For each target bin value i, find reference bin k where CDFs are closest
        # Using searchsorted to find the index in r_cdf closest to t_cdf[i]
        # Note: searchsorted returns insertion points. We want the index k
        # such that r_cdf[k] is closest to t_cdf[i].
        
        mapping = np.zeros(levels, dtype=int)
        for i in range(levels):
            # Find index k in r_cdf closest to t_cdf[i]
            # searchsorted finds the first index where r_cdf[k] >= t_cdf[i]
            k = np.searchsorted(r_cdf, t_cdf[i])
            # Clamp k to valid range
            k = np.clip(k, 0, levels - 1)
            mapping[i] = k
            
        # 4. Apply mapping
        # Clip target values to valid indices
        t_indices = np.clip(t_channel.astype(int), 0, levels - 1)
        matched_channel = mapping[t_indices]
        
        matched_flat[:, c] = matched_channel
        
    return matched_flat.reshape(target_rgb.shape)
```

**Parameters:**
*   `levels`: Number of discrete bins. Default 256 for 8-bit images [S1].
*   `eps`: Not specified in sources. [G] A small epsilon may be needed if CDFs are flat (zero variance) to avoid division errors in alternative implementations, though histogram matching relies on lookup rather than division.

**Edge Cases:**
*   **Zero Variance:** If a channel in the target has constant color, the CDF is a step function. The mapping will still work but may result in quantization artifacts if the reference has high variance [S1].
*   **Boundary Conditions:** Values outside the histogram range (e.g., floating point values > 255) must be clipped or handled explicitly [G].

## Subtopics

### Optimal Transport Color Matching
A variant that aligns color distributions by computing an optimal transport map between color histograms, weighted by person segmentation masks to prioritize subject color accuracy [S2, unofficial]. It generates person segmentation masks to identify regions of interest, computes weighted color histograms, and uses the Python Optimal Transport (POT) library to compute the mapping [S2, unofficial]. This method is chosen when specific subjects (e.g., people) require higher color fidelity than the background, addressing issues where feature-based matching (like SIFT) selects inconsistent colors for the same 3D point across views [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot C)$ for histogram computation and $O(L^3)$ or $O(L)$ for CDF and mapping, where $N$ is the number of pixels/voxels, $C$ is channels, and $L$ is the number of bins. Efficient for large datasets.
*   **Memory Complexity:** $O(L^3)$ or $O(L)$ for storing histograms and CDFs.
*   **Strengths:** Preserves the exact shape of the reference color distribution; simple to implement; robust to sensor differences [S1].
*   **Limitations:** Assumes a global color shift; may not preserve local color variations if the reference and target have different local structures; can introduce color bleeding if the mapping is not monotonic (though CDF matching usually ensures monotonicity) [S1].
*   **When to use:** When global color consistency is required between multi-sensor inputs (e.g., dual-camera setups) [S1].
*   **When not to use:** When local color variations are critical or when the reference and target have fundamentally different color palettes that cannot be mapped linearly [S1].

## Background
Originated in the context of dual-camera all-in-focus neural radiance fields to mitigate color discrepancies between main and ultra-wide camera sensors [S1]. The method was adapted from traditional image processing techniques to align the color of the ultra-wide image to the main image by matching their histogram cumulative distribution functions [S1].
