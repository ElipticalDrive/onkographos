# ExpModel

Also called: WbModel

## Overview
ExpModel is a conditional neural network that applies learned per-image color corrections to rendered RGB images to match training-time exposure conditions [S1, unofficial]. It provides two distinct variants: a White Balance model that scales RGB channels by a temperature condition, and an Exposure model that applies a log-scale adjustment based on an exposure condition [S1, unofficial]. It builds on [Trained Exposure Application](13959-trained-exposure-application.md) by parameterizing these specific color adjustments within a learned framework [S1, unofficial].

## How it works
### Inputs and Outputs
*   **Inputs**: `inputs_rgb` is a tensor of shape `(N, 3)` representing $N$ RGB pixels [S1, unofficial]. `condition` is a tensor of shape `(N,)` representing the scalar conditioning variable (temperature for White Balance, exposure for Exposure) [S1, unofficial].
*   **Outputs**: `rgb_wb` or `rgb_exp` is a tensor of shape `(N, 3)` representing the corrected RGB pixels [S1, unofficial].

### Data Structures
The models are implemented as Multi-Layer Perceptrons (MLPs) using dense layers initialized with Glorot uniform weights [S1, unofficial]. The architecture consists of a conditioning path that processes the scalar input, followed by an output layer that produces the color correction factors [S1, unofficial].

### White Balance Model (WbModel)
This model applies a learned scaling factor to RGB inputs based on a temperature condition [S1, unofficial].
1. Initialize `dense_layer` with Glorot uniform initialization [S1, unofficial].
2. Set `input_temp = condition.reshape(-1, 1)` [S1, unofficial].
3. Loop `i` from 0 to `net_depth - 1`: Apply `dense_layer(net_width)` to `input_temp`, then apply `net_activation` to the result [S1, unofficial].
4. Predict weight `w` by applying `dense_layer(num_rgb_channels)` to `input_temp` [S1, unofficial].
5. Apply `rgb_activation(w)` and multiply the result by 2 [S1, unofficial].
6. Compute `rgb_wb = inputs_rgb * w` [S1, unofficial].
7. Return `rgb_wb` [S1, unofficial].

### Exposure Model (ExpModel)
This model applies a learned log-scale adjustment to RGB inputs based on an exposure condition [S1, unofficial].
1. Initialize `dense_layer` with Glorot uniform initialization [S1, unofficial].
2. Set `input_exp = condition.reshape(-1, 1)` [S1, unofficial].
3. Extract `r`, `g`, `b` from `inputs_rgb` as slices `[:, 0:1]`, `[:, 1:2]`, `[:, 2:3]` [S1, unofficial].
4. Loop `i` from 0 to `net_depth - 1`: Apply `dense_layer(net_width)` to `input_exp`, then apply `net_activation` to the result [S1, unofficial].
5. Predict weight `w` by applying `dense_layer(one_rgb_channels)` to `input_exp` [S1, unofficial].
6. Apply `rgb_activation(w)` and multiply the result by 1.5 [S1, unofficial].
7. Compute log-adjusted channels: $r_e = r + \log(w)$, $g_e = g + \log(w)$, $b_e = b + \log(w)$ [S1, unofficial].
8. Concatenate $r_e$, $g_e$, $b_e$ along the last axis to get `rgb_exp` [S1, unofficial].
9. Return `rgb_exp` [S1, unofficial].

### Formulas
The White Balance correction is defined as:
$$w_{\text{wb}} = 2 \cdot \sigma\left(\text{Dense}_{\text{out}}\left(\text{MLP}_{\text{cond}}(c)\right)\right), \quad \mathbf{C}_{\text{wb}} = \mathbf{C}_{\text{in}} \odot w_{\text{wb}}$$
The Exposure correction is defined as:
$$w_{\text{exp}} = 1.5 \cdot \sigma\left(\text{Dense}_{\text{out}}\left(\text{MLP}_{\text{cond}}(c)\right)\right), \quad C_{e} = C_{\text{in}} + \log(w_{\text{exp}})$$
where $\sigma$ is the sigmoid activation, $\text{MLP}_{\text{cond}}$ denotes the hidden dense layers with ReLU activation, $\text{Dense}_{\text{out}}$ is the output layer, $c$ is the condition, $\odot$ is element-wise multiplication, and $C_{\text{in}}$ is the input channel value [S1, unofficial].

### Pseudocode
```python
import numpy as np
import functools

def glorot_uniform_initializer(size):
    fan_in, fan_out = size
    std = np.sqrt(2.0 / (fan_in + fan_out))
    return np.random.normal(0, std, size)

def create_dense_layer(in_features, out_features, kernel_init=glorot_uniform_initializer):
    kernel = kernel_init((in_features, out_features))
    bias = np.zeros(out_features)
    def layer(x):
        return x @ kernel + bias
    return layer

def relu(x):
    return np.maximum(0, x)

def sigmoid(x):
    return 1.0 / (1.0 + np.exp(-x))

def wb_model(inputs_rgb, condition, net_depth=2, net_width=32, 
             net_activation=relu, rgb_activation=sigmoid, num_rgb_channels=3):
    input_temp = condition.reshape(-1, 1)
    dense_layer = create_dense_layer(1, net_width)
    for _ in range(net_depth):
        input_temp = dense_layer(input_temp)
        input_temp = net_activation(input_temp)
    out_layer = create_dense_layer(net_width, num_rgb_channels)
    w = out_layer(input_temp)
    w = rgb_activation(w) * 2.0
    return inputs_rgb * w

def exp_model(inputs_rgb, condition, net_depth=2, net_width=32, 
              net_activation=relu, rgb_activation=sigmoid, one_rgb_channels=1):
    input_exp = condition.reshape(-1, 1)
    r = inputs_rgb[:, 0:1]
    g = inputs_rgb[:, 1:2]
    b = inputs_rgb[:, 2:3]
    dense_layer = create_dense_layer(1, net_width)
    for _ in range(net_depth):
        input_exp = dense_layer(input_exp)
        input_exp = net_activation(input_exp)
    out_layer = create_dense_layer(net_width, one_rgb_channels)
    w = out_layer(input_exp)
    w = rgb_activation(w) * 1.5
    r_e = r + np.log(w)
    g_e = g + np.log(w)
    b_e = b + np.log(w)
    return np.concatenate([r_e, g_e, b_e], axis=-1)
```

### Parameters
*   **WB Model**: `net_depth` = 2, `net_width` = 32, `net_activation` = ReLU, `rgb_activation` = Sigmoid, `num_rgb_channels` = 3 [S1, unofficial].
*   **EXP Model**: `net_depth` = 2, `net_width` = 32, `net_activation` = ReLU, `rgb_activation` = Sigmoid, `one_rgb_channels` = 1 [S1, unofficial].

### Edge Cases and Pitfalls
*   **Logarithm Domain**: The Exposure model computes $\log(w)$. Since `w` is the output of a sigmoid activation scaled by 1.5, $w \in (0, 1.5)$. The logarithm is defined for $w > 0$. Sigmoid outputs are strictly positive, so $\log(w)$ is always defined. However, if $w$ approaches 0, $\log(w)$ approaches $-\infty$, potentially causing numerical instability or NaNs if not handled. [G] In practice, sigmoid outputs are bounded away from exact zero, but clipping `w` to a small epsilon (e.g., $10^{-7}$) before taking the log is recommended for stability. [G]
*   **Condition Scaling**: The condition inputs (temperature, exposure) must be scaled appropriately for the network. The sources do not specify normalization steps for the condition input, implying it is used as-is or pre-normalized by the caller. [S1, unofficial]

## Subtopics

### ISP
An Image Signal Processing pipeline that chains White Balance, Exposure, and CRF models [S1, unofficial]. It instantiates `wb = WbModel()`, `exp = ExpModel()`, and `crf = CrfModel()`, then applies White Balance first: `input_wb = wb(input, temperature)` [S1, unofficial].
*   **Parameters**: `net_depth` = 8, `net_width` = 256, `net_depth_condition` = 1, `net_width_condition` = 128, `net_activation` = ReLU, `skip_layer` = 4 (adds a skip connection to the output of every N layers), `num_rgb_channels` = 3, `num_density_channels` = 1 [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: Linear with respect to the number of pixels $N$ and the depth of the MLP $D$. $O(N \cdot D \cdot W)$, where $W$ is the width [G].
*   **Memory Complexity**: $O(W \cdot D)$ for model weights [G].
*   **Strengths**: Simple, differentiable, and easy to integrate into neural rendering pipelines [G].
*   **Limitations**: Relies on learned parameters, so performance depends on the training data distribution. The log-scale adjustment in the Exposure model may be sensitive to small values of $w$ [G].
*   **When to use**: When a learned, per-image color correction is needed to match training-time exposure conditions [G].
*   **When not to use**: When a simple, fixed white balance or exposure correction is sufficient, or when computational resources are extremely limited [G].

## Background
ExpModel and WbModel originate from evaluation scripts for neural rendering pipelines that extend mip-NeRF with learned colorization models [S1, unofficial]. They were developed to apply per-image exposure matching during the rendering process, allowing trained networks to adapt to varying lighting conditions without retraining the base radiance field [S1, unofficial].
