# Reinhard Tonemapping for Training

Also called: HDR to sRGB conversion, Image Format Conversion for Neural Networks

## Overview
This method converts unbounded high-dynamic-range (HDR) linear radiance from a differentiable renderer into display-referred sRGB images suitable for neural network training [S1, unofficial]. It prevents numerical instabilities and out-of-distribution inputs by compressing the dynamic range into a bounded, perceptually plausible interval [S1, unofficial].

## How it works
**Inputs:** Rendered RGB image with unbounded linear radiance values in the renderer's internal basis [S1, unofficial].
**Outputs:** sRGB image with normalized intensities in $[0, 1]$ [S1, unofficial].

**Data Structures:**
*   Input: Tensor of shape $(H, W, 3)$, type float32, values $\in [0, \infty)$ [G].
*   Output: Tensor of shape $(H, W, 3)$, type float32, values $\in [0, 1]$ [G].

**Steps:**
1.  **Basis Transformation:** Transform the renderer's internal RGB basis to linear sRGB [S1, unofficial].
2.  **Reinhard Tonemapping:** Apply Reinhard tonemapping to compress the unbounded linear radiance [S1, unofficial]. For each color channel $c$, the tonemapped value $c_{tm}$ is calculated as $c_{tm} = \frac{c}{1 + c}$ [G]. This normalization preserves detail while preventing saturation [S1, unofficial].
3.  **sRGB Transfer Function:** Apply the sRGB gamma encoding to yield perceptually uniform intensities [S1, unofficial]. For each tonemapped channel $c_{tm}$, the final sRGB value $c_{srgb}$ is:
    $$ c_{srgb} = \begin{cases} 12.92 \cdot c_{tm} & \text{if } c_{tm} \le 0.0031308 \\ 1.055 \cdot c_{tm}^{1/2.4} - 0.055 & \text{if } c_{tm} > 0.0031308 \end{cases} $$ [G].

**Parameters:**
*   Reinhard normalization: Implicitly 1.0 in the denominator [G].
*   sRGB gamma: Standard sRGB transfer function coefficients [G].

**Edge Cases:**
*   **Zero/Negative Values:** If input radiance is negative (numerical noise), clamp to 0 before basis transformation [G].
*   **Infinity:** If input contains infinity, clamp to a large finite value or handle as NaN before processing [G].

**Pseudocode:**
```python
import numpy as np

def reinhard_tonemapping_for_training(rendered_image: np.ndarray, M: np.ndarray) -> np.ndarray:
    """
    Convert HDR linear radiance to sRGB for training.
    
    Args:
        rendered_image: np.ndarray of shape (H, W, 3), dtype float32, 
                        values in renderer's internal basis (unbounded).
        M: np.ndarray of shape (3, 3), dtype float32, 
           renderer-specific conversion matrix to linear sRGB.
    """
    # Step 1: Clamp negative values to zero
    img = np.maximum(rendered_image, 0.0)
    
    # Step 2: Transform to linear sRGB basis
    h, w, _ = img.shape
    pixels = img.reshape(-1, 3)
    linear_srgb = pixels @ M
    
    # Step 3: Reinhard tonemapping
    tonemapped = linear_srgb / (1.0 + linear_srgb)
    
    # Step 4: sRGB gamma encoding
    def srgb_gamma(c):
        return np.where(c <= 0.0031308, 12.92 * c, 1.055 * np.power(c, 1/2.4) - 0.055)
    
    srgb_image = srgb_gamma(tonemapped).reshape(h, w, 3)
    return srgb_image
```

## Subtopics

### Gamma Tone Mapping
Uses a fixed gamma function $g(c_0) = c_0^{1/2.2}$ instead of a learnable MLP because there is no significant difference in performance when either is employed, due to consistent exposure of the dataset [S2].

Not given in the sources.

## Background
Originated as a preprocessing step in differentiable rendering pipelines for vision model probing [S1, unofficial] and NeRF training [S2]. It is used to ensure rendered images are compatible with neural networks by converting raw renderer outputs into standard display-referred sRGB space [S1, unofficial].
