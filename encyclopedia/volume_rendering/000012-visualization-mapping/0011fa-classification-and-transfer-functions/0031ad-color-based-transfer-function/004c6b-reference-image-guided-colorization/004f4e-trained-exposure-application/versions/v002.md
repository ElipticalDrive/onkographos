# Trained Exposure Application

Also called: Learned per-image color transform, Per-image color correction

## Overview
Trained Exposure Application is a post-processing method that applies a learned, per-image linear color transform and bias vector to a rendered RGB image to match training-time exposure conditions [S1, unofficial]. It builds on [Reference Image Guided Colorization](13231-reference-image-guided-colorization.md) by providing the specific parameterized functions for white balance and exposure adjustments within that framework [S1, unofficial]. Unlike sibling methods that rely on semantic feature matching, this approach operates directly on the final rendered pixels using a compact affine transformation derived from training data [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A rendered RGB image tensor $I_{in}$ of shape $(H, W, 3)$ and an exposure tensor $E$ of shape $(4, 4)$ retrieved by image name [S1, unofficial].
- Output: A color-corrected RGB image tensor $I_{out}$ of shape $(H, W, 3)$ [S1, unofficial].

**Data Structures:**
- The exposure tensor $E$ is a $4 \times 4$ matrix where:
  - $E[:3, :3]$ is a $3 \times 3$ color transform matrix [S1, unofficial].
  - $E[:3, 3]$ is a $3 \times 1$ bias vector (broadcasted as $3 \times 1 \times 1$) [S1, unofficial].
  - The fourth row and column are unused in the transformation [S1, unofficial].

**Steps:**
1. Retrieve the exposure tensor $E$ associated with the current viewpoint camera's image name [S1, unofficial].
2. Permute the input image $I_{in}$ from shape $(3, H, W)$ to $(H, W, 3)$ to facilitate matrix multiplication [S1, unofficial].
3. Multiply the permuted image by the $3 \times 3$ color transform matrix: $M = I_{in}^{perm} \cdot E[:3, :3]$ [S1, unofficial].
4. Add the $3 \times 1$ bias vector to $M$, broadcasting the bias across the spatial dimensions [S1, unofficial].
5. Permute the result back to shape $(3, H, W)$ [S1, unofficial].

**Formula:**
$$I_{out} = (I_{in} \cdot E_{3\times3})^T + E_{3}$$
Where:
- $I_{in}$ is the input image tensor of shape $(H, W, 3)$ after permutation [S1, unofficial].
- $E_{3\times3}$ is the $3 \times 3$ color transform matrix $E[:3, :3]$ [S1, unofficial].
- $E_{3}$ is the $3 \times 1$ bias vector $E[:3, 3]$ [S1, unofficial].
- The transpose operation $(\cdot)^T$ restores the channel-first dimension order $(3, H, W)$ [S1, unofficial].

**Pseudocode:**
```python
def trained_exposure_application(rendered_image, exposure):
    """
    Applies a learned per-image 3x3 color transform and 3D bias vector.
    
    Args:
        rendered_image: Tensor of shape (3, H, W)
        exposure: Tensor of shape (4, 4) containing color transform and bias
        
    Returns:
        Tensor of shape (3, H, W)
    """
    # Permute from (3, H, W) to (H, W, 3)
    permuted_image = rendered_image.permute(1, 2, 0)
    
    # Multiply by 3x3 color transform matrix
    # exposure[:3, :3] is shape (3, 3)
    transformed = torch.matmul(permuted_image, exposure[:3, :3])
    
    # Add 3D bias vector, broadcasting to (H, W, 3)
    # exposure[:3, 3] is shape (3,)
    biased = transformed + exposure[:3, 3, None, None]
    
    # Permute back to (3, H, W)
    output = biased.permute(2, 0, 1)
    
    return output
```

**Parameters:**
- Exposure matrix: Learned per image, stored in a lookup table indexed by image name [S1, unofficial].
- Typical values: Not given in the sources.

**Edge Cases and Pitfalls:**
- Requires exposure data to be stored and retrievable by image name [S1, unofficial].
- Permutation operations must match tensor dimensions exactly to avoid shape mismatches [S1, unofficial].
- If the exposure tensor is not properly initialized, the transform may produce invalid colors [G].

## Subtopics

### [ExpModel](14212-expmodel.md)
ExpModel is a learned colorization module that applies a per-image 3x3 color transform and 3D bias vector to a rendered RGB image to match training-time exposure conditions. It operates as a conditional neural network that maps a scalar condition (temperature for white balance, exposure for log-scale adjustment) to a color correction factor. It builds on [Trained Exposure Application](13959-trained-exposure-application.md) by providing the specific parameterized functions for white balance and exposure adjustments within that framework.

## Operating characteristics
- Time complexity: $O(H \cdot W)$ for the matrix multiplication and addition, where $H$ and $W$ are image dimensions [S1, unofficial].
- Memory complexity: $O(H \cdot W)$ for the input and output tensors, plus constant space for the exposure matrix [S1, unofficial].
- Measured performance: Not given in the sources.
- Scaling: Linear with respect to image resolution [S1, unofficial].
- Strengths: Simple, fast, and differentiable; allows per-image customization [S1, unofficial].
- Limitations: Requires pre-computed exposure data for each image; does not handle semantic content [S1, unofficial].
- When to use: When per-image color correction is needed to match training conditions [S1, unofficial].
- When not to use: When semantic consistency or texture transfer is required [S1, unofficial].

Origin: The method is part of the Improved-GS project by XiaoBin2001 [S1, unofficial].
History: It was introduced as an improvement to standard Gaussian Splatting rendering pipelines to handle exposure variations [S1, unofficial].
