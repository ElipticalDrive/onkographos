# Reference Based Color Transfer for Medical Volume Rendering

Also called: Deep Semantic Color Transfer

## Overview
This method automates the colorization of monochromatic medical volume data (CT/MRI) by transferring visual attributes from a database of colored reference images (e.g., cryosections) using deep semantic correspondence, thereby eliminating the need for manual transfer function tuning [S1, unofficial]. It distinguishes itself from traditional volume rendering by replacing user-defined color/opacity parameters with automatic color transfer and luminance-based opacity, and from learning-based colorization by requiring only a small set of reference images rather than large-scale training datasets [S1, unofficial].

## How it works
**Inputs:**
1.  Target stack: A sequence of monochromatic medical images (CT or MRI slices) $T_i$.
2.  Reference database: A set of colored reference images $R_j$ (e.g., histological cryosections) semantically aligned with the target anatomy.

**Outputs:**
1.  Colorized volume stack: A sequence of RGBA images where RGB channels contain transferred color and the Alpha channel contains opacity derived from target luminance.
2.  Rendered 3D volume: Direct volume rendering of the colorized stack.

**Data Structures:**
*   **Feature Maps:** Multi-level feature tensors extracted from a pre-trained CNN. For VGG-19, these are typically the output feature maps from intermediate convolutional layers (e.g., conv1_2, conv2_2, conv3_3, conv4_3, conv5_3) [S1, unofficial].
*   **Correspondence Field:** A dense mapping derived from PatchMatch in the deep feature domain, aligning pixels in $T$ to pixels in $R$ [S1, unofficial].
*   **Intermediate Image ($T'$):** The result of the deep image analogy process, containing both structure of $T$ and visual attributes (color, texture, style) of $R$ [S1, unofficial].
*   **Colorized Image ($C$):** The final output after filtering, containing only the transferred color information [S1, unofficial].

**Parameters:**
*   **Feature Extractor:** VGG-19 network, pre-trained on ImageNet [S1, unofficial].
*   **Dense Matching Algorithm:** Deep Image Analogy using PatchMatch in the deep feature domain [S1, unofficial].
*   **Filter:** Guided Image Filter (GIF) [S1, unofficial].
*   **Opacity Mapping:** Direct mapping of voxel luminance to alpha channel [S1, unofficial].

**Steps:**

1.  **Reference Recommendation:** For each target slice $T$, compute deep features using VGG-19. Select the most semantically similar reference image $R$ from the database based on feature similarity [S1, unofficial].
2.  **Deep Feature Extraction:** Extract multi-level feature maps for both the target image $T$ and the selected reference image $R$ using the VGG-19 network [S1, unofficial].
3.  **Dense Correspondence:** Use the PatchMatch algorithm in the deep feature domain to find a dense correspondence between $T$ and $R$. This constructs an intermediate image $T'$ that retains the structural content of $T$ but adopts the visual attributes (color, texture, style) of $R$ [S1, unofficial].
4.  **Color Isolation:** Apply a Guided Image Filter to $T'$ using $T$ as the guidance image. This step discards texture and style artifacts transferred from $R$, preserving only the color information to produce the final colorized image $C$ [S1, unofficial].
5.  **Volumetric Mapping:**
    *   **Color (RGB):** Assign the RGB channels of the colorized image $C$ to the corresponding voxel in the volume [S1, unofficial].
    *   **Opacity (Alpha):** Calculate the luminance $L$ of the original target voxel $T$. Map $L$ directly to the alpha channel $\alpha$ [S1, unofficial].
6.  **Volume Rendering:** Perform direct volume rendering (ray casting) on the stack of colorized images using the derived RGBA values [S1, unofficial].

def transfer_color(target_image, reference_image):
    """
    Transfers color from reference to target using Deep Image Analogy and Guided Filter.
    """
    # Step 1: Extract multi-level features
    t_features = extract_features(target_image, layers=['conv1_2', 'conv2_2', 'conv3_3', 'conv4_3', 'conv5_3'])
    r_features = extract_features(reference_image, layers=['conv1_2', 'conv2_2', 'conv3_3', 'conv4_3', 'conv5_3'])
    
    # Step 2: Dense correspondence in deep feature domain
    # Constructs intermediate image T' with structure of T and attributes of R
    intermediate_image = deep_patch_match(t_features, r_features)
    
    # Step 3: Color isolation using Guided Image Filter
    # Use target image as guidance to preserve structure and remove texture/style
    colorized_image = guided_image_filter(intermediate_image, target_image)
    
    return colorized_image

def map_to_volume(colorized_image, original_target_image):
    """
    Maps colorized image to volume RGBA representation.
    """
    # RGB channels come from the colorized image
    rgba_volume = np.zeros((*colorized_image.shape, 4))
    rgba_volume[:, :, 0:3] = colorized_image
    
    # Alpha channel comes from luminance of the original target
    # Luminance calculation (standard ITU-R BT.601 or similar)
    # Assuming RGB input for luminance calculation
    luminance = 0.299 * original_target_image[:, :, 0] + \
                0.587 * original_target_image[:, :, 1] + \
                0.114 * original_target_image[:, :, 2]
    
    # Normalize luminance to [0, 1] if necessary, then assign to alpha
    rgba_volume[:, :, 3] = luminance
    
    return rgba_volume

def render_volume(volume_rgba):
    """
    Performs direct volume rendering (ray casting) on the RGBA volume stack.
    """
    # Standard ray casting implementation using the RGBA values

    rendered_image = ray_cast(volume_rgba)

def main(target_stack, reference_database):
    colorized_stack = []
    for target_slice in target_stack:
        # 1. Recommend reference
        ref_slice = reference_recommendation(target_slice, reference_database, vgg_model)
        
        # 2. Transfer color
        colorized_slice = transfer_color(target_slice, ref_slice)
        
        # 3. Map to volume
        rgba_slice = map_to_volume(colorized_slice, target_slice)
        
        colorized_stack.append(rgba_slice)

    return final_render

## Operating characteristics
*   **Time Complexity:** Dominated by the deep feature extraction (VGG-19) and the PatchMatch algorithm for each target-reference pair. The Guided Image Filter is linear in the number of pixels.
*   **Memory Complexity:** Requires storing feature maps for multiple layers of VGG-19 for both target and reference images during the correspondence step.
*   **Strengths:** Eliminates tedious manual interaction with transfer functions; leverages semantic understanding of anatomy via deep features; requires fewer reference images than end-to-end learning methods [S1, unofficial].
*   **Limitations:** Relies on the availability of semantically similar reference images (e.g., cryosections); does not automatically determine optimal opacity parameters from a transfer function, relying solely on luminance which may not always represent tissue visibility accurately [S1, unofficial].
*   **When to use:** When manual transfer function tuning is prohibitive and high-quality reference images (like histological slices) are available for the specific anatomical region.
*   **When not to use:** When reference images are unavailable or semantically mismatched; when precise opacity control based on physical properties (e.g., density) is required beyond simple luminance mapping.

## Background
The method was proposed by Devkota et al. in 2020/2022, extending the work of Liao et al. on Deep Image Analogy [S1, unofficial]. It addresses the challenge of visualizing monochromatic medical images (CT/MRI) by transferring color from colored reference images (cryosections) from the Visible Human Project [S1, unofficial]. The approach builds on the principle of reference image guided colorization, adapting it for volumetric data by processing slices individually and rendering the resulting colorized stack [S1, unofficial].
