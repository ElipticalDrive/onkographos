# Iterative Color Matching
## Overview
Iterative Color Matching warps the colors of an input image to match a reference image by iteratively solving for a quadratic color transformation using least squares [S1, S2, unofficial]. It differs from static color mapping methods by handling non-linear transformations and actively managing pixel clipping artifacts through iterative masking of unclipped pixels [S1, S2, unofficial].

## How it works
**Inputs and Outputs**
- Input: `img` (input image), `ref` (reference image). Both are assumed to be in the range $[0, 1]$ with $C$ channels (typically 3 for RGB) [G].
- Output: `img_warped` (warped input image matching the reference color distribution).

**Data Structures**
- `img_mat`, `ref_mat`: 2D matrices of shape $(-1, C)$ representing flattened input and reference pixels [S2, unofficial].
- `a_mat`: 2D matrix of shape $(-1, K)$ representing the quadratic expansion of the input pixels, where $K$ is the number of basis functions [G].
- `warp`: 2D matrix of shape $(K, C)$ containing the learned transformation coefficients for each output channel [G].
- `mask`: Boolean matrix of shape $(-1, C)$ indicating valid (unclipped) pixels for the least squares solve [G].

**Parameters**
- `num_iters`: Number of iterations for the color matching process. Default is 5 [S1, S2, unofficial].
- `eps`: Clipping threshold for unclipped pixels. Pixels with values in $[0, \text{eps})$ or $(1-\text{eps}, 1]$ are considered saturated/clipped. Default is $0.5/255$ [S1, S2, unofficial].

**Algorithm Steps**
1. Flatten `img` and `ref` into matrices `img_mat` and `ref_mat` of shape $(-1, C)$ [S2, unofficial].
2. Define `is_unclipped(z)` as `z >= eps & z <= 1 - eps` [S1, S2, unofficial].
3. Initialize `mask0` as a boolean matrix of shape $(-1, C)$ where `mask0[i, c]` is `True` if `img_mat[i, c]` is unclipped according to `is_unclipped` [S2, unofficial].
4. Loop `num_iters` times:
    a. Construct `a_mat` by concatenating quadratic terms (`img_c * img_c'`), linear terms (`img_mat`), and bias terms (`1`) for each channel [S2, unofficial]. For an input pixel vector $\mathbf{x} \in \mathbb{R}^C$, the corresponding row contains $x_c \cdot x_{c'}$ for all $c, c' \in \{0, \dots, C-1\}$, followed by $x_c$ for all $c$, followed by a single bias term $1$. The total number of columns is $K = \frac{C(C+1)}{2} + C + 1$ [G].
    b. Initialize `warp` as a zero matrix of shape $(K, C)$ [G].
    c. For each output channel $c \in \{0, \dots, C-1\}$:
        i. Set the target vector `b` as `ref_mat[:, c]` [S2, unofficial].
        ii. Compute the current mask for channel $c$: `mask[:, c] = mask0[:, c] & is_unclipped(img_mat[:, c]) & is_unclipped(b)` [S2, unofficial]. This ensures only pixels that are unclipped in the input, unclipped in the current estimate, and unclipped in the reference are used [S1, S2, unofficial].
        iii. Extract `masked_a_mat` from `a_mat` using `mask[:, c]` [S2, unofficial].
        iv. Extract `masked_b` from `b` using `mask[:, c]` [S2, unofficial].
        v. Solve the least squares problem $\min_w \| \text{masked\_a\_mat} \cdot w - \text{masked\_b} \|^2$ to find the coefficient vector $w$ for channel $c$ [S2, unofficial].
        vi. Store $w$ in `warp[:, c]` [S2, unofficial].
    d. Apply the warp to update `img_mat`: `img_mat = clip(matmul(a_mat, warp), 0, 1)` [S2, unofficial].
5. Reshape `img_mat` back to the original image shape to produce `img_warped` [S2, unofficial].

**Pseudocode**
```python
import numpy as np

def iterative_color_matching(img, ref, num_iters=5, eps=0.5/255):
    """
    Warps input image colors to match a reference image using iterative least squares.
    
    Args:
        img: Input image array of shape (H, W, C) with values in [0, 1].
        ref: Reference image array of shape (H, W, C) with values in [0, 1].
        num_iters: Number of iterations.
        eps: Clipping threshold.
        
    Returns:
        img_warped: Warped image array of shape (H, W, C).
    """
    # Flatten images
    img_mat = img.reshape(-1, img.shape[-1])
    ref_mat = ref.reshape(-1, ref.shape[-1])
    C = img_mat.shape[1]
    N = img_mat.shape[0]
    
    # Helper for unclipped check
    def is_unclipped(z):
        return (z >= eps) & (z <= 1 - eps)
    
    # Initialize mask for unclipped pixels in input
    mask0 = is_unclipped(img_mat)
    
    for i in range(num_iters):
        # Construct a_mat for current img_mat
        # Quadratic terms: x_c * x_c' for c <= c'
        quad_terms = []
        for c1 in range(C):
            for c2 in range(c1, C):
                quad_terms.append((img_mat[:, c1] * img_mat[:, c2]).reshape(-1, 1))
        
        # Linear terms
        linear_terms = img_mat
        
        # Bias term
        bias_terms = np.ones((N, 1))
        
        # Concatenate
        a_mat = np.concatenate(quad_terms + [linear_terms, bias_terms], axis=1)
        
        # Initialize warp coefficients
        warp = np.zeros((a_mat.shape[1], C))
        
        for c in range(C):
            b = ref_mat[:, c]
            
            # Update mask: unclipped in input, unclipped in current img estimate, unclipped in ref
            current_img_unclipped = is_unclipped(img_mat[:, c])
            ref_unclipped = is_unclipped(b)
            mask = mask0[:, c] & current_img_unclipped & ref_unclipped
            
            # Masked matrices
            masked_a = a_mat[mask]
            masked_b = b[mask]
            
            # Solve least squares
            # w = argmin || masked_a @ w - masked_b ||^2
            w, _, _, _ = np.linalg.lstsq(masked_a, masked_b, rcond=-1)
            warp[:, c] = w
            
        # Apply warp
        img_mat = np.clip(a_mat @ warp, 0, 1)
        
    # Reshape back
    img_warped = img_mat.reshape(img.shape)
    return img_warped
```

## Operating characteristics
- Time and memory complexity: Not given in the sources.
- Strengths: Handles non-linear color mappings effectively. Iterative masking reduces the impact of clipped pixels, which are common in HDR or high-contrast images [S1, S2, unofficial].
- Limitations: Computationally expensive for large images due to the quadratic expansion. Sensitive to the choice of `eps`; too small a value may include noisy clipped pixels, too large a value may discard valid data [G].
- When to use: When static color correction fails to match complex non-linear color distributions between two images [S1, S2, unofficial].
- When not to use: For real-time applications or very large images where performance is a concern [G].

## Background
Iterative Color Matching is used in computer vision and graphics for color correction and style transfer. It is implemented in projects such as AnySplat and mrGSplat [S1, S2, unofficial]. The method relies on iterative least squares estimation to handle non-linearities and clipping, which are common challenges in image processing [S1, S2, unofficial].
