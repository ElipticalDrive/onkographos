# Clamping

Also called: Range Clamping, Scalar Clamping

## Overview
Clamping is a technique to handle scalar values outside the defined transfer function range by mapping them to boundary colors or black [S1]. It explicitly defines the behavior for out-of-range scalars, mapping values below the lower bound to the first node color and values above the upper bound to the last node color when enabled [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A scalar value $s$ from the volume data; the transfer function range $[x_1, x_2]$; the transfer function node colors $C_{first}$ (at $x_1$) and $C_{last}$ (at $x_2$); a boolean flag `clamping_on` [S1].
*   **Output:** A color $C_{out}$ (typically RGBA) [S1].

**Data Structures:**
The transfer function stores nodes regularly spaced between $x_1$ and $x_2$ [S1]. For clamping, only the first node (at lower bound $x_1$) and the last node (at upper bound $x_2$) are strictly required for the boundary mapping [S1].

**Steps:**
1.  Check the state of the `clamping_on` flag [S1].
2.  If `clamping_on` is true:
    *   If $s < x_1$, set $C_{out} = C_{first}$ [S1].
    *   If $s > x_2$, set $C_{out} = C_{last}$ [S1].
    *   If $x_1 \le s \le x_2$, proceed with standard interpolation between nodes [S1].
3.  If `clamping_on` is false:
    *   If $s < x_1$ or $s > x_2$, set $C_{out} = \text{Black}$ [S1].
    *   If $x_1 \le s \le x_2$, proceed with standard interpolation [S1].

**Formulas:**
For $x_1 \le s \le x_2$, the output color is computed via linear interpolation: $C_{out} = C_{first} + \frac{s - x_1}{x_2 - x_1} (C_{last} - C_{first})$ [G].

**Pseudocode:**
```python
def clamp_color(s, x1, x2, C_first, C_last, clamping_on):
    """
    Map scalar s to color using clamping logic.
    s: scalar value from volume
    x1: lower bound of transfer function range
    x2: upper bound of transfer function range
    C_first: color at x1
    C_last: color at x2
    clamping_on: boolean flag
    """
    if clamping_on:
        if s < x1:
            return C_first
        elif s > x2:
            return C_last
        else:
            # Standard linear interpolation between C_first and C_last [G]
            t = (s - x1) / (x2 - x1)
            return (C_first[0] + t * (C_last[0] - C_first[0]),
                    C_first[1] + t * (C_last[1] - C_first[1]),
                    C_first[2] + t * (C_last[2] - C_first[2]),
                    C_first[3] + t * (C_last[3] - C_first[3]))
    else:
        if s < x1 or s > x2:
            return (0.0, 0.0, 0.0, 0.0) # Black
        else:
            # Standard linear interpolation between C_first and C_last [G]
            t = (s - x1) / (x2 - x1)
            return (C_first[0] + t * (C_last[0] - C_first[0]),
                    C_first[1] + t * (C_last[1] - C_first[1]),
                    C_first[2] + t * (C_last[2] - C_first[2]),
                    C_first[3] + t * (C_last[3] - C_first[3]))
```

**Parameters:**
*   `clamping_on`: Boolean flag that controls whether out-of-range values map to boundary colors or black [S1].

## Subtopics

### [Sigmoid Clamping](13010-sigmoid-clamping.md)
Sigmoid Clamping is a non-linear mapping technique that smooths and clips scalar values into the normalized range $[0, 1]$. It serves as a robust boundary handler for objective functions or transfer function inputs, preventing outliers from disrupting optimization or rendering by providing a soft transition at the boundaries rather than a hard cutoff. It differs from standard [Clamping](11530-clamping.md) by introducing a sigmoidal slope near the edges, which preserves gradient information for differentiable pipelines.
