# Sigmoid Clamping
Also called: Smoothing and Clipping Function (ξ), Soft Clamping
## Overview
Sigmoid Clamping smooths and clips scalar objective function values to the range $[0, 1]$ [S1, unofficial]. It differs from hard [Clamping](11530-clamping.md) by using a sigmoidal transition near the boundaries to preserve differentiability for optimization [S1, unofficial].
## How it works
**Inputs and Outputs:**
- Input: A scalar value $x \in \mathbb{R}$.
- Output: A scalar value $\xi(x) \in [0, 1]$ [S1, unofficial].

**Parameters:**
- $\alpha_3$: A shape parameter controlling the steepness of the sigmoid transition, set to $3$ [S1, unofficial].

**Formula:**
The function is defined as [S1, unofficial]:
$$
\xi(x) = \max\left(0, \min\left(1, \frac{1}{3} \left[ 1 + e^{(-\alpha_3 e x) + (\alpha_3 0.5 e)} \right]^{-1} \right)\right)
$$
Where:
- $e$ is Euler's number [G].
- The exponent is $-\alpha_3 e x + \alpha_3 0.5 e$ [S1, unofficial].
- The outer $\max(0, \min(1, \dots))$ enforces the $[0, 1]$ bounds [S1, unofficial].

**Pseudocode:**
```python
import math

def sigmoid_clamping(x: float, alpha_3: float = 3.0) -> float:
    e = math.e
    exponent = (-alpha_3 * e * x) + (alpha_3 * 0.5 * e)
    sigmoid_term = 1.0 / (1.0 + math.exp(exponent))
    scaled = (1.0 / 3.0) * sigmoid_term
    return max(0.0, min(1.0, scaled))
```

**Edge Cases and Pitfalls:**
- The outer clamping handles numerical overflow or underflow from the exponential term [G].
- The $1/3$ scaling factor bounds the unclamped sigmoid output to $[0, 1/3]$ before the final clamp [S1, unofficial].
## Subtopics

### Truncated Exponential Activation
A variant that applies the exponential function directly to the input, but clamps the pre-activation value to $[-15, 15]$ during the backward pass [S2, unofficial].
- **Forward:** Compute $y = \exp(x)$ [S2, unofficial].
- **Backward:** Compute gradient $dL/dx = dL/dy \cdot \exp(\text{clamp}(x, -15, 15))$ [S2, unofficial].
- **Parameter:** Clamp bounds $[-15, 15]$ applied to $x$ before exponentiation in the gradient calculation [S2, unofficial].
- **Implementation:**
```python
def truncated_exponential_forward(x):
    return math.exp(x)

def truncated_exponential_backward(dL_dout, x):
    x_clamped = max(-15.0, min(15.0, x))
    return dL_dout * math.exp(x_clamped)
```

## Operating characteristics
- **Time Complexity:** $O(1)$ per element, requiring one exponential, one addition, one division, and two comparisons [G].
- **Memory Complexity:** $O(1)$ auxiliary memory [G].
- **Strengths:** Differentiable almost everywhere and provides soft boundaries beneficial for gradient-based optimization of objective functions [S1, unofficial].
- **Limitations:** The specific scaling factor and parameterization are tailored to the SOARNet objective functions and may require re-tuning for general volume rendering transfer functions [S1, unofficial].
- **When to use:** When smoothing objective function scores before aggregation or loss calculation [S1, unofficial].
## Background
Sigmoid Clamping was introduced in the SOARNet architecture for active view planning in NeRF to normalize objective functions $f_C, f_Q, f_D, f_T$ to $[0, 1]$ [S1, unofficial]. The Truncated Exponential variant is documented in the `ngp_pl` repository [S2, unofficial].
