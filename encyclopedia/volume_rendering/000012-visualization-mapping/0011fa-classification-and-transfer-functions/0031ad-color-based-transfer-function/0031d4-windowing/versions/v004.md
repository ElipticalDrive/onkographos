# Windowing

Also called: Window Specification, Window/Level

## Overview
Windowing is a scalar-to-color mapping technique that restricts the visualization to a specific range of data values, mapping those values to a linear grayscale ramp while clamping out-of-range values to black or white [S1, unofficial]. It solves the problem of low contrast in volumetric data by isolating a "window" of interest (e.g., soft tissue) from the full data range, preventing background noise or irrelevant high-intensity structures (e.g., bone) from obscuring the target features [S1, unofficial]. Unlike [Colormap Application for Visualization](7714-colormap-application-for-visualization.md), which maps the entire domain to a spectrum, or [Clamping](11530-clamping.md), which maps out-of-range values to the boundary colors of the transfer function, windowing explicitly discards out-of-range information into neutral background colors [S1, unofficial][S2].

## How it works
**Inputs and Outputs**
*   Input: A scalar data value $x$ [S1, unofficial].
*   Parameters: Window center $c$ (the midpoint of the range) and window width $w$ (where $w \ge 1$) [S1, unofficial].
*   Output: A color value $C$ in the range $[0, 1]$ [S1, unofficial].

**Data Structures**
No complex data structures are required; the method operates directly on scalar parameters $c$, $w$, and input $x$ [S1, unofficial].

**Steps and Formula**
The mapping is defined by a piecewise linear function [S1, unofficial]. The lower bound of the window is $L = c - 0.5 - (w-1)/2$ and the upper bound is $R = c - 0.5 + (w-1)/2$ [S1, unofficial].
1. If $x \le L$, set $C = 0$ (black) [S1, unofficial].
2. Else if $x > R$, set $C = 1$ (white) [S1, unofficial].
3. Else, calculate $C$ using the linear interpolation: $C = \frac{x - (c - 0.5)}{w - 1} + 0.5$ [S1, unofficial].

**Pseudocode**
```python
def windowing(x: float, c: float, w: float) -> float:
    """
    Maps scalar value x to grayscale C using window center c and width w.
    Implements the piecewise linear mapping from [S1, unofficial].
    """
    lower_bound = c - 0.5 - (w - 1) / 2
    upper_bound = c - 0.5 + (w - 1) / 2
    
    if x <= lower_bound:
        return 0.0
    elif x > upper_bound:
        return 1.0
    else:
        return (x - (c - 0.5)) / (w - 1) + 0.5
```

**Parameters**
*   $c$: Center of the window [S1, unofficial].
*   $w$: Width of the window, constrained to $w \ge 1$ [S1, unofficial].
*   $x$: Input data value [S1, unofficial].
*   Typical values depend on the data type (e.g., Hounsfield units in CT) [G].

**Edge Cases and Pitfalls**
*   **Division by Zero:** The source specifies $w \ge 1$, but the denominator $(w-1)$ suggests $w > 1$ is required for the ramp [S1, unofficial]. Tracing the bounds reveals that when $w=1$, $L = R = c - 0.5$. The condition $x \le L$ catches all $x \le c - 0.5$, and $x > R$ catches all $x > c - 0.5$, leaving the `else` branch unreachable. Thus, division by zero is avoided in execution [G].
*   **Precision:** Floating-point comparisons at the boundaries $L$ and $R$ must use `<=` and `>` consistently to prevent gaps or overlaps in the mapping [G].

## Subtopics

### [Channel Window and Transfer Function Initialization](8807-channel-window-and-transfer-function-initialization.md)
This method initializes transfer function parameters for a multi-material volume renderer by mapping specific data value ranges to opacity profiles for background, tumor, vessel, and bone materials. It differs from generic windowing by hardcoding material-specific opacity ramps based on fixed sample value thresholds rather than deriving them dynamically from user-defined color maps.

### [Clamping](11530-clamping.md)
Clamping is a boundary handling technique in color-based transfer functions that maps scalar values outside the defined data range to the boundary colors of the transfer function, rather than to black or white [11530-clamping.md]. It differs from its parent [Windowing](6611-windowing.md) by preserving the visual continuity of the extreme values instead of clipping them to the background, and from its sibling [Channel Window and Transfer Function Initialization](8807-channel-window-and-transfer-function-initialization.md) by explicitly defining the behavior for out-of-range scalars [11530-clamping.md].

### Narrow Interval Weighting
Narrow Interval Weighting is a weighting function that is 1 for values in a specific narrow range and 0 elsewhere, used to focus error reduction on salient intervals [S2]. It differs from wide-interval weighting (uniformly 1) by covering only the minimal interval widths needed to cover non-transparent portions of color-opacity transfer functions, yielding results closer to ground truth [S2]. A key pitfall is that artifacts typical of block-wise downsampling, including smoothing effects and discontinuities at block boundaries, become more pronounced as the interval width increases [S2]. For the QVAPOR variable in climate test data, RMS error increases as the interval width increases from 0.1 to 0.9 [S2].

## Background
Windowing is one of the simplest transfer functions, introduced in early volume visualization literature as a method to map a range of data values ("window") to a linear ramp of grayscales [S1, unofficial]. It is commonly defined by its center $c$ and width $w$ [S1, unofficial]. Histograms of the data values are often used to guide the selection of window parameters, allowing users to identify peaks corresponding to specific tissues (e.g., fat, tissue, bone) [S1, unofficial]. The technique is widely used in medical imaging (e.g., CT scans) where specific tissue windows (e.g., "Brain Window", "Tissue Window") are standard [S1, unofficial].
