# Artistic Volume Rendering Template

Also called: Artistic Style Rendering

## Overview
A direct volume rendering technique that maps volumetric data attributes to visual artistic styles using fuzzy-logic rules, allowing for selective and gradual application of rendering effects [S1]. It differs from standard volume rendering by decoupling color evaluation into prioritized styles that are composited like layers in image editing software, and from sibling semantic methods by relying on shader templates parameterized by shaded sphere images rather than complex semantic models or analogies [S1].

## How it works
**Inputs:** Volumetric dataset, viewing rays, fuzzy logic rule outputs (defuzzified floating-point values for each style), style transfer functions (sets of images of shaded spheres), and a priority list for styles [S1].
**Outputs:** Final pixel color for each viewing ray [S1].

**Data Structures:**
*   **Style Transfer Function:** A collection of images representing shaded spheres, indexed by the surface normal of the current sample in eye-space [S1].
*   **Defuzzified Values:** A set of floating-point numbers, one per style, representing the degree to which the current sample belongs to that style [S1].

**Steps:**
1.  Cast viewing rays through the volume at equidistant sample positions [S1].
2.  For each sample position, evaluate the opacity transfer function to determine visibility [S1].
3.  If opacity is greater than zero, evaluate the fuzzy logic rules to obtain a defuzzified floating-point value for each artistic style [S1].
4.  Determine the normal of the current sample in eye-space [S1].
5.  Use this normal to index the corresponding image in the style transfer function for each active style [S1].
6.  Retrieve the color for each style from the indexed sphere image [S1].
7.  Composite the colors of all active styles from bottom to top based on their assigned priority, following standard image manipulation compositing schemes (e.g., "over" operator) [S1].

**Formulas:**
*   **Color Retrieval:** $C_{\text{style}} = \text{Lookup}(\text{StyleImage}, \mathbf{n}_{\text{eye}})$, where $\mathbf{n}_{\text{eye}}$ is the sample normal in eye-space [S1].
*   **Compositing:** Styles are composited sequentially; if style $A$ has higher priority than style $B$, $A$ is composited over $B$, and the final color depends on this priority order [S1].

**Parameters:**
*   **Priority List:** Defined by the user or fuzzy rules [S1].

**Edge Cases and Pitfalls:**
*   **Compositing Order:** The final color is highly sensitive to the priority order of styles; if style $A$ is prioritized over style $B$, $A$'s color dominates, whereas prioritizing $B$ over $A$ makes $B$'s color dominate [S1].
*   **Normal Indexing:** The normal must be correctly transformed to eye-space to index the sphere images accurately [S1].

**Pseudocode:**
```python
def length(v):
    return (v[0]**2 + v[1]**2 + v[2]**2)**0.5

def artistic_volume_rendering(ray_origin, ray_direction, ray_length, step_size, volume, styles, priorities):
    # ray_origin, ray_direction: 3D vectors
    # ray_length: float
    # step_size: float (equidistant sampling distance)
    # volume: object with sample(pos) -> scalar and get_normal(pos) -> 3D vector
    # styles: list of dicts with keys 'sphere_image' and 'defuzzified_value'
    # priorities: list of style indices sorted bottom-to-top (first element is bottom)
    
    accum_alpha = 0.0
    final_color = [0.0, 0.0, 0.0, 0.0]
    
    t = 0.0
    while t < ray_length:
        sample_pos = [ray_origin[i] + ray_direction[i] * t for i in range(3)]
        sample_value = volume.sample(sample_pos)
        
        # Evaluate opacity transfer function
        opacity = max(0.0, min(1.0, sample_value))
        
        if opacity > 0.0:
            # Get normal in eye-space
            normal_eye = volume.get_normal(sample_pos)
            normal_eye = [n / length(normal_eye) for n in normal_eye]
            
            # Composite styles for this sample (bottom to top)
            sample_color = [0.0, 0.0, 0.0, 0.0]
            sample_alpha = 0.0
            
            for idx in priorities:
                style = styles[idx]
                # Standard texture sampling indexed by normal [G]
                style_color = style['sphere_image'].sample(normal_eye)
                # Combine defuzzified value with sample opacity
                style_alpha = style['defuzzified_value'] * opacity
                
                # Front-to-back compositing of styles (Over operator)
                sample_color = [
                    style_color[0] * style_alpha + sample_color[0] * (1.0 - style_alpha),
                    style_color[1] * style_alpha + sample_color[1] * (1.0 - style_alpha),
                    style_color[2] * style_alpha + sample_color[2] * (1.0 - style_alpha),
                    style_color[3] * style_alpha + sample_color[3] * (1.0 - style_alpha)
                ]
                sample_alpha += style_alpha * (1.0 - sample_alpha)
                if sample_alpha >= 1.0:
                    break
            
            # Composite sample into ray
            final_color = [
                sample_color[0] * sample_alpha + final_color[0] * (1.0 - sample_alpha),
                sample_color[1] * sample_alpha + final_color[1] * (1.0 - sample_alpha),
                sample_color[2] * sample_alpha + final_color[2] * (1.0 - sample_alpha),
                sample_color[3] * sample_alpha + final_color[3] * (1.0 - sample_alpha)
            ]
            accum_alpha += sample_alpha * (1.0 - accum_alpha)
            if accum_alpha >= 1.0:
                break
        
        t += step_size
        
    return final_color
```

## Subtopics

### Flat Rendering Mode Template
Extends the artistic volume rendering template to emphasize spatial relations or hide structures by ignoring lower-priority regions [S1]. Each style has a priority, and higher-priority regions overdraw lower-priority ones [S1]. Along a viewing ray, common compositing is performed until a region of higher priority is reached [S1]. When entering a higher-priority region at position $x_i$, the ray color $c_r(x_i)$ is updated using the formula $c_r(x_i) = c_r(x_{i-1}) \times (1 - p_f)$, where $x_{i-1}$ is the previous sample position and $p_f$ is the flatness parameter [S1]. The flatness parameter $p_f$ controls the trade-off between showing spatial relationships and showing important regions: $p_f=0$ results in common volume rendering, while $p_f=1$ always shows regions with the highest priority [S1].

## Background
Introduced by Rautek et al. in 2008 as part of their work on interaction-dependent semantics for illustrative volume rendering [S1]. It builds on the concept of fuzzy-logic rule-based semantic layers to provide a flexible framework for artistic volume rendering [S1].
