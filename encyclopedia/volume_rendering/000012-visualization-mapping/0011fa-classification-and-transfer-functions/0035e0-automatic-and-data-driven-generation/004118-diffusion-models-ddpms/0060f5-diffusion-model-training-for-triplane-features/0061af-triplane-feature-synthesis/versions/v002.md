# Triplane Feature Synthesis

Also called: EG3D Triplane Synthesis, EG3D-style backbone, StyleGAN Triplane Generation, Triplanar NeRF Generator (EG3D-style backbone), triplanar decoder

## Overview
Triplane Feature Synthesis generates expressive 3D features by representing a scene as three orthogonal 2D feature planes (xy, xz, yz) conditioned on a latent code [S1, S2]. It differs from standard triplanar decoders by employing extra synthesis blocks for disentanglement, allowing plane-specific kernels to attend to features in each separate plane [S1].

## How it works
**Inputs:**
*   A prior noise vector $z \sim \mathcal{N}(0, I)$ [S2].
*   A 3D point coordinate $x \in \mathbb{R}^3$ for feature query [S1, S2].

**Outputs:**
*   A synthesized triplane feature tensor $T$ [S1, S2].
*   A final feature vector for point $x$, derived from $T$ [S1, S2].

**Data Structures:**
*   **Latent Code $w$**: Intermediate latent code residing in the W space, output of the mapping network [S2].
*   **Initial Triplane $T'$**: Output of the StyleGAN2 generator layers, before disentanglement blocks [S1].
*   **Feature Planes**: Three orthogonal 2D planes corresponding to xy, xz, and yz coordinate projections [S2]. Each plane is queried at 3D coordinates via bilinear sampling [S2].
*   **MLP**: A "tiny MLP" (triplanar decoder) that takes combined features as input to output final representation values (e.g., radiance field density and color, or SDF/geometry features) [S1, S2].

**Steps:**
1.  **Latent Mapping**: Sample a prior vector $z$ from a standard normal distribution $\mathcal{N}(0, I)$ [S2]. Pass $z$ through a mapping network to produce the latent code $w$ in the W space [S2].
2.  **Initial Synthesis**: Feed $w$ into a StyleGAN2 generator to produce an output feature map [S2]. This output forms the initial triplane $T'$ [S1].
3.  **Splitting**: Split the output feature map into three orthogonal planes corresponding to xy, xz, and yz coordinate projections [S2].
4.  **Disentanglement**: For each orthogonal plane $ij \in \{xy, xz, yz\}$, apply a `SynthesisBlock` to the features $f'_{ij}$ of $T'$ to generate expressive features $f_{ij}$ [S1]:
    $$f_{ij} = \text{SynthesisBlock}(f'_{ij})$$
    This design allows disentanglement between the intermediate triplane features, as plane-specific kernels can attend to the features in each separate plane [S1].
5.  **Feature Query**: To get features $T_x$ for a point $x$: Project $x$ to each of the three axis-aligned planes to obtain 2D coordinates [S1, S2]. Query each plane at these specific coordinates using bilinear sampling [S2].
6.  **Feature Combination**: Combine the three sampled feature vectors. Source [S1] specifies taking the Hadamard product of the three resultant vectors, while Source [S2] specifies summing them element-wise [S1, S2].
7.  **Decoding**: Pass the combined features into the triplanar decoder MLP to output the final representation [S1, S2].

**Parameters:**
*   **MLPSDF Initialization**: If using an SDF representation, the ReLU MLPSDF is initialized as in SAL [4] to ensure an approximately spherical SDF in the early part of training [S1].
*   **z**: Prior noise vector, sampled from $\mathcal{N}(0, I)$ [S2].
*   **w**: Intermediate latent code in W space [S2].

**Pseudocode:**
```python
import numpy as np

def triplane_synthesis(z, T_prime, decoder, use_hadamard=True):
    """
    Synthesize triplane features and query them for a point.
    
    Args:
        z: Noise vector from N(0, I).
        T_prime: Initial triplane feature map from StyleGAN2 generator.
        decoder: Triplanar decoder MLP.
        use_hadamard: If True, use Hadamard product for feature combination [S1].
                      If False, use summation [S2].
    Returns:
        final_features: Output of the decoder.
    """
    # Step 3: Disentanglement
    # Split T_prime into three orthogonal planes: xy, xz, yz
    # Assuming T_prime shape is (3, C, H, W)
    f_xy_prime, f_xz_prime, f_yz_prime = T_prime[0], T_prime[1], T_prime[2]
    
    # Apply SynthesisBlock to each plane for disentanglement [S1]
    # Sources do not specify the internal operations of the SynthesisBlock [S1]
    f_xy = f_xy_prime
    f_xz = f_xz_prime
    f_yz = f_yz_prime
    
    # Step 4: Feature Query for point x
    x = np.array([0.0, 0.0, 0.0]) # 3D point coordinate [S1, S2]
    
    # Project x to 2D coordinates for each plane
    coord_xy = (x[0], x[1])
    coord_xz = (x[0], x[2])
    coord_yz = (x[1], x[2])
    
    # Bilinear sampling at projected coordinates [S2]
    feat_xy = bilinear_sample(f_xy, coord_xy)
    feat_xz = bilinear_sample(f_xz, coord_xz)
    feat_yz = bilinear_sample(f_yz, coord_yz)
    
    # Combine features: sources specify either Hadamard product [S1] or summation [S2]
    if use_hadamard:
        combined_features = feat_xy * feat_xz * feat_yz
    else:
        combined_features = feat_xy + feat_xz + feat_yz
        
    # Step 5: Decoding
    final_features = decoder(combined_features)
    return final_features

def bilinear_sample(plane, coord):
    # Bilinear interpolation of a 2D feature plane at a specific coordinate [S2]
    # plane: 2D tensor of shape (C, H, W)
    # coord: tuple (u, v) normalized to [0, 1]
    u, v = coord
    h, w = plane.shape[1], plane.shape[2]
    u_idx = u * (w - 1)
    v_idx = v * (h - 1)
    u0, u1 = int(np.floor(u_idx)), int(np.ceil(u_idx))
    v0, v1 = int(np.floor(v_idx)), int(np.ceil(v_idx))
    u0, u1 = np.clip(u0, 0, w-1), np.clip(u1, 0, w-1)
    v0, v1 = np.clip(v0, 0, h-1), np.clip(v1, 0, h-1)
    w_u = u_idx - u0
    w_v = v_idx - v0
    val00 = plane[:, v0, u0]
    val01 = plane[:, v0, u1]
    val10 = plane[:, v1, u0]
    val11 = plane[:, v1, u1]
    top = val00 * (1 - w_u) + val01 * w_u
    bottom = val10 * (1 - w_u) + val11 * w_u
    return top * (1 - w_v) + bottom * w_v
```

**Edge Cases and Pitfalls:**
*   **Feature Combination**: Sources disagree on whether to use Hadamard product [S1] or summation [S2] for combining features from the three planes. The Hadamard product is associated with the EG3D-style backbone [S1], while summation is described in the unconditional generator pre-training [S2].
*   **Coordinate Normalization**: Bilinear sampling requires normalizing 3D coordinates to the 2D plane dimensions to avoid out-of-bounds access [G].

## Background
*   **Origin**: The method is based on EG3D [5] and StyleGAN2 [29] [S2]. It was introduced in the context of high-fidelity geometry in 3D GANs [S1] and single-image 3D reconstruction [S2].
*   **History**: The approach builds on previous work in 3D GANs and radiance field inversion [S1, S2].
