# Point Upsampling Diffusion

Also called: PDF Point Cloud Super-resolution, Point Super-resolution Diffusion

## Overview
Point Upsampling Diffusion is a generative method that samples a dense surface point cloud $x_d$ from a sparse input point cloud $x_s$ by progressively denoising Gaussian noise, conditioned on the sparse prior [S1]. It solves the lack of dense large-scale outdoor point cloud ground truth by learning a super-resolution distribution, enabling the generation of optional points for rendering stages to reduce sampling space [S1]. Unlike standard NeRF which samples individual points, this method samples regions rather than individual points from unbounded scenes, making it easier to fill sampled regions and complement the background for new viewpoint synthesis [S1].

## How it works
**Inputs and Outputs:**
- **Input:** A sparse point cloud $x_s \in \mathbb{R}^{M \times 3}$ reconstructed from images (e.g., via COLMAP) [S1].
- **Output:** A dense super-resolved point cloud $x_d \in \mathbb{R}^{N \times 3}$ [S1].

**Data Structures:**
The model operates on point clouds represented as sets of 3D coordinates. During training, three levels of point clouds are used:
1.  $x_s \in \mathbb{R}^{M \times 3}$: The original sparse reconstruction.
2.  $z_0 \in \mathbb{R}^{n \times 3}$: An intermediate sparse prior, downsampled from $x_s$ [S1].
3.  $x_0 \in \mathbb{R}^{m \times 3}$: The sparsest point cloud, downsampled from $z_0$ [S1].
The cardinalities satisfy $m < n < M < N$ [S1]. The target point cloud is defined as $x_0 = (z_0, \tilde{x}_0)$, where $z_0$ is the fixed prior shape and $\tilde{x}_0$ represents the diffused surface points to be generated [S1]. Intermediate states are $x_t = (z_0, \tilde{x}_t)$ [S1].

**Parameters:**
-   Diffusion steps: $T = 1000$ [S1].
-   Noise schedule: $\beta_0 = 10^{-4}$, $\beta_T = 0.01$, with linear interpolation for intermediate $\beta_t$ values [S1].
-   Optimizer: Adam with learning rate $2 \times 10^{-4}$ [S1].
-   Down-sampling retention rate: Random down-sampling with a retention rate between 0.2 and 1 for both samplings in the point cloud pair preparation [S1].

**Algorithm:**

1.  **Data Preparation:**
    -   Obtain a sparse point cloud $x_s$ from COLMAP reconstruction [S1].
    -   Downsample $x_s$ to create the prior $z_0$ using random down-sampling with a retention rate between 0.2 and 1 [S1].
    -   Downsample $z_0$ to create the sparsest input $x_0$ using random down-sampling with a retention rate between 0.2 and 1 [S1].
    -   Ensure $m < n < M < N$ [S1].

2.  **Forward Process (Noising):**
    -   The forward process adds Gaussian noise sequentially to the surface points $\tilde{x}$ while keeping the prior $z_0$ fixed.
    -   The transition probability is defined as:
        $$q(\tilde{x}_t | \tilde{x}_{t-1}, z_0) \triangleq \mathcal{N}(\tilde{x}_t; \sqrt{1 - \beta_t} \tilde{x}_{t-1}, \beta_t I)$$
        where $\beta_t$ is the noise variance at step $t$ [S1].
    -   The joint distribution of the forward process is:
        $$q(\tilde{x}_{0:T}, z_0) = q(\tilde{x}_0, z_0) \prod_{t=1}^{T} q(\tilde{x}_t | \tilde{x}_{t-1}, z_0)$$
        [S1].

3.  **Reverse Process (Denoising):**
    -   The network predicts the posterior distribution for a less noisy point cloud.
    -   The transition is defined as:
        $$p_\theta(\tilde{x}_{t-1} | \tilde{x}_t, z_0) \triangleq \mathcal{N}(\tilde{x}_{t-1}; \mu_\theta(\tilde{x}_t, z_0, t), \sigma_t^2 I)$$
        where $\mu_\theta(\tilde{x}_t, z_0, t)$ is the predicted shape at step $t-1$ [S1].
    -   The joint distribution of the reverse process is:
        $$p_\theta(\tilde{x}_{0:T}, z_0) = p(\tilde{x}_T, z_0) \prod_{t=1}^{T} p_\theta(\tilde{x}_{t-1} | \tilde{x}_t, z_0)$$
        [S1].

4.  **Training Loss:**
    -   The model is trained using a simplified L2 denoising loss:
        $$L_D = ||\epsilon - \epsilon_\theta(\tilde{x}_t, z_0, t)||^2$$
        where $\epsilon \sim \mathcal{N}(0, I)$ is the added random noise and $\epsilon_\theta(\tilde{x}_t, z_0, t)$ is the predicted noise output [S1].
    -   The prior $z_0$ is masked during loss minimization because it is fixed and unaffected by the diffusion process [S1].

5.  **Inference:**
    -   During testing, the sparse input $x_s$ is used as the prior (analogous to $z_0$ in training) to generate the dense point cloud $x_d$ [S1].
    -   The reverse process starts from Gaussian noise $\tilde{x}_T \sim \mathcal{N}(0, I)$ and iteratively denoises to $\tilde{x}_0$, which is combined with the prior to form the final dense cloud [S1].

import numpy as np

def prepare_training_data(x_s, retention_range=(0.2, 1.0)):
    """
    Prepare point cloud pairs for training.
    x_s: Sparse point cloud from COLMAP, shape (M, 3).
    Returns: z0 (prior), x0 (sparsest input).
    """
    # Downsample x_s to get z0
    # Random down-sampling with retention rate between 0.2 and 1
    rate_z = np.random.uniform(retention_range[0], retention_range[1])
    n = int(len(x_s) * rate_z)
    indices_z = np.random.choice(len(x_s), n, replace=False)
    z0 = x_s[indices_z]
    
    # Downsample z0 to get x0
    rate_x = np.random.uniform(retention_range[0], retention_range[1])
    m = int(len(z0) * rate_x)
    indices_x = np.random.choice(len(z0), m, replace=False)
    x0 = z0[indices_x]
    
    return z0, x0

    """
    Compute training loss for one step.
    """
    # Sample noise epsilon
    epsilon = np.random.normal(0, 1, size=x0.shape)
    
    # Add noise to get x_t
    # Using the forward transition from source Eq 1
    x_t = np.sqrt(1 - beta_t) * x0 + np.sqrt(beta_t) * epsilon
    
    # Predict noise
    epsilon_pred = model(x_t, z0, t)
    
    # Compute L2 loss
    loss = np.mean((epsilon - epsilon_pred) ** 2)
    
    return loss

## Operating characteristics
-   **Time Complexity:** Not given in the sources.
-   **Memory Complexity:** Not given in the sources.
-   **Measured Performance:** Trained on 4 A100 GPUs for around one day for the diffusion stage [S1]. The second stage (rendering optimization) took about 20 hours on a single A100 GPU [S1].
-   **Scaling:** The method is designed for large-scale outdoor scenes [S1].
-   **Strengths:** Reduces sampling space for rendering by providing dense optional points; complements background for new viewpoint synthesis [S1].
-   **Limitations:** Relies on COLMAP reconstruction for the initial sparse cloud; requires careful down-sampling to prevent over-fitting [S1].
-   **When to use:** When dense large-scale outdoor point cloud ground truth is unavailable and a super-resolution prior is needed for rendering [S1].
-   **When not to use:** When individual point sampling is preferred over region sampling [S1].

## Background
Originated in the paper "PDF: Point Diffusion Implicit Function for Large-scale Scene Neural Representation" [S1]. The method addresses the challenge of generating dense point clouds for large-scale outdoor scenes where ground truth is scarce. It builds on the Diffusion Models (DDPMs) framework [Parent].
