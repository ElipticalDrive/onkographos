# Histogram Peak Interpolation for Transfer Function Generation

Also called: Douglas-Peucker Histogram Interpolation, Interpolation between Transfer Function Peaks

## Overview
Histogram Peak Interpolation is an operation applied to two selected visualizations that examines the histogram section between their peaks to find intermediate peaks or place transfer functions equidistantly [S1, unofficial].

## How it works
**Inputs and Outputs**
- **Input:** A 1D histogram of the volume dataset and two selected unit transfer functions defined by their peak values $p_1$ and $p_2$ in the histogram domain [S1, unofficial].
- **Output:** A new set of transfer function peaks (up to three) located within the interval $[p_1, p_2]$, or equidistant positions if no peaks are found [S1, unofficial].

**Data Structures**
- **Histogram:** An array of bin counts $H[i]$ where $i$ represents the data value [S1, unofficial]. The exact resolution and bit packing are not given in the sources [S1, unofficial].

**Steps**
1. **Define Interval:** Identify the range of histogram bins between the two selected peak values $p_1$ and $p_2$ [S1, unofficial].
2. **Initialize Search:** Set the Douglas-Peucker tolerance parameter $\epsilon$ to an initial value greater than 2 [G].
3. **Iterative Peak Detection:**
   a. Apply the Douglas-Peucker algorithm to the histogram segment within $[p_1, p_2]$ using the current $\epsilon$ [S1, unofficial].
   b. The algorithm simplifies the curve by recursively dividing it at the point with the maximum perpendicular distance from the line segment connecting the endpoints [G].
   c. Points with distance $> \epsilon$ are retained as significant vertices [G].
   d. Collect the indices of the retained peaks strictly between $p_1$ and $p_2$ [G].
   e. If fewer than three peaks are found, decrease $\epsilon$ and repeat step 3a [S1, unofficial].
   f. Stop if three or more peaks are found, or if $\epsilon$ reaches the minimum threshold of 2 [S1, unofficial].
4. **Select Peaks:** From the detected peaks, select the three largest peaks based on their histogram bin counts (height) [S1, unofficial]. The source contains a contradiction regarding peak selection criteria: it states the method "selects any peak regardless of the size and the height of the peak" during detection, but explicitly requires finding "the three largest peaks within that section" for the final output [S1, unofficial].
5. **Handle Empty Interval:** If no peaks are found after $\epsilon$ reaches 2, place the new transfer functions equidistantly between $p_1$ and $p_2$ [S1, unofficial].

**Parameters**
- **$\epsilon$ (epsilon):** The tolerance parameter for the Douglas-Peucker algorithm. It is decreased iteratively during the interpolation peak search [S1, unofficial]. The search stops when three peaks are found or when $\epsilon = 2$ [S1, unofficial]. The initial value and decrement step are not given in the sources [G].

**Pseudocode**
```python
def histogram_peak_interpolation(histogram, p1, p2):
    # histogram: list of bin counts
    # p1, p2: indices of the two selected peaks (p1 < p2)
    # Returns: list of up to 3 peak indices or equidistant positions
    segment = histogram[p1:p2+1]
    points = [(i, segment[i]) for i in range(len(segment))]
    epsilon = 100.0 # Initial value not given in sources [G]
    min_epsilon = 2
    step = 1.0 # Decrement step not given in sources [G]

    while epsilon >= min_epsilon:
        vertices = douglas_peucker(points, epsilon)
        # Filter vertices to keep only those strictly between p1 and p2
        current_peaks = [v for v in vertices if 0 < v < len(segment) - 1]

        if len(current_peaks) >= 3:
            # Select the three largest peaks based on histogram bin counts
            current_peaks.sort(key=lambda idx: segment[idx], reverse=True)
            return current_peaks[:3]

        epsilon -= step

    # If no peaks found or epsilon reached minimum, place equidistantly
    num_functions = 3 # Number of functions to place not specified [G]
    equidistant_peaks = []
    for i in range(1, num_functions + 1):
        equidistant_peaks.append(int(p1 + i * (p2 - p1) / (num_functions + 1)))
    return equidistant_peaks

def douglas_peucker(points, epsilon):
    # points: list of (index, value) tuples
    if len(points) < 3:
        return [p[0] for p in points]
    start = points[0]
    end = points[-1]
    max_dist = 0.0
    max_idx = 0
    for i in range(1, len(points) - 1):
        dist = perpendicular_distance(points[i], start, end)
        if dist > max_dist:
            max_dist = dist
            max_idx = i
    if max_dist > epsilon:
        left = douglas_peucker(points[:max_idx+1], epsilon)
        right = douglas_peucker(points[max_idx:], epsilon)
        return left[:-1] + right
    else:
        return [start[0], end[0]]

def perpendicular_distance(point, line_start, line_end):
    x, y = point[0], point[1]
    x1, y1 = line_start[0], line_start[1]
    x2, y2 = line_end[0], line_end[1]
    A = y1 - y2
    B = x2 - x1
    C = x1*y2 - x2*y1
    return abs(A*x + B*y + C) / ((A**2 + B**2)**0.5)
```

## Subtopics

### [Visualization by Example / Constructive Visual Component-based Interface](17199-visualization-by-example-constructive-visual-component-based.md)
This method enables users to create direct volume rendering (DVR) visualizations by combining automatically generated unit transfer functions, requiring no knowledge of the DVR process or transfer function design. It distinguishes itself from its parent method, Histogram Peak Interpolation, by providing a constructive, spreadsheet-like interface where users select and merge pre-computed visualizations rather than manually interpolating between histogram peaks. Unlike traditional manual transfer function design, it prioritizes speed and ease of use for inexperienced users at the cost of precise control over material boundaries and opacity.

## Operating characteristics
Time and memory complexity are not given in the sources [S1, unofficial]. The method automatically detects intermediate structures without manual input and handles varying peak sizes by selecting the largest peaks in the interval [S1, unofficial]. It may fail to find peaks if the histogram segment is flat or noisy, resulting in equidistant placement which may not correspond to actual data structures [S1, unofficial]. It is used when visualizing intermediate densities between two known structures [S1, unofficial].

## Background
The method was introduced in the context of the "Visualization by Example" interface for Direct Volume Rendering [S1, unofficial]. It is part of a system implemented using Voreen, a rapid-prototyping environment for ray-casting-based volume visualizations [S1, unofficial]. The approach allows users to assemble complex transfer functions from simple unit transfer functions by interpolating between them [S1, unofficial].
