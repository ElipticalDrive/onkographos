# Unit Transfer Function Generation via Histogram Peak Detection

Also called: Douglas-Peucker Histogram Simplification, Peak-based Unit Transfer Function

## Overview
This method automatically generates "unit transfer functions"—simple mappings that visualize a single material structure—by identifying significant peaks in the data's histogram using the Douglas-Peucker algorithm [S1, unofficial]. It solves the complexity of manual transfer function design by decomposing the dataset into recognizable, simple visualizations that users can later assemble [S1, unofficial]. It differs from its parent, [Histogram-Based Transfer Function Generation](6182-histogram-based-transfer-function-generation.md), by specifically employing curve simplification to isolate global peaks rather than general boundary detection, and from [Histogram Noise Reduction](5356-histogram-noise-reduction.md) by focusing on feature extraction via geometric approximation rather than smoothing [S1, unofficial].

## How it works
**Inputs:** A scalar volume dataset; a user-defined epsilon ($\epsilon$) parameter [S1, unofficial].
**Outputs:** A set of unit transfer functions, each associated with a specific histogram peak, a random color, and a linear opacity function [S1, unofficial].

**Data Structures:**
1. **Histogram:** A 2D curve represented as a list of points $P_i = (v_i, h_i)$, where $v_i$ is the normalized bin value and $h_i$ is the normalized voxel count [S1, unofficial].
2. **Polyline $S$:** A list of indices or points representing the simplified curve [S1, unofficial].

**Normalization:**
To handle dramatic variations in bin counts, the raw histogram values are normalized using a logarithmic scale [S1, unofficial]:
$$ h_i = \frac{\log(\text{ValueOfTheCurrentBin}_i)}{\log(\text{MaxValue})} $$
where $\text{MaxValue}$ is the maximum voxel count in any bin [S1, unofficial]. The bin values $v_i$ correspond to the density values of the data range [S1, unofficial].

**Algorithm Steps:**
1. **Generate Histogram:** Create a bin for each value in the density range of the dataset. Compute the number of voxels for each value. Apply the logarithmic normalization defined above to obtain the curve points [S1, unofficial].
2. **Initialize Polyline:** Create a polyline $S$ containing only the first point (leftmost bin) and the last point (rightmost bin) of the normalized histogram curve [S1, unofficial].
3. **Recursive Simplification (Douglas-Peucker):**
   * For the current segment of the curve defined by the endpoints in $S$:
   * Compute the perpendicular distance from every intermediate point $P_k$ to the line segment connecting the segment's endpoints.
   * Find the point $P_{max}$ with the maximum distance $d_{max}$.
   * If $d_{max} < \epsilon$, the segment is simplified; stop processing this segment.
   * If $d_{max} \ge \epsilon$, add $P_{max}$ to $S$. Recursively apply this step to the two new sub-segments created by $P_{max}$ [S1, unofficial].
4. **Identify Peaks:** The points in the final polyline $S$ (excluding the start and end if they are not local maxima) represent the simplified curve. Identify local maxima (peaks) in this simplified set. A peak is a point higher than its immediate neighbors in $S$ [S1, unofficial].
5. **Sort Peaks:** Sort the identified peaks by "importance." Importance is determined by the height of the peak relative to the valleys on either side [S1, unofficial].
6. **Generate Unit Transfer Functions:** For each peak:
   * Define a transfer function that captures the region of the histogram represented by that peak's section.
   * Assign a random color value to the structure.
   * Define opacity $\alpha$ as a linear function of the density value $v$ corresponding to the peak: $\alpha(v)$ increases linearly with $v$ [S1, unofficial].

**Pseudocode:**
```python
import math
import random

def generate_unit_transfer_functions(data, epsilon):
    # 1. Generate Histogram
    min_val = min(data)
    max_val = max(data)
    bin_counts = [0] * (max_val - min_val + 1)
    for v in data:
        bin_counts[v - min_val] += 1
        
    max_count = max(bin_counts)
    
    # Normalize using logarithmic scale
    # Handle log(0) by treating 0 counts as 1 for log stability [G]
    normalized_heights = []
    for count in bin_counts:
        if count == 0:
            normalized_heights.append(0.0)
        else:
            normalized_heights.append(math.log(count) / math.log(max_count))
            
    # Points are (bin_value, normalized_height)
    points = [(min_val + i, normalized_heights[i]) for i in range(len(bin_counts))]
    
    # 2. Initialize Polyline S with first and last indices
    S = [0, len(points) - 1]
    
    # 3. Recursive Douglas-Peucker
    def douglas_peucker(start_idx, end_idx):
        if end_idx - start_idx < 2:
            return
        
        p1 = points[start_idx]
        p2 = points[end_idx]
        
        max_dist = -1.0
        max_idx = -1
        
        for k in range(start_idx + 1, end_idx):
            pk = points[k]
            dist = perpendicular_distance(pk, p1, p2)
            if dist > max_dist:
                max_dist = dist
                max_idx = k
                
        if max_dist < epsilon:
            return
        else:
            S.append(max_idx)
            douglas_peucker(start_idx, max_idx)
            douglas_peucker(max_idx, end_idx)

    douglas_peucker(0, len(points) - 1)
    S.sort()
    
    # 4. Identify Peaks in S
    peaks = []
    for i in range(1, len(S) - 1):
        idx = S[i]
        if points[idx][1] > points[S[i-1]][1] and points[idx][1] > points[S[i+1]][1]:
            peaks.append(idx)
            
    # 5. Sort Peaks by Importance
    scored_peaks = []
    for idx in peaks:
        left_val = points[S[S.index(idx)-1]][1]
        right_val = points[S[S.index(idx)+1]][1]
        valley = min(left_val, right_val)
        score = points[idx][1] - valley
        scored_peaks.append((score, idx))
        
    scored_peaks.sort(key=lambda x: x[0], reverse=True)
    
    # 6. Generate Unit Transfer Functions
    unit_tfs = []
    for score, idx in scored_peaks:
        color = [random.random() for _ in range(3)]
        peak_density = points[idx][0]
        def opacity_func(density, p=peak_density):
            return density / max_val  # Linear increase with density value [G]
            
        unit_tfs.append({
            'peak_value': peak_density,
            'color': color,
            'opacity_func': opacity_func
        })
        
    return unit_tfs

def perpendicular_distance(point, line_start, line_end):
    x, y = point
    x1, y1 = line_start
    x2, y2 = line_end
    A = y1 - y2
    B = x2 - x1
    C = x1*y2 - x2*y1
    dist = abs(A*x + B*y + C) / math.sqrt(A*A + B*B)
    return dist
```

**Parameters:**
* $\epsilon$ (epsilon): The maximum allowed error of the approximated curve. Controls the size of features captured. $\epsilon=0$ yields the original smoothed histogram; $\epsilon=\text{maximumBinValue}$ yields only one peak [S1, unofficial].

**Edge Cases and Pitfalls:**
* **Opacity Assumption:** The linear opacity increase assumes that regions with the highest density are inside the data set and lower density regions are outside (e.g., bone vs. muscle in CT). This may not hold for all data types [S1, unofficial].
* **Logarithm of Zero:** If a bin has 0 voxels, $\log(0)$ is undefined. The implementation must handle this, typically by treating 0 counts as a small positive number or excluding them from the log calculation [G].

## Subtopics

### [Histogram Peak Interpolation for Transfer Function Generation](16869-histogram-peak-interpolation-for-transfer-function-generatio.md)
A method for automatically generating intermediate transfer functions by analyzing the histogram data between two existing unit transfer function peaks. It distinguishes itself from its parent method by focusing on the interval between peaks rather than the global histogram maximums, and from its child, Visualization by Example, by providing the underlying algorithmic logic for peak detection rather than a constructive interface.

### Search Around a Feature
An operation that finds peaks in the histogram surrounding the peak corresponding to a selected visualization's transfer function, creating new unit transfer functions for them. Unlike the initial peak selection which sorts by importance (height relative to valleys), this function selects any peak regardless of its size and height [S1, unofficial].

## Operating characteristics
* **Time Complexity:** The Douglas-Peucker algorithm typically runs in $O(n \log n)$ on average, where $n$ is the number of histogram bins, though worst-case is $O(n^2)$ [G]. Sorting peaks is $O(k \log k)$ where $k$ is the number of peaks [G].
* **Memory Complexity:** $O(n)$ to store the histogram and polyline points [G].
* **Strengths:** Reduces complex transfer function design to a few simple, recognizable components. Automates the discovery of major material boundaries [S1, unofficial].
* **Limitations:** Relies on the assumption that structures correspond to histogram peaks. The linear opacity model is restrictive and data-type dependent. The choice of $\epsilon$ significantly impacts the result and requires user tuning [S1, unofficial].
* **When to use:** When the dataset has distinct material classes with clear density separations (e.g., medical CT) [S1, unofficial].
* **When not to use:** When the data lacks clear histogram peaks or when the density-to-opacity relationship is non-linear or inverted [G].

## Background
The method was introduced in the context of "Visualization by Example," a constructive interface for direct volume rendering. It builds on the observation that structures in scalar volume data sets can be characterized by peaks in the histogram, corresponding to the size of the structures [S1, unofficial]. The approach uses the Douglas-Peucker algorithm, originally from cartography (Peucker, 1973), to simplify the histogram curve [S1, unofficial]. It is part of a spreadsheet-like interface where users assemble complex visualizations from these unit transfer functions [S1, unofficial].
