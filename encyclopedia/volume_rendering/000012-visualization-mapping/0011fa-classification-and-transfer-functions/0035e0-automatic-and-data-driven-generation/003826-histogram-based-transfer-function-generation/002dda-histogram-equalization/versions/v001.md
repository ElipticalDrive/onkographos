# Histogram Equalization

Also called: Automatic Range Mapping, CDF-based Normalization

## Overview
Histogram Equalization is an automatic technique that redistributes scalar values in volume rendering data to spread out clustered regions, thereby enhancing features hidden within high-density areas of the data distribution [S1, unofficial]. It differs from its sibling method, [Range Mapping](5650-range-mapping.md), by being fully automatic and lacking user control, which often results in breaking the continuity of the scalar range [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A normalized scalar value $x$ derived from the volume data, typically represented via a discrete histogram.
*   **Output:** A new normalized scalar value $y$ that is uniformly distributed across the output range.

**Data Structures:**
*   **Histogram:** A discrete representation of the Probability Density Function (PDF). Let $N$ be the number of bins. The PDF for bin $i$ is $PDF(x_i)$.
*   **Lookup Table (LUT):** A precomputed array mapping input indices to output values, used for speed [S1, unofficial].

**Steps:**
1.  **Compute PDF:** Calculate the probability density for each normalized scalar input $x_i$. In a discrete implementation, this is the count of voxels falling into bin $i$ divided by the total number of voxels.
2.  **Compute CDF:** Calculate the Cumulative Distribution Function (CDF) by summing the PDFs. For a normalized scalar input $x_i$, the CDF is defined as:
    $$CDF(x_i) = \sum_{x_j < x_i} PDF(x_j)$$
    Note: The source formula uses a strict inequality ($x_j < x_i$) for the summation limit [S1, unofficial].
3.  **Map:** Perform the mapping on the normalized scalar input value $x$ to yield the output $y$:
    $$y = CDF(x)$$

**Pseudocode:**
```python
def histogram_equalization(volume_data, num_bins):
    # Step 1: Compute Histogram (PDF)
    # Normalize volume data to [0, 1] range first
    min_val = min(volume_data)
    max_val = max(volume_data)
    normalized_data = (volume_data - min_val) / (max_val - min_val)
    
    # Create histogram bins
    histogram = [0] * num_bins
    for val in normalized_data:
        # Clamp to [0, num_bins-1] to handle boundary precision issues
        bin_index = int(val * (num_bins - 1))
        if bin_index >= num_bins:
            bin_index = num_bins - 1
        histogram[bin_index] += 1
        
    total_voxels = len(normalized_data)
    
    # Normalize histogram to get PDF
    pdf = [count / total_voxels for count in histogram]
    
    # Step 2: Compute CDF
    cdf = [0.0] * num_bins
    current_sum = 0.0
    for i in range(num_bins):
        # Formula: CDF(x_i) = sum_{x_j < x_i} PDF(x_j)
        # This implies the sum excludes the current bin's PDF if we interpret 
        # x_j < x_i strictly as previous bins. 
        # However, standard CDF usually includes current bin. 
        # The source explicitly states sum_{x_j < x_i}. 
        # We follow the source strictly.
        cdf[i] = current_sum
        current_sum += pdf[i]
        
    # Normalize CDF to [0, 1] if necessary, though CDF naturally approaches 1.
    # The source implies y = CDF(x) directly.
    
    # Step 3: Create Lookup Table for mapping
    lut = [0.0] * num_bins
    for i in range(num_bins):
        # Map input bin index to output value
        # Input x corresponds to bin i. 
        # Output y is the CDF value.
        lut[i] = cdf[i]
        
    return lut

def apply_equalization(volume_data, lut):
    min_val = min(volume_data)
    max_val = max(volume_data)
    normalized_data = (volume_data - min_val) / (max_val - min_val)
    
    result = []
    num_bins = len(lut)
    for val in normalized_data:
        bin_index = int(val * (num_bins - 1))
        if bin_index >= num_bins:
            bin_index = num_bins - 1
        result.append(lut[bin_index])
        
    return result
```

**Parameters:**
*   `num_bins`: The resolution of the histogram/LUT. Typical values depend on hardware texture limits (e.g., 256, 512, 1024) [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Continuity Breaking:** The method tends to break the continuities of the scalar range, which can lead to visual artifacts [S1, unofficial].
*   **User Control:** It provides very little control over the redistribution process [S1, unofficial].
*   **Precision:** Discrete implementation requires careful binning to avoid precision errors at boundaries [G].

## Subtopics

### [Range Mapping](5650-range-mapping.md)
A generalization of histogram equalization that uses piecewise linear functions to provide user control while maintaining continuity. Choose this when user-defined feature emphasis is required.

## Operating characteristics
*   **Time Complexity:** $O(N)$ for computing the histogram and CDF, where $N$ is the number of voxels. Lookup application is $O(1)$ per voxel using a LUT.
*   **Memory Complexity:** $O(B)$ for the histogram and LUT, where $B$ is the number of bins.
*   **Strengths:** Speed and simplicity; effective at spreading out clustered regions automatically [S1, unofficial].
*   **Limitations:** Lack of user control; breaks scalar range continuity; automatic nature may not align with semantic features [S1, unofficial].
*   **When to use:** When automatic enhancement of HDR data is needed and user interaction is not desired [S1, unofficial].
*   **When not to use:** When continuity of the scalar range is critical or when specific regions need targeted emphasis via user control [S1, unofficial].

## Background
Histogram Equalization was introduced in the context of interactive transfer function specification for direct volume rendering, specifically to address the difficulties of designing transfer functions for high dynamic range (HDR) data [S1, unofficial]. It serves as the basis for the more controlled Range Mapping technique [S1, unofficial].
