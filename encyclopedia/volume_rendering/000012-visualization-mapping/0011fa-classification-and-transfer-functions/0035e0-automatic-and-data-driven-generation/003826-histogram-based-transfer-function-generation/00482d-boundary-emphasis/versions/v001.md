# Boundary Emphasis

Also called: Boundary Emphasis TF Generation, Histogram-based Boundary TF

## Overview
Boundary Emphasis is an automatic technique for generating initial transfer functions (TFs) that highlight material interfaces in volume data by exploiting local gradient information [S1, unofficial]. It builds on [Histogram-Based Transfer Function Generation](6182-histogram-based-transfer-function-generation.md) by using a 3D histogram of voxel values, first derivatives, and second derivatives to identify boundary regions [S1, unofficial]. Unlike sibling methods that focus on noise reduction or global equalization, this method creates color discontinuities at specific voxel values to visually separate adjacent materials with similar intensities [S1, unofficial].

## How it works
**Inputs:** A 3D scalar dataset $V$.
**Outputs:** A piecewise linear transfer function defined by control points, consisting of an opacity function $\alpha(v)$ and a color function $C(v)$.

**Data Structures:**
1.  **3D Histogram $H$:** A 3D array where axes correspond to voxel value $v$, first derivative magnitude $|\nabla v|$, and second derivative magnitude $|\nabla^2 v|$. The binning strategy is not specified in the sources [G: Standard uniform binning is assumed for implementation].
2.  **Control Point List $P$:** A list of objects, each containing:
    *   `value`: The voxel value $v_c$ associated with the boundary.
    *   `opacity`: A scalar $\alpha_c \in [\alpha_{min}, \alpha_{max}]$.
    *   `color_pos`: A 3D vector (RGB) for values $v > v_c$.
    *   `color_neg`: A 3D vector (RGB) for values $v < v_c$.

**Parameters:**
*   $\alpha_{min}$: Minimum opacity for control points. Default: Not given in the sources.
*   $\alpha_{max}$: Maximum opacity for control points. Default: Not given in the sources.
*   $w$: Width of the interval around each control point. Default: Adjustable (user-defined).

**Steps:**

1.  **Compute Derivatives:** Calculate the first derivative $\nabla v$ and second derivative $\nabla^2 v$ for every voxel in $V$.
2.  **Build Histogram:** Populate the 3D histogram $H$ using the triplet $(v, |\nabla v|, |\nabla^2 v|)$ for each voxel [S1, unofficial].
3.  **Identify Control Points:** Analyze $H$ to identify peaks or regions corresponding to boundaries. Select voxel values $v_c$ that are likely in a boundary region as control points [S1, unofficial].
4.  **Assign Opacity:** For each control point $c$, assign an opacity value $\alpha_c$ chosen randomly from the interval $[\alpha_{min}, \alpha_{max}]$ [S1, unofficial].
5.  **Construct Opacity TF:** For each control point $c$ at value $v_c$, define the opacity contribution over the interval $[v_c - w, v_c + w]$. The opacity decreases linearly with distance from $v_c$:
    $$ \alpha(v) = \alpha_c \cdot \left( 1 - \frac{|v - v_c|}{w} \right) \quad \text{for } |v - v_c| \le w $$
    Outside this interval, the contribution is 0. The final opacity TF is the sum of contributions from all control points, forming triangular shapes [S1, unofficial].
6.  **Assign Colors:** For each control point $c$, generate two random colors: $C_{pos}$ for $v > v_c$ and $C_{neg}$ for $v < v_c$ [S1, unofficial].
7.  **Construct Color TF:** Define the color function $C(v)$ by linearly interpolating between the colors associated with adjacent control points. Specifically, for a voxel value $v$ between two control points $c_i$ and $c_{i+1}$ (where $v_{c_i} < v < v_{c_{i+1}}$), interpolate between $C_{pos}(c_i)$ and $C_{neg}(c_{i+1})$ [S1, unofficial].

**Pseudocode:**

```python
import numpy as np

def boundary_emphasis_tf(data, alpha_min=0.1, alpha_max=1.0, interval_width=5.0):
    """
    Generates a Boundary Emphasis Transfer Function.
    
    Args:
        data: 3D numpy array of voxel values.
        alpha_min: Minimum opacity for control points.
        alpha_max: Maximum opacity for control points.
        interval_width: Width w of the triangular opacity intervals.
        
    Returns:
        control_points: List of dicts with 'value', 'opacity', 'color_pos', 'color_neg'.
        v_range: Tuple (min_v, max_v) for the TF domain.
    """
    # Step 1: Compute derivatives
    # Using central differences for interior points
    grad_x = np.gradient(data, axis=0)
    grad_y = np.gradient(data, axis=1)
    grad_z = np.gradient(data, axis=2)
    
    # First derivative magnitude
    first_deriv = np.sqrt(grad_x**2 + grad_y**2 + grad_z**2)
    
    # Second derivative magnitude (Laplacian)
    laplacian = np.gradient(grad_x, axis=0) + np.gradient(grad_y, axis=1) + np.gradient(grad_z, axis=2)
    second_deriv = np.abs(laplacian)
    
    # Step 2: Build 3D Histogram
    # Note: Exact binning parameters are not specified in sources [G: Assume uniform bins covering data range]
    # This step identifies boundary regions. For implementation, we assume a peak detection algorithm
    # on the histogram yields a list of representative voxel values.
    # In practice, this might involve finding local maxima in the histogram space.
    # Here we simulate the output of the histogram analysis: a list of boundary voxel values.

    boundary_values = find_histogram_peaks(data, first_deriv, second_deriv)
    
    if not boundary_values:
        return [], (np.min(data), np.max(data))

    # Step 3 & 4: Identify Control Points and Assign Opacity
    control_points = []
    v_range = (np.min(data), np.max(data))
    
    # Sort boundary values to ensure consistent interpolation
    boundary_values.sort()
    
    for v_c in boundary_values:
        # Random opacity between min and max
        alpha_c = np.random.uniform(alpha_min, alpha_max)
        
        # Step 6: Assign Colors
        # Two random colors: one for larger values, one for smaller
        color_pos = np.random.rand(3)
        color_neg = np.random.rand(3)
        
        control_points.append({
            'value': v_c,
            'opacity': alpha_c,
            'color_pos': color_pos,
            'color_neg': color_neg
        })
        
    return control_points, v_range

def evaluate_tf(control_points, v, interval_width):
    """
    Evaluates the opacity and color at a specific voxel value v.
    """
    if not control_points:
        return 0.0, np.array([0.0, 0.0, 0.0])
    
    # Opacity Calculation
    alpha_total = 0.0
    for cp in control_points:
        dist = abs(v - cp['value'])
        if dist <= interval_width:
            # Triangular shape: decreases linearly with distance
            alpha_contrib = cp['opacity'] * (1.0 - dist / interval_width)
            alpha_total += alpha_contrib
            
    # Color Calculation
    # Find the two surrounding control points
    # Sort control points by value
    sorted_cps = sorted(control_points, key=lambda k: k['value'])
    
    # Find index i such that sorted_cps[i].value <= v < sorted_cps[i+1].value
    idx = -1
    for i in range(len(sorted_cps) - 1):
        if sorted_cps[i]['value'] <= v < sorted_cps[i+1]['value']:
            idx = i
            break
            
    if idx == -1:
        # v is outside the range of control points
        # Use the color of the nearest control point
        if v < sorted_cps[0]['value']:
            color = sorted_cps[0]['color_neg']
        else:
            color = sorted_cps[-1]['color_pos']
    else:
        cp_left = sorted_cps[idx]
        cp_right = sorted_cps[idx+1]
        
        # Interpolate between color_pos of left CP and color_neg of right CP
        # Linear interpolation
        t = (v - cp_left['value']) / (cp_right['value'] - cp_left['value'])
        color = (1.0 - t) * cp_left['color_pos'] + t * cp_right['color_neg']
        
    return alpha_total, color

    # corresponding to identified boundary peaks.
    # Simplified heuristic for demonstration:
    # Find voxels with high gradient and high laplacian (edges)
    threshold = np.percentile(first_deriv, 90)
    edge_mask = first_deriv > threshold
```

**Edge Cases and Pitfalls:**
*   **Precision:** The linear interpolation and triangular opacity functions are sensitive to the exact placement of control points. Small variations in derivative calculation can shift boundary locations [G: Standard floating-point precision is sufficient, but derivative noise must be managed by the histogram binning].
*   **Boundaries:** The color interpolation assumes an ordering of control points. If control points are sparse, large intervals may lead to incorrect color blending [S1, unofficial].
*   **Degenerate Input:** If no boundaries are detected (e.g., uniform data), the control point list is empty, and the TF returns zero opacity and black color [G].

## Subtopics

### Feature-sensitive Transfer Function Generation
A technique by Kindlmann and Durkin that uses first and second derivatives to generate feature-sensitive transfer functions automatically, providing data segmentation [S2, unofficial]. It is the foundational method referenced by Boundary Emphasis [S1, unofficial]. While Boundary Emphasis focuses on creating color discontinuities for visual emphasis, Feature-sensitive TF Generation focuses on automatic segmentation based on the histogram of derivatives [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Dominated by the computation of derivatives ($O(N)$ for $N$ voxels) and the construction of the 3D histogram ($O(N)$). Peak detection in the histogram depends on the histogram resolution but is generally efficient.
*   **Memory Complexity:** Requires storage for the 3D histogram, which scales with the product of the number of bins in value, first derivative, and second derivative dimensions.
*   **Strengths:** Automatically identifies boundaries without user interaction; creates clear visual separation between materials with similar intensities through color discontinuities [S1, unofficial].
*   **Limitations:** Relies on the quality of derivative estimation; sensitive to noise in the data (though the histogram approach provides some robustness); the random assignment of opacities and colors may require user adjustment for optimal visualization [S1, unofficial].
*   **When to use:** When automatic segmentation of boundaries is required and manual TF design is impractical.
*   **When not to use:** When precise control over opacity and color mapping is needed, or when the data has low contrast boundaries.

## Background
The method is based on the work of Kindlmann and Durkin [KIN 98], who proposed using first and second derivatives to generate feature-sensitive transfer functions [S1, unofficial]. It follows the histogram approach used by Prauchner et al. [PRA 2005a] to choose control points [S1, unofficial]. The concept of creating color discontinuities to emphasize boundaries was suggested by Fujishiro et al. [FUJ 2000] [S1, unofficial].
