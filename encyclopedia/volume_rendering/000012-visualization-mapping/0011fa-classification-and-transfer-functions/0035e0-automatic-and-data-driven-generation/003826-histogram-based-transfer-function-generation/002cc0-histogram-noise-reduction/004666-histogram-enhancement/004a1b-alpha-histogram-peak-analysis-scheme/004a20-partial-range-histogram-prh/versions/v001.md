# Partial Range Histogram (PRH)
Also called: PRH method

## Overview
The Partial Range Histogram (PRH) method creates separate histograms for individual tissues by analyzing local voxel neighborhoods, contrasting with the $\alpha$-histogram which enhances tissues at the global histogram level [S1, S2]. It is specifically designed to detect highly overlapping peaks and expose minor tissue peaks that are obscured in the global histogram [S1, S2].

## How it works
**Inputs:** A 3D volume dataset $V$, a target intensity range $\Phi$, a block size $B$ (typically $8^3$ voxels), and a range weight threshold $\varepsilon$ [S2].
**Outputs:** A set of Partial Range Histograms, one for each distinct tissue peak detected within the analyzed ranges [S2].

**Data Structures:**
*   **Volume $V$:** A 3D grid of voxel intensities.
*   **Block $N$:** A non-overlapping cubic sub-volume of $V$ with side length $B$.
*   **Range Weight $w_r(\Phi, N)$:** A scalar value representing the fraction of voxels in block $N$ that fall within intensity range $\Phi$ [S2].

**Algorithm Steps:**

1.  **Iterate through blocks:** Divide the volume into non-overlapping cubic blocks of size $B \times B \times B$.
2.  **Calculate Range Weight:** For each block $N$ and a specific target intensity range $\Phi$, calculate the range weight $w_r$ using the formula [S2]:
    $$ w_r(\Phi, N) = \frac{|N \cap V_\Phi|}{|N|} $$
    Where:
    *   $|N|$ is the total number of voxels in block $N$.
    *   $V_\Phi$ is the set of all voxels in the volume with intensity values within range $\Phi$.
    *   $|N \cap V_\Phi|$ is the count of voxels in block $N$ that have intensities within $\Phi$.
3.  **Filter Blocks:** If $w_r(\Phi, N) \ge \varepsilon$, add all voxels from block $N$ to the Partial Range Histogram associated with range $\Phi$ [S2].
4.  **Peak Detection:** Analyze the resulting PRHs to identify peaks. The position of the peak is the primary input for Transfer Function (TF) construction; the height is less critical [S2].
5.  **Top Peak Handling (Optional):** If the vessel peak is known to be at the top of the intensity scale, create possible top peaks by merging $1, \dots, n_{PRH}-1$ of the topmost peaks detected in the PRHs, then perform peak selection according to valid range rules [S1].

**Parameters:**
*   **$\varepsilon$ (Range Weight Limit):** The minimum range weight required for a block to be added to the PRH. Typical values are $\varepsilon = 0.95$ for capturing narrow features and $\varepsilon = 0.5$ for picking up inhomogeneous regions [S2]. Other tested values include 0.6, 0.7, and 0.8 [S1].
*   **Block Size:** The neighborhoods used are cubic blocks. A size of $8^3$ voxels is used as a trade-off between simplicity and sensitivity to narrow features [S2].

**Pitfalls:**
*   **Sensitivity to $\varepsilon$:** The PRH method is sensitive to the choice of $\varepsilon$, which can cause greatly differing median errors [S1].
*   **Peak Confidence:** The peak confidence $c_p$ is always very large for PRHs because they correspond to separated tissue peaks, making $c_p$ of little interest for evaluating PRH results [S1].

## Operating characteristics
*   **Complexity:** The method requires iterating over all non-overlapping blocks in the volume. For each block, it calculates the fraction of voxels in a specific range. The complexity is proportional to the number of blocks times the number of ranges analyzed.
*   **Performance:** The block size ($8^3$) is a trade-off between simplicity and sensitivity [S2].
*   **Strengths:** Effective at exposing obscured minor peaks and handling highly overlapping peaks where global histograms fail [S1, S2].
*   **Limitations:** Sensitive to the threshold parameter $\varepsilon$ [S1]. Peak confidence is not a useful metric for PRHs [S1].
*   **Usage:** Suitable for medical DVR where minor tissues are important and may be obscured in global statistics [S2].

## Background
The PRH method was introduced in [S2] (Eurographics 2005) as a key concept for automatic exhaustive detection of tissues in volume rendering. It was further discussed in [S1] (Eurographics 2006) in comparison with the $\alpha$-histogram. The method is part of a framework using Adaptive Trapezoids for TF generation [S2].
