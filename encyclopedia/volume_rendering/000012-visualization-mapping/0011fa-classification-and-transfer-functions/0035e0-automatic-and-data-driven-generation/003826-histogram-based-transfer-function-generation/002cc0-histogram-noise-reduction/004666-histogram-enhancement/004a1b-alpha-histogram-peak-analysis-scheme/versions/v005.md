# Alpha-histogram Peak Analysis Scheme

Also called: Automatic Peak Detection in Alpha-histogram, Peak Detection Scheme, Peak analysis scheme

## Overview
The Alpha-histogram Peak Analysis Scheme is an automatic method for detecting significant material peaks in an $\alpha$-histogram to facilitate transfer function design [S1]. It addresses the challenge of noise in $\alpha$-histograms by applying selective and global smoothing, followed by an area-based importance assessment to filter and simplify the remaining peaks [S1]. It differs from its parent, [α-histogram Enhancement](11753-histogram-enhancement.md), by providing the specific algorithmic steps to extract discrete peak candidates from the enhanced histogram data, rather than just enhancing the histogram itself. It serves as the precursor to [TF adaptation peak selection](12678-tf-adaptation-peak-selection.md), which selects the final peak from the scheme's output.

## How it works
**Inputs:** An $\alpha$-histogram represented as an array of bin heights.
**Outputs:** A list of up to $np_2$ significant peaks, where each peak is defined by its apex position, width, and area.

**Data Structures:**
*   **Histogram:** An array $H$ of size $N$, where $H[i]$ is the count for intensity bin $i$.
*   **Peak:** A tuple $(x_0, x_-, x_+, A)$, where $x_0$ is the apex index, $x_-$ and $x_+$ are the 10th and 90th percentile width boundaries, and $A$ is the calculated area.

**Parameters:**
*   $np_1$: Maximum number of peaks allowed after global smoothing. Typical value: 20 [S1].
*   $np_2$: Predefined number of peaks to retain after simplification. Typical values: 1, 2, 3, 4 [S1].

**Algorithm Steps:**

1.  **Selective Smoothing:**
    Identify "minimal peaks" or "creases". A minimal peak is an apex $x_0$ surrounded by two valleys $x_-$ and $x_+$ such that the sequence is valley-apex-valley. A crease is an apex surrounded by two other apices (apex-valley-apex is not a crease; the definition specifies "middle of three directly adjacent valley-apex-valley or apex-valley-apex points" [S1]). Specifically, a point $x_i$ is a minimal peak if $H[i] > H[i-1]$ and $H[i] > H[i+1]$ and it is a local maximum that is smaller than its neighbors' peaks, or a local minimum between two peaks (crease). The text defines it as "the middle of three directly adjacent valley-apex-valley or apex-valley-apex points" [S1].
    Apply a binomial smoothing kernel to these specific points. Repeat this process iteratively until no minimal peaks or creases remain in the histogram.

2.  **Global Smoothing:**
    Apply the same binomial smoothing kernel to the entire histogram array.
    Repeat the smoothing process.
    Stop when the number of remaining peaks in the histogram equals $np_1$.
    *Note: The stopping criterion is explicitly "maximum number of remaining peaks: np1" [S1].*

3.  **Peak Listing and Simplification:**
    Identify all remaining peaks in the smoothed histogram.
    Calculate the area for each peak (see Formula below).
    While the number of peaks exceeds $np_2$:
    a. Find the peak with the least area.
    b. Remove this peak from the list.
    c. Extend a neighboring peak to cover the removed peak's range if doing so increases the neighbor's area.
    d. If both left and right neighbors would gain from an extension, select the neighbor with the largest peak height.

**Formulas:**

*   **Smoothing Kernel:**
    The smoothing operator is a binomial kernel applied to the histogram bins [S1]:
    $$ K = [0.25, 0.5, 0.25] $$
    For a point $x_i$, the smoothed value $H'[i]$ is:
    $$ H'[i] = 0.25 \cdot H[i-1] + 0.5 \cdot H[i] + 0.25 \cdot H[i+1] $$
    (Boundary conditions for $i=0$ and $i=N-1$ are not specified in the sources [G]. Standard practice is to clamp or reflect, but the source does not define this.)

*   **Peak Definition:**
    An apex is a point $x_0$ such that $H[x_0] > H[x_0-1]$ and $H[x_0] > H[x_0+1]$.
    A valley is the opposite [S1].

*   **Base Line Construction:**
    For a peak with apex $x_0$, the base line starts at the highest valley with a downward slope relative to the peak. It extends as a straight line touching exactly one more point on the histogram curve within the peak range [S1].

*   **Peak Area:**
    The area $A$ is the sum of the height differences between the base line and the histogram curve between the two touching points (the start valley and the second touching point) [S1].
    $$ A = \sum_{j=start}^{end} (H_{base}(j) - H(j)) $$
    Where $H_{base}(j)$ is the value of the base line at bin $j$.

*   **Peak Width (for evaluation, not core scheme):**
    $x_-$ and $x_+$ are defined as the 10th and 90th percentiles of the peak histogram area [S1].

## Subtopics

### [Partial Range Histogram (PRH)](12656-partial-range-histogram-prh.md)
The Partial Range Histogram (PRH) method creates separate histograms for individual tissues by analyzing local voxel neighborhoods, contrasting with the $\alpha$-histogram which enhances tissues at the global histogram level. It is specifically designed to detect highly overlapping peaks and expose minor tissue peaks that are obscured in the global histogram.

### [TF adaptation peak selection](12678-tf-adaptation-peak-selection.md)
This method selects the optimal transfer function peak from a set of candidate peaks detected in an $\alpha$-histogram or original density histogram. It solves the problem of identifying the most representative material density for automatic classification by prioritizing peaks that fall within a predefined "valid range" and maximizing a confidence metric. It differs from its parent, [Alpha-histogram Peak Analysis Scheme](12652-alpha-histogram-peak-analysis-scheme.md), by implementing a specific selection logic based on validity and confidence rather than just raw peak height, and from siblings like [Partial Range Histogram (PRH)](12656-partial-range-histogram-prh.md) by relying on the confidence score $c_p$ derived from the peak analysis scheme rather than partial range constraints alone.

### [Exhaustive Multiple-Peak Search](14136-exhaustive-multiple-peak-search.md)
An automatic algorithm to detect all tissue peaks in a global histogram by iteratively finding the highest peak, fitting a Gaussian, creating a PRH for that peak's range, removing the PRH's contribution from the global histogram, and repeating until the histogram is empty.

## Operating characteristics
**Time Complexity:** The algorithm involves iterative smoothing. The number of iterations depends on the noise level and the target $np_1$. Each iteration is $O(N)$ where $N$ is the number of bins. The simplification step is $O(P \log P)$ or $O(P^2)$ depending on implementation, where $P$ is the number of peaks after smoothing.
**Memory Complexity:** $O(N)$ for the histogram and $O(P)$ for the peak list.
**Performance:** The scheme is designed to handle noisy $\alpha$-histograms effectively [S1]. The selective smoothing step preserves subtle peaks that might be removed by global smoothing alone [S1].
**Strengths:** Automatic detection; handles noise; area-based importance is intuitive for material significance [S1].
**Limitations:** Requires tuning of $np_1$ and $np_2$ [S1]. The base line calculation and peak extension logic are complex to implement precisely [G]. Intensity value 0 is often discarded as it is orders of magnitude more frequent [S1].

## Background
The Alpha-histogram Peak Analysis Scheme was introduced in the paper "The alpha-histogram: Using Spatial Coherence to Enhance Histograms and Transfer Function Design" [S1]. It is part of a pipeline for automatic transfer function generation, building on the $\alpha$-histogram enhancement technique. The scheme was evaluated on 20 MR AAA angiographies [S1].
