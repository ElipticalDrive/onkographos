# Alpha-histogram Peak Analysis Scheme

Also called: Automatic Peak Detection in Alpha-histogram, Peak Detection Scheme, Peak analysis scheme

## Overview
The Alpha-histogram Peak Analysis Scheme is an automatic method for detecting significant material peaks in an $\alpha$-histogram to facilitate transfer function design [S1]. It solves the problem of noise and clutter in raw histograms by applying selective smoothing to remove minor irregularities while preserving subtle, meaningful peaks, followed by an area-based importance assessment to select the most relevant materials [S1]. It sets itself apart from its siblings, such as [Partial Range Histogram (PRH)](12656-partial-range-histogram-prh.md), by operating on the global $\alpha$-histogram to enhance tissues at the intensity level rather than isolating them spatially, and from [TF adaptation peak selection](12678-tf-adaptation-peak-selection.md) by providing the raw peak detection and simplification logic rather than the final selection based on validity ranges [S1].

## How it works
**Inputs:**
- An $\alpha$-histogram represented as an array of bin heights $H$ of size $N$.
- Parameter $np_1$: Maximum number of remaining peaks after global smoothing (Typical value: 20) [S1].
- Parameter $np_2$: Predefined number of peaks to retain after simplification (Typical values: 1, 2, 3, 4) [S1].

**Outputs:**
- A list of detected peaks, where each peak is defined by its apex position, width (10th and 90th percentiles of area), and calculated area [S1].

**Data Structures:**
- **Histogram Array:** $H[i]$ stores the count for intensity bin $i$.
- **Peak Definition:** A peak is a segment consisting of an apex $x_0$ surrounded by two valleys $x_-$ and $x_+$. An apex is a point $H[i]$ such that $H[i] > H[i-1]$ and $H[i] > H[i+1]$. A valley is the opposite [S1].
- **Base Line:** A straight line starting at the highest valley with a downward slope relative to the peak, touching exactly one other point on the histogram curve within the peak range [S1].

**Smoothing Kernel:**
A binomial kernel $K = [0.25, 0.5, 0.25]$ (represented as $0.25 \cdot [1, 2, 1]$) is used for smoothing [S1].

**Algorithm Steps:**

1.  **Selective Smoothing:**
    Identify all "minimal peaks" or "creases". A minimal peak is an apex surrounded by two valleys (valley-apex-valley). A crease is an apex surrounded by two other apices or a valley and an apex in a specific local configuration (apex-valley-apex or valley-apex-apex context implies the middle point of three adjacent extrema) [S1]. Specifically, the method targets the middle of three directly adjacent valley-apex-valley or apex-valley-apex points [S1].
    Apply the smoothing kernel to the bin values at these identified positions.
    Repeat this process iteratively until no minimal peaks or creases remain in the histogram [S1].

2.  **Global Smoothing:**
    Apply the same smoothing kernel to the entire histogram array repeatedly.
    After each pass, count the number of remaining peaks (local maxima).
    Stop when the number of remaining peaks equals $np_1$ [S1].

3.  **Peak Listing and Simplification:**
    List all remaining peaks from the smoothed histogram.
    Calculate the area for each peak. The area is the sum of the height differences between the histogram curve and the base line between the two touching points (the start valley and the second touching point) [S1].
    While the number of peaks exceeds $np_2$:
    a. Identify the peak with the least area.
    b. Remove this peak from the list.
    c. Extend a neighboring peak to cover the removed peak's range if doing so increases the neighbor's area.
    d. If both left and right neighbors would gain from an extension, select the neighbor with the largest peak height [S1].

4.  **Peak Characterization (Post-processing):**
    For each retained peak, define its width using the 10th and 90th percentiles of the peak's histogram area, denoted as $x_-$ and $x_+$ [S1].
    The apex position is $x_0$ [S1].

## Subtopics

### [Partial Range Histogram (PRH)](12656-partial-range-histogram-prh.md)
The Partial Range Histogram (PRH) method creates separate histograms for individual tissues by analyzing local voxel neighborhoods, contrasting with the $\alpha$-histogram which enhances tissues at the global histogram level. It is specifically designed to detect highly overlapping peaks and expose minor tissue peaks that are obscured in the global histogram.

### [TF adaptation peak selection](12678-tf-adaptation-peak-selection.md)
This method selects the optimal transfer function peak from a set of candidate peaks detected in an $\alpha$-histogram or original density histogram. It solves the problem of identifying the most representative material density for automatic classification by prioritizing peaks that fall within a predefined "valid range" and maximizing a confidence metric. It differs from its parent, [Alpha-histogram Peak Analysis Scheme](12652-alpha-histogram-peak-analysis-scheme.md), by implementing a specific selection logic based on validity and confidence rather than just raw peak height, and from siblings like [Partial Range Histogram (PRH)](12656-partial-range-histogram-prh.md) by relying on the confidence score $c_p$ derived from the peak analysis scheme rather than partial range constraints alone.

### [Exhaustive Multiple-Peak Search](14136-exhaustive-multiple-peak-search.md)
Exhaustive Multiple-Peak Search is an automatic algorithm for detecting all tissue peaks in a global intensity histogram by iteratively identifying the highest peak, fitting a Gaussian, creating a Partial Range Histogram (PRH) for that peak's range, removing the PRH's contribution from the global histogram, and repeating until the histogram is empty. It sets itself apart from its sibling [Partial Range Histogram (PRH)](12656-partial-range-histogram-prh.md) by providing the iterative search strategy that utilizes PRHs as the core component for isolating distinct materials, and from [TF adaptation peak selection](12678-tf-adaptation-peak-selection.md) by focusing on the detection phase rather than the transfer function construction phase.

## Operating characteristics
- **Time Complexity:** The selective smoothing step iterates until minimal peaks are removed, which depends on the noise level. Global smoothing iterates until $np_1$ peaks remain. Simplification is $O(P \log P)$ or $O(P)$ depending on implementation, where $P$ is the number of peaks. Overall complexity is dominated by the smoothing passes over the histogram bins.
- **Memory Complexity:** $O(N)$ for the histogram array, where $N$ is the number of bins.
- **Measured Performance:** Evaluated on 20 MR AAA angiographies with a block size of $8^3$ [S1]. The method successfully detects peaks in both original and $\alpha$-histograms [S1].
- **Strengths:** Effectively removes noise while preserving subtle peaks through selective smoothing. The area-based assessment provides a robust metric for peak importance.
- **Limitations:** The choice of $np_2$ affects the number of detected materials. The base line construction is geometrically complex to implement precisely without visual aids.
- **When to use:** When automatic transfer function generation is required for noisy $\alpha$-histograms and the user wants to retain the most significant material peaks.
- **When not to use:** When precise spatial localization of materials is required (use PRH instead) or when a specific valid range for materials is known (use TF adaptation peak selection).

## Background
The Alpha-histogram Peak Analysis Scheme was introduced in the paper "The alpha-histogram: Using Spatial Coherence to Enhance Histograms and Transfer Function Design" [S1]. It is part of the broader effort to automate transfer function design in volume rendering by leveraging the spatial coherence properties of the $\alpha$-histogram [S1]. The method addresses the challenge of noise in histograms and the need for an automatic assessment of peak importance [S1].
