# TF adaptation peak selection
Also called: Valid range peak selection
## Overview
This method selects the optimal transfer function peak from a set of candidate peaks detected in an $\alpha$-histogram or original density histogram. It solves the problem of identifying the most representative material density for automatic classification by prioritizing peaks that fall within a predefined "valid range" and maximizing a confidence metric. It differs from its parent, [Alpha-histogram Peak Analysis Scheme](12652-alpha-histogram-peak-analysis-scheme.md), by implementing a specific selection logic based on validity and confidence rather than just raw peak height, and from siblings like [Partial Range Histogram (PRH)](12656-partial-range-histogram-prh.md) by relying on the confidence score $c_p$ derived from the peak analysis scheme rather than partial range constraints alone.
## How it works
**Inputs:**
- A set of detected peaks $P = \{p_1, p_2, ..., p_k\}$, where each peak $p_i$ has an apex value $a_i$ and a confidence score $c_i$.
- A valid range $[r_{min}, r_{max}]$ defining the acceptable density interval.

**Outputs:**
- The selected peak $p_{selected}$ with apex $a_{selected}$.

**Data Structures:**
- Peaks are stored as tuples or objects containing `apex` (float/int) and `confidence` (float).

**Steps:**
1. **Filter Valid Peaks:** Identify the subset of peaks $P_{valid} \subseteq P$ such that for each $p_i \in P_{valid}$, the apex $a_i$ satisfies $r_{min} \le a_i \le r_{max}$.
2. **Check for Valid Candidates:**
   - If $P_{valid}$ is not empty, select the peak $p_j \in P_{valid}$ with the maximum confidence score $c_j$. That is, $p_{selected} = \arg\max_{p_i \in P_{valid}} c_i$.
   - If $P_{valid}$ is empty, select the peak $p_k \in P$ that minimizes the distance to the valid range. The distance is defined as $\min(|a_k - r_{min}|, |a_k - r_{max}|)$. If multiple peaks have the same minimal distance, the source does not specify a tie-breaking rule [G: typically, select the one with higher confidence or the first encountered].
3. **Return:** The selected peak $p_{selected}$.

**Parameters:**
- **Valid Range:** Defined by the application or previous analysis steps. The source mentions a static peak apex predictor at 98.1% of the full histogram area as a reference, but the valid range itself is a parameter for this selection step [S1].
- **Confidence ($c_p$):** A metric calculated by the parent [Alpha-histogram Peak Analysis Scheme](12652-alpha-histogram-peak-analysis-scheme.md). Specific formula not detailed in this article's scope.

**Pitfalls:**
- **Zero Intensity:** Intensity value 0 is discarded from the histogram before peak detection because it is often orders of magnitude more frequent than other values [S1].
- **No Valid Peaks:** If no peaks fall within the valid range, the fallback to the closest peak may select a suboptimal material representation if the valid range is poorly defined.

**Pseudocode:**
```python
def select_peak(peaks, valid_range_min, valid_range_max):
    """
    Selects the best peak based on validity and confidence.
    
    Args:
        peaks: List of dicts with 'apex' and 'confidence' keys.
        valid_range_min: Lower bound of the valid density range.
        valid_range_max: Upper bound of the valid density range.
        
    Returns:
        The selected peak dict.
    """
    # Step 1: Filter peaks within the valid range
    valid_peaks = [
        p for p in peaks 
        if valid_range_min <= p['apex'] <= valid_range_max
    ]
    
    # Step 2: Select based on availability
    if valid_peaks:
        # Select peak with highest confidence among valid ones
        selected = max(valid_peaks, key=lambda p: p['confidence'])
    else:
        # Select peak closest to the valid range
        def distance_to_range(apex):
            if apex < valid_range_min:
                return valid_range_min - apex
            elif apex > valid_range_max:
                return apex - valid_range_max
            else:
                return 0.0
        
        # Find min distance
        min_dist = min(peaks, key=lambda p: distance_to_range(p['apex']))
        selected = min_dist
        
    return selected
```

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the number of detected peaks, as it requires a single pass to filter and a single pass to find the maximum or minimum.
- **Memory Complexity:** $O(N)$ to store the list of valid peaks.
- **Strengths:** Robust to noise by using confidence scores; handles cases where no perfect peak exists by falling back to the closest valid candidate.
- **Limitations:** Relies heavily on the accuracy of the "valid range" definition. If the range is too narrow, the fallback mechanism may be triggered frequently.
- **When to use:** When automatic classification requires a single dominant peak from a histogram that may contain multiple local maxima or noise-induced peaks.
## Background
Originated in the context of automatic transfer function design for volume rendering, specifically in medical imaging (e.g., MR AAA angiographies) [S1]. The method is part of a pipeline that includes histogram enhancement and peak detection, aiming to reduce manual tuning of transfer functions.
