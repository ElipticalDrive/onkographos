# Voxel-based Transfer Function Optimization

Also called: Least Squares Transfer Function Optimization, Linear Transfer Function Optimization

## Overview
Voxel-based Transfer Function Optimization automatically computes a target transfer function $T_o$ for a scalar field $F_o$ such that its rendered output matches a reference field $F_r$ rendered with a reference transfer function $T_r$. It solves this by minimizing the difference between pre-shaded voxel colors and opacities, formulating the task as a linear least squares problem [S1, unofficial]. Unlike image-based approaches that prioritize voxels with larger visual impact on the final composite, this method treats all voxels equally in the linear system and minimizes differences in both color and opacity, whereas some prior work only optimized color due to the non-linearity of opacity in direct volume rendering [S1, unofficial].

## How it works
**Inputs:**
*   Reference scalar field $F_r$ defined on a rectangular grid.
*   Optimization scalar field $F_o$ defined on the same grid structure.
*   Reference transfer function $T_r$ (discretized).
*   Number of transfer function bins $n_T$.

**Outputs:**
*   Optimized transfer function $T_o$ (vector of $4n_T$ values).

**Data Structures:**
1.  **Transfer Function Bins:** $T$ is discretized into $n_T$ regularly spaced bins. Linear interpolation is used between bins. Each bin stores 4 values (R, G, B, $\alpha$). Total size: $4n_T$ floats.
2.  **System Matrix $A$:** Dimensions $m \times n$, where $m = 4m_V$ and $n = 4n_T$. $m_V$ is the number of voxels. The matrix is sparse; each row has exactly two non-zero entries. Due to the independence of color channels in the linearized formulation, there is a stride of 4 between the two non-zero entries in a row corresponding to the same voxel's color channels [S1, unofficial].
3.  **Target Vector $b$:** Dimensions $m \times 1$. Contains the linearized RGB$\alpha$ colors of the reference field $F_r$ after applying $T_r$.

**Steps:**

1.  **Discretize Transfer Functions:**
    Define $n_T$ bins for both $T_r$ and $T_o$. Assume linear interpolation between bin centers.

2.  **Compute Voxel Colors for Reference Field:**
    For each voxel $i$ in $F_r$ with density $D_i$:
    *   Quantize $D_i$ to bin index $j$ and compute interpolation weight $w(i)$ such that $D_i$ lies between bin $j$ and $j+1$.
    *   Calculate the pre-shaded color $V_{r,i}$ by applying $T_r$:
        $$ V_{r,i} = (1 - w(i))T_r(D_i) + w(i)T_r(D_i+1) $$
        Here $T_r(D)$ returns a 4-vector (R, G, B, $\alpha$).
    *   Store $V_{r,i}$ in the target vector $b$ at index corresponding to voxel $i$.

3.  **Construct System Matrix $A$ for Optimization Field:**
    For each voxel $i$ in $F_o$ with density $D_i$:
    *   Quantize $D_i$ to bin index $j$ and compute interpolation weight $w(i)$.
    *   The relationship between the unknown transfer function entries $T_o$ and the resulting voxel color $V_{o,i}$ is linear.
    *   Construct the row(s) in matrix $A$ corresponding to voxel $i$. Since $V_{o,i}$ depends only on $T_o$ entries at bins $j$ and $j+1$, the row has non-zero entries only at columns corresponding to these bins.
    *   Specifically, for the $k$-th channel (R, G, B, $\alpha$) of voxel $i$, the equation is:
        $$ V_{o,i,k} = (1 - w(i)) \cdot T_{o, j, k} + w(i) \cdot T_{o, j+1, k} $$
    *   Fill $A$ such that $A_{row, col} = (1 - w(i))$ or $w(i)$ depending on the channel and bin index. Note that channels do not interact, creating a block-diagonal-like structure with stride 4 [S1, unofficial].

4.  **Formulate Least Squares Problem:**
    The goal is to find $T_o$ (vector $x$) such that $A x \approx b$. This is an over-determined system since $m \gg n$ (number of voxels is typically much larger than number of TF bins).
    Minimize the energy term:
    $$ E(x) = \| b - Ax \|_2^2 = (b - Ax)^T (b - Ax) $$

5.  **Solve for $T_o$:**
    Solve the normal equations:
    $$ A^T A x = A^T b $$
    The solution is:
    $$ x = (A^T A)^{-1} A^T b $$
    If $A$ has full rank, this provides the optimal least squares solution [S1, unofficial].

```python
def voxel_based_tf_optimization_full(F_r, F_o, T_r, n_T, num_voxels):

    Full implementation including T_r.
    """
    # Bin centers
    bin_centers = np.linspace(0, 1, n_T)
    
    # Dimensions
    m = 4 * num_voxels
    n = 4 * n_T
    
    # Initialize sparse matrix A and vector b
    # Using COO format for efficiency due to sparsity
    rows = []
    cols = []
    vals = []
    b = np.zeros(m)
    
    # Precompute T_r values at bin centers if not already done
    # T_r is assumed to be an array of shape (n_T, 4)
    # If T_r is a function, evaluate it at bin_centers
    
    for i in range(num_voxels):
        d_r = F_r[i]
        d_o = F_o[i]
        
        # Quantize density to bin index and compute weight
        # Assuming density is normalized to [0, 1]
        # Handle edge cases: clamp density to [0, 1]
        d_r = np.clip(d_r, 0, 1)
        d_o = np.clip(d_o, 0, 1)
        
        # Find bin index j such that bin_centers[j] <= d < bin_centers[j+1]
        # Using searchsorted
        j_r = np.searchsorted(bin_centers, d_r, side='right') - 1
        j_r = np.clip(j_r, 0, n_T - 2) # Ensure j is within valid range for interpolation
        
        w_r = (d_r - bin_centers[j_r]) / (bin_centers[j_r + 1] - bin_centers[j_r])
        if np.isnan(w_r): w_r = 0.0 # Handle case where d_r == bin_centers[j_r] exactly or identical bins
        
        j_o = np.searchsorted(bin_centers, d_o, side='right') - 1
        j_o = np.clip(j_o, 0, n_T - 2)
        
        w_o = (d_o - bin_centers[j_o]) / (bin_centers[j_o + 1] - bin_centers[j_o])
        if np.isnan(w_o): w_o = 0.0
        
        # Compute reference voxel color V_r,i
        # T_r[j] is a vector of 4 values (R,G,B,a)
        V_r_i = (1 - w_r) * T_r[j_r] + w_r * T_r[j_r + 1]
        
        # Fill target vector b
        # Indices in b for voxel i: 4*i, 4*i+1, 4*i+2, 4*i+3
        b[4*i : 4*i+4] = V_r_i
        
        # Fill system matrix A for optimization field F_o
        # The equation is V_o,i = (1-w_o)*T_o[j_o] + w_o*T_o[j_o+1]
        # T_o is a vector of size 4*n_T
        # Channels are independent, stride 4
        
        # For each channel k in 0..3
        for k in range(4):
            row_idx = 4*i + k
            
            # Column indices for T_o entries corresponding to bins j_o and j_o+1 for channel k
            col_idx_1 = 4 * j_o + k
            col_idx_2 = 4 * (j_o + 1) + k
            
            rows.append(row_idx)
            cols.append(col_idx_1)
            vals.append(1 - w_o)
            
            rows.append(row_idx)
            cols.append(col_idx_2)
            vals.append(w_o)
            
    # Construct sparse matrix A
    A = np.zeros((m, n))
    A[np.array(rows), np.array(cols)] = vals
    
    # Solve least squares problem: min ||Ax - b||^2
    # Using normal equations: (A^T A) x = A^T b
    ATA = A.T @ A
    ATb = A.T @ b
    
    # Solve linear system
    # Check for singularity/ill-conditioning
    try:
        T_o = np.linalg.solve(ATA, ATb)
    except np.linalg.LinAlgError:
        # Fallback to pseudo-inverse if singular
        T_o = np.linalg.lstsq(A, b, rcond=None)[0]
        
    return T_o
```

**Parameters:**
*   $n_T$: Number of transfer function bins. Typical values depend on the desired smoothness and complexity of the TF. Not given in the sources.
*   $m_V$: Number of voxels. Determined by the volume resolution.
*   Density range: Assumed normalized to $[0, 1]$ for bin quantization. If not, normalization is required.

**Edge Cases and Pitfalls:**
*   **Numerical Instability:** The condition number of the normal equations matrix $A^T A$ is the square of the condition number of $A$ ($\text{cond}(A^T A) = \text{cond}(A)^2$). This can lead to stability issues if $A$ is ill-conditioned [S1, unofficial].
*   **Boundary Conditions:** Density values outside the range of the transfer function bins must be handled (e.g., clamping or extrapolation). The pseudocode clamps to $[0, 1]$ and assumes bins cover this range.
*   **Rank Deficiency:** If $A$ does not have full rank, the normal equations solution may not be unique. Use pseudo-inverse or regularization if necessary.

## Operating characteristics
*   **Time Complexity:** Solving the normal equations involves forming $A^T A$ ($O(m \cdot n^2)$ or less due to sparsity) and solving the linear system ($O(n^3)$). Since $n = 4n_T$ is typically small and $m = 4m_V$ is large, the dominant cost is forming the system. Sparse matrix operations can reduce this.
*   **Memory Complexity:** Storing $A$ requires $O(m)$ space if using a sparse format (since each row has 2 non-zeros). $b$ requires $O(m)$. $A^T A$ requires $O(n^2)$.
*   **Strengths:** Fast solution via linear algebra; treats all voxels equally; minimizes both color and opacity errors.
*   **Limitations:** Sensitive to ill-conditioning; assumes linear relationship between TF entries and voxel colors (valid for pre-shading); does not account for the non-linear nature of volume rendering integration (unlike image-based methods).
*   **When to use:** When a fast, global optimization of the transfer function is needed and the linear approximation is sufficient.
*   **When not to use:** When the non-linear effects of volume rendering (e.g., occlusion, blending) are critical and need to be modeled in the optimization.

## Background
The voxel-based transfer function optimization method was proposed by the authors of [S1, unofficial] as part of a comparative study with image-based optimization using differentiable direct volume rendering (DiffDVR). It builds upon earlier work using least squares for transfer function optimization, such as Berger et al. [BLL19] and Günther et al. [GRT13], but specifically formulates the problem in voxel space to minimize per-voxel color and opacity residuals. The method addresses the problem of automatically computing a transfer function for a scalar field to match a reference visualization.
