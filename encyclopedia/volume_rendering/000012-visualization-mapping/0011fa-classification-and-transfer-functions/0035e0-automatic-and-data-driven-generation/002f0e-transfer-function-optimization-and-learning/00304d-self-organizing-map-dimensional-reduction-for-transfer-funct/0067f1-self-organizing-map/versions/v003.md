# Self-Organizing Map

Also called: Kohonen Map, Kohonen's maps

## Overview
A Self-Organizing Map (SOM) is a neural network trained using unsupervised learning to produce a low-dimensional (typically two-dimensional), discretized representation of the input space of training samples [S1]. It maps high-dimensional data points onto a 2D grid organized by similarity, facilitating efficient data compression [S1]. In volume rendering, it structures voxel attributes (signatures) for transfer function design, building on [Self-Organizing Map Dimensional Reduction for Transfer Functions](6242-self-organizing-map-dimensional-reduction-for-transfer-funct.md) [S1].

## Subtopics

### Self-Sorting Map
A variant that avoids the isolation problem of SOM by swapping assigned positions of four input vectors at a time [S1]. ### Fast Linear Assignment Sorting (Fast LAS)
An adaptation of Linear Assignment Sorting (LAS) that outperforms other sorting methods in speed and quality for non-parallel computations by swapping all (or several) vectors simultaneously using a continuously filtered map [S1]. Designed to handle millions of items (e.g., Gaussians) where standard grid-sorting algorithms are inadequate [S1]. Enables continuous sorting of Gaussian data during training [S1].
