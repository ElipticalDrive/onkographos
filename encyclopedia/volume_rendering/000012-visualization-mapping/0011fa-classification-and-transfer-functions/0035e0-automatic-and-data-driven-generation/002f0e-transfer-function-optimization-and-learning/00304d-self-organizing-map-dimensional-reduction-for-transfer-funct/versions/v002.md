# Self-Organizing Map Dimensional Reduction for Transfer Functions

Also called: Dimensional reduction for TF design, Multi-dimensional Transfer Function Design using Self-Organizing Maps, SOM-based TF design, Voxel Signature Mapping

## Overview
This method simplifies the design of multi-dimensional (nD) transfer functions by reducing the dimensionality of voxel signatures using Self-Organizing Maps (SOMs) [S1]. It maps nD voxel signatures to a 2D map space, allowing the user to define optical properties in the 2D space, which is then composed with the dimensional reduction function to form the actual nD transfer function [S1]. Unlike explicit nD TF definition, this approach uses a simplified 2D interaction space, making exploration easier as dimensionality increases [S1]. It performs non-discrete classification, representing uncertainty, unlike volume segmentation techniques [S1].

## How it works
**Inputs:** Volume data (scalar or multivariate); user-defined voxel signature attributes (e.g., scalar value, gradient magnitude, directional second derivative, or statistical measures like mean, standard deviation, cubic root of third-order moment from a subvolume centered at the voxel) [S1].
**Outputs:** A multidimensional transfer function defined as the composition of a dimensional reduction function (mapping nD signature to 2D map coordinates) and a 2D transfer function (mapping 2D map coordinates to optical properties) [S1].

**Data Structures:**
*   **Voxel Signature:** An nD vector $\vec{V}$ containing normalized attribute values.
*   **SOM Grid:** A 2D array (Kohonen) or spherical mesh (Icosahedron-subdivided) of cells. Each cell $C_i$ has a weight vector $\tilde{W}(C_i)$ of dimension n.
*   **Map Coordinates:** For each voxel, a 2D coordinate $(u, v)$ corresponding to the Best Matching Unit (BMU) in the SOM grid [S1].

**Parameters:**
*   **Learning Rate ($\eta$):** Constant between 0 and 1. Stage 1: $\eta = 0.3$. Stage 2: $\eta = 0.5$ [S1].
*   **Map Size:** Kohonen maps: at least $20 \times 20$ cells (typical $32 \times 32$). Spherical maps: at least 7 subdivisions by icosahedron edge (typical 10) [S1].
*   **Distance Metric:** Weighted Euclidean distance. Vector elements are multiplied by weights before evaluation [S1].
    *   Statistical variables (mean, std dev, cubic root 3rd moment): Weights 1.3, 1.0, 0.7 respectively [S1].
    *   Scalar and first/second derivative values: Weights 1.0, 1.0, 0.7 respectively [S1].
    *   Hurricane dataset (wind speed, pressure, temperature): Weights 1.0, 1.0, 0.5 respectively [S1].
*   **Background Removal:** Optional. Uses region growing from exterior background seeds to exclude background voxels (e.g., air) from training [S1].

**Steps:**

1.  **Preprocessing:** Extract nD voxel signatures from volume data. Normalize the values. If background removal is enabled, identify background voxels in exterior regions and use region growing to exclude them from the training set [S1].
2.  **SOM Initialization:** Initialize weight vectors $\tilde{W}(C_i)$ for all cells $C_i$ in the SOM grid with random values between 0 and 1. The dimension of $\tilde{W}$ must match the dimension of the input voxel signatures [S1].
3.  **SOM Training Stage 1 (Global Structure):** Present non-background voxel signatures as training cases in random order. Update weights using the Gaussian neighborhood function $nf1(td)$ [S1]:
    $$nf1(td) = \exp\left(-\frac{td^2}{3}\right)$$
    where $td$ is the topological distance between the winner cell and the cell in focus. For Kohonen maps, $td$ is the Euclidean distance between integer 2D coordinates. For spherical maps, $td$ is the number of edges in the shortest path [S1].
    The weight update for cell $C_i$ is:
    $$\tilde{W}_{t+1}(C_i) = (1-a) \times \tilde{W}_t(C_i) + a \times \vec{T}$$
    where $a = \eta \times nf1(td(BMU, C_i))$, $\eta = 0.3$, and $\vec{T}$ is the current training case [S1].
4.  **SOM Training Stage 2 (Refinement):** Continue training with the same random order of signatures. Use the modified neighborhood function $nf2(td, d)$ [S1]:
    $$nf2(td, d) = \min(d, 1) \times \exp\left(-\frac{td^2}{3}\right)$$
    where $d$ is the distance between the training case $\vec{T}$ and the winner cell's weight vector $\tilde{W}(BMU)$ [S1]. This allows signatures far from their winner cell to have more influence, preventing large homogeneous regions from dominating the map [S1].
    The weight update uses $\eta = 0.5$ and $nf2$ [S1].
5.  **Dimensional Reduction:** Map all voxels (including background) to the 2D map space. For each voxel, find the Best Matching Unit (BMU) in the SOM grid based on signature similarity. Assign the voxel the 2D coordinates of its BMU [S1].
6.  **TF Design in 2D Space:** The user specifies the transfer function (optical properties like color and opacity) by interacting in the 2D map space. This is described as "dual domain interaction" [S1].
    *   **Automatic Color TF:** Assign different colors to different regions of the SOM map, corresponding to voxels with considerably different attribute values [S1].
    *   **Manual Opacity TF:** Allow user interaction by moving Gaussian opacity functions on the map space to tune parameters [S1].
7.  **Rendering:** The actual multidimensional transfer function is the composition of the dimensional reduction function (mapping nD signature to 2D map coordinates) and the 2D transfer function (mapping 2D map coordinates to optical properties) [S1].
    *   Evaluate Radial Basis Functions (RBF) for each non-background voxel to determine the transfer function response. This is solved using the Lapack library [S1].
    *   Render the volume using OpenGL and Cg. Use hardware interpolation for map coordinates and precomputed normals by default. Allow user selection of color/opacity interpolation and on-the-fly normal computation for high-quality rendering [S1]. Note: Precomputed normals cannot be used for multivariate data sets (e.g., Hurricane) because attributes lack a clear physical meaning for normal orientation [S1].

```python
import math
import random

def weighted_euclidean_distance(v1, v2, weights):
    """Calculate weighted Euclidean distance between two vectors."""
    dist_sq = 0.0
    for i in range(len(v1)):
        diff = (v1[i] - v2[i]) * weights[i]
        dist_sq += diff * diff
    return math.sqrt(dist_sq)

def topological_distance_kohonen(c1, c2):
    """Topological distance for Kohonen map (Euclidean distance between grid coords)."""
    return math.sqrt((c1[0] - c2[0])**2 + (c1[1] - c2[1])**2)

def gaussian_neighborhood(td):
    """Equation 3: Gaussian neighborhood function."""
    return math.exp(-(td**2) / 3.0)

def modified_neighborhood(td, d):
    """Equation 4: Modified neighborhood function."""
    return min(d, 1.0) * math.exp(-(td**2) / 3.0)

def train_som(signatures, map_width, map_height, is_spherical=False, 
              num_steps_stage1=3000000, num_steps_stage2=4500000,
              weights=None):
    """
    Train SOM on voxel signatures.
    signatures: List of nD vectors.
    map_width, map_height: Dimensions of the Kohonen grid.
    is_spherical: If True, use spherical topology (requires additional mesh data).
    weights: List of weights for each dimension of the signature.
    """
    if weights is None:
        weights = [1.0] * len(signatures[0])
    
    n_dims = len(signatures[0])
    
    # Initialize weights randomly between 0 and 1
    som_grid = []
    for y in range(map_height):
        row = []
        for x in range(map_width):
            row.append([random.random() for _ in range(n_dims)])
        som_grid.append(row)
    
    # Stage 1: Global Structure
    eta = 0.3
    for step in range(num_steps_stage1):
        t = random.choice(signatures)
        # Find BMU
        min_dist = float('inf')
        bmu = None
        for y in range(map_height):
            for x in range(map_width):
                dist = weighted_euclidean_distance(t, som_grid[y][x], weights)
                if dist < min_dist:
                    min_dist = dist
                    bmu = (x, y)
        
        # Update weights
        for y in range(map_height):
            for x in range(map_width):
                td = topological_distance_kohonen(bmu, (x, y))
                nf = gaussian_neighborhood(td)
                a = eta * nf
                for d in range(n_dims):
                    som_grid[y][x][d] = (1 - a) * som_grid[y][x][d] + a * t[d]

    # Stage 2: Refinement
    eta = 0.5
    for step in range(num_steps_stage2):
        t = random.choice(signatures)
        # Find BMU
        min_dist = float('inf')
        bmu = None
        for y in range(map_height):
            for x in range(map_width):
                dist = weighted_euclidean_distance(t, som_grid[y][x], weights)
                if dist < min_dist:
                    min_dist = dist
                    bmu = (x, y)
        
        # Update weights
        for y in range(map_height):
            for x in range(map_width):
                td = topological_distance_kohonen(bmu, (x, y))
                nf = modified_neighborhood(td, min_dist)
                a = eta * nf
                for d in range(n_dims):
                    som_grid[y][x][d] = (1 - a) * som_grid[y][x][d] + a * t[d]
                    
    return som_grid

def dimensional_reduction(signatures, som_grid, map_width, map_height, weights=None):
    """
    Map all voxels to 2D map coordinates.
    Returns list of 2D coordinates for each signature.
    """
    if weights is None:
        weights = [1.0] * len(signatures[0])
        
    map_coords = []
    for sig in signatures:
        min_dist = float('inf')
        bmu = None
        for y in range(map_height):
            for x in range(map_width):
                dist = weighted_euclidean_distance(sig, som_grid[y][x], weights)
                if dist < min_dist:
                    min_dist = dist
                    bmu = (x, y)
        map_coords.append(bmu)
    return map_coords
```

## Operating characteristics
*   **Time Complexity:** Training time is quadratically related to map size (number of cells) and proportional to weight vector size. Winner search is linear in the number of cells. Weight vector size has linear influence on winner search and update time [S1]. Dimensional reduction time is proportional to the number of non-background voxels, map size, and weight vector size [S1]. RBF evaluation time is proportional to the number of cells and the size of weight vectors [S1].
*   **Measured Performance:**
    *   **Training (32x32 Kohonen):** 57 seconds for 3,000,000 steps (Stage 1) and 87 seconds for 4,500,000 steps (Stage 2) [S1].
    *   **Training (Spherical, 10 subdivisions):** 151 seconds for 3,000,000 steps (Stage 1) and 264 seconds for 5,250,000 steps (Stage 2) [S1].
    *   **Dimensional Reduction (Kohonen):**
        *   Engine (256x2x128, 5,297,265 non-bg voxels): 140 seconds [S1].
        *   Tooth (128x2x256, 4,193,888 non-bg voxels): 110 seconds [S1].
        *   Foot (256^3, 4,890,753 non-bg voxels): 133 seconds [S1].
        *   Carp (256x2x512, 32,806,605 non-bg voxels): 845 seconds [S1].
        *   Hurricane (256x2x128, 8,388,608 non-bg voxels): 220 seconds [S1].
        *   Sheep heart (256^3, 16,776,721 non-bg voxels): 375 seconds [S1].
    *   Spherical map dimensional reduction time is approximately 13% greater than Kohonen map time [S1].
*   **Strengths:** Simplifies nD TF design by reducing it to 2D interaction. Handles arbitrary dimensional voxel signatures. Non-discrete classification represents uncertainty. Automatic color TFs emphasize details hard to visualize otherwise. Exploring 2D maps is easier and faster than navigating a class hierarchy [S1].
*   **Limitations:** Dimensional reduction causes loss and distortion of information, making accurate quantitative analysis impossible. Suitable only for qualitative aspects like shape and dissimilarity [S1]. Precomputed normals cannot be used for multivariate data sets [S1].
*   **When to use:** When designing multi-dimensional transfer functions for qualitative visualization and exploration. When the user needs to handle high-dimensional voxel signatures without manual nD interaction.
*   **When not to use:** When accurate quantitative analysis of the volume data is required during TF specification. When using multivariate data where precomputed normals are desired for shading [S1].

## Background
This method was proposed in a paper titled "Design of Multi-dimensional Transfer Functions Using Dimensional Reduction" [S1]. It addresses the difficulty of designing multi-dimensional transfer functions, where interaction and visualization become more difficult as the domain increases [S1]. The approach uses self-organizing maps (SOMs) and radial basis functions (RBFs) to simplify the design process [S1]. It is implemented using OpenGL, Cg, GLUT, GLUI, and the Lapack library [S1]. The method was tested on various datasets including Engine, Tooth, Foot, Carp, Hurricane, and Sheep heart [S1].
