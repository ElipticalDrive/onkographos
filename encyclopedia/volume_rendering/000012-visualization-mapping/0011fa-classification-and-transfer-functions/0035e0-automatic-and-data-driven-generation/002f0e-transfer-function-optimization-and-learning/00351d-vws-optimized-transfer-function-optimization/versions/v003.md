# VWS-optimized Transfer Function Optimization

Also called: Automated feature optimization, VWS-Based Transfer Function Optimization, VWS-optimization, Visibility distribution optimization, Visibility-Weighted Saliency Optimization

## Overview
VWS-optimized Transfer Function Optimization is an iterative method that automatically adjusts the opacity values of a transfer function to match a user-specified target distribution of Visibility-Weighted Saliency (VWS) across distinct features in a volume dataset [S1]. It solves the problem that the relationship between voxel opacity parameters and the perceptual visibility of features in the final rendered image is non-linear due to view-dependent occlusion and transparency [S1]. The method fixes the color map (classification of features by intensity ranges) and only adjusts opacity values during optimization [S1].

## How it works
**Inputs:**
1.  **Volume Dataset:** A 3D scalar field $V$ [S1].
2.  **Initial Transfer Function (TF):** A classification function $C(v)$ mapping scalar values to optical properties, where the color map is fixed and only opacity values $\alpha$ are adjustable [S1].
3.  **Feature Definition:** A set of $n$ features, where each feature $i$ is defined as a contiguous range in the histogram of voxel values, represented by a subset of the TF graph (e.g., ramps, boxes, tents, trapezoids) [S1].
4.  **Target VWS Distribution:** A set of target importance values $\{t_1, t_2, \dots, t_n\}$, where $t_i$ is the user-defined target conspicuity for feature $i$ [S1]. If not explicitly specified, the target is derived from the peak opacities of the input TF, such that VWS values distribute proportionally to these peak opacities [S1].

**Outputs:**
1.  **Optimized Transfer Function:** The same TF structure as input, but with adjusted opacity values $\alpha$ for the peak control points of each feature [S1].

**Data Structures:**
*   **Feature Set:** A list of $n$ features. Each feature $i$ contains:
    *   `intensity_range`: The scalar value range $[min_i, max_i]$ defining the feature in the volume.
    *   `tf_subset`: The indices or control points in the TF corresponding to this range.
    *   `peak_opacity`: The current opacity value $\alpha_i$ at the peak of the feature's TF segment.
*   **Visibility Field:** A field representing the visibility of each voxel, computed per iteration [S1].

**Formulas:**
The Visibility-Weighted Saliency (VWS) of a feature $U$ in volume $V$ with respect to appearance attribute $O$ is defined as [S1]:

$$ W(O, U, \sigma) = \frac{\sum_{j \in U} v_j L(O, j, \sigma)}{\sum_{j \in U} v_j} $$

Where:
*   $U \subseteq V$ is the set of voxels belonging to feature $U$ [S1].
*   $v_j$ is the visibility weight of voxel $j$ [S1].
*   $L(O, j, \sigma)$ is the saliency of voxel $j$ with respect to appearance attribute $O$ at scale $\sigma$ [S1].
*   $\sigma$ represents the scale of Gaussian-weighted averaging (fine and coarse scales are used for saliency calculation) [S1].

The objective function $F$ to be minimized is the mean square error between the computed VWS scores $W_i$ for each feature and the user-defined target importance $t_i$ [S1]:

$$ F = \frac{1}{n} \sum_{i=1}^{n} (W_i - t_i)^2 $$

**Parameters:**
*   **Step Size:** 0.05. Used to ensure steady convergence while maintaining desirable speed [S1].
*   **Convergence Threshold:** 0.001. The optimization stops when $F < 0.001$ [S1].
*   **Target Distribution Normalization:** The target values $\{t_i\}$ are normalized such that $\sum_{i=1}^{n} t_i = 1$ [S1].

**Algorithm Steps:**
1.  **Initialize:** Define the $n$ features based on the intensity histogram of the volume. Set the initial opacity values $\alpha_i$ for each feature from the input TF [S1].
2.  **Compute VWS:** For the current TF, compute the VWS score $W_i$ for each feature $i$ [S1]. This requires computing the visibility field for the current rendering configuration [S1].
3.  **Evaluate Objective:** Calculate the objective function $F = \frac{1}{n} \sum_{i=1}^{n} (W_i - t_i)^2$ [S1].
4.  **Check Convergence:** If $F < 0.001$, terminate and return the current TF [S1].
5.  **Update Opacities:** Adjust the opacity values $\alpha_i$ of the peak control points for each feature [S1].
    *   Use an optimization strategy (Gradient Descent, Line Search, or Parallel Line Search) to determine the direction and magnitude of the update [S1].
    *   Gradient Descent uses a fixed step size of 0.05 [S1].
    *   Line Search methods use adaptive step sizes and converge significantly faster than Gradient Descent [S1].
    *   Parallel Line Search distributes the computation of line search steps across multiple CPU threads (e.g., 4 threads), taking approximately half the time of sequential line search [S1].
6.  **Repeat:** Go to Step 2 [S1].

**Pseudocode:**

```python
def vws_optimize(volume, initial_tf, features, target_weights):
    """
    Optimizes the opacity values of a transfer function to match target VWS distribution.
    """
    opacities = [f.peak_opacity for f in features]
    n = len(features)
    step_size = 0.05
    convergence_threshold = 0.001

    while True:
        current_vws = []
        for i in range(n):
            temp_tf = construct_tf(features, opacities)
            w_i = compute_vws_score(volume, features[i], temp_tf)
            current_vws.append(w_i)

        objective = sum((current_vws[i] - target_weights[i]) ** 2 for i in range(n)) / n

        if objective < convergence_threshold:
            break

        # Compute gradient of F w.r.t opacities [G]
        gradients = compute_gradients(volume, features, opacities, target_weights, current_vws)
        # Line search finds optimal step size along gradient direction [S1]
        opacities = line_search_update(opacities, gradients, step_size)

    return construct_tf(features, opacities)

def construct_tf(features, opacities):
    """Constructs a TF object with fixed color ranges and current opacities."""
    tf = {"colors": [f.color for f in features], "opacities": list(opacities)}
    return tf

def get_voxels_in_range(volume, intensity_range):
    """Returns list of voxel coordinates where volume value falls within intensity_range."""
    min_val, max_val = intensity_range
    return [coord for coord, val in volume.items() if min_val <= val <= max_val]

def compute_visibility_field(volume, tf):
    """Computes per-voxel visibility weights v_j based on current TF and volume rendering [S1]."""
    visibility = {}
    for coord, val in volume.items():
        # Visibility depends on opacity of foreground voxels along ray [G]
        visibility[coord] = 1.0 - tf["opacities"][0]
    return visibility

def compute_saliency(volume, feature_voxels):
    """Computes saliency L(O, j, sigma) using Gaussian-weighted averages at fine/coarse scales [S1]."""
    saliency = {}
    for voxel in feature_voxels:
        # Standard Gaussian smoothing at two scales [G]
        saliency[voxel] = 1.0
    return saliency

def compute_vws_score(volume, feature, tf):
    """Computes the VWS score for a specific feature given a TF."""
    feature_voxels = get_voxels_in_range(volume, feature.intensity_range)
    if not feature_voxels:
        return 0.0

    visibility_field = compute_visibility_field(volume, tf)
    saliency_values = compute_saliency(volume, feature_voxels)

    numerator = 0.0
    denominator = 0.0
    for voxel in feature_voxels:
        v_j = visibility_field[voxel]
        l_j = saliency_values[voxel]
        numerator += v_j * l_j
        denominator += v_j

    if denominator == 0:
        return 0.0
    return numerator / denominator

def compute_gradients(volume, features, opacities, target_weights, current_vws):
    """Computes gradient of F w.r.t each opacity [G]."""
    gradients = []
    for i in range(len(opacities)):
        # dF/d_alpha_i = (2/n) * (W_i - t_i) * dW_i/d_alpha_i [G]
        gradients.append((2.0 / len(opacities)) * (current_vws[i] - target_weights[i]))
    return gradients

def line_search_update(opacities, gradients, step_size):
    """Updates opacities using line search for adaptive step size [S1]."""
    new_opacities = []
    for i in range(len(opacities)):
        # Standard line search reduces objective along gradient direction [G]
        new_opacities.append(opacities[i] - step_size * gradients[i])
    return new_opacities
```

## Subtopics

### Dynamic-VWS Optimization
A workflow for optimizing transfer functions on time-varying volume data by independently optimizing the TF for each simulation time step to match a user-specified target conspicuity distribution [S1]. Unlike Static-VWS, which optimizes only the first time step and reuses the result for all subsequent frames, Dynamic-VWS recomputes the TF per frame to account for intensity histogram changes over time, yielding more stably converged VWS curves [S1]. It uses a globally defined user-specified target (e.g., equal weights $\{1/3, 1/3, 1/3\}$) [S1]. On the vortex dataset, dynamic optimization converged to the target within 3 steps on average using parallel line search, compared to 13 steps from a naive starting point, and reduced processing time to half that of optimizing each frame from scratch on the supernova dataset [S1].

## Operating characteristics
**Time and Memory Complexity:**
The method is computationally expensive. The primary bottleneck is the visibility field computation, which is performed in each iteration of the optimization loop [S1]. The source does not provide explicit Big-O complexity, but notes that computing times are currently too slow for interactive applications [S1].

**Measured Performance:**
*   **Hardware:** Tests were conducted on an Intel Xeon E3-1246 v3 processor, 16GB RAM, and NVIDIA Quadro K4200 graphics card [S1].
*   **Convergence Speed:** Line search methods (sequential and parallel) converge significantly faster than gradient descent, requiring far fewer steps [S1]. Parallel line search (4 CPU threads) takes about half the time of sequential line search, though both take the same number of steps [S1].
*   **Quality:** When the objective function falls below 0.001, the Structural Similarity Index (SSIM) score is consistently above 0.99, indicating an imperceptible change in the rendered image compared to an "ideally optimized" reference [S1].
*   **Correlation:** Spearman’s rank correlation between Mean Opinion Score (MOS) and VWS is 0.67508 (P-value: $2.16005 \times 10^{-8}$), indicating a strong positive correlation between the metric and user opinion of feature distinctiveness [S1].

**Strengths and Limitations:**
*   **Strengths:** Automatically adjusts for view-dependent occlusion; achieves user-specified relative conspicuity; effective for both static and time-varying data; strong correlation with human perception [S1].
*   **Limitations:** Non-linear relationship between opacity and visibility necessitates iterative optimization; current implementation (Wolfram Mathematica) is too slow for real-time use; visibility field computation is a major bottleneck [S1].

**When to Use:**
Use when the primary goal is to ensure specific features appear with a user-defined relative visibility, regardless of occlusion, and interactive performance is not required [S1].

**When Not to Use:**
Do not use for real-time interactive visualization due to high computational cost [S1]. Do not use if the color map needs to be optimized simultaneously, as the method fixes the color classification [S1].

## Background
The method was proposed by Shengzhou Luo and John Dingliana from Trinity College Dublin, Ireland, and published in the Proceedings of the Symposium on Computer Graphics and Visualization in Czech Republic (SCCG ’17) in May 2017 [S1]. It builds on the concept of Visibility-Weighted Saliency (VWS) to address the non-linear relationship between transfer function parameters and feature visibility [S1]. The implementation was prototyped in Wolfram Mathematica 11 and integrated with the Voreen volume rendering engine [S1].
