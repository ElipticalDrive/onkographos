# MR-TF Approach

Also called: interactive ROI-based DVR in MR-HMDs, intuitive and semi-automated MR-TF approach

## Overview
The MR-TF approach is an interactive method for Direct Volume Rendering (DVR) in Mixed Reality Head-Mounted Displays (MR-HMDs) that combines biometric Region of Interest (ROI) selection with automatic Transfer Function (TF) optimization [S1]. It solves the problem of manually tuning TFs for specific structures in complex volumes by allowing users to select a target region via eye-gaze and finger-pointing, then automatically optimizing TF parameters to match a target visibility [S1]. It differs from general optimization methods by integrating real-time biometric input and optimizing for visibility tolerance weighted against TF movement constraints, specifically tailored for low-spec MR hardware [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D volume data (scalar field), MR-HMD tracking data (eye convergence, head pose, finger pointing vector), and a user-defined target visibility multiplier [S1].
*   **Output:** Optimized Transfer Function parameters $\theta$ and the resulting DVR image [S1].

**Data Structures:**
*   **Volume:** 3D grid of scalar intensity values $v$ [S1].
*   **Transfer Function:** A set of tent-shaped components mapping intensity to opacity [S1]. Each component is defined by its peak intensity value and base opacity, but the bottom side (base opacity) remains fixed during optimization [S1].
*   **ROI Mask:** Binary mask identifying voxels belonging to the selected region [S1].

**Steps:**
1.  **Biometric ROI Selection:**
    *   Generate a gazing plane by casting a line along the y-axis connecting the convergence point of both eyes and the center point of the MR-HMD [S1].
    *   Calculate the 3D intersection point between this gazing plane and the pointing vector of the user's finger [S1].
    *   Display a yellow sphere at the intersection point for validation [S1].
    *   Allow manual adjustment of the 3D point in 5-mm units along each axis via a control panel if precise placement is required [S1].
2.  **ROI Segmentation:**
    *   Use the validated 3D point as the seed voxel for a region growing algorithm [S1].
    *   Retrieve the intensity value $v_{\text{seed}}$ of the seed voxel [S1].
    *   Determine the threshold range based on a user-selected level $L$ (via voice command): $\text{Threshold} = L \times 30$ [S1]. Level 1 corresponds to $\pm 30$ on the intensity value, increasing by 30 steps per level up to a maximum level of 10 [S1].
    *   Iteratively propagate to adjacent voxels. A neighbor voxel is included if its intensity $v_{\text{neighbor}}$ satisfies $|v_{\text{neighbor}} - v_{\text{seed}}| \le \text{Threshold}$ [S1].
    *   Stop when no new adjacent voxels fall within the threshold range [S1].
3.  **Initial TF Setup:**
    *   Initialize the TF as a set of tent-shaped components [S1].
    *   The tent shape is chosen to depict iso-surfaces and allow semi-transparent exhibition of multiple ROIs [S1].
    *   Define the initial parameters $\theta_0$ as the peak positions of the tent-shaped components; the base opacities remain unchanged [S1].
4.  **Visibility Computation:**
    *   Compute the current visibility $V_C(\theta)$ of the ROI in the rendered image [S1].
    *   Obtain the target visibility $V_T$ from the user, expressed as a multiple of the initial visibility of the ROI [S1].
5.  **TF Parameter Optimization:**
    *   Optimize the parameters $\theta$ (specifically the peak positions of the tent-shaped components) using the Nelder-Mead simplex method [S1].
    *   Minimize the loss function $F(\theta) = \omega F_T(\theta) + (1 - \omega) F_M(\theta)$ [S1].
    *   The visibility tolerance loss is $F_T(\theta) = (V_T - V_C(\theta))^2$ [S1].
    *   The movement tolerance loss $F_M(\theta)$ penalizes large deviations from the initial TF to ensure smooth transitions [S1].
    *   $\omega$ is the weight for visibility tolerance [S1].

    # Calculate 3D intersection with finger pointing vector using standard vector projection [G]

    # Validate and allow manual adjustment (handled by UI loop)

    level = get_user_level() # Voice command input, 1 to 10
    threshold = level * 30
    roi_mask = region_growing(volume, final_seed_point, seed_intensity, threshold)

    # Step 3: Initial TF Setup
    initial_tf = create_tent_tf(volume.intensity_range)
    theta = initial_tf.peak_positions # Only peaks are optimized

    # Step 4 & 5: Visibility-based TF Parameter Optimization
    initial_visibility = compute_visibility(volume, roi_mask, initial_tf)
    target_visibility = initial_visibility * target_visibility_multiplier

        current_tf = update_tf(initial_tf, params)
        current_visibility = compute_visibility(volume, roi_mask, current_tf)
        ft = (target_visibility - current_visibility) ** 2
        fm = sum((p - p_init)**2 for p, p_init in zip(params, theta))
        omega = 0.7 # Example weight, typically tuned by user or system
        return omega * ft + (1 - omega) * fm

    optimized_params = nelder_mead_minimize(loss_function, theta)
    return update_tf(initial_tf, optimized_params)

**Edge Cases and Pitfalls:**
*   **Precision:** Manual adjustment is limited to 5-mm units [S1].
*   **Threshold Selection:** If the level is too high, the ROI may include too much background noise; if too low, it may fragment the structure [S1].
*   **Hardware Constraints:** The method is designed for low-spec commercial MR-HMDs, so complex segmentation algorithms are avoided in favor of region growing [S1].

## Operating characteristics
*   **Time Complexity:** Region growing is $O(N)$ where $N$ is the number of voxels in the connected component [G]. Nelder-Mead optimization is iterative and depends on the convergence criteria and dimensionality of $\theta$ [G].
*   **Memory Complexity:** Requires storage for the volume data, ROI mask, and TF parameters [G]. Minimal additional memory compared to standard DVR [G].
*   **Performance:** Optimized for on-device implementation on low-spec hardware [S1].
*   **Strengths:** Intuitive user interaction via biometrics; automatic TF generation reduces manual tuning; robust to noise due to region growing [S1].
*   **Limitations:** Relies on accurate biometric tracking; limited to scalar intensity-based segmentation; visibility computation may be simplified for performance [S1].

## Background
The MR-TF approach was introduced in 2025 by researchers publishing in *Virtual Reality* [S1]. It addresses the challenges of interactive volume rendering in Mixed Reality environments, where traditional manual TF editing is cumbersome due to the immersive nature of the display and the need for real-time interaction [S1]. The method builds on earlier work in intensity-based 1D TFs and tent-shaped components [S1].
