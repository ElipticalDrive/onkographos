# t-SNE for Transfer Function Design
Also called: t-SNE, t-SNE Voxel Similarity Mapping
## Overview
t-SNE for Transfer Function Design is a dimensionality reduction technique applied to multivariate voxel data to create a 2D similarity plot, enabling the separation and segmentation of different phases or features (e.g., noise, bone, sarcoma) based on voxel similarity [S1]. It solves the problem of visualizing high-dimensional multivariate voxel distributions by mapping them to a low-dimensional space where similar voxels are clustered together [S1]. Unlike its siblings, it uses non-linear manifold learning to preserve local neighborhood structures, making it particularly effective at separating complex, non-linearly separable phases such as noise (miasma) from signal [S1].
## How it works
**Inputs:** A 3D volume where each voxel $v$ is represented by a multivariate feature vector $\mathbf{x}_v \in \mathbb{R}^D$. $D$ is the number of modalities or features per voxel (e.g., CT, PET, MRI-T1, MRI-T2) [S1].
**Outputs:** A 2D similarity plot (embedding) where each voxel is mapped to a point $\mathbf{y}_v \in \mathbb{R}^2$, and optionally a clustering label for each voxel [S1].

**Data Structures:**
- Input: Array of shape $(N, D)$, where $N$ is the number of voxels.
- Output: Array of shape $(N, 2)$ containing the 2D coordinates.
- Optional: Array of shape $(N,)$ containing integer cluster labels from k-means.

**Steps:**
1. **Compute Pairwise Similarities:** Calculate the conditional probability $p_{j|i}$ that voxel $mathbf{x}_j$ would pick voxel $\mathbf{x}_i$ as its neighbor if neighbors were picked in proportion to their conditional probability density in a Gaussian neighborhood [S1]. The Gaussian is centered at $\mathbf{x}_i$ with variance $\sigma_i^2$ [S1]. The variance $\sigma_i$ is determined by a perplexity constraint [S1].
   $$ p_{j|i} = \frac{\exp(-\|\mathbf{x}_i - \mathbf{x}_j\|^2 / 2\sigma_i^2)}{\sum_{k \neq i} \exp(-\|\mathbf{x}_i - \mathbf{x}_k\|^2 / 2\sigma_i^2)} $$
   The joint probability $p_{ij} = \frac{p_{j|i} + p_{i|j}}{2N}$ [S1].
2. **Initialize Embedding:** Initialize the 2D positions $\mathbf{y}_i$ for all $N$ voxels randomly or using PCA initialization [G].
3. **Minimize KL Divergence:** Minimize the Kullback-Leibler divergence $C = \sum_i \sum_j p_{ij} \log \frac{p_{ij}}{q_{ij}}$ between the high-dimensional distribution $P$ and the low-dimensional distribution $Q$ [S1]. The low-dimensional similarity $q_{ij}$ is modeled by a Student's t-distribution with one degree of freedom (Cauchy distribution):
   $$ q_{ij} = \frac{(1 + \|\mathbf{y}_i - \mathbf{y}_j\|^2)^{-1}}{\sum_{k \neq l} (1 + \|\mathbf{y}_k - \mathbf{y}_l\|^2)^{-1}} $$
   The gradient descent updates $\mathbf{y}_i$ to reduce $C$ [S1].
4. **Generate Similarity Plot:** Map each voxel to its final 2D coordinate $\mathbf{y}_v$ [S1].
5. **Cluster (Optional):** Apply k-means clustering to the 2D points $\mathbf{y}_v$ to assign labels to voxels [S1]. Color the plot by these labels [S1].

**Parameters:**
- Perplexity: Not given in the sources.
- Number of clusters ($k$): Not given in the sources.
- Learning rate: Not given in the sources.

**Edge Cases and Pitfalls:**
- Computational cost: t-SNE is $O(N^2)$ or $O(N \log N)$ with approximations, making it expensive for large volumes [G].
- Noise separation: The method successfully separates noise (miasma) into its own region, which is a key advantage [S1].

## Operating characteristics
- **Time Complexity:** Not given in the sources. Standard t-SNE is $O(N^2)$ or $O(N \log N)$ [G].
- **Memory Complexity:** Not given in the sources. Standard t-SNE requires $O(N^2)$ memory for the similarity matrix [G].
- **Measured Performance:** In the MIEC dataset, t-SNE successfully separated phases including CFO, CGO, emergent phases, and miasma (noise) [S1]. In a medical dataset (knee sarcoma), it successfully segmented out the sarcoma and other features such as the patient's bone [S1].
- **Strengths:** Successfully separates complex, non-linearly separable phases; effectively isolates noise (miasma) from signal [S1].
- **Limitations:** Not given in the sources.
- **When to use:** When multivariate voxel data contains complex, non-linear structures that linear methods (like PCA) might fail to separate [S1].
- **When not to use:** When computational resources are limited for large datasets [G].
## Background
The method was applied to multivariate volume data containing four unique modalities per voxel: CT, PET, MRI-T1, and MRI-T2 [S1]. It was used in conjunction with SLIC superpixels and progressive agglomerative clustering for segmentation [S1]. The technique was validated on the MIEC dataset and a medical knee sarcoma dataset [S1].
