# Opacity TF Exploration via Latent Space Projection

Also called: Latent Space Browsing, Latent Space Interpolation, Latent Space TF Exploration, Opacity TF Latent Space Exploration, t-SNE based TF Browsing

## Overview
Opacity TF Exploration via Latent Space Projection is a user interface technique for volume rendering that allows users to browse and select transfer function (TF) variations by interacting with a projected 2D representation of the opacity TF latent space [S1]. It solves the problem of exploring the high-dimensional space of possible opacity functions to understand feature relationships and select appropriate visualizations [S1]. Unlike direct manipulation of TF control points, this method separates features based on latent space similarity, enabling structured browsing and detailed interpolation [S1]. It builds on [t-SNE for Transfer Function Design](7098-t-sne-for-transfer-function-design.md) by providing specific interaction mechanisms (grid browsing and Shepard interpolation) over the t-SNE projection [S1].

## How it works
The method operates on a pre-trained opacity Transfer Function autoencoder/generator that maps a latent vector $\mathbf{z}$ to an opacity TF [S1]. The process consists of four main phases: latent space sampling, 2D projection, structured browsing, and detailed interpolation [S1].

### Inputs and Outputs
*   **Inputs:**
    *   Pre-trained opacity TF decoder $D: \mathbb{R}^8 \rightarrow \text{TF}$ [S1].
    *   Pre-trained opacity TF encoder implemented via the 1D convolutional layers of the opacity GAN’s generator $E: \text{TF} \rightarrow \mathbb{R}^8$ [S1].
    *   Fixed view and color TFs for the scene [S1].
    *   Volume dataset for rendering [S1].
*   **Outputs:**
    *   2D t-SNE projection of latent samples [S1].
    *   Synthesized volume images corresponding to selected latent regions [S1].

### Data Structures
*   **Latent Space:** 8-dimensional vector space $\mathbb{R}^8$ used to represent opacity TF parameters [S1].
*   **Samples:** A set of $N$ latent vectors $\{\mathbf{z}_i\}_{i=1}^N$ [S1].
*   **Grid:** A $4 \times 4$ rectangular grid overlaid on the 2D projection [S1].
*   **Interpolation Disk:** A circular region in 2D space centered at a user-selected point [S1].

### Steps

1.  **Sample Points in Latent Space**
    Sample $N$ points uniformly at random in the 8D latent space [S1].
    $$ \mathbf{z}_i \sim \text{Uniform}(\mathbb{R}^8), \quad i = 1 \dots N $$

2.  **Obtain TFs via Decoder**
    Push the samples through the decoder to obtain a set of opacity TFs [S1].
    $$ \text{TF}_i = D(\mathbf{z}_i) $$

3.  **Re-encode to Discover Valid Submanifold**
    Transform the obtained TFs back to the latent space via the 1D convolutional layers of the opacity GAN’s generator to probe the range of valid TFs [S1]. This identifies the submanifold of valid TFs, as the decoder is not injective for invalid points [S1].
    $$ \mathbf{z}'_i = E(\text{TF}_i) $$

4.  **Verify Low-Dimensional Structure (Optional Diagnostic)**
    Compute the Singular Value Decomposition (SVD) of the re-encoded samples $\{\mathbf{z}'_i\}$ to observe the falloff in singular values, confirming the low-dimensional structure of valid TFs [S1].

5.  **Project to 2D using t-SNE**
    Project the set of re-encoded latent samples $\{\mathbf{z}'_i\}$ into 2D using t-SNE with a perplexity of 30 to preserve geometric structure and avoid biasing cluster perception [S1].
    $$ \mathbf{p}_i = \text{t-SNE}(\{\mathbf{z}'_j\}, \text{perplexity}=30) $$
    where $\mathbf{p}_i \in \mathbb{R}^2$.

6.  **Structured Browsing (Grid)**
    *   The user brushes a $4 \times 4$ rectangular grid on the 2D projection [S1].
    *   For each grid cell $c$, identify the subset of projected points $\mathcal{P}_c = \{\mathbf{p}_i \mid \mathbf{p}_i \in c\}$ [S1].
    *   Compute the mean of the corresponding re-encoded latent samples for the cell:
        $$ \bar{\mathbf{z}}_c = \frac{1}{|\mathcal{P}_c|} \sum_{\mathbf{p}_i \in \mathcal{P}_c} \mathbf{z}'_i $$
    *   Synthesize the image for each cell using the mean latent vector $\bar{\mathbf{z}}_c$, alongside the view and color TF [S1].
    *   For efficiency, push the $4 \times 4 = 16$ inputs through the network in a single minibatch [S1].

7.  **Detailed Inspection (Interpolation)**
    *   The user hovers over or selects a point $\mathbf{p}_{sel}$ in the 2D projection [S1].
    *   Define a disk centered at $\mathbf{p}_{sel}$ with radius $R = 0.05 \times \text{diagonal}$ of the 2D bounding box [S1].
    *   Identify all points $\mathbf{p}_i$ within this disk: $\mathcal{D} = \{\mathbf{p}_i \mid \|\mathbf{p}_i - \mathbf{p}_{sel}\| \le R\}$ [S1].
    *   Perform scattered data interpolation of the latent opacity TFs using Shepard interpolation with a Gaussian kernel [S1].
    *   The bandwidth $\sigma$ of the Gaussian kernel is $\sigma = R/3$ [S1].
    *   The interpolated latent vector $\mathbf{z}_{interp}$ is computed as:
        $$ \mathbf{z}_{interp} = \frac{\sum_{\mathbf{p}_i \in \mathcal{D}} w_i \mathbf{z}'_i}{\sum_{\mathbf{p}_i \in \mathcal{D}} w_i}, \quad w_i = \exp\left(-\frac{\|\mathbf{p}_i - \mathbf{p}_{sel}\|^2}{2\sigma^2}\right) $$
    *   Decode $\mathbf{z}_{interp}$ to obtain the opacity TF and synthesize the image [S1].

### Pseudocode

```python
import numpy as np

def opacity_tf_exploration(latent_samples, decoder, generator_encoder_layers, volume_data, view_tf, color_tf, user_selection_point=None):
    """
    Performs opacity TF exploration via latent space projection.
    
    Args:
        latent_samples: List of N 8D latent vectors (initial random samples).
        decoder: Function mapping 8D latent vector to opacity TF.
        generator_encoder_layers: Function mapping opacity TF to 8D latent vector via 1D conv layers [S1].
        volume_data: The volume dataset.
        view_tf: View transfer function.
        color_tf: Color transfer function.
        user_selection_point: 2D numpy array for detailed inspection [G].
        
    Returns:
        projected_points: 2D array of shape (N, 2)
        grid_images: List of images for 4x4 grid cells
        interpolated_image: Image for detailed inspection
    """
    N = len(latent_samples)
    
    # Step 2: Push samples through decoder to obtain TFs
    tfs = [decoder(z) for z in latent_samples]
    
    # Step 3: Transform TFs back to latent space via 1D conv layers of generator
    valid_latent_samples = [generator_encoder_layers(tf) for tf in tfs]
    
    # Step 4: (Diagnostic) SVD to check falloff
    # matrix = np.array(valid_latent_samples)
    # U, S, Vt = np.linalg.svd(matrix, full_matrices=False)
    # print("Singular values:", S)
    
    # Step 5: Project to 2D using t-SNE
    # Standard t-SNE projection algorithm [G]
    # projected_points = tsne_projection(valid_latent_samples, perplexity=30)
    projected_points = np.random.rand(N, 2)  # Placeholder for actual t-SNE output [G]
    
    # Step 6: Structured Browsing (Grid)
    min_x, max_x = projected_points[:, 0].min(), projected_points[:, 0].max()
    min_y, max_y = projected_points[:, 1].min(), projected_points[:, 1].max()
    
    grid_step_x = (max_x - min_x) / 4
    grid_step_y = (max_y - min_y) / 4
    
    grid_images = []
    for row in range(4):
        for col in range(4):
            x_min = min_x + col * grid_step_x
            x_max = x_min + grid_step_x
            y_min = min_y + row * grid_step_y
            y_max = y_min + grid_step_y
            
            cell_mask = (
                (projected_points[:, 0] >= x_min) & 
                (projected_points[:, 0] < x_max) &
                (projected_points[:, 1] >= y_min) & 
                (projected_points[:, 1] < y_max)
            )
            cell_indices = np.where(cell_mask)[0]
            
            if len(cell_indices) > 0:
                cell_latents = np.array([valid_latent_samples[i] for i in cell_indices])
                mean_latent = np.mean(cell_latents, axis=0)
                mean_tf = decoder(mean_latent)
                # Standard volume rendering call [G]
                # image = render_volume(volume_data, mean_tf, view_tf, color_tf)
                image = np.zeros((100, 100, 3))  # Placeholder for rendered image [G]
                grid_images.append(image)
            else:
                grid_images.append(None)
                
    # Step 7: Detailed Inspection (Interpolation)
    if user_selection_point is None:
        user_selection_point = np.array([0.0, 0.0])  # Default if not provided [G]
        
    diag = np.sqrt((max_x - min_x)**2 + (max_y - min_y)**2)
    R = 0.05 * diag
    
    dists = np.linalg.norm(projected_points - user_selection_point, axis=1)
    disk_mask = dists <= R
    disk_indices = np.where(disk_mask)[0]
    
    if len(disk_indices) > 0:
        disk_latents = np.array([valid_latent_samples[i] for i in disk_indices])
        disk_points = projected_points[disk_indices]
        
        sigma = R / 3.0
        weights = np.exp(-dists[disk_indices]**2 / (2 * sigma**2))
        
        interpolated_latent = np.average(disk_latents, axis=0, weights=weights)
        interp_tf = decoder(interpolated_latent)
        # Standard volume rendering call [G]
        # interpolated_image = render_volume(volume_data, interp_tf, view_tf, color_tf)
        interpolated_image = np.zeros((100, 100, 3))  # Placeholder for rendered image [G]
    else:
        interpolated_image = None
        
    return projected_points, grid_images, interpolated_image
```

### Parameters and Typical Values
*   **Number of Samples ($N$):** $10^4$ [S1].
*   **t-SNE Perplexity:** 30 [S1].
*   **Grid Size:** $4 \times 4$ [S1].
*   **Interpolation Radius ($R$):** $5\%$ of the 2D bounding box diagonal [S1].
*   **Shepard Kernel Bandwidth ($\sigma$):** $1/3$ of $R$ [S1].

### Edge Cases and Pitfalls
*   **Invalid Latent Points:** The decoder is not injective for points in the latent space that do not correspond to valid TFs [S1]. Sampling must be restricted to the submanifold of valid TFs, which is achieved by re-encoding the decoded TFs [S1].
*   **Precision:** The method relies on the stability of the t-SNE projection and the interpolation [G]. Degenerate cases (e.g., no points in a grid cell or disk) must be handled gracefully by returning null or skipping rendering [G].

## Operating characteristics
*   **Time Complexity:** Not given in the sources [S1]. The method enables interactivity by pushing the 4x4 grid inputs through the network in a single minibatch [S1].
*   **Memory Complexity:** Not given in the sources [S1]. Storage of $N=10^4$ 8D vectors is negligible [S1].
*   **Strengths:** Allows users to understand feature relationships and select TF variations based on latent space similarity [S1]. Provides both overview (grid) and detailed inspection (interpolation) [S1].
*   **Limitations:** Requires a pre-trained generative model (autoencoder/GAN) for the opacity TF [S1]. The decoder is not injective for invalid latent points, requiring sampling on the valid submanifold [S1].

## Background
This method was introduced in the paper "A Generative Model for Volume Rendering" [S1]. It is part of a broader approach to volume rendering exploration using generative models [S1]. The technique leverages the latent space of an opacity TF autoencoder to provide a structured way for users to browse and select transfer functions [S1]. The use of t-SNE for 2D projection follows the general trend of dimensionality reduction for visualization [S1].
