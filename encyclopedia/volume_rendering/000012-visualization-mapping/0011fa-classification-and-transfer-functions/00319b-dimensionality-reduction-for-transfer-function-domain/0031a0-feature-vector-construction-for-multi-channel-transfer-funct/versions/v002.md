# Feature Vector Construction for Multi-Channel Transfer Functions

Also called: Multi-channel Feature Vector Construction, Voxel Signature Construction for TF

## Overview
Feature vector construction for multi-channel transfer functions generates a high-dimensional signature for each voxel to encode areas of interest in multi-channel volume data, enabling the application of dimensionality reduction algorithms to create a low-dimensional transfer function domain [S1]. This method addresses the limitation of single-channel intensity-based classification by capturing correlations between multiple channels, such as spectral labels in confocal microscopy [S1]. It differs from its siblings, [t-SNE for Transfer Function Design](7098-t-sne-for-transfer-function-design.md) and [LLE-based Transfer Function Design](8549-lle-based-transfer-function-design.md), by defining the explicit feature space (intensity, gradient, Laplacian, statistics) that serves as the input to those reduction algorithms, rather than defining the reduction algorithm itself [S1].

## How it works
**Inputs and Outputs**
*   **Input:** Multi-channel volume data $V$ with $C$ channels, typically $C=3$ for the canonical examples [S1].
*   **Output:** A feature vector $\mathbf{f}_v$ for each voxel $v$ [S1].

**Data Structures**
The feature vector is a fixed-size array whose size depends on the chosen feature set [S1].
*   **24D Vector:** Used for complex tissue edge data [S1]. Fields 1–3 contain channel intensities ($u_1, u_2, u_3$) [S1]. Fields 4–6 contain gradient magnitudes ($|\nabla u_1|, |\nabla u_2|, |\nabla u_3|$) [S1]. Fields 7–18 contain gradient components for three channels (3 components $\times$ 3 channels = 9 fields) [S1]. Fields 19–21 contain discrete Laplacian values for three channels [S1]. Fields 22–24 contain the mean and variance of channel intensity from a $3 \times 3 \times 3$ voxel neighborhood for each of the three channels (2 statistics $\times$ 3 channels = 6 fields) [S1].
*   **6D Vector:** Used for simpler blood vessel data [S1]. Fields 1–3 contain channel intensities ($u_1, u_2, u_3$) [S1]. Fields 4–6 contain gradient magnitudes ($|\nabla u_1|, |\nabla u_2|, |\nabla u_3|$) [S1].

**Steps**
1.  **Compute Intensity:** For each voxel $v$ and channel $i \in \{1, 2, 3\}$, retrieve the scalar intensity value $u_i(v)$ [S1].
2.  **Compute Gradient:** Calculate the gradient vector $\nabla u_i(v)$ for each channel using central differences [G]. The gradient components are $\frac{\partial u_i}{\partial x}, \frac{\partial u_i}{\partial y}, \frac{\partial u_i}{\partial z}$ [G]. The gradient magnitude is $|\nabla u_i| = \sqrt{(\frac{\partial u_i}{\partial x})^2 + (\frac{\partial u_i}{\partial y})^2 + (\frac{\partial u_i}{\partial z})^2}$ [G].
3.  **Compute Laplacian:** Calculate the discrete Laplacian for each channel $i$ to capture ridges and valleys [S1]. The formula is:
    $$ L_i(v) = \frac{1}{6} \left( \frac{\partial^2 u_i}{\partial x^2} + \frac{\partial^2 u_i}{\partial y^2} + \frac{\partial^2 u_i}{\partial z^2} \right) $$
    [S1]
4.  **Compute Local Statistics:** For each channel $i$, compute the mean $\mu_i$ and variance $\sigma_i^2$ of the intensity values within a $3 \times 3 \times 3$ voxel cube centered at $v$ [S1].
5.  **Assemble Vector:** Concatenate the computed values into the vector $\mathbf{f}_v$ according to the selected dimensionality (6D or 24D) [S1].

**Pseudocode**
```python
import math

def clamp(val, min_val, max_val):
    return max(min_val, min(val, max_val))

def compute_gradient(volume, channel_idx, x, y, z, dims):
    """Compute gradient components and magnitude using central differences."""
    x_p = clamp(x + 1, 0, dims[0] - 1)
    x_m = clamp(x - 1, 0, dims[0] - 1)
    y_p = clamp(y + 1, 0, dims[1] - 1)
    y_m = clamp(y - 1, 0, dims[1] - 1)
    z_p = clamp(z + 1, 0, dims[2] - 1)
    z_m = clamp(z - 1, 0, dims[2] - 1)
    
    gx = (volume[z, y, x_p, channel_idx] - volume[z, y, x_m, channel_idx]) / max(2, x_p - x_m)
    gy = (volume[z, y_p, x, channel_idx] - volume[z, y_m, x, channel_idx]) / max(2, y_p - y_m)
    gz = (volume[z_p, y, x, channel_idx] - volume[z_m, y, x, channel_idx]) / max(2, z_p - z_m)
    mag = math.sqrt(gx**2 + gy**2 + gz**2)
    return gx, gy, gz, mag

def compute_laplacian(volume, channel_idx, x, y, z, dims):
    """Compute discrete Laplacian scaled by 1/6."""
    x_p = clamp(x + 1, 0, dims[0] - 1)
    x_m = clamp(x - 1, 0, dims[0] - 1)
    y_p = clamp(y + 1, 0, dims[1] - 1)
    y_m = clamp(y - 1, 0, dims[1] - 1)
    z_p = clamp(z + 1, 0, dims[2] - 1)
    z_m = clamp(z - 1, 0, dims[2] - 1)
    
    center = volume[z, y, x, channel_idx]
    lap = (volume[z, y, x_p, channel_idx] + volume[z, y, x_m, channel_idx] +
           volume[z, y_p, x, channel_idx] + volume[z, y_m, x, channel_idx] +
           volume[z_p, y, x, channel_idx] + volume[z_m, y, x, channel_idx] -
           6 * center) / 6.0
    return lap

def compute_local_stats(volume, channel_idx, x, y, z, dims, radius=1):
    """Compute mean and variance of intensity in 3x3x3 cube."""
    values = []
    for dz in range(-radius, radius + 1):
        for dy in range(-radius, radius + 1):
            for dx in range(-radius, radius + 1):
                cx = clamp(x + dx, 0, dims[0] - 1)
                cy = clamp(y + dy, 0, dims[1] - 1)
                cz = clamp(z + dz, 0, dims[2] - 1)
                values.append(volume[cz, cy, cx, channel_idx])
    
    mean_val = sum(values) / len(values)
    variance_val = sum((v - mean_val) ** 2 for v in values) / len(values)
    return mean_val, variance_val

def construct_feature_vector(volume, x, y, z, dims, mode='24d'):
    """Construct feature vector for a voxel."""
    num_channels = 3
    features = []
    
    # 1. Intensities (3 fields)
    for i in range(num_channels):
        features.append(volume[z, y, x, i])
        
    # 2. Gradient Magnitudes (3 fields)
    for i in range(num_channels):
        _, _, _, mag = compute_gradient(volume, i, x, y, z, dims)
        features.append(mag)
        
    # 3. Gradient Components (9 fields)
    for i in range(num_channels):
        gx, gy, gz, _ = compute_gradient(volume, i, x, y, z, dims)
        features.append(gx)
        features.append(gy)
        features.append(gz)
        
    # 4. Discrete Laplacian (3 fields)
    for i in range(num_channels):
        lap = compute_laplacian(volume, i, x, y, z, dims)
        features.append(lap)
        
    # 5. Local Statistics (6 fields for 24D: mean/var per channel)
    if mode == '24d':
        for i in range(num_channels):
            mean_val, variance_val = compute_local_stats(volume, i, x, y, z, dims)
            features.append(mean_val)
            features.append(variance_val)
            
    return features
```

**Parameters**
*   **Neighborhood Size:** $3 \times 3 \times 3$ voxel cube for statistics calculation [S1].
*   **Dimensionality:** 24 for Tissue Edge Data; 6 for Blood Vessel Data [S1].

**Edge Cases and Pitfalls**
*   **Redundancy:** Redundant information in feature vectors is handled by dimensionality reduction algorithms, which filter out redundancies and eliminate features with small variance [S1].
*   **Boundary Conditions:** Gradient and Laplacian calculations require handling volume boundaries, which is not specified in the sources [G].
*   **Feature Selection:** Adding or removing features is flexible, and ineffective features are removed by the dimensionality reduction step without significant overhead [S1].

## Subtopics

### Feature-based TF Design via CNN Features
A method for transfer function design using high-dimensional deep features from a CNN trained on user-labeled voxel examples, grouping features via spectral reordering and vector quantization [S2, unofficial]. It differs from the hand-crafted feature vectors above by using learned semantic features rather than explicit physical derivatives [S2, unofficial]. It is chosen when intensity and gradient features fail to separate semantically distinct regions that share similar value ranges [S2, unofficial]. On FIB-SEM bacteria volumes ($1,150 \times 450 \times 400$), the fitted-transform postprocessing improved VOC segmentation scores across all four classes [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of voxels $N$ for feature construction ($O(N)$), assuming constant neighborhood size [G]. The subsequent dimensionality reduction step adds complexity depending on the algorithm (e.g., $O(N^2)$ for t-SNE) [G].
*   **Memory Complexity:** $O(N \cdot D)$, where $D$ is the feature dimension (6 or 24) [G].
*   **Strengths:** Captures correlations between multiple channels; flexible feature definition; dimensionality reduction handles redundancy [S1].
*   **Limitations:** Requires manual feature engineering for the hand-crafted approach; CNN approach requires per-volume user labeling and does not transfer learned features across datasets [S2, unofficial].
*   **When to Use:** When multi-channel data (e.g., confocal microscopy) requires classification based on spectral correlations and boundary information [S1].

## Background
The method originates from research on dimensionality reduction for multi-dimensional transfer functions in information visualization [S1]. It was developed to address the limitations of single-channel intensity-based transfer functions in capturing multi-channel correlations [S1]. The approach was demonstrated on confocal volume image data of brain tissue edges (24D) and blood vessel data in the hippocampus (6D) [S1].
