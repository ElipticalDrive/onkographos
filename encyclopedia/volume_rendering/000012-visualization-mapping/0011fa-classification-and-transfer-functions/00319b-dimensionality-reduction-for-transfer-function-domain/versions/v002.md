# Dimensionality Reduction for Transfer Function Domain

Also called: Isomap, LLE for Transfer Function Design, Local Linear Embedding (LLE), Local Linear Embedding (LLE) for Dimension Reduction, Locally Linear Embedding (LLE), Locally Linear Embedding (LLE) for Transfer Function Design

## Overview
Dimensionality reduction for transfer function domain applies nonlinear manifold learning algorithms, primarily Isomap and Local Linear Embedding (LLE), to map high-dimensional voxel feature vectors into a low-dimensional space (typically 2D or 3D) [S1, S2]. This process solves the problem of visualizing and interacting with multivariate volume data by clustering similar voxels together in the reduced space, enabling users to define transfer functions (color and opacity assignments) based on geometric clusters rather than individual feature values [S1, S2]. Unlike linear methods such as PCA, these techniques preserve the global nonlinear structure of the data manifold, which is critical because voxel feature distributions in volume rendering are often nonlinear [S1, S2]. Isomap is distinguished by preserving geodesic distances across the manifold, while LLE is distinguished by preserving local linear structures via reconstruction weights [S2].

## How it works
The method operates in two phases: **Embedding** (computing the low-dimensional coordinates for a reference dataset) and **Mapping** (projecting new or remaining voxels into that space).

### Inputs and Outputs
*   **Input:** A set of $N$ high-dimensional feature vectors $\mathbf{X} = \{\mathbf{X}_1, \dots, \mathbf{X}_N\}$, where each $\mathbf{X}_i \in \mathbb{R}^D$. The features typically include intensity, gradient magnitude, gradient components, Laplacian, and statistical moments (mean, variance) [S1, S2].
*   **Output:** A set of low-dimensional embedding vectors $\mathbf{Y} = \{\mathbf{Y}_1, \dots, \mathbf{Y}_N\}$, where $\mathbf{Y}_i \in \mathbb{R}^d$ (typically $d=2$ or $3$) [S1, S2].

### Data Structures
*   **Feature Matrix:** $N \times D$ matrix of input vectors.
*   **Weight Matrix ($W$):** $N \times N$ sparse matrix where $W_{ij}$ represents the reconstruction weight of neighbor $j$ for point $i$. For LLE, this matrix is sparse; for Isomap, the intermediate distance matrix is dense [S2].
*   **Embedding Matrix:** $N \times d$ matrix of output coordinates.

### Algorithm: Local Linear Embedding (LLE)
LLE preserves locally linear structures by assuming each point lies on a linear patch of its neighbors [S2].

1.  **Neighbor Selection:** For each point $\mathbf{X}_i$, identify its $K$ nearest neighbors $\mathcal{N}_i$ in the high-dimensional space using Euclidean distance [S1, S2].
2.  **Weight Computation:** Compute reconstruction weights $W_{ij}$ for each neighbor $j \in \mathcal{N}_i$ by minimizing the local reconstruction error:
    $$ \epsilon(W) = \sum_{i=1}^N \left\| \mathbf{X}_i - \sum_{j \in \mathcal{N}_i} W_{ij} \mathbf{X}_j \right\|^2 $$
    Subject to constraints:
    *   $W_{ij} = 0$ if $\mathbf{X}_j \notin \mathcal{N}_i$ [S1, S2].
    *   $\sum_{j \in \mathcal{N}_i} W_{ij} = 1$ for all $i$ [S1, S2].
    This is solved as a constrained least-squares problem for each $i$ [S2].
3.  **Embedding Optimization:** Find the low-dimensional coordinates $\mathbf{Y}_i$ that preserve these weights by minimizing:
    $$ \phi(Y) = \sum_{i=1}^N \left\| \mathbf{Y}_i - \sum_{j \in \mathcal{N}_i} W_{ij} \mathbf{Y}_j \right\|^2 $$
    This is equivalent to finding the eigenvectors of the matrix $(I - W)^T (I - W)$ corresponding to the $d$ smallest non-zero eigenvalues [S1, S2].
4.  **Classification:** Apply k-means clustering in the 2D/3D embedding space to group voxels. Assign color and opacity to each cluster [S1].

### Algorithm: Isomap
Isomap preserves global geodesic distances by approximating the manifold geometry [S2].

1.  **Neighborhood Graph Construction:** Compute pairwise Euclidean distances between all points. For each $\mathbf{X}_i$, select $K$ nearest neighbors. Construct a graph where edges exist only between neighbors, weighted by the Euclidean distance [S2].
2.  **Geodesic Distance Estimation:** Compute the shortest path between all pairs of nodes in the graph using Dijkstra's algorithm. These shortest paths approximate the geodesic distances on the manifold [S2].
3.  **MDS Embedding:** Apply Classical Multidimensional Scaling (MDS) to the matrix of geodesic distances to find a low-dimensional representation $\mathbf{Y}$ where the Euclidean distances in $\mathbf{Y}$ best match the geodesic distances [S2].

### Mapping New Voxels (Extension)
To apply the transfer function to the entire volume when only a subset was embedded:
1.  Compute the feature vector $\mathbf{X}$ for a new voxel.
2.  Find its $K$ nearest neighbors $\{\mathbf{X}_{(1)}, \dots, \mathbf{X}_{(K)}\}$ from the reference embedded data [S2].
3.  Solve for weights $w_i$ by minimizing $\|\mathbf{X} - \sum_{i=1}^K w_i \mathbf{X}_{(i)}\|^2$ subject to $\sum w_i = 1$ [S2].
4.  Estimate the low-dimensional coordinate $\mathbf{Y}$ by linear interpolation: $\mathbf{Y} = \sum_{i=1}^K w_i \mathbf{Y}_{(i)}$ [S2].

### Parameters
*   **$K$ (Number of Neighbors):** Controls neighborhood size. No specific typical value given, but it determines graph sparsity [S2].
*   **$d$ (Embedding Dimension):** Default is 2D [S1]. Target dimensionality can be 3D [S2].
*   **Subsample Size:** For large volumes, a small cube is used for embedding (e.g., $128 \times 128 \times 24$ for 24D data, $50 \times 50 \times 24$ for 6D data) [S2].

### Pseudocode
```python
def lle_embed(X, K, d):
    """
    X: numpy array of shape (N, D)
    K: number of neighbors
    d: target dimensionality
    Returns: Y, numpy array of shape (N, d)
    """
    N, D = X.shape
    
    # Step 1: Find K-nearest neighbors
    # Compute pairwise distances
    dists = pairwise_euclidean_distances(X)
    # Get indices of K nearest neighbors for each point
    neighbors = get_k_nearest_neighbors(dists, K)
    
    # Step 2: Compute reconstruction weights W
    W = np.zeros((N, N))
    for i in range(N):
        neighbor_indices = neighbors[i]
        # Extract neighbor vectors
        X_neighbors = X[neighbor_indices]
        # Center the neighbors relative to X[i]
        X_centered = X_neighbors - X[i]
        
        # Solve for weights w such that sum(w) = 1 and error is minimized
        # This is a constrained least squares problem:
        # Minimize || X_centered @ w ||^2 subject to sum(w) = 1
        # Using Lagrange multipliers or standard solver
        # Let G = X_centered.T @ X_centered (Gram matrix)
        G = X_centered.T @ X_centered
        # Add constraint matrix
        # [ G  1 ] [ w ]   [ 0 ]
        # [ 1^T 0 ] [ lambda] = [ 1 ]
        # Construct augmented matrix
        ones = np.ones((K, 1))
        A_aug = np.block([[G, ones], [ones.T, np.zeros((1, 1))]])
        b_aug = np.array([0] * K + [1])
        
        # Solve linear system
        w_aug = np.linalg.solve(A_aug, b_aug)
        w = w_aug[:K]
        
        # Assign weights
        for j_idx, neighbor_idx in enumerate(neighbor_indices):
            W[i, neighbor_idx] = w[j_idx]
            
    # Step 3: Compute Embedding Y
    # Minimize || Y - W @ Y ||^2
    # Equivalent to finding eigenvectors of (I - W)^T (I - W)
    I = np.eye(N)
    M = (I - W).T @ (I - W)
    
    # Find d smallest non-zero eigenvalues and corresponding eigenvectors
    # Note: The smallest eigenvalue is 0 (constant vector), so we take the next d
    eigenvalues, eigenvectors = np.linalg.eigh(M)
    
    # Sort eigenvalues (eigh returns sorted)
    # Take eigenvectors corresponding to indices 1 to d (skipping the 0 eigenvalue at index 0)
    Y = eigenvectors[:, 1:d+1]
    
    return Y

def map_new_point(X_new, X_ref, Y_ref, K):
    """
    Map a new high-dimensional point to the pre-computed embedding space.
    X_new: shape (D,)
    X_ref: shape (N_ref, D)
    Y_ref: shape (N_ref, d)
    Returns: Y_new, shape (d,)
    """
    # Find K nearest neighbors in reference data
    dists = pairwise_euclidean_distances(X_ref, X_new)
    neighbor_indices = get_k_nearest_neighbors_indices(dists, K)
    
    X_neighbors = X_ref[neighbor_indices]
    X_centered = X_neighbors - X_new
    
    # Solve for weights
    G = X_centered.T @ X_centered
    ones = np.ones((K, 1))
    A_aug = np.block([[G, ones], [ones.T, np.zeros((1, 1))]])
    b_aug = np.array([0] * K + [1])
    w_aug = np.linalg.solve(A_aug, b_aug)
    w = w_aug[:K]
    
    # Interpolate embedding
    Y_neighbors = Y_ref[neighbor_indices]
    Y_new = Y_neighbors.T @ w
    
    return Y_new
```

### Edge Cases and Pitfalls
*   **Matrix Size:** LLE requires computing eigenvectors of an $N \times N$ matrix. For $N=400,000$, this is prohibitively expensive; feasible for $N=60,000$ [S2].
*   **Eigenvalue Cost:** Finding eigenvectors for the *smallest* eigenvalues (required by LLE) is computationally more expensive than finding the largest (required by PCA/Isomap) [S2].
*   **Information Loss:** Dimensionality reduction causes loss and distortion of information; LLE is suitable for qualitative aspects (shape, dissimilarity) but not for quantitative accuracy [S1].
*   **Non-linear Data:** Linear methods like PCA may fail if the data manifold is nonlinear; Isomap and LLE are preferred in such cases [S2].

## Subtopics

### [Feature Vector Construction for Multi-Channel Transfer Functions](6563-feature-vector-construction-for-multi-channel-transfer-funct.md)
Generates high-dimensional signatures for each voxel to encode areas of interest in multi-channel volume data, enabling the application of dimensionality reduction algorithms. It addresses the limitation of single-channel intensity-based classification by capturing correlations between multiple channels (e.g., spectral labels in confocal microscopy). It differs from [t-SNE for Transfer Function Design](7098-t-sne-for-transfer-function-design.md) and [LLE-based Transfer Function Design](8549-lle-based-transfer-function-design.md) by defining the explicit feature space (intensity, gradient, Laplacian, statistics) that serves as the input to those reduction algorithms, rather than defining the reduction algorithm itself.

### [t-SNE for Transfer Function Design](7098-t-sne-for-transfer-function-design.md)
A dimensionality reduction technique applied to multivariate voxel data to create a 2D similarity plot, enabling the separation and segmentation of different phases (e.g., noise, bone, sarcoma) based on voxel similarity. It solves the problem of visualizing high-dimensional multivariate voxel distributions by mapping them to a low-dimensional space where similar voxels are clustered together. Unlike its siblings, it uses non-linear manifold learning to preserve local neighborhood structures, making it particularly effective at separating complex, non-linearly separable phases such as noise (miasma) from signal.

### [LLE-based Transfer Function Design](8549-lle-based-transfer-function-design.md)
Constructs high-dimensional transfer functions by projecting multi-dimensional volume parameters into a low-dimensional (typically 2D) space using Local Linear Embedding (LLE), followed by k-means classification to assign colors. It solves the problem of interactive design complexity in high-dimensional feature spaces by reducing the dimensionality of the classification domain. Unlike its sibling [t-SNE for Transfer Function Design](7098-t-sne-for-transfer-function-design.md), which optimizes for local neighborhood preservation via stochastic gradient descent, LLE preserves local linear structures via deterministic least-squares optimization. Compared to [PCA-based Transfer Function Design](6556-dimensionality-reduction-for-transfer-function-domain.md), LLE handles non-linear relationships between features, offering easier operation and classification in 2D, though it requires extra mapping time.

### Scalability via Subsampling for Dimensionality Reduction
To handle large volumes, a small cube containing interesting parts is cut out from the entire data volume (e.g., $128 \times 128 \times 24$ voxels for 24D data, $50 \times 50 \times 24$ voxels for 6D data) [S2]. The transfer function is calculated on this small subset. The result is extended to the rest of the volume using LLE interpolation: for each remaining voxel, its $K$ nearest neighbors in the reference data are found, and its low-dimensional embedding is estimated by linearly interpolating the neighbors' embeddings using the computed weights [S2].

### Pivot MDS
A technique that applies classical dimensional reduction and projection methods to only a small subset of representative samples (landmarks) and projects the remaining samples via interpolation to reduce computation complexity [S3, unofficial]. This approach dramatically reduces computational cost while producing almost the same quality of the resulting low-dimensional representation [S2].

## Operating characteristics
*   **Time Complexity:**
    *   **Isomap:** Step 1 (K-NN) is $O(N^2 D)$ naively, optimizable [S2]. Step 2 (Dijkstra) is $O(N^2)$ naively, or $O(N \log N + E)$ with a Fibonacci heap [S2]. Step 3 (MDS) involves eigenvalue decomposition of an $N \times N$ matrix [S2].
    *   **LLE:** Step 1 (K-NN) is $O(N^2 D)$ naively [S2]. Step 2 (Weight computation) is $O(N \cdot K^3)$ or similar depending on solver [S2]. Step 3 (Eigenvalue decomposition) of an $N \times N$ sparse matrix is expensive, particularly for smallest eigenvalues [S2].
*   **Memory Complexity:**
    *   **Isomap:** Produces a dense distance matrix, consuming more memory [S2].
    *   **LLE:** The weight matrix $W$ is usually very sparse, consuming less memory than Isomap's dense matrix [S2].
*   **Performance:** LLE is preferred over PCA and metric MDS because it eliminates the need to estimate pairwise distances between widely separated points and maintains global nonlinear structure from locally linear fits [S1]. Nonlinear algorithms (Isomap, LLE) are preferred over linear ones (PCA) because points in the transfer function domain are often distributed nonlinearly [S2].
*   **Scalability:** LLE fails for very large $N$ (e.g., 400,000 points) due to eigenvector computation cost; feasible for 60,000 points [S2]. Subsampling or Pivot MDS is required for larger datasets [S2][S3, unofficial].
*   **Strengths:** Preserves global nonlinear structure; avoids local minima in optimization (unlike some manifold learning methods); easy to interpret in 2D for classification [S1, S2].
*   **Limitations:** Loss of quantitative accuracy; high computational cost for eigenvector decomposition; sensitive to parameter $K$ [S1, S2].

## Background
Originated from the application of manifold learning algorithms to volume rendering transfer function design. Local Linear Embedding (LLE) was introduced by Roweis and Saul [RS00] as an unsupervised learning algorithm for dimension reduction [S1]. Isomap was introduced by Tenenbaum, de Silva, and Langford [S2, S19, S20]. The application to transfer functions was pioneered in methods such as Parallel Coordinates based Transfer Function (PCbTF) design, which used LLE to project high-dimensional attribute parameters to 2D space for k-means clustering [S1]. Subsequent work expanded this to multi-channel data using Isomap and LLE to preserve relative distances in nonlinear feature spaces [S2].
