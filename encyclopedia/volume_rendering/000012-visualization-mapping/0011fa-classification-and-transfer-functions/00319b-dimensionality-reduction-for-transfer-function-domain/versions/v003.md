# Dimensionality Reduction for Transfer Function Domain

Also called: Isomap, LLE for Transfer Function Design, Local Linear Embedding (LLE), Local Linear Embedding (LLE) for Dimension Reduction, Locally Linear Embedding (LLE), Locally Linear Embedding (LLE) for Transfer Function Design

## Overview
Dimensionality reduction for transfer function domain maps high-dimensional voxel feature vectors into a low-dimensional (typically 2D or 3D) coordinate system to simplify the design of multi-dimensional transfer functions [S1, S2]. It solves the problem of visualizing and classifying complex, high-dimensional data distributions by preserving the relative distances or local structures of voxels, allowing users to assign colors and opacities in a manageable low-dimensional space [S1, S2]. Unlike linear methods such as [PCA-based Transfer Function Design](6556-dimensionality-reduction-for-transfer-function-domain.md), these nonlinear techniques (specifically Isomap and LLE) are preferred because the points in the transfer function domain are often distributed in a nonlinear way, and they avoid the need to estimate pairwise distances between widely separated points [S1, S2].

## How it works
The method encompasses two primary algorithms: Isomap and Locally Linear Embedding (LLE). Both take a set of high-dimensional feature vectors as input and produce a low-dimensional embedding.

**Inputs:**
*   A dataset of $N$ voxels, where each voxel $X_i$ is represented by a feature vector in $\mathbb{R}^D$. The feature vector typically includes intensity, gradient magnitude, gradient components, Laplacian values, and first-order statistics (mean, variance) [S2].
*   Parameters:
    *   $K$: The number of nearest neighbors used to construct the neighborhood graph [S2].
    *   $d$: The target dimensionality of the embedding space (default 2D, sometimes 3D) [S1, S2].

**Outputs:**
*   A set of low-dimensional coordinates $Y_i \in \mathbb{R}^d$ for each voxel $X_i$.
*   Classification labels for each $Y_i$ (typically via k-means clustering in the low-dimensional space) [S1].
*   Assigned color and opacity for each class [S1].

**Data Structures:**
*   **Feature Matrix:** $X \in \mathbb{R}^{N \times D}$, where rows are voxels.
*   **Adjacency/Weight Matrix:** $W \in \mathbb{R}^{N \times N}$, storing reconstruction weights or graph edges.
*   **Embedding Matrix:** $Y \in \mathbb{R}^{N \times d}$, storing the final coordinates.

### Isomap Algorithm
Isomap extends Multi-Dimensional Scaling (MDS) to preserve geodesic distances on a nonlinear manifold [S2].

1.  **Construct Neighborhood Graph:**
    *   For each point $X_i$, compute Euclidean distances to all other points $X_j$.
    *   Select the $K$ nearest neighbors.
    *   Set edge weights to the Euclidean distances $||X_i - X_j||^2$. No edge exists if points are not $K$-nearest neighbors [S2].
2.  **Compute Geodesic Distances:**
    *   Compute the shortest path between any two nodes in the graph using Dijkstra's algorithm. This encodes the geodesic distance, approximating the distance on the manifold [S2].
3.  **Apply MDS:**
    *   Run classical MDS on the matrix of geodesic distances to find a low-dimensional representation $\{Y_i\}$ where the Euclidean distance between points in $Y$ is closest to the computed geodesic distances [S2].

### Locally Linear Embedding (LLE) Algorithm
LLE preserves locally linear structures by exploiting the relationship between a point and its neighborhood [S2].

1.  **Find Neighbors:**
    *   For each data point $X_i$, compute its $K$ nearest neighbors in the high-dimensional feature space [S1, S2].
2.  **Compute Reconstruction Weights:**
    *   Compute weights $W_{ij}$ that reconstruct $X_i$ from its neighbors by minimizing the cost function:
        $$ \epsilon(W) = \sum_i \left\| X_i - \sum_j W_{ij} X_j \right\|^2 $$
    *   Subject to constraints:
        *   $W_{ij} = 0$ if $X_j$ is not a $K$-nearest neighbor of $X_i$.
        *   $\sum_j W_{ij} = 1$ [S1, S2].
3.  **Compute Low-Dimensional Embedding:**
    *   Find the best low-dimensional embedding $Y_i$ by minimizing the cost function:
        $$ \phi(Y) = \sum_i \left\| Y_i - \sum_j W_{ij} Y_j \right\|^2 $$
    *   This is solved by finding the $d+1$ eigenvectors of the matrix $(I - W)^T (I - W)$ with the smallest positive eigenvalues (excluding the trivial zero eigenvector) [S1, S2].
4.  **Classification:**
    *   Classify the data in the low-dimensional space (e.g., 2D) using the k-means algorithm [S1].
    *   Assign color and opacity for each class to obtain the final rendering result [S1].

### Interpolation for New Data (Scalability Variant)
To apply the transfer function to a large volume without re-running LLE on all data:
1.  Compute the feature vector for a new point $X$ in the large volume.
2.  Find its $k$ nearest neighbors $\{X_{(1)}, \dots, X_{(k)}\}$ from the reference data used for transfer function design, based on Euclidean distance in feature vector space [S2].
3.  Solve for weights $w_i$ by minimizing:
    $$ \left\| X - \sum_{i=1}^k w_i X_{(i)} \right\|^2 $$
    subject to $\sum_{i=1}^k w_i = 1$ [S2].
4.  Estimate the low-dimensional embedding $Y$ of $X$ by linearly interpolating the low-dimensional coordinates of the neighbors:
    $$ Y = \sum_{i=1}^k w_i Y_{(i)} $$
    where $Y_{(i)}$ are the pre-computed embeddings of the neighbors [S2].

**Pseudocode for LLE Embedding:**

```python
import numpy as np
from scipy.sparse import csr_matrix
from scipy.sparse.linalg import eigsh

def lle(X, k_neighbors, d):
    """
    X: numpy array of shape (N, D)
    k_neighbors: int, number of neighbors K
    d: int, target dimensionality
    Returns: Y, numpy array of shape (N, d)
    """
    N, D = X.shape
    
    # Step 1: Find K-nearest neighbors
    # Compute pairwise distances
    # Note: In practice, use efficient KD-tree or ball tree for large N
    dists = np.linalg.norm(X[:, np.newaxis, :] - X[np.newaxis, :, :], axis=2)
    
    # Get indices of K nearest neighbors (excluding self)
    # Sort distances and pick top K+1 (including self at index 0)
    neighbor_indices = np.argsort(dists, axis=1)[:, 1:k_neighbors+1]
    
    # Step 2: Compute reconstruction weights W
    # For each point i, solve for weights w_i such that X_i = sum(w_j * X_j)
    # Constraint: sum(w_j) = 1
    
    W = np.zeros((N, N))
    
    for i in range(N):
        neighbors = neighbor_indices[i]
        # Get neighbor coordinates
        X_neighbors = X[neighbors] # Shape (K, D)
        
        # Center the neighbors around the mean to handle the sum-to-1 constraint
        # Let C = X_neighbors - mean(X_neighbors, axis=0)
        C = X_neighbors - np.mean(X_neighbors, axis=0)
        
        # Compute Gram matrix G = C * C^T
        G = np.dot(C, C.T)
        
        # Add small regularization to G to ensure invertibility
        G += 1e-6 * np.eye(k_neighbors)
        
        # Solve G * w = 1 (vector of ones)
        ones = np.ones(k_neighbors)
        w = np.linalg.solve(G, ones)
        
        # Normalize weights to sum to 1 (numerical stability)
        w = w / np.sum(w)
        
        # Assign weights to the global W matrix
        for j_idx, neighbor_idx in enumerate(neighbors):
            W[i, neighbor_idx] = w[j_idx]
            
    # Step 3: Compute Embedding Y
    # Minimize ||Y - WY||^2 subject to Y^T Y = I and Y^T 1 = 0
    # This is equivalent to finding eigenvectors of (I - W)^T (I - W)
    
    I_N = np.eye(N)
    M = (I_N - W).T.dot(I_N - W)
    
    # Find the d+1 smallest eigenvalues/vectors
    # We need d+1 because the smallest eigenvalue is 0 (trivial solution)
    # We take the next d smallest
    eigenvalues, eigenvectors = eigsh(M, k=d+1, which='SM')
    
    # Sort by eigenvalue (should already be sorted by eigsh 'SM', but ensure)
    idx = np.argsort(eigenvalues)
    eigenvalues = eigenvalues[idx]
    eigenvectors = eigenvectors[:, idx]
    
    # Discard the first eigenvector (trivial zero eigenvalue)
    Y = eigenvectors[:, 1:]
    
    return Y
```

## Subtopics

### [Feature Vector Construction for Multi-Channel Transfer Functions](6563-feature-vector-construction-for-multi-channel-transfer-funct.md)
Feature vector construction for multi-channel transfer functions generates a high-dimensional signature for each voxel to encode areas of interest in multi-channel volume data, enabling the application of dimensionality reduction algorithms to create a low-dimensional transfer function domain. This method addresses the limitation of single-channel intensity-based classification by capturing correlations between multiple channels, such as spectral labels in confocal microscopy. It differs from its siblings, [t-SNE for Transfer Function Design](7098-t-sne-for-transfer-function-design.md) and [LLE-based Transfer Function Design](8549-lle-based-transfer-function-design.md), by defining the explicit feature space (intensity, gradient, Laplacian, statistics) that serves as the input to those reduction algorithms, rather than defining the reduction algorithm itself.

### [t-SNE for Transfer Function Design](7098-t-sne-for-transfer-function-design.md)
t-SNE for Transfer Function Design is a dimensionality reduction technique applied to multivariate voxel data to create a 2D similarity plot, enabling the separation and segmentation of different phases or features (e.g., noise, bone, sarcoma) based on voxel similarity. It solves the problem of visualizing high-dimensional multivariate voxel distributions by mapping them to a low-dimensional space where similar voxels are clustered together. Unlike its siblings, it uses non-linear manifold learning to preserve local neighborhood structures, making it particularly effective at separating complex, non-linearly separable phases such as noise (miasma) from signal.

### [LLE-based Transfer Function Design](8549-lle-based-transfer-function-design.md)
LLE-based Transfer Function Design is a method for constructing high-dimensional transfer functions by projecting multi-dimensional volume parameters into a low-dimensional (typically 2D) space using Local Linear Embedding (LLE), followed by k-means classification to assign colors. It solves the problem of interactive design complexity in high-dimensional feature spaces by reducing the dimensionality of the classification domain. Unlike its sibling [t-SNE for Transfer Function Design](7098-t-sne-for-transfer-function-design.md), which optimizes for local neighborhood preservation via stochastic gradient descent, LLE preserves local linear structures via deterministic least-squares optimization. Compared to [PCA-based Transfer Function Design](6556-dimensionality-reduction-for-transfer-function-domain.md), LLE handles non-linear relationships between features, offering easier operation and classification in 2D, though it requires extra mapping time.

### [Pivot MDS](9500-pivot-mds.md)
Pivot MDS (also known as FastMap) is a linear-time variant of Multidimensional Scaling (MDS) used to project high-dimensional voxel data into a low-dimensional space (typically 2D or 3D) while preserving relative distances between points. It solves the computational bottleneck of classical MDS, which has $O(n^3)$ time complexity, by using a heuristic to select only two pivot points per dimension and projecting all other points via interpolation. Unlike its siblings such as t-SNE or LLE, which focus on local neighborhood preservation or manifold learning, Pivot MDS focuses on global distance preservation with linear complexity, making it suitable for large datasets where computational resources are constrained.

### Scalability via Subsampling for Dimensionality Reduction
To handle large volumes, a small cube containing interesting parts is cut out from the entire data volume (e.g., $128 \times 128 \times 24$ voxels for 24D data, or $50 \times 50 \times 24$ voxels for 6D data) [S2]. The transfer function is calculated on this small subset of data using LLE. The result is extended to the rest of the volume using the LLE interpolation method: for each point $X$ in the large volume, its three nearest neighbors are found in the reference data, and its low-dimensional embedding is estimated by linearly interpolating the embeddings of these neighbors using the computed weights [S2].

## Operating characteristics
*   **Time Complexity:**
    *   **Isomap:** Step 1 (K-nearest neighborhood) is $O(N^2 D)$ naively, but can be optimized. Step 2 (Dijkstra) is $O(N^2)$ naively, or $O(N \log N + E)$ with a Fibonacci heap, where $E$ is the number of edges [S2]. Step 3 (MDS) involves eigenvalue decomposition of an $N \times N$ dense matrix, which is $O(N^3)$ [S2].
    *   **LLE:** Step 1 (K-nearest neighborhood) is $O(N^2 D)$ naively. Step 2 (Weight computation) is $O(N K^3)$ or $O(N K^2)$ depending on implementation. Step 3 (Eigenvalue decomposition) involves finding the smallest eigenvalues of an $N \times N$ sparse matrix, which is computationally expensive, often more so than finding the largest eigenvalues [S2].
*   **Memory Complexity:**
    *   **Isomap:** The matrix produced by Isomap is dense, consuming more memory than LLE [S2].
    *   **LLE:** The matrix constructed by LLE (the weight matrix $W$) is usually very sparse, consuming less memory than Isomap's dense matrix [S2]. However, for 400,000 points, computing eigenvectors of a $400,000 \times 400,000$ matrix was prohibitively expensive, though feasible for 60,000 points [S2].
*   **Strengths:**
    *   Nonlinear algorithms (Isomap, LLE) are preferred over linear ones (PCA) because the points in the transfer function domain are often distributed in a nonlinear way [S2].
    *   LLE eliminates the need to estimate pairwise distances between widely separated points and maintains global nonlinear structure from locally linear fits [S1].
    *   LLE does not require expensive shortest path processing (like Isomap) [S2].
    *   The algorithm is straightforward and easy to understand [S2].
*   **Limitations:**
    *   LLE causes loss and distortion of information, so it cannot provide quantitative information as accurate as PCbTF, but is suitable for revealing qualitative aspects like shape and dissimilarity [S1].
    *   Computational cost is higher than PCA due to the first two steps [S2].
    *   Finding eigenvectors of the smallest eigenvalues is usually much higher than that of the largest eigenvalues [S2].
*   **When to Use:**
    *   Use when the data distribution in the feature space is nonlinear and local structures are important [S2].
    *   Use LLE when memory is constrained (sparse matrix) and shortest path computation is too expensive [S2].
    *   Use Isomap when global geodesic distances are more critical than local linear patches [S2].
*   **When Not to Use:**
    *   Do not use for very large datasets (e.g., >400,000 points) without subsampling, due to the prohibitive cost of eigenvector computation [S2].
    *   Do not use when quantitative accuracy of distances is required, as dimension reduction causes distortion [S1].

## Background
The method originates from the application of nonlinear dimensionality reduction techniques to volume rendering transfer function design. Local Linear Embedding (LLE) was introduced by Roweis and Saul [RS00] as an unsupervised learning algorithm for dimension reduction. In the context of volume rendering, it was adapted by researchers to simplify the design of multi-dimensional transfer functions, specifically within the Parallel Coordinates based Transfer Function (PCbTF) framework [S1]. Isomap was introduced by Tenenbaum, de Silva, and Langford [S2] as an extension of MDS for nonlinear manifolds. These methods were adopted in visualization to handle the complexity of multi-channel data (e.g., confocal microscopy) where linear methods like PCA failed to capture the nonlinear relationships between features [S2]. The approach allows users to interactively design transfer functions in a 2D or 3D space that preserves the high-dimensional structure of the data [S1].
