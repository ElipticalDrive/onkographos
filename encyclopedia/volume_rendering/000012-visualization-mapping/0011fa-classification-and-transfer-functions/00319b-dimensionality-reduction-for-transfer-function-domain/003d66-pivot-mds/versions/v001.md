# Pivot MDS
Also called: FastMap, FastMap Dimensionality Reduction, Landmarks MDS, Pivot Multidimensional Scaling

## Overview
Pivot MDS (also known as FastMap) is a linear-time variant of Multidimensional Scaling (MDS) used to project high-dimensional voxel data into a low-dimensional space (typically 2D or 3D) while preserving relative distances between points [S1, unofficial]. It solves the computational bottleneck of classical MDS, which has $O(n^3)$ time complexity, by using a heuristic to select only two pivot points per dimension and projecting all other points via interpolation [S1, unofficial]. Unlike its siblings such as t-SNE or LLE, which focus on local neighborhood preservation or manifold learning, Pivot MDS focuses on global distance preservation with linear complexity, making it suitable for large datasets where computational resources are constrained [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A dataset $P$ of $n$ instances (voxels), where each instance has a feature vector of dimension $d$. A target dimension $k$ (typically $k < d$).
- **Output:** A set of projected points in a $k$-dimensional space.

**Data Structures:**
- $P$: List of $n$ points, where each point is a vector of size $d$.
- $O_a, O_b$: Pivot points selected from $P$.
- $x$: Projected coordinate value.
- $f(a, b)$: Distance function between points $a$ and $b$.

**Numbered Steps:**
1. **Pivot Selection:** Select two pivots $O_a$ and $O_b$ from the dataset $P$ that are furthest apart. This is done using a heuristic to maintain linear time complexity [S1, unofficial].
2. **Projection:** For each point $p \in P$, compute its coordinate $x$ along the axis defined by the segment $O_a O_b$ using the Law of Cosines [S1, unofficial].
3. **Distance Update:** For subsequent dimensions ($i > 1$), update the distance metric to account for previously projected dimensions [S1, unofficial].
4. **Recursion:** Repeat steps 1-3 for $k$ dimensions.

**Formulas:**
The projected coordinate $x$ for a point $p$ given pivots $O_a$ and $O_b$ is calculated as [S1, unofficial]:

$$x = \frac{f(O_a, p)^2 + f(O_a, O_b)^2 - f(O_b, p)^2}{2 f(O_a, O_b)}$$

where:
- $x$ is the projected coordinate.
- $p$ is the original point.
- $O_a$ and $O_b$ are the two pivot points.
- $f(a, b)$ is the distance function (e.g., Euclidean distance).

For dimensions $i \ge 2$, the distance between two points $p_a$ and $p_b$ is adjusted to remove the variance explained by previous projections [S1, unofficial]:

$$f(p_a, p_b) = \sqrt{\text{dist}_d(p_a, p_b)^2 - \text{dist}_{i-1}(\text{proj}_a, \text{proj}_b)^2}$$

where:
- $\text{dist}_d$ is the metric distance operator in the original $d$-dimensional space.
- $\text{dist}_{i-1}$ is the distance between the projections of $p_a$ and $p_b$ in the first $i-1$ dimensions.
- $\text{proj}_a, \text{proj}_b$ are the projected coordinates of $p_a$ and $p_b$ in the previous dimensions.

**Pivot Selection Heuristic (Algorithm 2):**
To avoid the quadratic cost of finding the true furthest pair, the following heuristic is used [S1, unofficial]:
1. Select an arbitrary point $p \in P$ as temporary pivot $O_a$.
2. Select point $p \in P$ furthest from $O_a$ as pivot $O_b$.
3. Select point $p \in P$ furthest from $O_b$ as final pivot $O_a$.

**Pseudocode:**

```python
def pivot_mds(points, target_dim, distance_func):
    """
    Projects points into target_dim dimensions using Pivot MDS (FastMap).
    
    Args:
        points: List of vectors (n x d).
        target_dim: Integer k, the number of output dimensions.
        distance_func: Function f(a, b) returning distance between a and b.
        
    Returns:
        projected_points: List of vectors (n x k).
    """
    n = len(points)
    projected_points = [[0.0] * target_dim for _ in range(n)]
    
    # Current distance matrix is implicit; we compute distances on the fly
    # or maintain a residual distance matrix. For O(nk) complexity, 
    # we typically recompute or update distances. 
    # Note: The formula for i>=2 requires distances in the residual space.
    
    for dim in range(target_dim):
        # Step 1: Select Pivots
        # 1.1 Select arbitrary point as temporary Oa
        idx_Oa = 0
        Oa = points[idx_Oa]
        
        # 1.2 Find point furthest from Oa -> Ob
        max_dist = -1.0
        idx_Ob = -1
        for i in range(n):
            # Use residual distance if dim > 0
            if dim == 0:
                d = distance_func(Oa, points[i])
            else:
                # Calculate residual distance based on previous projections
                # This requires storing previous projections or recomputing
                # For simplicity, assuming distance_func handles residual 
                # or we compute it here.
                # Let's assume we have a helper to get residual distance
                d = get_residual_distance(points, projected_points, i, idx_Oa, dim)
            
            if d > max_dist:
                max_dist = d
                idx_Ob = i
        
        Ob = points[idx_Ob]
        
        # 1.3 Find point furthest from Ob -> New Oa
        max_dist = -1.0
        idx_Oa = -1
        for i in range(n):
            if dim == 0:
                d = distance_func(Ob, points[i])
            else:
                d = get_residual_distance(points, projected_points, i, idx_Ob, dim)
            
            if d > max_dist:
                max_dist = d
                idx_Oa = i
        
        Oa = points[idx_Oa]
        
        # Step 2: Project all points
        # Calculate distance between pivots
        if dim == 0:
            dist_Oa_Ob = distance_func(Oa, Ob)
        else:
            dist_Oa_Ob = get_residual_distance(points, projected_points, idx_Oa, idx_Ob, dim)
            
        # Guard against division by zero
        if dist_Oa_Ob == 0:
            # If pivots are identical, all projections are 0
            for i in range(n):
                projected_points[i][dim] = 0.0
            continue
            
        for i in range(n):
            if dim == 0:
                dist_Oa_p = distance_func(Oa, points[i])
                dist_Ob_p = distance_func(Ob, points[i])
            else:
                dist_Oa_p = get_residual_distance(points, projected_points, i, idx_Oa, dim)
                dist_Ob_p = get_residual_distance(points, projected_points, i, idx_Ob, dim)
                
            # Formula: x = (f(Oa, p)^2 + f(Oa, Ob)^2 - f(Ob, p)^2) / (2 * f(Oa, Ob))
            x = (dist_Oa_p**2 + dist_Oa_Ob**2 - dist_Ob_p**2) / (2 * dist_Oa_Ob)
            projected_points[i][dim] = x

    return projected_points

    """

    # dist_d(a, b) = sqrt(sum((a[j] - b[j])^2))
    
    # For the sake of this pseudocode, we assume a global function

    # Calculate sum of squared differences of previous projections
    sum_sq_proj = 0.0
    for prev_dim in range(current_dim):
        diff = projected_points[idx_p][prev_dim] - projected_points[idx_q][prev_dim]
        sum_sq_proj += diff**2
        
    # Get original distance
    # Note: In a strict O(nk) implementation, we might not want to compute

    # The sources imply f(pa, pb) is the distance in the residual space.
    # f(pa, pb) = sqrt(dist_d(pa, pb)^2 - dist_{i-1}(proj_a, proj_b)^2)

def compute_original_distance(p1, p2):
    """Computes Euclidean distance between two vectors."""
    sum_sq = 0.0
    for a, b in zip(p1, p2):
        sum_sq += (a - b)**2
    return sum_sq**0.5
```

**Parameters:**
- $n$: Total number of voxels (instances).
- $d$: Original dimension of the domain.
- $k$: Target dimension (typically 2 or 3).

**Edge Cases and Pitfalls:**
- **Zero Pivot Distance:** If the two selected pivots are identical (distance 0), the denominator in the projection formula becomes zero. This results in undefined projections. A guard should be added to handle this case, typically by assigning a coordinate of 0 or selecting different pivots [G].
- **Numerical Precision:** The residual distance calculation involves subtracting squared distances, which can lead to negative values due to floating-point errors. A guard should clamp the residual to 0 before taking the square root [G].
- **Heuristic Accuracy:** The pivot selection heuristic does not guarantee the true furthest pair. This may result in slightly less accurate distance preservation compared to exhaustive search, but it is necessary for linear time complexity [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(nk)$, where $n$ is the number of instances and $k$ is the target dimension [S1, unofficial]. This is a significant improvement over classical MDS, which is $O(n^3)$ [S1, unofficial].
- **Memory Complexity:** $O(nk)$ to store the projected points. The distance computations can be done on the fly or with a precomputed distance matrix, but the heuristic approach allows for $O(n)$ space if distances are recomputed [S1, unofficial].
- **Strengths:** Linear time complexity makes it suitable for large datasets. It preserves global distances reasonably well.
- **Limitations:** The heuristic pivot selection may not preserve distances as accurately as exhaustive methods. It assumes the data can be well-approximated by a low-dimensional Euclidean space.
- **When to Use:** When dealing with large datasets where classical MDS is too slow, and global distance preservation is important.
- **When Not to Use:** When local neighborhood structure is more important than global distances (use t-SNE or LLE instead) [S1, unofficial].

## Background
Pivot MDS, also known as FastMap, was introduced by Faloutsos and Lin in 1995 [S1, unofficial]. It was developed as a linear-time variant of Multidimensional Scaling to address the computational infeasibility of classical MDS for large datasets. The method has been applied in various fields, including volume rendering for transfer function design, where it helps reduce high-dimensional feature vectors to a manageable 2D or 3D space for visualization [S1, unofficial]. It is often compared with other dimensionality reduction techniques like Landmarks MDS and t-SNE [S2, unofficial].
