# Transfer Function Core Data Structure

Also called: Transfer Function Management

## Overview
The Transfer Function Core Data Structure is the in-memory representation used to manage volume rendering transfer functions, storing control points for color and opacity mapping alongside Gaussian objects for smooth transitions [S1, unofficial]. It is distinguished from its siblings, [Real-time transfer function evaluation](1551-real-time-transfer-function-evaluation.md) and [Fast Classification Algorithm](5289-fast-classification-algorithm.md), by focusing on the management of control points and the generation of the underlying data tables rather than GPU-accelerated sampling or specific classification logic [S1, unofficial].

## How it works
**Inputs and Outputs:**
The primary input is a set of user-defined control points (color and alpha) and Gaussian objects [S1, unofficial]. The output is a pre-computed RGBA lookup table (`m_rgbaTable`) and an alpha array (`m_alphaArray`) of size `resolution` [S1, unofficial].

**Data Structures:**
The core class maintains the following internal vectors [S1, unofficial]:
*   `m_rgbaTable`: `std::vector<vec4f>`, size `resolution`. Stores the final RGBA values for each index [S1, unofficial].
*   `m_alphaArray`: `std::vector<float>`, size `resolution`. Stores the opacity values [S1, unofficial].
*   `m_colorControls`: `std::vector<ColorControl>` [S1, unofficial].
*   `m_alphaControls`: `std::vector<AlphaControl>` [S1, unofficial].
*   `m_gaussianObjects`: `std::vector<GaussianObject>` [S1, unofficial].

**Struct Layouts:**
The following structs define the control points and vector types [S1, unofficial]:
*   `vec2f`: `x` (float), `y` (float).
*   `vec3f`: `x` (float), `y` (float), `z` (float).
*   `vec4f`: `x` (float), `y` (float), `z` (float), `w` (float).
*   `ColorControl`: `position` (float), `color` (vec3f). Size must equal `sizeof(vec4f)` [S1, unofficial].
*   `AlphaControl`: `pos` (vec2f). Size must equal `sizeof(vec2f)` [S1, unofficial].
*   `GaussianObject`: `mean` (float), `sigma` (float), `heightFactor` (float), `alphaArray` (`std::vector<float>`) [S1, unofficial].

**Algorithm:**
The transfer function is constructed and updated through the following steps [S1, unofficial]:

1.  **Initialization**: Create a `TransferFunctionCore` instance with a `resolution` (default 1024) [S1, unofficial]. Allocate `m_rgbaTable` and `m_alphaArray` of this size [S1, unofficial]. The default constructor initializes `window_left` to 0, `window_width` to 1, and calls `randomize()` [S2, unofficial].
2.  **Control Point Management**: Add color control points to `m_colorControls`, maintaining sorted order by `position` [S1, unofficial]. Add alpha control points to `m_alphaControls` [S1, unofficial]. Add Gaussian objects to `m_gaussianObjects` [S1, unofficial].
3.  **Update Color Map**: Call `updateColorMap()` [S1, unofficial]. This function iterates through the `resolution` indices, calculates the normalized scalar value $x = i / (\text{resolution} - 1)$, interpolates the color from `m_colorControls`, and applies Gaussian objects to compute the alpha component for the RGBA table [S1, unofficial].
4.  **Update Alpha Array**: Call `updateFromAlphaControls()` [S1, unofficial]. This sets `m_alphaArray` entries based on `m_alphaControls` [S1, unofficial].
5.  **Finalize**: The `m_rgbaTable` now contains the final RGBA values and `m_alphaArray` contains the final opacity values, accessible via `data()` and `alphaArray()` respectively [S1, unofficial].

**Pseudocode:**
```python
import math

class vec2f:
    def __init__(self, x, y): self.x, self.y = x, y

class vec3f:
    def __init__(self, x, y, z): self.x, self.y, self.z = x, y, z

class vec4f:
    def __init__(self, x, y, z, w): self.x, self.y, self.z, self.w = x, y, z, w

class ColorControl:
    def __init__(self, position, color): self.position, self.color = position, color

class AlphaControl:
    def __init__(self, pos): self.pos = pos

class GaussianObject:
    def __init__(self, mean, sigma, height_factor):
        self.mean, self.sigma, self.height_factor = mean, sigma, height_factor

class TransferFunctionCore:
    def __init__(self, resolution=1024):
        if resolution <= 0:
            raise ValueError("Resolution must be greater than 0")
        self.resolution = resolution
        self.m_rgbaTable = [vec4f(0.0, 0.0, 0.0, 0.0) for _ in range(resolution)]
        self.m_alphaArray = [0.0] * resolution
        self.m_colorControls = []
        self.m_alphaControls = []
        self.m_gaussianObjects = []
        self.window_left = 0.0
        self.window_width = 1.0
        # randomize() call omitted; sources do not specify its implementation [G]

    def add_color_control(self, position, r, g, b):
        control = ColorControl(position, vec3f(r, g, b))
        self.m_colorControls.append(control)
        self.m_colorControls.sort(key=lambda c: c.position)
        self.update_color_map()

    def add_alpha_control(self, pos_x, pos_y):
        control = AlphaControl(vec2f(pos_x, pos_y))
        self.m_alphaControls.append(control)
        self.update_from_alpha_controls()

    def add_gaussian_object(self, mean, sigma, height_factor):
        gauss = GaussianObject(mean, sigma, height_factor)
        self.m_gaussianObjects.append(gauss)
        self.update_color_map()

    def update_color_map(self):
        for i in range(self.resolution):
            x = i / (self.resolution - 1) if self.resolution > 1 else 0.0
            color = self._interpolate_color(x)
            alpha = self._calculate_gaussian_alpha(x)
            self.m_rgbaTable[i] = vec4f(color.x, color.y, color.z, alpha)

    def _interpolate_color(self, x):
        if not self.m_colorControls:
            return vec3f(0.0, 0.0, 0.0)
        controls = self.m_colorControls
        if x <= controls[0].position:
            return controls[0].color
        if x >= controls[-1].position:
            return controls[-1].color
        for i in range(len(controls) - 1):
            if controls[i].position <= x <= controls[i+1].position:
                t = (x - controls[i].position) / (controls[i+1].position - controls[i].position)
                r = controls[i].color.x + t * (controls[i+1].color.x - controls[i].color.x)
                g = controls[i].color.y + t * (controls[i+1].color.y - controls[i].color.y)
                b = controls[i].color.z + t * (controls[i+1].color.z - controls[i].color.z)
                return vec3f(r, g, b)
        return vec3f(0.0, 0.0, 0.0)

    def _calculate_gaussian_alpha(self, x):
        alpha = 0.0
        for gauss in self.m_gaussianObjects:
            if gauss.sigma > 0:
                diff = x - gauss.mean
                alpha += gauss.height_factor * math.exp(-0.5 * (diff / gauss.sigma) ** 2)
        return min(alpha, 1.0)

    def update_from_alpha_controls(self):
        if not self.m_alphaControls:
            return
        controls = self.m_alphaControls
        for i in range(self.resolution):
            x = i / (self.resolution - 1) if self.resolution > 1 else 0.0
            if x <= controls[0].pos.x:
                self.m_alphaArray[i] = controls[0].pos.y
            elif x >= controls[-1].pos.x:
                self.m_alphaArray[i] = controls[-1].pos.y
            else:
                for j in range(len(controls) - 1):
                    if controls[j].pos.x <= x <= controls[j+1].pos.x:
                        t = (x - controls[j].pos.x) / (controls[j+1].pos.x - controls[j].pos.x)
                        self.m_alphaArray[i] = controls[j].pos.y + t * (controls[j+1].pos.y - controls[j].pos.y)
                        break

    def clear(self):
        self.m_rgbaTable = [vec4f(0.0, 0.0, 0.0, 0.0) for _ in range(self.resolution)]
        self.m_alphaArray = [0.0] * self.resolution
        self.m_colorControls.clear()
        self.m_alphaControls.clear()
        self.m_gaussianObjects.clear()
```

**Parameters:**
*   `resolution`: Number of entries in the RGBA table and alpha array, default 1024 [S1, unofficial].

**Edge Cases and Pitfalls:**
*   Resolution must be greater than 0 [S1, unofficial].
*   Color control points must be kept sorted by position [S1, unofficial].
*   ParaView's diverging color space interpolation is not supported in some converters, leading to incorrect colors [S1, unofficial].

## Subtopics

### [Transfer Function Serialization](4343-transfer-function-serialization.md)
Transfer Function Serialization converts an in-memory transfer function data structure into a persistent JSON format and reconstructs it upon loading. It stores volume rendering transfer function parameters, including color and opacity controls, Gaussian objects, and lighting settings, in a JSON file for runtime loading. It is distinguished from its parent, the Transfer Function Core Data Structure, by its focus on I/O persistence rather than runtime evaluation.

### Data Pointer Layout for Transfer Functions
Some implementations, such as VTK's `vtkColorTransferFunction`, provide a data pointer that returns an interleaved array with the layout `[X1, R1, G1, B1, X2, R2, G2, B2, ..., Xn, Rn, Gn, Bn]`, where `n` is the number of nodes defining the transfer function [S3]. The returned pointer is managed by the class; callers must not free it [S3]. This layout allows for efficient bulk updates or serialization of the transfer function nodes [S3].

## Background
