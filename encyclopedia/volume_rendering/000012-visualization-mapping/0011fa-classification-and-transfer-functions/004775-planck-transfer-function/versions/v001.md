# Planck Transfer Function
## Overview
The Planck Transfer Function maps volumetric scalar fields (typically temperature and density) to optical properties by modeling black body radiation convolved with spectral filters [S1]. It solves the problem of physically plausible emission and absorption for hot gases or plasmas, distinguishing itself from generic artistic transfer functions by grounding color and intensity in physical emission models [S1, S2].
## How it works
**Inputs and Outputs:**
*   **Inputs:** A scalar field representing temperature ($T$) and a scalar field representing density or optical depth parameter ($\rho$).
*   **Outputs:** Opacity ($\alpha$) and Color ($C = [r, g, b]$) for each sample point.

**Data Structures:**
The function maintains two lookup tables (LUTs) or continuous functions:
1.  **Emission Table:** Maps temperature $T$ to spectral radiance values for Red, Green, and Blue channels.
2.  **Absorption Table:** Maps density $\rho$ to absorption coefficients.

**Parameters:**
*   $T_{bounds}$: Tuple $(T_{min}, T_{max})$ defining the range of tabulated emission [S1].
*   $\rho_{bounds}$: Tuple $(\rho_{min}, \rho_{max})$ defining the range of tabulated absorption [S1].
*   $n_{bins}$: Number of bins for discretization (default 256) [S1].
*   $filter_{R}, filter_{G}, filter_{B}$: Johnson filter names (default 'R', 'V', 'B') [S1].
*   $a_{norm}$: Normalization fudge factor for scattering approximation (default $1,000,000.0$) [S1].

**Method Steps:**
1.  **Black Body Calculation:** For a given temperature $T$, calculate the spectral radiance $B(\lambda, T)$ using Planck's Law:
    $$ B(\lambda, T) = \frac{2hc^2}{\lambda^5} \frac{1}{e^{\frac{hc}{\lambda k_B T}} - 1} $$
    where $h$ is Planck's constant, $c$ is the speed of light, and $k_B$ is Boltzmann's constant [S1, S2].
2.  **Filter Convolution:** Integrate $B(\lambda, T)$ over the spectral response curves of the specified Johnson filters ($R, V, B$) to obtain raw channel intensities $I_R, I_G, I_B$ [S1].
3.  **Normalization:** Scale the intensities by $a_{norm}$ to adjust relative reddening and match the scattering approximation [S1].
    $$ I'_{c} = a_{norm} \cdot I_{c} \quad \text{for } c \in \{R, G, B\} $$
4.  **Absorption Mapping:** Calculate absorption coefficient $\alpha_{coeff}$ based on density $\rho$ within $\rho_{bounds}$ [S1].
5.  **Composite Output:** The final opacity and color for a sample are derived from the emission intensities and absorption coefficient. In the implementation, these are added to integration channels [S1].

**Pseudocode:**
```python
import numpy as np

def planck_lambda(wavelength, temp):
    """Calculate Planck's Law spectral radiance."""
    h = 6.626e-34
    c = 3.0e8
    kb = 1.38e-23
    exponent = (h * c) / (wavelength * kb * temp)
    # Handle division by zero or very small temps
    if exponent > 100:
        return 0.0
    return (2 * h * c**2) / (wavelength**5 * (np.exp(exponent) - 1))

def get_johnson_filter_response(filter_name):
    """Return spectral response curve for a Johnson filter. [G]"""
    # Placeholder for actual filter data
    return lambda w: 1.0 if 400e-9 <= w <= 700e-9 else 0.0

def evaluate_planck_tf(temp, density, t_bounds, rho_bounds, anorm, filters):
    """
    Evaluate Planck Transfer Function.
    temp: scalar temperature
    density: scalar density
    t_bounds: (t_min, t_max)
    rho_bounds: (rho_min, rho_max)
    anorm: normalization factor
    filters: dict {'R': filter_func, 'G': filter_func, 'B': filter_func}
    """
    # 1. Clamp temperature to bounds
    t_clamped = np.clip(temp, t_bounds[0], t_bounds[1])
    
    # 2. Calculate Black Body Emission per channel
    # Integrate Planck's law over visible spectrum (approx 400nm to 700nm)
    wavelengths = np.linspace(400e-9, 700e-9, 100)
    d_lambda = wavelengths[1] - wavelengths[0]
    
    emission = {}
    for channel, filter_func in filters.items():
        # Sum B(lambda, T) * Filter(lambda)
        radiance = 0.0
        for w in wavelengths:
            b_val = planck_lambda(w, t_clamped)
            f_val = filter_func(w)
            radiance += b_val * f_val * d_lambda
        # 3. Normalize
        emission[channel] = anorm * radiance
        
    # 4. Calculate Absorption from density
    # Linear mapping from density to absorption coefficient [G]
    rho_min, rho_max = rho_bounds
    if rho_max == rho_min:
        alpha_coeff = 0.0
    else:
        alpha_coeff = (density - rho_min) / (rho_max - rho_min)
        alpha_coeff = np.clip(alpha_coeff, 0.0, 1.0)
        
    # 5. Return Color and Opacity
    # Note: Exact combination of emission and absorption depends on the 
    # specific ray marching integrator. Here we return the raw optical properties.
    color = np.array([emission['R'], emission['G'], emission['B']])
    opacity = alpha_coeff # Or derived from alpha_coeff * path_length
    
    return color, opacity
```

## Subtopics

### Black Body Radiation Model
A variant used primarily for fire visualization. It transitions between an artistic look (parameter 0) and a realistic physically-based intensity (parameter 1) [S2]. In realistic mode, it multiplies the fire intensity by the Black Body Radiation model, giving strong brightness to hot parts of the fire [S2]. Controlled by the `emBlackBody` parameter [S2].

## Operating characteristics
**Time and Memory Complexity:**
*   **Memory:** Requires storage for the emission LUT (size $n_{bins} \times 3$) and absorption LUT (size $n_{bins}$) [S1].
*   **Time:** Evaluation is $O(1)$ per sample if using LUTs, or $O(N)$ if integrating Planck's law dynamically per sample [S1].

**Strengths and Limitations:**
*   **Strengths:** Provides physically accurate color for hot objects; handles reddening via $a_{norm}$ [S1].
*   **Limitations:** The normalization is arbitrary ("fudge factor") and unit-free, potentially leading to inaccurate relative reddening if not tuned [S1]. Not suitable for compositing fire mixed with smoke without additional opacity handling [S2].
## Background
Originated in the `yt` visualization library for astrophysics, specifically for rendering plasma and hot gas volumes where black body emission is a dominant physical process [S1]. Also referenced in Voxel Shader implementations for fire effects in Maya/Phoenix to enhance realism [S2].
