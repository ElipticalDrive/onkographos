# Split Conformal Prediction Calibration

Also called: Conformal Calibration, UA-NeRF Calibration

## Overview
Split Conformal Prediction Calibration is a post-hoc calibration method that yields provable, distribution-free per-ray coverage guarantees at any user-specified confidence level for uncertainty-aware volume rendering [S1, unofficial]. It addresses the problem of miscalibrated uncertainty estimates in neural radiance fields (NeRFs) by using a held-out calibration set to adjust prediction intervals, ensuring that the empirical coverage matches the nominal confidence level [S1, unofficial]. Unlike standard uncertainty quantification which may produce over- or under-confident predictions, this method provides marginal coverage guarantees without assuming a specific data distribution [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:**
    *   A trained uncertainty-aware NeRF model (e.g., UA-PlantNeRF) that outputs a predicted value $\hat{c}(r)$ and total uncertainty $U_{total}(r)$ for each ray $r$ [S1, unofficial].
    *   A calibration dataset $D_{cal}$ consisting of rays from held-out scenes (plants) entirely excluded from the training process [S1, unofficial].
    *   A significance level $\alpha$ (e.g., 0.10) [S1, unofficial].
*   **Outputs:**
    *   A conformal quantile $\hat{q}$ [S1, unofficial].
    *   Calibrated prediction intervals for test rays: $[\hat{c}(r) - \hat{q}\sqrt{U_{total}(r)}, \hat{c}(r) + \hat{q}\sqrt{U_{total}(r)}]$ [S1, unofficial].
    *   Masked density values for mesh extraction (zeroed where uncertainty is too high) [S1, unofficial].

**Data Structures:**
*   **Calibration Set ($D_{cal}$):** A collection of rays $\{(r_j, c_j)\}_{j=1}^{n_{cal}}$ where $r_j$ is the ray geometry and $c_j$ is the ground truth observation (e.g., color or density) [S1, unofficial].
*   **Non-Conformity Scores ($s_j$):** A scalar value for each calibration ray representing the normalized residual [S1, unofficial].
*   **Conformal Quantile ($\hat{q}$):** A single scalar value derived from the sorted scores [S1, unofficial].

**Parameters:**
*   **Significance Level ($\alpha$):** Typically 0.10 [S1, unofficial].
*   **Epsilon ($\varepsilon$):** $10^{-6}$, used to prevent division by zero in score calculation. Results are stable for $\varepsilon \in [10^{-8}, 10^{-4}]$ [S1, unofficial].
*   **Density Zeroing Threshold:** $1.5 \hat{q}$, used to mask unreliable regions prior to mesh extraction [S1, unofficial].

**Steps:**
1.  **Construct Calibration Set:** Select a set of scenes (plants) that are completely disjoint from the training set. This ensures exchangeability between calibration and test residuals [S1, unofficial]. Do not use held-out views of the same scenes, as view-correlated residuals violate exchangeability [S1, unofficial].
2.  **Compute Non-Conformity Scores:** For each ray $j$ in the calibration set, compute the score $s_j$ using the model's prediction $\hat{c}(r_j)$, ground truth $c_j$, and total uncertainty $U_{total}(r_j)$:
    $$ s_j = \frac{\|\hat{c}(r_j) - c_j\|}{\sqrt{U_{total}(r_j) + \varepsilon}} $$
    where $\|\cdot\|$ denotes the Euclidean norm (or absolute difference for scalar outputs) [S1, unofficial].
3.  **Calculate Conformal Quantile:** Sort the scores $\{s_j\}_{j=1}^{n_{cal}}$ in ascending order. Compute the quantile index $k = \lceil (n_{cal} + 1)(1 - \alpha) \rceil$. The conformal quantile $\hat{q}$ is the $k$-th smallest score:
    $$ \hat{q} = \text{Quantile}_{k/n_{cal}} \{s_j\}_{j=1}^{n_{cal}} $$
    [S1, unofficial].
4.  **Apply Calibration:** For any test ray $r$, construct the prediction interval:
    $$ \hat{c}(r) \pm \hat{q} \sqrt{U_{total}(r)} $$
    This interval provides marginal coverage $\ge 1 - \alpha$ [S1, unofficial].
5.  **Masking for Extraction (Optional):** Prior to mesh extraction (e.g., Marching Cubes), zero density values where $U_{total}(r) > 1.5 \hat{q}$ to remove regions with excessive uncertainty [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def split_conformal_calibration(
    model, 
    calibration_rays, 
    calibration_ground_truth, 
    alpha=0.10, 
    epsilon=1e-6
):
    """
    Computes the conformal quantile for calibration.
    
    Args:
        model: Uncertainty-aware NeRF model with predict(r) -> (pred, uncertainty).
        calibration_rays: List of ray objects or tensors for calibration set.
        calibration_ground_truth: Array of ground truth values corresponding to rays.
        alpha: Significance level (e.g., 0.10).
        epsilon: Small constant for numerical stability.
        
    Returns:
        q_hat: The conformal quantile.
    """
    n_cal = len(calibration_rays)
    scores = np.zeros(n_cal)
    
    for j in range(n_cal):
        r_j = calibration_rays[j]
        c_j = calibration_ground_truth[j]
        
        # Get model prediction and total uncertainty
        # Model returns predicted value and total uncertainty U_total
        c_hat, u_total = model.predict(r_j)
        
        # Compute non-conformity score
        # Using Euclidean norm for vector outputs, absolute diff for scalar
        residual_norm = np.linalg.norm(c_hat - c_j)
        scores[j] = residual_norm / np.sqrt(u_total + epsilon)
        
    # Sort scores
    sorted_scores = np.sort(scores)
    
    # Calculate quantile index
    # ceil((n_cal + 1) * (1 - alpha))
    k = int(np.ceil((n_cal + 1) * (1 - alpha)))
    
    # Ensure index is within bounds
    if k > n_cal:
        k = n_cal
        
    q_hat = sorted_scores[k - 1]
    
    return q_hat

def apply_calibration(model, test_rays, q_hat, epsilon=1e-6):
    """
    Applies the conformal quantile to generate prediction intervals.
    
    Args:
        model: Uncertainty-aware NeRF model.
        test_rays: List of test ray objects.
        q_hat: The conformal quantile computed from calibration.
        epsilon: Small constant for numerical stability.
        
    Returns:
        intervals: List of tuples (lower_bound, upper_bound) for each ray.
        masks: Boolean array indicating if density should be zeroed (U_total > 1.5 * q_hat).
    """
    intervals = []
    masks = []
    
    for r in test_rays:
        c_hat, u_total = model.predict(r)
        
        # Calibrated interval: c_hat +/- q_hat * sqrt(U_total)
        margin = q_hat * np.sqrt(u_total + epsilon)
        lower = c_hat - margin
        upper = c_hat + margin
        intervals.append((lower, upper))
        
        # Masking condition for mesh extraction
        masks.append(u_total > 1.5 * q_hat)
        
    return intervals, masks
```

**Edge Cases and Pitfalls:**
*   **Exchangeability Violation:** Using held-out views of the same scene for calibration violates exchangeability due to view-correlated residuals, leading to invalid coverage guarantees [S1, unofficial].
*   **Marginal vs. Conditional Coverage:** The guarantee is marginal (holds in expectation over the joint distribution), not conditional for specific anatomical regions or individual plants. Empirical conditional coverage may deviate from the target [S1, unofficial].
*   **Small Calibration Sets:** Conditional conformal methods require larger per-region calibration sets, which may not be available in sparse-view benchmarks [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Calibration requires a single forward pass over the calibration set to compute scores, followed by sorting $O(n_{cal} \log n_{cal})$. Test-time inference adds a constant-time adjustment to the prediction interval.
*   **Memory Complexity:** Requires storing the calibration set and the sorted scores. Memory usage is linear in the number of calibration rays.
*   **Measured Performance:** Evaluated on Pheno4D, ROSE-X, and UA-Field datasets. At sparsity level $N=30$, UA-PlantNeRF with conformal calibration achieved PSNR $28.7 \pm 0.6$ dB and SSIM $0.89 \pm 0.01$, outperforming baselines ($p < 0.05$). Conformal calibration achieved 89.7% empirical coverage at the 90% nominal target, reducing ECE from 0.143 to 0.041 [S1, unofficial].
*   **Strengths:** Provides distribution-free, provable coverage guarantees; simple to implement as a post-processing step; improves reliability of uncertainty estimates.
*   **Limitations:** Only guarantees marginal coverage; requires a sufficiently large, exchangeable calibration set; does not provide per-region conditional guarantees.

## Background
Split Conformal Prediction Calibration was introduced in the context of uncertainty-aware 3D plant reconstruction from sparse video frames using Neural Radiance Fields (UA-PlantNeRF) [S1, unofficial]. The method leverages the principles of conformal prediction to address the lack of calibrated uncertainty in deep learning-based volume rendering, specifically for high-throughput plant phenotyping applications where reliable uncertainty quantification is critical for downstream analysis [S1, unofficial].
