# Local Data Models for Probabilistic Transfer Function Design
Also called: Local GMM Classification, Probabilistic Transfer Function Design

## Overview
A technique for interactive multi-dimensional transfer function design that couples high-dimensional, probabilistic, data-centric segmentation with interaction in 3D space [S1, unofficial]. It fits variable Gaussian Mixture Models (GMMs) to user-specified subsets of data to create a probabilistic data model of a material type [S1, unofficial]. Unlike global fitting methods which may produce multiple small Gaussians in high-density regions requiring clipping, this method guides local feature classification by fitting GMMs only to selected subsets, yielding a probabilistic data model of the identified material type and its sources [S1, unofficial]. It builds on [Gaussian Mixture Models](15189-gaussian-mixture-models.md) and differs from [Gaussian Sum Transfer Function](1812-gaussian-sum-transfer-function.md) by emphasizing interactive, local subset selection rather than global statistical modeling.

## How it works
**Inputs:**
- A volume dataset with scalar values and potentially derived features (e.g., gradient magnitude).
- A user-defined selection of voxels in 3D space, typically via a spherical selection tool moving along the surface of the unclassified volume [S1, unofficial].

**Outputs:**
- A local data model defined as a mixture of GMMs representing the selected material type.
- A classification map assigning class membership probabilities to all voxels in the dataset.
- A saved classifier entry for further interaction (optical properties, merging) [S1, unofficial].

**Data Structures:**
- **Selection Mask:** A boolean or float mask updated locally during run-time to display selected regions of the volume [S1, unofficial].
- **Classified Voxels Set:** A set of voxels marked as classified to prevent re-classification.
- **GMM Parameters:** For each Gaussian component $k$ in the mixture: mean vector $\mu_k$, covariance matrix $\Sigma_k$, and weight $\alpha_k$. The number of Gaussians is variable and determined by the fitting process [S1, unofficial].

**Parameters:**
- $\delta$: A threshold parameter for the probability gradient constraint, used to ensure neighborhood in the histogram by constraining the maximal probability gradient magnitude. Typical value: $0.5$ [S1, unofficial].

**Steps:**
1. **User Selection:** The user initiates model estimation by providing feature samples via a spherical selection tool moving along the surface of the unclassified volume [S1, unofficial]. Selection in image space corresponds to a partial histogram selection [S1, unofficial].
2. **Local GMM Fitting:** A mixture of GMMs is fitted to the selected subset of the histogram using unsupervised learning and one-class classification to model the selected samples as random variables from multiple probabilistic sources [S1, unofficial].
3. **Initial Probabilistic Classification:** Samples within a predefined confidence interval of the extracted normal distributions are automatically classified with respective probability [S1, unofficial]. Let $P_i$ be the probability that voxel $i$ belongs to the current class.
4. **Neighborhood Extension:** Classification is extended to neighboring data points by taking image connectivity and histogram continuity into account. A data point $j$ with probability $P_j$ is included if all of the following conditions are fulfilled:
   - i) $P_j$ is significantly above zero [S1, unofficial].
   - ii) It is a direct neighbor (in image space) to a member $i$ of the class [S1, unofficial].
   - iii) $P_j > \delta P_i$, with $\delta < 1$ [S1, unofficial].
   These conditions guarantee that class membership is only extended to voxels that are spatially close to definite members both in volumetric image space and histogram space, counteracting the GMMs’ tendency to overgeneralize [S1, unofficial].
5. **Verification and Modification:** The user can inspect or modify the classification by adding/removing samples via interaction with the volume until visually verified [S1, unofficial].
6. **Saving and Removal:** After verification, the local data model is saved to a list of valid classifiers. Its members (for a given confidence value) are removed from the volume to prevent re-classification [S1, unofficial]. Saved classes are shown in a class list for further interaction, such as specification of optical properties or class merging [S1, unofficial].

**Pseudocode:**
```python
def local_data_model_classification(volume, initial_selection_mask, delta=0.5):
    """
    Performs local data model classification using GMMs.
    
    Args:
        volume: 3D array of feature vectors (e.g., [scalar, gradient]).
        initial_selection_mask: Boolean mask indicating user-selected voxels.
        delta: Probability gradient threshold (default 0.5).
        
    Returns:
        classification_map: 3D array of class membership probabilities.
        gmm_model: Fitted GMM parameters.
    """
    # Step 1: Extract selected features
    selected_features = volume[initial_selection_mask]
    
    # Step 2: Fit GMM to selected subset
    # Uses unsupervised learning (e.g., Expectation-Maximization)
    gmm_model = fit_gmm(selected_features)
    
    # Step 3: Initial classification based on confidence interval
    # Calculate probability P_i for all voxels i in volume
    classification_map = calculate_gmm_probabilities(volume, gmm_model)
    
    # Identify initially classified voxels (e.g., P_i > threshold)
    # Note: "significantly above zero" is implementation-dependent [G]
    initial_classified = find_voxels_above_threshold(classification_map, threshold=0.1)
    
    # Step 4: Neighborhood extension
    # Use a queue-based approach (e.g., BFS) to extend classification
    queue = list(initial_classified)
    classified_set = set(initial_classified)
    
    while queue:
        current_voxel = queue.pop(0)
        current_prob = classification_map[current_voxel]
        
        # Get direct neighbors in image space
        neighbors = get_direct_neighbors(current_voxel, volume.shape)
        
        for neighbor in neighbors:
            if neighbor not in classified_set:
                neighbor_prob = classification_map[neighbor]
                
                # Condition i: P_j significantly above zero [G]
                if neighbor_prob < 0.01:
                    continue
                    
                # Condition ii: Direct neighbor (checked by loop structure)
                # Condition iii: P_j > delta * P_i
                if neighbor_prob > delta * current_prob:
                    classified_set.add(neighbor)
                    queue.append(neighbor)
    
    # Step 5: Update classification map with extended results
    # Voxels in classified_set retain their calculated probabilities
    # Voxels not in classified_set are marked as unclassified (e.g., 0)
    final_classification_map = np.zeros_like(classification_map)
    for voxel in classified_set:
        final_classification_map[voxel] = classification_map[voxel]
        
    return final_classification_map, gmm_model
```

**Edge Cases and Pitfalls:**
- **Performance:** Large numbers of Gaussians evaluated per sample point on rays slow down volume rendering significantly [S1, unofficial]. This is alleviated by using pre-classified volume ray-casting, where each voxel is assigned class memberships during class construction [S1, unofficial].
- **Overgeneralization:** Without the neighborhood extension constraints, GMMs may overgeneralize [S1, unofficial]. The condition $P_j > \delta P_i$ ensures neighborhood in the histogram by constraining the maximal probability gradient magnitude [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Fitting GMMs is iterative and depends on the number of selected samples and Gaussians. Classification involves evaluating the GMM for all voxels and a neighborhood extension step. Performance is impacted by the number of Gaussians [S1, unofficial].
- **Memory Complexity:** Requires storage for the volume, the classification map, and the GMM parameters. Pre-classified volume ray-casting requires storing class memberships per voxel [S1, unofficial].
- **Measured Performance:** Not given in the sources.
- **Scaling:** The method is designed for interactive use, implying it scales reasonably for typical volume rendering resolutions. However, large numbers of Gaussians degrade rendering performance [S1, unofficial].
- **Strengths:** Allows for interactive, data-centric segmentation in 3D space; handles multi-dimensional data; prevents overgeneralization through neighborhood constraints; enables efficient transfer function design [S1, unofficial].
- **Limitations:** Performance degrades with many Gaussians; requires user interaction for selection; "significantly above zero" threshold is not explicitly defined [G].
- **When to use:** When interactive, local classification of materials in multi-dimensional volume data is required, and global fitting methods produce undesirable artifacts [S1, unofficial].
- **When not to use:** When real-time rendering with a very large number of material classes is critical without pre-classification, or when fully automatic, non-interactive classification is needed [S1, unofficial].

## Background
- **Origin:** The method was presented by H. Obermaier & K. I. Joy in 2013 [S1, unofficial].
- **History and Development:** It addresses problems of interactive multi-dimensional transfer function design by coupling high-dimensional, probabilistic, data-centric segmentation with interaction in the natural 3D space of the volume [S1, unofficial]. It contrasts with global GMM fitting approaches [WCS*10] which may require clipping to balance fits [S1, unofficial].
- **Applications:** Used in volume rendering for medicine and engineering, where distinct materials need to be displayed [S1, unofficial].
