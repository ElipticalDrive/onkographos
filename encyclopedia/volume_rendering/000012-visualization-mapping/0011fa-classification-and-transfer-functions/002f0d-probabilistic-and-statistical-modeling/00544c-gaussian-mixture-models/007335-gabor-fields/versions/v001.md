# Gabor Fields

Also called: Steerable Pyramid Decomposition, Volumetric Laplacian Pyramid

## Overview
Gabor Fields represent volumetric density as a mixture of Gaussian and Gabor kernels (harmonically modulated Gaussians) to enable continuous, orientation-selective frequency filtering and level-of-detail (LOD) without re-fitting or extra storage [S1, S2]. Unlike Gaussian-based representations that require expensive energy-based optimizations or mipmapping for downsampling, Gabor Fields achieve LOD by simply pruning primitives, preserving smooth transitions and avoiding discontinuities [S2]. This method achieves ~2 dB higher PSNR at equal primitive count and renders up to ~1.4× faster than Gaussian-based representations, while supporting acceleration via control variates for an additional ~2× speedup [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A volumetric dataset or procedural asset to be represented.
*   **Output:** A set of Gabor Field primitives (kernels) comprising a low-pass Gaussian base and high-frequency Gabor residuals, along with parameters for stochastic masking and LOD.

**Data Structures:**
Each primitive $i$ is defined by the following fields:
1.  **Amplitude ($A_i$):** Scalar weight. For the base, $A_i > 0$. For residuals, $A_i$ can be positive or negative.
2.  **Mean ($\boldsymbol{\mu}_i$):** 3D center position.
3.  **Covariance ($\boldsymbol{\Sigma}_i$):** $3 \times 3$ symmetric positive-definite matrix defining the Gaussian envelope's shape and orientation.
4.  **Frequency Vector ($\boldsymbol{\omega}_i$):** 3D vector defining the modulation frequency and orientation.
    *   For the low-pass base, $\boldsymbol{\omega}_i = \mathbf{0}$ (plain Gaussian).
    *   For residuals, $\|\boldsymbol{\omega}_i\| > 0$.
5.  **Frequency Band Index ($b_i$):** Integer identifying the spectral band (e.g., low, mid, high) to which the kernel belongs.

**Formulas:**
The density function of a single anisotropic Gabor kernel is:
$$ g_i(\mathbf{x}) = A_i \exp\left(-\frac{1}{2}(\mathbf{x} - \boldsymbol{\mu}_i)^T \boldsymbol{\Sigma}_i^{-1} (\mathbf{x} - \boldsymbol{\mu}_i)\right) \cos(\boldsymbol{\omega}_i^T (\mathbf{x} - \boldsymbol{\mu}_i)) $$
In the Fourier domain, the kernel consists of two symmetric lobes at $\pm \boldsymbol{\omega}_i$, concentrating the spectrum in a specific frequency band and orientation [S1]. The power spectrum allows analytical computation of each kernel's contribution [S1].

**Parameters:**
*   **$\beta$:** A parameter used in power-law probability selection for stochastic masking of Gabor residuals. It trades a small amount of high-frequency error for rendering speed [S1].
*   **Cutoff Frequency:** Determines which kernels are masked. As the cutoff shrinks, kernels with frequency components above the cutoff are excluded [S1, S2].

**Steps:**
1.  **Decomposition:** Represent the volume as a mixture of kernels. Combine positive, zero-frequency Gabor kernels (Gaussians) for the low-pass base and Gabor kernels with $\boldsymbol{\omega} \neq \mathbf{0}$ for the residual high-frequency bands [S1, S2].
2.  **Orientation Splitting:** Split each frequency band into oriented, steerable sub-bands to enable orientation selectivity [S1].
3.  **Ray-Space Masking (Pre-Intersection):** For a given ray direction $\mathbf{d}$, calculate the alignment with each kernel's frequency vector $\boldsymbol{\omega}_i$. If the ray aligns with the wave direction, the positive and negative lobes cancel, and the contribution collapses. Mask kernels that cannot contribute significantly to the ray before intersection [S1, S2].
4.  **LOD Filtering:** To reduce frequency content, selectively prune primitives (kernels) that do not contribute meaningfully at the desired cutoff frequency. This is done by removing kernels based on their spectral content, which can be analytically computed [S1, S2]. This provides continuous LOD without popping or re-fitting [S1, S2].
5.  **Control Variate Acceleration:**
    *   Always trace and analytically integrate the Gaussian base (low-pass), which constitutes ~2% of total primitives but carries most density [S1].
    *   At each sample, stochastically select which Gabor residuals to include based on their frequency band and a power-law probability governed by $\beta$ [S1].
    *   For shadow rays (next-event estimation), trace against the Gaussian base only, skipping Gabor residuals entirely, as the base contains almost all density [S1].

**Pseudocode:**
```python
def render_gabor_field(ray, primitives, base_primitives, beta, cutoff_freq):
    """
    Render a volume using Gabor Fields with control variates and LOD.
    
    Args:
        ray: Ray origin and direction.
        primitives: List of all Gabor kernels (base + residuals).
        base_primitives: List of zero-frequency Gabor kernels (Gaussians).
        beta: Power-law parameter for stochastic selection.
        cutoff_freq: Current frequency cutoff for LOD.
        
    Returns:
        Transmittance and color along the ray.
    """
    # 1. Analytically integrate the Gaussian base (Control Variate)
    base_transmittance = 0.0
    base_color = 0.0
    for kernel in base_primitives:
        # Analytical integration of Gaussian kernel along ray
        t_min, t_max = ray.intersect_bounding_box(kernel)
        if t_min > t_max:
            continue
        # Compute integral of Gaussian envelope along ray segment
        integral = kernel.analytic_integral_along_ray(ray, t_min, t_max)
        base_transmittance += integral
        base_color += integral * kernel.emission
        
    # 2. Stochastically select Gabor residuals for LOD and variance reduction
    residual_transmittance = 0.0
    residual_color = 0.0
    
    # Filter primitives by cutoff frequency and orientation
    active_residuals = []
    for kernel in primitives:
        if kernel in base_primitives:
            continue
            
        # LOD: Check if kernel frequency is below cutoff
        freq_magnitude = norm(kernel.frequency_vector)
        if freq_magnitude > cutoff_freq:
            continue
            
        # Orientation Masking: Check if ray aligns with kernel frequency
        # If ray direction is parallel to frequency vector, contribution cancels
        alignment = dot(ray.direction, normalize(kernel.frequency_vector))
        if abs(alignment) > 0.95: # Threshold for cancellation
            continue
            
        # Stochastic Selection: Power-law probability based on frequency
        # Higher frequency kernels have lower probability of being selected
        # This is controlled by beta
        prob = 1.0 / (1.0 + (freq_magnitude ** beta))
        if random() > prob:
            continue
            
        active_residuals.append(kernel)
        
    # 3. Trace active residuals
    for kernel in active_residuals:
        t_min, t_max = ray.intersect_bounding_box(kernel)
        if t_min > t_max:
            continue
        # Analytical integration of Gabor kernel along ray segment
        # Note: Gabor kernels can have negative density, so integral can be negative
        integral = kernel.analytic_integral_along_ray(ray, t_min, t_max)
        residual_transmittance += integral
        residual_color += integral * kernel.emission
        
    # 4. Combine results
    total_transmittance = base_transmittance + residual_transmittance
    total_color = base_color + residual_color
    
    return total_transmittance, total_color
```

**Edge Cases and Pitfalls:**
*   **Negative Density:** Gabor kernels can have both positive and negative density values, so they are not valid density functions on their own. This must be handled correctly during integration, as the total density can be negative in local regions, though the overall field should represent physical density [S2].
*   **Cancellation:** When a ray aligns with a kernel's wave direction, the positive and negative lobes cancel out. Failing to mask these kernels leads to unnecessary computation and potential numerical noise [S1].
*   **Precision:** Analytical integration of Gabor kernels requires careful handling of the oscillatory term to avoid precision loss, especially for high-frequency kernels [S1].

## Operating characteristics
*   **Time Complexity:** Rendering time is reduced by ~1.4× compared to Gaussian-based representations at equal variance due to orientation-selective masking and LOD [S1]. With control variates, an additional ~2× speedup is achieved (e.g., Disney Cloud scene: 977 s reference vs. 522 s with Zero NEE) [S1].
*   **Memory Complexity:** No extra storage is required for LOD (no mipmaps or pyramids), maintaining the same memory footprint as the base primitive set [S1, S2].
*   **Strengths:** Continuous LOD without popping or re-fitting; orientation-selective masking; high PSNR (~2 dB higher than Gaussians); efficient procedural generation [S1, S2].
*   **Limitations:** Gabor kernels have negative density values, requiring careful handling; analytical integration is more complex than simple Gaussians [S2].
*   **When to use:** When continuous LOD and orientation-selective filtering are required without the overhead of mipmapping or re-fitting; for procedural cloud generation [S1, S2].
*   **When not to use:** When simple, positive-only density representations are strictly required without post-processing [S2].

## Background
Gabor Fields were introduced by Jorge Condor, Nicolai Hermann, Mehmet Ata Yurtsever, and Piotr Didyk in "Gabor Fields: Orientation-Selective Level-of-Detail for Volume Rendering," published in ACM Transactions on Graphics (SIGGRAPH 2026) [S1, S2]. The method draws inspiration from steerable pyramid decompositions [S2] and aims to address the limitations of Gaussian-based volumes in achieving smooth, efficient LOD [S2].
