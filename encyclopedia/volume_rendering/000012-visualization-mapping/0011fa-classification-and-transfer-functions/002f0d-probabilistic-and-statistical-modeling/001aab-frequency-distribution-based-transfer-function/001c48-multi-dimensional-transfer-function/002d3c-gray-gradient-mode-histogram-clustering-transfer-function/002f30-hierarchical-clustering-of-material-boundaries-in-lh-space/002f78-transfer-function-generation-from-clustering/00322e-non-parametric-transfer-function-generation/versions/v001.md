# Non-Parametric Transfer Function Generation

Also called: Variable Kernel Density Estimation for TF Clustering

## Overview
Non-Parametric Transfer Function Generation is a clustering method for the 2D histogram (conventional or abstracted) using variable kernel density estimation to group data based on neighborhood information [S1, unofficial]. It sets itself apart from fixed-bandwidth density methods by adapting the kernel width to local data density, ensuring accurate estimation in sparse regions without assuming a specific number of clusters [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A set of $N$ samples $\{X_1, X_2, \dots, X_N\}$ in a 2D feature space (e.g., a 2D histogram of volume data values and gradients) [S1, unofficial].
*   **Output:** A probability density estimate $\hat{f}_h(x)$ for any location $x$ in the feature space, which identifies clusters as local maxima or high-density regions [S1, unofficial].

**Data Structures**
*   **Samples:** A list or array of $N$ points, where each point $X_i$ is a 2D vector representing a bin or voxel in the feature space [S1, unofficial].
*   **Parameters:**
    *   $N$: Total number of samples [S1, unofficial].
    *   $k$: Index of the nearest neighbor used to scale the kernel radius [S1, unofficial].

**Steps**
1.  **Calculate Nearest Neighbor Distances:** For each sample $X_i$, compute the distance to its $k$-th nearest neighbor in the set of $N-1$ other data points. Let this distance be $d_{i,k}$ [S1, unofficial].
2.  **Set Kernel Parameter:** Choose $k$ using the rule of thumb $k = \lfloor \sqrt{N} \rfloor$ to approximate optimal density estimation fitting [S1, unofficial].
3.  **Compute Density Estimate:** For a query location $x$, calculate the density estimate $\hat{f}_h(x)$ using the variable kernel method [S1, unofficial]:
    $$ \hat{f}_h(x) = \frac{1}{N} \sum_{i=1}^{N} \frac{1}{d_{i,k}} K\left(\frac{x - X_i}{d_{i,k}}\right) $$
    where:
    *   $d_{i,k}$ is the multi-dimensional smoothing parameter (distance from $X_i$ to its $k$-th nearest neighbor) [S1, unofficial].
    *   $K(u)$ is the kernel function [S1, unofficial].
4.  **Apply Kernel Function:** Use the Epanechnikov kernel to reduce calculation time [S1, unofficial]:
    $$ K(u) = \frac{3}{4}(1 - u^2) \cdot \mathbb{I}(\|u\| \le 1) $$
    where $\mathbb{I}(\|u\| \le 1)$ is 1 if $\|u\| \le 1$ and 0 otherwise [S1, unofficial].

**Pseudocode**
```python
import math
import numpy as np

def compute_variable_kernel_density(samples, k, query_point):
    """
    Compute the probability density estimate at query_point using variable kernel density estimation.
    
    Args:
        samples: List of 2D numpy arrays, shape (N, 2).
        k: Integer, index of the nearest neighbor for bandwidth scaling.
        query_point: 2D numpy array, shape (2,).
        
    Returns:
        float: The density estimate at query_point.
    """
    N = len(samples)
    density = 0.0
    
    # Precompute k-th nearest neighbor distances for all samples
    # Note: In a full implementation, this would be done efficiently (e.g., KD-tree).
    # Here we assume a helper function exists or compute naively for clarity.
    d_ik_list = []
    for i in range(N):
        Xi = samples[i]
        # Calculate distances to all other points
        dists = []
        for j in range(N):
            if i == j:
                continue
            Xj = samples[j]
            dist = np.linalg.norm(Xi - Xj)
            dists.append(dist)
        dists.sort()
        # k-th nearest neighbor distance (0-indexed list, so index k-1)
        # If N-1 < k, handle edge case (not given in sources, assume N is large enough)
        if k <= len(dists):
            d_ik = dists[k-1]
        else:
            d_ik = dists[-1] # Fallback to max distance if k is too large
        d_ik_list.append(d_ik)

    # Compute density sum
    for i in range(N):
        Xi = samples[i]
        d_ik = d_ik_list[i]
        
        # Avoid division by zero
        if d_ik == 0:
            continue
            
        # Calculate scaled vector u
        u = (query_point - Xi) / d_ik
        
        # Epanechnikov kernel
        norm_u = np.linalg.norm(u)
        if norm_u <= 1.0:
            K_u = 0.75 * (1.0 - norm_u**2)
        else:
            K_u = 0.0
            
        density += (1.0 / d_ik) * K_u
        
    density /= N
    return density

def get_k(N):
    """Rule of thumb for k."""
    return math.floor(math.sqrt(N))
```

**Parameters**
*   $k$: Set to $\lfloor \sqrt{N} \rfloor$ as a rule of thumb approximation for optimal density estimation fitting [S1, unofficial].
*   $d_{i,k}$: The multi-dimensional smoothing parameter, defined as the distance from the $i$-th sample $X_i$ to its $k$-th nearest neighbor in the set of $N-1$ data points [S1, unofficial].

**Edge Cases and Pitfalls**
*   **Sparse Regions:** Data points in sparse regions require flatter kernels to maintain density estimation accuracy. This is handled by scaling the kernel width proportional to $d_{i,k}$ [S1, unofficial].
*   **Zero Distance:** If $d_{i,k} = 0$ (e.g., duplicate points), division by zero occurs. The pseudocode includes a guard for this [G].

## Subtopics

## Operating characteristics
*   **Time Complexity:** Computing all $d_{i,k}$ values naively is $O(N^2)$. The density evaluation at a single point is $O(N)$. Using spatial indexing (e.g., KD-tree) can reduce nearest neighbor search to $O(N \log N)$ [G].
*   **Memory Complexity:** $O(N)$ to store samples and distances [G].
*   **Strengths:** Adapts to local data density, providing accurate estimates in both dense and sparse regions without assuming cluster shape or number [S1, unofficial].
*   **Limitations:** Computationally more expensive than fixed-bandwidth methods due to nearest neighbor calculations [S1, unofficial].
*   **When to use:** When the underlying data distribution is unknown or irregular, and accurate density estimation in sparse regions is critical [S1, unofficial].
