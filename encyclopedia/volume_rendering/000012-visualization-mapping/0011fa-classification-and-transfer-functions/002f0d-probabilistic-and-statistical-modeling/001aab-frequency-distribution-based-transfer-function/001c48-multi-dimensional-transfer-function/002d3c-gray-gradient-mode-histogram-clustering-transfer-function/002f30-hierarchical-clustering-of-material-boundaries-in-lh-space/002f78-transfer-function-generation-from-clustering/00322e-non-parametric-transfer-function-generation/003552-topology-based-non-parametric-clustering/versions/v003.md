# Topology-based Non-Parametric Clustering

Also called: Morse complex decomposition, Morse complex-based clustering, Valley Cell-Based Clustering

## Overview
Topology-based Non-Parametric Clustering decomposes a 2D density plot feature space into non-overlapping valley cells separated by valley lines, where each cell contains a local maximum representing a potential volumetric feature [S1]. It differs from discrete histogram-based clustering by operating on continuous density plots, thereby avoiding spurious peaks and valleys while preserving the spatial relationships of neighboring data points [S1]. Unlike frequency binning methods that consider only density magnitude, this method incorporates position in feature space via topological information, preventing disjoint segments for the same density value [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A 2D density plot $f(x, y)$ defined over a feature space where the x-axis represents scalar value and the y-axis represents gradient magnitude [S1].
*   **Output:** A set of non-overlapping valley cells, each associated with a local maximum, and a hierarchical tree representing the merging of these cells based on boundary persistence [S1].

**Data Structures**
1.  **Triangular Mesh:** A tessellation of the 2D feature space domain where the density function is approximated as piecewise linear over the triangles [S1].
2.  **Vertex Classification:** Each vertex $v$ is classified based on its density value relative to its neighbors in its star: maximum (greater than all neighbors), minimum (smaller than all neighbors), or $k$-fold saddle (has $k+1$ wedges in its lower star, where a wedge is a contiguous section of the lower star; regular points have $k=0$) [S1].
3.  **Valley Lines:** Paths connecting saddles to minima or other saddles, representing steepest descent directions [S1].
4.  **Valley Cells:** Regions bounded by valley lines and minima, containing exactly one local maximum [S1].
5.  **Boundary Persistence:** A scalar value associated with each boundary between two adjacent valley cells, defined as the minimal persistence of the saddles forming that boundary [S1].

**Steps**
1.  **Construct Density Function:** Build a continuous density function for the 2D density plot using Kernel Density Estimation (KDE) or continuous scatterplots [S1].
2.  **Tessellate:** Discretize the feature space into a 2D triangular mesh to enforce a piecewise linear approximation of the density function [S1].
3.  **Identify Critical Points:** Identify maxima, minima, and saddles on the mesh vertices [S1].
4.  **Trace Valley Lines:** For every $k$-fold saddle, trace $k+1$ paths of steepest descent [S1]. Each path follows a sequence of steepest descent edges [S1]. Termination conditions are: (a) hitting another saddle, or (b) hitting a previously traced path at a regular point $J$ (junction), which is treated as an artificial saddle to ensure every boundary has at least one saddle [S1].
5.  **Construct Valley Cells:** Use region growing (flood-fill) starting from each maximum [S1]. Recursively grow the region of neighboring triangles, stopping at valley lines or triangles whose vertices are minima [S1].
6.  **Saddle Duplication (Degeneracy Handling):** In degenerate cases, a single saddle may belong to more than two cells (associated with more than two maxima) [S1]. If a saddle $S$ has a connected maximum set of size $k$, duplicate $k-1$ saddles [S1]. The original saddle is replaced by $k$ distinct saddles, each associated with one of the maxima [S1].
7.  **Calculate Persistence:** For each saddle, calculate its persistence $p$ as the smaller difference between the saddle value and its connected maximum value:
    $$p = \min(|v_{saddle} - v_{max}|)$$
    where $v_{saddle}$ is the density value at the saddle and $v_{max}$ is the density value at the connected maximum [S1]. Calculate the **Boundary Persistence** $p_{boundary}$ for each boundary between two adjacent cells as the minimal persistence of its associated saddles:
    $$p_{boundary} = \min(p_{saddles})$$
    [S1].
8.  **Simplify Cells (Hierarchical Merging):** Sort all boundaries by their boundary persistence in ascending order [S1]. Iterate through the sorted boundaries. For each boundary, merge the two adjacent valley cells [S1]. Update the parent-child relationships in the hierarchical tree [S1]. The root of the tree corresponds to the cell with the largest local maximum [S1]. Stop when a persistence threshold is reached [S1].

**Parameters**
*   **Persistence Threshold:** Determines when to stop merging cells. Typically 0.1% - 1.5% of the maximal persistence, with 0.5% used as a default [S1].

**Pitfalls and Edge Cases**
*   **Degenerate Cases:** Piecewise linear discretization can cause multi-fold saddles and intersecting paths [S1]. Paths may terminate at another saddle or a previously traced path at a regular point [S1].
*   **Saddle Belonging to Multiple Cells:** As noted in Step 6, a saddle may be associated with more than two maxima in degenerate cases [S1]. This is resolved by saddle duplication [S1].
*   **Junctions:** When a path hits a regular point $J$ that is the maximum vertex on a path separating regions, $J$ is treated as an artificial saddle [S1].

**Pseudocode**
```python
def topology_based_clustering(density_function, bounds, grid_res):
    """
    Performs topology-based non-parametric clustering on a 2D density plot.
    Args:
        density_function: Callable f(x, y) returning density values.
        bounds: Tuple (x_min, x_max, y_min, y_max).
        grid_res: Tuple (res_x, res_y) for mesh resolution.
    Returns:
        cells: List of valley cells.
        hierarchy: Tree structure representing merged cells.
        threshold: The persistence threshold used.
    """
    # Step 1 & 2: Tessellate and Evaluate Density
    vertices, triangles = _tessellate_grid(bounds, grid_res)
    for v in vertices:
        v.density = density_function(v.x, v.y)

    # Step 3: Identify Critical Points
    maxima, minima, saddles = [], [], []
    for v in vertices:
        lower_neighbors = [u for tri in triangles if v in tri for u in tri if u != v and u.density < v.density]
        if not lower_neighbors:
            v.type = 'MAX'
            maxima.append(v)
        elif len(lower_neighbors) == len([u for tri in triangles if v in tri for u in tri if u != v]):
            v.type = 'MIN'
            minima.append(v)
        else:
            k = _count_connected_lower_wedges(v, lower_neighbors, triangles)
            if k > 0:
                v.type = 'SADDLE'
                v.fold = k
                saddles.append(v)
            else:
                v.type = 'REGULAR'

    # Step 4: Trace Valley Lines
    valley_lines = []
    traced = set()
    for s in saddles:
        for _ in range(s.fold + 1):
            path = [s]
            curr = s
            while True:
                neighbors = [u for tri in triangles if curr in tri for u in tri if u != curr]
                if not neighbors:
                    break
                nxt = min(neighbors, key=lambda n: n.density)
                if nxt.type == 'SADDLE':
                    path.append(nxt)
                    break
                if nxt in traced:
                    nxt.type = 'ARTIFICIAL_SADDLE'
                    path.append(nxt)
                    break
                path.append(nxt)
                curr = nxt
            valley_lines.append(path)
            for node in path:
                traced.add(node)

    # Step 5: Construct Valley Cells via Region Growing
    cells = []
    visited_tris = set()
    for m in maxima:
        cell_tris = []
        queue = [m]
        while queue:
            curr = queue.pop(0)
            for tri in triangles:
                if curr in tri.vertices and tri not in visited_tris:
                    if any(v.type in ('SADDLE', 'ARTIFICIAL_SADDLE') for v in tri.vertices) or \
                       any(v.type == 'MIN' for v in tri.vertices):
                        continue
                    cell_tris.append(tri)
                    visited_tris.add(tri)
                    for v in tri.vertices:
                        if v not in visited_tris:
                            queue.append(v)
        cells.append({'max': m, 'triangles': cell_tris, 'id': len(cells)})

    # Step 6: Saddle Duplication for Degenerate Cases
    # Map each cell boundary to a unique saddle instance
    cell_saddle_map = {c['id']: [] for c in cells}
    for tri in visited_tris:
        saddle_on_tri = [v for v in tri.vertices if v.type in ('SADDLE', 'ARTIFICIAL_SADDLE')]
        if saddle_on_tri:
            adj_cells = [c for c in cells if tri in c['triangles']]
            for s in saddle_on_tri:
                for c in adj_cells:
                    cell_saddle_map[c['id']].append(s)

    # Duplicate saddles if associated with >2 maxima
    saddle_instances = {}
    for c in cells:
        for s in cell_saddle_map[c['id']]:
            if s not in saddle_instances:
                saddle_instances[s] = []
            saddle_instances[s].append(c['id'])

    for s, c_ids in saddle_instances.items():
        if len(c_ids) > 2:
            # Create k-1 duplicates as per topological simplification rules
            for _ in range(len(c_ids) - 1):
                new_s = Vertex(s.x, s.y)
                new_s.type = 'SADDLE'
                new_s.fold = 1
                saddle_instances[s].append(new_s)

    # Step 7: Calculate Persistence
    boundaries = []
    for c in cells:
        for tri in c['triangles']:
            for v in tri.vertices:
                if v.type in ('SADDLE', 'ARTIFICIAL_SADDLE'):
                    adj = [other for other in cells if other is not c and tri in other['triangles']]
                    if adj:
                        p = min(abs(v.density - m.density) for m in [c['max'], adj[0]['max']])
                        boundaries.append({'saddles': [v], 'persistence': p, 'cells': [c['id'], adj[0]['id']]})

    # Deduplicate boundaries and take min persistence per boundary pair
    unique_boundaries = {}
    for b in boundaries:
        key = tuple(sorted(b['cells']))
        if key not in unique_boundaries or b['persistence'] < unique_boundaries[key]['persistence']:
            unique_boundaries[key] = b
    boundaries = list(unique_boundaries.values())

    # Step 8: Simplify and Build Hierarchy
    boundaries.sort(key=lambda b: b['persistence'])
    max_p = max((b['persistence'] for b in boundaries), default=0.0)
    threshold = max_p * 0.005
    hierarchy = {'root': None, 'nodes': {}}

    for b in boundaries:
        if b['persistence'] > threshold:
            break
        c1_id, c2_id = b['cells']
        # Merge adjacent cells and update parent-child relationships
        parent = {'cell_ids': [c1_id, c2_id], 'children': [c1_id, c2_id], 'persistence': b['persistence']}
        hierarchy['nodes'][c1_id] = parent
        hierarchy['nodes'][c2_id] = parent
        if hierarchy['root'] is None or c1_id == hierarchy['root']:
            hierarchy['root'] = c1_id
        # Note: In a full implementation, update maximum sets and boundary persistences of remaining boundaries here [S1]

    return cells, hierarchy, threshold

class Vertex:
    def __init__(self, x, y):
        self.x, self.y = x, y
        self.density = 0.0
        self.type = 'REGULAR'
        self.fold = 0

def _tessellate_grid(bounds, res):
    x_min, x_max, y_min, y_max = bounds
    verts = []
    for i in range(res[0] + 1):
        for j in range(res[1] + 1):
            verts.append(Vertex(x_min + i*(x_max-x_min)/res[0], y_min + j*(y_max-y_min)/res[1]))
    tris = []
    for i in range(res[0]):
        for j in range(res[1]):
            idx = i*(res[1]+1) + j
            tris.append([verts[idx], verts[idx+1], verts[idx+res[1]+1]])
            tris.append([verts[idx+1], verts[idx+res[1]+2], verts[idx+res[1]+1]])
    return verts, tris

def _count_connected_lower_wedges(v, lower_neighbors, triangles):
    if not lower_neighbors:
        return 0
    visited = set()
    wedges = 0
    for start in lower_neighbors:
        if start in visited:
            continue
        wedges += 1
        q = [start]
        while q:
            curr = q.pop(0)
            if curr in visited:
                continue
            visited.add(curr)
            for tri in triangles:
                if curr in tri:
                    for u in tri:
                        if u != curr and u.density < v.density and u not in visited:
                            q.append(u)
    return wedges
```

## Operating characteristics
*   **Time Complexity:** The complexity is dominated by the tessellation, critical point identification, and region growing [S1]. The region growing can be carried out quickly using flood-fill [S1]. The merging process involves sorting boundaries, which is $O(B \log B)$ where $B$ is the number of boundaries [S1].
*   **Memory Complexity:** Requires storage for the triangular mesh, critical points, valley lines, and the hierarchical tree [S1].
*   **Measured Performance:** The method was tested on the "Feet" data set [S1]. The default threshold of 0.5% of maximal persistence was found sufficient to automatically generate meaningful clusters [S1].
*   **Strengths:**
    *   Non-parametric: Does not assume the number or shape of clusters [S1].
    *   Continuous: Avoids spurious peaks and valleys associated with discrete histograms [S1].
    *   Topological: Preserves spatial relationships in feature space [S1].
    *   Hierarchical: Provides a tree structure for multi-scale exploration [S1].
*   **Limitations:**
    *   Degenerate cases in piecewise linear discretization require special handling (saddle duplication) [S1].
    *   Noise in the original data can create a large number of small valley cells, requiring simplification [S1].
*   **When to Use:** Suitable for automatic transfer function design in volume rendering when the user is not familiar with the data and needs an intuitive, non-parametric clustering of the 2D feature space [S1].
*   **When Not to Use:** When the feature space is not 2D (value and gradient magnitude) or when a discrete histogram approach is preferred for simplicity [S1].

## Background
*   **Origin:** Introduced by Yunhai Wang, Jian Zhang, Dirk J. Lehmann, Holger Theisel, and Xuebin Chi in the Eurographics Conference on Visualization 2012 [S1].
*   **History:** The method is based on the theory of Morse complex [Sma61] and is inspired by the Morse complex construction scheme in [EHZ03] [S1]. It differs from hierarchical watershed segmentation by determining separability intrinsically during region growing rather than through flooding and overflow detection [S1]. It addresses limitations of previous methods like [MWCE09] which only considered density value magnitude and ignored position in feature space [S1].
