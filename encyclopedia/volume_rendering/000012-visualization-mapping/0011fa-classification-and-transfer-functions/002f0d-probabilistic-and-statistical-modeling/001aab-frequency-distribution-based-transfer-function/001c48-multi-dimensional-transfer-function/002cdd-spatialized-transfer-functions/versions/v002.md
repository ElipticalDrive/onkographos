# Spatialized Transfer Functions

Also called: Spatialization of transfer functions

## Overview
Spatialized Transfer Functions (STF) is a technique that performs segmentation on the domain of the transfer function (histogram) rather than the volume domain, using spatial information (feature radius) to group scalar values into uniquely colored regions corresponding to materials [S1]. It solves the problem that standard transfer functions cannot separate features with identical statistical properties but different spatial positions [S1]. Unlike explicit segmentation which is time-consuming and not suitable for quick first impressions, STF performs segmentation on the transfer function domain automatically and fast, allowing interactive exploration [S1].

## How it works
STF is a one- or more-dimensional transfer function where spatial information is used to derive the color, whereas statistical (and/or spatial) information is used to setup the opacity [S1]. The method operates on a 2D histogram where the x-axis represents normalized scalar values $s \in [0, 1]$ and the y-axis represents normalized gradient magnitude $t \in [0, 1]$ [S1].

### Inputs and Outputs
**Inputs:**
1.  Volume dataset $V$.
2.  2D Histogram $H(s,t)$, where each entry contains:
    *   $n$: The count of contributing voxels.
    *   $s$: Normalized scalar value.
    *   $t$: Normalized gradient magnitude.
    *   $\{p_i\}_{i=1}^n$: The normalized 3D positions of the $n$ contributing voxels.

**Outputs:**
1.  Transfer Function $F(s,t)$ mapping $(s,t)$ to Color (Emission) and Opacity [S1].

### Data Structures
The histogram entry $H(s,t)$ stores spatial statistics for the voxels mapping to that bin [S1].
*   **Barycenter** $b(s,t)$: The centroid of the spatial positions [S1].
*   **Spatial Variance** $v(s,t)$: The average distance of voxels from the barycenter [S1].

### Preprocessing
For each histogram entry $H(s,t)$ with $n$ contributing voxels, compute the barycenter and spatial variance once per volume [S1].

$$ b(s,t) = \frac{1}{n} \sum_{i=1}^{n} p_i(s,t) $$

$$ v(s,t) = \frac{1}{n} \sum_{i=1}^{n} \| p_i(s,t) - b(s,t) \| $$

where $p_i(s,t)$ are the normalized positions of the voxels [S1].

### Opacity Setup
The opacity is derived from statistical information (gradient magnitude) to blend out low-gradient regions and emphasize boundaries [S1]. For an entry $F(s,t)$:

$$ F_\alpha(s,t) = t^{c_\alpha} $$

where $c_\alpha > 0$ is a constant defining global opacity [S1].

### Classification and Color Assignment
The color is derived from spatial proximity in the histogram [S1]. The goal is to assign the same color to all entries in the transfer function which map to almost the same position in the volume domain [S1].

1.  **Spatial Correspondence Norm**: Define a norm $N(T, T_0)$ to determine if a tuple $T$ belongs to the same feature as a reference tuple $T_0$ [S1]:

    $$ N(T, T_0) = \| b(T) - b(T_0) \| + | v(T_0) - v(T) | $$

    where $T$ and $T_0$ are histogram tuples, $b$ is the barycenter, and $v$ is the spatial variance [S1].

2.  **Initialization**: Start with a reference tuple $T_0$ initially chosen as the one with the highest histogram count [S1].

3.  **Grouping**: Classify all other tuples $T$ into groups where $N(T, T_0) < r$, assuming the variance is sufficiently small relative to the feature radius $r$ [S1]. Note that as variance increases, the relationship between barycenters and real feature location becomes less precise, especially if spatial variance exceeds $r$ [S1].

4.  **Color Assignment**: For each group of classified tuples, assign a unique RGB color triple $C_{RGB}$ with a random hue [S1]. The emission for each entry $T$ in the group is:

    $$ F_\epsilon(T) = C_{RGB} \cdot c_\epsilon $$

    where $c_\epsilon$ is a constant defining global emission [S1].

5.  **Iteration**: Repeat the classification and color assignment for remaining unclassified entries until all histogram entries are classified [S1].

### Interactive Exploration
Users can point and click into the histogram to select a specific class [S1]. The emission of all remaining classes is set to zero to highlight the selected feature [S1].

### Pseudocode

```python
import random

def compute_spatial_statistics(histogram):
    """
    Preprocessing step: Compute barycenter and variance for each histogram bin.
    histogram: List of bin objects, each with:
        - s: float, normalized scalar
        - t: float, normalized gradient
        - n: int, voxel count
        - positions: list of 3D vectors (normalized), length n
    Returns: List of bins with added fields barycenter (vec3) and variance (float).
    """
    for bin in histogram:
        if bin.n == 0:
            bin.barycenter = (0.0, 0.0, 0.0)
            bin.variance = 0.0
            continue
        
        # Compute barycenter
        sum_pos = (0.0, 0.0, 0.0)
        for p in bin.positions:
            sum_pos = (sum_pos[0] + p[0], sum_pos[1] + p[1], sum_pos[2] + p[2])
        bin.barycenter = (sum_pos[0] / bin.n, sum_pos[1] / bin.n, sum_pos[2] / bin.n)
        
        # Compute spatial variance
        sum_dist = 0.0
        for p in bin.positions:
            dx = p[0] - bin.barycenter[0]
            dy = p[1] - bin.barycenter[1]
            dz = p[2] - bin.barycenter[2]
            sum_dist += (dx*dx + dy*dy + dz*dz) ** 0.5
        bin.variance = sum_dist / bin.n

def spatialize_transfer_function(histogram, feature_radius, global_opacity_const, global_emission_const):
    """
    Classifies histogram bins into spatial groups and assigns colors.
    
    Parameters:
    - histogram: List of bin objects with precomputed barycenter and variance.
    - feature_radius (r): Float, max radius of features to detect.
    - global_opacity_const (c_alpha): Float, exponent for opacity.
    - global_emission_const (c_epsilon): Float, multiplier for emission.
    
    Returns:
    - transfer_function: List of tuples (s, t, opacity, color_rgb) for each bin.
    """
    transfer_function = []
    classified_indices = set()
    
    # Sort bins by count to find initial reference tuple with highest count
    indexed_bins = [(i, bin) for i, bin in enumerate(histogram)]
    indexed_bins.sort(key=lambda x: x[1].n, reverse=True)
    
    for i, bin in indexed_bins:
        if i in classified_indices:
            continue
            
        # Start new group with this bin as reference
        current_ref_bin = bin
        group_indices = [i]
        
        # Classify all other unclassified bins against this reference
        for j, other_bin in indexed_bins:
            if j in classified_indices or j == i:
                continue
                
            # Compute spatial correspondence norm
            # N(T, T0) = ||b(T) - b(T0)|| + |v(T0) - v(T)|
            b_diff_x = other_bin.barycenter[0] - current_ref_bin.barycenter[0]
            b_diff_y = other_bin.barycenter[1] - current_ref_bin.barycenter[1]
            b_diff_z = other_bin.barycenter[2] - current_ref_bin.barycenter[2]
            dist_barycenter = (b_diff_x**2 + b_diff_y**2 + b_diff_z**2) ** 0.5
            
            diff_variance = abs(current_ref_bin.variance - other_bin.variance)
            norm = dist_barycenter + diff_variance
            
            if norm < feature_radius:
                group_indices.append(j)
        
        # Assign unique random color to the group
        color = (random.random(), random.random(), random.random())
        
        # Process group members
        for idx in group_indices:
            bin = histogram[idx]
            s = bin.s
            t = bin.t
            
            # Opacity: F_alpha(s,t) = t^c_alpha
            opacity = t ** global_opacity_const
            
            # Emission: F_epsilon(T) = C_RGB * c_epsilon
            emission = (color[0] * global_emission_const, 
                        color[1] * global_emission_const, 
                        color[2] * global_emission_const)
            
            transfer_function.append((s, t, opacity, emission))
            classified_indices.add(idx)
            
    return transfer_function
```

### Parameters
*   **Feature radius $r$**: Controls the spatial extent of feature grouping in the histogram [S1]. It acts as the threshold for the spatial correspondence norm $N(T, T_0)$ [S1]. Typical values are between 0.05 and 0.25 [S1]. Interactive adjustment allows separation of features [S1].
*   **Global opacity $c_\alpha$**: A manual parameter chosen for each dataset to control overall transparency [S1].
*   **Global emission $c_\epsilon$**: A manual parameter chosen for each dataset to control overall brightness/emission [S1].

### Edge Cases and Pitfalls
*   **Noise**: In underrepresented regions where the number of voxels per histogram entry is very low (e.g., below 5-10 voxels), a valid classification cannot be made [S1]. The opacity of these entries should be set to zero [S1]. Super-sampling and k-neighborhood smoothing can reduce noise [S1].
*   **Variance Precision**: With increasing variance $v(T)$, the relationship between the barycenters $b(T)$ and the real location of a feature becomes imprecise, especially if the spatial variance exceeds the feature radius $r$ [S1].
*   **Complex Shapes**: Without STF, the exact shape of classes is almost impossible to setup manually [S1].

## Subtopics

### STF Guided Segmentation
A segmentation method where objects with the same characteristics are selected in the STF, characterized by non-zero opacity, and then segmented by spatial connectivity (region growing) [S1]. It is extremely fast, requiring only one lookup into the 2D opacity map per voxel [S1]. Steps: 1) Select objects in the STF to set their opacity entries to non-zero. 2) Perform region growing on voxels with non-zero opacity to break down objects into individual components based on spatial connectivity. 3) Assign a unique random tag to each detected segment to determine its hue value. 4) Select a segment in the render view by clicking on its hue value [S1].

### Pseudo-Shading
A technique to enhance feature discrimination by simulating a head-light appearance [S1]. It darkens object silhouettes by attenuating emission at low scalar values, making accumulated opacity predominant [S1]. Steps: 1) Determine the scalar range for each class in the transfer function. 2) Attenuate the emission of each class using a linear ramp over its determined scalar range, decreasing emission for the lowest occurring scalar values. 3) For selected classes, attenuate emission linearly to create a shaded appearance [S1].

## Operating characteristics
*   **Time Complexity**: The update time is well below 0.25 seconds on a PC with AMD Athlon 1GHz and NVIDIA GeForceFX 5800 Ultra, including redraw [S1]. This is because only transfer function entries are reclassified, not all voxels [S1].
*   **Memory Complexity**: Requires storing spatial statistics (barycenter and variance) for each histogram entry [S1].
*   **Strengths**: Automatic segmentation on the transfer function domain; fast interactive exploration; does not require explicit time-consuming segmentation of the volume domain [S1].
*   **Limitations**: Classification accuracy degrades if spatial variance exceeds the feature radius [S1]. Not suitable for replacing real brain segmentation but convenient for display [S1]. STF cannot be approximated efficiently by a sum of Gaussians [S1].
*   **When to use**: When features have identical statistical properties but different spatial positions, or when quick interactive exploration of complex multi-material volumes is needed [S1].
*   **When not to use**: When high-precision explicit segmentation is required, or when noise levels are too high to allow valid classification in low-count histogram bins [S1].

## Background
Spatialized Transfer Functions were introduced by S. Roettger, M. Bauer, and M. Stamminger in 2005 [S1]. The method was presented at the Eurographics Symposium on Visualization (EuroVis) [S1]. It addresses the limitations of standard transfer functions in separating features with identical statistical properties but different spatial positions [S1]. The approach was demonstrated on datasets such as the Tooth dataset [PLB*01] and the Bonsai dataset [Roe04] [S1].
