# Statistical Signatures

Also called: Statistical Signatures per Voxel, Tenginakai et al. Statistical Signatures

## Overview
Statistical Signatures is a method for automatic transfer function specification that characterizes each voxel by the statistical properties of its local neighborhood, rather than just its scalar value [S1, unofficial]. It solves the problem of identifying meaningful features, such as edges, by mapping voxels into a space defined by metrics like mean and standard deviation, allowing users to select regions of interest via histograms [S1, unofficial].

## How it works
**Inputs:** A scalar volume dataset $V$. A neighborhood radius $r$ defining the local window for statistical calculation [G].
**Outputs:** A transformed volume where each voxel is associated with a statistical signature vector, and a histogram mapping scalar values to these signatures to identify edge-representing scalar values [S1, unofficial].

**Data Structures:**
1. **Signature Vector:** For each voxel $v$ at position $(x,y,z)$, a vector $S_v$ containing calculated metrics [G].
2. **Histogram:** A multi-dimensional histogram where axes represent the scalar value of the voxel and its statistical signature components [G].

**Steps:**
1. **Neighborhood Definition:** For each voxel $v$ in the volume, define a local neighborhood $N_v$ consisting of voxels within a distance $r$ from $v$ [G].
2. **Metric Calculation:** Calculate the statistical metrics for the scalar values in $N_v$. The primary metrics are the mean ($\mu$) and standard deviation ($\sigma$) [S1, unofficial].
   * Mean: $\mu_v = \frac{1}{|N_v|} \sum_{u \in N_v} V(u)$ [G]
   * Standard Deviation: $\sigma_v = \sqrt{\frac{1}{|N_v|} \sum_{u \in N_v} (V(u) - \mu_v)^2}$ [G]
3. **Signature Assignment:** Assign the vector $S_v = [\mu_v, \sigma_v]$ to voxel $v$ [G].
4. **Histogram Construction:** Create a histogram relating the scalar value $V(v)$ with its signature $S_v$ [S1, unofficial].
5. **Edge Identification:** Analyze the histogram to identify scalar values that correspond to edges [S1, unofficial].

**Pseudocode:**
```python
def compute_statistical_signatures(volume, radius):
    height, width, depth = volume.shape
    signatures = [[[None for _ in range(depth)] for _ in range(width)] for _ in range(height)]
    histogram = {}
    for z in range(depth):
        for y in range(width):
            for x in range(height):
                neighborhood = []
                for dz in range(-radius, radius + 1):
                    for dy in range(-radius, radius + 1):
                        for dx in range(-radius, radius + 1):
                            nx, ny, nz = x + dx, y + dy, z + dz
                            if 0 <= nx < height and 0 <= ny < width and 0 <= nz < depth:
                                neighborhood.append(volume[nx][ny][nz])
                mean_val = sum(neighborhood) / len(neighborhood)
                variance = sum((v - mean_val)**2 for v in neighborhood) / len(neighborhood)
                std_val = variance**0.5
                signatures[x][y][z] = [mean_val, std_val]
                key = (volume[x][y][z], mean_val, std_val)
                histogram[key] = histogram.get(key, 0) + 1
    return signatures, histogram
```
*Note: The exact binning strategy for the histogram is not specified in the sources [G].*

**Parameters:**
* Neighborhood radius $r$: Not given in the sources. [G] Typical values in similar local-statistic methods range from 1 to 3 voxels.
* Metrics: Mean and Standard Deviation are explicitly cited [S1, unofficial].

**Edge Cases:**
* **Boundary Voxels:** Voxels near the volume boundary have incomplete neighborhoods. [G] Standard practice is to clamp the neighborhood to the volume bounds or use a smaller effective radius.

## Subtopics

### Higher-order moment analysis
An extension by Tenginakai and Machiraju that computes higher-order moments, specifically kurtosis and skewness, in small neighborhoods [S2, unofficial]. This provides better delineations of features in histogram space compared to using only mean and standard deviation [S2, unofficial]. It is chosen when finer feature separation is required in the statistical space, particularly for complex textures or subtle transitions that first/second-order moments cannot distinguish [G].

## Operating characteristics
**Time Complexity:** Not given in the sources. [G] Calculating mean and variance is linear in the neighborhood size.
**Memory Complexity:** Not given in the sources. [G] Storing signatures requires $O(N)$ space, plus $O(H)$ for the histogram.
**Strengths:** Automatic identification of edges and features; the method is described as quite efficient and requires only the interpretation of simple graphs [S1, unofficial].
**Limitations:** Not given in the sources. [G]
**When to use:** When automatic feature detection is needed and the user can interpret statistical histograms [S1, unofficial].
**When not to use:** Not given in the sources. [G]

## Background
The method was proposed by Tenginakai et al. in 2001 [S1, unofficial]. Source [S2, unofficial] describes it as an extension that added higher-order metrics to prior work. It builds on earlier work by Pekkarinen [S1, unofficial] and Fujishiro et al. [S1, unofficial], which focused on isosurface characteristics, by shifting the focus to voxel-level statistical neighborhoods [S1, unofficial]. The approach is cited in overviews of volume rendering as a key technique for feature-sensitive transfer functions [S2, unofficial].
