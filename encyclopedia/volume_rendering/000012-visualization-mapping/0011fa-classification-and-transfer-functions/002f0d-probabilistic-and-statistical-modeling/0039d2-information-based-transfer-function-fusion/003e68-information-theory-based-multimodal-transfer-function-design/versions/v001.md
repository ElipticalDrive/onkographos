# Information Theory-Based Multimodal Transfer Function Design

Also called: Bramon et al. approach, IT-based TF design, IT-based multimodal TF design, Multimodal TF optimization

## Overview
An automated method for designing multimodal transfer functions for two registered volume datasets $X$ and $Y$, using mutual information decomposition to guide color fusion and opacity optimization [S1]. It solves the problem of combining complementary information from different modalities (e.g., CT and MR) into a single coherent visualization where both inputs are represented at each voxel, rather than discarding one [S1]. It sets itself apart from manual methods by automating the design and from single-modality optimization methods by defining an information channel between two input data sets and another between viewpoints and bins [S1].

## How it works
**Inputs:** Two registered volume datasets $X$ and $Y$ (intensity values), pre-defined 1D transfer functions $TF_X$ and $TF_Y$ (colors and opacities), and a target distribution definition.
**Outputs:** A fused multimodal transfer function defining a single color $c(x,y)$ and opacity $\alpha(x,y,g)$ for every voxel based on its intensity pair $(x,y)$ and fused gradient $g$.

**Data Structures:**
1.  **Intensity Bins:** The continuous intensity values of $X$ and $Y$ are discretized into bins $\mathcal{X}$ and $\mathcal{Y}$ using a non-regular binning algorithm (see Binning). The joint space is $\mathcal{B} = \mathcal{X} \times \mathcal{Y}$.
2.  **Information Maps:** Two 3D volumes per dataset, storing values $I_2(x;Y)$ and $I_3(x;Y)$ for each voxel, shifted so the minimum is 0.
3.  **Joint Histogram:** A 3D histogram (or binned equivalent) counting occurrences of intensity pairs $(x,y)$ and potentially gradient values $g$.
4.  **Visibility Distribution:** A probability distribution $p(b|v)$ or $p(b)$ over bins $\mathcal{B}$ for specific viewpoints or all viewpoints.

**Steps:**

1.  **Reference Selection:** Select the reference dataset (e.g., $X$) based on contrast. Compute the mean local variance of intensities in a small window for each dataset (using segmented volumes for normalization if available). The dataset with the lower mean local variance (higher contrast) is chosen as the reference [S1].

2.  **Gradient Computation:** Compute gradient magnitudes $g_X(i,j,k)$ and $g_Y(i,j,k)$ for both datasets using 4D linear regression (Neumann et al.) to avoid the inaccuracies of standard finite differences [S1].

3.  **Information Map Generation:**
    *   Compute the input distribution $p(X)$, conditional probability matrix $p(Y|X)$, and output distribution $p(Y)$ from the voxel intensities of the registered datasets [S1].
    *   Calculate Predictability $I_2(x;Y)$ and Entanglement $I_3(x;Y)$ for each bin $x \in \mathcal{X}$:
        $$ I_2(x;Y) = -\sum_{y \in \mathcal{Y}} p(y) \log p(y) + \sum_{y \in \mathcal{Y}} p(y|x) \log p(y|x) $$
        $$ I_3(x;Y) = \sum_{y \in \mathcal{Y}} p(y|x) I_2(y;X) $$
    *   Shift the values of $I_2$ and $I_3$ maps so that their minimum value is 0 to avoid negative weights [S1].

4.  **Binning (One-Sided Clustering):**
    *   Apply agglomerative information bottleneck clustering to reduce the number of bins in the reference dataset $X$ to a target count (default 32) [S1].
    *   The clustering merges bins of $X$ by minimizing the loss of mutual information with $Y$. The "control" dataset $Y$ determines the relevant structures in $X$ [S1].
    *   Re-bin $Y$ and the gradient values accordingly to maintain the joint structure [S1].

5.  **Color Fusion:**
    *   For each voxel with intensities $x$ (from $X$) and $y$ (from $Y$), compute the fused color $c(x,y)$.
    *   Using the hue-preserving operator $\oplus$ in HSL space (recommended for natural hue transitions):
        $$ c(x,y) = \frac{I_2(x;Y)c_X(x) \oplus I_3(x;Y)c_Y(y)}{I_2(x;Y) + I_3(x;Y)} $$
    *   Where $c_X(x)$ and $c_Y(y)$ are the colors from the initial 1D transfer functions [S1].

6.  **Gradient Fusion:**
    *   Compute the fused gradient magnitude $g(i,j,k)$ using the information maps as weights:
        $$ g(i,j,k) = \frac{I_2(x;Y)g_X(i,j,k) + I_3(x;Y)g_Y(i,j,k)}{I_2(x;Y) + I_3(x;Y)} $$
    *   The fused gradient direction is computed similarly [S1].

7.  **Opacity Optimization:**
    *   **Initialization:** Initialize the multimodal transfer function opacity $\alpha_0(x,y,g)$ as a weighted average of the input opacities $\alpha_X(x)$ and $\alpha_Y(y)$ using $I_2$ and $I_3$ as weights [S1].
    *   **Target Distribution:** Define the target distribution $q(b)$ based on user preference. Options include:
        *   *Occurrence:* $q(b) = \frac{occur(b)}{\sum_{i \in \mathcal{B}} occur(i)}$
        *   *Gradient-weighted:* $q(b) = \frac{grad(b) occur(b)}{\sum_{i \in \mathcal{B}} (grad(i) occur(i))}$
        *   *Importance-weighted:* $q(b) = \frac{\text{imp}(b) grad(b) occur(b)}{\sum_{i \in \mathcal{B}} (\text{imp}(i) grad(i) occur(i))}$
    *   **Visibility Estimation:** Compute the visibility distribution $p(b|v)$ for a set of viewpoints (default 6 uniformly distributed viewpoints around the volume) using the current transfer function [S1].
    *   **Divergence Calculation:** Compute the divergence between visibility and target.
        *   *Global Informational Divergence (GID):* $D_{KL}(p(B), q(B)) = \sum_{b \in \mathcal{B}} p(b) \log \frac{p(b)}{q(b)}$, where $p(b) = \sum_{v \in V} p(v)p(b|v)$ [S1].
        *   *Viewpoint Informational Divergence (VID):* $D_{KL}(p(B|v), q(B)) = \sum_{b \in \mathcal{B}} p(b|v) \log \frac{p(b|v)}{q(b)}$. This is view-dependent and recomputed per viewpoint [S1].
    *   **Update:** Update the transfer function opacities using steepest gradient descent on the divergence gradient [S1].
    *   **Convergence:** Repeat until divergence is below a threshold (default 0.001) or max iterations reached (typically < 50) [S1].

    # X and Y are registered volumes with intensity bins
    # Compute joint histogram to get p(X), p(Y), p(Y|X)

    p_Y = compute_histogram(Y)
    p_Y_given_X = compute_conditional_histogram(X, Y)
    
    # Compute Entropy H(Y)

    I2_map = zeros_like(X)
    I3_map = zeros_like(X)

        # Predictability I2(x;Y)

        # Need to compute I2(y;X) for all y first (symmetric process)

        I3_val = sum(p_Y_given_X[y|x] * I2_map_for_Y[y] for y in Y_bins)

    denominator = I2 + I3
    if denominator == 0:

    return numerator / denominator

## Operating characteristics
*   **Time Complexity:** The binning step is greedy hierarchical clustering. The opacity optimization involves iterative ray casting for visibility estimation. Performance depends heavily on the number of bins and viewpoints.
*   **Memory Complexity:** Requires storing joint histograms, information maps, and gradient volumes. Binning reduces the joint histogram size significantly.
*   **Measured Performance:** On an Intel Core 2 Quad Q9550 CPU, 4GB RAM, NVIDIA GeForce GTX 280 GPU:
    *   CT-MR (32x32x1): 44.67s (26 iters, d<0.01), 48.97s (28 iters, d<0.001) [S1].
    *   CT-MR (32x32x8): 110.53s (30 iters, d<0.01), 173.49s (47 iters, d<0.001) [S1].
    *   CT-PET (64x64x1): 134.79s (34 iters, d<0.01), 458.45s (101 iters, d<0.001) [S1].
    *   Prostatix (32x32x8): 88.13s (36 iters, d<0.01), 128.96s (53 iters, d<0.001) [S1].
    *   DECT (6 viewpoints): 96.61s (29 iters, d<0.01), 158.60s (48 iters, d<0.001) [S1].
    *   DECT (20 viewpoints): 316.29s (31 iters, d<0.01), 507.32s (50 iters, d<0.001) [S1].
*   **Scaling:** Using 6 viewpoints is a good trade-off between quality and speed; the difference between 6 and 20 viewpoints is minimal [S1].
*   **Strengths:** Automates TF design; handles multimodal data effectively; preserves structures from both modalities; binning improves accuracy and reduces computational load.
*   **Limitations:** New fused colors may be difficult for physicians to interpret; asymmetric fusion requires careful reference selection (though impact is small if contrast is similar); requires registered data [S1].
*   **When to use:** When automatic fusion of two registered modalities is needed and manual TF design is too complex or time-consuming.
*   **When not to use:** When interpretability of specific colors is critical and cannot be mitigated by side-by-side visualization; when data is not registered.

## Background
Originated from Bramon et al. [S1], building on information theory concepts introduced in neural systems (Butts [31], Ruiz et al. [4]). It extends the work of Ruiz et al. [4] which handled single-modality opacity optimization, by defining an information channel between two input data sets. The binning algorithm is based on the agglomerative information bottleneck method by Bardera et al. [33].
