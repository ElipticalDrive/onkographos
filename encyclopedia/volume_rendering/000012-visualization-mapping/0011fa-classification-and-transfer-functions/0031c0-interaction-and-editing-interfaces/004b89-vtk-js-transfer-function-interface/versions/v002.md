# VTK.js Transfer Function Interface

Also called: Interactive Transfer Function Editing via Histogram Overlay, control point TF editing, histogram-based TF editor

## Overview
The VTK.js Transfer Function Interface is a JavaScript-based user interface component that allows users to interactively define and edit volume rendering transfer functions (TFs) by manipulating control points on a histogram overlay [S1, unofficial][S2, unofficial]. It solves the problem of mapping scalar volume data to optical properties (opacity and color) by providing a visual editor that generates a 1D texture sent to the GPU for rendering [S1, unofficial][S2, unofficial]. It differs from [2D Transfer Function Widget](5735-2d-transfer-function-widget.md) by specifically integrating with the VTK.js rendering pipeline and using a histogram-based layout for data-aware editing, and from [Sketch-based Transfer Function Editing](5943-sketch-based-transfer-function-editing.md) by relying on explicit control point manipulation rather than freehand drawing.

## How it works
**Inputs and Outputs:**
*   **Input:** A scalar volume dataset (accessed via VTK.js `vtkVolume` actor), the data range `[min, max]`, and optional initial control point configurations.
*   **Output:** A 1D RGBA texture (180x1 pixels) uploaded to the GPU, and an updated VTK.js volume property reflecting the new transfer function.

**Data Structures:**
The interface maintains two arrays of control points, sorted by scalar value:
1.  **Opacity Control Points:** `opaCtrlPoint` is an array of `[scalarValue, opacity]` tuples. `scalarValue` is in `[min, max]`, `opacity` is in `[0, 1]`.
2.  **Color Control Points:** `colorCtrlPoint` is an array of `[scalarValue, R, G, B]` tuples. `scalarValue` is in `[min, max]`, RGB values are in `[0, 1]`.

**Parameters:**
*   `bins`: Number of histogram bins. Typically 200 [S1, unofficial].
*   `numControlPoints`: Default number of initial control points. Typically 5 [S1, unofficial].
*   `_opacityViewPercentage`: Height ratio of the opacity view area relative to total height. Range `[0, 1]`. Typical value 0.8 [S2, unofficial].
*   `_initNumColorCtrlPoint`: Number of initial color control points. If -1, `_initColorCtrlPoint` is treated as a d3 color map function [S2, unofficial].
*   `_minMax`: Array `[min, max]` of the scalar data range [S2, unofficial].

**Step-by-Step Method:**

1.  **Initialize Histogram:**
    *   Determine bin count based on data type: 200 bins for '8bit' (256 levels), 200 bins for '16bit' (65536 levels), or 200 bins for 'float' (1 level) [S1, unofficial].
    *   Compute the histogram `hist` from the volume data.
    *   Compute the log-scale histogram for display: `histLog[i] = log(hist[i] + 1)` for all bins `i` [S1, unofficial].

2.  **Initialize Control Points:**
    *   **Opacity:** If `_initOpaCtrolPoint` is null, initialize with `[[min, 0], [max, 1]]` [S2, unofficial]. Otherwise, use the provided array.
    *   **Color:** If `_initNumColorCtrlPoint` is -1, use `_initColorCtrlPoint` as a d3 interpolation function to generate colors. Otherwise, generate `_initNumColorCtrlPoint` points.
        *   Calculate `step = 1 / (_initNumColorCtrlPoint - 1)`.
        *   For `i` from 0 to `_initNumColorCtrlPoint - 1`:
            *   `colorMapValue = i * step`.
            *   Get RGB string from `_initColorCtrlPoint(colorMapValue)`.
            *   Parse RGB components and normalize to `[0, 1]` by dividing by 255.0.
            *   Map `colorMapValue` to data range: `dataValue = colorMapValue * (max - min) + min`.
            *   Push `[dataValue, R, G, B]` to `colorCtrlPoint` [S2, unofficial].

3.  **Render UI (SVG/Two.js):**
    *   **Histogram:** Draw the log-scale histogram using anchors. Calculate `xStep = (width - borders) / bins` and `yStep = height / max(histLog)`. Place anchors at `border.left + i * xStep` and `height - histLog[i] * yStep` [S1, unofficial].
    *   **Transfer Function Polygon:** Sort control points by x-coordinate. Create a path starting at the bottom of the first point, passing through all control points, and ending at the bottom of the last point.
    *   **Gradient:** Generate a linear gradient for the polygon. For each control point `i`, calculate normalized position `p = (x_i - x_0) / polyWidth`. Create a gradient stop at `p` with the point's color and opacity 0.75 [S1, unofficial].

4.  **User Interaction (Adding/Editing Points):**
    *   **Add Opacity Point:** On click, get mouse position `(mousePosX, mousePosY)`. Invert scales: `newDataValue = xScale.invert(mousePosX)`, `newOpacity = yScale.invert(mousePosY) / opacityFactor`. Find insertion index `idx` where `opaCtrlPoint[idx][0] > newDataValue`. Insert `[newDataValue, newOpacity]` at `idx` [S2, unofficial].
    *   **Add Color Point:** On click, get `mousePosX`. Invert: `newDataValue = xScale.invert(mousePosX)`. Find `idx`. Get neighbors `prev = colorCtrlPoint[idx-1]`, `next = colorCtrlPoint[idx]`.
        *   **Pitfall:** If `prev[0] == next[0]`, division by zero occurs in interpolation factor calculation [S2, unofficial].
        *   Calculate interpolation factor `a = (newDataValue - prev[0]) / (next[0] - prev[0])`.
        *   Interpolate RGB: `newColor = [(1-a)*prev[1] + a*next[1], (1-a)*prev[2] + a*next[2], (1-a)*prev[3] + a*next[3]]`.
        *   Insert `[newDataValue, ...newColor]` at `idx` [S2, unofficial].
    *   **Drag/Delete:** Dragging moves points (clamped to bounds). Right-click opens color picker. Delete key + click removes point [S1, unofficial].

5.  **Generate and Upload Texture:**
    *   Iterate `i` from 0.5 to 180 with step `div.offsetWidth / 180`.
    *   For each `i`, calculate `alpha = getAlpha(i * step, opaCtrlPoint, height)` and `color = getColor(i * step, colorCtrlPoint)`.
    *   Concatenate RGB and Alpha into a `Uint8Array` (scaled by 255).
    *   Send to GPU using `gl.texSubImage2D` on `gl.TEXTURE1` with dimensions 180x1, format `RGBA`, type `UNSIGNED_BYTE` [S1, unofficial].

**Pseudocode:**

```python
class VTKjsTransferFunctionInterface:
    def __init__(self, parent_element_id, vis_width, vis_height, opacity_view_percentage, 
                 update_render_func, get_volume_actor_property_func, min_max, 
                 init_opa_ctrl_point=None, init_num_color_ctrl_point=5, 
                 init_color_ctrl_point=None):
        self.parent_element_id = parent_element_id
        self.vis_width = vis_width
        self.vis_height = vis_height
        self.opacity_view_percentage = opacity_view_percentage
        self.update_render_func = update_render_func
        self.get_volume_actor_property_func = get_volume_actor_property_func
        self.min_max = min_max
        self.bins = 200
        self.opacity_factor = 1.0
        
        # Initialize Opacity Control Points
        if init_opa_ctrl_point is None:
            self.opa_ctrl_point = [[min_max[0], 0.0], [min_max[1], 1.0]]
        else:
            self.opa_ctrl_point = init_opa_ctrl_point
            
        # Initialize Color Control Points
        self.color_ctrl_point = []
        if init_num_color_ctrl_point == -1:
            # Use d3 color map function
            step = 1.0 / (5 - 1) # Default fallback if not specified, but logic implies using init_num_color_ctrl_point if not -1
            # Assuming default 5 points if not specified when -1 is used as flag for function
            num_points = 5 
        else:
            num_points = init_num_color_ctrl_point
            
        step = 1.0 / (num_points - 1)
        for i in range(num_points):
            color_map_value = i * step
            # Get RGB from d3 function or default
            rgb_str = init_color_ctrl_point(color_map_value) if callable(init_color_ctrl_point) else "rgb(255,255,255)"
            r, g, b = parse_rgb(rgb_str)
            r, g, b = r/255.0, g/255.0, b/255.0
            data_value = color_map_value * (min_max[1] - min_max[0]) + min_max[0]
            self.color_ctrl_point.append([data_value, r, g, b])

    def init_histogram(self, volume_data):
        # Bin data into histogram
        hist = [0] * self.bins
        for val in volume_data:
            idx = int((val - self.min_max[0]) / (self.min_max[1] - self.min_max[0]) * self.bins)
            if 0 <= idx < self.bins:
                hist[idx] += 1
        
        # Log scale for display
        self.hist_log = [math.log(x + 1) for x in hist]
        return self.hist_log

    def add_opacity_point(self, mouse_pos_x, mouse_pos_y):
        # Invert scales
        new_data_value = self.x_scale.invert(mouse_pos_x)
        new_opacity = self.y_scale.invert(mouse_pos_y) / self.opacity_factor
        
        # Find insertion index
        idx = -1
        for i, pt in enumerate(self.opa_ctrl_point):
            if pt[0] > new_data_value:
                idx = i
                break
        if idx == -1:
            idx = len(self.opa_ctrl_point)
            
        self.opa_ctrl_point.insert(idx, [new_data_value, new_opacity])
        self.update_tf_interface()

    def add_color_point(self, mouse_pos_x):
        new_data_value = self.x_scale.invert(mouse_pos_x)
        idx = -1
        for i, pt in enumerate(self.color_ctrl_point):
            if pt[0] > new_data_value:
                idx = i
                break
        if idx == -1:
            idx = len(self.color_ctrl_point)
            
        # Handle boundary cases
        if idx == 0:
            prev = self.color_ctrl_point[0]
            next_pt = self.color_ctrl_point[1] if len(self.color_ctrl_point) > 1 else prev
        elif idx == len(self.color_ctrl_point):
            prev = self.color_ctrl_point[-1]
            next_pt = self.color_ctrl_point[-1]
        else:
            prev = self.color_ctrl_point[idx-1]
            next_pt = self.color_ctrl_point[idx]
            
        # Pitfall: Division by zero if prev[0] == next[0]
        if next_pt[0] == prev[0]:
            a = 0.0
        else:
            a = (new_data_value - prev[0]) / (next_pt[0] - prev[0])
            
        new_r = (1 - a) * prev[1] + a * next_pt[1]
        new_g = (1 - a) * prev[2] + a * next_pt[2]
        new_b = (1 - a) * prev[3] + a * next_pt[3]
        
        self.color_ctrl_point.insert(idx, [new_data_value, new_r, new_g, new_b])
        self.update_tf_interface()

    def update_tf_interface(self):
        # Sort points
        self.opa_ctrl_point.sort(key=lambda x: x[0])
        self.color_ctrl_point.sort(key=lambda x: x[0])
        
        # Generate Texture
        texture_data = Uint8Array(180 * 4)
        step = 180.0 / self.div_offset_width
        
        for i in range(180):
            val = (i + 0.5) * step
            alpha = self.get_alpha(val, self.opa_ctrl_point, self.div_offset_height)
            color = self.get_color(val, self.color_ctrl_point)
            
            idx = i * 4
            texture_data[idx] = int(color[0] * 255)
            texture_data[idx+1] = int(color[1] * 255)
            texture_data[idx+2] = int(color[2] * 255)
            texture_data[idx+3] = int(alpha * 255)
            
        # Upload to GPU
        gl.texSubImage2D(gl.TEXTURE1, 0, 0, 0, 180, 1, gl.RGBA, gl.UNSIGNED_BYTE, texture_data)
        
        # Update VTK.js Volume
        volume_property = self.get_volume_actor_property_func()
        volume_property.set_transfer_function_1d(self.create_vtk_color_opacity_function(texture_data))
        
        # Trigger Render
        self.update_render_func()

    def get_alpha(self, val, ctrl_points, height):
        # Linear interpolation between control points
        if not ctrl_points: return 0.0
        if val <= ctrl_points[0][0]: return ctrl_points[0][1]
        if val >= ctrl_points[-1][0]: return ctrl_points[-1][1]
        
        for i in range(len(ctrl_points) - 1):
            if ctrl_points[i][0] <= val <= ctrl_points[i+1][0]:
                t = (val - ctrl_points[i][0]) / (ctrl_points[i+1][0] - ctrl_points[i][0])
                return ctrl_points[i][1] + t * (ctrl_points[i+1][1] - ctrl_points[i][1])
        return 0.0

    def get_color(self, val, ctrl_points):
        # Linear interpolation between control points
        if not ctrl_points: return [0, 0, 0]
        if val <= ctrl_points[0][0]: return ctrl_points[0][1:]
        if val >= ctrl_points[-1][0]: return ctrl_points[-1][1:]
        
        for i in range(len(ctrl_points) - 1):
            if ctrl_points[i][0] <= val <= ctrl_points[i+1][0]:
                t = (val - ctrl_points[i][0]) / (ctrl_points[i+1][0] - ctrl_points[i][0])
                r = ctrl_points[i][1] + t * (ctrl_points[i+1][1] - ctrl_points[i][1])
                g = ctrl_points[i][2] + t * (ctrl_points[i+1][2] - ctrl_points[i][2])
                b = ctrl_points[i][3] + t * (ctrl_points[i+1][3] - ctrl_points[i][3])
                return [r, g, b]
        return [0, 0, 0]
```

## Operating characteristics
*   **Time Complexity:** Histogram computation is $O(N)$ where $N$ is the number of voxels. Texture generation is $O(1)$ (fixed 180 steps). Interaction updates are $O(M)$ where $M$ is the number of control points.
*   **Memory Complexity:** $O(B)$ for histogram bins ($B=200$) and $O(M)$ for control points. The GPU texture is fixed at 180x1 RGBA.
*   **Strengths:** Intuitive visual feedback via histogram overlay; direct integration with VTK.js; lightweight client-side implementation.
*   **Limitations:** Relies on JavaScript performance for large datasets; histogram binning may lose precision for very large 16-bit or float data if not handled carefully; prone to edge cases in interpolation (division by zero, index errors) if not guarded [S2, unofficial].
*   **When to use:** When developing web-based volume visualization using VTK.js and requiring interactive TF editing.
*   **When not to use:** For high-performance desktop applications where GPU-based TF editors are preferred; for automated classification tasks.

## Background
The VTK.js Transfer Function Interface was developed as part of the VTK.js ecosystem to provide a web-native solution for volume rendering classification. It was implemented in the repository `caseywang777/VTKjsVolumeRendering` [S2, unofficial] and documented in `johanna-b/VisWeb` [S1, unofficial]. It leverages D3.js for SVG manipulation and Two.js for vector graphics, integrating with WebGL via VTK.js's rendering pipeline.
