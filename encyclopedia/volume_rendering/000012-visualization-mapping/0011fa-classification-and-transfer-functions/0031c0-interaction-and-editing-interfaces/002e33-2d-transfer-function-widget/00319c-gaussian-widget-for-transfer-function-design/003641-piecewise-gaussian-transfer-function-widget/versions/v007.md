# Piecewise Gaussian Transfer Function Widget

Also called: Gaussian Widget, vtkPiecewiseGaussianWidget

## Overview
The Piecewise Gaussian Transfer Function Widget is an interactive user interface component that allows users to define and modify volume rendering transfer functions by placing Gaussian curves over a data histogram [S2, S3, S5, unofficial]. It solves the problem of manually specifying color and opacity mappings by providing a visual, direct-manipulation interface where Gaussian parameters control the contribution of scalar values to the final image [S2, S3, unofficial]. It builds on [Gaussian Widget for Transfer Function Design](6568-gaussian-widget-for-transfer-function-design.md) by implementing the specific UI mechanics for 2D texture-based transfer function editing, distinguishing itself from static parameter tuning by enabling real-time visual feedback and dynamic texture updates [S2, S3, S4, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A scalar data array (volume data) and a histogram representation of that data [S8, unofficial].
*   **Output:** A 2D texture representing the transfer function (TF), which maps scalar values to RGBA color and opacity values [S1, unofficial]. This texture is uploaded to the GPU for raycasting or raymarching [S1, unofficial].

**Data Structures:**
*   **Transfer Function Texture:** A 2D texture (e.g., WebGL `gl.TEXTURE_2D`) where the x-axis represents the scalar value and the y-axis represents opacity or color intensity [S1, unofficial]. The configuration object stores the TF as an array of arrays containing RGBA floats [S1, unofficial].
*   **Gaussian Curve:** Defined by parameters $(x, y, \sigma_x, \sigma_y, \alpha)$, where:
    *   $x$: Horizontal position (scalar value).
    *   $y$: Vertical height (opacity/color intensity).
    *   $\sigma_x$: Width of the Gaussian in the scalar domain.
    *   $\sigma_y$: Height spread in the opacity/color domain.
    *   $\alpha$: Opacity spread parameter [S2, unofficial].
*   **Configuration Object:** Contains settings such as `update_tf` (a boolean flag to trigger texture updates) [S1, unofficial]. Widget instantiation parameters include `numberOfBins` (histogram resolution) and `size` (widget dimensions) [S2, S3, S4, unofficial].

**Numbered Steps:**
1.  **Initialization:** Instantiate the widget with `numberOfBins` (typically 256) and `size` (e.g., [400, 150] pixels) [S3, S4, S5, unofficial].
2.  **Data Binding:** Bind the scalar data array to the widget to generate the underlying histogram [S4, S5, unofficial].
3.  **Style Application:** Apply visual styles including background, histogram colors, stroke, active states, handle colors, and padding [S3, S4, unofficial].
4.  **Gaussian Addition:** Add Gaussian curves to the widget using `addGaussian(x, y, sigmaX, sigmaY, alpha)` [S2, S3, S5, unofficial].
5.  **Function Application:** Apply the resulting opacity transfer function to a `piecewiseFunction` object and the color transfer function to a `lookupTable` object [S3, S5, unofficial].
6.  **Listener Binding:** Bind mouse listeners and modification events. On opacity change, apply the opacity to the piecewise function and trigger a render window update [S2, S3, unofficial].
7.  **Texture Update:** If `config.update_tf` is true, call `downloadTransferFunctionTexture` to generate the 2D texture from the current Gaussian configuration and upload it to the GPU [S1, unofficial].

**Pseudocode:**
```python
import math

class PiecewiseGaussianWidget:
    def __init__(self, numberOfBins=256, size=(400, 150)):
        self.numberOfBins = numberOfBins
        self.size = size
        self.gaussians = []
        self.histogram = [0.0] * numberOfBins
        self.dataRange = (0.0, 1.0)
        self.piecewiseFunction = None
        self.lookupTable = None
        self.renderWindow = None
        self.config = {'update_tf': True}

    def setDataArray(self, dataArray):
        """Bind scalar data to generate histogram."""
        if not dataArray:
            return
        minVal = min(dataArray)
        maxVal = max(dataArray)
        self.dataRange = (minVal, maxVal)
        self.histogram = [0.0] * self.numberOfBins
        for value in dataArray:
            binIndex = int(((value - minVal) / (maxVal - minVal)) * self.numberOfBins)
            if binIndex >= self.numberOfBins:
                binIndex = self.numberOfBins - 1
            if binIndex < 0:
                binIndex = 0
            self.histogram[binIndex] += 1.0

    def addGaussian(self, x, y, sigmaX, sigmaY, alpha):
        """Add a Gaussian curve to the widget."""
        self.gaussians.append({'x': x, 'y': y, 'sigmaX': sigmaX, 'sigmaY': sigmaY, 'alpha': alpha})

    def applyOpacity(self, piecewiseFunction):
        """Apply the current Gaussian configuration to the piecewise opacity function."""
        piecewiseFunction.clear()
        for i in range(self.numberOfBins):
            scalarValue = i / self.numberOfBins
            opacity = 0.0
            for g in self.gaussians:
                dx = (scalarValue - g['x']) / g['sigmaX']
                contribution = g['y'] * math.exp(-0.5 * dx * dx)
                opacity += contribution
            piecewiseFunction.addPoint(scalarValue, min(opacity, 1.0))

    def setColorTransferFunction(self, lookupTable):
        """Apply the current Gaussian configuration to the color lookup table."""
        lookupTable.clear()
        for i in range(self.numberOfBins):
            scalarValue = i / self.numberOfBins
            r, g, b = 0.0, 0.0, 0.0
            for gaus in self.gaussians:
                dx = (scalarValue - gaus['x']) / gaus['sigmaX']
                weight = gaus['y'] * math.exp(-0.5 * dx * dx)
                r += weight * 1.0
                g += weight * 0.8
                b += weight * 0.6
            lookupTable.addPoint(scalarValue, min(r, 1.0), min(g, 1.0), min(b, 1.0))

    def downloadTransferFunctionTexture(self, config):
        """Generate the 2D transfer function texture data."""
        if not config['update_tf']:
            return None
        textureData = self.generateTextureData()
        config['update_tf'] = False
        return textureData

    def generateTextureData(self):
        """Generate 2D texture data from Gaussians."""
        data = []
        # Note: Exact 2D texture layout mapping is marked as TODO in sources [S1, unofficial]
        for v in range(self.numberOfBins):
            for u in range(self.numberOfBins):
                scalarValue = u / self.numberOfBins
                opacityValue = v / self.numberOfBins
                combined = 0.0
                for g in self.gaussians:
                    dx = (scalarValue - g['x']) / g['sigmaX']
                    dy = (opacityValue - g['y']) / g['sigmaY']
                    contribution = g['y'] * math.exp(-0.5 * (dx*dx + dy*dy))
                    combined += contribution
                data.extend([combined, combined, combined, min(combined, 1.0)])
        return data

    def render(self):
        """Trigger a scene render."""
        if self.renderWindow:
            self.renderWindow.render()

    def onOpacityChange(self, callback):
        """Bind opacity change event."""
        self.opacityChangeCallback = callback
```

**Parameters:**
*   `numberOfBins`: Histogram resolution. Typical value: 256 [S2, S3, S4, S5, unofficial].
*   `size`: Widget dimensions in pixels. Typical value: [400, 150] [S3, S4, unofficial].
*   `addGaussian` parameters:
    *   `x`: Position (scalar value).
    *   `y`: Height (opacity/color intensity).
    *   `sigmaX`: Width.
    *   `sigmaY`: Height spread.
    *   `alpha`: Opacity spread [S2, unofficial].

**Edge Cases and Pitfalls:**
*   **2D Texture Layout:** The sources indicate the use of 2D textures for transfer functions instead of 1D, but the exact layout or interpolation requirement is not specified and marked as a TODO [S1, unofficial].
*   **Precision:** Floating-point precision in texture generation and GPU sampling may affect the smoothness of Gaussian curves [G].
*   **Boundary Conditions:** Ensure Gaussian curves are clamped to the valid data range [0, 1] or the data's min/max range to avoid artifacts [G].

## Subtopics

### [Programmable Transfer Function GUI Interaction](8214-programmable-transfer-function-gui-interaction.md)
An interactive UI widget for editing volume rendering transfer functions using draggable control points organized per color channel (R, G, B, A). It allows users to dynamically modify variables in Programmable Transfer Functions (PTFs), such as isovalue, shading color, volume step size, silhouette terms, and specular highlight coefficients, without recomputing and storing new transfer function textures. Unlike traditional methods that require recomputing and storing new transfer function textures, this approach enables real-time tuning of rendering parameters via a simple widget interface.

### [Interactive Transfer Function Editing](11521-interactive-transfer-function-editing.md)
Interactive Transfer Function (TF) Editing provides a graphical user interface for defining, modifying, and managing the color and opacity mappings used in volume rendering. It solves the problem of manually specifying which data values are visible and how they are colored, allowing users to iteratively refine visualizations through direct manipulation. Unlike static parameter tuning, this method integrates real-time feedback, history management, and structural context (such as cut-away views) into the editing workflow. It distinguishes itself from basic widget-based editing by offering persistent state management (history trees) and structural classification integration (focus+context).

### Opacity Widgets
The opacity function is composed of opacity widgets, which can be modified in linear and Iso-Dist modes as needed [S6, unofficial]. Three types of opacity widgets are available: pyramid, Gaussian, and control point based [S6, unofficial].

### Interactive Transfer Function and Gamma Control
Real-time updates are achieved via pixel shaders, making changes to transfer functions and gamma values immediately visible [S7, unofficial]. For single scalar variable data sets, change color mapping and scalar-to-opacity mapping using two dials and a button on the icon wall [S7, unofficial]. For multi-value data sets, use gamma dials on the icon wall to interactively change each color component's intensity [S7, unofficial].

### Histogram-Based Piecewise Widget Data Preparation
Computes a normalized histogram of scalar values to drive a Gaussian piecewise widget, enabling visual editing of transfer functions based on data distribution [S8, unofficial]. Steps: 1. Initialize histogram array: `histogram = new Float32Array(widget1.getNumberOfBins());` 2. Iterate over all data values and increment bin count based on normalized value: `bin = Math.floor(((value - dataRange[0]) / (dataRange[1] - dataRange[0])) * widget1.getNumberOfBins());` 3. Assign to widget: `widget1.setDataArray(histogram);` [S8, unofficial]. Widget bins: 256 [S8, unofficial].

## Background
The Piecewise Gaussian Transfer Function Widget originates from interactive volume rendering systems, particularly those using VTK (Visualization Toolkit) and WebGL-based frameworks [S2, S3, S4, S5, unofficial]. It is implemented in various academic and open-source projects, such as the CS247-KAUST Bonus Assignment and several volume rendering web applications [S1, S2, S3, S4, unofficial]. The specific implementation as a 2D texture-based widget with interactive controls is a development in the field of interactive visualization interfaces [S1, S2, unofficial].
