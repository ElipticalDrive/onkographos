# CNN-feature based viewpoint selection
Also called: weighted probability voting for viewpoint selection

## Overview
This method suggests the optimal viewpoint for features of interest in a given input volume and transfer function by considering the similarity between input features and features in a collected image set [S1]. It sets itself apart from image-based viewpoint selection models [38] by separating viewpoint estimation and similarity calculation into distinct stages solved by Convolutional Neural Networks (CNNs), rather than applying a single similarity measure to mix these stages [S1].

## How it works
**Inputs:**
*   Input volume $V$.
*   Transfer function $T$.
*   Pre-trained category classification network (AlexNet-based) [S1].
*   Pre-trained viewpoint estimation network [S1].
*   Collected image set $C = \{I_1, I_2, \dots, I_n\}$ for the determined category, where $n = |C|$ is the number of collected images [S1].

**Outputs:**
*   Optimal viewpoint parameters (camera position, orientation, tilt, background) [S1].

**Data Structures:**
*   Feature vectors $f(\cdot) \in \mathbb{R}^{4096}$ extracted from the last hidden layer of the category classification network [S1].
*   Rendered image set $S = \{R_1, R_2, \dots, R_k\}$ with $k=40$ [S1].

**Steps:**

1.  **Category Determination:**
    Render several images randomly from the input volume $V$ using the provided transfer function $T$. Classify these rendered images through the category classification network. The most voted category among these images is considered the category of the volume [S1].

2.  **Retrieve Collected Images:**
    Obtain the collected image set $C = \{I_1, I_2, \dots, I_n\}$ corresponding to the determined category [S1].

3.  **Estimate Viewpoints for Collected Images:**
    For each collected image $I_i \in C$, estimate its viewpoint $v_i$ using the viewpoint estimation network [S1].

4.  **Generate Rendered Image Set:**
    Render the input volume $V$ with the provided transfer function $T$ under the estimated viewpoint $v_i$ for each $I_i$. This rendering considers different camera-tilt angles and background colors to generate a rendered image set $S = \{R_1, R_2, \dots, R_k\}$ with $k=40$ images [S1].

5.  **Calculate Similarity:**
    Calculate the similarity $w_i$ between the collected image $I_i$ and the input volume (with transfer function) using the cosine distance of features from the last hidden layer of the category classification network. The feature vectors $f(R_j)$ and $f(I_i)$ are in $\mathbb{R}^{4096}$. The similarity is defined as:
    $$ w_i = \max_{R_j \in S} (\cos(f(R_j), f(I_i))) $$
    where $\cos(a, b)$ denotes the cosine similarity between vectors $a$ and $b$ [S1].

6.  **Compute Weighted Probability:**
    Design an exponential similarity weight $w_i'$ by weighting the probability by its similarity with the input volume and transfer function:
    $$ w_i' = \exp\left((w_i - 0.5) \cdot \frac{|C|}{10}\right) $$
    where $|C|$ is the number of images in the collected image set [S1].

7.  **Generate Voting Distribution:**
    Sum up all weighted probability distributions (viewpoint probability distributions of $I_i$ weighted by $w_i'$) to generate the voting probability distribution [S1].

8.  **Select Optimal Viewpoint:**
    Select the viewpoint with the largest probability from the summed distribution as the optimal viewpoint [S1].

**Pseudocode:**

```python
def cnn_feature_viewpoint_selection(volume, transfer_function, category_net, viewpoint_net, collected_images_C):
    """
    volume: Input volume data
    transfer_function: Transfer function T
    category_net: Pre-trained AlexNet-based category classification network
    viewpoint_net: Pre-trained viewpoint estimation network
    collected_images_C: List of collected images I_i for the determined category
    
    Returns: Optimal viewpoint parameters
    """
    
    # Step 1: Determine category
    # Render several random images from volume using transfer_function
    random_rendered_images = render_random_images(volume, transfer_function, count=5) # Count arbitrary, source says "several"
    
    # Classify these images
    category_votes = []
    for img in random_rendered_images:
        pred = category_net.predict(img)
        category_votes.append(pred)
        
    # Most voted category is the volume's category
    volume_category = get_most_voted_category(category_votes)
    
    # Step 2: Retrieve collected images C (already provided as input for this category)
    # C = collected_images_C
    
    # Step 3 & 4: For each collected image, estimate viewpoint and render variations
    rendered_sets_S = [] # List of sets S_i for each I_i
    estimated_viewpoints_v = []
    
    for I_i in collected_images_C:
        # Estimate viewpoint v_i
        v_i = viewpoint_net.estimate_viewpoint(I_i)
        estimated_viewpoints_v.append(v_i)
        
        # Render volume under v_i with different tilt angles and background colors
        # k=40 images
        S_i = render_variations(volume, transfer_function, v_i, num_images=40)
        rendered_sets_S.append(S_i)
        
    # Step 5: Calculate similarity w_i for each collected image
    similarities_w = []
    for idx, I_i in enumerate(collected_images_C):
        S_i = rendered_sets_S[idx]
        
        # Get feature vector for collected image
        f_Ii = category_net.extract_features(I_i) # From last hidden layer, R^4096
        
        max_cos_sim = -1.0
        for R_j in S_i:
            f_Rj = category_net.extract_features(R_j) # From last hidden layer, R^4096
            cos_sim = cosine_similarity(f_Rj, f_Ii)
            if cos_sim > max_cos_sim:
                max_cos_sim = cos_sim
                
        w_i = max_cos_sim
        similarities_w.append(w_i)
        
    # Step 6: Compute weighted probability w_i'
    n = len(collected_images_C)
    weighted_probs_w_prime = []
    for w_i in similarities_w:
        w_i_prime = math.exp((w_i - 0.5) * (n / 10.0))
        weighted_probs_w_prime.append(w_i_prime)
        
    # Step 7: Generate voting distribution
    # Assume each collected image I_i has an associated viewpoint probability distribution P(v | I_i)
    # This distribution is derived from the viewpoint estimation network or stored data
    # Sum up weighted distributions
    voting_distribution = {}
    
    for idx, I_i in enumerate(collected_images_C):
        # Get viewpoint probability distribution for I_i
        # This might be a histogram or set of probabilities over possible viewpoints
        # The source implies "viewpoint probability distribution of I_i" exists
        prob_dist_Ii = get_viewpoint_probability_distribution(I_i) 
        
        w_i_prime = weighted_probs_w_prime[idx]
        
        # Weight the distribution
        weighted_dist = {}
        for viewpoint, prob in prob_dist_Ii.items():
            weighted_viewpoint = viewpoint # Viewpoint identity
            weighted_prob = prob * w_i_prime
            if weighted_viewpoint not in voting_distribution:
                voting_distribution[weighted_viewpoint] = 0.0
            voting_distribution[weighted_viewpoint] += weighted_prob
            
    # Step 8: Select optimal viewpoint
    optimal_viewpoint = max(voting_distribution, key=voting_distribution.get)
    
    return optimal_viewpoint

def cosine_similarity(a, b):
    dot_product = sum(x * y for x, y in zip(a, b))
    norm_a = math.sqrt(sum(x * x for x in a))
    norm_b = math.sqrt(sum(x * x for x in b))
    if norm_a == 0 or norm_b == 0:
        return 0.0
    return dot_product / (norm_a * norm_b)
```

**Parameters:**
*   $k$: Number of rendered images in set $S$, set to 40 [S1].
*   Feature dimension: The features $f(R_j)$ and $f(I_i)$ are vectors in $\mathbb{R}^{4096}$ [S1].

**Edge Cases and Pitfalls:**
*   The method relies on the availability of a pre-trained category classification network and viewpoint estimation network [S1].
*   The collected image set $C$ must be representative of the determined category [S1].
*   The exponential weighting formula $w_i' = \exp((w_i - 0.5) \cdot |C| / 10)$ assumes $w_i$ is in a range where this transformation is meaningful (cosine similarity is typically in $[-1, 1]$) [S1].

## Operating characteristics
*   **Time Complexity:** The method involves multiple CNN inferences (category classification, viewpoint estimation, feature extraction) and rendering operations. The complexity is dominated by the number of collected images $|C|$ and the number of rendered variations $k=40$ per image.
*   **Memory Complexity:** Requires storing the collected image set $C$, the rendered image sets $S$, and the feature vectors.
*   **Strengths:** Separates viewpoint estimation and similarity calculation, allowing for more accurate similarity measurement based on CNN features [S1]. Considers the specific input volume and transfer function, unlike viewpoint preference analysis which suggests the same viewpoint for different features [S1].
*   **Limitations:** Requires pre-trained CNNs and a collected image set. Computationally expensive due to multiple renderings and CNN inferences [S1].
*   **When to use:** When an optimal viewpoint for specific features of interest in a volume is needed, and computational resources allow for CNN-based processing and multiple renderings [S1].
*   **When not to use:** When real-time performance is critical and pre-computation is not feasible, or when no collected image set is available [S1].
