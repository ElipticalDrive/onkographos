# Data Feature-Based Classification

Also called: Multi-Dimensional Transfer Function (MDTF) design, Feature-based classification

## Overview
Data Feature-Based Classification extends the classification domain from scalar intensity to multi-dimensional feature vectors $\mathbf{f}(\mathbf{x})$, allowing optical properties to be determined by derived attributes such as gradients, curvature, color, or topological structures [S1, unofficial][S2][S3]. It solves the ambiguity of scalar-based transfer functions where different materials share similar intensity values but differ in structural or contextual properties [S1, unofficial]. Unlike sibling methods that focus on specific geometric primitives (e.g., [Curvature-based Transfer Function](5452-curvature-based-transfer-function.md)) or global shape skeletons ([Shape-based Transfer Function Generation](5941-shape-based-transfer-function-generation.md)), this family encompasses a broad spectrum of feature extraction techniques, including high-dimensional color analysis ([High-Dimensional Classification with Color Data](6327-high-dimensional-classification-with-color-data.md)) and automated material graph deduction ([Robust Material Graph Deduction](7459-robust-material-graph-deduction.md)).

## Shared principles
All methods in this family evaluate a classification function $C(\mathbf{x})$ for each sample point $\mathbf{x}$ in the volume to produce optical properties [G].

**Input Domain:**
The input to the classification function is a feature vector $\mathbf{f}(\mathbf{x})$ associated with position $\mathbf{x}$. While basic methods use scalar intensity $v = f(\mathbf{x})$, this family extends the domain to include derived features such as gradient magnitude $\|\nabla f(\mathbf{x})\|$, curvature, shape descriptors, color components, or topological graph attributes [S1, unofficial][S2][S3].

**Output Range:**
The output is a set of optical properties, most commonly:
*   **Opacity ($\alpha$):** A value in $[0, 1]$ representing the probability of absorption or the inverse of transparency. $\alpha=0$ is fully transparent; $\alpha=1$ is fully opaque .
*   **Color ($C$):** A vector $(r, g, b)$ representing the emitted or reflected light color [S2].
*   **Weight:** In some emission-only models, a weight $w$ is assigned to modulate the contribution of samples during accumulation .

**Classification Types:**
1.  **Binary Classification:** Uses hard thresholds to include or exclude data [6229-binary-and-soft-classification.md]. Values below a threshold are assigned $\alpha=0$, and values above are assigned $\alpha=1$ (or a constant high value) [G].
2.  **Soft Classification:** Uses smooth transitions (e.g., piecewise linear ramps, Gaussian bumps, or power functions) to assign intermediate opacity values [S3].

**Evaluation Order:**
The timing of classification relative to sampling interpolation defines two main approaches [S2]:
*   **Pre-classification:** The transfer function is applied to scalar values at the grid points (voxels) before sampling. Colors and opacities are interpolated during ray casting. Pre-classification produces blurred images when the image resolution is higher than the volume resolution, but prevents color bleeding if color interpolation is done with opacity-weighted colors [S2].
*   **Post-classification:** Scalar values are interpolated from the volume texture during ray casting, and the transfer function is applied to these continuous sample values. Post-classification produces images with defined edges but is prone to aliasing because high-frequency details may be missed [S2].

**Implementation Structures:**
Transfer functions are commonly implemented as piecewise linear functions defined by user-specified keypoints [S3], lookup tables (LUTs) stored as 1D, 2D, or 3D textures for fast GPU sampling [S3], or shader functions evaluated dynamically during ray casting .

## Subtopics

### [Curvature-based Transfer Function](5452-curvature-based-transfer-function.md)
Maps scalar data values and local surface curvature to optical properties to highlight structural contours, ridges, and valleys. It distinguishes itself by utilizing second-order derivative information to differentiate features of similar intensity but different geometric shapes.

### [Shape-based Transfer Function Generation](5941-shape-based-transfer-function-generation.md)
Assigns optical properties based on 3D shape descriptors derived from curve-skeletons, solving the problem of distinguishing features with overlapping intensity ranges (e.g., vessels vs. bones). It assigns uniform descriptors to entire volumetric segments rather than individual voxels.

### [High-Dimensional Classification with Color Data](6327-high-dimensional-classification-with-color-data.md)
Classifies color volume data using a high-dimensional classification function that utilizes RGB values, neighbor colors, and spatial position, avoiding the difficulty of specifying 3D transfer functions for RGB data. It allows users to work directly with original RGB data rather than derived spaces like ICA.

### [Robust Material Graph Deduction](7459-robust-material-graph-deduction.md)
Automatically constructs transfer functions by discovering the topological structure of materials, producing a graph where nodes represent materials and edges represent interfaces. It explicitly models adjacency relationships to enable automatic background removal and depth-based opacity control.

### [Feature Graph](8595-feature-graph.md)
A hierarchical data structure (DAG) representing classified voxel models to visualize complex semantic hierarchies where voxels belong to multiple non-exclusive classes simultaneously. It enables focus+context rendering through multiresolution support.

### [Attribute Ranking Heuristic](11691-attribute-ranking-heuristic.md)
A greedy method for selecting relevant volumetric attributes to construct voxel signatures for multidimensional transfer function classification, ranking candidates based on information content and redundancy. It uses entropy for initial selection, differing from its child which balances entropy against redundancy.

### [Machine Learning and Feature Extraction](12097-machine-learning-and-feature-extraction.md)
Applies machine learning algorithms (e.g., SVMs, Neural Networks) and feature extraction techniques to determine optical properties automatically or semi-automatically. It differs from static heuristic functions by using learned decision boundaries.

### [Similarity-based Classification](12242-similarity-based-classification.md)
Determines optical properties by measuring the distance or correlation between a sample point's feature vector and reference exemplars. It maps high-dimensional feature spaces to classification labels rather than relying on global intensity-based transfer functions.

### [Local Histogram-based Classification Probability](14137-local-histogram-based-classification-probability.md)
Separates overlapping tissues by using local histogram range weights as a second attribute alongside intensity. It computes a signed classification certainty $P$ derived from the narrowness of local intensity distributions, enabling separation of materials indistinguishable by scalar value alone.

### [Critical Point Classification](14338-critical-point-classification.md)
Identifies and categorizes stationary points (where the gradient vanishes) in a scalar field to define optical properties. It focuses on topological singularities (maxima, minima, saddles) rather than local curvature magnitude or shape descriptors.

### Domain Knowledge Attributes for Classification
Attributes that capture domain knowledge to complement gradient-based measures. The paper specifically employs 'range weight' and 'local variance' as examples of these attributes to enable additional visualization possibilities [S1, unofficial].

### Feature Visualization
Calculate 3-dimensional PCA components using teacher's feature map of first frame of training view images. Visualize features by components as RGB, normalized with min-max values with outlier removal [S2].

### Color-based Feature Detectors
Feature detectors that exploit color separation in RGB image data to highlight specific tissues by computing normalized ratios of individual color channels [S3].
*   $c_R = R / (R + G + B)$
*   $c_G = G / (R + G + B)$
*   $c_B = B / (R + G + B)$
*   $c_{BR} = 0.5 * c_R + 1.0 * c_G$ (brown feature detector) [S3].

## Background
The concept of using attributes beyond intensity to guide classification was formalized in the context of Multi-Dimensional Transfer Function (MDTF) design. The approach of employing sorted histograms to dynamically define attributes and classification criteria was introduced by [S1, unofficial]. The use of color-based feature detectors for high-resolution cryo-imaging data was demonstrated in [S3]. The application of feature field distillation and PCA for visualizing learned features in neural networks was explored in [S2].
