# Data Feature-Based Classification
## Overview
Data feature-based classification extends the classification domain beyond raw scalar values to include derived features such as gradient magnitude, curvature, texture metrics, or spatial distance [S1, S2, S3]. This resolves the ambiguity of 1D transfer functions where distinct materials share similar intensity values but possess different structural or textural characteristics [S1]. It is distinguished from sibling methods like [Style Transfer Function (1D)](777-style-transfer-function-1d.md) by explicitly incorporating higher-dimensional feature spaces to drive classification decisions [S1, S2, S3].

## Shared principles
Data feature-based classification constructs a feature vector $\mathbf{f}_i$ for each voxel $i$ by combining the raw data value $V_i$ with one or more derived descriptors [S1, S2, S3]. Common descriptors include gradient magnitude, curvature (second derivative), texture metrics, distance to a segmented region, and spatial position [S1, S2, S3]. The classification function $C(\mathbf{f}_i)$ maps this high-dimensional input to optical properties, typically opacity $\alpha \in [0, 1]$ and color $\mathbf{c}$ [S1, S2, S3]. The general pipeline consists of feature extraction, classification (using heuristics, machine learning models like SVMs or neural networks, or clustering), and transfer function application [S1, S2, S3]. The choice of features determines discriminative power: texture metrics separate materials with similar intensities but different microstructures [S1], distance metrics isolate structures relative to landmarks [S1], and shape descriptors classify geometric forms [S1].

## Subtopics

### [Texture-based Transfer Function](5450-texture-based-transfer-function.md)
A transfer function that uses data value and 20 texture metrics as input. It is typically automatic or semi-automatic. It is chosen when materials have similar intensity values but distinct textural patterns (e.g., distinguishing tissue types in medical imaging or geological strata). It differs from scalar-based methods by incorporating local statistical variations.

### [Distance-based Transfer Function](5451-distance-based-transfer-function.md)
A transfer function that uses data value and distance to a previously segmented structure as metrics. It is chosen when the goal is to isolate a specific object or region relative to a known reference point. It differs from other methods by explicitly using spatial proximity as a discriminative feature, allowing for the selection of structures based on their location relative to a seed or boundary.

### [Shape-based Transfer Function Generation](5941-shape-based-transfer-function-generation.md)
Shape classification assigns to each skeleton region a degree of membership in supported shape classes. Only voxels in the pre-segmentation are considered; background voxels are ignored (descriptor set to all zero). Classes are computed independently. It is chosen when the geometric shape of a structure is a primary identifier (e.g., distinguishing between tubular and spherical organs). It differs from intensity-based methods by focusing on global or local geometric properties rather than raw values.

### [High-Dimensional Classification with Color Data](6327-high-dimensional-classification-with-color-data.md)
A method for classifying color volume data by assigning opacity based on a classification function that uses RGB values, neighbor colors, and position, avoiding the difficulty of specifying 3D transfer functions for RGB data. It is chosen when color and spatial context are more discriminative than intensity alone. It differs from scalar-based methods by operating directly in RGB space with neighborhood awareness.

### Curvature-based Transfer Function
**Definition**
A transfer function that uses data value and curvature (second derivative) to distinguish transitions in tissue [S1]. It maps data and curvature to color and opacity, often in combination with camera position [S1]. It is used to display contours around features, ridge/valley visualization, or emphasize bumpiness [S1].

**Step**
Computation of curvature requires at least a 26-point neighborhood [S1].

**Parameter**
Metrics: Data value and curvature [S1].

**Layout**
Data structure: 2D look-up table [S1].

**Pitfall**
Many features share the same curvature, making it difficult to emphasize a targeted feature without unintended emphasis [S1]. Noise amplifies this behavior [S1].

**Number**
Real-time capability: Yes, with a minimum of 27 3D texture lookups per sample [S1].

**Usage**
Real-time GPU variants are found in GPU Gems 2 [PF05] and [HSS∗05] for iso-surfaces [S1].

### Classifier Reuse
**Definition**
Saving a trained neural network or SVM configuration to apply it to new data sets with similar characteristics, reducing classification time [S2].

**Step**
Apply the saved classifier to the new data set [S2]. If misclassification occurs, the user can refine it by supplying additional training data [S2].

**Parameter**
Saved classifier size: under 30 kilobytes [S2].

**Pitfall**
Position information is specific to a given data set; using it reduces reusability because location changes between scans [S2]. It should be excluded if reusability is intended [S2]. Reused classifiers may misclassify materials if the new data set does not share similar characteristics (e.g., data value ranges or material locations) [S2].

### Cosine Similarity Map Computation
**Definition**
Computes a similarity volume $S_L$ by comparing annotated feature vectors against the full feature volume F using cosine similarity, enabling interactive feedback [S3].

**Formula**
$$S_L^C = \max_{a \in A_C} \frac{1}{|F|} \sum_{i \in F} \frac{F_a \cdot F_i}{\|F_a\|_2 \|F_i\|_2}$$
where $A_C$ is the set of annotations for class C, $F_a$ is the feature vector at annotation $a$, and $F_i$ is the feature vector at voxel $i$ [S3]. Resulting $S_L^C \in [0, 1]^{W' \times H' \times D'}$ [S3].
$$P(x) = \max_{a \in A_C} e^{-10\tilde{p}|x-a|}$$
where $x$ is the location in $\mathbb{R}^3$ and $a$ is an annotation location [S3].

**Parameter**
Proximity parameter $\tilde{p} \in [0, 1]$, used to scale similarity based on distance to annotations [S3].

**Number**
Computation time: A few milliseconds on CPU or GPU [S3].

### DINO Features for SVM/RF Classification
**Number**
SVM IoU on CT-ORG dataset with DINO features: 0.24 (liver), 0.36 (bones), 0.0 (other classes), mean 0.09 [S3]. Fit time: 407s. Inference time: 2077s [S3].

## Background
Data feature-based classification emerged to overcome the limitations of 1D transfer functions [S1]. Early extensions introduced gradient-based metrics [Lev88, KKH02], followed by curvature [KWTM03], texture [CR08], and distance-based methods [TPD06] [S1]. The survey by [S1] compares these types across real-time capability, memory, and automaticity. Later work by Tzeng et al. [S2] introduced high-dimensional classification using machine learning (SVMs, neural networks) on feature vectors including intensity and spatial position, noting that position should be excluded for classifier reusability [S2]. Recent approaches leverage self-supervised vision transformers (DINO) to extract semantic features for interactive transfer function design [S3].
