# Attribute Selection Heuristic for Multidimensional Transfer Functions

Also called: Heuristic for generation of ranking of candidate attributes, Zhou, Schott and Hansen heuristic (adapted)

## Overview
This method provides a greedy heuristic to rank volumetric attributes for inclusion in voxel signatures, thereby reducing the complexity of specifying multidimensional transfer functions (MTFs) [S1, unofficial]. It extends the original Zhou, Schott, and Hansen (2012) pairwise selection by generating a full ranking of candidate attributes using multiple correlation with all previously selected attributes, rather than just the initial one [S1, unofficial]. It builds on [Attribute Ranking Heuristic](11691-attribute-ranking-heuristic.md) by refining the scoring mechanism to explicitly balance information content (entropy) against redundancy (correlation) for sequential attribute selection [S1, unofficial].

## How it works
**Inputs:**
- $A$: A set of $N$ candidate volumetric attributes [S1, unofficial].
- $\eta$: The decision factor (weighting parameter), where $0 \leq \eta \leq 1$ [S1, unofficial].

**Outputs:**
- $R$: A ranked list of attributes, ordered by relevance for voxel signature composition [S1, unofficial].

**Data Structures:**
- $Y_i$: The $i$-th attribute in the candidate set $A$ [S1, unofficial].
- $Y_{prev}$: The set of attributes already selected for the signature (initially empty) [S1, unofficial].
- $E(Y)$: The entropy of attribute $Y$ [S1, unofficial].
- $Corr(Y_{prev}, Y)$: The multiple correlation coefficient between the set of previously selected attributes $Y_{prev}$ and the candidate attribute $Y$ [S1, unofficial].

**Formulas:**

1.  **Shannon Entropy:**
    For a discrete attribute $x$ with $n$ histogram classes, the entropy $E(x)$ is calculated as [S1, unofficial]:
    $$
    E(x) = -\sum_{k=1}^{n} p(x_k) \log_b p(x_k)
    $$
    where $p(x_k)$ is the probability of the $k$-th class occurring, $n$ is the number of histogram classes, and $b$ is the logarithm base (typically $b=2$ for Shannon Entropy) [S1, unofficial].

2.  **Normalized Entropy:**
    The entropy of each attribute is normalized by the maximum entropy observed in the dataset to allow comparison across attributes with different value ranges [S1, unofficial]:
    $$
    \hat{E}(Y_i) = \frac{E(Y_i)}{\max_{Y \in A} E(Y)}
    $$

3.  **Scoring Function:**
    The score $s_i$ for a candidate attribute $Y_i$ is computed as [S1, unofficial]:
    $$
    s_i = -\eta |Corr(Y_{prev}, Y_i)| + (1 - \eta) \hat{E}(Y_i)
    $$
    where:
    - $\eta$ is the decision factor.
    - $|Corr(Y_{prev}, Y_i)|$ is the absolute value of the multiple correlation coefficient.
    - $\hat{E}(Y_i)$ is the normalized entropy.

    **Interpretation:**
    - A score closer to 0 indicates high relevance (low correlation with existing attributes, high entropy) [S1, unofficial].
    - A value of $\eta$ close to 0 favors low correlation (minimizing redundancy) [S1, unofficial].
    - A value of $\eta$ close to 1 favors high entropy (maximizing information content) [S1, unofficial].

**Algorithm Steps:**
1.  Initialize the ranked list $R$ as empty [S1, unofficial].
2.  Calculate the entropy $E(Y)$ for all attributes $Y \in A$ [S1, unofficial].
3.  Determine $E_{max} = \max_{Y \in A} E(Y)$ [S1, unofficial].
4.  Normalize the entropy for all attributes: $\hat{E}(Y) = E(Y) / E_{max}$ [S1, unofficial].
5.  **First Selection:**
    - Select the attribute $Y_{first}$ with the highest normalized entropy $\hat{E}(Y)$ from $A$ [S1, unofficial].
    - Add $Y_{first}$ to $R$ [S1, unofficial].
    - Remove $Y_{first}$ from $A$ [S1, unofficial].
    - Set $Y_{prev} = \{Y_{first}\}$ [S1, unofficial].
6.  **Iterative Selection:**
    - While $A$ is not empty:
        a. For each remaining attribute $Y_i \in A$, calculate the multiple correlation coefficient $Corr(Y_{prev}, Y_i)$ [S1, unofficial].
        b. Compute the score $s_i = -\eta |Corr(Y_{prev}, Y_i)| + (1 - \eta) \hat{E}(Y_i)$ [S1, unofficial].
        c. Select the attribute $Y_{best}$ with the maximum score $s_i$ [S1, unofficial].
        d. Add $Y_{best}$ to $R$ [S1, unofficial].
        e. Remove $Y_{best}$ from $A$ [S1, unofficial].
        f. Update $Y_{prev} = Y_{prev} \cup \{Y_{best}\}$ [S1, unofficial].
7.  Return $R$ [S1, unofficial].

**Pseudocode:**
```python
import math

def attribute_selection_heuristic(attributes, eta):
    """
    attributes: List of attribute objects. Each object must provide:
                - get_histogram(): returns list of bin counts (int/float)
                - get_values(): returns list of voxel-wise values (float)
    eta: Decision factor in [0, 1].
    Returns: Ranked list of attributes.
    """
    # Step 1: Calculate and normalize entropy
    entropies = {}
    for attr in attributes:
        hist = attr.get_histogram()
        total = sum(hist)
        if total == 0:
            entropies[attr] = 0.0
            continue
        entropy = 0.0
        for count in hist:
            if count > 0:
                p = count / total
                entropy -= p * math.log2(p)
        entropies[attr] = entropy

    max_entropy = max(entropies.values()) if entropies else 0.0
    if max_entropy == 0:
        normalized_entropies = {attr: 0.0 for attr in attributes}
    else:
        normalized_entropies = {attr: e / max_entropy for attr, e in entropies.items()}

    ranked = []
    remaining = list(attributes)
    selected = []

    # Step 2: Select first attribute (highest entropy)
    first_attr = max(remaining, key=lambda x: normalized_entropies[x])
    ranked.append(first_attr)
    remaining.remove(first_attr)
    selected.append(first_attr)

    # Step 3: Iteratively select remaining attributes
    while remaining:
        best_attr = None
        max_score = float('-inf')

        for attr in remaining:
            # Compute multiple correlation coefficient R between selected attributes and candidate
            corr_value = compute_multiple_correlation(selected, attr)
            
            # Score: maximize to prefer high entropy and low correlation
            score = -eta * abs(corr_value) + (1 - eta) * normalized_entropies[attr]
            
            if score > max_score:
                max_score = score
                best_attr = attr
        
        ranked.append(best_attr)
        remaining.remove(best_attr)
        selected.append(best_attr)

    return ranked

def compute_multiple_correlation(selected_attributes, candidate_attribute):
    """
    Computes the multiple correlation coefficient R between the candidate
    and the set of selected attributes using linear regression [G].
    """
    n = len(selected_attributes)
    if n == 0:
        return 0.0

    # Extract voxel-wise data arrays
    X = [attr.get_values() for attr in selected_attributes]
    y = candidate_attribute.get_values()
    m = len(y)

    # Center data
    X_centered = [[x[i] - sum(x)/m for i in range(m)] for x in X]
    y_centered = [y[i] - sum(y)/m for i in range(m)]

    # Compute correlation matrix R_xx and correlation vector r_yx
    def std(v):
        return math.sqrt(sum(v_i**2 for v_i in v) / m)

    def corr(a, b):
        sa, sb = std(a), std(b)
        if sa == 0 or sb == 0: return 0.0
        return sum(a[i]*b[i] for i in range(m)) / (m * sa * sb)

    R_xx = [[corr(X[i], X[j]) for j in range(n)] for i in range(n)]
    r_yx = [corr(y, X[i]) for i in range(n)]

    # Invert R_xx (Gaussian elimination)
    R_xx_inv = invert_matrix(R_xx)

    # R^2 = r_yx^T * R_xx_inv * r_yx
    temp = [sum(R_xx_inv[i][j] * r_yx[j] for j in range(n)) for i in range(n)]
    r_squared = sum(r_yx[i] * temp[i] for i in range(n))
    r_squared = max(0.0, min(1.0, r_squared)) # Clamp for numerical stability

    return math.sqrt(r_squared)

def invert_matrix(M):
    """Gaussian elimination to invert matrix M [G]."""
    n = len(M)
    A = [row[:] + [1.0 if i == j else 0.0 for j in range(n)] for i, row in enumerate(M)]
    for i in range(n):
        pivot = A[i][i]
        if abs(pivot) < 1e-12:
            return [[0.0]*n for _ in range(n)] # Singular matrix fallback
        for j in range(2*n):
            A[i][j] /= pivot
        for k in range(n):
            if k != i:
                factor = A[k][i]
                for j in range(2*n):
                    A[k][j] -= factor * A[i][j]
    return [row[n:] for row in A]
```

**Edge Cases and Pitfalls:**
- **Zero Entropy:** If an attribute has constant values, its entropy is 0. The normalization step handles this by checking `max_entropy == 0` before division [G].
- **Multicollinearity:** If selected attributes are highly correlated, the multiple correlation calculation may become numerically unstable. The matrix inversion includes a singularity check and fallback [G].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Strengths:** Reduces the dimensionality of the transfer function specification problem by automatically identifying informative and non-redundant attributes [S1, unofficial]. More comprehensive than the original pairwise method by considering all previously selected attributes [S1, unofficial].
- **Limitations:** Relies on linear correlation, which may miss non-linear dependencies between attributes [S1, unofficial]. Computationally more expensive than simple entropy-based ranking due to multiple correlation calculations [S1, unofficial].

## Background
The method is an adaptation of the heuristic proposed by Zhou, Schott, and Hansen (2012) [S1, unofficial]. The original method selected a pair of attributes (initial attribute and second attribute) using simple correlation and entropy [S1, unofficial]. The adaptation, presented in the source [S1, unofficial], extends this to generate a full ranking of candidate attributes by using multiple correlation with all previously selected attributes [S1, unofficial]. This approach is used in volume exploration frameworks to assist in the semi-automatic classification of volumetric features and the generation of multidimensional transfer function specifications [S1, unofficial].
