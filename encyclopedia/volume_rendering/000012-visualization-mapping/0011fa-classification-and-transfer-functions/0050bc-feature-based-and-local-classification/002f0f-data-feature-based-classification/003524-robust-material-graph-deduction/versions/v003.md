# Robust Material Graph Deduction

Also called: Graph-based TF Creation, Material Graph Generation

## Overview
Robust Material Graph Deduction is an automated method for constructing transfer functions by discovering the topological structure of materials within a volume [S1, unofficial]. It solves the problem of manual transfer function creation by automatically identifying material interiors and their spatial interconnectivity, producing a graph where nodes represent materials and edges represent interfaces [S1, unofficial]. Unlike methods that focus solely on interface detection, this approach deduces material distributions and occlusion values to enable effective visualization of volume interiors and automatic background removal [S1, unofficial]. It is distinguished from sibling methods like [Feature Graph](8595-feature-graph.md) by its specific use of LH histogram edge sampling and HDBSCAN clustering to derive a weighted Gaussian intensity model for each material [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A 3D scalar volume dataset $V$.
*   **Output:** A material graph $G(M, I)$, where $M$ is the set of discovered materials and $I$ is the set of interfaces between adjacent materials. Each material $M_k$ is defined by an intensity distribution $V_k \sim \mathcal{N}(\mu_k, \sigma_k)$ and a mean occlusion value $\eta_k$ [S1, unofficial].

**Data Structures**
*   **LH Sample:** A tuple $(L, H)$ representing low and high intensity values found at a boundary pixel [S1, unofficial].
*   **Distance Matrix $D$:** A symmetric matrix where $D_{ij}$ is the Bhattacharyya distance between material distributions $V_i$ and $V_j$ [S1, unofficial].
*   **Material Graph $G$:** A graph structure with nodes $M$ and edges $I$ [S1, unofficial].

**Algorithm Steps**

1.  **Edge Detection:** Compute an initial set of interface edges $\hat{I}$ using the LH histogram [S1, unofficial]. For each edge pixel, perform a bidirectional traversal along the local gradient to search for a low value $L$ and a high value $H$ in a small neighborhood [S1, unofficial]. These values are samples from adjacent intensity distributions $V_{i,1}$ and $V_{i,2}$ [S1, unofficial].
2.  **Interface Clustering:** Cluster the LH samples from $\hat{I}$ using the HDBSCAN algorithm to define distinct material interfaces [S1, unofficial]. Subsample the interface set from their distribution to keep the algorithm computationally tractable for large volumes [S1, unofficial].
3.  **Base Threshold Calculation:** Compute the base distance threshold $\theta_{base}$ as the minimum Bhattacharyya distance between the two materials in any initial interface [S1, unofficial]:
    $$ \theta_{base} = \min_{i \in \{1, \dots, k\}} d_B(V_{i,1}, V_{i,2}) $$
    where $d_B$ is the Bhattacharyya distance [S1, unofficial].
4.  **Threshold Search Range:** Define a search range for the merging threshold $\theta$ using multipliers $\epsilon \ll 1$ and $\zeta \gg 1$:
    $$ \theta \in [\epsilon \theta_{base}, \zeta \theta_{base}] $$
    [S1, unofficial].
5.  **Graph Deduction (Greedy Merging):** For a given threshold $\theta$, deduce a feasible graph in two steps [S1, unofficial]:
    *   **Find Materials to Merge:** Walk through the distance matrix $D$ to find sets of similar materials. A set may include a material from an interface, but not both materials of that interface (to avoid collapsing an interface to a single material) [S1, unofficial]. Reduce each set to a single material using a parent-child hierarchy, merging all children with their respective parents [S1, unofficial].
    *   **Reconstruct Graph:** Merge nodes of similar materials together and merge repeating interface edges into one interface edge [S1, unofficial]. The resulting material intensity distributions are computed by a weighted average of the constituent material distributions (means and standard deviations) [S1, unofficial].
6.  **Optimal Graph Search:** Search for the optimal $\theta$ that maximizes the separation energy $E_{sep}$ [S1, unofficial]:
    $$ E_{sep}(G(M, I)) = \frac{1}{|I|} \sum_{j=1}^{|I|} d_B(V_{j,1}, V_{j,2}) $$
    [S1, unofficial]. Maximizing $E_{sep}$ results in a graph with fewer but well-separated interface edges [S1, unofficial].
7.  **Occlusion and Rendering:** Compute occlusion values $\eta$ for each material to indicate depth inside the volume, which is used for assigning transparency values [S1, unofficial]. The background material is set to invisible (white node) to hide it from rendering [S1, unofficial].

**Pseudocode**

```python
import numpy as np
from hdbscan import HDBSCAN

def bhattacharyya_distance(mean1, std1, mean2, std2):
    """
    Computes the Bhattacharyya distance between two 1D Gaussian distributions.
    """
    sigma1_sq = std1 ** 2
    sigma2_sq = std2 ** 2
    sigma_sq_avg = (sigma1_sq + sigma2_sq) / 2.0
    sigma_sq_prod = np.sqrt(sigma1_sq * sigma2_sq)
    
    term1 = 0.125 * ((mean1 - mean2) ** 2) / sigma_sq_avg
    term2 = 0.5 * np.log(sigma_sq_avg / sigma_sq_prod)
    
    return term1 + term2

def get_lh_samples(volume, gradient_field, neighborhood_radius):
    """
    Step 1: Compute initial edge set using LH histogram.
    """
    lh_samples = []
    # Iterate over edge pixels identified by gradient magnitude threshold
    edge_pixels = find_edge_pixels(gradient_field)
    
    for p in edge_pixels:
        # Bidirectional traversal along local gradient
        low_val, high_val = traverse_gradient(volume, p, gradient_field, neighborhood_radius)
        lh_samples.append((low_val, high_val))
        
    return np.array(lh_samples)

def deduce_material_graph(volume, lh_samples):
    """
    Steps 2-6: Cluster interfaces, deduce graph, and find optimal threshold.
    """
    # Step 2: Cluster LH samples to define interfaces
    # Subsample for tractability if necessary
    subsampled_samples = subsample(lh_samples, target_size=10000)
    
    # HDBSCAN clustering on LH samples to identify distinct interface clusters
    # Each cluster represents a unique interface between two materials
    clusterer = HDBSCAN(min_cluster_size=50)
    labels = clusterer.fit_predict(subsampled_samples)
    
    # Extract unique interfaces
    interfaces = []
    unique_labels = np.unique(labels)
    for label in unique_labels:
        cluster_samples = subsampled_samples[labels == label]
        # Compute initial material distributions for this interface
        # Assume Gaussian fit to L and H values separately
        mean_l = np.mean(cluster_samples[:, 0])
        std_l = np.std(cluster_samples[:, 0])
        mean_h = np.mean(cluster_samples[:, 1])
        std_h = np.std(cluster_samples[:, 1])
        interfaces.append({
            'mean_1': mean_l, 'std_1': std_l,
            'mean_2': mean_h, 'std_2': std_h
        })
        
    if not interfaces:
        return None, None

    # Step 3: Compute base threshold
    distances = []
    for iface in interfaces:
        d = bhattacharyya_distance(iface['mean_1'], iface['std_1'], 
                                   iface['mean_2'], iface['std_2'])
        distances.append(d)
        
    theta_base = np.min(distances)
    
    # Step 4: Define search range
    epsilon = 0.1 # << 1
    zeta = 10.0   # >> 1
    theta_range = np.linspace(epsilon * theta_base, zeta * theta_base, 50)
    
    best_theta = None
    max_e_sep = -np.inf
    best_graph = None
    
    # Step 5 & 6: Search for optimal theta
    for theta in theta_range:
        # Initialize graph with all interfaces as edges
        # Nodes are implicitly defined by the materials in interfaces
        # We need to build a distance matrix between all unique materials found
        
        # Collect all unique material distributions from interfaces
        all_materials = []
        mat_map = {} # map from (mean, std) tuple to index
        mat_index = 0
        
        for iface in interfaces:
            for mean, std in [(iface['mean_1'], iface['std_1']), 
                              (iface['mean_2'], iface['std_2'])]:
                key = (mean, std)
                if key not in mat_map:
                    mat_map[key] = mat_index
                    all_materials.append({'mean': mean, 'std': std})
                    mat_index += 1
                    
        n_mats = len(all_materials)
        D = np.zeros((n_mats, n_mats))
        
        # Compute full distance matrix
        for i in range(n_mats):
            for j in range(i + 1, n_mats):
                d = bhattacharyya_distance(all_materials[i]['mean'], all_materials[i]['std'],
                                           all_materials[j]['mean'], all_materials[j]['std'])
                D[i, j] = d
                D[j, i] = d
                
        # Greedy merging
        # Use Union-Find or similar structure to merge materials with distance < theta
        parent = list(range(n_mats))
        
        def find(i):
            if parent[i] != i:
                parent[i] = find(parent[i])
            return parent[i]
            
        def union(i, j):
            root_i = find(i)
            root_j = find(j)
            if root_i != root_j:
                parent[root_i] = root_j
                
        # Merge similar materials
        for i in range(n_mats):
            for j in range(i + 1, n_mats):
                if D[i, j] < theta:
                    union(i, j)
                    
        # Group materials by root
        groups = {}
        for i in range(n_mats):
            root = find(i)
            if root not in groups:
                groups[root] = []
            groups[root].append(i)
            
        # Compute merged material distributions (weighted average)
        merged_mats = []
        for root, indices in groups.items():
            # Weighted average based on number of samples or uniform?
            # Source says "weighted average of constituent material distributions"
            # Assuming uniform weight for simplicity if sample counts not tracked
            total_mean = sum(all_materials[i]['mean'] for i in indices) / len(indices)
            total_std = sum(all_materials[i]['std'] for i in indices) / len(indices)
            merged_mats.append({'mean': total_mean, 'std': total_std})
            
        # Reconstruct graph and compute separation energy
        # Interfaces are edges between merged materials
        current_interfaces = []
        for iface in interfaces:
            # Find indices of original materials
            idx1 = mat_map[(iface['mean_1'], iface['std_1'])]
            idx2 = mat_map[(iface['mean_2'], iface['std_2'])]
            
            # Find merged roots
            root1 = find(idx1)
            root2 = find(idx2)
            
            # If root1 == root2, interface is collapsed (invalid for separation energy)
            if root1 != root2:
                # Find indices in merged_mats
                mat1_idx = list(groups.keys()).index(root1)
                mat2_idx = list(groups.keys()).index(root2)
                
                m1 = merged_mats[mat1_idx]
                m2 = merged_mats[mat2_idx]
                
                d = bhattacharyya_distance(m1['mean'], m1['std'], m2['mean'], m2['std'])
                current_interfaces.append(d)
                
        if not current_interfaces:
            continue
            
        e_sep = np.mean(current_interfaces)
        
        if e_sep > max_e_sep:
            max_e_sep = e_sep
            best_theta = theta
            best_graph = (merged_mats, current_interfaces)
            
    return best_graph, best_theta

def compute_occlusion(volume, material_mask):
    """
    Compute mean occlusion value eta for a material.
    """
    # Occlusion indicates depth inside the volume
    # Implementation detail: [G] Typically computed via distance transform or ray casting
    # For this method, we assume a precomputed or simplified depth metric
    # Here we use the mean distance to the nearest boundary for voxels in the mask
    dist_transform = distance_transform_edt(1 - material_mask)
    occlusion = np.mean(dist_transform[material_mask > 0])
    return occlusion
```

**Parameters**
*   $\epsilon$: Lower bound multiplier for threshold search. Typical value: $\epsilon \ll 1$ (e.g., 0.1) [S1, unofficial].
*   $\zeta$: Upper bound multiplier for threshold search. Typical value: $\zeta \gg 1$ (e.g., 10.0) [S1, unofficial].
*   HDBSCAN `min_cluster_size`: Controls the granularity of interface clustering. Not given in the sources. [G]

**Edge Cases and Pitfalls**
*   **Noise:** Noise in volume data can result in repeating boundaries of the same interface. The clustering and merging steps help mitigate this, but excessive noise may lead to fragmented materials [S1, unofficial].
*   **Collapsed Interfaces:** If $\theta$ is too large, an interface may be collapsed into a single material (both materials in an interface merge). The algorithm explicitly excludes sets containing both materials of a single interface during the merging step to prevent this [S1, unofficial].
*   **Computational Cost:** For large volumes, the initial edge set $\hat{I}$ can be very large. Subsampling is required to keep the algorithm tractable [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The complexity is dominated by the edge detection ($O(N)$ where $N$ is the number of voxels), HDBSCAN clustering ($O(N \log N)$ typically), and the graph search over the threshold range. The number of thresholds is small (e.g., 50), and the merging step is nearly linear in the number of materials. Total time is reported as ~6 seconds for the full pipeline on tested datasets [S1, unofficial].
*   **Memory Complexity:** Requires storage for the volume, gradient field, LH samples, and the distance matrix. The distance matrix size depends on the number of unique materials, which is typically small compared to the volume size.
*   **Strengths:** Automatically discovers material interiors and connectivity; provides fine control over material color and opacities; enables automatic background removal; robust to noise through clustering and energy maximization [S1, unofficial].
*   **Limitations:** Relies on the assumption that materials can be modeled as Gaussian intensity distributions; performance depends on the quality of the LH histogram edge detection; requires tuning of HDBSCAN parameters [S1, unofficial].
*   **When to use:** When automatic transfer function generation is needed for complex volumes with multiple materials, and manual TF creation is prohibitive [S1, unofficial].
*   **When not to use:** When materials have non-Gaussian intensity distributions or when real-time performance is critical and the preprocessing time is unacceptable [S1, unofficial].

## Background
The method was proposed by Šereda et al. in 2018 [S1, unofficial]. It addresses the limitation of previous automatic synthesis methods that focused only on material boundaries, neglecting the interior of materials which is crucial for visualization [S1, unofficial]. The approach builds on the LH histogram proposed by Šereda et al. in 2006 [S1, unofficial]. It is implemented in a real-time GPU volume renderer written in C++ with a Python backend, using datasets from The Volume Library [S1, unofficial].
