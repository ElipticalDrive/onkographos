# Robust Material Graph Deduction

Also called: Graph-based TF Creation, Material Graph Generation

## Overview
Robust Material Graph Deduction is an automated method for constructing transfer functions by discovering the topological structure of materials within a volume [S1, unofficial]. It solves the problem of manual transfer function creation by automatically identifying material interiors and their spatial interconnectivity, producing a graph where nodes represent materials and edges represent interfaces [S1, unofficial]. Unlike sibling methods that focus on local feature extraction or high-dimensional clustering, this approach explicitly models the adjacency relationships between materials to enable automatic background removal and fine control over opacity based on depth [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A 3D volume dataset $V$ with scalar intensity values [S1, unofficial].
*   **Output:** A material graph $G(M, I)$, where $M$ is the set of discovered materials and $I$ is the set of interfaces between adjacent materials [S1, unofficial]. Each material $M_k$ is defined by a Gaussian intensity distribution $V_k \sim \mathcal{N}(\mu_k, \sigma_k)$ and a mean occlusion value $\eta_k$ [S1, unofficial].

**Data Structures**
*   **Initial Edge Set $\hat{I}$:** A collection of interface samples, where each sample is a pair of intensity values $(L, H)$ representing the low and high sides of an interface [S1, unofficial].
*   **Distance Matrix $D$:** A symmetric matrix where $D_{ij}$ is the Bhattacharyya distance between material distributions $V_i$ and $V_j$ [S1, unofficial].
*   **Material Graph $G$:** A graph structure with nodes $M$ and edges $I$ [S1, unofficial].

**Algorithm Steps**

1.  **Compute Initial Edge Set $\hat{I}$:**
    For each edge pixel in the volume, perform a bidirectional traversal along the local gradient to find a low value $L$ and a high value $H$ in a small neighborhood [S1, unofficial]. These values are samples from adjacent intensity distributions $V_{i,1}$ and $V_{i,2}$ [S1, unofficial].

2.  **Cluster Interfaces:**
    Cluster the $(L, H)$ samples from $\hat{I}$ using the HDBSCAN algorithm to define distinct material interfaces [S1, unofficial]. Subsample the interface set from their distribution to maintain computational tractability for large volumes [S1, unofficial].

3.  **Define Base Threshold $\theta_{base}$:**
    Calculate the minimum Bhattacharyya distance between any two materials in the initial interfaces:
    $$ \theta_{base} = \min_{i \in \{1, \dots, k\}} d_B(V_{i,1}, V_{i,2}) $$
    where $d_B$ is the Bhattacharyya distance [S1, unofficial].

4.  **Search for Optimal Threshold $\theta$:**
    Define a search range $[\epsilon \theta_{base}, \zeta \theta_{base}]$ where $\epsilon \ll 1$ and $\zeta \gg 1$ [S1, unofficial]. For each candidate $\theta$, perform greedy merging to construct a graph and calculate the separation energy $E_{sep}$:
    $$ E_{sep}(G(M, I)) = \frac{1}{|I|} \sum_{j=1}^{|I|} d_B(V_{j,1}, V_{j,2}) $$
    Select the $\theta$ that maximizes $E_{sep}$ [S1, unofficial]. Maximizing this energy results in a graph with fewer, well-separated interface edges [S1, unofficial].

5.  **Greedy Merging (for a fixed $\theta$):**
    *   **Find Materials to Merge:** Walk through the distance matrix $D$ to create sets of similar materials [S1, unofficial]. A set may include a material from an interface, but not both materials of that interface (to avoid collapsing an interface into a single material) [S1, unofficial]. Reduce each set to a single material using a parent-child hierarchy, merging all children with their respective parents [S1, unofficial].
    *   **Reconstruct Graph:** Merge nodes of similar materials and merge repeating interface edges into a single interface edge [S1, unofficial].
    *   **Update Distributions:** Compute the resulting material intensity distributions as a weighted average of the constituent material distributions (means and standard deviations) [S1, unofficial].

6.  **Assign Occlusion:**
    Calculate the mean occlusion value $\eta$ for each material, indicating its depth inside the volume, which is used to assign transparency values [S1, unofficial].

**Pseudocode**

```python
import math

def robust_material_graph_deduction(volume):
    # Step 1: Compute initial edge set I_hat
    initial_edges = []
    for pixel in volume.edge_pixels():
        L, H = bidirectional_gradient_traversal(pixel, volume)
        initial_edges.append((L, H))

    # Step 2: Cluster interfaces and subsample
    sampled_edges = initial_edges[:min(1000, len(initial_edges))]
    clusters = cluster_edges(sampled_edges)
    
    materials = []
    for cid, edges in clusters.items():
        vals = [v for e in edges for v in e]
        mu = sum(vals) / len(vals)
        sigma = math.sqrt(sum((v - mu)**2 for v in vals) / len(vals))
        materials.append({'id': cid, 'mu': mu, 'sigma': sigma, 'edges': edges})

    # Step 3: Compute base threshold
    n = len(materials)
    distances = [[0.0]*n for _ in range(n)]
    for i in range(n):
        for j in range(i+1, n):
            d = bhattacharyya(materials[i], materials[j])
            distances[i][j] = d
            distances[j][i] = d

    interface_pairs = get_interface_pairs(materials)
    theta_base = min(distances[i['id']][j['id']] for i, j in interface_pairs)

    # Step 4: Search for optimal theta
    epsilon = 0.1
    zeta = 10.0
    best_theta = theta_base
    max_energy = -float('inf')
    best_graph = None

    for log_t in range(int(math.log10(epsilon * theta_base) * 10), int(math.log10(zeta * theta_base) * 10)):
        theta = 10 ** (log_t / 10.0)
        if theta < epsilon * theta_base or theta > zeta * theta_base:
            continue

        merged_materials, merged_interfaces = greedy_merge(materials, distances, theta)
        if len(merged_interfaces) == 0:
            continue
        energy = sum(bhattacharyya(m1, m2) for m1, m2 in merged_interfaces) / len(merged_interfaces)
        if energy > max_energy:
            max_energy = energy
            best_theta = theta
            best_graph = (merged_materials, merged_interfaces)

    final_materials, final_interfaces = greedy_merge(materials, distances, best_theta)
    for material in final_materials:
        material['occlusion'] = compute_mean_occlusion(material, volume)
    return final_materials, final_interfaces

def bidirectional_gradient_traversal(pixel, volume):
    grad = volume.gradient(pixel)
    low_val = volume[pixel]
    high_val = volume[pixel]
    for _ in range(5):
        low_val = min(low_val, volume[pixel - grad])
        high_val = max(high_val, volume[pixel + grad])
    return low_val, high_val

def bhattacharyya(v1, v2):
    mu1, sigma1 = v1['mu'], v1['sigma']
    mu2, sigma2 = v2['mu'], v2['sigma']
    avg_sigma = (sigma1 + sigma2) / 2
    dist_sq = (mu1 - mu2)**2 / (2 * avg_sigma**2)
    coeff = 0.25 * math.log(avg_sigma**2 / (sigma1 * sigma2))
    return dist_sq + coeff

def cluster_edges(edges):
    # Groups edges by proximity using a simple distance threshold [G]
    clusters = {}
    threshold = 0.5
    for edge in edges:
        placed = False
        for cid, clust_edges in clusters.items():
            if any(math.sqrt((e[0]-edge[0])**2 + (e[1]-edge[1])**2) < threshold for e in clust_edges):
                clusters[cid].append(edge)
                placed = True
                break
        if not placed:
            clusters[len(clusters)] = [edge]
    return clusters

def get_interface_pairs(materials):
    # Extracts pairs of materials sharing an interface in I_hat
    pairs = []
    for mat in materials:
        for i, e1 in enumerate(mat['edges']):
            for j, e2 in enumerate(mat['edges']):
                if i < j:
                    pairs.append((materials[e1[0]], materials[e2[0]]))
    return pairs

def greedy_merge(materials, distances, theta):
    n = len(materials)
    parent = {i: i for i in range(n)}
    
    # Step 5a: Find materials to merge
    for i in range(n):
        for j in range(i + 1, n):
            if distances[i][j] < theta and not interface_collapses(materials[i], materials[j], materials):
                parent[j] = i
                
    # Reduce sets to single materials via parent-child hierarchy
    unique_materials = []
    for i in range(n):
        root = i
        while parent[root] != root:
            root = parent[root]
        if root not in [m['id'] for m in unique_materials]:
            unique_materials.append(materials[i])
            
    # Step 5b: Reconstruct graph and merge repeating interfaces
    interfaces = []
    for i, m1 in enumerate(unique_materials):
        for j, m2 in enumerate(unique_materials):
            if i < j and are_adjacent(m1, m2, materials):
                merged_dist = weighted_average_dist(m1, m2)
                interfaces.append((merged_dist, merged_dist))
                
    return unique_materials, interfaces

def interface_collapses(m1, m2, materials):
    for mat in materials:
        ids = {e[0] for e in mat['edges']}
        if m1['id'] in ids and m2['id'] in ids:
            return True
    return False

def are_adjacent(m1, m2, materials):
    for mat in materials:
        ids = {e[0] for e in mat['edges']}
        if m1['id'] in ids and m2['id'] in ids:
            return True
    return False

def weighted_average_dist(v1, v2):
    w1, w2 = v1['sigma'], v2['sigma']
    total_w = w1 + w2
    return {'mu': (w1*v1['mu'] + w2*v2['mu'])/total_w, 'sigma': (w1*v1['sigma'] + w2*v2['sigma'])/total_w}

def compute_mean_occlusion(material, volume):
    # Not given in the sources. Computes depth-based transparency weight [G]
    return 0.5
```

**Parameters**
*   $\epsilon$: Lower bound multiplier for threshold search. Must be much less than 1 ($\epsilon \ll 1$) [S1, unofficial].
*   $\zeta$: Upper bound multiplier for threshold search. Must be much greater than 1 ($\zeta \gg 1$) [S1, unofficial].
*   $\theta$: Distance threshold for merging materials. Searched in $[\epsilon \theta_{base}, \zeta \theta_{base}]$ [S1, unofficial].

**Edge Cases and Pitfalls**
*   **Noise:** Noise in volume data can result in repeating boundaries for the same interface [S1, unofficial]. The clustering and merging steps help mitigate this, but subsampling is critical for performance [S1, unofficial].
*   **Disconnected Components:** Materials may have multiple disconnected components [S1, unofficial]. The graph deduction assumes valid material-material interfaces from clustering [S1, unofficial].
*   **Background:** The background material is typically set to invisible (white node) to hide it from rendering [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The complexity is dominated by the initial edge detection and the HDBSCAN clustering [S1, unofficial]. The greedy merging is efficient, but the search for optimal $\theta$ requires evaluating multiple graph configurations [S1, unofficial].
*   **Memory Complexity:** Requires storing the initial edge set, distance matrix, and the final graph [S1, unofficial]. Subsampling helps manage memory for large volumes [S1, unofficial].
*   **Performance:** Implemented in a real-time GPU volume renderer with a Python backend [S1, unofficial]. Graph deduction takes approximately 2 seconds on standard datasets, with voxel classification taking ~4 seconds and interface clustering taking negligible time [S1, unofficial].
*   **Strengths:** Automatic discovery of materials and interfaces; fine control over color and opacity; automatic background removal; robust to noise via clustering [S1, unofficial].
*   **Limitations:** Relies on the quality of the initial edge detection; assumes materials can be modeled by Gaussian distributions; may struggle with highly complex or overlapping intensity distributions [S1, unofficial].

## Background
The method was proposed to address the limitation of existing techniques that focus on material boundaries without adequately representing material interiors [S1, unofficial]. It builds on the LH histogram approach for edge detection [S1, unofficial]. The algorithm was implemented and tested on datasets from The Volume Library [S1, unofficial].
