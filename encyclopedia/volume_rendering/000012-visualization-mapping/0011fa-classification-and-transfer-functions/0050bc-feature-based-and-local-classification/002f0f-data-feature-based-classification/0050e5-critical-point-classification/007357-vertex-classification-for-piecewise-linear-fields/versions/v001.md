# Vertex Classification for Piecewise Linear Fields

Also called: Edge graph classification, Gerstner and Pajarola's Vertex Classification for Piecewise Linear Fields, Local tetrahedral partitioning, Surrounding polyhedron method, Vertex Classification via Implicit Tetrahedrization

## Overview
This method classifies mesh vertices in piecewise linear (C⁰-continuous) scalar fields as regular, maximum, minimum, or saddle points by analyzing the connectivity of an edge graph derived from the vertex's local neighborhood [S1]. It distinguishes itself from differentiable field methods (like [Critical Point Classification](14338-critical-point-classification.md)) by operating on discrete, non-differentiable data where critical points are restricted to mesh vertices, using topological connectivity rather than Hessian eigenvalues [S1].

## How it works
**Inputs:** A scalar field $f$ defined on a mesh (tetrahedral or hexahedral/trilinear), and a target vertex $v_0$ with value $f(v_0)$.
**Outputs:** A classification label for $v_0$: {Regular, Maximum, Minimum, Saddle}.

**Data Structures:**
1.  **Surrounding Polyhedron:** The set of all tetrahedra (or cells) sharing an edge connected to $v_0$. The vertices of these cells form the local neighborhood.
2.  **Edge Graph:** A graph where nodes are the neighborhood vertices (excluding $v_0$) and edges are the connections between them within the surrounding polyhedron.
3.  **Polarity Map:** A mapping from each neighborhood vertex $v_i$ to a sign $s_i \in \{+, -\}$.

**Steps:**
1.  **Identify Neighborhood:** Determine the "surrounding polyhedron" consisting of all cells sharing an edge connected to $v_0$. Let $V_{nb}$ be the set of vertices in this polyhedron excluding $v_0$.
2.  **Assign Polarity:** For each $v_i \in V_{nb}$:
    *   If $f(v_i) > f(v_0)$, set $s_i = '+'$.
    *   If $f(v_i) < f(v_0)$, set $s_i = '-'$.
    *   If $f(v_i) = f(v_0)$, ignore $v_i$ (do not include in graph or count) [S1].
3.  **Construct Edge Graph:** Create a graph $G=(V_{nb}, E)$ where $E$ contains all edges from the surrounding polyhedron connecting vertices in $V_{nb}$.
4.  **Filter Edges:** Remove all edges $(u, v) \in E$ where $s_u \neq s_v$ (i.e., edges connecting vertices of different polarities) [S1].
5.  **Count Components:** Calculate the number of connected components $C$ in the remaining graph.
6.  **Classify:**
    *   If $C = 1$: The vertex is a **Maximum** if the component consists of '+' vertices, or a **Minimum** if it consists of '-' vertices [S1].
    *   If $C = 2$: The vertex is a **Regular** point [S1].
    *   If $C > 2$: The vertex is a **Saddle** point [S1].

**Alternative Implementation (Hexahedral/Trilinear):**
For hexahedral cells, the method leverages the fact that trilinear interpolation near a vertex mimics linear interpolation [S1].
1.  Identify the three edge-connected neighbors $v_1, v_2, v_4$ of $v_0$ within the same cell [S1].
2.  Treat $v_0, v_1, v_2, v_4$ as an implicit tetrahedron [S1].
3.  Apply the polarity and connectivity logic to these 4 vertices (plus any other edge-connected neighbors if the topology is more complex, but the core lemma relies on the 3 neighbors) [S1].
4.  The sources note that for trilinear fields, a case table of $2^6=64$ entries can be precomputed based on the signs of the 6 edge-connected vertices in a hexahedron, mapping the configuration to a classification [S1].

**Formulas and Definitions:**
Let $F: \mathbb{R}^d \rightarrow \mathbb{R}$ be the scalar field. Let $U_\delta$ be a small neighborhood of $v_0$. Let $R = U_\delta \cap C$ be the intersection with the cell $C$ containing $v_0$.
Let $N_1$ be the preimage of $(-\infty, F(v_0))$ in $R \setminus \{v_0\}$ and $P_1$ be the preimage of $[F(v_0), +\infty)$ in $R \setminus \{v_0\}$ [S1].
The classification is determined by the number of connected components $n_n$ (negative) and $n_p$ (positive) in the neighborhood:
*   **Regular:** $n_p = n_n = 1$ and $P_1 \neq N_1$ [S1].
*   **Minimum:** $n_p = 1$ and $n_n = 0$ [S1].
*   **Maximum:** $n_n = 1$ and $n_p = 0$ [S1].
*   **Saddle:** $n_p + n_n > 2$ [S1].

The edge graph method approximates these topological properties. The deletion of edges between different polarities effectively isolates the connected regions of higher/lower values.

**Pseudocode:**

```python
def classify_vertex(v0, mesh, scalar_field):
    """
    Classifies vertex v0 in a piecewise linear scalar field.
    v0: The vertex index to classify.
    mesh: Object providing connectivity (edges, cells).
    scalar_field: Array of scalar values for all vertices.
    """
    v0_val = scalar_field[v0]
    
    # Step 1: Identify surrounding polyhedron vertices
    # Get all cells (tetrahedra or hexahedra) that share an edge with v0
    # For simplicity, assume we can get all neighbors connected by an edge
    # and all vertices in the cells sharing those edges.
    
    neighbors = set()
    cells_sharing_edge = get_cells_sharing_edge_with_vertex(v0, mesh)
    
    for cell in cells_sharing_edge:
        neighbors.update(cell.vertices)
    
    # Remove v0 itself
    neighbors.discard(v0)
    
    # Step 2: Assign polarity and build graph
    graph_nodes = []
    node_to_idx = {}
    
    for i, v in enumerate(neighbors):
        val = scalar_field[v]
        if val == v0_val:
            continue # Ignore equal values
        if val > v0_val:
            polarity = '+'
        else:
            polarity = '-'
        graph_nodes.append({'id': v, 'polarity': polarity})
        node_to_idx[v] = i
        
    # Step 3: Construct edge graph and filter
    # Get edges between nodes in neighbors
    edges = get_edges_between_vertices(neighbors, mesh)
    
    remaining_edges = []
    for u, v in edges:
        if u in node_to_idx and v in node_to_idx:
            u_polarity = graph_nodes[node_to_idx[u]]['polarity']
            v_polarity = graph_nodes[node_to_idx[v]]['polarity']
            if u_polarity == v_polarity:
                remaining_edges.append((u, v))
                
    # Step 4: Count connected components
    # Build adjacency list from remaining_edges
    adj = {v: [] for v in neighbors if v in node_to_idx}
    for u, v in remaining_edges:
        adj[u].append(v)
        adj[v].append(u)
        
    visited = set()
    components = 0
    component_polarity = None
    
    for v in adj:
        if v not in visited:
            components += 1
            # Determine polarity of this component
            # All nodes in a component must have the same polarity
            # because edges between different polarities were removed.
            comp_polarity = graph_nodes[node_to_idx[v]]['polarity']
            component_polarity = comp_polarity
            
            # BFS/DFS to mark visited
            stack = [v]
            while stack:
                curr = stack.pop()
                if curr not in visited:
                    visited.add(curr)
                    for neighbor in adj[curr]:
                        if neighbor not in visited:
                            stack.append(neighbor)
                            
    # Step 5: Classify
    if components == 1:
        if component_polarity == '+':
            return 'Maximum'
        else:
            return 'Minimum'
    elif components == 2:
        return 'Regular'
    else:
        return 'Saddle'

def get_cells_sharing_edge_with_vertex(v0, mesh):
    """
    Returns all cells that contain at least one edge connected to v0.
    Implementation detail: Iterate over all edges connected to v0,
    then find all cells containing those edges.
    """
    cells = set()
    for neighbor in mesh.get_edge_neighbors(v0):
        edge = (v0, neighbor)
        cells.update(mesh.get_cells_containing_edge(edge))
    return list(cells)

def get_edges_between_vertices(vertices, mesh):
    """
    Returns list of edges (u, v) where both u and v are in vertices.
    """
    edges = []
    for u in vertices:
        for v in mesh.get_neighbors(u):
            if v in vertices and u < v: # Avoid duplicates
                edges.append((u, v))
    return edges
```

**Parameters:**
*   Neighborhood definition: "Surrounding polyhedron" defined by cells sharing an edge with the vertex [S1].
*   Equality handling: Vertices with equal scalar values are ignored [S1].

**Edge Cases and Pitfalls:**
*   **Equal Values:** Vertices with $f(v_i) = f(v_0)$ are excluded from the graph. This can reduce the number of nodes and potentially affect component counting if not handled consistently [S1].
*   **Degenerate Input:** If the neighborhood is too small or disconnected, the component count may be ambiguous.
*   **Trilinear Approximation:** The method relies on the lemma that trilinear interpolation near a vertex partitions space similarly to linear interpolation. This is an approximation and may not hold for all field configurations, though it is the basis for the method [S1].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of edges in the surrounding polyhedron. The dominant step is graph traversal (BFS/DFS) to count components.
*   **Memory Complexity:** Linear with respect to the size of the local neighborhood.
*   **Strengths:** Robust for discrete, piecewise linear data where derivatives are undefined. Simple to implement using standard graph algorithms.
*   **Limitations:** Only classifies vertices, not interior critical points. Accuracy depends on the mesh resolution and the validity of the trilinear-to-linear approximation assumption [S1].
*   **When to use:** When analyzing critical points in tetrahedral or hexahedral meshes with piecewise linear or trilinear interpolation, especially in adaptive refinement contexts where edge collapsing is performed [S1].

## Background
The method was introduced by Gerstner and Pajarola [S1]. It is based on the observation that for piecewise linear interpolation on tetrahedral grids, critical points can only occur at mesh vertices. The method extends to trilinear fields by leveraging the local linear behavior near vertices (Lemma 3 in the source) [S1]. It is used in the context of feature-based visualization and adaptive refinement of scalar fields [S1].
