# Cosine Similarity

Also called: Cosine Similarity on Unit Hypersphere

## Overview
Cosine similarity measures the angular agreement between two vectors by computing the inner product of their L2-normalized forms, effectively factoring out magnitude variations to focus on directional information [S1, unofficial]. In volume rendering classification, this allows transfer functions to distinguish semantic content based on the orientation of feature vectors (e.g., gradients or latent codes) rather than their scalar intensity or norm, which may be affected by scale or activation statistics [S1, unofficial]. It is distinct from magnitude-dependent methods and correlation-based methods like Pearson or Spearman, which assess linear or monotonic agreement across individual feature dimensions rather than global direction [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Two feature vectors $\mathbf{z}_{render}, \mathbf{z}_{target} \in \mathbb{R}^d$ associated with a sample point $\mathbf{x}$ in the volume.
*   **Output:** A similarity score $sim \in [-1, 1]$, representing the cosine of the angle between the vectors.

**Data Structures:**
*   Vectors $\mathbf{z}$ are dense arrays of floating-point numbers of dimension $d$.
*   No additional lookup tables or textures are required; the computation is algebraic.

**Parameters:**
*   $\epsilon$: A small positive constant added for numerical stability in the denominator. Typical values are $10^{-8}$ or $10^{-12}$ [S1, unofficial].

**Steps:**
1.  **L2-Normalization:** Map each vector $\mathbf{z}$ to the unit hypersphere $S^{d-1}$ using the function $\phi: \mathbb{R}^d \to S^{d-1}$:
    $$ \hat{\mathbf{z}} = \phi(\mathbf{z}) = \frac{\mathbf{z}}{\|\mathbf{z}\|_2 + \epsilon} $$
    where $\|\mathbf{z}\|_2 = \sqrt{\sum_{k=1}^d z_k^2}$ is the L2 norm [S1, unofficial].
2.  **Inner Product:** Compute the similarity as the dot product of the normalized vectors:
    $$ sim = \hat{\mathbf{z}}_{render}^\top \hat{\mathbf{z}}_{target} $$
3.  **Interpretation:** The result equals $\cos \theta$, where $\theta$ is the angle between the original vectors [S1, unofficial].

**Pseudocode:**
```python
def cosine_similarity(z_render, z_target, epsilon=1e-8):
    """
    Computes cosine similarity between two vectors.
    
    Args:
        z_render: List or array of floats, dimension d.
        z_target: List or array of floats, dimension d.
        epsilon: Small constant for numerical stability.
        
    Returns:
        Float similarity score in [-1, 1].
    """
    # Compute L2 norms
    norm_render = 0.0
    norm_target = 0.0
    for k in range(len(z_render)):
        norm_render += z_render[k] ** 2
        norm_target += z_target[k] ** 2
    
    norm_render = math.sqrt(norm_render)
    norm_target = math.sqrt(norm_target)
    
    # Normalize vectors
    # Note: In implementation, handle zero-norm case if necessary, 
    # though epsilon prevents division by zero.
    z_render_hat = [z / (norm_render + epsilon) for z in z_render]
    z_target_hat = [z / (norm_target + epsilon) for z in z_target]
    
    # Compute inner product
    sim = 0.0
    for k in range(len(z_render_hat)):
        sim += z_render_hat[k] * z_target_hat[k]
        
    return sim
```

**Edge Cases and Pitfalls:**
*   **Zero Vectors:** If a feature vector is zero, the L2 norm is zero. The addition of $\epsilon$ ensures the denominator is non-zero, resulting in a normalized vector of zeros, which yields a similarity of 0 against any other vector. This is a design choice for stability [S1, unofficial].
*   **Dimensionality:** The method assumes vectors are in the same space $\mathbb{R}^d$. Mismatched dimensions are undefined.

## Subtopics

### Class-Conditional Affinity Metric
A pairwise cosine similarity metric normalized per query to remove encoder-specific global structure, averaged by class pair to summarize within-class and between-class affinity [S2, unofficial]. It computes a query-wise normalized affinity $a_{ij}$ for every non-self pair using the mean $\mu$ and standard deviation $\sigma$ of the non-self gallery for each query, then averages $a_{ij}$ by class pair [S2, unofficial]. This normalization ensures that zero denotes the query-specific gallery average, not absolute similarity, revealing stronger class-relative organization in the feature space [S2, unofficial]. Parameters include an embedding dimension of 768 and query-wise normalization using gallery statistics [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(d)$ per pair, where $d$ is the vector dimension. The normalization and dot product are linear in dimensionality.
*   **Memory Complexity:** $O(d)$ to store the vectors. No auxiliary structures like LUTs are needed for the core calculation.
*   **Strengths:** Scale-invariant; robust to variations in vector magnitude caused by activation statistics or training dynamics [S1, unofficial]. Focuses on directional semantic content.
*   **Limitations:** Ignores magnitude information, which may be relevant in some physical contexts. Sensitive to the dimensionality $d$; high-dimensional spaces may suffer from the "curse of dimensionality" where distances become less discriminative.
*   **When to use:** When feature vectors encode semantic content primarily through orientation (e.g., deep latent representations) rather than norm [S1, unofficial].
*   **When not to use:** When magnitude carries critical information (e.g., density magnitude in some physical simulations) or when linear correlation across dimensions is more important than global direction (use Pearson/Spearman instead) [S1, unofficial].

## Background
Cosine similarity on the unit hypersphere was formalized in the context of probing vision models for 3D scene understanding using differentiable rendering [S1, unofficial]. It was introduced to handle latent representations from deep networks where semantic content is encoded by vector orientation rather than norm, which can be affected by scale or training dynamics [S1, unofficial]. The method maps vectors to $S^{d-1}$ via L2-normalization and computes the inner product, which corresponds to $\cos \theta$ [S1, unofficial]. It is contrasted with Pearson and Spearman correlations, which assess agreement across individual feature dimensions rather than global direction [S1, unofficial].
