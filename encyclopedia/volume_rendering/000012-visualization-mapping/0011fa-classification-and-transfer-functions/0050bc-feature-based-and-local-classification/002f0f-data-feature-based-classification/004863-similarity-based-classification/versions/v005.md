# Similarity-based Classification

Also called: Similarity-based Transfer Functions, Feature Similarity Classification

## Overview
Similarity-based classification methods determine optical properties by measuring the distance or correlation between a sample point's feature vector and a set of reference exemplars, annotations, or latent representations, rather than relying on absolute scalar thresholds [S1][S2][S3, unofficial][S4, unofficial][S6, unofficial]. This approach solves the problem of semantic ambiguity in high-dimensional or complex data by allowing users to define regions of interest based on structural or spectral resemblance to known patterns [S1]. Unlike [Data Feature-Based Classification](5934-data-feature-based-classification.md) methods that map features directly to opacity via fixed functions, this family maps features to a similarity score, enabling interactive, context-aware segmentation and visualization [S1][S2].

## Shared principles
All methods in this family evaluate a classification function $C(\mathbf{x})$ for each sample point $\mathbf{x}$ in the volume to produce optical properties [G].

**Input Domain:**
The input to the classification function is a feature vector $\mathbf{f}(\mathbf{x})$ associated with position $\mathbf{x}$. While basic methods use scalar intensity $v = f(\mathbf{x})$, this family extends the domain to include derived features such as gradient magnitude $\|\nabla f(\mathbf{x})\|$, curvature, shape descriptors, color components, or topological graph attributes [S1][S2][S3, unofficial][S4, unofficial].

**Output Range:**
The output is a set of optical properties, most commonly:
*   **Opacity ($\alpha$):** A value in $[0, 1]$ representing the probability of absorption or the inverse of transparency. $\alpha=0$ is fully transparent; $\alpha=1$ is fully opaque [S5, unofficial].
*   **Color ($C$):** A vector $(r, g, b)$ representing the emitted or reflected light color [S2][S4, unofficial].
*   **Weight:** In some emission-only models, a weight $w$ is assigned to modulate the contribution of samples during accumulation [S6, unofficial].

**Classification Types:**
1.  **Binary Classification:** Uses hard thresholds to include or exclude data [6229-binary-and-soft-classification.md]. Values below a threshold are assigned $\alpha=0$, and values above are assigned $\alpha=1$ (or a constant high value) [G].
2.  **Soft Classification:** Uses smooth transitions (e.g., piecewise linear ramps, Gaussian bumps, or power functions) to assign intermediate opacity values [S3, unofficial].

**Evaluation Order:**
The timing of classification relative to sampling interpolation defines two main approaches [S2][S5, unofficial]:
*   **Pre-classification:** The transfer function is applied to scalar values at the grid points (voxels) before sampling. Colors and opacities are interpolated during ray casting. Pre-classification produces blurred images when the image resolution is higher than the volume resolution, but prevents color bleeding if color interpolation is done with opacity-weighted colors [S2].
*   **Post-classification:** Scalar values are interpolated from the volume texture during ray casting, and the transfer function is applied to these continuous sample values. Post-classification produces images with defined edges but is prone to aliasing because high-frequency details may be missed [S2].

**Implementation Structures:**
Transfer functions are commonly implemented as piecewise linear functions defined by user-specified keypoints [S3, unofficial], lookup tables (LUTs) stored as 1D, 2D, or 3D textures for fast GPU sampling [S3, unofficial][S6, unofficial], or shader functions evaluated dynamically during ray casting [S5, unofficial].

## Subtopics

### [Range-Space Segmentation](13745-range-space-segmentation.md)
Range-Space Segmentation is a method for visualizing and analyzing function field data by projecting high-dimensional function samples into scalar fields based on their distance to a set of user-defined exemplar functions. It solves the problem of intelligently segmenting complex datasets (such as hyperspectral imagery or time-varying pollution data) by creating a classification field that assigns each spatial point to the nearest exemplar, thereby enabling feature-based visualization and surface extraction. Unlike multidimensional scaling (MDS) techniques which lose spatial layout, this method preserves the original spatial structure of the data while reducing the functional dimensionality to a scalar distance field and an integer label field.

### [Representational Similarity Analysis (RSA)](14970-representational-similarity-analysis-rsa.md)
Representational Similarity Analysis (RSA) is a method for evaluating the quality of a learned latent space by comparing the relational structure (manifold geometry) of two sets of representations against each other. Unlike pointwise similarity measures that assess individual latent codes in isolation, RSA assesses whether the pairwise similarity structure across an entire set of views is preserved. It is primarily used in the context of self-supervised learning and differentiable rendering to verify if a reconstructed latent space captures the same representational organization as a ground-truth or reference space.

### [CNN-based Image Retrieval](15632-cnn-based-image-retrieval.md)
A retrieval method using a pre-trained Convolutional Neural Network (AlexNet) to extract high-level spatial semantics from co-planar images along the ray for matching against a knowledge database.

### Cosine Similarity Map Computation
- **Definition:** Computes a similarity volume $S_L$ by comparing annotated feature vectors against the full feature volume $F$ using cosine similarity, enabling interactive feedback [S1].
- **Formula:** $S_L^C = \max_{a \in A_C} \frac{1}{|F|} \sum_{i \in F} \frac{F_a \cdot F_i}{\|F_a\|_2 \|F_i\|_2}$ where $A_C$ is the set of annotations for class $C$, $F_a$ is the feature vector at annotation $a$, and $F_i$ is the feature vector at voxel $i$. Resulting $S_L^C \in [0, 1]^{W' \times H' \times D'}$ [S1].
- **Formula:** $P(x) = \max_{a \in A_C} e^{-10\tilde{p}|x-a|}$ where $x$ is the location in $R^3$ and $a$ is an annotation location [S1].
- **Parameter:** Proximity parameter $\tilde{p} \in [0, 1]$, used to scale similarity based on distance to annotations [S1].
- **Number:** Computation time: A few milliseconds on CPU or GPU [S1].

### Thresholded Cosine Similarity Segmentation
- **Step:** Compute probability of a query using thresholded cosine similarity instead of softmax with negative queries [S2].
- **Step:** Set $p = 1$ if similarity exceeds threshold, $p = 0$ otherwise for hard decomposition [S2].

### Discrete Classification via Voxel Similarity
- **Definition:** A discrete voxel classification technique for multidimensional signatures. Users perform merge or bipartition operations on existing classes and define visual properties for each class. Preprocessing establishes an initial classification based on voxel similarity criteria, which are also respected during rapid bipartition operations [S3, unofficial].
- **Step:** 1. Preprocessing: Automatically establish initial classification respecting voxel similarity criteria. 2. User performs merge or bipartition operations on classes. 3. User defines visual properties for each class. 4. Bipartition operations are executed rapidly, respecting similarity criteria [S3, unofficial].

### S4
- **Definition:** A self-supervised approach to spatiotemporal similarity learning using a Siamese neural network trained on a binary pretext task to predict spatial-temporal proximity, eliminating the need for labeled data [S4, unofficial].
- **Step:** 1. Train a Siamese neural network on a binary pretext task: predict if two spatiotemporal patches originate from nearby locations in space and time. 2. Use the resulting latent space for similarity queries. 3. Users supply example patches as a query; S4 ranks the rest of the ensemble by learned similarity [S4, unofficial].

### Trajectory Arrows Clustering
- **Definition:** A clustering algorithm to select a representative subset of particle trajectories to display as arrows, based on similarity of pathlines over three time steps [S5, unofficial].
- **Step:** Select any pathline not already in a cluster to serve as the reference pathline [S5, unofficial].
- **Step:** Examine all other pathlines not already in a cluster as candidates [S5, unofficial].
- **Step:** If the similarity score between the reference pathline and the candidate pathline is less than a preset threshold, add the candidate to the cluster [S5, unofficial].
- **Step:** After examining all candidates, output the reference pathline as the trajectory arrow for that cluster [S5, unofficial].
- **Step:** Choose the next pathline not in a cluster and repeat the process [S5, unofficial].
- **Step:** Filter out pathlines shorter than a preset threshold [S5, unofficial].
- **Step:** Discard clusters that do not have a preset minimum number of pathlines [S5, unofficial].
- **Formula:** Similarity Metric: The sum of squared distances between particle positions at each time step in the three-time-step window [S5, unofficial].
- **Parameter:** Time Window: The number of time steps considered for trajectory similarity. Default: 3 [S5, unofficial].
- **Parameter:** Similarity Threshold: Determines cluster size. It is determined separately for each dataset based on distances between particles and can be changed interactively [S5, unofficial].

### Cosine Similarity
- **Definition:** A similarity measure that factors out vector magnitude variations to focus on directional information in latent representations, computed via L2-normalization and inner product [S6, unofficial].
- **Formula:** $\text{sim} = \hat{r}^T \hat{t} = \cos \theta$ [S6, unofficial].
- **Parameter:** $\epsilon$: A small constant added for numerical stability in the denominator [S6, unofficial].
- **Parameter:** $z$: A latent representation vector in $R^d$ [S6, unofficial].

### Pearson Correlation
- **Definition:** A linear correlation coefficient across feature dimensions of latent vectors, probing per-dimension structure agreement [S6, unofficial].
- **Definition:** A metric to probe stricter equivalence than cosine similarity by measuring linear agreement between feature dimensions of rendered and target latent vectors. It detects poorly coordinated feature dimensions that high cosine similarity might miss [S6, unofficial].
- **Formula:** $\rho_P = \frac{\sum_k (z_{\text{render},k} - \bar{z}_{\text{render}})(z_{\text{target},k} - \bar{z}_{\text{target}})}{\sqrt{\sum_k (z_{\text{render},k} - \bar{z}_{\text{render}})^2} \sqrt{\sum_k (z_{\text{target},k} - \bar{z}_{\text{target}})^2}}$ where $z_{\text{render},k}$ and $z_{\text{target},k}$ are the $k$-th feature dimensions of the rendered and target latent vectors, and $\bar{z}$ denotes their mean [S6, unofficial].
- **Parameter:** $z_{\text{render}}, z_{\text{target}}$: Latent vectors in $R^d$ [S6, unofficial].
- **Comparison:** Unlike cosine similarity which measures aggregate direction, Pearson correlation measures the coordination of individual feature dimensions. A gap between Pearson ($\rho_P$) and Spearman ($\rho_S$) indicates if mismatch is driven by outlier dimensions (large gap) or systematic non-linear warp (small gap) [S6, unofficial].

### Spearman Correlation
- **Definition:** A rank-based correlation coefficient that captures monotonic (possibly non-linear) agreement between feature dimensions [S6, unofficial].
- **Definition:** A metric capturing monotonic (possibly non-linear) agreement between feature dimensions by computing the Pearson correlation on the ranks of the entries [S6, unofficial].
- **Comparison:** Unlike Pearson which measures linear correlation, Spearman measures rank agreement, making it robust to non-linear but order-preserving distortions [S6, unofficial].

## Background
Similarity-based classification in volume rendering emerged from the need to handle high-dimensional data (such as hyperspectral or multivariate volumes) where scalar intensity alone is insufficient for semantic segmentation. Early work by Tzeng and Ma introduced discrete voxel classification based on multidimensional signatures, allowing users to define classes via merge/bipartition operations respecting voxel similarity [S3, unofficial]. The field expanded with the integration of machine learning, particularly self-supervised learning, where methods like S4 use Siamese networks to learn spatiotemporal proximity without labels [S4, unofficial]. More recently, the advent of differentiable rendering and neural radiance fields (NeRFs) has led to the use of Representational Similarity Analysis (RSA) and cosine similarity maps to align latent spaces with visual outputs, enabling interactive, annotation-driven transfer function design [S1][S2][S6, unofficial]. These methods are widely used in scientific visualization for exploring complex datasets, medical imaging for tissue segmentation, and computer graphics for material editing and retrieval.
