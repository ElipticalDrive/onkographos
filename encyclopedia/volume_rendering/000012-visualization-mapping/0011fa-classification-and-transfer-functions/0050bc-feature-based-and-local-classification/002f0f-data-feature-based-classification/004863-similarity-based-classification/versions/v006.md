# Similarity-based Classification

Also called: Similarity-based Transfer Functions, Feature Similarity Classification

## Overview
Similarity-based classification methods determine optical properties by measuring the distance or correlation between a sample point's feature vector and a set of reference exemplars, annotations, or database entries [S1][S2][S3, unofficial][S4, unofficial][S5, unofficial][S6, unofficial]. Unlike global intensity-based transfer functions that map scalar values directly to opacity, this family maps high-dimensional feature spaces or spatial relationships to classification labels or continuous similarity scores [S1]. It is distinct from [Curvature-based Transfer Function](5452-curvature-based-transfer-function.md) and [Shape-based Transfer Function Generation](5941-shape-based-transfer-function-generation.md) because it relies on explicit similarity metrics (e.g., Euclidean, Cosine, or learned latent distances) rather than local differential geometry or shape primitives [S1][S3, unofficial][S4, unofficial].

## Shared principles
All methods in this family evaluate a classification function $C(\mathbf{x})$ for each sample point $\mathbf{x}$ in the volume to produce optical properties [G].

**Input Domain:**
The input to the classification function is a feature vector $\mathbf{f}(\mathbf{x})$ associated with position $\mathbf{x}$. While basic methods use scalar intensity $v = f(\mathbf{x})$, this family extends the domain to include derived features such as gradient magnitude $\|\nabla f(\mathbf{x})\|$, curvature, shape descriptors, color components, or topological graph attributes [S1][S2][S3, unofficial][S4, unofficial].

**Output Range:**
The output is a set of optical properties, most commonly:
*   **Opacity ($\alpha$):** A value in $[0, 1]$ representing the probability of absorption or the inverse of transparency. $\alpha=0$ is fully transparent; $\alpha=1$ is fully opaque [S5, unofficial].
*   **Color ($C$):** A vector $(r, g, b)$ representing the emitted or reflected light color [S2][S4, unofficial].
*   **Weight:** In some emission-only models, a weight $w$ is assigned to modulate the contribution of samples during accumulation [S6, unofficial].

**Classification Types:**
1.  **Binary Classification:** Uses hard thresholds to include or exclude data [6229-binary-and-soft-classification.md]. Values below a threshold are assigned $\alpha=0$, and values above are assigned $\alpha=1$ (or a constant high value) [G].
2.  **Soft Classification:** Uses smooth transitions (e.g., piecewise linear ramps, Gaussian bumps, or power functions) to assign intermediate opacity values [S3, unofficial].

**Evaluation Order:**
The timing of classification relative to sampling interpolation defines two main approaches [S2][S5, unofficial]:
*   **Pre-classification:** The transfer function is applied to scalar values at the grid points (voxels) before sampling. Colors and opacities are interpolated during ray casting. Pre-classification produces blurred images when the image resolution is higher than the volume resolution, but prevents color bleeding if color interpolation is done with opacity-weighted colors [S2].
*   **Post-classification:** Scalar values are interpolated from the volume texture during ray casting, and the transfer function is applied to these continuous sample values. Post-classification produces images with defined edges but is prone to aliasing because high-frequency details may be missed [S2].

**Implementation Structures:**
Transfer functions are commonly implemented as piecewise linear functions defined by user-specified keypoints [S3, unofficial], lookup tables (LUTs) stored as 1D, 2D, or 3D textures for fast GPU sampling [S3, unofficial][S6, unofficial], or shader functions evaluated dynamically during ray casting [S5, unofficial].

## Subtopics

### [Range-Space Segmentation](13745-range-space-segmentation.md)
Range-Space Segmentation projects high-dimensional function samples into scalar fields based on their distance to user-defined exemplar functions. It solves the problem of segmenting complex datasets (e.g., hyperspectral imagery) by assigning each spatial point to the nearest exemplar, preserving spatial structure unlike MDS techniques. Choose this when analyzing function fields with multiple spectral or temporal bands where exemplars can be defined.

### [Representational Similarity Analysis (RSA)](14970-representational-similarity-analysis-rsa.md)
RSA evaluates the quality of a learned latent space by comparing the relational structure (pairwise similarities) of two sets of representations. Unlike pointwise measures, it assesses whether the manifold geometry is preserved across an entire set of views. Choose this for verifying self-supervised learning or differentiable rendering latent spaces against ground truth.

### [CNN-based Image Retrieval](15632-cnn-based-image-retrieval.md)
This method retrieves transfer functions by matching high-level spatial semantics extracted from co-planar images along a ray, rather than relying on 1D intensity profiles. It solves the problem of differentiating Segments of Interest (SOIs) that share intensity values but differ in shape or texture. Choose this when local intensity statistics are insufficient and deep learning features can capture regional semantics.

### Cosine Similarity Map Computation
Computes a similarity volume $S_L$ by comparing annotated feature vectors against the full feature volume $F$ using cosine similarity, enabling interactive feedback [S1].
*   **Formula:** $S_L^C = \max_{a \in A_C} \frac{1}{|F|} \sum_{i \in F} \frac{F_a \cdot F_i}{\|F_a\|_2 \|F_i\|_2}$ where $A_C$ is the set of annotations for class $C$, $F_a$ is the feature vector at annotation $a$, and $F_i$ is the feature vector at voxel $i$. Resulting $S_L^C \in [0, 1]^{W' \times H' \times D'}$ [S1].
*   **Proximity Scaling:** To select spatially local structures, the similarity map is scaled by $P(x) = \max_{a \in A_C} e^{-10\tilde{p}|x-a|}$, where $x$ is the location in $\mathbb{R}^3$ and $a$ is an annotation location [S1].
*   **Parameters:** Proximity parameter $\tilde{p} \in [0, 1]$ scales similarity based on distance to annotations [S1].
*   **Performance:** Computation takes a few milliseconds on CPU or GPU [S1].

### Thresholded Cosine Similarity Segmentation
Computes the probability of a query using thresholded cosine similarity instead of softmax with negative queries [S2].
*   **Step:** Set $p = 1$ if similarity exceeds threshold, $p = 0$ otherwise for hard decomposition [S2].

### Discrete Classification via Voxel Similarity
A discrete voxel classification technique for multidimensional signatures [S3, unofficial].
*   **Definition:** Users perform merge or bipartition operations on existing classes and define visual properties for each class [S3, unofficial].
*   **Steps:** 1. Preprocessing: Automatically establish initial classification respecting voxel similarity criteria. 2. User performs merge or bipartition operations on classes. 3. User defines visual properties for each class. 4. Bipartition operations are executed rapidly, respecting similarity criteria [S3, unofficial].

### S4 (Self-Supervised Spatiotemporal Similarity)
A self-supervised approach to spatiotemporal similarity learning using a Siamese neural network trained on a binary pretext task to predict spatial-temporal proximity, eliminating the need for labeled data [S4, unofficial].
*   **Steps:** 1. Train a Siamese neural network on a binary pretext task: predict if two spatiotemporal patches originate from nearby locations in space and time. 2. Use the resulting latent space for similarity queries. 3. Users supply example patches as a query; S4 ranks the rest of the ensemble by learned similarity [S4, unofficial].

### Trajectory Arrows Clustering
A clustering algorithm to select a representative subset of particle trajectories to display as arrows, based on similarity of pathlines over three time steps [S5, unofficial].
*   **Steps:** Select any pathline not already in a cluster to serve as the reference pathline. Examine all other pathlines not already in a cluster as candidates. If the similarity score between the reference pathline and the candidate pathline is less than a preset threshold, add the candidate to the cluster. After examining all candidates, output the reference pathline as the trajectory arrow for that cluster. Choose the next pathline not in a cluster and repeat the process. Filter out pathlines shorter than a preset threshold. Discard clusters that do not have a preset minimum number of pathlines [S5, unofficial].
*   **Formula:** Similarity Metric: The sum of squared distances between particle positions at each time step in the three-time-step window [S5, unofficial].
*   **Parameters:** Time Window: The number of time steps considered for trajectory similarity. Default: 3. Similarity Threshold: Determines cluster size. It is determined separately for each dataset based on distances between particles and can be changed interactively [S5, unofficial].

### Cosine Similarity
A similarity measure that factors out vector magnitude variations to focus on directional information in latent representations, computed via L2-normalization and inner product [S6, unofficial].
*   **Formula:** $\text{sim} = \hat{r}^T \hat{t} = \cos \theta$ [S6, unofficial].
*   **Parameters:** $\epsilon$: A small constant added for numerical stability in the denominator. $z$: A latent representation vector in $\mathbb{R}^d$ [S6, unofficial].

### Pearson Correlation
A linear correlation coefficient across feature dimensions of latent vectors, probing per-dimension structure agreement [S6, unofficial]. It detects poorly coordinated feature dimensions that high cosine similarity might miss [S6, unofficial].
*   **Formula:** $\rho_P = \frac{\sum_k (z_{\text{render},k} - \bar{z}_{\text{render}})(z_{\text{target},k} - \bar{z}_{\text{target}})}{\sqrt{\sum_k (z_{\text{render},k} - \bar{z}_{\text{render}})^2} \sqrt{\sum_k (z_{\text{target},k} - \bar{z}_{\text{target}})^2}}$ where $z_{\text{render},k}$ and $z_{\text{target},k}$ are the $k$-th feature dimensions of the rendered and target latent vectors, and $\bar{z}$ denotes their mean [S6, unofficial].
*   **Parameters:** $z_{\text{render}}, z_{\text{target}}$: Latent vectors in $\mathbb{R}^d$ [S6, unofficial].
*   **Comparison:** Unlike cosine similarity which measures aggregate direction, Pearson correlation measures the coordination of individual feature dimensions. A gap between Pearson ($\rho_P$) and Spearman ($\rho_S$) indicates if mismatch is driven by outlier dimensions (large gap) or systematic non-linear warp (small gap) [S6, unofficial].

### Spearman Correlation
A rank-based correlation coefficient that captures monotonic (possibly non-linear) agreement between feature dimensions [S6, unofficial]. It is the Pearson correlation computed on the ranks of the entries [S6, unofficial].
*   **Comparison:** Unlike Pearson which measures linear correlation, Spearman measures rank agreement, making it robust to non-linear but order-preserving distortions [S6, unofficial].

## Background
Similarity-based classification in volume rendering emerged from the need to handle multidimensional data (e.g., hyperspectral, time-varying, or multivariate scalar fields) where scalar intensity alone is insufficient for segmentation [S1][S3, unofficial]. Early work by Tzeng and Ma introduced discrete voxel classification based on multidimensional signatures, allowing users to merge or bipartition classes based on voxel similarity [S3, unofficial]. Later, the integration of deep learning features enabled methods like CNN-based image retrieval, which leverages pre-trained networks (e.g., AlexNet) to match spatial semantics across databases [S1]. More recently, self-supervised learning approaches (e.g., S4) and representational similarity analysis (RSA) have been applied to scientific visualization and differentiable rendering to evaluate latent spaces and perform similarity queries without labeled data [S4, unofficial][S6, unofficial].
