# CNN-based Image Retrieval

Also called: AlexNet retrieval, CNN-Based Image Matching, Image retrieval compartment

## Overview
This method retrieves transfer functions from a knowledge database by matching high-level spatial semantics extracted from co-planar images along a ray, rather than relying solely on 1D intensity profiles [S1]. It solves the problem of differentiating Segments of Interest (SOIs) that share similar intensity values but differ in shape, texture, or spatial relationships [S1]. Unlike sibling methods that use local intensity statistics, this approach leverages deep learning to capture regional image semantics [S1].

## How it works
**Inputs:**
*   **TIQ (Transfer Function Input Query):** A set of images extracted from the volume along a specific ray, containing two co-planar images aligned with primary axes and the 1D intensity profile along the ray [S1].
*   **Knowledge Database:** A collection of pre-labeled medical volume datasets, each associated with a known transfer function and its corresponding TIQ representation [S1].

**Outputs:**
*   **Retrieved Transfer Function:** The transfer function associated with the most similar image pair in the database [S1].
*   **Optical Properties:** Opacity ($\alpha$) and Color ($C$) values derived from the retrieved transfer function, applied to the volume samples [S1].

**Data Structures:**
*   **Image Pair:** Two 2D images ($I_1, I_2$) extracted from the volume, aligned with primary axes, with resolution $224 \times 224$ pixels [S1].
*   **Feature Vector:** A 4096-dimensional vector $\mathbf{f}$ extracted from the FC7 layer of the AlexNet network [S1].
*   **Database Index:** A mapping from image pairs to their corresponding transfer functions and feature vectors [S1].

**Algorithm Steps:**
1.  **Image Extraction:** Extract two co-planar images along the ray from the TIQ [S1].
2.  **Feature Extraction:** Pass each image through a pre-trained AlexNet network to produce a 4096-dimensional feature vector [S1].
3.  **Similarity Measurement:** Compare each query image with the corresponding database image aligned with the same primary axes, calculating the Euclidean distance between their CNN feature vectors [S1].
    $$ D(\mathbf{f}_{query}, \mathbf{f}_{db}) = \|\mathbf{f}_{query} - \mathbf{f}_{db}\|_2 $$
4.  **Retrieval:** Identify the top $N$ database entries with the smallest Euclidean distances [S1].
5.  **Re-ranking:** Re-rank the top $N$ results based on the similarity of 1D intensity profiles using Dynamic Time Warping to refine the selection [S1].
6.  **Transfer Function Application:** Retrieve the transfer function associated with the best-matching database entry and apply it to the volume samples along the ray to determine opacity and color [S1].

**Pseudocode:**
```python
def cnn_based_image_retrieval(query_images, database, alexnet_model):
    """
    query_images: List of two 2D arrays (224x224), representing co-planar images along a ray.
    database: List of tuples (db_images, db_tf, db_features), where db_images is a list of two arrays,
              db_tf is the transfer function, and db_features is the 4096-dim feature vector.
    alexnet_model: Pre-trained AlexNet model, outputting 4096-dim features from FC7.
    
    Returns:
    best_tf: The transfer function from the best matching database entry.
    """
    query_features = []
    for img in query_images:
        processed = preprocess_image(img)
        feat = alexnet_model.forward_fc7(processed)
        query_features.append(feat)

    distances = []
    for db_entry in database:
        db_images, db_tf, db_features = db_entry
        total_dist = 0.0
        for q_feat, db_feat in zip(query_features, db_features):
            total_dist += euclidean_distance(q_feat, db_feat)
        avg_dist = total_dist / len(query_features)
        distances.append((avg_dist, db_tf))

    distances.sort(key=lambda x: x[0])
    # [S1] Re-rank top N results using Dynamic Time Warping on 1D intensity profiles
    return distances[0][1]

def preprocess_image(image):
    # [G] Standard AlexNet preprocessing: resize to 224x224, normalize to ImageNet mean/std
    resized = resize_to_224(image)
    mean = [0.485, 0.456, 0.406]
    std = [0.229, 0.224, 0.225]
    h, w, c = len(resized), len(resized[0]), len(resized[0][0])
    normalized = [[(resized[i][j][k] - mean[k]) / std[k] for k in range(c)] for j in range(w) for i in range(h)]
    return normalized

def resize_to_224(image):
    # [G] Bilinear interpolation to 224x224
    h, w = len(image), len(image[0])
    scale_h, scale_w = h / 224.0, w / 224.0
    resized = [[image[int(i * scale_h)][int(j * scale_w)] for j in range(224)] for i in range(224)]
    return resized

def euclidean_distance(v1, v2):
    return sum((a - b) ** 2 for a, b in zip(v1, v2)) ** 0.5
```

**Parameters:**
*   **Network:** AlexNet, pre-trained on 1.2 million natural images from ImageNet [S1].
*   **Feature Dimension:** 4096 (from FC7 layer) [S1].
*   **Input Resolution:** $224 \times 224$ pixels [S1].
*   **Similarity Metric:** Euclidean Distance (ED) [S1].
*   **Top N:** Number of retrieval results to consider (value not specified in sources) [S1].

**Edge Cases and Pitfalls:**
*   **Domain Gap:** AlexNet is trained on natural images; deeper networks (GoogleNet, ResNet) yield lower recall on medical data due to overfitting to general image features [S1].
*   **Intensity Differentiation:** CNN features successfully differentiate SOIs with similar intensity values, which intensity profile retrieval alone cannot achieve [S1].
*   **Alignment:** Images must be aligned with the same primary axes for valid comparison [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** Achieved an average recall of 0.719 on medical images, outperforming GoogleNet and ResNet [S1].
*   **Strengths:** Provides regional image semantics (shapes, textures, spatial relationships), enabling differentiation of SOIs with similar intensity values [S1].
*   **Limitations:** Computationally intensive due to CNN inference; requires a pre-labeled knowledge database [S1].
*   **When to Use:** When SOIs have similar intensity profiles but distinct spatial structures or textures (e.g., artery vs. kidney in CT scans) [S1].
*   **When Not to Use:** Not given in the sources.

## Background
*   **Origin:** Proposed by Younhyun Jung et al. in "A Transfer Function Design for Medical Volume Data Using a Knowledge Database Based on Deep Image and Primitive Intensity Profile Features Retrieval" (2024) [S1].
*   **Development:** Builds upon earlier work using 1D intensity profile retrieval (DTW) [S1]. Developed to address limitations of intensity-only retrieval, which fails to distinguish SOIs with similar intensity values but different spatial characteristics [S1].
*   **Usage:** Applied in medical volume visualization for automatic transfer function design, specifically for segmenting organs like liver, bone, kidney, and spleen [S1].
