# Spearman Correlation

Also called: Spearman Rank Correlation Coefficient, Spearman's rank correlation coefficient

## Overview
Spearman Correlation is a similarity-based classification method that evaluates the monotonic agreement between feature dimensions by computing the Pearson correlation on the ranks of the entries [S1, unofficial]. Unlike Pearson correlation, which measures linear correlation, Spearman measures rank agreement, making it robust to non-linear but order-preserving distortions [S1, unofficial]. It is used in volume rendering to classify data based on the relative ordering of features rather than their absolute linear relationships [G].

## How it works
**Inputs and Outputs:**
*   **Input:** Two feature vectors, $\mathbf{z}_{render}$ and $\mathbf{z}_{target}$, each of dimension $d$ [G]. These vectors represent the feature values at a specific spatial location or across a set of samples [G].
*   **Output:** The Spearman rank correlation coefficient, $\rho_S$, a scalar value in $[-1, 1]$ [G].

**Data Structures:**
*   The method operates on arrays of floating-point numbers representing feature values [G].
*   Ranks are typically stored as integers or floats in an array of size $d$ [G].

**Steps:**
1.  **Rank Transformation:** Replace each value in $\mathbf{z}_{render}$ and $\mathbf{z}_{target}$ with its rank within its respective vector. Let $R(\mathbf{z})$ denote the vector of ranks. The rank of a value is its position when the vector is sorted in ascending order. Ties are typically handled by assigning the average rank of the tied values [G].
2.  **Compute Pearson Correlation on Ranks:** Calculate the Pearson correlation coefficient between the rank-transformed vectors $R(\mathbf{z}_{render})$ and $R(\mathbf{z}_{target})$ [G].

**Formula:**
Let $r_{i}$ be the rank of the $i$-th element in $\mathbf{z}_{render}$ and $s_{i}$ be the rank of the $i$-th element in $\mathbf{z}_{target}$. Let $\bar{r}$ and $\bar{s}$ be the mean ranks [G]. The Spearman correlation coefficient $\rho_S$ is defined as:

$$
\rho_S = \frac{\sum_{i=1}^{d} (r_i - \bar{r})(s_i - \bar{s})}{\sqrt{\sum_{i=1}^{d} (r_i - \bar{r})^2} \sqrt{\sum_{i=1}^{d} (s_i - \bar{s})^2}}
$$

Alternatively, if there are no ties, it can be computed using the sum of squared rank differences $D_i = r_i - s_i$:

$$
\rho_S = 1 - \frac{6 \sum_{i=1}^{d} D_i^2}{d(d^2 - 1)}
$$

**Parameters:**
*   $d$: The dimensionality of the feature vectors. Typical values depend on the feature space (e.g., number of spectral channels, gradient components) [G].

**Edge Cases and Pitfalls:**
*   **Ties:** If feature values are identical, their ranks must be averaged. The simple formula using $D_i^2$ is an approximation that becomes less accurate with many ties. The general Pearson-on-ranks formula is preferred for robustness [G].
*   **Constant Vectors:** If all values in a vector are identical, the variance is zero, and the correlation is undefined [G].
*   **Monotonicity:** Spearman correlation detects monotonic relationships. It will be 1 if one variable is a strictly increasing function of the other, regardless of the specific non-linear mapping [G].

**Pseudocode:**

```python
def get_ranks(values):
    """
    Computes ranks for a list of values, handling ties by averaging.
    Returns 1-based ranks as floats.
    """
    n = len(values)
    if n == 0:
        return []
    # Create list of (value, original_index)
    indexed_values = [(v, i) for i, v in enumerate(values)]
    # Sort by value
    indexed_values.sort(key=lambda x: x[0])
    
    ranks = [0.0] * n
    
    i = 0
    while i < n:
        # Find the range of ties
        j = i
        while j < n and indexed_values[j][0] == indexed_values[i][0]:
            j += 1
        
        # Average rank for the tied group (1-based)
        avg_rank = (i + 1 + j) / 2.0
        
        for k in range(i, j):
            original_index = indexed_values[k][1]
            ranks[original_index] = avg_rank
            
        i = j
        
    return ranks

def spearman_correlation(z_render, z_target):
    """
    Computes the Spearman rank correlation coefficient between two feature vectors.
    
    Args:
        z_render (list[float]): Feature values from the rendered volume.
        z_target (list[float]): Feature values from the target/reference volume.
        
    Returns:
        float: Spearman correlation coefficient.
    """
    n = len(z_render)
    if n != len(z_target):
        raise ValueError("Vectors must have the same length")
    if n < 2:
        return 0.0 # Undefined for single point, return 0 as default [G]

    # Step 1: Rank transformation
    ranks_render = get_ranks(z_render)
    ranks_target = get_ranks(z_target)

    # Step 2: Compute Pearson correlation on ranks
    mean_r = sum(ranks_render) / n
    mean_s = sum(ranks_target) / n

    numerator = 0.0
    denom_r = 0.0
    denom_s = 0.0

    for i in range(n):
        r_i = ranks_render[i]
        s_i = ranks_target[i]
        
        diff_r = r_i - mean_r
        diff_s = s_i - mean_s
        
        numerator += diff_r * diff_s
        denom_r += diff_r ** 2
        denom_s += diff_s ** 2

    denominator = (denom_r * denom_s) ** 0.5
    
    if denominator == 0:
        return 0.0 # Undefined if variance is zero [G]
        
    return numerator / denominator
```

## Subtopics

### Partial Spearman Correlation
A statistical method to determine if the association between cross-seed instability ($\sigma_{ens}$) and ensemble mean error ($\epsilon_{mean}$) persists after controlling for an oracle inverse-emissivity proxy ($\bar{E}$), treating low-emissivity regions as a signal-strength confound [S2, unofficial]. It is chosen when one needs to isolate the rank-based relationship between two variables by removing the influence of a third confounding variable [G]. The method involves rank-transforming all three variables and computing the standard partial Pearson correlation on the ranks [S2, unofficial]. The formula is:
$$
\rho(\sigma_{ens}, \epsilon_{mean} | \bar{E}) = \frac{\rho(\sigma_{ens}, \epsilon_{mean}) - \rho(\sigma_{ens}, \bar{E})\rho(\bar{E}, \epsilon_{mean})}{\sqrt{(1 - \rho^2(\sigma_{ens}, \bar{E}))(1 - \rho^2(\bar{E}, \epsilon_{mean}))}}
$$
A strong positive partial correlation indicates a nontrivial linear association between the rank-transformed $\sigma_{ens}$ and $\epsilon_{mean}$, after linear adjustment for the rank-transformed $\bar{E}$ proxy [S2, unofficial]. A pitfall is that mismatch conditions intentionally retain the nominal, unscaled Ground Truth (GT) emissivity for $\bar{E}$ to ensure it remains an oracle probe of the underlying physical signal rather than an observation-consistent proxy [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(d \log d)$ due to the sorting step required for rank transformation, where $d$ is the feature dimension. The subsequent Pearson correlation is $O(d)$ [G].
*   **Memory Complexity:** $O(d)$ to store the rank vectors [G].
*   **Strengths:** Robust to non-linear monotonic relationships. Does not assume linearity or normality of the data distribution. Effective when the relationship between features is consistent in order but not in magnitude [G].
*   **Limitations:** Less powerful than Pearson correlation if the relationship is truly linear and the data is normally distributed. Sensitive to ties. Does not capture non-monotonic relationships (e.g., U-shaped) [G].
*   **When to use:** When the feature dimensions have a monotonic but potentially non-linear relationship, or when the data contains outliers that would distort linear correlation [G].
*   **When not to use:** When the relationship is known to be linear and Gaussian, or when non-monotonic relationships are of interest [G].

## Background
Spearman correlation is a rank-based correlation coefficient introduced by Charles Spearman [G]. In the context of volume rendering and 3D scene understanding, it is used as a metric to probe vision models by comparing rendered features against target features [S1, unofficial]. It is distinct from cosine similarity (which measures direction) and Pearson correlation (which measures linear co-variation) [S1, unofficial]. It probes a stricter notion of equivalence than cosine, as a reconstruction can align in aggregate direction (high cosine) yet have poorly coordinated feature dimensions (low Pearson) [S1, unofficial]. The gap between Pearson and Spearman correlation can indicate whether a mismatch is driven by outlier dimensions or systematic non-linear warps [S1, unofficial].
