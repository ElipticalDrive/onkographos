# Representational Similarity Analysis (RSA)


## Overview
Representational Similarity Analysis (RSA) is a method for evaluating the quality of a learned latent space by comparing the relational structure (manifold geometry) of two sets of representations against each other [S1, unofficial]. Unlike pointwise similarity measures that assess individual latent codes in isolation, RSA assesses whether the pairwise similarity structure across an entire set of views is preserved [S1, unofficial]. It is primarily used in the context of self-supervised learning and differentiable rendering to verify if a reconstructed latent space captures the same representational organization as a ground-truth or reference space [S1, unofficial].

## How it works
**Inputs:**
*   Two sets of latent vectors representing the same $N$ views (e.g., images or scenes). Let $m \in \{1, 2\}$ denote the two representational spaces.
*   For each view $i \in \{1, \dots, N\}$, let $z_i^{(m)} \in \mathbb{R}^{d_m}$ be the latent vector produced by model $g_m$ for input $x_i$ [S1, unofficial].

**Outputs:**
*   A scalar RSA score $\rho_{RSA}$, which is the Pearson correlation coefficient between the dissimilarity structures of the two spaces [S1, unofficial].

**Data Structures:**
*   **Latent Vectors:** $z_i^{(m)}$ of dimension $d_m$.
*   **Normalized Vectors:** $\hat{z}_i^{(m)}$ of dimension $d_m$.
*   **Representational Similarity Matrix (RSM):** $S^{(m)} \in \mathbb{R}^{N \times N}$.
*   **Dissimilarity Matrix:** $D^{(m)} \in \mathbb{R}^{N \times N}$.

**Steps:**

1.  **L2-Normalization:** Map each latent vector onto the unit hypersphere to ensure scale invariance. For each $i$ and $m$:
    $$ \hat{z}_i^{(m)} = \frac{z_i^{(m)}}{\|z_i^{(m)}\|_2 + \epsilon} $$
    where $\epsilon$ is a small constant to prevent division by zero [S1, unofficial].

2.  **Construct RSM:** For each representational space $m$, compute the pairwise cosine similarities between all normalized latent vectors. The entry $S_{ij}^{(m)}$ is defined as:
    $$ S_{ij}^{(m)} = k(\hat{z}_i^{(m)}, \hat{z}_j^{(m)}) = (\hat{z}_i^{(m)})^\top \hat{z}_j^{(m)} $$
    where $k(a, b) = a^\top b$ is the dot product, serving as the cosine similarity since vectors are normalized [S1, unofficial].

3.  **Compute Dissimilarity Matrix:** Convert the similarity matrix to a dissimilarity matrix $D^{(m)}$ using:
    $$ D_{ij}^{(m)} = 1 - S_{ij}^{(m)} $$
    This transforms the similarity metric into a distance-like metric where higher values indicate greater dissimilarity [S1, unofficial].

4.  **Vectorize Upper Triangular Entries:** Extract the off-diagonal entries from the upper triangular part of both dissimilarity matrices. Let $\text{vec}_{\triangle}(\cdot)$ denote this operation. This yields two vectors of length $N(N-1)/2$ [S1, unofficial].

5.  **Calculate RSA Score:** Compute the Pearson correlation coefficient between the vectorized dissimilarity matrices:
    $$ \rho_{RSA} = \text{corr}(\text{vec}_{\triangle} D^{(1)}, \text{vec}_{\triangle} D^{(2)}) $$
    A high $\rho_{RSA}$ indicates that pairs of views that are similar (or dissimilar) in one latent space tend to be similarly related in the other, implying the two spaces encode a similar representational structure [S1, unofficial].

**Pseudocode:**

```python
import numpy as np

def representational_similarity_analysis(z1, z2, epsilon=1e-8):
    """
    Compute the RSA score between two sets of latent vectors.
    
    Args:
        z1: numpy array of shape (N, d1), latent vectors for space 1.
        z2: numpy array of shape (N, d2), latent vectors for space 2.
        epsilon: small constant for numerical stability.
        
    Returns:
        rho_rsa: float, the Pearson correlation coefficient of dissimilarity matrices.
    """
    N = z1.shape[0]
    
    # Step 1: L2-Normalization
    # Normalize each vector in z1
    norms1 = np.linalg.norm(z1, axis=1, keepdims=True)
    z1_hat = z1 / (norms1 + epsilon)
    
    # Normalize each vector in z2
    norms2 = np.linalg.norm(z2, axis=1, keepdims=True)
    z2_hat = z2 / (norms2 + epsilon)
    
    # Step 2: Construct RSM (Cosine Similarity)
    # S1 is N x N
    S1 = np.dot(z1_hat, z1_hat.T)
    # S2 is N x N
    S2 = np.dot(z2_hat, z2_hat.T)
    
    # Step 3: Compute Dissimilarity Matrix
    D1 = 1.0 - S1
    D2 = 1.0 - S2
    
    # Step 4: Vectorize upper triangular (off-diagonal) entries
    # Get indices for the upper triangle excluding the diagonal
    idx_i, idx_j = np.triu_indices(N, k=1)
    
    vec_D1 = D1[idx_i, idx_j]
    vec_D2 = D2[idx_i, idx_j]
    
    # Step 5: Calculate Pearson correlation
    # corr(a, b) = cov(a, b) / (std(a) * std(b))
    mean_D1 = np.mean(vec_D1)
    mean_D2 = np.mean(vec_D2)
    
    diff_D1 = vec_D1 - mean_D1
    diff_D2 = vec_D2 - mean_D2
    
    cov = np.mean(diff_D1 * diff_D2)
    std_D1 = np.std(vec_D1)
    std_D2 = np.std(vec_D2)
    
    if std_D1 == 0 or std_D2 == 0:
        return 0.0 # Avoid division by zero if variance is zero
        
    rho_rsa = cov / (std_D1 * std_D2)
    
    return rho_rsa
```

**Parameters:**
*   $\epsilon$: Small constant for numerical stability in normalization. Typical value: $10^{-8}$ [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Autocorrelation in Training Trajectories:** RSA collapses across all views into a single scalar per epoch. Consequently, the resulting training trajectory is strongly autocorrelated [S1, unofficial].
*   **Statistical Testing Error:** Treating training steps as independent observations for statistical testing (e.g., calculating Bayes factors) would inflate the effective sample size and yield spuriously decisive evidence [S1, unofficial]. RSA scores should not be used for per-step statistical inference in the same way as per-view metrics [S1, unofficial].

## Operating characteristics
*   **Complexity:** The construction of the RSM requires $O(N^2 d)$ operations for normalization and dot products, where $N$ is the number of views and $d$ is the latent dimension. The correlation step is $O(N^2)$.
*   **Strengths:** It provides a global perspective on the latent space geometry, ensuring that the relational structure is preserved, which is crucial for tasks where relative positioning of data points matters more than absolute code values [S1, unofficial].
*   **Limitations:** It is a global metric and does not provide pointwise error estimates. It is sensitive to the choice of views $N$; if the views are not representative, the correlation may be misleading.
*   **When to use:** When evaluating self-supervised representations or differentiable rendering reconstructions where the goal is to preserve the manifold structure of the data [S1, unofficial].
*   **When not to use:** When pointwise accuracy of individual latent codes is the primary concern, or when performing statistical hypothesis testing on training dynamics due to autocorrelation issues [S1, unofficial].

## Background
Representational Similarity Analysis (RSA) was originally introduced in cognitive neuroscience to compare neural representations [S1, unofficial]. In the context of computer graphics and machine learning, it has been adapted to evaluate latent spaces in self-supervised learning and differentiable rendering. Specifically, it is used in frameworks like MRD (MRD: Using Physically Based Differentiable Rendering to Probe Vision Models for 3D Scene Understanding) to assess whether a reconstructed latent space captures the same representational organization as a ground-truth space [S1, unofficial]. It complements pointwise similarity measures by focusing on the geometry of the manifold induced over a set of views [S1, unofficial].
