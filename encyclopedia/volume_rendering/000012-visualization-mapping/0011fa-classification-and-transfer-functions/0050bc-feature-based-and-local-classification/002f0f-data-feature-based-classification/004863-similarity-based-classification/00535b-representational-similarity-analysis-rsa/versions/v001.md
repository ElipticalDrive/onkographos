# Representational Similarity Analysis (RSA)
## Overview
Representational Similarity Analysis (RSA) evaluates the relational structure (geometry of the manifold) induced over a set of views, complementing pointwise similarity measures [S1, unofficial]. It assesses whether a reconstructed latent space captures the same representational organization as a ground-truth space by correlating their pairwise similarity structures [S1, unofficial]. Unlike pointwise metrics that align individual codes, RSA ensures the global geometry of the manifold is preserved [S1, unofficial].
## How it works
**Inputs:** Two sets of latent vectors representing the same $N$ views, generated by two different representational spaces (e.g., a reconstruction model and a baseline). Let $z_i^{(1)} \in \mathbb{R}^{d_1}$ and $z_i^{(2)} \in \mathbb{R}^{d_2}$ be the latent vectors for view $i$ from space 1 and space 2 respectively, for $i = 1, \dots, N$.
**Outputs:** A scalar RSA score $\rho_{RSA}$ representing the Pearson correlation between the dissimilarity structures of the two spaces.

**Data Structures:**
*   Latent vectors: $z^{(m)}$ for $m \in \{1, 2\}$.
*   Representational Similarity Matrix (RSM): $S^{(m)} \in \mathbb{R}^{N \times N}$.
*   Dissimilarity Matrix: $D^{(m)} \in \mathbb{R}^{N \times N}$.

**Steps:**
1.  **Normalization:** Map each latent vector onto the unit hypersphere using L2-normalization with a small epsilon $\epsilon$ for numerical stability [S1, unofficial]:
    $$ \hat{z}_i^{(m)} = \frac{z_i^{(m)}}{\|z_i^{(m)}\|_2 + \epsilon} $$
2.  **RSM Construction:** For each representational space $m$, construct the RSM $S^{(m)}$ where entries are the cosine similarities between normalized vectors [S1, unofficial]:
    $$ S_{ij}^{(m)} = k(\hat{z}_i^{(m)}, \hat{z}_j^{(m)}) = (\hat{z}_i^{(m)})^\top \hat{z}_j^{(m)} $$
    where $1 \le i, j \le N$.
3.  **Dissimilarity Matrix:** Define the dissimilarity matrix $D^{(m)}$ as [S1, unofficial]:
    $$ D_{ij}^{(m)} = 1 - S_{ij}^{(m)} $$
4.  **Vectorization:** Extract the upper triangular (off-diagonal) entries from both $D^{(1)}$ and $D^{(2)}$ and vectorize them using $\text{vec}_{\triangle}(\cdot)$ [S1, unofficial].
5.  **Correlation:** Compute the RSA score $\rho_{RSA}$ as the Pearson correlation coefficient between the two vectorized dissimilarity matrices [S1, unofficial]:
    $$ \rho_{RSA} = \text{corr}(\text{vec}_{\triangle} D^{(1)}, \text{vec}_{\triangle} D^{(2)}) $$

**Parameters:**
*   $\epsilon$: Small constant for numerical stability. Not given in the sources.

**Pitfalls:**
*   **Autocorrelation:** RSA collapses across all views into a single scalar per epoch. The resulting training trajectory is strongly autocorrelated [S1, unofficial]. Treating training steps as independent observations for statistical testing (e.g., Bayes factor) inflates the effective sample size and yields spuriously decisive evidence [S1, unofficial].
*   **Exchangeability:** Unlike per-view scores which are approximately exchangeable under the null hypothesis, RSA scores do not have semantically grounded pairings between epochs, making standard independent statistical tests invalid [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def representational_similarity_analysis(z1, z2, epsilon=1e-8):
    """
    Compute RSA score between two sets of latent vectors.
    
    Args:
        z1: numpy array of shape (N, d1), latent vectors for space 1.
        z2: numpy array of shape (N, d2), latent vectors for space 2.
        epsilon: float, small constant for numerical stability.
        
    Returns:
        rho_rsa: float, Pearson correlation of dissimilarity matrices.
    """
    N = z1.shape[0]
    
    # Step 1: L2-normalization
    # Add epsilon to denominator to avoid division by zero
    norm1 = np.linalg.norm(z1, axis=1, keepdims=True) + epsilon
    z1_hat = z1 / norm1
    
    norm2 = np.linalg.norm(z2, axis=1, keepdims=True) + epsilon
    z2_hat = z2 / norm2
    
    # Step 2: Construct RSMs (Cosine Similarity)
    # S_m[i, j] = dot(z_hat_i, z_hat_j)
    S1 = z1_hat @ z1_hat.T
    S2 = z2_hat @ z2_hat.T
    
    # Step 3: Dissimilarity Matrices
    D1 = 1.0 - S1
    D2 = 1.0 - S2
    
    # Step 4: Vectorize upper triangular off-diagonal entries
    # Indices i < j
    rows, cols = np.triu_indices(N, k=1)
    vec_D1 = D1[rows, cols]
    vec_D2 = D2[rows, cols]
    
    # Step 5: Pearson Correlation
    # corr(a, b) = cov(a, b) / (std(a) * std(b))
    mean1 = np.mean(vec_D1)
    mean2 = np.mean(vec_D2)
    
    diff1 = vec_D1 - mean1
    diff2 = vec_D2 - mean2
    
    cov = np.mean(diff1 * diff2)
    std1 = np.std(vec_D1, ddof=0) # Population std for correlation
    std2 = np.std(vec_D2, ddof=0)
    
    if std1 == 0 or std2 == 0:
        return 0.0 # Or handle as undefined
        
    rho_rsa = cov / (std1 * std2)
    
    return rho_rsa
```
## Operating characteristics
**Time Complexity:** $O(N^2 d)$ for normalization and RSM construction, where $N$ is the number of views and $d$ is the latent dimension. Vectorization and correlation are $O(N^2)$.
**Memory Complexity:** $O(N^2)$ to store the RSMs and dissimilarity matrices.
**Strengths:** Provides a global perspective on representational geometry, ensuring that the relational structure of the manifold is preserved, not just individual code alignment [S1, unofficial].
**Limitations:** Produces a single scalar per evaluation, losing per-view granularity. The resulting metric is strongly autocorrelated in sequential evaluations (e.g., training epochs), complicating statistical inference [S1, unofficial].
**When to use:** When assessing whether a reconstructed latent space captures the same representational organization as a ground-truth space [S1, unofficial].
**When not to use:** When per-view statistical independence is required or when evaluating simple pointwise alignment without regard to relational structure.
## Background
RSA was introduced as a higher-level measure to complement unit hypersphere similarity in the context of probing vision models for 3D scene understanding using physically based differentiable rendering [S1, unofficial]. It addresses the need to verify if the geometry of the manifold is preserved in reconstructed latent spaces [S1, unofficial].
