# Shape Attribute

Also called: Forma

## Overview
Shape Attribute is a data feature-based classification operator that discriminates volumetric objects by analyzing their local geometric structure through three shape aspects: tubiness (cylindrical), surfaceness (planar), and blobbiness (spherical) [S1, unofficial]. It is prepared on segmented volumes to enable intuitive transfer function design based on object morphology rather than intensity alone [S1, unofficial]. It differs from intensity-based or size-based transfer functions by focusing on the topological shape of the underlying data features [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A segmented volume dataset.
- Output: A scalar field representing the shape attributes (tubiness, surfaceness, blobbiness) for each voxel, which can be mapped to color and opacity in a transfer function.

**Data Structures:**
- The method operates on the local neighborhood of each voxel.
- For tensor-based implementations (Geometric Anisotropy Metrics), the input is a diffusion tensor $D$ at each voxel.
- The tensor $D$ is a $3 \times 3$ symmetric positive-definite matrix.
- The output consists of three scalar values $(c_l, c_p, c_s)$ per voxel, representing linear, planar, and spherical certainty, respectively.

**Steps:**
1. **Segmentation:** Prepare the volume by segmenting the regions of interest. The operator requires pre-segmented data [S1, unofficial].
2. **Tensor Estimation (if using Geometric Anisotropy Metrics):** Compute the diffusion tensor $D$ for each voxel. This tensor characterizes the local orientation and shape of the data structure [S2, unofficial].
3. **Eigenvalue Decomposition:** Compute the eigenvalues $\lambda_1, \lambda_2, \lambda_3$ of the tensor $D$.
4. **Sorting:** Sort the eigenvalues in descending order: $\lambda_1 \ge \lambda_2 \ge \lambda_3 \ge 0$ [S2, unofficial].
5. **Shape Metric Calculation:** Calculate the three barycentric coordinates using the sorted eigenvalues [S2, unofficial]:
   - Linear certainty (tubiness):
     $$c_l = \frac{\lambda_1 - \lambda_2}{\lambda_1 + \lambda_2 + \lambda_3}$$
   - Planar certainty (surfaceness):
     $$c_p = \frac{2(\lambda_2 - \lambda_3)}{\lambda_1 + \lambda_2 + \lambda_3}$$
   - Spherical certainty (blobbiness):
     $$c_s = \frac{3\lambda_3}{\lambda_1 + \lambda_2 + \lambda_3}$$
6. **Mapping:** Map the resulting $(c_l, c_p, c_s)$ values to the transfer function space. These coordinates form a triangular domain where each vertex represents a pure shape (linear, planar, or spherical) [S2, unofficial].

**Parameters:**
- Eigenvalue sorting order: Descending ($\lambda_1 \ge \lambda_2 \ge \lambda_3$) [S2, unofficial].
- Normalization: The denominator $\lambda_1 + \lambda_2 + \lambda_3$ is the trace of the tensor. If the trace is zero, the shape is undefined (degenerate case) [G].

**Edge Cases and Pitfalls:**
- **Degenerate Tensors:** If $\lambda_1 = \lambda_2 = \lambda_3 = 0$, the denominator is zero. This occurs in empty space or non-segmented regions. The shape attributes should be set to a default value (e.g., $(0,0,0)$ or $(1/3, 1/3, 1/3)$) or ignored [G].
- **Precision:** Numerical stability in eigenvalue decomposition is critical for noisy data. Small perturbations in eigenvalues can significantly alter the shape metrics, especially when eigenvalues are close [G].
- **Segmentation Dependency:** The method relies on accurate segmentation. Poor segmentation leads to incorrect tensor estimation and misleading shape attributes [S1, unofficial].

**Pseudocode:**
```python
def compute_shape_attributes(tensor):
    """
    Computes tubiness, surfaceness, and blobbiness from a 3x3 diffusion tensor.
    
    Args:
        tensor: A 3x3 numpy array representing the diffusion tensor D.
        
    Returns:
        A tuple (c_l, c_p, c_s) representing linear, planar, and spherical certainty.
    """
    # Step 1: Eigenvalue decomposition
    # D is symmetric, so we use eigh for stability
    eigenvalues = np.linalg.eigvalsh(tensor)
    
    # Step 2: Sort eigenvalues in descending order
    # eigh returns sorted in ascending order, so reverse
    eigenvalues = np.sort(eigenvalues)[::-1]
    lambda_1, lambda_2, lambda_3 = eigenvalues
    
    # Step 3: Calculate trace
    trace = lambda_1 + lambda_2 + lambda_3
    
    # Edge case: Handle degenerate tensors (zero trace)
    if trace == 0:
        return (0.0, 0.0, 0.0)
    
    # Step 4: Calculate shape metrics
    # Linear certainty (tubiness)
    c_l = (lambda_1 - lambda_2) / trace
    
    # Planar certainty (surfaceness)
    c_p = 2.0 * (lambda_2 - lambda_3) / trace
    
    # Spherical certainty (blobbiness)
    c_s = 3.0 * lambda_3 / trace
    
    return (c_l, c_p, c_s)
```

## Subtopics

### Geometric Anisotropy Metrics (Shape Domain)
A set of three barycentric coordinates $(c_l, c_p, c_s)$ that characterize a tensor's shape within a triangular domain, representing linear, planar, and spherical certainty [S2, unofficial]. It is based on the eigenvalues of the diffusion tensor and provides a rotationally invariant description of local structure [S2, unofficial]. Choose this when you need a mathematically rigorous, orientationless shape descriptor for tensor fields, such as in diffusion MRI or vector field visualization [S2, unofficial]. It is the mathematical foundation for the tubiness/surfaceness/blobbiness classification in Shape Attribute [S2, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the number of voxels, assuming tensor estimation is precomputed. Eigenvalue decomposition of a $3 \times 3$ matrix is constant time per voxel.
- **Memory Complexity:** $O(N)$ to store the tensor field and the resulting shape attribute volumes.
- **Strengths:** Intuitive mapping of complex 3D structures to a 2D triangular domain; rotationally invariant; separates shape from orientation [S2, unofficial].
- **Limitations:** Requires segmented data or accurate tensor estimation; sensitive to noise in eigenvalue computation; does not capture global topology [S1, unofficial].
- **When to Use:** When visualizing structures with distinct geometric shapes (tubes, surfaces, blobs) in segmented volumes [S1, unofficial].
- **When Not to Use:** For unsegmented data without reliable tensor estimation; when global context is more important than local shape [S1, unofficial].

## Background
Shape Attribute, also known as Forma, was proposed by Praßni et al. in 2010 as a transfer function based on shape [S1, unofficial]. It builds on the concept of geometric anisotropy metrics introduced by Westin et al. [WPG+97] for tensor visualization [S2, unofficial]. The method is used in medical volume rendering, particularly for visualizing anatomical structures like blood vessels (tubiness) and membranes (surfaceness) [S1, unofficial]. It is part of the broader family of data feature-based classification methods in volume rendering [S1, unofficial].
