# Barycentric Opacity Mapping

Also called: Barycentric Color Map

## Overview
Barycentric Opacity Mapping is a feature-based classification technique that uses three barycentric coordinates derived from the eigenvalues of a symmetric tensor to control opacity in volume rendering [S1, S2, unofficial]. It emphasizes important structural features (linear and planar anisotropy) while making unimportant regions (isotropic diffusion) transparent [S1, unofficial]. Unlike general scalar transfer functions, it maps the shape of the diffusion tensor directly to a 2D barycentric space, allowing distinct visual separation of isotropic, linear, and planar diffusion regimes [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A symmetric $3 \times 3$ diffusion tensor $T$ at a voxel.
*   **Output:** An opacity value $\alpha$ (and optionally color) for the voxel, determined by the barycentric coordinates of the tensor's eigenvalues.

**Data Structures:**
*   **Tensor:** A $3 \times 3$ symmetric matrix.
*   **Eigenvalues:** Three real numbers $\lambda_1, \lambda_2, \lambda_3$.
*   **Barycentric Coordinates:** Three values $c_l, c_p, c_s$ (or $\lambda_l, \lambda_p, \lambda_s$) summing to 1.

**Steps:**
1.  **Diagonalization:** Compute the three real eigenvalues of the symmetric diffusion tensor $T$.
2.  **Sorting:** Order the eigenvalues such that $\lambda_1 \geq \lambda_2 \geq \lambda_3$ [S1, S2, unofficial].
3.  **Coordinate Calculation:** Compute the three barycentric coordinates representing linear anisotropy ($c_l$), planar anisotropy ($c_p$), and isotropy ($c_s$) using the formulas below [S1, S2, unofficial].
4.  **Transfer Function Lookup:** Use the coordinates $(c_l, c_p, c_s)$ to sample an opacity transfer function. Typically, high opacity is assigned to regions with high $c_l$ or $c_p$ (significant anisotropy), and low opacity to regions with high $c_s$ (isotropy) [S1, unofficial].

**Formulas:**
Let $\lambda_1, \lambda_2, \lambda_3$ be the ordered eigenvalues. The sum of eigenvalues is $S = \lambda_1 + \lambda_2 + \lambda_3$.

Linear anisotropy coordinate:
$$c_l = \frac{\lambda_1 - \lambda_2}{\lambda_1 + \lambda_2 + \lambda_3}$$

Planar anisotropy coordinate:
$$c_p = \frac{2(\lambda_2 - \lambda_3)}{\lambda_1 + \lambda_2 + \lambda_3}$$

Isotropy coordinate:
$$c_s = \frac{3\lambda_3}{\lambda_1 + \lambda_2 + \lambda_3}$$

Note: $c_l + c_p + c_s = 1$. The coordinates form a point in a 2D barycentric triangle where the vertices represent pure linear, pure planar, and pure isotropic diffusion, respectively [S2, unofficial].

**Parameters:**
*   **Eigenvalues:** Must be real (guaranteed for symmetric tensors).
*   **Thresholds:** Not specified in the core definition, but practical implementations often filter noise by checking if $\lambda_{mean} > \epsilon$ or if anisotropy indices exceed a threshold [S2, G, unofficial].

**Edge Cases and Pitfalls:**
*   **Zero Denominator:** If $\lambda_1 + \lambda_2 + \lambda_3 = 0$ (e.g., all eigenvalues are zero), the coordinates are undefined. A small epsilon or a default isotropic value should be used [G].
*   **Numerical Stability:** When eigenvalues are very close (near-isotropic), floating-point errors may cause $c_l$ or $c_p$ to be slightly negative or positive due to precision limits. Clamping to $[0, 1]$ is recommended [G].
*   **Ordering:** Incorrect ordering of eigenvalues will swap the meaning of $c_l$ and $c_p$, leading to incorrect classification of linear vs. planar structures [S1, S2, unofficial].

**Pseudocode:**
```python
def barycentric_opacity_mapping(tensor):
    """
    Computes barycentric coordinates for a 3x3 symmetric diffusion tensor.
    Returns (c_l, c_p, c_s).
    """
    # 1. Compute eigenvalues of the symmetric 3x3 tensor
    # Note: In practice, use a robust symmetric eigensolver.
    eigenvalues = compute_eigenvalues_symmetric_3x3(tensor)
    
    # 2. Sort eigenvalues: lambda_1 >= lambda_2 >= lambda_3
    eigenvalues.sort(reverse=True)
    lambda_1 = eigenvalues[0]
    lambda_2 = eigenvalues[1]
    lambda_3 = eigenvalues[2]
    
    # 3. Compute sum of eigenvalues
    sum_eigenvalues = lambda_1 + lambda_2 + lambda_3
    
    # 4. Handle zero sum to avoid division by zero
    if sum_eigenvalues == 0:
        # Default to isotropic if tensor is zero
        return (0.0, 0.0, 1.0)
    
    # 5. Compute barycentric coordinates
    # Linear anisotropy
    c_l = (lambda_1 - lambda_2) / sum_eigenvalues
    
    # Planar anisotropy
    c_p = 2.0 * (lambda_2 - lambda_3) / sum_eigenvalues
    
    # Isotropy
    c_s = 3.0 * lambda_3 / sum_eigenvalues
    
    # 6. Clamp to [0, 1] to handle numerical noise
    c_l = max(0.0, min(1.0, c_l))
    c_p = max(0.0, min(1.0, c_p))
    c_s = max(0.0, min(1.0, c_s))
    
    return (c_l, c_p, c_s)
```

## Subtopics

### Barycentric Color Map
A variant that maps the barycentric coordinates to color rather than just opacity, visualizing the shape of diffusion directly [S2, unofficial].

### Lit-tensors
An illumination-based technique that interpolates between linear (streamline-like) and planar (surface-shading) lighting models based on the same anisotropy indices [S1, unofficial].

### Hyperstreamlines
A geometric visualization method that segments streamlines based on anisotropy and mean diffusivity thresholds, often using similar eigenvalue criteria [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Dominated by the eigenvalue decomposition of the $3 \times 3$ symmetric tensor, which is $O(1)$ per voxel. The coordinate calculation is also $O(1)$.
*   **Memory Complexity:** $O(1)$ auxiliary memory per voxel for storing eigenvalues and coordinates.
*   **Strengths:** Intuitively separates isotropic noise from meaningful linear (fiber) and planar (sheet) structures. Provides a compact 2D representation of tensor shape.
*   **Limitations:** Sensitive to noise in eigenvalue estimation. Does not encode direction, only shape. Requires accurate tensor estimation [S1, S2, unofficial].
*   **When to use:** Diffusion tensor imaging (DTI) visualization where distinguishing fiber tracts (linear) from sheet-like structures (planar) from isotropic regions (CSF, gray matter) is critical [S1, S2, unofficial].

## Background
Barycentric mapping for tensor shape exploration was developed as a method to visualize the geometric shape of diffusion tensors in medical imaging, particularly Diffusion Tensor Imaging (DTI) [S1, S2, unofficial]. The technique leverages the fact that the eigenvalues of a symmetric tensor can be mapped to a barycentric coordinate system, where the vertices represent the three canonical tensor shapes: linear, planar, and isotropic [S2, unofficial]. This approach was introduced to provide a more intuitive and feature-based classification than scalar transfer functions, allowing users to emphasize specific structural features while suppressing isotropic noise [S1, unofficial]. It is commonly used in conjunction with volume rendering and tensor ellipsoid visualization [S1, S2, unofficial].
