# Barycentric Mapping for Tensor Shape Exploration

Also called: Barycentric Shape Mapping, Tensor Anisotropy Barycentric Mapping

## Overview
Barycentric Mapping is an affine projection method that maps high-dimensional tensor anisotropy indices onto a 2D hyper-plane to drive interactive opacity and color transfer functions [S1]. It solves the problem of visualizing specific geometric shapes (linear, planar, spherical) within tensor fields by allowing users to select regions in a 2D barycentric space, which is more intuitive than manipulating multi-dimensional transfer functions directly [S1]. Unlike standard eigenvalue thresholding, it leverages the geometric relationship between shape indices ($c_p, c_l, c_s$) to highlight structural features in synthetic and Diffusion Weighted Imaging (DWI) data [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A symmetric tensor field (e.g., structure tensors or diffusion tensors) where each voxel contains a $3 \times 3$ symmetric matrix.
*   **Output:** A 2D vector $\mathbf{v}$ used to index a 2D opacity transfer function $\alpha_b(\mathbf{v})$ and a 2D color lookup table (LUT).

**Data Structures:**
*   **Tensor:** $3 \times 3$ symmetric matrix.
*   **Eigenvalues:** $\lambda_1, \lambda_2, \lambda_3$ sorted such that $\lambda_1 > \lambda_2 > \lambda_3$ [S1].
*   **Anisotropy Indices:** Three scalar values $c_p, c_l, c_s$ satisfying $c_p + c_l + c_s = 1$ [S1].
*   **Mapping Vector:** $\mathbf{v} = (v_x, v_y)^T$ where $v_x = 1 - c_l - 0.5c_s$ and $v_y = c_s$ [S1].

**Steps:**
1.  **Compute Eigenvalues:** For each tensor, calculate the three real eigenvalues $\lambda_1, \lambda_2, \lambda_3$ and sort them in descending order ($\lambda_1 > \lambda_2 > \lambda_3$) [S1].
2.  **Calculate Anisotropy Indices:** Compute the barycentric coordinates using the formulas from [S1]:
    $$c_p = \frac{\lambda_2 - \lambda_3}{\lambda_3}$$
    $$c_l = \frac{\lambda_1 - \lambda_2}{\lambda_3}$$
    $$c_s = \frac{\lambda_1}{\lambda_3}$$
    *Note:* The source [S1] states $c_p + c_l + c_s = 1$. However, algebraic substitution shows $\frac{\lambda_2 - \lambda_3 + \lambda_1 - \lambda_2 + \lambda_1}{\lambda_3} = \frac{2\lambda_1 - \lambda_3}{\lambda_3} \neq 1$ generally. The source [S1] explicitly defines these specific formulas and the sum property, so they are implemented as stated [S1].
3.  **Normalize Indices (Optional but Recommended):** To utilize the full range of the transfer function, normalize the indices based on the dataset's global minimum and maximum [S1]:
    $$c_i' = \frac{c_i - \min(c_i)}{\max(c_i) - \min(c_i)}$$
    where $i \in \{p, l, s\}$ [S1].
4.  **Project to 2D Space:** Construct the 2D vector $\mathbf{v}$ for the transfer function lookup [S1]:
    $$\mathbf{v} = \begin{pmatrix} 1 - c_l' - 0.5c_s' \\ c_s' \end{pmatrix}$$
5.  **Lookup:** Use $\mathbf{v}$ to sample the 2D opacity transfer function $\alpha_b(\mathbf{v})$ and the 2D color LUT [S1].

**Pseudocode:**
```python
def barycentric_mapping(tensor_matrix):
    # 1. Compute eigenvalues
    # tensor_matrix is a 3x3 symmetric matrix
    eigenvalues = compute_eigenvalues(tensor_matrix)
    
    # 2. Sort eigenvalues: lambda_1 > lambda_2 > lambda_3
    # Note: Standard solvers may return sorted or unsorted. 
    # We enforce the order required by the source formulas.
    sorted_eigs = sort_descending(eigenvalues)
    lambda_1 = sorted_eigs[0]
    lambda_2 = sorted_eigs[1]
    lambda_3 = sorted_eigs[2]
    
    # Guard against division by zero if lambda_3 is zero or negative
    if lambda_3 <= 0:
        # Handle degenerate case: return default or handle as isotropic
        # Source does not specify behavior for lambda_3 <= 0.
        # [G] Assuming isotropic behavior or clamping to avoid NaN.
        return (0.0, 0.0) 

    # 3. Calculate anisotropy indices as defined in [S1]
    c_p = (lambda_2 - lambda_3) / lambda_3
    c_l = (lambda_1 - lambda_2) / lambda_3
    c_s = lambda_1 / lambda_3
    
    # 4. Normalize indices
    # In a full implementation, min_c_p, max_c_p, etc., are pre-computed 
    # from the entire dataset. Here we assume they are available.
    c_p_norm = (c_p - min_c_p) / (max_c_p - min_c_p)
    c_l_norm = (c_l - min_c_l) / (max_c_l - min_c_l)
    c_s_norm = (c_s - min_c_s) / (max_c_s - min_c_s)
    
    # 5. Project to 2D vector v
    v_x = 1.0 - c_l_norm - 0.5 * c_s_norm
    v_y = c_s_norm
    
    return (v_x, v_y)
```

**Edge Cases and Pitfalls:**
*   **Division by Zero:** If $\lambda_3 = 0$, the indices are undefined. The source does not specify a fallback, but numerically this indicates a degenerate tensor (e.g., planar or linear with zero extent in one direction). [G] A small epsilon or clamping should be applied to $\lambda_3$ in practice.
*   **Normalization Range:** The normalization step requires global statistics ($\min, \max$) of the indices. If these are not pre-computed, the mapping will not utilize the full transfer function range [S1].
*   **Sum Property:** The source [S1] claims $c_p + c_l + c_s = 1$. As noted, this is mathematically inconsistent with the provided formulas unless specific constraints on eigenvalues are met. Implementers should be aware of this discrepancy and rely on the explicit formulas provided in [S1] for the mapping vector calculation.

## Subtopics

### Barycentric Opacity Mapping
A variant technique that uses three barycentric coordinates derived from eigenvalues to emphasize important features and make unimportant regions transparent [S2, unofficial]. It defines the spherical coordinate $c_s$ differently than the main method: $c_s = \frac{3\lambda_3}{\lambda_1 + \lambda_2 + \lambda_3}$, where $\lambda_1 \ge \lambda_2 \ge \lambda_3$ are the real eigenvalues of the symmetric diffusion matrix [S2, unofficial]. This coordinate is used alongside $c_l$ and $c_p$ to define opacity in the transfer function [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of voxels, dominated by eigenvalue decomposition ($O(1)$ per voxel for $3 \times 3$ matrices) and the mapping calculation.
*   **Memory Complexity:** $O(1)$ auxiliary memory per voxel for storing indices and the mapping vector.
*   **Performance:** The method allows hardware-accelerated lookup at framebuffer rates, as demonstrated with 1.8M texture pixels (using $8 \times 8$ texture polygons) on DWI data [S1].
*   **Strengths:** Interactive exploration of tensor shapes; intuitive 2D control for complex 3D tensor properties; effective for highlighting specific anisotropies (linear, planar, spherical) in both synthetic and real-world data (e.g., white-matter fiber tracks) [S1].
*   **Limitations:** Requires pre-computation of global statistics for optimal normalization; sensitive to eigenvalue ordering and small eigenvalues (division by $\lambda_3$) [S1].
*   **When to use:** When the goal is to visually isolate and explore specific geometric shapes (anisotropy types) within a tensor field using an interactive widget [S1].
*   **When not to use:** When precise quantitative measurement of anisotropy magnitude is required without normalization artifacts, or when $\lambda_3$ is frequently near zero causing numerical instability.

## Background
The method was introduced in the paper "Tensor Splats: Visualising Tensor Fields by Texture Mapped Volume Rendering" [S1]. It was applied to synthetic data (cube, sphere, radiating spikes) and Diffusion Weighted Imaging (DWI) data to elucidate the location of particular tensor anisotropies. The approach builds on the concept of tensor splatting and uses an interactive widget to control color and opacity based on the anisotropy indices $c_p, c_l, c_s$ [S1]. The variant "Barycentric Opacity Mapping" is described in lecture notes from ETH Zurich [S2, unofficial].
