# Silhouette Enhancement

Also called: View-Vector Silhouette, Oriented Feature Enhancement, Orthogonal gradient opacity modulation

## Overview
Silhouette Enhancement is a feature-based classification technique that emphasizes object boundaries and surface shape perception by modulating voxel opacity based on the geometric relationship between the view vector and the local surface normal [S1, S2][S3, unofficial]. It solves the problem of ambiguous depth cues in volume rendering by making voxels where the gradient is orthogonal to the view direction (silhouettes) more opaque, while reducing opacity for voxels facing the viewer [S1][S6, unofficial]. Unlike [Boundary-Enhanced Opacity](795-boundary-enhanced-opacity.md), which relies solely on gradient magnitude to detect material interfaces, Silhouette Enhancement incorporates view-dependent orientation to create sketch-like outlines and enhance the perception of volumetric features [S1][S6, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** Volume dataset $V$, transfer function parameters (base opacity $\alpha_g$ or $o_v$), view direction vector $V$, gradient field $\nabla f$.
*   **Output:** Enhanced opacity value $o_s$ (or $\alpha_{gf}$) for each sample point, used in the compositing loop.

**Data Structures**
*   **Gradient Field:** A 3D vector field where each voxel stores the gradient $\nabla f = (\frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}, \frac{\partial f}{\partial z})$.
*   **View Vector:** A normalized 3D vector $V$ pointing from the camera to the sample point (or vice versa, depending on convention; the dot product magnitude remains invariant to sign).

**Parameters**
*   $k_{sc}$: Controls the scaling of non-silhouette regions and the baseline opacity. Typical value: 0.9 [S5][S6, unofficial].
*   $k_{ss}$: Controls the amount of silhouette enhancement. Typical value: 50 [S5][S6, unofficial].
*   $k_{se}$ (or $k_{f2}$): Controls the sharpness of the silhouette curve (exponent). Typical value: 0.25 [S5][S6, unofficial].
*   $k_{f1}$: Scaling factor for opacity increase (alternative formulation). Typical value: 0.5 for anterior segment imaging [S2].

**Steps**
1.  **Compute Gradient:** Calculate the volume gradient $\nabla f$ at the current sample point $r_i$ using finite differences or pre-computed gradients.
2.  **Normalize Gradient:** Compute the normalized gradient vector $\nabla f_n = \frac{\nabla f}{\|\nabla f\|}$. This approximates the surface normal [S1][S7, unofficial].
3.  **Compute Silhouette Factor:** Calculate the alignment between the view direction $V$ and the surface normal. The sources provide two equivalent formulations for detecting orthogonality:
    *   Formulation A (Dot Product): $D = |\nabla f_n \cdot V|$ [S2, S5][S6, S7, unofficial].
    *   Formulation B (Cross Product): $C = \|\nabla f_n \times V\|$ [S4, S7 text description].
    *   Note: $D$ is near 0 when orthogonal; $C$ is near 1 when orthogonal. The sources predominantly use the dot product form $(1 - |\nabla f_n \cdot V|)$ to represent the silhouette strength [S2, S5][S6, S7, unofficial].
4.  **Calculate Enhanced Opacity:** Apply the modulation formula. Two common forms exist:
    *   **Form 1 (Multiplicative/Exponential):**
        $$o_s = o_v \left( k_{sc} + k_{ss} (1 - |\nabla f_n \cdot V|)^{k_{se}} \right)$$
        Where $o_v$ is the original/base opacity [S5][S6, S7, unofficial].
    *   **Form 2 (Additive/Linear):**
        $$\alpha_{gf}(r_i) = \alpha_g(r_i) \left[ 1 + k_{f1} (1 - |\nabla(r_i) \cdot V|)^{k_{f2}} \right]$$
        Where $\alpha_g(r_i)$ is the base opacity [S2].
5.  **Clamp:** Ensure the resulting opacity $o_s$ is within $[0, 1]$.
6.  **Composite:** Use $o_s$ in the standard front-to-back or back-to-front compositing equation.

**Pseudocode**
```python
def silhouette_enhance(base_opacity, gradient, view_direction, k_sc, k_ss, k_se):
    """
    Computes silhouette-enhanced opacity.
    
    Args:
        base_opacity (float): Original opacity o_v or alpha_g.
        gradient (Vector3): Unnormalized gradient vector.
        view_direction (Vector3): Normalized view vector V.
        k_sc (float): Scaling of non-silhouette regions.
        k_ss (float): Amount of silhouette enhancement.
        k_se (float): Sharpness of the silhouette curve.
        
    Returns:
        float: Enhanced opacity o_s.
    """
    # Step 1 & 2: Normalize gradient to approximate surface normal
    grad_norm = length(gradient)
    if grad_norm < 1e-6:
        # Degenerate case: no gradient, no silhouette effect
        return base_opacity
    
    grad_normalized = gradient / grad_norm
    
    # Step 3: Compute silhouette factor using dot product
    # Dot product is 0 when orthogonal (silhouette), 1 when parallel
    dot_product = abs(dot(grad_normalized, view_direction))
    
    # Silhouette strength: 1 when orthogonal, 0 when parallel
    silhouette_strength = 1.0 - dot_product
    
    # Step 4: Apply modulation formula (Form 1 from [S5][S6, S7, unofficial])
    # Term inside parenthesis: k_sc provides baseline, k_ss adds enhancement
    # Raised to k_se for sharpness control
    modulation_factor = k_sc + k_ss * (silhouette_strength ** k_se)
    
    enhanced_opacity = base_opacity * modulation_factor
    
    # Step 5: Clamp to valid range
    if enhanced_opacity > 1.0:
        return 1.0
    elif enhanced_opacity < 0.0:
        return 0.0
    else:
        return enhanced_opacity
```

**Edge Cases and Pitfalls**
*   **Darkening Effect:** Increasing the opacity of edge voxels causes them to reach the opacity threshold faster during compositing, which can make the silhouette lines appear darker than the underlying volume [S2].
*   **Transparency Requirements:** In applications requiring visualization of deeper structures (e.g., anterior segment eye imaging), the enhancement factor ($k_{f1}$ or $k_{ss}$) should be reduced (e.g., by a factor of 10) to prevent the silhouettes from occluding internal features [S2].
*   **Sketching Mode:** To create a sketch effect, non-volumetric silhouettes (features oriented toward the viewer) should be made transparent, and silhouette lines (orthogonal) should be rendered with high opacity and a specific color (white or black) [S5][S6, unofficial].

## Subtopics

### Sketching
A style where non-silhouette regions are made transparent and silhouette lines are rendered in high-contrast colors (white/black) to mimic pen-and-ink drawings [S1][S6, unofficial].

### Edge Coloring
Modifying the color of samples based on the silhouette term rather than opacity, often used to darken edges [S1].

### Boundary Emphasis Slider
A UI component that allows users to adjust the strength of boundary and silhouette enhancements interactively [Siblings].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per sample, requiring one dot product and one power operation per sample.
*   **Memory Complexity:** $O(1)$ additional memory per sample if gradients are pre-computed; $O(N)$ if gradients are computed on-the-fly.
*   **Performance:** The method is hardware-acceleratable and suitable for real-time interactive exploration [S8].
*   **Strengths:** Significantly improves depth perception and the visibility of fine internal structures (e.g., liver honeycomb structure) by emphasizing surface orientation [S6, unofficial]. Effective for creating illustrative styles [S1].
*   **Limitations:** Can obscure internal details if the enhancement is too strong; requires careful tuning of $k_{ss}$ and $k_{sc}$ for different anatomical regions [S2][S6, unofficial].
*   **When to use:** When shape perception and boundary clarity are more important than absolute internal density representation, or when creating non-photorealistic illustrations [S1][S6, unofficial].
*   **When not to use:** When transparent visualization of deep internal structures is required without occlusion by surface outlines [S2].

## Background
Silhouette enhancement in volume rendering was introduced by Ebert and Rheingans in 2000 [S1]. It draws inspiration from traditional artistic techniques, specifically the work of Étienne de Silhouette (1709–1767), who created profile portraits using black paper cutouts [S1]. The technique extends surface illustration concepts (such as those by Salisbury and Interrante) to volumetric data, using the volume gradient to approximate surface normals and modulating opacity based on view-dependent orientation [S1][S6, unofficial]. It is widely used in medical illustration to convey anatomical structure and in scientific visualization to enhance feature perception [S1][S3, unofficial].
