# Silhouette Enhancement

Also called: Oriented Feature Enhancement, Silhouette Curves, Silhouettes In Volumes, silhouette volumes

## Overview
Silhouette Enhancement is a technique to draw outlines or sketches of objects in volume data by detecting silhouettes, which are strongest where the view vector is orthogonal to the surface normal vector [S1]. It increases the opacity of volume samples where the gradient is nearly perpendicular to the view direction, strengthening silhouette cues for surface shape perception [S3, unofficial][S2]. Unlike its sibling [Isovalue Contour Surface Classification](1328-isovalue-contour-surface-classification.md) which extracts explicit surfaces, or [Classification and Shading](2278-classification-and-shading.md) which relies on lighting models, Silhouette Enhancement operates directly on the volumetric gradient and view alignment to create illustrative "sketch" effects or emphasize orientation [S1]. It builds on [Boundary-Enhanced Opacity](795-boundary-enhanced-opacity.md) by adding view-dependent opacity modulation on top of boundary detection.

## How it works
**Inputs and Outputs:**
*   **Input:** Volume scalar field $f$, camera/view direction vector $V$ (normalized), original sample opacity $o_v$, original sample color $C_v$.
*   **Output:** Enhanced opacity $o_s$ and optionally modified color $C_s$.

**Data Structures:**
*   **Gradient Field:** Pre-computed or computed on-the-fly. The normalized gradient $\nabla f_n$ is required.
    *   Layout: For a voxel at index $(i,j,k)$, store $\nabla f_n = (\frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}, \frac{\partial f}{\partial z}) / ||\nabla f||$.
    *   Note: If the gradient magnitude is zero (flat region), $\nabla f_n$ is undefined. [G] In implementation, set $\nabla f_n = (0,0,0)$ or skip enhancement for that sample to avoid division by zero.

**Parameters:**
*   $k_{sc}$: Controls scaling of non-silhouette regions. Typical value: 0.9 [S2][S3, unofficial].
*   $k_{ss}$: Controls the amount of silhouette enhancement. Typical value: 50 [S2][S3, unofficial].
*   $k_{se}$: Controls the sharpness of the silhouette curve. Typical value: 0.25 [S2][S3, unofficial].

**Steps:**
1.  **Compute Normal:** Approximate the surface normal using the volume gradient direction. Calculate the normalized gradient $\nabla f_n$ at the current sample point [S1].
2.  **Compute Silhouette Factor:** Calculate the alignment between the normalized gradient $\nabla f_n$ and the view direction $V$. The silhouette factor $S$ is defined as:
    $$ S = 1 - |\nabla f_n \cdot V| $$
    This value is close to 1 when the gradient is perpendicular to the view (silhouette) and close to 0 when parallel [S2][S3, unofficial].
3.  **Compute Enhanced Opacity:** Apply the silhouette enhancement formula to the original opacity $o_v$:
    $$ o_s = o_v (k_{sc} + k_{ss} S)^{k_{se}} $$
    Substituting $S$:
    $$ o_s = o_v (k_{sc} + k_{ss} (1 - |\nabla f_n \cdot V|))^{k_{se}} $$
    [S2][S3, unofficial][S4, unofficial]. Note: Source [S2] contains a typo in the exponent notation in the text description ($k_{sc}$ instead of $k_{se}$), but the parameter list and other sources [S3, unofficial][S4, unofficial] confirm the exponent is $k_{se}$ [S2].
4.  **Modify Color (Optional):** To create sketch effects, modify the sample color. For example, use white/black sketch colors and make non-volumetric silhouettes transparent [S3, unofficial]. Shadows can be calculated based on the original volume opacity $o_v$ [S3, unofficial].

**Pseudocode:**
```python
def silhouette_enhance(gradient_magnitude, gradient_vector, view_direction, original_opacity, k_sc, k_ss, k_se):
    """
    Computes silhouette-enhanced opacity for a single volume sample.
    
    Args:
        gradient_magnitude: float, magnitude of the volume gradient ||grad(f)||
        gradient_vector: tuple (gx, gy, gz), the volume gradient vector
        view_direction: tuple (vx, vy, vz), normalized view vector
        original_opacity: float, the base opacity o_v
        k_sc: float, scaling factor for non-silhouette regions
        k_ss: float, enhancement amount
        k_se: float, sharpness exponent
        
    Returns:
        float: enhanced opacity o_s
    """
    # Step 1: Compute normalized gradient
    # Guard against zero magnitude to avoid division by zero [G]
    if gradient_magnitude < 1e-9:
        return original_opacity
    
    nx = gradient_vector[0] / gradient_magnitude
    ny = gradient_vector[1] / gradient_magnitude
    nz = gradient_vector[2] / gradient_magnitude
    
    # Step 2: Compute silhouette factor S = 1 - |grad_n . view|
    dot_product = nx * view_direction[0] + ny * view_direction[1] + nz * view_direction[2]
    silhouette_factor = 1.0 - abs(dot_product)
    
    # Step 3: Compute enhanced opacity
    # Formula: o_s = o_v * (k_sc + k_ss * S) ^ k_se
    base_term = k_sc + k_ss * silhouette_factor
    enhanced_opacity = original_opacity * (base_term ** k_se)
    
    return enhanced_opacity
```

**Edge Cases and Pitfalls:**
*   **Zero Gradient:** In regions of constant density, the gradient is zero. The normalized gradient is undefined. The implementation must handle this, typically by returning the original opacity or treating the region as non-silhouette [G].
*   **View Direction:** The view direction $V$ must be normalized. If not, the dot product will be scaled incorrectly [G].
*   **Parameter Sensitivity:** High $k_{ss}$ values can cause opacity to exceed 1.0 or clip. The exponent $k_{se}$ affects the contrast of the silhouette lines; low values (e.g., 0.25) create softer transitions, while higher values create sharper lines [S3, unofficial].

## Subtopics

### Sketching
A specific application where non-silhouette regions are made transparent and silhouette regions are colored white or black to create a pen-and-ink look. Shadows are calculated based on original opacity [S3, unofficial].

### Edge Coloring
Modifying the color of samples based on the silhouette term, often darkening edges [S1].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per sample, assuming the gradient is pre-computed or computed via finite differences. Computing gradients adds $O(1)$ per sample.
*   **Memory Complexity:** $O(1)$ additional memory per sample for storing the normalized gradient if pre-computed.
*   **Strengths:** Effectively emphasizes surface shape and orientation cues, which are critical for perceiving 3D structure in volumes [S2]. Can create artistic sketch styles [S3, unofficial].
*   **Limitations:** Relies on the accuracy of the gradient estimation. Noisy data can produce noisy silhouettes. Performance is similar to standard volume rendering but with slightly higher computational cost due to gradient and dot product calculations.
*   **When to use:** When the goal is to emphasize boundaries and surface orientation, particularly in medical illustration or artistic visualization [S1].
*   **When not to use:** When photorealism is required, or when the volume data is very noisy and gradient-based methods fail.

## Background
The technique was introduced by Ebert and Rheingans in 2000 [S1]. It is inspired by the art of silhouette drawing, named after Étienne de Silhouette (1709–1767) [S1]. The method extends surface silhouette techniques to volumes by using the volume gradient to approximate surface normals [S1]. It is commonly used in medical illustration to convey shape and structure [S1].
