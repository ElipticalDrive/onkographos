# Boundary-Enhanced Opacity

Also called: Edge Coloring, Gradient-Based Boundary Enhancement, Gradient-Based Opacity Classification, Gradient-based opacity enhancement, Levoy90 gradient-based shading, gradient opacity enhancement

## Overview
Boundary-Enhanced Opacity is a feature-based classification technique that modulates the opacity of volume samples based on the local gradient magnitude of the scalar field, emphasizing material boundaries while rendering homogeneous regions transparent [S1, S2][S3, S4, unofficial]. It solves the problem of visualizing interfaces between distinct materials (e.g., air/skin, skin/muscle) by assigning high opacity to voxels with high gradients and low opacity to those with low gradients [S5, unofficial]. Unlike [Classification and Shading](2278-classification-and-shading.md), which uses gradients primarily for lighting and surface appearance while maintaining uniform opacity, this method explicitly controls transparency to reveal internal structure and boundary geometry [S1, S2]. It differs from [Silhouette Enhancement](796-silhouette-enhancement.md) by being view-independent and relying on scalar field derivatives rather than view-vector alignment [S3, unofficial][S2].

## How it works
**Inputs and Outputs:**
*   **Input:** A scalar volume dataset $V$ where each voxel or sample point $P_i$ has a scalar value $v_i = f(P_i)$ [S3, S4, unofficial].
*   **Input:** A base transfer function (optional) mapping scalar values to initial color $c_v$ and opacity $o_v$ [S3, S4, unofficial]. If not used, $o_v$ is a constant [S3, S4, unofficial].
*   **Output:** Enhanced opacity $o_g$ and color $c$ for each sample point used in ray casting [S3, S4, unofficial].

**Data Structures:**
*   **Volume Data:** A 3D grid of scalar values.
*   **Gradient Field:** A 3D grid of 3D vectors $\nabla f(P_i)$, computed from the volume data.
*   **Gradient Magnitude Field:** A 3D grid of scalars $\|\nabla f(P_i)\|$.
*   **Transfer Function:** A lookup table or function mapping scalar value $\to (c_v, o_v)$ [S3, S4, unofficial].

**Steps:**
1.  **Compute Scalar Values:** For each sample point $P_i = (x_i, y_i, z_i)$, obtain the scalar value $v_i = f(P_i)$ [S3, S4, unofficial].
2.  **Compute Gradient:** Calculate the value gradient vector $\nabla f(P_i)$ at $P_i$ [S3, S4, unofficial]. This is typically done using finite differences (e.g., central differences) on the scalar field [S5, G, unofficial].
3.  **Normalize Gradient (Optional):** Compute the normalized gradient $\nabla f_n = \frac{\nabla f(P_i)}{\|\nabla f(P_i)\|}$ if normalization is required for specific operations [S3, S4, unofficial]. Note: The primary boundary enhancement formula uses the magnitude, not the normalized vector, but normalization is mentioned for other operations [S3, S4, unofficial].
4.  **Base Transfer Function (Optional):** Map $v_i$ through a standard transfer function to get base opacity $o_v$ and color $c_v$ [S3, S4, unofficial]. If no transfer function is used, set $o_v$ to a constant value for the entire volume [S3, S4, unofficial].
5.  **Compute Gradient Magnitude:** Calculate the magnitude of the gradient: $g_i = \|\nabla f(P_i)\|$ [S3, S4, unofficial].
6.  **Compute Enhanced Opacity:** Apply the boundary-enhancement formula to compute $o_g$ [S3, S4, unofficial]:
    $$o_g = o_v \left( k_{gc} + k_{gs} \cdot g_i \right)^{k_{ge}}$$
    where:
    *   $o_v$ is the base opacity from the transfer function (or constant) [S3, S4, unofficial].
    *   $g_i = \|\nabla f(P_i)\|$ is the gradient magnitude [S3, S4, unofficial].
    *   $k_{gc}$ is the base opacity scaling factor (controls non-gradient regions) [S3, S4, unofficial].
    *   $k_{gs}$ is the gradient enhancement scaling factor [S3, S4, unofficial].
    *   $k_{ge}$ is the exponent controlling the slope of the opacity curve [S3, S4, unofficial].
7.  **Clamp Opacity:** Ensure $o_g \in [0, 1]$ [G].
8.  **Ray Casting:** Use $o_g$ and $c_v$ (or $c_v$ modified by gradient if edge coloring is applied) during volume integration [S3, S4, unofficial].

**Parameters:**
*   $k_{gc}$: Controls the base opacity scaling.
    *   $k_{gc} = 1, k_{gs} = 0$: No enhancement (opacity is just $o_v$) [S2][S3, S4, unofficial].
    *   $k_{gc} = 0$: Only areas with large gradients are visible (traditional gradient-based shading) [S2][S3, S4, unofficial].
    *   Typical value: $0.7$ [S3, S4, unofficial].
*   $k_{gs}$: Controls the amount of gradient enhancement.
    *   $k_{gs} = 0$: No gradient enhancement [S2][S3, S4, unofficial].
    *   Typical value: $10$ [S3, S4, unofficial].
*   $k_{ge}$: Exponent for the power function, adjusting the slope of the opacity curve.
    *   Typical value: $2.0$ [S2][S3, S4, unofficial].

**Pitfalls:**
*   **Formula Discrepancy:** Source [S2] presents the formula as $o_g = o_v ( k_{gc} + k_{gs} (\|\nabla_{fn}\|)^{k_{gc}} )$, using $k_{gc}$ as the exponent for the gradient norm, while [S3, S4, unofficial] use $k_{ge}$ as the exponent and $k_{gc}$ as a linear scaling factor. The implementation should follow [S3, S4, unofficial] as they are more consistent with the parameter descriptions ($k_{ge}$ is explicitly called the exponent) [S2][S3, S4, unofficial].
*   **Constant Opacity:** If no transfer function is used, $o_v$ must be explicitly set to a constant [S3, S4, unofficial].
*   **Gradient Noise:** Noise in the volume data can lead to high gradient magnitudes in homogeneous regions, causing unwanted opacity. Pre-filtering the volume may be necessary [G].
*   **Boundary Thickness:** The method emphasizes boundaries but does not inherently control their thickness; this is influenced by the gradient magnitude distribution and the parameters [S1, S2].

    """
    Computes boundary-enhanced opacity for a volume.
    
    Args:
        volume: 3D array of scalar values.
        transfer_function: Function mapping scalar value -> (color, opacity).
        k_gc: Base opacity scaling factor.
        k_gs: Gradient enhancement scaling factor.
        k_ge: Exponent for gradient enhancement.
        
    Returns:
        enhanced_opacity: 3D array of enhanced opacity values.
        colors: 3D array of colors (if transfer function is used).
    """
    # Step 1: Compute gradient magnitude
    # Using central differences for interior points, forward/backward for boundaries
    gradient_magnitude = compute_gradient_magnitude(volume)
    
    # Step 2: Get base opacity and color from transfer function
    # If no transfer function, use constants
    if transfer_function is not None:
        base_opacity, colors = apply_transfer_function(volume, transfer_function)
    else:
        base_opacity = np.ones_like(volume) * 0.5 # [G] Default constant opacity
        colors = np.ones_like(volume) * (1.0, 1.0, 1.0) # [G] Default white color
        
    # Step 3: Apply boundary enhancement formula
    # o_g = o_v * (k_gc + k_gs * gradient_magnitude) ^ k_ge
    enhanced_opacity = base_opacity * (k_gc + k_gs * gradient_magnitude) ** k_ge
    
    # Step 4: Clamp opacity to [0, 1]
    enhanced_opacity = np.clip(enhanced_opacity, 0.0, 1.0)
    
    return enhanced_opacity, colors

## Subtopics

### [Silhouette Enhancement](796-silhouette-enhancement.md)
Silhouette Enhancement increases opacity where the gradient is nearly perpendicular to the view direction, strengthening silhouette cues for surface shape perception. It is view-dependent, unlike the parent method. Choose it when view-dependent edge highlighting is needed.

### [Isovalue Contour Surface Classification](1328-isovalue-contour-surface-classification.md)
This method assigns opacity based on proximity to a selected isovalue, ensuring constant spatial width for the transition region regardless of gradient magnitude. It solves aliasing artifacts from binary thresholding. Choose it for rendering specific isosurfaces with consistent thickness.

### [Classification and Shading](2278-classification-and-shading.md)
Maps intensity to color and opacity, using gradient-based shading to enhance surface appearance while maintaining uniform or segment-specific opacity. Unlike Boundary-Enhanced Opacity, it does not modulate opacity based on gradient magnitude to emphasize boundaries. Choose it for realistic surface rendering.

### [Boundary Emphasis Slider](5644-boundary-emphasis-slider.md)
A UI control that modulates opacity based on the second derivative magnitude, emphasizing regions where the second derivative is small (boundaries/homogeneous regions). It differs from the parent by using the second derivative. Choose it for curvature-based boundary emphasis.

### Boundary Emphasis Function
A function $b(x)$ used with a distance map $d(v)$ to create an opacity function emphasizing boundaries [S6, unofficial]. The distance function $d(v)$ represents the distance to the boundary, with $x$ being the distance value [S6, unofficial]. Simple functions can accurately isolate material boundaries (e.g., 4 distinct boundaries in a tooth scan) [S6, unofficial].(Note: This variant is closely related to the Boundary Emphasis Slider and often implemented via similar distance-based transfer functions).

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of voxels/samples, for gradient computation and opacity calculation [S3, S4, unofficial].
*   **Memory Complexity:** $O(N)$ for storing the gradient field and enhanced opacity field [S3, S4, unofficial].
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Scales linearly with volume size [S3, S4, unofficial].
*   **Strengths:** Effectively emphasizes material boundaries and interfaces [S1, S2][S3, S4, unofficial]. Makes homogeneous regions transparent, revealing internal structures [S2][S3, S4, unofficial]. User-selectable enhancement levels via parameters [S2][S3, S4, unofficial].
*   **Limitations:** Sensitive to noise in the volume data [G]. Does not provide view-dependent cues like silhouettes [S3, unofficial][S2]. May require careful tuning of parameters for optimal results [S2][S3, S4, unofficial].
*   **When to use:** When visualizing interfaces between distinct materials is the primary goal [S5, unofficial]. When transparency of homogeneous regions is desired [S2][S3, S4, unofficial].
*   **When not to use:** When view-dependent edge highlighting is needed (use Silhouette Enhancement) [S1]. When consistent isosurface thickness is required (use Isovalue Contour Surface Classification) [S1, S2].

## Background
Boundary-Enhanced Opacity was originally introduced by Marc Levoy in 1990 [S3, S4, unofficial]. Levoy scaled voxel opacity by gradient magnitude to emphasize boundaries between data of different densities and make areas of constant density transparent [S3, S4, unofficial]. This technique was later adapted by Rheingans et al. to allow user-selective enhancement functions with parameters $k_{gc}$, $k_{gs}$, and $k_{ge}$ [S2][S3, S4, unofficial]. It is widely used in medical visualization to highlight tissue boundaries [S1, S2][S3, S4, unofficial].
