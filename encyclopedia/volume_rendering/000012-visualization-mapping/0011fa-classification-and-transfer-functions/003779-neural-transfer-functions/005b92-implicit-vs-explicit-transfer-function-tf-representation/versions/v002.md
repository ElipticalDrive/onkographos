# Implicit vs. Explicit Transfer Function (TF) Representation

Also called: Explicit TF Representation, Implicit TF Representation, Implicit vs Explicit TF

## Overview
This family contrasts implicit and explicit transfer function (TF) representations within neural volumetric rendering [S1]. Implicit representations use a preclassified volume to encode TF information, making the network invariant to input modality and simplifying the learning task by removing the need to learn TF application logic [S1]. Explicit representations encode the TF as raw parameters, requiring the network to jointly learn the illumination task and TF application, which steps away from hand-engineered features and offers potential inference efficiency, though at the cost of a significantly harder optimization landscape [S1].

## Shared principles
The distinction lies in whether the TF is precomputed as a volume or provided as raw parameters [S1]. Implicit representations output a preclassified volume that directly corresponds to the desired optical properties, bypassing a separate TF application step during inference [S1]. This approach makes learning easier and improves generalization across modalities because only data structures are unseen, not the general input scale [S1]. Explicit representations provide raw TF parameters (e.g., point lists or textures) that the network must interpret and apply [S1]. This adheres to learning representations from raw data but requires solving a harder joint task, often necessitating larger networks to match implicit quality, and has shown inferior performance in reported tests [S1].

## Subtopics

### Implicit TF Representation
Uses a preclassified volume to represent TF information [S1].

*   **Mechanism**: The network predicts a preclassified volume that directly corresponds to the TF's output, bypassing a separate TF application step during inference [S1].
*   **Advantages**: Learning is easier because the network does not need to learn TF application on top of illumination [S1]. It generalizes better across modalities since only structures are unseen, not the general input scale [S1].
*   **Disadvantages**: Inference is more expensive as it requires running the full network, increasing running times and memory requirements for large volumes [S1]. It relies on pre-classified structures rather than learning raw representations [S1].
*   **When to Choose**: Not given in the sources.

### Explicit TF Representation
Encodes the TF as raw parameters that the network must process and apply [S1].

*   **Mechanism**: The network takes raw TF parameters as input and jointly learns the illumination task and TF application [S1].
*   **Advantages**: Can save running time and memory compared to implicit approaches if efficient representations are learned [S1]. Steps away from hand-engineered features, adhering to raw representation learning [S1]. Learned feature spaces may enable future TF design or editing [S1].
*   **Disadvantages**: Solves a significantly harder task, often requiring larger networks with more parameters to match implicit quality [S1]. Reported tests show inferior performance compared to implicit methods [S1].
*   **When to Choose**: Not given in the sources.

### Explicit point-based representation
A variant representing the TF as a list of points $S$ [S1].

*   **Definition**: The TF is an unstructured set of points $S$ with varying length, inherently incompatible with CNNs requiring fixed-shape tensors [S1].
*   **Implementation**: To handle order independence and varying length, each point in $S$ is processed individually by three shared multilayer perceptrons (MLPs) to produce a feature descriptor of size 64 [S1]. The point features are reduced to a fixed-length TF descriptor using max pooling [S1].
*   **Result**: The output is a fixed-length feature vector compatible with downstream CNN strategies, though not directly with standard CNN input layers without further processing [S1].

## Background
This classification originates from the Deep Volumetric Ambient Occlusion (DVAO) paper [S1]. The authors compared implicit and explicit representations to determine the most effective integration method for neural volumetric rendering [S1]. While implicit methods performed better in experiments, the authors argued for future investigation into explicit methods due to their potential for efficiency and editability, noting that explicit approaches might require larger networks to achieve comparable quality [S1].
