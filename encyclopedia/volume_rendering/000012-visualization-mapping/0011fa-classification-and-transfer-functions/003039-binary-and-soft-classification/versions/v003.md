# Binary and Soft Classification

Also called: Binary Classifier, Non-Binary Classifier, Soft Classification

## Overview
Binary and Soft Classification evaluates input signals to determine voxel inclusion, producing either sharp transitions or smooth gradients in the output [S1, unofficial]. Binary classification makes hard "yes" or "no" decisions based on thresholds, while soft (non-binary) classification uses smooth transitions to avoid high-frequency artifacts [S1, unofficial]. This family focuses on the binary or continuous decision boundary for scalar values, differing from [Style Transfer Function (1D)](777-style-transfer-function-1d.md) which emphasizes stylistic mapping, and from [Boundary-Enhanced Opacity](795-boundary-enhanced-opacity.md) which operates on gradient-derived features [G].

## Shared principles
All methods in this family share the core mechanism of evaluating a classification function $C(\mathbf{x})$ for each sample point $\mathbf{x}$ in the volume to produce optical properties [S1, unofficial]. The input domain is typically a scalar value $v = f(\mathbf{x})$ representing voxel intensity or density [S1, unofficial]. The output range is a value in $[0, 1]$ representing inclusion probability or opacity [G]. The shape of the classification function directly affects the frequency content of the rendered image, where sharp transitions introduce high frequencies and smooth transitions reduce them [S1, unofficial].

## Subtopics

### [Piecewise-Linear Classification](881-piecewise-linear-classification.md)
Generalizes segmentation by applying per-channel piecewise linear functions to map input tensor values to RGBA formats, allowing continuous control over opacity and color rather than binary inclusion. Choose this when fine-grained, multi-channel control over the transfer function is required [G].

### [Binary Classification](931-binary-classification.md)
Categorizes voxels into two distinct groups (0-voxels and 1-voxels) based on a threshold, discarding 0-voxels to reduce memory consumption and accelerate rendering. Choose this for real-time rendering of large volumes where performance is critical and sharp boundaries are acceptable [G].

#### Non-Binary Classifier

### definition
A classifier that smoothly transitions from "no" to "yes" with varying degrees of acceptance, generating soft edges rather than sharp transitions [S1, unofficial].

### step
Apply smooth transitions between regions of interest and no interest, avoiding sharp corners in the classifier function [S1, unofficial].

### comparison
Unlike binary classifiers, it introduces significantly fewer high frequencies, reducing aliasing artifacts [S1, unofficial].

### [Multiple Material Classification](6343-multiple-material-classification.md)
A technique to classify more than one material in a volume by using multiple classifiers, allowing different materials to have different opacity values (e.g., high opacity for an organ, low for context) [G].

## Background
Binary classification was introduced in the context of parallel, feed-forward volume rendering algorithms [S1, unofficial]. The concept of non-binary (soft) classification was developed to mitigate the aliasing artifacts caused by the sharp transitions inherent in binary methods [S1, unofficial]. Multiple material classification extends this approach to handle distinct anatomical structures or materials within the same volume [G].
