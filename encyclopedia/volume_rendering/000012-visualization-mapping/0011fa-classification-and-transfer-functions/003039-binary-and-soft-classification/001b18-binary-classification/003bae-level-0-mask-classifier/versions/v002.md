# Level-0 Mask Classifier

Also called: Occupancy Network for Level-0 Mask

## Overview
The Level-0 Mask Classifier is a binary occupancy network that predicts whether a given voxel coordinate corresponds to an active or inactive value within a hierarchical VDB tree [S1]. It replaces explicit bitmask storage at the leaf level, distinguishing itself from sibling methods by operating strictly at voxel resolution to enable sparse field training [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D voxel coordinates $(x, y, z)$ [S1].
*   **Output:** A binary prediction indicating if the voxel is active ($1$) or inactive ($0$) [S1].

**Data Structures:**
The classifier is implemented as a shallow Multi-Layer Perceptron (MLP) [S1]. The network capacity is identical to the level-0 value regression network to maintain virtually identical memory footprints for the mask and value components [S1].
*   **Network Depth:** Shallow (typically 3 layers, denoted as $NN(3)$ in source literature) [S1].
*   **Input Dimension:** 3 (coordinates) [S1].
*   **Hidden Layers:** Linear transformations with non-linear activations (e.g., ReLU) [S1].
*   **Output Layer:** Single neuron with Sigmoid activation to produce a probability $p \in [0, 1]$ [S1].

**Training Procedure:**
1.  **Sampling:** Randomly sample voxel coordinates from the existing VDB grid [S1].
2.  **Forward Pass:** Pass sampled coordinates through the MLP to obtain an activation probability $p$ [S1].
3.  **Loss Calculation:** Compute the Binary Cross-Entropy (BCE) loss between the predicted probability and the ground truth active mask label $m_0$ [S1].
4.  **Optimization:** Update network weights using gradient descent [S1].

**Formulas:**
Let $m_0$ be the target active mask label for a voxel at level 0. The target label is defined as:
$$ m_0 \in \{0, 1\} $$
*(Note: The source text contains a typo "$m_0 \in \{m_1=1\}$", which is interpreted as the standard binary set $\{0, 1\}$ based on the context of "active or inactive" classification [S1].)*

The loss function is Vanilla Binary Cross-Entropy (BCE):
$$ \mathcal{L} = - \frac{1}{N} \sum_{i=1}^{N} \left[ m_0^{(i)} \log(p^{(i)}) + (1 - m_0^{(i)}) \log(1 - p^{(i)}) \right] $$
Where:
*   $N$ is the number of sampled voxels [S1].
*   $p^{(i)}$ is the predicted probability for the $i$-th sample [S1].
*   $m_0^{(i)}$ is the ground truth label ($1$ for active, $0$ for inactive) [S1].

**Parameters:**
*   **Loss Function:** Vanilla BCE. No additional tuning (e.g., class weights) is applied because the hierarchical structure (level-1 children nodes) addresses the class imbalance problem [S1].
*   **Network Capacity:** Identical to the level-0 value regression network to ensure virtually identical memory footprints [S1].

**Pseudocode:**
```python
import math
import random

def sigmoid(x):
    return 1.0 / (1.0 + math.exp(-x))

def relu(x):
    return max(0.0, x)

class Level0MaskClassifier:
    def __init__(self, hidden_dim=64):
        # Shallow MLP architecture [S1]
        self.W1 = [[random.uniform(-1, 1) for _ in range(3)] for _ in range(hidden_dim)]
        self.b1 = [0.0] * hidden_dim
        self.W2 = [[random.uniform(-1, 1) for _ in range(hidden_dim)]]
        self.b2 = [0.0]

    def forward(self, coords):
        # coords: list of [x, y, z]
        h = [relu(sum(w * c for w, c in zip(self.W1[i], coords)) + self.b1[i]) for i in range(len(self.W1))]
        out = sum(w * a for w, a in zip(self.W2[0], h)) + self.b2[0]
        return sigmoid(out)

def train_level0_mask_classifier(model, active_set, inactive_set, epochs=100, lr=1e-3):
    # Training samples voxel coordinates; target is active leaf mask m0 [S1]
    all_coords = list(active_set) + list(inactive_set)
    for epoch in range(epochs):
        random.shuffle(all_coords)
        for coords in all_coords:
            p = model.forward(coords)
            label = 1.0 if coords in active_set else 0.0
            # Vanilla BCE loss [S1]
            loss = -(label * math.log(p) + (1 - label) * math.log(1 - p))
```

## Subtopics

### Level-1 Mask Classifier
A ternary classifier that predicts one of three states for level-1 child node coordinates: 1) a leaf child node, 2) an active tile value, or 3) an inactive tile value [S1]. It uses cross-entropy loss and takes level-1 child node coordinates as input [S1].

## Operating characteristics
*   **Memory Footprint:** The network capacity is identical to the level-0 value regression network, resulting in virtually identical memory footprints for the mask and value components at level 0 [S1].
*   **Complexity:** The memory footprint of the hierarchical representation is dominated by the two lowest levels (0 and 1) [S1]. The neural representations of upper levels (2 and 3) have little impact on the overall footprint [S1].
*   **Performance:** The shallow network depth (3 layers) keeps inference fast [S1]. The use of vanilla BCE without tuning is feasible due to the hierarchical context where level-1 nodes address imbalance [S1].

## Background
The Level-0 Mask Classifier is part of the NeuralVDB framework, which proposes replacing the lowest two levels of the VDB tree structure with neural networks [S1]. This approach creates a hierarchical neural representation where the root and upper internal levels remain unchanged [S1]. The method was introduced in the paper "NeuralVDB: High-resolution Sparse Volume Representation using Hierarchical Neural Networks" [S1].
