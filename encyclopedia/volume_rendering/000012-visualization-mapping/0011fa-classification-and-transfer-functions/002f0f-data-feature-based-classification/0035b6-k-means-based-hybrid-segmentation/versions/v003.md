# K-means-based hybrid segmentation

Also called: hybrid segmentation

## Overview
This method enhances ray casting object distinction by assigning object membership information (ID tags) to cubical vertices in the volume, generated via a hybrid segmentation algorithm that combines self-organized neural networks with K-means clustering [S1, unofficial]. It differs from standard K-means by using a Self-Organizing Map (SOM) to initialize cluster centers, thereby avoiding local optima, and incorporates a Diagonal Busyness Factor (DF) to capture texture characteristics [S1, unofficial]. Unlike pure intensity-based classification, it leverages spatial texture and color to create binary, non-overlapping transfer functions for color and opacity assignment [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Volume data (typically RGB color bands or grayscale), optional pre-processing filters.
*   **Output:** Object membership ID tags assigned to volume vertices, which define binary transfer functions for rendering [S1, unofficial].

**Data Structures:**
*   **Neural Map:** A 2D grid of nodes with dimensions `map_width` $\times$ `map_length`. Each node stores a weight vector $w_v$ representing a color/feature value.
*   **Feature Vector:** For each pixel/voxel, the feature vector $D(t)$ consists of normalized RGB values and the Diagonal Busyness Factor (DF) [S1, unofficial].
*   **DF Calculation:** Computed over 4 diagonal neighbors ($x_i$) of a center pixel $C$: $DF = \sum_{i=1}^{4} |C - x_i|$ [S1, unofficial].

**Parameters:**
*   **Map Dimensions:** `map_width`, `map_length` (determines `NumberofMapNodes`) [S1, unofficial].
*   **Learning Rate:** Starts at 0.9, reduces to 0.1 in Stage 1; 0.01 in Stage 2 [S1, unofficial].
*   **Neighborhood Size:** Starts at half the map size, reduces to 1 in Stage 1; remains 1 in Stage 2 [S1, unofficial].
*   **Feature Normalization:** RGB values normalized from $[0, 255]$ to $[-1, 1]$ [S1, unofficial].

**Steps:**

1.  **Pre-processing (Optional):** Apply high-pass/low-pass filters and histogram equalization to remove noise and rectify intensity imbalance [S1, unofficial].
2.  **Neural Map Initialization:**
    *   Calculate `NumberofMapNodes` = `map_width` $\times$ `map_length`.
    *   Find min and max RGB values in the dataset.
    *   Calculate `Interval` = $(max - min) / (\text{NumberofMapNodes} - 1)$.
    *   Initialize nodes by traversing from min to max using the interval [S1, unofficial].
3.  **SOM Training (Stage 1):**
    *   Randomly select pixels as input vectors $D(t)$.
    *   Find the Best Matching Unit (BMU) $u$ for each input.
    *   Adjust BMU and neighborhood weights using the update rule:
        $$w_v(s+1) = w_v(s) + \theta(u,v,s)\theta(s)(D(t) - w_v(s))$$
        where $\theta(s)$ is the monotonically decreasing learning coefficient and $\theta(u,v,s)$ is the neighborhood function based on lattice distance [S1, unofficial].
    *   Reduce learning rate from 0.9 to 0.1 and neighborhood size from half map size to 1 [S1, unofficial].
4.  **SOM Training (Stage 2 - Refinement):**
    *   Stabilize feature vectors with a learning rate of 0.01.
    *   Neighborhood size remains 1 (only BMU adjusted) [S1, unofficial].
5.  **K-means Clustering (Phase 1.3):**
    *   Use SOM-derived centers as initial seeds for K-means.
    *   Limit dimensions to 3 color bands and DF [S1, unofficial].
    *   Perform few rounds of clustering to produce preliminary groups [S1, unofficial].
6.  **Statistical Optimization:**
    *   Apply Fisher discriminant ratio to convert preliminary groups into optimum segments [S1, unofficial].
    *   Use edge detection to exempt boundary information from irrelevant recombination [S1, unofficial].
    *   Apply recombination and epsilon tolerance factor for spatial tuning [S1, unofficial].

**Pseudocode:**

```python
def kmeans_hybrid_segmentation(volume_data, map_width, map_length):
    # Phase 1.1: Pre-processing
    # Apply filters and histogram equalization if needed [S1, unofficial]
    processed_data = apply_preprocessing(volume_data)

    # Phase 1.2: Neural Map Initialization
    num_nodes = map_width * map_length
    min_val = min(processed_data.flatten())
    max_val = max(processed_data.flatten())
    interval = (max_val - min_val) / (num_nodes - 1)
    
    # Initialize map nodes
    map_nodes = [min_val + i * interval for i in range(num_nodes)]
    
    # Phase 1.2: Training Stage 1
    learning_rate = 0.9
    neighborhood_size = map_width / 2
    
    for epoch in range(num_epochs_stage1):
        for pixel in random_sample(processed_data):
            # Normalize pixel RGB to [-1, 1] and compute DF
            feature_vector = normalize_and_compute_df(pixel)
            
            # Find BMU
            bmu_index = find_bmu(feature_vector, map_nodes)
            
            # Update weights
            for i in range(num_nodes):
                if distance(i, bmu_index) < neighborhood_size:
                    map_nodes[i] += learning_rate * neighborhood_function(i, bmu_index) * (feature_vector - map_nodes[i])
        
        # Decay parameters
        learning_rate = decay(learning_rate, target=0.1)
        neighborhood_size = max(1, neighborhood_size / 2)

    # Phase 1.2: Training Stage 2
    learning_rate = 0.01
    neighborhood_size = 1
    
    for epoch in range(num_epochs_stage2):
        for pixel in random_sample(processed_data):
            feature_vector = normalize_and_compute_df(pixel)
            bmu_index = find_bmu(feature_vector, map_nodes)
            
            # Only update BMU
            map_nodes[bmu_index] += learning_rate * (feature_vector - map_nodes[bmu_index])

    # Phase 1.3: K-means Clustering
    # Use map_nodes as initial centers
    kmeans_centers = map_nodes
    preliminary_clusters = run_kmeans(processed_data, kmeans_centers, features=['R', 'G', 'B', 'DF'])

    # Statistical Optimization
    optimum_segments = apply_fisher_discriminant(preliminary_clusters)
    apply_edge_detection_and_recombination(optimum_segments)

    return optimum_segments
```

**Edge Cases and Pitfalls:**
*   **Local Optima:** Random initialization in K-means can lead to non-representative clusters; SOM initialization mitigates this [S1, unofficial].
*   **Feature Ambiguity:** Using too many features can cause compromise; limiting to RGB and DF avoids this [S1, unofficial].
*   **Precision:** Normalization to $[-1, 1]$ is required for stable neural network training [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Dominated by SOM training iterations and K-means convergence. The use of SOM reduces the number of K-means iterations needed [S1, unofficial].
*   **Memory Complexity:** Requires storage for the neural map nodes and cluster assignments for all volume vertices [S1, unofficial].
*   **Strengths:** Improves object distinction in ray casting by providing binary, non-overlapping transfer functions; handles texture via DF; robust initialization [S1, unofficial].
*   **Limitations:** Requires pre-processing for noisy data; computationally intensive due to neural network training [S1, unofficial].
*   **When to Use:** When object boundaries are ambiguous due to similar intensities but distinct textures; when binary segmentation is required for clear object distinction [S1, unofficial].
*   **When Not to Use:** For simple volumes with distinct intensity ranges; when real-time performance is critical and pre-computation is not feasible [S1, unofficial].

## Background
The method was proposed by Azimzadeh and Pourgholi in 2020 to enhance ray casting object distinction [S1, unofficial]. It addresses the limitation of standard K-means clustering, which may converge to local optima if initialized randomly [S1, unofficial]. The approach integrates image processing techniques (filters, histogram equalization) with unsupervised neural networks (SOM) and statistical optimization (Fisher discriminant ratio) to create a robust segmentation pipeline for volume rendering [S1, unofficial].
