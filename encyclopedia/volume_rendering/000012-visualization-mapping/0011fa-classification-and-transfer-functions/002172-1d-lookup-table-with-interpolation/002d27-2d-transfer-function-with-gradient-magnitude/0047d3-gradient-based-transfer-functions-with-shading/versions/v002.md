# Gradient-Based Transfer Functions with Shading

Also called: Gradient-Based Transfer Functions, Ray Caster with Gradient-Based Transfer Functions, Shaded Gradient TF

## Overview
This method enhances volume visualization by precomputing surface normals and diffuse shading intensity values to drive a 2D opacity transfer function based on gradient magnitude, while using a 1D transfer function for color/intensity [S1, unofficial]. It distinguishes itself from standard 1D transfer functions by explicitly incorporating diffuse lighting calculations into the data preparation phase to reveal internal structures and material boundaries [S1, unofficial].

## How it works
**Inputs:**
- 3D scalar dataset $D$ of size $W \times H \times D$, where each voxel stores a byte intensity value [S1, unofficial].
- Light direction vector $\mathbf{l}$ (normalized) [S1, unofficial].
- User-defined 1D transfer function $TF_{1D}(v)$ mapping voxel value to intensity [S1, unofficial].
- User-defined 2D transfer function $TF_{2D}(v, g)$ mapping voxel value and gradient magnitude to opacity [S1, unofficial].
- Ray casting parameters: image resolution, number of sub-samples per pixel, step size [S1, unofficial].

**Outputs:**
- Final 2D image with pixel values in integer range $[0, 255]$ [S1, unofficial].

**Data Structures:**
1. **Original Data ($D_{raw}$):** The input 3D byte array [S1, unofficial].
2. **Gradient Data ($D_{grad}$):** A 3D byte array of the same dimensions as $D_{raw}$, storing the gradient magnitude at each voxel [S1, unofficial].
3. **Shaded Data ($D_{shaded}$):** A 3D byte array of the same dimensions as $D_{raw}$, storing the diffuse lighting intensity at each voxel [S1, unofficial].
4. **Compositing Scratchpad:** Per-pixel storage containing two floating-point numbers: current intensity $I_{comp}$ and current opacity $\alpha_{comp}$ [S1, unofficial].

**Preprocessing Steps:**
1. **Compute Normals and Gradient Magnitude:** For each voxel at $(x, y, z)$, compute the normal vector $\mathbf{n}$ by considering all 26 neighbors, attenuating contributions by the 18-neighbors and 26-neighbors [S1, unofficial]. Calculate the gradient vector $\mathbf{g}$ as the weighted sum of differences between the center voxel value and neighbor voxel values [G: Standard practice implies weighting by inverse distance or solid angle]. Compute the gradient magnitude $g = \|\mathbf{g}\|$ and store it in $D_{grad}(x, y, z)$, normalized to fit in the byte range $[0, 255]$ [S1, unofficial].
2. **Compute Shaded Intensity:** For each voxel, calculate the shaded intensity $s$ using diffuse lighting: $s = v \cdot \cos(\theta)$, where $v$ is the raw intensity $D_{raw}(x, y, z)$, $\theta$ is the angle between the light direction $\mathbf{l}$ and the computed normal $\mathbf{n}$, and $\cos(\theta) = \mathbf{n} \cdot \mathbf{l}$ [S1, unofficial]. The result is normalized to $[0, 1]$ and stored in $D_{shaded}(x, y, z)$ as a byte value, assuming light intensity is 1 [S1, unofficial].
3. **Ray Casting and Compositing:** For each pixel, shoot a ray through the volume. At user-controlled distances, take trilinearly interpolated samples $(v, s, g)$ from $D_{raw}$, $D_{shaded}$, and $D_{grad}$ [S1, unofficial]. Calculate transparency $\alpha = TF_{2D}(v, g)$ and intensity $I = TF_{1D}(v)$ [S1, unofficial]. Composite each sample into the scratchpad using front-to-back compositing: $\alpha_{new} = \alpha_{comp} + (1 - \alpha_{comp}) \cdot \alpha$, $I_{new} = I_{comp} + (1 - \alpha_{comp}) \cdot \alpha \cdot I$ [S1, unofficial]. After all samples, average sub-samples and transform the final floating-point intensity to $[0, 255]$ [S1, unofficial].

**Pseudocode:**

```python
import math

def trilinear_interpolate(data, x, y, z, width, height, depth):
    # Clamp coordinates to valid boundaries
    x = max(0, min(width - 1, x))
    y = max(0, min(height - 1, y))
    z = max(0, min(depth - 1, z))
    x0, y0, z0 = int(math.floor(x)), int(math.floor(y)), int(math.floor(z))
    x1, y1, z1 = min(x0 + 1, width - 1), min(y0 + 1, height - 1), min(z0 + 1, depth - 1)
    fx, fy, fz = x - x0, y - y0, z - z0
    v00 = data[x0, y0, z0] * (1-fx) + data[x1, y0, z0] * fx
    v01 = data[x0, y1, z0] * (1-fx) + data[x1, y1, z0] * fx
    v10 = data[x0, y0, z1] * (1-fx) + data[x1, y0, z1] * fx
    v11 = data[x0, y1, z1] * (1-fx) + data[x1, y1, z1] * fx
    v0 = v00 * (1-fy) + v01 * fy
    v1 = v10 * (1-fy) + v11 * fy
    return v0 * (1-fz) + v1 * fz

def compute_normal_and_gradient(data, x, y, z, width, height, depth):
    center_val = data[x, y, z]
    grad_vec = [0.0, 0.0, 0.0]
    for dx in [-1, 0, 1]:
        for dy in [-1, 0, 1]:
            for dz in [-1, 0, 1]:
                if dx == 0 and dy == 0 and dz == 0:
                    continue
                nx, ny, nz = x + dx, y + dy, z + dz
                nx = max(0, min(width-1, nx))
                ny = max(0, min(height-1, ny))
                nz = max(0, min(depth-1, nz))
                neighbor_val = data[nx, ny, nz]
                diff = neighbor_val - center_val
                vec = [float(dx), float(dy), float(dz)]
                dist = math.sqrt(dx*dx + dy*dy + dz*dz)
                weight = 1.0 / dist
                grad_vec[0] += diff * vec[0] * weight
                grad_vec[1] += diff * vec[1] * weight
                grad_vec[2] += diff * vec[2] * weight
    magnitude = math.sqrt(grad_vec[0]**2 + grad_vec[1]**2 + grad_vec[2]**2)
    return grad_vec, magnitude

def compute_shaded_intensity(normal, light_dir, raw_intensity):
    n_len = math.sqrt(normal[0]**2 + normal[1]**2 + normal[2]**2)
    if n_len == 0:
        return 0.0
    normal = [n / n_len for n in normal]
    cos_theta = normal[0]*light_dir[0] + normal[1]*light_dir[1] + normal[2]*light_dir[2]
    cos_theta = max(0.0, min(1.0, cos_theta))
    shaded = raw_intensity * cos_theta
    return shaded / 255.0

def render_volume(data, light_dir, tf_1d, tf_2d, width, height, depth, ray_steps, sub_samples):
    grad_data = [[[0.0]*depth for _ in range(height)] for _ in range(width)]
    shaded_data = [[[0.0]*depth for _ in range(height)] for _ in range(width)]
    
    for x in range(width):
        for y in range(height):
            for z in range(depth):
                normal, grad_mag = compute_normal_and_gradient(data, x, y, z, width, height, depth)
                grad_data[x][y][z] = grad_mag / 255.0
                shaded_data[x][y][z] = compute_shaded_intensity(normal, light_dir, data[x][y][z])
                
    image = [[0]*width for _ in range(height)]
    
    for px in range(width):
        for py in range(height):
            total_intensity = 0.0
            for ss in range(sub_samples):
                ray_origin = [float(px) + 0.5, float(py) + 0.5, 0.0]
                ray_dir = [0.0, 0.0, 1.0]
                
                comp_intensity = 0.0
                comp_opacity = 0.0
                
                for step in range(ray_steps):
                    t = step * (depth / ray_steps)
                    pos = [ray_origin[i] + ray_dir[i] * t for i in range(3)]
                    
                    v = trilinear_interpolate(data, pos[0], pos[1], pos[2], width, height, depth)
                    s_val = trilinear_interpolate(shaded_data, pos[0], pos[1], pos[2], width, height, depth)
                    g = trilinear_interpolate(grad_data, pos[0], pos[1], pos[2], width, height, depth)
                    
                    alpha = tf_2d(v, g)
                    intensity = tf_1d(v)
                    
                    alpha_new = comp_opacity + (1 - comp_opacity) * alpha
                    intensity_new = comp_intensity + (1 - comp_opacity) * alpha * intensity
                    
                    comp_intensity = intensity_new
                    comp_opacity = alpha_new
                
                total_intensity += comp_intensity
            
            avg_intensity = total_intensity / sub_samples
            image[py][px] = int(max(0, min(255, avg_intensity * 255)))
            
    return image
```

## Operating characteristics
- **Memory:** Requires two additional memory banks of the same size as the original dataset for storing the shaded data and gradient information [S1, unofficial]. This can be avoided by computing normals and shading on-the-fly, which also allows for view-dependent effects like specular lighting [S1, unofficial].
- **Performance:** In the cited example, shading took 5 seconds, gradient calculation took 5 seconds, and rendering took 35 seconds for all images at 512x341 resolution with one ray per pixel [S1, unofficial]. Gas rendering images at 512x341 resolution took 83 seconds each [S1, unofficial].

## Background
This method was developed for Computational Fluid Dynamics (CFD) visualization, specifically for visualizing gas flow fields [S1, unofficial]. It was presented by David Ebert et al. in the paper "Volume Rendering Methods for Computational Fluid Dynamics Visualization" [S1, unofficial]. The technique was used to visualize static pressure generated using computed Navier-Stokes equations [S1, unofficial].
