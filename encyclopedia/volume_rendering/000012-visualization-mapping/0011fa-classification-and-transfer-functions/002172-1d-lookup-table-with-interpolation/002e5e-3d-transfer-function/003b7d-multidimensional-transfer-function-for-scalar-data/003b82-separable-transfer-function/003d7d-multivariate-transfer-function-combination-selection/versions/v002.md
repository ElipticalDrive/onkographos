# Multivariate Transfer Function Combination Selection

Also called: Attribute Scoring Method, Correlation-Entropy Scoring for TF Selection, Entropy evaluation for TF attributes, Entropy-based Attribute Selection, Salient attribute selection, Scoring vector method, TF attribute scoring

## Overview
Multivariate Transfer Function Combination Selection is a preprocessing method for multivariate volume rendering that selects dataset properties to form a separable transfer function structure [S1, unofficial]. It solves the dimensionality problem by identifying which attributes form the 2D transfer function domain and which serve as 1D tertiary attributes, balancing property independence against information content [S1, unofficial]. It builds on [Separable Transfer Function](9014-separable-transfer-function.md) by automating the attribute selection process [S1, unofficial]. It differs from [Sequential 2D/1D Transfer Function Combination](9506-sequential-2d-1d-transfer-function-combination.md) and [Separable 3D Transfer Function Editor](9507-separable-3d-transfer-function-editor.md) by using a quantitative correlation-entropy scoring vector rather than manual or sequential heuristics [S1, unofficial].

## How it works
**Inputs:** A multivariate dataset with $l$ properties (attributes) $\{Y_1, Y_2, \dots, Y_l\}$ [S1, unofficial].
**Outputs:** A selection of one primary property $Y_p$, one secondary property $Y_q$, and a ranked list of remaining properties with scores $s_i$ to identify tertiary attributes [S1, unofficial].

**Data Structures:**
1. **Correlation Matrix $R$**: An $l \times l$ matrix where $R_{ij}$ is the correlation coefficient between property $Y_i$ and $Y_j$ [S1, unofficial].
2. **Entropy Vector $E$**: A vector of size $l$, where $E_i$ is the entropy of property $Y_i$ [S1, unofficial].
3. **Scoring Vector $s$**: A vector of size $l-2$ for the remaining properties containing the calculated scores [S1, unofficial].

**Parameters:**
* $a$: A dataset-dependent weight parameter balancing correlation and information. Range: $0 \leq a < 1$. Typical values cited are 0.4 and 0.6 [S1, unofficial].

**Steps:**
1. **Compute Correlation Matrix:** Calculate the correlation coefficient matrix $R$ for all $l$ properties [S1, unofficial]. The correlation between the primary property $Y_p$ and any other property $Y_i$ is given by:
   $$ R_{pi} = \frac{\text{Cov}(p,i)}{\sqrt{\text{Cov}(p,p)\text{Cov}(i,i)}} $$
   where $\text{Cov}(p,i)$ is the covariance between $Y_p$ and $Y_i$ [S1, unofficial].
2. **Compute Entropy Vector:** Calculate the entropy $E(Y_i)$ for each property $Y_i$ using its histogram [S1, unofficial]. Let $n$ be the number of bins, $b$ be the current bin index, and $p(y_b)$ be the probability of a data value falling into bin $b$:
   $$ E(Y_i) = \sum_{b=1}^{n} p(y_b) \log_2(p(y_b)) $$
   The source defines entropy this way, though standard implementations use the negative sum to yield positive values representing information content [S1, unofficial]. Higher entropy indicates lower homogeneity and more information [S1, unofficial].
3. **Select Primary and Secondary Properties:** Select the primary property $Y_p$ that represents the original information of the dataset (e.g., scalar value, mean volume) [S1, unofficial]. Select the secondary property $Y_q$ that is intrinsically associated with $Y_p$ (e.g., gradient magnitude $|\nabla x|$ for scalar $x$, or standard deviation $\sigma$ for mean $\mu$) [S1, unofficial]. $Y_p$ and $Y_q$ define the 2D transfer function space [S1, unofficial].
4. **Compute Scores for Remaining Properties:** For all remaining properties $Y_i$ (where $i \neq p, q$), compute the score $s_i$ using the linear interpolation of the absolute correlation with the primary property and the normalized entropy:
   $$ s_i = -a|R_{pi}| + (1-a)\frac{E(Y_i)}{\max E} $$
   where $\max E$ is the maximum entropy among all $l$ properties [S1, unofficial]. The term $-a|R_{pi}|$ favors properties with low correlation to the primary property (high independence) [S1, unofficial]. The term $(1-a)\frac{E(Y_i)}{\max E}$ favors properties with high entropy (high information content) [S1, unofficial].
5. **Rank and Select Tertiary Attributes:** Rank the remaining properties based on their scores $s_i$ [S1, unofficial]. Select one or two properties with the highest scores as tertiary attributes to define 1D transfer functions [S1, unofficial]. One of these is selected as the active tertiary attribute for each widget in the 2D transfer function space [S1, unofficial].

**Pseudocode:**
```python
import math

def compute_entropy(values, num_bins=256):
    """Computes Shannon entropy of a 1D array of values."""
    hist, _ = _histogram(values, num_bins)
    total = sum(hist)
    if total == 0:
        return 0.0
    probs = [h / total for h in hist]
    # Standard Shannon entropy uses a negative sign to yield positive values.
    # The source formula lacks the negative sign but context implies positive entropy.
    return -sum(p * math.log2(p) for p in probs if p > 0)

def compute_correlation(x, y):
    """Computes Pearson correlation coefficient between two arrays."""
    n = len(x)
    if n != len(y) or n == 0:
        return 0.0
    mean_x = sum(x) / n
    mean_y = sum(y) / n
    cov = sum((xi - mean_x) * (yi - mean_y) for xi, yi in zip(x, y)) / (n - 1)
    std_x = math.sqrt(sum((xi - mean_x) ** 2 for xi in x) / (n - 1))
    std_y = math.sqrt(sum((yi - mean_y) ** 2 for yi in y) / (n - 1))
    if std_x == 0 or std_y == 0:
        return 0.0
    return cov / (std_x * std_y)

def _histogram(values, num_bins):
    """Helper to compute histogram counts."""
    min_val, max_val = min(values), max(values)
    if min_val == max_val:
        return [len(values)] + [0] * (num_bins - 1)
    bin_width = (max_val - min_val) / num_bins
    bins = [0] * num_bins
    for v in values:
        idx = int((v - min_val) / bin_width)
        if idx == num_bins:
            idx -= 1
        bins[idx] += 1
    return bins

def select_tf_combinations(properties, primary_idx, secondary_idx, a=0.6):
    """
    Selects tertiary attributes for transfer function combination.
    Args:
        properties: List of 1D arrays representing dataset attributes.
        primary_idx: Index of the primary property Yp.
        secondary_idx: Index of the secondary property Yq.
        a: Weight parameter for correlation vs entropy.
    Returns:
        ranked_tertiaries: List of tuples (index, score) for remaining properties, sorted by score descending.
    """
    l = len(properties)
    entropies = [compute_entropy(prop) for prop in properties]
    max_e = max(entropies) if max(entropies) > 0 else 1.0

    scores = []
    for i in range(l):
        if i == primary_idx or i == secondary_idx:
            continue
        r_pi = compute_correlation(properties[primary_idx], properties[i])
        abs_r_pi = abs(r_pi)
        norm_e = entropies[i] / max_e
        s_i = -a * abs_r_pi + (1 - a) * norm_e
        scores.append((i, s_i))

    ranked_tertiaries = sorted(scores, key=lambda x: x[1], reverse=True)
    return ranked_tertiaries
```

**Edge Cases and Pitfalls:**
* **Correlation Alone:** Using only correlation coefficients may select properties that are independent but do not increase classification ability. The inclusion of entropy remedies this by favoring properties with more information [S1, unofficial].
* **Low Entropy Properties:** Properties with low entropy (high homogeneity) might still be useful if they highlight a small, unique feature not present in other attributes. These cases are hard to describe mathematically and require subjective determination [S1, unofficial].
* **Parameter $a$:** The value of $a$ is dataset-dependent. Incorrect selection may overemphasize independence at the cost of information, or vice versa [S1, unofficial].

## Operating characteristics
* **Time Complexity:** Not given in the sources.
* **Memory Complexity:** Not given in the sources.
* **Strengths:** Provides a quantitative, reproducible method for selecting transfer function dimensions [S1, unofficial]. Balances feature independence (correlation) with feature richness (entropy) [S1, unofficial].
* **Limitations:** Relies on the user to manually select the primary and secondary properties, which requires domain knowledge [S1, unofficial]. The scoring is heuristic and may not capture all semantic relationships [S1, unofficial].
* **When to use:** When dealing with multivariate datasets ($>3$ attributes) and a separable transfer function structure is desired to reduce complexity while maintaining expressivity [S1, unofficial].
* **When not to use:** Not given in the sources.

## Background
The method was proposed by L. Zhou in the context of multivariate transfer function design for volume rendering [S1, unofficial]. It addresses the trade-off between dimensionality and usability in transfer function design [S1, unofficial]. The method was demonstrated on datasets such as a CT scan of a backpack and a hurricane simulation (VisContest 2004) [S1, unofficial]. It is part of a broader effort to automate or semi-automate the selection of salient attributes for visualization [S1, unofficial].
