# Sequential 2D/1D Transfer Function Combination

Also called: Sequential 2D-then-1D TF, Sequential TF Application

## Overview
A method that sequentially applies a 2D transfer function and a 1D transfer function to all voxels of a multivariate volume dataset to improve feature classification specificity [S1, unofficial]. It addresses the difficulty of robustly separating features using only single 1D or 2D transfer functions by combining different transfer function spaces [S1, unofficial]. Unlike analytical multidimensional transfer functions that rely on multiplication in high dimensions, this approach avoids misclassification pitfalls associated with high-dimensional products [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A volume dataset $V$ containing $l$ properties (attributes) $Y_1, Y_2, \dots, Y_l$. Each voxel $v_X$ is identified by its 3D position $X$.
*   **Parameters:**
    *   $k$: The number of 2D transfer function widgets applied. This is user-defined; no fixed value is specified [S1, unofficial].
    *   $r$: The number of 1D transfer functions applied to the classified regions. Typically 1 or 2 [S1, unofficial].
*   **Output:** A final classified volume consisting of regions $W_i$.

**Data Structures**
The method operates on sets of voxels. No specific memory layout is mandated beyond the input volume $V$ and the logical sets generated during processing.
*   $C_j$: The $j$-th classified voxel set generated by the $j$-th 2D transfer function widget.
*   $W_i$: The final classified volume region.

**Steps**
1.  **2D Classification:** For each of the $k$ 2D transfer function widgets $w_j$ (where $j \in [1, k]$), evaluate the widget on two specific properties $Y_p$ and $Y_q$ (where $p, q \in [1, l]$) for every voxel $v_X$ in the dataset $V$.
2.  **Generate Intermediate Sets:** Create the set $C_j$ containing all voxels $v_X$ where the 2D transfer function value is positive:
    $$C_j := \{v_X \mid \text{TF}_{w_j}(Y_p(X), Y_q(X)) > 0, \ p,q \in [1,l]\}$$
    This results in $k$ distinct sets of classified voxels $\{C_1, C_2, \dots, C_k\}$ [S1, unofficial].
3.  **1D Refinement:** For each intermediate set $C_j$, apply one of the $r$ available 1D transfer functions $\text{TF}_r$ to a third property $Y_r$. The property $Y_r$ must be distinct from the properties $Y_p$ and $Y_q$ used in the 2D step (i.e., $r \in \{1, \dots, l\} \setminus \{p, q\}$).
4.  **Final Classification:** Define the final classified region $W_i$ as the subset of $C_j$ that satisfies the 1D transfer function condition:
    $$\{W_i \subset C_j\} = \text{TF}_r(Y_r(X)) \quad \text{where} \quad X \in C_j$$
    Each 2D transfer function widget is associated with one 1D transfer function [S1, unofficial].

**Pseudocode**
```python
def sequential_2d_1d_tf_combination(volume, properties, tf_2d_widgets, tf_1d_functions):
    """
    volume: 3D array of shape (D, H, W)
    properties: list of l 3D arrays corresponding to Y_1 ... Y_l
    tf_2d_widgets: list of k callable objects, each taking two scalar values and returning a float
    tf_1d_functions: list of r callable objects, each taking one scalar value and returning a float
    
    Returns:
    final_regions: list of k boolean 3D arrays, where final_regions[j] represents W_i for the j-th widget
    """
    l = len(properties)
    k = len(tf_2d_widgets)
    final_regions = []

    for j in range(k):
        # 1. Select two distinct property indices p and q for this widget
        # In a real implementation, these would be user-selected or configured per widget
        p, q = get_property_indices_for_widget(j, l) 
        
        # 2. Apply 2D TF to generate intermediate set C_j
        # C_j is a boolean mask where TF_2D > 0
        prop_p = properties[p]
        prop_q = properties[q]
        
        # Initialize mask for C_j
        mask_C_j = np.zeros_like(prop_p, dtype=bool)
        
        for X in all_voxel_indices(volume):
            val_p = prop_p[X]
            val_q = prop_q[X]
            
            # Evaluate 2D transfer function
            tf_val = tf_2d_widgets[j](val_p, val_q)
            
            if tf_val > 0:
                mask_C_j[X] = True

        # 3. Select a third property index r distinct from p and q
        r = get_property_index_excluding(p, q, l)
        prop_r = properties[r]

        # 4. Apply 1D TF to refine C_j into W_i
        # W_i is the subset of C_j where TF_1D(Y_r) is true/positive
        # Assuming the 1D TF returns a boolean or we threshold it
        mask_W_i = np.zeros_like(prop_p, dtype=bool)
        
        for X in all_voxel_indices(volume):
            if mask_C_j[X]:
                val_r = prop_r[X]
                # Apply 1D transfer function
                # Note: The source defines {W_i subset C_j} = TF_r(Y_r(X)). 
                # Implementation assumes TF_r returns a boolean or a value > 0 indicating inclusion.
                if tf_1d_functions[j](val_r) > 0:
                    mask_W_i[X] = True
                    
        final_regions.append(mask_W_i)

    return final_regions

def get_property_indices_for_widget(widget_index, l):
    # Placeholder for user configuration logic
    # In practice, the user selects p and q for each of the k widgets
    return (widget_index % l, (widget_index + 1) % l)

def get_property_index_excluding(p, q, l):
    # Find an index r in [0, l-1] such that r != p and r != q
    for r in range(l):
        if r != p and r != q:
            return r
    return None # Should not happen if l >= 3
```

**Edge Cases and Pitfalls**
*   **Classification Inconsistency:** The sequential dimension reduction can cause classification inconsistencies compared to a true $n$-dimensional transfer function. However, the precision loss is typically minor and considered a reasonable trade-off for usability [S1, unofficial].
*   **Property Selection:** The method requires $l \ge 3$ to allow for distinct $p, q, r$ indices. If $l < 3$, the 1D refinement step cannot use a property distinct from the 2D inputs.
*   **Misclassification Avoidance:** Unlike methods that multiply transfer function values in high dimensions (which can lead to misclassification as shown by Kniss et al.), this sequential approach avoids such pitfalls by filtering voxels in stages [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(k \cdot N)$, where $N$ is the number of voxels and $k$ is the number of 2D widgets. Each voxel is evaluated by $k$ 2D functions and potentially $r$ 1D functions.
*   **Memory Complexity:** $O(N)$ to store the intermediate masks $C_j$ and final regions $W_i$.
*   **Strengths:** Provides more specificity for data classification than traditional 1D or 2D transfer functions alone. It is more flexible than local transfer functions (which require pre-classified/tagged volumes) because it allows interactive labeling via 2D widgets followed by 1D refinement [S1, unofficial].
*   **Limitations:** Not as expressive as a true $n$-dimensional transfer function due to the sequential reduction.
*   **When to Use:** Suitable for multivariate volume visualization systems, particularly for time-varying and complex simulation datasets where high-dimensional transfer functions are needed but interactive design is required [S1, unofficial].
*   **When Not to Use:** When exact $n$-dimensional classification is critical and the performance cost of evaluating a full $n$-dimensional function is acceptable, or when the dataset has fewer than 3 properties.

## Background
This method was proposed by Zhou et al. in their dissertation on multivariate transfer function design [S1, unofficial]. It was developed to address the limitations of existing transfer function spaces, such as traditional 1D and 2D methods, which are not always effective for all datasets. The work contrasts with Kniss et al.'s analytical multidimensional transfer functions, which suffer from misclassification when extending to 3D via multiplication, and Rezk-Salama's local transfer functions, which rely on pre-classified tagged volumes. The method prioritizes classification specificity over illustrative rendering, distinguishing it from style indexing approaches like those of Bruckner and Groller [S1, unofficial].
