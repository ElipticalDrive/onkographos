# Multidimensional Transfer Function for Scalar Data

Also called: 2D/3D Transfer Function for Scalar Volumes, Gradient-based Transfer Function

## Overview
Multidimensional transfer functions classify volume rendering samples based on a combination of scalar values rather than a single scalar value, allowing unique isolation of features by increasing the degrees of freedom in the transfer function domain [S1]. It solves the problem of disambiguating complex boundary configurations where material boundaries overlap in data value and gradient magnitude but differ in second directional derivative [S1]. Unlike 1D transfer functions which cannot capture complex combinations of material boundaries, 2D/3D transfer functions using gradient/second-derivative information can uniquely classify them [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A scalar field $f$ representing volume data.
*   **Output:** Opacity and color assignments for each voxel/sample based on computed features.

**Data Structures:**
The method relies on computing three scalar fields from the input $f$:
1.  **Data Value:** The original scalar value $f(x,y,z)$.
2.  **Gradient Magnitude:** A scalar field $f'$ representing the local rate of change.
3.  **Second Directional Derivative:** A scalar field $f''$ representing curvature along the gradient direction.

**Steps:**
1.  **Compute Gradient Magnitude:** Calculate the gradient magnitude $f'$ for the scalar field $f$ using the formula:
    $$f' = \|\nabla f\|$$
    This value discriminates between homogeneous regions (low gradient magnitudes) and regions of change/boundaries (high gradient magnitudes) [S1].

2.  **Initial 2D Classification:** Use data value and gradient magnitude as axes in a 2D transfer function to discriminate between homogeneous regions and boundaries [S1].

3.  **Check for Overlap:** Analyze the joint histogram of data value and gradient magnitude. If boundaries overlap in this 2D space (e.g., background/dentin boundary shares the same ranges of data value and gradient magnitude as pulp/dentin or background/enamel boundaries), proceed to step 4 [S1].

4.  **Compute Second Directional Derivative:** If disambiguation is required, compute the second directional derivative $f''$ along the gradient direction. This involves the Hessian matrix $\mathbf{H}$, a matrix of second partial derivatives [S1]. The formula is:
    $$f'' = \frac{1}{\|\nabla f\|^2} (\nabla f)^T \mathbf{H} f \nabla f$$
    Note: The term $\mathbf{H} f$ in the source notation refers to the application of the Hessian to the gradient vector, effectively computing the directional second derivative [S1].

5.  **3D Classification:** Use data value, gradient magnitude, and second directional derivative as axes in a 3D transfer function. Assign lower opacity to nonzero second derivative values to render specific boundaries (e.g., background/dentin) in isolation [S1]. At the center of an idealized boundary between two homogeneous materials, the gradient magnitude is high and the second derivative is zero, allowing precise isolation [S1].

**Pseudocode:**
```python
def compute_multidimensional_tf_features(volume_data):
    """
    Computes gradient magnitude and second directional derivative for volume data.
    volume_data: 3D numpy array of scalar values.
    Returns: gradient_magnitude, second_directional_derivative
    """
    # Compute gradient components
    # Using central differences for interior points, forward/backward for boundaries
    fx = np.zeros_like(volume_data)
    fy = np.zeros_like(volume_data)
    fz = np.zeros_like(volume_data)
    
    # Central differences for interior
    fx[1:-1, 1:-1, 1:-1] = (volume_data[2:, 1:-1, 1:-1] - volume_data[:-2, 1:-1, 1:-1]) / 2.0
    fy[1:-1, 1:-1, 1:-1] = (volume_data[1:-1, 2:, 1:-1] - volume_data[1:-1, :-2, 1:-1]) / 2.0
    fz[1:-1, 1:-1, 1:-1] = (volume_data[1:-1, 1:-1, 2:] - volume_data[1:-1, 1:-1, :-2]) / 2.0
    
    # Boundary handling (G)
    fx[0, :, :] = volume_data[1, :, :] - volume_data[0, :, :]
    fx[-1, :, :] = volume_data[-1, :, :] - volume_data[-2, :, :]
    fy[:, 0, :] = volume_data[:, 1, :] - volume_data[:, 0, :]
    fy[:, -1, :] = volume_data[:, -1, :] - volume_data[:, -2, :]
    fz[:, :, 0] = volume_data[:, :, 1] - volume_data[:, :, 0]
    fz[:, :, -1] = volume_data[:, :, -1] - volume_data[:, :, -2]

    # Compute gradient magnitude
    gradient_magnitude = np.sqrt(fx**2 + fy**2 + fz**2)
    
    # Compute Hessian matrix components (second partial derivatives)
    # H_xx, H_xy, H_xz, H_yy, H_yz, H_zz
    # Using central differences for interior
    H_xx = np.zeros_like(volume_data)
    H_xy = np.zeros_like(volume_data)
    H_xz = np.zeros_like(volume_data)
    H_yy = np.zeros_like(volume_data)
    H_yz = np.zeros_like(volume_data)
    H_zz = np.zeros_like(volume_data)
    
    # Interior points
    H_xx[1:-1, 1:-1, 1:-1] = (fx[2:, 1:-1, 1:-1] - fx[:-2, 1:-1, 1:-1]) / 2.0
    H_yy[1:-1, 1:-1, 1:-1] = (fy[1:-1, 2:, 1:-1] - fy[1:-1, :-2, 1:-1]) / 2.0
    H_zz[1:-1, 1:-1, 1:-1] = (fz[1:-1, 1:-1, 2:] - fz[1:-1, 1:-1, :-2]) / 2.0
    
    # Mixed derivatives
    H_xy[1:-1, 1:-1, 1:-1] = (fy[2:, 1:-1, 1:-1] - fy[:-2, 1:-1, 1:-1]) / 2.0
    H_xz[1:-1, 1:-1, 1:-1] = (fz[2:, 1:-1, 1:-1] - fz[:-2, 1:-1, 1:-1]) / 2.0
    H_yz[1:-1, 1:-1, 1:-1] = (fz[1:-1, 2:, 1:-1] - fz[1:-1, :-2, 1:-1]) / 2.0
    
    # Boundary handling for Hessian (G) - simplified to 0 or forward/backward
    # For implementation completeness, boundaries are set to 0 or extrapolated
    # H_xx[0, :, :] = H_xx[1, :, :] # Placeholder for boundary condition
    
    # Compute second directional derivative
    # f'' = (grad^T * H * grad) / ||grad||^2
    # Vectorized computation
    grad_norm_sq = gradient_magnitude**2
    
    # Avoid division by zero
    safe_norm_sq = np.where(grad_norm_sq > 1e-8, grad_norm_sq, 1.0)
    
    # Compute H * grad
    # H is 3x3, grad is 3x1 vector at each voxel
    # H_grad_x = H_xx * fx + H_xy * fy + H_xz * fz
    # H_grad_y = H_xy * fx + H_yy * fy + H_yz * fz
    # H_grad_z = H_xz * fx + H_yz * fy + H_zz * fz
    
    H_grad_x = H_xx * fx + H_xy * fy + H_xz * fz
    H_grad_y = H_xy * fx + H_yy * fy + H_yz * fz
    H_grad_z = H_xz * fx + H_yz * fy + H_zz * fz
    
    # Dot product grad . (H * grad)
    numerator = fx * H_grad_x + fy * H_grad_y + fz * H_grad_z
    
    second_directional_derivative = numerator / safe_norm_sq
    
    return gradient_magnitude, second_directional_derivative
```

**Parameters:**
*   **Opacity Threshold for Second Derivative:** Lower opacity is assigned to nonzero second derivative values to isolate specific boundaries [S1]. The exact threshold is data-dependent [S1].

**Edge Cases and Pitfalls:**
*   **Boundary Overlap:** Material boundaries may share the same ranges of data value and gradient magnitude, causing overlap in the 2D transfer function histogram and erroneous coloring of other boundaries [S1].
*   **Precision:** The computation of the second directional derivative is computationally expensive and sensitive to noise in the data [S1].
*   **Zero Gradient:** Division by $\|\nabla f\|^2$ requires handling voxels with zero gradient magnitude to avoid numerical instability [G].

## Subtopics

### [Separable Transfer Function](9014-separable-transfer-function.md)
A Separable Transfer Function is a technique for composing multidimensional transfer functions as a combination of a primary 2D transfer function and a tertiary 1D transfer function. It solves the problem of managing the high memory cost and interaction complexity of true 3D transfer functions while retaining sufficient expressivity for specific feature types, such as material boundaries. It differs from general 3D transfer functions by decomposing the classification domain, thereby reducing total storage size, but at the cost of being unable to specify classification based on the unique combination of all three data values simultaneously.

### Occlusion-based Transfer Function
A method to classify features of similar scalar value but different local neighborhoods by using the occlusion of a voxel as an additional dimension of the transfer function domain [S2, unofficial]. Correa and Ma use the occlusion of a voxel as an additional dimension of the transfer function domain to classify features of similar scalar value, but different local neighborhoods [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Computing the gradient magnitude is $O(N)$ where $N$ is the number of voxels. Computing the Hessian and second directional derivative is also $O(N)$ but with a higher constant factor due to the need for second-order derivatives and matrix-vector multiplications per voxel [S1].
*   **Memory Complexity:** Requires storage for the original volume, gradient magnitude, and second directional derivative fields, totaling $3N$ scalar values (or more if intermediate Hessian components are stored) [S1].
*   **Measured Performance:** The second directional derivative measure is described as "computationally expensive" compared to simpler edge detection algorithms like the Marr-Hildreth [S1].
*   **Strengths:** Allows unique isolation of features that overlap in 1D or 2D transfer function domains [S1].
*   **Limitations:** Increases the degrees of freedom necessary for specifying a transfer function, requiring data set specific guidance and increasing interaction complexity [S1].
*   **When to Use:** When material boundaries share similar scalar values and gradient magnitudes but differ in their second directional derivative [S1].
*   **When Not to Use:** When computational resources are limited or when features can be adequately separated using 1D or 2D transfer functions [S1].

## Background
Multidimensional transfer functions were introduced to address the limitations of 1D transfer functions in capturing complex combinations of material boundaries [S1]. The concept of using gradient magnitude as an axis was demonstrated using the Chapel Hill CT Head dataset, showing the identification of air, soft tissue, and bone, as well as their boundaries [S1]. The use of the second directional derivative for disambiguation was demonstrated using a human tooth CT dataset, isolating the background/dentin boundary from pulp/dentin and background/enamel boundaries [S1]. The work is attributed to Correa and Ma [S1][S2, unofficial].
