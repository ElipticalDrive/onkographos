# Spline Parameterization
Also called: Catmull-Rom Spline Parameterization, Cubic Hermite Spline Parameterization

## Overview
Spline parameterization improves upon piecewise linear (chord) parameterization by approximating the transfer function curve $\rho(f(t))$ using a cubic Hermite spline (Catmull-Rom) formulation [S1]. It estimates tangents to create a curved interpolation, providing smoother adherence to $\rho(f(t))$ with fewer world-space samples when data is extremely noisy and samples are far apart [S1]. Unlike its parent [Chord Parameterization](14542-chord-parameterization.md), which assumes a linear path between samples, this method evaluates a spline segment to locate peaks more accurately [S1].

## How it works
**Inputs:**
- Four consecutive world-space samples: $f_{-1}, f_0, f_1, f_2$ [S1].
- Chord length $L_f$ between segment endpoints $f_0$ and $f_1$ [S1].
- Sampling increment $ds$ along the parameterized segment [S1].
- Segment parameter bounds $t_0$ and $t_1$ in world space [S1].

**Outputs:**
- Parameterized curve $F(s)$ for $s \in [0, 1]$ approximating the segment between $f_0$ and $f_1$ [S1].
- Peak parameter $t_\rho$ corresponding to the maximum density $\rho$ along the curve [S1].

**Data Structures:**
- A 1D texture storing precomputed Hermite basis coefficients $h_{ij}(s)$ for efficient GPU lookup [S1].

**Steps:**
1. Maintain a stencil of four world-space samples $f_{-1}, f_0, f_1, f_2$ [S1].
2. Precompute the cubic Hermite basis coefficients $h_{ij}(s)$ and store them in a 1D texture [S1].
3. Parameterize the segment between $f_0$ and $f_1$ using chord length $L_f$ to define $s \in [0, 1]$ [S1].
4. Choose a suitable increment $ds$ for sampling along the curve [S1].
5. Evaluate the Catmull-Rom spline $F(s)$ for each $s$ to approximate the curve [S1].
6. Find the parameter $s_\rho$ corresponding to the maximum density $\rho(F(s))$ along the segment [S1].
7. Interpolate to find the final peak parameter $t_\rho$ using linear interpolation between the segment endpoints' $t$ values: $t_\rho = t_0 + s_\rho (t_1 - t_0)$ [S1].

**Pseudocode:**
```python
def spline_parameterization(f_minus1, f0, f1, f2, ds, t0, t1):
    s = 0.0
    max_rho = -inf
    s_rho = 0.0
    while s <= 1.0:
        F_s = f0 * h00(s) + (f1 - f_minus1) * h10(s) + f1 * h01(s) + (f2 - f0) * h11(s)
        rho_val = rho(F_s)
        if rho_val > max_rho:
            max_rho = rho_val
            s_rho = s
        s += ds
    t_rho = t0 + s_rho * (t1 - t0)
    return t_rho
```

**Formulas:**
The Catmull-Rom spline parameterization is defined as [S1]:
$$F(s) = f_0 h_{00}(s) + (f_1 - f_{-1})h_{10}(s) + f_1 h_{01}(s) + (f_2 - f_0)h_{11}(s)$$
where $h_{ij}(s)$ are the cubic Hermite basis functions [S1].

**Parameters:**
- $ds$: The sampling increment along the curve. Value: Not given in the sources. [S1].

**Edge Cases and Pitfalls:**
- The method is impractical for most 2D transfer functions due to the computational cost of maintaining a 4-point stencil and evaluating the spline [S1].
- Arc-length parameterization is noted as too costly, so chord length is used as an imperfect but efficient metric [S1].
- The technique becomes useful only when the data is extremely noisy and world-space samples are far apart [S1].

## Subtopics

### Catmull-Rom Spline Interpolation
A method to generate smooth 3D curves for yarn trajectories from discrete contact points (knots) using Catmull-Rom splines, ensuring local influence and no aliasing artifacts [S2]. It is chosen for its algorithmic simplicity, low computational cost (usually below 2-3 seconds for a million crossings), and good results with initial sampling [S2]. It organizes sampling points $\{P_1 \dots P_n\}$ into sequential subsets containing two knots ($P_i, P_{i+1}$) and two extra samples ($P_{i-1}, P_{i+2}$) to estimate tangents [S2]. Each initial sample is shared across four overlapping subsets, changing roles to ensure the trajectory is only influenced by simulation and not interpolation side effects [S2]. The tangent at each control point is defined as $T_i = \frac{P_{i+1} - P_{i-1}}{2}$ and $T_{i+1} = \frac{P_{i+2} - P_i}{2}$ [S2]. The curve segment is represented by a cubic matrix formulation [Fol96] [S2]. It is useful for visualizing yarn trajectories in cloth simulation where contact points are located at non-uniform distances and capture points with maximum variability [S2].

## Operating characteristics
- **Time Complexity:** Higher than chord parameterization due to the cost of maintaining a 4-point stencil and evaluating the spline [S1].
- **Memory Complexity:** Requires storage for the 1D texture of precomputed coefficients $h_{ij}(s)$ [S1].
- **Measured Performance:** Not given in the sources for volume rendering. In the context of yarn visualization, computational cost is usually below 2-3 seconds for a million crossings [S2].
- **Strengths:** Improves adherence to the image $\rho(f(t))$, providing smoother results with fewer world-space samples [S1].
- **Limitations:** Impractical for most 2D transfer functions compared to simpler chordal parameterization with more samples [S1].
- **When to use:** When the data itself is extremely noisy and world-space samples are farther apart [S1].
- **When not to use:** For most standard 2D transfer functions where computational efficiency is prioritized over smoothness with sparse samples [S1].

## Background
Spline parameterization was introduced as a logical improvement over piecewise linear parameterization in the context of volume rendering with multidimensional peak finding [S1]. The specific Catmull-Rom formulation is based on the classic Catmull-Rom splines [CR74] [S2]. The technique is described in the context of finding peaks in transfer functions where arc-length parameterization is too costly [S1].
