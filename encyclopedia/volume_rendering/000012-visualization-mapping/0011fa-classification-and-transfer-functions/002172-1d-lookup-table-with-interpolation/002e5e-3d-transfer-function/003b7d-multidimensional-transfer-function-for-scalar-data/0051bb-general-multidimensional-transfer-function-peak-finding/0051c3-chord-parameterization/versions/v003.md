# Chord Parameterization

Also called: Chord-based Peak Finding, Linear Chord Sampling

## Overview
Chord Parameterization finds local maxima in multidimensional transfer functions by approximating the path between two world-space samples as a straight line in transfer function space and sampling along it [S1]. It sets itself apart from its parent [General Multidimensional Transfer Function Peak Finding](14527-general-multidimensional-transfer-function-peak-finding.md) by providing a specific linear geometric approximation for the search path, and from [Spline Parameterization](14543-spline-parameterization.md) by using linear interpolation instead of curved spline fits [S1].

## How it works
**Inputs:** Two world-space samples $t_0$ and $t_1$ along a ray, their corresponding transfer function values $f_0 = f(t_0)$ and $f_1 = f(t_1)$ in $\mathbb{R}^M$ space, transfer function discretization width $W$ (e.g., 1024), and sampling step parameter $\Delta s$ (pixels per sample in transfer space) [S1].

**Outputs:** The world-space position $t_\rho$ corresponding to the peak classification value $\rho$ along the segment [S1].

**Data Structures:** Standard floating-point variables for positions, vectors, and scalars [G].

**Steps:**
1. Fetch the front sample $f(t_1)$ and store the back sample $f(t_0)$ [S1].
2. Compute the chord length $L_f$ in transfer space: $L_f = ||f_1 - f_0||$ [S1].
3. Compute the step size $ds$ for sampling along the chord: $ds = \frac{\Delta s}{W \cdot L_f}$ [S1].
4. Define the direction vector $df = f_1 - f_0$ [S1].
5. Parameterize the chord as a ray $F(s)$ for $s \in [0, 1]$: $F(s) = f_0 + s \cdot df$ [S1].
6. Iterate $s$ from 0 to 1 with step $ds$ to find $s_\rho$ corresponding to the maximum $\rho(F(s))$ along the segment [S1].
7. Interpolate to find the peak position $t_\rho$: $t_\rho = t_0 + s_\rho (t_1 - t_0)$ [S1].

**Parameters:** $\Delta s$ (typically $>1$ for better visuals/performance with high-resolution smooth TFs; used $\Delta s = 4$ in Figure 1) and $W$ (discretization, e.g., 1024) [S1].

**Edge cases and pitfalls:** If $L_f = 0$, division by zero occurs in $ds$ calculation; guard by returning $t_0$ [G]. For analytical transfer functions, set $\Delta s$ based on the smallest desired feature size [S1]. Sampling monotonic regions incurs small cost, but insufficient sampling may miss peaks [S1].

```python
def chord_parameterization(t0, t1, f0, f1, W, delta_s):
    # Vector operations
    def vec_sub(a, b): return tuple(x - y for x, y in zip(a, b))
    def vec_add(a, b): return tuple(x + y for x, y in zip(a, b))
    def vec_scale(v, s): return tuple(x * s for x in v)
    def vec_norm(v): return sum(x * x for x in v) ** 0.5

    df = vec_sub(f1, f0)
    L_f = vec_norm(df)

    if L_f == 0.0:
        return t0

    ds = delta_s / (W * L_f)

    max_rho = float('-inf')
    s_rho = 0.0
    s = 0.0

    while s <= 1.0:
        f_s = vec_add(f0, vec_scale(df, s))
        # [G] Standard transfer function evaluation or texture lookup
        rho_val = evaluate_transfer_function(f_s)
        if rho_val > max_rho:
            max_rho = rho_val
            s_rho = s
        s += ds

    t_rho = vec_add(t0, vec_scale(vec_sub(t1, t0), s_rho))
    return t_rho
```

## Subtopics

### [Spline Parameterization](14543-spline-parameterization.md)
Spline parameterization improves upon piecewise linear (chord) parameterization by approximating the transfer function curve $\rho(f(t))$ using a cubic Hermite spline (specifically Catmull-Rom) formulation. It is designed to provide smoother adherence to the image $\rho(f(t))$ with fewer world-space samples, particularly when the underlying data is extremely noisy and samples are far apart. Unlike Chord Parameterization, which assumes a linear path between samples, this method estimates tangents to create a curved interpolation.

### Scanline Sampling (DDA)
A method for finding peaks in low-resolution (e.g., 256^2) piecewise-constant transfer functions using a Digital Differential Analyzer (DDA) to scan the chord in discretized $\mathbb{R}^M$-space [S1]. It scans the chord from $f_0$ to $f_1$ in discretized $\mathbb{R}^M$-space, parameterizing the distance between pixel centers and marching along the major axis (X or Y, whichever is greater), incrementing the differential until the endpoint on that axis is reached [S1]. It uses the position along the major axis to determine $s_\rho$ and interpolates to find $s_\rho$ [S1]. It provides better guarantees that features in $\rho$ will not be missed compared to ray marching and is slightly faster and better at finding peaks than ray marching for 256^2 and 512^2 TFs [S1]. Pitfalls include that Wu's algorithm (another scanline method) was slower and did not provide better quality, and rasterizing slabs produces fewer artifacts but is more expensive and can overestimate the number of peaks [S1].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of samples along the chord, where the sample count is determined by $L_f$ and $ds$ [S1].
*   **Memory Complexity:** Constant, requiring only storage for the current sample and the two endpoints [S1].
*   **Performance:** Better visuals and performance are achieved with relatively high-resolution transfer functions with smooth (non-pixelated) features and $\Delta s > 1$ [S1].
*   **Strengths:** Simple to implement and efficient for smooth, high-resolution TFs [S1].
*   **Limitations:** Approximation error due to the linear assumption; may miss peaks if sampling is too coarse ($\Delta s$ too large) [S1]. Not ideal for low-resolution, piecewise-constant TFs where DDA is preferred [S1].

## Background
Chord Parameterization is part of the "General Multidimensional Transfer Functions" peak finding approach described in "Volume Rendering with Multidimensional Peak Finding" [S1]. It was developed to address the difficulty of solving for specific peak values in M-dimensional transfer functions ($M > 1$) by dynamically finding local maxima along the ray with sufficient sampling [S1].
