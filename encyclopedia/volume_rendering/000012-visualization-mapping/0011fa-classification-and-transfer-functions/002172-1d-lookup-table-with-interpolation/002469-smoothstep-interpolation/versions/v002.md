# Smoothstep Interpolation
Also called: Cubic Hermite Spline Interpolation (Smoothstep), Perlin Smoothstep, smoothstep

## Overview
Smoothstep interpolation clamps and interpolates a scalar input $x$ between two bounds $edge0$ and $edge1$ using a cubic Hermite spline [S1, unofficial]. The function clips the normalized input to $[0, 1]$ and evaluates a cubic polynomial [S2, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A scalar value $x$, a lower bound $edge0$, and an upper bound $edge1$ [S1, unofficial].
- Output: A scalar value $y \in [0, 1]$ [S2, unofficial].

**Data Structures:**
No complex data structures are required; the method operates on standard floating-point scalars [G].

**Steps:**
1. Compute $t = \text{clamp}((x - edge0) / (edge1 - edge0), 0.0, 1.0)$ [S1, unofficial].
2. Return $t^2(3.0 - 2.0 t)$ [S1, unofficial].

**Formula:**
Let $t$ be the normalized input:
$$ t = \text{clamp}\left(\frac{x - edge0}{edge1 - edge0}, 0.0, 1.0\right) $$
The output $y$ is:
$$ y = t^2 (3.0 - 2.0 t) $$
where $\text{clamp}(v, min, max)$ returns $min$ if $v < min$, $max$ if $v > max$, and $v$ otherwise [S1, unofficial].

**Parameters:**
- $edge0$: The lower bound of the transition interval [S1, unofficial].
- $edge1$: The upper bound of the transition interval [S1, unofficial].
- Typical values: Not given in the sources; they are tuned per transfer function segment [G].

**Edge Cases and Pitfalls:**
- If $edge0 = edge1$, division by zero occurs; implementers must guard against this, typically returning $0.0$ or $1.0$ based on $x$ relative to $edge0$ [G].
- Inputs $x < edge0$ result in $y = 0.0$ due to clamping [S1, unofficial].
- Inputs $x > edge1$ result in $y = 1.0$ due to clamping [S1, unofficial].
- Precision issues near boundaries are handled by the clamping step [G].

**Pseudocode:**
```python
def smoothstep(edge0, edge1, x):
    # Guard against division by zero
    if edge0 == edge1:
        return 0.0 if x < edge0 else 1.0
    
    # Normalize and clamp
    t = (x - edge0) / (edge1 - edge0)
    t = max(0.0, min(1.0, t))
    
    # Apply cubic Hermite spline
    return t * t * (3.0 - 2.0 * t)
```

## Operating characteristics
- **Time Complexity:** $O(1)$ per sample [G].
- **Memory Complexity:** $O(1)$ [G].
- **Performance:** The calculation involves a few arithmetic operations and is extremely fast [G].
- **Strengths:** Simple to implement, computationally cheap, provides smooth derivatives ($C^1$ continuity), and avoids ringing artifacts [G].
- **Limitations:** Cannot represent sharp transitions or discontinuities; the fixed curve shape limits flexibility compared to splines with adjustable control points [G].
- **When to use:** Ideal for general-purpose transfer functions where smoothness is desired but complex curve fitting is unnecessary [G].
- **When not to use:** When sharp edges or specific curvature control is required, use [Cubic Spline Transfer Function](1811-cubic-spline-transfer-function.md) [G].

## Background
The smoothstep function was popularized by Ken Perlin in the context of procedural noise generation [G]. It is a standard component in graphics programming libraries [G]. In volume rendering, it maps scalar values to transfer function properties with smooth derivatives [G].
