# CDF Integration from Weights

Also called: Weight Integration

## Overview
Computes the cumulative distribution function (CDF) from a set of discrete weights that sum to 1 along the last axis, treating them as a step function [S1, unofficial]. The output size on the last dimension is one greater than the input because it computes the integral corresponding to the endpoints of the step function [S1, unofficial]. It builds on [Step Function Resampling](7924-step-function-resampling.md).

## How it works
**Inputs:**
- `w`: Input tensor of weights. Assumed to sum to 1 along the last axis.

**Outputs:**
- `cw0`: Output tensor where `cw0[..., 0] = 0` and `cw0[..., -1] = 1`.

**Data Structures:**
- The input `w` is a tensor of arbitrary shape with at least one dimension. The last dimension represents the bins of the step function.
- The output `cw0` has the same shape as `w` except the last dimension is increased by 1.

**Steps:**
1. Compute the cumulative sum of all weights except the last one along the last axis:
   $$ cw = \text{cumsum}(w[..., :-1], \text{axis}=-1) $$
2. Clamp the cumulative sum to a maximum value of 1 to prevent numerical overflow:
   $$ cw = \min(cw, 1) $$
3. Prepend a tensor of zeros and append a tensor of ones to ensure the CDF starts exactly at 0 and ends exactly at 1:
   $$ cw0 = \text{concatenate}([0, cw, 1], \text{axis}=-1) $$

**Pseudocode:**
```python
import torch

def cdf_integration_from_weights(w: torch.Tensor) -> torch.Tensor:
    """
    Computes the CDF from weights that sum to 1.
    
    Args:
        w: Tensor of weights. Must sum to 1 along the last axis.
        
    Returns:
        Tensor of CDF values with one extra bin on the last dimension.
    """
    # Step 1: Cumulative sum of all weights except the last one
    # Note: torch.cumsum includes the current element. 
    # We want the integral endpoints. If w has N bins, we want N+1 endpoints.
    # The value at endpoint i is the sum of weights 0..i-1.
    # So for the first N endpoints (0 to N-1), we cumsum w[0]..w[N-2].
    # The last endpoint (N) is 1.
    
    # Get shape for broadcasting zeros/ones
    shape = w.shape
    
    # Cumulative sum of weights excluding the last bin
    cw = torch.cumsum(w[..., :-1], dim=-1)
    
    # Step 2: Clamp to 1 to handle numerical errors where sum might slightly exceed 1
    cw = torch.minimum(cw, torch.tensor(1.0, device=w.device, dtype=w.dtype))
    
    # Step 3: Prepend 0 and append 1
    zeros = torch.zeros(shape, device=w.device, dtype=w.dtype)
    ones = torch.ones(shape, device=w.device, dtype=w.dtype)
    
    # Concatenate along the last dimension
    cw0 = torch.cat([zeros, cw, ones], dim=-1)
    
    return cw0
```

**Parameters:**
- `w`: Input tensor of weights assumed to sum to 1 along the last axis.

**Edge Cases and Pitfalls:**
- The function silently breaks if the input weights do not sum to 1 along the last axis [S1, unofficial].
- Numerical overflow is prevented by clamping the cumulative sum to 1 [S1, unofficial].

## Subtopics

### Weight-PDF Conversion
Converts between a vector of discrete weights that sum to 1 and a probability density function (PDF) that integrates to 1 over given spatial/temporal intervals [S1, unofficial].

**Steps:**
1. **Weight to PDF:** Divide each weight by the interval width clamped to `eps`.
2. **PDF to Weight:** Multiply each PDF value by the corresponding interval width.

**Formulas:**
- Weight to PDF:
  $$ p_i = \frac{w_i}{\max(\epsilon, t_{i+1} - t_i)} $$
  where $p_i$ is the PDF value, $w_i$ is the weight, $t$ are interval boundaries, and $\epsilon$ is a numerical stability constant.
- PDF to Weight:
  $$ w_i = p_i \cdot (t_{i+1} - t_i) $$
  where $w_i$ is the weight, $p_i$ is the PDF value, and $t$ are interval boundaries.

**Parameters:**
- `eps`: Numerical stability constant, typically set to `torch.finfo(torch.float16).eps**2` [S1, unofficial].
