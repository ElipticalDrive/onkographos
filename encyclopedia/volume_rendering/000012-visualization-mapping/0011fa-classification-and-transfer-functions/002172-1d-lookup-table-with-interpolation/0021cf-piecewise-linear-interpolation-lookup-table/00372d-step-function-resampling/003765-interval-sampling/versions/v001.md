# Interval Sampling

Also called: Sample Intervals

## Overview
Interval Sampling is a method for resampling a step function defined by endpoints and values into new intervals by deriving interval boundaries from sampled centers [S1, S2, unofficial]. It differs from point-based sampling by ensuring that the resulting intervals are symmetric around the chosen centers, reflecting midpoints to determine boundaries [S1, S2, unofficial]. This approach is distinct from sibling methods like Max Dilation, which expands intervals to cover maximum extent, and CDF Integration, which relies on cumulative distribution functions [S1, S2, unofficial].

## How it works
**Inputs:**
- `centers`: A tensor of shape $(..., N)$ containing the sampled centers $c_i$ for $N$ samples [S1, S2, unofficial].
- `domain`: A tuple $(minval, maxval)$ specifying the valid range for the output boundaries [S2, unofficial].
- `num_samples`: The number of samples $N$ [S1, S2, unofficial].

**Outputs:**
- `t_samples`: A tensor of shape $(..., N+1)$ containing the interval boundaries $t_j$ [S1, S2, unofficial].

**Data Structures:**
- `centers`: Floating-point tensor representing the centers of the intervals.
- `mid`: Floating-point tensor representing the midpoints between adjacent centers.
- `first`, `last`: Floating-point scalars or tensors representing the clamped first and last boundaries.
- `t_samples`: Concatenated tensor of boundaries.

**Steps:**
1.  **Validation**: Check if `num_samples > 1`. If not, raise a `ValueError` [S1, S2, unofficial].
2.  **Center Sampling**: Obtain `centers` using a sampling function with `deterministic_center=True` [S1, S2, unofficial].
3.  **Midpoint Calculation**: Compute the midpoints between adjacent centers:
    $$ mid_i = \frac{centers_{i+1} + centers_i}{2} \quad \text{for } i = 0, \dots, N-2 $$
    This results in a tensor of shape $(..., N-1)$ [S1, S2, unofficial].
4.  **First Boundary**: Reflect the first midpoint around the first center and clamp to `minval`:
    $$ first = \max(minval, 2 \cdot centers_0 - mid_0) $$
    This results in a tensor of shape $(..., 1)$ [S1, S2, unofficial].
5.  **Last Boundary**: Reflect the last midpoint around the last center and clamp to `maxval`:
    $$ last = \min(maxval, 2 \cdot centers_{N-1} - mid_{N-2}) $$
    This results in a tensor of shape $(..., 1)$ [S1, S2, unofficial].
6.  **Concatenation**: Concatenate `first`, `mid`, and `last` along the last dimension to form the final boundaries:
    $$ t\_samples = [first, mid_0, mid_1, \dots, mid_{N-2}, last] $$
    The resulting tensor has shape $(..., N+1)$ [S1, S2, unofficial].

**Pseudocode:**
```python
def interval_sampling(centers, domain):
    """
    Resamples a step function by deriving interval boundaries from centers.
    
    Args:
        centers: Tensor of shape (..., N) containing sample centers.
        domain: Tuple (minval, maxval) for clamping boundaries.
        
    Returns:
        t_samples: Tensor of shape (..., N+1) containing interval boundaries.
    """
    # Step 1: Validation
    if centers.shape[-1] <= 1:
        raise ValueError("num_samples must be greater than 1")
    
    minval, maxval = domain
    
    # Step 2: Center Sampling (Assumed to be provided as input)
    # centers = sample(..., deterministic_center=True)
    
    # Step 3: Midpoint Calculation
    # mid[i] = (centers[i+1] + centers[i]) / 2
    mid = (centers[..., 1:] + centers[..., :-1]) / 2
    
    # Step 4: First Boundary
    # first = clamp_min(2 * centers[0] - mid[0], minval)
    first = (2 * centers[..., :1] - mid[..., :1]).clamp_min(minval)
    
    # Step 5: Last Boundary
    # last = clamp_max(2 * centers[-1] - mid[-1], maxval)
    last = (2 * centers[..., -1:] - mid[..., -1:]).clamp_max(maxval)
    
    # Step 6: Concatenation
    t_samples = torch.cat([first, mid, last], dim=-1)
    
    return t_samples
```

**Parameters:**
- `domain`: Tuple `(minval, maxval)` specifying the range of valid values for `t` [S2, unofficial].

**Edge Cases and Pitfalls:**
- If `num_samples <= 1`, the method raises a `ValueError` [S1, S2, unofficial].
- Clamping ensures boundaries stay within the valid domain, preventing out-of-bounds errors [S1, S2, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
- Time Complexity: $O(N)$, where $N$ is the number of samples, due to linear operations for midpoint calculation and concatenation.
- Memory Complexity: $O(N)$ for storing midpoints and the final boundary tensor.

**Measured Performance:**
- Not given in the sources.

**Scaling:**
- Scales linearly with the number of samples.

**Strengths and Limitations:**
- Strengths: Ensures intervals are symmetric around centers, providing a consistent resampling strategy [S1, S2, unofficial].
- Limitations: Requires at least two samples to compute midpoints [S1, S2, unofficial].

**When to Use:**
- Use when symmetric interval boundaries around sampled centers are required [S1, S2, unofficial].

**When Not to Use:**
- Do not use if point-based sampling is sufficient or if `num_samples <= 1` [S1, S2, unofficial].

## Background
Interval Sampling is described in the context of volume rendering and step function resampling [S1, S2, unofficial]. It is part of a family of methods for handling interval-based sampling in rendering pipelines [S1, S2, unofficial].
