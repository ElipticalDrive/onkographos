# Step Function Resampling

Also called: Inner/Outer Measures

## Overview
Step Function Resampling constructs inner and outer measures for a step function defined by endpoints $t_p$ and values $v_p$ when querying at new points $t_0$. It solves the problem of accurately evaluating the integral or average of a piecewise constant function over arbitrary intervals without explicit integration loops. It differs from [Piecewise Linear Interpolation (Lookup Table)](2643-piecewise-linear-interpolation-lookup-table.md) by preserving the discontinuous nature of the input data, ensuring that the resampled values represent the exact mass (sum or weighted average) contained within the query intervals rather than interpolating between step levels.

## How it works
**Inputs:**
- `t1`: Array of step function endpoints (monotonically increasing), shape $(..., N)$.
- `y1`: Array of step function values associated with intervals defined by `t1`, shape $(..., N-1)$.
- `t0`: Array of query points or interval boundaries, shape $(..., M)$.
- `use_avg`: Boolean flag. If `False`, computes the sum of the step function over each interval in `t0`. If `True`, computes the width-weighted average value.
- `eps`: Small value to prevent division by zero when `use_avg=True`. Default is `torch.finfo(t.dtype).eps` [S1, unofficial].

**Outputs:**
- `y0`: Resampled values, shape $(..., M-1)$ if `t0` defines intervals, or $(..., M)$ if `t0` defines points (implementation dependent, typically intervals are implied by pairs of points or specific sampling strategies). Based on the source, the output corresponds to the intervals defined by the sorted and unique query points.

**Data Structures:**
- Cumulative sum array `cy1`: Shape $(..., N)$. Contains leading zero followed by cumulative sum of `y1`.

**Steps:**

1.  **Compute Cumulative Sum:**
    Construct `cy1` by prepending a zero tensor of the same shape as the last dimension of `y1` to the cumulative sum of `y1`.
    $$ cy1 = \text{concat}([0, \text{cumsum}(y1)]) $$
    Specifically: `cy1 = torch.cat([torch.zeros_like(y1[..., :1]), torch.cumsum(y1, dim=-1)], dim=-1)` [S1, unofficial].

2.  **Find Insertion Indices:**
    Determine the indices where `t0` would be inserted into `t1` to maintain order. This yields `idx_lo` (index of first element $\ge t0$) and `idx_hi` (index of first element $> t0$).
    `idx_lo, idx_hi = searchsorted(t1, t0)` [S1, unofficial].

3.  **Gather Cumulative Values:**
    Retrieve cumulative values at the found indices.
    `cy1_lo = torch.take_along_dim(cy1, idx_lo, dim=-1)`
    `cy1_hi = torch.take_along_dim(cy1, idx_hi, dim=-1)` [S1, unofficial].

4.  **Compute Outer Measure:**
    The outer measure represents the total value of the step function over the interval $[t0_i, t0_{i+1}]$, including any partial steps at the boundaries.
    $$ y0_{\text{outer}} = cy1_{hi} - cy1_{lo} $$
    Specifically, for intervals defined by `t0`, the source computes: `y0_outer = cy1_hi[..., 1:] - cy1_lo[..., :-1]` [S1, unofficial]. This implies `t0` is treated as a set of boundaries.

5.  **Compute Inner Measure:**
    The inner measure represents the value of the step function strictly inside the interval $[t0_i, t0_{i+1}]$, excluding partial steps at the boundaries if the boundaries do not align with step edges.
    $$ y0_{\text{inner}} = \begin{cases} cy1_{lo, i+1} - cy1_{hi, i} & \text{if } idx_{hi, i} \le idx_{lo, i+1} \\ 0 & \text{otherwise} \end{cases} $$
    Specifically: `y0_inner = torch.where(idx_hi[..., :-1] <= idx_lo[..., 1:], cy1_lo[..., 1:] - cy1_hi[..., :-1], torch.zeros_like(idx_lo[..., 1:]))` [S1, unofficial].

6.  **Resample Mode Selection:**
    - **If `use_avg` is False:**
        1. Compute cumulative sum of original values: `acc = cumsum(vp)`.
        2. Prepend zeros: `acc0 = concat([0, acc])`.
        3. Interpolate `acc0` at points `t`.
        4. Compute differences of interpolated cumulative sums to get values [S1, unofficial].
        *Note: The source notes for `use_avg=False` describe a generic interpolation of cumulative sums, which aligns with the standard integral calculation. However, the detailed steps 1-5 above describe the specific inner/outer measure logic. The `use_avg=False` path in the notes seems to describe a simpler cumulative difference approach, potentially equivalent to the outer measure if `t0` aligns with `t1`, or a linear interpolation of the CDF if `t0` is arbitrary. Given the "Inner/Outer Measures" alias, the primary method is the inner/outer calculation.*

    - **If `use_avg` is True:**
        1. Compute interval widths of the original step function: $w_p = \text{diff}(t_p)$.
        2. Resample the weighted values $v_p \cdot w_p$ using the sum mode (same logic as `use_avg=False` but on weighted values).
        3. Resample the widths $w_p$ using the sum mode.
        4. Compute average: $v = \frac{v_{\text{numer}}}{\max(\epsilon, v_{\text{denom}})}$ [S1, unofficial].

**Pseudocode:**

```python
import torch

def step_function_resampling(t1, y1, t0, use_avg=True, eps=None):
    """
    Resamples a step function defined by endpoints t1 and values y1.
    
    Args:
        t1: Tensor of shape (..., N), monotonically increasing step endpoints.
        y1: Tensor of shape (..., N-1), step values.
        t0: Tensor of shape (..., M), query points/boundaries.
        use_avg: If True, returns weighted average. If False, returns sum.
        eps: Epsilon for division.
        
    Returns:
        y0: Tensor of shape (..., M-1), resampled values.
    """
    if eps is None:
        eps = torch.finfo(t1.dtype).eps
        
    # Ensure t0 is sorted and unique for interval definition
    # Note: Source implies t0 defines intervals via pairs or specific sampling.
    # We assume t0 are the boundaries of the new intervals.
    
    # Step 1: Cumulative sum of y1 with leading zero
    # cy1 shape: (..., N)
    zeros = torch.zeros_like(y1[..., :1])
    cy1 = torch.cat([zeros, torch.cumsum(y1, dim=-1)], dim=-1)
    
    # Step 2: Find insertion indices
    # idx_lo: index of first element >= t0
    # idx_hi: index of first element > t0
    # searchsorted returns indices where t0 could be inserted into t1
    idx_lo = torch.searchsorted(t1, t0, side='left')
    idx_hi = torch.searchsorted(t1, t0, side='right')
    
    # Step 3: Gather cumulative values
    cy1_lo = torch.take_along_dim(cy1, idx_lo, dim=-1)
    cy1_hi = torch.take_along_dim(cy1, idx_hi, dim=-1)
    
    # Step 4 & 5: Compute Outer and Inner measures for intervals defined by t0
    # Assuming t0 defines M-1 intervals [t0[i], t0[i+1]]
    # We need values for i from 0 to M-2
    
    # Outer measure: Total mass in [t0[i], t0[i+1]]
    # cy1_hi[..., 1:] corresponds to upper bound of interval i+1
    # cy1_lo[..., :-1] corresponds to lower bound of interval i
    cy1_hi_next = cy1_hi[..., 1:]
    cy1_lo_curr = cy1_lo[..., :-1]
    
    y0_outer = cy1_hi_next - cy1_lo_curr
    
    # Inner measure: Mass strictly inside, excluding partial steps at boundaries
    # Condition: idx_hi[..., :-1] <= idx_lo[..., 1:]
    # This checks if the interval [t0[i], t0[i+1]] is fully contained within a single step or steps
    # where the boundaries align such that no partial steps are included in the "inner" count?
    # Actually, inner measure usually excludes the partial contributions at the edges.
    # The source formula: cy1_lo[..., 1:] - cy1_hi[..., :-1]
    # cy1_lo[..., 1:] is cumsum at t0[i+1] (left side)
    # cy1_hi[..., :-1] is cumsum at t0[i] (right side)
    
    idx_hi_curr = idx_hi[..., :-1]
    idx_lo_next = idx_lo[..., 1:]
    
    condition = idx_hi_curr <= idx_lo_next
    cy1_lo_next = cy1_lo[..., 1:]
    cy1_hi_curr = cy1_hi[..., :-1]
    
    y0_inner = torch.where(condition, cy1_lo_next - cy1_hi_curr, torch.zeros_like(cy1_lo_next))
    
    if not use_avg:
        # Return sum (Outer measure is the sum of the function over the interval)
        # Note: The source notes for use_avg=False describe a different path involving 
        # cumsum(vp) and interpolation. However, the outer measure calculation above 
        # effectively computes the integral (sum) of the step function over the interval.
        # If the source implies a linear interpolation of the CDF for use_avg=False,
        # that would be a different method. Given the alias "Inner/Outer Measures",
        # the outer measure is the standard "sum" result.
        return y0_outer
    else:
        # Use average
        # Resample weighted values and widths
        # 1. Compute widths of original steps
        # diff(t1) shape (..., N-1)
        wp = torch.diff(t1, dim=-1)
        
        # 2. Resample weighted values (y1 * wp) using sum mode
        # We can reuse the outer measure logic on weighted values
        y1_weighted = y1 * wp
        # Recompute cumsum for weighted values
        cy1_w = torch.cat([zeros, torch.cumsum(y1_weighted, dim=-1)], dim=-1)
        cy1_w_lo = torch.take_along_dim(cy1_w, idx_lo, dim=-1)
        cy1_w_hi = torch.take_along_dim(cy1_w, idx_hi, dim=-1)
        v_numer = cy1_w_hi[..., 1:] - cy1_w_lo[..., :-1]
        
        # 3. Resample widths wp using sum mode
        # Treat wp as values and 1 as... no, just sum wp over intervals
        # We need to sum wp over the intervals defined by t0
        # This is equivalent to computing the length of the intersection of [t0[i], t0[i+1]] with the steps
        # The length of the interval is t0[i+1] - t0[i]
        # However, the source says "Resample the widths wp using sum mode".
        # This implies we treat wp as the values of a step function defined by t1.
        # So we compute the sum of wp over [t0[i], t0[i+1]].
        # This is exactly the length of the intersection of the query interval with the support of the step function.
        # If t0 is within t1, this is just t0[i+1] - t0[i].
        # If t0 extends beyond, it clips.
        
        # Let's use the same outer measure logic for wp
        # Values are wp, endpoints are t1
        cy1_wp = torch.cat([zeros, torch.cumsum(wp, dim=-1)], dim=-1)
        cy1_wp_lo = torch.take_along_dim(cy1_wp, idx_lo, dim=-1)
        cy1_wp_hi = torch.take_along_dim(cy1_wp, idx_hi, dim=-1)
        v_denom = cy1_wp_hi[..., 1:] - cy1_wp_lo[..., :-1]
        
        # 4. Compute average
        v_avg = v_numer / torch.max(v_denom, torch.full_like(v_denom, eps))
        
        return v_avg
```

**Edge Cases and Pitfalls:**
- If `t0` contains points outside the range of `t1`, `searchsorted` handles boundaries, but the cumulative sum differences must be interpreted correctly (clamping to the domain of the step function).
- Division by zero in `use_avg=True` is prevented by `eps` [S1, unofficial].
- Precision issues may arise if `t1` and `t0` have very close values, leading to `idx_hi == idx_lo` and zero-width intervals.

## Subtopics

### Interval Sampling
Samples intervals from a step function by reflecting midpoints around sampled centers. It is chosen when uniform sampling of intervals is required rather than point queries.
- **Definition:** Samples intervals (rather than points) from a step function by reflecting midpoints around sampled centers [S1, unofficial].
- **Steps:**
    1. Sample centers using `sample(..., deterministic_center=True)` [S1, unofficial].
    2. Compute midpoints between adjacent centers: `mid = (centers[..., 1:] + centers[..., :-1]) / 2` [S1, unofficial].
    3. Compute first fencepost by reflecting first midpoint around first center, clamped to `minval`: `first = (2 * centers[..., :1] - mid[..., :1]).clamp_min(minval)` [S1, unofficial].
    4. Compute last fencepost by reflecting last midpoint around last center, clamped to `maxval`: `last = (2 * centers[..., -1:] - mid[..., -1:]).clamp_max(maxval)` [S1, unofficial].
    5. Concatenate first, mid, and last: `t_samples = torch.cat([first, mid, last], dim=-1)` [S1, unofficial].
- **Pitfall:** Raises `ValueError` if `num_samples <= 1` [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N \log M + M \log N)$ or $O(N + M)$ if `t1` and `t0` are sorted and `searchsorted` is linear, where $N$ is the number of step endpoints and $M$ is the number of query points. The dominant operation is `searchsorted` [S1, unofficial].
- **Memory Complexity:** $O(N + M)$ for storing cumulative sums and indices [S1, unofficial].
- **Strengths:** Exact integration of step functions; efficient vectorized implementation using cumulative sums; handles arbitrary query intervals [S1, unofficial].
- **Limitations:** Requires sorted input arrays; precision issues with very small intervals or values close to machine epsilon [S1, unofficial].
- **When to use:** When resampling piecewise constant data (e.g., histograms, discrete labels) to a new grid or set of intervals [S1, unofficial].
- **When not to use:** When linear or higher-order interpolation is required (use [Piecewise Linear Interpolation (Lookup Table)](2643-piecewise-linear-interpolation-lookup-table.md)) [S1, unofficial].

## Background
Step Function Resampling is a technique used in volume rendering and graphics to efficiently evaluate transfer functions or histograms defined on discrete intervals. It is implemented in the NVlabs InstantSplat project for fast runtime performance [S1, unofficial]. The method leverages cumulative sums to avoid explicit loops over intervals, enabling GPU acceleration.
