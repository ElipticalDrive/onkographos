# Blurring a Step Function

Also called: Step Function Blurring

## Overview
Blurring a Step Function is an algorithm that convolves a step function with a rectangular pulse to yield a piecewise linear spline [S1]. It operates directly on input arrays $x$ and $y$ representing the domain and range values of the step function [S1].

## How it works
**Inputs:**
- `x`: Array of $N$ domain values [S1].
- `y`: Array of $N$ range values [S1].
- `r`: Scalar half-width of the rectangular pulse [S1].

**Outputs:**
- `xr`: Array of $2N$ sorted domain values defining the breakpoints of the resulting spline [S1].
- `yr`: Array of $2N$ range values defining the piecewise linear spline at `xr` [S1].

**Data Structures:**
- Dense arrays of length $N$ for inputs and length $2N$ for outputs [S1].

**Parameters:**
- `r`: Half-width of the rectangular pulse [S1].
- Typical values: Not given in the sources.

**Algorithm Steps:**
1. Concatenate arrays $[x - r, x + r]$ and sort them to obtain `xr` and `sortidx` (the indices of the sorted elements) [S1].
2. Compute intermediate slopes $y'$ by subtracting shifted $y$ arrays and dividing by $2r$: $y' = ([y, 0] - [0, y]) / (2r)$ [S1].
3. Compute $y''$ by concatenating $[y', -y']$ and reordering according to `sortidx` excluding the last element: $y'' = \text{concatenate}([y', -y'])[\text{sortidx}[:-1]]$ [S1].
4. Compute output `yr` by taking the cumulative sum of the product of interval lengths (`xr[1:] - xr[:-1]`) and the cumulative sum of $y''$: `yr = [0, cumsum((xr[1:] - xr[:-1]) * cumsum(y''))]` [S1].

**Pseudocode:**
```python
def concatenate(a, b):
    return a + b

def sort_with_indices(arr):
    indices = sorted(range(len(arr)), key=lambda i: arr[i])
    return [arr[i] for i in indices], indices

def cumsum(arr):
    result = []
    s = 0.0
    for v in arr:
        s += v
        result.append(s)
    return result

def blur_stepfun(x, y, r):
    # Step 1: Compute breakpoints and sort indices
    x_shifted = concatenate([x - r, x + r])
    xr, sortidx = sort_with_indices(x_shifted)
    
    # Step 2: Compute slopes y'
    y_appended = concatenate([y, [0]])
    y_prepended = concatenate([[0], y])
    y_prime = [(ya - yp) / (2 * r) for ya, yp in zip(y_appended, y_prepended)]
    
    # Step 3: Compute y''
    y_double = concatenate([y_prime, [-v for v in y_prime]])
    y_double_prime = [y_double[i] for i in sortidx[:-1]]
    
    # Step 4: Compute yr
    dx = [xr[i+1] - xr[i] for i in range(len(xr) - 1)]
    cum_y_double_prime = cumsum(y_double_prime)
    weighted_cum = [d * c for d, c in zip(dx, cum_y_double_prime)]
    cum_weighted = cumsum(weighted_cum)
    yr = [0.0] + cum_weighted
    
    return xr, yr
```

**Edge Cases and Pitfalls:**
- The algorithm requires $r > 0$ to avoid division by zero [S1].
- If $x$ is not sorted, the sorting step reorders the domain, but the step function definition implies monotonic $x$ [S1].
