# Transfer Function Definition

Also called: 1D Transfer Function Definition, Composite Transfer Function Definition, Control Point Transfer Function Editor & Sampling, Piecewise Linear TF, TF Definition from Knots, TFEditor

## Overview
The Transfer Function Definition maps scalar volume data values to optical properties (color and opacity) using a piecewise linear function defined by control points [S1, S2, unofficial]. It is distinguished from its parent [1D Transfer Function Editor](8746-1d-transfer-function-editor.md) by being the underlying mathematical model and data structure, whereas the editor is the user interface component that manipulates these points [S2, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A set of control points for opacity (`alpha`) and color (`colors`), sorted by their domain coordinate $x$ [S2, unofficial].
*   **Output:** A compiled lookup table (LUT) `mLUT` of size `mLUTSize`, where each entry is a 4-component vector containing $(r, g, b, a)$ [S2, unofficial].

**Data Structures**
The control points are stored in two separate sorted vectors [S2, unofficial]:
1.  `std::vector<AlphaPoint> alpha`:
    *   `x`: `float`, domain coordinate.
    *   `a`: `float`, opacity value.
2.  `std::vector<ColorPoint> colors`:
    *   `x`: `float`, domain coordinate.
    *   `c`: `glm::vec3`, RGB color value.

The compiled LUT is `std::vector<glm::vec4> mLUT` [S2, unofficial]. Each entry `mLUT[i]` packs the interpolated color and opacity: `vec4(c, a)` [S2, unofficial].

**Parameters**
*   `mLUTSize`: Number of entries in the lookup table. Clamped to $\max(16, n)$ to prevent undersampling, where $n$ is the number of control points [S2, unofficial].

**Steps**
1.  **Sort and Clamp:** Sort `alpha` and `colors` vectors by $x$-coordinate. Force the first point's $x$ to $0.0$ and the last point's $x$ to $1.0$ for both vectors to ensure full domain coverage [S2, unofficial].
2.  **Sample Function:** To evaluate a value at domain coordinate $x$:
    *   If $x \le x_{front}$, return the front point's value [S2, unofficial].
    *   If $x \ge x_{back}$, return the back point's value [S2, unofficial].
    *   Otherwise, find interval $i$ such that $x_i \le x \le x_{i+1}$ [S2, unofficial].
    *   Compute interpolation factor $t = \frac{x - x_i}{x_{i+1} - x_i}$ [S2, unofficial].
    *   Return $(1-t)v_i + t v_{i+1}$, where $v$ is the value (opacity or color) [S2, unofficial].
3.  **Build LUT:**
    *   Resize `mLUT` to `mLUTSize` [S2, unofficial].
    *   For each index $i$ from $0$ to `mLUTSize` - 1:
        *   Compute $x = 0.0$ if `mLUTSize` == 1, else $x = \frac{i}{\text{mLUTSize} - 1}$ [S2, unofficial].
        *   Sample opacity $a = \text{sampleAlpha}(x)$ [S2, unofficial].
        *   Sample color $c = \text{sampleColor}(x)$ [S2, unofficial].
        *   Set `mLUT[i] = vec4(c, a)` [S2, unofficial].

**Pseudocode**
```python
def sample_alpha(x, alpha_points):
    """Sample opacity from sorted alpha control points."""
    if not alpha_points:
        return 0.0  # [G] Fallback for empty list; evidence does not specify behavior.
    if x <= alpha_points[0].x:
        return alpha_points[0].a
    if x >= alpha_points[-1].x:
        return alpha_points[-1].a
    for i in range(len(alpha_points) - 1):
        if alpha_points[i].x <= x <= alpha_points[i+1].x:
            t = (x - alpha_points[i].x) / (alpha_points[i+1].x - alpha_points[i].x)
            return (1 - t) * alpha_points[i].a + t * alpha_points[i+1].a
    return 0.0

def sample_color(x, color_points):
    """Sample color from sorted color control points."""
    if not color_points:
        return (1.0, 1.0, 1.0)  # [G] Fallback for empty list; evidence returns white.
    if x <= color_points[0].x:
        return color_points[0].c
    if x >= color_points[-1].x:
        return color_points[-1].c
    for i in range(len(color_points) - 1):
        if color_points[i].x <= x <= color_points[i+1].x:
            t = (x - color_points[i].x) / (color_points[i+1].x - color_points[i].x)
            c_i = color_points[i].c
            c_next = color_points[i+1].c
            return (
                (1 - t) * c_i[0] + t * c_next[0],
                (1 - t) * c_i[1] + t * c_next[1],
                (1 - t) * c_i[2] + t * c_next[2]
            )
    return (1.0, 1.0, 1.0)

def build_lut(alpha_points, color_points, mLUTSize):
    """Build the GPU-friendly lookup table."""
    n = max(len(alpha_points), len(color_points))
    actual_size = max(16, mLUTSize)
    lut = []
    for i in range(actual_size):
        x = 0.0 if actual_size == 1 else i / (actual_size - 1)
        a = sample_alpha(x, alpha_points)
        c = sample_color(x, color_points)
        lut.append((c[0], c[1], c[2], a))
    return lut
```

**Edge Cases and Pitfalls**
*   **Point Crossing:** Dragging an internal control point horizontally is clamped to $\max(x_{\text{left}} + 10^{-4}, \min(x_{\text{right}} - 10^{-4}, x_{\text{new}}))$ to maintain sorted order [S2, unofficial].
*   **Endpoint Protection:** Endpoints (index 0 and size-1) cannot be deleted, and their $x$-coordinates are not clamped by neighbors during dragging to preserve domain bounds $[0, 1]$ [S2, unofficial].
