# Cubic Spline Transfer Function
Also called: TF1DCubic
## Overview
A 1D transfer function that maps a scalar field value in $[0, 1]$ to density and attenuation color using cubic spline interpolation of control points [S1, unofficial]. It builds on [1D Lookup Table with Interpolation](2528-1d-lookup-table-with-interpolation.md) by evaluating piecewise cubic Hermite polynomials between control points [G].
## How it works
**Inputs and outputs:**
- Input: A scalar value $x \in [0, 1]$ [S1, unofficial].
- Input: An array of $N$ control points $P_i = (v_i, c_i)$, where $v_i$ is the scalar domain value and $c_i$ is the output color/density range value, sorted by $v_i$ [S1, unofficial].
- Output: A color/density vector $C(x)$ [S1, unofficial].

**Data structures:**
- `ControlPoint`: Struct containing `value` (float, domain) and `output` (3-component vector, range) [S1, unofficial].
- `ControlPoints`: Array of `ControlPoint` structs, size $N$ [S1, unofficial].

**Steps:**
1. **Find the interval:** Determine the index `left_point` such that $v_{\text{left\_point}} \le x < v_{\text{left\_point} + 1}$ [S1, unofficial].
   - Iterate: `while (x > control_points[left_point + 1].value) ++left_point;` [S1, unofficial].
   - Clamp: `left_point = clamp(left_point, 0, N - 2)` [S1, unofficial].
2. **Compute slope $m_k$ at $P_k$ (where $k = \text{left\_point}$):**
   - If $k = 0$: $m_k = \frac{c_1 - c_0}{v_1 - v_0}$ [S1, unofficial].
   - Otherwise: $m_k = \frac{1}{2} \left( \frac{c_k - c_{k-1}}{v_k - v_{k-1}} + \frac{c_{k+1} - c_k}{v_{k+1} - v_k} \right)$ [S1, unofficial].
3. **Compute slope $m_{k+1}$ at $P_{k+1}$:**
   - If $k + 1 = N - 1$: $m_{k+1} = \frac{c_{k+1} - c_k}{v_{k+1} - v_k}$ [S1, unofficial].
   - Otherwise: $m_{k+1} = \frac{1}{2} \left( \frac{c_{k+2} - c_{k+1}}{v_{k+2} - v_{k+1}} + \frac{c_{k+1} - c_k}{v_{k+1} - v_k} \right)$ [S1, unofficial].
4. **Evaluate Cubic Spline:**
   - Compute $\Delta = v_{k+1} - v_k$ [S1, unofficial].
   - Compute $t = \frac{\max(0, x - v_k)}{\Delta}$ [S1, unofficial].
   - Compute basis functions:
     $$h_{00} = 2t^3 - 3t^2 + 1$$
     $$h_{10} = t^3 - 2t^2 + t$$
     $$h_{01} = -2t^3 + 3t^2$$
     $$h_{11} = t^3 - t^2$$
   - Result: $C(x) = h_{00} c_k + h_{10} \Delta m_k + h_{01} c_{k+1} + h_{11} \Delta m_{k+1}$ [S1, unofficial].

**Pseudocode:**
```python
class Vec3:
    def __init__(self, x=0.0, y=0.0, z=0.0):
        self.x, self.y, self.z = x, y, z
    def __add__(self, other): return Vec3(self.x + other.x, self.y + other.y, self.z + other.z)
    def __sub__(self, other): return Vec3(self.x - other.x, self.y - other.y, self.z - other.z)
    def __mul__(self, scalar): return Vec3(self.x * scalar, self.y * scalar, self.z * scalar)
    def __truediv__(self, scalar): return Vec3(self.x / scalar, self.y / scalar, self.z / scalar)

def cubic_spline_transfer_function(x, control_points):
    n = len(control_points)
    if n < 2:
        return control_points[0][1] if n == 1 else Vec3(0.0, 0.0, 0.0)

    # Step 1: Find left_point
    left_point = 0
    while left_point < n - 2 and x > control_points[left_point + 1][0]:
        left_point += 1
    left_point = max(0, min(left_point, n - 2))

    k = left_point
    v_k, c_k = control_points[k]
    v_k1, c_k1 = control_points[k + 1]

    # Step 2: Compute slope m_k
    if k == 0:
        dv = v_k1 - v_k
        m_k = (c_k1 - c_k) / dv
    else:
        dv_prev = v_k - control_points[k - 1][0]
        dv_next = v_k1 - v_k
        s_prev = (c_k - control_points[k - 1][1]) / dv_prev
        s_next = (c_k1 - c_k) / dv_next
        m_k = (s_prev + s_next) * 0.5

    # Step 3: Compute slope m_k1
    if k + 1 == n - 1:
        dv = v_k1 - v_k
        m_k1 = (c_k1 - c_k) / dv
    else:
        dv_prev = v_k1 - v_k
        dv_next = control_points[k + 2][0] - v_k1
        s_prev = (c_k1 - c_k) / dv_prev
        s_next = (control_points[k + 2][1] - c_k1) / dv_next
        m_k1 = (s_prev + s_next) * 0.5

    # Step 4: Evaluate Cubic Spline
    delta = v_k1 - v_k
    if delta == 0:
        return c_k  # Guard against division by zero [G]
    t = max(0.0, (x - v_k) / delta)
    t = min(1.0, t)  # Clamp to [0, 1] [G]
    t2 = t * t
    t3 = t2 * t

    h00 = 2.0 * t3 - 3.0 * t2 + 1.0
    h10 = t3 - 2.0 * t2 + t
    h01 = -2.0 * t3 + 3.0 * t2
    h11 = t3 - t2

    return h00 * c_k + h10 * delta * m_k + h01 * c_k1 + h11 * delta * m_k1
```

**Parameters:**
- Control points: Defined by the user [S1, unofficial].
- $x$: Scalar value from the volume, normalized to $[0, 1]$ [S1, unofficial].

**Edge cases and pitfalls:**
- Division by zero: If $v_{k+1} = v_k$, the slope calculation involves division by zero; the implementation should handle this by setting the slope to zero or using a fallback [G].
- Boundary conditions: The slopes at the endpoints ($k=0$ and $k=N-1$) are computed using one-sided difference quotients or averages as specified [S1, unofficial].
- Precision: Floating-point precision issues may arise if $x$ is very close to a control point value; clamping $t$ to $[0, 1]$ is recommended [G].

This method manages 1D transfer functions for volume rendering by mapping scalar density values (0–255) to RGBA colors using cubic spline interpolation of control points, while caching the results in a 256-entry indexed array for fast integer lookup. It builds on [Cubic Spline Transfer Function](1811-cubic-spline-transfer-function.md) by adding an explicit indexed cache and lazy texture synchronization, distinguishing itself from standard spline implementations by decoupling the smooth float-based interpolation logic from the discrete integer-based rendering lookup. Choose this variant when fast integer-based rendering lookup is required without sacrificing the smoothness of cubic spline interpolation.
