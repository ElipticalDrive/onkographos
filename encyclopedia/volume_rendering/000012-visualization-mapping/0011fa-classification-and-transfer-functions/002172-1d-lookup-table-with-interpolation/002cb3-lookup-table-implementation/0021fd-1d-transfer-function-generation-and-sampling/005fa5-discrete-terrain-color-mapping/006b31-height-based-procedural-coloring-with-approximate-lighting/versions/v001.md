# Height-Based Procedural Coloring with Approximate Lighting

Also called: Distance Threshold Shading, Heightmap Color Mapping

## Overview
This method assigns discrete color bands to a volume or surface based on the normalized distance of each fragment from a central reference point, effectively mapping "height" relative to a planet or sphere. It approximates directional lighting by comparing the distance of the fragment and a center point to a hardcoded light source, modulating the fragment's emission intensity based on this difference. It builds on [Discrete Terrain Color Mapping](17937-discrete-terrain-color-mapping.md) by replacing static palette indices with continuous distance-based interpolation and adding a simplified lighting model.

## How it works
**Inputs:**
- `IN.objPos.xyz`: Fragment position in world/object space.
- `_CentrePoint`: Vector defining the center of the volume (default `(0,0,0,0)`).
- `_planetRadius`: Float defining the reference radius for normalization (default `0`).
- `_Yellow`, `_Green`, `_White`, `_Black`: Color constants defining the terrain palette.
- Hardcoded light position: `L = (1000.0, 0.0, -1000.0)`.

**Outputs:**
- `o.Emission`: The final color with lighting approximation applied.

**Data Structures:**
- No complex data structures are required. The method relies on scalar distance calculations and conditional logic.

**Steps:**

1.  **Calculate Radial Distance:**
    Compute the Euclidean distance from the center point to the fragment position:
    $$ d_{raw} = \text{distance}(\text{_CentrePoint}, \text{IN.objPos.xyz}) $$
    [S1, unofficial]

2.  **Normalize Height:**
    Subtract the planet radius to get the normalized height relative to the surface:
    $$ h = d_{raw} - \text{_planetRadius} $$
    [S1, unofficial]

3.  **Apply Color Thresholds:**
    Determine the base color $c$ based on $h$ using specific thresholds and linear interpolation (lerp):
    - If $h < -0.1$: $c = \text{_Yellow}$
    - If $-0.1 \le h < 0.1$: $c = \text{lerp}(\text{_Yellow}, \text{_Green}, (h + 0.1) \times 5)$
    - If $0.1 \le h < 0.8$: $c = \text{_Green}$
    - If $0.8 \le h < 0.9$: $c = \text{lerp}(\text{_Green}, \text{_White}, (h - 0.8) \times 10)$
    - If $h \ge 0.9$: $c = \text{_White}$
    [S1, unofficial]

4.  **Fade to Black:**
    Apply a global fade based on the normalized distance to blend into darkness at extreme distances:
    $$ c = \text{lerp}(\text{_Black}, c, \frac{h + 1}{2}) $$
    [S1, unofficial]

5.  **Compute Lighting Difference:**
    Calculate the distance from the center point and the fragment to the hardcoded light position $L$:
    $$ d_{center} = \text{distance}(\text{_CentrePoint}, L) $$
    $$ d_{frag} = \text{distance}(\text{IN.objPos.xyz}, L) $$
    $$ diff = d_{center} - d_{frag} $$
    [S1, unofficial]

6.  **Apply Emission Lighting:**
    Modulate the color $c$ based on $diff$ to simulate directional lighting:
    - If $diff < -10$: $o.Emission = c.rgb$
    - If $diff > 10$: $o.Emission = c.rgb / 6$
    - If $-10 \le diff \le 10$: $o.Emission = \text{lerp}(c.rgb, c.rgb / 6, \frac{diff + 10}{20})$
    [S1, unofficial]

**Pseudocode:**
```python
def height_based_coloring(obj_pos, centre_point, planet_radius, yellow, green, white, black, light_pos=(1000.0, 0.0, -1000.0)):
    # Step 1: Calculate radial distance
    raw_dist = distance(centre_point, obj_pos)
    
    # Step 2: Normalize height
    h = raw_dist - planet_radius
    
    # Step 3: Apply color thresholds
    if h < -0.1:
        c = yellow
    elif h < 0.1:
        t = (h + 0.1) * 5
        c = lerp(yellow, green, t)
    elif h < 0.8:
        c = green
    elif h < 0.9:
        t = (h - 0.8) * 10
        c = lerp(green, white, t)
    else:
        c = white
        
    # Step 4: Fade to black
    fade_factor = (h + 1) / 2
    c = lerp(black, c, fade_factor)
    
    # Step 5: Compute lighting difference
    centre_dist = distance(centre_point, light_pos)
    frag_dist = distance(obj_pos, light_pos)
    diff = centre_dist - frag_dist
    
    # Step 6: Apply emission lighting
    if diff < -10:
        emission = c.rgb
    elif diff > 10:
        emission = c.rgb / 6.0
    else:
        t = (diff + 10) / 20.0
        emission = lerp(c.rgb, c.rgb / 6.0, t)
        
    return emission
```
[G] The `distance` function computes the Euclidean norm $\sqrt{x^2 + y^2 + z^2}$. The `lerp(a, b, t)` function computes $a + t(b-a)$.

## Subtopics

### Distance-Based Discrete Color Banding
Applies discrete color bands based on the distance from a center point to the object position using strict threshold comparisons without the intermediate interpolation or lighting model. It uses a fixed center at `(0,0,1)` and thresholds at 1.25, 1.3005, 1.32, 1.38, and 1.5 to assign Blue, Cyan, Yellow, Green, and White respectively. This variant is simpler but lacks the smooth transitions and lighting approximation of the parent method. [S1, unofficial]

## Operating characteristics
- **Time Complexity:** $O(1)$ per fragment. The method involves a constant number of arithmetic operations, distance calculations, and conditional branches.
- **Memory Complexity:** $O(1)$. No additional data structures are allocated per fragment.
- **Strengths:** Computationally inexpensive; provides immediate visual feedback for spherical or planetary volumes; simple to implement in shaders.
- **Limitations:** The lighting model is an approximation based on distance differences rather than surface normals, which may not accurately represent shading on complex geometries. The hardcoded light position limits flexibility.
- **When to use:** Suitable for procedural planets, spheres, or any volume where height is defined radially from a center.
- **When not to use:** When accurate directional lighting based on surface normals is required, or when the light source position needs to be dynamic.

## Background
This method originates from the `proceduralplanet` project by paolorussian, which generates procedural planets using voxel-based terrain generation. It is used to color the generated terrain based on altitude relative to the planet's radius, providing a visual distinction between ocean, land, and snow peaks, while approximating sunlight direction.
