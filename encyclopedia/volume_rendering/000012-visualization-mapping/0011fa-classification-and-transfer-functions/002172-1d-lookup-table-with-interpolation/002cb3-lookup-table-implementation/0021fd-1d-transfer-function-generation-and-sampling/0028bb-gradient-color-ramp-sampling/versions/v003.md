# Gradient/Color Ramp Sampling

Also called: Color Ramp Sampling, Gradient Texture Sampling

## Overview
Gradient/Color Ramp Sampling maps scalar intensity values to RGBA colors by sampling a 2D gradient texture [S2, unofficial]. It differs from direct 1D LUT interpolation by using a 2D texture lookup where the scalar value typically drives the horizontal axis while the vertical axis is fixed or used for secondary parameters, enabling combined color and opacity mapping in a single pass [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Scalar intensity value (often extracted from a volume texture's red channel), a 2D gradient texture, and a gamma exponent [S2, unofficial].
*   **Output:** RGBA color value [S2, unofficial].

**Data Structures:**
*   **Gradient Stops:** Defined by position (offset) and RGBA values [G].
*   **GradientTexture2D:** A 2D texture resource. When `use_hdr` is enabled, the texture preserves floating-point channels above 1.0 [S1, unofficial].

**Steps:**
1.  Extract intensity from the input sample (e.g., `intensity = layer_col.r`) [S2, unofficial].
2.  Apply gamma correction: `intensity = pow(intensity, gamma)` [S2, unofficial].
3.  Sample the 2D gradient texture using the corrected intensity as the x-coordinate and 0 as the y-coordinate: `color = texture(gradient, vec2(intensity, 0))` [S2, unofficial].
4.  Read the luminance in float format and truncate each channel for the color ramp, as implemented in Godot [S1, unofficial].
5.  Run the gradient sampler and channel-to-byte conversion in float precision [S1, unofficial].
6.  If `use_hdr` is true, retain channels above 1.0 without truncation [S1, unofficial].

**Pseudocode:**
```python
def sample_gradient_ramp(intensity: float, gradient_stops: list, gamma: float, use_hdr: bool) -> tuple:
    # 1. Gamma correction
    corrected_intensity = pow(intensity, gamma)
    # 2. Clamp to [0, 1] for texture coordinates
    t = clamp(corrected_intensity, 0.0, 1.0)
    # 3. Sample 2D gradient texture at (t, 0) via linear interpolation along the x-axis
    idx = t * (len(gradient_stops) - 1)
    i = int(idx)
    f = idx - i
    if i >= len(gradient_stops) - 1:
        color = gradient_stops[-1].color
    else:
        c0 = gradient_stops[i].color
        c1 = gradient_stops[i+1].color
        color = c0 + (c1 - c0) * f
    # 4 & 5. Process channels in float, then convert to byte if not HDR
    if use_hdr:
        return (color.r, color.g, color.b, color.a)
    else:
        # Truncate each channel to byte range [0, 255]
        r = int(clamp(color.r, 0.0, 1.0) * 255)
        g = int(clamp(color.g, 0.0, 1.0) * 255)
        b = int(clamp(color.b, 0.0, 1.0) * 255)
        a = int(clamp(color.a, 0.0, 1.0) * 255)
        return (r, g, b, a)
```

**Parameters:**
*   `gamma`: Exponent for gamma correction. Not given in the sources [S1, unofficial][S2, unofficial].
*   `use_hdr`: Boolean. When true, preserves floating-point channels above 1.0 [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **HDR Handling:** Enabling `use_hdr` preserves channels above 1.0, which requires floating-point render targets to avoid clipping [S1, unofficial].
*   **Quantization:** Truncation introduces quantization errors; fixing the ramp implementation reduced Godot-measured off-by-one byte errors from 1212 to 0 out of 2244 samples [S1, unofficial].
*   **Accuracy:** Mean error for `noisetexture2d` decreased from 0.776/255 to 0.735/255 after the ramp fix [S1, unofficial].

## Subtopics

### [Fire Color and Opacity Curves](16944-fire-color-and-opacity-curves.md)
Remaps grid simulation data channels (e.g., Temperature or Fuel) into render-ready color and opacity values for fire visualization. It distinguishes itself from generic transfer functions by explicitly separating color mapping (via a gradient) from intensity/opacity mapping (via a curve), with specific modes for handling opacity relative to smoke.

### Gradient Mapping
A technique to color volume data by mapping scalar intensity values to a 2D color gradient texture. The intensity is derived from the red channel of the volume texture. It applies gamma correction to the intensity and samples the 2D gradient texture using the intensity as the x-coordinate and 0 as the y-coordinate [S2, unofficial].
