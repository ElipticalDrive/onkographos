# Inverse Sigmoid Function
Also called: Inverse Sigmoid
## Overview
Computes the inverse of the sigmoid function, mapping probability values in $(0, 1)$ to the real line $(-\infty, \infty)$. It serves as the canonical link function in logistic regression and is used in volume rendering to invert normalized transfer function outputs back to logit space for linear interpolation or gradient-based optimization. Unlike the parent [Sigmoid Function with Jacobian](6497-sigmoid-function-with-jacobian.md) which maps reals to probabilities, this method performs the reverse transformation.

## How it works
**Inputs and Outputs:**
- Input: A scalar or tensor $x$ where $x \in (0, 1)$.
- Output: A scalar or tensor $y$ of the same shape, where $y \in \mathbb{R}$.

**Data Structures:**
- Input tensor $x$: Floating-point values.
- Output tensor $y$: Floating-point values.

**Formula:**
The inverse sigmoid function, also known as the logit function, is defined as [S2, unofficial]:
$$ f(x) = \log\left(\frac{x}{1-x}\right) $$
where $\log$ denotes the natural logarithm.

**Steps:**
1. Compute the ratio $r = \frac{x}{1-x}$.
2. Compute the natural logarithm of the ratio: $y = \log(r)$.

**Parameters:**
- None.

**Edge Cases and Pitfalls:**
- **Boundary Values:** The function is undefined at $x=0$ and $x=1$ due to division by zero and logarithm of zero/infinity. In practice, inputs must be clamped to a small epsilon range, e.g., $[\epsilon, 1-\epsilon]$, where $\epsilon$ is a small positive number (e.g., $10^{-7}$) to prevent numerical instability [G].
- **Precision:** For $x$ very close to 0 or 1, the ratio $x/(1-x)$ can underflow or overflow. Using `logit` implementations that handle these cases via `log(x) - log(1-x)` may offer better numerical stability for extreme values [G].

**Pseudocode:**
```python
import math

def inverse_sigmoid(x: float, epsilon: float = 1e-7) -> float:
    """
    Computes the inverse sigmoid (logit) of x.
    
    Args:
        x: Input value in (0, 1).
        epsilon: Small constant to clamp input boundaries.
        
    Returns:
        The logit of x.
    """
    # Clamp input to avoid division by zero or log(0)
    x_clamped = max(epsilon, min(1.0 - epsilon, x))
    
    # Compute logit: log(x / (1 - x))
    # Equivalent to log(x) - log(1 - x) for potentially better stability
    return math.log(x_clamped) - math.log(1.0 - x_clamped)
```

## Subtopics

### Logistic Regression Link
The standard link function for binary classification models.

### Probability Calibration
Used to map predicted probabilities to log-odds for calibration techniques.

## Operating characteristics
- **Time Complexity:** $O(1)$ per element.
- **Memory Complexity:** $O(1)$ auxiliary space.
- **Strengths:** Simple, differentiable, and numerically stable with clamping.
- **Limitations:** Undefined at exact boundaries 0 and 1; requires careful handling of floating-point precision near boundaries.
- **When to use:** When converting normalized probabilities back to unbounded real values, such as in inverse transfer function mapping or logistic regression loss computation.
- **When not to use:** When inputs are not strictly within $(0, 1)$ or when numerical stability at boundaries is critical without clamping.

## Background
The inverse sigmoid function, or logit, originates from logistic regression and statistical modeling. It is widely used in machine learning and computer vision, including recent 3D Gaussian Splatting implementations where it is used to handle opacity or color values in logit space for better optimization dynamics [S1, S2, unofficial].
