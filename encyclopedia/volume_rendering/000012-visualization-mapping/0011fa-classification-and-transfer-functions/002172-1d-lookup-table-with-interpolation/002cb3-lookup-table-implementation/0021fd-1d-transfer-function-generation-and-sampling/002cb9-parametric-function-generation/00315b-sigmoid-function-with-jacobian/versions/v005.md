# Sigmoid Function with Jacobian

Also called: Sigmoid, Sigmoid derivative

## Overview
Computes the logistic sigmoid function and its analytical derivative (Jacobian) for a scalar input [S1, unofficial]. It maps real-valued inputs to the $(0, 1)$ range, providing a smooth, differentiable activation often used in transfer functions for soft classification or as a component in more complex parametric mappings [G]. It is distinguished from siblings like the Gaussian Transfer Function by its asymmetric S-shape and bounded output range, whereas Gaussians are symmetric and bell-shaped [G].

## How it works
**Inputs and outputs:**
- Input: A scalar value $x \in \mathbb{R}$.
- Outputs: The sigmoid value $s \in (0, 1)$ and its derivative $s' \in (0, 0.25]$ [S1, unofficial].

**Data structures:**
- No complex data structures; operates on scalar floats [G].

**Formulas:**
The sigmoid function is defined as:
$$ s = \sigma(x) = \frac{1}{1 + e^{-x}} $$

The derivative (Jacobian) with respect to $x$ is:
$$ \frac{ds}{dx} = s(1 - s) $$

**Parameters:**
- None. The function is standard [G].

**Edge cases and pitfalls:**
- **Numerical Stability:** For large negative $x$, $e^{-x}$ overflows in floating-point arithmetic. A numerically stable implementation checks the sign of $x$ and computes $e^x/(1+e^x)$ for $x < 0$ [G].
- **Derivative Range:** The maximum derivative is $0.25$ at $x=0$, which limits gradient magnitude in optimization [G].

**Pseudocode:**
```python
import math

def sigmoid(x):
    """Computes sigma(x) = 1 / (1 + exp(-x)). Handles overflow for x < 0."""
    if x >= 0:
        z = math.exp(-x)
        return 1.0 / (1.0 + z)
    else:
        z = math.exp(x)
        return z / (1.0 + z)

def sigmoid_with_jacobian(x):
    """Computes sigmoid and its derivative. Returns (s, ds_dx)."""
    s = sigmoid(x)
    ds_dx = s * (1.0 - s)
    return s, ds_dx
```

## Subtopics

### Inverse Sigmoid Function
Computes the inverse sigmoid function, also known as the logit function [S2, unofficial]. It maps a value $x \in (0, 1)$ back to the real line $\mathbb{R}$ [G]. It is defined as $\text{logit}(x) = \ln\left(\frac{x}{1-x}\right)$ [S2, unofficial]. Implementation returns `math.log(x / (1 - x))` [S2, unofficial]. This is useful for converting normalized probabilities or transfer function outputs back to the original data space [G].

## Operating characteristics
- **Time Complexity:** $O(1)$. Requires one exponential and a few arithmetic operations [G].
- **Memory Complexity:** $O(1)$ [G].
- **Strengths:** Smooth, differentiable, bounded output. Analytical derivative is cheap to compute from the function output [G].
- **Limitations:** Asymmetric; saturates at 0 and 1, leading to vanishing gradients for extreme inputs. Not suitable for symmetric highlighting of a specific range (use Gaussian for that) [G].
- **When to use:** When a smooth, monotonic transition from 0 to 1 is needed, or when the derivative is required for optimization or sensitivity analysis [G].
