# Sigmoid Function with Jacobian

Also called: Logistic Function, Logistic Sigmoid, Sigmoid Function, Sigmoid derivative

## Overview
Computes the logistic sigmoid function $\sigma(x)$ and its analytical derivative $\sigma'(x)$ for a scalar input $x$ [S2, unofficial]. It serves as a differentiable activation function in volume rendering and differentiable rendering pipelines, mapping real-valued inputs to the $(0, 1)$ interval while providing gradient information for optimization [S1][S2, unofficial].

## How it works
**Inputs and outputs:**
- Input: A scalar value $x \in \mathbb{R}$.
- Output: A tuple $(s, ds)$, where $s = \sigma(x) \in (0, 1)$ is the sigmoid value, and $ds = \sigma'(x)$ is the derivative with respect to $x$ [S2, unofficial].

**Data structures:**
- No complex data structures are required; the computation operates on scalar floating-point values [G].

**Steps:**
1. Compute the exponential term $e^{-x}$.
2. Compute the sigmoid value $s$ using the logistic formula [S2, unofficial].
3. Compute the derivative $ds$ using the identity $\sigma'(x) = s(1-s)$ [S2, unofficial].

**Formulas:**
The logistic sigmoid function is defined as [S1][S2, unofficial]:
$$ s = \sigma(x) = \frac{1}{1 + e^{-x}} $$

The derivative of the sigmoid function is [S2, unofficial]:
$$ \frac{ds}{dx} = s(1 - s) $$

**Parameters:**
- None. The function is standard and parameter-free [G].

**Edge cases and pitfalls:**
- **Numerical Stability:** For large positive $x$, $e^{-x}$ approaches 0 and $s$ approaches 1. For large negative $x$, $e^{-x}$ becomes very large, potentially causing overflow if computed naively as $1/(1+e^{-x})$ without care, though standard IEEE 754 floating-point handles large exponents by saturating to infinity, resulting in $s=0$ [G].
- **Derivative at Extremes:** As $x \to \pm \infty$, $ds \to 0$, which can lead to vanishing gradients in deep optimization problems [G].

**Pseudocode:**
```python
import math

def sigmoid_with_jacobian(x: float) -> tuple[float, float]:
    exp_neg_x = math.exp(-x)
    s = 1.0 / (1.0 + exp_neg_x)
    ds = s * (1.0 - s)
    return s, ds
```

## Subtopics

### [Inverse Sigmoid Function](7961-inverse-sigmoid-function.md)
Computes the inverse of the sigmoid function, mapping probability values in $(0, 1)$ to the real line $(-\infty, \infty)$. It serves as the canonical link function in logistic regression and is used in volume rendering to invert normalized transfer function outputs back to logit space for linear interpolation or gradient-based optimization. Unlike the parent [Sigmoid Function with Jacobian](6497-sigmoid-function-with-jacobian.md) which maps reals to probabilities, this method performs the reverse transformation [G].

## Operating characteristics
- **Time Complexity:** $O(1)$ per evaluation, requiring one exponential and a few arithmetic operations [G].
- **Memory Complexity:** $O(1)$. No auxiliary storage is needed [G].
- **Strengths:** Analytically differentiable, computationally inexpensive, and bounded output makes it suitable for probabilistic interpretations and soft thresholding in differentiable renderers [S1].
- **Limitations:** Suffers from vanishing gradients for large $|x|$ [G].
- **When to use:** When a smooth, monotonic transition between two states is required, or when aggregating probabilistic contributions in differentiable rendering [S1].
- **When not to use:** When the inverse mapping is required (use [Inverse Sigmoid Function](7961-inverse-sigmoid-function.md)) [G].

## Background
The logistic sigmoid function, also known as the FL function, corresponds to the logistic distribution [S1]. In the context of differentiable rendering, it is a popular choice for soft evaluation of geometric primitives (e.g., determining if a pixel lies inside a triangle) and for aggregating face contributions, where it provides a differentiable approximation of hard boolean operations [S1]. It is frequently referred to as "the" sigmoid in recent literature, distinguishing it from more general sigmoidal functions [S1].
