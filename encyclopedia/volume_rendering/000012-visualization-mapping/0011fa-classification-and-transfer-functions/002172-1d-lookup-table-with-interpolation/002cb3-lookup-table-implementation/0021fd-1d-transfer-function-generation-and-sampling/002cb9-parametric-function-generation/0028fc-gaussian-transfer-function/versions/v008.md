# Gaussian Transfer Function

Also called: 3-Gaussian Transfer Function, TransferFunctionWidget3

## Overview
The Gaussian Transfer Function constructs a 4-channel RGBA lookup table using three Gaussian bumps to map scalar values to color and opacity [S1, unofficial]. It differs from its siblings by explicitly normalizing RGB channels by their maximum sum to prevent overflow and by using fixed primary colors (red, green, blue) for the three respective bumps, whereas [Cosine Palette Color Mapping](3359-cosine-palette-color-mapping.md) uses a continuous palette and [Sigmoid Function with Jacobian](6497-sigmoid-function-with-jacobian.md) uses monotonic transitions [G].

## How it works
**Inputs and Outputs:**
- Input: Three sets of parameters $(level_j, opacity_j, width_j)$ for $j \in \{1, 2, 3\}$ [S1, unofficial].
- Output: A texture `rgba` of shape $(1024, 4)$, where index $i$ corresponds to normalized scalar $t = i/1023$ [S1, unofficial].

**Data Structures:**
- `rgba`: Array of shape $(1024, 4)$ [S1, unofficial].
- `colors`: Fixed list of RGB vectors: $[ (1,0,0), (0,1,0), (0,0,1) ]$ [S1, unofficial].

**Steps:**
1. Initialize `rgba` with zeros [S1, unofficial].
2. For each texel index $i$ from 0 to 1023:
   a. Calculate position $t = i / 1023.0$ [S1, unofficial].
   b. For each Gaussian $j \in \{1, 2, 3\}$:
      i. Calculate intensity: $I_j = \exp\left(-\left(\frac{t - level_j}{width_j}\right)^2\right)$ [S1, unofficial].
      ii. Add color contribution: `rgba[i, 0:3]` += `colors[j-1]` $\times opacity_j \times I_j$ [S1, unofficial].
      iii. Add opacity contribution: `rgba[i, 3]` += $opacity_j \times I_j$ [S1, unofficial].
   c. Normalize RGB: If `rgba[i, 0:3].max() > 0`, divide `rgba[i, 0:3]` by `rgba[i, 0:3].max()` [S1, unofficial]. If max is 0, leave RGB as 0 to avoid NaN [G].
   d. Clamp: `rgba[i]` = clip(`rgba[i]`, 0, 1) [S1, unofficial].

**Formulas:**
$$ I_j(t) = \exp\left(-\left(\frac{t - level_j}{width_j}\right)^2\right) $$ [S1, unofficial]
$$ \mathbf{C}_{raw}[i] = \sum_{j=1}^{3} \mathbf{c}_j \cdot opacity_j \cdot I_j(t) $$ [S1, unofficial]
$$ \alpha[i] = \sum_{j=1}^{3} opacity_j \cdot I_j(t) $$ [S1, unofficial]
$$ \mathbf{C}_{final}[i] = \text{clip}\left( \frac{\mathbf{C}_{raw}[i]}{\max(\mathbf{C}_{raw}[i])}, 0, 1 \right) $$ [S1, unofficial]

**Parameters:**
- `levels`: $[0.1, 0.5, 0.8]$ (Default) [S1, unofficial].
- `opacities`: $[0.4, 0.1, 0.1]$ (Default) [S1, unofficial].
- `widths`: $[0.1, 0.1, 0.1]$ (Default) [S1, unofficial].

**Pitfalls:**
- Division by zero if all Gaussians contribute 0 intensity at a specific $t$ [S1, unofficial]. The source code clips to [0,1] after division, which may leave NaNs if not guarded [S1, unofficial]. A guard `if max_val > 0` is required [G].

**Pseudocode:**
```python
import numpy as np

def generate_gaussian_tf(levels, opacities, widths):
    N = 1024
    rgba = np.zeros((N, 4))
    colors = np.array([[1, 0, 0], [0, 1, 0], [0, 0, 1]])
    
    for i in range(N):
        t = i / 1023.0
        rgb_sum = np.zeros(3)
        alpha_sum = 0.0
        
        for j in range(3):
            level = levels[j]
            opacity = opacities[j]
            width = widths[j]
            
            intensity = np.exp(-((t - level) / width) ** 2)
            
            rgb_sum += colors[j] * opacity * intensity
            alpha_sum += opacity * intensity
            
        max_rgb = np.max(rgb_sum)
        if max_rgb > 0:
            rgb_sum /= max_rgb
            
        rgba[i, 0:3] = rgb_sum
        rgba[i, 3] = alpha_sum
        
    return np.clip(rgba, 0, 1)
```
