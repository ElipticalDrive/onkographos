# Sigmoid Function with Jacobian

Also called: Sigmoid, Sigmoid derivative

## Overview
Computes the logistic sigmoid function and its analytical derivative for scalar inputs. It is used in volume rendering transfer function generation to map normalized scalar values to opacity or color intensity with smooth, differentiable transitions. It differs from the [Gaussian Transfer Function](4408-gaussian-transfer-function.md) by using a monotonic S-shaped curve rather than a bell-shaped curve, and from the [Cosine Palette Color Mapping](3359-cosine-palette-color-mapping.md) by providing a single-channel scalar mapping rather than a multi-channel color palette.

## How it works
**Inputs and Outputs:**
- Input: A scalar value $x$ (typically the normalized parameter $t \in [0, 1]$ from the parent method).
- Outputs: The sigmoid value $s$ and its derivative $s'$.

**Data Structures:**
- No complex data structures. The input is a scalar or tensor element. The output is a pair of scalars (or tensors of the same shape).

**Steps:**
1. Compute the exponential term $e^{-x}$.
2. Compute the sigmoid value $s$ using the formula:
   $$ s = \frac{1}{1 + e^{-x}} $$
3. Compute the derivative $s'$ using the identity:
   $$ s' = s(1 - s) $$

**Parameters:**
- None. The standard sigmoid has no adjustable parameters (unlike the generalized logistic function).

**Edge Cases and Pitfalls:**
- **Numerical Stability:** For large positive $x$, $e^{-x}$ underflows to 0, yielding $s=1$. For large negative $x$, $e^{-x}$ overflows. In practice, implementations should handle large negative $x$ by returning $s \approx 0$ directly to avoid overflow, though standard floating-point ranges usually suffice for normalized inputs $t \in [0,1]$ if $x$ is scaled appropriately [G].
- **Derivative Range:** The derivative $s'$ is always in $(0, 0.25]$. It peaks at $x=0$ where $s=0.5$ and $s'=0.25$.

**Pseudocode:**
```python
def sigmoid(x):
    # Compute 1 / (1 + exp(-x))
    # Guard against overflow for large negative x
    if x < 0:
        exp_x = exp(x)
        return exp_x / (1.0 + exp_x)
    else:
        exp_neg_x = exp(-x)
        return 1.0 / (1.0 + exp_neg_x)

def sigmoid_with_jacobian(x):
    s = sigmoid(x)
    ds = s * (1.0 - s)
    return s, ds
```

## Subtopics

### Inverse Sigmoid Function
Computes the inverse of the sigmoid function (logit). It is used when mapping from a probability or normalized intensity back to the log-odds space. It is defined as $\text{logit}(x) = \ln\left(\frac{x}{1-x}\right)$. It is valid only for $x \in (0, 1)$. Inputs of 0 or 1 result in $-\infty$ or $+\infty$ respectively [S2, unofficial].

## Operating characteristics
- **Time Complexity:** $O(1)$ per element. Requires one exponential and a few arithmetic operations.
- **Memory Complexity:** $O(1)$ auxiliary space.
- **Strengths:** Analytically simple, computationally cheap, and differentiable everywhere. The derivative is available in closed form without numerical approximation.
- **Limitations:** Monotonic; cannot create multiple peaks or valleys in the transfer function. Sensitive to the scaling of the input $x$ if the input range is not normalized or centered.
- **When to use:** When a smooth, monotonic transition is required, such as for opacity ramps or simple intensity thresholds.

## Background
The sigmoid function is a standard logistic function used in statistics and neural networks. In the context of 3D Gaussian Splatting and volume rendering, it is used in Taichi-based implementations for its differentiability and smoothness [S1, unofficial]. The inverse sigmoid (logit) is used in optimization contexts, such as in InstantSplat, to map probabilities back to unconstrained spaces [S2, unofficial].
