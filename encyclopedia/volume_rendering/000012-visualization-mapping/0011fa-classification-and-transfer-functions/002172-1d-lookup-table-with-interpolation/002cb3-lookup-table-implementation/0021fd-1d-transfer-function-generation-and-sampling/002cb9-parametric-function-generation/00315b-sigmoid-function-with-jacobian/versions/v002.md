# Sigmoid Function with Jacobian

Also called: Sigmoid, Sigmoid derivative

## Overview
The Sigmoid Function with Jacobian method evaluates the logistic sigmoid function and its first derivative simultaneously to map normalized scalar inputs to transfer function values. It is distinguished from sibling methods like the [Gaussian Transfer Function](4408-gaussian-transfer-function.md) by its S-shaped monotonic curve and explicit provision of the Jacobian (gradient), which is critical for optimization-based parameter tuning or gradient-based opacity estimation in differentiable rendering pipelines.

## How it works
**Inputs and Outputs:**
- Input: A scalar value $x \in \mathbb{R}$ (typically the normalized data value or a transformed coordinate).
- Outputs: The sigmoid value $s \in (0, 1)$ and its derivative $s' \in (0, 0.25]$.

**Data Structures:**
No complex data structures are required; the method operates on scalar values or element-wise tensor operations.

**Steps:**
1. Evaluate the exponential term $e^{-x}$.
2. Compute the sigmoid value $s$ using the logistic formula.
3. Compute the Jacobian (derivative) $s'$ using the algebraic identity derived from the sigmoid definition.

**Formulas:**
The sigmoid function is defined as:
$$ s = \sigma(x) = \frac{1}{1 + e^{-x}} $$

The derivative (Jacobian) with respect to $x$ is:
$$ \frac{ds}{dx} = s(1 - s) $$

**Parameters:**
- $x$: The input scalar. No explicit shape parameters (like center or width) are present in the base definition, though in practice $x$ is often a linear transformation of the data value $t$ (e.g., $x = \frac{t - \mu}{\sigma}$). Not given in the sources.

**Edge Cases and Pitfalls:**
- **Numerical Stability:** Direct computation of $e^{-x}$ can overflow for large negative $x$ or underflow for large positive $x$. In implementations, conditional branching or stable exponential functions should be used. [G]
- **Range:** The output $s$ is strictly bounded between 0 and 1, but never reaches exactly 0 or 1 for finite $x$. [G]

**Pseudocode:**
```python
import math

def sigmoid(x):
    # Stable sigmoid implementation
    if x >= 0:
        z = math.exp(-x)
        return 1.0 / (1.0 + z)
    else:
        z = math.exp(x)
        return z / (1.0 + z)

def sigmoid_with_jacobian(x):
    s = sigmoid(x)
    # The derivative of sigmoid(x) is s * (1 - s)
    ds_dx = s * (1.0 - s)
    return s, ds_dx
```

## Subtopics

### Inverse Sigmoid Function
Computes the inverse of the sigmoid function, also known as the logit function. It maps a value $x \in (0, 1)$ back to the real line $\mathbb{R}$. It is defined as $\text{logit}(x) = \ln\left(\frac{x}{1-x}\right)$. This is useful for converting probability-like outputs back to log-odds space for parameter initialization or optimization. [S2, unofficial]

## Operating characteristics
- **Time Complexity:** $O(1)$ per evaluation. Requires one exponential and one division.
- **Memory Complexity:** $O(1)$.
- **Strengths:** Smooth, continuous, and differentiable everywhere. The Jacobian is available analytically without numerical approximation, enabling efficient gradient-based optimization.
- **Limitations:** The S-shape may not fit data distributions that require asymmetric or multi-modal responses as well as Gaussian or Cosine variants. [S1, unofficial]

## Background
The sigmoid function is a fundamental activation function in neural networks and statistics. In the context of volume rendering and 3D Gaussian Splatting, it is used for transfer function generation and opacity modeling. The specific implementation with Jacobian is found in differentiable rendering frameworks such as Taichi-based 3D Gaussian Splatting implementations. [S1, unofficial]
