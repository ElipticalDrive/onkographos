# Cosine Palette Color Mapping

Also called: Inigo Quilez Palette

## Overview
Cosine Palette Color Mapping generates a smooth, continuous color gradient from a normalized scalar input $t \in [0, 1]$ by evaluating a parametric cosine function with distinct phase offsets for each RGB channel [S1, unofficial]. It solves the problem of creating visually distinct, aesthetically pleasing color ramps without the discontinuities of piecewise linear interpolation or the complexity of multi-component basis functions. It is distinguished from its sibling [Gaussian Transfer Function](4408-gaussian-transfer-function.md) by its use of trigonometric basis functions rather than exponential decay, and from [Sigmoid Function with Jacobian](6497-sigmoid-function-with-jacobian.md) by its simpler, single-wave structure per channel [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   Input: A normalized scalar value $t \in [0, 1]$.
*   Output: An RGB color vector $\mathbf{C} = (R, G, B)$.

**Data Structures:**
The method relies on four constant vector parameters $\mathbf{a}, \mathbf{b}, \mathbf{c}, \mathbf{d}$, each of size 3 (representing Red, Green, Blue channels).

**Parameters:**
The standard parameters defined by Inigo Quilez are [S1, unofficial]:
*   $\mathbf{a} = (0.5, 0.5, 0.5)$
*   $\mathbf{b} = (0.5, 0.5, 0.5)$
*   $\mathbf{c} = (1.0, 1.0, 1.0)$
*   $\mathbf{d} = (0.00, 0.33, 0.67)$

**Formula:**
The color is computed as:
$$ \mathbf{C}(t) = \mathbf{a} + \mathbf{b} \cdot \cos\left(2\pi \cdot (\mathbf{c} \cdot t + \mathbf{d})\right) $$
Where the operations are component-wise. Specifically for channel $i \in \{R, G, B\}$:
$$ C_i(t) = a_i + b_i \cos(2\pi (c_i t + d_i)) $$

**Steps:**
1.  Normalize the input scalar $t$ to the range $[0, 1]$.
2.  For each color channel $i$, compute the argument $arg_i = 2\pi (c_i t + d_i)$.
3.  Compute the cosine of the argument: $val_i = \cos(arg_i)$.
4.  Scale by amplitude $b_i$ and add offset $a_i$: $C_i = a_i + b_i \cdot val_i$.
5.  Return the vector $(C_R, C_G, C_B)$.

**Pseudocode:**
```python
import math

def cosine_palette(t: float) -> tuple[float, float, float]:
    """
    Generates an RGB color from a normalized scalar t in [0, 1]
    using the Inigo Quilez cosine palette parameters.
    """
    # Validate input
    if t < 0.0:
        t = 0.0
    elif t > 1.0:
        t = 1.0

    # Standard parameters [S1, unofficial]
    a = (0.5, 0.5, 0.5)
    b = (0.5, 0.5, 0.5)
    c = (1.0, 1.0, 1.0)
    d = (0.00, 0.33, 0.67)

    result = []
    for i in range(3):
        # Compute argument: 2 * pi * (c[i] * t + d[i])
        arg = 2.0 * math.pi * (c[i] * t + d[i])
        # Compute cosine
        cos_val = math.cos(arg)
        # Apply linear transform: a[i] + b[i] * cos_val
        color_channel = a[i] + b[i] * cos_val
        result.append(color_channel)

    return tuple(result)
```

**Edge Cases and Pitfalls:**
*   **Range:** The output values naturally fall within $[0, 1]$ given the standard parameters, but if parameters are modified, clamping may be required to prevent negative values or values exceeding 1.0 [G].
*   **Continuity:** The function is infinitely differentiable, ensuring no visual artifacts at boundaries [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per sample. Requires three cosine evaluations and basic arithmetic.
*   **Memory Complexity:** $O(1)$. Only four constant vectors are stored.
*   **Strengths:** Extremely compact representation; smooth gradients; easy to tune by adjusting phase offsets $\mathbf{d}$ to shift color regions.
*   **Limitations:** Limited flexibility compared to multi-component basis functions; the specific aesthetic is tied to the chosen parameters.
*   **When to use:** When a smooth, perceptually distinct color ramp is needed with minimal computational overhead and storage.

## Background
The method was popularized by Inigo Quilez in the context of shader programming and procedural color generation [S1, unofficial]. It leverages the properties of the cosine function to create smooth transitions between colors by shifting the phase of the wave for each RGB channel.
