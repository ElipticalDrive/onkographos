# Explorable Image Representation

Also called: Image-based volume exploration, Multi-layer explorable images

## Overview
Explorable Image Representation is a method for interactive volume visualization that pre-renders scalar data into a set of multi-layered 2D images, allowing users to modify layer transparency and color without re-rendering the 3D scene [S1, unofficial]. It differs from standard ray-casting by decoupling interaction from the 3D data, enabling image-based exploration [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Scalar volume data; user-defined ranges of interest; number of layers to explore [S1, unofficial].
*   **Output:** A set of 2D explorable images; metadata describing layer order, approximate color, and opacity for each layer [S1, unofficial].

**Data Structures:**
*   **Explorable Image:** A 2D raster image (RGBA) containing superimposed layers [S1, unofficial].
*   **Layer Metadata:** A list of objects, each containing:
    *   `layer_id`: Identifier for the material/region.
    *   `approx_color`: RGB estimate used for separation during generation [S1, unofficial].
    *   `approx_opacity`: Initial opacity estimate.
    *   `bounds`: Information about the innermost and outermost layers used to construct intermediate data [S1, unofficial].

**Algorithm Steps:**

1.  **Transfer Function Generation:**
    *   Compute peaks in the transfer function to identify material boundaries (iso-values) [S1, unofficial].
    *   Select peak centers to be as equally spaced as possible within the user-defined range [S1, unofficial].
    *   Construct a transfer function consisting of Gaussian curves centered on these peaks [S1, unofficial].
    *   The width, height, and number of peaks determine the granularity of the layers [S1, unofficial].
    *   *Note:* The initial transfer function is not optimized for final visualization because it serves as a basis for separable layer extraction [S1, unofficial].

2.  **Layer Separation and Image Generation:**
    *   Assume a rough estimate of each layer’s color to ensure separability during rendering [S1, unofficial].
    *   Render the volume using the generated transfer function [S1, unofficial].
    *   Apply boundary blurring control if specified by the user; otherwise, use a default value [S1, unofficial].

3.  **Layer Combination Scheme:**
    *   Generate a minimal set of images that allows reconstruction of any layer combination via compositing [S1, unofficial].
    *   **Image 1:** Contains the innermost and outermost layers [S1, unofficial].
    *   **Image 2:** Contains the innermost, outermost, and the middle layer [S1, unofficial].
    *   **Subsequent Images:** Follow the pattern where each new image adds the next intermediate layer, bounded by the previously established inner and outer layers, allowing data in between to be constructed from bounding layer information [S1, unofficial].

4.  **Interaction:**
    *   Users modify transparency and color of individual layers by applying image-based operations to the pre-rendered explorable images [S1, unofficial].
    *   No 3D data access or additional rendering passes are required during interaction [S1, unofficial].

**Pseudocode:**

```python
def generate_explorable_images(volume_data, user_ranges, num_layers):
    # Step 1: Transfer Function Generation
    # Compute peaks in the transfer function to identify material boundaries
    peaks = [peak for peak in detect_peaks(volume_data, user_ranges)]
    # Select peak centers to be as equally spaced as possible
    selected_peaks = sorted(peaks)[:num_layers]
    # Construct a transfer function consisting of Gaussian curves centered on these peaks
    transfer_function = [Gaussian(center=p) for p in selected_peaks]
    # The width, height, and number of peaks determine the granularity of the layers
    # Note: The initial transfer function is not optimized for final visualization

    # Step 2: Layer Separation and Image Generation
    # Assume a rough estimate of each layer’s color to ensure separability
    layer_colors = [estimate_color(volume_data, p) for p in selected_peaks]
    # Apply boundary blurring control if specified; otherwise use default
    blurred_volume = apply_blur(volume_data, default_blur)
    # Render the volume using the generated transfer function
    rendered_volume = ray_cast(blurred_volume, transfer_function)

    # Step 3: Layer Combination Scheme
    images = []
    metadata = []
    layer_indices = sorted(selected_peaks)

    # Image 1: Contains the innermost and outermost layers
    if len(layer_indices) >= 2:
        inner_idx = layer_indices[0]
        outer_idx = layer_indices[-1]
        img_1 = composite(rendered_volume, [inner_idx, outer_idx], layer_colors)
        images.append(img_1)
        metadata.append({
            'layers': [inner_idx, outer_idx],
            'colors': [layer_colors[inner_idx], layer_colors[outer_idx]],
            'bounds': [inner_idx, outer_idx]
        })

        # Image 2 and subsequent: Add intermediate layers bounded by inner/outer
        for i in range(1, len(layer_indices) - 1):
            mid_idx = layer_indices[i]
            current_layers = [inner_idx, mid_idx, outer_idx]
            img = composite(rendered_volume, current_layers, layer_colors)
            images.append(img)
            metadata.append({
                'layers': current_layers,
                'colors': [layer_colors[l] for l in current_layers],
                'bounds': [inner_idx, outer_idx]
            })

    return images, metadata

def interact_with_explorable_image(image, metadata, user_color_changes, user_opacity_changes):
    # Image-based interaction: modify transparency and color of individual layers
    result_image = image
    for layer_id in metadata['layers']:
        if layer_id in user_color_changes:
            result_image = blend_color(result_image, layer_id, user_color_changes[layer_id])
        if layer_id in user_opacity_changes:
            result_image = blend_opacity(result_image, layer_id, user_opacity_changes[layer_id])
    return result_image

# Helper definitions (standard operations or source-defined steps)
def detect_peaks(vol, ranges):
    # Standard peak detection on the transfer function over the scalar range [G]
    return [p for p in vol if is_local_max(p)]

def Gaussian(center):
    # Standard Gaussian function definition [G]
    return lambda x: exp(-((x - center) ** 2) / 2)

def estimate_color(vol, peak):
    # Rough estimate of each layer’s color for separation [S1, unofficial]
    return vol[peak]

def apply_blur(vol, blur_amount):
    # Apply boundary blurring; uses default if amount is unspecified [S1, unofficial]
    return vol if blur_amount is None else vol * blur_amount

def ray_cast(vol, tf):
    # Standard volume rendering using the transfer function [G]
    return composite_along_rays(vol, tf)

def composite(vol, indices, colors):
    # Composite layers based on indices and approximate colors [G]
    return sum(vol[i] * colors[i] for i in indices)

def blend_color(img, layer_id, new_color):
    # Apply user-defined color change to the specified layer [G]
    return img.replace_color(layer_id, new_color)

def blend_opacity(img, layer_id, new_opacity):
    # Apply user-defined opacity change to the specified layer [G]
    return img.replace_opacity(layer_id, new_opacity)
```

**Parameters:**
*   **Boundary Blurring:** Controls the amount of blurring at material boundaries; uses a default value if not specified [S1, unofficial].
*   **Number of Layers:** Controls the number of generated input images; users can select a range from a single image (entire data) to individual images for each layer [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Storage/Bandwidth Trade-off:** There is a trade-off between storage space/bandwidth requirements and the ability to reproduce all possible interactions between layers [S1, unofficial].
*   **Initial Optimization:** The initial transfer function is not optimized for visualization because it allows users to change color and opacity of individual layers [S1, unofficial].
*   **Color Approximation:** The method assumes a rough estimate of each layer’s color for separating input images [S1, unofficial].

## Subtopics

### Gaussian Transfer Function
Uses Gaussian bumps to define opacity and color based on scalar value position. Provides the basis for the transfer function generation in Explorable Image Representation. [Gaussian Transfer Function](4408-gaussian-transfer-function.md)

### Parametric Function Generation
Generates transfer functions using parametric curves (like Gaussians). Explorable Image Representation uses this to create the initial multi-layered transfer function. [Parametric Function Generation](4407-parametric-function-generation.md)

## Operating characteristics
*   **Time Complexity:** Pre-rendering time depends on the volume size and the number of layers [S1, unofficial]. Interaction time depends on the number of layers and user modifications, not the original volume size, as it operates on 2D images [S1, unofficial].
*   **Memory Complexity:** Storage requirements increase with the number of generated explorable images [S1, unofficial]. The method trades off storage/bandwidth for interactive flexibility [S1, unofficial].
*   **Strengths:** Enables image-based interaction without 3D data access or re-rendering passes [S1, unofficial].
*   **Limitations:** Initial transfer function is not optimized for final visualization and relies on color approximation for layer separation [S1, unofficial]. Trade-off between storage and interaction fidelity exists [S1, unofficial].
*   **When to Use:** When interactive exploration of layer properties is required on devices with limited rendering capabilities or constrained bandwidth [S1, unofficial].
*   **When Not to Use:** When high-fidelity, optimized visualization is the primary goal, as the initial transfer function is not optimized for visualization [S1, unofficial].

## Background
The Explorable Image Representation method was proposed by Tikhonova et al. in the context of volumetric medical images visualization on mobile devices [S1, unofficial]. It addresses the challenge of interactive volume exploration on resource-constrained devices by pre-computing explorable images [S1, unofficial].
