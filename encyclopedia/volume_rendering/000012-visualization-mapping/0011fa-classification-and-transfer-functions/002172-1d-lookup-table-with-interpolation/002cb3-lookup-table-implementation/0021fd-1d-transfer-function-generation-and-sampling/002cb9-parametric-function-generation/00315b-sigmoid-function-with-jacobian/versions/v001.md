# Sigmoid Function with Jacobian
Also called: Sigmoid, Sigmoid derivative, Logistic function, Logit inverse

## Overview
Computes the sigmoid activation $\sigma(x)$ and its analytical derivative $\sigma'(x)$ for scalar inputs. It serves as a differentiable mapping component in transfer function generation, providing smooth, bounded output $[0, 1]$ with known gradient properties essential for optimization-based parameter tuning. It differs from [Cosine Palette Color Mapping](3359-cosine-palette-color-mapping.md) by providing monotonic, non-periodic mapping, and from [Gaussian Transfer Function](4408-gaussian-transfer-function.md) by lacking localized peak control, instead offering global asymptotic behavior.

## How it works
**Inputs and Outputs**:
- Input: Scalar $x \in \mathbb{R}$.
- Output: Tuple $(s, ds)$, where $s = \sigma(x) \in (0, 1)$ and $ds = \frac{ds}{dx} \in (0, 0.25]$.

**Data Structures**:
- No complex structures; standard floating-point scalar types (e.g., `float32` or `float64`).

**Steps**:
1. Compute the exponential term $e^{-x}$.
2. Compute the sigmoid value $s = \frac{1}{1 + e^{-x}}$.
3. Compute the derivative $ds = s(1 - s)$.

**Formulas**:
$$ s = \frac{1}{1 + e^{-x}} $$
$$ \frac{ds}{dx} = s(1 - s) $$

**Parameters**:
- None. The function is fixed.

**Edge Cases and Pitfalls**:
- **Overflow/Underflow**: For large positive $x$, $e^{-x}$ underflows to 0, yielding $s=1$. For large negative $x$, $e^{-x}$ overflows to $\infty$, yielding $s=0$. In fixed-precision arithmetic, direct computation of $e^{-x}$ for $x < -88$ (float32) or $x < -708$ (float64) may cause issues. A numerically stable implementation checks the sign of $x$: if $x \ge 0$, compute $1/(1+e^{-x})$; if $x < 0$, compute $e^x/(1+e^x)$ [G].
- **Derivative at Boundaries**: As $s \to 0$ or $s \to 1$, $ds \to 0$. This vanishing gradient can hinder optimization if parameters are initialized in saturated regions.

**Pseudocode**:
```python
def sigmoid(x):
    # Numerically stable sigmoid
    if x >= 0:
        z = exp(-x)
        return 1.0 / (1.0 + z)
    else:
        z = exp(x)
        return z / (1.0 + z)

def sigmoid_with_jacobian(x):
    s = sigmoid(x)
    ds = s * (1.0 - s)
    return s, ds
```

## Subtopics

### Inverse Sigmoid Function
Computes the logit function, the inverse of the sigmoid. Defined as $\text{logit}(s) = \ln(\frac{s}{1-s})$. It maps $s \in (0, 1)$ back to $x \in \mathbb{R}$. Used when converting normalized probabilities or transfer function outputs back to log-odds space for parameter estimation. Implementation: `log(x / (1 - x))` [S2, unofficial]. Note: Input $s$ must be strictly within $(0, 1)$ to avoid division by zero or logarithm of zero/negative numbers.

## Operating characteristics
- **Time Complexity**: $O(1)$ per evaluation. Requires one exponential and basic arithmetic.
- **Memory Complexity**: $O(1)$. No storage required.
- **Strengths**: Analytically differentiable everywhere; computationally cheap; bounded output; monotonic.
- **Limitations**: Cannot represent multi-modal distributions (peaks/valleys) within a single function instance; requires composition or multiple instances for complex transfer functions.
- **When to use**: When a smooth, monotonic transition is needed, or as a base component for differentiable rendering pipelines where gradients are required for optimization.

## Background
The sigmoid function is a fundamental activation function in neural networks and statistics. In the context of volume rendering transfer functions, it is used to map scalar data values (like density) to opacity or color intensity smoothly. The provided implementations are from unofficial repositories for 3D Gaussian Splatting visualizers and splitters, leveraging automatic differentiation frameworks (Taichi, PyTorch) [S1, unofficial][S2, unofficial].
