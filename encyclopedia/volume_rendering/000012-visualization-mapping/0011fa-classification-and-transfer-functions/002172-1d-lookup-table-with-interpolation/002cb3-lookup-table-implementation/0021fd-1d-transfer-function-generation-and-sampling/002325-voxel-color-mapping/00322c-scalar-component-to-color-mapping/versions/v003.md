# Scalar/Component to Color Mapping

Also called: Target Value Visualization, Visualization Target Mapping

## Overview
Scalar/Component to Color Mapping converts a single scalar volume value or a specific component of a surface normal into an RGB color using a 2D colormap texture [S1, S2, unofficial]. It performs a direct lookup based on a normalized input, often used in direct volume rendering pipelines [S1, unofficial]. Unlike complex transfer functions that map multiple attributes to opacity and color, this method assigns a fixed color based on a single normalized scalar [S1, S2, unofficial]. It builds on [Voxel Color Mapping](2970-voxel-color-mapping.md) and differs from [Palette-based Color Mapping](7283-palette-based-color-mapping.md) by using a continuous 2D texture lookup rather than discrete palette indices.

## How it works
**Inputs:**
- `value`: The scalar volume data value (float) [S1, S2, unofficial].
- `normal`: The surface normal vector (vec3), used when `visualize_target` selects a normal component [S2, unofficial].
- `u_clim`: A `vec2` containing the lower and upper bounds of the value range for normalization [S1, unofficial].
- `u_colormap`: A 2D sampler texture containing the color map (e.g., Viridis) [S1, unofficial].
- `visualize_target`: An enumeration determining the input source: `VALUE`, `NORMAL_X`, `NORMAL_Y`, or `NORMAL_Z` [S2, unofficial].
- `cm_type`: Colormap type identifier (e.g., from `tinycolormap::ColormapType`) [S2, unofficial].

**Outputs:**
- RGB color with alpha 1.0 [S1, unofficial].

**Data Structures:**
- `u_colormap`: 2D texture storing RGB values. The y-coordinate is fixed at 0.5 for 1D colormaps stored in 2D space [S1, unofficial].

**Steps:**
1. Determine the input scalar `s` based on `visualize_target`:
   - If `VALUE`: `s = value` [S2, unofficial].
   - If `NORMAL_X`: `s = normal.x()` [S2, unofficial].
   - If `NORMAL_Y`: `s = normal.y()` [S2, unofficial].
   - If `NORMAL_Z`: `s = normal.z()` [S2, unofficial].
2. Normalize `s` to the range $[0, 1]$:
   - If `visualize_target` is `VALUE`:
     - Apply linear normalization using `u_clim`: $s_{\text{norm}} = \frac{s - \text{u\_clim}[0]}{\text{u\_clim}[1] - \text{u\_clim}[0]}$ [S1, unofficial].
   - If `visualize_target` is a normal component:
     - Map from $[-1, 1]$ to $[0, 1]$: $s_{\text{norm}} = \frac{s + 1.0}{2.0}$ [S2, unofficial].
   - Clamp $s_{\text{norm}}$ to $[0, 1]$ [S1, S2, unofficial].
3. Sample the colormap texture `u_colormap` at $(s_{\text{norm}}, 0.5)$ [S1, unofficial].
4. Return the sampled RGB color with alpha 1.0 [S1, unofficial].

**Pseudocode:**
```python
def clamp(val, min_val, max_val):
    return max(min_val, min(max_val, val))

def sample_colormap(colormap_data, x_coord, y_coord):
    # Simulates 2D texture lookup at fixed y=0.5 for 1D colormaps
    # Returns (r, g, b)
    idx = int(x_coord * (len(colormap_data) - 1))
    return colormap_data[idx]

def scalar_to_color(value, normal, u_clim, colormap_data, visualize_target):
    # 1. Determine input scalar s
    if visualize_target == 'VALUE':
        s = value
    elif visualize_target == 'NORMAL_X':
        s = normal[0]
    elif visualize_target == 'NORMAL_Y':
        s = normal[1]
    elif visualize_target == 'NORMAL_Z':
        s = normal[2]
    else:
        raise ValueError("Unknown visualize_target")

    # 2. Normalize s to [0, 1]
    if visualize_target == 'VALUE':
        denom = u_clim[1] - u_clim[0]
        if denom == 0:
            s_norm = 0.0
        else:
            s_norm = (s - u_clim[0]) / denom
    else:
        s_norm = (s + 1.0) / 2.0

    # Clamp to [0, 1]
    s_norm = clamp(s_norm, 0.0, 1.0)

    # 3. Sample colormap texture at (s_norm, 0.5)
    color_rgb = sample_colormap(colormap_data, s_norm, 0.5)

    # 4. Return RGB with alpha 1.0
    return (color_rgb[0], color_rgb[1], color_rgb[2], 1.0)
```

**Parameters:**
- `u_clim`: `vec2` for value range normalization [S1, unofficial].
- `visualize_target`: Enum for input selection (`VALUE`, `NORMAL_X`, `NORMAL_Y`, `NORMAL_Z`) [S2, unofficial].
- `cm_type`: Colormap type identifier [S2, unofficial].

**Edge Cases:**
- Division by zero in `u_clim` normalization if `u_clim[0] == u_clim[1]` [G].
- Normal components outside $[-1, 1]$ due to numerical error; clamping handles this [S2, unofficial].
- Degenerate input values (NaN, Inf); clamping or explicit checks may be needed [G].

## Subtopics

### Colormap Conversion
Maps a scalar tensor to RGB colors using a matplotlib colormap (default 'turbo') [S3, unofficial]. It normalizes input to $[0, 1]$, scales to $[0, 255]$, and indexes into pre-loaded colormap colors [S3, unofficial]. Steps: 1. Load colormap colors from matplotlib (e.g., 'turbo') and move to tensor device [S3, unofficial]. 2. Normalize input map: $(map - \min) / (\max - \min)$ [S3, unofficial]. 3. Scale to 0-255: $map \times 255$ [S3, unofficial]. 4. Round and convert to long integers [S3, unofficial]. 5. Squeeze dimensions [S3, unofficial]. 6. Index into colors tensor [S3, unofficial]. 7. Permute dimensions to $(2, 0, 1)$ (RGB, H, W) [S3, unofficial]. Parameter: `cmap` (colormap name string, default 'turbo') [S3, unofficial].

## Background
Originating from direct volume rendering implementations, this method is commonly used in educational and open-source projects for visualizing 3D textures [S1, S2, unofficial]. It is often paired with colormaps like Viridis for perceptual uniformity [S1, unofficial].
