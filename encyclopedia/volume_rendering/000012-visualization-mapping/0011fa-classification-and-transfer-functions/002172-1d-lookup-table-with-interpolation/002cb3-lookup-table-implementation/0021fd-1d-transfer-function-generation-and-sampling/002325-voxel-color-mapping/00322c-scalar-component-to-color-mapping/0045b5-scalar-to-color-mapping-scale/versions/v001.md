# Scalar to Color Mapping Scale

Also called: Linear scale, Log Scale Mapping, Log10 scale, Logarithmic scale

## Overview
Scalar to Color Mapping Scale determines the mathematical function used to normalize scalar data values into the $[0, 1]$ range required for transfer function lookup. It solves the problem of non-uniform data distribution by allowing logarithmic compression, which prevents high-value outliers from dominating the color map while preserving detail in low-value regions. It differs from sibling methods like [Colormap Conversion](7117-colormap-conversion.md) by defining the input domain transformation rather than the output color space interpolation.

## How it works
**Inputs:** Scalar value $v$, data range $[v_{min}, v_{max}]$, scale type $S \in \{\text{linear}, \text{log10}\}$.
**Outputs:** Normalized value $n \in [0, 1]$.

**Data Structures:**
The scale type is stored as an integer flag within the transfer function object.
- `scale_type`: `int` (0 for linear, 1 for log10, implementation-specific).

**Steps:**
1. Determine the effective scale type $S_{eff}$. If $S = \text{log10}$ and the data range $[v_{min}, v_{max}]$ contains zero (i.e., $v_{min} \le 0 \le v_{max}$), set $S_{eff} = \text{linear}$ to avoid undefined behavior [S1]. Otherwise, $S_{eff} = S$.
2. If $S_{eff} = \text{linear}$, compute the normalized value:
   $$ n = \frac{v - v_{min}}{v_{max} - v_{min}} $$
3. If $S_{eff} = \text{log10}$, compute the normalized value:
   $$ n = \frac{\log_{10}(v) - \log_{10}(v_{min})}{\log_{10}(v_{max}) - \log_{10}(v_{min})} $$
   This assumes $v > 0$, $v_{min} > 0$, and $v_{max} > 0$ [S2].
4. Clamp $n$ to $[0, 1]$.

**Parameters:**
- Default scale type: Linear [S1].

**Edge Cases and Pitfalls:**
- **Zero in Range:** If logarithmic scale is requested but the data range includes zero or negative values, the mapping defaults to linear [S1]. ParaView reports errors and attempts to automatically fix the range if it is invalid for log mapping [S2].
- **Non-Positive Data:** Log scale mapping assumes data is strictly non-zero and positive [S2].

**Pseudocode:**
```python
def map_scalar_to_color_scale(v, v_min, v_max, scale_type):
    """
    Maps a scalar value to [0, 1] using the specified scale.
    
    Args:
        v: Scalar value to map.
        v_min: Minimum value of the data range.
        v_max: Maximum value of the data range.
        scale_type: 'linear' or 'log10'.
        
    Returns:
        Normalized value in [0, 1].
    """
    # Determine effective scale
    effective_scale = scale_type
    
    # Pitfall: Log scale fails if range contains zero
    if effective_scale == 'log10':
        if v_min <= 0 or v_max <= 0:
            effective_scale = 'linear'
            # Implementation note: In ParaView, this may trigger an error report and range fix [S2]
    
    if effective_scale == 'linear':
        if v_max == v_min:
            return 0.0  # Avoid division by zero
        n = (v - v_min) / (v_max - v_min)
    elif effective_scale == 'log10':
        # Assumes v_min > 0 and v_max > 0
        log_min = math.log10(v_min)
        log_max = math.log10(v_max)
        if log_max == log_min:
            return 0.0  # Avoid division by zero
        log_v = math.log10(v)
        n = (log_v - log_min) / (log_max - log_min)
    else:
        # Default to linear if unknown type
        if v_max == v_min:
            return 0.0
        n = (v - v_min) / (v_max - v_min)
        
    # Clamp to [0, 1]
    return max(0.0, min(1.0, n))
```

## Operating characteristics
- **Time Complexity:** $O(1)$ per scalar value. Logarithmic computation is slightly more expensive than linear arithmetic but negligible in modern hardware.
- **Memory Complexity:** $O(1)$ for scale state.
- **Strengths:** Logarithmic scale improves visibility of low-intensity features in data with large dynamic ranges (e.g., density, pressure).
- **Limitations:** Cannot handle non-positive data directly; requires range adjustment or fallback to linear if zero/negative values are present [S1, S2].
- **When to use:** Use logarithmic scale when data spans several orders of magnitude and low-value details are critical. Use linear scale for uniformly distributed or positive-only data without extreme outliers.

## Background
The concept of scaling scalar values for color mapping is fundamental to volume rendering visualization. The specific implementation details described here originate from the VTK library (`vtkColorTransferFunction`) and are adopted by visualization tools like ParaView [S1, S2]. VTK introduced `SetScaleToLog10()` and `SetScaleToLinear()` methods to allow users to control the normalization function explicitly [S1]. ParaView provides a UI checkbox "Use log scale when mapping data to colors" which enforces the assumption of non-zero, positive data and includes automatic range correction mechanisms [S2].
