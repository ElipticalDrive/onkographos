# Map to Colormap


## Overview
`map_to_colormap` maps a continuous colormap directly to a specified range of scalar values (typically density), assigning a single constant alpha value to all values within that range [S1, S2]. Unlike layered transfer function methods that distribute opacity across different scalar bands, this method allows all density values in the dataset to contribute to the volume rendering simultaneously at a uniform visibility level [S1, S2]. It is designed to generate projections similar to standard projection plots while retaining volume rendering flexibility [S2].

## How it works
**Inputs:**
- `min_val`: float specifying the lower bound of the scalar range (e.g., `np.log10(3e-31)`) [S1, S2].
- `max_val`: float specifying the upper bound of the scalar range (e.g., `np.log10(5e-27)`) [S1, S2].
- `colormap`: string specifying the colormap to use (e.g., `"cmyt.arbre"`) [S1, S2].
- `scale_func`: callable function used to scale values within the range to $[0, 1]$ for colormap indexing [S1, S2].

**Outputs:**
- A configured transfer function object where the specified scalar range is mapped to the colors of the given colormap with a constant alpha [S1, S2].

**Data Structures:**
The method operates on a transfer function object (e.g., `ColorTransferFunction` in `yt`) [S1, S2]. The object stores:
- `tf`: The transfer function definition, storing the mapping rules [S1, S2].
- `bounds`: The scalar range bounds associated with the transfer function [S1, S2].

**Steps:**
1. Initialize the transfer function with the log-transformed bounds of the data range: $b = [\log_{10}(\text{min\_val}), \log_{10}(\text{max\_val})]$ [S1, S2].
2. Define a scaling function. The source example uses a linear ramp that normalizes values relative to their minimum and maximum:
   $$ \text{scale}(v) = \frac{v - \min(v)}{\max(v) - \min(v)} $$
   [S1, S2].
3. Call `map_to_colormap` with the log-transformed `min_val`, `max_val`, the `colormap` string, and the `scale_func` [S1, S2].
4. For each scalar value $s$ in the range $[\text{min\_val}, \text{max\_val}]$, compute the normalized index $n = \text{scale\_func}(s, \text{min\_val}, \text{max\_val})$ [S1, S2].
5. Retrieve the color $C$ from the colormap at index $n$ [G].
6. Assign a constant alpha value to all values in the range, ensuring uniform visibility [S1, S2].

**Pseudocode:**
```python
import numpy as np

def linramp(vals, minval, maxval):
    """Scales values to [0, 1] based on the min and max of the input array."""
    # Guard against division by zero if minval == maxval
    if maxval == minval:
        return np.zeros_like(vals)
    # Note: The source example uses vals.min()/max() instead of minval/maxval.
    # Corrected here to use the provided bounds for standard linear scaling.
    return (vals - minval) / (maxval - minval)

def map_to_colormap(min_val, max_val, colormap, scale_func):
    """
    Maps a colormap to a scalar range.
    Parameters:
    min_val (float): Lower bound of the scalar range.
    max_val (float): Upper bound of the scalar range.
    colormap (str): Name of the colormap.
    scale_func (callable): Function to normalize values to [0, 1].
    Returns:
    dict: Transfer function configuration.
    """
    # Initialize transfer function with log bounds
    tf = {
        "bounds": [min_val, max_val],
        "colormap": colormap,
        "alpha": 1.0,
        "scale_func": scale_func
    }
    return tf

def apply_transfer_function(tf, scalar_value):
    """Evaluates the transfer function for a single scalar value."""
    if tf["bounds"][0] <= scalar_value <= tf["bounds"][1]:
        # Normalize scalar value using the provided scale function
        normalized = tf["scale_func"](
            np.array([scalar_value]),
            tf["bounds"][0],
            tf["bounds"][1]
        )[0]
        # Clamp to valid colormap range
        normalized = np.clip(normalized, 0.0, 1.0)
        # Map to color (standard linear interpolation across colormap steps)
        color = get_color_from_colormap(tf["colormap"], normalized)
        alpha = tf["alpha"]
        return {"color": color, "alpha": alpha}
    return {"color": (0.0, 0.0, 0.0), "alpha": 0.0}

def get_color_from_colormap(name, t):
    """
    Standard colormap lookup.
    Not given in the sources. Maps normalized value t in [0, 1] to RGB.
    """
    return (t, 1.0 - t, 0.0)
```

**Parameters with Typical Values:**
- `min_val`: `np.log10(3e-31)` [S1, S2].
- `max_val`: `np.log10(5e-27)` [S1, S2].
- `colormap`: `"cmyt.arbre"` [S1, S2].
- `scale_func`: `linramp` (linear ramp) [S1, S2].

**Edge Cases and Pitfalls:**
- **Log Space:** If the data is rendered in log space, the `min_val` and `max_val` must be provided in log space (e.g., `np.log10(bounds)`) [S1, S2].
- **Division by Zero:** If `min_val` equals `max_val`, the scaling function will divide by zero [G].
- **Alpha Uniformity:** Since all values in the range share a single alpha, overlapping structures may not show depth cues as effectively as layered methods [G].

## Background
The method is part of the `yt` visualization framework's volume rendering capabilities [S1, S2]. It was introduced to provide an alternative to layered transfer functions, enabling users to create visualizations that resemble standard projection plots but with the flexibility of volume rendering techniques [S1, S2]. The specific example using `cmyt.arbre` colormap and log-transformed density bounds is documented in the `yt` project's 3D Visualization and Volume Rendering guide [S1, S2].
