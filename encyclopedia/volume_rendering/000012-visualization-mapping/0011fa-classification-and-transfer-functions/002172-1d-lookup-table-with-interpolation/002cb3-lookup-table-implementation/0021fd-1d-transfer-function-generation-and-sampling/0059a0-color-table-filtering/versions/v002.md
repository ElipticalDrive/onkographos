# Color Table Filtering

Also called: Filtering the color ramp, Rhoades et al. Color Table Filtering

## Overview
Color Table Filtering is a technique for anti-aliasing procedural textures where the final color is computed as $C(N(u))$, with $N(u)$ being a noise function and $C$ a 1D color table [S1, S2]. Instead of filtering the noise function $N(u)$ directly, this method filters the color table $C$ itself, returning the average color over a small interval $[N(u) - \delta, N(u) + \delta]$ [S1, S2]. It is distinguished from sibling methods like [Voxel Color Mapping](2970-voxel-color-mapping.md) by operating on the procedural noise domain's color mapping rather than pre-sampled voxel data, and from [Gradient/Color Ramp Sampling](4337-gradient-color-ramp-sampling.md) by its specific reliance on MIP-mapping the color table to approximate the integral [G].

## How it works
**Inputs:**
* $N(u)$: The procedural noise function evaluated at position $u$ [S1, S2].
* $C$: A 1D color table (lookup table) mapping noise values to RGBA colors [S1, S2].
* Filter size: The spatial extent of the filter kernel applied to the scene [S1, S2].

**Outputs:**
* Average color over the interval $[N(u) - \delta, N(u) + \delta]$ [S1, S2].

**Data Structures:**
* $C$: A 1D array of color values. To support MIP-mapping, this is typically stored as a hierarchy of 1D arrays where each level represents a downsampled version of the previous one [G]. The base level contains the original color table entries [G].

**Steps:**
1. **Define the Color Table:** Construct the 1D color table $C$ that maps noise values to colors [S2].
2. **Determine Filter Parameters:** Determine the filter size and the maximum gradient of the color table $C$ with respect to the noise value $u$ [S2].
3. **Compute Interval Size $\delta$:** Calculate the interval size $\delta$ based on the filter size and the maximum gradient of $C$ [S1, S2].
4. **Evaluate Average Color:** Evaluate the average color over the interval $[N(u) - \delta, N(u) + \delta]$ using MIP-mapping on the 1D color table [S1, S2].

**Formulas:**
The final color is the average of $C$ over the interval $[N(u) - \delta, N(u) + \delta]$ [S1, S2].
The interval size $\delta$ is computed from the filter size and the maximum gradient of $C$ with respect to $u$ [S1, S2].

**Parameters:**
* $\delta$: The size of the interval for averaging color. It is computed from the filter size and the maximum gradient of $C$ with respect to $u$ [S2].

**Pseudocode:**
```python
def color_table_filtering(noise_value, color_table_mip_levels, filter_size, max_gradient_c):
    """
    Computes the average color over the interval [noise_value - delta, noise_value + delta]
    using MIP-mapping on the color table.
    """
    # Step 3: Compute interval size delta
    # The exact formula for delta is not provided in the sources, 
    # but it depends on filter_size and max_gradient_c [S1, S2].
    # [G] A common approximation for such filtering is delta = filter_size * max_gradient_c.
    delta = filter_size * max_gradient_c
    
    # Define the interval
    lower_bound = noise_value - delta
    upper_bound = noise_value + delta
    center = (lower_bound + upper_bound) / 2.0
    
    # Step 4: Evaluate average color using MIP-mapping
    # [G] MIP-mapping on a 1D array involves selecting the appropriate MIP level
    # based on the interval size relative to the base array size,
    # and then sampling the array at the center with linear interpolation.
    
    base_size = len(color_table_mip_levels[0])
    
    # Determine MIP level based on interval size
    # [G] Larger intervals correspond to higher MIP levels (more downsampled).
    mip_level = 0
    current_size = base_size
    while current_size > delta and mip_level < len(color_table_mip_levels) - 1:
        current_size /= 2.0
        mip_level += 1
        
    # Sample the color table at the center of the interval using the selected MIP level
    # [G] Standard linear interpolation sample from the MIP level.
    texture = color_table_mip_levels[mip_level]
    u = center
    u = max(0.0, min(1.0, u))  # Clamp to valid range [G]
    
    idx = u * (len(texture) - 1)
    i = int(idx)
    f = idx - i
    
    if i + 1 < len(texture):
        average_color = texture[i] * (1 - f) + texture[i + 1] * f
    else:
        average_color = texture[i]
        
    return average_color
```

**Edge Cases and Pitfalls:**
* **Error Source:** A source of error is that the noise value and gradient are evaluated on the unfiltered noise [S1, S2].
* **Differentiability:** Most noises are differentiable, either through finite differencing or analytically, which allows for refinement using local noise gradient [S1, S2].

## Subtopics

### Refinement with Local Noise Gradient
Hart et al. refine this approach by using the local noise gradient, which is available for most differentiable noise functions [S1, S2].

### Variance-Based Estimation
Lagae et al. achieve accurate filtering by estimating the noise value range $\delta$ from the loss in noise variance due to filtering, which requires an analytical expression of the noise variance [S1, S2].

## Background
* **Origin:** Rhoades et al. [RTB* 92] introduced the method of filtering the color table $C$ rather than the noise function [S1, S2].
* **History and Development:** Hart et al. [HCK99] further refined this approach using the local noise gradient [S1, S2]. Lagae et al. [LLDD09a] relied on a similar mechanism but achieved accurate filtering by estimating the noise value range $\delta$ from the loss in noise variance due to filtering [S1, S2].
* **Usage:** Used in procedural noise function rendering to anti-alias the color mapping [S1, S2].
