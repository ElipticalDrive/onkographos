# Piecewise Linear Ray Integration with Pre-integrated Lookup Table

Also called: Gamma-based Pre-integration, Linear Luminance Integration, Williams and Max piecewise linear luminance solution

## Overview
This method evaluates the volume rendering integral for a single cell by assuming piecewise linear variation of luminance and attenuation coefficients across the cell depth [S1]. It solves the rendering equation analytically for linear profiles, allowing the result to be computed via a pre-computed 2D lookup table indexed by the products of attenuation coefficients and cell depth [S1]. This approach reduces computational cost compared to piecewise constant approximations while maintaining higher accuracy, particularly for nonlinear functions [S1]. It builds on [Preintegration LUT Generation](3895-preintegration-lut-generation.md) by providing the specific analytical solution and table indexing strategy for linear profiles.

## How it works

### Inputs and Outputs
**Inputs:**
*   $I_0$: Incident background intensity (scalar or vector).
*   $L_b$: Luminance at the back of the cell ($s=D$).
*   $L_f$: Luminance at the front of the cell ($s=0$).
*   $\tau_b$: Attenuation coefficient at the back of the cell.
*   $\tau_f$: Attenuation coefficient at the front of the cell.
*   $D$: Depth of the cell along the ray.

**Outputs:**
*   $I_D$: Transmitted intensity through the cell.

### Data Structures
**Pre-integration Lookup Table (LUT):**
*   A 2D texture or array indexed by normalized variables $\tau_b D$ and $\tau_f D$.
*   The table stores the value of the integral term $\Psi_{\tau_b D, \tau_f D}$, which represents the contribution of the cell's internal luminance to the final intensity, normalized by the exponential attenuation factors.
*   Dimensions: The table must cover the range of possible $\tau D$ products. Since $\tau D$ is unbounded and cell sizes vary, the domain must be carefully selected or normalized [S1].

### Formulas
The general volume rendering integral is:
$$I_D = I_0 e^{-\int_0^D \tau(t) dt} + \int_0^D L(s) \tau(s) e^{-\int_s^D \tau(t) dt} ds$$

Assuming linear profiles for luminance $L(s)$ and attenuation $\tau(s)$:
$$L(s) = L_b \left(1 - \frac{s}{D}\right) + L_f \frac{s}{D}$$
$$\tau(s) = \tau_b \left(1 - \frac{s}{D}\right) + \tau_f \frac{s}{D}$$

The integral can be decomposed into terms dependent on $I_0$, $L_b$, and $L_f$. The core computational insight is that the integral term involving the luminance can be expressed as a function of the products $\tau_b D$ and $\tau_f D$ only [S1].

Define the normalized variables:
$$u = \tau_b D$$
$$v = \tau_f D$$

The integral term $\Psi$ is defined as:
$$\Psi_{u,v} = \int_0^1 e^{-\int_s^1 (u(1-t) + v t) dt} ds$$

The final intensity $I_D$ is computed as:
$$I_D = I_0 e^{-\frac{1}{2}(u+v)} + L_b \cdot A(u,v) + L_f \cdot B(u,v)$$

Where $A(u,v)$ and $B(u,v)$ are coefficients derived from the analytical solution of the linear integral. The source notes that $\Psi$ can be stored in a 2D table. The specific coefficients $A$ and $B$ are linear combinations of $\Psi$ and exponential terms. The source states that the multiplications for $u$ and $v$ are essentially free if reused for the exponential term $e^{-\frac{1}{2}(u+v)}$ [S1].

*Note: The source provides the definition of $\Psi$ (Eq 10) and states that $I_D$ is computed using this pre-integrated value, but does not explicitly write out the final expanded formula for $I_D$ in terms of $A$ and $B$ in the provided snippets. However, it implies the structure is linear in $L_b$ and $L_f$ with coefficients dependent on $u$ and $v$.*

### Steps
1.  **Compute Products:** Calculate $u = \tau_b D$ and $v = \tau_f D$.
2.  **Compute Attenuation Factor:** Calculate $E = e^{-\frac{1}{2}(u+v)}$. This factor is used for the background term and potentially for normalizing the LUT lookup [S1].
3.  **Lookup:** Query the pre-integration LUT using indices $(u, v)$ to retrieve $\Psi_{u,v}$.
    *   *Pitfall:* The domain of $u$ and $v$ is unbounded. An appropriate finite domain must be chosen based on the expected range of $\tau D$ products in the dataset [S1].
4.  **Combine:** Compute $I_D$ using the retrieved $\Psi_{u,v}$, the calculated $E$, and the input luminances $L_b, L_f$. The exact linear combination depends on the specific derivation of the piecewise linear integral, which the source indicates is more accurate than piecewise constant methods [S1].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per cell after LUT lookup, dominated by two multiplications and one exponential calculation [S1].
*   **Memory Complexity:** $O(N^2)$ for the 2D LUT, where $N$ is the resolution of the table in each dimension.
*   **Accuracy:** Higher than piecewise constant (stair function) methods, with error 3 times lower for normal distribution estimations [S1].
*   **Limitations:** The domain of $\tau D$ is unbounded, requiring careful selection of LUT dimensions or normalization strategies [S1].

## Background
This method was proposed by Williams, Max, et al. in the paper "A Fast High Accuracy Volume Renderer for Unstructured Grids" (VolVis 2004) [S1]. It addresses the computational cost of accurate volume rendering by pre-integrating the linear luminance and attenuation profiles.
