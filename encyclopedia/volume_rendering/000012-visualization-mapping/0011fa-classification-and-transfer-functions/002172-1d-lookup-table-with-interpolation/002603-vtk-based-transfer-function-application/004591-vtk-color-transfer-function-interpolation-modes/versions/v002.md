# VTK Color Transfer Function Interpolation Modes

Also called: Color Space Interpolation, Color Transfer Function Interpolation Modes, Diverging interpolation, HSVWrap, Step interpolation, Transfer Function Color Mapping

## Overview
A method for mapping scalar values to colors using various interpolation spaces (RGB, HSV, CIELAB, PROLAB, Diverging, Step) within a color transfer function [S1]. It provides multiple interpolation spaces including RGB, HSV, CIELAB, PROLAB, Diverging, and Step, with specific behaviors for hue wrapping and diverging color paths [S1].

## How it works
**Inputs and Outputs:** Input is a scalar value $s$ and a set of control points $(x_i, c_i)$ where $x_i$ is the scalar position and $c_i$ is the color at that position [S1]. Output is the interpolated color $(R, G, B)$ at $s$ [S1].

**Data Structures:** The `vtkColorTransferFunction` maintains a list of nodes [S1]. Each node stores `position` (float scalar value) and `color` (array of 3 floats representing RGB or HSV values) [S1].

**Numbered Steps:**
1. Determine the interpolation mode $M$ set by `SetColorSpace()` [S1].
2. Find the interval $[x_i, x_{i+1}]$ containing the input scalar $s$ [S1].
3. If $s < x_0$, return the color of the first node (or black if clamping is off) [S1].
4. If $s > x_{n-1}$, return the color of the last node [S1].
5. Calculate the interpolation parameter $t = \frac{s - x_i}{x_{i+1} - x_i}$ [S1].
6. Interpolate the color components based on mode $M$ [S1].

**Formulas:**
- Linear interpolation parameter: $t = \frac{s - x_i}{x_{i+1} - x_i}$ [S1].
- RGB interpolation: $C = (1-t)C_i + tC_{i+1}$ for each component $C \in \{R, G, B\}$ [S1].
- HSV hue adjustment: If `HSVWrapOn`, compute shortest hue difference $\Delta H$; if $|\Delta H| > 180$, adjust by $\pm 360$ to find the shortest path [S1]. If `HSVWrapOff`, do not adjust for the 0/360 boundary [S1].
- CIELAB/CIEDE2000 interpolation: Shortest path in Lab space with respect to CIE Delta E 2000 distance measure [S1].
- Diverging interpolation: Passes through white when interpolating between two saturated colors [S1].
- Step interpolation: Returns $C_{i+1}$ directly [S1].

**Parameters:**
- `ColorSpace`: Enum or integer constant specifying RGB, HSV, CIELAB, PROLAB, Diverging, or Step [S1].
- `HSVWrap`: Boolean flag controlling whether hue interpolation crosses the 0/360 boundary [S1].

**Edge Cases:**
- Hue crossing: In HSV mode, if `HSVWrap` is Off, interpolation may take a long path around the hue circle if hues are near 0/360 [S1].
- Saturation detection: The threshold for "saturated" colors in Diverging mode is not specified in the sources [S1].
- Out-of-range mapping: Values outside the defined range map to the first or last node color, or black if clamping is off [S1].

**Pseudocode:**
```python
def interpolate_color(s, nodes, mode, hsv_wrap):
    # nodes: list of (position, color) tuples
    # color: list of 3 floats
    if s < nodes[0].position:
        return nodes[0].color
    if s > nodes[-1].position:
        return nodes[-1].color
    for i in range(len(nodes) - 1):
        if nodes[i].position <= s <= nodes[i+1].position:
            t = (s - nodes[i].position) / (nodes[i+1].position - nodes[i].position)
            c_i = nodes[i].color
            c_next = nodes[i+1].color
            if mode == "RGB":
                return [(1-t)*c_i[j] + t*c_next[j] for j in range(3)]
            elif mode == "HSV":
                h_i, sat_i, val_i = c_i
                h_next, sat_next, val_next = c_next
                dh = h_next - h_i
                if hsv_wrap and abs(dh) > 180:
                    dh += 360 if dh < 0 else -360
                h = h_i + t * dh
                sat = sat_i + t * (sat_next - sat_i)
                val = val_i + t * (val_next - val_i)
                return hsv_to_rgb(h, sat, val) # Standard conversion [G]
            elif mode in ("CIELAB", "PROLAB"):
                return [c_i[j] + t * (c_next[j] - c_i[j]) for j in range(3)]
            elif mode == "CIELAB_CIEDE2000":
                return shortest_path_lab(c_i, c_next, t) # CIE Delta E 2000 path [G]
            elif mode == "Diverging":
                return diverge_through_white(c_i, c_next, t) # White midpoint logic [G]
            elif mode == "Step":
                return c_next
    return nodes[-1].color
```

## Subtopics

### [Piecewise Hermite Color Transfer Function](11553-piecewise-hermite-color-transfer-function.md)
A method for mapping scalar values to RGB colors using modified piecewise Hermite interpolation within a specified color space. It solves the problem of defining smooth, perceptually controlled color gradients between user-defined nodes, supporting interpolation ranging from piecewise constant to piecewise linear. It is distinguished from its sibling [Piecewise Linear Color Transfer Function](11524-piecewise-linear-color-transfer-function.md) by the inclusion of `midpoint` and `sharpness` parameters, which allow for non-linear blending curves that can "squish" the transition or shift the average color location within an interval.

## Operating characteristics
Time and memory complexity are Not given in the sources. Strengths include perceptually uniform interpolation (CIELAB), correct hue wrapping (HSV), and specialized modes (Diverging, Step) [S1]. Limitations include unintuitive HSV interpolation when `HSVWrap` is Off and unspecified saturation detection logic for Diverging mode [S1].

## Background
The method originated in the Visualization Toolkit (VTK) library [S1]. The `vtkColorTransferFunction` class provides these interpolation modes to enable perceptually accurate color mapping for volume rendering and visualization tasks [S1].
