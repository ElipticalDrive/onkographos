# Automated Visibility-Based TF Parameter Optimization

Also called: Visibility-Based TF Parameter Optimization, visibility-driven TF tuning

## Overview
Automated Visibility-Based TF Parameter Optimization is an iterative method that adjusts transfer function (TF) parameters to minimize the squared difference between user-specified target visibility and the actual resultant visibility of Structures of Interest (SOIs) in a volume rendering [S2]. It solves the problem of manual fine-tuning by automatically prioritizing specific anatomical regions based on clinical or user-defined importance, ensuring that critical structures are not occluded by others [S1, unofficial][S2]. Unlike static TF assignment methods, this approach dynamically optimizes opacity parameters to enforce visibility priorities during DVR generation [S1, unofficial].

## How it works
**Inputs:**
1.  Initial Transfer Function $\theta$: A set of opacity parameters defining tent-shaped components for each SOI [S2].
2.  Target Visibility Thresholds ($VT_m$): A scalar value for each SOI $m$ representing its desired prominence, where $VT \in [0, 1]$ [S1, unofficial][S2].
3.  Volume Data: The 3D scalar field to be rendered [S2].
4.  Viewpoint $h$: The camera position for front-to-back ray casting [S2].

**Outputs:**
Optimized TF parameters $\theta^*$ that minimize the visibility tolerance error [S2].

**Data Structures:**
*   **SOI List:** A collection of $M$ Structures of Interest, each with an associated $VT_m$ and voxel indices [S2].
*   **TF Representation:** Composed of individual tent-shape components, one for each SOI, defined by apex opacity parameters $\theta$ [S1, unofficial][S2].
*   **Visibility Accumulator:** For each ray, a front-to-back accumulation buffer is maintained to compute voxel visibility [S2].

**Algorithm Steps:**

1.  **Initialize:** Set initial TF parameters $\theta$ (e.g., from a knowledge database or default values) [S1, unofficial][S2].
2.  **Compute Resultant Visibility ($VR_m$):** For each SOI $m$:
    a.  Cast rays from viewpoint $h$ through the volume [S2].
    b.  For each voxel $p$ in the volume, compute the accumulated opacity $A(p)$ using front-to-back composition:
        $$ A(p) = A(p - \Delta p) + (1.0 - A(p - \Delta p)) \cdot O(p) $$
        where $O(p)$ is the opacity of voxel $p$ defined by the current TF, and $\Delta p$ is the sampling step size [S2].
    c.  Compute the visibility contribution $F(p)$ for voxel $p$, representing the probability that $p$ is visible (not occluded by front voxels):
        $$ F(p) = e^{-\int_{h}^{p} A(g) dg} $$
        In discrete implementation, this is approximated by the accumulated transmittance from the viewpoint to $p$ [S2].
    d.  Calculate the resultant visibility $VR_m$ for SOI $m$ by summing the weighted opacities of all voxels $p$ belonging to SOI $m$:
        $$ VR_m = \sum_{p \in SOI_m} O(p) \cdot F(p) $$
        [S2]
3.  **Compute Energy Function ($E$):** Calculate the total visibility tolerance error across all $M$ SOIs:
    $$ E(\theta) = \sum_{m=1}^{M} (VT_m - VR_m)^2 $$
    [S2]
4.  **Optimize:** Use the downhill simplex method to adjust $\theta$ to minimize $E(\theta)$ [S2]. The iteration continues until convergence (minimum energy) is reached [S2].
5.  **Output:** The optimized TF parameters $\theta^*$ [S2].

**Parameters:**
*   $VT_m$: Visibility threshold for SOI $m$. Example values: $0.7$ for bones, $0.3$ for lungs [S1, unofficial]. Can be uniformly set or user-defined [S2].
*   $\theta$: Opacity parameters of tent apexes [S2].
*   $M$: Total number of SOIs [S2].
*   $\Delta p$: Sampling step size [S2].

**Pitfalls:**
*   The optimization landscape may contain multiple local minima, and the downhill simplex method is effective in this scenario, though gradient-based approaches like gradient descent are also applicable [S2].
*   False-positive SOIs retrieved from a knowledge database may require manual elimination, as the optimization only adjusts parameters for existing components [S1, unofficial].

**Pseudocode:**
```python
import math
import numpy as np

def sample_volume(volume, pos):
    """Trilinear interpolation of the 3D scalar field at continuous position pos."""
    ix, iy, iz = pos
    x0, y0, z0 = int(math.floor(ix)), int(math.floor(iy)), int(math.floor(iz))
    x1, y1, z1 = min(x0 + 1, volume.shape[0]-1), min(y0 + 1, volume.shape[1]-1), min(z0 + 1, volume.shape[2]-1)
    fx, fy, fz = ix - x0, iy - y0, iz - z0
    v00 = volume[x0, y0, z0] * (1-fx) + volume[x1, y0, z0] * fx
    v01 = volume[x0, y1, z0] * (1-fx) + volume[x1, y1, z0] * fx
    v10 = volume[x0, y0, z1] * (1-fx) + volume[x1, y0, z1] * fx
    v11 = volume[x0, y1, z1] * (1-fx) + volume[x1, y1, z1] * fx
    return v00 * (1-fy) * (1-fz) + v01 * (1-fy) * fz + v10 * fy * (1-fz) + v11 * fy * fz

def evaluate_tf(theta, scalar_value):
    """Evaluates opacity O(p) using tent-shaped TF components defined by theta."""
    # [G] Standard tent function: apex at theta[1] with height theta[0] and width theta[2]
    return max(0.0, theta[0] * (1.0 - abs(scalar_value - theta[1]) / theta[2]))

def compute_ray_visibility(volume, viewpoint, target_voxel, step_size, theta):
    """Computes F(p) for a voxel p via front-to-back ray casting."""
    ray_dir = np.array(target_voxel) - np.array(viewpoint)
    dist = np.linalg.norm(ray_dir)
    if dist == 0:
        return 1.0
    ray_dir = ray_dir / dist
    pos = np.array(viewpoint)
    accumulated_opacity = 0.0
    while np.linalg.norm(np.array(pos) - np.array(target_voxel)) > 1e-6:
        scalar = sample_volume(volume, pos)
        opacity = evaluate_tf(theta, scalar)
        accumulated_opacity = accumulated_opacity + (1.0 - accumulated_opacity) * opacity
        pos = pos + ray_dir * step_size
    return 1.0 - accumulated_opacity

def energy_function(theta, volume, sois, vt_targets):
    """Computes E(theta) = sum((VT_m - VR_m)^2)."""
    energy = 0.0
    for m, soi in enumerate(sois):
        vr_m = 0.0
        for p in soi.voxel_indices:
            o_p = evaluate_tf(theta, sample_volume(volume, p))
            f_p = compute_ray_visibility(volume, soi.viewpoint, p, soi.step_size, theta)
            vr_m += o_p * f_p
        energy += (vt_targets[m] - vr_m) ** 2
    return energy

def downhill_simplex_step(simplex, volume, sois, vt_targets):
    """Performs one iteration of the Nelder-Mead (downhill simplex) method."""
    # [G] Standard Nelder-Mead: sort vertices, compute centroid, reflect, expand/contract, shrink
    simplex = sorted(simplex, key=lambda v: energy_function(v, volume, sois, vt_targets))
    best, worst = simplex[0], simplex[-1]
    centroid = np.mean(simplex[:-1], axis=0)
    reflected = centroid + 0.5 * (centroid - worst)
    e_ref = energy_function(reflected, volume, sois, vt_targets)
    if e_ref < energy_function(best, volume, sois, vt_targets):
        simplex[-1] = centroid + 1.0 * (centroid - worst)
    elif e_ref < energy_function(simplex[-2], volume, sois, vt_targets):
        simplex[-1] = reflected
    else:
        simplex[-1] = 0.5 * (simplex[-1] + centroid)
    return simplex

def optimize_visibility_tf(volume, sois, vt_targets, max_iterations=100, tolerance=1e-4):
    """Optimizes TF parameters to match target visibilities for SOIs."""
    # Initialize TF parameters (tent apex opacities)
    theta = np.array([0.5, 128.0, 64.0]) # [G] Default tent parameters
    # Initialize simplex (M+1 vertices in parameter space)
    simplex = [theta.copy()]
    for i in range(len(theta)):
        vertex = theta.copy()
        vertex[i] *= 1.1 if vertex[i] != 0 else 1.1
        simplex.append(vertex)

    prev_energy = float('inf')
    for _ in range(max_iterations):
        energy = energy_function(theta, volume, sois, vt_targets)
        if abs(prev_energy - energy) < tolerance:
            break
        prev_energy = energy
        simplex = downhill_simplex_step(simplex, volume, sois, vt_targets)
        theta = simplex[0]
    return theta
```

## Subtopics

### [Visibility Histogram Refinement](11697-visibility-histogram-refinement.md)
A technique that combines visibility histograms with a non-assisted approach to refine transfer function specifications, revealing regions hidden from the observer's position. The user first performs a preliminary TF specification, which is then refined to make visible structures that were previously occluded.

## Operating characteristics
*   **Time Complexity:** The optimization is iterative, with each iteration requiring a full volume rendering pass to compute visibility for all SOIs [S2]. The downhill simplex method adds overhead proportional to the number of TF parameters [G]. No explicit complexity formula is given in the sources [S2].
*   **Memory Complexity:** Requires storage for the volume data, SOI voxel indices, and TF parameters [S2]. Visibility computation may require temporary buffers for ray casting [G].
*   **Performance:** Evaluated on the 3D-IRCADb-01 dataset (20 CT volumes of the upper abdomen) [S2]. The method effectively prioritizes visibility of specific SOIs (e.g., bones over lungs) without manual tuning [S1, unofficial].
*   **Strengths:** Automates TF fine-tuning, handles multiple local minima effectively, allows user-defined visibility priorities [S1, unofficial][S2].
*   **Limitations:** Requires initial TF components (e.g., from a knowledge database); false positives may need manual removal; convergence is not guaranteed to be global [S1, unofficial][S2].
*   **When to Use:** When automatic prioritization of specific anatomical structures is needed, and manual TF tuning is time-consuming or inconsistent [S1, unofficial].
*   **When Not to Use:** When real-time interactive TF editing is required, as the optimization may be too slow [S2].

## Background
The method was proposed by Younhyun Jung et al. in the context of a Transfer Function Design for Medical Volume Data Using a Knowledge Database [S2]. It builds upon earlier work on visibility-based TF parameter optimization [9, 10] cited in the paper [S2]. The approach is part of a broader effort to automate TF design using retrieved SOI features from a knowledge database [S1, unofficial][S2].
