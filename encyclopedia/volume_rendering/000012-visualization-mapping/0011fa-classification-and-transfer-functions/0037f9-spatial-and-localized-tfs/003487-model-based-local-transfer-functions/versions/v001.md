# Model-Based Local Transfer Functions

Also called: Morphon-based local TFs

## Overview
Model-Based Local Transfer Functions is a visualization method for medical image volumes that applies multiple voxel-specific transfer functions simultaneously to different anatomical regions, determined by a deformable anatomical model registered to the volume [S1]. It solves the problem of reviewing complex medical data by allowing a radiologist to efficiently visualize disjoint anatomical regions with their optimal transfer functions in a single pass, rather than switching between global settings [S1]. It differs from sibling methods like Spatial Style Zones by explicitly using a deformable anatomical model (via Morphon registration) to define the spatial priors for the transfer functions, ensuring the classification boundaries align with tissue anatomy rather than arbitrary spatial coordinates [S1].

## How it works
**Inputs:**
*   Target volume $I_T$: The medical image volume to be visualized.
*   Source model $I_S$: An anatomical model with $N$ compartments, initially identical to the target model structure $I_M$.
*   Display bit depth: $bits_{display}$, the number of bits available for the display device.
*   Storage bit depth: $bits_{stored}$, the number of bits used to store each voxel value in the input volume.

**Outputs:**
*   Display volume $I_{disp}$: The final rendered image where each voxel is mapped through a local transfer function.

**Data Structures:**
*   **Model Compartments ($IC_i$):** For each compartment $i \in \{1, \dots, N\}$, a 3D grid storing the probability $IC_i(x) \in [0, 1]$ that voxel $x$ belongs to tissue $i$.
*   **Deformation Field ($d(x)$):** A 3D vector field where each entry $d(x)$ represents the displacement vector required to map a point from the source model space to the target volume space.
*   **Parameters:**
    *   $a_i$: Weighting values for combining compartments to create a registration-ready model.
    *   $\alpha_i, \beta_i$: Minimum and maximum intensity values assigned to compartment $i$, defining the local transfer function range.

**Steps:**

1.  **Model Definition:**
    Define the anatomical model $I_M$ with $N$ compartments. Each compartment $IC_i(x)$ represents the probability of tissue $i$ at location $x$. The compartments are constrained such that:
    $$ \sum_{i=1}^{N} IC_i(x) = 1 $$
    The model used for registration, $I_M$, is a weighted combination of these compartments:
    $$ I_M = \sum_{i=1}^{N} a_i IC_i $$
    The weights $a_i$ are selected based on the registration method. For phase-based registration (e.g., Morphon), $a_i$ must ensure that the boundaries between compartments in $I_M$ have the same sign as the boundaries in the target volume $I_T$ [S1].

2.  **Registration (Morphon):**
    Register the source model $I_S$ (where $I_S = I_M$) to the target volume $I_T$ using the Morphon algorithm, a phase-based non-rigid registration method [S1].
    *   The algorithm iteratively deforms $I_S$ using a displacement field $d(x)$ such that the deformed source $I_D(x) = I_S(x + d(x))$ becomes similar to $I_T$.
    *   The process is multi-scale: it starts at coarse scales to register large global displacements and moves to finer scales to register smaller local deformations [S1].
    *   Upon completion, the final estimated deformation field $d(x)$ is obtained.

3.  **Deformation of Compartments:**
    Apply the estimated deformation field $d(x)$ to all model compartments using linear interpolation to obtain the deformed compartments $\tilde{IC}_i(x)$:
    $$ \tilde{IC}_i(x) = IC_i(x + d(x)) $$
    This step effectively warps the anatomical model to match the patient's anatomy in $I_T$ [S1].

4.  **Local Transfer Function Calculation:**
    For each voxel $x$, calculate the local minimum $I_\alpha(x)$ and maximum $I_\beta(x)$ based on the deformed compartment probabilities and the user-defined parameters $\alpha_i, \beta_i$:
    $$ I_\alpha(x) = \frac{\sum_{i=1}^{N} \alpha_i \tilde{IC}_i(x)}{\sum_{i=1}^{N} \tilde{IC}_i(x)} $$
    $$ I_\beta(x) = \frac{\sum_{i=1}^{N} \beta_i \tilde{IC}_i(x)}{\sum_{i=1}^{N} \tilde{IC}_i(x)} $$
    Note: Since $\sum \tilde{IC}_i(x) = 1$ (preserved by interpolation of probabilities), the denominators are effectively 1, simplifying to weighted sums [S1].

5.  **Voxel Mapping:**
    Transform the input voxel value $I(x)$ into the display value $I_{disp}(x)$ using the following sequence:
    *   Calculate the slope for the display range:
        $$ I_{slope} = \frac{2^{bits_{display}} - 1}{I_\beta(x) - I_\alpha(x)} $$
    *   Clamp the input voxel value $I(x)$ to the local range $[I_\alpha(x), I_\beta(x)]$:
        $$ \tilde{I}(x) = \min(\max(I(x), I_\alpha(x)), I_\beta(x)) $$
    *   Map the clamped value to the display range:
        $$ I_{disp}(x) = I_{slope} \cdot (\tilde{I}(x) - I_\alpha(x)) $$
    This ensures that the dynamic range of the display is utilized optimally for the specific tissue type at voxel $x$ [S1].

6.  **Transition Handling (Optional):**
    To handle transition regions between compartments where registration errors or tissue boundaries are ambiguous, apply a user-controlled averaging filter to the transition regions. The radiologist selects the filter type and size. This prevents disturbing features from appearing at compartment boundaries [S1].

        deformed_compartments.append(IC_i_tilde)
        
    # Initialize output volume
    I_disp = zeros_like(target_volume)
    
    # Step 4 & 5: Local TF and Mapping
    for x in voxel_coordinates(target_volume):
        I_val = target_volume[x]
        
        # Calculate local alpha and beta
        # Since sum(IC_i_tilde) should be 1, denominators are 1
        I_alpha = 0.0
        I_beta = 0.0
        for i in range(N):
            prob = deformed_compartments[i][x]
            I_alpha += alpha_params[i] * prob
            I_beta += beta_params[i] * prob
            
        # Calculate slope
        denominator = I_beta - I_alpha
        if denominator == 0:
            # Avoid division by zero; if range is zero, map to center or handle as edge case
            # Source does not specify, but typically implies constant intensity
            I_disp[x] = (2**bits_display - 1) / 2.0 
        else:
            I_slope = (2**bits_display - 1) / denominator
            
            # Clamp input
            I_tilde = max(min(I_val, I_beta), I_alpha)
            
            # Map to display
            I_disp[x] = I_slope * (I_tilde - I_alpha)
            
    # Step 6: Transition averaging (optional post-processing)

    return I_disp

def linear_interpolate_grid(grid, displacement_field):
    """
    Interpolates the grid values at positions shifted by the displacement field.
    displacement_field[x] = (dx, dy, dz)
    Returns new grid where new_grid[x] = grid[x + displacement_field[x]]
    """
    new_grid = zeros_like(grid)
    for x in voxel_coordinates(grid):
        # Calculate source coordinate in original grid
        src_x = x + displacement_field[x]
        # Perform trilinear interpolation at src_x in original grid
        new_grid[x] = trilinear_interpolate(grid, src_x)
    return new_grid

**Parameters:**
*   $a_i$: Weighting values for combining compartments. Selection depends on registration method (e.g., intensity-based vs. phase-based) [S1].
*   $\alpha_i, \beta_i$: Min and max values for each compartment $i$, controlling the local transfer function range [S1].
*   Transition averaging: User-controlled averaging filter type and size for transition regions [S1].

**Edge Cases and Pitfalls:**
*   **Transition Regions:** Registration algorithms are not perfect, and tissue borders are rarely binary. Discontinuous transitions between transfer functions can introduce disturbing features. The method uses continuous probability compartments $[0, 1]$ instead of binary models to ensure smooth transitions [S1].
*   **Zero Denominator:** If $I_\beta(x) = I_\alpha(x)$, the slope calculation involves division by zero. The source does not explicitly define the behavior, but it implies a constant intensity mapping or requires a guard [G].

## Operating characteristics
*   **Time Complexity:** Dominated by the Morphon registration step, which is iterative and multi-scale. The visualization step is linear with respect to the number of voxels and compartments.
*   **Memory Complexity:** Requires storage for the target volume, the source model compartments ($N$ grids), the deformation field, and the deformed compartments.
*   **Strengths:** Allows efficient review of multiple anatomical regions simultaneously with optimal contrast for each. Automatically assigns transfer functions based on anatomy.
*   **Limitations:** Relies on the accuracy of the registration algorithm. Poor registration leads to misaligned transfer functions. Requires a pre-defined anatomical model.
*   **When to use:** Medical image visualization where different tissues require different intensity mappings and anatomical context is available.
*   **When not to use:** Non-medical volumes without anatomical models, or when real-time performance is critical and registration overhead is prohibitive.

## Background
The method was proposed by Forsberg et al. in the paper "Model-Based Transfer Functions for Efficient Visualization of Medical Image Volumes" [S1]. It addresses the limitation of previous methods that did not utilize underlying human anatomy to control visualization. The Morphon algorithm used for registration is a phase-based non-rigid registration method [S1].
