# Pre-classification

Also called: Transfer Function Application (pre-sampling)

## Overview
Pre-classification is a volume rendering technique where the transfer function (TF) is applied to scalar values at the grid points (voxels) before sampling interpolation occurs [S2][S3, unofficial]. It maps every scalar value at the grid into color and opacity, which are then assigned at the resampling points [S2]. This approach suppresses high-frequency information introduced by nonlinear transfer functions, resulting in rendered images that appear blurry compared to post-classification methods [S2].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D volume grid of scalar values $v_i$ and a transfer function $T$ mapping scalars to optical properties [S2][S3, unofficial].
*   **Output:** A 2D image where each pixel is accumulated from interpolated optical properties (color $C$ and opacity $\alpha$) derived from the pre-classified voxels [G].

**Data Structures:**
The volume is stored as a 3D grid of scalar values. The transfer function maps each scalar input to a color vector $C \in [0, 1]^3$ (or $[0, 255]^3$) and an opacity $\alpha \in [0, 1]$ [S3, unofficial].

**Steps:**
1.  **Pre-classification:** For each voxel $i$ in the volume grid with scalar value $v_i$, evaluate the transfer function $T$ to obtain the color $C_i = T(v_i)$ and opacity $\alpha_i = T_\alpha(v_i)$ [S2][S3, unofficial].
2.  **Ray Casting:** For each pixel, cast a ray through the volume [S1, unofficial].
3.  **Interpolation:** Sample the pre-classified optical properties along the ray. The color $C_{sample}$ and opacity $\alpha_{sample}$ at a sample point are obtained by interpolating the $C_i$ and $\alpha_i$ values of the surrounding voxels [S2].
4.  **Accumulation:** Composite the interpolated samples using standard volume rendering integration (e.g., front-to-back compositing) to produce the final pixel color [G].

**Pseudocode:**
```python
def raycast_preclassified(colors, opacities, bounds, ray_origin, ray_direction, step_size):
    """
    Renders a single ray using pre-classified color and opacity arrays.
    colors: 4D array (Dx, Dy, Dz, 3) of pre-classified RGB values.
    opacities: 3D array (Dx, Dy, Dz) of pre-classified alpha values.
    bounds: [min_x, min_y, min_z, max_x, max_y, max_z]
    ray_origin: [ox, oy, oz]
    ray_direction: [dx, dy, dz]
    step_size: float, distance between samples.
    Returns: (r, g, b, alpha)
    """
    # 1. Ray-box intersection
    t_min, t_max = 0.0, float('inf')
    for i in range(3):
        if ray_direction[i] == 0:
            if ray_origin[i] < bounds[i] or ray_origin[i] > bounds[i+3]:
                return (0.0, 0.0, 0.0, 0.0)
        else:
            t1 = (bounds[i] - ray_origin[i]) / ray_direction[i]
            t2 = (bounds[i+3] - ray_origin[i]) / ray_direction[i]
            t_enter = min(t1, t2)
            t_exit = max(t1, t2)
            t_min = max(t_min, t_enter)
            t_max = min(t_max, t_exit)
            
    if t_max < t_min:
        return (0.0, 0.0, 0.0, 0.0)

    # 2. Initialize compositing
    acc_color = [0.0, 0.0, 0.0]
    acc_alpha = 0.0
    t = t_min

    # 3. Step along ray and accumulate
    while t < t_max:
        pos = [ray_origin[i] + t * ray_direction[i] for i in range(3)]
        c_sample, a_sample = interpolate_3d(colors, opacities, pos, bounds)
        
        # Front-to-back compositing
        weight = (1.0 - acc_alpha) * a_sample
        acc_color[0] += weight * c_sample[0]
        acc_color[1] += weight * c_sample[1]
        acc_color[2] += weight * c_sample[2]
        acc_alpha += weight
        
        if acc_alpha >= 1.0:
            break
            
        t += step_size

    return tuple(acc_color) + (acc_alpha,)

def interpolate_3d(colors, opacities, pos, bounds):
    """Trilinear interpolation of pre-classified color and opacity at pos."""
    # Map continuous position to grid coordinates
    dx = (bounds[3] - bounds[0]) / (colors.shape[0] - 1)
    dy = (bounds[4] - bounds[1]) / (colors.shape[1] - 1)
    dz = (bounds[5] - bounds[2]) / (colors.shape[2] - 1)
    
    x = (pos[0] - bounds[0]) / dx
    y = (pos[1] - bounds[1]) / dy
    z = (pos[2] - bounds[2]) / dz
    
    # Clamp to valid grid range
    x = max(0.0, min(float(colors.shape[0]-1), x))
    y = max(0.0, min(float(colors.shape[1]-1), y))
    z = max(0.0, min(float(colors.shape[2]-1), z))
    
    x0, y0, z0 = int(x), int(y), int(z)
    x1, y1, z1 = x0 + 1, y0 + 1, z0 + 1
    
    fx, fy, fz = x - x0, y - y0, z - z0
    
    # Fetch 8 neighbors
    def get_val(arr, ix, iy, iz):
        ix = max(0, min(arr.shape[0]-1, ix))
        iy = max(0, min(arr.shape[1]-1, iy))
        iz = max(0, min(arr.shape[2]-1, iz))
        return arr[ix, iy, iz]
        
    c000 = get_val(colors, x0, y0, z0)
    c100 = get_val(colors, x1, y0, z0)
    c010 = get_val(colors, x0, y1, z0)
    c110 = get_val(colors, x1, y1, z0)
    c001 = get_val(colors, x0, y0, z1)
    c101 = get_val(colors, x1, y0, z1)
    c011 = get_val(colors, x0, y1, z1)
    c111 = get_val(colors, x1, y1, z1)
    
    a000 = get_val(opacities, x0, y0, z0)
    a100 = get_val(opacities, x1, y0, z0)
    a010 = get_val(opacities, x0, y1, z0)
    a110 = get_val(opacities, x1, y1, z0)
    a001 = get_val(opacities, x0, y0, z1)
    a101 = get_val(opacities, x1, y0, z1)
    a011 = get_val(opacities, x0, y1, z1)
    a111 = get_val(opacities, x1, y1, z1)
    
    # Trilinear interpolation for color and opacity
    def lerp(v0, v1, t):
        return v0 * (1 - t) + v1 * t
        
    c00 = lerp(c000, c100, fx)
    c10 = lerp(c010, c110, fx)
    c01 = lerp(c001, c101, fx)
    c11 = lerp(c011, c111, fx)
    
    c0 = lerp(c00, c10, fy)
    c1 = lerp(c01, c11, fy)
    c_sample = lerp(c0, c1, fz)
    
    a00 = lerp(a000, a100, fx)
    a10 = lerp(a010, a110, fx)
    a01 = lerp(a001, a101, fx)
    a11 = lerp(a011, a111, fx)
    
    a0 = lerp(a00, a10, fy)
    a1 = lerp(a01, a11, fy)
    a_sample = lerp(a0, a1, fz)
    
    return c_sample, a_sample
```

**Parameters:**
*   **Transfer Function $T$:** Defines the mapping from scalar to optical properties, commonly defined by piecewise linear functions or user-specified keypoints [S3, unofficial].

**Edge Cases and Pitfalls:**
*   **Blurriness:** Pre-classification suppresses high-frequency information introduced by nonlinear transfer functions, causing the rendered image to appear blurry [S2]. This effect is particularly noticeable when the image resolution exceeds the volume resolution [G].
*   **Aliasing:** While post-classification is prone to aliasing ("striping" artifacts), pre-classification avoids this by smoothing the high frequencies, but at the cost of detail [S2].

## Operating characteristics
*   **Time Complexity:** Pre-classification requires $O(N)$ operations to map all $N$ voxels, performed once [G]. Ray casting remains $O(R \cdot S)$ where $R$ is the number of rays and $S$ is the number of samples per ray [G].
*   **Memory Complexity:** Requires storing pre-classified color and opacity arrays alongside the scalar volume, increasing memory footprint [G].
*   **Strengths:** Prevents aliasing artifacts associated with post-classification; suitable for pre-processing tasks like segmentation [S1, unofficial][S2].
*   **Limitations:** Produces blurry images and loses high-frequency details [S2].
*   **When to use:** When visual smoothness is preferred over sharp edges [S2].
*   **When not to use:** When sharp edges and high-frequency details are critical [S2].

## Background
Pre-classification and post-classification were introduced as fundamental approaches to volume rendering classification, distinguished by the order of applying the transfer function and sampling interpolation [S2][S3, unofficial]. Pre-integrated classification was later proposed to address the under-sampling problem and improve quality by simulating infinitely many interpolated samples between grid points [S2].
