# Directional Textured Tracelines

Also called: Animated Line Tracelines, Texture Map Animation for Vector Magnitude, Textured Streamlines

## Overview
Directional Textured Tracelines is a flow visualization technique that enhances standard 1D line primitives (streamlines) by overlaying an animated 1D texture to explicitly convey flow direction [S1, unofficial]. While standard lines indicate orientation and extent, they fail to show the direction of the underlying vector field; this method solves that ambiguity by moving a structured texture (e.g., a zebra-like pattern) along the line in the direction of the flow [S1, unofficial]. It builds on [Stream Lines](4796-stream-lines.md) by animating texture coordinates along the computed trajectories [G].

## How it works
**Inputs:**
- A set of streamlines, each defined as an ordered sequence of vertices [S1, unofficial].
- A 1D texture map $T$, containing a visual structure (e.g., alternating dark/light bands) that varies monotonically in intensity [S1, unofficial][S2, book].
- A global time parameter $\Delta t$ [S1, unofficial].

**Outputs:**
- Rendered streamlines with apparent motion indicating flow direction [S1, unofficial].

**Data Structures:**
- **Vertices:** Each vertex $v_i$ of a line is assigned a local texture coordinate $u_i$ [S1, unofficial].
- **Texture Coordinate Range:** The coordinates are normalized such that $u_0 = 0$ at the first vertex and $u_n = 1$ at the last vertex [S1, unofficial].
- **Texture Map:** A static 1D image computed on the CPU and downloaded to GPU memory once; it does not change during animation [S1, unofficial].

**Steps:**
1. **Assign Texture Coordinates:** For each vertex $v_i$ in a streamline, assign a local texture coordinate $u_i$ with a range between $[0, 1]$ from the first to the last vertex respectively [S1, unofficial].
2. **Select Texture:** Choose a 1D texture map whose intensity varies monotonically from dark to light [S2, book].
3. **Shift Coordinates:** For each frame, shift the local texture coordinate of each vertex by the global parameter $\Delta t$ to move the texture along the line in the direction of the underlying flow field [S1, unofficial]. The effective coordinate is computed as $u'_i = (u_i + \Delta t) \mod 1$.
4. **Render:** Render the lines using the shifted texture coordinates, which creates the illusion of the line crawling in the direction of the vector field [S2, book].

**Edge Cases and Pitfalls:**
- **Direction Ambiguity:** Lines alone fail to indicate flow direction; the animated texture is required to resolve this [S1, unofficial].
- **Texture Selection:** The texture must have visual structure (e.g., zebra-like pattern) for motion to be perceivable [S1, unofficial].
- **Precision & Boundaries:** The modulo operation handles coordinate wrapping seamlessly, but large $\Delta t$ values may cause visual aliasing if the texture lacks sufficient high-frequency detail [G]. Degenerate lines with fewer than two vertices must be skipped to avoid division by zero during coordinate assignment [G].

## Background
Originated in GPU-assisted multi-field video volume visualization [S1, unofficial]. The technique leverages texture coordinate animation to add apparent motion to geometric objects, a concept also applied to hedgehogs for vector magnitude visualization [S2, book]. It is used in scientific visualization to enhance the readability of vector fields in dynamic environments [G].
