# Direct Volume Rendering of LIC Textures
Also called: Fuzzy classifier based DVT, LIC DVT

## Overview
Direct Volume Rendering of LIC Textures is a visualization method that renders nerve fibre structures and other tissue types simultaneously by combining a Line Integral Convolution (LIC) texture with a probability map [S1]. It solves the problem of efficiently visualizing complex directional data in Diffusion Tensor Imaging (DTI) without the computational overhead of ensuring uniform coverage across the entire volume [S1]. Unlike streamline-based techniques which render explicit geometric primitives, this method uses volume rendering to represent finer details via noise texture resolution and allows for semi-transparent or nearly opaque fibre tracts [S1]. It sets itself apart from its sibling [Seed Line Integral Convolution](8864-seed-line-integral-convolution.md) by utilizing the generated LIC texture and hit-count probability map as dual inputs for transfer function definition, rather than just rendering the texture itself [S1].

## How it works
**Inputs:**
1.  A set of seed points distributed based on the probability of being within a Region of Interest (ROI) [S1]. These seed points are identical to those used in a preceding streamline visualization [S1].
2.  A streamline generation algorithm (or pre-computed streamlines) that enforces physiological constraints for nerve fibre tracking [S1].
3.  A noise texture used for convolution [S1].
4.  Transfer functions (colour and transparency look-up tables) [S1].

**Outputs:**
A volume-rendered image representing the directional information of nerve fibre structures and other tissue types [S1].

**Data Structures:**
1.  **LIC Texture:** A 2D or 3D texture encoding the direction information of nerve fibre structures [S1]. The resolution of this texture determines the level of fine detail visible [S1].
2.  **Probability Map:** A data set estimating the probability that a voxel lies within a nerve fibre structure [S1]. This is computed by counting the number of times each cell (voxel) is hit by field lines during the LIC texture generation process [S1].

**Algorithm Steps:**
1.  **Reuse Streamlines:** Reuse the generation of streamlines performed for previous visualizations to ensure nerve fibre structures are tracked appropriately with physiological constraints [S1].
2.  **Distribute Seeds:** Distribute seed points based on the probability that a point is within the Region of Interest (ROI) [S1].
3.  **Generate LIC Texture:** Compute the LIC texture using the seed points and streamlines, similar to the Seed LIC algorithm [S1]. This involves convolving the noise texture along the streamlines passing through the seed points [S1].
4.  **Compute Probability Map:** During the LIC generation, count the number of times each voxel is hit by the field lines [S1]. This count forms the probability map [S1].
5.  **Define Transfer Functions:** Use two data sets to define the transfer functions:
    *   The LIC texture, which encodes directional information [S1].
    *   The probability map, which indicates the likelihood of a voxel belonging to the nerve fibre structure [S1].
6.  **Volume Render:** Perform direct volume rendering using the LIC texture and the probability map to define colour and transparency [S1]. The opacity transfer functions can be adjusted to represent fibre tracts as semi-transparent or nearly opaque [S1].

**Pseudocode:**
```python
def direct_volume_rendering_of_lic_textures(
    roi_probability_grid,
    streamline_generator,
    noise_texture,
    colour_lut,
    opacity_lut
):
    """
    Performs Direct Volume Rendering of LIC Textures.
    
    Args:
        roi_probability_grid: 3D grid of probabilities for ROI membership.
        streamline_generator: Function to generate streamlines from seed points.
        noise_texture: 2D or 3D noise texture for convolution.
        colour_lut: Colour lookup table.
        opacity_lut: Opacity lookup table.
        
    Returns:
        Rendered image.
    """
    # Step 1: Reuse or generate streamlines based on ROI probabilities
    # Seed points are distributed based on the probability that a point is within the ROI
    seed_points = []
    for voxel in roi_probability_grid:
        if random() < voxel.probability:
            seed_points.append(voxel.center)
            
    # Generate streamlines using the seed points
    # This reuses the generation logic from streamline visualization
    streamlines = streamline_generator(seed_points)
    
    # Step 2: Generate LIC Texture and Probability Map
    # Initialize LIC texture and hit count map
    lic_texture = create_texture_like(noise_texture)
    hit_count_map = zeros_like(roi_probability_grid)
    
    for streamline in streamlines:
        # Trace the streamline and convolve noise
        for point in streamline:
            # Convolve noise along the streamline direction at point
            # This is similar to Seed LIC algorithm
            convolved_noise = convolve_noise_along_direction(
                noise_texture, 
                point, 
                streamline.direction_at(point)
            )
            # Store in LIC texture
            set_texture_value(lic_texture, point, convolved_noise)
            
            # Increment hit count for probability map
            hit_count_map[point] += 1
            
    # Normalize hit count map to get probability map
    probability_map = normalize(hit_count_map)
    
    # Step 3: Define Transfer Functions
    # Use LIC texture for directional info and probability map for structure likelihood
    # The specific mapping logic depends on the fuzzy classifier implementation
    # [G] Assuming a standard volume rendering transfer function application
    def get_colour_and_opacity(lic_value, prob_value):
        # Map LIC value to colour based on direction
        c = colour_lut(lic_value)
        # Map probability to opacity
        o = opacity_lut(prob_value)
        return c, o
        
    # Step 4: Volume Render
    # Render the volume using the LIC texture and the computed transfer functions
    image = volume_render(
        lic_texture,
        get_colour_and_opacity,
        opacity_lut=opacity_lut
    )
    
    return image
```

**Parameters:**
*   **Noise Texture Resolution:** Determines the fineness of details that can be represented [S1].
*   **Opacity Transfer Functions:** Control whether fibre tracts are represented as semi-transparent or nearly opaque [S1].

**Edge Cases and Pitfalls:**
*   **High Transparency:** For high transparency values, the 3D arrangement of fibre tracts is not as clear as for streamline-based techniques [S1].
*   **ROI Definition:** The method relies on accurate ROI probability distribution to avoid overhead; incorrect distribution may lead to incomplete coverage or wasted computation [S1].

## Operating characteristics
*   **Time Complexity:** Generation time is measured in seconds rather than hours, avoiding the overhead of Fast LIC and ensuring hits everywhere (even outside ROI) [S1].
*   **Memory Complexity:** Requires storage for the LIC texture and the probability map (hit count map) [S1].
*   **Strengths:** Efficient generation time; reuses streamline generation; represents finer details via noise texture resolution; allows interactive variation of opacity to improve 3D perception [S1].
*   **Limitations:** For high transparency values, the 3D arrangement of fibre tracts is less clear compared to streamline-based techniques [S1].
*   **When to Use:** When efficient visualization of directional nerve fibre structures is required, and interactive opacity adjustment is beneficial [S1].
*   **When Not to Use:** When clear 3D arrangement of fibre tracts at high transparency is critical [S1].

## Background
This method was developed for visualizing Diffusion Tensor Imaging (DTI) data to view brain anatomy and nerve fibre tracking in vivo [S1]. It was presented by Burkhard Wünsche, Jarno van der Linden, and Nathan Holmberg in a preprint submitted to Elsevier Science in March 2005 [S1]. The work is part of a broader effort in biomedical visualization and tensor field visualization [S1].
