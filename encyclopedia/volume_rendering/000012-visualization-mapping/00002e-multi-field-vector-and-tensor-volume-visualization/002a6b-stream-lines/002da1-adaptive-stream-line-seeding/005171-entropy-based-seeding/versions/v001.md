# Entropy-based Seeding

Also called: Information-Theoretic Streamline Seeding, Shannon Entropy Seeding

## Overview
Entropy-based Seeding is a method for selecting streamline seed locations in 3D vector fields by using Shannon’s entropy to measure local information content [S1]. It places seeds proportionally to entropy values to quantitatively capture critical flow features, such as turbulent cores, ensuring important regions are densely sampled [S1]. It differs from sibling methods like [Adaptive Stream Line Seeding](5604-adaptive-stream-line-seeding.md) by deriving seed density directly from an information-theoretic scalar field rather than geometric divergence or control kernels.

## How it works
**Inputs:** A 3D vector field $V$.
**Outputs:** A set of streamlines traced from seeds.

**Data Structures:**
*   **Entropy Volume:** A 3D scalar grid of the same resolution as the input vector field, storing $H(x)$ for each voxel.
*   **Seed List:** A collection of 3D coordinates $(x, y, z)$ where streamlines originate.

**Parameters:**
*   **Number of bins ($n$):** The number of partitions for vector quantization. The sources do not specify a default value but refer to suggestions by Xu et al. [XLS10].
*   **Neighborhood size:** The spatial extent around each voxel used to compute local entropy. The sources do not specify a default value but refer to suggestions by Xu et al. [XLS10].
*   **Integration method:** Fourth-order Runge-Kutta [S1].

**Steps:**

1.  **Calculate Local Entropy Field:**
    For each voxel in the vector field, compute the local Shannon entropy $H(x)$ based on the distribution of vectors in its neighborhood.
    
    The entropy of a discrete random variable $X$ is defined as [S1]:
    $$ H(x) = - \sum_{x_i \in X} p(x_i) \log_2 p(x_i) $$
    
    Where $p(x_i)$ is the probability mass function for bin $x_i$. This probability is approximated by creating a histogram of vectors in the local neighborhood using vector quantization [Leo06]:
    $$ p(x_i) = \frac{C(x_i)}{\sum_{j=1}^{n} C(x_j)} $$
    
    Here, $C(x_i)$ is the number of vectors falling into bin $x_i$, and $n$ is the total number of bins [S1].

2.  **Determine Seed Probabilities:**
    Set the probability of seeding at each voxel to be proportional to its scalar value in the computed entropy volume [S1].

3.  **Place Seeds:**
    Place a sufficient number of seeds in the field based on the probability associated with each voxel. The goal is to cover as many important areas (high entropy) as possible [S1].

4.  **Trace Streamlines:**
    Trace streamlines from the placed seeds using fourth-order Runge-Kutta integration [S1].

**Pseudocode:**

```python
def entropy_based_seeding(vector_field, num_bins, neighborhood_size):
    """
    vector_field: 3D array of vectors (Vx, Vy, Vz)
    num_bins: integer, number of bins for vector quantization
    neighborhood_size: integer or tuple, spatial size for local calculation
    """
    # Step 1: Calculate Entropy Field
    entropy_volume = create_empty_3d_grid_like(vector_field)
    
    # Pre-compute bin boundaries or quantization centers if using Leopardi's method
    # [G] Leopardi's vector quantization partitions vectors into bins. 
    # Implementation requires a specific quantization algorithm (e.g., k-means or fixed grid).
    # For this pseudocode, we assume a helper function `get_bin_index` exists.
    
    for each voxel (x, y, z) in vector_field:
        # Extract local neighborhood vectors
        local_vectors = get_local_vectors(vector_field, (x, y, z), neighborhood_size)
        
        if len(local_vectors) == 0:
            entropy_volume[x, y, z] = 0.0
            continue
            
        # Count vectors in each bin
        bin_counts = array of size num_bins, initialized to 0
        for v in local_vectors:
            bin_idx = get_bin_index(v, num_bins) # Uses vector quantization [Leo06]
            bin_counts[bin_idx] += 1
            
        # Calculate probabilities
        total_vectors = sum(bin_counts)
        probabilities = array of size num_bins
        for i in range(num_bins):
            if total_vectors > 0:
                probabilities[i] = bin_counts[i] / total_vectors
            else:
                probabilities[i] = 0.0
                
        # Calculate Shannon Entropy
        entropy = 0.0
        for p in probabilities:
            if p > 0:
                entropy -= p * log2(p)
                
        entropy_volume[x, y, z] = entropy
        
    # Step 2 & 3: Place Seeds
    seeds = []
    total_entropy = sum(entropy_volume.flatten())
    
    # Determine total number of seeds to place (Not given in sources)
    # [G] A common approach is to define a target seed count N_seeds.
    N_seeds = 1000 # Placeholder for implementation detail not in source
    
    for each voxel (x, y, z) in vector_field:
        # Probability proportional to entropy value
        p_seed = entropy_volume[x, y, z] / total_entropy
        
        # Stochastic placement or deterministic sampling based on p_seed
        # [G] The source says "place a sufficient number... based on the probability".
        # A standard implementation uses inverse transform sampling or rejection sampling.
        if random() < p_seed * N_seeds:
            seeds.append((x, y, z))
            
    # Step 4: Trace Streamlines
    streamlines = []
    for seed in seeds:
        line = trace_runge_kutta_4(vector_field, seed)
        streamlines.append(line)
        
    return streamlines
```

**Edge Cases and Pitfalls:**
*   **Zero Vectors:** If a neighborhood contains no vectors, entropy is undefined or zero. The pseudocode handles this by setting entropy to 0.0.
*   **Bin Count Selection:** The choice of $n$ (number of bins) significantly impacts the entropy value. The sources defer to Xu et al. [XLS10] for specific suggestions.
*   **Neighborhood Size:** The spatial extent of the neighborhood affects the smoothness and locality of the entropy field. The sources defer to Xu et al. [XLS10] for specific suggestions.

## Operating characteristics
*   **Complexity:** Not given in the sources.
*   **Performance:** Not given in the sources.
*   **Strengths:** Quantitatively captures critical flow features; emphasizes important regions with high entropy (e.g., turbulent cores) [S1].
*   **Limitations:** The number of streamlines generated in the first step can be large, necessitating a subsequent clustering step [S1].

## Background
*   **Origin:** Proposed by C.-K. Chen, S. Yan, H. Yu, N. Max & K.-L. Ma in "An Illustrative Visualization Framework for 3D Vector Fields" [S1].
*   **History:** The method builds upon the concept of Shannon’s entropy in information theory [S1] and uses vector quantization techniques proposed by Leopardi [Leo06]. It relies on parameter suggestions from Xu et al. [XLS10].
*   **Usage:** Used as the first step in an illustrative visualization framework, followed by streamline clustering to simplify the large number of generated streamlines [S1].
