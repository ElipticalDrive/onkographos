# Particle Traces on 2D Surfaces
Also called: Surface particle traces, Trace lines on surfaces

## Overview
Particle traces on 2D surfaces represent the magnitude and direction of a vector field on arbitrary 2D surfaces by drawing long, evenly spaced particle trace lines composed of contrasting color segments [S1]. Unlike random seed placement which does not guarantee coverage, this method uses hierarchical seeding to ensure a nearly constant density of lines across the surface, resolving directional ambiguity in still images via sawtooth color maps [S1]. It builds on [Integral Surface](11268-integral-surface.md) by focusing specifically on arbitrary 2D surfaces rather than just contour surfaces.

## How it works
**Inputs:**
*   A set of arbitrary 2D surfaces (not necessarily contour surfaces).
*   A 3D vector field defined over the domain containing the surfaces.
*   A length threshold parameter (initially large, reduced iteratively).

**Outputs:**
*   A set of particle trace lines rendered on the surfaces.

**Data Structures:**
*   **Octree:** The surfaces are scan-converted into an octree. Only cells intersecting the surfaces are present.
    *   **Cell Layout:** Each cell stores a plane equation consisting of four numbers (e.g., $Ax + By + Cz + D = 0$) [S1].
    *   **Subdivision:** Surfaces are subdivided down to a constant size cell [S1].
*   **Seed Lattice:** An integer lattice used for seed point selection, organized spatially hierarchically [S1].
*   **Trace History:** A map or grid storing the length of erased traces in the cells they passed through to prevent recalculation during backtracking [S1].

**Algorithm Steps:**

1.  **Surface Representation:** Scan convert the input surfaces into an octree. Store the plane equation in each intersecting cell. Subdivide until a constant cell size is reached [S1].

2.  **Seed Selection:** Choose seed points on an integer lattice in a spatially hierarchical manner. Start with a large length threshold [S1].

3.  **Advection Loop:** For each seed point:
    a.  Initialize a particle at the seed point.
    b.  Advect the particle along the surface in both forward and backward directions using variable step size Euler's method [S1].
    c.  At each step, project the 3D vector field $\mathbf{V}$ onto the surface. The direction of the segment is the projected vector. The segment length is calculated as:
        $$ L = \Delta t \cdot |\mathbf{V}| $$
        where $\Delta t$ is a constant time interval and $|\mathbf{V}|$ is the magnitude of the vector field [S1].
    d.  To handle stagnation zones where velocity approaches zero, the direction vector $\mathbf{T}$ is computed as:
        $$ \mathbf{T} = \mathbf{V} + r \cdot \mathbf{V}_{norm} $$
        (Note: The source text fragment "V--V--_ and T = V + r_" suggests a correction term $r$ is added to prevent the particle from shrinking to a dot when velocity is near zero [S1]).
    e.  Check termination conditions. Stop advection if:
        *   The particle reaches a stagnation zone.
        *   The particle reaches an edge of the surface.
        *   The particle becomes too close to its own trace.
        *   The particle becomes too close to another particle's trace [S1].

4.  **Validation and Backtracking:**
    a.  If the total trace length is less than the current length threshold, erase the trace.
    b.  Preserve the length of the erased trace in the cells it passed through. This value is used during backtracking to prevent extensive recalculation [S1].
    c.  If the trace is too short, select a new seed point and repeat advection.

5.  **Threshold Reduction:** After all seed points at the current resolution are tried, reduce the length threshold and repeat the process until the minimum threshold is reached. This gradual reduction produces an aesthetically pleasing distribution [S1].

6.  **Rendering:**
    a.  Render the trace lines.
    b.  Apply a sawtooth-shaped color map across each segment to resolve directional ambiguity in still images [S1].
    c.  (Optional) Use color table animation to simulate flow, where lines "flow" in the direction of the vector field with velocity proportional to magnitude [S1].

**Pseudocode:**

```python
def particle_traces_on_2d_surfaces(surfaces, vector_field, initial_threshold, min_threshold):
    # 1. Surface Representation
    octree = build_octree(surfaces)
    # Each cell in octree contains a plane equation (4 numbers)
    # Surfaces subdivided to constant cell size

    # 2. Seed Selection Setup
    seed_lattice = create_hierarchical_integer_lattice(octree.bounds)
    current_threshold = initial_threshold

    while current_threshold >= min_threshold:
        # Try all seeds at current resolution with current threshold
        for seed_point in seed_lattice.get_seeds_at_resolution():
            trace = advect_particle(seed_point, octree, vector_field, current_threshold)
            
            if trace is not None:
                render_trace(trace)
            else:
                # Trace was too short or invalid
                # Preserve length in cells to prevent recalculation
                record_erased_trace_length(trace_cells, trace_length)
        
        # Reduce threshold for next iteration
        current_threshold = reduce_threshold(current_threshold)

def advect_particle(seed, octree, vector_field, threshold):
    particle = Particle(seed)
    trace_segments = []
    total_length = 0
    
    # Advect in both directions
    for direction in [FORWARD, BACKWARD]:
        while not is_terminated(particle, octree, trace_segments):
            # Get vector at current position
            v = vector_field.evaluate(particle.position)
            
            # Handle stagnation: T = V + r * correction
            # Note: Exact formula for 'r' correction not fully specified in source, 
            # but intended to prevent shrinking to dot when V->0 [S1]
            if magnitude(v) < epsilon:
                t = v + small_radius_vector 
            else:
                t = v
            
            # Project t onto surface normal at particle.position
            normal = get_surface_normal(particle.position, octree)
            t_projected = project_onto_surface(t, normal)
            
            # Calculate segment length based on magnitude
            segment_length = constant_time_interval * magnitude(t_projected)
            
            # Move particle
            new_position = particle.position + normalize(t_projected) * segment_length
            
            # Add segment to trace
            trace_segments.append(Segment(particle.position, new_position, t_projected))
            total_length += segment_length
            particle.position = new_position
            
            # Check for self-intersection or proximity to other traces
            if is_too_close_to_trace(particle.position, trace_segments):
                break

    # Validation
    if total_length < threshold:
        return None # Erase trace
    else:
        return trace_segments

def is_terminated(particle, octree, trace_segments):
    # Check stagnation
    if magnitude(vector_field.evaluate(particle.position)) < epsilon:
        return True
    # Check surface edge
    if is_on_surface_edge(particle.position, octree):
        return True
    # Check proximity to own trace
    if is_too_close_to_trace(particle.position, trace_segments):
        return True
    # Check proximity to other particles' traces (requires global trace list)
    if is_too_close_to_other_traces(particle.position):
        return True
    return False
```

**Parameters:**
*   **Length Threshold:** A minimum acceptable length for a particle trace. Initially set to a large value, then gradually reduced to a minimum [S1].
*   **Constant Time Interval:** Used to determine segment length based on vector magnitude [S1].

**Pitfalls:**
*   **Directional Ambiguity:** In still images, the direction of flow is ambiguous. This is resolved by using a sawtooth-shaped color map across each segment [S1].
*   **Stagnation Zones:** When velocity approaches zero, particles may shrink to a dot. A correction term is added to the direction vector to mitigate this [S1].
*   **Recalculation:** Erased traces must store their length in cells to avoid expensive backtracking recalculation [S1].

## Operating characteristics
*   **Time Complexity:** The hierarchical seeding and threshold reduction strategy ensures that long traces are found first. Gradually reducing the threshold takes longer than using a single threshold value but produces a more aesthetically pleasing distribution [S1].
*   **Memory Complexity:** The octree representation is much more memory efficient than a full 3D grid, storing only cells intersecting the surfaces [S1].
*   **Strengths:** Guarantees that some seed point is near every point on the surfaces, unlike random placement. Allows visualization on arbitrary 2D surfaces, not just contour surfaces. Supports color table animation for flow visualization [S1].
*   **Limitations:** Viewpoint-dependent projection techniques (like eye projection) require recalculation of particle traces when the viewpoint changes. Viewpoint-independent techniques (normal, xy normal, cylinder projections) do not [S1].

## Background
This technique was introduced to visualize 3D velocity fields near contour surfaces and arbitrary 2D surfaces [S1]. It builds on the concept of streamlines but adapts them for surface visualization with specific seeding and rendering strategies to maintain line density and clarity. Color table animation, used to add motion, is an older technique applied to flow visualization by Van Gelder and Wilhelms [S1].
