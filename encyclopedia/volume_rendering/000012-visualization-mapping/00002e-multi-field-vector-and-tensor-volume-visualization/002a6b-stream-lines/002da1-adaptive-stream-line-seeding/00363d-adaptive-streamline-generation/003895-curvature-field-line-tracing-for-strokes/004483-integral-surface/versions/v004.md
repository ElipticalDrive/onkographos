# Integral Surface

Also called: Path Surface, Rake, Stream Surface

## Overview
An integral surface (also known as a path surface or rake) is a geometric structure generated by integrating a vector field along a one-dimensional seeding curve. In time-varying flow fields, it represents a path surface; in steady flow, it represents a stream surface. It is distinct from single streamlines by sweeping a curve through the field, creating a 2D manifold that visualizes the collective transport of particles originating from a continuous source line.

## How it works
**Inputs:**
- A velocity field $v(x, t)$ defined over space and time. For steady flow, $v(x)$ is time-independent.
- A univariate seeding curve (rake) $c(s)$, where $s \in I \subseteq \mathbb{R}$ maps to $\mathbb{R}^n$ (typically $\mathbb{R}^3$).

**Outputs:**
- A parametric surface $S(s, t)$ defined by parameters $s$ (along the rake) and $t$ (time or integration parameter).

**Data Structures:**
- The surface is represented as a parametric function $S: I \times [t_0, t_{end}] \to \mathbb{R}^n$.
- No explicit mesh is required for the definition; rendering requires discretizing $s$ and $t$ into a grid.

**Steps:**
1. Define the seeding curve $c(s)$ for $s \in I$.
2. For each point $s$ on the curve, integrate the velocity field forward in time from a start time $t_0$ to a target time $t$.
3. The position $S(s, t)$ is calculated using the following integral equation [S1, unofficial]:

$$
S(s, t) = c(s) + \int_{t_0}^{t} v(\tau, S(s, \tau)) \, d\tau
$$

**Definitions:**
- $S(s, t)$: The position on the integral surface at rake parameter $s$ and time $t$.
- $c(s)$: The initial position of the particle at time $t_0$, determined by the seeding curve.
- $v(\tau, x)$: The velocity vector at time $\tau$ and position $x$.
- $t_0$: The initial time of integration.
- $\tau$: The dummy variable of integration representing time.

**Parameters:**
- $t_0$: Start time. Typically $0$ or the current simulation time.
- $t$: End time. Determines the length of the surface in the time dimension.
- $s$: Parameter along the seeding curve. Range depends on the specific rake geometry.

**Edge Cases and Pitfalls:**
- **Self-intersection:** Lines on an integral surface for fixed $t$ are timelines. In complex flows, these lines may self-intersect or become non-tangential to the flow field [S1, unofficial].
- **Generalization:** If the seeding geometry is higher-dimensional (e.g., a surface instead of a curve), the result generalizes to a path volume or time surface [S1, unofficial].
- **Time-varying vs. Steady:** In steady flow, the integral surface is a stream surface. In time-varying flow, it is a path surface. If $c$ varies over time, the definition characterizes a generalized path surface [S1, unofficial].

**Pseudocode:**
```python
def compute_integral_surface(c, v, t0, t_end, num_s, num_t):
    """
    Computes an integral surface by integrating a velocity field along a seeding curve.
    
    Args:
        c: A function c(s) returning the 3D position for a scalar s.
        v: A function v(t, x) returning the 3D velocity at time t and position x.
        t0: Start time.
        t_end: End time.
        num_s: Number of samples along the seeding curve.
        num_t: Number of time steps for integration.
        
    Returns:
        A 2D array of shape (num_s, num_t) containing the surface points.
    """
    # Discretize the seeding curve parameter s
    s_values = linspace(min_s, max_s, num_s) # Bounds of I not given in sources [G]
    
    # Discretize time
    dt = (t_end - t0) / num_t
    t_values = linspace(t0, t_end, num_t)
    
    surface = zeros((num_s, num_t, 3))
    
    for i, s in enumerate(s_values):
        # Initial position from the seeding curve
        current_pos = c(s)
        current_time = t0
        
        surface[i, 0] = current_pos
        
        for j in range(1, num_t):
            # Integrate velocity field using a numerical integrator (e.g., Euler or RK4)
            # Note: The exact integrator is not specified in the source [G]
            # Standard Euler step:
            velocity = v(current_time, current_pos)
            current_pos = current_pos + velocity * dt
            current_time = current_time + dt
            
            surface[i, j] = current_pos
            
    return surface
```

## Subtopics

### [Magnetosphere Field Line Tracing](12012-magnetosphere-field-line-tracing.md)
This method traces a single magnetospheric magnetic field line starting from an ionospheric footpoint using a fixed-step Euler integration along the normalized magnetic field vector. It solves the problem of visualizing the topology of the Earth's magnetic field within the magnetosphere by connecting ionospheric regions to the magnetopause boundary. It is distinct from general stream line tracing by its specific reliance on an analytical dipole field model and its geometric termination conditions (ionosphere and magnetopause surfaces) rather than a uniform domain. It builds on [Integral Surface](11268-integral-surface.md) by providing the specific vector field evaluation and boundary logic for magnetospheric contexts.

### [Particle Traces on 2D Surfaces](12772-particle-traces-on-2d-surfaces.md)
Particle traces on 2D surfaces is a visualization technique that represents the magnitude and direction of a 3D vector field on arbitrary 2D surfaces (not necessarily contour surfaces) by drawing long, evenly spaced particle trace lines. Unlike random seed placement which does not guarantee coverage near every point, this method uses a hierarchical integer lattice to ensure some seed point is near every point on the surface, avoiding density issues where the visualization becomes too dense or too sparse. It sets itself apart from its parent [Integral Surface](11268-integral-surface.md) by explicitly breaking traces into segments of contrasting color to resolve directional ambiguity in still images and by projecting the vector field onto the surface geometry rather than integrating within the volume.

## Background
The concept of integral surfaces, also referred to as rakes or path surfaces, is defined in the context of multi-field visualization. It generalizes the concept of integral lines to higher dimensions by using a univariate seeding curve. The definition distinguishes between path surfaces in time-varying fields and stream surfaces in steady flow. The term "rake" is used synonymously with the seeding curve concept in this definition [S1, unofficial].
