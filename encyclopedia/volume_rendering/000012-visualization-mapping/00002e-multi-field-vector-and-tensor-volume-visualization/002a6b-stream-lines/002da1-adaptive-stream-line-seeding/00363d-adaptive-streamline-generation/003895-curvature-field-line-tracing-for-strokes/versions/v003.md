# Curvature Field Line Tracing for Strokes

Also called: Stroke generation via RK4(3)

## Overview
This method generates hatching strokes for volume illustration by tracing paths from seed points along the maximal curvature directions of a scalar field in object space [S1, unofficial]. It distinguishes itself from standard streamline tracing by using curvature gradients rather than velocity vectors, and employs an RK4(3) integrator with adaptive step sizing to maintain stroke alignment with the original hatch direction, ensuring strokes remain front-facing and visually coherent [S1, unofficial].

## How it works
**Inputs:**
- Scalar field $V(\mathbf{x})$ defined on a 3D grid.
- A set of seed points $\mathbf{s}_i$ located on or near a target iso-surface.
- A deviation threshold $\theta_{max}$ (constant angle) [S1, unofficial].

**Outputs:**
- A set of strokes, where each stroke is a line strip (sequence of points).
- Each point in a stroke stores: vertex coordinates $\mathbf{p}$, gray-scale gradient $\nabla V$, and texture coordinate $t$ [S1, unofficial].

**Data Structures:**
- **Point:** A struct containing:
  - `vec3 pos`: 3D vertex coordinates.
  - `vec3 grad`: Interpolated gray-scale gradient vector.
  - `float t`: Texture coordinate, defined as the distance from the current point to the seed point divided by the total stroke length [S1, unofficial].

**Algorithm Steps:**
1. **Initialize:** For each seed point $\mathbf{s}$, set current position $\mathbf{p}_0 = \mathbf{s}$ and initial direction $\mathbf{d}_0$ as the maximal curvature direction at $\mathbf{s}$. The maximal curvature direction is derived from the Hessian matrix of the scalar field, specifically the eigenvector corresponding to the largest eigenvalue magnitude [S1, unofficial].
2. **Integrate:** Use RK4(3) with adaptive step size to trace the path.
   - At each step, compute the curvature field direction $\mathbf{d}(\mathbf{p})$.
   - Update position $\mathbf{p}_{new}$ using the Runge-Kutta method.
   - Check termination condition: if the angle between the current direction $\mathbf{d}_{new}$ and the initial direction $\mathbf{d}_0$ exceeds $\theta_{max}$, terminate the stroke [S1, unofficial].
   - The adaptive step size control reduces the number of intermediate points by adjusting the step length based on local field variation, ensuring high accuracy despite tri-linear interpolation of the curvature field [S1, unofficial].
3. **Store Points:** For each valid point $\mathbf{p}_k$ along the path:
   - Interpolate the gray-scale gradient $\nabla V(\mathbf{p}_k)$ from the scalar field.
   - Compute the texture coordinate $t_k = \frac{\|\mathbf{p}_k - \mathbf{s}\|}{\|\mathbf{p}_{last} - \mathbf{s}\|}$, where $\mathbf{p}_{last}$ is the final point of the stroke [S1, unofficial].
   - Append $(\mathbf{p}_k, \nabla V(\mathbf{p}_k), t_k)$ to the stroke's point list.
4. **Back-face Culling:** Compute a cone of normals from the stored gradients for each stroke. Use this cone to cull back-facing strokes during rendering, ensuring only front-facing hatching is displayed [S1, unofficial].

**Pseudocode:**
```python
def generate_stroke(seed_point, scalar_field, max_deviation_angle):
    """
    Generates a single hatching stroke from a seed point.
    
    Args:
        seed_point (vec3): Starting position of the stroke.
        scalar_field (ScalarField): The input scalar volume.
        max_deviation_angle (float): Maximum allowed angle deviation from initial direction.
        
    Returns:
        list of dict: List of points, each with 'pos', 'grad', and 't'.
    """
    # 1. Initialize
    current_pos = seed_point
    initial_direction = get_maximal_curvature_direction(scalar_field, current_pos)
    stroke_points = []
    total_length = 0.0
    
    # Store initial direction for deviation check
    initial_dir_normalized = normalize(initial_direction)
    
    # 2. Integrate using RK4(3) with adaptive step size
    step_size = compute_initial_step_size(scalar_field, current_pos)
    
    while True:
        # Get current curvature direction
        current_direction = get_maximal_curvature_direction(scalar_field, current_pos)
        current_dir_normalized = normalize(current_direction)
        
        # Check termination condition: deviation from initial direction
        angle_deviation = acos(dot(initial_dir_normalized, current_dir_normalized))
        if angle_deviation > max_deviation_angle:
            break
            
        # RK4(3) integration step
        next_pos = rk43_integrate_step(scalar_field, current_pos, current_direction, step_size)
        
        # Adaptive step size control: adjust step_size based on local field variation
        # [G] Implementation detail: step_size is typically reduced if the change in direction
        # or magnitude of the curvature field is high.
        step_size = adapt_step_size(scalar_field, current_pos, next_pos)
        
        # Interpolate gradient at the new position
        gradient = interpolate_gradient(scalar_field, next_pos)
        
        # Compute texture coordinate (distance to seed relative to total length)
        # [G] Total length is not known until the stroke ends. We store partial length
        # and normalize later, or store cumulative distance.
        dist_to_seed = distance(next_pos, seed_point)
        
        stroke_points.append({
            'pos': next_pos,
            'grad': gradient,
            't': dist_to_seed # Will be normalized after stroke completion
        })
        
        current_pos = next_pos
        total_length = dist_to_seed
        
    # Normalize texture coordinates
    if total_length > 0:
        for point in stroke_points:
            point['t'] = point['t'] / total_length
            
    return stroke_points

def get_maximal_curvature_direction(scalar_field, point):
    """
    Computes the maximal curvature direction at a point.
    This is the eigenvector corresponding to the largest eigenvalue of the Hessian matrix.
    """
    hessian = compute_hessian(scalar_field, point)
    eigenvalues, eigenvectors = compute_eigenvalues_eigenvectors(hessian)
    # Return eigenvector for the largest absolute eigenvalue
    max_idx = argmax(abs(eigenvalues))
    return eigenvectors[:, max_idx]

def rk43_integrate_step(scalar_field, pos, direction, step_size):
    """
    Performs one step of RK4(3) integration.
    The vector field for integration is the maximal curvature direction field.
    """
    # [G] Standard RK4(3) implementation for ODE: dx/dt = F(x)
    # F(x) is the normalized maximal curvature direction at x.
    k1 = normalize(get_maximal_curvature_direction(scalar_field, pos))
    k2 = normalize(get_maximal_curvature_direction(scalar_field, pos + 0.5 * step_size * k1))
    k3 = normalize(get_maximal_curvature_direction(scalar_field, pos + 0.5 * step_size * k2))
    k4 = normalize(get_maximal_curvature_direction(scalar_field, pos + step_size * k3))
    
    next_pos = pos + (step_size / 6.0) * (k1 + 2*k2 + 2*k3 + k4)
    return next_pos

def interpolate_gradient(scalar_field, point):
    """
    Interpolates the gray-scale gradient from the scalar field using tri-linear interpolation.
    """
    # [G] Gradient is computed as the finite difference or analytical derivative of the
    # tri-linearly interpolated scalar field.
    return compute_gradient_via_finite_differences(scalar_field, point)

def adapt_step_size(scalar_field, current_pos, next_pos):
    """
    Adjusts the step size based on local field variation.
    """
    # [G] A simple heuristic: if the direction changes significantly between current and next,
    # reduce step size.
    dir_current = normalize(get_maximal_curvature_direction(scalar_field, current_pos))
    dir_next = normalize(get_maximal_curvature_direction(scalar_field, next_pos))
    angle_change = acos(dot(dir_current, dir_next))
    
    if angle_change > threshold:
        return step_size * 0.5
    else:
        return step_size * 1.5
```

**Edge Cases and Pitfalls:**
- **High Curvature Variation:** If the curvature field varies rapidly, the adaptive step size must be small enough to prevent the stroke from deviating beyond $\theta_{max}$ before the check occurs [S1, unofficial].
- **Boundary Conditions:** Seeds must be positioned such that the maximal curvature direction is well-defined. Near singularities or flat regions, the curvature direction may be unstable [S1, unofficial].
- **Back-facing Strokes:** Without the cone of normals culling, strokes may render behind the surface, breaking the hatching illusion [S1, unofficial].

## Subtopics

### [Integral Surface](11268-integral-surface.md)
An integral surface (also known as a path surface or rake) generalizes the concept of a stream line to a continuous curve of seed points, generating a 2D manifold in 3D space. In steady flows, it represents a stream surface; in time-varying flows, it represents a path surface. It is distinct from single stream lines by integrating along a univariate seeding curve (rake) rather than a single point, and from streak surfaces by tracking particles released at different times from the rake rather than continuously from a fixed point.

## Operating characteristics
- **Time Complexity:** Depends on the number of seeds and the length of each stroke. Adaptive step size reduces the number of integration steps in smooth regions but increases them in high-variation areas [S1, unofficial].
- **Memory Complexity:** Linear with respect to the number of points in all strokes. Each point stores position, gradient, and texture coordinate [S1, unofficial].
- **Performance:** The use of RK4(3) with adaptive step size allows for high accuracy with fewer points compared to fixed-step methods, reducing rendering load [S1, unofficial].
- **Strengths:** Produces visually coherent hatching strokes that follow the object's curvature, enhancing the perception of shape. Back-face culling improves visual quality [S1, unofficial].
- **Limitations:** Requires accurate computation of the Hessian matrix for curvature directions, which can be noisy. The deviation threshold $\theta_{max}$ is a user-defined parameter with no standard value [S1, unofficial].

## Background
This method was introduced in the context of interactive volume illustration, specifically for generating hatching strokes that enhance the perception of 3D structure in scalar fields [S1, unofficial]. It builds on the idea of using geometric properties (curvature) rather than flow properties (velocity) for visualization.
