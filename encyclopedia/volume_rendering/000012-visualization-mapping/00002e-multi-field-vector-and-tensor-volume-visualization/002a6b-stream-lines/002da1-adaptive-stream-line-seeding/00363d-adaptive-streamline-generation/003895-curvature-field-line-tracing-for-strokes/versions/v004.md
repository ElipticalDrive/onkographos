# Curvature Field Line Tracing for Strokes
Also called: Stroke generation via RK4(3)

## Overview
This method generates hatching strokes by tracing paths from seed points along maximal curvature directions in object space [S1, unofficial]. It solves the problem of creating visually coherent, front-facing hatching patterns for volume illustration by ensuring strokes remain aligned with surface geometry and lighting conditions [S1, unofficial]. It is distinct from standard streamline tracing by integrating along curvature fields rather than velocity fields, and by using a deviation-based termination criterion to prevent strokes from entering regions of high field variation [S1, unofficial].

## How it works
**Inputs:**
*   Scalar field $V(\mathbf{x})$ defining the volume.
*   Iso-value $I$ for the target surface.
*   Set of seed points $\mathbf{s}_i$ on the iso-surface.
*   Hatch direction $\mathbf{h}$ (constant reference vector for deviation check).
*   Deviation threshold $\theta_{max}$ (constant angle).

**Outputs:**
*   Set of strokes, where each stroke is a line strip (sequence of points).

**Data Structures:**
Each point $\mathbf{p}$ in a stroke stores:
1.  Vertex coordinates $\mathbf{x} \in \mathbb{R}^3$.
2.  Gray-scale gradient $\nabla V(\mathbf{x})$ (interpolated from scalar field).
3.  Texture coordinate $t = \frac{\|\mathbf{x} - \mathbf{s}\|}{L}$, where $\mathbf{s}$ is the stroke's seed point and $L$ is the total stroke length [S1, unofficial].

**Algorithm Steps:**
1.  **Preprocessing:** For each seed point, determine the initial maximal curvature direction in object space. Position the start point at a scalar value slightly smaller than the iso-value to ensure the stroke begins on the correct side of the surface [S1, unofficial].
2.  **Integration:** Use RK4(3) integration with adaptive step size control to trace the path along the curvature field [S1, unofficial].
    *   Let $\mathbf{x}_k$ be the current position.
    *   Compute the curvature field vector $\mathbf{C}(\mathbf{x}_k)$ at the current point.
    *   Perform RK4(3) step to compute $\mathbf{x}_{k+1}$ [S1, unofficial].
    *   The adaptive step size reduces the number of intermediate points by adjusting the step length based on local field variation [S1, unofficial].
3.  **Termination Check:** At each step, calculate the angle $\theta$ between the current hatch direction (tangent to the stroke) and the original hatch direction $\mathbf{h}$. If $\theta > \theta_{max}$, terminate the stroke [S1, unofficial]. This prevents stepping into regions where the curvature field shows high variations [S1, unofficial].
4.  **Lighting and Culling:**
    *   Interpolate the gray-scale gradient $\nabla V$ at each point $\mathbf{x}$ for lighting simulation [S1, unofficial].
    *   Compute a cone of normals from the set of all gradients to cull back-facing strokes [S1, unofficial].
    *   Assume sufficiently accurate curvature directions ensure each stroke is placed entirely in front of any selected surface [S1, unofficial].
5.  **Storage:** Store the sequence of points as a line strip. Compute and store texture coordinates for each point based on the distance to the seed relative to the total stroke length [S1, unofficial].

    stroke_points = []

    original_direction = compute_initial_curvature_direction(current_pos, scalar_field)

    step_size = initial_step_size # [G] Not given in sources, assume small positive value
    
    while True:
        # 1. Interpolate gradient for lighting
        grad = scalar_field.gradient(current_pos)

        # Note: total_length is not known until stroke ends, so store raw distance

            'x': current_pos,
            'grad': grad,
            'raw_dist': dist_to_seed
        })

        angle = angle_between(current_direction, hatch_direction)
        
        if angle > deviation_threshold:
            break
            
        # 4. Adaptive RK4(3) Integration
        # [G] Standard RK4(3) implementation for ODE dx/dt = C(x)
        # C(x) is the maximal curvature direction field
        curvature_field = get_curvature_field(scalar_field)
        next_pos = rk43_step(current_pos, curvature_field, step_size)
        
        # Update step size adaptively based on local variation

        step_size = adapt_step_size(current_pos, next_pos, scalar_field)
        
        current_pos = next_pos
        total_length += vector_length(next_pos - current_pos) # Approximation for loop
        
    # Post-processing: Normalize texture coordinates
    final_length = vector_length(stroke_points[-1]['x'] - seed_point)
    for point in stroke_points:
        point['t'] = point['raw_dist'] / final_length if final_length > 0 else 0.0
        
    return stroke_points

**Parameters:**
*   **Deviation threshold ($\theta_{max}$):** Constant angle deviation from the original hatch direction that terminates the stroke. No specific value given in the sources [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **High Variation Regions:** The deviation check prevents stepping into regions where the curvature field shows high variations, which could otherwise cause erratic stroke behavior [S1, unofficial].
*   **Back-facing Strokes:** The cone of normals derived from gradients is used to cull back-facing strokes, ensuring visual consistency [S1, unofficial].
*   **Precision:** Although tri-linear interpolation is used for the curvature field, RK4(3) ensures high accuracy in field line computation [S1, unofficial].

## Subtopics

### [Integral Surface](11268-integral-surface.md)
An integral surface generalizes the concept of a stream line or path line to a two-dimensional manifold in space-time, generated by sweeping a seeding curve through a vector field. It solves the problem of visualizing coherent structures in time-varying flows (as a path surface) or steady flows (as a stream surface) by connecting a continuous set of seed points rather than discrete locations. It is distinct from single-line tracing by maintaining topological connectivity across the seeding curve, and from streak surfaces by integrating from the initial time $t_0$ rather than tracking particles emitted continuously up to time $t$.
