# Multi-Channel Similarity Volume Visualization

Also called: Multi-Channel Color Mapping, Multi-Channel Similarity Visualization, Multi-channel volume visualization of genomic alignments, RGB channel mapping for similarity plots, RGB similarity plot mapping, Volume-based multiple alignment visualization

## Overview
Multi-Channel Similarity Volume Visualization maps multiple 1D similarity plots of genomic alignments to the Red, Green, and Blue color channels of a 3D volume, allowing the simultaneous visual comparison of conservation patterns across different species groups [S1, S2, unofficial]. It solves the problem of manually aligning and comparing multiple 1D plots by eye, where peaks must be visually correlated across separate displays [S1, unofficial]. Unlike [Frequency Distribution-based Transfer Function](814-frequency-distribution-based-transfer-function.md) which maps scalar density to color, this method maps distinct semantic similarity metrics to distinct color channels, enabling users to identify specific conservation patterns (e.g., primate-specific vs. universal) through color mixing [S1, S2, unofficial].

## How it works
**Inputs:**
*   A set of $N$ multiple sequence alignments (typically $N=3$ for RGB mapping) generated by tools like MLAGAN [S2, unofficial].
*   For each alignment, a 1D similarity score array $S_i$ of length $L$ (sequence length in basepairs), where scores are percentages (0–100%) [S1, S2, unofficial].
*   Annotation data for structural elements (exons, genes) [S2, unofficial].

**Outputs:**
*   A rendered 3D volume image where color indicates conservation status across the specified species groups [S1, S2, unofficial].
*   Overlay graphics for structural annotations (pipes/bars) [S2, unofficial].

**Data Structures:**
*   **Volume Grid:** A 3D array of dimensions $D_x \times D_y \times D_z$. Dimensions must be powers of two (e.g., $64^3$, $256^3$) [S2, unofficial].
*   **Voxel Data:** Each voxel stores three floating-point or normalized integer values $(R, G, B)$ representing the smoothed similarity scores for the three channels [S1, S2, unofficial].
*   **Hilbert Mapping:** A 1D-to-3D space-filling curve mapping used to distribute the linear sequence data into the 3D volume [S1, S2, unofficial].

**Parameters:**
*   **Box Filter Width ($W$):** Smoothing kernel size for similarity scores. Typical value: 50 [S1, S2, unofficial].
*   **Thresholds ($T_R, T_G, T_B$):** Minimum similarity score for a channel to be visible.
    *   Uniform mode: $T_R = T_G = T_B = 25\%$ [S1, S2, unofficial].
    *   Group comparison mode: $T_R = 50\%$, $T_G = 75\%$, $T_B = 75\%$ [S2, unofficial].
*   **Transfer Function:** Linear mapping from similarity score to color intensity [S1, unofficial].

**Steps:**

1.  **Assign Similarity Plots to Channels:**
    Select three similarity plots corresponding to different species groupings. Common assignments [S1, S2, unofficial]:
    *   **Red Channel:** Similarity among all species (e.g., all 5 or all 12 species).
    *   **Green Channel:** Similarity among a specific subgroup (e.g., primates: human/chimp, or human/mouse/chicken).
    *   **Blue Channel:** Similarity among another subgroup (e.g., rodents: mouse/rat, or fish species).

2.  **Smooth Data:**
    Apply a box filter (moving average) with width $W$ to each 1D similarity score array $S_i$ to reduce noise.
    $$ S'_i[j] = \frac{1}{W} \sum_{k=j-\lfloor W/2 \rfloor}^{j+\lfloor W/2 \rfloor} S_i[k] $$
    [S1, S2, unofficial]

3.  **Map 1D Sequence to 3D Volume:**
    Use a Hilbert curve to map the 1D sequence index $j$ (from $0$ to $L-1$) to 3D coordinates $(x, y, z)$ in the volume grid.
    *   The volume dimensions $D_x, D_y, D_z$ are powers of two.
    *   If $L < D_x \times D_y \times D_z$, the remaining voxels are empty/transparent [S2, unofficial].
    *   For each basepair $j$, determine voxel $(x,y,z)$ via Hilbert mapping.
    *   Set the voxel color $(R, G, B)$ based on the smoothed scores $S'_R[j], S'_G[j], S'_B[j]$ and their respective thresholds [S1, S2, unofficial].

4.  **Apply Transfer Function and Thresholding:**
    For each voxel, evaluate the smoothed scores against thresholds $T_R, T_G, T_B$.
    *   If $S'_R[j] \ge T_R$, set $R = \frac{S'_R[j] - T_R}{100 - T_R}$ (normalized to [0,1]), else $R=0$.
    *   If $S'_G[j] \ge T_G$, set $G = \frac{S'_G[j] - T_G}{100 - T_G}$, else $G=0$.
    *   If $S'_B[j] \ge T_B$, set $B = \frac{S'_B[j] - T_B}{100 - T_B}$, else $B=0$.
    *   [G] Values are clamped to [0, 1]. [S1, unofficial]

5.  **Render Volume:**
    Render the 3D volume using view-perpendicular slices with back-to-front ordering to support transparency [S1, unofficial].
    *   **Occlusion Handling:** Use Maximal Intensity Projection (MIP) to ensure high-similarity regions (bright colors) are visible even if occluded by foreground data [S1, S2, unofficial].

6.  **Overlay Annotations:**
    Render structural elements (exons, genes) as colored pipes or bars overlaid on the volume.
    *   Example: Purple pipes for human exons, orange for mouse exons, white for genes [S2, unofficial].

7.  **Navigation:**
    Use a 1D bar representation with a vertical line marker that moves along the Hilbert curve to navigate and zoom into specific regions of the volume [S1, S2, unofficial].

**Pseudocode:**

```python
def multi_channel_similarity_volume(similarity_plots, thresholds, filter_width, volume_dims):
    """
    similarity_plots: List of 3 arrays [S_R, S_G, S_B], each of length L.
    thresholds: Tuple (T_R, T_G, T_B).
    filter_width: Integer W.
    volume_dims: Tuple (Dx, Dy, Dz), powers of two.
    """
    # 1. Smooth the similarity scores
    smoothed_R = box_filter(similarity_plots[0], filter_width)
    smoothed_G = box_filter(similarity_plots[1], filter_width)
    smoothed_B = box_filter(similarity_plots[2], filter_width)
    
    L = len(smoothed_R)
    
    # 2. Initialize volume
    # Voxel structure: (R, G, B) floats in [0, 1]
    volume = create_volume(volume_dims)
    
    # 3. Map 1D data to 3D volume using Hilbert Curve
    # Note: Hilbert curve implementation is assumed available or implemented
    hilbert_map = generate_hilbert_mapping(volume_dims)
    
    for j in range(L):
        # Get 3D coordinates for sequence index j
        x, y, z = hilbert_map[j]
        
        # 4. Apply Transfer Function and Thresholds
        r_val = 0.0
        if smoothed_R[j] >= thresholds[0]:
            r_val = (smoothed_R[j] - thresholds[0]) / (100.0 - thresholds[0])
            
        g_val = 0.0
        if smoothed_G[j] >= thresholds[1]:
            g_val = (smoothed_G[j] - thresholds[1]) / (100.0 - thresholds[1])
            
        b_val = 0.0
        if smoothed_B[j] >= thresholds[2]:
            b_val = (smoothed_B[j] - thresholds[2]) / (100.0 - thresholds[2])
            
        # 5. Store in volume
        volume[x][y][z] = (r_val, g_val, b_val)
        
    return volume

def box_filter(data, width):
    """Simple moving average box filter."""
    n = len(data)
    smoothed = [0.0] * n
    half_w = width // 2
    for i in range(n):
        start = max(0, i - half_w)
        end = min(n, i + half_w + 1)
        smoothed[i] = sum(data[start:end]) / (end - start)
    return smoothed
```

**Color Interpretation:**
*   **White (R+G+B):** Regions conserved among all species/groups [S1, S2, unofficial].
*   **Blue:** Features specific to the group mapped to Blue (e.g., primates) and absent in the group mapped to Green (e.g., rodents) [S1, unofficial].
*   **Green:** Features specific to the group mapped to Green (e.g., rodents) and absent in the group mapped to Blue (e.g., primates) [S1, unofficial].
*   **Cyan:** Features specific to both the Blue and Green groups [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(L)$ for smoothing and mapping, where $L$ is the sequence length. Rendering is $O(D_x D_y D_z)$ per frame for slice-based rendering [S1, unofficial].
*   **Memory Complexity:** $O(D_x D_y D_z)$ for the volume grid. Since dimensions are powers of two, memory usage may exceed the data size if $L$ is small relative to the volume capacity [S2, unofficial].
*   **Performance:** On an NVIDIA 5900 FX GPU, rendering a $64^3$ volume ($\sim 260,000$ basepairs) at $800 \times 800$ resolution achieves 15 frames/sec [S1, unofficial].
*   **Strengths:**
    *   Allows simultaneous comparison of multiple conservation patterns without eye-strain from switching between 1D plots [S1, unofficial].
    *   High-similarity regions (white spots) are visually striking and easy to identify [S1, S2, unofficial].
    *   Handles large datasets (e.g., 16 million basepairs) better than some 1D tools [S1, unofficial].
*   **Limitations:**
    *   **Occlusion:** High-similarity regions inside the volume can be hidden; requires Maximal Intensity Projection (MIP) to mitigate [S1, S2, unofficial].
    *   **Resolution Constraints:** Volume dimensions must be powers of two, leading to unused space if sequence length is not a power of two [S2, unofficial].
    *   **Ambiguity:** Color mixing can be complex for users unfamiliar with additive color theory (e.g., distinguishing cyan from white) [S1, unofficial].
*   **When to use:** When comparing conservation patterns across 3 distinct species groups in genomic alignments.
*   **When not to use:** When more than 3 groups need comparison, or when precise quantitative values are required rather than visual patterns.

## Background
*   **Origin:** Developed by Nameeta Shah, Scott E. Dillard, Gunther H. Weber, and Bernd Hamann [S1, S2, unofficial].
*   **History:** The method was applied to genomic alignment datasets created with MLAGAN to discover regulatory elements and conserved noncoding sequences [S2, unofficial]. It was compared against 1D Phylo-VISTA similarity plots [S1, S2, unofficial].
*   **Datasets:**
    *   **SCL Dataset:** 150,000 basepairs, 5 species (human, mouse, chicken, pufferfish, zebrafish), rendered in $64^3$ volume [S2, unofficial].
    *   **CFTR Dataset:** 16 million basepairs, 12 species, rendered in $256^3$ volume (sequence fills 25% of volume) [S2, unofficial].
