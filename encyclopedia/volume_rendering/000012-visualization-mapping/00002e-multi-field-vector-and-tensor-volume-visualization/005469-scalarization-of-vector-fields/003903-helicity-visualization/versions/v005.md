# Helicity Visualization

Also called: Helicity Calculation

## Overview
Helicity Visualization maps the scalar helicity field to color and opacity to identify vortices and their rotation direction in fluid flows [S1, unofficial][S2]. It sets itself apart from siblings like [Metric Scalar Field Rendering from Vector Fields](14065-metric-scalar-field-rendering-from-vector-fields.md) by explicitly utilizing the directional relationship between velocity and vorticity via a dot product, allowing distinction of vortex chirality through signed color mapping [S1, unofficial].

## How it works
**Inputs:**
- Velocity field $\mathbf{F}(\mathbf{x}) = (u, v, w)$ defined on a grid [S1, unofficial][S2].
- Vorticity field $\boldsymbol{\omega}(\mathbf{x}) = \nabla \times \mathbf{F}$ [S2].

**Outputs:**
- Color $C(\mathbf{x})$ and Opacity $\alpha(\mathbf{x})$ for each sample point [S1, unofficial].

**Data Structures:**
- The helicity scalar field $h(\mathbf{x})$ is computed per voxel [S1, unofficial][S2].
- Transfer function $T(h)$ maps scalar value to $(R, G, B, \alpha)$ [S1, unofficial].

**Steps:**
1. **Compute Vorticity:** Calculate the curl of the velocity field at each grid point $\mathbf{x}$:
   $$ \boldsymbol{\omega}(\mathbf{x}) = \nabla \times \mathbf{F}(\mathbf{x}) $$
   [S2]
2. **Compute Helicity:** Calculate the dot product of the velocity and vorticity vectors:
   $$ h(\mathbf{x}) = \boldsymbol{\omega}(\mathbf{x}) \cdot \mathbf{F}(\mathbf{x}) $$
   [S1, unofficial][S2]
   This scalar represents the curl in the direction of the velocity [S2].
3. **Map Opacity:** Map the magnitude of helicity $|h(\mathbf{x})|$ to opacity $\alpha$: large magnitude maps to high opacity (opaque), and small magnitude maps to near transparency [S1, unofficial].
4. **Map Color:** Map the signed value of helicity $h(\mathbf{x})$ to color: extreme negative values map to cyan, extreme positive values map to magenta, and values near zero map to yellow [S1, unofficial].

**Pseudocode:**
```python
def compute_helicity_visualization(velocity_field):
    # velocity_field: 3D list of shape (Nx, Ny, Nz, 3) containing (u, v, w)
    nx, ny, nz = len(velocity_field), len(velocity_field[0]), len(velocity_field[0][0])
    output = [[[None for _ in range(nz)] for _ in range(ny)] for _ in range(nx)]
    
    # 1. Compute Vorticity (Curl) using central differences
    vorticity = [[[None for _ in range(nz)] for _ in range(ny)] for _ in range(nx)]
    for i in range(1, nx - 1):
        for j in range(1, ny - 1):
            for k in range(1, nz - 1):
                # omega_x = dW/dy - dV/dz
                # omega_y = dU/dz - dW/dx
                # omega_z = dV/dx - dU/dy
                vorticity[i][j][k] = [
                    (velocity_field[i][j+1][k][2] - velocity_field[i][j-1][k][2]) - (velocity_field[i][j][k+1][1] - velocity_field[i][j][k-1][1]),
                    (velocity_field[i][j][k+1][0] - velocity_field[i][j][k-1][0]) - (velocity_field[i+1][j][k][2] - velocity_field[i-1][j][k][2]),
                    (velocity_field[i+1][j][k][1] - velocity_field[i-1][j][k][1]) - (velocity_field[i][j+1][k][0] - velocity_field[i][j-1][k][0])
                ]
    
    # 2. Compute Helicity & 3. Apply Transfer Function
    for i in range(nx):
        for j in range(ny):
            for k in range(nz):
                # Handle boundaries by zero-padding (standard practice) [G]
                if vorticity[i][j][k] is None:
                    vorticity[i][j][k] = [0.0, 0.0, 0.0]
                
                h = (velocity_field[i][j][k][0] * vorticity[i][j][k][0] +
                     velocity_field[i][j][k][1] * vorticity[i][j][k][1] +
                     velocity_field[i][j][k][2] * vorticity[i][j][k][2])
                
                mag_h = abs(h)
                
                # Map Opacity: large magnitude -> opaque, small -> transparent [S1, unofficial]
                # Exact scaling function not provided in sources [G]
                alpha = min(1.0, mag_h / 10.0)
                
                # Map Color based on sign [S1, unofficial]
                # Exact thresholds for "extreme" and "near zero" not provided [G]
                if h > 0:
                    color = [1.0, 0.0, 1.0] # Magenta
                elif h < 0:
                    color = [0.0, 1.0, 1.0] # Cyan
                else:
                    color = [1.0, 1.0, 0.0] # Yellow
                
                output[i][j][k] = color + [alpha]
    return output
```

**Parameters:**
- Thresholds for "extreme" positive/negative and "near zero" are not explicitly defined in the sources [S1, unofficial].
- Scaling for opacity mapping is not specified [S1, unofficial].

**Edge Cases:**
- **Zero Helicity:** If $h(\mathbf{x}) = 0$, the value maps to yellow and low opacity [S1, unofficial].
- **Flow Reversal:** Negative x-component velocity values indicate flow separation, which can produce negative helicity values mapped to cyan [S1, unofficial].

## Subtopics

### [Perturbation Velocity Visualization](8398-perturbation-velocity-visualization.md)
Isolates flow disturbances by mapping perturbation velocity magnitude to opacity, making bulk free-stream flow invisible to highlight wakes or boundary layers.

## Operating characteristics
- **Strengths:** Effectively visualizes vortices and distinguishes rotation direction using color [S1, unofficial]. Maps magnitude to opacity to make features like "lambda" shocks and vortex cores visible [S1, unofficial].
- **Limitations:** Requires accurate computation of both velocity and its curl (vorticity) [S2]. Exact thresholds and scaling functions for the transfer function are not standardized in the sources [S1, unofficial].
- **Performance:** Depends on the cost of computing the curl and dot product per voxel. No specific hardware performance metrics are provided in the sources.

## Background
- **History:** Helicity is defined as the scalar function representing the curl in the direction of the velocity [S2]. It was used to visualize vortices generated by fins in flow fields, identifying features like the "lambda" shock [S1, unofficial].
- **Usage:** Used in Computational Fluid Dynamics (CFD) to isolate flow disturbances and identify vortices [S1, unofficial][S2].
