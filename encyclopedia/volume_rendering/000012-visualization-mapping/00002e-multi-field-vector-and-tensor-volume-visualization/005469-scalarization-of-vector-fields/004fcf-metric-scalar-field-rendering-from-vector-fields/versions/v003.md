# Metric Scalar Field Rendering from Vector Fields

Also called: Vector Field Metric Extraction

## Overview
Metric Scalar Field Rendering from Vector Fields converts multi-component vector field data into single-value scalar fields to enable standard scalar rendering techniques like volume rendering or isosurface extraction [S1, unofficial]. It differs from direct vector visualization methods (e.g., arrow glyphs or particle advection) by projecting vector data into metrics such as velocity magnitude, divergence, or curl [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A vector field $\mathbf{F}(x,y,z)$ defined on a 3D grid, optionally time-dependent [S1, unofficial].
*   **Output:** A scalar field $S(x,y,z)$ derived from $\mathbf{F}$, used as input for a scalar renderer (volume raymarching or isosurface extraction) [S1, unofficial].

**Data Structures:**
*   **Vector Field Grid:** A 3D array storing components $(F_1, F_2, F_3)$ at each voxel $(i,j,k)$ [S1, unofficial].
*   **Scalar Field Grid:** A 3D array storing the computed metric value $S$ at each voxel [S1, unofficial].

**Steps:**
1.  **Metric Calculation:** For each voxel $(i,j,k)$, compute the desired scalar metric from the vector components [S1, unofficial].
2.  **Temporal Interpolation:** If the data consists of discrete time slices, interpolate the vector and scalar values at the current time step between the surrounding time slices to support time-dependent visualization [S1, unofficial].
3.  **Rendering:** Pass the resulting scalar field to a standard scalar volume renderer or isosurface extractor [S1, unofficial].

**Formulas:**
*   **Velocity Magnitude:** $|\mathbf{F}| = \sqrt{F_1^2 + F_2^2 + F_3^2}$ [G]
*   **Divergence:** $\nabla \cdot \mathbf{F} = \frac{\partial F_1}{\partial x} + \frac{\partial F_2}{\partial y} + \frac{\partial F_3}{\partial z}$ [G]
*   **Curl Vector:** $\text{curl } \mathbf{F}(x,y,z) = \begin{pmatrix} \frac{\partial F_3}{\partial y} - \frac{\partial F_2}{\partial z} \\ \frac{\partial F_1}{\partial z} - \frac{\partial F_3}{\partial x} \\ \frac{\partial F_2}{\partial x} - \frac{\partial F_1}{\partial y} \end{pmatrix}$ [S2]
*   **Curl Magnitude:** $|\text{curl } \mathbf{F}(i,j,k)| = \sqrt{ \left(\frac{\partial F_3}{\partial y} - \frac{\partial F_2}{\partial z}\right)^2 + \left(\frac{\partial F_1}{\partial z} - \frac{\partial F_3}{\partial x}\right)^2 + \left(\frac{\partial F_2}{\partial x} - \frac{\partial F_1}{\partial y}\right)^2 }$ [S2]

**Parameters:**
*   **Metric Type:** Selection of magnitude, divergence, or curl [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Boundary Conditions:** Derivatives required for curl and divergence are sensitive to grid boundaries [G]. Not given in the sources how boundaries are handled.
*   **Loss of Directional Information:** Scalarization discards the vector direction, which may be critical for interpreting flow topology [G].

## Subtopics

### Curl Magnitude Calculation
A specific metric extraction method that computes the magnitude of the curl of the vector field to highlight swirling features and vorticity (turbulent behavior) [S2]. It is chosen when the visual goal is to identify regions of rotation or turbulence within the flow, distinguishing it from magnitude-based methods which show speed [S2].

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of voxels, for the metric calculation [G]. Rendering complexity depends on the underlying scalar renderer [G].
*   **Memory Complexity:** $O(N)$ to store the derived scalar field [G].
*   **Strengths:** Allows the use of mature scalar volume rendering techniques for vector data; provides immersive 3D views of internal structures [S1, unofficial].
*   **Limitations:** Discards directional information; requires careful selection of the metric to avoid misleading representations; derivatives (curl/divergence) are noisy and sensitive to discretization [G].

## Background
The method was developed within interactive visual data analysis systems to enable standard scalar rendering techniques (isosurface extraction and direct volume rendering) on vector field data [S1, unofficial]. It allows simultaneous visualization of scalar structures and vector-derived features [S1, unofficial]. The curl magnitude metric is formally defined in the context of multi-dimensional transfer functions for 3D flow visualization [S2].
