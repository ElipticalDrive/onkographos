# Metric Scalar Field Rendering from Vector Fields

Also called: Vector Field Metric Extraction

## Overview
Metric Scalar Field Rendering converts vector field data into scalar values to enable standard surface or volume rendering techniques [S1, unofficial]. It solves the problem of visualizing vector fields, which lack a single intensity value, by calculating metrics such as velocity magnitude, vorticity, or divergence [S1, unofficial]. It differs from [Helicity Visualization](8393-helicity-visualization.md) by focusing on general magnitude-based scalarization rather than the specific alignment of curl and velocity.

## How it works
**Inputs:** Vector field data $\mathbf{F}$ defined on a discrete grid; optional scalar texture data for time-dependent interpolation.
**Outputs:** A scalar field $S$ where each grid point $(i,j,k)$ holds a computed metric value.

**Data Structures:**
*   **Vector Field $\mathbf{F}$:** A 3D array of vectors. At each grid location $(i,j,k)$, $\mathbf{F}(i,j,k) = (F_1, F_2, F_3)$.
*   **Scalar Field $S$:** A 3D array of floats. $S(i,j,k)$ stores the computed metric magnitude.

**Steps:**
1.  **Interpolation (Time-Dependent):** If the data is time-dependent, interpolate values at the current time step between time slices of scalar and vector texture data [S1, unofficial]. [G] Linear interpolation between adjacent time steps $t_1$ and $t_2$ is standard: $\mathbf{F}_t = \mathbf{F}_{t_1} + \frac{t - t_1}{t_2 - t_1}(\mathbf{F}_{t_2} - \mathbf{F}_{t_1})$.
2.  **Metric Calculation:** Compute the chosen scalar metric for each grid point. For Curl Magnitude (see Subtopics), calculate the curl vector and its magnitude.
3.  **Rendering:** Use the resulting scalar field $S$ as input for iso-surface extraction (e.g., Marching Cubes) or direct volume rendering with a transfer function [S1, unofficial].

**Formulas:**
The curl of a vector field $\mathbf{F}(x,y,z)$ is defined as [S2]:
$$
\text{curl } \mathbf{F}(x,y,z) = \begin{pmatrix} \frac{\partial F_3}{\partial y} - \frac{\partial F_2}{\partial z} \\ \frac{\partial F_1}{\partial z} - \frac{\partial F_3}{\partial x} \\ \frac{\partial F_2}{\partial x} - \frac{\partial F_1}{\partial y} \end{pmatrix}
$$
The scalar value used for rendering is the magnitude [S2]:
$$
|\text{curl } \mathbf{F}(i,j,k)|
$$

**Parameters:**
*   Interpolation method: Linear [S1, unofficial].
*   Metric choice: Velocity magnitude, vorticity (curl) magnitude, or divergence [S1, unofficial].

**Edge Cases:**
*   Boundary conditions for derivatives are not specified in the sources [S2]. [G] Standard central differences or forward/backward differences at boundaries are typically used.
*   Degenerate input (zero vectors) results in zero metric values.

## Subtopics

### Curl Magnitude Calculation
A scalar property representing the vorticity (degree of turbulent behavior) of a vector field $\mathbf{F}$ [S2]. It is used to extract swirling features [S2]. The curl is defined as $\text{curl } \mathbf{F}(x,y,z) = (\frac{\partial F_3}{\partial y} - \frac{\partial F_2}{\partial z}, \frac{\partial F_1}{\partial z} - \frac{\partial F_3}{\partial x}, \frac{\partial F_2}{\partial x} - \frac{\partial F_1}{\partial y})$ [S2]. The magnitude $|\text{curl } \mathbf{F}(i,j,k)|$ is used at each discrete grid location [S2].

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of grid points, for the metric calculation. Interpolation adds a constant factor per time step.
*   **Memory Complexity:** $O(N)$ to store the scalar field.
*   **Strengths:** Enables the use of mature scalar-based rendering techniques (iso-surfaces, DVR) for vector data [S1, unofficial].
*   **Limitations:** Loss of directional information; the choice of metric significantly impacts visual interpretation [S1, unofficial].
*   **When to use:** When the magnitude of flow features (speed, turbulence) is the primary interest [S1, unofficial].
*   **When not to use:** When the direction or alignment of flow is critical (consider [Helicity Visualization](8393-helicity-visualization.md) or glyph rendering) [S1, unofficial].

## Background
Originated in the context of interactive visual data analysis for flow fields [S1, unofficial]. The method allows for the simultaneous display of structural data (like skull/head density) and vector field metrics [S1, unofficial]. It is often combined with particle advection and glyph rendering for comprehensive visualization [S1, unofficial].
