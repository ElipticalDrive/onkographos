# Multi-field Visualization Combination

Also called: Combined Scalar and Vector Field Visualization

## Overview
Multi-field Visualization Combination is a strategy that synthesizes volumetric scalar fields (representing object volume or magnitude) with vector field geometry (glyphs or streamlines representing motion or direction) to convey both spatial structure and dynamic status simultaneously [S1, unofficial]. It sets itself apart from sibling methods like [Domain Colouring](1833-domain-colouring.md) or [Stream Lines](4796-stream-lines.md) by explicitly layering distinct rendering techniques (e.g., volume rendering overlaid with stroke-based or glyph rendering) rather than mapping multiple components into a single attribute space [S1, unofficial][S2].

## How it works
The method combines two distinct data representations into a single image plane by rendering a scalar volume to establish context and boundaries, then superimposing vector field visualizations to indicate flow or direction [S1, unofficial][S2].

**Inputs and Outputs:**
*   **Input 1:** Scalar field data (e.g., video frame differences, temperature, salinity, vorticity magnitude) [S1, unofficial][S2].
*   **Input 2:** Vector field data (e.g., optical flow, velocity field) [S1, unofficial][S2].
*   **Output:** A composite image containing volumetric rendering and vector glyphs/strokes [S1, unofficial][S2].

**Data Structures:**
*   **Scalar Volume:** Typically stored as a 3D grid or a sequence of 2D frames (for video) [S1, unofficial].
*   **Vector Field:** Stored as a 3D grid of vectors or derived from the scalar field via differentiation/flow estimation [S1, unofficial][S2].
*   **Seed Points:** A set of 2D or 3D coordinates generated from the vector field to position glyphs or start streamlines [S1, unofficial].

**Steps:**
1.  **Generate Seed Points:** Determine a set of seed points for the vector field visualization [S1, unofficial]. For optical flow, this involves filtering the flow field to identify significant motion regions [S1, unofficial].
2.  **Render Scalar Volume:** Render the object volume using a volume rendering technique [S1, unofficial]. In video contexts, a "horseshoe layout" may be used to display multiple frames or sides of the video volume efficiently [S1, unofficial].
3.  **Render Vector Geometry:** Overlay the vector field visualization onto the rendered volume [S1, unofficial][S2]. This can be done using:
    *   **Glyphs:** Placing arrows or hedgehogs at seed points to show direction [S1, unofficial].
    *   **Streamlines/Strokes:** Tracing characteristic lines (particle tracing) and rendering them as strokes [S1, unofficial][S2].
4.  **Enhance Perception (Optional):** Apply visual enhancements such as darkening strokes away from regions of interest (e.g., sea surface) or highlighting boundaries to improve depth perception and focus [S2].

**Formulas:**
*   **Optical Flow Averaging:** To smooth the flow field for seed generation, averages $ \bar{u}_k $ and $ \bar{v}_k $ are computed in a neighborhood domain [S1, unofficial].
*   **Iteration:** The flow estimation may require a fixed number of iterations (e.g., 60 steps) for low-resolution data [S1, unofficial].

**Parameters:**
*   **Seed Density:** Controls the number of glyphs or streamline starts [S1, unofficial][S2].
*   **Stroke Length/Width:** Interactive parameters to adjust the visibility of flow lines [S2].
*   **Darkening Factor:** Controls the opacity reduction of strokes away from focal regions [S2].

**Edge Cases and Pitfalls:**
*   **Occlusion:** Mutual occlusion of streamlines or glyphs can lead to loss of visual information [S1, unofficial].
*   **Depth Perception:** Superimposing 2D strokes on a 3D volume can obscure spatial relationships if not handled with depth cues (e.g., darkening, highlighting) [S2].
*   **Performance:** Rendering both volume and complex vector fields (especially streamlines) is resource-intensive [S1, unofficial].

            path = euler_integrate(vector_field, point, steps=render_config.get('streamline_steps', 50))

def box_blur(field, radius):
    # Standard convolution for neighborhood averaging [G]
    out = create_zero_image(field.shape)
    for i in range(field.shape[0]):
        for j in range(field.shape[1]):
            for k in range(field.shape[2]):
                val = 0.0
                count = 0
                for di in range(-radius, radius+1):
                    for dj in range(-radius, radius+1):
                        for dk in range(-radius, radius+1):
                            ni, nj, nk = i+di, j+dj, k+dk
                            if 0 <= ni < field.shape[0] and 0 <= nj < field.shape[1] and 0 <= nk < field.shape[2]:
                                val += field[ni][nj][nk]
                                count += 1
                out[i][j][k] = val / count
    return out

## Subtopics

### Simultaneous Visualization
A multidimensional visualization approach presenting more than one property in a single visualization, such as superimposing volume rendering of one property with stroke-based rendering of another [S2]. It sets itself apart by using NPR (Non-Photorealistic Rendering) techniques like pencil-drawing-like strokes to reveal local flow direction while volume rendering provides context (e.g., vorticity magnitude or temperature) [S2]. Choose this when you need to show both the strength of a scalar field and the direction of a vector field simultaneously, especially in CFD or ocean simulation contexts [S2].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Requires storage for both scalar and vector fields, plus seed points and intermediate rendering buffers [S1, unofficial][S2].
*   **Performance:** GPU-assisted implementations can improve performance, but rendering deformed volumes (horseshoe layout) and complex streamlines remains computationally expensive [S1, unofficial].
*   **Strengths:** Conveys both spatial structure and dynamic motion/direction; improves comprehension of velocity fields when combined with scalar context [S1, unofficial][S2].
*   **Limitations:** Potential for visual clutter and occlusion; depth perception can be challenging without additional cues [S1, unofficial][S2].
*   **When to Use:** When analyzing video streams with motion, or CFD/ocean simulations where both magnitude and direction are critical [S1, unofficial][S2].
*   **When Not to Use:** When the vector field is too dense, leading to occlusion, or when the scalar field is not relevant to the analysis [S1, unofficial][S2].

## Background
The method originates from research into video visualization and multidimensional data visualization [S1, unofficial][S2]. It was notably applied to GPU-assisted multi-field video volume visualization, combining optical flow with volume rendering [S1, unofficial]. It also appears in the context of PDF visualization of multidimensional, multivariate volume data, where it is used to enhance perceptual effectiveness in scientific visualization [S2].
