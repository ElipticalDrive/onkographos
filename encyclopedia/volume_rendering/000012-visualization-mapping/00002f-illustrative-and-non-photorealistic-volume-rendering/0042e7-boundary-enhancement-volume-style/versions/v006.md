# Boundary Enhancement Volume Style
## Overview
Boundary Enhancement Volume Style is a non-photorealistic rendering technique that highlights feature bounds and reduces visual noise in volumetric data [S1, unofficial]. It operates as a composable style within a rendering graph, modifying the compositing pass to emphasize edges, distinct from sibling methods like [Line Illustration Detection](772-line-illustration-detection.md) that convert edges into line primitives [S1, unofficial].
## How it works
**Inputs and Outputs:**
- Input: A volumetric scalar field, a transfer function mapping values to color and opacity, ray origin, ray direction, and step size.
- Output: A 2D image where feature boundaries are enhanced with high-contrast highlights and noise is suppressed [S1, unofficial].

**Data Structures:**
The style is implemented as a node (e.g., `BoundaryEnhancementVolumeStyle`) that can be listed in the `renderStyle` field of a `ComposedVolumeStyle` node [S1, unofficial].

**Algorithm Steps:**
1. **Ray Marching:** Step along the ray through the volume using a specified step size.
2. **Gradient Estimation:** Compute the local gradient magnitude $|\nabla f|$ at the current sample point using central differences between adjacent voxels [G].
3. **Edge Detection & Noise Suppression:** Compare the gradient magnitude against a threshold $\tau$. Values below $\tau$ are treated as zero to suppress noise [G].
4. **Style Application:** Modulate the sample's opacity and color based on the edge strength. High gradient locations receive increased opacity or a bright highlight [G].
5. **Compositing:** Blend the enhanced sample along the ray using standard front-to-back alpha blending [G].

**Pseudocode:**
```python
def boundary_enhance_volume_style(ray_origin, ray_direction, volume_data, transfer_function, threshold, step_size):
    """Simulates BoundaryEnhancementVolumeStyle during ray marching."""
    color = vec3(0.0)
    alpha = 0.0
    t = 0.0
    max_distance = compute_ray_length(ray_origin, ray_direction, volume_data.bounds)  # [G]
    
    while t < max_distance:
        pos = ray_origin + t * ray_direction
        value = sample_volume(volume_data, pos)  # [G]
        grad_mag = compute_gradient_magnitude(volume_data, pos)  # [G]
        
        # Edge Detection & Noise Suppression
        edge_strength = max(0.0, grad_mag - threshold)
        
        # Get base color/opacity
        base_color, base_alpha = transfer_function(value)
        
        # Style Application
        enhanced_alpha = base_alpha * (1.0 + edge_strength)
        enhanced_color = base_color + vec3(edge_strength * 0.2)
        
        # Compositing (front-to-back)
        alpha_out = alpha + (1.0 - alpha) * enhanced_alpha
        color = color + (1.0 - alpha) * enhanced_alpha * enhanced_color
        alpha = alpha_out
        
        if alpha > 0.99:
            break
        t += step_size
        
    return color

def compute_ray_length(origin, direction, bounds):  # [G] Standard ray-box intersection
    t_min = -float('inf')
    t_max = float('inf')
    for i in range(3):
        if direction[i] == 0.0:
            if origin[i] < bounds.min[i] or origin[i] > bounds.max[i]:
                return 0.0
        else:
            t1 = (bounds.min[i] - origin[i]) / direction[i]
            t2 = (bounds.max[i] - origin[i]) / direction[i]
            t_min = max(t_min, min(t1, t2))
            t_max = min(t_max, max(t1, t2))
    return t_max if t_max > t_min else 0.0

def sample_volume(data, pos):  # [G] Trilinear interpolation from voxel grid
    return data.interpolate(pos)

def compute_gradient_magnitude(data, pos):  # [G] Central differences in 3D
    gx = data.interpolate(pos + vec3(0.5, 0.0, 0.0)) - data.interpolate(pos - vec3(0.5, 0.0, 0.0))
    gy = data.interpolate(pos + vec3(0.0, 0.5, 0.0)) - data.interpolate(pos - vec3(0.0, 0.5, 0.0))
    gz = data.interpolate(pos + vec3(0.0, 0.0, 0.5)) - data.interpolate(pos - vec3(0.0, 0.0, 0.5))
    return sqrt(gx*gx + gy*gy + gz*gz)
```

**Parameters:**
- `threshold`: Gradient magnitude cutoff for edge detection. Not given in the sources.
- `step_size`: Distance between samples along the ray. Set via `RayGenerationVolumeSettings` [S1, unofficial].

**Edge Cases:**
- **Non-equidistant grids:** If the volume data is not equidistant, the `dimensions` field is unused and gradient calculations must account for voxel spacing [S1, unofficial].
- **Swapped data:** 16-bit volumes may have swapped byte order; the `swapped` field acts as a simple helper to handle this [S1, unofficial].

## Subtopics

### XRayVolumeStyle
A non-composable render style used alternatively in the `VolumeData` node's `renderStyle` field [S1, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
- Time: $O(N)$ where $N$ is the number of samples per ray. Gradient computation adds a constant factor overhead per sample [G].
- Memory: $O(1)$ additional memory per ray for gradient and compositing state [G].

**Measured Performance:**
Performance depends on the GPU model and gradient calculation complexity. Using "interleaved" ray generation reduces wood artifacts and can improve cache coherence [S1, unofficial].

**Strengths and Limitations:**
- Strengths: Effective at reducing noise while preserving structural clarity. Can be combined with other styles like `ShadedVolumeStyle` and `OpacityMapVolumeStyle` via `ComposedVolumeStyle` [S1, unofficial].
- Limitations: Requires accurate gradient estimation, which can be sensitive to raw data noise. Not composable if using non-composable styles like `XRayVolumeStyle` [S1, unofficial].

**When to Use:**
Use when the goal is to clarify internal structures in noisy volumetric data without losing the context of the surrounding volume [G].

## Background
The method is part of the InstantReality 1.0 volume rendering framework, which provides a set of composable volume styles for non-photorealistic visualization [S1, unofficial]. It builds on the general principles of edge detection in volume rendering, where local intensity changes are mapped to visual highlights [G].
