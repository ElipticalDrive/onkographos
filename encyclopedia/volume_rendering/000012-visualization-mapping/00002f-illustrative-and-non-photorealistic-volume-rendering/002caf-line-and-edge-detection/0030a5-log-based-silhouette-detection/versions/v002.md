# LOG-based Silhouette Detection

Also called: Laplacian of Gaussian edge detection

## Overview
LOG-based Silhouette Detection is a volumetric edge detection technique used to identify silhouette voxels for rendering sketch-like curves in non-photorealistic volume rendering [S1]. It replaces an exhaustive 3x3x3 subspace search with a faster, precomputed Laplacian of Gaussian (LOG) operator to simplify boundary computation while providing virtually identical results [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A volumetric dataset $V$, where each voxel $i$ has a scalar value $V_i$.
*   **Output:** A set of line segments representing silhouette curves, drawn through the centers of identified silhouette voxels.

**Data Structures**
*   **Precomputed LOG Volume:** A volume of the same dimensions as the input dataset, storing the scalar LOG value for each voxel.
*   **Gradient Volume:** A volume storing the gradient vector $\nabla V_i$ for each voxel.

**Preprocessing Step**
1.  Compute the Laplacian of Gaussian (LOG) value for each voxel in the volume dataset [S1].
2.  Compute the gradient $\nabla V_i$ for each voxel [S1].

**Rendering Step**
For each voxel $i$ during rendering, determine if it is a silhouette voxel by checking three criteria simultaneously [S1]:

1.  **LOG Threshold:** The product of the voxel value and its LOG value must be below a threshold:
    $$ V_i \cdot \text{LOG}(V_i) < T_{hLOG} $$
    where $T_{hLOG}$ is a user-controllable threshold [S1].

2.  **Eye Vector Alignment:** The dot product of the eye (view) vector $\vec{E}$ and the gradient $\nabla V_i$ must be below a threshold:
    $$ (\vec{E} \cdot \nabla V_i) < T_{heye} $$
    where $\vec{E}$ is the eye vector and $T_{heye}$ is a user-controllable threshold [S1].

3.  **Gradient Magnitude:** The magnitude of the gradient must exceed a threshold:
    $$ \|\nabla V_i\| > T_{hgrad} $$
    where $T_{hgrad}$ is a user-controllable threshold [S1].

If a voxel satisfies all three criteria, draw a line segment through the center of the voxel in the direction of $\nabla V_i \times \vec{E}$ [S1].

**Pseudocode**

```python
def compute_log_volume(volume):
    """
    Precompute the Laplacian of Gaussian (LOG) for each voxel.
    Note: The specific convolution kernel or implementation details 
    for the LOG operator are not given in the sources [S1].
    """
    log_volume = create_empty_volume_like(volume)
    for voxel in volume:
        # Apply LOG operator to voxel value and local neighborhood
        log_value = apply_log_operator(voxel)
        log_volume[voxel] = log_value
    return log_volume

def compute_gradient_volume(volume):
    """
    Compute the gradient vector for each voxel.
    """
    gradient_volume = create_empty_vector_volume_like(volume)
    for voxel in volume:
        gradient = compute_gradient(voxel)
        gradient_volume[voxel] = gradient
    return gradient_volume

def render_silhouette_curves(volume, log_volume, gradient_volume, eye_vector, 
                             th_log, th_eye, th_grad):
    """
    Render silhouette curves by identifying silhouette voxels.
    """
    line_segments = []
    
    for voxel in volume:
        v_i = volume[voxel]
        log_v_i = log_volume[voxel]
        grad_v_i = gradient_volume[voxel]
        
        # Criterion 1: LOG threshold
        if not (v_i * log_v_i < th_log):
            continue
            
        # Criterion 2: Eye vector alignment
        if not (dot(eye_vector, grad_v_i) < th_eye):
            continue
            
        # Criterion 3: Gradient magnitude
        if not (norm(grad_v_i) > th_grad):
            continue
            
        # Voxel is a silhouette voxel
        # Draw line segment through center in direction of cross product
        direction = cross(grad_v_i, eye_vector)
        line_segments.append(LineSegment(center=voxel, direction=direction))
        
    return line_segments
```

**Parameters**
*   $T_{hLOG}$: Threshold for the LOG value product [S1].
*   $T_{heye}$: Threshold for the dot product of the eye vector and gradient [S1].
*   $T_{hgrad}$: Threshold for the gradient magnitude [S1].

**Edge Cases and Pitfalls**
*   The sources do not specify how to handle degenerate cases where the gradient is zero or the cross product is null [S1].
*   The sources do not specify the exact implementation of the LOG operator or gradient computation [S1].

## Operating characteristics
*   **Performance:** The LOG technique is much faster to calculate per frame than the exhaustive 3x3x3 subspace search because it simplifies boundary computation [S1].
*   **Quality:** It provides virtually identical results to the exhaustive search [S1].
*   **Frame Rate:** Interactive rendering is possible, with frame rates of 20 to 30 frames per second reported for stipple rendering [S1].
*   **Hardware:** Tested on a dual processor Intel Xeon 2.00 GHz computer with a Geforce 3 Ti 500 display card [S1].
*   **Data Size:** Typical datasets range from 5,000 to 2,000,000 point primitives, with silhouette curves ranging from 1,000 to 300,000 [S1].
*   **Preprocessing Time:** Varies from seconds to a minute depending on dataset size [S1].
*   **Limitations:** Performance can be improved by further reducing cache exchange and floating point operations [S1].

## Background
*   **Origin:** The method was introduced in the paper "Non-Photorealistic Volume Rendering Using Stippling Techniques" [S1].
*   **Purpose:** It was developed to address the performance bottleneck of exhaustive 3x3x3 subspace searches for silhouette detection in non-photorealistic volume rendering [S1].
*   **Application:** It is used in stipple rendering to highlight structures, such as bones in medical volumes [S1].
