# Lasso Contour Rendering
## Overview
Lasso Contour Rendering is an interactive non-photorealistic volume rendering technique that allows users to manually define regions of interest using a free-form selection tool to generate contour overlays [S1, unofficial]. It solves the problem of isolating complex volumetric structures by enabling user-driven contour generation [S1, unofficial]. It differs from siblings like [Object Contour NPR](787-object-contour-npr.md) by relying on explicit user interaction to define the region of interest rather than automatic geometric or scalar-based detection [S1, unofficial].

**Data Structures:**

*   **Render Pipeline:** An object containing the shader programs and render passes for drawing the contour overlay, accessed via `gLassoRenderPipeline` [S1, unofficial].
**Steps:**
1.  **Interaction Check:** The system checks if the user is currently drawing a lasso by querying `gLassoInputHandler.isCurrentlyDrawing()` [S1, unofficial].
2.  **Pipeline Validation:** The system verifies that the specific render pipeline for lasso contours exists (`gLassoRenderPipeline`) [S1, unofficial].
3.  **Rendering:** If the conditions are met, the active lasso contour is rendered using the offscreen render pass by calling `gLassoRenderPipeline.render()` [S1, unofficial].

    """
    Renders the lasso contour if the user is actively drawing.
    """
    # Step 1: Check if user is currently drawing a lasso
    if not input_handler.isCurrentlyDrawing():
        return

## Subtopics

### Flow Contours
Flow Contours is a variant technique designed for visualizing flow data where high gradients are rare and boundaries are not the primary concern [S2]. It uses a transfer function widget based on a sine function to control the frequency and amplitude of the contours, allowing users to reveal flow structures like vortices, sinks, and sources [S2]. To reduce visual clutter, it often combines these contours with silhouettes (projected 2D gradients) to highlight major structures [S2]. It is chosen when the goal is to understand flow topology rather than sharp material boundaries [S2].

## Background
The technique is associated with the work of Nikolai Svakhine, Yun Jang, David Ebert, and Kelly Gaither, presented in the context of volume illustration for medicine and flows [S2]. It builds on the principles of non-photorealistic rendering to enhance perceptual clarity in volumetric data [G]. The interactive lasso implementation is documented in a WebGPU volume renderer demonstration [S1, unofficial].
