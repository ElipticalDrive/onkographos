# Neural Network Sketch-Based Specification

Also called: Tzeng et al. Neural Network TF, Tzeng et al. method

## Overview
A technique using a neural network to adjust the transfer function based on a sketch drawn on a volume visualization, training the network to emphasize marked regions [S1, unofficial]. It implements multidimensional transfer functions as back-propagation neural networks to decide voxel visibility, where training is supervised by user-selected voxels on 2D slices [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Volumetric dataset and user sketch (painted voxels on 2D slices indicating desired visibility) [S2, unofficial].
*   **Output:** A trained back-propagation neural network representing the multidimensional transfer function, mapping voxel signatures to visibility values [S2, unofficial].

**Data Structures:**
*   **Voxel Signature:** A multidimensional vector representing the properties of a selected voxel [S2, unofficial]. The exact dimensionality and components are not specified in the sources.
*   **Labels:** Binary or categorical labels indicating "visible" or "invisible" for each selected voxel [S2, unofficial].

**Steps:**
1. The user visualizes 2D slices of the volumetric data [S2, unofficial].
2. The user paints voxels on the 2D slices with one color to indicate they should be visible in the final image, and another color to indicate they should remain invisible [S2, unofficial].
3. The multidimensional signatures of the selected voxels are extracted [S2, unofficial].
4. A back-propagation neural network is trained using the extracted signatures as input and the user-defined visibility labels as the target output [S2, unofficial].
5. Training continues until the network finds a specification capable of emphasizing the marked regions [S1, unofficial].

**Pseudocode:**
```python
def train_nn_sketch_based_specification(volume, user_sketch):
    # Step 1 & 2: Extract training data from user sketch
    training_inputs = []
    training_labels = []
    for coordinates, paint_color in user_sketch:
        # Extract multidimensional signature for the voxel
        # Note: Exact signature components are not specified in the sources [S2, unofficial]
        signature = [0.0] * 4  # Dummy signature for syntax; actual extraction method unspecified
        training_inputs.append(signature)
        # Map user color to label: 1.0 for visible, 0.0 for invisible
        training_labels.append(1.0 if paint_color == "visible" else 0.0)

    # Step 3: Initialize back-propagation neural network
    # Note: Network architecture (layers, neurons) is not specified in the sources [S2, unofficial]
    input_dim = len(training_inputs[0])
    hidden_dim = 8
    # Initialize weights with small random values
    W1 = [[0.01 * (2 * (i * input_dim + j) % 100 - 50) / 50 for j in range(input_dim)] for i in range(hidden_dim)]
    b1 = [0.0] * hidden_dim
    W2 = [[0.01 * (2 * (i * hidden_dim + j) % 100 - 50) / 50 for j in range(hidden_dim)] for i in range(1)]
    b2 = [0.0]

    # Step 4: Train the network
    # Training is supervised using the extracted signatures and labels
    # Note: Specific loss function, learning rate, and number of epochs are not specified [S2, unofficial]
    learning_rate = 0.1
    epochs = 100
    for epoch in range(epochs):
        for x, y in zip(training_inputs, training_labels):
            # Forward pass
            z1 = [sum(W1[i][j] * x[j] for j in range(input_dim)) + b1[i] for i in range(hidden_dim)]
            a1 = [1.0 / (1.0 + 2.718281828 ** (-z)) for z in z1]  # Sigmoid activation
            z2 = sum(W2[0][i] * a1[i] for i in range(hidden_dim)) + b2[0]
            a2 = 1.0 / (1.0 + 2.718281828 ** (-z2))  # Output activation

            # Backward pass
            error = a2 - y
            delta2 = error * a2 * (1.0 - a2)
            delta1 = [sum(W2[0][i] * delta2 for i in range(1)) * a1[i] * (1.0 - a1[i]) for i in range(hidden_dim)]

            # Update weights
            for i in range(hidden_dim):
                for j in range(input_dim):
                    W1[i][j] -= learning_rate * delta1[i] * x[j]
                b1[i] -= learning_rate * delta1[i]
                W2[0][i] -= learning_rate * delta2 * a1[i]
            b2[0] -= learning_rate * delta2

    # Step 5: Training continues until the network finds a specification capable of emphasizing the marked regions [S1, unofficial]
    return W1, b1, W2, b2
```
