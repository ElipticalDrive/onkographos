# Hybrid Shading

Also called: Hybrid CVR, Mixture of gradient-based shading with volumetric shading

## Overview
Hybrid Shading blends gradient-based shading, which captures local surface details, with volumetric shading, which provides global ambient occlusion, to balance an image's local and global features while reducing noise [S1][S2, unofficial]. It distinguishes itself from pure gradient-based methods by introducing a dynamic interpolation controlled by opacity and gradient magnitude, offering a softer appearance that is particularly effective for noisy data such as ultrasound [S2, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs:**
    *   $v$: User-defined blending factor, a scalar in the range $[0, 1]$ [S1].
    *   $g$: Gradient magnitude at the current sample point [S1][S2, unofficial].
    *   $\alpha x'$: Opacity value at the current sample point [S1][S2, unofficial].
    *   $L_{phong}$: Incident light computed via Phong lighting model [S1].
    *   $L_{vs}$: Incident light computed via volumetric shadow lighting [S1].
*   **Output:**
    *   $L_{in}$: Final incident light value for the fragment [S1].

**Data Structures**
No specific complex data structures are required beyond standard fragment shader inputs (gradient, opacity, light vectors) [G]. The method operates on per-sample values [S1][S2, unofficial].

**Steps**
1.  Calculate the gradient-based shading value ($L_{phong}$) using standard Phong illumination [S1].
2.  Calculate the volumetric shading value ($L_{vs}$) using volumetric shadow lighting [S1].
3.  Compute the blending coefficient $c_{blend}$ using the formula below [S1][S2, unofficial].
4.  Interpolate between the two lighting models using $c_{blend}$ to produce the final incident light [S1][S2, unofficial].

**Formulas**
The blending coefficient $c_{blend}$ is calculated as [S1]:

$$
c_{blend} = v \left( 1 - e^{|g|^{\frac{1}{\alpha x'}}} \right)
$$

Where:
*   $v$ is the user-defined blending factor ($0 \le v \le 1$) [S1].
*   $g$ is the gradient magnitude [S1][S2, unofficial].
*   $\alpha x'$ is the opacity value [S1][S2, unofficial].

The final incident light $L_{in}$ is calculated as [S1]:

$$
L_{in} = (1 - c_{blend}) L_{phong} + c_{blend} L_{vs}
$$

Where:
*   $L_{phong}$ is the Phong lighting contribution [S1].
*   $L_{vs}$ is the volumetric shadow lighting contribution [S1].

**Parameters**
*   **VolumetricScatteringBlending ($v$):** A user-defined coefficient controlling the interpolation between gradient-based and volumetric shading [S2, unofficial]. The blending factor ranges between 0 and 1 [S1].

**Pitfalls and Edge Cases**
*   **Exponentiation Stability:** The term $|g|^{\frac{1}{\alpha x'}}$ involves exponentiation where the exponent depends on the inverse of opacity [G]. If $\alpha x'$ approaches zero, the exponent approaches infinity, potentially causing numerical instability or overflow if $|g| > 1$ [G]. If $|g| < 1$, the term approaches zero [G]. Implementers should guard against division by zero or extreme values in the exponent [G].
*   **Noise Reduction vs. Detail Loss:** Setting the method to favor volumetric shading (higher $v$ or conditions where $c_{blend}$ is high) results in a softer appearance and reduces image noise, which is beneficial for ultrasound data [S2, unofficial]. However, small features may be dampened, which can be undesirable if fine detail preservation is required [S2, unofficial].
*   **Stochasticity vs. Interpolation:** The method uses deterministic interpolation rather than stochastic blending to reduce artifacts introduced by random sampling [S1].

**Pseudocode**
```python
import math

def hybrid_shading(v, g, alpha_x_prime, L_phong, L_vs):
    """
    Computes hybrid shading by interpolating between Phong and volumetric shading.
    
    Args:
        v (float): User-defined blending factor [0, 1].
        g (float): Gradient magnitude.
        alpha_x_prime (float): Opacity value.
        L_phong (float): Phong lighting intensity.
        L_vs (float): Volumetric shadow lighting intensity.
        
    Returns:
        float: Final incident light L_in.
    """
    # Guard against division by zero in exponent
    if alpha_x_prime <= 0.0:
        alpha_x_prime = 1e-6  # [G]

    # Calculate exponent term: |g|^(1 / opacity)
    exponent = 1.0 / alpha_x_prime
    base = abs(g)

    # Compute e^(base^exponent)
    exp_term = math.exp(math.pow(base, exponent))

    # Calculate blending coefficient: c_blend = v * (1 - exp_term)
    c_blend = v * (1.0 - exp_term)

    # Clamp blending coefficient to [0, 1] for valid interpolation weights [G]
    c_blend = max(0.0, min(1.0, c_blend))

    # Final incident light
    L_in = (1.0 - c_blend) * L_phong + c_blend * L_vs
    return L_in
```

## Operating characteristics
*   **Time Complexity:** The method adds a constant number of mathematical operations (exponentiation, multiplication, addition) per sample [G]. It avoids the computational cost of stochastic blending by using deterministic interpolation [S1].
*   **Memory Complexity:** No additional memory structures are required beyond standard volume data and fragment state [G].
*   **Performance:** The method is designed for interactive, in-browser rendering, balancing quality and speed [S1].
*   **Strengths:** Reduces noise in volumetric data (e.g., ultrasound) by favoring volumetric shading in noisy regions; balances local and global features [S1][S2, unofficial].
*   **Limitations:** May dampen small features if volumetric shading is favored too strongly [S2, unofficial]. Numerical stability of the exponent term requires careful handling of low opacity values [G].

## Background
Hybrid Shading was developed by the CVR team at Kitware as part of their Cinematic Volume Rendering work [S2, unofficial]. It was theorized to balance local and global features by combining gradient-based and volumetric shading [S2, unofficial]. The method was implemented and evaluated for interactive, in-browser cinematic volume rendering of medical images [S1]. The original formula was adopted and modified to increase speed and reduce speckle artifacts [S1].
