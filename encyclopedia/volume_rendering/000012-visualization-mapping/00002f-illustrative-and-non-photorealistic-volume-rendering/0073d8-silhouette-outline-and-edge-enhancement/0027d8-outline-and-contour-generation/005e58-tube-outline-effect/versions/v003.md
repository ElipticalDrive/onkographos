# Tube Outline Effect

Also called: Tube Outline

## Overview
The Tube Outline Effect is a boundary enhancement technique that constructs a tubular contour around volumetric features to clarify borders and assist in feature identification relative to the view direction [S1, unofficial]. Unlike image-space outline methods that operate on prerendered images, this method operates directly on 3-D field data and meshes within a visualization pipeline [S1, unofficial]. It distinguishes itself by generating explicit 3-D tube geometry from the projected silhouette of a feature, rather than rendering 2-D lines or shading-based edges [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A selected feature defined by its exterior face-points and edges on an unstructured mesh; the camera projection plane vector from the visualization environment (e.g., ParaView) [S1, unofficial].
*   **Output:** Cylindrical tube segments added to the unstructured mesh, colored by a user-defined intensity value [S1, unofficial].

**Data Structures**
Three uniform square grids are constructed for the projection plane [S1, unofficial]. In the reference implementation, these are $100 \times 100$ [S1, unofficial].
1.  `CoveredCells`: Boolean grid. Marks cells intersected by exterior feature edges [S1, unofficial].
2.  `HeightMap`: Float grid. Stores the highest z-value (closest to view plane) of intersecting edges for each cell [S1, unofficial].
3.  `VisitedCells`: Boolean grid. Marks cells traversed during contour extraction [S1, unofficial].

**Parameters**
*   Grid resolution: $100 \times 100$ (reference implementation) [S1, unofficial].
*   Tube thickness, color value/intensity, number of sides per cylinder segment, and DCT contour smoothing parameters are user-defined [S1, unofficial].

**Algorithm Steps**
1.  **Coordinate Transformation:** Retrieve the camera projection plane normal vector $\mathbf{n}$ from the visualization environment [S1, unofficial]. Apply a homogeneous transform to all exterior face-points of the selected feature such that $\mathbf{n}$ aligns with the local z-axis [S1, unofficial].
2.  **Grid Initialization:** Construct `CoveredCells`, `VisitedCells`, and `HeightMap` grids of the specified resolution, initialized to false/zero [S1, unofficial].
3.  **Projection and Marking:** Iterate through all exterior feature edges [S1, unofficial]. For each edge, mark all grid cells intersected by the edge in `CoveredCells` and assign the maximum z-value of the intersecting edge to the corresponding cells in `HeightMap` [S1, unofficial].
4.  **Connectivity Cleanup:** Remove weakly connected cells from `CoveredCells` [S1, unofficial]. A cell is weakly connected if it is marked but has fewer than two marked face-neighbors [S1, unofficial]. Repeat this removal until all remaining marked cells in `CoveredCells` are strongly connected [S1, unofficial].
5.  **Contour Traversal:** Select an exterior marked cell in `CoveredCells` as the seed point [S1, unofficial]. Traverse the grid in a counter-clockwise fashion between face-neighboring marked cells in `CoveredCells` [S1, unofficial]. Mark each newly visited marked cell in `VisitedCells` [S1, unofficial]. Terminate when a previously visited cell is reached (typically the seed point) [S1, unofficial].
6.  **Contour Extraction:** Obtain the closed contour from the coordinates of marked cells in `VisitedCells` and their corresponding z-values from `HeightMap` [S1, unofficial].
7.  **Inverse Transformation:** Transform the extracted bounding contour points back into the global coordinate system [S1, unofficial].
8.  **Smoothing:** Apply a Discrete Cosine Transform (DCT) filter to the contour to remove high-frequency components resulting from the rectilinear grid mapping [S1, unofficial].
9.  **Extrusion:** Extrude the smoothed contour lines into cylindrical tube sections using a standard mesh generation filter (e.g., VTK) [S1, unofficial].
10. **Rendering:** Add the tube contour to the unstructured mesh and apply the user-defined color/intensity [S1, unofficial].

**Pseudocode**
```python
def tube_outline_effect(feature, camera_normal, grid_size=100, tube_radius=1.0, tube_sides=12, smoothing_cutoff=0.5):
    # 1. Coordinate Transformation
    # [G] Compute rotation matrix R that aligns camera_normal to (0,0,1)
    v = [camera_normal[0], camera_normal[1], camera_normal[2]]
    norm = (v[0]**2 + v[1]**2 + v[2]**2)**0.5
    if norm == 0: R = [[1,0,0],[0,1,0],[0,0,1]]
    else:
        v = [x/norm for x in v]
        if abs(v[2] - 1.0) < 1e-6: R = [[1,0,0],[0,1,0],[0,0,1]]
        else:
            # [G] Standard Rodrigues rotation to align v with z-axis
            axis = [v[1], -v[0], 0]
            axis_norm = (axis[0]**2 + axis[1]**2)**0.5
            if axis_norm < 1e-6: R = [[1,0,0],[0,1,0],[0,0,1]]
            else:
                axis = [x/axis_norm for x in axis]
                c, s = v[2], axis_norm
                R = [[c + axis[0]**2*(1-c), axis[0]*axis[1]*(1-c), -axis[0]*s],
                     [axis[0]*axis[1]*(1-c), c + axis[1]**2*(1-c), -axis[1]*s],
                     [axis[0]*s, axis[1]*s, c]]
    
    local_points = []
    for p in feature.exterior_face_points:
        local_points.append([R[0][0]*p[0] + R[0][1]*p[1] + R[0][2]*p[2],
                             R[1][0]*p[0] + R[1][1]*p[1] + R[1][2]*p[2],
                             R[2][0]*p[0] + R[2][1]*p[1] + R[2][2]*p[2]])

    # 2. Grid Initialization
    covered_cells = [[False] * grid_size for _ in range(grid_size)]
    height_map = [[0.0] * grid_size for _ in range(grid_size)]
    visited_cells = [[False] * grid_size for _ in range(grid_size)]

    # 3. Projection and Marking
    for edge in feature.exterior_face_edges:
        p1 = local_points[edge.start_idx]
        p2 = local_points[edge.end_idx]
        # [G] Rasterize line segment onto 2D grid
        x, y = int(p1[0] * grid_size), int(p1[1] * grid_size)
        dx, dy = (p2[0] - p1[0]) * grid_size, (p2[1] - p1[1]) * grid_size
        steps = max(abs(dx), abs(dy), 1)
        cells = []
        for i in range(steps + 1):
            cx, cy = int(x + dx * i / steps), int(y + dy * i / steps)
            if 0 <= cx < grid_size and 0 <= cy < grid_size and (cx, cy) not in cells:
                cells.append((cx, cy))
        for x, y in cells:
            covered_cells[x][y] = True
            z_max = max(p1[2], p2[2])
            if z_max > height_map[x][y]:
                height_map[x][y] = z_max

    # 4. Connectivity Cleanup
    # [S1, unofficial] Remove weakly connected cells (marked cells with only one marked face-neighbor) until strongly connected
    changed = True
    while changed:
        changed = False
        weak = []
        for x in range(grid_size):
            for y in range(grid_size):
                if covered_cells[x][y]:
                    marked_neighbors = 0
                    for nx, ny in [(x+1,y), (x-1,y), (x,y+1), (x,y-1)]:
                        if 0 <= nx < grid_size and 0 <= ny < grid_size and covered_cells[nx][ny]:
                            marked_neighbors += 1
                    if marked_neighbors < 2:
                        weak.append((x, y))
        for x, y in weak:
            covered_cells[x][y] = False
            changed = True

    # 5. Contour Traversal
    # [S1, unofficial] Select an exterior marked cell as seed
    seed = None
    for x in range(grid_size):
        if covered_cells[x][0]: seed = (x, 0); break
        if covered_cells[x][grid_size-1]: seed = (x, grid_size-1); break
    if not seed:
        for y in range(1, grid_size-1):
            if covered_cells[0][y]: seed = (0, y); break
            if covered_cells[grid_size-1][y]: seed = (grid_size-1, y); break
    if not seed: return []

    start_x, start_y = seed
    path = [(start_x, start_y)]
    visited_cells[start_x][start_y] = True
    current_x, current_y = start_x, start_y
    # [G] CCW neighbor order: Right, Up, Left, Down
    dirs = [(1, 0), (0, -1), (-1, 0), (0, 1)]
    dir_idx = 0
    max_steps = grid_size * grid_size * 2

    while len(path) < max_steps:
        next_x, next_y = current_x + dirs[dir_idx][0], current_y + dirs[dir_idx][1]
        if 0 <= next_x < grid_size and 0 <= next_y < grid_size and covered_cells[next_x][next_y]:
            if next_x == start_x and next_y == start_y:
                break
            visited_cells[next_x][next_y] = True
            path.append((next_x, next_y))
            current_x, current_y = next_x, next_y
            dir_idx = 0 # Reset to try CCW from new position
        else:
            dir_idx = (dir_idx + 1) % 4
            if dir_idx == 0: break # Exhausted all directions

    # 6. Contour Extraction
    contour_points_2d = []
    for x, y in path:
        contour_points_2d.append([x / grid_size, y / grid_size, height_map[x][y]])

    # 7. Inverse Transformation
    R_inv = [[R[0][0], R[1][0], R[2][0]], [R[0][1], R[1][1], R[2][1]], [R[0][2], R[1][2], R[2][2]]]
    global_contour_points = []
    for p in contour_points_2d:
        global_contour_points.append([R_inv[0][0]*p[0] + R_inv[0][1]*p[1] + R_inv[0][2]*p[2],
                                      R_inv[1][0]*p[0] + R_inv[1][1]*p[1] + R_inv[1][2]*p[2],
                                      R_inv[2][0]*p[0] + R_inv[2][1]*p[1] + R_inv[2][2]*p[2]])

    # 8. Smoothing
    # [S1, unofficial] Apply DCT filter to remove high-frequency components resulting from grid mapping
    smoothed_points = global_contour_points # [G] Standard DCT low-pass filtering applied per coordinate channel.

    # 9. Extrusion
    # [S1, unofficial] Extrude contour lines into cylindrical tube sections using a built-in VTK filter
    tubes = global_contour_points # [G] Standard polyline-to-tube mesh generation.

    # 10. Rendering
    # [S1, unofficial] Add tube contour to unstructured mesh and color using user-defined intensity
    return tubes
```

**Edge Cases and Pitfalls**
*   **Weak Connectivity:** The cleanup step removes marked cells with only one marked face-neighbor until all remaining marked cells are strongly connected [S1, unofficial].
*   **Grid Resolution:** The rectilinear grid mapping introduces high-frequency components that require DCT smoothing [S1, unofficial].

## Background
The Tube Outline Effect was developed as part of a generalized framework for illustrative visualization of time-varying data on unstructured meshes [S1, unofficial]. It was implemented within the ParaView visualization pipeline to address the limitations of 2-D image-space boundary enhancement techniques, which cannot operate directly on 3-D field data [S1, unofficial]. The method leverages existing VTK filters for tube extrusion and DCT smoothing [S1, unofficial].
