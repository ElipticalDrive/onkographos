# Neural Network Sketch-Based Specification

Also called: Tzeng et al. Neural Network TF, Tzeng et al. method

## Overview
A technique using a neural network to adjust the transfer function based on a sketch drawn on a volume visualization, training the network to emphasize marked regions [S1, unofficial]. It implements multidimensional transfer functions as back-propagation neural networks to decide voxel visibility, where training is supervised by user-selected voxels on 2D slices [S2, unofficial]. It sets itself apart from sibling methods by using a learned mapping from visual sketches to multidimensional visibility decisions rather than manual parameter tuning or geometric contour separation [S1, unofficial][S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Volumetric dataset and user sketch (painted voxels on 2D slices indicating desired visibility) [S2, unofficial]. Initial network weights are standard for back-propagation but not explicitly specified [G].
*   **Output:** A trained back-propagation neural network representing the multidimensional transfer function, which maps voxel signatures to visibility values [S2, unofficial].

**Data Structures:**
*   **Voxel Signature:** A multidimensional vector representing the properties of a selected voxel [S2, unofficial]. The exact dimensionality is not given in the sources.
*   **Neural Network:** A back-propagation network [S2, unofficial]. The architecture (number of layers, neurons per layer) is not given in the sources.
*   **Labels:** Binary labels indicating "visible" or "invisible" for each selected voxel [S2, unofficial].

**Steps:**
1.  **Visualization:** The user visualizes 2D slices of the volumetric data [S2, unofficial].
2.  **Sketching/Painting:** The user paints voxels on the 2D slices with one color to indicate they should be visible, and another color to indicate they should remain invisible [S2, unofficial]. This constitutes the sketch [S1, unofficial].
3.  **Signature Extraction:** The multidimensional signatures of the selected voxels are extracted [S2, unofficial].
4.  **Training:** A back-propagation neural network is trained using the extracted signatures as input and the user-defined visibility labels as the target output [S2, unofficial].
5.  **Convergence:** Training continues until the network finds a specification capable of emphasizing the marked regions [S1, unofficial].

**Pseudocode:**
```python
import math
import random

def initialize_weights(input_dim, output_dim):
    # Standard uniform random initialization [G]
    return [[random.uniform(-0.5, 0.5) for _ in range(input_dim)] for _ in range(output_dim)]

def train_nn_sketch_based_specification(volume, user_sketch):
    # Step 3: Extract multidimensional signatures of selected voxels
    inputs = []
    targets = []
    for slice_data in user_sketch.slices:
        for voxel in slice_data.painted_voxels:
            # Extract signature components (e.g., scalar value, gradient magnitude) [G]
            val = volume[voxel.coordinates]
            # Compute gradient magnitude using finite differences [G]
            grad_x = volume[voxel.coordinates + (1, 0, 0)] - val
            grad_y = volume[voxel.coordinates + (0, 1, 0)] - val
            grad_z = volume[voxel.coordinates + (0, 0, 1)] - val
            grad_mag = math.sqrt(grad_x**2 + grad_y**2 + grad_z**2)
            signature = [val, grad_mag]
            inputs.append(signature)
            # Map paint color to target label: 1.0 for visible, 0.0 for invisible [G]
            target = 1.0 if voxel.paint_color == user_sketch.visible_color else 0.0
            targets.append(target)

    # Step 4: Train back-propagation neural network
    # Initialize network weights [Not given in the sources.]
    w1 = initialize_weights(input_dim=len(inputs[0]), hidden_dim=10)
    b1 = [0.0] * 10
    w2 = initialize_weights(input_dim=10, output_dim=1)
    b2 = [0.0]

    # Supervised training loop
    learning_rate = 0.01  # [Not given in the sources.]
    for epoch in range(1000):  # [Not given in the sources.]
        for i in range(len(inputs)):
            # Forward pass
            hidden = [1.0 / (1.0 + math.exp(-sum(w * x for w, x in zip(w1[j], inputs[i])) + b1[j])) for j in range(10)]
            output = 1.0 / (1.0 + math.exp(-sum(w * h for w, h in zip(w2[0], hidden)) + b2[0]))
            # Backward pass
            error = targets[i] - output
            delta_output = error * output * (1.0 - output)
            delta_hidden = [sum(w * delta_output for w in w2[0]) * h * (1.0 - h) for h in hidden]
            # Update weights
            w2[0] = [w + learning_rate * delta_output * h for w, h in zip(w2[0], hidden)]
            b2[0] += learning_rate * delta_output
            w1 = [[w + learning_rate * delta_hidden[j] * x for w, x in zip(row, inputs[i])] for j, row in enumerate(w1)]
            b1 = [b + learning_rate * d for b, d in zip(b1, delta_hidden)]

    # Step 5: Convergence check
    # Training continues until the network finds a specification capable of emphasizing the marked regions [S1, unofficial]
    return {'w1': w1, 'b1': b1, 'w2': w2, 'b2': b2}
```
