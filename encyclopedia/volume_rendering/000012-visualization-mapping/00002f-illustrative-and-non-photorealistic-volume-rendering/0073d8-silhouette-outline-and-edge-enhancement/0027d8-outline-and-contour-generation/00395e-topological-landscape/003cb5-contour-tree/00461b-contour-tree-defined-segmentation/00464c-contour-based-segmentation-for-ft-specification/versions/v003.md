# Contour-Based Segmentation for FT Specification

Also called: Ropinski et al. technique

## Overview
This method uses user-drawn contours to separate portions of a volume before transfer function (FT) specification, allowing manual parameter definition on the isolated region [S1, unofficial]. It sets itself apart from sibling methods by relying on direct geometric separation via 2D sketches rather than topological traversal or learned mappings [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A 3D volume dataset and user-drawn 2D contours [S1, unofficial].
- Output: A transfer function defined for the region enclosed by the contours [S1, unofficial].

**Data Structures:**
- Volume: 3D grid of scalar values [S1, unofficial].
- Contours: 2D closed curves defining the target region [S1, unofficial].
- FT: Mapping from scalar values to opacity and color [S1, unofficial].

**Steps:**
1. User draws contours to separate portions of the volume [S1, unofficial].
2. The desired region is isolated [S1, unofficial].
3. User manually specifies the FT for the isolated region [S1, unofficial].

**Pseudocode:**
```python
def contour_based_ft_specification(volume, contours):
    # Step 1: User draws contours to separate portions of the volume [S1, unofficial]
    # Step 2: The desired region is isolated [S1, unofficial]
    # [G] Creates a 3D boolean mask from 2D contours using point-in-polygon tests.
    mask_3d = create_3d_mask(volume.shape, contours)
    isolated_region = [[[volume[z][y][x] if mask_3d[z][y][x] else 0.0 for x in range(volume.shape[2])] for y in range(volume.shape[1])] for z in range(volume.shape[0])]
    
    # Step 3: User manually specifies the FT for the isolated region [S1, unofficial]
    # [G] The sources do not specify the FT specification interface or data structure.
    ft = specify_ft_interactively(isolated_region)
    return ft

def create_3d_mask(shape, contours):
    mask = [[[False for _ in range(shape[2])] for _ in range(shape[1])] for _ in range(shape[0])]
    for z in range(shape[0]):
        for y in range(shape[1]):
            for x in range(shape[2]):
                for contour in contours:
                    if point_in_polygon(x, y, contour):
                        mask[z][y][x] = True
    return mask

def point_in_polygon(x, y, polygon):
    inside = False
    n = len(polygon)
    for i in range(n):
        x1, y1 = polygon[i]
        x2, y2 = polygon[(i + 1) % n]
        if ((y1 > y) != (y2 > y)) and (x < (x2 - x1) * (y - y1) / (y2 - y1) + x1):
            inside = not inside
    return inside

def specify_ft_interactively(region_data):

    return {"opacity": 1.0, "color": [1.0, 1.0, 1.0]}
```

## Subtopics

### [Neural Network Sketch-Based Specification](11743-neural-network-sketch-based-specification.md)
A technique using a neural network to adjust the transfer function (FT) based on a sketch drawn on a volume visualization, training the network to emphasize marked regions. It implements multidimensional transfer functions as back-propagation neural networks to decide voxel visibility, where training is supervised by user-selected voxels on 2D slices [G]. It sets itself apart from sibling methods by replacing manual parameter tuning or geometric contour separation with a learned mapping from visual sketches to multidimensional visibility decisions[G].
