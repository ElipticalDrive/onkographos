# Hatching and Stroke-based Rendering

Also called: Illustrative Volume Rendering, Pen-and-Ink Volume Rendering

## Overview
Hatching and Stroke-based Rendering is a family of non-photorealistic volume rendering techniques that simulate hand-drawn line art (hatching, strokes, or stippling) to illustrate volumetric features [S1][S2, unofficial]. Unlike photorealistic methods that rely on physical light transport, these methods decouple illumination from physical accuracy, using mathematical functions of view direction, light direction, and scalar field properties to modulate color and line density [S4, unofficial]. This family is distinguished from surface-based NPR by its need to determine feature areas through local volumetric property analysis, as volumetric features vary continuously in 3D space rather than existing as well-defined polygonal meshes [S2, S4, unofficial].

## Shared principles
The family shares the goal of enhancing volume visualization through stylized lighting and feature abstraction [G]. All methods operate on fragment-level data, typically utilizing the volume sample gradient as a proxy for surface normal orientation [G]. They decouple illumination from the physical light transport equation, instead using mathematical functions of the view direction, light direction, and scalar field properties to modulate color [S4, unofficial]. Common inputs include the normalized gradient $\nabla f_n$, light vectors $L$, and base colors derived from transfer functions [G]. The output is a final color $c$ that combines ambient/gaseous components with directed illumination effects [G].

The framework utilizes four types of properties for enhancement:
1. Volume sample location and value [S4, unofficial].
2. Local volumetric properties, such as gradient and minimal change direction [S4, unofficial].
3. View direction [S4, unofficial].
4. Light information [S4, unofficial].

Volumetric illustration differs from surface-based NPR in several important ways [S2, S4, unofficial]. In surface NPR, surfaces (features) are well-defined, whereas with volumes, feature areas within the volume must be determined through analysis of local volumetric properties because volumetric features vary continuously throughout three-dimensional space [S2, S4, unofficial].

## Subtopics

### [Interactive Volume Illustration (Hatching)](5272-interactive-volume-illustration-hatching.md)
An object-space technique for illustrating volumetric data by simulating free-hand line art (hatching) using hardware-assisted volume and line rendering. It highlights curved areas by tracing hatches as polylines over the implicit surface along either a fixed direction or a smoothed principal curvature direction. Unlike geometry-based silhouette approaches that extract edges from polygonal meshes, this method computes silhouettes and curvature cues per-fragment for volumetric data using normal maps and view vectors, allowing for interactive frame rates on consumer hardware.

### [Fast Paint Texture](14343-fast-paint-texture.md)
A technique to simulate 3D paint undulations and overlap shadows on 2D strokes by generating a height field from stroke height maps and overlap counts, rendered via Phong shading, avoiding 3D mesh generation.

### [Visual Complexity (VC) Algorithm](14351-visual-complexity-vc-algorithm.md)
A nonphotorealistic visualization method that places every data element in a single region S0, then applies a painting algorithm with full coverage to create a list of strokes, varying stroke properties (color, size, aspect ratio, contour, contrast) as the list is created to simulate hand-painted visual complexity.

### VolFliesGPU Framework
- **Definition**: An interactive illustrative visualization framework for real-time pen-and-ink style rendering of volume data, based on a particle system [S1].
- **Layout**: Input consists of volume data stored in a 3D texture and proxy geometry comprising a 3D grid of equally spaced vertices [S1].
- **Usage**: Uses the VolumeFlies hidden surface removal filter: the iso-surface is splatted with uniquely colored cones generated by the geometry shader; particle visibility is determined by an off-screen framebuffer [S1].

### Non-photorealistic Volume Rendering via Point Sampling
- **Definition**: A methodology for sampling and rendering 3D volume data to simulate classical ink-and-paint non-photorealistic styles, addressing the lack of artist-friendly NPR volume rendering tools [S2, unofficial].
- **Steps**:
    1. Scatter point data within the 3D volume data based on density values, or create a custom point cloud [S2, unofficial].
    2. Ray cast from the camera to the hit position of the volume [S2, unofficial].
    3. From the ray's hit position, cast a secondary ray towards a direction, either towards a light source for shading or continuing in the same direction for a headlamp effect [S2, unofficial].
    4. Tally and normalize the number of scattered points found within a radius of the direction of the secondary ray [S2, unofficial].
    5. Interpolate between the lit color of the volume and the background color using the normalized value from the previous step [S2, unofficial].

### Curved Strokes
- **Definition**: A method to render strokes as Bézier curves with control points positioned based on data attribute orientations [S3].
- **Steps**:
    1. Query data attribute values at three sample points $s_0, s_1, s_2$. Compute associated orientations $\theta_0, \theta_1, \theta_2$ to position control points $A, B, C, D$ [S3].
    2. Place control points so that segment $BC$ has orientation $\theta_0$, $AB$ has orientation $\theta_1$, and $CD$ has orientation $\theta_2$ [S3].
    3. If $\max(d_1, d_2)$ is large, draw the stroke as a curve; otherwise, likely draw as linear segments (implied by contrast with 'draw stroke as a curve') [S3].

### Variegation
- **Definition**: A technique to simulate paint variation by drawing strokes as three quadrilaterals with varying colors and widths [S3].
- **Steps**:
    1. Sample center color $C=(R,G,B)$ and length $l$, width $w$. Vary $C$ to $C_1, C_2$ in small interval. Vary $w$ to $w_1, w_2$ such that $0 \le w_1, w_2 < w/8$ [S3].
    2. Draw $q$ centered on sample with length $l$, width $w-(w_1+w_2)$, color $C$. Draw $q_1$ next to $q$ with length $l$, width $w_1$, color $C_1$. Draw $q_2$ opposite $q_1$ with length $l$, width $w_2$, color $C_2$ [S3].

## Background
The family originates from the need to bridge the gap between realistic volume rendering and artistic, hand-drawn styles. Early work by Busking et al. [BVvW07] established the foundation for particle-based illustrative rendering, which was later expanded into the VolFliesGPU framework for real-time GPGPU-based pen-and-ink rendering [S1]. Subsequent research explored point sampling methods to simulate classical ink-and-paint techniques [S2, unofficial] and advanced stroke generation techniques such as curved strokes and variegation to increase visual complexity and detail [S3]. These methods are used in scientific visualization and medical imaging to enhance feature perception and provide an aesthetic, illustrative quality to volumetric data.
