# Fake Media Methods

Also called: Appearance-based methods, Non-physically based methods

## Overview
Fake media methods are rendering techniques that do not account for the physical phenomena of light transport but instead generate visually pleasant, realistic appearances suitable for applications where physical accuracy is not required [S1]. They differ from physically based volume rendering by decoupling illumination from the radiative transfer equation, relying on empirical models, texture synthesis, or simplified analytical solutions to achieve specific aesthetic goals [S1]. Unlike surface-based non-photorealistic rendering, these methods must determine volumetric features through local property analysis, as features vary continuously in 3D space [S2, S4, unofficial].

## How it works
Fake media methods encompass a diverse set of approaches, ranging from procedural texture generation to simplified analytical integration. The specific implementation depends on the target medium (clouds, water, fog) and the desired level of realism.

### Inputs and Outputs
*   **Inputs:** View direction, light direction, scalar field values (e.g., density), and pre-defined empirical parameters (e.g., attenuation coefficients, noise seeds).
*   **Outputs:** Final color $c$ for each pixel or fragment.

### Data Structures
The data structures vary by method:
1.  **Procedural Models (Gardner, Perlin):** No explicit volumetric grid is required. Noise functions and mathematical primitives (ellipsoids) are evaluated on-the-fly.
2.  **Analytical Models (Premoze & Ashikmin, Biri):** Require integration along the view ray. For Biri's fog, the extinction coefficient $\kappa_t$ is defined as a function allowing analytical integration.

### Algorithms and Formulas

#### 1. Gardner’s Cloud Model [S1]
Gardner generates synthetic clouds using a hybrid 2D/3D approach.
*   **2D Model:** Uses a sky plane positioned far from the viewer.
*   **3D Model:** Uses ellipsoids and a mathematical function to generate textures.
*   **Implementation:** Evaluate the mathematical function at the intersection of the view ray and the ellipsoid/sky plane to determine color and opacity.

#### 2. Perlin’s Procedural Media [S1]
Perlin uses a "Pixel Stream Editing" language based on noise and turbulence functions to create representations of clouds, fire, water, and marble.
*   **Implementation:** Evaluate noise functions $N(x, y, z)$ and turbulence functions $T(x, y, z)$ to modulate color and opacity along the ray.

#### 3. Yaeger et al.’s Atmospheric Simulation [S1]
Used for simulating Jupiter’s atmosphere in the film *2010*.
*   **Method:** Mixes physical fluid dynamics simulation for flow fields with visual simulation using a 2D particle model.
*   **Mapping:** Textures generated from the particle model are mapped onto a polygonalized sphere.
*   **Assumption:** The observer is far from the planet; the atmosphere is treated as opaque. No participating media treatment is applied.

#### 4. Premoze and Ashikmin’s Water Model [S1]
This model simplifies light transport in water by assuming radiance depends only on depth $z$. It does not simulate scattering radiance explicitly but uses an empirical diffuse field.
*   **Formula:**
    $$ L(0) = e^{-\kappa_t R} L(z) + \left(1 - e^{-(\kappa_t + \kappa_d \cos \theta)R}\right) L_{df}(0) $$
*   **Definitions:**
    *   $L(0)$: Apparent radiance just below the air-water interface.
    *   $L(z)$: Radiance of the target at depth $z$.
    *   $R$: Total path length, calculated as $R = -z / \cos \theta$.
    *   $\theta$: Angle counted from the vertical direction (positive z-axis).
    *   $\kappa_t$: Extinction coefficient.
    *   $\kappa_d$: Apparent water diffuse attenuation coefficient.
    *   $L_{df}(0)$: Diffused radiance just below the sea surface, estimated using empirical equations relating it to downwelling irradiance from the sun and skylight.

#### 5. Biri et al.’s Real-Time Fog Model [S1]
Designed for real-time animation, this model uses well-chosen functions for the extinction coefficient $\kappa_t$ that allow analytical integration.
*   **Formula:**
    $$ L(x) = \tau(x_0, x) L(x_0) + (1 - \tau(x_0, x)) J_{fog} $$
*   **Definitions:**
    *   $L(x)$: Radiance at position $x$.
    *   $L(x_0)$: Radiance at the entry point $x_0$.
    *   $\tau(x_0, x)$: Transmittance from $x_0$ to $x$, computed efficiently due to the specific definition of $\kappa_t$.
    *   $J_{fog}$: Constant source radiance within the fog.

### Pseudocode
The following pseudocode illustrates the general structure for a fake media method using an analytical integration approach (similar to Biri et al.), as procedural methods (Gardner, Perlin) are function-evaluation based.

```python
def render_fake_media(ray_origin, ray_direction, scene_params):
    """
    Renders a fake media scene using analytical integration.
    Assumes a medium with constant or analytically integrable extinction.
    """
    # 1. Determine entry and exit points of the ray through the medium
    # [G] Standard ray-box or ray-sphere intersection logic required here.
    t_min, t_max = compute_intersection(ray_origin, ray_direction, scene_params.bounds)
    
    if t_max < 0:
        return scene_params.background_color

    # 2. Compute transmittance and accumulated color
    # For Biri's fog: tau(x0, x) = exp(-integral(kappa_t * ds))
    # If kappa_t is constant: tau = exp(-kappa_t * distance)
    
    distance = t_max - t_min
    kappa_t = scene_params.extinction_coefficient
    
    # Analytical transmittance calculation
    transmittance = exp(-kappa_t * distance)
    
    # 3. Compute in-scattered light (Jfog)
    # [G] Jfog is typically a constant or function of light direction/view
    in_scattered_radiance = compute_fog_source_radiance(scene_params)
    
    # 4. Compute background radiance seen through the medium
    background_radiance = trace_ray_to_background(ray_origin, ray_direction, scene_params)
    
    # 5. Composite using the fake media equation
    # L(x) = tau * L(x0) + (1 - tau) * Jfog
    final_color = transmittance * background_radiance + \
                  (1.0 - transmittance) * in_scattered_radiance
                  
    return final_color

def compute_water_radiance(view_ray, depth_z, theta, kappa_t, kappa_d, sun_irradiance):
    """
    Implements Premoze and Ashikmin's water model.
    """
    # Calculate path length R
    # theta is angle from vertical (z-axis)
    cos_theta = cos(theta)
    if abs(cos_theta) < 1e-6:
        return BLACK # Avoid division by zero for horizontal rays
    
    R = -depth_z / cos_theta
    
    # Calculate diffuse field radiance Ldf(0) empirically
    # [G] Specific empirical equations depend on sun position and water type
    Ldf_0 = compute_empirical_diffuse_radiance(sun_irradiance)
    
    # Target radiance L(z) at depth z
    # [G] This might be the background or objects below water
    L_z = trace_ray_to_target(depth_z, view_ray)
    
    # Apply formula: L(0) = e^(-kappa_t * R) * L(z) + (1 - e^(-(kappa_t + kappa_d * cos_theta) * R)) * Ldf(0)
    term1 = exp(-kappa_t * R) * L_z
    term2_coeff = 1.0 - exp(-(kappa_t + kappa_d * cos_theta) * R)
    term2 = term2_coeff * Ldf_0
    
    return term1 + term2
```

### Edge Cases and Pitfalls
*   **Shadowing:** Fake media methods are generally not suited for proper self-shadowing or shadows cast by the medium [S1]. Texture-based methods (Gardner, Perlin, Yaeger) focus on modeling the medium but not its interaction with the scene [S1]. Analytical methods (Premoze & Ashikmin, Biri) use color blending without integrating the fog/medium into a global illumination scheme, thus ignoring shadows [S1].
*   **Atmospheric Opacity:** Yaeger et al.'s method assumes the atmosphere is opaque because the observer is restricted to being far away from the planet [S1].
*   **Dimensionality:** Premoze and Ashikmin's model assumes a one-dimensional dependency (depth only), which limits its applicability to scenes where lateral variations are negligible or handled separately [S1].

## Operating characteristics
*   **Performance:** These methods are generally computationally inexpensive compared to physically based path tracing or even single-scattering approximations. Biri et al.'s method achieves real-time animation by using functions for $\kappa_t$ that allow analytical integration [S1].
*   **Realism:** They produce "visually pleasant" results that can appear realistic in specific contexts (e.g., clouds, fog, water surfaces) but lack physical correctness [S1].
*   **Limitations:** Inability to handle complex light transport effects such as multiple scattering, self-shadowing, and dynamic shadow casting [S1].
*   **Use Cases:** Applications where physical accuracy is not required, such as stylized visualization, real-time games, or specific cinematic effects where aesthetic control is prioritized over physical fidelity [S1].

## Background
The term "fake media methods" was coined in the context of participating media rendering surveys to categorize techniques that prioritize appearance over physical accuracy [S1].
*   **Gardner [25]:** Developed early models for synthetic clouds using 2D sky planes and 3D ellipsoids.
*   **Perlin [71]:** Introduced procedural noise and turbulence functions for a wide range of natural phenomena.
*   **Yaeger et al. [107]:** Applied fluid dynamics and particle systems to simulate Jupiter's atmosphere for the film *2010*.
*   **Premoze and Ashikmin [73]:** Focused on the appearance of water surfaces, simplifying light transport to a 1D depth-dependent model.
*   **Biri et al. [8]:** Extended analytical integration techniques for real-time fog rendering.
