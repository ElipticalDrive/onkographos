# Pilot Network


## Overview
The Pilot Network is an auxiliary training mechanism used in Volume Feature Rendering (VFR) to stabilize the convergence of neural radiance fields during the early stages of training [S1][S2, unofficial]. It solves the problem of convergence failure in scenes with complex geometry (e.g., the 'ship' scene from the NeRF synthetic dataset) when using large neural networks [S1][S2, unofficial]. Unlike the main VFR framework, which integrates features from all samples along a ray before passing them to a large network, the Pilot Network performs standard volume rendering by evaluating a small network for each sample individually [S1][S2, unofficial]. This approach helps the model find coarse geometry before switching to the main VFR framework [S1][S2, unofficial].

## How it works
The Pilot Network is a small, temporary neural network used exclusively during the initial phase of training [S1][S2, unofficial]. It is discarded after a fixed number of training steps, after which the main VFR framework takes over [S1][S2, unofficial].

### Inputs and Outputs
*   **Inputs:** The input to the Pilot Network is the feature vector $F(x_i)$ and the view direction $d$ for a specific sample point $x_i$ along a ray [S1].
*   **Outputs:** The output is the predicted color contribution $C_i$ for that specific sample [S1].

### Data Structures
The Pilot Network is a Multi-Layer Perceptron (MLP) with the following architecture [S1][S2, unofficial]:
*   **Hidden Layers:** 2 hidden layers.
*   **Neurons per Layer:** 64 neurons per hidden layer.
*   **Activation:** Not specified in the sources [G]. Standard practice implies ReLU or similar, but not explicitly stated.
*   **Output Layer:** Produces color values (RGB).

### Numbered Steps
1.  **Initialization:** Initialize the Pilot Network with 2 hidden layers, each containing 64 neurons [S1][S2, unofficial].
2.  **Early Training (Steps 1–300):**
    *   For each ray, sample points $x_i$ along the ray.
    *   For each sample point $x_i$, compute its feature vector $F(x_i)$ [S1].
    *   Pass $F(x_i)$ and the view direction $d$ into the Pilot Network to predict the color contribution $C_i$ for that sample [S1].
    *   Compute the final ray color $C(r)$ using standard volume rendering integration:
        $$ C(r) = \sum_i w_i \text{PilotNet}(F(x_i), d) $$
        where $w_i$ are the standard volume rendering weights (based on opacity and transmittance) [S1].
3.  **Switch to Main Framework (Step 301+):**
    *   Discard the Pilot Network [S1][S2, unofficial].
    *   Switch to the main VFR framework, which uses a larger network (e.g., 4 hidden layers) [S1][S2, unofficial].
    *   The main framework integrates features from all samples along the ray before passing the aggregated feature to the large network [S1][S2, unofficial].

### Parameters
*   **Pilot Network Architecture:** 2 hidden layers, 64 neurons each [S1][S2, unofficial].
*   **Pilot Network Duration:** 300 training steps [S1][S2, unofficial].
*   **Total Training Steps:** Approximately 20,000 steps (the pilot phase is negligible in duration) [S1].

### Edge Cases and Pitfalls
*   **Convergence Failure:** Without the Pilot Network, VFR fails to converge on certain scenes (e.g., 'ship') when using large neural networks (e.g., 4 hidden layers) [S1][S2, unofficial]. This is attributed to the model's inability to find correct geometry due to feature integration of all samples (including empty space) in the early training stage [S1][S2, unofficial].
*   **Network Size:** The convergence failure is more likely to occur with comparably large neural networks [S1][S2, unofficial]. The standard VFR converges with a smaller network (2 hidden layers, 256 neurons) but fails with larger ones without the Pilot Network [S1][S2, unofficial].

### Pseudocode
```python
def train_vfr_with_pilot_network(total_steps=20000, pilot_steps=300):
    # Initialize main VFR network (large, e.g., 4 hidden layers)
    main_net = LargeNetwork()
    
    # Initialize Pilot Network (small, 2 hidden layers, 64 neurons)
    pilot_net = SmallNetwork(hidden_layers=2, neurons_per_layer=64)
    
    for step in range(1, total_steps + 1):
        # Sample rays and points
        rays, points, features, view_dirs = sample_data()
        
        if step <= pilot_steps:
            # Use Pilot Network for standard volume rendering
            # Evaluate network for each sample individually
            color_contributions = []
            for i in range(len(points)):
                # PilotNet takes feature vector and view direction
                c_i = pilot_net(features[i], view_dirs[i])
                color_contributions.append(c_i)
            
            # Standard volume rendering integration
            # weights are computed based on opacity/transmittance
            final_color = integrate_standard(color_contributions, weights)
            
            # Compute loss and update Pilot Network
            loss = compute_loss(final_color, target_color)
            update(pilot_net, loss)
            
        else:
            # Switch to Main VFR framework
            # Discard Pilot Network
            pilot_net = None
            
            # Integrate features from all samples along the ray
            aggregated_feature = integrate_features(features, weights)
            
            # Pass aggregated feature to large network
            final_color = main_net(aggregated_feature, view_dirs)
            
            # Compute loss and update Main Network
            loss = compute_loss(final_color, target_color)
            update(main_net, loss)
```

## Operating characteristics
*   **Time Complexity:** The Pilot Network adds negligible overhead to the total training time because it is only used for a small number of steps (300 out of ~20,000) [S1].
*   **Memory Complexity:** The Pilot Network is small (2 hidden layers, 64 neurons), so its memory footprint is minimal [S1][S2, unofficial].
*   **Strengths:** Stabilizes training for large neural networks in VFR, preventing convergence failure on complex scenes [S1][S2, unofficial].
*   **Limitations:** Only applicable during the early training phase; requires switching networks after a fixed number of steps [S1][S2, unofficial].
*   **When to Use:** When using large neural networks (e.g., 4 hidden layers) in VFR and experiencing convergence issues on complex scenes [S1][S2, unofficial].
*   **When Not to Use:** When using smaller neural networks that converge reliably without the Pilot Network [S1][S2, unofficial].

## Background
The Pilot Network was introduced in the paper "Volume Feature Rendering for Fast Neural Radiance Field Reconstruction" [S1][S2, unofficial]. It was designed to address convergence issues observed when scaling up the neural network size in the VFR framework [S1][S2, unofficial]. The authors hypothesized that the failure was due to the integration of features from all samples (including empty space) in the early training stage, which prevented the model from finding correct geometry [S1][S2, unofficial]. The Pilot Network was tested on the NeRF synthetic dataset, specifically the 'ship' scene, which was prone to convergence failure [S1][S2, unofficial].
