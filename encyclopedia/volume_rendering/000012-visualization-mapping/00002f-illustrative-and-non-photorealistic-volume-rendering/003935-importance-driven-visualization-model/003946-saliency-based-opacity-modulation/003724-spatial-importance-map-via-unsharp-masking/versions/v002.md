# Spatial Importance Map via Unsharp Masking

Also called: Gaussian Blur Difference Map, Intensity Filtering, Intensity-based Saliency Map, Spatial Importance Map Computation, Unsharp Masking for Volume

## Overview
This method computes a 3D spatial importance map by subtracting the original volume intensity values from a low-pass filtered (blurred) version of itself, effectively creating an unsharp mask [S1, unofficial]. It captures salient boundary and separability information to modulate color and opacity in illustrative volume rendering, distinguishing itself from radiance-based saliency methods by relying solely on input intensity, which allows it to be computed as a preprocessing step independent of lighting and transfer functions [S1, unofficial].

## How it works
**Inputs and Outputs**
- **Input:** A scalar volume model $V: \mathbb{N}^3 \rightarrow \mathbb{Z}$, where $\mathbb{Z}$ represents the scalar intensity values of the voxels [S1, unofficial].
- **Output:** A spatial importance map $\Delta D$, a 3D volume of the same dimensions as $V$, containing signed values representing boundary saliency [S1, unofficial].

**Data Structures**
- **Volume Data:** Stored as a 3D array of floating-point values for computation [S1, unofficial].
- **Gaussian Kernel:** A 1D array of normalized weights sampled from the Gaussian function, clamped to a specific radius [S1, unofficial].

**Parameters**
- **Radius ($R$):** The spatial extent of the Gaussian kernel in voxels. Typical values used in implementations are 5 and 10 [S1, unofficial].
- **Standard Deviation ($\sigma$):** Controls the spread of the Gaussian blur. It is defined as one-third of the radius: $\sigma = R / 3$ [S1, unofficial].

**Formulas**
The spatial importance map is computed as:
$$ \Delta D = G * V - V $$
where $G * V$ is the Gaussian blur of the volume [S1, unofficial].

The 1D Gaussian function is defined as:
$$ G(x) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{x^2}{2\sigma^2}} $$
where $x$ is the distance from the origin and $\sigma$ is the standard deviation [S1, unofficial].

In 3D, the Gaussian kernel $G$ is the product of three 1D Gaussians, one for each axis [S1, unofficial].

**Steps**
1. **Preprocessing:** Convert the input volume data $V$ to floating-point values [S1, unofficial].
2. **Kernel Generation:** Determine the kernel radius $R$ and calculate $\sigma = R / 3$ [S1, unofficial]. Clamp the Gaussian kernel at a distance of $3\sigma$ from the center, as values further than this are negligible [S1, unofficial]. Sample the 1D Gaussian function at the center of each voxel within the radius, then normalize the weights so that they sum to 1 [S1, unofficial].
3. **Separable Filtering:** Compute the blurred volume $G * V$ by exploiting the separability of the Gaussian function. This requires three consecutive 1D convolutions: convolve $V$ with the 1D kernel along the X-axis, then convolve the result along the Y-axis, and finally convolve that result along the Z-axis [S1, unofficial].
4. **Subtraction:** Compute the spatial importance map $\Delta D$ by subtracting the original volume from the blurred volume for each voxel:
   $$ \Delta D[i, j, k] = (G * V)[i, j, k] - V[i, j, k] $$
   [S1, unofficial].

**Pseudocode**
```python
import math

def compute_spatial_importance_map(volume: list[list[list[float]]], radius: int) -> list[list[list[float]]]:
    """
    Computes the spatial importance map using unsharp masking via separable Gaussian filtering.
    
    Args:
        volume: 3D list of floats representing the input volume V.
        radius: Integer radius R for the Gaussian kernel.
        
    Returns:
        3D list of floats representing the spatial importance map Delta D.
    """
    # 1. Prepare volume data (assumed already float)
    
    # 2. Generate 1D Gaussian Kernel
    sigma = radius / 3.0
    kernel_size = 2 * radius + 1
    kernel = []
    sum_weights = 0.0
    
    for x in range(-radius, radius + 1):
        weight = (1.0 / math.sqrt(2.0 * math.pi * sigma * sigma)) * math.exp(-(x * x) / (2.0 * sigma * sigma))
        kernel.append(weight)
        sum_weights += weight
        
    # Normalize kernel so it sums to 1
    kernel = [w / sum_weights for w in kernel]
    
    # 3. Separable Filtering
    dim_x = len(volume)
    dim_y = len(volume[0])
    dim_z = len(volume[0][0])
    
    # Allocate intermediate volumes
    v_xy = [[[0.0] * dim_z for _ in range(dim_y)] for _ in range(dim_x)]
    v_xyz = [[[0.0] * dim_z for _ in range(dim_y)] for _ in range(dim_x)]
    v_blur = [[[0.0] * dim_z for _ in range(dim_y)] for _ in range(dim_x)]
    
    # Convolve along X-axis
    for y in range(dim_y):
        for z in range(dim_z):
            for x in range(dim_x):
                sum_val = 0.0
                for k in range(-radius, radius + 1):
                    x_neighbor = x + k
                    if x_neighbor < 0:
                        x_neighbor = 0
                    elif x_neighbor >= dim_x:
                        x_neighbor = dim_x - 1
                    sum_val += volume[x_neighbor][y][z] * kernel[k + radius]
                v_xy[x][y][z] = sum_val

    # Convolve along Y-axis
    for x in range(dim_x):
        for z in range(dim_z):
            for y in range(dim_y):
                sum_val = 0.0
                for k in range(-radius, radius + 1):
                    y_neighbor = y + k
                    if y_neighbor < 0:
                        y_neighbor = 0
                    elif y_neighbor >= dim_y:
                        y_neighbor = dim_y - 1
                    sum_val += v_xy[x][y_neighbor][z] * kernel[k + radius]
                v_xyz[x][y][z] = sum_val

    # Convolve along Z-axis
    for x in range(dim_x):
        for y in range(dim_y):
            for z in range(dim_z):
                sum_val = 0.0
                for k in range(-radius, radius + 1):
                    z_neighbor = z + k
                    if z_neighbor < 0:
                        z_neighbor = 0
                    elif z_neighbor >= dim_z:
                        z_neighbor = dim_z - 1
                    sum_val += v_xyz[x][y][z_neighbor] * kernel[k + radius]
                v_blur[x][y][z] = sum_val

    # 4. Subtraction
    delta_d = [[[0.0] * dim_z for _ in range(dim_y)] for _ in range(dim_x)]
    
    for x in range(dim_x):
        for y in range(dim_y):
            for z in range(dim_z):
                delta_d[x][y][z] = v_blur[x][y][z] - volume[x][y][z]
                
    return delta_d
```

**Edge Cases and Pitfalls**
- **Boundary Voxels:** Boundary voxels have non-zero importance values because the blurred volume smooths boundaries, creating intensity differences compared to the original [S1, unofficial]. Implementation must handle boundary conditions (e.g., clamping) during convolution [G].
- **Memory Usage:** Using radiance instead of intensity would require significantly more memory. This method uses original intensity values to minimize memory requirements and remain independent of the transfer function and lighting [S1, unofficial].
- **Sign Interpretation:** Positive values in $\Delta D$ indicate voxels near boundaries with higher density material (intensity increased in blur relative to original), while negative values indicate boundaries with lower density material (intensity decreased in blur relative to original) [S1, unofficial].

- **Strengths:** Interactive rates achievable with GPU implementations (CUDA); independent of lighting and transfer functions; low memory footprint compared to radiance-based methods [S1, unofficial].
- **Limitations:** Relies on intensity values rather than radiance or gradient-based metrics [S1, unofficial].
- **When to use:** As a preprocessing step for illustrative volume rendering to modulate color and opacity based on boundary saliency [S1, unofficial].

## Background
The method was proposed by Marc Ruiz, Imma Boada, Miquel Feixas, and Mateu Sbert from the Graphics and Imaging Laboratory, Universitat de Girona, Spain [S1, unofficial]. It extends the spatial importance function $\Delta D$ proposed by Luft [LCD06] to 3D volumes [S1, unofficial]. The approach was presented in the context of interactive volume illustration, aiming to enhance perceptual quality and interpretation by modulating color and opacity based on boundary saliency [S1, unofficial]. It contrasts with methods like Tao et al. [TLB*09] that use radiance, arguing for the efficiency and preprocessing capability of using intensity [S1, unofficial].
