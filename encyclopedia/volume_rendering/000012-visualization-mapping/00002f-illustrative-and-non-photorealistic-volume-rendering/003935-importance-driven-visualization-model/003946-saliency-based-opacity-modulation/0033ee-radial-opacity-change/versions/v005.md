# Radial Opacity Change

Also called: Angular velocity metaphor opacity, Distance-based opacity modulation

## Overview
Radial Opacity Change is an illustrative volume rendering technique that modulates voxel opacity based on radial distance from a reference point to create a focus+context effect during user interaction [S1, S2, S3, unofficial]. It reveals inner structures by making peripheral voxels more transparent, inspired by the physics of viscous rotation [S3, unofficial].

## How it works
**Inputs:**
- Voxel position $\vec{P}_{voxel}$ in object space [S1, S2, S3, unofficial].
- Reference center position $\vec{P}_{center}$ [S1, S2, S3, unofficial].
- Style function $S(t)$, a scalar representing interaction intensity (e.g., angular velocity) [S1, S2, unofficial].
- Optional focus point $\vec{P}_{focus}$ for zooming semantics [S2, unofficial].

**Outputs:**
- Modulated opacity $\alpha_{voxel}$ [S1, unofficial].

**Data Structures:**
- Not given in the sources. Standard volume grid access is assumed [G].

**Steps:**
1. Calculate the Euclidean distance $\rho(\vec{P}_{voxel}, \vec{P}_{center})$ from the voxel to the reference center [S1, unofficial].
2. Retrieve the interaction intensity $S(t)$ [S1, S2, unofficial].
3. Compute the modulated opacity using the exponential decay formula [S1, S2, unofficial].

**Formulas:**
For standard rotation or center-based modulation [S1, S2, S3, unofficial]:
$$ \alpha_{voxel} = e^{-S(t) \cdot \rho(\vec{P}_{voxel}, \vec{P}_{center})} $$

For zooming interaction, where the transparency gradient shifts to a user-defined focus point [S2, unofficial]:
$$ \alpha_{voxel} = e^{-S(t) \cdot \max(0, \rho(\vec{P}_{voxel}, \vec{P}_{center}) - \rho(\vec{P}_{voxel}, \vec{P}_{focus}))} $$

**Parameters:**
- $S(t)$: Style function controlling modulation strength [S1, S2, unofficial].
- $\rho(\vec{P}_{voxel}, \vec{P}_{center})$: Distance from voxel to center [S1, unofficial].
- $\vec{P}_{focus}$: Initial point of interaction on the object for zooming [S2, unofficial].

**Pseudocode:**
```python
import math

def compute_radial_opacity(voxel_pos, center_pos, style_function, focus_pos=None):
    dx = voxel_pos[0] - center_pos[0]
    dy = voxel_pos[1] - center_pos[1]
    dz = voxel_pos[2] - center_pos[2]
    rho_center = math.sqrt(dx*dx + dy*dy + dz*dz)
    
    if focus_pos is None:
        exponent = -style_function * rho_center
    else:
        fx = voxel_pos[0] - focus_pos[0]
        fy = voxel_pos[1] - focus_pos[1]
        fz = voxel_pos[2] - focus_pos[2]
        rho_focus = math.sqrt(fx*fx + fy*fy + fz*fz)
        distance_diff = rho_center - rho_focus
        if distance_diff < 0:
            distance_diff = 0
        exponent = -style_function * distance_diff
        
    alpha = math.exp(exponent)
    return alpha
```

**Edge Cases and Pitfalls:**
- **Precision:** If $S(t)$ and $\rho$ are large, the exponent underflows to $-\infty$, yielding $\alpha_{voxel}=0$. This is expected behavior [G].
- **Boundary Conditions:** The formula assumes $\vec{P}_{center}$ is well-defined. For non-convex or disconnected volumes, the geometric center may lie outside the data, producing unintuitive transparency gradients [G].
- **Zooming Logic:** The $\max(0, \rho_{center} - \rho_{focus})$ term ensures voxels closer to the focus point than the center receive zero exponent (opacity 1), leaving context untouched while revealing inner parts near the focus [S2, unofficial].

## Subtopics

### [Radial Opacity Change (Zooming)](14595-radial-opacity-change-zooming.md)
Radial Opacity Change (Zooming) is an illustrative volume rendering technique that reveals inner structures by modulating voxel opacity based on the distance from a user-defined focus point, rather than the distance from the volume center. Unlike its sibling [Radial Opacity Change](7140-radial-opacity-change.md), which uses angular velocity and distance from the center to create a "tunnel" effect during rotation, this method shifts the transparency gradient to follow the user's interaction point, allowing for detailed inspection of specific regions while maintaining context elsewhere [14595-radial-opacity-change-zooming.md].

### Depth Opacity-Modulation
Depth Opacity-Modulation is a technique to ensure visibility of voxels at the back of an atomic structure by modulating opacity based on depth, preventing self-occlusion from hiding rear features [S4]. It is chosen when rendering complex atomic structures where rear features are frequently occluded by front features [S4].

**Formula:**
$$ \alpha_v = \begin{cases} Z(v), & \text{if } Z(v) \le 1 \\ 1, & \text{otherwise} \end{cases} $$
where
$$ Z(v) = \alpha_s \cdot G(g_v) \cdot r^{d_v - d_{min}(s)} $$

**Parameters:**
- $\alpha_v$: Opacity of voxel $v$ [S4].
- $\alpha_s$: Seed opacity value for the atomic structure $s$, provided by a genetic algorithm [S4].
- $G(g_v)$: Monotonically-increasing gradient magnitude opacity-modulation function mapping gradient magnitudes $g_v$ to opacity-modulation factors [S4].
- $d_v$: Depth value of voxel $v$ [S4].
- $d_{min}(s)$: Minimum depth of all voxels in the atomic structure $s$ [S4].
- $r$: Depth opacity-modulation rate, controlling the influence of voxel depth in modulation [S4].

**Pitfalls:**
- Voxels with high depth values (back side) are assigned high opacity to ensure visibility even if occluded by low depth voxels (front side) [S4].

## Operating characteristics
- **Time Complexity:** $O(1)$ per voxel/sample, involving basic arithmetic and exponential evaluation [G].
- **Memory Complexity:** $O(1)$ auxiliary memory per voxel; no additional large data structures are required [G].
- **Measured Performance:** Not given in the sources. Standard GPU/CPU exponential evaluation applies [G].
- **Scaling:** Not given in the sources. Performance scales linearly with voxel/sample count [G].
- **Strengths:** Effective for dynamic focus+context visualization during interaction; naturally reveals inner structures without complex preprocessing [S1, S2, unofficial].
- **Limitations:** The "angular velocity" metaphor may not intuitively map to all interaction types (e.g., panning); the choice of center point can be arbitrary for complex shapes [G].
- **When to use:** When the goal is to dynamically reveal internal structures during rotation or zooming in a volume visualization [S1, S2, unofficial].
- **When not to use:** When precise quantitative analysis of outer structures is required, as they are intentionally made transparent [G].

## Background
The Radial Opacity Change technique was proposed by Sikachev, Rautek, Bruckner, and Gröller in 2010 as part of a dynamic focus+context framework for volume rendering [S1, S2, S3, unofficial]. It is inspired by the metaphor of a viscous fluid rotating around its center, where particles at the border have the highest speed and are candidates to disappear [S3, unofficial]. The method was designed to aid users in exploring data efficiently and detecting unknown features during interaction [S1, unofficial]. It is often used in conjunction with DVR-MIP interpolation to enhance the visual feedback during user interaction [S1, S2, unofficial].
