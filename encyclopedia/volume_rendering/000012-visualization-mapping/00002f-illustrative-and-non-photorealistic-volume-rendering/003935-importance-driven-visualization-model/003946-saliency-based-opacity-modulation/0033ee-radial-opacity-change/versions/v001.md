# Radial Opacity Change

Also called: Angular velocity metaphor opacity, Distance-based opacity modulation

## Overview
Radial Opacity Change is a dynamic focus+context technique that modulates voxel opacity based on the distance from a central reference point, inspired by the angular velocity of a viscous fluid rotating around its center [S1, unofficial]. It solves the problem of occlusion in volume rendering by making voxels further from the center more transparent, thereby revealing inner structures during rotation or zooming interactions [S1, unofficial]. Unlike static saliency methods, it adapts opacity in real-time to user interaction, specifically distinguishing between global rotation (center-based) and local zooming (focus-based) [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Voxel position $\vec{P}_{voxel}$, object center $\vec{P}_{center}$, interaction focus point $\vec{P}_{focus}$ (optional), style function value $S(t)$ derived from previous saliency steps [S1, unofficial].
- Output: Modulated opacity $\alpha_{voxel}$ for each voxel [S1, unofficial].

**Data Structures:**
- The method requires access to the spatial coordinates of each voxel and the current interaction state (center and focus points) [S1, unofficial].
- $S(t)$ is a scalar value obtained from the preceding saliency computation step [S1, unofficial].

**Formulas:**
1.  **Rotation Mode:**
    $$ \alpha_{voxel} = e^{-S(t) \cdot \rho(\vec{P}_{voxel}, \vec{P}_{center})} $$
    Where:
    - $\alpha_{voxel}$ is the resulting opacity [S1, unofficial].
    - $S(t)$ is the style function (exponent) [S1, unofficial].
    - $\rho(\vec{P}_{voxel}, \vec{P}_{center})$ is the Euclidean distance from the voxel to the center of the object [S1, unofficial].
    - As distance increases, opacity decreases exponentially, revealing inner parts [S1, unofficial].

2.  **Zooming Mode:**
    $$ \alpha_{voxel} = e^{-S(t) \cdot \max(0, \rho(\vec{P}_{voxel}, \vec{P}_{center}) - \rho(\vec{P}_{voxel}, \vec{P}_{focus}))} $$
    Where:
    - $\vec{P}_{focus}$ denotes the initial point of interaction on the object [S1, unofficial].
    - The term $\rho(\vec{P}_{voxel}, \vec{P}_{focus})$ creates a local visibility boost near the focus point, leaving the surrounding context opacity unchanged [S1, unofficial].

**Pseudocode:**
```python
def compute_radial_opacity(voxel_pos, center_pos, focus_pos, style_func, interaction_mode):
    """
    Computes opacity based on radial distance.
    
    Args:
        voxel_pos: (x, y, z) coordinates of the current voxel.
        center_pos: (x, y, z) coordinates of the object center.
        focus_pos: (x, y, z) coordinates of the interaction focus point.
        style_func: Scalar value S(t) from saliency step.
        interaction_mode: String, either 'rotation' or 'zooming'.
        
    Returns:
        float: Modulated opacity alpha.
    """
    # Calculate distance to center
    dist_to_center = distance(voxel_pos, center_pos)
    
    if interaction_mode == 'rotation':
        # Standard radial fade based on distance from center
        exponent = style_func * dist_to_center
        alpha = math.exp(-exponent)
        
    elif interaction_mode == 'zooming':
        # Calculate distance to focus point
        dist_to_focus = distance(voxel_pos, focus_pos)
        
        # Calculate relative distance factor
        # max(0, ...) ensures non-negative contribution
        relative_dist = max(0, dist_to_center - dist_to_focus)
        
        exponent = style_func * relative_dist
        alpha = math.exp(-exponent)
        
    else:
        # Fallback if mode is undefined or invalid
        alpha = 1.0
        
    return alpha

def distance(p1, p2):
    """Euclidean distance between two 3D points."""
    dx = p1[0] - p2[0]
    dy = p1[1] - p2[1]
    dz = p1[2] - p2[2]
    return math.sqrt(dx*dx + dy*dy + dz*dz)
```

**Parameters:**
- $S(t)$: Style function value. Typical values depend on the saliency map generation; it acts as a scaling factor for the transparency effect [S1, unofficial].
- $\vec{P}_{center}$: The geometric center of the volume or the current rotation pivot [S1, unofficial].
- $\vec{P}_{focus}$: The point where the user initiates a zoom interaction [S1, unofficial].

**Edge Cases and Pitfalls:**
- If $\vec{P}_{focus}$ is not defined during a zoom interaction, the term $\rho(\vec{P}_{voxel}, \vec{P}_{focus})$ is undefined. The implementation must handle the mode switch explicitly [S1, unofficial].
- Precision issues may arise if $\rho(\vec{P}_{voxel}, \vec{P}_{center})$ is very large, causing $\alpha_{voxel}$ to underflow to zero. Clamping or normalization of distances may be required for large volumes [G].

## Subtopics

### Depth Opacity-Modulation
A technique used in atomic structure visualization to ensure visibility of voxels at the back of a structure by modulating opacity based on depth, preventing self-occlusion from hiding rear features [S2]. It differs from Radial Opacity Change by using depth relative to the viewpoint rather than distance from a geometric center [S2]. It is chosen when visualizing complex atomic structures where rear features are critical [S2]. The formula is $\alpha_v = \min(1, Z(v))$ where $Z(v) = \alpha_s \cdot G(g_v) \cdot r^{d_v - d_{min}(s)}$ [S2]. Parameters include seed opacity $\alpha_s$, gradient modulation $G(g_v)$, depth $d_v$, minimum depth $d_{min}(s)$, and modulation rate $r$ [S2]. A key pitfall is that voxels with high depth values are assigned high opacity to ensure visibility even if occluded by front-side voxels [S2].

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the number of voxels, as each voxel's opacity is computed independently based on its position [S1, unofficial].
- **Memory Complexity:** $O(1)$ auxiliary space per voxel, requiring only the storage of current interaction parameters ($\vec{P}_{center}, \vec{P}_{focus}$) and the style function value $S(t)$ [S1, unofficial].
- **Performance:** Real-time performance is achievable on modern GPUs due to the simplicity of the exponential calculation [S1, unofficial].
- **Strengths:** Effectively reveals inner structures during rotation and local details during zooming without altering the global context [S1, unofficial].
- **Limitations:** Requires accurate determination of the object center and focus point; may not be suitable for non-rigid deformations where the center shifts unpredictably [S1, unofficial].

## Background
Radial Opacity Change was introduced by Sikachev, Rautek, Bruckner, and Gröller in 2010 as part of the "Dynamic Focus+Context for Volume Rendering" framework [S1, unofficial]. It is inspired by the metaphor of a viscous fluid rotating around its center, where particles at the border have the highest angular velocity and are thus candidates to disappear [S1, unofficial]. The method is used in interactive volume visualization to enhance feature investigation during user interactions like rotation and zooming [S1, unofficial].
