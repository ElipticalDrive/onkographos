# Voxel Saliency

Also called: Saliency map

## Overview
Voxel Saliency is a feature importance metric for volume data defined as the magnitude of the gradient of the obscurance field [S1]. It identifies regions of high perceptual importance, such as edges, occlusion variations, and corners, by measuring how rapidly obscurance changes across a local neighborhood [S1]. Unlike sibling methods that may rely on direct intensity gradients or semantic labels, Voxel Saliency is derived from volumetric shadowing information (obscurance), making it particularly effective for highlighting structural boundaries in complex, self-occluding datasets [S1]. It serves as the core importance specification mechanism in the Importance-Driven Visualization Model, enabling viewpoint selection and transfer function modulation [S1].

## How it works
**Inputs:**
*   A 3D volume dataset $V$.
*   The precomputed obscurance field $O$, where $O(k)$ is the obscurance value for voxel $k$ [S1].

**Outputs:**
*   A scalar saliency map $S$, where $S(p) \in [0, 1]$ for each voxel $p$ [S1].

**Data Structures:**
*   **Obscurance Field:** A 3D array of floating-point values, same dimensions as the input volume.
*   **Saliency Map:** A 3D array of floating-point values, same dimensions as the input volume.

**Parameters:**
*   **Neighborhood Size:** A cubic neighborhood of $5^3$ voxels centered at the query voxel $p$ [S1]. (Note: A $3^3$ neighborhood was used in [NCKG00], but $5^3$ yields smoother results [S1]).
*   **Scaling:** Linear scaling to $[0, 1]$ per data volume [S1].

**Algorithm:**
1.  **Compute Obscurance:** Calculate the obscurance $O(k)$ for all voxels $k$ in the volume. This step relies on a local volumetric shadowing method (e.g., [HLY07, RMSD*08]) [S1].
2.  **Iterate Voxels:** For each voxel $p$ in the volume:
    a. Define the neighborhood $\mathcal{N}_p$ as the set of voxels $k$ within a $5^3$ cube centered at $p$ [S1].
    b. Initialize gradient components $A = 0$, $B = 0$, $C = 0$ [S1].
    c. For each voxel $k \in \mathcal{N}_p$:
        i. Calculate the vector $\vec{d}_{pk} = (x(k), y(k), z(k))$ from $p$ to $k$ [S1].
        ii. Calculate the distance weight $w(k)$. The source defines $w(k)$ as "the distance between voxels p and k" [S1]. [G] In standard 4D linear regression for gradient estimation, weights are typically inverse-square or Gaussian based on distance to reduce boundary bias. We implement $w(k)$ as the Euclidean distance $|\vec{d}_{pk}|$ as stated, though inverse distance is common in literature [G].
        iii. Accumulate components:
            $$A \leftarrow A + w(k) \cdot O(k) \cdot x(k)$$
            $$B \leftarrow B + w(k) \cdot O(k) \cdot y(k)$$
            $$C \leftarrow C + w(k) \cdot O(k) \cdot z(k)$$
    d. Compute the saliency magnitude:
        $$S(p) = \sqrt{A^2 + B^2 + C^2}$$
3.  **Normalize:** For the specific volume dataset, find the global maximum saliency $S_{max} = \max_p S(p)$. Scale the map: $S(p) \leftarrow S(p) / S_{max}$ [S1].

**Pseudocode:**
```python
def compute_voxel_saliency(obscurance_field: Volume3D, neighborhood_radius: int = 2) -> Volume3D:
    """
    Computes voxel saliency as the magnitude of the obscurance gradient.
    obscurance_field: 3D array of obscurance values O(k).
    neighborhood_radius: Half-size of the cubic neighborhood. 5^3 total implies radius 2.
    Returns: 3D array of saliency values S(p) scaled to [0, 1].
    """
    dims = obscurance_field.shape
    saliency_map = Volume3D.zeros(dims)
    
    # Precompute neighborhood offsets to avoid repeated calculation
    offsets = []
    for dx in range(-neighborhood_radius, neighborhood_radius + 1):
        for dy in range(-neighborhood_radius, neighborhood_radius + 1):
            for dz in range(-neighborhood_radius, neighborhood_radius + 1):
                offsets.append((dx, dy, dz))
    
    # Compute raw saliency
    for p in voxels_in_volume(dims):
        A = 0.0
        B = 0.0
        C = 0.0
        
        for dx, dy, dz in offsets:
            k = (p.x + dx, p.y + dy, p.z + dz)
            
            # Boundary check
            if not is_valid_voxel(k, dims):
                continue
                
            # Vector from p to k
            x_k = dx
            y_k = dy
            z_k = dz
            
            # Obscurance at k
            O_k = obscurance_field[k]
            
            # Weight w(k) is defined as the distance between p and k [S1]
            # Note: Using Euclidean distance as per literal interpretation of "distance"
            w_k = math.sqrt(x_k**2 + y_k**2 + z_k**2)
            
            # Accumulate gradient components
            # A = sum_k w(k)O(k)x(k)
            A += w_k * O_k * x_k
            B += w_k * O_k * y_k
            C += w_k * O_k * z_k
            
        # S(p) = sqrt(A^2 + B^2 + C^2)
        saliency_map[p] = math.sqrt(A**2 + B**2 + C**2)
        
    # Normalize to [0, 1]
    max_saliency = 0.0
    for p in voxels_in_volume(dims):
        if saliency_map[p] > max_saliency:
            max_saliency = saliency_map[p]
            
    if max_saliency > 0:
        for p in voxels_in_volume(dims):
            saliency_map[p] /= max_saliency
            
    return saliency_map
```

## Subtopics

### XS Map (Extinction-Saliency Map)
The XS Map is a combined importance map used in perceptual rendering of participating media [S2]. It integrates the Saliency map ($S$) with an Extinction map ($X$) to guide selective rendering [S2]. The combination is defined as $XS(w_x, w_s, op)$, where $w_x$ and $w_s$ are weighting coefficients and $op$ is the combination operator [S2]. The default configuration uses equal weighting ($w_x=0.5, w_s=0.5$) and an additive operator ($+$) to preserve all weighted features [S2]. A key limitation is that the XS Map fails to identify areas of strong multiple scattering around light sources, leading to poor sampling and visible artifacts in those regions [S2].

## Operating characteristics
*   **Complexity:** The computation is $O(N \cdot K)$, where $N$ is the number of voxels and $K$ is the neighborhood size ($5^3 = 125$). This is constant per voxel but requires access to the obscurance field.
*   **Memory:** Requires storage for the input obscurance field and the output saliency map. Both are single-channel 3D arrays of the same resolution as the volume data.
*   **Strengths:** Effectively highlights structural edges and occlusion boundaries in volumetric data [S1]. It is scale-dependent, allowing adjustment via neighborhood size [S1].
*   **Limitations:** Computationally expensive if obscurance is not precomputed or cached. It does not account for light scattering artifacts around sources (addressed partially by combining with X maps, but not fully) [S2].
*   **Usage:** Primarily used for automatic viewpoint selection (maximizing visible saliency) and for modulating transfer functions (opacity/color) to enhance salient features [S1].

## Background
Voxel Saliency was proposed in the Obscurance-based Volume Rendering Framework [S1]. It adapts the concept of mesh saliency [LVJ05] to volumetric data. The gradient estimation technique is based on the 4D linear regression method proposed in [NCKG00]. The method emphasizes that obscurance, representing occlusion information, varies perceptually at edges and corners, making its gradient a suitable saliency measure [S1].
