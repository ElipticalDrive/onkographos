# Marker Placement
Also called: Cone Markers

## Overview
Marker Placement is an illustrative volume rendering technique that overlays cone-shaped geometric primitives into the 3D data space to aid feature location and facilitate discussion during parameter adjustments [S1, unofficial][S2, unofficial]. It is specifically used to help locate features again after changes of visualization parameters [S1, unofficial][S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D volume dataset and user interaction via a pointer or wand [S1, unofficial][S2, unofficial].
*   **Output:** Cone-shaped markers placed in the dataset with updated positions and orientations [S1, unofficial][S2, unofficial].

**Data Structures:**
Each marker stores its 3D position and orientation, updated by the pointer or wand input [G].

**Steps:**
1. **Placement:** The user places a cone-shaped marker in the dataset using a pointer or wand [S1, unofficial][S2, unofficial].
2. **Manipulation:** The user moves and orients the marker arbitrarily using the pointer or wand [S1, unofficial][S2, unofficial].

## Subtopics

### Waypoint Mechanism
Stores and revisits marker locations on isosurface structures without manual 6 DoF navigation [S3]. Unlike standard manual navigation, it automatically returns to stored locations [S3]. Chosen when exploring large structures to avoid repetitive rotation and panning [S3]. Builds on [Visual Conventions](9605-visual-conventions.md).
