# Exact Projection Full Opacity

Also called: Background Object Blending, Full Opacity Rendering, Primary/Background Object Selection

## Overview
Exact Projection Full Opacity is a non-photorealistic volume rendering technique that simplifies visual output by identifying a single primary front object and optionally one significant background object, blending them based on density and distance thresholds rather than performing full front-to-back accumulation [S1, unofficial]. It differs from standard front-to-back compositing by skipping the accumulation of intermediate samples, storing only the first significant object (primary) and potentially one background object, then blending them directly to create a stylized, illustrative result [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D scalar volume texture (`volumeTexture`), a 4D color map texture (`colorMap`), ray origin (`startPos`), ray direction (`rayDir`), near/far clipping planes (`tNear`, `tFar`), volume dimensions (`volumeDimensions`), and boolean flags for lighting (`enableLighting`) and shadows (`enableShadow`) [S1, unofficial].
*   **Output:** A fragment color `FragColor` (vec4) [S1, unofficial].

**Data Structures:**
The method maintains state variables during ray traversal [S1, unofficial]:
*   `foundPrimaryObject` (bool): Indicates if the front-most significant object has been found [S1, unofficial].
*   `foundBackgroundObject` (bool): Indicates if a significant background object has been found [S1, unofficial].
*   `primaryObjectPos`, `backgroundObjectPos` (vec3): World-space positions of the primary and background objects [S1, unofficial].
*   `primaryObjectColor`, `backgroundObjectColor` (vec4): RGBA colors sampled from the color map [S1, unofficial].
*   `primaryObjectDistance`, `backgroundObjectDistance` (float): Ray parameter `t` values for the objects [S1, unofficial].
*   `primaryObjectDensity` (float): Scalar value from the volume texture at the primary object's position [S1, unofficial].
*   `accumulatedColor` (vec3): The final blended color [S1, unofficial].
*   `accumulatedAlpha` (float): The final blended alpha [S1, unofficial].

**Constants:**
The method uses the following constants [S1, unofficial]:
*   `HIGH_DENSITY_THRESHOLD = 0.7`: Density value above which front objects obscure back objects [S1, unofficial].
*   `DISTANCE_THRESHOLD = 0.5`: Distance beyond which back objects are ignored or blended minimally [S1, unofficial].
*   `minDensityThreshold`, `maxDensityThreshold`: Bounds for valid volume data [S1, unofficial].
*   `MAX_ITERATIONS = 2000`: Safety counter to prevent infinite loops [S1, unofficial].

**Steps:**
The algorithm proceeds as follows [S1, unofficial]:

1.  **Initialization:**
    Initialize `foundPrimaryObject = false`, `foundBackgroundObject = false` [S1, unofficial].
    Initialize `accumulatedColor = vec3(0.0)`, `accumulatedAlpha = 0.0` [S1, unofficial].
    Initialize `primaryObjectPos = vec3(0.0)`, `backgroundObjectPos = vec3(0.0)` [S1, unofficial].
    Initialize `primaryObjectColor = vec4(0.0)`, `backgroundObjectColor = vec4(0.0)` [S1, unofficial].
    Initialize `primaryObjectDistance = 0.0`, `backgroundObjectDistance = 0.0` [S1, unofficial].
    Initialize `primaryObjectDensity = 0.0` [S1, unofficial].
    Initialize `iterations = 0` [S1, unofficial].

2.  **Ray Traversal Loop:**
    While `t < tFar` and `iterations < MAX_ITERATIONS` [S1, unofficial]:
    
    a. **Sample Position:**
       Calculate `samplePos = startPos + rayDir * t` [S1, unofficial].
       
    b. **Boundary Check:**
       If `any(lessThan(samplePos, vec3(0.0)))` or `any(greaterThan(samplePos, vec3(1.0)))`:
       Increment `t` by a small step (e.g., `dt`) [S1, unofficial].
       Increment `iterations` [S1, unofficial].
       Continue to next iteration [S1, unofficial].
       
    c. **Voxel Traversal:**
       Calculate `voxelPos = samplePos * volumeDimensions` [S1, unofficial].
       Determine `nextVoxel` boundaries based on `rayDir` signs [S1, unofficial].
       Calculate `dtVec` components:
       ```
       dtVec.x = (rayDir.x > 0.0001) ? (nextVoxel.x - voxelPos.x) / (rayDir.x * volumeDimensions.x) : tFar
       dtVec.y = (rayDir.y > 0.0001) ? (nextVoxel.y - voxelPos.y) / (rayDir.y * volumeDimensions.y) : tFar
       dtVec.z = (rayDir.z > 0.0001) ? (nextVoxel.z - voxelPos.z) / (rayDir.z * volumeDimensions.z) : tFar
       ```
       `dt = max(min(dtVec.x, min(dtVec.y, dtVec.z)), 0.0001)` [S1, unofficial].
       
    d. **Volume Sampling:**
       `val = texture(volumeTexture, samplePos).r` [S1, unofficial].
       If `val < minDensityThreshold` or `val > maxDensityThreshold`:
       Increment `t` by `dt` [S1, unofficial].
       Increment `iterations` [S1, unofficial].
       Continue [S1, unofficial].
       
    e. **Color Mapping:**
       `color = texture(colorMap, val)` [S1, unofficial].
       If `color.a < 0.05`:
       Increment `t` by `dt` [S1, unofficial].
       Increment `iterations` [S1, unofficial].
       Continue [S1, unofficial].
       
    f. **Primary Object Identification:**
       If `!foundPrimaryObject`:
       Set `foundPrimaryObject = true` [S1, unofficial].
       Set `primaryObjectPos = samplePos` [S1, unofficial].
       Set `primaryObjectColor = color` [S1, unofficial].
       Set `primaryObjectDistance = t` [S1, unofficial].
       Set `primaryObjectDensity = val` [S1, unofficial].
       
       If `val > HIGH_DENSITY_THRESHOLD` or `color.a > 0.9`:
       Break loop (high opacity/density obscures background) [S1, unofficial].
       
       Increment `t` by `dt` [S1, unofficial].
       Increment `iterations` [S1, unofficial].
       Continue [S1, unofficial].
       
    g. **Background Object Identification:**
       If `foundPrimaryObject` and `!foundBackgroundObject` and `color.a > 0.6`:
       Set `foundBackgroundObject = true` [S1, unofficial].
       Set `backgroundObjectPos = samplePos` [S1, unofficial].
       Set `backgroundObjectColor = color` [S1, unofficial].
       Set `backgroundObjectDistance = t` [S1, unofficial].
       
       Calculate `distanceBetweenObjects = backgroundObjectDistance - primaryObjectDistance` [S1, unofficial].
       
       If `primaryObjectDensity > 0.5` or `distanceBetweenObjects > DISTANCE_THRESHOLD`:
       Set `foundBackgroundObject = false` (effectively ignore background) [S1, unofficial].
       
       Break loop (found primary and potentially background) [S1, unofficial].
       
    h. **Advance Ray:**
       Increment `t` by `dt` [S1, unofficial].
       Increment `iterations` [S1, unofficial].

3.  **Fallback:**
   If `!foundPrimaryObject`:
   Set `FragColor = vec4(0.0)` [S1, unofficial].
   Return [S1, unofficial].

4.  **Lighting and Blending:**
   a. **Primary Color:**
      If `enableLighting`:
      `normal = calculateNormal(primaryObjectPos)` [G].
      `primaryColor = calculateLighting(normal, -rayDir, primaryObjectPos, primaryObjectColor.rgb)` [G].
      Else:
      `primaryColor = primaryObjectColor.rgb` [S1, unofficial].
      
   b. **Initialize Accumulation:**
      `accumulatedColor = primaryColor` [S1, unofficial].
      `accumulatedAlpha = primaryObjectColor.a` [S1, unofficial].
      
   c. **Background Blending (if found):**
      If `foundBackgroundObject`:
      Calculate `distanceFactor = clamp((backgroundObjectDistance - primaryObjectDistance) / DISTANCE_THRESHOLD, 0.0, 1.0)` [S1, unofficial].
      Calculate `densityFactor = clamp(1.0 - primaryObjectDensity / HIGH_DENSITY_THRESHOLD, 0.0, 1.0)` [S1, unofficial].
      Calculate `backgroundContribution = min(distanceFactor, densityFactor) * 0.7` [S1, unofficial].
      
      Calculate `backgroundLitColor`:
      If `enableLighting`:
      `bgNormal = calculateNormal(backgroundObjectPos)` [G].
      `backgroundLitColor = calculateLighting(bgNormal, -rayDir, backgroundObjectPos, backgroundObjectColor.rgb)` [G].
      Else:
      `backgroundLitColor = backgroundObjectColor.rgb` [S1, unofficial].
      
      Blend:
      `accumulatedColor = mix(accumulatedColor, backgroundLitColor, backgroundContribution * (1.0 - accumulatedAlpha))` [S1, unofficial].
      `accumulatedAlpha = accumulatedAlpha + backgroundContribution * (1.0 - accumulatedAlpha)` [S1, unofficial].

5.  **Final Output:**
   `FragColor = vec4(accumulatedColor, max(accumulatedAlpha, 0.5))` [S1, unofficial].

**Pseudocode:**

```python
import math

def exact_projection_full_opacity(startPos, rayDir, tNear, tFar, volumeTexture, colorMap, volumeDimensions, enableLighting, enableShadow):
    # Constants
    HIGH_DENSITY_THRESHOLD = 0.7
    DISTANCE_THRESHOLD = 0.5
    MAX_ITERATIONS = 2000
    MIN_DENSITY_THRESHOLD = 0.0  # Not given in the sources, assumed 0.0
    MAX_DENSITY_THRESHOLD = 1.0  # Not given in the sources, assumed 1.0
    
    # State
    foundPrimaryObject = False
    foundBackgroundObject = False
    primaryObjectPos = [0.0, 0.0, 0.0]
    backgroundObjectPos = [0.0, 0.0, 0.0]
    primaryObjectColor = [0.0, 0.0, 0.0, 0.0]
    backgroundObjectColor = [0.0, 0.0, 0.0, 0.0]
    primaryObjectDistance = 0.0
    backgroundObjectDistance = 0.0
    primaryObjectDensity = 0.0
    
    t = tNear
    iterations = 0
    
    while t < tFar and iterations < MAX_ITERATIONS:
        samplePos = [startPos[i] + rayDir[i] * t for i in range(3)]
        
        # Boundary check
        if any(p < 0.0 for p in samplePos) or any(p > 1.0 for p in samplePos):
            t += 0.01  # Small step as per evidence
            iterations += 1
            continue
            
        # Voxel traversal logic for dt
        voxelPos = [samplePos[i] * volumeDimensions[i] for i in range(3)]
        nextVoxel = [
            math.floor(voxelPos[i]) + 1.0 if rayDir[i] > 0.0 else math.ceil(voxelPos[i]) - 1.0
            for i in range(3)
        ]
        
        dtVec = [tFar, tFar, tFar]
        if abs(rayDir[0]) > 0.0001: dtVec[0] = (nextVoxel[0] - voxelPos[0]) / (rayDir[0] * volumeDimensions[0])
        if abs(rayDir[1]) > 0.0001: dtVec[1] = (nextVoxel[1] - voxelPos[1]) / (rayDir[1] * volumeDimensions[1])
        if abs(rayDir[2]) > 0.0001: dtVec[2] = (nextVoxel[2] - voxelPos[2]) / (rayDir[2] * volumeDimensions[2])
        
        dt = max(min(dtVec[0], min(dtVec[1], dtVec[2])), 0.0001)
        
        # Sample volume
        val = volumeTexture(samplePos) # Simplified texture lookup
        if val < MIN_DENSITY_THRESHOLD or val > MAX_DENSITY_THRESHOLD:
            t += dt
            iterations += 1
            continue
            
        color = colorMap(val) # Simplified color map lookup
        if color[3] < 0.05:
            t += dt
            iterations += 1
            continue
            
        # Primary Object
        if not foundPrimaryObject:
            foundPrimaryObject = True
            primaryObjectPos = samplePos
            primaryObjectColor = color
            primaryObjectDistance = t
            primaryObjectDensity = val
            
            if val > HIGH_DENSITY_THRESHOLD or color[3] > 0.9:
                break
                
            t += dt
            iterations += 1
            continue
            
        # Background Object
        if foundPrimaryObject and not foundBackgroundObject and color[3] > 0.6:
            foundBackgroundObject = True
            backgroundObjectPos = samplePos
            backgroundObjectColor = color
            backgroundObjectDistance = t
            
            distanceBetweenObjects = backgroundObjectDistance - primaryObjectDistance
            
            if primaryObjectDensity > 0.5 or distanceBetweenObjects > DISTANCE_THRESHOLD:
                foundBackgroundObject = False
                
            break
            
        t += dt
        iterations += 1
        
    if not foundPrimaryObject:
        return [0.0, 0.0, 0.0, 0.0]
        
    # Lighting Primary
    if enableLighting:
        normal = calculateNormal(primaryObjectPos) # [G] Standard normal calculation
        primaryColor = calculateLighting(normal, [-r for r in rayDir], primaryObjectPos, primaryObjectColor[:3]) # [G] Standard lighting
    else:
        primaryColor = primaryObjectColor[:3]
        
    accumulatedColor = primaryColor
    accumulatedAlpha = primaryObjectColor[3]
    
    if foundBackgroundObject:
        # Lighting Background
        if enableLighting:
            bgNormal = calculateNormal(backgroundObjectPos) # [G] Standard normal calculation
            backgroundLitColor = calculateLighting(bgNormal, [-r for r in rayDir], backgroundObjectPos, backgroundObjectColor[:3]) # [G] Standard lighting
        else:
            backgroundLitColor = backgroundObjectColor[:3]
            
        distanceFactor = max(0.0, min(1.0, (backgroundObjectDistance - primaryObjectDistance) / DISTANCE_THRESHOLD))
        densityFactor = max(0.0, min(1.0, 1.0 - primaryObjectDensity / HIGH_DENSITY_THRESHOLD))
        backgroundContribution = min(distanceFactor, densityFactor) * 0.7
        
        mixFactor = backgroundContribution * (1.0 - accumulatedAlpha)
        accumulatedColor = [accumulatedColor[i] * (1.0 - mixFactor) + backgroundLitColor[i] * mixFactor for i in range(3)]
        accumulatedAlpha = accumulatedAlpha + backgroundContribution * (1.0 - accumulatedAlpha)
        
    return [accumulatedColor[0], accumulatedColor[1], accumulatedColor[2], max(accumulatedAlpha, 0.5)]
```

**Edge Cases and Pitfalls:**
*   **Precision:** The `dt` calculation uses a small epsilon (`0.0001`) to avoid division by zero or zero-step traversal [S1, unofficial].
*   **Boundaries:** Explicit checks ensure the ray does not sample outside the `[0,1]` volume space [S1, unofficial].
*   **Degenerate Input:** If no primary object is found (empty volume or all values out of range), the output is black [S1, unofficial].
*   **High Density:** If the primary object has density > 0.7 or alpha > 0.9, the loop breaks immediately, ignoring any potential background objects [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Significantly faster than standard front-to-back volume rendering because it terminates early [S1, unofficial]. The loop breaks after finding the primary object (if high density/opacity) or after finding the primary and one background object [S1, unofficial]. It does not process all samples along the ray [S1, unofficial].
*   **Memory Complexity:** Low. It only stores state for two objects (primary and background) rather than accumulating color/alpha for every sample [S1, unofficial].
*   **Strengths:** Efficient for illustrative rendering where full volumetric accuracy is not required. It provides a clean separation between foreground and background elements [S1, unofficial].
*   **Limitations:** Loses detailed volumetric information from intermediate samples. The blending is heuristic-based (distance and density thresholds) rather than physically based [S1, unofficial].
*   **When to use:** When performance is critical and a stylized, non-photorealistic look is desired. When the scene has distinct foreground and background objects that need to be highlighted [S1, unofficial].
*   **When not to use:** When physically accurate volume visualization is required. When the scene contains many overlapping semi-transparent structures where intermediate accumulation is important [S1, unofficial].
