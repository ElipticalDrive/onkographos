# Exact Projection Full Opacity

Also called: Background Object Blending, Full Opacity Rendering, Primary/Background Object Selection

## Overview
Exact Projection Full Opacity is a non-photorealistic volume rendering technique that simplifies the visual output by identifying a single primary front object and optionally one significant background object, blending them based on density and distance thresholds rather than performing full front-to-back accumulation [S1, unofficial]. It differs from standard front-to-back compositing by skipping the accumulation of intermediate samples, storing only the first significant object (primary) and potentially one background object, then blending them directly to create a stylized, illustrative result [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D scalar volume texture (`volumeTexture`), a 4D color map texture (`colorMap`), ray origin (`startPos`), ray direction (`rayDir`), near/far clipping planes (`tNear`, `tFar`), volume dimensions (`volumeDimensions`), and boolean flags for lighting (`enableLighting`) and shadows (`enableShadow`).
*   **Output:** A fragment color `FragColor` (vec4).

**Data Structures:**
The method maintains state variables during ray traversal:
*   `foundPrimaryObject` (bool): Indicates if the front-most significant object has been found.
*   `foundBackgroundObject` (bool): Indicates if a significant background object has been found.
*   `primaryObjectPos`, `backgroundObjectPos` (vec3): World-space positions of the primary and background objects.
*   `primaryObjectColor`, `backgroundObjectColor` (vec4): RGBA colors sampled from the color map.
*   `primaryObjectDistance`, `backgroundObjectDistance` (float): Ray parameter `t` values for the objects.
*   `primaryObjectDensity` (float): Scalar value from the volume texture at the primary object's position.
*   `accumulatedColor` (vec3): The final blended color.
*   `accumulatedAlpha` (float): The final blended alpha.

**Constants:**
*   `HIGH_DENSITY_THRESHOLD = 0.7`: Density value above which front objects obscure back objects [S1, unofficial].
*   `DISTANCE_THRESHOLD = 0.5`: Distance beyond which back objects are ignored or blended minimally [S1, unofficial].
*   `minDensityThreshold`, `maxDensityThreshold`: Bounds for valid volume data [S1, unofficial].
*   `MAX_ITERATIONS = 2000`: Safety counter to prevent infinite loops [S1, unofficial].

**Steps:**

1.  **Initialization:**
    Initialize `foundPrimaryObject = false`, `foundBackgroundObject = false`.
    Initialize `accumulatedColor = vec3(0.0)`, `accumulatedAlpha = 0.0`.
    Initialize `primaryObjectPos = vec3(0.0)`, `backgroundObjectPos = vec3(0.0)`.
    Initialize `primaryObjectColor = vec4(0.0)`, `backgroundObjectColor = vec4(0.0)`.
    Initialize `primaryObjectDistance = 0.0`, `backgroundObjectDistance = 0.0`.
    Initialize `primaryObjectDensity = 0.0`.
    Initialize `iterations = 0`.

2.  **Ray Traversal Loop:**
    While `t < tFar` and `iterations < MAX_ITERATIONS`:
    
    a. **Sample Position:**
       Calculate `samplePos = startPos + rayDir * t`.
       
    b. **Boundary Check:**
       If `any(lessThan(samplePos, vec3(0.0)))` or `any(greaterThan(samplePos, vec3(1.0)))`:
       Increment `t` by `stepSize` (or `dt` if using voxel traversal).
       Increment `iterations`.
       Continue to next iteration.
       
    c. **Voxel Traversal (Optional but implied for efficiency):**
       Calculate `voxelPos = samplePos * volumeDimensions`.
       Determine `nextVoxel` boundaries based on `rayDir` signs.
       Calculate `dtVec` components:
       ```
       dtVec.x = (rayDir.x > 0.0001) ? (nextVoxel.x - voxelPos.x) / (rayDir.x * volumeDimensions.x) : tFar
       dtVec.y = (rayDir.y > 0.0001) ? (nextVoxel.y - voxelPos.y) / (rayDir.y * volumeDimensions.y) : tFar
       dtVec.z = (rayDir.z > 0.0001) ? (nextVoxel.z - voxelPos.z) / (rayDir.z * volumeDimensions.z) : tFar
       ```
       `dt = max(min(dtVec.x, min(dtVec.y, dtVec.z)), 0.0001)`.
       
    d. **Volume Sampling:**
       `val = texture(volumeTexture, samplePos).r`.
       If `val < minDensityThreshold` or `val > maxDensityThreshold`:
       Increment `t` by `dt`.
       Increment `iterations`.
       Continue.
       
    e. **Color Mapping:**
       `color = texture(colorMap, val)`.
       If `color.a < 0.05`:
       Increment `t` by `dt`.
       Increment `iterations`.
       Continue.
       
    f. **Primary Object Identification:**
       If `!foundPrimaryObject`:
       Set `foundPrimaryObject = true`.
       Set `primaryObjectPos = samplePos`.
       Set `primaryObjectColor = color`.
       Set `primaryObjectDistance = t`.
       Set `primaryObjectDensity = val`.
       
       If `val > HIGH_DENSITY_THRESHOLD` or `color.a > 0.9`:
       Break loop (high opacity/density obscures background).
       
       Increment `t` by `dt`.
       Increment `iterations`.
       Continue.
       
    g. **Background Object Identification:**
       If `foundPrimaryObject` and `!foundBackgroundObject` and `color.a > 0.6`:
       Set `foundBackgroundObject = true`.
       Set `backgroundObjectPos = samplePos`.
       Set `backgroundObjectColor = color`.
       Set `backgroundObjectDistance = t`.
       
       Calculate `distanceBetweenObjects = backgroundObjectDistance - primaryObjectDistance`.
       
       If `primaryObjectDensity > 0.5` or `distanceBetweenObjects > DISTANCE_THRESHOLD`:
       Set `foundBackgroundObject = false` (effectively ignore background).
       
       Break loop (found primary and potentially background).
       
    h. **Advance Ray:**
       Increment `t` by `dt`.
       Increment `iterations`.

3.  **Fallback:**
   If `!foundPrimaryObject`:
   Set `FragColor = vec4(0.0)`.
   Return.

4.  **Lighting and Blending:**
   a. **Primary Color:**
      If `enableLighting`:
      `normal = calculateNormal(primaryObjectPos)`.
      `primaryColor = calculateLighting(normal, -rayDir, primaryObjectPos, primaryObjectColor.rgb)`.
      Else:
      `primaryColor = primaryObjectColor.rgb`.
      
   b. **Initialize Accumulation:**
      `accumulatedColor = primaryColor`.
      `accumulatedAlpha = primaryObjectColor.a`.
      
   c. **Background Blending (if found):**
      If `foundBackgroundObject`:
      Calculate `distanceFactor = clamp((backgroundObjectDistance - primaryObjectDistance) / DISTANCE_THRESHOLD, 0.0, 1.0)`.
      Calculate `densityFactor = clamp(1.0 - primaryObjectDensity / HIGH_DENSITY_THRESHOLD, 0.0, 1.0)`.
      Calculate `backgroundContribution = min(distanceFactor, densityFactor) * 0.7`.
      
      Calculate `backgroundLitColor`:
      If `enableLighting`:
      `bgNormal = calculateNormal(backgroundObjectPos)`.
      `backgroundLitColor = calculateLighting(bgNormal, -rayDir, backgroundObjectPos, backgroundObjectColor.rgb)`.
      Else:
      `backgroundLitColor = backgroundObjectColor.rgb`.
      
      Blend:
      `accumulatedColor = mix(accumulatedColor, backgroundLitColor, backgroundContribution * (1.0 - accumulatedAlpha))`.
      `accumulatedAlpha = accumulatedAlpha + backgroundContribution * (1.0 - accumulatedAlpha)`.

5.  **Final Output:**
   `FragColor = vec4(accumulatedColor, max(accumulatedAlpha, 0.5))`.

**Pseudocode:**

```python
def exact_projection_full_opacity(startPos, rayDir, tNear, tFar, volumeTexture, colorMap, volumeDimensions, enableLighting, enableShadow):
    # Constants
    HIGH_DENSITY_THRESHOLD = 0.7
    DISTANCE_THRESHOLD = 0.5
    MAX_ITERATIONS = 2000
    
    # State
    foundPrimaryObject = False
    foundBackgroundObject = False
    primaryObjectPos = vec3(0.0)
    backgroundObjectPos = vec3(0.0)
    primaryObjectColor = vec4(0.0)
    backgroundObjectColor = vec4(0.0)
    primaryObjectDistance = 0.0
    backgroundObjectDistance = 0.0
    primaryObjectDensity = 0.0
    
    t = tNear
    iterations = 0
    
    while t < tFar and iterations < MAX_ITERATIONS:
        samplePos = startPos + rayDir * t
        
        # Boundary check
        if any(samplePos < vec3(0.0)) or any(samplePos > vec3(1.0)):
            t += 0.01 # Placeholder for stepSize/dt if not using voxel traversal
            iterations += 1
            continue
            
        # Voxel traversal logic for dt
        voxelPos = samplePos * volumeDimensions
        nextVoxel = vec3(
            rayDir.x > 0.0 ? floor(voxelPos.x) + 1.0 : ceil(voxelPos.x) - 1.0,
            rayDir.y > 0.0 ? floor(voxelPos.y) + 1.0 : ceil(voxelPos.y) - 1.0,
            rayDir.z > 0.0 ? floor(voxelPos.z) + 1.0 : ceil(voxelPos.z) - 1.0
        )
        
        dtVec = vec3(tFar)
        if abs(rayDir.x) > 0.0001: dtVec.x = (nextVoxel.x - voxelPos.x) / (rayDir.x * volumeDimensions.x)
        if abs(rayDir.y) > 0.0001: dtVec.y = (nextVoxel.y - voxelPos.y) / (rayDir.y * volumeDimensions.y)
        if abs(rayDir.z) > 0.0001: dtVec.z = (nextVoxel.z - voxelPos.z) / (rayDir.z * volumeDimensions.z)
        
        dt = max(min(dtVec.x, min(dtVec.y, dtVec.z)), 0.0001)
        
        # Sample volume
        val = texture(volumeTexture, samplePos).r
        if val < 0.0 or val > 1.0: # Assuming normalized density
            t += dt
            iterations += 1
            continue
            
        color = texture(colorMap, val)
        if color.a < 0.05:
            t += dt
            iterations += 1
            continue
            
        # Primary Object
        if not foundPrimaryObject:
            foundPrimaryObject = True
            primaryObjectPos = samplePos
            primaryObjectColor = color
            primaryObjectDistance = t
            primaryObjectDensity = val
            
            if val > HIGH_DENSITY_THRESHOLD or color.a > 0.9:
                break
                
            t += dt
            iterations += 1
            continue
            
        # Background Object
        if foundPrimaryObject and not foundBackgroundObject and color.a > 0.6:
            foundBackgroundObject = True
            backgroundObjectPos = samplePos
            backgroundObjectColor = color
            backgroundObjectDistance = t
            
            distanceBetweenObjects = backgroundObjectDistance - primaryObjectDistance
            
            if primaryObjectDensity > 0.5 or distanceBetweenObjects > DISTANCE_THRESHOLD:
                foundBackgroundObject = False
                
            break
            
        t += dt
        iterations += 1
        
    if not foundPrimaryObject:
        return vec4(0.0)
        
    # Lighting Primary
    if enableLighting:
        normal = calculateNormal(primaryObjectPos)
        primaryColor = calculateLighting(normal, -rayDir, primaryObjectPos, primaryObjectColor.rgb)
    else:
        primaryColor = primaryObjectColor.rgb
        
    accumulatedColor = primaryColor
    accumulatedAlpha = primaryObjectColor.a
    
    if foundBackgroundObject:
        # Lighting Background
        if enableLighting:
            bgNormal = calculateNormal(backgroundObjectPos)
            backgroundLitColor = calculateLighting(bgNormal, -rayDir, backgroundObjectPos, backgroundObjectColor.rgb)
        else:
            backgroundLitColor = backgroundObjectColor.rgb
            
        distanceFactor = clamp((backgroundObjectDistance - primaryObjectDistance) / DISTANCE_THRESHOLD, 0.0, 1.0)
        densityFactor = clamp(1.0 - primaryObjectDensity / HIGH_DENSITY_THRESHOLD, 0.0, 1.0)
        backgroundContribution = min(distanceFactor, densityFactor) * 0.7
        
        accumulatedColor = mix(accumulatedColor, backgroundLitColor, backgroundContribution * (1.0 - accumulatedAlpha))
        accumulatedAlpha = accumulatedAlpha + backgroundContribution * (1.0 - accumulatedAlpha)
        
    return vec4(accumulatedColor, max(accumulatedAlpha, 0.5))
```

**Edge Cases and Pitfalls:**
*   **Precision:** The `dt` calculation uses a small epsilon (`0.0001`) to avoid division by zero or zero-step traversal.
*   **Boundaries:** Explicit checks ensure the ray does not sample outside the `[0,1]` volume space.
*   **Degenerate Input:** If no primary object is found (empty volume or all values out of range), the output is black.
*   **High Density:** If the primary object has density > 0.7 or alpha > 0.9, the loop breaks immediately, ignoring any potential background objects.

## Operating characteristics
*   **Time Complexity:** Significantly faster than standard front-to-back volume rendering because it terminates early. The loop breaks after finding the primary object (if high density/opacity) or after finding the primary and one background object. It does not process all samples along the ray.
*   **Memory Complexity:** Low. It only stores state for two objects (primary and background) rather than accumulating color/alpha for every sample.
*   **Strengths:** Efficient for illustrative rendering where full volumetric accuracy is not required. It provides a clean separation between foreground and background elements.
*   **Limitations:** Loses detailed volumetric information from intermediate samples. The blending is heuristic-based (distance and density thresholds) rather than physically based.
*   **When to use:** When performance is critical and a stylized, non-photorealistic look is desired. When the scene has distinct foreground and background objects that need to be highlighted.
*   **When not to use:** When physically accurate volume visualization is required. When the scene contains many overlapping semi-transparent structures where intermediate accumulation is important.
