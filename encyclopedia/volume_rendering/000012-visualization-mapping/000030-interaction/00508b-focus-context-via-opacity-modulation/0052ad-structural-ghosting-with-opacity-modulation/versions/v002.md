# Structural Ghosting with Opacity Modulation

Also called: Contextual Ghosting, Contextual cluster opacity computation, Structural Ghosting

## Overview
Structural Ghosting is a Focus+Context technique that modulates the opacity of non-focus volume clusters based on their structural relationship to a selected focus region within a classification hierarchy [S1, unofficial]. It solves visual clutter by rendering context clusters with varying transparency, where opacity decreases as the hierarchical distance from the focus increases [S1, unofficial]. Unlike simple cut-away methods, it preserves the surrounding hierarchical context, allowing users to perceive the data structure while emphasizing the region of interest [S1, unofficial].

## How it works
**Inputs:**
*   A classification hierarchy (tree/graph) of volume clusters [S1, unofficial].
*   A set of "focus clusters" $F$ identified by user query or selection [S1, unofficial].
*   A "ghosting level" parameter $L$ (integer) [S1, unofficial].
*   A "color ghosting" flag (boolean) [S1, unofficial].

**Outputs:**
*   A modified Color Transfer Function (CTF) where the $\alpha$-channel (opacity) for contextual clusters is adjusted based on their depth in the hierarchy relative to $F$ [S1, unofficial].

**Data Structures:**
*   **Hierarchy Graph:** Nodes represent clusters [S1, unofficial]. Edges represent parent-child or ancestor-descendant relationships [G].
*   **CTF:** Maps cluster IDs to RGBA values. The $\alpha$-channel is modified by this method [S1, unofficial].

**Parameters:**
*   **Ghosting Level ($L$):** Integer ranging from 0 to the maximum depth of the hierarchy trees in the graph [S1, unofficial].
    *   $L=0$: Cut-away mode (context clusters have zero opacity) [S1, unofficial].
    *   $L=1$: Shows clusters with a direct common ancestor with focus clusters [S1, unofficial].
    *   $L=2$: Shows clusters having common ancestors with focus clusters through a one-edge path in the graph [S1, unofficial].
*   **Color Ghosting Flag:** If true, contextual clusters are rendered in grayscale based on node intensity rather than RGB values [S1, unofficial].

**Algorithm Steps:**
1.  **Identify Focus Nodes:** Determine the set of graph nodes $F$ corresponding to the focus clusters [S1, unofficial].
2.  **Traverse Hierarchy:** Starting from nodes in $F$, traverse the hierarchy graph upwards (towards ancestors) up to a depth of $L$ steps [S1, unofficial].
3.  **Compute Context Opacity:** For each contextual cluster identified during traversal, compute its opacity factor inversely proportional to the depth of the related node in the hierarchy [S1, unofficial].
    *   Formula: $\alpha_{context} = \alpha_{max} \cdot \frac{1}{depth}$, where $depth$ is the distance from the focus node in the hierarchy traversal, and $\alpha_{max}$ is the maximum opacity (typically 1.0) [S1, unofficial].
    *   Note: The further in the hierarchy a node is, the lighter (lower opacity) the related cluster becomes [S1, unofficial].
4.  **Update CTF:** Set the $\alpha$-channel of the CTF for these contextual clusters to the computed opacity values [S1, unofficial].
5.  **Optional Color Modulation:** If the color ghosting flag is active, set the RGB values of the contextual clusters in the CTF to grayscale values derived from the node intensity, ignoring original RGB values [S1, unofficial]. This enhances contrast with the colored focus region [S1, unofficial].

**Pseudocode:**
```python
def compute_structural_ghosting(focus_clusters, hierarchy_graph, ghosting_level, color_ghosting_flag, ctf):
    """
    focus_clusters: List of cluster IDs identified as focus.
    hierarchy_graph: Graph structure where nodes are clusters and edges represent hierarchy.
    ghosting_level: Integer L.
    color_ghosting_flag: Boolean.
    ctf: Dictionary mapping cluster_id -> {'r': float, 'g': float, 'b': float, 'a': float}.
    """
    # Step 1: Identify focus nodes in the graph
    focus_nodes = [node for node in hierarchy_graph.nodes if node.id in focus_clusters]
    
    # Dictionary to store context clusters and their computed opacities
    context_opacities = {}
    
    # Step 2 & 3: Traverse hierarchy and compute opacity
    for focus_node in focus_nodes:
        queue = [(focus_node, 0)]
        visited = set([focus_node.id])
        
        while queue:
            current_node, current_depth = queue.pop(0)
            
            if current_depth > 0 and current_depth <= ghosting_level:
                # Compute opacity inversely proportional to depth
                opacity = 1.0 / current_depth 
                context_opacities[current_node.id] = opacity
                
            if current_depth < ghosting_level:
                for neighbor in current_node.neighbors:
                    if neighbor.id not in visited:
                        visited.add(neighbor.id)
                        queue.append((neighbor, current_depth + 1))

    # Step 4: Update CTF
    for cluster_id, opacity in context_opacities.items():
        ctf[cluster_id]['a'] = opacity
        
        # Step 5: Optional Color Modulation
        if color_ghosting_flag:
            original = ctf[cluster_id]
            # Standard luminance formula [G]
            intensity = 0.299 * original['r'] + 0.587 * original['g'] + 0.114 * original['b']
            ctf[cluster_id]['r'] = intensity
            ctf[cluster_id]['g'] = intensity
            ctf[cluster_id]['b'] = intensity
            
    return ctf
```

**Edge Cases and Pitfalls:**
*   **Ghosting Level 0:** Results in zero opacity for all context clusters (cut-away) [S1, unofficial].
*   **Hierarchy Depth:** The maximum ghosting level is bounded by the maximum depth of the hierarchy trees in the graph [S1, unofficial].
*   **Opacity Fluctuation:** In animated sequences, opacity of contextual structures may fluctuate between keyframes, causing visual inconsistency [S2].

## Subtopics

### Temporal Coherence Fix for Contextual Structures
A post-processing step applied to a sequence of keyframe Direct Volume Rendering Images (DVRIs) to stabilize the opacity of contextual structures across an animation [S2]. It prevents visual inconsistency caused by opacity fluctuations where a structure might appear highly transparent in one frame and less transparent in another [S2].
*   **Method:** For each structure, analyze all keyframes and record the lowest non-zero opacity assigned to that structure when used as context [S2]. For each keyframe, check if the context constraint is satisfied according to a context metric after assigning this recorded lowest opacity [S2]. If the condition is satisfied for all keyframes, commit the change to standardize the opacity [S2].
*   **Parameters:** Context metric (formula not provided) [S2].
*   **Pitfall:** Without this fix, contextual structures may cause confusion and inconsistency in the animation due to opacity fluctuations [S2].

## Operating characteristics
*   **Time Complexity:** Depends on the size of the hierarchy graph and the ghosting level $L$. Traversal is limited to depth $L$, so it is bounded by the number of nodes within $L$ edges of the focus clusters [S1, unofficial].
*   **Memory Complexity:** Requires storing the hierarchy graph and the modified CTF [S1, unofficial].
*   **Performance:** Experiments were conducted on a standard PC (Intel Core 2 Duo E6400, 3 GB RAM, GeForce 8600GT) [S2]. Rendering time for a CT head dataset (128×128×231) was 157 seconds to generate four images with 80% visibility of the brain structure [S2].
*   **Strengths:** Provides contextual information without cluttering the view; grayscale context enhances focus contrast [S1, unofficial].
*   **Limitations:** Opacity fluctuations in animations can cause visual inconsistency [S2].

## Background
The method was introduced in the context of structural focus+context rendering for volume data organized in a graph hierarchy [S1, unofficial]. It builds on the parent technique [Focus+Context via Opacity Modulation](14264-focus-context-via-opacity-modulation.md), which modifies the compositing scheme to increase transparency of flat regions while preserving local details. The temporal coherence fix was proposed to address issues in animated sequences [S2].
