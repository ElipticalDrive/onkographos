# Hybrid Rendering for Stress Tensor Fields

Also called: Focus and context visualization

## Overview
Hybrid Rendering for Stress Tensor Fields is a visualization technique that decouples the display of global context from local detail in stress tensor datasets by combining volume rendering with explicit geometric representations (glyphs and tensorlines) [S1, book]. It solves the problem of visual clutter and occlusion in dense tensor fields by allowing users to interactively select specific features via diagram views, which generates a mask to render those features as high-fidelity geometry while the remaining data is shown as a lower-opacity volume [S1, book].

## How it works
The method maintains two parallel rendering paths: a context path (volume rendering) and a focus path (geometric primitives) [S1, book]. Selection of focus regions is driven by user interaction with auxiliary diagram views, such as scatterplots or Mohr diagrams [S1, book].

### Inputs and Outputs
*   **Input:** A 3D stress tensor field $\mathbf{T}(\mathbf{x})$ defined on a voxel grid; user selections from 2D diagram views (e.g., eigenvalue plots) [S1, book].
*   **Output:** A composite image showing volume-rendered context and geometric focus elements [S1, book].

### Data Structures
1.  **Mask Volume $M(\mathbf{x})$:** A 3D volume of the same resolution as the tensor field. Each voxel stores a binary value: $M(\mathbf{x}) = 1$ for focus regions, $M(\mathbf{x}) = 0$ for context regions [S1, book].
2.  **Depth Buffer:** A 2D array storing depth values of the rendered geometric focus elements to handle occlusion against the volume [S1, book].

### Parameters
*   **Scalar Invariant for Context:** Typically von Mises stress, chosen by the user [S1, book].
*   **Opacity Modulation:** Opacity in focus regions is decreased to allow visibility of underlying or overlapping geometry [S1, book].
*   **Glyph Mapping Parameters:** $c$ determines the slope of the antisymmetric mapping function at the origin; $\alpha$ is a scaling parameter; a global scale parameter adjusts glyph size [S1, book].

### Steps
1.  **Mask Generation:** The user selects features in a diagram view. The system maps these selections to the 3D dataset, updating the mask volume $M(\mathbf{x})$ [S1, book]. Optionally, shear stress is mapped to transparency for the context view, where low shear stress yields low transparency and high shear stress yields nearly opaque points, effectively filtering out nearly isotropic tensors from the context view [S1, book].
2.  **Focus Rendering (Geometry):** Selected features are mapped to geometrical tensor representations [S1, book].
    *   **Tensorlines:** Seeds are randomly placed inside voxels where $M(\mathbf{x}) = 1$. Lines are integrated starting at each seed using a fourth-order Runge-Kutta scheme. Integration stops when the line enters an isotropic region [S1, book].
    *   **Tensor Glyphs:** Ellipsoids are drawn in focus regions. The local tensor is mapped to a positive-definite metric using an antisymmetric mapping to distinguish between positive and negative eigenvalues [S1, book]:
        $$ f(\sigma_i, c, \alpha) = \exp(\alpha \arctan(c \cdot \sigma_i)) $$
        where $\sigma_i$ are the eigenvalues of the tensor [S1, book]. Glyphs are scaled using the global scale parameter [S1, book].
    *   Geometric primitives are rendered into the scene, updating the depth buffer [S1, book].
3.  **Context Rendering (Volume):** Standard GPU ray-casting is performed for the volume rendering of the chosen scalar invariant [S1, book]. During volume traversal, the depth buffer is checked; rays are stopped as soon as they hit geometry positions to ensure correct intersection and prevent visual overlap [S1, book]. Opacity is decreased in regions where $M(\mathbf{x}) = 1$ to enhance focus geometry visibility [S1, book].

def hybrid_render_stress_tensor(tensor_field, user_selections, scalar_invariant_func):
    """
    Renders a stress tensor field using hybrid focus+context visualization.
    tensor_field: 3D list of tensors T(z,y,x)
    user_selections: criteria from diagram views
    scalar_invariant_func: function returning scalar from tensor
    """
    D, H, W = len(tensor_field), len(tensor_field[0]), len(tensor_field[0][0])
    
    # Step 1: Generate Mask Volume
    M = [[[False for _ in range(W)] for _ in range(H)] for _ in range(D)]
    for z in range(D):
        for y in range(H):
            for x in range(W):
                if matches_selections(tensor_field[z][y][x], user_selections):
                    M[z][y][x] = True
                    
    # Step 2: Render Focus Geometry
    cam_depth = [[0.0 for _ in range(W)] for _ in range(H)]
    
    # Render Tensorlines
    seeds = generate_random_seeds_in_mask(tensor_field, M)
    for seed in seeds:
        line = integrate_tensorline_rk4(tensor_field, seed)
        if not is_isotropic(line.end_point):
            render_line_to_depth_buffer(line, cam_depth)
            
    # Render Glyphs
    for z in range(D):
        for y in range(H):
            for x in range(W):
                if M[z][y][x]:
                    glyph = create_ellipsoid_glyph(tensor_field[z][y][x])
                    render_glyph_to_depth_buffer(glyph, cam_depth)
                    
    # Step 3: Context Rendering (Volume)
    color_buffer = [[[0.0, 0.0, 0.0] for _ in range(W)] for _ in range(H)]
    for y in range(H):
        for x in range(W):
            ray = cast_ray_through_pixel(x, y)
            t = ray.start
            alpha_accum = 0.0
            color = [0.0, 0.0, 0.0]
            while t < ray.end:
                if cam_depth[y][x] > 0 and cam_depth[y][x] < t:
                    break
                voxel = sample_tensor_field(tensor_field, ray.origin, ray.direction, t)
                scalar_val = scalar_invariant_func(voxel)
                opacity = 0.1 if M[voxel.z][voxel.y][voxel.x] else 0.5
                rgb = map_scalar_to_color(scalar_val)
                alpha_accum += (1.0 - alpha_accum) * opacity
                color = [color[i] + rgb[i] * opacity * (1.0 - alpha_accum) for i in range(3)]
                t += ray.step_size
                if alpha_accum >= 0.99:
                    break
            color_buffer[y][x] = color
    return color_buffer

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Provides clear separation of focus and context, allowing detailed analysis of specific stress features without losing the global spatial context provided by the volume rendering [S1, book].
*   **Limitations:** The quality of the focus representation depends on the density of seeds (for tensorlines) or the resolution of the glyph placement [S1, book].
*   **When to use:** When analyzing stress tensor fields where both global distribution (context) and local tensor orientation/magnitude (focus) are critical, and when users need to interactively select regions based on tensor properties [S1, book].

## Background
This method was introduced in the context of visual analysis of stress tensor fields, specifically in the paper "A Visual Approach to Analysis of Stress Tensor Fields" [S1, book]. It builds on the general concept of Focus+Context visualization, adapting it to the specific challenges of tensor data, such as the need to represent both magnitude and orientation [S1, book]. The approach leverages the structural relationships in tensor data, often visualized through Mohr diagrams or eigenvalue scatterplots, to drive the selection of focus regions [S1, book]. The use of antisymmetric mapping for glyphs allows for the distinction of eigenvalue signs, which is crucial in stress analysis [S1, book].
