# Hybrid Rendering for Stress Tensor Fields
Also called: Focus and context visualization

## Overview
Hybrid rendering for stress tensor fields is an interaction technique that separates a dataset into focus and context regions to facilitate detailed analysis of complex tensor data [S1, book]. It combines volume rendering of scalar invariants for the context with explicit geometric representations (glyphs or tensorlines) for user-selected focus regions [S1, book]. Unlike pure volume rendering, which can obscure internal structures, or pure glyph rendering, which lacks global context, this method uses an interactive mask volume to dynamically switch between these representations, allowing users to inspect local tensor details without losing the global stress distribution overview [S1, book].

## How it works
The method operates by maintaining a shared state between 2D diagram views (e.g., scatterplots, Mohr diagrams) and the 3D volume renderer [S1, book]. User selections in 2D update a 3D mask volume, which drives the hybrid rendering pipeline [S1, book].

### Inputs and Outputs
*   **Inputs:**
    *   Stress tensor field $T(\mathbf{x})$ defined on a 3D grid [S1, book].
    *   Scalar invariant field $S(\mathbf{x})$ (e.g., von Mises stress) derived from $T(\mathbf{x})$ [S1, book].
    *   User selection data from 2D views, defining the focus region [S1, book].
*   **Outputs:**
    *   Composite image containing volume-rendered context and geometric focus elements [G].

### Data Structures
1.  **Mask Volume ($M$):** A 3D scalar field, typically binary or continuous, where $M(\mathbf{x}) = 1$ indicates a focus voxel and $M(\mathbf{x}) = 0$ indicates a context voxel [S1, book]. This volume is updated interactively based on user selections in linked 2D views [S1, book].
2.  **Depth Buffer ($D_{geo}$):** A depth image storing the depth values of the explicitly rendered geometric primitives (glyphs and tensorlines) in the focus region [S1, book].

### Parameters
*   **Scalar Invariant:** The user selects a scalar field for context rendering, such as von Mises stress [S1, book].
*   **Opacity Function:** A transfer function mapping scalar values to opacity [S1, book]. In focus regions, opacity is decreased to allow visibility of underlying geometry [S1, book].
*   **Antisymmetric Mapping Parameters:**
    *   $c$: Determines the slope of the mapping function at the origin [S1, book].
    *   $\alpha$: A scaling parameter for the mapping [S1, book].
*   **Glyph Scale:** A global parameter controlling the size of tensor glyphs [S1, book].

### Steps
1.  **Mask Update:** When a user selects features in a 2D diagram view, the corresponding 3D voxels in the mask volume $M$ are updated to mark them as focus regions [S1, book].
2.  **Geometry Generation (Focus Region):**
    *   **Tensorlines:** Random seeds are placed within voxels where $M(\mathbf{x}) = 1$ [S1, book]. Lines are integrated through the tensor field starting from these seeds [S1, book]. Integration stops if the line enters an isotropic region (where eigenvalues are equal) [S1, book].
    *   **Tensor Glyphs:** Ellipsoids are generated for voxels where $M(\mathbf{x}) = 1$ [S1, book]. The tensor $T$ is mapped to a positive-definite metric to distinguish positive and negative eigenvalues using the antisymmetric mapping:
        $$ f(\sigma_i, c, \alpha) = \exp(\alpha \arctan(c \cdot \sigma_i)) $$
        where $c$ determines the slope at the origin and $\alpha$ is a scaling parameter [S1, book].
3.  **Geometry Rendering:** The generated tensorlines and glyphs are rendered to the framebuffer, updating the color buffer and writing to the depth buffer $D_{geo}$ [S1, book].
4.  **Volume Rendering (Context Region):**
    *   Standard GPU ray-casting is performed for the scalar invariant $S(\mathbf{x})$ [S1, book].
    *   During volume traversal, rays are stopped as soon as they hit geometry positions using a depth image of the geometry [S1, book].
    *   Rays terminate early when the traversal depth exceeds the stored geometry depth, ensuring correct occlusion of foreground primitives [S1, book].
    *   Opacity in focus regions ($M(\mathbf{x}) = 1$) is decreased to ensure the geometric representations remain visible [S1, book].

### Pseudocode
```python
def hybrid_render(tensor_field, scalar_invariant, mask_volume, user_selections, 
                  screen_width, screen_height, step_size, max_depth, c, alpha, glyph_scale):
    # Step 1: Update mask volume based on user selections in 2D views [S1, book]
    mask_volume = update_mask_from_selections(user_selections, tensor_field)

    # Step 2: Generate Geometry for Focus Regions [S1, book]
    geometry_list = []
    if render_mode == "tensorlines":
        seeds = random_seeds_inside_mask(mask_volume, tensor_field.grid_size)
        for seed in seeds:
            line = integrate_tensorline(seed, tensor_field, mask_volume, step_size)
            geometry_list.append(line)
    elif render_mode == "glyphs":
        for voxel_idx in voxels_in_mask(mask_volume):
            tensor = tensor_field[voxel_idx]
            eigenvalues = compute_eigenvalues(tensor)
            mapped_eigenvalues = [exp(alpha * arctan(c * sigma)) for sigma in eigenvalues]
            glyph = create_ellipsoid(mapped_eigenvalues, voxel_idx, glyph_scale)
            geometry_list.append(glyph)

    # Step 3: Render Geometry and Capture Depth [S1, book]
    depth_buffer = render_geometry(geometry_list, screen_width, screen_height)

    # Step 4: Volume Render Context with Depth Testing [S1, book]
    image = empty_image(screen_width, screen_height)
    for ray in rays_through_viewport(screen_width, screen_height):
        color = vec3(0.0)
        accumulated_alpha = 0.0
        t = ray.origin
        pixel_u, pixel_v = ray.screen_coords

        while t < ray.max_distance:
            # Convert continuous position to discrete grid index to fix vec3 indexing bug
            grid_idx = floor(t / step_size)
            if not in_bounds(grid_idx, tensor_field.grid_size):
                break

            # Check intersection with geometry depth buffer [S1, book]
            if depth_buffer[pixel_v, pixel_u] is not None and t > depth_buffer[pixel_v, pixel_u]:
                break

            # Get scalar invariant value [S1, book]
            s_val = sample_field(scalar_invariant, t, step_size)

            # Get mask value to adjust opacity [S1, book]
            m_val = sample_field(mask_volume, t, step_size)

            # Compute opacity: decreased in focus regions [S1, book]
            base_opacity = transfer_function(s_val)
            current_opacity = base_opacity * 0.5 if m_val > 0.5 else base_opacity

            # Composite [G]
            color += ray.color * current_opacity * (1.0 - accumulated_alpha)
            accumulated_alpha += current_opacity * (1.0 - accumulated_alpha)

            t += step_size

        image[pixel_v, pixel_u] = color
    return image

def integrate_tensorline(seed, tensor_field, mask_volume, step_size):
    points = [seed]
    current_pos = seed
    while True:
        tensor = sample_field(tensor_field, current_pos, step_size)
        eigenvalues = compute_eigenvalues(tensor)
        if is_isotropic(eigenvalues):
            break
        direction = dominant_eigenvector(tensor)
        current_pos = current_pos + direction * step_size
        points.append(current_pos)
        if not in_mask(current_pos, mask_volume, step_size):
            break
    return Line(points)

# Helper definitions
def update_mask_from_selections(selections, field):
    mask = zeros(field.grid_size)
    for sel in selections:
        mask[sel.grid_indices] = 1.0
    return mask

def random_seeds_inside_mask(mask, grid_size):
    seeds = []
    for i in range(mask.shape[0]):
        for j in range(mask.shape[1]):
            for k in range(mask.shape[2]):
                if mask[i, j, k] > 0.5:
                    seeds.append(vec3(i, j, k) + random_vec3())
    return seeds

def voxels_in_mask(mask):
    return [(i, j, k) for i in range(mask.shape[0]) for j in range(mask.shape[1]) for k in range(mask.shape[2]) if mask[i, j, k] > 0.5]

def render_geometry(geometry_list, width, height):
    buffer = zeros((height, width))
    for geom in geometry_list:
        for pixel in geom.screen_projection:
            buffer[pixel.v, pixel.u] = min(buffer[pixel.v, pixel.u], geom.depth)
    return buffer

def empty_image(width, height):
    return zeros((height, width, 3))

def rays_through_viewport(width, height):
    for v in range(height):
        for u in range(width):
            yield Ray(origin=vec3(0,0,0), direction=normalize(vec3(u - width/2, v - height/2, -focal_length)), screen_coords=(u, v))

def sample_field(field, pos, step_size):
    idx = floor(pos / step_size)
    if in_bounds(idx, field.grid_size):
        return field[idx]
    return 0.0

def in_bounds(idx, grid_size):
    return all(0 <= i < s for i, s in zip(idx, grid_size))

def in_mask(pos, mask, step_size):
    idx = floor(pos / step_size)
    return in_bounds(idx, mask.grid_size) and mask[idx] > 0.5

def compute_eigenvalues(tensor):
    return eigvals(tensor)

def is_isotropic(eigenvalues):
    return max(eigenvalues) - min(eigenvalues) < 1e-6

def dominant_eigenvector(tensor):
    return eigvecs(tensor)[:, 0]

def create_ellipsoid(mapped_eigenvalues, voxel_idx, scale):
    return Ellipsoid(center=voxel_idx, axes=mapped_eigenvalues * scale)

def transfer_function(s_val):
    return clamp(s_val / max_scalar, 0.0, 1.0)
```

### Edge Cases and Pitfalls
*   **Isotropic Regions:** Tensorlines must terminate when entering isotropic regions to avoid undefined integration directions [S1, book].
*   **Occlusion:** Failure to use the depth buffer $D_{geo}$ during volume traversal will result in volume data incorrectly occluding the foreground glyphs and tensorlines [S1, book].
*   **Eigenvalue Sign:** Standard ellipsoid glyphs cannot distinguish between positive and negative eigenvalues. The antisymmetric mapping is required to preserve this information [S1, book].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Allows simultaneous inspection of global stress distribution (context) and local tensor structure (focus) [S1, book]. The interactive mask allows dynamic exploration of specific stress states [S1, book].
*   **Limitations:** Requires careful tuning of opacity to balance visibility of context and focus [S1, book]. The antisymmetric mapping adds computational overhead for glyph generation [G].
*   **When to use:** When analyzing stress tensor fields where both global patterns and local tensor orientations/signs are critical, and users need to select specific regions for detailed inspection [S1, book].

## Background
This method was introduced in the context of visual analysis of stress tensor fields, specifically for engineering simulations like slit cube simulations [S1, book]. It builds on the principles of focus+context visualization, adapting them for 3D tensor data by combining volume rendering with explicit geometric primitives [S1, book]. The approach addresses the limitation of volume rendering in revealing internal tensor structures and the limitation of glyphs in providing global context [S1, book].
