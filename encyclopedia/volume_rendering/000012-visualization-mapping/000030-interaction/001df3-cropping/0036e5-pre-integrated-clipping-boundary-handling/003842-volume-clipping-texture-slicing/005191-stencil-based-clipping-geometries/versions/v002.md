# Stencil-based Clipping Geometries

Also called: Clipping geometries and Stenciling

## Overview
Stencil-based clipping is a hardware-accelerated method for volume clipping that uses the stencil buffer to restrict rendering to pixels inside or outside an arbitrary closed surface geometry [S1, unofficial]. It sets apart from sibling methods by decoupling the clipping boundary definition from the volume data itself, allowing any triangle mesh to act as a clipper without voxelization or ray-casting overhead [S1, unofficial].

## How it works
**Inputs:**
- A closed surface geometry defined by a list of triangles [S1, unofficial].
- A current slicing plane position and orientation [S1, unofficial].
- The volume texture data [S1, unofficial].

**Outputs:**
- A rendered slice where pixels are either accepted or rejected based on their intersection with the clipping geometry's cross-section [S1, unofficial].

**Data Structures:**
- **Stencil Buffer:** A per-pixel integer buffer that tracks which pixels are covered by the clipping cross-section [S1, unofficial].
- **Clipping Geometry:** A closed triangle mesh representing the arbitrary shape to clip against [S1, unofficial].

**Numbered Steps:**
1. **Enable Clipping Plane:** Enable an additional clipping plane in the rasterization stage with the same orientation and position as the current slicing plane [S1, unofficial].
2. **Render Back Faces:** Render the back faces of the clipping object in polygon mode [S1, unofficial]. This sets the stencil buffer for pixels covered by the cross-section without altering frame buffer color values [S1, unofficial].
3. **Correct Stencil Errors:** Render front faces into pixels where the stencil buffer was already set [S1, unofficial]. Clear the stencil buffer entry for these pixels if the pixel passes the depth test, correcting erroneous stencil entries caused by back-face-only rendering [S1, unofficial].
4. **Render Volume:** Render the textured volume polygon [S1, unofficial]. Configure the stencil test to accept or reject pixels based on the initialized stencil buffer, restricting drawing to pixels inside or outside the cross-section [S1, unofficial].

**Formulas:**
Not given in the sources.

**Parameters:**
- **Stencil Bits:** The number of bits provided by the visual hardware [S1, unofficial].
- **Stencil Planes:** Multiple stencil planes can be used to avoid clearing the buffer between slices [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Complex Geometries:** Rendering only back faces fails to determine the cross-section exactly for complex geometries [S1, unofficial]. This is corrected by the subsequent front-face pass [S1, unofficial].
- **Stencil Buffer Overflow:** The number of slices that can be processed without clearing the buffer depends on the number of stencil bits provided by the visual hardware [S1, unofficial].

**Pseudocode:**
```python
def render_clipped_slice(clipping_mesh, slicing_plane, volume_texture, stencil_buffer, stencil_bits):
    """
    Renders a volume slice clipped by an arbitrary closed surface using the stencil buffer.
    """
    # Step 1: Enable clipping plane matching the slicing plane
    enable_clipping_plane(slicing_plane)
    
    # Step 2: Render back faces to set stencil buffer
    set_stencil_op(pass_depth=REPLACE, fail_depth=KEEP, fail_stencil=KEEP)
    set_stencil_func(compare=ALWAYS, ref=1, mask=0xFF)
    set_cull_mode(cull_front=True)
    set_color_write(enabled=False)
    set_depth_write(enabled=False)
    draw_mesh(clipping_mesh)
    set_color_write(enabled=True)
    set_depth_write(enabled=True)
    
    # Step 3: Correct stencil errors by rendering front faces
    set_stencil_op(pass_depth=ZERO, fail_depth=KEEP, fail_stencil=KEEP)
    set_stencil_func(compare=EQUAL, ref=1, mask=0xFF)
    set_cull_mode(cull_front=False)
    set_color_write(enabled=False)
    set_depth_write(enabled=False)
    set_depth_test(enabled=True)
    draw_mesh(clipping_mesh)
    set_color_write(enabled=True)
    set_depth_write(enabled=True)
    set_depth_test(enabled=False)
    
    # Step 4: Render volume with stencil test
    set_stencil_func(compare=EQUAL, ref=1, mask=0xFF)
    set_stencil_op(pass_depth=KEEP, fail_depth=KEEP, fail_stencil=KEEP)
    draw_volume_slice(volume_texture, slicing_plane)
    
    disable_clipping_plane()
```

## Subtopics

### Multi-Slice Stenciling
Uses different stencil planes to process multiple slices without clearing the buffer, limited by stencil bit depth [S1, unofficial].

### Arbitrary Geometry Support
Allows any closed triangle mesh to define the clip boundary, supporting transformations without additional overhead [S1, unofficial].

- **Time Complexity:** Not given in the sources.

- **Limitations:** The number of slices that can be processed without clearing the buffer depends on the number of stencil bits provided by the visual hardware [S1, unofficial].

## Background
The method was described by Meissner in the context of volume visualization and rendering techniques [S1, unofficial]. It leverages existing rasterization features to provide a flexible tool for carving portions out of the data in an intuitive way [S1, unofficial].
