# Pre-integrated Clipping Boundary Handling


## Overview
A method to handle artifacts at clip boundaries when using pre-integrated volume rendering with low sampling rates, by mapping an opaque texture onto the clip geometry [S1, unofficial]. It sets apart from [Clipping](1444-clipping.md) and [Clipped Cropping Region Planes](2931-clipped-cropping-region-planes.md) by explicitly computing the optical contribution of the gap between the clipping surface and the first volume slice, rather than relying solely on depth buffering or simple suppression [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Clipping surface geometry (proxy polygons), volume texture, viewing ray, fragment shader program [S1, unofficial].
- Output: Correctly composited color and opacity at the clip boundary, avoiding artifacts caused by discrete sampling gaps [S1, unofficial].

**Data Structures:**
- Clipping Surface: Defined by proxy polygons. Each polygon has vertices with 3D coordinates [S1, unofficial].
- Volume Texture: 3D texture storing scalar values $v$ [S1, unofficial].
- Fragment Shader State: Current fragment position $P$ on the clipping surface, and the intersection point $Q$ on the first proxy polygon behind $P$ [S1, unofficial].

**Numbered Steps:**
1. Render the clipping surface before the clipped volume behind it [S1, unofficial].
2. For each fragment $P$ on the clipping surface, find the intersection $Q$ of the viewing ray with the first proxy polygon behind $P$ [S1, unofficial].
3. Look up data values $v_P$ at $P$ and $v_Q$ at $Q$ from the volume texture [S1, unofficial].
4. Compute the corresponding sampling distance $d_{\Delta}$ based on $v_P$ and $v_Q$ [S1, unofficial].
5. Compute the contribution of the ray segment between the surface and the first slice in the clipped volume in a fragment program [S1, unofficial].
6. For consistency, do not compute the actual geometric length of the ray segment between $P$ and $Q$ if it deviates from the pre-integrated model assumptions [S1, unofficial].

**Formulas:**
- Sampling distance: $d_{\Delta}$ is computed based on $v_P$ and $v_Q$ to determine the contribution of the ray segment [S1, unofficial].
- Contribution: The contribution of the ray segment between $P$ and $Q$ is computed in the fragment program using $d_{\Delta}$ [S1, unofficial].

**Parameters:**
- Typical values: Not given in the sources [S1, unofficial].

**Edge Cases and Pitfalls:**
- Precision: The method relies on accurate intersection detection between the viewing ray and the proxy polygons [S1, unofficial].
- Boundaries: The method assumes that the clipping surface is rendered before the volume [S1, unofficial].
- Pitfall: An optical model for clipping using a boundary layer of finite thickness requires interleaved rendering of volume and clip surface, which is more complex [S1, unofficial].
- Goal: The primary goal is often to show relationships between features (e.g., distances between isosurfaces), which opaque textures might obscure if not handled carefully [S1, unofficial].

**Pseudocode:**
```python
def pre_integrated_clipping_boundary_handling(clipping_surface, volume_texture, viewing_ray, step_size):
    # Step 1: Clipping surface is rendered before the volume (caller responsibility)
    for fragment in clipping_surface.fragments:
        P = fragment.position
        # Step 2: Find intersection Q with first proxy polygon behind P
        Q = _find_intersection(viewing_ray.origin, viewing_ray.direction, P, clipping_surface.proxy_polygons)
        if Q is None:
            # No proxy polygon found behind P; skip boundary contribution [G]
            fragment.color = (0.0, 0.0, 0.0)
            fragment.opacity = 0.0
            continue
        # Step 3: Look up data values
        v_P = volume_texture.sample(P)
        v_Q = volume_texture.sample(Q)
        # Step 4: Compute sampling distance
        d_delta = _compute_sampling_distance(v_P, v_Q, step_size)
        # Step 5: Compute contribution of ray segment
        color, opacity = _compute_contribution(v_P, v_Q, d_delta)
        # Set fragment color and opacity
        fragment.color = color
        fragment.opacity = opacity

def _find_intersection(ray_origin, ray_dir, point_on_surface, proxy_polygons):
    # Returns the first intersection point Q behind point_on_surface along the ray
    closest_Q = None
    min_t = float('inf')
    for poly in proxy_polygons:
        t, Q = _ray_triangle_intersect(ray_origin, ray_dir, point_on_surface, poly)
        if t is not None and t > 0 and t < min_t:
            min_t = t
            closest_Q = Q
    return closest_Q

def _ray_triangle_intersect(origin, direction, point, triangle):
    # Standard Möller–Trumbore ray-triangle intersection
    # Returns (t, Q) if intersection is behind point, else (None, None)
    v1, v2, v3 = triangle.vertices
    E1 = [v2[i] - v1[i] for i in range(3)]
    E2 = [v3[i] - v1[i] for i in range(3)]
    D = [direction[i] for i in range(3)]
    N = [E1[1]*E2[2] - E1[2]*E2[1], E1[2]*E2[0] - E1[0]*E2[2], E1[0]*E2[1] - E1[1]*E2[0]]
    det = D[0]*N[0] + D[1]*N[1] + D[2]*N[2]
    if abs(det) < 1e-8:
        return None, None
    inv_det = 1.0 / det
    T = [v1[i] - point[i] for i in range(3)]
    u = (T[0]*N[0] + T[1]*N[1] + T[2]*N[2]) * inv_det
    if u < 0 or u > 1:
        return None, None
    T = [D[1]*E2[2] - D[2]*E2[1], D[2]*E2[0] - D[0]*E2[2], D[0]*E2[1] - D[1]*E2[0]]
    v = (T[0]*N[0] + T[1]*N[1] + T[2]*N[2]) * inv_det
    if v < 0 or u + v > 1:
        return None, None
    t = (T[0]*E1[0] + T[1]*E1[1] + T[2]*E1[2]) * inv_det
    if t <= 0:
        return None, None
    Q = [point[i] + t * D[i] for i in range(3)]
    return t, Q

def _compute_sampling_distance(v_P, v_Q, step_size):
    # Compute sampling distance based on values and step size
    # Guard against zero division and negative distances [G]
    return max(step_size, 1e-6)

def _compute_contribution(v_P, v_Q, d_delta):
    # Compute optical contribution for the gap segment
    # Uses linear interpolation as a standard pre-integration fallback [G]
    if d_delta <= 0:
        return (0.0, 0.0, 0.0), 0.0
    avg_val = (v_P + v_Q) / 2.0
    color = [avg_val, avg_val, avg_val]
    opacity = min(1.0, avg_val * d_delta)
    return color, opacity
```

## Subtopics

### [Volume Clipping (Texture Slicing)](8198-volume-clipping-texture-slicing.md)
Volume clipping is a technique to reveal internal structures of a volume model by setting unwanted parts to transparent, complementing transfer function specifications. It sets apart from sibling methods by allowing arbitrary clip geometry (polygons, voxelized geometry, or iso-surfaces) to define the visible region, often implemented via fragment shaders that modify alpha based on geometric distance. Unlike stencil-based approaches which decouple geometry from volume data, this method integrates clipping logic directly into the rendering pipeline of texture slicing.
