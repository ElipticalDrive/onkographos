# AABB Clamping
Also called: AABB Clamping History Rectification

## Overview
AABB Clamping is a history rectification method that individually limits each channel of the reprojected historical color to the minimum and maximum values of the current frame's neighborhood samples [S1, unofficial]. It builds on [YCoCg Color Space Rectification](1971-ycocg-color-space-rectification.md), which transforms colors into a luminance-chrominance space before applying rectification [G]. What sets it apart from its siblings and nearest alternatives is its use of a simple Axis-Aligned Bounding Box (AABB) approximation constructed from per-channel minimum and maximum values, whereas variants like Variance Clipping use statistical distributions to define bounds [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** The reprojected historical color $c_h$, and a set of $N$ current-frame neighborhood samples $c_i \in \mathbb{R}^k$ (where $k$ is the number of channels, e.g., 3 or 4) [S1, unofficial].
*   **Output:** The rectified color $c_r$ [S1, unofficial].

**Data Structures:**
*   **AABB Bounds:** Two vectors, $c_{min}$ and $c_{max}$, each of size $k$ [S1, unofficial].
    *   $c_{min}[j] = \min_{i=1..N}(c_i[j])$ for each channel $j$ [S1, unofficial].
    *   $c_{max}[j] = \max_{i=1..N}(c_i[j])$ for each channel $j$ [S1, unofficial].

**Steps:**
1.  **Construct AABB:** Compute the component-wise minimum and maximum across all current-frame neighborhood samples to define the bounding box bounds $c_{min}$ and $c_{max}$ [S1, unofficial].
2.  **Clamp:** For each channel $j$ of the historical color $c_h$, clamp the value between the corresponding bounds $c_{min}[j]$ and $c_{max}[j]$ [S1, unofficial].

**Formula:**
The rectified color $c_r$ is obtained by clamping $c_h$ component-wise:
$$c_r = \min(\max(c_h, c_{min}), c_{max}) \quad (2.2)$$
where $\min$, $\max$, and arithmetic operations are performed component-wise [S1, unofficial].

**Pseudocode:**
```python
def aabb_clamp(historical_color, neighborhood_samples):
    """
    Rectifies historical color by clamping it to the AABB defined by neighborhood samples.
    
    Args:
        historical_color: List/Array of floats, shape (k,) representing ch.
        neighborhood_samples: List/Array of floats, shape (N, k) representing ci.
        
    Returns:
        List/Array of floats, shape (k,) representing cr.
    """
    k = len(historical_color)
    N = len(neighborhood_samples)
    
    # Step 1: Construct AABB bounds
    c_min = [0.0] * k
    c_max = [0.0] * k
    for j in range(k):
        c_min[j] = min(sample[j] for sample in neighborhood_samples)
        c_max[j] = max(sample[j] for sample in neighborhood_samples)
    
    # Step 2: Clamp historical color to bounds
    rectified_color = [0.0] * k
    for j in range(k):
        val = historical_color[j]
        if val < c_min[j]:
            val = c_min[j]
        elif val > c_max[j]:
            val = c_max[j]
        rectified_color[j] = val
        
    return rectified_color
```

**Edge Cases and Pitfalls:**
*   **Corner Accumulation:** Because each channel is individually clamped, values tend to collect in the corners of the AABB [S1, unofficial].
*   **Color Artifacts:** This corner accumulation can lead to strange color-related artifacts in scenes with significant color information, although it is generally not an issue for grayscale scenes [S1, unofficial].
*   **Accuracy:** This method is a fast approximation of the tighter convex hull approach. It is less accurate but much cheaper to build and intersect against [S1, unofficial].

## Subtopics

### [History Rectification](2503-history-rectification.md)
History Rectification is a class of Temporal Anti-Aliasing techniques that correct historical color values before blending by restricting the reprojected history to a region defined by current-frame neighborhood samples. It solves the problem of temporal lag and ghosting during abrupt scene changes where a baseline Exponential Moving Average fails to react quickly enough. What sets it apart from its siblings and nearest alternatives is the use of a spatial neighborhood of current-frame samples to define a "color extent" or bound; if the historical value falls outside this extent, it is considered stale and is corrected prior to blending. This approach builds on [AABB Clamping](2019-aabb-clamping.md), which uses a simpler Axis-Aligned Bounding Box approximation, whereas History Rectification encompasses more sophisticated variants like Variance Clipping and AABB Clipping that better handle color information and statistical distributions.

## Operating characteristics
*   **Time Complexity:** $O(N \cdot k)$ to compute min/max over $N$ samples with $k$ channels, followed by $O(k)$ for clamping [G]. It is computationally efficient compared to convex hull projection [S1, unofficial].
*   **Memory Complexity:** $O(k)$ to store the min and max bounds [G].
*   **Strengths:** Fast approximation of history rectification; easy to implement and intersect against; ensures history remains within valid color extent [S1, unofficial].
*   **Limitations:** Less accurate than convex hull methods; prone to color artifacts due to channel-wise clamping causing values to collect in AABB corners [S1, unofficial].
*   **When to use:** When performance is critical and the scene is predominantly grayscale or has limited color variation [G].
*   **When not to use:** In scenes with complex color information where color artifacts are noticeable, or when higher fidelity rectification (like AABB Clipping or Variance Clipping) is required [S1, unofficial].

## Background
AABB Clamping is a history rectification method implemented and evaluated in the context of temporal anti-aliasing for real-time froxel-based volumetric rendering [S1, unofficial]. It serves as a fast approximation to the computationally expensive convex hull projection, which is too costly for real-time rendering constraints [S1, unofficial]. The method is part of a class of techniques that correct historical color values before blending by restricting them to a region defined by current-frame neighborhood samples [S1, unofficial].
