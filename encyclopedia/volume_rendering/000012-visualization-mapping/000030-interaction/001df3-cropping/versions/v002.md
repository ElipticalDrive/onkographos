# Cropping
Also called: Slab Cropping, Slab-based cropping, Axis-Aligned Cropping

## Overview
Cropping is an interaction technique that restricts volume rendering to a specific region of interest by cutting off the volume along planes parallel to its faces [S2, unofficial]. It solves the problem of visual clutter and performance overhead by allowing users to see inside a volume dataset without altering the underlying data [S1]. Unlike [Clipping plane for volume suppression](887-clipping-plane-for-volume-suppression.md), which uses arbitrary-angle planes, cropping is strictly axis-aligned relative to the volume's object coordinates [S2, unofficial]. It differs from [Clipping](1444-clipping.md) by defining a bounded region of visibility via slabs rather than a half-space relative to the camera [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A volume dataset defined in object coordinates, and six scalar values defining the cropping boundaries: $x_{min}, x_{max}, y_{min}, y_{max}, z_{min}, z_{max}$ [S2, unofficial].
*   **Output:** A rendered image where only voxels within the defined region contribute to the final color; voxels outside are invisible (opacity set to zero) [S2, unofficial].

**Data Structures:**
The method relies on six registers or parameters defining three axis-aligned slabs [S2, unofficial].
*   $S_x$: The slab along the X-axis, defined by $x_{min}$ and $x_{max}$.
*   $S_y$: The slab along the Y-axis, defined by $y_{min}$ and $y_{max}$.
*   $S_z$: The slab along the Z-axis, defined by $z_{min}$ and $z_{max}$.

**Steps:**
1.  **Define Slabs:** Construct three axis-aligned slabs based on the input parameters. A point $(x, y, z)$ is in $S_x$ if $x_{min} \le x \le x_{max}$ [S2, unofficial]. Similarly for $S_y$ and $S_z$ [S2, unofficial].
2.  **Combine Slabs:** Determine the region of visibility by combining the slabs using set operations (intersection, union, or inverse) [S2, unofficial]. For example, the intersection of all three slabs creates a rectangular box [S2, unofficial].
3.  **Visibility Test:** For each sample at position $(x, y, z)$, determine if it falls within the defined region of visibility [S2, unofficial].
4.  **Render:** Render only the axis-aligned sets of voxels that are inside the cut-planes (or outside, depending on the chosen logic) [S2, unofficial].

**Formulas:**
The condition for a sample at $(x, y, z)$ to be visible in the standard intersection case is:
$$
(x_{min} \le x \le x_{max}) \land (y_{min} \le y \le y_{max}) \land (z_{min} \le z \le z_{max})
$$
[S2, unofficial]

**Parameters:**
*   **Cropping Planes:** The six values ($x_{min}, x_{max}, \dots$) may fall at arbitrary voxel positions [S2, unofficial].
*   **Logic:** Boolean operations (AND, OR, NOT) applied to the slab sets [S2, unofficial].

**Pitfalls:**
*   **Precision:** Cropping planes must be correctly mapped to the voxel grid. If planes fall between voxels, the exact inclusion/exclusion depends on the sampling strategy [S2, unofficial].
*   **Empty Regions:** If $x_{min} > x_{max}$ or similar for other axes, the region of visibility is empty, resulting in a blank image [G].
*   **Depth Order:** When using cutting planes, a depth texture from a prepass is required to maintain correct depth order for entry and exit points [S1].

**Pseudocode:**
```python
def is_visible(x, y, z, x_min, x_max, y_min, y_max, z_min, z_max):
    """Determines if a sample point is within the axis-aligned cropping region."""
    return (x >= x_min) and (x <= x_max) and \
           (y >= y_min) and (y <= y_max) and \
           (z >= z_min) and (z <= z_max)

def render_volume(volume_data, x_min, x_max, y_min, y_max, z_min, z_max):
    """Renders the volume, skipping samples outside the cropping region."""
    output_image = []
    for x, y, z in volume_data:
        if is_visible(x, y, z, x_min, x_max, y_min, y_max, z_min, z_max):
            # Standard volume rendering step: sample transfer function and accumulate color
            color = sample_volume(volume_data, x, y, z)
            accumulate_color(output_image, x, y, z, color)
        else:
            # Sample is outside the region of visibility; opacity is zero
            pass
    return output_image
```

## Subtopics

### [Clipping plane for volume suppression](887-clipping-plane-for-volume-suppression.md)
A clipping plane for volume suppression is an interaction technique that uses an independently movable planar slice of arbitrary thickness to suppress portions of a volume dataset, generating cutaway views. Unlike the parent [Cropping](1648-cropping.md), which restricts the view to a rectangular slab defined by axis-aligned planes, this method allows a single plane at an arbitrary angle to cut through the volume. It is distinguished from [Clipping](1444-clipping.md) by its specific implementation of a thickness-based transition region and its role as a frame-type widget that also supports slice mapping and position querying.

### [Clipping](1444-clipping.md)
Clipping is a technique to enable correct perspective projection in sliced-based volume rendering by defining a near clipping boundary relative to the viewpoint. It solves the problem of incorrect depth impression in inside views, where parallel projection fails to provide accurate spatial cues. Unlike general cropping [Cropping](1648-cropping.md) which cuts along volume faces, this method clips against the camera's near/far planes and active clipping planes to ensure only relevant slabs are processed.

### [Variance Clipping](1970-variance-clipping.md)
Variance clipping is a history rectification technique used in Temporal Anti-Aliasing (TAA) for volumetric rendering that constructs a tight bounding box for valid color values based on the statistical mean and variance of a neighborhood of samples. It solves the problem of ghosting artifacts during rapid illumination changes by adapting the clipping region to the local signal distribution, allowing it to reconstruct signals faster than fixed-bound methods. It sets itself apart from [AABB Clamping](2019-aabb-clamping.md) and [AABB Clipping](1444-clipping.md) by using a statistically derived, typically smaller, clipping region that reacts more precisely to changes, though at the cost of higher temporal instability.

### Clipped Cropping Region Planes
An algorithm to clamp user-defined cropping planes to the volume's bounding box bounds, ensuring the cropping region is valid and contained within the data [S4, unofficial]. It retrieves volume bounds into `volBounds[6]` using `this->GetInput(0)->GetBounds(volBounds)` [S4, unofficial]. For each min plane at index $i$, if `CroppingRegionPlanes[i] < volBounds[i]`, it sets `ClippedCroppingRegionPlanes[i] = volBounds[i]`; otherwise, it sets `ClippedCroppingRegionPlanes[i] = CroppingRegionPlanes[i]` [S4, unofficial]. The same logic applies to max planes [S4, unofficial]. A pitfall is that if cropping is not enabled or planes are not ordered (0<1, 2<3, 4<5), the parent `Render()` method silently stops [S4, unofficial].

### Clipping Geometry Illumination
Clipping geometry makes parts of the volume transparent. At the boundary of this geometry, the surface normal of the clipping geometry is used for illumination instead of the volume's gradient [S5, unofficial]. This technique was described in Weiskopf et al., TVCG 2003 [S5, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of samples or voxels processed. The visibility test itself is a simple constant-time comparison per sample [S2, unofficial].
*   **Memory Complexity:** $O(1)$ additional memory for the six plane parameters [S2, unofficial].
*   **Strengths:** Simple to implement; provides an easy way to specify a rectilinear region of interest for rendering [S2, unofficial]; reduces rendering load by ignoring irrelevant data [S2, unofficial].
*   **Limitations:** Only supports axis-aligned regions; cannot handle arbitrary orientations or complex shapes [S2, unofficial].
*   **When to use:** When the user needs to inspect a specific rectangular sub-volume or reduce rendering time for large datasets [S2, unofficial].
*   **When not to use:** When the region of interest is non-axis-aligned or irregularly shaped; use [Clipping plane for volume suppression](887-clipping-plane-for-volume-suppression.md) instead [S2, unofficial].

## Background
Cropping was introduced as a feature in the VolumePro real-time ray-casting system [S2, unofficial]. It allows users to visualize slices, cross-sections, or other portions of the volume, providing creative ways to see inside the data [S2, unofficial]. The technique is also described in patent US 6,407,737 B1, which details axis-aligned cropping for partitioned volume data sets [S3, unofficial].
