# Convex VOI Clipping via Weighted Sweep Graph

Also called: Clipper, WSG-based clipping

## Overview
This method is a CPU-based clipping algorithm that intersects a sequence of parallel sampling planes against a user-defined convex Volume of Interest (VOI) to reduce the computational load on the GPU [S1]. It solves the problem of unnecessary volume rendering computation in empty or irrelevant regions by transmitting only the clipped, valid portions of sampling planes to the GPU [S1]. It sets itself apart from general convex clipping algorithms by exploiting the coherence between parallel planes and using a Weighted Sweep Graph (WSG) to efficiently manage topological changes (vertex events) during the sweep, avoiding the recomputation of edge lists from scratch for every plane [S1].

## How it works
**Inputs:**
1. A convex VOI defined by a user via a carving approach starting from a basic convex shape (e.g., a cube) [S1].
2. A sequence of parallel sampling planes [S1].

**Outputs:**
A sequence of convex polygons, one for each sampling plane that intersects the VOI [S1]. Each polygon is defined by an ordered list of vertices lying on the edges of the VOI [S1].

**Data Structures:**
*   **Weighted Sweep Graph (WSG):** A graph structure that encodes the topological structure of the convex volume [S1]. It maintains the current list of edges intersected by the sweep plane, ordered to form the convex polygon [S1]. It detects vertex events and facilitates edge list updates by adding or removing edges incident to the vertex generating the event [S1].

**Algorithm Steps:**

1.  **VOI Definition:** The user defines the convex VOI starting from a basic convex shape (e.g., a cube) [S1]. Cutting planes are added to slice the volume [S1]. Each cutting plane is specified by a normal vector, controlled by dragging a line endpoint from the VOI center, and a reference point, controlled by a slider specifying the distance from the VOI center [S1].
2.  **Intersection Algorithm:** Compute the intersection of parallel sampling planes against the convex VOI [S1]. The algorithm exploits coherence between parallel planes [S1].
3.  **Polygon Generation:** The intersection of a single plane against the convex VOI results in a convex polygon defined by an ordered list of vertices lying on the edges of the VOI [S1].
4.  **Edge List Reuse:** For a parallel plane near the previous one, compute the new polygon vertices by intersecting the same list of edges from the previous calculation against the new plane [S1].
5.  **Vertex Event Handling:** If a VOI vertex lies between two planes, the edge list must be updated by adding or removing edges incident to that vertex [S1]. The WSG encodes the topological structure to maintain edge order and detect vertex events [S1].

**Parameters:**
*   **VOI Center:** The reference point for user interaction (normal vector direction and plane distance) [S1].
*   **Plane Normal:** The viewing direction, which is parallel for all sampling planes [S1].

**Edge Cases and Pitfalls:**
*   **Vertex Events:** A vertex lying exactly between two sampling planes triggers an edge list update [S1].
*   **Parallel Edges:** An edge parallel to the sampling plane yields no unique intersection point and must be skipped or handled as a degenerate boundary case [G].
*   **Precision:** Floating-point precision issues may arise when determining if a vertex is between two planes or if an intersection point lies exactly on an edge [G].

**Pseudocode:**

```python
def convex_voi_clipping(voi_edges, voi_vertices, sampling_planes, sweep_normal):
    """
    voi_edges: List of edges, each edge is a tuple (vertex_index_A, vertex_index_B)
    voi_vertices: List of vertices, each vertex is a 3D point (x, y, z)
    sampling_planes: List of distances along the sweep_normal for each plane
    sweep_normal: Unit vector (n_x, n_y, n_z) parallel to the viewing direction
    Returns: List of polygons, each polygon is a list of 3D points
    """
    # Precompute vertex projections along the sweep direction
    vertex_projections = [dot(v, sweep_normal) for v in voi_vertices]
    
    # Sort sampling planes by distance along the sweep direction
    sorted_plane_indices = sorted(range(len(sampling_planes)), key=lambda i: sampling_planes[i])
    polygons = []
    
    # Initialize edge list with edges intersecting the first plane
    current_edges = []
    first_plane_dist = sampling_planes[sorted_plane_indices[0]]
    for e_idx, (v_a, v_b) in enumerate(voi_edges):
        proj_a = vertex_projections[v_a]
        proj_b = vertex_projections[v_b]
        # Edge crosses the plane if endpoints are on opposite sides or on the plane
        if (proj_a - first_plane_dist) * (proj_b - first_plane_dist) <= 0:
            current_edges.append(e_idx)
            
    # Order edges to form a convex polygon cycle
    current_edges = sort_edges_to_polygon_order(current_edges, voi_edges)
    
    for i, p_idx in enumerate(sorted_plane_indices):
        plane_dist = sampling_planes[p_idx]
        
        # Check for vertex events between previous plane and current plane
        if i > 0:
            prev_plane_dist = sampling_planes[sorted_plane_indices[i-1]]
            for v_idx in range(len(voi_vertices)):
                proj_v = vertex_projections[v_idx]
                # Vertex lies strictly between the two planes
                if (prev_plane_dist < proj_v < plane_dist) or (plane_dist < proj_v < prev_plane_dist):
                    current_edges = update_edge_list_for_vertex_event(current_edges, v_idx, voi_edges)
                    current_edges = sort_edges_to_polygon_order(current_edges, voi_edges)
        
        # Compute polygon vertices by intersecting current edges with the plane
        polygon_vertices = []
        for e_idx in current_edges:
            v_a, v_b = voi_edges[e_idx]
            proj_a = vertex_projections[v_a]
            proj_b = vertex_projections[v_b]
            denom = proj_b - proj_a
            if abs(denom) < 1e-9:
                continue # Edge parallel to plane
            t = (plane_dist - proj_a) / denom
            if 0.0 <= t <= 1.0:
                p = add(voi_vertices[v_a], scale(sub(voi_vertices[v_b], voi_vertices[v_a]), t))
                polygon_vertices.append(p)
                
        polygons.append(polygon_vertices)
        
    return polygons

def sort_edges_to_polygon_order(edge_indices, voi_edges):
    """Order edges to form a convex polygon cycle via graph traversal [G]."""
    if not edge_indices:
        return []
    adj = {}
    for e_idx in edge_indices:
        v1, v2 = voi_edges[e_idx]
        adj.setdefault(v1, []).append(v2)
        adj.setdefault(v2, []).append(v1)
    start_v = voi_edges[edge_indices[0]][0]
    path = [start_v]
    current_v = start_v
    visited = {start_v}
    while len(path) < len(edge_indices) + 1:
        neighbors = adj.get(current_v, [])
        next_v = None
        for n in neighbors:
            if n not in visited:
                next_v = n
                break
        if next_v is None:
            if path[0] in neighbors:
                next_v = path[0]
            else:
                break
        path.append(next_v)
        visited.add(next_v)
        current_v = next_v
    ordered_edges = []
    for k in range(len(path) - 1):
        for e_idx in range(len(voi_edges)):
            if voi_edges[e_idx] == (path[k], path[k+1]) or voi_edges[e_idx] == (path[k+1], path[k]):
                ordered_edges.append(e_idx)
                break
    return ordered_edges

def update_edge_list_for_vertex_event(current_edges, v_idx, voi_edges):
    """Toggle inclusion of edges incident to a vertex when the sweep passes it [G].
    Removes the two edges in current_edges incident to v_idx, and adds the two
    edges not in current_edges that are incident to v_idx."""
    incident_edges = [e_idx for e_idx, (v_a, v_b) in enumerate(voi_edges) if v_idx in (v_a, v_b)]
    new_edges = [e for e in current_edges if e not in incident_edges]
    new_edges.extend([e for e in incident_edges if e not in current_edges])
    return new_edges

def dot(v1, v2):
    return v1[0]*v2[0] + v1[1]*v2[1] + v1[2]*v2[2]

def sub(v1, v2):
    return (v1[0]-v2[0], v1[1]-v2[1], v1[2]-v2[2])

def add(v1, v2):
    return (v1[0]+v2[0], v1[1]+v2[1], v1[2]+v2[2])

def scale(v, s):
    return (v[0]*s, v[1]*s, v[2]*s)
```

## Subtopics

### [GPU-based Eraser and Digger Tools](15966-gpu-based-eraser-and-digger-tools.md)
GPU-based eraser and digger tools are interactive visualization methods that allow users to selectively remove voxels from a volume rendering using a "painting" paradigm. They solve the problem of intuitive, real-time data manipulation by mapping 2D screen interactions to 3D voxel selection via line-of-sight projection. Unlike the parent [Convex VOI Clipping via Weighted Sweep Graph](15939-convex-voi-clipping-via-weighted-sweep-graph.md), which defines a static convex boundary for the entire Volume of Interest (VOI), these tools define dynamic, user-controlled removal zones that persist across multiple interaction strokes.

*   **Strengths:** Reduces GPU computation by clipping empty regions [S1]. Exploits coherence between parallel planes [S1]. Supports interactive VOI definition [S1].
*   **Limitations:** Adds CPU overhead for clipping calculations [S1]. Limited to convex VOIs [S1].
*   **When to use:** When the VOI is convex and the user wants to interactively define the clipping region [S1]. When the GPU is the bottleneck and can benefit from reduced sampling [S1].
*   **When not to use:** When the VOI is non-convex [G]. When the CPU is the bottleneck [G].

## Background
The method was proposed in the paper "Real-time interactive visualization and manipulation of the volumetric data using GPU-based methods" [S1]. It addresses the need for efficient clipping of volumetric data to improve rendering performance [S1]. The WSG is a novel data structure introduced in this work to manage the topological changes during the sweep [S1].
