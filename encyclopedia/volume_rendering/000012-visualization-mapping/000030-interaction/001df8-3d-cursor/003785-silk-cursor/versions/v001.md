# Silk Cursor
Also called: Semi-transparent lining cursor, Partial occlusion cursor

## Overview
The Silk Cursor is a 3D interaction technique for volumetric displays that enhances spatial awareness by lining a rectangular cursor with semi-transparent surfaces [S1, unofficial]. It solves the ambiguity of target depth relative to the cursor by creating a partial occlusion effect, allowing users to distinguish if a target is in front of, inside, or behind the cursor [S1, unofficial]. It is distinct from the Surface-constrained Cursor, which restricts movement to a boundary, whereas the Silk Cursor operates within the volume [S2].

## How it works
**Inputs and Outputs:**
*   **Input:** 2D cursor position from an input device (e.g., mouse, tracker).
*   **Output:** A 3D rectangular cursor rendered within the volumetric scene.

**Data Structures:**
*   **Cursor Geometry:** A rectangular prism (box) defined by its center position $(x, y, z)$ and dimensions $(w, h, d)$.
*   **Rendering Attributes:** The faces of the prism are rendered with semi-transparency (alpha blending). The interior is typically empty or transparent to allow visibility of contained objects.

**Steps:**
1.  **Map Input:** Convert the 2D input device coordinates into a 3D ray or position within the volumetric display's coordinate space.
2.  **Define Cursor:** Instantiate a rectangular box at the mapped 3D position.
3.  **Render Lining:** Render the six faces of the box using semi-transparent materials. The transparency level should be sufficient to allow light from objects behind the cursor to pass through, creating a "silk" or ghostly appearance [S1, unofficial].
4.  **Occlusion Check:** The semi-transparent lining creates visual cues for depth ordering. If an object is fully visible through the lining, it is behind. If partially obscured by the lining, it is in front. If the lining is not visible against the object, the object is inside [S1, unofficial].

**Parameters:**
*   **Transparency Level:** Not given in the sources. Must be tuned to balance visibility of the cursor's boundary with visibility of internal/external objects.
*   **Dimensions:** The width, height, and depth of the rectangular box. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Precision:** In stereoscopic displays, the semi-transparent lining must be rendered correctly for both eyes to maintain the depth cue [S1, unofficial].
*   **Boundaries:** The cursor is not constrained to the volume boundary, unlike surface-constrained methods.

**Pseudocode:**
```python
def render_silk_cursor(cursor_pos, cursor_dims, scene_objects):
    """
    Renders the silk cursor and handles depth perception cues.
    
    Args:
        cursor_pos: (x, y, z) center of the cursor.
        cursor_dims: (w, h, d) dimensions of the cursor box.
        scene_objects: List of objects in the scene with their positions and render states.
    """
    # Define the semi-transparent material for the cursor lining
    cursor_material = Material(
        color=(1.0, 1.0, 1.0), # White or neutral color
        alpha=0.3,            # Semi-transparent value [G]
        blending=BLEND_ALPHA
    )
    
    # Create the rectangular prism geometry
    cursor_box = Box(center=cursor_pos, size=cursor_dims)
    
    # Render the cursor lining
    # The lining allows users to see through it, creating partial occlusion
    render_object(cursor_box, material=cursor_material)
    
    # The user determines depth based on:
    # 1. Object fully visible through lining -> Behind cursor
    # 2. Object partially obscured by lining -> In front of cursor
    # 3. Lining not visible against object -> Inside cursor [S1, unofficial]
```

## Subtopics

### Plane-constrained Cursor
A variant where the cursor is constrained to move along a specific plane within the 3D scene [S2]. The plane can be specified via a secondary device or the orientation of the input plane itself [S2]. This resembles 2D cursor interaction on conventional displays but adapted for volumetric displays [S2]. It is useful for non-planar enclosures (e.g., domes) where casting a ray straight down to a ground plane is effective [S2].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per frame for cursor rendering, assuming fixed geometry.
*   **Memory Complexity:** $O(1)$ for cursor data structures.
*   **Performance:** Controlled experiments found the silk cursor beneficial in both monoscopic and stereoscopic displays [S1, unofficial].
*   **Strengths:** Enhances depth perception of targets relative to the cursor; simple to implement; works in both 2D and 3D display modes.
*   **Limitations:** Requires semi-transparent rendering support; may be less effective in highly cluttered scenes where occlusion cues are ambiguous.

## Background
The Silk Cursor was introduced in the context of interaction techniques for volumetric displays [S1, unofficial]. It builds on the concept of increasing the effective activation area of a target, similar to 2D area cursors, by using a rectangular shape with semi-transparent lining [S1, unofficial]. It is distinct from techniques like the Go-Go selection technique, which focuses on distance mapping rather than spatial awareness within the volume [S1, unofficial].
