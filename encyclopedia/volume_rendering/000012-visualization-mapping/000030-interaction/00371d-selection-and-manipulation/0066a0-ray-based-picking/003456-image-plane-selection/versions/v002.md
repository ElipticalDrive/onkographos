# Image Plane Selection

Also called: one-eyed cursor

## Overview
Image plane selection projects 3D objects onto a 2D image plane, where a cursor defines a perpendicular ray to select the first intersected object [S1, unofficial]. It extends desktop mouse interaction to 3D environments by using visual alignment or specific hand configurations as the selection mechanism [S1, unofficial]. Unlike direct 3D cursors that specify X, Y, and Z coordinates explicitly, this method relies on the user's input device (hand, finger, or virtual pointer) visually overlapping the target [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** User hand position/orientation (tracked via gloves, optical sensors, or head-tracking), camera viewpoint (eye position), and 3D scene geometry [S1, unofficial].
- **Outputs:** A selected object or set of objects identified by intersection with the selection ray or volume [S1, unofficial].

**Data Structures:**
- **Hand Pose:** Vector $H$ representing the position of the relevant hand feature (e.g., fingertip, palm center) [S1, unofficial].
- **Eye Position:** Vector $E$ representing the user's eye position [S1, unofficial].
- **Scene Geometry:** List of 3D primitives or volume data [S1, unofficial].

**Steps:**
1. **Define Selection Ray/Volume:**
   - **Standard Image Plane:** Define a ray $R(t) = E + t(C - E)$, where $E$ is the eye position and $C$ is the cursor position on the image plane [S1, unofficial].
   - **One-Eyed Cursor (Stereoscopic):** For stereoscopic displays, define the image plane as the viewpoint from only a single eye to create a "one-eyed cursor" [S1, unofficial].
   - **Aperture-Based:** Cast a cone from the eye $E$ through the user's finger, where the distance between the finger and the eye controls the cone's divergence angle [S1, unofficial].
   - **Head Crusher:** Define a selection volume between the index finger and thumb [S1, unofficial].
   - **Sticky Finger:** Define a ray from the eye $E$ through the tip of the index finger [S1, unofficial].
   - **Lifting Palm:** Define a plane or volume underneath the flattened palm [S1, unofficial].
   - **Framing Hands:** Use both hands to define a bounding box around the object using thumbs and index fingers [S1, unofficial].
   - **Icon Wall:** Use a virtual laser pointer from the hand to a point on the projection screen plane [S2, unofficial].
2. **Intersection Test:**
   - Cast the ray or test the volume against the 3D scene geometry [S1, unofficial].
   - For **Ray Cursor** (Laser Gun): The first object intersected by the ray is selected [S1, unofficial].
   - For **Occlusion Selection**: Objects visually lying behind the hand-attached cursor are selected [S1, unofficial].
   - For **Aperture-Based**: If the ray intersects multiple objects, use device orientation for disambiguation by selecting the object whose orientation is most closely matched by the input device [S1, unofficial].
3. **Selection Confirmation:**
   - Click or gesture confirmation selects the identified object [S1, unofficial][S2, unofficial].

**Pseudocode:**
```python
def select_object(hand_pose, eye_position, scene_objects, technique="standard"):
    # hand_pose: dict with 'fingertip' (vector), 'orientation' (vector)
    # eye_position: vector E
    # scene_objects: list of objects with geometry data
    
    # 1. Define ray origin and direction based on technique
    origin = eye_position
    if technique in ("aperture", "sticky_finger"):
        direction = hand_pose['fingertip'] - origin
    else:
        # Standard image plane: direction from eye to cursor C
        cursor = hand_pose.get('cursor', hand_pose['fingertip'])
        direction = cursor - origin
        
    direction = direction / norm(direction)
    
    # 2. Cast ray against scene geometry
    intersections = []
    for obj in scene_objects:
        # Standard ray-object intersection test
        t = intersect_ray_object(origin, direction, obj)
        if t is not None and t > 0:
            intersections.append((t, obj))
            
    # Sort by distance
    intersections.sort(key=lambda x: x[0])
    
    if not intersections:
        return None
        
    # 3. Handle ambiguity for aperture-based selection
    if len(intersections) > 1 and technique == "aperture":
        best_object = None
        best_score = -float('inf')
        for t, obj in intersections:
            # Orientation match: cosine similarity between object normal and hand orientation
            score = dot(normalize(obj.normal), hand_pose['orientation'])
            if score > best_score:
                best_score = score
                best_object = obj
        return best_object
        
    # Return first intersected object
    return intersections[0][1]
```

**Edge Cases and Pitfalls:**
- **Multiple Intersections:** In aperture-based selection, multiple objects may intersect the ray, requiring orientation matching for disambiguation [S1, unofficial].
- **Stereoscopic Ambiguity:** Without the one-eyed cursor technique, stereoscopic displays may lack a well-defined image plane, leading to selection errors [S1, unofficial].
- **Occlusion:** Users must visually align the cursor with the target, which can be difficult in cluttered scenes [S1, unofficial].

## Subtopics

### Icon Wall Interaction
Icons are drawn in the plane of the projection screen to allow both head-tracked and non-headtracked viewers to clearly view them at all times [S2, unofficial]. Users interact with icons by pointing at them with a virtual laser pointer and clicking a button [S2, unofficial]. Check boxes change state on click; dials are changed by clicking and twisting the hand [S2, unofficial].

## Background
Originated from desktop mouse interaction, where objects are projected onto a 2D image plane [S1, unofficial]. Extended to 3D displays by Ware and Lowther (1997) with the "one-eyed cursor" technique [S1, unofficial]. Liang and Green (1994) implemented a "laser gun" selection mechanism [S1, unofficial]. Forsberg et al. (1996) explored aperture-based selection [S1, unofficial]. Pierce et al. (1997) explored several occlusion selection techniques including Head Crusher, Sticky Finger, Lifting Palm, and Framing Hands [S1, unofficial].
