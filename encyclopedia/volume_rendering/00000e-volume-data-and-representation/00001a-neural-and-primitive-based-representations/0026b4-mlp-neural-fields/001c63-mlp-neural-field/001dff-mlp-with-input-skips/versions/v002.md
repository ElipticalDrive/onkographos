# MLP with Input Skips

Also called: Skip Connection MLP

## Overview
An MLP architecture that concatenates the original input $z$ to intermediate layers specified in `input_skips`, allowing the network to access low-level features at deeper layers [S1, S2, unofficial]. It differs from the parent [MLP Neural Field](1256-mlp-neural-field.md) by explicitly preserving high-frequency input information in hidden representations [S1, S2, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A coordinate vector $z \in \mathbb{R}^{in_{dim}}$ [S1, S2, unofficial].
- Output: A value vector $v \in \mathbb{R}^{output_{dim}}$ [S1, S2, unofficial].

**Data Structures:**
- `input_skips`: A list of integers representing layer indices where the skip connection is applied [S1, S2, unofficial].
- Weights $W_i$ and biases $b_i$ for each linear layer $i$ [S2, unofficial].

**Parameters:**
- $in_{dim}$: Dimensionality of the input vector $z$ [S1, S2, unofficial].
- $hidden_{dim}$: Dimensionality of the hidden layers [S1, S2, unofficial].
- $output_{dim}$: Dimensionality of the output vector [S1, S2, unofficial].
- $n_{layers}$: Total number of linear layers in the MLP [S1, S2, unofficial].
- $skip_{dim}$: Dimensionality of the vector $z$ to be skipped [S1, S2, unofficial].

**Algorithm:**
1. Initialize the hidden state $y$ as the input $z$ [S2, unofficial].
2. Iterate through each layer index $i$ from $0$ to $n_{layers} - 1$:
   a. If $i$ is in `input_skips` and $i > 0$: concatenate the original input $z$ to the current hidden state $y$: $y = [y, z]$ [S1, S2, unofficial].
   b. Apply the linear transformation: $y = W_i y + b_i$ [S2, unofficial].
   c. Apply the ReLU activation function: $y = \text{ReLU}(y)$ [S1, S2, unofficial].
3. After the final layer, apply a final linear transformation mapping $hidden_{dim}$ to $output_{dim}$ if $output_{dim} \neq hidden_{dim}$ [G]. The final output is $v = y$ [G].

**Initialization:**
- Layer 0: Input dimension $in_{dim}$, output dimension $hidden_{dim}$ [S2, unofficial].
- Layers $i \notin \text{input\_skips}$: Input dimension $hidden_{dim}$, output dimension $hidden_{dim}$ [S2, unofficial].
- Layers $i \in \text{input\_skips}$: Input dimension $hidden_{dim} + skip_{dim}$, output dimension $hidden_{dim}$ [S2, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

class MLPWithInputSkips:
    def __init__(self, in_dim, hidden_dim, output_dim, n_layers, input_skips):
        self.input_skips = set(input_skips)
        self.layers = []
        # Layer 0
        self.layers.append(torch.nn.Linear(in_dim, hidden_dim))
        # Intermediate layers
        for i in range(1, n_layers):
            if i in self.input_skips:
                in_features = hidden_dim + in_dim
            else:
                in_features = hidden_dim
            self.layers.append(torch.nn.Linear(in_features, hidden_dim))
        # Final output layer
        self.output_layer = torch.nn.Linear(hidden_dim, output_dim)

    def forward(self, z):
        y = z
        for i, layer in enumerate(self.layers):
            if i in self.input_skips and i > 0:
                y = torch.cat([y, z], dim=-1)
            y = layer(y)
            y = F.relu(y)
        return self.output_layer(y)
```

**Edge Cases and Pitfalls:**
- If `input_skips` contains 0, the skip is effectively ignored because there is no previous hidden state to concatenate to [G].
- Precision issues may arise if $in_{dim}$ is very large compared to $hidden_{dim}$, causing the skip connection to dominate the gradient [G].
- Boundary conditions require ensuring that the concatenation dimension is consistent across all layers [G].

## Subtopics

### ODENetwork (Conditioned Neural ODE)
A multi-layer perceptron that computes the derivative of the latent state over time, conditioned on a voxel embedding and a scalar time parameter [S3, unofficial]. It iterates through layers, concatenating the latent state, voxel embedding, and time $t$ at indices in `skip_layers` [S3, unofficial]. The update rule is $z_{i+1} = \text{ReLU}(\text{Linear}(z_i + \text{Concat}(\text{voxel\_emb}, t)))$ for skip layers, and $z_{i+1} = \text{ReLU}(\text{Linear}(z_i))$ otherwise [S3, unofficial]. The final output applies Tanh: $z_{out} = \tanh(\text{Linear}(z_{last}))$ [S3, unofficial]. Parameters include $latent_{dim}$ (default 512), $hidden_{dim}$ (default 512), and $skip_{layers}$ (default [1, 3]) [S3, unofficial]. It is chosen when modeling continuous latent state evolution conditioned on spatial embeddings [S3, unofficial].

## Operating characteristics
- Time Complexity: $O(n_{layers} \cdot hidden_{dim}^2)$ for standard layers, $O(n_{layers} \cdot hidden_{dim} \cdot (hidden_{dim} + in_{dim}))$ for skip layers [G].
- Memory Complexity: $O(n_{layers} \cdot hidden_{dim}^2)$ for weights, plus $O(hidden_{dim} + in_{dim})$ for activations [G].
