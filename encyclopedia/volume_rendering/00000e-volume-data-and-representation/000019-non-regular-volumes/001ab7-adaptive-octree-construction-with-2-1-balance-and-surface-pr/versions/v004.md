# Adaptive Octree Construction with 2:1 Balance and Surface Propagation

Also called: Algorithm Improvements and Extensions, Implicit Function Octree Construction, Isotopic Octree Approximation, adaptive grid refinement for isosurfaces, isomesh octree building

## Overview
This method constructs an adaptive octree for isosurface extraction by refining a 3D grid based on implicit function sign changes and geometric features, enforcing a 2:1 balance constraint (no face-adjacent leaves differ by more than 1 depth level) and ensuring manifold connectivity through surface propagation rules [S1, unofficial]. It differs from uniform grid approaches by concentrating resolution only where the implicit surface or geometric features exist, significantly reducing vertex counts for smooth shapes while guaranteeing watertight output [S1, unofficial].

## How it works
**Inputs:**
- Implicit function $f: \mathbb{R}^3 \to \mathbb{R}$ and optional gradient $\nabla f$ [G].
- Bounding box defined by `bbox_min` and `bbox_max` [S1, unofficial].
- Parameters: `min_depth`, `max_depth`, `angle_threshold_deg`, `iso_value` [S1, unofficial].

**Outputs:**
- An adaptive octree where leaf nodes are classified as Empty, Full, or Surface [S1, unofficial].
- Surface leaves are guaranteed to be at `max_depth` to eliminate T-junctions [S1, unofficial].

**Data Structures:**
- **Octree Node:** Contains spatial bounds (`bbox_min`, `bbox_max`), depth, and a list of child nodes (if not a leaf) [G].
- **Leaf Classification:** Enum {Empty, Full, Surface} [G].
- **EvalCache:** Dictionary mapping world coordinates to computed values and gradients to avoid redundant evaluations [S1, unofficial].
- **all_leaves:** Vector of leaf cells with coordinates $(cx, cy, cz)$ and depth [S1, unofficial].

**Parameters:**
- `min_depth`: u8. Minimum subdivision depth. Typical: 3 [S1, unofficial].
- `max_depth`: u8. Maximum subdivision depth. Typical: 7 [S1, unofficial].
- `angle_threshold_deg`: f64. Threshold for sharp feature detection. Typical: 30.0 [S1, unofficial].
- `iso_value`: f64. Isosurface level. Typical: 0.0 [S1, unofficial].

**Steps:**

1. **Initialization:** Initialize the octree with the bounding box. Build a uniform grid up to `min_depth`. If adaptive mode is enabled, call `build_adaptive` which internally invokes `enforce_balance_2to1` [S1, unofficial].

2. **Balance Enforcement (`enforce_balance_2to1`):**
   a. Collect all current leaf cells into `all_leaves`, storing their coordinates $(cx, cy, cz)$ and depth $d$ [S1, unofficial].
   b. Iterate through `all_leaves` to identify cells requiring subdivision based on balance rules:
      - **Rule 3 (Surface Propagation):** If a current cell is classified as Surface, and a face-adjacent neighbor is at the same depth but is a Branch containing surface descendants, and the current cell's depth $d < max\_depth$, then the current cell must subdivide [S1, unofficial]. This prevents cross-depth gaps where a coarse neighbor abuts a fine surface region [S1, unofficial].
   c. For each cell marked for subdivision:
      i. Compute the 8 child octants.
      ii. Compute the 8 corner grid positions for each octant [S1, unofficial].
      iii. Convert grid positions to world coordinates using `cache::grid_to_world` [S1, unofficial].
      iv. Batch evaluate the implicit function and gradients at these new points using `bridge::batch_evaluate` [S1, unofficial].
      v. If gradients are not provided by the function, estimate them using finite differences with step size $h = \text{cell\_size\_at\_max} \times 0.01$ [S1, unofficial]. Store values and gradients in `EvalCache` [S1, unofficial].
      vi. Classify each child as Empty, Full, or Surface based on sign changes relative to `iso_value` and feature metrics (e.g., normal angle spread) [S1, unofficial].
      vii. Subdivide the marked cells in the octree structure using `subdivide_cell_for_balance` [S1, unofficial].
   d. Repeat balance enforcement until no further subdivisions are required or `max_depth` is reached [S1, unofficial].

3. **Edge Completeness:** After the balance loop, call `ensure_edge_completeness` [S1, unofficial]. This ensures every sign-change edge has all 4 sharing cells present as surface leaves, eliminating gaps at depth boundaries [S1, unofficial]. It also checks for non-canonical edges (1-3, 5-7, 9-11) because surface cells that don't own a canonical edge still participate in quads generated by neighbors [S1, unofficial].

4. **Finalization:** Force all surface leaves to `max_depth` to guarantee watertight output and eliminate T-junction holes [S1, unofficial].

**Pseudocode:**

```python
def build_adaptive_octree(func, bbox_min, bbox_max, min_depth, max_depth, angle_threshold_deg, iso_value):
    # Initialize octree with bounding box and build uniform grid up to min_depth [S1, unofficial]
    octree = OctreeNode(bbox_min, bbox_max, min_depth)
    enforce_balance_2to1(octree, func, max_depth, angle_threshold_deg, iso_value)
    ensure_edge_completeness(octree, func, iso_value)
    force_surface_to_max_depth(octree, max_depth)
    return octree

def enforce_balance_2to1(octree, func, max_depth, angle_threshold_deg, iso_value):
    all_leaves = collect_leaves(octree)
    changed = True
    while changed:
        changed = False
        cells_to_subdivide = []
        for leaf in all_leaves:
            if leaf.depth >= max_depth:
                continue
            if leaf.classification == "Surface":
                neighbor = get_face_neighbor(leaf)
                if neighbor is not None and neighbor.is_branch() and neighbor.has_surface_descendants():
                    cells_to_subdivide.append(leaf)
        for cell in cells_to_subdivide:
            subdivide_cell(cell, func, angle_threshold_deg, iso_value)
            changed = True
            all_leaves = collect_leaves(octree)

def subdivide_cell(cell, func, angle_threshold_deg, iso_value):
    children = compute_octants(cell)
    for child in children:
        corners = get_corners(child)
        world_corners = [grid_to_world(c, cell) for c in corners]
        values, gradients = batch_evaluate(func, world_corners)
        if gradients is None:
            h = cell_size_at_max(cell) * 0.01
            gradients = estimate_gradients(values, world_corners, h)
        EvalCache[world_corners] = (values, gradients)
        child.classify(values, gradients, iso_value, angle_threshold_deg)
    cell.children = children

def ensure_edge_completeness(octree, func, iso_value):
    for edge in get_all_edges(octree):
        if edge.has_sign_change():
            sharing_cells = get_sharing_cells(edge)
            for cell in sharing_cells:
                if not cell.is_surface_leaf():
                    refine_to_surface(cell, func, iso_value)
    for edge in get_non_canonical_edges(octree):
        if edge.has_sign_change():
            refine_adjacent_cells(edge, func, iso_value)

def force_surface_to_max_depth(octree, max_depth):
    leaves = collect_leaves(octree)
    for leaf in leaves:
        if leaf.classification == "Surface" and leaf.depth < max_depth:
            subdivide_cell(leaf, lambda p: (0.0, None), 30.0, 0.0)

# Helper definitions
class OctreeNode:
    def __init__(self, bbox_min, bbox_max, depth):
        self.bbox_min, self.bbox_max, self.depth = bbox_min, bbox_max, depth
        self.children, self.classification = [], None
    def is_branch(self): return len(self.children) > 0
    def is_surface(self): return self.classification == "Surface"
    def is_surface_leaf(self): return not self.is_branch() and self.is_surface()
    def has_surface_descendants(self): return any(c.is_surface() for c in self.children)
    def classify(self, values, gradients, iso_value, angle_threshold_deg):
        self.classification = "Surface" if any(v < iso_value for v in values) else "Empty"

def collect_leaves(node):
    if not node.is_branch(): return [node]
    return [l for c in node.children for l in collect_leaves(c)]

def compute_octants(cell):
    mins, maxs = cell.bbox_min, cell.bbox_max
    mid = [(m + M) / 2.0 for m, M in zip(mins, maxs)]
    children = []
    for i in range(8):
        new_min = [mid[j] if (i >> j) & 1 else mins[j] for j in range(3)]
        new_max = [maxs[j] if (i >> j) & 1 else mid[j] for j in range(3)]
        children.append(OctreeNode(new_min, new_max, cell.depth + 1))
    return children

def get_corners(child):
    return [(i & 1, (i >> 1) & 1, (i >> 2) & 1) for i in range(8)]

def grid_to_world(c, cell):
    return tuple(m + c[j] * (M - m) for j, (m, M) in enumerate(zip(cell.bbox_min, cell.bbox_max)))

def batch_evaluate(func, points):
    return func(points)

def estimate_gradients(values, points, h):
    grads = []
    for i, p in enumerate(points):
        g = [0.0, 0.0, 0.0]
        for d in range(3):
            p_plus = list(p); p_plus[d] += h
            p_minus = list(p); p_minus[d] -= h
            v_plus, _ = batch_evaluate(lambda pts: func(pts)[0], [p_plus])
            v_minus, _ = batch_evaluate(lambda pts: func(pts)[0], [p_minus])
            g[d] = (v_plus[0] - v_minus[0]) / (2.0 * h)
        grads.append(g)
    return grads

def cell_size_at_max(cell):
    return max(M - m for m, M in zip(cell.bbox_min, cell.bbox_max))
```

## Subtopics

### [Octree Balance Subdivision](847-octree-balance-subdivision.md)
Octree Balance Subdivision is the recursive refinement step in adaptive octree construction for volume rendering and isosurface extraction. It splits a parent node into eight child octants, evaluates the implicit function at the children's corners, and classifies each child as Empty, Full, or Leaf based on sign changes relative to an isosurface. It ensures tree integrity by preventing orphaning of existing children and maintaining the 2:1 balance constraint required by the parent algorithm [Adaptive Octree Construction with 2:1 Balance and Surface Propagation](830-adaptive-octree-construction-with-2-1-balance-surface-pr.md).

### [Error Data Generation](1324-error-data-generation.md)
Error Data Generation computes a quantitative measure of the approximation error introduced by the Adaptive Resolution (AR) data reduction process. It solves the problem of quantifying data loss during the transition from fine-grained volume data to a coarser, adaptive representation, enabling the inclusion of error metrics in subsequent isosurface rendering pipelines.

### [Constrained Octree Refinement](2426-constrained-octree-refinement.md)
Constrained Octree Refinement is a construction-phase strategy that restricts the depth-disparity between face-adjacent octree nodes to a maximum of one. It prevents excessive geometric simplification in unconstrained adaptive octrees by ensuring a more uniform grid structure.

### [Topological Octree Construction](4698-topological-octree-construction.md)
Topological Octree Construction is an adaptive subdivision strategy that refines a 3D grid based on topological complexity to ensure the extracted implicit surface is manifold (free of non-manifold edges or vertices). It distinguishes itself from sibling methods by explicitly defining "complex" cells via edge and face connectivity analysis, whereas siblings like [Octree Balance Subdivision](847-octree-balance-subdivision.md) focus on geometric balance and [Constrained Octree Refinement](2426-constrained-octree-refinement.md) on general constraints. It builds on [Adaptive Octree Construction with 2:1 Balance and Surface Propagation](830-adaptive-octree-construction-with-2-1-balance-surface-pr.md) by providing the specific topological criteria for leaf refinement.

## Operating characteristics
- **Time Complexity:** Depends on the number of surface cells and the depth of refinement [G]. Adaptive refinement reduces the number of evaluated cells compared to uniform grids for smooth shapes [S1, unofficial]. For a sphere, adaptive refinement can reduce vertex count by 16x compared to uniform grids at equivalent accuracy [S1, unofficial].
- **Memory Complexity:** Proportional to the number of octree nodes [G]. Adaptive structures use less memory than uniform grids for sparse or smooth fields [G].
- **Strengths:** Guarantees watertight, manifold output [S1, unofficial]. Handles sharp features and thin walls effectively [S1, unofficial]. Eliminates T-junctions by forcing surface leaves to `max_depth` [S1, unofficial].
- **Limitations:** Requires vectorized implicit function evaluation [S1, unofficial]. Finite difference gradients are unreliable for neural SDFs; autodiff gradients are recommended [S1, unofficial]. Over-refinement can occur if `angle_threshold_deg` is set too low (below 25°) due to noisy neural gradients [S1, unofficial]. Balancing is not strictly necessary for an isotopic result, though its removal complicates leaf approximation [S2, unofficial].
- **When to use:** Isosurface extraction from SDFs, especially for mechanical parts or shapes with sharp features where manifold connectivity is critical [S1, unofficial].
- **When not to use:** When uniform grid resolution is sufficient and simplicity is preferred, or when the implicit function cannot be evaluated in batches [G].

## Background
The method is implemented in the `isomesh` library, which uses Dual Contouring for mesh extraction [S1, unofficial]. Dual Contouring was introduced by Ju et al. in "Dual Contouring of Hermite Data" (SIGGRAPH 2002) and extended to manifold dual contouring by Schaefer et al. (IEEE TVCG 2007) [S1, unofficial]. The adaptive octree construction with 2:1 balance is designed to support efficient extraction from SDF-based 3D generative models like DeepSDF and SDF-Diffusion [S1, unofficial]. The underlying isotopic approximation guarantees topological correctness between the mesh and the implicit surface, though Hausdorff distance optimization remains an open problem [S2, unofficial].
