# Topological Octree Construction

Also called: Adaptive Octree Refinement, Lobello et al. 2012 Method, Lobello et al. 2014 Method, Regular Octree Construction

## Overview
Topological Octree Construction is an adaptive subdivision strategy that refines a 3D grid based on topological complexity to ensure the extracted implicit surface is manifold, meaning it contains no non-manifold edges or vertices [S1, unofficial]. It differs from sibling methods by explicitly defining "complex" cells via edge and face intersection analysis rather than relying solely on scalar value heterogeneity or error bounds [S1, unofficial]. It builds on [Adaptive Octree Construction with 2:1 Balance and Surface Propagation](830-adaptive-octree-construction-with-2-1-balance-and-surface-pr.md) by providing the specific topological criteria for refinement and the balancing mechanism [S1, unofficial].

## How it works
**Inputs:**
- Binary volume data $V$ where $V(x,y,z) \in \{0, 1\}$, representing the interior and exterior of the object [S1, unofficial].
- Minimum tree level $L_{min}$ and maximum tree level $L_{max}$ [S1, unofficial].
- Construction mode: "Regular" (Lobello et al. 2012) or "Adaptive" (Lobello et al. 2014) [S1, unofficial].

**Outputs:**
- An octree data structure where leaf cells satisfy topological safety constraints [S1, unofficial].
- A balanced tree where leaf cells differ in depth by at most one level [S1, unofficial].

**Data Structures:**
- **Octree Node:** Contains a Morton key for spatial/hierarchical indexing, a depth level, a boolean flag `is_leaf`, and a list of 8 child pointers (null if leaf) [S1, unofficial].
- **Face Voxels:** For a given face, a 2D grid of voxel values corresponding to the intersection of the implicit surface boundary $\partial V$ with that face [S1, unofficial].

**Definitions:**
- **Complex Edge:** An edge of a cell is complex if it is intercepted by $\partial V$ more than once [S1, unofficial].
- **Complex Face:** A face is complex if it is intercepted by $\partial V$ but contains no complex edges, yet possesses an isolated connected component crossing it [S1, unofficial].
- **Complex Cell:** A leaf cell $C$ is complex if at least one of its edges or faces is complex [S1, unofficial].
- **Non-homogeneous Cell:** A cell where at least one corner has a different scalar value than the others (applies only to Regular Construction) [S1, unofficial].

**Algorithm Steps:**

1. **Initialization:** Create a root node at level $L_{min}$ and subdivide the volume into a regular grid of cells at level $L_{min}$ [S1, unofficial].
2. **Complexity Detection (Iterative):** For each leaf cell $C$ in the current octree:
   a. **Check Edges:** Iterate through the 12 edges of $C$ [S1, unofficial]. For each edge, traverse the voxels along the edge [S1, unofficial]. If the number of sign changes (transitions between 0 and 1) is greater than 1, the edge is complex [S1, unofficial]. If any edge is complex, mark $C$ as complex [S1, unofficial].
   b. **Check Faces:** If $C$ is not yet marked complex, iterate through the 6 faces [S1, unofficial]. For each face, extract the 2D grid of voxel values on the face [S1, unofficial]. Apply the Hoshen-Kopelman algorithm to identify connected components of internal voxels (voxels with value 0) [S1, unofficial]. Initialize a label counter $L = 0$ and a label map for the face voxels initialized to 0 [G]. Traverse face voxels in raster order. If a voxel $v$ has value 0 (internal): if $v$ has no label and no labeled neighbors, increment $L$ and assign label $L$ to $v$ [S1, unofficial]. If $v$ has labeled neighbors, assign the label of the first labeled neighbor to $v$ [S1, unofficial]. If $v$ has multiple labeled neighbors with different labels, union the sets of these labels (standard union-find operation) and update all voxels in the affected sets to the representative label [G]. After labeling, check each connected component [S1, unofficial]. If a component exists such that none of its voxels belong to the boundary edges of the face, the face is complex [S1, unofficial]. If any face is complex, mark $C$ as complex [S1, unofficial].
   c. **Check Non-homogeneity (Regular Construction Only):** If the construction mode is "Regular", check if $C$ is non-homogeneous [S1, unofficial]. If the 8 corners of $C$ do not all have the same value, mark $C$ as complex [S1, unofficial].
3. **Subdivision:** If $C$ is marked complex and its current depth $d < L_{max}$, subdivide $C$ into 8 children at depth $d+1$ [S1, unofficial]. Remove $C$ from the leaf list and add the 8 new children to the leaf list [G]. If $d = L_{max}$, the cell remains a leaf (maximum refinement reached) [S1, unofficial].
4. **Balancing:** After all complex cells are subdivided, enforce balance [S1, unofficial]. If any two face-adjacent leaf cells differ in depth by more than 1 level, subdivide the shallower cell until the constraint is satisfied [S1, unofficial]. This ensures surface quality by preventing large jumps in resolution [S1, unofficial].
5. **Termination:** Repeat steps 2-4 until no leaf cells require subdivision or all complex cells are at $L_{max}$ and the tree is balanced [S1, unofficial].

**Pseudocode:**

```python
def topological_octree_construction(volume, L_min, L_max, mode="adaptive"):
    """
    volume: 3D array of binary values (0 or 1)
    L_min: minimum depth level
    L_max: maximum depth level
    mode: "regular" or "adaptive"
    """
    # [G] Standard grid generation at level L_min
    leaves = get_cells_at_level(L_min, volume.shape)
    
    changed = True
    while changed:
        changed = False
        current_leaves = list(leaves)
        
        for cell in current_leaves:
            if cell.depth >= L_max:
                continue
                
            is_complex = False
            
            # Check edges [S1, unofficial]
            for edge in cell.edges:
                if count_sign_changes(edge.voxels) > 1:
                    is_complex = True
                    break
            
            # Check faces if not already complex [S1, unofficial]
            if not is_complex:
                for face in cell.faces:
                    if is_face_complex(face.voxels, face.edges):
                        is_complex = True
                        break
            
            # Check non-homogeneity for Regular mode [S1, unofficial]
            if not is_complex and mode == "regular":
                if not are_all_corners_same_value(cell.corners):
                    is_complex = True
            
            if is_complex:
                # Subdivision [S1, unofficial]
                children = cell.subdivide()
                leaves.remove(cell)
                leaves.extend(children)
                changed = True
        
        # Enforce balance [S1, unofficial]
        leaves = enforce_balance(leaves)
        
    return Octree(leaves)

def count_sign_changes(voxels):
    changes = 0
    for i in range(1, len(voxels)):
        if voxels[i] != voxels[i-1]:
            changes += 1
    return changes

def is_face_complex(face_voxels, face_edges):
    # face_voxels: 2D array, 0=internal, 1=external
    # face_edges: set of (x,y) coordinates on the face boundary
    labels = [[0] * face_voxels.shape[1] for _ in range(face_voxels.shape[0])]
    label_counter = 0
    uf = UnionFind()
    
    for y in range(face_voxels.shape[0]):
        for x in range(face_voxels.shape[1]):
            if face_voxels[y, x] == 0: # Internal voxel
                neighbors = get_labeled_neighbors(x, y, labels)
                if not neighbors:
                    label_counter += 1
                    labels[y, x] = label_counter
                    uf.make_set(label_counter)
                else:
                    first_label = neighbors[0]
                    labels[y, x] = first_label
                    uf.union(first_label, *neighbors)
    
    # Check for isolated components [S1, unofficial]
    for label in uf.get_labels():
        component_voxels = uf.get_voxels_for_label(label)
        is_on_edge = any(v in face_edges for v in component_voxels)
        if not is_on_edge:
            return True
    return False

class UnionFind:
    def __init__(self):
        self.parent = {}
        self.voxels = {}
    def make_set(self, label):
        self.parent[label] = label
        self.voxels[label] = []
    def find(self, label):
        if self.parent[label] != label:
            self.parent[label] = self.find(self.parent[label])
        return self.parent[label]
    def union(self, *labels):
        roots = [self.find(l) for l in labels]
        for r in roots[1:]:
            self.parent[r] = roots[0]
            self.voxels[roots[0]].extend(self.voxels[r])
            self.voxels[r] = []
    def get_labels(self):
        return [r for r in self.parent if self.parent[r] == r]
    def get_voxels_for_label(self, label):
        root = self.find(label)
        return self.voxels[root]

def get_labeled_neighbors(x, y, labels):
    neighbors = []
    for dy, dx in [(-1,0),(1,0),(0,-1),(0,1)]:
        ny, nx = y+dy, x+dx
        if 0 <= ny < len(labels) and 0 <= nx < len(labels[0]):
            if labels[ny][nx] != 0:
                neighbors.append(labels[ny][nx])
    return neighbors

def are_all_corners_same_value(corners):
    return all(c == corners[0] for c in corners)

def enforce_balance(leaves):
    # Subdivide shallow face-adjacent leaves until max depth diff is 1 [S1, unofficial]
    changed = True
    while changed:
        changed = False
        to_subdivide = []
        for i, leaf in enumerate(leaves):
            for neighbor in get_face_adjacent_leaves(leaves, leaf):
                if abs(leaf.depth - neighbor.depth) > 1:
                    if leaf.depth < neighbor.depth:
                        to_subdivide.append(leaf)
                        break
        for leaf in to_subdivide:
            children = leaf.subdivide()
            leaves.remove(leaf)
            leaves.extend(children)
            changed = True
    return leaves

def get_face_adjacent_leaves(leaves, target):
    # Returns leaves sharing a face with target based on coordinates [G]
    adjacent = []
    for other in leaves:
        if other is target:
            continue
        if are_face_adjacent(target, other):
            adjacent.append(other)
    return adjacent

def are_face_adjacent(a, b):
    # Checks if two cells share exactly one face [G]
    dx = abs(a.x - b.x)
    dy = abs(a.y - b.y)
    dz = abs(a.z - b.z)
    return (dx == 0 and dy == 0 and dz == 1) or \
           (dx == 0 and dy == 1 and dz == 0) or \
           (dx == 1 and dy == 0 and dz == 0)

def get_cells_at_level(level, shape):
    # [G] Generates a list of Cell objects representing a regular grid at the given level
    cell_size = max(shape) / (2 ** level)
    cells = []
    for z in range(shape[2] // int(cell_size)):
        for y in range(shape[1] // int(cell_size)):
            for x in range(shape[0] // int(cell_size)):
                cells.append(Cell(x * cell_size, y * cell_size, z * cell_size, level))
    return cells

class Cell:
    def __init__(self, x, y, z, depth):
        self.x = x
        self.y = y
        self.z = z
        self.depth = depth
        self.edges = [] # Populated by geometry helper
        self.faces = [] # Populated by geometry helper
        self.corners = [] # Populated by geometry helper
    def subdivide(self):
        # Returns 8 children at depth+1 [G]
        half = max(self.x, self.y, self.z) / 2 # Simplified for illustration
        children = []
        for dz in range(2):
            for dy in range(2):
                for dx in range(2):
                    children.append(Cell(self.x + dx*half, self.y + dy*half, self.z + dz*half, self.depth + 1))
        return children

class Octree:
    def __init__(self, leaves):
        self.leaves = leaves
```

## Subtopics

### Octree Face Connection Strategy
A strategy to connect vertices on octree faces to ensure that further subdivision does not change the isotopy of the surface, assuming a vertical parametrizable direction [S2]. For top and bottom faces (perpendicular to the parametrizable direction), vertices can be connected arbitrarily because changing connections corresponds to moving a saddle point through the surface, which does not affect isotopy in the union of adjacent cubes [S2]. For side faces, the gradient bound does not hold, and the intersection curve can pierce opposite edges, preventing unique topology determination [S2]. However, topology changes on side faces correspond to moving the surface sideways, which does not affect the global surface topology [S2]. To construct an isotopic approximation, newly created vertices on the boundary of an octree face are examined [S2]. If the configuration could correspond to a parametrizable intersection curve, vertices are connected to maintain parametrizability [S2]. For other configurations, vertices are connected pairwise starting from an arbitrary vertex [S2].

## Operating characteristics
- **Time Complexity:** Depends on the number of complex cells and the cost of Hoshen-Kopelman labeling on faces [S1, unofficial]. In the worst case, every cell is complex, leading to $O(N)$ subdivisions where $N$ is the number of voxels, but typically much less due to adaptivity [S1, unofficial].
- **Memory Complexity:** Proportional to the number of nodes in the octree [S1, unofficial].
- **Performance:** Regular Construction (Lobello et al. 2012) results in all surface-intersecting cells being at the maximum refinement level, leading to higher memory usage but potentially simpler connectivity [S1, unofficial]. Adaptive Construction (Lobello et al. 2014) allows surface-intersecting cells at various levels, reducing memory but requiring more complex balancing [S1, unofficial].
- **Strengths:** Guarantees manifold surfaces by construction [S1, unofficial]. Efficiently refines only where necessary [S1, unofficial].
- **Limitations:** Requires careful implementation of Hoshen-Kopelman and balancing [S1, unofficial]. Sensitive to the choice of $L_{min}$ and $L_{max}$ [S1, unofficial].

## Background
The method was introduced by Lobello et al. in 2012 and 2014 [S1, unofficial]. The 2012 paper proposed a "Regular Construction" using both complex cell and non-homogeneous cell rules [S1, unofficial]. The 2014 paper refined this to an "Adaptive Construction" using only the complex cell rule, allowing for variable refinement levels [S1, unofficial]. The method is used in the extraction of isosurfaces from massive binary volumes, such as salt domes [S1, unofficial]. The face connection strategy is described in the context of isotopic approximation of implicit curves and surfaces [S2].
