# Non-regular volumes


## Overview
Non-regular volumes represent scalar fields over unstructured, hierarchical, or particle-based domains rather than fixed Cartesian grids, solving the problem of efficiently storing and rendering sparse, anisotropic, or geometrically complex data without the memory overhead of uniform high-resolution grids [G]. This family builds on [Volume data and representation](2-volume-data-and-representation.md) by abandoning fixed topology in favor of adaptive structures that concentrate resolution where data features exist, and distinguishes itself from [Neural and primitive-based representations](10-neural-and-primitive-based-representations.md) by relying on explicit geometric primitives and basis functions rather than implicit neural networks for field evaluation [G].

## Shared principles
All methods in this family share the following mechanisms and mathematical foundations:
1. **Unstructured Topology:** Data is stored in elements (tetrahedra, hexahedra, cells) defined by arbitrary vertex positions, rather than a regular lattice. [G]
2. **Adaptive Resolution:** The domain is partitioned hierarchically or locally refined based on error metrics, gradient magnitudes, or feature density. [G]
3. **Basis Function Evaluation:** Scalar values at query points are computed using basis functions defined over the elements. [G]
4. **Ray-Element Intersection:** Rendering requires determining the entry and exit points of rays through element shapes. [G]
5. **Continuity and Regularization:** In differentiable rendering contexts, maintaining mesh validity (non-inverted elements) is critical. [G]

## Subtopics

### [Adaptive Subdivision in DiffTetVR](807-adaptive-subdivision-in-difftetvr.md)
A training strategy that refines a tetrahedral mesh by locally subdividing vertices with high accumulated color gradients, aiming to increase resolution in regions of high-frequency detail while avoiding wasted resolution in empty regions. It distinguishes itself from static mesh approaches by dynamically adjusting the mesh topology during optimization based on rendering error signals, and from general adaptive refinement methods by using a specific prism-splitting algorithm with Constraint Satisfaction Problem (CSP) constraints to maintain mesh validity.

### [Adaptive Octree Construction with 2:1 Balance and Surface Propagation](830-adaptive-octree-construction-with-2-1-balance-and-surface-pr.md)
This method constructs an adaptive octree for implicit surface extraction by refining a 3D grid based on implicit function sign changes and geometric features, while enforcing a strict 2:1 balance constraint (no face-adjacent leaves differ by more than 1 depth level) and ensuring manifold connectivity through surface propagation rules. It sets itself apart from sibling methods by explicitly resolving cross-depth gaps via Rule 3 subdivision and ensuring edge completeness, rather than relying on post-processing or differentiable tetrahedral regularization.

### [Tetrahedral Regularization](834-tetrahedral-regularization.md)
Tetrahedral Regularization is a penalty term added to the optimization loss function to prevent tetrahedral elements from becoming inverted (negative volume) or degenerate (volume approaching zero) during the differentiable rendering of non-regular tetrahedral meshes. It sets itself apart from sibling methods by actively correcting vertex positions via gradient descent rather than modifying the mesh topology, and from [Bezier Tetrahedra Evaluation](1422-bezier-tetrahedra-evaluation.md) by operating on linear basis functions with a smooth, differentiable quality metric.

### [Bezier Tetrahedra Evaluation](1422-bezier-tetrahedra-evaluation.md)
Bezier Tetrahedra (BT) evaluation is a method for representing and querying volumetric scalar fields using piecewise cubic polynomial solids defined on a tetrahedral mesh. It solves the problem of evaluating continuous functions over non-regular, unstructured volumetric data by mapping each tetrahedron to a Bernstein basis polynomial. Unlike [Adaptive Subdivision in DiffTetVR](807-adaptive-subdivision-in-difftetvr.md) which refines geometry, or [Point Cloud Density Evaluation](1743-point-cloud-density-evaluation.md) which uses kernel density estimation, BTs provide an exact, differentiable polynomial representation within each element. The method is distinguished by its use of barycentric coordinates and the bounding property of Bernstein polynomials, which enables efficient culling and exact ray intersection.

### [Point Cloud Density Evaluation](1743-point-cloud-density-evaluation.md)
Point Cloud Density Evaluation updates the intensity values of a set of 3D points based on a volumetric field, effectively sampling the volume at the point locations. It solves the problem of transferring scalar field data from a regular grid representation to a non-regular point cloud representation, which is often required for density-based regularization or supervision in neural rendering pipelines. It differs from its siblings by focusing on the direct interpolation and optional footprint pooling of intensities rather than structural mesh generation or adaptive subdivision.

### [RBF Approximation of Subdivision Basis Functions](2315-rbf-approximation-of-subdivision-basis-functions.md)
This method replaces the computationally expensive recursive subdivision of volumetric meshes with the efficient evaluation of Radial Basis Functions (RBFs) that mimic the subdivision algorithm's behavior, enabling interactive GPU-based volume splatting. It solves the problem of high memory and rendering costs associated with explicit tessellation of complex polyhedra (hexahedra, octahedra) into tetrahedra, which introduces interpolation errors and exponential growth in cell count. Unlike sibling methods like [Adaptive Subdivision in DiffTetVR](807-adaptive-subdivision-in-difftetvr.md) which rely on explicit mesh refinement, this approach approximates the continuous volumetric basis function using radially symmetric kernels, avoiding explicit connectivity storage and allowing adaptive refinement only in undersampled regions.

### [Particle-based Volume Rendering (PBVR)](4247-particle-based-volume-rendering-pbvr.md)
A method to generate images uniquely corresponding to a transfer function for large-scale unstructured volume data by estimating particle density from a particle emission model and generating particles per tetrahedral cell. It differs from traditional volume raycasting by not requiring storing all cell data in memory or sorting cells along the view ray, enabling streaming processing of datasets larger than available RAM.

### [Adaptive Mesh Refinement (AMR) Data Structures](5344-adaptive-mesh-refinement-amr-data-structures.md)
Adaptive Mesh Refinement (AMR) data structures organize volumetric data with non-uniform resolution to efficiently store and render sparse or high-gradient fields. This family solves the problem of managing hierarchical grids where refinement levels vary spatially, enabling efficient traversal and rendering without processing uniform high-resolution data everywhere. It sets itself apart from sibling methods like [Tetrahedral Regularization](834-tetrahedral-regularization.md) and [Bezier Tetrahedra Evaluation](1422-bezier-tetrahedra-evaluation.md) by focusing on the hierarchical organization of the data (typically box-based or tetrahedral forests) rather than the specific geometric interpolation or basis function evaluation techniques used during the rendering pass.

### [MFA-DVR](1091-mfa-dvr.md)
The first direct volume rendering pipeline utilizing the Multivariate Functional Approximation (MFA) model, designed for both structured and unstructured volumetric datasets. It addresses the challenges of high-order evaluation of values and derivatives anywhere in the spatial domain, providing a compact representation for large-scale data. It sets itself apart from sibling methods by using a global approximation basis rather than local piecewise interpolation, generating more faithful rendering results than local filters while performing faster on high-order interpolations.

### [Homogeneity-Based KD-Tree Construction](1325-homogeneity-based-kd-tree-construction.md)
A hierarchical data structure for AMR datasets that avoids the memory waste and performance penalty of homogeneous page tables by grouping same-level cells into patches and building a KD-tree based on level homogeneity. It sets itself apart from sibling methods by explicitly maintaining tree topology integrity during refinement, and from [Adaptive Octree Construction with 2:1 Balance and Surface Propagation](830-adaptive-octree-construction-with-2-1-balance-and-surface-pr.md) by operating on a structured KD-tree hierarchy rather than an octree.

### [DEFTET](6415-deftet.md)
DEFTET is a differentiable volumetric 3D shape representation that utilizes a deformable tetrahedral mesh for reconstruction, optimizing for both vertex placement (deformation) and binary occupancy of each tetrahedron. It solves the problem of aliasing (staircase patterns) inherent in discretized voxel grids and the topological rigidity of surface meshes by allowing vertices to move freely within a bounding volume. Unlike voxel grids, DEFTET bypasses aliasing by deforming vertices to align with surfaces, and unlike Differentiable Marching Cubes (DMC), it is not constrained to regular grid edges, providing greater flexibility in representing complex geometry.

## Background
The concept of non-regular volumes emerged from the need to handle complex geometries and sparse data that regular grids cannot represent efficiently [G]. Early work focused on unstructured tetrahedral meshes for scientific visualization, leveraging the Projected Tetrahedra (PT) algorithm for artifact-free rendering [G]. The introduction of Multivariate Functional Approximation (MFA) provided a unified model for high-order evaluation on both structured and unstructured data, leading to pipelines like [MFA-DVR](1091-mfa-dvr.md) implemented in VTK [G]. Concurrently, Adaptive Mesh Refinement (AMR) techniques were adapted for volume rendering, with structures like [Homogeneity-Based KD-Tree Construction](1325-homogeneity-based-kd-tree-construction.md) optimizing traversal for hierarchical data [G]. More recently, differentiable rendering has driven the development of adaptive subdivision strategies (e.g., [Adaptive Subdivision in DiffTetVR](807-adaptive-subdivision-in-difftetvr.md)) and regularization techniques to optimize mesh topology and vertex positions jointly with appearance [G].
