# In-level Adaptive Encoding

Also called: Adaptive NCP Selection for MFA

## Overview
In-level Adaptive Encoding is a method for determining the optimal Number of Control Points (NCP) for a single micro-block within the Multivariate Functional Approximation (MFA) framework [S1, unofficial]. It solves the problem of balancing compression efficiency against reconstruction accuracy by selecting the smallest NCP that satisfies a user-defined error bound [S1, unofficial]. It differs from its sibling, [Cross-level Adaptive Encoding](8168-cross-level-adaptive-encoding.md), by performing an exhaustive search for every micro-block independently, without leveraging results from other levels of detail (LODs) [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A micro-block of resolution $n^3$, the polynomial degree $degree$, and a required error bound $e$ [S1, unofficial].
*   **Output:** The optimal NCP value $NCP^*$ for the micro-block, and the encoded micro-model using $NCP^*$ [S1, unofficial].

**Data Structures**
*   **Error Map:** A lookup structure mapping each valid NCP to its corresponding reconstruction error metric, implemented as a dictionary or list `errors` [S1, unofficial].
*   **ComplexSet:** A set containing micro-blocks whose minimum required NCP exceeds a threshold, marking them as "complex" for cross-level optimization [S1, unofficial].

**Parameters**
*   $n$: The resolution of the micro-block (side length) [S1, unofficial].
*   $degree$: The polynomial degree used in the MFA encoder [S1, unofficial].
*   $e$: The maximum allowable error bound for the micro-block [S1, unofficial].

**Algorithm Steps**
1. Initialize an empty `errors` map to store error metrics for each valid NCP [S1, unofficial].
2. Iterate through valid NCP values in the range $[degree+1, n]$ from highest to lowest ($n$ down to $degree+1$) [S1, unofficial].
3. For each NCP, encode the micro-block using the MFA encoder and compute the resulting error metric [S1, unofficial].
4. Record the error in the `errors` map at the index corresponding to the current NCP [S1, unofficial].
5. If the computed error exceeds the error bound $e$, add the micro-block to the `ComplexSet` for the current LOD [S1, unofficial].
6. After evaluating all valid NCPs, determine the optimal $NCP^*$ by finding the smallest NCP in the evaluated set such that $Error(NCP) < e$ [S1, unofficial].
7. Return $NCP^*$ and the corresponding encoded micro-model [S1, unofficial].

**Formula**
The optimal NCP is selected as:
$$ NCP^* = \arg \min_{NCP} (Error(NCP) < e) $$
where $NCP \in [degree+1, n]$ [S1, unofficial].

def in_level_adaptive_encoding(micro_block, n, degree, error_bound):
    """
    Determines the optimal NCP for a micro-block using exhaustive search.
    
    Args:
        micro_block: The input volumetric data for the micro-block.
        n: Resolution of the micro-block (n^3).
        degree: Polynomial degree for MFA.
        error_bound: Maximum acceptable error e.
        
    Returns:
        ncp_star: The optimal number of control points.
        encoded_model: The MFA model encoded with ncp_star.
        is_complex: Boolean, true if the block is added to ComplexSet.
    """
    errors = {}
    is_complex = False
    
    # Iterate from highest NCP (n) down to lowest valid NCP (degree + 1)
    for ncp in range(n, degree, -1):
        # Encode micro-block and compute error using MFA [S1, unofficial]
        err = mfa_error(micro_block, ncp, degree)
        errors[ncp] = err
        
        # If error exceeds bound, mark block as complex [S1, unofficial]
        if err > error_bound:
            is_complex = True
            
    # Find smallest NCP satisfying the error bound [S1, unofficial]
    ncp_star = None
    for ncp in range(degree + 1, n + 1):
        if errors[ncp] < error_bound:
            ncp_star = ncp
            break
            
    # Fallback if no NCP satisfies the bound [G]
    if ncp_star is None:
        ncp_star = n
        
    # Encode final model with optimal NCP [S1, unofficial]
    final_model = mfa_error(micro_block, ncp_star, degree)
    
    return ncp_star, final_model, is_complex

## Subtopics

### [Cross-level Adaptive Encoding](8168-cross-level-adaptive-encoding.md)
A hierarchical optimization that uses the results of in-level encoding from lower LODs to constrain or skip searches in higher LODs, accelerating the pipeline.

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Guarantees the optimal NCP for the given error bound for each micro-block independently [S1, unofficial].
*   **Limitations:** The exhaustive search is redundant across LODs and does not exploit spatial coherence between levels [S1, unofficial].
*   **When to use:** When used as the base case for the lowest LOD in a multi-resolution hierarchy, or when cross-level coherence cannot be assumed [S1, unofficial].

## Background
In-level Adaptive Encoding was introduced in the paper "Adaptive Multi-Resolution Encoding for Interactive Large-Scale Volume Visualization through Functional Approximation" [S1, unofficial]. It operates as the foundational encoding step for micro-blocks before cross-level optimization is applied [S1, unofficial].
