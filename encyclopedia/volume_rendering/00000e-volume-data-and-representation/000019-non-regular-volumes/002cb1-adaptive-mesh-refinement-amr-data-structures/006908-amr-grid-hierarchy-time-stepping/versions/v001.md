# AMR Grid Hierarchy & Time-stepping

Also called: AMR time-stepping algorithm, Nested AMR hierarchy

## Overview
This method defines the structural organization and temporal evolution of Adaptive Mesh Refinement (AMR) data, where the domain is partitioned into a nested hierarchy of successively refined axis-aligned grids [S1]. It solves the problem of managing multi-resolution data consistency and temporal synchronization, ensuring that finer grids advance at appropriate rates relative to coarser grids while maintaining physical accuracy through data synchronization [S1]. It sets itself apart from sibling methods by explicitly defining the recursive time-stepping logic and the "proper nesting" topological constraint that governs how grids of different refinement levels interact, whereas siblings like [Octree-based hierarchical structures](19897-octree-based-hierarchical-structures.md) focus on spatial indexing and [Interpolation and reconstruction methods](17874-interpolation-and-reconstruction-methods.md) focus on value estimation [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   Initial coarsest grid hierarchy at $t=0$.
*   Refinement ratio $r$ (typically a power of two) [S1].
*   Maximum refinement level $l_{max}$ (user-set) [S1].
*   Convergence/stability criteria (e.g., based on vorticity or density gradients) [S1].

**Outputs:**
*   Updated grid hierarchy $G_{l,k}$ at time $t + \Delta t$.
*   Synchronized data values across levels.

### Data Structures
The hierarchy consists of grids identified by $G_{l,k}$, where $l$ is the refinement level and $k$ is a unique grid ID at that level [S1]. A continuous set of grids at level $l$ is denoted $G_{l,k \to k+n}$ [S1]. Each grid contains cells with spatial dimensions $\Delta x_l, \Delta y_l, \Delta z_l$ and temporal step $\Delta t_l$ [S1].

### Formulas
Spatial refinement between level $l$ and $l+1$ is defined by:
$$ \Delta x_{l+1} = \frac{1}{r} \Delta x_l, \quad \Delta y_{l+1} = \frac{1}{r} \Delta y_l, \quad \Delta z_{l+1} = \frac{1}{r} \Delta z_l $$
where $r$ is the number of level $l+1$ cells fitting into one level $l$ cell per axis [S1].

Temporal refinement is defined by:
$$ \Delta t_{l+1} = \frac{\Delta t_l}{r} $$
[S1].

### Parameters
*   $r$: Refinement ratio. Typically a power of two for coding simplicity, though it may vary between successive levels (e.g., $r=2$ between $l$ and $l+1$, $r=4$ between $l+1$ and $l+2$) [S1].
*   $l_{max}$: Maximum refinement level [S1].

### Numbered Steps
The time-stepping algorithm is recursive. To advance the hierarchy from level $l$ to $l_{max}$:

1.  **Advance Level $l$:** Advance grid cells at level $l$ by one timestep $\Delta t_l$. Calculate data values. Assess cells for additional refinement using convergence criteria. Generate new cells at level $l+1$ where needed [S1].
2.  **Advance Level $l+1$:** Advance grid cells at level $l+1$ by $r$ timesteps using $\Delta t_{l+1}$. At each step, calculate data values. Assess for refinement; generate cells at level $l+2$ if $l+1 < l_{max}$ [S1].
3.  **Synchronize:** Synchronize data back up to grid cells at level $l$. This propagates accuracy from higher resolution data to lower levels, correcting/adjusting lower-level data with higher-resolution information [S1].

### Pseudocode
```python
def amr_time_step(grid_hierarchy, level_l, max_level, refinement_ratio, convergence_criteria):
    """
    Advances the AMR hierarchy starting from level_l.
    """
    # Step 1: Advance current level
    current_grids = grid_hierarchy.get_grids(level_l)
    for grid in current_grids:
        grid.advance_time_step()
        grid.calculate_data_values()
        
        # Assess refinement needs
        new_fine_grids = []
        for cell in grid.cells:
            if convergence_criteria(cell) and level_l < max_level:
                # Generate new cells at level l+1
                new_fine_grids.append(cell.refine())
        
        # Merge new fine grids into the hierarchy for level l+1
        grid_hierarchy.add_grids(level_l + 1, new_fine_grids)

    # Step 2: Advance next level r times
    if level_l + 1 <= max_level:
        fine_grids = grid_hierarchy.get_grids(level_l + 1)
        dt_fine = grid_hierarchy.get_dt(level_l) / refinement_ratio
        
        for _ in range(refinement_ratio):
            for grid in fine_grids:
                grid.advance_time_step(dt_fine)
                grid.calculate_data_values()
                
                # Assess further refinement if not at max level
                if level_l + 1 < max_level:
                    for cell in grid.cells:
                        if convergence_criteria(cell):
                            grid_hierarchy.add_grids(level_l + 2, cell.refine())
        
        # Step 3: Synchronize data back up
        synchronize_data(grid_hierarchy, level_l, level_l + 1)

def synchronize_data(hierarchy, coarse_level, fine_level):
    """
    Propagates accuracy from fine level to coarse level.
    """
    coarse_grids = hierarchy.get_grids(coarse_level)
    fine_grids = hierarchy.get_grids(fine_level)
    
    for coarse_grid in coarse_grids:
        for cell in coarse_grid.cells:
            # Find corresponding fine grid cells covering this coarse cell
            # Note: Regions can be covered by multiple grids; use finest available
            fine_cells = find_covering_fine_cells(cell, fine_grids)
            if fine_cells:
                # Update coarse cell data with averaged or interpolated fine data
                cell.data = aggregate_fine_data(fine_cells)
```

### Edge Cases and Pitfalls
*   **Multiple Grid Coverage:** A spatial location may be covered by multiple grids across levels (e.g., $G_{2,a}$ also covered by $G_{1,b}$ and $G_{0,c}$) [S1]. Visualization methods must handle this by adopting the finest grid available at any location to ensure accuracy [S1].
*   **Proper Nesting Constraint:** Grid cells of level $l$ cannot abut cells other than levels $l$, $l+1$, or $l-1$. Violations break the hierarchy assumptions [S1].
*   **Initial Refinement:** The initial refinement process at $t=0$ is iterative, repeating testing and refining until convergence criteria are met or $l_{max}$ is reached [S1].

## Operating characteristics
*   **Time Complexity:** The method involves recursive advancement and synchronization. The cost scales with the number of grids and cells, particularly as refinement increases. Synchronization adds overhead to propagate accuracy [S1].
*   **Memory Complexity:** Memory usage depends on the number of active grids and cells. The nested hierarchy can lead to significant memory overhead if many levels are active [S1].
*   **Strengths:** Provides a robust framework for multi-resolution simulation data, ensuring temporal consistency and spatial accuracy through proper nesting and synchronization [S1].
*   **Limitations:** The proper nesting constraint can be restrictive. Synchronization requires careful handling of overlapping grids [S1].
*   **When to use:** When visualizing time-varying AMR simulation data where temporal consistency and multi-resolution accuracy are critical [S1].

## Background
The method is based on the AMR grid hierarchy outlined by Berger and Colella [S1]. It is used in query-driven visualization of time-varying AMR data [S1].
