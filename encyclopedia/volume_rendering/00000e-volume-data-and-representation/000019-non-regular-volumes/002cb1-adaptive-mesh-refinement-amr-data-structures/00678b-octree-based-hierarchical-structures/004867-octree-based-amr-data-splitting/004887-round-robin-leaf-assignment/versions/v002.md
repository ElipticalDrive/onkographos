# Round-robin Leaf Assignment

Also called: Round-robin distribution

## Overview
Round-robin Leaf Assignment is a parallel distribution strategy for Adaptive Mesh Refinement (AMR) volume rendering where octree leaves are assigned to processing nodes based on their index in an octree traversal, independent of the viewing direction [S1, unofficial]. It sets itself apart from sibling methods like Back-to-front Cell Assignment by using a static, view-independent assignment, which reduces I/O overhead during viewpoint animation, whereas alternatives often require dynamic re-traversal or cell-level decomposition based on camera position [S1, unofficial].

## How it works
**Inputs and outputs:**
- Input: An octree structure generated by the AMR splitting stage, containing a list of leaves with varying sizes [S1, unofficial].
- Input: $N$, the total number of processing nodes [S1, unofficial].
- Output: A mapping from each processing node $i$ (where $0 \le i < N$) to a subset of octree leaves [S1, unofficial].

**Data structures:**
- The octree leaves are accessed via a linearized list generated by an octree traversal [S1, unofficial]. The exact traversal order is not given in the sources.
- Each leaf has an implicit or explicit index $k$ in this traversal list, where $k = 0, 1, 2, \dots, L-1$ and $L$ is the total number of leaves [S1, unofficial].

**Steps:**
1. Perform an octree traversal to generate an ordered list of leaves [S1, unofficial].
2. For each leaf in the list, determine its zero-based index $k$ [S1, unofficial].
3. Assign leaf $k$ to processing node $i$, where $i = k \pmod N$ [S1, unofficial].

**Formula:**
Node $i$ is assigned all leaves with index $k$ such that:
$$ k = N \cdot j + i $$
where $j = 0, 1, 2, \dots$ and $N$ is the total number of processing nodes [S1, unofficial].

**Parameters:**
- $N$: Total number of processing nodes [S1, unofficial]. Typical values: Not given in the sources.

**Edge cases and pitfalls:**
- **Load balancing:** Octree leaves can vary vastly in size (number of cells or data volume). Since assignment is based on count rather than size, load balancing problems are expected [S1, unofficial].
- **Compositing complexity:** The compositing stage is complicated and involves significant communication because nodes render multiple non-contiguous leaves scattered across the octree [S1, unofficial].
- **Communication overhead:** Increased communication is required to gather partial images from non-contiguous leaves, though this can be overlapped with rendering [S1, unofficial].

**Pseudocode:**
```python
def assign_leaves_robin(octree_leaves, num_nodes):
    """
    Assign octree leaves to processing nodes using round-robin distribution.
    
    Args:
        octree_leaves: A list of leaf objects, ordered by a deterministic octree traversal.
        num_nodes: Total number of processing nodes (N).
        
    Returns:
        A dictionary mapping node_id to a list of assigned leaves.
    """
    assignments = {i: [] for i in range(num_nodes)}
    
    for index, leaf in enumerate(octree_leaves):
        node_id = index % num_nodes
        assignments[node_id].append(leaf)
        
    return assignments
```
