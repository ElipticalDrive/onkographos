# Adaptive Octree Construction with 2:1 Balance and Surface Propagation

Also called: Algorithm Improvements and Extensions, Implicit Function Octree Construction, Isotopic Octree Approximation, adaptive grid refinement for isosurfaces, isomesh octree building

## Overview
This method constructs an adaptive octree representation of an implicit surface by refining a 3D grid based on implicit function sign changes and geometric features, enforcing a 2:1 balance constraint (no face-adjacent leaves differ by more than 1 depth level) and ensuring manifold connectivity through surface propagation rules [S1, unofficial]. It solves the problem of generating a watertight, isotopic mesh approximation of complex implicit functions while minimizing vertex count compared to uniform grids [S1, unofficial]. Unlike [Homogeneity-Based KD-Tree Construction](1325-homogeneity-based-kd-tree-construction.md) which uses axis-aligned splits, or [MFA-DVR](1091-mfa-dvr.md) which focuses on direct volume rendering, this method produces a polygonal mesh via Dual Contouring [S1, unofficial]. It differs from [Constrained Octree Refinement](2426-constrained-octree-refinement.md) by explicitly enforcing the 2:1 balance during construction to prevent excessive geometric simplification, and from [Topological Octree Construction](4698-topological-octree-construction.md) by combining topological criteria with the specific balancing mechanism [S1, unofficial].

## How it works
The algorithm builds an octree where leaf cells are refined until they satisfy isotopy conditions (containing the surface or being clearly empty/inside) and balance constraints [S1, unofficial]. It uses Dual Contouring for mesh extraction, ensuring manifold output [S1, unofficial].

**Inputs and Outputs:**
- **Inputs:** `func` (vectorized implicit function $f: \mathbb{R}^3 \to \mathbb{R}$ and optionally $\nabla f$), `bbox_min`, `bbox_max`, `min_depth`, `max_depth`, `angle_threshold_deg`, `iso_value` [S1, unofficial].
- **Outputs:** `vertices` (mesh vertex positions), `faces` (mesh face indices) [S1, unofficial].

**Data Structures:**
- **Octree Node:** Contains `bbox_min`, `bbox_max` (bounding box), `depth` (u8), `children` (list of 8 nodes or `None`), `is_leaf` (bool), and integer coordinates `(cx, cy, cz)` [G].
- **EvalCache:** Maps cell ID to `(values: np.ndarray, gradients: np.ndarray | None)` to avoid redundant evaluations [S1, unofficial].
- **AllLeaves:** List of `(cx, cy, cz, depth)` tuples used for balance enforcement [S1, unofficial].

**Numbered Steps:**
1. **Initialization:** Initialize the octree with the bounding box and build a uniform grid up to `min_depth` [S1, unofficial].
2. **Adaptive Refinement Loop:** For each leaf cell $C$, compute the 8 child octants [S1, unofficial]. For each octant, compute the 8 corner grid positions, convert to world coordinates, and batch evaluate [S1, unofficial]. If `func` does not return gradients, estimate them using finite differences with step size `cell_size_at_max * 0.01`, storing values and gradients in `EvalCache` [S1, unofficial]. Mark cell $C$ for subdivision if it contains the surface (sign changes on edges or faces) [S1, unofficial], if the normal angle spread across the cell exceeds `angle_threshold_deg` [S1, unofficial], or if **Rule 3 (Surface Propagation)** applies: if current cell $C$ is a surface cell, a face-neighbor $N$ is at the same depth but is a Branch containing surface descendants, and $depth(C) < max\_depth$, then $C$ must subdivide to prevent cross-depth gaps [S1, unofficial]. Subdivide the marked cells in the octree structure using `subdivide_cell_for_balance` [S1, unofficial].
3. **2:1 Balance Enforcement:** Collect all leaf cells into `all_leaves` vector [S1, unofficial]. Iterate through `all_leaves` and subdivide leaves with face-adjacent neighbors differing by more than 1 depth level until stability [S1, unofficial]. Balancing is not strictly necessary for isotopy but simplifies leaf approximation [S2].
4. **Edge Completeness:** Call `ensure_edge_completeness` to ensure every sign-change edge has all 4 sharing cells present as surface leaves, eliminating gaps at depth boundaries [S1, unofficial]. Check non-canonical edges (1-3, 5-7, 9-11) for sign changes, as surface cells not owning a canonical edge still participate in quads generated by neighbors [S1, unofficial].
5. **Mesh Extraction (Dual Contouring):** For each surface leaf, construct a Quadric Error Function (QEF) based on the interpolated Hermite data (values and gradients) at the cell boundaries [S1, unofficial]. Solve for the vertex position using Jacobi SVD eigendecomposition with mass-point bias for rank-deficient cases [S1, unofficial]. Perform one Newton step to project each vertex exactly onto the zero-isosurface $f(x)=0$ [S1, unofficial]. Iterate over canonical edges, generate quads based on the flatness of the surface within the cell, and triangulate if necessary [S1, unofficial]. Force all surface leaves to `max_depth` during extraction to eliminate T-junction holes [S1, unofficial].

**Formulas:**
- World coordinate conversion: $P_{world} = P_{min} + P_{grid} \times (P_{max} - P_{min})$ [G].
- Finite difference gradient: $\nabla f(P) \approx \frac{f(P + h \hat{e}_i) - f(P - h \hat{e}_i)}{2h}$ with $h = \text{cell\_size\_at\_max} \times 0.01$ [S1, unofficial].
- Newton projection: $P_{new} = P - \frac{f(P)}{\nabla f(P)}$ [S1, unofficial].
- QEF vertex placement: minimize $\sum_i (n_i^T (x - p_i))^2$ via Jacobi SVD with mass-point bias [S1, unofficial].

**Parameters:**
- `min_depth`: u8. Typical: 3 [S1, unofficial].
- `max_depth`: u8. Typical: 7 [S1, unofficial].
- `angle_threshold_deg`: f64. Typical: 30.0 [S1, unofficial].
- `iso_value`: f64. Typical: 0.0 [S1, unofficial].
- `fd_step`: f64. Typical: `cell_size_at_max * 0.01` [S1, unofficial].

**Edge Cases and Pitfalls:**
- Cross-depth gaps occur if a surface cell is not subdivided when its face-neighbor is a Branch containing surface descendants at the same depth; Rule 3 forces subdivision [S1, unofficial].
- Non-canonical edges (1-3, 5-7, 9-11) must be checked for sign changes because surface cells not owning a canonical edge still participate in quads generated by neighbors; `ensure_edge_completeness` handles this [S1, unofficial].
- Singularities may cause subdivision to not terminate; using `max_depth` limits refinement, yielding an isotopic approximation outside arbitrarily small bounding boxes around singular points [S2].
- For unbounded curves or surfaces, expand the initial bounding box beyond the area of interest and discard outer cells afterwards [S2].
- Finite difference gradients are unreliable on neural SDFs; autodiff is required [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Depends on the number of leaves $L$ [G]. Refinement is $O(L)$ per level [G]. Balancing is $O(L)$ with potential repeated passes [G]. Extraction is $O(L)$ [G]. Total time is dominated by function evaluations at grid corners [S1, unofficial].
- **Memory Complexity:** $O(L)$ for storing octree nodes and leaf data [G].
- **Measured Performance:** On a sphere, adaptive refinement (depth 4->6) uses 536 vertices vs 8,600 for uniform depth 6, a 16x reduction [S1, unofficial]. On complex mechanical parts, adaptive mode is essential for quality [S1, unofficial].
- **Strengths:** Produces watertight, manifold meshes [S1, unofficial]. Handles sharp features better than Marching Cubes via QEF [S1, unofficial]. Adaptive resolution reduces vertex count for smooth surfaces [S1, unofficial]. Supports local updates for dynamic scenes (e.g., metaballs) [S2].
- **Limitations:** Balancing is not strictly necessary for isotopy but increases complexity [S2]. Singularities may require max depth limits, sacrificing isotopy locally [S2]. Finite difference gradients are unreliable for neural SDFs; autodiff is required [S1, unofficial].
- **When to use:** Extracting meshes from implicit functions, especially SDFs from neural networks or CAD data, where manifold output and sharp feature preservation are critical [S1, unofficial].
- **When not to use:** When Hausdorff distance minimization is the primary goal (this method prioritizes isotopy) [S2]. For unbounded curves or surfaces, expand the initial bounding box beyond the area of interest and discard outer cells afterwards [S2].

## Background
The method is based on the `isomesh` library, which implements Dual Contouring of Hermite Data [S1, unofficial]. The theoretical foundation for isotopic approximation of implicit surfaces is provided by [S2], which guarantees isotopy between the mesh and the surface. It builds on [Adaptive Octree Construction with 2:1 Balance and Surface Propagation](830-adaptive-octree-construction-with-2-1-balance-and-surface-pr.md) by providing the specific topological criteria for refinement and the balancing mechanism [S1, unofficial]. It is designed for use with neural SDF models like DeepSDF and SDF-Diffusion [S1, unofficial].
