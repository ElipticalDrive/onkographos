# Adaptive Octree Construction with 2:1 Balance and Surface Propagation

Also called: Algorithm Improvements and Extensions, Implicit Function Octree Construction, Isotopic Octree Approximation, adaptive grid refinement for isosurfaces, isomesh octree building

## Overview
This method constructs an adaptive octree representation of an implicit surface by refining a 3D grid based on implicit function sign changes and geometric features, enforcing a 2:1 balance constraint (no face-adjacent leaves differ by more than 1 depth level) and ensuring manifold connectivity through surface propagation rules [S1, unofficial]. It solves the problem of generating a watertight, isotopic mesh approximation of complex implicit functions while minimizing vertex count compared to uniform grids [S1, unofficial]. Unlike [Homogeneity-Based KD-Tree Construction](1325-homogeneity-based-kd-tree-construction.md) which uses axis-aligned splits, or [MFA-DVR](1091-mfa-dvr.md) which focuses on direct volume rendering, this method produces a polygonal mesh via Dual Contouring [S1, unofficial]. It differs from [Constrained Octree Refinement](2426-constrained-octree-refinement.md) by explicitly enforcing the 2:1 balance during construction to prevent excessive geometric simplification, and from [Topological Octree Construction](4698-topological-octree-construction.md) by combining topological criteria with the specific balancing mechanism [S1, unofficial].

## How it works
The algorithm builds an octree where leaf cells are refined until they satisfy isotopy conditions (containing the surface or being clearly empty/inside) and balance constraints [S1, unofficial]. It uses Dual Contouring for mesh extraction, ensuring manifold output [S1, unofficial].

**Inputs:**
- `func`: A vectorized implicit function $f: \mathbb{R}^3 \to \mathbb{R}$ and optionally its gradient $\nabla f$. Signature: `func(positions: np.ndarray) -> (values: np.ndarray, gradients: np.ndarray | None)` [S1, unofficial].
- `bbox_min`, `bbox_max`: Bounding box of the domain [S1, unofficial].
- `min_depth`: Minimum subdivision depth (default 3) [S1, unofficial].
- `max_depth`: Maximum subdivision depth (default 7) [S1, unofficial].
- `angle_threshold_deg`: Threshold for sharp feature detection (default 30.0) [S1, unofficial].
- `iso_value`: Isosurface value (default 0.0) [S1, unofficial].

**Outputs:**
- `vertices`: Array of mesh vertex coordinates [S1, unofficial].
- `faces`: Array of mesh face indices [S1, unofficial].

**Data Structures:**
- **Octree Node**: Contains a bounding box, depth, and a list of children [G]. Leaves store cell data [G].
- **EvalCache**: Stores computed values and gradients for grid corners to avoid redundant evaluations [S1, unofficial].
- **AllLeaves**: A vector of leaf cells with coordinates $(cx, cy, cz)$ and depth, used for balancing [S1, unofficial].

**Parameters:**
- `min_depth`: u8. Typical: 3.
- `max_depth`: u8. Typical: 7.
- `angle_threshold_deg`: f64. Typical: 30.0.
- `iso_value`: f64. Typical: 0.0.
- `fd_step`: f64. Finite difference step if gradients not provided. Typical: `cell_size_at_max * 0.01` [S1, unofficial].

**Steps:**

1. **Initialization**: Initialize the octree with the bounding box [S1, unofficial]. Build a uniform grid up to `min_depth` [S1, unofficial]. If adaptive mode is enabled, call `build_adaptive` which internally calls `enforce_balance_2to1` [S1, unofficial].
2. **Adaptive Refinement Loop**: For each leaf cell $C$ in the octree:
   a. **Evaluation**: Compute the implicit function values at the 8 corners of cell $C$ [S1, unofficial]. Convert grid positions to world coordinates using `cache::grid_to_world` [S1, unofficial]. Batch evaluate these new points using `bridge::batch_evaluate` [S1, unofficial].
   b. **Gradient Handling**: If `func` does not return gradients, estimate them using finite differences with step size `cell_size_at_max * 0.01` [S1, unofficial]. Store values and gradients in `EvalCache` [S1, unofficial].
   c. **Refinement Criteria**: Mark cell $C$ for subdivision if:
      - The cell contains the surface (sign changes on edges or faces) [S1, unofficial].
      - The normal angle spread across the cell exceeds `angle_threshold_deg` [S1, unofficial].
      - **Rule 3 (Surface Propagation)**: If current cell $C$ is a surface cell, a face-neighbor $N$ is at the same depth but is a Branch containing surface descendants, and $depth(C) < max\_depth$, then $C$ must subdivide to prevent cross-depth gaps [S1, unofficial].
   d. **Subdivision**: For each marked cell, compute the 8 child octants [S1, unofficial]. Subdivide the marked cells in the octree structure using `subdivide_cell_for_balance` [S1, unofficial].
3. **2:1 Balance Enforcement**:
   a. Collect all leaf cells into `all_leaves` vector [S1, unofficial].
   b. Iterate through `all_leaves`. If a leaf $L$ has a face-adjacent neighbor $N$ with $depth(N) < depth(L) - 1$, subdivide $L$ (and potentially its siblings) until the depth difference is $\le 1$ [S1, unofficial]. Use `subdivide_cell_for_balance` [S1, unofficial].
   c. Note: Balancing is not strictly necessary for isotopy but simplifies leaf approximation and ensures uniformity [S2].
4. **Edge Completeness**: Call `ensure_edge_completeness` to ensure every sign-change edge has all 4 sharing cells present as surface leaves [S1, unofficial]. This eliminates gaps at depth boundaries [S1, unofficial]. Check non-canonical edges (1-3, 5-7, 9-11) for sign changes, as surface cells not owning a canonical edge still participate in quads generated by neighbors [S1, unofficial].
5. **Mesh Extraction (Dual Contouring)**:
   a. **QEF Vertex Placement**: For each surface leaf, construct a Quadric Error Function (QEF) based on the interpolated Hermite data (values and gradients) at the cell boundaries [G]. Solve for the vertex position using Jacobi SVD eigendecomposition [S1, unofficial]. Apply mass-point bias for rank-deficient cases to preserve sharp features [S1, unofficial].
   b. **Newton Projection**: Perform one Newton step to project each vertex exactly onto the zero-isosurface $f(x)=0$ [S1, unofficial].
   c. **Quad Generation**: Iterate over canonical edges [S1, unofficial]. Generate quads based on the flatness of the surface within the cell [S1, unofficial]. Triangulate quads if necessary [S1, unofficial].
   d. **Watertight Guarantee**: All surface leaves are forced to `max_depth` during extraction to eliminate T-junction holes [S1, unofficial].

**Pseudocode:**

```python
def extract_implicit_surface(func, bbox_min, bbox_max, min_depth=3, max_depth=7, angle_threshold=30.0, iso_value=0.0):
    octree = Octree(bbox_min, bbox_max, min_depth)
    refine_octree(octree, func, min_depth, max_depth, angle_threshold, iso_value)
    enforce_balance_2to1(octree)
    ensure_edge_completeness(octree)
    vertices, faces = dual_contour_extract(octree, func, iso_value)
    return vertices, faces

def refine_octree(octree, func, min_depth, max_depth, angle_threshold, iso_value):
    for leaf in octree.leaves:
        if leaf.depth >= max_depth:
            continue
        # Convert grid positions to world coordinates using cache::grid_to_world
        corners = get_corner_positions(leaf)
        # Batch evaluate these new points using bridge::batch_evaluate
        values, gradients = evaluate_func_batch(func, corners)
        if gradients is None:
            # If the Python function does not return gradients, estimate them using finite differences with step size cell_size_at_max * 0.01
            gradients = estimate_gradients(func, corners, step_size=leaf.cell_size_at_max * 0.01)
        # Store values and gradients in EvalCache
        leaf.cache = {"values": values, "gradients": gradients}
        
        needs_refine = False
        # The cell contains the surface (sign changes on edges or faces)
        if has_sign_changes(values, iso_value):
            needs_refine = True
        # The normal angle spread across the cell exceeds angle_threshold_deg
        if gradients is not None and normal_spread(gradients) > angle_threshold:
            needs_refine = True
        # Rule 3 (Surface Propagation)
        if is_surface_cell(values, iso_value):
            for neighbor in leaf.face_neighbors:
                if neighbor.depth == leaf.depth and neighbor.is_branch_with_surface_descendants():
                    if leaf.depth < max_depth:
                        needs_refine = True
                        break
        if needs_refine:
            # Subdivide the marked cells in the octree structure using subdivide_cell_for_balance
            subdivide_cell_for_balance(leaf)
            for child in leaf.children:
                refine_octree(child, func, min_depth, max_depth, angle_threshold, iso_value)

def enforce_balance_2to1(octree):
    # collect all leaf cells with coordinates (cx, cy, cz) and depth into all_leaves vector
    all_leaves = octree.get_all_leaves()
    changed = True
    while changed:
        changed = False
        for leaf in all_leaves:
            for neighbor in leaf.face_neighbors:
                if neighbor.is_leaf:
                    if leaf.depth - neighbor.depth > 1:
                        subdivide_cell_for_balance(leaf)
                        changed = True
                    elif neighbor.depth - leaf.depth > 1:
                        subdivide_cell_for_balance(neighbor)
                        changed = True

def ensure_edge_completeness(octree):
    # ensure every sign-change edge has all 4 sharing cells present as surface leaves
    for edge in octree.sign_change_edges:
        sharing_cells = edge.get_sharing_cells()
        for cell in sharing_cells:
            if not cell.is_surface_leaf:
                if cell.depth < octree.max_depth:
                    subdivide_cell_for_balance(cell)

def dual_contour_extract(octree, func, iso_value):
    vertices = []
    faces = []
    for leaf in octree.surface_leaves:
        # QEF Vertex Placement: construct QEF based on interpolated Hermite data
        qef_data = collect_hermite_data(leaf)
        vertex = solve_qef_jacobi_svd(qef_data)
        # Newton surface projection: one Newton step projects each vertex exactly onto the zero-isosurface
        vertex = newton_project(vertex, func, iso_value)
        vertices.append(vertex)
        # Quad Generation: iterate over canonical edges. Generate quads based on flatness
        quads = generate_quads(leaf, vertex)
        for quad in quads:
            faces.extend(triangulate_quad(quad))
    return vertices, faces

# Helper definitions
def get_corner_positions(leaf):
    # Convert grid positions to world coordinates
    positions = []
    for i in range(8):
        offset = np.array([(i & 1), ((i >> 1) & 1), ((i >> 2) & 1)], dtype=np.float64)
        positions.append(leaf.bbox_min + offset * leaf.size)
    return np.array(positions)

def evaluate_func_batch(func, positions):
    return func(positions)

def has_sign_changes(values, iso_value):
    return np.any(values < iso_value) and np.any(values > iso_value)

def is_surface_cell(values, iso_value):
    return has_sign_changes(values, iso_value)

def normalize(v):
    return v / np.linalg.norm(v)

def normal_spread(normals):
    # Compute max angular spread between normals
    if len(normals) < 2:
        return 0.0
    diffs = np.linalg.norm(normals[0] - normals[1:], axis=1)
    return np.max(diffs)

def estimate_gradients(func, corners, step_size):
    grads = np.zeros_like(corners)
    for i in range(3):
        offset = np.zeros_like(corners)
        offset[:, i] = step_size
        vals_plus, _ = func(corners + offset)
        vals_minus, _ = func(corners - offset)
        grads[:, i] = (vals_plus - vals_minus) / (2 * step_size)
    return grads

def subdivide_cell_for_balance(leaf):
    new_size = leaf.size / 2.0
    for i in range(8):
        offset = np.array([(i & 1), ((i >> 1) & 1), ((i >> 2) & 1)], dtype=np.float64)
        child_min = leaf.bbox_min + offset * leaf.size
        child = OctreeNode(child_min, child_min + new_size, leaf.depth + 1)
        leaf.children.append(child)
    leaf.is_leaf = False

def collect_hermite_data(leaf):
    corners = get_corner_positions(leaf)
    values, gradients = evaluate_func_batch(leaf.func, corners)
    return {"corners": corners, "values": values, "gradients": gradients}

def solve_qef_jacobi_svd(qef_data):
    # Standard QEF: minimize sum((a_i^T x - b_i)^2) where a_i = grad_i, b_i = grad_i^T * corner_i
    A = qef_data["gradients"]
    b = np.sum(A * qef_data["corners"], axis=1)
    # Solve using least squares (equivalent to SVD for this purpose)
    x, _, _, _ = np.linalg.lstsq(A, b, rcond=None)
    return x

def newton_project(vertex, func, iso_value):
    # One Newton step: x_new = x - f(x)/||grad(f)||^2 * grad(f)
    val, grad = func(np.array([vertex]))
    grad = grad[0]
    denom = np.dot(grad, grad)
    if denom < 1e-12:
        return vertex
    return vertex - (val[0] / denom) * grad

def generate_quads(leaf, vertex):
    # Standard Dual Contouring quad generation on cell faces
    quads = []
    face_normals = [
        np.array([1, 0, 0]), np.array([-1, 0, 0]),
        np.array([0, 1, 0]), np.array([0, -1, 0]),
        np.array([0, 0, 1]), np.array([0, 0, -1])
    ]
    face_offsets = [
        leaf.bbox_min + np.array([leaf.size, 0, 0]),
        leaf.bbox_min,
        leaf.bbox_min + np.array([0, leaf.size, 0]),
        leaf.bbox_min,
        leaf.bbox_min + np.array([0, 0, leaf.size]),
        leaf.bbox_min
    ]
    for i, (normal, center) in enumerate(zip(face_normals, face_offsets)):
        # Project vertex onto face plane
        dist = np.dot(vertex - center, normal)
        if abs(dist) < leaf.size * 0.5:
            # Generate quad on this face
            quad = [
                center + np.array([-0.5, -0.5, 0]) * leaf.size,
                center + np.array([0.5, -0.5, 0]) * leaf.size,
                center + np.array([0.5, 0.5, 0]) * leaf.size,
                center + np.array([-0.5, 0.5, 0]) * leaf.size
            ]
            quads.append(quad)
    return quads

def triangulate_quad(quad):
    return [quad[:3], [quad[0], quad[2], quad[3]]]
```

## Operating characteristics
- **Time Complexity**: Depends on the number of leaves $L$ [G]. Refinement is $O(L)$ per level [G]. Balancing is $O(L)$ with potential repeated passes [G]. Extraction is $O(L)$ [G]. Total time is dominated by function evaluations at grid corners [S1, unofficial].
- **Memory Complexity**: $O(L)$ for storing octree nodes and leaf data [G]. The octree structure itself is sparse [G].
- **Measured Performance**: On a sphere, adaptive refinement (depth 4->6) uses 536 vertices vs 8,600 for uniform depth 6, a 16x reduction [S1, unofficial]. On complex mechanical parts, adaptive mode is essential for quality [S1, unofficial].
- **Strengths**: Produces watertight, manifold meshes [S1, unofficial]. Handles sharp features better than Marching Cubes via QEF [S1, unofficial]. Adaptive resolution reduces vertex count for smooth surfaces [S1, unofficial]. Supports local updates for dynamic scenes (e.g., metaballs) [S2].
- **Limitations**: Balancing is not strictly necessary for isotopy but increases complexity [S2]. Singularities may require max depth limits, sacrificing isotopy locally [S2]. Finite difference gradients are unreliable for neural SDFs; autodiff is required [S1, unofficial].
- **When to use**: Extracting meshes from implicit functions, especially SDFs from neural networks or CAD data, where manifold output and sharp feature preservation are critical [S1, unofficial].
- **When not to use**: When Hausdorff distance minimization is the primary goal (this method prioritizes isotopy) [S2]. For unbounded curves or surfaces, the initial bounding box must be made larger than the area of interest and outer cells discarded afterwards [S2].

## Background
The method is based on the `isomesh` library, which implements Dual Contouring of Hermite Data [S1, unofficial]. The theoretical foundation for isotopic approximation of implicit surfaces is provided by [S2], which guarantees isotopy between the mesh and the surface. The algorithm builds on [Adaptive Octree Construction with 2:1 Balance and Surface Propagation](830-adaptive-octree-construction-with-2-1-balance-and-surface-pr.md) by providing the specific topological criteria for refinement and the balancing mechanism [S1, unofficial]. It is designed for use with neural SDF models like DeepSDF and SDF-Diffusion [S1, unofficial].
