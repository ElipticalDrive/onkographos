# Scene Geometry and Scalar Range Initialization

Also called: BuildSceneGeometry

## Overview
Constructs the scene geometry and scalar ranges for volume rendering by aggregating Adaptive Mesh Refinement (AMR) box data, computing global bounding boxes via MPI, applying normalization scaling, and determining scalar value ranges including optional logarithmic scaling. It differs from sibling methods by focusing on the initialization phase of the rendering pipeline, specifically establishing the spatial and data domains before reconstruction or ray marching begins.

## How it works
**Inputs and Outputs:**
*   **Inputs:** `ownedLevels` (vector of AMR level data), `levelGeometry` (geometry for each level), `options` (configuration struct containing `minLevel`, `maxLevel`, `component`, `logScaleInput`, `noDataError`, `invalidScalarError`).
*   **Outputs:** A populated `scene` object containing `ownedLevels`, `localBoxes`, `globalMin`/`globalMax`, `explicitBounds`, `originalScalarRange`, `processedScalarRange`, and `scalarTransform`.

**Data Structures:**
*   `VolumeRenderer::AmrBox`:
    *   `cellDimensions`: `amrex::IntVect` (dimensions in cells).
    *   `validBox`: `amrex::Box` (logical box indices).
    *   `values`: `const array reference` from MultiFab.
    *   `component`: `int` (data component index).
    *   `minCorner`: `Vec3` (physical minimum corner).
    *   `maxCorner`: `Vec3` (physical maximum corner).
*   `LocalScalarStats`:
    *   `minValue`: `amrex::Real` (initialized to $+\infty$).
    *   `maxValue`: `amrex::Real` (initialized to $-\infty$).
    *   `minPositive`: `amrex::Real` (initialized to $+\infty$).
    *   `finiteCount`: `amrex::Long` (initialized to 0).

**Steps:**

1.  **Validate Inputs:** Throw `std::invalid_argument` if `ownedLevels` is null or if `ownedLevels->size() != levelGeometry.size()`.
2.  **Initialize Scene:** Move `ownedLevels` into `scene.ownedLevels`. Reserve 64 slots for `scene.localBoxes`. Initialize `localMinOriginal` and `localMaxOriginal` to $\pm \infty$. Set `hasLocalBoxes = false`. Initialize `localScalarStats`.
3.  **Iterate Levels:** Loop `level` from `options.minLevel` to `options.maxLevel`.
    *   Skip if `level < 0` or `level >= scene.ownedLevels->size()`.
    *   Get `MultiFab mf` from `ownedLevels[level]`.
    *   Skip if `mf.size() == 0`.
4.  **Compute Local Scalar Statistics:** Call `reduceLocalScalarStats(mf, options.component)` and merge results into `localScalarStats`.
    *   *Note:* The GPU reduce kernel checks finiteness. For each value, if finite, it returns `{raw, raw, positive, 1}`; otherwise `{inf, -inf, inf, 0}`.
5.  **Iterate Valid Boxes:** Use `amrex::MFIter` to iterate valid boxes in `mf`.
    *   Get `box`, `lo` (smallEnd), `hi` (bigEnd).
    *   Calculate dimensions `nx, ny, nz`.
    *   Skip if any dimension $\le 0$.
    *   Assign `minCorner` and `maxCorner` to `amrBox`.
    *   Update `localMinOriginal` and `localMaxOriginal` using `componentMin` and `componentMax` from the box data.
    *   Set `hasLocalBoxes = true`.
    *   Push `amrBox` to `scene.localBoxes`.
    *   *Formula for corners:*
        $$ \text{minCorner}[x] = \text{geom.probLo}[x] + \text{lo}[x] \times \text{geom.cellSize}[x] $$
        $$ \text{maxCorner}[x] = \text{geom.probLo}[x] + (\text{hi}[x] + 1) \times \text{geom.cellSize}[x] $$
        for $x \in \{0, 1, 2\}$.
6.  **Compute Global Bounding Box (Original):** Gather `localMinOriginal` and `localMaxOriginal` arrays to all ranks using `MPI_Allreduce` with `MPI_MIN` and `MPI_MAX` to obtain `globalMinOriginal` and `globalMaxOriginal`.
7.  **Compute Global Scale Factor:**
    *   Find `minExtent` as the minimum non-zero finite axis length of `globalExtentOriginal` ($\text{globalMaxOriginal} - \text{globalMinOriginal}$).
    *   Set `globalScale = 1.0 / minExtent`.
    *   If `minExtent <= 0` or is not finite, set `globalScale = 1.0`.
    *   If `globalScale` is not finite or $\le 0$, reset to `1.0`.
8.  **Apply Global Scale:** If `globalScale != 1.0`, multiply all box `minCorner`/`maxCorner`, `globalMinOriginal`, and `globalMaxOriginal` by `globalScale`.
9.  **Compute Final Global Bounding Box:** Compute `globalMin` and `globalMax` from the scaled boxes using `MPI_Allreduce` (`MPI_MIN`/`MPI_MAX`).
10. **Compute Explicit Bounds:**
    *   `extent = globalMax - globalMin`.
    *   `maxExtent = max(axis extents)`.
    *   `paddingAmount = maxExtent * 0.05` if `maxExtent > 0`, else `1.0`.
    *   `scene.explicitBounds.minCorner = globalMin - padding`.
    *   `scene.explicitBounds.maxCorner = globalMax + padding`.
    *   Set `scene.hasExplicitBounds = true`.
11. **Gather Scalar Statistics:**
    *   Send `localOriginalMinSend` and `localOriginalMaxSend` (based on `localScalarStats.finiteCount > 0`) via `MPI_Allreduce` (`MPI_MIN`/`MPI_MAX`) to get `globalOriginalScalarMin` and `globalOriginalScalarMax`.
    *   Sum `finiteCount` via `MPI_SUM` to get `globalOriginalFiniteCount`.
12. **Set Original Scalar Range:** If `globalOriginalFiniteCount > 0` and both min/max are finite, set `scene.originalScalarRange = makeScalarRange(globalOriginalScalarMin, globalOriginalScalarMax)` and `scene.hasOriginalScalarRange = true`.
13. **Logarithmic Scaling (Optional):** If `options.logScaleInput` is true:
    *   Gather `globalPositiveMin` (min of positive values) via `MPI_MIN`.
    *   Count `globalPositiveCount` via `MPI_SUM`.
    *   If `globalPositiveCount <= 0` or `globalPositiveMin` is not finite or $\le 0$, throw `std::runtime_error "Log scaling requested but no positive scalar values were found."`.
    *   *Formula for processed range:*
        $$ \text{processedMin} = \log(\text{globalPositiveMin}) $$
        $$ \text{processedMax} = \log(\max(\text{globalOriginalScalarMax}, \text{globalPositiveMin})) $$
    *   Set `scene.processedScalarRange`, `scene.hasProcessedScalarRange`, `scene.scalarTransform.processedMin`, `scene.scalarTransform.processedMax`, and `scene.scalarTransform.inverseProcessedSpan = 1.0 / (\text{processedMax} - \text{processedMin})`.
    *   Set `scene.scalarTransform.positiveFloor = globalPositiveMin`.

**Pseudocode:**

```python
def build_scene_geometry(owned_levels, level_geometry, options):
    # 1. Validate Inputs
    if owned_levels is None or len(owned_levels) != len(level_geometry):
        raise std.invalid_argument("Invalid input levels")

    scene = Scene()
    scene.owned_levels = owned_levels
    scene.local_boxes.reserve(64)
    local_min_original = float('inf')
    local_max_original = float('-inf')
    has_local_boxes = False
    local_scalar_stats = LocalScalarStats()

    # 3. Iterate Levels
    for level in range(options.min_level, options.max_level + 1):
        if level < 0 or level >= len(scene.owned_levels):
            continue
        
        mf = scene.owned_levels[level]
        if mf.size() == 0:
            continue

        # 4. Compute Local Scalar Statistics
        reduce_local_scalar_stats(mf, options.component, local_scalar_stats)

        # 5. Iterate Valid Boxes
        for box in amrex.MFIter(mf):
            lo = box.small_end()
            hi = box.big_end()
            nx, ny, nz = box.dimensions()
            
            if nx <= 0 or ny <= 0 or nz <= 0:
                continue

            geom = level_geometry[level]
            
            # Formula for corners
            min_corner = Vec3(
                geom.prob_lo[0] + lo[0] * geom.cell_size[0],
                geom.prob_lo[1] + lo[1] * geom.cell_size[1],
                geom.prob_lo[2] + lo[2] * geom.cell_size[2]
            )
            max_corner = Vec3(
                geom.prob_lo[0] + (hi[0] + 1) * geom.cell_size[0],
                geom.prob_lo[1] + (hi[1] + 1) * geom.cell_size[1],
                geom.prob_lo[2] + (hi[2] + 1) * geom.cell_size[2]
            )

            # Update scalar stats from box data
            comp_min, comp_max = get_component_min_max(mf, box, options.component)
            local_min_original = min(local_min_original, comp_min)
            local_max_original = max(local_max_original, comp_max)

            has_local_boxes = True
            amr_box = AmrBox(
                cell_dimensions=box.dimensions(),
                valid_box=box,
                values=mf.get_array(box),
                component=options.component,
                min_corner=min_corner,
                max_corner=max_corner
            )
            scene.local_boxes.push_back(amr_box)

    # Pitfall: Handle empty ranges
    if not has_local_boxes:
        local_min_original = float('max') # Implementation specific max
        local_max_original = float('-max') # Implementation specific min

    # 6. Compute Global Bounding Box (Original)
    global_min_original = mpi_allreduce(local_min_original, op=mpi_min)
    global_max_original = mpi_allreduce(local_max_original, op=mpi_max)

    # 7. Compute Global Scale Factor
    global_extent = global_max_original - global_min_original
    min_extent = min(axis_lengths(global_extent))
    
    if min_extent <= 0 or not is_finite(min_extent):
        global_scale = 1.0
    else:
        global_scale = 1.0 / min_extent

    if not is_finite(global_scale) or global_scale <= 0:
        global_scale = 1.0

    # 8. Apply Global Scale
    if global_scale != 1.0:
        for box in scene.local_boxes:
            box.min_corner *= global_scale
            box.max_corner *= global_scale
        global_min_original *= global_scale
        global_max_original *= global_scale

    # 9. Compute Final Global Bounding Box
    # Re-gather from scaled boxes to ensure consistency
    global_min = mpi_allreduce_min(scene.local_boxes, 'min_corner')
    global_max = mpi_allreduce_max(scene.local_boxes, 'max_corner')

    # 10. Compute Explicit Bounds
    extent = global_max - global_min
    max_extent = max(axis_lengths(extent))
    padding_amount = max_extent * 0.05 if max_extent > 0 else 1.0
    
    scene.explicit_bounds.min_corner = global_min - padding_amount
    scene.explicit_bounds.max_corner = global_max + padding_amount
    scene.has_explicit_bounds = True

    # 11. Gather Scalar Statistics
    if local_scalar_stats.finite_count > 0:
        global_orig_scalar_min = mpi_allreduce(local_scalar_stats.min_value, op=mpi_min)
        global_orig_scalar_max = mpi_allreduce(local_scalar_stats.max_value, op=mpi_max)
    else:
        global_orig_scalar_min = float('inf')
        global_orig_scalar_max = float('-inf')
        
    global_orig_finite_count = mpi_allreduce(local_scalar_stats.finite_count, op=mpi_sum)

    # 12. Set Original Scalar Range
    if global_orig_finite_count > 0 and is_finite(global_orig_scalar_min) and is_finite(global_orig_scalar_max):
        scene.original_scalar_range = make_scalar_range(global_orig_scalar_min, global_orig_scalar_max)
        scene.has_original_scalar_range = True

    # 13. Logarithmic Scaling
    if options.log_scale_input:
        global_positive_min = mpi_allreduce(local_scalar_stats.min_positive, op=mpi_min)
        global_positive_count = mpi_allreduce(local_scalar_stats.finite_count, op=mpi_sum) # Note: Source says sum finiteCount, but logic implies counting positives. Assuming source logic holds.
        
        if global_positive_count <= 0 or not is_finite(global_positive_min) or global_positive_min <= 0:
            raise std.runtime_error("Log scaling requested but no positive scalar values were found.")

        processed_min = log(global_positive_min)
        processed_max = log(max(global_orig_scalar_max, global_positive_min))
        
        scene.processed_scalar_range = make_scalar_range(processed_min, processed_max)
        scene.has_processed_scalar_range = True
        scene.scalar_transform.processed_min = processed_min
        scene.scalar_transform.processed_max = processed_max
        scene.scalar_transform.inverse_processed_span = 1.0 / (processed_max - processed_min)
        scene.scalar_transform.positive_floor = global_positive_min

    # Pitfall: Check for invalid ranges
    if global_min > global_max:
        raise std.runtime_error(options.no_data_error)
        
    if not is_finite(processed_min) or not is_finite(processed_max):
        raise std.runtime_error(options.invalid_scalar_error)
        
    if processed_min == processed_max:
        scene.scalar_transform.processed_max = processed_min + 1.0

    return scene
```

**Parameters:**
*   `options.logScaleInput`: Boolean flag to enable logarithmic scaling of scalar values.
*   `options.component`: Integer index specifying which component of the MultiFab to use for scalar values.
*   `options.minLevel` / `options.maxLevel`: Integer bounds for the AMR levels to process.

## Subtopics

### Data Bounds Determination
A procedure to obtain minimum and maximum data bounds for scaling colors, using one of three methods: manual user setting for consistent coloring across file types, percentile bounds (default 1st and 99th) to handle outliers by scanning data for a histogram, or global bounds for the entire dataset [S2, unofficial].
