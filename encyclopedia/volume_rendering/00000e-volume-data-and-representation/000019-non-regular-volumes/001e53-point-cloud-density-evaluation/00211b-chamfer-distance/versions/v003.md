# Chamfer Distance
Also called: Depth Error, F-score, Geometry Metrics, Normal Error

## Overview
Chamfer Distance (CD) calculates a symmetric distance between two point clouds by averaging the nearest-neighbor distances in both directions [S1, S2]. It is used to evaluate the geometric accuracy of reconstructed meshes or point clouds against ground-truth data [S3, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Two point clouds, $\chi_1$ and $\chi_2$, where each cloud is a set of 3D points [S1].
- Output: A scalar value representing the symmetric Chamfer Distance.

**Data Structures:**
- Point clouds $\chi_1$ and $\chi_2$ are stored as arrays of coordinates [G]. A spatial index structure such as a KDTree is typically used for efficient nearest-neighbor queries [G].

**Formula:**
The Chamfer Distance is defined as [S1, S2]:

$$CD(\chi_1, \chi_2) = \frac{1}{|\chi_1|} \sum_{x \in \chi_1} \min_{y \in \chi_2} ||x - y||_2 + \frac{1}{|\chi_2|} \sum_{y \in \chi_2} \min_{x \in \chi_1} ||y - x||_2$$

Where:
- $|\chi|$ is the number of points in the cloud [S2].
- $||\cdot||_2$ is the Euclidean distance [S2].
- The first term averages the distance from each point in $\chi_1$ to its nearest neighbor in $\chi_2$ [S1, S2].
- The second term averages the distance from each point in $\chi_2$ to its nearest neighbor in $\chi_1$ [S1, S2].

**Steps:**
1. For each point $x \in \chi_1$, find the nearest neighbor $y \in \chi_2$ [G].
2. Compute the Euclidean distance $||x - y||_2$ for all $x \in \chi_1$ and average them to get the first term [G].
3. For each point $y \in \chi_2$, find the nearest neighbor $x \in \chi_1$ [G].
4. Compute the Euclidean distance $||y - x||_2$ for all $y \in \chi_2$ and average them to get the second term [G].
5. Sum the two averaged terms to obtain the final CD value [G].

**Pseudocode:**
```python
import numpy as np

def chamfer_distance(points1: np.ndarray, points2: np.ndarray) -> float:
    """
    Calculate the symmetric Chamfer Distance between two point clouds.
    
    Args:
        points1: Array of shape (N, 3) containing coordinates of the first point cloud.
        points2: Array of shape (M, 3) containing coordinates of the second point cloud.
        
    Returns:
        The symmetric Chamfer Distance.
    """
    # Compute pairwise Euclidean distances from points1 to points2
    # Broadcasting: (N, 1, 3) - (1, M, 3) -> (N, M, 3)
    dists1_to_2 = np.sqrt(np.sum((points1[:, np.newaxis, :] - points2[np.newaxis, :, :]) ** 2, axis=2))
    min_dists1 = np.min(dists1_to_2, axis=1)
    mean_dist1 = np.mean(min_dists1)

    # Compute pairwise Euclidean distances from points2 to points1
    dists2_to_1 = np.sqrt(np.sum((points2[:, np.newaxis, :] - points1[np.newaxis, :, :]) ** 2, axis=2))
    min_dists2 = np.min(dists2_to_1, axis=1)
    mean_dist2 = np.mean(min_dists2)

    # Symmetric Chamfer Distance
    return float(mean_dist1 + mean_dist2)
```

**Parameters:**
- $\chi_1, \chi_2$: The two point clouds to compare [S1].
- No other specific parameters are required for the standard definition [G].

## Subtopics

### Mean Distance Computation
Computes the mean squared distance to the 3 nearest neighbors (excluding self, hence indices 1:4) and returns it as a tensor [S4, unofficial].

### Edge Chamfer Distance
Chamfer Distance calculated specifically for points sampled on the edges of meshes to gauge edge reconstruction quality and sharpness [S1].

## Background
Chamfer Distance was introduced as an evaluation metric for 3D shape reconstruction tasks [S1, S2]. It is widely used in benchmarks such as ABC and Thingi10k to assess mesh reconstruction quality [S2]. The metric is also part of a broader set of geometry metrics including F-score, Depth Error, and Normal Error, which are used to evaluate reconstructed geometry in datasets like DTU and Tanks & Temples [S3, unofficial].
