# Chamfer Distance Transform
Also called: Chamfer DT
## Overview
The Chamfer Distance Transform (CDT) is a grid-based algorithm that estimates the Euclidean distance from any voxel to the nearest zero-surface (boundary) by propagating distance values from neighbors using fixed template weights [S1, unofficial][S2]. Unlike exact methods such as the Fast Marching Method, CDT approximates distances through local additions, making it computationally efficient but less accurate at larger distances from the surface [S2]. It is primarily used in volume data generation pipelines alongside brute-force and vector-based transforms [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A 3D voxel grid where boundary voxels (zero-surface) are initialized with distance 0, and interior/exterior voxels are initialized with infinity or a large constant.
- Output: A 3D distance field where each voxel contains the estimated Euclidean distance to the nearest boundary voxel.

**Data Structures:**
- A 3D array `D` of size $W \times H \times D$ (width, height, depth).
- Each element `D[i][j][k]` stores a floating-point distance value.
- A boolean mask or signed distance field (SDF) initialization step identifies boundary voxels.

**Algorithm Steps:**
1. **Initialization:** Set all voxels to $\infty$. Set voxels on the zero-surface (boundary) to 0.
2. **Propagation:** Iterate through the grid in a specific order (typically multiple passes, e.g., forward and backward) to propagate distances. For each voxel, update its distance based on its neighbors using a predefined template.
3. **Template Application:** The new distance for a voxel is computed by adding a template value to the distance of a neighbor. The template values approximate the Euclidean distance between grid points.
4. **Convergence:** Repeat passes until distances stabilize or a fixed number of passes is completed.

**Formulas:**
The distance update for a voxel $v$ is:
$$ D[v] = \min_{n \in \text{Neighbors}} (D[n] + T[n \to v]) $$
where:
- $D[v]$ is the distance at voxel $v$.
- $n$ is a neighboring voxel.
- $T[n \to v]$ is the template weight for the direction from $n$ to $v$.

**Parameters:**
- **Template Weights:** Common 3D templates include:
  - 6-connected (face neighbors): weight $\approx 1.0$
  - 18-connected (face + edge neighbors): weights $\approx 1.0, \sqrt{2} \approx 1.414$
  - 26-connected (face + edge + corner neighbors): weights $\approx 1.0, \sqrt{2}, \sqrt{3} \approx 1.732$
  - Specific optimized templates exist to minimize error, but exact values are not provided in the sources [S2].
- **Passes:** Typically 2 passes (forward and backward) are sufficient for convergence in many implementations, though more may be needed for accuracy [S2].

**Pseudocode:**
```python
def chamfer_distance_transform(grid, template_weights):
    """
    grid: 3D array initialized with 0 for boundary voxels and infinity for others.
    template_weights: dict mapping neighbor offsets to distance weights.
    Returns: 3D array of distances.
    """
    # Initialize distance field
    D = grid.copy()
    
    # Define neighbor offsets based on connectivity (e.g., 26-connected)
    # Offsets are relative coordinates (dx, dy, dz)
    offsets = list(template_weights.keys())
    
    # Multiple passes for propagation
    # Forward pass
    for i in range(grid.shape[0]):
        for j in range(grid.shape[1]):
            for k in range(grid.shape[2]):
                current_dist = D[i, j, k]
                for offset in offsets:
                    dx, dy, dz = offset
                    ni, nj, nk = i + dx, j + dy, k + dz
                    # Check bounds
                    if 0 <= ni < grid.shape[0] and 0 <= nj < grid.shape[1] and 0 <= nk < grid.shape[2]:
                        neighbor_dist = D[ni, nj, nk]
                        weight = template_weights[offset]
                        new_dist = neighbor_dist + weight
                        if new_dist < current_dist:
                            current_dist = new_dist
                D[i, j, k] = current_dist
                
    # Backward pass (to ensure full propagation)
    for i in range(grid.shape[0] - 1, -1, -1):
        for j in range(grid.shape[1] - 1, -1, -1):
            for k in range(grid.shape[2] - 1, -1, -1):
                current_dist = D[i, j, k]
                for offset in offsets:
                    dx, dy, dz = offset
                    ni, nj, nk = i + dx, j + dy, k + dz
                    # Check bounds
                    if 0 <= ni < grid.shape[0] and 0 <= nj < grid.shape[1] and 0 <= nk < grid.shape[2]:
                        neighbor_dist = D[ni, nj, nk]
                        weight = template_weights[offset]
                        new_dist = neighbor_dist + weight
                        if new_dist < current_dist:
                            current_dist = new_dist
                D[i, j, k] = current_dist
                
    return D
```

**Edge Cases and Pitfalls:**
- **Accuracy Degradation:** Accuracy decreases as the distance from the surface increases [S2].
- **Boundary Conditions:** Proper handling of grid boundaries is required to avoid out-of-bounds errors.
- **Initialization:** Incorrect initialization of boundary voxels leads to incorrect distance fields.

## Operating characteristics
- **Time Complexity:** $O(N)$ per pass, where $N$ is the number of voxels. Typically requires 2-3 passes.
- **Memory Complexity:** $O(N)$ for the distance field.
- **Performance:** Fast and suitable for real-time applications due to simple arithmetic operations [S2].
- **Strengths:** Simple implementation, low computational cost, easy to parallelize.
- **Limitations:** Approximate distances, accuracy degrades with distance from surface [S2].
- **When to Use:** When speed is critical and approximate distances are acceptable.
- **When Not to Use:** When high precision is required, especially far from the surface.

## Background
The Chamfer Distance Transform was introduced as a method for propagating distance information from a zero-surface in a grid-based volume [S1, unofficial]. It is often compared with Vector Distance Transforms and Fast Marching Methods in the context of volume data generation from triangle meshes [S1, unofficial][S2]. The technique is part of a broader family of distance transforms used in computer graphics and geometric modeling.
