# Plausible Diversity Metric

Also called: PlausibleDiversity

## Overview
The Plausible Diversity Metric evaluates an estimated set of object poses against a reference set of plausible poses by computing plausibility and coverage scores [S1, unofficial]. Plausibility measures the average distance from each estimated pose to its nearest plausible pose, while coverage measures the average distance from each plausible pose to its nearest estimated pose [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A batch of $B$ estimated transforms $T_{\text{est}}$ (world-to-link) and a set of $P$ plausible transforms $T_p$ (world-to-link) [S1, unofficial].
*   **Output:** A `PlausibleDiversityReturn` named tuple containing `plausibility`, `coverage`, `most_plausible_per_estimated`, and `most_covered_per_plausible` [S1, unofficial].

**Data Structures:**
*   `PlausibleDiversityReturn`: A `NamedTuple` with fields `plausibility` (torch.tensor), `coverage` (torch.tensor), `most_plausible_per_estimated` (torch.tensor), and `most_covered_per_plausible` (torch.tensor) [S1, unofficial].
*   `errors_per_batch`: A 2D tensor of shape $(B, P)$ containing the pairwise distances between each estimated transform and each plausible transform [S1, unofficial].

**Parameters:**
*   `num_model_points_eval`: Number of points sampled from the object mesh for evaluation. Default is 500 [S1, unofficial].
*   `bidirectional`: Boolean flag. If `True`, the metric is computed in both directions and averaged [S1, unofficial].
*   `plausible_suboptimality`: Tolerance for SDF queries used in underlying mesh operations [S1, unofficial].

**Steps:**
1.  **Initialization:** If `model_points_eval` is not provided, sample `num_model_points_eval` (default 500) points from the object mesh [S1, unofficial].
2.  **Pairwise Error Calculation:** Compute the pairwise error matrix `errors_per_batch` of shape $(B, P)$ using `compute_tf_pairwise_error_per_batch(T_{\text{est}}^{-1}, T_p, \text{scale})` [S1, unofficial].
3.  **Forward Evaluation:** Evaluate plausibility and coverage from `errors_per_batch` using `do_evaluate_plausible_diversity_on_pairwise_chamfer_dist(errors_per_batch)` [S1, unofficial].
4.  **Bidirectional Averaging (Optional):** If `bidirectional` is `True`, compute reverse `errors_per_batch_rev` using $T_p$ and $T_{\text{est}}^{-1}$, evaluate `ret2`, and average the results: $\text{plausibility} = (\text{ret.plausibility} + \text{ret2.coverage}) / 2$, $\text{coverage} = (\text{ret.coverage} + \text{ret2.plausibility}) / 2$ [S1, unofficial]. Otherwise, use `ret` directly [S1, unofficial].

**Formulas:**
Let $E$ be the `errors_per_batch` matrix of shape $(B, P)$, where $E_{ij}$ is the distance between the $i$-th estimated transform and the $j$-th plausible transform [S1, unofficial].

*   **Plausibility:** The average minimum distance from each estimated transform to its nearest plausible transform [S1, unofficial]:
    $$ \text{plausibility} = \frac{1}{B} \sum_{i=1}^{B} \min_{j} E_{ij} $$
    In code: `sum(min(errors_per_batch, dim=1).values) / B` [S1, unofficial].

*   **Coverage:** The average minimum distance from each plausible transform to its nearest estimated transform [S1, unofficial]:
    $$ \text{coverage} = \frac{1}{P} \sum_{j=1}^{P} \min_{i} E_{ij} $$
    In code: `sum(min(errors_per_batch, dim=0).values) / P` [S1, unofficial].

**Pseudocode:**
```python
import torch
from typing import NamedTuple

class PlausibleDiversityReturn(NamedTuple):
    plausibility: torch.Tensor
    coverage: torch.Tensor
    most_plausible_per_estimated: torch.Tensor
    most_covered_per_plausible: torch.Tensor

def plausible_diversity_metric(
    T_est_inv: torch.Tensor,
    T_p: torch.Tensor,
    scale: float = 1.0,
    bidirectional: bool = False,
    num_model_points_eval: int = 500
) -> PlausibleDiversityReturn:
    # Step 1: Initialization
    # If model_points_eval is None, sample num_model_points_eval points from the mesh [S1, unofficial]
    # Point sampling is handled internally by the library's mesh utilities [G]

    # Step 2: Compute pairwise error matrix of shape (B, P) [S1, unofficial]
    errors_per_batch = compute_tf_pairwise_error_per_batch(T_est_inv, T_p, scale)

    # Step 3: Forward evaluation [S1, unofficial]
    ret = do_evaluate_plausible_diversity_on_pairwise_chamfer_dist(errors_per_batch)

    if bidirectional:
        # Step 4: Bidirectional averaging [S1, unofficial]
        errors_per_batch_rev = compute_tf_pairwise_error_per_batch(T_p, T_est_inv, scale)
        ret2 = do_evaluate_plausible_diversity_on_pairwise_chamfer_dist(errors_per_batch_rev)
        plausibility = (ret.plausibility + ret2.coverage) / 2.0
        coverage = (ret.coverage + ret2.plausibility) / 2.0
        most_plausible_per_estimated = ret.most_plausible_per_estimated
        most_covered_per_plausible = ret.most_covered_per_plausible
    else:
        plausibility = ret.plausibility
        coverage = ret.coverage
        most_plausible_per_estimated = ret.most_plausible_per_estimated
        most_covered_per_plausible = ret.most_covered_per_plausible

    return PlausibleDiversityReturn(
        plausibility=plausibility,
        coverage=coverage,
        most_plausible_per_estimated=most_plausible_per_estimated,
        most_covered_per_plausible=most_covered_per_plausible
    )

def compute_tf_pairwise_error_per_batch(T1: torch.Tensor, T2: torch.Tensor, scale: float) -> torch.Tensor:
    """
    Computes pairwise distances between two sets of transforms.
    Returns a tensor of shape (len(T1), len(T2)).
    Uses translation components as a standard proxy for pose distance [G].
    """
    t1 = T1[:, :3, 3]  # (B, 3)
    t2 = T2[:, :3, 3]  # (P, 3)
    dist = torch.cdist(t1, t2) * scale
    return dist

def do_evaluate_plausible_diversity_on_pairwise_chamfer_dist(errors: torch.Tensor) -> PlausibleDiversityReturn:
    """
    Computes plausibility and coverage from a pairwise error matrix.
    Args:
        errors: Tensor of shape (B, P).
    Returns:
        PlausibleDiversityReturn.
    """
    B, P = errors.shape
    
    # Plausibility: min over P (dim=1) for each B [S1, unofficial]
    min_errors_est, most_plausible_per_estimated = torch.min(errors, dim=1)
    plausibility = torch.sum(min_errors_est) / B
    
    # Coverage: min over B (dim=0) for each P [S1, unofficial]
    min_errors_p, most_covered_per_plausible = torch.min(errors, dim=0)
    coverage = torch.sum(min_errors_p) / P
    
    return PlausibleDiversityReturn(
        plausibility=plausibility,
        coverage=coverage,
        most_plausible_per_estimated=most_plausible_per_estimated,
        most_covered_per_plausible=most_covered_per_plausible
    )
```

## Operating characteristics
The evaluation step computes a $(B, P)$ error matrix, yielding $O(B \cdot P)$ complexity per direction. Bidirectional evaluation doubles this cost. Not given in the sources.

## Background
The metric is implemented in the `pytorch_volumetric` library [S1, unofficial].
