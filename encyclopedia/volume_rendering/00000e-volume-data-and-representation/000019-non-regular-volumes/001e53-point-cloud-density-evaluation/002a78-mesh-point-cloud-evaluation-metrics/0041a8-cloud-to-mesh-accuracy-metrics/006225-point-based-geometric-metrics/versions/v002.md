# Point-Based Geometric Metrics

Also called: point-to-point, point-to-plane, plane-to-plane

## Overview
Point-Based Geometric Metrics are full-reference methods that assess the geometric fidelity of a distorted point cloud by comparing its points against a reference model [S1]. They differ from projection-based metrics by operating directly in 3D space rather than projecting onto 2D views, and from point-to-mesh metrics by avoiding surface reconstruction artifacts that can skew scores [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Reference point cloud $P_{\text{ref}}$ and distorted point cloud $P_{\text{dist}}$ [S1].
*   **Outputs:** A scalar error metric (MSE, RMS, or Hausdorff distance) or geometric PSNR [S1].

**Data Structures:**
*   Points are represented as 3D vectors $\mathbf{p} = (x, y, z)$ [G].
*   Normals are unit vectors $\mathbf{n} = (n_x, n_y, n_z)$ [G].

**Steps:**

1.  **Association:** Associate each distorted point $\mathbf{p}_i \in P_{\text{dist}}$ with its nearest neighbor $\mathbf{r}_i \in P_{\text{ref}}$ using the nearest neighbor algorithm [S1].
2.  **Metric Calculation:** Compute the per-point error $e_i$ based on the chosen variant [S1].
    *   **Point-to-Point:** Computes the Euclidean distance between associated points [S1].
        $$ e_i = \| \mathbf{p}_i - \mathbf{r}_i \|_2 $$
    *   **Point-to-Plane:** Projects the error vector onto the normal vector $\mathbf{n}_i$ of the reference point $\mathbf{r}_i$ [S1].
        $$ e_i = | (\mathbf{p}_i - \mathbf{r}_i) \cdot \mathbf{n}_i | $$
    *   **Plane-to-Plane:** Computes the angular similarity between the tangent plane of the distorted point and the tangent plane of the reference point [S1]. Let $\mathbf{n}_i^{\text{dist}}$ be the normal of the distorted point and $\mathbf{n}_i$ be the normal of the reference point [G].
        $$ e_i = 1 - | \mathbf{n}_i^{\text{dist}} \cdot \mathbf{n}_i | $$
3.  **Aggregation:** Aggregate the per-point errors $e_i$ for $i=1 \dots N$ to obtain total geometric degradation using MSE, RMS, or Hausdorff distance [S1].
    *   **Mean Squared Error (MSE):**
        $$ \text{MSE} = \frac{1}{N} \sum_{i=1}^{N} e_i^2 $$
    *   **Root-Mean-Squared (RMS):**
        $$ \text{RMS} = \sqrt{\frac{1}{N} \sum_{i=1}^{N} e_i^2} $$
    *   **Hausdorff Distance:**
        $$ H = \max_{i} e_i $$
4.  **Geometric PSNR:** To account for differently scaled contents, compute the geometric PSNR as the ratio of the squared maximum distance of nearest neighbors of the original content divided by the squared error value [S1].
    $$ \text{PSNR} = 10 \log_{10} \left( \frac{d_{\text{max}}^2}{\text{Error}^2} \right) $$
    where $d_{\text{max}}$ is the maximum nearest-neighbor distance in $P_{\text{ref}}$ and $\text{Error}$ is the aggregated metric value [S1].

**Pseudocode:**
```python
import numpy as np

def compute_point_based_metrics(ref_pts, dist_pts, ref_normals=None, dist_normals=None, 
                                metric_type="point_to_point", aggregation="mse"):
    # 1. Association: find nearest neighbor in ref for each dist point
    # Uses standard spatial indexing (e.g., KDTree) [G]
    indices = find_nearest_neighbors(dist_pts, ref_pts)
    ref_pts_assoc = ref_pts[indices]
    
    errors = []
    for i, (p, r) in enumerate(zip(dist_pts, ref_pts_assoc)):
        if metric_type == "point_to_point":
            e = np.linalg.norm(p - r)
        elif metric_type == "point_to_plane":
            n = ref_normals[indices[i]]
            e = abs(np.dot(p - r, n))
        elif metric_type == "plane_to_plane":
            n_dist = dist_normals[i]
            n_ref = ref_normals[indices[i]]
            e = 1 - abs(np.dot(n_dist, n_ref))
        errors.append(e)
    errors = np.array(errors)
    
    # 3. Aggregation
    if aggregation == "mse":
        return np.mean(errors**2)
    elif aggregation == "rms":
        return np.sqrt(np.mean(errors**2))
    elif aggregation == "hausdorff":
        return np.max(errors)
```

**Parameters:**
*   Normal estimation method for Point-to-Plane and Plane-to-Plane: Not given in the sources [S1].
*   Neighborhood size for normal estimation: Not given in the sources [S1].

**Edge Cases and Pitfalls:**
*   **Point-to-Mesh:** Metrics based on projected distances to a reconstructed mesh are considered sub-optimal because objective scores strongly depend on the selected surface reconstruction algorithm [S1]. These are excluded from this family.
*   **Scaling:** Raw error values depend on scene scale, requiring PSNR for cross-scene comparison [S1].

## Operating characteristics
*   **Complexity:** Dominated by nearest neighbor search, typically $O(N \log N)$ or $O(N)$ with spatial indexing [G].
*   **Strengths:** Directly measures 3D geometric displacement or surface deviation [S1].
*   **Limitations:** Requires associated points and is sensitive to noise if normals are not robustly estimated [G].
*   **When to use:** When assessing geometric fidelity of point clouds against a ground truth reference [S1].

## Background
Originating from full-reference quality assessment methodologies for point cloud representations, these metrics are categorized alongside projection-based methods [S1]. The specific distinction between point-to-point, point-to-plane, and plane-to-plane approaches was detailed in studies assessing the geometry of point clouds [S1].
