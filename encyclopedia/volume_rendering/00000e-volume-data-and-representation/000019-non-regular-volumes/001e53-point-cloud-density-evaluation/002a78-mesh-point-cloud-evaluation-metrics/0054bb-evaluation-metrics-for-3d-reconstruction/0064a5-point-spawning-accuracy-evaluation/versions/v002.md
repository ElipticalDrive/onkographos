# Point Spawning Accuracy Evaluation

Also called: F-score Evaluation on Tanks&Temples

## Overview
Point Spawning Accuracy Evaluation measures the geometric fidelity of reconstructed point clouds against ground truth data using the F-score metric, specifically within the context of the Tanks&Temples benchmark [S1]. It combines precision and recall to evaluate spatial alignment [S2].

## How it works
**Inputs and Outputs:**
- **Input:** A reconstructed point cloud $P$ and a ground truth point cloud $P^*$.
- **Output:** A scalar F-score value in $[0, 1]$, where 1 indicates perfect overlap [S2].

**Data Structures:**
- $P$: Set of $N$ points $\{p_1, ..., p_N\}$ in $\mathbb{R}^3$.
- $P^*$: Set of $M$ points $\{p^*_1, ..., p^*_M\}$ in $\mathbb{R}^3$.
- Threshold $\tau$: Distance tolerance for matching, set to $0.05$ meters for the Tanks&Temples benchmark [S2].

**Steps:**
1. **Compute Precision:** For each point $p \in P$, find the minimum Euclidean distance to any point in $P^*$:
   $$ d(p, P^*) = \min_{p^* \in P^*} \| p - p^* \| $$
   Precision is the fraction of points in $P$ within distance $\tau$ of $P^*$:
   $$ \text{Precision} = \frac{1}{|P|} \sum_{p \in P} \mathbb{I}(d(p, P^*) < \tau) $$
   [S2].
2. **Compute Recall:** For each point $p^* \in P^*$, find the minimum Euclidean distance to any point in $P$:
   $$ d(p^*, P) = \min_{p \in P} \| p^* - p \| $$
   Recall is the fraction of points in $P^*$ within distance $\tau$ of $P$:
   $$ \text{Recall} = \frac{1}{|P^*|} \sum_{p^* \in P^*} \mathbb{I}(d(p^*, P) < \tau) $$
   [S2].
3. **Compute F-score:** Combine Precision and Recall using the harmonic mean:
   $$ \text{F-score} = \frac{2 \times \text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}} $$
   [S2].

**Pseudocode:**
```python
import numpy as np

def point_spawning_accuracy_evaluation(P, P_star, threshold=0.05):
    """
    Computes the F-score for point cloud accuracy.
    
    Args:
        P: numpy array of shape (N, 3), reconstructed points.
        P_star: numpy array of shape (M, 3), ground truth points.
        threshold: float, distance tolerance (default 0.05).
        
    Returns:
        float: F-score.
    """
    if len(P) == 0 or len(P_star) == 0:
        return 0.0

    # Compute pairwise distances between P and P_star
    # Shape: (N, M)
    diff = P[:, np.newaxis, :] - P_star[np.newaxis, :, :]
    dists = np.sqrt(np.sum(diff**2, axis=2))
    
    # Minimum distance from each p in P to P_star
    min_dists_p = np.min(dists, axis=1)
    
    # Minimum distance from each p_star in P_star to P
    min_dists_p_star = np.min(dists.T, axis=1)
    
    # Precision: fraction of P points within threshold of P_star
    precision = np.mean(min_dists_p < threshold)
    
    # Recall: fraction of P_star points within threshold of P
    recall = np.mean(min_dists_p_star < threshold)
    
    # F-score
    if precision + recall == 0:
        return 0.0
    f_score = (2 * precision * recall) / (precision + recall)
    
    return f_score
```

**Parameters:**
- **Threshold ($\tau$):** $0.05$ meters is the standard for Tanks&Temples [S2].
- **Point Clouds:** Must be aligned in the same coordinate space [G].

**Edge Cases:**
- Empty point clouds result in division by zero; handled by returning $0.0$ [G].
- Large disparities in point cloud density can skew results if not normalized by count [G].

## Subtopics

### F-score Evaluation
The core metric combining precision and recall [S2]. It is chosen when a single scalar is needed to balance completeness (recall) and correctness (precision) [S2]. It is preferred over simple Chamfer distance when binary classification of "valid" vs "invalid" geometry is required via a threshold [S2].

## Operating characteristics
**Time and Memory Complexity:**
- **Time:** $O(N \cdot M)$ for naive pairwise distance computation, where $N$ and $M$ are the number of points in $P$ and $P^*$ respectively [G].
- **Memory:** $O(N \cdot M)$ for the full distance matrix in the naive approach [G].

**Measured Performance:**
- On the Tanks&Temples "Meetingroom" scene: COLMAP F-score = 0.335, Ours = 0.338, Ours-full = 0.365 [S1].
- On the "Barn" scene: COLMAP F-score = 0.591, Ours = 0.591, Ours-full = 0.651 [S1].
- These results indicate that Ours-full improves geometric accuracy by nearly 10% over COLMAP on the Meetingroom scene [S1].

**Strengths and Limitations:**
- **Strengths:** Not given in the sources.
- **Limitations:** Sensitive to the choice of threshold $\tau$ [S2].

**When to Use:**
- Use when evaluating geometric reconstruction quality on standard benchmarks like Tanks&Temples [S1].
- When not to use: Not given in the sources.

## Background
Originating from the Tanks&Temples benchmark [S1], this metric is used in 3D reconstruction to evaluate point cloud completeness and accuracy [S1]. It was applied in the VET method to assess the geometric impact of point spawning and cleaning strategies [S1].
