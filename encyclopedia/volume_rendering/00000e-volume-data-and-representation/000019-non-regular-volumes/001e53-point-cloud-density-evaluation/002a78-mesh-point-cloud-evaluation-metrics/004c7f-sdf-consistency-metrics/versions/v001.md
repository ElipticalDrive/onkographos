# SDF Consistency Metrics

Also called: SDF Surface Error Metric, SDF accuracy evaluation, SDF error evaluation, mesh-to-SDF consistency, surface SDF error

## Overview
SDF Consistency Metrics evaluate how closely a reconstructed mesh matches the trained Signed Distance Function (SDF) field by measuring the network's SDF output at points on the mesh surface and at its vertices [S1, unofficial]. Unlike geometric metrics that compare two meshes, this method assesses the internal consistency of the implicit representation, ensuring the extracted geometry aligns with the learned field [S1, unofficial]. It is distinct from [Cloud-to-Mesh Accuracy Metrics](10560-cloud-to-mesh-accuracy-metrics.md) which measure distance to ground truth, and [Evaluation Metrics](9899-evaluation-metrics.md) which provide a broader suite of quality indicators [S1, unofficial].

## How it works
The method computes statistical errors of the SDF values at specific locations on the mesh. It operates in two modes: surface evaluation (sampling points uniformly on the mesh) and vertex evaluation (using mesh vertices directly).

### Inputs and Outputs
*   **Inputs**:
    *   `mesh`: A triangle mesh object (e.g., `trimesh.Trimesh`) containing vertices and normals.
    *   `net`: The trained SDF network capable of evaluating $SDF(\mathbf{p})$.
    *   `training_data`: An object providing the scaling factor $R$ used during training.
    *   `n_samples`: Number of points to sample on the surface (default: 2,097,152) [S1, unofficial].
*   **Outputs**:
    *   A dictionary containing MAE, RMS, Max Absolute Error, and Standard Deviation of the SDF values.

### Data Structures
*   **Scaled Points**: Tensor of shape $(N, 3)$, dtype float32, representing points in the normalized training space.
*   **SDF Values**: Tensor of shape $(N)$, dtype float32, containing the network output $y_i$.

### Steps
1.  **Sampling**:
    *   For surface metrics: Sample $N$ points uniformly on the mesh surface. If normals are available, they are sampled as well, though only positions are used for SDF evaluation [S1, unofficial].
    *   For vertex metrics: Use the mesh vertices directly.
2.  **Scaling**: Multiply all point coordinates by the training data scaling factor $R$ to match the network's input space [S1, unofficial].
3.  **Batching**: Split the points into batches of size `batch_size` (default: 32,768) to manage GPU memory [S1, unofficial].
4.  **Evaluation**: For each batch, query the network: $y_i = \text{net.sdf}(\mathbf{p}_i)$. Concatenate all results into a single tensor $\mathbf{y}$ of size $N$ [S1, unofficial].
5.  **Metric Computation**: Calculate the four statistics defined below.

### Formulas
Let $N$ be the number of samples (surface points or vertices) and $\hat{y}_i$ be the SDF value at the $i$-th sample point [S1, unofficial].

*   **Mean Absolute Error (MAE)**:
    $$ \text{MAE} = \frac{1}{N} \sum_{i=1}^N | \hat{y}_i | $$
*   **Root Mean Square (RMS)**:
    $$ \text{RMS} = \sqrt{ \frac{1}{N} \sum_{i=1}^N \hat{y}_i^2 } $$
*   **Max Absolute Error**:
    $$ \text{MaxAbs} = \max_{i} | \hat{y}_i | $$
*   **Standard Deviation (Std)**:
    $$ \text{Std} = \sqrt{ \frac{1}{N} \sum_{i=1}^N (\hat{y}_i - \mu)^2 } $$
    where $\mu = \text{MAE}$ is the mean of the absolute values (or mean of $\hat{y}_i$ depending on implementation; the source code uses `torch.std` on the raw values, but the formula description implies centered variance. The code snippet `torch.std(all_sdf_values)` computes the standard deviation of the raw SDF values, not the absolute errors. However, the text description says "Std" generally. We follow the code's behavior for implementation but note the formula definition in the notes refers to variance around the mean $\mu$) [S1, unofficial]. *Note: The source code calculates `torch.std` on the raw SDF values, while the formula section defines Std generally. In practice, for a consistent surface, the mean SDF should be near 0.*

### Parameters
*   `batch_size`: 32,768 [S1, unofficial].
*   `n_samples`: 2,097,152 for surface metrics [S1, unofficial].

### Pseudocode
```python
import torch
import numpy as np

def compute_sdf_consistency(mesh, net, training_data, n_samples=2097152, batch_size=32768):
    """
    Compute SDF consistency metrics for a mesh against a trained network.
    
    Args:
        mesh: trimesh.Trimesh object
        net: Trained SDF network (PyTorch model)
        training_data: Object with attribute R (scaling factor)
        n_samples: Number of surface points to sample
        batch_size: Batch size for inference
        
    Returns:
        dict: MAE, RMS, MaxAbs, Std of SDF values
    """
    # 1. Sample points on surface
    # Using trimesh sample functionality
    points, _ = mesh.sample(n_samples, return_index=False)
    
    # 2. Scale points
    R = training_data.R
    points_scaled = torch.tensor(points, dtype=torch.float32, device=net.device) * R
    
    # 3. Evaluate SDF in batches
    all_sdf_values = []
    num_points = points_scaled.shape[0]
    
    with torch.no_grad():
        for i in range(0, num_points, batch_size):
            end_idx = min(i + batch_size, num_points)
            batch_points = points_scaled[i:end_idx]
            
            # Query network. Assuming net.sdf returns tensor of shape (batch, 1) or (batch,)
            # The source uses [:, 0] indicating shape (batch, 1)
            sdf_batch = net.sdf(batch_points)
            if sdf_batch.dim() > 1:
                sdf_batch = sdf_batch[:, 0]
            
            # Move to CPU and append
            all_sdf_values.append(sdf_batch.cpu())
            
    # Concatenate all results
    all_sdf_values = torch.cat(all_sdf_values, dim=0)
    
    # 4. Compute metrics
    abs_sdf = torch.abs(all_sdf_values)
    mae = torch.mean(abs_sdf).item()
    rms = torch.sqrt(torch.mean(all_sdf_values ** 2)).item()
    max_abs = torch.max(abs_sdf).item()
    std = torch.std(all_sdf_values).item()
    
    return {
        "mae_sdf": mae,
        "rms_sdf": rms,
        "max_abs_sdf": max_abs,
        "std_sdf": std
    }

def compute_sdf_consistency_vertices(mesh, net, training_data, batch_size=32768):
    """
    Compute SDF consistency metrics using mesh vertices only.
    """
    vertices = mesh.vertices
    vertices_scaled = torch.tensor(vertices, dtype=torch.float32, device=net.device) * training_data.R
    
    all_sdf_values = []
    num_vertices = vertices_scaled.shape[0]
    
    with torch.no_grad():
        for i in range(0, num_vertices, batch_size):
            end_idx = min(i + batch_size, num_vertices)
            batch_verts = vertices_scaled[i:end_idx]
            sdf_batch = net.sdf(batch_verts)
            if sdf_batch.dim() > 1:
                sdf_batch = sdf_batch[:, 0]
            all_sdf_values.append(sdf_batch.cpu())
            
    all_sdf_values = torch.cat(all_sdf_values, dim=0)
    
    abs_sdf = torch.abs(all_sdf_values)
    return {
        "mae_sdf": torch.mean(abs_sdf).item(),
        "rms_sdf": torch.sqrt(torch.mean(all_sdf_values ** 2)).item(),
        "max_abs_sdf": torch.max(abs_sdf).item(),
        "std_sdf": torch.std(all_sdf_values).item()
    }
```

### Edge Cases and Pitfalls
*   **Memory Overflow**: Large meshes with high `n_samples` may exceed GPU memory. The batching mechanism (32,768 points per batch) is critical [S1, unofficial].
*   **Scaling Mismatch**: If the mesh is not scaled by $R$ correctly, the SDF values will be incorrect, leading to misleading error metrics [S1, unofficial].
*   **Degenerate Meshes**: If the mesh has no surface area or invalid geometry, sampling may fail or return empty sets.

## Subtopics

### Surface SDF Error
Evaluates SDF at uniformly sampled points on the mesh surface. Best for assessing overall surface alignment with the implicit field. [Link](#how-it-works)

### Vertex SDF Error
Evaluates SDF at mesh vertices. Faster to compute but less representative of the entire surface geometry. [Link](#how-it-works)

## Operating characteristics
*   **Time Complexity**: $O(N)$ where $N$ is the number of samples. Dominated by the network inference time.
*   **Memory Complexity**: $O(N)$ to store the SDF values. Batching reduces peak memory usage to $O(\text{batch\_size})$.
*   **Performance**: On standard GPUs, evaluating 2 million points with a batch size of 32,768 takes a few seconds depending on network depth.
*   **Strengths**: Directly measures the quality of the implicit representation; independent of ground truth geometry.
*   **Limitations**: Does not measure geometric accuracy against a reference mesh; sensitive to network scaling and normalization.

## Background
SDF Consistency Metrics were introduced in the context of TetraSDF, a method for 3D shape reconstruction using tetrahedral grids [S1, unofficial]. The metric was developed to evaluate the fidelity of the extracted mesh to the learned SDF field, ensuring that the marching cubes extraction process accurately reflects the network's output. It is part of a broader evaluation pipeline that includes angular error and Chamfer Distance comparisons [S1, unofficial].
