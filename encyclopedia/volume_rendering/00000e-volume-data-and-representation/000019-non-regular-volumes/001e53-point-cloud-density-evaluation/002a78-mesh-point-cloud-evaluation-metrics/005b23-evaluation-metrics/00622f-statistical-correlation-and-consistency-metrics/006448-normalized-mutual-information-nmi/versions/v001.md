# Normalized Mutual Information (NMI)

Also called: Bruckner & Möller Mutual Information Method, Normalized Mutual Information (NMI) Correlation Analysis, Normalized Mutual Information Distance

## Overview
Normalized Mutual Information (NMI) is a statistical metric used to evaluate the correlation between two random variables by quantifying the amount of shared information, capturing both linear and non-linear dependencies [S1]. In the context of volume rendering and data evaluation, it serves as a distance measure between volumes (e.g., test vs. reference) or as a diagnostic tool to assess attribute independence in compressed representations [S1, S2]. It sets itself apart from simple correlation coefficients by being sensitive to non-linear relationships and by normalizing the mutual information against the individual entropies of the variables, ensuring a bounded result [S1].

## How it works
**Inputs and Outputs:**
- **Inputs:** Two discrete random variables $X$ and $Y$, represented by their joint probability mass function (pmf) $p(x, y)$ and marginal pmfs $p(x)$ and $p(y)$. In volume contexts, $X$ and $Y$ may represent distance fields of two volumes [S2] or different attribute channels (e.g., SHAC coefficients) [S1].
- **Output:** A scalar value $NMI(X, Y)$ in the range $[0, 1]$, where 1 indicates perfect correlation (identical information content) and 0 indicates no mutual correlation [S1].

**Data Structures:**
- **Joint Histogram:** A 2D array or hash map storing counts for each pair $(x, y)$, normalized to sum to 1 to form $p(x, y)$.
- **Marginal Histograms:** 1D arrays storing counts for $x$ and $y$ independently, normalized to form $p(x)$ and $p(y)$.

**Steps:**
1. **Compute Joint PMF:** Calculate $p(x, y)$ for all unique pairs $(x, y)$ present in the data.
2. **Compute Marginal PMFs:** Derive $p(x) = \sum_{y} p(x, y)$ and $p(y) = \sum_{x} p(x, y)$.
3. **Compute Mutual Information $I(X; Y)$:**
   $$ I(X; Y) = \sum_{x \in X} \sum_{y \in Y} p(x, y) \log \left( \frac{p(x, y)}{p(x)p(y)} \right) $$
   [S1]
4. **Compute Entropies $H(X)$ and $H(Y)$:**
   $$ H(X) = - \sum_{x \in X} p(x) \log p(x) $$
   $$ H(Y) = - \sum_{y \in Y} p(y) \log p(y) $$
   [S1]
5. **Compute NMI:**
   $$ NMI(X, Y) = \frac{2 \cdot I(X; Y)}{H(X) + H(Y)} $$
   [S1]

**Parameters:**
- **Logarithm Base:** The source uses $\log$ without specifying the base. In information theory, base 2 (bits) or base $e$ (nats) are standard. The ratio remains invariant to the base choice as long as it is consistent across $I$, $H(X)$, and $H(Y)$ [S1].
- **Bin Count:** For continuous volume data (like distance fields), binning is required to estimate pmfs. The source does not specify the binning strategy or number of bins [S2].

**Edge Cases and Pitfalls:**
- **Zero Probabilities:** If $p(x, y) = 0$ but $p(x) > 0$ and $p(y) > 0$, the term $p(x, y) \log(\dots)$ is 0. If $p(x) = 0$ or $p(y) = 0$, the term is undefined; these pairs should be excluded from the sum [S1].
- **Zero Entropy:** If $H(X) + H(Y) = 0$ (i.e., both variables are constant), NMI is undefined. This occurs if the volume data has no variance [S1].
- **Binning Sensitivity:** For continuous data like distance fields, the choice of bin width significantly affects the estimated mutual information [S2].

**Pseudocode:**
```python
import math

def compute_nmi(x_values, y_values):
    """
    Computes Normalized Mutual Information between two discrete variables.
    x_values, y_values: lists of discrete values (e.g., binned distance field values).
    """
    # Step 1: Compute Joint PMF
    joint_counts = {}
    for x, y in zip(x_values, y_values):
        joint_counts[(x, y)] = joint_counts.get((x, y), 0) + 1
    
    n = len(x_values)
    joint_pmf = {k: v / n for k, v in joint_counts.items()}
    
    # Step 2: Compute Marginal PMFs
    marginal_x = {}
    marginal_y = {}
    
    for (x, y), p_xy in joint_pmf.items():
        marginal_x[x] = marginal_x.get(x, 0) + p_xy
        marginal_y[y] = marginal_y.get(y, 0) + p_xy
        
    # Step 3: Compute Mutual Information I(X; Y)
    mi = 0.0
    for (x, y), p_xy in joint_pmf.items():
        p_x = marginal_x[x]
        p_y = marginal_y[y]
        
        # Guard against zero probability in denominator
        if p_x > 0 and p_y > 0:
            # Guard against zero probability in numerator (log(0) is -inf)
            if p_xy > 0:
                mi += p_xy * math.log(p_xy / (p_x * p_y))
                
    # Step 4: Compute Entropies H(X) and H(Y)
    h_x = 0.0
    for p_x in marginal_x.values():
        if p_x > 0:
            h_x -= p_x * math.log(p_x)
            
    h_y = 0.0
    for p_y in marginal_y.values():
        if p_y > 0:
            h_y -= p_y * math.log(p_y)
            
    # Step 5: Compute NMI
    denominator = h_x + h_y
    if denominator == 0:
        return 0.0 # Or undefined, depending on convention. Source implies 0 if no correlation.
        
    nmi = (2.0 * mi) / denominator
    return nmi
```

## Operating characteristics
- **Time Complexity:** $O(N)$ to compute histograms and pmfs, where $N$ is the number of samples (voxels/pixels). The summation for MI and Entropy depends on the number of unique bins $B$. In the worst case $B \approx N$, making it $O(N)$.
- **Memory Complexity:** $O(B)$ to store the joint and marginal pmfs.
- **Strengths:** Captures non-linear correlations; bounded output $[0, 1]$ allows for easy comparison across different datasets; robust to monotonic transformations [S1].
- **Limitations:** Sensitive to binning choices for continuous data; computationally expensive for high-dimensional data or fine binning; requires sufficient samples to estimate pmfs accurately [S1, S2].
- **When to use:** When assessing the independence of attributes in compressed volume data (e.g., Gaussian Splatting coefficients) or comparing the similarity of volume distance fields [S1, S2].
- **When not to use:** For simple linear correlation assessment where Pearson's coefficient suffices; when data is sparse and pmf estimation is unreliable [S1].

## Background
Normalized Mutual Information was adapted for volume evaluation by Bruckner and Möller, who proposed using mutual information between distance fields as a distance measure [S2]. It has been further applied in the context of 3D Gaussian Splatting entropy coding to evaluate the correlation between spherical harmonic coefficients and other attributes, supporting the design of factorized entropy models [S1]. In the Mip-NeRF 360 'bicycle' scene, NMI analysis revealed weak intra-correlation within SHAC coefficients and no inter-correlation between SHAC and other attributes (rotation, scaling, opacity, SHDC), justifying independent channel encoding [S1].
