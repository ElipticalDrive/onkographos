# Target-Focused Quantitative Evaluation

Also called: Region-of-Interest PSNR/SSIM/LPIPS

## Overview
Target-Focused Quantitative Evaluation computes PSNR, SSIM, and LPIPS within a fixed foreground bounding box enclosing a primary target, rather than over the entire image frame, to isolate local reconstruction fidelity from background regions. [S1]

## How it works
The method evaluates rendering fidelity by applying standard image quality metrics to a specific spatial subset of the image. [S1]

**Inputs and Outputs:**
*   **Inputs:** Reference image $I_{\text{ref}}$, rendered image $I_{\text{render}}$, and a rectangular region definition $(x, y, w, h)$ specifying the target's location and size. [S1]
*   **Outputs:** Scalar values for PSNR, SSIM, and LPIPS computed only over the pixels within the defined region. [S1]

**Data Structures:**
*   **Region Definition:** A tuple or struct containing $x, y$ (top-left pixel coordinates) and $w, h$ (width and height in pixels). [S1]
*   **Image Data:** 2D arrays of pixel values for $I_{\text{ref}}$ and $I_{\text{render}}$. [S1]

**Steps:**
1.  **Select Views:** Choose representative test views where the target is visible. [S1]
2.  **Define Region:** Identify the rectangular bounding box that encloses the primary target in the reference image. [S1]
3.  **Apply Region:** Extract the sub-images $I_{\text{ref}}^{\text{ROI}}$ and $I_{\text{render}}^{\text{ROI}}$ using the coordinates $(x, y, w, h)$ from both the reference and rendered images. [S1]
4.  **Calculate Metrics:** Compute PSNR, SSIM, and LPIPS on $I_{\text{ref}}^{\text{ROI}}$ and $I_{\text{render}}^{\text{ROI}}$ using standard full-image evaluation procedures. [S1]

**Formulas:**
The metrics are calculated using standard definitions, restricted to the ROI pixels. [S1]
*   **PSNR:**
    $$ \text{PSNR} = 10 \cdot \log_{10} \left( \frac{MAX_I^2}{\text{MSE}} \right) $$
    Where $MAX_I$ is the maximum possible pixel value, and MSE is the Mean Squared Error between the ROI pixels of the reference and rendered images. [G]
*   **SSIM:**
    $$ \text{SSIM}(x, y) = \frac{(2\mu_x\mu_y + C_1)(2\sigma_{xy} + C_2)}{(\mu_x^2 + \mu_y^2 + C_1)(\sigma_x^2 + \sigma_y^2 + C_2)} $$
    The final SSIM score is the mean of the local SSIM maps over the ROI. [G]
*   **LPIPS:**
    Computed using learned perceptual image patch similarity, restricted to the ROI patches. [S1]

**Parameters:**
*   **SSIM Window Size:** Not given in the sources. [S1]
*   **SSIM Standard Deviation:** Not given in the sources. [S1]
*   **Data Range:** Not given in the sources. [S1]

**Edge Cases and Pitfalls:**
*   **Boundary Alignment:** The bounding box must be applied identically to both reference and rendered images to ensure pixel-wise correspondence. [S1]
*   **Target Occlusion:** If the target is partially occluded or outside the frame in the rendered view, the metric may become undefined or misleading. [G]
*   **Background Influence:** Metrics are compared with whole-image metrics to examine the influence of non-target background regions on scene-level evaluation. [S1]

**Pseudocode:**
```python
def target_focused_evaluation(I_ref, I_render, x, y, w, h, MAX_I):
    # Extract ROI from both images using the bounding box
    I_ref_roi = I_ref[y:y+h, x:x+w]
    I_render_roi = I_render[y:y+h, x:x+w]

    # Compute MSE restricted to ROI pixels
    mse = mean((I_ref_roi - I_render_roi) ** 2)
    psnr = 10 * log10(MAX_I**2 / mse)

    # Compute SSIM restricted to ROI patches
    # Standard SSIM implementation is applied to the ROI sub-images.
    ssim = ssim(I_ref_roi, I_render_roi)

    # Compute LPIPS restricted to ROI patches
    # Standard LPIPS implementation is applied to the ROI sub-images.
    lpips = lpips(I_ref_roi, I_render_roi)

    return psnr, ssim, lpips
```

## Subtopics

### [ROI-Level Quantitative Evaluation](18860-roi-level-quantitative-evaluation.md)
ROI-Level Quantitative Evaluation assesses the reconstruction quality of specific, semantically important regions within a rendered volume or image, rather than evaluating the entire scene uniformly. It addresses the limitation of global metrics by isolating local features—such as vegetation crowns, structural details, or fine surface textures—to verify visibility and fidelity where they matter most. It differs from full-image assessment by focusing on representative target features and from global target-focused evaluation by applying standard perceptual metrics within fixed spatial windows rather than aggregating over logical object masks. [ROI-Level Quantitative Evaluation](18860-roi-level-quantitative-evaluation.md)

## Operating characteristics
*   **Time Complexity:** Not given in the sources. [S1]
*   **Memory Complexity:** Not given in the sources. [S1]
*   **Strengths:** Isolates quality of specific objects; prevents background uniformity from skewing metrics. [S1]
*   **Limitations:** Not an unbiased statistical sample of the whole image; results depend heavily on the subjective selection of the ROI. [S1]
*   **When to Use:** When the primary interest is the reconstruction quality of specific foreground objects or detailed textures, rather than overall scene coherence. [S1]

## Background
Introduced in the context of evaluating 3D Gaussian Splatting for real-world scene reconstruction. [S1]
