# SA-Points (Self-Augmented Pre-filtering)
Also called: SA-HashGS
## Overview
SA-Points is a physically grounded pre-filtering module used to stabilize view selection by restricting the candidate set for Fisher uncertainty evaluation [S1]. It explicitly estimates observed regions to form a stable candidate subset, which is then refined through uncertainty-aware reasoning [S1].
## How it works
Inputs: A set of candidate viewpoints and the current 3D Gaussian Splatting (3DGS) or point cloud representation of the scene [G].
Outputs: A filtered subset of candidate viewpoints with high geometric novelty [G].

Data Structures:
- Hash-encoded SA-Points: A spatial hash structure representing the current scene geometry for view selection [G].

Steps:
1. **Initialization**: Initialize the SA-Points structure from the current scene representation. SA-Points are used only for view selection and are not included in the COLMAP SfM or 3DGS initialization [S1].
2. **Geometric Filtering**: Project the current SA-Points into the 2D image plane for each candidate viewpoint to estimate observed regions [G]. Rank candidates based on geometric novelty to restrict the candidate set [S1].
3. **Uncertainty Refinement**: Apply Fisher information matrix-based uncertainty metrics only to the filtered subset of candidates [S1]. Select the viewpoint with the highest uncertainty score from this reduced set [S1].

Parameters:
- Number of training views: The method is applied in stages, adding one view every 100 epochs until reaching 20 training views [S1].
- Hash resolution: Not given in the sources.

Edge cases and pitfalls:
- Stochasticity in the training process requires repeating experiments multiple times (e.g., four times) to report average scores, as results can vary [S1].

Pseudocode:
```python
def select_next_view(candidates, current_scene, sa_points_hash):
    """
    Selects the next best view using SA-Points pre-filtering.
    """
    novelty_scores = []
    
    # Step 2: Geometric Filtering
    for view in candidates:
        # [G] Project current SA-Points to the view's image plane
        projected_points = []
        for point in sa_points_hash:
            # Standard perspective projection
            u, v = project_3d_to_2d(point, view.camera_params)
            if is_in_fov(u, v, view.image_dims):
                projected_points.append((u, v))
        
        # [G] Calculate novelty based on coverage/discrepancy
        score = compute_novelty(projected_points, view)
        novelty_scores.append((view, score))
    
    # Step 3: Filtering
    # Sort by novelty score descending
    novelty_scores.sort(key=lambda x: x[1], reverse=True)
    
    # Select top-k candidates (k not specified in sources, typically small subset)
    k = 5  # [G] Typical value for NBV candidate reduction
    filtered_candidates = [item[0] for item in novelty_scores[:k]]
    
    # Step 4: Uncertainty Refinement
    best_view = None
    best_uncertainty = float('-inf')
    
    for view in filtered_candidates:
        # [G] Calculate Fisher uncertainty for the filtered view
        uncertainty = compute_fisher_uncertainty(view, current_scene)
        
        if uncertainty > best_uncertainty:
            best_uncertainty = uncertainty
            best_view = view
            
    return best_view
```
## Subtopics

### [Physically Grounded View Selection](20890-physically-grounded-view-selection.md)
A strategy that uses SA-Points to filter candidates based on geometric dissimilarity before ranking by uncertainty. Choose this when computational cost of exhaustive uncertainty evaluation is prohibitive.

## Operating characteristics
Time complexity: Reduced compared to exhaustive search because uncertainty is only evaluated on a filtered subset of candidates [S1].
Memory complexity: Not given in the sources. SA-Points are used only for view selection and are not included in the COLMAP SfM or 3DGS initialization [S1].
Measured performance: SA-HashGS and SA-ResGS variants show competitive PSNR and SSIM scores on NeRF-Synthetic and Mip-NeRF 360 datasets compared to other active view selection methods [S1].
Strengths: Stabilizes view selection by restricting the candidate set for Fisher uncertainty evaluation [S1].
Limitations: The method requires a stable initial scene representation to guide the pre-filtering, and stochasticity in training necessitates multiple experimental repeats for reliable evaluation [S1].
## Background
Origin: SA-Points was introduced in the SA-ResGS paper (2024) as a self-augmented residual 3D Gaussian Splatting method for Next Best View selection [S1].
History: It was introduced to stabilize active view selection for 3D Gaussian Splatting [S1].
Usage: Used in active 3D reconstruction pipelines, particularly those involving 3D Gaussian Splatting, to optimize the selection of training viewpoints [S1].
