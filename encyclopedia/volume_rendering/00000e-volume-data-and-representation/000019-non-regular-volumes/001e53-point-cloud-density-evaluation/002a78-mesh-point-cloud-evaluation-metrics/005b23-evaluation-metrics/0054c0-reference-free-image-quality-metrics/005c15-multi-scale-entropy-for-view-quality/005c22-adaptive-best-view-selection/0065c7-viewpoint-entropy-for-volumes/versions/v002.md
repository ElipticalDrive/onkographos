# Viewpoint Entropy for Volumes

Also called: Feature-driven viewpoint entropy, Weighted sum of viewpoint entropies, map of viewpoint entropy

## Overview
Viewpoint Entropy for Volumes is a method to find the optimal viewpoint for volumetric data by evaluating the optimality of arrangements of decomposed feature interval volumes (IVs) in 2D projections [S1, book]. It sets itself apart from voxel-based balance metrics (e.g., Bordoloi et al. [4]) by focusing on the well-balanced visibility of feature subvolumes rather than individual voxel contributions [S1, book]. The method calculates entropies for combinations of decomposed feature IVs and finds a global compromise via a weighted sum [S1, book].

## How it works
**Inputs:**
- A volume dataset decomposed into feature Interval Volumes (IVs) using a level-set graph [S1, book].
- A specific combination of IVs constituting an isosurface join or split (identified via saddle critical points in the level-set graph) [S1, book].
- An opacity transfer function for direct volume rendering [S1, book].

**Outputs:**
- A scalar entropy value $E$ representing the viewpoint optimality for the current combination of IVs [S1, book].
- A map of entropy values over the viewing sphere [S1, book].

**Data Structures:**
- **Level-Set Graph:** Nodes represent critical points (minima, maxima, saddles); edges represent connections between them [S1, book]. Links in the source figures denote combinations of IVs for evaluation [S1, book].
- **Interval Volume (IV):** A subvolume defined by scalar field intervals [S1, book]. Each IV has a set of faces [S1, book].
- **Weight Vector:** $\lambda_i$ for each IV $i$, derived from the opacity transfer function [S1, book].

**Parameters:**
- $\lambda_i$: Weight value for the $i$-th IV. Calculated using an opacity transfer function [S1, book].
- $n$: Number of IVs in the combination [S1, book].
- $L$: Normalization factor, $L = \sum_{i=1}^{n} \lambda_i$ [S1, book].
- **Color Mapping:** Warm colors represent higher entropy regions in the entropy map [S1, book].

**Steps:**
1. **Identify Combinations:** Identify combinations of decomposed feature IVs that constitute isosurface joins or splits of specific types, based on saddle critical points in the level-set graph [S1, book].
2. **Calculate Individual Entropies:** For each IV $i$ in the combination:
   - Identify the visible faces of the IV from the current viewpoint [S1, book].
   - If faces are partially occluded by other IVs in the combination, assume the occluded regions are painted in the background color (treated as background area $A_0$) [S1, book].
   - Calculate the individual viewpoint entropy $E_i$ using the surface-based formula (Eq. 1 in source) [S1, book].
3. **Calculate Global Entropy:** Compute the weighted sum of the individual entropies:
   $$ E = \sum_{i=1}^{n} \frac{\lambda_i}{L} E_i $$
   where $L = \sum_{i=1}^{n} \lambda_i$ [S1, book].
4. **Update Viewpoint:** Calculate the sum of the viewpoint optimality values for the remaining components to update the position of the optimal viewpoint each time an outer component is peeled off [S1, book].

**Edge Cases and Pitfalls:**
- **Occlusion:** The method explicitly handles occlusion by treating occluded regions as background color to avoid undesirable occlusions between IVs in the combination [S1, book].
- **Degenerate Input:** If the opacity transfer function yields zero weights for all IVs, the normalization factor $L$ becomes zero, requiring a guard [G].

## Operating characteristics
- **Time Complexity:** Not given in the sources [S1, book].
- **Memory Complexity:** Not given in the sources [S1, book].
- **Performance:** The method allows for interactive and automatic traversal of volumetric inner structures [S1, book]. It updates the optimal viewpoint smoothly as outer components are peeled off [S1, book].
- **Strengths:** Effectively presents inner structures of volumes (e.g., sheep heart dataset) by balancing the visibility of decomposed components [S1, book].
- **Limitations:** Relies on the accuracy of the interval volume decomposition and the level-set graph construction [S1, book].
- **When to use:** When the goal is to preview volume decomposition and find viewpoints that best reveal nested inner structures [S1, book].
- **When not to use:** When voxel-level balance is preferred over feature subvolume arrangement [S1, book].

## Background
- **Origin:** The method was introduced by Takahashi et al. [S1, book]. It is described in the chapter "Previewing Volume Decomposition Through Optimal Viewpoints" [S1, book].
- **History:** It was implemented in a previous formulation of viewpoint entropy for volumes [29] [S1, book]. It was developed to address the problem of finding optimal viewpoints for volumes with multi-layered inner structures [S1, book].
- **Usage:** Used in an interface called "interval volume decomposer" for systematically decomposing volume datasets and previewing them [S1, book].
