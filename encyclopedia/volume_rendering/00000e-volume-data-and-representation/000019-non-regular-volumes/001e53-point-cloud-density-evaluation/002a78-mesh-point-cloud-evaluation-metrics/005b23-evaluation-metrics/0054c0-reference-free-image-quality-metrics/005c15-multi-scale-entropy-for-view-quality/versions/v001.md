# Multi-Scale Entropy for View Quality

Also called: Multi resolution entropy, Wavelet entropy

## Overview
Multi-Scale Entropy (MSE) is a reference-free metric that quantifies the visual information content of a rendered volume image by analyzing the Shannon entropy of wavelet coefficients across multiple resolution levels [S1]. Unlike standard histogram-based entropy, which is insensitive to pixel spatial correlation, MSE captures structural information and local correlations, making it suitable for evaluating the quality of volume rendering views [S1]. It serves as the core evaluation function for adaptive best-view selection algorithms in volume visualization [S1].

## How it works
**Inputs:** A rendered RGB image $X$ of size $W \times H$, where each pixel is encoded in 8 bits per color channel [S1].
**Outputs:** A scalar value $H_W(X)$ representing the multi-scale entropy of the image [S1].

**Data Structures:**
The method operates on the wavelet decomposition of the image. The image is decomposed into $L$ levels. At each level $l$, there are $N_l$ wavelet coefficients for each color channel (Red, Green, Blue) [S1].

**Parameters:**
*   **Wavelet Transform:** Haar wavelet transform [S1].
*   **Decomposition Levels ($L$):** Typically 4 levels are sufficient [S1].
*   **Bit Depth:** 8 bits per color channel [S1].
*   **Logarithm Base:** 2 [S1].

**Algorithm Steps:**
1.  **Decomposition:** Apply the Haar wavelet transform to the input RGB image $X$ to obtain wavelet coefficients $w_{l,k}$ for each color channel, where $l \in \{1, \dots, L\}$ is the resolution level and $k \in \{0, \dots, N_l-1\}$ is the coefficient index [S1].
2.  **Histogram Construction:** For each level $l$ and each color channel $c \in \{R, G, B\}$, compute the histogram of the wavelet coefficients. Let $p(w_{l,k}^{(c)})$ be the relative frequency (probability) of a specific coefficient value $k$ at level $l$ in channel $c$ [S1].
3.  **Channel Entropy Calculation:** Calculate the entropy contribution $h_{RGB}(w_{l,k}^{(c)})$ for each coefficient value using the Shannon entropy formula:
    $$ h_{RGB}(w_{l,k}^{(c)}) = - p(w_{l,k}^{(c)}) \log_2 p(w_{l,k}^{(c)}) $$
    By convention, $0 \log_2 0 = 0$ [S1].
4.  **Summation:** Sum the entropy contributions across all coefficient values $k$ at each level $l$, and then sum across all levels $l$ and all color channels. The total Multi-Scale Entropy $H_W(X)$ is defined as [S1]:
    $$ H_W(X) = - \sum_{l=1}^{L} \sum_{k=0}^{N_l-1} \sum_{c \in \{R,G,B\}} p(w_{l,k}^{(c)}) \log_2 p(w_{l,k}^{(c)}) $$
    Note: The source formula [S1] writes $\sum_{k=0}^{N_l} h_{RGB}(w_{l,k})$. Given $N_l$ is the number of coefficients, the index $k$ typically runs from $0$ to $N_l-1$. The term $h_{RGB}$ aggregates the channel contributions.

**Edge Cases and Pitfalls:**
*   **Resolution:** The source notes that $256 \times 256$ resolution is sufficient for best view computation, yielding identical results to $512 \times 512$ [S1]. Using lower resolutions may lose structural detail; higher resolutions increase computation without benefit for view selection [S1].
*   **Degenerate Input:** If all pixels have the same value, entropy is 0 [S1].
*   **Boundary Conditions:** The Haar transform requires handling image boundaries. The source does not specify the padding strategy (e.g., zero, reflection, periodic). Implementers must choose a consistent strategy [G].

## Subtopics

### Adaptive Best View Selection
An algorithm that efficiently selects the viewpoint with the highest Multi-Scale Entropy value, avoiding a brute-force search over all possible viewpoints [S1]. It starts from a minimal input consisting of a classified model (via a transfer function) and a region of interest [S1]. While a brute-force analysis of a dense set of views takes roughly half a minute on a QuadCore PC with 8GB memory and a GF 8800 card, the adaptive method aims to complete within the dataset loading time (several seconds) [S1]. The method generates a set of representative views and an exploration path for users to choose the most suggestive view [S1].

## Operating characteristics
*   **Time Complexity:** The brute-force approach is slow, taking ~30 seconds for a dense set of views on the specified hardware [S1]. The adaptive method reduces this to the order of dataset loading time (seconds) [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** On a QuadCore PC with 8GB memory and GF 8800 card, brute-force analysis takes ~30 seconds [S1].
*   **Strengths:** Captures structural information and pixel correlation better than standard histogram entropy [S1]. Efficient enough for interactive use when combined with adaptive search [S1].
*   **Limitations:** Brute-force search is too slow for real-time interaction [S1]. Performance depends on dataset dimension, number of analyzed views, and the transfer function (which determines the number of processed voxels) [S1].
*   **When to use:** When selecting representative views for volume models where structural detail is important and computational resources are limited [S1].
*   **When not to use:** When exhaustive search is feasible and high precision is required over a very small set of views, or when real-time feedback on every single viewpoint change is needed without adaptive sampling [S1].

## Background
The metric was proposed by P.-P. Vázquez, E. Monclús, and Navazo in the paper "Representative Views and Paths for Volume Models" [S1]. It builds upon the concept of multiresolution entropy introduced by Starck et al. [S1]. The method was validated through user studies showing that Multi-Scale Entropy is a good approximation to the amount of information revealed by illumination [S1]. It is primarily used in medical volume visualization to help users find adequate views efficiently [S1].
