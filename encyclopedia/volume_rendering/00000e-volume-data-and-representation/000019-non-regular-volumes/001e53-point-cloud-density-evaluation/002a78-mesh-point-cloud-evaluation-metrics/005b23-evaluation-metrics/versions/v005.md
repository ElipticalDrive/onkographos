# Evaluation Metrics

Also called: Image Quality Metrics, PSNR and SSIM Calculation, Rendering Quality Assessment, Rendering Quality Metrics

## Overview
Evaluation Metrics computes quantitative assessments of rendering and reconstruction quality by comparing generated outputs against ground truth data [S3, unofficial][S5]. It addresses the problem of objectively measuring fidelity in 3D graphics, covering data-level, image-level, and geometric-level errors [S3, unofficial][S4]. It differs from [Cloud-to-Mesh Accuracy Metrics](10560-cloud-to-mesh-accuracy-metrics.md) by focusing on image and volume data metrics (PSNR, LPIPS) rather than purely geometric point-cloud distances, though it shares the Chamfer Distance metric for isosurface evaluation [S1][S3, unofficial].

## How it works
The method calculates three primary metrics: Peak Signal-to-Noise Ratio (PSNR), Learned Perceptual Image Patch Similarity (LPIPS), and Chamfer Distance (CD) [S3, unofficial]. PSNR and SSIM assess image-level fidelity, while LPIPS measures perceptual similarity using deep features, and CD measures geometric alignment of isosurfaces [S3, unofficial][S5].

**Inputs and Outputs:**
*   **Inputs:** Reconstructed/Rendered image or volume ($I_{rec}$), Ground Truth image or volume ($I_{gt}$) [S3, unofficial][S4]. For geometric metrics, two point clouds or meshes representing the reconstructed and ground truth surfaces [S1].
*   **Outputs:** Scalar scores for PSNR, SSIM, LPIPS, and/or CD [S3, unofficial].

**Data Structures:**
*   Images: Tensor normalized to $[0, 1]$ [S2].
*   Volumes: 3D grid or implicit representation [S4].
*   Points/Meshes: Set of 3D coordinates or triangle lists [S1].

**Formulas and Steps:**

1.  **PSNR Calculation:**
    Compute the Mean Squared Error (MSE) between $I_{rec}$ and $I_{gt}$:
    $$ MSE = \frac{1}{N} \sum_{i=1}^{N} (I_{rec}(i) - I_{gt}(i))^2 $$
    where $N$ is the total number of pixels/voxels [S5].
    Calculate PSNR:
    $$ PSNR = 10 \cdot \log_{10} \left( \frac{data\_range^2}{MSE} \right) $$
    where $data\_range$ is the maximum pixel value (typically 1.0 for normalized data) [S2]. Higher PSNR indicates superior quality [S3, unofficial].

2.  **LPIPS Calculation:**
    Extract deep features from both images using a pre-trained convolutional neural network (AlexNet) [S3, unofficial]. Compute the weighted $L_2$ distance between normalized feature maps across layers [G]. Lower LPIPS indicates superior quality [S3, unofficial].

3.  **Chamfer Distance (CD) Calculation:**
    For isosurfaces extracted from decompressed and ground truth volumes, or for mesh/point cloud comparison [S3, unofficial][S4]. Sample $10^6$ points from the reconstructed surface ($P_{rec}$) and apply face-to-point projection [S1]. Compute the minimum distance from each point in one set to the other set using the $L_2$ norm:
    $$ CD = \frac{1}{N} \sum_{p \in P_{rec}} \min_{q \in P_{gt}} \| p - q \|_2^2 + \frac{1}{M} \sum_{q \in P_{gt}} \min_{p \in P_{rec}} \| q - p \|_2^2 $$
    Note: Some implementations use squared CD for stability [S1]. Lower CD indicates superior quality [S3, unofficial]. Reported CD values are often scaled by $10^5$ for readability [S1].

4.  **F1 Score Calculation (for Mesh/Point Cloud):**
    Compute precision and recall based on a distance threshold $\tau$ (typically 0.003) [S1].
    $$ Precision = \frac{|\{p \in P_{rec} : \min_{q \in P_{gt}} \| p - q \|_2 \le \tau\}|}{|P_{rec}|} $$
    $$ Recall = \frac{|\{q \in P_{gt} : \min_{p \in P_{rec}} \| q - p \|_2 \le \tau\}|}{|P_{gt}|} $$
    $$ F1 = 2 \cdot \frac{Precision \cdot Recall}{Precision + Recall} $$
    Higher F1 indicates better shape capture [S1].

5.  **Normal Consistency (NC):**
    Compare surface normals of projected points. Average the dot product of corresponding normals after alignment [S1].

**Parameters:**
*   `channel_axis`: Set to -1 for RGB channels in the last dimension [S2].
*   `data_range`: Set to 1.0 for normalized $[0,1]$ image data [S2].
*   `F1_threshold`: Set to 0.003 to ensure sensitivity to fine details [S1].
*   `CD_scale`: Factor of $10^5$ for reporting [S1].
*   `network`: AlexNet for LPIPS feature extraction [S3, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import torchvision.models as models

def calculate_psnr(rec_img, gt_img, data_range=1.0):
    """
    Calculate PSNR between reconstructed and ground truth images.
    rec_img, gt_img: Tensor of shape (..., C) or (B, H, W, C), values in [0, 1].
    """
    assert rec_img.shape == gt_img.shape
    mse = torch.mean((rec_img - gt_img) ** 2)
    if mse == 0:
        return float('inf')
    return 10 * torch.log10((data_range ** 2) / mse)

def calculate_lpips(rec_img, gt_img):
    """
    Calculate LPIPS using AlexNet features.
    rec_img, gt_img: Tensor of shape (B, H, W, C) or (H, W, C), values in [0, 1].
    """
    # Load pre-trained AlexNet features [G]
    alexnet = models.alexnet(pretrained=True).features.eval()
    # Extract features from standard LPIPS layers [G]
    layers = [0, 3, 8, 15, 22]
    feats_rec = []
    feats_gt = []
    x = rec_img
    y = gt_img
    for i, layer in enumerate(alexnet.children()):
        x = layer(x)
        y = layer(y)
        if i in layers:
            feats_rec.append(x)
            feats_gt.append(y)
    # Compute weighted L2 distance between normalized features [G]
    weights = [1/8, 1/16, 1/8, 1/4, 1/2]
    lpips_score = 0.0
    for f_r, f_g, w in zip(feats_rec, feats_gt, weights):
        norm_r = F.normalize(f_r, p=2, dim=1)
        norm_g = F.normalize(f_g, p=2, dim=1)
        lpips_score += w * torch.mean((norm_r - norm_g) ** 2)
    return lpips_score

def calculate_chamfer_distance(points_rec, points_gt):
    """
    Calculate Chamfer Distance between two point clouds.
    points_rec, points_gt: Tensor of shape (N, 3) and (M, 3).
    """
    dist_matrix = torch.cdist(points_rec, points_gt, p=2)
    min_dist_rec_to_gt = torch.min(dist_matrix, dim=1)[0]
    min_dist_gt_to_rec = torch.min(dist_matrix, dim=0)[0]
    cd_rec = torch.mean(min_dist_rec_to_gt ** 2)
    cd_gt = torch.mean(min_dist_gt_to_rec ** 2)
    return cd_rec + cd_gt

def calculate_f1_score(points_rec, points_gt, threshold=0.003):
    """
    Calculate F1 score for mesh/point cloud alignment.
    """
    dist_matrix = torch.cdist(points_rec, points_gt, p=2)
    precision = torch.mean((torch.min(dist_matrix, dim=1)[0] <= threshold).float())
    recall = torch.mean((torch.min(dist_matrix, dim=0)[0] <= threshold).float())
    if precision + recall == 0:
        return 0.0
    return 2 * (precision * recall) / (precision + recall)
```

## Subtopics

### Real-world Dataset Evaluation
Evaluates methods on real-world scenes from BlendedMVS and Bag of Chips datasets, which provide images and depth maps reconstructed by MVS methods or RGBD cameras [S6]. The BlendedMVS test set consists of the last ten images, and the Bag of Chips test set consists of the last 1/5 of the images [S6]. Performance degrades on real-world data due to varying exposures, rough geometry, and insufficient background for ambient illumination reconstruction [S6].

### Pearson's Correlation Coefficient (PCC)
An image fidelity score used to evaluate the quality of 3D reconstructions and novel 2D views [S7, unofficial]. It measures the linear correlation between the reconstructed and ground truth pixel values [S7, unofficial].

### Differentiable Vectorization Benchmark
A benchmark to evaluate multi-scale methods by recovering positions of 2D disks with known colors from a reference image, testing long-range feature matching with sparse gradients [S8]. Image Resolution is 128 × 128 [S8]. Disks count $n$ is [4, 16, 32, 64, 256] [S8]. Spatial scale parameters are set to $\alpha = [1, 5, 15]$ and $\sigma = [1, 5, 15, 45]$ [S8]. For $n=256$ disks, the method achieved PSNR 21.57 and SSIM 0.90, compared to GP PSNR 9.60/SSIM 0.34, MS-SSIM PSNR 9.83/SSIM 0.35, and LPIPS PSNR 15.2/SSIM 0.76 [S8]. The method uses Wasserstein distance on histograms, while other methods measure L2 error between features [S8].

### Pixel Accuracy
Computes the proportion of correctly classified pixels over the total number of pixels [S9]. It is a simple and intuitive measure but might not capture the overall performance accurately, especially when dealing with imbalanced classes [S9].

## Operating characteristics
*   **Time and Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Storage footprint is reported in kilobytes (KB), accounting for intrinsic parameters, network weights, and topological overheads, stored with identical zip compression across methods [S5].
*   **Strengths and Limitations:** PSNR and SSIM assess image-level fidelity and structural details [S5]. LPIPS measures perceptual similarity using deep features [S3, unofficial]. CD measures geometric alignment of isosurfaces [S3, unofficial][S4]. Performance degrades on real-world data due to varying exposures, rough geometry, and insufficient background [S6].
*   **When to use:** Use PSNR/SSIM for data-level and structural fidelity assessment [S5]. Use LPIPS for perceptual quality assessment [S3, unofficial]. Use CD for geometric accuracy of isosurfaces or meshes [S3, unofficial][S4]. Use PCC for linear correlation analysis [S7, unofficial].

## Background
PSNR and SSIM are standard image quality metrics [S5]. LPIPS was introduced using AlexNet for feature extraction [S3, unofficial]. Chamfer Distance is a standard geometric metric for isosurfaces [S3, unofficial][S4]. The metrics are applied in neural rendering, volume compression, and 3D reconstruction pipelines [S1][S3, unofficial][S4, S5].
