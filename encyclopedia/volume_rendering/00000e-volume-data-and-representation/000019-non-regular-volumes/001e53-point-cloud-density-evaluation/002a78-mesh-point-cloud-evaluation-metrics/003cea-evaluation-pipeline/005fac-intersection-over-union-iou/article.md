# Intersection over Union (IoU)
Also called: Intersection over Union (IoU) Calculation

## Overview
Intersection over Union (IoU) evaluates the spatial alignment between predicted and ground-truth masks by aggregating confusion matrix counts [S2, unofficial]. It operates on discrete masks or voxel grids rather than continuous surfaces, making it sensitive to spatial overlap errors in volume rendering evaluation pipelines [S2, unofficial][S3, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** Counts of true positives ($tp$), false positives ($fp$), true negatives ($tn$), and false negatives ($fn$) derived from comparing predictions against ground truth [S2, unofficial].
- **Output:** A scalar value $IoU \in [0, 1]$, where 1 indicates perfect overlap [S2, unofficial].

**Data Structures:**
- The method relies on four integer counters: $tp, fp, tn, fn$ [S2, unofficial]. These are typically aggregated across a dataset or batch [S2, unofficial].

**Steps:**
1. Generate a predicted mask and a ground-truth mask by min-max normalizing rendered depth maps and thresholding at 0.5 [S2, unofficial][S3, unofficial].
2. Classify each spatial element (pixel or voxel) into one of four categories: $tp$ (predicted occupied, ground-truth occupied), $fp$ (predicted occupied, ground-truth empty), $tn$ (predicted empty, ground-truth empty), and $fn$ (predicted empty, ground-truth occupied) [S2, unofficial].
3. Aggregate the counts across the evaluation set [S2, unofficial].
4. Compute the ratio using the aggregated counts [S2, unofficial].

**Formula:**
$$ IoU = \frac{tp}{tp + fp + fn} $$
The denominator excludes $tn$ to focus on occupied space alignment [S2, unofficial].

**Pseudocode:**
> **Unverified code.** The code below did not pass a test run against a reference implementation, or no test fits it, so it may contain errors.

```python
def compute_iou(tp: int, fp: int, fn: int) -> float:
    """Compute Intersection over Union from confusion matrix counts."""
    denominator = tp + fp + fn
    if denominator == 0:
        return 1.0  # [G] Standard convention for empty sets.
    return tp / denominator
```

**Parameters:**
- Threshold: 0.5 is used for binarizing depth maps or opacity values into masks [S2, unofficial][S3, unofficial].

**Edge Cases and Pitfalls:**
- **Empty Sets:** If both prediction and ground truth are empty ($tp=0, fp=0, fn=0$), the denominator is zero [G].
- **Precision:** IoU does not distinguish between different sources of error, such as floaters versus missing geometry [S2, unofficial].

## Subtopics

### [Jaccard Index Evaluation](17997-jaccard-index-evaluation.md)
Evaluates voxel segmentation quality by computing the Jaccard index between target and predicted voxel grids. It measures spatial overlap between binary or multi-class voxel sets and requires exact voxel-wise agreement, serving as a stricter alternative to correlation-based metrics.

### Silhouette IoU Metric
Computes IoU between the predicted mask (generated by thresholding pixel opacity at 0.5) and the un-eroded ground-truth mask [S3, unofficial]. It quantifies misalignment between renders and ground truth and is typically reported only when test-time camera refinement is applied [S3, unofficial].

### Alpha IoU
A soft IoU variant measuring agreement between predicted foreground alpha and ground-truth mask [S4, unofficial]. It computes the ratio of summed minimums to summed maximums over all pixels: $IoU(\hat{A}, M) = \frac{\sum_v \min(\hat{A}(v), M(v))}{\sum_v \max(\hat{A}(v), M(v))}$, where $\hat{A}(v)$ is predicted alpha and $M(v)$ is the ground-truth mask at pixel $v$ [S4, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Strengths:** Measures overall alignment between predicted and ground-truth masks [S2, unofficial].
- **Limitations:** Does not distinguish between different sources of error, such as floaters versus missing geometry [S2, unofficial].
- **When to use:** Evaluating binary segmentation quality of rendered depth maps or voxel grids [S2, unofficial].
- **When not to use:** When detailed error source analysis is required; use alongside True Positive Rate (TPR), False Positive Rate (FPR), and False Discovery Rate (FDR) [S2, unofficial].

## Background
In volume rendering and neural view synthesis, IoU assesses the geometric accuracy of implicit and primitive-based representations by comparing thresholded rendered depth maps against ground-truth masks [S2, unofficial]. It is applied in space-focused evaluation pipelines to quantify reconstruction alignment [S2, unofficial].
