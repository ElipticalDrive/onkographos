# Evaluation Pipeline

Also called: Reconstruction Evaluation, Visible Surface Evaluation

## Overview
This pipeline computes Chamfer distance ($C_{\ell1}$), intersection-over-union (IoU), normal consistency (NC), and F-score on reconstructed surfaces visible in the input color/depth streams [S1]. It differs from standard mesh evaluation by explicitly culling occluded or unseen geometry to prevent error inflation from regions where the network output is unpredictable or where ground truth contains hidden surfaces [S1]. It builds on [Mesh/Point Cloud Evaluation Metrics](4797-mesh-point-cloud-evaluation-metrics.md) but restricts the comparison domain to the viewing frusta of the input cameras [S1].

## How it works
**Inputs:**
- Reconstructed mesh $M_{rec}$ [S1].
- Ground truth mesh $M_{gt}$ [S1].
- Camera poses and intrinsics for all input frames [S1].
- Input color/depth streams [S1].

**Outputs:**
- Scalar metrics: $C_{\ell1}$, IoU, NC, F-score [S1].

**Data Structures:**
- Point cloud $S_{rec}$: Set of 3D points sampled from $M_{rec}$ [G].
- Point cloud $S_{gt}$: Set of 3D points sampled from $M_{gt}$ [G].
- Voxel grid $V_{rec}$: Binary occupancy grid for $M_{rec}$ [G].

**Parameters:**
- Max edge length for subdivision: $L_{max} = 1.5$ cm [S1].
- Sampling density: $\rho = 1$ point/cm² [S1].
- Voxel edge length: $L_{vox} = 5$ cm [S1].
- F-score threshold: $\tau = 5$ cm [S1].

**Steps:**
1. **Mesh Subdivision**: Subdivide all triangles in $M_{rec}$ until every edge length is strictly less than $L_{max} = 1.5$ cm [S1].
2. **Visibility Detection**: Detect visible vertices using the ground truth camera trajectory [S1]. Cull triangles with zero visible vertices (occluded or outside viewing frusta) to avoid error computation in unseen regions [S1].
3. **Point Cloud Sampling**: Sample the culled geometry of $M_{rec}$ at a density of $\rho = 1$ point/cm² to form point cloud $S_{rec}$ [S1]. Similarly, sample points from the corresponding visible regions of $M_{gt}$ to form $S_{gt}$ [S1].
4. **Chamfer Distance and Normal Consistency**: Compute $C_{\ell1}$ between $S_{rec}$ and $S_{gt}$ [S1]. Compute NC based on cosine similarity between the normal at each point in $S_{rec}$ and the nearest point's normal in $S_{gt}$ [S1].
5. **IoU and F-score**: Voxelize $M_{rec}$ into a binary grid with edge length $L_{vox} = 5$ cm [S1]. Compute IoU on the resulting voxel sets [S1]. Compute F-score using a distance threshold of $\tau = 5$ cm [S1].

**Pitfalls:**
- **Occlusion Handling**: Failing to cull occluded triangles inflates error metrics because the network cannot predict geometry it never saw, and GT may contain hidden surfaces [S1].

## Subtopics

### [Uniform Sampling Evaluation](9611-uniform-sampling-evaluation.md)
A geometric evaluation protocol for surface reconstruction that eliminates vertex-density bias by uniformly sampling a fixed number of points from the reconstructed mesh surface within the ground truth crop volume. It ensures a strictly fair geometric comparison by decoupling the evaluation density from the mesh tessellation quality. Unlike legacy vertex-based metrics, it prevents scores from being artificially inflated by denser tessellations. It is primarily used for evaluating Gaussian-based surface reconstruction on Tanks and Temples and structured scan datasets.

## Operating characteristics
- **Time and Memory Complexity**: Not given in the sources.
- **Measured Performance**: Not given in the sources.
- **Scaling**: Not given in the sources.
- **Strengths**: Provides a fair evaluation of reconstruction quality by ignoring regions the model could not possibly have reconstructed correctly (occlusions/unseen areas) [S1].
- **Limitations**: Metrics are sensitive to the visibility detection algorithm. If visibility is incorrectly determined, valid geometry may be culled or invalid geometry retained [S1]. The choice of subdivision and sampling parameters affects precision [S1].
- **When to use**: Evaluating RGB-D reconstruction methods where input views are limited and occlusions are prevalent [S1].
- **When not to use**: When evaluating scene completion or methods that explicitly predict hidden geometry [S1].

## Background
The pipeline was introduced in the context of Neural RGB-D Surface Reconstruction [S1]. It addresses the limitation of standard mesh metrics by acknowledging that reconstruction methods are typically trained only on visible geometry [S1]. By restricting evaluation to the viewing frusta of input images, it provides a more meaningful assessment of the method's ability to reconstruct observed surfaces [S1].
