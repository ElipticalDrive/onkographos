# Mesh/Point Cloud Evaluation Metrics

Also called: F-score, F1 score, Mesh Quality Evaluation Metrics

## Overview
Mesh/Point Cloud Evaluation Metrics provides a comprehensive suite of geometric and photometric measures to quantify the fidelity of reconstructed 3D surfaces and point clouds against ground truth data [S2, unofficial][S3, unofficial][S5]. It addresses the problem of objectively measuring reconstruction quality by computing distances, consistency, and shape properties, covering data-level, image-level, and geometric-level errors [S3, unofficial]. Unlike its sibling [Evaluation Pipeline](9358-evaluation-pipeline.md), which orchestrates the workflow and culls occluded geometry, this method defines the specific mathematical functions for quality calculation [S2, unofficial][S5]. It differs from [Cloud-to-Mesh Accuracy Metrics](10560-cloud-to-mesh-accuracy-metrics.md) by focusing on symmetric point-cloud distances and broader quality indicators (including image metrics like PSNR) rather than purely orthogonal cloud-to-mesh displacements [S1, S3, unofficial].

## How it works
The method evaluates geometric consistency under a distance threshold and computes comprehensive mesh quality metrics including Chamfer Distance (CD), Normal Consistency (NC), F1 score, Edge Chamfer Distance (ECD), Edge F1 (EF1), aspect ratio, radius ratio, angle regularity, and self-intersection percentage [S2, unofficial].

### Inputs and Outputs
**Inputs:**
*   Predicted mesh or point cloud ($P_{pred}$).
*   Ground truth mesh or point cloud ($P_{gt}$).
*   Optional: Normal vectors for $P_{pred}$ and $P_{gt}$.
*   Optional: Image streams for photometric metrics (PSNR).

**Outputs:**
*   Scalar metrics: CD, NC, F1, ECD, EF1, Aspect Ratios, Self-intersection %, PSNR.

### Data Structures
*   **Point Clouds:** Arrays of shape $(N, 3)$ containing vertex coordinates.
*   **KDTree:** Spatial index structure built on point clouds for nearest-neighbor queries.
*   **Normals:** Arrays of shape $(N, 3)$ containing unit normal vectors.

### Parameters
*   `f1_threshold`: Float, default 0.001. Distance threshold for F1 recall/precision calculation [S2, unofficial].
*   `ef1_threshold`: Float, default 0.005. Distance threshold for edge F1 calculation [S2, unofficial].
*   `ef1_radius`: Float, default 0.004. Radius for edge point detection [S2, unofficial].
*   `ef1_dotproduct_threshold`: Float, default 0.2. Dot product threshold for edge classification [S2, unofficial].
*   `num_points`: Int, default 100,000. Number of points sampled for evaluation if inputs are dense meshes [S2, unofficial].

### Formulas
1.  **Chamfer Distance (CD):** Symmetric average closest-point distance [S1, unofficial][S5].
    $$ CD(P_{pred}, P_{gt}) = \frac{1}{|P_{pred}|} \sum_{p \in P_{pred}} \min_{q \in P_{gt}} \|p - q\|_2 + \frac{1}{|P_{gt}|} \sum_{q \in P_{gt}} \min_{p \in P_{pred}} \|q - p\|_2 $$
    *Note: [S5] defines Chamfer-L1 using $\|\cdot\|_1$, while [S1, unofficial] uses $\|\cdot\|_2$. The implementation below uses L2 as per [S2, unofficial] step 3.*

2.  **F-score (F1):** Geometric consistency under a threshold [S1, unofficial][S2, unofficial].
    $$ F1 = \frac{2 \cdot Precision \cdot Recall}{Precision + Recall} $$
    Where:
    $$ Recall = \frac{\sum_{p \in P_{pred}} \mathbb{I}(\min_{q \in P_{gt}} \|p - q\| < f1\_threshold)}{|P_{pred}|} $$
    $$ Precision = \frac{\sum_{q \in P_{gt}} \mathbb{I}(\min_{p \in P_{pred}} \|q - p\| < f1\_threshold)}{|P_{gt}|} $$

3.  **Normal Consistency (NC):** Dot product of normals at corresponding points [S5].
    $$ NC = \frac{1}{N} \sum_{i=1}^{N} n_{pred}^i \cdot n_{gt}^i $$
    Where $n_{pred}$ and $n_{gt}$ are normal vectors computed from the prediction and ground truth point clouds respectively [S5].

4.  **Aspect Ratio ($\rho(t)$):** Evaluates triangle shape quality [S4].
    $$ \rho(t) = \frac{\lambda_2}{\lambda_1} $$
    Where $\lambda_1 \ge \lambda_2$ are the greatest eigenvalues of the inertia matrix of triangle $t$. $\rho(t)=1$ for equilateral triangles, $\rho(t)=0$ for degenerate triangles [S4].

5.  **PSNR:** Photometric precision [S5].
    $$ PSNR = \frac{1}{N_I} \sum_{n=1}^{N_I} 20 \cdot \log_{10} \left( \frac{1}{\sqrt{MSE(C^n_{pred}, C^n_{gt})}} \right) $$
    Where $N_I$ is the number of images, and $C^n_{pred}, C^n_{gt}$ are the predicted and ground truth images [S5].

### Pseudocode
```python
import numpy as np
from scipy.spatial import KDTree

def evaluate_mesh_metrics(pred_points, gt_points, pred_normals=None, gt_normals=None):
    """
    Computes Chamfer Distance, Normal Consistency, and F1 Score.
    pred_points, gt_points: np.ndarray of shape (N, 3)
    pred_normals, gt_normals: np.ndarray of shape (N, 3) or None
    """
    # 1. Build KDTree for prediction and ground truth points
    tree_pred = KDTree(pred_points)
    tree_gt = KDTree(gt_points)
    
    # 2. Query nearest neighbors (k=1) for both directions
    # dist_gt_to_pred: distance from each GT point to nearest Pred point
    dist_gt_to_pred, _ = tree_gt.query(pred_points, k=1)
    # dist_pred_to_gt: distance from each Pred point to nearest GT point
    dist_pred_to_gt, _ = tree_pred.query(gt_points, k=1)
    
    # 3. Compute distances for CD1 (L1) and CD2 (L2)
    # Using L2 as per [S1, unofficial] and [S2, unofficial]
    cd = np.mean(dist_pred_to_gt) + np.mean(dist_gt_to_pred)
    
    # 4. Compute Normal Consistency via dot product of normals
    nc = 0.0
    if pred_normals is not None and gt_normals is not None:
        # Normalize to handle potential non-unit normals from mesh extraction
        pred_norms_unit = pred_normals / (np.linalg.norm(pred_normals, axis=1, keepdims=True) + 1e-8)
        gt_norms_unit = gt_normals / (np.linalg.norm(gt_normals, axis=1, keepdims=True) + 1e-8)
        
        # Dot product
        dotproduct = np.sum(pred_norms_unit * gt_norms_unit, axis=1)
        nc = np.mean(dotproduct)
        
    # 5. Compute F1 score using recall and precision at f1_threshold
    f1_threshold = 0.001
    recall = np.sum(dist_pred_to_gt < f1_threshold) / len(pred_points)
    precision = np.sum(dist_gt_to_pred < f1_threshold) / len(gt_points)
    
    if recall + precision == 0:
        f1 = 0.0
    else:
        f1 = 2 * recall * precision / (recall + precision)
        
    return {
        "chamfer_distance": cd,
        "normal_consistency": nc,
        "f1_score": f1
    }
```

### Edge Cases and Pitfalls
*   **Precision:** Floating-point precision issues may arise when computing dot products for normal consistency or very small distances for F1 thresholds [S2, unofficial].
*   **Boundaries:** The F1 score is sensitive to the choice of `f1_threshold`. A threshold that is too small yields low recall/precision; too large yields false positives [S1, unofficial].
*   **Degenerate Input:** Triangles with zero area (degenerate) yield an aspect ratio of 0 [S4]. Self-intersecting triangles should be detected and reported separately [S3, unofficial].

## Subtopics

### [Evaluation Pipeline](9358-evaluation-pipeline.md)
This pipeline computes Chamfer distance ($C_{\ell1}$), intersection-over-union (IoU), normal consistency (NC), and F-score on reconstructed surfaces that are visible in the input color/depth streams. It differs from standard mesh evaluation by explicitly culling occluded or unseen geometry to prevent error inflation from regions where the network output is unpredictable or where ground truth contains hidden surfaces. It builds on [Mesh/Point Cloud Evaluation Metrics](4797-mesh-point-cloud-evaluation-metrics.md) but restricts the comparison domain to the viewing frusta of the input cameras.

### [Evaluation Metrics](9899-evaluation-metrics.md)
Evaluation Metrics computes quantitative assessments of rendering and reconstruction quality by comparing generated outputs against ground truth data. It addresses the problem of objectively measuring fidelity in 3D graphics, covering data-level, image-level, and geometric-level errors. Unlike its sibling [Evaluation Pipeline](9358-evaluation-pipeline.md), which orchestrates the workflow, this method defines the specific mathematical functions for quality calculation. It differs from [Cloud-to-Mesh Accuracy Metrics](10560-cloud-to-mesh-accuracy-metrics.md) by focusing on image and volume data metrics (PSNR, LPIPS) rather than purely geometric point-cloud distances, though it shares the Chamfer Distance metric for isosurface evaluation.

### [Cloud-to-Mesh Accuracy Metrics](10560-cloud-to-mesh-accuracy-metrics.md)
Cloud-to-Mesh Accuracy Metrics quantify how closely a reconstructed point cloud reflects ground truth locations by computing the Euclidean displacements from each point in the compared cloud to the nearest facet of a reference mesh. Unlike symmetric metrics that average errors in both directions, this method specifically evaluates the precision of the reconstruction by measuring the orthogonal distance to the reference surface, handling cases where the projection falls outside the triangle boundaries by measuring to the nearest edge.

### [SDF Consistency Metrics](13280-sdf-consistency-metrics.md)
SDF Consistency Metrics evaluate how closely a reconstructed mesh matches the trained Signed Distance Function (SDF) field by measuring the network's SDF output at points on the mesh surface and at its vertices. Unlike geometric metrics that compare two meshes, this method assesses the internal consistency of the implicit representation, ensuring the extracted geometry aligns with the learned field. It is distinct from [Cloud-to-Mesh Accuracy Metrics](10560-cloud-to-mesh-accuracy-metrics.md) which measure distance to ground truth, and [Evaluation Metrics](9899-evaluation-metrics.md) which provide a broader suite of quality indicators.

### Mesh Quality Evaluation
A metric to evaluate triangle shape quality, preferring well-shaped triangles over long and skinny ones [S4]. The aspect ratio of triangle $t=abc$ is $\rho(t) = \lambda_2 / \lambda_1$, where $\lambda_1 \ge \lambda_2$ are the greatest eigenvalues of the inertia matrix of $t$ [S4]. $\rho(t) = 1$ if the triangle is equilateral ($\lambda_1 = \lambda_2$) and $\rho(t) = 0$ if it is degenerate ($\lambda_2 = 0$) [S4].

### Shape Novelty Verification
To verify generated models are new shapes and not memorized training data: Given a generated mesh, retrieve the most similar mesh in the training set by computing the Chamfer distance of point cloud samples from the generated mesh against all meshes in the training set [S3, unofficial].

### Evaluation Metrics for 3D Reconstruction
Computes geometric accuracy, completeness, photometric precision/recall, F-score, normal consistency, and PSNR to evaluate neural scene reconstruction quality [S5]. The PSNR formula is $PSNR = \frac{1}{N_I} \sum_{n=1}^{N_I} 20 \cdot \log_{10} \left( \frac{1}{\sqrt{MSE(C^n_{pred}, C^n_{gt})}} \right)$ [S5]. Parameters include $P$: Sampled point cloud from the predicted mesh, $n_p, n_{\bar{p}}$: Normal vectors computed from the prediction and ground truth point clouds respectively, and $N_I$: Number of images used for evaluation [S5].

## Operating characteristics
*   **Time Complexity:** Dominated by nearest-neighbor queries using KDTree, which is $O(N \log N)$ for construction and $O(\log N)$ per query [S2, unofficial].
*   **Memory Complexity:** $O(N)$ to store point clouds and KDTree structures [S2, unofficial].
*   **Scaling:** Performance scales with the number of points `num_points` (default 100,000) [S2, unofficial].
*   **Strengths:** Comprehensive coverage of geometric (CD, F1, NC) and shape (Aspect Ratio) metrics; handles both point clouds and meshes [S2, unofficial][S4].
*   **Limitations:** Sensitive to sampling density; requires careful threshold selection for F1 [S1, unofficial]. Does not inherently handle occlusion unless combined with an Evaluation Pipeline [S1, unofficial].
*   **When to use:** When objective quantitative comparison of 3D reconstruction quality is required against ground truth [S3, unofficial].
*   **When not to use:** When only relative ranking is needed and computational resources are extremely limited; or when occlusion handling is critical without post-processing [S1, unofficial].

## Background
The metrics originate from the need to benchmark neural radiance fields and 3D reconstruction methods [S1, unofficial]. The F-score and Chamfer Distance are standard in point cloud evaluation [S1, unofficial][S5]. Mesh quality metrics like aspect ratio were adapted from geometric processing literature [S4]. The comprehensive suite including ECD and EF1 was detailed in recent implementations for evaluating neural surface reconstructions [S2, unofficial]. Reporting standards, such as using median for min/max aspect ratios to remove extreme numbers, were established in volumetric mesh generation studies [S3, unofficial].
