# Mesh/Point Cloud Evaluation Metrics


## Overview
This method computes comprehensive geometric quality metrics for reconstructed surfaces by comparing predicted meshes or point clouds against ground truth data. It calculates Chamfer Distance (CD), Normal Consistency (NC), F1 score, Edge Chamfer Distance (ECD), Edge F1 (EF1), aspect ratio, radius ratio, angle regularity, and self-intersection percentage. It differs from standard mesh evaluation by explicitly supporting both point cloud and mesh inputs, and by providing specialized edge-aware metrics (ECD/EF1) to penalize jagged or noisy boundaries more heavily than uniform surface errors.

## How it works
**Inputs:**
- Ground truth mesh/point cloud ($P_{gt}$) and predicted mesh/point cloud ($P_{pred}$).
- Ground truth normals ($N_{gt}$) and predicted normals ($N_{pred}$). If normals are not provided, they are estimated from the mesh geometry.
- Parameters: `num_points` (default 100,000), `f1_threshold` (default 0.001), `ef1_radius` (default 0.004), `ef1_dotproduct_threshold` (default 0.2).

**Data Structures:**
- KDTree structures for $P_{gt}$ and $P_{pred}$ to enable efficient nearest neighbor queries.
- Arrays of points and normals.

**Steps:**
1. **Sampling:** If inputs are dense meshes, sample `num_points` uniformly from the surface of $P_{gt}$ and $P_{pred}$ to create point sets $S_{gt}$ and $S_{pred}$. If inputs are already point clouds, use them directly.
2. **KDTree Construction:** Build a KDTree for $S_{gt}$ and another for $S_{pred}$.
3. **Chamfer Distance (CD):**
   - Query the nearest neighbor ($k=1$) in $S_{gt}$ for each point in $S_{pred}$ to get distances $d_{pred \to gt}$.
   - Query the nearest neighbor ($k=1$) in $S_{pred}$ for each point in $S_{gt}$ to get distances $d_{gt \to pred}$.
   - Compute $CD_1$ (L1) as the mean of $d_{pred \to gt} + d_{gt \to pred}$.
   - Compute $CD_2$ (L2) as the square root of the mean of $(d_{pred \to gt}^2 + d_{gt \to pred}^2)$.
4. **Normal Consistency (NC):**
   - For each point in $S_{pred}$, find its nearest neighbor in $S_{gt}$.
   - Compute the dot product between the predicted normal $n_{pred}$ and the ground truth normal $n_{gt}$ of the matched pair.
   - Normalize by the product of norms if normals are not unit length:
     $$ \text{dotproduct} = \frac{\sum (n_{gt} \cdot n_{pred})}{\|n_{gt}\| \|n_{pred}\|} $$
   - NC is typically the mean of these dot products.
5. **F1 Score:**
   - Compute Recall: $R = \frac{\text{count}(d_{pred \to gt} < \text{f1\_threshold})}{|S_{pred}|}$.
   - Compute Precision: $P = \frac{\text{count}(d_{gt \to pred} < \text{f1\_threshold})}{|S_{gt}|}$.
   - Compute F1:
     $$ F1 = \frac{2 \cdot R \cdot P}{R + P} $$
6. **Edge Detection:**
   - Identify "edge points" in both $S_{gt}$ and $S_{pred}$ using a radius query with `ef1_radius`. Points with fewer neighbors than a certain density threshold (or specifically classified via `ef1_dotproduct_threshold` on local geometry) are marked as edge points.
7. **Edge Chamfer Distance (ECD) and Edge F1 (EF1):**
   - Compute Chamfer Distance only between the identified edge points of $S_{gt}$ and $S_{pred}$.
   - Compute F1 score using `ef1_threshold` (default 0.005) on these edge point distances.
8. **Mesh Quality Metrics (if input is a mesh):**
   - **Aspect Ratio:** For each triangle $t=abc$, compute the inertia matrix $M_t$:
     $$ M_t = \frac{1}{3} \left[ (a-\hat{t})(a-\hat{t})^T + (b-\hat{t})(b-\hat{t})^T + (c-\hat{t})(c-\hat{t})^T \right] $$
     where $\hat{t}$ is the centroid. Let $\lambda_1 \ge \lambda_2$ be the eigenvalues. Aspect ratio $\rho(t) = \lambda_2 / \lambda_1$.
   - **Radius Ratio:** Ratio of circumradius to inradius (computed via `pyvista`).
   - **Angle Regularity:** Statistical measure of angle distribution (computed via `trimesh`).
   - **Self-Intersection:** Percentage of triangles intersecting other triangles in the mesh.
9. **Return:** Aggregated metrics dictionary.

    dist_pred_to_gt, idx_pred_to_gt = tree_pred.query(pred_points, k=1)
    dist_gt_to_pred, idx_gt_to_pred = tree_gt.query(gt_points, k=1)
    
    cd1 = np.mean(dist_pred_to_gt + dist_gt_to_pred)
    cd2 = np.sqrt(np.mean(dist_pred_to_gt**2 + dist_gt_to_pred**2))
    
    # 4. Normal Consistency
    # Match pred normals to gt normals via nearest neighbor
    matched_gt_normals = gt_normals[idx_pred_to_gt]
    # Normalize
    norm_pred = pred_normals / (np.linalg.norm(pred_normals, axis=1, keepdims=True) + 1e-8)
    norm_gt = matched_gt_normals / (np.linalg.norm(matched_gt_normals, axis=1, keepdims=True) + 1e-8)
    dot_products = np.sum(norm_pred * norm_gt, axis=1)
    nc = np.mean(dot_products)
    
    # 5. F1 Score
    recall = np.mean(dist_pred_to_gt < f1_threshold)
    precision = np.mean(dist_gt_to_pred < f1_threshold)
    f1 = 2 * recall * precision / (recall + precision + 1e-8)

## Subtopics

### [Evaluation Pipeline](9358-evaluation-pipeline.md)
This pipeline computes Chamfer distance ($C_{\ell1}$), intersection-over-union (IoU), normal consistency (NC), and F-score on reconstructed surfaces that are visible in the input color/depth streams. It differs from standard mesh evaluation by explicitly culling occluded or unseen geometry to prevent error inflation from regions where the network output is unpredictable or where ground truth contains hidden surfaces. It builds on [Mesh/Point Cloud Evaluation Metrics](4797-mesh-point-cloud-evaluation-metrics.md) but restricts the comparison domain to the viewing frusta of the input cameras.

## Operating characteristics
- **Time Complexity:** Dominated by KDTree construction $O(N \log N)$ and nearest neighbor queries $O(N \log N)$, where $N$ is the number of points. Edge detection and mesh quality metrics add overhead proportional to the number of triangles/points.
- **Memory Complexity:** $O(N)$ for storing points, normals, and KDTree structures.
- **Strengths:** Provides a holistic view of surface quality, including boundary accuracy (via ECD/EF1) and geometric regularity.
- **Limitations:** Sensitive to sampling density; requires careful handling of occlusions (addressed by the Evaluation Pipeline variant). Computationally expensive for very high-resolution meshes without sampling.

## Background
The metrics described are standard in computer vision and graphics for evaluating 3D reconstruction quality. The specific combination of CD, NC, F1, and edge-aware metrics is detailed in the TetWeave project [S1, unofficial]. The aspect ratio metric for mesh quality originates from work on isosurface extraction and interpretation in geophysics [S2].
