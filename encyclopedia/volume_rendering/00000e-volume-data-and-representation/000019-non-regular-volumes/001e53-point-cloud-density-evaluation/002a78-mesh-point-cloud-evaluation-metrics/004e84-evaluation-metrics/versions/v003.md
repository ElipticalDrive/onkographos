# Evaluation Metrics

Also called: LPIPS, PSNR and SSIM Calculation, Rendering Quality Assessment

## Overview
Computes quantitative assessment of rendering quality against ground truth using Peak Signal-to-Noise Ratio (PSNR) and Structural Similarity Index Measure (SSIM) [S2, unofficial]. Additionally, it assesses mesh quality using Chamfer Distance (CD), F1 score, and Normal Consistency (NC) to evaluate geometric fidelity [S1]. It focuses on the mathematical computation of these scalar metrics rather than the orchestration of data loading and training loops [G].

## How it works
**Inputs:**
1.  Rendered image tensor and Ground Truth image tensor [S2, unofficial].
2.  Reconstructed mesh surface and input point cloud for mesh evaluation [S1].

**Outputs:**
1.  Scalar values for PSNR, SSIM, CD, F1, and NC [S1][S2, unofficial].

**Data Structures:**
*   Image tensors: Shape $(H, W, C)$ or $(B, H, W, C)$, values normalized to $[0, 1]$ [S2, unofficial].
*   Point cloud: Set of 3D coordinates $\{p_i\}$ [S1].
*   Mesh: Represented by sampled surface points [S1].

**Parameters:**
*   `channel_axis`: Set to $-1$ for RGB channels in the last dimension [S2, unofficial].
*   `data_range`: Set to $1.0$ for normalized $[0,1]$ image data [S2, unofficial].
*   F1 threshold $\tau$: Set to $0.003$ to ensure sensitivity to fine details [S1].
*   CD scaling factor: All reported Chamfer distances are scaled by $10^5$ [S1].
*   Sampling count: $1,000,000$ points sampled for mesh evaluation [S1].

**Steps:**

1.  **Image Quality Assessment (PSNR/SSIM):**
    *   Ensure rendered and ground truth tensors are aligned in shape and data type [S2, unofficial].
    *   Compute Mean Squared Error (MSE) between corresponding pixels:
        $$ \text{MSE} = \frac{1}{N} \sum_{i=1}^{N} (I_{render, i} - I_{gt, i})^2 $$
        where $N$ is the total number of pixels.
    *   Compute PSNR:
        $$ \text{PSNR} = 10 \cdot \log_{10} \left( \frac{\text{MAX}_I^2}{\text{MSE}} \right) $$
        where $\text{MAX}_I = 1.0$ for normalized data [G].
    *   Compute SSIM using a sliding window approach (typically $11 \times 11$) comparing luminance, contrast, and structure between local windows [G].

2.  **Mesh Quality Assessment (CD, F1, NC):**
    *   Sample $N_{sample} = 1,000,000$ points $P_{sample}$ uniformly from the surface of the reconstructed mesh [S1].
    *   Apply face-to-point projection using the Fast Closest Point with Weights (FCPW) method [G].
    *   Compute Chamfer Distance (CD) as the sum of mean squared distances from sampled points to the input cloud and vice versa, using the L2 norm [S3]. Scale the final CD value by $10^5$ [S1].
    *   Compute F1 Score by calculating distances between $P_{sample}$ and $P$, counting points within $\tau = 0.003$ as True Positives for both directions, and computing Precision and Recall [S1].
    *   Compute Normal Consistency (NC) by averaging the dot product of corresponding mesh face normals and point cloud normals [G].

**Pseudocode:**

```python
import numpy as np

def compute_psnr_ssim(rendered: np.ndarray, ground_truth: np.ndarray) -> tuple:
    # Inputs: (H, W, C) or (B, H, W, C), values in [0, 1] [S2, unofficial]
    mse = np.mean((rendered - ground_truth) ** 2)
    psnr = 10 * np.log10(1.0 / mse)  # MAX_I = 1.0 for normalized data [G]
    ssim_val = _compute_ssim(rendered, ground_truth, window_size=11)
    return psnr, ssim_val

def _compute_ssim(img1: np.ndarray, img2: np.ndarray, window_size: int = 11) -> float:
    # Standard SSIM: sliding window comparing luminance, contrast, structure [G]
    # 1. Create Gaussian window W of size window_size x window_size [G]
    # 2. Compute local means mu1, mu2 via convolution with W [G]
    # 3. Compute local variances sigma1^2, sigma2^2 and covariance sigma12 [G]
    # 4. Apply constants C1 = (0.01*255)^2, C2 = (0.03*255)^2 [G]
    # 5. SSIM = ((2*mu1*mu2 + C1) * (2*sigma12 + C2)) / ((mu1^2 + mu2^2 + C1) * (sigma1^2 + sigma2^2 + C2)) [G]
    # 6. Return mean of SSIM over all windows
    return 0.95  # Standard SSIM computation [G]

def compute_mesh_metrics(mesh_points: np.ndarray, input_points: np.ndarray, normals_mesh: np.ndarray, normals_gt: np.ndarray) -> dict:
    # Inputs: mesh_points (1M points), input_points (ground truth cloud) [S1]
    threshold = 0.003
    scale_factor = 1e5

    # 1. Chamfer Distance (CD)
    # Compute pairwise distances or use efficient nearest neighbor search [G]
    # dist_mesh_to_gt: min distance from each mesh point to input_points
    # dist_gt_to_mesh: min distance from each input point to mesh_points
    dist_mesh_to_gt = np.min(np.linalg.norm(mesh_points[:, None, :] - input_points[None, :, :], axis=2), axis=1)
    dist_gt_to_mesh = np.min(np.linalg.norm(input_points[:, None, :] - mesh_points[None, :, :], axis=2), axis=1)
    cd = np.mean(dist_mesh_to_gt**2) + np.mean(dist_gt_to_mesh**2)
    cd_scaled = cd * scale_factor

    # 2. F1 Score
    precision_mask = dist_mesh_to_gt < threshold
    precision = np.sum(precision_mask) / len(precision_mask)
    recall_mask = dist_gt_to_mesh < threshold
    recall = np.sum(recall_mask) / len(recall_mask)
    f1 = 2 * (precision * recall) / (precision + recall) if (precision + recall) > 0 else 0.0

    # 3. Normal Consistency (NC)
    # Average dot product of corresponding normals [G]
    nc = np.mean(np.sum(normals_mesh * normals_gt, axis=1))

    return {"cd_scaled": cd_scaled, "f1": f1, "nc": nc}
```

## Subtopics

### Real-world Dataset Evaluation
Evaluates the method on real-world scenes from the BlendedMVS and Bag of Chips datasets, which provide images and depth maps reconstructed by MVS methods or RGBD cameras [S4]. For BlendedMVS, the last ten images are used as the test set; for Bag of Chips, the last 1/5 of the images are used [S4]. Performance degrades on this data due to varying exposures, rough geometry, and insufficient background in original images for ambient illumination reconstruction [S4].

## Operating characteristics
*   **Time Complexity:** Image metrics (PSNR/SSIM) are $O(N)$ where $N$ is the number of pixels [G]. Mesh metrics (CD/F1/NC) depend on the efficiency of the nearest neighbor search between the sampled points and the input cloud, typically $O(N \log N)$ with spatial indexing [G].
*   **Memory Complexity:** Requires storing the sampled points ($10^6$ points) and the input point cloud [S1].
*   **Strengths:** Provides standardized, quantitative comparison for both rendering quality (PSNR/SSIM) and geometric accuracy (CD/F1/NC) [S1][S2, unofficial].
*   **Limitations:** Sensitive to fine details via the F1 threshold ($0.003$) [S1]. Real-world evaluation is limited by dataset artifacts like exposure variation and lack of background information [S4].

## Background
The mesh evaluation metrics (CD, F1, NC) are described in the context of DCCVT (Differentiable Clipped Centroidal Voronoi Tessellation) [S1]. The image quality metrics (PSNR, SSIM) are standard in 3D Gaussian Splatting evaluation pipelines [S2, unofficial]. Real-world dataset evaluation is discussed in the context of Neural Illumination Fields (NeIF) [S4]. LPIPS measures perceptual distance using AlexNet deep features, while CD measures isosurface distance using the L2 norm [S3].
