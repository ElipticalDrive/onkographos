# Clusterability Check

Also called: Kdtree::calClusterability, RectilinearGrid::calClusterability

## Overview
Clusterability Check determines if a K-D tree node's grid can be clustered (optimized for rendering) by checking if the combined QEF point count matches the sum of component point counts [S1, unofficial].

## How it works
**Inputs and Outputs:**
* **Input:** A K-D tree node (or `RectilinearGrid`) containing child grids, a plane direction vector `planeDir`, minimum/maximum codes `minCode`/`maxCode`, and a scalar field `t` [S1, unofficial].
* **Output:** A boolean `clusterable` indicating if the node's geometry can be safely merged.

**Data Structures:**
The method relies on the `QefSolver` structure [S1, unofficial], which maintains:
* `ATA`: $3 \times 3$ matrix (accumulated $A^T A$).
* `ATb`: $3$-vector (accumulated $A^T b$).
* `pointCount`: Integer count of points.
* `massPointSum`: $3$-vector sum of point positions.
* `averageNormalSum`: $3$-vector sum of normals.
* `roughness`: Float scalar.
* `btb`, `diag_ATc`, `diag_ctc`: Floats/Vectors for error/variance calculation [S1, unofficial].

**Steps:**
1. If `selfClusterable` is false, set `clusterable = false` and return [S1, unofficial].
2. Iterate over all children. If any child is not clusterable, set `clusterable = false` and return [S1, unofficial].
3. Verify that the combined QEF point count matches the sum of component point counts [S1, unofficial].
4. Set `clusterable = true` [S1, unofficial].

**Pseudocode:**
```python
def cal_clusterability(node, plane_dir, min_code, max_code, scalar_field_t):
    if not node.self_clusterable:
        return False
    for child in node.children:
        if not cal_clusterability(child, plane_dir, min_code, max_code, scalar_field_t):
            return False
    combined_count = sum(child.qef_solver.point_count for child in node.children)
    if node.qef_solver.point_count != combined_count:
        return False
    return True
```

**Parameters:**
* `planeDir`, `minCode`, `maxCode`, `t`: Arguments passed to the function [S1, unofficial]. Their exact semantic roles are not given in the sources.

## Subtopics

### Weighted Covering / Plank Collapsing
A method to certify when a group of primitives can be collapsed into fewer representative planks without forfeiting more than an $\epsilon$-fraction of volumetric mass [S2, unofficial]. It uses Theorem 4 (Weighted Covering) to manage essentially distinct families of tubes with weights satisfying the Katz–Tao density condition $\Delta_{max}(T) \lesssim 1$ [S2, unofficial]. A "plank" is defined as an oriented box of half-extents $h = 3\sigma$ with opacity weight, serving as the unit of geometric bookkeeping [S2, unofficial].
