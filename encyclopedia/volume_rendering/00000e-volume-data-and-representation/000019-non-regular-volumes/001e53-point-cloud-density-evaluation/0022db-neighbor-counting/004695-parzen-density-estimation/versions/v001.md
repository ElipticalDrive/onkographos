# Parzen Density Estimation

Also called: Cluster conditional pdf estimation, PDF cube construction, Parzen Density Estimation for Cluster Classification

## Overview
Parzen Density Estimation estimates the probability density function (pdf) of cluster data within a silhouette slice to determine cluster membership for test points, enabling the construction of a 3D pdf cube for surface reconstruction [S1]. It differs from sibling methods like KDTree-based Neighbor Counting by using a continuous Gaussian kernel interpolation to define cluster boundaries rather than discrete neighbor counts, allowing for smoother decision boundaries in the context of connecting clusters across quantized marching cubes slices [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A set of training data points $\tilde{t}_i$ belonging to a specific cluster $c_j$ within a quantized marching cubes (MC) slice $S_{i_{ocq}}$ [S1].
*   **Input:** A test point $\tilde{t} = [u, v]^T$ in the same slice [S1].
*   **Input:** The Gaussian window area parameter $w_n$ [S1].
*   **Output:** The cluster conditional pdf value $p_i(\tilde{t}|c_j)$ [S1].
*   **Output:** The assigned cluster ID via the decision function $d(\tilde{t})$ [S1].

**Data Structures**
*   **PDF Cube:** A 3D data structure where each slice $i$ stores the cluster conditional pdfs for all clusters found in that slice [S1]. In the source example, each cluster conditional pdf is interpolated over a grid of 170x170 pixels [S1].

**Parameters**
*   $w_n$: The area of the Gaussian window. This parameter controls the degree of smoothness of the pdf. In the source experiments, $w_n = 5$ [S1].

**Formulas**
The Parzen estimator for the cluster conditional pdf is defined as [S1]:
$$
p_i(\tilde{t}|c_j) = \frac{1}{n_j} \sum_{i=0}^{n_j} w(\tilde{t} - \tilde{t}_i)
$$
where:
*   $n_j$ is the total number of data points classified as the $j$-th cluster in the slice $S_{i_{ocq}}$ [S1].
*   $\tilde{t}_i$ are the training data points for cluster $c_j$ [S1].
*   $w(\cdot)$ is a Gaussian window function with an area equal to $w_n$ [S1].

The probability $P$ that $j$-th cluster data is found in a square with area $w_n$ centered at $(x, y)$ is theoretically [S1]:
$$
P = \int_{v=y-w_n/2}^{y+w_n/2} \int_{u=x-w_n/2}^{x+w_n/2} p_i(\tilde{t}|c_j) \, du \, dv
$$
In practice, this is approximated by the ratio of counts [S1]:
$$
P \simeq \frac{k}{n_j}
$$
where $k$ is the number of data points classified as the $j$-th cluster within the square [S1].

The cluster decision function $d(\tilde{t})$ determines the cluster ID of a test data $\tilde{t}$ in the $i$-th quantized MC slice [S1]:
$$
d(\tilde{t}) = \arg\max_j p_i(\tilde{t}|c_j) P_i(c_j)
$$
where $P_i(c_j)$ is the prior probability of cluster $c_j$ in slice $i$ [S1].

**Pseudocode**
```python
import math

def gaussian_window(t, t_i, w_n):
    """
    Computes the Gaussian window value w(t - t_i).
    Note: The exact functional form of w() is not specified in the source,
    only that it is a Gaussian window with area w_n.
    We assume a standard 2D Gaussian kernel scaled by the area.
    """
    # Distance squared between test point t and sample t_i
    dist_sq = (t[0] - t_i[0])**2 + (t[1] - t_i[1])**2
    
    # Standard Gaussian kernel: (1 / (2 * pi * sigma^2)) * exp(-dist^2 / (2 * sigma^2))
    # The area w_n relates to the spread. For a Gaussian, area is often related to sigma.
    # Without explicit formula for w() in terms of w_n, we use a standard normalization
    # where the kernel integrates to 1. The source states w_n determines smoothness.
    # A common interpretation for "area w_n" in this context implies the support or variance scaling.
    # We implement a standard Gaussian kernel. The scaling factor ensures the sum approximates density.
    
    # Assuming w_n defines the variance parameter sigma^2 or similar. 
    # Source says "area equals to w_n". For a Gaussian, the integral over R^2 is 1.
    # If w_n is the "area" of the window function's effective support, we might scale sigma.
    # However, without explicit mapping, we use a standard Gaussian.
    # To strictly follow "Gaussian window with area w_n", we might interpret w_n as the variance sigma^2.
    # Let's assume sigma^2 = w_n / (2*pi) or similar? 
    # Actually, simpler: The source just says w() is a Gaussian window with area w_n.
    # We will use a standard Gaussian kernel. The parameter w_n likely scales the exponent.
    
    # Let's assume the kernel is: (1/w_n) * exp(-dist^2 / w_n) ? 
    # Or standard: (1/(2*pi*sigma^2)) * exp(-dist^2/(2*sigma^2))
    # If area = w_n, and for Gaussian area ~ sigma^2, let sigma^2 = w_n.
    # Then w(t) = (1/(2*pi*w_n)) * exp(-dist^2 / (2*w_n))
    
    sigma_sq = w_n
    coeff = 1.0 / (2.0 * math.pi * sigma_sq)
    return coeff * math.exp(-dist_sq / (2.0 * sigma_sq))

def parzen_density_estimate(test_t, cluster_samples, w_n):
    """
    Estimates the cluster conditional pdf p_i(t|c_j) for a test point.
    """
    n_j = len(cluster_samples)
    if n_j == 0:
        return 0.0
    
    density_sum = 0.0
    for t_i in cluster_samples:
        density_sum += gaussian_window(test_t, t_i, w_n)
        
    return density_sum / n_j

def classify_point(test_t, slice_clusters, priors):
    """
    Determines the cluster ID for a test point using the decision function.
    slice_clusters: dict mapping cluster_id -> list of sample points
    priors: dict mapping cluster_id -> P_i(c_j)
    """
    best_cluster_id = None
    max_score = -math.inf
    
    for cluster_id, samples in slice_clusters.items():
        # Estimate conditional pdf
        p_cond = parzen_density_estimate(test_t, samples, w_n=5) # w_n=5 from source
        
        # Get prior
        prior = priors.get(cluster_id, 0.0)
        
        # Decision function: argmax p(t|c_j) * P(c_j)
        score = p_cond * prior
        
        if score > max_score:
            max_score = score
            best_cluster_id = cluster_id
            
    return best_cluster_id
```

**Edge Cases and Pitfalls**
*   **Zero Samples:** If $n_j = 0$ for a cluster, the density is undefined; the implementation should return 0 or handle the absence of the cluster [S1].
*   **Window Size Sensitivity:** The size of $w_n$ determines the smoothness. Too small a window leads to overfitting (noisy density); too large leads to over-smoothing (loss of detail) [S1].
*   **Boundary Conditions:** The source mentions quantized MC slices. Points near the boundary of the slice may have incomplete neighborhood information, affecting the Gaussian kernel evaluation [S1].

## Subtopics

### PDF Cube Construction
The process of storing the estimated cluster conditional pdfs for all clusters in a slice into a 3D data structure. This allows subsequent slices to reference previous density information for cluster connection [S1].

### Cluster Connection via PDF
Using the PDF cube from the next slice ($i+1$) to determine connections for clusters in the current slice ($i$), leveraging the similarity of connected clusters [S1].

## Operating characteristics
*   **Complexity:** The estimation requires summing over all $n_j$ samples in a cluster for each test point. Complexity is $O(n_j)$ per test point per cluster.
*   **Memory:** Requires storing the PDF cube, which in the source example interpolates 170x170 pixels per cluster per slice [S1].
*   **Strengths:** Provides smooth, continuous density estimates that facilitate the connection of clusters across slices, handling multiple connections by minimizing duplication [S1].
*   **Limitations:** Computationally expensive for large $n_j$ if evaluated naively for every test point. The source notes that treating multiple connections simply can cause unnecessary surface duplication, which this method addresses via density-based decision functions [S1].

## Background
The method originates from work on local hull-based surface construction of volumetric data from silhouettes, specifically for connecting clusters in marching cubes outputs [S1]. It was developed to address the problem of determining cluster membership and connecting clusters across quantized slices using nonparametric density estimation [S1].
