# Density-based Clustering with Weighted Dissimilarity

Also called: DBSCAN variation, Weighted Dissimilarity DBSCAN

## Overview
A clustering approach using a variation of DBSCAN to identify similar phases or states across different simulation sequences [S1]. It uses a weighted dissimilarity measure based on sum of squared intensity differences and temporal indices [S1]. It builds on [DBSCAN](11722-dbscan.md) but modifies the distance metric and neighborhood density calculation to account for the hierarchical structure of simulation data [S1].

## How it works
**Inputs:** A set of segment representatives derived from a prior segmentation process [S1]. Each representative corresponds to a segment of time steps [S1]. Each volume $v$ has a sequence identifier $s(v)$ and a time step index $t_i(v)$ [S1].

**Outputs:** A set of clusters [S1]. Each cluster contains: 1) References to its member segments, 2) The cluster medoid (member minimizing average dissimilarity to all other cluster members), 3) The sequence range (set of sequence identifiers with at least one member in the cluster), 4) The temporal range (set of time step indices covered by cluster members), 5) Temporal medoids (for each distinct time step index in the cluster, the member minimizing average dissimilarity to cluster members of that same time step) [S1].

**Data Structures:**
*   **Segment Representative:** An object representing a segment of time steps [S1]. It stores the sequence identifier $s$, the representative time step index $t_i$, and the number of members $|S_0|$ in the original segment [S1].
*   **Dissimilarity Matrix:** A symmetric matrix $D$ of size $N \times N$, where $N$ is the number of segment representatives [S1]. $D_{ij}$ stores the dissimilarity $d(v_i, v_j)$ between representative $i$ and representative $j$ [S1].
*   **Neighborhood Index:** For each representative, a list of indices sorted by ascending dissimilarity values [S1].

**Parameters:**
*   $\epsilon$ (epsilon): Maximum dissimilarity distance for two points to be considered neighbors [S1]. Set to the average dissimilarity between all segment representatives [S1].
*   $p_{min}$: Minimum number of points required to form a dense region [S1]. Calculated as:
    $$ p_{min} = \left\lceil \frac{1}{\ln |S_0|} \right\rceil $$
    where $|S_0|$ is the average number of members in a segment [S1].

**Algorithm Steps:**

1.  **Compute Dissimilarity Matrix:**
    For every pair of segment representatives $v_1$ and $v_2$, compute the dissimilarity $d(v_1, v_2)$ using the weighted formula:
    $$ d(v_1, v_2) = w(v_1, v_2) \sum_{u} (v_1(u) - v_2(u))^2 $$
    where $u$ iterates over all 3D grid positions, $v_1(u)$ and $v_2(u)$ are the intensity values at position $u$, and $w(v_1, v_2)$ is the weight factor defined as:
    $$ w(v_1, v_2) = \begin{cases} 1 + \sqrt{|t_i(v_1) - t_i(v_2)|} & \text{if } s(v_1) = s(v_2) \\ 0 & \text{otherwise} \end{cases} $$
    [S1]

2.  **Generate Neighborhood Indices:**
    For each segment representative $v_i$, sort all other representatives $v_j$ by their dissimilarity $d(v_i, v_j)$ in ascending order [S1]. Store this sorted list as the neighborhood index for $v_i$ [S1].

3.  **Execute DBSCAN:**
    Initialize all points as unvisited [S1]. For each unvisited point $p$:
    a.  Mark $p$ as visited [S1].
    b.  Retrieve the neighborhood index for $p$ [S1].
    c.  Identify all neighbors $N_p$ such that $d(p, q) \le \epsilon$ [S1].
    d.  Calculate neighborhood size by summing the member counts of all neighbors in $N_p$ [S1].
    e.  If neighborhood size $\ge p_{min}$:
        i.  Create a new cluster $C$ [S1].
        ii. Add $p$ to $C$ [S1].
        iii. For each neighbor $q \in N_p$:
            1.  If $q$ is unvisited, mark it as visited [S1].
            2.  Retrieve the neighborhood index for $q$ [S1].
            3.  Identify neighbors $N_q$ such that $d(q, r) \le \epsilon$ [S1].
            4.  If neighborhood size of $q \ge p_{min}$, add these neighbors to the frontier of $N_p$ [S1].
            5.  Add $q$ to $C$ [S1].
    f.  If neighborhood size $< p_{min}$, mark $p$ as noise [S1].

4.  **Assign Members:**
    If a segment representative is part of a cluster, all original members of that segment are assumed to share this cluster association [S1].

5.  **Compute Cluster Metadata:**
    After clustering completes, compute the additional information for each cluster [S1]:
    *   **Cluster Medoid:** Find the member $m \in C$ that minimizes $\frac{1}{|C|-1} \sum_{k \in C, k \neq m} d(m, k)$ [S1].
    *   **Sequence Range:** Set $\{ s(m) \mid m \in C \}$ [S1].
    *   **Temporal Range:** Set $\{ t_i(m) \mid m \in C \}$ [S1].
    *   **Temporal Medoids:** For each distinct time step index $t$ in the temporal range, find the member $m \in C$ with $t_i(m) = t$ that minimizes $\frac{1}{|C_t|-1} \sum_{k \in C_t, k \neq m} d(m, k)$, where $C_t = \{ k \in C \mid t_i(k) = t \}$ [S1].

**Pseudocode:**

```python
import math

def compute_dissimilarity(v1, v2):
    """
    v1, v2: dicts with keys 'u' (array of values), 'ti' (time index), 'si' (sequence id), 'members' (int)
    Returns weighted dissimilarity.
    """
    ssd = sum((v1['u'][idx] - v2['u'][idx])**2 for idx in range(len(v1['u'])))
    weight = 1 + math.sqrt(abs(v1['ti'] - v2['ti'])) if v1['si'] == v2['si'] else 0
    return weight * ssd

def weighted_dbscan(representatives, epsilon, p_min):
    """
    representatives: list of segment representative dicts
    epsilon: float
    p_min: int
    Returns: list of clusters (list of indices), list of noise indices
    """
    n = len(representatives)
    dist_matrix = [[0.0] * n for _ in range(n)]
    for i in range(n):
        for j in range(i + 1, n):
            d = compute_dissimilarity(representatives[i], representatives[j])
            dist_matrix[i][j] = d
            dist_matrix[j][i] = d

    neighborhood_indices = []
    for i in range(n):
        dists = [(dist_matrix[i][j], j) for j in range(n) if i != j]
        dists.sort(key=lambda x: x[0])
        neighborhood_indices.append(dists)

    visited = [False] * n
    clusters = []
    noise = []

    for i in range(n):
        if visited[i]:
            continue
        visited[i] = True
        
        neighbors = []
        for dist, idx in neighborhood_indices[i]:
            if dist <= epsilon:
                neighbors.append(idx)
            else:
                break
        
        neighbor_member_count = sum(representatives[idx]['members'] for idx in neighbors)
        
        if neighbor_member_count >= p_min:
            cluster = [i]
            seed_set = list(neighbors)
            while seed_set:
                q = seed_set.pop(0)
                if not visited[q]:
                    visited[q] = True
                    q_neighbors = []
                    for dist, idx in neighborhood_indices[q]:
                        if dist <= epsilon:
                            q_neighbors.append(idx)
                        else:
                            break
                    q_member_count = sum(representatives[idx]['members'] for idx in q_neighbors)
                    if q_member_count >= p_min:
                        for nb in q_neighbors:
                            if nb not in seed_set and nb not in cluster:
                                seed_set.append(nb)
                    cluster.append(q)
                elif q not in cluster:
                    cluster.append(q)
            clusters.append(cluster)
        else:
            noise.append(i)
            
    return clusters, noise
```

**Edge Cases and Pitfalls:**
*   **Weight Zero:** If $s(v_1) \neq s(v_2)$, the weight is $0$, making dissimilarity $0$ [S1].
*   **Precision:** Sum of squared differences can be large; ensure floating-point precision is sufficient [G].
*   **Boundary Conditions:** The dissimilarity is undefined for the last time step of a sequence in the segmentation phase, but the clustering operates on segment representatives, so this is handled upstream [S1].

## Operating characteristics
*   **Time Complexity:** Computing the dissimilarity matrix takes $O(N^2 \cdot V)$, where $N$ is the number of segment representatives and $V$ is the number of 3D grid positions [S1]. DBSCAN execution is $O(N^2)$ in the worst case without spatial indexing, but with the precomputed sorted neighborhood indices, neighbor queries are efficient [S1]. The source notes that the time required for executing the actual clustering algorithm once the dissimilarity matrix has been computed is negligible [S1].
*   **Memory Complexity:** $O(N^2)$ to store the dissimilarity matrix [S1].
*   **Strengths:** Discovers clusters of arbitrary shape; does not require predetermining the number of clusters; robust to noise; incorporates temporal and sequence information via the weighted dissimilarity [S1].
*   **Limitations:** Sensitive to parameter selection ($\epsilon$, $p_{min}$); high computational cost for large volumes due to the sum of squared differences over all grid positions; the weight function's behavior for different sequences may lead to unintended merging [S1].
*   **When to Use:** When analyzing simulation data to find similar temporal progressions across multiple sequences, especially when sequences are not perfectly synchronized [S1].
*   **When Not to Use:** When computational resources are limited for large volumes; when sequences are expected to be strictly synchronous and simple Euclidean distance suffices [S1].

## Background
This method was introduced in the context of result-driven exploration of simulation parameter spaces for visual effects design [S1]. It is a variation of DBSCAN [12] adapted for clustering segment representatives from simulation sequences [S1]. The weighted dissimilarity measure is motivated by the need to visualize simulation data based on observable characteristics, using a simplistic but effective metric based on sum of squared intensity differences [S1]. The approach is related to measures proposed by Birant and Kut [9] [S1].
