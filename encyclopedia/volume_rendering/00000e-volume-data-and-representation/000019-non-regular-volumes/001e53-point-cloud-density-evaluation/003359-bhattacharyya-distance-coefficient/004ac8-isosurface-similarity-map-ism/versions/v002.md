# Isosurface Similarity Map (ISM)
Also called: Isosurface Similarity Map Generation, Mutual Information-based Similarity Map Construction, SMV

## Overview
Isosurface Similarity Map (ISM) is a visualization technique that depicts the structural information of volume data by quantifying the similarity between individual isosurfaces using an information-theoretic measure, specifically normalized mutual information [S1]. Unlike conventional histograms that rely on the frequency of isovalues or derivatives, ISM provides a symmetric $N \times N$ matrix recording the similarity between every pair of isosurfaces generated from a discrete set of $N$ isovalues [S1]. This approach is distinct from its parent method, [Bhattacharyya Distance Coefficient](6998-bhattacharyya-distance-coefficient.md), which measures distribution overlap via histograms of voxel values, and its sibling, [Wasserstein Distance](7206-wasserstein-distance.md), by focusing on the geometric relationship between level sets via their distance transforms [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A scalar volumetric field $f: \mathbb{R}^3 \rightarrow \mathbb{R}$ and a discrete set of $N$ isovalues $V = \{h_1, \dots, h_N\}$.
*   **Output:** An $N \times N$ symmetric matrix $SMV$, where $SMV(i, j)$ is the similarity between the isosurface defined by $h_i$ and the isosurface defined by $h_j$.

**Data Structures:**
1.  **Distance Transform Array:** For each isovalue $h_k$, a 3D array $D_{h_k}$ storing the Euclidean distance from each voxel to the isosurface $L_{h_k}$. These are typically stored in compressed form on disk to manage memory [S1].
2.  **Joint Histogram:** A 2D histogram with fixed dimensions $128 \times 128$ bins used to estimate the joint probability distribution of distances for a pair of isosurfaces [S1].

**Steps:**

1.  **Define Isosurfaces:** For each isovalue $h \in V$, define the isosurface $L_h$ as the locus of points where the scalar field equals $h$:
    $$ L_h = \{ x \in \mathbb{R}^3 : f(x) = h \} $$
    [S1]

2.  **Compute Distance Transforms:** For each isosurface $L_h$, compute its distance transform $D_h$. For any point $x$ in the volume, $D_h(x)$ is the minimum Euclidean distance to the surface:
    $$ D_h(x) = \min_{y \in L_h} d(x, y) $$
    where $d$ is the Euclidean distance metric [S1]. The distance transforms are generated at the original volume resolution and then downsampled if necessary to reduce computation time, rather than computing them from a downsampled volume [S1].

3.  **Iterate Pairs:** For each unique pair of isovalues $(h_i, h_j)$ with $i < j$:
    a.  **Treat Distances as Random Variables:** Consider the distance values $D_{h_i}(x)$ and $D_{h_j}(x)$ at every voxel position $x$ as realizations of random variables $X$ and $Y$ [S1].
    b.  **Compute Joint Histogram:** Construct a 2D joint histogram of $D_{h_i}$ and $D_{h_j}$. Iterate over all voxels $x$; for each voxel, increment the bin corresponding to the pair of values $(D_{h_i}(x), D_{h_j}(x))$. The histogram has $128 \times 128$ bins [S1].
    c.  **Estimate Probabilities:**
        *   Let $H_{ij}$ be the joint histogram counts.
        *   Compute the joint probability distribution $p_{X,Y}(x, y)$ by normalizing $H_{ij}$ by the total number of voxels.
        *   Compute the marginal probability distributions $p_X(x)$ and $p_Y(y)$ by summing the rows and columns of $p_{X,Y}$, respectively [S1].

4.  **Compute Entropies:** Calculate the marginal entropies $H(X)$ and $H(Y)$ and the joint entropy $H(X, Y)$ using the estimated probabilities:
    $$ H(X) = - \sum_{x} p_X(x) \log(p_X(x)) $$
    $$ H(Y) = - \sum_{y} p_Y(y) \log(p_Y(y)) $$
    $$ H(X, Y) = - \sum_{x} \sum_{y} p_{X,Y}(x, y) \log(p_{X,Y}(x, y)) $$
    [S1]

5.  **Compute Similarity:** Calculate the normalized mutual information $\hat{I}(X, Y)$ to determine the similarity $SMV(i, j)$:
    $$ I(X, Y) = H(X) + H(Y) - H(X, Y) $$
    $$ \hat{I}(X, Y) = \frac{2 I(X, Y)}{H(X) + H(Y)} $$
    Set $SMV(i, j) = SMV(j, i) = \hat{I}(X, Y)$ [S1].

6.  **Diagonal Values:** Set $SMV(i, i) = 1$ for all $i$, as the mutual information of a variable with itself is equal to its entropy, resulting in a normalized value of 1 [S1].

**Pseudocode:**

```python
def compute_isosurface_similarity_map(volume, isovalues, num_bins=128):
    """
    Computes the Isosurface Similarity Map for a given volume and set of isovalues.
    
    Args:
        volume: 3D numpy array representing the scalar field f(x).
        isovalues: List of N scalar values {h_1, ..., h_N}.
        num_bins: Number of bins for the joint histogram (default 128).
        
    Returns:
        SMV: N x N numpy array of similarity values.
    """
    N = len(isovalues)
    SMV = np.zeros((N, N))
    
    # Step 1 & 2: Compute Distance Transforms for all isovalues
    # Note: In practice, these are computed and stored/compressed immediately.
    # We assume a helper function compute_distance_transform(volume, isovalue) exists.
    distance_transforms = []
    for h in isovalues:
        # Extract isosurface L_h implicitly via marching cubes or similar,
        # then compute Euclidean distance transform D_h.
        # For implementation completeness, we assume this step yields a 3D array.
        D_h = compute_distance_transform(volume, h)
        distance_transforms.append(D_h)
        
    # Step 3: Iterate over pairs (i < j)
    for i in range(N):
        SMV[i, i] = 1.0  # Diagonal is always 1
        for j in range(i + 1, N):
            D_i = distance_transforms[i]
            D_j = distance_transforms[j]
            
            # Step 3b: Compute Joint Histogram
            # Flatten distance arrays to 1D lists of values
            vals_i = D_i.flatten()
            vals_j = D_j.flatten()
            
            # Determine range of distances to map to bins
            # Assuming distances are non-negative. 
            # Find max distance to define bin width.
            max_dist = max(np.max(vals_i), np.max(vals_j))
            if max_dist == 0:
                # Degenerate case: no volume or zero distance everywhere
                similarity = 1.0
            else:
                bin_width = max_dist / num_bins
                
                # Initialize histogram
                joint_hist = np.zeros((num_bins, num_bins))
                
                # Populate histogram
                for d_i, d_j in zip(vals_i, vals_j):
                    # Map continuous distance to bin index
                    bin_i = int(d_i / bin_width)
                    bin_j = int(d_j / bin_width)
                    
                    # Clamp to valid bin range
                    bin_i = min(bin_i, num_bins - 1)
                    bin_j = min(bin_j, num_bins - 1)
                    
                    joint_hist[bin_i, bin_j] += 1
                
                # Step 3c: Estimate Probabilities
                total_voxels = vals_i.shape[0]
                joint_prob = joint_hist / total_voxels
                
                # Marginal probabilities
                p_X = np.sum(joint_prob, axis=1)
                p_Y = np.sum(joint_prob, axis=0)
                
                # Step 4: Compute Entropies
                # Helper to compute entropy from probability array
                def entropy(p):
                    # Filter out zero probabilities to avoid log(0)
                    p_nonzero = p[p > 0]
                    return -np.sum(p_nonzero * np.log2(p_nonzero))
                
                H_X = entropy(p_X)
                H_Y = entropy(p_Y)
                
                # Joint entropy
                p_joint_nonzero = joint_prob[joint_prob > 0]
                H_XY = -np.sum(p_joint_nonzero * np.log2(p_joint_nonzero))
                
                # Step 5: Compute Normalized Mutual Information
                if (H_X + H_Y) == 0:
                    similarity = 1.0
                else:
                    I_XY = H_X + H_Y - H_XY
                    similarity = (2 * I_XY) / (H_X + H_Y)
            
            SMV[i, j] = similarity
            SMV[j, i] = similarity
            
    return SMV
```

**Parameters:**
*   $N$: Number of discrete isovalues. Typical values depend on the dataset's dynamic range and desired resolution of the map [S1].
*   Joint Histogram Bin Count: Fixed at $128 \times 128$ bins [S1].
*   Distance Transform Resolution: Can be downsampled from the original volume resolution to reduce computation time. Typical tested resolutions include $64 \times 64 \times 64$ [S1].

**Edge Cases and Pitfalls:**
*   **Redundant Isosurfaces:** Volume data often contains onion-peel structures, material inhomogeneities, partial volume effects, and noise, leading to redundant isosurfaces. The distance transform representation is chosen because it is stable and robust to these shape perturbations and noise [S1].
*   **Computational Cost:** The brute-force approach of computing joint histograms for all pairs is computationally expensive, potentially taking several hours for full-resolution data. The most performance-critical component is the construction of the joint histogram [S1].
*   **Downsampling Strategy:** Distance transforms should be generated at the original resolution and then downsampled, rather than computing them from a downsampled volume, to preserve unique characteristics of the isosurface shape [S1].

## Subtopics

### Isosurface Similarity Distribution (SDV)
A vector describing the average similarity for each individual isosurface, derived by summing the rows (or columns) of the ISM and normalizing by the number of isovalues $|V|$ [S1]:
$$ SDV(i) = \frac{1}{|V|} \sum_{j=1}^{|V|} SMV(i, j) $$
Peaks in SDV correspond to isosurfaces most similar to others, while valleys indicate regions of rapid structural change [S1]. To efficiently evaluate SDV for arbitrary continuous subranges of isovalues (not just the full set), a summed-area table of the similarity map should be used [S1].

## Operating characteristics
**Time and Memory Complexity:**
*   **Time:** The method is $O(N^2 \cdot V)$, where $N$ is the number of isovalues and $V$ is the number of voxels in the distance transform grid. The dominant cost is the construction of the joint histogram for each pair [S1].
*   **Memory:** Requires storing $N$ distance transforms. To manage memory, these are often written to disk in compressed form immediately after computation [S1].

**Measured Performance:**
*   **Hardware:** Intel Core 2 Duo 2.53 GHz CPU, 4 GB RAM, NVidia GeForce 9600M GT GPU [S1].
*   **Dataset:** Original resolution $512 \times 512 \times 230$.
*   **DT Resolution 256x256x230:** 569.1 minutes [S1].
*   **DT Resolution 64x64x57:** 22.1 minutes [S1].
*   **DT Resolution 32x32x28:** 20.6 minutes [S1].
*   **Typical Notebook Time:** ~25 minutes for standard datasets with DT resolution of $64 \times 64 \times 64$ [S1].

**Strengths and Limitations:**
*   **Strengths:** Provides a concise overview of dataset structure; distinct features manifest as squares in the map; transitional regions are detected through nesting; uncorrelated noise has little influence due to the use of mutual information; robust to shape perturbations [S1].
*   **Limitations:** High computational cost (brute-force approach); considered a serious limitation for current methods; not easily combinable with multi-dimensional classification approaches using gradient magnitude or curvature [S1].

**When to Use:**
*   When a global overview of structural similarity between isosurfaces is needed for transfer function design or automatic identification of representative isovalues [S1].
*   When noise robustness is required [S1].

**When Not to Use:**
*   When real-time or interactive generation of the similarity map is required due to high computational cost [S1].
*   When the primary goal is frequency-based analysis of isovalues rather than structural similarity [S1].

## Background
The Isosurface Similarity Map was introduced by Stefan Bruckner and Thomas Möller in 2010 [S1]. It was developed at the GrUVi Lab, School of Computing Science, Simon Fraser University, Canada [S1]. The method builds upon information-theoretic measures of similarity, specifically mutual information, which has been applied in shape registration, multi-modality fusion, and viewpoint selection [S1]. The authors chose mutual information because it is robust to noise and shape perturbations, addressing the issue of redundant isosurfaces in volume data [S1]. The implementation utilized a CUDA-based version of the mutual information computation algorithm by Shams and Barnes [S1].
