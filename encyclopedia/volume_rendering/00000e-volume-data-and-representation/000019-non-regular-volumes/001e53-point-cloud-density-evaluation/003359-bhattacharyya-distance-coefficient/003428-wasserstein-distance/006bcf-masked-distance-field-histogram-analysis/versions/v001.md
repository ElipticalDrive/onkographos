# Masked Distance Field Histogram Analysis

Also called: Masked Distance Field Histogram

## Overview
Masked Distance Field Histogram Analysis is a technique for quantifying the geometric overlap between a target volume (e.g., a resident's drilled cavity) and a reference volume (e.g., an expert's drilled cavity) by comparing the distributions of distance field values within and outside the target region [S1]. It differs from mutual information-based approaches like Bruckner and Möller [1] by employing a masking strategy on expert-derived distance fields and using Earth-Mover’s Distance (EMD) for the interior distribution, which better captures shape discrepancies in sparse or binary volumetric data [S1].

## How it works
The method constructs a high-dimensional feature vector representing the similarity between a test volume and one or more reference volumes. It operates on binary volumetric data where a voxel is either occupied (part of the cavity) or empty [S1].

### Inputs and Outputs
**Inputs:**
1.  **Reference Volume ($R$):** The expert's ground-truth binary volume.
2.  **Test Volume ($T$):** The target binary volume to be evaluated.
3.  **Distance Field ($D_R$):** The signed distance field computed from $R$.
4.  **Histogram Parameters:** Number of bins $n$, penalty scaling parameter $s$.

**Outputs:**
1.  **Feature Vector:** A vector containing $\omega_{in}$ and $\omega_{out}$ scores for the test volume against the reference.

### Data Structures
*   **Distance Field ($D_R$):** A 3D grid of floating-point values. $D_R(v) = 0$ on the surface, negative inside, positive outside.
*   **Histogram ($H$):** A 1D array of size $n$. Each bin $i$ (where $i=1 \dots n$) stores the count of voxels whose distance field value falls within the bin's range.
*   **Mask:** The binary test volume $T$, used to select voxels from $D_R$.

### Steps
1.  **Generate Reference Distance Field:** Compute the Euclidean distance field $D_R$ for the reference volume $R$. Voxels inside $R$ have negative values; voxels outside have positive values [S1].
2.  **Mask Distance Field:** Apply the test volume $T$ as a mask to $D_R$. This creates a masked distance field $D_{masked}$ where values are retained only for voxels where $T(v) = 1$ (occupied). Voxels where $T(v) = 0$ are excluded from subsequent histogram calculations [S1].
3.  **Compute Histograms:**
    *   **Inside Histogram ($A_{in}$):** Compute the histogram of $D_{masked}$ considering only negative values (interior of the test volume).
    *   **Outside Histogram ($A_{out}$):** Compute the histogram of $D_{masked}$ considering only positive values (exterior of the test volume, but inside the test mask).
    *   *Note:* The reference baseline histograms ($B_{in}, B_{out}$) are computed similarly using the reference volume $R$ as the mask for $D_R$. For $B_{out}$, since the mask is identical to the distance field generation object, the histogram contains only zero-valued bins (empty bins) because there are no voxels outside $R$ that are also inside $R$ [S1].
4.  **Calculate Inside Score ($\omega_{in}$):** Compute the Earth-Mover’s Distance between $A_{in}$ and $B_{in}$ [S1].
5.  **Calculate Outside Score ($\omega_{out}$):** Compute a weighted sum of the bins in $A_{out}$ [S1].
6.  **Construct Feature Vector:** Combine $\omega_{in}$ and $\omega_{out}$ for the test volume against each reference volume (e.g., ALL, ANY, individual experts) to form the final feature vector [S1].

### Pseudocode

```python
def masked_distance_field_histogram_analysis(reference_volume, test_volume, num_bins=100, s=1.2):
    """
    Computes the feature vector for a test volume against a reference volume.
    
    Args:
        reference_volume: Binary 3D array (1 for occupied, 0 for empty).
        test_volume: Binary 3D array (1 for occupied, 0 for empty).
        num_bins: Number of histogram bins (n).
        s: Penalty scaling parameter.
        
    Returns:
        omega_in: Float, EMD score for inside histograms.
        omega_out: Float, Weighted sum score for outside histograms.
    """
    
    # Step 1: Generate Reference Distance Field
    # Compute Euclidean distance field for the reference volume.
    # Voxels inside reference have negative values, outside have positive.
    dist_field_ref = compute_euclidean_distance_field(reference_volume)
    
    # Step 2: Mask Distance Field with Test Volume
    # Create a masked distance field where only voxels in test_volume are kept.
    # Voxels not in test_volume are ignored for histogram calculation.
    masked_dist_field = dist_field_ref * test_volume
    
    # Step 3: Compute Histograms
    # Extract negative values (inside) and positive values (outside) from the masked field.
    inside_values = masked_dist_field[masked_dist_field < 0]
    outside_values = masked_dist_field[masked_dist_field > 0]
    
    # Compute histogram for inside values
    # Bin edges should be determined by the range of distance values.
    # For simplicity, assume uniform binning over the max distance range.
    hist_in, _ = np.histogram(inside_values, bins=num_bins, range=(min_dist, max_dist))
    
    # Compute histogram for outside values
    hist_out, _ = np.histogram(outside_values, bins=num_bins, range=(min_dist, max_dist))
    
    # Compute Reference Histograms (Baseline)
    # Mask the reference distance field with the reference volume itself.
    masked_ref_dist = dist_field_ref * reference_volume
    ref_inside_values = masked_ref_dist[masked_ref_dist < 0]
    ref_outside_values = masked_ref_dist[masked_ref_dist > 0]
    
    hist_ref_in, _ = np.histogram(ref_inside_values, bins=num_bins, range=(min_dist, max_dist))
    # Note: ref_outside_values will be empty because reference_volume masks out everything outside itself.
    # Thus, hist_ref_out is all zeros.
    
    # Step 4: Calculate Inside Score (EMD)
    # EMD between the test inside histogram and reference inside histogram.
    omega_in = earth_movers_distance(hist_in, hist_ref_in)
    
    # Step 5: Calculate Outside Score (Weighted Sum)
    # The source formula uses (n-i)^s.
    # i is the bin index (1-based).
    # A_out[i] is the count in the ith bin.
    
    numerator = 0.0
    denominator = 0.0
    
    for i in range(1, num_bins + 1):
        # Bin index i
        # Weight calculation based on source formula
        weight = (num_bins - i) ** s
        numerator += weight * hist_out[i - 1] # hist_out is 0-indexed in Python
        
        # Denominator is constant for a given n and s
        denominator += i ** s
        
    if denominator == 0:
        omega_out = 0.0
    else:
        omega_out = numerator / denominator
        
    return omega_in, omega_out

def compute_euclidean_distance_field(binary_volume):
    """
    Computes the signed Euclidean distance field for a binary volume.
    Returns a 3D array where:
    - 0 is on the surface.
    - Negative values are inside.
    - Positive values are outside.
    """
    # Implementation detail: Use scipy.ndimage.distance_transform_edt
    # or a similar library function.
    # [G] Standard library function assumed.
    from scipy.ndimage import distance_transform_edt
    
    # Get distance to nearest zero (outside) for inside voxels
    inside_mask = binary_volume == 1
    dist_inside = distance_transform_edt(~inside_mask)
    
    # Get distance to nearest one (inside) for outside voxels
    dist_outside = distance_transform_edt(inside_mask)
    
    # Combine into signed distance field
    # Inside: negative distance
    # Outside: positive distance
    sdf = np.where(inside_mask, -dist_inside, dist_outside)
    return sdf

def earth_movers_distance(hist1, hist2):
    """
    Computes the 1D Earth Mover's Distance between two histograms.
    """
    # [G] Standard EMD implementation for 1D histograms.
    # EMD is the minimum cost to transform one distribution into another.
    # For 1D, it is the L1 distance between the cumulative distribution functions.
    cdf1 = np.cumsum(hist1)
    cdf2 = np.cumsum(hist2)
    # Normalize CDFs to sum to 1
    cdf1 = cdf1 / cdf1[-1] if cdf1[-1] != 0 else cdf1
    cdf2 = cdf2 / cdf2[-1] if cdf2[-1] != 0 else cdf2
    
    # L1 distance between CDFs
    emd = np.sum(np.abs(cdf1 - cdf2))
    return emd
```

### Edge Cases and Pitfalls
*   **Undefined EMD for Outside Histograms:** The reference baseline outside histogram ($B_{out}$) consists entirely of zero-valued bins because the reference volume mask excludes all voxels outside the reference surface. Consequently, EMD cannot be used for the outside portion as it would be undefined or trivial. A weighted sum is used instead [S1].
*   **Precision:** The distance field computation requires sufficient precision to distinguish small variations near the boundary, which are critical for the inside score [S1].
*   **Bin Count:** The number of bins $n$ affects the resolution of the histogram. Too few bins may lose shape detail; too many may introduce noise [S1].

## Subtopics

### Histogram Distance Scoring
This variant specifically refers to the calculation of the $\omega_{in}$ and $\omega_{out}$ scores. $\omega_{in}$ uses Earth-Mover’s Distance to compare the interior distance distributions, while $\omega_{out}$ uses a weighted sum to penalize errors in the exterior region of the test volume relative to the expert's distance field. The weighting function $(n-i)^s$ ensures that errors further from the boundary (depending on bin ordering) are penalized according to the parameter $s$ [S1].

## Operating characteristics
*   **Time Complexity:** Dominated by the distance field generation ($O(V \log V)$ or $O(V)$ depending on implementation) and the EMD calculation ($O(n \log n)$ or $O(n)$ for 1D). Histogramming is $O(V)$.
*   **Memory Complexity:** Requires storage for the distance field ($O(V)$) and histograms ($O(n)$).
*   **Strengths:** Captures shape information effectively by using distance fields. The masking approach allows for comparing a test volume against a reference even if the test volume is smaller or incomplete. The use of EMD is robust to small shifts in the distribution compared to simple bin-wise differences [S1].
*   **Limitations:** Requires pre-processing to generate distance fields. The method is sensitive to the choice of binning and the parameter $s$. It is designed for binary volumes (occupied/empty) [S1].
*   **When to use:** Suitable for evaluating performance in virtual surgery or training scenarios where a resident's action (e.g., drilling) is compared to an expert's reference. It is less suitable for continuous scalar fields where mutual information might be more appropriate [S1].

## Background
The method was introduced in the context of virtual mastoidectomy performance evaluation [S1]. It was developed to provide a quantitative measure of the overlap between a resident's drilled cavity and an expert's drilled cavity. The approach was inspired by the work of Bruckner and Möller, who used distance fields and mutual information for isosurface comparison. However, this method diverges by using a masking strategy and Earth-Mover’s Distance to construct a high-dimensional feature vector for interactive visualization and analysis of multi-volume datasets [S1].
