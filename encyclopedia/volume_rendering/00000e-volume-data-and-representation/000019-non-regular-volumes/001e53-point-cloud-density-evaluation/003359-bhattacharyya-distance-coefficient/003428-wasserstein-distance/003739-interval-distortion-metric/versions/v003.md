# Interval Distortion Metric
Also called: Interval Distortion
## Overview
The Interval Distortion Metric computes the mean absolute distance between two uniform distributions defined by intervals $[t0_{lo}, t0_{hi}]$ and $[t1_{lo}, t1_{hi}]$ [S1, unofficial].
## How it works
### Inputs and Outputs
- **Inputs**: Two intervals, $I_0 = [t0_{lo}, t0_{hi}]$ and $I_1 = [t1_{lo}, t1_{hi}]$ [S1, unofficial].
- **Output**: A scalar value representing the mean absolute difference between the two uniform distributions [S1, unofficial].

### Data Structures
No complex data structures are required; the method operates on scalar values or vectors of interval endpoints [G].

### Steps
1. **Check for Disjoint Intervals**: Determine if the intervals are disjoint using the condition $t0_{lo} > t1_{hi}$ OR $t1_{lo} > t0_{hi}$ [S1, unofficial].
2. **Compute Distance for Disjoint Intervals**: If disjoint, compute the absolute difference between their midpoints: $d_{disjoint} = \left| \frac{t1_{lo} + t1_{hi}}{2} - \frac{t0_{lo} + t0_{hi}}{2} \right|$ [S1, unofficial].
3. **Compute Distance for Overlapping Intervals**: If not disjoint, compute the distance using the closed-form integral: $d_{overlap} = \frac{2 (\min(t0_{hi}, t1_{hi})^3 - \max(t0_{lo}, t1_{lo})^3) + 3 (t1_{hi} t0_{hi} |t1_{hi} - t0_{hi}| + t1_{lo} t0_{lo} |t1_{lo} - t0_{lo}| + t1_{hi} t0_{lo} (t0_{lo} - t1_{hi}) + t1_{lo} t0_{hi} (t1_{lo} - t0_{hi}))}{6 (t0_{hi} - t0_{lo}) (t1_{hi} - t1_{lo})}$ [S1, unofficial].
4. **Return Result**: Return $d_{disjoint}$ if disjoint, otherwise return $d_{overlap}$ [S1, unofficial].

### Pseudocode
```python
def interval_distortion(t0_lo, t0_hi, t1_lo, t1_hi):
    # Check if intervals are disjoint
    are_disjoint = (t0_lo > t1_hi) or (t1_lo > t0_hi)
    
    if are_disjoint:
        # Distance is the absolute difference between midpoints
        mid0 = (t0_lo + t0_hi) / 2.0
        mid1 = (t1_lo + t1_hi) / 2.0
        return abs(mid1 - mid0)
    else:
        # Overlapping case
        min_hi = min(t0_hi, t1_hi)
        max_lo = max(t0_lo, t1_lo)
        
        abs_diff_hi = abs(t1_hi - t0_hi)
        abs_diff_lo = abs(t1_lo - t0_lo)
        
        term1 = 2.0 * (min_hi**3 - max_lo**3)
        term2 = 3.0 * (t1_hi * t0_hi * abs_diff_hi + t1_lo * t0_lo * abs_diff_lo + t1_hi * t0_lo * (t0_lo - t1_hi) + t1_lo * t0_hi * (t1_lo - t0_hi))
        
        numerator = term1 + term2
        denominator = 6.0 * (t0_hi - t0_lo) * (t1_hi - t1_lo)
        
        # Guard for zero-width intervals (denominator == 0) [G]
        if denominator == 0.0:
            return 0.0
            
        return numerator / denominator
```

### Parameters and Edge Cases
- **Zero-width intervals**: If $t0_{hi} = t0_{lo}$ or $t1_{hi} = t1_{lo}$, the denominator in the overlapping formula becomes zero [S1, unofficial]. Not given in the sources. [G] A robust implementation should check for zero-width intervals and return 0 or the width of the non-degenerate interval.
