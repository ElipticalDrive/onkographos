# Wasserstein Distance
Also called: Wasserstein Distance Volumes, Wasserstein Distance for Volumes

## Overview
Computes the 1D Wasserstein distance between the distribution of voxel values inside a target object and those outside, serving as a shape and alignment metric for non-regular volumes [S1, unofficial]. It differs from its parent [Bhattacharyya Distance Coefficient](6998-bhattacharyya-distance-coefficient.md) by measuring the "cost" of transforming one distribution into another rather than their overlap integral, making it sensitive to the spatial displacement of intensity values [S1, unofficial].

## How it works
**Inputs:**
- `target`: 3D array of voxel values for the target object.
- `volume`: 3D array of background or reference voxel values.
- `mask`: Binary mask where `1` indicates the target object (derived from `target > 0`).

**Outputs:**
- `distance`: Scalar float representing the 1D Wasserstein distance.

**Data Structures:**
- `p`: 1D array of voxel values where `mask == 1`.
- `q`: 1D array of voxel values where `mask == 0`.
- `sorted_p`, `sorted_q`: Sorted versions of `p` and `q`.

**Steps:**
1. Flatten `target` and `volume` arrays into 1D vectors.
2. Create a binary mask `M` such that $M_i = 1$ if $target_i > 0$, else $0$.
3. Extract values inside the target: $p = \{target_i \mid M_i = 1\}$.
4. Extract values outside the target: $q = \{volume_i \mid M_i = 0\}$.
5. Sort $p$ and $q$ in ascending order to obtain empirical cumulative distribution functions (CDFs).
6. Compute the 1D Wasserstein distance (Earth Mover's Distance) between $p$ and $q$. For discrete distributions of equal size $N$, this is the mean absolute difference between the sorted values:
   $$ W_1(p, q) = \frac{1}{N} \sum_{i=1}^{N} |sorted\_p_i - sorted\_q_i| $$
   [S1, unofficial]

**Parameters:**
- Exponent $p$: Set to 1 for the standard Wasserstein distance (mean absolute difference) [S1, unofficial].

**Edge Cases:**
- If `p` or `q` is empty, the distance is undefined or should return infinity/NaN depending on implementation [G].
- Precision issues may arise if voxel values span several orders of magnitude; normalization may be required [G].

**Pseudocode:**
```python
def wasserstein_distance_volumes(target: Array, volume: Array) -> float:
    # Flatten inputs
    target_flat = target.flatten()
    volume_flat = volume.flatten()
    
    # Create binary mask for target > 0
    mask = (target_flat > 0).astype(float)
    
    # Extract voxel values inside (p) and outside (q) the target
    p = target_flat[mask == 1]
    q = volume_flat[mask == 0]
    
    # Handle edge case: empty distributions
    if len(p) == 0 or len(q) == 0:
        return float('nan') # Or raise error
        
    # Sort values to compute empirical CDFs
    sorted_p = np.sort(p)
    sorted_q = np.sort(q)
    
    # Ensure equal length for simple 1D Wasserstein calculation
    # Note: The source implies a direct comparison, often assuming 
    # equal number of samples or using interpolation for unequal sizes.
    # For equal sizes N:
    N = len(sorted_p)
    if len(sorted_q) != N:
        # Interpolate to match sizes if necessary, or use weighted sum
        # Simplified assumption for this method: resize or interpolate
        # [G] Implementation detail: resize q to match p's length via interpolation
        sorted_q = np.interp(np.linspace(0, 1, N), np.linspace(0, 1, len(sorted_q)), sorted_q)
        
    # Compute 1D Wasserstein distance (p=1)
    distance = np.mean(np.abs(sorted_p - sorted_q))
    
    return distance
```

## Subtopics

### [Interval Distortion Metric](7945-interval-distortion-metric.md)
The Interval Distortion Metric computes the mean absolute distance between two uniform distributions defined by intervals $[t0_{lo}, t0_{hi}]$ and $[t1_{lo}, t1_{hi}]$. It serves as a specific case of the Wasserstein Distance for 1D interval data, used to measure the alignment or shape difference between two sets of values. It is distinct from general Wasserstein implementations by providing a closed-form analytical solution that handles both disjoint and overlapping intervals efficiently.

### Histogram Matching via Wasserstein Distance
An optimization objective that minimizes the difference between rendered ($H'$) and reference ($H_{gt}$) histograms using the Wasserstein distance, computed via cumulative distribution functions (CDF) [S2]. It is used in differentiable rendering to match image statistics across scales [S2].

**Steps:**
1. Compute the CDF for both rendered and reference histograms at each pixel and scale [S2].
2. Calculate the error $E$ as the summation of point-wise errors between their CDFs over the domain [S2]:
   $$ E(\theta, \alpha, \beta, \sigma) = \int_{R^2} \int_0^1 |cdf_{H'}(x, k; \theta, \alpha, \beta, \sigma) - cdf_{H_{gt}}(x, k; \alpha, \beta, \sigma)|^{1/p} dk dx $$
   [S2]
3. Sum the errors $E$ over all scales ($\alpha, \beta, \sigma$) to get the total error $E_{total}$ [S2].

**Parameters:**
- $p$: Exponent for the Wasserstein distance; set to 1 in experiments [S2].

## Operating characteristics
- **Time Complexity:** Sorting the voxel values takes $O(N \log N)$ where $N$ is the number of voxels. The distance calculation is $O(N)$.
- **Memory Complexity:** $O(N)$ to store the extracted and sorted value arrays.
- **Strengths:** Provides a metric sensitive to the displacement of intensity values, unlike Bhattacharyya which measures overlap. Closed-form solution for 1D makes it computationally efficient [S1, unofficial].
- **Limitations:** Sensitive to the ordering of values; does not account for spatial structure within the volume directly, only the distribution of values [S1, unofficial].
- **When to use:** When aligning shapes or volumes based on intensity distribution similarity is required [S1, unofficial].

## Background
Originated in the context of inverse rendering for tomographic volumetric additive manufacturing, where it is used to compare the distribution of voxel values inside and outside a target object [S1, unofficial]. It is also applied in differentiable rendering for histogram matching to optimize image statistics [S2].
