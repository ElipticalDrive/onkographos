# Wasserstein Distance
Also called: Wasserstein Distance Volumes, Wasserstein Distance for Volumes

## Overview
Computes the 1D Wasserstein distance between the distribution of voxel values inside a target object and those outside, serving as a shape and alignment metric for non-regular volumes [S1, unofficial]. It differs from its parent [Bhattacharyya Distance Coefficient](6998-bhattacharyya-distance-coefficient.md) by comparing the full intensity distributions rather than their overlap integral [S1, unofficial].

## How it works
**Inputs:**
- `target`: 3D array of voxel values for the target object [S1, unofficial].
- `volume`: 3D array of background or reference voxel values [S1, unofficial].

**Outputs:**
- `distance`: Scalar float representing the 1D Wasserstein distance [S1, unofficial].

**Data Structures:**
- `p`: 1D array of voxel values where the target mask is active [S1, unofficial].
- `q`: 1D array of voxel values where the target mask is inactive [S1, unofficial].

**Steps:**
1. Flatten `target` and `volume` arrays into 1D vectors [S1, unofficial].
2. Create a binary mask `M` such that $M_i = 1$ if $target_i > 0$, else $0$ [S1, unofficial].
3. Extract values inside the target: $p = \{target_i \mid M_i = 1\}$ [S1, unofficial].
4. Extract values outside the target: $q = \{volume_i \mid M_i = 0\}$ [S1, unofficial].
5. Compute the 1D Wasserstein distance between the empirical distributions of $p$ and $q$ [S1, unofficial]. For discrete distributions of equal size $N$, this is the mean absolute difference between the sorted values:
   $$ W_1(p, q) = \frac{1}{N} \sum_{i=1}^{N} |p_{(i)} - q_{(i)}| $$

**Parameters:**
- Not given in the sources.

**Edge Cases:**
- If `p` or `q` is empty, the distance is undefined [G].
- If `p` and `q` have different lengths, interpolation or resampling is required to align the empirical CDFs before computing the distance [G].

**Pseudocode:**
```python
def wasserstein_distance_volumes(target: list, volume: list) -> float:
    # Flatten inputs
    target_flat = [v for row in target for v in row]
    volume_flat = [v for row in volume for v in row]
    
    # Create binary mask for target > 0
    mask = [1 if v > 0 else 0 for v in target_flat]
    
    # Extract voxel values inside (p) and outside (q) the target
    p = [target_flat[i] for i in range(len(target_flat)) if mask[i] == 1]
    q = [volume_flat[i] for i in range(len(volume_flat)) if mask[i] == 0]
    
    # Handle edge case: empty distributions
    if len(p) == 0 or len(q) == 0:
        return float('nan')
        
    # Sort values to compute empirical CDFs
    p_sorted = sorted(p)
    q_sorted = sorted(q)
    
    # Ensure equal length for simple 1D Wasserstein calculation
    N = len(p_sorted)
    if len(q_sorted) != N:
        # Interpolate q to match p's length
        q_sorted = [q_sorted[min(int(i * len(q_sorted) / N), len(q_sorted) - 1)] for i in range(N)]
        
    # Compute 1D Wasserstein distance
    distance = sum(abs(p_sorted[i] - q_sorted[i]) for i in range(N)) / N
    
    return distance
```

## Subtopics

### [Interval Distortion Metric](7945-interval-distortion-metric.md)
The Interval Distortion Metric computes the mean absolute distance between two uniform distributions defined by intervals $[t0_{lo}, t0_{hi}]$ and $[t1_{lo}, t1_{hi}]$. It serves as a specific case of the Wasserstein Distance for 1D interval data, used to measure the alignment or shape difference between two sets of values. It is distinct from general Wasserstein implementations by providing a closed-form analytical solution that handles both disjoint and overlapping intervals efficiently.

### Histogram Matching via Wasserstein Distance
An optimization objective that minimizes the difference between rendered ($H'$) and reference ($H_{gt}$) histograms using the Wasserstein distance, computed via cumulative distribution functions (CDF) [S2]. It is used in differentiable rendering to match image statistics across scales [S2].

**Steps:**
1. Compute the CDF for both rendered and reference histograms at each pixel and scale [S2].
2. Calculate the error $E$ as the summation of point-wise errors between their CDFs over the domain [S2]:
   $$ E(\theta, \alpha, \beta, \sigma) = \int_{R^2} \int_0^1 |cdf_{H'}(x, k; \theta, \alpha, \beta, \sigma) - cdf_{H_{gt}}(x, k; \alpha, \beta, \sigma)|^{1/p} dk dx $$
   [S2]
3. Sum the errors $E$ over all scales ($\alpha, \beta, \sigma$) to get the total error $E_{total}$ [S2].

**Parameters:**
- $p$: Exponent for the Wasserstein distance; set to 1 in experiments [S2].

## Background
Originated in the context of inverse rendering for tomographic volumetric additive manufacturing, where it is used to compare the distribution of voxel values inside and outside a target object [S1, unofficial]. It is also applied in differentiable rendering for histogram matching to optimize image statistics [S2].
