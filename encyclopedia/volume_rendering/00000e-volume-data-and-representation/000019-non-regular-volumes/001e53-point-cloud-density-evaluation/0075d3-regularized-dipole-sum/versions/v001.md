# Regularized Dipole Sum

Also called: dipole sum, regularized Poisson kernel sum

## Overview
The Regularized Dipole Sum is a scalar field representation for geometry and radiance defined as a weighted sum of regularized Poisson kernels centered at oriented point cloud locations [S1]. It solves the problem of robust geometry representation in inverse rendering by allowing learnable per-point attributes to model noise and outliers, unlike the standard winding number which uses fixed unit weights [S1]. It sets itself apart from its siblings by explicitly decoupling geometry modification from point location updates, enabling the suppression of outliers without moving the underlying points [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** An oriented point cloud $\mathbf{P} = \{(\mathbf{p}_m, \mathbf{n}_m, A_m)\}_{m=1}^M$, where $\mathbf{p}_m$ is the position, $\mathbf{n}_m$ is the normal, and $A_m$ is the area weight for point $m$. A regularization parameter $\varepsilon \ge 0$. A moment function with per-point samples $f_m$ for $m=1, \dots, M$.
*   **Output:** A scalar field $\widetilde{f}_\varepsilon(x)$ and the derived geometry field $F(x)$.

**Data Structures:**
*   **Point Cloud:** A list of $M$ points. Each point stores:
    *   $\mathbf{p}_m \in \mathbb{R}^3$: Position.
    *   $\mathbf{n}_m \in \mathbb{R}^3$: Normal vector.
    *   $A_m \in \mathbb{R}$: Area weight.
    *   $f_m \in \mathbb{R}$: Learnable geometry attribute.
*   **Regularization Parameter:** $\varepsilon \in \mathbb{R}_{\ge 0}$.

**Formulas:**
The regularized Poisson kernel $\mathbf{p}_\varepsilon(x, \mathbf{p}_m)$ is defined in the parent context (Equation 14 of [S1]). The Regularized Dipole Sum $\widetilde{f}_\varepsilon(x)$ is calculated as:

$$
\widetilde{f}_\varepsilon(x) \equiv \sum_{m=1}^M A_m \mathbf{p}_\varepsilon(x, \mathbf{p}_m) f_m \quad (17)
$$

The geometry field $F(x)$ is derived from the dipole sum:

$$
F(x) \equiv \frac{1}{2} - \widetilde{f}_\varepsilon(x) \quad (18)
$$

**Parameters:**
*   $f_m$: Learnable per-point geometry attribute.
    *   **Initialization:** $f_m = 1$ for all $m$. This initializes the field to equal the regularized winding number [S1].
    *   **Optimization:** $f_m$ is optimized during inverse rendering. Values decrease towards 0 to diminish outlier influence or adjust to correct noisy locations/holes [S1].
*   $\varepsilon$: Regularization parameter. $\varepsilon \ge 0$.

**Steps:**
1.  Initialize all geometry attributes $f_m = 1$ for $m=1, \dots, M$.
2.  For a query point $x$, compute the regularized Poisson kernel $\mathbf{p}_\varepsilon(x, \mathbf{p}_m)$ for each point $m$ in the cloud.
3.  Compute the weighted sum: $\widetilde{f}_\varepsilon(x) = \sum_{m=1}^M A_m \mathbf{p}_\varepsilon(x, \mathbf{p}_m) f_m$.
4.  Compute the geometry field: $F(x) = \frac{1}{2} - \widetilde{f}_\varepsilon(x)$.
5.  Convert $F(x)$ to vacancy $v$ and attenuation coefficient $\alpha$ using the methods defined in the parent context (Equations 3 and 4 of [S1]).
6.  During inverse rendering, optimize $f_m$ to update scene geometry. Decreasing $f_m$ reduces the influence of outliers; adjusting $f_m$ allows geometry correction without moving $\mathbf{p}_m$ [S1].

**Edge Cases and Pitfalls:**
*   **Outliers:** If $f_m$ is not optimized, outliers contribute fully. The method relies on optimization to set $f_m \approx 0$ for outliers [S1].
*   **Initialization:** Setting $f_m \neq 1$ initially deviates from the regularized winding number baseline [S1].
*   **Precision:** The sum involves $M$ terms. For large $M$, numerical stability may require careful summation order or the use of [Barnes-Hut Fast Summation](23364-barnes-hut-fast-summation.md) [S1].

## Subtopics

### [Barnes-Hut Fast Summation](23364-barnes-hut-fast-summation.md)
An algorithm that accelerates the evaluation of dipole sums by approximating distant clusters using a single centroid, reducing complexity from $O(N)$ to $O(\log N)$. Choose this when dealing with dense point clouds where naive summation is too slow.

## Operating characteristics
*   **Time Complexity:** Naive summation is $O(N)$ per query point, where $N$ is the number of points [S1]. With [Barnes-Hut Fast Summation](23364-barnes-hut-fast-summation.md), complexity reduces to $O(\log N)$ [S1].
*   **Memory Complexity:** $O(N)$ to store point attributes ($\mathbf{p}_m, \mathbf{n}_m, A_m, f_m$) [S1].
*   **Strengths:** Allows diminishing outlier influence by optimizing $f_m$; enables geometry modification (e.g., correcting holes) without moving points, which facilitates faster inverse rendering [S1].
*   **Limitations:** Requires optimization of $f_m$ during inverse rendering to achieve robustness against outliers [S1].
*   **When to use:** When robust geometry representation is needed in the presence of noisy or outlier point clouds, and when inverse rendering performance can benefit from fixed point locations [S1].
*   **When not to use:** When real-time evaluation of very dense point clouds is required without hierarchical acceleration [S1].

## Background
The Regularized Dipole Sum was introduced in "3D Reconstruction with Fast Dipole Sums" [S1]. It generalizes the point-cloud winding number by allowing non-unit weights $f_m$, addressing shortcomings of the standard winding number in handling noise and outliers [S1]. It is used in inverse rendering pipelines to define point-based geometry fields [S1].
