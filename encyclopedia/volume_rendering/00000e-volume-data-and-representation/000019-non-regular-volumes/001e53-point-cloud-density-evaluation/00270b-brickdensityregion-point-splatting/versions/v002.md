# BrickDensityRegion Point Splatting
## Overview
BrickDensityRegion Point Splatting maps point cloud data with location and O2 concentration attributes to a 3D voxel grid using normalization, threshold-based splat radii, and a distance-weighted kernel [S1, unofficial]. It differs from sibling methods like [Chamfer Distance](2446-chamfer-distance.md) or [Neighbor Counting](2905-neighbor-counting.md) by accumulating weighted density values into voxels rather than computing discrete metrics or occupancy counts [S1, unofficial].
## How it works
**Inputs:**
- Point cloud data containing location ($P$) and O2 concentration ($O_2$) [S1, unofficial].
- Volume resolution ($V_{res} = (X, Y, Z)$) [S1, unofficial].
- Minimum location ($minLoc$) and location difference ($locDiff$) for normalization [S1, unofficial].
- Minimum O2 concentration ($minO_2$) and O2 difference ($O_2diff$) for normalization [S1, unofficial].
- Density multiplier ($m\_density\_mult$) [S1, unofficial].
- Brick dimensions ($size\_x, size\_y, size\_z$) for boundary clamping [S1, unofficial].

**Outputs:**
- A 3D voxel grid where each voxel stores an accumulated density value [S1, unofficial].

**Data Structures:**
- **Voxel Grid:** A 3D array of floats indexed by $(i, j, k)$ [S1, unofficial].
- **Point:** Contains `getLocation()` (Vec3) and `getO2Concenration()` (float) [S1, unofficial].

**Algorithm Steps:**
1. **Normalize Point Location:** Calculate the normalized location $tmpLoc$ for a point $P$: $tmpLoc = (P - minLoc) / locDiff$ [S1, unofficial].
2. **Normalize O2 Concentration:** Calculate the normalized O2 value $tmpO_2$: $tmpO_2 = (O_2 - minO_2) / O_2diff$ [S1, unofficial].
3. **Map to Voxel Coordinates:** Determine the integer voxel coordinates $(end\_x, end\_y, end\_z)$: $end\_x = \lfloor tmpLoc.x \cdot X \rfloor$, $end\_y = \lfloor tmpLoc.y \cdot Y \rfloor$, $end\_z = \lfloor tmpLoc.z \cdot Z \rfloor$ [S1, unofficial].
4. **Calculate Base Density:** $end\_density = tmpO_2 \cdot m\_density\_mult$ [S1, unofficial].
5. **Determine Splat Radius ($splatVal$):** The splat radius is an integer determined by thresholds on $tmpO_2$: $0$ if $tmpO_2 < 0.4$, $1$ if $tmpO_2 < 0.6$, $2$ if $tmpO_2 < 0.9$, $3$ if $tmpO_2 < 0.95$, and $4$ otherwise [S1, unofficial].
6. **Boundary Check:** Only proceed if the voxel is strictly inside the grid boundaries: $1 < end\_x < X-2$, $1 < end\_y < Y-2$, and $1 < end\_z < Z-2$ [S1, unofficial].
7. **Splatting (Weighted Update):** Iterate over the cubic neighborhood defined by the splat radius, clamped to the brick boundaries, and update voxels with a distance-weighted contribution [S1, unofficial].

**Pseudocode:**
```python
def splat_point_to_brick(point, min_loc, loc_diff, min_o2, o2_diff, 
                         vol_res, density_mult, brick, brick_size):
    """
    point: object with getLocation() -> Vec3, getO2Concenration() -> float
    vol_res: Vec3 (X, Y, Z)
    brick: mutable 3D array of floats indexed by (i, j, k)
    brick_size: Vec3 (size_x, size_y, size_z)
    """
    # 1. Normalize location
    tmp_loc_x = (point.getLocation().x - min_loc.x) / loc_diff.x
    tmp_loc_y = (point.getLocation().y - min_loc.y) / loc_diff.y
    tmp_loc_z = (point.getLocation().z - min_loc.z) / loc_diff.z
    
    # 2. Normalize O2
    tmp_o2 = (point.getO2Concenration() - min_o2) / o2_diff
    
    # 3. Map to integer voxel coordinates
    end_x = int(tmp_loc_x * vol_res.x)
    end_y = int(tmp_loc_y * vol_res.y)
    end_z = int(tmp_loc_z * vol_res.z)
    
    # 4. Calculate base density
    base_density = tmp_o2 * density_mult
    
    # 5. Determine splat radius
    if tmp_o2 < 0.4:
        splat = 0
    elif tmp_o2 < 0.6:
        splat = 1
    elif tmp_o2 < 0.9:
        splat = 2
    elif tmp_o2 < 0.95:
        splat = 3
    else:
        splat = 4
        
    # 6. Boundary check: strictly between 1 and resolution-2
    if not (1 < end_x < vol_res.x - 2 and 
            1 < end_y < vol_res.y - 2 and 
            1 < end_z < vol_res.z - 2):
        return

    # 7. Splatting
    max_dist = (splat * splat * 3) ** 0.5
    
    start_x = max(0, end_x - splat)
    end_x_iter = min(brick_size.x - 1, end_x + splat)
    start_y = max(0, end_y - splat)
    end_y_iter = min(brick_size.y - 1, end_y + splat)
    start_z = max(0, end_z - splat)
    end_z_iter = min(brick_size.z - 1, end_z + splat)
    
    for i in range(start_x, end_x_iter + 1):
        for j in range(start_y, end_y_iter + 1):
            for k in range(start_z, end_z_iter + 1):
                dist = ((end_x - i)**2 + (end_y - j)**2 + (end_z - k)**2) ** 0.5
                if splat == 0:
                    contrib = 1.0
                else:
                    contrib = 1.0 - (dist / max_dist)
                brick[i, j, k] += base_density * contrib * contrib
```
## Subtopics

### BrickDensityRegion Splatting
This variant defines the splatting radius calculation as $max = \sqrt{splat^2 \cdot 3}$ and uses a linear falloff kernel $contrib = 1 - (dist / max)$ [S1, unofficial]. If the splat radius is $0$, the contribution is constant at $1$ [S1, unofficial]. The weight is squared ($contrib^2$) before being multiplied by the base density and added to the voxel [S1, unofficial].
