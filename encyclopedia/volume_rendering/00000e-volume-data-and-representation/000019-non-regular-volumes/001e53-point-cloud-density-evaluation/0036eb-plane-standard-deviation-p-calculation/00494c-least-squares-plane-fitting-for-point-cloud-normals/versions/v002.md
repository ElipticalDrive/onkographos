# Least Squares Plane Fitting for Point Cloud Normals

Also called: Local Surface Fitting for Normals, Normal estimation for point clouds, Point Cloud Normal Estimation via Least Squares

## Overview
This method estimates normal vectors for point cloud splats by fitting a least-squares plane to a local surface neighborhood, allowing splats to align with the object geometry [S1]. It operates on extracted clusters, using the cluster's estimated resolution to define the search radius [S1].

## How it works
**Inputs:** A set of extracted point clusters, where each cluster has an estimated resolution $r$ [S1].
**Outputs:** A normal vector $\mathbf{n}_i$ for each point $i$ in the cloud [G].

**Data Structures:**
*   **Point Cloud:** A list of points $P = \{p_1, p_2, ..., p_N\}$, where each $p_i \in \mathbb{R}^3$ [G].
*   **Neighborhood:** A subset of points $N_i \subset P$ within a search radius $R = 3r$ of point $p_i$ [S1].
*   **Covariance Matrix:** A $3 \times 3$ symmetric matrix $C_i$ computed from the coordinates in $N_i$ [G].

**Steps:**
1.  **Cluster Resolution Estimation:** Determine the resolution $r$ for the cluster containing point $p_i$ [S1].
2.  **Neighborhood Search:** Identify all points $p_j$ such that $\|p_j - p_i\| \le 3r$ [S1]. Let this set be $N_i$ with cardinality $k$ [G].
3.  **Centroid Calculation:** Compute the centroid $\mathbf{c}_i$ of the neighborhood:
    $$ \mathbf{c}_i = \frac{1}{k} \sum_{j \in N_i} p_j $$
    [G].
4.  **Covariance Matrix Construction:** Compute the $3 \times 3$ covariance matrix $C_i$:
    $$ C_i = \frac{1}{k} \sum_{j \in N_i} (p_j - \mathbf{c}_i)(p_j - \mathbf{c}_i)^T $$
    [G].
5.  **Eigenvalue Decomposition:** Perform eigenvalue decomposition on $C_i$ to find eigenvalues $\lambda_0 \le \lambda_1 \le \lambda_2$ and corresponding eigenvectors $\mathbf{v}_0, \mathbf{v}_1, \mathbf{v}_2$ [G].
6.  **Normal Selection:** The normal vector $\mathbf{n}_i$ is the eigenvector corresponding to the smallest eigenvalue $\lambda_0$:
    $$ \mathbf{n}_i = \mathbf{v}_0 $$
    [G].
7.  **Orientation Consistency (Optional but Recommended):** To ensure consistent normal orientation across the surface, compare $\mathbf{n}_i$ with the vector from the centroid to the point, and flip $\mathbf{n}_i$ if $\mathbf{n}_i \cdot (p_i - \mathbf{c}_i) < 0$ [G].

**Parameters:**
*   **Search Radius Multiplier:** 3 (i.e., radius $= 3r$) [S1].
*   **Minimum Neighbors:** Not given in the sources. Implementation should handle cases where $k < 3$ by assigning a default normal or skipping [G].

**Edge Cases and Pitfalls:**
*   **Degenerate Neighborhoods:** If all points in $N_i$ are collinear or coincident, the covariance matrix is singular and the normal is undefined [G]. A guard should check if $\lambda_0 \approx 0$ or if $k < 3$ [G].
*   **Boundary Effects:** Points on object boundaries may have asymmetric neighborhoods, leading to inaccurate normals [G].
*   **Precision:** Use double precision for covariance matrix computation to avoid numerical instability in eigenvalue decomposition [G].

**Pseudocode:**
```python
import numpy as np

def estimate_normals(points, cluster_resolutions):
    """
    points: Nx3 array of point coordinates
    cluster_resolutions: N array of resolution r for each point's cluster
    returns: Nx3 array of normal vectors
    """
    normals = np.zeros_like(points)
    N = len(points)
    for i in range(N):
        p_i = points[i]
        r = cluster_resolutions[i]
        radius = 3.0 * r
        dists = np.linalg.norm(points - p_i, axis=1)
        neighbor_indices = np.where(dists <= radius)[0]
        k = len(neighbor_indices)
        if k < 3:
            normals[i] = np.array([0.0, 0.0, 1.0])
            continue
        neighbors = points[neighbor_indices]
        centroid = np.mean(neighbors, axis=0)
        diff = neighbors - centroid
        C = np.dot(diff.T, diff) / k
        eigenvalues, eigenvectors = np.linalg.eigh(C)
        normal = eigenvectors[:, 0]
        if np.dot(normal, p_i - centroid) < 0:
            normal = -normal
        normals[i] = normal
    return normals
```

## Subtopics

### Normal Estimation with KdTree and OMP
This variant uses a KdTree for efficient neighborhood search and OpenMP for parallel processing [S2, unofficial]. It is implemented in the Point Cloud Library (PCL) as `NormalEstimationOMP` [S2, unofficial]. It configures the number of nearest neighbors (`kSearch`) to 20, rather than using a fixed radius [S2, unofficial].

## Background
The method is applied to each extracted cluster to estimate normal vectors for point cloud splats [S1]. It is implemented in the Point Cloud Library (PCL) by Rusu and Cousins [S1]. It is used in preprocessing steps for stroke-based splatting to ensure primitives align with the object's geometry [S1].
