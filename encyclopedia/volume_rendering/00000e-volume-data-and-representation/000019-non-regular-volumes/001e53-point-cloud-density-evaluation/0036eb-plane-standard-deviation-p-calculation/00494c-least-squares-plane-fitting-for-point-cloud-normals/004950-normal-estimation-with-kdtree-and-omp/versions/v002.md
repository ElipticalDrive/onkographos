# Normal Estimation with KdTree and OMP

Also called: PCL NormalEstimationOMP, Parallel KdTree Normal Estimation

## Overview
This method estimates surface normal vectors for a point cloud by performing parallel least-squares plane fitting within local neighborhoods defined by a KdTree search structure [S1, unofficial]. It builds on [Least Squares Plane Fitting for Point Cloud Normals](12472-least-squares-plane-fitting-for-point-cloud-normals.md) by parallelizing the neighborhood search and covariance computation steps using OpenMP [S1, unofficial].

## How it works
**Inputs:**
- `input_cloud`: A point cloud containing 3D coordinates ($x, y, z$) [S1, unofficial].
- `kSearch`: The number of nearest neighbors to consider for each point (default: 20) [S1, unofficial].

**Outputs:**
- `output_normals`: A point cloud where each point has an associated normal vector ($n_x, n_y, n_z$) [S1, unofficial].

**Data Structures:**
- `KdTree`: A spatial indexing structure storing the `input_cloud` to enable efficient neighbor queries [S1, unofficial].
- `NormalEstimationOMP`: The processing object that stores the input cloud, search method, and computed normals [S1, unofficial].

**Steps:**
1. **Preprocessing**: Remove NaN values from the input cloud if present [S1, unofficial].
2. **KdTree Construction**: Initialize a KdTree with the cleaned input cloud [S1, unofficial].
3. **Configuration**: Instantiate `NormalEstimationOMP`, set the input cloud and KdTree search method, and configure `kSearch` [S1, unofficial].
4. **Parallel Neighbor Search & Fitting**: For each point $P_i$, query the KdTree to find the $k$-nearest neighbors $N_i$ [S1, unofficial]. Compute the centroid $\mu$ of $N_i$ [G]. Construct the covariance matrix $C = \sum_{P_j \in N_i} (P_j - \mu)(P_j - \mu)^T$ [G]. Perform eigenvalue decomposition on $C$; the eigenvector corresponding to the smallest eigenvalue is the normal vector $n_i$ [G].
5. **Output**: Store the computed normal vectors in a `pcl::PointCloud<pcl::Normal>` structure [S1, unofficial].

**Parameters:**
- `kSearch`: Number of nearest neighbors. Typical value: 20 [S1, unofficial].

**Edge Cases:**
- **Sparse Regions**: If fewer than $k$ neighbors are found at boundaries, the method may produce inaccurate normals; a radius-based fallback is not specified in the sources [S1, unofficial].
- **Degenerate Geometry**: If points are collinear or coplanar, the covariance matrix may be singular; standard regularization is not detailed in the sources [S1, unofficial].

**Pseudocode:**
```python
import numpy as np
from scipy.spatial import KDTree

def remove_nan(cloud):
    """Filter out points containing NaN values."""
    return cloud[~np.isnan(cloud).any(axis=1)]

def estimate_normals_kdtree_omp(point_cloud, k_search=20):
    # 1. Preprocessing
    cloud = remove_nan(point_cloud)
    n_points = len(cloud)
    
    # 2. KdTree Construction
    kdtree = KDTree(cloud)
    
    # 3. Initialize output
    normals = np.zeros((n_points, 3))
    
    # 4. Parallel Loop (simulating OpenMP distribution)
    def process_point(i):
        point = cloud[i]
        # Query k-nearest neighbors
        distances, indices = kdtree.query(point, k=k_search)
        neighbors = cloud[indices]
        
        # Compute centroid
        centroid = np.mean(neighbors, axis=0)
        
        # Compute covariance matrix
        diff = neighbors - centroid
        cov_matrix = diff.T @ diff
        
        # Eigenvalue decomposition
        eigenvalues, eigenvectors = np.linalg.eigh(cov_matrix)
        
        # Normal is eigenvector with smallest eigenvalue
        normal = eigenvectors[:, np.argmin(eigenvalues)]
        return normal

    # Parallel execution simulation
    import concurrent.futures
    with concurrent.futures.ThreadPoolExecutor() as executor:
        results = list(executor.map(process_point, range(n_points)))
        normals = np.array(results)
        
    return normals
```

## Subtopics

### Planar Filter
A variant that estimates normals from a depth map rather than a point cloud [S2, unofficial]. It solves for local plane gradients ($Z_x, Z_y, Z_z$) at each pixel using a filter function to weight neighbors and regularization to enforce fronto-parallelism [S2, unofficial]. It is chosen when working with dense depth maps from stereo or structured light sensors where point cloud extraction is not the primary input [S2, unofficial].
- **Steps**: Compute coordinate grids by creating $x$ and $y$ meshgrids scaled to $\sim[0, 1]$ using `xy_scale = 2 / np.mean(xy_shape-1)` [S2, unofficial]. Apply `filt` to `[1, x, y, Z, x^2, xy, xZ, y^2, yZ]` to get `[F1, Fx, Fy, Fz, Fxx, Fxy, Fxz, Fyy, Fyz]` [S2, unofficial]. Construct matrix coefficients `A11, A22, A12, A13, A23, A33` using F terms, $x$, $y$, and $\epsilon^2$ [S2, unofficial]. Construct vector coefficients `b1, b2, b3` using `Fz`, $x$, $y$ [S2, unofficial]. Solve the linear system via `solve_image_ldl3` to obtain $Z_x, Z_y, Z_z$ [S2, unofficial]. Return `-Z_x*xy_scale, -Z_y*xy_scale, Z_z` [S2, unofficial].
- **Parameters**: `Z` (H $\times$ W depth map), `filt` (blurring function taking a linear non-negative combination of inputs), `eps` (regularization strength for fronto-parallel constraint) [S2, unofficial].
