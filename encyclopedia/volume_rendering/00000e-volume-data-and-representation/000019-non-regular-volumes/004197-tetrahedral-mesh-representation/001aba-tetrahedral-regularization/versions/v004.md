# Tetrahedral Regularization

Also called: Softplus Quality Regularizer

## Overview
Tetrahedral Regularization is a loss term added to the optimization of tetrahedral mesh vertex positions to prevent elements from becoming inverted (negative volume) or degenerate (volume approaching zero) [S1, unofficial]. It solves the problem of mesh validity during differentiable rendering optimization, where high learning rates or discontinuous fields can cause geometric collapse [S1, unofficial]. It sets itself apart from standard surface-only reconstruction methods by explicitly penalizing volumetric degeneracy [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of tetrahedra $T$, where each tetrahedron $t$ is defined by four vertex positions $p_0, p_1, p_2, p_3 \in \mathbb{R}^3$ [S1, unofficial].
*   **Output:** A scalar regularization loss value and its gradient with respect to the vertex positions [S1, unofficial].

**Data Structures:**
The method operates on the geometric properties of individual tetrahedra. No complex data structures are required beyond the vertex position arrays [G].

**Parameters:**
*   $\lambda$: Weight assigned to the regularization term in the complete loss function. Typical value: 10 [S1, unofficial].
*   $\beta$: Softplus parameter controlling the penalty shape. Typical values: 10 or 100. Higher values penalize slightly deformed tetrahedra less [S1, unofficial].

**Steps:**
1.  For each tetrahedron $t \in T$ with vertices $p_0, p_1, p_2, p_3$:
    a.  Compute the signed volume $V$ using the scalar triple product:
        $$V = \langle (p_3 - p_0), (p_1 - p_0) \times (p_2 - p_0) \rangle$$
        If $V \le 0$, the tetrahedron is inverted [S1, unofficial].
    b.  Compute the six edge lengths $l_i$ for $i=0..5$ between all pairs of vertices [S1, unofficial].
    c.  Compute the root-mean-square edge length $l_{rms}$:
        $$l_{rms} = \sqrt{\frac{1}{6} \sum_{i=0}^5 l_i^2}$$
    d.  Compute the quality measure $Q$:
        $$Q = 6\sqrt{2} \frac{V}{l_{rms}^3}$$
        This measure is smooth and approaches $-\infty$ for inverted tetrahedra and $0$ for degenerate ones [S1, unofficial].
    e.  Compute the Softplus penalty applied to $-Q$:
        $$\text{Softplus}(-Q) = \frac{1}{\beta} \log(1 + \exp(-\beta Q))$$
2.  Sum the penalties over all tetrahedra and scale by $\lambda$:
    $$\text{loss}_{\text{reg}} = \lambda \sum_{t \in T} \text{Softplus}(-Q(t))$$
3.  The total loss is:
    $$\text{loss} = \text{loss}_{\text{img}} + \text{loss}_{\text{reg}}$$

**Pseudocode:**
```python
import math

def dot(u, v):
    return u[0]*v[0] + u[1]*v[1] + u[2]*v[2]

def cross(u, v):
    return [u[1]*v[2] - u[2]*v[1], u[2]*v[0] - u[0]*v[2], u[0]*v[1] - u[1]*v[0]]

def sub(u, v):
    return [u[0]-v[0], u[1]-v[1], u[2]-v[2]]

def tetrahedral_regularization(vertices, tets, lambda_reg=10.0, beta=10.0):
    loss = 0.0
    grad_vertices = [[0.0, 0.0, 0.0] for _ in vertices]
    
    for tet in tets:
        p0, p1, p2, p3 = [vertices[i] for i in tet]
        
        # Vectors from p0
        v1 = sub(p1, p0)
        v2 = sub(p2, p0)
        v3 = sub(p3, p0)
        
        # Signed Volume V
        cross_v1_v2 = cross(v1, v2)
        V = dot(v3, cross_v1_v2)
        
        # Edge vectors
        edges = [v1, v2, v3, sub(p2, p1), sub(p3, p1), sub(p3, p2)]
        l_sq_sum = sum(dot(e, e) for e in edges)
        l_rms = math.sqrt(l_sq_sum / 6.0)
        
        # Quality Q
        if l_rms < 1e-8:
            Q = -1e8
        else:
            Q = 6.0 * math.sqrt(2.0) * V / (l_rms ** 3)
            
        # Softplus(-Q) penalty
        x = -Q
        if beta * x > 20:
            softplus_val = x
        else:
            softplus_val = (1.0 / beta) * math.log1p(math.exp(beta * x))
            
        loss += softplus_val
        
        # Gradient computation
        if l_rms < 1e-8:
            continue
            
        # d(Softplus(-Q))/dQ = -1 / (1 + exp(beta*Q))
        grad_softplus_dQ = -1.0 / (1.0 + math.exp(beta * Q))
        
        C = 6.0 * math.sqrt(2.0)
        dQ_dV = C / (l_rms ** 3)
        dQ_d_l_rms = -3.0 * C * V / (l_rms ** 4)
        
        # Gradients of V w.r.t vertices
        grad_V_p0 = sub(sub(cross(v3, v1), cross_v1_v2), cross(v3, v2))
        grad_V_p1 = cross(v3, v2)
        grad_V_p2 = cross(v1, v3)
        grad_V_p3 = cross_v1_v2
        
        # Gradients of l_rms w.r.t vertices
        # d(l_rms)/dp_k = (1/(3*l_rms)) * sum of outgoing edge vectors from p_k
        factor = 1.0 / (3.0 * l_rms)
        
        grad_l_rms_p0 = sub([0.0,0.0,0.0], [v1[0]+v2[0]+v3[0], v1[1]+v2[1]+v3[1], v1[2]+v2[2]+v3[2]])
        grad_l_rms_p0 = [f * factor for f in grad_l_rms_p0]
        
        e12, e13 = sub(p2, p1), sub(p3, p1)
        grad_l_rms_p1 = [v1[0]+e12[0]+e13[0], v1[1]+e12[1]+e13[1], v1[2]+e12[2]+e13[2]]
        grad_l_rms_p1 = [f * factor for f in grad_l_rms_p1]
        
        e21, e23 = sub(p1, p2), sub(p3, p2)
        grad_l_rms_p2 = [v2[0]+e21[0]+e23[0], v2[1]+e21[1]+e23[1], v2[2]+e21[2]+e23[2]]
        grad_l_rms_p2 = [f * factor for f in grad_l_rms_p2]
        
        e31, e32 = sub(p1, p3), sub(p2, p3)
        grad_l_rms_p3 = [v3[0]+e31[0]+e32[0], v3[1]+e31[1]+e32[1], v3[2]+e31[2]+e32[2]]
        grad_l_rms_p3 = [f * factor for f in grad_l_rms_p3]
        
        # Total grad Q
        grad_Q_p0 = [dQ_dV * grad_V_p0[i] + dQ_d_l_rms * grad_l_rms_p0[i] for i in range(3)]
        grad_Q_p1 = [dQ_dV * grad_V_p1[i] + dQ_d_l_rms * grad_l_rms_p1[i] for i in range(3)]
        grad_Q_p2 = [dQ_dV * grad_V_p2[i] + dQ_d_l_rms * grad_l_rms_p2[i] for i in range(3)]
        grad_Q_p3 = [dQ_dV * grad_V_p3[i] + dQ_d_l_rms * grad_l_rms_p3[i] for i in range(3)]
        
        scale = lambda_reg * grad_softplus_dQ
        for idx, g in zip(tet, [grad_Q_p0, grad_Q_p1, grad_Q_p2, grad_Q_p3]):
            grad_vertices[idx] = [grad_vertices[idx][i] + scale * g[i] for i in range(3)]
            
    return loss, grad_vertices
```

**Edge Cases and Pitfalls:**
*   **Inverted Tetrahedra:** If $V < 0$, the quality $Q$ becomes negative, triggering the Softplus penalty. This prevents self-intersections [S1, unofficial].
*   **Degenerate Tetrahedra:** If $V \to 0$ or $l_{rms} \to 0$, $Q \to 0$ or $-\infty$. The Softplus function provides a smooth penalty for these states [S1, unofficial].
*   **Numerical Stability:** Division by zero in $l_{rms}$ must be guarded [G]. The source notes that analytic derivatives are typically computed via SymPy and implemented in GLSL for GPU acceleration [S1, unofficial].
*   **Learning Rate:** High learning rates can cause rapid degeneration due to C0-continuity of the color field [S1, unofficial].

## Subtopics

### Shape Operator
The Shape Operator is a variant used in smoke volume rendering to suppress degenerated tetrahedra by weighting their contribution based on deviation from a regular tetrahedron [S2, unofficial]. It sets itself apart by modifying the effective density rather than just adding a loss term, making it suitable for advection-based simulations [S2, unofficial]. Choose it when rendering dynamic volumetric effects like smoke where mesh distortion occurs during advection [S2, unofficial].

**Definition:**
The shape operator compares the volume of a tetrahedron $T$ with the volume of a regular tetrahedron $T_R$ having the same longest edge length $a$ [S2, unofficial].

**Formula:**
$$\text{shape}(T) = \left( \frac{12}{\sqrt{2}} \frac{\text{vol}(T)}{a^3} \right)^s$$
where $\text{vol}(T_R) = \frac{\sqrt{2}}{12} a^3$ [S2, unofficial]. The term $\frac{T_s}{T_s}$ in the source notes appears to be a normalization factor for initial volume correction, effectively equal to 1 in the shape definition itself, but applied to the density [S2, unofficial].

**Effective Density:**
$$\sigma(T) = \frac{1}{|\text{vol}(T)|} \cdot T_s \cdot k \cdot \text{shape}(T)$$
where $k$ is a quality multiplier and $T_s$ is a correction factor for initial volume [S2, unofficial].

**Parameter:**
*   $s$: Exponent design parameter controlling the strength of the shape operation. Typical value: 0.5 [S2, unofficial].

### Hexagonal Mesh Regularization
Hexagonal Mesh Regularization enforces geometric constraints on hexagonal meshes to maintain surface quality during optimization. It sets itself apart by using a curvature loss that enforces equality of sides and centrosymmetry in hexagons [S3, unofficial]. Choose it when reconstructing surfaces from neural implicit representations where gradient steps pull on silhouettes without considering distortions [S3, unofficial].

**Step:**
To alter topology and increase resolution, an interpolation-based subdivision operation is used: a point is added at the midpoint of each edge. This produces four times the number of points and faces while maintaining hexagonal topology [S3, unofficial].

**Formula:**
$$L_h(S) = \sum_{i=1}^{n} \sum_{j=1}^{3} (2x_i - x_k - x'_{k'})^2$$
where $S$ represents vertices, $x_i$ is the coordinate of vertex $i$, and $x_k, x'_{k'}$ are coordinates of neighboring vertices defined by $N(e(v_j, v_i)) = e(v_{j+3}, v_i)$. The constraint enforces the equality of sides in hexagons [S3, unofficial].

**Parameter:**
*   Weight $\lambda_1 = 2$ for the hexagonal regularization loss $L_h$ in the initial phase, and $\lambda'_1 = 4$ in the later phase [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of tetrahedra, as each tetrahedron's quality is computed independently [G].
*   **Memory Complexity:** $O(1)$ auxiliary memory per tetrahedron [G].
*   **Performance:** The method is computationally lightweight compared to full remeshing. However, computing gradients for optimization can be expensive if not implemented with automatic differentiation or optimized shaders [S1, unofficial].
*   **Strengths:** Prevents mesh inversion and degeneracy during optimization; smooth differentiable penalty [S1, unofficial].
*   **Limitations:** Requires careful tuning of $\lambda$ and $\beta$; does not fix severely inverted meshes, only penalizes them; relies on the optimizer to correct the geometry [S1, unofficial].
*   **When to Use:** Differentiable tetrahedral volume rendering where mesh validity is critical for ray-element intersection [S1, unofficial].

## Background
Tetrahedral Regularization was introduced in the context of Differentiable Tetrahedral Volume Rendering (DiffTetVR) [S1, unofficial]. The quality measure $Q$ is attributed to Parthasarathy et al. [48] and discussed by Shewchuk [46, 47] for tetrahedral mesh quality assessment [S1, unofficial]. The method was developed to address the instability of vertex optimization in differentiable rendering pipelines [S1, unofficial].
