# Neural Volumetric Mesh Generator (NVMG) Evaluation & Regularization

Also called: NVMG Evaluation, NVMG Regularization

## Overview
This method defines the regularization loss terms and evaluation metrics used to ensure the geometric validity of tetrahedral meshes generated by the Neural Volumetric Mesh Generator (NVMG) [S1, unofficial]. It addresses inverted (negative volume) and degenerate (zero volume) tetrahedra, as well as self-intersecting surfaces, which occur during neural optimization of voxel-based representations [S1, unofficial]. It is distinguished from its parent [Tetrahedral Regularization](834-tetrahedral-regularization.md) by its specific combination of four loss components: surface, robust projection, orientation, and smooth terms, and its use of aspect ratio and oriented volume signs for quality assessment [S1, unofficial].

## How it works
The method operates within the NVMG pipeline for single-view shape reconstruction, image-to-mesh generation, and user-driven shape editing [S1, unofficial]. Its core consists of a composite loss function applied during optimization and specific metrics used to evaluate the resulting mesh quality [S1, unofficial].

### Inputs and Outputs
*   **Inputs:**
    *   Reconstructed tetrahedral mesh (vertices, connectivity) [S1, unofficial].
    *   Ground-truth surface (for evaluation) [S1, unofficial].
    *   Image features (extracted via ResNet-18) for image-conditional generation [S1, unofficial].
*   **Outputs:**
    *   Regularization loss values (Surface, Projection, Orientation, Smooth) [S1, unofficial].
    *   Quality metrics: Chamfer distance, count of flipped tetrahedra, count of distorted triangles [S1, unofficial].

### Data Structures
*   **Tetrahedron:** Defined by 4 vertices $v_1, v_2, v_3, v_4$ [S1, unofficial].
*   **Triangle:** Defined by 3 vertices [S1, unofficial].
*   **Oriented Volume:** Calculated for each tetrahedron to determine orientation [S1, unofficial].
*   **Aspect Ratio:** Calculated for each triangle to determine distortion [S1, unofficial].

### Formulas and Definitions

**1. Oriented Volume (Flip Detection)**
The sign of the oriented volume determines if a tetrahedron is flipped [S1, unofficial].
$$ V_{tet} = \det(v_2-v_1, v_3-v_1, v_4-v_1) $$
*   If $V_{tet} < 0$, the tetrahedron is flipped (inverted) [S1, unofficial].
*   If $V_{tet} \ge 0$, the orientation is valid [S1, unofficial].

**2. Aspect Ratio (Distortion Detection)**
The aspect ratio $AR$ of a triangle is used to flag distorted faces [S1, unofficial].
$$ AR = \frac{R}{2r} $$
Where:
*   $R$ is the circumradius of the triangle [S1, unofficial].
*   $r$ is the inradius of the triangle [S1, unofficial].
*   Triangles with $AR > 2.6$ are flagged as distorted [S1, unofficial].

**3. Regularization Loss Terms**
The total loss includes four components [S1, unofficial]:
*   **Surface Term:** Approximates the underlying surface [S1, unofficial].
*   **Robust Projection Term:** Reduces the number of distorted triangle faces [S1, unofficial].
*   **Orientation Term:** Penalizes volumes below a minimal threshold to prevent thin structures from vanishing and promotes physical feasibility [S1, unofficial]. It significantly reduces the number of flipped tetrahedra [S1, unofficial].
*   **Smooth Term:** Contributes to overall mesh smoothness [S1, unofficial].

*Note: The exact mathematical formulation of the loss terms is not provided in the sources, but their effects are described [S1, unofficial].*

### Pseudocode
```python
import math
import random

def evaluate_mesh_quality(mesh, ground_truth_surface):
    """
    Evaluates the quality of a reconstructed tetrahedral mesh.
    """
    flipped_tets = 0
    distorted_tris = 0

    # 1. Check for flipped tetrahedra
    for tet in mesh.tetrahedra:
        v1, v2, v3, v4 = tet.vertices
        # Calculate oriented volume: det(v2-v1, v3-v1, v4-v1)
        vol = determinant([v2-v1, v3-v1, v4-v1])
        if vol < 0:
            flipped_tets += 1

    # 2. Check for distorted triangles
    for tri in mesh.surface_triangles:
        v1, v2, v3 = tri.vertices
        a, b, c = length(v2-v1), length(v3-v2), length(v1-v3)
        s = (a + b + c) / 2.0
        area = math.sqrt(max(0, s * (s-a) * (s-b) * (s-c)))
        R = (a * b * c) / (4.0 * area) if area > 0 else float('inf')
        r = area / s if s > 0 else 0.0
        if r > 0:
            aspect_ratio = R / (2 * r)
            if aspect_ratio > 2.6:
                distorted_tris += 1
        else:
            distorted_tris += 1

    # 3. Calculate Chamfer Distance
    # Uniformly sample 10,000 points on the reconstructed mesh [S1, unofficial]
    sampled_points = uniform_sample_mesh(mesh, num_points=10000)
    chamfer_dist = compute_chamfer_distance(sampled_points, ground_truth_surface)

    return {
        "chamfer_distance": chamfer_dist,
        "flipped_tetrahedra_count": flipped_tets,
        "distorted_triangles_count": distorted_tris
    }

def compute_chamfer_distance(points_A, points_B):
    """
    Computes the Chamfer distance between two point sets.
    """
    # [G] Standard Chamfer distance: mean squared distance to nearest neighbors in both directions.
    dist_A_to_B = sum(min(distance(p, q)**2 for q in points_B) for p in points_A)
    dist_B_to_A = sum(min(distance(q, p)**2 for p in points_A) for q in points_B)
    return (dist_A_to_B / len(points_A)) + (dist_B_to_A / len(points_B))

def uniform_sample_mesh(mesh, num_points):
    """
    Uniformly samples points on the mesh surface proportional to triangle areas.
    """
    # [G] Standard uniform mesh sampling step.
    total_area = sum(triangle_area(tri) for tri in mesh.surface_triangles)
    points = []
    for tri in mesh.surface_triangles:
        v1, v2, v3 = tri.vertices
        area = triangle_area(tri)
        n_sample = max(1, int(num_points * area / total_area))
        for _ in range(n_sample):
            r1, r2 = random.random(), random.random()
            if r1 + r2 > 1:
                r1, r2 = 1 - r1, 1 - r2
            points.append(v1 + r1 * (v2 - v1) + r2 * (v3 - v1))
    return points[:num_points]

def triangle_area(tri):
    v1, v2, v3 = tri.vertices
    a, b, c = length(v2-v1), length(v3-v2), length(v1-v3)
    s = (a + b + c) / 2.0
    return math.sqrt(max(0, s * (s-a) * (s-b) * (s-c)))
```

### Parameters
*   **Aspect Ratio Threshold:** 2.6 [S1, unofficial].
*   **Sample Points for Evaluation:** 10,000 points uniformly sampled per mesh [S1, unofficial].
*   **Image Feature Extractor:** ResNet-18 [S1, unofficial].

### Edge Cases and Pitfalls
*   **Omission of Regularization:** Self-intersecting triangles and tetrahedra occur when regularization terms are omitted [S1, unofficial].
*   **Insufficient Regularization:** Using only the surface term yields good surface approximation but results in flipped tetrahedra and highly distorted faces [S1, unofficial].
*   **Thin Structures:** Without the orientation term, thin structures (e.g., chair legs) may vanish, reducing physical feasibility [S1, unofficial].
*   **Distorted Faces:** Without the robust projection term, the number of distorted triangle faces remains high [S1, unofficial].

## Subtopics

### [Volumetric Mesh Optimization Objective](10955-volumetric-mesh-optimization-objective.md)
The Volumetric Mesh Optimization Objective is a composite loss function used to regularize the geometry of tetrahedral meshes generated by neural networks, specifically within the Neural Volumetric Mesh Generator (NVMG) framework. It addresses the problem of generating high-quality, non-self-intersecting volumetric meshes from voxel-based representations by penalizing geometric distortions, orientation flips, and surface irregularities. It is distinguished from sibling methods by its explicit inclusion of an orientation preservation term based on the determinant of the tetrahedron transformation matrix and a Laplacian term that differentiates between volume and surface neighborhoods.

## Operating characteristics

    *   Chair: NVMG 0.471 vs. Best Baseline (DeepMesh) 0.514 [S1, unofficial].
    *   Table: NVMG 0.342 vs. Best Baseline (DeepMesh) 0.404 [S1, unofficial].
    *   Bench: NVMG 0.439 vs. Best Baseline (DeepMesh) 0.516 [S1, unofficial].
*   **Strengths:**
    *   Preserves shape details and thin geometric features better than baselines [S1, unofficial].
    *   Effectively prevents flipped tetrahedra and distorted faces when all regularization terms are used [S1, unofficial].
    *   Supports user-driven shape editing via voxel-based modification [S1, unofficial].
*   **Limitations:**
    *   Requires careful tuning of regularization weights (implied by ablation study) [S1, unofficial].
*   **When to Use:** Single-view shape reconstruction, image-to-mesh generation, and user-driven shape editing in 3D creation workflows [S1, unofficial].
