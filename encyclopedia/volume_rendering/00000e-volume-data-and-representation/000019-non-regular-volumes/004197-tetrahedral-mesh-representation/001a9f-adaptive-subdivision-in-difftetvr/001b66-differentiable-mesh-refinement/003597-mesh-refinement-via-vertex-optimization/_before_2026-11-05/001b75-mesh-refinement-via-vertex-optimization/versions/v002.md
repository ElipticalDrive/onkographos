# Mesh Refinement via Vertex Optimization


## Overview
Mesh Refinement via Vertex Optimization improves the geometric fidelity of a mesh by adjusting vertex positions to better fit an underlying occupancy field [S1, unofficial]. It distinguishes itself from grid-based refinement methods by operating directly on the mesh topology, using face subsampling to maintain computational efficiency during the optimization loop [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Initial mesh vertex positions $V_0$, latent code $c$, occupancy field representation, and optimization hyperparameters [S1, unofficial].
*   **Output:** Optimized vertex positions $V^*$ [S1, unofficial].

**Data Structures:**
*   **Vertex Parameters:** A PyTorch `torch.nn.Parameter` tensor initialized from $V_0$ [S1, unofficial].
*   **Face DataLoader:** A data structure batching faces for efficient processing [S1, unofficial].

**Steps:**
1.  **Initialization:** Create a trainable parameter for vertex positions: $v = \text{torch.nn.Parameter}(v_0.\text{clone}())$ [S1, unofficial].
2.  **Latent Detachment:** Detach the latent code $c$ from the computation graph to prevent gradient retention during this phase: $c = c.\text{detach}()$ [S1, unofficial].
3.  **Optimizer Setup:** Initialize an RMSprop optimizer for the vertex parameters with a learning rate of $1 \times 10^{-5}$: $\text{optimizer} = \text{optim.RMSprop}([v], \text{lr}=1\text{e-}5)$ [S1, unofficial].
4.  **Face Sampling:** Create a DataLoader for the mesh faces with a batch size of `refine_max_faces` and `shuffle=True` [S1, unofficial].
5.  **Optimization Loop:** Iterate for `refinement_step` iterations, processing batches of faces from the dataloader [S1, unofficial].

**Parameters:**
*   `refinement_step`: Number of optimization iterations. Default: 0 [S1, unofficial].
*   `refine_max_faces`: Maximum number of faces used as the batch size for refinement. Default: 10,000 [S1, unofficial].

## Subtopics

### [TetWeave Late-Stage Optimization](2583-tetweave-late-stage-optimization.md)
TetWeave Late-Stage Optimization is a differentiable refinement phase that adjusts the Signed Distance Field (SDF) values, point positions, and spherical harmonics (SH) coefficients of an existing tetrahedral mesh without modifying its topological structure. It distinguishes itself from earlier stages by decoupling geometry optimization from grid updates, relying instead on multi-view rendering losses (mask, depth, normal) and SDF regularization to polish the reconstruction. This method builds on [Mesh Refinement via Vertex Optimization](989-mesh-refinement-via-vertex-optimization.md) by operating on the final mesh representation derived from the optimized points and SDF.
