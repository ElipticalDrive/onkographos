# Recursive Subdivision


## Overview
Recursive Subdivision is a deterministic tetrahedral mesh generation and refinement technique for regular volume data [S1]. It recursively bisects tetrahedra by adding edge midpoints, following a fixed sequence of geometric cases (Step 1, Step 2, Step 3) to produce a hierarchical framework [S1]. Unlike octree decompositions that require complex stitching to handle resolution boundaries, this method guarantees conforming faces and well-shaped tetrahedra without element quality degradation during subdivision [S1, S1].

## How it works
**Inputs:**
*   A regular volume grid of dimensions $(2N+1) \times (2N+1) \times (2N+1)$ [S1].
*   An initial tetrahedral decomposition of the cubic domain [S1].

**Outputs:**
*   A hierarchical tetrahedral mesh where each tetrahedron can be further subdivided into two smaller tetrahedra [S1].
*   A set of Dividing Points (DP) added at selected edge midpoints [S1].

**Data Structures:**
*   **Vertex Index:** Each vertex in the grid is assigned a unique integer index to identify its position [S1]. For a vertex with grid coordinates $(i, j, k)$, the index is calculated as:
    $$ \text{Index} = i + j(2N + 1) + k(2N + 1)^2 $$
    where $N$ defines the grid size [S1].
*   **Dividing Point (DP):** A vertex added during subdivision, located at the midpoint of a selected edge [S1]. Its index equals the average of the indices of the two endpoints of the bisected edge [S1].

**Algorithm Steps:**
1.  **Initial Decomposition:** Generate the initial set of tetrahedra from the cubic domain [S1]. This initial subdivision produces 12 tetrahedra, all of which fall into Case 1 [S1].
2.  **Case Classification:** Classify each generated tetrahedron into one of three geometric configurations based on face and edge alignment relative to coordinate planes [S1]:
    *   **Case 1:** Exactly one face is parallel to a coordinate plane, and exactly one edge $L$ on that face is *not* parallel to any coordinate axis [S1].
    *   **Case 2:** Exactly one face is parallel to a coordinate plane, and exactly one edge $L$ on that face *is* parallel to a coordinate axis [S1].
    *   **Case 3:** Exactly two faces are parallel to coordinate planes, and edge $L$ is the edge that does *not* belong to either of these two faces [S1].
3.  **Bisection:** Select edge $L$ according to the tetrahedron's case [S1]. Compute the midpoint of $L$ as the Dividing Point (DP) [S1]. Bisect the tetrahedron into two new tetrahedra using the plane passing through the DP and the edge opposite to $L$ (the edge sharing no vertices with $L$) [S1].
4.  **Iteration Sequence:** The subdivision follows a strict cyclic order based on the resulting configuration of the new tetrahedra [S1]:
    *   **Step 1:** Perform subdivision for Case 1 [S1].
    *   **Step 2:** Perform subdivision for Case 2 [S1].
    *   **Step 3:** Perform subdivision for Case 3 [S1].
    *   **Cycle:** After the initial subdivision, all 12 tetrahedra are in Case 1, so Step 1 is performed first [S1]. After Step 1, newly generated tetrahedra fall into Case 2, triggering Step 2 [S1]. After Step 2, they fall into Case 3, triggering Step 3 [S1]. After Step 3, configurations recursively return to Case 1, repeating the cycle if further refinement is needed [S1].

**Pseudocode:**
```python
def recursive_subdivision(initial_tetrahedra, max_cycles):
    """
    Recursively subdivides tetrahedra using the deterministic Case/Step cycle.
    Args:
        initial_tetrahedra: List of Tetrahedron objects.
        max_cycles: Number of full Step 1-2-3 cycles to perform.
    Returns:
        List of refined Tetrahedron objects.
    """
    current_tets = initial_tetrahedra
    for cycle in range(max_cycles):
        next_tets = []
        # Cycle order: Step 1 -> Step 2 -> Step 3 -> Step 1 ...
        step = (cycle % 3) + 1
        for tet in current_tets:
            case = classify_case(tet)
            # Select edge L based on case
            if case == 1:
                edge_L = tet.get_edge_case_1()
            elif case == 2:
                edge_L = tet.get_edge_case_2()
            elif case == 3:
                edge_L = tet.get_edge_case_3()
            else:
                raise ValueError("Invalid tetrahedron configuration")

            # Compute midpoint (Dividing Point)
            v1, v2 = edge_L.vertices
            midpoint = Vertex((v1.x + v2.x) / 2.0, (v1.y + v2.y) / 2.0, (v1.z + v2.z) / 2.0)

            # Find opposite edge (shares no vertices with edge_L)
            opposite_edge = None
            for e in tet.get_edges():
                if e is not edge_L and not any(v in e.vertices for v in edge_L.vertices):
                    opposite_edge = e
                    break

            # Bisect into two new tetrahedra
            # Plane passes through midpoint and opposite_edge vertices
            o_v1, o_v2 = opposite_edge.vertices
            # New tetrahedra share the face formed by midpoint and opposite_edge
            new_tet_1 = Tetrahedron([midpoint, o_v1, o_v2, edge_L.vertices[0]])
            new_tet_2 = Tetrahedron([midpoint, o_v1, o_v2, edge_L.vertices[1]])
            next_tets.append(new_tet_1)
            next_tets.append(new_tet_2)
        current_tets = next_tets
    return current_tets

def classify_case(tet):
    """Classifies tetrahedron geometry relative to coordinate planes."""
    faces = tet.get_faces()
    parallel_faces = [f for f in faces if is_parallel_to_coord_plane(f)]
    count = len(parallel_faces)

    if count == 1:
        face = parallel_faces[0]
        face_edges = face.get_edges()
        non_parallel = [e for e in face_edges if not is_parallel_to_coord_axis(e)]
        parallel = [e for e in face_edges if is_parallel_to_coord_axis(e)]
        if len(non_parallel) == 1:
            return 1
        elif len(parallel) == 1:
            return 2
    elif count == 2:
        # Edge L is the one not belonging to either parallel face
        edges_in_parallel = set()
        for f in parallel_faces:
            for e in f.get_edges():
                edges_in_parallel.add(id(e))
        for e in tet.get_edges():
            if id(e) not in edges_in_parallel:
                return 3
    raise ValueError("Tetrahedron does not match Case 1, 2, or 3")

def is_parallel_to_coord_plane(face):
    n = face.normal()
    return (abs(n.x) > 0.9) or (abs(n.y) > 0.9) or (abs(n.z) > 0.9)

def is_parallel_to_coord_axis(edge):
    v = edge.vector()
    return (abs(v.x) > 0.9) or (abs(v.y) > 0.9) or (abs(v.z) > 0.9)
```

**Edge Cases and Pitfalls:**
*   **Termination:** The subdivision stops when all points of the original volume are added to the generated framework [S1]. For $N=1$ (a $3 \times 3 \times 3$ volume), this occurs after the initial subdivision, Step 1, and Step 2 [S1]. For $N=2$ (a $5 \times 5 \times 5$ volume), it requires Step 3, Step 1, and Step 2 [S1].
*   **Precision:** Floating-point arithmetic must preserve grid alignment for large $N$ to maintain the conforming boundary guarantee [G].
*   **Configuration Assumption:** The algorithm assumes the initial tetrahedra are in Case 1; deviating from the prescribed initial decomposition breaks the deterministic Step 1 $\rightarrow$ Step 2 $\rightarrow$ Step 3 cycle [S1].

## Subtopics

### Face-Block Finite State Machine
A finite state machine that tracks isosurface topology evolution across a face block containing a face saddle, using sequential vertex sweeps to generate and disambiguate topological cases [S2]. It subdivides the face block into four simple blocks via planes through the face saddle perpendicular to the face [S2]. Vertices on the $x=0$ plane receive the isovalue $f$ (face saddle), and points on the upper saddle plane receive values between $u$ and $l$ [S2]. The sweep starts at case 0; sweeping past vertex $0_{ul}$ or $0_{lu}$ generates case 1 in one sub-block and case 0 in three others, yielding overall case 1 [S2]. Sweeping past the other of $0_{lu}/0_{ul}$ generates Nielson's case 3.0 (two separate surfaces) [S2]. Sweeping past $f$ generates case 5 in two sub-blocks and case 8 in the other two, yielding overall case 3.1 (single tent-like surface) [S2]. Sweeping past $u$ generates cases $1^*C^*$, $2^*C^*$, $2^*C^*$, and 5, yielding overall case $1^*C^*$, and the sweep continues until case $0^*C^*$ is reached [S2]. This method uses the face saddle to disambiguate between topological cases 3.0 and 3.1, functioning identically to the Asymptotic Decider [S2].

## Operating characteristics
*   **Time Complexity:** Each tetrahedron is split into two in constant time $O(1)$ per split [S1]. The total number of tetrahedra grows exponentially with the number of subdivision steps [S1]. For a grid of size $N$, the number of steps required to include all grid points is limited (e.g., 5 steps for $N=2$) [S1].
*   **Memory Complexity:** Proportional to the number of tetrahedra in the final mesh [S1]. The source describes a full framework generation process rather than delta-based storage [S1].
*   **Strengths:** Guarantees high-quality tetrahedra (no degenerate elements) because the shape and quality are preserved after three subdivision cycles [S1]. Provides a systematic, deterministic refinement path without manual intervention [S1].
*   **Limitations:** The rigid case-based structure limits arbitrary error-driven refinement and assumes a regular grid input [S1].
*   **When to use:** When visualizing regular volume data requires a tetrahedral mesh with guaranteed element quality and hierarchical refinement capabilities [S1].
*   **When not to use:** For unstructured or irregular input data where the grid structure assumption does not hold, or when arbitrary anisotropic refinement is required without the constraint of maintaining the specific case cycle [S1].

## Background
Recursive Subdivision was introduced in the context of multiresolution tetrahedral frameworks for visualizing regular volume data [S1]. The method builds on Hebert's decomposition for finite element meshes [HEB94] and is specifically detailed in the paper "Multiresolution tetrahedral framework for visualizing regular volume data" [S1]. It is used for multiresolution visualization of regular volume data [S1].
