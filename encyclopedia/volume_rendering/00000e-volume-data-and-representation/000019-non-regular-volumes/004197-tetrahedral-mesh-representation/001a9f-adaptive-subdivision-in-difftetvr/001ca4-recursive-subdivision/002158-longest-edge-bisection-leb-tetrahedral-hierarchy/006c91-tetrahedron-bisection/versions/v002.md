# Tetrahedron Bisection

Also called: Recursive Bisection, Red-Refinement

## Overview
Tetrahedron bisection is a hierarchical subdivision method for non-regular volumes that recursively splits tetrahedra along their longest edge, starting from an initial decomposition of a cubic domain into six tetrahedra [S1]. It sets itself apart from sibling methods like [Supercube](18952-supercube.md) by producing a hierarchy where element quality is preserved through cyclic shape repetition, ensuring that recursive splitting yields well-shaped tetrahedra without degradation [Parent].

## How it works
**Inputs:** An initial cubic domain [S1].
**Outputs:** A hierarchical tetrahedral mesh defined by a base mesh and a set of conforming updates [S1].

**Data Structures:**
The hierarchy is defined by a base mesh $\mathcal{M}_b$ and a set of updates $U$ [S1]. Each update $u$ is a pair $(\mathcal{F}_1, \mathcal{F}_2)$, where $\mathcal{F}_1$ is a tetrahedral cluster (tetrahedra to be removed) and $\mathcal{F}_2$ is a split-set (tetrahedra to be inserted) [S1].

**Steps:**
1. **Initial Decomposition:** Decompose the cubic domain into six initial tetrahedra. These six tetrahedra are all of shape "1/8 pyramid" [S1].
2. **Recursive Bisection:** For any tetrahedron in the mesh, identify its longest edge. Bisect the tetrahedron by cutting along the plane passing through the midpoint of the longest edge and the opposite edge [S1].
3. **Shape Classification:** Regardless of the number of recursive splits, the resulting tetrahedra fall into one of three cyclic shapes [S1]:
    * **1/2 Pyramid:** Obtained by splitting a 1/8 pyramid (or initial tetrahedron) along its longest edge [S1].
    * **1/4 Pyramid:** Obtained by splitting a 1/2 pyramid along its longest edge [S1].
    * **1/8 Pyramid:** Obtained by splitting a 1/4 pyramid along its longest edge. This shape is geometrically similar to the initial tetrahedra [S1].
    * Every three levels of decomposition result in a geometrically similar shape [S1].
4. **Non-Conforming Updates:** A single bisection is a non-conforming update [S1].
5. **Cluster Formation (Conforming Updates):** To maintain mesh conformity, non-conforming updates are merged into clusters. A cluster is a minimal set of non-conforming updates whose union is a conforming update [S1]. Clustering is performed by grouping tetrahedra along their splitting edge [S1]. There are three types of clusters [S1]:
    * **Axis-aligned cluster:** Formed by eight 1/2 pyramids sharing an axis-aligned edge. Cluster size ($\mathcal{F}_1$): 4 tetrahedra. Split-set size ($\mathcal{F}_2$): 8 tetrahedra.
    * **Plane-aligned cluster:** Formed by four 1/4 pyramids sharing a plane-aligned edge (parallel to a coordinate plane). Cluster size ($\mathcal{F}_1$): 6 tetrahedra. Split-set size ($\mathcal{F}_2$): 12 tetrahedra.
    * **Non-aligned cluster:** Formed by twelve 1/8 pyramids sharing an edge not aligned to a coordinate axis or plane. Cluster size ($\mathcal{F}_1$): 8 tetrahedra. Split-set size ($\mathcal{F}_2$): 16 tetrahedra.
6. **Average Cost:** On average, six tetrahedra are added by an update [S1].

**Pseudocode:**
```python
def bisection(tet):
    # tet is a list of 4 vertices (each a 3D vector)
    # 1. Identify longest edge
    edges = [(tet[0], tet[1]), (tet[0], tet[2]), (tet[0], tet[3]),
             (tet[1], tet[2]), (tet[1], tet[3]), (tet[2], tet[3])]
    longest = max(edges, key=lambda e: norm(e[1] - e[0]))
    # 2. Midpoint of longest edge
    mid = (longest[0] + longest[1]) / 2.0
    # 3. Identify opposite edge (vertices not in longest)
    longest_ids = {id(longest[0]), id(longest[1])}
    opp_verts = [v for v in tet if id(v) not in longest_ids]
    # 4. Split along plane through mid and opposite edge
    # The plane divides the original tet into two new tets
    tet1 = [opp_verts[0], opp_verts[1], longest[0], mid]
    tet2 = [opp_verts[0], opp_verts[1], longest[1], mid]
    return tet1, tet2
```

## Subtopics

### Cluster Formation
A conforming update formed by merging a set of non-conforming updates such that their union is conforming and no proper subset is [S1]. It is chosen when mesh conformity is required after multiple bisections. The type (axis-aligned, plane-aligned, or non-aligned) depends on the geometric alignment of the splitting edges of the merged tetrahedra [S1]. For tetrahedron bisection, conforming updates are defined by clustering tetrahedra along their splitting edge [S1]. Axis-aligned clusters consist of eight 1/2 pyramids sharing an axis-aligned edge, with first component size 4 and second component size 8 tetrahedra [S1]. Plane-aligned clusters consist of four 1/4 pyramids sharing a plane-aligned edge, with first component size 6 and second component size 12 tetrahedra [S1]. Non-aligned clusters consist of twelve 1/8 pyramids sharing a non-aligned edge, with first component size 8 and second component size 16 tetrahedra [S1].

## Operating characteristics
**Time and Memory Complexity:** Not given in the sources [S1].
**Measured Performance:** Not given in the sources [S1].
**Scaling:** The hierarchy ensures that element quality does not degrade because recursively splitting a tetrahedron three times yields smaller tetrahedra with exactly the same shape and quality as the initial one [Parent].
**Strengths:** Produces only well-shaped tetrahedra; preserves geometric similarity over cycles of three levels [Parent, S1].
**Limitations:** Single bisections are non-conforming, requiring clustering logic to maintain valid mesh topology [S1].

## Background
The method originates from the analysis of multiresolution tetrahedral meshes presented by [S1] in 2002. It is used in the context of hierarchical tetrahedral (HT) meshes to generate multi-resolution representations [S1].
