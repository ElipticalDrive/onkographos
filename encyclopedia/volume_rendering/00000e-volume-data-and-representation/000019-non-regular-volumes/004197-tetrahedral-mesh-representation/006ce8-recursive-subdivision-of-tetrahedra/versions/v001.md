# Recursive Subdivision of Tetrahedra

Also called: Hierarchical Tetrahedral Meshing, Implicit Subdivision

## Overview
Recursive Subdivision of Tetrahedra is a technique for generating high-resolution tetrahedral meshes from a coarse base mesh without explicitly storing the refined geometry [S1]. It solves the memory and complexity constraints of storing dense unstructured meshes by implicitly defining the mesh hierarchy through a fixed subdivision pattern [S1]. Unlike explicit mesh representations, this method allows for efficient multi-resolution feature encoding and on-the-fly sampling, making it suitable for deformation and animation tasks where memory usage must be minimized [S1].

## How it works
**Inputs:**
*   A coarse tetrahedral mesh defined by vertices $\mathbf{v}_i^\ell$ at level $\ell$.
*   A sampling point $\mathbf{p}$ in 3D space.
*   The total number of subdivision levels $L$ [S1].

**Outputs:**
*   The barycentric coordinates $\boldsymbol{\alpha}^{\ell+1}$ of the point $\mathbf{p}$ within the specific child tetrahedron at level $\ell+1$ [S1].
*   The vertex indices or positions of the child tetrahedron containing $\mathbf{p}$ [S1].

**Data Structures:**
*   **Coarse Mesh:** Stores vertex positions $\mathbf{v}_i^\ell \in \mathbb{R}^3$ for the base level $\ell=0$.
*   **Subdivision Pattern:** A fixed, uniform pattern for connecting edge midpoints. The pattern is applied identically to all tetrahedra [S1].
*   **Coefficient Matrices ($C_k$):** Eight $4 \times 4$ constant matrices, one for each child configuration $k \in \{0, \dots, 7\}$, mapping parent barycentric coordinates to child barycentric coordinates [S1].

**Algorithm Steps:**

1.  **Initialization:** Start with the coarse mesh at level $\ell=0$. For a query point $\mathbf{p}$, determine its initial barycentric coordinates $\boldsymbol{\alpha}^0 = (\alpha_0^0, \alpha_1^0, \alpha_2^0, \alpha_3^0)$ relative to the containing tetrahedron in the coarse mesh. If $\mathbf{p}$ is not in the coarse mesh, the method is undefined for that point [S1].

2.  **Recursive Subdivision Loop:** For each level $\ell$ from $0$ to $L-1$:
    a.  **Identify Child Configuration:** Determine which of the eight child tetrahedra contains $\mathbf{p}$ based on the current barycentric coordinates $\boldsymbol{\alpha}^\ell$.
        *   **Corner Check:** If any $\alpha_i^\ell > 0.5$, the point is in a corner child. The specific corner index $i$ identifies the child [S1].
        *   **Boundary Check:** If any $\alpha_i^\ell = 0.5$, the point lies on a shared face between two adjacent child tetrahedra. Assign the point to either adjacent tetrahedron; the result is unaffected [S1].
        *   **Central Check:** If all $\alpha_i^\ell < 0.5$, the point is in one of the four central children. Determine the specific child by evaluating the sums:
            *   If $\alpha_1^\ell + \alpha_2^\ell > 0.5$ and $\alpha_2^\ell + \alpha_3^\ell > 0.5$, the child is identified by configuration $k_1$ [S1].
            *   If $\alpha_1^\ell + \alpha_2^\ell \le 0.5$ and $\alpha_2^\ell + \alpha_3^\ell \le 0.5$, the child is identified by configuration $k_2$ [S1].
            *   The remaining two central configurations are determined by the mixed cases ($\alpha_1^\ell + \alpha_2^\ell > 0.5$ and $\alpha_2^\ell + \alpha_3^\ell \le 0.5$, or vice versa) [S1].
            *   *Note:* The exact mapping of these sum conditions to indices $k \in \{0, \dots, 7\}$ depends on the specific uniform subdivision pattern chosen. The supplementary material of [S1] provides the detailed criteria for the specific pattern used in DeformRF [S1].
    b.  **Update Coordinates:** Once the child index $k$ is identified, compute the barycentric coordinates for the next level using the pre-determined constant coefficient matrix $C_k$:
        $$ \boldsymbol{\alpha}^{\ell+1} = C_k \boldsymbol{\alpha}^\ell $$
        where $\boldsymbol{\alpha}^{\ell+1} = (\alpha_0^{\ell+1}, \alpha_1^{\ell+1}, \alpha_2^{\ell+1}, \alpha_3^{\ell+1})$ [S1].

3.  **Feature Sampling:** After $L$ levels, the final barycentric coordinates $\boldsymbol{\alpha}^L$ and the vertex positions of the finest-level child tetrahedron are used to interpolate features. The position $\mathbf{p}$ is consistent with the representation:
    $$ \mathbf{p} = \sum_{i=0}^{3} \alpha_i^\ell \mathbf{v}_i^\ell $$
    This holds for any level $\ell$ if the vertices $\mathbf{v}_i^\ell$ are the vertices of the tetrahedron at that level containing $\mathbf{p}$ [S1].

**Pseudocode:**

```python
def get_child_index(alpha, pattern_config):
    """
    Determines the index k in {0..7} of the child tetrahedron containing the point.
    alpha: tuple of 4 barycentric coordinates (a0, a1, a2, a3)
    pattern_config: defines the specific mapping of conditions to indices 0-7.
                    This must be derived from the specific subdivision pattern in [S1].
    """
    a0, a1, a2, a3 = alpha
    
    # Check for boundary cases (alpha == 0.5)
    # If any alpha is exactly 0.5, the point is on a shared face.
    # Assign to either adjacent tetrahedron. For deterministic implementation,
    # we can pick the lower index or a fixed rule.
    if abs(a0 - 0.5) < 1e-9 or abs(a1 - 0.5) < 1e-9 or \
       abs(a2 - 0.5) < 1e-9 or abs(a3 - 0.5) < 1e-9:
        # Return a valid index for the boundary case. 
        # The exact index depends on the pattern, but the feature value is invariant.
        # Here we return 0 as a placeholder for the boundary assignment.
        return 0 

    # Check for corner cases (alpha > 0.5)
    if a0 > 0.5: return pattern_config['corner_0']
    if a1 > 0.5: return pattern_config['corner_1']
    if a2 > 0.5: return pattern_config['corner_2']
    if a3 > 0.5: return pattern_config['corner_3']

    # All alpha < 0.5: Central children
    sum12 = a1 + a2
    sum23 = a2 + a3
    
    if sum12 > 0.5 and sum23 > 0.5:
        return pattern_config['center_1']
    elif sum12 <= 0.5 and sum23 <= 0.5:
        return pattern_config['center_2']
    elif sum12 > 0.5 and sum23 <= 0.5:
        return pattern_config['center_3']
    else: # sum12 <= 0.5 and sum23 > 0.5
        return pattern_config['center_4']

def recursive_subdivision_step(alpha, C_matrices, pattern_config):
    """
    Performs one level of recursive subdivision.
    alpha: current barycentric coordinates
    C_matrices: list of 8 matrices (4x4) for each child k
    pattern_config: mapping from conditions to child indices
    """
    k = get_child_index(alpha, pattern_config)
    C_k = C_matrices[k]
    
    # Matrix multiplication: alpha_new = C_k * alpha
    # alpha is a column vector
    alpha_new = [0.0] * 4
    for i in range(4):
        sum_val = 0.0
        for j in range(4):
            sum_val += C_k[i][j] * alpha[j]
        alpha_new[i] = sum_val
        
    return alpha_new, k

def sample_point(p, coarse_mesh_vertices, L, C_matrices, pattern_config):
    """
    Samples features at point p using recursive subdivision.
    p: 3D point
    coarse_mesh_vertices: list of vertices for the coarse mesh
    L: total number of levels
    """
    # 1. Find containing tetrahedron in coarse mesh and compute initial alpha
    # This step requires a point-in-tetrahedron test and barycentric calculation.
    # Not detailed in [S1], but required as input to the recursion.
    tet_idx, alpha = find_containing_tetrahedron_and_barycentrics(p, coarse_mesh_vertices)
    
    # 2. Recursively subdivide
    current_alpha = alpha
    for level in range(L):
        current_alpha, child_k = recursive_subdivision_step(current_alpha, C_matrices, pattern_config)
        
    # 3. The final alpha corresponds to the position within the finest-level child tetrahedron.
    # To get features, one would look up the vertices of this finest tetrahedron
    # and interpolate using current_alpha.
    # The vertices of the finest tetrahedron can be computed from the coarse vertices
    # and the sequence of child indices, or looked up if stored in a hash table [S1].
    
    return current_alpha, child_k
```

**Parameters:**
*   $L$: Total number of levels in the subdivision hierarchy, including the initial coarse mesh level and the total number of subdivision levels [S1].

**Edge Cases and Pitfalls:**
*   **Boundary Points:** If a sampling point lies exactly on a shared face between two child tetrahedra (i.e., some $\alpha_i^\ell = 0.5$), it can be assigned to either adjacent tetrahedron without affecting the final feature interpolation result [S1].
*   **Precision:** Floating-point precision issues may arise when checking $\alpha_i^\ell = 0.5$ or $\alpha_i^\ell > 0.5$. A small epsilon should be used for comparisons [G].
*   **Subdivision Pattern:** The method relies on a specific, uniform subdivision pattern. The exact mapping of barycentric conditions to child indices $k$ depends on this pattern. The supplementary material of [S1] provides the detailed criteria for the pattern used in DeformRF [S1].

## Operating characteristics
*   **Memory:** Significantly reduces memory usage compared to storing explicit high-resolution meshes, as only the coarse mesh and hash tables for features are stored [S1].
*   **Time Complexity:** Sampling a point requires $O(L)$ operations, where $L$ is the number of subdivision levels. Each level involves a constant number of arithmetic operations to determine the child index and update barycentric coordinates [S1].
*   **Scalability:** Enables high-resolution representation by increasing $L$ without increasing storage costs linearly with resolution [S1].
*   **Strengths:** Efficient multi-resolution feature encoding, seamless integration with neural representations (e.g., Instant-NGP hash tables), and support for deformation and animation [S1].
*   **Limitations:** Requires a specific uniform subdivision pattern; the mapping of conditions to child indices is non-trivial and pattern-dependent [S1].

## Background
The method was introduced in the context of DeformRF, a framework that combines the manipulability of tetrahedral meshes with the high-quality rendering capabilities of feature grid representations [S1]. It was designed to bypass complex and resource-intensive tetrahedralization processes while maintaining high-fidelity rendering [S1]. The approach is inspired by the efficient encoding strategy of Instant-NGP, adapting it to multi-resolution tetrahedral meshes [S1].
