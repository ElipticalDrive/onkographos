# Hierarchical Wavelet Transform on Omnitrees

Also called: Moment-conserving anisotropic compression, Wavelet compression on omnitrees

## Overview
This method transforms nodal omnitree data into wavelet coefficients to enable lossless or lossy compression via pruning and tree restructuring (downsplit) [S1]. It operates directly on the omnitree's anisotropic structure, allowing coarsening in specific dimensions while preserving the hierarchical spatial layout [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** An omnitree where each node $v$ has a splitting label $\vec{b}(v)$, refined dimensions $\sigma(v)$, and nodal coefficients (scaling values) $w_{c \emptyset}$ for its children $c$, ordered in Z-order [S1].
*   **Output:** A set of wavelet coefficients $\vec{w}^v$ for all non-leaf nodes, and a root scaling coefficient $w_\theta^{\text{root}}$ [S1].

**Data Structures:**
*   **Omnitree Node:** Contains splitting label $\vec{b}(v)$, refined dimensions $\sigma(v)$, and a list of child nodes [S1].
*   **Scaling Vector $\vec{s}^v$:** A vector of size $2^{|\sigma(v)|}$ containing the nodal coefficients of the children of node $v$, arranged in Z-order [S1].
*   **Wavelet Vector $\vec{w}^v$:** A vector of size $2^{|\sigma(v)|}$ arranged in a compatible order to $\vec{s}^v$ [S1].

**Algorithm Steps:**
1.  **Gather Scaling Coefficients:** For each node $v$, gather the nodal coefficients of its children into vector $\vec{s}^v$ [S1].
2.  **Local Transformation (Bottom-Up):** Process nodes from leaves to root [S1]. For each node $v$ with refined dimensions $\sigma(v)$:
    *   Compute the local transformation matrix $H_{|\sigma(v)|}$ [S1].
    *   Compute wavelet coefficients: $\vec{w}^v = H_{|\sigma(v)|} \cdot \vec{s}^v$ [S1].
    *   The first element of $\vec{w}^v$ is the scaling coefficient for the parent; the remaining elements are detail coefficients [S1].
    *   Store the computed wavelet coefficients in the node [S1].
3.  **Reconstruction (Top-Down):** To reconstruct nodal values, apply the inverse transformation successively from larger to finer scales (root down to leaves) [S1].
    *   Start at the root. The root scaling coefficient $w_\theta^{\text{root}}$ holds the mean value [S1].
    *   For each node $v$ from root to leaves:
        *   Retrieve the wavelet coefficients $\vec{w}^v$ [S1].
        *   Compute the inverse transformation matrix $R_{|\sigma(v)|} = H_{|\sigma(v)|}^{-1}$ [S1].
        *   Reconstruct scaling coefficients for children: $\vec{s}^v = R_{|\sigma(v)|} \cdot \vec{w}^v$ [S1].
        *   Distribute these values to the children's nodal coefficients [S1].

**Formulas:**
The wavelet coefficients are computed by:
$$ \vec{w}^v = H_{|\sigma(v)|} \cdot \vec{s}^v \quad (10) $$
where $H_{|\sigma(v)|}$ is the hierarchization matrix [S1]. For Haar wavelets:
$$ H_{|\sigma(v)|} = \frac{1}{2^{|\sigma(v)|}} \bigotimes_{j \in \sigma(v)} \begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix} \quad (11) $$
The function $f$ is represented as:
$$ f = w_\theta^{\text{root}} + \sum_{v: \text{nonleaf}} \sum_{\emptyset \neq \tau \subset \sigma(v)} w_\tau^v \cdot \psi_\tau^v \quad (12) $$
where $\psi_\tau^v$ are the wavelet basis functions [S1]. The inverse transformation satisfies $R_{|\sigma(v)|} H_{|\sigma(v)|} = I$ [S1].

**Parameters:**
*   **Wavelet Type:** Haar wavelets are specified [S1].
*   **Normalization:** The matrix includes a factor of $1/2^{|\sigma(v)|}$ [S1].

**Edge Cases and Pitfalls:**
*   **Leaf Nodes:** Leaf nodes have no children, so no transformation is applied. They store scaling coefficients directly [S1].
*   **Root Node:** The root scaling coefficient represents the mean over the entire domain $(0,1)^d$ [S1].
*   **Precision:** Not given in the sources.

**Pseudocode:**

```python
def kronecker_product(A, B):
    """Computes the Kronecker product of two matrices."""
    result = []
    for row_a in A:
        for row_b in B:
            new_row = []
            for val_a in row_a:
                new_row.extend([val_a * x for x in row_b])
            result.append(new_row)
    return result

def compute_wavelet_transform(node):
    """Bottom-up transform: computes wavelet coefficients for an omnitree node."""
    if node.is_leaf():
        return node.scaling_coefficient
    
    # Gather scaling coefficients from children in Z-order
    s_v = [child.scaling_coefficient for child in node.children]
    k = len(node.refined_dimensions)
    n = 2 ** k
    
    # Construct Haar transformation matrix H
    # H = (1/2^k) * Kronecker product of 1D Hadamard matrices
    H = [[1.0]]
    for _ in range(k):
        H_1d = [[1, 1], [1, -1]]
        H = kronecker_product(H, H_1d)
    
    # Apply normalization factor
    scale = 1.0 / (2 ** k)
    H = [[val * scale for val in row] for row in H]
    
    # Compute wavelet coefficients: w_v = H @ s_v
    w_v = [sum(H[i][j] * s_v[j] for j in range(n)) for i in range(n)]
    
    node.wavelet_coefficients = w_v
    return w_v[0]  # Scaling coefficient for the parent

def reconstruct_nodal_values(node):
    """Top-down reconstruction: recovers nodal coefficients from wavelet coefficients."""
    if node.is_leaf():
        return node.scaling_coefficient
    
    w_v = node.wavelet_coefficients
    k = len(node.refined_dimensions)
    n = 2 ** k
    
    # Reconstruct H to compute R = H^-1
    H = [[1.0]]
    for _ in range(k):
        H_1d = [[1, 1], [1, -1]]
        H = kronecker_product(H, H_1d)
    scale = 1.0 / (2 ** k)
    H = [[val * scale for val in row] for row in H]
    
    # Inverse transformation R = H^-1. For Haar, H is symmetric and H^-1 = 2^k * H
    scale_inv = 2 ** k
    R = [[val * scale_inv for val in row] for row in H]
    
    # Reconstruct scaling coefficients: s_v = R @ w_v
    s_v = [sum(R[i][j] * w_v[j] for j in range(n)) for i in range(n)]
    
    # Distribute to children
    for i, child in enumerate(node.children):
        child.scaling_coefficient = s_v[i]
        
    return s_v
```

## Subtopics

### Haar Wavelet Transform on Omnitrees
Represents piecewise constant functions $f \in L^2([0,1]^d)$ hierarchically [S1]. The nodal representation stores $f$ as a sum over leaf nodes $v$ with $b(v)=0$: $f = \sum s^v \phi^v$, where $\phi^v$ is 1 if $x \in \text{rect}(v)$, 0 else [S1]. This is the specific wavelet basis used in the main method [S1].

## Operating characteristics
*   **Time Complexity:** $O(2^d N)$, linear in the number of coefficients $N$, using data stacks [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Enables lossless or lossy compression via pruning and tree restructuring (downsplit) [S1]. Coarsening can be implemented as a special case of refinement [S1].
*   **Limitations:** Not given in the sources.

## Background
Originated in the paper "Towards Fully Dynamic Omnitrees: Moment-Conserving Anisotropic Compression With Wavelets" [S1]. It extends omnitree data structures with wavelet transforms to support dynamic compression and reconstruction [S1].
