# Hierarchical Wavelet Transform on Omnitrees

Also called: Moment-conserving anisotropic compression, Wavelet compression on omnitrees

## Overview
This method transforms nodal omnitree data into wavelet coefficients to enable lossless or lossy compression via pruning and tree restructuring (downsplit) [S1]. It differs from standard multiresolution rendering by operating directly on the omnitree's anisotropic structure, allowing coarsening in specific dimensions while preserving the hierarchical spatial layout [S1]. It builds on [Wavelet-based Volume Rendering](1052-wavelet-based-volume-rendering.md) but adapts the transform to the irregular, dimension-specific splits of omnitrees rather than uniform grids.

## How it works
**Inputs and Outputs:**
*   **Input:** An omnitree where each node $v$ has a splitting label $\vec{b}(v)$, refined dimensions $\sigma(v)$, and nodal coefficients (scaling values) $w_{c \emptyset}$ for its children $c$. The children are ordered in Z-order.
*   **Output:** A set of wavelet coefficients $\vec{w}^v$ for all non-leaf nodes, and a root scaling coefficient $w_\theta^{\text{root}}$.

**Data Structures:**
*   **Omnitree Node:** Contains splitting label $\vec{b}(v)$ (binary vector), refined dimensions $\sigma(v)$ (subset of $\{1, \dots, d\}$), and a list of child nodes.
*   **Scaling Vector $\vec{s}^v$:** A vector of size $2^{|\sigma(v)|}$ containing the nodal coefficients of the children of node $v$, arranged in Z-order.
*   **Wavelet Vector $\vec{w}^v$:** A vector of size $2^{|\sigma(v)|} - 1$ (excluding the mean) or $2^{|\sigma(v)|}$ (including mean), arranged in a compatible order to $\vec{s}^v$.

**Algorithm Steps:**

1.  **Gather Scaling Coefficients:** For each node $v$, gather the nodal coefficients of its children into vector $\vec{s}^v$. The children are ordered according to Z-order.
2.  **Local Transformation (Bottom-Up):** Process nodes from leaves to root. For each node $v$ with refined dimensions $\sigma(v)$:
    *   Compute the local transformation matrix $H_{|\sigma(v)|}$.
    *   Compute wavelet coefficients: $\vec{w}^v = H_{|\sigma(v)|} \cdot \vec{s}^v$.
    *   The first element of $\vec{w}^v$ (or the element corresponding to the all-ones mask) is the scaling coefficient for the parent. The remaining elements are detail coefficients.
    *   Replace the nodal coefficients of $v$'s children with the computed wavelet coefficients for storage/transmission.
3.  **Reconstruction (Top-Down):** To reconstruct nodal values:
    *   Start at the root. The root scaling coefficient $w_\theta^{\text{root}}$ holds the mean value.
    *   For each node $v$ from root to leaves:
        *   Retrieve the wavelet coefficients $\vec{w}^v$.
        *   Compute the inverse transformation matrix $R_{|\sigma(v)|} = H_{|\sigma(v)|}^{-1}$.
        *   Reconstruct scaling coefficients for children: $\vec{s}^v = R_{|\sigma(v)|} \cdot \vec{w}^v$.
        *   Distribute these values to the children's nodal coefficients.

**Formulas:**
The wavelet coefficients are computed by:
$$ \vec{w}^v = H_{|\sigma(v)|} \cdot \vec{s}^v \quad (10) $$
where $H_{|\sigma(v)|}$ is the hierarchization matrix. For Haar wavelets:
$$ H_{|\sigma(v)|} = \frac{1}{2^{|\sigma(v)|}} \bigotimes_{j \in \sigma(v)} \begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix} \quad (11) $$
The function $f$ is represented as:
$$ f = w_\theta^{\text{root}} + \sum_{v: \text{nonleaf}} \sum_{\emptyset \neq \tau \subset \sigma(v)} w_\tau^v \cdot \psi_\tau^v \quad (12) $$
where $\psi_\tau^v$ are the wavelet basis functions. The inverse transformation satisfies $R_{|\sigma(v)|} H_{|\sigma(v)|} = I$.

**Parameters:**
*   **Wavelet Type:** Haar wavelets are specified [S1].
*   **Normalization:** The matrix includes a factor of $1/2^{|\sigma(v)|}$ [S1].

**Edge Cases and Pitfalls:**
*   **Leaf Nodes:** Leaf nodes have no children, so no transformation is applied. They store scaling coefficients directly.
*   **Root Node:** The root scaling coefficient represents the mean over the entire domain $(0,1)^d$ [S1].
*   **Precision:** The transformation is linear and invertible. Numerical stability depends on the condition number of $H$, which is well-behaved for Haar wavelets [S1].

**Pseudocode:**

```python
def compute_wavelet_transform(node):
    """
    Recursively computes wavelet coefficients for an omnitree node.
    Assumes children are already processed if not leaf.
    """
    if node.is_leaf():
        return node.scaling_coefficients
    
    # Gather scaling coefficients from children in Z-order
    s_v = []
    for child in node.children:
        s_v.extend(child.scaling_coefficients)
    
    s_v = np.array(s_v)
    num_refined = len(node.refined_dimensions)
    num_children = 2 ** num_refined
    
    # Construct Haar transformation matrix H
    # H = (1/2^k) * Hadamard_k
    H = np.eye(num_children)
    for dim in node.refined_dimensions:
        # 1D Hadamard matrix for this dimension
        H_1d = np.array([[1, 1], [1, -1]])
        # Kronecker product to build full matrix
        # Note: This is a simplified representation; actual implementation 
        # should use efficient butterfly operations or precomputed matrices.
        H = np.kron(H, H_1d)
    
    H = H / (2 ** num_refined)
    
    # Compute wavelet coefficients
    w_v = H @ s_v
    
    # Store wavelet coefficients in the node
    node.wavelet_coefficients = w_v
    
    # Return the scaling coefficient (mean) for the parent
    # In the vector w_v, the first element is typically the mean (all +1s)
    return w_v[0]

def reconstruct_nodal_values(node):
    """
    Recursively reconstructs nodal coefficients from wavelet coefficients.
    """
    if node.is_leaf():
        return node.scaling_coefficients
    
    w_v = np.array(node.wavelet_coefficients)
    num_refined = len(node.refined_dimensions)
    num_children = 2 ** num_refined
    
    # Inverse transformation R = H^-1 = H (for Haar, H is orthogonal up to scaling)
    # Actually, H^-1 = 2^k * H^T for the unnormalized Hadamard.
    # With the 1/2^k factor, H^-1 = 2^k * H^T? 
    # Let's use the property R * H = I.
    # For Haar, H is symmetric. H^-1 = 2^k * H? 
    # Check: H * H = (1/2^k) * H_hadamard * (1/2^k) * H_hadamard 
    # = (1/4^k) * 2^k * I = (1/2^k) * I. 
    # So H^-1 = 2^k * H.
    
    R = (2 ** num_refined) * H
    
    # Reconstruct scaling coefficients
    s_v = R @ w_v
    
    # Distribute to children
    child_size = num_children // 2 # Assuming binary split per dimension? 
    # Actually, if |sigma(v)| = k, there are 2^k children.
    # Each child has its own scaling coefficients.
    # The vector s_v contains the scaling coefficients for all 2^k children.
    
    idx = 0
    for child in node.children:
        child.scaling_coefficients = s_v[idx : idx + child.num_scaling_coeffs]
        idx += child.num_scaling_coeffs
        
    return s_v
```

## Subtopics

### Haar Wavelet Transform on Omnitrees
Represents piecewise constant functions $f \in L^2([0,1]^d)$ hierarchically. The nodal representation stores $f$ as a sum over leaf nodes $v$ with $b(v)=0$: $f = \sum s^v \phi^v$, where $\phi^v$ is 1 if $x \in \text{rect}(v)$, 0 else [S1]. This is the specific wavelet basis used in the main method [S1].

## Operating characteristics
*   **Time Complexity:** $O(2^d N)$, linear in the number of coefficients $N$, using data stacks [S1].
*   **Memory Complexity:** Linear in $N$ for storing coefficients [S1].
*   **Strengths:** Enables lossless or lossy compression via pruning and tree restructuring (downsplit) [S1]. Coarsening can be implemented as a special case of refinement [S1].
*   **Limitations:** Requires careful handling of anisotropic splits [S1].

## Background
Originated in the paper "Towards Fully Dynamic Omnitrees: Moment-Conserving Anisotropic Compression With Wavelets" [S1]. It extends omnitree data structures with wavelet transforms to support dynamic compression and reconstruction.
