# Hash Grid Loss
## Overview
Hash Grid Loss is a regularization term used in compressive neural volume rendering to minimize the bit consumption of the binary occupancy structure of a hash grid during training [S1]. It operates by modeling the probability distribution of the binary hash grid values and optimizing the negative log-likelihood, effectively driving the model to create a more concentrated hash grid structure [S1]. It is distinct from sibling methods like Voxel World Data Structure which manage spatial indexing, and from Entropy Loss which focuses on the continuous or quantized attribute values stored within active cells rather than the occupancy bits themselves [S1, 1101-voxel-world-data-structure.md].
## How it works
**Inputs and Outputs:**
- Input: Binary hash grid values (specifically counts of +1 and -1 values) [S1].
- Output: A scalar loss value $L_{\text{hash}}$ representing the estimated bit cost of encoding the hash grid structure [S1].

**Data Structures:**
The method operates on the binary hash grid generated by the parent [Hash Grids](936-hash-grids.md) method [S1]. The grid consists of binary flags indicating occupancy [S1].

**Parameters:**
- $h_f$: Occurrence frequency of the +1 value in the hash grid [S1].
- $M_+$: Total number of +1 values in the hash grid [S1].
- $M_-$: Total number of -1 values in the hash grid [S1].

**Formula:**
The loss is defined as the sum of the negative log-probabilities of the observed values [S1]:

$$L_{\text{hash}} = M_+ (-\log_2(h_f)) + M_- (-\log_2(1 - h_f))$$

Where $h_f$ is the occurrence frequency of the +1 value [S1]. The terms $-\log_2(h_f)$ and $-\log_2(1 - h_f)$ represent the self-information (bit cost) of occupied and empty cells, respectively [G].

**Steps:**
1. Count the total number of +1 values ($M_+$) and -1 values ($M_-$) in the hash grid [S1].
2. Compute the occurrence frequency of +1 values: $h_f = M_+ / (M_+ + M_-)$ [G].
3. Compute the loss using the formula above [S1].
4. Add $L_{\text{hash}}$ to the total training loss [S1].

**Pseudocode:**
> **Unverified code.** The code below did not pass a test run against a reference implementation, or no test fits it, so it may contain errors.

```python
import math

def compute_hash_grid_loss(M_plus, M_minus):
    """
    Compute the Hash Grid Loss for a binary hash grid.
    
    Args:
        M_plus: Total number of +1 values (occupied cells).
        M_minus: Total number of -1 values (empty cells).
        
    Returns:
        float: The computed hash grid loss L_hash.
    """
    total_cells = M_plus + M_minus
    if total_cells == 0:
        return 0.0
        
    h_f = M_plus / total_cells
    
    # Clamp h_f to avoid log(0) if the grid is perfectly empty or full [G]
    epsilon = 1e-9
    h_f_clamped = max(min(h_f, 1.0 - epsilon), epsilon)
    
    log2_h_f = math.log2(h_f_clamped)
    log2_1_minus_h_f = math.log2(1.0 - h_f_clamped)
    
    loss = M_plus * (-log2_h_f) + M_minus * (-log2_1_minus_h_f)
    return loss
```

**Edge Cases and Pitfalls:**
- If $h_f = 0$ or $h_f = 1$, the logarithm becomes undefined (negative infinity), indicating a perfectly empty or perfectly full grid [G].
- The definition assumes binary values +1 and -1 [S1]. If the hash grid uses different encodings, the counts must be adjusted accordingly [G].

## Subtopics

### [Entropy Loss](2114-entropy-loss.md)
Entropy Loss is a regularization term used in compressive neural volume rendering to minimize the bit consumption of anchor attributes during training. It operates by modeling the probability distribution of quantized attributes and optimizing the negative log-likelihood, effectively driving the model to represent data with fewer bits. It is distinct from the Hash Grid Loss, which optimizes the binary occupancy of the hash grid structure itself, whereas Entropy Loss focuses on the continuous or quantized attribute values stored within those active cells.

## Background
Hash Grid Loss was introduced in the context of ECoNGS (Efficient Compressive Neural Gaussian Splats for Volume Visualization) [S1]. It is part of a two-stage optimization process where the hash grid component is optimized for compression alongside anchor attributes [S1]. The method leverages the concept of entropy coding, where the bit cost of a symbol is proportional to the negative logarithm of its probability [S1]. By minimizing this loss, the model learns to distribute the hash grid values in a way that minimizes the expected bit length of the encoded structure [S1].
