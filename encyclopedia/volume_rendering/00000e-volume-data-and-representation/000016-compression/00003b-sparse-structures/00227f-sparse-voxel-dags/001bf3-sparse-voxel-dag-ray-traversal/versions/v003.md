# Sparse Voxel DAG Ray Traversal

Also called: Ray tracing a sparse voxel DAG, SVO DAG Ray Tracer

## Overview
A GPU-based ray traversal method for Sparse Voxel Directed Acyclic Graphs (SVDAGs) designed for visibility queries (shadows, ambient occlusion) and primary ray intersection [S1]. It simplifies the standard SVO traversal loop by eliminating contour intersection tests and distance maintenance, leveraging the DAG's structure to traverse voxels in ray order [S1]. It extends beam optimization to soft shadows by determining conservative intersection intervals via reverse beam tracing [S1].

## How it works
**Inputs:** A Sparse Voxel DAG representing geometry; ray origin and direction for primary rays, or view-sample position and light direction for shadow rays; a traditional SVO structure containing material information for primary ray shading [S1].
**Outputs:** Hit points for primary rays, or occlusion values for shadows and ambient occlusion [S1].

**Data Structures:**
*   **SVDAG Node:** Contains a child mask and pointers to non-empty children [S1]. In memory, both mask and pointers are 4 bytes [S1]. Pointers to non-empty children are stored consecutively after the child mask [S1]. Node size depends on the number of children [S1].
*   **Traditional SVO:** Used separately to store material properties for shading at hit points obtained from the DAG traversal [S1].

**Algorithm Steps:**
1.  **Primary Ray Traversal:** Initialize traversal similar to Laine and Karras [2010a] [S1]. Traverse the DAG in ray order. Do not maintain distance traveled along the ray, as contour intersection tests are not required [S1]. Stop when a non-empty voxel is found or the ray span terminates [S2]. Upon finding a hit point, query the traditional SVO structure for material information [S1].
2.  **Beam Optimization (Primary Rays):** Group primary rays into beams of size $8 \times 8$ pixels to improve performance [S1].
3.  **Soft Shadow Traversal:** For each pixel, shoot a beam of four rays from the view-sample position to the area light [S1]. Find the conservative furthest distance along these rays where no geometry is intersected [S1]. Shorten all shadow rays for that pixel to this distance [S1]. Trace the same beam rays in reverse direction (from the light source) to find a conservative interval where geometry *may* be intersected [S1]. This further improves traversal speed by identifying pixels with no intersections [S1].
4.  **Ambient Occlusion:** Approximated by casting rays over the hemisphere and averaging occlusion, mapping the first-hit distance to a falloff function [S1].

**Pseudocode:**
```python
def traverse_svdag_ray(origin, direction, max_dist, nodes, child_masks, child_ptrs):
    # DDA initialization
    step = [1 if direction[i] > 0 else -1 for i in range(3)]
    t_delta = [1.0 / abs(direction[i]) if direction[i] != 0 else float('inf') for i in range(3)]
    t_max = [0.0] * 3
    # Initialize t_max for root voxel boundaries
    root = nodes[0]
    for i in range(3):
        if direction[i] > 0:
            t_max[i] = (root.bounds.min[i] - origin[i]) * t_delta[i]
        else:
            t_max[i] = (root.bounds.max[i] - origin[i]) * t_delta[i]
    
    # Stack stores (node_index, t_max_x, t_max_y, t_max_z)
    stack = [(0, t_max[0], t_max[1], t_max[2])]
    
    while stack:
        node_idx, t_max_x, t_max_y, t_max_z = stack.pop()
        node = nodes[node_idx]
        
        if node.is_empty():
            continue
        if not ray_intersects_node(origin, direction, node.bounds, max_dist):
            continue
        if node.is_leaf():
            return compute_hit(origin, direction, node)
        
        # Push children in reverse ray order to maintain traversal order
        for i in range(7, -1, -1):
            if (node.child_mask >> i) & 1:
                ptr = child_ptrs[node.child_ptr_offset + i]
                child = nodes[ptr]
                c_t_max = [0.0] * 3
                for d in range(3):
                    base_t = t_max_x if d == 0 else (t_max_y if d == 1 else t_max_z)
                    if direction[d] > 0:
                        c_t_max[d] = max(base_t, (child.bounds.min[d] - origin[d]) * t_delta[d])
                    else:
                        c_t_max[d] = max(base_t, (child.bounds.max[d] - origin[d]) * t_delta[d])
                stack.append((ptr, c_t_max[0], c_t_max[1], c_t_max[2]))
    return None

def optimize_shadow_beam(view_pos, light_pos, beam_count=4):
    forward_rays = create_beam_rays(view_pos, light_pos, beam_count)
    max_free_dist = float('inf')
    for ray in forward_rays:
        hit = traverse_svdag_ray(ray.origin, ray.direction, distance(view_pos, light_pos), nodes, child_masks, child_ptrs)
        if hit is not None:
            dist = distance(ray.origin, hit)
            if dist < max_free_dist:
                max_free_dist = dist
    reverse_rays = create_beam_rays(light_pos, view_pos, beam_count)
    min_intersect_dist = float('inf')
    max_intersect_dist = 0.0
    for ray in reverse_rays:
        hit = traverse_svdag_ray(ray.origin, ray.direction, distance(light_pos, view_pos), nodes, child_masks, child_ptrs)
        if hit is not None:
            dist = distance(ray.origin, hit)
            if dist > max_intersect_dist:
                max_intersect_dist = dist
            if dist < min_intersect_dist:
                min_intersect_dist = dist
    return max_free_dist, min_intersect_dist if min_intersect_dist != float('inf') else 0.0, max_intersect_dist

def ray_intersects_node(origin, direction, bounds, max_dist):
    t0 = [(bounds.min[i] - origin[i]) / direction[i] for i in range(3)]
    t1 = [(bounds.max[i] - origin[i]) / direction[i] for i in range(3)]
    t_enter = max(min(t0), min(t1))
    t_exit = min(max(t0), max(t1))
    return t_enter <= max_dist and t_exit >= 0

def compute_hit(origin, direction, node):
    return [origin[i] + direction[i] * distance(origin, node.bounds.center) for i in range(3)]

def create_beam_rays(view_pos, light_pos, count):
    rays = []
    base_dir = normalize(light_pos, view_pos)
    for _ in range(count):
        rays.append({'origin': view_pos, 'direction': base_dir})
    return rays

def distance(a, b):
    return ((a[0]-b[0])**2 + (a[1]-b[1])**2 + (a[2]-b[2])**2)**0.5

def normalize(v, origin):
    l = distance(v, origin)
    return [(v[i] - origin[i]) / l for i in range(3)]
```

**Parameters:**
*   Beam size: $8 \times 8$ pixels for primary rays [S1].
*   Shadow beam rays: 4 rays per pixel [S1].

**Edge Cases:**
*   **Precision:** Not specified in sources.
*   **Boundaries:** Ray span termination stops traversal [S1].

## Subtopics

### GPU Ray-tracing of SSVDAG
A GPU-based raytracer traversal method for Symmetry-aware Sparse Voxel DAGs (SSVDAG) that adapts octree traversal to handle variable-rate encoded child pointers and apply symmetry transformations upon entering subtrees [S2]. It stores the dataset in two texture buffer objects (one for inner nodes, one for leaves), using 3D textures if data exceeds buffer addressing limits [S2]. Traversal uses a depth-first visit of the octree based on a recursive digital differential analyzer (DDA) implemented with a full stack, stopping when a non-empty voxel is found or the ray span terminates [S2]. When following child pointers, the variable-rate encoding logic is applied, and the transformation stored with the pointer is applied every time a child is entered [S2]. Rendering setup uses deferred shading with screen-space normal estimation (via finite differences in the frame buffer using a discontinuity preserving filter) and hard shadows for one point light [S2]. The code does not use any other acceleration or shading structure [S2].

## Operating characteristics
*   **Time Complexity:** Not explicitly given, but beam optimization and reverse beam tracing improve traversal speed for soft shadows [S1].
*   **Memory Complexity:** Node size depends on the number of children, with 4-byte masks and pointers [S1]. SSVDAG variant uses texture buffer objects or 3D textures [S2].
*   **Measured Performance:** For the Powerplant model at $64K^3$ resolution, SSVDAG raytracing achieved 74fps and 70fps for two viewpoints, compared to 86fps and 81fps for USSVDAG, and 87fps and 82fps for SVDAG [S2].
*   **Strengths:** Simplified traversal loop (no contour tests, no distance maintenance); efficient soft shadow computation via beam optimization; suitable for real-time navigation of large compressed scenes [S1, S2].
*   **Limitations:** Requires a separate traditional SVO for material information [S1]; SSVDAG requires applying transformations on entry [S2].
*   **When to use:** Visibility queries (shadows, AO) and primary ray intersection in deferred rendering pipelines where geometry is represented as a sparse voxel DAG [S1].
*   **When not to use:** When material information is tightly coupled with the DAG structure and cannot be stored separately [S1].

## Background
Originated from the implementation of a GPU-based raytracer in CUDA for Sparse Voxel DAGs [S1]. The traversal loop closely resembles that of Laine and Karras [2010a] [S1]. The SSVDAG variant was implemented in GLSL to test traversal of symmetry-aware structures [S2]. Used for deferred rendering targets, evaluating hard shadows, soft shadows, and ambient occlusion [S1, S2].
