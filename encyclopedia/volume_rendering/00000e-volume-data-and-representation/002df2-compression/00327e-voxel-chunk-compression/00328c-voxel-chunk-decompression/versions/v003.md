# Voxel Chunk Decompression

Also called: Decompress, Voxel Compression and Decompression

## Overview
Voxel Chunk Decompression reconstructs uncompressed voxel data from a compressed binary buffer [S2, unofficial]. It retrieves spatial data (albedo, normals, material indices, and lighting) from a compact representation for rendering or simulation [S1, unofficial]. It is distinguished from general volume compression by its specific handling of packed 8-bit components and planar data layouts typical in voxel engines [S1, unofficial][S2, unofficial].

## How it works
### Inputs and Outputs
- **Input**: A compressed voxel chunk buffer containing a header and payload [S2, unofficial].
- **Output**: An uncompressed voxel data structure (`DNvoxel` or `OutData`) containing the original voxel components [S1, unofficial][S2, unofficial].

### Data Structures
The decompression process relies on a specific header structure (`FVoxelChunkBufferHeader`) and payload format [S2, unofficial].

**Header Layout**:
- `Magic`: Identifier for the chunk format [S2, unofficial].
- `FormatVersion`: Version number of the compression format [S2, unofficial].
- `CodecId`: Identifier for the compression algorithm used (e.g., Raw) [S2, unofficial].
- `bPlanar`: Boolean flag indicating if the payload data is stored in a planar layout (separate planes for each component) or interleaved [S2, unofficial].
- `RawBytes`: Total size of the uncompressed voxel data in bytes [S2, unofficial].
- `NumVoxels`: Total number of voxels in the chunk [S2, unofficial].

**Voxel Component Packing**:
Voxels are stored as packed 32-bit unsigned integers (`uint`) [S1, unofficial]. The components are extracted using bitwise operations [S1, unofficial]. The specific components decoded are:
- `normalRead`: A `uvec4` derived from a `uint` [S1, unofficial].
- `albedoRead`: A `uvec4` derived from a `uint` [S1, unofficial].
- `specLightRead`: A `uvec4` derived from a `uint` [S1, unofficial].
- `diffuseLightRead`: A `uvec4` derived from a `uint` [S1, unofficial].

### Numbered Steps
1. **Header Validation**: Check if the input buffer size is less than `sizeof(FVoxelChunkBufferHeader)` [S2, unofficial]. Copy the header from the buffer [S2, unofficial]. Verify the `Magic` and `FormatVersion` fields match expected values [S2, unofficial]. Retrieve `RawBytes`, `NumVoxels`, `CodecId`, and `bPlanar` from the header [S2, unofficial]. If `NumVoxels <= 0`, return failure [S2, unofficial].
2. **Output Allocation**: Allocate memory for the output data (`OutData`) with a size of `RawBytes` [S2, unofficial].
3. **Payload Retrieval**: Get the pointer and size of the payload data following the header [S2, unofficial].
4. **Codec Dispatch**: Identify the codec based on `Header.CodecId` [S2, unofficial]. If Codec is Raw, verify `PayloadSize >= RawBytes` [S2, unofficial]. Copy the payload directly to `OutData` [S2, unofficial]. Return success [S2, unofficial]. If Codec is Compressed, check `bPlanar` [S2, unofficial]. If `bPlanar` is true, allocate a temporary `Planes` buffer [S2, unofficial]. Decompress the payload into the `Planes` buffer [S2, unofficial]. Call `ReInterleave(Planes, NumVoxels, OutData)` to convert planar layout to interleaved layout [S2, unofficial]. If `bPlanar` is false, decompress the payload directly into `OutData` [S2, unofficial].
5. **Component Decoding**: For each voxel in `OutData`, decode the packed components into floating-point values [S1, unofficial]. Extract `normalRead` and scale by `0.00392156862` [S1, unofficial]. Subtract `0.5` and multiply by `2.0` to map the range $[0, 1]$ to $[-1, 1]$ for components `y`, `z`, and `w` [S1, unofficial]. Assign `normalRead.x` as the material index [S1, unofficial]. Extract `albedoRead.xyz` and scale by `0.00392156862` [S1, unofficial]. Reconstruct diffuse light from `specLightRead.z`, `diffuseLightRead.x`, `diffuseLightRead.z` (upper 8 bits shifted left 8) and `specLightRead.w`, `diffuseLightRead.y`, `diffuseLightRead.w` (lower 8 bits), combine via bitwise OR, and scale by `0.0000152590219` [S1, unofficial]. Extract `albedoRead.w` and `specLightRead.xy` and scale by `0.00392156862` for specular light [S1, unofficial].

### Pseudocode
```python
def decompress_voxel_chunk(compressed_buffer: bytes) -> list:
    """
    Decompresses a voxel chunk from a binary buffer.
    Returns a list of decoded voxel dictionaries.
    """
    # [G] Typical header size; replace with actual sizeof(FVoxelChunkBufferHeader)
    HEADER_SIZE = 16
    if len(compressed_buffer) < HEADER_SIZE:
        return False

    # Parse header fields inline
    magic = int.from_bytes(compressed_buffer[0:4], 'little')
    format_version = int.from_bytes(compressed_buffer[4:8], 'little')
    codec_id = int.from_bytes(compressed_buffer[8:12], 'little')
    b_planar = compressed_buffer[12] == 1
    raw_bytes = int.from_bytes(compressed_buffer[13:17], 'little')
    num_voxels = int.from_bytes(compressed_buffer[17:21], 'little')

    # [G] Example constants; replace with actual expected values
    EXPECTED_MAGIC = 0x564F584C
    EXPECTED_VERSION = 1

    if magic != EXPECTED_MAGIC or format_version != EXPECTED_VERSION:
        return False
    if num_voxels <= 0:
        return False

    # Step 2: Output Allocation
    out_data = bytearray(raw_bytes)

    # Step 3: Payload Retrieval
    payload = compressed_buffer[HEADER_SIZE:]
    payload_size = len(payload)

    # Step 4: Codec Dispatch
    CODEC_RAW = 0
    if codec_id == CODEC_RAW:
        if payload_size < raw_bytes:
            return False
        out_data = bytearray(payload[:raw_bytes])
    else:
        # [S2, unofficial] Actual codec decompression logic is not provided in the sources.
        if b_planar:
            planes_buffer = bytearray(raw_bytes)
            # decompress_payload(payload, planes_buffer)
            out_data = re_interleave(planes_buffer, num_voxels)
        else:
            # decompress_payload(payload, out_data)
            pass

    # Step 5: Component Decoding
    voxels = []
    for i in range(num_voxels):
        base = i * 16
        packed_normal = int.from_bytes(out_data[base:base+4], 'little')
        packed_albedo = int.from_bytes(out_data[base+4:base+8], 'little')
        packed_spec_light = int.from_bytes(out_data[base+8:base+12], 'little')
        packed_diffuse_light = int.from_bytes(out_data[base+12:base+16], 'little')

        normal_read = decode_uint_RGBA(packed_normal)
        albedo_read = decode_uint_RGBA(packed_albedo)
        spec_light_read = decode_uint_RGBA(packed_spec_light)
        diffuse_light_read = decode_uint_RGBA(packed_diffuse_light)

        # Normal Vector Reconstruction
        normal_y = (normal_read[1] * 0.00392156862 - 0.5) * 2.0
        normal_z = (normal_read[2] * 0.00392156862 - 0.5) * 2.0
        normal_w = (normal_read[3] * 0.00392156862 - 0.5) * 2.0
        material_index = normal_read[0]

        # Albedo
        albedo_x = albedo_read[0] * 0.00392156862
        albedo_y = albedo_read[1] * 0.00392156862
        albedo_z = albedo_read[2] * 0.00392156862

        # Diffuse Light Reconstruction
        # Reconstructed from specLightRead.z, diffuseLightRead.x, diffuseLightRead.z (upper 8 bits shifted left 8)
        # and specLightRead.w, diffuseLightRead.y, diffuseLightRead.w (lower 8 bits), combined via bitwise OR
        diffuse_raw = ((spec_light_read[2] << 8) | diffuse_light_read[0]) | \
                      ((diffuse_light_read[2] << 8) | spec_light_read[3]) | \
                      ((diffuse_light_read[1] << 8) | diffuse_light_read[3])
        diffuse_light = diffuse_raw * 0.0000152590219

        # Specular Light
        specular_x = albedo_read[3] * 0.00392156862
        specular_y = spec_light_read[0] * 0.00392156862
        specular_z = spec_light_read[1] * 0.00392156862

        voxels.append({
            'material_index': material_index,
            'normal': (normal_y, normal_z, normal_w),
            'albedo': (albedo_x, albedo_y, albedo_z),
            'diffuse_light': diffuse_light,
            'specular_light': (specular_x, specular_y, specular_z)
        })

    return voxels

def decode_uint_RGBA(val: int) -> tuple:
    """
    Extracts 4 8-bit components from a 32-bit unsigned integer.
    Matches: uvec4 decode_uint_RGBA(uint val) { uvec4 res; res.x = val >> 24; res.y = val >> 16; res.z = val >> 8; res.w = val; return res & 0xFF; }
    """
    res_x = (val >> 24) & 0xFF
    res_y = (val >> 16) & 0xFF
    res_z = (val >> 8) & 0xFF
    res_w = val & 0xFF
    return (res_x, res_y, res_z, res_w)

def re_interleave(planes: bytearray, num_voxels: int) -> bytearray:
    """Converts planar layout to interleaved layout."""
    out = bytearray(len(planes))
    stride = len(planes) // 4
    for i in range(num_voxels):
        for c in range(4):
            out[i * 4 + c] = planes[c * stride + i]
    return out
```

### Parameters
- **Compression Codec**: The specific algorithm used (e.g., Raw, LZ4) [S2, unofficial].
- **Planar Flag**: `bPlanar` indicates if data is stored in planar format [S2, unofficial].

### Edge Cases and Pitfalls
- **Buffer Size**: If the input buffer is smaller than the header size, decompression fails immediately [S2, unofficial].
- **Invalid NumVoxels**: If `NumVoxels` is zero or negative, decompression fails [S2, unofficial].
- **Payload Size**: For Raw codec, if `PayloadSize` is less than `RawBytes`, decompression fails [S2, unofficial].
- **Precision**: The scaling factors `0.00392156862` and `0.0000152590219` are critical for correct value reconstruction [S1, unofficial]. Using incorrect floating-point precision may lead to visual artifacts [G].
- **Bit Packing Ambiguity**: The description of diffuse light reconstruction involves complex bit shifting and OR operations across multiple packed values [S1, unofficial]. The exact mapping of bits to components is not fully specified in the notes, requiring careful implementation [G].

### Planar vs Interleaved Layouts
Planar layout stores all values for a component together, while interleaved stores all components for a voxel together [S2, unofficial]. Planar layout may offer better compression ratios for certain codecs [S2, unofficial]. [Voxel Chunk Compression](6778-voxel-chunk-compression.md)

## Operating characteristics
- **Time Complexity**: $O(N)$ where $N$ is the number of voxels, for both decompression and decoding steps [S2, unofficial].
- **Memory Complexity**: $O(N)$ for the output data [S2, unofficial]. If `bPlanar` is true, an additional $O(N)$ buffer is required for the `Planes` buffer [S2, unofficial].
- **Measured Performance**: Not given in the sources [G].
- **Scaling**: Linear scaling with the number of voxels [S2, unofficial].
- **Strengths**: Fast decompression for Raw codec (memcpy) [S2, unofficial]. Flexible support for various compression codecs via `CodecId` [S2, unofficial].
- **Limitations**: Complex bit-packing for lighting components may be error-prone to implement [S1, unofficial]. Planar layout requires an extra de-interleaving step [S2, unofficial].
- **When to Use**: When voxel data needs to be transmitted or stored in a compact format and then reconstructed for rendering [S1, unofficial][S2, unofficial].
- **When Not to Use**: When real-time decompression is not required and data can be stored uncompressed if memory is not a constraint [S2, unofficial].

## Background
The method is part of the VoxelWorlds engine ecosystem, specifically used for managing voxel data in biomes and terrain generation [S2, unofficial]. It is implemented in the `VoxelCore` module [S2, unofficial]. The specific bit-packing and decoding logic is found in the DoonEngine repository, suggesting a shared or derived implementation between the two projects [S1, unofficial][S2, unofficial].
