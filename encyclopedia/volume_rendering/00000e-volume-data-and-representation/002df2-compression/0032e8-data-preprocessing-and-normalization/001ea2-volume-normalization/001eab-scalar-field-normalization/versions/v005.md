# Scalar Field Normalization

Also called: Global Min-Max Scaling, Image Normalization & Whitening, Min-Max Normalization, Normalise Function, Universal Threshold Normalization, Volume Sampling Normalization, normalise

## Overview
Scalar Field Normalization maps the raw intensity values of a volume tensor to a standardized numerical range, typically $[0, 1]$ or $[-1, 1]$, to resolve disparate data magnitudes and coordinate scales [S1, S3, S4, S5, unofficial]. It sets itself apart from non-linear methods like [Power Transformation](2346-power-transformation.md) by preserving linear relationships within the mapped range, and from global statistical methods like [Percentile-based Normalization](5158-percentile-based-normalization.md) by relying on fixed or global extrema rather than distribution percentiles [G]. This linear scaling enables the use of universal thresholds (e.g., 0.5) for object distinction and ensures consistent behavior across different input resolutions and data types [S5, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A scalar field volume $V$ of shape $(D, H, W)$ or $(D, H, W, C)$, containing raw intensity values (integer or float).
- Output: A normalized volume $V'$ with values in the target range $[a, b]$ (typically $[0, 1]$), stored as `float32`.

**Data Structures:**
- The volume is treated as a contiguous array of scalar values. No complex metadata structures are required for the normalization step itself, though boundary checks may require spatial coordinates $(x, y, z)$ [S3, unofficial].

**Steps:**
1. **Type Casting:** Convert all input values to `float32` to ensure precision consistency [S1, unofficial].
2. **Outlier/NaN Handling:** Replace any `NaN` values with 0. If the maximum value of the cleaned data is 0, return a zero-filled array of the same shape [S2, unofficial].
3. **Boundary Check (Optional):** If the volume is accessed via coordinate sampling, return 0 for any coordinate outside the dataset bounds (e.g., $x < 0$ or $x \geq \text{width}$) [S3, unofficial].
4. **Extrema Calculation:** Iterate over all valid data elements to find the global minimum ($\min$) and global maximum ($\max$) of the scalar field [S4, unofficial].
5. **Normalization:** Apply the linear scaling formula to each voxel value $x$:
   $$ x' = \frac{(b - a)(x - \min)}{\max - \min} + a $$
   where $a$ is the lowest normalized value (typically 0) and $b$ is the highest (typically 1) [S5, unofficial].
   - If $\max - \min \leq 0$ (constant field or empty), return a zero-filled array [S1, S2, unofficial].
6. **Clamping:** Clamp the result to the range $[a, b]$ to handle any floating-point inaccuracies [S3, unofficial].

**Pseudocode:**
```python
import numpy as np

def scalar_field_normalization(volume: np.ndarray, target_min: float = 0.0, target_max: float = 1.0) -> np.ndarray:
    """
    Normalizes a scalar field volume to [target_min, target_max] using global min-max scaling.
    
    Args:
        volume: Input volume array (any numeric dtype).
        target_min: Lower bound of the output range.
        target_max: Upper bound of the output range.
        
    Returns:
        Normalized volume array with dtype float32.
    """
    # Step 1: Cast to float32
    f = volume.astype(np.float32)
    
    # Step 2: Handle NaNs
    f = np.nan_to_num(f, nan=0.0)
    
    # Step 3: Check for empty or zero-only volume
    if f.max() == 0:
        return np.zeros_like(f)
    
    # Step 4: Calculate global min and max
    field_min = f.min()
    field_max = f.max()
    
    # Step 5: Avoid division by zero
    denom = field_max - field_min
    if denom <= 0:
        return np.zeros_like(f)
    
    # Step 6: Apply linear scaling formula
    # x' = ((b - a) * (x - min) / (max - min)) + a
    normalized = ((target_max - target_min) * (f - field_min) / denom) + target_min
    
    # Step 7: Clamp to target range (guard against precision errors)
    normalized = np.clip(normalized, target_min, target_max)
    
    return normalized
```

**Parameters:**
- `target_min` ($a$): The lowest normalized value. Typically 0 [S5, unofficial].
- `target_max` ($b$): The highest normalized value. Typically 1 [S5, unofficial].
- `dtype`: Output data type. Always `float32` [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Division by Zero:** Occurs if $\max = \min$ (constant volume) or if the volume is empty. The algorithm must check `denom > 0` and return zeros in such cases [S1, S2, unofficial].
- **NaN Values:** Raw data may contain `NaN`. These must be replaced (e.g., with 0) before calculating min/max to prevent propagation [S2, unofficial].
- **Outliers:** Global min/max are sensitive to extreme outliers, which can compress the visible range of the majority of the data. This is a known limitation compared to percentile-based methods [G].

## Subtopics

### [Scaling](2287-scaling.md)
Linear transformation of values or coordinates to a normalized range. Preserves linear relationships but is sensitive to outliers.

### [Percentile-based Normalization](5158-percentile-based-normalization.md)
Uses robust statistical bounds (percentiles) to ignore outliers, preventing contrast loss in data with extreme values.

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the total number of voxels, as it requires a single pass to find min/max and a second pass to scale values.
- **Memory Complexity:** $O(N)$ for the output array. In-place normalization is possible but requires careful handling of the original min/max values.
- **Strengths:** Simple to implement, computationally inexpensive, preserves linear intensity relationships, and enables universal thresholding [S5, unofficial].
- **Limitations:** Highly sensitive to outliers; a single extreme value can render the majority of the data indistinguishable in the normalized range. Not suitable for data with heavy-tailed distributions without prior outlier removal.
- **When to Use:** When data magnitudes are consistent, or when a simple linear mapping is required for downstream algorithms that expect $[0, 1]$ inputs (e.g., neural networks, standard transfer functions).
- **When Not to Use:** When the data contains significant outliers that distort the global range, or when preserving local contrast is more important than global intensity consistency.

## Background
Scalar field normalization is a fundamental preprocessing step in volume rendering and image processing. It originated from the need to standardize data for visualization and algorithmic processing. The technique is widely used in medical imaging (CT, MRI) to map Hounsfield units or signal intensities to displayable ranges [S3, S5, unofficial]. The specific formulation using global min/max is often referred to as Min-Max Normalization [S4, unofficial]. The application of a universal threshold (0.5) after normalization for object distinction was highlighted in segmentation-assisted volume rendering contexts [S5, unofficial].
