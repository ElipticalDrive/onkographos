# Scalar Field Normalization

Also called: Global Min-Max Scaling, Image Normalization & Whitening, Min-Max Normalization, Volume Sampling Normalization

## Overview
Scalar Field Normalization maps a volume's scalar values to a canonical range, typically $[0, 1]$, to ensure numerical stability and consistent contrast across different datasets [S1, S3, unofficial]. It differs from non-linear methods like [Power Transformation](2346-power-transformation.md) by preserving the linear relationship between input intensity and output value, and from [Scaling and Biasing](2888-scaling-and-biasing.md) by lacking an explicit bias term in its core definition, though biasing is often applied subsequently [S2287-scaling.md].

## How it works
**Inputs and Outputs:**
- Input: A volume tensor (3D array) of scalar values, typically integer or float.
- Output: A volume tensor of the same shape and dimensions, with values normalized to the target range.

**Data Structures:**
- The input is treated as a contiguous array of voxels.
- The output is allocated in `float32` precision to maintain dynamic range [S1, unofficial].

**Steps:**
1. **Data Type Conversion:** Cast the input volume to `float32` [S1, unofficial].
2. **Boundary Check (for sampling):** If accessing a voxel at coordinates $(x, y, z)$, check if coordinates are within bounds. If $x < 0$, $x \ge \text{width}$, $y < 0$, $y \ge \text{height}$, or $z < 0$, $z \ge \text{depth}$, return $0.0$ [S2, unofficial].
3. **Compute Statistics:** Iterate over all valid data elements to find the global minimum (`field_min`) and global maximum (`field_max`) [S3, unofficial].
4. **Normalization:** Apply the linear transformation:
   $$ \text{data}[i] = \frac{\text{data}[i] - \text{field\_min}}{\text{field\_max} - \text{field\_min}} $$
   [S3, unofficial]
5. **Edge Case Handling:** If `field_max` equals `field_min` (or standard deviation is zero for whitening), return an array of zeros to avoid division by zero [S1, S3, unofficial].

**Pseudocode:**
```python
import numpy as np

def normalize_scalar_field(volume: np.ndarray) -> np.ndarray:
    """
    Normalizes a 3D volume scalar field to [0, 1] using global min-max scaling.
    """
    # 1. Cast to float32
    vol_float = volume.astype(np.float32)
    
    # 2. Compute global min and max
    field_min = np.min(vol_float)
    field_max = np.max(vol_float)
    
    # 3. Handle degenerate case (constant volume)
    if field_max == field_min:
        return np.zeros_like(vol_float)
    
    # 4. Apply normalization formula
    normalized = (vol_float - field_min) / (field_max - field_min)
    
    return normalized

def sample_normalized_volume(norm_volume: np.ndarray, x: int, y: int, z: int) -> float:
    """
    Samples a voxel from a normalized volume with boundary checks.
    """
    height, width, depth = norm_volume.shape
    
    # Boundary check
    if x < 0 or x >= width or \
       y < 0 or y >= height or \
       z < 0 or z >= depth:
        return 0.0
    
    return norm_volume[y, x, z]
```

**Parameters:**
- `dtype`: Input is cast to `np.float32` [S1, unofficial].

**Pitfalls:**
- **Division by Zero:** Occurs if all voxel values are identical. Guarded by checking `max > min` or `std > 0` [S1, unofficial].
- **Outlier Sensitivity:** Global min/max can be skewed by extreme outliers, compressing the useful dynamic range of the majority of the data [S4, unofficial].

## Subtopics

### [Scaling](2287-scaling.md)
Scaling is a fundamental scalar field normalization technique that maps input data values to a target range, typically $[0, 1]$, by dividing by a scale factor. It serves as the base linear transformation for volume data representation, ensuring numerical stability and consistent contrast across different datasets. It differs from non-linear methods like [Power Transformation](2346-power-transformation.md) by preserving the linear relationship between input intensity and output value, and from [Scaling and Biasing](2888-scaling-and-biasing.md) by lacking an explicit bias term in its core definition, though biasing is often applied subsequently.

### Percentile-based Normalization
This variant uses percentiles (e.g., 5th and 95th) instead of global min/max to mitigate the effect of outliers [S4, unofficial].
**Steps:**
1. Calculate `min_val` and `max_val` as the 5th and 95th percentiles of the image data [S4, unofficial].
2. Clip image values to `[min_val, max_val]` [S4, unofficial].
3. Normalize: $image\_normalized = (image\_clipped - min\_val) / (max\_val - min\_val + 1e-8)$ [S4, unofficial].
4. Scale to 0-255 and cast to uint8: $image\_8bit = (image\_normalized * 255).astype(np.uint8)$ [S4, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the number of voxels, to compute min/max. Normalization is also $O(N)$.
- **Memory Complexity:** $O(N)$ for the output array in `float32` [S1, unofficial].
- **Strengths:** Simple, fast, and preserves linear intensity relationships [S2287-scaling.md].
- **Limitations:** Highly sensitive to outliers; a single extreme value can compress the visible range of the rest of the data [S4, unofficial]. Not suitable for data with significant noise spikes unless clipped [S4, unofficial].

## Background
Scalar field normalization is a standard preprocessing step in volume rendering and medical imaging to ensure that rendering parameters (like transfer functions) work consistently across different datasets [S1, S3, unofficial]. It is often used in conjunction with compression and rendering pipelines [S2, S3, unofficial].
