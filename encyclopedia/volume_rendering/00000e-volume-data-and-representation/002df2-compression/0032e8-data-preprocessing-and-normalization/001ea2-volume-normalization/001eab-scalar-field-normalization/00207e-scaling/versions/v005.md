# Scaling

Also called: Scalar Field Scaling

## Overview
Scaling transforms scalar field values or spatial coordinates into a normalized range, typically [0, 1] or [-1, 1], to resolve disparate data magnitudes and coordinate scales [G]. It sets itself apart from non-linear normalization methods like [Power Transformation](2346-power-transformation.md) by preserving linear relationships within the mapped range, and from global statistical methods like [Percentile-based Normalization](5158-percentile-based-normalization.md) by relying on fixed or global extrema rather than distribution percentiles [G].

## How it works
### Inputs and Outputs
- **Inputs**: A scalar field $V$ (e.g., Hounsfield Units, raw density) or a set of 3D coordinates $P$. A scale factor $s$ and optionally a bias $b$.
- **Outputs**: A normalized scalar field $V'$ or transformed coordinates $P'$.

### Data Structures
- **Scalar Field**: A 3D grid or tensor of floating-point values.
- **Coordinates**: A vector of shape $(N, 3)$ representing spatial positions.

### Steps
1. **Coordinate Scaling**: Divide each point $p$ by the scale factor $s$ [S1, unofficial].
2. **HU to Attenuation Mapping**: Calculate an intermediate HU value from the volume data, then compute the attenuation coefficient $\mu$ [S2, unofficial].
3. **Scene Extent Normalization**: Apply a corrected scene extent $e'_{scene}$ to the densification splitting condition to improve precision [S4].

### Formulas
- Coordinate scaling: $p' = p / s$ [S1, unofficial]
- Intermediate HU calculation: $hu = vol \times (3024 - (-3524)) + (-3524)$
- Attenuation coefficient: $\mu = 0.05 \times (1.0 + hu / 800.0)$ [S2, unofficial]
- Densification splitting condition: $max(s_k) > P_{dense} \cdot e'_{scene}$ [S4]

### Parameters
- **Scale Factor ($s$)**: Determines the spatial extent. For Voronoi-based methods, $s$ is chosen such that sites $\phi \in [-1, 1]^{N \times 3}$ [S3].
- **Clamping**: Values outside the target range are clamped to the boundaries [S2, unofficial].

### Edge Cases and Pitfalls
- **Zero Division**: If $max_v = min_v$ during min/max scaling, the denominator becomes zero; return zeros or a constant [G].
- **Optimizer Instability**: Without coordinate scaling, optimizers like ADAM may oscillate or converge slowly due to variable magnitude invariance issues [S3].
- **Precision**: In fixed-point or low-precision formats, extreme dynamic ranges may lose detail [G].

### Pseudocode
```python
def scale_coordinates(points, scale_factor):
    """Scale 3D points by a factor s."""
    return points / scale_factor

def hu_to_attenuation(vol):
    """Map Hounsfield Units to attenuation coefficients."""
    hu = vol * (3024 - (-3524)) + (-3524)
    mu = 0.05 * (1.0 + hu / 800.0)
    return mu

def check_scene_extent_splitting(max_splat_scale, P_dense, e_prime_scene):
    """Determine if a Gaussian should be split based on corrected scene extent."""
    return max_splat_scale > P_dense * e_prime_scene
```

## Subtopics

### [Power Transformation](2346-power-transformation.md)
The Power Transformation is a parameterized function used to map metric distance $t$ to a normalized distance $s$, enabling effective resampling and distortion loss calculation in neural radiance fields. It sets itself apart from discrete normalization choices (like pure log or inverse distance) by allowing smooth interpolation between linear, logarithmic, and inverse behaviors via a single shape parameter $\lambda$, while maintaining a linear-like shape near the origin to avoid singularities at the ray start.

### [Scaling and Biasing](2888-scaling-and-biasing.md)
Scaling and Biasing applies a linear transformation to volume texture samples to adjust contrast and brightness, commonly known as window/level adjustment. It maps a specific range of input intensities to the full display range. Unlike non-linear methods such as [Power Transformation](2346-power-transformation.md), it preserves the linear relationship between input intensity and output brightness within the window.

### Linear HU to Attenuation Map
A simple linear mapping from Hounsfield Units (HU) to attenuation coefficients ($\mu$) with clamping [S2, unofficial].
- **Step**: Calculate intermediate HU value: $hu = vol \times (3024 - (-3524)) + (-3524)$.
- **Step**: Calculate $\mu$: $\mu = 0.05 \times (1.0 + hu / 800.0)$ [S2, unofficial].

### Parameter Magnitude Scaling
A preprocessing step scaling the scene coordinate system so that Voronoi sites $\phi \in [-1, 1]^{N \times 3}$ [S3]. This is necessary when using optimizers like ADAM to prevent training oscillation or slow progress due to variable magnitude invariance issues [S3]. Without scaling, common optimizers like ADAM may fail to converge properly because the training process is not invariant to the magnitude of individual variables [S3].

### Scene Extent Normalization
A correction mechanism for the scene extent $e'_{scene}$ used in the densification splitting condition to improve precision [S4].
- **Step**: Use the corrected scene extent $e'_{scene}$ in the condition $max(s_k) > P_{dense} \cdot e'_{scene}$ to determine if a Gaussian should be split [S4].
- **Comparison**: Deactivating this component causes the highest decrease in PSNR among the proposed methods, indicating its critical role in reconstruction quality [S4].

## Background
Scaling is a foundational technique in computer graphics and scientific visualization [G]. Its application in neural volume rendering, particularly for coordinate scaling to prevent optimizer instability, was highlighted in the DeRF paper [S3]. The specific linear mapping from HU to attenuation coefficients is used in medical imaging pipelines [S2, unofficial]. The Power Transformation for distance mapping in neural fields is described in the Torch-Sphere-Tracer repository [S1, unofficial].
