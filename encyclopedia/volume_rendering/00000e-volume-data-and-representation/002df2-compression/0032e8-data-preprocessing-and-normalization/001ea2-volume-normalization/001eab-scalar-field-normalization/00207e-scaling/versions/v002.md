# Scaling
Also called: Scalar Field Scaling
## Overview
Scaling is a fundamental normalization technique that maps scalar field data to a target range, typically [0, 1], based on global minimum and maximum values [Parent]. It serves as the base linear transformation for volume data preparation, distinguishing itself from non-linear methods like [Power Transformation](2346-power-transformation.md) by preserving relative distances linearly.
## How it works
### Inputs and outputs
- **Input**: A scalar field $V$ with global minimum $min$ and maximum $max$.
- **Output**: A normalized scalar field $V'$ where values are scaled to the target range.

### Data structures
- **Scalar Field**: A 3D grid or tensor of floating-point values representing the volume data.

### Steps
1. Determine the global minimum $min$ and maximum $max$ of the input scalar field $V$.
2. For each voxel value $v$ in $V$, compute the normalized value $v'$ using the linear scaling formula:
   $$ v' = \frac{v - min}{max - min} $$
3. If the target range is not [0, 1], apply a bias and scale:
   $$ v' = v' \cdot (max_{target} - min_{target}) + min_{target} $$

### Parameters
- **Target Range**: Typically [0, 1].
- **Clamping**: Optional clamping to handle outliers or NaN values.

### Edge cases and pitfalls
- **Zero Denominator**: If $min = max$, the denominator becomes zero. Handle by setting all values to the midpoint of the target range or a default value [G].
- **Outliers**: Extreme outliers can compress the useful data range. Consider using percentile-based min/max instead of global min/max if outliers are present [G].
- **Precision**: Ensure sufficient floating-point precision to avoid quantization artifacts in the normalized output.

### Pseudocode
```python
def scale_scalar_field(V, min_val, max_val, target_min=0.0, target_max=1.0):
    """
    Scale scalar field V to target range [target_min, target_max].
    
    Args:
    V: Input scalar field (3D tensor or array).
    min_val: Global minimum of V.
    max_val: Global maximum of V.
    target_min: Lower bound of target range.
    target_max: Upper bound of target range.
    
    Returns:
    V_scaled: Scaled scalar field.
    """
    if max_val == min_val:
        # Handle zero denominator case
        midpoint = (target_min + target_max) / 2.0
        return torch.full_like(V, midpoint)
    
    # Linear scaling
    V_scaled = (V - min_val) / (max_val - min_val)
    V_scaled = V_scaled * (target_max - target_min) + target_min
    
    return V_scaled
```

## Subtopics

### [Power Transformation](2346-power-transformation.md)
The Power Transformation is a parameterized function used to map metric distance $t$ to a normalized distance $s$, enabling effective resampling and distortion loss calculation in neural radiance fields. It sets itself apart from discrete normalization choices (like pure log or inverse distance) by allowing smooth interpolation between linear, logarithmic, and inverse behaviors via a single shape parameter $\lambda$, while maintaining a linear-like shape near the origin to avoid singularities at the ray start.

### [Scaling and Biasing](2888-scaling-and-biasing.md)
Scaling and Biasing applies scaling and biasing to texture samples for window/level contrast adjustment. It sets the current sample's volume to $x \cdot 16 + y$. It differs from [Power Transformation](2346-power-transformation.md) by applying a linear transformation rather than a non-linear mapping [G].

### Linear HU to Attenuation Map
#### Definition
A simple linear mapping from Hounsfield Units (HU) to attenuation coefficients (mu) with clamping [S2, unofficial].

#### Steps
1. Calculate intermediate HU value: $hu = vol \cdot (3024 - (-3524)) + (-3524)$ [S2, unofficial].
2. Calculate mu: $mu = 0.05 \cdot (1.0 + hu / 800.0)$ [S2, unofficial].

#### Code
```python
def linear_hu_to_mu(vol):
    """
    Convert volume data (assumed to be in a specific range) to attenuation coefficients.
    
    Args:
    vol: Input volume data.
    
    Returns:
    mu: Attenuation coefficients.
    """
    hu = vol * (3024 - (-3524)) + (-3524)
    mu = 0.05 * (1.0 + hu / 800.0)
    return mu
```

## Operating characteristics
- **Time Complexity**: $O(N)$, where $N$ is the number of voxels.
- **Memory Complexity**: $O(N)$ for storing the normalized field.
- **Strengths**: Simple, fast, and preserves linear relationships.
- **Limitations**: Sensitive to outliers; may not enhance subtle features as effectively as non-linear methods.
- **When to Use**: When linear scaling is sufficient and outliers are not a concern.
- **When Not to Use**: When non-linear enhancement is needed or outliers significantly affect the range.

## Background
Scaling is a basic operation in data normalization, widely used in volume rendering for preparing scalar field data. It is often a precursor to more complex normalization techniques.
