# Scaling

Also called: Scalar Field Scaling

## Overview
Scaling is a specific instance of [Scalar Field Normalization](1842-scalar-field-normalization.md) that maps input data to the range $[0, 1]$ using the global minimum and maximum values. It serves as the foundational linear transformation for volume data preprocessing, distinct from non-linear methods like [Percentile-based Normalization](5158-percentile-based-normalization.md) which ignore outliers.

## How it works
**Inputs:** A scalar field $V$ with global minimum $min$ and maximum $max$.
**Outputs:** A normalized scalar field $V'$ where $V' \in [0, 1]$.

**Data Structures:**
- Input: Array of floating-point values representing the volume.
- Parameters: $min$ (float), $max$ (float).

**Steps:**
1. Compute the range $R = max - min$.
2. For each voxel value $v$ in $V$:
   $$ v' = \frac{v - min}{R} $$
3. Clamp $v'$ to $[0, 1]$ to handle potential precision errors or if $min=max$.

**Parameters:**
- $min$: Global minimum of the input volume.
- $max$: Global maximum of the input volume.

**Edge Cases:**
- If $min = max$, the range is zero. The result is undefined by the formula; typically, the output is set to 0 or 0.5 [G].
- Precision loss may occur if $min$ and $max$ are large and close together in floating-point arithmetic.

## Subtopics

### [Power Transformation](2346-power-transformation.md)
The Power Transformation is a parameterized function used to map metric distance $t$ to a normalized distance $s$, enabling effective resampling and distortion loss calculation in neural radiance fields. It sets itself apart from discrete normalization choices (like pure log or inverse distance) by allowing smooth interpolation between linear, logarithmic, and inverse behaviors via a single shape parameter $\lambda$, while maintaining a linear-like shape near the origin to avoid singularities at the ray start.

#### Parameter Magnitude Scaling
**Definition:** A preprocessing step scaling the scene coordinate system so that Voronoi sites $\phi \in [-1, 1]^{N \times 3}$ [S3]. This is necessary when using optimizers like ADAM to prevent training oscillation or slow progress due to variable magnitude invariance issues [S3].
**Pitfall:** Without scaling, common optimizers like ADAM may fail to converge properly because the training process is not invariant to the magnitude of individual variables [S3].

## Operating characteristics
**Time and Memory Complexity:** $O(N)$ time and $O(1)$ auxiliary memory, where $N$ is the number of voxels.
**Strengths:** Simple to implement; preserves relative linear relationships.
**Limitations:** Highly sensitive to outliers; a single extreme value can compress the majority of the data into a narrow range near 0 or 1.
**When to use:** When the data distribution is uniform and free of significant outliers.
**When not to use:** When the data contains extreme outliers or has a heavy-tailed distribution; use [Percentile-based Normalization](5158-percentile-based-normalization.md) instead.

## Background
Scaling is a standard linear normalization technique widely used in computer graphics and scientific visualization. It is often the first step in volume rendering pipelines to ensure data fits within standard texture coordinate ranges or shader expectations.
