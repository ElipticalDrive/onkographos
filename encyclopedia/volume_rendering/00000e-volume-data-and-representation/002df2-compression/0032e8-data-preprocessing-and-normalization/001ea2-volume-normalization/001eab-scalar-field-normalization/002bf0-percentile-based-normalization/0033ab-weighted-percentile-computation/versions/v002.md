# Weighted Percentile Computation


## Overview
Computes the weighted percentiles of a step function defined by points $t$ and weights $w$, where weights must sum to 1 [S1, unofficial]. It is used to compute weighted percentile(s) of a single vector for determining value bounds for visualization [S2, unofficial]. It differs from standard percentile computation by incorporating a weight vector into the cumulative distribution calculation [S2, unofficial].

## How it works
**Inputs:**
- $x$: A vector of data values (points $t$).
- $w$: A vector of non-negative weights corresponding to $x$.
- $ps$: A list of target percentile values (e.g., $[1, 99]$) [S2, unofficial].
- `assume_sorted`: A boolean flag indicating if $x$ is already sorted in ascending order [S2, unofficial].

**Outputs:**
- $p$: A vector of weighted percentile values corresponding to $ps$.

**Data Structures:**
- $x$: 1D array of length $N$.
- $w$: 1D array of length $N$.
- $cw$: 1D array of length $N$ storing cumulative weights.
- $p$: 1D array of length $M$ (number of target percentiles).

**Steps:**
1. **Reshape:** Flatten $x$ and $w$ into 1D vectors if they are not already [S2, unofficial].
2. **Sort (if necessary):** If `assume_sorted` is false, sort $x$ and $w$ together by the values in $x$ [S2, unofficial].
3. **Cumulative Weights:** Compute the cumulative sum of the weights: $cw_i = \sum_{j=0}^{i} w_j$ for $i = 0, \dots, N-1$ [S1, S2, unofficial]. Let $W_{total} = cw_{N-1}$.
4. **Target Cumulative Values:** For each target percentile $ps_k$, compute the target cumulative weight: $T_k = ps_k \times \frac{W_{total}}{100}$ [S2, unofficial].
5. **Interpolation:** For each $T_k$, find index $k$ such that $cw_k \le T_k < cw_{k+1}$ (clamping to the first or last element if $T_k$ falls outside $[cw_0, cw_{N-1}]$) and compute: $p_k = x_k + \frac{T_k - cw_k}{cw_{k+1} - cw_k}(x_{k+1} - x_k)$ [S1, S2, unofficial].
6. **Reshape:** Reshape the output vector $p$ to match the original shape of $x$ plus a new dimension for the percentiles [S1, unofficial].

**Pseudocode:**
```python
def weighted_percentile(x, w, ps, assume_sorted=False):
    # 1. Reshape to 1D
    x = list(x) if not isinstance(x, list) else x
    w = list(w) if not isinstance(w, list) else w
    N = len(x)
    
    # 2. Sort if necessary
    if not assume_sorted:
        sortidx = sorted(range(N), key=lambda i: x[i])
        x = [x[i] for i in sortidx]
        w = [w[i] for i in sortidx]
        
    # 3. Cumulative weights
    acc_w = []
    current = 0.0
    for val in w:
        current += val
        acc_w.append(current)
    total_w = acc_w[-1] if acc_w else 0.0
    
    # 4. Target cumulative values
    targets = [p * (total_w / 100.0) for p in ps]
    
    # 5. Interpolation helper
    def interp(target, cw, vals):
        if total_w == 0.0:
            return 0.0
        if target <= cw[0]:
            return vals[0]
        if target >= cw[-1]:
            return vals[-1]
        k = 0
        while k < len(cw) - 1 and cw[k+1] < target:
            k += 1
        denom = cw[k+1] - cw[k]
        if denom == 0.0:
            return vals[k]
        return vals[k] + ((target - cw[k]) / denom) * (vals[k+1] - vals[k])
        
    results = [interp(t, acc_w, x) for t in targets]
    
    # 6. Reshape (restore original dimensions if needed)
    return results
```

**Parameters:**
- `ps`: Typical values are $[1, 99]$ or $[0.1, 99.9]$ for robust bounds [S2, unofficial].
- `assume_sorted`: Defaults to `False` [S2, unofficial].

**Edge Cases and Pitfalls:**
- **Zero Total Weight:** If $\sum w = 0$, the method is undefined and interpolation fails [G].
- **Negative Weights:** The method assumes non-negative weights, as negative weights break the cumulative distribution interpretation [G].
- **Unsorted Data:** If `assume_sorted` is false and data is not sorted, the cumulative sum will be incorrect, leading to wrong percentiles [S2, unofficial].
- **Precision:** Floating-point precision in cumulative sum can accumulate error for very large $N$; Kahan summation may be required for extreme precision [G].

## Operating characteristics
- **Time Complexity:** $O(N \log N)$ due to sorting, or $O(N)$ if `assume_sorted` is true [G].
- **Memory Complexity:** $O(N)$ to store the sorted arrays and cumulative weights [G].
- **Strengths:** Robust to outliers; allows emphasis on high-confidence or high-opacity regions; computationally efficient for large datasets [S2, unofficial].
- **Limitations:** Requires a weight vector; sensitive to the choice of weights; not suitable for data with negative weights without modification [G].
- **Measured Performance:** Not given in the sources.

## Background
Weighted percentile computation is a statistical technique used in image processing and volume rendering to determine robust statistics [S2, unofficial]. It is implemented in open-source projects for 3D reconstruction and visualization [S1, S2, unofficial].
