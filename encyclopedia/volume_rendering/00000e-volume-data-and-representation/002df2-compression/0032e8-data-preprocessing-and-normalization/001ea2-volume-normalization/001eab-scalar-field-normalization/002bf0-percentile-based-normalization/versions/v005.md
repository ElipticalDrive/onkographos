# Percentile-based Normalization
Also called: DRR Image Normalization, Grayscale Mapping
## Overview
Percentile-based Normalization scales scalar field data to the range $[0, 1]$ by using robust statistical bounds (percentiles) instead of global extrema, effectively ignoring outliers that would otherwise compress the visible contrast. It differs from [Scaling](2287-scaling.md) and [Scalar Field Normalization](1842-scalar-field-normalization.md) by replacing the absolute minimum and maximum with the $p_{min}$-th and $p_{max}$-th percentiles, ensuring that extreme noise or sparse artifacts do not dominate the dynamic range. This method is particularly suited for generating Digital Radiograph (DRR) images and 8-bit visualizations where preserving local contrast is critical.
## How it works
**Inputs and Outputs:**
- Input: A scalar field (e.g., a 2D projection image or 3D volume) $I$ with arbitrary real values.
- Output: A normalized scalar field $I_{norm}$ in $[0, 1]$ or an 8-bit integer image $I_{8bit}$ in $[0, 255]$.

**Data Structures:**
- The input is treated as a dense array of floating-point values.
- Two scalar bounds, $v_{min}$ and $v_{max}$, are computed.

**Steps:**
1. **Compute Percentile Bounds:** Calculate the lower bound $v_{min}$ as the $p_{min}$-th percentile and the upper bound $v_{max}$ as the $p_{max}$-th percentile of the input data $I$. Typical values are $p_{min}=5$ and $p_{max}=95$ to exclude the most extreme 10% of values [S1, unofficial].
2. **Clip Values:** Clip all values in $I$ to the range $[v_{min}, v_{max}]$. Values below $v_{min}$ become $v_{min}$, and values above $v_{max}$ become $v_{max}$.
3. **Normalize:** Apply linear scaling to map the clipped range to $[0, 1]$. A small epsilon $\epsilon$ is added to the denominator to prevent division by zero if $v_{min} = v_{max}$.
   $$ I_{norm}(x) = \frac{\max(0, \min(1, \frac{I_{clipped}(x) - v_{min}}{v_{max} - v_{min} + \epsilon}))} $$
   where $\epsilon = 10^{-8}$ [S1, unofficial].
4. **Quantize (Optional):** To produce an 8-bit grayscale image, scale by 255 and cast to unsigned 8-bit integer:
   $$ I_{8bit}(x) = \text{uint8}(I_{norm}(x) \times 255) $$

**Pseudocode:**
```python
import numpy as np

def percentile_normalize(image: np.ndarray, p_min: float = 5.0, p_max: float = 95.0) -> np.ndarray:
    """
    Normalize image data using percentile-based clipping and scaling.
    Returns float array in [0, 1].
    """
    # Step 1: Compute bounds
    v_min = np.percentile(image, p_min)
    v_max = np.percentile(image, p_max)
    
    # Step 2: Clip
    image_clipped = np.clip(image, v_min, v_max)
    
    # Step 3: Normalize
    # Add epsilon to avoid division by zero
    epsilon = 1e-8
    range_val = v_max - v_min + epsilon
    image_normalized = (image_clipped - v_min) / range_val
    
    # Ensure strict [0, 1] bounds due to potential floating point errors
    image_normalized = np.clip(image_normalized, 0.0, 1.0)
    
    return image_normalized

def percentile_normalize_to_8bit(image: np.ndarray, p_min: float = 5.0, p_max: float = 95.0) -> np.ndarray:
    """
    Normalize and convert to 8-bit grayscale.
    """
    norm = percentile_normalize(image, p_min, p_max)
    return (norm * 255).astype(np.uint8)
```

**Parameters:**
- $p_{min}$: Lower percentile. Default 5.0 [S1, unofficial].
- $p_{max}$: Upper percentile. Default 95.0 [S1, unofficial].
- $\epsilon$: Epsilon for numerical stability. Default $10^{-8}$ [S1, unofficial].

**Edge Cases:**
- If $v_{min} = v_{max}$ (e.g., constant image), the denominator becomes $\epsilon$, resulting in a zero image (all black) after clipping, which is a safe fallback [S1, unofficial].
- Outliers: By definition, this method ignores values outside the percentile range, which is its primary advantage over min-max normalization.

## Operating characteristics
- **Time Complexity:** $O(N)$ to compute percentiles and $O(N)$ to clip and scale, where $N$ is the number of voxels/pixels. Percentile computation can be $O(N)$ using selection algorithms or $O(N \log N)$ using sorting.
- **Memory Complexity:** $O(N)$ for the input and output arrays. No significant auxiliary memory is required.
- **Strengths:** Robust to outliers; preserves contrast in the "interesting" part of the data distribution; simple to implement.
- **Limitations:** Requires a full pass over the data to compute percentiles; not suitable for streaming data where global statistics are unknown.
- **When to use:** Visualization of medical images (CT, DRR), scientific data with heavy-tailed distributions, or when global min/max are dominated by noise.
- **When not to use:** When absolute intensity values are critical for quantitative analysis, or when the data distribution is uniform and min-max normalization is sufficient.

## Background
This method is widely used in medical imaging, particularly in the generation of Digital Radiograph (DRR) images from CT data. It serves as a standard preprocessing step to map Hounsfield units or attenuation coefficients to a displayable range. The approach is documented in practical implementations for ray-casting and DRR generation [S1, unofficial].
