# Colormap Visualization with Weighted Bounds
## Overview
Visualizes a 1D scalar image and a 1D weighting map according to a colormap, using weighted percentiles to determine normalization bounds [S1, unofficial]. It differs from standard normalization by incorporating per-pixel weights into the percentile calculation, allowing the bounds to reflect the distribution of significant data rather than the full range [S1, unofficial].
## How it works
**Inputs and Outputs:**
Inputs are a scalar field `value`, a weighting field `weight`, an optional `colormap`, an optional `percentile` (default 99), optional explicit bounds `lo` and `hi`, an optional `curve_fn`, and an optional `modulus` [S1, unofficial]. The output is a colorized RGB image `colorized` [S1, unofficial].

**Data Structures:**
Both `value` and `weight` are arrays or tensors of identical shape `(H, W)` [S1, unofficial]. The bounds `lo` and `hi` are scalars [S1, unofficial]. The `colorized` output is a 3D array of shape `(H, W, 3)` containing RGB values [S1, unofficial].

**Steps and Formulas:**
1. Compute automatic lower and upper bounds using weighted percentiles [S1, unofficial]:
   $$ lo\_auto, hi\_auto = \text{weighted\_percentile}(value, weight, [50 - \frac{percentile}{2}, 50 + \frac{percentile}{2}]) $$
2. Set final bounds with epsilon adjustment to prevent division by zero [S1, unofficial]:
   $$ \epsilon = \text{np.finfo}(\text{np.float32}).\text{eps} $$
   $$ lo = lo \text{ if } lo \text{ is not None else } (lo\_auto - \epsilon) $$
   $$ hi = hi \text{ if } hi \text{ is not None else } (hi\_auto + \epsilon) $$
3. Apply the curve function to the value and bounds [S1, unofficial]:
   $$ value, lo, hi = [\text{curve\_fn}(x) \text{ for } x \text{ in } [value, lo, hi]] $$
4. If `modulus` is provided, normalize the value by the modulus [S1, unofficial]:
   $$ value = \frac{\text{np.mod}(value, modulus)}{modulus} $$
5. Otherwise, clip and scale the value to the range `[0, 1]` [S1, unofficial]:
   $$ value = \text{np.nan\_to\_num}\left(\text{np.clip}\left(\frac{value - \text{np.minimum}(lo, hi)}{\text{np.abs}(hi - lo)}, 0, 1\right)\right) $$
6. Apply the colormap if provided [S1, unofficial]:
   $$ colorized = \text{colormap}(value)[:, :, :3] $$
7. If no colormap is provided, assume the value is already in RGB format [S1, unofficial]:
   $$ \text{assert len}(value.\text{shape}) == 3 \text{ and } value.\text{shape}[-1] == 3 $$
   $$ colorized = value $$
8. Return the `colorized` image [S1, unofficial].

**Parameters:**
- `percentile`: The percentile of the value map to crop to when automatically generating `lo` and `hi` [S1, unofficial]. Default is 99 [S1, unofficial].
- `curve_fn`: A curve function applied to `value`, `lo`, and `hi` before visualization [S1, unofficial]. Default is the identity function `lambda x: x` [S1, unofficial].
- `modulus`: If not `None`, the normalized value is modulo-divided by `modulus` [S1, unofficial]. Use a value in `(0, 1]` [S1, unofficial]. If `modulus` is not `None`, `lo`, `hi`, and `percentile` are ignored [S1, unofficial].

**Edge Cases and Pitfalls:**
- If `lo` equals `hi`, division by zero occurs in step 5 [S1, unofficial]. The epsilon adjustment in step 2 ensures `hi` is strictly greater than `lo_auto` (and `lo` is strictly less than `hi_auto`), mitigating this risk [S1, unofficial].
- `np.nan_to_num` replaces `NaN` values in `value` with `0` before clipping [S1, unofficial].
- When `modulus` is provided, the automatic bounds and curve function are bypassed entirely [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def visualize_cmap(value, weight, colormap=None, percentile=99, lo=None, hi=None, curve_fn=None, modulus=None):
    # Default curve_fn to identity if not provided
    curve_fn = curve_fn or (lambda x: x)
    # Note: weighted_percentile is defined in the parent article [S1, unofficial]
    lo_auto, hi_auto = weighted_percentile(value, weight, [50 - percentile / 2, 50 + percentile / 2])
    eps = np.finfo(np.float32).eps
    lo = lo if lo is not None else (lo_auto - eps)
    hi = hi if hi is not None else (hi_auto + eps)
    value, lo, hi = [curve_fn(x) for x in [value, lo, hi]]
    if modulus is not None:
        value = np.mod(value, modulus) / modulus
    else:
        value = np.nan_to_num(np.clip((value - np.minimum(lo, hi)) / np.abs(hi - lo), 0, 1))
    if colormap is not None:
        colorized = colormap(value)[:, :, :3]
    else:
        assert len(value.shape) == 3 and value.shape[-1] == 3
        colorized = value
    return colorized
```
