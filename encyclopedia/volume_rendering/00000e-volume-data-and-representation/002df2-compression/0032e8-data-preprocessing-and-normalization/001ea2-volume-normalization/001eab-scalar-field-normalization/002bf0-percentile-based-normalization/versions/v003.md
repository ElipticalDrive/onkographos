# Percentile-based Normalization

Also called: DRR Image Normalization, Grayscale Mapping

## Overview
Percentile-based normalization scales scalar field data to a target range (typically [0, 1] or [0, 255]) by using robust statistical bounds (percentiles) rather than global extrema. This method solves the problem of outlier sensitivity in global normalization [S1, S2, unofficial]. Unlike [Scaling](2287-scaling.md), which uses the absolute minimum and maximum, percentile-based normalization ignores extreme tails of the distribution, preserving contrast for the majority of the data [S1, unofficial].

## How it works
**Inputs:** A scalar field (image or volume) $I$.
**Outputs:** A normalized scalar field $I_{norm}$ in $[0, 1]$ or an 8-bit integer representation $I_{8bit}$.

**Data Structures:**
- Input: Array of floating-point values.
- Output: Array of floating-point values in $[0, 1]$ or `uint8` array.

**Steps:**
1. **Compute Bounds:** Calculate the lower percentile $p_{min}$ and upper percentile $p_{max}$ of the finite values in $I$. Common choices are the 5th and 95th percentiles [S1, unofficial].
2. **Clip:** Clip the input values to the computed bounds:
   $$ I_{clipped} = \text{clip}(I, p_{min}, p_{max}) $$
3. **Normalize:** Scale the clipped values to $[0, 1]$ using linear interpolation. A small epsilon $\epsilon$ is added to the denominator to prevent division by zero if $p_{min} \approx p_{max}$ [S1, unofficial]:
   $$ I_{norm} = \frac{I_{clipped} - p_{min}}{p_{max} - p_{min} + \epsilon} $$
   Typical $\epsilon = 10^{-8}$ [S1, unofficial].
4. **Quantize (Optional):** Convert to 8-bit grayscale for display:
   $$ I_{8bit} = \text{astype}(\lfloor I_{norm} \times 255 \rfloor, \text{uint8}) $$ [S1, unofficial].

**Parameters:**
- $p_{min}, p_{max}$: Percentile values (e.g., 5, 95).
- $\epsilon$: Epsilon for numerical stability (e.g., $10^{-8}$) [S1, unofficial].

**Edge Cases:**
- If all values are identical, $p_{min} = p_{max}$, resulting in a zero denominator. The epsilon term handles this [S1, unofficial].
- Non-finite values (NaN, Inf) should be excluded from percentile calculation [S2, unofficial].

**Pseudocode:**
```python
import numpy as np

def percentile_normalize(image, p_min=5, p_max=95, epsilon=1e-8):
    """
    Normalize image using percentile-based windowing.
    
    Args:
        image: np.ndarray of float values.
        p_min: Lower percentile (0-100).
        p_max: Upper percentile (0-100).
        epsilon: Small constant to avoid division by zero.
        
    Returns:
        np.ndarray: Normalized image in [0, 1].
    """
    # Filter finite values for robust percentile calculation
    finite_mask = np.isfinite(image)
    finite_values = image[finite_mask]
    
    if finite_values.size == 0:
        return np.zeros_like(image)
        
    # Step 1: Calculate bounds
    min_val = np.percentile(finite_values, p_min)
    max_val = np.percentile(finite_values, p_max)
    
    # Step 2: Clip
    image_clipped = np.clip(image, min_val, max_val)
    
    # Step 3: Normalize
    denominator = max_val - min_val + epsilon
    image_normalized = (image_clipped - min_val) / denominator
    
    return image_normalized

def normalize_to_8bit(image, p_min=5, p_max=95, epsilon=1e-8):
    """
    Normalize image and convert to 8-bit uint8.
    """
    norm = percentile_normalize(image, p_min, p_max, epsilon)
    return (norm * 255).astype(np.uint8)
```

## Subtopics

### Intensity-to-Grayscale Mapping
Maps absolute field intensity values to 8-bit grayscale luminance indices [0, 255] using percentile normalization combined with gamma compression [S2, unofficial]. It differs from standard linear normalization by applying a non-linear gamma transform to enhance mid-range contrast [S2, unofficial]. Choose this when visual perception of intensity variations is prioritized over linear physical accuracy [S2, unofficial].

**Steps:**
1. **Compute Saturation Threshold:** Calculate the upper bound $b_{max}$ as the 99th percentile of finite intensity values plus epsilon [S2, unofficial]:
   $$ b_{max} = \text{percentile}(I_{finite}, 99) + \epsilon $$
2. **Normalize:** Clip and scale to $[0, 1]$ [S2, unofficial]:
   $$ I_{norm} = \text{clip}\left(\frac{I}{b_{max}}, 0, 1\right) $$
3. **Gamma Compression:** Apply gamma correction and scale to 8-bit [S2, unofficial]:
   $$ I_{8bit} = \text{astype}(\lfloor I_{norm}^\gamma \times 255 \rfloor, \text{int}) $$

**Parameters:**
- $\gamma$: Compression exponent. Default is 0.55. Values $< 1$ expand the mid-range [S2, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N)$ for sorting or selection algorithms to compute percentiles, where $N$ is the number of voxels/pixels [S1, unofficial].
- **Memory Complexity:** $O(N)$ to store the input and output arrays [S1, unofficial].
- **Strengths:** Robust against outliers; preserves contrast in the central distribution [S1, unofficial].
- **Limitations:** Loses information about extreme values; requires a full pass over data to compute statistics [S1, unofficial].
- **When to Use:** Medical imaging (DRR), astrophysical visualization where dynamic range is large and outliers are common [S1, S2, unofficial].
- **When Not to Use:** When absolute intensity values are critical for quantitative analysis [S1, unofficial].

## Background
Originated in medical imaging for generating Digital Radiography (DRR) images from CT data, where robust windowing is essential for visualizing anatomical structures [S1, unofficial]. Also applied in astrophysical vector field visualization to map magnetic field intensities to grayscale [S2, unofficial].
