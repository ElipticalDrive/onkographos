# Percentile-based Normalization

Also called: DRR Image Normalization, Grayscale Mapping

## Overview
Percentile-based Normalization scales scalar field data to a target range (typically [0, 1] or [0, 255]) by using percentile bounds instead of global extrema. This method mitigates the impact of outliers, which is critical in medical imaging (e.g., DRR generation) where extreme values can compress the visible contrast of the region of interest [S1, unofficial]. It differs from [Scaling](2287-scaling.md) by using robust statistical bounds rather than absolute min/max values.

## How it works
**Inputs:** Input scalar field $I$ (e.g., a 2D projection image or 3D volume).
**Outputs:** Normalized scalar field $I_{norm}$ in $[0, 1]$ or 8-bit integer image $I_{8bit}$.

**Data Structures:**
- $I$: Input array of floats.
- $min\_val, max\_val$: Float scalars representing the lower and upper percentile bounds.
- $I_{clipped}$: Array with values clamped to $[min\_val, max\_val]$.

**Steps:**
1. **Compute Percentiles:** Calculate the lower percentile $P_{low}$ (e.g., 5th) and upper percentile $P_{high}$ (e.g., 95th) of the input data $I$.
   $$ min\_val = P_{low}(I) $$
   $$ max\_val = P_{high}(I) $$
   [S1, unofficial]

2. **Clip Values:** Clamp all values in $I$ to the computed bounds to exclude outliers.
   $$ I_{clipped}(x) = \begin{cases} min\_val & \text{if } I(x) < min\_val \\ I(x) & \text{if } min\_val \le I(x) \le max\_val \\ max\_val & \text{if } I(x) > max\_val \end{cases} $$
   [S1, unofficial]

3. **Normalize:** Linearly scale the clipped values to $[0, 1]$. A small epsilon $\epsilon$ is added to the denominator to prevent division by zero if $min\_val \approx max\_val$.
   $$ I_{norm}(x) = \frac{I_{clipped}(x) - min\_val}{max\_val - min\_val + \epsilon} $$
   where $\epsilon = 10^{-8}$ [S1, unofficial].

4. **Quantize (Optional):** Scale to 8-bit integer range for visualization.
   $$ I_{8bit}(x) = \text{uint8}(\lfloor I_{norm}(x) \times 255 \rfloor) $$
   [S1, unofficial]

**Pseudocode:**
```python
import numpy as np

def percentile_normalize(image: np.ndarray, low_percentile: float = 5.0, high_percentile: float = 95.0) -> np.ndarray:
    """
    Normalize image using percentile-based windowing.
    Returns 8-bit uint8 image.
    """
    # Step 1: Compute bounds
    min_val = np.percentile(image, low_percentile)
    max_val = np.percentile(image, high_percentile)
    
    # Step 2: Clip
    image_clipped = np.clip(image, min_val, max_val)
    
    # Step 3: Normalize to [0, 1]
    # Add epsilon to avoid division by zero
    epsilon = 1e-8
    image_normalized = (image_clipped - min_val) / (max_val - min_val + epsilon)
    
    # Step 4: Scale to 0-255 and cast
    image_8bit = (image_normalized * 255).astype(np.uint8)
    
    return image_8bit
```

**Parameters:**
- `low_percentile`: Default 5.0 [S1, unofficial].
- `high_percentile`: Default 95.0 [S1, unofficial].
- `epsilon`: Default $10^{-8}$ [S1, unofficial].

**Edge Cases:**
- If $min\_val \approx max\_val$ (e.g., uniform image), the epsilon prevents NaN/Inf results [S1, unofficial].
- Outliers are strictly ignored in the scaling factor but clamped to the bounds [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N)$ to compute percentiles and $O(N)$ to clip/normalize, where $N$ is the number of pixels/voxels.
- **Memory Complexity:** $O(N)$ for the output array.
- **Strengths:** Robust against outliers; enhances contrast for the central distribution of data [S1, unofficial].
- **Limitations:** Loses information about extreme values; requires a full pass to compute percentiles [S1, unofficial].
- **Use Case:** Medical imaging (DRR), where bone or air artifacts might skew global min/max [S1, unofficial].

## Background
Originated in medical image processing for Digital Radiography (DRR) generation. The method simulates X-ray film contrast by focusing on the relevant attenuation range [S1, unofficial].
