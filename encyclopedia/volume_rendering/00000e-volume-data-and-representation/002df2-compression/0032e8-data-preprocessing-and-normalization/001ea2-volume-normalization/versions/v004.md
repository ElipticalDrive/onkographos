# Volume Normalization

Also called: Min-Max Volume Normalization, Linear Volume Scaling

## Overview
Volume Normalization transforms a volume tensor's scalar values into a standardized numerical range, typically $[0, 1]$, to resolve issues with disparate data magnitudes, numerical instability, and poor convergence in neural optimization or threshold-based segmentation [S1, S3, S4, S5, unofficial]. It sets itself apart from non-linear methods like [Power Transformation](2346-power-transformation.md) by preserving linear relationships within the mapped range, and from robust statistical methods like [Percentile-based Normalization](5158-percentile-based-normalization.md) by relying on fixed global extrema rather than distribution percentiles [S1, S4, S5, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A volume tensor $V$ of shape $(D, H, W)$ or $(D, H, W, C)$ containing scalar values.
- Output: A normalized volume tensor $V_{norm}$ of the same shape, with values in $[0, 1]$.

**Data Structures:**
- The volume is treated as a dense array of floating-point numbers. No additional metadata structures are required for the normalization step itself.

**Steps:**
1. Compute the global minimum value $v_{min} = \min(V)$ and global maximum value $v_{max} = \max(V)$ across all voxels in the volume.
2. Calculate the range $R = v_{max} - v_{min}$.
3. Check for degeneracy: If $R \leq \epsilon$ (where $\epsilon$ is a small threshold, typically $10^{-8}$), the volume is considered constant.
   - If $v_{max} > 0.0$, set all values in $V_{norm}$ to $1.0$.
   - Otherwise, set all values in $V_{norm}$ to $0.0$.
4. For non-constant volumes, apply the linear scaling formula to each voxel $v \in V$:
   $$v_{norm} = \frac{v - v_{min}}{v_{max} - v_{min}}$$

**Pseudocode:**
```python
def volume_normalization(volume: np.ndarray, epsilon: float = 1e-8) -> np.ndarray:
    """
    Normalize a volume tensor to [0, 1] using min-max scaling.
    Handles constant volumes by mapping to 1.0 if max > 0, else 0.0.
    """
    # Step 1: Compute global extrema
    vol_min = volume.min()
    vol_max = volume.max()
    
    # Step 2: Calculate range
    vol_range = vol_max - vol_min
    
    # Step 3: Handle degenerate/constant volumes
    if vol_range <= epsilon:
        if vol_max > 0.0:
            return np.ones_like(volume, dtype=np.float32)
        else:
            return np.zeros_like(volume, dtype=np.float32)
    
    # Step 4: Apply linear normalization
    # Using float32 for consistency with typical volume data types
    normalized = (volume - vol_min) / vol_range
    return normalized.astype(np.float32)
```

**Parameters:**
- `epsilon`: Threshold for detecting constant volumes. Default is $10^{-8}$ [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Constant Volumes:** If the volume has identical values, division by zero is avoided by checking if the range is near zero. The output is $1.0$ if the constant value is positive, and $0.0$ otherwise [S1, unofficial].
- **Precision:** Use floating-point arithmetic to prevent integer division truncation.
- **Boundaries:** The method assumes the input volume contains valid scalar data. Invalid data (e.g., NaNs) should be handled prior to normalization [G].

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the number of voxels, as it requires a single pass to find min/max and another to scale.
- **Memory Complexity:** $O(N)$ for the output tensor.
- **Strengths:** Simple, fast, and preserves the relative linear ordering of voxel intensities.
- **Limitations:** Sensitive to outliers; a single extreme value can compress the dynamic range of the majority of the data. Not suitable for data with heavy-tailed distributions where robust scaling is preferred.
- **When to Use:** When data magnitudes are consistent and outliers are not a concern, or when linear relationships must be preserved for downstream neural network training.
- **When Not to Use:** When the data contains significant outliers or has a non-linear distribution that benefits from log or power transformations.

## Background
Volume Normalization is a fundamental preprocessing step in volume rendering and medical image analysis pipelines. It ensures that input data is within a standard range, which is critical for the stability of gradient-based optimization in neural networks and for consistent thresholding in segmentation tasks. The method is widely used in conjunction with other preprocessing steps such as [Preprocessing Pipeline](6733-preprocessing-pipeline.md) and [Geometric Normalization](12018-geometric-normalization.md).
