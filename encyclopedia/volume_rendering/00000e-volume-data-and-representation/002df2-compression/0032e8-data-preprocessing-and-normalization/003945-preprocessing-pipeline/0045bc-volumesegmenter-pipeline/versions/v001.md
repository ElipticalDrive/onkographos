# VolumeSegmenter Pipeline

Also called: Compact Brick Rendering, Grouped Volume Rendering

## Overview
The VolumeSegmenter Pipeline is an end-to-end method for compressing large RAW volumetric datasets into compact, spatially mapped bricks organized into selectable logical groups, enabling efficient rendering in WebGL2 [S1, unofficial]. It reduces stored and GPU-resident voxel data significantly, though it may increase rendering time due to sparse lookup and ray-marching overhead compared to monolithic source rendering [S1, unofficial]. It differs from the [Volume Partitioning Pipeline](11585-volume-partitioning-pipeline.md) by explicitly grouping bricks via intensity bands and adjacency rather than purely spatial partitioning, and builds on the general [Preprocessing Pipeline](6733-preprocessing-pipeline.md) framework.

## How it works
**Inputs and Outputs:**
*   **Input:** RAW volume slices or OME-Zarr chunks. Parameters include width, height, depth (exact voxel dimensions), data type (`uint8` or little-endian `uint16` `<u2>`), layout (X fastest, then Y, then Z), physical spacing (Z, Y, X), and byte size [S1, unofficial].
*   **Output:** A set of textures (`pageTable`, `packedData`, optional `maskData`) and metadata files representing grouped bricks, ready for WebGL2 rendering [S1, unofficial].

**Data Structures:**
1.  **Page Table Texture (`pageTable`):** `usampler3D`. Each texel is a `uvec4` record [S1, unofficial].
    *   `record.x`: 1-based index into packed data (0 means empty brick) [S1, unofficial].
    *   `record.y`: Encodes origin. Bits 0-4: Z, 5-9: Y, 10-14: X (max 31 each) [S1, unofficial].
    *   `record.z`: Encodes shape. Bits 0-5: Z, 6-11: Y, 12-17: X (max 63 each) [S1, unofficial].
    *   `record.w`: Unused/Reserved [G].
2.  **Mask Data Texture (`maskData`):** `usampler2DArray`. Used when `maskedStorage` is true [S1, unofficial].
    *   Coordinates: `ivec3(mi % maskWidth, (mi / maskWidth) % maskHeight, mi / (maskWidth * maskHeight))` [S1, unofficial].
    *   Value: `uvec2 mask`. `mask.x` is the base index offset. `mask.y` is a 32-bit bitmask for occupancy [S1, unofficial].
3.  **Packed Data Texture (`packedData`):** `usampler2DArray`. Stores actual voxel values [S1, unofficial].
    *   Coordinates: `ivec3(index % packedWidth, (index / packedWidth) % packedHeight, index / (packedWidth * packedHeight))` [S1, unofficial].

**Steps:**
1.  **Read:** Process RAW slices or OME-Zarr chunks in batches to avoid loading the full input and label volume into memory simultaneously [S1, unofficial].
2.  **Filter:** Apply an explicit intensity cutoff. This is the only lossy step. Voxels with values $\le$ cutoff are discarded [S1, unofficial].
3.  **Partition:** Divide the volume into bricks. Each nonempty brick stores only its local intensity range and its coordinates in the source volume. Bricks are never expanded to full width/height/depth [S1, unofficial].
4.  **Group:**
    *   Assign bricks to median-intensity bands defined by strictly increasing, unique edges greater than the cutoff and $\le$ data maximum [S1, unofficial].
    *   Join bricks through six-neighbor adjacency.
    *   Keep the nine largest connected components separate.
    *   Pool smaller components explicitly by band.
    *   Every brick belongs to exactly one group [S1, unofficial].
5.  **Encode:** Choose the smaller of a dense crop or an occupancy-mask representation. Masks omit interior empty positions without quantizing or deleting additional retained voxels [S1, unofficial].
6.  **Verify:** Independent readers check hashes, coordinates, ownership, values, histograms, and three maximum-intensity projections [S1, unofficial].
7.  **Render:** Logical parent AABBs reference member bricks. Selecting groups rebuilds resident textures and releases previous selections. Demand paging, caching, and LOD are not implemented [S1, unofficial].

**Ray-Box Intersection:**
Used to determine entry and exit points of a ray into a brick or volume [S1, unofficial].
$$ \mathbf{a} = -\mathbf{ro}/\mathbf{sd} $$
$$ \mathbf{b} = (\mathbf{dims} - \mathbf{ro})/\mathbf{sd} $$
$$ start = \max(0., \max(n_x, \max(n_y, n_z))) \quad \text{where } \mathbf{n} = \min(\mathbf{a}, \mathbf{b}) $$
$$ end = \min(f_x, \min(f_y, f_z)) \quad \text{where } \mathbf{f} = \max(\mathbf{a}, \mathbf{b}) $$
$\mathbf{ro}$ is ray origin, $\mathbf{rd}$ is ray direction, $\mathbf{sd}$ is the sign vector of $\mathbf{rd}$ with $10^{-9}$ replacing zeros to avoid division by zero [S1, unofficial].

**Transfer Function Mixing:**
Maps voxel value to color and extinction [S1, unofficial].
$$ d = \text{clamp}(value/windowMax, 0., 1.) $$
$$ f = \begin{cases} d \cdot 2 & d < 0.5 \\ (d - 0.5) \cdot 2 & d \ge 0.5 \end{cases} $$
$$ tint = \begin{cases} \text{mix}(tfLow, tfMid, f) & d < 0.5 \\ \text{mix}(tfMid, tfHigh, f) & d \ge 0.5 \end{cases} $$
$$ extinction = \begin{cases} \text{mix}(tfOpacity.x, tfOpacity.y, f) & d < 0.5 \\ \text{mix}(tfOpacity.y, tfOpacity.z, f) & d \ge 0.5 \end{cases} $$

**Volume Rendering Accumulation:**
$$ \alpha = 1 - \exp(-extinction \cdot stepSize) $$
$$ \mathbf{rgb} += remaining \cdot \alpha \cdot tint $$
$$ remaining *= 1 - \alpha $$

**Final Color Tone Mapping:**
$$ \mathbf{color} = (\mathbf{rgb} + remaining \cdot [0.025, 0.035, 0.05])^{1/2.2} $$

**Pseudocode:**
```python
# Fragment shader core loop for ray marching with grouped volume rendering
# Inputs: ro (ray origin), rd (ray direction), dims (volume dimensions),
#         cutoff, windowMax, tfLow, tfMid, tfHigh, tfOpacity, stepSize,
#         pageTable, packedData, maskData, maskedStorage, mode, cached, record,
#         brick, sampleIndex, start, end, remaining, rgb

# Precompute sign vector for ray direction
sd = vec3(1.0)
if rd.x < 0.0: sd.x = -1.0
if rd.y < 0.0: sd.y = -1.0
if rd.z < 0.0: sd.z = -1.0
# Replace zeros to avoid division by zero
if abs(rd.x) < 1e-9: sd.x = 1e-9 * sign(rd.x) if rd.x != 0 else 1e-9 # G: sign handling
if abs(rd.y) < 1e-9: sd.y = 1e-9 * sign(rd.y) if rd.y != 0 else 1e-9
if abs(rd.z) < 1e-9: sd.z = 1e-9 * sign(rd.z) if rd.z != 0 else 1e-9

# Compute ray-box intersection for the entire volume or brick
# Note: The provided code calculates start/end dynamically or assumes precomputed
# The snippet below follows the provided loop structure closely

for s in range(16384):
    t = start + (sampleIndex + 0.5) * stepSize
    if t >= end or remaining < 0.005:
        break
    
    p = ro + rd * t
    v = ivec3(floor(p))
    value = 0.0
    
    if all(greaterThanEqual(v, ivec3(0))) and all(lessThan(v, dims)):
        if mode == 0:
            # Source mode: direct sampling
            value = float(texelFetch(originalData, v, 0).r)
        else:
            # Grouped mode
            cell = v / brick
            if any(notEqual(cell, cached)):
                cached = cell
                record = texelFetch(pageTable, cell, 0)
            
            if record.x == 0u:
                # Empty brick, skip to next brick
                edge = vec3((cell + ivec3(step(vec3(0), rd))) * brick)
                exits = (edge - ro) / sd
                if abs(rd.x) < 1e-9: exits.x = 1e30
                if abs(rd.y) < 1e-9: exits.y = 1e30
                if abs(rd.z) < 1e-9: exits.z = 1e30
                sampleIndex = max(sampleIndex + 1., ceil((min(exits.x, min(exits.y, exits.z)) - start) / stepSize - 0.5))
                continue
            
            # Decode origin and shape from record
            origin = ivec3(record.y & 31u, (record.y >> 5u) & 31u, (record.y >> 10u) & 31u)
            shape = ivec3(record.z & 63u, (record.z >> 6u) & 63u, (record.z >> 12u) & 63u)
            q = v - cell * brick - origin
            
            if all(greaterThanEqual(q, ivec3(0))) and all(lessThan(q, shape)):
                localIndex = uint((q.z * shape.y + q.y) * shape.x + q.x)
                index = record.x - 1u + localIndex
                present = True
                
                if maskedStorage:
                    mi = record.x - 1u + localIndex / 32u
                    bit = localIndex % 32u
                    mask = texelFetch(maskData, ivec3(mi % uint(maskWidth), (mi / uint(maskWidth)) % uint(maskHeight), mi / (uint(maskWidth) * uint(maskHeight))), 0).rg
                    present = (mask.y & (1u << bit)) != 0u
                    index = mask.x + popcount(mask.y & ((1u << bit) - 1u))
                
                if present:
                    value = float(texelFetch(packedData, ivec3(index % uint(packedWidth), (index / uint(packedWidth)) % uint(packedHeight), index / (uint(packedWidth) * uint(packedHeight))), 0).r)
    
    if value > cutoff:
        d = clamp(value / windowMax, 0., 1.)
        tint = mix(vec3(0.22, 0.5, 0.7), vec3(1.0, 0.9, 0.72), d)
        extinction = d * 0.12
        
        if useTransfer:
            f = d * 2. if d < 0.5 else (d - 0.5) * 2.
            tint = mix(tfLow, tfMid, f) if d < 0.5 else mix(tfMid, tfHigh, f)
            extinction = mix(tfOpacity.x, tfOpacity.y, f) if d < 0.5 else mix(tfOpacity.y, tfOpacity.z, f)
        
        alpha = 1. - exp(-extinction * stepSize)
        rgb += remaining * alpha * tint
        remaining *= 1. - alpha
        
    sampleIndex += 1.

# Final tone mapping
color = pow(rgb + remaining * vec3(0.025, 0.035, 0.05), vec3(1.0/2.2))
```

**Parameters:**
*   `cutoff`: Retain source values greater than this value. Example: `32` [S1, unofficial].
*   `edges`: Median-intensity band edges. Must be strictly increasing, unique, greater than cutoff, and $\le$ data maximum. Example: `[96, 160]` [S1, unofficial].

**Edge Cases and Pitfalls:**
*   Rendering speed did not consistently improve; grouped representation was slower for Foot, Engine, and Kingsnake datasets due to sparse lookup and ray-marching overhead outweighing memory savings [S1, unofficial].
*   Logical groups are spatial/intensity candidates, not validated tissue classes [S1, unofficial].
*   Brick-graph connectivity does not guarantee voxel-level connectivity [S1, unofficial].
*   Division by zero in ray direction components must be handled by replacing zeros with $10^{-9}$ [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Not explicitly given, but rendering involves sparse lookups and ray-marching per brick, potentially slower than monolithic access [S1, unofficial].
*   **Memory Complexity:** Substantially reduced stored and GPU-resident data. Reductions range from 54.7% to 95.6% across datasets [S1, unofficial].
*   **Measured Performance:**
    *   **Bonsai:** Source 16.00 MiB -> Grouped 2.65 MiB (83.5% reduction). GPU Time: 3.41 ms -> 3.23 ms [S1, unofficial].
    *   **Foot:** Source 16.00 MiB -> Grouped 4.08 MiB (74.5% reduction). GPU Time: 3.55 ms -> 3.99 ms [S1, unofficial].
    *   **Engine:** Source 8.00 MiB -> Grouped 1.72 MiB (78.5% reduction). GPU Time: 1.96 ms -> 4.01 ms [S1, unofficial].
    *   **Kingsnake:** Source 795.00 MiB -> Grouped 360.39 MiB (54.7% reduction). GPU Time: 8.47 ms -> 9.65 ms [S1, unofficial].
    *   **Woodbranch:** Source 16,384.00 MiB -> Grouped 719.48 MiB (95.6% reduction). GPU Time: Skipped (Source) -> 11.78 ms (Grouped) [S1, unofficial].
*   **Strengths:** Handles volumes exceeding monolithic allocation budgets (e.g., 16 GiB Woodbranch). Preserves exact voxel data for retained values.
*   **Limitations:** Rendering overhead can negate memory benefits. No demand paging, caching, or LOD implemented.
*   **When to Use:** Large RAW volumes that exceed GPU memory limits for monolithic textures, where exact reconstruction of filtered data is required.
*   **When Not to Use:** When rendering speed is critical and memory is not a constraint, or for small volumes where overhead dominates.

## Background
The VolumeSegmenter Pipeline is an end-to-end proof of concept developed for the VolumeSegmenter project, used for rendering large RAW volumes in WebGL2 [S1, unofficial]. It was designed to handle datasets like Bonsai, Foot, Engine, Kingsnake, and Woodbranch, specifically addressing memory constraints in web-based volume rendering [S1, unofficial].
