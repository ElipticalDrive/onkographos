# Median Normalization

Also called: Value Normalization, normalize

## Overview
Median Normalization scales a scalar field by dividing each valid value by the median of the valid values and multiplying by a configurable multiplier [S1, unofficial]. It handles NaNs and non-positive values by replacing NaNs with zero and excluding non-positive values from the median calculation [S1, unofficial].

## How it works
**Inputs:**
- `value_tensor`: The input tensor of scalar values [S1, unofficial].
- `config_value`: The multiplier to apply after normalization [S1, unofficial].

**Outputs:**
- `ret_value`: A tensor of the same shape as `value_tensor` with dtype `torch.float32`, containing the normalized values [S1, unofficial].

**Data Structures:**
- The input and output are dense tensors [G].
- Temporary boolean masks and index arrays are used to identify valid values [G].

**Formulas:**
The normalized value $y_i$ for each valid index $i$ is computed as $y_i = \mu \cdot \frac{x_i}{m}$ [S1, unofficial], where $x_i$ is the input value at index $i$, $\mu$ is `config_value`, and $m = \text{median}(\{x_j \mid x_j > 0\})$ is the median of all positive values in `value_tensor` [S1, unofficial]. All values at indices not in the valid set are set to $0$ [S1, unofficial].

**Steps:**
1. Initialize `ret_value` as a tensor of zeros with the same shape as `value_tensor` and dtype `torch.float32` [S1, unofficial].
2. Replace all `NaN` values in `value_tensor` with `0` [S1, unofficial].
3. Identify `valid_indices` where `value_tensor > 0` [S1, unofficial].
4. Extract `valid_value` from `value_tensor` at `valid_indices` and cast to `torch.float32` [S1, unofficial].
5. Compute `median_val` as the median of `valid_value` [S1, unofficial].
6. If `valid_value` is empty or `median_val` is zero, return `ret_value` (all zeros) [G].
7. Set `ret_value[valid_indices] = config_value * (valid_value / median_val)` [S1, unofficial].
8. Return `ret_value` [S1, unofficial].

**Pseudocode:**
```python
import torch

def median_normalization(value_tensor: torch.Tensor, config_value: float) -> torch.Tensor:
    # Step 1: Initialize output with zeros
    ret_value = torch.zeros_like(value_tensor, dtype=torch.float32)
    
    # Step 2: Replace NaN with 0
    value_tensor = torch.nan_to_num(value_tensor, nan=0.0)
    
    # Step 3: Identify valid indices (value > 0)
    valid_mask = value_tensor > 0
    valid_indices = torch.nonzero(valid_mask, as_tuple=False).squeeze()
    
    # Handle edge case: no valid values
    if valid_indices.numel() == 0:
        return ret_value
    
    # Step 4: Extract valid values and cast to float32
    valid_value = value_tensor[valid_indices].to(torch.float32)
    
    # Step 5: Compute median
    median_val = torch.median(valid_value)
    
    # Handle edge case: median is zero
    if median_val == 0:
        return ret_value
        
    # Step 6 & 7: Normalize and assign
    ret_value[valid_indices] = config_value * (valid_value / median_val)
    
    # Step 8: Return result
    return ret_value
```

**Parameters:**
- `config_value`: The multiplier to apply after normalization. Typical values are not given in the sources [S1, unofficial].
- `value_tensor`: The input tensor to normalize [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Zero Median:** If all valid values are identical and non-zero, the median is non-zero and normalization proceeds [S1, unofficial]. If the median calculation returns zero due to numerical issues or if no valid values exist, division by zero is avoided by returning the zero-initialized output tensor [G].
- **NaN Handling:** NaNs are replaced with `0` before masking, ensuring they are excluded from the median calculation and remain `0` in the output [S1, unofficial].
- **Negative Values:** Values $\le 0$ are excluded by the `valid_indices` mask and remain `0` in the output tensor [S1, unofficial].

## Subtopics

### [Statistical Normalization (Z-Score)](17944-statistical-normalization-z-score.md)
Statistical Normalization transforms a scalar field so that the resulting data has a zero mean and a standard deviation of one. This process ensures consistent hyperparameters and initial parameters across different models or rendering pipelines. Unlike Median Normalization, which scales by the median, this method relies on the first and second statistical moments (mean and variance) of the distribution.
