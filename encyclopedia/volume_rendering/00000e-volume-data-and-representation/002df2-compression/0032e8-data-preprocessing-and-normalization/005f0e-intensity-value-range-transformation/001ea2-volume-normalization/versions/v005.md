# Volume Normalization


## Overview
Volume Normalization transforms a volume tensor's scalar values into the range $[0, 1]$ while preserving constant positive masks as full foreground ($1.0$) [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A volume tensor containing scalar values.
- Output: A normalized volume tensor with values in $[0, 1]$.

**Data Structures:**
- The volume is treated as a dense array of floating-point numbers [G].

**Steps:**
1. Compute the global minimum value $v_{min} = \min(V)$ and global maximum value $v_{max} = \max(V)$ across all voxels in the volume [S1, unofficial].
2. Calculate the range $R = v_{max} - v_{min}$ [S1, unofficial].
3. Check for degeneracy: If $R \leq 10^{-8}$, the volume is considered constant [S1, unofficial].
   - If $v_{max} > 0.0$, set all values in $V_{norm}$ to $1.0$ [S1, unofficial].
   - Otherwise, set all values in $V_{norm}$ to $0.0$ [S1, unofficial].
4. For non-constant volumes, apply the linear scaling formula to each voxel $v \in V$:
   $$v_{norm} = \frac{v - v_{min}}{v_{max} - v_{min}}$$ [S1, unofficial].

**Pseudocode:**
```python
def volume_normalization(volume, epsilon=1e-8):
    """
    Normalize a volume tensor to [0, 1] using min-max scaling.
    Handles constant volumes by mapping to 1.0 if max > 0, else 0.0.
    """
    # Step 1: Compute global extrema
    flat_volume = [v for row in volume for col in row for v in col]
    vol_min = min(flat_volume)
    vol_max = max(flat_volume)
    
    # Step 2: Calculate range
    vol_range = vol_max - vol_min
    
    # Step 3: Handle degenerate/constant volumes
    if vol_range <= epsilon:
        if vol_max > 0.0:
            return [[1.0 for _ in col] for col in row for row in volume]
        else:
            return [[0.0 for _ in col] for col in row for row in volume]
    
    # Step 4: Apply linear normalization
    normalized = [[(v - vol_min) / vol_range for v in col] for col in row for row in volume]
    return normalized
```

**Parameters:**
- `epsilon`: Threshold for detecting constant volumes. Default is $10^{-8}$ [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Constant Volumes:** If the volume has identical values, division by zero is avoided by checking if the range is near zero. The output is $1.0$ if the constant value is positive, and $0.0$ otherwise [S1, unofficial].
- **Precision:** Use floating-point arithmetic to prevent integer division truncation [G].
- **Boundaries:** The method assumes the input volume contains valid scalar data. Invalid data (e.g., NaNs) should be handled prior to normalization [G].

## Subtopics

### [Scalar Field Normalization](1842-scalar-field-normalization.md)
Scalar Field Normalization maps the raw intensity values of a volume tensor to a standardized numerical range, typically $[0, 1]$ or $[-1, 1]$, to resolve disparate data magnitudes and coordinate scales. It sets itself apart from non-linear methods like [Power Transformation](2346-power-transformation.md) by preserving linear relationships within the mapped range, and from global statistical methods like [Percentile-based Normalization](5158-percentile-based-normalization.md) by relying on fixed or global extrema rather than distribution percentiles [G]. This linear scaling enables the use of universal thresholds (e.g., $0.5$) for object distinction and ensures consistent behavior across different input resolutions and data types [G].

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the number of voxels, as it requires a single pass to find min/max and another to scale [G].
- **Memory Complexity:** $O(N)$ for the output tensor [G].
- **Strengths:** Simple, fast, and preserves the relative linear ordering of voxel intensities [G].
- **Limitations:** Sensitive to outliers; a single extreme value can compress the dynamic range of the majority of the data [G].
- **When to Use:** When data magnitudes are consistent and outliers are not a concern, or when linear relationships must be preserved for downstream neural network training [G].
- **When Not to Use:** When the data contains significant outliers or has a non-linear distribution that benefits from log or power transformations [G].

## Background
Volume Normalization is a standard preprocessing step in volume rendering and medical image analysis pipelines [G]. It ensures that input data is within a standard range, which is critical for the stability of gradient-based optimization in neural networks and for consistent thresholding in segmentation tasks [G]. The method is widely used in conjunction with other preprocessing steps such as [Preprocessing Pipeline](6733-preprocessing-pipeline.md) and [Geometric Normalization](12018-geometric-normalization.md) [G].
