# Intensity/Value Range Transformation

Also called: Intensity Transformation, Value Range Transformation, Density Range Restriction

## Overview
Intensity/Value Range Transformation is a family of preprocessing techniques that map raw scalar voxel values to a specific target range or distribution before compression or rendering [G]. It solves the problem of wide dynamic ranges, irrelevant background data, and numerical instability by filtering or compressing the intensity spectrum [G]. It differs from sibling methods like [Geometric Normalization](12018-geometric-normalization.md) (which handles spatial coordinates) and [Byte/Short Conversion](11742-byte-short-conversion.md) (which handles quantization) by operating directly on the continuous or high-precision scalar values to shape their statistical distribution or physical relevance [G].

## Shared principles
The family operates on a volume tensor $V$ containing scalar voxel values [G]. The core mechanism involves applying a transformation function $T(v)$ to each voxel $v \in V$ [G]. This function is typically piecewise linear, logarithmic, or affine, designed to map the input domain to a target codomain (e.g., $[0, 1]$ or $[0, 255]$) [G]. Common goals include:
1. **Range Restriction:** Setting values outside a region of interest to zero or a background value [S1, unofficial].
2. **Dynamic Range Compression:** Reducing the span of values to fit storage or rendering constraints [G].
3. **Discontinuity Avoidance:** Using ramps to prevent high-frequency artifacts during subsequent compression (e.g., wavelet transforms) [S1, unofficial].

**Pseudocode:**
```python
def apply_intensity_transform(volume: list[float], transform_func: callable) -> list[float]:
    """Applies a scalar transformation function to each voxel in the volume."""
    # Step 1: Iterate through each voxel value
    # Step 2: Apply the transformation function T(v)
    # Step 3: Return the transformed volume tensor
    return [transform_func(v) for v in volume]
```

## Subtopics

### [Volume Normalization](1823-volume-normalization.md)
Maps a volume tensor's scalar values to the range $[0, 1]$ while preserving constant positive masks as full foreground ($1.0$). It is chosen when a uniform $[0, 1]$ range is required for downstream neural networks or transfer functions. See [Volume Normalization](1823-volume-normalization.md) for implementation details.

### Density Range Restriction and Ramp Function
A preprocessing function applied to volume data to restrict the range of density values, improving compression ratio by removing irrelevant data and avoiding discontinuities that generate high frequencies [S1, unofficial]. It is chosen when using wavelet-based compression (e.g., Haar Wavelet) where discontinuities degrade compression efficiency [S1, unofficial].

**Definition:**
The function $T$ filters density values to keep only those representing regions of interest. It keeps densities intact between a selected range $[d_2, d_3]$ and adds ramps before $d_2$ and after $d_3$ to avoid discontinuities [S1, unofficial].

**Steps:**
1. Apply function $T$ to each density value:
   - If density $\le d_1$, set density $= 0$.
   - If density $\ge d_3$, set density $= 0$.
   - If $d_1 \le \text{density} \le d_2$, set density $= (\text{density} - d_1) \times \frac{d_2}{d_2 - d_1}$.
   - If $d_3 \le \text{density} \le d_4$, set density $= (d_3 - \text{density}) \times \frac{d_4}{d_4 - d_3}$.
   - *Note: The source text states "if density $\ge d_3 \rightarrow density = 0$" in the summary but uses $d_4$ in the formula block [S1, unofficial]. The formula block is more precise for a ramp ending at $d_4$.*
2. Normalize models with histograms outside the $[0, 255]$ range to achieve the same output value range after applying $T$ [S1, unofficial].

**Parameters:**
- $d_1, d_2, d_3, d_4$: Threshold parameters defining the density range $[d_2, d_3]$ to keep intact and the ramps $[d_1, d_2]$ and $[d_3, d_4]$ to avoid discontinuities [S1, unofficial].

### Logarithmic Intensity Compression
Compresses volume intensity data logarithmically to handle wide dynamic ranges typical in diffraction data [S2, unofficial]. It is chosen when raw linear mapping leaves most data transparent due to orders-of-magnitude intensity spans (e.g., Bragg peaks in crystallography) [S2, unofficial].

**Definition:**
Applies a logarithmic transformation to clamp negatives and compress high values [S2, unofficial].

**Steps:**
1. Cast input to float32.
2. Apply $\max(x, 0.0)$ to clamp negatives.
3. Apply $\log(1 + x)$ to compute the compressed output.

**Formula:**
$$y = \log(1 + \max(x, 0))$$
where $x$ is the input intensity array and $y$ is the compressed output [S2, unofficial].

**Pitfalls:**
Raw linear mapping leaves everything but the brightest Bragg peak fully transparent due to orders-of-magnitude intensity span [S2, unofficial].

### Triplane Feature Normalization
Normalizes feature channels to zero-mean, clips outliers, and scales to a fixed range. It is chosen for 3D neural field generation (e.g., Triplane Diffusion) where unbounded features skew the distribution [S3].

**Steps:**
1. Normalize feature channels to zero-mean [S3].
2. Clip each channel to be within $S = 16$ standard deviations of the mean [S3].
3. Scale each channel to be within the range $[-1, 1]$ [S3].

### Grayscale Transform
A global intensity remapping operation that replaces original voxel values with new values using a conversion table, enabling filtering of specific grey values or gamma correction [S4, unofficial].

**Steps:**
1. Generate or manually edit a conversion table (lookup table) [S4, unofficial].
2. Distribute the table to all processors [S4, unofficial].
3. Each processor applies the table to map original voxel values to new values. The table can be automatically generated from the merged histogram to perform histogram equalization [S4, unofficial].

**Parameters:**
- `transform.sizes`: `[3][2]INT` array defining the volume-of-interest for the transform [S4, unofficial].
- `grey.table`: `[256]INT` array containing the lookup table values for intensity mapping [S4, unofficial].

**Layout:**
Request message layout: `to.net ! command; pe.grey.transform; [3][2]INT transform.sizes; [256]INT grey.table` [S4, unofficial].

### Linear Intensity Rescaling for Histogram Binning
A technique to reduce the size of the joint histogram and speed up Mutual Information (MI) computation by rescaling image intensity values into a smaller range before registration [S5, unofficial].

**Formula:**
$$s = \frac{s_2 - s_1}{r_2 - r_1} (r - r_1) + s_1, \quad \text{for } r_1 \le r \le r_2$$
where $r$ is the original intensity value in range $[r_1, r_2]$, and $s$ is the rescaled intensity value in range $[s_1, s_2]$ [S5, unofficial].

**Parameters:**
- The recommended target intensity range for rescaling is $[0, 63]$, which provides an excellent tradeoff between accuracy and computation time cost [S5, unofficial].

**Comparison:**
Original medical images have intensity values with a range up to 4096, inducing a very large joint histogram [S5, unofficial]. Using a higher number of levels (e.g., 256) results in higher MI values and a sharper MI surface, but causes a great calculation burden because the joint histogram is recalculated on each iteration. Using fewer levels (e.g., 16) reduces computation time but lowers MI values and sharpness. The range $[0, 63]$ (64 levels) is chosen as a tradeoff [S5, unofficial].

## Background
Intensity transformation is a fundamental step in volume data pipelines, particularly in medical imaging and scientific visualization [G]. Early implementations focused on simple windowing and leveling [G]. The specific "Density Range Restriction and Ramp Function" was introduced in the context of mobile medical image visualization to improve compression ratios using Haar Wavelets [S1, unofficial]. Logarithmic compression is standard in diffraction data analysis (e.g., X-ray crystallography) to handle the vast dynamic range of pixel intensities [S2, unofficial]. Triplane normalization is a modern technique used in generative 3D models (e.g., Triplane Diffusion) to stabilize training by bounding feature distributions [S3]. Grayscale transforms using lookup tables were implemented on transputer networks for parallel voxel processing [S4, unofficial]. Linear intensity rescaling for histogram binning was developed to accelerate Mutual Information computation in medical image registration [S5, unofficial].
