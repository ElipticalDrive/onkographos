# Volume Utility Functions


## Overview
Volume Utility Functions prepare volumetric data for the [Compression](4-compression.md) pipeline by addressing distinct aspects of data integrity or range mapping [Parent]. They handle tensor dimensionality alignment via `make_nd` [S1, unofficial], physical unit normalization via `normalize_hounsfield` [S1, unofficial], spatial resampling via `normalize_voxel_scale` [S1, unofficial], and memory/layout corrections [S3, unofficial][S4, unofficial][S6][S7, unofficial][S8, unofficial].

## How it works
### make_nd
**Inputs:** `t` (tensor/array), `n` (integer target dimensionality) [S1, unofficial].
**Outputs:** Tensor of dimensionality `n` [S1, unofficial].
**Steps:**
1. If $n < \text{len}(t.\text{shape})$, raise an exception [S1, unofficial].
2. While $\text{len}(t.\text{shape}) < n$, prepend a dimension of size 1 to `t` [S1, unofficial].
3. Return `t` [S1, unofficial].
**Pseudocode:**
```python
def make_nd(t, n):
    """Prepends singleton dimensions to tensor t until it is n-dimensional. Raises exception if n < t.ndim."""
    if n < len(t.shape):
        raise ValueError(f"Target dimension {n} is less than current dimension {len(t.shape)}")
    while len(t.shape) < n:
        t = t.reshape((1,) + t.shape)
    return t
```

### normalize_hounsfield
**Inputs:** `vol` (volume data), `dtype` (optional output data type) [S1, unofficial].
**Outputs:** Normalized volume in $[0, 1]$ [S1, unofficial].
**Steps:**
1. Divide all voxel values in `vol` by 4095 [S1, unofficial].
2. Clamp the result to the range $[0, 1]$ [S1, unofficial].
3. Cast to `dtype` if provided [S1, unofficial].
4. Return the clamped volume [S1, unofficial].
**Pseudocode:**
```python
def normalize_hounsfield(vol, dtype=None):
    """Normalizes volume by 4095 and clamps to [0, 1]. Handles torch tensors and numpy arrays."""
    normalized = vol / 4095.0
    normalized = normalized.clip(0.0, 1.0) if hasattr(normalized, 'clip') else torch.clamp(normalized, 0.0, 1.0)
    if dtype is not None:
        normalized = normalized.astype(dtype)
    return normalized
```

### normalize_voxel_scale
**Inputs:** `vol` (input volume), `vox_scl` (voxel scale as array/tensor of shape $[3]$) [S1, unofficial].
**Outputs:** Resampled volume [S1, unofficial].
**Steps:**
1. Calculate the new shape based on `vox_scl` [S1, unofficial].
2. Resample `vol` to the new shape using trilinear interpolation [S1, unofficial].
3. Return the resampled volume [S1, unofficial].
**Pseudocode:**
```python
def normalize_voxel_scale(vol, vox_scl):
    """Resamples volume to new shape based on voxel scale using trilinear interpolation."""
    old_shape = vol.shape
    new_shape = [int(dim / scale) for dim, scale in zip(old_shape, vox_scl)]
    # Standard trilinear interpolation [G]
    resampled = trilinear_interpolate(vol, new_shape)
    return resampled
```

## Subtopics

### [Vector Normalization](3145-vector-normalization.md)
Vector Normalization converts a 3D vector into a unit vector, or returns a zero vector if the input magnitude is below a precision threshold. Some implementations modify the input vector in place rather than returning a new instance. It is used to process direction data such as sun vectors.

### [Half-Precision Float Conversion](3267-half-precision-float-conversion.md)
A utility function to convert a 32-bit float to a 16-bit half-precision float, avoiding undefined behavior from type punning.

### Volume Resize and Save
Resizes a volume using bilinear interpolation to a specified target size, normalizes the volume values to the range $[0, 1]$, and rotates the volume 90 degrees around axes 1 and 2 [S2, unofficial]. If a `save_root` directory is provided, the function creates the directory and saves each slice as a PNG image scaled to $[0, 255]$ `uint8` [S2, unofficial].

### Volume Size Fixing
Corrects the volume size's Z dimension (frame count) based on the actual data byte length and X/Y dimensions, handling cases where the stored `image_size[2]` attribute is incorrect [S3, unofficial]. It calculates `realFrameCount` as `data.byteLength` divided by `(volumeSize[0] * volumeSize[1])`. If `realFrameCount` does not equal `volumeSize[2]`, it logs a warning and updates `volumeSizeFixed[2]` to `realFrameCount` before returning the corrected size array [S3, unofficial]. The original file's `image_size[2]` attribute may be wrong, requiring correction based on actual data size [S3, unofficial].

### Region Normalization and Validation
Clamps region coordinates to valid chunk bounds and checks if a region is empty [S4, unofficial]. It extracts min and max coordinates, clamps min coordinates (X and Z to $[\text{FIRST\_INDEX}, \text{CHUNK\_SIZE}]$, Y to $[\text{FIRST\_INDEX}, \text{height}]$), and clamps max coordinates (X and Z to $[\text{minX}, \text{CHUNK\_SIZE}]$, Y to $[\text{minY}, \text{height}]$) [S4, unofficial]. The region is flagged as empty if $\text{min} \ge \text{max}$ in any axis [S4, unofficial]. `FIRST_INDEX` defines the minimum valid index for chunk coordinates [S4, unofficial].

### VolPack Normal Vector Encoding/Decoding
Encodes a normalized 3D vector into a 16-bit integer format expected by VolPack shaders, and decodes it back [S5]. Encoding calls `int vpNormalIndex(double nx, double ny, double nz)` where $nx^2 + ny^2 + nz^2 = 1$, returning a 16-bit encoded normal [S5]. Decoding calls `vpResult vpNormal(int n, double *nx, double *ny, double *nz)` to store the decoded components at the provided pointers [S5].

### Memory Alignment / Word Alignment
Rounds up `byteCount` to the nearest `wordSize` [S6]. `wordSize` specifies the alignment size in bytes, and `byteCount` is the input byte count [S6].

### Scale Unpacking
Decodes packed scale data from a buffer into floating-point log-scale values [S7, unofficial]. It iterates `coordCount` times (where `coordCount` = `pointCount` $\times$ 3), and for each byte `src[i]`, computes `out[i] = src[i] / 16.0f - 10.0f` [S7, unofficial].

### NIfTI Analysis and Multi-Channel Debugging
A Python script (`analyze.py`) for inspecting NIfTI files, displaying metadata, voxel statistics, multi-channel analysis, and winner-takes-all (argmax) labelmap simulation [S8, unofficial]. `load_nifti(path)` loads the file using `nibabel` and returns `fdata` as `np.float32` [S8, unofficial]. `describe_nifti(img, data, name)` prints file path, dtype, shape, dimensions, voxel size (mm), affine 4x4 matrix, axis orientation, finite voxel statistics (min, max, mean, std, non-zero count), and header key fields (`descrip`, `datatype`, `bitpix`, `scl_slope`, `scl_inter`, `qform_code`, `sform_code`, `xyzt_units`, `toffset`, `intent_name`, `intent_code`, `cal_min`, `cal_max`) [S8, unofficial]. `describe_multichannel(data, name)` prints central voxel values across all channels, argmax channel, and per-channel statistics for 4D data [S8, unofficial]. `describe_multichannel_as_winner_map(data, name)` computes `winner_channel = np.argmax(data, axis=3)` and `winner_value = np.max(data, axis=3)`, creates `hard_labels` (if `winner_value > 0`, label is `winner_channel + 1`, else 0), and prints a histogram of winning labels with counts and percentages [S8, unofficial].

## Background
These functions are derived from various open-source volume rendering and compression libraries, including `flashdrr` [S1, unofficial], `DGR` [S2, unofficial], `web-vol-viewer` [S3, unofficial], `mc-meshing` [S4, unofficial], `VolPack` [S5], `nanovdb` [S6], `spz` [S7, unofficial], and `vrdf-sdk` [S8, unofficial]. They represent common patterns in volumetric data handling rather than a single unified algorithm.
