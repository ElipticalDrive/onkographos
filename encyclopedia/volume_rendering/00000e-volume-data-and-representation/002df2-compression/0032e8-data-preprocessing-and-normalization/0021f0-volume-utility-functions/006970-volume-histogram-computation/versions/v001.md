# Volume Histogram Computation

Also called: Distributed Volume Histogram, Histogram Computation, pe.histogram

## Overview
Volume Histogram Computation is a global operation that calculates the frequency distribution of voxel intensities within a specified volume-of-interest (VOI) across a distributed network [S1, unofficial]. It serves as a foundational statistical tool for subsequent volume processing tasks, such as automatic thresholding, edge detection, and the generation of histogram equalization tables for grey-scale transforms [S1, unofficial]. Unlike local filters that operate on individual voxels or neighborhoods, this method aggregates data from all processing elements (PEs) to provide a complete statistical view of the dataset [S1, unofficial].

## How it works
The method operates in a distributed environment where voxel data is partitioned across multiple processors. The process involves local histogram generation, message passing, and global merging.

**Inputs and Outputs:**
*   **Input:** Distributed voxel data set; a VOI defined by `transform.sizes`; a `threshold.value`.
*   **Output:** A merged 256-bin integer histogram on the host node.

**Data Structures and Layouts:**
1.  **Request Message:** Sent from a PE to the network/host.
    *   `command`: Identifier for the operation.
    *   `pe.histogram`: Command tag.
    *   `transform.sizes`: `[3][2]INT` array. Defines the VOI via start- and end-values of voxel indices in X, Y, and Z directions.
    *   `threshold.value`: `INT`. Threshold applied during computation.
2.  **Response Message:** Sent from the host/merger back to the network or stored on the host.
    *   `command`: Identifier.
    *   `merge.histogram`: Response tag.
    *   `histogram`: `[256]INT` array. The final merged frequency distribution.

**Algorithm Steps:**
1.  **Local Computation:** Each PE identifies the voxels belonging to its local partition that fall within the VOI defined by `transform.sizes` [S1, unofficial].
2.  **Thresholding:** The PE applies the `threshold.value` to filter or weight the voxel data during the histogram calculation [S1, unofficial].
3.  **Local Histogram Generation:** The PE computes a frequency distribution (histogram) of the valid voxel intensities. The source specifies a 256-bin integer histogram, implying an 8-bit intensity range (0-255) or a quantized mapping [S1, unofficial].
4.  **Transmission:** Each PE transmits its partial histogram to a host node.
5.  **Merging:** The host node receives all partial histograms and sums them element-wise to produce the complete global histogram [S1, unofficial].
6.  **Post-Processing (Optional):** The host may plot the result and generate a histogram equalization table. This table is then transmitted to all nodes for use in automatic thresholding or edge detection [S1, unofficial].

**Pseudocode:**
```python
# Distributed Volume Histogram Computation
# Assumptions: 
# - Voxel data is distributed across PEs.
# - Each PE has access to its local chunk of voxel data.
# - transform.sizes is [3][2]INT: [[x_start, x_end], [y_start, y_end], [z_start, z_end]]
# - threshold.value is INT.

def compute_local_histogram(local_voxels, transform_sizes, threshold_value):
    """
    Computes a 256-bin histogram for local voxels within the VOI.
    """
    # Initialize 256-bin histogram
    local_hist = [0] * 256
    
    # Determine VOI bounds
    x_start, x_end = transform_sizes[0]
    y_start, y_end = transform_sizes[1]
    z_start, z_end = transform_sizes[2]
    
    # Iterate over local voxels
    for voxel in local_voxels:
        # Check if voxel is within VOI
        if (x_start <= voxel.x <= x_end and
            y_start <= voxel.y <= y_end and
            z_start <= voxel.z <= z_end):
            
            intensity = voxel.intensity
            
            # Apply threshold
            # Note: The exact nature of thresholding (filtering vs weighting) 
            # is not explicitly detailed beyond "applying the threshold" [S1, unofficial].
            # Assuming standard filtering: only include if intensity meets criteria.
            if intensity >= threshold_value:
                # Clamp to 0-255 range for 256 bins
                bin_index = max(0, min(255, intensity))
                local_hist[bin_index] += 1
                
    return local_hist

def merge_histograms(partial_histograms):
    """
    Merges partial histograms from all PEs into a global histogram.
    """
    global_hist = [0] * 256
    
    for partial_hist in partial_histograms:
        for i in range(256):
            global_hist[i] += partial_hist[i]
            
    return global_hist

# Main Execution Flow
# 1. Each PE computes its local histogram
local_hist = compute_local_histogram(my_voxels, transform_sizes, threshold_value)

# 2. Send local_hist to Host
send_to_host(local_hist)

# 3. Host collects all partial histograms and merges them
# (This part happens on the Host)
all_partial_hists = receive_from_all_pes()
global_hist = merge_histograms(all_partial_hists)

# 4. Host generates equalization table if needed
# equalization_table = generate_equalization_table(global_hist)
# send_to_all_pes(equalization_table)
```

**Parameters:**
*   `transform.sizes`: `[3][2]INT`. Defines the volume-of-interest via start- and end-values of voxel indices in X, Y, Z.
*   `threshold.value`: `INT`. Threshold applied during histogram computation.

**Edge Cases and Pitfalls:**
*   **Precision:** The histogram uses integer counts. If the volume is extremely large, integer overflow may occur if the bin capacity exceeds the integer limit. The source specifies `[256]INT`, implying standard integer types are used [S1, unofficial].
*   **Boundaries:** The VOI is defined by inclusive start/end indices. Care must be taken to ensure indices are within the actual data bounds of each PE's local chunk.
*   **Thresholding Logic:** The source mentions "applying the threshold" but does not specify if it is a lower bound, upper bound, or range. The pseudocode assumes a lower bound (`>=`), but this may vary by implementation [S1, unofficial].

## Subtopics

### 2D Histogram Generation
Computes a 2D histogram of voxel values across all sub-volumes, applies logarithmic scaling, and normalizes to 8-bit output, likely for transfer function or opacity mapping visualization [S2, unofficial]. It requires `nelts >= 2` (number of elements/channels); if less, the function returns 0 with an error message [S2, unofficial]. The algorithm allocates a float array `ih[256*256]` initialized to 0. It iterates over all sub-volumes and voxels, computing a linear index `vox = i*xiSize*yiSize*nelts + j*xiSize*nelts + k*nelts`. It reads values `d[vox]` and `d[vox+1]`, then increments the bin `ih[d[vox] + d[vox+1]*256] += 1`. After counting, it applies a logarithm: `ih[i] = log(ih[i])`. It finds the maximum value `max` and scales to 8-bit: `hist[i] = (unsigned char)(ih[i]/max*255)` [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of voxels in the VOI on each PE ($O(N)$), plus communication overhead proportional to the number of PEs and the fixed size of the histogram (256 integers) [S1, unofficial].
*   **Memory Complexity:** $O(1)$ per PE for the local histogram (256 integers), plus $O(1)$ on the host for the merged histogram [S1, unofficial].
*   **Strengths:** Provides a global statistical view necessary for adaptive processing like histogram equalization. Efficient for distributed systems as it aggregates small fixed-size messages [S1, unofficial].
*   **Limitations:** Limited to 256 bins (8-bit resolution) in the described implementation. Requires network communication for merging, which can be a bottleneck in large-scale distributed systems.
*   **When to use:** When global intensity statistics are needed for thresholding, edge detection, or transfer function generation.
*   **When not to use:** When high-precision (e.g., 16-bit or 32-bit) histograms are required, or when real-time per-voxel processing is needed without global synchronization.

## Background
The method originates from the TNO report "Voxel Data Processing on a Transputer Network" (DTIC ADA245410), which describes a system for processing voxel data on a distributed transputer network [S1, unofficial]. It is part of a suite of global image processing operations designed to work in conjunction with local filters and grey-scale transforms. The histogram data is used to generate equalization tables, which are then distributed to all nodes for automatic thresholding or edge detection [S1, unofficial]. The 2D variant is found in the `simian-spacemonkey` project, likely for medical or scientific volume visualization [S2, unofficial].
