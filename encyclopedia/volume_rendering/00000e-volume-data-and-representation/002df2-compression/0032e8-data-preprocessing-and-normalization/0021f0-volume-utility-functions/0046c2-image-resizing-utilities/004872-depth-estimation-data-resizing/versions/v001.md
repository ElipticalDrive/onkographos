# Depth Estimation Data Resizing

Also called: Resize

## Overview
A preprocessing utility to resize depth estimation samples (image, disparity, mask) to a target size while optionally maintaining aspect ratio and ensuring dimensions are multiples of a specific value [S1, unofficial]. It differs from generic resizing by enforcing discrete-value preservation for semantic and depth fields and by providing specific aspect-ratio constraints ('lower_bound', 'upper_bound', 'minimal') tailored for neural network input requirements [S1, unofficial].

## How it works
**Inputs and Outputs**
- **Input**: A dictionary `sample` containing:
  - `image`: The RGB or grayscale image to resize.
  - `disparity` (optional): Disparity map.
  - `depth` (optional): Depth map.
  - `mask` (optional): Binary or segmentation mask.
  - `semseg_mask` (optional): Semantic segmentation mask (handled as a float tensor with batch/channel dimensions).
- **Parameters**:
  - `target_height` (`int`): Desired output height.
  - `target_width` (`int`): Desired output width.
  - `resize_method` (`str`): Aspect ratio handling strategy. Options: `'lower_bound'`, `'upper_bound'`, `'minimal'` [S1, unofficial].
  - `ensure_multiple_of` (`int`): Integer constraining output width and height to be multiples of this value. Defaults to 1 [S1, unofficial].
  - `image_interpolation_method` (`int`): Interpolation method for the image, defaulting to `cv2.INTER_AREA` [S1, unofficial].
  - `keep_aspect_ratio` (`bool`): Whether to preserve the original aspect ratio [S1, unofficial].
- **Output**: The modified `sample` dictionary with resized fields.

**Data Structures**
- The `sample` dictionary fields are resized in-place or replaced with new arrays of shape `(new_height, new_width)` for 2D data, or `(B, C, new_height, new_width)` for tensor-based semantic masks.

**Steps**
1. **Constrain to Multiple**: Define a helper function `constrain_to_multiple_of(x, min_val, max_val, multiple_of)` that rounds `x` to the nearest multiple of `multiple_of`. If the result exceeds `max_val`, it floors to the previous multiple. If it is below `min_val`, it ceils to the next multiple [S1, unofficial].
2. **Determine Scale**: Calculate initial scales:
   $$ \text{scale\_height} = \frac{\text{target\_height}}{\text{height}} $$
   $$ \text{scale\_width} = \frac{\text{target\_width}}{\text{width}} $$
   where `height` and `width` are the original dimensions of the image [S1, unofficial].
3. **Apply Aspect Ratio Constraint**: If `keep_aspect_ratio` is true, adjust scales based on `resize_method`:
   - `'lower_bound'`: Fits the larger dimension to the target (minimizing scaling).
   - `'upper_bound'`: Fits the smaller dimension (maximizing scaling).
   - `'minimal'`: Picks the dimension closest to a 1:1 scale [S1, unofficial].
4. **Calculate New Dimensions**: Based on `resize_method`, calculate `new_height` and `new_width` using `constrain_to_multiple_of`:
   - `'lower_bound'`: Enforces `min_val` (ensures output is at least as large as given size).
   - `'upper_bound'`: Enforces `max_val` (ensures output is at most as large).
   - `'minimal'`: Has no bounds [S1, unofficial].
5. **Resize Image**: Resize `sample['image']` to `(new_width, new_height)` using `cv2.resize` with `image_interpolation_method` [S1, unofficial].
6. **Resize Targets**:
   - If `resize_target` is true, resize `disparity`, `depth`, and `mask` fields using `cv2.INTER_NEAREST` [S1, unofficial].
   - Resize `semseg_mask` using `F.interpolate` with mode `'nearest'` on a float tensor with added batch/channel dimensions [S1, unofficial].

**Parameters with Typical Values**
- `resize_method`: `'lower_bound'` is common for ensuring minimum input size for networks [S1, unofficial].
- `ensure_multiple_of`: `1` by default, but often `8` or `16` for CNNs with downsampling [S1, unofficial].
- `image_interpolation_method`: `cv2.INTER_AREA` for downsampling, `cv2.INTER_LINEAR` for upsampling [S1, unofficial].

**Edge Cases and Pitfalls**
- Disparity, depth, and mask fields must use `cv2.INTER_NEAREST` to preserve discrete values and avoid interpolation artifacts [S1, unofficial].
- If `resize_method` is not one of `'lower_bound'`, `'upper_bound'`, or `'minimal'`, a `ValueError` is raised [S1, unofficial].
- Precision issues may arise when calculating scales for very small or very large images.
- Boundary conditions: `constrain_to_multiple_of` handles cases where the rounded value exceeds `max_val` or falls below `min_val` [S1, unofficial].

## Operating characteristics
- **Time Complexity**: Linear with respect to the number of pixels in the image, $O(H \times W)$, due to the resizing operations [S1, unofficial].
- **Memory Complexity**: Linear with respect to the number of pixels, $O(H \times W)$, for storing the resized images [S1, unofficial].
- **Measured Performance**: Not given in the sources.
- **Scaling**: Scales linearly with image resolution [S1, unofficial].
- **Strengths**: Ensures dimensions are multiples of a specific value, which is crucial for neural networks with downsampling layers. Preserves discrete values for depth and mask data [S1, unofficial].
- **Limitations**: Aspect ratio constraints may result in padding or cropping if not handled explicitly (though this method only resizes) [S1, unofficial].
- **When to use**: When preparing depth estimation data for neural network training where input dimensions must be multiples of a specific value and aspect ratio must be preserved [S1, unofficial].
- **When not**: When exact pixel-perfect resizing without aspect ratio constraints is required [S1, unofficial].
