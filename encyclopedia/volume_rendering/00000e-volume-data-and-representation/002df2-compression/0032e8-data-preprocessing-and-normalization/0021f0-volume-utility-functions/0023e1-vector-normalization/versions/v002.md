# Vector Normalization

Also called: MaxIndex, Normalize 3-tuple, PV.unitize, Sun Direction Normalization

## Overview
Vector Normalization converts a 3D vector into a unit vector, or returns a zero vector if the input magnitude is below a precision threshold [S3, unofficial]. Some implementations modify the input vector in place rather than returning a new instance [S2, unofficial]. It is used to process direction data such as sun vectors [S4, unofficial].

## How it works
**Inputs:** A 3D vector $v$ [S1].
**Outputs:** A normalized 3D vector, or a zero vector if the magnitude is below a threshold [S3, unofficial]. Some implementations modify the input vector in place [S2, unofficial].

**Data Structures:**
The input is a 3-component vector [S1]. For grid operations, active voxels are represented as coordinates and values $(c, v)$ within a grid tree, and results are stored in a dictionary keyed by coordinate [S3, unofficial].

**Parameters:**
- $\epsilon(T)$: A precision threshold dependent on the data type $T$ [S3, unofficial]. Not given in the sources.

**Steps:**
1. Compute the magnitude $n$ of $v$. Implementations may use `Math.hypot` for stability [S4, unofficial] or standard Euclidean calculation [S3, unofficial].
2. Check for degeneracy: If $n < \epsilon(T)$, return or set the vector to $(0, 0, 0)$ [S3, unofficial].
3. Normalize: Divide each component by $n$. The formula is $u_i \leftarrow \frac{u_i}{\|u\|}$ for $i=0,1,2$ [S2, unofficial].

**Pseudocode:**
```python
def vector_normalize(v, eps):
    n = (v[0]**2 + v[1]**2 + v[2]**2)**0.5
    if n < eps:
        return (0.0, 0.0, 0.0)
    return (v[0] / n, v[1] / n, v[2] / n)
```

**Edge Cases:**
- **Zero Vector:** If the input magnitude is below $\epsilon(T)$, division by zero is avoided by returning $(0, 0, 0)$ [S3, unofficial].
- **Precision:** Using `Math.hypot` can be used to calculate the length [S4, unofficial].
