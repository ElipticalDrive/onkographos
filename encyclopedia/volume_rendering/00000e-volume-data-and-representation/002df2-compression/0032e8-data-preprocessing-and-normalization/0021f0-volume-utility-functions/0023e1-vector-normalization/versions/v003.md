# Vector Normalization

Also called: MaxIndex, Normalize 3-tuple, PV.unitize, Sun Direction Normalization

## Overview
Vector Normalization converts a 3D vector into a unit vector, or returns a zero vector if the input magnitude falls below a precision threshold [S3, unofficial]. Some implementations modify the input vector in place rather than returning a new instance [S2, unofficial]. It is commonly used to process direction data such as sun vectors [S4, unofficial].

## How it works
**Inputs:** A 3D vector $v$ [S2, unofficial].
**Outputs:** A normalized 3D vector, or a zero vector $(0,0,0)$ if the magnitude is below the threshold [S3, unofficial].

**Data Structures:**
The input is a 3-component vector [S2, unofficial]. For grid-based operations, active voxels are represented as coordinate-value pairs $(c, v)$ within a grid tree, and normalized results are stored in a dictionary keyed by coordinate [S3, unofficial]. The resulting grid retains the original voxel size and uses a background value of $(0,0,0)$ [S3, unofficial].

**Parameters:**
- $\epsilon(T)$: A precision threshold dependent on the data type $T$ [S3, unofficial].

**Steps:**
1. Compute the magnitude $n = \|v\|$ of the input vector [S3, unofficial].
2. Implementations may use `Math.hypot` for numerical stability [S4, unofficial] or standard Euclidean calculation [S3, unofficial].
3. Check for degeneracy: If $n < \epsilon(T)$, return or set the vector to $(0, 0, 0)$ [S3, unofficial].
4. Normalize: Divide each component by $n$ [S2, unofficial].
5. For grid operations, iterate over all active voxels $(c, v)$ in the grid tree, apply the normalization to $v$, store the result in a dictionary keyed by coordinate, and build the result grid using the computed data, a background value of $(0,0,0)$, and the original grid's voxel size [S3, unofficial].

**Formulas:**
- $n = \|v\|$
- $u_i \leftarrow \frac{u_i}{\|u\|}$ for $i=0,1,2$, where $u$ is the vector and $\|u\|$ is its magnitude [S2, unofficial].
- $\text{result} = (0,0,0)$ if $n < \epsilon(T)$, else $(v[0]/n, v[1]/n, v[2]/n)$ [S3, unofficial].

**Pseudocode:**
```python
def vector_normalize(v, eps):
    n = (v[0]**2 + v[1]**2 + v[2]**2)**0.5
    if n < eps:
        return (0.0, 0.0, 0.0)
    return (v[0] / n, v[1] / n, v[2] / n)
```

**Edge Cases:**
- **Zero Vector:** If the input magnitude is below $\epsilon(T)$, division by zero is avoided by returning $(0, 0, 0)$ [S3, unofficial].
- **Precision:** Using `Math.hypot` can be used to calculate the length [S4, unofficial].
