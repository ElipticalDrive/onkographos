# Data-Dependent Normal Vector Quantizer (Simulated Annealing)
Also called: Simulated Annealing Normal Quantizer

## Overview
This method generates a normal vector quantizer optimized for specific volume data to improve rendering image quality over static quantizers [S1]. Unlike the parent [Octahedral Normal Decoding](3373-octahedral-normal-decoding.md) which relies on a fixed geometric distribution (e.g., 240 vectors from a dodecahedron tessellation), this approach uses iterative optimization to adapt the vector distribution and count to the input data [S1].

## How it works
**Inputs:**
- Volume dataset $V$ (scalar field).
- Initial quantizer $Q_0$ (e.g., the static dodecahedron-based quantizer with 240 vectors) [S1].

**Outputs:**
- Optimized quantizer $Q_{opt}$, consisting of a set of normal vectors $\{n_i\}$ and their associated quantization regions [S1].

**Data Structures:**
- The quantizer is represented as a set of normal vectors. The number of vectors $N$ is not fixed to 240 but is determined by the optimization process [S1].
- Hardware constraints may limit the final size to 256 entries to match typical color map support [S1].

**Steps:**
1. **Initialization:** Generate an initial quantizer $Q_0$. A standard choice is the static quantizer derived from a tessellation of the sphere into 240 almost equal-sized triangles, where each normal vector is quantized to the center of gravity of its respective triangle [S1].
2. **Optimization Loop:** Apply an iterative optimization technique based on Simulated Annealing to $Q_0$ [S1].
   - The objective is to minimize a cost function related to rendering error or shading quality for the specific volume data $V$ [S1].
   - The algorithm iteratively perturbs the positions of the normal vectors and the boundaries of their quantization regions.
   - Simulated Annealing allows the algorithm to escape local minima by accepting worse solutions with a probability that decreases over time [S1].
3. **Convergence:** The process continues until convergence or a time limit is reached, yielding a data-dependent distribution of normal vectors [S1].

**Parameters:**
- Initial temperature and cooling schedule for Simulated Annealing: Not given in the sources.
- Target number of vectors: Variable, potentially differing from 240 [S1].

**Edge Cases and Pitfalls:**
- **Hardware Limits:** The final quantizer size should ideally be $\le 256$ to fit in standard hardware color maps [S1].
- **Data Dependency:** The quality of the quantizer is strictly tied to the input volume data; a quantizer optimized for one dataset may perform poorly on another [S1].

## Subtopics

### Spherical Tessellation for Normal Quantization
A new tessellation of the sphere that serves as the basis for normal-vector quantization in the Voltx method [S2, unofficial]. It is used to generate triangles for rendering concentric spherical shells to compensate for perspective viewing slab thickness variations [S2, unofficial]. This technique is suitable for generating the triangles needed to approximate spherical shells rather than planar slabs, addressing perspective distortion errors that can increase to 14% for large window widths [S2, unofficial].

## Operating characteristics
- **Time Complexity:** High, due to the iterative Simulated Annealing process [S1].
- **Memory Complexity:** Depends on the number of vectors $N$; typically $\le 256$ for hardware compatibility [S1].
- **Strengths:** Produces a data-dependent distribution of normal vectors that can improve image quality over static quantizers [S1]. Allows for a variable number of vectors, potentially optimizing the use of hardware color map entries (e.g., using fewer than 240 if beneficial) [S1].
- **Limitations:** Requires pre-computation per dataset; not suitable for real-time generation without caching [S1].
- **When to use:** When static quantizers (like the standard 240-vector dodecahedron) yield suboptimal shading or image quality for specific volume data [S1].

## Background
Originated in the context of interactive volume rendering using 3D texture mapping [S1]. The method was proposed to address the limitations of static quantizers, which use a fixed distribution (e.g., 240 vectors) that may not be optimal for all datasets [S1]. The authors were implementing this method at the time of writing [S1].
