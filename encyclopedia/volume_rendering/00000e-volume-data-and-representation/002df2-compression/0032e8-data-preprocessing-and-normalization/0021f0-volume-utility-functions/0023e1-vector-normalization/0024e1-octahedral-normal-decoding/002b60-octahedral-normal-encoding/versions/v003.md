# Octahedral Normal Encoding

Also called: Normal Packing
## Overview
Octahedral Normal Encoding packs a 3D normal vector into a single u8 representing one of six octahedral directions based on the dominant axis and sign [S1, unofficial]. It performs the forward mapping (vector to index), contrasting with [Octahedral Normal Decoding](3373-octahedral-normal-decoding.md) which decodes the index back to a vector [G]. Unlike [Cubic Normal Encoding](11140-cubic-normal-encoding.md), which projects onto a cube face for higher precision, this method uses a fixed threshold-based selection yielding only six discrete outputs [S1, unofficial].
## How it works
**Inputs and Outputs:**
- Input: A 3D normal vector $\mathbf{n} = (n_x, n_y, n_z)$ [S1, unofficial].
- Output: An 8-bit unsigned integer index $i \in \{0, 1, 2, 3, 4, 5\}$ [S1, unofficial].

**Data Structures:**
- The output is a single byte. No intermediate data structures are required [G].

**Steps:**
1. If $n_x > 0.5$, return 1 [S1, unofficial].
2. Else if $n_x < -0.5$, return 0 [S1, unofficial].
3. Else if $n_y > 0.5$, return 3 [S1, unofficial].
4. Else if $n_y < -0.5$, return 2 [S1, unofficial].
5. Else if $n_z > 0.5$, return 5 [S1, unofficial].
6. Else, return 4 [G]. (Fallback for remaining cases, consistent with the defined index mapping.)

**Parameters:**
- Normal indices mapping:
  - 0: $-X$
  - 1: $+X$
  - 2: $-Y$
  - 3: $+Y$
  - 4: $-Z$
  - 5: $+Z$ [S1, unofficial].

**Pseudocode:**
```python
def pack_normal(n_x: float, n_y: float, n_z: float) -> int:
    """
    Encodes a 3D normal vector into a single u8 representing one of 6 octahedral directions.
    Based on the logic in [S1, unofficial].
    """
    if n_x > 0.5:
        return 1
    elif n_x < -0.5:
        return 0
    elif n_y > 0.5:
        return 3
    elif n_y < -0.5:
        return 2
    elif n_z > 0.5:
        return 5
    else:
        return 4
```

## Subtopics

### [Cubic Normal Encoding](11140-cubic-normal-encoding.md)
Maps a 3D unit normal to a 32-bit integer by projecting onto the cube face with the largest absolute component. It preserves higher precision for axis-aligned normals compared to this method's 6-value output, making it preferable when memory efficiency is less critical than accuracy.

## Operating characteristics

- **Memory Complexity:** $O(1)$, single byte output [S1, unofficial].
