# Octahedral Normal Encoding

Also called: Normal Packing

## Overview
Octahedral Normal Encoding compresses a 3D unit normal vector into a single 8-bit integer by identifying the dominant axis and its sign [S1, unofficial]. This method maps the normal to one of six discrete octahedral directions [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A 3D unit normal vector $\mathbf{n} = (n_x, n_y, n_z)$ [S1, unofficial].
- Output: An 8-bit unsigned integer index $i \in \{0, 1, 2, 3, 4, 5\}$ [S1, unofficial].

**Data Structures:**
- The output is a single byte. No intermediate data structures are required [S1, unofficial].

**Steps:**
The encoding selects the axis with the largest absolute component using a fixed priority order based on threshold comparisons against 0.5 [S1, unofficial].
1. Check if $n_x > 0.5$. If true, return index 1.
2. Else, check if $n_x < -0.5$. If true, return index 0.
3. Else, check if $n_y > 0.5$. If true, return index 3.
4. Else, check if $n_y < -0.5$. If true, return index 2.
5. Else, check if $n_z > 0.5$. If true, return index 5.
6. Else, return index 4 [S1, unofficial].

**Parameters:**
- Normal indices mapping:
  - 0: $-X$
  - 1: $+X$
  - 2: $-Y$
  - 3: $+Y$
  - 4: $-Z$
  - 5: $+Z$ [S1, unofficial].

**Pseudocode:**
```python
def pack_normal(n_x: float, n_y: float, n_z: float) -> int:
    """
    Encodes a 3D normal vector into a single u8 representing one of 6 octahedral directions.
    """
    if n_x > 0.5:
        return 1
    elif n_x < -0.5:
        return 0
    elif n_y > 0.5:
        return 3
    elif n_y < -0.5:
        return 2
    elif n_z > 0.5:
        return 5
    else:
        return 4
```

## Subtopics

### [Cubic Normal Encoding](11140-cubic-normal-encoding.md)
Cubic Normal Encoding maps a 3D unit normal vector to a single 32-bit integer by projecting the vector onto the cube face with the largest absolute component. It preserves higher precision for normals aligned with the axes and uses a deterministic tie-breaking rule when components are equal, unlike the 6-value octahedral representation. Choose it when memory efficiency is critical for sparse voxel octree storage.

## Operating characteristics
- **Time Complexity:** Constant time with a maximum of five comparisons [S1, unofficial].
- **Memory Complexity:** $O(1)$ due to the single-byte output [S1, unofficial].
- **Strengths:** Extremely fast execution and a minimal memory footprint [S1, unofficial].
- **Limitations:** Very low accuracy with only six possible output values [S1, unofficial].
