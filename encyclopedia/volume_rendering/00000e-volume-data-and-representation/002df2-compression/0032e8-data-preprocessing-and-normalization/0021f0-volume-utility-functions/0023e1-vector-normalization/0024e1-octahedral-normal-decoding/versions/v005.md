# Octahedral Normal Decoding
## Overview
Decodes a 2D octahedral coordinate into a 3D unit vector [S1, unofficial].
## How it works
**Inputs:** A 2D vector `e` representing the octahedral coordinate [S1, unofficial].
**Outputs:** A 3D unit vector `v` [S1, unofficial].

**Data Structures:**
- `e`: `vec2` (float), the encoded coordinate.
- `v`: `vec3` (float), the decoded normal.

**Steps:**
1. Construct an intermediate vector `v` using the formula:
   $$v = \text{vec3}(e, 1.0 - |e.x| - |e.y|)$$ [S1, unofficial].
2. If `v.z < 0`:
   - Compute the sign factors for x and y based on the signs of `e.x` and `e.y` [S1, unofficial].
   - Update `v.xy` using:
     $$v.xy = (1.0 - |e.yx|) \cdot \text{vec2}(\text{sign}(e.x), \text{sign}(e.y))$$ [S1, unofficial].
     where $\text{sign}(a) = 1$ if $a \ge 0$ else $-1$.
3. Calculate the length `len` of `v` [S1, unofficial].
4. If `len > 0`, return `v / len`. Otherwise, return `vec3(0, 0, 1)` [S1, unofficial].

**Pseudocode:**
```python
import math

def oct_decode(e_x, e_y):
    # Step 1: Initial construction
    v_z = 1.0 - abs(e_x) - abs(e_y)
    v = (e_x, e_y, v_z)
    
    # Step 2: Handle negative z
    if v[2] < 0:
        # Calculate sign factors
        sign_x = 1.0 if e_x >= 0 else -1.0
        sign_y = 1.0 if e_y >= 0 else -1.0
        
        # Update xy components (e.yx swizzle maps to (e.y, e.x))
        factor_x = 1.0 - abs(e_y)
        factor_y = 1.0 - abs(e_x)
        
        v = (factor_x * sign_x, factor_y * sign_y, v[2])
        
    # Step 3: Normalize
    length = math.sqrt(v[0]**2 + v[1]**2 + v[2]**2)
    
    # Step 4: Return
    if length > 0:
        return (v[0] / length, v[1] / length, v[2] / length)
    else:
        return (0.0, 0.0, 1.0)
```

**Parameters:**
- None.

**Edge Cases:**
- If the resulting vector has zero length, the method returns `(0,0,1)` [S1, unofficial].
