# Video Frame Extraction and Preprocessing

Also called: Laparoscopic Video Preprocessing

## Overview
This method extracts and preprocesses equidistant frames from laparoscopic surgical video to create a clean input dataset for 3D scene reconstruction [S1]. It discards frames with severe exposure issues or motion blur detected via adjacent camera pose differences, and crops redundant black borders [S1, S2].

## How it works
**Inputs and Outputs**
- Input: Raw laparoscopic video file.
- Output: A set of $n_{frame}$ preprocessed image frames and associated camera pose metadata [S1, S2].

**Data Structures**
- Frame List: A sequence of $n_{frame}$ images.
- Metadata: Camera pose matrices and optional UV coordinates for texture mapping [S2].

**Steps**
1. Extract $n_{frame}$ equidistant frames from the source video [S1].
2. Discard frames with severe under- and over-exposure and motion blur, detected from the difference in camera pose between adjacent frames [S2].
3. Crop the video frames to remove redundant black areas: 6.6% from the left and 9.1% from the right [S1].
4. Linearize the image gamma, apply white balancing, and remove lens distortion [S2].
5. Represent scene geometry with a standard triangle mesh with UV texture parameterization. If UV coordinates are missing, generate them automatically using Blender’s standard “Smart UV Project” operator [S2].

**Parameters**
- Original Resolution: $3840 \times 2160$ pixels [S1].
- Cropped Resolution: $3237 \times 2160$ pixels [S1].
- Video Duration: 93 seconds [S1].
- Frame Rate: $\approx 29.935$ fps [S1].
- Total Available Frames: 2784 [S1].
- $n_{frame}$: Variable number of extracted frames (e.g., 310, 1392, 2784) to test sparsity levels [S1].

**Pseudocode**
```python
def preprocess_video(video_path, n_frame, video_duration=93.0, fps=29.935):
    # Step 1: Extract equidistant frames
    total_frames = int(video_duration * fps)
    step = total_frames // n_frame
    frames = []
    for i in range(n_frame):
        idx = i * step
        frames.append(read_frame_from_video(video_path, idx))

    # Step 2: Filter bad frames using camera pose differences
    poses = compute_sfm_poses(frames)
    valid_frames = []
    valid_poses = []
    pose_threshold = 1.0
    for i in range(len(frames)):
        if i == 0 or i == len(frames) - 1:
            valid_frames.append(frames[i])
            valid_poses.append(poses[i])
        else:
            if pose_distance(poses[i], poses[i-1]) < pose_threshold and \
               pose_distance(poses[i], poses[i+1]) < pose_threshold:
                valid_frames.append(frames[i])
                valid_poses.append(poses[i])

    # Step 3: Crop frames
    h, w = valid_frames[0].shape[:2]
    crop_left = int(w * 0.066)
    crop_right = int(w * 0.091)
    cropped_frames = [f[:, crop_left:w-crop_right, :] for f in valid_frames]

    # Step 4: Linearize and White-Balance
    corrected_frames = []
    for frame in cropped_frames:
        linear = frame ** (1.0 / 2.2)
        corrected_frames.append(apply_white_balance(linear))

    # Step 5: Remove Lens Distortion
    undistorted_frames = []
    for frame in corrected_frames:
        undistorted_frames.append(undistort_lens(frame, intrinsics, distortion_coeffs))

    return undistorted_frames, valid_poses
```

## Subtopics

### Video Preprocessing for 3DGS
Extracts frames at evenly spaced intervals (default 305, adjustable via `--num-frames-target`) from an input video, runs COLMAP feature extraction and matching, executes bundle adjustment to recover camera poses and sparse 3D structure, and refines camera intrinsics [S3, unofficial]. Parameters include `--data` for the input video path and `--output-dir` for COLMAP output [S3, unofficial]. A 609-frame input video yields 305 extracted images prefixed with 'frame_' [S3, unofficial].

### Data Cleanup for Wild Capture
Captures time-lapse video on a multi-camera rig, runs a sharpness detector based on the variance of Laplacians, and discards images more than 1.5 standard deviations below the mean sharpness [S4]. Uses Mask R-CNN to identify and mask out people and animals, and detects motion for vehicles by checking if SfM points with error lower than 1.5 pixels exist under vehicle masks [S4]. Uses EgoBlur to remove vehicle license plates, constraining license plate masks to be included in segmented vehicle masks via Mask R-CNN [S4].

## Operating characteristics
- Time Complexity: Depends on $n_{frame}$ and the cost of camera pose estimation. For $n_{frame}=2784$, COLMAP takes 04:32:53 [S1]. The text states HLOC and LocalRF were not used for this sparsity, though Table 1 lists LocalRF running time as 75:10:54 on an RTX A6000 GPU [S1].
- Memory Complexity: Not given in the sources.
- Strengths: Filters frames based on camera pose discontinuities to remove motion blur and exposure issues [S2].
- Limitations: Pose estimation latency increases with $n_{frame}$ [S1].
- When to Use: Laparoscopic surgical video reconstruction [S1].
- When Not to Use: Not given in the sources.

## Background
Originated in the context of abdominal 3-D scene rendering from laparoscopic surgical videos using NeRFs [S1]. The method addresses the need for high-quality, sparse view inputs for neural rendering in medical settings [S1]. It also incorporates techniques from texture-space differentiable rendering for complex indoor scenes, such as UV generation for synthetic data [S2].
