# Voxel Clustering (Global)
Also called: Global Voxel Clustering
## Overview
Voxel Clustering (Global) is a preprocessing step in volume rendering that groups downsampled voxels into a small number of clusters based on their albedo values to share weight factors for scattering parameters [S1]. It addresses the challenge of managing a large number of unknowns in anisotropic media rendering by reducing spatial variability into discrete, globally consistent groups [S1]. Unlike sibling methods that handle local or illumination-specific variations, this method operates on the entire volume's albedo distribution to minimize global rendering error [S1].
## How it works
**Inputs:** Downsampled albedo $\bar{\alpha}_i$ for each voxel $i$, computed via linear downsampling [S1].
**Outputs:** Cluster assignment $c(i)$ for each voxel, and optimized weight factors $w_k$ for each cluster $k$ [S1].

**Data Structures:**
-   **Voxel List:** Array of voxels, each storing scalar albedo $\bar{\alpha}_i$ and a list of $m$ phase function lobes (SGGX normal distributions).
-   **Cluster Map:** Array mapping voxel index $i$ to cluster index $k \in \{0, \dots, K-1\}$.
-   **Weights:** Array $w$ of size $K$, storing the optimized weight factor for each cluster.

**Parameters:**
-   $K$: Number of voxel clusters. Typically 2 to 5 [S1].
-   $m$: Number of phase function lobes per voxel [S1].

**Steps:**
1.  **Initialize Naïve Weights:** Compute initial weight factors using naïve downsampling. For a voxel $i$ and lobe $j$, the naïve weight is:
    $$ W_{i,j}^{\text{naïve}} = \bar{\alpha}_i \frac{|V(i,j)|}{|V(i)|} $$
    where $|V(i,j)|$ is the volume contribution of lobe $j$ in voxel $i$, and $|V(i)|$ is the total volume of voxel $i$ [S1]. This is equivalent to setting the effective albedo $\alpha_i^{\text{eff}} = \bar{\alpha}_i$ [S1]. Global weights $w_k$ are initialized as the mean naïve weight within each cluster [S1].

2.  **Cluster Voxels:** Apply K-means clustering to the downsampled albedos $\bar{\alpha}_i$ to assign each voxel to one of $K$ clusters [S1].
    -   *Pitfall Handling:* To prevent visible seams where cluster boundaries cross areas with smoothly varying albedos, jitter the clustering by slightly perturbing each $\bar{\alpha}_i$ with uniform noise during the K-means execution [S1].

3.  **Reorder Lobes:** Since weight factors $w_k$ are shared among voxels in the same cluster, the ordering of phase function lobes $f_{i,j}$ must be consistent across voxels in that cluster [S1].
    -   For each cluster, pick an arbitrary reference voxel $i_0$ and fix its lobe ordering [S1].
    -   For every other voxel $i$ in the cluster, find a permutation $\pi^*_{i_0}$ of $\{1, \dots, m\}$ that minimizes the L2 difference between corresponding SGGX normal distributions $D$:
        $$ \pi^*_{i_0} = \arg \min_{\pi} \sum_{j=1}^m \int D_{i,j}(m) - D_{i_0,\pi(j)}(m) \, dm $$
    -   Reorder the lobes of voxel $i$ using $\pi^*_{i_0}$ [S1].

4.  **Optimize Weights:** Optimize the global weight factors $w_k$ for each cluster $k$ to minimize rendering error [S1].
    -   *Error Metric:* Use a generalized L2 distance between mean pixel intensities of the rendered image $\tilde{I}_r$ and ground truth $I_r$ across six bounding-box directions:
        $$ E = \sum_{r=1}^6 c_r \left( \text{mean}(\tilde{I}_r) - \text{mean}(I_r) \right)^2 $$
        where $c_r = \max(\text{mean}(I_r), 0.05)^{-1}$ is a normalization factor [S1].
    -   *Optimization:* Numerically solve for $w_1, \dots, w_K$ using gradient-based methods [S1]. The optimization is prone to local minima if the error metric does not provide clear gradients for specific clusters [S1].

**Pseudocode:**
```python
import random
import itertools

def global_voxel_clustering(voxels, K, num_lobes):
    # voxels: list of dicts with 'alpha_bar' and 'lobes' (list of m distributions)
    # Returns: cluster_map (list of ints), weights (list of floats)

    # Step 1: Initialize Naïve Weights
    # W_{i,j}^{naive} = alpha_bar_i * |V(i,j)| / |V(i)|
    # Initialize global weights w_k as the mean naïve weight in each cluster
    weights = [1.0] * K

    # Step 2: Cluster Voxels (K-means on alpha_bar with jitter)
    albedos = [v['alpha_bar'] for v in voxels]
    jittered_albedos = [a + random.uniform(-1e-4, 1e-4) for a in albedos]
    centroids = sorted(random.sample(jittered_albedos, K))
    cluster_map = [0] * len(voxels)

    for _ in range(100):
        for i, a in enumerate(jittered_albedos):
            cluster_map[i] = min(range(K), key=lambda k: abs(a - centroids[k]))
        new_centroids = [0.0] * K
        counts = [0] * K
        for i, k in enumerate(cluster_map):
            new_centroids[k] += jittered_albedos[i]
            counts[k] += 1
        for k in range(K):
            centroids[k] = new_centroids[k] / counts[k] if counts[k] > 0 else centroids[k]

    # Step 3: Reorder Lobes for Consistency
    for k in range(K):
        cluster_indices = [i for i, c in enumerate(cluster_map) if c == k]
        if not cluster_indices: continue
        ref_idx = cluster_indices[0]
        ref_lobes = voxels[ref_idx]['lobes']

        for idx in cluster_indices[1:]:
            v = voxels[idx]
            best_perm = None
            min_dist = float('inf')
            for perm in itertools.permutations(range(num_lobes)):
                dist = sum(abs(v['lobes'][j] - ref_lobes[perm[j]]) for j in range(num_lobes))
                if dist < min_dist:
                    min_dist = dist
                    best_perm = perm
            v['lobes'] = [v['lobes'][p] for p in best_perm]

    # Step 4: Optimize Weights
    def compute_error(w, v_list, cmap):
        error = 0.0
        for r in range(6):
            mean_tilde = 0.5  # Placeholder for renderer output
            mean_truth = 0.5  # Placeholder for ground truth
            c_r = 1.0 / max(mean_truth, 0.05)
            error += c_r * (mean_tilde - mean_truth) ** 2
        return error

    lr = 0.01
    for step in range(1000):
        grad = [0.0] * K
        for k in range(K):
            eps = 1e-5
            w_plus = weights[:]
            w_plus[k] += eps
            grad[k] = (compute_error(w_plus, voxels, cluster_map) - compute_error(weights, voxels, cluster_map)) / eps
        for k in range(K):
            weights[k] -= lr * grad[k]
            weights[k] = max(weights[k], 0.0)

    return cluster_map, weights
```
## Subtopics

### Optimizing Weight Factors
This variant focuses specifically on the numerical optimization of the global weight factors $w_k$ for each voxel cluster [S1]. It involves initializing weights via naïve downsampling, clustering voxels by albedo, reordering phase function lobes for consistency across voxels in the same cluster, and finally optimizing the global weights $w_k$ using an error metric based on the L2 distance between mean pixel intensities of rendered and ground truth images [S1]. The process is prone to local minima if the error metric lacks clear gradients for specific clusters [S1].

## Operating characteristics
**Time Complexity:** Dominated by K-means clustering on the number of voxels $N$, which is $O(N \cdot K \cdot I)$ where $I$ is the number of iterations, plus the optimization step which depends on the number of rendering evaluations [S1].
**Memory Complexity:** $O(N)$ to store voxel albedos and cluster assignments, plus $O(K)$ for weights [S1].
**Strengths:** Reduces the number of unknowns significantly by sharing weight factors among voxels with similar albedos [S1]. A small number of clusters (2-5) yields high-quality results [S1].
**Limitations:** Visible seams can occur if cluster boundaries cross smoothly varying albedo regions, requiring jittering [S1]. Optimization is prone to local minima [S1].
**When to Use:** When rendering anisotropic media with many voxels and limited computational resources for per-voxel parameter optimization [S1].
**When Not to Use:** When albedo varies smoothly and cluster boundaries would cause visible artifacts, or when high precision in per-voxel scattering is required [S1].
## Background
Originated in the context of downsampling scattering parameters for rendering anisotropic media [S1]. The method was developed to address the challenge of managing a large number of unknowns in volume rendering by clustering voxels based on albedo and optimizing shared weight factors [S1]. It builds on previous phase function downsampling approaches, such as those by Heitz et al. [2015], which focused on special cases [S1].
