# K-Means Spatial-Intensity Partitioning

Also called: K-Means Spatial-Intensity Clustering

## Overview
K-Means Spatial-Intensity Partitioning partitions a 3D volume into a specified number of components by clustering foreground voxels based on a weighted combination of their spatial coordinates (x, y, z) and intensity values [S1, unofficial]. It solves the problem of organizing volumetric data into manageable, semantically coherent regions for downstream processing such as compression or rendering [S1, unofficial]. It sets itself apart from [Greedy Axis-Aligned Spatial Partitioning](11585-volume-partitioning-pipeline.md) by incorporating intensity similarity into the clustering metric, allowing partitions to respect data content rather than just geometry, and from [Bounded-Memory Large Volume Export](11587-bounded-memory-large-volume-export.md) by operating as a preprocessing clustering step rather than an export strategy.

## How it works
**Inputs:**
- `volume`: A 3D numpy array or memory-mapped array of the volume data.
- `components`: The target number of clusters/partitions (integer). Default: 8.
- `spatial_weight`: Weight for spatial coordinates (x, y, z). Intensity weight is calculated as `1 - spatial_weight`. Default: 0.5.
- `seed`: Random seed for reproducibility.
- `batch_size`: Number of voxels processed per prediction batch. Default: 100,000.

**Outputs:**
- `labels`: A 3D array of the same shape as `volume`, containing integer cluster labels for each voxel. Background voxels are labeled 0; foreground voxels are labeled 1 to `components`.

**Data Structures:**
- `foreground`: 1D array of linear indices where `volume` is non-zero.
- `features`: 2D array of shape `(N, 4)` where N is the number of sampled voxels. Columns are `[x, y, z, intensity]`.
- `scaler`: A fitted `StandardScaler` instance used to normalize features.
- `kmeans`: A fitted `KMeans` model.

**Steps:**
1. **Identify Foreground:** Compute `foreground = np.flatnonzero(volume)`. If `foreground` is empty, return an array of zeros.
2. **Initialize Labels:** Create `labels` array of zeros with shape `volume.shape`.
3. **Feature Extraction:**
   - Unravel the linear indices in `foreground` to 3D coordinates `(z, y, x)`.
   - Extract intensity values from `volume` at these indices.
   - Stack `x`, `y`, `z`, and `intensity` into a 2D array of shape `(N, 4)`.
   - Cast all values to `float32`.
4. **Sampling:**
   - Determine sample size: `sample_size = min(30000, foreground.size)`.
   - Randomly select `sample_size` indices from `foreground` without replacement: `sample_indices = rng.choice(foreground, sample_size, replace=False)`.
   - Extract features for these sampled indices to form the training set `X_sample`.
5. **Normalization:**
   - Fit a `StandardScaler` on `X_sample`.
   - Transform `X_sample` using the fitted scaler.
6. **Weighting:**
   - Define weight vector `w = [spatial_weight, spatial_weight, spatial_weight, 1 - spatial_weight]`.
   - Scale the transformed features: `X_weighted = X_sample * w`.
7. **Clustering:**
   - Determine number of clusters: `n_clusters = min(components, len(np.unique(volume[volume != 0])))`.
   - Fit a `KMeans` model with `n_clusters`, `n_init=3`, `random_state=seed`, `max_iter=100` on `X_weighted`.
8. **Prediction:**
   - Initialize `labels` array of zeros with shape `volume.shape`.
   - Process all foreground voxels in batches of size `batch_size`.
   - For each batch:
     - Extract features `(x, y, z, intensity)` for the batch indices.
     - Transform features using the fitted `StandardScaler`.
     - Scale by weights `w`.
     - Predict cluster labels using the fitted `KMeans` model.
     - Assign labels to `labels` array at the corresponding indices, adding 1 to the result (since 0 is reserved for background).

**Pseudocode:**
```python
import numpy as np
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

def kmeans_spatial_intensity_partitioning(volume, components=8, spatial_weight=0.5, seed=42, batch_size=100000):
    # 1. Identify Foreground
    foreground = np.flatnonzero(volume)
    if foreground.size == 0:
        return np.zeros(volume.shape, dtype=np.int32)

    # 2. Initialize Labels
    labels = np.zeros(volume.shape, dtype=np.int32)

    # 3. Feature Extraction
    # Unravel indices to z, y, x
    z, y, x = np.unravel_index(foreground, volume.shape)
    intensity = volume[foreground]
    
    # Stack features: x, y, z, intensity
    features = np.stack((x, y, z, intensity), axis=-1).astype(np.float32)

    # 4. Sampling
    sample_size = min(30000, foreground.size)
    rng = np.random.default_rng(seed)
    sample_indices = rng.choice(foreground, sample_size, replace=False)
    
    # Extract features for sampled indices
    sample_z, sample_y, sample_x = np.unravel_index(sample_indices, volume.shape)
    sample_intensity = volume[sample_indices]
    X_sample = np.stack((sample_x, sample_y, sample_z, sample_intensity), axis=-1).astype(np.float32)

    # 5. Normalization
    scaler = StandardScaler()
    X_sample_scaled = scaler.fit_transform(X_sample)

    # 6. Weighting
    weights = np.array([spatial_weight, spatial_weight, spatial_weight, 1 - spatial_weight], dtype=np.float32)
    X_sample_weighted = X_sample_scaled * weights

    # 7. Clustering
    # Determine unique foreground values to cap clusters if necessary
    unique_vals = np.unique(volume[foreground])
    n_clusters = min(components, len(unique_vals))
    
    kmeans = KMeans(n_clusters=n_clusters, n_init=3, random_state=seed, max_iter=100)
    kmeans.fit(X_sample_weighted)

    # 8. Prediction
    # Process all foreground voxels in batches
    n_foreground = foreground.size
    for start in range(0, n_foreground, batch_size):
        end = min(start + batch_size, n_foreground)
        batch_indices = foreground[start:end]
        
        # Extract features for batch
        batch_z, batch_y, batch_x = np.unravel_index(batch_indices, volume.shape)
        batch_intensity = volume[batch_indices]
        X_batch = np.stack((batch_x, batch_y, batch_z, batch_intensity), axis=-1).astype(np.float32)
        
        # Transform and weight
        X_batch_scaled = scaler.transform(X_batch)
        X_batch_weighted = X_batch_scaled * weights
        
        # Predict
        batch_labels = kmeans.predict(X_batch_weighted)
        
        # Assign to labels array (add 1 for background offset)
        labels[batch_indices] = batch_labels + 1

    return labels
```

**Parameters:**
- `components`: Number of clusters/partitions. Default: 8 [S1, unofficial].
- `spatial_weight`: Weight for spatial coordinates (x,y,z). Intensity weight is `1 - spatial_weight`. Default: 0.5 [S1, unofficial].
- `batch_size`: Number of voxels processed per prediction batch. Default: 100,000 [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Empty Volume:** If the volume contains no foreground voxels, the method returns an array of zeros.
- **Precision:** Features are cast to `float32` to balance precision and memory usage during scaling and clustering [S1, unofficial].
- **Boundary Conditions:** The method assumes `volume` is non-negative or that "foreground" is defined by non-zero values. If the volume contains negative values, the definition of foreground must be adjusted (e.g., `volume > cutoff`) [G].
- **Cluster Count:** The number of clusters is capped by the number of unique intensity values in the foreground to prevent over-clustering on discrete data [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Dominated by the K-Means clustering step on the sampled data (up to 30,000 voxels) and the prediction step on all foreground voxels. Prediction is linear in the number of foreground voxels $O(N)$, where $N$ is the number of foreground voxels.
- **Memory Complexity:** Requires storing the volume, labels, and features for the current batch. The sampling step limits memory usage for clustering to a fixed size (30,000 voxels). Batch processing ensures memory usage for prediction scales with `batch_size`, not the total volume size [S1, unofficial].
- **Measured Performance:** Not given in the sources.
- **Scaling:** Scales well with volume size due to sampling and batch processing. The fixed sample size ensures clustering time is independent of volume size.
- **Strengths:** Handles both spatial and intensity variations; memory efficient due to sampling and batching; flexible weighting between spatial and intensity importance.
- **Limitations:** Relies on a fixed number of clusters; sensitive to the choice of `spatial_weight`; sampling may miss rare but important features if they are not represented in the 30,000 sample [S1, unofficial].
- **When to use:** When partitioning a volume into regions that are both spatially coherent and intensity-similar is desired, and memory constraints prevent processing the entire volume at once.
- **When not:** When the volume is very small (sampling overhead is unnecessary) or when intensity is not a relevant feature for partitioning.
