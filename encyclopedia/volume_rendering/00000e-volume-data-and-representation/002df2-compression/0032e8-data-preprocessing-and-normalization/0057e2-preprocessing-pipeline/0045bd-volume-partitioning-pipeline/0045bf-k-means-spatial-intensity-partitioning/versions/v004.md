# K-Means Spatial-Intensity Partitioning
Also called: K-Means Spatial-Intensity Clustering, Weighted Spatial-Intensity K-Means

## Overview
K-Means Spatial-Intensity Partitioning partitions a 3D volume into a fixed number of components by clustering foreground voxels based on a weighted combination of their spatial coordinates (x, y, z) and intensity values [S1, unofficial]. It sets itself apart from sibling methods like [Greedy Axis-Aligned Spatial Partitioning](11589-greedy-axis-aligned-spatial-partitioning.md) by incorporating intensity similarity into the clustering metric, allowing partitions to respect both geometric proximity and data homogeneity, whereas [Bounded-Memory Large Volume Export](11587-bounded-memory-large-volume-export.md) focuses on memory-constrained export rather than semantic partitioning.

## How it works
**Inputs and Outputs:**
- Input: A 3D volume array (typically integer or float), a target number of `components` (clusters), a `spatial_weight` parameter, and a `seed` for reproducibility.
- Output: A label array of the same shape as the volume, where background voxels are labeled 0 and foreground voxels are labeled 1 to `components`.

**Data Structures:**
- `volume`: The input 3D array.
- `labels`: An integer array of shape `volume.shape`, initialized to 0.
- `features`: A 2D float32 array of shape `(N, 4)` for the sampled foreground voxels, where columns are `[x, y, z, intensity]`.
- `scaler`: A `StandardScaler` instance fitted on the sampled features.

**Steps:**
1. **Foreground Extraction:** Identify all foreground voxel indices. In the source implementation, foreground is defined as `volume > cutoff` (where cutoff is typically 0 or derived from metadata) [S1, unofficial]. Let `foreground` be the flat indices of these voxels.
2. **Sampling:** To manage computational cost, sample up to 30,000 foreground indices without replacement. If the number of foreground voxels is less than 30,000, use all of them [S1, unofficial].
   $$ \text{sample\_indices} = \text{random\_choice}(\text{foreground}, \min(30000, |\text{foreground}|), \text{replace=False}) $$
3. **Feature Construction:** For the sampled indices, unravel the flat indices into 3D coordinates $(z, y, x)$ and extract the intensity value at each coordinate. Stack these into a 2D array of shape $(N_{sample}, 4)$ with columns $[x, y, z, \text{intensity}]$. Cast to `float32` [S1, unofficial].
4. **Normalization:** Fit a `StandardScaler` on the sampled features to zero-mean and unit-variance. Transform the sampled features using this scaler [S1, unofficial].
5. **Weighting:** Define a weight vector $W = [w_s, w_s, w_s, w_i]$ where $w_s = \text{spatial\_weight}$ and $w_i = 1 - \text{spatial\_weight}$. Apply these weights to the normalized features:
   $$ \text{weighted\_features} = \text{normalized\_features} \times W $$
6. **Clustering:** Fit a K-Means model on the weighted features with:
   - `n_clusters` = $\min(\text{components}, \text{unique\_foreground\_count})$
   - `n_init` = 3
   - `max_iter` = 100
   - `random_state` = `seed` [S1, unofficial].
7. **Label Assignment:** Predict cluster labels for all foreground voxels. To avoid memory issues, process in batches of `batch_size` (default 100,000) [S1, unofficial]:
   - Extract features for the batch (unravel indices, stack x,y,z,intensity).
   - Transform using the fitted `scaler`.
   - Scale by weights $W$.
   - Predict cluster labels (0 to $K-1$).
   - Assign to `labels` array at the corresponding indices, adding 1 to shift from 0-based cluster index to 1-based label (0 is reserved for background) [S1, unofficial].

**Parameters:**
- `components`: Number of clusters/partitions. Default: 8 [S1, unofficial].
- `spatial_weight`: Weight for spatial coordinates (x, y, z). The intensity weight is $1 - \text{spatial\_weight}$. Default: 0.5 [S1, unofficial].
- `batch_size`: Number of voxels processed per prediction batch. Default: 100,000 [S1, unofficial].
- `seed`: Random seed for reproducibility.

**Pseudocode:**
```python
import numpy as np
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

def kmeans_spatial_intensity_partition(volume, components=8, spatial_weight=0.5, batch_size=100000, seed=42):
    # 1. Identify foreground voxels (assuming > 0 is foreground, adjust cutoff as needed)
    foreground = np.flatnonzero(volume)
    if len(foreground) == 0:
        return np.zeros_like(volume, dtype=np.int32)

    # 2. Sample up to 30,000 indices
    n_sample = min(30000, len(foreground))
    rng = np.random.default_rng(seed)
    sample_indices = rng.choice(foreground, n_sample, replace=False)

    # 3. Feature extraction: unravel to z, y, x and get intensity
    # Note: np.unravel_index returns (z, y, x) for 3D array
    coords = np.unravel_index(sample_indices, volume.shape)
    # Stack x, y, z, intensity. Note: coords[0] is z, coords[1] is y, coords[2] is x
    features = np.stack([coords[2], coords[1], coords[0], volume[sample_indices]], axis=1).astype(np.float32)

    # 4. Normalize features
    scaler = StandardScaler()
    features_scaled = scaler.fit_transform(features)

    # 5. Apply weights
    weights = np.array([spatial_weight, spatial_weight, spatial_weight, 1.0 - spatial_weight])
    features_weighted = features_scaled * weights

    # 6. Determine number of clusters
    unique_count = len(foreground)
    n_clusters = min(components, unique_count)

    # 7. Fit K-Means
    kmeans = KMeans(n_clusters=n_clusters, n_init=3, max_iter=100, random_state=seed)
    kmeans.fit(features_weighted)

    # 8. Predict labels for all foreground voxels in batches
    labels = np.zeros(volume.shape, dtype=np.int32)
    
    # Process in batches to manage memory
    n_foreground = len(foreground)
    for start in range(0, n_foreground, batch_size):
        end = min(start + batch_size, n_foreground)
        batch_indices = foreground[start:end]
        
        # Extract features for batch
        batch_coords = np.unravel_index(batch_indices, volume.shape)
        batch_features = np.stack([batch_coords[2], batch_coords[1], batch_coords[0], volume[batch_indices]], axis=1).astype(np.float32)
        
        # Transform and weight
        batch_scaled = scaler.transform(batch_features)
        batch_weighted = batch_scaled * weights
        
        # Predict
        batch_labels = kmeans.predict(batch_weighted)
        
        # Assign to output labels (add 1 because 0 is background)
        labels[batch_indices] = batch_labels + 1

    return labels
```

**Edge Cases and Pitfalls:**
- **Empty Volume:** If no foreground voxels exist, return a zero-filled label array [S1, unofficial].
- **Precision:** Features are cast to `float32` for compatibility with standard ML libraries [S1, unofficial].
- **Boundary Conditions:** The method assumes a uniform grid for spatial coordinates. Non-uniform voxel sizes are not explicitly handled in the basic weighting scheme [S1, unofficial].

## Subtopics

### [Sub-Vector Quantization (SVQ) for Gaussian Features](13486-sub-vector-quantization-svq-for-gaussian-features.md)
Sub-Vector Quantization (SVQ) is a compression technique applied to per-Gaussian features (scale, rotation, appearance) that uses fixed K-means cluster indices and dynamically optimized codebooks to reduce storage footprint. It sets itself apart from sibling methods by decoupling cluster assignment from codebook optimization, allowing for feature-specific sub-vector lengths and dynamic range learning via 16-bit floating-point codebooks. Unlike static quantization, SVQ adapts the quantization range during the final training phase, offering a trade-off between storage efficiency and attribute representation accuracy.

### [Illumination-Aware Data Transformation](16293-illumination-aware-data-transformation.md)
Illumination-Aware Data Transformation is a precomputation step that transforms multiple volumetric modalities into a single common data structure using k-means cluster analysis with illumination-aware weighting. It solves the problem of high GPU memory footprint and costly sampling operations when rendering multimodal volumes with advanced illumination algorithms. It sets itself apart from standard clustering by incorporating occlusion and boundary-based weights into the distance metric to prioritize visually significant voxels, and from [Sub-Vector Quantization (SVQ) for Gaussian Features](13486-sub-vector-quantization-svq-for-gaussian-features.md) by operating on discrete intensity vectors rather than Gaussian parameters.

### SLIC Superpixel Segmentation with Agglomerative Clustering
A segmentation method for multivariate volumes that generates SLIC superpixels from multivariate voxels and merges them through progressive agglomerative clustering to accurately segment phases/composites [S2]. It handles disjointed regions of the same phase/composite separated by noise or other phases by using global consideration of similarity during merging to label similar disconnected regions as belonging to the same phase [S2]. Successfully demonstrated on the MIEC dataset [S2].

### Depth Map Clustering
Reduces the number of depth layers to accelerate hologram calculation with minimal visual quality decrease. Uses k-means clustering on depth map histogram [S3]. It initializes depth intervals based on the histogram, then iteratively refines boundaries by minimizing distance to cluster averages until convergence [S3]. The maximum number of depth intervals is $N_z \le 256$ [S3].

## Operating characteristics
**Time and Memory Complexity:**
- The method involves sampling, scaling, and K-Means clustering on a subset of voxels (up to 30,000), which is computationally efficient. Prediction on the full volume is linear in the number of foreground voxels, $O(N)$, where $N$ is the number of foreground voxels, assuming batch processing [S1, unofficial].
- Memory usage is dominated by the storage of the volume and the label array, plus temporary buffers for batch processing [S1, unofficial].

**Strengths and Limitations:**
- **Strengths:** Balances spatial coherence and intensity homogeneity. The sampling step ensures scalability to large volumes. Batch processing prevents memory overflow during label assignment [S1, unofficial].
- **Limitations:** The quality of clustering depends on the choice of `spatial_weight`. A weight of 0.5 treats spatial and intensity dimensions equally after normalization, which may not be optimal for all data distributions. The method assumes foreground is well-defined (e.g., non-zero) [S1, unofficial].

**When to Use:**
- Use when you need to partition a volume into semantically meaningful regions that respect both geometry and data values, such as for adaptive rendering or compression.
- Avoid when the volume has no clear foreground/background distinction or when intensity variations are not relevant to the partitioning goal.

## Background
The method is described in the context of volume segmentation and preprocessing pipelines, specifically in the `VolumeSegmenter` repository [S1, unofficial]. It is part of a broader effort to preprocess large volumes for efficient rendering and analysis, often preceding export or compression steps. The approach combines standard K-Means clustering with spatial coordinates to create partitions that are both spatially compact and intensity-homogeneous.
