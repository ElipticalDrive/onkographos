# Depth Map Clustering

Also called: Depth Interval Clustering, K-Means Depth Clustering

## Overview
Depth Map Clustering reduces the number of depth layers in a depth map to accelerate hologram calculation with minimal visual quality decrease [S1]. It partitions the depth range into a limited set of intervals using k-means clustering on the depth map histogram [S1]. Unlike [K-Means Spatial-Intensity Partitioning](11588-k-means-spatial-intensity-partitioning.md), which clusters voxels based on spatial coordinates and intensity, this method operates solely on the 1D histogram of depth values to determine layer boundaries [S1].

## How it works
**Inputs:**
- Depth map $D(x, y)$ with resolution $N_x \times N_y$.
- Maximum number of depth intervals $N_z \le 256$ [S1].
- Initial depth range $[0, 256]$ [S1].

**Outputs:**
- $N_z$ depth intervals $[d_i, d_{i+1}[$ for $i \in \{0, \dots, N_z - 1\}$ [S1].
- Cluster centers $d_i$ representing the average depth value of each cluster [S1].

**Data Structures:**
- Histogram $H_D$: Array of size 257 (for depth values 0 to 256), where $H_D[n]$ is the count of pixels with depth value $n$ [S1].
- Cluster centers: Array of size $N_z$, storing the average depth value for each cluster [S1].

**Algorithm:**
1. **Histogram Computation:** Compute $H_D$ from the input depth map $D$ [S1].
2. **Initialization:** Set initial boundaries $d_0 = 0$ and $d_{N_z} = 256$ [S1].
3. **Initial Interval Calculation:** For $i = 0, \dots, N_z - 2$, compute the next boundary:
   $$ d_{i+1} = \left\lceil \frac{1}{N_z} \sum_{n=d_i}^{d_{i+1}} H_D[n] \right\rceil $$
   [S1]. Note: The summation range in the source uses the current $d_i$ and $d_{i+1}$ as bounds for the histogram bin accumulation, effectively distributing the histogram mass evenly [S1].
4. **Iteration:** Repeat the following steps until cluster centers $d_i$ no longer change:
   - **Assignment Step:** For each $i = 0, \dots, N_z - 1$, update the boundary $d_{i+1}$ to the minimum integer $d$ such that:
     $$ |d - d_i| > |d - d_{i+1}| $$
     where $d_i$ is the current average depth value of cluster $i$ [S1]. This step effectively assigns depth values to the nearest cluster center [S1].
   - **Update Step:** Re-compute $d_i$ as the average depth value of all pixels assigned to cluster $i$ [S1].

- The phase $\phi(x, y)$ is set to a uniform random value for diffuse scenes [S1].

## Subtopics

### [Depth Clipping for DDGI Probes](17139-depth-clipping-for-ddgi-probes.md)
A compression technique for DDGI light probe depth maps that reduces the dynamic range of stored depth values by clipping them to the maximum distance between adjacent probes, allowing probes with no nearby geometry to be identified as 'dead' and compressed efficiently.

## Operating characteristics
- **Time Complexity:** Depends on the number of iterations of k-means and the size of the depth map $N_x \times N_y$. Each iteration involves histogram computation ($O(N_x N_y)$) and cluster updates ($O(N_z)$ or $O(N_x N_y)$ depending on implementation) [S1].
- **Memory Complexity:** $O(N_x N_y)$ for the depth map and histogram $H_D$ of size 257 [S1].
- **Performance:** Accelerates hologram calculation by reducing the number of depth layers from potentially high resolution to $N_z \le 256$ [S1].
- **Strengths:** Minimal decrease in visual quality [S1]. Suitable for embedded platforms like NVIDIA Jetson AGX Orin [S1].
- **Limitations:** Only applicable to depth maps for holographic rendering [S1].

## Background
- **Origin:** Proposed by Antonin Gilles, Pierre Le Gargasson, Grégory Hocquet, and Patrick Gioia in 2023 [S1].
- **Context:** Part of an embedded hologram rendering engine for a holographic near-eye display [S1].
- **Application:** Used in layer-based hologram synthesis to reduce the number of depth layers [S1].
