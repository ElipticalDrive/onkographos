# Illumination-Aware Data Transformation

Also called: Cluster-based data compression, Illumination-aware clustering, Multimodal Data Transformation (k-means Clustering), Volumetric Representation Clustering

## Overview
Illumination-Aware Data Transformation is a precomputation step that transforms multiple volumetric modalities into a single common data structure using k-means cluster analysis with illumination-aware weighting [S1, unofficial]. It solves the problem of high GPU memory footprint and costly sampling operations when rendering multimodal volumes with advanced illumination algorithms [S1, unofficial]. It sets itself apart from standard clustering by incorporating occlusion and boundary-based weights into the distance metric to prioritize visually significant voxels, and from [Sub-Vector Quantization (SVQ) for Gaussian Features](13486-sub-vector-quantization-svq-for-gaussian-features.md) by operating on discrete intensity vectors rather than Gaussian parameters [S1, unofficial].

## How it works
**Inputs:** A dataset consisting of $n$ volumetric modalities, where each voxel has an intensity value for each modality.
**Outputs:** A reference volume (3D texture) containing a cluster ID for each voxel, and a cluster lookup map (2D texture) storing the intensity vectors for each cluster.

**Data Structures:**
1.  **Reference Volume:** A 3D volume where each voxel stores a single integer representing its assigned cluster ID.
2.  **Cluster Lookup Map:** A 2D texture where each row corresponds to a cluster ID and each column corresponds to a modality. To optimize fetches, up to four modalities are combined into a single texel (4 channels). If $n > 4$, multiple texels or offsetting techniques are used to exceed maximum texture dimensions [S1, unofficial].

**Algorithm Steps:**
1.  **Weight Calculation:** For each voxel $x$ and each modality $i$, compute a local weight $w_i(x)$ based on illumination importance. Two schemes are defined:
    *   *Occlusion-Based:* Compute occlusion $occ(x)$ using a neighborhood radius $r$ and intensity window $\delta$. Count $n_r$ (total voxels in neighborhood) and $n_o$ (voxels with intensity in $[s_i(x) - \delta, s_i(x) + \delta]$). Set $w_i(x) = 1 - occ(x)$ where $occ(x) = \frac{n_o}{n_r}$ [S1, unofficial].
    *   *Boundary-Based:* Compute the gradient magnitude of the voxel. Normalize gradient magnitudes across the volume and map them to weights such that larger gradients (boundaries) receive higher weights [S1, unofficial].
2.  **Distance Metric Modification:** Define the weighted Euclidean distance between two intensity vectors $x_i$ and $x_j$ (representing voxels or cluster centers) as:
    $$d(i, j) = \sqrt{\sum_{k=1}^{n} w_k |x_{ik} - x_{jk}|^2}$$
    where $w_k$ are the local weights derived from the illumination importance of the voxel location [S1, unofficial].
3.  **K-Means Clustering:** Perform CPU-based k-means clustering on the intensity vectors of all voxals using the modified distance metric. The algorithm iterates until convergence, assigning each voxel to the nearest cluster center [S1, unofficial].
4.  **Data Structure Construction:**
    *   Create the **Reference Volume** by storing the final cluster ID for each voxel.
    *   Create the **Cluster Lookup Map** by storing the final cluster center intensity vector for each cluster ID. Each row in the map corresponds to a cluster, and columns correspond to modalities [S1, unofficial].
5.  **GPU Upload:** Upload the Reference Volume and Cluster Lookup Map to GPU memory. Use offsetting if the number of clusters exceeds the maximum texture dimension [S1, unofficial].

**Pseudocode:**
```python
def illumination_aware_data_transformation(modalities, num_clusters, r, delta):
    """
    modalities: list of 3D arrays, shape (D, H, W), containing intensity values for each modality.
    num_clusters: int, number of clusters K.
    r: int, neighborhood radius for occlusion calculation.
    delta: float, intensity window parameter for occlusion calculation.
    """
    D, H, W = modalities[0].shape
    n_modalities = len(modalities)

    # Initialize weight arrays
    weights = [np.zeros((D, H, W)) for _ in range(n_modalities)]
    
    for i in range(n_modalities):
        mod = modalities[i]
        # Compute occlusion-based weights

        # This requires a local neighborhood search. For efficiency, this is often done with a sliding window or spatial index.
        # Here we assume a helper function compute_occlusion(mod, r, delta) exists which returns occ_map.
        occ_map = compute_occlusion(mod, r, delta)
        weights[i] = 1.0 - occ_map
        
        # Note: Boundary-based weighting would replace or combine with this.
        # If using boundary-based:
        # grad_mag = compute_gradient_magnitude(mod)
        # weights[i] = normalize(grad_mag) 
        
    # Step 2: Prepare data for clustering
    # Flatten volumes to list of vectors
    voxel_indices = np.ndindex(D, H, W)
    intensity_vectors = []
    voxel_positions = []
    
    for idx in voxel_indices:
        vec = [modalities[m][idx] for m in range(n_modalities)]
        intensity_vectors.append(vec)
        voxel_positions.append(idx)
        
    intensity_vectors = np.array(intensity_vectors)

    # Initialize centroids randomly or using k-means++
    centroids = initialize_centroids(intensity_vectors, num_clusters)
    
    assignments = np.zeros(len(intensity_vectors), dtype=int)

            best_cluster = -1

                # Compute weighted distance
                dist_sq = 0.0
                for m in range(n_modalities):
                    w = weights[m][voxel_positions[v_idx]]
                    dist_sq += w * (vec[m] - centroid[m])**2
                dist = np.sqrt(dist_sq)
                
                if dist < min_dist:

                    best_cluster = c_idx
            assignments[v_idx] = best_cluster
            
        # Update centroids
        for c_idx in range(num_clusters):
            cluster_voxels = intensity_vectors[assignments == c_idx]
            if len(cluster_voxels) > 0:
                # Weighted mean update? The source describes weighted distance for assignment.
                # Standard k-means updates centroid as mean of assigned points.
                # The weighting affects which points are grouped, not necessarily the centroid calculation itself
                # unless specified. We assume standard mean update for centroid.
                centroids[c_idx] = np.mean(cluster_voxels, axis=0)
                
        # Check convergence
        if converged(centroids, old_centroids):
            break
        old_centroids = centroids.copy()
        
    # Step 4: Construct Reference Volume
    reference_volume = np.zeros((D, H, W), dtype=int)
    for v_idx, idx in enumerate(voxel_indices):
        reference_volume[idx] = assignments[v_idx]
        
    # Step 5: Construct Cluster Lookup Map
    # Map shape: (num_clusters, n_modalities)
    # If n_modalities > 4, pack into multiple texels or use offsetting.
    lookup_map = np.zeros((num_clusters, n_modalities))
    for c_idx in range(num_clusters):
        cluster_voxels = intensity_vectors[assignments == c_idx]
        if len(cluster_voxels) > 0:
            lookup_map[c_idx] = np.mean(cluster_voxels, axis=0)
            
    return reference_volume, lookup_map

def compute_occlusion(mod, r, delta):
    """
    Computes occlusion map for a single modality.
    occ(x) = n_o / n_r
    """
    D, H, W = mod.shape
    occ_map = np.zeros((D, H, W))
    
    # Iterate over all voxels
    for z in range(D):
        for y in range(H):
            for x in range(W):
                intensity = mod[z, y, x]
                # Define neighborhood bounds
                z_min, z_max = max(0, z-r), min(D-1, z+r)
                y_min, y_max = max(0, y-r), min(H-1, y+r)
                x_min, x_max = max(0, x-r), min(W-1, x+r)
                
                n_r = 0
                n_o = 0
                
                # Count voxels in neighborhood
                for zz in range(z_min, z_max + 1):
                    for yy in range(y_min, y_max + 1):
                        for xx in range(x_min, x_max + 1):
                            n_r += 1
                            if abs(mod[zz, yy, xx] - intensity) <= delta:
                                n_o += 1
                                
                occ_map[z, y, x] = n_o / n_r if n_r > 0 else 0
                
    return occ_map
```

**Parameters:**
*   `num_clusters`: Number of clusters $K$. Not given in the sources.
*   `r`: Neighborhood radius for occlusion calculation. Not given in the sources.
*   `delta`: Intensity window parameter for occlusion calculation. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Texture Dimensions:** The number of clusters may exceed the maximum texture dimension of the GPU. Offseting techniques must be used to handle this [S1, unofficial].
*   **Modality Count:** The method combines up to four modalities into a single texel. For more than four modalities, additional handling is required [S1, unofficial].
*   **Occlusion Calculation:** The neighborhood search for occlusion is computationally expensive on the CPU. Efficient spatial indexing or sliding window techniques are implied but not detailed [S1, unofficial].

## Subtopics

### Occlusion-Based Weighting
A weighting scheme that derives local weights based on voxel occlusion to consider occluded voxels as less important during clustering [S1, unofficial]. It computes the degree of occlusion for each voxel and its intensity $s_i(x)$ by considering a local neighborhood radius $r$ and an intensity window parameter $\delta$. The occlusion is derived based on the number of all voxels within the $r$ neighborhood ($n_r$) and the number of voxels ($n_o$) having intensity in $[s_i(x) - \delta, s_i(x) + \delta]$. The weight is $1 - occ(x)$ where $occ(x) = \frac{n_o}{n_r}$ [S1, unofficial]. Choose this when occlusion significantly impacts the visual contribution of voxels.

### Boundary-Based Weighting
A weighting scheme based on the rationale that viewers focus on boundary layers, mapping gradient length to a local weight to emphasize shadow silhouettes [S1, unofficial]. It maps the gradient length of a voxel to a local weight used in the Euclidean distance function. Gradient magnitudes are normalized and mapped to weights such that larger gradient magnitudes obtain higher weighting [S1, unofficial]. Choose this when boundary features are critical for shape recognition and illumination effects.

## Operating characteristics
**Time Complexity:** The clustering step is CPU-based and involves iterative k-means with a weighted distance calculation for each voxel and cluster. The occlusion calculation adds a neighborhood search cost per voxel. Not given in the sources.
**Memory Complexity:** The reference volume stores one integer per voxel. The lookup map stores $K \times n$ floats, where $K$ is the number of clusters and $n$ is the number of modalities. This is significantly smaller than storing $n$ full volumes if $K \ll D \times H \times W$ [S1, unofficial].
**Measured Performance:** Data query time is constant time: one 3D texture fetch (for cluster ID) and one additional 2D texture fetch (for intensity vector) for up to four modalities [S1, unofficial].
**Strengths:** Reduces GPU memory footprint and sampling costs. Enables rapid data fetches. Incorporates perceptual properties of illumination to simplify computation [S1, unofficial].
**Limitations:** Requires CPU precomputation. Limited to up to four modalities per texel fetch without offsetting complexity. The quality of clustering depends on the weight schemes [S1, unofficial].
**When to use:** When rendering multimodal volumes with advanced illumination algorithms where GPU memory and sampling costs are bottlenecks.
**When not to use:** When real-time preprocessing is not feasible or when the number of modalities is very large and cannot be efficiently packed [S1, unofficial].

## Background
Originated in the paper "Multimodal Volume Illumination" by Sunden et al. (2015) [S1, unofficial]. The method is part of a four-stage workflow for multimodal volume illumination, where stage 1 is data transformation via clustering [S1, unofficial]. It builds on the observation that perceptual properties of illumination can be exploited to simplify computation [S1, unofficial].
