# Illumination-Aware Data Transformation

Also called: Cluster-based data compression, Illumination-aware clustering, Multimodal Data Transformation (k-means Clustering), Volumetric Representation Clustering

## Overview
Illumination-Aware Data Transformation is a precomputation step that transforms multiple volumetric modalities into a single common data structure using k-means cluster analysis with illumination-aware weighting [S1, unofficial]. It solves the problem of high GPU memory footprint and costly sampling operations when rendering multimodal volumes with advanced illumination algorithms [S1, unofficial]. It sets itself apart from standard k-means by incorporating occlusion and boundary-based weights into the distance metric to prioritize visually significant voxels [S1, unofficial].

## How it works
**Inputs:** A dataset consisting of $n$ volumetric modalities, where each voxel has an intensity value for each modality [S1, unofficial].
**Outputs:** A reference volume containing a cluster ID for each voxel, and a cluster lookup map storing the associated intensity vectors for each cluster ID [S1, unofficial].

**Data Structures:**
1. **Reference Volume:** A 3D volume where each voxel stores a single integer representing its assigned cluster ID [S1, unofficial].
2. **Cluster Lookup Map:** A 2D map where each row corresponds to an intensity vector (cluster) and each column corresponds to one modality [S1, unofficial]. To optimize fetches, up to four modalities are combined into a single texel (4 channels) [S1, unofficial].

**Algorithm Steps:**
1. **Weight Calculation:** For each voxel $x$ and each modality $i$, compute a local weight $w_i(x)$ based on illumination importance [S1, unofficial]. Two schemes are defined:
   * *Occlusion-Based:* Compute the degree of occlusion for each voxel and its intensity $s_i(x)$ by considering a local neighborhood radius $r$ and an intensity window parameter $\delta$ [S1, unofficial]. Derive occlusion based on the number of all voxels within the $r$ neighborhood ($n_r$) and the number of voxels ($n_o$) having intensity in $[s_i(x) - \delta, s_i(x) + \delta]$ [S1, unofficial]. Set $w_i(x) = 1 - occ(x)$ where $occ(x) = \frac{n_o}{n_r}$ [S1, unofficial].
   * *Boundary-Based:* Map the gradient length of a voxel to a local weight used in the Euclidean distance function [S1, unofficial]. Normalize gradient magnitudes and map them to weights such that larger gradient magnitudes obtain higher weighting [S1, unofficial].
2. **Distance Metric Modification:** Modify the Euclidean distance metric in k-means clustering by incorporating illumination-aware weights to emphasize important voxels [S1, unofficial]. The distance between two intensity vectors $x_i$ and $x_j$ is:
   $$d(i, j) = \sqrt{w_1 |x_{i1} - x_{j1}|^2 + w_2 |x_{i2} - x_{j2}|^2 + ... + w_n |x_{in} - x_{jn}|^2}$$
   where $w_k$ are the local weights derived from the illumination importance of the current voxel location [S1, unofficial].
3. **K-Means Clustering:** Perform CPU-based k-means clustering on the intensity vectors of all voxels using the modified distance metric [S1, unofficial]. The algorithm iterates until convergence, assigning each voxel to the nearest cluster center [S1, unofficial].
4. **Data Structure Construction:** Create the **Reference Volume** by storing the final cluster ID for each voxel [S1, unofficial]. Create the **Cluster Lookup Map** by storing the final cluster center intensity vector for each cluster ID [S1, unofficial].
5. **GPU Upload:** Upload the Reference Volume and Cluster Lookup Map to GPU memory [S1, unofficial]. Use offsetting to avoid limiting clusters to the maximum texture dimension of the GPU [S1, unofficial].

**Pseudocode:**
```python
def illumination_aware_data_transformation(modalities, num_clusters, r, delta):
    """
    modalities: list of 3D lists/arrays, shape (D, H, W), containing intensity values for each modality.
    num_clusters: int, number of clusters K.
    r: int, neighborhood radius for occlusion calculation.
    delta: float, intensity window parameter for occlusion calculation.
    """
    D, H, W = len(modalities[0]), len(modalities[0][0]), len(modalities[0][0][0])
    n_modalities = len(modalities)
    
    # Step 1: Compute weights for each voxel and modality
    # The source specifies using a single modality's occlusion to derive weights for the k-means algorithm.
    weights = [[[0.0 for _ in range(W)] for _ in range(H)] for _ in range(D)]
    
    for z in range(D):
        for y in range(H):
            for x in range(W):
                intensity = modalities[0][z][y][x]
                z_min, z_max = max(0, z - r), min(D - 1, z + r)
                y_min, y_max = max(0, y - r), min(H - 1, y + r)
                x_min, x_max = max(0, x - r), min(W - 1, x + r)
                
                n_r = 0
                n_o = 0
                for zz in range(z_min, z_max + 1):
                    for yy in range(y_min, y_max + 1):
                        for xx in range(x_min, x_max + 1):
                            n_r += 1
                            if abs(modalities[0][zz][yy][xx] - intensity) <= delta:
                                n_o += 1
                occ = n_o / n_r if n_r > 0 else 0.0
                weights[z][y][x] = 1.0 - occ
    
    # Step 2: Prepare data for clustering
    voxel_indices = []
    intensity_vectors = []
    for z in range(D):
        for y in range(H):
            for x in range(W):
                voxel_indices.append((z, y, x))
                vec = [modalities[m][z][y][x] for m in range(n_modalities)]
                intensity_vectors.append(vec)
    
    # Step 3: K-Means Clustering with weighted distance
    import random
    centroids = random.sample(intensity_vectors, num_clusters)
    assignments = [0] * len(intensity_vectors)
    max_iterations = 100
    converged = False
    
    for iteration in range(max_iterations):
        if converged:
            break
        old_centroids = [c[:] for c in centroids]
        
        # Assign each voxel to nearest centroid using weighted distance
        for v_idx, vec in enumerate(intensity_vectors):
            min_dist_sq = float('inf')
            best_cluster = -1
            for c_idx, centroid in enumerate(centroids):
                dist_sq = 0.0
                for m in range(n_modalities):
                    w = weights[voxel_indices[v_idx][0]][voxel_indices[v_idx][1]][voxel_indices[v_idx][2]]
                    dist_sq += w * (vec[m] - centroid[m]) ** 2
                if dist_sq < min_dist_sq:
                    min_dist_sq = dist_sq
                    best_cluster = c_idx
            assignments[v_idx] = best_cluster
            
        # Update centroids
        for c_idx in range(num_clusters):
            cluster_voxels = [intensity_vectors[i] for i in range(len(intensity_vectors)) if assignments[i] == c_idx]
            if len(cluster_voxels) > 0:
                new_centroid = [0.0] * n_modalities
                for m in range(n_modalities):
                    new_centroid[m] = sum(v[m] for v in cluster_voxels) / len(cluster_voxels)
                centroids[c_idx] = new_centroid
        
        # Check convergence
        converged = True
        for c_idx in range(num_clusters):
            for m in range(n_modalities):
                if abs(centroids[c_idx][m] - old_centroids[c_idx][m]) > 1e-6:
                    converged = False
                    break
            if not converged:
                break
                
    # Step 4: Construct Reference Volume
    reference_volume = [[[0 for _ in range(W)] for _ in range(H)] for _ in range(D)]
    for v_idx, idx in enumerate(voxel_indices):
        reference_volume[idx[0]][idx[1]][idx[2]] = assignments[v_idx]
        
    # Step 5: Construct Cluster Lookup Map
    lookup_map = [[0.0] * n_modalities for _ in range(num_clusters)]
    for c_idx in range(num_clusters):
        cluster_voxels = [intensity_vectors[i] for i in range(len(intensity_vectors)) if assignments[i] == c_idx]
        if len(cluster_voxels) > 0:
            for m in range(n_modalities):
                lookup_map[c_idx][m] = sum(v[m] for v in cluster_voxels) / len(cluster_voxels)
                
    return reference_volume, lookup_map
```

**Parameters:**
* `num_clusters`: Number of clusters $K$. Not given in the sources.
* `r`: Neighborhood radius for occlusion calculation. Not given in the sources.
* `delta`: Intensity window parameter for occlusion calculation. Not given in the sources.

**Edge Cases and Pitfalls:**
* **Texture Dimensions:** The number of clusters may exceed the maximum texture dimension of the GPU, requiring offsetting techniques during upload [S1, unofficial].
* **Modality Count:** The method combines up to four modalities into a single texel for constant-time query fetches [S1, unofficial].
* **Occlusion Calculation:** The neighborhood search for occlusion is computationally expensive on the CPU [S1, unofficial].

## Subtopics

### Occlusion-Based Weighting
A weighting scheme that derives local weights based on voxel occlusion to consider occluded voxels as less important during clustering [S1, unofficial]. It computes the degree of occlusion for each voxel and its intensity $s_i(x)$ by considering a local neighborhood radius $r$ and an intensity window parameter $\delta$ [S1, unofficial]. The occlusion is derived based on the number of all voxels within the $r$ neighborhood ($n_r$) and the number of voxels ($n_o$) having intensity in $[s_i(x) - \delta, s_i(x) + \delta]$ [S1, unofficial]. The weight is $1 - occ(x)$ where $occ(x) = \frac{n_o}{n_r}$ [S1, unofficial]. Choose this when occlusion significantly impacts the visual contribution of voxels [S1, unofficial].

### Boundary-Based Weighting
A weighting scheme based on the rationale that viewers focus on boundary layers, mapping gradient length to a local weight to emphasize shadow silhouettes [S1, unofficial]. It maps the gradient length of a voxel to a local weight used in the Euclidean distance function [S1, unofficial]. Gradient magnitudes are normalized and mapped to weights such that larger gradient magnitudes obtain higher weighting [S1, unofficial]. Choose this when boundary features are critical for shape recognition and illumination effects [S1, unofficial].

## Operating characteristics
**Time Complexity:** The clustering step is CPU-based and involves iterative k-means with a weighted distance calculation for each voxel and cluster. The occlusion calculation adds a neighborhood search cost per voxel [S1, unofficial].
**Memory Complexity:** The reference volume stores one integer per voxel. The lookup map stores $K \times n$ floats, where $K$ is the number of clusters and $n$ is the number of modalities [S1, unofficial].
**Measured Performance:** Data query time is constant time: one 3D texture fetch (for cluster ID) and one additional 2D texture fetch (for intensity vector) for up to four modalities [S1, unofficial].
**Strengths:** Reduces GPU memory footprint and sampling costs. Enables rapid data fetches. Incorporates perceptual properties of illumination to simplify computation [S1, unofficial].
**Limitations:** Requires CPU precomputation. Limited to up to four modalities per texel fetch without offsetting complexity. The quality of clustering depends on the weight schemes [S1, unofficial].
**When to use:** When rendering multimodal volumes with advanced illumination algorithms where GPU memory and sampling costs are bottlenecks [S1, unofficial].
**When not to use:** Not given in the sources.

## Background
Originated in the paper "Multimodal Volume Illumination" by Sunden et al. (2015) [S1, unofficial]. The method is part of a four-stage workflow for multimodal volume illumination, where stage 1 is data transformation via clustering [S1, unofficial]. It builds on the observation that perceptual properties of illumination can be exploited to simplify computation [S1, unofficial].
