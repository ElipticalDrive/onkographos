# K-Means Spatial-Intensity Partitioning

Also called: Spatial-Intensity K-Means Clustering

## Overview
K-Means Spatial-Intensity Partitioning partitions a 3D volume into a specified number of components by clustering foreground voxels based on a weighted combination of their spatial coordinates (x, y, z) and intensity values [S1, unofficial]. It solves the problem of organizing volumetric data into manageable, semantically coherent regions for downstream processing such as compression or rendering. It sets itself apart from [Greedy Axis-Aligned Spatial Partitioning](11589-greedy-axis-aligned-spatial-partitioning.md) by using iterative centroid-based clustering rather than recursive axis-aligned splits, and from [Bounded-Memory Large Volume Export](11587-bounded-memory-large-volume-export.md) by focusing on feature-based grouping rather than memory-constrained export strategies.

## How it works
**Inputs:**
- `volume`: A 3D numpy array or memory-mapped array representing the volume data.
- `components`: The target number of clusters/partitions (default: 8).
- `spatial_weight`: Weight for spatial coordinates (default: 0.5). The intensity weight is calculated as `1 - spatial_weight`.
- `seed`: Random seed for reproducibility (default: None).
- `batch_size`: Number of voxels processed per prediction batch (default: 100,000).

**Outputs:**
- `labels`: A 3D array of the same shape as `volume`, containing integer cluster labels. Background voxels are labeled 0; foreground voxels are labeled 1 to `components`.

**Data Structures:**
- `foreground`: A 1D array of flat indices where `volume` is non-zero.
- `features`: A 2D array of shape `(N, 4)` where N is the number of sampled voxels, containing normalized (x, y, z, intensity) values.
- `scaler`: A `StandardScaler` instance fitted on the sample features.
- `kmeans`: A `KMeans` model instance.

**Steps:**
1. **Identify Foreground:** Compute `foreground = np.flatnonzero(volume)`. If `foreground` is empty, return an array of zeros.
2. **Initialize Labels:** Create a `labels` array of zeros with shape `volume.shape`.
3. **Feature Extraction:**
   - Unravel the flat indices in `foreground` to get 3D coordinates `(z, y, x)`.
   - Extract intensity values from `volume` at these indices.
   - Stack `x`, `y`, `z`, and `intensity` into a 2D array of shape `(M, 4)`, where M is `foreground.size`.
   - Cast to `float32`.
4. **Sampling:**
   - Determine sample size: `sample_size = min(30000, M)`.
   - Randomly select `sample_size` indices from `foreground` without replacement: `sample_indices = rng.choice(foreground, sample_size, replace=False)`.
   - Extract features for these indices to form `sample_features`.
5. **Scaling:**
   - Fit a `StandardScaler` on `sample_features`.
   - Transform `sample_features` using the fitted scaler.
6. **Weighting:**
   - Define weight vector `w = [spatial_weight, spatial_weight, spatial_weight, 1 - spatial_weight]`.
   - Scale the transformed sample features: `weighted_sample = sample_features_transformed * w`.
7. **Clustering:**
   - Determine number of clusters: `n_clusters = min(components, len(np.unique(volume[volume != 0])))`.
   - Fit a `KMeans` model with `n_clusters`, `n_init=3`, `random_state=seed`, and `max_iter=100` on `weighted_sample`.
8. **Prediction:**
   - Initialize `all_features` array of shape `(M, 4)` for all foreground voxels.
   - Fill `all_features` with the unraveled coordinates and intensities of all foreground voxels.
   - Transform `all_features` using the fitted `StandardScaler`.
   - Scale by weights `w`.
   - Predict labels in batches of `batch_size`:
     - For each batch of features, call `kmeans.predict()`.
     - Add 1 to the predicted labels (to reserve 0 for background).
     - Assign these labels to the corresponding positions in the `labels` array using the flat indices in `foreground`.

**Pseudocode:**

```python
import numpy as np
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

def kmeans_spatial_intensity_partitioning(volume, components=8, spatial_weight=0.5, seed=None, batch_size=100000):
    # 1. Identify Foreground
    foreground = np.flatnonzero(volume)
    if foreground.size == 0:
        return np.zeros(volume.shape, dtype=np.int32)
    
    # 2. Initialize Labels
    labels = np.zeros(volume.shape, dtype=np.int32)
    
    # 3. Feature Extraction
    # Unravel indices to z, y, x
    z, y, x = np.unravel_index(foreground, volume.shape)
    intensities = volume[foreground]
    
    # Stack x, y, z, intensity. Note: sklearn expects (n_samples, n_features)
    # We use x, y, z, intensity order as per source definition
    all_features = np.stack([x, y, z, intensities], axis=1).astype(np.float32)
    M = all_features.shape[0]
    
    # 4. Sampling
    sample_size = min(30000, M)
    rng = np.random.default_rng(seed)
    sample_indices = rng.choice(M, sample_size, replace=False)
    sample_features = all_features[sample_indices]
    
    # 5. Scaling
    scaler = StandardScaler()
    sample_features_scaled = scaler.fit_transform(sample_features)
    
    # 6. Weighting
    weights = np.array([spatial_weight, spatial_weight, spatial_weight, 1 - spatial_weight], dtype=np.float32)
    weighted_sample = sample_features_scaled * weights
    
    # 7. Clustering
    unique_foreground_values = np.unique(volume[foreground])
    n_clusters = min(components, len(unique_foreground_values))
    
    kmeans = KMeans(n_clusters=n_clusters, n_init=3, random_state=seed, max_iter=100)
    kmeans.fit(weighted_sample)
    
    # 8. Prediction
    # Transform all features
    all_features_scaled = scaler.transform(all_features)
    weighted_all = all_features_scaled * weights
    
    # Predict in batches
    current_labels = np.zeros(M, dtype=np.int32)
    for i in range(0, M, batch_size):
        end = min(i + batch_size, M)
        batch = weighted_all[i:end]
        batch_preds = kmeans.predict(batch)
        current_labels[i:end] = batch_preds + 1  # +1 to reserve 0 for background
        
    # Assign to output labels
    labels[foreground] = current_labels
    
    return labels
```

**Parameters:**
- `components`: Number of clusters/partitions. Default 8 [S1, unofficial].
- `spatial_weight`: Weight for spatial coordinates (x,y,z). Intensity weight is `1 - spatial_weight`. Default 0.5 [S1, unofficial].
- `batch_size`: Number of voxels processed per prediction batch. Default 100,000 [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Empty Volume:** If the volume contains no foreground voxels, the method returns an array of zeros.
- **Precision:** Features are cast to `float32` to balance precision and memory usage [S1, unofficial].
- **Boundary Conditions:** The method explicitly pools small disconnected regions by band for manageable UI, though the core algorithm relies on global clustering [S1, unofficial].

## Subtopics

### SLIC Superpixel Segmentation with Agglomerative Clustering
A segmentation method for multivariate volumes that generates SLIC superpixels from multivariate voxels and merges them through progressive agglomerative clustering to accurately segment phases/composites. It sets itself apart from sibling methods by using local superpixel generation followed by global merging, which handles disjointed regions of the same phase separated by noise or other phases by labeling them as belonging to the same phase. It is chosen when accurate phase segmentation in multivariate scientific data (e.g., MIEC dataset) is required. [SLIC Superpixel Segmentation with Agglomerative Clustering](13487-slic-superpixel-segmentation-with-agglomerative-clustering.md)

### Depth Map Clustering
Reduces the number of depth layers to accelerate hologram calculation with minimal visual quality decrease. Uses k-means clustering on depth map histogram. It sets itself apart from sibling methods by operating on 2D depth maps for holographic rendering rather than 3D volumetric intensity/spatial features. It is chosen when rendering holograms with limited depth layers is necessary. [Depth Map Clustering](13488-depth-map-clustering.md)

## Operating characteristics
**Time and Memory Complexity:**
- Time complexity is dominated by the K-Means clustering step, which is $O(I \cdot N \cdot K \cdot D)$ where $I$ is iterations, $N$ is sample size, $K$ is clusters, and $D$ is features (4). Prediction is $O(M \cdot K \cdot D)$ where $M$ is total foreground voxels.
- Memory complexity is $O(M \cdot D)$ for storing features and labels.

**Measured Performance:**
- Not given in the sources.

**Scaling:**
- The method uses sampling (up to 30,000 voxels) for fitting, making it scalable to large volumes. Prediction is done in batches to manage memory.

**Strengths and Limitations:**
- Strengths: Combines spatial and intensity information; scalable via sampling and batching.
- Limitations: Requires tuning of `spatial_weight`; assumes convex cluster shapes (K-Means assumption).

**When to use it and when not:**
- Use when you need to partition a volume into coherent regions based on both location and value.
- Do not use when the volume is empty or when non-convex cluster shapes are expected and cannot be handled by weighting.

## Background
Originated from the VolumeSegmenter project by Winson-L [S1, unofficial]. It is used in preprocessing pipelines for volume data to group voxels into manageable components for further analysis or compression.
