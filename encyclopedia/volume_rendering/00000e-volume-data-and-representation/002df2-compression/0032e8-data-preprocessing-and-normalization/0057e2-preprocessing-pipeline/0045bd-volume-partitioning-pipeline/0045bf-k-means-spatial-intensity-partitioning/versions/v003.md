# K-Means Spatial-Intensity Partitioning
Also called: K-Means Spatial-Intensity Clustering, Weighted Spatial-Intensity K-Means

## Overview
K-Means Spatial-Intensity Partitioning partitions a 3D volume into a specified number of components by clustering foreground voxels based on a weighted combination of their spatial coordinates (x, y, z) and intensity values [S1, unofficial]. It sets itself apart from sibling methods by explicitly balancing geometric locality with radiometric similarity, allowing the user to tune the influence of position versus intensity via a `spatial_weight` parameter, whereas [Greedy Axis-Aligned Spatial Partitioning](11589-greedy-axis-aligned-spatial-partitioning.md) relies solely on spatial boundaries and [Bounded-Memory Large Volume Export](11587-bounded-memory-large-volume-export.md) focuses on memory-constrained export rather than semantic clustering.

## How it works
**Inputs and Outputs:**
- Input: A 3D volume array (binary or intensity), number of clusters `components`, `spatial_weight`, `batch_size`, `seed`.
- Output: A label array of the same shape as the volume, where background voxels are labeled 0 and foreground voxels are labeled 1 to `components`.

**Data Structures:**
- `volume`: 3D numpy array.
- `labels`: 3D numpy array of integers, initialized to 0.
- `features`: 2D float32 array of shape `(N, 4)` for N sampled voxels, columns `[x, y, z, intensity]`.
- `scaler`: StandardScaler instance fitted on the sample.
- `kmeans`: KMeans instance.

**Steps:**
1. **Foreground Extraction:** Identify foreground voxel indices using `np.flatnonzero(volume)`. Let this array be `foreground`.
2. **Sampling:** If `foreground.size` > 30,000, randomly sample 30,000 indices without replacement using a random number generator seeded by `seed`. Otherwise, use all foreground indices. Let this subset be `sample_indices`.
3. **Feature Construction:** For each index in `sample_indices`, unravel the flat index to 3D coordinates `(z, y, x)`. Stack these coordinates with the voxel's intensity value to form a 4D feature vector `[x, y, z, intensity]`. Cast all values to `float32`.
4. **Normalization:** Fit a `StandardScaler` on the sampled feature vectors. Transform the sampled features using the fitted scaler.
5. **Weighting:** Define a weight vector `w = [spatial_weight, spatial_weight, spatial_weight, 1 - spatial_weight]`. Multiply the transformed features element-wise by `w`.
6. **Clustering:** Initialize a K-Means model with `n_clusters = min(components, number_of_unique_foreground_values)`, `n_init=3`, `random_state=seed`, and `max_iter=100`. Fit the model on the weighted, scaled sample features.
7. **Prediction:** Iterate through all foreground voxels in batches of size `batch_size` (default 100,000). For each batch:
    a. Unravel indices to `(z, y, x)` and stack with intensity to form features.
    b. Cast to `float32`.
    c. Transform features using the fitted `StandardScaler`.
    d. Scale features by `w`.
    e. Predict cluster labels using the fitted K-Means model.
    f. Assign labels to the output `labels` array at the corresponding positions, adding 1 to the predicted label (since 0 is reserved for background).

**Formulas:**
- Feature vector for voxel $v$: $f_v = [x_v, y_v, z_v, I_v]$
- Weighted feature: $f'_v = f_v \cdot w$
- Normalized feature: $\hat{f}_v = \frac{f'_v - \mu}{\sigma}$, where $\mu$ and $\sigma$ are the mean and standard deviation of the sample features per dimension.
- Label assignment: $L_v = \text{argmin}_{k} \| \hat{f}_v - c_k \|^2 + 1$, where $c_k$ is the centroid of cluster $k$.

**Parameters:**
- `components`: Number of clusters. Default: 8 [S1, unofficial].
- `spatial_weight`: Weight for spatial coordinates. Intensity weight is $1 - \text{spatial\_weight}$. Default: 0.5 [S1, unofficial].
- `batch_size`: Voxels per prediction batch. Default: 100,000 [S1, unofficial].
- `seed`: Random seed for reproducibility.

**Edge Cases and Pitfalls:**
- If `components` exceeds the number of unique foreground intensity values, the number of clusters is capped at the unique count [S1, unofficial].
- Background voxels (zero intensity or false in binary mask) are excluded from clustering and assigned label 0 [S1, unofficial].
- Precision issues may arise if intensity values vary significantly in scale compared to spatial coordinates; the `StandardScaler` mitigates this by normalizing each dimension to zero mean and unit variance before weighting [S1, unofficial].

**Pseudocode:**
```python
import numpy as np
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

def kmeans_spatial_intensity_partition(volume, components=8, spatial_weight=0.5, batch_size=100000, seed=42):
    # 1. Get foreground indices
    foreground = np.flatnonzero(volume)
    if foreground.size == 0:
        return np.zeros_like(volume, dtype=np.int32)
    
    # 2. Sample up to 30,000
    rng = np.random.default_rng(seed)
    n_sample = min(30000, foreground.size)
    sample_indices = rng.choice(foreground, size=n_sample, replace=False)
    
    # 3. Feature extraction
    # Unravel flat indices to (z, y, x)
    coords = np.unravel_index(sample_indices, volume.shape)
    # Stack x, y, z, intensity. Note: coords are (z, y, x)
    features = np.stack([coords[2], coords[1], coords[0], volume[sample_indices]], axis=1).astype(np.float32)
    
    # 4. Fit StandardScaler
    scaler = StandardScaler()
    features_scaled = scaler.fit_transform(features)
    
    # 5. Define weights
    w = np.array([spatial_weight, spatial_weight, spatial_weight, 1.0 - spatial_weight], dtype=np.float32)
    features_weighted = features_scaled * w
    
    # 6. Fit KMeans
    # Cap clusters by unique foreground values if necessary
    unique_vals = len(np.unique(volume[foreground]))
    n_clusters = min(components, unique_vals)
    
    kmeans = KMeans(n_clusters=n_clusters, n_init=3, random_state=seed, max_iter=100)
    kmeans.fit(features_weighted)
    
    # 7. Predict for all foreground voxels in batches
    labels = np.zeros(volume.shape, dtype=np.int32)
    
    # Process in batches
    for i in range(0, foreground.size, batch_size):
        batch_indices = foreground[i:i+batch_size]
        batch_coords = np.unravel_index(batch_indices, volume.shape)
        batch_features = np.stack([batch_coords[2], batch_coords[1], batch_coords[0], volume[batch_indices]], axis=1).astype(np.float32)
        
        batch_scaled = scaler.transform(batch_features)
        batch_weighted = batch_scaled * w
        
        batch_labels = kmeans.predict(batch_weighted)
        # Add 1 because 0 is background
        labels[batch_indices] = batch_labels + 1
        
    return labels
```

## Subtopics

### SLIC Superpixel Segmentation with Agglomerative Clustering
A segmentation method for multivariate volumes that generates SLIC superpixels from multivariate voxels and merges them through progressive agglomerative clustering to accurately segment phases/composites [S2]. It sets itself apart from K-Means Spatial-Intensity Partitioning by operating on multivariate data and using a two-stage process (superpixel generation followed by merging) rather than direct clustering, which helps handle disjointed regions of the same phase separated by noise or other phases by using global consideration of similarity during merging [S2]. It was successfully demonstrated on the MIEC dataset [S2].

### Depth Map Clustering
Reduces the number of depth layers to accelerate hologram calculation with minimal visual quality decrease. Uses k-means clustering on depth map histogram [S3]. It sets itself apart by operating on 2D depth maps rather than 3D volumes and using a histogram-based initialization for cluster boundaries, followed by iterative assignment and update steps to refine depth intervals [S3]. The maximum number of depth intervals is $N_z \le 256$ [S3].

## Operating characteristics
- **Time Complexity:** Dominated by the K-Means fitting on the sample (up to 30,000 points) and the prediction pass over all foreground voxels. Prediction is $O(N \cdot K \cdot D)$ where $N$ is foreground voxel count, $K$ is clusters, $D=4$.
- **Memory Complexity:** $O(N)$ for storing labels and features. The sample size is capped at 30,000, keeping model memory low [S1, unofficial].
- **Strengths:** Balances spatial coherence and intensity similarity; scalable via batching; handles large volumes by sampling [S1, unofficial].
- **Limitations:** Requires tuning `spatial_weight`; assumes spherical clusters in the weighted feature space; sensitive to outliers in intensity if not scaled properly (mitigated by StandardScaler) [S1, unofficial].
- **When to use:** When semantic segmentation of volumetric data requires both geometric locality and radiometric homogeneity, and the volume is too large for full-volume clustering.
- **When not to use:** When intensity is the only relevant factor (use intensity-only clustering) or when strict spatial boundaries are required (use axis-aligned partitioning) [S1, unofficial].

## Background
Originated from the VolumeSegmenter project by Winson-L, which implements a preprocessing pipeline for volume data segmentation [S1, unofficial]. The method is part of a broader effort to manage large volumetric datasets by partitioning them into manageable components for further processing or visualization.
