# K-Means Spatial-Intensity Partitioning

Also called: Spatial-Intensity K-Means Clustering

## Overview
K-Means Spatial-Intensity Partitioning partitions a 3D volume into a specified number of components by clustering foreground voxels based on a weighted combination of their spatial coordinates (x, y, z) and intensity values [S1, unofficial]. It sets itself apart from sibling methods like [Greedy Axis-Aligned Spatial Partitioning](11589-greedy-axis-aligned-spatial-partitioning.md) by incorporating intensity into the clustering metric, and from [Automatic Crop Box Generation via Otsu Thresholding](17117-automatic-crop-box-generation-via-otsu-thresholding.md) by producing multiple semantic partitions rather than a single binary mask. This method is used to group visually or structurally similar regions for downstream processing such as compression or rendering optimization.

## How it works
**Inputs:**
- `volume`: A 3D numpy array of voxel data.
- `components`: Integer, number of clusters to form. Default: 8.
- `spatial_weight`: Float, weight for spatial coordinates. Intensity weight is $1 - \text{spatial\_weight}$. Default: 0.5.
- `seed`: Integer, random seed for reproducibility.
- `batch_size`: Integer, number of voxels processed per prediction batch. Default: 100,000.

**Outputs:**
- `labels`: A 3D array of the same shape as `volume`, containing integer cluster labels. Background voxels (zero intensity) are assigned label 0. Foreground voxels are assigned labels $1$ to $K$.

**Data Structures:**
- `foreground`: 1D array of flat indices where `volume` is non-zero.
- `features`: 2D array of shape $(N, 4)$, where $N$ is the number of sampled voxels. Columns are $x, y, z, \text{intensity}$.
- `scaler`: A `StandardScaler` instance fitted on the sample features.

**Steps:**
1. **Identify Foreground:** Compute `foreground = np.flatnonzero(volume)`. If `foreground` is empty, return an array of zeros.
2. **Initialize Labels:** Create `labels` array of zeros with shape `volume.shape`.
3. **Sample Voxels:** Select up to 30,000 indices from `foreground` without replacement:
   $$ \text{sample} = \text{rng.choice}(\text{foreground}, \min(30000, \text{foreground.size}), \text{replace=False}) $$
4. **Extract Features:** For each index in `sample`, unravel the flat index to $(z, y, x)$ coordinates. Stack these with the corresponding intensity value from `volume` to form a feature vector $[x, y, z, \text{intensity}]$. Cast all values to `float32`.
5. **Normalize:** Fit a `StandardScaler` on the sample features. Transform the sample features using the scaler.
6. **Define Weights:** Construct a weight vector $W = [w_s, w_s, w_s, w_i]$ where $w_s = \text{spatial\_weight}$ and $w_i = 1 - \text{spatial\_weight}$.
7. **Scale Features:** Multiply the transformed sample features element-wise by $W$.
8. **Fit K-Means:** Fit a K-Means model with:
   - $n\_clusters = \min(\text{components}, \text{unique\_count})$, where `unique_count` is the number of unique values in `volume` (or a reasonable upper bound if unique count is too large).
   - $n\_init = 3$.
   - $random\_state = \text{seed}$.
   - $max\_iter = 100$.
9. **Predict Labels:** Iterate through all foreground indices in batches of `batch_size`:
   - Extract features for the batch (unravel indices, stack with intensity).
   - Transform features using the fitted `scaler`.
   - Scale features by $W$.
   - Predict cluster labels using the fitted K-Means model.
   - Assign labels to the `labels` array at the corresponding flat indices, adding 1 to the result (so background remains 0).

**Pseudocode:**
```python
import numpy as np
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

def kmeans_spatial_intensity_partitioning(volume, components=8, spatial_weight=0.5, seed=42, batch_size=100000):
    # 1. Identify Foreground
    foreground = np.flatnonzero(volume)
    if foreground.size == 0:
        return np.zeros_like(volume, dtype=np.int32)
    
    # 2. Initialize Labels
    labels = np.zeros(volume.shape, dtype=np.int32)
    
    # 3. Sample Voxels
    rng = np.random.default_rng(seed)
    n_samples = min(30000, foreground.size)
    sample_indices = rng.choice(foreground, size=n_samples, replace=False)
    
    # 4. Extract Features
    # Unravel flat indices to (z, y, x)
    coords = np.unravel_index(sample_indices, volume.shape)
    x = coords[2].astype(np.float32)
    y = coords[1].astype(np.float32)
    z = coords[0].astype(np.float32)
    intensity = volume[sample_indices].astype(np.float32)
    
    # Stack features: [x, y, z, intensity]
    features = np.stack([x, y, z, intensity], axis=-1)
    
    # 5. Normalize
    scaler = StandardScaler()
    features_scaled = scaler.fit_transform(features)
    
    # 6. Define Weights
    w_s = spatial_weight
    w_i = 1.0 - spatial_weight
    weights = np.array([w_s, w_s, w_s, w_i], dtype=np.float32)
    
    # 7. Scale Features
    features_weighted = features_scaled * weights
    
    # 8. Fit K-Means
    # Determine number of clusters
    unique_count = len(np.unique(volume))
    n_clusters = min(components, unique_count)
    
    kmeans = KMeans(n_clusters=n_clusters, n_init=3, random_state=seed, max_iter=100)
    kmeans.fit(features_weighted)
    
    # 9. Predict Labels for all foreground voxels
    n_foreground = foreground.size
    for start in range(0, n_foreground, batch_size):
        end = min(start + batch_size, n_foreground)
        batch_indices = foreground[start:end]
        
        # Extract features for batch
        batch_coords = np.unravel_index(batch_indices, volume.shape)
        bx = batch_coords[2].astype(np.float32)
        by = batch_coords[1].astype(np.float32)
        bz = batch_coords[0].astype(np.float32)
        b_intensity = volume[batch_indices].astype(np.float32)
        
        batch_features = np.stack([bx, by, bz, b_intensity], axis=-1)
        batch_scaled = scaler.transform(batch_features)
        batch_weighted = batch_scaled * weights
        
        # Predict
        batch_labels = kmeans.predict(batch_weighted)
        
        # Assign to output labels (add 1 for background)
        labels.flat[batch_indices] = batch_labels + 1
        
    return labels
```

## Subtopics

### SLIC Superpixel Segmentation with Agglomerative Clustering
A segmentation method for multivariate volumes that generates SLIC superpixels from multivariate voxels and merges them through progressive agglomerative clustering to accurately segment phases/composites [S2]. It sets itself apart from K-Means Spatial-Intensity Partitioning by using a superpixel-based approach followed by hierarchical merging, which handles global similarity considerations to label similar disconnected regions as belonging to the same phase, overcoming issues where noise or other phases might disjointed regions [S2]. It is chosen when accurate phase segmentation in multivariate data (e.g., medical or scientific datasets) is required, as demonstrated on the MIEC dataset [S2].

## Operating characteristics
- **Time Complexity:** Dominated by the K-Means fitting on the sample (up to 30,000 points) and the prediction pass over all foreground voxels. Prediction is $O(N \cdot K \cdot D)$ where $N$ is foreground voxel count, $K$ is number of clusters, and $D=4$ is feature dimension.
- **Memory Complexity:** $O(N)$ for storing labels and features. The sample size is capped at 30,000, keeping the model fitting memory low.
- **Strengths:** Balances spatial coherence and intensity similarity. The sampling step makes it feasible for very large volumes.
- **Limitations:** Relies on a sample, which may not represent the entire volume's distribution if the volume is highly heterogeneous. The choice of `spatial_weight` significantly impacts the shape of clusters.
- **When to use:** When you need to partition a volume into semantically meaningful groups that respect both geometry and content intensity.
- **When not to use:** When strict spatial locality is required without intensity consideration (use [Greedy Axis-Aligned Spatial Partitioning](11589-greedy-axis-aligned-spatial-partitioning.md)) or when only a binary foreground/background split is needed (use [Automatic Crop Box Generation via Otsu Thresholding](17117-automatic-crop-box-generation-via-otsu-thresholding.md)).

## Background
This method is described in the context of volume segmentation and preprocessing pipelines, specifically within the `VolumeSegmenter` repository [S1, unofficial]. It is designed to be a flexible preprocessing step that can adapt to different volume characteristics via the `spatial_weight` parameter.
