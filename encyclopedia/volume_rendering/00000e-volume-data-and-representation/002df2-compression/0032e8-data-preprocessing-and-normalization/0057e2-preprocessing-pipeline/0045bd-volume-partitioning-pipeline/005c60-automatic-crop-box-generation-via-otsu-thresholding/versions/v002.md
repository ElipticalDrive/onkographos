# Automatic Crop Box Generation via Otsu Thresholding

Also called: Automatic trim, Object box from coarse level, Otsu Thresholding, Otsu's Method

## Overview
This method automatically computes a tight bounding box for a 3D volume by thresholding a downsampled (coarse) level using Otsu's method, identifying connected components, and projecting the result to the target resolution [S2, unofficial]. It solves the problem of manually placing crop boxes by providing a reproducible, data-driven alternative that significantly reduces voxel count and export size [S2, unofficial]. It sets itself apart from sibling methods like [K-Means Spatial-Intensity Partitioning](11588-k-means-spatial-intensity-partitioning.md) by focusing on global intensity separation rather than spatial clustering, and from [Greedy Axis-Aligned Spatial Partitioning](11589-greedy-axis-aligned-spatial-partitioning.md) by relying on intensity-based segmentation rather than geometric splitting [G].

## How it works
**Inputs:**
- Volume data at a selected coarse level (e.g., level 2) [S2, unofficial].
- A spatial transform (e.g., ITK transform) defining the rotation/translation from the coarse level's frame to the output frame [S2, unofficial].
- Target resolution (level 0) spacing [S2, unofficial].
- Minimum piece size filter (in voxels) [S2, unofficial].
- Safety margin parameters: one rotated coarse voxel plus 10 voxels at target spacing [S2, unofficial].

**Outputs:**
- A 3D axis-aligned bounding box (min/max coordinates) in the target output frame [S2, unofficial].
- Metadata recording the window/threshold used and the transform applied [S2, unofficial].

**Data Structures:**
- `CoarseVolume`: Array of intensity values at the coarse level resolution.
- `BinaryMask`: Boolean array of same shape as `CoarseVolume`, where `True` if `value > threshold`.
- `ConnectedComponents`: Label map where each voxel is assigned an integer ID corresponding to its connected component.
- `BoundingBox`: Tuple `(min_x, min_y, min_z, max_x, max_y, max_z)` in the output frame coordinates.

**Steps:**
1. **Select Coarse Level:** Choose a downsampled level (e.g., level 2) to reduce computational cost [S2, unofficial].
2. **Compute Threshold:** Apply Otsu's method to the intensity histogram of the coarse level data to find the optimal threshold $T$ [S1, unofficial].
3. **Threshold:** Create a binary mask $M$ where $M[i] = 1$ if $CoarseVolume[i] > T$, else $0$ [S2, unofficial].
4. **Connected Components:** Identify connected components (pieces) in $M$ using 6-connectivity [S2, unofficial].
5. **Filter Small Pieces:** Discard components with voxel count below a minimum threshold to exclude noise or dust [S2, unofficial].
6. **Rotate Voxels:** For each voxel $v$ in the kept components, apply the transform to get its position $p_{out}$ in the target frame [S2, unofficial].
7. **Compute Bounds:** Find the minimum and maximum coordinates across all rotated voxels:
   $$ min_x = \min(p_{out}.x), \quad max_x = \max(p_{out}.x) $$
   $$ min_y = \min(p_{out}.y), \quad max_y = \max(p_{out}.y) $$
   $$ min_z = \min(p_{out}.z), \quad max_z = \max(p_{out}.z) $$ [S2, unofficial].
8. **Add Safety Margin:** Add one rotated coarse voxel's physical size to each side of the bounds, then add a 10-voxel pad at the target (level 0) spacing on all six sides [S2, unofficial].
   $$ final\_min = min - 10 \cdot \Delta_{target} - \Delta_{coarse} $$
   $$ final\_max = max + 10 \cdot \Delta_{target} + \Delta_{coarse} $$
   where $\Delta_{target}$ is the target spacing and $\Delta_{coarse}$ is the physical size of a coarse voxel [S2, unofficial].

**Pseudocode:**
```python
def compute_crop_box(coarse_volume, transform, target_spacing, coarse_spacing, min_piece_size):
    # Step 1: Compute Otsu threshold
    threshold = compute_otsu_threshold(coarse_volume)
    
    # Step 2: Binary mask
    binary_mask = [[coarse_volume[i][j][k] > threshold for k in range(coarse_volume.shape[2])] 
                   for j in range(coarse_volume.shape[1])] 
                   for i in range(coarse_volume.shape[0])]
                   
    # Step 3: Connected components (6-connectivity)
    labeled_mask = find_connected_components(binary_mask)
    label_counts = count_labels(labeled_mask)
    
    # Step 4: Filter small pieces
    valid_labels = {label for label, count in label_counts.items() if count >= min_piece_size}
    
    # Step 5: Rotate voxels and compute bounds
    min_coords = [float('inf'), float('inf'), float('inf')]
    max_coords = [float('-inf'), float('-inf'), float('-inf')]
    
    for i, j, k in indices_of(labeled_mask):
        if labeled_mask[i][j][k] in valid_labels:
            # Convert voxel index to physical coordinates in coarse frame
            coarse_pos = [i * coarse_spacing[0], j * coarse_spacing[1], k * coarse_spacing[2]]
            # Apply transform to get position in output frame
            output_pos = transform(coarse_pos)
            # Update bounds
            min_coords = [min(min_coords[d], output_pos[d]) for d in range(3)]
            max_coords = [max(max_coords[d], output_pos[d]) for d in range(3)]
            
    # Step 6: Add margins
    # One rotated coarse voxel's physical size
    coarse_voxel_size = [coarse_spacing[0], coarse_spacing[1], coarse_spacing[2]]
    # 10-voxel pad at target spacing
    pad_size = 10 * target_spacing
    
    final_min = [min_coords[d] - pad_size - coarse_voxel_size[d] for d in range(3)]
    final_max = [max_coords[d] + pad_size + coarse_voxel_size[d] for d in range(3)]
    
    return final_min, final_max
```

**Edge Cases:**
- **Dust/Noise:** Small pieces (dust specks) can cause the box to expand significantly if not filtered [S2, unofficial].
- **Low Thresholds:** Very low thresholds may include external holders or artifacts [S2, unofficial].
- **Loose Pieces:** Detached objects (e.g., a loose tooth) may fall outside the main box; the method should report these rather than silently dropping them [S2, unofficial].

## Subtopics

### [Chunked Otsu Thresholding](17130-chunked-otsu-thresholding.md)
A memory-efficient implementation of Otsu's method for large volumes, processing data in chunks to avoid high memory peaks. It sets itself apart by avoiding full-volume copies, making it suitable for very large datasets. Choose it when memory is constrained.

## Operating characteristics
- **Time Complexity:** Dominated by Otsu's histogram calculation and connected components on the coarse level [G].
- **Memory Complexity:** Proportional to the coarse level size [G].
- **Performance:** On a dry skull at level 2 (24.5 µm, ~90 MB), the process took 12 seconds [S2, unofficial].
- **Voxel Reduction:** The automatic box had 43% fewer voxels than a hand-placed box (11.4 G vs 20.0 G) [S2, unofficial].
- **Strengths:** Reproducible, reduces data size, excludes external artifacts if threshold is correct [S2, unofficial].
- **Limitations:** Sensitive to threshold choice; may include holders if threshold is too low; requires piece filtering to avoid noise [S2, unofficial].
- **When to Use:** When a tight, data-driven crop is needed without manual intervention [G].
- **When Not to Use:** When the object has low contrast or is mixed with similar-intensity artifacts [G].

## Background
This method is part of a preprocessing pipeline for volume data, specifically for exporting large volumes efficiently [S2, unofficial]. It was developed as an alternative to hand-placed boxes to automate the cropping process [S2, unofficial].
