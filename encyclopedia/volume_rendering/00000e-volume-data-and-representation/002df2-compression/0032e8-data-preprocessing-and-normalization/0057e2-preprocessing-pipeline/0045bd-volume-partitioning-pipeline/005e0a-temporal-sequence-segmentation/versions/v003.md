# Temporal Sequence Segmentation
Also called: Greedy Temporal Segmentation, Sequence Segmentation, Time-step Clustering

## Overview
Temporal Sequence Segmentation splits a volumetric time sequence into multiple short segments of varying length to facilitate robust clustering and reduce the computational load of subsequent processing steps [S1]. Unlike video shot detection which identifies distinct boundaries, this method groups neighboring time steps based on high similarity and temporal continuity without seeking global distinct boundaries [S1]. It serves as a preprocessing step in the Volume Partitioning Pipeline, preparing data for clustering by reducing the number of units to process [S1].

## How it works
**Inputs:** A volumetric time sequence $S$ consisting of $T$ time steps [S1]. Each time step $t$ contains a 3D grid of data values $s_t(u)$, where $u$ is a 3D grid position [S1].
**Outputs:** A set of segments $S_0 \subseteq S$, where each segment contains one or more contiguous time steps [S1]. For each segment, a representative time step $r(S_0)$ is identified [S1].
**Parameters:**
- Maximum segment count ($N_{max}$): Determines the target number of segments [S1]. Set according to available computational resources [S1].
- Cost threshold: The minimum cost at which merging stops [S1]. Typically set to the average dissimilarity of the sequence [S1].

**Data Structures:**
- Dissimilarity array $D$: An array of size $T-1$, where $D[t]$ stores the dissimilarity $d_S(t)$ between time step $t$ and $t+1$ [S1].
- Segment list: A list of segments, initially containing $T$ single-time-step segments [S1]. Each segment tracks its constituent time step indices and its current cost value [S1].

**Steps:**
1. **Compute Dissimilarity:** Calculate the dissimilarity $d_S(t)$ for all $t \in [1, T-1]$ using the sum of squared intensity differences between adjacent time steps [S1]:
   $$ d_S(t) = \sum_u (s_{t+1}(u) - s_t(u))^2 $$
   where $u$ iterates over all 3D grid positions [S1].

2. **Initialize Segments:** Initialize each time step as its own segment with a cost value of zero [S1].

3. **Iterative Merging:** While the number of segments is greater than $N_{max}$:
   a. Identify the pair of neighboring segments with the minimal combined cost [S1]. The cost of merging two neighboring segments is defined as the sum of the dissimilarity at their boundary and their individual costs [S1].
   b. Merge these two segments [S1].
   c. Update the cost of the resulting merged segment to this sum [S1].

4. **Threshold Check:** After the number of segments reaches $N_{max}$, terminate the merging process when the minimum cost of any potential merge exceeds the cost threshold [S1].

5. **Select Representatives:** For each resulting segment $S_0$, determine the representative time step $r(S_0)$ [S1]:
   $$ r(S_0) = \arg \min_{s_i \in S_0} \left| \sum_{s_j \in S_0, j<i} d_S(j) - \sum_{s_j \in S_0, j>i} d_S(j-1) \right| $$
   This minimizes the absolute difference between the cumulative dissimilarity of predecessors and successors within the segment [S1].
   - **Edge Case:** For segments with only two members, the lower time step is chosen as the representative [S1].

**Pseudocode:**
```python
def temporal_sequence_segmentation(time_steps, max_segments, cost_threshold):
    """
    time_steps: List of 3D arrays/lists, where time_steps[t] is the volume at time t.
    max_segments: Integer, maximum number of segments to produce.
    cost_threshold: Float, average dissimilarity of the sequence.
    Returns: List of segments, where each segment is a list of time step indices.
    """
    T = len(time_steps)
    if T == 0:
        return []

    # Step 1: Compute dissimilarity
    # d_S(t) is dissimilarity between time step t and t+1
    # Pseudocode uses 0-based indexing: dissimilarities[t] corresponds to boundary between t and t+1
    dissimilarities = []
    for t in range(T - 1):
        diff_sq_sum = sum((a - b) ** 2 for a, b in zip(time_steps[t+1].flat, time_steps[t].flat))
        dissimilarities.append(diff_sq_sum)

    # Step 2: Initialize segments
    # Each segment is a tuple: (list_of_time_step_indices, current_cost)
    segments = [([t], 0) for t in range(T)]

    # Helper to compute merge cost and new segment state
    def compute_merge(seg1, seg2):
        last_t = seg1[0][-1]
        boundary_dissim = dissimilarities[last_t]
        new_cost = boundary_dissim + seg1[1] + seg2[1]
        new_indices = seg1[0] + seg2[0]
        return new_cost, new_indices

    # Step 3 & 4: Iterative merging
    while len(segments) > max_segments:
        min_cost = float('inf')
        merge_idx = -1

        # Find pair of neighboring segments with minimal combined cost
        for i in range(len(segments) - 1):
            cost, _ = compute_merge(segments[i], segments[i+1])
            if cost < min_cost:
                min_cost = cost
                merge_idx = i

        # If min cost exceeds threshold, stop
        if min_cost > cost_threshold:
            break

        # Merge segments at merge_idx and merge_idx+1
        seg1 = segments[merge_idx]
        seg2 = segments[merge_idx+1]
        new_cost, new_indices = compute_merge(seg1, seg2)
        segments[merge_idx] = (new_indices, new_cost)
        segments.pop(merge_idx + 1)

    return [seg[0] for seg in segments]

def get_representative(segment_indices, dissimilarities):
    """
    segment_indices: List of time step indices in the segment.
    dissimilarities: List of d_S(t) values.
    Returns: The index of the representative time step.
    """
    if len(segment_indices) == 2:
        # Edge case: lower time step is chosen
        return segment_indices[0]
    
    best_idx = segment_indices[0]
    min_diff = float('inf')
    
    for i in segment_indices:
        # Sum of dissimilarities of predecessors within segment
        pred_sum = sum(dissimilarities[j] for j in segment_indices if j < i)
        
        # Sum of dissimilarities of successors within segment
        succ_sum = sum(dissimilarities[j-1] for j in segment_indices if j > i)
        
        diff = abs(pred_sum - succ_sum)
        if diff < min_diff:
            min_diff = diff
            best_idx = i
            
    return best_idx
```

## Background
This method draws inspiration from video processing methods for generating overviews by dividing input into shots, but adapts the approach for simulation sequences which do not exhibit distinct boundaries [S1]. It is part of a pipeline that includes spatial partitioning and clustering to facilitate robust analysis of large volumetric datasets [S1].
