# Raw Image Preprocessing Pipeline

Also called: DNG processing, RawNeRF preprocessing

## Overview
This pipeline converts raw camera sensor data (typically DNG format) into normalized, color-corrected images suitable for training neural radiance fields (NeRF) or 3D Gaussian Splatting. It solves the problem of inconsistent exposure, color balance, and sensor noise in raw inputs by applying a standardized sequence of demosaicking, white balancing, and tonemapping. It differs from sibling pipelines by focusing on the low-level sensor signal conversion rather than high-level segmentation, partitioning, or video-specific extraction.

## How it works
**Inputs:** Raw image data (CFA pattern), EXIF metadata (WhiteLevel, BlackLevel, AsShotNeutral, ColorMatrix2, ShutterSpeed).
**Outputs:** Normalized RGB image tensor with values in $[0, 1]$.

**Data Structures:**
- `z`: Input raw pixel values (integer or float).
- `w`: WhiteLevel (EXIF field).
- `b`: BlackLevel (EXIF field).
- `gwb`: AsShotNeutral vector (3 elements).
- `C_ccm`: ColorMatrix2 (3x3 matrix).
- `p`: Percentile for exposure adjustment (default 97).

**Steps:**

1.  **Normalization to Sensor Range:**
    Subtract black level and normalize by white level.
    $$ z \leftarrow \frac{z - b}{w - b} $$
    This preserves values below zero if the sensor allows negative raw values relative to black [S1].

2.  **Demosaicking:**
    Apply bilinear demosaicking to convert the CFA pattern to full RGB. This step is applied "when necessary," implying it may be skipped if the input is already full RGB or if a different demosaicking method is preferred for specific sensors [S1].

3.  **White Balance:**
    Apply elementwise gains from the `AsShotNeutral` vector.
    $$ z \leftarrow \frac{z}{gwb} $$
    Here, division is elementwise across the R, G, B channels [S1].

4.  **Color Correction:**
    Apply the combined color correction matrix (Camera RGB to canonical XYZ, then XYZ to sRGB) defined in `ColorMatrix2`.
    $$ z \leftarrow C_{ccm} \cdot z $$
    The matrix $C_{ccm}$ is an XYZ-to-camera-RGB transform under the D65 illuminant [S1].

5.  **Exposure Adjustment:**
    Adjust exposure so that the $p$-th percentile of the image brightness equals 1. This effectively scales the image to utilize the dynamic range.
    $$ z \leftarrow \frac{z}{\text{percentile}(z, p)} $$
    Default $p = 97$ [S1].

6.  **Clipping:**
    Clip values to the valid range.
    $$ z \leftarrow \text{clip}(z, 0, 1) $$
    This ensures no values exceed the displayable range after tonemapping [S1].

7.  **Tonemapping (sRGB Gamma):**
    Apply the sRGB gamma curve to each color channel.
    $$ z \leftarrow \gamma_{sRGB}(z) $$
    This maps the linear light values to the non-linear sRGB space [S1].

**Pseudocode:**

```python
def preprocess_raw_image(raw_z, exif_metadata):
    # Extract EXIF values
    w = exif_metadata['WhiteLevel']
    b = exif_metadata['BlackLevel']
    gwb = exif_metadata['AsShotNeutral'] # Vector [gr, gg, gb]
    C_ccm = exif_metadata['ColorMatrix2'] # 3x3 Matrix
    p = 97 # Default percentile

    # Step 1: Normalize to sensor range
    # Handle potential division by zero if w == b, though unlikely in valid DNG
    if w == b:
        z = raw_z - b
    else:
        z = (raw_z - b) / (w - b)

    # Step 2: Demosaicking (if input is CFA)
    # Assuming raw_z is CFA; if already RGB, skip or pass through
    z = bilinear_demosaick(z)

    # Step 3: White Balance
    # Elementwise division
    z = z / gwb

    # Step 4: Color Correction
    # Matrix multiplication for each pixel
    # z shape: (H, W, 3)
    z = np.einsum('ij,hwj->hwi', C_ccm, z)

    # Step 5: Exposure Adjustment
    # Calculate percentile of brightness (e.g., mean of RGB channels)
    brightness = np.mean(z, axis=-1)
    threshold = np.percentile(brightness, p)
    if threshold > 0:
        z = z / threshold
    else:
        z = z # Avoid division by zero

    # Step 6: Clip
    z = np.clip(z, 0.0, 1.0)

    # Step 7: sRGB Gamma
    z = apply_srgb_gamma(z)

    return z
```

**Edge Cases:**
- If `WhiteLevel` equals `BlackLevel`, normalization fails; guard against division by zero [S1].
- If the percentile threshold is 0, exposure scaling is skipped [S1].
- Demosaicking is conditional; skipping it requires the input to be full RGB [S1].

## Subtopics

### Aria Synthetic Environments Preprocessing
This variant prepares fisheye images and depths for 3D Gaussian Splatting (3DGS) optimization in the Aria Synthetic Environments dataset. It differs from the standard pipeline by handling fisheye distortion and multi-sensor depth fusion. Steps include: undistorting fisheye images and depth frames, applying a devignetting mask for brightness correction, and fusing sensor depths to generate point clouds for 3DGS initialization [S2].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of pixels $N$ for most steps (normalization, white balance, clipping). Demosaicking and matrix multiplication are also $O(N)$. Percentile calculation is $O(N \log N)$ or $O(N)$ with selection algorithms.
- **Memory Complexity:** $O(N)$ to store the intermediate image tensors.
- **Strengths:** Standardizes raw inputs for neural rendering, handling high dynamic range and color inaccuracies.
- **Limitations:** Relies on accurate EXIF metadata; incorrect `ColorMatrix2` or `AsShotNeutral` leads to color errors. Demosaicking introduces artifacts if the CFA pattern is non-standard.
- **When to use:** When training NeRF or 3DGS from raw DNG images.
- **When not to use:** For already processed JPEG/EXR images, or when using synthetic data with known perfect lighting.

## Background
Originated in the "NeRF in the Dark" paper by Gharbi et al. (CVPR 2022), this pipeline was designed to enable high dynamic range view synthesis from noisy raw images. It builds on standard DNG processing specifications (Adobe DNG 1.4.0.0) and integrates exposure control tailored for neural rendering training stability [S1].
