# Target-Driven Smoke Animation
Also called: Driving force smoke, Gathering force smoke

## Overview
Target-Driven Smoke Animation is a method for generating complex smoke formations by using target smoke states to attract particles via a driving force and a gathering force to prevent dissipation [S1, unofficial]. Unlike Key-Frame Animation with In-Betweening, which interpolates between discrete states, this method operates on an instant-by-instant basis, allowing smoke to be herded into a formation without requiring an exact match at a specific time [S1, unofficial]. It is distinguished by its use of a "gathering force" that diffuses density error only near the target vicinity, solving the problem of insufficient initial density or excessive diffusion [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Current smoke state (density field $\rho$, velocity field $\mathbf{u}$), target smoke state (target density field $\rho_{target}$), and control parameters (smoothing, simulation speed, smoke speed, wispy-ness).
*   **Output:** Updated smoke state for the next time step.

**Data Structures:**
*   **Density Field:** A grid storing scalar density values $\rho$.
*   **Velocity Field:** A grid storing vector velocity values $\mathbf{u}$.
*   **Target Density Field:** A grid storing scalar target density values $\rho_{target}$.

**Parameters:**
*   **Driving Force Smoothing:** Controls the organization of smoke formation [S1, unofficial].
*   **Simulation Speed:** Controls the overall pace of the animation [S1, unofficial].
*   **Smoke Speed:** Controls the particle advection rate [S1, unofficial].
*   **Wispy-ness:** Adjusts the final formation texture [S1, unofficial].

**Steps:**
1.  **Define Target States:** Set the desired target density field $\rho_{target}$ for the current frame or sequence [S1, unofficial].
2.  **Calculate Driving Force:** Compute a driving force that advects smoke toward the target. The force magnitude should decrease as the smoke approaches the target state to allow it to come to rest [S1, unofficial].
3.  **Blur Target Values:** Briefly blur the target density values $\rho_{target}$ to facilitate the smoke coming to rest at the target [S1, unofficial].
4.  **Calculate Density Error:** Compute the density error $E$ as the difference between the initial (current) density and the target density:
    $$ E = \rho_{target} - \rho $$
    [S1, unofficial]
5.  **Apply Gathering Force:** Diffuse the density error $E$ using a gathering force. This diffusion is applied **only** in areas where smoke is already at or near the target vicinity. This prevents early-stage diffusion and ensures convergence [S1, unofficial].
6.  **Multiple Field Flow (Optional):** Split smoke into separate fields with independent paths toward the target while keeping the overall velocity field unaffected. This allows for more complex, wispy formations [S1, unofficial].
7.  **Advect and Update:** Advect the smoke density and velocity fields using the computed forces and simulation speed [S1, unofficial].

*   **Strengths:** Allows for complex, realistic smoke formations; flexible as it does not require exact timing matches; gathering force prevents dissipation [S1, unofficial].
*   **Limitations:** Lacks direct quality control; requires tweaking parameters rather than intuitive hands-on approach; results may not be physically true [S1, unofficial].
*   **When to Use:** When creating complex, artistic smoke animations where exact keyframe matching is not required [S1, unofficial].
*   **When Not to Use:** When precise, physically accurate simulation is required or when direct, intuitive control over the animation is needed [S1, unofficial].

## Background
The method was introduced by Fattal and Lischinski [3] as a major step in creating realistic and complex smoke animations [S1, unofficial]. It differs from optimal approximation of keyframes by using target states to attract smoke particles [S1, unofficial]. It allows animators to control smoke fields sharing the same fluid [S1, unofficial]. The method is part of a broader effort to tame liquids and smoke for rapidly changing targets, as seen in related work by Lin Shi and Yizhou Yu [20] [S1, unofficial].
