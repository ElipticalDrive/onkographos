# Dataset Preprocessing (DeepLesion)
Also called: HU Normalization and Cropping

## Overview
This method prepares tomographic images from the DeepLesion dataset for training generative models by converting raw pixel intensities to Hounsfield Units (HU), segmenting the body from background air, and normalizing spatial dimensions [S1, unofficial]. It differs from general volume normalization by applying a specific, fixed thresholding and cropping pipeline tailored to the wide dynamic range of CT data, rather than statistical normalization of the entire volume [S1, unofficial]. It builds on [Data Preprocessing and Normalization](6880-data-preprocessing-and-normalization.md).

## How it works
**Inputs:** Raw tomographic image data stored with 16-bit precision. The raw pixel intensity $I_{raw}$ is assumed to be in a format where the offset 32768 corresponds to 0 HU.
**Outputs:** A normalized 3D volume (or 2D slice) of size $256 \times 256$ (or discarded) with HU values.

**Data Structures:**
- Input: 16-bit integer array or float array representing raw scanner values.
- Intermediate: Binary mask array of same spatial dimensions as input.
- Output: Float array of shape $(256, 256)$ or $(Z, 256, 256)$ depending on whether the crop is applied per-slice or per-volume. **Steps:**
1.  **HU Conversion**: Convert raw pixel intensities to Hounsfield Units.
    $$ HU = I_{raw} - 32768 $$
    Where $I_{raw}$ is the raw pixel value. This maps air to -1000 HU and water to 0 HU [S1, unofficial].
2.  **Thresholding**: Create a binary mask $M$ where pixels with $HU > -9050$ are set to 1 (foreground), and others to 0 (background). The threshold -9050 HU is chosen to be slightly higher than the density of air (-1000 HU) to exclude air but include soft tissue and bone [S1, unofficial].
3.  **Cropping**: Find the smallest circle that contains all pixels where $M=1$. Define the bounding square of this circle. Crop the original HU image to this square region.
4.  **Validation and Resizing**: Check the dimensions of the cropped region. If the width and height are both less than 256 pixels, discard the image. Otherwise, rescale the cropped region to exactly $256 \times 256$ pixels using interpolation (e.g., linear or nearest-neighbor) and add it to the dataset [S1, unofficial].

**Pseudocode:**
```python
def preprocess_deeplesion(raw_image_16bit):
    # raw_image_16bit: numpy array of shape (H, W) or (Z, H, W)
    # Assuming 2D slice processing for the "circle" logic, 
    # or 3D if the source implies a 3D bounding box (but circle is 2D).
    # We assume 2D slice-by-slice or the image is 2D.
    
    # 1. HU Conversion
    hu_image = raw_image_16bit.astype(float) - 32768.0
    
    # 2. Thresholding
    # Threshold is -9050 HU. Pixels > -9050 are foreground.
    binary_mask = (hu_image > -9050.0).astype(float)
    
    # 3. Find smallest circle containing all binary pixels
    # Get coordinates of foreground pixels
    coords = np.argwhere(binary_mask > 0)
    if len(coords) == 0:
        return None # No body found, discard
        
    # Calculate bounding box of the foreground
    y_min, x_min = coords.min(axis=0)
    y_max, x_max = coords.max(axis=0)
    
    # Calculate center and radius of the smallest enclosing circle for the bounding box
    # The smallest circle containing a rectangle is defined by the diagonal
    center_y = (y_min + y_max) / 2.0
    center_x = (x_min + x_max) / 2.0
    radius = np.sqrt(((y_max - y_min)/2)**2 + ((x_max - x_min)/2)**2)
    
    # Define square region from the circle
    # The square must contain the circle, so side length = 2 * radius
    # However, we need integer indices.
    # We crop the square region corresponding to the bounding box of the circle
    # The circle extends radius from center.
    # Square bounds:
    y_start = int(center_y - radius)
    y_end = int(center_y + radius)
    x_start = int(center_x - radius)
    x_end = int(center_x + radius)
    
    # Clip to image boundaries
    y_start = max(0, y_start)
    y_end = min(hu_image.shape[0], y_end)
    x_start = max(0, x_start)
    x_end = min(hu_image.shape[1], x_end)
    
    cropped_hu = hu_image[y_start:y_end, x_start:x_end]
    
    # 4. Validation and Resizing
    h, w = cropped_hu.shape
    if h < 256 or w < 256:
        return None # Discard if smaller than 256x256
        
    # Rescale to 256x256
    # Using linear interpolation for HU values
    resized_hu = cv2.resize(cropped_hu, (256, 256), interpolation=cv2.INTER_LINEAR)
    
    return resized_hu
```
*Note: The pseudocode assumes 2D processing. If the input is 3D, this function should be applied to each slice, or the "circle" logic must be adapted to 3D (e.g., smallest sphere). The source text "Find the smallest circle" strongly implies 2D. If applied to 3D volumes, the "circle" might refer to the in-plane footprint. We assume per-slice application or that the "image" refers to a 2D slice.*

**Parameters:**
- Offset: 32768 [S1, unofficial].
- Threshold: -9050 HU [S1, unofficial].
- Minimum Crop Size: 256x256 pixels [S1, unofficial].
- Target Size: 256x256 pixels [S1, unofficial].

**Edge Cases:**
- If no pixels exceed the threshold, the mask is empty, and the image is discarded.
- If the cropped region is smaller than 256x256, it is discarded.
- Precision: The subtraction of 32768 should be done in floating point to avoid overflow/underflow if raw values are near the limits of 16-bit integers.

## Subtopics

### Vannier Pre-processing for CT
A pre-processing method for craniofacial surgical planning using CT scans [S2, unofficial]. It involves dividing individual slices into separate files, filtering them through a threshold value, and saving the processed data in the same CT format for reading by imaging technology [S2, unofficial]. It is used to produce life-size displays for surgeons via an interactive CAD system [S2, unofficial]. Unlike the DeepLesion method, it focuses on file-level processing for surgical planning rather than dataset normalization for training [S2, unofficial].

## Operating characteristics
- **Time Complexity**: Linear with respect to the number of pixels $N$ for thresholding and cropping. Resizing is $O(N)$ or $O(N \log N)$ depending on interpolation.
- **Memory Complexity**: Requires storage for the original image, the binary mask, and the cropped image.
- **Strengths**: Removes background air, standardizes the field of view, and ensures consistent input size for neural networks.
- **Limitations**: Discards small or poorly centered regions. The fixed threshold of -9050 HU may not be optimal for all scanner types or pathologies.
- **When to use**: When training generative models on the DeepLesion dataset.
- **When not to use**: When preserving the full field of view is critical, or when the dataset does not contain significant background air.

## Background
The method was introduced in the context of "Generative Tomography Reconstruction" using the DeepLesion dataset [S1, unofficial]. DeepLesion is a large dataset of annotated tomographic images stored with 16-bit precision [S1, unofficial]. The preprocessing steps were designed to prepare these images for training a generative model that optimizes over a free parameter on a sphere [S1, unofficial]. The threshold of -9050 HU was chosen to be slightly higher than the density of air (-1000 HU) [S1, unofficial].
