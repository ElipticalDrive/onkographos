# Dataset Preprocessing (DeepLesion)
Also called: HU Normalization and Cropping

## Overview
This method prepares tomographic images from the DeepLesion dataset for training generative models by converting raw pixel intensities to Hounsfield Units (HU), segmenting the body from background air, and normalizing spatial dimensions [S1, unofficial]. It differs from general volume normalization by applying a specific, fixed thresholding and cropping pipeline tailored to the wide dynamic range of CT data, rather than statistical normalization of the entire volume [S1, unofficial].

## How it works
**Inputs:** Raw tomographic image data stored with 16-bit precision [S1, unofficial].
**Outputs:** A normalized 2D image of size $256 \times 256$ with HU values, or the image is discarded [S1, unofficial].
**Data Structures:** Input is a 2D array of 16-bit integers representing a single slice [S1, unofficial]. An intermediate binary mask of identical spatial dimensions is generated [S1, unofficial]. The output is a 2D float array of shape $(256, 256)$ [S1, unofficial]. The source specifies a "circle" and "square region", indicating the operation is applied to 2D slices rather than 3D volumes [S1, unofficial].

**Steps:**
1. **HU Conversion:** Convert raw pixel intensities to Hounsfield Units using $HU = I_{\text{raw}} - 32768$ [S1, unofficial].
2. **Thresholding:** Create a binary mask $M$ where pixels with $HU > -9050$ are set to 1 (foreground), and others to 0 (background) [S1, unofficial].
3. **Cropping:** Find the smallest circle containing all pixels where $M=1$ [S1, unofficial]. Crop the original HU image to the square region that bounds this circle [S1, unofficial].
4. **Validation and Resizing:** If the cropped region is smaller than $256 \times 256$, discard it [S1, unofficial]. Otherwise, rescale the cropped region to exactly $256 \times 256$ pixels and add it to the dataset [S1, unofficial].

**Pseudocode:**
```python
def preprocess_deeplesion(raw_image):
    # raw_image: 2D list or array of 16-bit integers
    # 1. HU Conversion
    hu_image = [[float(p) - 32768.0 for p in row] for row in raw_image]
    h, w = len(hu_image), len(hu_image[0])

    # 2. Thresholding
    # Threshold is -9050 HU. Pixels > -9050 are foreground.
    mask = [[1 if hu_image[r][c] > -9050.0 else 0 for c in range(w)] for r in range(h)]

    # 3. Find smallest circle containing all binary pixels
    # Collect coordinates of foreground pixels
    coords = [(r, c) for r in range(h) for c in range(w) if mask[r][c] == 1]
    if not coords:
        return None  # No body found, discard

    # The bounding box of the foreground pixels defines the square region
    # that bounds the smallest enclosing circle [G].
    r_min = min(r for r, c in coords)
    r_max = max(r for r, c in coords)
    c_min = min(c for r, c in coords)
    c_max = max(c for r, c in coords)

    # Crop to the bounding box
    cropped_hu = [row[c_min:c_max+1] for row in hu_image[r_min:r_max+1]]
    crop_h, crop_w = len(cropped_hu), len(cropped_hu[0]) if cropped_hu else 0

    # 4. Validation and Resizing
    if crop_h < 256 or crop_w < 256:
        return None  # Discard if smaller than 256x256

    # Rescale to 256x256 using bilinear interpolation [G]
    resized_hu = resize_bilinear(cropped_hu, 256, 256)
    return resized_hu

def resize_bilinear(src, target_h, target_w):
    src_h, src_w = len(src), len(src[0])
    dst = [[0.0] * target_w for _ in range(target_h)]
    for y in range(target_h):
        for x in range(target_w):
            src_y = y * (src_h - 1) / (target_h - 1)
            src_x = x * (src_w - 1) / (target_w - 1)
            y0, x0 = int(src_y), int(src_x)
            y1, x1 = min(y0 + 1, src_h - 1), min(x0 + 1, src_w - 1)
            dy, dx = src_y - y0, src_x - x0
            val = (1 - dy) * (1 - dx) * src[y0][x0] + \
                  (1 - dy) * dx * src[y0][x1] + \
                  dy * (1 - dx) * src[y1][x0] + \
                  dy * dx * src[y1][x1]
            dst[y][x] = val
    return dst
```

**Parameters:**
- Offset: 32768 [S1, unofficial].
- Threshold: -9050 HU [S1, unofficial].
- Minimum Crop Size: 256x256 pixels [S1, unofficial].
- Target Size: 256x256 pixels [S1, unofficial].

**Edge Cases:**
- If no pixels exceed the threshold, the mask is empty and the image is discarded [S1, unofficial].
- If the cropped region is smaller than 256x256, it is discarded [S1, unofficial].
- Precision: The subtraction of 32768 should be performed in floating point to avoid overflow or underflow if raw values approach 16-bit integer limits [G].

### Vannier Pre-processing for CT
A pre-processing method for craniofacial surgical planning using CT scans [S2, unofficial]. It involves dividing individual slices into separate files, filtering them through a threshold value, and saving the processed data in the same CT format for reading by imaging technology [S2, unofficial]. It is used to produce life-size displays for surgeons via an interactive CAD system [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of pixels $N$ for thresholding and cropping [G]. Resizing is $O(N)$ for bilinear interpolation [G].
- **Memory Complexity:** Requires storage for the original image, the binary mask, and the cropped image [G].
- **Strengths:** Removes background air, standardizes the field of view, and ensures consistent input size for neural networks [G].
- **Limitations:** Discards small or poorly centered regions [S1, unofficial]. The fixed threshold of -9050 HU may not be optimal for all scanner types or pathologies [G].
- **When to use:** When training generative models on the DeepLesion dataset [S1, unofficial].
- **When not to use:** When preserving the full field of view is critical, or when the dataset does not contain significant background air [G].

## Background
The method was introduced in the context of "Generative Tomography Reconstruction" using the DeepLesion dataset [S1, unofficial]. DeepLesion is a large dataset of annotated tomographic images stored with 16-bit precision [S1, unofficial]. The preprocessing steps were designed to prepare these images for training a generative model that optimizes over a free parameter on a sphere [S1, unofficial]. The threshold of -9050 HU was chosen to be slightly higher than the density of air (-1000 HU) [S1, unofficial].
