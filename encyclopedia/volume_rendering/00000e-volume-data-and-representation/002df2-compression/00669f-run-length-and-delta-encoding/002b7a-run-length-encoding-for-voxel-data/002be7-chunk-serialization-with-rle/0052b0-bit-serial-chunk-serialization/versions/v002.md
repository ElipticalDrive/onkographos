# Bit-serial Chunk Serialization

Also called: Bit-serial chunk transfer, VTC Format, Voxel Chunk Serialization

## Overview
Bit-serial Chunk Serialization is a binary serialization method for voxel data chunks, designed for network transmission or persistent storage [S2, unofficial]. It extends the parent [Chunk Serialization with RLE](5162-chunk-serialization-with-rle.md) by employing bit-level serialization to encode voxel data, allowing for variable-length encoding of chunk identifiers and efficient bit-packing of the underlying voxel states [S2, unofficial].

## How it works
**Inputs and Outputs:**
The method takes a collection of voxel chunks, each defined by a 3D position $(x, y, z)$ and a root identifier [S1, unofficial]. The output is a 4D byte array `bytes[x][y][z][bit_data]` containing the serialized binary representation of the chunks [S2, unofficial].

**Data Structures:**
1.  **VTC Header:** A fixed-size header containing a magic number (`VTC_MAGIC`) identifying the file format [S1, unofficial].
2.  **Chunk Entry:** For each chunk, the serialized data includes the 3D position as Big-Endian $i32$ values, a mapped root ID encoded as a variable-length integer (VarInt), and the voxel data serialized bit-by-bit [S1, unofficial][S2, unofficial].
3.  **Output Layout:** The total output is structured as a 4D byte array where the first three dimensions correspond to chunk coordinates and the fourth holds the serialized bit data for that specific chunk [S2, unofficial].

**Parameters:**
*   `VTC_MAGIC`: A constant byte array identifying the file format [S1, unofficial].
*   `id_map`: A hash map mapping old root IDs to new IDs [S1, unofficial].

**Steps:**
1.  Initialize the output 4D byte array structure `bytes[chunks.length][chunks[0].length][chunks[0][0].length][]` [S2, unofficial].
2.  Write the `VTC_MAGIC` bytes to the beginning of the stream [S1, unofficial].
3.  Iterate through each chunk in the world data structure [S2, unofficial].
4.  For each chunk at position $(x, y, z)$, write the position components $x, y, z$ as Big-Endian $i32$ values [S1, unofficial].
5.  Retrieve the chunk's current root ID and map it to a new ID using `id_map` [S1, unofficial].
6.  Encode the new ID as a variable-length integer (VarInt) and write it to the stream [S1, unofficial].
7.  Serialize the voxel data of the chunk using bit-serial writing by writing each voxel bit individually to a bit stream [S2, unofficial].
8.  Close the stream and return the resulting byte array for the chunk [S2, unofficial].

**Pseudocode:**
```python
def serialize_chunks(chunks, id_map, vtc_magic):
    # Initialize 4D byte array structure as specified
    bytes_4d = [[[] for _ in range(len(chunks[0][0]))] for _ in range(len(chunks[0]))]
    output = bytearray(vtc_magic)
    
    for x in range(len(chunks)):
        for y in range(len(chunks[0])):
            for z in range(len(chunks[0][0])):
                chunk = chunks[x][y][z]
                # Write position as Big-Endian i32
                output.extend(chunk.x.to_bytes(4, byteorder='big', signed=True))
                output.extend(chunk.y.to_bytes(4, byteorder='big', signed=True))
                output.extend(chunk.z.to_bytes(4, byteorder='big', signed=True))
                # Map root ID and encode as VarInt
                new_id = id_map[chunk.root_id]
                output.extend(varint_encode(new_id))
                # Serialize voxel data bit-by-bit
                chunk_bits = serialize_chunk_bits(chunk)
                bytes_4d[x][y][z] = chunk_bits
                output.extend(chunk_bits)
    return bytes(output)

def varint_encode(value):
    result = bytearray()
    while True:
        byte = value & 0x7F
        value >>= 7
        if value != 0:
            byte |= 0x80
        result.append(byte)
        if value == 0:
            break
    return bytes(result)

def serialize_chunk_bits(chunk):
    # Pack voxel states into bits [G]
    bits = bytearray()
    for voxel in chunk.voxels:
        bits.append(1 if voxel else 0)
    packed = bytearray((len(bits) + 7) // 8)
    for i, bit in enumerate(bits):
        packed[i // 8] |= (bit << (i % 8))
    return bytes(packed)
```

**Edge Cases and Pitfalls:**
*   **ID Mapping:** If `id_map` is incomplete, serialization fails because the map must contain all active root IDs [S1, unofficial].
*   **Bit Alignment:** The bit-serial nature requires careful handling of byte boundaries during packing [S2, unofficial].
*   **Endianness:** Position data is explicitly Big-Endian; mismatched endianness during deserialization will corrupt coordinates [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot B)$, where $N$ is the number of chunks and $B$ is the number of bits per chunk [S2, unofficial].
*   **Memory Complexity:** $O(S)$, where $S$ is the size of the serialized byte array [S2, unofficial].
*   **Strengths:** Compact representation for sparse or low-ID ranges due to VarInt encoding; flexible bit-level packing for voxel data [S2, unofficial].
*   **Limitations:** Requires pre-computation of `id_map`; bit-serial writing can be slower than byte-serial if not optimized [S2, unofficial].
