# Feature-Preserving Volume Data Reduction and Focus+Context Visualization

Also called: Feature-Directed Voxel Repositioning, Grid Space Deformation, Voxel Reposition

## Overview
This method reduces volumetric data size while preserving features of interest and enabling focus+context visualization by deforming the 3D grid space to magnify important regions and compress unimportant ones, followed by resampling [S1]. Unlike uniform downsampling which discards information oblivious to data content, or multiresolution methods that require extra data packing or blending to handle cross-resolution boundaries, this method uses continuous deformation to intelligently allocate more samples to important features and sparsely sample unimportant regions, guaranteeing similar resolutions along neighboring grid boundaries and avoiding seams [S1].

## How it works
**Inputs:** Volumetric data set $V_{data}$, user-specified color and opacity transfer functions, scaling factor $s$ (typically $s > 1.0$).
**Outputs:** A reduced data set (downsampled voxels) and a deformed grid $G'$ used for shape recovery at runtime.

**Data Structures:**
The volume is partitioned into a uniform grid $G = \{V, E, C\}$:
*   $V = \{v_1, v_2, ..., v_n\}$: Set of vertex positions.
*   $E$: Set of edges connecting vertices.
*   $C$: Set of space cubes (voxels).

**Preprocessing:**
1.  **Denoising:** If the input data contains noise, apply a denoising method such as bilateral filtering before computing cube importance to prevent high color contrasts from artificially inflating importance values [S1].
2.  **Importance Assignment:** Analyze the content of each local region (cube). Assign an importance value $w_c$ to each cube $c \in C$ based on the averaged interior voxel importance values, normalized to $[0, 1]$. The importance is determined by the color gradients of interior voxels, which depends on the user-defined transfer function [S1].

**Deformation Process:**
The goal is to find deformed vertex positions $V' = \{v'_1, ..., v'_n\}$ that minimize distortion while satisfying constraints.

1.  **Define Energy Terms:**
    *   **Edge-based Feature Energy:** Preserves the shape of individual cubes. For a cube $c$, let $E_c$ be its edges. Let $e_{ij} = v_i - v_j$ be the original edge and $e'_{ij} = v'_i - v'_j$ be the deformed edge. Let $s'_c$ be the scaling factor and $R'_c$ be the rotation matrix for cube $c$.
        $$D_f(c) = \sum_{\{i,j\} \in E_c} \|e_{ij} - s'_c R'_c e_{ij}\|^2 \quad (3)$$
    *   **Laplacian Smoothing Energy:** Minimizes distortion in areas surrounding features of interest by preserving the deformed Laplacian coordinate of each grid vertex. Let $E(i)$ be neighboring edges sharing vertex $v_i$, and $C(i)$ be neighboring cubes sharing $v_i$. Let $L(v_i)$ be the original Laplacian coordinate:
        $$L(v_i) = \frac{1}{|E(i)|} \sum_{\{i,j\} \in E(i)} (v_i - v_j)$$
        Let $s'_i$ and $R'_i$ be the average scaling factor and rotation matrix of neighboring cubes $C(i)$:
        $$s'_i = \frac{1}{|C(i)|} \sum_{c \in C(i)} s'_c, \quad R'_i = \frac{1}{|C(i)|} \sum_{c \in C(i)} R'_c$$
        The energy is:
        $$D_\ell = \sum_{v_i \in V} \|L(v_i) - s'_i R'_i L(v_i)\|^2 \quad (4)$$
    *   **Boundary Constraints:** Fix the bounding space. Let $\partial V_x, \partial V_y, \partial V_z$ be boundary vertices in the $yz, xz, xy$ planes respectively:
        $$\begin{cases} v'_{i,x} = v_{i,x} & \text{if } v_i \in \partial V_x \\ v'_{i,y} = v_{i,y} & \text{if } v_i \in \partial V_y \\ v'_{i,z} = v_{i,z} & \text{if } v_i \in \partial V_z \end{cases} \quad (5)$$

2.  **Solve for Vertex Positions:**
    Transform the objective function ($D_f + D_\ell$) into a linear system $AV_0 = b(V_0)$ where $A$ contains coefficients of unknown vertex positions $V_0$. Since the scaling factors $s'_i$ and rotation matrices $R'_c$ are unknown, apply the Gaussian-Newton method to minimize the constrained non-linear objective function iteratively [S1].
    *   Initialize $s'_i = 1.0$ and $R'_c = I$ (identity matrix).
    *   Solve for $V_0$ in a least squares sense (equations > unknowns).
    *   Update $R'_c$ and $s'_c$: Place original and deformed cubes at the origin, compute the transformation matrix approximating the mapping from original to deformed vertices, and decompose via polar decomposition into rotation $R$ and shear $S$. Set $R_c = R$ and $s_c = \text{average of diagonal elements in } S$.
    *   Update $V_0$ again.
    *   Repeat until convergence. Solve x, y, z coordinates separately due to different boundary constraints [S1].

3.  **Edge Flipping Constraints:**
    Varying importance values can cause region intersections. Detect edges conflicting with the direction constraint $e'_{ij} \cdot e_{ij} > 0$ [S1].
    *   If violated, add penalty energy: $D_e(i, j) = \gamma \|e'_{ij} - \delta e_{ij}\|^2$.
    *   Parameters: $\delta = 0.1$ prevents shrinking to zero/negative scale, $\gamma = 10$ is penalty weight [S1].
    *   **Pitfall Handling:** Flipped edges may become legal if the user changes the transfer function or scaling factor. Constraining them to zero length causes abnormal deformation. Remove the flipping constraint when $|e'_{ij}| > \delta|e_{ij}|$ (stretching case), as only squeezing flips edges [S1].

4.  **Determine Magnification Level:**
    Measure cube distortion $\Psi$ incrementally as the volume is magnified. $\Psi$ is the weighted mean squared distance between corresponding vertices of the original cube $c_k$ and the deformed cube $c'_k$, transformed to match the original's size and orientation:
    $$\Psi = \frac{1}{n} \sum_{c_k \in C} w_k \|c_k - (s'_k R'_k)^{-1} c'_k\|^2 \quad (9)$$
    Stop the magnification process when $\Psi$ increases rapidly, indicating that less important regions are already fully squeezed and further scaling yields diminishing returns [S1].

**Resampling and Output:**
1.  **Downsampling:** Downsample the deformed volume data set. Extract voxels via trilinear interpolation on the GPU using the deformed grid to locate queried voxels in the reduced data set during rendering (texture lookup) [S1].
2.  **Output Format:** The result consists of only two components: the reduced data set and the deformed grid [S1].

```python
def feature_preserving_reduction(volume_data, transfer_function, scaling_factor_s):
    # 1. Preprocessing
    if has_noise(volume_data):
        volume_data = bilateral_filter(volume_data)
    
    # 2. Partition Grid
    G = partition_into_uniform_grid(volume_data)
    V, E, C = G.vertices, G.edges, G.cubes
    
    # 3. Compute Importance
    for cube in C:
        cube.importance = compute_importance_from_transfer_function(cube, transfer_function)
        
    # 4. Initialize Deformation Variables
    V_deformed = copy(V)
    S_factors = {c: 1.0 for c in C}
    R_matrices = {c: identity_matrix() for c in C}
    
    # 5. Iterative Optimization (Gaussian-Newton)
    for iteration in range(max_iterations):
        # Build Linear System AV = b based on D_f and D_l
        A, b = build_linear_system(V_deformed, S_factors, R_matrices, E, C)
        
        # Solve for coordinates separately due to boundary constraints
        V_deformed.x = solve_least_squares(A, b.x)
        V_deformed.y = solve_least_squares(A, b.y)
        V_deformed.z = solve_least_squares(A, b.z)
        
        # Update S and R for each cube
        for cube in C:
            original_vertices = get_cube_vertices(cube, V)
            deformed_vertices = get_cube_vertices(cube, V_deformed)
            T = compute_transformation_matrix(original_vertices, deformed_vertices)
            R, S = polar_decomposition(T)
            R_matrices[cube] = R
            S_factors[cube] = average_diagonal(S)
            
        # 6. Edge Flipping Constraints
        for edge in E:
            e_original = edge.vector(V)
            e_deformed = edge.vector(V_deformed)
            if dot(e_deformed, e_original) <= 0:
                # Check if stretching
                if length(e_deformed) > 0.1 * length(e_original):
                    remove_constraint(edge)
                else:
                    add_penalty_energy(edge, gamma=10, delta=0.1)
                    
        # 7. Check Distortion Stop Condition
        distortion = compute_distortion_metric(C, V, V_deformed, S_factors, R_matrices)
        if distortion_increases_rapidly(distortion):
            break
            
    # 8. Resampling
    reduced_data = trilinear_resample(volume_data, V_deformed, target_resolution)
    
    return reduced_data, V_deformed
```

## Operating characteristics
*   **Complexity:** The method involves solving a large linear system iteratively. The number of equations is much larger than the number of unknown vertex positions, solved in a least squares sense [S1].
*   **Performance:** Demonstrated reduction rate of 10:1 while preserving features better than direct downsampling [S1]. Implemented on GPU for parallel execution of cube importance determination, objective function minimization, and volumetric raycasting [S1].
*   **Strengths:** Continuous space deformation guarantees similar resolutions along neighboring grid boundaries, obviating the need for extra data packing or blending required by multiresolution methods [S1]. Automatically recognizes and visualizes all features of interest simultaneously, unlike lens-based focus+context methods restricted to a single focus [S1].
*   **Limitations:** If features are distributed everywhere, the deformation fails to magnify them, degenerating into pure downsampling [S1]. Homogeneous cubes are not shrunk to preserve space continuity, preventing full utilization of available space for feature preservation [S1]. Local deformation does not guarantee preservation of global structures like straight lines or symmetry [S1].
*   **When to use:** Validated on volume data sets from medical applications and scientific simulations where features are well-defined by transfer functions [S1].

## Background
Originated by Yu-Shuen Wang, Chaoli Wang, Tong-Yee Lee, and Kwan-Liu Ma [S1]. The approach is inspired by resizing techniques proposed by Wang et al. [32]–[34] but revised for volumetric data [S1]. It addresses the challenge of interactive visualization of large volumetric data sets (from $128^3$ to $1024^3$ voxels or larger) by reducing storage and rendering costs without the complication of runtime decompression [S1].
