# Reduced-MS / RDO-Gaussian

Also called: RDO-Gaussian, Reduced-MS

## Overview
Reduced-MS (Rate-Distortion Optimization for Gaussians) is a compression method for 3D Gaussian Splatting that minimizes the Lagrangian cost function during the encoding phase to balance bitrate and reconstruction fidelity [S1, unofficial]. It distinguishes itself from static quantization schemes by dynamically selecting quantization parameters based on the specific rate-distortion trade-off of the data, rather than applying fixed bit-depths or heuristic offsets [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of 3D Gaussians defined by position $\mathbf{x}$, covariance (or scale/rotation), spherical harmonic (SH) coefficients for color, and opacity $\alpha$.
*   **Output:** A compressed bitstream containing quantized parameters and entropy-coded indices.

**Data Structures:**
The method operates on the standard 3DGS parameter set:
1.  **Position:** 3D vector.
2.  **Scale/Rotation:** 3D scale vector, 4D quaternion.
3.  **SH Coefficients:** $K$ bands of coefficients per color channel.
4.  **Opacity:** Scalar.

**Steps:**
1.  **Cost Function Definition:** Define the Lagrangian cost function $J$ for each Gaussian $i$:
    $$ J_i = D_i + \lambda R_i $$
    Where $D_i$ is the distortion (e.g., MSE or perceptual metric) introduced by quantization, $R_i$ is the bitrate (bits) required to encode the quantized parameters, and $\lambda$ is the Lagrange multiplier controlling the compression strength [S1, unofficial].

2.  **Quantization Search:** For each Gaussian, search for the optimal quantization configuration (e.g., bit-depth for position, SH bands, opacity) that minimizes $J_i$. This involves:
    *   Quantizing parameters to candidate bit-depths (e.g., 16-bit half, 12-bit residuals, 8-bit INT8 for SH higher bands) [S1, unofficial].
    *   Calculating the resulting distortion $D_i$ by comparing the quantized Gaussian to the original.
    *   Estimating the bitrate $R_i$ based on the entropy of the quantized values (often using arithmetic or Huffman coding models) [S1, unofficial].

3.  **Parameter Selection:** Select the quantization settings that yield the minimum $J_i$ for each Gaussian. This allows high-detail Gaussians to retain higher precision while low-detail or distant Gaussians are heavily compressed [S1, unofficial].

4.  **Entropy Coding:** Encode the selected quantized parameters and the chosen bit-depth indices using entropy coding (e.g., Huffman, range coding, or zstd) to produce the final bitstream [S1, unofficial].

**Parameters:**
*   $\lambda$: Lagrange multiplier. Typical values depend on the desired compression ratio. Not given in the sources.
*   Bit-depth candidates: e.g., 16-bit for position, 8-bit for opacity, 8-bit for SH higher bands [S1, unofficial].

**Edge Cases:**
*   **Precision Loss:** Aggressive quantization of SH coefficients can cause color artifacts. The RDO process mitigates this by preserving higher precision for visually significant Gaussians [S1, unofficial].
*   **Computational Cost:** The search for optimal quantization parameters increases encoding time compared to fixed quantization [S1, unofficial].

    """
    Compress a list of Gaussians using Rate-Distortion Optimization.
    gaussians: List of Gaussian objects with attributes:
        - pos: (3,) float32
        - scale: (3,) float32
        - rot: (4,) float32 (quaternion)
        - sh_coeffs: (K, 3, C) float32 (Spherical Harmonics)
        - opacity: float32
    lambda_param: float, Lagrange multiplier for rate-distortion trade-off.
    Returns:
        compressed_data: List of encoded tuples (bit_depth_config, quantized_values)
    """
    compressed_data = []
    
    # Candidate quantization configurations
    # Each config specifies bit-depths for different attributes
    configs = [
        {'pos_bits': 16, 'sh_high_bits': 8, 'opacity_bits': 8},
        {'pos_bits': 12, 'sh_high_bits': 6, 'opacity_bits': 6},
        {'pos_bits': 8, 'sh_high_bits': 4, 'opacity_bits': 4},
        # Add more configurations as needed
    ]
    
    for g in gaussians:
        best_j = float('inf')
        best_config = None
        best_quantized = None
        
        for config in configs:
            # 1. Quantize
            quantized_pos = quantize(g.pos, config['pos_bits'])
            quantized_sh_high = quantize(g.sh_coeffs[1:], config['sh_high_bits']) # Assuming DC is kept higher precision
            quantized_opacity = quantize(g.opacity, config['opacity_bits'])
            
            # 2. Calculate Distortion (D)
            # Reconstruct original-like values for error calculation
            reconstructed_pos = dequantize(quantized_pos, config['pos_bits'])
            reconstructed_sh_high = dequantize(quantized_sh_high, config['sh_high_bits'])
            reconstructed_opacity = dequantize(quantized_opacity, config['opacity_bits'])
            
            # Simple MSE for demonstration; real implementation uses perceptual metric
            d_pos = mse(g.pos, reconstructed_pos)
            d_sh = mse(g.sh_coeffs[1:], reconstructed_sh_high)
            d_opacity = mse(g.opacity, reconstructed_opacity)
            D = d_pos + d_sh + d_opacity
            
            # 3. Estimate Rate (R)
            # Bitrate is proportional to the number of bits used
            R = (config['pos_bits'] * 3 + 
                 config['sh_high_bits'] * (g.sh_coeffs.shape[0]-1) * 3 * g.sh_coeffs.shape[2] + 
                 config['opacity_bits'])
            
            # 4. Calculate Lagrangian Cost (J)
            J = D + lambda_param * R
            
            # 5. Update Best
            if J < best_j:
                best_j = J
                best_config = config
                best_quantized = (quantized_pos, quantized_sh_high, quantized_opacity)
        
        # Store the best configuration and quantized values
        # In practice, the config index and quantized values are entropy coded
        compressed_data.append((best_config, best_quantized))
        
    return compressed_data

## Operating characteristics
*   **Time Complexity:** Encoding is slower than fixed quantization due to the search for optimal parameters. Decoding is comparable to standard Gaussian Splatting decoding.
*   **Memory Complexity:** Storage is reduced by 15x with less than 0.5 dB drop in quality [S1, unofficial].
*   **Strengths:** Achieves high compression ratios while maintaining visual quality by adapting to the importance of each Gaussian.
*   **Limitations:** Increased encoding complexity and time.
*   **When to use:** When storage or bandwidth is constrained and encoding time is not the primary bottleneck.

## Background
Reduced-MS is part of the broader effort to compress 3D Gaussian Splatting representations. It leverages rate-distortion optimization principles common in video and image coding, adapted for the unique structure of Gaussian splats [S1, unofficial].
