# Volume Partitioning Pipeline


## Overview
The Volume Partitioning Pipeline splits a 3D volume into foreground regions, optionally partitions them spatially or by intensity, crops them to bounding boxes, downsamples, and exports them as raw files with metadata [S1, unofficial]. It differs from its sibling [VolumeSegmenter Pipeline](11584-volumesegmenter-pipeline.md) by focusing on geometric and intensity-based partitioning of foreground data for export rather than semantic segmentation, and from [Preprocessing Pipeline](6733-preprocessing-pipeline.md) by specifically handling the decomposition and packaging of volume components [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D volume array (typically `uint8` or `uint16`), processing parameters (`mode`, `components`, `threshold`, etc.).
*   **Output:** A directory containing one `.raw` file per component (e.g., `component_1.raw`) and a `metadata.json` file describing the layout, origins, and integrity of the data.

**Data Structures:**
*   **Metadata JSON:** Contains `schema_version` (int), `dtype` (str), `array_order` (str, e.g., 'ZYX'), `coordinate_order` (str, e.g., 'XYZ'), `input_file` (str), `input_sha256` (str), `dimensions_xyz` (list[int]), `original_bytes` (int), `parameters` (dict), `foreground_metrics` (dict), `original_nonzero` (int), `retained_nonzero` (int), `components` (list[dict]), `output_bytes` (int), `processing_seconds` (float), and `reconstruction` (str).
*   **Component Record:** Each entry in `components` list contains: `file` (str), `dimensions_xyz` (list[int]), `origin_xyz` (list[int]), `spacing_xyz` (list[float]), `extent_xyz` (list[int]), `bytes` (int), and `sha256` (str).

**Parameters:**
*   `mode`: Processing mode. Choices: 'original', 'crop', 'partition'. Default: 'partition' [S1, unofficial].
*   `components`: Number of partitions. Range: 1–15. Default: 8 [S1, unofficial].
*   `spatial_weight`: Weight for kmeans partitioning. Range: [0,1]. Default: 0.5 [S1, unofficial].
*   `downsample`: Integer downsampling factor applied to all axes. Range: >= 1. Default: 1 [S1, unofficial].
*   `threshold`: Foreground cutoff value. Range: [0,255]. If None, uses `background_threshold` [S1, unofficial].
*   `cleanup`: Foreground cleanup strategy. Choices: 'none', 'connected', 'opening', 'legacy'. Default: 'none' [S1, unofficial].
*   `min_region_voxels`: Minimum voxel count for valid regions. Default: 512 [S1, unofficial].
*   `strategy`: Partition strategy. Choices: 'spatial', 'kmeans'. Default: 'spatial' [S1, unofficial].
*   `seed`: Random seed for kmeans partitioning. Default: 42 [S1, unofficial].

**Steps:**
1.  **Validate Inputs:** Ensure `mode` is in ['original', 'crop', 'partition']; `components` is in [1, 15]; `spatial_weight` is in [0, 1]; `downsample` is an integer >= 1; `threshold` is in [0, 255] if provided. Ensure the output directory is empty; raise `ValueError` if `component_*.raw` or `metadata.json` already exists [S1, unofficial].
2.  **Read Volume and Compute Cutoff:** Read the input volume. Compute `cutoff`: 0.0 for 'original' mode; otherwise, use `background_threshold(original, seed)` if `threshold` is None, else `float(threshold)` [S1, unofficial].
3.  **Compute Foreground Mask:** Compute foreground mask and metrics via `select_foreground(cutoff, cleanup, min_region_voxels)`. Create `retained` array: `retained = np.where(mask, original, 0).astype(np.uint8)` [S1, unofficial].
4.  **Compute Labels:**
    *   If `mode` is 'partition':
        *   If `strategy` is 'spatial': Compute labels using `spatial_partition(retained, components)` [S1, unofficial].
        *   If `strategy` is 'kmeans': Compute labels using `kmeans_partition(retained, components, seed, spatial_weight)` [S1, unofficial].
    *   Otherwise ('original' or 'crop'): `labels = (retained > 0).astype(np.uint8)` [S1, unofficial].
5.  **Process Components:** Iterate over unique label IDs > 0. For each ID:
    *   Compute bounding box `(lo, hi)` from label coordinates.
    *   Extract subvolume.
    *   Apply mask.
    *   Downsample by `downsample` factor along all axes: `data = data[::downsample, ::downsample, ::downsample].copy()` [S1, unofficial].
    *   Write `data` to `component_{id}.raw`.
    *   Record `dimensions_xyz`, `origin_xyz`, `spacing_xyz`, `extent_xyz`, `bytes`, and `sha256` hash in a component record [S1, unofficial].
6.  **Generate Metadata:** Create `metadata.json` with `schema_version=2`, `dtype='uint8'`, `array_order='ZYX'`, `coordinate_order='XYZ'`, input metadata, parameters, foreground metrics, component records, and a reconstruction note [S1, unofficial].

**Pseudocode:**

```python
import numpy as np
import hashlib
import json
from pathlib import Path

def volume_partitioning_pipeline(input_path, output_dir, mode='partition', components=8, 
                                 spatial_weight=0.5, downsample=1, threshold=None, 
                                 cleanup='none', min_region_voxels=512, strategy='spatial', seed=42):
    out = Path(output_dir)
    if out.exists() and any(out.iterdir()):
        raise ValueError('Output directory must be empty')
    out.mkdir(parents=True, exist_ok=True)

    # 1. Validate inputs
    if mode not in ['original', 'crop', 'partition']:
        raise ValueError('Mode must be original, crop, or partition')
    if not (1 <= components <= 15):
        raise ValueError('Components must be 1-15')
    if not (0 <= spatial_weight <= 1):
        raise ValueError('Spatial weight must be in [0,1]')
    if not isinstance(downsample, int) or downsample < 1:
        raise ValueError('Downsample must be integer >= 1')
    if threshold is not None and not (0 <= threshold <= 255):
        raise ValueError('Threshold must be in [0,255]')

    # 2. Read volume and compute cutoff
    original = np.load(input_path) # Assume numpy array loading; source implies numpy usage
    if mode == 'original':
        cutoff = 0.0
    else:
        if threshold is None:
            cutoff = background_threshold(original, seed) # [G] Helper function to determine background threshold
        else:
            cutoff = float(threshold)

    # 3. Compute foreground mask and retained array
    mask, metrics = select_foreground(cutoff, cleanup, min_region_voxels) # [G] Helper for mask generation
    retained = np.where(mask, original, 0).astype(np.uint8)

    # 4. Compute labels
    if mode == 'partition':
        if strategy == 'spatial':
            labels = spatial_partition(retained, components) # [G] Helper for spatial partitioning
        elif strategy == 'kmeans':
            labels = kmeans_partition(retained, components, seed, spatial_weight) # [G] Helper for kmeans partitioning
        else:
            raise ValueError('Unknown strategy')
    else:
        labels = (retained > 0).astype(np.uint8)

    unique_ids = np.unique(labels)
    unique_ids = unique_ids[unique_ids > 0] # Exclude background

    component_records = []
    for label_id in unique_ids:
        # 5. Process component
        coords = np.argwhere(labels == label_id)
        if len(coords) == 0:
            continue
        
        lo = coords.min(axis=0)
        hi = coords.max(axis=0)
        
        # Extract subvolume
        subvol = retained[lo[0]:hi[0]+1, lo[1]:hi[1]+1, lo[2]:hi[2]+1]
        
        # Apply mask (re-apply to ensure only foreground is kept if mask was global)
        # Note: mask might need to be cropped to subvol bounds
        sub_mask = mask[lo[0]:hi[0]+1, lo[1]:hi[1]+1, lo[2]:hi[2]+1]
        subvol = np.where(sub_mask, subvol, 0).astype(np.uint8)
        
        # Downsample
        if downsample > 1:
            subvol = subvol[::downsample, ::downsample, ::downsample].copy()
        
        # Write raw file
        filename = f'component_{label_id}.raw'
        filepath = out / filename
        subvol.tofile(filepath)
        
        # Compute hash
        sha256 = hashlib.sha256(subvol.tobytes()).hexdigest()
        
        # Record metadata
        record = {
            'file': filename,
            'dimensions_xyz': list(subvol.shape),
            'origin_xyz': list(lo),
            'spacing_xyz': [1.0, 1.0, 1.0], # [G] Placeholder for actual spacing; source mentions spacing_xyz in metadata
            'extent_xyz': list(subvol.shape),
            'bytes': subvol.nbytes,
            'sha256': sha256
        }
        component_records.append(record)

    # 6. Generate metadata
    metadata = {
        'schema_version': 2,
        'dtype': 'uint8',
        'array_order': 'ZYX',
        'coordinate_order': 'XYZ',
        'input_file': str(input_path),
        'input_sha256': hashlib.sha256(original.tobytes()).hexdigest(),
        'dimensions_xyz': list(original.shape),
        'original_bytes': original.nbytes,
        'parameters': {
            'mode': mode,
            'components': components,
            'spatial_weight': spatial_weight,
            'downsample': downsample,
            'threshold': threshold,
            'cleanup': cleanup,
            'min_region_voxels': min_region_voxels,
            'strategy': strategy,
            'seed': seed
        },
        'foreground_metrics': metrics,
        'original_nonzero': int(np.count_nonzero(original)),
        'retained_nonzero': int(np.count_nonzero(retained)),
        'components': component_records,
        'output_bytes': sum(r['bytes'] for r in component_records),
        'processing_seconds': 0.0, # [G] Placeholder for actual time
        'reconstruction': 'Reconstruct by loading components and placing at origin_xyz'
    }
    
    (out / 'metadata.json').write_text(json.dumps(metadata, indent=2))

def background_threshold(volume, seed):
    # [G] Implementation detail not provided in sources
    return np.percentile(volume[volume > 0], 1) if np.any(volume > 0) else 0

def select_foreground(cutoff, cleanup, min_region_voxels):
    # [G] Implementation detail not provided in sources
    mask = np.zeros_like(cutoff, dtype=bool) # Placeholder
    return mask, {}

def spatial_partition(retained, components):
    # [G] Implementation detail not provided in sources
    return np.zeros_like(retained, dtype=np.uint8)

def kmeans_partition(retained, components, seed, spatial_weight):

    return np.zeros_like(retained, dtype=np.uint8)
```

## Subtopics

### [Bounded-Memory Large Volume Export](11587-bounded-memory-large-volume-export.md)
Bounded-Memory Large Volume Export processes large 3D volumes (such as OME-Zarr or RAW formats) with bounded memory usage by streaming input chunks, computing intensity baselines, cropping data to disjoint aligned bricks, and writing compressed outputs without loading the full volume into RAM. It differs from sibling methods by explicitly enforcing a memory bound through chunked streaming and packing only foreground voxels into a compact, offset-indexed raw file, discarding background values entirely. See [Bounded-Memory Large Volume Export](11587-bounded-memory-large-volume-export.md).

### [Greedy Axis-Aligned Spatial Partitioning](11589-greedy-axis-aligned-spatial-partitioning.md)
Greedy Axis-Aligned Spatial Partitioning creates a disjoint spatial partition of a 3D volume into axis-aligned bounding boxes (AABBs) using a greedy heuristic that minimizes the total bounding box volume. It is used in the Volume Partitioning Pipeline to split foreground regions into manageable components for export. It differs from [Slab-projected kd-tree partitioning](11586-slab-projected-kd-tree-partitioning.md) by using a direct greedy box-splitting approach rather than slab-projection slices for out-of-core processing. See [Greedy Axis-Aligned Spatial Partitioning](11589-greedy-axis-aligned-spatial-partitioning.md).

### K-Means Spatial-Intensity Partitioning
K-Means Spatial-Intensity Partitioning partitions volume into components by clustering foreground voxels based on spatial coordinates (x,y,z) and intensity, using a weighted combination [S1, unofficial]. It uses a sample of up to 30,000 foreground indices to fit a StandardScaler and KMeans, then predicts labels for all foreground voxels in batches [S1, unofficial]. Parameters include `components` (default 8), `spatial_weight` (default 0.5), and `batch_size` (default 100,000) [S1, unofficial].
