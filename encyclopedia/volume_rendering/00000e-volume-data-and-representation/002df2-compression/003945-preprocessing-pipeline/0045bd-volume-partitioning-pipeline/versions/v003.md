# Volume Partitioning Pipeline


## Overview
The Volume Partitioning Pipeline splits a 3D volume into foreground regions, optionally partitions them spatially or by intensity, crops them to bounding boxes, downsamples, and exports them as raw files with metadata [S1, unofficial]. It differs from the [VolumeSegmenter Pipeline](11584-volumesegmenter-pipeline.md) by focusing on explicit component partitioning and compact export rather than semantic segmentation, and from the [3D Seismic Data Compression Pipeline](11727-3d-seismic-data-compression-pipeline.md) by its general-purpose intensity-based foreground detection and flexible partitioning strategies [S1, unofficial].

## How it works
**Inputs and Outputs**
- **Input**: A 3D volume array (typically `uint8` or `uint16`), processing parameters (`mode`, `components`, `threshold`, etc.).
- **Output**: A directory containing one `.raw` file per component (e.g., `component_1.raw`) and a `metadata.json` file describing the structure, dimensions, and integrity of the exported data.

**Data Structures**
- **Metadata JSON**: A JSON object with the following schema:
  - `schema_version`: Integer (fixed at 2).
  - `dtype`: String (e.g., `'uint8'`).
  - `array_order`: String (e.g., `'ZYX'`).
  - `coordinate_order`: String (e.g., `'XYZ'`).
  - `input_file`: String (path to original input).
  - `input_sha256`: String (SHA-256 hash of input).
  - `dimensions_xyz`: List of 3 integers.
  - `original_bytes`: Integer.
  - `parameters`: Dictionary of processing parameters.
  - `foreground_metrics`: Dictionary containing `original_nonzero` and `retained_nonzero`.
  - `components`: List of component dictionaries. Each component dict contains:
    - `file`: String (filename, e.g., `component_1.raw`).
    - `dimensions_xyz`: List of 3 integers.
    - `origin_xyz`: List of 3 integers.
    - `spacing_xyz`: List of 3 floats.
    - `extent_xyz`: List of 3 integers.
    - `bytes`: Integer (file size).
    - `sha256`: String (SHA-256 hash of the raw file).
  - `output_bytes`: Integer.
  - `processing_seconds`: Float.
  - `reconstruction`: String (note on reconstruction).

**Parameters**
- `mode`: Processing mode. Choices: `'original'`, `'crop'`, `'partition'`. Default: `'partition'`.
- `components`: Number of partitions. Range: 1–15. Default: 8.
- `spatial_weight`: Weight for k-means partitioning. Range: [0, 1]. Default: 0.5.
- `downsample`: Integer downsampling factor applied to all axes. Range: >= 1. Default: 1.
- `threshold`: Foreground cutoff value. Range: [0, 255]. If `None`, uses `background_threshold`.
- `cleanup`: Foreground cleanup strategy. Choices: `'none'`, `'connected'`, `'opening'`, `'legacy'`. Default: `'none'`.
- `min_region_voxels`: Minimum voxel count for valid regions. Default: 512.
- `strategy`: Partition strategy. Choices: `'spatial'`, `'kmeans'`. Default: `'spatial'`.
- `seed`: Random seed for k-means partitioning. Default: 42.

**Steps**
1. **Validate Inputs**:
   - Ensure `mode` is one of `'original'`, `'crop'`, `'partition'`.
   - Ensure `components` is an integer between 1 and 15.
   - Ensure `spatial_weight` is a float in [0, 1].
   - Ensure `downsample` is an integer >= 1.
   - If `threshold` is provided, ensure it is an integer in [0, 255].
   - Ensure the output directory is empty; raise `ValueError` if `component_*.raw` or `metadata.json` already exists [S1, unofficial].

2. **Read Volume and Compute Cutoff**:
   - Read the input volume into memory.
   - If `mode` is `'original'`, set `cutoff = 0.0`.
   - Otherwise, if `threshold` is `None`, compute `cutoff = background_threshold(original, seed)`.
   - If `threshold` is provided, set `cutoff = float(threshold)`.

3. **Compute Foreground Mask and Metrics**:
   - Call `select_foreground(cutoff, cleanup, min_region_voxels)` to generate a boolean `mask` and compute metrics.
   - Create `retained` array: `retained = np.where(mask, original, 0).astype(np.uint8)`.

4. **Compute Labels**:
   - If `mode` is `'partition'`:
     - If `strategy` is `'spatial'`, call `spatial_partition(retained, components)` to get `labels`.
     - If `strategy` is `'kmeans'`, call `kmeans_partition(retained, components, seed, spatial_weight)` to get `labels`.
   - Otherwise (`mode` is `'original'` or `'crop'`), set `labels = (retained > 0).astype(np.uint8)`.

5. **Process Components**:
   - Iterate over unique label IDs `id` in `labels` where `id > 0`.
   - For each `id`:
     - Compute bounding box `(lo, hi)` from coordinates where `labels == id`.
     - Extract subvolume: `data = retained[lo[0]:hi[0], lo[1]:hi[1], lo[2]:hi[2]]`.
     - Apply mask: `data = data * (labels[lo[0]:hi[0], lo[1]:hi[1], lo[2]:hi[2]] == id)`.
     - Downsample: `data = data[::downsample, ::downsample, ::downsample].copy()`.
     - Write `data` to `component_{id}.raw`.
     - Compute SHA-256 hash of the raw file.
     - Record dimensions, origin, spacing, extent, bytes, and hash for metadata.

6. **Generate Metadata**:
   - Create `metadata.json` with the schema defined above, including input metadata, parameters, foreground metrics, component records, and a reconstruction note.

**Pseudocode**
```python
import numpy as np
import hashlib
import json
import os
from pathlib import Path

def volume_partitioning_pipeline(input_path, output_dir, **kwargs):
    # 1. Validate Inputs
    mode = kwargs.get('mode', 'partition')
    components = kwargs.get('components', 8)
    spatial_weight = kwargs.get('spatial_weight', 0.5)
    downsample = kwargs.get('downsample', 1)
    threshold = kwargs.get('threshold', None)
    cleanup = kwargs.get('cleanup', 'none')
    min_region_voxels = kwargs.get('min_region_voxels', 512)
    strategy = kwargs.get('strategy', 'spatial')
    seed = kwargs.get('seed', 42)

    if mode not in ['original', 'crop', 'partition']:
        raise ValueError("mode must be 'original', 'crop', or 'partition'")
    if not (1 <= components <= 15):
        raise ValueError("components must be 1-15")
    if not (0 <= spatial_weight <= 1):
        raise ValueError("spatial_weight must be in [0,1]")
    if not isinstance(downsample, int) or downsample < 1:
        raise ValueError("downsample must be integer >= 1")
    if threshold is not None and not (0 <= threshold <= 255):
        raise ValueError("threshold must be in [0,255]")
    
    out = Path(output_dir)
    if out.exists() and any(out.glob('component_*.raw')) or (out / 'metadata.json').exists():
        raise ValueError("Output directory must be empty")
    out.mkdir(parents=True, exist_ok=True)

    # 2. Read Volume and Compute Cutoff
    original = np.load(input_path) # Assume .npy or similar; actual source may vary
    if mode == 'original':
        cutoff = 0.0
    else:
        if threshold is None:
            cutoff = background_threshold(original, seed) # [G] Placeholder for specific algorithm
        else:
            cutoff = float(threshold)

    # 3. Compute Foreground Mask and Metrics
    mask, metrics = select_foreground(cutoff, cleanup, min_region_voxels) # [G] Placeholder for specific algorithm
    retained = np.where(mask, original, 0).astype(np.uint8)

    # 4. Compute Labels
    if mode == 'partition':
        if strategy == 'spatial':
            labels = spatial_partition(retained, components) # [G] Placeholder for specific algorithm
        elif strategy == 'kmeans':
            labels = kmeans_partition(retained, components, seed, spatial_weight) # [G] Placeholder for specific algorithm
        else:
            raise ValueError("strategy must be 'spatial' or 'kmeans'")
    else:
        labels = (retained > 0).astype(np.uint8)

    # 5. Process Components
    component_records = []
    unique_ids = np.unique(labels)
    unique_ids = unique_ids[unique_ids > 0]

    for label_id in unique_ids:
        coords = np.argwhere(labels == label_id)
        if len(coords) == 0:
            continue
        
        lo = coords.min(axis=0)
        hi = coords.max(axis=0) + 1
        
        subvolume = retained[lo[0]:hi[0], lo[1]:hi[1], lo[2]:hi[2]]
        sub_labels = labels[lo[0]:hi[0], lo[1]:hi[1], lo[2]:hi[2]]
        sub_mask = (sub_labels == label_id)
        data = (subvolume * sub_mask).astype(np.uint8)
        
        if downsample > 1:
            data = data[::downsample, ::downsample, ::downsample].copy()
        
        filename = f"component_{label_id}.raw"
        filepath = out / filename
        data.tofile(filepath)
        
        sha256_hash = hashlib.sha256(data.tobytes()).hexdigest()
        file_bytes = filepath.stat().st_size
        
        # Compute origin, spacing, extent based on original volume metadata
        # [G] Placeholder for specific coordinate system handling
        origin_xyz = [int(x) for x in lo]
        extent_xyz = [int(x) for x in (hi - lo)]
        dimensions_xyz = list(data.shape)
        spacing_xyz = [1.0, 1.0, 1.0] # [G] Placeholder for actual spacing
        
        component_records.append({
            "file": filename,
            "dimensions_xyz": dimensions_xyz,
            "origin_xyz": origin_xyz,
            "spacing_xyz": spacing_xyz,
            "extent_xyz": extent_xyz,
            "bytes": file_bytes,
            "sha256": sha256_hash
        })

    # 6. Generate Metadata
    metadata = {
        "schema_version": 2,
        "dtype": "uint8",
        "array_order": "ZYX",
        "coordinate_order": "XYZ",
        "input_file": str(input_path),
        "input_sha256": hashlib.sha256(original.tobytes()).hexdigest(),
        "dimensions_xyz": list(original.shape),
        "original_bytes": original.nbytes,
        "parameters": {
            "mode": mode,
            "components": components,
            "spatial_weight": spatial_weight,
            "downsample": downsample,
            "threshold": threshold,
            "cleanup": cleanup,
            "min_region_voxels": min_region_voxels,
            "strategy": strategy,
            "seed": seed
        },
        "foreground_metrics": {
            "original_nonzero": int(np.count_nonzero(original)),
            "retained_nonzero": int(np.count_nonzero(retained))
        },
        "components": component_records,
        "output_bytes": sum(c["bytes"] for c in component_records),
        "processing_seconds": 0.0, # [G] Placeholder for actual time
        "reconstruction": "Components can be reconstructed by reading raw files and placing them at their origin_xyz in a zero-filled volume of dimensions_xyz."
    }
    
    with open(out / 'metadata.json', 'w') as f:
        json.dump(metadata, f, separators=(',', ':'))
```

## Subtopics

### [Bounded-Memory Large Volume Export](11587-bounded-memory-large-volume-export.md)
Processes large 3D volumes with bounded memory usage by streaming input chunks, computing intensity baselines, cropping data to disjoint aligned bricks, and writing compressed outputs without loading the full volume into RAM. It differs from sibling methods by explicitly enforcing a memory bound through chunked streaming and packing only foreground voxels into a compact, offset-indexed raw file, discarding background values entirely.

### [K-Means Spatial-Intensity Partitioning](11588-k-means-spatial-intensity-partitioning.md)
Segments a 3D volume into distinct components by clustering foreground voxels based on a weighted combination of their spatial coordinates (x, y, z) and their intensity values. It addresses the problem of organizing large volumes into manageable, semantically coherent regions for downstream processing, such as compression or visualization. Unlike [Greedy Axis-Aligned Spatial Partitioning](11589-greedy-axis-aligned-spatial-partitioning.md), which splits purely by geometric boundaries, this method incorporates intensity similarity, allowing clusters to respect material or signal boundaries even if they are spatially disjoint. It differs from [Bounded-Memory Large Volume Export](11587-bounded-memory-large-volume-export.md) by focusing on clustering logic rather than memory-constrained I/O streaming.

### [Greedy Axis-Aligned Spatial Partitioning](11589-greedy-axis-aligned-spatial-partitioning.md)
Creates a disjoint spatial partition of a 3D volume into axis-aligned bounding boxes (AABBs) using a greedy heuristic that minimizes the total bounding box volume. It is used in the Volume Partitioning Pipeline to split foreground regions into manageable components for export. It differs from [Slab-projected kd-tree partitioning](11586-slab-projected-kd-tree-partitioning.md) by using a direct greedy box-splitting approach rather than slab-projection slices for out-of-core processing.

## Operating characteristics
- **Time Complexity**: Depends on the partitioning strategy. K-means is $O(I \cdot N \cdot K)$ where $I$ is iterations, $N$ is foreground voxels, $K$ is components. Spatial partitioning is generally linear in $N$. Bounding box extraction and downsampling are linear in the number of foreground voxels.
- **Memory Complexity**: In the standard pipeline, the full volume and label array are loaded into memory. For very large volumes, the [Bounded-Memory Large Volume Export](11587-bounded-memory-large-volume-export.md) variant should be used, which streams chunks and uses bounded memory.
- **Measured Performance**: Not given in the sources.
- **Scaling**: Scales with volume size and number of components. Downsampling reduces output size and processing time linearly.
- **Strengths**: Flexible partitioning strategies, explicit memory bounds in variants, compact raw file output, detailed metadata.
- **Limitations**: Requires full volume in memory for the standard pipeline (unless using bounded-memory variant), threshold selection can be critical, partitioning quality depends on strategy.
- **When to use**: When you need to split a large volume into manageable, foreground-focused components for export or further processing, especially when memory is not a constraint or when using the bounded-memory variant.
- **When not**: When semantic segmentation is required (use [VolumeSegmenter Pipeline](11584-volumesegmenter-pipeline.md)), or when specific compression algorithms are needed (use [3D Seismic Data Compression Pipeline](11727-3d-seismic-data-compression-pipeline.md)).

## Background
The Volume Partitioning Pipeline is part of the VolumeSegmenter project by Winson-L [S1, unofficial]. It is designed to preprocess large 3D volumes for efficient storage and processing by partitioning them into foreground components. The pipeline supports various strategies for partitioning, including spatial and k-means clustering, and provides options for cropping, downsampling, and cleanup.
