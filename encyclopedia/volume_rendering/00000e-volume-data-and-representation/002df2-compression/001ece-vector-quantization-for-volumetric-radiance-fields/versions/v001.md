# Vector Quantization for Volumetric Radiance Fields

Also called: Codebook Encoding, Vector Quantization (VQ), Vector Quantization (VQ) Decompression

## Overview
Vector Quantization (VQ) is a dictionary-based compression strategy that encodes voxel color features into a compact codebook, substituting multiple voxel features with a single code vector to reduce storage from individual voxel storage to codebook storage plus mapping indices [S1]. It solves the problem of high memory consumption for color features in volumetric radiance fields by enabling per-voxel random access through on-the-fly reconstruction [S2][S3, unofficial]. Unlike sparse structures that store explicit coordinates or value compression that quantizes individual values, VQ learns a shared representation space [S1]. It sets itself apart by allowing a trade-off between compression ratio and rendering quality via a "keep quantile" that preserves the most important voxels uncompressed [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A pre-trained volumetric radiance field model (e.g., DVGO, Plenoxels, TensoRF) consisting of a density grid, color feature grid, and optionally a small neural network. The features are typically stored in float16 [S1].
*   **Output:** A compressed representation comprising a codebook, voxel-to-codebook mapping indices, a mask, quantized density/non-VQ features, and entropy-encoded data [S1].

**Data Structures:**
The final storage consists of six components [S1]:
1.  **2-bit mask:** Identifies pruned, VQ-compressed, or unaltered (non-VQ) voxels.
2.  **Code vectors:** The codebook $B$ of size $K \times C$ stored in float16 [S1].
3.  **Mapping indexes:** Indices mapping each voxel to a code vector, requiring $\lceil \log_2(K) \rceil$ bits per voxel [S1].
4.  **8-bit quantized density grid:** Full-precision density cast to unsigned 8-bit integers [S1].
5.  **8-bit quantized non-VQ voxels:** Color features of voxels saved without VQ, cast to unsigned 8-bit integers [S1].
6.  **Small network weights:** Weights of the auxiliary network (if applicable, e.g., in DVGO) [S1].

**Parameters:**
*   **Codebook size ($K$):** Default 4096 [S1].
*   **Keep quantile ($\beta_k$):** Fraction of most important voxels saved without VQ. Value is 0.6 for DVGO and Plenoxels, 0.7 for TensoRF [S1].
*   **Decay factor ($\lambda_d$):** Moving average factor for code vector updating. Default 0.8 [S1].
*   **Expired codes ($J$):** Number of dead codes expired at every step. Default 10 [S1].
*   **Batch size:** 10,000 voxels for initialization; varies for finetuning (e.g., 8196 rays for VQ-DVGO, 5000 for VQ-Plenoxels) [S1].

**Algorithm Steps:**

1.  **Importance Scoring:** Calculate an importance score $I_j$ for each voxel $v_j$ based on its contribution to rendering [S1].
2.  **Thresholding:** Determine the keeping threshold $\theta_k = Q(\beta_k) = F^{-1}(\beta_k)$, where $F^{-1}$ is the inverse cumulative distribution function of importance scores. Voxels with $I_j > \theta_k$ are marked as non-VQ voxels and stored uncompressed (after 8-bit quantization) [S1].
3.  **Codebook Initialization:** Initialize codebook $B = \{b_1, ..., b_K\}$ using iterative weighted clustering on the remaining voxels.
    *   Randomly select a batch of voxels.
    *   Calculate Euclidean distance between selected voxels and each code vector to determine association [S1].
    *   Update code vectors using the moving average rule:
        $$ \mathbf{b}_k := \lambda_d \mathbf{b}_k + (1 - \lambda_d) \sum_{\mathbf{v}_j \in \mathcal{R}(\mathbf{b}_k)} I_j \mathbf{u}_j $$
        where $\mathbf{u}_j$ is the color feature, $I_j$ is the importance score, and $\mathcal{R}(b_k)$ is the set of voxels assigned to code $b_k$ [S1].
    *   **Code Expiration:** Track capacity $s_k = \sum_{\mathbf{v}_j \in \mathcal{R}(\mathbf{b}_k)} I_j$. Rank codes by capacity. Expire $J$ codes with the lowest capacity and reinitialize them with features of the top $J$ most important voxels in the current batch [S1].
4.  **Joint Finetuning:** Fix and save the voxel-to-codebook mapping. Tune four parts: code vectors, density grid, non-VQ voxels, and the small network (if applicable) [S1].
    *   Update code vectors by synchronizing weights across assigned voxels every $i$ iterations [S1].
    *   For VQ-DVGO: 10,000 steps, 8196 rays/batch [S1].
    *   For VQ-Plenoxels: 25,600 steps, batch size 5000 [S1].
5.  **Post-Processing:**
    *   Apply 8-bit uniform weight quantization to density voxels and non-VQ feature voxels (cast full-precision float to unsigned int) [S1].
    *   Do not quantize the codebook [S1].
    *   Encode all components (mask, codebook, indices, quantized grids) with entropy encoding (LZ77) and pack together [S1].

def quantize_8bit(value):
    """Cast full-precision float to unsigned 8-bit integer."""
    # [G] Standard uniform quantization: clamp to [0, 1] or appropriate range, then scale to [0, 255]

    return int(max(0, min(255, value * 255)))

def euclidean_distance(v1, v2):
    return sum((a - b) ** 2 for a, b in zip(v1, v2)) ** 0.5

## Subtopics

### [VQRF (Vector Quantized Radiance Fields)](1903-vqrf-vector-quantized-radiance-fields.md)
VQRF is the specific implementation of Vector Quantization applied to Volumetric Radiance Fields, notably achieving high compression ratios (e.g., 75x for DVGO) with minimal quality loss. It is chosen when maximum compression is required for grid-based representations like DVGO, which have high redundancy. It differs from other VQ variants by its specific integration with the DVGO/Plenoxels/TensoRF architectures and the use of importance-score-based thresholding. Link: [VQRF](1903-vqrf-vector-quantized-radiance-fields.md).

### Flag-based Classified Hierarchical Vector Quantization
A dictionary-based method where each voxel is reconstructed on-the-fly by accessing selected codewords, supporting per-voxel random access [S3, unofficial]. It is a variant of VQ that uses a hierarchical structure with flags to classify voxels, potentially allowing for multi-resolution or multi-dictionary access [S3, unofficial]. It is chosen when hierarchical decomposition is beneficial for compression [S3, unofficial]. Link: [Flag-based Classified Hierarchical Vector Quantization](flag-based-classified-hierarchical-vector-quantization.md).

## Operating characteristics
*   **Time Complexity:** Reconstruction is linear $O(N)$, where $N$ is the number of blocks/voxels [S2][S3, unofficial].
*   **Memory Complexity:** Storage is reduced to codebook size $K \times C$ plus indices $\log_2(K)$ per voxel [S1].
*   **Measured Performance:** VQ-DVGO achieves 75x average compression on Synthetic-NeRF with 0.13 dB PSNR drop [S1]. VQ-Plenoxels achieves 20x compression with 0.2 dB drop [S1]. VQ-TensoRF achieves 20x compression [S1].
*   **Strengths:** High compression ratios, especially for redundant representations like DVGO; supports per-voxel random access; fast decoding on GPU [S1][S2][S3, unofficial].
*   **Limitations:** Requires finetuning which adds training time (50% of original for DVGO, 20% for Plenoxels) [S1]; inactive code issue requires careful management [S1]; quality loss increases with higher compression ratios [S1].
*   **When to use:** When storage/bandwidth is critical and the underlying representation (like DVGO) has high redundancy [S1].
*   **When not to use:** When the representation is already highly compact (like TensoRF) or when finetuning time is prohibitive [S1].

## Background
Vector Quantization for Volumetric Radiance Fields was introduced in the paper "Compressing Volumetric Radiance Fields to 1 MB" (CVPR 2023) [S1]. It builds on the observation that color features in volumetric grids have high redundancy and can be effectively compressed using a codebook [S1]. The method was developed to address the large model sizes of recent radiance field representations like DVGO, Plenoxels, and TensoRF [S1]. It is used in conjunction with these representations to enable efficient storage and transmission of neural radiance fields [S1].
