# Sparse Coding (K-SVD)

Also called: Compressive Volume Rendering via Dictionary Learning, Dictionary Learning for Volume Rendering, K-SVD, K-SVD Dictionary Learning

## Overview
Sparse Coding (K-SVD) compresses volume rendering data by learning an overcomplete dictionary from training images and representing image blocks as sparse linear combinations of dictionary atoms [S2, unofficial]. It differs from fixed-basis methods like DCT by adapting the basis to the specific statistical structure of the volume renderings, yielding higher reconstruction fidelity (PSNR) for the same or lower bitrates, particularly in recovering missing pixels or compressing at high rates [S2, unofficial]. It builds on [Neural Network and Deep Learning Compression](13849-neural-network-and-deep-learning-compression.md) by using data-driven representation learning and sparse latent codes, but replaces the neural network decoder with a linear combination of learned atoms [S1, unofficial][S2, unofficial].

## How it works
**Inputs:** A dataset of volume rendered images (grayscale or RGB) for training; a block size $B \times B$ (e.g., $16 \times 16$); a target dictionary size $D \times N$ (rows $\times$ columns); a sparsity constraint $L$ (maximum non-zero coefficients per block).
**Outputs:** A learned dictionary matrix $\mathbf{D}$ and, for each input block, a sparse coefficient vector $\mathbf{x}$.

**Data Structures:**
*   **Dictionary $\mathbf{D}$:** Matrix of size $D \times N$. Each column $\mathbf{d}_j$ is an atom. For grayscale, $D = B^2$ (e.g., 256 for $16 \times 16$ blocks). For RGB, $D = 3B^2$ (e.g., 768 for $16 \times 16 \times 3$ blocks). $N$ is the number of atoms (e.g., 1024 or 2304).
*   **Coefficient Matrix $\mathbf{X}$:** Matrix of size $N \times K$, where $K$ is the number of training blocks. Column $\mathbf{x}_i$ corresponds to the $i$-th training block.
*   **Training Data Matrix $\mathbf{Y}$:** Matrix of size $D \times K$, where column $\mathbf{y}_i$ is the $i$-th training block vectorized.

**Algorithm Steps:**
The K-SVD algorithm alternates between two steps until convergence [S2, unofficial]:

1.  **Sparse Coding Step:** Given the current dictionary $\mathbf{D}$, find the sparse coefficient matrix $\mathbf{X}$ that minimizes the reconstruction error subject to the sparsity constraint. This is solved independently for each column $\mathbf{y}_i$ of $\mathbf{Y}$:
    $$ \min_{\mathbf{x}_i} \|\mathbf{y}_i - \mathbf{D}\mathbf{x}_i\|_2^2 \quad \text{subject to} \quad \|\mathbf{x}_i\|_0 \leq L $$
    This is typically solved using Orthogonal Matching Pursuit (OMP) [S2, unofficial].

2.  **Dictionary Update Step:** Given the sparse coefficients $\mathbf{X}$, update the dictionary $\mathbf{D}$ to minimize the reconstruction error $\|\mathbf{Y} - \mathbf{D}\mathbf{X}\|_F^2$ without violating the sparsity pattern of $\mathbf{X}$ [S2, unofficial].
    *   For each atom $\mathbf{d}_j$ in $\mathbf{D}$:
        *   Identify the set of indices $\mathcal{K}_j = \{i \mid \mathbf{x}_i \neq 0 \text{ at position } j\}$ where atom $j$ is used.
        *   Define the residual matrix $\mathbf{E}_j = \mathbf{Y} - \sum_{k \neq j} \mathbf{d}_k \mathbf{x}_k^T$ (the error excluding the contribution of atom $j$).
        *   Let $\mathbf{X}_j$ be the submatrix of $\mathbf{X}$ containing only the rows corresponding to $\mathcal{K}_j$.
        *   Perform Singular Value Decomposition (SVD) on $\mathbf{E}_j \mathbf{X}_j^T = \mathbf{U} \mathbf{\Sigma} \mathbf{V}^T$.
        *   Update the atom $\mathbf{d}_j$ to the first column of $\mathbf{U}$ and the corresponding coefficient row $\mathbf{x}_j^T$ to the first row of $\mathbf{V}^T$ scaled by $\sigma_1$ (the largest singular value) [S2, unofficial].

**Pseudocode:**

```python
import numpy as np
from numpy.linalg import svd

def k_svd_train(Y, D_size, N_atoms, L_sparsity, max_iter=100):
    """
    Train a dictionary using K-SVD.
    Y: Training data matrix of shape (D_size, K), where K is number of blocks.
    D_size: Dimension of each block (e.g., 256 for 16x16 grayscale).
    N_atoms: Number of dictionary atoms (columns of D).
    L_sparsity: Maximum number of non-zero coefficients per block.
    max_iter: Maximum number of alternating steps.
    Returns:
        D: Learned dictionary of shape (D_size, N_atoms).
        X: Sparse coefficient matrix of shape (N_atoms, K).
    """
    K = Y.shape[1]
    # Initialize dictionary D randomly or using PCA
    D = np.random.randn(D_size, N_atoms)
    D = D / np.linalg.norm(D, axis=0) # Normalize columns to unit norm
    
    X = np.zeros((N_atoms, K))
    
    for iteration in range(max_iter):
        # Step 1: Sparse Coding (OMP)
        for i in range(K):
            y_i = Y[:, i]
            x_i = orthogonal_matching_pursuit(D, y_i, L_sparsity)
            X[:, i] = x_i
            
        # Step 2: Dictionary Update
        for j in range(N_atoms):
            # Find indices where atom j is used
            # Note: In practice, use a threshold or exact zero check
            indices = np.where(np.abs(X[j, :]) > 1e-10)[0]
            
            if len(indices) == 0:
                # Atom is not used, reinitialize or keep as is
                continue
                
            # Compute residual E_j excluding atom j
            # E_j = Y - sum_{k != j} d_k * x_k^T
            # Efficiently: E_j = Y - D @ X + d_j @ x_j^T
            E_j = Y - D @ X + D[:, j] * X[j, :]
            
            # Submatrix of X for indices where atom j is active
            X_j = X[indices, :] # Shape: (1, len(indices)) if we take row j
            # Actually, X_j should be the row j of X restricted to indices
            # Let's refine: X_j is 1 x len(indices)
            X_j = X[j, indices].reshape(1, -1)
            
            # Submatrix of E_j for indices where atom j is active
            E_j_indices = E_j[:, indices] # Shape: (D_size, len(indices))
            
            # Compute E_j * X_j^T
            # E_j_indices is D_size x M, X_j is 1 x M
            # We need E_j_indices * X_j^T -> D_size x 1
            product = E_j_indices @ X_j.T # Shape: (D_size, 1)
            
            # SVD of the product
            U, S, Vt = svd(product, full_matrices=False)
            
            # Update atom d_j and coefficient row x_j
            D[:, j] = U[:, 0]
            X[j, indices] = S[0] * Vt[0, :]
            
    return D, X

def orthogonal_matching_pursuit(D, y, L):
    """
    Simple OMP implementation for sparse coding.
    D: Dictionary (D_size, N_atoms)
    y: Signal (D_size,)
    L: Sparsity level
    Returns:
        x: Sparse coefficient vector (N_atoms,)
    """
    N_atoms = D.shape[1]
    x = np.zeros(N_atoms)
    residual = y.copy()
    indices = []
    
    for _ in range(L):
        # Find atom most correlated with residual
        correlations = np.abs(D.T @ residual)
        idx = np.argmax(correlations)
        
        if idx in indices:
            break
            
        indices.append(idx)
        
        # Solve least squares for selected atoms
        D_selected = D[:, indices]
        try:
            coeffs, _, _, _ = np.linalg.lstsq(D_selected, y, rcond=None)
            x[indices] = coeffs
            residual = y - D_selected @ coeffs
        except:
            break
            
    return x
```

**Parameters:**
*   **Block Size:** $16 \times 16$ pixels for grayscale; $16 \times 16 \times 3$ for RGB [S2, unofficial].
*   **Dictionary Size:** $256 \times 1024$ for grayscale; $768 \times 2304$ for RGB [S2, unofficial]. For 3D volume blocks, $D=1024$ atoms are used with block size $8 \times 8 \times 8$ voxels [S1, unofficial].
*   **Sparsity ($L$ or $K$):** 10 for grayscale dictionary learning [S2, unofficial]; 6 for Chameleon/Supernova datasets, 4 for Turbulence dataset [S1, unofficial].
*   **Training Data:** Rendered from multiple viewpoints (e.g., 35 views for training, 1 for testing) using a transfer function with dominant colors [S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Convergence:** The algorithm converges if the sparse coding step provides the best approximation to the signal with no more than $L$ non-zero entries [S2, unofficial].
*   **Initialization:** Random initialization may lead to poor local minima; PCA initialization is common but not specified in the source [G].
*   **RGB Handling:** Training separate dictionaries per channel is inefficient and ignores inter-channel correlations. Training on vectorized RGB blocks (linearized) captures correlations but increases dictionary size and training time (e.g., 47.3 minutes vs 7.1 minutes for grayscale) [S2, unofficial].
*   **Missing Pixels:** For recovery, the dictionary must be decimated ($\tilde{\mathbf{D}} = S\mathbf{D}$) and OMP solved on the subsampled signal [S2, unofficial].

## Subtopics

### [Orthogonal Matching Pursuit (OMP)](1999-orthogonal-matching-pursuit-omp.md)
Used as the sparse coding solver in K-SVD to find the sparse coefficient vector $\mathbf{x}$ for a given dictionary $\mathbf{D}$ and signal $\mathbf{y}$.

### [CP Decomposition](2255-cp-decomposition.md)
An alternative tensor factorization method for volume compression, using rank-one components instead of sparse linear combinations.

### [Tucker Decomposition (HOSVD)](5352-tucker-decomposition-hosvd.md)
Another tensor factorization method using a core tensor and factor matrices, differing from the sparse coding approach.

### [Karhunen-Loeve Transform (KLT)](5365-karhunen-loeve-transform-klt.md)
A linear decorrelation transform that finds an optimal orthogonal basis, unlike the overcomplete learned dictionary in K-SVD.

### [Sparse Representation (Dictionary Based)](5366-sparse-representation-dictionary-based.md)
The general framework of encoding data as sparse combinations of dictionary atoms, of which K-SVD is a specific algorithm for learning the dictionary.

## Operating characteristics
*   **Time Complexity:** Training is iterative and depends on the number of atoms, block size, and sparsity. For grayscale $16 \times 16$ blocks, training took 7.1 minutes on a single-threaded Intel Core i7-4770K CPU [S2, unofficial]. RGB training took 47.3 minutes [S2, unofficial]. Encoding (sparse coding) is fast using OMP.
*   **Memory Complexity:** Requires storing the dictionary $\mathbf{D}$ ($D \times N$ floats) and the sparse coefficients $\mathbf{X}$ for all blocks. For the grayscale case, $256 \times 1024$ floats for the dictionary [S2, unofficial].
*   **Performance:** Achieves bits-per-sample (bps) of 0.25 (Chameleon $1024^2$), 0.07 (Supernova 1080p), and 0.20 (Turbulence $512^4$) [S1, unofficial].
*   **Reconstruction Quality:** Trained dictionary achieves PSNR of 31.2 dB with 70% missing pixels, compared to 22.97 dB for a DCT dictionary [S2, unofficial]. Deblocked SSIM scores are 0.72 (Chameleon), 0.76 (Supernova), 0.84 (Turbulence) [S1, unofficial].
*   **Strengths:** Better reconstruction quality than fixed dictionaries (DCT) for the same redundancy; effective for missing pixel recovery and high compression rates [S2, unofficial].
*   **Limitations:** Requires training data; training time can be significant; encoding requires sparse coding step which can be slower than fixed-basis transforms [S2, unofficial].

## Background
K-SVD was introduced by M. Aharon, M. Elad, and A. Bruckstein in 2006 [S2, unofficial]. It is a generalization of K-Means clustering, alternating between sparse coding and dictionary updates. In volume rendering, it was applied by [S2, unofficial] for compressive volume rendering, treating rendered images as collections of pixel blocks to learn overcomplete dictionaries for compression and artifact reduction. It was also used by [S1, unofficial] for real-time deblocked GPU rendering of compressed volumes, achieving high compression rates with good visual quality.
