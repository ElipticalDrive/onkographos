# Rank-1 Tensor Approximation
Also called: CP Rank-1, Outer Product Approximation, Rank-1 Tensor Decomposition
## Overview
Rank-1 Tensor Approximation represents a volume dataset (modeled as an $N$-th order tensor) as a single outer product of basis vectors scaled by a scalar. It serves as the fundamental building block for higher-rank approximations (such as CP decomposition) and provides the simplest form of tensor factorization. It is distinguished from its siblings by its minimal structural complexity: unlike Tucker Decomposition which uses a core tensor, or Tensor-Train which uses a chain of cores, Rank-1 approximation uses no core tensor, relying solely on the alignment of mode vectors.
## How it works
**Inputs and Outputs:**
- Input: An $N$-th order real tensor $\mathbf{A} \in \mathbb{R}^{I_1 \times I_2 \times \dots \times I_N}$ representing the volume data.
- Output: A rank-1 approximation tensor $\tilde{\mathbf{A}}$ defined by a scalar $\lambda$ and $N$ basis vectors $\mathbf{u}^{(k)}$.

**Data Structures:**
- $\lambda \in \mathbb{R}$: A single scalar value.
- $\mathbf{u}^{(k)} \in \mathbb{R}^{I_k}$: A vector of length $I_k$ for each mode $k=1 \dots N$.
- Total storage: $1 + \sum_{k=1}^N I_k$ values, compared to $\prod_{k=1}^N I_k$ for the original tensor.

**Method:**
The rank-1 approximation $\tilde{\mathbf{A}}$ is constructed via the outer product of the basis vectors, scaled by $\lambda$ [S1, book]:

$$
\tilde{\mathbf{A}} = \lambda \cdot \mathbf{u}^{(1)} \otimes \mathbf{u}^{(2)} \otimes \dots \otimes \mathbf{u}^{(N)}
$$

Where $\otimes$ denotes the tensor product (outer product). The element at index $(i_1, i_2, \dots, i_N)$ is:

$$
\tilde{A}_{i_1, i_2, \dots, i_N} = \lambda \cdot u^{(1)}_{i_1} \cdot u^{(2)}_{i_2} \cdot \dots \cdot u^{(N)}_{i_N}
$$

**Computation Steps:**
1. **Initialization:** Define the target rank-1 structure.
2. **Optimization:** Determine $\lambda$ and $\mathbf{u}^{(k)}$ to minimize the reconstruction error $\|\mathbf{A} - \tilde{\mathbf{A}}\|_F^2$. This is typically solved using Alternating Least Squares (ALS) or Higher-Order Orthogonal Iteration (HOOI) [S1, book].
   - For a fixed set of vectors $\mathbf{u}^{(j)}$ ($j \neq k$), the optimal $\mathbf{u}^{(k)}$ is proportional to the matricization of $\mathbf{A}$ along mode $k$, multiplied by the other vectors.
   - The scalar $\lambda$ is often absorbed into one of the vectors (e.g., $\mathbf{u}^{(1)}$) to enforce unit norm constraints on others, or computed as the inner product of $\mathbf{A}$ with the normalized rank-1 tensor.
3. **Construction:** Compute the outer product of the optimized vectors and scale by $\lambda$.

**Pseudocode:**
```python
def rank_1_approximation(tensor_A, num_iterations=10):
    """
    Computes a rank-1 approximation of tensor A using ALS.
    tensor_A: N-dimensional numpy array.
    Returns: lambda, list of vectors [u1, u2, ..., uN]
    """
    N = tensor_A.ndim
    shapes = tensor_A.shape
    
    # Initialize vectors randomly or via SVD of mode-1 matricization
    vectors = []
    for k in range(N):
        # Matricize along mode k
        # Reshape tensor to (I_k, prod(other_dims))
        # Compute leading singular vector
        vectors.append(compute_first_singular_vector(tensor_A, k))
        
    for _ in range(num_iterations):
        for k in range(N):
            # Compute the product of all other vectors
            # This forms a vector of size prod(other_dims)
            other_vectors = vectors[:k] + vectors[k+1:]
            product_vector = reduce(lambda a, b: np.outer(a, b).flatten(), other_vectors)
            
            # Matricize A along mode k
            A_k = matricize_along_mode(tensor_A, k)
            
            # Update u_k: A_k * product_vector
            # Normalize to prevent scaling ambiguity
            u_k = A_k @ product_vector
            norm = np.linalg.norm(u_k)
            if norm > 0:
                u_k = u_k / norm
            vectors[k] = u_k
            
    # Compute lambda as the projection of A onto the rank-1 tensor
    # lambda = <A, u1 x u2 x ... x uN>
    # Efficiently computed by contracting A with all vectors
    lambda_val = contract_tensor_with_vectors(tensor_A, vectors)
    
    return lambda_val, vectors
```

**Edge Cases:**
- **Zero Tensor:** If $\mathbf{A}$ is zero, all vectors and $\lambda$ are zero.
- **Scaling Ambiguity:** The decomposition is not unique with respect to scaling; $\lambda \mathbf{u}^{(1)} \otimes \mathbf{u}^{(2)}$ is identical to $(\lambda c) (c^{-1}\mathbf{u}^{(1)}) \otimes \mathbf{u}^{(2)}$. Normalization (e.g., $\|\mathbf{u}^{(k)}\|=1$) is required for stable implementation [G].
- **Degenerate Input:** If the tensor has rank 0, approximation is trivial. If rank 1, error is zero.

## Subtopics

### Linear Combination of Rank-1 Approximations
Also known as: CP Decomposition, CANDECOMP/PARAFAC.
This variant extends the rank-1 approximation by summing $R$ rank-1 terms: $\tilde{\mathbf{A}} = \sum_{r=1}^R \lambda_r \cdot \mathbf{u}^{(1)}_r \otimes \mathbf{u}^{(2)}_r \otimes \dots \otimes \mathbf{u}^{(N)}_r$ [S1, book]. It is chosen when a single rank-1 tensor cannot capture the volume's complexity. It differs from Tucker Decomposition by using a diagonal core tensor (implicit in the sum) rather than a dense core, often leading to better interpretability and lower storage for sparse structures.

## Operating characteristics
**Time Complexity:**
- Computing the optimal rank-1 approximation via ALS is iterative. Each iteration involves matricization and matrix-vector multiplications, costing $O(N \cdot \prod I_k \cdot \max(I_k))$ per step. Convergence is not guaranteed to be global.
**Memory Complexity:**
- Storage is $O(\sum I_k)$, a significant reduction from $O(\prod I_k)$ for the full tensor.
**Strengths:**
- Maximum compression ratio for a single term.
- Simple structure.
**Limitations:**
- Poor approximation quality for complex, multi-component volume data (high rank).
- Sensitive to initialization.
**When to use:**
- When the volume data is dominated by a single coherent structure or trend.
- As a preliminary step or component in higher-rank decompositions.
**When not to use:**
- For general volume compression where high fidelity is required; use CP (Rank-R) or Tucker instead.
