# Tensor Approximation Decomposition via HOOI

Also called: HOOI-based Tensor Approximation, Higher-Order Orthogonal Iteration, TA with HOOI

## Overview
This method implements the decomposition phase of Tensor Approximation (TA) for structural 3D volume data using the Higher-Order Orthogonal Iteration (HOOI) algorithm [S1]. It reduces the dimensionality of volumetric datasets while preserving essential multiscale features and oriented patterns that axis-aligned methods like Wavelet Transform (WT) struggle to capture [S1]. Unlike its sibling [Tensor Approximation](5362-tensor-approximation.md) which defines the general Tucker model, this article specifies the iterative optimization procedure (HOOI) used to compute the basis matrices and core tensor [S2, book].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D volume tensor $\mathcal{A}$ of dimensions $I_1 \times I_2 \times I_3$ [S1].
*   **Input:** Target reduced ranks $R_1, R_2, R_3$ [S1].
*   **Output:** A core tensor $\mathcal{B}$ of dimensions $R_1 \times R_2 \times R_3$ and three basis matrices $\mathbf{U}^{(1)} \in \mathbb{R}^{I_1 \times R_1}$, $\mathbf{U}^{(2)} \in \mathbb{R}^{I_2 \times R_2}$, $\mathbf{U}^{(3)} \in \mathbb{R}^{I_3 \times R_3}$ [S1].

**Data Structures:**
*   $\mathcal{A}$: Dense 3D array or tensor [S1].
*   $\mathbf{U}^{(n)}$: Orthogonal matrices where columns represent the basis vectors for mode $n$ [S2, book].
*   $\mathcal{B}$: The core tensor containing the interaction coefficients between the basis vectors [S2, book].

**Steps:**
1.  **Define Initial Ranks:** Select the target ranks $R_1, R_2, R_3$ [S1]. A common scheme sets these to half the original dimensions, i.e., $R_n = I_n / 2$ for the first approximation level [S1].
2.  **Initialize Basis Matrices:** Generate an initial guess for the basis matrices $\mathbf{U}^{(n)}$ [S1]. The sources specify computing this initial guess based on eigenvalues [S1]. [G] In standard implementations, this involves computing the leading eigenvectors of the mode-$n$ matricizations of $\mathcal{A}$ to initialize $\mathbf{U}^{(n)}$.
3.  **Iterative Optimization (HOOI):** Perform the Higher-Order Orthogonal Iteration to optimize the basis matrices $\mathbf{U}^{(n)}$ and the core tensor $\mathcal{B}$ [S2, book]. The algorithm alternates between updating each basis matrix while holding others fixed, ensuring orthogonality [S2, book]. For each mode $n \in \{1, 2, 3\}$: compute the mode-$n$ matricization of the current core estimate, compute the leading $R_n$ eigenvectors of the covariance matrix derived from the other modes' basis matrices and the data, and update $\mathbf{U}^{(n)}$ with these eigenvectors [S2, book]. Repeat until a fixed number of iterations or convergence [S2, book].
4.  **Compute Core Tensor:** Once the basis matrices $\mathbf{U}^{(n)}$ are determined, compute the core tensor $\mathcal{B}$ using the Tensor Times Matrix (TTM) operation: $\mathcal{B} = \mathcal{A} \times_1 \mathbf{U}^{(1)T} \times_2 \mathbf{U}^{(2)T} \times_3 \mathbf{U}^{(3)T}$ [S1][S2, book].

**Pseudocode:**
```python
def hooci_decomposition(volume_A, ranks_R, max_iterations=50, tol=1e-6):
    """
    Decomposes volume A into core tensor B and basis matrices U using HOOI.
    Args:
        volume_A: 3D numpy array of shape (I1, I2, I3)
        ranks_R: Tuple (R1, R2, R3)
        max_iterations: Maximum number of HOOI passes [G]
        tol: Convergence tolerance for change in basis matrices [G]
    Returns:
        core_B: 3D numpy array of shape (R1, R2, R3)
        U: List of 3 matrices [U1, U2, U3]
    """
    I1, I2, I3 = volume_A.shape
    R1, R2, R3 = ranks_R

    # Step 1: Initialize basis matrices using eigenvalues [S1]
    # [G] Standard initialization: compute SVD of mode-n matricizations
    U1, _, _ = np.linalg.svd(volume_A.reshape(I1, I2 * I3), full_matrices=False)
    U1 = U1[:, :R1]
    U2, _, _ = np.linalg.svd(volume_A.transpose(1, 0, 2).reshape(I2, I1 * I3), full_matrices=False)
    U2 = U2[:, :R2]
    U3, _, _ = np.linalg.svd(volume_A.transpose(2, 0, 1).reshape(I3, I1 * I2), full_matrices=False)
    U3 = U3[:, :R3]

    prev_norm = float('inf')

    # Step 2: HOOI Iteration
    for iteration in range(max_iterations):
        # Update U1
        temp1 = np.tensordot(volume_A, U2.T, axes=([1], [0]))
        temp1 = np.tensordot(temp1, U3.T, axes=([1], [0]))
        M1 = temp1.reshape(I1, -1)
        U1, _, _ = np.linalg.svd(M1, full_matrices=False)
        U1 = U1[:, :R1]

        # Update U2
        temp2 = np.tensordot(volume_A, U1.T, axes=([0], [0]))
        temp2 = np.tensordot(temp2, U3.T, axes=([1], [0]))
        M2 = temp2.reshape(I2, -1)
        U2, _, _ = np.linalg.svd(M2, full_matrices=False)
        U2 = U2[:, :R2]

        # Update U3
        temp3 = np.tensordot(volume_A, U1.T, axes=([0], [0]))
        temp3 = np.tensordot(temp3, U2.T, axes=([1], [0]))
        M3 = temp3.reshape(I3, -1)
        U3, _, _ = np.linalg.svd(M3, full_matrices=False)
        U3 = U3[:, :R3]

        # Check convergence [G]
        current_norm = np.linalg.norm(U1) + np.linalg.norm(U2) + np.linalg.norm(U3)
        if abs(current_norm - prev_norm) < tol:
            break
        prev_norm = current_norm

    # Step 3: Compute Core Tensor B
    # B = A x1 U1^T x2 U2^T x3 U3^T
    core_B = np.tensordot(volume_A, U1.T, axes=([0], [0]))
    core_B = np.tensordot(core_B, U2.T, axes=([0], [0]))
    core_B = np.tensordot(core_B, U3.T, axes=([0], [0]))

    return core_B, [U1, U2, U3]
```

**Parameters:**
*   $R_n$: Target ranks. Typical value: $I_n / 2$ for the first approximation level [S1].
*   `max_iterations`: Not given in the sources. [G] Typically 10-50 iterations are sufficient for convergence in HOOI.

**Edge Cases and Pitfalls:**
*   **Rank Selection:** Choosing ranks too low may lose feature fidelity, while ranks too high reduce compression benefits [S1].
*   **Orthogonality:** Numerical instability can cause basis matrices to lose orthogonality. [G] Re-orthogonalization steps (e.g., QR decomposition) may be required after eigendecomposition.

## Operating characteristics
*   **Time Complexity:** Not given in the sources. [G] HOOI typically has complexity proportional to the number of iterations times the cost of matricization and eigendecomposition, which is $O(N \cdot I^3)$ for dense tensors of size $I \times I \times I$.
*   **Memory Complexity:** Not given in the sources. [G] Requires storing the core tensor and basis matrices, significantly less than the original volume if ranks are small.
*   **Strengths:** Captures oriented patterns and multiscale features better than axis-aligned methods like WT [S1]. Maintains feature fidelity at low ranks [S1].
*   **Limitations:** Not given in the sources.
*   **When to use:** When feature-aware compression of structural 3D volume data is required, especially for data with oriented patterns like tooth enamel growth lines [S1].
*   **When not to use:** When axis-aligned features dominate and simpler methods like WT are sufficient [S1].

## Background
The Higher-Order Orthogonal Iteration (HOOI) is an algorithm used to implement the tensor decomposition in the Tucker model [S2, book]. It has been applied to multiscale volume feature representations in medical imaging, such as pcST scans of tooth enamel [S1].
