# Column Subsampled SSVD for Tensor-Train Decomposition
Also called: Improved SSVD, SSVD with column subsampling

## Overview
This method computes the first step of the Tensor-Train (TT) decomposition by avoiding the expensive SVD on the full mode-1 unfolded matrix [S1][S2, unofficial]. It exploits the low-dimensional column space of the unfolded tensor to compute the required right singular vectors via column subsampling, thereby reducing memory usage and computational cost compared to standard SSVD [S1][S2, unofficial].

## How it works
**Inputs and Outputs**
- Input: A 4D tensor $\mathcal{T} \in \mathbb{R}^{N_1 \times N_2 \times N_3 \times N_4}$ and target TT ranks $R_1, R_2, R_3$ [S1][S2, unofficial].
- Output: The first TT core $C_1 \in \mathbb{R}^{1 \times N_1 \times R_1}$ and the intermediate matrix $V^\top \in \mathbb{R}^{R_1 \times (N_2 N_3 N_4)}$ which serves as the starting point for subsequent cores [S1][S2, unofficial].

**Data Structures**
The TT cores $C_i$ have shapes $\mathbb{R}^{R_{i-1} \times N_i \times R_i}$ with boundary ranks $R_0 = 1$ and $R_4 = 1$ [S1][S2, unofficial].
- $C_1$ is a matrix of shape $1 \times N_1 \times R_1$ [S1][S2, unofficial].
- $C_2$ is a 3D tensor of shape $R_1 \times N_2 \times R_2$ [S1][S2, unofficial].
- $C_3$ is a 3D tensor of shape $R_2 \times N_3 \times R_3$ [S1][S2, unofficial].
- $C_4$ is a matrix of shape $R_3 \times N_4 \times 1$ [S1][S2, unofficial].

**Algorithm**
1. **Mode-1 Unfolding**: Unfold $\mathcal{T}$ into a matrix $A \in \mathbb{R}^{N_1 \times (N_2 N_3 N_4)}$, where the first dimension corresponds to mode 1 and the second dimension is the product of the remaining modes [S1].
2. **Column Subsampling**: Recognize that $A$ is highly imbalanced with $N_1 \ll (N_2 N_3 N_4)$ [S1][S2, unofficial]. The linear column space of $A$ is spanned by at most $N_1$ linearly independent columns, making all other columns linearly dependent [S1][S2, unofficial]. A subset of columns is selected to compute $U$ [S2, unofficial].
3. **Subsampled SVD**: Compute the SVD of the selected columns to obtain the left singular vectors $U \in \mathbb{R}^{N_1 \times R_1}$ [S2, unofficial].
4. **Recover Right Singular Vectors**: Compute $V^\top$ using the relation $V^\top = U^\top A$ [S2, unofficial]. This avoids the expensive SVD computation on the full wide matrix $A$ [S2, unofficial].
5. **Form First Core**: Reshape $U$ into the first TT core $C_1$ of shape $1 \times N_1 \times R_1$ [S1][S2, unofficial].
6. **Iterate**: Use $V^\top$ as the input for the next step to compute $C_2$, continuing until all cores are obtained [S1].

**Pseudocode**
```python
def column_subsampled_ssvd(T, R1):
    """
    T: 4D tensor of shape (N1, N2, N3, N4)
    R1: Target rank for the first core
    Returns: C1 (shape 1 x N1 x R1), Vt (shape R1 x N2*N3*N4)
    """
    N1, N2, N3, N4 = T.shape
    
    # Step 1: Mode-1 unfolding
    # Reshape to (N1, N2*N3*N4)
    A = T.reshape(N1, -1)
    
    # Step 2: Column Subsampling
    # Select R1 columns from A. 
    # The exact selection strategy is not specified in the sources [G].
    # We assume deterministic selection of the first R1 columns for completeness.
    A_sub = A[:, :R1]
    
    # Step 3: Subsampled SVD
    # Compute SVD of the small matrix A_sub to get left singular vectors U
    # svd: standard linear algebra routine [G]
    U, S, Vt_sub = svd(A_sub, full_matrices=False)
    # U is (N1, R1)
    
    # Step 4: Recover Right Singular Vectors
    # Vt = U^T * A
    Vt = U.T @ A
    
    # Step 5: Form First Core
    # Reshape U into (1, N1, R1)
    C1 = U.reshape(1, N1, R1)
    
    return C1, Vt
```

**Parameters**
- $R_1$: The target rank for the first TT core. Typical values depend on the desired compression ratio and accuracy. Not given in the sources.

**Edge Cases and Pitfalls**
- **Imbalanced Matrix**: The matrix $A$ is highly imbalanced ($N_1 \ll N_2 N_3 N_4$), leading to linearly dependent columns [S1][S2, unofficial].
- **Memory Efficiency**: The method avoids explicit reshaping of the large matrix $V^\top$ by exploiting column-major storage, reducing memory overhead [S2, unofficial].
- **Selection Strategy**: The specific method for selecting the $R_1$ columns is not detailed in the sources [G].

## Operating characteristics
- **Time Complexity**: Not given in the sources.
- **Memory Complexity**: Significantly reduced as it avoids storing the full $N_1 \times (N_2 N_3 N_4)$ matrix explicitly in some implementations by leveraging storage layout [S2, unofficial].
- **Strengths**: Memory-efficient, avoids expensive SVD on large matrices [S1][S2, unofficial].
- **Limitations**: Not given in the sources.

## Background
This method is proposed in the context of Tensor-Train-based 4D time-dependent volume rendering [S1][S2, unofficial]. It is an improvement over the standard SSVD approach to reduce memory and time consumption [S1][S2, unofficial].
