# Tensor Approximation Decomposition via HOOI

Also called: HOOI-based Tensor Approximation, Higher-Order Orthogonal Iteration, TA with HOOI

## Overview
This method implements the decomposition phase of Tensor Approximation (TA) for structural 3D volume data using the Higher-Order Orthogonal Iteration (HOOI) algorithm [S1]. It solves the problem of reducing the dimensionality of volumetric datasets while preserving essential multiscale features and oriented patterns that axis-aligned methods like Wavelet Transform (WT) struggle to capture [S1]. Unlike its sibling [Tensor Approximation](5362-tensor-approximation.md) which defines the general Tucker model, this article specifies the iterative optimization procedure (HOOI) used to compute the basis matrices and core tensor [S2, book].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D volume tensor $\mathcal{A}$ of dimensions $I_1 \times I_2 \times I_3$.
*   **Input:** Target reduced ranks $R_1, R_2, R_3$.
*   **Output:** A core tensor $\mathcal{B}$ of dimensions $R_1 \times R_2 \times R_3$ and three basis matrices $\mathbf{U}^{(1)} \in \mathbb{R}^{I_1 \times R_1}$, $\mathbf{U}^{(2)} \in \mathbb{R}^{I_2 \times R_2}$, $\mathbf{U}^{(3)} \in \mathbb{R}^{I_3 \times R_3}$ [S1].

**Data Structures:**
*   $\mathcal{A}$: Dense 3D array or tensor.
*   $\mathbf{U}^{(n)}$: Orthogonal matrices where columns represent the basis vectors for mode $n$.
*   $\mathcal{B}$: The core tensor containing the interaction coefficients between the basis vectors.

**Steps:**
1.  **Define Initial Ranks:** Select the target ranks $R_1, R_2, R_3$. A common scheme sets these to half the original dimensions, i.e., $R_n = \lfloor I_n / 2 \rfloor$ for the first approximation level [S1].
2.  **Initialize Basis Matrices:** Generate an initial guess for the basis matrices. The sources specify computing this initial guess based on eigenvalues [S1]. [G] In standard HOOI implementations, this typically involves computing the leading eigenvectors of the mode-$n$ matricizations of $\mathcal{A}$ to initialize $\mathbf{U}^{(n)}$.
3.  **Iterative Optimization (HOOI):** Perform the Higher-Order Orthogonal Iteration to optimize the basis matrices $\mathbf{U}^{(n)}$ and the core tensor $\mathcal{B}$. The algorithm alternates between updating each basis matrix while holding others fixed, ensuring orthogonality [S2, book].
    *   For each mode $n \in \{1, 2, 3\}$:
        *   Compute the mode-$n$ matricization of the current core estimate.
        *   Compute the leading $R_n$ eigenvectors of the covariance matrix derived from the other modes' basis matrices and the data.
        *   Update $\mathbf{U}^{(n)}$ with these eigenvectors.
    *   Repeat until convergence or a fixed number of iterations [S2, book].
4.  **Compute Core Tensor:** Once the basis matrices $\mathbf{U}^{(n)}$ are determined, compute the core tensor $\mathcal{B}$ using the Tensor Times Matrix (TTM) operation: $\mathcal{B} = \mathcal{A} \times_1 \mathbf{U}^{(1)T} \times_2 \mathbf{U}^{(2)T} \times_3 \mathbf{U}^{(3)T}$ [S1][S2, book].

**Parameters:**
*   $R_n$: Target ranks. Typical value: $I_n / 2$ for the first approximation level [S1].

**Edge Cases and Pitfalls:**
*   **Rank Selection:** Choosing ranks too low may lose feature fidelity, while ranks too high reduce compression benefits [S1].
*   **Orthogonality:** Numerical instability can cause basis matrices to lose orthogonality. [G] Re-orthogonalization steps (e.g., QR decomposition) may be required after eigendecomposition.
*   **Convergence:** HOOI is guaranteed to converge to a local optimum, but the initial guess affects the result [S2, book].

## Operating characteristics
*   **Time Complexity:** Not given in the sources. [G] HOOI typically has complexity proportional to the number of iterations times the cost of matricization and eigendecomposition, which is $O(N \cdot I^3)$ for dense tensors of size $I \times I \times I$.
*   **Memory Complexity:** Not given in the sources. [G] Requires storing the core tensor and basis matrices, significantly less than the original volume if ranks are small.
*   **Strengths:** Captures oriented patterns and multiscale features better than axis-aligned methods like WT [S1]. Maintains feature fidelity at low ranks [S1].
*   **Limitations:** Struggles with curved structures if the tensor approximation rank is insufficient [S1].
*   **When to use:** When feature-aware compression of structural 3D volume data is required, especially for data with oriented patterns like tooth enamel growth lines [S1].
*   **When not to use:** When axis-aligned features dominate and simpler methods like WT are sufficient, or when real-time performance is critical and HOOI's iterative nature is too slow.

## Background
The Higher-Order Orthogonal Iteration (HOOI) was introduced by Lieven De Lathauwer, Bart De Moor, and Joos Vandewalle in 2000 [S2, book]. It is an algorithm used to implement the tensor decomposition in the Tucker model [S2, book]. The method is an improvement over the Higher-Order Singular Value Decomposition (HOSVD) in that it optimizes the core tensor to minimize the reconstruction error, whereas HOSVD uses a fixed core based on the initial basis matrices [S2, book]. It has been applied to multiscale volume feature representations in medical imaging, such as pcST scans of tooth enamel [S1].
