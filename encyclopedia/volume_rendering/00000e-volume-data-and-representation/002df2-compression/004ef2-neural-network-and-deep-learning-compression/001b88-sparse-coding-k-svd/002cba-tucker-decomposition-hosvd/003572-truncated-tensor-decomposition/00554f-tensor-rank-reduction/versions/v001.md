# Tensor Rank Reduction

Also called: Multiscale Approximation, Progressive Rank Reduction

## Overview
Tensor Rank Reduction is a technique that reconstructs a full-resolution volume at a coarser feature scale by selecting a subset of columns from the factor matrices and corresponding core tensor entries, thereby reducing the tensor rank [S1, unofficial]. It differs from spatial subsampling (which reduces resolution) by maintaining the original voxel grid while discarding high-frequency feature details [S1, unofficial]. It builds on [Truncated Tensor Decomposition](7540-truncated-tensor-decomposition.md) by explicitly choosing ranks $(R_1, R_2, ..., R_N)$ smaller than the initial decomposition ranks to achieve compression and adaptive visualization [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A Tucker decomposition of an input volume tensor $\mathbf{A} \in \mathbb{R}^{I_1 \times I_2 \times I_3}$, consisting of a core tensor $\mathbf{B} \in \mathbb{R}^{K_1 \times K_2 \times K_3}$ and factor matrices $\mathbf{U}^{(1)} \in \mathbb{R}^{I_1 \times K_1}$, $\mathbf{U}^{(2)} \in \mathbb{R}^{I_2 \times K_2}$, $\mathbf{U}^{(3)} \in \mathbb{R}^{I_3 \times K_3}$ [S1, unofficial].
*   **Output:** A rank-reduced approximation tensor $\tilde{\mathbf{A}}$ at full spatial resolution $I_1 \times I_2 \times I_3$ with reduced multilinear rank $(R_1, R_2, R_3)$ where $R_n \le K_n$ [S1, unofficial].

**Data Structures:**
*   **Core Tensor $\mathbf{B}$:** Stored as a 3D array of size $K_1 \times K_2 \times K_3$.
*   **Factor Matrices $\mathbf{U}^{(n)}$:** Stored as 2D arrays of size $I_n \times K_n$. Columns correspond to basis vectors for mode $n$.

**Parameters:**
*   **Target Ranks $(R_1, R_2, R_3)$:** The desired reduced ranks. A small $R_n$ removes many details (low-rank approximation), while a large $R_n$ preserves more features [S1, unofficial].
*   **Initial Ranks $(K_1, K_2, K_3)$:** The ranks of the initial decomposition (e.g., $256, 256, 256$) [S1, unofficial].

**Steps:**
1.  **Select Factor Columns:** For each mode $n \in \{1, 2, 3\}$, select the first $R_n$ columns from the factor matrix $\mathbf{U}^{(n)}$. Let the reduced factor matrix be $\tilde{\mathbf{U}}^{(n)} \in \mathbb{R}^{I_n \times R_n}$, where $\tilde{\mathbf{U}}^{(n)}[:, i] = \mathbf{U}^{(n)}[:, i]$ for $0 \le i < R_n$ [S1, unofficial].
2.  **Select Core Entries:** Extract the sub-tensor of $\mathbf{B}$ corresponding to the selected indices. Let the reduced core tensor be $\tilde{\mathbf{B}} \in \mathbb{R}^{R_1 \times R_2 \times R_3}$, where $\tilde{\mathbf{B}}[i, j, k] = \mathbf{B}[i, j, k]$ for $0 \le i < R_1, 0 \le j < R_2, 0 \le k < R_3$ [S1, unofficial].
3.  **Reconstruct:** Compute the approximation $\tilde{\mathbf{A}}$ using the multilinear product of the reduced components:
    $$ \tilde{\mathbf{A}} = \tilde{\mathbf{B}} \times_1 \tilde{\mathbf{U}}^{(1)} \times_2 \tilde{\mathbf{U}}^{(2)} \times_3 \tilde{\mathbf{U}}^{(3)} $$
    This results in a tensor of size $I_1 \times I_2 \times I_3$ [S1, unofficial].

**Pseudocode:**
```python
def tensor_rank_reduction(core_tensor, factor_matrices, target_ranks):
    """
    Performs progressive rank reduction on a Tucker decomposition.
    
    Args:
        core_tensor: 3D numpy array of shape (K1, K2, K3)
        factor_matrices: List of 3 numpy arrays, shapes (I1, K1), (I2, K2), (I3, K3)
        target_ranks: Tuple (R1, R2, R3)
        
    Returns:
        reconstructed_volume: 3D numpy array of shape (I1, I2, I3)
    """
    R1, R2, R3 = target_ranks
    
    # Step 1: Select subset of columns from factor matrices
    # U^(n)[:, :Rn] keeps the first Rn columns
    U1_reduced = factor_matrices[0][:, :R1]
    U2_reduced = factor_matrices[1][:, :R2]
    U3_reduced = factor_matrices[2][:, :R3]
    
    # Step 2: Select corresponding core tensor entries
    # B[:R1, :R2, :R3] keeps the sub-tensor defined by the ranks
    B_reduced = core_tensor[:R1, :R2, :R3]
    
    # Step 3: Reconstruct using multilinear product
    # A = B x1 U1 x2 U2 x3 U3
    # Implemented as sequential matrix multiplications along modes
    # Mode 1: reshape B to (R1, R2*R3), multiply by U1^T, reshape back
    B_reshaped = B_reduced.reshape(R1, -1)
    temp = B_reshaped @ U1_reduced.T # Shape: (R2*R3, I1)
    temp = temp.T.reshape(I1, R2, R3) # Shape: (I1, R2, R3)
    
    # Mode 2: reshape temp to (I1*R2, R3), multiply by U2^T, reshape back
    temp_reshaped = temp.reshape(I1 * R2, R3)
    temp = temp_reshaped @ U2_reduced.T # Shape: (I1*R2, I2)
    temp = temp.T.reshape(I2, I1, R3) # Shape: (I2, I1, R3)
    temp = temp.transpose(1, 0, 2) # Shape: (I1, I2, R3)
    
    # Mode 3: reshape temp to (I1*I2, R3), multiply by U3^T, reshape back
    temp_reshaped = temp.reshape(I1 * I2, R3)
    reconstructed_volume = temp_reshaped @ U3_reduced.T # Shape: (I1*I2, I3)
    reconstructed_volume = reconstructed_volume.reshape(I1, I2, I3)
    
    return reconstructed_volume
```

**Edge Cases and Pitfalls:**
*   **Core Tensor Ordering:** Unlike matrix SVD, core tensor coefficients in Tucker decomposition are not strictly decreasing [S1, unofficial]. Therefore, simply truncating based on coefficient magnitude is not standard; progressive reduction typically selects the first $R_n$ columns, assuming the initial decomposition (e.g., HOSVD) ordered them by importance [S1, unofficial].
*   **Precision:** Reconstruction at full resolution with low ranks may introduce significant approximation error, visible as blurring or loss of fine features [S1, unofficial].

## Subtopics

### Multiscale Tensor Approximation
A specific application where Tucker decompositions are generated at varying ranks $(R_1, R_2, ..., R_N)$ to create a hierarchy of approximations from one initial high-rank decomposition [S2, book]. It allows analyzing reconstruction error (RMSE) in a rate-distortion sense dependent on the number of coefficients [S2, book]. The initial decomposition is typically computed using HOSVD or HOOI, with an initial guess for Tucker ALS computed on eigenvalues [S2, book]. The error is defined as $\epsilon = \sum_{r,s,t} (A[r,s,t] - \tilde{A}[r,s,t])^2$, with RMSE $= \sqrt{\epsilon / (I_1 \cdot I_2 \cdot I_3)}$ [S2, book].

## Operating characteristics
*   **Time Complexity:** Reconstruction is $O(I_1 I_2 I_3 R_1 R_2 R_3)$ if computed naively, but can be optimized to $O(I_1 I_2 I_3 (R_1 + R_2 + R_3))$ using the sequential matrix multiplication approach shown in the pseudocode [S2, book].
*   **Memory Complexity:** The storage cost is dominated by the core tensor $R_1 R_2 R_3$ and factor matrices $I_1 R_1 + I_2 R_2 + I_3 R_3$ [S1, unofficial]. Reducing $R_n$ linearly reduces the core tensor size and the "active" part of the factor matrices used in reconstruction.
*   **Performance:** In a $512^3$ volume example, progressive reduction from rank $(256, 256, 256)$ to fixed ranks $R=4, 8, 16, 32, 64, 128, 256$ demonstrates that even low-rank approximations (e.g., $R=4$) capture main features while significantly reducing data size [S1, unofficial].
*   **Strengths:** Maintains full spatial resolution, enabling view-dependent adaptive LOD rendering without geometric distortion [S1, unofficial]. Efficient for interactive visualization where feature scale is more important than exact voxel values [S1, unofficial].
*   **Limitations:** Approximation quality degrades with lower ranks; not suitable if exact voxel values are required [S1, unofficial]. The lack of strict ordering in core tensors means rank selection is heuristic [S1, unofficial].

## Background
Tensor Approximation (TA) is a SVD/PCA-like approximation tool for higher-order data tensors [S1, unofficial]. In volume visualization, volumes are represented as third-order tensors [S1, unofficial]. The method was developed for multiresolution and adaptive visualization of large volume datasets, addressing challenges in interactive visual analysis [S1, unofficial]. It exploits TA properties for both spatial selection (subvolumes) and multiscale approximation (rank reduction) [S1, unofficial].
