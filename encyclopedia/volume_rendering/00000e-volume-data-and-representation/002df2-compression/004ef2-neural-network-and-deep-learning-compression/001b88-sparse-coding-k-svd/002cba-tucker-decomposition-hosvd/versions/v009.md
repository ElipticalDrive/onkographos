# Tucker Decomposition (HOSVD)

Also called: Higher-Order SVD, Higher-Order Singular Value Decomposition, Multilinear SVD, Tucker Model, Tucker Tensor Decomposition

## Overview
Tucker Decomposition (HOSVD) is a tensor factorization method that approximates an N-dimensional input tensor $\mathcal{A}$ by a core tensor $\mathcal{B}$ and a set of factor matrices $\mathbf{U}^{(n)}$, preserving orthonormality in the factor matrices [S1, S4, unofficial]. It solves the problem of compressing high-dimensional volume data by extracting multi-linear structures, offering a global basis generation that captures non-axis-aligned features more effectively than separable transforms like wavelets [S2, S3]. Unlike CP Decomposition, which yields a rank-R decomposition with a diagonal core, Tucker preserves orthonormal row and column vectors and provides strict error bounds, making it preferred when fidelity guarantees are required [S1, S4, unofficial].

## How it works
**Inputs:**
- Input tensor $\mathcal{A} \in \mathbb{R}^{I_1 \times I_2 \times \dots \times I_N}$ [S1, unofficial].
- Multilinear rank $(R_1, R_2, \dots, R_N)$, where $R_n \le I_n$ [S1, unofficial]. Typical initial choice is $R_n = I_n / 2$ [S2, S3].

**Outputs:**
- Core tensor $\mathcal{B} \in \mathbb{R}^{R_1 \times R_2 \times \dots \times R_N}$ [S1, unofficial].
- Factor matrices $\mathbf{U}^{(n)} \in \mathbb{R}^{I_n \times R_n}$ for $n=1 \dots N$, with orthonormal columns [S1, unofficial].

**Data Structures:**
- **Tensor Unfolding (Matricization):** $\mathcal{A}$ is reshaped into matrix $A^{(n)} \in \mathbb{R}^{I_n \times (I_1 \dots I_{n-1} I_{n+1} \dots I_N)}$ by stacking mode-$n$ fibers as columns [S1, unofficial].
- **SVD Output:** $A^{(n)} = U^{(n)} \Sigma^{(n)} V^{(n)T}$, where $U^{(n)}$ contains left singular vectors [S1, unofficial].

**Steps:**
1. **Unfold:** For each mode $n \in \{1, \dots, N\}$, unfold $\mathcal{A}$ into $A^{(n)}$ [S1, unofficial].
2. **SVD:** Compute the matrix SVD of $A^{(n)}$ [S1, unofficial]:
   $$A^{(n)} = U^{(n)} \Sigma^{(n)} V^{(n)T}$$
3. **Truncate:** Select the $R_n$ leading left singular vectors from $U^{(n)}$ to form the basis matrix $\mathbf{U}^{(n)} \in \mathbb{R}^{I_n \times R_n}$ [S1, unofficial].
4. **Core Computation:** Compute the core tensor $\mathcal{B}$ by projecting $\mathcal{A}$ onto the transposes of the factor matrices [S1, unofficial]:
   $$\mathcal{B} = \mathcal{A} \times_1 \mathbf{U}^{(1)T} \times_2 \mathbf{U}^{(2)T} \times_3 \cdots \times_N \mathbf{U}^{(N)T}$$
   Element-wise, this is:
   $$b_{r_1 r_2 \dots r_N} = \sum_{i_1=1}^{I_1} \sum_{i_2=1}^{I_2} \dots \sum_{i_N=1}^{I_N} a_{i_1 i_2 \dots i_N} \cdot u_{i_1, r_1}^{(1)} \cdot u_{i_2, r_2}^{(2)} \cdots u_{i_N, r_N}^{(N)}$$
   [S1, unofficial].
5. **Reconstruction (Optional):** The approximation $\hat{\mathcal{A}}$ is given by:
   $$\hat{\mathcal{A}} = \mathcal{B} \times_1 \mathbf{U}^{(1)} \times_2 \mathbf{U}^{(2)} \times_3 \cdots \times_N \mathbf{U}^{(N)}$$
   [S1, unofficial].

**Pseudocode:**
```python
def hosvd(tensor_A, ranks):
    """
    Computes the Higher-Order SVD (HOSVD) of a tensor.
    
    Args:
        tensor_A: numpy array of shape (I1, I2, ..., IN)
        ranks: list of integers [R1, R2, ..., RN]
        
    Returns:
        core_B: numpy array of shape (R1, R2, ..., RN)
        U_matrices: list of numpy arrays, where U_matrices[n] has shape (In, Rn)
    """
    N = tensor_A.ndim
    U_matrices = []
    
    # Step 1-3: Compute factor matrices via mode-n SVD
    for n in range(N):
        # Unfold tensor along mode n
        # A(n) has shape (In, product of all other dimensions)
        A_n = numpy.moveaxis(tensor_A, n, 0)
        A_n = A_n.reshape(A_n.shape[0], -1)
        
        # Compute SVD
        # We only need the left singular vectors (U)
        # Using a standard SVD routine
        U, S, Vt = numpy.linalg.svd(A_n, full_matrices=False)
        
        # Truncate to rank Rn
        Rn = ranks[n]
        U_truncated = U[:, :Rn]
        
        U_matrices.append(U_truncated)
        
    # Step 4: Compute core tensor
    # B = A x1 U1^T x2 U2^T ... xN UN^T
    # Start with the original tensor
    core_B = tensor_A
    
    for n in range(N):
        # n-mode product with U_n^T
        # core_B = core_B x_n U_n^T
        # This contracts the n-th mode of core_B with U_n^T
        # Resulting shape: (I1, ..., Rn, ..., IN)
        U_T = U_matrices[n].T # Shape (Rn, In)
        
        # Perform n-mode product
        # Reshape core_B to matrix where mode n is the first dimension
        core_B_moved = numpy.moveaxis(core_B, n, 0)
        core_B_flat = core_B_moved.reshape(core_B_moved.shape[0], -1)
        
        # Multiply: (Rn, In) @ (In, Rest) -> (Rn, Rest)
        core_B_flat = numpy.dot(U_T, core_B_flat)
        
        # Reshape back to tensor shape
        new_shape = list(core_B.shape)
        new_shape[n] = Rn
        core_B = core_B_flat.reshape(new_shape)
        
    return core_B, U_matrices
```

**Edge Cases and Pitfalls:**
- **Non-uniqueness:** The Tucker decomposition is not unique; core tensor rotations (modifying $\mathcal{B}$ and $\mathbf{U}$ simultaneously) do not affect the model fit [S1, unofficial].
- **Core Size:** Standard HOSVD produces a core tensor $\mathcal{B}$ with the same size as input $\mathcal{A}$ if $R_n = I_n$, and quadratic factor matrices. Rank-reduced versions are required for compression [S1, unofficial].
- **Memory:** Large volumes require memory-mapped files and parallel memory-aligned matrix-matrix multiplications during unfolding and SVD [S2].

## Subtopics

### [Tensor Approximation](5362-tensor-approximation.md)
Tensor Approximation (TA) is a framework for data reduction and feature extraction in volume rendering that transforms multidimensional datasets into compact representations via tensor decomposition and reconstructs them via tensor reconstruction. It solves the problem of storing and rendering massive volume datasets by factorizing the data into a core tensor and factor matrices, allowing for high compression ratios while preserving specific structural features. Unlike standard Level-of-Detail (LOD) reduction which typically results in blurring, rank-reduced TA removes small-scale features in a way that highlights specific structural features at different spatial scales, such as non-axis aligned patterns. It is distinguished from wavelet transforms by its ability to capture non-axis aligned features more effectively with the same number of coefficients, though wavelets may still outperform TA in reconstructing overall statistical distributions at coarse resolutions.

### [Tensor-Specific Quantization](6775-tensor-specific-quantization.md)
Tensor-Specific Quantization is a fixed bit-length encoding strategy used to compactly represent Tucker decomposition coefficients, thereby reducing disk-to-host-to-device bandwidth during volume rendering. It distinguishes itself from generic floating-point storage by applying uniform linear quantization to factor matrices and logarithmic quantization to the core tensor, a design choice that simplifies parallel decoding on the GPU.

### [Truncated Tensor Decomposition](7540-truncated-tensor-decomposition.md)
Truncated Tensor Decomposition is a post-processing technique that reduces the multilinear rank of an already computed Tucker decomposition to achieve data compression or interactive level-of-detail (LOD). It solves the problem of balancing reconstruction fidelity against storage and computational cost by explicitly selecting a reduced rank $(R'_1, R'_2, ..., R'_N)$ smaller than the original Tucker rank $(R_1, R_2, ..., R_N)$. Unlike [Tensor Approximation](5362-tensor-approximation.md), which computes the decomposition from scratch to find the optimal rank, or [Tensor-Specific Quantization](6775-tensor-specific-quantization.md), which focuses on bit-depth reduction, Truncated Tensor Decomposition leverages the all-orthogonality property of the Tucker core to allow progressive, ex-post truncation without recomputing the full decomposition.

### [Spatial Selectivity](15073-spatial-selectivity.md)
Spatial Selectivity is a property of Tensor Approximation (TA) that allows the reconstruction of a specific spatial subvolume by selecting a subset of rows from the factor matrices corresponding to the spatial dimensions. It enables efficient access to spatially restricted data without reconstructing the full volume, which is distinct from sibling methods like [Truncated Tensor Decomposition](7540-truncated-tensor-decomposition.md) that reduce rank globally.

### Tensor Rank Definitions
- **n-rank:** The n-rank of a tensor $\mathcal{A}$, denoted $R_n = \text{rank}_n(\mathcal{A})$, is the dimension of the vector space spanned by mode-n vectors, which are the column vectors of the unfolding $A^{(n)}$ [S1, unofficial].
- **Multilinear Rank:** A higher-order tensor has a multilinear rank $(R_1, R_2, \dots, R_N)$ if its mode-1 rank through mode-N rank are equal to $R_1, R_2, \dots, R_N$ [S1, unofficial].
- **Rank-one Tensor:** A rank-one tensor (Kruskal tensor) is an N-way tensor expressible as the outer product of N vectors: $\mathcal{A} = \mathbf{b}^{(1)} \circ \mathbf{b}^{(2)} \circ \dots \circ \mathbf{b}^{(N)}$ [S1, unofficial].
- **Tensor Rank:** The tensor rank $R = \text{rank}(\mathcal{A})$ is the minimal number of rank-one tensors that yield $\mathcal{A}$ in a linear combination [S1, unofficial]. It always holds that $R_n \le R$ [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Dominated by the SVD computations on unfolded matrices. For an $N$-dimensional tensor of size $I^N$, unfolding creates matrices of size $I \times I^{N-1}$. SVD on these matrices is costly, typically $O(I^2 I^{N-1})$ or $O(I^{N+1})$ per mode, leading to $O(N I^{N+1})$ total time for the basis generation [S1, unofficial][S2].
- **Memory Complexity:** Requires storing the input tensor, all unfolded matrices (temporarily), and the factor matrices. For large volumes, memory-mapped files are necessary [S2]. The core tensor size is $\prod R_n$, and factor matrices total $\sum I_n R_n$.
- **Performance:** HOSVD is an offline step. Reconstruction is fast, involving tensor-times-matrix products [S4, unofficial].
- **Strengths:** Provides orthonormal bases, error bounds, and captures non-axis-aligned features better than separable transforms [S3][S4, unofficial].
- **Limitations:** Computationally expensive for large datasets; core tensor can be large if ranks are not truncated [S1, unofficial][S2].

## Background
Tucker Decomposition, also known as the Tucker Model, is a generalization of Principal Component Analysis (PCA) and Matrix SVD to higher-order tensors [S1, S4, unofficial]. It was introduced by Hitchcock in 1927 [S1, unofficial]. The Higher-Order SVD (HOSVD) algorithm was formalized by De Lathauwer, De Moor, and Vandewalle in 2000 [S1, unofficial]. In volume rendering, it has been adapted for Tensor Approximation (TA) to enable multiresolution visualization, notably by Suter et al. [SMP13] and Ballester-Ripoll et al. [S4, unofficial].
