# Random Column Sampling for SVD Approximation
Also called: Random Submatrix SVD

## Overview
A method to compute the first $R_i$ left singular vectors of a wide matrix $A \in \mathbb{R}^{M \times N}$ (where $M \ll N$) by applying SVD only to a randomly selected submatrix of columns [S1][S2, unofficial]. It leverages the fact that the column space of such matrices is highly over-defined, allowing a subset of columns to span the same space as the full matrix [S2, unofficial]. It is distinguished from its sibling [Alternating MaxVol Column Sampling](14048-alternating-maxvol-column-sampling.md) by its simplicity and lower computational cost, though it sacrifices the guarantee of optimal column selection [S1][S2, unofficial].

## How it works
**Inputs:**
- Matrix $A \in \mathbb{R}^{M \times N}$ with $M \ll N$ [S1][S2, unofficial].
- Target rank $R_i$ (number of left singular vectors to compute) [S1].
- Oversampling parameter $p \ge 0$ [S1][S2, unofficial].

**Outputs:**
- Matrix $U_{sub} \in \mathbb{R}^{M \times R_i}$ containing the first $R_i$ left singular vectors of $A$ [S1][S2, unofficial].

**Data Structures:**
- $A_{sub} \in \mathbb{R}^{M \times (R_i + p)}$: The randomly selected submatrix [S1][S2, unofficial].

**Parameters:**
- $R_i$: The desired number of singular vectors [S1].
- $p$: Oversampling parameter. Typical values are not explicitly given in the sources [S1][S2, unofficial].

**Steps:**
1. Randomly select $R_i + p$ distinct column indices from $\{1, \dots, N\}$ to form the selection set [S1][S2, unofficial].
2. Extract the columns of $A$ indexed by the selection set to form the submatrix $A_{sub}$ [S1][S2, unofficial].
3. Compute the SVD of $A_{sub}$ to obtain its left singular vectors [S1][S2, unofficial].
4. Check if $A_{sub}$ has full rank. If not, the selected columns do not contain $R_i$ linearly independent vectors; select a new set of random columns and repeat from Step 1 [S1][S2, unofficial].
5. If $A_{sub}$ has full rank, return the first $R_i$ left singular vectors as the approximation [S1][S2, unofficial].

**Pseudocode:**
```python
import random
import numpy as np

def random_column_sampling_svd(A, R_i, p):
    """
    Compute the first R_i left singular vectors of A using random column sampling.
    
    Args:
        A: Matrix of shape (M, N) where M << N.
        R_i: Number of left singular vectors to compute.
        p: Oversampling parameter (p >= 0).
        
    Returns:
        U_sub: Matrix of shape (M, R_i) containing the first R_i left singular vectors.
    """
    M, N = A.shape
    num_cols = R_i + p
    
    while True:
        # Step 1: Randomly select R_i + p distinct column indices
        indices = random.sample(range(N), num_cols)
        
        # Step 2: Form submatrix A_sub
        A_sub = A[:, indices]
        
        # Step 3: Compute SVD on A_sub
        # [G] Standard linear algebra routine for SVD
        U_sub, S_sub, V_sub_T = np.linalg.svd(A_sub, full_matrices=False)
        
        # Step 4: Check if A_sub has full rank
        # [G] Standard numerical threshold for rank deficiency
        if len(S_sub) >= R_i and S_sub[R_i - 1] > 1e-10:
            # Step 5: Return first R_i left singular vectors
            return U_sub[:, :R_i]
        # If not full rank, loop continues to select a new set of random columns
```

**Edge Cases and Pitfalls:**
- **Singular Vectors Representation:** Random sampling does not guarantee the best column set. The resulting singular vectors may not represent the matrix $A$ well if the random selection misses important structural columns [S1][S2, unofficial].
- **Rank Deficiency:** If $p=0$, the probability of selecting $R_i$ linearly independent vectors is lower. With $p>0$, the chance is very high because more columns than needed are chosen [S1][S2, unofficial].
- **Numerical Stability:** The check for full rank must account for numerical precision [G].

## Subtopics

### Alternating MaxVol Column Sampling
Uses the maxvol algorithm to iteratively select rows and columns to maximize the volume of the submatrix, offering better accuracy than random sampling but at higher computational cost. See [Alternating MaxVol Column Sampling](14048-alternating-maxvol-column-sampling.md).

## Operating characteristics
- **Time Complexity:** Not given in the sources. The method is described as more time-efficient than the maximum volume approach [S1][S2, unofficial].
- **Memory Complexity:** Not given in the sources. The method is described as more memory-efficient than the maximum volume approach [S1][S2, unofficial].
- **Strengths:** Simple to implement, computationally efficient, suitable for very wide matrices where $M \ll N$ [S1][S2, unofficial].
- **Limitations:** Does not guarantee optimal column selection; accuracy depends on the randomness of the selection and the oversampling parameter $p$ [S1][S2, unofficial].
- **When to use:** Not given in the sources.
- **When not to use:** Not given in the sources.

## Background
The method is presented in the paper *TT4D: Tensor‐Train‐based 4D Time‐Dependent Volume Rendering* [S1][S2, unofficial]. It is one of two efficient methods proposed for selecting a submatrix to compute left singular vectors, the other being the maximum volume approximation approach [S1][S2, unofficial]. The approach leverages the over-defined nature of the column space in wide, imbalanced matrices [S2, unofficial].
