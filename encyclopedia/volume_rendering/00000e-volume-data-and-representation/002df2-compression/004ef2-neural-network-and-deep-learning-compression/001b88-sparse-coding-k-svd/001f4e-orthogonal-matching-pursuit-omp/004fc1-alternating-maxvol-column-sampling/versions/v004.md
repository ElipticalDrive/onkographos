# Alternating MaxVol Column Sampling

Also called: Alternating Maximum Volume Approximation for Column Sampling, Alternating maximum volume approximation, Iterative MaxVol column selection, MaxVol with random preselection, maxvol

## Overview
Alternating MaxVol Column Sampling selects a subset of columns from a wide matrix $A \in \mathbb{R}^{M \times N}$ (where $M \ll N$) to approximate its column space, enabling efficient low-rank approximations such as computing left singular vectors via SVD on a small submatrix [S1][S2, unofficial]. It distinguishes itself from [Random Column Sampling for SVD Approximation](14052-random-column-sampling-for-svd-approximation.md) by iteratively maximizing the volume of the selected submatrix to guarantee a better basis representation, whereas random sampling sacrifices this guarantee for lower computational cost [S1][S2, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Matrix $A \in \mathbb{R}^{M \times N}$ with $M < N$, target rank $R$, oversampling parameter $p \ge 0$, oversampling factor $F$, and maximum iterations `max_iter` [S1][S2, unofficial].
- Output: A submatrix $A_{sub} \in \mathbb{R}^{M \times K}$ (where $K \approx R+p$) consisting of selected columns from $A$ [S1][S2, unofficial].

**Data Structures:**
- $A$: The input matrix [S1][S2, unofficial].
- $A_{sub}$: The current candidate submatrix, initialized to a random subset of columns [S1][S2, unofficial].
- $I$: A list of integer indices for random subsampling [S1][S2, unofficial].
- $A'_{sub}$: A row-subsampled version of $A_{sub}$ [S1][S2, unofficial].
- $R_{mat}$: A row-submatrix of $A$ defined by selected row indices (renamed from the source's $R$ to avoid collision with the rank parameter) [S1][S2, unofficial].
- $R'_{sub}$: A column-subsampled version of $R_{mat}$ [S1][S2, unofficial].
- $I_r$: Indices of selected rows returned by `maxvol` [S1][S2, unofficial].
- $I_c$: Indices of selected columns returned by `maxvol` [S1][S2, unofficial].

**Parameters:**
- $R$: The target rank (number of singular vectors or independent columns desired) [S1][S2, unofficial].
- $p$: Oversampling parameter added to $R$ to ensure linear independence. Typical value: $p \ge 0$ [S1][S2, unofficial].
- $F$: Oversampling factor used to subsample rows/columns before applying maxvol to reduce intermediate matrix size. It multiplies $(R + p)$ [S1][S2, unofficial].
- `max_iter`: Maximum number of iterations for the alternating loop [S1][S2, unofficial].

**Algorithm Steps:**
1. **Initialization**: Select $I_c$ as $(R + p)$ random, uniform column indices from $A$. Initialize $A_{sub} \leftarrow A[:, I_c]$ [S1][S2, unofficial].
2. **Iteration Loop**: For $i = 0$ to `max_iter`:
    a. **Sample Rows**:
        i. Compute the number of rows to sample: $N_{rows} = F \cdot (R + p)$ [S1][S2, unofficial].
        ii. Select $I$ as $N_{rows}$ random row indices from $A_{sub}$ [S1][S2, unofficial].
        iii. Form the row submatrix $A'_{sub} \leftarrow A_{sub}[I, :]$ [S1][S2, unofficial].
        iv. Compute row indices $I_r$ returned by the `maxvol` algorithm applied to $A'_{sub}$ [S1][S2, unofficial].
        v. Let $R_{mat} \leftarrow A[I_r, :]$ be the submatrix of the original matrix $A$ containing the selected rows [S1][S2, unofficial].
    b. **Sample Columns**:
        i. Compute the number of columns to sample: $N_{cols} = F \cdot (R + p)$ [S1][S2, unofficial].
        ii. Select $I$ as $N_{cols}$ random column indices from $R_{mat}$ [S1][S2, unofficial].
        iii. Form the column submatrix $R'_{sub} \leftarrow R_{mat}[:, I]$ [S1][S2, unofficial].
        iv. Compute column indices $I_c$ returned by the `maxvol` algorithm applied to $R'_{sub}$ [S1][S2, unofficial].
        v. Update $A_{sub} \leftarrow A[:, I_c]$ using the new column indices from the original matrix $A$ [S1][S2, unofficial].
3. **Return**: Return $A_{sub}$ [S1][S2, unofficial].

**Pseudocode:**
```python
def alternating_maxvol_column_sampling(A, R, p, F, max_iter):
    """
    Selects a subset of columns from wide matrix A using alternating MaxVol.
    
    Args:
        A: Input matrix of shape (M, N) where M < N.
        R: Target rank.
        p: Oversampling parameter (p >= 0).
        F: Oversampling factor for subsampling.
        max_iter: Maximum number of alternating iterations.
        
    Returns:
        A_sub: Submatrix of A with selected columns.
    """
    M, N = A.shape
    
    # Step 1: Initialization
    # Select R + p random column indices
    num_init_cols = R + p
    Ic = random.sample(range(N), num_init_cols)
    A_sub = A[:, Ic]
    
    # Step 2: Iterative Alternating Selection
    for i in range(max_iter):
        # --- Row Sampling Phase ---
        # Calculate number of rows to sample
        num_rows_to_sample = int(F * (R + p))
        
        # Get current number of rows in A_sub
        current_rows = A_sub.shape[0]
        
        # Sample random row indices from A_sub
        I = random.sample(range(current_rows), num_rows_to_sample)
        
        # Form row submatrix A'_sub
        A_prime_sub = A_sub[I, :]
        
        # Apply maxvol to A'_sub to get row indices Ir
        Ir = maxvol_pivot_exchange(A_prime_sub)
        
        # Extract rows from original matrix A using Ir
        # Ir are indices relative to A'_sub, which map directly to A's rows
        R_mat = A[Ir, :]
        
        # --- Column Sampling Phase ---
        # Calculate number of columns to sample
        num_cols_to_sample = int(F * (R + p))
        
        # Get current number of columns in R_mat
        current_cols = R_mat.shape[1]
        
        # Sample random column indices from R_mat
        I = random.sample(range(current_cols), num_cols_to_sample)
        
        # Form column submatrix R'
        R_prime_sub = R_mat[:, I]
        
        # Apply maxvol to R' to get column indices Ic
        Ic = maxvol_pivot_exchange(R_prime_sub)
        
        # Update A_sub using new column indices from original matrix A
        # Ic are indices relative to R_prime_sub, which map directly to A's columns
        A_sub = A[:, Ic]
        
    return A_sub

def maxvol_pivot_exchange(submatrix):
    """
    Standard iterative pivot exchange to find a submatrix with maximum volume [G].
    Returns the indices of the rows/columns forming this submatrix.
    """
    m, n = submatrix.shape
    k = min(m, n)
    # Initialize with first k indices
    row_idx = list(range(k))
    col_idx = list(range(k))
    
    for _ in range(10):  # Standard pivot exchange iterations [G]
        improved = False
        for r in range(m):
            if r in row_idx:
                continue
            # Compute volume if we swap row r with each row in row_idx
            for j, old_r in enumerate(row_idx):
                # Calculate determinant change using Sherman-Morrison or LU updates [G]
                # For simplicity, we compute the full determinant of the swapped submatrix
                new_row_idx = row_idx[:j] + [r] + row_idx[j+1:]
                sub = submatrix[new_row_idx, :]
                sub = sub[:, col_idx]
                vol = abs(linalg.det(sub))
                old_vol = abs(linalg.det(submatrix[row_idx, :][:, col_idx]))
                if vol > old_vol:
                    row_idx[j] = r
                    improved = True
                    break
            if improved:
                break
        if not improved:
            break
    return row_idx
```

**Edge Cases and Pitfalls:**
- **Large N**: If $N$ (number of columns) is very large, the `maxvol` algorithm computes an intermediate $N \times N$ matrix, which is expensive in memory and computation [S1][S2, unofficial]. Random subsampling (using factor $F$) is applied before calling `maxvol` to mitigate this cost [S1][S2, unofficial].
- **Linear Independence**: The oversampling parameter $p$ ensures that the selected columns are likely to be linearly independent [S1][S2, unofficial]. If the selected set does not contain $R$ linearly independent vectors, the subsequent SVD will fail or produce poor results [S2, unofficial].

## Subtopics

### [Random Column Sampling for SVD Approximation](14052-random-column-sampling-for-svd-approximation.md)
A method to compute the first $R_i$ left singular vectors of a wide matrix $A \in \mathbb{R}^{M \times N}$ (where $M \ll N$) by applying SVD only to a randomly selected submatrix of columns. It leverages the fact that the column space of such matrices is highly over-defined, allowing a subset of columns to span the same space as the full matrix. It is distinguished from its sibling [Alternating MaxVol Column Sampling](14048-alternating-maxvol-column-sampling.md) by its simplicity and lower computational cost, though it sacrifices the guarantee of optimal column selection.

## Operating characteristics
- **Time Complexity**: The complexity is dominated by the `maxvol` calls within each iteration [S1][S2, unofficial]. Each `maxvol` call on a submatrix of size roughly $F(R+p) \times F(R+p)$ is significantly cheaper than operating on the full $N \times N$ matrix, but the exact complexity depends on the `maxvol` implementation [S1][S2, unofficial]. The alternating loop runs `max_iter` times [S1][S2, unofficial].
- **Memory Complexity**: By subsampling rows and columns before applying `maxvol`, the method avoids storing large intermediate $N \times N$ matrices, reducing memory usage compared to full SVD or naive MaxVol on the entire matrix [S1][S2, unofficial].
- **Measured Performance**: Not given in the sources.
- **Scaling**: The method scales well to large $N$ due to the random preselection subsampling step [S1][S2, unofficial].
- **Strengths**: Guarantees a better basis representation than random sampling by maximizing the volume spanned by the selected columns [S1][S2, unofficial]. Efficient for wide matrices where $M \ll N$ [S1][S2, unofficial].
- **Limitations**: Requires tuning of parameters $F$, $p$, and `max_iter` [S1][S2, unofficial].
- **When to use**: When a high-quality low-rank approximation is needed for a wide matrix, and random sampling is insufficient to capture the column space accurately [S1][S2, unofficial].

## Background
- **Origin**: The method is based on the maximum volume approximation (maxvol) approach [MO15] and was presented in the context of Tensor-Train-based 4D Time-Dependent Volume Rendering [S1][S2, unofficial].
- **History and Development**: It was developed to address the expense of SVD on large matrices by leveraging the over-defined column space of wide, imbalanced matrices [S1][S2, unofficial]. The alternating strategy iteratively improves column choice by maximizing volume, addressing the limitation that random sampling does not guarantee the best possible set of columns [S1][S2, unofficial].
- **Usage**: Used in TT decomposition for volume rendering, specifically for selecting submatrices to approximate left singular vectors [S1][S2, unofficial].
