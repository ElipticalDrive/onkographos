# Alternating MaxVol Column Sampling

Also called: Alternating Maximum Volume Approximation for Column Sampling, Alternating maximum volume approximation, Iterative MaxVol column selection, MaxVol with random preselection, maxvol

## Overview
Alternating MaxVol Column Sampling is an iterative algorithm that selects a subset of columns from a wide matrix $A \in \mathbb{R}^{M \times N}$ (where $M \ll N$) to approximate its column space [S1][S2, unofficial]. It addresses the limitation of random column sampling, which is efficient but does not guarantee a basis that represents the matrix well, by iteratively maximizing the volume of the selected submatrix [S1][S2, unofficial]. Unlike [Orthogonal Matching Pursuit (OMP)](1999-orthogonal-matching-pursuit-omp.md), which selects atoms sequentially based on residual correlation, this method selects a block of columns simultaneously by alternating between row and column selection to find a submatrix with a large determinant [S1][S2, unofficial]. It is primarily used to enable efficient SVD computation on large matrices by reducing them to a smaller submatrix before decomposition [S1][S2, unofficial].

## How it works
**Inputs:**
*   Matrix $A \in \mathbb{R}^{M \times N}$ with $M < N$ [S1][S2, unofficial].
*   Target rank $R$ [S1][S2, unofficial].
*   Oversampling parameter $p \ge 0$ [S1][S2, unofficial].
*   Oversampling factor $F$ [S1][S2, unofficial].
*   Maximum number of iterations `max_iter` [S1][S2, unofficial].

**Outputs:**
*   Submatrix $A_{sub} \in \mathbb{R}^{M \times (R+p)}$ consisting of selected columns of $A$ [S1][S2, unofficial].

**Data Structures:**
*   $A_{sub}$: The current candidate submatrix, initialized to a random subset of columns.
*   $I$: A list of integer indices for rows or columns.
*   $A'_{sub}$: A row-subsampled version of $A_{sub}$.
*   $R_{mat}$: A row-subsampled version of $A$ (named $R$ in sources, distinct from rank $R$).
*   $R'_{mat}$: A column-subsampled version of $R_{mat}$.
*   $I_r$: Indices of selected rows returned by `maxvol`.
*   $I_c$: Indices of selected columns returned by `maxvol`.

**Algorithm Steps:**
1.  **Initialization:** Select $R + p$ random, uniform column indices $I_c$ from $A$. Initialize $A_{sub} \leftarrow A[:, I_c]$ [S1][S2, unofficial].
2.  **Iteration Loop:** For $i = 0$ to `max_iter`:
    1.  **Row Sampling:** Compute the number of rows to sample: $k = F \cdot (R + p)$. Select $k$ random row indices $I$ from $A_{sub}$ [S1][S2, unofficial].
    2.  **Row Submatrix:** Form $A'_{sub} \leftarrow A_{sub}[I, :]$ [S1][S2, unofficial].
    3.  **Row Selection:** Compute row indices $I_r$ by applying the `maxvol` algorithm to $A'_{sub}$ [S1][S2, unofficial].
    4.  **Row Extraction:** Let $R_{mat} \leftarrow A[I_r, :]$ (extracting the selected rows from the original matrix $A$) [S1][S2, unofficial].
    5.  **Column Sampling:** Compute the number of columns to sample: $k = F \cdot (R + p)$. Select $k$ random column indices $I$ from $R_{mat}$ [S1][S2, unofficial].
    6.  **Column Submatrix:** Form $R'_{mat} \leftarrow R_{mat}[:, I]$ [S1][S2, unofficial].
    7.  **Column Selection:** Compute column indices $I_c$ by applying the `maxvol` algorithm to $R'_{mat}$ [S1][S2, unofficial].
    8.  **Update:** Update $A_{sub} \leftarrow A[:, I_c]$ using the newly selected column indices from the original matrix $A$ [S1][S2, unofficial].
3.  **Return:** Return $A_{sub}$ [S1][S2, unofficial].

**Parameters:**
*   $R$: Target rank of the approximation [S1][S2, unofficial].
*   $p$: Oversampling parameter, $p \ge 0$, added to $R$ to ensure linear independence of the selected columns [S1][S2, unofficial].
*   $F$: Oversampling factor, used to determine the size of the random subsample before applying `maxvol` [S1][S2, unofficial].
*   `max_iter`: Maximum number of iterations for the alternating loop [S1][S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Large N:** The standard `maxvol` algorithm computes an intermediate $N \times N$ matrix, which is expensive for large $N$ [S1][S2, unofficial]. The random subsampling step (using factor $F$) is critical to mitigate this memory and computation cost [S1][S2, unofficial].
*   **Linear Independence:** Random sampling may select linearly dependent vectors. The oversampling parameter $p$ helps ensure that at least $R$ linearly independent vectors are selected, but the alternating MaxVol process further refines this by maximizing volume [S1][S2, unofficial].
*   **Subsample Size:** The number of sampled rows/columns is $F \cdot (R + p)$. If this exceeds the number of available rows or columns in the current submatrix, sampling without replacement will fail or require adjustment [G].

## Subtopics

### [Random Column Sampling for SVD Approximation](14052-random-column-sampling-for-svd-approximation.md)
A simpler method that selects $R+p$ columns uniformly at random. It is faster and uses less memory but does not guarantee the best basis representation. Choose this when computational resources are extremely limited and approximate results are acceptable.

### [Orthogonal Matching Pursuit (OMP)](1999-orthogonal-matching-pursuit-omp.md)
The parent method, which selects dictionary atoms one by one. Alternating MaxVol differs by selecting a block of columns simultaneously via volume maximization, which can be more effective for subspace approximation than greedy residual minimization.

## Operating characteristics
*   **Time Complexity:** Dominated by the `maxvol` calls within the loop. Each `maxvol` call on a submatrix of size $k \times k$ (where $k \approx F(R+p)$) is generally cubic in $k$ for determinant-based approaches, but the subsampling keeps $k$ small. The loop runs `max_iter` times.
*   **Memory Complexity:** Significantly reduced compared to full SVD or full `maxvol` on $A$. The intermediate matrices are of size $k \times k$ where $k \ll N$, thanks to random subsampling [S1][S2, unofficial].
*   **Performance:** More accurate than random sampling, as it guarantees a basis that spans a larger volume, leading to better representation of the column space [S1][S2, unofficial]. However, it is slower than random sampling due to the iterative optimization [S1][S2, unofficial].
*   **Strengths:** Handles very large $N$ efficiently via subsampling; provides a high-quality basis for SVD approximation.
*   **Limitations:** Requires tuning of $F$ and $p$; relies on the external `maxvol` algorithm; convergence is not guaranteed in a fixed number of iterations, though `max_iter` provides a bound.

## Background
The method was introduced in the context of Tensor-Train (TT) based 4D time-dependent volume rendering [S1][S2, unofficial]. It was proposed to efficiently compute the left singular vectors of large, wide matrices (cores of the TT decomposition) by avoiding full SVD. The approach builds on the Maximum Volume Approximation (MaxVol) algorithm [MO15], adapting it with random preselection to handle the large dimensions typical in volume rendering data [S1][S2, unofficial].
