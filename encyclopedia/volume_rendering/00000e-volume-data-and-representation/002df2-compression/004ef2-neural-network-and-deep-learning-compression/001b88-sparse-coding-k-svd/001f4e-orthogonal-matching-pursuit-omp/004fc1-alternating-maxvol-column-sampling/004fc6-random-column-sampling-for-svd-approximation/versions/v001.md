# Random Column Sampling for SVD Approximation
Also called: Random Submatrix SVD

## Overview
A method to compute the first $R_i$ left singular vectors of a wide matrix $A \in \mathbb{R}^{M \times N}$ (where $M \ll N$) by applying SVD only to a randomly selected submatrix of columns [S1][S2, unofficial]. It leverages the fact that the column space of such matrices is highly over-defined, allowing a subset of columns to span the same space as the full matrix [S2, unofficial]. It is distinguished from its sibling [Alternating MaxVol Column Sampling](14048-alternating-maxvol-column-sampling.md) by its simplicity and lower computational cost, though it sacrifices the guarantee of optimal column selection [S1][S2, unofficial].

## How it works
**Inputs:**
- Matrix $A \in \mathbb{R}^{M \times N}$ with $M \ll N$.
- Target rank $R_i$ (number of left singular vectors to compute).
- Oversampling parameter $p \ge 0$.

**Outputs:**
- Matrix $U_{sub} \in \mathbb{R}^{M \times R_i}$ containing the first $R_i$ left singular vectors of $A$.

**Data Structures:**
- $A_{sub} \in \mathbb{R}^{M \times (R_i + p)}$: The randomly selected submatrix.
- $I_{sel} \in \mathbb{Z}^{R_i + p}$: Indices of the selected columns.

**Parameters:**
- $R_i$: The desired number of singular vectors.
- $p$: Oversampling parameter. Typical values are not explicitly given in the sources, but $p \ge 0$ is required [S1][S2, unofficial].

**Steps:**
1. Randomly select $R_i + p$ distinct column indices from $\{1, \dots, N\}$ to form $I_{sel}$ [S1][S2, unofficial].
2. Extract the columns of $A$ indexed by $I_{sel}$ to form the submatrix $A_{sub} \in \mathbb{R}^{M \times (R_i + p)}$ [S1][S2, unofficial].
3. Compute the SVD of $A_{sub}$:
   $$ A_{sub} = U_{sub} \Sigma_{sub} V_{sub}^T $$
   where $U_{sub} \in \mathbb{R}^{M \times M}$ (or truncated to $M \times (R_i+p)$) [S1][S2, unofficial].
4. Check if $A_{sub}$ has full rank (specifically, rank $R_i$ or higher). This is determined by checking if the first $R_i$ singular values in $\Sigma_{sub}$ are non-zero (above a numerical tolerance) [S1][S2, unofficial].
5. If $A_{sub}$ does not have full rank (i.e., the selected columns do not contain $R_i$ linearly independent vectors), discard $A_{sub}$ and return to Step 1 [S1][S2, unofficial].
6. If $A_{sub}$ has full rank, return the first $R_i$ columns of $U_{sub}$ as the approximation of the left singular vectors of $A$ [S1][S2, unofficial].

**Pseudocode:**
```python
def random_column_sampling_svd(A, R_i, p):
    """
    Compute the first R_i left singular vectors of A using random column sampling.
    
    Args:
        A: Matrix of shape (M, N) where M << N.
        R_i: Number of left singular vectors to compute.
        p: Oversampling parameter (p >= 0).
        
    Returns:
        U_sub: Matrix of shape (M, R_i) containing the first R_i left singular vectors.
    """
    M, N = A.shape
    num_cols = R_i + p
    
    while True:
        # Step 1: Randomly select R_i + p column indices
        # Ensure distinct indices
        indices = random.sample(range(N), num_cols)
        
        # Step 2: Form submatrix A_sub
        A_sub = A[:, indices]
        
        # Step 3: Compute SVD on A_sub
        # We only need the left singular vectors corresponding to non-zero singular values
        # Using a standard SVD routine
        U_sub, S_sub, V_sub_T = svd(A_sub, full_matrices=False)
        
        # Step 4: Check if A_sub has full rank (rank >= R_i)
        # Check if the first R_i singular values are non-zero (above a small epsilon)
        # Note: S_sub contains singular values in descending order
        if len(S_sub) >= R_i and S_sub[R_i - 1] > 1e-10: # [G] epsilon threshold for numerical stability
            # Step 6: Return first R_i left singular vectors
            return U_sub[:, :R_i]
        else:
            # Step 5: If not full rank, retry
            continue
```

**Edge Cases and Pitfalls:**
- **Singular Vectors Representation:** Random sampling does not guarantee the best column set. The resulting singular vectors may not represent the matrix $A$ well if the random selection misses important structural columns [S1][S2, unofficial].
- **Rank Deficiency:** If $p=0$, the probability of selecting $R_i$ linearly independent vectors is lower. With $p>0$, the chance is very high because more columns than needed are chosen [S1][S2, unofficial].
- **Numerical Stability:** The check for full rank must account for numerical precision. Singular values close to zero should be treated as zero [S1][S2, unofficial].

## Subtopics

### Alternating MaxVol Column Sampling
Uses the maxvol algorithm to iteratively select rows and columns to maximize the volume of the submatrix, offering better accuracy than random sampling but at higher computational cost. See [Alternating MaxVol Column Sampling](14048-alternating-maxvol-column-sampling.md).

## Operating characteristics
- **Time Complexity:** Dominated by the SVD of the submatrix $A_{sub}$, which is $O(M^2 (R_i + p))$ or $O(M (R_i + p)^2)$ depending on implementation, significantly less than the full SVD of $A$ which is $O(M^2 N)$ [S1][S2, unofficial].
- **Memory Complexity:** Requires storing the submatrix $A_{sub}$ of size $M \times (R_i + p)$, which is much smaller than $A$ ($M \times N$) [S1][S2, unofficial].
- **Performance:** More time- and memory-efficient than the maximum volume approach [S1][S2, unofficial].
- **Strengths:** Simple to implement, computationally efficient, suitable for very wide matrices where $M \ll N$ [S1][S2, unofficial].
- **Limitations:** Does not guarantee optimal column selection; accuracy depends on the randomness of the selection and the oversampling parameter $p$ [S1][S2, unofficial].
- **When to use:** When computational resources are limited and an approximate set of left singular vectors is sufficient.
- **When not to use:** When high accuracy in column selection is required, or when the matrix has a structure that makes random sampling likely to miss important columns.

## Background
The method is presented in the context of Tensor-Train-based 4D Time-Dependent Volume Rendering, specifically for compressing large matrices arising from volume data representation [S1][S2, unofficial]. It is one of two efficient methods proposed for selecting a submatrix to compute left singular vectors, the other being the maximum volume approximation approach [S1][S2, unofficial]. The approach leverages the over-defined nature of the column space in wide, imbalanced matrices [S2, unofficial].
