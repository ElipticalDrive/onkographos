# Alternating MaxVol Column Sampling

Also called: Alternating Maximum Volume Approximation for Column Sampling, Alternating maximum volume approximation, Iterative MaxVol column selection, MaxVol with random preselection, maxvol

## Overview
Alternating MaxVol Column Sampling is an iterative algorithm that selects a subset of columns from a wide matrix $A \in \mathbb{R}^{M \times N}$ (where $M \ll N$) to approximate its column space [S1][S2, unofficial]. It solves the problem of efficiently computing low-rank approximations (such as left singular vectors) for large matrices by avoiding the computational cost of a full SVD on $A$ [S1][S2, unofficial]. It is distinguished from its sibling [Random Column Sampling for SVD Approximation](14052-random-column-sampling-for-svd-approximation.md) by its use of an alternating row/column selection process based on maximum volume, which guarantees a better basis representation than random sampling, albeit at higher computational cost [S1][S2, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A matrix $A \in \mathbb{R}^{M \times N}$ with $M < N$ [S1][S2, unofficial].
*   **Input:** The target rank $R$ [S1][S2, unofficial].
*   **Input:** An oversampling parameter $p \ge 0$ [S1][S2, unofficial].
*   **Input:** An oversampling factor $F$ [S1][S2, unofficial].
*   **Input:** A maximum iteration count `max_iter` [S1][S2, unofficial].
*   **Output:** A submatrix $A_{sub} \in \mathbb{R}^{M \times K}$ containing the selected columns of $A$, where $K$ is the number of selected columns [S1][S2, unofficial].

**Data Structures**
*   $A$: The input matrix of size $M \times N$.
*   $A_{sub}$: The current submatrix of selected columns, initialized as a subset of $A$ [S1][S2, unofficial].
*   $I$: A list of random indices for subsampling [S1][S2, unofficial].
*   $A'_{sub}$: A row-subsampled version of $A_{sub}$ [S1][S2, unofficial].
*   $I_r$: Indices of selected rows returned by the `maxvol` subroutine [S1][S2, unofficial].
*   $R$: A matrix containing the rows of $A$ indexed by $I_r$ [S1][S2, unofficial].
*   $R'$: A column-subsampled version of $R$ [S1][S2, unofficial].
*   $I_c$: Indices of selected columns returned by the `maxvol` subroutine [S1][S2, unofficial].

**Subroutines**
*   `maxvol(M)`: A subroutine that finds a submatrix of $M$ with a large determinant (maximum volume) and returns the indices of the selected rows or columns. Note: The sources assume `maxvol` is available. The standard MaxVol algorithm typically involves an iterative exchange process to maximize the volume of a square submatrix [S1][S2, unofficial]. The sources do not provide the internal implementation of `maxvol`, only its usage [S1][S2, unofficial].

**Parameters**
*   $R$: Target rank. Typical values depend on the application's desired approximation accuracy [S1][S2, unofficial].
*   $p$: Oversampling parameter. Ensures linear independence. $p \ge 0$ [S1][S2, unofficial].
*   $F$: Oversampling factor. Used to determine the number of random indices for subsampling. The number of indices is $F \cdot (R + p)$ [S1][S2, unofficial].
*   `max_iter`: Maximum number of alternating iterations.

**Steps**
1.  **Initialization:** Select $R + p$ random, uniform column indices $I_c$ from $A$. Initialize $A_{sub} \leftarrow A[:, I_c]$ [S1][S2, unofficial].
2.  **Iteration Loop:** For $i$ from 0 to `max_iter`:
    a.  **Sample Rows:**
        i.  Compute the number of row indices to sample: $N_{rows} = F \cdot (R + p)$ [S1][S2, unofficial].
        ii. Select $N_{rows}$ random row indices $I$ from $A_{sub}$ [S1][S2, unofficial].
        iii. Form the row-subsampled matrix $A'_{sub} \leftarrow A_{sub}[I, :]$ [S1][S2, unofficial].
        iv. Apply `maxvol` to $A'_{sub}$ to obtain row indices $I_r$ [S1][S2, unofficial].
        v. Extract the rows of the original matrix $A$ corresponding to $I_r$ to form matrix $R \leftarrow A[I_r, :]$ [S1][S2, unofficial].
    b.  **Sample Columns:**
        i.  Compute the number of column indices to sample: $N_{cols} = F \cdot (R + p)$ [S1][S2, unofficial].
        ii. Select $N_{cols}$ random column indices $I$ from $R$ [S1][S2, unofficial].
        iii. Form the column-subsampled matrix $R' \leftarrow R[:, I]$ [S1][S2, unofficial].
        iv. Apply `maxvol` to $R'$ to obtain column indices $I_c$ [S1][S2, unofficial].
        v. Update $A_{sub}$ to be the columns of the original matrix $A$ indexed by $I_c$: $A_{sub} \leftarrow A[:, I_c]$ [S1][S2, unofficial].
3.  **Return:** Return $A_{sub}$ [S1][S2, unofficial].

            I = np.arange(num_rows_sub)
        else:

            I = np.random.choice(num_rows_sub, num_row_samples, replace=False)

        # Compute number of column indices to sample
        num_col_samples = int(F * (R + p))
        
        # Get number of columns in R_mat
        num_cols_R = R_mat.shape[1]
        
        if num_col_samples > num_cols_R:
            # If we need more samples than available columns, sample all
            I_col = np.arange(num_cols_R)
        else:
            # Select random column indices from R_mat
            I_col = np.random.choice(num_cols_R, num_col_samples, replace=False)
        
        # Form column-subsampled matrix R'
        R_prime = R_mat[:, I_col]
        
        # Apply maxvol to R' to get column indices Ic_local
        Ic_local = maxvol_subroutine(R_prime)
        
        # Map local indices back to original column indices of R_mat
        Ic_R = I_col[Ic_local]
        
        # Map indices from R_mat back to original matrix A
        # R_mat was formed from rows Ir of A. The columns of R_mat correspond to columns of A.
        # So Ic_R are indices into the columns of A.
        Ic = Ic_R
        
        # Update A_sub to be the columns of A indexed by Ic
        A_sub = A[:, Ic]
        
    return A_sub

**Edge Cases and Pitfalls**
*   **Large N:** The `maxvol` algorithm computes an intermediate $N \times N$ matrix, which is expensive for large $N$ [S1][S2, unofficial]. The random subsampling step (using factor $F$) is critical to mitigate this memory and computation cost [S1][S2, unofficial].
*   **Linear Independence:** The oversampling parameter $p$ ensures that the selected columns are likely to be linearly independent [S1][S2, unofficial]. If $p=0$ and the selected columns are linearly dependent, the resulting basis may be poor [S1][S2, unofficial].
*   **Subsampling Size:** The number of samples $F \cdot (R + p)$ must not exceed the number of available rows or columns in the current submatrix. If it does, all available indices should be selected [G].

## Subtopics

### [Random Column Sampling for SVD Approximation](14052-random-column-sampling-for-svd-approximation.md)
A method to compute the first $R_i$ left singular vectors of a wide matrix $A \in \mathbb{R}^{M \times N}$ (where $M \ll N$) by applying SVD only to a randomly selected submatrix of columns. It leverages the fact that the column space of such matrices is highly over-defined, allowing a subset of columns to span the same space as the full matrix. It is distinguished from its sibling [Alternating MaxVol Column Sampling](14048-alternating-maxvol-column-sampling.md) by its simplicity and lower computational cost, though it sacrifices the guarantee of optimal column selection.

## Operating characteristics
*   **Time Complexity:** The complexity is dominated by the `maxvol` subroutine and the SVD computation on the final submatrix. The `maxvol` subroutine typically has a complexity related to the size of the submatrix it operates on. The alternating loop runs `max_iter` times. The random subsampling reduces the size of the matrix passed to `maxvol`, making it more efficient than applying `maxvol` directly to the full matrix [S1][S2, unofficial].
*   **Memory Complexity:** The memory usage is significantly reduced compared to full SVD or direct `maxvol` on the full matrix due to the random subsampling step [S1][S2, unofficial]. The intermediate matrices $A'_{sub}$ and $R'$ are smaller than $A$ [S1][S2, unofficial].
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** The method scales well to large $N$ due to the subsampling step [S1][S2, unofficial].
*   **Strengths:** Guarantees a better basis representation than random sampling by maximizing the volume spanned by the selected columns [S1][S2, unofficial]. More efficient than full SVD for wide matrices [S1][S2, unofficial].
*   **Limitations:** More complex and computationally expensive than random sampling [S1][S2, unofficial]. Requires tuning of parameters $p$ and $F$ [S1][S2, unofficial].
*   **When to use:** When a high-quality low-rank approximation is needed for a wide matrix, and full SVD is too expensive, but random sampling is insufficient [S1][S2, unofficial].
*   **When not to use:** When computational resources are extremely limited and a rough approximation is acceptable (use random sampling instead) [S1][S2, unofficial].

## Background
*   **Origin:** The method is based on the maximum volume approximation (maxvol) approach [MO15] [S1][S2, unofficial]. It was presented in the context of Tensor-Train-based 4D Time-Dependent Volume Rendering [S1][S2, unofficial].
*   **History and Development:** The maxvol algorithm was introduced in [MO15] [S1][S2, unofficial]. The alternating version with random preselection was proposed to handle large matrices in the context of TT decomposition [S1][S2, unofficial].
*   **Where it is used:** It is used in Tensor-Train (TT) decomposition for compressing large 4D volume data [S1][S2, unofficial].
