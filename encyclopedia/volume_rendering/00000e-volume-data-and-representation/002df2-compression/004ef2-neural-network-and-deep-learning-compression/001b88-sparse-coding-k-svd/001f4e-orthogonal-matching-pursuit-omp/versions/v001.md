# Orthogonal Matching Pursuit (OMP)
Also called: Matching Pursuit (MP)

## Overview
Orthogonal Matching Pursuit (OMP) is a greedy algorithm used for sparse coding to find an approximate sparse solution $\mathbf{x}$ for the problem $\min \|\mathbf{x}\|_0$ subject to $\|\mathbf{y} - \mathbf{D}\mathbf{x}\|_2 \leq \epsilon$ [S1, unofficial]. It is preferred over standard Matching Pursuit (MP) because it offers improvements on orthogonality and faster convergence [S1, unofficial].

## How it works
**Inputs:**
- Signal vector $\mathbf{y} \in \mathbb{R}^M$.
- Dictionary matrix $\mathbf{D} \in \mathbb{R}^{M \times N}$, where columns $\mathbf{d}_i$ are normalized ($\|\mathbf{d}_i\|_2 = 1$).
- Target sparsity $L$ (maximum number of nonzero entries in $\mathbf{x}$) [S1, unofficial].

**Outputs:**
- Sparse coefficient vector $\mathbf{x} \in \mathbb{R}^N$.

**Data Structures:**
- $\mathbf{x}$: Coefficient vector, initialized to zeros.
- $\mathcal{I}$: Set of selected indices, initialized to empty.
- $\mathbf{r}$: Residual vector, initialized to $\mathbf{y}$.

**Steps:**
1. Initialize residual $\mathbf{r} = \mathbf{y}$ and index set $\mathcal{I} = \emptyset$.
2. For $k = 1$ to $L$:
   a. Compute inner products between the current residual $\mathbf{r}$ and all dictionary atoms: $\mathbf{p} = \mathbf{D}^T \mathbf{r}$.
   b. Select the index $j$ of the atom with the maximum absolute inner product: $j = \arg\max_i |p_i|$.
   c. Add $j$ to the selected index set: $\mathcal{I} = \mathcal{I} \cup \{j\}$.
   d. Solve the least squares problem to update coefficients using only the selected atoms: $\mathbf{x}_{\mathcal{I}} = (\mathbf{D}_{\mathcal{I}}^T \mathbf{D}_{\mathcal{I}})^{-1} \mathbf{D}_{\mathcal{I}}^T \mathbf{y}$, where $\mathbf{D}_{\mathcal{I}}$ contains columns of $\mathbf{D}$ indexed by $\mathcal{I}$. [S1, unofficial]
   e. Update the residual: $\mathbf{r} = \mathbf{y} - \mathbf{D}_{\mathcal{I}} \mathbf{x}_{\mathcal{I}}$.
3. Return $\mathbf{x}$ with zeros at indices not in $\mathcal{I}$.

**Parameters:**
- $L$: The target sparsity, representing the maximum number of nonzero entries allowed in the coefficient vector $\mathbf{x}_i$ [S1, unofficial].

**Edge Cases and Pitfalls:**
- The algorithm assumes the dictionary columns are normalized. If not, normalization is required before step 2a.
- Solving the least squares problem in step 2d requires $\mathbf{D}_{\mathcal{I}}^T \mathbf{D}_{\mathcal{I}}$ to be invertible. This is guaranteed if the selected atoms are linearly independent.
- The exact sparsest representation is NP-hard [S1, unofficial]. OMP provides an approximation.

**Pseudocode:**
```python
def orthogonal_matching_pursuit(y, D, L):
    """
    y: signal vector (M,)
    D: dictionary matrix (M, N)
    L: target sparsity
    """
    M, N = D.shape
    x = np.zeros(N)
    r = y.copy()
    I = set()
    
    for k in range(L):
        # Compute inner products
        p = D.T @ r
        
        # Select atom with maximum absolute correlation
        j = np.argmax(np.abs(p))
        
        # Add to selected indices
        I.add(j)
        
        # Solve least squares for selected atoms
        D_I = D[:, list(I)]
        # Use pseudo-inverse or solve linear system
        # x_I = (D_I.T @ D_I)^-1 @ D_I.T @ y
        # To avoid explicit inverse, solve linear system
        coeffs, _, _, _ = np.linalg.lstsq(D_I, y, rcond=None)
        
        # Update residual
        r = y - D_I @ coeffs
        
        # Store coefficients in full x vector
        for idx, i in enumerate(I):
            x[i] = coeffs[idx]
            
    return x
```

## Operating characteristics
- **Time Complexity:** $O(L \cdot M \cdot N)$ for inner products and $O(L \cdot M^2)$ or $O(L \cdot N^2)$ for least squares depending on implementation. Generally faster than MP due to fewer iterations needed for convergence [S1, unofficial].
- **Memory Complexity:** $O(M \cdot N)$ to store the dictionary.
- **Strengths:** Simplicity, faster convergence than MP, orthogonality improvement [S1, unofficial].
- **Limitations:** Greedy nature may lead to suboptimal solutions compared to Basis Pursuit (BP) [S1, unofficial]. Performance depends on dictionary properties [S1, unofficial].
- **When to use:** When a fast approximate sparse solution is needed and the dictionary is well-conditioned.
- **When not to use:** When exact sparsity is required (NP-hard) or when the dictionary has high coherence.

## Background
OMP was introduced in [CBL89, DMZ94, PRK93, Tro04] [S1, unofficial]. It is a variant of Matching Pursuit (MP) [MZ93] [S1, unofficial]. It is widely used in sparse coding and is related to the K-SVD dictionary learning algorithm [S1, unofficial]. The algorithm converges under the condition that the sparse coding works perfectly, giving the best approximation to the signal $\mathbf{y}_i$ that contains no more than $L$ nonzero entries [S1, unofficial]. Each sparse coding step reduces the total representation mean squared error (MSE) $\|\mathbf{Y} - \mathbf{D}\mathbf{X}\|_F^2$ while the dictionary updating stage guarantees an additional reduction or no change in the MSE without violating the sparsity constraint [S1, unofficial].
