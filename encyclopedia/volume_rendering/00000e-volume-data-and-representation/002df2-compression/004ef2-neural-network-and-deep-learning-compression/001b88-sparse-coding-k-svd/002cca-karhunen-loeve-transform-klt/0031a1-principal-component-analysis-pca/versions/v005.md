# Principal Component Analysis (PCA)

Also called: PCA Compression, Principal Component Analysis for Residuals

## Overview
Principal Component Analysis (PCA) is a linear dimensionality reduction technique that finds a subspace maximizing the variance of projected data, assuming sample points lie on or near a linear subspace [S2].

## How it works
**Inputs and Outputs:**
Inputs: A set of $N$ input vectors $\{X_i\}_{i=1}^N$, where each $X_i \in \mathbb{R}^D$ [S2]. In volume rendering contexts, feature grids $f_1$ and residual grids $r_t$ are reshaped into $m \times n$ matrices, where $m$ is the number of non-empty feature voxels and $n$ is the number of feature channels [S1].
Outputs: A low-dimensional representation $\{Y_i\}_{i=1}^N$ where $Y_i \in \mathbb{R}^d$ ($d < D$), and the principal directions (eigenvectors) $\hat{u}_j$ for $j=1, \dots, d$ [S2].

**Data Structures:**
1. **Input Matrix $X$:** Size $N \times D$. Each row is a sample vector $X_i$ [G].
2. **Covariance Matrix $C$:** Size $D \times D$ [G].
3. **Eigenvectors $U$:** Size $D \times d$. Columns are the top $d$ eigenvectors $\hat{u}_j$ [G].
4. **Projected Data $Y$:** Size $N \times d$ [G].

**Numbered Steps:**
1. Reshape the original feature grid $f_1$ and residual grid $r_t$ into $m \times n$ feature matrices [S1].
2. Compute the covariance matrix $C$ of the sample points $X_i$ [S2].
3. Solve the eigenvalue equation $C\hat{u} = \lambda\hat{u}$ using Singular Value Decomposition (SVD) [S2].
4. Select the top $d$ eigenvectors $\hat{u}_j$ yielding the largest eigenvalues as directions [S2].
5. Compute the $j$-th component of the low-dimensional representation $Y_i$ by taking the inner product of the input $X_i$ and the eigenvector $\hat{u}_j$: $Y_{ij} = X_i \cdot \hat{u}_j$ [S2]. For residual matrices, project $r_t$ onto the principal directions $V$ to obtain the compressed residual $r_t' = r_t \cdot V$ [S1].

**Formulas:**
- Covariance matrix: $C = \frac{1}{N} \sum_{i=1}^N (X_i - \mu)(X_i - \mu)^T$, where $\mu$ is the mean vector [G].
- Eigenvalue equation: $C\hat{u} = \lambda\hat{u}$ [S2].
- Projection: $Y_{ij} = X_i \cdot \hat{u}_j$ [S2].
- Residual SVD: $r_t(m,n) = U \cdot \text{diag}(S) \cdot V^T$, where $V$ is $n \times q$, $S$ is a $q$-vector, and $U$ is $m \times q$ [S1].
- Residual projection: $r_t' = r_t \cdot V$ [S1].

**Parameters:**
- $d$: Target dimensionality. Typical values are not given in the sources. [S1] uses $q$ to denote the number of principal directions.
- $m, n$: Dimensions of the feature/residual matrix. $m$ is the number of non-empty voxels, $n$ is the number of channels [S1].

**Edge Cases and Pitfalls:**
- **Nonlinearity:** PCA assumes sample points are on or near a linear subspace. If the data has nonlinear structures, PCA fails to preserve the shape faithfully [S2].
- **Computational Cost:** Computing the covariance matrix and solving the eigenvalue equation is computationally expensive [S2].

**Pseudocode:**
```python
import numpy as np

def pca_compress(X, d):
    """
    Compress data X using PCA as described in [S2].
    X: numpy array of shape (N, D)
    d: target dimensionality
    Returns: Y (compressed data), V (principal directions)
    """
    # Step 1: Center the data
    mean = np.mean(X, axis=0)
    X_centered = X - mean

    # Step 2: Compute Covariance Matrix C
    N, D = X_centered.shape
    C = (X_centered.T @ X_centered) / N

    # Step 3: Solve eigenvalue equation C*u = lambda*u using SVD
    # The right singular vectors of X_centered are the eigenvectors of C
    _, _, Vt = np.linalg.svd(X_centered, full_matrices=False)
    V = Vt.T  # Shape (D, min(N, D))

    # Step 4: Select top d eigenvectors corresponding to largest eigenvalues
    # Singular values are sorted descending, so we take the first d columns
    V_principal = V[:, :d]  # Shape (D, d)

    # Step 5: Project data: Y_ij = X_i . u_j
    Y = X_centered @ V_principal  # Shape (N, d)

    return Y, V_principal

def pca_compress_residual(rt, d):
    """
    Compress residual matrix rt as described in [S1].
    rt: numpy array of shape (m, n)
    d: number of principal directions (q in source)
    Returns: rt_prime (compressed residual), V (principal directions)
    """
    m, n = rt.shape
    q = min(m, n)

    # Step 1: Singular Value Decomposition of rt
    # rt(m,n) = U * diag(S) * V^T
    U, s, Vt = np.linalg.svd(rt, full_matrices=False)
    V = Vt.T  # Shape (n, q)

    # Step 2: Select top d principal directions
    V_principal = V[:, :d]  # Shape (n, d)

    # Step 3: Project rt onto principal directions
    # rt' = rt * V
    rt_prime = rt @ V_principal  # Shape (m, d)

    return rt_prime, V_principal
```

## Subtopics

### [Clustered Principal Component Analysis (CPCA)](10896-clustered-principal-component-analysis-cpca.md)
Applies PCA to clusters of tiles in the angular domain to exploit spatial and angular locality, suitable when global linearity does not hold.

### [PCA-based TSDF Compression](12932-pca-based-tsdf-compression.md)
Applies PCA to Truncated Signed Distance Field voxel blocks using a single global basis to preserve structural information and filter noise.

## Operating characteristics
- **Time Complexity:** Computationally expensive due to the Singular Value Decomposition (SVD) or eigenvalue decomposition required to compute the covariance matrix and its eigenvectors [S2]. Exact Big-O notation is not given in the sources [G].
- **Memory Complexity:** Requires storing the covariance matrix ($D \times D$) or the full SVD components [G].
- **Measured Performance and Scaling:** Not given in the sources [G].
- **Strengths:** The solution is a global minimum for the variance maximization problem [S2].
- **Limitations:** Fails on nonlinear data structures [S2].
- **When to use:** Not given in the sources [G].
- **When not to use:** Not given in the sources [G].

## Background
PCA is widely used in many fields due to its simplicity [S2]. It is closely related to the Karhunen-Loeve Transform (KLT) [Parent].
