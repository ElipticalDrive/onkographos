# SVD-based Cloud Volume Compression

Also called: SVD Compression for Cloud Volumes

## Overview
This method compresses a database of extracted cloud volumes by projecting their voxel density vectors onto a low-dimensional subspace defined by the left singular vectors of the dataset matrix. It differs from its parent, [PCA-based TSDF Compression](12932-pca-based-tsdf-compression.md), by operating directly on the raw voxel density values of normalized cloud blocks rather than on Signed Distance Field (SDF) or TSDF representations. While PCA relies on the covariance matrix of the data, this method explicitly constructs the data matrix and performs Singular Value Decomposition (SVD) to determine the basis, allowing for a direct energy-threshold-based truncation of the basis set.

## How it works
**Inputs:** A set of $N$ extracted cloud volumes $D_n$ (where $n = 1, \dots, N$).
**Outputs:** A compressed database containing the truncated basis vectors $\{u_k\}_{k=1}^K$ and their corresponding coefficients $\{w_{nk}\}_{n=1, k=1}^{N, K}$.

**Data Structures:**
1.  **Normalized Volume ($S_n$):** A cubic grid of size $m \times m \times m$.
2.  **Density Vector ($x_n$):** A column vector of size $M \times 1$, where $M = m^3$. It contains the voxel densities $\rho(p)$ of $S_n$ flattened in a consistent order (e.g., row-major or column-major).
    $$x_n = [\rho_n(p_1), \rho_n(p_2), \dots, \rho_n(p_M)]^T$$
3.  **Data Matrix ($A$):** An $M \times N$ matrix formed by concatenating the density vectors.
    $$A = [x_1, x_2, \dots, x_N]$$
    *Constraint:* The method assumes $M \ge N$. If $M < N$, the decomposition logic remains valid but the interpretation of "basis vectors" as the primary storage reduction mechanism changes; the source assumes $M \ge N$ [S1].
4.  **Basis Vectors ($U$):** The left singular vectors of $A$. Specifically, the first $K$ columns of $U$, denoted $u_1, \dots, u_K$, serve as the basis. Each $u_k$ is a vector of size $M \times 1$.
5.  **Coefficients ($W$):** A matrix of size $N \times K$ where entry $(n, k)$ is $w_{nk}$.

**Parameters:**
*   $m$: The side length of the normalized cube. Chosen experimentally to capture small-scale details of the original cloud volumes [S1].
*   $\alpha$: Energy threshold constant controlling approximation accuracy. Typical value: $0.9$ [S1].

**Algorithm Steps:**

1.  **Normalization:** For each cloud volume $D_n$, extract the bounding box of the connected cloud region. Resize/interpolate this volume to a fixed cubic resolution of $m \times m \times m$ to create $S_n$ [S1].
2.  **Vectorization:** Flatten each $S_n$ into the column vector $x_n$ of size $M = m^3$ [S1].
3.  **Matrix Construction:** Assemble the data matrix $A = [x_1 \dots x_N]$ of size $M \times N$ [S1].
4.  **SVD Decomposition:** Compute the Singular Value Decomposition of $A$:
    $$A = U \Sigma V^*$$
    Where:
    *   $U$ is an $M \times M$ unitary matrix. Its columns $u_i$ are the left singular vectors.
    *   $\Sigma$ is an $M \times N$ diagonal matrix with non-negative singular values $\sigma_k$ on the diagonal, sorted in decreasing order ($\sigma_1 \ge \sigma_2 \ge \dots \ge \sigma_N$).
    *   $V$ is an $N \times N$ unitary matrix. Its columns $v_j$ are the right singular vectors.
    *   $V^*$ denotes the conjugate transpose of $V$ [S1].
5.  **Basis Selection:** Determine the smallest integer $K$ such that the sum of the first $K$ singular values satisfies the energy threshold:
    $$\sum_{k=1}^{K} \sigma_k \ge \alpha \sum_{k=1}^{N} \sigma_k$$
    This $K$ represents the number of basis vectors required to retain $\alpha$ percent of the total signal energy [S1].
6.  **Coefficient Calculation:** For each cloud volume $n$, compute the projection coefficients onto the selected basis vectors. Since the left singular vectors $u_k$ are orthogonal:
    $$w_{nk} = x_n \cdot u_k$$
    This is computed for $k = 1, \dots, K$ [S1].
7.  **Storage:** Store the basis vectors $u_1, \dots, u_K$ (each of size $M$) and the coefficients $w_{nk}$ for all $n=1\dots N, k=1\dots K$ in the database. The original vectors $x_n$ are discarded [S1].

import numpy as np

def svd_cloud_compression(cloud_volumes, m, alpha):
    """
    Compress a set of cloud volumes using SVD.
    
    Args:
        cloud_volumes: List of N 3D arrays representing raw cloud volumes.
        m: Integer, side length of the normalized cube.
        alpha: Float, energy threshold (e.g., 0.9).
        
    Returns:
        basis_vectors: Array of shape (K, M) containing the first K left singular vectors.
        coefficients: Array of shape (N, K) containing the projection coefficients.
        K: Integer, number of basis vectors used.
    """
    N = len(cloud_volumes)
    M = m * m * m
    
    # Step 1 & 2: Normalize and Vectorize
    # Note: Normalization involves resizing the bounding box of the cloud to m x m x m.
    # This step assumes 'normalize_volume' handles interpolation/resizing.
    vectors = []
    for vol in cloud_volumes:
        normalized = normalize_volume_to_cube(vol, m) # [G] Helper to resize/interpolate
        vec = normalized.flatten() # Flatten to M x 1 vector
        vectors.append(vec)
        
    # Step 3: Construct Matrix A (M x N)
    # Stack vectors as columns
    A = np.column_stack(vectors) 
    
    # Step 4: SVD Decomposition
    # Compute full SVD. For large M, 'full_matrices=False' might be used, 
    # but the source defines U as M x M. We assume standard full SVD for correctness 
    # as per source definition [S1].
    U, S, Vt = np.linalg.svd(A, full_matrices=True)
    
    # S contains singular values sigma_k. 
    # U columns are left singular vectors u_k.
    
    # Step 5: Determine K based on energy threshold
    total_energy = np.sum(S)
    cumulative_energy = 0.0
    K = 0
    for k in range(len(S)):
        cumulative_energy += S[k]
        if cumulative_energy >= alpha * total_energy:
            K = k + 1
            break
            
    # Step 6: Calculate Coefficients
    # w_nk = x_n . u_k
    # We only need the first K columns of U
    U_k = U[:, :K] # Shape (M, K)
    
    # Coefficients matrix W (N, K)
    # A is (M, N). U_k is (M, K).
    # We want W such that A approx U_k @ W^T
    # Since U_k columns are orthonormal: W^T = U_k^T @ A
    # W = A^T @ U_k
    coefficients = A.T @ U_k # Shape (N, K)
    
    # Step 7: Return compressed data
    # basis_vectors stored as (K, M) for easier iteration if needed, 
    # though source implies storing u_k.
    basis_vectors = U_k.T # Shape (K, M)
    
    return basis_vectors, coefficients, K

**Edge Cases and Pitfalls:**
*   **Matrix Dimensions:** The method assumes $M \ge N$. If the number of cloud volumes exceeds the number of voxels in the normalized cube, the standard SVD interpretation for compression (where $K \ll N$) may not yield significant storage reduction in the same manner [S1].
*   **Normalization Consistency:** The resizing to $m \times m \times m$ must use a consistent interpolation method (e.g., trilinear) to ensure that the basis vectors $u_k$ represent meaningful spatial density patterns. Inconsistent normalization breaks the orthogonality assumptions or semantic meaning of the coefficients [S1].
*   **Precision:** Floating-point precision in the SVD computation can affect the exact value of $K$ when the energy threshold is near a singular value boundary.

## Operating characteristics
*   **Compression Ratio:** With $\alpha = 0.9$, the database size was reduced to 84% of the original size [S1].
*   **Approximation Error:** Under the same conditions ($\alpha = 0.9$), the approximation error was measured at 4.5% [S1].
*   **Complexity:**
    *   **Preprocessing (Training):** Dominated by the SVD of an $M \times N$ matrix. Complexity is typically $O(M N^2)$ or $O(M^2 N)$ depending on implementation, assuming $M \ge N$.
    *   **Storage:** Stores $K \times M$ basis values and $N \times K$ coefficients. Total storage $\approx K(M + N)$. Original storage is $N \times M$. Reduction factor is roughly $K/M$ if $N$ is small relative to $M$, but the source notes an 84% reduction (16% size) for $\alpha=0.9$, implying $K$ is small relative to $N$ or the specific data structure overhead is considered.
    *   **Retrieval:** Retrieval involves projecting a query vector onto the basis $U_K$ (cost $O(K \cdot M)$) and comparing coefficients. This is faster than comparing against full volumes [S1].
*   **Strengths:** Simple implementation; leverages the high correlation in cloud shapes; reduces storage and retrieval computational cost [S1].
*   **Limitations:** Requires a fixed resolution $m$ for all clouds, potentially losing large-scale context or wasting resolution on small clouds; sensitive to the choice of $m$ [S1].

## Background
This method was proposed in the context of a sketch-based system for realistic cloud image synthesis [S1]. It builds upon the need to store large datasets of simulated cloud volumes (tens of gigabytes) generated from atmospheric fluid dynamics simulations [Miyazaki et al. 2002]. The approach adapts standard SVD compression techniques, commonly used in image processing (e.g., JPEG), to 3D volumetric data by treating each cloud volume as a high-dimensional vector. It is specifically tailored for clouds, which have roughly similar shapes, allowing for effective low-rank approximation [S1].
