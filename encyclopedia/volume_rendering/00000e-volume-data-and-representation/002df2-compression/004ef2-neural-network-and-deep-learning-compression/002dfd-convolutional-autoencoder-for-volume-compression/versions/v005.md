# Convolutional Autoencoder for Volume Compression

Also called: Autoencoder-based volume rendering, CNN Autoencoder, Compressed Volume Rendering using Deep Learning, Data-driven compressed volume rendering, Deep Learning Compression

## Overview
This method obtains a data-driven compact representation of multivariate, time-varying volumetric data using a deep convolutional autoencoder network, enabling interactive rendering and navigation by decompressing the representation on the GPU [S1, unofficial]. It solves the problem of storing and transmitting large scientific volumes by learning high-level hierarchical features that capture the underlying data distribution more effectively than linear bases [S1, unofficial]. It differs from its siblings by using a fixed, non-linear convolutional architecture to compress individual multivariate slices into a latent code, whereas [Sparse Coding (K-SVD)](1018-sparse-coding-k-svd.md) relies on linear combinations of learned atoms, and [Masked Entropy Model for TensoRF-VM](17063-masked-entropy-model-for-tensorf-vm.md) uses entropy coding on tensor decompositions.

## How it works
**Inputs and Outputs:**
*   **Input:** A multivariate time-varying volume represented as a multidimensional array of size $X \times Y \times Z \times K \times T$, where $X, Y, Z$ are spatial dimensions, $K$ is the number of multivariate fields (channels), and $T$ is the number of time steps [S1, unofficial].
*   **Output:** A compressed latent representation for each time step, and a real-time reconstructed volume for rendering [S1, unofficial].

**Data Structures and Layout:**

**Parameters:**
*   **Filter Size:** $3 \times 3$ for all convolutional layers [S1, unofficial].
*   **Optimizer:** ADADELTA solver with momentum of 0.95 [S1, unofficial].
*   **Loss Function:** Cross-entropy between the input slice and the reconstructed slice. Training stops when the mean squared error (MSE) between the input volume and reconstructed volume stops decreasing [S1, unofficial].

**Steps:**

1.  **Preprocessing:**
    *   Normalize the data between 0 and 1 for each multivariate dimension across all time steps [S1, unofficial].
    *   Arrange the data as multivariate slices along the z-axis. The multivariate field ($K$) acts as the channel dimension for the network. The input to the network for a single slice is of size $X \times Y \times K$ [S1, unofficial].

2.  **Training:**
    *   Randomly sample multivariate slices from all time steps [S1, unofficial].
    *   Feed slices through the autoencoder.
    *   Update weights using backpropagation to minimize the loss.
    *   **Activation Functions:**
        *   Hidden layers use Rectified Linear Units (ReLU): $f(v_i) = \max(0, v_i)$ [S1, unofficial].
        *   The output layer of the encoder (and potentially the decoder's final output before clipping) uses the sigmoid activation function to map values to $[0, 1]$:
            $$f(v_i) = \frac{1}{1 + e^{-v_i}}$$
            [S1, unofficial]
    *   The convolution operation for the $i$-th channel $V_i$ of the output volume is:
        $$V_i = \sum_{j=1}^p W_{j,q} * U_j + b_i$$
        where $U_j$ is the $j$-th input channel, $W_{j,q}$ is the filter, and $b_i$ is the bias [S1, unofficial].

3.  **Decompression (Rendering):**
    *   Split the trained network into Encoder ($E$) and Decoder ($D$) [S1, unofficial].
    *   For a required time step, decompress subsampled slices along the z-axis using $D$ to create a coarser volume [S1, unofficial].
    *   Render this coarser volume.
    *   Continuously refine by decompressing remaining slices while rendering.
    *   Switch to finer volume rendering once decompression is complete [S1, unofficial].
    *   Decompression requires additional memory for only one reconstructed slice at full resolution [S1, unofficial].

4.  **Rendering:**
    *   Visualize the reconstructed volume using ray casting [S1, unofficial].
    *   Apply a user-defined transfer function: Map voxel intensity (0-255) to color and opacity. Opacity and color are linearly interpolated between adjacent control points [S1, unofficial].

## Subtopics

### [3D Shape Autoencoder](6689-3d-shape-autoencoder.md)
The 3D Shape Autoencoder is a convolutional neural network architecture designed to learn a compact prior distribution of 3D shapes. It solves the problem of representing complex volumetric or geometric data by mapping high-dimensional 3D inputs into a low-dimensional latent vector and reconstructing them, thereby enabling tasks such as novel-view synthesis and image relighting. It differs from standard autoencoders by explicitly focusing on learning a "shape prior" using 3D convolutions, which allows for the recovery of pose and shape factors from single images, outperforming feed-forward networks in structural consistency. See [3D Shape Autoencoder](6689-3d-shape-autoencoder.md).

### [Deep Implicit Volume Compression](6807-deep-implicit-volume-compression.md)
Deep Implicit Volume Compression is a block-based neural network architecture trained end-to-end to compress Truncated Signed Distance Fields (TSDF) stored in 3D voxel grids, achieving state-of-the-art rate-distortion trade-offs. It solves the problem of topological errors in reconstructed surfaces caused by quantization noise in magnitude values by losslessly compressing the sign configuration separately from the geometric magnitude. Unlike standard convolutional autoencoders that minimize only reconstruction error, this method employs dual-output heads and conditional entropy coding to minimize bit rate while guaranteeing that the reconstructed surface is homeomorphic to the ground truth. See [Deep Implicit Volume Compression](6807-deep-implicit-volume-compression.md).

### Conditional Diffusion Model for Volume Compression
A conditional diffusion model that compresses tensor blocks, with post-processing that corrects blocks exceeding the user-specified error bound [S2, unofficial]. On E3SM climate data, it achieved at least 2× larger compression ratios than SZ3 above NRMSE $10^{-4}$ [S2, unofficial]. However, the iterative denoising process imposes a severe decoding bottleneck (978 seconds decoding time vs. 12 seconds for SZ3 and 2 seconds for a standard autoencoder), making data-space diffusion impractical for interactive use [S2, unofficial].

### FlowNet
The first deep learning framework for clustering and selecting representative streamlines/stream surfaces, which voxelizes flow structures into binary volumes and trains a 3D CNN autoencoder to produce feature descriptors [S2, unofficial]. Steps: 1. Voxelize each flow structure into a binary volume. 2. Train a 3D CNN autoencoder to produce a 1024-dimensional feature descriptor per structure. 3. Perform dimensionality reduction via t-SNE to project descriptors into 2D space. 4. Use DBSCAN clustering to identify groups for filtering and selection [S2, unofficial]. Across eleven flow field datasets, it achieved training F1 scores of 0.72–0.96 and test F1 scores of 0.57–0.86 [S2, unofficial].

### Temporal Selection via Autoencoder Descriptors
An extension of the autoencoder paradigm for selecting representative timesteps from long time-varying simulations by producing multivariate temporal descriptors [S2, unofficial]. Steps: 1. Train an encoder-decoder network accepting multichannel volumes (one channel per scalar variable). 2. Produce a 1024-dimensional descriptor per timestep. 3. Project descriptors via t-SNE. 4. Select representatives by arc-length or angular criteria [S2, unofficial].

### Large-Scale Mapping with Moving Active Volume
An application of autoencoder descriptors for large-scale mapping [S3]. Steps: 1. Extend SDF Tracker with a moving active volume centered around the camera translation vector. 2. For every 16-voxel increment, encode voxel blocks exiting the active TSDF on the lagging end (if not empty). 3. Reduce voxel blocks from 4096 voxels to descriptor size or a token if the block is empty [S3]. Parameter: Active volume translation step is 16 voxels [S3].

## Operating characteristics
**Time and Memory Complexity:**
*   **Memory:** Stores only the compressed representation for all time steps on GPU memory. Decompression requires additional memory for only one reconstructed slice at full resolution [S1, unofficial].
*   **Compression Ratio:** Achieved a compression ratio of 14.28:1 (compressed representation takes 7% of total memory) [S1, unofficial].

**Measured Performance:**
*   **Dataset 1** (52x52x37, 88 timesteps, 2.56GB): CNN Autoencoder MSE=0.000061, PSNR=42.125. Best Wavelet (Discrete Mayer) MSE=0.0015, PSNR=28.239 [S1, unofficial].
*   **Dataset 2** (100x100x100, 20 timesteps, 5.81GB): CNN Autoencoder MSE=0.0049, PSNR=23.098. Best Wavelet (Biorthogonal 9/3) MSE=0.0219, PSNR=16.588 [S1, unofficial].
*   Compared to Wavelet compression (Daubechies, Mayer, Biorthogonal), the CNN Autoencoder achieves significantly lower MSE and higher PSNR at the same 7% storage usage [S1, unofficial]. Wavelets result in coarse reconstruction with artifacts; Autoencoder provides close approximation with no visible artifacts [S1, unofficial].

**Strengths and Limitations:**
*   **Strengths:** Enables interactive rendering and navigation of large time-varying datasets by fitting the compressed representation on GPU memory. Learns hierarchical features that capture complex data distributions better than linear bases.
*   **Limitations:** Requires training time. The method described uses a fixed architecture; adapting to different data types may require retraining. The decoding bottleneck is not as severe as diffusion models but still requires GPU acceleration for real-time performance [S1, unofficial].

## Background
This method was proposed by Jain et al. [S1, unofficial]. It addresses the challenge of visualizing large multivariate time-varying volumetric data generated by simulations, which is essential for understanding underlying scientific processes. The approach leverages the fact that deep neural networks correspond to hierarchical tensor decompositions, offering richer representational capacity than traditional Tensor Approximation [S1, unofficial].
