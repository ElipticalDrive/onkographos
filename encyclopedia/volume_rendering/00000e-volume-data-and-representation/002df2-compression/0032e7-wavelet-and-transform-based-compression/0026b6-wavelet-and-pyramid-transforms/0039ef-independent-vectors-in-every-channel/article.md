# Independent vectors in every channel

Also called: Scheme 1

## Overview
A multiresolution compression scheme that extracts $k$-dimensional vectors independently within each channel of the wavelet decomposition hierarchy, without correlating data across different resolution levels [S1, unofficial]. It solves the problem of compressing medical volume data by exploiting spatial redundancy within individual frequency bands while maintaining true multiresolution browsing capabilities, distinguishing it from cross-scale methods that sacrifice resolution adaptability for higher compression ratios [S1, unofficial].

## How it works
**Inputs:** A 3D volume dataset (e.g., CT scans) [S1, unofficial].
**Outputs:** A compressed bitstream containing Huffman-coded indices for quantized coefficients [G].

**Data Structures:**
The multiresolution decomposition (MD) hierarchy consists of four subbands generated by a three-level decomposition, ordered according to Mallat’s convention with the lowest resolution version at the root (left-bottom/proximal corner) [S1, unofficial]:
1. **Lowest Resolution Image (LRI):** The coarsest approximation subband [S1, unofficial].
2. **Detail Level 1 (DL1):** The finest detail coefficients [S1, unofficial].
3. **Detail Level 2 (DL2):** Intermediate detail coefficients [S1, unofficial].
4. **Detail Level 3 (DL3):** Coarse detail coefficients [S1, unofficial].

**Parameters:**
* **Wavelet Basis:** Daubechies-6 [S1, unofficial].
* **Decomposition Levels:** 3 levels (producing LRI, DL1, DL2, DL3) [S1, unofficial].
* **Vector Dimension ($k$):** Spatial neighborhood size within a single channel; typical values are $k=4$ or $k=16$ [S1, unofficial].
* **Codebook Size ($N_c$):** Number of centroids in the Vector Quantization (VQ) codebook; typical values are 256 or 512 [S1, unofficial].

**Steps:**
1. **Histogram Equalization:** Apply histogram equalization to the volume data prior to quantization to improve coding efficiency [S1, unofficial].
2. **Wavelet Decomposition:** Perform a three-level separable 3D wavelet decomposition using the Daubechies-6 basis. Order the resulting subbands according to Mallat’s convention [S1, unofficial].
3. **Vector Extraction:** Extract $k$-dimensional vectors independently from the coefficients within each channel (resolution level) of the hierarchy. Vectors are formed from spatial neighbors within the same level; no coefficients from other levels are included in the same vector [S1, unofficial].
4. **Quantization:** Apply Scalar Quantization (SQ) to the coefficients of the LRI [S1, unofficial]. Apply Vector Quantization (VQ) to the coefficients in DL1, DL2, and DL3 [S1, unofficial].
5. **Codebook Training:** Train the VQ codebook using the LBG (Linde-Buzo-Gray) algorithm, a k-means clustering algorithm enhanced with a specific initialization procedure [S1, unofficial]. The codebook is trained on representative data (e.g., Visible Human project volumes) [S1, unofficial].
6. **Entropy Coding:** Perform Huffman coding on the indices resulting from the quantization steps (SQ indices for LRI, VQ codebook indices for DL1-3) [S1, unofficial].

## Subtopics

### Vectors selected across scales
A variant that extracts vectors spanning multiple resolution levels to exploit correlation across scales, rather than processing levels independently [S1, unofficial].
* **Definition:** Vectors combine coefficients from the current level and lower levels. The vector dimension $k$ is calculated as $k = 1 + 3(1 \times 1) + 3(2 \times 2) + 3(4 \times 4)$ [S1, unofficial].
* **Method:** Apply Vector Quantization to these cross-scale vectors [S1, unofficial].
* **Pitfall:** The method does not support true multiresolution browsing because reconstruction requires retrieving the full vector across scales; partial retrieval is not possible [S1, unofficial].
* **Comparison:** Achieves much higher compression ratios than the independent channel method, but with lower image quality (SNR) [S1, unofficial].

## Operating characteristics
* **Compression Ratio vs. Quality:** Scheme 1 yields higher Signal-to-Noise Ratio (SNR) at high compression ratios compared to cross-scale schemes (Scheme 2), but suffers a significant drop in compression ratio when higher detail levels (DL2, DL3) are included in reconstruction [S1, unofficial].
* **Performance Metrics:** For a codebook size $N_c=256$ and vector dimension $k=16$, Scheme 1 achieves a compression ratio of 35.7:1 with an SNR of 20.55 dB and MSE of 3209.6. For $N_c=512, k=16$, it achieves 30.2:1 compression with 22.88 dB SNR [S1, unofficial].
* **Strengths:** Maintains true multiresolution browsing capability; higher quality (SNR) at equivalent compression ratios compared to cross-scale methods [S1, unofficial].
* **Limitations:** Compression ratio drops significantly as more detail levels are added to the reconstruction, making it less efficient for full-resolution rendering compared to cross-scale methods [S1, unofficial].
* **Hardware/Resolution:** Tested on medical CT volumes from the Visible Human project [S1, unofficial].
