# Rate-Distortion Optimized RAHT

Also called: RDO RAHT, RDO RAHT framework

## Overview
Rate-Distortion Optimized RAHT (RDO RAHT) is a standard-compatible quantization framework for the Region Adaptive Hierarchical Transform (RAHT) in G-PCC, designed to optimize bit allocation for high-dynamic-range attributes such as those in 3D Gaussian Splatting (3DGS) [S1, unofficial]. It distinguishes itself from standard RAHT by introducing a configurable fixed-point precision extension to mitigate numerical error floors and deriving an analytical rate-distortion model that allocates bits according to the hierarchical contribution of RAHT layers, achieving significant BD-rate gains without requiring neural training [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** 3DGS attribute data (e.g., spherical harmonics coefficients) organized in an octree structure with node weights $w_{l,n}$ representing the count of Gaussians per node [S1, unofficial].
*   **Output:** Quantized RAHT coefficients (low-frequency DC and high-frequency AC) and a bitstream compliant with G-PCC standards, including an Attribute Parameter Set (APS) extension signaling the precision mode [S1, unofficial].

**Data Structures:**
*   **Octree Node:** Contains attribute values $A_{l,n}$, weight $w_{l,n}$, and transformed coefficients $L_{l,n}$ (DC) and $H_{l,n}$ (AC) [S1, unofficial].
*   **Attribute Parameter Set (APS):** Extends the G-PCC standard to signal the configurable fixed-point precision parameters [S1, unofficial].

**Method Steps:**

1.  **Precision Extension Configuration:**
    Signal a higher configurable fixed-point precision in the APS extension to mitigate precision-induced error floors caused by the conversion of floating-point weights to integers [S1, unofficial]. This ensures backward compatibility at the bitstream level while reducing the non-orthogonality error inherent in standard 15-bit fixed-point arithmetic [S1, unofficial].

2.  **Forward RAHT Transform:**
    For a node at layer $l$ with index $n$, merge low-frequency coefficients from two adjacent child nodes (indexed by $2n$ and $2n+1$) at layer $l+1$ into parent coefficients at layer $l$ using weighted merging [S1, unofficial]:
    $$
    L_{l,n} = a L_{l+1,2n} + b L_{l+1,2n+1}
    $$
    $$
    H_{l,n} = b L_{l+1,2n} - a L_{l+1,2n+1}
    $$
    where the weights $a$ and $b$ are defined as:
    $$
    a = \frac{w_{l+1,2n}}{w_{l+1,2n} + w_{l+1,2n+1}}, \quad b = \frac{w_{l+1,2n+1}}{w_{l+1,2n} + w_{l+1,2n+1}}
    $$
    Here, $L_{l,n}$ is the low-frequency DC coefficient, $H_{l,n}$ is the high-frequency AC coefficient, and $w$ represents the node weight (count of Gaussians) [S1, unofficial].

3.  **Distortion Modeling:**
    Derive the relationship between coefficient distortion and attribute reconstruction error [S1, unofficial].
    *   For the DC coefficient $L_{l,n}$, a distortion $\Delta L_{l,n}$ propagates uniformly to all attributes in the node:
        $$
        \Delta_{attr} = \frac{\Delta L_{l,n}}{\sqrt{w_{l,n}}} \quad \forall attr \in A_{l,n}
        $$
    *   For the AC coefficient $H_{l,n}$, a quantization distortion $\Delta H_{l,n}$ induces specific reconstruction errors in the child nodes:
        $$
        \Delta_{attr} = \mp \frac{\Delta H_{l,n}}{\sqrt{w_{l+1,2n} + w_{l+1,2n+1}}} \quad \forall attr \in A_{l+1,\{2n, 2n+1\}}
        $$
    *   The total reconstruction error $Y$ is the linear superposition of independent layer-wise errors $Y_i$:
        $$
        Y = \sum_{i=0}^{M-1} Y_i
        $$
        where $M$ is the total number of layers, and $Y_i$ is the error distribution in 3D space induced by the $i$-th layer [S1, unofficial].

4.  **Precision Error Correction:**
    Account for the precision error $\epsilon$ introduced by fixed-point arithmetic, where $a^2 + b^2 = 1 + \epsilon$ [S1, unofficial]. The reconstruction error for child coefficients is scaled by this factor:
    $$
    \Delta L_{l+1,2n} = -\epsilon L_{l+1,2n}, \quad \Delta L_{l+1,2n+1} = -\epsilon L_{l+1,2n+1}
    $$
    This error is proportional to the signal magnitude and is mitigated by the precision extension in Step 1 [S1, unofficial].

5.  **Rate-Distortion Optimization (RDO):**
    Optimize bit allocation across layers by solving for the optimal Quantization Parameter (QP) offset for each layer [S1, unofficial]. Since the distortion in the $i$-th layer is governed solely by its specific QP and is independent of other layers, the optimization problem decouples into layer-wise sub-problems [S1, unofficial]. The model allocates more bits to layers with higher sensitivity to distortion, leveraging the analytical model derived in Step 3 [S1, unofficial].

6.  **Quantization and Encoding:**
    Quantize the high-frequency coefficients $H_{l,n}$ using the optimized QP offsets and transmit them [S1, unofficial]. The low-frequency coefficients $L_{l,n}$ are inherited by the parent node for subsequent reconstruction [S1, unofficial].

7.  **Decoding:**
    Invert the process: combine the inherited parent coefficient $L_{l,n}$ with the decoded $H_{l,n}$ to reconstruct child coefficients $L_{l+1,2n}$ and $L_{l+1,2n+1}$, passing information down to the next finer layer [S1, unofficial].

**Pseudocode:**

```python
def rdo_raht_encode(attributes, octree, aps_precision):
    """
    Encodes 3DGS attributes using Rate-Distortion Optimized RAHT.
    
    Args:
        attributes: List of attribute values per node.
        octree: Octree structure with node weights w[l][n].
        aps_precision: Configurable fixed-point precision parameter.
        
    Returns:
        bitstream: Encoded bitstream including APS and quantized coefficients.
    """
    # Step 1: Configure Precision
    # Signal aps_precision in the Attribute Parameter Set (APS)
    # to mitigate fixed-point precision errors.
    precision_factor = 1.0 / (1.0 + get_precision_error(aps_precision))
    
    # Step 2: Forward Transform and RDO Optimization
    # Initialize layer-wise QP offsets
    layer_qp_offsets = optimize_layer_qp_offsets(octree, attributes, precision_factor)
    
    bitstream = []
    bitstream.append(f"APS:{aps_precision}")
    
    # RAHT is a bottom-up transform; process from deepest layer to root
    for layer in range(octree.max_depth - 1, 0, -1):
        for node in octree.nodes_at_layer(layer):
            if node.is_leaf:
                continue
            
            # Get child nodes (indices 2n and 2n+1)
            left_child = node.children[0]
            right_child = node.children[1]
            
            # Calculate weights a and b
            w_left = left_child.weight
            w_right = right_child.weight
            w_sum = w_left + w_right
            
            a = w_left / w_sum
            b = w_right / w_sum
            
            # Forward RAHT Transform
            L_left = left_child.dc_coeff
            L_right = right_child.dc_coeff
            
            L_parent = a * L_left + b * L_right
            H_parent = b * L_left - a * L_right
            
            # Step 5: Quantize using optimized QP
            base_qp = get_base_qp(layer)
            qp = base_qp + layer_qp_offsets[layer]
            quantization_step = 2.0 ** (-qp / 6.0)
            H_quantized = round(H_parent / quantization_step) * quantization_step
            
            # Encode H_quantized
            bitstream.append(f"H:{layer}:{node.index}:{H_quantized}")
            
            # Pass L_parent to parent node
            node.dc_coeff = L_parent
            
    return bitstream

def get_precision_error(aps_precision):
    """Returns epsilon for the given precision mode."""
    # Standard 15-bit fixed-point introduces non-orthogonality error
    return 1e-3 if aps_precision == 15 else 0.0

def get_base_qp(layer):

    return 12  # Not given in the sources.

def optimize_layer_qp_offsets(octree, attributes, precision_factor):
    """
    Analytically derives optimal QP offsets for each layer to minimize total distortion Y.
    Y = sum(Y_i) where Y_i is independent layer-wise error.
    """
    # The sources do not provide the exact analytical derivation for the QP offset optimization.
    # It typically involves solving a Lagrange multiplier problem for the sum of layer-wise 
    # distortions subject to a bit budget, where distortion propagation follows 
    # Delta_attr = Delta_H / sqrt(w_left + w_right) [G].
```

**Edge Cases and Pitfalls:**
*   **Fixed-Point Precision:** Standard RAHT uses 15-bit fixed-point arithmetic, which acts as a coarse quantization floor for high-precision 3DGS attributes [S1, unofficial]. Floating-point weights converted to integers violate perfect orthogonality ($a^2 + b^2 = 1 + \epsilon$), introducing precision error proportional to signal magnitude [S1, unofficial].
*   **Backward Compatibility:** The precision extension must be signaled in the APS to ensure backward compatibility [S1, unofficial]. Decoders that do not support the extension must fall back to standard 15-bit arithmetic, potentially resulting in higher distortion [S1, unofficial].
*   **Independence Assumption:** The RDO model assumes that layer-wise errors are independent [S1, unofficial]. This holds true because the distortion in the $i$-th layer is governed solely by its specific QP [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The transform is $O(N)$ where $N$ is the number of nodes [S1, unofficial]. The RDO optimization remains analytical and training-free [S1, unofficial].
*   **Memory Complexity:** $O(N)$ for storing coefficients and weights [S1, unofficial].
*   **Performance:** Achieves an average BD-rate gain of 37.87% over existing G-PCC RAHT [S1, unofficial].
*   **Strengths:** Training-free, standard-compatible, effective for high-dynamic-range attributes (e.g., 3DGS), mitigates precision error floors [S1, unofficial].
*   **Limitations:** Relies on the analytical model's accuracy [S1, unofficial].
*   **When to Use:** When compressing 3DGS data or other high-precision attribute data using G-PCC RAHT, especially in bandwidth-constrained scenarios [S1, unofficial].
*   **When Not to Use:** When neural compression methods are acceptable and training time is not a constraint, or when the attributes do not benefit from hierarchical optimization [S1, unofficial].
