# L2 Norm Wavelet Compression

Also called: L2 compression, Wavelet image compression using the L2 norm

## Overview
L2 Norm Wavelet Compression is a lossy compression method for volume data that selects a subset of wavelet coefficients to minimize the $L_2$ error norm between the original and reconstructed data [S1, unofficial]. It differs from sibling methods like [Biorthogonal Wavelet Compression](5381-biorthogonal-wavelet-compression.md) or [Wavelet Slice Compression (Video Coding Approach)](5379-wavelet-slice-compression-video-coding-approach.md) by using a global magnitude-based sorting and thresholding strategy rather than block-based coding or video-specific motion compensation [S1, unofficial]. It builds on [Wavelet and Pyramid Transforms](3856-wavelet-and-pyramid-transforms.md) by leveraging the orthonormality of the basis to guarantee that retaining the largest coefficients yields the optimal $L_2$ approximation [S1, unofficial].

## How it works
**Inputs:** A volume $V$ decomposed into a set of wavelet coefficients $C = \{c_0, c_1, \dots, c_{M-1}\}$ using the transform defined in [Wavelet and Pyramid Transforms](3856-wavelet-and-pyramid-transforms.md).
**Outputs:** A compressed bitstream containing the indices and values of the retained coefficients, or a threshold value and a list of coefficients above that threshold.
**Parameters:**
*   $\epsilon$: User-specified error tolerance. For lossless compression, $\epsilon = 0$ [S1, unofficial].
*   $M'$: The number of retained coefficients [S1, unofficial].

**Data Structures:**
The coefficients are stored in a list or array. For RGB data, coefficients are 3-byte vectors [S2, unofficial].

**Steps:**
1.  **Compute Coefficients:** Apply the wavelet transform to the input volume to obtain the coefficient set $C$ [S1, unofficial]. The basis used is typically the normalized two-dimensional Haar wavelet basis extended to 3D [S1, unofficial].
2.  **Sort Coefficients:** Sort the coefficients in order of decreasing magnitude to produce a sequence $c_{\sigma(0)}, c_{\sigma(1)}, \dots, c_{\sigma(M-1)}$ such that $|c_{\sigma(0)}| \ge |c_{\sigma(1)}| \ge \dots \ge |c_{\sigma(M-1)}|$ [S1, unofficial].
3.  **Determine Retention Count ($M'$):** Find the least integer $M' < M$ such that the sum of squared discarded coefficients is less than the error tolerance $\epsilon^2$:
    $$ \sum_{i=M'}^{M-1} (c_{\sigma(i)})^2 < \epsilon^2 $$
    This condition is derived from the orthonormality of the basis, where the $L_2$ error norm is equal to the sum of the squares of the discarded coefficients [S1, unofficial].
4.  **Encode:** Store the indices and values of the first $M'$ coefficients from the sorted sequence. Alternatively, an iterative thresholding approach may be used: repeatedly discard all coefficients smaller in magnitude than a threshold $T$, doubling $T$ in each iteration until the allowable error level is achieved [S1, unofficial].

**Pseudocode:**
```python
def l2_wavelet_compress(coefficients, epsilon):
    """
    Compress wavelet coefficients using L2 norm minimization.
    
    Args:
        coefficients (list of float): The wavelet coefficients c_0 ... c_{M-1}.
        epsilon (float): The maximum allowed L2 error norm.
        
    Returns:
        list of int: Indices of retained coefficients.
        list of float: Values of retained coefficients.
    """
    M = len(coefficients)
    
    # Step 2: Sort coefficients by magnitude, keeping track of original indices
    # Create pairs of (magnitude, original_index)
    indexed_coeffs = []
    for i, c in enumerate(coefficients):
        indexed_coeffs.append((abs(c), i))
    
    # Sort descending by magnitude
    indexed_coeffs.sort(key=lambda x: x[0], reverse=True)
    
    # Step 3: Find the least M' such that the tail sum of squares < epsilon^2
    # We iterate from the smallest coefficient upwards, accumulating the error
    # until the remaining coefficients (the head) satisfy the condition.
    # Alternatively, calculate total energy and subtract from largest.
    
    total_energy = sum(c**2 for c in coefficients)
    current_retained_energy = 0.0
    retained_indices = []
    retained_values = []
    
    # Iterate through sorted coefficients (largest first)
    for mag, original_index in indexed_coeffs:
        # Check if adding this coefficient keeps the *discarded* energy below epsilon^2
        # Discarded energy = Total Energy - Retained Energy
        # We want: Total Energy - (Retained Energy + mag^2) < epsilon^2
        # Or: Retained Energy + mag^2 > Total Energy - epsilon^2
        
        if current_retained_energy + mag**2 >= total_energy - epsilon**2:
            retained_indices.append(original_index)
            retained_values.append(coefficients[original_index])
            current_retained_energy += mag**2
        else:
            # If we can't add this coefficient and still meet the error bound,
            # we stop. However, the definition says "least M'".
            # This implies we take the largest coefficients until the condition is met.
            # The loop above adds coefficients as long as the condition holds.
            # If the condition fails for the current largest remaining, we stop.
            break
            
    return retained_indices, retained_values
```

**Edge Cases:**
*   **Lossless:** If $\epsilon = 0$, all coefficients must be retained ($M' = M$) [S1, unofficial].
*   **Precision:** The calculation of the sum of squares must handle floating-point precision carefully to ensure the error bound is strictly met [S1, unofficial].

### RGB Vector Wavelet Compression
A compression method for RGB color images by treating them as volume data with vector-valued voxels (r,g,b), reusing the CT wavelet transform and compression scheme [S2, unofficial]. It quantizes the 3-byte vector coefficients to 1-byte indices of a color table to improve compression ratio [S2, unofficial]. The input bit depth is 24-bit per voxel, and coefficients are stored in a 3-byte stream [S2, unofficial].

## Operating characteristics
**Time Complexity:** Sorting the coefficients takes $O(M \log M)$ where $M$ is the number of coefficients [S1, unofficial]. Finding $M'$ is linear in the sorted list [S1, unofficial].
**Memory Complexity:** Requires storing all coefficients for sorting, then a subset for output [S1, unofficial].
**Performance:** Demonstrated compression ratios of 1.22 bits/voxel (bpv), 0.4 bpv, and 0.10 bpv [S1, unofficial].
**Strengths:** Provides optimal $L_2$ approximation for a given number of coefficients; simple to implement [S1, unofficial].
**Limitations:** Sorting is computationally expensive for large volumes; does not exploit spatial locality as effectively as block-based methods [S1, unofficial].

## Background
Originated in the context of wavelet image compression, specifically using the Haar wavelet basis [S1, unofficial]. It was applied to CT data and RGB images [S1, S2, unofficial]. The method relies on the mathematical property that for an orthonormal basis, the best approximation in the $L_2$ norm is obtained by keeping the coefficients with the largest magnitudes [S1, unofficial].
