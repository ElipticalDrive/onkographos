# Wavelet Compression (Haar Basis)
Also called: Haar Wavelet Linear Algebra Approach, Matrix-based Haar Transform, Multiresolution Image Compression

## Overview
Wavelet Compression (Haar Basis) expresses original volume data using a smaller set of coefficients via a Haar wavelet basis, supporting both lossless and lossy compression based on a user-specified error tolerance [S1, unofficial]. It distinguishes itself from sibling methods by offering a linear algebra formulation where the transform is executed via explicit matrix multiplication, providing a mathematically explicit framework for understanding the decomposition [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A volume dataset $V$ (or a 1D vector $\tilde{x}_0$ for the 1D case) and a user-specified error tolerance $\epsilon$ [S1, unofficial]. For lossless compression, $\epsilon = 0$ [S1, unofficial].
*   **Output:** A compressed set of coefficients $\tilde{X}_1$ containing averages and differences [S2, unofficial].

**Data Structures:**
The method operates on vectors and matrices [S2, unofficial].
*   **Vector $\tilde{x}_0$:** The input data array of size $N$ [S2, unofficial].
*   **Haar Matrix $A_k$:** A matrix representing the transform at level $k$, where the columns are orthogonal with respect to the standard dot product [S2, unofficial].
*   **Combined Matrix $W$:** The product of individual level matrices $W = A_1 * A_2 * \dots * A_n$ [S2, unofficial].

**Steps:**
1.  **1D Transform (Vector):**
    For a single vector $\tilde{x}_0$, the transform is performed by multiplying by the Haar Matrix $A_1$:
    $$ \tilde{X}_1 = A_1 * \tilde{x}_0 $$
    The resulting vector $\tilde{X}_1$ contains components representing averages (low-frequency) and differences (high-frequency) of adjacent values in $\tilde{x}_0$ [S2, unofficial].

2.  **Multi-level Transform:**
    To achieve deeper compression levels, the process is recursive [S2, unofficial]. The resulting vector from level $j$ is multiplied by the next Haar matrix $A_{j+1}$, or a single combined matrix $W$ is pre-computed as the product of all level matrices:
    $$ W = A_1 * A_2 * \dots * A_n $$
    The final coefficients are obtained by applying the combined matrix:
    $$ \tilde{X}_n = W * \tilde{x}_0 $$
    [S2, unofficial]

3.  **2D Transform (Matrix):**
    For a 2D matrix $P$ of size $2^r \times 2^r$, the transform is applied separably [S2, unofficial].
    *   **Row Transformation:** $Q = P \hat{W}$ (where $\hat{W}$ is the Haar matrix applied to rows) [S2, unofficial].
    *   **Column Transformation:** The result is transposed and multiplied by the Haar matrix again, yielding:
        $$ T = W^0 P W $$
        where $W^0$ denotes the transpose of $W$ [S2, unofficial].
    *   **Decompression:** To recover $P$ from $T$:
        $$ P = (W^{-1})^0 T W^{-1} $$
        [S2, unofficial]

4.  **3D Transform (Volume):**
    The 2D approach is extended to 3D volumes [S2, unofficial]. The volume is processed by applying the Haar transform along each of the three dimensions, either by treating the volume as a stack of 2D matrices and applying the 2D transform to each followed by the third dimension, or by applying the 1D transform to vectors along each axis sequentially [S2, unofficial].

5.  **Reconstruction:**
    To recover the original data, the inverse transform is applied [S2, unofficial]. The inverse of the combined matrix is:
    $$ W^{-1} = A_1^{-1} * A_2^{-1} * \dots * A_n^{-1} $$
    [S2, unofficial]

**Parameters:**
*   **$\epsilon$ (epsilon):** User-specified error tolerance. Determines the threshold for discarding small coefficients in lossy mode. $\epsilon = 0$ for lossless [S1, unofficial].

**Pseudocode:**
```python
import math

def haar_matrix_1d(size):
    """
    Constructs the 1D orthogonal Haar transform matrix for a given power-of-2 size.
    Returns an N x N matrix A where columns are orthogonal w.r.t standard dot product [G].
    """
    if size == 1:
        return [[1.0]]
    
    A = [[0.0] * size for _ in range(size)]
    norm = 1.0 / math.sqrt(size)
    
    # First row: all 1/sqrt(N) for the DC component
    for j in range(size):
        A[0][j] = norm
        
    # Subsequent rows: Haar wavelet basis functions
    row = 1
    block_size = 1
    while row < size:
        for i in range(row):
            for j in range(block_size):
                idx = i + j
                A[row][idx] = norm
                A[row][idx + block_size] = -norm
            row += 1
        block_size *= 2
        
    return A

def transform_1d(x, W):
    """
    Applies the 1D Haar transform to vector x using matrix W.
    Returns X = W * x.
    """
    n = len(x)
    result = [0.0] * n
    for i in range(n):
        s = 0.0
        for j in range(n):
            s += W[i][j] * x[j]
        result[i] = s
    return result

def transform_2d(P, W):
    """
    Applies 2D Haar transform to matrix P.
    T = W^T * P * W (matches T = W^0 P W from source [S2, unofficial])
    """
    rows = len(P)
    cols = len(P[0])
    n = len(W)
    
    # Step 1: Row transformation Q = P * W
    Q = [[0.0] * n for _ in range(rows)]
    for i in range(rows):
        for j in range(n):
            s = 0.0
            for k in range(cols):
                s += P[i][k] * W[k][j]
            Q[i][j] = s
            
    # Step 2: Column transformation T = W^T * Q
    W_T = [[W[j][i] for j in range(n)] for i in range(n)]
    T = [[0.0] * cols for _ in range(rows)]
    for i in range(rows):
        for j in range(cols):
            s = 0.0
            for k in range(n):
                s += W_T[i][k] * Q[k][j]
            T[i][j] = s
            
    return T

def inverse_transform_2d(T, W):
    """
    Reconstructs P from T.
    P = W * T * W^T (since W is orthogonal, W^-1 = W^T, matching P = (W^-1)^0 T W^-1 [S2, unofficial])
    """
    rows = len(T)
    cols = len(T[0])
    n = len(W)
    W_T = [[W[j][i] for j in range(n)] for i in range(n)]
    
    # Step 1: T * W^T
    Q = [[0.0] * n for _ in range(rows)]
    for i in range(rows):
        for j in range(n):
            s = 0.0
            for k in range(cols):
                s += T[i][k] * W_T[k][j]
            Q[i][j] = s
            
    # Step 2: W * Q
    P = [[0.0] * cols for _ in range(rows)]
    for i in range(rows):
        for j in range(cols):
            s = 0.0
            for k in range(n):
                s += W[i][k] * Q[k][j]
            P[i][j] = s
            
    return P
```

## Subtopics

### [3D Non-standard Haar Wavelet Decomposition with Integer Packing](6693-3d-non-standard-haar-wavelet-decomposition-with-integer-pack.md)
Uses unsigned 32-bit integers to store coefficients, replacing floating-point arithmetic to leverage faster integer operations without loss of precision. It differs from standard float-based wavelet compression by utilizing the unused bits of a 32-bit integer word to handle intermediate overflows and underflows, allowing for a fixed-point hierarchy that occupies the same memory footprint as the original volume.

## Operating characteristics
*   **Time Complexity:** The dense matrix multiplication approach requires $O(N^3)$ operations for an $N \times N$ 2D matrix, which is inefficient for large datasets; the source explicitly notes that "for large data sets there are much better ways to accomplish the wavelet transform" [S2, unofficial].
*   **Memory Complexity:** The matrix-based approach requires storing the Haar matrix $W$, which is $O(N^2)$ for 2D [S2, unofficial]. The integer packing variant maintains the same memory footprint as the original volume [S1, unofficial].
*   **Strengths:** Simple mathematical definition; orthogonal basis ensures stable reconstruction; supports both lossless and lossy compression via $\epsilon$ [S1, unofficial].
*   **Limitations:** The dense matrix implementation is computationally expensive compared to fast wavelet algorithms [S2, unofficial].
*   **When to use:** When an explicit linear algebra formulation is required or for educational clarity regarding the matrix structure of the transform [S2, unofficial].

## Background
The method is based on work by Stollnitz in computer graphics, applying multiresolution decomposition using wavelets [S1, unofficial]. The matrix-based formulation is presented for volumetric data compression [S2, unofficial].
