# Shearlet Transform
Also called: Alpha Shearlet Transform, AlphaTransforms-based Shearlet Transform

## Overview
The Shearlet Transform decomposes a volume into directional, anisotropic coefficients that capture geometric features more efficiently than isotropic wavelets, particularly for surfaces with edges [S1, unofficial]. It differs from its siblings by using shear parameters to orient basis functions, providing sparse representations for objects with curved singularities, whereas wavelets and Laplacian pyramids rely on separable or fixed directional filters [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A 3D volume $V$ (or 2D image $x$ in the reference implementation).
- Output: A set of shearlet coefficients $C$.
- Reconstruction: The adjoint transform $\mathcal{S}^*$ applied to $C$ yields the reconstructed volume $\hat{V}$.

**Data Structures:**
The implementation relies on a precomputed set of Fourier coefficients. These coefficients are computed once at initialization and can be cached [S1, unofficial]. The coefficients define the basis functions in the frequency domain. For a volume of size $N \times N \times N$ (or $N \times N$ in 2D), the transform generates a specific number of coefficients based on the number of scales and shear parameters [S1, unofficial].

**Parameters:**
- $\alpha$: The alpha parameter for the shearlet transform. Typically set to $0.5$ to normalize the basis on the Fourier side to form a Parseval frame [S1, unofficial].
- $n_{scales}$: The number of scales for the transform. A typical value is $5$ [S1, unofficial].
- Image Size: The spatial dimensions of the input data (e.g., $512 \times 512$) [S1, unofficial].

**Steps:**
1.  **Initialization:** Create the Shearlet Transform object with the specified image size, number of scales, and alpha values. The Fourier coefficients are computed and stored [S1, unofficial].
    $$ \text{shearlet} = \text{ShearletTransform}(\text{size}, \text{size}, [\alpha] \times n_{scales}) $$
2.  **Forward Transform:** Compute the shearlet coefficients by applying the forward transform to the input volume $x$.
    $$ C = \text{shearlet.forward}(x) $$
3.  **Backward Transform (Reconstruction):** Reconstruct the volume from the coefficients using the adjoint transform. If $\alpha=0.5$ (Parseval frame), the composition of the forward and backward transforms is the identity mapping [S1, unofficial].
    $$ \hat{x} = \text{shearlet.backward}(C) $$

**Pseudocode:**
```python
# Initialization
# size: int, e.g., 512
# n_scales: int, e.g., 5
# alpha: float, e.g., 0.5
shearlet = ShearletTransform(size, size, [alpha] * n_scales)

# Forward Transform
# x: Input volume (tensor)
coeff = shearlet.forward(x)

# Backward Transform (Reconstruction)
# coeff: Shearlet coefficients
rec = shearlet.backward(coeff)
```

**Edge Cases and Pitfalls:**
- **Precision:** Half precision (16-bit) data can be packed 4 images into the channels of a single texture to reduce memory reads by a factor of 4. However, arithmetic operations should be performed in single precision (32-bit) to minimize accuracy loss [S1, unofficial].
- **Accuracy Loss:** Converting from single to half precision introduces a relative error. For example, the relative error between single and half representation of a Shepp-Logan phantom is $1.40 \cdot 10^{-4}$ [S1, unofficial]. The relative error between coefficients generated by the AlphaTransforms library and the TorchRadon implementation is $3.86 \cdot 10^{-7}$ in single precision [S1, unofficial].
- **Parseval Frame:** Setting $\alpha = 0.5$ ensures the transform forms a Parseval frame, meaning the energy is preserved and the adjoint acts as the inverse [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Performance:** Using half precision with texture packing provides a speedup of more than $2.5\times$ compared to single precision [S1, unofficial].
- **Strengths:** GPU-accelerated, supports parallel batch processing, sparse representation for geometric features [S1, unofficial].
- **Limitations:** Requires precomputation of Fourier coefficients [S1, unofficial].

## Background
The Shearlet Transform is implemented in the TorchRadon library, which provides fast differentiable routines for computed tomography [S1, unofficial]. The implementation is based on the AlphaTransforms library but differs by performing all operations after Fourier coefficient initialization on the GPU, enabling parallel batch processing [S1, unofficial]. The specific variant discussed uses real-valued alpha-shearlets with $\alpha = 0.5$ and 5 scales, producing 59 coefficients for a $512 \times 512$ image [S1, unofficial].
