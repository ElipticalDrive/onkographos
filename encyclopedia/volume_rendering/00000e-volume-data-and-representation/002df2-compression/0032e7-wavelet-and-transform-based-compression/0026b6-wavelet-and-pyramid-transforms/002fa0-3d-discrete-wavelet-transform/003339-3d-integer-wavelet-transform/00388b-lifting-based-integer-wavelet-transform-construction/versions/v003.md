# Lifting-Based Integer Wavelet Transform Construction

Also called: Integer Lifting Scheme, Integer Wavelet Transform via Lifting, Rounding Lifting

## Overview
The Lifting-Based Integer Wavelet Transform Construction is a method for converting standard floating-point wavelet filters (such as the Daubechies 9/7) into reversible integer-to-integer transforms suitable for lossless compression [S1]. It solves the problem of non-invertibility in traditional wavelet transforms caused by non-integer arithmetic and rounding errors [S1]. It sets itself apart from sibling methods by using the lifting scheme to decompose the transform into simple prediction and update steps, where rounding is applied at each step to ensure the output remains integer-valued while maintaining perfect reconstructibility [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 1D signal (or subband) of integer samples $x[n]$.
*   **Output:** Integer low-pass coefficients $L[n]$ and integer high-pass coefficients $H[n]$.

**Data Structures:**
*   The algorithm operates on interleaved or separate arrays of integers, with low-pass and high-pass coefficients interleaved in the lifting structure to allow simultaneous access [S1].

**Parameters:**
*   **Filter Coefficients:** The method approximates the coefficients of the target wavelet filter (e.g., Daubechies 9/7) with rational numbers or integers that allow implementation via bit shifts and additions [S1]. For example, coefficients like $1/4$ or $1/2$ are implemented as right bit shifts [S1].
*   **Rounding:** A rounding operation $\lfloor \cdot \rceil$ (round to nearest integer) is applied after every linear combination in the lifting steps [S1].

**Steps:**
1.  **Filter Approximation:** Approximate the first four lifting steps of the target wavelet filter (e.g., Daubechies 9/7) in integer form by adding rounding to each step, as detailed in the source's Table I [S1].
2.  **Scaling by Lifting:** Replace the final scaling operation (multiplying low-pass coefficients up by $s_0$ and high-pass coefficients down by $s_1$, where $s_0 s_1 = 2$ for unitary energy preservation) with four additional lifting steps that achieve the same scaling effect using integer arithmetic [S1].
3.  **Execution:** Apply all eight lifting steps sequentially. Each step computes a linear combination of samples and applies rounding [S1].

**Formulas:**
The general lifting step for a prediction or update is:
$$ y[n] = \lfloor x[n] + c \cdot z[n] \rceil $$
where $c$ is an approximated filter coefficient and $\lfloor \cdot \rceil$ denotes rounding to the nearest integer [S1].

The scaling matrix is decomposed into a product of four lifting matrices to avoid real-number multiplication:
$$ \begin{bmatrix} s_0 & 0 \\ 0 & s_1 \end{bmatrix} = \begin{bmatrix} 1 & 0 \\ \alpha & 1 \end{bmatrix} \begin{bmatrix} 1 & \beta \\ 0 & 1 \end{bmatrix} \begin{bmatrix} 1 & 0 \\ \gamma & 1 \end{bmatrix} \begin{bmatrix} 1 & \delta \\ 0 & 1 \end{bmatrix} $$
These four steps are applied using integer arithmetic [S1].

**Pseudocode:**
```python
def lifting_forward(x):
    """
    Forward Lifting-Based Integer Wavelet Transform (8-step structure).
    x: list of integers.
    Returns: low_pass, high_pass lists of integers.
    """
    even = x[0::2]
    odd = x[1::2]
    
    def round_val(v):
        return int(v + (1 if v >= 0 else -1) * 0.5)
        
    # Steps 1-4: Filter approximation lifting steps (coefficients from Table I) [S1]
    for i in range(len(odd)):
        odd[i] = round_val(odd[i] + even[i]) # Apply first filter lifting step
    for i in range(len(even)):
        even[i] = round_val(even[i] + odd[i]) # Apply second filter lifting step
    for i in range(len(odd)):
        odd[i] = round_val(odd[i] + even[i]) # Apply third filter lifting step
    for i in range(len(even)):
        even[i] = round_val(even[i] + odd[i]) # Apply fourth filter lifting step
        
    # Steps 5-8: Scaling by lifting steps (coefficients from Table II) [S1]
    for i in range(len(even)):
        even[i] = round_val(even[i] + odd[i]) # First scaling lifting step
        odd[i] = round_val(odd[i] + even[i]) # Second scaling lifting step
    for i in range(len(even)):
        even[i] = round_val(even[i] + odd[i]) # Third scaling lifting step
        odd[i] = round_val(odd[i] + even[i]) # Fourth scaling lifting step
        
    return even, odd
```

**Edge Cases and Pitfalls:**
*   **Precision:** Rounding errors accumulate, but the inverse transform uses the exact same rounding operations to ensure perfect reconstruction [S1].
*   **Memory:** The method does not require more memory than a floating-point implementation because low-pass and high-pass samples are available simultaneously due to interleaving in the lifting process [S1].
*   **Boundary Conditions:** Not given in the sources.

## Subtopics

### [Reversible Denoising Lifting Scheme DWT](11260-reversible-denoising-lifting-scheme-dwt.md)
Reversible Denoising Lifting Scheme DWT (RDLS-DWT) is a variant that replaces standard prediction and update steps with denoising-aware steps to prevent noise propagation between subbands while maintaining perfect reversibility. It sets itself apart from standard Lifting-Based Integer Wavelet Transforms by integrating irreversible denoising filters into the lifting process, allowing the transform to adapt to signal characteristics without losing invertibility.

### Scaling by Lifting
Scaling by Lifting is a technique where the final scaling matrix of the wavelet transform is decomposed into a product of four lifting matrices [S1]. This replaces the need for real-number multiplication with integer lifting steps [S1]. A key advantage is that it does not require more memory than a floating-point implementation because the low-pass and high-pass samples are available simultaneously due to interleaving in the lifting structure [S1].

## Operating characteristics
*   **Time Complexity:** Linear $O(N)$ for an input of size $N$, as it consists of a fixed number of lifting steps per sample [S1].
*   **Memory Complexity:** $O(N)$ in-place or with minimal temporary storage, as samples are interleaved and available simultaneously [S1].
*   **Performance:** The integer approximation allows for fast implementation via bit shifts and additions, avoiding expensive floating-point operations [S1].
*   **Strengths:** Perfect reversibility (lossless), simple implementation, efficient hardware realization [S1].
*   **Limitations:** The integer approximation may introduce small quantization errors compared to the ideal floating-point transform, though this is controlled by the rounding [S1].

## Background
The method was introduced in the context of lossy-to-lossless compression of medical volumetric data [S1]. It builds on the lifting scheme concept, which allows for the construction of integer wavelet transforms by approximating non-integer transforms with rounding [S1]. The specific application to the Daubechies 9/7 filter and the decomposition of scaling into lifting steps are detailed in the source [S1].
