# Optimized 3D Wavelet Transform

Also called: Optimized 3D Discrete Wavelet Transform, 3D Wavelet Optimization

## Overview
The Optimized 3D Wavelet Transform reduces the computational cost of the standard 3D Discrete Wavelet Transform (DWT) by exploiting transform separability and multiresolution data structure [S1, unofficial]. It solves the problem of high processing time associated with applying 1D transforms to all dimensions of a volumetric dataset [G]. Unlike the standard [3D Discrete Wavelet Transform](6083-3d-discrete-wavelet-transform.md), which applies the 1D transform to all rows, columns, and depth planes, this method applies the 1D transform to only one-fourth of the lines in the third dimension, reducing the number of processed data elements from $3s^3$ to $1.75s^3$, a 41.7% reduction [S1, unofficial].

## How it works
The method extends the 2D optimization strategy to 3D data [S1, unofficial]. It relies on the separability of the 3D DWT, where the 3D transform is computed as a sequence of 1D transforms along the x, y, and z axes [G].

**Inputs and Outputs:**
- Input: A volumetric dataset of size $s \times s \times s$ [S1, unofficial].
- Output: Wavelet coefficients stored in a "cushion" or transformed data structure [S1, unofficial].

**Data Structures:**
- The dataset is stored in a 3D array [G].
- A "cushion" is used to store the resulting wavelet coefficients, allowing for the nullification of original data points to save memory or prepare for the next stage [S1, unofficial].

**Steps:**
1. **Apply 1D Transform to Rows:** Apply the 1D wavelet transform to all rows along the x-axis for the entire volume [S1, unofficial].
2. **Apply 1D Transform to Columns:** Apply the 1D wavelet transform to all columns along the y-axis for the entire volume [S1, unofficial].
3. **Optimized Depth Transform:** Apply the 1D wavelet transform to only one-fourth of the lines in the third dimension (z-axis) [S1, unofficial]. The specific subset of lines chosen is not detailed in the sources [G].
4. **Store Coefficients:** Store the resulting wavelet coefficients in the new cushion and nullify the original data points [S1, unofficial].
5. **Iterative Refinement (Optional):** For multiresolution isosurface extraction, perform iterations of the forward wavelet transform only on the high-resolution region [S1, unofficial]. Modify data points at the center of boundary faces after each iteration [S1, unofficial].
6. **Extraction:** Perform isosurface extraction on the transformed data [S1, unofficial].

    """
    volume: 3D array of size s x s x s
    s: integer size of the volume dimension
    """
    # Step 1: Transform along x-axis (rows)
    for z in range(s):
        for y in range(s):

            volume[:, y, z] = apply_1d_dwt(row)

            volume[x, :, z] = apply_1d_dwt(col)

    for x in range(0, s, 4):
        for y in range(0, s, 4):
            line = volume[x, y, :]
            volume[x, y, :] = apply_1d_dwt(line)
            
    # Step 4: Store coefficients in cushion and nullify original data
    cushion = volume.copy()
    volume[:] = 0
    return cushion

**Edge Cases and Pitfalls:**
- **Boundary Conditions:** Data points at the center of boundary faces must be modified after each iteration to handle edge effects [S1, unofficial].
- **Precision:** Wavelet transforms can introduce precision errors; using floating-point arithmetic is standard [G].
- **Degenerate Input:** If the volume size $s$ is not divisible by 4, the "one-fourth" selection must be defined (e.g., floor or ceil); the source does not specify [G].

## Subtopics

### Analytical Gaussian Construction
An analytical formulation for directly representing a volumetric radiance field using Gaussian primitives by associating each wavelet coefficient with a Gaussian primitive and aggregating them via the linearity of the inverse DWT [S2, unofficial]. It solves the problem of efficiently rendering wavelet-compressed volumes by converting them into a 3D Gaussian Splatting (3DGS) compatible format [G]. Unlike standard wavelet visualization which requires inverse transform and ray marching, this method allows for real-time rendering using Gaussian primitives [G]. It is chosen when real-time visualization of wavelet-compressed data is required [G].

**Definition:**
The method maps wavelet coefficients to Gaussian primitives. Each coefficient $A_{j,o,k,c}$ in subband $(j,o)$ and spatial index $k$ for channel $c$ is associated with a Gaussian $g(x; u_{j,o,k}, \Sigma_{j,o})$ [S2, unofficial].

**Steps:**
1. **Decomposition:** Apply a J-level 3D DWT to the volumetric radiance field $V(x) = [R(x), G(x), B(x), \alpha(x)]^\top$ to obtain coefficients $\{A_{j,o,k,c}\}$ [S2, unofficial].
2. **Sparsification:** Apply an adaptive filtering strategy to retain a sparse set of significant coefficients, defining the set of retained indices $\Omega_{j,o}$ [S2, unofficial].
3. **Centroid and Covariance Estimation:** Within the Region of Interest (ROI) defined by a relative threshold $\tau$, estimate the centroid $u_{j,o}$ and covariance $\Sigma_{j,o}$ of the kernel from weighted moments [S2, unofficial]:
   $$ u_{j,o} = \frac{\sum_{x \in R} W(x) x}{\sum_{x \in R} W(x)} $$
   $$ \Sigma_{j,o} = \frac{\sum_{x \in R} W(x) (x - u_{j,o})(x - u_{j,o})^\top}{\sum_{x \in R} W(x)} $$
   where $W(x)$ is the wavelet coefficient magnitude [S2, unofficial].
4. **Translation:** Translate the canonical Gaussian center to the spatial location of the coefficient [S2, unofficial]:
   $$ u_{j,o,k} = T_{2^j k + \delta_{j,o}}(u_{j,o}) $$
   where $T$ is the translation operator [S2, unofficial].
5. **Attenuation Compensation:** Apply attenuation compensation $s_{j,o} = 2^{-3j/2}$ to account for intrinsic decay of wavelet energy at coarser scales [S2, unofficial].
6. **Amplitude Calculation:** Compute the amplitude vector $p_{j,o,k}$ by element-wise multiplication of the coefficient vector with channel weights $w_{j,o}$ [S2, unofficial]:
   $$ p_{j,o,k} = [|A_{j,o,k,R}|, |A_{j,o,k,G}|, |A_{j,o,k,B}|, |A_{j,o,k,\alpha}|]^\top \odot w_{j,o} $$
7. **Aggregation:** Combine all primitives into a unified radiance field [S2, unofficial]:
   $$ RF(x) \approx \sum_{j=1}^{J} \sum_{o} \sum_{k \in \Omega_{j,o}} s_{j,o} p_{j,o,k} g(x; u_{j,o,k}, \Sigma_{j,o}) $$

**Parameters:**
- $\tau$: Relative threshold for ROI selection, $\tau \in (0, 1)$ [S2, unofficial].
- $J$: Number of decomposition levels [S2, unofficial].

## Operating characteristics
- **Time Complexity:** The optimized method reduces the number of 1D transform operations from $3s^3$ to $1.75s^3$, a 41.7% reduction in computational cost compared to the standard separable 3D DWT [S1, unofficial].
- **Memory Complexity:** Standard for 3D DWT, requiring storage for the transformed coefficients [G]. The "cushion" technique allows in-place or low-memory storage by nullifying original data [S1, unofficial].
- **Performance:** The reduction in operations makes it faster for large volumes [G]. The source does not provide measured performance on specific hardware [S1, unofficial].
- **Strengths:** Significant reduction in processing time for 3D wavelet transforms [S1, unofficial]. Suitable for multiresolution isosurface extraction [S1, unofficial].
- **Limitations:** The specific selection of the "one-fourth" lines is not detailed, which may impact the completeness of the transform if not implemented correctly [G]. The method is specific to the wavelet domain and requires subsequent steps (like isosurface extraction or Gaussian conversion) for visualization [S1, unofficial].
- **When to use:** When computational resources are limited and a 41.7% reduction in transform time is valuable [S1, unofficial]. When using multiresolution isosurface extraction [S1, unofficial].
- **When not to use:** When full fidelity of all frequency bands is required without any approximation in the selection of processed lines [G].

## Background
The method originates from research on seamless multiresolution isosurfaces using wavelets [S1, unofficial]. It extends 2D optimization techniques to 3D to handle volumetric data more efficiently [S1, unofficial]. The Analytical Gaussian Construction variant is derived from recent work on variable basis mapping for real-time volumetric visualization [S2, unofficial], aiming to bridge wavelet compression with modern Gaussian Splatting rendering techniques [S2, unofficial].
