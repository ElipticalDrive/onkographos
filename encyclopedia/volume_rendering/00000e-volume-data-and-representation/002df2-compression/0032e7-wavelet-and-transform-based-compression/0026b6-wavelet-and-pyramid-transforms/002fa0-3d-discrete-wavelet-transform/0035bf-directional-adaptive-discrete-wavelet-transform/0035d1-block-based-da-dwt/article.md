# Block-based DA-DWT

Also called: Slice-based DA-DWT

## Overview
Block-based DA-DWT is a segmentation strategy for the Directional Adaptive Discrete Wavelet Transform (DA-DWT) that partitions volumetric data into fixed-size blocks to enable directional adaptivity. It solves the problem of efficiently selecting optimal wavelet directions for local regions by minimizing the L1-norm of high-pass coefficients. Unlike its sibling [Segmentation-Driven Directionally Adaptive DWT](7556-segmentation-driven-directionally-adaptive-dwt.md), which allows arbitrary region shapes, this method uses rigid, fixed-sized blocks, trading granularity for reduced signaling overhead.

## How it works
**Inputs:** Volumetric image data; DA-block dimensions ($N_X, N_Y, N_Z$); set of candidate direction vectors.
**Outputs:** Transformed coefficients; selected direction vector index for each DA-block.

**Data Structures:**
*   **DA-block:** A sub-volume of size $N_X \times N_Y \times N_Z$.
*   **Direction Vector:** A 2D vector representing an angle in the slice plane, indexed from a predefined set.

**Parameters:**
*   **DA-block size:** Typically $32 \times 32 \times 1$ for slice-based applications [S1].
*   **Kernel:** 5x3 wavelet for horizontal/vertical directions; Haar or 5x3 for axial [S1].
*   **Direction Set:** A set of 9 candidate vectors is commonly used [S1].

**Steps:**
1.  **Segmentation:** Partition the input volume into non-overlapping DA-blocks of size $N_X \times N_Y \times N_Z$ [S1].
2.  **Direction Selection:** For each DA-block, select two direction vectors: one for the horizontal 1D-DWT ($d_H$) and one for the vertical 1D-DWT ($d_V$) [S1].
3.  **Metric Calculation:** For each candidate direction vector $d$ in the set, calculate the L1-norm of the prediction (high-pass) coefficients generated by applying the 1D-DWT along that direction [S1].
    $$ L_1(X) = \sum_i |x_i| $$
    where $x_i$ are the high-pass coefficients [S1].
4.  **Optimization:** Select the direction vector $d$ that minimizes the L1-norm of the high-pass coefficients [S1].
5.  **Transformation:** Apply the DA-DWT using the selected direction vectors for the horizontal and vertical decompositions [S1].
6.  **Coding:** Encode the selected direction vector indexes and the transformed coefficients. Direction vectors are coded as indexes to the actual vectors in the modulus $N_D$ (number of possible direction vectors) [S1].

```python
def block_based_da_dwt(volume, block_size, direction_set):
    """
    volume: 3D array of voxel values
    block_size: tuple (Nx, Ny, Nz)
    direction_set: list of 2D direction vectors
    """
    Nx, Ny, Nz = block_size
    num_blocks_x = volume.shape[0] // Nx
    num_blocks_y = volume.shape[1] // Ny
    num_blocks_z = volume.shape[2] // Nz
    
    selected_directions = []
    transformed_volume = volume.copy()
    
    for z in range(num_blocks_z):
        for y in range(num_blocks_y):
            for x in range(num_blocks_x):
                # Extract DA-block
                block = volume[
                    x*Nx : (x+1)*Nx, 
                    y*Ny : (y+1)*Ny, 
                    z*Nz : (z+1)*Nz
                ]
                
                # Select optimal horizontal direction
                best_d_h = None
                min_l1_h = float('inf')
                
                for d in direction_set:
                    # Apply 1D-DWT along horizontal direction for this block
                    # Note: Implementation of 1D-DWT along arbitrary direction d
                    # is assumed to be available.
                    high_pass_coeffs_h = apply_1d_dwt_horizontal(block, d)
                    l1_h = sum(abs(c) for c in high_pass_coeffs_h)
                    
                    if l1_h < min_l1_h:
                        min_l1_h = l1_h
                        best_d_h = d
                
                # Select optimal vertical direction
                best_d_v = None
                min_l1_v = float('inf')
                
                for d in direction_set:
                    high_pass_coeffs_v = apply_1d_dwt_vertical(block, d)
                    l1_v = sum(abs(c) for c in high_pass_coeffs_v)
                    
                    if l1_v < min_l1_v:
                        min_l1_v = l1_v
                        best_d_v = d
                
                # Store selected directions
                selected_directions.append((best_d_h, best_d_v))
                
                # Apply DA-DWT to the block (simplified)
                # The actual transform modifies the block in place or returns new coefficients
                transformed_block = apply_da_dwt(block, best_d_h, best_d_v)
                
                # Update volume with transformed block
                transformed_volume[
                    x*Nx : (x+1)*Nx, 
                    y*Ny : (y+1)*Ny, 
                    z*Nz : (z+1)*Nz
                ] = transformed_block
                
    return transformed_volume, selected_directions
```

**Edge Cases and Pitfalls:**
*   **Boundary Conditions:** The method assumes the volume dimensions are divisible by the DA-block size. Padding or truncation may be required if not [G].
*   **L1-norm Approximation:** The L1-norm is an approximating metric for the final bit-rate and may not always select the optimal direction vector for lossless compression [S1].

## Subtopics

### Axial DA-DWT
Application of DA-DWT for axial decomposition of volumetric images. It uses 5x3 or Haar kernels for horizontal/vertical and axial directions. Optimal directions are selected by minimizing the L1-norm of high-pass coefficients. Horizontal and vertical decompositions typically use 5x3 kernel with 4 levels. Coefficients are lossless encoded with code-blocks of $32 \times 32 \times 32$. A key pitfall is that the L1-norm criterion is only an approximation and may not select the best direction in all situations. In practice, no directional features are effectively exploited between slices with current implementations, and the optimal direction vector is often $d_{A0}$ [S1].

### Block-based segmentation for DA-DWT
This variant uses tree-based segmentation to measure splitting cost versus coding gain in a rate-distortion optimal way, down to a predefined minimum DA-block size. Large DA-blocks reduce signaling overhead but decrease adaptability granularity, affecting energy compaction. Small blocks increase overhead [S1].

### Block-based DA-DWT with L1-norm metric
This is the core selection mechanism where the L1-norm of prediction (high-pass) coefficients is calculated for all candidate direction vectors. The vector minimizing this sum is selected. The metric is defined as $L_1(X) = \sum_i |x_i|$ [S1].

## Operating characteristics
*   **Complexity:** The complexity is dominated by the exhaustive search over direction vectors for each DA-block. For a block of size $B$ and $N_D$ directions, the selection cost is $O(N_D \cdot B)$.
*   **Performance:** In lossless compression of volumetric medical images, slice-based DA-DWT has close to no effect on compression efficiency compared to standard transforms. The primary gain comes from the volumetric decomposition structure rather than the directional adaptivity [S1].
*   **Limitations:** The L1-norm metric is an approximation and may not yield the optimal direction for bit-rate minimization [S1]. Typical volumetric medical images contain few directional features that can be effectively exploited [S1].

## Background
The method was proposed in the context of wavelet-based volumetric medical image compression. It builds on earlier work in segmentation-driven DA-DWT and aims to balance adaptability with signaling overhead. The approach was evaluated on medical volumetric images using 5x3 and Haar wavelet kernels [S1].
