# Segmentation-Driven Directionally Adaptive DWT

Also called: Generic segmentation (SD-DA-DWT), SD-DA-DWT, Segmentation Driven DA-DWT, Slice-based SD-DA-DWT

## Overview
Segmentation-Driven Directionally Adaptive DWT (SD-DA-DWT) is a wavelet compression method that adapts the transform direction locally by segmenting the input data into regions of similar orientation [S1]. It solves the problem of inefficient energy compaction in data with varying local geometries, which fixed-direction transforms like the parent [Directional Adaptive Discrete Wavelet Transform](7554-directional-adaptive-discrete-wavelet-transform.md) handle only globally or via block-based heuristics [S1]. Unlike [Block-based DA-DWT](7586-block-based-da-dwt.md), which uses fixed rectangular blocks, SD-DA-DWT uses irregular, gradient-based segments to maximize directional adaptability at the sample resolution [S1].

## How it works
**Inputs:** 2D slice data or volumetric dataset [S1].
**Outputs:** Compressed bitstream of wavelet coefficients. (Note: segmentation signaling overhead is typically excluded from reported bit-rates due to the lack of a suitable volumetric segmentation compression scheme [S1].)

**Data Structures:**
1. **Segment Map:** A 2D grid of integer segment IDs, one per input sample [S1].
2. **Wavelet Coefficients:** Low-pass and high-pass sub-bands generated by the directional DWT [S1].

**Parameters:**
* **Kernel:** (6,6) for the 2D SD-DA-DWT decomposition [S1].
* **Code-block size:** $64 \times 64 \times 1$ for volumetric slice-based processing to avoid inter-slice side effects [S1].
* **Direction Selection Metric:** L1-norm of the high-pass prediction coefficients [S1].

**Steps:**
1. **Segmentation:** Apply the Edgementation algorithm to the input slice [S1]. This performs gradient-based segmentation to identify initial regions, followed by rate-distortion-driven segment merging to reduce complexity, and contour simplification to limit overhead [S1]. Contour coding uses the algorithm from [53] [S1].
2. **Direction Selection:** For each segment, determine the optimal direction vector $d$ by evaluating the L1-norm of the high-pass prediction coefficients for all candidate directions in a predefined set [S1].
3. **Transformation:** Apply the 2D SD-DA-DWT using the (6,6) kernel and the selected direction $d$ for each segment [S1].
4. **Coding:** Encode the resulting coefficients using EBCOT (Embedded Block Coding with Optimized Truncation) [S1]. Organize coefficients into code-blocks of size $64 \times 64 \times 1$ [S1].

**Formulas:**
The direction selection metric is the L1-norm of the high-pass coefficients $H$ within a segment $S$:
$$ M(d) = \sum_{(i,j) \in S} |H_{i,j}(d)| $$
where $H_{i,j}(d)$ is the high-pass prediction coefficient at spatial location $(i,j)$ for candidate direction $d$ [S1]. The optimal direction $d^*$ minimizes this metric: $d^* = \arg\min_d M(d)$ [S1].

    # volume_data: 3D array of shape (Z, Y, X) [S1]
    compressed_stream = []
    candidate_directions = [(1, 0), (0, 1), (1, 1), (1, -1)] # [G] standard 2D directional set
    kernel = (6, 6) # [S1]
    block_size = (64, 64) # [S1]
    
    for z in range(volume_data.shape[0]):
        slice_data = volume_data[z, :, :]
        
        # Step 1: Segment the slice using Edgementation
        segments = edgementation_segmentation(slice_data) # [G] gradient-based segmentation, rate-distortion merging, contour simplification [S1]
        
        # Step 2: Direction selection per segment
        directions = {}
        unique_ids = set(segments.flatten())
        for seg_id in unique_ids:
            mask = (segments == seg_id)
            min_l1 = float('inf')
            best_d = candidate_directions[0]
            for d in candidate_directions:
                high_pass = directional_high_pass(slice_data, d, kernel) # [G] directional prediction step
                l1 = sum(abs(high_pass[i, j]) for i, j in zip(*mask.nonzero())) # [S1]
                if l1 < min_l1:
                    min_l1 = l1
                    best_d = d
            directions[seg_id] = best_d
            
        # Step 3: Apply 2D SD-DA-DWT per segment using selected directions [S1]
        coeffs = apply_directional_dwt_2d(slice_data, segments, directions, kernel) # [G] standard DWT decomposition
        
        # Step 4: Encode with EBCOT using 64x64 code-blocks [S1]
        ebcot_stream = ebcot_encode(coeffs, block_size) # [G] standard EBCOT entropy coding
        compressed_stream.append(ebcot_stream)
        
    return compressed_stream

**Edge Cases and Pitfalls:**
* **Volumetric Complexity:** Determining optimal 3D segmentation is complex; the method typically degrades to 2D slice-based processing for medical data [S1].
* **Overhead:** Storing segmentation descriptions incurs severe overhead. In many evaluations, this overhead is ignored because no suitable volumetric segmentation compression scheme was available, potentially inflating perceived performance [S1].
* **Failure Mode:** SD-DA-DWT can fail completely if segmentation does not match regions with similar directional features [S1].
* **Coding Efficiency:** Non-alignment of segmentation boundaries with EBCOT code-block structures negatively influences entropy coder efficiency [S1].

## Subtopics

### [Direction-Adaptive DWT (DA-DWT)](7827-direction-adaptive-dwt-da-dwt.md)
DA-DWT is a wavelet transform technique where the direction vector $d$ changes dynamically based on spatial location to optimize energy compaction for localized directional features in volumetric data. It solves the problem of inefficient energy compaction when using fixed-direction transforms on data with varying local orientations. Unlike standard 3D DWT which uses fixed axes, DA-DWT adapts to the data's geometry, but requires signaling the chosen direction in the code-stream.

## Operating characteristics
* **Performance:** For medical volumetric images, SD-DA-DWT delivers no significant overall compression improvements compared to classical DWT [S1]. Only specific datasets (CT5, CT6) show modest gains, but these results exclude segmentation signaling overhead [S1].
* **Complexity:** High computational complexity due to the iterative Edgementation segmentation process and per-segment direction selection [S1].
* **Overhead:** Significant overhead from segmentation metadata. The method's practical utility is limited by the lack of efficient volumetric segmentation compression [S1].
* **Strengths:** Maximal directional adaptability at sample resolution [S1].
* **Limitations:** Fails on images where segmentation cannot match directional features; sensitive to code-block alignment; high overhead [S1].
* **When to use:** Theoretical analysis of directional adaptability limits [S1].
* **When not to use:** Practical volumetric medical image compression where overhead and complexity are critical [S1].

## Background
SD-DA-DWT was introduced in the work of [34] (cited in [S1]) as a generic segmentation-driven approach [S1]. It applies 2D SD-DA-DWT to volumetric datasets by segmenting slices separately, using the (6,6) kernel [S1]. The segmentation relies on the Edgementation algorithm [51, 52] and contour coding from [53] [S1].
