# Block-based DA-DWT

Also called: Slice-based DA-DWT

## Overview
Block-based DA-DWT is a segmentation strategy for the Directional Adaptive Discrete Wavelet Transform (DA-DWT) that partitions volumetric data into fixed-size blocks to enable directional adaptivity [S1]. It solves the problem of efficiently selecting optimal wavelet directions for local regions by minimizing the L1-norm of high-pass coefficients [S1]. Unlike its sibling [Segmentation-Driven Directionally Adaptive DWT](7556-segmentation-driven-directionally-adaptive-dwt.md), which allows arbitrary region shapes, this method uses rigid, fixed-sized blocks, trading granularity for reduced signaling overhead [S1].

## How it works
**Inputs:** Volumetric image data; DA-block dimensions ($N_X, N_Y, N_Z$); set of candidate direction vectors [S1].
**Outputs:** Transformed coefficients; selected direction vector index for each DA-block [S1].

**Data Structures:**
*   **DA-block:** A sub-volume of size $N_X \times N_Y \times N_Z$ [S1].
*   **Direction Vector:** A 2D vector representing an angle in the slice plane, indexed from a predefined set [S1].

**Parameters:**
*   **DA-block size:** Typically $32 \times 32 \times 1$ for slice-based applications [S1].
*   **Kernel:** 5x3 wavelet for horizontal/vertical directions; Haar or 5x3 for axial [S1].
*   **Direction Set:** A set of 9 candidate vectors is commonly used [S1].
*   **Entropy Coding:** EBCOT with volumetric code-blocks of $32 \times 32 \times 32$ pixels [S1].

**Steps:**
1.  **Segmentation:** Partition the input volume into non-overlapping DA-blocks of size $N_X \times N_Y \times N_Z$ [S1].
2.  **Direction Selection:** For each DA-block, select two direction vectors: one for the horizontal 1D-DWT ($d_H$) and one for the vertical 1D-DWT ($d_V$) [S1].
3.  **Metric Calculation:** For each candidate direction vector $d$ in the set, calculate the L1-norm of the prediction (high-pass) coefficients generated by applying the 1D-DWT along that direction [S1].
    $$ L_1(X) = \sum_i |x_i| $$
    where $x_i$ are the high-pass coefficients [S1].
4.  **Optimization:** Select the direction vector $d$ that minimizes the L1-norm of the high-pass coefficients [S1].
5.  **Transformation:** Apply the DA-DWT using the selected direction vectors for the horizontal and vertical decompositions [S1].
6.  **Coding:** Encode the selected direction vector indexes and the transformed coefficients. Direction vectors are coded as indexes to the actual vectors in the modulus $N_D$ (number of possible direction vectors) [S1].

**Pseudocode:**
```python
def block_based_da_dwt(volume, block_size, direction_set):
    Nx, Ny, Nz = block_size
    num_blocks_x = volume.shape[0] // Nx
    num_blocks_y = volume.shape[1] // Ny
    num_blocks_z = volume.shape[2] // Nz
    
    selected_directions = []
    transformed_volume = volume.copy()
    
    for z in range(num_blocks_z):
        for y in range(num_blocks_y):
            for x in range(num_blocks_x):
                block = volume[x*Nx:(x+1)*Nx, y*Ny:(y+1)*Ny, z*Nz:(z+1)*Nz]
                
                best_d_h, min_l1_h = None, float('inf')
                for d in direction_set:
                    # Sources do not specify the exact 1D-DWT implementation along arbitrary directions [G]
                    coeffs_h = standard_1d_dwt(block, axis=0)
                    l1_h = sum(abs(c) for c in coeffs_h)
                    if l1_h < min_l1_h:
                        min_l1_h = l1_h
                        best_d_h = d
                
                best_d_v, min_l1_v = None, float('inf')
                for d in direction_set:
                    coeffs_v = standard_1d_dwt(block, axis=1)
                    l1_v = sum(abs(c) for c in coeffs_v)
                    if l1_v < min_l1_v:
                        min_l1_v = l1_v
                        best_d_v = d
                
                selected_directions.append((best_d_h, best_d_v))
                # Sources do not specify the exact DA-DWT application routine [G]
                transformed_block = apply_da_dwt(block, best_d_h, best_d_v)
                transformed_volume[x*Nx:(x+1)*Nx, y*Ny:(y+1)*Ny, z*Nz:(z+1)*Nz] = transformed_block
                
    return transformed_volume, selected_directions

def standard_1d_dwt(signal, axis):

def apply_da_dwt(block, d_h, d_v):
```

**Edge Cases and Pitfalls:**
*   **Boundary Conditions:** The method assumes the volume dimensions are divisible by the DA-block size. Padding or truncation may be required if not [G].
*   **L1-norm Approximation:** The L1-norm is an approximating metric for the final bit-rate and may not always select the optimal direction vector for lossless compression [S1].

## Subtopics

### Axial DA-DWT
Application of DA-DWT for axial decomposition of volumetric images [S1]. It uses 5x3 or Haar kernels for horizontal/vertical and axial directions [S1]. Optimal directions are selected by minimizing the L1-norm of high-pass coefficients [S1]. Horizontal and vertical decompositions typically use 5x3 kernel with 4 levels [S1]. Coefficients are lossless encoded with code-blocks of $32 \times 32 \times 32$ [S1]. A key pitfall is that the L1-norm criterion is only an approximation and may not select the best direction in all situations [S1]. In practice, no directional features are effectively exploited between slices with current implementations, and the optimal direction vector is often $d_{A0}$ [S1].

### Block-based segmentation for DA-DWT
This variant segments input into fixed-sized $N_X \times N_Y \times N_Z$ blocks (DA-blocks) [S1]. It signals globally chosen DA-block dimensions and one selected direction vector for each DA-block [S1]. It uses tree-based segmentation to measure splitting cost versus coding gain in a rate-distortion optimal way, down to a predefined minimum DA-block size [S1]. Large DA-blocks reduce signaling overhead but decrease adaptability granularity, affecting energy compaction [S1]. Small blocks increase overhead [S1].

### Block-based DA-DWT with L1-norm metric
This is the core selection mechanism where the L1-norm of prediction (high-pass) coefficients is calculated for all candidate direction vectors [S1]. The vector minimizing this sum is selected [S1]. The metric is defined as $L_1(X) = \sum_i |x_i|$ [S1].

## Operating characteristics
*   **Complexity:** The complexity is dominated by the exhaustive search over direction vectors for each DA-block. For a block of size $B$ and $N_D$ directions, the selection cost is $O(N_D \cdot B)$ [G].
*   **Performance:** In lossless compression of volumetric medical images, slice-based DA-DWT has close to no effect on compression efficiency compared to standard transforms. The primary gain comes from the volumetric decomposition structure rather than the directional adaptivity [S1].
*   **Limitations:** The L1-norm metric is an approximation and may not yield the optimal direction for bit-rate minimization [S1]. Typical volumetric medical images contain few directional features that can be effectively exploited [S1].

## Background
The method was proposed in the context of wavelet-based volumetric medical image compression [S1]. It builds on earlier work in segmentation-driven DA-DWT and aims to balance adaptability with signaling overhead [S1]. The approach was evaluated on medical volumetric images using 5x3 and Haar wavelet kernels [S1].
