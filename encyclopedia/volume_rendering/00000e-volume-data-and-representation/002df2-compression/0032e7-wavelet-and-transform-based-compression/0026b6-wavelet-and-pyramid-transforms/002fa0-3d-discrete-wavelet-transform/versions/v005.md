# 3D Discrete Wavelet Transform

Also called: 3D Wavelet Transformation

## Overview
The 3D Discrete Wavelet Transform (3D DWT) is a multiresolution decomposition method that extends the 2D algorithm to volumetric data by applying a separable three-pass filter bank along the $x$, $y$, and $z$ axes [S1, unofficial]. It generates a hierarchical pyramid representation of the volume, serving as the foundational transform for subsequent compression and rendering stages. Unlike its siblings, it applies a fixed, axis-aligned decomposition hierarchy without adaptive direction selection or integer-only constraints [G].

## How it works
**Inputs and Outputs:**
- Input: A 3D volume $V$ of dimensions $N_x \times N_y \times N_z$.
- Output: A hierarchical set of wavelet coefficients organized in a pyramid structure, consisting of one approximation subband and multiple detail subbands at each decomposition level [S1, unofficial][G].

**Data Structures:**
For a single level of decomposition, the input volume is split into 8 subbands of size $\frac{N_x}{2} \times \frac{N_y}{2} \times \frac{N_z}{2}$ (assuming even dimensions and downsampling) [G]:
1. $LLL$: Approximation (Low-Low-Low)
2. $HLL$: Detail (High-Low-Low)
3. $LHL$: Detail (Low-High-Low)
4. $LLH$: Detail (Low-Low-High)
5. $HHL$: Detail (High-High-Low)
6. $HLH$: Detail (High-Low-High)
7. $LHH$: Detail (Low-High-High)
8. $HHH$: Detail (High-High-High)

**Algorithm Steps:**
The transform is separable and applied in three passes, one for each dimension [S1, unofficial]:
1. **Pass 1 (X-axis):** Apply 1D DWT along the $x$-axis for all $y, z$. This splits the volume into low-pass ($L_x$) and high-pass ($H_x$) components.
2. **Pass 2 (Y-axis):** Apply 1D DWT along the $y$-axis for all $x, z$ on the results of Pass 1. This splits $L_x$ into $LL_{xy}$ and $H_x$ into $HL_{xy}$, and similarly for the other components.
3. **Pass 3 (Z-axis):** Apply 1D DWT along the $z$-axis for all $x, y$ on the results of Pass 2. This splits each of the 4 intermediate subbands into two, yielding the 8 final subbands.

**Recursive Decomposition:**
The approximation subband $LLL$ from level $j$ is used as the input for level $j+1$. This process repeats until the dimension of the approximation subband becomes small enough (e.g., $16 \times 16 \times 16$), generating a pyramid wavelet representation [S1, unofficial].

**Pseudocode:**
```python
def dwt_3d(volume, levels=1):
    """
    Performs a multi-level 3D Discrete Wavelet Transform.
    volume: 3D numpy array of shape (Nx, Ny, Nz)
    levels: number of recursive decomposition levels
    """
    current = volume
    coefficients = []
    for _ in range(levels):
        # Pass 1: X-axis
        current = dwt_1d_axis(current, axis=0)
        # Pass 2: Y-axis
        current = dwt_1d_axis(current, axis=1)
        # Pass 3: Z-axis
        current = dwt_1d_axis(current, axis=2)
        # Extract approximation subband (first half along each axis)
        approx = current[:current.shape[0]//2, :current.shape[1]//2, :current.shape[2]//2]
        coefficients.append(current)
        current = approx
    return coefficients
```

- Wavelet Filter: Not given in the sources. Standard implementations typically use orthogonal or biorthogonal filter banks [G].
- Decomposition Levels: Determined by the target resolution of the approximation subband (e.g., stopping at $16 \times 16 \times 16$) [S1, unofficial].

**Edge Cases:**
- Boundary Handling: Not given in the sources. Implementers must choose a method to handle voxels at the volume boundaries during convolution [G].
- Dimension Size: The recursive process assumes dimensions are divisible by $2^L$ where $L$ is the number of levels. If not, padding or truncation is required [G].

## Subtopics

### [Depth-plane Reduction](6446-depth-plane-reduction.md)
Deforms a volumetric model by shifting voxels to fill empty depth planes, reducing the total planes required for the 3D transform. Chosen when the volume has sparse depth distribution.

### [3D Integer Wavelet Transform](6956-3d-integer-wavelet-transform.md)
Maps integer input to integer coefficients using embedded rounding, ensuring perfect reconstruction with finite precision. Chosen when lossless compression with finite arithmetic is required.

### [3-D Medical Image Compression with VOI Coding](7407-3-d-medical-image-compression-with-voi-coding.md)
Partitions coefficients into code-cubes and uses modified EBCOT to enable scalable, arbitrary Volume of Interest (VOI) retrieval. Chosen for telemedicine applications requiring selective VOI decoding.

### [Directional Adaptive Discrete Wavelet Transform](7554-directional-adaptive-discrete-wavelet-transform.md)
Selects the optimal decomposition direction for each block to align with non-axis-aligned features. Chosen for data with smooth, rotated structures where fixed-axis transforms underperform.

### [3-D SPIHT](8260-3-d-spiht.md)
Treats coefficients as 3-D spatio-temporal orientation trees for embedded entropy coding. Chosen when a scalable bitstream with high compression ratios is needed.

## Operating characteristics
- **Time Complexity:** $O(N \cdot L)$ where $N$ is the number of voxels and $L$ is the number of decomposition levels, as each voxel is processed a constant number of times per level [G].
- **Memory Complexity:** $O(N)$ for storing the coefficients. The total size of all subbands at one level equals the input size [G].
- **Strengths:** Simple to implement, separable, and provides a standard multi-resolution hierarchy [G].
- **Limitations:** Not given in the sources.

## Background
The 3D DWT is a straightforward extension of the 2D algorithm to 3D data [S1, unofficial]. It has been used in computer graphics and engineering for image and volume compression, leveraging multiresolution decomposition to enable efficient storage and rendering [S1, unofficial].
