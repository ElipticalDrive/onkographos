# MMD2_MC_5/3


## Overview
MMD2_MC_5/3 is a lossless volumetric compression technique for medical images that applies a 2D Multiplicative Multiresolution Decomposition (MMD) for spatial decomposition within each slice, followed by an MC_5/3 filter in the inter-slice direction, and finally encodes the resulting sub-bands using 3D SPIHT [S1]. It differs from its sibling [MMD1_MC_5/3](23818-mmd1-mc-5-3.md) by using 2D MMD in both $x$ and $y$ directions for spatial decorrelation, whereas MMD1_MC_5/3 uses 1D MMD in $x$ and 1D integer wavelet transform in $y$ [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D medical image volume $X$ with dimensions $N_x \times N_y \times N_z$.
*   **Output:** A compressed bitstream representing the volume losslessly.

**Data Structures:**
The volume is processed as a set of Groups of Slices (GOS). A GOS consists of $M$ consecutive slices in the $z$-direction [S1]. The specific value of $M$ is not given in the sources [G].

**Steps:**
1.  **Spatial Decomposition (2D MMD):** For each slice in the volume, apply a 2D MMD in the $x$ and $y$ directions [S1]. This replaces the 1D MMD (x) and 1D IWT (y) used in MMD1_MC_5/3 [S1].
2.  **Inter-slice Filtering (MC_5/3):** Apply the MC_5/3 filter in the $z$-direction to the sub-bands obtained from the spatial decomposition [S1]. The MC_5/3 filter uses different prediction techniques to reduce the energy of the sub-bands [S1].
3.  **Coding (3D SPIHT):** Encode the filtered sub-bands using 3D SPIHT (Set Partitioning in Hierarchical Trees) [S1].

## Subtopics

### WT_MC_5/3
WT_MC_5/3 is a compression technique using a 2D integer wavelet transform in the spatial directions ($x, y$) followed by the MC_5/3 filter in the inter-slice direction ($z$), coded with 3D SPIHT [S1]. It differs from MMD2_MC_5/3 by using the 2D integer wavelet transform instead of 2D MMD for spatial decomposition [S1]. It is used as a reference compression technique for evaluating the performance of MMD-based techniques on 3D medical images [S1].

## Operating characteristics
*   **Lossless Compression:** The MMD approach permits lossless improvement compared with classic approaches such as 3D SPIHT and JP3D [S1].

## Background
The technique is presented in the paper "Multiplicative Multiresolution Decomposition for Lossless Volumetric Medical Images Compression" [S1]. The paper introduces MMD-based techniques (MMD1_3D-SPIHT, MMD1_MC_5/3, MMD2_MC_5/3) and compares them with WT-based techniques (WT_3D-SPIHT, WT_MC_5/3) and classic approaches (3D SPIHT, JP3D) for lossless compression of volumetric medical images [S1]. The WT_3D-SPIHT is based on 3D integer wavelet transform and 3D SPIHT coding [S1].
