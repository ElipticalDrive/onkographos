# 3-D SPIHT

Also called: 3-D Set Partitioning in Hierarchical Trees, SPIHT for Volumetric Data, SPIHT-based zero tree coding, Set Partitioning in Hierarchical Trees (SPIHT) application to distance volumes, Three-Dimensional SPIHT, Zero Tree Coder for Signed-Distance Volumes

## Overview
3-D SPIHT is an embedded entropy coder for 3-D volumetric data that treats wavelet coefficients as 3-D spatio-temporal orientation trees [S1]. It solves the problem of compressing volumetric datasets by exploiting spatial redundancy across all three dimensions, achieving significantly higher compression ratios than 2-D methods [S1]. Unlike its sibling [Depth-plane Reduction](6446-depth-plane-reduction.md), which reduces dimensionality, 3-D SPIHT fully utilizes the third dimension to decorrelate data, resulting in a small edge over 3-D CB-EZW in lossless coding and superior performance over 2-D SPIHT [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3-D volume of wavelet coefficients (typically from a 3-D Discrete Wavelet Transform).
*   **Output:** A bitstream containing significance bits, zerotree symbols, sign bits, and magnitude bits.

**Data Structures:**
The algorithm organizes coefficients into **spatio-temporal orientation trees** (or spatial orientation trees for static volumes). Each tree consists of coefficients from all subbands that correspond to the same spatial location in the volume [S1].
*   **Tree Structure:** A parent node in the tree corresponds to a coefficient at a coarser scale (lower resolution), and its children correspond to coefficients at finer scales (higher resolution) at the same spatial location [S1].
*   **Significance State:** A set of coefficients is **significant** if the maximum magnitude among its coefficients is greater than or equal to a threshold $T$. Otherwise, it is **insignificant** [S1]. A single coefficient is significant if its magnitude is $\ge T$ [S1].

**Algorithm Steps:**
1.  **Initialization:** Determine the initial threshold $T$. Typically, $T$ is set to half the value of the largest wavelet coefficient magnitude in the volume [S2]. If powers of two are used, $T$ is the largest power of two less than or equal to the maximum coefficient magnitude [S1].
2.  **Sorting Pass (Significance Testing):**
    *   Traverse the orientation trees.
    *   Test the significance of larger sets (roots of subtrees) first [S1].
    *   If a set is **insignificant** (max magnitude $< T$), emit a **zerotree bit** (or symbol) to indicate that all coefficients in that subtree are insignificant with respect to the current threshold [S1, S2]. This efficiently encodes the positions of insignificant coefficients [S2].
    *   If a set is **significant**, partition it into subsets (child sets) for further significance tests in the current pass [S1].
    *   If a set is a single coefficient and is significant, proceed to the refinement pass.
3.  **Refinement Pass (Magnitude Encoding):**
    *   For coefficients that were already significant in previous passes (but not yet fully encoded), transmit the next most significant bit of their magnitude [S2].
    *   For coefficients that just became significant in the sorting pass, transmit their **sign bit** and their **most significant bit** (the bit corresponding to the current threshold $T$) [S2].
4.  **Threshold Update:** Halve the threshold $T$ (i.e., $T \leftarrow T / 2$) [S1, S2].
5.  **Iteration:** Repeat steps 2–4 until the desired bit rate is reached or all coefficients are encoded. Each traversal progressively adds more coefficients to the significant group [S2].

**Parameters:**
*   **Threshold ($T$):** Starts at half the maximum coefficient magnitude and is halved each pass [S2].
*   **Context Models:** For lossy-to-lossless coding, context models with 2 symbols ($k=0,1$) are used for groups of 8 pixels to code information based on the number of significant pixels [S1].
*   **Bit Plane Skipping:** In lossy-to-lossless coding, bit planes of all zeros generated by bit shifts in certain subbands are skipped [S1].

**Edge Cases and Pitfalls:**
*   **Geometric Error:** For signed-distance volumes, standard zero tree coding assumes an L1 error because the significance test depends only on the coefficient value, not the wavelet support size. This can lead to suboptimal bit ordering for geometric accuracy [S2].
*   **Topology Changes:** The basic implementation does not track topology changes, which can produce holes in thin shapes at small bit counts that disappear later [S2].
*   **Error Metrics:** Standard error metrics may over-emphasize errors of small components removed early in reconstruction [S2].

## Subtopics

### [Asymmetric Tree SPIHT (AT-SPIHT)](13879-asymmetric-tree-spiht-at-spiht.md)
A variant that uses asymmetric trees to exploit statistical disparities between intraslice and interslice coefficients, achieving better compression for medical volumes.

## Operating characteristics
*   **Time Complexity:** Not explicitly given in sources, but described as having "relatively low complexity" [S1]. Encoding/decoding the whole 192 slices of Skull takes 13 seconds for decoding on a Pentium 1-GHz PC [S1].
*   **Memory Complexity:** Not explicitly given, but requires storing orientation trees and state lists.
*   **Performance:** 3-D SPIHT is 7.65 dB better than 2-D SPIHT at 0.1 b/p and 6.21 dB better at 0.5 b/p [S1]. It has a small edge over 3-D CB-EZW in lossless coding [S1].
*   **Strengths:** Embedded bitstream (allows progressive transmission), low complexity, effective decorrelation in 3-D [S1].
*   **Limitations:** Geometric error for signed-distance volumes can be improved with modified bit ordering [S2]. Topology changes are not tracked, potentially causing transient holes [S2]. Using generic entropy coders (like gzip) as a backend is less efficient than tailored arithmetic coding [S2].

## Background
3-D SPIHT was introduced by B.-J. Kim, Z. Xiong, and W. A. Pearlman in "Low bit-rate scalable video coding with 3-D set partitioning in hierarchical trees (3-D SPIHT)" (IEEE Trans. Circuits Syst. Video Technol., vol. 10, pp. 1365–1374, Dec. 2000) [S1]. It extends the 2-D SPIHT algorithm [5] to 3-D data by treating wavelet coefficients as 3-D spatio-temporal orientation trees [S1]. It is widely used in medical image compression, particularly for volumetric data like CT and MR scans [S1].
