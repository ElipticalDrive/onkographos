# 3-D SPIHT

Also called: 3-D Set Partitioning in Hierarchical Trees, SPIHT for Volumetric Data, Three-Dimensional SPIHT

## Overview
3-D SPIHT is an embedded entropy coder for 3-D volumetric data that treats wavelet coefficients as 3-D spatio-temporal orientation trees [S1]. It extends the 2-D SPIHT algorithm by exploiting redundancies across the third dimension, improving compression by approximately 35% on average compared to 2-D methods [S1]. It offers a small edge over 3-D CB-EZW in lossless coding and significantly outperforms 2-D SPIHT in lossy scenarios [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** 3-D volumetric data (e.g., medical images) transformed via a 3-D wavelet transform (such as the 3-D Integer Wavelet Transform).
*   **Output:** An embedded bitstream. Decoding any truncated version of this stream yields a lossy version of the original data with quality commensurate with the bit rate [S1].

**Data Structures:**
*   **3-D Spatio-Temporal Orientation Trees:** Coefficients are organized into trees where each node represents a group of wavelet coefficients from all subbands corresponding to the same spatial location across time/slices [S1].
*   **Significance State:** A set is significant if the largest coefficient magnitude $\theta$ in the set is greater than or equal to a threshold $T$ [S1]. A coefficient is significant if its magnitude is $\ge T$ [S1].

**Algorithm Steps:**
1.  **Initialization:** Set the initial threshold $T$ to a power of two, typically determined by the maximum coefficient magnitude in the volume [S1].
2.  **Significance Testing (Pass):**
    *   Test the significance of larger sets in the tree first [S1].
    *   If a set is insignificant (max magnitude $< T$), emit a "zerotree" bit to indicate all coefficients in the set are zero relative to the current threshold [S1].
    *   If a set is significant, partition it into subsets (child sets) for further significance tests [S1].
    *   Individual coefficients are tested similarly; insignificant coefficients are marked as zero [S1].
3.  **Threshold Update:** After all coefficients in the current pass are tested, halve the threshold ($T \leftarrow T / 2$) before the next pass [S1].
4.  **Lossy-to-Lossless Optimization:** For lossy-to-lossless coding, skip bit planes of all zeros generated by bit shifts in certain subbands to reduce bitstream size [S1].
5.  **Context Modeling:** To increase efficiency, each node in the orientation tree represents a group of 8 pixels [S1]. Use context models with 2 symbols ($k=0,1$) to code information based on the number of significant pixels in the group [S1]. Different contexts provide better probability estimates conditioned on the number of adjacent significant/insignificant pixels [S1].

    """
    Encodes 3D wavelet coefficients using 3-D SPIHT.
    coefficients: 3D array of wavelet coefficients.
    initial_threshold: Initial threshold T (power of 2).
    """
    threshold = initial_threshold
    bitstream = []
    
    # Build 3-D spatio-temporal orientation trees
    # Each tree node represents a group of 8 coefficients from subbands
    # at the same spatial location across time/slices.
    trees = build_orientation_trees(coefficients)
    
    while threshold > 0:
        # Pass 1: Significance Testing
        for tree in trees:
            if not tree.is_significant(threshold):
                # Emit zerotree bit
                bitstream.append(0)
            else:
                # Set is significant, partition into subsets
                bitstream.append(1)
                for child_set in tree.partition():
                    if child_set.is_significant(threshold):
                        bitstream.append(1)
                        # Further partition or test individual coefficients
                        for coeff in child_set.get_coefficients():
                            if abs(coeff) >= threshold:
                                bitstream.append(1)
                                # Encode sign and magnitude bits
                                encode_sign_and_magnitude(coeff, threshold, bitstream)
                            else:
                                bitstream.append(0)
                    else:
                        bitstream.append(0)
                        # Emit zerotree for this subset
                        bitstream.append(0)

    return bitstream

**Parameters:**
*   **Threshold:** Starts as a power of two, halved each pass [S1].
*   **Group Size:** 8 pixels per node for context modeling [S1].

**Edge Cases and Pitfalls:**
*   **Boundary Conditions:** PSNR drops may occur across GOP boundaries (beginning and end of data volume) unless memory-constrained wavelet transforms are used [S1].
*   **Precision:** The algorithm assumes floating-point or integer coefficients; bit shifts for thresholding require careful handling of integer arithmetic [S1].

## Operating characteristics
*   **Complexity:** 3-D SPIHT has relatively low complexity compared to 3-D ESCOT, which is about 50% more complex [S1].
*   **Performance:** On a Pentium 1-GHz PC, decoding the whole 192 slices of Skull takes 13 seconds for 3-D SPIHT [S1]. Encoding/decoding the whole 192 slices of Skull takes 20 seconds for 3-D ESCOT and 13 seconds for 3-D SPIHT [S1].
*   **Quality:** 3-D SPIHT is 7.65 dB better than 2-D SPIHT at 0.1 b/p and 6.21 dB better at 0.5 b/p [S1]. It gains about 10% over 3-D CB-EZW in lossless coding [S1].
*   **Scalability:** Embedded bitstream allows for scalable decoding at different bit rates [S1].

## Background
3-D SPIHT was introduced by B.-J. Kim, Z. Xiong, and W. A. Pearlman in "Low bit-rate scalable video coding with 3-D set partitioning in hierarchical trees (3-D SPIHT)" (IEEE Trans. Circuits Syst. Video Technol., vol. 10, pp. 1365–1374, Dec. 2000) [S1]. It extends the 2-D SPIHT algorithm [S1] to 3-D embedded SPIHT video coding, treating 3-D wavelet coefficients as a collection of 3-D spatio-temporal orientation trees [S1]. It is used for lossy-to-lossless compression of medical volumetric data [S1].
