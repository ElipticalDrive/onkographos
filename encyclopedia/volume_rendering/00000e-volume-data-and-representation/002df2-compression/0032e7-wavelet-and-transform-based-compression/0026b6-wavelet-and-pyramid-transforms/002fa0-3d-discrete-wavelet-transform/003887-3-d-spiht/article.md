# 3-D SPIHT

Also called: 3-D Set Partitioning in Hierarchical Trees, SPIHT for Volumetric Data, SPIHT-based zero tree coding, Set Partitioning in Hierarchical Trees (SPIHT) application to distance volumes, Three-Dimensional SPIHT, Zero Tree Coder for Signed-Distance Volumes

## Overview
3-D SPIHT is an embedded entropy coder for 3-D volumetric data that treats wavelet coefficients as 3-D spatio-temporal orientation trees [S1]. It solves the problem of compressing volumetric data (such as medical images or signed-distance volumes) by exploiting the self-similarity of wavelet coefficients across spatial and temporal (or depth) dimensions [S1]. Unlike its sibling [3D Discrete Wavelet Transform](6083-3d-discrete-wavelet-transform.md), which only performs the transform, 3-D SPIHT provides the entropy coding stage that produces a scalable bitstream [S1]. It outperforms 2-D SPIHT by approximately 7.65 dB at 0.1 b/p and 6.21 dB at 0.5 b/p [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3-D volume of wavelet coefficients generated by a 3-D Discrete Wavelet Transform (e.g., from [3D Discrete Wavelet Transform](6083-3d-discrete-wavelet-transform.md) or [3D Integer Wavelet Transform](6956-3d-integer-wavelet-transform.md)). The coefficients are organized into spatial orientation trees.
*   **Output:** A compressed bitstream. For lossy-to-lossless coding, a single embedded bitstream is generated where decoding any truncation yields a lossy version of the original data [S1].

**Data Structures:**
*   **Spatial Orientation Tree:** A tree structure where each node represents a wavelet coefficient. A parent node corresponds to a coefficient at a coarser scale, and its children correspond to coefficients at finer scales at the same spatial location. In 3-D, these are spatio-temporal orientation trees, meaning the hierarchy extends across the depth/time dimension as well [S1].
*   **Threshold ($T$):** A scalar value used to determine significance. It starts at half the maximum coefficient magnitude and is halved after each pass [S2].

**Algorithm Steps:**
1.  **Initialization:** Calculate the maximum absolute value of all wavelet coefficients. Set the initial threshold $T = \frac{1}{2} \max(|c|)$ [S2].
2.  **Significance Testing:** For each tree, test the significance of the root set (the entire tree). A set is significant if the maximum coefficient magnitude in the set is greater than or equal to $T$ [S1].
3.  **Zerotree Coding:** If a set is insignificant (max magnitude $< T$), emit a "zerotree" bit. This symbol informs the decoder that every coefficient in the hierarchy is insignificant with respect to the current threshold [S2].
4.  **Partitioning:** If a set is significant, partition it into subsets (child sets) for further significance tests [S1].
5.  **Significant Coefficient Encoding:** Once a single coefficient is deemed significant:
    *   Transmit its sign bit [S2].
    *   Transmit its most significant bit (relative to the current threshold) [S2].
6.  **Threshold Update:** After all coefficients in the volume have been tested in one pass, halve the threshold ($T \leftarrow T / 2$) and repeat the process [S1].
7.  **Bit Plane Refinement:** On each subsequent traversal, add another bit to the representation of previously significant coefficients [S2].
8.  **Lossy-to-Lossless Optimization:** For integer wavelet transforms, skip bit planes of all zeros generated by bit shifts in certain subbands to reduce redundancy [S1].
9.  **Context Modeling (Optional):** To increase efficiency, nodes can represent groups of wavelet coefficients (e.g., groups of 8 pixels). Use context models with 2 symbols ($k=0,1$) to code information based on the number of significant pixels in the group [S1].

```python
def encode_3d_spiht(coefficients, threshold):
    """
    Encodes 3D wavelet coefficients using SPIHT.
    coefficients: 3D array of wavelet coefficients.
    threshold: Initial threshold value.
    """
    bitstream = []
    
    # Identify all orientation trees in the 3D volume
    trees = build_orientation_trees(coefficients)
    
    while threshold > 0:
        for tree in trees:
            test_set_significance(tree, threshold, bitstream)
        threshold /= 2.0
        
    return bitstream

def test_set_significance(node, threshold, bitstream):
    """
    Recursively tests significance of a set in the orientation tree.
    """
    # Calculate max magnitude in the current set
    max_mag = max(abs(c) for c in node.get_coefficients())
    
    if max_mag < threshold:
        # Set is insignificant
        bitstream.append(0) # Zerotree bit
    else:
        # Set is significant
        bitstream.append(1)
        
        if node.is_leaf():
            # Single coefficient is significant
            sign = 1 if node.coefficient >= 0 else 0
            bitstream.append(sign)
            # Emit most significant bit relative to threshold
            msb = int(abs(node.coefficient) // threshold) % 2
            bitstream.append(msb)
        else:
            # Partition into children
            for child in node.children:
                test_set_significance(child, threshold, bitstream)
```

**Parameters:**
*   **Initial Threshold:** Half the value of the largest wavelet coefficient [S2].
*   **Context Model Size:** Groups of 8 pixels for context modeling [S1].

**Edge Cases and Pitfalls:**
*   **Geometric Error:** Standard zero tree coding assumes an L1 error because the significance test depends only on the coefficient value, not the size of the wavelet support. This can lead to suboptimal bit ordering for geometric reconstruction [S2].
*   **Topology Holes:** The implementation may not track topology changes, allowing simplifications and refinements to occur simultaneously. This can produce holes in thin shapes at small bit counts that disappear later [S2].
*   **Error Metrics:** Traditional error metrics may over-emphasize errors of small components removed early in reconstruction [S2].

## Subtopics

### 3-D ESCOT
An embedded subband coding technique that gains about 10% over 3-D CB-EZW and slightly more over 3-D SPIHT, but has 50% higher complexity [S1].

### 3-D CB-EZW
A 3-D embedded subband coding method that 3-D SPIHT has a small edge over in lossless coding [S1].

### Signed-Distance Volume Compression
An application of 3-D SPIHT to compress signed-distance volumes for progressive surface rendering, where subdivision surfaces may be more compact for smooth surfaces [S2].

## Operating characteristics
*   **Time Complexity:** Decoding the whole 192 slices of Skull takes 13 seconds on a Pentium 1-GHz PC [S1]. For signed-distance volumes, the zero tree coder took 0.5 to 3 seconds for the horse model and 1 to 20 seconds for a large isosurface, depending on resolution and bits produced [S2].
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** 3-D SPIHT is 7.65 dB better than 2-D SPIHT at 0.1 b/p and 6.21 dB better at 0.5 b/p [S1]. It has a small edge over 3-D CB-EZW in lossless coding [S1].
*   **Strengths:** Embedded bitstream allows scalable decoding; low complexity compared to 3-D ESCOT; exploits 3-D redundancies for 35% average compression improvement over 2-D methods [S1].
*   **Limitations:** Less efficient than arithmetic coding tailored for wavelet transforms; geometric error can be improved with modified bit ordering; potential for topological holes in thin shapes [S2].
*   **When to Use:** When embedded, scalable compression of 3-D volumetric data is required with low computational complexity.
*   **When Not to Use:** When maximum compression efficiency is needed (consider arithmetic coding or 3-D ESCOT) or when smooth surface representation is the primary goal (consider subdivision surfaces) [S2].

## Background
3-D SPIHT was introduced by B.-J. Kim, Z. Xiong, and W. A. Pearlman in "Low bit-rate scalable video coding with 3-D set partitioning in hierarchical trees (3-D SPIHT)" (IEEE Trans. Circuits Syst. Video Technol., vol. 10, pp. 1365–1374, Dec. 2000) [S1]. It extends the 2-D SPIHT algorithm [6] to 3-D by treating wavelet coefficients as 3-D spatio-temporal orientation trees [S1]. The algorithm is based on the principle that most images/volumes have decaying power spectral densities, allowing zerotree symbols to efficiently signify spatial subtrees of zeros [S1]. It is widely used in medical image compression and progressive surface rendering [S1, S2].
