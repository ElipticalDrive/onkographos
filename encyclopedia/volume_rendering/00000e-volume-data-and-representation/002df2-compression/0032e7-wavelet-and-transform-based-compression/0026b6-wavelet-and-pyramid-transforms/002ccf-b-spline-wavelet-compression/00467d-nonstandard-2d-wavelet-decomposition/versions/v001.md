# Nonstandard 2D Wavelet Decomposition

Also called: Alternating Row-Column Wavelet, Lifted 2D Wavelet

## Overview
Nonstandard 2D Wavelet Decomposition is a multi-dimensional extension strategy for wavelet transforms that alternates 1D transforms between rows and columns at each resolution level [S1, unofficial]. It solves the problem of mixed-resolution basis functions found in standard decompositions, providing direct control over the resolution level $m$ and ensuring all basis functions have square support [S1, unofficial]. It is more computationally efficient than the standard row-then-column approach [S1, unofficial].

## How it works
**Inputs:** A 2D data array (e.g., image or volume slice).
**Outputs:** A set of scaling coefficients $c_{mpq}$ and detail coefficients $d^{type}_{mpq}$ for each resolution level $m$ and type (1, 2, 3).

**Data Structures:**
The output is organized by resolution level $m$. For each level, the coefficients are stored in arrays corresponding to the basis functions:
- Scaling coefficients: $c_{mpq}$ associated with $\phi^2_{mpq}$.
- Detail coefficients: $d^{1}_{mpq}$ (horizontal detail), $d^{2}_{mpq}$ (vertical detail), $d^{3}_{mpq}$ (diagonal detail).

**Basis Functions:**
The 2D basis functions are constructed as tensor products of 1D scaling ($\phi$) and wavelet ($\psi$) functions [S1, unofficial]:
$$
\begin{aligned}
\phi_{mpq}^2(x, y) &= \phi_{mp}(x)\phi_{mq}(y) \\
\psi_{mpq}^{2,1}(x, y) &= \psi_{mp}(x)\phi_{mq}(y) \\
\psi_{mpq}^{2,2}(x, y) &= \phi_{mp}(x)\psi_{mq}(y) \\
\psi_{mpq}^{2,3}(x, y) &= \psi_{mp}(x)\psi_{mq}(y)
\end{aligned}
$$
where $type=1$ corresponds to horizontal detail, $type=2$ to vertical detail, and $type=3$ to diagonal detail [S1, unofficial].

**Algorithm Steps:**
1. Initialize the input data as the approximation at the finest level $m_0$.
2. For each resolution level $m$ from $m_0 + 1$ upwards:
    a. Apply the 1D wavelet transform to each row of the current approximation coefficients. This separates each row into low-pass (scaling) and high-pass (detail) components.
    b. Apply the 1D wavelet transform to each column of the result from step (a). Note that the columns contain a mix of scaling and detail coefficients from the row transform.
    c. Extract the resulting scaling coefficients $c_{mpq}$ and detail coefficients $d^{type}_{mpq}$ for the current level $m$.
3. Repeat until the desired coarseness level $M$ is reached.

**Pseudocode:**
```python
def nonstandard_2d_wavelet_decomposition(data):
    """
    Performs nonstandard 2D wavelet decomposition.
    data: 2D array of input values.
    Returns: List of tuples (level, scaling_coeffs, detail_coeffs_1, detail_coeffs_2, detail_coeffs_3)
    """
    current_data = data
    levels = []
    
    # Assume we decompose down to a single coefficient or a specified coarse level
    # The loop continues as long as the data dimensions allow for further decomposition
    while current_data.shape[0] > 1 and current_data.shape[1] > 1:
        # Step 1: Transform rows
        # Apply 1D transform to each row
        row_transformed = apply_1d_wavelet_transform_along_axis(current_data, axis=1)
        
        # Step 2: Transform columns
        # Apply 1D transform to each column of the row-transformed data
        col_transformed = apply_1d_wavelet_transform_along_axis(row_transformed, axis=0)
        
        # Step 3: Extract coefficients
        # The output of the 2D transform is split into four subbands:
        # LL (Scaling), LH (Horizontal Detail), HL (Vertical Detail), HH (Diagonal Detail)
        # Note: The exact indexing depends on the specific 1D implementation's output structure.
        # Assuming apply_1d_wavelet_transform returns (low, high) for each dimension.
        
        # For a standard dyadic decomposition:
        # After row transform: each row is [low_row, high_row]
        # After col transform: each col of the result is processed.
        
        # Let's assume the 1D transform splits the input into two halves: low-pass and high-pass.
        # Row transform result shape: (H, 2 * W/2) -> (H, W) if padded, or (H, W) if in-place.
        # Let's assume standard in-place or split storage.
        
        # Simplified extraction logic based on tensor product structure:
        # c_{mpq} comes from LL subband
        # d^{1}_{mpq} comes from LH subband (Horizontal detail: wavelet in x, scaling in y)
        # d^{2}_{mpq} comes from HL subband (Vertical detail: scaling in x, wavelet in y)
        # d^{3}_{mpq} comes from HH subband (Diagonal detail: wavelet in x, wavelet in y)
        
        # Note: The nonstandard approach alternates. 
        # If we do Row then Col:
        # Row transform: f(x,y) -> sum c_x(x) phi_x(y) + sum d_x(x) psi_x(y) ? 
        # Actually, the standard nonstandard definition [S1, unofficial] implies:
        # Level m is obtained by transforming the approximation from level m-1.
        
        # Let's stick to the high-level description from [S1, unofficial]:
        # "apply 1D wavelet transform to rows, then to columns"
        
        # Extracting the four components from the 2D result:
        # The result of the 2D transform is a 2D array where each element is a coefficient.
        # We need to separate them into the four types.
        
        # Assuming the 1D transform returns low and high frequency parts.
        # Row transform: Input H x W -> Output H x W (interleaved or split)
        # Let's assume split: H x (W/2 + W/2)
        
        # To implement this cleanly without library internals:
        # 1. Row Transform:
        low_rows = []
        high_rows = []
        for r in range(current_data.shape[0]):
            low, high = apply_1d_wavelet_transform(current_data[r, :])
            low_rows.append(low)
            high_rows.append(high)
        
        # Stack low and high rows
        # low_rows: H x W/2
        # high_rows: H x W/2
        # Combined: H x W (conceptually, but we need to process columns of the *result*)
        # The result of row transform is a matrix where each row is [low, high].
        # We need to apply column transform to this entire matrix.
        
        # However, the nonstandard decomposition [S1, unofficial] says "alternate... at each level".
        # This implies the input to the column transform is the output of the row transform.
        
        # Let's construct the intermediate matrix M_row
        M_row = np.hstack([low_rows, high_rows]) # H x W
        
        # 2. Column Transform:
        # Apply 1D transform to each column of M_row
        low_cols = []
        high_cols = []
        for c in range(M_row.shape[1]):
            col_data = M_row[:, c]
            low, high = apply_1d_wavelet_transform(col_data)
            low_cols.append(low)
            high_cols.append(high)
            
        # Stack low and high columns
        # low_cols: H/2 x W
        # high_cols: H/2 x W
        # This doesn't seem right for 2D. The column transform should operate on the columns.
        # If M_row is H x W, and we transform each column, we get H/2 low and H/2 high for each column.
        # So the result is (H/2) x W for low-pass and (H/2) x W for high-pass?
        # No, the 2D transform produces 4 subbands.
        
        # Correct interpretation of Nonstandard 2D Wavelet:
        # It is equivalent to the standard tensor product but computed iteratively.
        # Level m coefficients are derived from level m-1 approximation.
        
        # Let's use the explicit formula [S1, unofficial] to guide the extraction.
        # The approximation at level m is c_{mpq}.
        # The details are d^{type}_{mpq}.
        
        # Implementation of the 2D transform via 1D steps:
        # 1. Transform rows: f(x,y) -> sum_p c_{m-1,p}(y) phi_{m-1,p}(x) + sum_p d^{1}_{m-1,p}(y) psi_{m-1,p}(x)
        #    This is not quite right. The 1D transform on rows separates x-frequencies.
        #    Result: Low-pass in x (LL-like), High-pass in x (LH-like).
        # 2. Transform columns: Apply 1D transform to the result of step 1 along y.
        #    This separates y-frequencies.
        
        # Let's assume the 1D transform splits the signal into Low (L) and High (H).
        # Row transform:
        # Input: H x W
        # Output: H x W (L and H interleaved or stored separately)
        # Let's store as two matrices: L_rows (H x W/2) and H_rows (H x W/2)
        
        L_rows = []
        H_rows = []
        for r in range(current_data.shape[0]):
            l, h = apply_1d_wavelet_transform(current_data[r, :])
            L_rows.append(l)
            H_rows.append(h)
            
        L_rows = np.array(L_rows) # H x W/2
        H_rows = np.array(H_rows) # H x W/2
        
        # Now apply column transform to L_rows and H_rows separately?
        # No, the nonstandard decomposition [S1, unofficial] says "apply 1D wavelet transform to rows, then to columns".
        # This implies the column transform is applied to the *entire* result of the row transform.
        # But the row transform result is not a single signal per column.
        
        # Actually, the standard nonstandard algorithm [S2, unofficial] is:
        # for each row r: 1D_Transform(r)
        # for each column c: 1D_Transform(c)
        # This implies the column transform is applied to the columns of the matrix resulting from the row transforms.
        
        # Let's assume the 1D transform modifies the array in place or returns a new array of the same size.
        # If it returns the same size, then:
        # After row transform, we have a matrix M1.
        # Then we apply 1D transform to each column of M1.
        
        # Let's assume apply_1d_wavelet_transform returns (low, high) and we need to handle the structure.
        # For the purpose of this article, we define the logical steps.
        
        # Extracting coefficients from the final 2D result:
        # The final result of the 2D transform is a set of coefficients.
        # We need to identify which coefficients correspond to c, d1, d2, d3.
        
        # Based on [S1, unofficial]:
        # c_{mpq} corresponds to the scaling function in both x and y.
        # d^{1}_{mpq} corresponds to wavelet in x, scaling in y.
        # d^{2}_{mpq} corresponds to scaling in x, wavelet in y.
        # d^{3}_{mpq} corresponds to wavelet in x, wavelet in y.
        
        # In the row-then-column approach:
        # Row transform produces Low (scaling) and High (wavelet) in x.
        # Column transform produces Low (scaling) and High (wavelet) in y.
        
        # So:
        # LL (Low-Low) -> c_{mpq}
        # HL (High-Low) -> d^{1}_{mpq} (Wavelet in x, Scaling in y) -- Wait, [S1, unofficial] says d1 is psi(x)phi(y).
        # LH (Low-High) -> d^{2}_{mpq} (Scaling in x, Wavelet in y) -- [S1, unofficial] says d2 is phi(x)psi(y).
        # HH (High-High) -> d^{3}_{mpq} (Wavelet in x, Wavelet in y) -- [S1, unofficial] says d3 is psi(x)psi(y).
        
        # So we need to separate the final result into these 4 subbands.
        
        # Let's assume the 1D transform returns the low and high parts.
        # After row transform, we have L_rows and H_rows.
        # We apply column transform to L_rows and H_rows.
        
        L_cols_L = []
        L_cols_H = []
        for c in range(L_rows.shape[1]):
            l, h = apply_1d_wavelet_transform(L_rows[:, c])
            L_cols_L.append(l)
            L_cols_H.append(h)
        L_cols_L = np.array(L_cols_L).T # W/2 x H/2
        L_cols_H = np.array(L_cols_H).T # W/2 x H/2
        
        H_cols_L = []
        H_cols_H = []
        for c in range(H_rows.shape[1]):
            l, h = apply_1d_wavelet_transform(H_rows[:, c])
            H_cols_L.append(l)
            H_cols_H.append(h)
        H_cols_L = np.array(H_cols_L).T # W/2 x H/2
        H_cols_H = np.array(H_cols_H).T # W/2 x H/2
        
        # Now we have 4 matrices of size H/2 x W/2.
        # c_{mpq} = L_cols_L
        # d^{2}_{mpq} = L_cols_H (Scaling in x, Wavelet in y) -> Wait, L_cols_H is Low in x, High in y.
        # d^{1}_{mpq} = H_cols_L (Wavelet in x, Scaling in y) -> H_cols_L is High in x, Low in y.
        # d^{3}_{mpq} = H_cols_H (Wavelet in x, Wavelet in y) -> H_cols_H is High in x, High in y.
        
        # Check [S1, unofficial] definitions:
        # d^{1}: psi(x)phi(y) -> Wavelet in x, Scaling in y. This is H_cols_L.
        # d^{2}: phi(x)psi(y) -> Scaling in x, Wavelet in y. This is L_cols_H.
        # d^{3}: psi(x)psi(y) -> Wavelet in x, Wavelet in y. This is H_cols_H.
        # c: phi(x)phi(y) -> Scaling in x, Scaling in y. This is L_cols_L.
        
        scaling_coeffs = L_cols_L
        detail_1 = H_cols_L
        detail_2 = L_cols_H
        detail_3 = H_cols_H
        
        levels.append((m, scaling_coeffs, detail_1, detail_2, detail_3))
        
        # The next level's approximation is the scaling coefficients from the current level
        current_data = scaling_coeffs
        m += 1
        
    return levels
```

**Parameters:**
- Resolution levels: Determined by the size of the input data. For an $N \times N$ image, $\log_2 N$ levels are typical.
- Wavelet type: B-spline wavelets are used in the context of B-spline Wavelet Compression [Parent].

**Edge Cases and Pitfalls:**
- **Boundary Conditions:** The 1D transform must handle boundaries correctly. Padding or extension strategies must be consistent with the wavelet support [S1, unofficial].
- **Precision:** Floating-point precision errors can accumulate in deep decompositions.
- **Degenerate Input:** If the input size is not a power of 2, padding or truncation is required.

## Subtopics

### Optimized Non-Standard 2D Wavelet Decomposition
A modification to the standard non-standard technique that reduces computational requirements by skipping columns that contain only wavelet coefficients [S2, unofficial]. In the standard algorithm, the 1D transform is applied to every column after the row transform. In the optimized version, the column transform is applied only to alternate columns (those comprising data values, i.e., scaling coefficients from the row transform) [S2, unofficial]. For a dataset of size $s \times s$, this reduces the number of data elements processed by the 1D transform from $2s^2$ to $1.5s^2$, a 25% reduction in computational load [S2, unofficial]. The resulting multiresolution data sets are identical to those generated by the original algorithm [S2, unofficial].

## Operating characteristics
**Time Complexity:** The nonstandard decomposition is slightly more efficient than the standard decomposition [S1, unofficial]. The optimized variant reduces the number of 1D transforms by 25% [S2, unofficial].
**Memory Complexity:** Requires storage for all coefficients at all levels. The nonstandard approach allows direct control of resolution level $m$, which can be advantageous for progressive transmission [S1, unofficial].
**Strengths:** Square support for all basis functions, direct control of resolution level, and higher efficiency than standard decomposition [S1, unofficial].
**Limitations:** Requires careful handling of boundary conditions. The optimized variant assumes a specific structure of coefficients (skipping columns with only wavelet coefficients) which may not apply to all wavelet types or data layouts.

## Background
The nonstandard decomposition was introduced to overcome the limitations of the standard decomposition, specifically the mixing of basis functions from different resolution levels and the non-square support of some basis functions [S1, unofficial]. It is used in wavelet-based compression of surfaces and volumes [S1, unofficial]. The optimized variant was developed for seamless multiresolution isosurfaces [S2, unofficial].
