# B-spline Wavelet Compression

Also called: B-spline FWT, B-spline Wavelet Transform, Fast Wavelet Transform, Matrix-based Wavelet Transform

## Overview
B-spline Wavelet Compression is a method for decomposing volumetric data into a multi-resolution hierarchy of scaling and wavelet coefficients using B-spline basis functions [S1, unofficial]. It solves the problem of efficiently representing smooth volumetric data by exploiting the linear complexity of the B-spline transform [S1, unofficial]. Unlike [L2 Norm Wavelet Compression](3542-l2-norm-wavelet-compression.md) which focuses on error metrics, or [Biorthogonal Wavelet Compression](5381-biorthogonal-wavelet-compression.md) which uses separate primal/dual filters, this method relies on the semi-orthogonality of B-splines, projecting data into dual space for decomposition and solving linear systems for reconstruction [S1, unofficial].

## How it works
**Inputs:** A 1D data vector $\mathbf{c}_m$ of length $N = 2^{M-m} + d$, where $M$ is the maximum decomposition level, $m$ is the current level, and $d$ is the B-spline degree (e.g., $d=3$ for cubic B-splines) [S1, unofficial].
**Outputs:** Dual-space scaling coefficients $\tilde{\mathbf{c}}_{m+1}$ and primal detail coefficients $\mathbf{d}_{m+1}$ [S1, unofficial].

**Data Structures:**
*   $\mathbf{c}_m$: Input coefficient vector of length $N$ [S1, unofficial].
*   $\tilde{\mathbf{c}}_m$: Dual-space scaling coefficients [S1, unofficial].
*   $\tilde{\mathbf{d}}_m$: Dual-space wavelet coefficients [S1, unofficial].
*   $\mathbf{C}_m$: Band-diagonal inner-product matrix for primal-to-dual projection [S1, unofficial].
*   $\mathbf{D}_m$: Band-diagonal inner-product matrix for dual-space wavelet normalization [S1, unofficial].
*   $\mathbf{P}_{m+1}, \mathbf{Q}_{m+1}$: Primal projection matrices for scaling and detail [S1, unofficial].
*   $\mathbf{A}_{m+1}, \mathbf{B}_{m+1}$: Decomposition operators [S1, unofficial].

**Steps:**
1.  **Expansion:** Expand the original data vector $\mathbf{c}_m$ by repeating the last data value to yield the required length $N = 2^{M-m} + d$ [S1, unofficial].
2.  **Dual Space Projection:** Transform the primal coefficients into the dual space using the inner-product matrix $\mathbf{C}_m$:
    $$ \tilde{\mathbf{c}}_m = \mathbf{C}_m \mathbf{c}_m $$
    Since $\mathbf{C}_m$ is band-diagonal, this step runs in $O(N)$ time [S1, unofficial].
3.  **Decomposition:** Apply the transpose of the primal projection matrices to obtain the dual-space coefficients:
    $$ \tilde{\mathbf{c}}_{m+1} = (\mathbf{P}_{m+1})^T \tilde{\mathbf{c}}_m $$
    $$ \tilde{\mathbf{d}}_{m+1} = (\mathbf{Q}_{m+1})^T \tilde{\mathbf{c}}_m $$
    The lengths of $\tilde{\mathbf{c}}_{m+1}$ and $\tilde{\mathbf{d}}_{m+1}$ are $2^{M-m-1}+1$ and $2^{M-m-1}+d$ respectively, allowing space-efficient in-place implementation [S1, unofficial].
4.  **Recovery of Detail Signals:** Solve for the primal detail coefficients $\mathbf{d}_{m+1}$ by inverting the dual-space normalization:
    $$ \mathbf{D}_{m+1} \mathbf{d}_{m+1} = \tilde{\mathbf{d}}_{m+1} $$
    The matrix $\mathbf{D}_{m+1}$ is diagonally dominant and well-conditioned, but its inverse is dense and ill-conditioned [S1, unofficial]. Therefore, brute-force inversion is avoided; instead, an LU-decomposition is used to solve the system in linear time [S1, unofficial].
5.  **Final Level:** At the final level $M$, compute $\mathbf{c}_M$ in the same fashion as the detail signal at previous levels by solving the linear system [S1, unofficial].

**Reconstruction:**
To reconstruct $\mathbf{c}_m$ from $\mathbf{c}_{m+1}$ and $\mathbf{d}_{m+1}$:
$$ \mathbf{c}_m = \mathbf{P}_{m+1} \mathbf{c}_{m+1} + \mathbf{Q}_{m+1} \mathbf{d}_{m+1} $$
The backprojection of the pure scaling function subband into primal space must be carried out separately in higher dimensions [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def bspline_decompose_1d(c_m, P, Q, C, D):
    """
    Decomposes a 1D vector using B-spline wavelets.
    c_m: input vector of length N = 2^(M-m) + d
    P, Q: projection matrices for current level
    C: inner-product matrix for current level
    D: inner-product matrix for next level (for detail recovery)
    """
    # Step 2: Project to dual space (band-diagonal matrix-vector multiply)
    c_m_tilde = C @ c_m
    
    # Step 3: Apply projection operators
    c_m1_tilde = P.T @ c_m_tilde
    d_m1_tilde = Q.T @ c_m_tilde
    
    # Step 4: Recover primal detail coefficients
    # Solve D @ d_m1 = d_m1_tilde using LU decomposition (standard linear algebra)
    d_m1 = np.linalg.solve(D, d_m1_tilde)
    
    return c_m1_tilde, d_m1

def bspline_reconstruct_1d(c_m1, d_m1, P, Q):
    """
    Reconstructs primal coefficients from scaling and detail coefficients.
    """
    # Step 5: Reconstruct primal coefficients
    c_m = P @ c_m1 + Q @ d_m1
    return c_m
```

**Parameters:**
*   $d$: Degree of the B-spline. Typical value: 3 (cubic) [S1, unofficial].
*   $M$: Maximum decomposition level [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Ill-conditioned Inverse:** The inverse of $\mathbf{D}_{m+1}$ is dense and ill-conditioned, so direct inversion must not be used [S1, unofficial].
*   **Non-compact Support:** Dual functions of B-spline basis do not have compact support (only fast exponential decay), so standard decomposition operators are not band matrices and require the modified dual-space scheme [S1, unofficial].
*   **Boundary Conditions:** The data vector must be expanded by repeating the last value to satisfy the length requirement $2^{M-m} + d$ [S1, unofficial].

## Subtopics

### Wavelet-GS
A compression method that compresses the SH coefficients of each Gaussian using a wavelet decomposition, discarding high-frequency components that are not visible at typical viewing distances [S3, unofficial].

### 2D Wavelet Decomposition
Adaptation of the 1D decomposition scheme to higher dimensions, handling mixed bands comprising both primal and dual coefficients [S1, unofficial]. It performs single iteration steps involving operators $L^*, H^*, L^{-1}, H^{-1}$ to separate scaling and wavelet subbands, and carries out the backprojection of the pure scaling function subband into primal space separately [S1, unofficial]. Overall complexity is $O(N)$ [S1, unofficial].

### Nonstandard 2D Wavelet Decomposition
A multi-dimensional extension strategy where 1D transforms are alternated between rows and columns at each resolution level, avoiding mixed-resolution basis functions [S1, unofficial]. It extracts detail coefficients $d^{type}_{mpq}$ for type 1, 2, 3 and scaling coefficients $c_{mpq}$ [S1, unofficial]. The 2D Basis functions are defined as $\phi^2_{mpq}(x,y) = \phi_{mp}(x)\phi_{mq}(y)$, $\psi^{2,1}_{mpq} = \psi_{mp}\phi_{mq}$, $\psi^{2,2}_{mpq} = \phi_{mp}\psi_{mq}$, $\psi^{2,3}_{mpq} = \psi_{mp}\psi_{mq}$ [S1, unofficial]. It differs from Standard Decomposition (row-then-column) by providing direct control of resolution level $m$, having square support for all basis functions, and being more efficient [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$, where $N$ is the length of the data vector [S1, unofficial].
*   **Memory Complexity:** Space-efficient in-place implementation is possible because the total length of the decomposition vectors equals the length of the original vector [S1, unofficial].
*   **Performance:** Full decomposition and reconstruction of a 1D data vector requires 30.25 multiplications per data value [S1, unofficial].
*   **Strengths:** Linear complexity construction, which is not guaranteed for general bi- or semi-orthogonal wavelets [S1, unofficial].
*   **Limitations:** Dual functions lack compact support, requiring the modified dual-space projection scheme [S1, unofficial]. The inverse of the detail normalization matrix is ill-conditioned, requiring LU decomposition [S1, unofficial].

## Background
Originated in the context of multiresolution representation and compression of surfaces and volumes, specifically detailed in the thesis "Multiresolution representation and compression of surfaces and volumes" [S1, unofficial]. It is used in volume rendering compression pipelines, often combined with delta encoding, quantization, run-length, and Huffman coding [S2]. It is also applied in modern Gaussian Splatting compression (Wavelet-GS) to compress spherical harmonic coefficients [S3, unofficial].
