# TT Reconstruction for Time-Dependent Rendering

Also called: TT Reconstruction, TT-based Time Step Reconstruction

## Overview
TT Reconstruction is a method to reconstruct a specific 3D volume at a given time step $t$ from the Tensor-Train (TT) cores of a 4D dataset for time-dependent volume rendering [S1][S2, unofficial]. It sets itself apart from naive TT evaluation by pre-multiplying the spatial cores, allowing the reconstruction of any time step via a single tensor-vector multiplication with the time-specific core [S1][S2, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
*   The set of TT cores $\{C_1, C_2, C_3, C_4\}$ for a 4D dataset [S2, unofficial].
*   The target time step index $t$ [S2, unofficial].

**Outputs:**
*   A 3D volume tensor $V_t \in \mathbb{R}^{N_1 \times N_2 \times N_3}$ representing the volume at time step $t$ [S2, unofficial].

### Data Structures
The 4D dataset is represented by $d=4$ TT cores $C_i$ [S2, unofficial]. Each core $C_i$ has dimensions $R_{i-1} \times N_i \times R_i$, where $R_i$ are the TT ranks and $N_i$ are the mode sizes [S2, unofficial].
*   $C_1 \in \mathbb{R}^{1 \times N_1 \times R_1}$ [S2, unofficial].
*   $C_2 \in \mathbb{R}^{R_1 \times N_2 \times R_2}$ [S2, unofficial].
*   $C_3 \in \mathbb{R}^{R_2 \times N_3 \times R_3}$ [S2, unofficial].
*   $C_4 \in \mathbb{R}^{R_3 \times N_4 \times 1}$ [S2, unofficial].

Here, $N_4$ corresponds to the number of time steps [S2, unofficial]. The boundary ranks are fixed: $R_0 = 1$ and $R_4 = 1$ [S2, unofficial].

### Steps
1.  **Preprocessing**: Multiply the first three TT cores ($C_1, C_2, C_3$) together to form a preprocessed tensor [S1][S2, unofficial].
2.  **Extraction**: Extract the $t$-th column vector from the last TT core $C_4$ [S1][S2, unofficial].
3.  **Reconstruction**: Multiply the preprocessed tensor with the extracted column vector to reconstruct the 3D volume for time step $t$ [S1][S2, unofficial].

### Formulas
The TT decomposition of the 4D tensor $T$ is defined as:
$$ T_{i_1, i_2, i_3, i_4} = \sum_{r_1, r_2, r_3} C_1(1, i_1, r_1) C_2(r_1, i_2, r_2) C_3(r_2, i_3, r_3) C_4(r_3, i_4, 1) $$

The preprocessing step computes the tensor $P$:
$$ P_{i_1, i_2, i_3, r_3} = \sum_{r_1, r_2} C_1(1, i_1, r_1) C_2(r_1, i_2, r_2) C_3(r_2, i_3, r_3) $$

The extraction step selects the vector $v_t$ from $C_4$ corresponding to time index $t$ (where $i_4 = t$):
$$ v_t(r_3) = C_4(r_3, t, 1) $$

The final reconstruction is the contraction of $P$ and $v_t$ over the rank index $r_3$:
$$ V_t(i_1, i_2, i_3) = \sum_{r_3} P_{i_1, i_2, i_3, r_3} v_t(r_3) $$

### Pseudocode
```python
def contract(A, B, axis_a, axis_b):
    """Explicit tensor contraction over specified axes."""
    # Move contraction axes to the end
    A_axes = list(range(A.ndim))
    A_axes.remove(axis_a)
    A_axes.append(axis_a)
    B_axes = list(range(B.ndim))
    B_axes.remove(axis_b)
    B_axes.append(axis_b)
    
    A_perm = A.transpose([A_axes.index(i) for i in A_axes])
    B_perm = B.transpose([B_axes.index(i) for i in B_axes])
    
    # Reshape to 2D matrices
    A_mat = A_perm.reshape(-1, A_perm.shape[-1])
    B_mat = B_perm.reshape(-1, B_perm.shape[-1])
    
    # Matrix multiply
    C_mat = A_mat @ B_mat.T
    
    # Reshape back and remove contracted dimension
    out_shape = list(A_perm.shape[:-1]) + list(B_perm.shape[:-1])
    C = C_mat.reshape(out_shape)
    return C

def reconstruct_time_step(C1, C2, C3, C4, t):
    """
    Reconstructs the 3D volume at time step t from TT cores.
    
    Args:
        C1: Tensor of shape (1, N1, R1)
        C2: Tensor of shape (R1, N2, R2)
        C3: Tensor of shape (R2, N3, R3)
        C4: Tensor of shape (R3, N4, 1)
        t: Integer index of the time step (0 <= t < N4)
        
    Returns:
        V_t: Tensor of shape (N1, N2, N3)
    """
    # Step 1: Preprocess by multiplying C1, C2, and C3
    # Contract C1 and C2 over R1 (axis 2 of C1, axis 0 of C2)
    temp1 = contract(C1, C2, 2, 0)
    # Squeeze the first dimension (size 1)
    temp1 = temp1.squeeze(0)
    
    # Contract temp1 and C3 over R2 (axis 2 of temp1, axis 0 of C3)
    P = contract(temp1, C3, 2, 0)
    
    # Step 2: Extract the t-th column vector from C4
    # C4 shape: (R3, N4, 1)
    # We want the slice at index t along the second dimension (N4)
    # Result shape: (R3,)
    v_t = C4[:, t, 0]
    
    # Step 3: Multiply preprocessed tensor P with vector v_t
    # Contract P and v_t over R3 (axis 3 of P, axis 0 of v_t)
    V_t = contract(P, v_t, 3, 0)
    
    return V_t
```

### Parameters and Edge Cases
*   **Time Index $t$**: Must be within bounds $0 \le t < N_4$ [S2, unofficial].
*   **Ranks $R_i$**: Not given in the sources.
*   **Precision**: Standard floating-point arithmetic is used [G].

## Subtopics

### TT Decomposition for 4D Volumes
*   **What it is**: The parent method that generates the TT cores from the raw 4D data [S2, unofficial].
*   **Difference**: While TT Reconstruction focuses on *accessing* a specific time step from existing cores, the parent method focuses on *compressing* the full 4D dataset into those cores [S2, unofficial].
*   **When to choose**: Use this when you need to compress the data first [S2, unofficial].
*   **Link**: [Tensor-Train Decomposition for 4D Volumes](14070-tensor-train-decomposition-for-4d-volumes.md)

## Background
The method is described in the context of Tensor-Train-based 4D Time-Dependent Volume Rendering [S1][S2, unofficial]. The TT decomposition itself was introduced by Oseledets [Ose11] and further detailed in [LLLZ22]. The specific application to 4D volume rendering and the optimization of reconstruction via preprocessing of spatial cores is presented in [S1] and [S2, unofficial].
