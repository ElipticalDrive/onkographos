# Quantization with Noise Injection

Also called: Noise-injected attribute quantization, Quantization-aware training with noise injection, Quantization Noise Simulation

## Overview
Quantization with Noise Injection is a technique for compressing continuous anchor attributes into discrete values suitable for entropy coding by simulating the quantization error during training via noise addition, while applying explicit rounding during inference [S1, unofficial][S2]. It differs from standard quantization by enabling gradient flow through the non-differentiable quantization operation during the training phase, allowing the model to learn robust representations that are resilient to the discretization errors introduced at test time [S1, unofficial][S2].

## How it works
**Inputs and Outputs:**
*   **Input:** Continuous attribute components $f_i$ (e.g., color, scale, rotation, position deltas) and a predefined quantization step $Q$.
*   **Output:** Quantized attribute values $\hat{f}_i$ for entropy coding.

**Data Structures:**
Attributes are stored as continuous floating-point values during training and converted to discrete integers or fixed-point representations for storage. The specific attributes quantized in the primary implementation are $f_a$ (appearance/color), $l_s$ (scale), $l_r$ (rotation), and $\Delta x_g$ (position) [S1, unofficial].

**Steps:**
1.  **Compute Quantization Step:** Calculate the adaptive quantization step size $q_i$ for each attribute component $i$ using a refinement factor $r_i$ output from a context model [S1, unofficial].
2.  **Training Phase (Noise Injection):**
    *   Sample uniform noise $\mathcal{V} \sim U[-0.5, 0.5]$ [S1, unofficial].
    *   Inject noise into the attribute value to simulate quantization error: $\hat{f}_i = f_i + \mathcal{V} \times q_i$ [S1, unofficial].
    *   Use $\hat{f}_i$ for forward pass and backpropagation, substituting the original $f_i$ [S1, unofficial].
    *   Alternatively, in some implementations, uniform noise $\epsilon \sim U[-0.5, 0.5]$ is added to the encoder output $E(x; \theta_e)$ to simulate quantization error $\hat{z} = E(x; \theta_e) + \epsilon$ [S2].
3.  **Inference Phase (Explicit Quantization):**
    *   Compute the quantized value using rounding: $\hat{f}_i = \text{round}(f_i / q_i) \times q_i$ [S1, unofficial].
    *   Pass the discrete $\hat{f}_i$ to the entropy coder [S1, unofficial][S2].

**Formulas:**
The quantization step size $q_i$ is defined as [S1, unofficial]:
$$ q_i = Q \times (1 + \tanh(r_i)) $$
where:
*   $Q$ is the predefined base quantization step size.
*   $r_i$ is the refinement factor from the context model.

The training quantization is [S1, unofficial]:
$$ \hat{f}_i = f_i + \mathcal{V}(-\frac{1}{2}, \frac{1}{2}) \times q_i $$
where $\mathcal{V}$ represents uniform sampling.

The testing quantization is [S1, unofficial]:
$$ \hat{f}_i = \text{round}\left(\frac{f_i}{q_i}\right) \times q_i $$

**Parameters:**
Typical values for the predefined quantization step $Q$ vary by attribute component due to different numerical scales [S1, unofficial]:
*   $Q = 1$ for $f_a$ (appearance)
*   $Q = 0.001$ for $l_s$ (scale)
*   $Q = 0.001$ for $l_r$ (rotation)
*   $Q = 0.2$ for $\Delta x_g$ (position)

**Edge Cases and Pitfalls:**
*   **Precision:** The refinement factor $r_i$ allows adaptive adjustment of $q_i$, which is critical because attributes exhibit different statistical distributions and scales [S1, unofficial].
*   **Distribution Assumption:** The method assumes attributes exhibit Gaussian-like distributions, allowing the context model to output individual mean $\mu_i$ and variance $\sigma_i$ for probability modeling [S1, unofficial].

**Pseudocode:**
```python
import math
import random

def compute_quantization_step(Q, r_i):
    """
    Computes the adaptive quantization step size.
    Q: Predefined base quantization step.
    r_i: Refinement factor from context model.
    """
    return Q * (1 + math.tanh(r_i))

def quantize_training(f_i, q_i):
    """
    Simulates quantization during training by adding uniform noise.
    f_i: Original continuous attribute value.
    q_i: Quantization step size.
    """
    # Sample uniform noise from U[-0.5, 0.5]
    noise = random.uniform(-0.5, 0.5)
    return f_i + noise * q_i

def quantize_inference(f_i, q_i):
    """
    Performs explicit quantization during inference.
    f_i: Continuous attribute value.
    q_i: Quantization step size.
    """
    # Round to nearest integer multiple of q_i
    return round(f_i / q_i) * q_i

# Example usage for an attribute component
Q_base = 1.0  # Example Q for f_a
r_i = 0.5     # Example refinement factor
q_i = compute_quantization_step(Q_base, r_i)

# Training
f_i_train = 0.75
f_i_quantized_train = quantize_training(f_i_train, q_i)

# Inference
f_i_infer = 0.75
f_i_quantized_infer = quantize_inference(f_i_infer, q_i)
```

## Subtopics

### Post-Training Compression
A technique that reduces storage requirements by quantizing vertex positions, features, and MLP weights after training, followed by entropy coding [S3]. It quantizes vertex positions to UInt16, vertex features to uniform Int8 (with per-channel scale and offset), and MLP weights to FP16 [S3]. An entropy coder (Zstandard, level 19) is applied to the serialized payload [S3]. This achieves an additional compression factor of approximately 3x beyond the training result with negligible quality loss [S3].

## Operating characteristics
*   **Time Complexity:** Training requires additional computation for noise sampling and context model inference, but inference complexity is dominated by the rounding operation and entropy coding, which is efficient [S1, unofficial][S2].
*   **Memory Complexity:** Significantly reduces memory footprint by storing discrete quantized values instead of full-precision floats, with further gains from entropy coding [S1, unofficial][S3].
*   **Performance:** The method achieves competitive PSNR and substantially outperforms alternatives like Instant NGP in perceptual quality (LPIPS) at high compression ratios [S2, S3].
*   **Strengths:** Enables end-to-end training with quantization constraints, leading to better reconstruction quality compared to post-training quantization alone [S1, unofficial][S2].
*   **Limitations:** Requires careful tuning of $Q$ and the context model for refinement factors [S1, unofficial].

## Background
The technique originates from the need to compress neural representations for volume rendering and image coding, where continuous latent codes must be discretized for entropy coding [S1, unofficial][S2]. Ballé et al. [S2] proposed simulating quantization noise during training to enable backpropagation through the quantization operation. This approach has been adapted for compressing Neural Gaussian Splats (ECoNGS) [S1, unofficial] and Neural Harmonic Textures [S3].
