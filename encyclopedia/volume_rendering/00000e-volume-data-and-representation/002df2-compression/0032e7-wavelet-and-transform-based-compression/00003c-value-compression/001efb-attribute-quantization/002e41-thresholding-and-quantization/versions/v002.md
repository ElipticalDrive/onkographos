# Thresholding and Quantization

Also called: Coefficient Thresholding and Quantization

## Overview
Thresholding and Quantization is a lossy compression technique applied to the coefficients of a compact volume model to further reduce data size by neglecting insignificant values [S1][S2]. It allows the user to define the maximum allowed error, making it a controllable trade-off between compression ratio and fidelity [S1][S2].

## How it works
**Inputs and Outputs:**
*   **Input:** Coefficients from a compact model (e.g., wavelet coefficients, PCA components, or tensor factors) [S1][S2].
*   **Output:** A reduced set of coefficients and metadata defining the reconstruction error or compression ratio [S1][S2].

**Data Structures:**
Not given in the sources.

**Steps:**
1.  **Thresholding:** Identify coefficients with magnitude below a threshold $\tau$ and set them to zero. This is particularly effective for wavelet transforms where energy is concentrated in few large coefficients [S2].
    $$ c'_i = \begin{cases} 0 & \text{if } |c_i| < \tau \\ c_i & \text{otherwise} \end{cases} $$
2.  **Truncation:** For models like PCA, sort coefficients by magnitude or importance and truncate the least significant ones, keeping only the top $k$ coefficients [S2].
3.  **Quantization:** Map floating-point coefficients to a limited set of integer values [S1]. Alternatively, use a pre-learned dictionary (Vector Quantization) where each coefficient is replaced by the index of the best-matching codeword, with dictionaries designed to explicitly include a quantization step [S1][S2].
    $$ c'_i = \text{round}\left(\frac{c_i}{\Delta}\right) \cdot \Delta $$
    Where $\Delta$ is the quantization step size [G].
4.  **Error Control:** The user defines the allowed error $\epsilon$ [S2]. The threshold $\tau$ or step size $\Delta$ is adjusted to meet this constraint [G].

**Pseudocode:**
```python
def threshold_and_quantize(coefficients, method='threshold', threshold=0.0, delta=1.0):
    """
    Apply thresholding or quantization to volume model coefficients.
    
    Args:
        coefficients: List or array of float coefficients.
        method: 'threshold' or 'quantize'.
        threshold: Magnitude threshold for zeroing.
        delta: Quantization step size.
        
    Returns:
        Reduced coefficients array.
    """
    if method == 'threshold':
        return [0.0 if abs(c) < threshold else c for c in coefficients]
    elif method == 'quantize':
        return [round(c / delta) * delta for c in coefficients]
    else:
        raise ValueError("Unknown method")
```

**Parameters:**
*   **Threshold ($\tau$):** Controls sparsity. Not given in the sources.
*   **Allowed Error ($\epsilon$):** The user-defined bound on reconstruction error [S2].
*   **Quantization Step ($\Delta$):** Determines the number of representable levels. Not given in the sources.

## Subtopics

### Wavelet Thresholding
Applies magnitude thresholding to wavelet coefficients to exploit sparsity [S2]. Sets it apart by targeting localized frequency components. Choose when data exhibits sparse wavelet representations. Link: [Wavelet Compression](wavelet-compression.md).

### Vector Quantization
Replaces coefficients with indices from a pre-learned dictionary of codewords [S1][S2]. Sets it apart by using learned codebooks rather than fixed rules. Choose when data has complex, non-linear structures. Link: [Vector Quantization](vector-quantization.md).

### PCA Truncation
Sorts and retains the most significant coefficients from a PCA-like model [S2]. Sets it apart by operating on globally correlated components. Choose when data has dominant principal modes. Link: [PCA Compression](pca-compression.md).

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Reduces memory by storing only non-zero coefficients or smaller integer types [S1][S2].
*   **Performance:** Achieves high compression ratios (e.g., ~0.1% to ~13% of original size) with acceptable visual quality for volume rendering [S1].
*   **Strengths:** Simple to implement, user-controlled error, effective for sparse data [S1][S2].
*   **Limitations:** Lossy; may introduce artifacts if parameters are not tuned correctly [S1][S2].
*   **When to Use:** When memory bandwidth is a bottleneck and some visual error is acceptable [G].
*   **When Not to Use:** When exact data preservation is required [G].

## Background
Originating from general signal processing and data compression techniques, this method was adapted for compressed GPU-based direct volume rendering. It is discussed in the context of compact models like wavelets and tensors [S1][S2]. The approach leverages the fact that many volume datasets have compact representations where most coefficients are small or redundant [S1][S2].
