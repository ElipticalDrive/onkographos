# Sensitivity Threshold Clustering


## Overview
Sensitivity Threshold Clustering is a lossy compression technique for 3D Gaussian Splatting that reduces memory footprint by clustering spherical harmonic (SH) coefficients and Gaussian shape parameters based on their rendering impact [S1]. It distinguishes itself from uniform quantization by using sensitivity thresholds to exclude a small fraction of high-impact vectors from clustering, storing them explicitly instead [S1].

## How it works
**Inputs:** A set of 3D Gaussians defined by position, opacity, rotation $R$, scaling vector $s$, and SH coefficients $c$, along with training images for sensitivity computation [S1].
**Outputs:** Codebooks for SH coefficients and shape parameters, plus per-Gaussian storage of codebook indices, scalar scaling factors $\eta$, and full coefficients for sensitive vectors [S1].

**Data Structures:**
1.  **Codebook ($C$):** A list of $K$ centroids [S1]. For SH, $C \in \mathbb{R}^{K \times D}$ where $D$ is the SH vector dimension [S1]. For shape, $C \in \mathbb{R}^{K \times 3}$ representing normalized covariance matrices or normalized scaling vectors [S1].
2.  **Gaussian Attributes:** `codebook_index` (integer ID), `eta` (scalar float for shape magnitude), and full coefficients stored only if the Gaussian is sensitive [S1].

**Sensitivity Computation:**
Sensitivity $S(x)$ for a vector $x$ is defined as the maximum sensitivity across its components [S1]:
$$ S(x) = \max_d S(x_d) $$

**Algorithm Steps:**
1.  **Compute Sensitivity:** Calculate $S(c_i)$ for SH coefficients and $S(\text{shape}_i)$ for shape parameters using gradients from training images [S1].
2.  **Re-parameterize Shape:** Decompose scaling vector $s = \eta \hat{s}$, where $\eta = \|s\|_2$ and $\hat{s} = \eta^{-1} s$ [S1]. Construct the normalized covariance matrix $\hat{\Sigma} = (R \hat{S})(R \hat{S})^T$ [S1].
3.  **Identify Sensitive Vectors:** If $S(c_i) > \beta_c$, mark Gaussian $i$ as SH-sensitive; if $S(\text{shape}_i) > \beta_g$, mark it as shape-sensitive [S1].
4.  **Cluster Non-Sensitive Vectors:** Collect all non-sensitive SH vectors and non-sensitive normalized shape vectors, then perform sensitivity-aware vector clustering to generate codebooks $C_{SH}$ and $C_{Shape}$ [S1].
5.  **Assign Centroids:** For each non-sensitive Gaussian, find the centroid $c_k \in C$ minimizing the weighted distance:
    $$ D(x, c_k) = S(x) \|x - c_k\|_2^2 $$
    Assign the Gaussian to cluster $k$ [S1].
6.  **Store Results:** Sensitive Gaussians store full coefficients/parameters; non-sensitive Gaussians store `codebook_index` and $\eta$ [S1].

**Sensitivity-Aware Vector Clustering (Pseudocode):**
This function implements the batched k-Means variant with moving-average updates described in the source [S1].

```python
def sensitivity_aware_kmeans(vectors, sensitivities, k, max_steps, decay_factor, batch_size):
    """
    Clusters vectors using sensitivity-weighted distance with batched moving-average updates.
    vectors: List of vectors x in R^D.
    sensitivities: List of scalar sensitivities S(x) for each vector.
    k: Number of centroids.
    max_steps: Number of update steps.
    decay_factor: Lambda_d for moving average update.
    batch_size: Number of vectors processed per step.
    """
    import random
    # Initialize centroids by sampling k vectors from the input
    centroids = random.sample(vectors, k)
    
    for step in range(max_steps):
        # Sample a batch of indices
        batch_indices = random.sample(range(len(vectors)), batch_size)
        
        assignments = []
        for idx in batch_indices:
            x = vectors[idx]
            s = sensitivities[idx]
            min_dist = float('inf')
            best_j = -1
            for j, c in enumerate(centroids):
                # Weighted squared Euclidean distance
                dist = s * sum((x[d] - c[d])**2 for d in range(len(x)))
                if dist < min_dist:
                    min_dist = dist
                    best_j = j
            assignments.append((idx, best_j))
            
        # Update centroids using moving average
        for j in range(k):
            assigned = [(idx, sensitivities[idx]) for idx, best_j in assignments if best_j == j]
            if not assigned:
                continue
            # Compute weighted mean for the batch
            new_centroid = [0.0] * len(vectors[0])
            weight_sum = 0.0
            for idx, s in assigned:
                x = vectors[idx]
                for d in range(len(x)):
                    new_centroid[d] += s * x[d]
                weight_sum += s
            if weight_sum > 0:
                new_centroid = [v / weight_sum for v in new_centroid]
            # Moving average update
            centroids[j] = [decay_factor * centroids[j][d] + (1 - decay_factor) * new_centroid[d] for d in range(len(x))]
            
    return centroids
```

**Parameters:**
*   $\beta_c$ (SH sensitivity threshold): Tested values $6.0 \cdot 10^{-8}$, $3.0 \cdot 10^{-7}$, $6.0 \cdot 10^{-7}$, $1.2 \cdot 10^{-6}$, $6.0 \cdot 10^{-6}$, $1.5 \cdot 10^{-6}$, $3.0 \cdot 10^{-6}$ [S1]. Default configuration $\beta_c = 3.0 \cdot 10^{-7}$ [S1].
*   $\beta_g$ (Shape sensitivity threshold): Tested values $6.0 \cdot 10^{-6}$, $3.0 \cdot 10^{-5}$, and no threshold (-) [S1]. Default configuration $\beta_g = 6.0 \cdot 10^{-6}$ [S1].
*   Codebook size ($K$): Default 4096 [S1].
*   Decay factor ($\lambda_d$): 0.8 [S1].
*   Update steps: 800 for Gaussians, 100 for SH coefficients [S1].
*   Batch size: $2^{18}$ for color features, $2^{20}$ for Gaussian parameters [S1].

**Edge Cases:**
*   **No Threshold:** If $\beta_c$ and $\beta_g$ are set to exclude no vectors, all vectors are clustered, yielding similar size but slightly lower PSNR/SSIM compared to the default configuration [S1].
*   **High Sensitivity:** Vectors with sensitivity above the threshold are stored explicitly, which degrades compression ratio if most vectors are sensitive [S1].
*   **Precision:** Sensitivity calculation relies on gradients; numerical instability in gradient computation can misclassify sensitive vectors [G].

## Subtopics

### Gaussian Shape Compression
Compresses 3D Gaussian shape parameters by re-parameterizing the scaling vector into a scalar magnitude $\eta$ and a normalized direction, then clustering the resulting normalized covariance matrices [S1]. It uses a sensitivity threshold $\beta_g$ (typical value $3 \cdot 10^{-6}$) to exclude highly sensitive shapes from clustering [S1]. Each Gaussian stores a codebook index for the shape and the scalar $\eta$ [S1].

## Operating characteristics
**Time Complexity:** Clustering is iterative and uses a batched strategy with 800 steps for Gaussians and 100 for SH coefficients [S1]. The complexity per step is $O(B \cdot K \cdot D)$ where $B$ is batch size, $K$ is codebook size, and $D$ is vector dimension [G].
**Memory Complexity:** Reduces storage from full coefficients to codebook indices and scalars [S1]. Default configuration achieves a size of 28.80 MB for the Garden scene (Mip-Nerf360), compared to a baseline of 1379.99 MB [S1].
**Measured Performance:** On Mip-Nerf360, default settings ($\beta_c=3.0 \cdot 10^{-7}, \beta_g=6.0 \cdot 10^{-6}$) yield PSNR 26.98, SSIM 0.80, LPIPS 0.24 [S1]. Image quality is highly sensitive to $\beta_c$; increasing $\beta_c$ causes significant PSNR drops [S1].
**Strengths:** High compression rates with minimal quality loss for the majority of Gaussians [S1].
**Limitations:** Position quantization is not supported without significant error [S1].

## Background
Originated in the paper "Compressed 3D Gaussian Splatting for Accelerated Novel View Synthesis" (CVPR 2024) [S1]. It addresses the high memory footprint of 3D Gaussian Splatting, particularly the storage of spherical harmonic coefficients for color and shape parameters for geometry [S1]. The method leverages the observation that only a small fraction of Gaussians significantly contribute to the training images' appearance, allowing the rest to be compressed via clustering [S1].
