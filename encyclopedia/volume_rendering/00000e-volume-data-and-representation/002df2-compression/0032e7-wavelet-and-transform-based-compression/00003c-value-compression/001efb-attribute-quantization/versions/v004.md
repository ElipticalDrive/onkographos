# Attribute Quantization

Also called: CIELAB color quantization, Perceptual quantization

## Overview
Attribute Quantization is a lossy compression technique that reduces the precision of voxel attributes (such as colors and normals) to lower memory footprint while maintaining perceptual quality [S1]. It solves the problem of excessive memory usage in attribute arrays, which often exceeds the geometry storage size in hierarchical volume representations [S1]. It is distinguished from its siblings, such as [Quantization](5935-quantization.md) (generic) and [Thresholding and Quantization](5722-thresholding-and-quantization.md) (coefficient reduction), by specializing the quantization strategy based on the data type (e.g., using CIELAB for colors and Octahedron Normal Vectors for normals) to leverage human perception limits and achieve higher precision per bit [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A volume attribute array $A$ containing continuous values for colors (RGB) and/or normals (3D vectors).
*   **Output:** A compressed attribute array with reduced bit depth and/or palette indices, ready for entropy coding.

**Data Structures:**
*   **Color:** Quantized values in CIELAB space.
*   **Normals:** Quantized Octahedron Normal Vectors (ONVs).
*   **Palette:** A lookup table mapping quantized indices to representative attribute values (used in conjunction with palette compression).

**Steps:**

1.  **Color Quantization (CIELAB):**
    *   Convert input RGB colors to CIELAB color space. This space is (locally) perceptually uniform, allowing for clustering based on perceived difference rather than Euclidean distance in RGB [S1].
    *   Perform data-driven clustering (e.g., k-means) on the CIELAB values to determine representative colors. The number of colors is user-defined; 12-bit (4096 colors) is typical [S1].
    *   Replace each voxel's color with the index of its nearest cluster center.
    *   *Note:* This method requires preprocessing to analyze the color distribution of the scene [S1].

2.  **Normal Quantization (ONVs):**
    *   For each normal vector $\mathbf{n} = (n_x, n_y, n_z)$, compute the Octahedron Normal Vector representation.
    *   The ONV maps the sphere to an octahedron, allowing for uniform quantization. This yields higher precision for the same number of bits compared to storing one value per dimension [S1].
    *   Quantize the ONV coordinates to the desired bit depth (e.g., 10-bit or 12-bit).
    *   *Typical Values:* 12-bit ONVs produce minor banding; 10-bit may suffice for diffuse shading but causes visible banding on smooth surfaces; 16-bit is preferred for specular effects [S1].

3.  **Palette Compression (Optional but Recommended):**
    *   Construct a palette of unique quantized attributes.
    *   Replace the attribute array with indices into this palette.
    *   This reduces the number of distinct values significantly, improving subsequent entropy coding ratios [S1].

**Formulas:**
*   **CIE94 Delta-E:** Used to assess perceptual quality. Parameters: $k_L = 1$, $K_1 = 0.045$, $K_2 = 0.015$, with D65 illuminant as reference white [S1].
*   **Color Difference Magnitude:** $\sqrt{dR^2 + dG^2 + dB^2}$, used for visual comparison metrics [S1].

**Pseudocode:**

```python
def quantize_colors_rgb_to_lab(rgb_array, num_colors=4096):
    """
    Quantize RGB colors using CIELAB clustering.
    """
    # Convert RGB to CIELAB
    lab_array = rgb_to_lab(rgb_array)
    
    # Data-driven clustering (e.g., k-means) to find centroids
    # This step requires preprocessing
    centroids = kmeans(lab_array, k=num_colors)
    
    # Assign each voxel to nearest centroid
    indices = find_nearest_centroid(lab_array, centroids)
    
    return indices, centroids

def quantize_normals_onv(normals, bit_depth=12):
    """
    Quantize normals using Octahedron Normal Vectors.
    """
    # Normalize input normals
    n = normalize(normals)
    
    # Map to octahedron coordinates
    # ONV(x, y) = (sign(z) * (1 - |y|), sign(z) * (1 - |x|))
    # Note: Exact ONV formula may vary by implementation, 
    # but the goal is uniform distribution on the octahedron surface.
    onv_x = sign(n.z) * (1 - abs(n.y))
    onv_y = sign(n.z) * (1 - abs(n.x))
    
    # Quantize to bit_depth
    max_val = 2**bit_depth - 1
    q_x = round(onv_x * max_val) / max_val
    q_y = round(onv_y * max_val) / max_val
    
    # Reconstruct normal from quantized ONV if needed for rendering
    # Or store q_x, q_y directly
    return q_x, q_y

def build_palette(indices, centroids):
    """
    Build a palette from quantized indices and centroids.
    """
    unique_indices = unique(indices)
    palette = [centroids[i] for i in unique_indices]
    return palette
```

## Subtopics

### [Quantization with Noise Injection](2090-quantization-with-noise-injection.md)
Quantization with Noise Injection compresses continuous attributes into discrete values for entropy coding by simulating quantization error during training via uniform noise injection, while applying explicit rounding during inference. It differs from standard quantization by preserving gradient flow through the otherwise non-differentiable rounding operation, enabling end-to-end training with quantization constraints.

### [Thresholding and Quantization](5722-thresholding-and-quantization.md)
Thresholding and Quantization is a lossy compression technique that reduces the data size of a compact volume model by neglecting or approximating its coefficients. It solves the problem of excessive memory footprint in hierarchical or transform-based representations by allowing the user to define an acceptable error bound. It is distinguished from its parent, Attribute Quantization, by focusing on the reduction of model coefficients (such as wavelet or tensor coefficients) rather than just attribute precision, and from its sibling, Quantization with Noise Injection, by relying on deterministic truncation or rounding rather than stochastic noise addition.

## Operating characteristics
*   **Memory Reduction:** Attribute arrays often exceed the geometry (DAG) size. Quantization combined with palette compression can reduce the attribute memory footprint to a similar order of magnitude as the geometry [S1].
*   **Compression Rates:** Reported compression rates for attributes vary by scene (e.g., 20% to 69% reduction) [S1].
*   **Perceptual Quality:** Assessed using CIE94 Delta-E and SSIM metrics. 12-bit colors and normals generally maintain high visual quality [S1].
*   **Preprocessing Cost:** Color quantization requires preprocessing to analyze colors, which adds an initial computational cost [S1].
*   **Bit Depth Trade-offs:** Lower bit depths (e.g., 10-bit normals) may cause visible banding on smooth surfaces or specular highlights, while higher bit depths (16-bit) are preferred for high-fidelity effects [S1].

## Background
Attribute Quantization was proposed in the context of geometry and attribute compression for voxel scenes [S1]. It addresses the limitation of lossless palette compression, which is overly conservative for scenes with millions of similar colors [S1]. By leveraging perceptual uniformity (CIELAB) and efficient normal representation (ONVs), it enables significant memory savings without noticeable visual degradation [S1].
