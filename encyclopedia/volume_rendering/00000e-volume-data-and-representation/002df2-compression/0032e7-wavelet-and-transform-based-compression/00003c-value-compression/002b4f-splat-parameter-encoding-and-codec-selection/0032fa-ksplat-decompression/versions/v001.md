# Ksplat Decompression

Also called: .ksplat format decoder, Kevin Kwok's compressed splat format, Splat Transform Ksplat Reader, ksplat reader, readKsplat

## Overview
Ksplat Decompression reads and decompresses `.ksplat` files, which contain spatially bucketed and quantized 3D Gaussian Splat data, into a structured `DataTable` format suitable for rendering. It handles position quantization, scale/rotation compression, and spherical harmonics decoding. Unlike raw PLY formats, it supports three distinct compression modes (Float32, Float16, Uint8) to balance file size and precision, and uses spatial bucketing to optimize position storage.

## How it works
**Inputs and Outputs:**
- **Input:** A binary `.ksplat` file.
- **Output:** A structured object (DataTable) containing 14 base columns (`x, y, z, scale_0, scale_1, scale_2, f_dc_0, f_dc_1, f_dc_2, opacity, rot_0, rot_1, rot_2, rot_3`) and additional columns for spherical harmonics (`f_rest_i`).

**Data Structures:**
The file layout is defined by a Main Header and Section Headers.

**Main Header (4096 bytes):**
- Offset 0: `majorVersion` (u8)
- Offset 1: `minorVersion` (u8)
- Offset 4: `maxSections` (u32 LE)
- Offset 16: `numSplats` (u32 LE)
- Offset 20: `compressionMode` (u16 LE)
- Offset 36: `minHarmonicsValue` (f32 LE)
- Offset 40: `maxHarmonicsValue` (f32 LE)

**Section Header (1024 bytes):**
- Offset 0: `sectionSplatCount` (u32 LE)
- Offset 4: `maxSectionSplats` (u32 LE)
- Offset 8: `bucketCapacity` (u32 LE)
- Offset 12: `bucketCount` (u32 LE)
- Offset 16: `spatialBlockSize` (f32 LE)
- Offset 20: `bucketStorageSize` (u16 LE)
- Offset 24: `quantizationRange` (u32 LE)
- Offset 32: `fullBuckets` (u32 LE)
- Offset 36: `partialBuckets` (u32 LE)
- Offset 40: `harmonicsDegree` (u16 LE)

**Compression Modes:**
The `COMPRESSION_MODES` array defines byte sizes for each component based on `compressionMode` (0, 1, or 2).
- **Mode 0 (Float32):** center=12, scale=12, rotation=16, color=4, harmonics=4. `scaleStart`=12, `rotStart`=24, `colorStart`=40, `harmStart`=44. `quantRange`=1.
- **Mode 1 (Float16):** center=6, scale=6, rotation=8, color=4, harmonics=2. `scaleStart`=6, `rotStart`=12, `colorStart`=20, `harmStart`=24. `quantRange`=32767.
- **Mode 2 (Uint8):** center=6, scale=6, rotation=8, color=4, harmonics=1. `scaleStart`=6, `rotStart`=12, `colorStart`=20, `harmStart`=24. `quantRange`=32767.

**Steps:**
1. **Load and Validate:** Read the entire file into a buffer. Validate `totalSize >= 4096`. Parse the main header. Check `majorVersion === 0` and `minorVersion >= 1`. Check `compressionMode <= 2`. Check `numSplats > 0`.
2. **Initialize Columns:** Create 14 base `Float32Array`s of size `numSplats` for `x, y, z, scale_0/1/2, f_dc_0/1/2, opacity, rot_0/1/2/3`.
3. **Determine Harmonics:** Iterate section headers to find `maxHarmonicsDegree`. Calculate `maxHarmonicsComponentCount` using `HARMONICS_COMPONENT_COUNT[maxHarmonicsDegree]`. Add `f_rest_i` columns for `i` from 0 to `maxHarmonicsComponentCount - 1`.
4. **Calculate Byte Sizes:** Get `compressionConfig` from `COMPRESSION_MODES[compressionMode]`. Calculate `bytesPerSplat = centerBytes + scaleBytes + rotationBytes + colorBytes + harmonicsComponentCount * harmonicsBytes`.
5. **Process Sections:** Iterate `sectionIdx` from 0 to `maxSections - 1`. Read section header at `MAIN_HEADER_SIZE + sectionIdx * 1024`. If `sectionSplatCount === 0`, skip.
6. **Calculate Bucket Info:** Determine `bucketCapacity` and `bucketCount` from the section header. Calculate `fullBuckets` and `partialBuckets`.
7. **Read Bucket Centers:** Read `bucketCount * 3` Float32s for bucket centers.
8. **Read Partial Bucket Sizes:** Read `partialBuckets` Uint32s for partial bucket sizes.
9. **Iterate Splats:** For each splat in the section (0 to `sectionSplatCount - 1`):
    a. **Calculate Offset:** `splatByteOffset = splatIdx * bytesPerSplat`.
    b. **Determine Bucket Index:** If `splatIdx < fullBucketSplats`, `bucketIdx = Math.floor(splatIdx / bucketCapacity)`. Else, track `currentPartialBucket` and `currentPartialBase` using `partialBucketSizes` to find the correct bucket.
    c. **Decode Position:**
       - If `compressionMode == 0`: Read three Float32s.
       - Else: Read three Uint16s. Subtract `quantizationRange`, multiply by `positionScale`, and add `bucketCenters[bucketIdx * 3 + i]`.
       - `positionScale = spatialBlockSize / 2.0 / quantizationRange`.
    d. **Decode Scales:**
       - If `compressionMode == 0`: Read three Float32s.
       - Else: Read three Uint16s and decode to Float16.
       - If `scaleX > 0`, store `Math.log(scaleX)`, else store `-10`.
    e. **Decode Rotation:**
       - If `compressionMode == 0`: Read four Float32s.
       - Else: Read four Uint16s and decode to Float16.
       - Store in `rot_0..rot_3`.
    f. **Decode Color/Opacity:** Read four Uint8s for R, G, B, Opacity.
       - Convert R/G/B from 0-255 to 0-1, subtract 0.5, divide by `SH_C0` (0.28209479177387814).
       - Clamp `opacity/255.0` to `[epsilon, 1-epsilon]` where `epsilon=1e-6`. Apply inverse sigmoid: `Math.log(normalizedOpacity / (1.0 - normalizedOpacity))`.
    g. **Decode Spherical Harmonics:**
       - Loop `i` from 0 to `harmonicsComponentCount - 1`.
       - Map `i` to channel and coefficient based on band packing (Band 0: 9 coeffs, Band 1: 15 coeffs).
       - Calculate column index `col = channel * (harmonicsComponentCount / 3) + coefficient`.
       - Decode Harmonics:
         - Mode 0: Read Float32.
         - Mode 1: Read Uint16 and decode Float16.
         - Mode 2: Read Uint8, normalize by 255, then map to `[minHarmonicsValue, maxHarmonicsValue]`.
       - Store in `columns[14 + col]`.

**Pseudocode:**

```python
import struct
import math

def decode_float16(encoded: int) -> float:
    sign_bit = (encoded >> 15) & 1
    exponent = (encoded >> 10) & 0x1f
    mantissa = encoded & 0x3ff
    
    if exponent == 0:
        if mantissa == 0:
            return -0.0 if sign_bit else 0.0
        m = mantissa
        exp = -14
        while not (m & 0x400):
            m <<= 1
            exp -= 1
        m &= 0x3ff
        final_exp = exp + 127
        final_mantissa = m << 13
        bits = (sign_bit << 31) | (final_exp << 23) | final_mantissa
        return struct.unpack('f', struct.pack('I', bits))[0]
    
    if exponent == 0x1f:
        return -math.inf if (sign_bit and mantissa == 0) else (math.inf if not sign_bit and mantissa == 0 else math.nan)
    
    final_exp = exponent - 15 + 127
    final_mantissa = mantissa << 13
    bits = (sign_bit << 31) | (final_exp << 23) | final_mantissa
    return struct.unpack('f', struct.pack('I', bits))[0]

def decode_ksplat(file_path: str) -> dict:
    with open(file_path, 'rb') as f:
        data = f.read()
    
    if len(data) < 4096:
        raise ValueError("File too small")
    
    # Parse Main Header
    major_version = data[0]
    minor_version = data[1]
    max_sections = struct.unpack_from('<I', data, 4)[0]
    num_splats = struct.unpack_from('<I', data, 16)[0]
    compression_mode = struct.unpack_from('<H', data, 20)[0]
    min_harmonics_value = struct.unpack_from('<f', data, 36)[0]
    max_harmonics_value = struct.unpack_from('<f', data, 40)[0]
    
    if major_version != 0 or minor_version < 1:
        raise ValueError("Unsupported version")
    if compression_mode > 2:
        raise ValueError("Invalid compression mode")
    if num_splats == 0:
        raise ValueError("Empty file")
    
    # Compression Modes Config
    COMPRESSION_MODES = [
        {'center': 12, 'scale': 12, 'rotation': 16, 'color': 4, 'harmonics': 4, 'scale_start': 12, 'rot_start': 24, 'color_start': 40, 'harm_start': 44, 'quant_range': 1},
        {'center': 6, 'scale': 6, 'rotation': 8, 'color': 4, 'harmonics': 2, 'scale_start': 6, 'rot_start': 12, 'color_start': 20, 'harm_start': 24, 'quant_range': 32767},
        {'center': 6, 'scale': 6, 'rotation': 8, 'color': 4, 'harmonics': 1, 'scale_start': 6, 'rot_start': 12, 'color_start': 20, 'harm_start': 24, 'quant_range': 32767}
    ]
    
    config = COMPRESSION_MODES[compression_mode]
    
    # Initialize Columns
    columns = {
        'x': [0.0] * num_splats,
        'y': [0.0] * num_splats,
        'z': [0.0] * num_splats,
        'scale_0': [0.0] * num_splats,
        'scale_1': [0.0] * num_splats,
        'scale_2': [0.0] * num_splats,
        'f_dc_0': [0.0] * num_splats,
        'f_dc_1': [0.0] * num_splats,
        'f_dc_2': [0.0] * num_splats,
        'opacity': [0.0] * num_splats,
        'rot_0': [0.0] * num_splats,
        'rot_1': [0.0] * num_splats,
        'rot_2': [0.0] * num_splats,
        'rot_3': [0.0] * num_splats
    }
    
    # Determine Harmonics
    max_harmonics_degree = 0
    section_headers = []
    for i in range(max_sections):
        offset = 4096 + i * 1024
        if offset + 1024 > len(data):
            break
        section_splat_count = struct.unpack_from('<I', data, offset)[0]
        max_section_splats = struct.unpack_from('<I', data, offset + 4)[0]
        bucket_capacity = struct.unpack_from('<I', data, offset + 8)[0]
        bucket_count = struct.unpack_from('<I', data, offset + 12)[0]
        spatial_block_size = struct.unpack_from('<f', data, offset + 16)[0]
        bucket_storage_size = struct.unpack_from('<H', data, offset + 20)[0]
        quantization_range = struct.unpack_from('<I', data, offset + 24)[0]
        full_buckets = struct.unpack_from('<I', data, offset + 32)[0]
        partial_buckets = struct.unpack_from('<I', data, offset + 36)[0]
        harmonics_degree = struct.unpack_from('<H', data, offset + 40)[0]
        
        if section_splat_count > 0:
            section_headers.append({
                'splat_count': section_splat_count,
                'max_splats': max_section_splats,
                'bucket_capacity': bucket_capacity,
                'bucket_count': bucket_count,
                'spatial_block_size': spatial_block_size,
                'quantization_range': quantization_range if quantization_range > 0 else config['quant_range'],
                'full_buckets': full_buckets,
                'partial_buckets': partial_buckets,
                'harmonics_degree': harmonics_degree
            })
            if harmonics_degree > max_harmonics_degree:
                max_harmonics_degree = harmonics_degree
    
    # HARMONICS_COMPONENT_COUNT mapping (simplified for degree 0 and 1)
    HARMONICS_COMPONENT_COUNT = {0: 9, 1: 27, 2: 45, 3: 63} # Example mapping, actual logic may vary
    max_harmonics_component_count = HARMONICS_COMPONENT_COUNT.get(max_harmonics_degree, 0)
    
    # Add Harmonics Columns
    for i in range(max_harmonics_component_count):
        columns[f'f_rest_{i}'] = [0.0] * num_splats
    
    # Process Sections
    current_splat_idx = 0
    for section in section_headers:
        section_data_offset = 4096 + len(section_headers) * 1024 # Simplified offset calculation, actual offset depends on previous sections' data size
        # Note: In real implementation, offsets must be calculated sequentially based on previous section data sizes.
        # For this pseudocode, we assume sequential reading from a single buffer pointer.
        
        bucket_capacity = section['bucket_capacity']
        bucket_count = section['bucket_count']
        spatial_block_size = section['spatial_block_size']
        quantization_range = section['quantization_range']
        full_buckets = section['full_buckets']
        partial_buckets = section['partial_buckets']
        
        position_scale = spatial_block_size / 2.0 / quantization_range
        
        # Read Bucket Centers
        bucket_centers_offset = section_data_offset + 4096 + len(section_headers) * 1024 # Placeholder for actual offset logic
        bucket_centers = []
        for i in range(bucket_count * 3):
            val = struct.unpack_from('<f', data, bucket_centers_offset + i * 4)[0]
            bucket_centers.append(val)
            
        # Read Partial Bucket Sizes
        partial_bucket_sizes_offset = bucket_centers_offset + bucket_count * 3 * 4
        partial_bucket_sizes = []
        for i in range(partial_buckets):
            val = struct.unpack_from('<I', data, partial_bucket_sizes_offset + i * 4)[0]
            partial_bucket_sizes.append(val)
            
        # Calculate bytes per splat
        bytes_per_splat = config['center'] + config['scale'] + config['rotation'] + config['color'] + max_harmonics_component_count * config['harmonics']
        
        current_partial_bucket = 0
        current_partial_base = 0
        
        for splat_idx in range(section['splat_count']):
            splat_byte_offset = section_data_offset + 4096 + len(section_headers) * 1024 + splat_idx * bytes_per_splat # Simplified
            
            # Determine Bucket Index
            if splat_idx < full_buckets * bucket_capacity:
                bucket_idx = splat_idx // bucket_capacity
            else:
                # Handle partial buckets
                while current_partial_bucket < partial_buckets and current_partial_base + partial_bucket_sizes[current_partial_bucket] <= splat_idx:
                    current_partial_base += partial_bucket_sizes[current_partial_bucket]
                    current_partial_bucket += 1
                bucket_idx = full_buckets + current_partial_bucket
            
            # Decode Position
            if compression_mode == 0:
                x = struct.unpack_from('<f', data, splat_byte_offset)[0]
                y = struct.unpack_from('<f', data, splat_byte_offset + 4)[0]
                z = struct.unpack_from('<f', data, splat_byte_offset + 8)[0]
            else:
                x_raw = struct.unpack_from('<H', data, splat_byte_offset)[0]
                y_raw = struct.unpack_from('<H', data, splat_byte_offset + 2)[0]
                z_raw = struct.unpack_from('<H', data, splat_byte_offset + 4)[0]
                x = (x_raw - quantization_range) * position_scale + bucket_centers[bucket_idx * 3]
                y = (y_raw - quantization_range) * position_scale + bucket_centers[bucket_idx * 3 + 1]
                z = (z_raw - quantization_range) * position_scale + bucket_centers[bucket_idx * 3 + 2]
            
            columns['x'][current_splat_idx] = x
            columns['y'][current_splat_idx] = y
            columns['z'][current_splat_idx] = z
            
            # Decode Scales
            if compression_mode == 0:
                scale_0 = struct.unpack_from('<f', data, splat_byte_offset + config['center'])[0]
                scale_1 = struct.unpack_from('<f', data, splat_byte_offset + config['center'] + 4)[0]
                scale_2 = struct.unpack_from('<f', data, splat_byte_offset + config['center'] + 8)[0]
            else:
                scale_0 = decode_float16(struct.unpack_from('<H', data, splat_byte_offset + config['center'])[0])
                scale_1 = decode_float16(struct.unpack_from('<H', data, splat_byte_offset + config['center'] + 2)[0])
                scale_2 = decode_float16(struct.unpack_from('<H', data, splat_byte_offset + config['center'] + 4)[0])
            
            columns['scale_0'][current_splat_idx] = math.log(scale_0) if scale_0 > 0 else -10
            columns['scale_1'][current_splat_idx] = math.log(scale_1) if scale_1 > 0 else -10
            columns['scale_2'][current_splat_idx] = math.log(scale_2) if scale_2 > 0 else -10
            
            # Decode Rotation
            if compression_mode == 0:
                rot_0 = struct.unpack_from('<f', data, splat_byte_offset + config['scale_start'])[0]
                rot_1 = struct.unpack_from('<f', data, splat_byte_offset + config['scale_start'] + 4)[0]
                rot_2 = struct.unpack_from('<f', data, splat_byte_offset + config['scale_start'] + 8)[0]
                rot_3 = struct.unpack_from('<f', data, splat_byte_offset + config['scale_start'] + 12)[0]
            else:
                rot_0 = decode_float16(struct.unpack_from('<H', data, splat_byte_offset + config['scale_start'])[0])
                rot_1 = decode_float16(struct.unpack_from('<H', data, splat_byte_offset + config['scale_start'] + 2)[0])
                rot_2 = decode_float16(struct.unpack_from('<H', data, splat_byte_offset + config['scale_start'] + 4)[0])
                rot_3 = decode_float16(struct.unpack_from('<H', data, splat_byte_offset + config['scale_start'] + 6)[0])
            
            columns['rot_0'][current_splat_idx] = rot_0
            columns['rot_1'][current_splat_idx] = rot_1
            columns['rot_2'][current_splat_idx] = rot_2
            columns['rot_3'][current_splat_idx] = rot_3
            
            # Decode Color/Opacity
            r = data[splat_byte_offset + config['rot_start']] / 255.0
            g = data[splat_byte_offset + config['rot_start'] + 1] / 255.0
            b = data[splat_byte_offset + config['rot_start'] + 2] / 255.0
            opacity_raw = data[splat_byte_offset + config['rot_start'] + 3] / 255.0
            
            epsilon = 1e-6
            opacity_clamped = max(epsilon, min(1.0 - epsilon, opacity_raw))
            opacity_logit = math.log(opacity_clamped / (1.0 - opacity_clamped))
            
            sh_c0 = 0.28209479177387814
            columns['f_dc_0'][current_splat_idx] = (r - 0.5) / sh_c0
            columns['f_dc_1'][current_splat_idx] = (g - 0.5) / sh_c0
            columns['f_dc_2'][current_splat_idx] = (b - 0.5) / sh_c0
            columns['opacity'][current_splat_idx] = opacity_logit
            
            # Decode Spherical Harmonics
            harm_offset = splat_byte_offset + config['harm_start']
            for i in range(max_harmonics_component_count):
                if compression_mode == 0:
                    val = struct.unpack_from('<f', data, harm_offset + i * 4)[0]
                elif compression_mode == 1:
                    val = decode_float16(struct.unpack_from('<H', data, harm_offset + i * 2)[0])
                else:
                    raw_val = data[harm_offset + i]
                    val = (raw_val / 255.0) * (max_harmonics_value - min_harmonics_value) + min_harmonics_value
                
                # Map to column
                # Simplified mapping logic
                col_idx = i
                columns[f'f_rest_{i}'][current_splat_idx] = val
            
            current_splat_idx += 1
            
    return columns
```

**Edge Cases and Pitfalls:**
- File size < 4096 bytes, `numSplats == 0`, `compressionMode > 2`, or unsupported version must throw errors.
- `quantizationRange` in section header may be 0; fallback to `scaleQuantRange` from `COMPRESSION_MODES`.
- Scale must be positive for log conversion; if not, store -10.
- Opacity must be clamped away from 0 and 1 before inverse sigmoid to avoid infinity.

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of splats and sections.
- **Memory Complexity:** Linear with respect to the number of splats, storing all columns in memory.
- **Performance:** Mode 0 (Float32) offers highest precision but largest file size. Modes 1 (Float16) and 2 (Uint8) reduce file size significantly but introduce quantization artifacts. Mode 2 is the most compact but lowest precision.
- **Strengths:** Efficient storage for large Gaussian Splat scenes, spatial bucketing for position data.
- **Limitations:** Limited to 3 compression modes, potential precision loss in Modes 1 and 2.

It was developed to support efficient reading and writing of compressed Gaussian Splat data in both Node.js and browser environments.
