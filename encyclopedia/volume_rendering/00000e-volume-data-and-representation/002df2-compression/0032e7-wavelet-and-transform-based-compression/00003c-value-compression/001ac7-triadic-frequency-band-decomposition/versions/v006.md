# Triadic frequency band decomposition

Also called: Hierarchical Data Decomposition, Hierarchical quantization scheme

## Overview
Triadic frequency band decomposition is a lossy compression method for volumetric scalar fields that partitions data into $4^3$ blocks and decomposes each block into a multiresolution representation of three frequency bands: high-frequency differences, mid-frequency differences, and mean [S1, unofficial]. It differs from scalar quantization by grouping spatially correlated differences into fixed-length vectors for vector quantization, and from pure transform coding by relying on hardware-friendly dependent texture fetches for on-the-fly decoding [S1, unofficial].

## How it works
**Inputs:** A 3D scalar field of size $N_x \times N_y \times N_z$.
**Outputs:** An RGB index texture $I$, two codebook textures $C_1$ and $C_2$, and an address texture $A$.

**Data Structures:**
1.  **Index Texture $I$:** A 3D texture of size $(N_x/4) \times (N_y/4) \times (N_z/4)$. Each texel stores three 8-bit values:
    *   R-component: The mean value of the block (8-bit).
    *   G-component: Index into codebook $C_1$ (8-bit).
    *   B-component: Index into codebook $C_2$ (8-bit).
2.  **Codebook $C_1$:** A 2D texture of size $256 \times 64$.
    *   Indexed by s-coordinate (from G-component of $I$) and t-coordinate (from Address Texture $A$).
    *   Stores 64-component codewords representing high-frequency differences.
3.  **Codebook $C_2$:** A 2D texture of size $256 \times 8$.
    *   Indexed by s-coordinate (from B-component of $I$) and t-coordinate (from Address Texture $A$).
    *   Stores 8-component codewords representing mid-frequency differences.
4.  **Address Texture $A$:** A 2D texture of size $4^3$ (matching the encoded texel region size).
    *   R-component: Stores 64 different addresses to index $C_1$.
    *   G-component: Stores 8 different addresses to index $C_2$.
    *   Mapped via nearest-neighbor interpolation.

**Algorithm Steps:**

1.  **Partitioning:** Divide the original scalar field into disjoint blocks of size $4^3$ voxels [S1, unofficial].
2.  **First Down-sampling (High-Frequency Band):** For each $4^3$ block, down-sample by a factor of two by averaging disjoint sets of $2^3$ voxels. This produces $2^3 = 8$ mean values [S1, unofficial].
3.  **High-Frequency Vector:** Calculate the difference between the original 64 data samples and their respective down-sampled values (the 8 mean values replicated to fill the $4^3$ space). Store these 64 differences in a 64-component vector [S1, unofficial].
4.  **Second Down-sampling (Mid-Frequency Band):** Apply the same down-sampling process (averaging disjoint sets of $2^3$ voxels) to the 8 mean values from Step 2. This produces one single value representing the mean of the entire block [S1, unofficial].
5.  **Mid-Frequency Vector:** Store the 7 difference values carrying the information lost when going from the 8 mean values to the final single mean value in an 8-component vector [S1, unofficial].
6.  **Mean Vector:** Store the single mean value in a 1-component vector [S1, unofficial].
7.  **Thresholding:** Apply thresholding to the 64-component and 8-component difference vectors. If detail coefficients are small or zero (indicating homogeneous or empty regions), map the vector to the zero vector. This maximizes codeword usage for significant non-zero vectors and simplifies the quantization relaxation process [S1, unofficial].
8.  **Vector Quantization:** Quantize each frequency band separately using vector quantization with pre-computed codebooks [S1, unofficial].
    *   The 64-component vector is quantized using codebook $C_1$.
    *   The 8-component vector is quantized using codebook $C_2$.
    *   Codebook length is 256 entries for both, allowing indices to be stored as one 8-bit value [S1, unofficial].
9.  **Assembly:** Assemble the original signal from the mean and the quantized difference contributions to enhance fidelity [S1, unofficial].
10. **Storage:** Store the mean (R), $C_1$ index (G), and $C_2$ index (B) in the corresponding texel of Index Texture $I$ [S1, unofficial].

**Pseudocode:**

```python
def triadic_decomposition(volume, block_size=4):
    """
    Decomposes a 3D volume into triadic frequency bands.
    volume: 3D numpy array of shape (Nx, Ny, Nz)
    Returns: mean_texture, idx_c1_texture, idx_c2_texture, address_texture
    """
    Nx, Ny, Nz = volume.shape
    # Ensure dimensions are divisible by block_size
    assert Nx % block_size == 0 and Ny % block_size == 0 and Nz % block_size == 0
    
    # Pre-compute codebooks C1 and C2 (256 entries each)
    # In practice, these are trained on representative data.
    # Here we assume they exist and provide quantization functions.
    # C1: 256 x 64 codewords
    # C2: 256 x 8 codewords
    
    # Address texture A: 4x4x4 (flattened to 2D for texture storage)
    # R: 64 addresses for C1
    # G: 8 addresses for C2
    address_texture = create_address_texture()
    
    # Output textures
    # I: (Nx/4) x (Ny/4) x (Nz/4)
    mean_texture = np.zeros((Nx//block_size, Ny//block_size, Nz//block_size), dtype=np.uint8)
    idx_c1_texture = np.zeros((Nx//block_size, Ny//block_size, Nz//block_size), dtype=np.uint8)
    idx_c2_texture = np.zeros((Nx//block_size, Ny//block_size, Nz//block_size), dtype=np.uint8)
    
    for x in range(0, Nx, block_size):
        for y in range(0, Ny, block_size):
            for z in range(0, Nz, block_size):
                # Extract block
                block = volume[x:x+block_size, y:y+block_size, z:z+block_size]
                
                # Step 1: Down-sample by averaging 2x2x2 sets
                # Block is 4x4x4. 8 sets of 2x2x2.
                # Reshape to (2,2,2, 2,2,2) and average over last 3 dims
                reshaped = block.reshape(2, 2, 2, 2, 2, 2)
                means_2x2x2 = reshaped.mean(axis=(3, 4, 5)) # Shape: (2,2,2) -> 8 values
                
                # Step 2: High-frequency vector (64 components)
                # Replicate means to 4x4x4 and subtract from original
                means_replicated = means_2x2x2.repeat(2, axis=0).repeat(2, axis=1).repeat(2, axis=2)
                high_freq_vector = (block - means_replicated).flatten() # 64 components
                
                # Step 3: Second down-sample (1 value)
                # Average the 8 means into 1
                means_reshaped = means_2x2x2.reshape(2, 2, 2)
                mean_val = means_2x2x2.mean()
                
                # Step 4: Mid-frequency vector (8 components)
                # Difference between the 8 means and the single mean
                mid_freq_vector = (means_2x2x2 - mean_val).flatten() # 8 components
                
                # Step 5: Thresholding
                # Map small/zero vectors to zero vector
                threshold = 0.0 # Example threshold
                if np.max(np.abs(high_freq_vector)) < threshold:
                    high_freq_vector = np.zeros(64)
                if np.max(np.abs(mid_freq_vector)) < threshold:
                    mid_freq_vector = np.zeros(8)
                    
                # Step 6: Vector Quantization
                # Quantize high_freq_vector using C1
                idx1 = quantize_vector(high_freq_vector, codebook_C1)
                
                # Quantize mid_freq_vector using C2
                idx2 = quantize_vector(mid_freq_vector, codebook_C2)
                
                # Step 7: Store in Index Texture
                # Mean is stored directly as 8-bit value
                mean_texture[x//block_size, y//block_size, z//block_size] = quantize_8bit(mean_val)
                idx_c1_texture[x//block_size, y//block_size, z//block_size] = idx1
                idx_c2_texture[x//block_size, y//block_size, z//block_size] = idx2
                
    return mean_texture, idx_c1_texture, idx_c2_texture, address_texture

def quantize_vector(vector, codebook):
    """
    Finds the index of the closest codeword in the codebook.
    codebook: array of shape (256, len(vector))
    """
    # Compute Euclidean distance to all codewords
    distances = np.linalg.norm(codebook - vector, axis=1)
    return np.argmin(distances)

def quantize_8bit(value):
    """
    Maps a float value to 8-bit integer.
    Assumes value is normalized or scaled appropriately.
    """
    # [G] Implementation detail: scaling depends on data range.
    # Standard linear quantization:
    return int(np.clip(value, 0, 255)).astype(np.uint8)
```

**Parameters:**
*   Block size: $4^3$ voxels [S1, unofficial].
*   Down-sampling factor: 2, using disjoint sets of $2^3$ voxels for averaging [S1, unofficial].
*   Codebook length: 256 entries for both $C_1$ and $C_2$, allowing indices to be stored as one 8-bit value [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Homogeneous Regions:** Thresholding maps zero-difference vectors to the zero vector. This is intentional to maximize codeword usage for significant vectors and simplify quantization [S1, unofficial].
*   **Precision:** Mean values are stored as 8-bit values directly, potentially losing precision compared to codebook lookup [S1, unofficial].
*   **Boundary Conditions:** The method assumes the volume dimensions are divisible by the block size ($4^3$). Padding or cropping may be required for non-divisible dimensions.

## Subtopics

### [Triadic Vector Quantization](6504-triadic-vector-quantization.md)
Triadic Vector Quantization is a lossy compression method for volumetric data that partitions scalar fields into $4^3$ blocks, decomposes each block into a multiresolution representation of three frequency bands, and quantizes the resulting vectors using discrete codebooks. It differs from scalar quantization by grouping spatially correlated differences into fixed-length vectors, and from pure transform coding by relying on hardware-friendly texture lookups for decoding.

### Spectral decomposition and error band partitioning
Spectral decomposition and error band partitioning computes centered Fourier spectra and partitions frequency coordinates into low, mid, and high bands to measure spectral magnitude reconstruction errors [S2, unofficial]. It differs from spatial block-based decomposition by operating in the frequency domain using 2D Discrete Fourier Transforms (DFT) and radial distance thresholds [S2, unofficial].

**Steps:**
1.  Compute the 2D discrete Fourier transform $\mathcal{F}(I)$ of the grayscale image $I$ [S2, unofficial].
2.  Apply `fftshift` to center the zero-frequency component, yielding the centered complex spectrum $\hat{I}$ [S2, unofficial].
3.  Extract the magnitude spectrum $A_I$ from $\hat{I}$ [S2, unofficial].
4.  For each frequency coordinate $(\xi, \eta)$, compute the Euclidean radial distance $D(\xi, \eta)$ from the centered zero-frequency location [S2, unofficial].
5.  Partition coordinates into three bands:
    *   Low: $D(\xi, \eta) \leq 30$
    *   Mid: $30 < D(\xi, \eta) \leq 80$
    *   High: $D(\xi, \eta) > 80$
    [S2, unofficial]

**Formulas:**
$$ \hat{I} = \text{fftshift}(\mathcal{F}(I)), \quad A_I = |\hat{I}| $$
$$ \Omega_{\text{low}} = \{(\xi, \eta) : D(\xi, \eta) \leq 30\}, \quad \Omega_{\text{mid}} = \{(\xi, \eta) : 30 < D(\xi, \eta) \leq 80\}, \quad \Omega_{\text{high}} = \{(\xi, \eta) : D(\xi, \eta) > 80\} $$
[S2, unofficial]

## Operating characteristics
*   **Time Complexity:** Encoding involves block-wise averaging and vector quantization, which is linear with respect to the number of voxels $N$. Decoding involves texture lookups and additions, which is also linear and highly parallelizable on GPU hardware [S1, unofficial].
*   **Memory Complexity:** The compressed representation requires storing the index texture $I$ (3 bytes per block) and two codebook textures ($256 \times 64$ and $256 \times 8$ floats/bytes) plus the address texture. The compression ratio depends on the codebook efficiency and thresholding effectiveness [S1, unofficial].
*   **Measured Performance:** The method was demonstrated on an ATI 9700 GPU, exploiting per-fragment arithmetic and dependent texture fetches [S1, unofficial].
*   **Strengths:** Hardware-friendly decoding via texture lookups; enhanced fidelity by assembling signal from separate frequency bands; efficient handling of homogeneous regions via thresholding [S1, unofficial].
*   **Limitations:** Lossy compression; requires pre-computed codebooks; block artifacts may be visible if codebooks are not well-trained; mean value precision limited to 8-bit [S1, unofficial].
*   **When to Use:** Real-time volume rendering on hardware with limited bandwidth but strong texture fetch capabilities; scenarios where homogeneous regions are common [S1, unofficial].
*   **When Not to Use:** When lossless compression is required; when high-frequency detail preservation is critical without artifacting; when hardware does not support dependent texture fetches [S1, unofficial].

## Background
Triadic frequency band decomposition, also known as hierarchical quantization scheme, was introduced in the context of compression domain volume rendering. It exploits the OpenGL API and ATI hardware (specifically the ATI 9700) to perform arithmetic operations and dependent texture fetches on a per-fragment basis [S1, unofficial]. The method was designed to enable real-time rendering of large volumetric datasets by compressing the data into a format that can be efficiently decoded on the GPU [S1, unofficial].
