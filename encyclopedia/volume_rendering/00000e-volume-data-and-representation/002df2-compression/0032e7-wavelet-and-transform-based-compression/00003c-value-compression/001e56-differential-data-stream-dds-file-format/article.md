# Differential Data Stream (DDS) File Format

Also called: Differential Data Stream, Differential Data Stream (DDS) Compression

## Overview
The Differential Data Stream (DDS) format is a lossless compression method for volume data that encodes differential values using run-length encoding and adaptive bit allocation per run [S1, unofficial]. It handles multi-channel volume data by interleaving channels and processing them in blocks, selecting between two file versions based on data size [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Raw volume data array `data` of size `bytes` (in bytes), channel count `skip` (1-4), and spatial stride `strip` [S1, unofficial].
- Output: Compressed byte stream `chunk` of size `size` [S1, unofficial].

**Data Structures:**
- **Header:** Magic ID (`DDS_ID` for version 1, `DDS_ID2` for version 2) [S1, unofficial]. 2 bits for `skip - 1` and 16 bits for `strip - 1` [S1, unofficial].
- **Chunk:** The compressed bitstream generated by the encoder [S1, unofficial].

**Constants:**
- `DDS_BLOCKSIZE`: Cache allocation size (1 MiB) [S1, unofficial].
- `DDS_INTERLEAVE`: Threshold for version selection; if `bytes > DDS_INTERLEAVE`, version 2 is used, otherwise version 1 [S1, unofficial].
- `DDS_RL`: Maximum run length encoded in 7 bits (127) [S1, unofficial].

**Algorithm Steps:**

1. **Version Selection:** If `bytes > DDS_INTERLEAVE`, set `version = 2`, else `version = 1` [S1, unofficial].
2. **Header Writing (Encoding):** Write `DDS_ID` if `version == 1`, else write `DDS_ID2` [S1, unofficial]. Write `skip - 1` (2 bits) and `strip - 1` (16 bits) [S1, unofficial].
3. **Data Preparation (Interleaving):** If `version == 2`, deinterleave the input byte stream based on channel `skip` and block size using `DDS_deinterleave` [S1, unofficial]. The exact deinterleaving algorithm is not provided in the sources [G]. If `version == 1`, process data in its original format [S1, unofficial].
4. **Differential Encoding & Bit Allocation:** Initialize a lookup table `lookup` mapping differential values in `[-128, 127]` to required bit counts [S1, unofficial]. Iterate through the data bytes, compute the differential value `act1`, clamp it to `[-128, 127]`, and map it to a bit count `bits1` via the lookup table [S1, unofficial].
5. **Run-Length Encoding of Bit Counts:** Track runs of identical bit counts, maintaining a current run `(cnt1, bits1)` and an accumulated previous run `(cnt2, bits2)` [S1, unofficial]. Merge runs if `cnt1 + cnt2 < (1 << DDS_RL)` and `(cnt1 + cnt2) * max(bits1, bits2) < cnt1 * bits1 + cnt2 * bits2 + DDS_RL + 3` [S1, unofficial]. When a run ends, write the run length, bit count, and differential values [S1, unofficial].
6. **Bitstream Packing:** Pack bits into 32-bit words using `DDS_writebits`, handling buffer overflow and endianness [S1, unofficial].
7. **Finalization:** Flush remaining bits, re-interleave the stream if `version == 2`, and write `chunk` of size `size` to file [S1, unofficial].

**Pseudocode (Encoding):**

```python
def DDS_encode(data, bytes, skip, strip, version):
    # 1. Initialize lookup table for [-128, 127]
    lookup = [0] * 256
    for i in range(-128, 128):
        bits = 0
        if i <= 0:
            while (1 << bits) >> 1 < -i:
                bits += 1
        else:
            while (1 << bits) >> 1 <= i:
                bits += 1
        lookup[i + 128] = bits

    # 2. Prepare bitstream buffer
    buffer = 0
    bufsize = 0
    output = []

    # 3. Deinterleave if version 2
    if version == 2:
        data = DDS_deinterleave(data, skip, DDS_BLOCKSIZE) # Not given in sources [G]

    # 4. Run tracking and differential encoding
    cnt1, bits1 = 0, 0
    cnt2, bits2 = 0, 0
    pre1 = 0

    for ptr1 in range(bytes):
        tmp1 = data[ptr1]
        if strip == 1:
            act1 = tmp1 - pre1
        else:
            act1 = tmp1 - pre1 - data[ptr1 - strip] + data[ptr1 - strip - 1]

        # Clamp to [-128, 127] to avoid out-of-bounds access
        act1 = max(-128, min(127, act1))
        bits1 = lookup[act1 + 128]
        cnt1 += 1

        # Merge runs if conditions met
        if cnt1 + cnt2 < (1 << DDS_RL) and (cnt1 + cnt2) * max(bits1, bits2) < cnt1 * bits1 + cnt2 * bits2 + DDS_RL + 3:
            cnt2 += cnt1
            bits2 = bits1
            cnt1 = 0
            bits1 = 0
            continue

        # Flush accumulated run
        if cnt2 > 0:
            write_run(cnt2, bits2, pre1, data, ptr1 - cnt2, strip, buffer, bufsize, output)
            cnt2, bits2 = 0, 0

    # Flush remaining runs
    if cnt2 > 0:
        write_run(cnt2, bits2, pre1, data, ptr1 - cnt2 + 1, strip, buffer, bufsize, output)
    elif cnt1 > 0:
        write_run(cnt1, bits1, pre1, data, ptr1 - cnt1 + 1, strip, buffer, bufsize, output)

    # Flush final buffer
    if bufsize > 0:
        output.append(buffer & 0xFFFFFFFF)

    # 5. Re-interleave if version 2
    if version == 2:
        output = DDS_interleave(output, skip, DDS_BLOCKSIZE) # Not given in sources [G]

    return output

def write_run(cnt, bits, pre1, data, start_ptr, strip, buffer, bufsize, output):
    # Write run length (7 bits)
    buffer, bufsize = DDS_writebits(cnt, DDS_RL, buffer, bufsize, output)
    # Write bit count (3 bits)
    buffer, bufsize = DDS_writebits(DDS_code(bits), 3, buffer, bufsize, output)
    # Write differential values
    for i in range(cnt):
        ptr = start_ptr + i
        tmp = data[ptr]
        if strip == 1:
            act = tmp - pre1
        else:
            act = tmp - pre1 - data[ptr - strip] + data[ptr - strip - 1]
        act = max(-128, min(127, act))
        buffer, bufsize = DDS_writebits(act + (1 << bits) >> 1, bits, buffer, bufsize, output)
        pre1 = tmp
    return buffer, bufsize

def DDS_writebits(value, bits, buffer, bufsize, output):
    value &= (1 << bits) - 1
    if bufsize + bits < 32:
        buffer = (buffer << bits) | value
        bufsize += bits
    else:
        output.append(buffer & 0xFFFFFFFF)
        remaining = bits - (32 - bufsize)
        buffer = value >> remaining
        bufsize = remaining
        if remaining > 0:
            output.append(buffer & 0xFFFFFFFF)
            buffer = value & ((1 << remaining) - 1)
            bufsize = remaining
    return buffer, bufsize

def DDS_code(b):
    return b & 0x7 # Maps 0-7 to 3-bit code [G]
```

**Decoding:**
1. Read header bytes. Compare against `DDS_ID`. If mismatch, compare against `DDS_ID2` to determine version [S1, unofficial].
2. Read `skip` and `strip` from header [S1, unofficial].
3. Read compressed chunk size and data [S1, unofficial].
4. If `version == 2`, deinterleave the input byte stream using `DDS_deinterleave` [S1, unofficial].
5. Initialize the same lookup table as encoding [S1, unofficial].
6. Iterate through the bitstream: read run length `cnt` (7 bits) and bit count `bits` (3 bits, decoded via `DDS_code`) [S1, unofficial]. For each value in the run, read `val` (`bits` bits) [S1, unofficial]. Recover differential: `act = val - (1 << bits) >> 1` [S1, unofficial]. Reconstruct original byte: `tmp1 = pre1 + act` (or using the `strip` formula if `strip > 1`) [S1, unofficial]. Update `pre1` and write to output [S1, unofficial].
7. If `version == 2`, re-interleave the output data [S1, unofficial].

**Parameters:**
- `skip`: Number of channels (1-4). Stored as 2 bits (`skip-1`) [S1, unofficial].
- `strip`: Spatial/temporal stride for differential calculation. Stored as 16 bits (`strip-1`) [S1, unofficial].
- `DDS_BLOCKSIZE`: Cache allocation size (1 MiB) [S1, unofficial].

**Edge Cases and Pitfalls:**
- Differential values must be clamped to `[-128, 127]` before lookup to avoid out-of-bounds access [S1, unofficial].
- Run length is limited to 127 (`DDS_RL`). Longer runs must be split [S1, unofficial].
- Endianness handling is required when flushing 32-bit words to cache [S1, unofficial].

## Subtopics

### DDS Bitstream Packing/Unpacking
A variable-length bitstream encoder/decoder that packs/unpacks bits into 32-bit words with automatic cache management and endianness handling [S1, unofficial]. It uses a buffer (`DDS_buffer`) and size counter (`DDS_bufsize`) to manage bit alignment [S1, unofficial]. When the buffer is full, it flushes the 32-bit word to the output cache, swapping bytes if the system is little-endian [S1, unofficial]. The cache allocation size is defined by `DDS_BLOCKSIZE` (1 MiB) [S1, unofficial]. This component is essential for the efficient storage of the variable-length bit counts and differential values generated by the main DDS algorithm [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources. The algorithm involves linear iteration through data with constant-time lookup and bit manipulation [S1, unofficial].
- **Memory Complexity:** Not given in the sources. Requires a 256-byte lookup table, a 32-bit buffer, and a cache of 1 MiB (`DDS_BLOCKSIZE`) [S1, unofficial].
- **Measured Performance:** Not given in the sources.
- **Strengths:** Lossless compression tailored for volume data with strong local correlations. Adaptive bit allocation reduces overhead for small differential values [S1, unofficial].
- **Limitations:** Limited to 8-bit differential precision (`[-128, 127]`). Run-length encoding is limited to 127, which may reduce efficiency for very long constant bit-count sequences [S1, unofficial].
- **When to use:** Suitable for lossless storage of multi-channel volume data where spatial correlation is high and data size exceeds `DDS_INTERLEAVE` (version 2) or is smaller (version 1) [S1, unofficial].
- **When not to use:** For data with large differential values exceeding 8-bit range, or when lossy compression is acceptable and higher compression ratios are needed from transform methods [S1, unofficial].

## Background
The Differential Data Stream (DDS) format is described in the context of volume rendering data compression, specifically within the `SRaimondi/VolumeRender` repository [S1, unofficial]. It is presented as a specialized codec for volume data, distinct from general image or video codecs [S1, unofficial]. The format supports two versions to handle different data sizes via the `DDS_INTERLEAVE` parameter [S1, unofficial].
