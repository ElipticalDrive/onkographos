# Q2 Finite Element Compression

Also called: Hierarchical Q2 Finite Element Compression, Hierarchical finite elements framework, Q2 wavelet-like compression

## Overview
Q2 Finite Element Compression is a multiresolution analysis scheme for multidimensional functions that uses a hierarchical basis of quadratic polynomials ($P_2$) to decompose a signal into coarse coefficients and detail coefficients [S1, unofficial]. It solves the problem of sparse storage for large datasets by discarding details below a threshold $\epsilon$, enabling efficient visualization without explicit quantization or encoding steps [S1, unofficial]. It differs from sibling methods like [Triadic frequency band decomposition](828-triadic-frequency-band-decomposition.md) and [Laplacian Pyramid](2250-laplacian-pyramid.md) by using a continuous piecewise quadratic basis rather than discrete frequency bands or Gaussian pyramids, allowing for linear complexity and strong theoretical foundations for tensor product transformations [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A function $f$ sampled on a uniform grid over interval $[a, b]$ with $N=2^n$ subintervals.
*   **Parameters:**
    *   $n$: Finest level of resolution [S1, unofficial].
    *   $l$: Coarsest level of resolution to keep ($0 \le l \le n-1$) [S1, unofficial].
    *   $\epsilon$: Compression threshold. Details with $|d| \le \epsilon$ are discarded [S1, unofficial].
*   **Output:** A compressed function representation $f_c$ containing only significant coarse coefficients $c$ and detail coefficients $d$.

**Data Structures**
The method relies on a hierarchical basis. The vector space $V_h$ has dimension $2N+1$. The basis functions $L_i(x)$ are defined such that $L_i(x_k) = \delta_{i,k}$ (Kronecker delta) [S1, unofficial].
*   **Coarse Basis:** $L_{2i}(x)$, $L_{2i+1}(x)$, $L_{2i+2}(x)$ associated with nodes $x_i, x_{i+1/2}, x_{i+1}$ at level $j$.
*   **Detail Basis:** $L_{2i+1/2}(x)$ is a "hat" function supported only on $[x_i, x_{i+1}]$, defined as:
    $$
    L_{2i+1/2}(x) = \begin{cases} 
    \text{non-zero} & \text{if } x \in [x_i, x_{i+1}] \\
    0 & \text{otherwise}
    \end{cases}
    $$
    Specifically, it is constructed to be zero at $x_i$ and $x_{i+1}$ and peak at $x_{i+1/2}$ [S1, unofficial].

**Algorithm Steps**
The compression builds the sparse representation $f_c$ starting from the finest level $n-1$ down to $l$. The compressed function $f_c$ is initially empty.

1.  Iterate $j$ from $n-1$ down to $l$ (inclusive).
2.  Iterate $i$ from $0$ to $2^j - 1$ (inclusive).
3.  Initialize `insert` = 0.
4.  For $k \in \{0, 1\}$:
    a. Compute the detail coefficient $d_{j, 2i+k}$ using the linear combination of function values at specific points within the interval $I^j_i = [x_i, x_{i+1}]$.
    b. If $|d_{j, 2i+k}| > \epsilon$:
        i. Add the sub-element $I^{j+1}_{2i+k}$ to $f_c$. This involves storing the three coefficients $c^{j+1}_{2(2i+k)+l}$ for $l=0,1,2$ [S1, unofficial].
        ii. Set `insert` = 1.
5.  If `insert` == 1:
    a. Add the parent element $I^j_i$ to $f_c$. This involves storing its three coefficients $c^j_{2i+l}$ for $l=0,1,2$ [S1, unofficial]. This ensures the tree structure is maintained; if a child is kept, the parent must be present to define the support [S1, unofficial].

**Formulas**
The approximation $\tilde{f}_h$ in the enriched vector space is:
$$
\tilde{f}_h(x) = \sum_{i=0}^{2N} c_i L_i(x) + \sum_{i=0}^{2^{N-1}} d_i L_{i+1/2}(x)
$$
where $c_i$ are coarse coefficients and $d_i$ are details [S1, unofficial].

The detail coefficients $d_{2i}$ and $d_{2i+1}$ are computed as:
$$
d_{2i} = \frac{1}{4}f(x_{i+1/4}) - \frac{1}{8}f(x_i) - \frac{1}{8}f(x_{i+1}) + \frac{1}{4}f(x_{i+1/2})
$$
$$
d_{2i+1} = \frac{1}{4}f(x_{i+3/4}) + \frac{1}{8}f(x_i) - \frac{1}{8}f(x_{i+1}) - \frac{1}{4}f(x_{i+1/2})
$$
where $x_{i+1/4}$ and $x_{i+3/4}$ are midpoints of the sub-intervals $[x_i, x_{i+1/2}]$ and $[x_{i+1/2}, x_{i+1}]$ respectively [S1, unofficial].

**Pseudocode**
```python
def q2_finite_element_compression(f_values, n, l, epsilon):
    """
    f_values: array of function values at finest level nodes.
    n: finest resolution level.
    l: coarsest resolution level to keep.
    epsilon: threshold for detail coefficients.
    Returns: list of (level, index, coefficients) tuples for f_c.
    """
    f_c = []
    
    # Iterate from finest level down to l
    for j in range(n - 1, l - 1, -1):
        # Number of intervals at level j is 2^j
        num_intervals = 1 << j  # 2^j
        
        for i in range(num_intervals):
            insert = False
            
            # Compute details for the two sub-intervals of I^j_i
            # Interval I^j_i spans from x_i to x_{i+1}
            # We need values at x_i, x_{i+1/2}, x_{i+1}, x_{i+1/4}, x_{i+3/4}
            # Assuming f_values is indexed by the finest grid points.
            # Mapping level j indices to finest level indices requires scaling.
            # Let h be the finest step. At level j, step is h * 2^(n-j).
            # x_i at level j corresponds to index i * 2^(n-j) in finest grid.
            
            step_j = 1 << (n - j)
            idx_i = i * step_j
            idx_i_half = idx_i + (step_j // 2)
            idx_i_1 = idx_i + step_j
            
            # Sub-interval 1: [x_i, x_{i+1/2}]
            # Midpoint is x_{i+1/4}
            idx_i_1_4 = idx_i + (step_j // 4)
            
            # Sub-interval 2: [x_{i+1/2}, x_{i+1}]
            # Midpoint is x_{i+3/4}
            idx_i_3_4 = idx_i + (3 * step_j // 4)
            
            # Get function values
            f_i = f_values[idx_i]
            f_i_half = f_values[idx_i_half]
            f_i_1 = f_values[idx_i_1]
            f_i_1_4 = f_values[idx_i_1_4]
            f_i_3_4 = f_values[idx_i_3_4]
            
            # Compute d_{j, 2i} (k=0)
            d_0 = 0.25 * f_i_1_4 - 0.125 * f_i - 0.125 * f_i_1 + 0.25 * f_i_half
            
            # Compute d_{j, 2i+1} (k=1)
            d_1 = 0.25 * f_i_3_4 + 0.125 * f_i - 0.125 * f_i_1 - 0.25 * f_i_half
            
            # Check thresholds
            if abs(d_0) > epsilon:
                insert = True
            if abs(d_1) > epsilon:
                insert = True
                
            if insert:
                # Add parent element I^j_i coefficients
                # The parent element has 3 coefficients. 
                # In the hierarchical basis, these correspond to the coarse representation.
                # We store the index and the coefficients.
                # Note: The source says "inserting its three coefficients c^j_{2i+l} for l=0,1,2".
                # These coefficients are derived from the function values at the nodes of I^j_i.
                # c^j_{2i} corresponds to L_{2i}(x_i) -> value f_i
                # c^j_{2i+1} corresponds to L_{2i+1}(x_{i+1/2}) -> value f_i_half
                # c^j_{2i+2} corresponds to L_{2i+2}(x_{i+1}) -> value f_i_1
                # However, in the hierarchical scheme, the coarse coefficients are usually 
                # the values at the nodes if the basis is interpolating.
                # The source states: "It consists in inserting the three coefficients...".
                # We assume these are the nodal values for the interpolating basis.
                
                parent_coeffs = [f_i, f_i_half, f_i_1]
                f_c.append(('coarse', j, i, parent_coeffs))
                
                # If a detail is kept, we also need to store the detail coefficients 
                # and potentially the sub-element structure. 
                # The source says: "Add I^{j+1}_{2i+k} to f_c".
                # This implies storing the detail coefficients d_0 and d_1 if they exceed epsilon.
                # The sub-element I^{j+1}_{2i+k} is associated with the detail basis function.
                
                if abs(d_0) > epsilon:
                    f_c.append(('detail', j, 2*i, d_0))
                if abs(d_1) > epsilon:
                    f_c.append(('detail', j, 2*i+1, d_1))
                    
    return f_c
```

**Edge Cases and Pitfalls**
*   **Boundary Conditions:** The algorithm assumes a uniform grid over $[a, b]$. Boundary points must be handled correctly in the finest level [S1, unofficial].
*   **Threshold Selection:** If $\epsilon$ is too high, significant features may be lost. If $\epsilon$ is too low, compression ratio approaches 1 (no compression) [S1, unofficial].
*   **Tree Structure:** The parent element must be inserted if any child detail is kept. Failure to do so breaks the hierarchical reconstruction [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Linear complexity $O(N)$ due to the locality of the basis functions and the single pass from finest to coarsest level [S1, unofficial].
*   **Memory Complexity:** Proportional to the number of non-zero coefficients (details $> \epsilon$ and their parents). Sparse storage [S1, unofficial].
*   **Strengths:** No quantization or encoding steps required; efficient parallelization due to locality; strong theoretical foundation for tensor product transformations in 4D [S1, unofficial].
*   **Limitations:** Requires uniform grid; compression ratio is 1 if finest resolution must be kept for good approximation [S1, unofficial].
