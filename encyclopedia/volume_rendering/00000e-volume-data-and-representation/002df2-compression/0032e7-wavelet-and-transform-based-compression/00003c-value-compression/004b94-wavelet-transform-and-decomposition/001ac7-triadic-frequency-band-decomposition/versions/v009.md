# Triadic frequency band decomposition

Also called: Hierarchical Data Decomposition, Hierarchical quantization scheme

## Overview
Triadic frequency band decomposition is a lossy compression method for volumetric scalar fields that partitions the data into $4^3$ blocks and decomposes each block into a multiresolution representation of three frequency bands: high-frequency differences, mid-frequency differences, and the block mean [S1, unofficial]. It differs from its siblings by using a fixed, hardware-friendly block size and a specific hierarchical downsampling scheme that maps directly to dependent texture fetches for on-chip decoding, whereas [Laplacian Pyramid](2250-laplacian-pyramid.md) uses Gaussian pyramids and [Wavelet Kernel Selection](7035-wavelet-kernel-selection.md) focuses on optimizing basis functions for general wavelet transforms [G].

## How it works
**Inputs:** A 3D scalar volume $V$ of dimensions $N_x \times N_y \times N_z$ [S1, unofficial].
**Outputs:** An RGB index texture $I$, two codebook textures $C_1$ and $C_2$, and an address texture $A$ [S1, unofficial].

**Data Structures:**
1.  **Index Texture $I$:** A 3D texture of size $(N_x/4) \times (N_y/4) \times (N_z/4)$ [S1, unofficial]. Each texel stores three 8-bit values:
    *   $R$: The mean value of the corresponding $4^3$ block [S1, unofficial].
    *   $G$: An index (0–255) into codebook $C_1$ (high-frequency band) [S1, unofficial].
    *   $B$: An index (0–255) into codebook $C_2$ (mid-frequency band) [S1, unofficial].
2.  **Codebook $C_1$:** A 2D texture of size $256 \times 64$ [S1, unofficial]. The $s$-coordinate is the index from $I.G$ [S1, unofficial]. The $t$-coordinate is a relative address from texture $A$ [S1, unofficial]. It stores 64-component codewords representing high-frequency differences [S1, unofficial].
3.  **Codebook $C_2$:** A 2D texture of size $256 \times 8$ [S1, unofficial]. The $s$-coordinate is the index from $I.B$ [S1, unofficial]. The $t$-coordinate is a relative address from texture $A$ [S1, unofficial]. It stores 8-component codewords representing mid-frequency differences [S1, unofficial].
4.  **Address Texture $A$:** A 2D texture of size $4^3$ (matching the encoded texel region size) [S1, unofficial]. It is mapped via nearest-neighbor interpolation [S1, unofficial].
    *   $R$-component: Stores 64 different addresses to index $C_1$ [S1, unofficial].
    *   $G$-component: Stores 8 different addresses to index $C_2$ [S1, unofficial].

**Algorithm Steps:**
1.  **Partitioning:** Divide the input volume $V$ into disjoint blocks of size $4^3$ voxels [S1, unofficial].
2.  **High-Frequency Band Extraction:** For each block, down-sample by a factor of 2 by averaging disjoint sets of $2^3$ voxels. This produces a $2^3$ voxel grid of mean values [S1, unofficial]. Calculate the difference between the original 64 voxels in the block and the corresponding down-sampled value (the mean of the $2^3$ voxels they belong to) [S1, unofficial]. Store these 64 difference values in a vector $D_{high}$ [S1, unofficial].
3.  **Mid-Frequency Band Extraction:** Take the $2^3$ mean values obtained in Step 2 [S1, unofficial]. Down-sample this $2^3$ grid by a factor of 2 by averaging all $2^3$ values to produce a single scalar value [S1, unofficial]. Calculate the difference between the original $2^3$ mean values and this single scalar value [S1, unofficial]. Store these 8 difference values in a vector $D_{mid}$ [S1, unofficial].
4.  **Mean Band Extraction:** The single scalar value from Step 3 is the mean of the entire $4^3$ block. Store this in a 1-component vector $M$ [S1, unofficial].
5.  **Thresholding:** Apply thresholding to $D_{high}$ and $D_{mid}$. If a difference vector is small or zero (indicating homogeneous or empty regions), map the entire vector to the zero vector. This maximizes the usage of codewords for significant non-zero vectors and simplifies quantization [S1, unofficial].
6.  **Vector Quantization:** Quantize $D_{high}$ using a codebook $C_1$ of length 256, resulting in an index $idx_1$ [S1, unofficial]. Quantize $D_{mid}$ using a codebook $C_2$ of length 256, resulting in an index $idx_2$ [S1, unofficial]. Quantize $M$ as an 8-bit value directly [S1, unofficial].
7.  **Storage:** Store $M$ in $I.R$, $idx_1$ in $I.G$, and $idx_2$ in $I.B$ for the corresponding block location [S1, unofficial].

**Pseudocode:**
```python
def triadic_decomposition(volume, codebook_C1, codebook_C2):
    """
    Decomposes a 3D volume into triadic frequency bands.
    volume: 3D list of shape (Nx, Ny, Nz)
    codebook_C1: 2D list of shape (256, 64)
    codebook_C2: 2D list of shape (256, 8)
    """
    Nx, Ny, Nz = len(volume), len(volume[0]), len(volume[0][0])
    index_texture_I = [[[None for _ in range(Nz // 4)] for _ in range(Ny // 4)] for _ in range(Nx // 4)]

    for x in range(0, Nx, 4):
        for y in range(0, Ny, 4):
            for z in range(0, Nz, 4):
                # 1. Extract 4x4x4 block
                block = [[[volume[x+dx][y+dy][z+dz] for dz in range(4)] for dy in range(4)] for dx in range(4)]
                block_flat = [block[dx][dy][dz] for dx in range(4) for dy in range(4) for dz in range(4)]

                # 2. High-frequency band: 64 components
                # Down-sample by averaging disjoint sets of 2^3=8 voxels
                means_2x2x2 = []
                for i in range(0, 64, 8):
                    group = block_flat[i:i+8]
                    means_2x2x2.append(sum(group) / 8.0)

                # High-freq differences: original - corresponding mean
                D_high = []
                for i in range(64):
                    group_idx = i // 8
                    D_high.append(block_flat[i] - means_2x2x2[group_idx])

                # Thresholding for D_high
                threshold_high = 0.0  # [G] Implementation-specific threshold
                if all(abs(v) < threshold_high for v in D_high):
                    D_high = [0.0] * 64

                # Quantize D_high
                idx_1 = quantize_vector(D_high, codebook_C1)

                # 3. Mid-frequency band: 8 components
                # Down-sample the 8 means to 1 value
                mean_block = sum(means_2x2x2) / 8.0

                # Mid-freq differences: means_2x2x2 - mean_block
                D_mid = [m - mean_block for m in means_2x2x2]

                # Thresholding for D_mid
                threshold_mid = 0.0  # [G] Implementation-specific threshold
                if all(abs(v) < threshold_mid for v in D_mid):
                    D_mid = [0.0] * 8

                # Quantize D_mid
                idx_2 = quantize_vector(D_mid, codebook_C2)

                # 4. Mean band
                M = mean_block

                # 5. Store in Index Texture
                # M is stored as 8-bit value. Scaling/offsetting for wider ranges is not given in the sources. [G]
                index_texture_I[x//4][y//4][z//4] = (
                    max(0, min(255, int(round(M)))),
                    idx_1,
                    idx_2
                )

    return index_texture_I

def quantize_vector(vector, codebook):
    """
    Finds the index of the codeword in the codebook that minimizes the Euclidean distance to the vector.
    codebook: list of shape (256, vector_length)
    """
    min_dist = float('inf')
    best_idx = 0
    for i in range(256):
        dist = sum((vector[j] - codebook[i][j]) ** 2 for j in range(len(vector))) ** 0.5
        if dist < min_dist:
            min_dist = dist
            best_idx = i
    return best_idx
```

**Parameters:**
*   Block size: $4^3$ voxels [S1, unofficial].
*   Down-sampling factor: 2, using disjoint sets of $2^3$ voxels for averaging [S1, unofficial].
*   Codebook length: 256 entries for both $C_1$ and $C_2$, allowing indices to be stored as one 8-bit value [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Homogeneous Regions:** Thresholding maps zero-difference vectors to the zero vector. This is critical for maximizing codeword efficiency [S1, unofficial].
*   **Precision:** Mean values are stored directly as 8-bit values. Not given in the sources whether scaling or offsetting is required for wider ranges [G].
*   **Boundary Conditions:** The volume dimensions $N_x, N_y, N_z$ must be divisible by 4. If not, padding or partial block handling is required (not specified in sources) [G].

## Subtopics

### Spectral decomposition and error band partitioning
This variant computes centered Fourier spectra and partitions frequency coordinates into low, mid, and high bands to measure spectral magnitude reconstruction errors [S2, unofficial]. It is used for error analysis rather than direct compression [S2, unofficial].
*   **Definition:** Computes the 2D discrete Fourier transform (DFT) of an image, centers the spectrum, and partitions frequency coordinates based on radial distance from the zero-frequency component [S2, unofficial].
*   **Steps:**
    1.  Compute the 2D DFT $\mathcal{F}(I)$ of the grayscale image $I$ [S2, unofficial].
    2.  Apply `fftshift` to center the zero-frequency component, yielding the centered complex spectrum $\hat{I}$ [S2, unofficial].
    3.  Extract the magnitude spectrum $A_I = |\hat{I}|$ [S2, unofficial].
    4.  For each frequency coordinate $(\xi, \eta)$, compute the Euclidean radial distance $D(\xi, \eta)$ from the centered zero-frequency location [S2, unofficial].
    5.  Partition coordinates into three bands [S2, unofficial]:
        *   Low: $D(\xi, \eta) \leq 30$
        *   Mid: $30 < D(\xi, \eta) \leq 80$
        *   High: $D(\xi, \eta) > 80$
*   **Formulas:**
    $$ \hat{I} = \text{fftshift}(\mathcal{F}(I)), \quad A_I = |\hat{I}| $$
    $$ \Omega_{\text{low}} = \{(\xi, \eta) : D(\xi, \eta) \leq 30\}, \quad \Omega_{\text{mid}} = \{(\xi, \eta) : 30 < D(\xi, \eta) \leq 80\}, \quad \Omega_{\text{high}} = \{(\xi, \eta) : D(\xi, \eta) > 80\} $$
*   **When to choose:** Use for evaluating reconstruction fidelity in frequency space [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Encoding is $O(N)$ where $N$ is the number of voxels, as each voxel is processed once in a block. Vector quantization is $O(N \cdot K)$ where $K=256$ is the codebook size, which can be optimized with search algorithms [G].
*   **Memory Complexity:** The compressed representation is $1/4$ the size of the original volume in terms of texels (since each $4^3$ block is represented by one texel in $I$), plus the size of the codebooks ($256 \times 64 + 256 \times 8$ floats/bytes) and the address texture ($4^3$) [S1, unofficial].
*   **Performance:** Designed for hardware acceleration using dependent texture fetches on GPUs (e.g., ATI 9700) [S1, unofficial]. Decoding is efficient as it involves simple texture lookups and additions [S1, unofficial].
*   **Strengths:** High compression ratio for homogeneous data due to thresholding; hardware-friendly decoding; multi-resolution access via the hierarchical structure [S1, unofficial].
*   **Limitations:** Fixed block size limits adaptability; vector quantization requires pre-computed codebooks; lossy compression introduces artifacts in non-homogeneous regions [S1, unofficial].
*   **When to use:** Real-time volume rendering on hardware with limited bandwidth and texture units; scenes with large homogeneous regions [S1, unofficial].
*   **When not to use:** Scenes with fine, high-frequency details throughout; lossless compression requirements [G].

## Background
Triadic frequency band decomposition was introduced in the context of compression domain volume rendering, specifically targeting hardware acceleration on early GPU architectures like the ATI 9700 [S1, unofficial]. It was developed to leverage the capabilities of dependent texture fetches and per-fragment arithmetic operations for efficient on-chip decoding [S1, unofficial]. The method is part of a broader family of wavelet and transform-based compression techniques for volumetric data [S1, unofficial].
