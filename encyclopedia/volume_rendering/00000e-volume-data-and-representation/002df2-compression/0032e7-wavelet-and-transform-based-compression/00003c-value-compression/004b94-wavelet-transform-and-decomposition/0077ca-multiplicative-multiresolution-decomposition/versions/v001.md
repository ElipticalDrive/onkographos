# Multiplicative Multiresolution Decomposition

Also called: 1D MMD, 2D MMD, MMD analysis, MMD synthesis

## Overview
Multiplicative Multiresolution Decomposition (MMD) is a nonlinear filter bank technique for volumetric image compression that exploits multiplicative relationships between pixel pairs to generate low and high frequency coefficients [S1]. It is designed to produce many zero coefficients in homogeneous regions, similar to wavelet transforms, but achieves this through a nonlinear ratio-based analysis rather than linear convolution [S1]. Unlike linear wavelet transforms which rely on additive differences, MMD uses a multiplicative structure to enhance sparsity in medical images, which often contain large uniform areas [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 1D signal segment (or 2D/3D volume slice) $x$.
*   **Output:** Low frequency coefficients $Y_1$ and high frequency coefficients $Y_2$ (or quantized $Y'_2$).

**Data Structures:**
The method operates on polyphase components. For an input signal $x$, the polyphase components $x_i[n]$ for $i \in \{1, 2\}$ are defined as:
$$x_i[n] = x[2(n-1)+i]$$
The filters are also defined in polyphase form. The linear analysis filter $h_i$ and synthesis filter $f_i$ are:
$$h_i[k] = h[2(k-1)+i]$$
$$f_i[k] = f[2(k-1)+i]$$
Perfect reconstruction requires $f_i[k] = h_i^{-1}[k]$ [S1].

**Parameters:**
*   $C1$: A positive scalar used to amplify pixels before calculating high frequency coefficients. Typical value: 50000 [S1].
*   $\beta$: A positive scalar used in the calculation of high frequency coefficients. Typical value: 1.0 [S1].
*   $C2$: A positive scalar used to scale the difference $(Y2 - \beta)$. Values vary by decomposition level and axis [S1].
*   $\alpha$: An offset value representing the smallest value of $((Y2 - \beta) \times C2)$ obtained when $Y2 > \beta$ and $x'_2 - x'_1 = 1$. This maximizes zero coefficients [S1].

**Steps:**

1.  **Polyphase Decomposition:** Split the input signal $x$ into two polyphase components $x_1$ and $x_2$ using $x_i[n] = x[2(n-1)+i]$ [S1].
2.  **Amplification:** Calculate modified inputs $x'_i$ by adding $C1$ to each component:
    $$x'_i = x_i + C1 \quad \forall i \in \{1,2\}$$
    This prevents division by zero and handles negative values if present [S1].
3.  **High Frequency Calculation (Nonlinear Analysis):** Compute the high frequency coefficients $Y2$ using the nonlinear analysis filter $D$:
    $$Y2 = \begin{cases} \beta \frac{x'_2}{x'_1}, & x'_1 \geq x'_2 \\ \beta \left( 2 - \frac{x'_1}{x'_2} \right), & x'_1 < x'_2 \end{cases}$$
    In homogeneous regions where $x'_1 \approx x'_2$, $Y2$ approaches $\beta$ [S1].
4.  **Quantization/Scaling of High Frequency Coefficients:** To maximize zero coefficients, subtract $\beta$ and scale by $C2$, then apply offset $\alpha$:
    $$Y'2 = \lfloor (Y2 - \beta) \times C2 - \alpha \rfloor$$
    Note: The source uses $Y2$ in the formula description but refers to the result as $Y'2$. The variable $Y2$ in the condition for $\alpha$ refers to the pre-quantization value [S1].
5.  **Low Frequency Calculation (Linear Analysis):** Compute the low frequency coefficients $Y_1$ using the linear analysis filter $h_i$ on the original (non-amplified) polyphase components $x_i$. The source states: "the low frequency coefficients are used in next step without coefficient $C1$" [S1]. This implies $Y_1$ is derived from $x_i$ directly, not $x'_i$, or that $C1$ is subtracted back. Given $x'_i = x_i + C1$, and $h_i$ is linear, if $h_i$ sums to 1 (common for low-pass), the constant $C1$ might persist. However, the text explicitly says "without coefficient C1" for the next step's input, implying $Y_1$ is calculated from $x_i$ [S1].
6.  **Recursive Decomposition:** For subsequent levels, treat the low frequency sub-band $Y_1$ as the new input signal. Split $Y_1$ into polyphase components and repeat steps 1-5. The value of $C2$ must increase for all MMD techniques after each 1D MMD filter application to maintain lossless compression, because low-pass MMD coefficients increase in magnitude after each filter application [S1].

**Edge Cases and Pitfalls:**
*   **Division by Zero:** The amplification $C1$ prevents $x'_i$ from being zero. $C1$ must be large enough to handle the minimum possible value in $x_i$ [S1].
*   **Coefficient Growth:** Low-pass MMD coefficients increase in magnitude after each 1D MMD filter application. To maintain lossless compression with a constant $C1$, the value of $C2$ must increase for all MMD techniques after each 1D MMD filter [S1].
*   **Homogeneous Regions:** The method is designed such that in homogeneous regions, $Y2$ becomes $\beta$, leading to $Y'2 = 0$ after quantization. This sparsity is key to compression [S1].

## Background
Multiplicative Multiresolution Decomposition (MMD) was proposed for lossless compression of volumetric medical images [S1]. It is based on the MMD technique originally used in speckle reduction [S1]. The method integrates MMD into a lossless compression scheme by applying MMD/wavelet or MMD transform to each slice, after an inter-slice filter employing wavelet transform and motion compensation is used [S1]. The resulting sub-bands are coded by the 3D zero-tree algorithm SPIHT [S1].
