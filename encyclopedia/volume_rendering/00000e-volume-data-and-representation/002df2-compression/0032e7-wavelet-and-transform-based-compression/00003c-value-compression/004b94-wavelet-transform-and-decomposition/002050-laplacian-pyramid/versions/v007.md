# Laplacian Pyramid

Also called: Burt and Adelson pyramid, 拉普拉斯金字塔

## Overview

The Laplacian Pyramid is a multiresolution decomposition technique that removes inter-pixel correlation to achieve compression by representing data as a low-resolution base plus a series of full-resolution difference signals (residuals) [S1, unofficial][S3]. It sets itself apart from orthogonal wavelet transforms by using a non-orthogonal, redundant representation where the prediction is derived via Gaussian low-pass filtering and upsampling, guaranteeing perfect reconstruction through simple addition [S1, unofficial].

## How it works

**Inputs and Outputs**
*   **Input:** A 3D volume data array $V_0$ of dimensions $N_x \times N_y \times N_z$.
*   **Output:** A set of Laplacian levels $L_0, L_1, \dots, L_{k-1}$ and a coarse base volume $G_k$ (the root).

**Data Structures**
The pyramid consists of $k+1$ levels.
*   **Base Level ($G_k$):** Dimensions $\lfloor N_x/2^k \rfloor \times \lfloor N_y/2^k \rfloor \times \lfloor N_z/2^k \rfloor$.
*   **Laplacian Levels ($L_i$ for $i=0 \dots k-1$):** Dimensions $N_x/2^i \times N_y/2^i \times N_z/2^i$.
*   **Storage:** Each level stores the raw voxel values (typically quantized integers or floats). The total storage is larger than the original volume due to oversampling (see Operating characteristics).

**Parameters**
*   **Filter Kernel:** A 3D Gaussian low-pass filter. In 2D, a $5 \times 5$ kernel is standard; in 3D, a $5 \times 5 \times 5$ kernel is used [S1, unofficial].
*   **Kernel Weights ($w$):** Real, symmetric coefficients ($w(m,n,p) = w(-m,-n,-p)$) normalized such that $\sum w = 1$ [S1, unofficial].
*   **Levels ($L$ or $k$):** Typically 5 or 6 levels for image data; determined by the desired compression ratio or minimum resolution [S1, S4, unofficial].
*   **Quantization:** Uniform quantization is commonly applied to the Laplacian levels for compression [S1, S4, unofficial].

**Algorithm: Decomposition**

The decomposition iteratively reduces resolution and extracts residuals.

1.  **Define Operators:**
    *   **REDUCE (Downsample):** Convolve with the low-pass kernel $w$ and subsample by 2.
        $$G_{i+1}(u,v,w) = \sum_{m=-2}^{2} \sum_{n=-2}^{2} \sum_{p=-2}^{2} w(m,n,p) \cdot G_i(2u+m, 2v+n, 2w+p)$$
    *   **EXPAND (Upsample):** Upsample by 2 (insert zeros) and convolve with the same kernel $w$.
        $$\bar{G}_i(u,v,w) = \sum_{m=-2}^{2} \sum_{n=-2}^{2} \sum_{p=-2}^{2} w(m,n,p) \cdot G_{i+1}(\frac{u-m}{2}, \frac{v-n}{2}, \frac{w-p}{2})$$
        *Note:* The indices $(u-m)/2$ etc. are valid only when even; odd indices in the expanded grid correspond to zero-inserted positions before convolution. Effectively, this reverses the decimation [S1, unofficial].

2.  **Iterate for $i = 0$ to $k-1$:**
    *   Compute the next lower resolution level:
        $$G_{i+1} = \text{REDUCE}(G_i)$$
    *   Compute the predicted high-resolution version from the lower level:
        $$\bar{G}_i = \text{EXPAND}(G_{i+1})$$
    *   Compute the Laplacian residual (difference):
        $$L_i = G_i - \bar{G}_i$$

3.  **Final Base:**
    *   The last level $G_k$ is the coarsest approximation (root).

**Algorithm: Reconstruction**

Reconstruction is the inverse process, adding the residuals back to the upsampled predictions.

1.  **Initialize:**
    $$R_k = G_k$$

2.  **Iterate for $i = k-1$ down to $0$:**
    *   Upsample the current reconstruction:
        $$\bar{R}_i = \text{EXPAND}(R_{i+1})$$
    *   Add the Laplacian residual:
        $$R_i = L_i + \bar{R}_i$$

3.  **Result:**
    *   $R_0$ is the reconstructed original volume $V_0$.

**Pseudocode**

```python
def laplacian_pyramid_decompose(volume, levels=5, kernel_1d=None):
    """
    Decomposes a 3D volume into a Laplacian pyramid.
    
    Args:
        volume: 3D numpy array (Nx, Ny, Nz)
        levels: Number of decomposition steps
        kernel_1d: 1D array of weights for the Gaussian filter. 
                   If None, uses a standard 5-tap Gaussian approximation.
    
    Returns:
        laplacian_levels: List of 3D arrays [L0, L1, ..., L_{k-1}]
        base: The coarsest volume G_k
    """
    if kernel_1d is None:
        # Standard 5-tap Gaussian-like weights for demonstration
        # Must sum to 1.0 and be symmetric
        kernel_1d = [0.05, 0.25, 0.4, 0.25, 0.05]
    
    # Precompute 3D kernel from 1D separable kernel
    # w_3d[m,n,p] = kernel_1d[m] * kernel_1d[n] * kernel_1d[p]
    # Since it is separable, we apply 1D filters along x, y, z sequentially.
    
    current_vol = volume.copy()
    laplacian_levels = []
    
    for i in range(levels):
        # 1. REDUCE: Convolve and Downsample
        # Convolve with 5x5x5 kernel
        blurred = convolve_3d_separable(current_vol, kernel_1d)
        # Downsample by 2 (take every other element)
        next_vol = blurred[::2, ::2, ::2]
        
        # 2. EXPAND: Upsample and Convolve
        # Upsample by inserting zeros
        expanded = upsample_3d(next_vol)
        # Convolve with same kernel to smooth the interpolated values
        predicted = convolve_3d_separable(expanded, kernel_1d)
        
        # 3. Compute Laplacian Level (Residual)
        # Ensure dimensions match (predicted is same size as current_vol)
        residual = current_vol - predicted
        laplacian_levels.append(residual)
        
        current_vol = next_vol
        
    return laplacian_levels, current_vol

def laplacian_pyramid_reconstruct(laplacian_levels, base):
    """
    Reconstructs the volume from the Laplacian pyramid.
    
    Args:
        laplacian_levels: List of 3D arrays [L0, L1, ..., L_{k-1}]
        base: The coarsest volume G_k
    
    Returns:
        reconstructed_volume: 3D numpy array
    """
    current_recon = base
    
    # Iterate backwards from the last Laplacian level to the first
    for i in range(len(laplacian_levels) - 1, -1, -1):
        # EXPAND the current reconstruction
        expanded = upsample_3d(current_recon)
        predicted = convolve_3d_separable(expanded, [0.05, 0.25, 0.4, 0.25, 0.05]) # Same kernel as decompose
        
        # Add the Laplacian residual
        current_recon = laplacian_levels[i] + predicted
        
    return current_recon
```

**Edge Cases and Pitfalls**
*   **Oversampling:** The method produces a redundant representation. The sum of the sizes of all Laplacian levels plus the base is larger than the original volume size [S1, unofficial].
*   **Boundary Conditions:** The convolution and upsampling operations require handling volume boundaries. Standard implementations use zero-padding or symmetric extension, which can introduce artifacts at the edges if not handled consistently during reconstruction [S1, unofficial].
*   **Precision:** Floating-point errors during the subtract/add cycle can prevent perfect reconstruction in fixed-point arithmetic. Uniform quantization of the residuals introduces small errors (e.g., RMSE of 1.3 for CT data) [S1, unofficial].

## Subtopics

### Triadic frequency band decomposition
A sibling method that decomposes data into frequency bands using triadic (base-3) scaling rather than dyadic (base-2) scaling. It is chosen when non-power-of-two resolutions are preferred or for specific spectral analysis needs. [Triadic frequency band decomposition](828-triadic-frequency-band-decomposition.md)

### Wavelet Kernel Selection
A sibling method that focuses on choosing the optimal wavelet basis function for a specific dataset to maximize compression or feature preservation. It is chosen when the fixed Gaussian kernel of the Laplacian pyramid is suboptimal for the data's specific frequency characteristics. [Wavelet Kernel Selection](7035-wavelet-kernel-selection.md)

## Operating characteristics

**Time and Memory Complexity**
*   **Memory:** The representation is redundant. For $k$ levels, the total memory is $\sum_{i=0}^{k-1} (2^i)^3 + (2^k)^3$ relative to the base unit. This is significantly larger than the original volume size [S1, unofficial].
*   **Time:** Decomposition and reconstruction are linear in the number of voxels per level. The use of separable 1D filters reduces the computational cost of the 3D convolution. The reconstruction process sees a constant speedup of roughly a factor of 8 when using separable operators compared to full 3D convolution [S1, unofficial].

**Measured Performance**
*   **Compression Ratio:** A compression ratio of approximately 10:1 can be achieved with uniform quantization for CT volume data [S1, S4, unofficial].
*   **Error:** With 10:1 compression using uniform quantization, a root mean square error (RMSE) of 1.3 was observed for test CT volume data [S1, unofficial].
*   **Quantization Error:** Uniform quantization introduces small errors, typically less than 1% in pixel value deviation [S1, unofficial].

**Strengths and Limitations**
*   **Strengths:**
    *   Guarantees perfect reconstruction (lossless) if no quantization is applied [S1, unofficial].
    *   Simple implementation using standard convolution and subsampling [S1, unofficial].
    *   Effective at removing inter-pixel correlation, concentrating values around zero, which reduces entropy and allows for efficient variable-length encoding [S1, unofficial].
    *   Supports progressive rendering (coarse-to-fine) [S1, unofficial].
*   **Limitations:**
    *   Oversampling leads to higher memory usage compared to orthogonal wavelet transforms [S1, unofficial].
    *   High computational cost for encoding/decoding if variable-length coding is used on the residuals [S1, unofficial].
    *   The fixed Gaussian kernel may not be optimal for all data types compared to learned bases [S4, unofficial].

**When to Use**
*   Use when progressive rendering (coarse-to-fine) is required.
*   Use when a simple, non-orthogonal multiresolution structure is sufficient and perfect reconstruction is needed before quantization.
*   Use when the data benefits from Gaussian smoothing as part of the decomposition.

**When Not to Use**
*   Use when memory bandwidth is the primary constraint and redundancy is unacceptable (consider orthogonal wavelets).
*   Use when the data has sharp discontinuities that Gaussian smoothing blurs significantly, causing large residuals.

## Background

The Laplacian Pyramid was introduced by Peter J. Burt and Edward H. Adelson in 1983 [S1, unofficial]. It is recognized in wavelet research as having a strong connection to multiresolution analysis and orthonormal bases of wavelets, though it predates the rapid development of wavelet transformations in the late 1980s [S1, unofficial]. It was originally developed for image encoding but has been extended to 3D volume data for compression and rendering [S1, S4, unofficial].
