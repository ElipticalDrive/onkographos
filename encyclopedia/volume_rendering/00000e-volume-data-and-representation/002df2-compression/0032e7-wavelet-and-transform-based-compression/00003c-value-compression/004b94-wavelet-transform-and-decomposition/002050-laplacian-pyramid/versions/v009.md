# Laplacian Pyramid
Also called: Burt and Adelson pyramid, 拉普拉斯金字塔

## Overview
The Laplacian Pyramid is a multiresolution decomposition technique that represents a volume by a coarse approximation and a set of detail residuals (deltas) between the original data and a prediction derived from the coarser level [S1, unofficial][S3]. It solves the problem of high inter-pixel correlation in volume data by decorrelating the signal, concentrating values around zero to reduce entropy and enable efficient compression [S1, unofficial]. Unlike orthogonal wavelet transforms or sibling methods such as [Triadic frequency band decomposition](828-triadic-frequency-band-decomposition.md), [Wavelet Kernel Selection](7035-wavelet-kernel-selection.md), and [Q2 Finite Element Compression](17905-q2-finite-element-compression.md), it is an oversampled representation where full-resolution detail bands are stored alongside the downsampled approximation, guaranteeing perfect reconstruction through simple addition [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D volume $V$ of dimensions $N_x \times N_y \times N_z$ [G].
*   **Output:** A Gaussian pyramid sequence $G = \{g_0, g_1, \dots, g_L\}$ and a Laplacian pyramid sequence $L = \{l_0, l_1, \dots, l_{L-1}\}$, where $g_0 = V$ [S1, unofficial]. The final approximation $g_L$ is stored as the root [S1, unofficial].

**Data Structures:**
*   **Gaussian Pyramid ($g_j$):** A sequence of volumes where $g_j$ has dimensions $\lfloor N_x/2^j \rfloor \times \lfloor N_y/2^j \rfloor \times \lfloor N_z/2^j \rfloor$ [G].
*   **Laplacian Pyramid ($l_j$):** A sequence of volumes where $l_j$ has the same dimensions as $g_j$ [S1, unofficial].
*   **Filter Kernel ($w$):** A separable 1D low-pass filter [S1, unofficial]. For 3D, the kernel is a product of three 1D filters [S1, unofficial].

**Parameters:**
*   **Filter Weights ($w$):** Real, symmetric coefficients normalized such that $\sum_n w(n) = 1$ [S1, unofficial]. The equal contribution constraint requires $\sum_n w(2n) = \sum_n w(2n+1)$ to ensure stability [S1, unofficial].
*   **Levels ($L$):** The number of decomposition steps. Typical values are $L=5$ or $6$ [S1, unofficial].

**Algorithm:**

1.  **REDUCE (Downsampling):**
    Compute the next level of the Gaussian pyramid by convolving the current level with the low-pass filter and decimating [S1, unofficial].
    For a 1D signal $c^{j-1}$, the next level $c^j$ is:
    $$ c^j_k = \sum_n w(n - 2k) c^{j-1}_n $$
    In 3D, this is applied separably along x, y, and z axes using a 5x5x5 filter [S1, unofficial].

2.  **EXPAND (Upsampling/Prediction):**
    Compute the predicted version of the current level from the coarser level [S1, unofficial].
    For a 1D signal $c^j$, the expanded version $\bar{c}^{j-1}$ is:
    $$ \bar{c}^{j-1}_n = \sum_k w(n - 2k) c^j_k $$
    This effectively reverses the decimation by inserting zeros and convolving with the same filter [S1, unofficial].

3.  **SUB (Detail Extraction):**
    Compute the Laplacian detail band by subtracting the prediction from the original [S1, unofficial].
    $$ l^{j-1} = c^{j-1} - \bar{c}^{j-1} $$
    Or in operator notation: $d^{j-1} = (I - F'F)c^{j-1}$ [S1, unofficial].

4.  **Decomposition Loop:**
    Repeat steps 1-3 for $j = 1$ to $L$ [S1, unofficial].
    *   $g_j = \text{REDUCE}(g_{j-1})$
    *   $\bar{g}_{j-1} = \text{EXPAND}(g_j)$
    *   $l_{j-1} = g_{j-1} - \bar{g}_{j-1}$
    Store $l_{j-1}$ and proceed to the next level [S1, unofficial]. The final $g_L$ is the root [S1, unofficial].

5.  **Reconstruction:**
    To reconstruct $g_0$ from $L$ and $g_L$:
    *   Set $r_L = g_L$ [S1, unofficial].
    *   For $i = L-1$ down to $0$:
        $$ r_i = l_i + \text{EXPAND}(r_{i+1}) $$
    *   The result $r_0$ is the reconstructed volume [S1, unofficial].

**Pseudocode:**

```python
def laplacian_decompose(volume, weights, levels):
    """
    Decomposes a 3D volume into a Laplacian Pyramid.
    
    Args:
        volume: 3D list of lists of lists (Nx, Ny, Nz)
        weights: 1D list of symmetric filter weights (e.g., length 5)
        levels: int, number of decomposition steps
        
    Returns:
        gaussian_pyramid: list of 3D arrays [g0, g1, ..., gL]
        laplacian_pyramid: list of 3D arrays [l0, l1, ..., l(L-1)]
    """
    gaussian_pyramid = [volume]
    laplacian_pyramid = []
    current = volume
    
    for j in range(levels):
        # 1. REDUCE: Separable convolution then downsample by 2
        blurred = separable_convolve(current, weights)
        downsampled = [[[blurred[i][j][k] for k in range(0, len(blurred[0][0]), 2)]
                        for j in range(len(blurred[0]))]
                       for i in range(len(blurred))]
        gaussian_pyramid.append(downsampled)
        
        # 2. EXPAND: Upsample then convolve to predict current
        expanded = upsample_and_convolve(downsampled, weights)
        
        # 3. SUB: Compute detail
        detail = [[[current[i][j][k] - expanded[i][j][k] 
                    for k in range(len(current[0][0]))]
                   for j in range(len(current[0]))]
                  for i in range(len(current))]
        laplacian_pyramid.append(detail)
        
        current = downsampled
        
    return gaussian_pyramid, laplacian_pyramid

def laplacian_reconstruct(gaussian_root, laplacian_pyramid, weights):
    """
    Reconstructs the volume from the Laplacian Pyramid.
    
    Args:
        gaussian_root: The coarsest level gL
        laplacian_pyramid: List [l0, l1, ..., l(L-1)]
        weights: 1D list of symmetric filter weights
        
    Returns:
        reconstructed_volume: 3D list of lists of lists
    """
    current = gaussian_root
    
    # Iterate from the last detail band (finest) down to the first
    for i in range(len(laplacian_pyramid) - 1, -1, -1):
        l_i = laplacian_pyramid[i]
        expanded = upsample_and_convolve(current, weights)
        current = [[[l_i[i][j][k] + expanded[i][j][k] 
                     for k in range(len(l_i[0][0]))]
                    for j in range(len(l_i[0]))]
                   for i in range(len(l_i))]
        
    return current

def convolve_1d(signal, weights):
    """1D convolution with zero-padding boundaries."""
    n = len(signal)
    w_len = len(weights)
    half = w_len // 2
    padded = [0] * half + list(signal) + [0] * half
    result = []
    for i in range(n):
        val = 0.0
        for k in range(w_len):
            val += weights[k] * padded[i + k]
        result.append(val)
    return result

def separable_convolve(volume, weights):
    """Applies a 1D filter separably along x, y, z axes."""
    # Convolve along X
    vol_x = [[[convolve_1d(volume[i][j][k], weights) for k in range(len(volume[0][0]))]
              for j in range(len(volume[0]))]
             for i in range(len(volume))]
    # Convolve along Y
    vol_y = [[[convolve_1d(vol_x[i][j][k], weights) for k in range(len(vol_x[0][0]))]
              for j in range(len(vol_x[0]))]
             for i in range(len(vol_x))]
    # Convolve along Z
    vol_z = [[[convolve_1d(vol_y[i][j][k], weights) for k in range(len(vol_y[0][0]))]
              for j in range(len(vol_y[0]))]
             for i in range(len(vol_y))]
    return vol_z

def upsample_and_convolve(volume, weights):
    """Upsamples by inserting zeros and convolves with the filter."""
    nx, ny, nz = len(volume), len(volume[0]), len(volume[0][0])
    new_shape = (nx * 2, ny * 2, nz * 2)
    expanded = [[[0.0 for _ in range(new_shape[2])] for _ in range(new_shape[1])] for _ in range(new_shape[0])]
    
    # Place original values at even indices
    for i in range(nx):
        for j in range(ny):
            for k in range(nz):
                expanded[i * 2][j * 2][k * 2] = volume[i][j][k]
                
    return separable_convolve(expanded, weights)
```

**Edge Cases and Pitfalls:**
*   **Oversampling:** The representation is redundant. The total number of coefficients is greater than the original volume size because the detail bands are full resolution [S1, unofficial].
*   **Boundary Conditions:** The choice of boundary handling (zero-padding, replication, symmetric) during convolution and upsampling affects the reconstruction accuracy at the volume edges [G].
*   **Precision:** Floating-point errors can accumulate during multiple levels of expansion and subtraction. Double precision is recommended for high-quality reconstruction [G].

## Operating characteristics
*   **Time Complexity:** Each level involves convolution and downsampling/upsampling [S1, unofficial]. Separable filtering provides a constant speedup in the reconstruction process by roughly a factor of 8 compared to non-separable 3D convolution [S1, unofficial].
*   **Memory Complexity:** The storage requirement is larger than the original volume due to oversampling, as full-resolution detail bands are stored alongside the downsampled approximation [S1, unofficial].
*   **Performance:** Achieves compression ratios of approximately 10:1 with uniform quantization for CT volume data, with a root mean square error (RMSE) of 1.3 [S1, unofficial][S4, unofficial].
*   **Strengths:** Perfect reconstruction is guaranteed by construction. It effectively decorrelates data, reducing entropy and making it suitable for entropy coding [S1, unofficial].
*   **Limitations:** Oversampling increases memory usage compared to orthogonal wavelets. The reconstruction speedup from separable filtering is roughly a factor of 8 compared to non-separable 3D convolution [S1, unofficial].

## Background
The Laplacian Pyramid was introduced by Burt and Adelson as an early multiresolution technique, predating the widespread adoption of wavelet transforms in the late 1980s [S1, unofficial]. It was recognized for its strong connection to multiresolution analysis and orthonormal wavelet bases [S1, unofficial]. It has been applied to volume data compression, particularly in medical imaging (CT volumes), where it serves as a basis for adaptive and progressive rendering [S1, unofficial][S4, unofficial].
