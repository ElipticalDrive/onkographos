# Laplacian Pyramid
Also called: Burt and Adelson pyramid, 拉普拉斯金字塔

## Overview
The Laplacian Pyramid is a multiresolution decomposition technique that removes inter-pixel correlation by predicting a signal from its low-resolution version and encoding the difference (residual) [S1, unofficial]. It solves the problem of high redundancy in volume data by concentrating values around zero, thereby reducing variance and entropy to allow for efficient compression [S1, unofficial]. Unlike orthogonal wavelet transforms, it uses a non-orthogonal, redundant representation where the original signal is perfectly reconstructed by adding the residuals to the upsampled coarse approximation [S1, unofficial].

## How it works
**Inputs:** A 3D volume data array $V_0$ of dimensions $N_x \times N_y \times N_z$.
**Outputs:** A set of Laplacian levels $L_0, L_1, \dots, L_{k-1}$ and a coarse root volume $G_k$.

**Data Structures:**
*   **Gaussian Pyramid Levels ($G_i$):** Low-pass filtered, downsampled volumes. $G_i$ has dimensions $\lfloor N_x/2^i \rfloor \times \lfloor N_y/2^i \rfloor \times \lfloor N_z/2^i \rfloor$.
*   **Laplacian Levels ($L_i$):** Residual volumes at the resolution of $G_i$. $L_i$ has the same dimensions as $G_i$.
*   **Root ($G_k$):** The smallest low-pass volume.

**Parameters:**
*   **Filter Kernel ($w$):** A separable Gaussian low-pass filter. In 3D, a $5 \times 5 \times 5$ kernel is used, decomposable into three 1D operators [S1, unofficial].
*   **Levels ($L$):** The number of decomposition steps. Typical values are $L=5$ or $6$ [S1, unofficial].
*   **Quantization:** Uniform quantization is applied to the Laplacian levels for compression [S1, unofficial].

**Algorithm:**

1.  **Decomposition (Build Pyramid):**
    For $i = 0$ to $k-1$:
    a.  **Reduce:** Compute the next Gaussian level $G_{i+1}$ from $G_i$ (where $G_0 = V_0$).
        *   Convolve $G_i$ with the 3D Gaussian kernel $w$.
        *   Downsample by taking every second voxel along each axis.
        *   Formula for 1D reduction (applied separably in x, y, z):
            $$G_{i+1}[u,v,w] = \sum_{n} w(n - 2m) G_i[m, \dots]$$
            where $w$ is symmetric and normalized ($\sum w(n) = 1$) [S1, unofficial].
    b.  **Expand:** Upsample $G_{i+1}$ to the resolution of $G_i$.
        *   Insert zeros between voxels.
        *   Convolve the upsampled volume with the same kernel $w$.
        *   Let $EXPAND(G_{i+1})$ denote this operation.
    c.  **Laplacian Level:** Compute the residual.
        $$L_i = G_i - EXPAND(G_{i+1})$$
    d.  If $i < k-1$, set $G_{i+1}$ as the input for the next iteration.

2.  **Root:**
    The final coarse volume $G_k$ is the root of the pyramid.

3.  **Reconstruction:**
    Given $L_0, \dots, L_{k-1}$ and $G_k$:
    a.  Set $R_k = G_k$.
    b.  For $i = k-1$ down to $0$:
        $$R_i = L_i + EXPAND(R_{i+1})$$
    c.  The original volume is $V_0 = R_0$.

**Pseudocode:**

```python
def laplacian_pyramid_decompose(volume, levels=5):
    """
    Decomposes a 3D volume into a Laplacian pyramid.
    volume: 3D numpy array (Nx, Ny, Nz)
    levels: integer, number of decomposition steps
    returns: list of Laplacian levels [L0, L1, ..., Lk-1], and root Gk
    """
    # Initialize Gaussian pyramid with the input volume
    gaussian_levels = [volume]
    current_vol = volume
    
    for i in range(levels):
        # 1. Reduce: Low-pass filter and downsample
        # Apply 1D Gaussian filter along X, Y, Z separately
        filtered = apply_1d_gaussian(current_vol, axis=0)
        filtered = apply_1d_gaussian(filtered, axis=1)
        filtered = apply_1d_gaussian(filtered, axis=2)
        
        # Downsample by taking every second element
        next_vol = filtered[::2, ::2, ::2]
        gaussian_levels.append(next_vol)
        current_vol = next_vol

    # 2. Compute Laplacian levels
    laplacian_levels = []
    # Iterate backwards from the finest level to the coarsest
    # We have levels+1 Gaussian volumes: G0...Gk
    # We need L0...Lk-1
    for i in range(levels):
        G_i = gaussian_levels[i]
        G_next = gaussian_levels[i+1]
        
        # Expand G_next to match G_i resolution
        expanded = expand_volume(G_next)
        
        # Compute residual
        L_i = G_i - expanded
        laplacian_levels.append(L_i)
        
    # The last Gaussian volume is the root
    root = gaussian_levels[-1]
    
    return laplacian_levels, root

def expand_volume(coarse_vol):
    """
    Upsamples a volume by inserting zeros and convolving with the Gaussian kernel.
    """
    # Determine target dimensions (double the coarse dimensions)
    target_shape = (coarse_vol.shape[0] * 2, 
                    coarse_vol.shape[1] * 2, 
                    coarse_vol.shape[2] * 2)
    
    # Create expanded volume with zeros
    expanded = np.zeros(target_shape, dtype=coarse_vol.dtype)
    
    # Place coarse voxels at even indices
    expanded[::2, ::2, ::2] = coarse_vol
    
    # Convolve with the same Gaussian kernel used in Reduce
    # Apply 1D Gaussian filter along X, Y, Z separately
    result = apply_1d_gaussian(expanded, axis=0)
    result = apply_1d_gaussian(result, axis=1)
    result = apply_1d_gaussian(result, axis=2)
    
    return result

def apply_1d_gaussian(volume, axis):
    """
    Applies a 1D Gaussian low-pass filter along a specific axis.
    Assumes a symmetric, normalized kernel w(n).
    """
    # Kernel definition (example 5-tap Gaussian approximation)
    # Note: Exact coefficients depend on implementation, but must be symmetric and sum to 1
    kernel = np.array([0.0625, 0.25, 0.375, 0.25, 0.0625]) 
    
    # Convolve along the specified axis
    # Using standard convolution, keeping size same
    result = np.apply_along_axis(lambda x: np.convolve(x, kernel, mode='same'), axis, volume)
    return result

def laplacian_pyramid_reconstruct(laplacian_levels, root):
    """
    Reconstructs the original volume from Laplacian pyramid levels.
    """
    # Start with the root
    current_vol = root
    
    # Iterate backwards from the coarsest Laplacian level to the finest
    for i in range(len(laplacian_levels) - 1, -1, -1):
        L_i = laplacian_levels[i]
        
        # Expand the current volume to match L_i resolution
        expanded = expand_volume(current_vol)
        
        # Add the residual
        current_vol = L_i + expanded
        
    return current_vol
```

**Edge Cases and Pitfalls:**
*   **Oversampling:** The scheme results in a redundant representation because the low-resolution version and the full-resolution difference signal are stored together [S1, unofficial].
*   **Boundary Conditions:** The convolution and downsampling operations require careful handling of volume boundaries to avoid artifacts. The sources assume standard convolution behavior [S1, unofficial].
*   **Precision:** Reconstruction is perfect in theory, but quantization of the Laplacian levels introduces errors. Uniform quantization was reported to yield a root mean square error (RMSE) of 1.3 for CT volume data [S1, unofficial].

## Operating characteristics
*   **Compression Ratio:** Achieves approximately 10:1 compression with uniform quantization on CT volume data [S1, S4, unofficial].
*   **Error:** Uniform quantization introduces small errors, typically less than 1% in pixel values, with an RMSE of 1.3 in tested experiments [S1, unofficial].
*   **Performance:** Using separable 1D operators for filtering provides a constant speedup in the reconstruction process by roughly a factor of 8 compared to non-separable 3D filtering [S1, unofficial].
*   **Strengths:** Removes inter-pixel correlation, decorrelating data and concentrating values around zero, which reduces entropy and allows for significant bit-rate reduction [S1, unofficial].
*   **Limitations:** The redundant representation (oversampling) increases memory usage compared to orthogonal transforms. The computational cost of encoding and decoding is high due to multiple filtering and expansion steps [S1, unofficial].

## Background
The Laplacian Pyramid was introduced by Burt and Adelson [3] as an early multiresolution decomposition technique, predating the rapid development of wavelet transforms in the late 1980s [S1, unofficial]. It is recognized for its strong connection to multiresolution analysis and orthonormal wavelet bases [S1, unofficial]. In volume rendering, it is used for efficient coding, progressive rendering (coarse-to-fine), and adaptive rendering [S1, unofficial].
