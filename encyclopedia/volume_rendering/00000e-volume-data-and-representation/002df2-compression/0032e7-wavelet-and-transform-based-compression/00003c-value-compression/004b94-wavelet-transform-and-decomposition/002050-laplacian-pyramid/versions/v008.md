# Laplacian Pyramid
Also called: Burt and Adelson pyramid, 拉普拉斯金字塔

## Overview
The Laplacian Pyramid is a multiresolution decomposition technique that represents a volume by a coarse approximation and a set of detail residuals (deltas) between the original data and a prediction derived from the coarser level [S1, unofficial][S3]. It solves the problem of high inter-pixel correlation in volume data by decorrelating the signal, concentrating values around zero to reduce entropy and enable efficient compression [S1, unofficial]. Unlike orthogonal wavelet transforms, it is an oversampled representation where the full-resolution detail bands are stored alongside the downsampled approximation, guaranteeing perfect reconstruction through simple addition [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D volume $V$ of dimensions $N_x \times N_y \times N_z$.
*   **Output:** A Gaussian pyramid sequence $G = \{g_0, g_1, \dots, g_L\}$ and a Laplacian pyramid sequence $L = \{l_0, l_1, \dots, l_{L-1}\}$, where $g_0 = V$. The final approximation $g_L$ is typically stored as the root.

**Data Structures:**
*   **Gaussian Pyramid ($g_j$):** A sequence of volumes where $g_j$ has dimensions $\lfloor N_x/2^j \rfloor \times \lfloor N_y/2^j \rfloor \times \lfloor N_z/2^j \rfloor$.
*   **Laplacian Pyramid ($l_j$):** A sequence of volumes where $l_j$ has the same dimensions as $g_j$ (full resolution relative to level $j$).
*   **Filter Kernel ($w$):** A separable 1D low-pass filter. For 3D, the kernel is a product of three 1D filters. A common implementation uses a 5-tap Gaussian-like kernel [S1, unofficial].

**Parameters:**
*   **Filter Weights ($w$):** Real, symmetric coefficients normalized such that $\sum_n w(n) = 1$. The equal contribution constraint requires $\sum_n w(2n) = \sum_n w(2n+1)$ to ensure stability [S1, unofficial].
*   **Levels ($L$):** The number of decomposition steps. Typical values are $L=5$ or $6$ [S1, unofficial].

**Algorithm:**

1.  **REDUCE (Downsampling):**
    Compute the next level of the Gaussian pyramid by convolving the current level with the low-pass filter and decimating.
    For a 1D signal $c^{j-1}$, the next level $c^j$ is:
    $$ c^j_k = \sum_n w(n - 2k) c^{j-1}_n $$
    In 3D, this is applied separably along x, y, and z axes using a 5x5x5 filter [S1, unofficial].

2.  **EXPAND (Upsampling/Prediction):**
    Compute the predicted version of the current level from the coarser level.
    For a 1D signal $c^j$, the expanded version $\bar{c}^{j-1}$ is:
    $$ \bar{c}^{j-1}_n = \sum_k w(n - 2k) c^j_k $$
    This effectively reverses the decimation by inserting zeros and convolving with the same filter [S1, unofficial].

3.  **SUB (Detail Extraction):**
    Compute the Laplacian detail band by subtracting the prediction from the original.
    $$ l^{j-1} = c^{j-1} - \bar{c}^{j-1} $$
    Or in operator notation: $d^{j-1} = (I - F'F)c^{j-1}$ [S1, unofficial].

4.  **Decomposition Loop:**
    Repeat steps 1-3 for $j = 1$ to $L$.
    *   $g_j = \text{REDUCE}(g_{j-1})$
    *   $\bar{g}_{j-1} = \text{EXPAND}(g_j)$
    *   $l_{j-1} = g_{j-1} - \bar{g}_{j-1}$
    Store $l_{j-1}$ and proceed to the next level. The final $g_L$ is the root.

5.  **Reconstruction:**
    To reconstruct $g_0$ from $L$ and $g_L$:
    *   Set $r_L = g_L$.
    *   For $i = L-1$ down to $0$:
        $$ r_i = l_i + \text{EXPAND}(r_{i+1}) $$
    *   The result $r_0$ is the reconstructed volume [S1, unofficial].

**Pseudocode:**

```python
def laplacian_decompose(volume, filter_weights, levels):
    """
    Decomposes a 3D volume into a Laplacian Pyramid.
    
    Args:
        volume: 3D numpy array (Nx, Ny, Nz)
        filter_weights: 1D list/array of symmetric weights (e.g., length 5)
        levels: int, number of decomposition steps
        
    Returns:
        gaussian_pyramid: list of 3D arrays [g0, g1, ..., gL]
        laplacian_pyramid: list of 3D arrays [l0, l1, ..., l(L-1)]
    """
    gaussian_pyramid = [volume]
    laplacian_pyramid = []
    
    current_vol = volume
    
    for j in range(levels):
        # 1. REDUCE: Convolve with low-pass filter and downsample
        # Apply 1D filter along X, then Y, then Z (separable)
        blurred = separable_convolve(current_vol, filter_weights)
        downsampled = blurred[::2, ::2, ::2] # Decimate by 2 in each dimension
        
        gaussian_pyramid.append(downsampled)
        
        # 2. EXPAND: Upsample and convolve to predict current_vol
        # Insert zeros to expand dimensions
        expanded = upsample_and_convolve(downsampled, filter_weights)
        
        # 3. SUB: Compute detail
        detail = current_vol - expanded
        laplacian_pyramid.append(detail)
        
        current_vol = downsampled
        
    return gaussian_pyramid, laplacian_pyramid

def laplacian_reconstruct(gaussian_root, laplacian_pyramid, filter_weights):
    """
    Reconstructs the volume from the Laplacian Pyramid.
    
    Args:
        gaussian_root: The coarsest level gL
        laplacian_pyramid: List [l(L-1), ..., l0] (ordered from coarsest detail to finest)
        filter_weights: 1D list/array of symmetric weights
        
    Returns:
        reconstructed_volume: 3D numpy array
    """
    # Note: laplacian_pyramid is usually stored as [l0, l1, ...]. 
    # We iterate backwards from the finest detail to the coarsest.
    # Let's assume input is [l0, l1, ..., l(L-1)]
    
    current_vol = gaussian_root
    
    # Iterate from the last detail band (finest) down to the first
    for i in range(len(laplacian_pyramid) - 1, -1, -1):
        l_i = laplacian_pyramid[i]
        
        # Expand current_vol to match dimensions of l_i
        expanded = upsample_and_convolve(current_vol, filter_weights)
        
        # Add detail
        current_vol = l_i + expanded
        
    return current_vol

def separable_convolve(volume, weights):
    """Applies a 1D filter separably along x, y, z axes."""
    # Convolve along X
    vol_x = convolve_1d(volume, weights, axis=0)
    # Convolve along Y
    vol_y = convolve_1d(vol_x, weights, axis=1)
    # Convolve along Z
    vol_z = convolve_1d(vol_y, weights, axis=2)
    return vol_z

def convolve_1d(volume, weights, axis):
    """1D convolution with boundary handling (e.g., zero-padding or replication)."""
    # Implementation depends on boundary conditions. 
    # Standard Laplacian Pyramid often uses zero-padding or symmetric extension.
    # Here we assume a standard convolution.
    from scipy.signal import convolve
    # Note: For production, use optimized 1D convolution kernels.
    # This is a conceptual placeholder for the 1D operation.
    result = np.apply_along_axis(lambda x: np.convolve(x, weights, mode='same'), axis, volume)
    return result

def upsample_and_convolve(volume, weights):
    """Upsamples by inserting zeros and convolves with the filter."""
    # Create a new volume with doubled dimensions
    new_shape = (volume.shape[0] * 2, volume.shape[1] * 2, volume.shape[2] * 2)
    expanded = np.zeros(new_shape, dtype=volume.dtype)
    
    # Place original values at even indices
    expanded[::2, ::2, ::2] = volume
    
    # Convolve with the filter
    return separable_convolve(expanded, weights)
```

**Edge Cases and Pitfalls:**
*   **Oversampling:** The representation is redundant. The total number of coefficients is greater than the original volume size because the detail bands are full resolution [S1, unofficial].
*   **Boundary Conditions:** The choice of boundary handling (zero-padding, replication, symmetric) during convolution and upsampling affects the reconstruction accuracy at the volume edges [G].
*   **Precision:** Floating-point errors can accumulate during multiple levels of expansion and subtraction. Double precision is recommended for high-quality reconstruction [G].

## Operating characteristics
*   **Time Complexity:** Decomposition and reconstruction are $O(N \log N)$ for $N$ voxels, assuming $L$ levels. Each level involves convolution and downsampling/upsampling. Separable filtering reduces the cost from $O(N \cdot K^3)$ to $O(N \cdot 3K)$ per level, where $K$ is the kernel size [S1, unofficial].
*   **Memory Complexity:** The storage requirement is larger than the original volume due to oversampling. The total size is $\sum_{j=0}^{L-1} N/2^j + N/2^L \approx 2N$ (for 2D; similar for 3D with slight variations in summation). Specifically, the detail bands sum to approximately the size of the original image, plus the small root [S1, unofficial].
*   **Performance:** Achieves compression ratios of approximately 10:1 with uniform quantization for CT volume data, with a root mean square error (RMSE) of 1.3 [S1, S4, unofficial].
*   **Strengths:** Perfect reconstruction is guaranteed by construction. It effectively decorrelates data, reducing entropy and making it suitable for entropy coding [S1, unofficial].
*   **Limitations:** Oversampling increases memory usage compared to orthogonal wavelets. The reconstruction speedup from separable filtering is roughly a factor of 8 compared to non-separable 3D convolution [S1, unofficial].

## Background
The Laplacian Pyramid was introduced by Burt and Adelson [3] as an early multiresolution technique, predating the widespread adoption of wavelet transforms in the late 1980s [S1, unofficial]. It was recognized for its strong connection to multiresolution analysis and orthonormal wavelet bases [S1, unofficial]. It has been applied to volume data compression, particularly in medical imaging (CT volumes), where it serves as a basis for adaptive and progressive rendering [S1, S4, unofficial].
