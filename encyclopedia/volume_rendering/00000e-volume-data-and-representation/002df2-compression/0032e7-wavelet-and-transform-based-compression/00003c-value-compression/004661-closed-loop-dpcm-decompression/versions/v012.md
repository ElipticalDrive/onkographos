# Closed-Loop DPCM Decompression

Also called: TraceBlockCodec.decompress

## Overview
Closed-Loop DPCM Decompression reconstructs volumetric trace data from compressed payloads using differential pulse-code modulation with a feedback loop to prevent error accumulation [S1, unofficial]. It distinguishes itself from open-loop variants by using the decoder's own reconstructed values as predictors for subsequent samples, ensuring bit-exact reconstruction in lossless contexts and stable error bounds in lossy contexts [S1, unofficial]. It is the primary decompression method for modern `.sdc` file formats, falling back to legacy decoding for backward compatibility [S1, unofficial].

## How it works
**Inputs:** A `CompressedTraceBlock` object containing a payload, metadata (trace ID, sample count, min/max values), and bit-depth information.
**Outputs:** A `TraceBlock` object containing the reconstructed floating-point samples.

**Data Structures:**
*   `CompressedTraceBlock`:
    *   `payload`: Binary data (compressed residuals/quantized values).
    *   `traceId`: Identifier for the trace.
    *   `min()`, `max()`: Scaling bounds for denormalization.
    *   `samplesPerTrace()`: Integer $n$, the number of samples in the trace.
*   `ClosedLoopQuantizer`: Helper object providing methods to inspect and unpack quantized data.
*   `Preprocessing`: Helper object for normalization/denormalization.

**Steps:**
1.  **Format Check:** Determine if the payload uses the closed-loop format.
    *   Call `isClosedLoop(cb.payload())`.
    *   If `false`, invoke `decompressLegacy(cb)` and return the result [S1, unofficial].
2.  **Initialization:**
    *   Get $n = cb.samplesPerTrace()$.
    *   Get `bits` = `ClosedLoopQuantizer.storedBits(cb.payload())`.
    *   Compute the inverse quantization scale factor: $inv = \frac{1.0}{ClosedLoopQuantizer.maxQ(bits)}$.
    *   Initialize the previous reconstructed value $prev = 0.0$.
3.  **Unpacking and Reconstruction Loop:**
    *   Unpack the quantized residuals $q$ from the payload: $q = ClosedLoopQuantizer.unpack(cb.payload(), n)$.
    *   For each index $i$ from $0$ to $n-1$:
        *   Reconstruct the current normalized value using the closed-loop predictor:
            $$prev = ClosedLoopQuantizer.reconstruct(prev, q[i], inv)$$
        *   Store the result: $norm[i] = prev$.
    *   *Note:* The `reconstruct` function internally handles the addition of the residual to the previous reconstructed value and scaling by $inv$ [S1, unofficial].
4.  **Denormalization:**
    *   Map the normalized values $norm$ from the range $[-1, 1]$ to the original data range $[min, max]$.
    *   $samples = Preprocessing.denormalizeFromMinusOneToOne(norm, cb.min(), cb.max())$.
5.  **Return:** Construct and return a new `TraceBlock` with the original `traceId` and the computed `samples`.

**Pseudocode:**
```python
def decompress_closed_loop(cb):
    # Step 1: Check format
    if not ClosedLoopQuantizer.isClosedLoop(cb.payload):
        return decompress_legacy(cb)

    # Step 2: Initialization
    n = cb.samplesPerTrace()
    bits = ClosedLoopQuantizer.storedBits(cb.payload)
    inv = 1.0 / ClosedLoopQuantizer.maxQ(bits)
    prev = 0.0
    norm = [0.0] * n

    # Step 3: Unpack and Reconstruct
    q = ClosedLoopQuantizer.unpack(cb.payload, n)
    
    for i in range(n):
        # Closed-loop reconstruction: 
        # The decoder uses its own 'prev' (reconstructed) value, not the original,
        # to predict the next sample.
        prev = ClosedLoopQuantizer.reconstruct(prev, q[i], inv)
        norm[i] = prev

    # Step 4: Denormalize
    samples = Preprocessing.denormalizeFromMinusOneToOne(norm, cb.min(), cb.max())

    # Step 5: Return
    return TraceBlock(traceId=cb.traceId, samples=samples)
```

**Parameters:**
*   `bits`: The number of bits used to store the quantized values. Typical values depend on the compression profile (e.g., 8, 12, 16 bits) [S1, unofficial].
*   `inv`: Derived from `bits`. $inv = 1 / 2^{bits}$ (assuming uniform quantization centered at 0) [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Legacy Compatibility:** If the payload was generated by the legacy encoder (pre-closed-loop revision), this method must not be used. It will fail or produce incorrect results. The `isClosedLoop` check is mandatory [S1, unofficial].
*   **Precision:** The use of floating-point `prev` accumulation can introduce minor rounding errors in lossy modes, but ensures consistency between encoder and decoder states [S1, unofficial].

## Subtopics

### Legacy Decompression
Decompresses payloads written before the closed-loop revision, supporting `.sdc` v2 files [S1, unofficial]. It uses raw zlib inflation, 16-bit quantization, and open-loop delta decoding [S1, unofficial].
**Steps:**
1.  Inflate `cb.payload()` using `inflate(cb.payload())`.
2.  Convert raw bytes to shorts: `shorts = bytesToShorts(rawBytes, cb.samplesPerTrace())`.
3.  Decode deltas: `deltas = LinearQuantizer.decode(shorts)`.
4.  Delta-decode: `norm = Preprocessing.deltaDecode(deltas)`.
5.  Denormalize: `samples = Preprocessing.denormalizeFromMinusOneToOne(norm, cb.min(), cb.max())`.
**Pitfall:** Files compressed with fewer than 16 bits by the legacy version cannot be decoded correctly because the bit depth was never stored in the file header [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of samples $n$, $O(n)$, due to the single pass unpacking and reconstruction loop [S1, unofficial].
*   **Memory Complexity:** $O(n)$ to store the normalized and reconstructed sample arrays [S1, unofficial].
*   **Strengths:** Bit-exact reconstruction in lossless scenarios; stable error propagation in lossy scenarios due to the closed-loop structure [S1, unofficial].
*   **Limitations:** Requires the `ClosedLoopQuantizer` helper logic; incompatible with legacy `.sdc` v2 files without a fallback path [S1, unofficial].
*   **When to use:** When decompressing modern `.sdc` files where bit-exactness or stable lossy reconstruction is required [S1, unofficial].
*   **When not to use:** When processing legacy `.sdc` v2 files (use Legacy Decompression) [S1, unofficial].

## Background
This method is part of the SeismicDataCompressor project, an unofficial implementation for compressing seismic data traces [S1, unofficial]. It was introduced to replace the open-loop delta coding used in earlier versions, addressing error accumulation issues in lossy compression scenarios [S1, unofficial]. The closed-loop approach ensures that the decoder's state matches the encoder's state at every step, which is critical for iterative processing or when exact reproducibility is needed [S1, unofficial].
