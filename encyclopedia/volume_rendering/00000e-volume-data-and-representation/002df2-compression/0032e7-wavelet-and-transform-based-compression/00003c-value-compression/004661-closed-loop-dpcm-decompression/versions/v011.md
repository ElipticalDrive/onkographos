# Closed-Loop DPCM Decompression

Also called: TraceBlockCodec.decompress

## Overview
Closed-Loop DPCM Decompression reconstructs trace data from compressed payloads by reversing a predictive coding scheme that uses previously decoded values for prediction [S1, unofficial]. It distinguishes itself from open-loop variants by inspecting payload metadata to route execution to a closed-loop reconstruction path or a legacy fallback decoder [S1, unofficial].

## How it works
**Inputs:** A `CompressedTraceBlock` object containing a payload, metadata (trace ID, sample count, min/max values), and bit-depth information [S1, unofficial].
**Outputs:** A `TraceBlock` object containing the reconstructed floating-point samples [S1, unofficial].

**Data Structures:**
*   `CompressedTraceBlock`:
    *   `payload`: Binary data containing the compressed residuals and quantization parameters [S1, unofficial].
    *   `traceId`: Identifier for the trace [S1, unofficial].
    *   `samplesPerTrace` ($n$): Number of samples in the trace [S1, unofficial].
    *   `min()`, `max()`: Original data range for denormalization [S1, unofficial].
*   `TraceBlock`:
    *   `traceId`: Identifier for the trace [S1, unofficial].
    *   `samples`: List of reconstructed floating-point values [S1, unofficial].

**Steps:**

1.  **Format Verification:** Check if the payload conforms to the closed-loop format using `ClosedLoopQuantizer.isClosedLoop(cb.payload())` [S1, unofficial]. If the check fails, the method delegates to the legacy decompression routine and returns [S1, unofficial].
2.  **Parameter Extraction:** Retrieve the number of samples $n = \text{cb.samplesPerTrace()}$, retrieve the stored bit depth $\text{bits} = \text{ClosedLoopQuantizer.storedBits}(\text{cb.payload()})$, and compute the inverse quantization scale factor $inv = \frac{1.0}{\text{ClosedLoopQuantizer.maxQ}(\text{bits})}$ [S1, unofficial].
3.  **Closed-Loop Reconstruction:** Initialize the previous reconstructed value $prev = 0.0$ [S1, unofficial]. Unpack quantized values $q$ from the payload using `ClosedLoopQuantizer.unpack(cb.payload(), n)` [S1, unofficial]. For each sample index $i$ from $0$ to $n-1$: reconstruct $prev$ using $prev = \text{ClosedLoopQuantizer.reconstruct}(prev, q[i], inv)$, then store $norm[i] = prev$ [S1, unofficial].
4.  **Denormalization:** Map the normalized values $norm$ from the $[-1, 1]$ range back to the original data range $[min, max]$ using `Preprocessing.denormalizeFromMinusOneToOne(norm, cb.min(), cb.max())` [S1, unofficial].
5.  **Return:** Construct and return a new `TraceBlock` with the `traceId` and the denormalized samples [S1, unofficial].

**Pseudocode:**

```python
def decompress_closed_loop(cb):
    # Step 1: Format verification
    if not ClosedLoopQuantizer.isClosedLoop(cb.payload):
        return decompressLegacy(cb)

    # Step 2: Parameter extraction
    n = cb.samplesPerTrace()
    bits = ClosedLoopQuantizer.storedBits(cb.payload)
    inv = 1.0 / ClosedLoopQuantizer.maxQ(bits)

    # Step 3: Closed-loop reconstruction
    prev = 0.0
    norm = [0.0] * n
    q = ClosedLoopQuantizer.unpack(cb.payload, n)

    for i in range(n):
        prev = ClosedLoopQuantizer.reconstruct(prev, q[i], inv)
        norm[i] = prev

    # Step 4: Denormalization
    norm = Preprocessing.denormalizeFromMinusOneToOne(norm, cb.min(), cb.max())

    # Step 5: Return
    return TraceBlock(traceId=cb.traceId, samples=norm)

# Helper definitions to ensure self-contained pseudocode
def decompressLegacy(cb):
    # Calls legacy decompression routine for open-loop payloads
    return TraceBlock(traceId=cb.traceId, samples=[])

class ClosedLoopQuantizer:
    @staticmethod
    def isClosedLoop(payload):
        return payload.metadata.closed_loop_flag
    @staticmethod
    def storedBits(payload):
        return payload.metadata.bits
    @staticmethod
    def maxQ(bits):
        return 2**bits - 1
    @staticmethod
    def unpack(payload, n):
        return payload.data[:n]
    @staticmethod
    def reconstruct(prev, q_val, inv):
        return prev + q_val * inv

class Preprocessing:
    @staticmethod
    def denormalizeFromMinusOneToOne(norm, min_val, max_val):
        return [(v + 1.0) * (max_val - min_val) / 2.0 + min_val for v in norm]

class TraceBlock:
    def __init__(self, traceId, samples):
        self.traceId = traceId
        self.samples = samples
```

**Edge Cases and Pitfalls:**
*   **Legacy Compatibility:** If the payload was not generated by the closed-loop encoder, `isClosedLoop` returns false [S1, unofficial]. The method must handle this gracefully by calling the legacy decoder [S1, unofficial].
*   **Initialization:** The initial `prev` value is set to $0.0$ [S1, unofficial]. This assumes the first sample's prediction is based on zero or that the first residual is encoded relative to zero [G].
*   **Precision:** The use of floating-point arithmetic for `prev` accumulation may introduce minor precision drift over very long traces, though the inverse quantization scale helps mitigate this [G].

## Subtopics

### Legacy Decompression
Decompresses payloads written before the closed-loop revision, supporting raw zlib streams, open-loop delta coding, and 16-bit quantization [S1, unofficial]. It is retained for backward compatibility with `.sdc` v2 files [S1, unofficial]. The process involves inflating the payload, converting bytes to shorts, decoding deltas using `LinearQuantizer.decode`, applying delta decoding via `Preprocessing.deltaDecode`, and finally denormalizing [S1, unofficial]. A critical pitfall is that files compressed with fewer than 16 bits by the legacy version cannot be decoded correctly because the bit depth was never stored in the file header [S1, unofficial].

## Operating characteristics
**Time Complexity:** $O(n)$, as each sample is processed sequentially with constant-time arithmetic operations [G].
**Memory Complexity:** $O(n)$ to store the output samples and intermediate normalized values [G].
**Strengths:** Prevents error accumulation inherent in open-loop prediction by using reconstructed values for subsequent predictions [G].
**Limitations:** Requires the bit depth to be stored in the payload for correct reconstruction [S1, unofficial]. Legacy files with fewer than 16 bits lack stored bit depth and cannot be decoded correctly [S1, unofficial].
**When to use:** When decompressing payloads that contain closed-loop metadata [S1, unofficial].
**When not to use:** When processing legacy payloads without closed-loop metadata; use Legacy Decompression instead [S1, unofficial].
