# Closed-Loop DPCM Decompression

Also called: TraceBlockCodec.decompress

## Overview
Closed-loop DPCM decompression reconstructs trace data from compressed payloads by using the decoder's own output as the prediction for subsequent samples [S1, unofficial]. It reads the bit depth explicitly from the payload and falls back to a legacy decoder if the payload is not marked as closed-loop [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A `CompressedTraceBlock` object containing a `payload` (byte array/bitstream), `samplesPerTrace` (integer $n$), `min` (float), `max` (float), and `traceId` [S1, unofficial].
- **Output:** A `TraceBlock` object containing the reconstructed `traceId` and an array of denormalized samples [S1, unofficial].

**Data Structures:**
- `CompressedTraceBlock`: Holds the compressed payload and trace metadata [S1, unofficial].
- `ClosedLoopQuantizer`: Helper providing `isClosedLoop`, `storedBits`, `unpack`, `reconstruct`, and `maxQ` [S1, unofficial].
- `Preprocessing`: Helper providing `denormalizeFromMinusOneToOne` [S1, unofficial].

**Steps:**
1. **Validation:** Check if the payload is marked as closed-loop using `ClosedLoopQuantizer.isClosedLoop(cb.payload())` [S1, unofficial]. If false, call `decompressLegacy(cb)` and return [S1, unofficial].
2. **Initialization:** Retrieve $n$ from `cb.samplesPerTrace()` [S1, unofficial]. Retrieve `bits` from `ClosedLoopQuantizer.storedBits(cb.payload())` [S1, unofficial]. Compute the inverse quantization scale factor $inv = 1.0 / \text{ClosedLoopQuantizer.maxQ}(bits)$ [S1, unofficial]. Initialize the previous reconstructed value $prev = 0.0$ [S1, unofficial].
3. **Decoding Loop:** For each sample index $i$ from $0$ to $n-1$: Unpack the quantized residual $q[i]$ from the payload using `ClosedLoopQuantizer.unpack(cb.payload(), n)` [S1, unofficial]. Reconstruct the current normalized value using the closed-loop prediction: $prev = \text{ClosedLoopQuantizer.reconstruct}(prev, q[i], inv)$ [S1, unofficial]. Store the result in the normalized array: $norm[i] = prev$ [S1, unofficial].
4. **Denormalization:** Convert the normalized values $norm$ back to the original data scale using the trace's minimum and maximum values: $value[i] = \text{Preprocessing.denormalizeFromMinusOneToOne}(norm[i], cb.min(), cb.max())$ [S1, unofficial].
5. **Return:** Construct and return a new `TraceBlock` containing the `traceId` and the denormalized samples [S1, unofficial].

**Pseudocode:**
```python
def decompress_closed_loop(cb):
    # Step 1: Validation
    if not ClosedLoopQuantizer.isClosedLoop(cb.payload):
        return decompress_legacy(cb)

    # Step 2: Initialization
    n = cb.samples_per_trace
    bits = ClosedLoopQuantizer.storedBits(cb.payload)
    inv = 1.0 / ClosedLoopQuantizer.maxQ(bits)
    prev = 0.0
    norm = [0.0] * n

    # Step 3: Decoding Loop
    q = ClosedLoopQuantizer.unpack(cb.payload, n)
    for i in range(n):
        prev = prev + q[i] * inv  # Standard closed-loop DPCM accumulation [G]
        norm[i] = prev

    # Step 4: Denormalization
    # Maps normalized values from [-1, 1] to [min, max] [G]
    samples = [v * (cb.max - cb.min) + cb.min for v in norm]

    # Step 5: Return
    return TraceBlock(trace_id=cb.trace_id, samples=samples)

def decompress_legacy(cb):
    # Legacy fallback implementation [S1, unofficial]
    raw = inflate(cb.payload)
    shorts = bytes_to_shorts(raw, cb.samples_per_trace)
    deltas = LinearQuantizer.decode(shorts)
    deltas_norm = Preprocessing.deltaDecode(deltas)
    samples = [v * (cb.max - cb.min) + cb.min for v in deltas_norm]
    return TraceBlock(trace_id=cb.trace_id, samples=samples)

class TraceBlock:
    def __init__(self, trace_id, samples):
        self.trace_id = trace_id
        self.samples = samples
```

**Parameters:**
- `bits`: The number of bits used to store the quantized residuals, retrieved from the payload [S1, unofficial].
- `inv`: The inverse quantization scale factor, computed as $inv = 1.0 / \text{maxQ}(bits)$ [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Legacy Payloads:** If the payload is not marked as closed-loop, the method must not attempt closed-loop decoding and must call the legacy decoder instead [S1, unofficial].
- **Bit Depth Ambiguity:** Legacy files written with fewer than 16 bits cannot be decoded correctly because the bit depth was never stored [S1, unofficial]. Closed-loop mode avoids this pitfall by explicitly storing `bits` in the payload [S1, unofficial].

## Subtopics

### Legacy Decompression
Decompresses payloads written before the closed-loop revision, supporting raw zlib streams, open-loop delta encoding, and 16-bit quantization [S1, unofficial]. It is kept for backward compatibility with `.sdc` v2 files [S1, unofficial]. The process involves inflating the payload, converting bytes to shorts, decoding deltas using `LinearQuantizer.decode`, delta-decoding the normalized values, and denormalizing [S1, unofficial]. A critical pitfall is that legacy files with fewer than 16 bits cannot be decoded correctly because the bit depth was never stored [S1, unofficial].
