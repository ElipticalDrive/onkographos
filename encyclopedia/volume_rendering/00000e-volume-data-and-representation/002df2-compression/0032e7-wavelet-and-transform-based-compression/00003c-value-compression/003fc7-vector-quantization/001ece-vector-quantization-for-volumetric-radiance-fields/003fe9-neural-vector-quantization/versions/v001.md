# Neural Vector Quantization

Also called: Neural VQ, VQ with Neural Decoders

## Overview
Neural Vector Quantization (NVQ) is a compression technique for 3D Gaussian Splatting that reduces storage costs by partitioning Gaussian attribute vectors into sub-vectors, clustering them via K-Means, and quantizing each cluster using separate codebooks [S1, unofficial]. It further minimizes storage by replacing high-dimensional Spherical Harmonic (SH) coefficients with lightweight neural decoders that reconstruct diffuse and view-dependent components from quantized latent codes [S1, unofficial]. Unlike traditional vector quantization that uses a single codebook for the entire attribute vector, NVQ employs a sub-vector decomposition strategy to enhance representation flexibility and mitigate codeword collisions [S1, unofficial].

## How it works
**Inputs:**
*   Trained 3D Gaussian primitives with attributes: position, scale, rotation, opacity, and Spherical Harmonic coefficients $Y$.
*   Hyperparameters: Number of clusters $K$, cluster length $L$, number of codewords per subspace $B$, and number of MLP groups (typically 5) [S1, unofficial].

**Outputs:**
*   Quantized attribute codes (indices into codebooks).
*   Huffman-encoded bitstream of the codes.
*   Quantized MLP weights for SH reconstruction.

**Data Structures:**
1.  **Codebooks:** $K$ separate codebooks $C_k \in \mathbb{R}^{B \times L}$, where $k \in \{1, \dots, K\}$. Each codebook $C_k$ contains $B$ codewords of dimension $L$ [S1, unofficial].
2.  **MLPs:** Lightweight Multi-Layer Perceptrons $\text{MLP}_d$ and $\text{MLP}_v$ for diffuse and view-dependent SH components. Each MLP has a single hidden layer with 64 neurons [S1, unofficial]. Weights are quantized to 16-bit precision [S1, unofficial].
3.  **Indices:** For each Gaussian, an index vector mapping its sub-vectors to the respective codebooks [S1, unofficial].

**Steps:**

1.  **Attribute Partitioning:**
    Decompose the Gaussian attribute vector $z \in \mathbb{R}^{KL}$ into $K$ clusters (sub-vectors) $\{z_1, z_2, \dots, z_K\}$, where each $z_k \in \mathbb{R}^L$. The sources specify that attributes are partitioned into five groups of sub-vectors [S1, unofficial].

2.  **Clustering:**
    For each cluster $k$, apply K-Means clustering to the set of all $z_k$ vectors across all Gaussians to initialize the codebook $C_k$ [S1, unofficial].

3.  **Quantization:**
    For each Gaussian, replace each sub-vector $z_k$ with the nearest codeword from its corresponding codebook $C_k$. Let $c_k \in C_k$ be the selected codeword. The quantized representation is the sequence of indices $\{i_1, i_2, \dots, i_K\}$ where $i_k$ is the index of $c_k$ in $C_k$ [S1, unofficial].

4.  **SH Decomposition and Neural Decoding:**
    Decompose the original SH feature $Y$ into a diffuse component $h_d \in \mathbb{R}^3$ and a view-dependent component $h_v \in \mathbb{R}^3$ via NVQ [S1, unofficial].
    Compute the final SH features for rendering using the MLPs:
    $$
    f_d = \text{MLP}_d(h_d, h_v)
    $$
    $$
    f_v = \text{MLP}_v(h_d, h_v)
    $$
    where $f_d$ and $f_v$ are the predicted diffuse and view-dependent SH components [S1, unofficial]. The MLPs are trained jointly with the 3D Gaussian primitives for 30k iterations [S1, unofficial].

5.  **Entropy Coding:**
    Apply Huffman coding to the sequence of quantized attribute indices to reduce storage redundancy [S1, unofficial].

6.  **Pruning (Optional/Associated):**
    Contribution-based pruning removes Gaussians with low opacity and scale to further decrease storage costs [S1, unofficial]. Distribution-based pruning is applied during the initial 25k iterations with interval $I_{prune}=1000$ and threshold $v=0.6$ [S1, unofficial].

## Subtopics

### Gaussian Parameter Compression via Codebooks and Adaptive Quantization
This variant focuses on compressing Gaussian properties by predicting the probability of each quantized attribute using Gaussian distributions and devising an adaptive quantization module [S2]. It uses sensitivity measures for effective quantization and fine-tuning, achieving storage reduction ratios of 10-20x [S2].

## Operating characteristics
*   **Storage Reduction:** Achieves significant storage reduction, often by factors of 10-20x [S2]. NVQ specifically minimizes overall storage costs by eliminating the need to store high-dimensional SH coefficients directly [S1, unofficial].
*   **Rendering Speed:** Enables real-time rendering on mobile devices due to lower storage usage and faster data access [S1, unofficial].
*   **Memory Footprint:** Multi-codebook quantization reduces the memory footprint of each codebook and simplifies lookup operations during inference [S1, unofficial].
*   **Limitations:** Deploying on edge devices with tight memory budgets remains challenging [S2]. The trade-off between compression efficiency and visual fidelity is an open problem [S2].

## Background
Neural Vector Quantization was introduced in the context of deploying 3D Gaussian Splatting on mobile devices to reduce storage usage and improve rendering speed [S1, unofficial]. It builds on vector quantization techniques and incorporates neural decoders to handle view-dependent effects efficiently [S1, unofficial]. The method was proposed in "Mobile-GS: Real-time Gaussian Splatting for Mobile Devices" [S1, unofficial].
