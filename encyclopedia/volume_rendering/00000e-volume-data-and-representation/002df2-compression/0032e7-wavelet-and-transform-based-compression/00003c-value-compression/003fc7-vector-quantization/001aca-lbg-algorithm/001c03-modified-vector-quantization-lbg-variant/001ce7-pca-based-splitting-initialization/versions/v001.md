# PCA-Based Splitting Initialization

Also called: Covariance Analysis Splitting, Principal Component Analysis Splitting

## Overview
PCA-Based Splitting Initialization is a method for generating the initial codebook for Vector Quantization (VQ) by using Principal Component Analysis to determine optimal splitting planes, thereby avoiding the empty cell problem and accelerating convergence compared to random initialization [S1, unofficial][S2]. It differs from standard LBG by replacing random seed placement with a distortion-driven, geometry-aware subdivision process that selects the split plane based on the variance of the data distribution within each cell [S1, unofficial][S2].

## How it works
The method constructs an initial codebook by iteratively splitting the most distorted cells using PCA-derived directions, followed by a brief LBG refinement phase to stabilize Voronoi regions [S1, unofficial][S2].

**Inputs and Outputs:**
*   **Input:** A set of input vectors $I = \{X_1, X_2, \dots, X_n\}$, where each $X_i \in \mathbb{R}^d$. A target codebook size $K$.
*   **Output:** An initial codebook $C = \{Y_1, Y_2, \dots, Y_K\}$, where each $Y_j$ is a centroid vector.

**Data Structures:**
*   **To-Do List:** A double-linked list storing tuples $(D_j, Y_j, I_j)$.
    *   $D_j$: Scalar residual distortion of cell $j$.
    *   $Y_j$: Current centroid (codebook entry) for cell $j$.
    *   $I_j$: Set of indices $\{i \in I : X_i \in V_j\}$, identifying which input vectors belong to the Voronoi region $V_j$ defined by $Y_j$.
*   The list is sorted in descending order by $D_j$.

**Step-by-Step Procedure:**

1.  **Initialization:**
    *   Create a single quantization cell $V_1$ containing the entire input set $I$.
    *   Compute the initial centroid $Y_1$ as the mean of $I$:
        $$ Y_1 = \frac{1}{|I|} \sum_{X \in I} X $$
    *   Compute the initial distortion $D_1$:
        $$ D_1 = \sum_{X \in V_1} \delta(X, Y_1) $$
        where $\delta(X, Y)$ is the distortion metric (typically squared Euclidean distance $\|X - Y\|^2$) [S1, unofficial].
    *   Insert the group $(D_1, Y_1, I_1 = \{i \in I : X_i \in V_1\}) into the To-Do List [S1, unofficial].

2.  **Iterative Splitting:**
    *   While the number of codebook entries is less than $K$:
        1.  **Select Cell:** Extract the element $j$ with the largest residual distortion $D_j$ from the To-Do List [S1, unofficial].
        2.  **PCA Split:** Perform Principal Component Analysis on the input vectors in $I_j$ to find the optimal splitting plane [S2].
            *   Compute the covariance matrix $\Sigma$ of the vectors in $I_j$.
            *   Compute the eigenvectors of $\Sigma$.
            *   Select the eigenvector corresponding to the largest eigenvalue as the splitting direction [S1, unofficial].
            *   Split the cell $V_j$ into two sub-cells $V_{j,a}$ and $V_{j,b}$ such that the residual distortions of the sub-cells are roughly equal [S2]. This is achieved by projecting the data onto the principal component and finding a split point that balances the variance or distortion [S1, unofficial][S2].
        3.  **Update Codebook:**
            *   Compute new centroids $Y_{j,a}$ and $Y_{j,b}$ for the sub-cells.
            *   Remove $(D_j, Y_j, I_j)$ from the To-Do List.
            *   Compute new distortions $D_{j,a}$ and $D_{j,b}$ for the sub-cells.
            *   Insert $(D_{j,a}, Y_{j,a}, I_{j,a})$ and $(D_{j,b}, Y_{j,b}, I_{j,b})$ into the To-Do List.
            *   Re-sort the To-Do List in descending order by distortion [S1, unofficial].
        4.  **Post-Refinement (Optional but recommended):** Apply a few steps of the standard LBG algorithm (nearest neighbor search and centroid update) to the newly created cells to relax the centroids and generate stable Voronoi regions [S2].

**Parameters:**
*   **Target Codebook Size ($K$):** Determines when the splitting stops. Not given in the sources.
*   **Distortion Metric ($\delta$):** Typically squared Euclidean distance. Not given in the sources.
*   **Post-Refinement Steps:** Number of LBG iterations applied after splitting. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Degenerate Input:** If all input vectors in a cell are identical, the covariance matrix is zero, and PCA fails to define a unique splitting direction. [G] In this case, the cell should not be split, or a random split direction should be used.
*   **Precision:** Computing eigenvectors requires numerical stability. [G] Use standard SVD or eigenvalue decomposition routines with appropriate tolerance.
*   **Empty Cells:** The PCA-based splitting ensures that sub-cells are formed based on data distribution, reducing the risk of empty cells compared to random splitting [S1, unofficial].

**Pseudocode:**

```python
import numpy as np

def pca_splitting_initialization(input_vectors, target_codebook_size):
    """
    Generates an initial codebook using PCA-based splitting.
    
    Args:
        input_vectors: np.array of shape (n, d)
        target_codebook_size: int, K
        
    Returns:
        codebook: np.array of shape (K, d)
    """
    n, d = input_vectors.shape
    
    # To-Do List: list of tuples (distortion, centroid, indices)
    # Indices refer to positions in input_vectors
    todo_list = []
    
    # Step 1: Initialization
    centroid = np.mean(input_vectors, axis=0)
    # Distortion: sum of squared distances
    distortion = np.sum(np.sum((input_vectors - centroid)**2, axis=1))
    indices = np.arange(n)
    
    todo_list.append((distortion, centroid, indices))
    
    # Current codebook entries (initially just one)
    codebook_entries = [centroid]
    
    while len(codebook_entries) < target_codebook_size:
        # Step 2: Select cell with highest distortion
        # Sort todo_list by distortion descending
        todo_list.sort(key=lambda x: x[0], reverse=True)
        
        dist, centroid, indices = todo_list.pop(0)
        
        # Get the vectors in this cell
        cell_vectors = input_vectors[indices]
        
        # Step 3: PCA Split
        # Compute covariance matrix
        if len(cell_vectors) < 2:
            # Cannot split if fewer than 2 points
            # Re-insert with zero distortion or handle as leaf
            # For simplicity, skip splitting this cell if it cannot be split
            # In practice, this case should be rare if K < n
            continue
            
        cov_matrix = np.cov(cell_vectors, rowvar=False)
        
        # Compute eigenvectors
        eigenvalues, eigenvectors = np.linalg.eigh(cov_matrix)
        
        # Select the eigenvector corresponding to the largest eigenvalue
        # eigh returns eigenvalues in ascending order
        principal_component = eigenvectors[:, -1]
        
        # Project data onto principal component
        projections = cell_vectors @ principal_component
        
        # Find split point to balance distortions
        # A simple approach is to split at the median of projections
        # However, the source mentions "roughly equal residual distortions"
        # Using median is a common heuristic for equal-sized splits
        split_value = np.median(projections)
        
        # Split indices based on projection
        left_mask = projections <= split_value
        right_mask = ~left_mask
        
        left_indices = indices[left_mask]
        right_indices = indices[right_mask]
        
        # If split results in empty cell, handle appropriately
        if len(left_indices) == 0 or len(right_indices) == 0:
            # Fallback: random split or skip
            # For robustness, skip this split
            continue
            
        # Compute new centroids and distortions
        left_centroid = np.mean(input_vectors[left_indices], axis=0)
        left_distortion = np.sum(np.sum((input_vectors[left_indices] - left_centroid)**2, axis=1))
        
        right_centroid = np.mean(input_vectors[right_indices], axis=0)
        right_distortion = np.sum(np.sum((input_vectors[right_indices] - right_centroid)**2, axis=1))
        
        # Insert new groups into todo_list
        todo_list.append((left_distortion, left_centroid, left_indices))
        todo_list.append((right_distortion, right_centroid, right_indices))
        
        # Add new centroids to codebook entries
        codebook_entries.append(left_centroid)
        codebook_entries.append(right_centroid)
        
        # Step 4: Post-Refinement (Optional)
        # Apply a few LBG steps to the new centroids
        # This is a simplified version
        for _ in range(3): # 3 iterations
            # Assign each input vector to nearest centroid
            assignments = np.argmin(np.array([np.sum((input_vectors - c)**2, axis=1) for c in codebook_entries]), axis=0)
            # Update centroids
            for i in range(len(codebook_entries)):
                mask = assignments == i
                if np.any(mask):
                    codebook_entries[i] = np.mean(input_vectors[mask], axis=0)
    
    return np.array(codebook_entries)
```

## Subtopics

### Standard LBG Initialization
Random initialization of codebook entries. Simple but prone to empty cells and slow convergence. [S2]

### Hierarchical Clustering
Uses PCA for hierarchical clustering of point sets, similar to the splitting technique used here. [S1, unofficial]

### Residual Vector Quantization
A technique where VQ is applied to residuals to improve quality. Can be combined with PCA-based initialization. [S2]

## Operating characteristics
*   **Time Complexity:** The splitting process requires computing covariance matrices and eigenvectors for each cell. This is more expensive than random initialization but avoids the $O(n \cdot K)$ nearest neighbor searches of standard LBG during initialization. The sorting of the To-Do List adds a logarithmic factor. [S1, unofficial]
*   **Memory Complexity:** Requires storing the To-Do List and the input vectors. The To-Do List size is proportional to the number of codebook entries. [S1, unofficial]
*   **Performance:** Provides a significant speed-up compared to standard LBG initialization by avoiding explicit gain computation for every possible split. [S1, unofficial]
*   **Strengths:** Avoids empty cells, improves convergence speed, and produces a better initial codebook. [S1, unofficial][S2]
*   **Limitations:** More complex to implement than random initialization. Requires numerical stability for PCA. [S1, unofficial]
*   **When to Use:** When the initial codebook quality significantly impacts the final VQ performance, and computational resources allow for the overhead of PCA. [S1, unofficial][S2]
*   **When Not to Use:** For very large datasets where PCA computation becomes prohibitive, or when a quick, approximate codebook is sufficient. [S1, unofficial]

## Background
The method was described in the context of compression domain volume rendering, specifically for vector quantization of volume data. It builds on techniques used in hierarchical clustering of point sets and scanned BRDFs. [S1, unofficial][S2] The approach was proposed to solve the problem of slow convergence and empty cells in standard LBG initialization. [S1, unofficial]
