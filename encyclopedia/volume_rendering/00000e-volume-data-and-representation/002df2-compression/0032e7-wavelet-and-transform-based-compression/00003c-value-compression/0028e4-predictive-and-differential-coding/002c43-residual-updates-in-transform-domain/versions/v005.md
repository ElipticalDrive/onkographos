# Residual Updates in Transform Domain

Also called: Inter-frame DCT coding

## Overview
Residual Updates in Transform Domain is a temporal compression method for volumetric data that operates in the frequency domain rather than the spatial domain. It solves the problem of efficiently encoding changes in dynamic implicit surfaces (such as TSDF volumes) by exploiting temporal coherence. Unlike spatial predictors that estimate voxel values from neighbors, this method predicts the current frame's transform coefficients (e.g., DCT) using the previously reconstructed coefficients of the same block. This approach avoids the computational cost of explicit geometric correspondence tracking and concentrates residual energy near regions of surface change, improving compressibility for subsequent transform and entropy coding [S1].

## How it works
The method relies on a block-based representation of the volume (e.g., a voxel block grid). For each block $b$ at time step $t$, the encoder and decoder maintain a reference buffer of reconstructed transform coefficients.

**Inputs and Outputs:**
*   **Input:** Current frame's transform coefficients $\mathbf{c}_t^{(b)}$ for active blocks; reference buffer $\tilde{\mathbf{c}}_{t-1}^{(b)}$ from the previous frame.
*   **Output:** Entropy-coded residuals $\Delta \mathbf{c}_t^{(b)}$ and block activity flags.

**Data Structures:**
*   **Reference Buffer:** A map keyed by block coordinates $(x, y, z)$ storing the reconstructed coefficient vector $\tilde{\mathbf{c}}_{t-1}^{(b)} \in \mathbb{R}^K$, where $K$ is the number of retained coefficients.
*   **Coefficient Vector:** The retained $K$ coefficients of the 3D DCT representation of a block, ordered according to a fixed scanning pattern (e.g., zig-zag or frequency-based) [S1].

**Steps:**

1.  **Initialization:** The first frame is encoded as an intra-coded frame (no temporal prediction) to initialize the decoder's reference buffer. The decoder reconstructs the coefficients and stores them in $\tilde{\mathbf{c}}_{0}^{(b)}$ [S1].

2.  **Residual Formation:** For each subsequent frame $t$ and each block $b$:
    *   If block $b$ is **active** in the current frame, compute the residual:
        $$ \Delta \mathbf{c}_t^{(b)} = \mathbf{c}_t^{(b)} - \tilde{\mathbf{c}}_{t-1}^{(b)} $$
    *   If block $b$ is **inactive** (absent) in the current frame but existed in the reference, treat it as a removal event by setting the current coefficients $\mathbf{c}_t^{(b)} = \mathbf{0}$, resulting in a residual equal to the negative of the reference:
        $$ \Delta \mathbf{c}_t^{(b)} = \mathbf{0} - \tilde{\mathbf{c}}_{t-1}^{(b)} = -\tilde{\mathbf{c}}_{t-1}^{(b)} $$
    *   If block $b$ is newly activated (did not exist in the reference), the reference $\tilde{\mathbf{c}}_{t-1}^{(b)}$ is treated as $\mathbf{0}$, so the residual is simply the current coefficients:
        $$ \Delta \mathbf{c}_t^{(b)} = \mathbf{c}_t^{(b)} $$

3.  **Quantization:** Quantize the residual vector $\Delta \mathbf{c}_t^{(b)}$ using the same quantization steps (e.g., separate handling of DC and AC components) as used for intra coding [S1]. Let $Q(\cdot)$ denote the quantization function.

4.  **Entropy Coding:** Range-encode the resulting quantized integers using the same per-coefficient entropy coding strategy (e.g., adaptive probability models) as intra coding [S1].

5.  **Closed-Loop Update:** To prevent encoder-decoder drift, the encoder updates its reference buffer using the reconstructed residual. The decoder performs the same update after decoding. The update rule is:
    $$ \tilde{\mathbf{c}}_t^{(b)} = \tilde{\mathbf{c}}_{t-1}^{(b)} + Q^{-1}(Q(\Delta \mathbf{c}_t^{(b)})) $$
    where $Q^{-1}(\cdot)$ is the dequantization function [S1].

**Pseudocode:**

```python
def encode_temporal_block(current_coeffs, ref_coeffs, quantizer, entropy_encoder):
    """
    Encodes a single block's temporal residual.
    
    Args:
        current_coeffs: Vector of DCT coefficients for block b at time t.
                        If block is inactive, this is None or empty.
        ref_coeffs: Vector of reconstructed DCT coefficients for block b at time t-1.
                    If block was inactive in t-1, this is None or empty.
        quantizer: Function Q(x) that quantizes coefficients.
        entropy_encoder: Function to range-encode integers.
        
    Returns:
        encoded_bits: The bitstream for this block.
        updated_ref: The new reference coefficients for the next frame.
    """
    # Determine current coefficients vector c_t
    if current_coeffs is None:
        # Block is inactive in current frame
        c_t = [0] * len(ref_coeffs)
        is_active = False
    else:
        c_t = current_coeffs
        is_active = True

    # Determine reference coefficients vector c_tilde_{t-1}
    if ref_coeffs is None:
        # Block was inactive in previous frame
        c_tilde_prev = [0] * len(c_t)
    else:
        c_tilde_prev = ref_coeffs

    # Calculate residual delta_c
    delta_c = [c_t[i] - c_tilde_prev[i] for i in range(len(c_t))]

    # Quantize residual
    quantized_delta = quantizer(delta_c)

    # Entropy encode the quantized residual
    encoded_bits = entropy_encoder(quantized_delta)

    # Closed-loop update: reconstruct the residual and add to reference
    dequantized_delta = quantizer.inverse(quantized_delta)
    updated_ref = [c_tilde_prev[i] + dequantized_delta[i] for i in range(len(c_t))]

    return encoded_bits, updated_ref

def decode_temporal_block(encoded_bits, ref_coeffs, quantizer, entropy_decoder):
    """
    Decodes a single block's temporal residual.
    
    Args:
        encoded_bits: The bitstream for this block.
        ref_coeffs: Vector of reconstructed DCT coefficients for block b at time t-1.
        quantizer: Function Q(x) and inverse Q^-1(x).
        entropy_decoder: Function to range-decode integers.
        
    Returns:
        decoded_coeffs: The reconstructed DCT coefficients for block b at time t.
        updated_ref: The new reference coefficients for the next frame.
    """
    # Decode quantized residual
    quantized_delta = entropy_decoder(encoded_bits)

    # Dequantize residual
    dequantized_delta = quantizer.inverse(quantized_delta)

    # Closed-loop update: add dequantized residual to reference
    updated_ref = [ref_coeffs[i] + dequantized_delta[i] for i in range(len(ref_coeffs))]

    return updated_ref, updated_ref
```

**Parameters:**
*   **Block Size:** Not specified in the sources, but implied to be a fixed 3D block size suitable for 3D DCT [S1].
*   **Number of Retained Coefficients ($K$):** Determined by a fixed ordering/scanning pattern (e.g., retaining low-frequency coefficients) [S1].

**Edge Cases and Pitfalls:**
*   **Block Activation/Deactivation:** The method must explicitly handle blocks that appear or disappear. If a block is absent in the current frame, the residual is set to the negative of the reference, effectively "removing" the surface [S1].
*   **Drift:** Failure to use the closed-loop update (adding the *quantized* residual back to the reference) will cause encoder-decoder drift over time [S1].
*   **Probability Models:** Range coding requires shared probability models. Explicit tables (histograms) can be used but introduce side information overhead. Adaptive models are preferred for online settings [S1].

## Subtopics

### Zero-Motion Block Prediction
A specific application of residual updates in transform domain where the predictor is the previous reconstructed TSDF (Signed Distance Field) on the same voxel block grid. It reuses the previous frame's data as a "zero-motion predictor" and encodes only blockwise residual updates. This concentrates residual energy near regions of surface change, improving compressibility. It requires an initial intra-coded frame to initialize the decoder reference [S1].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of active blocks and coefficients. The main costs are the DCT transform (if not pre-computed), residual subtraction, quantization, and entropy coding. It is computationally efficient compared to methods requiring explicit geometric correspondence tracking [S1].
*   **Memory Complexity:** Requires storing the reference coefficient buffer for all blocks. The size is proportional to the number of blocks times the number of retained coefficients $K$.
*   **Strengths:** Simple implementation due to regular, indexable block structure. No need for explicit motion estimation or correspondence tracking. Effective for dynamic implicit surfaces with local changes [S1].
*   **Limitations:** Performance degrades if there is significant global motion or if the block structure does not align well with the surface changes. Requires an initial intra-coded frame [S1].
*   **When to Use:** Dynamic volumetric data (e.g., TSDF volumes) where changes are local and temporal coherence is high.
*   **When Not to Use:** Data with large global motions or where explicit geometry codecs are more suitable [S1].

## Background
The method was introduced in the paper "Implicit Surface Compression -- with Good Old Discrete Cosine Transform and Motion Compensation" [S1]. It builds on the idea of using DCT for implicit surface compression and extends it with motion compensation in the transform domain. The approach leverages the regular structure of voxel block grids to simplify temporal coding [S1].
