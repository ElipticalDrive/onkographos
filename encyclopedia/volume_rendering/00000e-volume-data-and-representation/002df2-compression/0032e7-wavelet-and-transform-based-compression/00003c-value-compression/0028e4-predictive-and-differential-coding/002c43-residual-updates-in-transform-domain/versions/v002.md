# Residual Updates in Transform Domain

Also called: Inter-frame DCT coding

## Overview
Residual Updates in Transform Domain is a temporal compression method for volumetric data that operates in the frequency domain rather than the spatial domain. It solves the problem of efficiently encoding changes in dynamic implicit surfaces (such as TSDF volumes) by exploiting temporal coherence. Unlike spatial predictors that estimate values from neighbors, this method subtracts the DCT coefficients of the previously reconstructed frame from the current frame's coefficients to form residuals [S1]. This approach concentrates residual energy near regions of surface change, improving compressibility for subsequent transform and range encoding [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Current frame's TSDF samples $\mathbf{s}_t^{(b)}$ for active blocks $b$; Reference buffer $\tilde{\mathbf{c}}_{t-1}^{(b)}$ containing reconstructed DCT coefficients from the previous frame $t-1$.
*   **Output:** Encoded bitstream of quantized transform-domain residuals; Updated reference buffer $\tilde{\mathbf{c}}_t^{(b)}$.

**Data Structures:**
*   **Reference Buffer:** A map keyed by block coordinates $b$. Each entry stores a vector $\tilde{\mathbf{c}}^{(b)}$ of size $K$, representing the retained $K$ coefficients of the 3D DCT representation under a fixed ordering [S1].
*   **Block Representation:** For a block $b$ at frame $t$, let $\mathbf{c}_t^{(b)} \in \mathbb{R}^K$ denote the current frame's DCT coefficients [S1].

**Steps:**
1.  **Initialization:** For the first frame ($t=0$), encode using intra-coding (spatial prediction and transform) to initialize the decoder's reference buffer. No temporal residual is formed [S1].
2.  **Transform:** Compute the 3D DCT coefficients $\mathbf{c}_t^{(b)}$ for all active blocks $b$ in the current frame $t$ [S1].
3.  **Residual Formation:** For each block $b$, calculate the transform-domain residual $\Delta \mathbf{c}_t^{(b)}$ using the reference buffer from the previous frame [S1]:
    $$
    \Delta \mathbf{c}_t^{(b)} = \mathbf{c}_t^{(b)} - \tilde{\mathbf{c}}_{t-1}^{(b)}
    $$
    *   If block $b$ is absent in the current frame but existed in the reference, treat it as a removal event by setting $\mathbf{c}_t^{(b)} = \mathbf{0}$ [S1].
    *   If block $b$ is newly activated in the current frame, $\tilde{\mathbf{c}}_{t-1}^{(b)}$ is treated as $\mathbf{0}$ (or undefined, effectively making the residual equal to the current coefficients) [S1].
4.  **Quantization:** Quantize the residual vector $\Delta \mathbf{c}_t^{(b)}$ using the same quantization steps (separate handling of DC and AC components) as intra coding [S1]. Let $Q(\cdot)$ denote the quantization function.
5.  **Entropy Coding:** Range-encode the resulting integers using the same per-coefficient entropy coding strategy (adaptive probability models) as intra coding [S1].
6.  **Closed-Loop Update:** To prevent encoder-decoder drift, the encoder updates its reference buffer using the reconstructed residual. The decoder performs the same update after decoding [S1]:
    $$
    \tilde{\mathbf{c}}_t^{(b)} = \tilde{\mathbf{c}}_{t-1}^{(b)} + Q^{-1}(Q(\Delta \mathbf{c}_t^{(b)}))
    $$
    where $Q^{-1}(\cdot)$ denotes dequantization [S1].

**Pseudocode:**
```python
def encode_temporal_block(block_id, current_tsdf_samples, prev_ref_coeffs, quantizer):
    """
    Encodes a single block's temporal residual.
    
    Args:
        block_id: Identifier for the voxel block.
        current_tsdf_samples: Array of TSDF values for the current frame's block.
        prev_ref_coeffs: Array of K DCT coefficients from the previous frame's reconstruction.
        quantizer: Object handling Q() and Q_inv() for DC/AC components.
        
    Returns:
        encoded_bits: Bitstream for the residual.
        new_ref_coeffs: Updated reference coefficients for the next frame.
    """
    # Step 1: Transform current samples to DCT domain
    # Assumes a standard 3D DCT implementation for the block size
    current_coeffs = compute_3d_dct(current_tsdf_samples)
    
    # Step 2: Form residual
    # If block is new, prev_ref_coeffs is effectively zero.
    # If block is removed, current_coeffs is effectively zero.
    # Here we assume block exists in both for the core logic.
    residual_coeffs = current_coeffs - prev_ref_coeffs
    
    # Step 3: Quantize residual
    quantized_residual = quantizer.quantize(residual_coeffs)
    
    # Step 4: Entropy Encode
    # Uses adaptive probability models shared with intra coding
    encoded_bits = range_encode(quantized_residual)
    
    # Step 5: Closed-loop update for encoder reference
    # Dequantize and add to previous reference
    reconstructed_residual = quantizer.dequantize(quantized_residual)
    new_ref_coeffs = prev_ref_coeffs + reconstructed_residual
    
    return encoded_bits, new_ref_coeffs

def decode_temporal_block(block_id, encoded_bits, prev_ref_coeffs, quantizer):
    """
    Decodes a single block's temporal residual.
    
    Args:
        block_id: Identifier for the voxel block.
        encoded_bits: Bitstream for the residual.
        prev_ref_coeffs: Array of K DCT coefficients from the previous frame's reconstruction.
        quantizer: Object handling Q() and Q_inv() for DC/AC components.
        
    Returns:
        new_ref_coeffs: Updated reference coefficients for the next frame.
    """
    # Step 1: Entropy Decode
    quantized_residual = range_decode(encoded_bits)
    
    # Step 2: Dequantize
    reconstructed_residual = quantizer.dequantize(quantized_residual)
    
    # Step 3: Closed-loop update
    new_ref_coeffs = prev_ref_coeffs + reconstructed_residual
    
    return new_ref_coeffs
```

**Edge Cases and Pitfalls:**
*   **Block Activation/Deactivation:** If a block is newly activated, the reference coefficient vector is effectively zero, so the residual equals the current coefficients. If a block is removed, the current coefficients are zero, and the residual is the negative of the previous reference coefficients [S1].
*   **Drift:** Without the closed-loop update ($\tilde{\mathbf{c}}_t^{(b)} = \tilde{\mathbf{c}}_{t-1}^{(b)} + Q^{-1}(Q(\Delta \mathbf{c}_t^{(b)}))$), quantization errors would accumulate, causing encoder-decoder drift [S1].

## Subtopics

### Zero-Motion Block Prediction
A specific application of residual updates in transform domain for TSDF volumes. It reuses the previous reconstructed TSDF on the same voxel block grid as a "zero-motion predictor" [S1]. Only blockwise residual updates are encoded, which concentrates residual energy near regions of surface change, improving compressibility for subsequent transform and range encoding [S1]. It begins by sending one intra-coded frame to initialize the decoder reference, then uses the previous reconstructed TSDF as the predictor for subsequent frames [S1]. This method avoids explicit correspondence tracking often required by explicit geometry codecs [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Requires storing the reference coefficient buffer $\tilde{\mathbf{c}}_{t-1}^{(b)}$ for all active blocks [S1].
*   **Strengths:** Computationally efficient; does not require explicit correspondence tracking; concentrates residual energy near surface changes [S1].
*   **Limitations:** Requires temporal coherence (frames must be similar); sensitive to large motions or structural changes that break the block-wise correspondence [S1].
*   **When to use:** Dynamic volumetric data with slow surface changes (e.g., medical imaging sequences, fluid simulations with small deformations) [S1].
*   **When not to use:** Data with large, abrupt structural changes or no temporal coherence [S1].

## Background
The method originates from research on implicit surface compression using the Discrete Cosine Transform (DCT) and motion compensation [S1]. It leverages the regular, indexable structure of voxel block grids to simplify temporal coding [S1]. The approach was developed to improve compressibility for dynamic TSDF volumes by operating in the transform domain, where residuals are smaller and more amenable to entropy coding than spatial residuals [S1].
