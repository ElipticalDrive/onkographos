# Residual Updates in Transform Domain

Also called: Inter-frame DCT coding

## Overview
Residual Updates in Transform Domain is a temporal compression method for volumetric data (specifically TSDF) that operates in the frequency domain rather than the spatial domain. It solves the problem of efficiently encoding changes in dynamic implicit surfaces by subtracting the DCT coefficients of the previously reconstructed frame from the current frame's coefficients. Unlike spatial residual methods that predict voxel values directly, this approach predicts frequency coefficients, concentrating residual energy near regions of surface change to improve compressibility for subsequent transform and entropy coding [S1].

## How it works
The method relies on a block-based representation of the volume. The volume is divided into fixed-size voxel blocks. Each block is transformed into the DCT domain. The encoder maintains a reference buffer of reconstructed DCT coefficients from the previous time step.

**Inputs:**
- Current frame's TSDF voxel block data.
- Reference buffer $\tilde{\mathbf{c}}_{t-1}^{(b)}$ containing reconstructed DCT coefficients from frame $t-1$.

**Outputs:**
- Encoded bitstream of residuals and block activity flags.
- Updated reference buffer $\tilde{\mathbf{c}}_t^{(b)}$.

**Data Structures:**
- **Block Grid:** A regular, indexable grid of voxel blocks.
- **Coefficient Vector $\mathbf{c}_t^{(b)}$:** For a block $b$ at time $t$, this is a vector of retained 3D DCT coefficients. The ordering is fixed [S1].
- **Reference Buffer $\tilde{\mathbf{c}}_{t-1}^{(b)}$:** Stores the dequantized, reconstructed coefficients of block $b$ from the previous frame. Initialized to zero or populated by an initial intra-coded frame.

**Steps:**

1.  **Initialization:** Send one intra-coded frame to initialize the decoder reference. The decoder reconstructs the first frame's coefficients and stores them in $\tilde{\mathbf{c}}_0^{(b)}$ [S1].

2.  **Block Activity Check:** For each block $b$ in the current frame $t$:
    - If block $b$ is active (present) in the current frame, retrieve its DCT coefficients $\mathbf{c}_t^{(b)}$.
    - If block $b$ is inactive (absent) in the current frame but existed in the reference, treat it as a removal event. Set the current coefficients $\mathbf{c}_t^{(b)} = \mathbf{0}$ [S1].
    - If block $b$ is newly activated (did not exist in the reference), the reference $\tilde{\mathbf{c}}_{t-1}^{(b)}$ is treated as $\mathbf{0}$ [S1].

3.  **Residual Calculation:** Compute the transform-domain residual $\Delta \mathbf{c}_t^{(b)}$ for each active or removed block using the formula [S1]:
    $$
    \Delta \mathbf{c}_t^{(b)} = \mathbf{c}_t^{(b)} - \tilde{\mathbf{c}}_{t-1}^{(b)}
    $$
    Here, $\mathbf{c}_t^{(b)}$ is the current frame's DCT coefficients, and $\tilde{\mathbf{c}}_{t-1}^{(b)}$ is the reference buffer from the previous frame.

4.  **Quantization:** Quantize the residual coefficients $\Delta \mathbf{c}_t^{(b)}$ using the same quantization steps (handling DC and AC coefficients separately) as used in intra coding [S1]. Let $Q(\cdot)$ denote the quantization function.

5.  **Entropy Coding:** Range-encode the resulting quantized integers. Use the same per-coefficient entropy coding strategy (adaptive probability models) as intra coding [S1].

6.  **Closed-Loop Reference Update:** To prevent encoder-decoder drift, the encoder updates its reference buffer using the reconstructed residual. The decoder performs the same update after decoding. The update formula is [S1]:
    $$
    \tilde{\mathbf{c}}_t^{(b)} = \tilde{\mathbf{c}}_{t-1}^{(b)} + Q^{-1}(Q(\Delta \mathbf{c}_t^{(b)}))
    $$
    where $Q^{-1}(\cdot)$ is the dequantization function. This ensures the encoder's reference matches the decoder's reference exactly.

**Pseudocode:**

```python
def encode_transform_domain_residuals(current_tsdf_blocks, prev_reconstructed_coeffs):
    """
    Encodes temporal residuals in the DCT domain.
    
    Args:
        current_tsdf_blocks: Dictionary mapping block_id -> TSDF voxel data for current frame t.
        prev_reconstructed_coeffs: Dictionary mapping block_id -> DCT coefficients from frame t-1.
        
    Returns:
        bitstream: Encoded data.
        next_reconstructed_coeffs: Updated reference buffer for frame t.
    """
    bitstream = []
    next_reconstructed_coeffs = {}
    
    # Identify all blocks present in either current or previous frame
    all_block_ids = set(current_tsdf_blocks.keys()) | set(prev_reconstructed_coeffs.keys())
    
    for block_id in all_block_ids:
        # Step 2: Block Activity Check
        if block_id in current_tsdf_blocks:
            # Active block: compute DCT coefficients
            current_coeffs = compute_dct(current_tsdf_blocks[block_id])
        else:
            # Inactive block (removal event): set coefficients to zero
            current_coeffs = zeros_like(prev_reconstructed_coeffs.get(block_id, zeros_like(current_coeffs)))
            
        # Get reference coefficients (zero if block didn't exist previously)
        ref_coeffs = prev_reconstructed_coeffs.get(block_id, zeros_like(current_coeffs))
        
        # Step 3: Residual Calculation
        residual = current_coeffs - ref_coeffs
        
        # Step 4: Quantization
        quantized_residual = quantize(residual)
        
        # Step 5: Entropy Coding
        encoded_symbols = range_encode(quantized_residual)
        bitstream.append((block_id, encoded_symbols))
        
        # Step 6: Closed-Loop Reference Update
        # Dequantize and add to reference
        reconstructed_residual = dequantize(quantized_residual)
        next_reconstructed_coeffs[block_id] = ref_coeffs + reconstructed_residual
        
    return bitstream, next_reconstructed_coeffs
```

## Subtopics

### Zero-Motion Block Prediction
A specific application of residual updates in transform domain where the previous reconstructed TSDF on the same voxel block grid is reused as a "zero-motion predictor." Only blockwise residual updates are encoded. This concentrates residual energy near regions of surface change, improving compressibility for subsequent transform and range encoding. It requires sending one intra-coded frame to initialize the decoder reference, after which only residuals are sent for subsequent frames [S1].

## Operating characteristics
- **Complexity:** The method is computationally efficient because it operates on a regular, indexable block structure. It does not require explicit correspondence tracking often required by explicit geometry codecs [S1].
- **Performance:** By concentrating residual energy near surface changes, it achieves better compressibility than spatial prediction for dynamic TSDF data.
- **Limitations:** It assumes a fixed voxel block grid. It is less effective if the surface motion is complex and causes significant block-level occlusion or disocclusion that isn't captured by simple block activation/deactivation flags.
- **Drift Prevention:** The closed-loop update mechanism is critical; without it, quantization errors would accumulate, causing encoder-decoder drift [S1].

## Background
This method was introduced in the context of implicit surface compression using the Discrete Cosine Transform (DCT) and motion compensation. It leverages the regularity of block-based TSDF representations to simplify temporal coding. The approach was detailed in research on compressing dynamic implicit surfaces, highlighting the efficiency of transform-domain residuals over spatial ones for this specific data type [S1].
