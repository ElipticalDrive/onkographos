# RDLS-SS-DWT+Pred

Also called: Hybrid Transform, Reversible Denoising Lifting Steps with Step Skipping and Prediction

## Overview
RDLS-SS-DWT+Pred is a lossless volumetric compression method that combines the 3D Discrete Wavelet Transform (DWT) with reversible denoising lifting steps (RDLS), step skipping (SS), and predictive coding [S1]. It solves the problem of high entropy in wavelet subbands by applying spatial prediction to the final subbands generated by the transform [S1]. It differs from its sibling [SS-DWT+Pred](5256-ss-dwt-pred.md) by incorporating RDLS filters to reduce noise artifacts, though sources indicate that using actual denoising filters may be avoided without sacrificing bitrate improvements, making it functionally similar to [SS-DWT+Pred](5256-ss-dwt-pred.md) in practice [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D volumetric image $V$ of dimensions $W \times H \times D$.
*   **Output:** A compressed bitstream containing the entropy-coded prediction residuals.

**Data Structures:**
*   **Subbands:** The 3D-DWT decomposition produces multiple subbands. The method operates specifically on the "final subbands" (typically the highest frequency detail subbands at the deepest decomposition level).
*   **Prediction Errors:** Residuals $R_t = V_t - V_{pred}$ stored for entropy coding.

**Parameters:**
*   **Decomposition Level:** Set to 3 levels in all reported experiments [S1].
*   **RDLS Filters:** Selected from a set including Null, None, and actual denoising filters. The heuristic selects filters to minimize bitrate [S1].
*   **Predictor Set:** A predefined set of candidate predictors (see Table 1 in [S1]). Includes NOP, $P_X, P_Y, P_Z$, $AVG_{XY}, AVG_{XZ}, AVG_{YZ}, MED_{XY}, MED_{XZ}, MED_{YZ}, AVG3D$, and directional predictors based on neighbors A-H [S1].

**Steps:**
1.  **Transform Construction:** Apply RDLS-SS-DWT to the input volume. This involves:
    *   Applying reversible denoising lifting steps (RDLS) to the wavelet coefficients.
    *   Skipping specific lifting steps (SS) based on a heuristic that minimizes estimated or actual bitrate [S1].
2.  **Predictor Selection:** For each final subband of the RDLS-SS-DWT output:
    *   Iterate through the set of candidate predictors.
    *   For each candidate predictor, compute the prediction errors for all samples in the subband.
    *   Compute the memoryless entropy $H$ of the prediction errors using the formula below.
    *   Select the predictor that yields the smallest $H$.
    *   If all actual predictors increase entropy compared to the NOP predictor, select NOP [S1].
3.  **Prediction Application:** Apply the selected predictor to the subband samples.
    *   Prediction is performed in raster scan order: volume slices from front to back, slice rows from top to bottom, pixels in a row from left to right [S1].
    *   If a predictor cannot be computed for a sample (e.g., neighbors are out of bounds), fall back to a simpler predictor (e.g., NOP) [S1].
4.  **Residual Encoding:** Entropy-code the resulting prediction residuals $R_t$ using the standard JP3D entropy coding pipeline (e.g., arithmetic coding or histogram packing) [S1].

**Formula:**
The memoryless entropy $H$ of the prediction errors in a subband is calculated as [S1]:

$$ H = -\sum_{i=\text{MinPE}}^{\text{MaxPE}} p_i \log_2 p_i $$

Where:
*   $M$ is the number of samples in the subband.
*   $\text{MinPE}$ and $\text{MaxPE}$ are the smallest and greatest prediction errors, respectively.
*   $p_i$ is the probability of occurrence of prediction error $i$ in the subband.
*   $0 \log_2 0 = 0$ [S1].

**Pseudocode:**

```python
def rdls_ss_dwt_plus_pred(volume, decomposition_level=3):
    """
    Compress a 3D volume using RDLS-SS-DWT+Pred.
    
    Args:
        volume: 3D numpy array of shape (D, H, W)
        decomposition_level: int, number of DWT levels (default 3)
        
    Returns:
        compressed_data: bytes, the compressed bitstream
    """
    # Step 1: Apply RDLS-SS-DWT transform
    # The heuristic selects RDLS filters and steps to skip.
    # For implementation, we assume a function that performs the transform
    # and returns the subbands.
    subbands = apply_rdls_ss_dwt(volume, decomposition_level)
    
    # Identify final subbands (highest frequency detail subbands)
    final_subbands = get_final_subbands(subbands)
    
    compressed_data = b""
    
    # Step 2 & 3: For each final subband, select predictor and apply
    for subband in final_subbands:
        # Get candidate predictors
        candidates = get_candidate_predictors()
        
        best_predictor = None
        min_entropy = float('inf')
        
        for predictor in candidates:
            # Compute prediction errors
            errors = compute_prediction_errors(subband, predictor)
            
            # Compute memoryless entropy
            entropy = compute_memoryless_entropy(errors)
            
            if entropy < min_entropy:
                min_entropy = entropy
                best_predictor = predictor
                
        # Apply best predictor to get residuals
        residuals = compute_prediction_errors(subband, best_predictor)
        
        # Step 4: Entropy code residuals
        # This part depends on the specific entropy coder (e.g., JP3D arithmetic coding)
        # Here we assume a generic entropy coder function
        residual_bits = entropy_encode(residuals)
        compressed_data += residual_bits
        
    return compressed_data

def compute_memoryless_entropy(errors):
    """
    Compute H = -sum(p_i * log2(p_i)) for prediction errors.
    """
    # Count occurrences of each error value
    error_counts = Counter(errors)
    total_samples = len(errors)
    
    entropy = 0.0
    for error_val, count in error_counts.items():
        if count > 0:
            p_i = count / total_samples
            # 0 * log2(0) is defined as 0
            if p_i > 0:
                entropy -= p_i * math.log2(p_i)
                
    return entropy

def compute_prediction_errors(subband, predictor):
    """
    Compute residuals R_t = V_t - V_pred for each sample in the subband.
    Handles boundary conditions by falling back to NOP if neighbors are out of bounds.
    """
    D, H, W = subband.shape
    errors = np.zeros_like(subband)
    
    # Raster scan order: D (front to back), H (top to bottom), W (left to right)
    for d in range(D):
        for h in range(H):
            for w in range(W):
                try:
                    predicted_value = predictor.predict(subband, d, h, w)
                except BoundaryError:
                    # Fallback to NOP predictor if neighbors are out of bounds
                    predicted_value = 0.0
                    
                errors[d, h, w] = subband[d, h, w] - predicted_value
                
    return errors
```

## Subtopics

### [Adaptive Transform Construction Heuristic](11258-adaptive-transform-construction-heuristic.md)
A greedy parameter selection method for the RDLS-SS-DWT+Pred transform that selects denoising filters for RDLS subbands and predictors for the final subbands to minimize the estimated bitrate of the compressed volume. It differs from exhaustive search by using a fast entropy estimation to approximate JP3D bitrate, allowing image-adaptive configuration without prohibitive computational cost.

## Operating characteristics
*   **Time Complexity:** The heuristic selection of RDLS filters and steps can be computationally expensive if based on actual JP3D bitrates. Using an entropy estimator (H0) reduces this cost [S1]. The prediction step is linear in the number of samples per subband.
*   **Memory Complexity:** Requires storage for the volume, wavelet coefficients, and prediction residuals. No significant additional memory overhead compared to standard DWT-based methods.
*   **Measured Performance:** In experiments on medical images (CT, MRI, US), RDLS-SS-DWT+Pred showed bitrate improvements over standard DWT. For example, on MRI1, it achieved an 8.973% bitrate reduction compared to DWT [S1]. The difference between RDLS-SS-DWT+Pred and SS-DWT+Pred is very small, indicating that actual denoising filters may be omitted without significant loss [S1].
*   **Strengths:** Significant lossless compression ratio improvement for volumetric medical images. Adaptive to image content via heuristic selection.
*   **Limitations:** Heuristic selection can be slow if not using entropy estimation. Actual denoising filters are time-consuming to apply and select, though they may not be necessary [S1].
*   **When to use:** When lossless compression of 3D volumetric data (especially medical images) is required and standard DWT compression is insufficient.
*   **When not to use:** When computational speed is critical and the overhead of heuristic selection is unacceptable. When lossy compression is acceptable, other methods may be more efficient.

## Background
The method was proposed in 2020 by researchers from Vrije Universiteit Brussel (VUB) and Interdisciplinary Institute for BroadBand Technology (IBBT) [S1]. It builds on previous work on 2D-DWT variants using step skipping and reversible denoising lifting steps [S1]. The initial phase of the research was presented in a conference report [S1]. The implementation is available as a patch to IRIS-JP3D [S1].
