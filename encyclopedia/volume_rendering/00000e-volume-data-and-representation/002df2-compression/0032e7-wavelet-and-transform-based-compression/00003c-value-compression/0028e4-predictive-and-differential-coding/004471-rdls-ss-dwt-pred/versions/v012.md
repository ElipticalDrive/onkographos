# RDLS-SS-DWT+Pred

Also called: Hybrid Transform, Reversible Denoising Lifting Steps with Step Skipping and Prediction

## Overview
RDLS-SS-DWT+Pred is a lossless volumetric compression transform that combines 3D Discrete Wavelet Transform (DWT) with predictive coding to minimize the entropy of the resulting coefficients [S1]. It operates by applying Reversible Denoising Lifting Steps (RDLS) with step skipping to a 3D-DWT, followed by spatial prediction on the final subbands [S1]. It differs from its sibling [SS-DWT+Pred](6518-ss-dwt-pred.md) by incorporating denoising filters in the lifting steps, though sources indicate that using actual denoising filters yields negligible bitrate improvements over skipping them entirely [S1]. It builds on [Predictive and Differential Coding](4393-predictive-and-differential-coding.md) by applying prediction specifically to the transformed subbands rather than the raw volume data [G].

## How it works
**Inputs:** A 3D volumetric image $V$ of dimensions $W \times H \times D$ [S1].
**Outputs:** A set of entropy-coded residuals for each final subband of the transform [S1].

**Data Structures:**
The transform decomposes the volume into subbands [S1]. The "final subbands" are the high-frequency detail subbands at the deepest decomposition level [S1]. For a 3-level decomposition, these are the subbands at level 3 [S1].

**Parameters:**
*   **Decomposition Level:** Fixed at 3 levels in the source experiments [S1].
*   **RDLS Filters:** Selected from a set including Null, None, and actual denoising filters [S1]. The heuristic selects which steps to skip and which filters to apply [S1].
*   **Predictor Set:** A set of candidate spatial predictors (see Table 1 below) [S1].
*   **NOP Predictor:** A candidate predictor that assumes the value is 0 [S1]. It is used if other predictors increase entropy or if neighbors are out of bounds [S1].

**Candidate Predictors:**
The source defines predictors based on the spatial arrangement of neighbors in the current slice (slice $i$) and the previous slice (slice $i-1$) [S1]. Let $A, B, C, D, E, F, G, H$ be the voxel values at specific relative positions in the raster scan order [S1]. The raster scan order is: volume slices from front to back, slice rows from top to bottom, pixels in a row from left to right [S1].

| Predictor Name | Formula | Context/Notes |
| :--- | :--- | :--- |
| NOP | $0$ | Default if others fail or increase entropy [S1]. |
| $P_X$ | $A$ | Horizontal neighbor (Left) [S1]. |
| $P_Y$ | $B$ | Vertical neighbor (Top) [S1]. |
| $P_Z$ | $D$ | Depth neighbor (Previous Slice) [S1]. |
| $AVG_{XY}$ | $(A + B) / 2$ | Average of Left and Top neighbors in current slice [S1]. |
| $AVG_{XZ}$ | $(A + D) / 2$ | Average of Left and Previous Slice neighbors [S1]. |
| $AVG_{YZ}$ | $(B + D) / 2$ | Average of Top and Previous Slice neighbors [S1]. |
| $MED_{XY}$ | $\text{median}(A, B, A+B-C)$ | Median predictor using Left, Top, and Top-Left [S1]. |
| $MED_{XZ}$ | $\text{median}(A, D, A+D-E)$ | Median predictor using Left, Prev, and Prev-Left [S1]. |
| $MED_{YZ}$ | $\text{median}(B, D, B+D-F)$ | Median predictor using Top, Prev, and Prev-Top [S1]. |
| $AVG3D$ | $(A + B + D) / 3$ | Average of Left, Top, and Previous Slice neighbors [S1]. |

*Note: The source provides a table with labels A-H corresponding to spatial positions. Specifically, for a voxel at $(x,y,z)$: $A = V(x-1, y, z)$ (Left), $B = V(x, y-1, z)$ (Top), $C = V(x-1, y-1, z)$ (Top-Left), $D = V(x, y, z-1)$ (Previous Slice), $E = V(x-1, y, z-1)$ (Prev-Left), $F = V(x, y-1, z-1)$ (Prev-Top) [S1]. The source table maps specific formulas to specific predictor names [S1].*

**Steps:**
1.  **Transform Construction:** Apply the RDLS-SS-DWT transform to the volume [S1]. This involves selecting RDLS filters and determining which lifting steps to skip based on a heuristic (either actual bitrate or entropy estimation) [S1].
2.  **Subband Processing:** For each final subband produced by the transform:
    a.  Iterate through all samples in raster scan order [S1].
    b.  For each sample, compute the prediction $V_{pred}$ using the candidate predictors [S1].
    c.  If a predictor cannot be computed (e.g., neighbors are out of bounds), fall back to the NOP predictor [S1].
    d.  Compute the prediction error (residual) $R = V_{actual} - V_{pred}$ [S1].
    e.  Calculate the memoryless entropy $H$ for the set of residuals in the subband using the formula below [S1].
    f.  Select the predictor that yields the minimum entropy $H$ for that subband [S1].
    g.  Encode the residuals using the selected predictor [S1].
3.  **Entropy Calculation:** The memoryless entropy $H$ for a subband is calculated as:
    $$ H = -\sum_{i=MinPE}^{MaxPE} p_i \log_2 p_i $$
    where:
    *   $M$ is the number of samples in the subband [S1].
    *   $MinPE$ and $MaxPE$ are the smallest and greatest prediction errors in the subband [S1].
    *   $p_i = \text{count}(i) / M$ is the probability of occurrence of prediction error $i$ [S1].
    *   $0 \log_2 0 = 0$ [S1].

**Pseudocode:**

```python
import math

def rdls_ss_dwt_plus_pred(volume, decomposition_level=3):
    # Step 1: Apply 3-level 3D DWT with RDLS and step skipping heuristic [S1]
    subbands = apply_rdls_ss_dwt(volume, decomposition_level)

    # Step 2: Extract final subbands at the deepest level [S1]
    final_subbands = get_final_subbands(subbands, decomposition_level)

    encoded_data = {}

    for subband_name, subband_data in final_subbands.items():
        best_predictor = None
        min_entropy = float('inf')
        best_residuals = None

        candidates = ['NOP', 'P_X', 'P_Y', 'P_Z', 'AVG_XY', 'AVG_XZ', 'AVG_YZ',
                      'MED_XY', 'MED_XZ', 'MED_YZ', 'AVG3D']

        for predictor_name in candidates:
            residuals = []

            # Iterate through subband samples in raster scan order [S1]
            for d in range(subband_data.shape[0]):
                for h in range(subband_data.shape[1]):
                    for w in range(subband_data.shape[2]):
                        actual_val = subband_data[d, h, w]
                        pred_val = compute_predictor(predictor_name, subband_data, d, h, w, subband_data.shape)

                        if pred_val is None:
                            pred_val = 0

                        residuals.append(actual_val - pred_val)

            entropy = calculate_entropy(residuals)

            if entropy < min_entropy:
                min_entropy = entropy
                best_predictor = predictor_name
                best_residuals = residuals

        encoded_data[subband_name] = entropy_encode(best_residuals)

    return encoded_data

def compute_predictor(name, subband, d, h, w, shape):
    def get_val(dx, dy, dz):
        nd, nh, nw = d + dz, h + dy, w + dx
        if 0 <= nd < shape[0] and 0 <= nh < shape[1] and 0 <= nw < shape[2]:
            return subband[nd, nh, nw]
        return None

    A = get_val(-1, 0, 0)
    B = get_val(0, -1, 0)
    C = get_val(-1, -1, 0)
    D = get_val(0, 0, -1)
    E = get_val(-1, 0, -1)
    F = get_val(0, -1, -1)

    if name == 'NOP':
        return 0
    elif name == 'P_X':
        return A if A is not None else 0
    elif name == 'P_Y':
        return B if B is not None else 0
    elif name == 'P_Z':
        return D if D is not None else 0
    elif name == 'AVG_XY':
        return (A + B) / 2 if A is not None and B is not None else None
    elif name == 'AVG_XZ':
        return (A + D) / 2 if A is not None and D is not None else None
    elif name == 'AVG_YZ':
        return (B + D) / 2 if B is not None and D is not None else None
    elif name == 'MED_XY':
        return median([A, B, A + B - C]) if A is not None and B is not None and C is not None else None
    elif name == 'MED_XZ':
        return median([A, D, A + D - E]) if A is not None and D is not None and E is not None else None
    elif name == 'MED_YZ':
        return median([B, D, B + D - F]) if B is not None and D is not None and F is not None else None
    elif name == 'AVG3D':
        vals = [v for v in [A, B, D] if v is not None]
        return sum(vals) / 3 if len(vals) == 3 else None
    return 0

def median(values):
    s = sorted(values)
    n = len(s)
    return s[n // 2] if n % 2 == 1 else (s[n // 2 - 1] + s[n // 2]) / 2

def calculate_entropy(residuals):
    if not residuals:
        return 0.0
    min_pe = min(residuals)
    max_pe = max(residuals)
    counts = {}
    for r in residuals:
        counts[r] = counts.get(r, 0) + 1
    M = len(residuals)
    entropy = 0.0
    for i in range(min_pe, max_pe + 1):
        p_i = counts.get(i, 0) / M
        if p_i > 0:
            entropy -= p_i * math.log2(p_i)
    return entropy
```

## Subtopics

### [Adaptive Transform Construction Heuristic](11258-adaptive-transform-construction-heuristic.md)
A greedy parameter selection method for the RDLS-SS-DWT component. It selects denoising filters and steps to skip to minimize estimated bitrate, using a fast entropy estimator (H0) instead of actual JP3D bitrates to reduce computational cost.

## Operating characteristics
**Time Complexity:** The transform involves a 3-level 3D-DWT and a linear pass over the final subbands for prediction and entropy calculation [S1]. The heuristic selection of filters/steps adds overhead; using entropy estimation (H0) is faster than computing actual JP3D bitrates [S1].
**Memory Complexity:** Requires storage for the volume and the subbands [S1]. The prediction pass accesses spatial neighbors in raster scan order, and the source does not specify additional large buffers [S1].
**Performance:** In experiments on medical images (CT, MRI, US), RDLS-SS-DWT+Pred provided bitrate improvements over standard DWT [S1]. For the MRI1 image, RDLS-SS-DWT+Pred reduced the bitrate by 8.973% compared to standard DWT [S1]. The improvement over SS-DWT+Pred (without denoising filters) was very small, suggesting that the denoising filters in RDLS may be omitted without significant loss [S1].
**Strengths:** Effective for volumetric medical images; combines the energy compaction of DWT with the redundancy reduction of prediction [S1].
**Limitations:** The heuristic selection is suboptimal; performance varies by image type (better for MRI1, less consistent for others) [S1].

## Background
The method was proposed in 2020 by researchers from Vrije Universiteit Brussel (VUB) and Interdisciplinary Institute for BroadBand Technology (IBBT) [S1]. It is an extension of 2D image compression techniques (RDLS-SS-DWT+Pred) generalized to 3D volumetric data [S1]. The initial phase of the research was presented in a conference report [S1]. The implementation is available as a patch to IRIS-JP3D [S1].
