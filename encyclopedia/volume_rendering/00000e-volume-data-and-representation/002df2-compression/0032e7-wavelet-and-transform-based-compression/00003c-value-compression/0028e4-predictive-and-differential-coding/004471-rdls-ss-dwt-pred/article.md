# RDLS-SS-DWT+Pred

Also called: Hybrid Transform, Reversible Denoising Lifting Steps with Step Skipping and Prediction

## Overview
RDLS-SS-DWT+Pred is a lossless volumetric compression method that constructs a hybrid transform by combining 3D-DWT with reversible denoising lifting steps (RDLS), step skipping (SS), and predictive coding [S1]. It solves the problem of high entropy in wavelet subbands by applying spatial prediction to the final subbands of the RDLS-SS-DWT transform [S1]. It sets itself apart from its parent [Predictive and Differential Coding](4393-predictive-and-differential-coding.md) by integrating prediction specifically into the post-processing stage of a modified DWT, and from its sibling [SS-DWT+Pred](6518-ss-dwt-pred.md) by including the RDLS denoising stage, although sources note that RDLS offers negligible bitrate improvement over SS-DWT+Pred alone [S1].

## How it works
**Inputs:** A 3D volumetric image $V$ of dimensions $W \times H \times D$.
**Outputs:** A compressed bitstream (typically via JP3D/ISO/IEC 29170-2 entropy coding).

**Data Structures:**
The transform operates on subbands generated by a 3-level 3D-DWT decomposition. Each subband is a 3D array of coefficients. The method applies prediction to the "final subbands" (the highest frequency detail subbands at the deepest decomposition level).

**Parameters:**
*   **Decomposition Level:** Fixed at 3 levels for all experiments [S1].
*   **RDLS Filters:** Selected from a set including Null, None, and actual denoising filters. Sources indicate that using actual denoising filters is unnecessary as SS-DWT+Pred yields similar results [S1].
*   **Predictors:** Selected from a candidate set (see Table 1 below).
*   **Packet Size:** In JP3D implementation, packets are $26 \times 26 \times 24$ to optimize creation speed [S1].

**Candidate Predictors:**
Prediction is performed in raster scan order: volume slices from front to back, slice rows from top to bottom, pixels in a row from left to right [S1]. If a predictor requires neighbors that are out of bounds (e.g., the front-top-left pixel), a simpler predictor (e.g., NOP) is used [S1].

The candidate predictors are defined by their reference samples relative to the current sample $P$ at coordinates $(x, y, z)$. Let $A, B, C, D, E, F, G, H$ denote specific neighbor locations in the spatial domain or subband structure as defined in the source's Figure 2 and Table 1 [S1].

| Predictor Name | Prediction Formula | Context/Notes |
| :--- | :--- | :--- |
| NOP | $0$ | Default fallback; predicts sample is 0. |
| $P_X$ | $V(x-1, y, z)$ | Horizontal neighbor (Left). |
| $P_Y$ | $V(x, y-1, z)$ | Vertical neighbor (Above). |
| $P_Z$ | $V(x, y, z-1)$ | Axial neighbor (Front). |
| $AVG_{XY}$ | $(P_X + P_Y) / 2$ | Average of Left and Above. |
| $AVG_{XZ}$ | $(P_X + P_Z) / 2$ | Average of Left and Front. |
| $AVG_{YZ}$ | $(P_Y + P_Z) / 2$ | Average of Above and Front. |
| $MED_{XY}$ | $\text{median}(P_X, P_Y, P_X+P_Y-P_{XY})$ | Median predictor in XY plane. |
| $MED_{XZ}$ | $\text{median}(P_X, P_Z, P_X+P_Z-P_{XZ})$ | Median predictor in XZ plane. |
| $MED_{YZ}$ | $\text{median}(P_Y, P_Z, P_Y+P_Z-P_{YZ})$ | Median predictor in YZ plane. |
| $AVG3D$ | $(P_X + P_Y + P_Z) / 3$ | Average of Left, Above, Front. |

*Note: The source Table 1 includes complex references to subband coefficients (e.g., $H_{LL}$, $L_{HH}$) for specific RDLS configurations. For a general implementation, the spatial neighbors $P_X, P_Y, P_Z$ and their combinations are the primary candidates. The specific subband-based predictors (like $H_{LL}$) apply to the transformed coefficients directly, relying on the RDLS structure [S1].*

**Steps:**
1.  **Transform Construction:** Apply 3D-DWT with RDLS and Step Skipping to the input volume. The specific RDLS filters and skipped steps are selected by a heuristic (see Subtopics) to minimize entropy or bitrate [S1].
2.  **Entropy Estimation:** For each final subband, calculate the memoryless entropy $H$ for each candidate predictor. The entropy is computed as:
    $$ H = -\sum_{i=\text{MinPE}}^{\text{MaxPE}} p_i \log_2 p_i $$
    where $M$ is the number of samples in the subband, $\text{MinPE}$ and $\text{MaxPE}$ are the smallest and greatest prediction errors, $p_i$ is the probability of occurrence of prediction error $i$, and $0 \log_2 0 = 0$ [S1].
3.  **Predictor Selection:** Select the candidate predictor that results in the smallest memoryless entropy $H$ for each subband. If all actual predictors increase entropy compared to NOP, select NOP [S1].
4.  **Prediction and Residual:** For each sample in the subband, in raster scan order, compute the predicted value $V_{pred}$ using the selected predictor. Compute the residual $R = V_{actual} - V_{pred}$ [S1].
5.  **Entropy Coding:** Encode the residuals using JP3D entropy coding (e.g., arithmetic coding) [S1].

```python
def rdls_ss_dwt_plus_pred(volume, decomposition_level=3):
    # 1. Apply RDLS-SS-DWT transform
    # The heuristic selects filters and steps. 
    # For simplicity, we assume a standard RDLS-SS-DWT is applied.
    subbands = rdls_ss_dwt_transform(volume, decomposition_level)
    
    compressed_subbands = {}
    
    for subband_name, subband_data in subbands.items():
        # 2. Select best predictor for this subband
        best_predictor = select_best_predictor(subband_data)
        
        # 3. Apply prediction and compute residuals
        residuals = apply_prediction(subband_data, best_predictor)
        
        # 4. Entropy code residuals
        # In practice, this involves packetization and JP3D arithmetic coding
        bitstream_segment = jp3d_entropy_encode(residuals)
        
        compressed_subbands[subband_name] = bitstream_segment
        
    return compressed_subbands

def select_best_predictor(subband_data):
    candidates = [NOP, PX, PY, PZ, AVG_XY, AVG_XZ, AVG_YZ, AVG3D]
    # Note: MED predictors require specific neighbor logic
    # For brevity, assuming spatial neighbors are available
    
    min_entropy = infinity
    best_pred = NOP
    
    for pred_func in candidates:
        # Compute prediction errors
        errors = []
        for z in range(subband_data.depth):
            for y in range(subband_data.height):
                for x in range(subband_data.width):
                    # Get neighbors, handling boundaries
                    p_x = get_neighbor(subband_data, x-1, y, z)
                    p_y = get_neighbor(subband_data, x, y-1, z)
                    p_z = get_neighbor(subband_data, x, y, z-1)
                    
                    # Handle boundary cases by falling back to NOP if needed
                    if p_x is None or p_y is None or p_z is None:
                        pred_val = 0
                    else:
                        pred_val = pred_func(p_x, p_y, p_z)
                        
                    actual = subband_data[z, y, x]
                    errors.append(actual - pred_val)
        
        # Calculate memoryless entropy
        entropy = calculate_entropy(errors)
        
        if entropy < min_entropy:
            min_entropy = entropy
            best_pred = pred_func
            
    return best_pred

def calculate_entropy(errors):
    # Count occurrences
    counts = {}
    for e in errors:
        counts[e] = counts.get(e, 0) + 1
        
    total = len(errors)
    entropy = 0.0
    for count in counts.values():
        if count > 0:
            p = count / total
            entropy -= p * math.log2(p)
    return entropy

def get_neighbor(data, x, y, z):
    if 0 <= x < data.width and 0 <= y < data.height and 0 <= z < data.depth:
        return data[z, y, x]
    return None
```

## Subtopics

### [Adaptive Transform Construction Heuristic](11258-adaptive-transform-construction-heuristic.md)
A greedy parameter selection method for the RDLS-SS-DWT transform. It selects denoising filters for RDLS subbands and predictors for the final subbands to minimize the estimated bitrate of the compressed volume. It differs from exhaustive search by using a fast entropy estimation to approximate JP3D bitrate, allowing image-adaptive configuration without prohibitive computational cost.

## Operating characteristics
*   **Complexity:** The transform complexity is dominated by the 3D-DWT and RDLS steps. The heuristic selection of filters and predictors adds overhead. Entropy coding is the slowest part of the JP3D pipeline [S1].
*   **Performance:** On medical images (CT, MRI, US), RDLS-SS-DWT+Pred provides bitrate improvements over standard DWT. For example, on MRI1, it achieved an 8.973% bitrate reduction compared to DWT [S1]. The improvement over SS-DWT+Pred is very small, suggesting RDLS filters are not strictly necessary for bitrate gains [S1].
*   **Memory:** Requires storage for the 3D-DWT subbands and the residuals. The 3-level decomposition increases memory usage compared to 1 or 2 levels.
*   **Strengths:** Significant lossless compression ratio improvement for volumetric medical images. Adaptive to image content via heuristic selection.
*   **Limitations:** Heuristic selection can be computationally expensive if not optimized. RDLS filters are time-consuming to apply and select, offering little benefit over SS-DWT alone.

## Background
The method was proposed in 2020 by researchers from Vrije Universiteit Brussel (VUB) and Interdisciplinary Institute for BroadBand Technology (IBBT) [S1]. It builds on previous work generalizing 2D-DWT variants with step skipping to 3D [S1]. The implementation is available as a patch to IRIS-JP3D [S1]. The research was presented at a conference prior to the journal publication [S1].
