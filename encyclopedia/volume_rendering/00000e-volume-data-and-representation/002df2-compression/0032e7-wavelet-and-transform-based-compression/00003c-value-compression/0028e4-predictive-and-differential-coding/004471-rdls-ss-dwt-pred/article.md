# RDLS-SS-DWT+Pred

Also called: Hybrid Transform, Reversible Denoising Lifting Steps with Step Skipping and Prediction

## Overview
RDLS-SS-DWT+Pred is a lossless compression method for volumetric data that combines a modified Discrete Wavelet Transform (DWT) with predictive coding [S1]. It solves the problem of high entropy in wavelet subbands by applying spatial prediction to the final subbands of a transform that uses Reversible Denoising Lifting Steps (RDLS) and Step Skipping (SS) [S1]. It sets itself apart from standard DWT-based methods by integrating denoising and step-skipping heuristics before prediction, and from pure predictive methods by leveraging the multi-resolution structure of the wavelet tree [S1]. It builds on [Predictive and Differential Coding](4393-predictive-and-differential-coding.md).

## How it works
**Inputs and Outputs:**
- Input: A 3D volumetric image $V$ with dimensions $W \times H \times D$.
- Output: A compressed bitstream (typically via JPEG 2000/JP3D entropy coding).

**Data Structures:**
The transform operates on the coefficient subbands generated by the 3D-DWT. The final subbands (highest frequency detail coefficients) are the target for prediction. No specific bit-packing is defined in the transform step itself; it relies on the subsequent entropy coder (e.g., JP3D) for packing [S1].

**Parameters:**
- Decomposition level: 3 levels (used in all experiments) [S1].
- RDLS Filters: Selected from a set including Null, None, and denoising filters. The Null filter is significant as it yields subbands closer to the untransformed image, making prediction more effective [S1].
- Step Skipping: Selected based on heuristic to reduce computational cost and potentially bitrate [S1].
- Candidate Predictors: A set of spatial predictors (see Table 1 below) [S1].

**Candidate Predictors:**
The following predictors are available. $A, B, C, D, E, F, G, H$ represent neighboring voxel values in the current slice or adjacent slices. The prediction order is raster scan: slices front-to-back, rows top-to-bottom, pixels left-to-right [S1].

| Predictor | Formula | Context/Neighbors |
| :--- | :--- | :--- |
| NOP | $0$ | Default if others fail or increase entropy [S1] |
| $P_X$ | $A$ | Horizontal neighbor in current slice [S1] |
| $P_Y$ | $B$ | Vertical neighbor in current slice [S1] |
| $P_Z$ | $C$ | Neighbor in previous slice (axial) [S1] |
| $AVG_{XY}$ | $(A + B) / 2$ | Average of horizontal and vertical neighbors [S1] |
| $AVG_{XZ}$ | $(A + C) / 2$ | Average of horizontal and axial neighbors [S1] |
| $AVG_{YZ}$ | $(B + C) / 2$ | Average of vertical and axial neighbors [S1] |
| $MED_{XY}$ | $\text{median}(A, B, A+B-C)$ | Median predictor in XY plane [S1] |
| $MED_{XZ}$ | $\text{median}(A, C, A+C-E)$ | Median predictor in XZ plane [S1] |
| $MED_{YZ}$ | $\text{median}(B, C, B+C-F)$ | Median predictor in YZ plane [S1] |
| $AVG3D$ | $(A + B + C) / 3$ | Average of three immediate neighbors [S1] |

*Note: The specific geometric locations of A, B, C, etc., are defined in the source's Figure 2 and Table 1. Generally, A is the left neighbor, B is the top neighbor, C is the previous slice neighbor in the same position, and D, E, F are further neighbors required for median predictors [S1].*

**Steps:**
1. **Transform Construction:** Apply the RDLS-SS-DWT transform to the volume $V$ with 3 decomposition levels. The RDLS and step-skipping parameters are selected using a heuristic (either based on actual JP3D bitrate or an entropy estimator) [S1].
2. **Subband Identification:** Identify the final subbands of the transformed volume. These are the subbands at the finest resolution level [S1].
3. **Prediction Application:** For each final subband, apply a predictor from the candidate set. The predictor is chosen to minimize the memoryless entropy of the prediction errors [S1].
4. **Entropy Calculation:** The memoryless entropy $H$ of the prediction errors is calculated as:
   $$ H = -\sum_{i=\text{MinPE}}^{\text{MaxPE}} p_i \log_2(p_i) $$
   where $M$ is the number of samples in the subband, $\text{MinPE}$ and $\text{MaxPE}$ are the smallest and greatest prediction errors, $p_i$ is the probability of occurrence of prediction error $i$, and $0 \log_2 0 = 0$ [S1].
5. **Fallback:** If a predictor cannot be computed for a specific pixel (e.g., due to boundary conditions), a simpler predictor (e.g., NOP) is used [S1].
6. **Entropy Coding:** The predicted residuals are encoded using an entropy coder (e.g., JP3D) [S1].

        min_entropy = infinity
        
        # Get candidate predictors
        candidates = [NOP, PX, PY, PZ, AVG_XY, AVG_XZ, AVG_YZ, MED_XY, MED_XZ, MED_YZ, AVG3D]

            errors = []
            for voxel in subband.voxels_in_raster_order():
                try:
                    pred_val = predictor.predict(voxel.neighbors)
                    error = voxel.value - pred_val
                    errors.append(error)
                except BoundaryError:

                    # This implies per-voxel fallback or predictor selection.
                    # We assume per-voxel fallback to NOP for simplicity in entropy calc,
                    # or that the predictor selection is done on the whole subband using a robust predictor.
                    # The source implies selecting ONE predictor for the subband based on entropy.
                    # If a predictor fails at boundaries, we might exclude those voxels from entropy calc
                    # or use NOP for them. Let's assume we calculate entropy on valid predictions.
                    pass
            
            if not errors:
                continue
                
            # Calculate memoryless entropy
            entropy = calculate_memoryless_entropy(errors)
            
            if entropy < min_entropy:
                min_entropy = entropy
                best_predictor = predictor
        
        # Apply best predictor to the subband
        for voxel in subband.voxels_in_raster_order():
            try:
                pred_val = best_predictor.predict(voxel.neighbors)
                voxel.value = voxel.value - pred_val
            except BoundaryError:
                # Fallback to NOP prediction (predict 0)
                # NOP predicts 0, so residual is just the value itself
                pass

def calculate_memoryless_entropy(errors):
    # Count occurrences of each error value
    counts = histogram(errors)
    total = len(errors)
    entropy = 0.0
    for count in counts.values():
        if count > 0:
            p_i = count / total
            entropy -= p_i * log2(p_i)
    return entropy

## Subtopics

### [Adaptive Transform Construction Heuristic](11258-adaptive-transform-construction-heuristic.md)
A greedy parameter selection method for the RDLS-SS-DWT transform. It selects denoising filters for RDLS subbands and predictors for the final subbands to minimize the estimated bitrate of the compressed volume. It differs from exhaustive search by using a fast entropy estimation to approximate JP3D bitrate, allowing image-adaptive configuration without prohibitive computational cost.

## Operating characteristics
- **Time Complexity:** The transform is $O(N)$ where $N$ is the number of voxels, but the heuristic selection of RDLS filters and step skipping adds overhead. If actual JP3D bitrates are used for heuristic selection, the time complexity is significantly higher due to full compression trials. Using entropy estimation ($H_0$) reduces this cost [S1].
- **Memory Complexity:** Requires storage for the volume and its wavelet coefficients. The prediction step requires access to neighbors, which is local.
- **Measured Performance:** On medical images (CT, MRI, US), RDLS-SS-DWT+Pred provides bitrate improvements over standard DWT. For example, on MRI1, it achieved an 8.973% bitrate reduction compared to DWT [S1]. The improvement is generally better than SS-DWT+Pred and DWT+Pred [S1].
- **Strengths:** Significant lossless compression improvement, especially for medical images. The use of NOP predictor allows avoiding prediction if it increases entropy.
- **Limitations:** The heuristic selection can be slow if based on actual bitrates. The benefit of RDLS (denoising filters) over SS-DWT (Null filter) is minimal, suggesting RDLS complexity may not be justified [S1].
- **When to use:** When lossless compression of volumetric medical images is required and computational resources allow for heuristic selection.
- **When not to use:** When real-time performance is critical and the overhead of heuristic selection is prohibitive.

## Background
The method was proposed in 2020 by researchers from Vrije Universiteit Brussel (VUB) and Interdisciplinary Institute for BroadBand Technology (IBBT) [S1]. It builds on previous work on 2D-DWT variants with step skipping and reversible denoising lifting steps [S1]. The implementation is available as a patch to IRIS-JP3D [S1]. The research was presented at a conference in an earlier report [S1].
