# RDLS-SS-DWT+Pred

Also called: Hybrid Transform, Reversible Denoising Lifting Steps with Step Skipping and Prediction

## Overview
RDLS-SS-DWT+Pred is a lossless volumetric compression transform that combines the 3D Discrete Wavelet Transform (DWT) with Reversible Denoising Lifting Steps (RDLS), Step Skipping (SS), and predictive coding [S1]. It solves the problem of high entropy in wavelet subbands by applying spatial prediction to the final subbands, significantly improving compression ratios for medical images compared to standard DWT or SS-DWT alone [S1]. It differs from its siblings by integrating denoising lifting steps and step skipping into the wavelet decomposition before applying prediction, whereas siblings like [Delta Encoding](1096-delta-encoding.md) or [Lorenz Predictor with Arithmetic Coding](8070-lorenz-predictor-with-arithmetic-coding.md) typically apply prediction directly to raw data or simpler transforms [S1].

## How it works
**Inputs:** A 3D volumetric image $V$ of dimensions $W \times H \times D$.
**Outputs:** A set of entropy-coded residuals for each final subband.

**Data Structures:**
The transform decomposes the volume into subbands. The final subbands are the high-frequency components at the deepest decomposition level. The specific layout of coefficients depends on the chosen RDLS filters and skipped steps, but generally follows standard DWT subband naming (LL, LH, HL, HH, etc., extended to 3D).

**Parameters:**
*   **Decomposition Level:** Set to 3 levels in experimental implementations [S1].
*   **RDLS Filters:** Selected from a candidate set (including Null, None, and denoising filters) [S1].
*   **Skipped Steps:** Selected from a candidate set to reduce computational cost [S1].
*   **Predictor Set:** A set of candidate predictors (see Table 1 below) [S1].

**Candidate Predictors:**
The following predictors are defined based on neighbor locations relative to the current voxel. Let $A, B, C, D, E, F, G, H$ be the values of neighboring voxels in the current slice or adjacent slices as defined in the source's Figure 2 [S1].

| Predictor | Prediction Formula | Context |
| :--- | :--- | :--- |
| NOP | $0$ | Default if others fail or increase entropy |
| $P_X$ | $0$ | Horizontal (Axial) |
| $P_Y$ | $0$ | Vertical |
| $P_Z$ | $0$ | Depth |
| $AVG_{XY}$ | $(A + B)/2$ | Axial slice |
| $AVG_{XZ}$ | $(A + D)/2$ | Vertical slice |
| $AVG_{YZ}$ | $(B + D)/2$ | Depth slice |
| $MED_{XY}$ | $\text{median}(A, B, A+B-C)$ | Axial slice |
| $MED_{XZ}$ | $\text{median}(A, D, A+D-E)$ | Vertical slice |
| $MED_{YZ}$ | $\text{median}(B, D, B+D-F)$ | Depth slice |
| $AVG3D$ | $(A + B + D)/3$ | 3D average |

*Note: The specific geometric mapping of A-H to spatial neighbors is defined in the source's Figure 2 [S1]. For implementation, standard 3D neighbors (left, above, previous slice) are used where applicable.*

**Algorithm Steps:**

1.  **Transform Construction:**
    Apply the 3D-DWT with RDLS and Step Skipping to the input volume $V$. The RDLS filters and skipped steps are selected using a heuristic (see [Adaptive Transform Construction Heuristic](11258-adaptive-transform-construction-heuristic.md)) to minimize estimated bitrate [S1].

2.  **Subband Iteration:**
    For each final subband $S$ produced by the transform:
    
    a. **Entropy Estimation:**
       For each candidate predictor $P$ in the predictor set:
       1.  Compute the prediction error $e_i = v_i - \hat{v}_i$ for all samples $i$ in subband $S$, where $\hat{v}_i$ is the prediction using $P$.
       2.  Handle boundary conditions: If a predictor cannot be computed for a voxel (e.g., neighbors are out of bounds), use the NOP predictor for that voxel [S1].
       3.  Calculate the memoryless entropy $H_P$ of the errors:
           $$ H_P = -\sum_{i=\text{MinPE}}^{\text{MaxPE}} p_i \log_2(p_i) $$
           where $M$ is the number of samples in the subband, $\text{MinPE}$ and $\text{MaxPE}$ are the smallest and greatest prediction errors, $p_i$ is the probability of error $i$ occurring in the subband, and $0 \log_2 0 = 0$ [S1].

    b. **Predictor Selection:**
       Select the predictor $P_{best}$ that yields the minimum entropy $H_P$. If all actual predictors result in higher entropy than NOP, select NOP [S1].

    c. **Residual Encoding:**
       Compute the residuals $d_i = v_i - \hat{v}_i$ using $P_{best}$ and entropy-code them (e.g., using JPEG 2000's MQ coder) [S1].

3.  **Reconstruction:**
    The decoder applies the inverse RDLS-SS-DWT transform to the entropy-decoded residuals, then applies the inverse prediction $v_i = \hat{v}_i + d_i$ in raster scan order to recover the original volume [S1].

**Pseudocode:**

```python
def rdls_ss_dwt_plus_pred(volume, decomposition_level=3):
    """
    Applies RDLS-SS-DWT followed by predictive coding to a 3D volume.
    volume: 3D numpy array or similar structure [D, H, W]
    decomposition_level: int, fixed at 3 for experiments [S1]
    """
    # Step 1: Apply RDLS-SS-DWT transform
    # The heuristic for filter/step selection is delegated to the 
    # Adaptive Transform Construction Heuristic [S1].
    subbands = apply_rdls_ss_dwt(volume, decomposition_level)
    
    # Candidate predictors defined in source Table 1 [S1]
    # Note: Geometric mapping of neighbors (A, B, C...) is from source Figure 2 [S1]
    predictors = [
        PredictorNOP(),
        PredictorPX(),
        PredictorPY(),
        PredictorPZ(),
        PredictorAVGXY(),
        PredictorAVGXZ(),
        PredictorAVGYZ(),
        PredictorMEDXY(),
        PredictorMEDXZ(),
        PredictorMEDYZ(),
        PredictorAVG3D()
    ]
    
    encoded_subbands = {}
    
    # Step 2: Process each final subband
    for subband_name, subband_data in subbands.items():
        best_predictor = None
        min_entropy = float('inf')
        best_residuals = None
        
        # Step 2a: Evaluate each predictor
        for pred in predictors:
            # Compute residuals handling boundaries
            residuals = compute_residuals_with_boundary_check(subband_data, pred)
            
            # Step 2b: Calculate memoryless entropy
            entropy = calculate_memoryless_entropy(residuals)
            
            if entropy < min_entropy:
                min_entropy = entropy
                best_predictor = pred
                best_residuals = residuals
        
        # Step 2c: Encode best residuals
        # In practice, this involves histogram packing and entropy coding (e.g., MQ coder) [S1]
        encoded_subbands[subband_name] = entropy_encode(best_residuals)
        
    return encoded_subbands

def compute_residuals_with_boundary_check(data, predictor):
    """
    Computes residuals, falling back to NOP if predictor fails at boundaries.
    """
    residuals = np.zeros_like(data)
    for z in range(data.shape[0]):
        for y in range(data.shape[1]):
            for x in range(data.shape[2]):
                try:
                    prediction = predictor.predict(data, z, y, x)
                    residuals[z, y, x] = data[z, y, x] - prediction
                except BoundaryError:
                    # Fallback to NOP (predicts 0) [S1]
                    residuals[z, y, x] = data[z, y, x]
    return residuals

def calculate_memoryless_entropy(residuals):
    """
    H = - sum(p_i * log2(p_i))
    0 * log2(0) = 0 [S1]
    """
    # Count occurrences of each error value
    unique, counts = np.unique(residuals, return_counts=True)
    total_samples = len(residuals)
    
    entropy = 0.0
    for count in counts:
        if count > 0:
            p_i = count / total_samples
            if p_i > 0:
                entropy -= p_i * np.log2(p_i)
    return entropy
```

## Subtopics

### [Adaptive Transform Construction Heuristic](11258-adaptive-transform-construction-heuristic.md)
A greedy parameter selection method for the RDLS-SS-DWT transform. It selects denoising filters for RDLS subbands and predictors for the final subbands to minimize the estimated bitrate of the compressed volume. It differs from exhaustive search by using a fast entropy estimation to approximate JP3D bitrate, allowing image-adaptive configuration without prohibitive computational cost.

## Operating characteristics
*   **Time Complexity:** The transform involves 3D DWT with lifting steps and prediction. The heuristic selection of filters and predictors adds overhead. Entropy coding is noted as the slowest part of the JP3D pipeline [S1].
*   **Memory Complexity:** Requires storage for the volume and subbands. No significant additional memory beyond standard DWT buffers.
*   **Performance:** In experiments on medical images (CT, MRI, US), RDLS-SS-DWT+Pred showed bitrate improvements over standard DWT ranging from -0.175% to -8.973% (negative indicates reduction) [S1]. The improvement is particularly significant for MRI1 [S1].
*   **Comparison with SS-DWT+Pred:** The bitrate difference between RDLS-SS-DWT+Pred and SS-DWT+Pred is very small [S1]. This suggests that using actual denoising filters in RDLS (filters other than Null and None) may be avoided without sacrificing bitrate improvements, as SS-DWT+Pred yields similar results [S1].
*   **Strengths:** Significant compression ratio improvement for medical images; adaptive to image characteristics via heuristic.
*   **Limitations:** Heuristic selection can be suboptimal for some images; entropy coding is computationally expensive [S1].

## Background
The method was proposed in 2020 by researchers from Vrije Universiteit Brussel (VUB) and Interdisciplinary Institute for BroadBand Technology (IBBT) [S1]. It builds on previous work generalizing 2D-DWT variants to 3D using step skipping [S1]. The initial phase of the research was presented in a conference report [S1]. The implementation is available as a patch to IRIS-JP3D [S1].
