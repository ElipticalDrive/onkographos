# RDLS-SS-DWT+Pred

Also called: Hybrid Transform, Reversible Denoising Lifting Steps with Step Skipping and Prediction

## Overview
RDLS-SS-DWT+Pred is a lossless compression method for volumetric data that combines a modified 3D Discrete Wavelet Transform (DWT) with predictive coding [S1]. It solves the problem of high entropy in wavelet subbands by applying spatial prediction to the final subbands generated by Reversible Denoising Lifting Steps (RDLS) with Step Skipping (SS) [S1]. Unlike standard DWT, it uses RDLS to reduce noise and SS to skip redundant lifting steps, while the added prediction layer further decorrelates the data, particularly when Null filters are used in the RDLS stage [S1]. It differs from its sibling [SS-DWT+Pred](5256-residual-updates-in-transform-domain.md) by including the RDLS denoising phase, though sources indicate that skipping RDLS (using SS-DWT+Pred) yields very similar bitrate improvements with lower computational cost [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D volumetric image $V$ with dimensions $W \times H \times D$.
*   **Output:** A compressed bitstream (typically formatted for JP3D) representing the transformed and predicted coefficients.

**Data Structures:**
*   **Subbands:** The 3D DWT decomposition produces multiple subbands. The method operates specifically on the "final subbands" (the highest frequency detail subbands at the deepest decomposition level).
*   **Prediction Errors:** The difference between the actual sample value and the predicted value.

**Parameters:**
*   **Decomposition Level:** Set to 3 levels in all reported experiments [S1].
*   **RDLS Filters:** Selectors for denoising filters. Sources note that using "Null" filters (effectively disabling RDLS) is sufficient, as RDLS-SS-DWT+Pred and SS-DWT+Pred yield similar results [S1].
*   **Step Skipping:** Selectors for which lifting steps to skip in the DWT lattice [S1].
*   **Predictor Set:** A set of candidate spatial predictors (see Table 1 below) [S1].

**Candidate Predictors:**
The following predictors are available. $A, B, C, D, E, F, G, H$ represent neighboring voxel values relative to the current voxel $P$ being predicted. The prediction is performed in raster scan order: volume slices from front to back, slice rows from top to bottom, pixels in a row from left to right [S1]. If a neighbor is out of bounds, a simpler predictor (e.g., NOP) is used [S1].

| Predictor | Formula | Neighbors Required |
| :--- | :--- | :--- |
| NOP | $0$ | None |
| $P_X$ | $A$ | Left neighbor |
| $P_Y$ | $B$ | Top neighbor |
| $P_Z$ | $C$ | Front neighbor |
| $AVG\_XY$ | $(A + B) / 2$ | Left, Top |
| $AVG\_XZ$ | $(A + C) / 2$ | Left, Front |
| $AVG\_YZ$ | $(B + C) / 2$ | Top, Front |
| $MED\_XY$ | $\text{median}(A, B, A + B - C)$ | Left, Top, Front |
| $MED\_XZ$ | $\text{median}(A, D, A + D - E)$ | Left, Front, Back |
| $MED\_YZ$ | $\text{median}(B, D, B + D - F)$ | Top, Front, Back |
| $AVG3D$ | $(A + B + D) / 3$ | Left, Top, Back |

*(Note: Neighbor positions A-H correspond to standard 3D spatial neighbors: A=Left, B=Top, C=Front, D=Back, E=Right, F=Bottom, G=Top-Front, H=Bottom-Front, etc., as implied by the formulas and standard raster order [S1].)*

**Algorithm Steps:**

1.  **Transform Construction:**
    Apply the RDLS-SS-DWT transform to the volume $V$.
    *   Apply RDLS (Reversible Denoising Lifting Steps) using selected filters.
    *   Apply Step Skipping (SS) to skip specific lifting steps in the DWT decomposition.
    *   Perform a 3-level 3D DWT decomposition [S1].

2.  **Predictor Selection (Heuristic):**
    For each final subband:
    *   Iterate through the set of candidate predictors.
    *   For each candidate predictor, compute the prediction errors for all samples in the subband.
    *   Compute the memoryless entropy $H$ of the prediction errors for each candidate.
    *   Select the predictor that yields the minimum entropy $H_{min}$.
    *   If all actual predictors result in higher entropy than NOP, select NOP [S1].

    The memoryless entropy $H$ is calculated as:
    $$ H = -\sum_{i=MinPE}^{MaxPE} p_i \log_2(p_i) $$
    Where:
    *   $M$ is the number of samples in the subband.
    *   $MinPE$ and $MaxPE$ are the smallest and greatest prediction errors, respectively.
    *   $p_i$ is the probability of occurrence of prediction error $i$.
    *   $0 \log_2 0 = 0$ [S1].

3.  **Prediction Application:**
    Apply the selected predictor to the final subbands.
    *   Traverse the subband in raster scan order (slices front-to-back, rows top-to-bottom, pixels left-to-right) [S1].
    *   For each voxel, compute the predicted value using the selected formula.
    *   Compute the prediction error: $Error = Voxel - PredictedValue$.
    *   Replace the original voxel value with the prediction error in the data structure [S1].
    *   **Edge Case:** If a predictor requires a neighbor that is out of bounds (e.g., predicting the front-top-left voxel with a predictor requiring left/top/front neighbors), fall back to a simpler predictor (e.g., NOP) for that specific voxel [S1].

4.  **Entropy Encoding:**
    Encode the transformed and predicted coefficients using an entropy coder (e.g., JP3D/Huffman/Arithmetic) [S1].

**Pseudocode:**

```python
def rdls_ss_dwt_plus_pred(volume, decomposition_level=3):
    """
    Compress a 3D volume using RDLS-SS-DWT+Pred.
    volume: 3D numpy array or similar structure (W x H x D)
    """
    # Step 1: Transform
    # Apply RDLS with Null filters (or selected filters) and Step Skipping
    # Then apply 3D DWT decomposition
    subbands = apply_rdls_ss_dwt(volume, filters='null', steps='skip', level=decomposition_level)
    
    # Identify final subbands (highest frequency detail subbands)
    final_subbands = get_final_subbands(subbands)
    
    # Step 2 & 3: Predictive Coding
    for subband in final_subbands:
        # Get all candidate predictors
        candidates = [NOP, P_X, P_Y, P_Z, AVG_XY, AVG_XZ, AVG_YZ, MED_XY, MED_XZ, MED_YZ, AVG3D]
        
        best_predictor = None
        min_entropy = infinity
        
        for predictor in candidates:
            # Compute prediction errors for the entire subband
            errors = compute_prediction_errors(subband, predictor)
            
            # Compute memoryless entropy of errors
            entropy = compute_memoryless_entropy(errors)
            
            if entropy < min_entropy:
                min_entropy = entropy
                best_predictor = predictor
        
        # Apply the best predictor to the subband
        apply_predictor_to_subband(subband, best_predictor)
        
    # Step 4: Entropy Encoding
    # Encode the modified subbands using JP3D or similar entropy coder
    bitstream = entropy_encode(subbands)
    
    return bitstream

def compute_prediction_errors(subband, predictor):
    """
    Compute prediction errors for a subband using a specific predictor.
    Handles boundary conditions by falling back to NOP if neighbors are missing.
    """
    errors = create_empty_array_like(subband)
    W, H, D = subband.shape
    
    for z in range(D):
        for y in range(H):
            for x in range(W):
                # Get neighbors based on predictor requirements
                # If neighbor is out of bounds, use NOP fallback logic implicitly
                # by checking bounds before accessing
                predicted_value = predictor.predict(subband, x, y, z)
                actual_value = subband[x, y, z]
                errors[x, y, z] = actual_value - predicted_value
                
    return errors

def compute_memoryless_entropy(errors):
    """
    Compute H = -sum(p_i * log2(p_i)) for prediction errors.
    """
    # Count occurrences of each error value
    error_counts = histogram(errors)
    total_samples = sum(error_counts.values())
    
    entropy = 0.0
    for error_val, count in error_counts.items():
        if count > 0:
            p_i = count / total_samples
            if p_i > 0:
                entropy -= p_i * math.log2(p_i)
                
    return entropy
```

## Subtopics

### [Adaptive Transform Construction Heuristic](11258-adaptive-transform-construction-heuristic.md)
A greedy parameter selection method for the RDLS-SS-DWT+Pred transform. It selects denoising filters for RDLS subbands and predictors for the final subbands to minimize the estimated bitrate of the compressed volume. It differs from exhaustive search by using a fast entropy estimation to approximate JP3D bitrate, allowing image-adaptive configuration without prohibitive computational cost.

## Operating characteristics
*   **Complexity:** The method involves a 3D DWT decomposition, RDLS steps, and per-subband entropy calculations for predictor selection. The entropy calculation is $O(N)$ per subband per predictor, where $N$ is the number of samples. With multiple predictors, this adds a constant factor overhead during compression. Decompression is linear with respect to the number of coefficients.
*   **Performance:** In experiments on medical images (CT, MRI, US), RDLS-SS-DWT+Pred achieved bitrate reductions compared to standard DWT. For example, on image MRI1, it achieved an 8.973% bitrate reduction [S1]. The improvement over SS-DWT+Pred is very small, suggesting RDLS adds little benefit for bitrate but increases complexity [S1].
*   **Strengths:** Effective for lossless compression of volumetric medical images. Combines the noise reduction benefits of RDLS (if used) with the decorrelation benefits of prediction.
*   **Limitations:** The heuristic selection of filters and predictors adds compression time. The benefit of RDLS is marginal compared to SS-DWT+Pred, making the full RDLS-SS-DWT+Pred potentially less efficient than SS-DWT+Pred for the same bitrate [S1].
*   **When to use:** When lossless compression of 3D medical volumes is required and JP3D compatibility is needed.
*   **When not to use:** When compression speed is critical and the marginal bitrate gain of RDLS is not worth the computational cost; SS-DWT+Pred is preferred in this case [S1].

## Background
The method was proposed in 2020 by researchers from Vrije Universiteit Brussel (VUB) and Interdisciplinary Institute for BroadBand Technology (IBBT) [S1]. It builds on previous work in 2D image compression using step skipping and reversible denoising lifting steps [S1]. The initial phase of the research was presented in a conference report [S1]. The method is implemented as a patch to IRIS-JP3D [S1].
