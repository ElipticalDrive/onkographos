# Residual Coding for Volumetric Compression

Also called: Residual Coding

## Overview
Residual coding is a technique to improve the compression performance (reconstructed image quality) of volumetric data by encoding the difference between the original image and the direct reconstructed image from the volume without quantization or coding [S1]. It does not contribute to view synthesis quality and may deteriorate it [S1]. Unlike standard video codecs where residuals change with bitrate, here the residuals are derived from the unquantized volume reconstruction, making them similar across all bitrates [S1].

## How it works
**Inputs:** Original image data $I_{orig}$, and a reconstructed volume $V$ (constructed from reference views) which can be directly rendered to produce a reconstructed image $I_{recon}$ without quantization or entropy coding [S1].
**Outputs:** A bitstream containing the encoded volume data and the encoded residuals [S1].

**Data Structures:**
The method operates on a per-view basis. For each view, a residual map is computed. The residuals are encoded alongside the volume data. In open-loop operation, the same residuals are coded for all bitrates to preserve scalability [S1].

**Steps:**
1.  **Volume Construction:** Construct the volume using information from reference views [S1].
2.  **Direct Reconstruction:** Render the volume to obtain the reconstructed image $I_{recon}$ for each view. This step is performed without quantization or coding [S1].
3.  **Residual Calculation:** Calculate the residual $R$ for each view as the difference between the original image $I_{orig}$ and the direct reconstructed image $I_{recon}$:
    $$ R = I_{orig} - I_{recon} $$
    [S1]
4.  **Encoding:** Encode the residuals alongside the volume data. The residuals are encoded in a way that allows scalable decoding (e.g., significant parts first) [S1].
5.  **Decoding:** At the decoder, select the quality of the volume first. Then, decode parts of the residual bitstream until the target bitrate is obtained [S1].

**Parameters:**
*   **Bitrate thresholds for residual application:** Residuals are employed at bitrates higher than those where view synthesis quality drops below lossless quality by specific thresholds: -0.05 dB, -0.1 dB, or -0.5 dB [S1].
    *   -0.5 dB represents applications where views at original camera positions are significant [S1].
    *   -0.05 dB represents applications where good quality of virtual views is more essential (e.g., 3D rendering, look-around, free-view point) [S1].

**Edge Cases and Pitfalls:**
*   **View Synthesis Degradation:** Residuals do not greatly improve reconstructed image quality at low bitrates but significantly exacerbate the quality of view synthesis [S1]. View synthesis performance can degrade up to 0.1 dB at high bitrate when residuals are added [S1].
*   **Suboptimal Compression:** The highest compression performance cannot be achieved by choosing the low-quality decoded volume because residuals are obtained from the original volume, not directly from reconstructed images at each particular bitrate [S1].
*   **Scalability Constraint:** Because residuals are derived from the unquantized volume reconstruction, the residuals encoded at all bitrates are similar, unlike residuals in MPEG standard video codecs [S1].

**Pseudocode:**
```python
def compute_residuals(original_images, volume):
    """
    Computes residuals for each view by comparing original images
    to direct reconstructions from the volume.
    
    Args:
        original_images: List of original image arrays for each view.
        volume: The volumetric data structure.
        
    Returns:
        List of residual arrays for each view.
    """
    residuals = []
    for img in original_images:
        # Direct reconstruction without quantization or coding
        recon_img = render_volume_directly(volume)
        residual = img - recon_img
        residuals.append(residual)
    return residuals

def decode_with_scalability(volume_bitstream, residual_bitstream, target_bitrate):
    """
    Decodes volume and partial residuals to meet target bitrate.
    
    Args:
        volume_bitstream: Encoded volume data.
        residual_bitstream: Encoded residuals (ordered by significance).
        target_bitrate: Desired total bitrate.
        
    Returns:
        Reconstructed image.
    """
    # 1. Decode volume quality first
    volume_quality = select_volume_quality(volume_bitstream)
    decoded_volume = decode_volume(volume_bitstream, volume_quality)
    
    # 2. Decode residual parts until target bitrate is reached
    remaining_bitrate = target_bitrate - bitrate_of_decoded_volume
    decoded_residuals = decode_residuals_partial(residual_bitstream, remaining_bitrate)
    
    # 3. Reconstruct final image
    # Note: In the source context, the residual is added to the 
    # direct reconstruction of the decoded volume.
    direct_recon = render_volume_directly(decoded_volume)
    final_image = direct_recon + decoded_residuals
    
    return final_image
```

## Operating characteristics
*   **Compression Performance:** Residual coding enhances compression performance. For example, at 0.42 bpv with a -0.5 dB acceptable quality criterion, the method achieves the same PSNR (34 dB) as higher bitrate methods (0.68 bpv and 0.56 bpv) but with lower bitrate [S1].
*   **View Synthesis Quality:** The method may deteriorate view synthesis quality. At high bitrates, view synthesis quality can degrade up to 0.1 dB when residuals are added [S1].
*   **Scalability:** The method supports scalability in open-loop operation. The same residuals are coded for all bitrates, allowing the decoder to select volume quality and then add residual bits up to a target bitrate [S1].
*   **Strengths:** Improves reconstructed image quality, particularly correcting errors at edges and loss of high frequencies due to bitstream truncation [S1]. Allows achieving acceptable PSNR at lower bitrates [S1].
*   **Limitations:** Does not contribute to view synthesis quality and can degrade it [S1]. Highest compression performance is not achieved if low-quality volumes are chosen because residuals are fixed to the original volume [S1].

## Background
Residual coding for volumetric compression was investigated in the context of improving compression performance for realistic view synthesis applications [S1]. The technique was evaluated using volumes constructed from five reference views [S1]. The study highlighted the trade-off between reconstructed image quality and view synthesis quality, noting that residuals improve the former but may harm the latter [S1].
