# Closed-Loop DPCM Decompression

Also called: TraceBlockCodec.decompress

## Overview
Closed-Loop DPCM Decompression reconstructs volumetric trace data from compressed payloads by using the previously reconstructed sample to predict the current sample, thereby preventing error accumulation [S1, unofficial]. It distinguishes itself from open-loop methods by ensuring the decoder's prediction state matches the encoder's, which is critical for maintaining fidelity in lossy quantization scenarios [S1, unofficial].

## How it works
**Inputs:** A `CompressedTraceBlock` object containing a payload, metadata (minimum and maximum values), and sample count.
**Outputs:** A `TraceBlock` containing the reconstructed floating-point samples.

**Data Structures:**
*   `CompressedTraceBlock`: Contains `payload` (binary data), `samplesPerTrace` (integer $n$), `min` (float), `max` (float), and `traceId`.
*   `ClosedLoopQuantizer`: Helper object providing methods to determine bit depth, unpack quantized integers, and reconstruct floating-point values.

**Steps:**
1.  **Check Mode:** Determine if the payload uses closed-loop quantization. If `ClosedLoopQuantizer.isClosedLoop(cb.payload())` returns false, the method falls back to legacy decompression [S1, unofficial].
2.  **Initialize Parameters:**
    *   Let $n$ be the number of samples per trace (`cb.samplesPerTrace()`).
    *   Let $b$ be the number of stored bits (`ClosedLoopQuantizer.storedBits(cb.payload())`).
    *   Compute the inverse quantization scale factor: $inv = \frac{1.0}{2^b - 1}$ [S1, unofficial]. *Note: The source code uses `maxQ(bits)` which typically corresponds to the maximum value representable by $b$ bits.*
    *   Initialize the previous reconstructed value $prev = 0.0$.
3.  **Unpack and Reconstruct:**
    *   Unpack the quantized integer residuals $q_0, q_1, \dots, q_{n-1}$ from the payload using `ClosedLoopQuantizer.unpack`.
    *   For each sample index $i$ from $0$ to $n-1$:
        *   Reconstruct the normalized value: $norm_i = \text{ClosedLoopQuantizer.reconstruct}(prev, q_i, inv)$.
        *   Update the prediction state: $prev = norm_i$.
        *   Store $norm_i$ in the output array.
4.  **Denormalize:**
    *   Map the normalized values from the range $[-1, 1]$ to the original data range $[min, max]$ using `Preprocessing.denormalizeFromMinusOneToOne`.
    *   Formula: $V_{rec} = \frac{norm_i + 1}{2} \times (max - min) + min$.
5.  **Return:** Construct and return a new `TraceBlock` with the denormalized samples and the original `traceId`.

**Pseudocode:**
```python
def decompress_closed_loop(cb):
    # 1. Check if payload is closed-loop
    if not ClosedLoopQuantizer.is_closed_loop(cb.payload):
        return decompress_legacy(cb)

    # 2. Get parameters
    n = cb.samples_per_trace
    bits = ClosedLoopQuantizer.stored_bits(cb.payload)
    max_q = (1 << bits) - 1  # Maximum quantized value for 'bits' bits
    inv = 1.0 / max_q
    
    # 3. Unpack quantized values
    q = ClosedLoopQuantizer.unpack(cb.payload, n)
    
    # 4. Reconstruct samples
    prev = 0.0
    norm = []
    for i in range(n):
        # Reconstruct normalized value based on previous reconstructed value
        # The specific reconstruction logic depends on ClosedLoopQuantizer.reconstruct
        # Assuming it performs: prev + (q[i] * inv) or similar differential decoding
        current_norm = ClosedLoopQuantizer.reconstruct(prev, q[i], inv)
        prev = current_norm
        norm.append(current_norm)
        
    # 5. Denormalize to original scale
    min_val = cb.min()
    max_val = cb.max()
    samples = []
    for val in norm:
        # Map [-1, 1] to [min_val, max_val]
        sample = ((val + 1.0) / 2.0) * (max_val - min_val) + min_val
        samples.append(sample)
        
    return TraceBlock(trace_id=cb.trace_id, samples=samples)
```

## Subtopics

### Legacy Decompression
Decompresses payloads written before the closed-loop revision, supporting raw zlib streams, open-loop delta encoding, and 16-bit quantization for backward compatibility with `.sdc` v2 files [S1, unofficial]. It inflates the payload, converts bytes to shorts, decodes deltas using `LinearQuantizer`, delta-decodes the normalized values, and denormalizes them [S1, unofficial]. A critical pitfall is that files compressed with fewer than 16 bits by the legacy version cannot be decoded correctly because the bit depth was never stored in the file format [S1, unofficial].

## Operating characteristics
Time complexity is linear with respect to the number of samples $n$ in the trace. Memory complexity is linear for storing the output samples. The method is efficient for real-time decompression as it avoids complex transform inversions, relying instead on simple arithmetic and lookup operations. It is suitable for seismic data where trace-by-trace processing is standard.

## Background
This method is part of the SeismicDataCompressor project, an unofficial implementation for compressing seismic data [S1, unofficial]. It was introduced to replace or supplement legacy open-loop DPCM methods to improve reconstruction accuracy in lossy scenarios by synchronizing encoder and decoder states.
