# Closed-Loop DPCM Decompression

Also called: TraceBlockCodec.decompress

## Overview
Closed-Loop DPCM Decompression reconstructs volumetric trace data from compressed payloads by reversing a predictive coding scheme that uses the decoder's own reconstructed values to prevent error accumulation [S1, unofficial]. It distinguishes itself from open-loop variants by ensuring that the prediction for the current sample is based on the previously *decoded* sample rather than the original ground truth, thereby containing quantization errors [S1, unofficial]. It serves as the primary decoder for modern `.sdc` file formats, falling back to legacy methods for older files [S1, unofficial].

## How it works
**Inputs:** A `CompressedTraceBlock` object containing a payload, metadata (trace ID, sample count, min/max values), and bit-depth information.
**Outputs:** A `TraceBlock` object containing the reconstructed floating-point samples.

**Data Structures:**
*   `CompressedTraceBlock`:
    *   `payload`: Binary data containing the compressed residuals and quantization parameters.
    *   `traceId`: Identifier for the trace.
    *   `samplesPerTrace` ($n$): Number of samples in the trace.
    *   `min()`, `max()`: Original data range for denormalization.
*   `ClosedLoopQuantizer`: Helper object providing methods to inspect and decode quantization parameters.
*   `Preprocessing`: Helper object for normalization/denormalization.

**Steps:**

1.  **Format Verification:** Check if the payload conforms to the closed-loop format using `ClosedLoopQuantizer.isClosedLoop(cb.payload())`. If the check fails, the method delegates to the legacy decompression routine and returns [S1, unofficial].
2.  **Parameter Extraction:**
    *   Retrieve the number of samples: $n = \text{cb.samplesPerTrace()}$.
    *   Retrieve the stored bit depth: $\text{bits} = \text{ClosedLoopQuantizer.storedBits}(\text{cb.payload()})$.
    *   Compute the inverse quantization scale factor: $inv = \frac{1.0}{\text{ClosedLoopQuantizer.maxQ}(\text{bits})}$.
3.  **Closed-Loop Reconstruction:**
    *   Initialize the previous reconstructed value: $prev = 0.0$.
    *   For each sample index $i$ from $0$ to $n-1$:
        *   Extract the quantized residual $q_i$ from the payload using `ClosedLoopQuantizer.unpack(cb.payload(), n)`.
        *   Reconstruct the normalized value using the closed-loop formula:
            $$
            prev = \text{ClosedLoopQuantizer.reconstruct}(prev, q_i, inv)
            $$
            *Note: The exact implementation of `reconstruct` maps the quantized integer $q_i$ and the previous float $prev$ back to the current float value using the inverse scale $inv$. In standard DPCM, this typically implies $prev_{new} = prev_{old} + q_i \times inv$ or a similar linear mapping depending on the specific quantizer definition [G].*
        *   Store the result: $norm[i] = prev$.
4.  **Denormalization:**
    *   Map the normalized values $norm$ from the $[-1, 1]$ range back to the original data range $[min, max]$ using `Preprocessing.denormalizeFromMinusOneToOne(norm, cb.min(), cb.max())`.
5.  **Return:** Construct and return a new `TraceBlock` with the `traceId` and the denormalized samples.

**Pseudocode:**

> **Unverified code.** The code below did not pass a test run against a reference implementation, or no test fits it, so it may contain errors.

```python
def decompress_closed_loop(cb):
    # Step 1: Check format
    if not ClosedLoopQuantizer.isClosedLoop(cb.payload):
        return decompress_legacy(cb)

    # Step 2: Extract parameters
    n = cb.samplesPerTrace()
    bits = ClosedLoopQuantizer.storedBits(cb.payload)
    max_q = ClosedLoopQuantizer.maxQ(bits)
    inv = 1.0 / max_q
    
    # Step 3: Closed-loop reconstruction
    prev = 0.0
    norm = []
    
    for i in range(n):
        # Unpack quantized residual for current sample
        q_i = ClosedLoopQuantizer.unpack(cb.payload, n, index=i)
        
        # Reconstruct using previous decoded value (closed-loop)
        # Implementation detail: reconstruct typically adds the scaled residual to the previous value
        prev = prev + (q_i * inv)
        
        norm.append(prev)

    # Step 4: Denormalize
    min_val = cb.min()
    max_val = cb.max()
    
    # Map from [-1, 1] to [min_val, max_val]
    denormalized = []
    for val in norm:
        # Standard linear denormalization from [-1, 1] to [min, max]
        # y = (x + 1) * (max - min) / 2 + min
        original_val = (val + 1.0) * (max_val - min_val) / 2.0 + min_val
        denormalized.append(original_val)

    return TraceBlock(traceId=cb.traceId, samples=denormalized)
```

**Edge Cases and Pitfalls:**
*   **Legacy Compatibility:** If the payload was not generated by the closed-loop encoder, `isClosedLoop` returns false. The method must handle this gracefully by calling the legacy decoder [S1, unofficial].
*   **Initialization:** The initial `prev` value is set to 0.0. This assumes the first sample's prediction is based on zero or that the first residual is encoded relative to zero [G].
*   **Precision:** The use of floating-point arithmetic for `prev` accumulation may introduce minor precision drift over very long traces, though the inverse quantization scale helps mitigate this [G].

## Subtopics

### Legacy Decompression
Decompresses payloads written before the closed-loop revision, supporting raw zlib streams, open-loop delta coding, and 16-bit quantization [S1, unofficial]. It is retained for backward compatibility with `.sdc` v2 files [S1, unofficial]. The process involves inflating the payload, converting bytes to shorts, decoding deltas using `LinearQuantizer.decode`, applying delta decoding via `Preprocessing.deltaDecode`, and finally denormalizing [S1, unofficial]. A critical pitfall is that files compressed with fewer than 16 bits by the legacy version cannot be decoded correctly because the bit depth was never stored in the file header [S1, unofficial].

## Operating characteristics
**Time Complexity:** Linear with respect to the number of samples $n$, $O(n)$, as each sample is processed sequentially with constant-time arithmetic operations [S1, unofficial].
**Memory Complexity:** $O(n)$ to store the output samples and intermediate normalized values [S1, unofficial].
**Strengths:** Prevents error accumulation inherent in open-loop prediction by using reconstructed values for subsequent predictions [S1, unofficial]. Efficient for seismic data traces where samples are highly correlated [S1, unofficial].
**Limitations:** Requires the bit depth to be stored in the payload for correct reconstruction [S1, unofficial]. Not backward compatible with legacy files without a fallback mechanism [S1, unofficial].
**When to use:** When decompressing modern `.sdc` files that utilize the closed-loop quantizer [S1, unofficial].
**When not to use:** When processing legacy `.sdc` v2 files that lack closed-loop metadata; use Legacy Decompression instead [S1, unofficial].

## Background
The method is part of the Seismic Data Compressor project, which focuses on efficient compression of seismic trace data [S1, unofficial]. The closed-loop approach was introduced to address the error propagation issues found in earlier open-loop delta coding schemes [S1, unofficial]. It is implemented in the `TraceBlockCodec` class within the project's codebase [S1, unofficial].
