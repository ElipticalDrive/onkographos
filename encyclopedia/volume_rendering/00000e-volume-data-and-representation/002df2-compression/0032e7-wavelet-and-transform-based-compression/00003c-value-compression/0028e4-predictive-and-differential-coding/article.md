# Predictive and Differential Coding

Also called: Differential Pulse Code Modulation (DPCM), Linear Predictive Coding (LPC), Residual Coding

## Overview
Predictive and Differential Coding reduces volumetric data redundancy by encoding the difference (residual) between a voxel's actual value and a predicted value derived from its neighbors or reference frames, rather than encoding the absolute values [S1, unofficial]. It sets itself apart from transform-based methods (like [Wavelet and Transform-based Compression](52-wavelet-and-transform-based-compression.md)) by operating directly on spatial or temporal dependencies without requiring a global frequency decomposition, making it highly effective for data with strong local coherence [S1, unofficial][S2].

## Shared principles
All methods in this family share the mechanism of estimating a voxel's value $V_{pred}$ from previously processed neighbors or reference frames, computing a residual $R = V_{actual} - V_{pred}$, and encoding $R$ [S1, unofficial].

1.  **Prediction:** The core operation is generating $V_{pred}$ from a causal neighborhood (spatial) or a reference frame (temporal). The predictor can be fixed (e.g., previous value, zero) or adaptive (e.g., linear combination of neighbors, optimal coefficients derived from covariance) [S1, unofficial][S2].
2.  **Residual Calculation:** The residual $R$ is computed. In lossless contexts, $R$ is exact. In lossy contexts, $R$ may be quantized. The goal is to minimize the variance of $R$, concentrating its probability mass near zero [S1, unofficial].
3.  **Entropy Coding:** The residuals are encoded using entropy coding (Huffman, Arithmetic, or Range coding). Because residuals are typically small integers with a Laplacian-like distribution, they compress significantly better than raw values [S1, unofficial].
4.  **Closed-Loop vs. Open-Loop:** In temporal or iterative contexts, a closed-loop structure is often required where the decoder uses its *reconstructed* value (not the original) as the predictor for the next step to prevent error accumulation [S1, unofficial].

## Subtopics

### [Residual Coding for Volumetric Compression](6518-residual-coding-for-volumetric-compression.md)
Residual Coding improves the compression performance of a volumetric codec by encoding the difference between the original view images and the direct reconstruction of the volume without quantization or coding [6518-residual-coding-for-volumetric-compression.md]. Unlike standard video codecs where residuals are bitrate-dependent, this method encodes residuals derived from an unquantized reference, allowing the same residuals to be coded for all bitrates to preserve scalability [6518-residual-coding-for-volumetric-compression.md]. It is chosen when view synthesis quality must be preserved across scalable bitrates, though it may deteriorate view synthesis performance at high bitrates [6518-residual-coding-for-volumetric-compression.md].

### [Optimal Linear Volumetric Predictor with Truncated Huffman Coding](7759-optimal-linear-volumetric-predictor-with-truncated-huffman-c.md)
This method is a lossless compression algorithm for 3D volume data that exploits spatial coherence by predicting voxel values from previously encoded neighbors and encoding the difference using a truncated Huffman code [7759-optimal-linear-volumetric-predictor-with-truncated-huffman-c.md]. It derives optimal linear coefficients for each volume using the Yule-Walker equations, automatically compensating for non-isotropic voxel sampling, unlike fixed-coefficient predictors [7759-optimal-linear-volumetric-predictor-with-truncated-huffman-c.md]. It is chosen for medical volume datasets where isotropic or anisotropic spatial redundancy is high and lossless reconstruction is required [7759-optimal-linear-volumetric-predictor-with-truncated-huffman-c.md].

### [Lorenz Predictor with Arithmetic Coding](8070-lorenz-predictor-with-arithmetic-coding.md)
The Lorenz Predictor is a lossless compression method for $n$-dimensional scalar fields that estimates a voxel's value from its $2^n - 1$ immediate neighbors in a regular grid to generate residuals, which are then encoded using arithmetic coding [8070-lorenz-predictor-with-arithmetic-coding.md]. It is distinguished from anisotropic scanline predictors by being isotropic, exploiting data coherence in all dimensions, and is the simplest isotropic predictor capable of exactly reconstructing all polynomials of degree less than $n$ [8070-lorenz-predictor-with-arithmetic-coding.md]. It is chosen for regular grids where isotropic prediction is beneficial and arithmetic coding is available [8070-lorenz-predictor-with-arithmetic-coding.md].

### [RDLS-SS-DWT+Pred](11251-rdls-ss-dwt-pred.md)
RDLS-SS-DWT+Pred is a lossless volumetric compression transform that combines 3D Discrete Wavelet Transform (DWT) with predictive coding to minimize the entropy of the resulting coefficients [11251-rdls-ss-dwt-pred.md]. It operates by applying Reversible Denoising Lifting Steps (RDLS) with step skipping to a 3D-DWT, followed by spatial prediction on the final subbands [11251-rdls-ss-dwt-pred.md]. It differs from its sibling [SS-DWT+Pred](6518-ss-dwt-pred.md) by incorporating denoising filters in the lifting steps, though sources indicate that using actual denoising filters yields negligible bitrate improvements over skipping them entirely [11251-rdls-ss-dwt-pred.md]. It is chosen when transform-domain compression is preferred but entropy reduction via spatial prediction on subbands is needed [11251-rdls-ss-dwt-pred.md].

### [Closed-Loop DPCM Decompression](11737-closed-loop-dpcm-decompression.md)
Closed-Loop DPCM Decompression reconstructs volumetric trace data from compressed payloads by reversing a predictive coding scheme that uses the decoder's own reconstructed values to prevent error accumulation [11737-closed-loop-dpcm-decompression.md]. It distinguishes itself from open-loop variants by ensuring that the prediction for the current sample is based on the previously *decoded* sample rather than the original ground truth, thereby containing quantization errors [11737-closed-loop-dpcm-decompression.md]. It serves as the primary decoder for modern `.sdc` file formats, falling back to legacy methods for older files [11737-closed-loop-dpcm-decompression.md].

### [Spatial Predictive Coding](12623-spatial-predictive-coding.md)
Spatial Predictive Coding reduces information redundancy in voxel grids by exploiting statistical dependence between spatially adjacent samples, analogous to adjacent pixel correlation in images [12623-spatial-predictive-coding.md]. It sets itself apart from sibling methods by constructing a reference graph to select the optimal neighbor via Sum of Absolute Differences (SAD) and by performing quantization *before* prediction to improve parallelism [12623-spatial-predictive-coding.md]. Unlike methods that predict raw values, this approach operates specifically on quantized feature vectors, calculating residuals from quantized references [12623-spatial-predictive-coding.md]. It is chosen for feature-rich volumes (e.g., color/RGB) where spatial correlation is strong [12623-spatial-predictive-coding.md].

### [Temporal Prediction](12644-temporal-prediction.md)
Temporal prediction exploits the high degree of coherence between consecutive time steps in dynamic volume data to reduce redundancy. It solves the problem of encoding time-varying volumes by estimating the current voxel's value from previously processed reference frames, encoding only the residual difference [12644-temporal-prediction.md]. It sets itself apart from spatial predictors like [Spatial Predictive Coding](12623-spatial-predictive-coding.md) by leveraging temporal rather than spatial locality, and from transform-domain methods like [Residual Updates in Transform Domain](5256-residual-updates-in-transform-domain.md) by operating directly on spatial voxel values in its simplest form [12644-temporal-prediction.md]. It is chosen for time-varying datasets where inter-frame correlation is high [12644-temporal-prediction.md].

## Background
Predictive coding has its roots in early digital signal processing and image compression standards. Differential Pulse Code Modulation (DPCM) was introduced in the 1960s for audio and image compression [S1, unofficial]. In the context of volumetric data, linear predictive coding has been applied to medical imaging and holographic displays. For instance, directional linear predictive coding was proposed for lossless compression of hologram interference patterns, achieving a compression rate of 26.7% by selecting the direction of minimum entropy [S1, unofficial]. JPEG-LS, an older JPEG standard variant, has also been tested for 3D medical data, providing the best compression for certain datasets like ANGIO but lacking quality scalability [S2]. More recent developments include the Lorenz predictor for isotropic $n$-dimensional fields and closed-loop DPCM for modern trace data formats [S1, unofficial].
