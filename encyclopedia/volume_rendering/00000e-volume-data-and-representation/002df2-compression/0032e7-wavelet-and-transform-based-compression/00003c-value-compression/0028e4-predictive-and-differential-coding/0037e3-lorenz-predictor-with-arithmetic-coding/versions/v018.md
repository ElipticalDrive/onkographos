# Lorenz Predictor with Arithmetic Coding

Also called: Lorenzo, Lorenz预测与算术编码, n-dimensional Lorenzo predictor, n-dimensional parallelogram predictor

## Overview
The Lorenz Predictor with Arithmetic Coding is a lossless compression method for $n$-dimensional scalar fields that estimates a sample's value from its $2^n - 1$ immediate neighbors in a regular grid to generate residuals, which are then encoded using arithmetic coding [S1, unofficial]. It is distinguished from anisotropic scanline predictors by being isotropic, exploiting data coherence in all dimensions, and is the simplest isotropic predictor capable of exactly reconstructing all polynomials of degree less than $n$ [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** An $n$-dimensional scalar field $F$ defined on a grid with dimensions $D_1 \times D_2 \times \dots \times D_n$.
*   **Output:** A bitstream representing the compressed residuals.

**Data Structures:**
*   **Footprint Buffer:** A circular FIFO buffer storing the values of the "footprint" (the $2^n - 1$ neighbors required for prediction). The size of the buffer in $R^n$ is $\prod_{i=1}^{n-1} D_i + \prod_{i=1}^{n-2} D_i + \dots + D_1 + 1$ [S1, unofficial]. For $R^4$, the size is $XM \cdot YM \cdot ZM + XM \cdot YM + XM + 1$, where $XM, YM, ZM$ are the ranges in the respective axes [S1, unofficial].
*   **Context Arithmetic Encoder:** An entropy coder that uses the predicted value as context for encoding the residual [S1, unofficial].

**Prediction Formula:**
Let $v$ be the current sample point with local coordinates $(1, 1, \dots, 1)$ in a system where previously visited neighbors have coordinates in $\{0, 1\}^n$. The predicted value $P(v)$ is:
$$ P(v) = \sum_{u \in \{0,1\}^n \setminus \{v\}} (-1)^{g(u)} F(u) $$
where $g(u)$ is the number of coordinates of $u$ that equal 0 (i.e., the Hamming distance from $u$ to $v$ in the hypercube, or $n - u \cdot v$ if $v=(1,\dots,1)$) [S1, unofficial].

**Steps:**
1.  **Initialization:** Initialize the footprint buffer with zeros or appropriate boundary values. Initialize the arithmetic encoder.
2.  **Traversal:** Process the data in a specific recursive scanline order defined by the `Lorenzo` function.
3.  **Prediction:** For each sample $F[x_1, \dots, x_n]$, compute $P(v)$ using the values currently in the footprint buffer.
4.  **Residual Calculation:** Compute the residual $R = F[x_1, \dots, x_n] - P(v)$.
5.  **Encoding:** Encode $R$ using the context arithmetic encoder, using $P(v)$ as the context [S1, unofficial].
6.  **Update:** Update the footprint buffer with the current sample value $F[x_1, \dots, x_n]$ for future predictions.

**Edge Cases and Pitfalls:**
*   **Boundary Conditions:** The predictor requires $2^n - 1$ neighbors. At the boundaries of the grid, some neighbors may not exist. The source does not specify how boundaries are handled (e.g., zero-padding, replication, or skipping) [S1, unofficial]. [G] Implementers typically use zero-padding or clamp coordinates to the nearest valid neighbor.
*   **Polynomial Degree:** The predictor is exact for polynomials of degree $< n$. For a 3D predictor applied to a cubic function, the error is between 3% and 8% (L-infinity sense). For a 4D predictor applied to a quartic function, the error is less than 1% [S1, unofficial].
*   **Memory Footprint:** The buffer size grows exponentially with dimension if not managed carefully, but the recursive scanline order ensures only the current "slice" and lower-dimensional footprints are kept in memory [S1, unofficial].

## Subtopics

### [Lorenzo Predictor](10120-lorenzo-predictor.md)
The Lorenzo predictor is an isotropic predictive coding method for $n$-dimensional scalar fields that estimates a sample value from its $2^n - 1$ immediate neighbors in a regular grid to generate residuals for compression. It is distinguished from anisotropic scanline predictors by exploiting data coherence in all dimensions and is the simplest isotropic predictor capable of exactly reconstructing all polynomials of degree less than $n$.

### [SZ-L/R](11010-sz-l-r.md)
SZ-L/R is a block-based lossless/lossy compression algorithm for volumetric data that employs Lorenzo and linear regression predictors. It partitions input data into independent 6×6×6 blocks, allowing for cache-friendly processing and random access without inter-block dependencies. Unlike global interpolation methods such as [SZ-Interp](52-sz-interp.md), SZ-L/R prioritizes local feature preservation, making it suitable for unsmooth and irregular datasets, though it may introduce block-wise artifacts.

## Operating characteristics
**Time and Memory Complexity:**
*   **Time:** The prediction for each sample involves $2^n - 1$ lookups and additions. The arithmetic coding is linear in the number of bits. Overall time complexity is $O(N)$ where $N$ is the total number of samples [S1, unofficial].
*   **Memory:** The memory footprint is $O(\prod_{i=1}^{n-1} D_i)$, which is the size of one slice plus lower-dimensional footprints [S1, unofficial]. This makes it suitable for out-of-core implementations [S1, unofficial].

**Measured Performance:**
*   On a 3D model of a house on fire (43,202,395 bytes uncompressed), 4D Lorenzo compression reduced the size to 524,768 bytes (1.21% of total), outperforming 3D slice compression (1,076,587 bytes, 2.49%) by 50% [S1, unofficial].
*   On a fluid mixing simulation dataset, 3D time slice predictor produced 304,937,058 bytes (1.77 bits/symbol) and 4D Lorenzo produced 318,871,620 bytes (1.85 bits/symbol) [S1, unofficial].
*   Context arithmetic encoder gives a 25% gain over adaptive arithmetic encoder for encoding residuals [S1, unofficial].

**Strengths and Limitations:**
*   **Strengths:** Isotropic prediction exploits data coherence in all dimensions. Exact reconstruction of polynomials of degree $< n$. Low memory footprint suitable for large datasets [S1, unofficial].
*   **Limitations:** For data with high-frequency components or non-polynomial behavior, the residuals may be larger. In some lossless scenarios, cubic wavelets are slightly better than the Lorenzo predictor in terms of residual entropy for 4D datasets [S1, unofficial].

**When to Use:**
*   Use for large $n$-dimensional scalar fields where data coherence exists in all dimensions and memory is constrained [S1, unofficial].
*   Use when lossless compression is required and the data can be approximated by low-degree polynomials [S1, unofficial].

**When Not to Use:**
*   Use wavelets if the data has complex multi-scale features and lossless compression is prioritized over memory footprint [S1, unofficial].
*   Use anisotropic predictors if the data coherence is primarily along one or two dimensions [S1, unofficial].

## Background
The Lorenz Predictor was introduced by S. Mennon and M. Rizk in the paper "Out-of-Core Compression and Decompression of Large n-Dimensional Scalar Fields" [S1, unofficial]. It is an extension of the 2D parallelogram predictor to higher dimensions. The method is designed for out-of-core compression and decompression of large datasets, leveraging the limited memory footprint of the recursive scanline traversal [S1, unofficial].
