# Lorenz Predictor with Arithmetic Coding

Also called: Lorenzo, Lorenz预测与算术编码, n-dimensional Lorenzo predictor, n-dimensional parallelogram predictor

## Overview
The Lorenz Predictor with Arithmetic Coding is a lossless compression method for $n$-dimensional scalar fields that estimates a voxel's value from its $2^n - 1$ immediate neighbors in a regular grid to generate residuals, which are then encoded using arithmetic coding [S1, unofficial]. It is distinguished from anisotropic scanline predictors by being isotropic, exploiting data coherence in all dimensions, and is the simplest isotropic predictor capable of exactly reconstructing all polynomials of degree less than $n$ [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: An $n$-dimensional scalar field $F$ with dimensions $D_1 \times D_2 \times \dots \times D_n$.
- Output: A compressed bitstream representing the residuals of the prediction.

**Data Structures:**
- **Footprint Buffer:** A circular FIFO buffer storing the values of the "footprint" (the $2^n - 1$ neighbors required for prediction). The size of the buffer in $R^4$ is $X_M \cdot Y_M \cdot Z_M + X_M \cdot Y_M + X_M + 1$, where $X_M, Y_M, Z_M$ are the ranges in the respective axes [S1, unofficial]. For general $n$, the buffer stores the values of the hypercube corners excluding the current vertex.
- **Coordinate System:** A local coordinate system is used where the current sample $v$ has coordinates $(1, 1, \dots, 1)$ and its previously visited neighbors have coordinates in $\{0, 1\}^n$ [S1, unofficial].

**Prediction Formula:**
The predicted value $P(v)$ for a sample $v$ is the weighted sum of the values $F(u)$ at the other corners $u$ of the unit hypercube $\{0, 1\}^n$:
$$ P(v) = \sum_{u \in \{0,1\}^n \setminus \{(1,\dots,1)\}} (-1)^{g(u)} F(u) $$
where $g(u)$ is the number of coordinates of $u$ that equal 0 (i.e., the Hamming distance from $v$ in the local coordinate system) [S1, unofficial]. Equivalently, $g(u) = n - u \cdot v$ where $n$ is the dimension and $u \cdot v$ is the dot product [S1, unofficial].

**Steps:**
1. **Initialization:** Start the recursive traversal with $Lorenzo(n, -1, \dots, -1)$ [S1, unofficial].
2. **Traversal:** Process samples in a specific order defined by the recursive function $Lorenzo(d, x_1, \dots, x_n)$:
   - If all $x_i \neq -1$:
     - Compute prediction $p = LorenzoPredictor(d, x_1, \dots, x_n)$ using the formula above.
     - Compute residual $R = F[x_1, \dots, x_n] - p$.
     - Encode $R$ using arithmetic coding [S1, unofficial].
   - If some $x_i = -1$:
     - Find the first dimension $d$ where $x_d = -1$.
     - Set $x_d = 0$ and recurse: $Lorenzo(d-1, x_1, \dots, x_{d-1}, 0, x_{d+1}, \dots, x_n)$.
     - Loop $i$ from 1 to $D_d$ (the size of dimension $d$):
       - Recurse: $Lorenzo(d, x_1, \dots, x_{d-1}, i, x_{d+1}, \dots, x_n)$ [S1, unofficial].
3. **Encoding:** The residuals are encoded using a context arithmetic encoder, which uses the actual prediction as context, providing a 25% gain over an adaptive arithmetic encoder [S1, unofficial].

## Subtopics

### [Lorenzo Predictor](10120-lorenzo-predictor.md)
The Lorenzo predictor is an isotropic predictive coding method for $n$-dimensional scalar fields that estimates a sample value from its $2^n - 1$ immediate neighbors in a regular grid to generate residuals for compression. It is distinguished from anisotropic scanline predictors by exploiting data coherence in all dimensions and is the simplest isotropic predictor capable of exactly reconstructing all polynomials of degree less than $n$.

### [SZ-L/R](11010-sz-l-r.md)
SZ-L/R is a block-based lossless/lossy compression algorithm for volumetric data that employs Lorenzo and linear regression predictors. It partitions input data into independent 6×6×6 blocks, allowing for cache-friendly processing and random access without inter-block dependencies. Unlike global interpolation methods such as [SZ-Interp](52-sz-interp.md), SZ-L/R prioritizes local feature preservation, making it suitable for unsmooth and irregular datasets, though it may introduce block-wise artifacts.

## Operating characteristics
- **Time Complexity:** The predictor is of the highest possible order among all predictors attempting to predict the value at one corner of a cube from the other $2^n - 1$ corners [S1, unofficial]. The traversal is $O(N)$ where $N$ is the total number of samples.
- **Memory Complexity:** The footprint buffer size in $R^4$ is $X_M \cdot Y_M \cdot Z_M + X_M \cdot Y_M + X_M + 1$, where $X_M, Y_M, Z_M$ are the ranges in the respective axes [S1, unofficial]. This allows for out-of-core implementations where the total size of the data set significantly exceeds the available memory [S1, unofficial].
- **Measured Performance:**
  - On a 3D model of a house on fire (43,202,395 bytes uncompressed), 4D Lorenzo compression reduced the size to 524,768 bytes (1.21% of total), outperforming 3D slice compression (1,076,587 bytes, 2.49%) by 50% [S1, unofficial].
  - On a fluid mixing simulation dataset, 3D time slice predictor produced 304,937,058 bytes (1.77 bits/symbol) and 4D Lorenzo produced 318,871,620 bytes (1.85 bits/symbol) [S1, unofficial].
  - Context arithmetic encoder gives a 25% gain over adaptive arithmetic encoder for encoding residuals [S1, unofficial].
- **Strengths and Limitations:**
  - Strengths: Isotropic, exploits data coherence in all dimensions, exact for polynomials of degree less than $n$, suitable for out-of-core implementations [S1, unofficial].
  - Limitations: In lossless compression, cubic wavelets are slightly better than the Lorenzo predictor in terms of residual entropy for 4D datasets [S1, unofficial].
- **When to use:** When data has high coherence in all dimensions and out-of-core processing is required [S1, unofficial].
- **When not to use:** When lossless compression is required and cubic wavelets are available, as they may provide slightly better compression ratios [S1, unofficial].

## Background
The Lorenz Predictor with Arithmetic Coding was introduced by S. Mennon and M. Rizk in the paper "Out-of-Core Compression and Decompression of Large n-Dimensional Scalar Fields" [S1, unofficial]. It is an extension of the simple two-dimensional parallelogram predictor to higher dimensions [S1, unofficial]. The method is particularly well suited for out-of-core implementations where the total size of the data set significantly exceeds the available memory [S1, unofficial].
