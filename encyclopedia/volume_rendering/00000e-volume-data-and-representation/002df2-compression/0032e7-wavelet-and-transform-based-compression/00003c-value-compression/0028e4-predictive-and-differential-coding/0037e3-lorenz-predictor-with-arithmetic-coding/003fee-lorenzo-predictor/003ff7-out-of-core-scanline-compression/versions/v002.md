# Out-of-Core Scanline Compression

Also called: Lorenzo Out-of-Core Compression, Lorenzo-based Out-of-Core Compression, Scanline Compression Algorithm

## Overview
Out-of-Core Scanline Compression is a method for compressing large $n$-dimensional scalar fields by processing data in scanline order using the Lorenzo predictor to generate residuals, which are then encoded via arithmetic coding [S1, S2, unofficial]. It solves the problem of compressing datasets too large to fit in main memory by requiring only a small buffer (the size of a single slice) in core memory, unlike wavelet-based methods that require hierarchical processing and larger temporary storage [S1, S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** An $n$-dimensional scalar field $F$ organized as a regular grid with dimensions $D_1, \dots, D_n$ [S1, S2, unofficial]. The data is accessed sequentially in scanline order [S2, unofficial].
*   **Output:** A compressed bitstream of residuals [S1, unofficial].

**Data Structures:**
*   **Grid:** $F[x_1, \dots, x_n]$ where $0 \le x_i < D_i$ [S1, unofficial].
*   **Buffer:** A circular FIFO vector storing the "footprint" points required by the predictor. The buffer size equals the size of one $(n-1)$-dimensional slice plus the footprint for a dataset one dimension less [S1, unofficial]. For a 4D dataset, the buffer size is $X_M Y_M Z_M + X_M Y_M + X_M + 1$ [S1, unofficial].
*   **Probability Tables:** Space for an adaptive arithmetic encoder, which is much smaller than the dataset [S1, unofficial].

**The Lorenzo Predictor:**
The predictor estimates the value $E(v)$ at sample $v$ using its immediate neighbors that have already been processed [S2, unofficial]. In a local coordinate system where $v$ is at $(1, \dots, 1)$, the neighbors $u$ are vertices of the unit cube $\{0,1\}^n \setminus \{v\}$ [S2, unofficial]. The prediction is:
$$ E(v) = \sum_{u \in U} (-1)^{c_0(u)+1} F(u) $$
where $U = \{0,1\}^n \setminus \{v\}$ and $c_0(u)$ is the number of coordinates of $u$ equal to 0 [S2, unofficial]. Source [S1, unofficial] expresses this as $P(v) = \sum_u (-1)^{g(u)} F(u)$ where $g(u)$ counts zero coordinates; both describe the same isotropic predictor for polynomials of degree $< n$ [S1, S2, unofficial].

**Algorithm Steps:**
1.  Initialize the recursive traversal function `Lorenzo(d, x_1, ..., x_n)` with $d=n$ and all coordinates $x_i = -1$ [S1, unofficial].
2.  The function `Lorenzo(d, x_1, ..., x_n)` performs the following:
    *   If all coordinates $x_1, \dots, x_n$ are not $-1$:
        *   Compute prediction $p = \text{LorenzoPredictor}(d, x_1, \dots, x_n)$ using the formula above [S1, unofficial].
        *   Calculate residual $r = F[x_1, \dots, x_n] - p$ [S1, unofficial].
        *   Encode $r$ using arithmetic coding [S1, unofficial].
    *   Else (if any coordinate is $-1$):
        *   Recursively call `Lorenzo(d-1, x_1, ..., x_{d-1}, 0, x_{d+1}, ..., x_n)` to initialize the current dimension's index to 0 [S1, unofficial].
        *   Iterate $i$ from 1 to $D_d$ (the size of the $d$-th dimension):
            *   Call `Lorenzo(d, x_1, ..., x_{d-1}, i, x_{d+1}, ..., x_n)` [S1, unofficial].
3.  The starting call for a 4D dataset is `Lorenzo(4, -1, -1, -1, -1)` [S1, unofficial].

```python
def lorenzo_predictor(coords):
    """Computes Lorenzo prediction for local coordinates where sample v is at (1,...,1)."""
    n = len(coords)
    prediction = 0.0
    for mask in range(1 << n):
        u = tuple(1 if (mask >> j) & 1 else 0 for j in range(n))
        if all(c == 1 for c in u):
            continue
        c0 = sum(1 for c in u if c == 0)
        sign = -1 if (c0 + 1) % 2 != 0 else 1
        prediction += sign * buffer[u]  # [G] buffer stores footprint points
    return prediction

def lorenzo_recursive(d, coords, buffer, encoder, grid_dims):
    """Recursive scanline traversal. d is current dimension index (1-based)."""
    if all(c != -1 for c in coords):
        # All dimensions initialized: compute residual and encode
        prediction = lorenzo_predictor(coords)
        actual = buffer[coords]  # [G] Retrieves F[coords] from buffer/stream
        residual = actual - prediction
        encoder.encode(residual)
    else:
        # Find first uninitialized dimension
        for i in range(len(coords)):
            if coords[i] == -1:
                coords[i] = 0
                lorenzo_recursive(d - 1, coords, buffer, encoder, grid_dims)
                for k in range(1, grid_dims[i]):
                    coords[i] = k
                    lorenzo_recursive(d, coords, buffer, encoder, grid_dims)
                break

def compress_out_of_core(grid_dims):
    """Main compression routine."""
    n = len(grid_dims)
    # Buffer size: size of one slice + footprint for n-1 dimensions
    # For R4: X_M*Y_M*Z_M + X_M*Y_M + X_M + 1
    buffer_capacity = sum(grid_dims[i] for i in range(n-1))  # [G] Simplified capacity calc
    buffer = [0.0] * buffer_capacity
    encoder = AdaptiveArithmeticEncoder()
    coords = [-1] * n
    lorenzo_recursive(n, coords, buffer, encoder, grid_dims)
```

**Parameters:**
*   $d$: Current dimension being processed in recursion [S1, unofficial].
*   $x_1 \dots x_n$: Coordinates of the sample, initialized to $-1$ [S1, unofficial].
*   $d_{max}$: Number of samples in the $d$-th dimension [S1, unofficial].

**Edge Cases and Pitfalls:**
*   The algorithm assumes data is organized as a regular grid and visited in scanline order [S1, unofficial].
*   The predictor relies on previously recovered neighbors; if the buffer is not correctly maintained, predictions will fail [S1, unofficial].
*   If corrections are compressed with an adaptive arithmetic encoder, space for probability tables is needed [S1, unofficial].
*   Only a subset of corrections (representing >99% of all corrections, small range centered around 0) need to be compressed with arithmetic coding [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Linear in the number of samples $N$, as each sample is visited once [S1, unofficial].
*   **Memory Complexity:** $O(D_1 \times \dots \times D_{n-1})$, i.e., the size of a single $(n-1)$-dimensional slice [S1, unofficial]. This is significantly smaller than the full dataset size $N$ [S1, unofficial].
*   **Performance:** Often outperforms wavelet compression in an $L_\infty$ sense [S1, S2, unofficial].
*   **Strengths:** Low memory footprint (out-of-core capable), simple isotropic predictor, no need to split data into chunks [S1, S2, unofficial].
*   **Limitations:** Requires regular grid structure. Anisotropic predictors (lower-dimensional) fail to exploit coherence in all dimensions, but Lorenzo is isotropic [S1, unofficial].
*   **When to use:** When data is too large for main memory and a regular grid structure is available [S1, unofficial].
*   **When not to use:** For irregular grids or when hierarchical processing is already required for other reasons [S2, unofficial].

## Background
*   **Origin:** Introduced by [S1, S2, unofficial] for compressing large $n$-dimensional scalar fields from engineering, biomedical, and scientific simulations.
*   **History:** Extended from a simple two-dimensional parallelogram predictor [S2, unofficial]. The method was developed to address the limitations of wavelet and DCT approaches which require more temporary storage or chunking [S2, unofficial].
*   **Usage:** Used for lossy and lossless compression of volumetric data [S1, S2, unofficial].
