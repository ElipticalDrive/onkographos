# Predictive and Differential Coding


## Overview
Predictive and differential coding reduces data redundancy by encoding the difference (residual) between a sample's actual value and a predicted value derived from its neighbors or reference frames, rather than encoding absolute values. It sets itself apart from transform-based methods by operating directly on spatial or temporal dependencies without requiring a global frequency decomposition, making it highly effective for data with strong local coherence.

## Shared principles
All methods in this family share the mechanism of estimating a sample's value $V_{pred}$ from previously processed neighbors or reference frames, computing a residual $R = V_{actual} - V_{pred}$, and encoding $R$ [G].

1.  **Prediction:** The core operation is generating $V_{pred}$ from a causal neighborhood (spatial) or a reference frame (temporal). The predictor can be fixed (e.g., previous value, zero) or adaptive (e.g., linear combination of neighbors, optimal coefficients derived from covariance) [G].
2.  **Residual Calculation:** The residual $R$ is computed. In lossless contexts, $R$ is exact. In lossy contexts, $R$ may be quantized [G].
3.  **Entropy Coding:** The residuals are encoded using entropy coding (Huffman, Arithmetic, or Range coding) [G].
4.  **Closed-Loop vs. Open-Loop:** In temporal or iterative contexts, a closed-loop structure is often required where the decoder uses its *reconstructed* value (not the original) as the predictor for the next step to prevent error accumulation [G].

## Subtopics

### [Residual Coding for Volumetric Compression](6518-residual-coding-for-volumetric-compression.md)
Residual Coding improves the compression performance of a volumetric codec by encoding the difference between the original view images and the direct reconstruction of the volume without quantization or coding. Unlike standard video codecs where residuals are bitrate-dependent, this method encodes residuals derived from an unquantized reference, allowing the same residuals to be coded for all bitrates to preserve scalability. It is chosen when view synthesis quality must be preserved across scalable bitrates, though it may deteriorate view synthesis performance at high bitrates.

### [Optimal Linear Volumetric Predictor with Truncated Huffman Coding](7759-optimal-linear-volumetric-predictor-with-truncated-huffman-c.md)
This method is a lossless compression algorithm for 3D volume data that exploits spatial coherence by predicting voxel values from previously encoded neighbors and encoding the difference using a truncated Huffman code. It derives optimal linear coefficients for each volume using the Yule-Walker equations, automatically compensating for non-isotropic voxel sampling, unlike fixed-coefficient predictors. It is chosen for medical volume datasets where isotropic or anisotropic spatial redundancy is high and lossless reconstruction is required.

### [Lorenz Predictor with Arithmetic Coding](8070-lorenz-predictor-with-arithmetic-coding.md)
The Lorenz Predictor is a lossless compression method for $n$-dimensional scalar fields that estimates a sample's value from its $2^n - 1$ immediate neighbors in a regular grid to generate residuals, which are then encoded using arithmetic coding. It is distinguished from anisotropic scanline predictors by being isotropic, exploiting data coherence in all dimensions, and is the simplest isotropic predictor capable of exactly reconstructing all polynomials of degree less than $n$. It is chosen for regular grids where isotropic prediction is beneficial and arithmetic coding is available.

### [RDLS-SS-DWT+Pred](11251-rdls-ss-dwt-pred.md)
RDLS-SS-DWT+Pred is a lossless volumetric compression transform that combines 3D Discrete Wavelet Transform (DWT) with predictive coding to minimize the entropy of the resulting coefficients. It operates by applying Reversible Denoising Lifting Steps (RDLS) with step skipping to a 3D-DWT, followed by spatial prediction on the final subbands. It differs from its sibling [SS-DWT+Pred](6518-ss-dwt-pred.md) by incorporating denoising filters in the lifting steps, though sources indicate that using actual denoising filters yields negligible bitrate improvements over skipping them entirely. It is chosen when transform-domain compression is preferred but entropy reduction via spatial prediction on subbands is needed.

### [Closed-Loop DPCM Decompression](11737-closed-loop-dpcm-decompression.md)
Closed-Loop DPCM Decompression reconstructs volumetric trace data from compressed payloads by reversing a predictive coding scheme that uses the decoder's own reconstructed values to prevent error accumulation. It distinguishes itself from open-loop variants by ensuring that the prediction for the current sample is based on the previously *decoded* sample rather than the original ground truth, thereby containing quantization errors. It serves as the primary decoder for modern trace data formats, falling back to legacy methods for older files.

### [Spatial Predictive Coding](12623-spatial-predictive-coding.md)
Spatial Predictive Coding reduces information redundancy in voxel grids by exploiting statistical dependence between spatially adjacent samples, analogous to adjacent pixel correlation in images. It sets itself apart from sibling methods by constructing a reference graph to select the optimal neighbor via Sum of Absolute Differences (SAD) and by performing quantization *before* prediction to improve parallelism. Unlike methods that predict raw values, this approach operates specifically on quantized feature vectors, calculating residuals from quantized references. It is chosen for feature-rich volumes (e.g., color/RGB) where spatial correlation is strong.

### [Temporal Prediction](12644-temporal-prediction.md)
Temporal prediction exploits the high degree of coherence between consecutive time steps in dynamic volume data to reduce redundancy. It solves the problem of encoding time-varying volumes by estimating the current sample's value from previously processed reference frames, encoding only the residual difference. It sets itself apart from spatial predictors like [Spatial Predictive Coding](12623-spatial-predictive-coding.md) by leveraging temporal rather than spatial locality, and from transform-domain methods like [Residual Updates in Transform Domain](5256-residual-updates-in-transform-domain.md) by operating directly on spatial sample values in its simplest form. It is chosen for time-varying datasets where inter-frame correlation is high.

#### Directional Linear Predictive Coding
Compresses hologram interference patterns losslessly by exploiting directional correlation using DPCM and linear prediction [S1, unofficial]. It segments interference patterns into blocks and scans the pixels in eight directions for each block [S1, unofficial]. It calculates entropy in each direction and determines the direction with minimum entropy [S1, unofficial]. It encodes the difference by DPCM in the determined direction [S1, unofficial]. It calculates prediction coefficients for the determined direction and uses DPCM only to determine the prediction direction for the original pixel [S1, unofficial]. It calculates the difference between the predicted and the original pixel [S1, unofficial]. The first process (directional DPCM) achieved a compression rate of 26.7% [S1, unofficial].

#### JPEG-LS
An older JPEG standard variant tested against 3-D/2-D MLZC, featuring seven prediction modes [S2]. It provides the best compression for ANGIO data but lacks quality scalability and simultaneous lossy/lossless support in the same codestream [S2].

#### Functional Representation (Spherical Ellipsoids)
An approach similar to inter-frame delta encoding but encoding data with a functional representation based on spherical ellipsoids [S3].

## Background
Predictive and differential coding has been applied to medical imaging and holographic displays. Directional linear predictive coding was proposed for lossless compression of hologram interference patterns, achieving a compression rate of 26.7% by selecting the direction of minimum entropy [S1, unofficial]. JPEG-LS, an older JPEG standard variant, has been tested for 3D medical data, providing the best compression for certain datasets like ANGIO but lacking quality scalability [S2]. Functional representation based on spherical ellipsoids has also been explored for time-varying volume data [S3].
