# Predictive and Differential Coding

Also called: Differential Pulse-Code Modulation (DPCM), Residual Coding

## Overview
Predictive and differential coding compresses volumetric data by encoding the difference (residual) between a predicted value and the actual value, rather than encoding the raw values themselves [S1, unofficial]. This family exploits spatial or temporal redundancy to reduce the dynamic range of the data, making residuals more amenable to entropy coding [S1, unofficial]. It differs from transform-based methods (like [Triadic frequency band decomposition](828-triadic-frequency-band-decomposition.md)) by operating directly in the spatial or temporal domain without frequency decomposition, and from block codecs by typically applying prediction across the entire dataset or sequence unless explicitly partitioned [S1, unofficial].

## Shared principles
All methods in this family share the following mechanism:

1.  **Prediction:** A predictor function estimates the current data value $\hat{v}$ based on previously processed data (neighbors in space or time) [S1, unofficial].
2.  **Residual Calculation:** The residual (error) $e$ is computed as the difference between the actual value $v$ and the prediction: $e = v - \hat{v}$ [S1, unofficial].
3.  **Entropy Coding:** The residuals are encoded using entropy coding techniques (e.g., Huffman, Arithmetic, rANS) [S1, unofficial]. The residuals often exhibit a distribution with high probability mass near zero, which entropy coders exploit for high compression ratios [S1, unofficial].
4.  **Reconstruction:** Decoding involves reconstructing the value by adding the decoded residual to the predicted value: $v = \hat{v} + e$ [S1, unofficial].

## Subtopics

### [Delta Encoding](1096-delta-encoding.md)
Delta encoding (also known as Differential Pulse-Code Modulation or DPCM) stores the difference between a current data value and a predicted value based on previously processed data. In volume rendering, it is primarily used to exploit temporal coherence in time-varying datasets or progressive variation in heightfields, converting raw values into residuals that often contain large uniform regions (e.g., zeros) suitable for subsequent entropy coding. It differs from transform-based methods by operating directly in the spatial or temporal domain without frequency decomposition, and from block-based variants by typically applying prediction across the entire dataset or sequence unless explicitly partitioned.

### [Residual Updates in Transform Domain](5256-residual-updates-in-transform-domain.md)
Residual Updates in Transform Domain is a temporal compression method for volumetric data that operates in the frequency domain rather than the spatial domain. It solves the problem of efficiently encoding changes in dynamic implicit surfaces (such as TSDF volumes) by leveraging temporal coherence. Unlike spatial predictive coding which predicts voxel values from neighbors, this method predicts the current frame's transform coefficients (e.g., DCT) from the previously reconstructed frame's coefficients. It sets itself apart from siblings like [Delta Encoding](1096-delta-encoding.md) by working on transformed coefficients, which often concentrates residual energy more effectively for smooth volumetric changes, and from [Residual Coding for Volumetric Compression](6518-residual-coding-for-volumetric-compression.md) by explicitly handling block activation/deactivation events in the transform domain.

### [Residual Coding for Volumetric Compression](6518-residual-coding-for-volumetric-compression.md)
Residual coding is a technique to improve the compression performance (reconstructed image quality) of volumetric data by encoding the difference between the original image and the direct reconstructed image from the volume without quantization or coding. It does not contribute to view synthesis quality and may deteriorate it. Unlike standard video codecs where residuals change with bitrate, here the residuals are derived from the unquantized volume reconstruction, making them similar across all bitrates.

### [Optimal Linear Volumetric Predictor with Truncated Huffman Coding](7759-optimal-linear-volumetric-predictor-with-truncated-huffman-c.md)
This method is a lossless compression algorithm for 3D volume data that exploits spatial coherence by predicting voxel values from previously encoded neighbors and encoding the difference (residual) using a truncated Huffman code. It achieves approximately 50% compression ratios on biomedical volume datasets, outperforming generic compressors like gzip and zip by removing spatial redundancy rather than just statistical redundancy. Unlike simple delta encoding, it uses an optimal linear predictor derived from the data's covariance to minimize residual variance.

### Directional Linear Predictive Coding
**Definition**
Compresses hologram interference patterns losslessly by exploiting directional correlation using DPCM and linear prediction [S1, unofficial].

**Steps**
1.  Segment interference patterns into blocks [S1, unofficial].
2.  Scan the pixels in eight directions for each block [S1, unofficial].
3.  Calculate entropy in each direction [S1, unofficial].
4.  Determine the direction with minimum entropy [S1, unofficial].
5.  Encode the difference by DPCM in the determined direction [S1, unofficial].
6.  Calculate prediction coefficients for the determined direction [S1, unofficial].
7.  Use DPCM only to determine the prediction direction for the original pixel [S1, unofficial].
8.  Calculate the difference between the predicted and the original pixel [S1, unofficial].

**Performance**
The first process (directional DPCM) achieved a compression rate of 26.7% [S1, unofficial].

### JPEG-LS
**Definition**
An older JPEG standard variant tested against 3-D/2-D MLZC, featuring seven prediction modes [S2].

**Comparison**
Provides the best compression for ANGIO data but lacks quality scalability and simultaneous lossy/lossless support in the same codestream [S2].

### Inter-frame Delta Encoding with Haar Wavelets
**Definition**
Classifying each time step as intra-coded or predictive frame. All frames are encoded with Haar wavelet, but predictive frames are also expressed as delta with respect to previous frames and then encoded [S3].

### Functional Representation (Spherical Ellipsoids)
**Definition**
An approach similar to inter-frame delta encoding but encoding data with a functional representation based on spherical ellipsoids [S3].

### Lorenz Predictor with Arithmetic Coding
**Steps**
Compress the prediction error using arithmetic coding [S4, unofficial].

## Background
Predictive coding has been applied to volume data for lossless compression of biomedical and geological datasets. Early work demonstrated that linear predictive coding based on the directionality of interference patterns in holograms could achieve significant compression rates [S1, unofficial]. The method was compared against DPCM, with DPCM achieving a 26.7% compression rate in the first process of the study [S1, unofficial]. In the context of medical data, JPEG-LS was tested against 3-D/2-D MLZC, showing best performance for ANGIO data [S2]. For time-varying volumes, methods such as inter-frame delta encoding with Haar wavelets and functional representations using spherical ellipsoids have been proposed to leverage temporal coherence [S3]. Additionally, Lorenz predictors combined with arithmetic coding have been used to compress prediction errors in volumetric data [S4, unofficial].
