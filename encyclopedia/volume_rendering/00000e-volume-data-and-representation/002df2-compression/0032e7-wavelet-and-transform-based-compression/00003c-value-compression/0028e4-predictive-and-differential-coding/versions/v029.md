# Predictive and Differential Coding

Also called: DPCM, Linear Predictive Coding (LPC), Residual Coding

## Overview
Predictive and Differential Coding reduces data redundancy by estimating a voxel's value from its neighbors or reference frames, encoding only the residual difference $R = V_{actual} - V_{pred}$ [S1, unofficial]. Unlike transform-based methods that decorrelate data globally, this family operates locally or temporally, often serving as a post-processing step for transform coefficients or a standalone lossless/lossy codec for feature grids [S1, unofficial]. It sets itself apart from [Value compression](6-value-compression.md) by focusing on spatial/temporal correlation exploitation rather than frequency domain decomposition, though it frequently complements [Wavelet and Transform-based Compression](3856-wavelet-and-pyramid-transforms.md) by coding the resulting subbands [S1, unofficial].

## Shared principles
All methods in this family share the mechanism of estimating a voxel's value $V_{pred}$ from previously processed neighbors or reference frames, computing a residual $R = V_{actual} - V_{pred}$, and encoding $R$ [S1, unofficial].

1.  **Prediction:** The core operation generates $V_{pred}$ from a causal neighborhood (spatial) or a reference frame (temporal). Predictors can be fixed (e.g., previous value, zero) or adaptive (e.g., linear combination of neighbors, optimal coefficients derived from covariance) [S1, unofficial].
2.  **Residual Calculation:** The residual $R = V_{actual} - V_{pred}$ is computed. In lossless contexts, $R$ is exact; in lossy contexts, $R$ may be quantized. The goal is to minimize the variance or entropy of $R$ [S1, unofficial].
3.  **Entropy Coding:** The residuals are encoded using entropy coding (e.g., Huffman, Arithmetic, or Range coding) [S1, unofficial].
4.  **Closed-Loop vs. Open-Loop:** In temporal or iterative contexts, a closed-loop structure is often required where the decoder uses its reconstructed value (not the original) as the predictor for the next step to prevent error accumulation [S1, unofficial].

## Subtopics

### [Residual Coding for Volumetric Compression](6518-residual-coding-for-volumetric-compression.md)
Residual coding is a technique that improves the compression performance (reconstructed image quality) of volumetric codecs by encoding the difference between the original image and the direct reconstructed image from the volume without quantization or coding. It does not contribute to view synthesis quality and may deteriorate it. Unlike standard video codecs where residuals depend on the quantization level, here the residuals are derived from the unquantized volume reconstruction, making them similar across all bitrates.

### [Lorenz Predictor with Arithmetic Coding](8070-lorenz-predictor-with-arithmetic-coding.md)
The Lorenz Predictor with Arithmetic Coding is a lossless compression method for $n$-dimensional scalar fields that estimates the value of a sample from its $2^n - 1$ previously visited neighbors in a regular grid to generate residuals, which are then encoded using arithmetic coding. It is distinguished from anisotropic scanline predictors by being isotropic, exploiting data coherence in all dimensions, and is the simplest isotropic predictor capable of exactly reconstructing all polynomials of degree less than $n$.

### [RDLS-SS-DWT+Pred](11251-rdls-ss-dwt-pred.md)
RDLS-SS-DWT+Pred is a lossless volumetric compression method that constructs a hybrid transform by combining 3D-DWT with reversible denoising lifting steps (RDLS), step skipping (SS), and predictive coding. It solves the problem of high entropy in wavelet subbands by applying spatial prediction to the final subbands of the RDLS-SS-DWT transform. It sets itself apart from its parent [Predictive and Differential Coding](4393-predictive-and-differential-coding.md) by integrating prediction specifically into the post-processing stage of a modified DWT, and from its sibling [SS-DWT+Pred](6518-ss-dwt-pred.md) by including the RDLS denoising stage, although sources note that RDLS offers negligible bitrate improvement over SS-DWT+Pred alone.

### [Spatial Predictive Coding](12623-spatial-predictive-coding.md)
Spatial Predictive Coding reduces information redundancy in voxel grids by exploiting statistical dependence between spatially adjacent samples, analogous to adjacent pixel correlation in images. It sets itself apart from sibling methods by constructing a reference graph to select the optimal neighbor via Sum of Absolute Differences (SAD) and by performing quantization *before* prediction to improve parallelism. Unlike methods that predict density, this approach targets feature grids (e.g., color) where storage costs are significantly higher.

### [Temporal Prediction](12644-temporal-prediction.md)
Temporal prediction compresses time-varying volume data by exploiting temporal coherence, estimating a voxel's value from previously processed reference frames rather than spatial neighbors. It sets itself apart from spatial predictive methods by operating across time steps, often requiring closed-loop reconstruction to prevent error accumulation between encoder and decoder.

### Directional Linear Predictive Coding
- [S1, unofficial] Compresses hologram interference patterns losslessly by exploiting directional correlation using DPCM and linear prediction.

### JPEG-LS
- [S2] An older JPEG standard variant tested against 3-D/2-D MLZC, featuring seven prediction modes.
- [S2] Provides the best compression for ANGIO data but lacks quality scalability and simultaneous lossy/lossless support in the same codestream.

- [S3] An approach similar to inter-frame delta encoding but encoding data with a functional representation based on spherical ellipsoids.

## Background
Predictive coding in volume rendering emerged from the need to handle large medical and scientific datasets efficiently. Early work compared 3-D/2-D MLZC against older standards like JPEG-LS, noting that 3-D encoding provided significant gains for smooth data like MR-MRI [S2]. The technique was also applied to holographic display methods for volume data, where directional linear predictive coding was used to compress interference patterns [S1, unofficial]. More recently, it has been integrated into advanced wavelet-based codecs (e.g., RDLS-SS-DWT+Pred) to reduce entropy in high-frequency subbands [S1, unofficial].
