# Spatial Predictive Coding

Also called: Spatial Prediction for Feature Grids

## Overview
Spatial Predictive Coding reduces information redundancy in voxel grids by exploiting statistical dependence between spatially adjacent samples, analogous to adjacent pixel correlation in images [S1]. It constructs a reference relation graph to select the optimal neighbor via Sum of Absolute Differences (SAD) and performs quantization before prediction to improve parallelism [S1]. Unlike methods that predict raw values, this approach operates specifically on quantized feature vectors, calculating residuals from quantized references [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A grid of feature vectors (typically color/RGB features, not density) [S1].
*   **Output:** A bitstream containing reference indices and encoded residuals [S1].

**Data Structures:**
*   **Feature Grid:** Stores quantized feature vectors $\hat{x}$ for each voxel [S1].
*   **Reference Index:** An integer identifying the chosen neighbor for each voxel [S1].
*   **Residual:** The difference between the current quantized feature and the reference quantized feature [S1].

**Parameters:**
*   **Quantization:** Straightforward scalar quantization is used instead of vector quantization to avoid difficulties in subsequent prediction and bitrate estimation [S1].
*   **Reference Scope:** Only complete, previously reconstructed voxels are used as prediction values; interpolation at non-integer positions is not used [S1].
*   **Block Partitioning:** Voxels can be partitioned into blocks to share a single reference mode, trading prediction accuracy for lower index bit cost [S1].

**Steps:**
1.  **Quantization:** Quantize the original feature vector $x$ to obtain $\hat{x}$ using scalar quantization [S1].
2.  **Reference Selection:** Identify the causal neighborhood of previously reconstructed voxels for the current voxel [S1].
3.  **SAD Calculation:** Calculate the Sum of Absolute Differences (SAD) between the current quantized feature $\hat{x}$ and each candidate's quantized feature $\hat{x}_{ref}$ [S1].
4.  **Optimal Reference:** Select the neighbor with the minimum SAD as the reference and record its index in the bitstream [S1].
5.  **Residual Calculation:** Compute the residual $y$ using the formula:
    $$ y = \hat{x} - \hat{x}_{ref} $$
    where $\hat{x}$ is the quantized feature to be coded and $\hat{x}_{ref}$ is the quantized reference feature [S1].
6.  **Entropy Coding:** Encode the reference indices and the residuals $y$ using an entropy coder [S1].

**Pseudocode:**
```python
def spatial_predictive_encode(feature_grid):
    """
    Encodes a feature grid using spatial predictive coding.
    feature_grid: List of feature vectors [x_1, x_2, ..., x_N]
    Returns: bitstream containing reference indices and residuals
    """
    bitstream = []
    reconstructed_features = []
    
    for i, x in enumerate(feature_grid):
        # 1. Quantization
        x_hat = [round(val) for val in x]
        
        # 2. Reference Selection
        # Causal neighbors are previously reconstructed voxels
        candidates = reconstructed_features
        
        if not candidates:
            # Edge case: First voxel has no spatial reference
            ref_index = -1
            x_ref_hat = [0] * len(x_hat)
        else:
            min_sad = float('inf')
            best_ref_index = -1
            best_ref_hat = None
            
            for idx, x_ref_hat in enumerate(candidates):
                sad = sum(abs(a - b) for a, b in zip(x_hat, x_ref_hat))
                if sad < min_sad:
                    min_sad = sad
                    best_ref_index = idx
                    best_ref_hat = x_ref_hat
            
            ref_index = best_ref_index
            x_ref_hat = best_ref_hat

        # 3. Residual Calculation
        residual = [a - b for a, b in zip(x_hat, x_ref_hat)]
        
        # 4. Encode
        bitstream.append(("index", ref_index))
        bitstream.append(("residual", residual))
        
        # 5. Update Reconstructed List (Closed-Loop)
        reconstructed_features.append(x_hat)
        
    return bitstream
```

**Edge Cases and Pitfalls:**
*   **High Bit Cost of Indices:** Selecting the optimal reference per voxel incurs a high bit cost for storing reference indexes [S1]. Mitigation: Partition voxels into blocks and select a single mode for all voxels within a block [S1].
*   **Feature vs. Density:** Prediction is performed only on the feature grid, not on density grids, because color feature grids typically cost much more storage [S1].
*   **Quantization Choice:** Scalar quantization is preferred over vector quantization to avoid difficulties in subsequent prediction and bitrate estimation [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources. Reference selection compares the current voxel against causal neighbors, and block-based selection reduces index bit cost [S1].
*   **Memory Complexity:** Requires storing the reconstructed feature grid for causal access [G].
*   **Strengths:** Exploits strong spatial correlation in feature grids. Quantization before prediction improves parallelism [S1].
*   **Limitations:** High bit cost for reference indices if not block-quantized. Scalar quantization may be less efficient than vector quantization for high-dimensional features, though residuals are often near zero [S1].
*   **When to use:** When compressing feature grids where spatial correlation is high and storage cost of features is significant [S1].
*   **When not to use:** When density grids are the primary target, as the method specifies feature grids only [S1].

## Background
Spatial Predictive Coding in the context of voxel-based radiance fields was proposed in "SPC-NeRF: Spatial Predictive Compression for Voxel-Based Radiance Field" [S1]. The method addresses redundancy in feature grids by modeling the bit cost of residuals through a reference relation graph and integrates with rate-distortion joint finetuning to optimize compression performance [S1].
