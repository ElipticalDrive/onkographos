# Spatial Predictive Coding

Also called: Spatial Prediction for Feature Grids

## Overview
Spatial Predictive Coding reduces information redundancy in voxel grids by exploiting statistical dependence between spatially adjacent samples, analogous to adjacent pixel correlation in images [S1]. It sets itself apart from sibling methods by constructing a reference relation graph to select the optimal neighbor via the Sum of Absolute Differences (SAD) metric, and by performing scalar quantization *before* prediction to improve parallelism [S1]. Unlike methods that predict raw values, this approach operates specifically on quantized feature vectors, calculating residuals from quantized references [S1]. Only complete, previously reconstructed voxels are used as prediction values; interpolation at non-integer positions is not used [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A grid of feature vectors (typically color/RGB features, not density) [S1].
*   **Output:** A bitstream containing reference indices and encoded residuals [S1].

**Data Structures:**
*   **Feature Grid:** Stores quantized feature vectors $\hat{x}$ for each voxel [S1].
*   **Reference Index:** An integer identifying the chosen neighbor for each voxel [S1].
*   **Residual:** The difference between the current quantized feature and the reference quantized feature [S1].

**Parameters:**
*   **Quantization:** Scalar quantization is used for feature vectors [S1].
*   **Reference Scope:** Only complete, previously reconstructed voxels are used as references; interpolation at non-integer positions is not used [S1].
*   **Block Size:** Voxels can be partitioned into blocks to share a single reference mode, trading prediction accuracy for lower index bit cost [S1].

**Steps:**
1.  **Quantization:** Quantize the original feature vector $x$ to obtain $\hat{x}$ using scalar quantization [S1].
2.  **Reference Selection:** For each voxel, identify candidate neighbors (previously reconstructed voxels) [S1]. Calculate the Sum of Absolute Differences (SAD) between the current quantized feature $\hat{x}$ and each candidate's quantized feature $\hat{x}_{ref}$ [S1].
3.  **Optimal Reference:** Select the neighbor with the minimum SAD as the reference [S1]. Record the index of this reference in the bitstream [S1].
4.  **Residual Calculation:** Compute the residual $y$ using the formula:
    $$ y = \hat{x} - \hat{x}_{ref} $$
    where $\hat{x}$ is the quantized feature to be coded and $\hat{x}_{ref}$ is the quantized reference feature [S1].
5.  **Entropy Coding:** Encode the reference indices and the residuals $y$ using an entropy coder (e.g., Huffman or Arithmetic coding) [S1].

**Pseudocode:**
```python
def spatial_predictive_encode(feature_grid):
    """
    Encodes a feature grid using spatial predictive coding.
    feature_grid: List of feature vectors [x_1, x_2, ..., x_N]
    Returns: bitstream containing reference indices and residuals
    """
    bitstream = []
    reconstructed_features = []  # Stores quantized features for causal access
    
    for x in feature_grid:
        # 1. Quantization
        x_hat = quantize_scalar(x)
        
        # 2. Reference Selection
        candidates = get_causal_neighbors(x_hat, reconstructed_features)
        
        if not candidates:
            # Edge case: First voxel, no reference available
            ref_index = -1
            x_ref_hat = [0.0] * len(x_hat)
        else:
            min_sad = float('inf')
            best_ref_index = -1
            best_ref_hat = None
            
            for idx, x_ref_hat in enumerate(candidates):
                sad = sum(abs(a - b) for a, b in zip(x_hat, x_ref_hat))
                if sad < min_sad:
                    min_sad = sad
                    best_ref_index = idx
                    best_ref_hat = x_ref_hat
            
            ref_index = best_ref_index
            x_ref_hat = best_ref_hat

        # 3. Residual Calculation
        residual = [a - b for a, b in zip(x_hat, x_ref_hat)]
        
        # 4. Encode
        bitstream.append(ref_index)
        bitstream.append(residual)
        
        # 5. Update Reconstructed List (Closed-Loop)
        reconstructed_features.append(x_hat)
        
    return bitstream

def quantize_scalar(feature_vector):
    """Applies straightforward scalar quantization to a feature vector."""
    return [round(val) for val in feature_vector]

def get_causal_neighbors(current, history):
    """[G] Returns a subset of history containing only spatially adjacent voxels processed earlier."""
    return history
```

**Edge Cases and Pitfalls:**
*   **High Bit Cost of Indices:** Selecting the optimal reference per voxel incurs a high bit cost for storing reference indexes [S1]. Mitigation: Partition voxels into blocks and select a single mode for all voxels within a block [S1].
*   **Feature vs. Density:** Prediction is performed only on the feature grid, not on density grids, because color feature grids typically cost much more storage [S1].
*   **Quantization Choice:** Scalar quantization is preferred over vector quantization to avoid difficulties in subsequent prediction and bitrate estimation [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Requires storing the reconstructed feature grid for causal access [G].
*   **Strengths:** Exploits strong spatial correlation in feature grids. Quantization before prediction improves parallelism [S1].
*   **Limitations:** High bit cost for reference indices if not block-quantized [S1]. Scalar quantization may be less efficient than vector quantization for high-dimensional features, though residuals are often near zero [S1].
*   **When to use:** When compressing feature grids (e.g., in NeRFs) where spatial correlation is high and storage cost of features is significant [S1].
*   **When not to use:** When density grids are the primary target, as prediction is performed only on feature grids [S1].

## Background
Spatial Predictive Coding in the context of voxel-based radiance fields was proposed in "SPC-NeRF: Spatial Predictive Compression for Voxel-Based Radiance Field" [S1]. The method addresses the redundancy in feature grids by modeling the bit cost of residuals through a reference relation graph [S1]. It integrates with rate-distortion joint finetuning to optimize compression performance [S1].
