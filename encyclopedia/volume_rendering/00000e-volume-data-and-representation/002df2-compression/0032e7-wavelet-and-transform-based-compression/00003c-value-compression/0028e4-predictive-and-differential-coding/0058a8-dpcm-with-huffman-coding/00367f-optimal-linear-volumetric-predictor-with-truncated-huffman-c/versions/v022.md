# Optimal Linear Volumetric Predictor with Truncated Huffman Coding

Also called: DPCM with Huffman Coding, DPCM-Huffman, Predictive Huffman Coding for Volumes, Volume DPCM with Huffman Coding, compvox algorithm, volumetric DPCM with optimal coefficients, 差值编码与霍夫曼编码结合

## Overview
This method is a lossless compression algorithm for 3D volume data that exploits spatial coherence by predicting voxel values from previously encoded neighbors and encoding the difference (residual) using a truncated Huffman code [S1, unofficial]. It achieves approximately 50% compression ratios on medical volume datasets, outperforming generic compressors like gzip and zip by explicitly removing spatial redundancy rather than just statistical redundancy [S1, unofficial]. Unlike fixed-coefficient predictors, it derives optimal linear coefficients via the Yule-Walker equations to handle non-isotropic sampling, and unlike standard Huffman coding, it uses a truncated codebook to bound maximum code length [S1, unofficial].

## How it works
The algorithm operates in two phases: coefficient estimation (training) and encoding/decoding. It assumes the volume data is wide-sense stationary [S1, unofficial].

### Inputs and Outputs
*   **Input:** A 3D volume array $V$ of size $X \times Y \times Z$. The source data is typically 16-bit integers, implying voxel values in a standard range (e.g., 0–65535) [S1, unofficial].
*   **Output:** A compressed bitstream containing the Huffman-encoded residuals, preceded by a header storing the mean, predictor coefficients, and the Huffman code table [S1, unofficial].

### Data Structures
1.  **Volume Array:** $V[x, y, z]$ for $0 \le x < X, 0 \le y < Y, 0 \le z < Z$.
2.  **Covariance Matrix ($A$):** A $3 \times 3$ symmetric matrix used to solve for predictor coefficients.
3.  **Covariance Vector ($b$):** A $3 \times 1$ vector.
4.  **Huffman Table:** A mapping from difference values (symbols) to bit sequences. It consists of two parts:
    *   **Huffman Codes:** For the $L_1$ most frequent symbols.
    *   **Fixed-Length Codes:** For the remaining $L - L_1$ symbols [S1, unofficial].

### Parameters
*   **$L_1$:** The number of most frequent symbols to Huffman code. Default value is 256 [S1, unofficial].
*   **$L$:** Total number of possible source symbols. For 16-bit voxels, residuals range from $-66535$ to $65536$, so $L = 131,071$ [S1, unofficial].
*   **Scan Order:** Raster-scan order (increasing $x$, then $y$, then $z$) to ensure causality [S1, unofficial].

### Steps

#### Phase 1: Coefficient Estimation
1.  **Estimate Mean:** Scan the entire volume to calculate the mean $\bar{v}$ [S1, unofficial]:
    $$ \bar{v} = \frac{1}{XYZ} \sum_{x=0}^{X-1} \sum_{y=0}^{Y-1} \sum_{z=0}^{Z-1} V(x, y, z) $$
2.  **Estimate Covariance:** Scan the volume to estimate the covariance $r(x, y, z)$ for lags in $\{-1, 0, 1\}$. The estimator uses a reduced domain to avoid boundary issues during lag calculation [S1, unofficial]:
    $$ r(x, y, z) = \frac{1}{(X-2)(Y-2)(Z-2)} \sum_{x'=1}^{X-2} \sum_{y'=1}^{Y-2} \sum_{z'=1}^{Z-2} [V(x', y', z') - \bar{v}] [V(x'+x, y'+y, z'+z) - \bar{v}] $$
    *Note: The source defines the summation limits as $1$ to $X-2$, etc., which implies the indices $x', y', z'$ refer to the center of the correlation window, and the lagged terms access neighbors within the valid range [S1, unofficial].*
3.  **Solve for Coefficients:** Construct the linear system $A \mathbf{a} = \mathbf{b}$ using the estimated covariances. The matrix $A$ and vector $\mathbf{b}$ are defined as [S1, unofficial]:
    $$
    \begin{bmatrix}
    r(0,0,0) & r(1,-1,0) & r(1,0,-1) \\
    r(-1,1,0) & r(0,0,0) & r(0,1,-1) \\
    r(-1,0,1) & r(0,-1,1) & r(0,0,0)
    \end{bmatrix}
    \begin{bmatrix}
    a_1 \\ a_2 \\ a_3
    \end{bmatrix}
    =
    \begin{bmatrix}
    r(1,0,0) \\ r(0,1,0) \\ r(0,0,1)
    \end{bmatrix}
    $$
    Solve for $\mathbf{a} = [a_1, a_2, a_3]^T$ [S1, unofficial].

#### Phase 2: Encoding
4.  **Calculate Residuals:** Scan the volume in raster-scan order. For each voxel $V(x, y, z)$, calculate the predicted value $\tilde{V}(x, y, z)$ using mean-subtracted neighbors [S1, unofficial]:
    $$ \tilde{V}(x, y, z) = a_1 V_1(x, y, z) + a_2 V_2(x, y, z) + a_3 V_3(x, y, z) $$
    Where the neighbor terms $V_i$ are defined as:
    $$
    V_1(x, y, z) = \begin{cases} 0 & \text{if } x = 0 \\ V(x-1, y, z) - \bar{v} & \text{if } x > 0 \end{cases}
    $$
    $$
    V_2(x, y, z) = \begin{cases} 0 & \text{if } y = 0 \\ V(x, y-1, z) - \bar{v} & \text{if } y > 0 \end{cases}
    $$
    $$
    V_3(x, y, z) = \begin{cases} 0 & \text{if } z = 0 \\ V(x, y, z-1) - \bar{v} & \text{if } z > 0 \end{cases}
    $$
    Compute the difference value:
    $$ d(x, y, z) = V(x, y, z) - \tilde{V}(x, y, z) $$
5.  **Count Frequencies:** Count the occurrences of each difference value $d(x, y, z) = s_i$ across the volume to estimate symbol probabilities $p_i$ [S1, unofficial].
6.  **Build Huffman Table:**
    *   Sort symbols by frequency.
    *   Assign Huffman codes to the $L_1$ most frequent symbols.
    *   Assign fixed-length codes (of sufficient length to represent the remaining symbols) to the remaining $L - L_1$ symbols [S1, unofficial].
7.  **Encode:** Scan the volume again. For each voxel, calculate $d(x, y, z)$ using the predictor (Step 4) and output the corresponding Huffman code from the table [S1, unofficial].

#### Phase 3: Decompression
8.  **Read Header:** Read $\bar{v}$, $a_1, a_2, a_3$, and the Huffman table from the compressed file [S1, unofficial].
9.  **Decode and Reconstruct:** For each voxel in raster-scan order:
    *   Read the next Huffman code from the bitstream.
    *   Look up the difference value $d(x, y, z)$ in the Huffman table.
    *   Reconstruct the voxel value using the same predictor logic:
        $$ V(x, y, z) = \tilde{V}(x, y, z) + d(x, y, z) $$
    *   Note: The decoder uses the *reconstructed* values $V(x-1, y, z)$, etc., to compute $\tilde{V}(x, y, z)$ for the next step, ensuring closed-loop consistency [S1, unofficial].

### Pseudocode

```python
def compress_volume(V, X, Y, Z, L1=256):
    # Phase 1: Statistics
    # 1. Estimate Mean
    total_sum = 0
    for x in range(X):
        for y in range(Y):
            for z in range(Z):
                total_sum += V[x][y][z]
    mean_v = total_sum / (X * Y * Z)

    # 2. Estimate Covariance
    # r(x, y, z) for x,y,z in {-1, 0, 1}
    # Note: Source uses indices 1 to X-2 for summation limits
    cov = {}
    denom = (X - 2) * (Y - 2) * (Z - 2)
    for lag_x in [-1, 0, 1]:
        for lag_y in [-1, 0, 1]:
            for lag_z in [-1, 0, 1]:
                sum_cov = 0
                for x_prime in range(1, X - 1):
                    for y_prime in range(1, Y - 1):
                        for z_prime in range(1, Z - 1):
                            val1 = V[x_prime][y_prime][z_prime] - mean_v
                            val2 = V[x_prime + lag_x][y_prime + lag_y][z_prime + lag_z] - mean_v
                            sum_cov += val1 * val2
                cov[(lag_x, lag_y, lag_z)] = sum_cov / denom

    # 3. Solve for coefficients a1, a2, a3
    # Matrix A and Vector b as defined in source
    r000 = cov[(0, 0, 0)]
    r1m10 = cov[(1, -1, 0)]
    r10m1 = cov[(1, 0, -1)]
    rm110 = cov[(-1, 1, 0)]
    rm101 = cov[(-1, 0, 1)]
    r0m11 = cov[(0, -1, 1)]
    r01m1 = cov[(0, 1, -1)]
    
    # b vector
    b1 = cov[(1, 0, 0)]
    b2 = cov[(0, 1, 0)]
    b3 = cov[(0, 0, 1)]

    # Solve linear system A * a = b
    # A = [[r000, r1m10, r10m1],
    #      [rm110, r000, r01m1],
    #      [rm101, r0m11, r000]]
    a1, a2, a3 = solve_linear_system(
        [[r000, r1m10, r10m1],
         [rm110, r000, r01m1],
         [rm101, r0m11, r000]],
        [b1, b2, b3]
    )

    # Phase 2: Encoding
    # 4 & 5. Calculate residuals and count frequencies
    freq = {}
    for x in range(X):
        for y in range(Y):
            for z in range(Z):
                # Calculate neighbors with mean subtraction
                if x == 0:
                    v1 = 0
                else:
                    v1 = V[x-1][y][z] - mean_v
                
                if y == 0:
                    v2 = 0
                else:
                    v2 = V[x][y-1][z] - mean_v
                
                if z == 0:
                    v3 = 0
                else:
                    v3 = V[x][y][z-1] - mean_v

                pred = a1 * v1 + a2 * v2 + a3 * v3
                diff = V[x][y][z] - pred
                
                # Count frequency
                freq[diff] = freq.get(diff, 0) + 1

    # 6. Build Huffman Table
    # Sort symbols by frequency descending
    sorted_symbols = sorted(freq.keys(), key=lambda k: freq[k], reverse=True)
    
    huffman_table = {}
    # Assign Huffman codes to top L1 symbols
    # Implementation of Huffman coding algorithm omitted for brevity, 
    # assuming a function that generates codes from sorted probabilities
    top_symbols = sorted_symbols[:L1]
    huffman_codes = generate_huffman_codes(top_symbols, [freq[s] for s in top_symbols])
    for i, s in enumerate(top_symbols):
        huffman_table[s] = huffman_codes[i]
    
    # Assign fixed-length codes to remaining symbols
    # Determine bit length needed for remaining symbols
    remaining_count = len(sorted_symbols) - L1
    if remaining_count > 0:
        fixed_len = ceil(log2(remaining_count))
        # Assign sequential fixed-length codes
        fixed_code_counter = 0
        for s in sorted_symbols[L1:]:
            huffman_table[s] = format(fixed_code_counter, f'0{fixed_len}b')
            fixed_code_counter += 1

    # 7. Encode
    bitstream = []
    for x in range(X):
        for y in range(Y):
            for z in range(Z):
                if x == 0:
                    v1 = 0
                else:
                    v1 = V[x-1][y][z] - mean_v
                if y == 0:
                    v2 = 0
                else:
                    v2 = V[x][y-1][z] - mean_v
                if z == 0:
                    v3 = 0
                else:
                    v3 = V[x][y][z-1] - mean_v
                
                pred = a1 * v1 + a2 * v2 + a3 * v3
                diff = V[x][y][z] - pred
                
                bitstream.append(huffman_table[diff])
    
    # Header: mean, a1, a2, a3, huffman_table
    return header, bitstream

def decompress_volume(header, bitstream, X, Y, Z):
    mean_v, a1, a2, a3, huffman_table = header
    V = [[0]*Z for _ in range(Y)] # Placeholder for 3D array structure
    # Note: Pseudocode assumes V[x][y][z] access. 
    # Reconstructing 3D array logic:
    V = [[[0 for z in range(Z)] for y in range(Y)] for x in range(X)]

    for x in range(X):
        for y in range(Y):
            for z in range(Z):
                # Decode diff
                code = read_next_code(bitstream)
                diff = huffman_table.lookup(code) # Reverse lookup or direct mapping if stored by code
                
                # Predict using RECONSTRUCTED values
                if x == 0:
                    v1 = 0
                else:
                    v1 = V[x-1][y][z] - mean_v
                
                if y == 0:
                    v2 = 0
                else:
                    v2 = V[x][y-1][z] - mean_v
                
                if z == 0:
                    v3 = 0
                else:
                    v3 = V[x][y][z-1] - mean_v
                
                pred = a1 * v1 + a2 * v2 + a3 * v3
                V[x][y][z] = pred + diff
                
    return V
```

### Edge Cases and Pitfalls
*   **Causality:** The predictor must strictly use only previously processed voxels ($x-1, y, z$; $x, y-1, z$; $x, y, z-1$). If the decoder uses original values instead of reconstructed values, error accumulation will occur [S1, unofficial].
*   **Non-stationarity:** The optimal predictor assumes wide-sense stationarity. Real volume data is not stationary, making global statistics suboptimal. The algorithm does not handle this locally (e.g., via octrees) [S1, unofficial].
*   **Memory vs. Speed:** The algorithm scans the volume four times (two for statistics, one for residual calculation, one for encoding) to avoid storing the large residual array. This increases computational time but reduces memory footprint [S1, unofficial].
*   **Boundary Handling:** At boundaries ($x=0, y=0, z=0$), the neighbor terms are set to 0 (after mean subtraction). This ensures the prediction error is orthogonal to the input variables as per the derivation [S1, unofficial].

## Operating characteristics
*   **Compression Ratio:** Achieves approximately 50% compression (i.e., reduces file size to ~50% of original) on medical volume datasets [S1, unofficial]. For example, on `3dhead.vox`, it achieved 48.5% compression compared to 36.1% for gzip and 33.8% for zip [S1, unofficial].
*   **Performance:** On a HP 9000 Series 735, compression of `3dhead.vox` took 4.7 minutes, and decompression took 1.4 minutes [S1, unofficial].
*   **Entropy:** The method reduces entropy to near the theoretical limit. Test datasets showed entropies ranging from 3.28 bits/voxel (`sod.30.vox`) to 10.29 bits/voxel (`hipiph.vox`) [S1, unofficial].
*   **Strengths:** Significantly outperforms generic compressors by removing spatial redundancy. The optimal predictor automatically compensates for non-isotropic voxel sampling [S1, unofficial].
*   **Limitations:** High computational cost due to multiple volume scans and covariance matrix solving. Assumes stationarity, which may not hold for complex anatomical structures. The truncated Huffman code requires a fixed $L_1$ parameter, which is arbitrarily set to 256 [S1, unofficial].

## Background
The method was introduced by James Edwin Fowler and Roni Yagel in January 1995 at the Proceedings of the 1994 Symposium on Volume Visualization [S1, unofficial]. It was designed specifically for lossless compression of biomedical volume data (MRI, CT, electron-density maps) where lossy compression is unacceptable [S1, unofficial]. The algorithm combines Differential Pulse-Code Modulation (DPCM) with Huffman coding, leveraging the spatial coherence of volume data [S1, unofficial].
