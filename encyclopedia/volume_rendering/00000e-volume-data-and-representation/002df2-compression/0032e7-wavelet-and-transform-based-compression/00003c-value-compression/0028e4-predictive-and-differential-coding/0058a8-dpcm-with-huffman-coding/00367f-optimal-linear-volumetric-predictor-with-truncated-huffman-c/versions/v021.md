# Optimal Linear Volumetric Predictor with Truncated Huffman Coding

Also called: DPCM with Huffman Coding, DPCM-Huffman, Predictive Huffman Coding for Volumes, Volume DPCM with Huffman Coding, compvox algorithm, volumetric DPCM with optimal coefficients, 差值编码与霍夫曼编码结合

## Overview
This method is a lossless compression algorithm for 3D volume data that exploits spatial coherence by predicting voxel values from previously encoded neighbors and encoding the difference (residual) using a truncated Huffman code [S1, unofficial]. It achieves approximately 50% compression ratios on medical volume datasets, outperforming generic compressors like gzip and zip by explicitly removing spatial redundancy rather than just statistical redundancy [S1, unofficial]. Unlike fixed-coefficient predictors, this method derives optimal linear coefficients for each volume using the Yule-Walker equations, automatically compensating for non-isotropic voxel sampling [S1, unofficial].

## How it works
### Inputs and Outputs
- **Input:** A 3D volume array $V$ of size $X \times Y \times Z$, where each voxel $v(x,y,z)$ is a 16-bit integer [S1, unofficial].
- **Output:** A compressed bitstream containing the encoded residuals, preceded by a header storing the estimated mean, predictor coefficients, and the Huffman code table [S1, unofficial].

### Data Structures
1.  **Volume Data:** Stored in raster-scan order (x, then y, then z) to ensure causality [S1, unofficial].
2.  **Covariance Matrix ($A$):** A $3 \times 3$ symmetric matrix used to solve for predictor coefficients [S1, unofficial].
3.  **Covariance Vector ($b$):** A $3 \times 1$ vector of lagged covariances [S1, unofficial].
4.  **Huffman Table:** A mapping from difference values (symbols) to variable-length bit codes [S1, unofficial]. For truncated Huffman coding, the $L_1$ most frequent symbols are assigned Huffman codes, while the remaining $L - L_1$ symbols are assigned fixed-length codes [S1, unofficial].
    -   Default $L_1 = 256$ [S1, unofficial].
    -   Total possible symbols $L = 131,071$ (range $-66,535$ to $65,536$) for 16-bit inputs [S1, unofficial].

### Parameters
-   **Predictor Order:** 3 coefficients ($a_1, a_2, a_3$) using the 6-neighborhood (face-sharing neighbors) [S1, unofficial].
-   **Truncation Parameter ($L_1$):** Number of symbols Huffman-coded. Default: 256 [S1, unofficial].
-   **Scan Order:** Raster-scan (x, y, z) [S1, unofficial].

### Algorithm Steps

#### 1. Estimate Global Statistics
The algorithm assumes wide-sense stationarity to derive optimal coefficients [S1, unofficial].

**Step 1: Estimate Mean**
Scan the entire volume to calculate the mean $\bar{v}$:
$$ \bar{v} = \frac{1}{XYZ} \sum_{x=0}^{X-1} \sum_{y=0}^{Y-1} \sum_{z=0}^{Z-1} v(x,y,z) $$
[S1, unofficial]

**Step 2: Estimate Covariance**
Scan the volume to estimate the covariance $r(x,y,z)$ for lags $x,y,z \in \{-1, 0, 1\}$:
$$ r(x,y,z) = \frac{1}{(X-2)(Y-2)(Z-2)} \sum_{x'=1}^{X-2} \sum_{y'=1}^{Y-2} \sum_{z'=1}^{Z-2} [v(x',y',z') - \bar{v}] [v(x'+x, y'+y, z'+z) - \bar{v}] $$
[S1, unofficial]

**Step 3: Solve for Predictor Coefficients**
Solve the linear system $A \mathbf{a} = \mathbf{b}$ for coefficients $\mathbf{a} = [a_1, a_2, a_3]^T$ [S1, unofficial]. The matrix $A$ and vector $\mathbf{b}$ are constructed from the estimated covariances [S1, unofficial]:
$$
\begin{bmatrix}
r(0,0,0) & r(1,-1,0) & r(1,0,-1) \\
r(-1,1,0) & r(0,0,0) & r(0,1,-1) \\
r(-1,0,1) & r(0,-1,1) & r(0,0,0)
\end{bmatrix}
\begin{bmatrix}
a_1 \\
a_2 \\
a_3
\end{bmatrix}
=
\begin{bmatrix}
r(1,0,0) \\
r(0,1,0) \\
r(0,0,1)
\end{bmatrix}
$$
Note: The source provides this specific matrix layout in Equation (8), which may contain index typos compared to standard Yule-Walker derivations, but this is the implementation instruction given [S1, unofficial].

#### 2. Calculate Residuals (First Pass)
Scan the volume to calculate difference values $d(x,y,z)$ [S1, unofficial]. The predictor uses mean-subtracted neighbors to ensure orthogonality [S1, unofficial].

For each voxel $(x,y,z)$:
1.  Determine neighbor values $v_1, v_2, v_3$:
    $$
    v_1(x,y,z) = \begin{cases} 0 & \text{if } x=0 \\ v(x-1,y,z) - \bar{v} & \text{if } x>0 \end{cases}
    $$
    $$
    v_2(x,y,z) = \begin{cases} 0 & \text{if } y=0 \\ v(x,y-1,z) - \bar{v} & \text{if } y>0 \end{cases}
    $$
    $$
    v_3(x,y,z) = \begin{cases} 0 & \text{if } z=0 \\ v(x,y,z-1) - \bar{v} & \text{if } z>0 \end{cases}
    $$
2.  Calculate predicted value:
    $$ \tilde{v}(x,y,z) = a_1 v_1(x,y,z) + a_2 v_2(x,y,z) + a_3 v_3(x,y,z) $$
3.  Calculate residual:
    $$ d(x,y,z) = v(x,y,z) - \tilde{v}(x,y,z) $$
[S1, unofficial]

#### 3. Build Huffman Table
**Step 5: Count Frequencies**
Count the occurrences of each difference value $s_i$ across the volume to estimate symbol probabilities $p_i$ [S1, unofficial].

**Step 6: Construct Table**
Determine a truncated Huffman code table using probabilities $p_i$ [S1, unofficial]. The first $L_1$ most frequent symbols are Huffman coded; the remaining symbols are assigned fixed-length codes [S1, unofficial].

#### 4. Encode (Second Pass)
**Step 7: Encode**
Scan the volume again [S1, unofficial]. For each voxel, calculate $d(x,y,z)$ using the same predictor logic as Step 2 [S1, unofficial]. Encode $d(x,y,z)$ using the Huffman table [S1, unofficial]. Do not store the difference values; output only the encoded bits [S1, unofficial].

#### 5. Compressed File Header
Store the following in the file header before the bitstream:
-   Estimated mean $\bar{v}$
-   Predictor coefficients $a_1, a_2, a_3$
-   Huffman code table (mapping source symbols $s_i$ to codes) [S1, unofficial]

#### 6. Decompression
1.  Read $\bar{v}$, $a_1, a_2, a_3$, and the Huffman table from the header [S1, unofficial].
2.  Read the next Huffman code from the stream and look up the difference value $d(x,y,z)$ [S1, unofficial].
3.  Reconstruct the voxel using the same causal predictor and the decoded difference:
    $$ v(x,y,z) = \tilde{v}(x,y,z) + d(x,y,z) $$
    where $\tilde{v}(x,y,z)$ is calculated using the previously reconstructed neighbors $v(x-1,y,z)$, $v(x,y-1,z)$, and $v(x,y,z-1)$ [S1, unofficial].

### Pseudocode
```python
def compress_volume(volume: list, L1: int = 256) -> tuple:
    """
    Compress a 3D volume using Optimal Linear Predictor and Truncated Huffman Coding.
    volume: 3D list of shape (X, Y, Z) with 16-bit integers.
    Returns: tuple of (header_dict, compressed_bit_list).
    """
    X, Y, Z = len(volume), len(volume[0]), len(volume[0][0])
    
    # Step 1: Estimate Mean
    mean_v = sum(volume[x][y][z] for x in range(X) for y in range(Y) for z in range(Z)) / (X * Y * Z)
    
    # Step 2: Estimate Covariance
    cov = {}
    for dx in [-1, 0, 1]:
        for dy in [-1, 0, 1]:
            for dz in [-1, 0, 1]:
                total = 0
                count = 0
                for xp in range(1, X - 1):
                    for yp in range(1, Y - 1):
                        for zp in range(1, Z - 1):
                            total += (volume[xp][yp][zp] - mean_v) * (volume[xp + dx][yp + dy][zp + dz] - mean_v)
                            count += 1
                cov[(dx, dy, dz)] = total / count
                
    # Step 3: Solve for Coefficients (3x3 linear system) [G]
    r = cov
    A = [[r[(0,0,0)], r[(1,-1,0)], r[(1,0,-1)]],
         [r[(-1,1,0)], r[(0,0,0)], r[(0,1,-1)]],
         [r[(-1,0,1)], r[(0,-1,1)], r[(0,0,0)]]]
    b = [r[(1,0,0)], r[(0,1,0)], r[(0,0,1)]]
    a1, a2, a3 = solve_3x3(A, b) # [G]
    
    # Step 4 & 5: Calculate Residuals and Count Frequencies (Pass 1)
    freq = {}
    for x in range(X):
        for y in range(Y):
            for z in range(Z):
                v1 = 0 if x == 0 else volume[x-1][y][z] - mean_v
                v2 = 0 if y == 0 else volume[x][y-1][z] - mean_v
                v3 = 0 if z == 0 else volume[x][y][z-1] - mean_v
                pred = a1 * v1 + a2 * v2 + a3 * v3
                d = volume[x][y][z] - pred
                freq[d] = freq.get(d, 0) + 1
                
    # Step 6: Build Huffman Table [G]
    huffman_table = build_huffman_table(freq, L1)
    
    # Step 7: Encode (Pass 2)
    bitstream = []
    for x in range(X):
        for y in range(Y):
            for z in range(Z):
                v1 = 0 if x == 0 else volume[x-1][y][z] - mean_v
                v2 = 0 if y == 0 else volume[x][y-1][z] - mean_v
                v3 = 0 if z == 0 else volume[x][y][z-1] - mean_v
                pred = a1 * v1 + a2 * v2 + a3 * v3
                d = volume[x][y][z] - pred
                bitstream.append(huffman_table[d])
                
    header = {'mean': mean_v, 'coeffs': (a1, a2, a3), 'huffman_table': huffman_table}
    return header, bitstream # [G]

def decompress_volume(header: dict, bitstream: list, X: int, Y: int, Z: int) -> list:
    mean_v = header['mean']
    a1, a2, a3 = header['coeffs']
    inv_table = {code: sym for sym, code in header['huffman_table'].items()}
    
    volume = [[[0]*Z for _ in range(Y)] for _ in range(X)]
    
    for x in range(X):
        for y in range(Y):
            for z in range(Z):
                d = inv_table[bitstream.pop(0)]
                v1 = 0 if x == 0 else volume[x-1][y][z] - mean_v
                v2 = 0 if y == 0 else volume[x][y-1][z] - mean_v
                v3 = 0 if z == 0 else volume[x][y][z-1] - mean_v
                pred = a1 * v1 + a2 * v2 + a3 * v3
                volume[x][y][z] = pred + d
    return volume

def solve_3x3(A, b): # [G]
    # Standard Gaussian elimination for 3x3 system
    n = 3
    M = [A[i] + [b[i]] for i in range(n)]
    for i in range(n):
        for j in range(i+1, n):
            if M[i][i] == 0: continue
            factor = M[j][i] / M[i][i]
            for k in range(i, n+1):
                M[j][k] -= factor * M[i][k]
    x = [0]*n
    for i in range(n-1, -1, -1):
        x[i] = M[i][n]
        for j in range(i+1, n):
            x[i] -= M[i][j] * x[j]
        x[i] /= M[i][i]
    return x

def build_huffman_table(freq, L1): # [G]
    # Standard truncated Huffman construction
    sorted_syms = sorted(freq.items(), key=lambda item: item[1], reverse=True)
    table = {}
    for i, (sym, count) in enumerate(sorted_syms):
        if i < L1:
            table[sym] = f"code_{i}" # Placeholder for actual bit pattern
        else:
            table[sym] = f"fixed_{i-L1}"
    return table
```

### Edge Cases and Pitfalls
-   **Causality:** The predictor must only use previously processed voxels ($x-1, y, z$), ($x, y-1, z$), and ($x, y, z-1$) [S1, unofficial]. Using future voxels breaks decompression [S1, unofficial].
-   **Non-stationarity:** The optimal predictor assumes wide-sense stationarity [S1, unofficial]. Real volume data is not stationary, making global statistics suboptimal [S1, unofficial]. The source suggests dividing the volume into an octree for local predictors as a future improvement [S1, unofficial].
-   **Memory vs. Speed:** The algorithm scans the volume four times (two for statistics, one for residuals, one for encoding) to avoid storing the large residual array [S1, unofficial]. This increases CPU time but reduces memory footprint [S1, unofficial].
-   **Boundary Handling:** Neighbors at the boundary ($x=0, y=0, z=0$) are treated as 0 in the mean-subtracted space [S1, unofficial]. This ensures the prediction error is orthogonal to the input variables [S1, unofficial].

## Operating characteristics
-   **Time Complexity:** The algorithm requires four full scans of the volume [S1, unofficial]. The calculation of optimal predictor coefficients takes approximately 6% of the total compression time [S1, unofficial].
-   **Memory Complexity:** Low memory footprint during the main encoding pass as residuals are not stored [S1, unofficial]. Requires storage for the volume data and frequency counts [S1, unofficial].
-   **Performance:** Achieves approximately 50% lossless compression on medical volume datasets [S1, S2, unofficial]. On the `3dhead.vox` dataset (HP 9000 Series 735), compression took 4.7 minutes and decompression 1.4 minutes [S1, unofficial].
-   **Comparison:** Outperforms generic algorithms (gzip, zip, compress, pack) which only remove statistical redundancy, by also removing spatial redundancy [S1, unofficial].
-   **Entropy:** Typical entropies for test datasets range from 3.28 to 10.29 bits/voxel [S1, unofficial].
-   **Limitations:** The assumption of wide-sense stationarity limits optimality on non-stationary data [S1, unofficial]. The fixed 6-neighborhood predictor may be less effective than 18- or 26-neighborhood predictors, though the latter were not implemented in the core algorithm [S1, unofficial].

## Background
-   **Origin:** Introduced by James Edwin Fowler and Roni Yagel in January 1995 at the Proceedings of the 1994 Symposium on Volume Visualization [S1, unofficial].
-   **Context:** Developed to address the high storage requirements of volume data in biomedical and scientific applications where lossless compression is mandatory [S1, unofficial].
-   **Development:** The method combines Differential Pulse-Code Modulation (DPCM) with Huffman coding [S1, unofficial]. It was compared against generic compressors and simple fixed-coefficient predictors (e.g., $a_1=a_2=a_3=1/3$) [S1, unofficial].
