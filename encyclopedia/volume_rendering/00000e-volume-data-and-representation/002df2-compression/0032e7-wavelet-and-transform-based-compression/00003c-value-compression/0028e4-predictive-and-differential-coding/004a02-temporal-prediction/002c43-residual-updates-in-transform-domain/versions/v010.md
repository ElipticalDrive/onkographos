# Residual Updates in Transform Domain

Also called: Inter-frame DCT coding

## Overview
Residual Updates in Transform Domain is a temporal compression method for volumetric data that operates in the frequency domain rather than the spatial domain [S1]. It solves the problem of compressing sequences of volume datasets, such as TSDF volumes, by exploiting temporal coherence between frames [S1]. Unlike spatial prediction methods that estimate voxel values from neighbors, this method estimates the current frame's transform coefficients from the previously reconstructed frame's coefficients [S1]. It sets itself apart from siblings like [Delta Encoding](1096-delta-encoding.md) by performing subtraction and quantization in the DCT space, which concentrates residual energy more effectively for smooth volumetric changes, thereby improving compressibility for subsequent entropy coding [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A sequence of volumetric frames divided into blocks [S1]. For each block $b$ at time $t$, the input is the spatial samples $s_t^{(b)}$ [S1].
*   **Output:** A bitstream containing block metadata and entropy-coded residuals for active blocks [S1].

**Data Structures:**
*   **Reference Buffer:** A dictionary or array keyed by block coordinates, storing the reconstructed DCT coefficients $\tilde{\mathbf{c}}_{t-1}^{(b)}$ from the previous frame [S1].
*   **Current Coefficients:** $\mathbf{c}_t^{(b)}$, the DCT coefficients of the current frame's block [S1].
*   **Residual:** $\Delta \mathbf{c}_t^{(b)}$, the difference between current and reference coefficients [S1].

**Steps:**
1.  **Initialization:** The first frame is encoded using intra-coding (standard DCT, quantization, and entropy coding) to initialize the decoder's reference buffer [S1].
2.  **Transform:** For each subsequent frame $t$, divide the volume into blocks and compute the 3D DCT for each block $b$ to obtain coefficients $\mathbf{c}_t^{(b)}$ [S1].
3.  **Residual Formation:** For each block $b$, retrieve the reference coefficients $\tilde{\mathbf{c}}_{t-1}^{(b)}$ from the buffer [S1]. If block $b$ is active in the current frame, compute the residual $\Delta \mathbf{c}_t^{(b)} = \mathbf{c}_t^{(b)} - \tilde{\mathbf{c}}_{t-1}^{(b)}$ [S1]. If block $b$ is newly activated, set $\tilde{\mathbf{c}}_{t-1}^{(b)} = \mathbf{0}$ and compute $\Delta \mathbf{c}_t^{(b)} = \mathbf{c}_t^{(b)}$ [S1]. If block $b$ existed in the reference but is inactive in the current frame, treat it as a removal event by setting $\mathbf{c}_t^{(b)} = \mathbf{0}$ and computing $\Delta \mathbf{c}_t^{(b)} = -\tilde{\mathbf{c}}_{t-1}^{(b)}$ [S1].
4.  **Quantization:** Quantize the residual coefficients $\Delta \mathbf{c}_t^{(b)}$ using the same quantization steps (separate handling of DC and AC components) as the intra-coding mode [S1].
5.  **Entropy Coding:** Range-encode the quantized residual integers using the same per-coefficient entropy coding strategy as intra coding [S1].
6.  **Closed-Loop Update:** To prevent encoder-decoder drift, the encoder updates its reference buffer using the reconstructed residual rather than the original coefficients [S1].
    $$ \tilde{\mathbf{c}}_t^{(b)} = \tilde{\mathbf{c}}_{t-1}^{(b)} + Q^{-1}(Q(\Delta \mathbf{c}_t^{(b)})) $$
    where $Q(\cdot)$ denotes quantization and $Q^{-1}(\cdot)$ denotes dequantization [S1]. This updated buffer is used for the next frame $t+1$ [S1].

**Pseudocode:**
```python
def encode_temporal_transform_domain(current_blocks, prev_ref_buffer, all_block_ids, quantizer, entropy_coder):
    """
    Encodes a frame using residual updates in the transform domain.
    Args:
        current_blocks: Dict mapping block_id -> spatial_samples (array-like)
        prev_ref_buffer: Dict mapping block_id -> reconstructed_dct_coeffs (array-like)
        all_block_ids: Set of all block coordinates in the grid
        quantizer: Object with methods quantize(residual) and dequantize(q_residual)
        entropy_coder: Object with method encode(residuals)
    Returns:
        bitstream: Encoded data
        new_ref_buffer: Updated reference buffer for next frame
    """
    new_ref_buffer = {}
    bitstream = []
    
    for block_id in all_block_ids:
        # 1. Determine current coefficients
        if block_id in current_blocks:
            current_coeffs = compute_3d_dct(current_blocks[block_id])
        else:
            # Block is inactive in current frame (removal event)
            current_coeffs = [0.0] * len(prev_ref_buffer.get(block_id, []))
        
        # 2. Get reference coefficients
        if block_id in prev_ref_buffer:
            ref_coeffs = prev_ref_buffer[block_id]
        else:
            # Block is newly activated
            ref_coeffs = [0.0] * len(current_coeffs)
        
        # 3. Form residual
        residual_coeffs = [current_coeffs[i] - ref_coeffs[i] for i in range(len(current_coeffs))]
        
        # 4. Quantize
        q_residuals = quantizer.quantize(residual_coeffs)
        
        # 5. Encode
        entropy_coder.encode(q_residuals)
        
        # 6. Closed-loop update
        reconstructed_coeffs = [ref_coeffs[i] + quantizer.dequantize(q_residuals[i]) for i in range(len(q_residuals))]
        new_ref_buffer[block_id] = reconstructed_coeffs
        
    return bitstream, new_ref_buffer

def compute_3d_dct(samples):
    # [G] Standard 3D DCT-II computation applied separably along each dimension.
    return [0.0] * len(samples)
```

**Parameters:**
*   **Block Size:** Not given in the sources.
*   **Quantization Step:** Not given in the sources, but must match the intra-coding quantization strategy [S1].

**Edge Cases:**
*   **Block Appearance/Disappearance:** The method explicitly handles blocks that appear (newly activated) or disappear (removed) by treating them as residuals against zero or the reference, respectively [S1].
*   **Drift:** Failure to use the closed-loop update causes encoder-decoder mismatch [S1].

## Subtopics

### Zero-Motion Block Prediction
A specific application of residual updates in transform domain for TSDF volumes [S1]. It reuses the previous reconstructed TSDF on the same voxel block grid as a predictor [S1]. Only blockwise residual updates are encoded, which concentrates residual energy near regions of surface change and improves compressibility [S1]. It requires sending one intra-coded frame to initialize the decoder reference [S1].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of blocks and coefficients, requiring DCT computation per block and per-frame buffer updates [S1].
*   **Memory Complexity:** Requires storing the reference coefficient buffer for all active blocks [S1].
*   **Performance:** Improves compressibility for subsequent frames by concentrating residual energy near surface changes [S1].
*   **Strengths:** Computationally efficient and does not require explicit correspondence tracking often required by explicit geometry codecs [S1].
*   **Limitations:** Requires a block-based structure and performance depends on temporal coherence [S1].

## Background
Originated in the context of implicit surface compression using DCT and motion compensation [S1]. It leverages the regular, indexable structure of voxel blocks to simplify temporal coding [S1].
