# Residual Updates in Transform Domain

Also called: Inter-frame DCT coding

## Overview
Residual Updates in Transform Domain is a temporal compression method for volumetric data that operates in the frequency domain rather than the spatial domain. It solves the problem of efficiently encoding changes in dynamic implicit surfaces (such as TSDF volumes) by leveraging temporal coherence. Unlike spatial predictive coding which predicts voxel values from neighbors, this method predicts the current frame's transform coefficients (e.g., DCT) from the previously reconstructed frame's coefficients. It sets itself apart from siblings like [Delta Encoding](1096-delta-encoding.md) by working on transformed coefficients, which often concentrates residual energy more effectively for smooth volumetric changes, and from [Residual Coding for Volumetric Compression](6518-residual-coding-for-volumetric-compression.md) by explicitly handling block activation/deactivation events in the transform domain.

## How it works
The method assumes a block-based representation of the volume (e.g., a grid of voxel blocks). Each block is transformed (typically via 3D DCT) into a set of coefficients. The encoder maintains a reference buffer of reconstructed coefficients from the previous frame.

**Inputs and Outputs:**
*   **Input:** Current frame's block coefficients $\mathbf{c}_t^{(b)}$, previous frame's reconstructed coefficients $\tilde{\mathbf{c}}_{t-1}^{(b)}$, block activity status.
*   **Output:** Quantized and entropy-coded residuals $\Delta \mathbf{c}_t^{(b)}$.

**Data Structures:**
*   **Reference Buffer:** A map or array keyed by block coordinates $b$, storing $\tilde{\mathbf{c}}_{t-1}^{(b)}$.
*   **Block Coefficients:** For block $b$ at time $t$, $\mathbf{c}_t^{(b)} \in \mathbb{R}^k$ (where $k$ is the number of retained coefficients).

**Steps:**
1.  **Reference Initialization:** For the first frame ($t=0$), encode the block coefficients $\mathbf{c}_0^{(b)}$ using standard intra-coding (transform, quantize, entropy code). Initialize the reference buffer $\tilde{\mathbf{c}}_{-1}^{(b)} = \mathbf{c}_0^{(b)}$ (after reconstruction).
2.  **Residual Formation:** For each subsequent frame $t$ and each block $b$:
    *   If block $b$ is **active** in the current frame:
        $$ \Delta \mathbf{c}_t^{(b)} = \mathbf{c}_t^{(b)} - \tilde{\mathbf{c}}_{t-1}^{(b)} $$
    *   If block $b$ is **inactive** in the current frame but was present in the reference:
        Treat as a removal event. Set $\mathbf{c}_t^{(b)} = \mathbf{0}$ (or effectively $\Delta \mathbf{c}_t^{(b)} = -\tilde{\mathbf{c}}_{t-1}^{(b)}$).
    *   If block $b$ is **newly activated** (not in reference):
        Set $\tilde{\mathbf{c}}_{t-1}^{(b)} = \mathbf{0}$. Then $\Delta \mathbf{c}_t^{(b)} = \mathbf{c}_t^{(b)}$.
3.  **Quantization:** Quantize the residual coefficients $\Delta \mathbf{c}_t^{(b)}$ using the same quantization steps (e.g., $\Delta$DC, $\Delta$AC handling) as intra coding. Let $Q(\cdot)$ denote quantization.
4.  **Entropy Coding:** Range-encode the quantized integers using the same per-coefficient entropy coding strategy as intra coding.
5.  **Closed-Loop Update:** To prevent encoder-decoder drift, the encoder updates its reference buffer using the reconstructed residual:
    $$ \tilde{\mathbf{c}}_t^{(b)} = \tilde{\mathbf{c}}_{t-1}^{(b)} + Q^{-1}(Q(\Delta \mathbf{c}_t^{(b)})) $$
    where $Q^{-1}(\cdot)$ is dequantization. This ensures the decoder's reference matches the encoder's reference exactly.

**Pseudocode:**
```python
def transform_domain_encode(current_frame_blocks, prev_reconstructed_blocks, quantizer, entropy_coder):
    """
    Encodes temporal residuals in the transform domain.
    
    Args:
        current_frame_blocks: Dict mapping block_id -> coefficient_vector (c_t^(b))
        prev_reconstructed_blocks: Dict mapping block_id -> coefficient_vector (c_tilde_(t-1)^(b))
        quantizer: Function Q(x)
        entropy_coder: Function to encode integers
        
    Returns:
        List of encoded bitstreams for each block
    """
    encoded_data = []
    next_reconstructed_blocks = {}
    
    for block_id, c_t in current_frame_blocks.items():
        # Get reference coefficient; default to 0 if block was inactive/absent
        c_tilde_prev = prev_reconstructed_blocks.get(block_id, [0] * len(c_t))
        
        # Form residual
        delta_c = [c_t[i] - c_tilde_prev[i] for i in range(len(c_t))]
        
        # Quantize
        quantized_delta = quantizer(delta_c)
        
        # Entropy code
        bitstream = entropy_coder(quantized_delta)
        encoded_data.append((block_id, bitstream))
        
        # Closed-loop update: reconstruct and store for next frame
        dequantized_delta = quantizer.inverse(quantized_delta)
        c_tilde_curr = [c_tilde_prev[i] + dequantized_delta[i] for i in range(len(c_t))]
        next_reconstructed_blocks[block_id] = c_tilde_curr
        
    # Handle blocks that were active in prev frame but inactive in current
    for block_id in prev_reconstructed_blocks:
        if block_id not in current_frame_blocks:
            # Removal event: residual is -c_tilde_prev
            c_tilde_prev = prev_reconstructed_blocks[block_id]
            delta_c = [-c_tilde_prev[i] for i in range(len(c_tilde_prev))]
            
            quantized_delta = quantizer(delta_c)
            bitstream = entropy_coder(quantized_delta)
            encoded_data.append((block_id, bitstream))
            
            # Update reference to zero (block is now inactive)
            next_reconstructed_blocks[block_id] = [0] * len(c_tilde_prev)
            
    return encoded_data, next_reconstructed_blocks

def transform_domain_decode(encoded_data, prev_reconstructed_blocks, quantizer, entropy_decoder):
    """
    Decodes temporal residuals in the transform domain.
    """
    next_reconstructed_blocks = {}
    
    for block_id, bitstream in encoded_data:
        # Decode quantized residual
        quantized_delta = entropy_decoder(bitstream)
        
        # Dequantize
        dequantized_delta = quantizer.inverse(quantized_delta)
        
        # Get reference
        c_tilde_prev = prev_reconstructed_blocks.get(block_id, [0] * len(dequantized_delta))
        
        # Reconstruct current reference
        c_tilde_curr = [c_tilde_prev[i] + dequantized_delta[i] for i in range(len(c_tilde_prev))]
        next_reconstructed_blocks[block_id] = c_tilde_curr
        
    return next_reconstructed_blocks
```

**Parameters:**
*   **Block Size:** Not given in the sources.
*   **Transform:** 3D DCT is specified [S1].
*   **Quantization:** Same steps as intra coding [S1].

**Edge Cases:**
*   **Block Activation/Deactivation:** The method explicitly handles blocks appearing or disappearing by treating them as residuals against zero or the previous reference [S1].
*   **Drift:** Closed-loop update is mandatory to prevent divergence between encoder and decoder [S1].

## Subtopics

### Zero-Motion Block Prediction
A specific application of residual updates in the transform domain for TSDF volumes. It reuses the previous reconstructed TSDF on the same voxel block grid as a predictor. Only blockwise residual updates are encoded, concentrating residual energy near regions of surface change. It requires an initial intra-coded frame to initialize the decoder reference [S1].

## Operating characteristics
*   **Time Complexity:** Linear in the number of active blocks and coefficients. Transform and inverse transform operations are required if working in spatial domain, but here it operates directly on coefficients.
*   **Memory Complexity:** Requires storing the reference coefficient buffer for the previous frame.
*   **Strengths:** Computationally efficient; does not require explicit correspondence tracking often required by explicit geometry codecs [S1]. Improves compressibility for subsequent transform and range encoding by concentrating residual energy near surface changes [S1].
*   **Limitations:** Requires temporal coherence. Performance degrades if there is significant motion or non-rigid deformation that is not captured by block-wise residuals.
*   **When to use:** Dynamic volumetric data with smooth changes and temporal coherence, such as animated TSDF volumes.

## Background
Originated in the context of implicit surface compression using DCT and motion compensation [S1]. It leverages the regular, indexable structure of block-based representations to simplify temporal coding [S1].
