# Residual Updates in Transform Domain

Also called: Inter-frame DCT coding, Transform-domain temporal prediction

## Overview
Residual Updates in Transform Domain is a temporal compression method for volumetric data that operates in the frequency domain rather than the spatial domain. It solves the problem of compressing sequences of volume datasets (such as TSDF volumes) by exploiting temporal coherence between frames. Unlike spatial prediction methods that estimate voxel values from neighbors, this method estimates the current frame's transform coefficients from the previously reconstructed frame's coefficients. It sets itself apart from siblings like [Delta Encoding](1096-delta-encoding.md) by performing subtraction and quantization in the DCT space, which concentrates residual energy more effectively for smooth volumetric changes, thereby improving compressibility for subsequent entropy coding.

## How it works
**Inputs and Outputs:**
*   **Input:** A sequence of volumetric frames. Each frame is divided into blocks. For each block $b$ at time $t$, the input is the spatial samples $s_t^{(b)}$.
*   **Output:** A bitstream containing block metadata (presence/absence) and entropy-coded residuals for active blocks.

**Data Structures:**
*   **Reference Buffer:** A dictionary or array keyed by block coordinates $(x, y, z)$, storing the reconstructed DCT coefficients $\tilde{\mathbf{c}}_{t-1}^{(b)}$ from the previous frame.
*   **Current Coefficients:** $\mathbf{c}_t^{(b)}$, the DCT coefficients of the current frame's block.
*   **Residual:** $\Delta \mathbf{c}_t^{(b)}$, the difference between current and reference coefficients.

**Steps:**
1.  **Initialization:** The first frame is encoded using intra-coding (standard DCT + quantization + entropy coding) to initialize the decoder's reference buffer. No temporal prediction is used for the first frame.
2.  **Transform:** For each subsequent frame $t$, divide the volume into blocks. Compute the 3D DCT for each block $b$ to obtain coefficients $\mathbf{c}_t^{(b)}$.
3.  **Residual Formation:** For each block $b$:
    *   Retrieve the reference coefficients $\tilde{\mathbf{c}}_{t-1}^{(b)}$ from the buffer.
    *   Determine block status:
        *   If block $b$ is **active** in the current frame: Compute the residual $\Delta \mathbf{c}_t^{(b)} = \mathbf{c}_t^{(b)} - \tilde{\mathbf{c}}_{t-1}^{(b)}$.
        *   If block $b$ is **inactive** (removed) in the current frame but existed in the reference: Treat as a removal event. Set $\mathbf{c}_t^{(b)} = \mathbf{0}$ (implicitly) and compute residual $\Delta \mathbf{c}_t^{(b)} = \mathbf{0} - \tilde{\mathbf{c}}_{t-1}^{(b)} = -\tilde{\mathbf{c}}_{t-1}^{(b)}$.
        *   If block $b$ is **newly activated** (did not exist in reference): Set $\tilde{\mathbf{c}}_{t-1}^{(b)} = \mathbf{0}$. Compute residual $\Delta \mathbf{c}_t^{(b)} = \mathbf{c}_t^{(b)} - \mathbf{0} = \mathbf{c}_t^{(b)}$.
4.  **Quantization:** Quantize the residual coefficients $\Delta \mathbf{c}_t^{(b)}$ using the same quantization steps (e.g., separate handling of DC and AC components) as the intra-coding mode. Let $Q(\cdot)$ denote quantization.
5.  **Entropy Coding:** Range-encode the quantized residual integers using the same per-coefficient entropy coding strategy (adaptive probability models) as intra coding.
6.  **Closed-Loop Update:** To prevent encoder-decoder drift, the encoder must update its reference buffer using the reconstructed residual, not the original coefficients.
    $$ \tilde{\mathbf{c}}_t^{(b)} = \tilde{\mathbf{c}}_{t-1}^{(b)} + Q^{-1}(Q(\Delta \mathbf{c}_t^{(b)})) $$
    where $Q^{-1}(\cdot)$ is dequantization. This updated buffer is used for the next frame $t+1$.

**Pseudocode:**
```python
def encode_temporal_transform_domain(frame_blocks, prev_ref_buffer, quantizer, entropy_coder):
    """
    Encodes a frame using residual updates in the transform domain.
    
    Args:
        frame_blocks: Dict mapping block_id -> spatial_samples (numpy array)
        prev_ref_buffer: Dict mapping block_id -> reconstructed_dct_coeffs (numpy array)
        quantizer: Object with methods quantize(residual) and dequantize(q_residual)
        entropy_coder: Object with method encode(residuals)
        
    Returns:
        bitstream: Encoded data
        new_ref_buffer: Updated reference buffer for next frame
    """
    new_ref_buffer = {}
    bitstream = []
    
    for block_id, spatial_samples in frame_blocks.items():
        # 1. Transform current block
        current_coeffs = compute_3d_dct(spatial_samples)
        
        # 2. Get reference coefficients
        if block_id in prev_ref_buffer:
            ref_coeffs = prev_ref_buffer[block_id]
            is_active = True
        else:
            # Block is new or was inactive
            ref_coeffs = np.zeros_like(current_coeffs)
            is_active = True # We are encoding it now, so it's active in current frame
            
        # Note: If block_id was in prev_ref_buffer but NOT in frame_blocks,
        # it is a removal event. This is handled by the caller iterating only
        # over active blocks or explicitly signaling removals.
        # Assuming the loop iterates over ALL blocks present in the grid structure:
        if block_id not in frame_blocks:
            # Removal event: current coefficients are zero
            current_coeffs = np.zeros_like(ref_coeffs)
            is_active = False # Not sending spatial data, just residual of removal
            
        # 3. Form residual
        residual_coeffs = current_coeffs - ref_coeffs
        
        # 4. Quantize
        q_residuals = quantizer.quantize(residual_coeffs)
        
        # 5. Encode
        entropy_coder.encode(q_residuals)
        
        # 6. Closed-loop update
        # Reconstruct the coefficient for the next reference
        reconstructed_coeffs = ref_coeffs + quantizer.dequantize(q_residuals)
        new_ref_buffer[block_id] = reconstructed_coeffs
        
    return bitstream, new_ref_buffer

def compute_3d_dct(samples):
    # Standard 3D DCT implementation
    return np.real(np.fft.rfft(np.fft.rfft(np.fft.rfft(samples))))
```

**Parameters:**
*   **Block Size:** Not given in the sources.
*   **Quantization Step:** Not given in the sources, but must match the intra-coding quantization strategy.

**Edge Cases:**
*   **Block Appearance/Disappearance:** The method explicitly handles blocks that appear (newly activated) or disappear (removed) by treating them as residuals against zero or the reference, respectively [S1].
*   **Drift:** Failure to use the closed-loop update (Eq. 11) causes encoder-decoder mismatch [S1].

## Subtopics

### Zero-Motion Block Prediction
A specific application of residual updates in transform domain for TSDF volumes. It reuses the previous reconstructed TSDF on the same voxel block grid as a predictor. Only blockwise residual updates are encoded. This concentrates residual energy near regions of surface change, improving compressibility. It requires sending one intra-coded frame to initialize the decoder reference [S1].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of blocks and coefficients. Requires DCT computation per block and per-frame buffer updates.
*   **Memory Complexity:** Requires storing the reference coefficient buffer for all active blocks.
*   **Performance:** Improves compressibility for subsequent frames by concentrating residual energy near surface changes [S1].
*   **Strengths:** Computationally efficient; does not require explicit correspondence tracking often required by explicit geometry codecs [S1].
*   **Limitations:** Requires block-based structure; performance depends on temporal coherence.

## Background
Originated in the context of implicit surface compression using DCT and motion compensation [S1]. It leverages the regular, indexable structure of voxel blocks to simplify temporal coding [S1].
