# Delta Encoding
Also called: Differential pulse-code modulation, Heightfield Compression, Temporal prediction

## Overview
Delta encoding compresses data by storing the difference (residual) between a predicted value and the actual value, exploiting local coherence in space or time [S1][S2, unofficial]. It sets itself apart from sibling methods by typically using the immediately preceding value (in time or a linear scan order) as the predictor, rather than complex linear combinations or transform-domain residuals [S1][S2, unofficial]. This simplicity makes it highly effective for data with high temporal coherence or smooth spatial gradients, though it suffers from poor random access capabilities without auxiliary structures [S1][S2, unofficial].

## How it works
**Inputs:** A sequence of data values $V = \{v_0, v_1, \dots, v_{N-1}\}$ (e.g., voxel values over time or in a linearized volume).
**Outputs:** A sequence of delta values $D = \{d_0, d_1, \dots, d_{N-1}\}$, where $d_i$ is the residual for $v_i$.

**Data Structures:**
*   **Input Buffer:** Array of original values, size $N$, type $T$ (e.g., 16-bit integer, float).
*   **Output Buffer:** Array of delta values, size $N$, type $T$ or reduced bit-depth if quantization is applied.

**Steps:**
1.  **Prediction:** For each element $v_i$, predict the value $\hat{v}_i$ based on previously processed data.
    *   *Temporal Case:* $\hat{v}_i = v_{i-1}$ (the value from the previous time step) [S1].
    *   *Spatial/Heightfield Case:* $\hat{v}_i$ is often the previous element in a linearized block or a block base value [S2, unofficial].
    *   *Boundary Condition:* For the first element $v_0$, $\hat{v}_0 = v_0$ (resulting in $d_0 = 0$) or $\hat{v}_0 = 0$ [G].
2.  **Residual Calculation:** Compute the delta $d_i$ as the difference between the actual value and the prediction:
    $$ d_i = v_i - \hat{v}_i $$
    [S1]
3.  **Storage:** Store $d_i$. If the data exhibits coherence (e.g., unchanged regions), many $d_i$ will be zero or small, allowing efficient entropy coding [S1].
4.  **Reconstruction:** To recover $v_i$, add the decoded delta to the predicted value:
    $$ v_i = \hat{v}_i + d_i $$
    [S1]

**Pseudocode:**
```python
def delta_encode(values):
    """
    Encodes a sequence of values using delta encoding.
    values: List of numeric values (e.g., integers or floats).
    Returns: List of delta values.
    """
    if not values:
        return []
    
    deltas = []
    # Initialize previous value for the first element
    # Standard practice: predict first element as itself or zero.
    # Here we predict v[0] as v[0] so d[0] is 0, preserving absolute start.
    prev = values[0]
    
    for current in values:
        delta = current - prev
        deltas.append(delta)
        prev = current
        
    return deltas

def delta_decode(deltas):
    """
    Decodes a sequence of delta values back to original values.
    deltas: List of delta values.
    Returns: List of reconstructed original values.
    """
    if not deltas:
        return []
        
    reconstructed = []
    # The first delta is typically 0 if encoded as d[0] = v[0] - v[0]
    # Reconstruct v[0] by adding d[0] to the prediction of v[0].
    # If prediction was v[0] itself, we need the absolute value.
    # However, standard DPCM often stores d[0]=0 and relies on 
    # the decoder knowing v[0] or storing it separately.
    # Assuming d[0] corresponds to v[0] - v[0] = 0, we need v[0].
    # If the encoder stored d[0] = v[0] (predicting 0), then:
    
    # Let's assume the standard recursive reconstruction:
    # v[i] = v[i-1] + d[i]
    # This requires v[-1] to be defined or d[0] to be absolute.
    # Based on [S1], "Add the calculated delta value to the existing value".
    # This implies the decoder holds the previous reconstructed value.
    
    if len(deltas) == 0:
        return []
        
    # Initialize with the first delta. 
    # If d[0] is 0 (self-prediction), we need an external absolute value.
    # If d[0] is v[0] (predicting 0), we start with 0.
    # Common implementation: d[0] = v[0].
    current = deltas[0]
    reconstructed.append(current)
    
    for i in range(1, len(deltas)):
        delta = deltas[i]
        current = current + delta
        reconstructed.append(current)
        
    return reconstructed
```

**Parameters:**
*   **Prediction Model:** Usually nearest-neighbor in time or space [S1][S2, unofficial].
*   **Bit Depth:** Deltas may have a smaller dynamic range than original values, allowing reduced bit-depth storage [S1].

**Edge Cases and Pitfalls:**
*   **Random Access:** Delta encoding prevents jumping directly to a specific time step or index because all previous values must be decoded to reconstruct the current one [S1][S2, unofficial].
*   **Error Propagation:** In lossy variants or if transmission errors occur, a single corrupted delta affects all subsequent values [G].
*   **Storage Overhead:** Solving the random access problem by storing absolute values alongside deltas increases storage requirements [S1].

## Operating characteristics
*   **Time Complexity:** Encoding and decoding are $O(N)$, where $N$ is the number of elements. The operations are simple subtractions/additions, making them extremely fast [S1].
*   **Memory Complexity:** $O(N)$ for storing the deltas. No significant auxiliary memory is required during the core process [S1].
*   **Performance:** Highly effective for time-varying data with high temporal coherence (e.g., fluid simulations where voxels change slowly) [S1]. Also effective for heightfields with progressive variations [S2, unofficial].
*   **Strengths:** Simple implementation; low computational overhead; high compression ratios for coherent data [S1][S2, unofficial].
*   **Limitations:** Poor random access performance; requires sequential decoding [S1][S2, unofficial].
*   **When to Use:** When data has high temporal or spatial coherence and random access is not required or can be mitigated by block-based variants [S1][S2, unofficial].
*   **When Not to Use:** When random access to arbitrary time steps or spatial locations is critical without block-based modifications [S1][S2, unofficial].

## Background
Delta encoding, also known as Differential Pulse-Code Modulation (DPCM), has been used in volume rendering compression to exploit temporal coherence in time-varying data [S1]. It was highlighted in works such as [AABY06, FBS07] as a promising method for predicting voxel values by assuming they remain unchanged between time steps [S1]. It is also applied in heightfield compression for layered datasets [S2, unofficial].
