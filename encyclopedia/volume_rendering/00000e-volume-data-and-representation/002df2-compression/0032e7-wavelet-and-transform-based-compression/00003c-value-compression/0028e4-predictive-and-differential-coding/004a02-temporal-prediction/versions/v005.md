# Temporal Prediction
## Overview
Temporal prediction compresses time-varying volume data by exploiting temporal coherence between frames [S1]. It distinguishes itself from sibling methods like [Spatial Predictive Coding](12623-spatial-predictive-coding.md) by operating across time steps, and from [Residual Coding for Volumetric Compression](6518-residual-coding-for-volumetric-compression.md) by its specific focus on frame-to-frame dependencies in dynamic datasets [G].
## Shared principles
The sources describe several specific implementations rather than a single unified mathematical framework [S1]. Common elements include predicting current frame data from previous frames using delta encoding, applying transforms (e.g., Haar wavelets, DCT), quantizing residuals based on data range, and compressing the results with algorithms like LZO or vector quantization [S1]. Closed-loop reconstruction is required when using delta encoding to prevent error accumulation across time steps [G].
## Subtopics

### [Delta Encoding](1096-delta-encoding.md)
Operates directly in the spatial-temporal domain without prior transform steps, relying on unchanged regions producing zero-valued residuals. Choose when data exhibits high spatial-temporal coherence and uniform bricks can be exploited for compression.

### [Residual Updates in Transform Domain](5256-residual-updates-in-transform-domain.md)
Operates in the frequency domain (e.g., DCT), estimating current frame's transform coefficients from the previously reconstructed frame's coefficients. Choose when volumetric changes are smooth and frequency-domain concentration of residual energy improves compressibility.

### [MPEG-like Time-Variant Encoding](13596-mpeg-like-time-variant-encoding.md)
Applies lossy MPEG encoding principles to time-varying data, allowing high compression ratios and fast rendering via texture mapping hardware. Choose when hardware-accelerated on-the-fly decompression and rendering are available.

### [Difference encoding for time-variant volumes](13616-difference-encoding-for-time-variant-volumes.md)
Transforms data in the temporal domain by computing first- and second-order differences for each voxel's time series. Choose when temporal redundancy at individual spatial locations is high and entropy coding can exploit clustered coefficient distributions.

### Inter-frame Delta Encoding with Haar Wavelets
Classifies each time step as an intra-coded or predictive frame. All frames are encoded with Haar wavelets, but predictive frames are additionally expressed as deltas with respect to previous frames before encoding [S1].

### Dynamic Rendering with Advection
Augments a sample prediction network to take current time as input, outputs velocities to advect sample points to the nearest keyframe time using a forward-Euler step, and renders final color by summing over samples at the advected positions [S2].

## Background
Temporal prediction techniques have been applied to compressed GPU-based direct volume rendering to handle dynamic datasets [S1]. Early approaches included packing three time steps into RGB channels for 3D-RGB compression [NIH08] and classifying frames as intra-coded or predictive, encoding predictive frames as deltas with respect to previous frames using Haar wavelets [KLW∗ 08]. Subsequent methods performed delta encoding on block data with respect to the previous time step, quantizing blocks based on data range and encoding with LZO [MRH10], or performing delta encoding followed by hierarchical vector quantization [SBN11].
