# Optimal Linear Volumetric Predictor with Truncated Huffman Coding

Also called: DPCM with Huffman Coding, DPCM-Huffman, Predictive Huffman Coding for Volumes, Volume DPCM with Huffman Coding, compvox algorithm, volumetric DPCM with optimal coefficients, 差值编码与霍夫曼编码结合

## Overview
This method is a lossless compression algorithm for 3D volume data that exploits spatial coherence by predicting voxel values from previously encoded neighbors and encoding the difference (residual) using a truncated Huffman code [S1, unofficial]. It achieves approximately 50% compression ratios on biomedical volume datasets, outperforming generic compressors like gzip and zip by removing spatial redundancy in addition to statistical redundancy [S1, unofficial]. The method is distinguished from its siblings by the use of a globally optimal linear predictor derived from the Yule-Walker equations, which adapts to non-isotropic voxel sampling, combined with a truncated Huffman code to manage alphabet size [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D volume array $V$ of size $X \times Y \times Z$, where each voxel is a 16-bit integer [S1, unofficial].
*   **Output:** A compressed bitstream containing the encoded residuals, preceded by a header storing the estimated mean, predictor coefficients, and the Huffman code table [S1, unofficial].

**Data Structures:**
*   **Volume Data:** Stored in raster-scan order (x, then y, then z) to ensure causality [S1, unofficial].
*   **Huffman Table:** A mapping from source symbols (difference values $s_i$) to variable-length bit codes. The table includes entries for the $L_1$ most frequent symbols (Huffman coded) and the remaining $L - L_1$ symbols (fixed-length coded) [S1, unofficial].
*   **Header:** Contains the estimated mean $\bar{v}$, predictor coefficients $a_1, a_2, a_3$, and the Huffman code table [S1, unofficial].

**Parameters:**
*   **Predictor Order:** 3 coefficients ($a_1, a_2, a_3$) using the 6-neighborhood (face-sharing neighbors) [S1, unofficial].
*   **Truncated Huffman Parameter ($L_1$):** The number of most frequent symbols to be Huffman coded. Default value: $L_1 = 256$ [S1, unofficial].
*   **Alphabet Size ($L$):** For 16-bit voxels, difference values range from -66535 to 65536, resulting in $L = 131,071$ possible source symbols [S1, unofficial].

**Steps:**

1.  **Estimate Mean:** Scan the entire volume to calculate the mean $\bar{v}$ [S1, unofficial]:
    $$ \bar{v} = \frac{1}{XYZ} \sum_{x=0}^{X-1} \sum_{y=0}^{Y-1} \sum_{z=0}^{Z-1} v(x, y, z) $$

2.  **Estimate Covariance:** Scan the volume to estimate the covariance $r(x, y, z)$ for lags $x, y, z \in \{-1, 0, 1\}$ [S1, unofficial]:
    $$ r(x, y, z) = \frac{1}{(X-2)(Y-2)(Z-2)} \sum_{x'=1}^{X-2} \sum_{y'=1}^{Y-2} \sum_{z'=1}^{Z-2} [v(x', y', z') - \bar{v}] [v(x'+x, y'+y, z'+z) - \bar{v}] $$

3.  **Calculate Predictor Coefficients:** Solve the linear system $A\mathbf{a} = \mathbf{b}$ for coefficients $\mathbf{a} = [a_1, a_2, a_3]^T$ using the estimated covariance values [S1, unofficial]:
    $$
    \begin{bmatrix}
    r(0,0,0) & r(1,-1,0) & r(1,0,-1) \\
    r(-1,1,0) & r(0,0,0) & r(0,1,-1) \\
    r(-1,0,1) & r(0,-1,1) & r(0,0,0)
    \end{bmatrix}
    \begin{bmatrix}
    a_1 \\ a_2 \\ a_3
    \end{bmatrix}
    =
    \begin{bmatrix}
    r(1,0,0) \\ r(0,1,0) \\ r(0,0,1)
    \end{bmatrix}
    $$
    *Note: The source provides this specific matrix layout in Equation (8), which may contain index typos compared to standard Yule-Walker formulations, but this is the implementation instruction given [S1, unofficial].*

4.  **Calculate Difference Values (First Pass):** Scan the volume to compute residuals $d(x, y, z)$. For each voxel, calculate the predicted value $\tilde{v}(x, y, z)$ using mean-subtracted neighbors [S1, unofficial]:
    $$ \tilde{v}(x, y, z) = a_1 v_1(x, y, z) + a_2 v_2(x, y, z) + a_3 v_3(x, y, z) $$
    Where the neighbor values are adjusted for boundaries:
    $$
    v_1(x, y, z) = \begin{cases} 0 & \text{if } x=0 \\ v(x-1, y, z) - \bar{v} & \text{else} \end{cases}
    $$
    $$
    v_2(x, y, z) = \begin{cases} 0 & \text{if } y=0 \\ v(x, y-1, z) - \bar{v} & \text{else} \end{cases}
    $$
    $$
    v_3(x, y, z) = \begin{cases} 0 & \text{if } z=0 \\ v(x, y, z-1) - \bar{v} & \text{else} \end{cases}
    $$
    Then compute the difference:
    $$ d(x, y, z) = v(x, y, z) - \tilde{v}(x, y, z) $$
    *Note: The difference values are not stored to prevent excessive memory costs [S1, unofficial].*

5.  **Count Symbol Frequencies:** Count the occurrences of each difference value $d(x, y, z) = s_i$ across the volume to estimate symbol probabilities $p_i$ [S1, unofficial].

6.  **Build Huffman Table:** Determine a truncated Huffman code table using the probabilities $p_i$. The first $L_1=256$ most frequent symbols are Huffman coded. The remaining $L-L_1$ symbols are assigned fixed-length codes [S1, unofficial].

7.  **Encode (Second Pass):** Scan the volume again. Calculate $d(x, y, z)$ using the predictor (same as Step 4) and encode each $d(x, y, z)$ using the Huffman table from Step 6. Write the encoded bits to the output stream [S1, unofficial].

**Decompression:**
1.  Read the estimated mean $\bar{v}$, predictor coefficients $a_1, a_2, a_3$, and the Huffman code table from the compressed file header [S1, unofficial].
2.  Read the next Huffman code from the compressed file and look up the difference value $d(x, y, z)$ in the Huffman table [S1, unofficial].
3.  Reconstruct the current voxel value using the same predictor and the decoded difference [S1, unofficial]:
    $$ v(x, y, z) = \tilde{v}(x, y, z) + d(x, y, z) $$
    Where $\tilde{v}(x, y, z)$ is calculated using the previously reconstructed neighbors and the stored coefficients [S1, unofficial].

**Pseudocode:**

```python
def compress_volume(volume: List[List[List[int]]], L1: int = 256) -> bytes:
    X, Y, Z = len(volume), len(volume[0]), len(volume[0][0])
    
    # Step 1: Estimate Mean
    total_sum = 0
    for x in range(X):
        for y in range(Y):
            for z in range(Z):
                total_sum += volume[x][y][z]
    mean_v = total_sum / (X * Y * Z)
    
    # Step 2: Estimate Covariance
    # Covariance r(x,y,z) for x,y,z in {-1, 0, 1}
    # Note: Source uses specific indices for estimation range
    cov = {}
    for dx in [-1, 0, 1]:
        for dy in [-1, 0, 1]:
            for dz in [-1, 0, 1]:
                sum_cov = 0
                count = 0
                for x_prime in range(1, X - 1):
                    for y_prime in range(1, Y - 1):
                        for z_prime in range(1, Z - 1):
                            val1 = volume[x_prime][y_prime][z_prime] - mean_v
                            val2 = volume[x_prime + dx][y_prime + dy][z_prime + dz] - mean_v
                            sum_cov += val1 * val2
                            count += 1
                cov[(dx, dy, dz)] = sum_cov / count if count > 0 else 0
                
    # Step 3: Calculate Predictor Coefficients
    # Solve A * a = b
    # Matrix A and vector b defined by covariance estimates
    # A = [[r(0,0,0), r(1,-1,0), r(1,0,-1)],
    #      [r(-1,1,0), r(0,0,0), r(0,1,-1)],
    #      [r(-1,0,1), r(0,-1,1), r(0,0,0)]]
    # b = [r(1,0,0), r(0,1,0), r(0,0,1)]
    
    r000 = cov[(0, 0, 0)]
    r1m10 = cov[(1, -1, 0)]
    r10m1 = cov[(1, 0, -1)]
    rm110 = cov[(-1, 1, 0)]
    rm101 = cov[(-1, 0, 1)]
    r0m11 = cov[(0, -1, 1)]
    r01m1 = cov[(0, 1, -1)]
    
    r100 = cov[(1, 0, 0)]
    r010 = cov[(0, 1, 0)]
    r001 = cov[(0, 0, 1)]
    
    # Linear system solver (e.g., Gaussian elimination)
    A = [
        [r000, r1m10, r10m1],
        [rm110, r000, r01m1],
        [rm101, r0m11, r000]
    ]
    b = [r100, r010, r001]
    coeffs = solve_linear_system(A, b) # Returns [a1, a2, a3]
    a1, a2, a3 = coeffs
    
    # Step 4 & 5: Calculate Differences and Count Frequencies
    # We do not store differences to save memory, so we scan twice or store counts
    # Here we assume we can store counts in a dictionary/array
    diff_counts = {}
    
    # First pass: calculate diffs and count
    for x in range(X):
        for y in range(Y):
            for z in range(Z):
                # Calculate neighbors with mean subtraction
                if x == 0:
                    v1 = 0
                else:
                    v1 = volume[x-1][y][z] - mean_v
                    
                if y == 0:
                    v2 = 0
                else:
                    v2 = volume[x][y-1][z] - mean_v
                    
                if z == 0:
                    v3 = 0
                else:
                    v3 = volume[x][y][z-1] - mean_v
                    
                pred = a1 * v1 + a2 * v2 + a3 * v3
                diff = volume[x][y][z] - pred
                
                # Count frequency
                diff_counts[diff] = diff_counts.get(diff, 0) + 1
                
    # Step 6: Build Huffman Table
    # Sort symbols by frequency
    sorted_symbols = sorted(diff_counts.items(), key=lambda item: item[1], reverse=True)
    
    # Truncated Huffman: Top L1 symbols get Huffman codes, rest get fixed length
    huffman_table = {}
    
    # Assign Huffman codes to top L1 symbols
    # Implementation of Huffman tree construction omitted for brevity, 
    # assuming a function that generates codes based on probabilities
    top_symbols = sorted_symbols[:L1]
    probs_top = [count / (X*Y*Z) for _, count in top_symbols]
    symbols_top = [sym for sym, _ in top_symbols]
    
    # Generate Huffman codes for top symbols
    huffman_codes = generate_huffman_codes(symbols_top, probs_top)
    for i, sym in enumerate(symbols_top):
        huffman_table[sym] = huffman_codes[i]
        
    # Assign fixed-length codes to remaining symbols
    remaining_symbols = sorted_symbols[L1:]
    fixed_length_bits = ceil(log2(len(remaining_symbols))) if remaining_symbols else 0
    
    for i, (sym, _) in enumerate(remaining_symbols):
        # Fixed length code based on index i
        code = format(i, f'0{fixed_length_bits}b')
        huffman_table[sym] = code
        
    # Step 7: Encode
    bitstream = []
    
    # Encode header
    bitstream.append(mean_v) # Store mean
    bitstream.append(coeffs) # Store coefficients
    bitstream.append(huffman_table) # Store table
    
    # Encode data
    for x in range(X):
        for y in range(Y):
            for z in range(Z):
                # Recalculate diff (same as Step 4)
                if x == 0:
                    v1 = 0
                else:
                    v1 = volume[x-1][y][z] - mean_v
                    
                if y == 0:
                    v2 = 0
                else:
                    v2 = volume[x][y-1][z] - mean_v
                    
                if z == 0:
                    v3 = 0
                else:
                    v3 = volume[x][y][z-1] - mean_v
                    
                pred = a1 * v1 + a2 * v2 + a3 * v3
                diff = volume[x][y][z] - pred
                
                # Encode diff
                code = huffman_table[diff]
                bitstream.append(code)
                
    return bitstream

def decompress_volume(compressed_data: bytes, X: int, Y: int, Z: int) -> List[List[List[int]]]:
    # Extract header
    mean_v, coeffs, huffman_table = extract_header(compressed_data)
    a1, a2, a3 = coeffs
    volume = [[[0 for z in range(Z)] for y in range(Y)] for x in range(X)]
    
    # Decode data
    bitstream = extract_bitstream(compressed_data)
    
    for x in range(X):
        for y in range(Y):
            for z in range(Z):
                # Calculate prediction using previously reconstructed neighbors
                if x == 0:
                    v1 = 0
                else:
                    v1 = volume[x-1][y][z] - mean_v
                    
                if y == 0:
                    v2 = 0
                else:
                    v2 = volume[x][y-1][z] - mean_v
                    
                if z == 0:
                    v3 = 0
                else:
                    v3 = volume[x][y][z-1] - mean_v
                    
                pred = a1 * v1 + a2 * v2 + a3 * v3
                
                # Decode diff
                diff = decode_huffman(bitstream, huffman_table)
                
                # Reconstruct voxel
                volume[x][y][z] = pred + diff
                
    return volume
```

## Operating characteristics
*   **Time Complexity:** The algorithm scans the volume four times: two scans for statistics (mean and covariance), one scan to calculate differences (not stored), and one scan for encoding [S1, unofficial]. The calculation of the optimal predictor takes approximately 6% of the total compression time [S1, unofficial].
*   **Memory Complexity:** The algorithm avoids storing the difference values to prevent excessive memory costs, necessitating the fourth scan [S1, unofficial].
*   **Performance:** On a set of volume data files, the method achieves around 50% compression [S1, unofficial]. For the `3dhead.vox` dataset (256x256x109, 13.6 Mb) on an HP 9000 Series 735, compression time was 4.7 minutes and decompression time was 1.4 minutes [S1, unofficial]. The compression ratio was 48.5%, compared to 36.1% for gzip and 33.8% for zip [S1, unofficial].
*   **Strengths:** Removes spatial redundancy in addition to statistical redundancy, achieving better compression than generic algorithms [S1, unofficial]. The optimal predictor automatically compensates for non-isotropic sampling [S1, unofficial].
*   **Limitations:** Assumes wide-sense stationarity, which may not hold for real volume data, making global statistics suboptimal [S1, unofficial]. The four-pass nature can be computationally intensive [S1, unofficial].

## Background
The method was introduced by James Edwin Fowler and Roni Yagel in January 1995 at the Proceedings of the 1994 symposium on Volume visualization [S1, unofficial]. It was developed to address the large storage requirements of volume data in biomedical and scientific applications where lossless compression is essential [S1, unofficial]. The algorithm combines differential pulse-code modulation (DPCM) with Huffman coding [S1, unofficial].
