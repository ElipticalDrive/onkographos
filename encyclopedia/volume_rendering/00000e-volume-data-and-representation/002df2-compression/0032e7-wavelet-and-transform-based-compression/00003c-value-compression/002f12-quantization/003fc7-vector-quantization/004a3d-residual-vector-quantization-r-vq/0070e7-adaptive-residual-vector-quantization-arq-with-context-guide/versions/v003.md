# Adaptive Residual Vector Quantization (ARQ) with Context-Guided Recovery

Also called: ARQEC, Adaptive Residual Vector Quantization (ARQ) with Attribute Adaptation, Adaptive-Depth RVQ

## Overview
Adaptive Residual Vector Quantization (ARQ) with Context-Guided Recovery is a compression method for 3D Gaussian Splatting (3DGS) that compresses high-dimensional anchor features using three-stage residual vector quantization (RVQ) with per-anchor adaptive depth, recovers features using spatial context, and refines quantized offsets and scaling using an attribute adapter [S1, unofficial]. Unlike progressive methods that provide multiple reconstruction levels, ARQ produces a single compressed anchor representation where the RVQ depth is determined separately for each anchor based on a local rate-distortion proxy, followed by rendering-based calibration [S1, unofficial]. It builds on [Residual Vector Quantization (R-VQ)](12711-residual-vector-quantization-r-vq.md) by adding adaptive depth selection and context-guided refinement [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Pretrained anchor-based 3DGS representation. For each anchor $i \in \{1, \dots, N_a\}$, the input attributes are $\mathcal{A}_i = \{\mathbf{x}_i, \mathbf{f}_i^{Tea}, \mathbf{s}_i^{Tea}, \mathbf{O}_i^{Tea}\}$ [S1, unofficial].
    *   $\mathbf{x}_i \in \mathbb{R}^3$: Anchor center position (unchanged during compression) [S1, unofficial].
    *   $\mathbf{f}_i^{Tea} \in \mathbb{R}^{D_f}$: Anchor feature vector before quantization ($D_f$ is feature dimension) [S1, unofficial].
    *   $\mathbf{s}_i^{Tea} \in \mathbb{R}^6$: Teacher scaling vector [S1, unofficial].
    *   $\mathbf{O}_i^{Tea} \in \mathbb{R}^{K \times 3}$: Teacher local offsets ($K$ offsets per anchor) [S1, unofficial].
    *   $\mathcal{H}$: Decoded spatial hash grid from the base HAC representation [S1, unofficial].
*   **Output:** Compressed bitstream containing the depth symbol $d_i$, RVQ indices $\mathbf{z}_i$, and entropy-coded symbols [S1, unofficial]. Decoded state includes adapted scaling $\hat{\mathbf{s}}_i^{anchor}$ and offsets $\hat{\mathbf{O}}_i$ [S1, unofficial].

**Data Structures:**
*   **Codebooks:** $\mathbf{C}^{(l)} \in \mathbb{R}^{M_l \times D_f}$ for stage $l \in \{1, 2, 3\}$, where $M_l$ is the number of codewords [S1, unofficial].
*   **Indices:** $\mathbf{z}_i = (z_i^{(1)}, \dots, z_i^{(d_i)})$ where $z_i^{(l)} \in \{1, \dots, M_l\}$ is the selected index at stage $l$ [S1, unofficial].
*   **Depth Symbol:** $d_i \in \{1, 2, 3\}$, the quantization depth for anchor $i$ [S1, unofficial].
*   **Mask:** $m_i^{(l)} = \mathbb{I}[d_i \geq l]$ indicates if stage $l$ is active [S1, unofficial].
*   **Context:** $\mathbf{h}_i = \text{Interp}(\mathbf{x}_i, \mathcal{H})$ is the spatial context interpolated from the hash grid [S1, unofficial].
*   **Embedding:** $\mathbf{e}(d_i)$ is the embedding of the depth symbol [S1, unofficial].

**Numbered Steps:**

1.  **Initialization:** For each anchor $i$, initialize the residual $\mathbf{r}_i^{(0)} = \mathbf{f}_i^{Tea}$ [S1, unofficial]. For each stage $l \in \{1, 2, 3\}$, find the nearest neighbor index:
    $$z_{i,\text{NN}}^{(l)} = \arg \min_{k \in \{1, \dots, M_l\}} \left\| \mathbf{r}_i^{(l-1)} - \mathbf{C}^{(l)}[k] \right\|_2^2 \quad (3)$$
    Initialize the selected index $z_i^{(l)}$ with $z_{i,\text{NN}}^{(l)}$. This index may be reselected later by rate-distortion search [S1, unofficial].

2.  **Context Interpolation:** Compute the spatial context $\mathbf{h}_i$ by interpolating from the decoded spatial hash grid $\mathcal{H}$ at the anchor's position $\mathbf{x}_i$:
    $$\mathbf{h}_i = \text{Interp}(\mathbf{x}_i, \mathcal{H}) \quad (8)$$
    This step is performed at the decoder and introduces no additional per-anchor storage [S1, unofficial].

3.  **Context Refiner Input Construction:** Construct the input vector $\mathbf{u}_i$ for the Context Refiner by concatenating masked quantized codewords, spatial context, and depth embedding:
    $$\mathbf{u}_i = \left[ m_i^{(1)} \mathbf{q}_i^{(1)}, m_i^{(2)} \mathbf{q}_i^{(2)}, m_i^{(3)} \mathbf{q}_i^{(3)}, \mathbf{h}_i, \mathbf{e}(d_i) \right] \quad (9)$$
    where $\mathbf{q}_i^{(l)} = \mathbf{C}^{(l)}[z_i^{(l)}]$ is the codeword lookup [S1, unofficial].

4.  **Feature Recovery and Attribute Adaptation:** The Context Refiner recovers the anchor feature $\hat{\mathbf{f}}_i^{Stu}$ from $\mathbf{u}_i$ [S1, unofficial]. The Attribute Adapter then refines the quantized offsets $\tilde{\mathbf{O}}_i$ and scaling $\tilde{\mathbf{s}}_i$ (produced by the base HAC quantizer) based on the recovered features, yielding adapted estimates $\hat{\mathbf{O}}_i$ and $\hat{\mathbf{s}}_i^{anchor}$ [S1, unofficial].

5.  **Error Calculation:** Compute the proxy distortion components for a candidate depth $d$ and index set $\mathbf{z}$:
    *   **Offset Error:**
        $$E_i^O(d, \mathbf{z}) = \frac{1}{3K} \left\| (\hat{\mathbf{O}}_i(d, \mathbf{z}) - \mathbf{O}_i^{Tea}) \circ (\mathbf{s}_i^{pos,Tea} + \epsilon) \right\|_1 \quad (17)$$
        where $\mathbf{s}_i^{pos,Tea}$ are the first 3 dims of the teacher scaling, replicated $K$ times, and $\epsilon > 0$ is for stability [S1, unofficial].
    *   **Scaling Error:**
        $$E_i^S(d, \mathbf{z}) = \frac{1}{6} \left\| \log(\hat{\mathbf{s}}_i^{anchor}(d, \mathbf{z}) + \epsilon) - \log(\mathbf{s}_i^{anchor,Tea} + \epsilon) \right\|_1 \quad (18)$$
        where $\epsilon > 0$ is for stability [S1, unofficial].
    *   **Feature Error:** $E_i^f(d, \mathbf{z})$ is computed similarly (formula truncated in source, but implied as part of the proxy) [S1, unofficial].

6.  **Local Rate-Distortion Cost:** Combine errors into a proxy distortion:
    $$\widehat{D}(d, \mathbf{z}) = \lambda_f^{\text{RD}} E_i^f(d, \mathbf{z}) + \lambda_O E_i^O(d, \mathbf{z}) + \lambda_S E_i^S(d, \mathbf{z}) \quad (19)$$
    where $\lambda_f^{\text{RD}}, \lambda_O, \lambda_S$ control relative contributions [S1, unofficial].

7.  **Fixed-Depth Index Search:** For each depth $d \in \{1, 2, 3\}$, perform stage-wise beam search to find optimal indices $\mathbf{z}_i(d)$:
    *   At stage $l$, select candidates from $K_{dist}$ entries with smallest Euclidean distance to the residual and $K_{prob}$ entries with highest conditional probability $p_l(z_i^{(l)} \mid \mathbf{h}_i, \mathbf{e}(d_i), \mathbf{z}_i^{(<l)})$ [S1, unofficial].
    *   Union of these expands partial paths. The beam is pruned at each stage [S1, unofficial].
    *   The retained complete index paths form the set $\mathcal{B}_i(d)$ [S1, unofficial].

8.  **Depth Selection:** Calculate the proxy-distortion reduction and rate increase for moving from depth $l-1$ to $l$:
    $$\Delta_i^{(l)} = \widehat{D}_i(l-1, \mathbf{z}_{i,l-1}) - \widehat{D}_i(l, \mathbf{z}_{i,l}) \quad (23)$$
    $$\Delta R_i^{(l)} = R_i(l, \mathbf{z}_{i,l}) - R_i(l-1, \mathbf{z}_{i,l-1}) \quad (24)$$
    The estimated code length is:
    $$R_i(d_i, \mathbf{z}_i) = -\log_2 p_d(d_i \mid \mathbf{h}_i, \mathbf{x}_i) - \sum_{l=1}^{d_i} \log_2 p_l\left(\mathbf{z}_i^{(l)} \mid \mathbf{h}_i, \mathbf{e}(d_i), \mathbf{z}_i^{(<l)}\right) \quad (15)$$
    The local depth-selection cost is:
    $$\Delta \mathcal{J}_i^{(l)} = -w_i \Delta_i^{(l)} + \lambda_{\text{depth}} \Delta R_i^{(l)} \quad (25)$$
    where $\lambda_{\text{depth}}$ controls the rate penalty of an additional RVQ stage [S1, unofficial]. If $\Delta \mathcal{J}_i^{(l)} < 0$, the deeper representation is retained as a candidate [S1, unofficial].

9.  **Rendering-Based Calibration:** Evaluate selected depth changes by rendering held-out calibration views to account for visibility, Gaussian overlap, and alpha-compositing interactions [S1, unofficial]. Divide pending anchors into candidate groups and evaluate sequentially to limit computational cost [S1, unofficial]. The average rendering distortion is:
    $$\mathcal{D}_{\text{cal}} \left( I^{Stu}, I^{GT} \right) = \frac{1}{|\mathcal{V}_{\text{cal}}|} \sum_{v \in \mathcal{V}_{\text{cal}}} \dots$$
    (Formula truncated in source) [S1, unofficial].

10. **Entropy Coding:** Encode the depth symbol $d_i$ before the RVQ indices so the decoder knows how many indices to read [S1, unofficial]. Convert predicted probabilities into integer cumulative distribution functions (CDFs) for arithmetic coding [S1, unofficial].

**Pseudocode:**

```python
import math

def arq_compress(anchor_features, positions, teacher_scales, teacher_offsets, 
                 codebooks, hash_grid, lambda_depth, K_dist, K_prob, 
                 lambda_f_RD, lambda_O, lambda_S, epsilon):
    """
    Compress anchor features using ARQ with Context-Guided Recovery.
    """
    compressed_data = {}
    
    for i in range(len(anchor_features)):
        f_Tea = anchor_features[i]
        x_i = positions[i]
        s_Tea = teacher_scales[i]
        O_Tea = teacher_offsets[i]
        
        # Step 1: Initialize residuals and nearest neighbors
        r = f_Tea.copy()
        nn_indices = []
        for l in range(1, 4): # Stages 1, 2, 3
            C_l = codebooks[l-1]
            distances = [sum((a - b) ** 2 for a, b in zip(C_l[k], r)) for k in range(len(C_l))]
            nn_idx = distances.index(min(distances))
            nn_indices.append(nn_idx)
            
        # Step 2: Context Interpolation
        # h_i = Interp(x_i, H) [G]
        h_i = [0.0] * 64  # Placeholder for hash grid interpolation [G]
        
        # Step 3-4: Context Refiner Input Construction & Feature Recovery
        # u_i = [m^(1)q^(1), m^(2)q^(2), m^(3)q^(3), h_i, e(d_i)]
        # Context Refiner recovers f_hat^Stu from u_i [G]
        # Attribute Adapter refines offsets and scales [G]
        
        # Step 5-8: Depth Selection and Index Search
        best_depth = 1
        best_indices = [nn_indices[0]]
        best_proxy_dist = float('inf')
        best_rate = 0
        
        depths_to_evaluate = [1, 2, 3]
        
        for d in depths_to_evaluate:
            # Fixed-Depth Index Search (Beam Search)
            current_indices = find_best_indices_beam_search(
                f_Tea, codebooks[:d], h_i, lambda_depth, K_dist, K_prob, epsilon
            )
            
            masks = [1 if l <= d else 0 for l in range(1, 4)]
            
            codewords = []
            for l in range(1, d+1):
                idx = current_indices[l-1]
                codewords.append(codebooks[l-1][idx])
            
            full_codewords = []
            for l in range(1, 4):
                if l <= d:
                    full_codewords.append(codewords[l-1])
                else:
                    full_codewords.append([0.0] * len(codewords[0]))
                    
            e_d = [0.0] * 8  # Placeholder for depth embedding [G]
            u_i = []
            for l in range(3):
                u_i.extend(masks[l] * full_codewords[l])
            u_i.extend(h_i)
            u_i.extend(e_d)
            
            f_hat, O_hat, s_hat = [0.0]*len(u_i), [[0.0]*3 for _ in range(len(O_Tea))], [0.0]*6  # Placeholder for Context Refiner & Adapter [G]
            
            s_pos_Tea = s_Tea[:3]
            s_pos_rep = [s_pos_Tea for _ in range(len(O_Tea))]
            offset_diff = [[O_hat[j][k] - O_Tea[j][k] for k in range(3)] for j in range(len(O_Tea))]
            offset_error = sum(abs(offset_diff[j][k] * (s_pos_rep[j][k] + epsilon)) for j in range(len(O_Tea)) for k in range(3)) / (3 * len(O_Tea))
            
            scale_error = sum(abs(math.log(s_hat[k] + epsilon) - math.log(s_Tea[k] + epsilon)) for k in range(6)) / 6
            feature_error = sum(abs(f_hat[k] - f_Tea[k]) for k in range(len(f_hat)))
            
            proxy_dist = lambda_f_RD * feature_error + lambda_O * offset_error + lambda_S * scale_error
            
            p_d = 0.5  # Placeholder for depth probability [G]
            rate_depth = -math.log2(p_d)
            
            rate_indices = 0
            for l in range(1, d+1):
                p_l = 0.5  # Placeholder for index probability [G]
                rate_indices -= math.log2(p_l)
                
            total_rate = rate_depth + rate_indices
            
            if d > 1:
                prev_proxy_dist = best_proxy_dist
                prev_rate = best_rate
                
                delta_D = prev_proxy_dist - proxy_dist
                delta_R = total_rate - prev_rate
                
                w_i = 1.0  # Placeholder for importance weight [G]
                delta_J = -w_i * delta_D + lambda_depth * delta_R
                
                if delta_J < 0:
                    best_depth = d
                    best_indices = current_indices
                    best_proxy_dist = proxy_dist
                    best_rate = total_rate
            else:
                best_depth = d
                best_indices = current_indices
                best_proxy_dist = proxy_dist
                best_rate = total_rate
                
        compressed_data[i] = {
            'depth': best_depth,
            'indices': best_indices,
            'context': h_i,
            'adapted_offsets': O_hat,
            'adapted_scales': s_hat
        }
        
    return compressed_data

def find_best_indices_beam_search(f_Tea, codebooks, h_i, lambda_depth, K_dist, K_prob, epsilon):
    """
    Perform stage-wise beam search to find best indices for a given depth.
    """
    beam = [(f_Tea.copy(), [], 0.0, 0.0)]
    
    for l in range(1, len(codebooks) + 1):
        C_l = codebooks[l-1]
        new_beam = []
        
        for residual, indices, rate, dist in beam:
            distances = [sum((a - b) ** 2 for a, b in zip(C_l[k], residual)) for k in range(len(C_l))]
            closest_indices = sorted(range(len(distances)), key=lambda k: distances[k])[:K_dist]
            
            probs = [0.5] * len(C_l)  # Placeholder for index probabilities [G]
            prob_indices = sorted(range(len(probs)), key=lambda k: probs[k], reverse=True)[:K_prob]
            
            candidate_indices = sorted(list(set(closest_indices + prob_indices)))
            
            for idx in candidate_indices:
                q = C_l[idx]
                new_residual = [residual[k] - q[k] for k in range(len(residual))]
                new_indices = indices + [idx]
                
                p_l = 0.5  # Placeholder for index probability [G]
                new_rate = rate - math.log2(p_l)
                
                new_dist = math.sqrt(sum(x**2 for x in new_residual))
                
                new_beam.append((new_residual, new_indices, new_rate, new_dist))
        
        K_beam = 10
        new_beam.sort(key=lambda x: x[2] + x[3])
        beam = new_beam[:K_beam]
        
    best = min(beam, key=lambda x: x[2] + x[3])
    return best[1]
```

**Parameters:**
*   **Quantization Depth $d_i$:** An integer in $\{1, 2, 3\}$ assigned to each anchor, determining how many RVQ stages are active [S1, unofficial].
*   **$\lambda_{\text{depth}}$:** Parameter controlling the rate penalty of an additional RVQ stage in depth selection [S1, unofficial].
*   **$K_{dist}$:** Number of closest codewords to consider in beam search [S1, unofficial].
*   **$K_{prob}$:** Number of highest probability codewords to consider in beam search [S1, unofficial].
*   **$\lambda_f^{\text{RD}}, \lambda_O, \lambda_S$:** Weights for feature, offset, and scaling errors in proxy distortion [S1, unofficial].
*   **$\epsilon$:** Small constant for numerical stability in offset and scaling error calculations [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision:** Use $\epsilon > 0$ in offset and scaling error calculations to avoid division by zero or log of zero [S1, unofficial].
*   **Boundaries:** The depth symbol $d_i$ is encoded before RVQ indices to ensure the decoder knows how many indices to read [S1, unofficial].
*   **Degenerate Input:** If an anchor has no valid context (e.g., out of bounds), interpolation should handle this gracefully (e.g., return zero vector) [G].

## Subtopics

### [Rendering-based calibration for depth selection](18737-rendering-based-calibration-for-depth-selection.md)
A post-selection refinement step that evaluates candidate depth changes by rendering held-out calibration views to account for visibility, Gaussian overlap, and alpha-compositing interactions which are not explicitly modeled by the local proxy. It serves as the final quality gate in Adaptive Residual Vector Quantization (ARQ) with Context-Guided Recovery, ensuring that depth adjustments selected via local proxies actually improve the rendered image quality.

### [Two-Stage Vector Quantization (VQ) for SH-AC](19632-two-stage-vector-quantization-vq-for-sh-ac.md)
Two-Stage VQ for SH-AC is a compression method for Spherical Harmonic (SH) coefficients in 3D Gaussian Splatting (3DGS) that reduces bitrate by separating coarse shape approximation from fine residual detail. It builds on [KNN-based Grouping for SH-AC Residuals](19531-knn-based-grouping-for-sh-ac-residuals.md) by applying vector quantization to grouped residual sub-vectors rather than the original coefficients. Unlike its parent method which only groups residuals, this method explicitly quantizes both the coarse vector and the grouped residuals using separate codebooks, enabling efficient entropy coding of the resulting indices.

## Operating characteristics
*   **Time Complexity:** The method involves a three-stage RVQ with beam search, which is computationally expensive due to the need to evaluate multiple candidates for each anchor. The rendering-based calibration adds further computational cost as it requires rendering held-out views [S1, unofficial].
*   **Memory Complexity:** The method stores the codebooks, the spatial hash grid, and the compressed indices and depth symbols. The context is interpolated from the hash grid, so no additional per-anchor storage is needed for context [S1, unofficial].
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** The method scales with the number of anchors and the complexity of the beam search. The rendering-based calibration scales with the number of calibration views and the number of candidate anchors [S1, unofficial].
*   **Strengths:** Adaptive depth allows for efficient compression by assigning more bits to complex anchors and fewer to simple ones. Context-guided recovery improves reconstruction quality. Attribute adaptation refines offsets and scaling for better visual fidelity [S1, unofficial].
*   **Limitations:** High computational cost due to beam search and rendering-based calibration. The method is specific to 3D Gaussian Splatting [S1, unofficial].
*   **When to use:** When high-quality compression of 3D Gaussian Splatting representations is required and computational resources are available for the encoding process [S1, unofficial].

## Background
Adaptive Residual Vector Quantization (ARQ) with Context-Guided Recovery was introduced in the paper "3D Gaussian Splatting Data Compression via Adaptive Residual Quantization and Error Compensation" [S1, unofficial]. It is designed to compress the high-dimensional anchor features of a pretrained anchor-based 3DGS representation [S1, unofficial]. The method combines residual vector quantization with adaptive depth selection, context-guided feature recovery, and attribute adaptation to achieve high compression ratios while maintaining visual quality [S1, unofficial].
