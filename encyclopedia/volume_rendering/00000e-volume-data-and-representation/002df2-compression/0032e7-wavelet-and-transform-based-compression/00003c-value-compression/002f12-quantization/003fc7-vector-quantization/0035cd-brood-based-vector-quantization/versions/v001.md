# Brood-based Vector Quantization

Also called: Residual VQ, VQ compression

## Overview
Brood-based Vector Quantization is a lossy compression method that reduces the storage size of inter-level data residuals in hierarchical tree structures by grouping them into blocks (broods) and replacing each block with a codebook index [S1, unofficial]. It sets itself apart from standard uniform-grid VQ by operating on tree-based residuals, which allows it to correct coarse-level errors in finer levels and yield significantly less error for the same bit rate [S1, unofficial]. It builds on [Vector Quantization](907-vector-quantization.md) by applying it specifically to the residual vectors associated with sibling nodes in a spatial hierarchy.

## How it works
**Inputs and Outputs:**
*   **Input:** A hierarchical data tree $T$ containing multi-dimensional data values (e.g., pixel intensities, volumetric samples).
*   **Output:** A VQ tree $T'$, which is one level shorter than $T$. Each leaf node in $T'$ stores a codebook index representing the residuals of a brood (block of children) in $T$.

**Data Structures:**
*   **VQ Tree ($T'$):** A tree structure where each node stores a fixed-length index.
    *   **Index Size:** 7 bits for internal levels (supporting a codebook of 128 elements).
    *   **Finest Level ($L$):** 8 bits (supporting a codebook of 256 elements) because all nodes at this level are leaves, allowing the omission of leaf-child bits [S1, unofficial].
*   **Codebook:** A set of $K$ codevectors. For 2D single-channel data, each codevector is 4-dimensional (representing 4 pixel residuals). For color images, it is 12-dimensional. Codevectors are quantized to 8 bits per coordinate to reduce size [S1, unofficial].

**Algorithm Steps:**
1.  **Residual Calculation:** For each parent node in the original tree $T$, compute the residuals between the children's data values and the parent's value (or predicted value). Group these residuals into vectors corresponding to broods (blocks of $2^d$ children in $d$ dimensions) [S1, unofficial].
2.  **Codebook Generation:** For each level of the tree (except the finest, which uses a fixed 256-entry codebook), generate a codebook using $k$-means clustering on the residual vectors [S1, unofficial].
    *   Use cluster teleportation to escape local minima [S1, unofficial].
    *   Quantize the resulting codevectors to 8 bits per coordinate [S1, unofficial].
3.  **Quantization:** Replace each residual vector in the brood with the index of the nearest codevector in the level-specific codebook.
4.  **Tree Construction:** Construct $T'$ such that each node stores the 7-bit (or 8-bit at level $L$) index. $T'$ has one fewer level than $T$ because each node in $T'$ encodes the residuals of a brood in $T$ [S1, unofficial].

    create_nodes_in_T_prime(T_prime, indices, finest_level)
    
    return T_prime

**Edge Cases and Pitfalls:**
*   **Undefined Data:** If residual blocks contain undefined values (e.g., outside domain bounds), standard $k$-means fails. The algorithm must ignore undefined components during distance calculation and centroid updates [S1, unofficial].
*   **Finest Level:** The finest level $L$ requires special handling because all nodes are leaves. An 8-bit index and 256-entry codebook are used instead of the 7-bit/128-entry scheme to improve accuracy [S1, unofficial].
*   **Precision:** Codevectors are quantized to 8 bits per coordinate, which may introduce additional error but reduces codebook size [S1, unofficial].

## Subtopics

### [Adaptive VQ Tree Construction](7771-adaptive-vq-tree-construction.md)
Adaptive VQ Tree Construction is a method for building a simplified, error-bounded vector quantization (VQ) tree from a complete mipmap hierarchy. It solves the problem of achieving a target compression rate while strictly bounding the $L_\infty$ approximation error at all resolution levels to a user-defined tolerance $\tau$. It sets itself apart from standard VQ by adaptively pruning fine-level broods (blocks of children) based on their contribution to the global error, rather than uniformly quantizing all levels. It builds on [Brood-based Vector Quantization](7595-brood-based-vector-quantization.md) by adding a topology simplification step that removes redundant nodes.

## Operating characteristics
*   **Compression Ratio:** For a complete quadtree, brood-based VQ with 128-element codebooks (7-bit indices) yields approximately 1.75 bits per data sample at the finest level, or 2.33 bits per data sample when accounting for all levels [S1, unofficial].
*   **Error:** Tree-based VQ yields significantly less error than VQ applied to a uniform grid of blocks [S1, unofficial].
*   **Memory:** The VQ tree $T'$ is one level shorter than the original tree $T$, reducing the number of nodes [S1, unofficial].
*   **Strengths:** Efficient random access; corrects coarse-level errors in finer levels; handles sparse/undefined data.
*   **Limitations:** Lossy compression; requires careful handling of undefined data; codebook generation is computationally intensive ($k$-means).

## Background
Brood-based Vector Quantization was introduced in the paper "Compressed Random-Access Trees for Spatially Coherent Data" by S. Lefebvre and H. Hoppe [S1, unofficial]. It is used in the context of compressed random-access trees for spatially coherent data, enabling efficient storage and retrieval of hierarchical data structures.
