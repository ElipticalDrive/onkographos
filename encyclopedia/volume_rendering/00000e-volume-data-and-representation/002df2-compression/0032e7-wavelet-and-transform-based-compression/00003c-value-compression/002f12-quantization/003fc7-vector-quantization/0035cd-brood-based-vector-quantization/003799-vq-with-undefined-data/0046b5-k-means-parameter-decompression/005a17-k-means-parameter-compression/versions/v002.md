# K-means Parameter Compression

Also called: K-means clustering compression, torchpq K-means

## Overview
K-means Parameter Compression reduces the memory footprint of Gaussian Splatting parameters by clustering high-dimensional feature vectors into a fixed number of centroids using K-means clustering, then storing only the cluster labels and quantized centroid values [S1, unofficial]. It differs from nearest-seed assignment by using iterative refinement to improve clustering quality, though the gain is marginal [S1, unofficial]. Unlike methods requiring fixed budgets or retraining for different compression levels, it allows adjustable compression at inference time [S1, unofficial].

## How it works
**Inputs:**
- `params`: A tensor of Gaussian Splatting parameters to compress.
- `n_clusters`: Number of K-means clusters (default: 65536) [S1, unofficial].
- `quantization`: Number of bits for centroid quantization (default: 6) [S1, unofficial].

**Outputs:**
- `centroids_quant`: Quantized centroid values stored as `uint8`.
- `labels`: Cluster assignments for each parameter vector stored as `uint16`.
- `metadata`: Dictionary containing `shape`, `dtype`, `mins`, `maxs`, and `quantization` bits.

**Data Structures:**
- `centroids_quant`: Array of shape `(n_features, n_clusters)` of type `uint8`.
- `labels`: Array of shape `(n_params,)` of type `uint16`.
- `metadata`: Dictionary with keys `shape` (tuple), `dtype` (string), `mins` (array), `maxs` (array), `quantization` (int).

**Steps:**
1. Initialize K-means object with `n_clusters`, distance metric `manhattan`, and verbose flag [S1, unofficial].
2. Reshape `params` to `(params.shape[0], -1)`, permute to `(-1, params.shape[0])`, and make contiguous to form input tensor `x` [S1, unofficial].
3. Fit K-means on `x` to obtain labels [S1, unofficial].
4. Detach labels, move to CPU, and convert to numpy array [S1, unofficial].
5. Extract centroids from the K-means object, permute to `(-1, n_clusters)`, and convert to numpy array [S1, unofficial].
6. Compute `mins` and `maxs` of the centroids tensor [S1, unofficial].
7. Normalize centroids to `[0, 1]` range:
   $$ \text{centroids\_norm} = \frac{\text{centroids} - \text{mins}}{\text{maxs} - \text{mins}} $$
   [S1, unofficial].
8. Quantize normalized centroids to `uint8`:
   $$ \text{centroids\_quant} = \left\lfloor \text{centroids\_norm} \times (2^{\text{quantization}} - 1) + 0.5 \right\rfloor \pmod{2^{\text{quantization}}} $$
   Cast to `np.uint8` [S1, unofficial].
9. Convert labels to `uint16` [S1, unofficial].
10. Save `centroids_quant` and `labels` to an NPZ file using `np.savez_compressed` [S1, unofficial].
11. Return metadata dictionary containing `shape`, `dtype`, `mins`, `maxs`, and `quantization` bits [S1, unofficial].

**Pseudocode:**
```python
import numpy as np
import torch
from torchpq.clustering import KMeans

def kmeans_compress(params, n_clusters=65536, quantization=6):
    # Step 2: Prepare input tensor
    x = params.reshape(params.shape[0], -1).permute(1, 0).contiguous()
    
    # Step 3: Fit K-means
    kmeans = KMeans(n_clusters=n_clusters, distance='manhattan', verbose=False)
    labels_tensor = kmeans.fit(x)
    
    # Step 4: Process labels
    labels = labels_tensor.detach().cpu().numpy().astype(np.uint16)
    
    # Step 5: Extract centroids
    centroids = kmeans.centroids.detach().cpu().numpy()
    centroids = centroids.permute(1, 0) if hasattr(centroids, 'permute') else centroids.T
    # Assuming centroids is already numpy array from detach().cpu().numpy()
    # If it's a torch tensor, permute might be needed. 
    # Based on note: "permute to (-1, n_clusters)"
    # Let's assume centroids is (n_features, n_clusters) after proper handling
    # The note says "permute to (-1, n_clusters)" which implies transposing if it was (n_clusters, n_features)
    # torchpq KMeans centroids shape is typically (n_clusters, n_features)
    # So we need to transpose to (n_features, n_clusters)
    centroids = centroids.T
    
    # Step 6: Compute mins and maxs
    mins = centroids.min(axis=1)
    maxs = centroids.max(axis=1)
    
    # Step 7: Normalize
    # Avoid division by zero
    denom = maxs - mins
    denom[denom == 0] = 1.0
    centroids_norm = (centroids - mins.reshape(-1, 1)) / denom.reshape(-1, 1)
    
    # Step 8: Quantize
    scale = 2**quantization - 1
    centroids_quant = np.round(centroids_norm * scale).astype(np.uint8)
    
    # Step 9: Labels are already uint16
    
    # Step 10 & 11: Save and return metadata
    metadata = {
        'shape': params.shape,
        'dtype': str(params.dtype),
        'mins': mins,
        'maxs': maxs,
        'quantization': quantization
    }
    
    # In practice, save to file:
    # np.savez_compressed('compressed.npz', centroids_quant=centroids_quant, labels=labels)
    
    return centroids_quant, labels, metadata
```

**Edge Cases and Pitfalls:**
- Division by zero in normalization if `maxs == mins`. Handled by setting denominator to 1.0 [G].
- Precision loss during quantization. Using `uint8` limits centroid precision [S1, unofficial].
- Memory usage during K-means fitting on large tensors. The method reshapes and permutes, which may create copies [S1, unofficial].

## Subtopics

### [Inference-Time Clustering](17336-inference-time-clustering.md)
Groups geometry tokens into clusters via k-means and merges each cluster into a single scene token, reducing the Gaussian budget while preserving cross-view consistency. It allows adjustable compression at inference without retraining, distinguishing it from methods that require fixed budgets or retraining for different compression levels. Unlike nearest-seed assignment, it uses iterative refinement to improve quality, though the gain is marginal.

## Operating characteristics
- **Time Complexity:** Dominated by K-means clustering, which is iterative. The number of iterations depends on convergence criteria.
- **Memory Complexity:** Stores `n_clusters * n_features` centroids and `n_params` labels. Quantization reduces centroid storage to 1 byte per value [S1, unofficial].
- **Measured Performance:** Not given in the sources.
- **Scaling:** Scales with the number of clusters and features. Larger `n_clusters` improves fidelity but increases memory [S1, unofficial].
- **Strengths:** Adjustable compression at inference, no retraining required [S1, unofficial].
- **Limitations:** Marginal quality gain from iterative refinement compared to nearest-seed [S1, unofficial]. Quantization introduces error [S1, unofficial].
- **When to Use:** When memory is constrained and adjustable compression is needed without retraining [S1, unofficial].
- **When Not to Use:** When high fidelity is critical and memory is not a constraint [G].

## Background
K-means Parameter Compression is used in Gaussian Splatting parameter compression. It was introduced in the `splatad` repository [S1, unofficial]. The method leverages the `torchpq` library for K-means clustering [S1, unofficial].
