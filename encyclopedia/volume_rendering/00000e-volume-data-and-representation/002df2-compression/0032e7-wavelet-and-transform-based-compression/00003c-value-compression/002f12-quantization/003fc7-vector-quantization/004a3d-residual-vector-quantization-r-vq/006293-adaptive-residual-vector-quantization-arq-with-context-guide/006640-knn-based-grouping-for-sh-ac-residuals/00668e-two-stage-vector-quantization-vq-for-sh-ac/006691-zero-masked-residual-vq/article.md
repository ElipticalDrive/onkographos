# Zero-Masked Residual VQ

Also called: Two-Stage VQ with KNN Grouping and Zero-Masking, Zero-Masking for SH-AC Residuals

## Overview
Zero-Masked Residual VQ is a compression technique that maps small-magnitude residual sub-vectors to a zero index on a group-wise basis to increase index-map sparsity and improve HEVC coding efficiency [S1]. It builds on [Two-Stage Vector Quantization (VQ) for SH-AC](19632-two-stage-vector-quantization-vq-for-sh-ac.md) by adding a masking step that selectively discards low-energy residual information [S1]. Unlike its sibling [Two-Stage Vector Quantization (VQ) for SH-AC](19632-two-stage-vector-quantization-vq-for-sh-ac.md), which quantizes all residuals, this method increases sparsity in the second-stage index maps, allowing for significantly higher compression ratios at the cost of increased quantization error [S1].

## How it works
**Inputs and Outputs:**
- **Input:** Residual sub-vectors $r$ from the second stage of VQ, grouped by KNN [S1].
- **Output:** A sparse index map where small residuals are mapped to index 0, encoded via HEVC [S1].

**Data Structures:**
- **Index Map:** A 2D array of integers representing the VQ indices for each spatial location and sub-vector group [S1].
- **Codebook:** Fixed-size codebook for each sub-vector group [S1].

**Parameters:**
- **Zero-Masking Threshold ($T$):** The percentage of residual vectors to be masked to zero [S1].
- **Rate Point (RP):** A discrete quality level determining the threshold and group configuration [S1].
- **Empirical Thresholds:**
  - RP1: $T = 0.95$ [S1]
  - RP2: $T = 0.8$ [S1]
  - RP3: $T = 0.6$ [S1]
  - RP4: $T = 0$ [S1]

**Steps:**
1. **Group Residuals:** Partition the residual vectors into sub-vector groups using KNN-based grouping [S1].
2. **Quantize:** Perform VQ on each sub-vector group to obtain indices and residuals [S1].
3. **Calculate Magnitude:** For each residual sub-vector $r_i$, calculate its magnitude $\|r_i\|$ [S1].
4. **Determine Masking Ratio:** Select the zero-masking ratio $T$ based on the target Rate Point (RP) [S1].
5. **Sort and Mask:**
   - Sort all residual sub-vectors in a group by magnitude $\|r_i\|$ in ascending order [S1].
   - Identify the top $T \times N$ vectors (where $N$ is the total number of vectors in the group) [S1].
   - Map the indices of these vectors to 0 [S1].
   - [G] The remaining vectors retain their original VQ indices.
6. **Encode:** Pack the resulting sparse index maps into frames and encode them using HEVC [S1].

**Edge Cases and Pitfalls:**
- **Precision:** Higher thresholds increase quantization error while reducing bitrate; lower thresholds reduce error but increase bitrate [S1].
- **Boundaries:** At RP4, masking is disabled ($T=0$), and the method behaves like standard grouped VQ [S1].
- **Degenerate Input:** If all residuals are small, a high threshold may mask all vectors, potentially leading to loss of detail [S1].

```python
def zero_mask_residuals(residuals, threshold):
    """
    Maps small-magnitude residual sub-vectors to zero index.
    
    Args:
        residuals: List of residual sub-vectors (numpy arrays or similar).
        threshold: Float between 0 and 1, representing the fraction of vectors to mask.
        
    Returns:
        indices: List of VQ indices, with small residuals set to 0.
    """
    n = len(residuals)
    if n == 0:
        return []
    
    # Calculate magnitude for each residual
    magnitudes = [norm(r) for r in residuals]
    
    # Create a list of (magnitude, original_index) tuples
    indexed_magnitudes = list(enumerate(magnitudes))
    
    # Sort by magnitude ascending
    indexed_magnitudes.sort(key=lambda x: x[1])
    
    # Determine number of vectors to mask
    num_to_mask = int(threshold * n)
    
    # Initialize indices with placeholder (e.g., -1 or max index)
    # Note: In practice, indices are assigned by VQ first. 
    # This function assumes 'residuals' are already quantized and we are masking the indices.
    # However, the source describes masking based on magnitude of the residual *after* quantization.
    # The index map is generated by VQ, then modified.
    
    # Let's assume we have a list of current indices from VQ
    # The source says: "maps small-magnitude residual sub-vectors to the zero index"
    # So we need to know which index corresponds to which residual.
    # For simplicity, we assume residuals[i] corresponds to indices[i]
    
    # Re-sort indices based on magnitude
    sorted_indices = [idx for idx, _ in indexed_magnitudes]
    
    # Create new index map
    new_indices = list(range(len(residuals))) # Placeholder for actual VQ indices
    
    # Map the smallest 'num_to_mask' residuals to index 0
    for i in range(num_to_mask):
        original_idx = sorted_indices[i]
        new_indices[original_idx] = 0
        
    return new_indices
```

## Subtopics

### Flexible Sub-Vector Group Configuration
A compression configuration where the number of residual sub-vector groups is adjusted for each Rate Point (RP) to improve rate-distortion performance, while the codebook size remains fixed [S1]. Compared to a fixed nine-group configuration, flexible grouping improves the balance between index bitrate and reconstruction quality, providing approximately 5–6% additional BD-rate reductions [S1]. The zero-masking ratio and group configuration vary by RP: RP1 uses 1 group with 0.95 masking, RP2 uses 2 groups with 0.83 masking, RP3 uses 3 groups with 0.65 masking, and RP4 uses 9 groups with 0 masking [S1].

## Operating characteristics
- **Time and Memory Complexity:** Not given in the sources.
- **Measured Performance:** On the Bartender dataset, this method achieves a -22.3% BD-rate reduction over an RGB-PSNR range of 34.4–44.1 dB [S1].
- **Scaling:** Flexible grouping reduces the SH-AC index-map bitstream at RP1–RP3, while the remaining-attribute bitstreams and metadata remain unchanged [S1].
- **Strengths and Limitations:** It covers a much wider quality range (34.4–44.1 dB) compared to first-stage only methods (34.3–36.7 dB) by overcoming the quality ceiling of coarse VQ using residual information [S1]. However, higher thresholds increase quantization error [S1].
- **When to Use:** Use when high compression efficiency is required and some loss of detail is acceptable, particularly at lower rate points.
- **When Not to Use:** Avoid when high-quality reconstruction is critical, as masking introduces quantization error.

## Background
The method was proposed in a paper on hybrid compression for trained 3D Gaussian Splatting models based on VQ and HEVC [S1]. It addresses the inefficiency of encoding dense residual index maps by exploiting the sparsity of small-magnitude residuals [S1].
