# Codebook Sharing

Also called: Shared Codebook, Universal Codebook

## Overview
Codebook sharing is a technique to reduce memory usage by reusing a single codebook across all tree levels for smooth data (distance fields, light maps) via scaling, or across similar images via a universal codebook trained on a reference image [S1, unofficial]. It sets itself apart from standard Vector Quantization by eliminating the need to store separate codebooks for each level of detail or distinct image, leveraging the spatial coherence or content similarity of the data [S1, unofficial].

## How it works
**Inputs and outputs:**
* **Inputs:** A hierarchical dataset (e.g., distance fields, light maps) or a set of similar images; a reference image for universal codebook training [S1, unofficial].
* **Outputs:** A shared codebook $r$ and, for each level, the scaling factors or modulated codevectors required for reconstruction [S1, unofficial].

**Data structures:**
* **Shared Codebook $r$:** A table of codevectors [S1, unofficial]. For smooth data, the memory size is approximately 1 KB [S1, unofficial]. For a single-channel image, a standard codebook is 3 KB, but the shared version is 1 KB [S1, unofficial].
* **Scaling Factor:** A scalar value computed per level to adapt the shared codebook [S1, unofficial].

**Steps:**
1. Construct the shared codebook $r$ at the finest level [S1, unofficial].
2. Compute scaling factors for coarser levels. For each coarser level, compute the scaling factor as the ratio of the norm of the image residuals relative to the shared codebook [S1, unofficial].
3. Apply this scaling factor to the codevectors of the shared codebook to adapt them for the current level [S1, unofficial].

**Formulas:**
$$ s = \frac{\|r_{\text{level}}\|}{\|r\|} $$
where $s$ is the scaling factor, $r_{\text{level}}$ denotes the residuals at the current level, and $r$ is the shared codebook [S1, unofficial].

**Parameters:**
* Memory size of a single-channel image codebook: 3 KB [S1, unofficial].
* Memory size of a shared codebook for smooth data: 1 KB [S1, unofficial].

**Edge cases and pitfalls:**
* Universal codebooks do not extend well to dissimilar light maps or color images [S1, unofficial].

    finest_residuals = data_levels[0]

    norm_shared = norm(shared_codebook)

        else:
            scale = norm_level / norm_shared

        scaling_factors.append(scale)

    return shared_codebook, scaling_factors

def reconstruct_level(shared_codebook, scaling_factor, indices):
    """
    Reconstruct data for a specific level using the shared codebook and scaling.
    """
    codevectors = shared_codebook[indices]
    scaled_codevectors = [v * scaling_factor for v in codevectors]
    return scaled_codevectors

## Subtopics

### Coherent Basis Modulation
A module that produces a level-specific version of the codebook $C^{(\ell)}$ for LOD $\ell$ by fine-tuning or modulating entries of a global foundational codebook $C$, preserving structural relationships while tailoring features to detail requirements [S2]. It differs from simple scaling by allowing non-linear adaptation of codebook entries through fine-tuning [S2]. Choose this when preserving learned structural relationships between anchors is critical while adapting to specific detail levels [S2]. The local feature representation for anchor $j$ at LOD $\ell$ is adapted by retrieving the corresponding modulated entry using its fixed foundational index $\text{idx}_j$:
$$ f_{\text{loc},j}^{(\ell)} = C^{(\ell)}[\text{idx}_j] $$
where $f_{\text{loc},j}^{(\ell)}$ is the local feature representation, $C^{(\ell)}$ is the modulated codebook for LOD $\ell$, and $\text{idx}_j$ is the fixed foundational index for anchor $j$ [S2]. At full fidelity the codebook is randomly initialized, and when unfolding the table of the target level is copied from the trained foundational codebook and then fine-tuned [S2]. The Global Anchor Codebook size $N_c$ is typically 256, the codebook feature dimension $D_c$ is typically 32, and the learning rate for codebook updates during unfolding is typically 0.005 [S2].

## Operating characteristics
* **Memory:** Reduces memory usage significantly for smooth data. A shared codebook for smooth data requires only 1 KB, compared to 3 KB for a single-channel image codebook [S1, unofficial].
* **Performance:** Compression times range from 2 to 10 minutes, with most time spent in VQ optimization [S1, unofficial].
* **Limitations:** Universal codebooks do not work well for dissimilar light maps or color images [S1, unofficial].
* **Use cases:** Best suited for distance fields and light maps where data residuals are extremely autosimilar across levels [S1, unofficial].

## Background
Originated in the work of S. Lefebvre & H. Hoppe, "Compressed Random-Access Trees for Spatially Coherent Data" [S1, unofficial]. It is used in the context of tree-based compression for spatially coherent data, including light maps, alpha mattes, distance fields, and high-dynamic-range images [S1, unofficial].
