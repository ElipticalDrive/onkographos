# VQRF (Vector Quantized Radiance Fields)
Also called: VQ-DVGO, VQ-Plenoxels, VQ-TensoRF

## Overview
VQRF is a compression framework for volumetric radiance fields (DVGO, Plenoxels, TensoRF) that reduces model size to approximately 1 MB by combining adaptive voxel pruning, learnable vector quantization, and weight quantization [S1]. It achieves a superior PSNR-size trade-off compared to uncompressed baselines and their direct vector-quantized variants (VQ-DVGO, VQ-Plenoxels, VQ-TensoRF) [S1].

## How it works
The method compresses a volumetric radiance field through five sequential steps: baseline initialization, voxel pruning, vector quantization, joint finetuning, and weight quantization [S1].

**Inputs and Outputs:**
*   **Input:** An uncompressed volumetric radiance field model (DVGO, Plenoxels, or TensoRF) trained on a dataset [S1].
*   **Output:** A compressed model with significantly reduced zip-compressed storage size while maintaining high rendering quality (PSNR, SSIM) [S1].

**Data Structures:**
1.  **Voxel Grid:** The spatial representation of the radiance field, where low-importance voxels are removed during pruning [S1].
2.  **Codebook:** A learnable lookup table of size $K$ containing $K$ code vectors [S1].
3.  **Indices:** A mapping from active voxels to codebook indices, substituting individual voxel features with a single code vector to reduce storage from individual voxel storage to codebook storage plus mapping indices [S1].
4.  **Weights:** Neural network parameters (e.g., in TensoRF or MLP-based components) quantized to lower precision [S1].

**Parameters:**
*   **Pruning parameter $\beta_p$:** Controls voxel pruning aggressiveness. Larger $\beta_p$ yields better quality but larger size. Default: 0.6 [S1].
*   **Keeping parameter $\beta_k$:** Controls the keeping quantile during pruning. Smaller $\beta_k$ improves compression but degrades visual performance. Default: 0.001 [S1].
*   **Codebook size $K$:** Number of entries in the vector quantization codebook. Model size and PSNR increase simultaneously as $K$ increases. Tested sizes: 16, 64, 256, 1024, 4096, 16384. Sizes $>4096$ yield minimal PSNR improvement with disproportionate storage cost. Default/Best trade-off: 4096 [S1].

**Algorithm Steps:**

1.  **Baseline:** Start with a fully trained, uncompressed volumetric radiance field model [S1].
2.  **Voxel Pruning:** Remove voxels deemed unimportant based on $\beta_p$ and $\beta_k$. This achieves ~5x compression with negligible PSNR drop [S1].
3.  **Vector Quantization:** Replace individual voxel feature vectors with indices into a shared codebook of size $K$. This achieves another ~5x reduction but decreases PSNR by ~0.5 dB [S1].
4.  **Joint Finetuning:** Retrain the model (updating both the codebook and the remaining parameters) to recover rendering performance lost in step 3, without increasing model size [S1].
5.  **Weight Quantization:** Apply quantization to the model weights to reach the final ~1 MB size [S1].

import random

class Voxel:
    def __init__(self, feature=None, index=None, density=0.0):
        self.feature = feature
        self.index = index
        self.density = density

class Model:
    def __init__(self, voxels, codebook=None, weights=None):
        self.voxels = voxels
        self.codebook = codebook
        self.weights = weights

def VQRF_Compress(baseline_model, dataset, beta_p=0.6, beta_k=0.001, codebook_size=4096, num_epochs=1000):
    # Step 1: Baseline is provided
    model = baseline_model

    # Step 2: Voxel Pruning
    # The exact importance metric for pruning is not specified in the sources [G]
    importance = [sum(v.feature[i]**2 for i in range(len(v.feature))) for v in model.voxels] # [G]
    threshold_idx = int(len(importance) * beta_k)
    sorted_importance = sorted(importance, reverse=True)
    threshold = sorted_importance[threshold_idx] if threshold_idx < len(sorted_importance) else 0.0
    active_voxels = [v for v, imp in zip(model.voxels, importance) if imp >= threshold]
    pruned_model = Model(active_voxels, model.codebook, model.weights)

    # Step 3: Vector Quantization
    feature_dim = len(pruned_model.voxels[0].feature) if pruned_model.voxels else 0
    codebook = [[random.uniform(-1, 1) for _ in range(feature_dim)] for _ in range(codebook_size)] # [G]
    quantized_voxels = []
    for v in pruned_model.voxels:
        dists = [sum((v.feature[i] - codebook[c][i])**2 for i in range(feature_dim)) for c in range(codebook_size)]
        idx = dists.index(min(dists))
        quantized_voxels.append(Voxel(index=idx, density=v.density))
    quantized_model = Model(quantized_voxels, codebook, pruned_model.weights)

def quantize_weights(weights, bits=8):
    # Uniform quantization to specified bit depth [G]
    min_val, max_val = min(weights), max(weights)
    scale = (max_val - min_val) / (2**bits - 1)
    return [round((w - min_val) / scale) for w in weights]

**Edge Cases and Pitfalls:**
*   **Codebook Size:** Choosing a codebook size larger than 4096 yields minimal PSNR improvement but significantly increases storage, making it inefficient [S1].
*   **Pruning Parameters:** Incorrect tuning of $\beta_p$ and $\beta_k$ can lead to either excessive quality loss or insufficient compression [S1].
*   **Performance Drop:** Vector quantization alone causes a ~0.5 dB PSNR drop, which must be recovered via joint finetuning [S1].

## Subtopics

### [Local Histogram Clustering for Volume Illumination](11177-local-histogram-clustering-for-volume-illumination.md)
A preprocessing technique that captures complex light interactions (diffuse interreflection and scattering) in volumetric data by computing local histograms for each voxel and clustering them into a small set of representative codebook entries. It enables interactive rendering with minimal additional texture fetches, distinguishing itself from standard volume rendering integrals that capture only emission and absorption, and from surface-based techniques that cannot dynamically adapt to transfer function changes.

## Operating characteristics
*   **Model Size:** VQRF achieves a model size of 1.4 MB (after zip compression) on the synthetic-NeRF dataset [S1].
*   **Rendering Quality:** On the synthetic-NeRF dataset, VQRF achieves a PSNR of 31.77 and SSIM of 0.954 [S1].
*   **Comparison to Baselines:**
    *   DVGO: 34.90 PSNR, 119.8 MB [S1].
    *   Plenoxels: 31.71 PSNR, 259.8 MB [S1].
    *   TensoRF: 33.09 PSNR, 67.6 MB [S1].
    *   VQRF outperforms these baselines and their VQ variants (VQ-DVGO, VQ-Plenoxels, VQ-TensoRF) in PSNR-size trade-off [S1].
*   **Compression Steps Impact:**
    *   Baseline: 31.90 PSNR, 105.9 MB [S1].
    *   +Voxel Pruning: 31.88 PSNR, 19.0 MB (5x compression) [S1].
    *   +Vector Quantization: 31.32 PSNR, 4.8 MB (another 5x reduction, -0.5 dB PSNR) [S1].
    *   +Joint Finetuning: 31.79 PSNR, 4.8 MB (recovers most performance) [S1].
    *   +Weight Quantization: 31.77 PSNR, 1.4 MB [S1].
*   **Strengths:** Extremely small model size (~1 MB) with high visual quality. Generalizes well to different datasets (synthetic-NeRF, synthetic-NSVF, Tanks&Temples, LLFF) [S1].
*   **Limitations:** Requires joint finetuning to recover performance after quantization. Performance is sensitive to codebook size and pruning parameters [S1].

## Background
VQRF was proposed in the paper "Compressing Volumetric Radiance Fields to 1 MB" [S1]. It builds on the parent method [Vector Quantization for Volumetric Radiance Fields](1870-vector-quantization-for-volumetric-radiance-fields.md) and applies it to specific volumetric radiance field representations like DVGO, Plenoxels, and TensoRF [S1]. The method addresses the large storage requirements of volumetric radiance fields by introducing a structured compression pipeline [S1].
