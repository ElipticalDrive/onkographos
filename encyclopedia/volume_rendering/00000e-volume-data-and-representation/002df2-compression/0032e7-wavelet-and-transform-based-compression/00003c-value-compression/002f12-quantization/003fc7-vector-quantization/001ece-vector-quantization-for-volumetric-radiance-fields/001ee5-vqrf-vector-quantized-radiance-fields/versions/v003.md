# VQRF (Vector Quantized Radiance Fields)
Also called: VQ-DVGO, VQ-Plenoxels, VQ-TensoRF

## Overview
VQRF is a compression framework for volumetric radiance fields (such as DVGO, Plenoxels, and TensoRF) that reduces model size to approximately 1 MB by combining adaptive voxel pruning, learnable vector quantization, and weight quantization [S1]. It achieves a superior PSNR-size trade-off compared to uncompressed baselines and their direct vector-quantized variants (VQ-DVGO, VQ-Plenoxels, VQ-TensoRF) [S1].

## How it works
The method compresses a volumetric radiance field through five sequential steps: baseline initialization, voxel pruning, vector quantization, joint finetuning, and weight quantization [S1].

**Inputs and Outputs:**
*   **Input:** An uncompressed volumetric radiance field model (e.g., DVGO, Plenoxels, or TensoRF) trained on a dataset.
*   **Output:** A compressed model with significantly reduced storage size (zip-compressed) while maintaining high rendering quality (PSNR, SSIM).

**Data Structures:**
1.  **Voxel Grid:** The spatial representation of the radiance field. Pruning removes low-importance voxels.
2.  **Codebook:** A learnable lookup table of size $K$ containing $K$ code vectors. Each voxel's feature vector is replaced by an index pointing to the nearest code vector in this table.
3.  **Indices:** A mapping from active voxels to codebook indices.
4.  **Weights:** The neural network parameters (if applicable, e.g., in TensoRF or MLP-based components) are quantized.

**Parameters:**
*   **Pruning parameter $\beta_p$:** Controls voxel pruning aggressiveness. Larger $\beta_p$ yields better quality but larger size. Default: 0.6 [S1].
*   **Keeping parameter $\beta_k$:** Controls the quantile threshold during pruning. Smaller $\beta_k$ improves compression but degrades visual performance. Default: 0.001 [S1].
*   **Codebook size $K$:** Number of entries in the vector quantization codebook. Tested sizes: 16, 64, 256, 1024, 4096, 16384. Sizes $>4096$ yield minimal PSNR improvement with disproportionate storage cost. Default/Best trade-off: 4096 [S1].

**Algorithm Steps:**

1.  **Baseline:** Start with a fully trained, uncompressed volumetric radiance field model.
2.  **Voxel Pruning:** Remove voxels deemed unimportant based on $\beta_p$ and $\beta_k$. This achieves ~5x compression with negligible PSNR drop [S1].
3.  **Vector Quantization:** Replace individual voxel feature vectors with indices into a shared codebook of size $K$. This achieves another ~5x reduction but decreases PSNR by ~0.5 dB [S1].
4.  **Joint Finetuning:** Retrain the model (updating both the codebook and the remaining parameters) to recover rendering performance lost in step 3, without increasing model size [S1].
5.  **Weight Quantization:** Apply quantization to the model weights to reach the final ~1 MB size [S1].

**Pseudocode:**

```python
def VQRF_Compress(baseline_model, dataset, beta_p=0.6, beta_k=0.001, codebook_size=4096):
    """
    Compress a volumetric radiance field using VQRF.
    
    Args:
        baseline_model: Uncompressed model (DVGO/Plenoxels/TensoRF).
        dataset: Training dataset for finetuning.
        beta_p: Pruning quality parameter.
        beta_k: Pruning keeping quantile.
        codebook_size: Number of entries in the VQ codebook.
        
    Returns:
        Compressed model.
    """
    
    # Step 1: Baseline is already provided
    
    # Step 2: Voxel Pruning
    # Identify voxels to keep based on importance metrics and parameters beta_p, beta_k.
    # The exact importance metric is not specified in the source, but it is a standard 
    # pruning operation for volumetric fields.
    pruned_model = apply_voxel_pruning(baseline_model, beta_p, beta_k)
    
    # Step 3: Vector Quantization
    # Initialize codebook of size K with random or k-means initialized vectors.
    codebook = initialize_codebook(codebook_size, feature_dim=pruned_model.feature_dim)
    
    # Replace voxel features with codebook indices.
    # This involves finding the nearest code vector for each voxel's feature.
    quantized_model = apply_vector_quantization(pruned_model, codebook)
    
    # Step 4: Joint Finetuning
    # Retrain the quantized model on the dataset to optimize both the codebook 
    # and the remaining model parameters (e.g., density/opacity fields, MLP weights).
    finetuned_model = joint_finetune(quantized_model, dataset, epochs=1000) # Epochs not specified [G]
    
    # Step 5: Weight Quantization
    # Quantize the weights of the model (e.g., to 8-bit or lower) to reduce size further.
    compressed_model = apply_weight_quantization(finetuned_model)
    
    return compressed_model

def apply_voxel_pruning(model, beta_p, beta_k):
    """
    Remove voxels based on importance.
    beta_p: Controls quality vs size trade-off.
    beta_k: Controls the quantile of voxels to keep.
    """
    # Calculate importance score for each voxel.
    # The specific importance metric is not detailed in the source [G].
    importance_scores = calculate_voxel_importance(model)
    
    # Determine threshold based on beta_k and beta_p.
    # Smaller beta_k -> stricter threshold -> more pruning.
    # Larger beta_p -> looser threshold -> less pruning.
    threshold = compute_pruning_threshold(importance_scores, beta_p, beta_k)
    
    # Keep voxels with importance > threshold.
    active_voxels = [v for v in model.voxels if v.importance > threshold]
    
    # Reconstruct model with only active voxels.
    return Model(active_voxels)

def apply_vector_quantization(model, codebook):
    """
    Replace voxel features with codebook indices.
    """
    new_voxels = []
    for voxel in model.voxels:
        # Find nearest code vector in codebook.
        # Euclidean distance is standard for VQ.
        nearest_idx = argmin([dist(voxel.feature, code) for code in codebook])
        
        # Create new voxel with index instead of full feature vector.
        new_voxel = Voxel(index=nearest_idx, density=voxel.density)
        new_voxels.append(new_voxel)
        
    return Model(new_voxels, codebook=codebook)

def joint_finetune(model, dataset, epochs):
    """
    Retrain model to recover performance.
    """
    optimizer = Optimizer(model.parameters())
    for epoch in range(epochs):
        for batch in dataset:
            loss = compute_rendering_loss(model, batch)
            loss.backward()
            optimizer.step()
    return model

def apply_weight_quantization(model):
    """
    Quantize model weights to reduce size.
    """
    # Quantize weights to lower precision (e.g., 8-bit).
    # The specific quantization scheme is not detailed in the source [G].
    quantized_weights = quantize(model.weights)
    model.weights = quantized_weights
    return model
```

**Edge Cases and Pitfalls:**
*   **Codebook Size:** Choosing a codebook size larger than 4096 yields minimal PSNR improvement but significantly increases storage, making it inefficient [S1].
*   **Pruning Parameters:** Incorrect tuning of $\beta_p$ and $\beta_k$ can lead to either excessive quality loss or insufficient compression. The default values (0.6 and 0.001) provide a balanced trade-off [S1].
*   **Performance Drop:** Vector quantization alone causes a ~0.5 dB PSNR drop, which must be recovered via joint finetuning [S1].

A preprocessing technique that captures complex light interactions (diffuse interreflection and scattering) in volumetric data by computing local histograms for each voxel and clustering them into a small set of representative codebook entries. It enables interactive rendering with minimal additional texture fetches, distinguishing itself from standard volume rendering integrals that capture only emission and absorption, and from surface-based techniques that cannot dynamically adapt to transfer function changes.

## Operating characteristics
*   **Model Size:** VQRF achieves a model size of 1.4 MB (after zip compression) on the synthetic-NeRF dataset [S1].
*   **Rendering Quality:** On the synthetic-NeRF dataset, VQRF achieves a PSNR of 31.77 and SSIM of 0.954 [S1].
*   **Comparison to Baselines:**
    *   DVGO: 34.90 PSNR, 119.8 MB [S1].
    *   Plenoxels: 31.71 PSNR, 259.8 MB [S1].
    *   TensoRF: 33.09 PSNR, 67.6 MB [S1].
    *   VQRF outperforms these baselines and their VQ variants (VQ-DVGO, VQ-Plenoxels, VQ-TensoRF) in PSNR-size trade-off [S1].
*   **Compression Steps Impact:**
    *   Baseline: 31.90 PSNR, 105.9 MB [S1].
    *   +Voxel Pruning: 31.88 PSNR, 19.0 MB (5x compression) [S1].
    *   +Vector Quantization: 31.32 PSNR, 4.8 MB (another 5x reduction, -0.5 dB PSNR) [S1].
    *   +Joint Finetuning: 31.79 PSNR, 4.8 MB (recovers most performance) [S1].
    *   +Weight Quantization: 31.77 PSNR, 1.4 MB [S1].
*   **Strengths:** Extremely small model size (~1 MB) with high visual quality. Generalizes well to different datasets (synthetic-NeRF, synthetic-NSVF, Tanks&Temples, LLFF) [S1].
*   **Limitations:** Requires joint finetuning to recover performance after quantization. Performance is sensitive to codebook size and pruning parameters.

## Background
VQRF was proposed in the paper "Compressing Volumetric Radiance Fields to 1 MB" [S1]. It builds on the parent method [Vector Quantization for Volumetric Radiance Fields](1870-vector-quantization-for-volumetric-radiance-fields.md) and applies it to specific volumetric radiance field representations like DVGO, Plenoxels, and TensoRF [S1]. The method addresses the large storage requirements of volumetric radiance fields by introducing a structured compression pipeline.
