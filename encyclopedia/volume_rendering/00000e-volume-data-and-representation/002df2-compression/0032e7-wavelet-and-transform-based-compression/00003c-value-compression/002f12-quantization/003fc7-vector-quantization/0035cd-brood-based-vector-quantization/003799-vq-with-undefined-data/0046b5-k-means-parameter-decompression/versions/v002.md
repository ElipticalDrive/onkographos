# K-means Parameter Decompression
Also called: K-means Decompression
## Overview
K-means Parameter Decompression reconstructs a parameter tensor from compressed K-means centroids and cluster labels by dequantizing and remapping the values [S1, unofficial]. It reverses the quantization and indexing steps of the compression phase [S1, unofficial].
## How it works
**Inputs and Outputs:**
- Input: A compressed `.npz` file containing `centroids_quant` (quantized integer centroids) and `labels` (integer indices), along with metadata (`meta`) including `quantization` bit depth, `mins`/`maxs` (per-dimension bounds), `shape`, and `dtype` [S1, unofficial].
- Output: A reconstructed parameter tensor of shape `meta["shape"]` and type `meta["dtype"]` [S1, unofficial].

**Data Structures:**
- `centroids_quant`: Array of quantized integer values [S1, unofficial].
- `labels`: Array of integer indices mapping each data point to a centroid [S1, unofficial].
- `meta`: Dictionary containing:
  - `quantization`: Integer, number of bits used for quantization [S1, unofficial].
  - `mins`: Tensor of minimum values per dimension [S1, unofficial].
  - `maxs`: Tensor of maximum values per dimension [S1, unofficial].
  - `shape`: Tuple defining the target tensor shape [S1, unofficial].
  - `dtype`: Data type (e.g., `float32`) [S1, unofficial].

**Steps:**
1. Load the compressed `.npz` file to extract `centroids_quant` and `labels` arrays [S1, unofficial].
2. Normalize quantized centroids to the $[0, 1]$ range using the quantization bit depth:
   $$ \text{centroids\_norm} = \frac{\text{centroids\_quant}}{2^{\text{quantization}} - 1} $$
3. Scale normalized centroids back to the original parameter range using stored min/max bounds:
   $$ \text{centroids} = \text{centroids\_norm} \times (\text{maxs} - \text{mins}) + \text{mins} $$
4. Index the centroids array with the labels array to reconstruct the full parameter tensor:
   $$ \text{params} = \text{centroids}[\text{labels}] $$
5. Reshape the reconstructed tensor to `meta["shape"]` and cast to `meta["dtype"]` [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def decompress_kmeans_params(npz_filepath, meta):
    """
    Reconstructs parameter tensor from K-means compressed data.
    
    Args:
        npz_filepath (str): Path to the .npz file containing centroids_quant and labels.
        meta (dict): Metadata dictionary with keys:
            - quantization (int): Bit depth for quantization.
            - mins (np.ndarray): Per-dimension minimum values.
            - maxs (np.ndarray): Per-dimension maximum values.
            - shape (tuple): Target tensor shape.
            - dtype (np.dtype): Target data type.
            
    Returns:
        np.ndarray: Reconstructed parameter tensor.
    """
    # Step 1: Load compressed data
    data = np.load(npz_filepath)
    centroids_quant = data['centroids_quant']
    labels = data['labels']
    
    # Step 2: Normalize quantized centroids to [0, 1]
    quantization_bits = meta['quantization']
    denominator = 2 ** quantization_bits - 1
    centroids_norm = centroids_quant / denominator
    
    # Step 3: Scale back to original range
    mins = meta['mins']
    maxs = meta['maxs']
    centroids = centroids_norm * (maxs - mins) + mins
    
    # Step 4: Index centroids with labels
    params = centroids[labels]
    
    # Step 5: Reshape and cast
    params = params.reshape(meta['shape']).astype(meta['dtype'])
    
    return params
```

**Parameters:**
- `quantization` (int): Number of bits used for centroid quantization, determines the denominator $2^{\text{quantization}} - 1$ [S1, unofficial].
- `mins`, `maxs` (Tensor): Per-dimension minimum and maximum values used for linear dequantization scaling [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Zero Quantization Bits:** If `quantization` is $0$, the denominator becomes $0$, causing division by zero during normalization [G].
- **Constant Dimensions:** If `mins` equals `maxs` for any dimension, the range is zero and the scaling step yields `mins` for all centroids, which is mathematically valid but indicates a degenerate dimension [G].
- **Shape Mismatch:** The product of the `labels` length and the centroid dimensionality must equal the total number of elements in `meta["shape"]` [G].

### [K-means Parameter Compression](16511-k-means-parameter-compression.md)
Compresses parameters by clustering them into centroids using K-means, then storing only cluster labels and quantized centroids to reduce memory footprint. Choose this when memory reduction is the primary goal and slight accuracy loss is acceptable [G].
