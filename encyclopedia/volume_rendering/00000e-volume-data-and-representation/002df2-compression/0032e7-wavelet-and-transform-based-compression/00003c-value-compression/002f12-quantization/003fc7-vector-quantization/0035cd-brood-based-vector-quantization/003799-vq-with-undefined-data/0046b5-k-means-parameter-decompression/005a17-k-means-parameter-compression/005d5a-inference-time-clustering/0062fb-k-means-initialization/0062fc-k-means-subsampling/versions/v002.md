# K-means++ Subsampling

Also called: k-means++ clustering

## Overview
K-means++ Subsampling is a data reduction technique that selects a representative subset of raw data points to serve as the initial cluster centers for k-means clustering [S1]. It addresses the scalability bottleneck in high-dimensional volume data exploration by limiting the number of points processed during the iterative clustering phase, thereby allowing the algorithm to terminate within a reasonable time limit [S1]. It differs from standard k-means++ initialization [K-Means++ Initialization](18746-k-means-initialization.md) by treating the initialization step as a permanent subsampling operation for the entire clustering process, rather than just a setup phase for using all data points [G].

## How it works
**Inputs:** A dataset of $n$ points in a high-dimensional space; a target number of clusters $k$; a sampling rate $\alpha \in (0, 1]$ [S1].
**Outputs:** A subset of $m = \lfloor n \cdot \alpha \rfloor$ points from the original dataset, which serve as the initial centroids for the subsequent k-means clustering [S1].

**Data Structures:**
- `points`: List of $n$ vectors, each of dimension $d$.
- `centers`: List of $k$ vectors, initialized from the subsampled points.
- `distances`: Array of size $m$, storing the squared Euclidean distance from each retained point to its nearest selected center.

**Parameters:**
- **Sampling rate ($\alpha$):** The fraction of raw data points retained. Typical values are 50% for hyperspectral data, 30% for hurricane data, and 25% for ionization data [S1].
- **Number of clusters ($k$):** Fixed at 3000 in the referenced implementations [S1].

**Algorithm Steps:**
1. **Calculate Total Points:** Determine the number of points to retain: $m = \lfloor n \cdot \alpha \rfloor$ [S1].
2. **Initialize First Center:** Select one point $c_1$ uniformly at random from the $n$ input points [S1].
3. **Compute Distances:** For all $n$ points, compute the squared Euclidean distance to $c_1$. Store these in `distances` [S1].
4. **Iterative Selection:** For $i$ from 2 to $k$:
   a. **Normalize Probabilities:** Compute the probability $P_j$ for each unselected point $j$ as:
      $$ P_j = \frac{\text{distances}[j]}{\sum_{l \in \text{unselected}} \text{distances}[l]} $$
      If the sum of distances is zero, select uniformly at random among unselected points [G].
   b. **Select Center:** Choose a point $c_i$ from the unselected points based on probabilities $P_j$ [S1].
   c. **Update Distances:** For each unselected point $j$, update `distances[j]` to be the minimum of its current value and the squared distance to the newly selected center $c_i$ [S1].
5. **Final Subsampling:** The set of selected centers $\{c_1, \dots, c_k\}$ constitutes the subsampled data [S1]. The source states "maximize the sampling rate... until clustering terminates," implying the subsampled set size is the variable controlled by $\alpha$ [S1].

**Pseudocode:**
```python
def k_means_pp_subsampling(points, k, alpha):
    n = len(points)
    m = int(n * alpha)
    subset = points[:m]
    centers = []
    distances = [float('inf')] * m
    idx = _rand_int(0, m - 1)
    centers.append(subset[idx])
    for i in range(m):
        distances[i] = sum((a - b) ** 2 for a, b in zip(subset[i], subset[idx]))
    for _ in range(1, k):
        total = sum(distances)
        if total == 0:
            idx = _rand_int(0, m - 1)
        else:
            r = _rand_float(0, total)
            cumulative = 0.0
            for i in range(m):
                cumulative += distances[i]
                if cumulative >= r:
                    idx = i
                    break
        centers.append(subset[idx])
        new_pt = subset[idx]
        for i in range(m):
            d = sum((a - b) ** 2 for a, b in zip(subset[i], new_pt))
            if d < distances[i]:
                distances[i] = d
    return centers

def _rand_int(a, b):
    import random
    return random.randint(a, b)

def _rand_float(a, b):
    import random
    return random.uniform(a, b)
```

## Subtopics

### MiniBatch K-means
A variant that updates codewords using subsets of input vectors to reduce computational cost. It initializes the first center randomly and samples each subsequent center with probability proportional to its squared distance from the nearest selected center. This approach is used in hybrid compression methods for 3D Gaussian Splatting models to train VQ codebooks efficiently [S2].

## Operating characteristics
**Time Complexity:** $O(nk^2)$ per iteration, where $n$ is the number of data points and $k$ is the number of clusters [S1].
**Memory Complexity:** Not explicitly given for the subsampling step alone, but subspace clustering (a related step in the pipeline) incurs $O(m^2)$ memory where $m$ is the number of samples [S1].
**Performance:** The method allows processing of large datasets (e.g., 1.2GB hyperspectral images) by limiting the number of points used for clustering. The sampling rate is maximized until the algorithm terminates in a reasonable time [S1].
**Strengths:** Improves scalability for high-dimensional data exploration; ensures initial centers are well-spread [S1].
**Limitations:** Complexity grows quadratically with $k$ and linearly with $n$; hardware capacities still limit the size of raw volumetric data that can be processed for smooth animated transitions [S1].

## Background
The method is used in multivariate volume visualization through dynamic projections, particularly for earth remote sensing and hyperspectral imaging. It was introduced as part of a system for handling multivariate TF (Transfer Function) design and volume rendering, where data reduction via sampling and clustering is necessary to manage system scalability and hardware limits [S1].
