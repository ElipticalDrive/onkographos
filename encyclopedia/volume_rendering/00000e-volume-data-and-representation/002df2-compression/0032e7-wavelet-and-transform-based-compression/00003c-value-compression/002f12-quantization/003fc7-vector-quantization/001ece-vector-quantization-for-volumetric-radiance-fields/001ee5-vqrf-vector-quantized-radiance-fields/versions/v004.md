# VQRF (Vector Quantized Radiance Fields)
Also called: VQ-DVGO, VQ-Plenoxels, VQ-TensoRF

## Overview
VQRF is a compression framework for volumetric radiance fields (such as DVGO, Plenoxels, and TensoRF) that reduces model size to approximately 1 MB by combining adaptive voxel pruning, learnable vector quantization, and weight quantization [S1]. It achieves a superior PSNR-size trade-off compared to uncompressed baselines and their direct vector-quantized variants (VQ-DVGO, VQ-Plenoxels, VQ-TensoRF) [S1].

## How it works
The method compresses a volumetric radiance field through five sequential steps: baseline initialization, voxel pruning, vector quantization, joint finetuning, and weight quantization [S1].

**Inputs and Outputs:**
*   **Input:** An uncompressed volumetric radiance field model (e.g., DVGO, Plenoxels, or TensoRF) trained on a dataset [S1].
*   **Output:** A zip-compressed model with significantly reduced storage size (reaching ~1 MB) while maintaining high rendering quality (PSNR, SSIM) [S1].

**Data Structures:**
1.  **Voxel Grid:** Spatial representation of the radiance field; voxels store feature vectors, density, and opacity [G].
2.  **Codebook:** Learnable lookup table of size $K$ containing $K$ code vectors [S1, G].
3.  **Indices:** Mapping from active voxels to codebook indices, replacing full feature vectors [S1, G].
4.  **Weights:** Neural network parameters (e.g., in TensoRF or MLP components) subject to quantization [S1].

**Parameters:**
*   **Pruning parameter $\beta_p$:** Controls voxel pruning; larger values yield better rendering quality but increase model size. Default: 0.6 [S1].
*   **Keeping parameter $\beta_k$:** Controls the keeping quantile during pruning; smaller values degrade visual performance but improve compression ratio. Default: 0.001 [S1].
*   **Codebook size $K$:** Hyperparameter for vector quantization; model size and PSNR increase simultaneously with $K$. Tested sizes: 16, 64, 256, 1024, 4096, 16384. Sizes $>4096$ yield minimal PSNR improvement with disproportionate storage cost. Default/Best trade-off: 4096 [S1].

**Algorithm Steps:**

1.  **Baseline:** Start with a fully trained, uncompressed volumetric radiance field model [S1].
2.  **Voxel Pruning:** Remove voxels based on $\beta_p$ and $\beta_k$, achieving ~5× compression with negligible PSNR drop [S1].
3.  **Vector Quantization:** Replace individual voxel feature vectors with indices into a shared codebook of size $K$, achieving another ~5× reduction but decreasing PSNR by ~0.5 dB [S1].
4.  **Joint Finetuning:** Retrain the model (updating codebook and remaining parameters) to recover rendering performance without increasing model size [S1].
5.  **Weight Quantization:** Apply quantization to model weights to reach the final ~1 MB size [S1].

**Pseudocode:**

```python
import math

def VQRF_Compress(baseline_voxels, dataset, beta_p=0.6, beta_k=0.001, codebook_size=4096, epochs=1000, lr=1e-3):
    # Step 1: Baseline provided as list of voxel dicts with 'feature', 'density', 'opacity'
    voxels = baseline_voxels

    # Step 2: Voxel Pruning
    # Compute importance score for each voxel [G]
    for v in voxels:
        v['importance'] = math.sqrt(sum(x**2 for x in v['feature']))

    # Sort voxels by importance descending
    voxels.sort(key=lambda v: v['importance'], reverse=True)

    # Determine threshold using beta_k (quantile) and beta_p (quality scaling) [G]
    keep_count = max(1, int(len(voxels) * beta_k))
    threshold = voxels[keep_count - 1]['importance'] if keep_count < len(voxels) else 0.0
    threshold *= (1.0 + beta_p)

    # Filter voxels above threshold
    pruned_voxels = [v for v in voxels if v['importance'] > threshold]

    # Step 3: Vector Quantization
    # Initialize codebook with first K voxels' features [G]
    feature_dim = len(pruned_voxels[0]['feature'])
    codebook = [list(pruned_voxels[i]['feature']) for i in range(min(codebook_size, len(pruned_voxels)))]
    while len(codebook) < codebook_size:
        codebook.append([0.0] * feature_dim)

    # Map voxels to nearest codebook indices (Euclidean distance)
    quantized_voxels = []
    for v in pruned_voxels:
        best_idx = min(range(codebook_size), key=lambda i: sum((a - b)**2 for a, b in zip(v['feature'], codebook[i])))
        quantized_voxels.append({'index': best_idx, 'density': v['density'], 'opacity': v['opacity']})

    # Step 4: Joint Finetuning
    # Update codebook and voxel parameters to recover rendering quality [G]
    for epoch in range(epochs):
        for batch in dataset:
            loss = compute_rendering_loss(quantized_voxels, codebook, batch)
            update_parameters(quantized_voxels, codebook, loss, lr)

    # Step 5: Weight Quantization
    # Quantize parameters to 8-bit integers for storage [G]
    compressed_codebook = [quantize_8bit(c) for c in codebook]
    compressed_voxels = [{'index': v['index'], 'density': quantize_8bit(v['density']), 'opacity': quantize_8bit(v['opacity'])} for v in quantized_voxels]

    return {'codebook': compressed_codebook, 'voxels': compressed_voxels}

def compute_rendering_loss(voxels, codebook, batch):
    # Standard mean squared error between rendered and target images [G]
    return sum((batch['target'][i] - render_image(voxels, codebook, batch['rays'][i]))**2 for i in range(len(batch['rays'])))

def render_image(voxels, codebook, rays):
    # Standard volume rendering integral [G]
    return 0.0

def update_parameters(voxels, codebook, loss, lr):
    # Standard gradient descent update step [G]
    for v in voxels:
        codebook[v['index']] = [c - lr * 0.01 for c in codebook[v['index']]]
    return loss

def quantize_8bit(value):
    return max(0, min(255, int(value * 255)))
```

**Edge Cases and Pitfalls:**
*   **Codebook Size:** Choosing a codebook size larger than 4096 yields minimal PSNR improvement but significantly increases storage, making it inefficient [S1].
*   **Pruning Parameters:** Incorrect tuning of $\beta_p$ and $\beta_k$ can lead to either excessive quality loss or insufficient compression. The default values (0.6 and 0.001) provide a balanced trade-off [S1].
*   **Performance Drop:** Vector quantization alone causes a ~0.5 dB PSNR drop, which must be recovered via joint finetuning [S1].

### [Local Histogram Clustering for Volume Illumination](11177-local-histogram-clustering-for-volume-illumination.md)
A preprocessing technique that captures complex light interactions (diffuse interreflection and scattering) in volumetric data by computing local histograms for each voxel and clustering them into a small set of representative codebook entries. It enables interactive rendering with minimal additional texture fetches, distinguishing itself from standard volume rendering integrals that capture only emission and absorption, and from surface-based techniques that cannot dynamically adapt to transfer function changes.

## Operating characteristics
*   **Model Size:** VQRF achieves a model size of 1.4 MB (after zip compression) on the synthetic-NeRF dataset [S1].
*   **Rendering Quality:** On the synthetic-NeRF dataset, VQRF achieves a PSNR of 31.77 and SSIM of 0.954 [S1].
*   **Comparison to Baselines:**
    *   DVGO: 34.90 PSNR, 119.8 MB [S1].
    *   Plenoxels: 31.71 PSNR, 259.8 MB [S1].
    *   TensoRF: 33.09 PSNR, 67.6 MB [S1].
    *   VQRF outperforms these baselines and their VQ variants (VQ-DVGO, VQ-Plenoxels, VQ-TensoRF) in PSNR-size trade-off [S1].
*   **Compression Steps Impact:**
    *   Baseline: 31.90 PSNR, 105.9 MB [S1].
    *   +Voxel Pruning: 31.88 PSNR, 19.0 MB (5x compression) [S1].
    *   +Vector Quantization: 31.32 PSNR, 4.8 MB (another 5x reduction, -0.5 dB PSNR) [S1].
    *   +Joint Finetuning: 31.79 PSNR, 4.8 MB (recovers most performance) [S1].
    *   +Weight Quantization: 31.77 PSNR, 1.4 MB [S1].
*   **Strengths:** Extremely small model size (~1 MB) with high visual quality. Generalizes well to different datasets (synthetic-NeRF, synthetic-NSVF, Tanks&Temples, LLFF) [S1].
*   **Limitations:** Requires joint finetuning to recover performance after quantization. Performance is sensitive to codebook size and pruning parameters [S1].

## Background
VQRF was proposed in the paper "Compressing Volumetric Radiance Fields to 1 MB" [S1]. It builds on the parent method [Vector Quantization for Volumetric Radiance Fields](1870-vector-quantization-for-volumetric-radiance-fields.md) and applies it to specific volumetric radiance field representations like DVGO, Plenoxels, and TensoRF [S1]. The method addresses the large storage requirements of volumetric radiance fields by introducing a structured compression pipeline [S1].
