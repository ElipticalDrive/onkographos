# Temporal/Spatial Vector Quantization


## Overview
Temporal/Spatial Vector Quantization is a compression technique for multivariate time-varying volumetric data that groups voxels into blocks either along the temporal axis or the spatial axis to apply vector quantization algorithms [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Multivariate time-varying volume data [S1].
*   **Output:** Compressed bitstream containing block indices and the codebook [G].

**Data Structures:**
The method operates on two block types defined by the grouping strategy [S1]:
1.  **Temporal Block:** Voxels at a fixed spatial position $(x, y, z)$ across consecutive time steps.
2.  **Spatial Block:** Voxels at a fixed time step $t$ within a local spatial neighborhood.
Exact block dimensions are Not given in the sources.

**Algorithm Steps:**
1.  **Block Partitioning:** Partition the volume into either temporal or spatial blocks according to the chosen coherence strategy [S1].
2.  **Vector Formation:** Extract scalar values from each block to form a high-dimensional vector $\mathbf{v}$ [G].
3.  **Vector Quantization:** Use a pre-trained codebook $\mathcal{C} = \{\mathbf{c}_1, \dots, \mathbf{c}_L\}$ of representative vectors [G]. For each input vector $\mathbf{v}$, find the index $i$ of the closest codeword $\mathbf{c}_i$ using a distance metric (typically Euclidean distance):
    $$ i = \arg \min_{j \in \{1, \dots, L\}} \| \mathbf{v} - \mathbf{c}_j \|^2 $$
    [G]
4.  **Compression:** Store the index $i$ in the compressed stream [G].
5.  **Reconstruction (Decoding):** Retrieve the codeword $\mathbf{c}_i$ from the codebook, de-vectorize it back into the original block structure, and replace the original block values [G].

**Parameters:**
*   **Block Size:** Not given in the sources.
*   **Codebook Size ($L$):** Not given in the sources.
*   **Time Steps per Temporal Block:** Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Boundary Conditions:** Voxels at volume or time boundaries may not form complete blocks, requiring padding or irregular block handling [G].
*   **Codebook Training:** The codebook must be trained on representative data to ensure low quantization error [G].
*   **Precision:** Quantization error accumulates; high-precision data may require larger codebooks or smaller blocks [G].

### [Vector Quantization for Time-Varying Fields](6719-vector-quantization-for-time-varying-fields.md)
Extends vector quantization to encode scalar fields based on temporal coherence in a hierarchical data structure for time-varying unstructured grids. Chosen when dealing with unstructured grids where regular spatial blocking is not feasible.

## Operating characteristics
*   **Time and Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Not given in the sources.
*   **Strengths:** Exploits temporal or spatial redundancy effectively in multivariate time-varying volumes [S1].
*   **Limitations:** Performance depends heavily on block size and codebook selection, which are Not given in the sources.
*   **When to Use:** Suitable for multivariate time-varying volumes where either temporal or spatial coherence is strong [S1].
*   **When Not to Use:** When data lacks coherence in both domains or when high precision is required without large codebooks [G].

## Background
The method was proposed by Fout et al. [FAM* 05] for multivariate time-varying volumes [S1]. It builds on earlier work in wavelet-based compression and hierarchical structures for time-varying data [S1].
