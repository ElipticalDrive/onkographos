# Neural Implicit Network Compression

Also called: Coordinate-based MLP Compression, SIREN-based INR Compression, neurcomp

## Overview
Neural Implicit Network (INR) Compression replaces explicit grid-based storage with a coordinate-based neural network that maps spatial coordinates directly to field values, serving as simultaneously compressed storage and a queryable data source [S1, unofficial]. Unlike traditional lossy compressors (e.g., SZ, ZFP) that produce bitstreams requiring full decoding before visualization, INRs allow direct rendering via ray marching through the network [S1, unofficial]. The foundational method, neurcomp, distinguishes itself by using a SIREN MLP with residual connections and k-means weight quantization, achieving high compression ratios on scalar fields where traditional tensor decomposition methods fail [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D scalar field volume $V$ defined on an $N \times N \times N$ grid (e.g., $512^3$).
*   **Output:** A compressed neural network model (weights and biases) that approximates $V$.

**Data Structures:**
*   **Network Architecture:** A Multi-Layer Perceptron (MLP) using Sine Activation Functions (SIREN).
    *   **Layers:** Input layer (3D coordinates), hidden layers (typically 8 layers, 256 units each), output layer (1 unit for scalar value).
    *   **Residual Connections:** Added to improve gradient flow and fidelity [S1, unofficial].
    *   **Weight Quantization:** Weights are quantized to 9 bits using k-means clustering [S1, unofficial].

**Steps:**
1.  **Sampling:** Sample coordinates $(x, y, z)$ from the volume grid. Trilinear interpolation of the ground truth volume provides the target values $v$.
2.  **Encoding:** Apply positional or hash encoding $\gamma(x)$ to the input coordinates to help the network capture high-frequency details [S1, unofficial].
3.  **Training:** Train the SIREN MLP to minimize the reconstruction error between the network output and the sampled volume values.
    *   **Loss Function:** Standard Mean Squared Error (MSE) between predicted and actual values.
    *   **Gradient Regularization (Optional):** An optional gradient regularization term can be added to the loss to improve isosurface fidelity, at the cost of slight PSNR reduction [S1, unofficial].
4.  **Quantization:** Apply k-means clustering to the trained network weights to quantize them to 9 bits [S1, unofficial].
5.  **Storage:** Store the quantized weights and the network architecture definition.

## Subtopics

### Time-varying INR compression via Laplacian pyramid
A method that decomposes time-varying volumes via a Laplacian pyramid with per-block MLPs to improve decoding speed [S1, unofficial]. It achieves decoding speeds 13–30× faster than neurcomp on datasets up to $1,728^3$ [S1, unofficial].

### MVNet
A method for compressing multivariate data by formulating it as multi-task learning, using a Residual SIREN with a v-dimensional output layer (v = number of physical variables) sharing intermediate parameters across variables [S1, unofficial]. It outperforms TTHRESH (48.62 dB at 343:1) on a 100-variable climate dataset (1568 MB) with 49.68 dB PSNR at 1298:1 compression, preserving inter-variable statistical dependencies better than traditional compressors [S1, unofficial]. It has only been tested on static datasets [S1, unofficial].

### KD-INR
A two-stage pipeline for compressing time-varying data: first compressing each timestep independently with a small INR with bottleneck layers, then merging all per-timestep teacher models into a single student via offline knowledge distillation (an $O(n)$ procedure) [S1, unofficial]. It uses entropy-based adaptive sampling to concentrate training on high-information blocks [S1, unofficial]. On time-varying datasets up to 23.44 GB (argon bubble, 150 timesteps), it outperformed CoordNet, NeurComp, and SIREN at compression ratios from 733 to 10,000, with per-timestep compression requiring 1–6 minutes on a single GPU [S1, unofficial].

## Operating characteristics
*   **Compression Ratio:** neurcomp achieved 545:1 compression on the Rayleigh-Taylor dataset with 47.9 dB PSNR, outperforming tensor decomposition (TTHRESH) at high compression ratios for scalar fields up to $512^3$ [S1, unofficial].
*   **Performance:** MVNet achieved 1298:1 compression on a 100-variable climate dataset [S1, unofficial]. KD-INR achieved compression ratios from 733 to 10,000 on time-varying datasets [S1, unofficial].
*   **Speed:** Neurcomp training requires hours per volume on a V100 GPU [S1, unofficial]. Time-varying variants like the Laplacian pyramid approach offer 13–30× faster decoding than neurcomp [S1, unofficial]. KD-INR requires 1–6 minutes per timestep [S1, unofficial].
*   **Limitations:** Neurcomp cannot render interactively [S1, unofficial]. MVNet is limited to static datasets [S1, unofficial].
*   **Strengths:** Simultaneously compressed storage and queryable data source [S1, unofficial]. Preserves inter-variable statistical dependencies in multivariate data [S1, unofficial].

## Background
Neural Implicit Network Compression was introduced as the first INR compression method for scientific volumes, using a coordinate-based SIREN MLP with residual connections and 9-bit weight quantization via k-means clustering [S1, unofficial]. It addresses the strain on storage systems and I/O pipelines caused by full-resolution scientific volumes [S1, unofficial]. The method was developed to provide an alternative to traditional lossy compressors like SZ and ZFP, which require full decoding before visualization [S1, unofficial].
