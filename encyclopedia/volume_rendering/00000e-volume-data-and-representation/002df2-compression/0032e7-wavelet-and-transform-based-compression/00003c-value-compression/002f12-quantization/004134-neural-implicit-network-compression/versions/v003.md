# Neural Implicit Network Compression

Also called: Coordinate-based MLP Compression, SIREN-based INR Compression, neurcomp

## Overview
Neural Implicit Network Compression (specifically the **neurcomp** method) compresses scientific volume data by training a coordinate-based neural network to map spatial coordinates directly to field values [S1, unofficial]. Unlike traditional lossy compressors that produce bitstreams requiring full decoding before visualization, this method serves as simultaneously compressed storage and a queryable data source [S1, unofficial]. It distinguishes itself from sibling quantization methods by replacing explicit grid storage with a compact neural representation, achieving high compression ratios (e.g., 545:1) on scalar fields where traditional tensor decomposition fails [S1, unofficial].

## How it works
**Inputs:** A scalar volume $V$ defined on a 3D grid (e.g., $N^3$).
**Outputs:** A quantized neural network model (weights and biases) that approximates $V$.

**Data Structures:**
The core data structure is a Multi-Layer Perceptron (MLP), specifically a SIREN (Sinusoidal Representation Network) architecture with residual connections.
*   **Weights/Biases:** Stored as fixed-point integers. The method uses 9-bit quantization for weights.
*   **Quantization Scheme:** K-means clustering is applied to the continuous weight values to determine the optimal discrete levels for the 9-bit representation.

**Algorithm Steps:**
1.  **Sampling:** Generate a set of training samples consisting of spatial coordinates $\{(x_j, y_j, z_j)\}$ and their corresponding field values $v_j = V(x_j, y_j, z_j)$.
2.  **Network Initialization:** Initialize a SIREN MLP. SIRENs use sinusoidal activation functions ($\sin(\cdot)$) which are effective for representing high-frequency details in scientific data. Residual connections are added to facilitate training deep networks.
3.  **Training:** Optimize the network parameters $\theta$ to minimize the mean squared error between the network output and the sampled data:
    $$ \mathcal{L}(\theta) = \frac{1}{M} \sum_{j=1}^{M} \| f_\theta(x_j, y_j, z_j) - v_j \|^2 $$
    where $f_\theta$ is the network, $M$ is the number of samples, and $\theta$ are the weights.
4.  **Optional Regularization:** To improve isosurface fidelity, an optional gradient regularization term can be added to the loss function. This penalizes deviations in the spatial gradients of the network output, improving the accuracy of derived features like surfaces at the cost of a slight reduction in PSNR [S1, unofficial].
5.  **Quantization:** After training converges, apply k-means clustering to the learned weight matrices to quantize them to 9-bit precision [S1, unofficial].
6.  **Storage:** Store the quantized weights and the network architecture definition.

def trilinear_interpolate(grid, coords, N):
    """
    Performs trilinear interpolation on a 3D grid.
    """
    # Scale coordinates to grid dimensions
    scaled_coords = coords * (N - 1)
    x, y, z = scaled_coords[:, 0], scaled_coords[:, 1], scaled_coords[:, 2]
    
    # Get integer and fractional parts
    x0, y0, z0 = np.floor(x).astype(int), np.floor(y).astype(int), np.floor(z).astype(int)
    x1, y1, z1 = x0 + 1, y0 + 1, z0 + 1
    
    # Handle boundary conditions
    x0 = np.clip(x0, 0, N-1)
    y0 = np.clip(y0, 0, N-1)
    z0 = np.clip(z0, 0, N-1)
    x1 = np.clip(x1, 0, N-1)
    y1 = np.clip(y1, 0, N-1)
    z1 = np.clip(z1, 0, N-1)
    
    # Extract corner values
    v000 = grid[x0, y0, z0]
    v100 = grid[x1, y0, z0]
    v010 = grid[x0, y1, z0]
    v110 = grid[x1, y1, z0]
    v001 = grid[x0, y0, z1]
    v101 = grid[x1, y0, z1]
    v011 = grid[x0, y1, z1]
    v111 = grid[x1, y1, z1]
    
    # Interpolation weights
    fx = x - x0
    fy = y - y0
    fz = z - z0
    
    # Trilinear interpolation formula
    v00 = v000 * (1-fx) + v100 * fx
    v10 = v010 * (1-fx) + v110 * fx
    v01 = v001 * (1-fx) + v101 * fx
    v11 = v011 * (1-fx) + v111 * fx
    
    v0 = v00 * (1-fy) + v10 * fy
    v1 = v01 * (1-fy) + v11 * fy
    
    result = v0 * (1-fz) + v1 * fz
    return result

*   **Interactive Rendering:** The method could not render interactively from the volume due to the computational cost of querying the neural network [S1, unofficial].
*   **Gradient Regularization Trade-off:** Using gradient regularization improves isosurface fidelity but reduces PSNR [S1, unofficial].

## Subtopics

### Time-varying INR compression via Laplacian pyramid
A method that decomposes time-varying volumes using a Laplacian pyramid with per-block MLPs to improve decoding speed [S1, unofficial]. It is chosen when decoding speed is critical for large time-varying datasets. It achieves decoding speeds 13–30× faster than neurcomp on datasets up to $1,728^3$ [S1, unofficial].

### MVNet
A method for compressing multivariate data by formulating it as multi-task learning, using a Residual SIREN with a $v$-dimensional output layer (where $v$ is the number of physical variables) and sharing all intermediate parameters across variables [S1, unofficial]. It is chosen for multivariate datasets to preserve inter-variable statistical dependencies (Pearson correlation and mutual information) better than traditional compressors [S1, unofficial]. On a 100-variable climate dataset (1568 MB), it achieved 49.68 dB PSNR at 1298:1 compression, outperforming TTHRESH (48.62 dB at 343:1) [S1, unofficial]. Pitfall: Only tested on static datasets [S1, unofficial].

### KD-INR
A two-stage pipeline for compressing time-varying data. Stage 1 compresses each timestep independently with a small INR with bottleneck layers, using entropy-based adaptive sampling to concentrate training on high-information blocks. Stage 2 merges all per-timestep teacher models into a single student via offline knowledge distillation (an $O(n)$ procedure) [S1, unofficial]. It is chosen for time-varying data where a single unified model is preferred over per-timestep models. On datasets up to 23.44 GB (argon bubble, 150 timesteps), it outperformed CoordNet, NeurComp, and SIREN at compression ratios from 733 to 10,000, with per-timestep compression requiring 1–6 minutes on a single GPU [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Training requires hours per volume on a V100 GPU [S1, unofficial]. KD-INR reduces per-timestep training to 1–6 minutes [S1, unofficial].
*   **Memory Complexity:** Storage is determined by the size of the quantized neural network weights. For neurcomp, 9-bit quantization significantly reduces the footprint compared to full-precision floats.
*   **Measured Performance:** On scalar fields up to $512^3$, neurcomp achieved 47.9 dB PSNR at 545:1 compression on the Rayleigh-Taylor dataset, outperforming tensor decomposition (TTHRESH) at high compression ratios [S1, unofficial].
*   **Strengths:** Simultaneously compressed storage and queryable data source; high compression ratios; preserves inter-variable dependencies (MVNet); fast decoding for time-varying data (Laplacian pyramid, KD-INR).
*   **Limitations:** Cannot render interactively from the volume (neurcomp); training time can be significant; quality is upper-bounded by the teacher model (KD-INR); only tested on static datasets for MVNet [S1, unofficial].
*   **When to Use:** When storage space is constrained and interactive rendering is not required during the compression phase, or when using variants optimized for decoding speed.
*   **When Not to Use:** When interactive rendering from the compressed representation is required without additional caching or acceleration structures.

## Background
Neural Implicit Network Compression for scientific volumes was introduced by Sheibanifard and Yu [102, unofficial] as the first INR compression method for scientific volumes. It uses a coordinate-based SIREN MLP with residual connections and 9-bit weight quantization via k-means clustering [S1, unofficial]. The method addresses the strain on storage systems and I/O pipelines caused by full-resolution scientific volumes, offering an alternative to traditional lossy compressors like SZ and ZFP which produce bitstreams that must be fully decoded before visualization [S1, unofficial].
