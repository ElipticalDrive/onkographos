# Neural Implicit Network Compression

Also called: Coordinate-based MLP Compression, SIREN-based INR Compression, neurcomp

## Overview
Neural Implicit Network (INR) Compression replaces explicit volumetric grids with a coordinate-based neural network that maps spatial coordinates directly to field values, serving as simultaneously compressed storage and a queryable data source [S1, unofficial]. Unlike traditional lossy compressors (e.g., SZ, ZFP) that produce bitstreams requiring full decoding before visualization, INRs allow direct evaluation at arbitrary resolutions [S1, unofficial]. The primary method, **neurcomp**, distinguishes itself by using a SIREN MLP with residual connections and 9-bit weight quantization via k-means clustering, achieving high compression ratios on scalar fields where tensor decomposition methods fail [S1, unofficial]. It builds on [Quantization](5935-quantization.md) principles to reduce model size.

## How it works
**Inputs:** A scalar volumetric dataset $V$ of resolution $N \times N \times N$ (e.g., $512^3$).
**Outputs:** A quantized neural network model (weights and biases) that approximates $V$.

**Data Structures:**
1.  **Network Weights:** A set of matrices $W$ and vectors $b$ representing the MLP.
2.  **Quantization Codebook:** A set of $K$ centroids generated via k-means clustering on the original weights.
3.  **Indices:** For each weight element, an integer index pointing to the nearest centroid in the codebook.

**Method Steps:**
1.  **Network Architecture:** Construct a coordinate-based MLP using SIREN (Sinusoidal Representation Networks) layers. SIREN layers use sine activation functions $\sin(\omega_0 x)$, which are critical for representing high-frequency details in scientific data [S1, unofficial].
2.  **Residual Connections:** Add residual connections between layers to stabilize training and improve gradient flow for deep networks [S1, unofficial].
3.  **Training:** Train the network to minimize the mean squared error (MSE) between the network output $f(x, y, z)$ and the ground truth value $v$ at sampled coordinates $(x, y, z)$ from the volume.
    *   *Optional:* Add a gradient regularization term $\lambda \|\nabla f - \nabla v\|^2$ to improve isosurface fidelity. This improves geometric accuracy at the cost of a slight reduction in PSNR [S1, unofficial].
4.  **Weight Quantization:** After training, apply k-means clustering to the network weights to find $K$ centroids. Replace each weight value with the index of its nearest centroid.
    *   *Typical Parameter:* 9-bit quantization (512 centroids) is used in the baseline neurcomp method [S1, unofficial].
5.  **Storage:** Store the codebook (centroids) and the quantized indices. The total size is the sum of the codebook size and the index size.

    """
    Quantizes trained weights using k-means clustering.
    Returns quantized model (indices) and codebook.
    """
    codebook = []
    quantized_weights = {}
    
    for name, param in model.named_parameters():
        weights = param.detach().cpu().numpy().flatten()
        
        # K-means clustering
        kmeans = KMeans(n_clusters=num_centroids, random_state=42)

        quantized_weights[name] = labels.reshape(param.shape)

**Parameters:**
*   **Bit Depth:** 9 bits per weight (512 centroids) [S1, unofficial].
*   **Hardware:** Training requires hours per volume on a V100 GPU [S1, unofficial].
*   **Resolution:** Tested on scalar fields up to $512^3$ [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Interactive Rendering:** The method could not render interactively from the volume due to the computational cost of evaluating the MLP for every ray [S1, unofficial].
*   **Precision:** High-frequency details may be lost if the network capacity is insufficient or if quantization is too aggressive.
*   **Training Time:** Training is computationally expensive compared to traditional compression [S1, unofficial].

## Subtopics

### Time-varying INR compression via Laplacian pyramid
A method decomposing time-varying volumes via a Laplacian pyramid with per-block MLPs to improve decoding speed [S1, unofficial]. It achieves decoding speeds 13–30× faster than neurcomp on datasets up to $1,728^3$ [S1, unofficial].

### MVNet
A method for compressing multivariate data by formulating it as multi-task learning, using a Residual SIREN with a v-dimensional output layer (v = number of physical variables) sharing intermediate parameters across variables [S1, unofficial]. It outperforms TTHRESH (48.62 dB at 343:1) on a 100-variable climate dataset (1568 MB) with 49.68 dB PSNR at 1298:1 compression, while preserving inter-variable statistical dependencies (Pearson correlation and mutual information) better than traditional compressors [S1, unofficial]. It has only been tested on static datasets [S1, unofficial].

### KD-INR
A two-stage pipeline for compressing time-varying data: first compressing each timestep independently with a small INR with bottleneck layers, using entropy-based adaptive sampling to concentrate training on high-information blocks; then merging all per-timestep teacher models into a single student via offline knowledge distillation (an $O(n)$ procedure) [S1, unofficial]. On time-varying datasets up to 23.44 GB (argon bubble, 150 timesteps), it outperformed CoordNet, NeurComp, and SIREN at compression ratios from 733 to 10,000, with per-timestep compression requiring 1–6 minutes on a single GPU [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Training time is high, requiring hours per volume on a V100 GPU for neurcomp [S1, unofficial]. KD-INR reduces this to 1–6 minutes per timestep [S1, unofficial].
*   **Memory Complexity:** Storage size is determined by the quantized weights. neurcomp achieves 545:1 compression on the Rayleigh-Taylor dataset [S1, unofficial]. MVNet achieves 1298:1 on a 100-variable climate dataset [S1, unofficial].
*   **Performance:** neurcomp outperforms tensor decomposition (TTHRESH) at high compression ratios, achieving 47.9 dB PSNR at 545:1 compression on the Rayleigh-Taylor dataset [S1, unofficial].
*   **Strengths:** High compression ratios, queryable data source, preserves inter-variable dependencies (MVNet), fast decoding for time-varying data (Laplacian pyramid, KD-INR).
*   **Limitations:** Slow interactive rendering (neurcomp), high training time, limited to static or time-varying data (MVNet tested only on static) [S1, unofficial].
*   **When to use:** When storage is constrained and interactive rendering is not required, or when using acceleration structures (e.g., GPU caches) for rendering.
*   **When not to use:** When real-time interactive rendering is required without additional acceleration, or when training time is a critical bottleneck.

## Background
Neural Implicit Network Compression was introduced as a method for scientific volumes, with neurcomp being the first INR compression method for this domain [S1, unofficial]. It leverages the ability of coordinate-based MLPs to represent continuous functions, allowing for compressed storage and arbitrary-resolution querying. The method uses SIREN MLPs, which are known for their ability to represent high-frequency signals, and applies weight quantization to reduce model size [S1, unofficial]. Subsequent variants like MVNet, KD-INR, and Laplacian pyramid methods have extended this approach to multivariate and time-varying data [S1, unofficial].
