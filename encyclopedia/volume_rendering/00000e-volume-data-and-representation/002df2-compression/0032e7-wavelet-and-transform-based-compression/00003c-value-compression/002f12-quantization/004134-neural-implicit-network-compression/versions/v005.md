# Neural Implicit Network Compression

Also called: Coordinate-based MLP Compression, SIREN-based INR Compression, neurcomp

## Overview
Neural Implicit Network Compression (INR Compression) maps spatial coordinates directly to field values using a coordinate-based neural network, serving as simultaneously compressed storage and a queryable data source [S1, unofficial]. It solves the storage and I/O bottlenecks of traditional lossy compressors (e.g., SZ, ZFP) by replacing large bitstreams with compact network weights [S1, unofficial]. Unlike [Quantization](5935-quantization.md) which discretizes values, INR compression learns a continuous function; unlike [Differentiable Quantization for Neural Fields](10195-differentiable-quantization-for-neural-fields.md) which focuses on quantizing existing fields, this method *is* the compression mechanism itself [S1, unofficial].

## How it works
**Inputs:**
*   3D spatial coordinates $\mathbf{x} = (x, y, z)$ sampled from the volume domain.
*   Ground truth scalar field values $v$ at those coordinates.
*   (Optional) Gradient information for regularization.

**Outputs:**
*   A trained neural network (typically a SIREN MLP) whose weights represent the compressed volume.
*   The network acts as a decoder: $v_{pred} = f_{\theta}(\mathbf{x})$.

**Data Structures:**
*   **Network Weights:** Stored as quantized integers. In the baseline neurcomp method, weights are quantized to 9-bit integers using k-means clustering [S1, unofficial].
*   **Sampling Grid:** Coordinates are typically sampled uniformly or via entropy-based adaptive sampling for high-information blocks [S1, unofficial].

**Algorithm (neurcomp baseline):**
1.  **Architecture Selection:** Initialize a coordinate-based SIREN (Sinusoidal Representation Network) MLP with residual connections [S1, unofficial].
2.  **Coordinate Encoding:** Map input coordinates $\mathbf{x}$ using positional encoding or hash encoding $\gamma(\mathbf{x})$ [S1, unofficial].
3.  **Forward Pass:** Compute predicted value $\hat{v} = f_{\theta}(\gamma(\mathbf{x}))$ [S1, unofficial].
4.  **Loss Calculation:** Minimize reconstruction error (e.g., MSE) between $\hat{v}$ and ground truth $v$. Optionally add a gradient regularization term $\mathcal{L}_{grad}$ to improve isosurface fidelity [S1, unofficial].
    $$ \mathcal{L} = \mathcal{L}_{rec} + \lambda \mathcal{L}_{grad} $$
5.  **Quantization:** Apply k-means clustering to the learned weights $\theta$ to quantize them to 9-bit integers [S1, unofficial].
6.  **Storage:** Store the quantized weights and the network architecture definition [S1, unofficial].

**Pseudocode:**
```python
def train_neurcomp(volume_data, num_epochs=1000, learning_rate=1e-4):
    # Initialize SIREN MLP with residual connections
    model = SIREN_MLP(residual=True)
    
    # Sample coordinates and values from volume
    coords, values = sample_volume(volume_data)
    
    optimizer = Adam(model.parameters(), lr=learning_rate)
    
    for epoch in range(num_epochs):
        optimizer.zero_grad()
        
        # Forward pass
        encoded_coords = positional_encoding(coords)
        predicted_values = model(encoded_coords)
        
        # Reconstruction loss
        loss_rec = mse_loss(predicted_values, values)
        
        # Optional gradient regularization for isosurface fidelity
        # Note: Requires computing gradients of predicted_values w.r.t coords
        grad_loss = compute_gradient_regularization(predicted_values, coords)
        loss = loss_rec + 0.1 * grad_loss  # lambda = 0.1 [G]
        
        loss.backward()
        optimizer.step()
        
    # Quantize weights using k-means clustering to 9-bit
    quantized_weights = kmeans_quantize(model.get_weights(), bits=9)
    
    return quantized_weights

def query_neurcomp(quantized_weights, coords):
    # Reconstruct model from quantized weights
    model = SIREN_MLP.from_weights(quantized_weights)
    encoded_coords = positional_encoding(coords)
    return model(encoded_coords)
```

**Parameters:**
*   **Weight Bit Depth:** 9-bit (neurcomp) [S1, unofficial].
*   **Training Time:** Hours per volume on a V100 GPU [S1, unofficial].
*   **Max Resolution (neurcomp):** $512^3$ [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Interactive Rendering:** The method could not render interactively from the volume due to the computational cost of querying the network [S1, unofficial].
*   **Training Cost:** High training time per volume [S1, unofficial].

## Subtopics

### Time-varying INR compression via Laplacian pyramid
A method decomposing time-varying volumes via a Laplacian pyramid with per-block MLPs to improve decoding speed [S1, unofficial]. It achieves decoding speeds 13–30× faster than neurcomp on datasets up to $1,728^3$ [S1, unofficial].

### MVNet
A method for compressing multivariate data by formulating it as multi-task learning, using a Residual SIREN with a v-dimensional output layer (v = number of physical variables) sharing all intermediate parameters across variables [S1, unofficial]. It preserves inter-variable statistical dependencies (Pearson correlation and mutual information) better than traditional compressors [S1, unofficial]. On a 100-variable climate dataset (1568 MB), it achieved 49.68 dB PSNR at 1298:1 compression, outperforming TTHRESH (48.62 dB at 343:1) [S1, unofficial]. It has only been tested on static datasets [S1, unofficial].

### KD-INR
A two-stage pipeline for compressing time-varying data: Stage 1 compresses each timestep independently with a small INR with bottleneck layers and entropy-based adaptive sampling; Stage 2 merges all per-timestep teacher models into a single student via offline knowledge distillation (an $O(n)$ procedure) [S1, unofficial]. On time-varying datasets up to 23.44 GB (argon bubble, 150 timesteps), it outperformed CoordNet, NeurComp, and SIREN at compression ratios from 733 to 10,000, with per-timestep compression requiring 1–6 minutes on a single GPU [S1, unofficial].

## Operating characteristics
*   **Compression Ratio:** neurcomp achieved 545:1 on the Rayleigh-Taylor dataset ($512^3$) with 47.9 dB PSNR, outperforming tensor decomposition (TTHRESH) at high compression ratios [S1, unofficial]. MVNet achieved 1298:1 on a 100-variable climate dataset [S1, unofficial]. KD-INR achieved ratios from 733 to 10,000 [S1, unofficial].
*   **Performance:** neurcomp training requires hours per volume on a V100 GPU [S1, unofficial]. Laplacian pyramid method offers 13–30× faster decoding than neurcomp [S1, unofficial].
*   **Strengths:** Simultaneously compressed storage and queryable data source; preserves inter-variable dependencies (MVNet); high compression ratios for scientific volumes [S1, unofficial].
*   **Limitations:** Cannot render interactively (neurcomp); high training time; limited to static datasets for some variants (MVNet) [S1, unofficial].
*   **When to use:** When storage/I/O is a bottleneck and interactive rendering is not required during the compression phase; for multivariate data where statistical dependencies matter [S1, unofficial].
*   **When not to use:** When interactive rendering speed is critical without caching; for very large time-varying datasets where training time is prohibitive [S1, unofficial].

## Background
Neural Implicit Network Compression was introduced as the first INR compression method for scientific volumes, using a coordinate-based SIREN MLP with residual connections and 9-bit weight quantization via k-means clustering [S1, unofficial]. It addresses the strain that full-resolution scientific volumes place on storage systems and I/O pipelines [S1, unofficial]. Traditional lossy compressors like SZ and ZFP produce bitstreams that must be fully decoded before visualization, whereas INRs offer a compact network that maps spatial coordinates to field values [S1, unofficial].
