# Neural Implicit Network Compression

Also called: Coordinate-based MLP Compression, SIREN-based INR Compression, neurcomp

## Overview
Neural Implicit Network (INR) Compression represents a volumetric field $V$ as a coordinate-based neural network that maps spatial coordinates directly to field values, serving as simultaneously compressed storage and a queryable data source [S1, unofficial]. Unlike traditional lossy compressors (e.g., SZ, ZFP) that produce bitstreams requiring full decoding before visualization, INR compression enables direct rendering from the network weights [S1, unofficial]. It sets itself apart from sibling quantization methods by replacing explicit coefficient storage with learned parametric functions, allowing for infinite-resolution queries at the cost of significant training overhead and non-interactive inference speeds in early implementations [S1, unofficial].

## How it works
The core method, introduced as **neurcomp**, uses a coordinate-based SIREN (Sinusoidal Representation Networks) MLP with residual connections [S1, unofficial].

**Inputs and Outputs:**
*   **Input:** A scalar field volume $V$ on an $N^3$ grid (e.g., $512^3$).
*   **Output:** A set of quantized network weights $W$ that define the function $f_\theta(x, y, z) \approx V(x, y, z)$.

**Data Structures:**
*   **Network Architecture:** A Multi-Layer Perceptron (MLP) using SIREN layers.
    *   Input: 3D coordinates $(x, y, z)$.
    *   Hidden Layers: Linear layers with sinusoidal activation functions $\sin(\omega_0 x)$.
    *   Residual Connections: Added to stabilize training and improve fidelity [S1, unofficial].
*   **Weight Storage:** The network weights are quantized using k-means clustering to 9-bit precision [S1, unofficial].

**Steps:**
1.  **Sampling:** Sample spatial coordinates $\{(x_j, y_j, z_j)\}$ from the volume $V$.
2.  **Encoding:** Apply positional or hash encoding $\gamma(x)$ to the coordinates if not using raw coordinates (SIREN typically uses raw coordinates with specific frequency scaling) [S1, unofficial].
3.  **Forward Pass:** Compute field values $v_j = f_\theta(x_j, y_j, z_j)$ using the current network parameters $\theta$.
4.  **Loss Calculation:** Minimize the reconstruction error between $v_j$ and the ground truth $V(x_j, y_j, z_j)$. An optional gradient regularization term can be added to improve isosurface fidelity, though it may slightly reduce PSNR [S1, unofficial].
5.  **Quantization:** Apply k-means clustering to the network weights to reduce precision to 9 bits [S1, unofficial].

**Pseudocode:**
```python

def train_neurcomp(volume_data, grid_size):
    # 1. Initialize SIREN MLP with residual connections
    # Input dim: 3 (x, y, z)
    # Hidden layers: Linear + sin activation
    model = SIREN_MLP(residual=True)
    
    # 2. Sample coordinates from the volume
    # In practice, this involves sampling points from the N^3 grid
    coordinates = sample_coordinates(volume_data, grid_size)
    ground_truth_values = interpolate_volume(volume_data, coordinates)
    
    # 3. Training Loop
    for epoch in range(num_epochs):
        # Forward pass
        predicted_values = model(coordinates)
        
        # Loss: Reconstruction error + optional gradient regularization
        reconstruction_loss = mse(predicted_values, ground_truth_values)
        gradient_loss = compute_gradient_regularization(predicted_values, coordinates)
        total_loss = reconstruction_loss + lambda_grad * gradient_loss
        
        # Backpropagation and optimization
        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()
        
    return model

def compress_weights(model):
    # 4. Quantize weights using k-means clustering to 9-bit precision
    all_weights = get_all_weights(model)
    quantized_weights = kmeans_quantize(all_weights, bits=9)
    return quantized_weights

def render(quantized_weights, query_points):
    # 5. Reconstruct network and query
    model = reconstruct_model(quantized_weights)
    values = model(query_points)
    return values
```

**Parameters:**
*   **Weight Quantization Bits:** 9 bits (using k-means) [S1, unofficial].
*   **Training Hardware:** V100 GPU [S1, unofficial].
*   **Training Time:** Hours per volume [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Interactive Rendering:** The method could not render interactively from the volume due to the computational cost of evaluating the network for every ray/sample [S1, unofficial].
*   **Fidelity vs. PSNR:** Adding gradient regularization improves isosurface fidelity but causes a slight reduction in PSNR [S1, unofficial].

## Subtopics

### Time-varying INR compression via Laplacian pyramid
A method that decomposes time-varying volumes via a Laplacian pyramid with per-block MLPs to improve decoding speed [S1, unofficial]. It achieves decoding speeds 13–30× faster than neurcomp on datasets up to $1,728^3$ [S1, unofficial].

### MVNet
A method for compressing multivariate data by formulating it as multi-task learning, using a Residual SIREN with a $v$-dimensional output layer (where $v$ is the number of physical variables) that shares all intermediate parameters across variables [S1, unofficial]. It preserves inter-variable statistical dependencies (Pearson correlation and mutual information) better than traditional compressors. On a 100-variable climate dataset (1568 MB), it achieved 49.68 dB PSNR at 1298:1 compression, outperforming TTHRESH (48.62 dB at 343:1) [S1, unofficial]. It has only been tested on static datasets [S1, unofficial].

### KD-INR
A two-stage pipeline for compressing time-varying data: first, each timestep is independently compressed with a small INR with bottleneck layers, using entropy-based adaptive sampling to concentrate training on high-information blocks; second, all per-timestep teacher models are merged into a single student via offline knowledge distillation (an $O(n)$ procedure) [S1, unofficial]. On time-varying datasets up to 23.44 GB (argon bubble, 150 timesteps), it outperformed CoordNet, NeurComp, and SIREN at compression ratios from 733 to 10,000, with per-timestep training requiring 1–6 minutes on a single GPU [S1, unofficial].

## Operating characteristics
*   **Compression Performance:** On scalar fields up to $512^3$, neurcomp outperformed tensor decomposition (TTHRESH) at high compression ratios, achieving 47.9 dB PSNR at 545:1 compression on the Rayleigh-Taylor dataset [S1, unofficial].
*   **Training Cost:** Training requires hours per volume on a V100 GPU [S1, unofficial].
*   **Rendering Speed:** Early implementations (neurcomp) could not render interactively [S1, unofficial]. Variants like the Laplacian pyramid approach achieve 13–30× faster decoding than neurcomp [S1, unofficial].
*   **Scalability:** MVNet scales compression ratios with the number of variables [S1, unofficial]. KD-INR scales to datasets up to 23.44 GB [S1, unofficial].
*   **Strengths:** Simultaneously compressed storage and queryable data source; preserves inter-variable dependencies (MVNet); high compression ratios for scientific volumes [S1, unofficial].
*   **Limitations:** High training time; non-interactive rendering in basic forms; lack of standardized benchmarks makes cross-method comparison difficult [S1, unofficial].

## Background
Neural Implicit Network Compression was introduced as the first INR compression method for scientific volumes [S1, unofficial]. It utilizes coordinate-based SIREN MLPs with residual connections and 9-bit weight quantization via k-means clustering [S1, unofficial]. The approach addresses the strain on storage systems and I/O pipelines caused by full-resolution scientific volumes [S1, unofficial].
