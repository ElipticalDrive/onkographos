# Global Quantization

Also called: Global shared parameter table quantization

## Overview
Global quantization is a compression strategy for neural volume representations that maintains a single shared parameter table for all independent small Multi-Layer Perceptrons (MLPs) within a specific scale, rather than quantizing each network locally [S1]. It solves the redundancy problem where distinct spatial blocks often contain similar content, allowing multiple MLPs to map to the same set of floating-point parameters [S1]. This approach achieves higher compression ratios than local quantization while maintaining comparable reconstruction accuracy [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of independent small MLPs encoding disjoint volumetric blocks at a specific scale; a target quantization precision $\beta$ (in bits).
*   **Output:** A single global shared parameter table of floating-point values and a set of $\beta$-bit indices for each MLP mapping its weights and biases to this table.

**Data Structures:**
1.  **Global Shared Parameter Table:** A list of $2^\beta$ floating-point values. This table stores the actual quantized weights and biases for all MLPs in the scale.
2.  **Index Map:** For each MLP, a mapping from its original weight/bias positions to indices in the Global Shared Parameter Table. Each index is $\beta$ bits long.

**Parameters:**
*   $\beta$: The number of bits used for local quantization precision. Typical value: 7 [S1].

**Steps:**
1.  **Clustering:** For a specific layer across all MLPs in the scale, apply standard k-means clustering to group the unpruned weights into $2^\beta$ clusters [S1].
2.  **Indexing:** Represent the weights and biases of each MLP in the quantized layer as $\beta$-bit indices that map to the $2^\beta$ shared floating-point parameters [S1].
3.  **Global Sharing:** Apply this quantization globally across all MLPs within the single scale. This leverages the fact that different blocks often contain similar content, allowing them to share the same parameters [S1].
4.  **Bias Quantization:** Quantize both the MLP biases and weights, rather than only weights, to boost the compression ratio under similar reconstruction accuracy [S1].
5.  **Fine-tuning:** Fix the parameter indices after quantization. Fine-tune the corresponding shared parameters through backpropagation to minimize performance degradation at the same precision [S1].

**Pseudocode:**

```python
import numpy as np
from sklearn.cluster import KMeans

def global_quantization(mlp_list, beta):
    """
    Applies global quantization to a list of MLPs at a specific scale.
    
    Args:
        mlp_list: List of MLP objects, each containing weight and bias tensors.
        beta: Number of bits for quantization precision.
        
    Returns:
        global_table: Array of shape (2**beta, feature_dim) containing shared parameters.
        index_maps: Dictionary mapping each MLP to its index mapping.
    """
    num_clusters = 2 ** beta
    
    # Step 1: Collect all unpruned weights and biases from all MLPs in the scale
    # Note: In practice, this is done layer by layer or per parameter type.
    # For simplicity, we assume a single layer or flattened parameter vector for the example.
    all_params = []
    mlp_ids = []
    
    for i, mlp in enumerate(mlp_list):
        # Flatten weights and biases for clustering
        params = np.concatenate([mlp.weights.flatten(), mlp.biases.flatten()])
        all_params.append(params)
        mlp_ids.append(i)
        
    # Combine all parameters for global clustering
    # Shape: (total_params, 1)
    combined_params = np.vstack(all_params)
    
    # Step 2: Apply k-means clustering to group parameters into 2^beta clusters
    kmeans = KMeans(n_clusters=num_clusters, random_state=42)
    kmeans.fit(combined_params)
    
    # The cluster centers form the global shared parameter table
    global_table = kmeans.cluster_centers_.flatten()
    
    # Step 3: Map each MLP's parameters to cluster indices
    # Predict cluster labels for all parameters
    labels = kmeans.predict(combined_params)
    
    # Reconstruct index maps for each MLP
    index_maps = {}
    current_idx = 0
    for i, mlp in enumerate(mlp_list):
        # Determine the number of parameters in this MLP
        num_params = len(mlp.weights.flatten()) + len(mlp.biases.flatten())
        
        # Extract indices for this MLP
        mlp_indices = labels[current_idx : current_idx + num_params]
        
        # Store the mapping. The MLP now stores indices instead of values.
        # In a real implementation, the MLP would look up values in global_table using these indices.
        index_maps[mlp_ids[i]] = mlp_indices
        
        current_idx += num_params
        
    # Step 4: Fine-tuning (Conceptual)
    # Fix indices, optimize global_table via backpropagation.
    # This step is handled by the training loop, not this function.
    
    return global_table, index_maps
```

**Edge Cases and Pitfalls:**
*   **Precision:** The choice of $\beta$ affects the trade-off between compression ratio and reconstruction accuracy. A value of $\beta=7$ is typical for small MLPs [S1].
*   **Similarity Assumption:** The method relies on the assumption that different blocks contain similar content. If blocks are highly dissimilar, global quantization may lead to higher performance degradation compared to local quantization [S1].
*   **Bias Quantization:** Quantizing biases is crucial for boosting compression ratio; omitting them reduces effectiveness [S1].

## Subtopics

### Local Quantization
Quantizes each MLP individually. Less effective for compression when blocks share content. Choose when blocks are highly dissimilar. [S1]

### Entropy Encoding
A lossless encoding scheme (e.g., Huffman coding) applied after quantization to further compress the model file. Provides an additional ~10% size reduction. [S1]

## Operating characteristics
*   **Time Complexity:** Clustering time depends on the number of parameters and MLPs. K-means is iterative but efficient for the parameter sizes involved. Fine-tuning adds training overhead.
*   **Memory Complexity:** Significantly reduced compared to local quantization. Instead of storing $N \times 2^\beta$ parameters for $N$ MLPs, only $2^\beta$ shared parameters are stored, plus $\beta$-bit indices for each parameter.
*   **Measured Performance:** On the asteroids dataset, ECNR (with global quantization) achieved a PSNR of 40.59 dB with a model size of 0.49 MB, compared to ECNR* (local quantization) with 40.24 dB PSNR and 0.93 MB size [S1]. On supernova-1, ECNR achieved 48.55 dB PSNR with 1.5 MB, same size as ECNR* (44.86 dB) [S1].
*   **Strengths:** Higher compression ratios than local quantization; effective when blocks share content; simple to implement using standard k-means.
*   **Limitations:** Performance may degrade if blocks are dissimilar; requires fine-tuning to recover accuracy.

## Background
Global quantization was introduced in the ECNR (Efficient Compressive Neural Representation) framework for time-varying volumetric datasets [S1]. It builds on prior work in network quantization [24] but extends it to multiple independent small MLPs, a scenario not thoroughly investigated previously [S1]. The method was developed to address the redundancy in neural representations of volumetric data where disjoint blocks often share similar content [S1].
