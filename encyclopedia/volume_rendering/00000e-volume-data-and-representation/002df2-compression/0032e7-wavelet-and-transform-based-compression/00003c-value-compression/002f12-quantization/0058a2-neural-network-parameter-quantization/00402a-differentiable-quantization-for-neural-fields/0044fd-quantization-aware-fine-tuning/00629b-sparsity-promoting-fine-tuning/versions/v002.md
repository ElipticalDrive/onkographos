# Sparsity-promoting Fine-tuning

Also called: Fine-tuning with sparsity loss

## Overview
Sparsity-promoting fine-tuning is a post-training optimization stage applied to 3D Gaussian Splatting (3DGS) models before transform coding to improve energy compaction in the transform domain and enhance rate-distortion performance [S1]. It distinguishes itself from standard quantization-aware fine-tuning by explicitly penalizing large-magnitude transform coefficients, thereby guiding the model toward spatially coherent representations that compress more efficiently without sacrificing visual quality [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A pre-trained 3DGS model containing Gaussian positions, covariances, and appearance attributes [S1].
*   **Output:** A refined set of appearance attributes optimized for compression, while Gaussian positions remain fixed [S1].

**Data Structures**
The method operates on the appearance attributes of the Gaussians. Specifically, it tracks:
*   $n_{ch}$: The number of attributes per Gaussian (channels) [S1].
*   $n_{ac}$: The number of AC (Alternating Current) coefficients resulting from the Reconstruction Adaptive Hierarchical Transform (RAHT) applied to the attributes [S1].
*   $x_{ij}$: The $j$-th transform coefficient of the $i$-th channel [S1].

**Numbered Steps**
1.  **Freeze Geometry:** Fix the positions and covariances of all Gaussians; disable densification and pruning operations [S1].
2.  **Optimize Appearance:** Enable gradient updates exclusively for appearance attributes (e.g., spherical harmonics coefficients, opacity, scaling) [S1].
3.  **Compute Losses:** Calculate the distortion loss $L_D$ using L1 and SSIM metrics, and calculate the sparsity loss $L_S$ based on the RAHT coefficients of the current attributes [S1].
4.  **Update with Quantization:** Include quantization in the forward pass using a straight-through estimator to approximate gradients through the non-differentiable quantization step [S1].
5.  **Iterate:** Repeat the optimization for a fixed number of iterations (e.g., 2k or 5k steps) [S1].

**Formulas**
The distortion loss $L_D$ is defined as [S1]:
$$ L_D = (1 - \lambda_{SSIM})L_1 + \lambda_{SSIM}L_{SSIM} $$
where $L_1$ is the L1 loss, $L_{SSIM}$ is the SSIM loss, and $\lambda_{SSIM}$ is a hyperparameter [S1].

The sparsity loss $L_S$ is defined as [S1]:
$$ L_S = \frac{1}{n_{ch}} \sum_{i=1}^{n_{ch}} \sum_{j=1}^{n_{ac}} |x_{ij}| $$
where $n_{ch}$ is the number of attributes per Gaussian, $n_{ac}$ is the number of AC coefficients after applying RAHT, and $x_{ij}$ denotes the $j$-th transform coefficient of the $i$-th channel [S1]. This formulation corresponds to the average $\ell_1$ norm per channel, encouraging sparsity by pushing many coefficients toward zero [S1].

The total loss function $L$ is a linear combination of $L_D$ and $L_S$ [S1]:
$$ L = (1 - \lambda_S)L_D + \lambda_S L_S $$
where $\lambda_S$ is a hyperparameter controlling the relative importance of sparsity [S1].

**Parameters**
*   $\lambda_{SSIM}$: Fixed at 0.2 [S1].
*   $\lambda_S$: Set to $5 \cdot 10^{-7}$ [S1].

**Pitfalls**
*   **Skipping Fine-tuning:** Omitting this stage results in notable quality degradation because the original parameters are not optimized for spatial coherence, even if pruning and RAHT provide size reduction [S1].
*   **Ignoring Sparsity Loss:** Fine-tuning without the sparsity term improves rendering quality via quantization-aware training but fails to reduce bitstream size, limiting compression benefits [S1].

**Pseudocode**
```python
def sparsity_promoting_finetuning(gaussians, training_views, num_iterations, lambda_ssim, lambda_s):
    # Step 1: Freeze geometry and disable densification
    gaussians.positions.requires_grad = False
    gaussians.covariances.requires_grad = False
    
    # Step 2: Enable gradients only for appearance attributes
    for attr in gaussians.appearance_attributes:
        attr.requires_grad = True

    optimizer = GradientDescentOptimizer(gaussians.appearance_attributes)

    for step in range(num_iterations):
        optimizer.zero_grad()
        batch_loss = 0.0

        for view in training_views:
            # Straight-through quantization: quantize for forward pass, keep raw for backward
            quantized_attrs = straight_through_quantize(gaussians.appearance_attributes)

            # Standard volume rendering pass
            rendered_image = render(gaussians, view, quantized_attrs)
            target_image = view.target

            # Distortion loss components
            l1_loss = sum(abs(rendered_image - target_image)) / len(rendered_image)
            ssim_loss = 1.0 - structural_similarity(rendered_image, target_image)
            l_d = (1 - lambda_ssim) * l1_loss + lambda_ssim * ssim_loss

            # Sparsity loss on RAHT coefficients
            raht_coeffs = apply_raht(gaussians.appearance_attributes)
            n_ch = raht_coeffs.shape[0]
            n_ac = raht_coeffs.shape[1]
            l_s = sum(abs(raht_coeffs)) / (n_ch * n_ac)

            batch_loss += (1 - lambda_s) * l_d + lambda_s * l_s

        batch_loss.backward()
        optimizer.step()

def straight_through_quantize(attrs):
    # Quantize for forward pass, but pass raw gradients backward
    quantized = round_to_grid(attrs)
    return quantized

def apply_raht(attrs):
    # Apply Reconstruction Adaptive Hierarchical Transform to attributes
    return raht_transform(attrs)

def render(gaussians, view, attrs):
    # Standard differentiable volume rendering of Gaussians
    return volume_render(gaussians, view, attrs)

def structural_similarity(img1, img2):
    # Standard SSIM computation
    return compute_ssim(img1, img2)
```

## Subtopics

### JointRF Training Procedure
A sibling method that jointly optimizes rendering and compression parameters. It differs by focusing on joint parameter optimization rather than explicit sparsity-promoting loss in the transform domain. Choose it when joint optimization of rendering and compression is preferred over sequential fine-tuning. [JointRF Training Procedure](11657-jointrf-training-procedure.md)

## Operating characteristics
*   **Time Complexity:** The computational overhead is negligible because RAHT is already part of the training loop for quantization-aware fine-tuning [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** Improves rate-distortion performance by concentrating energy into fewer transform coefficients, allowing for better compression efficiency [S1].
*   **Strengths:** Provides flexible control over the rate-distortion trade-off via $\lambda_S$ tuning [S1].
*   **Limitations:** Requires additional training iterations (e.g., 2k-5k steps) [S1].

## Background
Sparsity-promoting fine-tuning was introduced in the context of improving RAHT-based compression of 3D Gaussian Splats [S1]. It addresses the limitation that optimizing for visual quality alone often results in models with highly diverse attributes among spatially close Gaussians, which limits spatial redundancy exploitation [S1]. The method builds on the principles of quantization-aware training and straight-through estimation [S1].
