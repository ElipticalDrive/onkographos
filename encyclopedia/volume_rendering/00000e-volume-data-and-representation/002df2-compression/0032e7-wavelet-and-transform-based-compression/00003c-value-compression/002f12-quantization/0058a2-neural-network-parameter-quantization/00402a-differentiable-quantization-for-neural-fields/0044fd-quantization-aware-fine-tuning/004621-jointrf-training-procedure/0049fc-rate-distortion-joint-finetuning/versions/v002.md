# Rate-Distortion Joint Finetuning


## Overview
Rate-Distortion Joint Finetuning is a training approach that treats compression and 3D-scene representation as a single optimization problem, training the NeRF model for bitrate and distortion simultaneously [S1]. Unlike techniques that treat compression and 3D-scene representation as two independent optimization problems, which reduces compression performance and limits effectiveness across a wider bitrate range, this method jointly optimizes the model parameters to achieve an optimal Rate-Distortion curve by adjusting a single trade-off factor [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A pre-trained NeRF model (or feature grid), a reference graph $G$ defining spatial dependencies, and a quantization step $Q_{step}$ [S1].
*   **Output:** A finetuned NeRF model optimized for a specific bitrate-distortion trade-off defined by $\lambda$ [S1].

**Data Structures:**
*   **Feature Grid:** A 3D grid of feature vectors $v$ [S1].
*   **Reference Graph $G$:** A set of edges $(v_i, v_j)$ where $v_j$ is a reference candidate for $v_i$ [S1]. The implementation uses preceding voxels (previously reconstructed in the decoding process) as references [S1]. For training convenience, only complete voxels are used as prediction values, avoiding interpolation at non-integer positions [S1].
*   **Critical Voxels Set $C$:** A subset of voxels identified as critical for rendering quality, used in the two-step variant [S1].

**Numbered Steps:**

1.  **Quantization with Noise Injection:**
    During training, the feature vector $x$ is quantized using a uniform quantizer [S1]. To handle the zero-gradient problem of standard quantization, the quantization error is substituted with uniform noise for backpropagation [S1]. The quantized feature $\tilde{x}$ is computed as:
    $$ \tilde{x} = \hat{x} + U\left(-\frac{1}{2Q_{step}}, \frac{1}{2Q_{step}}\right) $$
    where $\hat{x}$ is the quantized feature, $Q_{step}$ is the quantization step, and $U$ denotes the uniform distribution [S1].

2.  **Entropy Modeling and Bitrate Estimation:**
    The method assumes the prediction residuals $y = \hat{x} - \hat{x}_{ref}$ follow an exponential distribution $EXP(\epsilon)$ [S1]. The bitrate $R$ is estimated as the entropy of these residuals [S1]. The theoretical bitrate is given by:
    $$ R = E_{y \sim EXP(\epsilon)}[-\log(p(y))] = \kappa E(|y|) + \beta $$
    where $\kappa$ and $\beta$ are constant terms related to the exponential distribution parameters [S1].
    
    Assuming the quantization error conforms to a uniform distribution, the expected absolute residual is approximated as:
    $$ E|y| = E|\hat{x} - \hat{x}_{ref}| \approx E|\tilde{x} - \tilde{x}_{ref}| = \frac{E|x - x_{ref}|}{Q_{step}} $$
    [S1].
    
    Since constant terms ($\beta$) and the factor $\kappa/Q_{step}$ (which can be absorbed into the hyperparameter $\lambda$) do not affect the optimization direction, the practical bitrate loss term $R$ is simplified to the mean absolute difference over the reference graph edges [S1]:
    $$ R = \frac{1}{|G|} \sum_{(v_i, v_j) \in G} \|v_i - v_j\|_1 $$
    where $|G|$ is the number of edges in the reference graph $G$, and $v$ denotes the feature voxel [S1].

3.  **Loss Calculation:**
    The total loss function combines the bitrate estimate and the rendering distortion loss $D$ (from the original NeRF method) using a Lagrangian multiplier $\lambda$ [S1]:
    $$ \text{Loss} = \lambda \times R + D $$
    where $\lambda$ is a hyperparameter balancing bitrate and distortion [S1].

4.  **Optimization:**
    The model parameters are updated by minimizing the total loss [S1]. An optimal RD curve is obtained by adjusting $\lambda$ [S1].

**Parameters:**
*   $\lambda$: Lagrangian multiplier. Typical values are not specified in the sources, but it is adjusted to traverse the RD curve [S1].
*   $Q_{step}$: Quantization step. In experiments, a value of 0.5 was used for the synthetic lego scene [S1].

**Edge Cases and Pitfalls:**
*   **Large Quantization Steps:** Large $Q_{step}$ values lead to unacceptable performance loss even with noise compensation, while finer quantization increases bit cost [S1].
*   **Gradient Vanishing:** Standard quantization has zero gradients almost everywhere; the noise substitution method is required to enable backpropagation [S1].
*   **Reference Selection:** The method uses Sum of Absolute Differences (SAD) to choose the optimal reference voxel from available neighbors (preceding voxels) [S1].

**Pseudocode:**

```python
def rate_distortion_joint_finetuning(nerf_params, feature_grid, reference_graph, lambda_param, q_step, distortion_loss_fn, lr, num_epochs):
    """
    Performs joint rate-distortion finetuning.
    
    Args:
        nerf_params: NeRF model parameters.
        feature_grid: 3D grid of feature vectors.
        reference_graph: List of tuples (i, j) indexing feature_grid for edges in G.
        lambda_param: Hyperparameter lambda for balancing rate and distortion.
        q_step: Quantization step size.
        distortion_loss_fn: Function to compute rendering distortion loss D.
        lr: Learning rate for parameter updates.
        num_epochs: Number of training iterations.
        
    Returns:
        Finetuned nerf_params.
    """
    import math
    import random
    
    # Helper: Quantize to nearest multiple of q_step
    def quantize(x):
        return q_step * math.floor(x / q_step + 0.5)
        
    # Helper: Sample uniform noise in [-1/(2*q_step), 1/(2*q_step)]
    def sample_uniform_noise(size):
        low = -1.0 / (2.0 * q_step)
        high = 1.0 / (2.0 * q_step)
        return [low + random.random() * (high - low) for _ in range(size)]
        
    # Helper: SGD parameter update
    def sgd_step(params, grads, learning_rate):
        for p, g in zip(params, grads):
            p -= learning_rate * g
            
    for epoch in range(num_epochs):
        # 1. Forward pass to get raw features
        raw_features = nerf_params.forward()
        
        # 2. Quantization with uniform noise injection
        quantized_features = [quantize(x) for x in raw_features]
        noise = sample_uniform_noise(len(raw_features))
        quantized_features_noisy = [q + n for q, n in zip(quantized_features, noise)]
        
        # 3. Compute Bitrate Loss R
        # R = (1/|G|) * sum(||vi - vj||_1) for all (vi, vj) in G
        rate_loss_sum = 0.0
        edge_count = 0
        for i, j in reference_graph:
            diff = abs(quantized_features_noisy[i] - quantized_features_noisy[j])
            rate_loss_sum += diff
            edge_count += 1
            
        rate_loss = rate_loss_sum / edge_count if edge_count > 0 else 0.0
        
        # 4. Compute Distortion Loss D
        distortion_loss = distortion_loss_fn(nerf_params, quantized_features_noisy)
        
        # 5. Compute Total Loss
        total_loss = lambda_param * rate_loss + distortion_loss
        
        # 6. Backpropagation and Update
        grads = total_loss.backward() # Standard autograd operation
        sgd_step(nerf_params, grads, lr)
        
    return nerf_params
```

## Subtopics

### Two-step Finetuning Procedure
A procedure to handle large quantization steps by performing precise quantization only for critical voxels, combining hierarchical quantization with finetuning to maximize bit saving without excessive rendering degradation [S1]. It involves a post-finetuning stage where a coarse feature grid is reconstructed after quantization and dequantization [S1]. All non-critical voxels in the feature grid are frozen, and only the remaining parameters (critical voxels) are finetuned [S1]. Non-pruned volume density and RGB networks are included to compensate for quantization loss [S1]. The bitrate for this stage is modeled as the residual bits for critical voxels: $R = \frac{1}{|C|} \sum_{v_i \in C} \|v_i - \hat{v}_i\|_1$, where $C$ is the set of all critical voxels and $\hat{v}$ denotes the feature voxel in the coarse grid [S1].

## Background
The method originates from SPC-NeRF (Spatial Predictive Compression for Voxel-Based Radiance Field) [S1]. It addresses the limitation of previous NeRF compression techniques that treated compression and 3D-scene representation as two independent optimization problems [S1]. The approach leverages predictive coding paradigms and entropy modeling based on exponential distributions of prediction residuals [S1].
