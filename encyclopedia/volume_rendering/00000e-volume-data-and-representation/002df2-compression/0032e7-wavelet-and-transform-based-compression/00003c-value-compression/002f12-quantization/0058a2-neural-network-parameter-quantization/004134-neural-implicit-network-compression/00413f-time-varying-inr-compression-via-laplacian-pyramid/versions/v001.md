# Time-varying INR compression via Laplacian pyramid

Also called: Laplacian Pyramid INR, Tang and Wang, Tang and Wang Laplacian Pyramid INR

## Overview
This method compresses time-varying volumetric datasets by decomposing the data into a Laplacian pyramid and fitting a separate Multi-Layer Perceptron (MLP) to each block in the pyramid [S1, unofficial]. It is designed to improve decoding speed compared to centralized INR approaches like [Neural Implicit Network Compression](10414-neural-implicit-network-compression.md), which typically suffer from high computational costs during inference [S1, unofficial]. By partitioning the problem into smaller, independent blocks, the method enables parallel decoding, achieving significant speedups on large-scale scientific data [S1, unofficial].

## How it works
**Inputs:** A time-varying volumetric dataset $V$ with spatial dimensions up to $1,728^3$ and a temporal dimension $T$ [S1, unofficial].
**Outputs:** A set of trained MLPs representing the Laplacian pyramid coefficients for each spatial block and time step.

**Data Structures:**
1.  **Laplacian Pyramid:** The volume is decomposed into a set of residual bands. Let $L_k$ denote the $k$-th level of the pyramid. The original volume is reconstructed by summing the pyramid levels [S1, unofficial].
2.  **Block Partitioning:** The spatial domain is divided into disjoint blocks. Each block is associated with a specific MLP [S1, unofficial].
3.  **MLP:** A coordinate-based neural network (typically a SIREN or similar architecture, though specific architecture details beyond "per-block MLPs" are not explicitly detailed in the provided source text) takes spatial coordinates $(x, y, z)$ and time $t$ as input and outputs the value for that block at that time [S1, unofficial].

**Steps:**
1.  **Decomposition:** Apply a Laplacian pyramid decomposition to the time-varying volume. This involves iteratively smoothing the volume and subtracting the smoothed version from the original to create residual bands [S1, unofficial].
2.  **Partitioning:** Divide the spatial domain of each pyramid level into disjoint blocks [S1, unofficial].
3.  **Training:** For each block in each pyramid level, train a dedicated MLP to map spatial coordinates and time to the residual values in that block [S1, unofficial].
4.  **Storage:** Store the weights of all trained MLPs. The compressed representation consists of the union of these weights [S1, unofficial].
5.  **Reconstruction:** To decode a point $(x, y, z, t)$, identify which block it belongs to in each pyramid level, query the corresponding MLP for the residual value, and sum the results across all levels to recover the original value [S1, unofficial].

*   **Scale:** Validated on datasets up to $1,728^3$ [S1, unofficial].
*   **Strengths:** Significant improvement in decoding speed for large-scale time-varying volumes [S1, unofficial].

This method was proposed by Tang and Wang [141] as an approach to time-varying INR compression [S1, unofficial]. It addresses the scalability issues of centralized INR methods by leveraging decomposition and partitioning techniques [S1, unofficial].
