# Global Quantization

Also called: Global shared parameter table quantization

## Overview
Global quantization is a compression strategy for neural volume representations that maintains a single shared parameter table for all independent small Multi-Layer Perceptrons (MLPs) within a specific scale, rather than quantizing each network individually [S1]. It addresses the redundancy in neural implicit representations where different spatial blocks often contain similar content, allowing distinct MLPs to share the same quantized parameters [S1]. This approach significantly reduces model size compared to local quantization methods while maintaining reconstruction accuracy [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of independent small MLPs encoding disjoint volumetric blocks at a specific scale; the weight quantization precision $\beta$ (in bits).
*   **Output:** A single global shared parameter table of floating-point values and a set of $\beta$-bit indices mapping each MLP's weights and biases to these shared parameters.

**Data Structures:**
1.  **Global Shared Parameter Table:** A list of $2^\beta$ floating-point values. These values represent the centroids of the quantized weight/bias clusters.
2.  **Index Map:** For each MLP and each layer, a tensor of $\beta$-bit integers. Each integer corresponds to an index into the Global Shared Parameter Table.

**Algorithm Steps:**
1.  **Global Clustering:** For a specific layer across all MLPs in the scale, collect all unpruned weights (and biases, if included). Apply standard $k$-means clustering to group these values into $2^\beta$ clusters [S1]. The number of clusters is determined by the precision $\beta$, where $2^\beta$ is the number of unique shared parameters [S1].
2.  **Index Assignment:** Replace every weight and bias in every MLP's layer with a $\beta$-bit index pointing to the corresponding cluster centroid in the global table [S1].
3.  **Fine-Tuning:** Fix the $\beta$-bit indices (do not update them during backpropagation). Fine-tune only the values in the Global Shared Parameter Table using backpropagation to minimize reconstruction error (e.g., MSE or PSNR degradation) [S1]. This step allows the shared parameters to adapt to the collective needs of all MLPs [S1].
4.  **Entropy Encoding (Optional Post-Processing):** Apply Huffman coding to the resulting model file (indices and shared parameters) to achieve an additional ~10% size reduction [S1].

**Formulas:**
*   Let $W$ be the set of all unpruned weights and biases in a layer across all MLPs.
*   Let $k = 2^\beta$.
*   $k$-means minimizes:
    $$ \sum_{i=1}^{k} \sum_{w \in C_i} \| w - c_i \|^2 $$
    where $C_i$ is the set of weights assigned to cluster $i$, and $c_i$ is the centroid (shared parameter) for cluster $i$.
*   The quantized weight $w'$ for any original weight $w$ is:
    $$ w' = c_{\text{index}(w)} $$
    where $\text{index}(w)$ is the $\beta$-bit index assigned during clustering.

**Parameters:**
*   $\beta$: Number of bits for local quantization. Determines the size of the shared parameter table ($2^\beta$). Typical value: 7 [S1].

**Edge Cases and Pitfalls:**
*   **Precision Selection:** If $\beta$ is too small, the quantization error may degrade rendering fidelity significantly. If $\beta$ is too large, the compression benefit diminishes [S1].
*   **Index Fixing:** The indices must be fixed during the fine-tuning phase. Updating indices would require discrete optimization, which is not standard in this method [S1].
*   **Bias Quantization:** Quantizing biases in addition to weights increases compression ratio but requires careful handling during fine-tuning to avoid instability [S1].

import numpy as np
from sklearn.cluster import KMeans

def global_quantization(mlp_layers, beta):
    """
    Applies global quantization to a list of MLP layers.
    
    Args:
        mlp_layers: List of lists, where each inner list contains the weights 
                    and biases for one MLP. Structure: [MLP1_Layer1_W, MLP1_Layer1_B, ...]
        beta: Quantization precision in bits.
        
    Returns:
        shared_params: Array of shape (2**beta,) containing the shared floating-point values.
        indices: List of arrays, one per MLP, containing the beta-bit indices.
    """
    num_clusters = 2 ** beta
    
    # Step 1: Collect all weights and biases from all MLPs for a specific layer
    # Assuming we process layer by layer. Here we assume mlp_layers is already 
    # filtered for the specific layer index being processed.
    all_weights = []
    for mlp in mlp_layers:
        # Flatten weights and biases for clustering
        w = mlp['weights'].flatten()
        b = mlp['biases'].flatten()
        all_weights.extend(w)
        all_weights.extend(b)
        
    all_weights = np.array(all_weights)
    
    # Step 2: Apply k-means clustering
    kmeans = KMeans(n_clusters=num_clusters, random_state=42, n_init=10)
    kmeans.fit(all_weights.reshape(-1, 1))
    
    # Get the cluster centers (shared parameters)
    shared_params = kmeans.cluster_centers_.flatten()
    
    # Get the labels (indices) for each weight/bias
    labels = kmeans.labels_
    
    # Step 3: Map indices back to individual MLPs
    indices_per_mlp = []
    current_idx = 0
    for mlp in mlp_layers:
        w_count = mlp['weights'].size
        b_count = mlp['biases'].size
        total_count = w_count + b_count
        
        # Extract indices for this MLP's weights and biases
        mlp_labels = labels[current_idx : current_idx + total_count]
        
        # Reshape to match original tensor shapes
        w_indices = mlp_labels[:w_count].reshape(mlp['weights'].shape)
        b_indices = mlp_labels[w_count:].reshape(mlp['biases'].shape)
        
        indices_per_mlp.append({
            'weights': w_indices,
            'biases': b_indices
        })
        
        current_idx += total_count
        
    return shared_params, indices_per_mlp

## Operating characteristics
*   **Time Complexity:** The clustering step is $O(N \cdot k \cdot d \cdot i)$, where $N$ is the total number of weights/biases, $k=2^\beta$, $d$ is the dimensionality (1 for scalar weights), and $i$ is the number of k-means iterations. Fine-tuning is standard backpropagation complexity.
*   **Memory Complexity:** The model size is reduced to $O(M \cdot \beta + 2^\beta)$, where $M$ is the total number of weights/biases across all MLPs. The shared parameters take $O(2^\beta)$ space, and the indices take $O(M \cdot \beta)$ space.
*   **Measured Performance:** On the asteroids dataset, ECNR (with global quantization) achieved a PSNR of 40.59 dB with a model size of 0.49 MB, compared to 40.24 dB and 0.93 MB for local quantization (ECNR*) [S1]. On supernova-1, ECNR achieved 48.55 dB PSNR with 1.5 MB, while ECNR* achieved 44.86 dB with 1.5 MB [S1].
*   **Strengths:** Significant model size reduction (up to 1.9x smaller than local quantization for similar PSNR) [S1]. Effective for time-varying volumetric datasets with multiple MLPs [S1].
*   **Limitations:** Requires fine-tuning after quantization, which adds computational cost. Performance depends on the similarity of content across blocks; if blocks are very different, sharing parameters may degrade accuracy [S1].
*   **When to Use:** When compressing neural representations composed of multiple independent MLPs (e.g., block-based encoding) and memory bandwidth or storage is a constraint.
*   **When Not to Use:** When the content across blocks is highly diverse and sharing parameters would lead to significant reconstruction errors. When real-time training is not feasible due to the fine-tuning step.

## Background
Global quantization was introduced in the context of Efficient Compressive Neural Representation (ECNR) for time-varying volumetric datasets [S1]. It builds on prior work in neural network quantization  but extends it to multiple independent small MLPs, a scenario not thoroughly investigated in prior literature [S1]. The method leverages the structure of ECNR, which decomposes volumetric data into disjoint blocks encoded by separate MLPs [S1]. By recognizing that different blocks often contain similar content, the authors proposed sharing quantized parameters globally across all MLPs within a scale [S1]. This approach was shown to outperform standard pruning and local quantization in terms of model size and reconstruction accuracy [S1].
