# Global Quantization

Also called: Global shared parameter table quantization

## Overview
Global Quantization is a post-training compression strategy for neural fields that replaces local, per-network weight quantization with a single shared parameter table across all Multi-Layer Perceptrons (MLPs) within a specific spatial scale [S1]. It solves the redundancy problem where independent MLPs encoding distinct volumetric blocks often represent similar content with different, non-shared weights [S1]. Unlike sibling methods that quantize each MLP individually, Global Quantization clusters weights across the entire scale, allowing multiple networks to reference the same floating-point parameters, thereby significantly reducing model size without increasing reconstruction error [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A set of trained, unpruned MLPs $\{M_1, M_2, \dots, M_N\}$ belonging to a single spatial scale, where each MLP $M_i$ contains weight matrices $W$ and bias vectors $b$.
*   **Output:** A global shared parameter table containing $2^\beta$ floating-point values per layer, and a set of $\beta$-bit indices mapping each MLP's original weights to these shared values.

**Data Structures**
1.  **Global Shared Parameter Table:** A list of floating-point values. For a layer with precision $\beta$, the table size is $2^\beta$.
2.  **Index Map:** For each MLP $M_i$ and each layer $l$, a tensor of indices with the same shape as the original weights/biases, where each element is an integer in $[0, 2^\beta - 1]$.

**Parameters**
*   $\beta$: The quantization precision in bits. It determines the number of clusters $K = 2^\beta$.
    *   Typical value: $\beta = 7$ [S1].

**Algorithm Steps**
1.  **Global Clustering:** For each layer $l$ across all MLPs in the scale:
    *   Collect all unpruned weights (and biases, if included) from all MLPs $M_1 \dots M_N$ into a single large vector or matrix $V_{global}$.
    *   Apply standard k-means clustering to $V_{global}$ with $K = 2^\beta$ clusters [S1].
    *   Let the cluster centroids be $C_l = \{c_1, c_2, \dots, c_{2^\beta}\}$, where each $c_j \in \mathbb{R}$. These form the Global Shared Parameter Table for layer $l$.
2.  **Index Assignment:**
    *   For each original weight $w$ in each MLP $M_i$'s layer $l$, find the index $idx$ of the closest centroid in $C_l$.
    *   Store $idx$ in the Index Map for $M_i, l$.
    *   The quantized weight is reconstructed as $w' = c_{idx}$.
3.  **Fine-Tuning:**
    *   Fix the indices in the Index Maps (they are no longer trainable) [S1].
    *   Optimize only the values in the Global Shared Parameter Table $C_l$ using backpropagation to minimize the reconstruction loss (e.g., MSE between rendered images and ground truth) [S1].
    *   This step corrects quantization errors and adapts the shared parameters to the global distribution [S1].

**Pseudocode**
```python
def global_quantization(mlps, beta, learning_rate, epochs):
    """
    mlps: List of MLP objects, each having layers with weights W and biases b.
    beta: Quantization precision in bits.
    """
    K = 2 ** beta
    
    # Step 1: Collect all weights and biases for a specific layer across all MLPs
    # Assume we process layer by layer. For layer l:
    all_weights = []
    all_biases = []
    
    for mlp in mlps:
        layer = mlp.layers[l]
        # Flatten weights and biases for clustering
        all_weights.extend(layer.W.flatten())
        all_biases.extend(layer.b.flatten())
        
    # Step 2: K-means clustering on the combined data
    # Note: In practice, weights and biases might be clustered separately or together.
    # The source implies clustering "weights" generally, but explicitly mentions quantizing biases too.
    # We assume separate clustering for W and b for clarity, or combined if specified.
    # Here we cluster W and b separately to maintain structure, then map.
    
    centroids_W = kmeans(all_weights, K) # Returns array of size K
    centroids_b = kmeans(all_biases, K)
    
    # Step 3: Create Index Maps and Shared Tables
    shared_params_W = centroids_W.copy() # These will be fine-tuned
    shared_params_b = centroids_b.copy()
    
    index_maps_W = []
    index_maps_b = []
    
    for mlp in mlps:
        layer = mlp.layers[l]
        
        # Map original weights to indices
        # Find closest centroid for each weight
        indices_W = find_closest_indices(layer.W.flatten(), centroids_W)
        indices_W = indices_W.reshape(layer.W.shape)
        index_maps_W.append(indices_W)
        
        # Map original biases to indices
        indices_b = find_closest_indices(layer.b.flatten(), centroids_b)
        indices_b = indices_b.reshape(layer.b.shape)
        index_maps_b.append(indices_b)
        
    # Step 4: Fine-tuning
    # The index maps are fixed. We optimize shared_params_W and shared_params_b.
    # This requires a differentiable rendering pipeline or loss function L.
    
    for epoch in range(epochs):
        loss = 0
        for mlp_idx, mlp in enumerate(mlps):
            # Reconstruct weights from shared params and indices
            reconstructed_W = shared_params_W[index_maps_W[mlp_idx]]
            reconstructed_b = shared_params_b[index_maps_b[mlp_idx]]
            
            # Update MLP layer with reconstructed params
            mlp.layers[l].W = reconstructed_W
            mlp.layers[l].b = reconstructed_b
            
            # Compute loss (e.g., rendering loss)
            current_loss = compute_rendering_loss(mlp)
            loss += current_loss
            
        # Backpropagate to update shared_params_W and shared_params_b
        gradients_W = compute_gradients(loss, shared_params_W)
        gradients_b = compute_gradients(loss, shared_params_b)
        
        shared_params_W -= learning_rate * gradients_W
        shared_params_b -= learning_rate * gradients_b
        
    return shared_params_W, shared_params_b, index_maps_W, index_maps_b
```

**Edge Cases and Pitfalls**
*   **Precision:** If $\beta$ is too small, the number of clusters $2^\beta$ may be insufficient to capture the weight distribution, leading to high quantization error. The source notes $\beta=7$ as typical for small MLPs [S1].
*   **Boundary Artifacts:** While Global Quantization compresses parameters, it does not inherently solve boundary artifacts between disjoint volumetric blocks. This requires separate mitigation strategies (e.g., boundary artifact mitigation techniques mentioned in the source) [S1].
*   **Clustering Stability:** K-means initialization can affect results. Standard k-means is used, but convergence to a local minimum is possible [S1].

## Operating characteristics
*   **Compression Ratio:** Significantly higher than local quantization. In experiments, ECNR (with global quantization) achieved a model size of 0.49 MB vs 0.93 MB for ECNR* (local quantization) on the asteroids dataset, and 1.5 MB vs 1.5 MB (controlled for size) on supernova-1, with better PSNR [S1].
*   **Time Complexity:** The clustering step is $O(N \cdot D \cdot K \cdot I)$, where $N$ is the number of MLPs, $D$ is the number of weights, $K$ is clusters, and $I$ is k-means iterations. Fine-tuning adds the cost of backpropagation over the shared parameters.
*   **Memory Complexity:** The storage is dominated by the shared parameter table ($2^\beta$ floats per layer) and the index maps ($\beta$ bits per weight). This is much smaller than storing full weights for each MLP.
*   **Strengths:** Leverages redundancy across multiple MLPs; improves reconstruction accuracy at the same model size compared to local quantization [S1].
*   **Limitations:** Requires all MLPs in a scale to be quantized together; fine-tuning is necessary to recover accuracy, adding training time [S1].

## Background
Global Quantization was introduced in the context of Efficient Compressive Neural Representation (ECNR) for time-varying volumetric datasets [S1]. It addresses the limitation of prior quantization approaches that focused on single neural networks, extending the concept to multiple independent small MLPs [S1]. The method builds on the observation that different blocks in a volume often contain similar content, making global sharing of parameters feasible and meaningful [S1].
