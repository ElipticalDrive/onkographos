# Learned Bitwidth Quantization (LBQ)

## Overview
Learned Bitwidth Quantization (LBQ) is a differentiable quantization framework for neural radiance fields that treats integer bitwidth as a continuous, learnable variable ("soft bitwidth") rather than a fixed hyperparameter. It solves the problem of manually selecting optimal bitwidths for different components and scenes by aligning model complexity with scene intricacy during training. Unlike sibling methods like [Differentiable Quantization for Neural Fields](10195-differentable-quantization-for-neural-fields.md) which quantize to a fixed byte size, LBQ dynamically allocates bitwidths per component based on their statistical properties and content sensitivity, reducing computational complexity without significant accuracy degradation.

## How it works
**Inputs and Outputs:**
- **Input:** A radiance field model $F$ mapping 3D location $\mathbf{x}$ and 2D view direction $\mathbf{d}$ to opacity $\sigma$ and color $\mathbf{c}$, along with training data (rays and target colors).
- **Output:** A quantized model with learned bitwidths $b_i$ for each component, where the integer bitwidth $B_i = \lfloor b_i \rceil$ determines the quantization range.

**Data Structures:**
- **Soft Bitwidth ($b$):** A floating-point scalar parameter for each component.
- **Range Scale ($r_v$):** A trainable scalar replacing the fixed step size $s$.
- **Offset ($v_{max}$):** A trainable scalar replacing the zero-point offset $Z$.
- **Quantization Range:** Defined by $v_{min}$ and $v_{max}$. For symmetric signed quantization, $v_{min} = -v_{max}$. For asymmetric unsigned, $v_{min} = 0$.

**Formulas:**
The radiance field function is:
$$ F: (\mathbf{x}, \mathbf{d}) \xrightarrow{} (\sigma, \mathbf{c}) $$
Location coordinates are encoded as $\mathbf{y}_x = \text{enc}(\mathbf{x}, \Theta)$ and view directions as $\mathbf{y}_d$ using spherical harmonics. The encoded vector $\mathbf{y} = (\mathbf{y}_x, \mathbf{y}_d)$ is fed to an MLP $m$ with weights $\Phi$:
$$ (\sigma, \mathbf{c}) = m(\mathbf{y}, \Phi) $$
The expected color $\mathbf{C}(\mathbf{r})$ along a ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ is:
$$ \mathbf{C}(\mathbf{r}) = \int_{t_n}^{t_f} T(t) \sigma(\mathbf{r}(t)) \mathbf{c}(\mathbf{r}(t), \mathbf{d}) dt, \quad T(t) = \exp\left(-\int_{t_n}^t \sigma(\mathbf{r}(s)) ds\right) $$

**Fake Quantizer:**
LBQ inserts "fake quantizers" into the forward pass to simulate quantization error. For data $\mathbf{v}$, the quantized output $\hat{\mathbf{v}}$ is:
$$ \hat{\mathbf{v}} = s(\hat{\mathbf{V}} - Z) = s \left[ \text{clamp}\left( \left\lfloor \frac{\mathbf{v}}{s} \right\rceil + Z; q_{\min}, q_{\max} \right) - Z \right] $$
where $\lfloor \cdot \rceil$ is round-to-nearest, and $\text{clamp}(x; a, c)$ limits $x$ to $[a, c]$.
The step size $s$ and zero-point $Z$ are derived from trainable parameters $r_v$ and $v_{max}$:
$$ s = \frac{r_v}{r_q}, \quad r_q = 2^B - 1, \quad B = \lfloor b \rceil $$
$$ Z = \left\lfloor q_{\max} - \frac{v_{max}}{s} \right\rceil = \left\lfloor q_{\max} - \frac{v_{max}}{r_v} r_q \right\rceil $$
For symmetric signed quantization: $q_{\min} = -2^{B-1}$, $q_{\max} = 2^{B-1}-1$, $v_{min} = -v_{max}$.
For asymmetric unsigned quantization: $q_{\min} = 0$, $q_{\max} = 2^B - 1$, $v_{min} = 0$.

**Gradients:**
The Straight-Through Estimator (STE) is used for the rounding operation: $\partial \lfloor x \rceil / \partial x = 1$.
The partial derivatives of $\hat{v}$ with respect to trainable parameters are:

| Variable Range | $\partial \hat{v} / \partial r_v$ | $\partial \hat{v} / \partial b$ | $\partial \hat{v} / \partial v_{max}$ |
| :--- | :--- | :--- | :--- |
| $v_{min} \leq v \leq v_{max}$ | $(s \cdot \lfloor v/s \rceil - v) / r_v$ | $(v - s \cdot \lfloor v/s \rceil) \cdot 2^B \ln 2 / r_q$ | $0$ |
| $v > v_{max}$ | $1 - v_{max}/r_v - Z/r_q$ | $(v_{max} - r_v + sZ) \cdot 2^B \ln 2 / r_q$ | $1$ |
| $v < v_{min}$ | $-v_{max}/r_v - Z/r_q$ | (Not given in the sources) | (Not given in the sources) |

**Algorithm Steps:**
1. **Initialization:** Initialize soft bitwidths $b$. All components are initialized to 8-bit ($b=8$) except exponential activations, which are initialized to 32-bit ($b=32$) due to their extensive range. Initialize $r_v$ and $v_{max}$ using a simple Post-Training Quantization (PTQ) method.
2. **Forward Pass:**
   a. Encode inputs $\mathbf{x}, \mathbf{d}$ to $\mathbf{y}$.
   b. Pass $\mathbf{y}$ through the MLP.
   c. Apply fake quantizers to weights and activations. For each component $i$, compute $\hat{\mathbf{v}}_i$ using its specific $b_i, r_{v,i}, v_{max,i}$.
   d. Render the image using volume rendering.
3. **Loss Calculation:** Compute the reconstruction loss $\mathcal{L}^{\text{NeRF}}_{\text{fp}}$ (e.g., MSE between rendered and target color).
4. **Backward Pass:**
   a. Compute gradients of the loss with respect to model weights and quantization parameters ($b, r_v, v_{max}$).
   b. Update $b, r_v, v_{max}$ using gradient descent.
5. **Constraint:** Constrain $b$ within $[2, 32]$. Binary quantization (1-bit) is excluded as it yields nonsensical results.

**Pseudocode:**
```python
def fake_quantize(v, b, rv, vmax, q_min, q_max):
    """
    Simulates quantization with learnable bitwidth.
    v: input tensor
    b: soft bitwidth (float)
    rv: range scale (float)
    vmax: offset (float)
    q_min, q_max: integer quantization range limits
    """
    # Calculate integer bitwidth
    B = round(b)
    
    # Calculate quantization range scale
    rq = 2**B - 1
    
    # Calculate step size and zero-point
    s = rv / rq
    Z = round(q_max - (vmax / s))
    
    # Quantize and de-quantize
    # Round to nearest
    v_rounded = round(v / s)
    
    # Add zero-point and clamp
    v_clamped = clamp(v_rounded + Z, q_min, q_max)
    
    # De-quantize
    v_hat = s * (v_clamped - Z)
    
    return v_hat

def forward_pass_with_lbq(model, x, d, quant_params):
    """
    model: Radiance field model
    x: 3D coordinates
    d: 2D view directions
    quant_params: dict mapping component names to (b, rv, vmax)
    """
    # Encode
    y_x = encode_position(x, model.theta)
    y_d = encode_direction(d) # Spherical harmonics
    y = concat(y_x, y_d)
    
    # MLP Forward with Fake Quantization
    for layer in model.mlp_layers:
        # Apply fake quantization to weights if specified
        if 'weights' in quant_params[layer.name]:
            b, rv, vmax = quant_params[layer.name]['weights']
            layer.weights = fake_quantize(layer.weights, b, rv, vmax, 
                                          q_min=-2**(b-1), q_max=2**(b-1)-1) # Symmetric signed
        
        # Linear operation
        y = layer.linear(y)
        
        # Activation
        if layer.activation == 'relu':
            y = relu(y)
            # Apply fake quantization to ReLU activations
            if 'relu_act' in quant_params[layer.name]:
                b, rv, vmax = quant_params[layer.name]['relu_act']
                y = fake_quantize(y, b, rv, vmax, q_min=0, q_max=2**b - 1) # Asymmetric unsigned
        elif layer.activation == 'exp':
            y = exp(y)
            # Apply fake quantization to exp activations
            if 'exp_act' in quant_params[layer.name]:
                b, rv, vmax = quant_params[layer.name]['exp_act']
                y = fake_quantize(y, b, rv, vmax, q_min=0, q_max=2**b - 1) # Asymmetric unsigned
                
    # Output layer
    sigma, c = model.output_layer(y)
    
    # Volume Rendering
    C = volume_render(sigma, c, x, d)
    return C

def train_lbq(model, rays, targets, quant_params, lr=0.001):
    """
    Training loop for LBQ.
    """
    optimizer = Adam([model.parameters()] + list(quant_params.values()), lr=lr)
    
    for ray, target in rays:
        # Forward pass
        pred = forward_pass_with_lbq(model, ray.origin, ray.direction, quant_params)
        
        # Loss
        loss = mse_loss(pred, target)
        
        # Backward pass
        optimizer.zero_grad()
        loss.backward()
        
        # Clip bitwidths to [2, 32]
        for name, params in quant_params.items():
            params.b = clamp(params.b, 2.0, 32.0)
            
        optimizer.step()
```

## Subtopics

### Component-Specific Quantization Schemes
LBQ applies different quantization configurations to different components based on their statistical properties to minimize error and maximize efficiency [S1].
- **Neural Weights:** Symmetric signed quantization with range $[-2^{B-1}, 2^{B-1}-1]$. Parameters $v_{max}$ and $r_v$ are not applicable (N/A) because weights are symmetric around zero. Bitwidth $b$ is trainable. This introduces no additional computational overhead during inference [S1].
- **ReLU and Exponential Activations:** Asymmetric unsigned quantization with range $[0, 2^B - 1]$. Parameters $v_{max}$ and $r_v$ are trainable. Bitwidth $b$ is trainable. Exponential activations are initialized to 32-bit due to their extensive range scale, while others are initialized to 8-bit [S1].
- **Positional Encoding (PE) and Others:** Asymmetric unsigned quantization with range $[0, 2^B - 1]$. Parameters $v_{max}$ and $r_v$ are trainable. Bitwidth $b$ is trainable. This configuration uses $v_{max}$ to handle components lacking significant statistical features [S1].

## Operating characteristics
- **Time Complexity:** Training time increases slightly due to the additional forward/backward passes for fake quantization and gradient computation for $b, r_v, v_{max}$. Inference time is reduced as lower bitwidths allow for faster integer-only operations.
- **Memory Complexity:** Memory usage is reduced proportional to the average bitwidth. The bitwidth is constrained within $[2, 32]$.
- **Measured Performance:** On Synthetic-NeRF, RTMV, and Mip-NeRF360 datasets, LBQ achieves high PSNR with significantly lower Feature Quantization Rate (FQR) compared to fixed-bitwidth methods. For example, on the "chair" scene, it achieves 28.13 PSNR with an average bitwidth of 8.13 bits, compared to 32-bit full precision [S1].
- **Strengths:** Content-aware; aligns model complexity with scene intricacy; eliminates manual bitwidth selection; supports mixed-precision per component.
- **Limitations:** Binary quantization (1-bit) yields nonsensical results and is excluded; requires careful initialization (e.g., 32-bit for exp activations).
- **When to use:** When computational efficiency is critical and scene complexity varies; when manual bitwidth tuning is impractical.
- **When not to use:** When strict fixed-bitwidth hardware constraints are required without flexibility; when 1-bit quantization is necessary.

## Background
LBQ was introduced by W. Liu, X. X. Zheng et al. in the paper "Content-Aware Radiance Fields: Aligning Model Complexity with Scene Intricacy Through Learned Bitwidth Quantization" [S1]. It builds on the limitations of existing Quantization-Aware Training (QAT) schemes like LSQ and LSQ+, which are limited to fixed-bitwidth scenarios. LBQ makes bitwidth a continuous variable $b$ with differentiable gradients, allowing it to be learned during training. It is used in the context of neural radiance fields (NeRFs), specifically evaluated on Instant-NGP [S1].
