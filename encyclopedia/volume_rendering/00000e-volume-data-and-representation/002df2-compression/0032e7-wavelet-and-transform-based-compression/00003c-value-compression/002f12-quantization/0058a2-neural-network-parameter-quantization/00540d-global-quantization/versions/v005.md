# Global Quantization

Also called: Global shared parameter table quantization

## Overview
Global Quantization is a weight compression strategy for neural volume representations that maintains a single shared parameter table across multiple independent small Multi-Layer Perceptrons (MLPs) within a single spatial scale, rather than quantizing each network individually [S1]. It solves the problem of redundant parameter storage in block-based neural volume encodings by leveraging the observation that different spatial blocks often contain similar content that can be represented by the same set of floating-point values [S1]. Unlike local quantization methods that assign unique codebooks to each MLP, this approach groups weights globally to maximize parameter sharing and compression ratio [S1].

## How it works
**Inputs and Outputs**
- **Input:** A set of $N$ independent MLPs $\{M_1, ..., M_N\}$ representing disjoint volumetric blocks at a specific scale, where each MLP contains unpruned weights and biases.
- **Output:** A single global shared parameter table (codebook) and a set of $\beta$-bit indices mapping each MLP's weights and biases to entries in this table.

**Data Structures**
- **Global Shared Parameter Table:** A list of floating-point values. The size of this table is determined by the quantization precision $\beta$. Specifically, for a layer with $2^\beta$ clusters, the table contains $2^\beta$ floating-point numbers.
- **Index Map:** For each MLP and each layer, a tensor of $\beta$-bit integers. Each integer is an index into the Global Shared Parameter Table.

**Parameters**
- $\beta$: The number of bits used for local quantization precision. This determines the number of clusters $K = 2^\beta$. Typical value: 7 [S1].

**Steps**
1. **Global Clustering:** For a specific layer across all MLPs in the scale, collect all unpruned weights (and biases, if included). Apply standard k-means clustering with $K = 2^\beta$ clusters to group these weights into $K$ clusters [S1].
2. **Parameter Assignment:** Assign each weight (and bias) to the centroid of its nearest cluster. The centroids form the Global Shared Parameter Table for that layer [S1].
3. **Index Mapping:** Replace the original floating-point weights and biases in each MLP with $\beta$-bit indices pointing to the corresponding centroid in the Global Shared Parameter Table [S1].
4. **Fine-tuning:** Fix the parameter indices (do not change cluster assignments). Fine-tune the values in the Global Shared Parameter Table using backpropagation to minimize reconstruction error (e.g., PSNR loss) while maintaining the fixed index structure [S1].

**Pseudocode**
```python
def global_quantization(mlps, beta):
    """
    mlps: List of MLP objects, each containing layers with weights and biases.
    beta: Quantization precision in bits.
    """
    num_clusters = 2 ** beta
    # Dictionary to store global shared parameters for each layer index across all MLPs
    # Structure: { layer_idx: { 'weights': [float] * num_clusters, 'biases': [float] * num_clusters } }
    global_table = {}

    # Step 1: Collect all weights and biases for a specific layer across all MLPs
    # Assuming all MLPs have the same architecture for simplicity in this global scope
    for layer_idx in range(num_layers):
        all_weights = []
        all_biases = []
        
        for mlp in mlps:
            layer = mlp.layers[layer_idx]
            # Flatten weights and biases for clustering
            all_weights.extend(layer.weights.flatten())
            all_biases.extend(layer.biases.flatten())
            
        # Step 2: Apply k-means clustering to weights
        # centroids_w is a list of num_clusters centroids
        centroids_w = kmeans(all_weights, num_clusters)
        
        # Step 2: Apply k-means clustering to biases
        centroids_b = kmeans(all_biases, num_clusters)
        
        # Store in global table
        global_table[layer_idx] = {
            'weights': centroids_w,
            'biases': centroids_b
        }

    # Step 3: Map weights and biases to indices
    for mlp in mlps:
        for layer_idx in range(num_layers):
            layer = mlp.layers[layer_idx]
            
            # Find indices for weights
            indices_w = find_cluster_indices(layer.weights.flatten(), global_table[layer_idx]['weights'])
            # Reshape indices to match original weight shape
            layer.weight_indices = indices_w.reshape(layer.weights.shape)
            
            # Find indices for biases
            indices_b = find_cluster_indices(layer.biases.flatten(), global_table[layer_idx]['biases'])
            layer.bias_indices = indices_b.reshape(layer.biases.shape)

    # Step 4: Fine-tune global parameters
    # Fix indices, optimize global_table values
    optimizer = Optimizer(global_table.values())
    for epoch in range(num_epochs):
        loss = compute_reconstruction_loss(mlps, global_table)
        loss.backward()
        optimizer.step()
        
    return global_table
```

**Edge Cases and Pitfalls**
- **Precision:** The choice of $\beta$ directly impacts the codebook size and reconstruction accuracy. A small $\beta$ may lead to high quantization error if the weight distribution is complex [S1].
- **Memory:** While global quantization reduces storage for indices, the global table itself must be stored. However, since it is shared, the total size is significantly smaller than storing separate codebooks for each MLP [S1].
- **Initialization:** K-means initialization can affect convergence. Standard k-means++ initialization is recommended to avoid poor local minima [G].

## Operating characteristics
- **Time Complexity:** The clustering step is $O(N \cdot L \cdot W \cdot \beta)$, where $N$ is the number of MLPs, $L$ is the number of layers, and $W$ is the number of weights per layer. Fine-tuning adds the cost of backpropagation over the shared parameters.
- **Memory Complexity:** The storage is dominated by the global shared parameter tables ($2^\beta$ floats per layer) and the index maps ($\beta$ bits per weight/bias). This is significantly more compact than local quantization, which requires $N \cdot 2^\beta$ floats [S1].
- **Performance:** ECNR with global quantization achieves better reconstruction accuracy than standard pruning and local quantization (ECNR*) under the same model size. For example, on the asteroids dataset, ECNR achieves 40.59 dB PSNR with 0.49 MB, while ECNR* achieves 40.24 dB PSNR with 0.93 MB [S1].
- **Strengths:** High compression ratio, effective for volumes with similar content across blocks.
- **Limitations:** Requires all MLPs to be quantized together; not suitable for highly heterogeneous blocks where shared parameters would introduce significant error.

## Background
Global Quantization was introduced in the context of ECNR (Efficient Compressive Neural Representation) for time-varying volumetric datasets [S1]. It builds on the observation that prior quantization approaches focused on single neural networks, whereas neural volume representations often use multiple independent small MLPs [S1]. By applying quantization globally across these MLPs, the method leverages the redundancy in volumetric data to achieve higher compression ratios without sacrificing reconstruction fidelity [S1].
