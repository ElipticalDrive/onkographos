# Neural Network Parameter Quantization

Also called: Neural Field Quantization, INR Compression, Global Quantization

## Overview
Neural Network Parameter Quantization applies quantization techniques to the weights and parameters of neural networks used for volumetric data representation, such as Implicit Neural Representations (INRs) and neural fields. It addresses the storage and I/O bottlenecks of high-resolution volumetric data by replacing raw grids with compact, coordinate-based models . Unlike standard post-training quantization which often degrades rendering quality, this family includes methods that integrate quantization into the training process or leverage global parameter sharing to maintain fidelity while significantly reducing memory footprint .

## Shared principles
The family shares the fundamental mechanism of mapping a continuous input space to a discrete output space. While specific implementations vary, the core operation involves a quantization function $Q(x)$ that maps a real-valued input $x$ to a discrete index or representative value, and an inverse function for reconstruction.

1.  **Discretization:** Continuous values (voxel intensities, transform coefficients, neural network weights, or color components) are mapped to a finite set of levels. This is often achieved by dividing the dynamic range into bins or by finding the nearest entry in a codebook .
2.  **Indexing/Representation:** The quantized data is represented by compact indices, bit-packed integers, or reduced-precision floating-point formats .
3.  **Error Trade-off:** Quantization is inherently lossy. The error introduced is typically measured by distortion metrics such as Mean Squared Error (MSE) or Peak Signal-to-Noise Ratio (PSNR) . The goal is to minimize this error for a given bit budget .
4.  **Integration with Compression:** Quantization is usually followed by entropy coding (e.g., Huffman, Arithmetic) or used in conjunction with predictive coding to further compress the resulting discrete data .

## Subtopics

### [Differentiable Quantization for Neural Fields](10195-differentiable-quantization-for-neural-fields.md)
Differentiable quantization reduces the memory footprint of neural field parameters (such as those in MERF) by mapping continuous grid values to single-byte integers during the optimization phase, rather than after training. This approach prevents the reconstruction quality drop associated with post-training quantization by ensuring the model is optimized for the discrete representation it will actually use at render time. It differs from standard post-training quantization by integrating the rounding operation into the gradient flow via a straight-through estimator, and from global quantization by applying per-channel or per-parameter affine scaling to handle different value distributions (e.g., densities vs. colors).

### [Neural Implicit Network Compression](10414-neural-implicit-network-compression.md)
Neural Implicit Network Compression (neurcomp) is the first method to apply Implicit Neural Representations (INRs) to compress scientific volumetric data. It solves the storage and I/O bottlenecks of traditional lossy compressors (e.g., SZ, ZFP) by replacing the raw grid with a compact coordinate-based Multi-Layer Perceptron (MLP) that maps spatial coordinates directly to field values. Unlike traditional compressors that require full decoding before visualization, neurcomp serves as simultaneously compressed storage and a queryable data source. It sets itself apart from siblings like [Differentiable Quantization for Neural Fields](10195-differentiable-quantization-for-neural-fields.md) by using post-training k-means clustering for weight quantization rather than differentiable training-time quantization, and from [Global Quantization](15134-global-quantization.md) by focusing on the specific architecture of SIRENs with residual connections for scientific fields.

### [Global Quantization](15134-global-quantization.md)
Global Quantization is a post-training compression strategy for neural fields that replaces local, per-network weight quantization with a single shared parameter table across all Multi-Layer Perceptrons (MLPs) within a specific spatial scale. It solves the redundancy problem where independent MLPs encoding distinct volumetric blocks often represent similar content with different, non-shared weights. Unlike sibling methods that quantize each MLP individually, Global Quantization clusters weights across the entire scale, allowing multiple networks to reference the same floating-point parameters, thereby significantly reducing model size without increasing reconstruction error.

## Background
The application of neural networks to volumetric data representation has grown significantly, leading to the need for efficient storage and transmission methods. Traditional lossy compressors like SZ and ZFP face I/O bottlenecks when handling large scientific volumes . Implicit Neural Representations (INRs) offer a compact alternative but require efficient parameter management. The specific methods within this family, such as neurcomp and Global Quantization, emerged to address the trade-off between model size and rendering fidelity in neural fields .
