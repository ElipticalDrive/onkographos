# Global Quantization

Also called: Global shared parameter table quantization

## Overview
Global quantization is a compression strategy for neural volumetric representations that maintains a single shared parameter table for all independent small Multi-Layer Perceptrons (MLPs) within a specific scale, rather than quantizing each network locally [S1]. It solves the redundancy problem where distinct spatial blocks often contain similar content, allowing different MLPs to map to the same quantized parameters [S1]. Unlike local quantization methods that treat each MLP in isolation, this approach leverages cross-MLP similarity to achieve higher compression ratios with minimal performance degradation [S1].

## How it works
**Inputs:**
*   A set of independent small MLPs encoding disjoint volumetric blocks within a single scale.
*   Each MLP contains unpruned weights and biases.
*   A target quantization precision $\beta$ (number of bits).

**Outputs:**
*   A global shared parameter table containing $2^\beta$ floating-point values.
*   For each MLP, a set of $\beta$-bit indices mapping its weights and biases to the global table.

**Data Structures:**
1.  **Global Shared Parameter Table:** A list of $2^\beta$ floating-point numbers.
2.  **Index Map:** For each MLP layer, a tensor of indices where each element is an integer in $[0, 2^\beta - 1]$.

**Parameters:**
*   $\beta$: The number of bits for local quantization. Typical value: 7 [S1].

**Steps:**
1.  **Global Clustering:** Apply standard k-means clustering to the unpruned weights of all MLPs within a single scale. The number of clusters is set to $2^\beta$ [S1].
2.  **Parameter Assignment:** The centroids of the $2^\beta$ clusters form the Global Shared Parameter Table [S1].
3.  **Index Mapping:** For every weight and bias in every MLP, assign the index of the closest cluster centroid from the global table. This replaces the original high-precision values with $\beta$-bit indices [S1].
4.  **Fine-Tuning:** Fix the parameter indices (do not change which centroid each weight maps to) and fine-tune the values in the Global Shared Parameter Table through backpropagation to minimize reconstruction error [S1].
5.  **Entropy Encoding (Optional):** Apply Huffman coding to the resulting model file (indices and shared parameters) for additional lossless compression [S1].

**Pseudocode:**
```python
def global_quantization(mlps, beta):
    """
    mlps: List of MLP objects. Each MLP has layers.
          Each layer has weights (W) and biases (b).
    beta: int, number of quantization bits.
    """
    num_clusters = 2 ** beta
    
    # Step 1: Collect all unpruned weights and biases from all MLPs in the scale
    all_params = []
    for mlp in mlps:
        for layer in mlp.layers:
            # Flatten weights and biases into 1D arrays
            all_params.extend(layer.weights.flatten())
            all_params.extend(layer.biases.flatten())
            
    all_params = np.array(all_params)
    
    # Step 2: Apply k-means clustering to group parameters into 2^beta clusters
    # kmeans returns cluster centers (centroids) and labels
    # Note: Standard k-means implementation required
    centroids, labels = kmeans(all_params, n_clusters=num_clusters)
    
    # Step 3: Create the global shared parameter table
    global_table = centroids
    
    # Step 4: Map original parameters to indices and reconstruct MLPs
    # We need to store the mapping back to the original structure
    # Reconstruct the flat array of labels corresponding to all_params
    # The order must match the order in which all_params was built
    
    label_idx = 0
    for mlp in mlps:
        for layer in mlps.layers:
            # Calculate number of elements in this layer's weights and biases
            n_w = layer.weights.size
            n_b = layer.biases.size
            
            # Extract labels for this layer
            layer_labels = labels[label_idx : label_idx + n_w + n_b]
            label_idx += n_w + n_b
            
            # Reshape labels to match weight and bias shapes
            w_indices = layer_labels[:n_w].reshape(layer.weights.shape)
            b_indices = layer_labels[n_w:].reshape(layer.biases.shape)
            
            # Store indices in the layer
            layer.weight_indices = w_indices
            layer.bias_indices = b_indices
            
            # Note: The actual values are now looked up from global_table
            # during inference or fine-tuning
            
    # Step 5: Fine-tune the global table
    # Fix indices, optimize global_table values

        loss = 0.0
        for mlp in mlps:
            # Forward pass using global_table and stored indices
            # Reconstruct weights/biases from indices
            reconstructed_weights = global_table[mlp.layers[0].weight_indices]
            # ... (similar for biases and subsequent layers)
            # Compute reconstruction loss
            loss += compute_loss(reconstructed_weights, original_weights)
            
        optimizer.step(loss)
        
    return global_table, mlps
```

**Edge Cases and Pitfalls:**
*   **Precision:** The choice of $\beta$ significantly impacts compression ratio and fidelity. $\beta=7$ is typical for small MLPs [S1].
*   **Boundary Artifacts:** While global quantization compresses parameters, it does not inherently solve boundary artifacts between disjoint volumetric blocks; this requires separate mitigation strategies (e.g., boundary artifact mitigation) [S1].
*   **Clustering Stability:** K-means initialization can affect results. Standard k-means++ initialization is recommended to avoid poor local minima [G].

## Subtopics

### Vector Quantization
Maps vectors to a codebook. Global quantization is a scalar variant applied to individual weight parameters across multiple networks [Siblings].

### Scalar Quantization
Maps individual scalars to discrete levels. Global quantization extends this by sharing the codebook across multiple MLPs [Siblings].

### Chroma Subsampling
Reduces color resolution. Not directly related to neural network parameter compression [Siblings].

### Differentiable Quantization for Neural Fields
Uses straight-through estimators or similar techniques for end-to-end training. Global quantization typically uses a two-stage process (quantize then fine-tune) [Siblings].

### Neural Implicit Network Compression
General category including pruning and quantization. Global quantization is a specific quantization technique within this category [Siblings].

### Unquantization Functions
Methods to recover values from quantized indices. Global quantization uses direct table lookup [Siblings].

## Operating characteristics
*   **Time Complexity:** Clustering is $O(N \cdot K \cdot I)$ where $N$ is the total number of parameters, $K=2^\beta$, and $I$ is the number of k-means iterations. Fine-tuning is comparable to standard neural network training but on a smaller parameter space (the global table).
*   **Memory Complexity:** The model size is dominated by the global table ($2^\beta$ floats) and the index maps ($N \cdot \beta$ bits). This is significantly smaller than storing full precision weights for each MLP.
*   **Measured Performance:** On the asteroids dataset, ECNR (with global quantization) achieved 40.59 dB PSNR with 0.49 MB model size, compared to ECNR* (local quantization) with 40.24 dB PSNR and 0.93 MB model size [S1]. On supernova-1, ECNR achieved 48.55 dB PSNR with 1.5 MB, while ECNR* achieved 44.86 dB PSNR with 1.5 MB [S1].
*   **Strengths:** Higher compression ratio for similar accuracy; leverages redundancy across spatial blocks; simple to implement with standard k-means.
*   **Limitations:** Requires fine-tuning after quantization; clustering cost increases with the number of parameters; not suitable for dynamic networks where the structure changes frequently.
*   **When to use:** When encoding time-varying volumetric datasets with multiple MLPs per scale and significant redundancy between blocks [S1].
*   **When not to use:** When the content across blocks is highly diverse with little similarity, or when fine-tuning time is prohibitive.

## Background
Global quantization was introduced in the context of Efficient Compressive Neural Representation (ECNR) for time-varying volumetric datasets [S1]. Prior quantization approaches focused on single neural networks [S1]. ECNR extended this by applying quantization across multiple independent small MLPs within a scale, recognizing that different blocks often contain similar content [S1]. The method builds on standard k-means clustering and entropy encoding (Huffman coding) [S1].
