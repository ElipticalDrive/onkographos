# Efficient Compressive Neural Representation (ECNR)


## Overview
ECNR is an adaptive neural representation method for compressing time-varying volumetric datasets by replacing a single global Implicit Neural Representation (INR) with multiple small local Multi-Layer Perceptrons (MLPs) [S1]. It decomposes 4D space-time data into a multiscale block structure using a Laplacian pyramid, assigns blocks to MLPs via balanced clustering, and applies deep compression techniques including block-guided pruning, global quantization, and entropy encoding [S1]. Unlike [neurcomp](52-name.md), which uses one large MLP for the entire volume, ECNR achieves significantly faster encoding and decoding speeds while maintaining high reconstruction quality, making it suitable for archiving large datasets where speed is not the primary concern [S1].

## How it works
**Inputs:** A time-varying volumetric dataset $V$ with dimensions $(x, y, z, t)$ and a target number of scales $s$.
**Outputs:** A compressed model consisting of pruned and quantized MLP parameters, latent codes, and entropy-encoded indices for each scale.

**Data Structures:**
*   **Laplacian Pyramid:** A hierarchical decomposition of $V$ into $s$ scales. Scale $s$ is the coarsest, Scale $1$ is the finest.
*   **Block:** A 3D spatial sub-volume of size $(x_b, y_b, z_b)$. The temporal dimension is handled implicitly by the 4D nature of the residual or by treating time as part of the coordinate space in the unified approach.
*   **MLP:** A small neural network with sinusoidal activation functions. Input: concatenated spatial coordinates $(x, y, z)$ and a learnable latent code $\phi$. Output: voxel value.
*   **Latent Code $\phi_i$:** A learnable vector associated with each effective block $i$.

**Algorithm Steps:**

1.  **Multiscale Decomposition:**
    *   Initialize the coarsest scale $s$. Let $V_s$ be the downsampled volume at scale $s$.
    *   For scale $i$ from $s$ down to $1$:
        *   If $i < s$, reconstruct the volume at scale $i-1$ from the previous scale's reconstruction $\hat{V}_i$ using the upsampling operator $U(\cdot)$.
        *   Compute the residual $R_{i-1} = V_{i-1} - U(\hat{V}_i)$.
        *   Split $R_{i-1}$ into 3D spatial blocks of size $(x_b, y_b, z_b)$.
        *   Identify "effective" blocks: Calculate the L2 norm of each block's residual. Discard blocks where the norm is below a threshold (representing them as empty blocks).
        *   Let $n_i$ be the number of effective blocks at scale $i$.

2.  **Block Assignment:**
    *   Determine the target number of blocks per MLP, $b_i$, for scale $i$.
    *   Calculate the number of MLPs required: $m_i = \lceil n_i / b_i \rceil$.
    *   Perform **K-means Cluster Size Uniformization** (Algorithm 1) to assign blocks to $m_i$ clusters (MLPs):
        *   Initialize clusters $S$ and centroids $C$ using standard k-means with Euclidean distance between voxel values of the blocks.
        *   Compute distance matrix $D[i][j] = ||d_i - C_j||^2$ for all blocks $i$ and clusters $j$.
        *   Compute assignment priority $\delta[i] = \max_j(D[i][j]) - \min_j(D[i][j])$.
        *   Sort blocks by $\delta$ in descending order.
        *   For each sorted block $d_i$:
            *   Find a cluster $\hat{S}$ with size $< \lfloor n_i / m_i \rfloor$. If found, assign $d_i$ to the nearest cluster in $\hat{S}$.
            *   Else, assign $d_i$ to the nearest cluster in $S$ with size $< \lceil n_i / m_i \rceil$.
    *   Initialize a latent code $\phi_k$ for each cluster $k$.

3.  **MLP Optimization:**
    *   For each scale $i$ from $s$ down to $1$:
        *   For each MLP $k$ in scale $i$:
            *   Define the loss function for the $j$ blocks assigned to MLP $k$:
                $$ L_{f_\theta} = \frac{1}{j} \sum_{p=1}^{j} ||\hat{v}_p - v_p||^2 $$
                where $\hat{v}_p = f_\theta(x_p; \phi_k)$, $x_p$ are local coordinates, and $v_p$ are target values.
            *   Train MLP $k$ in parallel with other MLPs at the same scale.
            *   Apply **Block-Guided Pruning** iteratively:
                *   Rank parameters by importance $I(p) = N(|p|) + \lambda_b N(L_b(p))$, where $N(\cdot)$ is min-max normalization, $|p|$ is absolute weight value, $L_b(p)$ is the average block loss for the MLP containing $p$, and $\lambda_b$ is a hyperparameter (typically 0.1).
                *   Prune least important parameters until target sparsity is met. Exclude weights in the last layer and biases in the first and last layers.
                *   Fine-tune with reduced learning rate.
            *   Apply **Global Quantization**:
                *   For weight precision $\beta$ bits, use k-means to group unpruned weights in a layer into $2^\beta$ clusters.
                *   Replace weights with $\beta$-bit indices mapping to shared floating-point parameters.
                *   Quantize globally across all MLPs at the same scale.
                *   Fine-tune for a fixed number of epochs (e.g., 20) after quantization.

4.  **Inference:**
    *   Decode scales from $1$ to $s$.
    *   For each scale, reconstruct blocks using their assigned MLPs and latent codes.
    *   Upsample and add residuals to reconstruct the final volume.
    *   Apply a lightweight CNN to mitigate block boundary artifacts [S1].

**Pseudocode:**

```python
def ecnr_compress(V, s, block_dim, target_sparsity, beta_bits):
    """
    V: 4D numpy array (x, y, z, t)
    s: number of scales
    block_dim: tuple (xb, yb, zb)
    target_sparsity: float, target sparsity for pruning
    beta_bits: int, bits for quantization
    """
    # 1. Multiscale Decomposition
    scales_residuals = []
    current_V = V
    
    # Downsample to coarsest scale s
    for _ in range(s - 1):
        current_V = downsample(current_V)
    
    scales_residuals.append(current_V)
    
    # Compute residuals for finer scales
    for i in range(s - 2, -1, -1):
        # Upsample previous coarse reconstruction
        upscaled = upsample(scales_residuals[-1])
        # Compute residual against original data at this scale
        # Note: V must be downsampled to match the scale resolution
        original_at_scale = downsample(V, factor=s - 1 - i)
        residual = original_at_scale - upscaled
        scales_residuals.append(residual)
    
    # Reverse to process from coarsest (index 0) to finest (index s-1)
    scales_residuals.reverse()
    
    all_mlp_params = []
    
    for scale_idx, residual in enumerate(scales_residuals):
        # 2. Block Splitting and Effective Block Identification
        blocks = split_into_blocks(residual, block_dim)
        effective_blocks = []
        for block in blocks:
            if l2_norm(block) > threshold:
                effective_blocks.append(block)
        
        n_blocks = len(effective_blocks)
        # Determine target blocks per MLP (example logic from notes)
        # For static datasets, b_i might vary by scale. For time-varying, assume constant or derived.
        # Using note: "Adjust the number of target blocks per MLP... 1, 2, 4, 8 for static"
        # For general time-varying, we assume a fixed b_i or derived from n_blocks.
        # Let's assume b_i is provided or calculated as ceil(n_blocks / desired_mlp_count)
        # For implementation, we need a target number of MLPs or blocks per MLP.
        # The notes mention: m_i = ceil(n_i / b_i). We need b_i.
        # Let's assume b_i is a hyperparameter or derived.
        # For this pseudocode, we assume b_i is passed or calculated.
        b_i = calculate_blocks_per_mlp(scale_idx, n_blocks) 
        m_i = ceil(n_blocks / b_i)
        
        # 3. Block Assignment
        clusters, centroids = kmeans_cluster_size_uniformization(effective_blocks, m_i)
        
        # Initialize latent codes
        latent_codes = [learnable_vector() for _ in range(m_i)]
        
        # 4. MLP Optimization
        mlps = []
        for k in range(m_i):
            mlp = MLP(activation='sinusoidal')
            assigned_blocks = clusters[k]
            
            # Training loop
            for epoch in range(num_epochs):
                loss = 0
                for block in assigned_blocks:
                    # Get latent code for this cluster
                    phi = latent_codes[k]
                    # Forward pass
                    pred = mlp(block.coordinates, phi)
                    loss += mse(pred, block.values)
                loss /= len(assigned_blocks)
                
                # Backpropagate
                mlp.update(loss)
                
                # Pruning (iterative)
                if epoch in pruning_epochs:
                    prune_mlp(mlp, target_sparsity, lambda_b=0.1)
                
                # Quantization (after training)
                if epoch == final_epoch:
                    quantize_mlp(mlp, beta_bits, global_quantization=True)
            
            mlps.append(mlp)
        
        all_mlp_params.append((mlps, latent_codes))
        
    return all_mlp_params

def kmeans_cluster_size_uniformization(blocks, k):
    # Standard k-means initialization
    centroids, clusters = standard_kmeans(blocks, k)
    
    # Distance matrix
    D = [[l2_norm(b - c) for c in centroids] for b in blocks]
    
    # Priority
    delta = [max(d) - min(d) for d in D]
    
    # Sort blocks by delta descending
    sorted_indices = sorted(range(len(blocks)), key=lambda i: delta[i], reverse=True)
    
    # Reassign
    new_clusters = [[] for _ in range(k)]
    cluster_sizes = [0] * k
    target_size_uniform = floor(len(blocks) / k)
    target_size_max = ceil(len(blocks) / k)
    
    for idx in sorted_indices:
        block = blocks[idx]
        distances = D[idx]
        
        # Find nearest cluster with size < target_size_uniform
        best_cluster = -1
        min_dist = infinity
        for c in range(k):
            if cluster_sizes[c] < target_size_uniform:
                if distances[c] < min_dist:
                    min_dist = distances[c]
                    best_cluster = c
        
        if best_cluster == -1:
            # Find nearest cluster with size < target_size_max
            min_dist = infinity
            for c in range(k):
                if cluster_sizes[c] < target_size_max:
                    if distances[c] < min_dist:
                        min_dist = distances[c]
                        best_cluster = c
        
        if best_cluster != -1:
            new_clusters[best_cluster].append(block)
            cluster_sizes[best_cluster] += 1
            
    return new_clusters, centroids
```

**Parameters:**
*   $s$: Number of scales. Typical value: 3 [S1].
*   $x_b, y_b, z_b$: Block dimensions. Typical values: $25 \times 15 \times 10$ for Tangaroa, $40 \times 15 \times 5$ for half-cylinder [S1].
*   $\lambda_b$: Pruning weight. Typical value: 0.1 [S1].
*   $\beta$: Quantization bits. Typical value: 9 [S1].
*   $s$ (spatial scale factor): For large spatial extent datasets. Typical value: 4 (e.g., supernova-2) [S1].

**Edge Cases and Pitfalls:**
*   **Imbalanced Assignment:** Standard k-means can lead to imbalanced block counts per MLP, hurting CR and parallel efficiency. The uniformization algorithm mitigates this [S1].
*   **Pruning Exclusions:** Weights in the last layer and biases in the first/last layers are excluded from pruning to maintain performance [S1].
*   **Timestep Independence:** ECNR does not process timesteps independently, which may limit use cases requiring per-timestep access [S1].
*   **Scale Symmetry:** Enforces the same number of scales for spatial and temporal domains, which may be suboptimal for datasets with small spatial and large temporal dimensions [S1].
*   **Content Richness:** Effectiveness drops if the dataset has consistently super-rich spatiotemporal content, as the percentage of effective blocks remains high [S1].
*   **Boundary Artifacts:** MLP decoding can produce block boundary artifacts, mitigated by a lightweight CNN [S1].

## Subtopics

### Block Assignment
A mechanism in ECNR where multiple blocks are assigned to a single MLP, contrasting with MINER which assigns exactly one block per MLP and does not optimize or store latent codes [S1]. It uses k-means cluster size uniformization to ensure balanced workload and high compression ratio [S1]. Performance vs MINER variants: With the same model size, ECNR yields the best result and MINER+ (MINER with deep compression) outperforms MINER. With the same model parameters, all three achieve similar results while ECNR gains the highest compression ratio [S1].

### ECNR⋆ (Standard Pruning and Local Quantization Baseline)
A baseline variant of ECNR that replaces block-guided pruning with standard pruning and global quantization with local quantization to evaluate the impact of the proposed compression strategies [S1]. ECNR⋆ uses standard pruning and local quantization, resulting in a model size 1.9× larger than ECNR for similar PSNR, and lower reconstruction accuracy under the same model size [S1]. Typical quantization bits $\beta$ for ECNR⋆: 7 [S1].

## Operating characteristics
*   **Time Complexity:** Encoding is slower than conventional methods (SZ3, TTHRESH) but up to 3.18× faster than neurcomp [S1]. Decoding is up to 29.57× faster than neurcomp [S1].
*   **Memory Complexity:** Consumes about half of the GPU memory and less than 20% of the CPU memory required by neurcomp [S1].
*   **Quality:** Achieves +5.87 dB and +7.18 dB higher PSNR on average compared to SZ3 and TTHRESH respectively under high compression rates [S1]. Better reconstruction accuracy (PSNR, LPIPS, CD) and visual quality than neurcomp, SZ3, and TTHRESH under similar compression ratios [S1].
*   **Strengths:** High compression ratio, fast decoding, reduced memory usage, adaptive network capacity [S1].
*   **Limitations:** Slow encoding compared to CPU-based methods, not suitable for time-critical scenarios (in situ/co-processing) unless massive GPU parallelism is available, limited by block boundary artifacts and content richness [S1].
*   **When to Use:** Archiving large time-varying datasets during post-processing where speed is not the primary concern [S1].

## Background
ECNR was proposed as an adaptive solution for time-varying volumetric data compression using MLPs with sinusoidal activation functions [S1]. It builds on the MINER approach for implicit neural representation of image and point cloud data but extends it to 4D space-time data [S1]. The method abandons the single-MLP approach of neurcomp, using multiple small local MLPs to encode disjoint clusters of spatiotemporal blocks in a multiscale fashion [S1]. It integrates deep compression strategies (block-guided pruning, global quantization, entropy encoding) and a lightweight CNN for artifact mitigation [S1].
