# Global Quantization

Also called: Global shared parameter table quantization

## Overview
Global quantization is a compression strategy for neural volume representations that maintains a single shared parameter table across multiple independent small Multi-Layer Perceptrons (MLPs) within a single spatial scale, rather than quantizing each network individually [S1]. It solves the redundancy problem where distinct volumetric blocks contain similar content, allowing different MLPs to map to the same set of floating-point parameters [S1]. Unlike local quantization which treats each MLP as an isolated entity, global quantization leverages cross-MLP similarity to achieve higher compression ratios with minimal performance degradation [S1].

## How it works
**Inputs:** A set of $N$ independent small MLPs encoding disjoint volumetric blocks at a specific scale; a target weight quantization precision $\beta$ (in bits).
**Outputs:** A single global shared parameter table (codebook) of size $2^\beta$ floating-point values; $\beta$-bit indices for each weight and bias in all MLPs.

**Data Structures:**
1.  **Global Shared Parameter Table:** A 1D array of $2^\beta$ floating-point numbers. This table stores the representative values for all quantized weights and biases across all MLPs in the scale.
2.  **Index Maps:** For each MLP $i$ and each layer $l$, a mapping from the original weight/bias positions to indices in the global table. Since the table is shared, the index $q \in [0, 2^\beta - 1]$ refers to the same physical value for all MLPs.

**Parameters:**
*   $\beta$: The number of bits used for local quantization precision. Typical value: 7 [S1]. This determines the size of the shared codebook as $2^\beta$ [S1].

**Steps:**
1.  **Global Clustering:** For each layer across all MLPs in the scale, collect all unpruned weights (and biases, if included). Apply standard k-means clustering to group these weights into $2^\beta$ clusters [S1]. The centroid of each cluster becomes a value in the global shared parameter table [S1].
2.  **Index Assignment:** Replace every weight and bias in every MLP with a $\beta$-bit integer index pointing to the corresponding centroid in the global shared parameter table [S1].
3.  **Fine-Tuning:** Fix the $\beta$-bit indices (the assignment of weights to clusters) and fine-tune only the values in the global shared parameter table via backpropagation to minimize reconstruction error [S1]. This step mitigates performance degradation caused by quantization [S1].
4.  **Entropy Encoding (Optional Post-Processing):** Apply Huffman coding to the resulting model file (specifically the indices and the shared table) to achieve additional lossless compression, empirically reducing model size by ~10% [S1].

**Pseudocode:**
```python
def global_quantization(mlps, beta):
    """
    mlps: List of MLP objects, each containing layers with weights and biases.
    beta: Quantization precision in bits.
    """
    num_clusters = 1 << beta  # 2^beta
    
    # Step 1: Collect all weights and biases from all MLPs in the scale
    all_params = []
    param_metadata = [] # Store (mlp_id, layer_id, param_type, original_value)
    
    for mlp_id, mlp in enumerate(mlps):
        for layer_id, layer in enumerate(mlp.layers):
            # Flatten weights and biases
            weights = layer.weights.flatten()
            biases = layer.biases.flatten()
            
            # Combine for clustering
            current_params = np.concatenate([weights, biases])
            
            # Store metadata to reconstruct later
            for val in current_params:
                all_params.append(val)
                param_metadata.append((mlp_id, layer_id, 'weight' if val in weights else 'bias'))
                
    all_params = np.array(all_params)
    
    # Step 2: K-means clustering to find global centroids
    # k-means returns cluster centers (centroids) and labels (indices)
    centroids, labels = kmeans(all_params, n_clusters=num_clusters)
    
    # Step 3: Create the global shared parameter table
    global_table = centroids.astype(float)
    
    # Step 4: Assign indices to each MLP's layers
    # We need to map the flat list of labels back to the structure of each MLP
    label_idx = 0
    for mlp_id, mlp in enumerate(mlps):
        for layer_id, layer in enumerate(mlp.layers):
            num_weights = layer.weights.size
            num_biases = layer.biases.size
            
            # Extract labels for this layer's weights and biases
            layer_labels = labels[label_idx : label_idx + num_weights + num_biases]
            label_idx += num_weights + num_biases
            
            # Reshape and assign
            layer.quantized_weights = layer_labels[:num_weights].reshape(layer.weights.shape)
            layer.quantized_biases = layer_labels[num_weights:].reshape(layer.biases.shape)
            
            # Store reference to global table
            layer.global_table_ref = global_table

    # Step 5: Fine-tune global table values
    # Fix indices, optimize global_table values via backprop
    # This requires a differentiable rendering or reconstruction loss
    # L = Loss(Reconstruct(mlps, global_table, indices), GroundTruth)
    # Optimize global_table using gradient descent
    
    optimizer = Adam(global_table.parameters(), lr=1e-4)
    for epoch in range(num_fine_tuning_epochs):
        optimizer.zero_grad()
        loss = compute_reconstruction_loss(mlps, global_table)
        loss.backward()
        optimizer.step()
        
    return global_table, mlps
```

**Edge Cases and Pitfalls:**
*   **Precision:** The choice of $\beta$ is critical. Too low a $\beta$ leads to high quantization error; too high reduces compression benefits. $\beta=7$ is a typical baseline for small MLPs [S1].
*   **Boundary Artifacts:** While global quantization compresses parameters, it does not inherently solve boundary artifacts between disjoint volumetric blocks. This requires separate mitigation strategies (e.g., boundary artifact mitigation techniques) [S1].
*   **Clustering Stability:** K-means initialization can affect results. Standard k-means++ initialization is recommended to ensure stable centroids [S1].

## Subtopics

### Local Quantization
Quantizes each MLP independently. Simpler to implement but less efficient for volumes with redundant content across blocks. Choose when blocks are highly distinct. [Link](907-vector-quantization.md)

### Vector Quantization
Groups multi-dimensional vectors (e.g., entire weight vectors) into clusters. Global quantization typically operates on scalar weights/biases individually but shares the codebook globally. [Link](5726-scalar-quantization.md)

## Operating characteristics
*   **Time Complexity:** Clustering is $O(N \cdot D \cdot I)$ where $N$ is total number of weights/biases, $D$ is dimensionality (1 for scalars), and $I$ is k-means iterations. Fine-tuning adds standard backpropagation cost per MLP.
*   **Memory Complexity:** The shared parameter table size is $2^\beta \times \text{bytes\_per\_float}$. The index storage is $\beta$ bits per weight/bias. This is significantly smaller than storing full precision weights for each MLP.
*   **Performance:** ECNR (with global quantization) achieves a model size of 0.49 MB vs 0.93 MB for local quantization (ECNR*) on the asteroids dataset at similar PSNR (40.59 vs 40.24 dB) [S1]. On supernova-1, it achieves 48.55 dB PSNR vs 44.86 dB for local quantization at the same model size (1.5 MB) [S1].
*   **Strengths:** High compression ratio for volumes with spatially similar features; effective for multiple small MLPs.
*   **Limitations:** Requires fine-tuning which adds training time; less effective if volumetric blocks are highly heterogeneous.

## Background
Global quantization was introduced in the context of Efficient Compressive Neural Representation (ECNR) for time-varying volumetric datasets [S1]. Prior quantization approaches focused on single neural networks [S1]. ECNR extended this by applying quantization across multiple independent small MLPs, recognizing that different blocks often contain similar content [S1]. The method builds on standard k-means clustering and entropy encoding (Huffman coding) [S1].
