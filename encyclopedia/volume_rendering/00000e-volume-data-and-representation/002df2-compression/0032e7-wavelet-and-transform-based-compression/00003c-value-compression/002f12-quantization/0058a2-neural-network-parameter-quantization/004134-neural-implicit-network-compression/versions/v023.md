# Neural Implicit Network Compression

Also called: Coordinate-based MLP Compression, SIREN-based INR Compression, neurcomp

## Overview
Neural Implicit Network Compression (NeurComp) is a method for compressing scientific volume data by training a coordinate-based Multi-Layer Perceptron (MLP) to map spatial coordinates directly to field values [S1, unofficial]. It solves the problem of high storage and I/O costs associated with full-resolution scientific volumes by providing a compact network that serves as simultaneously compressed storage and a queryable data source [S1, unofficial]. It sets itself apart from traditional lossy compressors like SZ and ZFP, which produce bitstreams requiring full decoding before visualization, by enabling direct querying of the implicit representation [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A scalar field volume $V$ defined on a regular grid (e.g., $N^3$).
*   **Output:** A trained SIREN MLP model parameters (weights and biases) representing the compressed volume.

**Data Structures:**
*   **MLP Weights:** The network weights are quantized to 9 bits per weight using k-means clustering [S1, unofficial].
*   **Network Architecture:** A SIREN (Sinusoidal Representation Network) MLP with residual connections [S1, unofficial].

**Steps:**
1.  **Sampling:** Sample a set of 3D spatial coordinates $\{(x_j, y_j, z_j)\}$ from the volume domain.
2.  **Encoding:** Apply positional or hash encoding $\gamma(x)$ to the input coordinates [S1, unofficial].
3.  **Forward Pass:** Pass the encoded coordinates through the SIREN MLP to predict field values $v_j$.
4.  **Training:** Optimize the network parameters to minimize the reconstruction error between predicted values and ground truth values $V(x_j, y_j, z_j)$.
5.  **Quantization:** Apply k-means clustering to the trained network weights to quantize them to 9 bits [S1, unofficial].
6.  **Regularization (Optional):** Apply an optional gradient regularization term to improve isosurface fidelity, accepting a slight reduction in PSNR [S1, unofficial].

**Formulas:**
*   Reconstruction Loss: $\mathcal{L} = \sum_j \| \text{MLP}(\gamma(x_j)) - V(x_j) \|^2$ [S1, unofficial].
*   Gradient Regularization: Adds a term penalizing the difference between the predicted gradient and the numerical gradient of the ground truth [S1, unofficial].

**Parameters:**
*   **Weight Quantization Bits:** 9 bits [S1, unofficial].
*   **Hardware:** Training performed on a V100 GPU [S1, unofficial].
*   **Training Time:** Hours per volume [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Interactivity:** The method could not render interactively from the volume due to the computational cost of querying the MLP [S1, unofficial].
*   **Precision:** Gradient regularization improves isosurface fidelity but reduces PSNR [S1, unofficial].

## Subtopics

### [Time-varying INR compression via Laplacian pyramid](10432-time-varying-inr-compression-via-laplacian-pyramid.md)
This method compresses time-varying volumetric datasets by decomposing the 4D space-time domain into a Laplacian pyramid and representing each spatial block at each scale with a separate Implicit Neural Representation (INR). It sets itself apart from centralized INR approaches like [Neural Implicit Network Compression](10414-neural-implicit-network-compression.md) by trading a single global model for multiple local models, which significantly accelerates decoding speeds while maintaining reconstruction quality.

### MVNet
MVNet is a method for compressing multivariate data by formulating it as multi-task learning, using a Residual SIREN with a v-dimensional output layer sharing intermediate parameters across variables [S1, unofficial]. It uses a Residual SIREN with a v-dimensional output layer (v = number of physical variables) and shares all intermediate parameters across variables [S1, unofficial]. It has only been tested on static datasets [S1, unofficial]. On a 100-variable climate dataset (1568 MB), it achieved 49.68 dB PSNR at 1298:1 compression, outperforming TTHRESH (48.62 dB at 343:1) and preserving inter-variable statistical dependencies (Pearson correlation and mutual information) better than traditional compressors [S1, unofficial].

### KD-INR
KD-INR is a two-stage pipeline for compressing time-varying data: first compressing each timestep independently with a small INR, then merging all per-timestep teacher models into a single student via offline knowledge distillation [S1, unofficial]. Stage 1 involves compressing each timestep independently with a small INR with bottleneck layers and using entropy-based adaptive sampling to concentrate training on high-information blocks [S1, unofficial]. Stage 2 merges all per-timestep teacher models into a single student via offline knowledge distillation (an O(n) procedure) [S1, unofficial]. On time-varying datasets up to 23.44 GB (argon bubble, 150 timesteps), it outperformed CoordNet, NeurComp, and SIREN at compression ratios from 733 to 10,000, with per-timestep compression requiring 1–6 minutes on a single GPU [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Training requires hours per volume on a V100 GPU [S1, unofficial].
*   **Memory Complexity:** Determined by the size of the quantized MLP weights (9-bit quantization) [S1, unofficial].
*   **Performance:** On scalar fields up to $512^3$, NeurComp outperformed tensor decomposition (TTHRESH) at high compression ratios, achieving 47.9 dB PSNR at 545:1 compression on the Rayleigh-Taylor dataset [S1, unofficial].
*   **Strengths:** Provides a compact representation that is simultaneously storage and a queryable source; outperforms traditional compressors at high compression ratios [S1, unofficial].
*   **Limitations:** Cannot render interactively from the volume due to query latency; training time is significant [S1, unofficial].
*   **When to use:** When interactive rendering is not required, and high compression ratios with good reconstruction quality are needed for static scientific volumes [S1, unofficial].
*   **When not to use:** When interactive visualization is required [S1, unofficial].

## Background
Neural Implicit Network Compression (NeurComp) is the first INR compression method for scientific volumes [S1, unofficial]. It uses a coordinate-based SIREN MLP with residual connections and 9-bit weight quantization via k-means clustering [S1, unofficial]. It was developed to address the strain that full-resolution scientific volumes place on storage systems and I/O pipelines [S1, unofficial].
