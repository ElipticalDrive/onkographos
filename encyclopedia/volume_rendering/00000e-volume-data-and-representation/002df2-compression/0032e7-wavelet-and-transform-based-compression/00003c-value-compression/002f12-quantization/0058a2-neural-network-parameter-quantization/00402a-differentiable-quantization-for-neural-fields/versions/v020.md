# Differentiable Quantization for Neural Fields

Also called: MERF Quantization, Quantization for Memory Reduction

## Overview
This method reduces the render-time memory footprint of neural field representations (such as 3D Gaussian Splatting or radiance fields) by compressing grid values to single bytes during the optimization phase. It solves the quality degradation caused by naive post-training quantization, where the discretization error mismatches the trained continuous model. It differs from [Scalar Quantization](5726-scalar-quantization.md) by integrating the quantization operation directly into the training loop via a straight-through estimator, ensuring the model converges to values that are robust to discretization.

## How it works
**Inputs and Outputs:**
- Input: Continuous grid values $\tilde{\mathbf{t}}$ (densities, colors, features) during optimization.
- Output: Quantized grid values $\tilde{\mathbf{t}}'$ stored in memory, and gradients flowing through the quantization step.

**Data Structures:**
- Grid values are stored as single bytes (uint8).
- Each dimension is mapped independently.

**Parameters:**
- $m$: Scaling factor for affine mapping.
  - $m = 14$ for densities (computed using exponential nonlinearity) [S1].
  - $m = 7$ for diffuse colors and features [S1].
- $B = 2^8 - 1 = 255$: Number of quantization levels [S1].

**Steps:**
1. **Nonlinear Mapping:** Apply a sigmoid function $\sigma(\cdot)$ to map the continuous grid values $\tilde{\mathbf{t}}$ to the range $[0, 1]$.
2. **Quantization:** Apply the quantization function $q(x)$ to map the sigmoid output to a single byte.
3. **Affine Mapping:** Map the quantized byte value back to the range $[-m, m]$ using the scaling factor $m$.
4. **Gradient Flow:** Use the straight-through estimator to allow gradients to pass through the non-differentiable quantization step during backpropagation.

**Formula:**
The quantized value $\tilde{\mathbf{t}}'$ is computed as:
$$ \tilde{\mathbf{t}}' = 2m \cdot q(\sigma(\tilde{\mathbf{t}})) - m $$

The quantization function $q(x)$ is defined as:
$$ q(x) = x + \mathcal{V}\left(\frac{\lfloor (2^8 - 1)x + 1/2 \rfloor}{2^8 - 1} - x\right) $$
where $\mathcal{V}$ is the straight-through estimator operator, which returns the gradient of the identity function for the input $x$ while the forward pass computes the rounded value [S1].

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

def differentiable_quantize(t, m):
    """
    Quantizes grid values t to single bytes during optimization.
    
    Args:
        t: Continuous grid values (tensor).
        m: Scaling factor (14 for densities, 7 for colors/features).
        
    Returns:
        t_prime: Quantized values in range [-m, m].
    """
    # Step 1: Map to [0, 1] using sigmoid
    t_sigmoid = torch.sigmoid(t)
    
    # Step 2: Quantize to single byte (0-255)
    # Floor with rounding: floor((255 * x) + 0.5)
    # Then divide by 255 to get back to [0, 1] range
    quantized_float = torch.floor((255 * t_sigmoid) + 0.5) / 255.0
    
    # Step 3: Straight-through estimator
    # Forward pass uses quantized_float, backward pass uses t_sigmoid
    # In PyTorch, this is achieved by detaching the quantized value
    # and adding the original value's gradient
    quantized_st = t_sigmoid.detach() + (quantized_float - t_sigmoid).detach() + t_sigmoid
    
    # Step 4: Affine mapping to [-m, m]
    t_prime = 2 * m * quantized_st - m
    
    return t_prime
```

**Edge Cases and Pitfalls:**
- Simply quantizing after training causes quality drops due to mismatch between optimized and rendered models [S1].
- The quantization is applied to values stored in the grid; nonlinearities in subsequent rendering equations are applied after linear interpolation and summation [S1].
- Content is only baked in regions considered occupied by the proposal MLP during training to avoid introducing mismatch [S1].

## Subtopics

### [Quantization-Aware Fine-Tuning](11387-quantization-aware-fine-tuning.md)
Quantization-Aware Fine-Tuning (QAT) is a post-clustering optimization step designed to recover reconstruction quality lost during the vector quantization of 3D scene parameters. While clustering compresses parameters into compact codebooks, it introduces discretization errors; QAT mitigates this by fine-tuning the scene representation on training images while simulating the target low-precision quantization during the forward pass. This method differs from post-training quantization, where weights are reduced after training, by simulating quantization during training to obtain numerically stable gradients and reduce final inference errors.

## Operating characteristics
- **Memory:** Reduces memory consumption by storing each grid dimension as a single byte [S1].
- **Performance:** Enables real-time view synthesis in unbounded scenes by reducing memory bandwidth requirements [S1].
- **Quality:** Maintains rendering quality comparable to full-precision models when quantization is integrated into optimization, avoiding the drops seen in post-training quantization [S1].
- **Limitations:** Requires careful tuning of the scaling factor $m$ for different attribute types (density vs. color) [S1].

## Background
Originated in the MERF (Memory-Efficient Radiance Fields) paper, which proposes methods for real-time view synthesis in unbounded scenes with limited memory [S1]. The method addresses the trade-off between memory efficiency and rendering quality in neural field representations.
