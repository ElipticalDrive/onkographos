# Differentiable Quantization for Neural Fields

Also called: MERF Quantization, Quantization for Memory Reduction

## Overview
This method reduces the render-time memory footprint of neural radiance fields by quantizing grid-based feature values to single bytes during the optimization process. Unlike post-training quantization, which causes quality degradation due to the mismatch between the optimized continuous model and the discrete inference model, this approach integrates quantization into the training loop. It sets itself apart from sibling methods like [Scalar Quantization](5726-scalar-quantization.md) by using a differentiable approximation (straight-through estimator) to allow gradients to flow through the non-differentiable rounding operation, ensuring the network learns values that are robust to the specific quantization scheme.

## How it works
**Inputs and Outputs:**
- Input: Continuous grid values $\tilde{\mathbf{t}}$ (densities, colors, or features) produced by the neural field.
- Output: Quantized grid values $\tilde{\mathbf{t}}'$ stored in memory, which are used for rendering.

**Data Structures:**
- The grid stores values as single bytes (uint8).
- Each dimension of the grid (density, RGB color, feature vectors) is quantized independently.

**Parameters:**
- $m$: Scaling factor for the affine mapping.
  - $m = 14$ for densities (computed using exponential nonlinearity).
  - $m = 7$ for diffuse colors and features.
- $B = 2^8 - 1 = 255$: The number of quantization levels minus one.

**Steps:**
1. **Nonlinear Mapping to [0, 1]:** Apply a sigmoid function $\sigma(\cdot)$ to the continuous grid values $\tilde{\mathbf{t}}$ to bound them within the interval $[0, 1]$.
   $$ x = \sigma(\tilde{\mathbf{t}}) $$
2. **Quantization:** Map the bounded value $x$ to a discrete integer index in $[0, 255]$ and then back to a floating-point value in $[0, 1]$. This step is non-differentiable.
   $$ q(x) = \frac{\lfloor B x + 0.5 \rfloor}{B} $$
3. **Affine Mapping to $[-m, m]$:** Scale the quantized value to the target range.
   $$ \tilde{\mathbf{t}}' = 2m \cdot q(x) - m $$
4. **Gradient Flow:** Use the straight-through estimator (STE) to allow gradients to pass through the quantization function during backpropagation. The gradient of the quantization function is treated as the identity function for the backward pass.

**Formula:**
The complete differentiable quantization function $q_{diff}(x)$ is defined as:
$$ q_{diff}(x) = x + \text{stop-gradient}\left( \frac{\lfloor (2^8 - 1)x + 1/2 \rfloor}{2^8 - 1} - x \right) $$
Where $\text{stop-gradient}(\cdot)$ prevents gradients from flowing through the rounding operation, effectively making the gradient of $q_{diff}$ equal to 1 with respect to $x$ in the forward pass context of the STE.

The final quantized value for a grid entry $\tilde{\mathbf{t}}$ is:
$$ \tilde{\mathbf{t}}' = 2m \cdot q_{diff}(\sigma(\tilde{\mathbf{t}})) - m $$

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

def differentiable_quantize(t, m):
    """
    Quantizes grid values t to single bytes during optimization.
    
    Args:
        t: Continuous grid values (float32).
        m: Scaling factor (14 for density, 7 for color/features).
        
    Returns:
        Quantized values in range [-m, m].
    """
    # Step 1: Sigmoid to [0, 1]
    x = torch.sigmoid(t)
    
    # Step 2: Quantize to byte and back to float [0, 1]
    # Floor with rounding: floor(val + 0.5)
    quantized_float = torch.floor((255 * x) + 0.5) / 255.0
    
    # Step 3: Straight-Through Estimator
    # Forward pass uses quantized_float, backward pass uses x
    quantized_ste = x + (quantized_float - x).detach()
    
    # Step 4: Affine mapping to [-m, m]
    result = 2 * m * quantized_ste - m
    
    return result
```

**Edge Cases and Pitfalls:**
- **Post-Training Quantization:** Simply quantizing grid values after training completes leads to a significant drop in rendering quality because the optimized model is not adapted to the discrete representation [S1].
- **Precision:** The use of `float32` for intermediate calculations is recommended to maintain gradient stability, even though the final stored values are `uint8`.

## Operating characteristics
- **Memory Reduction:** Reduces the storage size of each grid dimension to 1 byte per value, significantly lowering render-time memory consumption [S1].
- **Performance:** No significant runtime overhead during rendering compared to standard floating-point grids, as the quantization is applied during training/baking, not inference.
- **Quality:** Maintains high rendering quality comparable to full-precision models when integrated into the training loop, avoiding the quality drops associated with naive post-training quantization [S1].
- **Limitations:** Requires modifying the training pipeline to include the quantization step. The choice of $m$ is critical and must be tuned per data type (density vs. color).

## Background
This method was introduced in the MERF (Memory-Efficient Radiance Fields) paper for real-time view synthesis in unbounded scenes. It addresses the high memory requirements of neural radiance fields by enabling efficient storage of grid-based features without sacrificing rendering quality.
