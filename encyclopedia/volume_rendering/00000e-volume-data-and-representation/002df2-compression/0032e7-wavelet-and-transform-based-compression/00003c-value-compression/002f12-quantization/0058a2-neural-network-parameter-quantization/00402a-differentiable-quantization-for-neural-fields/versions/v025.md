# Differentiable Quantization for Neural Fields

Also called: MERF Quantization, Quantization for Memory Reduction

## Overview
Differentiable quantization reduces the memory footprint of neural field parameters (such as those in MERF) by mapping continuous grid values to single-byte integers during the optimization phase, rather than after training. This approach prevents the reconstruction quality drop associated with post-training quantization by ensuring the model is optimized for the discrete representation it will actually use at render time. It differs from standard post-training quantization by integrating the rounding operation into the gradient flow via a straight-through estimator, and from global quantization by applying per-channel or per-parameter affine scaling to handle different value distributions (e.g., densities vs. colors) [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Continuous grid parameter values $\tilde{\mathbf{t}}$ (e.g., densities, colors, features) from the neural field representation.
*   **Output:** Quantized grid values $\tilde{\mathbf{t}}'$ stored as single-byte integers (uint8) but treated as continuous values for gradient computation.

**Data Structures:**
*   The grid stores values as 8-bit unsigned integers (uint8).
*   Each value represents an index in the range $[0, 2^8 - 1]$.
*   These indices are mapped to a specific physical range $[-m, m]$ during evaluation.

**Parameters:**
*   $m$: The scaling factor for the affine mapping.
    *   $m = 14$ for densities (due to exponential nonlinearity).
    *   $m = 7$ for diffuse colors and features [S1].
*   $B = 2^8 - 1 = 255$: The number of quantization levels minus one.

**Method Steps:**
1.  **Nonlinear Mapping to [0, 1]:** Apply a sigmoid function $\sigma(\cdot)$ to the raw grid values $\tilde{\mathbf{t}}$ to bound them within $[0, 1]$.
    $$ x = \sigma(\tilde{\mathbf{t}}) $$
2.  **Quantization:** Map the continuous value $x \in [0, 1]$ to the nearest integer index in $[0, 255]$. This is done by rounding $(255 \cdot x)$ to the nearest integer.
3.  **Affine Mapping to $[-m, m]$:** Scale the integer index back to the target range $[-m, m]$.
    $$ \tilde{\mathbf{t}}' = 2m \cdot \frac{\text{round}(255 \cdot x)}{255} - m $$
4.  **Gradient Flow:** Use the Straight-Through Estimator (STE) to allow gradients to pass through the non-differentiable rounding operation. The gradient of the quantization function is treated as the identity function during the backward pass.

**Formula:**
The complete quantization function $q(x)$ applied to the sigmoid output $x$ is defined as:
$$ q(x) = x + \mathcal{V}\left(\frac{\lfloor (2^8 - 1)x + 1/2 \rfloor}{2^8 - 1} - x\right) $$
where $\mathcal{V}(\cdot)$ is the stop-gradient operator (or straight-through estimator), meaning the gradient of the term inside $\mathcal{V}$ is zero, but the forward pass uses the rounded value. Effectively:
$$ q(x) = \frac{\lfloor 255x + 0.5 \rfloor}{255} $$
The final stored value is:
$$ \tilde{\mathbf{t}}' = 2m \cdot q(\sigma(\tilde{\mathbf{t}})) - m $$

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

def differentiable_quantize(t, m):
    """
    Quantizes grid values t to single bytes during optimization.
    
    Args:
        t: Continuous tensor of grid values.
        m: Scaling factor (14 for densities, 7 for colors/features).
        
    Returns:
        Quantized tensor values in range [-m, m].
    """
    # Step 1: Map to [0, 1] using sigmoid
    x = torch.sigmoid(t)
    
    # Step 2 & 3: Quantize to 8-bit integer and map to [-m, m]
    # Round to nearest integer in [0, 255]
    # Note: torch.round rounds to nearest even for .5 cases, 
    # but floor(x + 0.5) is standard for "round half up". 
    # The source uses floor((2^8-1)x + 1/2), which is equivalent to round(x) 
    # if we consider the specific implementation of floor.
    # We use the explicit formula from the source for fidelity.
    quantized_index = torch.floor((255 * x) + 0.5)
    
    # Clamp to valid range [0, 255] to handle edge cases
    quantized_index = torch.clamp(quantized_index, 0, 255)
    
    # Convert to float for affine mapping
    quantized_float = quantized_index.float() / 255.0
    
    # Step 4: Affine mapping to [-m, m]
    # Forward pass: 2 * m * quantized_float - m
    # Backward pass: Straight-Through Estimator (gradient of quantized_float w.r.t x is 1)
    # We implement STE by detaching the gradient of the rounding part 
    # or simply using the continuous approximation for gradient flow.
    # The source defines q(x) = x + V(...). 
    # In PyTorch, this is often implemented as:
    # q(x) = (x - x.detach()) + rounded_x
    # However, since x is sigmoid(t), we can just compute the forward value
    # and let gradients flow through the sigmoid and linear ops.
    # The "stop-gradient" is on the difference between rounded and continuous.
    
    # Implementation of STE for the quantization step:
    # Forward: rounded value
    # Backward: gradient of the continuous value (x)
    
    # Calculate the rounded value
    rounded_val = quantized_float
    
    # Calculate the continuous value for gradient flow
    continuous_val = x
    
    # Combine: Forward uses rounded, Backward uses continuous
    # This is equivalent to: rounded_val + (continuous_val - rounded_val).detach()
    q_x = rounded_val + (continuous_val - rounded_val).detach()
    
    # Final affine mapping
    t_prime = 2 * m * q_x - m
    
    return t_prime
```

**Edge Cases and Pitfalls:**
*   **Post-Training Quantization:** Simply quantizing grid values after training causes a significant drop in rendering quality because the model was optimized for continuous values, not discrete ones [S1].
*   **Precision:** The use of 8-bit integers limits the dynamic range. The affine scaling $m$ must be chosen carefully to avoid clipping. $m=14$ for densities accounts for the exponential nonlinearity used in volume rendering [S1].
*   **Boundaries:** The sigmoid ensures values are in $[0,1]$, but numerical precision might push values slightly outside. Clamping is recommended.

## Operating characteristics
*   **Memory Reduction:** Reduces grid parameter storage from 32-bit floats (4 bytes) to 8-bit integers (1 byte), achieving a 4x compression ratio for the grid data [S1].
*   **Performance:** No significant runtime overhead during rendering, as the quantized values are stored and accessed as integers. The sigmoid and affine mapping are applied during training only.
*   **Quality:** Maintains high rendering quality comparable to full-precision models when quantization is performed during optimization [S1].
*   **Limitations:** The choice of $m$ is critical and may require tuning for different scene types or non-linearities. Not suitable for post-training scenarios without fine-tuning.

## Background
This method was introduced in the MERF (Memory-Efficient Radiance Fields) paper, which focuses on real-time view synthesis in unbounded scenes. The key insight is that quantizing during optimization, rather than after, allows the model to adapt to the discrete representation, avoiding the quality degradation seen in post-training quantization [S1].
