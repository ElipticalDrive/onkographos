# Neural Network Parameter Quantization

Also called: Neural Field Quantization, INR Compression

## Overview
Neural Network Parameter Quantization applies quantization techniques to the weights and parameters of neural networks used for volume representation, such as Implicit Neural Representations (INRs) and neural fields. It solves the storage and I/O bottlenecks associated with high-resolution volumetric data by replacing explicit grids or large unquantized models with compact, quantized parameter sets . It differs from standard volume compression by optimizing the network parameters directly rather than compressing the output field values, and from sibling methods by leveraging the specific statistical properties of neural weights (e.g., redundancy across spatial blocks or specific activation distributions) to achieve higher compression ratios .

## Shared principles
The family shares the fundamental mechanism of mapping a continuous input space to a discrete output space. While specific implementations vary, the core operation involves a quantization function $Q(x)$ that maps a real-valued input $x$ to a discrete index or representative value, and an inverse function for reconstruction.

1.  **Discretization:** Continuous values (voxel intensities, transform coefficients, neural network weights, or color components) are mapped to a finite set of levels. This is often achieved by dividing the dynamic range into bins or by finding the nearest entry in a codebook .
2.  **Indexing/Representation:** The quantized data is represented by compact indices, bit-packed integers, or reduced-precision floating-point formats .
3.  **Error Trade-off:** Quantization is inherently lossy. The error introduced is typically measured by distortion metrics such as Mean Squared Error (MSE) or Peak Signal-to-Noise Ratio (PSNR) . The goal is to minimize this error for a given bit budget .
4.  **Integration with Compression:** Quantization is usually followed by entropy coding (e.g., Huffman, Arithmetic) or used in conjunction with predictive coding to further compress the resulting discrete data .

## Subtopics

### [Differentiable Quantization for Neural Fields](10195-differentiable-quantization-for-neural-fields.md)
Differentiable quantization reduces the memory footprint of neural field parameters by mapping continuous grid values to single-byte integers during the optimization phase, rather than after training. This approach prevents the reconstruction quality drop associated with post-training quantization by ensuring the model is optimized for the discrete representation it will actually use at render time. It differs from standard post-training quantization by integrating the rounding operation into the gradient flow via a straight-through estimator, and from global quantization by applying per-channel or per-parameter affine scaling to handle different value distributions (e.g., densities vs. colors) [10195-differentiable-quantization-for-neural-fields.md].

### [Neural Implicit Network Compression](10414-neural-implicit-network-compression.md)
Neural Implicit Network Compression (neurcomp) is the first method to apply Implicit Neural Representations (INRs) to compress scientific volumetric data. It solves the storage and I/O bottlenecks of traditional lossy compressors by replacing the raw grid with a compact coordinate-based Multi-Layer Perceptron (MLP) that maps spatial coordinates directly to field values. Unlike traditional compressors that require full decoding before visualization, neurcomp serves as simultaneously compressed storage and a queryable data source. It sets itself apart from siblings by using post-training k-means clustering for weight quantization rather than differentiable training-time quantization, and from Global Quantization by focusing on the specific architecture of SIRENs with residual connections for scientific fields [10414-neural-implicit-network-compression.md].

### [Global Quantization](15134-global-quantization.md)
Global Quantization is a post-training compression strategy for neural fields that replaces local, per-network weight quantization with a single shared parameter table across all Multi-Layer Perceptrons (MLPs) within a specific spatial scale. It solves the redundancy problem where independent MLPs encoding distinct volumetric blocks often represent similar content with different, non-shared weights. Unlike sibling methods that quantize each MLP individually, Global Quantization clusters weights across the entire scale, allowing multiple networks to reference the same floating-point parameters, thereby significantly reducing model size without increasing reconstruction error [15134-global-quantization.md].

## Background
The application of neural networks to volume representation, specifically Implicit Neural Representations (INRs) and neural fields, has grown significantly as an alternative to explicit voxel grids [10414-neural-implicit-network-compression.md, 10195-differentiable-quantization-for-neural-fields.md, 15134-global-quantization.md]. Traditional volume compression methods, such as those based on wavelets or predictive coding (e.g., SZ, ZFP), face I/O bottlenecks when handling high-resolution scientific data [10414-neural-implicit-network-compression.md]. Neural network parameter quantization emerged to address the large memory footprint of these neural representations, which can be prohibitively large for storage and transmission [10414-neural-implicit-network-compression.md, 15134-global-quantization.md]. Early approaches focused on post-training quantization, but it was observed that this led to significant quality degradation because the networks were not optimized for discrete parameters [10195-differentiable-quantization-for-neural-fields.md]. Subsequent methods introduced differentiable quantization during training [10195-differentiable-quantization-for-neural-fields.md] and global quantization to exploit redundancy across spatially distributed neural fields [15134-global-quantization.md].
