# Neural Network Parameter Quantization


## Overview
Neural Network Parameter Quantization refers to a family of techniques that compress the parameters of neural networks used for volume representation (such as Neural Radiance Fields or Implicit Neural Representations) by mapping continuous weight or feature values to a discrete, lower-bit representation. This family solves the problem of excessive memory consumption and bandwidth requirements associated with storing high-precision floating-point parameters for large-scale 3D data . It sets itself apart from sibling methods like [Vector Quantization](907-vector-quantization.md) and [Scalar Quantization](5726-scalar-quantization.md) by specifically targeting the structural redundancy and spatial locality inherent in neural volume models, often employing strategies such as differentiable training-time quantization, implicit network compression, or global shared codebooks across multiple local networks .

## Shared principles
The family shares the fundamental mechanism of mapping a continuous input space to a discrete output space. While specific implementations vary, the core operation involves a quantization function $Q(x)$ that maps a real-valued input $x$ to a discrete index or representative value, and an inverse function for reconstruction.

1.  **Discretization:** Continuous values (voxel intensities, transform coefficients, neural network weights, or color components) are mapped to a finite set of levels. This is often achieved by dividing the dynamic range into bins or by finding the nearest entry in a codebook .
2.  **Indexing/Representation:** The quantized data is represented by compact indices, bit-packed integers, or reduced-precision floating-point formats .
3.  **Error Trade-off:** Quantization is inherently lossy. The error introduced is typically measured by distortion metrics such as Mean Squared Error (MSE) or Peak Signal-to-Noise Ratio (PSNR) . The goal is to minimize this error for a given bit budget .
4.  **Integration with Compression:** Quantization is usually followed by entropy coding (e.g., Huffman, Arithmetic) or used in conjunction with predictive coding to further compress the resulting discrete data .

## Subtopics

### [Differentiable Quantization for Neural Fields](10195-differentiable-quantization-for-neural-fields.md)
This method reduces the render-time memory footprint of neural radiance fields by quantizing grid-based feature and density values to single bytes during the optimization process [10195-differentiable-quantization-for-neural-fields.md]. Unlike post-training quantization, which causes quality degradation due to the mismatch between the optimized continuous model and the discrete inference model, this approach integrates quantization into the training loop [10195-differentiable-quantization-for-neural-fields.md]. It sets itself apart from siblings like [Global Quantization](15134-global-quantization.md) by applying per-dimension byte quantization with specific affine scaling factors tailored to the data distribution (density vs. color) rather than a global uniform range [10195-differentiable-quantization-for-neural-fields.md].

### [Neural Implicit Network Compression](10414-neural-implicit-network-compression.md)
Neural Implicit Network Compression (neurcomp) is the first method to apply Implicit Neural Representations (INRs) to compress scientific volume data, mapping spatial coordinates directly to field values to serve as both compressed storage and a queryable data source [10414-neural-implicit-network-compression.md]. It distinguishes itself from traditional lossy compressors (e.g., SZ, ZFP) by enabling direct querying without full bitstream decoding, and from centralized INR variants by establishing the baseline architecture for scientific volume compression using SIRENs [10414-neural-implicit-network-compression.md].

### [Global Quantization](15134-global-quantization.md)
Global quantization is a parameter compression strategy for neural volume representations that maintains a single shared parameter table across multiple independent small Multi-Layer Perceptrons (MLPs) within a single scale, rather than quantizing each network locally [15134-global-quantization.md]. It solves the redundancy problem where distinct spatial blocks often contain similar content, allowing different MLPs to map to the same set of floating-point parameters [15134-global-quantization.md]. It sets itself apart from local quantization by leveraging cross-MLP similarity to achieve higher compression ratios for similar reconstruction accuracy [15134-global-quantization.md].

## Background
The application of quantization to neural network parameters for volume rendering emerged as a solution to the high memory costs of storing large-scale 3D neural fields. Early approaches relied on post-training quantization, which often resulted in significant quality loss [10195-differentiable-quantization-for-neural-fields.md]. Subsequent research introduced differentiable quantization to allow end-to-end optimization [10195-differentiable-quantization-for-neural-fields.md] and global quantization to exploit redundancy across spatially distributed MLPs [15134-global-quantization.md]. Additionally, the use of Implicit Neural Representations (INRs) like SIRENs for scientific volume compression provided a new paradigm for queryable, compressed storage [10414-neural-implicit-network-compression.md].
