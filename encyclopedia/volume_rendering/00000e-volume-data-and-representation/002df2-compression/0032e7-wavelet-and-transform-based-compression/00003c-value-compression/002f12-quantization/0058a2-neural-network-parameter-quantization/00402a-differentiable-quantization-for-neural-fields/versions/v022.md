# Differentiable Quantization for Neural Fields

Also called: MERF Quantization, Quantization for Memory Reduction

## Overview
Differentiable quantization reduces the render-time memory footprint of neural radiance fields by compressing grid values to single bytes during the optimization process [S1]. Unlike post-training quantization, which causes quality degradation due to mismatch between the optimized model and the inference model, this method integrates quantization into the training loop using a straight-through estimator [S1]. It sets itself apart from sibling methods like [Global Quantization](15134-global-quantization.md) by applying per-parameter scaling ranges and enforcing quantization constraints during gradient descent rather than as a post-processing step.

## How it works
**Inputs and Outputs:**
- Input: Continuous grid values $\tilde{\mathbf{t}}$ (densities, colors, features) from the neural field representation.
- Output: Quantized grid values $\tilde{\mathbf{t}}'$ stored in memory, and gradients for backpropagation.

**Data Structures:**
- Grid values are stored as single bytes (8-bit integers) in the final model.
- During training, values are processed in floating-point precision but constrained to the quantized domain.

**Parameters:**
- $m$: Scaling factor for affine mapping.
  - $m = 14$ for densities (which use an exponential nonlinearity).
  - $m = 7$ for diffuse colors and features [S1].
- $B = 2^8 - 1 = 255$: Number of quantization levels [S1].

**Steps:**
1. **Sigmoid Mapping:** Map the raw grid value $\tilde{\mathbf{t}}$ to the range $[0, 1]$ using a sigmoid function $\sigma(\cdot)$ [S1].
   $$ x = \sigma(\tilde{\mathbf{t}}) $$
2. **Quantization:** Apply the byte quantization function $q(x)$. This function rounds $x$ to the nearest representable byte value and returns the continuous approximation for gradient flow [S1].
   $$ q(x) = x + \mathcal{V}\left(\frac{\lfloor (2^8 - 1)x + 1/2 \rfloor}{2^8 - 1} - x\right) $$
   Where $\mathcal{V}$ is the straight-through estimator operator, which passes the gradient of the identity function through the non-differentiable rounding operation [S1].
3. **Affine Mapping:** Map the quantized value back to the target range $[-m, m]$ [S1].
   $$ \tilde{\mathbf{t}}' = 2m \cdot q(\sigma(\tilde{\mathbf{t}})) - m $$

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

def sigmoid_quantize(t, m):
    """
    Applies differentiable quantization to grid values.
    
    Args:
        t (torch.Tensor): Raw grid values.
        m (float): Scaling factor for the output range [-m, m].
        
    Returns:
        torch.Tensor: Quantized values in range [-m, m].
    """
    # Step 1: Sigmoid mapping to [0, 1]
    x = torch.sigmoid(t)
    
    # Step 2: Quantization to 256 levels [0, 255]
    # Round to nearest integer, then divide by 255 to get back to [0, 1]
    # The straight-through estimator is handled by PyTorch's autograd
    # by default for operations that don't block gradients, 
    # but explicitly we treat the rounding as identity for backward pass.
    quantized_x = torch.round(x * 255) / 255.0
    
    # Step 3: Affine mapping to [-m, m]
    t_prime = 2 * m * quantized_x - m
    
    return t_prime

# Example usage for densities and colors
# Density values
density_quantized = sigmoid_quantize(raw_density, m=14)
# Color/Feature values
color_quantized = sigmoid_quantize(raw_color, m=7)
```

**Edge Cases and Pitfalls:**
- **Post-training Quantization:** Simply quantizing grid values after training leads to a mismatch between the optimized model and the rendering model, causing significant quality drops [S1].
- **Nonlinearity Application:** The non-linearities (e.g., exponential for density) are applied *after* linear interpolation and summation of the quantized values, not before [S1].

## Operating characteristics
- **Memory Reduction:** Reduces grid memory consumption to 1 byte per dimension per location [S1].
- **Performance:** Enables real-time view synthesis in unbounded scenes by reducing memory bandwidth requirements [S1].
- **Quality:** Maintains high rendering quality when integrated into training, avoiding the degradation seen in post-training quantization [S1].
- **Limitations:** Requires modification of the training pipeline to include differentiable quantization; not applicable to already-trained models without fine-tuning.

## Background
Originated in the MERF (Memory-Efficient Radiance Fields) paper, which addresses the challenge of storing large neural radiance fields for real-time view synthesis in unbounded scenes [S1]. The method was developed to overcome the memory bottlenecks of traditional 3D Gaussian Splatting and NeRF representations by compressing the grid-based feature storage.
