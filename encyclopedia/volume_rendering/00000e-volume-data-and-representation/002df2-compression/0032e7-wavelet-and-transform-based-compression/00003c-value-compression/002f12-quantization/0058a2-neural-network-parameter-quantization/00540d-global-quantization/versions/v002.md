# Global Quantization

Also called: Global shared parameter table quantization

## Overview
Global quantization is a compression strategy for neural volumetric representations that maintains a single shared parameter table across multiple independent small Multi-Layer Perceptrons (MLPs) within a single scale, rather than quantizing each network individually [S1]. It solves the redundancy problem where distinct spatial blocks often contain similar content that can be represented by the same parameters [S1]. Unlike local quantization, which assigns separate codebooks to each MLP, global quantization leverages cross-MLP similarity to achieve higher compression ratios with minimal performance degradation [S1].

## How it works
**Inputs and Outputs:**
- Input: A set of independent small MLPs encoding disjoint volumetric blocks within a single scale; a target quantization precision $\beta$ (in bits).
- Output: A single global shared parameter table (floating-point values) and a set of $\beta$-bit indices mapping each MLP's weights and biases to entries in this table.

**Data Structures:**
1.  **Global Shared Parameter Table:** A list of $2^\beta$ floating-point values. This table stores the quantized weights and biases for all layers across all MLPs in the scale.
2.  **Index Map:** For each MLP and each layer, a tensor of $\beta$-bit integers. Each integer is an index into the Global Shared Parameter Table. The layout matches the shape of the original weights/biases.

**Steps:**
1.  **Local Clustering (Initialization):** For each MLP in the scale, apply standard k-means clustering to the unpruned weights of a specific layer. The number of clusters is $2^\beta$, where $\beta$ is the target quantization precision in bits [S1].
2.  **Global Merging:** Instead of keeping separate clusters for each MLP, merge the clusters from all MLPs in the scale. Identify similar effective blocks (parameters) across different MLPs and map them to the same shared parameters [S1]. This results in a single global table of size $2^\beta$ per layer type (or per layer if shapes differ, but shared by all MLPs) [S1].
3.  **Index Assignment:** Represent the weights and biases of all MLPs in the quantized layer as $\beta$-bit indices that map to the $2^\beta$ shared floating-point parameters in the global table [S1].
4.  **Bias Quantization:** Quantize both the MLP biases and weights, rather than only weights, to boost the compression ratio under similar reconstruction accuracy [S1].
5.  **Fine-Tuning:** Fix the parameter indices (the mapping from weights to global table entries) and fine-tune the corresponding shared parameters through backpropagation to minimize performance degradation at the same precision [S1].

**Formulas:**
-   Let $W$ be the set of all weights and biases across all MLPs in a scale.
-   Let $K = 2^\beta$ be the number of clusters/parameters.
-   The quantized value $q$ for a parameter $w$ is determined by the index $i$ assigned during clustering:
    $$ q = \text{GlobalTable}[i] $$
    where $i \in \{0, 1, \dots, 2^\beta - 1\}$.

**Parameters:**
-   $\beta$: Number of bits used for local quantization. Typical value: 7 [S1].

    mlps: List of MLP objects, each containing layers with weights and biases.
    beta: Quantization precision in bits.

    """
    num_clusters = 2 ** beta

    # We assume all MLPs have the same layer structure for simplicity in this example.
    # In practice, layers with different shapes are quantized separately but share the same global table size.
    
    global_table = {} # Maps layer_index to array of size num_clusters
    index_maps = {}   # Maps mlp_index -> layer_index -> index_tensor
    
    for layer_idx, layer in enumerate(mlps[0].layers):
        # Collect all weights and biases from all MLPs for this layer
        all_params = []
        param_shapes = []
        
        for mlp_idx, mlp in enumerate(mlps):
            w = mlp.layers[layer_idx].weight
            b = mlp.layers[layer_idx].bias
            all_params.append(w.flatten())
            all_params.append(b.flatten())
            param_shapes.append(w.shape)
            param_shapes.append(b.shape)
            
        # Flatten all parameters into a single vector for clustering
        # Note: This assumes we can cluster across different shapes by flattening.
        # A more robust implementation might cluster weights and biases separately
        # or use a unified representation. The source implies grouping "unpruned weights".
        
        flat_params = np.concatenate(all_params)
        
        # Apply k-means clustering to group parameters into 2^beta clusters
        # kmeans_labels will have length equal to total number of parameters
        kmeans_labels, _ = kmeans(flat_params, num_clusters)
        
        # Create the global table from cluster centers
        global_table[layer_idx] = kmeans_centers # Size: (num_clusters, feature_dim)
        
        # Assign indices back to each MLP
        current_idx = 0
        mlp_indices = []
        for mlp_idx, mlp in enumerate(mlps):
            w = mlp.layers[layer_idx].weight
            b = mlp.layers[layer_idx].bias
            
            # Extract labels for this MLP's parameters
            w_len = w.numel()
            b_len = b.numel()
            
            w_labels = kmeans_labels[current_idx : current_idx + w_len]
            b_labels = kmeans_labels[current_idx + w_len : current_idx + w_len + b_len]
            current_idx += w_len + b_len
            
            # Reshape labels to original shapes
            w_indices = w_labels.reshape(w.shape)
            b_indices = b_labels.reshape(b.shape)
            
            mlp_indices.append({

                'bias_indices': b_indices
            })
            
        index_maps[layer_idx] = mlp_indices

    # Step 4 & 5: Fine-tune global table
    # Fix indices, optimize global_table values via backpropagation
    # This step is conceptual; implementation depends on the specific framework.
    # The indices are fixed, and gradients flow through the global_table lookups.
    
    return global_table, index_maps

**Edge Cases and Pitfalls:**
-   **Precision:** The choice of $\beta$ significantly impacts compression ratio and accuracy. $\beta=7$ is typical for small MLPs [S1].
-   **Boundary Artifacts:** While global quantization compresses parameters, it does not inherently solve boundary artifacts between disjoint volumetric blocks. This requires separate mitigation strategies (e.g., boundary artifact mitigation) [S1].
-   **Similarity Assumption:** The method relies on the assumption that different blocks contain similar content. If blocks are highly diverse, the global table may not provide significant compression benefits over local quantization [S1].

## Subtopics

### Vector Quantization
A general technique where input vectors are mapped to codebook entries. Global quantization is a specific application of vector quantization principles across multiple networks [S1].

### Scalar Quantization
Quantizes each parameter individually. Global quantization differs by sharing parameters across networks, whereas scalar quantization typically does not [S1].

### Chroma Subsampling
A technique for reducing color information. Not directly related to neural network parameter quantization [S1].

### Differentiable Quantization for Neural Fields
Allows gradients to flow through quantization operations. Global quantization uses fixed indices during fine-tuning, making it non-differentiable with respect to indices [S1].

### Neural Implicit Network Compression
A broad category including pruning and quantization. Global quantization is a specific compression method within this category [S1].

### Unquantization Functions
Functions that map quantized indices back to values. In global quantization, this is a simple lookup in the shared parameter table [S1].

## Operating characteristics
-   **Time Complexity:** The clustering step (k-means) is performed once during training/fine-tuning. The complexity depends on the number of parameters and clusters. Fine-tuning involves backpropagation through the shared table, which is comparable to standard training but with fewer unique parameters.
-   **Memory Complexity:** The memory footprint is dominated by the global shared parameter table ($2^\beta$ values per layer) and the index maps ($\beta$ bits per parameter). This is significantly smaller than storing full-precision weights for each MLP [S1].
-   **Measured Performance:** On the asteroids dataset, ECNR (with global quantization) achieved a PSNR of 40.59 dB with a model size of 0.49 MB, compared to 40.24 dB and 0.93 MB for standard local quantization (ECNR*) [S1]. On the supernova-1 dataset, ECNR achieved 48.55 dB PSNR with 1.5 MB, compared to 44.86 dB and 1.5 MB for ECNR* (note: model size was controlled to be similar for supernova-1, but PSNR was higher) [S1].
-   **Strengths:** Higher compression ratios due to parameter sharing across similar blocks; minimal performance degradation after fine-tuning [S1].
-   **Limitations:** Requires fine-tuning to recover accuracy; assumes similarity across blocks; not suitable for highly diverse data without significant accuracy loss [S1].
-   **When to Use:** When encoding multiple independent small MLPs for volumetric data where blocks share similar content, and high compression is desired [S1].
-   **When Not to Use:** When blocks are highly diverse, or when fine-tuning time is prohibitive [S1].

## Background
Global quantization was introduced in the context of Efficient Compressive Neural Representation (ECNR) for time-varying volumetric datasets [S1]. It builds on prior work in network quantization, such as neurcomp [24], but extends it to multiple independent small MLPs [S1]. The method was developed to address the limitations of standard pruning and local quantization, which resulted in larger model sizes for similar accuracy [S1]. The approach leverages the structure of ECNR, where each scale consists of multiple MLPs encoding distinct blocks [S1].
