# Rate-Distortion Joint Finetuning

Also called: Joint Rate-Distortion Optimization for Neural Fields, RD Joint Finetuning

## Overview
Rate-Distortion Joint Finetuning is a training methodology that treats neural network compression and 3D scene representation as a single, unified optimization problem, simultaneously optimizing the model for bitrate efficiency and rendering distortion [S1]. Unlike prior methods that treat compression and scene representation as independent stages, this approach integrates a differentiable entropy model directly into the loss function, allowing the network to adapt its feature distributions to minimize the Lagrangian cost of transmission and reconstruction [S1]. It builds on [JointRF Training Procedure](11657-jointrf-training-procedure.md) by introducing specific mechanisms for handling quantization gradients and hierarchical importance weighting [S1].

## How it works
The method operates by modifying the standard training loop of a voxel-based NeRF to include a differentiable rate term [S1]. It relies on predictive coding, where each voxel's value is predicted from a reference neighbor (typically the preceding voxel in a traversal order) to minimize the residual entropy [S1].

### Inputs and Outputs
*   **Inputs:** A voxel-based NeRF model (feature grid), a set of training images with camera poses, a reference graph $G$ defining prediction dependencies, and a quantization step size $Q_{step}$ [S1].
*   **Outputs:** A quantized feature grid and associated entropy model parameters that minimize the combined rate-distortion loss [S1].

### Data Structures
*   **Feature Grid:** A 3D grid of feature vectors $v$ [S1]. Each voxel $v_i$ is associated with a reference voxel $v_j$ from the reference graph $G$ [S1].
*   **Reference Graph $G$:** A directed graph where edges $(v_i, v_j)$ indicate that $v_j$ is used to predict $v_i$ [S1]. In the basic implementation, $v_j$ is the preceding voxel in the decoding order [S1].
*   **Critical Voxels Set $C$:** A subset of voxels identified as critical for rendering quality, used in the two-step finetuning variant [S1].

### Numbered Steps

1.  **Predictive Coding Setup:** Define a reference graph $G$ where each voxel $v_i$ has a reference $v_j$. For training convenience, only complete voxels are used as references, avoiding interpolation [S1].
2.  **Forward Pass with Quantization Simulation:**
    *   Compute the raw feature vector $x$ for a voxel [S1].
    *   Simulate uniform quantization by adding uniform noise to the gradient path. Let $\hat{x}$ be the quantized value. The differentiable surrogate $\tilde{x}$ is computed as:
        $$ \tilde{x} = \hat{x} + U\left(-\frac{1}{2Q_{step}}, \frac{1}{2Q_{step}}\right) $$
        where $U$ denotes the uniform distribution and $Q_{step}$ is the quantization step size [S1].
    *   Compute the prediction residual $y = \tilde{x} - \tilde{x}_{ref}$, where $\tilde{x}_{ref}$ is the quantized reference feature [S1].
3.  **Rate Estimation:**
    *   Assume the residual $y$ follows an exponential distribution $EXP(\epsilon)$. The bitrate $R$ is estimated as the negative log-likelihood of the residual [S1]:
        $$ R = E_{y \sim EXP(\epsilon)} [-\log(p(y))] = \kappa E[|y|] + \beta $$
        where $\kappa$ and $\beta$ are constants derived from the exponential distribution parameters [S1].
    *   Assuming the quantization error is uniformly distributed, the expected absolute residual is approximated by the expected absolute difference between the raw features divided by the quantization step:
        $$ E[|y|] = E[|\hat{x} - \hat{x}_{ref}|] \approx E[|\tilde{x} - \tilde{x}_{ref}|] = \frac{E[|x - x_{ref}|]}{Q_{step}} $$
    *   Discard constant terms ($\beta$ and terms absorbed by $\lambda$) to simplify the rate loss $R_{loss}$ for optimization [S1]. The rate loss becomes the mean L1 distance of residuals over the reference graph edges [S1]:
        $$ R_{loss} = \frac{1}{|G|} \sum_{(v_i, v_j) \in G} \|v_i - v_j\|_1 $$
        where $|G|$ is the number of edges in $G$ [S1].
4.  **Loss Computation:**
    *   Compute the distortion loss $D$ using the original method's loss function (e.g., MSE between rendered and ground truth pixels) [S1].
    *   Compute the total loss using a Lagrangian multiplier $\lambda$:
        $$ \text{Loss} = \lambda \times R_{loss} + D $$
        $\lambda$ balances the trade-off between bitrate and distortion [S1].
5.  **Backpropagation:**
    *   Backpropagate through the surrogate quantization step $\tilde{x}$ to update the network weights [S1]. The gradient flows through the uniform noise addition, effectively treating the quantization error as a regularizer [S1].

### Pseudocode

```python
def rate_distortion_joint_finetuning(model, data_loader, lambda_param, q_step, reference_graph):
    """
    Performs joint rate-distortion finetuning for a voxel-based NeRF.
    
    Args:
        model: The neural network model (e.g., TensoRF-VM feature grid).
        data_loader: Iterator yielding batches of (images, camera_poses).
        lambda_param: Lagrangian multiplier for rate-distortion trade-off.
        q_step: Quantization step size for uniform quantization simulation.
        reference_graph: List of tuples (i, j) indicating voxel i is predicted from voxel j.
        
    Returns:
        Trained model parameters.
    """
    # Initialize optimizer state (e.g., Adam with lr=1e-3)
    optimizer = create_optimizer(model.parameters(), lr=1e-3)
    
    for batch in data_loader:
        images, poses = batch
        zero_gradients(model)
        
        # 1. Forward pass to get raw features
        raw_features = model.get_features(poses)
        
        # 2. Simulate Quantization with Uniform Noise
        # Quantize raw features (simulated)
        quantized_features = [round(v / q_step) * q_step for v in raw_features]
        
        # Add uniform noise for backpropagation: U(-1/2Qstep, 1/2Qstep)
        noise = [random.uniform(-0.5 * q_step, 0.5 * q_step) for _ in raw_features]
        differentiable_features = [q + n for q, n in zip(quantized_features, noise)]
        
        # 3. Compute Rate Loss (Predictive Coding)
        # Gather reference features based on reference_graph
        ref_indices = [j for i, j in reference_graph]
        pred_indices = [i for i, j in reference_graph]
        
        ref_features = [differentiable_features[idx] for idx in ref_indices]
        pred_features = [differentiable_features[idx] for idx in pred_indices]
        
        # Compute L1 residuals
        residuals = [abs(p - r) for p, r in zip(pred_features, ref_features)]
        
        # Rate loss is mean L1 of residuals
        # Constants kappa and beta are absorbed into lambda or discarded
        rate_loss = sum(residuals) / len(residuals)
        
        # 4. Compute Distortion Loss
        # Render images from differentiable features
        rendered_images = model.render(poses, differentiable_features)
        
        # Distortion loss (e.g., MSE)
        distortion_loss = sum((r - t)**2 for r, t in zip(rendered_images, images)) / len(images)
        
        # 5. Total Loss
        total_loss = lambda_param * rate_loss + distortion_loss
        
        # 6. Backpropagation
        gradients = compute_gradients(total_loss, model)
        update_parameters(model, gradients, optimizer)
        
    return model.parameters()
```

### Parameters
*   **$\lambda$ (Lagrangian Multiplier):** Balances bitrate and distortion. Adjusting $\lambda$ generates different points on the Rate-Distortion (RD) curve [S1].
*   **$Q_{step}$ (Quantization Step):** Determines the granularity of quantization. Larger steps increase rate loss but may degrade distortion if not compensated by finetuning [S1].

### Edge Cases and Pitfalls
*   **Gradient Vanishing:** Standard quantization has zero gradients almost everywhere [S1]. The uniform noise substitution is critical to enable backpropagation [S1].
*   **Large Quantization Steps:** Large $Q_{step}$ values can lead to unacceptable performance loss despite the noise injection [S1]. This necessitates the Two-step Finetuning Procedure for critical voxels [S1].
*   **Reference Selection:** The choice of reference graph $G$ affects the residual distribution [S1]. Using the preceding voxel is a simple baseline; more refined spatial predictive coding may use interpolation, but complete voxels are preferred for training stability [S1].

## Subtopics

### [Neural NeRF Compression (Per-Scene, Encoder-Free)](17064-neural-nerf-compression-per-scene-encoder-free.md)
A method for compressing grid-based NeRF models (specifically TensoRF-VM) by optimizing latent codes directly for individual scenes without an encoder, using a lightweight decoder and a masked entropy model to minimize rate-distortion loss. It differs from previous works (Li et al., 2023a;b; Deng & Tartaglione, 2023) which use voxel pruning and/or vector quantization, by taking into account varying importance levels of voxel grid locations via importance-weighted objectives and masking.

### Two-step Finetuning Procedure
A procedure to handle large quantization steps by performing precise quantization only for critical voxels, combining hierarchical quantization with finetuning to maximize bit saving without excessive rendering degradation [S1].
**Steps:**
1.  **Initial Training:** Perform standard joint rate-distortion finetuning as described in the main method [S1].
2.  **Quantization and Reconstruction:** Quantize the feature grid and dequantize to reconstruct a coarse feature grid [S1].
3.  **Critical Voxel Identification:** Identify critical voxels $C$ that are most important for rendering quality [S1].
4.  **Post Finetuning:** Freeze all non-critical voxels in the feature grid [S1]. Finetune the remaining parameters (critical voxels) and the non-pruned volume density and RGB networks to compensate for quantization loss [S1].
**Rate Formula for Critical Voxels:**
The rate for critical voxels is modeled as the residual bits relative to the coarse grid:
$$ R = \frac{1}{|C|} \sum_{v_i \in C} \|v_i - \hat{v}_i\|_1 $$
where $C$ is the set of all critical voxels, and $\hat{v}_i$ denotes the feature voxel in the coarse grid [S1].

## Operating characteristics
*   **Time Complexity:** Training time increases due to the additional computation of residuals and the potential two-step finetuning process [S1]. The rate loss calculation is linear in the number of voxels and edges in the reference graph [S1].
*   **Memory Complexity:** Requires storing the feature grid and the reference graph [S1]. The two-step procedure requires maintaining both the fine and coarse grids during the post-finetuning phase [S1].
*   **Performance:** By jointly optimizing rate and distortion, the method achieves better RD curves compared to methods that treat compression and representation independently [S1]. The two-step procedure allows for larger quantization steps (higher compression) without significant quality loss on critical structures [S1].
*   **Strengths:** End-to-end optimization of compression and rendering; differentiable entropy model avoids complex entropy coding during training; hierarchical approach handles varying voxel importance [S1].
*   **Limitations:** Requires careful tuning of $\lambda$ and $Q_{step}$; performance may degrade if critical voxel selection is inaccurate; relies on predictive coding which may not be optimal for all scene structures [S1].

## Background
Rate-Distortion Joint Finetuning was introduced in the context of Spatial Predictive Compression for Voxel-Based Radiance Fields (SPC-NeRF) [S1]. The work addresses the limitation of existing NeRF compression techniques that treat compression and 3D-scene representation as two independent optimization problems, which reduces compression performance and limits effectiveness across a wider bitrate range [S1]. The method leverages the observation that voxels are not equally important to rendering results, leading to the development of the two-step finetuning procedure for hierarchical quantization [S1].
