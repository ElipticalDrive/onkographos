# Neural Network Parameter Quantization

Also called: Neural Field Quantization, INR Compression

## Overview
Neural Network Parameter Quantization reduces the memory footprint of neural field representations (such as Neural Radiance Fields or Implicit Neural Representations) by mapping continuous network weights or grid parameters to discrete, low-bit indices. It solves the storage and I/O bottlenecks of high-resolution volumetric data by replacing raw grids or large MLP weight matrices with compact quantized representations . It differs from standard post-training quantization by integrating quantization into the optimization process (e.g., via differentiable estimators) or by sharing parameters across multiple local networks to exploit redundancy, thereby preventing the reconstruction quality drops associated with naive discretization .

## Shared principles
This family operates on the output of the [Quantization](5935-quantization.md) pipeline. While [Quantization](5935-quantization.md) defines the general mapping of continuous values to discrete indices, Neural Network Parameter Quantization specifically targets the weights of coordinate-based MLPs or the parameters of neural field grids. The core mechanism involves defining a quantization function $Q(x)$ that maps real-valued weights or features to a discrete set of representatives (centroids or indices), and an inverse function for reconstruction. The choice of strategy—whether differentiable training-time quantization, post-training clustering, or global sharing—determines the trade-off between compression ratio and reconstruction fidelity .

## Subtopics

### [Differentiable Quantization for Neural Fields](10195-differentiable-quantization-for-neural-fields.md)
Uses straight-through estimators to quantize grid values to uint8 during optimization, preventing quality loss from post-training discretization. Choose when memory is constrained but training-time optimization is feasible.

### [Neural Implicit Network Compression](10414-neural-implicit-network-compression.md)
Applies k-means clustering to SIREN MLP weights post-training to compress scientific volumetric data. Choose when dealing with static scientific fields and interactive rendering speed is not the primary constraint.

### [Global Quantization](15134-global-quantization.md)
Shares a single parameter table across all MLPs in a spatial scale via clustering, reducing redundancy. Choose when multiple local networks encode similar content and significant compression is needed without retraining from scratch.

## Background
Originating from the need to compress neural fields for efficient storage and transmission, this approach was developed to address the large memory footprint of high-resolution neural representations . It builds on [Value compression](6-value-compression.md) and [Quantization](5935-quantization.md) principles, adapting them for the specific architectures of neural fields (MLPs and grids) .
