# Global Quantization

Also called: Global shared parameter table quantization

## Overview
Global quantization is a parameter compression strategy for neural volume representations that maintains a single shared parameter table across multiple independent small Multi-Layer Perceptrons (MLPs) within a single scale, rather than quantizing each network locally [S1]. It solves the redundancy problem where distinct spatial blocks often contain similar content, allowing different MLPs to map to the same set of floating-point parameters [S1]. It sets itself apart from local quantization by leveraging cross-MLP similarity to achieve higher compression ratios for similar reconstruction accuracy [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of independent small MLPs (one per spatial block) within a specific scale, each containing unpruned weights and biases.
*   **Output:** A single global shared parameter table (codebook) of floating-point values and a set of $\beta$-bit indices for each MLP mapping to these shared values.

**Data Structures:**
1.  **Global Shared Parameter Table:** A list of $2^\beta$ floating-point values. These are the representative values for the quantized weights and biases.
2.  **Index Map:** For each MLP, a mapping from its original weight/bias positions to indices in the Global Shared Parameter Table. These indices are $\beta$-bit integers.

**Parameters:**
*   $\beta$: The quantization precision in bits. Typical value: 7 [S1]. This determines the size of the shared codebook ($2^\beta$ entries).

**Steps:**
1.  **Global Clustering:** Apply standard k-means clustering to group the unpruned weights and biases of *all* MLPs within a single scale together. The number of clusters is $2^\beta$ [S1].
2.  **Index Assignment:** Represent the weights and biases of each MLP as $\beta$-bit indices that map to the $2^\beta$ shared floating-point parameters derived from the cluster centroids [S1].
3.  **Fine-Tuning:** Fix the parameter indices (the mapping from MLP positions to codebook entries) and fine-tune the corresponding shared parameters through backpropagation to minimize performance degradation (e.g., reconstruction error) at the same precision [S1].
4.  **Entropy Encoding (Optional Post-Processing):** Apply lossless entropy encoding (e.g., Huffman coding) to the resulting model file (indices and shared parameters) to achieve additional size reduction (empirically ~10%) [S1].

import numpy as np
from sklearn.cluster import KMeans

def global_quantization(mlp_params_list, beta):
    """
    Perform global quantization on a list of MLP parameter tensors.
    
    Args:
        mlp_params_list: List of lists of tensors. 
                         mlp_params_list[i] contains [weights, biases] for MLP i.
        beta: Quantization precision in bits.
        
    Returns:
        shared_params: Array of shape (2**beta, ) containing the global shared parameters.
        indices_list: List of index arrays for each MLP, mapping original params to shared_params.
    """
    # 1. Flatten and concatenate all weights and biases from all MLPs in the scale
    all_params = []
    for mlp_params in mlp_params_list:
        for param in mlp_params:
            all_params.append(param.flatten())
    
    all_params_flat = np.concatenate(all_params)
    
    # 2. Apply k-means clustering to group parameters into 2^beta clusters
    n_clusters = 2 ** beta
    kmeans = KMeans(n_clusters=n_clusters, random_state=42, n_init=10)
    kmeans.fit(all_params_flat.reshape(-1, 1))
    
    # 3. Get the cluster centers as the shared parameters
    shared_params = kmeans.cluster_centers_.flatten()
    
    # 4. Assign indices to each original parameter based on cluster labels
    labels = kmeans.labels_
    
    # We need to reconstruct the index mapping for each MLP
    # First, determine the offset of each MLP's parameters in the concatenated array
    indices_list = []
    current_offset = 0
    
    for mlp_params in mlp_params_list:
        mlp_indices = []
        for param in mlp_params:
            param_size = param.size
            # Get the labels for this specific parameter's flattened values
            param_labels = labels[current_offset : current_offset + param_size]
            # Reshape to match original tensor shape
            param_indices = param_labels.reshape(param.shape)
            mlp_indices.append(param_indices)
            current_offset += param_size
        indices_list.append(mlp_indices)
        
    return shared_params, indices_list

**Edge Cases and Pitfalls:**
*   **Precision:** The choice of $\beta$ directly impacts the codebook size ($2^\beta$). A small $\beta$ may lead to high quantization error if the data distribution is complex [S1].
*   **Boundary Artifacts:** While global quantization compresses parameters, it does not inherently solve boundary artifacts between disjoint volumetric blocks; this requires separate mitigation strategies (e.g., boundary artifact mitigation) [S1].
*   **Clustering Convergence:** K-means may converge to local minima. Multiple initializations or careful initialization may be needed [S1].

## Operating characteristics
*   **Time Complexity:** Dominated by the k-means clustering step on the concatenated parameters of all MLPs in a scale. Fine-tuning adds iterative backpropagation cost.
*   **Memory Complexity:** The model size is determined by the size of the global shared parameter table ($2^\beta$ floats) plus the storage for the $\beta$-bit indices for each parameter in all MLPs. This is significantly smaller than storing full precision parameters for each MLP [S1].
*   **Performance:** ECNR with global quantization achieves a model size of 0.49 MB vs 0.93 MB for local quantization (ECNR*) on the asteroids dataset with similar PSNR (40.59 dB vs 40.24 dB) [S1]. On supernova-1, it achieves 48.55 dB PSNR vs 44.86 dB for local quantization at the same model size (1.5 MB) [S1].
*   **Strengths:** Higher compression ratio for similar accuracy; leverages redundancy across spatial blocks [S1].
*   **Limitations:** Requires fine-tuning to recover performance; clustering cost scales with the number of parameters [S1].

## Background
Global quantization was introduced in the context of ECNR (Efficient Compressive Neural Representation) for time-varying volumetric datasets [S1]. It addresses the limitation of prior quantization approaches that focused on single neural networks, extending the concept to multiple independent small MLPs [S1]. The method was developed to improve the compression efficiency of neural volume representations by exploiting the similarity of content across different spatial blocks [S1].
