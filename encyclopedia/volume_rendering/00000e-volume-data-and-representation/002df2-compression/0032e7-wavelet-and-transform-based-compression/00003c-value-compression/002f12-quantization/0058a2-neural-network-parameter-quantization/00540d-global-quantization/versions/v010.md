# Global Quantization

Also called: Global shared parameter table quantization

## Overview
Global quantization is a parameter compression strategy for neural volume representations that maintains a single shared parameter table across multiple independent small Multi-Layer Perceptrons (MLPs) within a single scale, rather than quantizing each network locally [S1]. It solves the redundancy problem where distinct spatial blocks often contain similar content, allowing different MLPs to map to the same set of floating-point parameters [S1]. It sets itself apart from local quantization by leveraging cross-MLP similarity to achieve higher compression ratios for similar reconstruction accuracy [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of independent small MLPs (one per spatial block) within a specific scale, each containing unpruned weights and biases [S1].
*   **Output:** A single global shared parameter table (codebook) of floating-point values and a set of $\beta$-bit indices for each MLP mapping to these shared values [S1].

**Data Structures:**
1.  **Global Shared Parameter Table:** A list of $2^\beta$ floating-point values representing the cluster centroids for quantized weights and biases [S1].
2.  **Index Map:** For each MLP, a mapping from its original weight/bias tensor positions to indices in the Global Shared Parameter Table, stored as $\beta$-bit integers [S1].

**Parameters:**
*   $\beta$: The quantization precision in bits, determining the codebook size ($2^\beta$ entries) [S1]. Typical value: 7 [S1].

**Steps:**
1.  **Global Clustering:** Concatenate the unpruned weights and biases of all MLPs within a single scale and apply standard k-means clustering to group them into $2^\beta$ clusters [S1].
2.  **Index Assignment:** Represent the weights and biases of each MLP as $\beta$-bit indices that map to the $2^\beta$ shared floating-point cluster centroids [S1].
3.  **Fine-Tuning:** Fix the parameter indices (the mapping from MLP positions to codebook entries) and fine-tune the corresponding shared parameters through backpropagation to minimize performance degradation at the same precision [S1].
4.  **Entropy Encoding (Optional Post-Processing):** Apply lossless entropy encoding (e.g., Huffman coding) to the resulting model file (indices and shared parameters) to achieve an additional ~10% model size reduction [S1].

**Pseudocode:**

```python
import numpy as np

def global_quantization(mlp_params_list, beta):
    """
    Perform global quantization on a list of MLP parameter tensors.
    
    Args:
        mlp_params_list: List of lists of numpy arrays. 
                         mlp_params_list[i] contains [weights, biases] for MLP i.
        beta: Quantization precision in bits.
        
    Returns:
        shared_params: Array of shape (2**beta,) containing the global shared parameters.
        indices_list: List of index arrays for each MLP, mapping original params to shared_params.
    """
    n_clusters = 2 ** beta
    # 1. Flatten and concatenate all weights and biases from all MLPs in the scale
    all_params = np.concatenate([p.flatten() for mlp in mlp_params_list for p in mlp])
    
    # 2. Initialize centroids randomly from the data
    init_indices = np.random.choice(len(all_params), n_clusters, replace=False)
    centroids = all_params[init_indices].copy()
    
    # 3. Standard k-means clustering
    for _ in range(100):
        # Compute distances to all centroids
        dists = np.abs(all_params[:, None] - centroids[None, :])
        labels = np.argmin(dists, axis=1)
        # Update centroids
        new_centroids = np.zeros_like(centroids)
        for k in range(n_clusters):
            mask = labels == k
            if np.any(mask):
                new_centroids[k] = all_params[mask].mean()
            else:
                new_centroids[k] = centroids[k]
        if np.allclose(centroids, new_centroids):
            break
        centroids = new_centroids
        
    # 4. Assign indices to each original parameter based on cluster labels
    indices_list = []
    offset = 0
    for mlp in mlp_params_list:
        mlp_indices = []
        for p in mlp:
            size = p.size
            p_labels = labels[offset:offset+size]
            mlp_indices.append(p_labels.reshape(p.shape))
            offset += size
        indices_list.append(mlp_indices)
        
    return centroids, indices_list

def fine_tune_shared_params(shared_params, indices_list, mlp_params_list, learning_rate, epochs):
```

**Edge Cases and Pitfalls:**
*   **Precision:** The choice of $\beta$ directly impacts the codebook size ($2^\beta$) and reconstruction fidelity [S1].
*   **Boundary Artifacts:** Global quantization compresses parameters but does not inherently resolve boundary artifacts between disjoint volumetric blocks, requiring separate mitigation strategies [S1].
*   **Clustering Convergence:** K-means may converge to local minima depending on initialization [G].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** The model size is determined by the size of the global shared parameter table ($2^\beta$ floats) plus the storage for the $\beta$-bit indices for each parameter in all MLPs [S1].
*   **Performance:** On the asteroids dataset, ECNR achieves 40.59 dB PSNR at 0.49 MB, compared to 40.24 dB at 0.93 MB for local quantization (ECNR*) [S1]. On the supernova-1 dataset, ECNR achieves 48.55 dB PSNR at 1.5 MB, compared to 44.86 dB for local quantization at the same model size [S1].
*   **Strengths:** Higher compression ratio for similar accuracy by leveraging redundancy across spatial blocks [S1].
*   **Limitations:** Requires fine-tuning to recover performance; clustering cost scales with the number of parameters [S1].

## Background
Global quantization was introduced in the context of ECNR (Efficient Compressive Neural Representation) for time-varying volumetric datasets [S1]. It addresses the limitation of prior quantization approaches that focused on single neural networks, extending the concept to multiple independent small MLPs [S1]. The method was developed to improve the compression efficiency of neural volume representations by exploiting the similarity of content across different spatial blocks [S1].
