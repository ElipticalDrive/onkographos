# Neural Network Parameter Quantization

Also called: Neural Field Quantization, INR Weight Quantization, Global Quantization for Neural Volumes

## Overview
Neural Network Parameter Quantization reduces the memory footprint of neural volume representations (such as Neural Radiance Fields and Implicit Neural Representations) by discretizing network weights or grid parameters. It addresses the high storage cost of continuous floating-point parameters in large-scale volumetric models. It differs from sibling methods like [Scalar Quantization](5726-scalar-quantization.md) by often employing learned or clustering-based mappings tailored to neural network statistics, and from [Vector Quantization](907-vector-quantization.md) by typically operating on individual weight elements or shared global tables rather than vector codebooks.

## Shared principles
This family operates on the output of the [Quantization](5935-quantization.md) pipeline. While [Quantization](5935-quantization.md) defines the general mapping of continuous values to discrete indices, Neural Network Parameter Quantization specifically targets the weights of Multi-Layer Perceptrons (MLPs) or grid-based parameters in neural fields. The core mechanism involves replacing continuous floating-point parameters with discrete representations (indices or low-bit values) to enable storage and transmission efficiency. The choice of quantization strategy (differentiable during training, post-training clustering, or global sharing) determines the trade-off between compression ratio and reconstruction fidelity.

## Subtopics

### [Differentiable Quantization for Neural Fields](10195-differentiable-quantization-for-neural-fields.md)
Integrates quantization into the training loop using the Straight-Through Estimator to avoid post-training quality degradation. It uses per-dimension affine scaling and sigmoid mapping. Choose when real-time training optimization is required for neural radiance fields.

### [Neural Implicit Network Compression](10414-neural-implicit-network-compression.md)
Applies Implicit Neural Representations (INRs) to compress scientific volume data using SIREN MLPs with k-means weight quantization. It eliminates the need for full bitstream decoding before visualization. Choose for high-ratio compression of scalar fields where interactive rendering is not required.

### [Global Quantization](15134-global-quantization.md)
Maintains a single shared parameter table for all independent small MLPs within a specific scale. It addresses redundancy across spatial blocks by sharing quantized parameters. Choose when distinct spatial blocks contain similar content and significant model size reduction is needed.

## Background
The application of quantization to neural volume representations emerged with the rise of Neural Radiance Fields (NeRF) and Implicit Neural Representations (INRs) for 3D scene representation. Early methods focused on post-training quantization, which often led to significant quality drops due to the mismatch between optimized continuous models and discrete inference models . Subsequent research introduced differentiable quantization techniques to integrate discretization into the optimization process . Other approaches, such as Neural Implicit Network Compression, adapted these techniques for scientific volume data, demonstrating the viability of INRs as compressed storage formats . Global quantization further optimized this by sharing parameters across multiple MLPs to exploit spatial redundancy .
