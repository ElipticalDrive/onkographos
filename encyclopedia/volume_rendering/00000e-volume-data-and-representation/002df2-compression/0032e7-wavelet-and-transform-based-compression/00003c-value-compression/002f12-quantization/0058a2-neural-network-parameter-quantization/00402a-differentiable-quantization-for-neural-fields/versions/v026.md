# Differentiable Quantization for Neural Fields

Also called: MERF Quantization, Quantization for Memory Reduction

## Overview
This method reduces the render-time memory footprint of neural radiance fields by quantizing grid-based feature and density values to single bytes during the optimization process [S1]. Unlike post-training quantization, which causes quality degradation due to the mismatch between the optimized continuous model and the discrete inference model, this approach integrates quantization into the training loop [S1]. It sets itself apart from siblings like [Global Quantization](15134-global-quantization.md) by applying per-dimension byte quantization with specific affine scaling factors tailored to the data distribution (density vs. color) rather than a global uniform range [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Continuous grid values $\tilde{\mathbf{t}}$ (densities, diffuse colors, or features) optimized during training.
*   **Output:** Quantized grid values $\tilde{\mathbf{t}}'$ stored as single bytes, which are affinely mapped back to a specific range for rendering.

**Data Structures:**
*   Grid values are stored as single-byte integers (uint8) in memory.
*   During forward pass, these bytes are converted to floats and scaled.

**Parameters:**
*   $m$: Scaling factor for affine mapping.
    *   $m = 14$ for densities (computed using exponential nonlinearity) [S1].
    *   $m = 7$ for diffuse colors and features [S1].
*   $B = 2^8 - 1 = 255$: Number of quantization levels [S1].

**Quantization Function:**
The core operation maps continuous values to bytes and back, using a Straight-Through Estimator (STE) to allow gradients to flow through the non-differentiable rounding operation [S1].

1.  **Sigmoid Mapping:** Map input $\tilde{\mathbf{t}}$ to $[0, 1]$ using a sigmoid function $\sigma(\cdot)$ [S1].
    $$ x = \sigma(\tilde{\mathbf{t}}) $$
2.  **Quantization:** Round $x$ to the nearest of $2^8$ levels. The quantization function $q(x)$ is defined as:
    $$ q(x) = x + \mathcal{V}\left(\frac{\lfloor (2^8 - 1)x + 1/2 \rfloor}{2^8 - 1} - x\right) $$
    Where $\mathcal{V}$ is the Straight-Through Estimator operator, which returns the gradient of the identity function for the input $x$, effectively bypassing the gradient of the rounding term $\frac{\lfloor (2^8 - 1)x + 1/2 \rfloor}{2^8 - 1} - x$ [S1].
3.  **Affine Mapping:** Map the quantized value $q(x)$ to the range $[-m, m]$:
    $$ \tilde{\mathbf{t}}' = 2m \cdot q(\sigma(\tilde{\mathbf{t}})) - m $$
    This $\tilde{\mathbf{t}}'$ is the value stored in the grid and used for interpolation during rendering [S1].

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

def sigmoid_quantize(t, m):
    """
    Quantizes grid values t to single bytes during optimization.
    
    Args:
        t: Continuous tensor of grid values.
        m: Scaling factor (14 for density, 7 for color/features).
        
    Returns:
        Quantized and affine-mapped tensor t_prime.
    """
    # 1. Sigmoid mapping to [0, 1]
    x = torch.sigmoid(t)
    
    # 2. Quantization to byte levels [0, 255]
    # Calculate the nearest integer level
    levels = 2**8 - 1  # 255
    quantized_float = (torch.floor((levels * x) + 0.5) / levels)
    
    # 3. Straight-Through Estimator (STE)
    # The gradient flows through 'x' (the input to quantization),
    # ignoring the gradient of the floor operation.
    quantized_ste = x + (quantized_float - x).detach()
    
    # 4. Affine mapping to [-m, m]
    t_prime = 2 * m * quantized_ste - m
    
    return t_prime

# Example usage during training step:
# t_quantized = sigmoid_quantize(t_continuous, m=14) # for density
# t_quantized = sigmoid_quantize(t_continuous, m=7)  # for color/features
```

**Edge Cases and Pitfalls:**
*   **Post-training Quantization:** Simply quantizing grid values after training converges causes a significant drop in rendering quality due to the mismatch between the optimized model and the quantized inference model [S1].
*   **Non-linearity Application:** The non-linearities defined in the radiance field equations (e.g., exponential for density) are applied *after* linear interpolation and summation of the quantized values, not before [S1].

## Subtopics

### [Quantization-Aware Fine-Tuning](11387-quantization-aware-fine-tuning.md)
A post-clustering optimization step to recover quality lost during vector quantization. It differs by fine-tuning scene parameters while simulating low-precision quantization during the forward pass to obtain stable gradients.

## Operating characteristics
*   **Memory:** Reduces grid memory consumption significantly by storing each dimension as a single byte [S1].
*   **Performance:** Enables real-time view synthesis in unbounded scenes by lowering memory bandwidth requirements [S1].
*   **Quality:** Maintains high rendering quality comparable to full-precision models when quantization is integrated during optimization, avoiding the quality drops associated with post-training quantization [S1].
*   **Limitations:** Requires careful tuning of the scaling factor $m$ for different data types (density vs. color) [S1].

## Background
This method was introduced in the MERF (Memory-Efficient Radiance Fields) paper for real-time view synthesis in unbounded scenes [S1]. It addresses the high memory consumption of neural radiance fields by baking content only in regions occupied by a proposal MLP and quantizing the grid values to bytes during optimization [S1].
