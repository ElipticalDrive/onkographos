# Neural Implicit Network Compression

Also called: Coordinate-based MLP Compression, SIREN-based INR Compression, neurcomp

## Overview
Neural Implicit Network Compression (NeurComp) represents scientific volume data using a coordinate-based Multi-Layer Perceptron (MLP), typically a SIREN, to map spatial coordinates directly to field values [S1, unofficial]. It solves the problem of high storage and I/O costs for large scientific volumes by providing a compact, queryable data source that serves as simultaneously compressed storage and a reconstruction engine [S1, unofficial]. It sets itself apart from traditional lossy compressors like SZ or ZFP, which produce bitstreams requiring full decoding before visualization, by allowing direct querying of the implicit representation [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A 3D scalar field defined on a grid of size $N^3$ (e.g., $512^3$).
- Output: A trained neural network (MLP) that approximates the field values $f(x, y, z)$ for any coordinate $(x, y, z)$.

**Data Structures:**
- The primary data structure is the neural network weights.
- NeurComp uses a SIREN MLP with residual connections.
- Weights are quantized to 9 bits using k-means clustering [S1, unofficial].

**Steps:**
1. **Sampling:** Sample spatial coordinates $(x_j, y_j, z_j)$ from the volume grid.
2. **Encoding:** Apply positional or hash encoding $\gamma(x)$ to the coordinates [S1, unofficial].
3. **Training:** Train the SIREN MLP to minimize the reconstruction error between the network output and the sampled field values $v_j$.
4. **Regularization (Optional):** Apply an optional gradient regularization term to improve isosurface fidelity. This comes at the cost of a slight reduction in PSNR [S1, unofficial].
5. **Quantization:** Apply k-means clustering to the trained network weights to quantize them to 9 bits [S1, unofficial].

**Parameters:**
- Training time: Hours per volume on a V100 GPU [S1, unofficial].
- Weight quantization: 9 bits [S1, unofficial].

**Pitfalls:**
- The method could not render interactively from the volume due to the computational cost of querying the network [S1, unofficial].
- Training requires significant GPU time [S1, unofficial].

## Subtopics

### [Time-varying INR compression via Laplacian pyramid](10432-time-varying-inr-compression-via-laplacian-pyramid.md)
This method compresses time-varying volumetric datasets by decomposing the 4D space-time domain into a Laplacian pyramid and representing each spatial block at each scale with a separate Implicit Neural Representation (INR). It sets itself apart from centralized INR approaches like [Neural Implicit Network Compression](10414-neural-implicit-network-compression.md) by trading a single global model for multiple local models, which significantly accelerates decoding speeds while maintaining reconstruction quality.

### MVNet
MVNet is a method for compressing multivariate data by formulating it as multi-task learning, using a Residual SIREN with a v-dimensional output layer sharing intermediate parameters across variables [S1, unofficial]. It uses a Residual SIREN with a v-dimensional output layer (v = number of physical variables) and shares all intermediate parameters across variables [S1, unofficial]. It has only been tested on static datasets [S1, unofficial]. On a 100-variable climate dataset (1568 MB), MVNet achieved 49.68 dB PSNR at 1298:1 compression, outperforming TTHRESH (48.62 dB at 343:1) and preserving inter-variable statistical dependencies (Pearson correlation and mutual information) better than traditional compressors [S1, unofficial].

### KD-INR
KD-INR is a two-stage pipeline for compressing time-varying data: first compressing each timestep independently with a small INR, then merging all per-timestep teacher models into a single student via offline knowledge distillation [S1, unofficial]. Stage 1 involves compressing each timestep independently with a small INR with bottleneck layers and using entropy-based adaptive sampling to concentrate training on high-information blocks [S1, unofficial]. Stage 2 merges all per-timestep teacher models into a single student via offline knowledge distillation (an O(n) procedure) [S1, unofficial]. On time-varying datasets up to 23.44 GB (argon bubble, 150 timesteps), KD-INR outperformed CoordNet, NeurComp, and SIREN at compression ratios from 733 to 10,000, with per-timestep compression requiring 1–6 minutes on a single GPU [S1, unofficial].

## Operating characteristics
- **Compression Performance:** On scalar fields up to $512^3$, NeurComp outperformed tensor decomposition (TTHRESH) at high compression ratios, achieving 47.9 dB PSNR at 545:1 compression on the Rayleigh-Taylor dataset [S1, unofficial].
- **Training Time:** Training required hours per volume on a V100 GPU [S1, unofficial].
- **Rendering:** The method could not render interactively from the volume [S1, unofficial].
- **Strengths:** Provides a compact, queryable representation that serves as both storage and data source [S1, unofficial].
- **Limitations:** High training time and lack of interactive rendering capability [S1, unofficial].

## Background
Neural Implicit Network Compression (NeurComp) is the first INR compression method for scientific volumes [S1, unofficial]. It uses a coordinate-based SIREN MLP with residual connections and 9-bit weight quantization via k-means clustering [S1, unofficial]. It was developed to address the strain on storage systems and I/O pipelines caused by full-resolution scientific volumes [S1, unofficial].
