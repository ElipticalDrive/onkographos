# Neural Implicit Network Compression

Also called: Coordinate-based MLP Compression, SIREN-based INR Compression, neurcomp

## Overview
Neural Implicit Network Compression (NeurComp) is a method for compressing scientific volumetric data by training a coordinate-based Multi-Layer Perceptron (MLP) to map spatial coordinates directly to field values [S1, unofficial]. It serves as both a compressed storage format and a queryable data source, eliminating the need for full decoding before visualization [S1, unofficial]. Unlike traditional lossy compressors that produce bitstreams requiring complete decoding, NeurComp represents the volume as a compact neural network [S1, unofficial]. It distinguishes itself from sibling methods like [Vector Quantization](907-vector-quantization.md) and [Scalar Quantization](5726-scalar-quantization.md) by using learned neural weights as the primary compression mechanism, rather than quantizing pre-transformed coefficients [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A scalar volumetric dataset $V$ defined on a regular grid of size $N \times N \times N$ (e.g., $512^3$).
*   **Output:** A trained SIREN MLP model with quantized weights, representing the compressed volume.

**Data Structures:**
*   **MLP Weights:** The network parameters are quantized to 9-bit precision using k-means clustering [S1, unofficial].
*   **Coordinates:** Sample points $(x_j, y_j, z_j)$ are drawn from the volume domain.
*   **Encoding:** Coordinates are processed via positional or hash encoding $\gamma(x)$ [S1, unofficial].

**Algorithm Steps:**
1.  **Sampling:** Generate a set of training samples consisting of spatial coordinates and their corresponding field values from the original volume $V$.
2.  **Network Architecture:** Initialize a SIREN (Sinusoidal Representation Network) MLP with residual connections [S1, unofficial].
3.  **Training:** Train the network to minimize the reconstruction error between the network output and the sampled field values.
    *   *Optional:* Apply a gradient regularization term to improve isosurface fidelity, accepting a slight reduction in PSNR [S1, unofficial].
4.  **Quantization:** Apply k-means clustering to the trained network weights to quantize them to 9-bit precision [S1, unofficial].
5.  **Storage:** Store the quantized weights as the compressed representation [S1, unofficial].

**Pseudocode:**
```python
def train_neurcomp(volume_grid, num_samples=100000):
    # 1. Sample coordinates and values
    # Generate random coordinates within the volume bounds
    coords = random_uniform_sample(volume_grid.shape, num_samples)
    # Trilinearly interpolate values at these coordinates
    values = trilinear_interpolate(volume_grid, coords)
    
    # 2. Initialize SIREN with residual connections
    # SIREN uses sine activation functions
    model = SIREN_MLP(residual=True)
    
    # 3. Training loop
    for epoch in range(max_epochs):
        # Forward pass
        encoded_coords = positional_encoding(coords)
        predicted_values = model(encoded_coords)
        
        # Loss function (MSE)
        loss = mean_squared_error(predicted_values, values)
        
        # Optional gradient regularization for isosurface fidelity
        # This adds a term penalizing differences in predicted gradients
        # compared to finite-difference gradients of the target field
        if use_gradient_reg:
            grad_loss = compute_gradient_regularization(model, coords, values)
            loss += lambda_grad * grad_loss
            
        # Backpropagation and weight update
        update_weights(model, loss)
        
    # 4. Quantize weights using k-means clustering to 9-bit
    quantized_weights = kmeans_quantize(model.weights, bits=9)
    
    return quantized_weights
```

**Parameters:**
*   **Weight Quantization Bits:** 9-bit [S1, unofficial].
*   **Hardware:** V100 GPU [S1, unofficial].
*   **Training Time:** Hours per volume [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Interactive Rendering:** The method cannot render interactively from the volume due to the computational cost of evaluating the network [S1, unofficial].
*   **Gradient Regularization:** Using gradient regularization improves isosurface fidelity but reduces PSNR [S1, unofficial].

## Subtopics

### [Time-varying INR compression via Laplacian pyramid](10432-time-varying-inr-compression-via-laplacian-pyramid.md)
This method compresses time-varying volumetric datasets by decomposing the 4D space-time domain into a Laplacian pyramid and representing each spatial block at each scale with a separate Implicit Neural Representation (INR). It sets itself apart from centralized INR approaches like [Neural Implicit Network Compression](10414-neural-implicit-network-compression.md) by trading a single global model for multiple local models, which significantly accelerates decoding speeds while maintaining reconstruction quality.

### MVNet
**Definition:** A method for compressing multivariate data by formulating it as multi-task learning, using a Residual SIREN with a v-dimensional output layer sharing intermediate parameters across variables [S1, unofficial].
**Steps:**
1.  Use a Residual SIREN with a v-dimensional output layer (where v is the number of physical variables) [S1, unofficial].
2.  Share all intermediate parameters across variables [S1, unofficial].
**Pitfalls:** Only tested on static datasets [S1, unofficial].
**Performance:** On a 100-variable climate dataset (1568 MB), MVNet achieved 49.68 dB PSNR at 1298:1 compression [S1, unofficial]. It outperforms TTHRESH (48.62 dB at 343:1) and preserves inter-variable statistical dependencies (Pearson correlation and mutual information) better than traditional compressors [S1, unofficial].

### KD-INR
**Definition:** A two-stage pipeline for compressing time-varying data: first compressing each timestep independently with a small INR, then merging all per-timestep teacher models into a single student via offline knowledge distillation [S1, unofficial].
**Steps:**
1.  **Stage 1:** Compress each timestep independently with a small INR with bottleneck layers [S1, unofficial].
2.  **Stage 1:** Use entropy-based adaptive sampling to concentrate training on high-information blocks [S1, unofficial].
3.  **Stage 2:** Merge all per-timestep teacher models into a single student via offline knowledge distillation (an $O(n)$ procedure) [S1, unofficial].
**Performance:** On time-varying datasets up to 23.44 GB (argon bubble, 150 timesteps), KD-INR outperformed CoordNet, NeurComp, and SIREN at compression ratios from 733 to 10,000 [S1, unofficial]. Training time is 1–6 minutes per timestep on a single GPU [S1, unofficial].

## Operating characteristics
*   **Compression Ratio:** NeurComp outperforms tensor decomposition (TTHRESH) at high compression ratios. For example, it achieved 47.9 dB PSNR at 545:1 compression on the Rayleigh-Taylor dataset (scalar fields up to $512^3$) [S1, unofficial].
*   **Performance:** MVNet achieved 49.68 dB PSNR at 1298:1 compression on a 100-variable climate dataset [S1, unofficial]. KD-INR achieved compression ratios from 733 to 10,000 on time-varying datasets [S1, unofficial].
*   **Training Time:** NeurComp requires hours per volume on a V100 GPU [S1, unofficial]. KD-INR requires 1–6 minutes per timestep on a single GPU [S1, unofficial].
*   **Strengths:** Simultaneously compressed storage and queryable data source; preserves inter-variable statistical dependencies (MVNet); high compression ratios for scientific volumes [S1, unofficial].
*   **Limitations:** Cannot render interactively from the volume (NeurComp) [S1, unofficial]; MVNet only tested on static datasets [S1, unofficial].

## Background
Neural Implicit Network Compression was introduced as the first INR compression method for scientific volumes [S1, unofficial]. It utilizes a coordinate-based SIREN MLP with residual connections and 9-bit weight quantization via k-means clustering [S1, unofficial]. The method addresses the strain that full-resolution scientific volumes place on storage systems and I/O pipelines, offering an alternative to traditional lossy compressors like SZ and ZFP which produce bitstreams that must be fully decoded before visualization [S1, unofficial].
