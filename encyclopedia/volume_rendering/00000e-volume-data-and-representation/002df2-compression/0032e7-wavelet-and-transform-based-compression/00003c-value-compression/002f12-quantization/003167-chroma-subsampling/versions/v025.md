# Chroma Subsampling
Also called: Chroma Subsampling for Volumetric Data, Chroma subsampling for volume, Color component subsampling

## Overview
Chroma subsampling reduces the bitrate of volumetric color data by lowering the resolution of chrominance components (U, V) while maintaining full resolution for luminance (Y), thereby preventing color loss at low bitrates [S1]. It differs from direct subsampling by aggregating color information from groups of eight adjacent voxel corners using a median filter, which preserves sharpness and reduces outlier influence [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A set of existing voxels, each with a position and a color value (typically in YUV or RGB space).
*   **Output:** A subsampled set of chroma voxels at reduced resolution, and a reconstruction method for decoding.

**Data Structures**
The method operates on groups of eight adjacent voxel corners in the 3D grid.
*   **Corner Group:** A $2 \times 2 \times 2$ block of voxel positions.
*   **Voxel State:** Each corner is either "existing" (contains a voxel with color data) or "non-existing" (empty/transparent).
*   **Subsampled Voxel:** Represents the aggregated color for the group.

**Steps**
1.  **Grouping:** Divide the volume grid into non-overlapping groups of eight adjacent corners.
2.  **Existence Check:** For each group, determine which corners contain existing voxels.
3.  **Transparent Case:** If no existing voxels are present in any of the eight corners, define the subsampled voxel as transparent [S1].
4.  **Median Calculation:** If one or more voxels are present in the eight adjacent corners, collect the color values of the existing voxels. Compute the median value of these existing voxels for each chrominance component (U, V) [S1].
    *   Let $C_i$ be the color value of the $i$-th existing voxel in the group.
    *   Let $N$ be the number of existing voxels ($1 \le N \le 8$).
    *   The subsampled chroma value $C_{sub}$ is the median of $\{C_1, C_2, ..., C_N\}$ [S1].
    *   The median method is chosen over the average method because it provides better sharpness and is less influenced by outlier values [S1].
5.  **Luminance Handling:** Luminance (Y) is kept at full resolution and is not subsampled by this method [S1].

**Decoding (Reconstruction)**
1.  **Interpolation or Repetition:** On the decoder side, missing chroma values for non-subsampled positions are reconstructed.
2.  **Repeating Approach:** The preferred method in simulation is to repeat the preceding sample (nearest-neighbor interpolation in the decoding order) [S1]. This is employed because viewers' sense of color is barely affected by this approximation [S1].
3.  **Alternative:** Interpolation from neighboring voxels is also a valid reconstruction strategy [S1].

**Pitfalls and Edge Cases**
*   **Color Loss:** Without chroma subsampling, chroma information can be completely lost at low bitrates, resulting in grey objects [S1].
*   **Outliers:** Using the mean instead of the median can lead to color inaccuracies due to outlier values in sparse volumes [S1].
*   **Sharpness:** Direct subsampling causes significant information loss; the median aggregation preserves edge sharpness better than averaging [S1].

            v_values = [c.V for c in existing_colors]
            
            median_u = median(u_values)
            median_v = median(v_values)
            
            # Y is kept at full res, so for the subsampled voxel, 
            # we might store a placeholder or the Y of the first existing voxel
            # depending on the specific pipeline. 
            # The source focuses on U, V subsampling.
            subsampled_color = (None, median_u, median_v) 
            
        # Create subsampled voxel at the block origin (or representative position)
        subsampled_voxel = Voxel(
            pos=block_origin,
            color=subsampled_color,
            exists=True
        )
        subsampled_voxels.append(subsampled_voxel)
        
    return subsampled_voxels

def median(values):
    """Compute the median of a list of numbers."""
    sorted_vals = sorted(values)
    n = len(sorted_vals)
    if n % 2 == 1:
        return sorted_vals[n // 2]
    else:
        # For even number of elements, standard median is average of two middle
        # However, source says "median value of the existing voxels".
        # In image processing, median filter often picks one of the sorted values.
        # Given the discrete nature of color indices, picking the middle element
        # or averaging is acceptable. Source implies robustness to outliers,
        # so standard statistical median is implied.
        return (sorted_vals[n // 2 - 1] + sorted_vals[n // 2]) / 2

## Operating characteristics
*   **Compression Ratio:** Chroma subsampling significantly reduces bitrate for color components. In the Leo sequence experiment, it achieved 39.30 dB PSNR at 1.18 bpv (bits per voxel), whereas non-subsampling required 2.90 bpv for the same quality [S1].
*   **Quality:** Prevents complete loss of color information (grey objects) at low bitrates [S1].
*   **Complexity:** The median calculation is $O(N)$ where $N$ is the number of existing voxels in a group (max 8), which is constant time per group. Reconstruction is $O(1)$ per voxel with the repeating approach.
*   **Strengths:** Preserves color quality at low bitrates; robust to outliers; simple to implement.
*   **Limitations:** Reduces chroma resolution, which may affect fine color details; relies on the assumption that human color perception is less sensitive to high-frequency chroma changes.

## Background
Chroma subsampling is a technique adapted from image and video compression (e.g., 4:2:0, 4:2:2) to volumetric data. In volumes, intensity and color are defined only for existing voxels, making direct subsampling problematic due to sparse data. The specific method described here, using median aggregation over 8-corner groups, was proposed to address these challenges in volumetric view synthesis [S1].
