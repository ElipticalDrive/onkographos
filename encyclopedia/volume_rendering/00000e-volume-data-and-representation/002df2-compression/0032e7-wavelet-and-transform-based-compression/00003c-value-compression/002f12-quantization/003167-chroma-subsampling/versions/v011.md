# Chroma Subsampling

Also called: Chroma Subsampling for Volumetric Data, Chroma subsampling for volume, Color component subsampling

## Overview
Chroma subsampling for volumetric data is a compression technique that reduces the resolution of chrominance components (U, V) while maintaining the luminance component (Y) at full resolution, thereby improving color quality at low bitrates [S1]. Unlike direct subsampling which causes significant information loss in sparse volumes, this method defines one color value for every eight adjacent corners, preserving color information more effectively [S1]. It sets itself apart from sibling quantization methods by specifically addressing the sparsity and geometric nature of volumetric data, where intensity and color are defined only for existing voxels, rather than treating the volume as a dense grid [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A set of existing voxels in a volumetric scene, each with a color value (typically in YUV or similar color space).
*   **Output:** A compressed representation where chrominance data is subsampled, reducing the bitrate while maintaining perceptual color quality.

**Data Structures**
The method operates on groups of eight adjacent corners in the volumetric grid. For each group, a single subsampled voxel is defined. The layout involves checking the existence of voxels in the eight corners and computing a representative color value if any exist.

**Steps**
1.  **Grouping:** Divide the volumetric space into groups of eight adjacent corners.
2.  **Existence Check:** For each group, determine if any existing voxel is present in the eight corners.
3.  **Transparent Handling:** If no existing voxel is present in any of the eight corners, define the subsampled voxel as transparent [S1].
4.  **Median Calculation:** If one or more voxels are present in the eight adjacent corners, calculate the median value of the existing voxels' chrominance components (U, V) [S1]. The median is chosen over the average because it provides better sharpness and is less influenced by outlier values, ignoring high-difference values [S1].
5.  **Decoder Interpolation:** On the decoder side, missing values (holes in the subsampled grid) are handled by either interpolating from neighboring voxels or repeating the preceding sample [S1]. In simulation contexts, the repeating approach is employed because viewers' sense of color is barely affected by this method [S1].

def chroma_subsampling_volumetric(existing_voxels):
    """
    existing_voxels: A list or grid of voxels, where each voxel has a position (x, y, z) and color (Y, U, V).
                     Voxels that do not exist are represented as None or excluded from the list.
    Returns: A list of subsampled voxels with reduced chroma resolution.
    """
    subsampled_voxels = []
    
    # Iterate through the volume in groups of 8 adjacent corners
    # Assuming a regular grid structure for grouping
    for group in get_8_corner_groups(existing_voxels):
        # group is a list of 8 potential voxel positions
        existing_in_group = [v for v in group if v is not None]
        
        if not existing_in_group:
            # No existing voxel in any corner: define as transparent
            subsampled_voxels.append(Voxel(color=(0, 0, 0), is_transparent=True))
        else:
            # One or more voxels present: use median of existing chroma values
            u_values = [v.color.U for v in existing_in_group]
            v_values = [v.color.V for v in existing_in_group]
            
            median_u = median(u_values)
            median_v = median(v_values)
            
            # Luminance Y is kept at full resolution, so it is not subsampled here
            # However, the subsampled voxel represents the chroma for the group
            # The luminance for this group would be handled separately or kept full res
            subsampled_voxels.append(Voxel(color=(None, median_u, median_v), is_transparent=False))
            
    return subsampled_voxels

def median(values):
    """Calculate the median of a list of values."""
    sorted_values = sorted(values)
    n = len(sorted_values)
    if n % 2 == 1:
        return sorted_values[n // 2]
    else:
        return (sorted_values[n // 2 - 1] + sorted_values[n // 2]) / 2.0

**Edge Cases and Pitfalls**
*   **Complete Loss of Color:** Without chroma subsampling, chroma information can be completely lost at low bitrates, resulting in grey objects [S1].
*   **Outliers:** The median method is robust against outliers, which is crucial in sparse volumes where a single high-intensity voxel might skew an average [S1].
*   **Transparency:** Correctly handling groups with no existing voxels as transparent is essential to maintain the correct shape and avoid artifacts [S1].

## Operating characteristics
*   **Bitrate Reduction:** Chroma subsampling significantly reduces the bitrate required for chrominance components. In the Leo sequence experiment, chroma subsampling achieved 39.30 dB PSNR at 1.18 bpv (bits per voxel), while non-subsampling required 2.90 bpv for the same quality [S1].
*   **Quality:** Improves the quality of reconstructed color components, preventing the grey object artifact seen in non-subsampled approaches at low bitrates [S1].
*   **Complexity:** The method involves grouping, existence checking, and median calculation, which are computationally efficient operations.
*   **Limitations:** The effectiveness depends on the accuracy of the available geometry model, as the coding performance is linked to the spatial distribution of existing voxels [S1].

## Background
Chroma subsampling for volumetric data was proposed in the context of color volumetric compression for realistic view synthesis applications [S1]. The method was tested on the multiview Leo sequence captured at the University of Bristol [S1]. It addresses the challenge of compressing volumetric data where intensity and color are defined only for existing voxels, a scenario where direct subsampling leads to significant information loss [S1].
