# Chroma Subsampling
Also called: Chroma Subsampling for Volumetric Data, Chroma subsampling for volume, Color component subsampling

## Overview
Chroma subsampling is a data rearrangement technique that reduces the resolution of chrominance components (U, V) in volumetric data while maintaining luminance (Y) at full resolution, thereby improving color quality at low bitrates [S1]. It sets itself apart from direct subsampling by defining one color value for every eight adjacent corners, which preserves color information significantly better than direct subsampling methods that cause significant information loss [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of existing voxels, each with a color value (typically in YUV or similar color space) and a presence flag (existing or non-existing/transparent).
*   **Output:** A subsampled volume where chrominance data is stored at a lower resolution (1 value per 8-corner group), while luminance remains at full resolution.

**Data Structures:**
The method operates on groups of eight adjacent corners in the volumetric grid. Each group is associated with a single subsampled chroma voxel. The presence of data in the original corners determines the value of this subsampled voxel.

**Steps:**
1.  **Grouping:** Divide the volumetric grid into groups of eight adjacent corners.
2.  **Presence Check:** For each group, determine if any of the eight corners contain an existing voxel.
3.  **Value Assignment:**
    *   If **no** existing voxel is present in any of the eight corners, define the subsampled voxel as **transparent** [S1].
    *   If **one or more** voxels are present in the eight adjacent corners, calculate the **median** value of the existing voxels' chrominance components and use this as the color value for the subsampled voxel [S1]. The median is chosen over the average because it provides better sharpness and is less influenced by outlier values [S1].
4.  **Decoding (Reconstruction):**
    *   On the decoder side, missing values (transparent voxels in the subsampled grid) must be handled.
    *   Options include interpolating from neighboring voxels or repeating the preceding sample [S1].
    *   In simulation contexts, the **repeating approach** is employed because viewers' sense of color is barely affected by this approximation [S1].

**Parameters:**
*   **Group Size:** 8 adjacent corners [S1].
*   **Aggregation Method:** Median [S1].
*   **Decoding Strategy:** Repeating (simulation) or Interpolation [S1].

**Edge Cases and Pitfalls:**
*   **Empty Groups:** If no voxels exist in a group, the result is transparent [S1].
*   **Outliers:** The median method is robust against outlier values, which is critical when the eight corners have high variance in color [S1].
*   **Color Loss:** Without this subsampling, chroma information can be completely lost at low bitrates, resulting in grey objects [S1].

## Operating characteristics
*   **Bitrate Reduction:** Chroma subsampling significantly reduces the bitrate required for chrominance components. In the Leo sequence experiment, it achieved 39.30 dB PSNR at 1.18 bpv (bits per voxel), whereas non-subsampling required 2.90 bpv for the same quality [S1].
*   **Quality:** It preserves color information better than direct subsampling, preventing the "grey object" artifact at low bitrates [S1].
*   **Complexity:** The method involves grouping, median calculation, and simple decoding. The computational overhead is low compared to the bitrate savings.
*   **Limitations:** The method assumes that the luminance (Y) is coded at full resolution. It only applies to chrominance components (U, V) [S1].

## Background
Chroma subsampling for volumetric data was proposed in the context of color volumetric compression for realistic view synthesis applications [S1]. It addresses the issue that direct subsampling of volume causes significant information loss, as intensity and color are defined only for existing voxels [S1]. The technique was tested on multiview captured data, such as the Leo sequence captured at the University of Bristol [S1].
