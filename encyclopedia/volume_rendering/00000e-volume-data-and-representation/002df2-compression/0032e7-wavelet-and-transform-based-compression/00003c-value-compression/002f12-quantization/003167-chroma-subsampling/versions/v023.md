# Chroma Subsampling

Also called: Chroma Subsampling for Volumetric Data, Chroma subsampling for volume, Color component subsampling

## Overview
Chroma subsampling for volumetric data reduces the bitrate of color information by lowering the resolution of chrominance components (U, V) while maintaining luminance (Y) at full resolution, thereby preventing color loss at low bitrates [S1]. It differs from direct subsampling by aggregating color values from groups of eight adjacent voxel corners using a median filter, which preserves sharpness and reduces sensitivity to outliers compared to averaging [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A set of existing voxels, each containing a color value (typically in YUV or similar color space) and a validity flag (existing/transparent).
*   **Output:** A subsampled volume where chrominance data is stored at a coarser resolution (one value per $2 \times 2 \times 2$ corner group), while luminance remains at the original resolution.

**Data Structures**
The method operates on a grid of voxel corners. For every group of eight adjacent corners forming a unit cube, a single subsampled chroma voxel is generated.
*   **Subsampled Voxel:** Contains a color value (U, V) and a validity indicator.
*   **Original Voxel:** Contains Y, U, V and a validity flag.

**Algorithm Steps**
1.  **Grouping:** Divide the volume grid into non-overlapping groups of eight adjacent corners (forming $2 \times 2 \times 2$ blocks).
2.  **Validity Check:** For each group, determine if any of the eight corners contain an existing (non-transparent) voxel.
3.  **Value Assignment:**
    *   If **no** existing voxels are present in the eight corners, define the subsampled voxel as transparent [S1].
    *   If **one or more** existing voxels are present, extract the chrominance values (U, V) from all existing voxels in the group.
    *   Compute the **median** of these chrominance values. The median is chosen over the average because it provides better sharpness and is less influenced by outlier values (highly different color values) [S1].
    *   Assign this median value to the subsampled voxel [S1].
4.  **Decoding/Reconstruction:**
    *   For missing values in the subsampled grid (holes), interpolate from neighboring voxels or repeat the preceding sample [S1].
    *   In simulation, the repeating approach is employed because viewers' sense of color is barely affected by this approximation [S1].

**Pseudocode**
```python
def chroma_subsampling_volume(original_voxels):
    """
    original_voxels: A 3D grid or list of voxel objects.
    Each voxel has attributes: .exists (bool), .u (float), .v (float).
    Returns: A 3D grid of subsampled voxels with reduced chroma resolution.
    """
    # Assume grid dimensions are divisible by 2 for simplicity
    # In practice, handle boundary conditions by padding or clamping
    
    subsampled_grid = create_empty_grid(size=[D//2, H//2, W//2])
    
    for d in range(0, D, 2):
        for h in range(0, H, 2):
            for w in range(0, W, 2):
                # Collect chroma values from the 8 corners of the 2x2x2 block
                chroma_values = []
                has_existing_voxel = False
                
                for dz in [0, 1]:
                    for hh in [0, 1]:
                        for ww in [0, 1]:
                            voxel = original_voxels[d + dz, h + hh, w + ww]
                            if voxel.exists:
                                has_existing_voxel = True
                                chroma_values.append((voxel.u, voxel.v))
                
                # Determine subsampled value
                if not has_existing_voxel:
                    subsampled_grid[d//2, h//2, w//2] = TransparentVoxel()
                else:
                    # Compute median of existing chroma values
                    # Separate U and V components for median calculation
                    u_values = [c[0] for c in chroma_values]
                    v_values = [c[1] for c in chroma_values]
                    
                    median_u = median(u_values)
                    median_v = median(v_values)
                    
                    subsampled_grid[d//2, h//2, w//2] = SubsampledVoxel(u=median_u, v=median_v)
    
    return subsampled_grid

def median(values):
    """Helper to compute median of a list of numbers."""
    sorted_vals = sorted(values)
    n = len(sorted_vals)
    if n % 2 == 1:
        return sorted_vals[n // 2]
    else:
        return (sorted_vals[n // 2 - 1] + sorted_vals[n // 2]) / 2.0
```

**Parameters and Typical Values**
*   **Subsampling Factor:** $2 \times 2 \times 2$ (one value per 8 corners) [S1].
*   **Aggregation Method:** Median [S1].
*   **Color Space:** YUV (Luminance Y kept at full resolution; Chrominance U, V subsampled) [S1].

**Edge Cases and Pitfalls**
*   **Low Bitrate Color Loss:** Without chroma subsampling, chroma information can be completely lost at low bitrates, resulting in grey objects [S1].
*   **Outliers:** Using the mean instead of the median can lead to blurred colors due to outlier influence; the median is preferred for sharpness [S1].
*   **Missing Data Handling:** Interpolation vs. repetition. Repetition is used in simulation for simplicity and acceptable perceptual quality [S1].

## Operating characteristics
*   **Bitrate Reduction:** Significantly reduces the bitrate required for chroma components. In the Leo sequence experiment, chroma subsampling achieved 39.30 dB PSNR at 1.18 bpv (bits per voxel), whereas non-subsampling required 2.90 bpv for the same quality [S1].
*   **Quality:** Preserves color information better than direct subsampling at low bitrates [S1].
*   **Complexity:** The aggregation step (median calculation over 8 elements) is computationally inexpensive. The main cost is the additional logic for grouping and handling missing voxels.
*   **Strengths:** Prevents total color loss at low bitrates; robust to outliers; simple to implement.
*   **Limitations:** Reduces spatial resolution of color; may introduce slight color blurring if the median is not representative of the local color distribution (though less than mean).

## Background
Chroma subsampling is a well-known technique in image and video compression (e.g., 4:2:0, 4:2:2) that exploits the human visual system's lower sensitivity to color detail compared to luminance detail [S1]. Its application to volumetric data was proposed to address the specific challenge that in volumes, intensity and color are defined only for existing voxels, making direct subsampling prone to significant information loss [S1]. The method was introduced in the context of multiview volume compression for realistic view synthesis [S1].
