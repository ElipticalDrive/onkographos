# Chroma Subsampling

Also called: Chroma Subsampling for Volumetric Data, Chroma subsampling for volume, Color component subsampling

## Overview
Chroma subsampling for volumetric data reduces the bitrate of color information by lowering the resolution of chrominance components (U, V) while maintaining full resolution for luminance (Y). Unlike direct subsampling which causes significant information loss in sparse volumes, this method defines one color value for every eight adjacent corners of a voxel grid, preserving color fidelity at low bitrates. It sets itself apart from sibling quantization methods by specifically addressing the spatial sparsity and geometric structure of volumetric data rather than just precision reduction.

## How it works
**Inputs and Outputs:**
*   **Input:** A sparse volumetric dataset where voxels exist only at specific locations (corners of the grid cells), each associated with a color value (typically in YUV or RGB space).
*   **Output:** A compressed representation where chrominance data is stored at 1/8th the spatial density of the original voxel grid, with luminance remaining at full resolution.

**Data Structures:**
The method operates on a grid of $2 \times 2 \times 2$ corner groups. For each group of eight adjacent corners, a single subsampled chroma value is computed.
*   **Voxel Presence:** A binary indicator for whether a voxel exists at a specific corner.
*   **Chroma Value:** The computed median color value for the group.

**Steps:**
1.  **Grouping:** Divide the volume grid into non-overlapping groups of eight adjacent corners (forming a $2 \times 2 \times 2$ block).
2.  **Existence Check:** Determine if any voxel exists within the eight corners of the current group.
3.  **Transparent Handling:** If no voxel exists in any of the eight corners, define the subsampled voxel for this group as transparent.
4.  **Median Calculation:** If one or more voxels exist in the eight adjacent corners, compute the median value of the chrominance components (U, V) of the existing voxels. The median is preferred over the average because it provides better sharpness and is less influenced by outlier values [S1].
5.  **Storage:** Store the computed median chroma value for the group. Luminance (Y) is stored for each individual voxel as per standard practice or parent method specifications.

**Decoder Side Reconstruction:**
1.  **Interpolation/Repetition:** For missing chroma values in the reconstructed volume, interpolate from neighboring voxels or repeat the preceding sample.
2.  **Simulation Choice:** In simulation environments, the repeating approach (repeating the preceding sample) is employed because viewers' sense of color is barely affected by this approximation [S1].

**Pseudocode:**
```python
def chroma_subsample_volume(voxel_corners, voxel_colors):
    """
    voxel_corners: List of tuples (x, y, z) indicating existing voxel positions.
    voxel_colors: Dictionary mapping (x, y, z) to color tuple (Y, U, V).
    
    Returns:
    subsampled_chroma: Dictionary mapping group_key to (U, V) median.
    """
    subsampled_chroma = {}
    
    # Iterate through all possible 2x2x2 groups in the grid
    # Assuming grid bounds are known or derived from voxel_corners
    for x in range(0, max_x, 2):
        for y in range(0, max_y, 2):
            for z in range(0, max_z, 2):
                group_key = (x, y, z)
                existing_voxels = []
                
                # Check all 8 corners of the 2x2x2 block
                for dx in [0, 1]:
                    for dy in [0, 1]:
                        for dz in [0, 1]:
                            corner = (x + dx, y + dy, z + dz)
                            if corner in voxel_corners:
                                existing_voxels.append(voxel_colors[corner])
                
                if not existing_voxels:
                    # No voxel exists in this group; mark as transparent
                    subsampled_chroma[group_key] = None
                else:
                    # Compute median of existing voxels' chrominance (U, V)
                    # Assuming colors are (Y, U, V)
                    u_values = [v[1] for v in existing_voxels]
                    v_values = [v[2] for v in existing_voxels]
                    
                    median_u = median(u_values)
                    median_v = median(v_values)
                    
                    subsampled_chroma[group_key] = (median_u, median_v)
                    
    return subsampled_chroma

def median(values):
    """Helper to compute median of a list of numbers."""
    sorted_vals = sorted(values)
    n = len(sorted_vals)
    if n % 2 == 1:
        return sorted_vals[n // 2]
    else:
        return (sorted_vals[n // 2 - 1] + sorted_vals[n // 2]) / 2.0
```

**Parameters:**
*   **Group Size:** Fixed at $2 \times 2 \times 2$ corners (8 voxels) [S1].
*   **Median vs. Mean:** Median is strictly used [S1].

**Edge Cases and Pitfalls:**
*   **Empty Groups:** If no voxels exist in a $2 \times 2 \times 2$ block, the result is transparent. Failure to handle this may lead to artifacts or errors in reconstruction [S1].
*   **Outliers:** Using the mean instead of the median can introduce artifacts due to outlier color values in sparse regions. The median is robust against this [S1].
*   **Low Bitrate Loss:** Without chroma subsampling, chroma information can be completely lost at low bitrates, resulting in grey objects. This method prevents that by concentrating the available bits on the most representative color value for the group [S1].

## Operating characteristics
*   **Bitrate Reduction:** Significantly reduces the bitrate required for chrominance components. In the Leo sequence experiment, chroma subsampling achieved 39.30 dB PSNR at 1.18 bpv (bits per voxel), whereas the non-subsampling approach required 2.90 bpv for the same quality [S1].
*   **Quality Preservation:** Prevents the complete loss of color information at low bitrates, avoiding the "grey object" artifact common in non-subsampled sparse volumes [S1].
*   **Complexity:** The encoding complexity is linear with respect to the number of $2 \times 2 \times 2$ groups, involving simple existence checks and median calculations. Decoding involves simple repetition or interpolation, which is computationally inexpensive [S1].
*   **Limitations:** The method assumes a grid structure with defined corners. It is specifically designed for sparse volumetric data where voxels are defined at corners, not solid volumes [S1].

## Background
Chroma subsampling for volumetric data was proposed in the context of realistic view synthesis applications, specifically for compressing multiview captured volumes. It addresses the inefficiency of coding chrominance at full resolution for sparse volumes where direct subsampling leads to significant information loss. The method was tested on the multiview Leo sequence captured at the University of Bristol [S1].
