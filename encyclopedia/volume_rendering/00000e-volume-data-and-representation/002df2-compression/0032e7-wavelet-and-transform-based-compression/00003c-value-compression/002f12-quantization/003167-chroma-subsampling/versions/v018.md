# Chroma Subsampling

Also called: Chroma Subsampling for Volumetric Data, Chroma subsampling for volume, Color component subsampling

## Overview
Chroma subsampling for volumetric data reduces the bitrate of color information by lowering the resolution of chrominance components (U, V) while maintaining full resolution for luminance (Y) [S1]. It solves the problem of significant color information loss and "grey object" artifacts that occur when direct subsampling is applied to sparse volumetric data at low bitrates [S1]. Unlike direct subsampling, which discards data indiscriminately, this method defines one color value for every eight adjacent corners, using a median-based aggregation that preserves sharpness and resists outlier influence better than averaging [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A set of existing voxels, each containing a color value (typically in YUV or similar space) and a validity flag (existing/non-existing).
*   **Output:** A subsampled volume where chrominance data is stored at 1/8th the spatial density of the original, with luminance remaining at full resolution.

**Data Structures**
The method operates on groups of eight adjacent corners in the voxel grid.
*   **Corner Group:** A logical grouping of 8 voxel positions.
*   **Voxel State:** Each corner in the group has a state: `Existing` (contains a valid voxel) or `Non-existing` (empty/transparent).
*   **Subsampled Voxel:** Stores the aggregated chrominance value for the group.

**Algorithm Steps**
1.  **Grouping:** Partition the voxel grid into non-overlapping groups of eight adjacent corners.
2.  **Aggregation:** For each group, determine the chrominance value for the subsampled voxel:
    *   If **no** existing voxels are present in any of the eight corners, define the subsampled voxel as **transparent** [S1].
    *   If **one or more** voxels are present in the eight adjacent corners, calculate the **median** value of the chrominance components (U, V) of all existing voxels in the group [S1].
3.  **Storage:** Store the calculated median value (or transparent flag) in the subsampled data structure. Luminance (Y) is processed separately at full resolution.

**Decoder Side Reconstruction**
To reconstruct the full-resolution chrominance for rendering or further processing:
1.  **Interpolation:** Interpolate missing values from neighboring subsampled voxels [S1].
2.  **Repetition:** Alternatively, repeat the preceding sample value [S1]. The source notes that viewers' sense of color is barely affected by this repetition, making it a valid and efficient simulation strategy [S1].

**Pseudocode**
```python
def chroma_subsample_volume(voxels):
    """
    Subsample chrominance (U, V) of a volumetric dataset.
    voxels: List of voxel objects, each with:
        - pos: (x, y, z) integer coordinates
        - valid: boolean, True if voxel exists
        - color: tuple (Y, U, V)
    Returns:
        subsampled_voxels: List of subsampled voxel objects
    """
    subsampled_voxels = []
    
    # Group voxels into 2x2x2 blocks (8 corners)
    # Note: Implementation requires mapping global coordinates to block indices
    # and handling boundary conditions.
    
    for block_origin in get_block_origins(voxels):
        # Collect existing voxels in this 2x2x2 block
        existing_colors = []
        for voxel in voxels_in_block(block_origin, voxels):
            if voxel.valid:
                existing_colors.append(voxel.color)
        
        if not existing_colors:
            # No existing voxel in any corner: define as transparent
            subsampled_voxels.append(Voxel(
                pos=block_origin,
                valid=True,
                color=(None, None, None) # Transparent
            ))
        else:
            # One or more voxels present: use median of existing chrominance
            # Extract U and V components
            u_values = [c[1] for c in existing_colors]
            v_values = [c[2] for c in existing_colors]
            
            median_u = median(u_values)
            median_v = median(v_values)
            
            # Luminance is not subsampled here, but for the subsampled voxel
            # we might store a placeholder or aggregate Y separately if required.
            # The source focuses on U, V subsampling.
            subsampled_voxels.append(Voxel(
                pos=block_origin,
                valid=True,
                color=(None, median_u, median_v)
            ))
            
    return subsampled_voxels

def median(values):
    """Calculate the median of a list of numbers."""
    sorted_vals = sorted(values)
    n = len(sorted_vals)
    if n % 2 == 1:
        return sorted_vals[n // 2]
    else:
        return (sorted_vals[n // 2 - 1] + sorted_vals[n // 2]) / 2.0
```

**Parameters and Typical Values**
*   **Subsampling Factor:** 8:1 (one value per 8 corners) [S1].
*   **Aggregation Method:** Median [S1].
*   **Reconstruction Method:** Repetition of preceding sample (for simulation) or interpolation [S1].

**Edge Cases and Pitfalls**
*   **Empty Groups:** If all 8 corners are empty, the result is transparent. Failure to handle this may lead to undefined values or artifacts [S1].
*   **Outliers:** The median method is chosen specifically because it is less influenced by outlier values than the average method, preserving sharpness [S1].
*   **Low Bitrate Loss:** Without subsampling, chroma information can be completely lost at low bitrates, resulting in grey objects. Subsampling prevents this by concentrating available bits on the most representative color value for the group [S1].

## Operating characteristics
**Time and Memory Complexity**
*   **Memory:** Reduces chrominance storage by a factor of 8. Luminance remains unchanged. Total memory reduction depends on the ratio of chroma to luminance data.
*   **Time:** Aggregation is $O(N)$ where $N$ is the number of voxel groups. Median calculation is $O(1)$ per group (max 8 elements).

**Measured Performance**
*   In the Leo sequence experiment, chroma subsampling achieved **39.30 dB PSNR** at **1.18 bpv** (bits per voxel) for chrominance components [S1].
*   The non-subsampling approach required **2.90 bpv** to achieve the same 39.30 dB PSNR [S1].
*   This represents a significant bitrate saving for equivalent color quality [S1].

**Strengths and Limitations**
*   **Strengths:** Preserves color quality at low bitrates; prevents grey artifacts; median aggregation resists outliers and preserves sharpness better than averaging [S1].
*   **Limitations:** Only applies to chrominance; luminance must still be coded at full resolution; requires careful handling of sparse data (empty corners) [S1].

## Background
Chroma subsampling is a well-known technique in image and video compression (e.g., 4:2:0, 4:2:2) that exploits the human visual system's lower sensitivity to color detail compared to luminance detail [S1]. Its application to volumetric data, specifically for realistic view synthesis, was proposed to address the unique challenges of sparse voxel representations where direct subsampling leads to severe information loss [S1]. The method was tested on multiview captured data (Leo sequence) from the University of Bristol [S1].
