# Chroma Subsampling

Also called: Chroma Subsampling for Volumetric Data, Chroma subsampling for volume, Color component subsampling

## Overview
Chroma subsampling reduces the bitrate of volumetric color data by lowering the spatial resolution of chrominance components (U, V) while maintaining full resolution for luminance (Y) [S1]. It addresses the problem that direct subsampling of sparse volumetric data causes significant information loss, often resulting in grey objects at low bitrates [S1]. Unlike sibling methods that may apply uniform reduction, this approach defines one color value for every eight adjacent corners, using a median-based aggregation to preserve sharpness and resist outliers [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A set of existing voxels, each containing a color value (typically in YUV or similar space) and a validity flag (existing/transparent).
*   **Output:** A subsampled volume where chrominance data is stored at 1/8th the spatial density of the original voxel grid, while luminance remains at full resolution.

**Data Structures**
The subsampled volume uses a grid where each cell corresponds to a $2 \times 2 \times 2$ block of original voxels.
*   **Luminance (Y):** Stored at every original voxel coordinate.
*   **Chrominance (U, V):** Stored at coordinates $(i, j, k)$ where $i, j, k$ are even indices in the original grid, representing the group of eight adjacent corners.

**Algorithm Steps**
1.  **Grouping:** Partition the original voxel grid into non-overlapping $2 \times 2 \times 2$ blocks. Each block consists of eight adjacent corners.
2.  **Validity Check:** For each block, determine if any of the eight corners contain an existing (non-transparent) voxel.
3.  **Aggregation:**
    *   If **no** existing voxels are present in the block, define the subsampled voxel as transparent (or null) [S1].
    *   If **one or more** existing voxels are present, extract the chrominance values (U, V) from all existing voxels in the block.
    *   Compute the **median** of these chrominance values. The median is chosen over the average because it provides better sharpness and is less influenced by outlier values [S1].
    *   Assign this median value to the subsampled voxel's chrominance channel [S1].
4.  **Luminance Handling:** Luminance values are retained at full resolution for all existing voxels. No subsampling is applied to Y [S1].

**Pseudocode**
```python
def chroma_subsample_volume(original_voxels):
    """
    original_voxels: A dictionary or sparse array mapping (x, y, z) -> {Y, U, V, valid}
    Returns: subsampled_voxels mapping (x//2, y//2, z//2) -> {U, V}
    """
    subsampled_chroma = {}
    
    # Group voxels into 2x2x2 blocks
    # Iterate through all unique block coordinates
    for bx in range(0, max_x, 2):
        for by in range(0, max_y, 2):
            for bz in range(0, max_z, 2):
                
                existing_colors = []
                
                # Check all 8 corners of the block
                for dx in [0, 1]:
                    for dy in [0, 1]:
                        for dz in [0, 1]:
                            coord = (bx + dx, by + dy, bz + dz)
                            if coord in original_voxels and original_voxels[coord].valid:
                                existing_colors.append(original_voxels[coord].chroma)
                
                # Determine subsampled chroma value
                if not existing_colors:
                    # No existing voxel: mark as transparent/null
                    subsampled_chroma[(bx//2, by//2, bz//2)] = None
                else:
                    # Use median of existing chroma values
                    # Note: Median is computed per component (U and V) independently
                    u_values = [c[0] for c in existing_colors]
                    v_values = [c[1] for c in existing_colors]
                    
                    median_u = median(u_values)
                    median_v = median(v_values)
                    
                    subsampled_chroma[(bx//2, by//2, bz//2)] = (median_u, median_v)
                    
    return subsampled_chroma

def median(values):
    """Helper to compute median of a list of numbers."""
    sorted_vals = sorted(values)
    n = len(sorted_vals)
    if n % 2 == 1:
        return sorted_vals[n // 2]
    else:
        return (sorted_vals[n // 2 - 1] + sorted_vals[n // 2]) / 2.0
```

**Decoding (Reconstruction)**
On the decoder side, missing chroma values in the original grid must be reconstructed from the subsampled data.
1.  **Interpolation:** Interpolate missing values from neighboring subsampled voxels [S1].
2.  **Repetition:** Alternatively, repeat the preceding sample [S1].
3.  **Simulation Choice:** In simulations, the repeating approach is employed because viewers' sense of color is barely affected by the interpolation artifacts [S1].

**Parameters and Edge Cases**
*   **Block Size:** Fixed at $2 \times 2 \times 2$ corners [S1].
*   **Median vs. Mean:** The median is strictly preferred over the average to ignore high-difference outlier values and preserve sharpness [S1].
*   **Empty Blocks:** Blocks with no existing voxels are explicitly handled as transparent to avoid assigning arbitrary color data [S1].

## Operating characteristics
*   **Compression Ratio:** Chroma subsampling significantly reduces bitrate. In the Leo sequence experiment, it achieved 39.30 dB PSNR at 1.18 bits per voxel (bpv), whereas the non-subsampling approach required 2.90 bpv for the same quality [S1].
*   **Quality:** Prevents the complete loss of chroma information at low bitrates, avoiding the "grey object" artifact seen in non-subsampled volumes [S1].
*   **Complexity:** The aggregation step requires sorting or selection for the median, which is $O(1)$ per block (since block size is fixed at 8).
*   **Limitations:** The method assumes a regular grid structure for grouping. It does not compress luminance, so total bitrate reduction is limited to the chrominance channels.

## Background
Chroma subsampling is a technique adapted from image and video compression (e.g., YUV 4:2:0) to volumetric data [S1]. In traditional 2D images, chroma can be defined at lower resolution than luminance. However, for volumes, intensity and color are defined only for existing voxels, making direct subsampling prone to information loss [S1]. This specific method for volumetric data was proposed to improve color quality at low bitrates in realistic view synthesis applications [S1].
