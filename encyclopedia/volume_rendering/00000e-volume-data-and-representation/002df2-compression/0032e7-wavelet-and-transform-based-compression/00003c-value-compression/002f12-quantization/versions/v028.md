# Quantization

Also called: Quantization with Matrix

## Overview
Quantization reduces the precision of volume data coefficients or neural field parameters to compress storage and bandwidth. It sets itself apart from sibling methods like [Predictive and Differential Coding](4393-predictive-and-differential-coding.md) by directly mapping continuous values to a discrete set, rather than encoding differences between samples.

## Shared principles
This family operates on the output of the [Value compression](6-value-compression.md) pipeline. While [Value compression](6-value-compression.md) defines the general transform-encode-decode loop, Quantization specifically addresses the step where continuous coefficients or weights are mapped to discrete indices or reduced-precision values. The core mechanism involves defining a quantization function $Q(x)$ that maps a real value $x$ to a discrete representation, and an inverse function $Q^{-1}$ for reconstruction. The choice of quantization strategy (scalar, vector, or learned) determines the trade-off between compression ratio and reconstruction fidelity.

## Subtopics

### [Vector Quantization](907-vector-quantization.md)
Vector Quantization (VQ) maps $n$-dimensional input vectors to a single fixed-length index referencing an entry in a pre-defined or learned codebook. It solves the problem of storing large volumetric datasets by exploiting spatial redundancy: identical or similar data blocks are replaced by compact indices, allowing for extremely fast decompression on the GPU. Unlike [Scalar Quantization](5726-scalar-quantization.md), which processes values independently, VQ groups data into blocks to capture correlations, and unlike [Hierarchical Vector Quantization](827-hierarchical-vector-quantization.md), it typically employs a single resolution level codebook.

### [Scalar Quantization](5726-scalar-quantization.md)
Scalar quantization maps continuous or high-precision volume data to a discrete, lower-precision set of values to reduce memory footprint and bandwidth requirements. In the context of compressed volume rendering, it is primarily implemented as a per-block random-access decompression method where each spatial block is represented by its local minimum and maximum values alongside a compact index for each voxel. Unlike global quantization which applies a single scale to the entire dataset, per-block scalar quantization adapts to local data ranges, offering a trade-off between compression ratio and reconstruction fidelity.

### [Chroma Subsampling](6512-chroma-subsampling.md)
Chroma subsampling for volumetric data reduces the bitrate of color information by lowering the resolution of chrominance components (U, V) while maintaining luminance (Y) at full resolution, thereby preventing color loss at low bitrates. It differs from direct subsampling by aggregating color values from groups of eight adjacent voxel corners using a median filter, which preserves sharpness and reduces sensitivity to outliers compared to averaging.

### [Differentiable Quantization for Neural Fields](10195-differentiable-quantization-for-neural-fields.md)
Differentiable quantization reduces the render-time memory footprint of neural radiance fields by compressing grid values to single bytes during the optimization process. Unlike post-training quantization, which causes quality degradation due to mismatch between the optimized model and the inference model, this method integrates quantization into the training loop using a straight-through estimator. It sets itself apart from sibling methods like [Global Quantization](15134-global-quantization.md) by applying per-parameter scaling ranges and enforcing quantization constraints during gradient descent rather than as a post-processing step.

### [Neural Implicit Network Compression](10414-neural-implicit-network-compression.md)
Neural Implicit Network Compression (NeurComp) is a method for compressing scientific volume data by training a coordinate-based Multi-Layer Perceptron (MLP) to map spatial coordinates directly to field values. It solves the problem of high storage and I/O costs associated with full-resolution scientific volumes by providing a compact network that serves as simultaneously compressed storage and a queryable data source. It sets itself apart from traditional lossy compressors like SZ and ZFP, which produce bitstreams requiring full decoding before visualization, by enabling direct querying of the implicit representation.

### [Unquantization Functions](13872-unquantization-functions.md)
Unquantization functions map discrete integer codes back to floating-point values, serving as the inverse of the quantization step in volume data compression. In the context of BC6H-based volume rendering, these functions reconstruct half-precision or full-precision color/volume values from compressed 8-bit indices. They are distinguished from general scalar quantization by their specific fixed-point arithmetic optimizations designed for GPU real-time decompression, particularly handling non-linear weight interpolation for endpoint blending.

### [Global Quantization](15134-global-quantization.md)
Global quantization is a compression strategy for neural volume representations that maintains a single shared parameter table across multiple independent small Multi-Layer Perceptrons (MLPs) within a single spatial scale, rather than quantizing each network individually. It solves the redundancy problem where distinct volumetric blocks contain similar content, allowing different MLPs to map to the same set of floating-point parameters. Unlike local quantization which treats each MLP as an isolated entity, global quantization leverages cross-MLP similarity to achieve higher compression ratios with minimal performance degradation.

### Lossy Quantization for Coarsened Patches
Lossy compression for coarsened patches in the bintree hierarchy. Quantization error $q$ is proportional to coarsening error $c$: $q = qc$, where $q$ is a fixed constant usually $< 1$. A single unified error is recomputed and nested for each patch. Quantization levels are restricted to power-of-two multiples of vertical resolution $\Delta z$ for efficient bit-shift implementation. Shift $k$ is calculated as: $k = \lceil \log_2(\epsilon_q / \Delta z) \rceil + 1$ if $\epsilon_q \ge \Delta z$, else $0$. All finest level vertices have zero shift. Vertices classified as boundary (corners $C$, legs $L$, hypotenuse $H$) and interior $I$. Corners stored at full precision. Quantization of original height values (not residuals) ensures adjacent patches agree on shared boundaries [S2].

### HSV Colour Sorting
A technique to preserve colour quality during DXT1 compression by reordering colours based on HSV values [S3, unofficial]. The effectiveness of HSV sorting depends on which component (H, S, or V) is the most frequent in the voxel data’s set of colours [S3, unofficial].

### Interpolation Symmetry Quantization
A method to improve the accuracy of quantized weights by exploiting the symmetry of linear interpolation between segments [S4]. Quantize both $w$ and $1 - w$ using the codebook generated by the scalar quantizer. Keep the representation resulting in the lower error. Store either $(i, j, w)$ or $(j, i, 1 - w)$ in the output stream [S4]. Linear interpolation: $(1 - w)s_i + w s_j$, where $(i, j, w)$ is equivalent to $(j, i, 1 - w)$ [S4].

### Position Lattice Quantization
An attempted method to compress Gaussian positions by quantizing them to a lattice structure and embedding positional constraints into the training process [S5]. Fails to compress positions without introducing significant rendering error [S5]. Identified as a future research direction for end-to-end positional compression [S5].

### Post-finetune Refinement
A refinement step that uses a small number of bits to enhance the reconstruction quality of important voxels, compensating for losses introduced by coarse quantization [S6]. Ablation study on Synthetic-NeRF dataset shows disabling post-finetune causes a -1.72 dB $\Delta$PSNR, -0.07 $\Delta$SSIM, and -0.079 MB $\Delta$Size [S6]. Disabling post-finetune saves bits but inevitably deteriorates rendering quality, confirming its necessity for maintaining RD performance [S6].

## Background
Quantization is a fundamental technique in signal processing and data compression. In the context of volume rendering, it has been adapted to handle the specific requirements of 3D data, such as spatial coherence and the need for real-time decompression. Early applications involved scalar quantization of DCT coefficients for 3D video compression [S1]. More recently, with the rise of neural radiance fields (NeRFs) and 3D Gaussian splatting, quantization has become critical for compressing the large parameter spaces of neural networks [S1, S5, S6].
