# Quantization

Also called: Quantization with Matrix

## Overview
Quantization reduces the precision of volumetric data coefficients or raw voxel values to lower memory footprint and bandwidth requirements. It sets itself apart from transform-based compression siblings by operating directly on the amplitude of values (scalar or vector) rather than altering the frequency domain structure, though it is frequently applied to the coefficients produced by those transforms.

## Shared principles
The family shares the mechanism of mapping a continuous or high-precision domain to a discrete, lower-precision set of representable values. This mapping is defined by a quantization function $Q(v)$ and an inverse unquantization function $U(q)$. The core trade-off is between the bit-rate (determined by the size of the discrete set or codebook) and the reconstruction error (distortion).

## Subtopics

### [Vector Quantization](907-vector-quantization.md)
Maps $n$-dimensional blocks to codebook indices. Choose when spatial correlation within blocks is high and GPU texture lookup is desired.

### [Scalar Quantization](5726-scalar-quantization.md)
Maps individual values to indices based on local min/max. Choose for simple, hardware-friendly random access decompression.

### [Chroma Subsampling](6512-chroma-subsampling.md)
Reduces color resolution for sparse volumes. Choose when color fidelity is secondary to luminance and bitrate is constrained.

### [Differentiable Quantization for Neural Fields](10195-differentiable-quantization-for-neural-fields.md)
Integrates quantization into neural field training. Choose for 3D Gaussian Splatting or NeRFs to avoid post-training quality loss.

### [Neural Implicit Network Compression](10414-neural-implicit-network-compression.md)
Quantizes MLP weights. Choose for compact, queryable implicit representations of scientific data.

### [Unquantization Functions](13872-unquantization-functions.md)
Implements the inverse mapping for block-compression formats. Choose when decoding BC6H or similar compressed textures/volumes.

### [Global Quantization](15134-global-quantization.md)
Shares a single codebook across multiple small MLPs. Choose to exploit redundancy between disjoint volumetric blocks in neural representations.

### Lossy Quantization for Coarsened Patches
A method for compressing coarsened patches in a bintree hierarchy where quantization error $q$ is proportional to coarsening error $c$ ($q = qc$, with $q < 1$) [S2]. Quantization levels are restricted to power-of-two multiples of vertical resolution $\Delta z$ for efficient bit-shift implementation [S2]. The shift $k$ is calculated as $k = \lceil \log_2(\epsilon_q / \Delta z) \rceil + 1$ if $\epsilon_q \ge \Delta z$, else $0$ [S2]. Vertices are classified as boundary (corners $C$, legs $L$, hypotenuse $H$) or interior $I$; corners are stored at full precision, and quantization of original height values (not residuals) ensures adjacent patches agree on shared boundaries [S2].

### HSV Colour Sorting
A technique to preserve color quality during DXT1 compression by reordering colors based on HSV values before storage [S3, unofficial]. Its effectiveness depends on which HSV component (H, S, or V) is the most frequent in the voxel data's color set [S3, unofficial].

### Interpolation Symmetry Quantization
A method to improve quantization accuracy by exploiting the symmetry of linear interpolation $(1-w)s_i + w s_j \equiv (1-(1-w))s_j + (1-w)s_i$ [S4]. It quantizes both $w$ and $1-w$ using a scalar quantizer codebook, keeps the representation with lower error, and stores either $(i, j, w)$ or $(j, i, 1-w)$ [S4].

### Position Lattice Quantization
An attempted method to compress Gaussian positions by quantizing them to a lattice structure and embedding constraints into training [S5]. It fails to compress positions without introducing significant rendering error and is identified as a future research direction [S5].

### Post-finetune Refinement
A refinement step using a small number of bits to enhance reconstruction quality for important voxels, compensating for coarse quantization losses [S6]. Disabling it causes a -1.72 dB $\Delta$PSNR and -0.07 $\Delta$SSIM on the Synthetic-NeRF dataset, confirming its necessity for RD performance [S6].

## Background
Quantization is a fundamental step in lossy compression, originating from early digital signal processing and image coding standards (e.g., JPEG, MPEG). In volume rendering, it was adapted to handle the large memory footprint of 3D scalar fields. Early implementations used scalar quantization with global or local min/max scaling [S1][S3, unofficial]. With the rise of neural volumetric representations (NeRFs, 3D Gaussian Splatting), differentiable quantization and global quantization of MLP weights have become critical for reducing memory usage without retraining [S1, S5, S6].
