# Quantization

Also called: Quantization with Matrix

## Overview
Quantization reduces the precision of volumetric data coefficients or raw values by mapping continuous or high-precision representations to a discrete, lower-precision set, thereby reducing memory footprint and bandwidth requirements [S1, S2][S3, unofficial]. It solves the problem of high storage and transmission costs for volumetric data by exploiting redundancy, replacing raw values with compact indices or reduced-precision representations [S2, S5]. Unlike [Value compression](6-value-compression.md) which encompasses the entire transform-encode pipeline, quantization specifically defines the lossy or lossless discretization step that determines the trade-off between compression ratio and reconstruction fidelity.

## Shared principles
This family shares the fundamental mechanism of mapping a continuous or high-precision input space to a discrete output space. The core operation is defined by a quantization function $Q(x)$ and its inverse (unquantization) $Q^{-1}(i)$, where $x$ is the input value and $i$ is the discrete index or quantized value.

1.  **Discretization:** Input values are mapped to a finite set of representative values (centroids, endpoints, or grid points). This mapping is often lossy, introducing quantization error.
2.  **Indexing:** In many variants (e.g., Vector Quantization), the quantized value is replaced by an index referencing a codebook, further reducing storage if the codebook is shared or small.
3.  **Error Control:** The quantization process is designed to minimize a specific distortion metric, such as Mean Squared Error (MSE) or perceptual error, often guided by psycho-visual experiments or training objectives [S1, S6].
4.  **Reconstruction:** Decoding involves retrieving the discrete representation (index or quantized value) and applying the inverse mapping to approximate the original value. The accuracy of this reconstruction depends on the quantization step size, the density of the codebook, and the specific unquantization function used [S1, S2][S3, unofficial][S4].

## Subtopics

### [Vector Quantization](907-vector-quantization.md)
Vector Quantization (VQ) maps $n$-dimensional input vectors (e.g., voxel blocks) to a single fixed-length index referencing an entry in a pre-defined or learned codebook. It solves the problem of high storage requirements by exploiting spatial redundancy, replacing individual voxel blocks with compact indices. Unlike [Scalar Quantization](5726-scalar-quantization.md) which processes values independently, VQ groups data into blocks to capture correlations, and unlike [Hierarchical Vector Quantization](827-hierarchical-vector-quantization.md) which uses multiple resolution levels, standard VQ typically employs a single dictionary for the entire dataset.

### [Scalar Quantization](5726-scalar-quantization.md)
Scalar quantization maps continuous or high-precision volume data to a discrete, lower-precision set of values to reduce memory footprint and bandwidth requirements. In the context of compressed volume rendering, it is primarily implemented as a per-block random-access decompression method where each spatial block is represented by its local minimum and maximum values alongside a compact index for each voxel. Unlike global quantization which applies a single scale to the entire dataset, per-block scalar quantization adapts to local data ranges, offering a trade-off between compression ratio and reconstruction fidelity.

### [Chroma Subsampling](6512-chroma-subsampling.md)
Chroma subsampling reduces the bitrate of volumetric color data by lowering the resolution of chrominance components (U, V) while maintaining full resolution for luminance (Y), thereby preventing color loss at low bitrates. It differs from direct subsampling by aggregating color information from groups of eight adjacent voxel corners using a median filter, which preserves sharpness and reduces outlier influence.

### [Unquantization Functions](13872-unquantization-functions.md)
Unquantization functions reconstruct continuous floating-point values from discrete integer indices produced by [Quantization](5935-quantization.md). In the context of BC6H compression, these functions map compressed half-precision or 7/9-bit integer representations back to their original dynamic range. They differ from sibling methods like [Scalar Quantization](5726-scalar-quantization.md) by being tightly coupled to the specific bit-packing and endpoint generation logic of block-based texture compression, specifically handling the non-linear or scaled linear mappings required for BC6H.

### [Neural Network Parameter Quantization](16222-neural-network-parameter-quantization.md)
Neural Network Parameter Quantization reduces the memory footprint of neural field representations (such as Neural Radiance Fields or Implicit Neural Representations) by mapping continuous network weights or grid parameters to discrete, low-bit indices. It solves the storage and I/O bottlenecks of high-resolution volumetric data by replacing raw grids or large MLP weight matrices with compact quantized representations. It differs from standard post-training quantization by integrating quantization into the optimization process (e.g., via differentiable estimators) or by sharing parameters across multiple local networks to exploit redundancy, thereby preventing the reconstruction quality drops associated with naive discretization.

### Lossy Quantization for Coarsened Patches
Lossy compression for coarsened patches in the bintree hierarchy. Quantization error $q$ is proportional to coarsening error $c$: $q = qc$, where $q$ is a fixed constant usually $< 1$. A single unified error is recomputed and nested for each patch. Quantization levels are restricted to power-of-two multiples of vertical resolution $\Delta z$ for efficient bit-shift implementation. Shift $k$ is calculated as: $k = \lceil \log_2(\epsilon_q / \Delta z) \rceil + 1$ if $\epsilon_q \ge \Delta z$, else $0$. All finest level vertices have zero shift. Vertices classified as boundary (corners $C$, legs $L$, hypotenuse $H$) and interior $I$. Corners stored at full precision. Quantization of original height values (not residuals) ensures adjacent patches agree on shared boundaries [S2].

### HSV Colour Sorting
A technique to preserve colour quality during DXT1 compression by reordering colours based on HSV values [S3, unofficial]. The effectiveness of HSV sorting depends on which component (H, S, or V) is the most frequent in the voxel data’s set of colours [S3, unofficial].

### Interpolation Symmetry Quantization
A method to improve the accuracy of quantized weights by exploiting the symmetry of linear interpolation between segments [S4]. Quantize both $w$ and $1 - w$ using the codebook generated by the scalar quantizer. Keep the representation resulting in the lower error. Store either $(i, j, w)$ or $(j, i, 1 - w)$ in the output stream. Linear interpolation: $(1 - w)s_i + w s_j$, where $(i, j, w)$ is equivalent to $(j, i, 1 - w)$ [S4].

### Position Lattice Quantization
An attempted method to compress Gaussian positions by quantizing them to a lattice structure and embedding positional constraints into the training process [S5]. Fails to compress positions without introducing significant rendering error [S5]. Identified as a future research direction for end-to-end positional compression [S5].

### Post-finetune Refinement
A refinement step that uses a small number of bits to enhance the reconstruction quality of important voxels, compensating for losses introduced by coarse quantization [S6]. Ablation study on Synthetic-NeRF dataset shows disabling post-finetune causes a -1.72 dB $\Delta$PSNR, -0.07 $\Delta$SSIM, and -0.079 MB $\Delta$Size [S6]. Disabling post-finetune saves bits but inevitably deteriorates rendering quality, confirming its necessity for maintaining RD performance [S6].

### Vector Quantization Rendering
Apply vector quantization in the spatial domain to compress the volume. Directly render the quantized blocks using regular spatial domain volume rendering algorithms [S7, book].

## Background
Quantization is a foundational technique in data compression, originating in signal processing and image coding. In the context of volume rendering, it has been adapted to handle the large datasets generated by medical imaging, scientific simulations, and 3D graphics. Early applications included scalar quantization for terrain data [S2] and vector quantization for volumetric visualization [S7, book]. More recently, with the rise of neural radiance fields (NeRFs) and 3D Gaussian splatting, quantization has become critical for compressing neural network parameters and feature grids [S1, S5, S6]. The technique is widely used in standard image and video codecs (e.g., JPEG, MPEG) which rely on transform-based quantization [S1], and in texture compression formats (e.g., BC6H) which use specialized unquantization functions .
