# Quantization

Also called: Quantization with Matrix

## Overview
Quantization is a lossy compression technique that maps continuous or high-precision volumetric data to a discrete set of values, reducing the bit-depth required for storage and transmission. It solves the problem of excessive memory footprint in volume rendering by exploiting the redundancy in data precision, often in conjunction with transform-based methods. Unlike [Triadic frequency band decomposition](828-triadic-frequency-band-decomposition.md) which focuses on spatial frequency separation, quantization focuses on amplitude precision reduction, and unlike [Neural Implicit Network Compression](10414-neural-implicit-network-compression.md) which replaces data with learned functions, quantization retains explicit coefficient storage but with reduced precision.

## Shared principles
The family of quantization methods shares the fundamental mechanism of mapping a continuous input domain to a discrete set of levels. While specific implementations vary (scalar, vector, attribute, or neural), the core principle involves a quantization function $Q(x)$ that maps an input value $x$ to a quantized index or value $q$, and a reconstruction function $Q^{-1}(q)$ that approximates the original value. The error introduced by this mapping, known as quantization error, is the primary trade-off for compression. Methods may use uniform spacing between levels or data-dependent codebooks. In the context of the parent [Value compression](6-value-compression.md), quantization is typically applied after a linear transform to decorrelate the data, concentrating energy into fewer coefficients that can be coarsely quantized with minimal perceptual impact.

## Subtopics

### [Vector Quantization](907-vector-quantization.md)
Maps $n$-dimensional input vectors to a fixed-length index referencing a codebook entry. Chosen for high spatial coherence data and real-time GPU rendering due to fast decompression.

### [Attribute Quantization](1912-attribute-quantization.md)
Reduces precision of voxel attributes (colors, normals) using perceptually uniform spaces (CIELAB, Octahedron). Chosen for attribute arrays to maintain perceptual quality while lowering memory.

### [Scalar Quantization](5726-scalar-quantization.md)
Maps a block of voxels to a local range defined by block-specific min/max values. Chosen for random-access decompression and parallel GPU processing without full-resolution loading.

### [Uniform Quantization](5855-uniform-quantization.md)
Maps input to discrete levels with equal spacing. Chosen for simplicity and low bit-depth reduction (e.g., float to int), but less effective for wide dynamic range data.

### [Chroma Subsampling](6512-chroma-subsampling.md)
Lowers chrominance resolution while maintaining luminance. Chosen for volumetric color data to reduce bitrate while preserving perceived color quality, using median aggregation for sparse data.

### [Differentiable Quantization for Neural Fields](10195-differentiable-quantization-for-neural-fields.md)
Quantizes grid values to single bytes during training using a Straight-Through Estimator. Chosen for neural radiance fields to reduce memory footprint without quality degradation from post-training mismatch.

### [Neural Implicit Network Compression](10414-neural-implicit-network-compression.md)
Quantizes network weights of coordinate-based MLPs. Chosen for infinite-resolution queries and parametric storage, replacing explicit coefficients with learned functions.

### Lossy Quantization for Coarsened Patches
A method for lossy compression of coarsened patches in a bintree hierarchy where quantization error $q$ is proportional to coarsening error $c$ ($q = qc$, with $q < 1$) [S2]. A single unified error is recomputed and nested for each patch. Quantization levels are restricted to power-of-two multiples of vertical resolution $\Delta z$ for efficient bit-shift implementation. The shift $k$ is calculated as $k = \lceil \log_2(\epsilon_q / \Delta z) \rceil + 1$ if $\epsilon_q \ge \Delta z$, else $0$. All finest level vertices have zero shift. Vertices are classified as boundary (corners $C$, legs $L$, hypotenuse $H$) and interior $I$. Corners are stored at full precision. Quantization of original height values (not residuals) ensures adjacent patches agree on shared boundaries [S2].

### HSV Colour Sorting
A technique to preserve color quality during DXT1 compression by reordering colors based on HSV values before compression [S3, unofficial]. The effectiveness depends on which HSV component (H, S, or V) is the most frequent in the voxel data's set of colors [S3, unofficial].

### Interpolation Symmetry Quantization
A method to improve the accuracy of quantized weights by exploiting the symmetry of linear interpolation between segments [S4]. It quantizes both $w$ and $1 - w$ using the codebook generated by the scalar quantizer, keeping the representation resulting in the lower error. It stores either $(i, j, w)$ or $(j, i, 1 - w)$ in the output stream, where linear interpolation is $(1 - w)s_i + w s_j$ [S4].

### Position Lattice Quantization
An attempted method to compress Gaussian positions by quantizing them to a lattice structure and embedding positional constraints into the training process [S5]. It fails to compress positions without introducing significant rendering error and is identified as a future research direction for end-to-end positional compression [S5].

### Quantization and Entropy Encoding/Decoding Pipeline
A compression procedure involving quantization followed by entropy encoding (range-coder) for compression, and entropy decoding for decompression [S6]. The procedure converts compressed data to non-negative values to enable compression into int8 format, then reverts to the original range during decompression. The formula is $\hat{x} = \frac{D(E(Q(q \cdot x) - Q(q \cdot \min(x)))) + Q(q \cdot \min(x))}{q}$, where $E$ is entropy encoder, $D$ is entropy decoder, $Q$ is quantization, and $q$ is the quantization parameter. Adjusting $q$ trades off reconstruction quality and model storage size [S6].

### Post-finetune Refinement
A refinement step that uses a small number of bits to enhance the reconstruction quality of important voxels, compensating for losses introduced by coarse quantization [S7]. An ablation study on the Synthetic-NeRF dataset shows that disabling post-finetune causes a -1.72 dB $\Delta$PSNR, -0.07 $\Delta$SSIM, and -0.079 MB $\Delta$Size [S7]. Disabling it saves bits but inevitably deteriorates rendering quality, confirming its necessity for maintaining RD performance [S7].

## Background
Quantization is a foundational technique in signal processing and data compression, widely used in image and video coding standards (e.g., JPEG, MPEG) and adapted for volumetric data. In volume rendering, it is often employed in conjunction with transform-based methods to reduce the precision of coefficients. The specific application of quantization matrices based on psycho-visual experiments for 3D DCT coefficients was detailed in the context of Neural Residual Radiance Fields (ReRF) [S1]. The method allows for variable bitrates via a scaling factor $S_q$, enabling dynamic adaptive streaming [S1]. The quantized coefficient is given by $\hat{R}(u,v,w) = \text{round}\left(\frac{R(u,v,w)}{S_q \times Q(u,v,w)}\right)$ [S1]. The quantization matrix $Q(u,v,w)$ values are constructed based on psycho-visual experiments [S1].
