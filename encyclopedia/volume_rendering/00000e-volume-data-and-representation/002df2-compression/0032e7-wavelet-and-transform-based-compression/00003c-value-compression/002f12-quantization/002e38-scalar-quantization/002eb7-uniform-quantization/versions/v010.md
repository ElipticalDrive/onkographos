# Uniform Quantization


## Overview
Uniform quantization is a lossy compression method that maps a continuous or high-precision source domain to a discrete set of levels with fixed spacing, typically reducing 32-bit data to 8 bits for a 4:1 compression ratio [S1, S2, unofficial]. It solves the problem of storing and transmitting large volume datasets by limiting the number of distinct values, but differs from non-uniform and adaptive quantizers by using a constant step size regardless of the data distribution [S1, S2, unofficial]. While simple to implement, it is less effective than non-uniform methods at minimizing distortion error for data with wide dynamic ranges or specific feature importance [S1, S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A volume dataset $V$ containing raw data values $x$, typically 32-bit floating-point or integer values.
*   **Output:** A quantized dataset where each value $x$ is mapped to a discrete index $q$ or representative value $\phi_i$, stored with fewer bits (e.g., 8 bits).

**Data Structures:**
*   **Quantization Levels:** A set of $M$ representative values $\phi_i$. For uniform quantization over range $[x_{min}, x_{max}]$, these are evenly spaced.
*   **Bit Depth:** The number of bits $b$ used to store the quantized index, where $M = 2^b$. Commonly $b=8$ for 32-bit input [S1, S2, unofficial].

**Parameters:**
*   $x_{min}$: Minimum value in the dataset or defined range.
*   $x_{max}$: Maximum value in the dataset or defined range.
*   $M$: Number of quantization levels. Typically $M=256$ for 8-bit storage [S2, unofficial].
*   $\phi$: Step size, defined as $\phi = (x_{max} - x_{min}) / M$ [S2, unofficial].

**Steps:**
1.  **Determine Range:** Identify $x_{min}$ and $x_{max}$ of the source data. If the data has a wide dynamic range, care must be taken as important features may become invisible if the range is too large [S1, S2, unofficial].
2.  **Calculate Step Size:** Compute the uniform step size $\phi = (x_{max} - x_{min}) / M$ [S2, unofficial].
3.  **Map to Index:** For each data value $x$, compute the quantization index $q$:
    $$ q = \left\lfloor \frac{x - x_{min}}{\phi} \right\rfloor $$
    Clamp $q$ to the range $[0, M-1]$ to handle values outside $[x_{min}, x_{max}]$ [G].
4.  **Store/Reconstruct:** Store $q$ using $b$ bits. To reconstruct, map $q$ back to a representative value $\phi_i$. The simplest reconstruction is the midpoint of the bin:
    $$ \phi_i = x_{min} + (q + 0.5) \phi $$
    Alternatively, the lower bound $x_{min} + q \phi$ may be used [G].

**Error Measure:**
For uniformly distributed source data values $x$, the mean squared error (MSE) is given by [S2, unofficial]:
$$ \sigma^2 = \int_{x_{min}}^{x_{max}} \frac{1}{M} (x - \phi_i)^2 dx $$
where $f(x) = \frac{1}{x_{max} - x_{min}}$ is the probability density function for uniform distribution [S2, unofficial].

For visualization tasks, an importance function $\alpha(x)$ (e.g., opacity transfer function) is included to weight the error [S1, S2, unofficial]:
$$ \sigma^2 = E \int (x - \phi(x))^2 f(x) \alpha(x) dx $$
where $f(x)$ characterizes the general source data distribution and $\alpha(x)$ is the user-provided importance function [S1, S2, unofficial].

**Pitfalls:**
*   **Wide Dynamic Range:** In datasets with wide dynamic ranges (e.g., turbulence flow), uniform quantization can cause important features in later time steps to become invisible if not handled with care [S1, S2, unofficial].
*   **Feature Loss:** Unlike non-uniform quantization, uniform quantization does not allocate more levels to ranges of interest, potentially leading to higher distortion error for specific features [S1, S2, unofficial].

## Subtopics

### [Non-uniform Quantization](5858-non-uniform-quantization.md)
Allocates more levels to specific ranges to enhance features; chosen when data has wide dynamic range or specific importance functions.

## Operating characteristics
*   **Compression Ratio:** Typically 4:1, achieved by representing 32-bit data with 8 bits [S1, S2, unofficial].
*   **Complexity:** Time complexity is $O(N)$ for $N$ voxels, as each value requires a simple arithmetic operation. Memory complexity is reduced by the factor of the bit depth ratio (e.g., 4x for 32-bit to 8-bit).
*   **Performance:** Simple and fast to implement and decode. However, it may not preserve visual quality as well as non-uniform methods for complex data distributions [S1, S2, unofficial].
*   **Strengths:** Simplicity, low computational overhead, predictable memory usage.
*   **Limitations:** Poor performance with wide dynamic range data; does not adapt to data statistics or user-defined importance functions [S1, S2, unofficial].
*   **When to Use:** When data distribution is uniform or when simplicity and speed are prioritized over optimal visual fidelity.
*   **When Not to Use:** When data has wide dynamic range or specific features require higher precision (use [Non-uniform Quantization](5858-non-uniform-quantization.md) instead) [S1, S2, unofficial].

## Background
Uniform quantization is a well-studied area in signal processing and data compression. In the context of volume rendering, its impact was not carefully studied until the late 1990s. The method is described in the paper "Efficient Encoding and Rendering of Time-Varying Volume Data" by researchers associated with NASA and DTIC, published around 1998 [S1, S2, unofficial]. The paper highlights that while quantization is simple, its effect on visualization quality, especially for time-varying data with wide dynamic ranges, requires careful consideration [S1, S2, unofficial].
