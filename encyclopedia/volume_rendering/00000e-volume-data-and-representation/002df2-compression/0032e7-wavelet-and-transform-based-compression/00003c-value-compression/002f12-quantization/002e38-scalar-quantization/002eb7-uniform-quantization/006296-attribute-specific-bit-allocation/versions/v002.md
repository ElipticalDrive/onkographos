# Attribute-specific Bit Allocation

Also called: Channel-wise bit allocation

## Overview
Attribute-specific Bit Allocation is a lossy compression technique that assigns different bit depths to different attribute channels of a volumetric representation based on their individual sensitivity to quantization error [S1]. Unlike Uniform Quantization, which applies a single bit depth to all data, this method guides quantization by identifying the saturation points of specific attributes, allowing coarser quantization for less critical parameters while preserving precision for those that significantly impact rendering quality [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A set of volumetric attributes (e.g., opacity, scale, rotation, spherical harmonic coefficients) [S1].
*   **Output:** Quantized attribute values stored with variable bit depths per channel, and the bit allocation table defining the storage format [S1].

**Data Structures**
The bit allocation is defined per attribute channel. The specific layout for the proposed scheme is:

| Parameter (Attribute Channel) | Bit Depth ($b^*_i$) |
| :--- | :--- |
| Alpha ($\alpha$) | 8 bits |
| Scale ($e_i, i \in [1,3]$) | 8 bits |
| Color 0th order ($C_i$) | 10 bits |
| Scale ($s_i, i \in [1,3]$) | 4 bits |
| Color 1st order ($C_i$) | 4 bits |
| Color 2nd order ($C_i$) | 2 bits |
| Color 3rd order ($C_i$) | 2 bits |

The source distinguishes between two types of scale parameters, $e_i$ and $s_i$, assigning 8 bits to the former and 4 bits to the latter [S1].

**Method Steps**
1.  **Analyze Saturation Points:** Determine the rate-distortion (RD) characteristics for each attribute channel by evaluating how visual quality changes with bit depth [S1].
2.  **Assign Bit Depths:** Assign the saturation-based bit depth $b^*_i$ to each attribute channel $i$ according to the allocation table [S1].
3.  **Quantize:** Apply uniform quantization to each attribute channel using its assigned bit depth $b^*_i$ [S1].
4.  **Encode:** Store the quantized values using the specified bit widths [S1].

**Formulas**
The total bit depth for an attribute $i$ is $b^*_i$ [S1]. The quantization distortion is minimized by balancing the rate and distortion loss:
$$ L_D = (1 - \lambda_{SSIM})L_1 + \lambda_{SSIM}L_{SSIM} $$
where $L_D$ is the distortion loss, $L_1$ is the L1 loss, $L_{SSIM}$ is the SSIM loss, and $\lambda_{SSIM}$ is a weighting factor [S1].

**Parameters**
*   $\lambda_{SSIM}$: Weight for SSIM loss. Not given in the sources.
*   Bit depths: As specified in the Data Structures table [S1].

**Edge Cases and Pitfalls**
*   **Precision Requirements:** Some attributes, particularly scale parameters, require finer precision due to their high impact on rendering quality, making uniform allocation suboptimal [S1].
*   **Generalization:** The saturation behavior is consistent across scenes, supporting the generalization of bit allocation decisions without requiring scene-specific tuning [S1].

**Pseudocode**
```python
# Bit allocation table derived from saturation analysis [S1]
BIT_ALLOCATION = {
    'alpha': 8,
    'scale_e': 8,
    'color_0th': 10,
    'scale_s': 4,
    'color_1st': 4,
    'color_2nd': 2,
    'color_3rd': 2
}

def quantize(value, bit_depth):
    # Uniform quantization over a normalized range [min_val, max_val]
    # The exact range is not given in the sources. [G]
    min_val, max_val = 0.0, 1.0
    levels = 2 ** bit_depth
    step = (max_val - min_val) / levels
    quantized = round((value - min_val) / step) * step + min_val
    return max(min_val, min(max_val, quantized))

def compress(attributes):
    compressed = {}
    for attr_name, values in attributes.items():
        if attr_name in BIT_ALLOCATION:
            bits = BIT_ALLOCATION[attr_name]
            compressed[attr_name] = [quantize(v, bits) for v in values]
        else:
            # Handling for attributes not in the allocation table is not given in the sources.
            pass
    return compressed
```

## Subtopics

### Non-uniform Quantization
A method that uses non-uniform step sizes for quantization, often based on probability distributions [G]. It differs from Attribute-specific Bit Allocation by varying the step size within a channel rather than varying the bit depth across channels [G]. Choose when attribute distributions are highly non-uniform [G]. [Non-uniform Quantization](5858-non-uniform-quantization.md)

## Operating characteristics
**Time and Memory Complexity**
*   **Memory:** On the Room scene, it achieves 24.88 MB size compared to 26.15 MB for 8-bit uniform [S1]. On the Truck scene, it achieves 18.08 MB compared to 44.87 MB for 8-bit uniform [S1]. On the Mic scene, it achieves 20.30 MB compared to 7.44 MB for 8-bit uniform [S1]. The average compression gain compared to 8-bit uniform allocation is 3.3x [S1].
*   **Time:** The quantization step is integrated into the optimization loop using a straight-through estimator, which approximates gradients through the non-differentiable quantization step [S1].

**Measured Performance**
*   **Room Scene:** 31.7 dB PSNR, 24.88 MB size (vs. 31.15 dB, 26.15 MB for 8-bit uniform; 20.71 dB, 9.09 MB for 6-bit uniform) [S1].
*   **Truck Scene:** 25.62 dB PSNR, 18.08 MB size (vs. 25.61 dB, 44.87 MB for 8-bit uniform; 28.22 dB, 10.85 MB for 6-bit uniform) [S1].
*   **Mic Scene:** 35.54 dB PSNR, 20.30 MB size (vs. 35.13 dB, 7.44 MB for 8-bit uniform; 6.21 dB, 2.57 MB for 6-bit uniform) [S1].

**Strengths and Limitations**
*   **Strengths:** Outperforms 6-bit uniform quantization in both quality and rate, as some attributes require finer precision [S1]. Compared to 8-bit uniform allocation, it achieves an average compression gain of 3.3x with a negligible quality loss of only 0.32 dB [S1].
*   **Limitations:** The Mic scene shows a size increase compared to 8-bit uniform, indicating that the fixed bit allocation may not be optimal for all scenes or attribute distributions [S1].

**When to Use**
*   Use when different attributes have varying sensitivities to quantization error and when a fixed bit depth leads to suboptimal compression or quality [S1].

## Background
Attribute-specific Bit Allocation was proposed in the context of compressing 3D Gaussian Splats [S1]. The method is based on the observation that different attributes saturate at different bit depths, with higher-order spherical harmonic coefficients tolerating coarser quantization than lower-order coefficients or scale parameters [S1]. The approach was introduced in "Improved RAHT-based Compression of 3D Gaussian Splats" [S1].
