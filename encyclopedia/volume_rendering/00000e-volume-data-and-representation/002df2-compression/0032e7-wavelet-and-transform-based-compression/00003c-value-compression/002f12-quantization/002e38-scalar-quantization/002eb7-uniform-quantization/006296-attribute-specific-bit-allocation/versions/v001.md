# Attribute-specific Bit Allocation

Also called: Channel-wise bit allocation

## Overview
Attribute-specific Bit Allocation is a lossy compression technique that assigns different bit depths to different attribute channels of a volumetric representation based on their individual sensitivity to quantization error [S1]. Unlike Uniform Quantization, which applies a single bit depth to all data, this method guides quantization by identifying the saturation points of specific attributes, allowing coarser quantization for less critical parameters while preserving precision for those that significantly impact rendering quality [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A set of volumetric attributes (e.g., opacity, scale, rotation, spherical harmonic coefficients) derived from a 3D Gaussian Splatting model or similar representation.
*   **Output:** Quantized attribute values stored with variable bit depths per channel, and the bit allocation table defining the storage format.

**Data Structures**
The bit allocation is defined per attribute channel. The specific layout for the proposed scheme is:

| Parameter (Attribute Channel) | Bit Depth ($b^*_i$) |
| :--- | :--- |
| Alpha ($\alpha$) | 8 bits |
| Scale ($e_i, i \in [1,3]$) | 8 bits |
| Color 0th order ($C_i$) | 10 bits |
| Scale ($s_i, i \in [1,3]$) | 4 bits |
| Color 1st order ($C_i$) | 4 bits |
| Color 2nd order ($C_i$) | 2 bits |
| Color 3rd order ($C_i$) | 2 bits |

*Note: The source distinguishes between two types of scale parameters, $e_i$ and $s_i$, assigning 8 bits to the former and 4 bits to the latter [S1].*

**Method Steps**
1.  **Analyze Saturation Points:** Determine the rate-distortion (RD) characteristics for each attribute channel. Identify the bit depth at which visual quality saturates (i.e., further increasing bit depth yields negligible PSNR improvement) [S1].
    *   Example: Higher-order attributes (like 2nd order SH) exhibit flatter RD curves and saturate near 4 bpp, tolerating coarser quantization [S1].
    *   Example: Attributes like scale parameters require finer precision due to high impact on rendering quality [S1].
2.  **Assign Bit Depths:** Assign the determined saturation-based bit depth ($b^*_i$) to each attribute channel $i$ according to the allocation table [S1].
3.  **Quantize:** Apply uniform quantization to each attribute channel using its assigned bit depth $b^*_i$.
    *   The quantization step is integrated into the optimization loop using a straight-through estimator to approximate gradients through the non-differentiable quantization step [S1].
4.  **Encode:** Store the quantized values using the specified bit widths.

**Formulas**
The total bit depth for an attribute $i$ is $b^*_i$. The quantization distortion is minimized by balancing the rate and distortion loss:
$$ L_D = (1 - \lambda_{SSIM})L_1 + \lambda_{SSIM}L_{SSIM} $$
where $L_D$ is the distortion loss, $L_1$ is the L1 loss, $L_{SSIM}$ is the SSIM loss, and $\lambda_{SSIM}$ is a weighting factor [S1].

**Parameters**
*   $\lambda_{SSIM}$: Weight for SSIM loss. Not given in the sources.
*   Bit depths: As specified in the Data Structures table [S1].

**Edge Cases and Pitfalls**
*   **Precision Requirements:** Some attributes, particularly scale parameters, require finer precision. Uniform quantization may be suboptimal if these are down-sampled to the same bit depth as less sensitive attributes [S1].
*   **Generalization:** The saturation points observed are consistent across scenes, supporting generalization of bit allocation decisions without requiring scene-specific tuning [S1].

**Pseudocode**
```python
# Define bit allocation based on saturation analysis
bit_allocation = {
    'alpha': 8,
    'scale_e': 8,  # Scale parameter e_i
    'color_0th': 10,
    'scale_s': 4,  # Scale parameter s_i
    'color_1st': 4,
    'color_2nd': 2,
    'color_3rd': 2
}

def quantize_attribute(value, bit_depth):
    """
    Quantizes a value to the specified bit depth.
    Assumes value is normalized to [0, 1] or similar range.
    """
    if bit_depth == 0:
        return 0
    
    # Determine quantization step
    # Assuming uniform quantization over a normalized range [0, 1]
    # In practice, range might be determined by attribute statistics
    max_val = 1.0 
    min_val = 0.0
    
    levels = 2 ** bit_depth
    step = (max_val - min_val) / levels
    
    # Quantize
    quantized = round((value - min_val) / step) * step + min_val
    
    # Clip to valid range
    quantized = max(min_val, min(max_val, quantized))
    
    return quantized

def compress_attributes(attributes):
    """
    Compresses attributes using attribute-specific bit allocation.
    attributes: dict mapping attribute name to list of values
    """
    compressed = {}
    for attr_name, values in attributes.items():
        if attr_name in bit_allocation:
            bits = bit_allocation[attr_name]
            # Apply quantization
            quantized_values = [quantize_attribute(v, bits) for v in values]
            compressed[attr_name] = quantized_values
        else:
            # Fallback or error handling for unknown attributes
            # Not given in the sources.
            pass
    return compressed
```

## Subtopics

### Non-uniform Quantization
A method that uses non-uniform step sizes for quantization, often based on probability distributions. It differs from Attribute-specific Bit Allocation by varying the step size within a channel rather than varying the bit depth across channels. Choose when attribute distributions are highly non-uniform. [Link](5858-non-uniform-quantization.md)

## Operating characteristics
**Time and Memory Complexity**
*   **Memory:** The method achieves significant compression gains. On the Room scene, it reduces size from 26.15 MB (8-bit uniform) to 24.88 MB. On the Truck scene, it reduces size from 44.87 MB to 18.08 MB. On the Mic scene, it reduces size from 7.44 MB to 20.30 MB (Note: The Mic scene size increases, likely due to the higher bit depth for 0th order color). The average compression gain compared to 8-bit uniform allocation is 3.3x [S1].
*   **Time:** The quantization step is integrated into the optimization loop using a straight-through estimator, which adds minimal computational overhead during training but requires careful gradient approximation [S1].

**Measured Performance**
*   **Room Scene:** 31.7 dB PSNR, 24.88 MB size (vs. 31.15 dB, 26.15 MB for 8-bit uniform; 20.71 dB, 9.09 MB for 6-bit uniform) [S1].
*   **Truck Scene:** 25.62 dB PSNR, 18.08 MB size (vs. 25.61 dB, 44.87 MB for 8-bit uniform; 28.22 dB, 10.85 MB for 6-bit uniform) [S1].
*   **Mic Scene:** 35.54 dB PSNR, 20.30 MB size (vs. 35.13 dB, 7.44 MB for 8-bit uniform; 6.21 dB, 2.57 MB for 6-bit uniform) [S1].

**Strengths and Limitations**
*   **Strengths:** Achieves higher compression ratios than uniform quantization with negligible quality loss (average 0.32 dB loss compared to 8-bit uniform). Outperforms 6-bit uniform quantization in both quality and rate for scenes where some attributes require finer precision [S1].
*   **Limitations:** The Mic scene shows a significant increase in size compared to 8-bit uniform, indicating that the fixed bit allocation may not be optimal for all scenes or attribute distributions. The method assumes that saturation points are consistent across scenes, which may not hold for all types of volumetric data [S1].

**When to Use**
*   Use when different attributes have varying sensitivities to quantization error and when a fixed bit depth leads to suboptimal compression or quality. It is particularly effective for 3D Gaussian Splatting models where attributes like scale and color have different importance [S1].

## Background
Attribute-specific Bit Allocation was proposed in the context of compressing 3D Gaussian Splats. The method is based on the observation that different attributes saturate at different bit depths, with higher-order spherical harmonic coefficients tolerating coarser quantization than lower-order coefficients or scale parameters [S1]. The approach was introduced in "Improved RAHT-based Compression of 3D Gaussian Splats" [S1].
