# Non-uniform Quantization

Also called: Adaptive Quantization, Logarithmic Quantization

## Overview
Non-uniform quantization is a lossy compression method that allocates more quantization levels to a particular range of source data values to enhance specific features and minimize distortion error, rather than using uniform spacing [S1, unofficial][S2, unofficial]. It solves the problem of volume data with a wide dynamic range, where uniform spacing would cause important features to become invisible [S1, unofficial][S2, unofficial]. It differs from uniform quantization by adapting level density to either the source data distribution or a user-defined importance function [S1, unofficial][S2, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Source volume data values $x$, number of quantization levels $L$, importance function $\alpha(x)$, and optionally the probability density function $f(x)$ [S1, unofficial][S2, unofficial].
- Output: Quantized indices representing the source data [S1, unofficial][S2, unofficial].

**Data Structures:**
- Exact layouts, fields, sizes, and bit packing are Not given in the sources [S1, unofficial][S2, unofficial].

**Formulas:**
The distortion measure $D$ for non-uniform quantization incorporates an importance function $\alpha(x)$, typically the opacity transfer function in volume rendering [S1, unofficial][S2, unofficial]:
$$
D = \int (x - \hat{x})^2 \alpha(x) f(x) dx
$$
where:
- $x$ is the source value.
- $\hat{x}$ is the reconstructed value.
- $f(x)$ is the general source data distribution [S1, unofficial][S2, unofficial].
- $\alpha(x)$ is the importance function provided by the user [S1, unofficial][S2, unofficial].

**Steps:**
1. **Define Importance:** Determine the importance function $\alpha(x)$, which in volume rendering corresponds to the user-defined opacity transfer function [S1, unofficial][S2, unofficial].
2. **Analyze Statistics:** Obtain the probability density function $f(x)$ of the source data, or assume a uniform distribution if statistics are unavailable [G].
3. **Select Mapping Strategy:** For data with a wide dynamic range, apply a logarithmic mapping to compress the value range before quantization [S1, unofficial][S2, unofficial]. For general cases, set quantization levels adaptively to minimize the weighted distortion $D$ [S1, unofficial][S2, unofficial].
4. **Quantize:** Map each source value $x$ to its corresponding quantization level using the chosen mapping or adaptive boundaries [S1, unofficial][S2, unofficial].

**Pseudocode:**
```python
import math

def non_uniform_quantize(data, num_levels, importance_func=None):
    """
    Quantize volume data using non-uniform spacing.
    data: array of source values
    num_levels: number of quantization levels (L)
    importance_func: optional function alpha(x) for weighted distortion [S1, unofficial][S2, unofficial]
    """
    if num_levels < 2:
        return [0] * len(data)  # Guard for degenerate level count [G]
        
    min_val = min(data)
    max_val = max(data)
    
    # Logarithmic mapping for wide dynamic range [S1, unofficial][S2, unofficial]
    # Handle zero/negative values to avoid log domain errors [G]
    offset = 1.0 if min_val <= 0 else 0.0
    shifted_data = [x + offset for x in data]
    
    log_min = math.log(min(shifted_data))
    log_max = math.log(max(shifted_data))
    log_step = (log_max - log_min) / (num_levels - 1)
    
    indices = []
    for x in shifted_data:
        log_x = math.log(x)
        idx = int((log_x - log_min) / log_step)
        indices.append(max(0, min(num_levels - 1, idx)))
        
    # Adaptive quantization based on f(x) and alpha(x) to minimize D
    # is not fully specified in the sources [G]
    return indices
```

**Edge Cases:**
- **Wide Dynamic Range:** Data with extreme variations (e.g., turbulence flow datasets) requires careful quantization to prevent important features from becoming invisible [S1, unofficial][S2, unofficial].
- **Missing Statistics or Importance Function:** The sources do not specify fallback behavior when $f(x)$ or $\alpha(x)$ are unavailable [S1, unofficial][S2, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources [S1, unofficial][S2, unofficial].
- **Memory Complexity:** Not given in the sources [S1, unofficial][S2, unofficial].
- **Performance:** More effective than uniform quantization at minimizing distortion error and enhancing specific features in volume data [S1, unofficial][S2, unofficial].
- **Strengths:** Preserves and enhances particular features in the data; allocates more levels to ranges of interest [S1, unofficial][S2, unofficial].
- **Limitations:** Requires knowledge of source data statistics or an importance function; data values outside the range of interest and their distortion error are ignored [S1, unofficial][S2, unofficial].

## Background
Developed for the efficient encoding and rendering of time-varying volume data [S1, unofficial][S2, unofficial]. It was applied to datasets with multiple time steps, such as an 81-step turbulence flow simulation, where wide dynamic ranges would otherwise obscure important features [S1, unofficial][S2, unofficial].
