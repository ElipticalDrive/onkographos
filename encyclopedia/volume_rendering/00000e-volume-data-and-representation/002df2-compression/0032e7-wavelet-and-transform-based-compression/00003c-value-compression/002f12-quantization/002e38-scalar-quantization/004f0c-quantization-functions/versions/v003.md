# Quantization Functions

Also called: Quantize10, Quantize7, Quantize9

## Overview
Quantization functions map continuous floating-point values to discrete integer representations to enable storage or transmission via standard codecs [S1, unofficial]. This method defines the mathematical mapping and spatial channel packing strategies required to convert multichannel feature planes into fixed-precision integer canvases compatible with image and video compression standards [S1, unofficial]. It differs from [Scalar Quantization](5726-scalar-quantization.md) by focusing on global or channel-wise normalization for codec compatibility rather than per-block random-access reconstruction, and from [Uniform Quantization](5855-uniform-quantization.md) by explicitly coupling numerical range mapping with packing strategies to minimize cross-channel mixing artifacts during encoding [S1, unofficial].

## How it works

### Inputs and Outputs
*   **Input:** Multichannel floating-point tensor $X \in \mathbb{R}^{C \times H \times W}$ [S1, unofficial].
*   **Output:** Quantized integer tensor $X_{01}$ in range $[0, 1]$ (or mapped to codec bit-depth), and packed canvas $Y$ with dimensions $[C_{out}, H', W']$ where $C_{out} \in \{1, 3\}$ [S1, unofficial].

### Data Structures
*   **Float Tensor:** $X \in \mathbb{R}^{C \times H \times W}$ [S1, unofficial].
*   **Canvas:** $Y \in \mathbb{Z}^{C_{out} \times H' \times W'}$, where pixel values are integers suitable for standard codecs (e.g., 8-bit or 10-bit) [S1, unofficial].

### Steps and Formulas
1.  **Range Estimation:** Determine the normalization bounds $[\alpha, \beta]$ for each channel [S1, unofficial].
    *   **AbsMax:** A fixed range shared by all channels [S1, unofficial].
    *   **Channelwise:** Estimate the per-channel central 95% range [S1, unofficial]. Let $\alpha_c$ and $\beta_c$ be the lower and upper bounds for channel $c$ [S1, unofficial].
2.  **Normalization and Quantization:** Map each element $X_{c,h,w}$ to $[0, 1]$ using the estimated bounds [S1, unofficial].
    $$
    X_{01, c, h, w} = \text{clip}\left( \frac{X_{c, h, w} - \alpha_c}{\beta_c - \alpha_c}, 0, 1 \right)
    $$
    Where $\text{clip}(v, 0, 1)$ limits the value to the interval $[0, 1]$ [S1, unofficial].
3.  **Dequantization (Reconstruction):** To recover the approximate original value $\widehat{X}$:
    $$
    \widehat{X}_{c, h, w} = X_{01, c, h, w} (\beta_c - \alpha_c) + \alpha_c
    $$
    [S1, unofficial]
4.  **Packing:** Rearrange the normalized tensor $X_{01}$ into a codec-friendly canvas $Y$ with $C_{out} \in \{1, 3\}$ channels [S1, unofficial]. Three strategies are defined for an input with $C=48$ channels:
    *   **FlattenGray:** Stacks all channels spatially into a single monochrome canvas [S1, unofficial]. For $C=48$, the layout becomes $[1, 6H, 8W]$ [S1, unofficial]. This avoids cross-channel mixing [S1, unofficial].
    *   **FlattenRGB:** Groups channels into three equal groups [S1, unofficial]. For $C=48$, each group has 16 channels [S1, unofficial]. The layout becomes $[3, 4H, 4W]$ [S1, unofficial].
    *   **PixelShuffle:** Rearranges channels into spatial neighborhoods (spatial-to-depth) [S1, unofficial]. For $C=48$, the layout also becomes $[3, 4H, 4W]$ [S1, unofficial].
5.  **Density Grid Handling:** For density grids $D$ controlling opacity, tile the grid into a single monochrome canvas and encode as grayscale to avoid mixing across channels [S1, unofficial].
6.  **Half-Precision Scaling:** Convert float3 to half-precision and scale to integer range for 7, 9, or 10-bit quantization [S1, unofficial].
    $$
    \text{Quantized} = \frac{\text{Half}(x) \times \text{Scale}}{32767}
    $$
    where Scale is 128, 512, or 1024 for 7, 9, or 10 bits respectively [S1, unofficial].

### Pseudocode
```python
import math

def quantize_and_pack(X, strategy='FlattenGray', density_grid=None):
    """
    Quantize multichannel float tensor X and pack into a codec-compatible canvas.
    X is a 3D list [C][H][W].
    """
    C, H, W = len(X), len(X[0]), len(X[0][0])
    bounds = []
    X_01 = [[[0.0] * W for _ in range(H)] for _ in range(C)]

    # Step 1 & 2: Channelwise Quantization
    for c in range(C):
        channel_data = [X[c][h][w] for h in range(H) for w in range(W)]
        # Estimate central 95% range
        sorted_data = sorted(channel_data)
        n = len(sorted_data)
        alpha = sorted_data[n // 40]  # Approx 2.5th percentile
        beta = sorted_data[n * 39 // 40]  # Approx 97.5th percentile
        bounds.append((alpha, beta))

        # Normalize to [0, 1]
        denom = beta - alpha
        for h in range(H):
            for w in range(W):
                val = (X[c][h][w] - alpha) / denom if denom != 0 else 0.0
                X_01[c][h][w] = max(0.0, min(1.0, val))

    # Step 4: Packing
    if strategy == 'FlattenGray':
        # Stack all channels spatially: [1, 6H, 8W] for C=48
        Y = [[[0.0] * (8 * W) for _ in range(6 * H)] for _ in range(1)]
        idx = 0
        for c in range(C):
            for h in range(H):
                for w in range(W):
                    row = idx // (8 * W)
                    col = idx % (8 * W)
                    Y[0][row][col] = X_01[c][h][w]
                    idx += 1
    elif strategy == 'FlattenRGB':
        # Group into 3 channels of 16 each: [3, 4H, 4W]
        Y = [[[0.0] * (4 * W) for _ in range(4 * H)] for _ in range(3)]
        for c_out in range(3):
            for c_in in range(16):
                base_c = c_out * 16 + c_in
                for h in range(H):
                    for w in range(W):
                        row = (c_in // 4) * H + h
                        col = (c_in % 4) * W + w
                        Y[c_out][row][col] = X_01[base_c][h][w]
    elif strategy == 'PixelShuffle':
        # Spatial-to-depth rearrangement
        Y = [[[0.0] * (4 * W) for _ in range(4 * H)] for _ in range(3)]
        for c_out in range(3):
            for c_in in range(16):
                base_c = c_out * 16 + c_in
                for h in range(H):
                    for w in range(W):
                        row = (c_in // 4) * H + h
                        col = (c_in % 4) * W + w
                        Y[c_out][row][col] = X_01[base_c][h][w]
    else:
        raise ValueError("Unknown strategy")

    # Handle Density Grid if provided
    if density_grid is not None:
        # Tile density grid into single monochrome canvas
        pass

    return Y, bounds
```

### Parameters
*   **Strategy:** Determines packing layout [S1, unofficial]. 'FlattenGray' minimizes cross-channel mixing but may reduce spatial locality for codecs optimized for RGB [S1, unofficial]. 'FlattenRGB' and 'PixelShuffle' group channels to fit standard 3-channel video codecs [S1, unofficial].
*   **Range Estimation Method:** 'Channelwise' uses the central 95% percentile range per channel [S1, unofficial]. 'AbsMax' uses a fixed global range [S1, unofficial].
*   **Bit Depth Scale:** Scale is 128, 512, or 1024 for 7, 9, or 10 bits respectively [S1, unofficial].

### Edge Cases and Pitfalls
*   **Outliers:** If the central 95% range is heavily skewed by outliers, quantization precision for the majority of the data decreases [G]. Consider using robust statistics or clipping extreme values before range estimation [G].
*   **Channel Mixing:** Using 'FlattenRGB' or 'PixelShuffle' mixes information from different feature channels into the same spatial location [S1, unofficial]. This may confuse codecs that assume color correlation between channels [S1, unofficial]. 'FlattenGray' avoids this but may be less efficient for RGB-optimized codecs [S1, unofficial].
*   **Density Grid:** Encoding density as grayscale prevents mixing opacity information with color features, which is critical for correct volume rendering reconstruction [S1, unofficial].
*   **Precision:** Half-precision conversion followed by scaling to integer ranges may introduce rounding artifacts if the dynamic range exceeds the target bit-depth capacity [S1, unofficial].

## Subtopics

### Amplitude-Only Hologram Quantization
A method to generate an amplitude-only hologram $H$ by quantizing the real part of the object wave $O$, normalized between -1 and +1, using a uniform mid-rise quantizer $Q$ with $L$ discrete levels [S2]. It is chosen when energy efficiency is critical for holographic displays [S2]. It differs from standard scalar quantization by using a specific clipping parameter $\Delta$ to balance granular and overload distortions [S2].
*   **Formula:**
    $$
    Q(X, L, \Delta) = 
    \begin{cases} 
    0 & \text{if } X < -\Delta \\
    \frac{(X + \Delta)L}{2\Delta} & \text{if } -\Delta \le X < \Delta \\
    L - 1 & \text{otherwise}
    \end{cases}
    $$
    [S2]
*   **Parameters:**
    *   $L$: Number of discrete quantization levels. Typical value: 256 [S2].
    *   $\Delta$: Input quantizer range clipping value. Typical value: 0.4 [S2]. Controls the balance between energy efficiency and image quality [S2].
*   **Pitfall:** Increasing $\Delta$ improves imaging quality (PSNR/SSIM) but decreases energy efficiency [S2]. At $\Delta = 0.5$, energy efficiency drops to 1.4% for amplitude holograms [S2].

### Bit Depth Conversion with Windowing
Converting 16-bit input data to 8-bit output during resampling, using a defined intensity window to preserve relevant contrast [S3, unofficial]. It is used in medical imaging (e.g., dry bone scans) where the signal range is well-defined [S3, unofficial]. It differs from general quantization by recording the window (min/max or percentile) in metadata for accurate dequantization [S3, unofficial].
*   **Steps:**
    1.  Perform interpolation in floating-point precision [S3, unofficial].
    2.  Map the floating-point result to the output bit depth using the recorded window [S3, unofficial].
*   **Comparison:** 8-bit is sufficient for dry bone because the signal range (26k-36k) maps well to 8-bit steps without losing real data, whereas contrast-stained scans retain 16-bit to preserve lower-intensity details [S3, unofficial].
*   **Pitfall:** Rounding error for 0-40,000 to 8-bit is ~45 grey levels (RMS), against 1678 grey levels of natural variation in bone [S3, unofficial].

### Low-Bit Quantization and Clipping
Reducing memory usage by using lower bit-depth representations (e.g., 16-bit half-floats instead of 32-bit floats) for attributes that do not require high precision [S4]. In SOG, the authors clip various attribute ranges, including RGB, opacity, and spherical harmonics, based on percentile thresholds to ensure consistent normalization across models [S4]. After clipping, they quantize these attributes by rounding to the nearest value within predefined linear ranges $q$, with $q = 2^{14}$ for coordinates, $q = 2^6$ for scale/opacity/rotation, and $q = 2^5$ for SH [S4]. Fan et al. quantize selective Spherical Harmonics, position, shape, rotation, and opacity attributes [S4]. Remaining storage is reduced by packing attributes using codecs like LZ77 or JPEG XL [S4].

### [Quantization and Packing for Standard Codecs](17894-quantization-and-packing-for-standard-codecs.md)
This method maps multichannel floating-point feature planes to fixed-precision integer canvases compatible with standard image and video codecs (e.g., JPEG, AV1). It solves the incompatibility between neural volume representations (which output high-dimensional, continuous tensors) and standard compression pipelines (which expect 1- or 3-channel, fixed-bit-depth images). It sets itself apart from generic quantization by explicitly coupling the numerical range mapping with spatial channel packing strategies designed to minimize cross-channel mixing artifacts during codec encoding.

## Operating characteristics

*   **Time Complexity:** $O(C \cdot H \cdot W)$ for quantization and packing [S1, unofficial]. Range estimation is $O(C \cdot H \cdot W)$ if percentiles are computed per channel [G].
*   **Memory Complexity:** $O(C \cdot H \cdot W)$ for the input and output tensors [S1, unofficial].
*   **Strengths:** Compatible with standard, highly optimized codecs [S1, unofficial]. Channelwise quantization preserves dynamic range per feature [S1, unofficial].
*   **Limitations:** Packing strategies may introduce cross-channel mixing or reduce spatial locality, potentially reducing codec efficiency [S1, unofficial]. Range estimation requires a pass over the data [G].
*   **When to Use:** When compressing neural radiance fields or other multichannel volumetric data for streaming via standard video/image codecs [S1, unofficial].
*   **When Not to Use:** When random-access decompression is required (use [Scalar Quantization](5726-scalar-quantization.md)) or when the data has extreme outliers that skew the central 95% range [G].

## Background

Quantization functions for multichannel data have emerged with the rise of neural radiance fields (NeRFs) and their compression [S1, unofficial]. The specific packing strategies and channelwise quantization for codec compatibility were introduced in the context of CATRF (Codec-Adaptive TriPlane Radiance Fields) for volumetric content delivery [S1, unofficial]. Earlier work in holography used similar quantization principles for amplitude-only holograms [S2], and medical imaging has long used windowing for bit-depth conversion [S3, unofficial]. The specific 7/9/10-bit quantization for half-precision floats converts float3 to half-precision and scales to integer ranges for 7, 9, or 10-bit quantization [S1, unofficial].
