# Differentiable Quantization for Neural Fields

Also called: MERF Quantization, Quantization for Memory Reduction

## Overview
Differentiable Quantization for Neural Fields reduces the memory footprint of 3D Gaussian Splatting and neural radiance fields by compressing grid values to single bytes during the optimization process [S1]. Unlike post-training quantization, which causes quality degradation due to mismatch between the optimized model and the rendering engine, this method integrates quantization into the training loop using a straight-through estimator [S1]. It sets itself apart from sibling methods like [Scalar Quantization](5726-scalar-quantization.md) by ensuring the quantized representation is learned end-to-end, preserving rendering quality while enabling real-time synthesis in unbounded scenes [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Continuous grid values $\tilde{\mathbf{t}}$ (densities, diffuse colors, features) from the neural field.
*   **Output:** Quantized grid values $\tilde{\mathbf{t}}'$ stored as single-byte integers, reconstructed to the target range for rendering.

**Data Structures:**
*   Grid values are stored as 8-bit unsigned integers (bytes).
*   Range parameters $m$ are stored per attribute type (density vs. color/feature).

**Steps:**
1.  **Sigmoid Mapping:** Map the continuous grid value $\tilde{\mathbf{t}}$ to the interval $[0, 1]$ using a sigmoid function $\sigma$:
    $$ x = \sigma(\tilde{\mathbf{t}}) $$
2.  **Quantization:** Apply the quantization function $q(x)$ to map $x$ to the nearest discrete level in an 8-bit space. The function uses a straight-through estimator to allow gradients to flow through the non-differentiable rounding operation:
    $$ q(x) = x + \mathcal{V}\left(\frac{\lfloor (2^8 - 1)x + 1/2 \rfloor}{2^8 - 1} - x\right) $$
    where $\mathcal{V}$ denotes the straight-through estimator (gradient of the identity function for the input $x$, and zero for the quantization error term) [S1].
3.  **Affine Mapping:** Scale and shift the quantized value to the target range $[-m, m]$:
    $$ \tilde{\mathbf{t}}' = 2m \cdot q(\sigma(\tilde{\mathbf{t}})) - m $$
4.  **Interpolation and Summation:** During rendering, linearly interpolate the quantized grid values $\tilde{\mathbf{t}}'$ and sum them. The non-linearities defined in the original field formulation (e.g., exponential for density) are applied *after* this linear interpolation and summation step [S1].

**Parameters:**
*   $m = 14$ for densities (which use an exponential nonlinearity) [S1].
*   $m = 7$ for diffuse colors and features [S1].
*   Bit depth: 8 bits (256 levels) [S1].

**Pitfalls:**
*   **Post-training Quantization:** Simply quantizing grid values after training completes leads to a mismatch between the optimized model and the rendering model, causing significant drops in rendering quality [S1].
*   **Gradient Flow:** The rounding operation is non-differentiable. Without the straight-through estimator, gradients cannot propagate through the quantization step during optimization [S1].

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

def sigmoid_quantize(t, m):
    """
    Quantizes grid values t to single bytes during optimization.
    
    Args:
        t: Continuous grid values (tensor).
        m: Range parameter (14 for density, 7 for color/feature).
        
    Returns:
        Quantized and affine-mapped values t_prime.
    """
    # Step 1: Sigmoid mapping to [0, 1]
    x = torch.sigmoid(t)
    
    # Step 2: Quantization with Straight-Through Estimator
    # Calculate the quantized value
    quantized_level = torch.floor((2**8 - 1) * x + 0.5) / (2**8 - 1)
    
    # Straight-Through Estimator:
    # Forward pass uses quantized_level, backward pass uses x (identity gradient)
    # In PyTorch, this is achieved by detaching the quantized value for the forward pass
    # and using the original x for the backward pass via stop_gradient logic.
    # q(x) = x + (quantized_level - x) where gradient of (quantized_level - x) is 0
    q_x = x + (quantized_level - x).detach()
    
    # Step 3: Affine mapping to [-m, m]
    t_prime = 2 * m * q_x - m
    
    return t_prime

# Example usage during training step:
# t_prime = sigmoid_quantize(t, m=14) # for density
# t_prime = sigmoid_quantize(t, m=7)  # for color/feature
```

## Operating characteristics
*   **Memory Reduction:** Reduces grid memory consumption by storing values as single bytes instead of higher-precision floats [S1].
*   **Performance:** Enables real-time view synthesis in unbounded scenes by lowering memory bandwidth requirements [S1].
*   **Quality:** Maintains rendering quality comparable to full-precision models when quantization is integrated into training, avoiding the quality drops associated with post-training quantization [S1].
*   **Limitations:** Requires careful tuning of range parameters $m$ for different attribute types to prevent clipping or precision loss [S1].

## Background
This method was introduced in the MERF (Memory-Efficient Radiance Fields) paper, which focuses on real-time view synthesis in unbounded scenes [S1]. The authors identified that standard quantization after training caused mismatches between the optimized model and the rendering engine, leading to quality degradation. Their solution was to quantize grid values during optimization using a differentiable approach [S1].
