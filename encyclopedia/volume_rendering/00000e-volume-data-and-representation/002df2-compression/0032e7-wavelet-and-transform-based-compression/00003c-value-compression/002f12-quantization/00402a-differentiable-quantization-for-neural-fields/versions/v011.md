# Differentiable Quantization for Neural Fields

Also called: MERF Quantization, Quantization for Memory Reduction

## Overview
This method reduces the render-time memory footprint of neural radiance fields by quantizing grid-based feature values to single bytes during the training process itself. Unlike post-training quantization, which applies rounding after convergence and causes significant quality degradation due to the mismatch between the optimized continuous model and the discrete rendering model, this approach integrates quantization into the optimization loop. It sets itself apart from sibling methods like [Scalar Quantization](5726-scalar-quantization.md) by using a differentiable approximation (Straight-Through Estimator) to allow gradients to flow through the non-differentiable rounding operation, ensuring the network adapts its parameters to the target precision.

## How it works
**Inputs and Outputs:**
*   **Input:** Raw grid values $\tilde{\mathbf{t}}$ (densities, colors, features) produced by the neural field's feature grid.
*   **Output:** Quantized grid values $\tilde{\mathbf{t}}'$ stored in memory, which are used for interpolation and subsequent non-linearities (e.g., exponential for density, sigmoid for color).

**Data Structures:**
*   The grid stores values as single-byte integers (uint8).
*   Each value represents one of $2^8 = 256$ discrete levels.

**Parameters:**
*   $m$: Scaling factor for affine mapping.
    *   $m = 14$ for densities (due to exponential nonlinearity).
    *   $m = 7$ for diffuse colors and features [S1].
*   $B = 2^8 - 1 = 255$: Number of quantization levels minus one.

**Quantization Function:**
The core mechanism maps continuous values to bytes and back, using a Straight-Through Estimator (STE) for gradients.

1.  **Normalization:** Map raw values $\tilde{\mathbf{t}}$ to $[0, 1]$ using a sigmoid function $\sigma(\cdot)$.
    $$ x = \sigma(\tilde{\mathbf{t}}) $$
2.  **Quantization:** Apply the byte quantization function $q(x)$. This function rounds $x$ to the nearest discrete level and returns the rounded value, but passes the original input $x$ as the gradient during backpropagation.
    $$ q(x) = x + \text{stop\_gradient}\left( \frac{\lfloor (2^8 - 1)x + 1/2 \rfloor}{2^8 - 1} - x \right) $$
    *   The term $\frac{\lfloor (2^8 - 1)x + 1/2 \rfloor}{2^8 - 1}$ computes the discrete quantized value.
    *   The difference is subtracted from $x$ inside `stop_gradient`, effectively replacing the forward pass value with the quantized one while keeping the gradient equal to 1 (Straight-Through Estimator) [S1].
3.  **Affine Mapping:** Scale the quantized value from $[0, 1]$ to $[-m, m]$.
    $$ \tilde{\mathbf{t}}' = 2m \cdot q(\sigma(\tilde{\mathbf{t}})) - m $$

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

def differentiable_quantize(raw_values, m):
    """
    Quantizes raw grid values to single bytes during optimization.
    
    Args:
        raw_values (torch.Tensor): Continuous grid values.
        m (float): Scaling factor (14 for density, 7 for color/features).
        
    Returns:
        torch.Tensor: Quantized values in range [-m, m].
    """
    # 1. Normalize to [0, 1] using sigmoid
    x = torch.sigmoid(raw_values)
    
    # 2. Quantize to 256 levels
    # Calculate discrete levels: floor((255 * x) + 0.5) / 255
    # Use stop_gradient to implement Straight-Through Estimator
    # Forward pass: returns the rounded value
    # Backward pass: gradient flows through the original 'x'
    quantized_x = x + torch.autograd.Function.stop_gradient(
        (torch.floor((255 * x) + 0.5) / 255) - x
    )
    
    # 3. Affine map to [-m, m]
    # Formula: 2 * m * quantized_x - m
    quantized_values = 2 * m * quantized_x - m
    
    return quantized_values
```

**Edge Cases and Pitfalls:**
*   **Post-Training Quantization:** Simply quantizing grid values after training converges leads to a mismatch between the optimized model and the rendering model, causing a drop in rendering quality [S1].
*   **Non-linearity Timing:** The quantization is applied to the grid values *before* subsequent non-linearities (like the exponential for density or sigmoid for color) are applied during rendering. This ensures the non-linearities operate on the quantized values [S1].
*   **Occupancy:** Content is only baked in regions considered occupied by the proposal MLP during training to avoid wasting memory on empty space [S1].

## Subtopics

### [Quantization-Aware Fine-Tuning](11387-quantization-aware-fine-tuning.md)
A post-clustering optimization step designed to regain reconstruction quality lost during vector quantization. It differs by focusing on re-optimizing scene parameters under discrete codebook constraints, whereas this method focuses on byte-level quantization of grid values during the initial training of neural fields.

## Operating characteristics
*   **Memory Reduction:** Reduces grid memory consumption by storing each dimension at every location as a single byte [S1].
*   **Performance:** Enables real-time view synthesis in unbounded scenes by lowering memory bandwidth requirements [S1].
*   **Quality:** Maintains high rendering quality comparable to full-precision models when quantization is integrated during training, avoiding the quality drops associated with post-training quantization [S1].
*   **Limitations:** Requires careful tuning of the scaling factor $m$ for different attribute types (density vs. color) to prevent clipping or loss of precision in critical ranges [S1].

## Background
This method was introduced in the MERF (Memory-Efficient Radiance Fields) paper, which addresses the challenge of rendering high-quality, real-time views of large-scale, unbounded scenes using neural radiance fields. The key insight is that the memory bottleneck in neural fields often lies in the feature grids, and quantizing these grids to single bytes during training allows for significant memory savings without sacrificing visual fidelity [S1].
