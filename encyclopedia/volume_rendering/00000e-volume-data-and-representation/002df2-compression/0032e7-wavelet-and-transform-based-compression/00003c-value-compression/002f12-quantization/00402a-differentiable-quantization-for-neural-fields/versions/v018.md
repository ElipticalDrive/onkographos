# Differentiable Quantization for Neural Fields

Also called: MERF Quantization, Quantization for Memory Reduction

## Overview
Differentiable Quantization for Neural Fields reduces the render-time memory footprint of 3D Gaussian Splatting and neural radiance fields by compressing grid values to single bytes during the optimization process [S1]. Unlike post-training quantization, which applies rounding to already optimized weights and causes significant quality degradation due to the mismatch between the training and inference states, this method integrates quantization directly into the training loop [S1]. It sets itself apart from standard scalar quantization by using a straight-through estimator to allow gradients to flow through the non-differentiable rounding operation, ensuring the model converges to values that are robust to low-precision representation [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** The continuous grid values $\tilde{\mathbf{t}}$ (densities, colors, features) optimized during training.
*   **Output:** Quantized grid values $\tilde{\mathbf{t}}'$ stored as single bytes, mapped back to a continuous range for rendering.

**Data Structures:**
*   Grid values are stored as 8-bit unsigned integers (bytes) in memory.
*   During training, gradients are computed with respect to the pre-quantization continuous values.

**Parameters:**
*   $m$: Scaling factor for the affine mapping.
    *   $m = 14$ for densities (which use an exponential nonlinearity) [S1].
    *   $m = 7$ for diffuse colors and features [S1].
*   Number of quantization levels: $2^8 = 256$ [S1].

**Steps:**
1.  **Nonlinear Mapping:** Map the raw grid values $\tilde{\mathbf{t}}$ to the range $[0, 1]$ using a sigmoid function $\sigma(\cdot)$ [S1].
2.  **Quantization:** Apply the byte quantization function $q(x)$ to the sigmoid-mapped values. This function rounds the input to the nearest of 256 discrete levels [S1].
3.  **Affine Mapping:** Scale and shift the quantized byte value to the target range $[-m, m]$ [S1].
4.  **Gradient Flow:** Use the straight-through estimator to pass gradients from the loss function back to the pre-quantization values $\tilde{\mathbf{t}}$, bypassing the non-differentiable rounding step [S1].

**Formula:**
The quantization function $q(x)$ is defined as:
$$q(x) = x + \mathcal{V}\left(\frac{\lfloor (2^8 - 1)x + 1/2 \rfloor}{2^8 - 1} - x\right)$$
where $\mathcal{V}$ is the straight-through estimator operator, which returns the input $x$ during the backward pass but returns the rounded value $\frac{\lfloor (2^8 - 1)x + 1/2 \rfloor}{2^8 - 1}$ during the forward pass [S1].

The final quantized value $\tilde{\mathbf{t}}'$ is computed as:
$$\tilde{\mathbf{t}}' = 2m \cdot q(\sigma(\tilde{\mathbf{t}})) - m$$
where $\sigma(\cdot)$ is the sigmoid function [S1].

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

def differentiable_quantize(t, m):
    """
    Quantizes grid values t to single bytes during optimization.
    
    Args:
        t: Continuous grid values (tensor).
        m: Scaling factor (14 for densities, 7 for colors/features).
        
    Returns:
        t_prime: Quantized values mapped to [-m, m].
    """
    # Step 1: Map to [0, 1] using sigmoid
    t_sigmoid = torch.sigmoid(t)
    
    # Step 2: Quantize to 256 levels
    # Calculate the rounded index
    num_levels = 256
    rounded_val = torch.floor((num_levels - 1) * t_sigmoid + 0.5) / (num_levels - 1)
    
    # Step 3: Straight-Through Estimator
    # Forward pass: use rounded_val
    # Backward pass: use t_sigmoid (gradient flows through sigmoid)
    t_quantized = rounded_val + (t_sigmoid - rounded_val).detach()
    
    # Step 4: Affine mapping to [-m, m]
    t_prime = 2 * m * t_quantized - m
    
    return t_prime
```

**Edge Cases and Pitfalls:**
*   **Post-Training Quantization:** Simply quantizing grid values after training completes leads to a mismatch between the optimized model and the rendering model, causing a drop in rendering quality [S1].
*   **Precision:** The method assumes values can be effectively normalized to $[0, 1]$ via sigmoid. If the distribution of grid values is not well-behaved, the quantization error may be non-uniform [S1].

## Operating characteristics
*   **Memory:** Reduces render-time memory consumption by storing each grid dimension as a single byte [S1].
*   **Performance:** Enables real-time view synthesis in unbounded scenes by reducing memory bandwidth requirements [S1].
*   **Quality:** Maintains high rendering quality comparable to full-precision models when integrated during optimization, avoiding the quality drops associated with post-training quantization [S1].
*   **Limitations:** The method is specific to grid-based neural field representations (like MERF) and may not directly apply to other neural field architectures without modification [S1].

## Background
The method was introduced in the MERF (Memory-Efficient Radiance Fields) paper, which focuses on real-time view synthesis in unbounded scenes [S1]. The authors identified that memory consumption was a bottleneck for large-scale scenes and proposed quantizing grid values to single bytes during optimization to mitigate this [S1].
