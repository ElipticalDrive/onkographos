# Differentiable Quantization for Neural Fields

Also called: MERF Quantization, Quantization for Memory Reduction

## Overview
Differentiable Quantization for Neural Fields reduces the memory footprint of 3D scene representations by mapping grid values to single bytes during the optimization process, ensuring consistency between the trained model and the render-time representation [S1]. Unlike post-training quantization, which causes quality drops due to mismatch between the optimized high-precision values and the discrete render-time values, this method integrates quantization into the training loop using a straight-through estimator to allow gradient flow [S1].

## How it works
**Inputs and Outputs:**
- Input: Continuous grid values $\tilde{\mathbf{t}}$ (densities, colors, features) during optimization.
- Output: Quantized grid values $\tilde{\mathbf{t}}'$ stored in memory, which are single-byte representations mapped to a specific range.

**Data Structures:**
- The grid stores values as single bytes (8-bit integers).
- Each byte represents a quantized level in the range $[-m, m]$.

**Parameters:**
- $m$: The scaling factor for the affine mapping.
  - $m = 14$ for densities (computed using exponential nonlinearity) [S1].
  - $m = 7$ for diffuse colors and features [S1].
- $B = 2^8 - 1 = 255$: The number of quantization levels minus one [S1].

**Steps:**
1. **Sigmoid Mapping:** Map the continuous grid value $\tilde{\mathbf{t}}$ to the range $[0, 1]$ using a sigmoid function $\sigma(\cdot)$ [S1].
   $$ x = \sigma(\tilde{\mathbf{t}}) $$
2. **Quantization:** Apply the quantization function $q(\cdot)$ to map $x$ to a single byte index. The function uses a straight-through estimator to allow gradients to pass through the non-differentiable rounding operation [S1].
   $$ q(x) = x + \mathcal{V}\left(\frac{\lfloor (2^8 - 1)x + 1/2 \rfloor}{2^8 - 1} - x\right) $$
   Where $\mathcal{V}$ is the straight-through estimator operator, which returns the gradient of the identity function for the forward pass but allows gradients to flow through the rounding operation in the backward pass [S1].
3. **Affine Mapping:** Map the quantized value $q(x)$ from $[0, 1]$ to the target range $[-m, m]$ [S1].
   $$ \tilde{\mathbf{t}}' = 2m \cdot q(\sigma(\tilde{\mathbf{t}})) - m $$

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

def sigmoid(x):
    return torch.sigmoid(x)

def quantize(x):
    # Map to [0, 1] range for quantization
    # x is assumed to be in [0, 1] after sigmoid
    # Quantize to 256 levels (0 to 255)
    # Using straight-through estimator: forward pass is rounded, backward pass is identity
    quantized = torch.round(x * 255) / 255.0
    # Straight-through estimator: gradient flows through the identity
    # In PyTorch, this is often implemented using detach or custom autograd function
    # Here we simulate the straight-through behavior
    return x + (quantized - x).detach()

def differentiable_quantization(t, m):
    # Step 1: Sigmoid mapping
    x = sigmoid(t)
    
    # Step 2: Quantization
    q_x = quantize(x)
    
    # Step 3: Affine mapping to [-m, m]
    t_prime = 2 * m * q_x - m
    
    return t_prime

# Example usage for density (m=14) and color (m=7)
density_m = 14
color_m = 7

# Assuming t_density and t_color are the continuous grid values
quantized_density = differentiable_quantization(t_density, density_m)
quantized_color = differentiable_quantization(t_color, color_m)
```

**Edge Cases and Pitfalls:**
- Simply quantizing after training causes quality drops due to mismatch between the optimized model and the one used for rendering [S1].
- Quantizing during optimization with straight-through estimator allows gradients to flow through the non-differentiable rounding [S1].

## Subtopics

## Operating characteristics
- **Memory Reduction:** Reduces memory consumption by quantizing each dimension at every location in the grid to a single byte [S1].
- **Rendering Quality:** Maintains rendering quality by ensuring consistency between the trained model and the render-time representation [S1].
- **Performance:** Real-time view synthesis in unbounded scenes is supported [S1].

## Background
- **Origin:** MERF: Memory-Efficient Radiance Fields for Real-time View Synthesis in Unbounded Scenes [S1].
- **Development:** The method was developed to address the memory limitations of neural radiance fields in large-scale scenes [S1].
