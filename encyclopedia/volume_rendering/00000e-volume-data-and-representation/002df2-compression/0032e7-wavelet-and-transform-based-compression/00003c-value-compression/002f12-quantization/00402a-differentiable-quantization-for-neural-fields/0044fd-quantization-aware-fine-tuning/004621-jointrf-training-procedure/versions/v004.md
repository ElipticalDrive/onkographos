# JointRF Training Procedure
## Overview
JointRF Training is a differentiable optimization method for dynamic neural radiance fields (NeRFs) that jointly optimizes scene representation and compression. It solves the problem of high memory consumption in dynamic scenes by training a model to produce quantized feature grids with minimal rate-distortion trade-off. It sets itself apart from methods that treat compression and representation as independent steps by integrating an entropy model into the forward pass, allowing end-to-end gradient propagation through the quantization simulation [S1].
## How it works
**Inputs and Outputs:**
- **Inputs:** Pre-trained dynamic NeRF parameters, a reconstructed keyframe buffer containing the long-reference basis feature grid $\hat{B}_k$, and a target bitrate constraint (implicit via the entropy model).
- **Outputs:** Optimized residual feature grid $\hat{R}_t$, coefficient feature grid $\hat{C}_t$, and the parameters of the entropy model.

**Data Structures:**
- **Basis Feature Grid ($\hat{B}_k$):** A long-reference feature grid loaded from the reconstructed keyframe buffer.
- **Coefficient Feature Grid ($\hat{C}_t$):** Quantized coefficients representing the static or slowly varying components of the dynamic features.
- **Residual Feature Grid ($\hat{R}_t$):** Quantized residuals representing the temporal changes or high-frequency details.
- **Entropy Model:** A probabilistic model estimating the probability distribution of the quantized grids to predict bitrates.

**Algorithm Steps:**
1. **Simulated Quantization:** Apply uniform noise to the continuous feature values to simulate quantization. This allows gradients to flow through the quantization operation. The quantized value $Q(x)$ is computed as:
   $$ Q(x) = x + u, \quad u \sim U\left(-\frac{1}{2}, \frac{1}{2}\right) $$
   where $u$ is uniform noise [S1]. This generates the quantized coefficient grid $\hat{C}_t$ and residual grid $\hat{R}_t$.

2. **Rate Estimation:** Estimate the bitrate (rate) of $\hat{C}_t$ and $\hat{R}_t$ using the entropy model. This estimated rate is used as a loss term during the forward pass to encourage a low-entropy distribution of features, effectively imposing a bitrate constraint [S1].

3. **Load Basis Grid:** Load the long-reference basis feature grid $\hat{B}_k$ from the reconstructed keyframe buffer.

4. **Reconstruction and Distortion Loss:** Combine the basis grid $\hat{B}_k$ with the quantized coefficient grid $\hat{C}_t$ and residual grid $\hat{R}_t$ to reconstruct the feature representation. Compute the Mean Squared Error (MSE) loss between the reconstructed features and the ground truth features.

5. **Joint Optimization:** Sequentially train each frame. Update the parameters of the residual feature grid, coefficient feature grid, and the entropy model by minimizing the combined loss (MSE distortion + estimated rate) [S1].

**Pseudocode:**
```python
def joint_rf_training_step(nerf_model, keyframe_buffer, entropy_model, target_frames):
    """
    Performs one step of JointRF training for a sequence of frames.
    
    Args:
        nerf_model: The dynamic NeRF model containing parameters for B_k, C_t, R_t.
        keyframe_buffer: Buffer containing reconstructed keyframe basis grids.
        entropy_model: Model estimating entropy of quantized features.
        target_frames: List of frames to process sequentially.
        
    Returns:
        None (updates model parameters via gradient descent)
    """
    for frame in target_frames:
        # Step 1: Simulated Quantization
        # Get continuous feature values from the model
        continuous_C_t = nerf_model.get_coefficient_features(frame)
        continuous_R_t = nerf_model.get_residual_features(frame)
        
        # Apply uniform noise to simulate quantization
        # u ~ U(-0.5, 0.5)
        noise_C = torch.rand_like(continuous_C_t) - 0.5
        noise_R = torch.rand_like(continuous_R_t) - 0.5
        
        # Quantized grids
        C_hat_t = continuous_C_t + noise_C
        R_hat_t = continuous_R_t + noise_R
        
        # Step 2: Rate Estimation
        # Estimate entropy (rate) of the quantized grids
        rate_C = entropy_model.estimate_entropy(C_hat_t)
        rate_R = entropy_model.estimate_entropy(R_hat_t)
        total_rate = rate_C + rate_R
        
        # Step 3: Load Basis Grid
        # Load the long-reference basis feature grid from the keyframe buffer
        B_hat_k = keyframe_buffer.get_basis_grid(frame.keyframe_id)
        
        # Step 4: Reconstruction and Distortion Loss
        # Combine basis, coefficients, and residuals to reconstruct features
        # Note: The exact combination formula (e.g., addition, multiplication) 
        # is not explicitly detailed in the provided text, but typically involves 
        # combining these components to approximate the full feature set.
        # Assuming additive combination for reconstruction:
        reconstructed_features = B_hat_k + C_hat_t + R_hat_t
        
        # Get ground truth features for the frame
        ground_truth_features = get_ground_truth_features(frame)
        
        # Compute MSE loss
        mse_loss = torch.mean((reconstructed_features - ground_truth_features) ** 2)
        
        # Step 5: Joint Optimization
        # Combined loss: Distortion + Lambda * Rate
        # Lambda is a trade-off factor for rate-distortion optimization
        lambda_rate = 0.01 # Example value, typically tuned
        total_loss = mse_loss + lambda_rate * total_rate
        
        # Backpropagate and update parameters
        total_loss.backward()
        optimizer.step()
        optimizer.zero_grad()
```

**Parameters:**
- **Noise Range:** Uniform distribution $U(-0.5, 0.5)$ [S1].
- **Trade-off Factor ($\lambda$):** Not explicitly given in the sources. Typically tuned to balance rate and distortion.

**Edge Cases and Pitfalls:**
- **Gradient Flow:** Standard quantization is non-differentiable. The use of uniform noise simulation is critical for gradient propagation [S1].
- **Entropy Model Accuracy:** The accuracy of the rate estimation depends on the entropy model's ability to predict the true distribution of quantized features. Poor estimation can lead to suboptimal rate-distortion trade-offs.
- **Keyframe Buffer Dependency:** The method relies on a pre-reconstructed keyframe buffer. Errors in the keyframe reconstruction can propagate to the dynamic frame training.

## Subtopics

### [Rate-Distortion Joint Finetuning](12624-rate-distortion-joint-finetuning.md)
Rate-Distortion Joint Finetuning is a training approach that treats compression and 3D-scene representation as a single optimization problem, training the NeRF model for bitrate and distortion simultaneously. Unlike techniques that treat compression and 3D-scene representation as two independent optimization problems, which reduces compression performance and limits effectiveness across a wider bitrate range, this method jointly optimizes the model parameters to achieve an optimal Rate-Distortion (RD) curve by adjusting a single trade-off factor. It builds on [JointRF Training Procedure](11657-jointrf-training-procedure.md) by introducing a differentiable entropy model and noise-based gradient approximation to enable end-to-end learning of quantized features.

### [Conjoint Pruning of the Ensemble](12978-conjoint-pruning-of-the-ensemble.md)
Conjoint Pruning of the Ensemble (CPE) is the final optimization phase in the JointRF training procedure, designed to jointly prune multiple pre-trained neural field models to achieve superior reconstruction quality compared to ensembling pre-trained models with a comparable or lower memory footprint. It distinguishes itself from sibling methods like [Rate-Distortion Joint Finetuning](12624-rate-distortion-joint-finetuning.md) by explicitly modifying the ensemble's aggregation logic from averaging to summation to prevent signal degradation during the pruning process.

## Operating characteristics
- **Time Complexity:** Not given in the sources. Sequential training per frame implies linear scaling with the number of frames.
- **Memory Complexity:** Not given in the sources. Depends on the size of the feature grids and the entropy model.
- **Measured Performance:** Not given in the sources.
- **Strengths:** End-to-end differentiable optimization allows for joint learning of representation and compression. The noise-based gradient approximation enables training with quantization.
- **Limitations:** Relies on an accurate entropy model for rate estimation. Performance is dependent on the quality of the keyframe buffer.
- **When to use:** When high compression ratios are required for dynamic NeRFs and end-to-end optimization is feasible.
- **When not to use:** When computational resources for training are limited or when an accurate entropy model is difficult to construct.

## Background
JointRF Training was introduced in the paper "JOINTRF: End-To-End Joint Optimization for Dynamic Neural Radiance Field Representation and Compression" [S1]. It addresses the challenges of compressing dynamic neural radiance fields by integrating compression directly into the training process.
