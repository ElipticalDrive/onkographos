# JointRF Training Procedure


## Overview
JointRF Training is the optimization phase of the JointRF framework, designed to simultaneously compress dynamic Neural Radiance Fields (NeRFs) and reconstruct their visual quality. It solves the problem of bitrate-constrained dynamic scene representation by integrating rate estimation directly into the training loop via differentiable quantization. Unlike standard NeRF training which minimizes only reconstruction error, JointRF jointly optimizes for Mean Squared Error (MSE) and estimated bitrate, allowing the network to learn a compressed feature representation that balances fidelity and storage cost.

## How it works
The method trains the dynamic NeRF model sequentially across frames, updating the coefficient grid, residual grid, and the entropy model parameters. It relies on a long-reference basis feature grid $\hat{B}_k$ derived from a reconstructed keyframe buffer.

**Inputs:**
- Current frame index $t$.
- Long-reference basis feature grid $\hat{B}_k$ loaded from the keyframe buffer.
- Current estimates of the coefficient feature grid $\hat{C}_t$ and residual feature grid $\hat{R}_t$.
- Parameters for the entropy model.

**Outputs:**
- Updated parameters for $\hat{C}_t$, $\hat{R}_t$, and the entropy model.
- Gradients for the loss function.

**Data Structures:**
- $\hat{C}_t$: Coefficient feature grid storing the primary quantized features.
- $\hat{R}_t$: Residual feature grid storing the quantized differences or corrections.
- $\hat{B}_k$: Basis feature grid from the reference keyframe.

**Formulas:**
The core mechanism for gradient propagation through quantization is simulated uniform noise addition [S1]:
$$
Q(x) = x + u, \quad u \sim U\left(-\frac{1}{2}, \frac{1}{2}\right)
$$
where $x$ is the input value and $u$ is uniform noise. This approximates the quantization operation $Q(\cdot)$ while preserving differentiability [S1].

The total loss $\mathcal{L}$ combines the reconstruction error and the estimated rate [S1]:
$$
\mathcal{L} = \mathcal{L}_{MSE} + \lambda \mathcal{L}_{Rate}
$$
where $\mathcal{L}_{MSE}$ is computed by combining $\hat{B}_k$, $\hat{C}_t$, and $\hat{R}_t$, and $\mathcal{L}_{Rate}$ is the estimated entropy of $\hat{C}_t$ and $\hat{R}_t$ [S1]. The parameter $\lambda$ controls the trade-off between distortion and bitrate.

**Steps:**
1. **Simulated Quantization:** Apply the noise-based quantization $Q(\cdot)$ to the raw feature outputs to generate the quantized coefficient grid $\hat{C}_t$ and residual grid $\hat{R}_t$ [S1].
2. **Rate Estimation:** Pass $\hat{C}_t$ and $\hat{R}_t$ through the entropy model to estimate their entropy. This value serves as the rate loss $\mathcal{L}_{Rate}$ during the forward pass [S1].
3. **Reconstruction Loss Calculation:** Load the long-reference basis feature grid $\hat{B}_k$ from the reconstructed keyframe buffer [S1]. Combine $\hat{B}_k$ with $\hat{C}_t$ and $\hat{R}_t$ to compute the reconstruction error $\mathcal{L}_{MSE}$ [S1].
4. **Loss Aggregation:** Compute the total loss $\mathcal{L}$ using the weighted sum of $\mathcal{L}_{MSE}$ and $\mathcal{L}_{Rate}$ [S1].
5. **Optimization:** Perform backpropagation to update the parameters of the residual feature grid, coefficient feature grid, and the entropy model [S1].
6. **Iteration:** Proceed to the next frame $t+1$ and repeat the process [S1].

**Pseudocode:**
```python
def joint_rf_training_step(frame_t, basis_grid_Bk, coeff_grid_Ct, residual_grid_Rt, entropy_model, lambda_rate):
    # Step 1: Simulated Quantization
    # Apply uniform noise to simulate quantization for gradient propagation
    # u is sampled from Uniform(-0.5, 0.5)
    quantized_Ct = Ct + torch.rand_like(Ct) * (1.0) - 0.5
    quantized_Rt = Rt + torch.rand_like(Rt) * (1.0) - 0.5
    
    # Step 2: Rate Estimation
    # Estimate entropy of quantized grids using the entropy model
    # This approximates the bitrate without non-differentiable entropy encoding
    estimated_rate = entropy_model.estimate_entropy(quantized_Ct, quantized_Rt)
    rate_loss = estimated_rate
    
    # Step 3: Reconstruction Loss
    # Load basis grid Bk (already provided as input in this step context)
    # Combine Bk, quantized_Ct, and quantized_Rt to get reconstructed features
    reconstructed_features = combine_features(Bk, quantized_Ct, quantized_Rt)
    
    # Compute MSE against ground truth or target features
    # Note: The specific target for MSE is not detailed in the source, 
    # but it is derived from the combination of Bk, Ct, and Rt [S1]
    mse_loss = compute_mse(reconstructed_features, target_features)
    
    # Step 4: Loss Aggregation
    total_loss = mse_loss + lambda_rate * rate_loss
    
    # Step 5: Optimization
    # Backpropagate to update Ct, Rt, and entropy model parameters
    total_loss.backward()
    optimizer.step()
    optimizer.zero_grad()
    
    return total_loss
```

**Edge Cases and Pitfalls:**
- **Gradient Discontinuity:** Standard entropy encoding is non-differentiable. Using the entropy model for estimation is critical to allow gradient flow [S1].
- **Noise Range:** The uniform noise range $[-\frac{1}{2}, \frac{1}{2}]$ is specific to the simulated quantization of integer-valued features or normalized values. Incorrect scaling of this noise may break the quantization approximation [S1].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Performance:** The method enables end-to-end joint optimization, allowing the network to adapt its feature distribution to minimize bitrate while maintaining visual quality [S1].
- **Strengths:** Integrates rate estimation directly into training, avoiding the need for post-training compression or non-differentiable steps during optimization [S1].
- **Limitations:** Relies on the accuracy of the entropy model to estimate the true bitrate; if the model is poorly calibrated, the rate constraint may not be met [S1].

## Background
JointRF was introduced in the paper "JOINTRF: End-To-End Joint Optimization for Dynamic Neural Radiance Field Representation and Compression" [S1]. The method addresses the challenge of compressing dynamic NeRFs by treating the representation and compression as a joint optimization problem, leveraging differentiable quantization to enable gradient-based training of the compressed feature grids [S1].
