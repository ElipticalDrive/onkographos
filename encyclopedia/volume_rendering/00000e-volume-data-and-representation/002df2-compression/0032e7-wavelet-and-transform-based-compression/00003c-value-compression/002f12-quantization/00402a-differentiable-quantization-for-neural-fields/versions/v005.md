# Differentiable Quantization for Neural Fields
Also called: MERF Quantization, Quantization for Memory Reduction

## Overview
Differentiable quantization reduces the memory footprint of neural radiance fields by mapping continuous grid values to single-byte integers during the optimization process, ensuring consistency between the training and rendering models [S1]. Unlike post-training quantization, which causes quality degradation due to distribution mismatches, this method integrates quantization into the training loop using a straight-through estimator to allow gradient flow [S1].

## How it works
**Inputs and Outputs:**
- Input: Continuous grid values $\tilde{\mathbf{t}}$ (densities, colors, or features) for each dimension at every grid location.
- Output: Quantized grid values $\tilde{\mathbf{t}}'$ stored as single bytes, mapped to a specific range $[-m, m]$.

**Data Structures:**
- The grid stores values as 8-bit integers (bytes).
- Each dimension is quantized independently.

**Parameters:**
- $m$: Range scaling factor.
  - $m = 14$ for densities (computed using exponential nonlinearity) [S1].
  - $m = 7$ for diffuse colors and features [S1].
- Bit depth: 8 bits ($2^8 = 256$ levels) [S1].

**Quantization Function:**
The quantization function $q(x)$ maps a value $x \in [0, 1]$ to the nearest discrete level in $[0, 1]$ and uses a straight-through estimator for gradients [S1]. The formula is:

$$q(x) = x + \mathcal{V}\left(\frac{\lfloor (2^8 - 1)x + 1/2 \rfloor}{2^8 - 1} - x\right)$$

where $\mathcal{V}$ is the straight-through estimator operator, which passes the gradient of the identity function through the non-differentiable rounding operation [S1]. Specifically, the gradient of $q(x)$ with respect to $x$ is 1, ignoring the derivative of the floor function [S1].

**Steps:**
1. **Sigmoid Mapping:** Apply a sigmoid function $\sigma(\cdot)$ to the continuous grid values $\tilde{\mathbf{t}}$ to map them to the range $[0, 1]$ [S1].
   $$x = \sigma(\tilde{\mathbf{t}})$$
2. **Quantization:** Apply the quantization function $q(x)$ to map $x$ to the nearest byte level [S1].
   $$q_{val} = q(x)$$
3. **Affine Mapping:** Map the quantized value $q_{val}$ from $[0, 1]$ to the range $[-m, m]$ using the parameter $m$ specific to the data type [S1].
   $$\tilde{\mathbf{t}}' = 2m \cdot q_{val} - m$$

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

def sigmoid(x):
    return torch.sigmoid(x)

def quantize(x):
    # x is in [0, 1]
    # Round to nearest integer level in [0, 255]
    # Straight-through estimator: gradient is 1
    levels = 255.0
    rounded = torch.round(x * levels)
    # Clip to valid range [0, 255]
    rounded = torch.clamp(rounded, 0, levels)
    # Map back to [0, 1]
    quantized = rounded / levels
    # Straight-through: return quantized value, but gradient flows as if identity
    # In PyTorch, this is often done via detach or custom autograd function.
    # Here we simulate the straight-through behavior:
    # The gradient of the output w.r.t input is 1.
    # Since quantized is a function of rounded, and rounded is discrete,
    # we use a custom operation or assume the framework handles STE.
    # For explicit implementation without custom ops:
    # grad_output * 1.0
    return quantized

def differentiable_quantization(t, m):
    # t: continuous grid values
    # m: range parameter (14 for density, 7 for color/features)
    
    # Step 1: Sigmoid mapping to [0, 1]
    x = sigmoid(t)
    
    # Step 2: Quantization to byte
    # Note: In a real framework, use a STE-aware quantization op.
    # Here we assume a function that performs rounding but passes gradients through.
    q_val = quantize(x)
    
    # Step 3: Affine mapping to [-m, m]
    t_prime = 2 * m * q_val - m
    
    return t_prime
```

**Edge Cases and Pitfalls:**
- Simply quantizing after training causes quality drops due to mismatch between optimized model and rendering model [S1].
- Quantization must be performed during optimization to allow the model to adapt to the low-precision representation [S1].
- The non-linearities in the radiance field computation (e.g., exponential for density) are applied *after* linear interpolation and summation of the quantized values, not before [S1].

## Operating characteristics
- **Memory:** Reduces memory consumption by storing each grid dimension as a single byte [S1].
- **Performance:** Enables real-time view synthesis in unbounded scenes by reducing memory bandwidth requirements [S1].
- **Quality:** Maintains rendering quality comparable to full-precision models when quantization is integrated into training [S1]. Post-training quantization leads to significant quality drops [S1].
- **Complexity:** Adds minimal computational overhead during training due to the efficient straight-through estimator [S1].

## Background
This method was introduced in the MERF (Memory-Efficient Radiance Fields) paper for real-time view synthesis in unbounded scenes [S1]. It addresses the high memory consumption of neural radiance fields by quantizing grid values during optimization [S1].
