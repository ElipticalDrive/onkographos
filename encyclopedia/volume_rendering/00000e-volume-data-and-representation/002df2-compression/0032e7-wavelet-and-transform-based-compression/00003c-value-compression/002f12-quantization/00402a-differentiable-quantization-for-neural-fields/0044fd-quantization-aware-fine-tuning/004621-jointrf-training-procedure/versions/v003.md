# JointRF Training Procedure
## Overview
JointRF is an end-to-end training procedure for dynamic Neural Radiance Fields (NeRFs) that jointly optimizes scene representation and compression [S1]. It solves the problem of bitrate-constrained dynamic scene storage by treating compression and 3D-scene representation as a single optimization problem, adjusting a single trade-off factor to achieve an optimal Rate-Distortion (RD) curve [S1]. Unlike techniques that treat compression and 3D-scene representation as two independent optimization problems, which reduces compression performance and limits effectiveness across a wider bitrate range, this method enables end-to-end learning of quantized features using a differentiable entropy model and noise-based gradient approximation [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A sequence of training frames; a reconstructed keyframe buffer containing the long-reference basis feature grid $\hat{B}_k$; an entropy model for rate estimation.
*   **Outputs:** Trained residual feature grid, coefficient feature grid, and the corresponding entropy model parameters.

**Data Structures:**
*   **Coefficient Grid ($\hat{C}_t$):** Quantized coefficient representation for frame $t$.
*   **Residual Grid ($\hat{R}_t$):** Quantized residual representation for frame $t$.
*   **Basis Feature Grid ($\hat{B}_k$):** Long-reference basis feature grid loaded from the reconstructed keyframe buffer.

**Method Steps:**
1.  **Simulated Quantization:** Apply uniform noise within the range $[-\frac{1}{2}, \frac{1}{2}]$ to the continuous feature values to simulate quantization. This allows gradient propagation during training [S1]. The quantization operation is defined as:
    $$ Q(x) = x + u, \quad u \sim U\left(-\frac{1}{2}, \frac{1}{2}\right) $$
    This generates the quantized coefficient grid $\hat{C}_t$ and residual grid $\hat{R}_t$ [S1].

2.  **Rate Estimation:** Estimate the rate of $\hat{C}_t$ and $\hat{R}_t$ using an entropy model during the forward pass. This estimated rate is used as a loss component to encourage a lower-entropy distribution of features, effectively imposing a bitrate constraint on the network updates [S1]. Note that actual entropy encoding does not preserve gradients, so the differentiable entropy model is used for backpropagation [S1].

3.  **Basis Loading:** Load the long-reference basis feature grid $\hat{B}_k$ from the reconstructed keyframe buffer [S1].

4.  **Distortion Loss Calculation:** Combine $\hat{B}_k$ with $\hat{C}_t$ and $\hat{R}_t$ to reconstruct the features for the current frame. Compute the Mean Squared Error (MSE) loss between the reconstructed features and the ground truth [S1].

5.  **Joint Optimization:** Sequentially train each frame. Update the residual feature grid, coefficient feature grid, and the corresponding entropy model parameters by minimizing the combined loss (Rate + Distortion) [S1].

**Pseudocode:**

**Parameters:**
*   **Lambda Rate ($\lambda$):** Trade-off factor between rate and distortion. Not given in the sources.
*   **Noise Range:** Uniform distribution $[-\frac{1}{2}, \frac{1}{2}]$ [S1].

**Edge Cases and Pitfalls:**
*   **Gradient Flow:** Standard entropy encoding does not preserve gradients. The method relies on the differentiable entropy model and simulated quantization (noise addition) to enable backpropagation [S1].
*   **Precision:** The simulated quantization uses additive uniform noise. Implementation must ensure this noise is differentiable or handled via the straight-through estimator if using discrete quantization [S1].

## Subtopics

### [Rate-Distortion Joint Finetuning](12624-rate-distortion-joint-finetuning.md)
Rate-Distortion Joint Finetuning is a training approach that treats compression and 3D-scene representation as a single optimization problem, training the NeRF model for bitrate and distortion simultaneously. Unlike techniques that treat compression and 3D-scene representation as two independent optimization problems, which reduces compression performance and limits effectiveness across a wider bitrate range, this method jointly optimizes the model parameters to achieve an optimal Rate-Distortion (RD) curve by adjusting a single trade-off factor. It builds on JointRF Training Procedure by introducing a differentiable entropy model and noise-based gradient approximation to enable end-to-end learning of quantized features.

### Conjoint Pruning of the Ensemble
Conjoint Pruning of the Ensemble (CPE) is a pruning phase that jointly prunes the ensemble models, targeting superior performance compared to ensembling pre-trained models with comparable or lower memory footprint [S2]. It builds on Quantization-Aware Fine-Tuning by applying pruning to an ensemble of models.

**Steps:**
1.  Compute the ensemble output $C^2_i$ by summing the outputs of the $n$ models instead of averaging:
    $$ C^2_i = \sum_{n=1}^{N} C_n(w_n, x_i, \bar{\theta}_n) $$
2.  Minimize the loss function $L_{sum}$, which measures the squared difference between target color $C_m$ and the summed ensemble output:
    $$ L_{sum}(w) = \frac{1}{M} \sum_{m=1}^{M} \left( C_m - \sum_{n=1}^{N} C_n(w_n, x_i, \bar{\theta}_n) \right)^2 $$

**Parameters:**
*   **Compression Rates:** Low (87.50% of total parameters retained) and High (96.87% of total parameters retained) [S2].

**Pitfalls:**
*   Using averaging ($L_{avg}$) during conjoint pruning causes significant signal reduction because pruning creates null/zero values in model outputs, leading to suboptimal results when averaged [S2].

*   **Strengths:** End-to-end optimization allows for better Rate-Distortion trade-offs compared to separate compression and training steps [S1]. Differentiable entropy model enables gradient-based optimization of compression parameters [S1].
*   **Limitations:** Requires careful tuning of the rate-distortion trade-off factor. The method relies on simulated quantization, which may not perfectly match the actual quantization and entropy coding used in deployment [S1].

## Background
JointRF was introduced in the paper "JOINTRF: End-To-End Joint Optimization for Dynamic Neural Radiance Field Representation and Compression" [S1]. The method addresses the need for efficient storage and transmission of dynamic 3D scenes represented by NeRFs.

Conjoint Pruning of the Ensemble was introduced in "Two is Better than One: Achieving High-Quality 3D Scene Modeling with a NeRF Ensemble" [S2]. It addresses the performance degradation in pruned NeRF ensembles by jointly optimizing the pruning and the ensemble output combination.
