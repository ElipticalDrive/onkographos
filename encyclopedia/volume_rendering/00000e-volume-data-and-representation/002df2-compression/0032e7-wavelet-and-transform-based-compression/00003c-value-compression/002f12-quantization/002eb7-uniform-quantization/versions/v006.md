# Uniform Quantization

Also called: Scalar uniform quantization, Fixed-step quantization

## Overview
Uniform quantization is a lossy compression method that maps a continuous range of source data values to a discrete set of levels with equal spacing, using a limited number of bits to represent a larger number of distinct raw values [S1, S2, unofficial]. It solves the problem of reducing the memory footprint and transmission bandwidth of volume data, typically achieving a 4:1 compression ratio by representing 32-bit floating-point data with 8-bit integers [S1, S2, unofficial]. It differs from non-uniform quantization by maintaining constant step sizes across the entire data range, which makes it simple to implement but prone to losing features in data with wide dynamic ranges if the range is not carefully selected [S1, S2, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A volume dataset with values $x$ in the range $[x_{min}, x_{max}]$.
- Output: A quantized dataset where each value is represented by an integer index $i \in \{0, \dots, M-1\}$, where $M = 2^b$ and $b$ is the bit depth.

**Data Structures:**
- The quantized data is stored as a grid of integers. If the original data is 32-bit float, the quantized data is typically 8-bit integer (uint8) [S1, S2, unofficial].
- The number of quantization levels $M$ is determined by the bit depth $b$ ($M = 2^b$). For a standard 4:1 compression, $b=8$ and $M=256$ [S1, S2, unofficial].

**Parameters:**
- $x_{min}$: The minimum value of the data range to be quantized.
- $x_{max}$: The maximum value of the data range to be quantized.
- $M$: The number of quantization levels ($2^b$).
- $\phi$: The step size (quantization interval), calculated as $\phi = (x_{max} - x_{min}) / M$ [S1, S2, unofficial].

**Steps:**
1. Determine the data range $[x_{min}, x_{max}]$. This range must be chosen carefully to encompass the features of interest. If the range is too wide (e.g., in turbulence flow data with wide dynamic range), important features may become invisible [S1, S2, unofficial].
2. Calculate the step size $\phi = (x_{max} - x_{min}) / M$ [S1, S2, unofficial].
3. For each data value $x$:
   a. Clamp $x$ to the range $[x_{min}, x_{max}]$. Values outside this range are typically clipped to the nearest boundary [G].
   b. Compute the quantization index $i$:
      $$ i = \left\lfloor \frac{x - x_{min}}{\phi} \right\rfloor $$
   c. Clamp $i$ to the range $[0, M-1]$ [G].
4. Store $i$ as the quantized value.

**Reconstruction:**
To reconstruct the approximate value $\hat{x}$ from the index $i$:
$$ \hat{x} = x_{min} + i \cdot \phi + \frac{\phi}{2} $$
This represents the midpoint of the quantization interval [G].

**Pitfalls:**
- **Wide Dynamic Range:** If the data has a wide dynamic range (e.g., turbulence flow), using a uniform range based on the global min/max can cause important features in later time steps or specific regions to become invisible because the step size $\phi$ becomes too large to resolve small variations in those regions [S1, S2, unofficial].
- **Clipping:** Values outside $[x_{min}, x_{max}]$ are lost. Care must be taken to select $x_{min}$ and $x_{max}$ to include all relevant features [S1, S2, unofficial].

**Pseudocode:**
```python
def uniform_quantize(data, x_min, x_max, b):
    """
    Quantize volume data using uniform quantization.
    
    Args:
        data: 3D array of float values.
        x_min: Minimum value of the quantization range.
        x_max: Maximum value of the quantization range.
        b: Bit depth (e.g., 8 for 8-bit).
        
    Returns:
        quantized_data: 3D array of uint8 values.
    """
    M = 2 ** b
    phi = (x_max - x_min) / M
    
    # Clamp data to range
    clamped_data = np.clip(data, x_min, x_max)
    
    # Compute indices
    indices = ((clamped_data - x_min) / phi).astype(np.int32)
    
    # Clamp indices to [0, M-1]
    indices = np.clip(indices, 0, M - 1)
    
    return indices.astype(np.uint8)

def uniform_dequantize(quantized_data, x_min, x_max, b):
    """
    Dequantize uniform quantized data.
    
    Args:
        quantized_data: 3D array of uint8 values.
        x_min: Minimum value of the quantization range.
        x_max: Maximum value of the quantization range.
        b: Bit depth (e.g., 8 for 8-bit).
        
    Returns:
        reconstructed_data: 3D array of float values.
    """
    M = 2 ** b
    phi = (x_max - x_min) / M
    
    # Reconstruct using midpoint
    reconstructed_data = x_min + quantized_data.astype(np.float32) * phi + phi / 2.0
    
    return reconstructed_data
```

## Operating characteristics
- **Time Complexity:** $O(N)$ for quantization and dequantization, where $N$ is the number of voxels. The operations are simple arithmetic and clamping.
- **Memory Complexity:** $O(N \cdot b)$ bits, where $b$ is the bit depth. For 8-bit quantization of 32-bit data, memory usage is reduced by 4x [S1, S2, unofficial].
- **Measured Performance:** Achieves a 4:1 compression ratio for 32-bit to 8-bit conversion [S1, S2, unofficial].
- **Strengths:** Simple to implement, fast, predictable error distribution for uniformly distributed data.
- **Limitations:** Poor performance for data with wide dynamic ranges or non-uniform distributions, as important features may be lost if the quantization range is not carefully chosen [S1, S2, unofficial].
- **When to Use:** When data is uniformly distributed or when the range of interest is well-known and narrow.
- **When Not to Use:** When data has a wide dynamic range and important features are in narrow ranges (e.g., turbulence flow), where non-uniform or adaptive quantization is preferred [S1, S2, unofficial].

## Background
Uniform quantization is a well-studied area in signal processing and data compression [S1, S2, unofficial]. In the context of volume rendering, its impact has not been as carefully studied as other aspects, but it is recognized as the simplest lossy compression method [S1, S2, unofficial]. The method is often used as a baseline for comparison with more advanced techniques like non-uniform and adaptive quantization [S1, S2, unofficial]. The sources cite the work of NASA and DTIC in 1998 regarding efficient encoding and rendering of time-varying volume data [S1, S2, unofficial].
