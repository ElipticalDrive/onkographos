# Colorspace Transformations for Compression

Also called: Colorspace Optimization for Wavelet Compression, PCA colorspace, RGB to optimized colorspace, RGB to optimized colorspace transform, YIQ colorspace

## Overview
This method transforms RGB volume data into an optimized colorspace to decorrelate channels and assign significance weights for encoding and quantization [S1, unofficial]. It sets itself apart from sibling methods by explicitly leveraging perceptual or statistical channel importance to prioritize wavelet coefficients during compression, rather than treating all color channels equally [S1, unofficial].

## How it works
**Inputs:** RGB volume data (vectors $\mathbf{R}, \mathbf{G}, \mathbf{B}$) [S1, unofficial].
**Outputs:** Transformed volume data in an optimized colorspace with associated significance weights [S1, unofficial].

**Data Structures:**
The optimized colorspace is spanned by three basis vectors $\mathbf{C}_1, \mathbf{C}_2, \mathbf{C}_3$ [S1, unofficial]. Each wavelet coefficient is represented by coordinates in this space [S1, unofficial].

**Steps:**
1.  **Transform RGB to Optimized Colorspace:** Convert the input RGB volume data into the space spanned by $\mathbf{C}_1, \mathbf{C}_2, \mathbf{C}_3$ [S1, unofficial].
2.  **Assign Significance Weights:** For each wavelet coefficient, calculate two independent significance weights: one based on the energy of the associated wavelet function, and one based on the global significance of the colorspace coordinates [S1, unofficial].
3.  **Calculate Significance Score:** Compute the significance score $S$ for each coefficient using the formula:
    $$ S(w, \mathbf{C}) = E(w(\mathbf{C})) \cdot I(\mathbf{C}) $$
    Where:
    *   $w$ is the wavelet coefficient [S1, unofficial].
    *   $\mathbf{C}$ represents the colorspace coordinates [S1, unofficial].
    *   $E(w(\mathbf{C}))$ is the wavelet energy [S1, unofficial].
    *   $I(\mathbf{C})$ is the color channel importance [S1, unofficial].
4.  **Encode/Quantize:** Use the significance score to sort coefficients and determine quantization precision [S1, unofficial].

**Parameters and Specific Colorspaces:**
*   **YIQ Colorspace:** A data-independent transform obtained by a simple matrix transform [S1, unofficial]. $Y$ encodes luminance; $I$ and $Q$ encode chromaticity [S1, unofficial]. Importance factors based on NTSC bandwidth conventions are $Y$: 4, $I$: 1.5, $Q$: 0.6 [S1, unofficial].
*   **PCA/Karhunen-Loève Expansion:** A data-dependent transform [S1, unofficial]. The transformation matrix is computed individually for each dataset [S1, unofficial]. The significance of each eigenvector is described by the absolute values of the corresponding eigenvalues [S1, unofficial].

**Edge Cases and Pitfalls:**
*   The transformation can be skipped for intensity volumes such as raw CT or MRI data sets [S1, unofficial].
*   PCA computation is computationally more challenging for offline forward compression but provides better results [S1, unofficial].

    # rgb_volume: 3D list of shape (D, H, W) containing [R, G, B] lists
    if method == 'YIQ':
        y = [[[0.299 * rgb_volume[d][h][w][0] + 0.587 * rgb_volume[d][h][w][1] + 0.114 * rgb_volume[d][h][w][2] for w in range(W)] for h in range(H)] for d in range(D)]
        i = [[[0.596 * rgb_volume[d][h][w][0] - 0.274 * rgb_volume[d][h][w][1] - 0.322 * rgb_volume[d][h][w][2] for w in range(W)] for h in range(H)] for d in range(D)]
        q = [[[0.211 * rgb_volume[d][h][w][0] - 0.523 * rgb_volume[d][h][w][1] + 0.312 * rgb_volume[d][h][w][2] for w in range(W)] for h in range(H)] for d in range(D)]
        transformed_volume = [[[y[d][h][w], i[d][h][w], q[d][h][w]] for w in range(W)] for h in range(H)] for d in range(D)]
        importance_factors = {'Y': 4, 'I': 1.5, 'Q': 0.6}
    elif method == 'PCA':
        data = [rgb_volume[d][h][w] for d in range(D) for h in range(H) for w in range(W)]
        n = len(data)
        mean = [sum(v[c] for v in data) / n for c in range(3)]
        centered = [[v[c] - mean[c] for c in range(3)] for v in data]
        cov = [[sum(centered[k][i] * centered[k][j] for k in range(n)) / (n - 1) for j in range(3)] for i in range(3)]
        # Standard 3x3 symmetric eigenvalue solver [G]
        eigenvalues, eigenvectors = eigen_decompose_3x3(cov)
        # Sort eigenvectors by absolute eigenvalue descending
        indices = sorted(range(3), key=lambda k: abs(eigenvalues[k]), reverse=True)
        eigenvalues = [eigenvalues[i] for i in indices]
        eigenvectors = [[eigenvectors[i][j] for j in range(3)] for i in indices]
        transformed_data = [[sum(centered[k][i] * eigenvectors[i][j] for i in range(3)) for j in range(3)] for k in range(n)]
        transformed_volume = [[[transformed_data[d * H * W + h * W + w][c] for c in range(3)] for w in range(W)] for h in range(H)] for d in range(D)]
        importance_factors = {'C1': abs(eigenvalues[0]), 'C2': abs(eigenvalues[1]), 'C3': abs(eigenvalues[2])}
    return transformed_volume, importance_factors

## Subtopics

### YIQ Colorspace
A data-independent transform using luminance/chrominance separation. Choose when computational simplicity is preferred and NTSC-like progressive refinement is desired. [YIQ Colorspace](2090-quantization-with-noise-injection.md)

### PCA Colorspace
A data-dependent transform using statistical optimization. Choose when better compression results are needed and offline computation cost is acceptable. [PCA Colorspace](5722-thresholding-and-quantization.md)

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** YIQ allows progressive refinement in both spatial and color domains [S1, unofficial]. PCA provides better compression results due to optimal decorrelation [S1, unofficial].
*   **Strengths:** Improves compression efficiency by prioritizing perceptually or statistically important information [S1, unofficial].
*   **Limitations:** PCA is computationally intensive for offline compression [S1, unofficial]. Not applicable to intensity volumes [S1, unofficial].

## Background
The method was developed for compression domain volume rendering to balance CPU, network, and graphics performance, enabling scalability with minimal client storage requirements (e.g., less than 5KB for mother-wavelet splats and Huffman tables) [S1, unofficial]. It builds on wavelet compression techniques and significance encoding [S1, unofficial].
