# Edge Index Encoding

Also called: Compressed isosurface transmission, Isosurface compression

## Overview
Edge Index Encoding is a compression scheme for isosurfaces extracted from regular 3D volumes that exploits the geometric embedding of vertices in the underlying 3D mesh to reduce storage and transmission size, avoiding the explicit storage of $(x,y,z)$ coordinates [S1]. Unlike standard isosurface representations that store triangular meshes of vertex and face indices—thereby ignoring the 3D embedding and resulting in inefficiency—this method stores indices of valid cells and function values of relevant vertices, allowing coordinates to be reconstructed from edge indices and endpoint values [S1]. It is specifically designed for scenarios requiring the transmission of isosurfaces from computational nodes to rendering servers over networks or storage on disk, offering incremental encoding/decoding with low memory usage [S1].

## How it works
**Inputs:** A regular 3D volume $V$ of dimension $n_1 \times n_2 \times n_3$, an isovalue $p$, and a quantization scheme for function values [S1].
**Outputs:** A compressed bitstream containing encoded indices of relevant vertices, encoded function values, and encoded indices of valid cells [S1].

**Data Structures:**
1.  **Relevant Vertex Bitmap:** A 2D bitmap for each slice where bit $r=1$ if the vertex is an intersection point on an edge of the volume (relevant), and $r=0$ otherwise [S1].
2.  **Valid Cell Bitmap:** A 2D bitmap for each layer (between two adjacent slices) where bit $i=1$ if the cell contains isosurface geometry (valid), and $i=0$ otherwise [S1].
3.  **Function Values:** Quantized values for relevant vertices [S1].

**Numbered Steps:**

1.  **Initialization:** Read the first slice of the volume into main memory [S1].
2.  **Iteration:** For each layer $k$ in the volume (from $0$ to $n_2 - 2$):
    a.  Read the next slice (slice $k+1$) into main memory as the second slice [S1].
    b.  **Mark Relevant Vertices:** March through all vertices on the current slice (slice $k$) [S1]. For each vertex, determine if it lies on the isosurface (i.e., it is an intersection point on an edge of the regular 3D volume) [S1]. Set bit $r=1$ if relevant, $r=0$ otherwise [S1].
    c.  **Mark Valid Cells:** March through all cells in the layer between slice $k$ and slice $k+1$ [S1]. For each cell, determine if it is a "valid cell" (i.e., its 8 corners contain at least one vertex with value $> p$ and one with value $< p$) [S1]. Set bit $i=1$ if valid, $i=0$ otherwise [S1].
    d.  **Encode Vertex Indices (Slice $k$):** Encode the indices of the relevant vertices on slice $k$ using an entropy encoding method [S1]. The 2D bitmap of relevant vertices is converted to a bit sequence using scan-line conversion [S1].
    e.  **Encode Function Values (Slice $k$):** Encode the quantized function values of the relevant vertices on slice $k$ using second-order difference prediction (see Formula below) [S1].
    f.  **Encode Cell Indices (Layer $k$):** Encode the indices of the valid cells in the current layer using an entropy encoding method [S1]. The 2D bitmap of valid cells is converted to a bit sequence using scan-line conversion [S1].
    g.  **Output:** Output the encoded data for this step [S1].
    h.  **Shift Memory:** Remove slice $k$ from memory [S1]. Set slice $k+1$ as the new first slice [S1].
3.  **Final Slice:** Encode the last slice (slice $n_2 - 1$) similarly to step 2d and 2e, and output the encoded data [S1].

**Decoding Steps:**
1.  For each layer of the volume:
    a.  Receive the encoded indices of the valid cells in the layer and the encoded indices/function values of the relevant vertices on its bounding slices [S1].
    b.  Decode the data to reconstruct the bitmaps and function values [S1].
    c.  For every valid cell in the layer:
        i.  Find its configuration by checking the signs of the 8 vertices relative to the isovalue $p$ [S1].
        ii. Compute the intersection points on its edges using linear interpolation with the decoded function values [S1].
        iii. Get the triangulation inside the cell from the standard Marching Cubes table [S1].
        iv. Render the triangles [S1].

**Formulas:**
For floating-point function values, they are first normalized to the range $[-0.5, 0.5]$ [S1]. Let $x_0, \dots, x_n$ be the sequence of function values for relevant vertices on a slice [S1]. Let $p$ be the isovalue.

1.  Encode the quantization of the first value $x_0$ and its sign relative to $p$ [S1]. Let $\tilde{x}_0$ be the quantized value of $x_0$ [S1].
2.  For $i = 0, \dots, n - 1$:
    $$ \Delta_i = x_{i+1} - \tilde{x}_i $$
    Encode $\Delta_i$ using the given quantization bits and the sign of $x_{i+1}$ relative to the isovalue $p$ [S1].
    Update the predictor:
    $$ \tilde{x}_{i+1} = \tilde{x}_i + \tilde{\Delta}_i $$
    where $\tilde{\Delta}_i$ is the quantized value of $\Delta_i$ [S1].

The correction term $\Delta_i = x_{i+1} - \tilde{x}_i$ is used instead of $x_{i+1} - x_i$ to prevent the accumulation of quantization errors [S1]. An extra sign bit is stored for every relevant vertex to indicate the sign of its function value $x$ relative to $p$ [S1]. This handles quantization errors that might cause a sign flip (e.g., $x < p$ becomes $\tilde{x} > p$), which would alter the isosurface topology [S1].

**Parameters:**
*   **Entropy Coding:** Adaptive arithmetic coder [S1] or adaptive Z-Coder [S1]. Z-Coder runs faster with similar compression ratios [S1].
*   **Bitmap Conversion:** Scan-line conversion is used to convert 2D bitmaps into bit sequences. Size variations among conversion methods are insignificant [S1].
*   **Quantization:** For float values, 32 bits are used for the first point and 14 bits for differences [S1]. For fixed-precision data (u_short, u_char), encoding can be lossless [S1].

**Pitfalls and Edge Cases:**
*   **Sign Flip:** Quantization error may cause the sign of a function value $x$ relative to the isovalue $p$ to flip (e.g., $x < p$ becomes $\tilde{x} > p$) [S1]. The method handles this by storing an extra sign bit per relevant vertex [S1]. During decoding, if a decompressed value has a sign flip against the isovalue, it is shifted by one quantization unit left or right to recover the correct sign [S1].
*   **Memory Usage:** The algorithm requires only two slices and one layer in main memory at any time, enabling incremental processing [S1].

**Pseudocode:**

```python
def encode_edge_index_encoding(volume, isovalue, quantization_bits):
    """
    volume: 3D array of shape (n1, n2, n3)
    isovalue: float or int
    quantization_bits: int
    Returns: list of encoded bitstreams per slice/layer
    """
    n1, n2, n3 = volume.shape
    stream = []
    slice_prev = volume[:, 0, :]

    # Encode first slice relevant vertices and values
    relevant_prev = create_vertex_bitmap(slice_prev, isovalue)
    stream.append(entropy_encode_scanline(relevant_prev))
    stream.append(encode_function_values(slice_prev, relevant_prev, isovalue, quantization_bits))

    for k in range(1, n2):
        slice_curr = volume[:, k, :]
        valid_cells = create_cell_bitmap(slice_prev, slice_curr, isovalue)

        # Encode valid cell indices for the layer
        stream.append(entropy_encode_scanline(valid_cells))

        # Encode relevant vertex indices and values for current slice
        relevant_curr = create_vertex_bitmap(slice_curr, isovalue)
        stream.append(entropy_encode_scanline(relevant_curr))
        stream.append(encode_function_values(slice_curr, relevant_curr, isovalue, quantization_bits))

        slice_prev = slice_curr

    return stream

def create_vertex_bitmap(slice_data, isovalue):
    """Returns 2D array of 0/1 where 1 indicates a relevant vertex."""
    h, w = slice_data.shape
    bitmap = [[0] * w for _ in range(h)]
    for x in range(h):
        for z in range(w):
            if slice_data[x, z] != isovalue:
                bitmap[x][z] = 1
    return bitmap

def create_cell_bitmap(slice_prev, slice_curr, isovalue):
    """Returns 2D array of 0/1 where 1 indicates a valid cell in the layer."""
    h, w = slice_prev.shape
    cells = [[0] * (w - 1) for _ in range(h - 1)]
    for x in range(h - 1):
        for z in range(w - 1):
            vals = [slice_prev[x, z], slice_prev[x, z + 1], slice_curr[x, z], slice_curr[x, z + 1]]
            if not all(v > isovalue for v in vals) and not all(v < isovalue for v in vals):
                cells[x][z] = 1
    return cells

def entropy_encode_scanline(bitmap):
    """Flattens 2D bitmap into a 1D list of bits and compresses it."""
    bits = [bit for row in bitmap for bit in row]
    # Standard adaptive arithmetic coder or Z-Coder [G]
    return bits

def quantize(value, bits):
    """Rounds value to nearest integer given quantization bits."""
    scale = 1 << (bits - 1)
    return int(round(value * scale))

def encode_function_values(slice_data, vertices, isovalue, q_bits, stream):
    """Encodes function values using predictive difference coding."""
    values = []
    for x in range(len(vertices)):
        for z in range(len(vertices[0])):
            if vertices[x][z] == 1:
                values.append(slice_data[x, z] - isovalue)
    
    if not values:
        return stream
        
    # Normalize to [-0.5, 0.5] [S1]
    max_abs = max(abs(v) for v in values) if max(abs(v) for v in values) != 0 else 1
    normalized = [v / max_abs * 0.5 for v in values]
    
    # Encode first value and sign [S1]
    x0 = normalized[0]
    sign_x0 = 1 if x0 >= 0 else -1
    quantized_x0 = quantize(x0, q_bits)
    stream.append(sign_x0)
    stream.append(quantized_x0)
    
    prev_quantized = quantized_x0
    
    for i in range(len(normalized) - 1):
        x_next = normalized[i + 1]
        sign_next = 1 if x_next >= 0 else -1
        delta = x_next - prev_quantized
        quantized_delta = quantize(delta, q_bits)
        
        stream.append(sign_next)
        stream.append(quantized_delta)
        
        prev_quantized = prev_quantized + quantized_delta
        
    return stream

def decode_edge_index_encoding(encoded_stream, volume_dims, isovalue, quantization_bits):
    """Reconstructs the isosurface triangles from the encoded stream."""
    triangles = []
    n1, n2, n3 = volume_dims
    idx = 0
    
    # Decode first slice
    relevant_prev = decode_bitmap(encoded_stream[idx], n1, n3); idx += 1
    values_prev = decode_function_values(encoded_stream[idx], isovalue, quantization_bits); idx += 1
    
    vertex_data_prev = [(x, z, values_prev[i]) for i, (x, z) in enumerate([(x, z) for x in range(n1) for z in range(n3) if relevant_prev[x][z] == 1])]
    
    for k in range(1, n2):
        valid_cells = decode_bitmap(encoded_stream[idx], n1 - 1, n3 - 1); idx += 1
        relevant_curr = decode_bitmap(encoded_stream[idx], n1, n3); idx += 1
        values_curr = decode_function_values(encoded_stream[idx], isovalue, quantization_bits); idx += 1
        
        vertex_data_curr = [(x, z, values_curr[i]) for i, (x, z) in enumerate([(x, z) for x in range(n1) for z in range(n3) if relevant_curr[x][z] == 1])]
        all_vertices = vertex_data_prev + vertex_data_curr
        
        for cell in valid_cells:
            config = get_marching_cubes_config(cell, all_vertices, isovalue)
            intersections = compute_intersections(cell, all_vertices, isovalue)
            tris = get_triangulation(config, intersections)
            triangles.extend(tris)
            
        vertex_data_prev = vertex_data_curr
        
    return triangles

def decode_bitmap(bit_sequence, h, w):
    """Reconstructs 2D bitmap from flattened bit sequence."""
    return [[int(bit_sequence[x * w + z]) for z in range(w)] for x in range(h)]

def decode_function_values(bit_sequence, isovalue, q_bits):
    """Decodes function values using predictive difference coding."""
    values = []
    sign_x0 = bit_sequence[0]
    quantized_x0 = bit_sequence[1]
    values.append(quantized_x0)
    
    prev_quantized = quantized_x0
    i = 2
    while i < len(bit_sequence):
        sign_next = bit_sequence[i]
        quantized_delta = bit_sequence[i + 1]
        prev_quantized = prev_quantized + quantized_delta
        values.append(prev_quantized)
        i += 2
        
    # Correct sign flips if necessary [S1]
    corrected_values = []
    scale = 1 << (q_bits - 1)
    for i, v in enumerate(values):
        expected_sign = 1 if i == 0 else bit_sequence[2 * i]
        if (v >= 0) != (expected_sign >= 0):
            v += scale if v > 0 else -scale
        corrected_values.append(v)
        
    # Denormalize and shift back to original scale
    max_abs = max(abs(v) for v in corrected_values) if max(abs(v) for v in corrected_values) != 0 else 1
    return [v / 0.5 * max_abs + isovalue for v in corrected_values]
```

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of cells and vertices in the volume, as it requires a single pass through the volume data during encoding and decoding [S1].
*   **Memory Complexity:** Low. Only two slices and one layer of cells need to be held in main memory at any time, enabling incremental encoding and decoding [S1].
*   **Measured Performance:**
    *   **Hipip (float, isovalue 0.0):** Original 1,465,862 bytes, General Algorithm 129,068 bytes, Edge Index 88,804 bytes [S1].
    *   **Foot (u_short, isovalue 600):** Original 7,536,227 bytes, General Algorithm 587,344 bytes, Edge Index 407,658 bytes [S1].
    *   **Engine (u_char, isovalue 180):** Original 3,601,040 bytes, General Algorithm 224,893 bytes, Edge Index 121,504 bytes [S1].
*   **Scaling:** The method scales well on commodity clusters (e.g., Compaq SP750 workstations) for datasets up to 16.5 GB, leveraging incremental processing to start rendering before full transmission [S1].
*   **Strengths:** Better compression ratios than general surface compression (which uses 8 bits per coordinate per vertex); allows incremental encoding/decoding; low memory footprint; robust to quantization errors via sign bits [S1].
*   **Limitations:** Specific to isosurfaces from regular 3D volumes; requires the Marching Cubes algorithm or similar for reconstruction; dependent on the quality of the entropy coder [S1].

## Background
Edge Index Encoding was introduced in the context of scalable isosurface visualization on commodity off-the-shelf clusters [S1]. It addresses the need for compact representation of isosurfaces transmitted from computational nodes to rendering servers via network or stored on disk for later examination [S1]. The method exploits the property that isosurfaces extracted from regular 3D volumes are embedded in the 3D mesh, allowing coordinate reconstruction from edge indices and endpoint values, thus avoiding explicit coordinate storage [S1]. It was compared against general surface compression algorithms (such as the one in [7]) and demonstrated superior compression ratios and lower memory requirements [S1].
