# LBG Algorithm
Also called: Linde-Buzo-Gray, Generalized Lloyd Algorithm
## Overview
The Linde-Buzo-Gray (LBG) algorithm is an iterative vector quantization method that partitions a set of input vectors into quantization regions and updates codebook entries to minimize distortion [S1, unofficial]. It solves the problem of finding an optimal codebook for lossy compression by iteratively refining centroid positions [S1, unofficial].
## How it works
**Inputs:**
- Set of input vectors $I \subset \mathbb{R}^n$ [S1, unofficial].
- Target number of codebook entries $m = 2^r$, where $r$ is the bit-rate [S1, unofficial].
- Convergence threshold $\epsilon$ [S1, unofficial].
- Distance metric $\delta(X, Y)$, typically squared Euclidean distance [S1, unofficial].

**Outputs:**
- Final codebook $C = \{Y_i\}_{i=1}^m$ [S1, unofficial].
- Partition $\{V_i\}_{i=1}^m$ of $I$, where each $X \in I$ is mapped to an index [S1, unofficial].

**Data Structures:**
- Codebook $C$: Array of $m$ vectors, each of dimension $n$ [S1, unofficial].
- Input set $I$: Array of vectors, each of dimension $n$ [S1, unofficial].
- Quantization regions $V_i$: Implicitly defined by assignment; can be stored as an index map mapping each $X \in I$ to an integer $i \in \{1, \dots, m\}$ [S1, unofficial].

**Steps:**
1. **Initialize:** Start with an initial codebook $C^{(0)} = \{Y_i^{(0)}\}_{i=1}^m \subset \mathbb{R}^n$ [S1, unofficial]. Set iteration counter $k = 0$, previous distortion $D^{(0)} = 0$, and select convergence threshold $\epsilon$ [S1, unofficial]. The initial codebook is usually obtained by a splitting technique: start with the centroid of $I$ as one entry, add a random offset to create a second entry, run LBG until convergence, and repeat doubling until $m$ entries are reached [S1, unofficial].
2. **Assign regions:** For each codebook entry $Y_i^{(k)}$, find the quantization region $V_i^{(k)} = \{X \in I : \delta(X, Y_i^{(k)}) < \delta(X, Y_j^{(k)}) \text{ for all } j \neq i, j=1,\dots,m\}$ [S1, unofficial]. This assigns each input vector to its nearest codebook entry [S1, unofficial].
3. **Compute distortion:** Calculate total distortion $D^{(k)} = \sum_{i=1}^m \sum_{X \in V_i^{(k)}} \delta(X, Y_i^{(k)})$ [S1, unofficial].
4. **Check convergence:** If $\frac{D^{(k-1)} - D^{(k)}}{D^{(k)}} < \epsilon$, stop [S1, unofficial].
5. **Update codebook:** Increment $k$. Find new codebook $\{Y_i^{(k)}\}_{i=1}^m$ by calculating the centroids of each cell $V_i^{(k-1)}$ [S1, unofficial]. Go to step 2 [S1, unofficial].

**Pseudocode:**
```python
def lbq_algorithm(I, m, epsilon, delta_func):
    """
    I: list of input vectors (each a list/array of floats)
    m: number of codebook entries
    epsilon: convergence threshold
    delta_func: distance function delta(X, Y)
    """
    n = len(I[0])
    
    # Step 1: Initialize codebook using splitting technique [S1, unofficial]
    centroid = [sum(X[j] for X in I) / len(I) for j in range(n)]
    C = [centroid]
    import random
    offset = [random.uniform(-1, 1) for _ in range(n)]
    C.append([centroid[j] + offset[j] for j in range(n)])
    
    # Run LBG convergence, then double until m entries
    while len(C) < m:
        k = 0
        D_prev = 0.0
        while True:
            V = [[] for _ in range(len(C))]
            for X in I:
                min_dist = float('inf')
                best_idx = -1
                for i in range(len(C)):
                    d = delta_func(X, C[i])
                    if d < min_dist:
                        min_dist = d
                        best_idx = i
                V[best_idx].append(X)
            
            D_curr = sum(sum(delta_func(X, C[i]) for X in V[i]) for i in range(len(C)))
            if k > 0 and (D_prev - D_curr) / D_curr < epsilon:
                break
            
            new_C = []
            for i in range(len(C)):
                if len(V[i]) == 0:
                    new_C.append(C[i]) # [G] Keep previous centroid to avoid collapse
                else:
                    centroid_i = [sum(X[j] for X in V[i]) / len(V[i]) for j in range(n)]
                    new_C.append(centroid_i)
            C = new_C
            D_prev = D_curr
            k += 1
        
        # Double codebook size
        new_C = []
        for Y in C:
            new_C.append(Y)
            offset = [random.uniform(-1, 1) for _ in range(n)]
            new_C.append([Y[j] + offset[j] for j in range(n)])
        C = new_C

    # Final LBG refinement for target size m
    k = 0
    D_prev = 0.0
    while True:
        V = [[] for _ in range(m)]
        for X in I:
            min_dist = float('inf')
            best_idx = -1
            for i in range(m):
                d = delta_func(X, C[i])
                if d < min_dist:
                    min_dist = d
                    best_idx = i
            V[best_idx].append(X)
        
        D_curr = sum(sum(delta_func(X, C[i]) for X in V[i]) for i in range(m))
        if k > 0 and (D_prev - D_curr) / D_curr < epsilon:
            break
        
        new_C = []
        for i in range(m):
            if len(V[i]) == 0:
                new_C.append(C[i]) # [G] Keep previous centroid
            else:
                centroid_i = [sum(X[j] for X in V[i]) / len(V[i]) for j in range(n)]
                new_C.append(centroid_i)
        C = new_C
        D_prev = D_curr
        k += 1
        
    return C, V
```

**Parameters:**
- $\epsilon$: Convergence threshold for relative distortion change. Typical value not specified, but used to stop iteration when gain is negligible [S1, unofficial].
- $m$: Number of codebook entries, determined by bit-rate $r$ such that $m = 2^r$ [S1, unofficial].

**Pitfalls:**
- **Empty cell problem:** Codebook entries may collapse during refinement, resulting in empty cells that waste codebook entries. The standard LBG does not detect these automatically [S1, unofficial].
- **Performance:** Repeated nearest neighbor searches in step 2 slow down performance significantly [S1, unofficial].
- **Initialization sensitivity:** The algorithm's result depends on the initial codebook [S1, unofficial].

## Subtopics

### [Modified Vector Quantization (LBG variant)](1130-modified-vector-quantization-lbg-variant.md)
Modified Vector Quantization is a vector quantization algorithm that uses a distortion-based splitting technique to generate the initial codebook, avoiding the time-consuming nearest neighbor searches of the standard LBG algorithm and solving the empty cell problem. It sets itself apart from standard LBG by replacing the random initialization and iterative Lloyd-Max refinement with a deterministic, greedy splitting process driven by residual distortion.

### Agglomerative Information Bottleneck
A technique that extracts a compact representation of variable $X$ (denoted $\hat{X}$) with minimal loss of mutual information with respect to variable $Y$, using hard partitions where each $x$ is assigned to only one cluster [S4, unofficial]. An optimal merge of $l$ components can be obtained by $l - 1$ consecutive optimal merges of pairs of components [S4, unofficial]. The decrease in mutual information due to merging components $x_1, \dots, x_l$ is given by $\delta I_{\hat{x}} = p(\hat{x}) JS(\pi_1, \dots, \pi_l; p_1, \dots, p_l) \geq 0$, where weights $\pi_k = p(x_k)/p(\hat{x})$ and distributions $p_k = p(Y|x_k)$ [S4, unofficial].

## Operating characteristics
- **Scaling:** Repeated nearest neighbor searches slow down performance significantly [S1, unofficial].
- **Strengths:** Simple to implement [S1, unofficial].
- **Limitations:** Sensitive to initialization; suffers from empty cell problem; slow for large datasets [S1, unofficial].

## Background
The LBG algorithm is a modification of the Lloyd-Max algorithm for scalar quantization, extended to vector quantization [S1, unofficial]. It is general enough to deal with high-dimensional multi-parameter data [S1, unofficial].
