# Block Transforms


## Overview
Block transforms decompose a 1-D signal into fixed-size, non-overlapping blocks and apply a linear transformation matrix to each block independently to produce transform coefficients [S1, unofficial]. The input signal $S$ is divided into blocks $B_i$ of $M$ samples [S1, unofficial]. The method is defined as a separable transform, meaning the 1-D transform is applied sequentially to all dimensions [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A 1-D signal $S$.
*   **Output:** A vector of transform coefficients $\bar{S}$ of the same length as $S$ [S1, unofficial].

**Data Structures**
The signal is partitioned into $n+1$ blocks $B_i$, where each block $B_i$ contains $M$ samples [S1, unofficial]. The global forward transform matrix $H$ is a block-diagonal matrix of size $L_{total} \times L_{total}$ [S1, unofficial].

**Formulas**
1.  **Block Partitioning:** The signal $S$ is divided into fixed-size, non-overlapping blocks $B_i$ of $M$ samples [S1, unofficial]:
    $$ B_i = [S_{M \times i}, S_{M \times i+1}, \dots, S_{M \times i+M-1}] $$
    $$ S = [B_0, B_1, \dots, B_n] $$
2.  **Block Transformation:** Each block $B_i$ is transformed by a real-valued $M \times M$ transform matrix $T_f$ [S1, unofficial]:
    $$ \bar{B}_i = T_f B_i $$
3.  **Global Transformation:** The coefficients are concatenated as $\bar{S} = [\bar{B}_0, \bar{B}_1, \dots, \bar{B}_n]$ [S1, unofficial]. The global matrix $H$ places $T_f$ on its diagonal:
    $$ H = \begin{bmatrix} T_f & 0 & \dots & 0 \\ 0 & T_f & \dots & 0 \\ \vdots & \vdots & \ddots & \vdots \\ 0 & 0 & \dots & T_f \end{bmatrix} $$

**Parameters**
*   $M$: Block size (number of samples per block). Not given in the sources [S1, unofficial].
*   $T_f$: The specific transform matrix (e.g., DCT, LOT). Not given in the sources [S1, unofficial].

**Pseudocode**
```python
def block_transform_forward(signal, block_size, transform_matrix):
    """
    Performs forward block transform on a 1-D signal.
    
    Args:
        signal (list[float]): Input 1-D signal S.
        block_size (int): M, the number of samples per block.
        transform_matrix (list[list[float]]): MxM matrix T_f.
        
    Returns:
        list[float]: Transformed coefficients S_bar.
    """
    n_samples = len(signal)
    num_blocks = n_samples // block_size
    transformed_signal = []
    
    for i in range(num_blocks):
        start_idx = i * block_size
        end_idx = start_idx + block_size
        block = signal[start_idx:end_idx]
        
        transformed_block = [0.0] * block_size
        for r in range(block_size):
            sum_val = 0.0
            for c in range(block_size):
                sum_val += transform_matrix[r][c] * block[c]
            transformed_block[r] = sum_val
            
        transformed_signal.extend(transformed_block)
        
    return transformed_signal

def block_transform_inverse(transformed_signal, block_size, inverse_transform_matrix):
    """
    Performs inverse block transform to reconstruct the signal.
    
    Args:
        transformed_signal (list[float]): Input coefficients S_bar.
        block_size (int): M.
        inverse_transform_matrix (list[list[float]]): MxM matrix T_f_inv.
        
    Returns:
        list[float]: Reconstructed signal S.
    """
    n_samples = len(transformed_signal)
    num_blocks = n_samples // block_size
    reconstructed_signal = []
    
    for i in range(num_blocks):
        start_idx = i * block_size
        end_idx = start_idx + block_size
        block = transformed_signal[start_idx:end_idx]
        
        reconstructed_block = [0.0] * block_size
        for r in range(block_size):
            sum_val = 0.0
            for c in range(block_size):
                sum_val += inverse_transform_matrix[r][c] * block[c]
            reconstructed_block[r] = sum_val
            
        reconstructed_signal.extend(reconstructed_block)
        
    return reconstructed_signal
```

**Edge Cases and Pitfalls**
*   **Boundary Conditions:** The method assumes the signal length is an exact multiple of the block size $M$; padding or truncation is required otherwise [G].
*   **Separability:** The source defines this as a "separable transform," meaning the 1-D transform is applied sequentially to all dimensions (e.g., rows then columns for 2-D data) [S1, unofficial].

## Subtopics

### Generalized Lapped Orthogonal Transform (GenLOT)
GenLOT generalizes the LOT and DCT by allowing overlapping blocks with an overlap factor $N$ [S1, unofficial]. The analysis and synthesis filters $g_i(n)$ and $f_i(n)$ satisfy $g_i(n) = f_i(L - (n + 1)) \pm f_i(n)$, where $L = M \times N$ and $M$ is an even integer [S1, unofficial]. The poly-phase transfer matrix is $E(z) = S Q^T \Lambda(z)^{N-1} T_{N-2} \Lambda(z) \dots T_0 \Lambda(z) Q$, where $S, Q$ are orthogonal, $\Lambda(z)$ is a delay matrix, and $T_i$ are orthogonal matrices [S1, unofficial]. This factors into $E(z) = K_{N-1}(z) \dots K_1(z) E_0(z)$, with $K_i(z) = \Phi_i W \Lambda(z) W$ and $E_0(z)$ containing Type 2 DCT components [S1, unofficial]. The time-domain matrix $P_i$ is computed recursively as $P_i = \Phi_i \begin{bmatrix} 0 & 0 \\ I & 0 \\ 0 & I \end{bmatrix} \begin{bmatrix} 0 & W P_{i-1} \\ 0 & 0 \end{bmatrix}$, initialized with $P_0$ as the Type 2 DCT [S1, unofficial]. GenLOT1 and GenLOT2 are special cases where the subscript indicates the number of overlapping blocks, making DCT and LOT specific instances [S1, unofficial].
