# Transform-based Block Coding

Also called: Block Transformation Coding

## Overview
Transform-based Block Coding decomposes volumetric data into fixed-size blocks, applies a linear transform to each block to concentrate energy into a few coefficients, and encodes these coefficients for storage or transmission. It solves the problem of efficiently compressing large volumetric datasets while maintaining spatial locality for random access. It differs from global transform methods by operating on independent blocks, which simplifies parallelization and error propagation but may ignore inter-block correlations, and from predictive coding by relying on frequency domain decorrelation rather than spatial redundancy prediction.

## Shared principles
All methods in this family share the mechanism of decomposing the input volume $V$ into a set of coefficients $C$ using a linear transform, followed by encoding and optional decoding for rendering.

1.  **Transform:** The volume is decomposed using a separable 1D filter bank applied along each axis. For a 3D volume, this results in subbands representing different frequency components. In wavelet transforms, these are typically approximation (low-pass) and detail (high-pass) coefficients. In Laplacian pyramids, they are detail residuals between levels of a Gaussian pyramid [see [Wavelet and Pyramid Transforms](3856-wavelet-and-pyramid-transforms.md)].
2.  **Hierarchy:** The decomposition is recursive. The approximation subband from level $j$ is further decomposed at level $j+1$, creating a tree-like structure of coefficients. This allows for multi-resolution access, where coarse data is available at the root and fine details are deeper in the tree [see [Value compression](6-value-compression.md)].
3.  **Quantization and Entropy Encoding:** Coefficients are quantized (lossy) or kept precise (lossless). Entropy coding (e.g., Huffman, Arithmetic, Run-Length) is applied to the quantized or raw coefficients to produce the compressed bitstream [see [Value compression](6-value-compression.md)].
4.  **Reconstruction:** To render, the necessary coefficients are decoded and the inverse transform is applied. This can be done globally (full reconstruction) or locally (block-wise or point-wise) to support adaptive resolution rendering [see [Value compression](6-value-compression.md)].

## Subtopics

### [ZFP Block-Based Compression](1504-zfp-block-based-compression.md)
[ZFP Block-Based Compression](1504-zfp-block-based-compression.md) is a floating-point compression algorithm using fixed-rate compression, encoding blocks of 4x4x4 floating-point values. It is a de facto standard in the HPC community.

### [TSDF Block Transform Coding](2548-tsdf-block-transform-coding.md)
[TSDF Block Transform Coding](2548-tsdf-block-transform-coding.md) is a compression method for Truncated Signed Distance Function (TSDF) volumes that decomposes the input into fixed-size voxel blocks, applies a 3D Discrete Cosine Transform (DCT) to map spatial values to frequency coefficients, and entropy codes the retained low-frequency components. It distinguishes itself from sibling methods like JPEG2000 by using a fixed, data-independent 3D DCT kernel rather than wavelets, and from Learned Transform Coding by avoiding the need to compute and transmit scene-specific transform parameters, thereby targeting real-time streaming across arbitrary scenes.

### [JPEG2000](2883-jpeg2000.md)
[JPEG2000](2883-jpeg2000.md) is a wavelet-based compression standard for still images that serves as the primary benchmark for 2-D coding systems in volumetric data compression. In the context of volume rendering, it is often employed as a baseline method where each 2D layer of a layered image is coded separately using JPEG2000 Part-1, referred to as "Individual layer coding". This approach sets itself apart from 3D volumetric schemes by ignoring inter-slice correlations, resulting in lower compression efficiency and visible artifacts at layer boundaries compared to methods that exploit 3D redundancy.

### [Learned Transform Coding](7046-learned-transform-coding.md)
[Learned Transform Coding](7046-learned-transform-coding.md) is a compression approach used when direct rate-distortion optimization is intractable due to high-dimensional input data. It transforms input data $x$ into a latent representation $z$ via an encoder $E$, recovers a lossy version $\hat{x}$ from a quantized latent $\hat{z}$ via a decoder $D$, and optimizes both transformations jointly with a learned probability model for the latent. It is distinguished from fixed-basis transform methods like JPEG2000 and TSDF Block Transform Coding by its ability to learn data-adaptive, non-linear transformations and probabilistic priors, allowing for superior rate-distortion trade-offs on complex volumetric data.

#### Block Transformation Coding
**Definition**
A technique based on block transformation coding to address difficulties of rendering large datasets on a GPU [S1].

## Background
The concept of block transformation coding for volume rendering was proposed by Fout and Ma to address the difficulties of rendering large datasets on a GPU [S1]. Jung et al. presented a multiresolution scheme to render large out-of-core CT human cadaver volumes using GPU raycasting, employing techniques such as load-on-demand data management and transfer function-based data reduction [S1].
