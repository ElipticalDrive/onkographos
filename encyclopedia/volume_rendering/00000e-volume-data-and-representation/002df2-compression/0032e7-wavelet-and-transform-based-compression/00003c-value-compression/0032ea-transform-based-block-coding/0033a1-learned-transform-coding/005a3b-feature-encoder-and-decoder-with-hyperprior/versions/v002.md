# Feature Encoder and Decoder with Hyperprior

Also called: Neural Feature Compression

## Overview
This method compresses the feature planes of hybrid Neural Radiance Fields (NeRF) by mapping them into a latent space, quantizing them, and using a hyperprior to estimate probability distributions for entropy coding [S1]. It addresses the failure of directly applying standard neural image compression to NeRF feature planes, which yields poor rate-distortion performance [S1]. It sets itself apart from Variational Autoencoder-based Compression by explicitly incorporating a feature compensation module to recover high-frequency residuals lost during quantization, rather than relying solely on the latent reconstruction [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Feature planes $x$ from a hybrid NeRF variant [S1].
*   **Output:** Reconstructed feature planes $\tilde{x}$ and a bitstream containing quantized latent code $\hat{y}$, quantized hyperprior latent code $\hat{z}$, feature decoder head parameters $D_{\phi 2}$, feature residual vectors $v_{\Delta x}$, tiny MLP parameters $f$, and metadata [S1].

**Data Structures:**
*   **Feature Planes ($x$):** Input feature planes from the hybrid NeRF variant [S1].
*   **Latent Code ($y$):** Continuous latent representation of $x$ obtained via $E_\theta$ [S1].
*   **Quantized Latent ($\hat{y}$):** Discretized version of $y$ [S1].
*   **Hyperprior Latent ($z$):** Coarse representation derived from $y$ via $H_E$ [S1].
*   **Quantized Hyperprior ($\hat{z}$):** Discretized version of $z$ [S1].
*   **Feature Residual Vectors ($v_{\Delta x}$):** Vectors used to form the residual matrix $M_{\Delta x}$ via outer product [S1].
*   **Feature Decoder Backbone ($D_{\phi 1}$):** Pre-trained neural image compression network, kept frozen [S1].
*   **Feature Decoder Head ($D_{\phi 2}$):** Content-specific parameters, trained jointly [S1].
*   **Tiny MLP ($f$):** Predicts color and density from $\tilde{x}$ [S1].

**Steps:**
1.  **Encoding:** The feature encoder $E_\theta$ maps input feature planes $x$ to latent code $y$ [S1].
2.  **Quantization:** $y$ is quantized to $\hat{y}$ [S1].
3.  **Hyperprior Generation:** A hyperprior encoder $H_E$ processes $y$ to obtain hyperprior latent code $z$ [S1].
4.  **Hyperprior Quantization:** $z$ is quantized to $\hat{z}$ [S1].
5.  **Probability Estimation:** A hyperprior decoder $H_D$ takes $\hat{z}$ to estimate the probability distribution $P_{\hat{y}}$ of the quantized latent code [S1].
6.  **Entropy Coding:** The quantized latent code $\hat{y}$ is entropy-coded using $P_{\hat{y}}$ [S1].
7.  **Decoding:** The quantized latent code $\hat{y}$ is fed into the feature decoder $D_\phi$ to generate reconstructed feature planes $\hat{x}$ [S1]. The decoder $D_\phi$ consists of the backbone $D_{\phi 1}$ and head $D_{\phi 2}$ [S1].
8.  **Feature Compensation:** To compensate for high-frequency loss, a feature residual matrix $M_{\Delta x}$ is added to $\hat{x}$ [S1]. The matrix is represented by the outer product of feature residual vectors $v_{\Delta x}$ [S1].
    $$ \tilde{x} = \hat{x} + M_{\Delta x} $$
    *(Note: $M_{\Delta x}$ is constructed as the outer product of $v_{\Delta x}$; exact tensor reshaping depends on the spatial and channel dimensions of $x$ [G].)*
9.  **Rendering:** The final feature planes $\tilde{x}$ are passed to a tiny MLP $f$ to predict color and density for volume rendering [S1].

**Parameters:**
*   $E_\theta$: Feature encoder parameters [S1].
*   $H_E, H_D$: Hyperprior encoder/decoder parameters [S1].
*   $D_{\phi 1}$: Frozen pre-trained backbone [S1].
*   $D_{\phi 2}$: Trained decoder head [S1].
*   $v_{\Delta x}$: Feature residual vectors [S1].
*   $f$: Tiny MLP for rendering [S1].

**Pitfalls:**
*   Directly applying advanced neural image compression methods to hybrid NeRF feature planes without modification (like the hyperprior and compensation) does not achieve high rate-distortion performance [S1].
*   Precision issues may arise in the outer product calculation if $v_{\Delta x}$ is not normalized or scaled appropriately relative to $\hat{x}$ [G].

## Subtopics

### Hyperprior-based Entropy Encoding
This variant, described in the context of 3D Gaussian Splatting compression, maps input Gaussian attributes $x$ into latent space $\hat{y}$ via an analysis transform $g_a$ and quantization $Q$ [S2, unofficial]. A hyperprior branch uses a coarse representation $\hat{z}$ to estimate the distribution parameters of $\hat{y}$ under a Gaussian distribution assumption, aiding entropy encoding and decoding [S2, unofficial]. It may also apply various context models to $\hat{y}$ to improve probability estimation [S2, unofficial]. The synthesis transform $g_s$ projects $\hat{y}$ back to the original space as $\hat{x}$ [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources. [S1]
*   **Memory Complexity:** Not given in the sources. [S1]
*   **Measured Performance:** Not given in the sources. [S1]
*   **Strengths:** Improves rate-distortion performance for hybrid NeRFs compared to unmodified neural image compression methods by addressing high-frequency loss [S1].
*   **Limitations:** Requires training of specific components ($E_\theta, H_E, H_D, D_{\phi 2}, v_{\Delta x}, f$) while keeping $D_{\phi 1}$ frozen [S1].
*   **When to use:** When compressing feature planes of hybrid NeRF variants where standard image codecs fail to preserve rendering quality [S1].

## Background
The method was proposed in "NeRFCodec: Neural Feature Compression Meets Neural Radiance Fields for Memory-Efficient Scene Representation" [S1]. It builds on prior neural network compression work [S1] and addresses the limitations of applying image compression to NeRF features [S1].
