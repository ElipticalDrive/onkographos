# Variational Autoencoder-based Compression

Also called: Autoencoders and Variational Autoencoders (VAEs), Probabilistic Autoencoder Compression, VAE-based Compression

## Overview
Variational Autoencoder-based Compression uses an encoder-decoder pair to map volumetric data into a probabilistic latent space, enabling lossy compression where the latent code replaces the original grid [S1, unofficial]. It distinguishes itself from deterministic autoencoders by imposing a probabilistic structure on the latent variables, which enables sampling and interpolation capabilities [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A volumetric dataset $V$ (e.g., a 3D grid of scalar or vector values) [S1, unofficial].
- Output: A compressed representation consisting of the latent code $z$, and a reconstructed volume $\hat{V}$ [G].

**Data Structures:**
- **Encoder Network ($E$):** A neural network that maps $V$ to latent parameters [G].
- **Latent Space:** A continuous vector space where each point $z$ represents a compressed version of the input [G].
- **Decoder Network ($D$):** A neural network that maps $z$ back to the reconstruction space [G].
- **Latent Code:** The compressed output, typically a tensor of lower dimensionality than $V$ [G].
Exact Layouts: Not given in the sources.

**Method Steps:**
1. **Encoding:** The input volume $V$ is passed through the encoder $E$ to produce latent parameters, typically a mean $\mu$ and variance $\sigma^2$ for a Gaussian distribution [G].
2. **Reparameterization:** To enable backpropagation through the stochastic sampling process, the latent vector $z$ is sampled using the reparameterization trick:
   $$ z = \mu + \sigma \odot \epsilon $$
   where $\epsilon \sim \mathcal{N}(0, I)$ is noise sampled from a standard normal distribution, $\mu$ is the mean vector, $\sigma$ is the standard deviation vector, and $\odot$ denotes element-wise multiplication [G].
3. **Compression:** The latent vector $z$ replaces the original grid $V$ [S1, unofficial].
4. **Decoding:** The latent code $z$ is passed through the decoder $D$ to reconstruct the volume:
   $$ \hat{V} = D(z) $$
   where $\hat{V}$ is the reconstructed volumetric data [G].
5. **Training:** The network is trained to minimize a loss function that balances reconstruction fidelity and latent space regularization (e.g., KL divergence between the learned latent distribution and a prior, typically $\mathcal{N}(0, I)$) [G].

**Parameters:**
Latent Dimensionality: Not given in the sources.
- Network Architecture: Typically convolutional networks, with related scientific volume methods adopting 3D convolutions in frameworks like SRGAN and ESRGAN [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Decoding Bottleneck:** Data-space diffusion methods can suffer from severe decoding bottlenecks (e.g., 978 seconds versus 2 seconds for a standard autoencoder), making them impractical for interactive use [S1, unofficial].
- **Precision:** The probabilistic nature allows for interpolation but introduces inherent reconstruction error dependent on the training data distribution [G].

## Subtopics

### Latent Space Diffusion
A variant that moves diffusion into latent space to address decoding bottlenecks. It sets itself apart from data-space diffusion by compressing only selected keyframes via a VAE with hyperprior and interpolating non-keyframes, offering significantly higher throughput. Choose this variant when interactive decoding speed is critical and the volume data exhibits strong temporal or spatial coherence [S1, unofficial].

## Operating characteristics
- Time Complexity: Not given in the sources.
- Memory Complexity: The latent code replaces the original grid, reducing memory footprint [S1, unofficial].
- Measured Performance: On an A100 GPU, decoding throughput reached 61 MB/s for latent space diffusion variants, which is 200× faster than GCDTC’s data-space diffusion (978 seconds) and faster than SZ3 (12 seconds) on comparable tasks [S1, unofficial]. Achieved up to 10× higher compression ratios than SZ3 on S3D combustion data and 4× on E3SM climate data [S1, unofficial].
- Scaling: Fine-tuning from 1,000 to 32 denoising steps preserved compression quality while raising decoding throughput [S1, unofficial].
- Strengths: Enables lossy compression of large volumes and captures semantically meaningful structure in the latent space for feature learning [S1, unofficial].
- Limitations: Data-space diffusion methods suffer from severe decoding bottlenecks; probabilistic models require careful training to ensure latent space continuity [G].
- When to use: Suitable for large scientific volumes where latent codes replace original grids and semantic structure preservation is valuable [S1, unofficial].
- When not to use: Unsuitable when interactive decoding speed is required and data-space diffusion is used, due to severe bottlenecks [S1, unofficial].

## Background
Autoencoders and Variational Autoencoders (VAEs) have been explored for scientific data compression before more recent frameworks matured [S1, unofficial]. Earlier works included feature-aware in-situ autoencoders achieving 32× reduction on particle data, GAN in-situ compressors reaching 64:1 on CFD pressure fields, SR-enhanced SZ predictors with up to 75% ratio improvement on volumes up to 512^3, hierarchical vector-quantized autoencoders achieving 231× compression at 50 dB on climate data, and GAN volume completion synthesizing missing subvolumes at 34–45 dB with up to 50% data absent [S1, unofficial]. VAEs specifically impose a probabilistic latent structure, enabling sampling and interpolation, which distinguishes them from deterministic autoencoders [S1, unofficial].
