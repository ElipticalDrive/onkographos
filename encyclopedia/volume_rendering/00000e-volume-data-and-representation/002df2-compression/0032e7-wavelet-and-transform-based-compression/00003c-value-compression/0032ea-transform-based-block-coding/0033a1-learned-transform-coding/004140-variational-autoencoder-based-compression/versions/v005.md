# Variational Autoencoder-based Compression

Also called: Autoencoders and Variational Autoencoders (VAEs), Probabilistic Autoencoder Compression, VAE-based Compression

## Overview
Variational Autoencoder-based Compression uses encoder-decoder pairs to learn compressed latent codes that reconstruct input volume data, imposing a probabilistic latent structure that enables sampling and interpolation [S1, unofficial]. It differs from standard autoencoders by enforcing this probabilistic structure, and from deterministic learned transform coding by optimizing the latent distribution rather than just a point estimate, making it suitable for both lossy compression (where the latent code replaces the original grid) and feature learning [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A volume dataset $V$ (e.g., a 3D grid of scalar or vector values).
- Output: A compressed representation consisting of the latent code $z$ (and potentially hyperparameters for the probabilistic model), and a reconstructed volume $\hat{V}$.

**Data Structures:**
- **Encoder $E$**: A neural network (typically 3D convolutions) mapping $V \rightarrow z$.
- **Decoder $D$**: A neural network (typically 3D transposed convolutions or deconvolutions) mapping $z \rightarrow \hat{V}$.
- **Latent Code $z$**: A continuous vector or tensor representing the compressed state. In VAEs, $z$ is drawn from a distribution $q(z|V)$, typically parameterized as a Gaussian $\mathcal{N}(\mu, \sigma^2)$ where $\mu$ and $\sigma$ are outputs of the encoder [S1, unofficial].

**Steps:**
1. **Encoding**: Pass the input volume $V$ through the encoder $E$ to obtain the parameters of the latent distribution, specifically the mean $\mu$ and log-variance $\log \sigma^2$.
2. **Reparameterization**: Sample the latent code $z$ from the distribution $q(z|V) = \mathcal{N}(\mu, \sigma^2)$ using the reparameterization trick: $z = \mu + \sigma \odot \epsilon$, where $\epsilon \sim \mathcal{N}(0, I)$ [S1, unofficial].
3. **Decoding**: Pass the latent code $z$ through the decoder $D$ to reconstruct the volume $\hat{V}$.
4. **Optimization**: Jointly optimize the encoder and decoder parameters to minimize a loss function that balances reconstruction fidelity and the divergence between the learned latent distribution and a prior (typically a standard normal distribution). The loss typically includes a reconstruction term (e.g., Mean Squared Error) and a Kullback-Leibler (KL) divergence term [S1, unofficial].

**Parameters:**
- **Latent Dimensionality**: Determined by the architecture of the encoder's bottleneck layer. Not given in the sources.
- **Prior Distribution**: Typically a standard normal distribution $\mathcal{N}(0, I)$ [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Precision**: Floating-point precision in the latent representation affects reconstruction quality.
- **Boundaries**: Boundary effects in 3D convolutions may require padding strategies.
- **Degenerate Input**: VAEs may struggle with highly sparse or discontinuous data if the probabilistic assumption does not match the data distribution.

**Pseudocode:**
```python
def train_vae(volume_data, encoder, decoder, optimizer, epochs):
    for epoch in range(epochs):
        for batch in volume_data:
            # Forward pass
            mu, log_var = encoder(batch)
            
            # Reparameterization trick
            std = torch.exp(0.5 * log_var)
            eps = torch.randn_like(std)
            z = mu + std * eps
            
            # Reconstruction
            reconstructed = decoder(z)
            
            # Loss calculation
            reconstruction_loss = mse_loss(reconstructed, batch)
            kl_loss = -0.5 * torch.sum(1 + log_var - mu.pow(2) - log_var.exp())
            loss = reconstruction_loss + kl_loss
            
            # Backward pass
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
```

## Subtopics

### Latent Space Diffusion
Latent Space Diffusion moves diffusion models into the latent space to address decoding bottlenecks in volume compression [S1, unofficial]. It compresses only selected keyframes via a VAE with hyperprior, then uses a conditional latent diffusion model with factorized space-time attention to interpolate latent representations for non-keyframes [S1, unofficial]. This method fine-tunes from 1,000 to 32 denoising steps to preserve compression quality [S1, unofficial]. It achieved up to 10× higher compression ratios than SZ3 on S3D combustion data and 4× on E3SM climate data [S1, unofficial]. It raised decoding throughput to 61 MB/s on an A100 GPU, 200× faster than GCDTC’s data-space diffusion [S1, unofficial].

## Operating characteristics
- **Time Complexity**: Encoding and decoding complexity depends on the neural network architecture (typically $O(N)$ for linear layers or $O(N \log N)$ for attention mechanisms in Transformers) [S1, unofficial].
- **Memory Complexity**: The latent code size is significantly smaller than the original volume, determined by the bottleneck dimension [S1, unofficial].
- **Measured Performance**: Latent Space Diffusion achieved 61 MB/s decoding throughput on an A100 GPU [S1, unofficial]. Standard autoencoders have been reported to decode in 2 seconds compared to 978 seconds for data-space diffusion (GCDTC) [S1, unofficial].
- **Scaling**: Scales with the capacity of the neural network and the available GPU memory [S1, unofficial].
- **Strengths**: Enables sampling and interpolation due to probabilistic latent structure; efficient compression for large volumes [S1, unofficial].
- **Limitations**: Requires training data and computational resources for training; decoding bottleneck if not optimized (e.g., via latent space diffusion) [S1, unofficial].
- **When to Use**: When lossy compression of large volumes is needed, and the latent space can capture semantically meaningful structure [S1, unofficial].
- **When Not to Use**: When real-time decoding is critical and hardware acceleration for neural networks is unavailable, or when exact reconstruction is required [S1, unofficial].

## Background
Variational Autoencoders (VAEs) were introduced as a probabilistic extension of autoencoders, enabling sampling and interpolation in the latent space [S1, unofficial]. In the context of scientific volume visualization, autoencoders and VAEs have been explored for lossy compression of large volumes and feature learning, where the latent space captures semantically meaningful structure [S1, unofficial]. Earlier works explored autoencoder and GAN architectures for scientific data compression, including feature-aware in-situ autoencoders and hierarchical vector-quantized autoencoders [S1, unofficial].
