# Learned Transform Coding
Also called: Lossy Transform Coding, Neural Transform Coding

## Overview
Learned Transform Coding is a compression approach used when direct rate-distortion optimization is intractable for high-dimensional data [S1]. It transforms input data $x$ into a latent representation $z$ via an encoder $E$, recovers a lossy version $\hat{x}$ from a quantized latent $\hat{z}$ via a decoder $D$, and optimizes both transformations jointly with a learned probability model for the latent [S1].

## How it works
**Inputs and Outputs:**
*   Input: Original volumetric data $x$.
*   Output: Compressed bitstream representing the quantized latent $\hat{z}$ entropy-coded using the learned prior $p_{\hat{z}}$ [S1].

**Data Structures:**
*   Encoder parameters $\theta_e$: Weights of the neural network $E$ [S1].
*   Decoder parameters $\theta_d$: Weights of the neural network $D$ [S1].
*   Probability model parameters $\phi$: Parameters defining the distribution $p_{\hat{z}}$ [S1].
*   Latent representation $z$: Continuous vector/tensor output by $E$ [S1].
*   Quantized latent $\hat{z}$: Discretized version of $z$ [S1].

**Steps:**
1.  **Encode:** Compute the continuous latent representation $z$ by applying the encoder network to the input data $x$:
    $$ z = E(x; \theta_e) $$
2.  **Quantize:** Discretize the latent representation $z$ to obtain $\hat{z}$:
    $$ \hat{z} = Q(z) $$
    The quantization operation $Q(\cdot)$ is non-differentiable [S1].
3.  **Model:** Compute the bit rate $R(\hat{z}; \phi)$ using the learned probability model (prior) $p_{\hat{z}}$ with parameters $\phi$:
    $$ R(\hat{z}; \phi) = -\log p_{\hat{z}}(\hat{z}; \phi) $$
4.  **Decode:** Recover the lossy reconstruction $\hat{x}$ from the quantized latent $\hat{z}$ using the decoder network:
    $$ \hat{x} = D(\hat{z}; \theta_d) $$
5.  **Entropy Code:** Convert $\hat{z}$ into a variable-length bit string using entropy coding based on the learned prior distribution $p_{\hat{z}}$ [S1].

**Optimization:**
The system is trained by minimizing the joint objective function:
$$ \arg \min_{\theta, \phi} D(x, \hat{x}; \theta) + \lambda R(\hat{z}; \phi) $$
where $D(x, \hat{x}; \theta)$ is the distortion metric, $R(\hat{z}; \phi)$ is the bit rate, and $\lambda$ is the rate-distortion trade-off parameter [S1].

**Parameters:**
*   $\lambda$: Rate-distortion trade-off parameter. Higher values yield better bit rates at the expense of increased distortion [S1].
*   $\theta = \{\theta_e, \theta_d\}$: Parameters for the encoder and decoder networks [S1].
*   $\phi$: Parameters for the learned probability model $p_{\hat{z}}$ [S1].

```python
    rate = -math.log(p_z_hat)

    # Recover z_hat from bitstream using the learned prior [S1]
    z_hat = standard_entropy_decode(bitstream)
    # Step 4: Decode
    x_hat = decoder(z_hat)
    return x_hat

def learned_transform_coding_train(x, encoder, decoder, model, quantizer, optimizer, lambda_param):
    # Forward pass
    z = encoder(x)
    z_hat = quantizer(z)
    x_hat = decoder(z_hat)
    # Compute distortion (standard mean squared error)
    distortion = sum((x - x_hat) ** 2) / len(x)
    # Compute rate
    p_z_hat = model.probability(z_hat)
    rate = -math.log(p_z_hat)
    # Total loss
    loss = distortion + lambda_param * rate
    # Backpropagation
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    return loss
```

## Subtopics

### Sliced-Wasserstein Autoencoder Compression
A variant that replaces the linear regression predictor in SZ2.1 with a pre-trained Sliced-Wasserstein autoencoder (SWAE) in an error-bounded compression framework [S2, unofficial]. It distinguishes itself by selecting, for each data block, whichever predictor (autoencoder or Lorenzo) achieves lower $\ell_1$ loss [S2, unofficial]. It applies linear-scale quantization followed by Huffman and Zstd encoding [S2, unofficial]. On volumes up to $512^3$ (NYX cosmology), it achieved 100–800% higher compression ratios than SZ2.1 and ZFP at matched PSNR, though its compression throughput (12–68 MB/s) remains an order of magnitude below that of the unmodified SZ pipeline [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** On volumes up to $512^3$ (NYX cosmology), the Sliced-Wasserstein variant achieved 100–800% higher compression ratios than SZ2.1 and ZFP at matched PSNR [S2, unofficial].
*   **Throughput:** Compression throughput is 12–68 MB/s, which is an order of magnitude below that of the unmodified SZ pipeline [S2, unofficial].
*   **Strengths:** Direct rate-distortion optimization is intractable for high-dimensional data, making the transform approach necessary [S1].
*   **Limitations:** Training requires joint optimization of encoder, decoder, and probability model [S1]. Throughput can be significantly lower than traditional pipelines [S2, unofficial].

## Background
Learned Transform Coding is a general framework for lossy compression where direct rate-distortion optimization is intractable [S1]. It has been applied to scientific volume data, such as cosmology simulations (NYX) using Sliced-Wasserstein Autoencoders [S2, unofficial].
