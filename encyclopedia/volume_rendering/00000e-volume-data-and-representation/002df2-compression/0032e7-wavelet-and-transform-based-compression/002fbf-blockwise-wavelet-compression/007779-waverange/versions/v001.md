# WaveRange

Also called: Three-dimensional wavelet transform (WaveRange)

## Overview
WaveRange is a wavelet-based data compression method designed for three-dimensional numerical simulation data on regular grids, specifically targeting applications in Earth science such as atmospheric dynamic simulations [S1]. It operates by applying a separable 3D discrete wavelet transform, followed by quantization and entropy coding, to minimize compressed file size at a given accuracy [S1]. It differs from similar methods, such as that of Sakai et al. (2013a), primarily in its specific error control mechanisms and wavelet transform depth configuration [S1].

## How it works
The method consists of three sequential steps: wavelet transform, quantization, and entropy coding. Reconstruction is performed by applying the inverse operations in reverse order [S1].

### Inputs and Outputs
*   **Input:** A 3D array of point values in physical space, $f_{i_x, i_y, i_z}$, where $i_x = 1, \dots, n_x$, $i_y = 1, \dots, n_y$, and $i_z = 1, \dots, n_z$ [S1]. The data is sampled on single- or multi-block grids with each block using three-dimensional Cartesian indexing [S1].
*   **Output:** A compressed representation. The wavelet transform step produces approximation and detail coefficients placed in the same array as the input, $F_{i_x, i_y, i_z}$ [S1].

### Data Structures
The algorithm operates in-place on a 3D array. During the transform, data elements are copied into contiguous 1D arrays for processing along each axis.

### Algorithm Steps

1.  **Initialization:**
    Initialize the current dimensions $m_x, m_y, m_z$ to the input dimensions $n_x, n_y, n_z$. Copy the input data $f_{i_x, i_y, i_z}$ to the output array $F_{i_x, i_y, i_z}$ [S1].

2.  **Multi-level 3D Wavelet Transform:**
    Iterate through decomposition levels $l = 1$ to $L$. For each level, apply the 1D wavelet transform sequentially along the $x$, $y$, and $z$ axes. The approximation coefficients from the previous level serve as the input for the next level [S1].

    The 1D wavelet transform along a specific axis (e.g., $x$) for a fixed $i_y, i_z$ is performed as follows:
    *   Copy elements $F_{j_x, i_y, i_z}$ (where $j_x = 1, \dots, m_x$) into a contiguous 1D array $g_{j_x}$ [S1].
    *   Apply the 1D wavelet transform to $g_{j_x}$ [S1].
    *   Copy the result back to $F_{j_x, i_y, i_z}$ [S1].

    This process is repeated for the $y$ and $z$ axes if their respective dimensions are greater than 1 [S1].

3.  **Dimension Update:**
    After processing all three axes for a level, update the dimensions for the next level:
    $$m_x \leftarrow \lceil m_x/2 \rceil; \quad m_y \leftarrow \lceil m_y/2 \rceil; \quad m_z \leftarrow \lceil m_z/2 \rceil$$
    [S1].

4.  **Quantization:**
    Quantize the wavelet coefficients. Detail coefficients smaller than an accuracy threshold are approximated as integer zeros. Small detail coefficients are reduced to a few (less than 8) bytes per coefficient [S1].

5.  **Entropy Coding:**
    Compress the quantized coefficients. The quantized transform contains constant sequences of one-byte integers, including sequences of zeros, which are efficiently compressed by entropy coding [S1].

### Parameters
*   **Accuracy Threshold:** A parameter used in quantization to approximate detail coefficients smaller than this value as integer zeros. The specific value is not defined in the sources [S1].
*   **Number of Levels ($L$):** The depth of the wavelet transform. The sources note that WaveRange differs from Sakai et al. (2013a) in wavelet transform depth, but do not specify the default or optimal $L$ [S1].

### Edge Cases and Pitfalls
*   **Grid Topology:** The method is restricted to single- or multi-block grids with three-dimensional Cartesian indexing [S1].
*   **Precision:** Small-scale structures may randomize quickly if small initial errors are introduced in the simulation, affecting reconstruction accuracy [S1].
*   **Quantization:** The source states that detail coefficients smaller than the threshold are approximated as integer zeros, but does not specify the exact bit-depth for non-zero small coefficients, only that they are reduced to less than 8 bytes per coefficient [S1].

## Subtopics

### Vorticity Cartesian Compression
A variant of WaveRange applied to velocity fields. It computes the spatial average of the velocity field $\mathbf{U}_0$ and the vorticity $\boldsymbol{\Omega} = \nabla \times \mathbf{U}$. The three components of $\boldsymbol{\Omega}$ are compressed independently using WaveRange with a prescribed tolerance $\epsilon$. The velocity is reconstructed from $\boldsymbol{\Omega}$ and $\mathbf{U}_0$ using the Biot–Savart formula. All differential and integral operators are approximated using a Fourier spectral method. This method is less efficient than velocity Cartesian compression due to truncation errors from differentiation and non-uniform error distribution across components [S1].

## Operating characteristics
*   **Compression Ratio:** Defined as $r = s(f) / s(\varphi)$, where $s(f)$ is the original size and $s(\varphi)$ is the compressed size [S1].
*   **Performance:** The method is designed to minimize compressed file size at a given accuracy. It is particularly efficient for signals that are locally correlated and have sparse fine-scale activity, such as turbulent flow fields [S1].
*   **Accuracy vs. Compression:** The relationship between reconstruction error and compression ratio is a key focus. The 'velocity Cartesian' method (standard WaveRange application) provides the best compression for a desired $10^{-4}$ accuracy compared to variants like 'vorticity Cartesian' or 'velocity polar' [S1].
*   **Limitations:** The 'vorticity Cartesian' and 'velocity polar' variants suffer from loss of uniformity in spatial error distribution and unequal errors across components, leading to inefficiency [S1]. The 'velocity polar' method also suffers from discontinuities in spherical coordinates ($\vartheta, \phi$) that artificially introduce small scales [S1].

## Background
WaveRange was developed for three-dimensional numerical simulation data on regular grids, with a focus on Earth science applications like atmospheric dynamic simulations [S1]. The computer code is implemented in C/C++ and is open-source [S1]. The method is conceptually similar to the method of Sakai et al. (2013a) but differs in error control and wavelet transform depth [S1].
