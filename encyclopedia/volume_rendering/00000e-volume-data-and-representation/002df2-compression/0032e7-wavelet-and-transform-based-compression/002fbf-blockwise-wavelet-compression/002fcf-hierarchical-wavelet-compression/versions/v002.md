# Hierarchical Wavelet Compression

Also called: Hierarchical Wavelet Representation

## Overview
Hierarchical Wavelet Compression is a lossy compression technique that extends blockwise wavelet decomposition by organizing volumetric data into an octree structure, enabling multi-resolution access and high compression ratios without noticeable artifacts [S1, unofficial][S2]. It differs from standard blockwise approaches by recursively grouping low-frequency components across multiple levels, whereas alternatives like [8] apply wavelet equations only twice in a fixed 16×16×16 subregion [S1, unofficial].

## How it works
**Inputs and Outputs:**
* **Input:** A three-dimensional array of integers with fixed precision [S1, unofficial].
* **Output:** A compressed octree representation where insignificant coefficients are discarded [S1, unofficial].

**Data Structures:**
* **Octree:** Each node describes a volume of $k^3$ voxels [S1, unofficial].
* **Node Content:** The node stores the low-pass filtered coefficients (the $k^3$ volume) and high-frequency coefficients [S1, unofficial]. The high-frequency coefficients allow the reconstruction of child nodes from the current node [S1, unofficial].

**Algorithm Steps:**
1. **Block Division:** Divide the input volume data set into cubic blocks of size $(2k)^3$ voxels [S1, unofficial].
2. **Wavelet Transform:** Apply wavelet filters to each $(2k)^3$ block to obtain a low-pass filtered component of size $k^3$ voxels and high-frequency components of size $(2k)^3 - k^3$ voxels [S1, unofficial].
3. **Grouping:** Group the low-pass filtered blocks by groups of 8 to form a new block of size $(2k)^3$ voxels for the next level [S1, unofficial].
4. **Recursion:** Repeat steps 2 and 3 on the newly formed low-pass blocks until only a single block remains, resulting in an octree structure [S1, unofficial].
5. **Thresholding:** Define a threshold below which all wavelet coefficients are mapped to zero to reduce storage space, making the compression lossy [S1, unofficial].

**Formulas:**
* Low-pass filtered size: $k^3$ voxels [S1, unofficial].
* High-pass filtered size: $(2k)^3 - k^3$ voxels [S1, unofficial].

**Parameters:**
* **Threshold:** A value below which coefficients are zeroed out. The specific value is not given in the sources [S1, unofficial].
* **Block Size:** The base block size parameter $k$ is not explicitly defined in the sources, though the initial block dimension is $(2k)^3$ [S1, unofficial].

**Pseudocode:**
```python
def hierarchical_wavelet_compress(volume, k, threshold):
    # volume: 3D array of shape (N, N, N) with integer values
    # k: base dimension parameter; initial blocks are (2k)^3
    # threshold: scalar; coefficients with |value| < threshold are zeroed [S1, unofficial]

    # Step 1: Divide volume into (2k)^3 blocks
    blocks = []
    for i in range(0, volume.shape[0], 2 * k):
        for j in range(0, volume.shape[1], 2 * k):
            for l in range(0, volume.shape[2], 2 * k):
                blocks.append(volume[i:i+2*k, j:j+2*k, l:l+2*k])

    current_level_blocks = blocks

    # Steps 2-4: Recursive wavelet decomposition and grouping
    while len(current_level_blocks) > 1:
        next_level_blocks = []
        # Step 3: Group low-pass blocks by 8 to form (2k)^3 blocks for the next level
        for idx in range(0, len(current_level_blocks), 8):
            group = current_level_blocks[idx : idx + 8]
            if len(group) < 8:
                continue # Incomplete group; handled as leaf or padded [G]

            # Combine 8 blocks of size k^3 into a (2k)^3 volume
            combined = np.empty((2*k, 2*k, 2*k), dtype=group[0].dtype)
            for i in range(2):
                for j in range(2):
                    for m in range(2):
                        idx_block = i * 4 + j * 2 + m
                        combined[i*k:(i+1)*k, j*k:(j+1)*k, m*k:(m+1)*k] = group[idx_block]

            # Step 2: Apply separable 3D wavelet transform to the (2k)^3 block [G]
            low_pass = combined.copy()
            high_pass = np.zeros_like(combined)
            for axis in range(3):
                # Apply 1D low-pass and high-pass filters along current axis
                low_pass, high_pass_axis = apply_1d_wavelet_pair(low_pass, combined)
                high_pass += high_pass_axis # Accumulate high-frequency details [G]
                low_pass = low_pass[:, :, :] # Update low_pass for next axis

            # Create octree node: stores k^3 low-pass volume and high-pass coefficients
            node = {
                'low_pass': low_pass,
                'high_pass': high_pass
            }
            next_level_blocks.append(node)

        current_level_blocks = next_level_blocks

    # Step 4: Single block remains -> root
    octree_root = current_level_blocks[0] if current_level_blocks else None

    # Step 5: Thresholding to discard insignificant coefficients
    threshold_octree(octree_root, threshold)

    return octree_root

def apply_1d_wavelet_pair(data, original):
    # Standard 1D DWT along the last axis: low-pass (downsampled) and high-pass (detail) [G]
    # Assumes even length and standard orthogonal filter pair
    half = data.shape[-1] // 2
    low = np.zeros_like(data[..., :half])
    high = np.zeros_like(data[..., :half])
    for i in range(data.shape[-1] // 2):
        low[..., i] = 0.5 * (data[..., 2*i] + data[..., 2*i+1])
        high[..., i] = 0.5 * (data[..., 2*i] - data[..., 2*i+1])
    return low, high

def threshold_octree(node, threshold):
    # Zero out high-frequency coefficients below threshold [S1, unofficial]
    node['high_pass'] = np.where(np.abs(node['high_pass']) < threshold, 0, node['high_pass'])
    if 'children' in node:
        for child in node['children']:
            threshold_octree(child, threshold)
```

## Subtopics

### [3D Haar Wavelet Compression with Hierarchical Subblocks](6519-3d-haar-wavelet-compression-with-hierarchical-subblocks.md)
A compression scheme for 3D volumetric datasets that applies the Haar Wavelet Transform hierarchically to 16x16x16 unit blocks, dividing data into low-frequency averages and high-frequency error matrices across four levels. It differs from standard blockwise approaches by organizing four distinct levels of compression within the block structure, whereas alternatives like [8] apply equations only twice in a 2x2x2 subregion. The method prioritizes computational simplicity and fast reconstruction speed over the high-quality smoothing provided by bases like Daubechies.

## Operating characteristics
* **Compression Ratio:** Up to 4:1 for typical data sets (lossy) [S1, unofficial]. The source also notes that Guthe et al.'s scheme allows compression ratios of 30:1 without noticeable artifacts [S1, unofficial].
* **Memory:** Large data sets can be stored in main memory due to the high compression ratio [S1, unofficial].
* **Hardware:** Tested on a 2Ghz Pentium 4 PC with 1GB of RAM and an nVidia GeForce 4 Ti4600 graphics board with 128MB of local video memory [S1, unofficial].
* **Strengths:** Allows compression of large data sets into main memory; enables access to parts of the volume without decompressing the whole data set (unlike [6]) [S1, unofficial].
* **Limitations:** Lossy compression; requires preprocessing to convert integer arrays to compressed representation [S1, unofficial].

## Background
* **Origin:** Proposed by Stefan Guthe et al. [S1, unofficial].
* **History:** This work solved problems presented in Guthe et al. [6], which proposed a wavelet compression scheme with extensions for encoding animated data sets but did not allow access to part of the volume without decompressing the whole data set [S1, unofficial].
* **Usage:** Used for interactive visualization of very large volume data sets [S1, unofficial][S2].
