# 3D Haar Wavelet Compression with Hierarchical Subblocks

Also called: Haar Wavelet Transform, Local Wavelet Compression, Haar-based 3D Wavelet Compression

## Overview
A compression scheme for 3D volumetric datasets that applies the Haar Wavelet Transform hierarchically to 16x16x16 unit blocks, dividing data into low-frequency averages and high-frequency error matrices across four levels [S1, S2, unofficial]. It differs from standard blockwise approaches by organizing four distinct levels of compression within the block structure, whereas alternatives like [8] apply equations only twice in a 2x2x2 subregion [S1, unofficial]. The method prioritizes computational simplicity and fast reconstruction speed over the high-quality smoothing provided by bases like Daubechies [S2, unofficial].

## How it works
**Inputs:** A 3D volumetric dataset (scalar density or RGB vector values).
**Outputs:** Compressed data stream containing low-frequency coefficients, quantized error coefficients, quantization parameters ($I_K, L_K$), transfer function parameters, and metadata.

**Data Structures:**
*   **Unit Block:** A 16x16x16 voxel sub-volume.
*   **Coefficient Array:** Stores decomposed coefficients in a specific ordering (see [S2, Fig 2, unofficial]). The array size equals the input size.
*   **Quantization Parameters:** $I_K$ and $L_K$, representing values in groups of matrices sharing a face, edge, or vertex with the low-frequency matrix [S1, unofficial].

**Algorithm Steps:**

1.  **Partitioning:** Divide the volume into non-overlapping 16x16x16 unit blocks [S1, S2, unofficial].
2.  **Hierarchical Decomposition (W1-W4):** For each unit block, apply the 3D Haar transform iteratively to the low-frequency submatrix of the previous step. The transform operates on 2x2x2 submatrices using 8 equations (low-pass and high-pass filters) [S1, unofficial].
    *   **Step W1:** Apply the 8 equations $8 \times 8 \times 8$ times to each 2x2x2 submatrix within the 16x16x16 block. Extract the low-frequency submatrix [S1, unofficial].
    *   **Step W2:** Apply the 8 equations $4 \times 4 \times 4$ times to each 2x2x2 submatrix of the result from W1. Extract the low-frequency submatrix [S1, unofficial].
    *   **Step W3:** Apply the 8 equations $2 \times 2 \times 2$ times to each 2x2x2 submatrix of the result from W2. Extract the low-frequency submatrix [S1, unofficial].
    *   **Step W4:** Apply the 8 equations 1 time to the single remaining 2x2x2 submatrix of the result from W3 [S1, unofficial].
    *   *Note:* While [S2, unofficial] describes applying the transform twice per block, [S1, unofficial] details the four-level hierarchical structure (W1-W4) which is the defining characteristic of this specific method [S1, S2, unofficial]. The four-level approach ensures that for a 16x16x16 block, only one element remains as the global low-frequency average [S1, unofficial].
3.  **Quantization:** Quantize the wavelet coefficients (both low frequencies and high-frequency error values) to restrict values to a limited number of possibilities. This is the primary stage of information loss [S2, unofficial]. Use $I_K$ and $L_K$ parameters for quantization [S1, unofficial]. The L2 norm is used for CT and RGB data compression [S2, unofficial].
4.  **Encoding:** Encode the quantized symbols using a variable length coder (e.g., Huffman or arithmetic coding) [S2, unofficial]. The transmitted information includes low-frequency coefficients, quantified error coefficients, function $T$ parameters, transfer function $T_R$, and $I_K/L_K$ [S1, unofficial].

**Formulas:**
The 3D Haar transform decomposes a 2x2x2 subregion into 8 coefficients: $c_{lll}$ (average) and 7 detail coefficients [S2, unofficial].
Detail coefficients correspond to filter sequences. For example, $c_{hlh}$ is obtained by applying high-pass, low-pass, then high-pass filters [S2, unofficial].
The specific filter bank expressions and reconstruction formulae are referenced in [S2, Fig 2, unofficial] and [S2, Fig 3, unofficial] respectively. Reconstruction is the reverse of decomposition [S2, unofficial].

## Subtopics

### Hierarchical Reconstruction for Interactive Zoom/Pan
A client-side reconstruction process allowing interaction control by applying between 0 and 4 reconstruction steps to compressed data, generating models of varying resolutions [S1, unofficial].
*   **Step 0:** Group only the one low-frequency value from each 16x16x16 sub-block to obtain a low-resolution model (e.g., 16x16x8 for a 256x256x128 model) [S1, unofficial].
*   **Step 1:** Group the 2x2x2 low-frequency sub-matrices in each 16x16x16 sub-block to obtain a higher-resolution model (e.g., 32x32x16) [S1, unofficial].
*   **Steps 2-4:** Continue grouping sub-matrices to increase resolution until the original resolution is generated [S1, unofficial].
*   **Rendering:** After reconstruction, recover density values between 0 and 255 ($V_T$), then apply transfer function $T_R$ to assign color and opacity [S1, unofficial].

### Quantization and Huffman Encoding for Wavelet Compressed Volumes
A quantization scheme where wavelet coefficients are transformed into quantized values, followed by Huffman coding for transmission [S1, unofficial].
*   **Quantization:** Low frequencies and error values are quantized using parameters $I_K$ and $L_K$ [S1, unofficial].
*   **Encoding:** The compressed data (low frequency coefficients, quantified error coefficients, parameters of function $T$, transfer function $T_R$, and $I_K/L_K$) is encoded using Huffman Codes [S1, unofficial].
*   **Parameters:** $I_K$ and $L_K$ are generic variables representing values in groups of matrices which share a face, edge, or vertex with the low-frequency matrix [S1, unofficial].

## Operating characteristics
*   **Complexity:** The Haar wavelet is computationally cheap, implemented by additions, subtractions, and shifts [S2, unofficial]. Reconstruction is fast [S2, unofficial].
*   **Performance:** In a 256x256x128 model, after 4 compression steps, the low-frequency matrix has only one element per 16x16x16 block, resulting in 16x16x8 = 2048 low-frequency elements total [S1, unofficial]. Two applications of the transform (as per [S2, unofficial]) decompose 63/64 of the data into detail coefficients [S2, unofficial].
*   **Strengths:** Fast decomposition and reconstruction; suitable for wireless transmission due to high compression ratios [S1, S2, unofficial].
*   **Limitations:** Lower quality compared to Daubechies wavelets [S2, unofficial]. Variable length coders (Huffman/Arithmetic) are inappropriate if individual data items must be quickly reconstructed in an arbitrary sequence [S2, unofficial].
*   **When to use:** Interactive visualization on mobile devices or wireless networks where speed and bandwidth are critical [S1, unofficial].
*   **When not to use:** When high-quality smoothing is required or random access to individual voxels is needed without full decoding [S2, unofficial].

## Background
Originated in the context of volumetric medical images visualization on mobile devices [S1, unofficial]. The method was proposed to achieve good compression results for transmission over wireless networks [S1, unofficial]. It builds on local wavelet compression techniques but differs from prior work [8] by applying four levels of compression organized in different structures [S1, unofficial]. The Haar basis was selected for its simplicity and speed, despite lower quality compared to other bases [S2, unofficial].
