# Bounded Integer Sequence Encoding (BISE)
## Overview
Bounded Integer Sequence Encoding (BISE) is a variable-length coding method that stores sequences of integers from arbitrary alphabets (up to 256 symbols) using a fractional number of bits per symbol [S1]. It solves the inefficiency of rounding up symbol counts to the next power of two by packing symbols into groups that align with bit boundaries, specifically using binary, trit (3-symbol), and quint (5-symbol) encodings [S1]. Unlike standard binary encoding, BISE allows the compressor to select the most space-efficient alphabet representation for a given symbol count, significantly reducing storage waste for non-power-of-two alphabet sizes [S1].

## How it works
**Inputs:** A sequence of $S$ integers (symbols), where each integer is in the range $[0, N-1]$ for an alphabet size $N$ [S1].
**Outputs:** A bit string of fixed length determined by $N$ and $S$ [S1].

**Data Structures:**
The encoding relies on three primitive alphabet types [S1]:
1. **Binary:** Alphabet size up to $2^n - 1$ [S1].
2. **Trit:** Alphabet size up to $3 \cdot 2^n - 1$ [S1]. Uses a trit $t \in [0, 2]$ and $n$ bits $m$ [S1].
3. **Quint:** Alphabet size up to $5 \cdot 2^n - 1$ [S1]. Uses a quint $q \in [0, 4]$ and $n$ bits $m$ [S1].

**Parameters:**
* $S$: Number of symbols in the sequence [S1].
* $N$: Size of the alphabet (number of distinct symbol values) [S1].
* $n$: Integer parameter such that $2^n$ is the base power of two for the encoding scheme [S1].

**Formulas:**
The compressor selects the encoding scheme that minimizes storage [S1]. The storage cost for a sequence of $S$ symbols with alphabet size $N$ is [S1]:

1. **Binary Encoding:**
   If $N \le 2^n - 1$:
   $$ \text{Bits} = n \cdot S $$
   [S1]

2. **Trit Encoding:**
   If $N \le 3 \cdot 2^n - 1$:
   $$ \text{Bits} = n \cdot S + \lceil 8S / 5 \rceil $$
   [S1]
   Reconstruction of a symbol $x$ from trit $t$ and bits $m$:
   $$ x = t \cdot 2^n + m $$
   [S1]

3. **Quint Encoding:**
   If $N \le 5 \cdot 2^n - 1$:
   $$ \text{Bits} = n \cdot S + \lceil 7S / 3 \rceil $$
   [S1]
   Reconstruction of a symbol $x$ from quint $q$ and bits $m$:
   $$ x = q \cdot 2^n + m $$
   [S1]

**Numbered Steps:**
1. Determine the alphabet size $N$ required for the data [S1].
2. Identify the smallest integer $n$ such that the alphabet fits into one of the three schemes: Binary ($N \le 2^n - 1$), Trit ($N \le 3 \cdot 2^n - 1$), or Quint ($N \le 5 \cdot 2^n - 1$) [S1].
3. Calculate the storage cost for each valid scheme using the formulas above [S1].
4. Select the scheme with the minimum storage cost [S1].
5. Encode the sequence of $S$ symbols using the selected scheme [S1].
   * For **Binary**: Pack $n$ bits per symbol directly [S1].
   * For **Trit**: Pack groups of 5 symbols. Each group uses 8 bits [S1]. The 8 bits store the trit overhead, while $n$ bits are stored per symbol for the $m$ component [S1].
   * For **Quint**: Pack groups of 3 symbols. Each group uses 7 bits [S1]. The 7 bits store the quint overhead, while $n$ bits are stored per symbol for the $m$ component [S1].
6. **Zero-Padding Constraint:** If the last few values in the sequence are zero, the corresponding last few bits in the encoded bit string must also be zero [S1]. This ensures no explicit padding bits are needed at the end of the stream [S1].

**Pseudocode:**

```python
import math

def bise_encode(symbols, alphabet_size):
    """
    Encodes a sequence of symbols using Bounded Integer Sequence Encoding (BISE).
    symbols: list of integers in [0, alphabet_size - 1]
    alphabet_size: int, N
    Returns: bytes object representing the bit string
    """
    S = len(symbols)
    if S == 0:
        return b''

    # Determine best encoding scheme
    best_bits = float('inf')
    best_scheme = None
    best_n = None

    for n in range(1, 9): # n up to 8 covers up to 256 symbols
        # Check Binary
        if alphabet_size <= (2**n - 1):
            bits = n * S
            if bits < best_bits:
                best_bits = bits
                best_scheme = 'binary'
                best_n = n

        # Check Trit
        if alphabet_size <= (3 * 2**n - 1):
            bits = n * S + math.ceil(8 * S / 5)
            if bits < best_bits:
                best_bits = bits
                best_scheme = 'trit'
                best_n = n

        # Check Quint
        if alphabet_size <= (5 * 2**n - 1):
            bits = n * S + math.ceil(7 * S / 3)
            if bits < best_bits:
                best_bits = bits
                best_scheme = 'quint'
                best_n = n

    # Encode based on selected scheme
    bit_buffer = []

    if best_scheme == 'binary':
        for sym in symbols:
            bit_buffer.append(format(sym, f'0{best_n}b'))

    elif best_scheme == 'trit':
        # Pack n bits per symbol for the m component
        for sym in symbols:
            m = sym % (2**best_n)
            bit_buffer.append(format(m, f'0{best_n}b'))
        # Pack trit overhead: ceil(8S/5) bits
        # Group symbols into sets of 5, encode trit t = sym // (2^n)
        for i in range(0, S, 5):
            group = symbols[i:i+5]
            trits = [sym // (2**best_n) for sym in group]
            # Pack 5 trits into 8 bits
            trit_val = 0
            for t in trits:
                trit_val = (trit_val << 2) | t
            # Pad remaining trits in the last group to 0 if S is not a multiple of 5
            for _ in range(5 - len(group)):
                trit_val <<= 2
            bit_buffer.append(format(trit_val, '08b'))

    elif best_scheme == 'quint':
        # Pack n bits per symbol for the m component
        for sym in symbols:
            m = sym % (2**best_n)
            bit_buffer.append(format(m, f'0{best_n}b'))
        # Pack quint overhead: ceil(7S/3) bits
        # Group symbols into sets of 3, encode quint q = sym // (2^n)
        for i in range(0, S, 3):
            group = symbols[i:i+3]
            quints = [sym // (2**best_n) for sym in group]
            # Pack 3 quints into 7 bits
            quint_val = 0
            for q in quints:
                quint_val = (quint_val << 3) | q
            # Pad remaining quints in the last group to 0 if S is not a multiple of 3
            for _ in range(3 - len(group)):
                quint_val <<= 3
            bit_buffer.append(format(quint_val, '07b'))

    # Join bits and apply zero-padding constraint
    bit_string = ''.join(bit_buffer)
    # Remove trailing zeros as per constraint to avoid padding
    bit_string = bit_string.rstrip('0')
    # Convert to bytes (pad to byte boundary for output)
    if len(bit_string) % 8 != 0:
        bit_string = bit_string.ljust(len(bit_string) + (8 - len(bit_string) % 8), '0')
    return bytes(int(bit_string[i:i+8], 2) for i in range(0, len(bit_string), 8))
```

**Edge Cases and Pitfalls:**
* **Non-multiple of 3 or 5:** When $S$ is not a multiple of 3 (for quint) or 5 (for trit), the "last few bits" constraint must be carefully managed to avoid wasting storage [S1]. The encoder must ensure that any unused bits at the end of the sequence are zero if the corresponding symbols are zero [S1].
* **Precision:** The formulas use ceiling functions for the overhead bits [S1]. Incorrect rounding can lead to storage miscalculations [S1].
* **Alphabet Size Limits:** BISE supports alphabets up to 256 symbols [S1]. For larger alphabets, other methods are required [S1].

## Operating characteristics
* **Time Complexity:** Encoding requires determining the optimal $n$ and scheme, which is $O(1)$ for fixed alphabet sizes, followed by $O(S)$ for packing the symbols [S1].
* **Memory Complexity:** $O(S)$ bits for the output [S1].
* **Performance:** BISE is significantly more efficient than simple binary encoding for alphabet sizes that are not powers of two [S1]. For example, a 5-symbol alphabet (quint) uses 7 bits for 3 symbols (2.33 bits/symbol) instead of 6 bits (2 bits/symbol) or 9 bits (3 bits/symbol) [S1].
* **Strengths:** High compression efficiency for small, arbitrary alphabets; no padding overhead [S1].
* **Limitations:** Complex bit-packing logic for trits and quints; only supports alphabets up to 256 symbols [S1].

## Background
BISE was developed as part of the Adaptive Scalable Texture Compression (ASTC) format by ARM [S1]. It was designed to allow fine-grained control over compression quality and size by efficiently encoding quantized color and weight values per texel [S1]. The technique leverages the mathematical properties of small prime numbers (3 and 5) to pack symbols into bit boundaries with minimal waste [S1].
