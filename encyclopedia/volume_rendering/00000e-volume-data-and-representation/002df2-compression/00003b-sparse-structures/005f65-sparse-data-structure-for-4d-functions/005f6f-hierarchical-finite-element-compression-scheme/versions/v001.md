# Hierarchical Finite Element Compression Scheme

Also called: Sparse Data Structure Compression, Uniform 4D Compression Scheme

## Overview
The Hierarchical Finite Element Compression Scheme is a uniform 4D compression method that replaces traditional quantization and encoding steps with a dedicated sparse data structure, enabling efficient random access for hyperslice reconstruction of large multidimensional scalar fields [S1, unofficial]. It sets itself apart from wavelet-based approaches by constructing non-overlapping basis functions within a subvolume, which significantly reduces the computational cost of the reconstruction algorithm [S1, unofficial]. It builds on [Sparse Data Structure for 4D Functions](17886-sparse-data-structure-for-4d-functions.md) by providing the specific mathematical foundation and compression logic required to populate that structure.

## How it works
The method approximates a scalar function $f: [a, b] \to \mathbb{R}$ using piecewise quadratic polynomials over a uniform grid, organized hierarchically to allow linear-time compression and reconstruction.

**Inputs and Outputs:**
- **Input:** A multidimensional scalar field defined on a domain $[a, b]^d$ (where $d=4$ for the primary application).
- **Output:** A compressed representation stored in the sparse data structure, consisting of hierarchical coefficients.

**Data Structures:**
The core data structure is a hierarchical basis representation. For a single dimension, the domain is subdivided into $N = 2^n$ subintervals. The approximation space $\mathcal{V}_h$ has dimension $2N + 1$. The coefficients are stored in a flat array or tree structure corresponding to the hierarchical basis functions $L_i(x)$.

**Definitions:**
- Let $N = 2^n$ be the number of subintervals per dimension, where $n$ is an integer controlling the discretization resolution [S1, unofficial].
- The domain interval $[a, b]$ is subdivided into $N$ regularly spaced subintervals $I_i = [x_i, x_{i+1}]$ for $0 \le i < N$, with uniform step size $h = x_{i+1} - x_i$ [S1, unofficial].
- A scalar function $f$ is approximated by $f_h$ such that on each subinterval $I_i$, $f_h|_{I_i} \in \mathcal{P}_2$, where $\mathcal{P}_2$ is the vector space spanned by polynomials of degree at most 2 [S1, unofficial].
- The vector space $\mathcal{V}_h$ has dimension $2N + 1$, corresponding to the $(N+1)$ grid points $x_i$ and additional degrees of freedom (specifically, values at midpoints or similar internal points, though the exact geometric interpretation of the $2N+1$ basis is implied by the quadratic nature) [S1, unofficial].

**Algorithm Steps:**

1.  **Discretization:** Subdivide the 1D domain $[a, b]$ into $N = 2^n$ uniform subintervals $I_i = [x_i, x_{i+1}]$ with step size $h = (b-a)/N$ [S1, unofficial].
2.  **Basis Construction:** Construct the hierarchical basis $\{L_i(x)\}_{i=0}^{2N}$ for the space $\mathcal{V}_h$. The basis functions are designed to be non-overlapping within a subvolume to minimize reconstruction cost [S1, unofficial]. The approximation is given by:
    $$ f_h(x) = \sum_{i=0}^{2N} c_i L_i(x) $$
    where $c_i$ are the coefficients [S1, unofficial].
3.  **Hierarchical Refinement:** The basis is constructed by considering multiple levels of refinement. Let $h_j = 2^{n-j} h$ for $0 \le j \le n$. The intervals at level $j$ are $I^j_i = [x^j_i, x^j_{i+1}]$ for $0 \le i \le 2^j - 1$ [S1, unofficial]. The coefficients $c_i$ are determined such that they represent the detail between levels, similar to multiresolution analysis but using finite element bases [S1, unofficial].
4.  **Compression (Coefficient Calculation):** Compute the coefficients $c_i$ by projecting the input function values onto the basis functions. This step replaces quantization and encoding [S1, unofficial]. The coefficients satisfy specific properties derived from the Kronecker delta relationship of the basis functions (Equation 6 in source), ensuring that each coefficient corresponds to a specific local feature [S1, unofficial].
5.  **Storage:** Store the non-zero or significant coefficients in the sparse data structure defined by the parent article. The tensor product of 1D transformations allows the 4D compression to be performed efficiently [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Precision:** The linear complexity relies on the sparsity of the coefficients. If the function is not smooth, many coefficients may be significant, reducing compression efficiency [S1, unofficial].
- **Boundary Conditions:** The uniform subdivision assumes the domain is $[a, b]$. Handling boundaries requires care to ensure the basis functions are well-defined at $x_0$ and $x_N$ [S1, unofficial].
- **Degenerate Input:** If $n=0$, $N=1$, the structure degenerates to a single interval. The algorithm should handle this base case explicitly [S1, unofficial].

## Operating characteristics
- **Time Complexity:** The compression and reconstruction algorithms operate with linear time complexity $O(N)$ with respect to the number of subintervals [S1, unofficial].
- **Memory Complexity:** The memory usage is proportional to the number of non-zero coefficients. Due to the sparse data structure, it is significantly less than storing the full grid, especially for smooth functions where many coefficients are negligible [S1, unofficial].
- **Strengths:**
    - Linear complexity for both compression and reconstruction [S1, unofficial].
    - Non-overlapping basis functions reduce reconstruction cost compared to wavelets [S1, unofficial].
    - Locality allows for efficient parallelization [S1, unofficial].
    - No quantization or encoding steps needed, simplifying the pipeline [S1, unofficial].
- **Limitations:**
    - Requires a uniform grid structure, which may not be optimal for all data distributions.
    - The basis functions are specific to quadratic polynomials, limiting flexibility for higher-order approximations without modification [S1, unofficial].
- **When to Use:** Use this method when visualizing large 4D scalar fields (e.g., time-varying 3D data) and efficient random access for slice extraction is critical. It is particularly suitable when the data is smooth and can be well-approximated by piecewise quadratic functions.
- **When Not to Use:** Avoid if the data has sharp discontinuities or high-frequency content that requires many coefficients to represent accurately, as this will reduce compression efficiency. Also, if adaptive grid resolution is needed, this uniform scheme may not be optimal.

## Background
The hierarchical representation concept originates from [17] (cited in [S1, unofficial]), which shares similarities with wavelets and multiresolution analysis but prioritizes non-overlapping basis functions for reconstruction efficiency. The specific compression scheme described in [S1, unofficial] stays within the framework of multiresolution analysis and uses tensor products of 1D transformations to handle the 4D case. The main motivation for avoiding wavelets was to build non-overlapping basis functions within a subvolume, reducing the computational cost of the reconstruction algorithm [S1, unofficial].
