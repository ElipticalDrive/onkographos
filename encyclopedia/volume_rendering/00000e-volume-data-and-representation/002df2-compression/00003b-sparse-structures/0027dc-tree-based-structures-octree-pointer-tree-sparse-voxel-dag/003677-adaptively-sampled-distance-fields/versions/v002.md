# Adaptively Sampled Distance Fields

Also called: ASDF

## Overview
Adaptively Sampled Distance Fields (ASDF) are a tree-based compression method for representing 3D shapes and vector outlines by encoding a signed distance field (SDF) rather than binary occupancy [S1, unofficial]. Unlike traditional binary-valued trees that require excessive refinement to capture smooth boundaries, ASDF exploits distance field smoothness and enforces sign preservation during simplification to accurately encode the zero set while achieving high compression [S1, unofficial]. It is particularly suited for applications requiring resolution-independent antialiasing and magnification of complex vector outlines [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A target shape defined by a signed distance field (SDF) sampled on a regular grid, or a parametric vector representation converted to an SDF [S1, unofficial].
*   **Output:** A compressed random-access tree structure representing the SDF, optimized for spatial coherence [S1, unofficial].

**Data Structures:**
The method uses a compressed tree structure (specifically a random-access compressed tree, as detailed in the parent article [4139-tree-based-structures-octree-pointer-tree-sparse-voxel-dag.md]) [S1, unofficial]. The tree nodes store quantized distance values, and compression utilizes a codebook (either specialized or universal) to encode the residuals or coefficients of the tree nodes [S1, unofficial].

**Algorithm Steps:**
1.  **Initialization:** Construct or load the signed distance field for the target shape at a specified resolution (e.g., $10252$) [S1, unofficial].
2.  **Tree Construction:** Build the hierarchical tree structure over the SDF domain via recursive subdivision [G].
3.  **Adaptive Simplification with Sign Preservation:** Apply tree simplification (pruning/coarsening) to reduce the number of nodes [G]. Let $\tau$ be the approximation tolerance; the method allows a larger $\tau$ but restricts simplification to preserve the sign of the approximated data $a_l$ everywhere [S1, unofficial]. This guarantees that the zero isosurface (the shape boundary) is preserved exactly in topology [S1, unofficial].
4.  **Compression:** Encode the simplified tree using a codebook (universal or specialized) to generate the final compressed bitstream [S1, unofficial].

**Formulas:**
*   **Sign Preservation Condition:** For all points $x$ in the domain, $\text{sign}(a_l) = \text{sign}(d(x))$, where $d(x)$ is the original distance and $a_l$ is the approximated data [S1, unofficial].
*   **Accuracy Metric:** Geometric PSNR is calculated by extracting the zero isocurve from the compressed SDF and measuring the RMS distance between points on this curve and the original curve [S1, unofficial].

**Parameters:**
*   **Tolerance ($\tau$):** The approximation tolerance is set larger than in standard binary tree compression to allow more aggressive pruning, relying on the sign preservation constraint to maintain shape fidelity [S1, unofficial].
*   **Resolution:** Examples cite input resolutions such as $10252$ (noted as "10252" in source text) [S1, unofficial].
*   **Accuracy:** Geometric PSNR accuracy is $82$ dB [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Zero Set Accuracy:** The primary risk is violating the sign preservation constraint, which would shift the shape boundary. The algorithm must strictly enforce $\text{sign}(a_l) = \text{sign}(d(x))$ [S1, unofficial].

## Operating characteristics
*   **Compression Ratio:** ASDF achieves significantly higher compression ratios than traditional binary-valued trees for smooth shapes because it exploits the smoothness of the distance field [S1, unofficial]. For example, a vector shape represented as an SDF in a compressed tree was $7.8$ KB, compared to $3.2$ KB for the original parametric representation and $131$ KB for a binary image at the same resolution [S1, unofficial].
*   **Accuracy:** The method provides high geometric accuracy, with reported PSNR of $82$ dB for the zero isocurve extraction, implying errors are not visible at resolutions below $10\text{K}^2$ pixels [S1, unofficial].
*   **Rendering Benefits:** The distance field representation enables high-quality antialiasing and resolution-independent magnification, which are not possible with traditional binary images [S1, unofficial].
*   **Limitations:** Traditional binary-valued trees are much larger because they cannot exploit the smoothness of the vector outline and require more refinement [S1, unofficial].

## Background
Adaptively Sampled Distance Fields were introduced by Fedkiw, Perrin, Rausch, and James in 2000 [S1, unofficial]. The method was developed to address the limitations of binary-valued tree representations for complex shapes, which require excessive refinement to capture smooth boundaries. By using a signed distance field and enforcing sign preservation during tree simplification, ASDF provides a compact and accurate representation for vector outlines and 3D shapes [S1, unofficial].
