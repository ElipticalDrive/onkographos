# BasicDAGUncompressedColors
## Overview
BasicDAGUncompressedColors stores uncompressed color data for DAG leaves in a flat array, indexed by leaf count [S1, unofficial]. It provides direct color access via a simple index lookup, contrasting with sibling variants that resolve colors during traversal or use separate color trees [S1, unofficial].
## Shared principles
The family stores uncompressed color data for DAG leaves in a flat array indexed by leaf count [S1, unofficial]. Each leaf is represented by a `ColorLeaf` struct containing a `StaticArray<uint32> colors`, where each element stores a color value [S1, unofficial].
## Subtopics

### BasicDAGUncompressedColors
Stores uncompressed color data for DAG leaves in a flat array, indexed by leaf count [S1, unofficial]. The layout consists of a `ColorLeaf` struct containing a `StaticArray<uint32> colors`, where each element stores a color value [S1, unofficial]. Retrieval is performed via a function `get_color(leaveCount)` which returns an `UncompressedColor` struct wrapping the color value at index `leaveCount` in the colors array: `{ colors[leaveCount] }` [S1, unofficial].
```python
def get_color(leaveCount: int, colors: list) -> UncompressedColor:
    return UncompressedColor(colors[leaveCount])
```

### HashDAG Color Lookup
A GPU kernel implementation that retrieves the color for a pixel by traversing the DAG path and looking up the color in a separate color DAG [S1, unofficial].
**Algorithm:**
```python
def HashDAG_Color_Lookup(traceParams):
    # traceParams contains pathsSurface, colorsSurface, toolInfo, debugColors, debugColorsIndexLevel
    # 1. Calculate pixel coordinates and return if outside bounds
    # 2. Load path from pathsSurface; if null, set default color (187, 242, 250) and return
    if pathsSurface.load_path() is None:
        colorsSurface.write(default_color=(187, 242, 250))
        return
    # 3. Initialize traversal: level=0, nodeIndex=root, colorNodeIndex=0, colorLeaf=default
    level = 0
    nodeIndex = root
    colorNodeIndex = 0
    colorLeaf = default
    # 4. Loop while level < leaf_level
    while level < leaf_level:
        # 5. Increment level, get node and childMask, determine child index from path
        level += 1
        node, childMask = get_node_and_child_mask(nodeIndex)
        child_index = get_child_index_from_path(path)
        # 6. If child not in childMask, set magenta color (0xFF00FF) and return
        if child_index not in childMask:
            colorsSurface.write(color=(0xFF00FF))
            return
        # 7. If level-1 < color_tree_levels, update colorNodeIndex and get colorLeaf if at final color tree level
        if level - 1 < color_tree_levels:
            colorNodeIndex = update_color_node_index(colorNodeIndex)
            if level - 1 == color_tree_levels - 1:
                colorLeaf = get_color_leaf(colorNodeIndex)
        # 8. Handle debug colors: Index, Position, ColorTree, ColorBits, MinColor, MaxColor, Weight
        if debugColors:
            handle_debug_colors(debugColors, debugColorsIndexLevel)
        # 9. If at leaf level, count preceding leaves to determine nof_leaves
        if level == leaf_level:
            nof_leaves = count_preceding_leaves()
        # 10. Update nodeIndex to child
        nodeIndex = child_index
    # 11. If colorLeaf invalid or index out of range, set invalid color and return
    if not colorLeaf.is_valid() or nof_leaves >= len(colorLeaf):
        colorsSurface.write(invalid_color)
        return
    # 12. Get compressed color from colorLeaf using nof_leaves
    compressed_color = colorLeaf.get_compressed_color(nof_leaves)
    # 13. Extract final color based on debug mode or default color
    final_color = extract_final_color(compressed_color, debugColors)
    # 14. Write color to colorsSurface
    colorsSurface.write(final_color)
```
