# BasicDAGColorsBase

Also called: BaseDAGColors

## Overview
BasicDAGColorsBase is the foundational data structure for managing color information within the BasicDAG volume rendering framework. It solves the problem of efficiently storing and accessing leaf node color data by decoupling the storage of leaf counts from the main geometry array. This separation allows for independent access to leaf metadata without requiring the re-implementation of complex storage logic, distinguishing it from siblings that either store colors inline or use more complex mixture models.

## Shared principles
The core mechanism of this family is the decoupling of leaf count storage from the primary geometry data. This is achieved through an enclosed array structure that maintains metadata about the number of leaves at various hierarchy levels.

The data layout consists of two primary components:
1.  `topLevels`: A `uint32` value storing the total number of top levels in the DAG hierarchy.
2.  `enclosedLeaves`: A `StaticArray<EnclosedLeavesType>` that stores the leaf counts for upper-level nodes.

This structure ensures that leaf count information is accessible independently of the voxel geometry indices, facilitating efficient traversal and memory management for color data.

## Subtopics

### [BasicDAGColorErrors](6743-basicdagcolorerrors.md)
Computes a binary error flag by comparing compressed and uncompressed color representations for adaptive quality control. It builds on [BasicDAGColorsBase](6742-basicdagcolorsbase.md) by utilizing the shared data layout to perform error checks without re-implementing storage logic.

### [BasicDAGUncompressedColors](6741-basicdaguncompressedcolors.md)
Stores color data in an uncompressed format. Choose this when memory bandwidth is not a constraint and maximum fidelity is required.

### [Mixture Graph](11065-mixture-graph.md)
Uses a mixture model for color representation. Choose this for complex material blending or when color data exhibits high variance that simple compression cannot handle efficiently.

## Background
The BasicDAGColorsBase structure originates from the HashDAG project, an unofficial implementation of sparse voxel DAGs for volume rendering. It was developed to optimize the handling of color data in large-scale volumetric datasets by separating metadata from geometry.
