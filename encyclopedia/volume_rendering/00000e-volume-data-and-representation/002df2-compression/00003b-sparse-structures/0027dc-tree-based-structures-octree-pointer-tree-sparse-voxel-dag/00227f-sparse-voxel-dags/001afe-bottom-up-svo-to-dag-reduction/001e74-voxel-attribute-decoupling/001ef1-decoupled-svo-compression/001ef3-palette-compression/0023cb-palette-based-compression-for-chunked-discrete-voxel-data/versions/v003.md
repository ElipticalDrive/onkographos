# Palette-based compression for chunked discrete voxel data

Also called: BlockStorage, Indices Bit-Compression, Minecraft 1.13 compression, Palette Compression via Bit-Packing, Variable-length-integer buffer for indices

## Overview
This method compresses discrete voxel volume chunks by decoupling voxel identity (block type) from usage (indices), storing types in a sparse palette and indices in a variable-bit-length buffer [S2, unofficial]. It differs from fixed-size array storage by reducing memory footprint to 1–2 bits per voxel in low-entropy regions (e.g., air/stone) while supporting thousands of block types, a technique famously implemented in Minecraft 1.13 [S2, unofficial]. It builds on [Palette Compression](1873-palette-compression.md) by implementing the specific bit-packing and dynamic palette management required for chunked discrete data.

## How it works
**Inputs:** A voxel chunk of size $N = \text{CHUNK\_SIZE}^3$ (typically $32^3$ or $64^3$) [S2, unofficial].
**Outputs:** A compressed representation consisting of a `Palette` array and a `BitBuffer` of indices.

### Data Structures
1.  **PaletteEntry**: A struct containing:
    *   `type`: The discrete voxel/block type (e.g., `ushort` or `BlockType`) [S1][S2, unofficial].
    *   `refcount`: An integer tracking how many voxels in the current chunk reference this entry (default 0) [S1][S2, unofficial].
2.  **BlockStorage**: The core container for a chunk, containing:
    *   `size`: Total number of voxels ($N$) [S2, unofficial].
    *   `palette`: An array of `PaletteEntry` objects, sized to $2^{\text{indicesLength}}$ [S2, unofficial].
    *   `paletteCount`: The number of currently active (non-zero refcount) entries in the palette [S2, unofficial].
    *   `indicesLength`: The bit-width of each index in the buffer. Starts at 1. Grows/shrinks exponentially [S2, unofficial].
    *   `data`: A `BitBuffer` storing the indices. Size is $N \times \text{indicesLength}$ bits [S2, unofficial].
3.  **BitBuffer**: An interface for arbitrary bit-range access:
    *   `set(bitIndex, bitLength, bits)`: Writes `bits` into the buffer starting at `bitIndex` [S2, unofficial].
    *   `get(bitIndex, bitLength)`: Reads `bitLength` bits starting at `bitIndex` [S2, unofficial].

### Algorithm Steps

#### 1. Initialization
Initialize `BlockStorage` with `size` voxels. Set `indicesLength = 1`, `paletteCount = 0`. Allocate `palette` of size $2^1$ and `data` of size `size * 1` bits [S2, unofficial].

#### 2. Reading a Voxel (`getBlock`)
Given a voxel index $i$:
1.  Read the palette index $p$ from `data` at bit offset $i \times \text{indicesLength}$ with length `indicesLength` [S2, unofficial].
2.  Return `palette[p].type` [S2, unofficial].
*Complexity: O(1)* [S2, unofficial].

#### 3. Writing a Voxel (`setBlock`)
Given voxel index $i$ and new `type`:
1.  Read current palette index $p_{old}$ from `data` at $i \times \text{indicesLength}$ with length `indicesLength` [S2, unofficial].
2.  Decrement `palette[p_old].refcount` [S2, unofficial].
3.  Search `palette` for an existing entry $p_{new}$ where `palette[p_new].type == type` [S2, unofficial].
    *   **If found:**
        1.  Write $p_{new}$ to `data` at $i \times \text{indicesLength}$ with length `indicesLength` [S2, unofficial].
        2.  Increment `palette[p_new].refcount` [S2, unofficial].
        3.  Return.
    *   **If not found:**
        1.  If `palette[p_old].refcount == 0`:
            *   Overwrite `palette[p_old].type` with `type` [S2, unofficial].
            *   Set `palette[p_old].refcount = 1` [S2, unofficial].
            *   Write $p_{old}$ to `data` at $i \times \text{indicesLength}$ with length `indicesLength` [S2, unofficial].
            *   Return.
        2.  If `palette[p_old].refcount > 0`:
            *   Call `newPaletteEntry()` to get a free slot $p_{free}$ [S2, unofficial].
            *   Set `palette[p_free].type = type` and `palette[p_free].refcount = 1` [S2, unofficial].
            *   Write $p_{free}$ to `data` at $i \times \text{indicesLength}$ with length `indicesLength` [S2, unofficial].
            *   Increment `paletteCount` [S2, unofficial].

#### 4. Managing Palette Entries (`newPaletteEntry`)
1.  Find the first index $k$ in `palette` where `palette[k]` is null or `palette[k].refcount == 0` [S2, unofficial].
2.  If found, return $k$ [S2, unofficial].
3.  If not found, call `growPalette()` [S2, unofficial].
4.  Recursively call `newPaletteEntry()` to find the new free slot [S2, unofficial].

#### 5. Growing the Palette (`growPalette`)
1.  Decode all indices from `data` into an integer array `indices` of size `size` [S2, unofficial].
2.  Double `indicesLength` (`indicesLength << 1`) [S2, unofficial].
3.  Allocate `newPalette` of size $2^{\text{indicesLength}}$ [S2, unofficial].
4.  Copy existing `palette` entries to `newPalette` [S2, unofficial].
5.  Allocate new `BitBuffer` of size `size * indicesLength` bits [S2, unofficial].
6.  Encode all indices from `indices` array into the new `data` buffer [S2, unofficial].
7.  Update `palette` to `newPalette` [S2, unofficial].

#### 6. Shrinking the Palette (`fitPalette`)
Called when `paletteCount` drops significantly.
1.  Iterate `palette`, setting entries with `refcount == 0` to null and decrementing `paletteCount` [S2, unofficial].
2.  If `paletteCount` is not less than half of its closest power of two, return (do not shrink) [S2, unofficial].
3.  Decode all indices from `data` into `indices` [S2, unofficial].
4.  Halve `indicesLength` (`indicesLength >> 1`) [S2, unofficial].
5.  Allocate `newPalette` of size $2^{\text{indicesLength}}$ [S2, unofficial].
6.  Iterate old `palette`, copying non-null entries to `newPalette` at `paletteCounter` [S2, unofficial].
7.  For each moved entry, re-encode indices: if old index matches current old palette index, update `indices[di]` to `paletteCounter` and increment found count `fc` until `fc` equals entry's refcount [S2, unofficial].
8.  Allocate new `BitBuffer` of size `size * indicesLength` bits [S2, unofficial].
9.  Encode all indices from `indices` array into new `data` buffer [S2, unofficial].
10. Update `palette` to `newPalette` [S2, unofficial].

### Bit-Packing Strategies
When `indexbits` (calculated as $\lceil \log_2(\text{palettesize}) \rceil$) does not divide 64 evenly, three packing options exist [S1]:
1.  **Round Up:** Round `indexbits` to the nearest power of two. Simple but wastes bits (e.g., 15 wasted bits for 3-bit size) [S1].
2.  **Aligned Per-Cell:** Pack as many indices as fit in each 64-bit cell, zeroing remaining MSBs. Minimal waste and no performance penalty for access [S1].
3.  **Unaligned Cross-Cell:** Pack bits tightly across cell boundaries. Best space efficiency but high CPU cost due to complex bit-offset/mask calculations [S1].
*Recommendation:* Aligned Per-Cell is preferred for runtime performance [S1].

### Pseudocode
```python
class PaletteEntry:
    type: int  # Voxel type ID
    refcount: int = 0

class BlockStorage:
    def __init__(self, size: int):
        self.size = size
        self.indicesLength = 1
        self.paletteCount = 0
        self.palette = [PaletteEntry() for _ in range(2 ** self.indicesLength)]
        self.data = BitBuffer(size * self.indicesLength)

    def get_block(self, index: int) -> int:
        palette_index = self.data.get(index * self.indicesLength, self.indicesLength)
        return self.palette[palette_index].type

    def set_block(self, index: int, type: int):
        # 1. Get current entry and decrement refcount
        palette_index = self.data.get(index * self.indicesLength, self.indicesLength)
        current_entry = self.palette[palette_index]
        current_entry.refcount -= 1

        # 2. Search for existing type
        replace_index = -1
        for i, entry in enumerate(self.palette):
            if entry.type == type:
                replace_index = i
                break
        
        if replace_index != -1:
            # Found existing type
            self.data.set(index * self.indicesLength, self.indicesLength, replace_index)
            self.palette[replace_index].refcount += 1
            return

        # 3. Type not found
        if current_entry.refcount == 0:
            # Reuse the empty slot we just decremented
            current_entry.type = type
            current_entry.refcount = 1
            self.data.set(index * self.indicesLength, self.indicesLength, palette_index)
            return

        # Need a new entry
        new_entry_index = self.new_palette_entry()
        self.palette[new_entry_index] = PaletteEntry(type=type, refcount=1)
        self.data.set(index * self.indicesLength, self.indicesLength, new_entry_index)
        self.paletteCount += 1

    def new_palette_entry(self) -> int:
        # Find first free slot
        for i, entry in enumerate(self.palette):
            if entry.refcount == 0:
                return i
        
        # No free slot, grow
        self.grow_palette()
        # Recursively find the new free slot
        return self.new_palette_entry()

    def grow_palette(self):
        # Decode all indices
        indices = []
        for i in range(self.size):
            indices.append(self.data.get(i * self.indicesLength, self.indicesLength))
        
        # Double indices length
        self.indicesLength = self.indicesLength << 1
        
        # Grow palette
        new_palette = [PaletteEntry() for _ in range(2 ** self.indicesLength)]
        for i in range(len(self.palette)):
            new_palette[i] = self.palette[i]
        self.palette = new_palette
        
        # Re-encode indices (simplified: just write back old indices with new bit width)
        # Note: In a real implementation, indices might need remapping if palette entries were compacted,
        # but growPalette typically just expands capacity. 
        # The source [S2, unofficial] implies re-encoding into the new buffer.
        self.data = BitBuffer(self.size * self.indicesLength)
        for i in range(self.size):
            self.data.set(i * self.indicesLength, self.indicesLength, indices[i])

    def fit_palette(self):
        # Clean up zero refcount entries
        for i, entry in enumerate(self.palette):
            if entry.refcount == 0:
                self.palette[i] = PaletteEntry() # Null out
                self.paletteCount -= 1
        
        # Check if we should shrink
        # "half of its closest power of two" logic
        # Simplified: if paletteCount < (2^indicesLength) / 2
        if self.paletteCount >= (2 ** self.indicesLength) / 2:
            return

        # Decode indices
        indices = []
        for i in range(self.size):
            indices.append(self.data.get(i * self.indicesLength, self.indicesLength))
        
        # Halve indices length
        self.indicesLength = self.indicesLength >> 1
        
        # Create new smaller palette
        new_palette = [PaletteEntry() for _ in range(2 ** self.indicesLength)]
        palette_counter = 0
        
        # Copy non-null entries and re-map indices
        for i, entry in enumerate(self.palette):
            if entry.refcount > 0:
                new_palette[palette_counter] = entry
                # Update indices that pointed to 'i' to point to 'palette_counter'
                for j in range(self.size):
                    if indices[j] == i:
                        indices[j] = palette_counter
                palette_counter += 1
        
        self.palette = new_palette
        self.paletteCount = palette_counter
        
        # Re-encode
        self.data = BitBuffer(self.size * self.indicesLength)
        for i in range(self.size):
            self.data.set(i * self.indicesLength, self.indicesLength, indices[i])

class BitBuffer:
    def __init__(self, size_bits: int):
        self.size_bits = size_bits
        self.cells = (size_bits + 63) // 64
        self.data = [0] * self.cells

    def get(self, bit_index: int, bit_length: int) -> int:
        # Extract bit_length bits starting at bit_index
        # Implementation depends on cell alignment
        # [G] Standard bit extraction logic:
        start_cell = bit_index // 64
        offset = bit_index % 64
        val = 0
        for i in range(bit_length):
            bit_pos = offset + i
            cell_idx = start_cell + (bit_pos // 64)
            bit_in_cell = bit_pos % 64
            if cell_idx < len(self.data):
                if self.data[cell_idx] & (1 << bit_in_cell):
                    val |= (1 << i)
        return val

    def set(self, bit_index: int, bit_length: int, value: int):
        # Write bit_length bits from value starting at bit_index
        # [G] Standard bit insertion logic:
        for i in range(bit_length):
            bit_pos = bit_index + i
            cell_idx = bit_pos // 64
            bit_in_cell = bit_pos % 64
            if cell_idx < len(self.data):
                if (value >> i) & 1:
                    self.data[cell_idx] |= (1 << bit_in_cell)
                else:
                    self.data[cell_idx] &= ~(1 << bit_in_cell)
```

## Operating characteristics
*   **Time Complexity:** Reading is O(1) [S2, unofficial]. Writing is O(P) where P is palette size due to linear search [S2, unofficial]. Palette growth/shrinkage is O(N) where N is chunk size [S2, unofficial].
*   **Memory Complexity:** Memory usage scales with $N \times \lceil \log_2(P) \rceil$ bits plus palette overhead. For low-entropy regions, this approaches 1 bit per voxel [S2, unofficial].
*   **Performance:** Best suited for "earth-like" scenes with large uniform areas (air/stone) [S1]. Performance degrades if chunks are too large (>64³) or if entropy is extremely high (random noise) [S2, unofficial].
*   **Strengths:** Massive memory reduction for sparse data; supports thousands of block types; lossless [S2, unofficial].
*   **Limitations:** Write operations are slower than direct array access due to palette management; non-power-of-two bit sizes require careful handling [S1].

## Background
This technique was introduced in Minecraft 1.13 (the "Village & Pillage" update) as a lossless compression method for voxel data [S2, unofficial]. It is based on the concept of color palettes used in formats like GIF [S2, unofficial]. The method separates block types from their indices, allowing for efficient storage of discrete voxel data [S1].
