# Compact SSVDAG Encoding

Also called: Frequency-based pointer compaction, Leaf grouping, Memory-aligned encoding

## Overview
Compact SSVDAG Encoding is a GPU-friendly memory layout for Symmetry-aware Sparse Voxel Directed Acyclic Graphs that minimizes pointer overhead while enabling fast, decompression-free ray tracing [S1, unofficial]. It distinguishes itself from standard SVDAGs by combining leaf grouping, frequency-based pointer compaction, and half-word memory alignment to reduce the memory footprint of high-resolution scenes [S1, unofficial]. The technique relies on highly skewed reference distributions, where in a 64K³ Powerplant dataset, the most common 10% of nodes account for nearly 90% of pointers at level 14 and nearly 50% at level 11 [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A constructed SVDAG (typically from bottom-up construction using $2^3$ leaf matching) [S1, unofficial].
*   **Output:** A compact binary representation consisting of an indexing structure, an inner node array, and a leaf node array [S1, unofficial].

**Data Structures:**
1.  **Indexing Structure:**
    *   `max_level`: 32-bit integer, the maximum depth $L$ of the tree [S1, unofficial].
    *   `level_offsets`: Array of three 32-bit integers. Each offset points to the start of a specific level's inner node array within the inner level array [S1, unofficial].
2.  **Inner Node Array:**
    *   A contiguous array of inner nodes [S1, unofficial].
    *   Nodes are reordered by reference count (descending) before encoding [S1, unofficial].
    *   Each node is encoded as a variable-length sequence of 16-bit half-words [S1, unofficial].
3.  **Leaf Node Array:**
    *   A contiguous array of leaf nodes (bricks) [S1, unofficial].
    *   Each leaf is fixed at 64 bits (8 bytes) [S1, unofficial].

**Inner Node Layout:**
Each inner node begins with a 16-bit header containing eight 2-bit tags, one for each of the 8 potential children [S1, unofficial].
*   **Tag 00 (Null):** The child is not stored [S1, unofficial]. No pointer data follows [S1, unofficial].
*   **Tag 01 (16-bit Child):** Followed by a 16-bit child pointer [S1, unofficial].
    *   Bits [15:13]: 3-bit transformation code [S1, unofficial].
    *   Bits [12:0]: 13-bit offset (in level-words) from the start of the next level's array [S1, unofficial].
*   **Tag 10 (32-bit Child):** Followed by a 32-bit child pointer [S1, unofficial].
    *   Bits [31:29]: 3-bit transformation code [S1, unofficial].
    *   Bits [28:0]: Lowest 29 bits of the offset [S1, unofficial].
*   **Tag 11 (32-bit Child with MSB):** Followed by a 32-bit child pointer [S1, unofficial].
    *   Bits [31:29]: 3-bit transformation code [S1, unofficial].
    *   Bit [28]: Highest bit of the offset (MSB) [S1, unofficial].
    *   Bits [27:0]: Lowest 28 bits of the offset [S1, unofficial].
    *   *Note:* The source states "highest bit of offset in rightmost header bit" for tags 10/11 [S1, unofficial]. This implies the header tag itself indicates the MSB: Tag 10 has MSB=0 in the header, Tag 11 has MSB=1 in the header [S1, unofficial]. The 32-bit payload contains the remaining 29 bits [S1, unofficial].

**Level-Word Size:**
*   For inner levels: 1 level-word = 2 bytes (16 bits) [S1, unofficial].
*   For leaf level: 1 level-word = 8 bytes (64 bits) [S1, unofficial].

**Algorithm Steps:**
1.  **Leaf Grouping:** Coarsen the construction graph by one level [S1, unofficial]. Instead of storing $2^3$ leaves as individual nodes, group $4^3$ grids into simple grids (bricks) stored in a single array [S1, unofficial]. Each brick occupies 64 bits [S1, unofficial]. This avoids new matching passes; it operates on the graph from the bottom-up construction [S1, unofficial].
2.  **Frequency Analysis:** Count the reference count for every node at each level in the DAG [S1, unofficial].
3.  **Reordering:** Sort the nodes at each level in descending order of their reference counts [S1, unofficial]. Most referenced nodes appear first in the level's array [S1, unofficial].
4.  **Offset Calculation:** Replace absolute pointers with offsets from the beginning of the respective level's array [S1, unofficial]. Calculate the offset in level-words [S1, unofficial].
5.  **Pointer Compaction:** Determine the number of bits required for each offset based on its magnitude and the available bit slots in the encoding format (16-bit or 32-bit child pointers) [S1, unofficial]. Assign the smallest valid tag (01, 10, or 11) that can represent the offset [S1, unofficial].
6.  **Encoding:** Write the 16-bit header with the 2-bit tags for each of the 8 children [S1, unofficial]. Write the child pointer data (transformation + offset) immediately after the header for each non-null child [S1, unofficial]. Pack the resulting bytes into 16-bit half-words for memory alignment [S1, unofficial].
7.  **Indexing:** Construct the indexing structure with `max_level` and the starting offsets for each level in the inner node array [S1, unofficial].

**Pseudocode:**

```python
def encode_compact_ssvdag(nodes_by_level):
    """
    nodes_by_level: List of lists. nodes_by_level[l] contains node objects.
    Each node has:
      - children: list of 8 child references (or None)
      - ref_count: integer
      - transform_code: 3-bit integer (0-7)
    """
    inner_arrays = []
    leaf_array = []
    level_offsets = []

    for level_idx, level_nodes in enumerate(nodes_by_level):
        # Step 2 & 3: Frequency Analysis and Reordering
        level_nodes.sort(key=lambda n: n.ref_count, reverse=True)

        if level_idx == len(nodes_by_level) - 1:
            # Leaf Level: Encode leaves as 64-bit bricks
            for node in level_nodes:
                leaf_array.append(node.data) # 64-bit voxel data
        else:
            # Inner Level
            inner_arrays.append([])
            next_level_nodes = nodes_by_level[level_idx + 1]

            # Build a map from node ID to its new sorted index for offset calculation
            node_to_idx = {id(n): i for i, n in enumerate(next_level_nodes)}

            for node in level_nodes:
                header = 0
                child_payloads = []

                for child_idx in range(8):
                    child = node.children[child_idx]
                    if child is None:
                        # Tag 00: Null
                        header |= (0x00 << (child_idx * 2))
                    else:
                        # Calculate offset in level-words (2-byte units)
                        child_idx_in_next = node_to_idx[id(child)]
                        offset_words = child_idx_in_next

                        # Check if offset fits in 13 bits (Tag 01)
                        if offset_words < (1 << 13):
                            tag = 0x01
                            # 16-bit payload: 3-bit transform, 13-bit offset
                            payload = ((child.transform_code & 0x7) << 13) | (offset_words & 0x1FFF)
                            child_payloads.append(payload)
                        else:
                            # Use 32-bit payload (Tag 10 or 11)
                            # MSB of offset goes to header tag LSB
                            msb = (offset_words >> 28) & 0x1
                            tag = 0x02 | msb # 10 or 11
                            # Payload: 3-bit transform, 29-bit offset (lower 29 bits)
                            payload = ((child.transform_code & 0x7) << 29) | (offset_words & 0x1FFFFFF)
                            child_payloads.append(payload)

                        # Set tag in header
                        header |= (tag << (child_idx * 2))

                # Pack header and payloads into 16-bit half-words
                words = [header]
                for p in child_payloads:
                    if p < (1 << 16):
                        words.append(p)
                    else:
                        # 32-bit payload split into two 16-bit words
                        words.append(p & 0xFFFF)
                        words.append((p >> 16) & 0xFFFF)
                inner_arrays[-1].append(words)

            # Step 7: Indexing (accumulate offsets)
            level_offsets.append(sum(len(n) for n in inner_arrays[-1]))

    # Finalize indexing structure
    indexing = {
        'max_level': len(nodes_by_level) - 1,
        'level_offsets': level_offsets
    }

    return indexing, inner_arrays, leaf_array
```

**Parameters:**
*   **Encoding Basis:** 16-bit half-words [S1, unofficial].
*   **Leaf Size:** 64 bits (8 bytes) [S1, unofficial].
*   **Addressable Space:** >2 GB for inner levels, 8 GB for leaves [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Offset Overflow:** If a node's offset exceeds 29 bits (for inner) or the leaf limit, it cannot be encoded with the current scheme [S1, unofficial].
*   **Precision & Boundaries:** Offsets are measured in level-words; misinterpreting level-word size (2 bytes vs 8 bytes) will cause traversal failures [S1, unofficial].
*   **Degenerate Input:** Nodes with all null children still consume a 16-bit header word [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources [S1, unofficial].
*   **Memory Complexity:** Not given in the sources [S1, unofficial].
*   **Addressable Space:** >2 GB for inner levels, 8 GB for leaves [S1, unofficial].
*   **Performance:** Optimized for GPU ray tracing. The memory-aligned encoding simplifies decoding on GPUs [S1, unofficial].
*   **Strengths:** Low memory footprint, fast tracing, no decompression overhead [S1, unofficial].
*   **Limitations:** Addressable space limits, encoding complexity due to reordering and offset calculation [S1, unofficial].

## Background
*   **Origin:** Introduced in the paper "Symmetry-aware Sparse Voxel DAGs (SSVDAGs) for compression-domain tracing of high-resolution geometric scenes" [S1, unofficial].
*   **Development:** Builds upon the SVDAG structure [Kämpe et al. 2013] and the bottom-up construction method described in the same paper [S1, unofficial].
*   **Usage:** Used in high-resolution geometric scene compression and ray tracing [S1, unofficial].
