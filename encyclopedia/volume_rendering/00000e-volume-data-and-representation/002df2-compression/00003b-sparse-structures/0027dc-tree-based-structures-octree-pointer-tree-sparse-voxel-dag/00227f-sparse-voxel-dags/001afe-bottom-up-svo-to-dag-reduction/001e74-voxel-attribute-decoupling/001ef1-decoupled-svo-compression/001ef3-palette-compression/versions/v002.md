# Palette Compression
Also called: Block-based palette compression, Variable-length palette compression

## Overview
Palette compression is a variable-length compression scheme for the attribute array in decoupled Sparse Voxel Octrees (SVOs) that reduces memory footprint by exploiting spatial coherence through global material arrays and local palettes [S1]. It differs from fixed-width indexing by allowing the bit-width of indices to adapt to the number of unique attributes within localized blocks of the depth-first attribute array, achieving higher compression ratios for scenes with large homogeneous regions [S1].

## How it works
**Inputs and Outputs**
- **Input**: An indexed attribute array $A^e = \{m_0, \dots, m_{\Lambda-1}\}$, where each $m_i$ is an index into the global material array $M$ [S1]. $\Lambda$ equals the voxel count in the original SVO [S1].
- **Output**: An array of blocks $\{B_0, \dots, B_{\gamma-1}\}$, an array of palettes $\{P_0, \dots, P_{\rho-1}\}$, and a block directory mapping block start indices to palette indices [S1].

**Data Structures**
1. **Global Material Array ($M$)**: Stores all $\lambda$ unique attributes in the scene [S1].
2. **Block Directory**: An array of entries ordered by the starting node index of each block, enabling binary search for random access [S1]. Each entry stores the starting index and the index of the associated palette in the palette array [S1].
3. **Block ($B$)**: A contiguous sub-segment of the attribute array that stores indices into its associated palette rather than into $M$ [S1].
4. **Palette ($P$)**: An array of unique indices into $M$ required to retrieve all attributes present in its associated block [S1]. A palette can be shared by multiple blocks [S1].

**Parameters**
- $\Lambda$: Total number of entries in $A^e$ [S1].
- $\lambda$: Number of unique voxel attributes in $M$ [S1].
- $\omega$: Bit-width used for indices within a block, determined by the number of unique entries in the palette [S1].

**Algorithm Steps**
The compression uses a greedy heuristic to partition $A^e$ into blocks [S1]. The process consists of two phases [S1]:
1. **Phase 1 (Greedy Heuristic for Large Blocks)**: Iterate $\omega$ from 0 to 3 [S1]. Find the largest contiguous block $B$ within the current unassigned range that contains exactly $2^\omega$ unique material indices [S1]. Calculate the memory cost using the formula below [S1]. If the memory cost is less than the cost of storing the block without compression (i.e., $(l - k + 1) \cdot (\omega + 1)$), create the palette $P$, replace the material indices in $B$ with local indices into $P$, and recursively process the remaining unassigned data before and after $B$ [S1]. If the criterion fails, increment $\omega$ and repeat [S1]. Terminate Phase 1 if $\omega \ge 4$ (16 unique indices), as finding the largest block becomes computationally infeasible [S1].
2. **Phase 2 (Remaining Data)**: For the remaining unassigned data, consider blocks starting at the current index $m_i$ for $\omega \in \{0, \dots, 8\}$ [S1]. For each $\omega$, find the largest block $B_\omega$ starting at $m_i$ with $2^\omega$ unique indices [S1]. Calculate the memory per entry $S_\omega$ for each candidate block [S1]. Select the block with the minimal $S_\omega$ [S1]. Create the palette, replace indices, and recursively process the remainder [S1].

**Memory Formula**
The memory required for a block $B$ spanning indices $m_i$ to $m_j$ with bit-width $\omega$ is [S1]:
$$ \text{MEMORY}(\{m_i, \dots, m_j\}, \omega) = (j - i + 1) \cdot \omega + 2^\omega \cdot \lceil \log_2 \lambda \rceil + \text{size}(\text{directory entry}) $$
Where $(j - i + 1) \cdot \omega$ is the size of the block data (number of entries $\times$ bits per index) [S1]. $2^\omega \cdot \lceil \log_2 \lambda \rceil$ is the size of the palette (number of unique entries $\times$ bits per material index) [S1]. $\text{size}(\text{directory entry})$ is the overhead for the block directory entry [S1].

**Pseudocode**
```python
import math

def palette_compression(attribute_array_Ae, lambda_unique_materials, dir_entry_size_bits=32):
    """
    Compresses the indexed attribute array Ae using palette compression.
    """
    palettes = []
    directory = []

    def create_palette(block_indices_global):
        unique_indices = sorted(list(set(block_indices_global)))
        index_map = {val: i for i, val in enumerate(unique_indices)}
        local_indices = [index_map[val] for val in block_indices_global]
        return local_indices, unique_indices

    def memory_cost(start_idx, end_idx, omega):
        num_entries = end_idx - start_idx + 1
        palette_bits = (2 ** omega) * math.ceil(math.log2(lambda_unique_materials))
        block_bits = num_entries * omega
        return block_bits + palette_bits + dir_entry_size_bits

    def find_largest_block_with_unique_count(start, end, target_unique_count):
        best_len = -1
        best_start = -1
        best_end = -1
        for i in range(start, end + 1):
            unique_set = set()
            for j in range(i, end + 1):
                unique_set.add(attribute_array_Ae[j])
                if len(unique_set) == target_unique_count:
                    current_len = j - i + 1
                    if current_len > best_len:
                        best_len = current_len
                        best_start = i
                        best_end = j
                    break
                elif len(unique_set) > target_unique_count:
                    break
        if best_len > 0:
            return best_start, best_end
        return None

    def find_largest_blocks(start, end, omega):
        if start > end:
            return
        while omega < 4:
            result = find_largest_block_with_unique_count(start, end, 2 ** omega)
            if result is None:
                omega += 1
                continue
            b_start, b_end = result
            b_len = b_end - b_start + 1
            cost_compressed = memory_cost(b_start, b_end, omega)
            cost_alternative = b_len * (omega + 1)
            if cost_compressed < cost_alternative:
                block_global_indices = attribute_array_Ae[b_start : b_end + 1]
                local_indices, palette_global_indices = create_palette(block_global_indices)
                palette_idx = len(palettes)
                palettes.append(palette_global_indices)
                directory.append((b_start, palette_idx))
                for k in range(b_len):
                    attribute_array_Ae[b_start + k] = local_indices[k]
                find_largest_blocks(start, b_start - 1, omega)
                find_largest_blocks(b_end + 1, end, omega)
                return
            else:
                omega += 1
        find_remaining_blocks(start, end)

    def find_remaining_blocks(start, end):
        if start > end:
            return
        best_omega = -1
        best_b_start = -1
        best_b_end = -1
        min_s_omega = float('inf')
        for omega in range(9):
            target_unique = 2 ** omega
            result = find_largest_block_with_unique_count(start, end, target_unique)
            if result is not None:
                b_start, b_end = result
                b_len = b_end - b_start + 1
                cost = memory_cost(b_start, b_end, omega)
                s_omega = cost / b_len
                if s_omega < min_s_omega:
                    min_s_omega = s_omega
                    best_omega = omega
                    best_b_start = b_start
                    best_b_end = b_end
        if best_omega != -1:
            block_global_indices = attribute_array_Ae[best_b_start : best_b_end + 1]
            local_indices, palette_global_indices = create_palette(block_global_indices)
            palette_idx = len(palettes)
            palettes.append(palette_global_indices)
            directory.append((best_b_start, palette_idx))
            for k in range(best_b_end - best_b_start + 1):
                attribute_array_Ae[best_b_start + k] = local_indices[k]
            find_remaining_blocks(best_b_end + 1, end)

    find_largest_blocks(0, len(attribute_array_Ae) - 1, 0)
    return palettes, directory
```

**Edge Cases and Pitfalls**
- **Combinatorial Complexity**: Finding the optimal block partition is a hard combinatorial problem [S1]. The greedy heuristic is used as an approximation [S1].
- **Phase 1 Termination**: Phase 1 terminates when $\omega \ge 4$ because finding the largest block with 16 or more unique indices becomes computationally infeasible [S1].
- **Palette Sharing**: Palettes can be shared by multiple blocks, so the algorithm must check for existing matching palettes before creating new ones [S1].

## Operating characteristics
- **Time Complexity**: Finding the optimal block set is a hard combinatorial problem [S1]. The algorithm uses a greedy heuristic to approximate the optimal partitioning [S1]. Phase 1 is limited to small $\omega$ ($<4$) to keep the brute-force search for the largest block feasible [S1]. Phase 2 searches for blocks starting at the current index for $\omega \in \{0, \dots, 8\}$ [S1].
- **Memory Complexity**: The memory footprint is reduced by storing indices into palettes instead of full attributes or global indices [S1]. The overhead includes the palettes themselves and the block directory [S1]. The directory overhead is described as negligible [S1].
- **Performance**: The method is efficient for scenes with high spatial coherence, where large areas share a limited set of attributes [S1].
- **Strengths**: Exploits spatial coherence; variable-length indices allow fine-grained compression; fast runtime access due to local palettes [S1].
- **Limitations**: Approximate solution due to greedy heuristic; Phase 1 is limited to small palettes for performance [S1].

## Background
Palette compression was introduced in the context of geometry and attribute compression for voxel scenes, specifically as part of a decoupled SVO compression scheme [S1]. It addresses the memory bottleneck of uncompressed attribute arrays in high-resolution voxel scenes by leveraging the observation that the number of unique attributes is often much smaller than the total voxel count and that attributes exhibit spatial coherence [S1].
