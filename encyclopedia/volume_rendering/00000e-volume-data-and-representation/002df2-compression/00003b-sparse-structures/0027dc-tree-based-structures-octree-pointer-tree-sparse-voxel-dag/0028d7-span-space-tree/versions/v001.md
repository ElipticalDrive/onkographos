# Span Space Tree

Also called: SST

## Overview
The Span Space Tree (SST) is a hierarchical data structure designed to manage scene complexity for large volume datasets, enabling interactive rendering where standard techniques struggle. It refines the interval tree concept to efficiently cull empty regions and reduce the visited set of cells during rendering [S1, unofficial]. It is distinguished from sibling structures like the Sparse Voxel Octree by its specific focus on interval-based traversal optimization for large-scale data.

## How it works
The Span Space Tree is a refinement of the interval tree concept, originally proposed by Livnat et al. to handle larger volume data than previously feasible [S1, unofficial].

**Inputs and Outputs:**
*   **Input:** A large 3D volume dataset (typically exceeding $512^3$ resolution, where interactive visualization becomes difficult for other techniques) [S1, unofficial].
*   **Output:** A hierarchical structure allowing efficient traversal and culling during rendering or extraction.

**Data Structures:**
The structure is based on an interval tree. While the exact node layout is not detailed in the provided source, it builds upon the min-max hierarchy concept embedded in a branch-on-need octree proposed by Wilhelms and Van Gelder [S1, unofficial]. The SST refines this by managing spans (intervals) of non-empty data.

**Steps:**
1.  **Construction:** The volume is analyzed to identify spans of non-empty data. The structure is built to represent these spans hierarchically, allowing for the trivial ignoring of empty regions [S1, unofficial].
2.  **Traversal:** During rendering, the tree is traversed to visit only relevant cells. The interval-based nature allows for efficient culling of empty space, reducing the number of visited cells [S1, unofficial].

**Parameters:**
*   **Resolution:** The method is specifically noted for enabling interactive visualization of data up to $512^3$ resolution, and is intended for larger data where other techniques fail [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Large Data:** The method addresses the difficulty of interactive visualization for data larger than $512^3$, which is a limitation of many earlier techniques [S1, unofficial].

## Background
The Span Space Tree was created by Livnat et al. as a refinement of the interval tree concept [S1, unofficial]. It was developed to address the challenges of rendering larger volume data interactively, building upon earlier work by Wilhelms and Van Gelder on min-max hierarchies in octrees [S1, unofficial]. It is part of a lineage of techniques including min-max octrees and adaptive marching cubes, aimed at enabling interactive visualization of complex volume data [S1, unofficial].
