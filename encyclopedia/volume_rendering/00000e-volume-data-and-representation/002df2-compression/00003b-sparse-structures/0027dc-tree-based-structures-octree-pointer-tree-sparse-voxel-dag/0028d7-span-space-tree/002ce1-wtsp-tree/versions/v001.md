# WTSP Tree

Also called: Spatio-Temporal Wavelet Tree Construction, WTSP Tree Construction, WTSP Tree Hierarchical Structure, Wavelet Tree Spatial and Temporal, Wavelet-Based Time-Space Partitioning (WTSP) Tree

## Overview

The WTSP Tree is a hierarchical data structure designed to organize multiresolution time-varying volume data by combining spatial and temporal hierarchies into a unified structure [S1, S2]. It solves the problem of efficiently storing and rendering large-scale time-varying volumetric datasets by allowing independent control over spatial and temporal resolution [S2]. Unlike its parent, the Span Space Tree, which primarily manages spatial complexity, the WTSP Tree explicitly integrates a temporal dimension via wavelet transforms, creating a single unified spatio-temporal hierarchy [S1, S2]. It is distinguished from the Time-Space Partitioning Tree by its use of wavelet-based compression and error metrics for both spatial and temporal domains [S2].

## How it works

**Inputs and Outputs**
*   **Input:** A time-varying volume dataset consisting of $T$ time steps, where each time step is a 3D grid of voxels. The dataset is divided into blocks. When loading data, one voxel overlapping boundaries between neighboring blocks in each dimension is considered to ensure correct rendering [S2].
*   **Output:** A unified WTSP Tree structure, which is an octree (spatial hierarchy) of binary trees (temporal hierarchy) [S1, S2].

**Data Structures**
The WTSP Tree consists of two nested hierarchies:
1.  **Spatial Hierarchy (Octree):** A single octree skeleton shared across all time steps. Each node represents a subvolume at a specific spatial resolution.
2.  **Temporal Hierarchy (Binary Time Tree):** Attached to each node of the spatial octree. This binary tree spans the entire time sequence ($0$ to $T-1$) [S1, S2].

**Layout Details:**
*   **Octree Node:** Contains a pointer to the root of a binary time tree.
*   **Binary Time Tree Node:** Represents a specific time interval or point. It contains wavelet coefficients (averages and differences) derived from the temporal transform of the spatial wavelet coefficients at that location [S1].
*   **Leaf Nodes:**
    *   Spatial leaves contain the low-pass filtered subblocks (approximation coefficients) or raw data if no further subdivision is needed.
    *   Temporal leaves contain the final compressed coefficients for that spatial node across the time sequence [S1].

**Algorithm Steps**

The construction is a two-stage process [S2]:

1.  **Stage 1: Spatial Hierarchy Construction**
    *   For each time step $t \in [0, T-1]$:
        *   Recursively apply a 3D wavelet transform to the volume data blocks [S1, S2].
        *   Group subblocks to form an octree. The root represents the entire volume. Child nodes represent subvolumes with higher spatial resolution [S1, S2].
        *   Wavelet coefficients are stored at child nodes; low-pass filtered subblocks are passed up to the parent [S1].
        *   **Optimization (Uniform Blocks):** If a data block is uniform, skip the 3D wavelet transform. Set the low-pass filtered subblock to the uniform value and all corresponding wavelet coefficients to zero [S1].
    *   This results in one multiresolution spatial octree hierarchy per time step [S1].

2.  **Stage 2: Temporal Hierarchy Construction**
    *   Identify octree nodes that have the same spatial location and resolution across all time steps [S1, S2].
    *   **For non-root nodes:**
        *   Collect the wavelet coefficients associated with these nodes across the time sequence [S1].
        *   Apply a 1D wavelet transform along the time dimension to these coefficients [S1, S2].
        *   **Optimization (Zero Coefficients):** If the wavelet coefficients of corresponding octree nodes in the time sequence are all zero, skip the 1D wavelet transform process [S1].
    *   **For root nodes:**
        *   Build the temporal hierarchy from the low-resolution data blocks (approximations) rather than wavelet coefficients [S1].
    *   The 1D wavelet transform merges all spatial octrees across time into a single unified spatio-temporal structure [S1, S2].
    *   **Compression:** Compress the 1D wavelet transform coefficients using run-length encoding combined with a fixed Huffman encoder [S1]. This scheme is efficient if many consecutive zero subsequences are present [S1].

**Parameters**
*   **Wavelet Type:**
    *   **Temporal:** Haar wavelets are used for the 1D temporal transform [S1, S2]. This produces a binary time tree similar to the error tree algorithm [MVW98].
    *   **Spatial:** 3D spatial wavelet transforms are not limited to Haar wavelets; higher-order wavelets can be used for better image quality, though this increases reconstruction cost [S1].
*   **Error Tolerances:** Users specify separate spatial and temporal error tolerances at run time to select data blocks with various spatio-temporal resolutions [S2].

**Formulas**
*   **Hierarchical Spatial and Temporal Error Metric:** A metric is used to calculate approximation spatial and temporal errors for each time tree node. The specific formula is not provided in the sources, but it guides the selection of data blocks based on user-specified tolerances [S2].
*   **Temporal Wavelet Transform (Haar):** For a sequence of coefficients $C_t$ at time $t$, the Haar transform produces averages $A$ and differences $D$ for time spans $[t_1, t_2]$. For example, $A[0,3]$ and $D[0,3]$ are computed from coefficients at times 0, 1, 2, 3 [S1].

def build_wtsp_tree(volume_data, time_steps, spatial_wavelet_type='haar', 
                    spatial_error_tol=0.0, temporal_error_tol=0.0):
    """
    Constructs the WTSP Tree from time-varying volume data.
    
    Args:
        volume_data: List of 3D arrays, one for each time step.
        time_steps: Number of time steps T.
        spatial_wavelet_type: Type of wavelet for spatial transform.
        spatial_error_tol: User-specified spatial error tolerance.
        temporal_error_tol: User-specified temporal error tolerance.
        
    Returns:
        wtsp_tree: The root of the WTSP Tree structure.
    """
    # Stage 1: Build spatial octrees for each time step
    spatial_octrees = []
    for t in range(time_steps):
        octree = build_spatial_octree(volume_data[t], spatial_wavelet_type)
        spatial_octrees.append(octree)
        
    # Stage 2: Merge into unified WTSP Tree
    # The WTSP tree has one octree skeleton. 
    # We traverse the spatial octrees to build the temporal trees.
    
    # Helper to find corresponding nodes across time steps
    # Assumes nodes are aligned by spatial location and resolution
    def get_corresponding_nodes(octrees, node_path):
        """
        Returns a list of nodes from each time step's octree 
        that correspond to the same spatial location/resolution.
        """
        nodes = []
        for octree in octrees:
            node = octree.get_node_by_path(node_path)
            if node is None:
                return None # Node does not exist in all time steps
            nodes.append(node)
        return nodes

    # Build the unified tree
    # Root of the WTSP tree
    wtsp_root = OctreeNode(path=[])
    
    # Process root node separately (uses low-res data blocks)
    root_nodes = get_corresponding_nodes(spatial_octrees, [])
    if root_nodes:
        # Extract low-pass filtered subblocks (approximations) from root nodes
        approximations = [node.approximation for node in root_nodes]
        # Build temporal tree for root using approximations
        temporal_tree_root = build_temporal_tree_haar(approximations, temporal_error_tol)
        wtsp_root.temporal_tree = temporal_tree_root
        
    # Recursively build children
    build_wtsp_children(wtsp_root, spatial_octrees, path=[])
    
    return wtsp_root

def build_wtsp_children(parent_node, spatial_octrees, path):
    """
    Recursively builds the spatial octree and attaches temporal trees.
    """
    # Determine child paths (e.g., 000 to 111 for octree)
    child_paths = get_octree_child_paths(path)
    
    for child_path in child_paths:
        # Check if this spatial node exists in all time steps
        corresponding_nodes = get_corresponding_nodes(spatial_octrees, child_path)
        
        if corresponding_nodes is None:
            continue # Skip if not aligned across all time steps
            
        # Create spatial child node
        spatial_child = OctreeNode(path=child_path)
        parent_node.children.append(spatial_child)
        
        # Extract wavelet coefficients for this spatial location across time
        # For non-root nodes, use wavelet coefficients
        coefficients = [node.wavelet_coefficients for node in corresponding_nodes]
        
        # Check for optimization: if all coefficients are zero, skip transform
        if all(is_zero(coeff) for coeff in coefficients):
            # Store zero temporal tree or null
            spatial_child.temporal_tree = ZeroTemporalTree()
        else:
            # Build temporal tree using 1D Haar wavelet transform
            temporal_tree_root = build_temporal_tree_haar(coefficients, temporal_error_tol)
            spatial_child.temporal_tree = temporal_tree_root
            
        # Recurse for deeper spatial levels
        # Only if the spatial node is not a leaf (i.e., it has children in the octree)
        if not is_spatial_leaf(corresponding_nodes[0]):
            build_wtsp_children(spatial_child, spatial_octrees, child_path)

def is_zero(coeff):
    """Check if a coefficient is effectively zero."""
    return coeff == 0.0

def is_spatial_leaf(node):
    """Check if a spatial octree node is a leaf."""
    return node.children is None or len(node.children) == 0

def get_octree_child_paths(path):
    """Generate the 8 child paths for an octree node."""
    paths = []
    for i in range(8):
        # Convert integer i to 3-bit binary string
        bits = format(i, '03b')
        new_path = path + list(bits)
        paths.append(new_path)
    return paths

def haar_transform_1d(sequence):
    """
    Performs one level of 1D Haar wavelet transform.
    Returns averages and differences.
    """
    n = len(sequence)
    if n % 2 != 0:
        raise ValueError("Sequence length must be even for Haar transform")
    
    averages = []
    differences = []
    
    for i in range(0, n, 2):
        a = (sequence[i] + sequence[i+1]) / 2.0
        d = (sequence[i] - sequence[i+1]) / 2.0
        averages.append(a)
        differences.append(d)
        
    return averages, differences

def construct_haar_binary_tree(coefficients, error_tol):
    """
    Constructs the binary time tree recursively.
    This is a placeholder for the specific error tree algorithm [MVW98].
    """
    # If the sequence is short or error is within tolerance, return a leaf
    if len(coefficients) <= 1 or check_error(coefficients, error_tol):
        return TimeTreeLeaf(value=coefficients[0] if coefficients else 0.0)
    
    # Perform Haar transform
    avg, diff = haar_transform_1d(coefficients)
    
    # Recursively build children
    # The average branch represents the low-frequency component
    avg_node = construct_haar_binary_tree(avg, error_tol)
    # The difference branch represents the high-frequency component
    diff_node = construct_haar_binary_tree(diff, error_tol)
    
    # Create internal node
    node = TimeTreeInternalNode(average=avg, difference=diff, left=avg_node, right=diff_node)
    return node

## Subtopics

### [Time-Space Partitioning Tree](5382-time-space-partitioning-tree.md)
A structure made by an octree whose nodes contain a binary tree with temporal information. It is the predecessor to the WTSP Tree, which adds wavelet-based compression and error metrics. Choose WTSP Tree when wavelet compression benefits are needed; choose TSP Tree for simpler hierarchical navigation without wavelet transforms.

## Operating characteristics

*   **Time Complexity:** Construction involves 3D wavelet transforms for each time step and 1D wavelet transforms for aligned nodes across time. The complexity is dominated by the wavelet transforms, which are generally $O(N \log N)$ for $N$ voxels per time step, plus the merging step. Decompression is fast due to run-length encoding [S1].
*   **Memory Complexity:** The structure stores wavelet coefficients for both spatial and temporal dimensions. Compression via run-length encoding and Huffman coding reduces memory usage, especially if many coefficients are zero [S1].
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** The structure scales with the number of time steps and spatial resolution. The single octree skeleton helps manage spatial complexity, while the temporal trees handle time variations [S1, S2].
*   **Strengths:** Unified spatio-temporal hierarchy allows independent LOD selection for space and time. Fast decompression due to run-length encoding. Efficient handling of uniform data and zero coefficients [S1].
*   **Limitations:** Trade-off between image quality and reconstruction cost when using higher-order spatial wavelets [S1]. Requires aligned spatial nodes across time steps for temporal transform [S1, S2].
*   **When to use:** Large-scale time-varying volume data visualization where both spatial and temporal resolution control are needed [S1, S2].
*   **When not to use:** Static volume data (use standard Octree or Wavelet Tree) or data with significant temporal misalignment that prevents aligned node grouping [S1, S2].

## Background

The WTSP Tree originates from the Time-Space Partitioning (TSP) tree [25] and was introduced by C. Wang, J. Gao, L. Li, and H. W. Shen in the paper "A Multiresolution Volume Rendering Framework for Large-Scale Time-Varying Data Visualization" (VG05) [S1, S2]. It was developed to address the challenges of visualizing large-scale time-varying volumetric data by providing a multiresolution framework that supports hierarchical navigation and LOD selection [S1, S2]. The method uses Haar wavelets for temporal transforms and allows for higher-order wavelets for spatial transforms [S1, S2].
