# Time-Space Partitioning Tree

Also called: TSP Tree, Time-Space Partition (TSP) Tree

## Overview
The Time-Space Partitioning (TSP) Tree is a hierarchical data structure for time-varying volume data that decouples spatial and temporal domains to exploit both spatial and temporal coherence [S1, unofficial]. It addresses resolution discrepancies and I/O overhead in out-of-core applications by allowing user-supplied error tolerances for a runtime trade-off between image quality and rendering speed [S1, unofficial]. Unlike 4D octrees which treat time as a fourth spatial dimension, the TSP tree maintains visibility order and spatial locality during traversal, avoiding issues where high spatial variation masks temporal coherence [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Time-varying volume data (scalar field), current time step, user-supplied error tolerance for standard deviation ($\epsilon_{std}$), and user-supplied error tolerance for temporal coherence ($\epsilon_{temp}$).
*   **Output:** A rendered image composed of intermediate results from subvolumes, with intermediate results cached in the tree nodes for reuse [S1, unofficial].

**Data Structures:**
The TSP tree is a time-supplemented octree [S1, unofficial].
1.  **Spatial Skeleton:** A complete octree recursively subdividing the volume spatially until all subvolumes reach a predefined minimum size (brick size) [S1, unofficial].
2.  **Temporal Component:** Each octree node contains a binary time tree representing the time span $[0, t]$ [S1, unofficial].
3.  **Node Layout:**
    *   **Octree Node:** Represents a spatial subdomain.
    *   **Binary Time Tree Node:** Associated with an octree node, it represents the same spatial subdomain but a different time span. It stores:
        *   Mean value of voxels in the subvolume across all time steps in that span.
        *   Standard deviation of voxel values.
        *   A measurement of temporal coherence for the subvolume within the time span [S1, unofficial].
    *   **Leaf Nodes:** The leaf nodes of the TSP tree (octree leaves) are volume bricks, not individual voxels, with a predefined minimum size [S1, unofficial].

**Formulas:**
Let $v_{i,t}$ be the value of voxel $i$ at time step $t$, and $A$ be the total number of voxels in the subvolume across all time steps [S1, unofficial].

*   **Mean:**
    $$ \text{Mean} = \frac{1}{A} \sum v_{i,t} $$
    [S1, unofficial]

*   **Standard Deviation:**
    $$ \text{Standard Deviation} = \sqrt{\frac{1}{A} \sum (v_{i,t} - \text{Mean})^2} $$
    This formula is equivalent to the standard statistical formula but is suitable for one-pass bottom-up octree construction [S1, unofficial].

*   **Temporal Coherence:**
    To quantify temporal coherence for a time span $[t_1, t_2]$, treat each voxel as an independent variable. Compute the standard deviation of each voxel over the time span, then average these values [S1, unofficial].
    Let $s(v_i)$ be the standard deviation of voxel $v_i$ in the time span $[t_1, t_2]$, and $n$ be the number of voxels within the subvolume [S1, unofficial].
    $$ s(v_i) = \sqrt{\frac{1}{t_2 - t_1 + 1} \sum_{t=t_1}^{t_2} (v_{i,t} - \bar{v}_i)^2} $$
    $$ \text{Temporal Coherence} = \frac{1}{n} \sum_{i=1}^{n} s(v_i) $$
    [S1, unofficial]

**Parameters:**
*   **Predefined minimum size:** The spatial subdivision stops when subvolumes reach this size. Limiting this size reduces storage space and compositing overhead [S1, unofficial].
*   **User-supplied error tolerance ($\epsilon_{std}$):** Used as a stopping criterion during traversal to render regions with tolerable spatial coherence using their mean values [S1, unofficial].
*   **User-supplied error tolerance ($\epsilon_{temp}$):** Used to identify regions where rendered images can be reused across several time steps [S1, unofficial].

**Algorithm Steps:**
1.  **Initialization:** Initiate rendering by supplying the current time step and the two error tolerances ($\epsilon_{std}, \epsilon_{temp}$) [S1, unofficial].
2.  **Spatial Traversal:** Perform a regular octree traversal starting from the root. Recursively visit nodes to check if spatial and temporal coherence satisfy user tolerances [S1, unofficial].
3.  **Spatial Check:**
    *   If coherence satisfies tolerances, render the subvolume as a whole [S1, unofficial].
    *   Otherwise, walk down to its eight children following back-to-front visibility order determined by viewing direction [S1, unofficial].
4.  **Temporal Traversal (for each TSP node):** For each TSP node (which is a binary time tree), start error checking from the root of the time tree [S1, unofficial].
    *   Check if temporal coherence measure is smaller than $\epsilon_{temp}$ [S1, unofficial].
    *   If **no** (temporal coherence is not smaller than tolerance), traverse down to the branch of the time tree corresponding to the current time and repeat the check [S1, unofficial].
    *   If **yes** (temporal coherence is smaller than tolerance), check if standard deviation is smaller than $\epsilon_{std}$ [S1, unofficial].
        *   If **yes** (standard deviation is smaller than tolerance), use the associated mean value to draw the entire subvolume and terminate traversal along this path [S1, unofficial].
        *   If **no** (standard deviation is not smaller than tolerance), return to the main TSP traversal routine and indicate the need to go down to the children of the current TSP node [S1, unofficial].
5.  **Rendering:** Render gathered subvolumes independently using a divide-and-conquer paradigm; the final image is a composition of intermediate results [S1, unofficial].
6.  **Caching:** Save intermediate rendering results from subvolumes in their associated TSP tree nodes [S1, unofficial].
7.  **Reuse:** When rendering a different time step, repeat traversal. If nodes with high temporal coherence are encountered and stored intermediate results cover the current time step, skip rendering and reuse results [S1, unofficial].

**Pseudocode:**

```python
def render_tsp_tree(root_node, current_time, epsilon_std, epsilon_temp):
    """
    Renders a time-varying volume using the TSP tree.
    :param root_node: The root of the TSP tree (Octree root).
    :param current_time: The current time step index.
    :param epsilon_std: User-supplied tolerance for standard deviation.
    :param epsilon_temp: User-supplied tolerance for temporal coherence.
    :return: Composed image.
    """
    subvolumes = []
    traverse_octree(root_node, current_time, epsilon_std, epsilon_temp, subvolumes)
    
    # Divide-and-conquer rendering
    intermediate_results = []
    for subvolume in subvolumes:
        result = render_subvolume(subvolume)
        intermediate_results.append(result)
        
    return compose_results(intermediate_results)

def traverse_octree(node, current_time, epsilon_std, epsilon_temp, subvolumes):
    """
    Recursively traverses the spatial octree.
    """
    # Check if leaf node (brick)
    if node.is_leaf():
        # Perform temporal check on the binary time tree associated with this octree node
        time_tree_node = node.binary_time_tree_root
        temporal_result = traverse_time_tree(time_tree_node, current_time, epsilon_std, epsilon_temp)
        
        if temporal_result == "USE_MEAN":
            # Render subvolume using mean value
            subvolume = Subvolume(node.spatial_bounds, node.mean_value)
            subvolumes.append(subvolume)
        elif temporal_result == "RECURSE_SPATIAL":
            # Cannot use mean, need actual data. 
            # In TSP, if we recurse spatially, we usually go to children.
            # However, if this is a leaf brick, we must render it with actual data.
            # The source implies returning to main routine to go to children.
            # If leaf, we treat it as a subvolume requiring actual data rendering.
            subvolume = Subvolume(node.spatial_bounds, node.data) # Actual data
            subvolumes.append(subvolume)
        return

    # Internal octree node: Check spatial coherence first?
    # Source says: "recursively visit the tree node starting from the root to check if its 
    # spatial and temporal coherence satisfy the user’s tolerance. If yes, we render this 
    # subvolume as a whole. Otherwise we walk down to its eight children..."
    # Note: Spatial coherence is often implied by the mean/std deviation check in the time tree 
    # or a separate spatial check. The source links spatial coherence to the standard deviation 
    # check in the time tree context for the specific time span.
    
    # Let's assume we check the time tree root for the current time span to decide 
    # if we can render the whole spatial subvolume (node) or must split.
    time_tree_node = node.binary_time_tree_root
    
    # Check temporal coherence for the full time span [0, current_time] or relevant span
    # The source says: "Check if temporal coherence measure at this node is smaller than 
    # the user tolerance. If no, traverse down to the branch... corresponding to the current time"
    
    if time_tree_node.temporal_coherence < epsilon_temp:
        # Temporal coherence is good. Check spatial coherence (std dev).
        if time_tree_node.standard_deviation < epsilon_std:
            # Both good. Render as whole.
            subvolume = Subvolume(node.spatial_bounds, time_tree_node.mean_value)
            subvolumes.append(subvolume)
            return
        else:
            # Spatial coherence bad. Must recurse spatially.
            pass
    else:
        # Temporal coherence bad. Must recurse temporally? 
        # Source: "If no [temporal coherence < tolerance], traverse down to the branch 
        # of the time tree that corresponds to the current time and repeat this step"
        # This implies we stay at this spatial node but go deeper in time tree.
        # However, the main loop is spatial traversal.
        # The source structure: "For each TSP node... perform error checking... 
        # If temporal coherence not smaller... traverse down... If temporal coherence smaller... 
        # check std dev... If std dev not smaller... return to main TSP traversal routine 
        # and indicate need to go down to children."
        
        # So, if temporal coherence is BAD, we don't necessarily recurse spatially immediately.
        # We recurse temporally within the time tree.
        # But the main function is `traverse_octree`.
        # Let's refine: The TSP traversal is an octree traversal. At each node, we check 
        # the time tree.
        
        # Re-reading carefully:
        # 1. Regular octree traversal.
        # 2. Check if spatial and temporal coherence satisfy tolerance.
        # 3. If yes -> render whole.
        # 4. If no -> walk down to 8 children.
        
        # How is "spatial and temporal coherence" checked?
        # "For each TSP node... start error checking from root of time tree...
        # Check temporal coherence... If no, traverse down time tree...
        # If yes, check std dev... If yes, use mean... If no, return to main TSP traversal 
        # and indicate need to go down to children."
        
        # This implies the "Check" happens inside the node processing.
        # If we return "RECURSE_SPATIAL", the caller (octree traversal) goes to children.

        elif time_tree_result == "USE_ACTUAL_DATA":

            # but rather split spatially.
            pass

    for child in node.children:

def traverse_time_tree(node, current_time, epsilon_std, epsilon_temp):
    """
    Traverses the binary time tree associated with an octree node.
    :return: "USE_MEAN", "RECURSE_SPATIAL", or "USE_ACTUAL_DATA"
    """
    # Check temporal coherence
    if node.temporal_coherence < epsilon_temp:
        # Temporal coherence is acceptable. Check spatial coherence (std dev).
        if node.standard_deviation < epsilon_std:
            return "USE_MEAN"
        else:
            # Spatial coherence is bad. Need to split spatially.
            return "RECURSE_SPATIAL"
    else:
        # Temporal coherence is bad.
        # Traverse down to the branch corresponding to current_time.
        # Assuming binary tree splits time span [t1, t2] into [t1, mid] and [mid+1, t2]
        if current_time <= node.mid_time:
            if node.left_child:
                return traverse_time_tree(node.left_child, current_time, epsilon_std, epsilon_temp)
            else:
                # Leaf node of time tree (unit time step)
                # If we are here, temporal coherence check passed? 
                # No, we only get here if temporal coherence was BAD.
                # But if it's a leaf, there is no further time split.
                # This implies the data at this specific time step has high variation?
                # Or the coherence metric is not applicable at unit step?
                # Source: "traverse down to the branch... corresponding to the current time 
                # and repeat this step".
                # If we hit a leaf and coherence is still bad (or we couldn't check it?),
                # we must use actual data.
                return "USE_ACTUAL_DATA"
        else:
            if node.right_child:
                return traverse_time_tree(node.right_child, current_time, epsilon_std, epsilon_temp)
            else:
                return "USE_ACTUAL_DATA"
```

**Edge Cases and Pitfalls:**
*   **Spatial Variation Masking Temporal Coherence:** In 4D octrees, if a subvolume has dramatic spatial variation but remains unchanged temporally, overall value coherence appears low, causing temporal coherence to be missed. The TSP tree avoids this by decoupling domains [S1, unofficial].
*   **Resolution Discrepancies:** In 4D octrees with large time steps, temporal coherence for subvolumes smaller than the spatial subdivision size (e.g., $256^3$) cannot be detected because branching involves only spatial subdivisions. The TSP tree detects temporal coherence independently of spatial brick size [S1, unofficial].
*   **Compositing Overhead:** If the minimum brick size is not limited, the overhead of compositing a large number of small subimages increases [S1, unofficial].

## Subtopics

### Wavelet-based TSP
A variant of the TSP tree applied to a 3D wavelet transformation of the original data [S2]. It uses a similar hierarchical structure (octree with temporal binary trees) but operates on wavelet coefficients rather than raw voxel values [S2].

## Operating characteristics
*   **Time Complexity:** Depends on the data characteristics and user-specified error tolerances. Higher tolerances lead to faster rendering by skipping more subvolumes [S1, unofficial].
*   **Memory Complexity:** Reduced storage space compared to 4D octrees due to the brick-based leaf structure and limited minimum size [S1, unofficial].
*   **Performance:** Accelerates time-varying volume rendering by exploiting both spatial and temporal coherence [S1, unofficial].
*   **Strengths:**
    *   Decouples spatial and temporal domains, effectively detecting temporal coherence even when spatial variation is high [S1, unofficial].
    *   Reduces I/O overhead, making it suitable for out-of-core applications [S1, unofficial].
    *   Allows runtime trade-off between image quality and rendering speed via user-supplied tolerances [S1, unofficial].
    *   Maintains visibility order and spatial locality during traversal [S1, unofficial].
*   **Limitations:**
    *   Performance is data-dependent; if temporal coherence is low, acceleration is reduced [S1, unofficial].
    *   Requires careful tuning of minimum brick size to balance storage and compositing overhead [S1, unofficial].
*   **When to use:** Out-of-core rendering of large-scale time-varying volumes where temporal coherence is present [S1, unofficial].
*   **When not to use:** When temporal coherence is absent or when strict real-time performance is required without tolerance tuning [S1, unofficial].

## Background
The TSP tree was proposed to address challenges in visualizing large-scale time-varying fields, where treating time as a fourth spatial dimension leads to difficulties due to resolution discrepancies and the inability to detect unique temporal coherence [S1, unofficial]. It builds on the concept of temporal hierarchical index trees [S1, unofficial]. The structure was implemented with an application-controlled demand paging system for out-of-core rendering [S1, unofficial].
