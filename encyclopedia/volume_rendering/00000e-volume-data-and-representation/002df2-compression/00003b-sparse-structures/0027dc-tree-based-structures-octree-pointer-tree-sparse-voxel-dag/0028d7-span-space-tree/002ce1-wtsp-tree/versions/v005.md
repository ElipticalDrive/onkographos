# WTSP Tree

Also called: Spatio-Temporal Wavelet Tree Construction, WTSP Tree Construction, WTSP Tree Hierarchical Structure, Wavelet Tree Spatial and Temporal, Wavelet-Based Time-Space Partitioning (WTSP) Tree, Wavelet-Based Time-Space Partitioning (WTSP) Tree Construction

## Overview
The WTSP (Wavelet-Based Time-Space Partitioning) tree is a hierarchical data structure for organizing multiresolution time-varying volume data, exploiting spatial and temporal locality to allow flexible spatio-temporal level-of-detail (LOD) selection [S1, S2]. It builds on the [Span Space Tree](4379-span-space-tree.md) concept by decoupling spatial and temporal domains into a unified structure: a single octree skeleton where each node contains a binary time tree spanning the entire time sequence [S1, S2]. Unlike 4D octrees that treat time as a fourth spatial dimension, the WTSP tree maintains visibility order and spatial locality during traversal, avoiding issues where high spatial variation masks temporal coherence [S1, S2]. It distinguishes itself from its sibling [Time-Space Partitioning Tree](5382-time-space-partitioning-tree.md) by using wavelet compression and error-guided bucketization for distributed rendering [S1, S2].

## How it works
**Inputs:** Time-varying volume data consisting of $T$ time steps, each with spatial dimensions $N \times N \times N$ [S1, S2]. User-specified spatial error tolerance ($\epsilon_s$) and temporal error tolerance ($\epsilon_t$) [S1, S2]. Block size $n$ (number of voxels per initial subvolume) [S1].

**Outputs:** A unified spatio-temporal hierarchical data structure (WTSP tree) containing compressed wavelet coefficients and low-pass filtered subblocks, along with hierarchical error metrics for each node [S1].

**Data Structures:**
1.  **Spatial Octree Node:**
    *   `low_pass`: Array of $n/8$ voxels (for non-root nodes) or $n$ voxels (for root nodes).
    *   `wavelet_coeffs`: Array of $7n/8$ coefficients (for non-root nodes).
    *   `spatial_error`: Scalar value $s_e$.
    *   `children`: Array of 8 child nodes (or null if leaf).
2.  **Temporal Time Tree Node:**
    *   `value`: Wavelet coefficient (Haar average or difference) or low-pass block (for root).
    *   `temporal_error`: Scalar value $t_e$.
    *   `left_child`: Reference to time tree node for first half of time interval.
    *   `right_child`: Reference to time tree node for second half of time interval.
    *   `compressed_data`: Run-length encoded and Huffman-encoded bitstream of coefficients.

**Algorithm Steps:**

1.  **Data Loading with Overlap:**
    Load volume data for each time step. To ensure correct rendering at block boundaries, include one voxel of overlap between neighboring blocks in each dimension [S2].

2.  **Stage 1: Spatial Hierarchy Construction (Per Time Step):**
    For each time step $t \in [0, T-1]$:
    a.  **Block Subdivision:** Subdivide the volumetric data into data blocks of size $n$ voxels [S1, S2].
    b.  **3D Wavelet Transform:** Perform a 3D wavelet transform on each block [S1, S2].
        *   *Optimization:* If the data block is uniform, skip the transform. Set the low-pass filtered subblock to the uniform value and all wavelet coefficients to zero [S1].
        *   The transform produces a low-pass filtered subblock of size $n/8$ and wavelet coefficients of size $7n/8$ [S1].
    c.  **Thresholding:** Compare wavelet coefficients against a user-specified threshold. Clamp coefficients smaller than the threshold to zero [S1].
    d.  **Octree Assembly:** Recursively group low-pass filtered subblocks from eight neighboring subvolumes into a single block of $n$ voxels to form the parent node. Keep wavelet coefficients at the child nodes [S1].
    e.  **Recursion:** Repeat steps b-d until the root of the octree is reached, where a single block of size $n$ represents the entire volume [S1, S2].
    f.  **Repeat:** Construct one multiresolution spatial octree hierarchy for every time step [S1].

3.  **Stage 2: Temporal Hierarchy Construction (Across Time Steps):**
    a.  **Coefficient Alignment:** Identify octree nodes that have the same spatial location and resolution across all time steps [S1, S2].
    b.  **1D Wavelet Transform:** Apply 1D wavelet transforms along the time dimension to the wavelet coefficients associated with these aligned nodes [S1, S2].
        *   *Optimization:* If the wavelet coefficients of corresponding octree nodes in the time sequence are all zero, skip the 1D transform process [S1].
        *   Use Haar wavelets for the temporal transform [S1, S2]. This produces a binary time tree similar to the error tree algorithm [MVW98] [S1].
    c.  **Root Handling:** For the root nodes of the octrees, build the temporal hierarchy from the low-resolution data blocks rather than wavelet coefficients [S1].
    d.  **Compression:** Compress the 1D wavelet transform coefficients using run-length encoding combined with a fixed Huffman encoder [S1]. This scheme is fast to decompress and effective when many consecutive zero subsequences are present [S1].
    e.  **Unification:** The 1D transform merges all spatial octrees across time into a single unified spatio-temporal hierarchical structure [S1, S2]. The result is an octree skeleton where each node contains a binary time tree spanning the entire time sequence [S1, S2].

4.  **Hierarchical Error Metric Calculation:**
    During the bottom-up construction, calculate spatial error ($s_e$) and temporal error ($t_e$) for each time tree node based on Mean Square Error (MSE) [S1, S2].
    *   **Spatial Error ($s_e$):** For a time tree leaf node $T$ (corresponding to a single time step), calculate the sum of the MSE between the data at node $T$ and the data of the same time step at $T$'s eight spatial child nodes in the next spatial level of the octree, plus the maximum spatial error of the child nodes [S1].
        $$ s_e(T) = \sum_{i=0}^{7} \text{MSE}(T, T_i) + \max_{i=0}^{7} \{ s_e(T_i) \} $$
        Where $T_i$ are the eight spatial child nodes [S1].
    *   **Temporal Error ($t_e$):** Calculated similarly for the temporal hierarchy, though the specific formula is not provided in the sources [S2]. The metric allows users to specify separate spatial and temporal error tolerances to select data blocks with various spatio-temporal resolutions [S1, S2].

**Parameters:**
*   **Block Size ($n$):** Size of the initial spatial subvolume in voxels [S1].
*   **Spatial Threshold:** User-specified threshold for clamping spatial wavelet coefficients [S1].
*   **Spatial Error Tolerance ($\epsilon_s$):** User-specified tolerance for spatial approximation error [S1, S2].
*   **Temporal Error Tolerance ($\epsilon_t$):** User-specified tolerance for temporal approximation error [S1, S2].
*   **Wavelet Type (Spatial):** 3D spatial wavelets. Not limited to Haar; higher-order wavelets can be used for better image quality [S1].
*   **Wavelet Type (Temporal):** Haar wavelets [S1, S2].

**Edge Cases and Pitfalls:**
*   **Uniform Data Blocks:** If a data block is uniform, skip the 3D wavelet transform. Set the low-pass filtered subblock to the uniform value and all wavelet coefficients to zero [S1].
*   **Zero Coefficients:** If the wavelet coefficients of corresponding octree nodes in the time sequence are all zero, skip the 1D wavelet transform process [S1].
*   **Boundary Overlap:** When loading volume data, consider one voxel overlapping boundaries between neighboring blocks in each dimension to produce correct rendering results [S2].
*   **Trade-off:** Using higher-order wavelets for spatial transforms improves image quality but increases reconstruction cost at run time [S1].

## Subtopics

### [Time-Space Partitioning Tree](5382-time-space-partitioning-tree.md)
The Time-Space Partitioning (TSP) Tree is a hierarchical data structure for time-varying volume data that decouples spatial and temporal domains to exploit both spatial and temporal coherence. It addresses resolution discrepancies and I/O overhead in out-of-core applications by allowing user-supplied error tolerances for a runtime trade-off between image quality and rendering speed. Unlike 4D octrees which treat time as a fourth spatial dimension, the TSP tree maintains visibility order and spatial locality during traversal, avoiding issues where high spatial variation masks temporal coherence. See [Time-Space Partitioning Tree](5382-time-space-partitioning-tree.md).

### [WTSP Tree Traversal and Parallel Rendering](7583-wtsp-tree-traversal-and-parallel-rendering.md)
This method traverses the Wavelet-based Time-Space Partitioning (WTSP) tree at run time to reconstruct and render data blocks of varying spatio-temporal resolutions in parallel, composing the final image. It solves the problem of efficiently visualizing large-scale time-varying data on parallel clusters by eliminating parent-child data dependencies for reconstruction and balancing workload among processors. It is distinguished from its parent [WTSP Tree](5371-wtsp-tree.md) by its runtime execution strategy and from its sibling [Time-Space Partitioning Tree](5382-time-space-partitioning-tree.md) by its specific use of wavelet compression and error-guided bucketization for distributed rendering. See [WTSP Tree Traversal and Parallel Rendering](7583-wtsp-tree-traversal-and-parallel-rendering.md).

### Hierarchical Spatial and Temporal Error Metric
Spatial error ($s_e$) and temporal error ($t_e$) are calculated for each time tree node during the bottom-up construction of the WTSP tree. The metric is based on Mean Square Error (MSE) [S1]. The spatial error for a time tree leaf node $T$ is the sum of the MSE between the data at node $T$ and the data of the same time step at $T$'s eight spatial child nodes in the next spatial level of the octree, plus the maximum spatial error of the child nodes: $s_e(T) = \sum_{i=0}^{7} \text{MSE}(T, T_i) + \max_{i=0}^{7} \{ s_e(T_i) \}$ [S1]. Users specify separate spatial and temporal error tolerances to select data blocks with various spatio-temporal resolutions [S1, S2].
