# Time-Space Partitioning Tree

Also called: TSP Tree, Time-Space Partition (TSP) Tree

## Overview
The Time-Space Partitioning (TSP) Tree is a hierarchical data structure for time-varying volume data that decouples spatial and temporal domains to exploit both spatial and temporal coherence [S1, unofficial]. It addresses resolution discrepancies and I/O overhead in out-of-core applications by allowing user-supplied error tolerances for a runtime trade-off between image quality and rendering speed [S1, unofficial]. Unlike 4D octrees which treat time as a fourth spatial dimension, the TSP tree maintains visibility order and spatial locality during traversal, avoiding issues where high spatial variation masks temporal coherence [S1, unofficial].

## How it works
**Inputs and Outputs:**
The method takes time-varying volume data, a current time step, and two user-supplied error tolerances as inputs [S1, unofficial]. It outputs a rendered image composed of intermediate results from subvolumes, with intermediate results cached in the tree nodes for reuse across time steps [S1, unofficial].

**Data Structures:**
The TSP tree is a time-supplemented octree [S1, unofficial]. The spatial skeleton is a complete octree that recursively subdivides the volume spatially until all subvolumes reach a predefined minimum size [S1, unofficial]. Each octree node contains a binary time tree representing the time span $[0, t]$ [S1, unofficial]. Every node in the binary time tree represents the same spatial subdomain but a different time span [S1, unofficial]. Each binary time tree node stores the mean value of voxels in the subvolume across all time steps in that span, the standard deviation of voxel values, and a measurement of temporal coherence for the subvolume within the time span [S1, unofficial]. The leaf nodes of the TSP tree are volume bricks, not individual voxels, with a predefined minimum size [S1, unofficial].

**Formulas:**
Let $v_{i,t}$ be the value of voxel $i$ at time step $t$, and $A$ be the total number of voxels in the subvolume across all time steps [S1, unofficial].

*   **Mean:**
    $$ \text{Mean} = \frac{1}{A} \sum v_{i,t} $$
    [S1, unofficial]

*   **Standard Deviation:**
    $$ \text{Standard Deviation} = \sqrt{\frac{1}{A} \sum (v_{i,t} - \text{Mean})^2} $$
    This formula is equivalent to the standard statistical formula but is suitable for one-pass bottom-up octree construction [S1, unofficial].

*   **Temporal Coherence:**
    To quantify temporal coherence for a time span $[t_1, t_2]$, each voxel is treated as an independent variable [S1, unofficial]. The standard deviation of each voxel over the time span is computed, then these values are averaged [S1, unofficial]. Let $s(v_i)$ be the standard deviation of voxel $v_i$ in the time span $[t_1, t_2]$, and $n$ be the number of voxels within the subvolume [S1, unofficial].
    $$ s(v_i) = \sqrt{\frac{1}{t_2 - t_1 + 1} \sum_{t=t_1}^{t_2} (v_{i,t} - \bar{v}_i)^2} $$
    $$ \text{Temporal Coherence} = \frac{1}{n} \sum_{i=1}^{n} s(v_i) $$
    [S1, unofficial]

**Parameters:**
The predefined minimum size determines when spatial subdivision stops, reducing storage space and compositing overhead [S1, unofficial]. The user-supplied error tolerance for standard deviation ($\epsilon_{std}$) acts as a stopping criterion during traversal to render regions with tolerable spatial coherence using their mean values [S1, unofficial]. The user-supplied error tolerance for temporal coherence ($\epsilon_{temp}$) identifies regions where rendered images can be reused across several time steps [S1, unofficial].

**Algorithm Steps:**
1. Initiate rendering by supplying the current time step and the two error tolerances ($\epsilon_{std}, \epsilon_{temp}$) [S1, unofficial].
2. Perform a regular octree traversal starting from the root, recursively visiting nodes to check if spatial and temporal coherence satisfy user tolerances [S1, unofficial].
3. If coherence satisfies tolerances, render the subvolume as a whole [S1, unofficial]. Otherwise, walk down to its eight children following back-to-front visibility order determined by viewing direction [S1, unofficial].
4. For each TSP node (which is a binary time tree), start error checking from the root of the time tree [S1, unofficial]. Check if the temporal coherence measure is smaller than $\epsilon_{temp}$ [S1, unofficial]. If temporal coherence is not smaller than tolerance, traverse down to the branch of the time tree corresponding to the current time and repeat the check [S1, unofficial]. If temporal coherence is smaller than tolerance, check if standard deviation is smaller than $\epsilon_{std}$ [S1, unofficial]. If standard deviation is smaller than tolerance, use the associated mean value to draw the entire subvolume and terminate traversal along this path [S1, unofficial]. If standard deviation is not smaller than tolerance, return to the main TSP traversal routine and indicate the need to go down to the children of the current TSP node [S1, unofficial].
5. Render gathered subvolumes independently using a divide-and-conquer paradigm; the final image is a composition of intermediate results [S1, unofficial].
6. Save intermediate rendering results from subvolumes in their associated TSP tree nodes [S1, unofficial].
7. When rendering a different time step, repeat traversal [S1, unofficial]. If nodes with high temporal coherence are encountered and stored intermediate results cover the current time step, skip rendering and reuse results [S1, unofficial].

**Pseudocode:**
```python
def render_tsp(root, current_time, epsilon_std, epsilon_temp):
    # 1. Initiate rendering with current time step and error tolerances
    subvolumes = []
    traverse_octree(root, current_time, epsilon_std, epsilon_temp, subvolumes)
    # 5. Render gathered subvolumes independently using divide-and-conquer
    # 6. Save intermediate results in associated TSP tree nodes
    final_image = compose_intermediate_results(subvolumes)
    # 7. Reuse cached results for different time steps if temporal coherence covers current step
    return final_image

def traverse_octree(node, current_time, epsilon_std, epsilon_temp, subvolumes):
    # 2. Perform regular octree traversal from root
    action = traverse_time_tree(node.time_tree_root, current_time, epsilon_std, epsilon_temp)
    if action == "USE_MEAN":
        # 3. If coherence satisfies tolerances, render subvolume as whole
        subvolumes.append({"bounds": node.bounds, "render_mode": "mean", "value": node.time_tree_root.mean_value})
        return
    elif action == "RECURSE_SPATIAL":
        # 3. Otherwise, walk down to eight children following back-to-front visibility order
        children = sorted(node.children, key=lambda c: dot(c.center - camera_position, view_direction))
        for child in children:
            traverse_octree(child, current_time, epsilon_std, epsilon_temp, subvolumes)
    elif action == "USE_ACTUAL_DATA":
        subvolumes.append({"bounds": node.bounds, "render_mode": "data", "value": node.data})
        return

def traverse_time_tree(node, current_time, epsilon_std, epsilon_temp):
    # 4. Check if temporal coherence measure is smaller than user tolerance
    if node.temporal_coherence < epsilon_temp:
        # 4. Check if standard deviation is smaller than user tolerance
        if node.standard_deviation < epsilon_std:
            return "USE_MEAN"
        else:
            return "RECURSE_SPATIAL"
    else:
        # 4. Traverse down to branch corresponding to current time
        if current_time <= node.mid_time and node.left:
            return traverse_time_tree(node.left, current_time, epsilon_std, epsilon_temp)
        elif node.right:
            return traverse_time_tree(node.right, current_time, epsilon_std, epsilon_temp)
        else:
            return "USE_ACTUAL_DATA"

def compose_intermediate_results(subvolumes):
    if len(subvolumes) == 1:
        return render_subvolume(subvolumes[0])
    mid = len(subvolumes) // 2
    left_img = compose_intermediate_results(subvolumes[:mid])
    right_img = compose_intermediate_results(subvolumes[mid:])
    return blend_results(left_img, right_img)

def render_subvolume(sv):
    if sv["render_mode"] == "mean":
        return render_with_mean(sv["bounds"], sv["value"])
    else:
        return render_with_data(sv["bounds"], sv["data"])

def blend_results(img1, img2):
    return img1 + img2

def dot(v1, v2):
    return v1.x * v2.x + v1.y * v2.y + v1.z * v2.z

def render_with_mean(bounds, mean_val):
    return create_subimage(bounds, mean_val)

def render_with_data(bounds, data):
    return cast_rays_through_bounds(bounds, data)

def create_subimage(bounds, mean_val):
    return allocate_image(bounds.size, mean_val)

def cast_rays_through_bounds(bounds, data):
    return standard_ray_cast(bounds, data)
```

**Edge Cases and Pitfalls:**
In 4D octrees, if a subvolume has dramatic spatial variation but remains unchanged temporally, overall value coherence appears low, causing temporal coherence to be missed [S1, unofficial]. The TSP tree avoids this by decoupling domains [S1, unofficial]. In 4D octrees with large time steps, temporal coherence for subvolumes smaller than the spatial subdivision size (e.g., $256^3$) cannot be detected because branching involves only spatial subdivisions [S1, unofficial]. The TSP tree detects temporal coherence independently of spatial brick size [S1, unofficial]. If the minimum brick size is not limited, the overhead of compositing a large number of small subimages increases [S1, unofficial].

## Subtopics

### Wavelet-based TSP
A variant of the TSP tree applied to a 3D wavelet transformation of the original data [S3]. It uses a similar hierarchical structure (octree with temporal binary trees) but operates on wavelet coefficients rather than raw voxel values [S3].

## Operating characteristics
Time complexity depends on the data characteristics and user-specified error tolerances [S1, unofficial]. Higher tolerances lead to faster rendering by skipping more subvolumes [S1, unofficial]. Memory complexity is reduced compared to 4D octrees due to the brick-based leaf structure and limited minimum size [S1, unofficial]. Performance accelerates time-varying volume rendering by exploiting both spatial and temporal coherence [S1, unofficial]. Strengths include decoupling spatial and temporal domains to effectively detect temporal coherence even when spatial variation is high, reducing I/O overhead for out-of-core applications, allowing runtime trade-offs between image quality and rendering speed via user-supplied tolerances, and maintaining visibility order and spatial locality during traversal [S1, unofficial]. Limitations include data-dependent performance where low temporal coherence reduces acceleration, and the requirement for careful tuning of minimum brick size to balance storage and compositing overhead [S1, unofficial]. It should be used for out-of-core rendering of large-scale time-varying volumes where temporal coherence is present [S1, unofficial].

## Background
The TSP tree was proposed to address challenges in visualizing large-scale time-varying fields, where treating time as a fourth spatial dimension leads to difficulties due to resolution discrepancies and the inability to detect unique temporal coherence [S1, unofficial]. It builds on the concept of temporal hierarchical index trees [S1, unofficial]. The structure was implemented with an application-controlled demand paging system for out-of-core rendering [S1, unofficial].
