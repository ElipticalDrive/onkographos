# Tree Evaluation with Bilinear Interpolation and VQ Residuals

Also called: Adaptive Tree Evaluation, Primal Subdivision Evaluation

## Overview
This method evaluates a signal value at a point $\mathbf{x}$ by traversing an adaptive quadtree structure, using bilinear interpolation of node values and Vector Quantization (VQ) residuals to reconstruct the signal [S1, unofficial]. It serves as the evaluation engine for the Compressed Random-Access Tree (CRAT) framework, enabling fine-grain random queries required by rendering algorithms [S1, unofficial]. Unlike its sibling [Trilinear Evaluation on Compressed Trees](7074-trilinear-evaluation-on-compressed-trees.md), which operates in 3D with trilinear filtering, this method is designed for 2D spatially coherent data using bilinear filtering and primal subdivision logic [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A point $\mathbf{x}$ in 2D space, a starting level $l$ (typically the root of a forested mipmap structure), and a compressed tree structure where nodes store addresses and values.
*   **Output:** The interpolated signal value at $\mathbf{x}$.

**Data Structures:**
*   **Node:** Contains an address (pointer/offset to children) and a value.
*   **VQ Codebook:** A lookup table storing residual values for quantized node differences [S1, unofficial].
*   **Tree Topology:** Primal subdivision structure where children of a node at location $(x, y)$ in level $l$ have locations $(x, y)$, $(x + 2^l, y)$, $(x, y + 2^l)$, and $(x + 2^l, y + 2^l)$ [S1, unofficial].

**Algorithm Steps:**
1.  Identify the cell containing $\mathbf{x}$ at the starting level $l$ (the coarsest level of the forested mipmap) [S1, unofficial].
2.  For each of the four corners of this cell, retrieve the root node address and value [S1, unofficial].
3.  Re-express point $\mathbf{x}$ in the cell’s local coordinates [S1, unofficial].
4.  Loop until termination:
    1.  At point $\mathbf{x}$, bilinearly interpolate the four node values to get the current coarse value $v_C$ [S1, unofficial].
    2.  If $l < 1$ or all four node addresses are NULL, return the value at $\mathbf{x}$ linearly interpolated (lerped) with the value from the prior level using $l$ as the weight [S1, unofficial].
    3.  Set the new cell as the quadrant containing point $\mathbf{x}$ [S1, unofficial].
    4.  For each of the four new cell corners:
        1.  Predict the new node value using bilinear interpolation of the parent's children [S1, unofficial].
        2.  If the node parent address is non-NULL, access the VQ codebook to add the residual value to the predicted value [S1, unofficial].
    5.  Update the node address to the appropriate child for each corner [S1, unofficial].
    6.  Re-express point $\mathbf{x}$ in the new cell’s coordinates [S1, unofficial].
    7.  Decrement $l$ [S1, unofficial].

**Edge Cases and Pitfalls:**
*   If node addresses are NULL or depth is insufficient ($l < 1$), the algorithm must blend with the prior level to avoid undefined behavior [S1, unofficial].
*   In primal subdivision, some subtrees may fall outside the input domain (dangling links) due to the "slanting" of the tree structure; these are ignored by the compression scheme [S1, unofficial].

## Subtopics

### [Compressed Random-Access Tree Framework](7109-compressed-random-access-tree-framework.md)
The Compressed Random-Access Tree (CRAT) framework compresses adaptive multiresolution hierarchies into a compact, randomly-accessible structure. Unlike prior schemes that use entropy coding on sequential traversals, CRAT employs fixed-rate encoding for both topology and data, enabling fine-grain random queries required by rendering algorithms. It replaces pointers with local offsets, uses a forested mipmap structure, and applies vector quantization (VQ) to inter-level residuals, storing both offsets and codebook indices as byte records.

### Primal Subdivision Tree for Adaptive Mipmapping
In 2D, children of a node at location $(x, y)$ in level $l$ have locations $(x, y)$, $(x + 2^l, y)$, $(x, y + 2^l)$, and $(x + 2^l, y + 2^l)$ [S1, unofficial]. This 'slanting' causes some subtrees to fall outside the input domain (dangling links), which the compression scheme ignores [S1, unofficial]. The core loop for evaluating a 1D adaptive primal tree iteratively initializes $l$ and $r$ as the two current nodes, computes the coarse value $v_C$, and loops: if both pruned, return $v_C$; compute midpoint $v_m$; select left or right subtree based on $x$; update $l, r, v_l, v_r$; compute fine value $v_F$; if level $\le 1.0$, blend $v_C$ and $v_F$ and return; else update $v_C=v_F$, level--, and continue [S1, unofficial]. Dual subdivision requires 3 lookups per level and large support for pruned nodes (interpolating from next-coarser level), equivalent to multiquadratic B-splines. Primal subdivision requires only 2 lookups per level and simple multilinear interpolation when all 2 local nodes are pruned [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The number of tree levels traversed is relatively low on average due to tree adaptivity and the collapse of coarsest levels into a forested mipmap [S1, unofficial].
*   **Memory Complexity:** Fixed-rate encoding for topology and data allows for compact storage [S1, unofficial].
*   **Strengths:** Efficient random access, low lookup count (2 per level for primal vs 3 for dual), and simple interpolation in pruned areas [S1, unofficial].
*   **Limitations:** Dangling links in primal subdivision require handling [S1, unofficial].
*   **When to use:** When evaluating 2D spatially coherent data with adaptive resolution and random access patterns [S1, unofficial].

## Background
The method originates from the work on Compressed Random-Access Trees for Spatially Coherent Data [S1, unofficial]. It builds on primal subdivision concepts from [FPRJ00] and [LKS*06], contrasting with dual-subdivision approaches like those in [ZS01] and [BD02]. The primal subdivision approach was highlighted for its efficiency in mipmap filtering compared to dual subdivision, which suffers from expensive interpolation in pruned areas [S1, unofficial].
