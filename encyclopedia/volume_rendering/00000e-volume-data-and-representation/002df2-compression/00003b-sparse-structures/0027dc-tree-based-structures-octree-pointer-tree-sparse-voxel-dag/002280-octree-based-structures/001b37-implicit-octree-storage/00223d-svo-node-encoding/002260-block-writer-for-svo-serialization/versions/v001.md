# Block Writer for SVO Serialization

Also called: BlockWriter class

## Overview
The Block Writer is a utility class responsible for serializing Sparse Voxel Octree (SVO) nodes into a binary file format. It solves the problem of persisting the hierarchical voxel data structure by tracking the cumulative byte and element counts during the write process. It differs from sibling serialization methods by operating at the block level, utilizing a fixed element size constant to maintain accurate statistics for the resulting binary stream.

## How it works
**Inputs and Outputs:**
- **Input:** A binary output stream and SVO node objects (specifically `Block` or `Voxel` types derived from the SVO structure).
- **Output:** Binary data written to the stream; internal state updates to `byte_count` and `element_count`.

**Data Structures:**
The class maintains two internal counters:
1. `byte_count`: Tracks the total number of bytes written to the file.
2. `element_count`: Tracks the number of elements (nodes) written.

**Parameters:**
- `Block::ELEMENT_SIZE`: A constant integer value of 4. This value is used to calculate the increment for `element_count` when a node is written.

**Steps:**
1. Initialize `byte_count` to 0 and `element_count` to 0.
2. When a node is to be serialized, invoke the `operator<<` method with the node as an argument.
3. Inside `operator<<`:
   a. Write the node's data to the binary stream.
   b. Update `byte_count` by adding the size of the written node data in bytes.
   c. Update `element_count` by adding `Block::ELEMENT_SIZE` (which is 4).

**Pseudocode:**
```python
class BlockWriter:
    def __init__(self, output_stream):
        self.stream = output_stream
        self.byte_count = 0
        self.element_count = 0
        self.ELEMENT_SIZE = 4

    def write_node(self, node):
        """
        Writes a single SVO node to the binary stream.
        :param node: The node object to serialize.
        """
        # Write node data to stream
        # Implementation detail: The specific binary layout of 'node' 
        # is defined by the SVO Node Encoding scheme [2705-svo-node-encoding.md].
        # Here we assume a generic write_bytes operation.
        node_bytes = self._serialize_node(node)
        self.stream.write(node_bytes)
        
        # Update byte count
        self.byte_count += len(node_bytes)
        
        # Update element count based on constant
        self.element_count += self.ELEMENT_SIZE

    def _serialize_node(self, node):
        """
        Serializes a node into bytes.
        Note: The exact binary packing of the node is determined by the 
        SVO Node Encoding (32-bit integer) [2705-svo-node-encoding.md].
        This helper is a placeholder for the specific bit-packing logic 
        not detailed in the Block Writer definition itself.
        """
        # [G] Placeholder for actual node serialization logic.
        # In a real implementation, this would pack the 32-bit integer 
        # representing the node into bytes.
        return node.to_bytes(4, byteorder='little')

    def get_stats(self):
        return {
            "byte_count": self.byte_count,
            "element_count": self.element_count
        }
```

**Edge Cases and Pitfalls:**
- **Precision:** The `byte_count` and `element_count` must be large enough to handle the total size of the SVO. If the SVO is very large, these counters may overflow if they are not sized appropriately (e.g., using 64-bit integers).
- **Boundaries:** The `operator<<` assumes the node data is correctly formatted according to the SVO Node Encoding. Writing malformed nodes will result in corrupted binary data.
- **Degenerate Input:** Empty or null nodes should be handled by the caller before passing to `write_node`, or the writer should check for validity.

## Operating characteristics
- **Time Complexity:** O(1) per node write, assuming fixed-size node encoding.
- **Memory Complexity:** O(1) auxiliary memory, as it only maintains counters.
- **Strengths:** Simple, efficient, and provides accurate statistics for the serialized data.
- **Limitations:** Does not handle complex compression or variable-length encoding; relies on the fixed `ELEMENT_SIZE` which may not reflect actual variable-sized nodes if the encoding changes.
- **When to use:** When serializing SVOs to a binary format that requires accurate byte and element counts.
- **When not to use:** When variable-length encoding or complex compression is required.

## Background
The Block Writer is part of the Zazen ray tracer's SVO implementation. It was developed by Gabriel Muller as part of the open-source project "zazen". The class is designed to work with the 32-bit SVO Node Encoding scheme.
