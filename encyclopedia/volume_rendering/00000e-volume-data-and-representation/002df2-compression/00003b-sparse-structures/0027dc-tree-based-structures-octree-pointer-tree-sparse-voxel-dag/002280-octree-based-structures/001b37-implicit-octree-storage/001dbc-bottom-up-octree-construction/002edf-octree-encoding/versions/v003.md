# Octree Encoding

Also called: Hierarchical spatial encoding, Macro voxel fusion

## Overview
Octree encoding is a spatial domain compression technique for volumetric data that organizes quantized voxel data hierarchically using recursive spatial subdivision [S1, unofficial]. It solves the problem of storing and processing 3D grids by fusing immediate neighboring voxels with identical values into macro voxels, thereby reducing memory footprint and I/O costs [S1, unofficial]. Unlike sibling methods that may focus on unbalanced structures or specific construction optimizations, this method specifically defines the fusion logic and the resulting storage format for the encoded tree, serving as the spatial counterpart to temporal difference encoding [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A 3D scalar array of quantized volume data.
*   **Output:** An octree structure where homogeneous regions are represented by macro voxels, and internal nodes store statistical summaries (min, max, mean) [S1, unofficial].

**Data Structures**
The method uses a linear octree representation where a single bit per node indicates whether it is a leaf or internal node [S1, unofficial].
*   **Leaf Nodes:** Represent individual voxels or macro voxels [S1, unofficial].
*   **Internal Nodes:** Store values characterizing the data within their subtree to optimize rendering, such as minimum, maximum, and mean data values [S1, unofficial].
*   **Space Overhead:** The maximum space overhead for internal nodes is bounded by $v/b$, where $v$ is the total number of voxels in the data and $b$ is the number of bytes used to store information about each internal tree node [S1, unofficial].

**Algorithm Steps**
The encoding process follows a bottom-up construction strategy:

1.  **Organization:** Organize each time step of the quantized data into an octree structure [S1, unofficial].
2.  **Recursive Fusion:** Perform recursive fusing of immediate neighboring voxels with identical values to form macro voxels [S1, unofficial].
    *   This process continues until no more voxels or macro voxels can be merged [S1, unofficial].
    *   The fusion is performed in a **bottom-up** manner [S1, unofficial].
3.  **Statistical Aggregation:** For each internal node created during the fusion, compute and store the minimum, maximum, and mean data values of the constituent voxels [S1, unofficial].

**Pseudocode**
```python
def octree_encode(volume_data):
    """
    Encodes quantized 3D volume data using bottom-up octree construction.
    volume_data: 3D list/array of quantized voxel values, assumed N x N x N.
    Returns: Root node of the octree.
    """
    class Node:
        def __init__(self, value=None, children=None):
            self.value = value
            self.children = children
            self.min = None
            self.max = None
            self.mean = None

    # Step 1: Initialize leaf nodes for the base resolution
    leaves = []
    for x in range(len(volume_data)):
        for y in range(len(volume_data[0])):
            for z in range(len(volume_data[0][0])):
                leaves.append(Node(value=volume_data[x][y][z]))

    current_level = leaves

    # Step 2 & 3: Bottom-up recursive fusion and aggregation
    while len(current_level) > 1:
        next_level = []
        for i in range(0, len(current_level), 8):
            siblings = current_level[i : i+8]
            
            # Handle boundary octants by padding with a sentinel value
            while len(siblings) < 8:
                siblings.append(Node(value=-1))

            # Check if all 8 siblings have identical values
            first_val = siblings[0].value
            identical = all(s.value == first_val for s in siblings)

            if identical:
                # Merge into a single macro voxel (internal node)
                parent = Node(value=first_val)
                parent.min = first_val
                parent.max = first_val
                parent.mean = first_val
                next_level.append(parent)
            else:
                # Cannot merge; create internal node with children
                parent = Node()
                parent.children = siblings
                # Compute statistics for rendering optimization
                vals = [s.value for s in siblings]
                parent.min = min(vals)
                parent.max = max(vals)
                parent.mean = sum(vals) / len(vals)
                next_level.append(parent)

        current_level = next_level

    return current_level[0]
```

**Parameters and Edge Cases**
*   **Quantization:** The method assumes input data has been quantized. The quality of quantization significantly influences encoding performance [S1, unofficial].
*   **Error Tolerance:** For 8-bit data, fusing voxels based on error tolerance (non-identical values) produces images generally not acceptable for visualization [S1, unofficial]. Fusion should strictly occur for identical values [S1, unofficial].
*   **Data Dependency:** Compression effectiveness is data-dependent. A data set containing many large, coherent structures usually can be effectively compressed [S1, unofficial].

## Subtopics

### [Recursive Octree Network (RocNet)](8404-recursive-octree-network-rocnet.md)
A deep recursive autoencoder network for compressing 3D voxel data into a compact latent space. It solves the problem of storing and processing 3D grids of arbitrary size by recursively merging octants from leaves to root, representing the entire octree as a small 1D feature vector. Unlike O-CNN and OctNet which perform convolution across octant boundaries, RocNet restricts convolution to within octants, and unlike OGN which focuses on up-sampling from coarse grids, RocNet creates a grid-independent latent space for arbitrary-sized inputs. Choose it when neural compression of arbitrary-sized voxel grids is required.

## Operating characteristics
*   **Time Complexity:** The bottom-up algorithm visits each data value only once and avoids recalculating evaluation data [S1, unofficial]. It is approximately two times faster than the top-down method [S1, unofficial].
*   **Memory Complexity:** The space overhead is bounded by $v/b$, where $v$ is the total number of voxels and $b$ is the bytes per internal node [S1, unofficial]. Using a linear octree, leaf indication can be as low as 1 bit per node [S1, unofficial].
*   **Strengths:** Reduces I/O costs, enables selective rendering, and allows for higher user interactivity in visualization [S1, unofficial].
*   **Limitations:** Strict fusion criteria (identical values only) limit compression on noisy 8-bit data [S1, unofficial].

## Background
Octree encoding was introduced in the context of efficient encoding and rendering of time-varying volume data [S1, unofficial]. It builds on earlier work using binary octrees for skipping transparent voxels (Levoy) and 4D octrees for volume rendering (Laur and Hanrahan) [S1, unofficial]. The method is part of a broader strategy that combines spatial domain compression (octree encoding) with temporal domain compression (difference encoding) for time-varying datasets [S1, unofficial].
