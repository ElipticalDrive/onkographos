# Recursive Octree Network (RocNet)
Also called: RocNet

## Overview
RocNet is a deep recursive autoencoder network designed for the compression of 3D voxel data into a compact latent space [S1]. It solves the problem of storing and processing 3D grids of arbitrary size by recursively merging octants from leaves to root, representing the entire octree as a small 1D feature vector [S1]. Unlike O-CNN and OctNet which perform convolution across octant boundaries, RocNet restricts convolution to within octants, and unlike OGN which focuses on up-sampling from coarse grids, RocNet creates a grid-independent latent space for arbitrary-sized inputs [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D voxel grid of binary occupancy (or other representations) converted into a standard octree structure where nodes are homogeneous (empty/full leaf) or mixed, up to a maximum depth [S1].
*   **Output (Encoder):** A compact 1D feature vector of dimension $d_{out}$ [S1].
*   **Output (Decoder):** A reconstructed octree structure and explicit voxel grids for mixed leaves [S1].

**Data Structures:**
*   **Octree Nodes:** Four types defined: empty leaf, full leaf, mixed leaf, and interior node [S1].
*   **Tree Topology:** Encoded using post-order Depth-First Search (DFS) ordering. The traversal starts at the root, goes as far down as possible through children (left to right), visits the node, and backtracks [S1].
*   **Mixed Leaf Representation:** Mixed leaf nodes are collected in post-order DFS sequence, forming a 4D binary matrix [S1].
*   **Feature Maps:**
    *   Leaf features: $R^{64 \times 4 \times 4 \times 4}$ [S1].
    *   Node features: $R^{64 \times 4 \times 4 \times 4}$ [S1].
    *   Latent vector: $R^{d_{out}}$ where $d_{out}=80$ [S1].

**Parameters:**
*   **Leaf Resolution ($k$):** $k=32$ for input grids larger than $32^3$; $k=16$ for $32^3$ grids [S1].
*   **Channels:** Leaf encoder outputs 64 channels. Intermediate node processing uses 128 channels before mapping back to 64 [S1].
*   **Activation:** Exponential Linear Unit (ELU): $f(x) = \max(0, x) + \min(0, e^x - 1)$ [S1].
*   **Normalization:** Batch Normalization (BN) applied after every 3D convolution layer in encoders and after transposed convolutions in decoders (except final leaf decoder layer) [S1].

**Algorithm Steps:**

1.  **Octree Construction:** Convert the input voxel grid into an octree. Recursively decompose until nodes are homogeneous (all voxels occupied or empty) or maximum depth is reached [S1].
2.  **Leaf Encoding:** For each mixed leaf node, encode the $k \times k \times k$ binary voxel block into a $64 \times 4 \times 4 \times 4$ feature map using a sequence of 3D Convolution + BN + ELU layers with kernel size 4 and stride 2 [S1].
    *   *Leaf Skip:* Empty and full leaf nodes are passed directly to the next stage without convolution [S1].
3.  **Node Encoding (Bottom-Up):** Recursively merge child features into parent features until the root is reached.
    *   For each interior node with children $F_1, \dots, F_8$:
        1.  Lift channels from 64 to 128 using $\phi: R^{64 \times 4 \times 4 \times 4} \to R^{128 \times 4 \times 4 \times 4}$ (1x1x1 3D Conv).
        2.  Apply ELU.
        3.  Apply 3D Convolution + BN to each child.
        4.  Sum the results.
        5.  Map channels back to 64 using $\psi$ (inverse of $\phi$).
    *   Formula:
        $$ F_p = \psi\left( \sum_{i=1}^{8} \text{elu}(\phi(F_i)) \right) $$
        where $F_p$ is the parent feature ($R^{64 \times 4 \times 4 \times 4}$) and $F_i$ are child features [S1].
    *   *Note:* Node encoders do not share weights across different depths [S1].
4.  **Tree Encoding:** Flatten the root feature map ($64 \times 4 \times 4 \times 4$) into a 1D vector of size $d_{out}$ using a 3D Convolution layer with kernel size 4 and stride 1 [S1].
5.  **Node Classification (Testing Only):** Use a node classifier to label each node as empty, full, mixed, or interior. The classifier has the same layers as the tree encoder plus a fully-connected layer, trained with cross-entropy loss [S1].
6.  **Tree Decoding:** Convert the 1D latent vector back to a $64 \times 4 \times 4 \times 4$ feature map using a transposed convolutional layer (kernel 4, stride 1) followed by ELU [S1].
7.  **Node Decoding (Top-Down):** Recursively decode the root feature to leaf features.
    *   For each interior node, apply a 3D convolutional layer for the node itself and convolutional layers for each of its 8 children, followed by BN [S1].
    *   *Note:* Node decoders do not share weights across different depths [S1].
8.  **Leaf Decoding:** For nodes classified as mixed leaves, decode the feature map back to a $k \times k \times k$ binary voxel grid using stacked transposed 3D convolutions (kernel 4, stride 2, padding 1) with BN and ELU, except the final layer which uses Sigmoid activation without BN [S1]. Empty and full leaves are recovered directly from topology [S1].

def rocnet_decode(latent_vector, node_labels):

    Full decoding pipeline.
    latent_vector: 1D vector.

## Subtopics

### RocNet Node Classifier
A 4-category classifier used during the testing stage to recover octree topology by labeling each node as empty, full, mixed leaf, or interior node [S1]. It has the same layers as the tree encoder except for an additional fully-connected layer [S1]. The classifier is disabled during training and is only used for prediction in the testing stage to decide whether to stop decoding (empty/full leaf), use leaf decoder (mixed leaf), or use node decoder (interior node) [S1]. It is trained using cross-entropy loss [S1].

## Operating characteristics
*   **Memory:** Compresses voxel grids of any size down to a very small latent space. Experiments show compression of $32^3$, $64^3$, and $128^3$ grids down to just 80 floats [S1].
*   **Time:** Saves computational time by skipping 3D convolutions for empty and full leaf nodes ("leaf skips") [S1].
*   **Performance:** Maintains accuracy while consuming less memory and shorter training times compared to existing methods, especially in 3D reconstruction tasks [S1].
*   **Limitations:** Node encoders and decoders do not share weights across different depths, which may increase parameter count compared to weight-sharing recursive networks [S1].

## Background
RocNet was introduced by Steven and Brendan McCane from the University of Otago in August 2020 [S1]. It is based on the concept of recursive autoencoders originally proposed for grammar tree parsing in natural language and applied to graphics in GRASS [S1]. It differs from OGN which focuses on decoding only [S1].
