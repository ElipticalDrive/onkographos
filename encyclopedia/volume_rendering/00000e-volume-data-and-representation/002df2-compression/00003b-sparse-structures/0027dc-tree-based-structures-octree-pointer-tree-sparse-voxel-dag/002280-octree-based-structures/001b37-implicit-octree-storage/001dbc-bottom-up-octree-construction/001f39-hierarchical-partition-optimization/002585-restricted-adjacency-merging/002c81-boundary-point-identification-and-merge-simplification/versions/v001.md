# Boundary Point Identification and Merge Simplification

Also called: Boundary Point Identification, Merge Simplification, Time Lag Method (for simplification constraint)

## Overview
Boundary Point Identification and Merge Simplification is a post-processing step for merging adjacent spatial blocks (sub-volumes) in parallel isosurface extraction. It resolves geometric discontinuities at block boundaries by identifying shared vertices and simplifying the resulting mesh while preserving topological integrity. It differs from [Restricted Adjacency Merging](3556-restricted-adjacency-merging.md) by handling the actual geometric vertex alignment and mesh simplification constraints after the topological merge eligibility has been determined.

## How it works
**Inputs:** Two adjacent merged blocks containing extracted isosurface triangles; the shared boundary geometry; the error criterion $E_0$ used during initial surface extraction; the radius $rad(c)$ associated with the critical point $c$ for each triangle.
**Outputs:** A single, simplified, watertight mesh component for the merged region.

**Data Structures:**
*   **Vertex List:** Stores 3D coordinates $(x, y, z)$ and associated critical point radius $rad(c)$.
*   **Triangle List:** Stores indices into the Vertex List.
*   **Boundary Edge Set:** Set of edges lying on the shared interface between the two blocks.

**Steps:**

1.  **Identify Common Points:**
    Extract vertices from both blocks that lie on the shared boundary. Due to numerical inaccuracies in vertex extraction, exact coordinate comparison is insufficient. Instead, leverage the property of the marching-cubes algorithm: a cell edge generates at most one intersection point. Therefore, vertices belonging to the same cell edge in adjacent blocks are geometrically identical and must be merged into a single vertex.
    *   *Implementation Note:* Group vertices by their originating cell edge index. If multiple vertices map to the same edge, merge them into one representative vertex. The representative's position can be the average of the merged vertices to minimize numerical drift.

2.  **Merge Vertices:**
    Replace duplicate vertices on the boundary with the single representative vertex. Update all triangle indices referencing these vertices to point to the new representative.

3.  **Simplify Pasted Area:**
    Apply mesh simplification to the merged region using the same error criterion $E_0$ used during the initial surface extraction. This reduces triangle count while maintaining visual fidelity.
    *   *Constraint (Time Lag Method):* During simplification, edge contraction is prevented if the contraction would violate the inclusion property of the critical point's sphere. Specifically, for an edge $ab$ with midpoint $m$, let $rad(c)$ be the radius of the sphere centered at $m$ associated with the critical point $c$. The contraction of edge $ab$ is **prevented** as long as this sphere is not totally included in the merged blocks. This ensures that the simplification does not remove features that are only partially represented in the current merged context, preventing artifacts caused by "time lag" in refinement [S1].

4.  **Dump Component:**
    Once merging and simplification are complete, dump the finished mesh component to disk or memory buffer.

**Pseudocode:**

    """
    block_a, block_b: Mesh objects with vertices and triangles
    shared_boundary_edges: Set of edge identifiers (e.g., cell_edge_index) present in both blocks
    E0: Error threshold for simplification
    rad_c_map: Function mapping triangle index to critical point radius rad(c)
    """
    
    # Step 1 & 2: Identify and Merge Common Points
    # Map cell_edge_index -> list of vertex indices from both blocks
    edge_to_vertices = defaultdict(list)
    
    for edge_idx in shared_boundary_edges:
        # Find all vertices in block_a belonging to this edge
        for v_idx in block_a.vertices_on_edge(edge_idx):
            edge_to_vertices[edge_idx].append((v_idx, block_a.vertices[v_idx].pos))
        # Find all vertices in block_b belonging to this edge
        for v_idx in block_b.vertices_on_edge(edge_idx):
            edge_to_vertices[edge_idx].append((v_idx, block_b.vertices[v_idx].pos))
            
    # Merge vertices for each edge
    merged_vertices = {} # old_idx -> new_idx
    new_vertex_list = []
    vertex_remap = {} # old_idx -> new_idx (global remap)
    
    # Process Block A vertices first to establish base
    for v_idx, v in enumerate(block_a.vertices):
        vertex_remap[v_idx] = len(new_vertex_list)
        new_vertex_list.append(v)
        
    # Process Block B vertices, merging if on boundary
    for v_idx, v in enumerate(block_b.vertices):
        # Check if this vertex is on a shared boundary edge
        is_boundary = False
        for edge_idx in shared_boundary_edges:
            if v_idx in block_b.vertices_on_edge(edge_idx):
                is_boundary = True
                break
                
        if is_boundary:
            # Find the representative vertex from the same edge in Block A
            # Since we merged by edge, we look up the edge's vertices
            # Note: In practice, we need to map block_b's edge indices to block_a's
            # Assuming edge_idx is global or mapped consistently
            rep_idx = None
            for old_idx, pos in edge_to_vertices[edge_idx]:
                if old_idx in block_a.vertex_indices: # It's from block A
                    rep_idx = vertex_remap[old_idx]
                    break
            
            if rep_idx is not None:
                vertex_remap[v_idx] = rep_idx
            else:
                # Fallback: should not happen if boundary identification is correct
                vertex_remap[v_idx] = len(new_vertex_list)
                new_vertex_list.append(v)
        else:
            vertex_remap[v_idx] = len(new_vertex_list)
            new_vertex_list.append(v)
            
    # Create merged vertex list
    merged_vertices = new_vertex_list
    
    # Remap triangles from both blocks
    merged_triangles = []
    for tri in block_a.triangles:
        new_indices = [vertex_remap[i] for i in tri]
        merged_triangles.append(new_indices)
        
    for tri in block_b.triangles:
        new_indices = [vertex_remap[i] for i in tri]
        merged_triangles.append(new_indices)
        
    # Step 3: Simplify Pasted Area
    # Apply simplification with constraint
    simplified_triangles = simplify_mesh(merged_triangles, merged_vertices, E0, 
                                         rad_c_map, shared_boundary_edges)
                                         
    # Step 4: Dump Component
    return Mesh(merged_vertices, simplified_triangles)

**Parameters:**
*   $E_0$: Error criterion for simplification. Typical value: Same as used in initial extraction [S1].
*   $rad(c)$: Radius of the sphere associated with the critical point $c$. Determined during extraction [S1].

**Edge Cases and Pitfalls:**
*   **Numerical Inaccuracy:** Direct coordinate comparison fails. Must use cell-edge identity for merging [S1].
*   **Sphere Inclusion:** The "time lag" constraint prevents over-simplification near boundaries. If the sphere is not fully included, the edge is preserved, potentially leaving higher triangle counts at boundaries [S1].
*   **Degenerate Input:** If blocks share no boundary (e.g., non-adjacent), the merge step is skipped.

## Subtopics

### Boundary Persistence
A metric quantifying the separability between two adjacent valley cells in a 2D density plot, used to guide noise suppression and cell merging in transfer function design [S2]. It measures the degree of separability of peaks on adjacent cells [S2].

### Valley Cell Simplification
A process to remove noisy small valley cells by merging them based on boundary persistence thresholds. It iteratively eliminates boundaries with the smallest persistence values until a threshold is reached. The threshold range is typically 0.1% to 1.5% of the maximal persistence value [S2].

## Operating characteristics
*   **Time Complexity:** Dominated by the simplification step, which is typically $O(N \log N)$ or $O(N)$ depending on the simplification algorithm, where $N$ is the number of triangles. Boundary identification is $O(E)$, where $E$ is the number of boundary edges.
*   **Memory Complexity:** Requires storing the merged mesh and boundary edge sets. No significant additional memory beyond the output mesh.
*   **Strengths:** Ensures watertightness and geometric continuity across block boundaries. The time lag method prevents topological errors near boundaries.
*   **Limitations:** The sphere inclusion check can be computationally expensive if not optimized. Over-conservative simplification may leave unnecessary triangles at boundaries.
*   **When to Use:** When parallel isosurface extraction is performed on decomposed volumes and the resulting meshes must be merged into a single coherent surface.

## Background
The method was introduced in the context of parallel extraction and simplification of large isosurfaces using an extended tandem algorithm [S1]. It addresses the issue of discontinuities and artifacts that arise when merging surfaces extracted from adjacent sub-volumes. The "time lag" method for simplification constraints was shown to improve triangulation quality near block boundaries [S1].
