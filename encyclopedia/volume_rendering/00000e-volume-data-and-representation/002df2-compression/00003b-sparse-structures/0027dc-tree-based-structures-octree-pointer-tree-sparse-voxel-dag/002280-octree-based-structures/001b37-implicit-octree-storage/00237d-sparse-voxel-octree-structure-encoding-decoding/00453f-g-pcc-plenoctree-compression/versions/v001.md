# G-PCC PlenOctree Compression

Also called: PlenOctree Attribute Compression via G-PCC, RAHT/Predlift PlenOctree Compression

## Overview
G-PCC PlenOctree Compression is a method for compressing PlenOctree models by encoding the geometry losslessly and the attributes (opacity $\sigma$ and spherical harmonic coefficients $k$) lossily using Geometry-based Point Cloud Coding (G-PCC) standards [S1]. It differs from sibling methods like [Octree File I/O Format](5032-octree-file-i-o-format.md) by treating the voxel grid as a point cloud to leverage standard PC codecs, and from [Sparse Voxel DAG](5984-sparse-voxel-dag.md) by preserving the explicit octree structure rather than merging identical nodes [S1].

## How it works
**Inputs:** A PlenOctree of depth $M$ with nodes containing opacity $\sigma$ and spherical harmonic (SH) coefficients $k$.
**Outputs:** A compressed bitstream containing lossless geometry and lossy attributes.

**Data Structures:**
The PlenOctree is viewed as a depth-$M$ voxelized point cloud $P$ of $N$ voxels.
*   **Geometry Coordinates ($x_{pc}$):** Derived from the grid indices $x_{oct}(n) = [X_n, Y_n, Z_n]$ of the $n$-th child node.
    $$x_{pc} = x_{oct} \times 2^M - 0.5$$
*   **Attributes ($s(n)$):** A vector for each point containing the opacity and SH coefficients:
    $$s(n) = [\sigma_n, k^0_{n0}, k^{-1}_{n1}, k^0_{n1}, k^1_{n1}, \dots, k^\ell_{n\ell}]$$
    where $k^\ell_{n\ell} \in \mathbb{R}^3$ represents the SH coefficients of degree $\ell$ [S1].

**Steps:**
1.  **Geometry Encoding:** Encode $x_{pc}$ losslessly using direct geometry quantization via octrees. This preserves the original PlenOctree structure [S1].
2.  **Attribute Scaling:** Scale each attribute individually for each color channel to the range $[0, T]$.
    *   For $\sigma$, $T = 2047$ [S1].
    *   For SH DC coefficients ($\ell=0, m=0$), $T = 1023$ [S1].
    *   For SH AC coefficients ($\ell \neq 0$), $T = 511$ [S1].
    *   Scaling on SHs is performed over their absolute values, with signs sent as side information [S1].
3.  **Attribute Coding:** Encode the scaled attributes $s$ using G-PCC attribute coders based on either RAHT or Predlift transforms, using standard quantization stepsizes [S1].
4.  **Decoding:** Decode the attributes and unscale them to reconstruct the point cloud $\hat{P}$ [S1].
5.  **Reconstruction:** Reconstruct the PlenOctree using the losslessly encoded geometry $x_{pc}$ of $\hat{P}$ and the lossy reconstructed $\sigma$ and $k$, maintaining the original octree structure [S1].

**Pseudocode:**
```python
def compress_plenoctree(plen_octree, depth_M):
    # 1. Extract geometry and attributes
    # x_oct is a list of [X, Y, Z] indices for all N voxels
    x_oct = get_voxel_indices(plen_octree)
    N = len(x_oct)
    
    # Convert to point cloud coordinates
    # x_pc = x_oct * 2^M - 0.5
    scale_factor = 2 ** depth_M
    x_pc = [(x * scale_factor - 0.5, y * scale_factor - 0.5, z * scale_factor - 0.5) 
            for x, y, z in x_oct]
    
    # 2. Prepare attributes
    # s(n) = [sigma, k_00, k_-11, k_01, k_11, ...]
    attributes = []
    for node in plen_octree.nodes:
        sigma = node.sigma
        sh_coeffs = node.sh_coeffs # List of R^3 vectors for degrees 0 to L
        attr = [sigma] + [coeff for coeff in sh_coeffs]
        attributes.append(attr)
    
    # 3. Scale attributes
    # Define T values
    T_sigma = 2047
    T_dc = 1023
    T_ac = 511
    
    scaled_attributes = []
    signs = [] # Side information for SH signs
    
    for attr in attributes:
        scaled_attr = []
        current_signs = []
        
        # Scale sigma
        # Assuming sigma is in [0, 1] or similar, map to [0, T_sigma]
        # Note: Source implies direct scaling to range [0, T]
        scaled_sigma = attr[0] * T_sigma
        scaled_attr.append(scaled_sigma)
        
        # Scale SH coefficients
        # attr[1:] contains SH coefficients. 
        # Index 1 is DC (l=0, m=0). Indices 2+ are AC (l!=0).
        for i, coeff in enumerate(attr[1:]):
            # coeff is R^3 vector
            abs_coeff = [abs(c) for c in coeff]
            sign_vec = [1 if c >= 0 else -1 for c in coeff]
            
            if i == 0: # DC
                T = T_dc
            else: # AC
                T = T_ac
                
            scaled_coeff = [c * T for c in abs_coeff]
            scaled_attr.extend(scaled_coeff)
            current_signs.extend(sign_vec)
            
        scaled_attributes.append(scaled_attr)
        signs.append(current_signs)
        
    # 4. Encode Geometry Losslessly
    # Using direct geometry quantization via octrees (as per [S1])
    # This step is handled by the G-PCC geometry encoder
    geometry_bitstream = encode_geometry_lossless(x_pc)
    
    # 5. Encode Attributes Lossily
    # Choose between RAHT or Predlift. RAHT is generally better for PlenOctrees [S1].
    # Standard quantization stepsizes are used [S1].
    attribute_bitstream = encode_attributes_gpc(scaled_attributes, method="RAHT")
    
    # 6. Pack side information (SH signs)
    # Signs are sent as side information [S1]
    signs_bitstream = encode_signs(signs)
    
    return geometry_bitstream, attribute_bitstream, signs_bitstream

def decompress_plenoctree(geometry_bitstream, attribute_bitstream, signs_bitstream, depth_M):
    # 1. Decode Geometry
    x_pc = decode_geometry_lossless(geometry_bitstream)
    
    # 2. Decode Attributes
    scaled_attributes = decode_attributes_gpc(attribute_bitstream)
    
    # 3. Decode Signs
    signs = decode_signs(signs_bitstream)
    
    # 4. Unscale Attributes
    attributes = []
    for i, scaled_attr in enumerate(scaled_attributes):
        unscaled_attr = []
        current_signs = signs[i]
        
        # Unscale sigma
        sigma = scaled_attr[0] / 2047
        unscaled_attr.append(sigma)
        
        # Unscale SH coefficients
        # Reconstruct R^3 vectors
        sh_idx = 0
        for i_sh in range(len(scaled_attr) - 1):
            # Each SH coeff is 3 values
            abs_vals = [scaled_attr[1 + sh_idx + j] for j in range(3)]
            sign_vals = [current_signs[sh_idx + j] for j in range(3)]
            
            # Reconstruct original sign
            coeff = [a * s for a, s in zip(abs_vals, sign_vals)]
            unscaled_attr.append(coeff)
            sh_idx += 3
            
        attributes.append(unscaled_attr)
        
    # 5. Reconstruct PlenOctree
    # Map x_pc back to grid indices to rebuild structure
    scale_factor = 2 ** depth_M
    plen_octree = PlenOctree(depth=depth_M)
    
    for x_pc_val, attr in zip(x_pc, attributes):
        # Reverse coordinate transformation
        # x_pc = x_oct * 2^M - 0.5  =>  x_oct = (x_pc + 0.5) / 2^M
        x_oct_val = [(int((c + 0.5) / scale_factor)) for c in x_pc_val]
        
        # Create node with attributes
        sigma = attr[0]
        sh_coeffs = attr[1:]
        
        node = PlenOctreeNode(sigma=sigma, sh_coeffs=sh_coeffs)
        plen_octree.set_node(x_oct_val, node)
        
    return plen_octree
```

**Parameters:**
*   $T_\sigma = 2047$: Scaling factor for opacity [S1].
*   $T_{DC} = 1023$: Scaling factor for SH DC coefficients ($\ell=0, m=0$) [S1].
*   $T_{AC} = 511$: Scaling factor for SH AC coefficients ($\ell \neq 0$) [S1].
*   Grid Size: Expected to be 512 for the $T_\sigma$ calculation [S1].

**Edge Cases and Pitfalls:**
*   **KLT Decorrelation:** Applying Karhunen-Loève Transform (KLT) over SH-transformed coefficients ("RAHT+KLT") does not improve performance because SH decomposition already decorrelates the channels sufficiently [S1].
*   **Method Selection:** RAHT outperforms Predlift due to the low correlation of neighbors' attributes in PlenOctrees [S1].
*   **Precision:** The scaling step introduces slight quality degradation, which is inherent to the lossy compression [S1].

## Operating characteristics
*   **Compression Ratio:** The lossy compression method provides a size reduction of almost 50 times compared to the uncompressed solution [S1]. The lossless approach reduces the model's average size by around 8 times [S1].
*   **Quality:** The RAHT-based approach is approximately three times smaller than the compressed '0.4 GB' curve of the reference PlenOctree while being more than 0.6 dB better in PSNR [S1]. The lossy method causes slight performance degradation compared to the uncompressed solution but maintains quality similar to the original PlenOctrees [S1].
*   **Performance:** The method maintains the high rendering speed of PlenOctrees, being faster by 1.5+ times compared to the original PlenOctrees [S1].
*   **Strengths:** Significant size reduction while maintaining rendering speed and quality. Outperforms SNeRG and KiloNeRF in size/quality trade-off [S1].
*   **Limitations:** Slight quality degradation due to scaling. DIVeR outperforms in quality, though this method is ~30% smaller [S1].

## Background
The method was proposed to address the large size disadvantages of PlenOctree models while keeping rendering quality and speed [S1]. It targets changes in the NN training, optimization, and compression stages of the PlenOctree pipeline [S1]. The work utilizes G-PCC standards from the Moving Picture Experts Group (MPEG) [S1]. Experiments were conducted on the NeRF-Synthetic 360 dataset (Blender dataset) [S1].
