# OpenVDB File Format Parsing

Also called: OpenVDB deserialization, VDB file reader

## Overview
This method describes the binary parsing and deserialization of the OpenVDB (VDB) file format to reconstruct the hierarchical sparse voxel grid in memory [S1, unofficial]. It converts the compact, compressed on-disk representation into a traversable in-memory tree structure suitable for rendering or simulation [S1, unofficial]. It is distinguished from generic VDB loading by its explicit handling of the specific binary layout of Node5 and Node4 hierarchies, including the complex logic for decompressing active masks and inactive values [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input**: A binary file stream conforming to the OpenVDB specification [S1, unofficial].
*   **Output**: An in-memory representation of the grid, typically structured as a `GridDescriptor` containing a `RootNode` (or `Tree`), which holds the sparse voxel data [S1, unofficial].

**Data Structures**
1.  **GridDescriptor**: `name` (length-prefixed string), `grid_type` (length-prefixed string), `instance_parent` (length-prefixed string), `grid_pos` (`u64` little-endian), `block_pos` (`u64` little-endian), `end_pos` (`u64` little-endian), `compression` (enum/flags), `meta_data` (`Metadata`) [S1, unofficial].
2.  **Metadata**: `HashMap<String, MetadataValue>` [S1, unofficial]. `MetadataValue` variants: `String`, `Bool`, `I32`, `I64`, `Float`, `Vec3i`, `Unknown { name: String, data: Vec<u8> }` [S1, unofficial].
3.  **NodeHeader**: `child_mask` (`BitVec<u64>`, LSB0, size $N::SIZE$), `value_mask` (`BitVec<u64>`, LSB0, size $N::SIZE$), `data` (`Vec<T>`), `log_2_dim` (`usize`) [S1, unofficial].
4.  **RootNode**: `map` (`HashMap<RootKey, RootData>`), `background` ($T$) [S1, unofficial]. `RootData` variants: `Tile<T>(value, active)` or `Node(Box<Node5>)` [S1, unofficial].
5.  **Node5**: Contains an array of `InternalData` (either `Tile<T>` or `Node(Box<Node4>)`) [S1, unofficial].
6.  **Node4**: Contains an array of `InternalData` (either `Tile<T>` or `Node(Box<Node3>)`) [S1, unofficial].
7.  **Node3**: Leaf node containing the actual voxel values [S1, unofficial].

**Numbered Steps**
1.  Read `name`, `grid_type`, `instance_parent` as length-prefixed strings [S1, unofficial].
2.  Read `grid_pos`, `block_pos`, `end_pos` as `u64` little-endian integers [S1, unofficial].
3.  If file version $\ge$ `OPENVDB_FILE_VERSION_NODE_MASK_COMPRESSION`, read `compression` flag as `u32` little-endian; otherwise, use default [S1, unofficial].
4.  Read metadata count as `u32` little-endian [S1, unofficial].
5.  For each metadata entry: read `name` and `type` as length-prefixed strings, read `length` as `u32` little-endian, then parse value based on `type` (`"string"`, `"bool"`, `"int32"`, `"int64"`, `"float"`, `"vec3i"`, or raw bytes for unknown) [S1, unofficial].
6.  Read `buffer_count` as `u32` little-endian [S1, unofficial].
7.  Read `root_node_background` as `u32` little-endian, converted to type $T$ [S1, unofficial].
8.  Read `num_tiles` and `num_node5s` as `u32` little-endian [S1, unofficial].
9.  Iterate tiles: read `origin` as `vec3i` (three `i32`), compute `root_key`, read `value` as `u32` little-endian converted to $T$, read `active` flag as `u8` (1 = active, 0 = inactive), store as `RootData::Tile<T>(value, active)` [S1, unofficial].
10. Iterate Node5s: read `origin` as `vec3i`, compute `root_key`, read internal node header (`child_mask` and `value_mask` as `u64` bitvectors, compressed data), construct `Node5`, then recursively read Node4 children for each active child in `child_mask` [S1, unofficial].
11. For each active child in Node4: read `value_mask` as `u64` bitvector, construct `Node3` leaf, and assign to Node4 data array [S1, unofficial].
12. Read compressed node data: read metadata byte if version $\ge$ mask compression; read 0, 1, or 2 inactive values based on metadata; read selection mask if metadata indicates masked inactive values; compute active count based on compression flags and metadata; handle f16/f32 type conversion; expand active mask data to full node size if needed [S1, unofficial].

**Pseudocode**
```python
def read_compressed(grid_descriptor, size, value_mask, reader):
    """
    Reads and decompresses node data for a Node5 or Node4.
    Args:
        grid_descriptor: Object with .compression (set of flags) and .meta_data (dict).
        size: Total number of elements in the node (e.g., 128 for Node5, 64 for Node4).
        value_mask: List of booleans indicating which elements are active.
        reader: Binary reader with .header, .read_u8(), .read_u64_into(), .read_bytes() methods.
    Returns:
        List[T]: Decompressed array of values.
    """
    # NodeMetaData enum mapping from source [G]
    META_DATA_MAP = {0: "NoMaskAndAllVals", 1: "MaskAndOneInactiveVal", 2: "MaskAndTwoInactiveVals"}
    meta_data = META_DATA_MAP.get(reader.read_u8(), "NoMaskAndAllVals") if reader.header.file_version >= OPENVDB_FILE_VERSION_NODE_MASK_COMPRESSION else "NoMaskAndAllVals"

    inactive_val0 = 0  # Type-dependent zero value [G]
    inactive_val1 = 0  # Type-dependent zero value [G]

    if meta_data in ("MaskAndOneInactiveVal", "NoMaskAndOneInactiveVal"):
        inactive_val0 = reader.read_bytes(size_of_value(grid_descriptor))  # [G] Step not given in sources
    elif meta_data == "MaskAndTwoInactiveVals":
        inactive_val0 = reader.read_bytes(size_of_value(grid_descriptor))  # [G] Step not given in sources
        inactive_val1 = reader.read_bytes(size_of_value(grid_descriptor))  # [G] Step not given in sources

    selection_mask = [False] * size
    if meta_data in ("MaskAndNoInactiveVals", "MaskAndOneInactiveVal", "MaskAndTwoInactiveVals"):
        reader.read_u64_into(selection_mask)  # [G] Step not given in sources

    # Compute active count based on compression flags and metadata [S1, unofficial]
    if (grid_descriptor.compression & Compression.ACTIVE_MASK) and \
       meta_data != "NoMaskAndAllVals" and \
       reader.header.file_version >= OPENVDB_FILE_VERSION_NODE_MASK_COMPRESSION:
        count = sum(value_mask)
    else:
        count = size

    expected_type = type_of(grid_descriptor)  # [G] Step not given in sources
    real_type = "f16" if grid_descriptor.meta_data.is_half_float() else "f32"

    # Decompress data. Sources note Blosc is used, but exact routine is not given [G]
    raw_data = decompress_blosc(grid_descriptor, count)  # [G] Step not given in sources

    # Handle type conversion (f16/f32) [S1, unofficial]
    if expected_type == real_type:
        data = raw_data
    elif expected_type == "f16" and real_type == "f32":
        data = [f16_from_f32(v) for v in raw_data]  # [G] Step not given in sources
    elif expected_type == "f32" and real_type == "f16":
        data = [f16_to_f32(v) for v in raw_data]  # [G] Step not given in sources
    elif real_type == "f16":
        data = [T_from_f16_bites(v) for v in raw_data]  # [G] Step not given in sources
    elif real_type == "f32":
        data = [T_from_f32_bites(v) for v in raw_data]  # [G] Step not given in sources
    else:
        raise RuntimeError("Unreachable type combination")

    # Expand active mask data to full node size if needed [S1, unofficial]
    if (grid_descriptor.compression & Compression.ACTIVE_MASK) and len(data) != size:
        expanded = [0] * size  # Type-dependent zero value [G]
        read_idx = 0
        for dest_idx in range(size):
            if value_mask[dest_idx]:
                expanded[dest_idx] = data[read_idx]
                read_idx += 1
            elif selection_mask[dest_idx]:
                expanded[dest_idx] = inactive_val1
            else:
                expanded[dest_idx] = inactive_val0
        return expanded
    return data
```

**Pitfalls**
*   Multi-buffer trees are not supported; the reader explicitly panics or errors if `buffer_count != 1` [S1, unofficial].
*   Half-float storage logic may be incomplete; uncertainty exists regarding whether half-floats take 4 bytes in the file format [S1, unofficial].
*   Blosc decompression fails if the uncompressed size (`nbytes`) is 0, returning `UnsupportedBloscFormat` error [S1, unofficial].
*   Active mask expansion requires careful index tracking: reads from the compressed data array only when `value_mask[dest_idx]` is true, otherwise assigns `inactive_val1` or `inactive_val0` based on `selection_mask` [S1, unofficial].

## Subtopics

### [OpenVDB Import via Python](7124-openvdb-import-via-python.md)
This method describes the process of converting seismic SEG-Y data into the OpenVDB format using Python, and subsequently importing that VDB file into a rendering engine (specifically Unreal Engine 5) for sparse voxel texture (SVT) rendering. It addresses the problem of handling massive datasets (e.g., 4.4 GB) that exceed standard 32-bit integer limits for memory addressing and buffer sizes, which causes import crashes and rendering artifacts. It is distinguished from generic VDB loading by its specific focus on the Python-side conversion pipeline and the subsequent engine-side integer overflow fixes required for large-scale sparse volumes.
