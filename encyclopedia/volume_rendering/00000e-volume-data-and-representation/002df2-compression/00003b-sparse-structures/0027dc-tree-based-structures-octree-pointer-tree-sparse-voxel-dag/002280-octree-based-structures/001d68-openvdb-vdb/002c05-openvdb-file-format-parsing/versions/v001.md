# OpenVDB File Format Parsing

Also called: OpenVDB deserialization, VDB file reader

## Overview
This method describes the binary parsing of the OpenVDB file format to reconstruct sparse voxel grids in memory. It solves the problem of loading hierarchical, compressed volumetric data from disk into a traversable tree structure. Unlike raw voxel grids, this method handles sparse storage via Node5 and Node4 internal nodes, and Node3 leaf nodes, supporting both active mask compression and value compression [S1, unofficial]. It differs from [NanoVDB Linear Representation](1527-nanovdb-linear-representation.md) by maintaining a hierarchical tree structure in memory rather than a flat linear array, and from [VDB Volume Rendering with OpenVDB/NanoVDB](804-vdb-volume-rendering-with-openvdb-nanovdb.md) by focusing solely on data loading rather than rendering traversal.

## How it works
### Inputs and Outputs
- **Input**: A binary file stream conforming to the OpenVDB file format specification.
- **Output**: A `GridDescriptor` object containing metadata, and a root tree structure (typically a `RootNode`) containing the voxel data.

### Data Structures
The parser constructs the following in-memory structures:

1.  **GridDescriptor**:
    -   `name`: String (length-prefixed).
    -   `grid_type`: String (length-prefixed).
    -   `instance_parent`: String (length-prefixed).
    -   `grid_pos`: u64 (little-endian).
    -   `block_pos`: u64 (little-endian).
    -   `end_pos`: u64 (little-endian).
    -   `compression`: Enum/Flags indicating compression types (e.g., `ACTIVE_MASK`, `BLOSC`).
    -   `meta_data`: HashMap<String, MetadataValue>.

2.  **MetadataValue**:
    -   Variants: `String`, `Bool`, `I32`, `I64`, `Float`, `Vec3i`, `Unknown { name: String, data: Vec<u8> }`.
    -   Stored as 0-indexed tuple struct `.0` in the source implementation [S1, unofficial].

3.  **NodeHeader** (for Node5 and Node4):
    -   `child_mask`: BitVec<u64> (LSB0, size $N::SIZE$). Indicates which children exist.
    -   `value_mask`: BitVec<u64> (LSB0, size $N::SIZE$). Indicates which children have non-background values.
    -   `data`: `Vec<T>`. Compressed or raw values.
    -   `log_2_dim`: usize.

4.  **RootNode**:
    -   `map`: HashMap<RootKey, RootData>.
    -   `background`: T (the background value for the grid).
    -   `RootData` variants:
        -   `Tile<T>(value: T, active: bool)`: Represents a uniform tile.
        -   `Node(Box<Node5>)`: Represents a child internal node.

5.  **Node5**:
    -   Contains an array of `InternalData` (either `Tile<T>` or `Node(Box<Node4>)`).
    -   Indexed by the 5-bit key derived from the origin.

6.  **Node4**:
    -   Contains an array of `InternalData` (either `Tile<T>` or `Node(Box<Node3>)`).
    -   Indexed by the 4-bit key.

7.  **Node3**:
    -   Leaf node containing the actual voxel values.
    -   Size is $8 \times 8 \times 8 = 512$ values.

### Numbered Steps

1.  **Read Grid Descriptor**:
    -   Read `name`, `grid_type`, `instance_parent` as length-prefixed strings.
    -   Read `grid_pos`, `block_pos`, `end_pos` as u64 little-endian integers.
    -   If file version $\ge$ `OPENVDB_FILE_VERSION_NODE_MASK_COMPRESSION`, read `compression` flag as u32 little-endian; otherwise, set to default (no compression).
    -   Read metadata count as u32 little-endian. For each entry:
        -   Read name and type as length-prefixed strings.
        -   Read length as u32 little-endian.
        -   Parse value based on type string: "string", "bool", "int32", "int64", "float", "vec3i", or raw bytes for unknown types.

2.  **Read Tree Topology Header**:
    -   Read buffer count as u32 little-endian. **Pitfall**: Must equal 1. Multi-buffer trees are not supported [S1, unofficial].
    -   Read root node background value as u32 little-endian, converted to type T.
    -   Read number of tiles and Node5s as u32 little-endian.

3.  **Iterate Tiles**:
    -   For each tile:
        -   Read origin as `vec3i`.
        -   Compute `root_key` from origin.
        -   Read value as u32 little-endian, converted to T.
        -   Read active flag as u8 (1=active, 0=inactive).
        -   Store as `RootData::Tile<T>(value, active)`.

4.  **Iterate Node5s**:
    -   For each Node5:
        -   Read origin as `vec3i`.
        -   Compute `root_key`.
        -   Read internal node header:
            -   Read `child_mask` as u64 bitvector.
            -   Read `value_mask` as u64 bitvector.
            -   Read compressed data payload.
        -   Construct `Node5`.
        -   For each active child in `child_mask`:
            -   Recursively read Node4 children.

5.  **Read Node4 Children**:
    -   For each active child in Node5's `child_mask`:
        -   Read `value_mask` as u64 bitvector.
        -   Construct `Node3` leaf.
        -   Assign to Node4 data array.

6.  **Read Compressed Node Data**:
    -   For each node (Node5 or Node4) with compressed data:
        -   Read metadata byte if file version $\ge$ `OPENVDB_FILE_VERSION_NODE_MASK_COMPRESSION` [S1, unofficial].
        -   Determine inactive values:
            -   Read 0, 1, or 2 inactive values based on metadata.
            -   Read selection mask if metadata indicates masked inactive values.
        -   Compute active count based on compression flags and metadata.
        -   Handle f16/f32 type conversion if necessary.
        -   Expand active mask data to full node size if needed.

### Pseudocode

```python
def parse_openvdb_file(file_stream):
    """
    Parses an OpenVDB file and returns a GridDescriptor and RootNode.
    """
    header = read_file_header(file_stream)
    grid_descriptor = read_grid_descriptor(file_stream, header)
    root_node = read_root_node(file_stream, grid_descriptor)
    return grid_descriptor, root_node

def read_grid_descriptor(file_stream, header):
    """
    Reads the GridDescriptor structure.
    """
    name = read_length_prefixed_string(file_stream)
    grid_type = read_length_prefixed_string(file_stream)
    instance_parent = read_length_prefixed_string(file_stream)
    grid_pos = read_u64_le(file_stream)
    block_pos = read_u64_le(file_stream)
    end_pos = read_u64_le(file_stream)
    
    compression = Compression.NONE
    if header.file_version >= OPENVDB_FILE_VERSION_NODE_MASK_COMPRESSION:
        compression = read_u32_le(file_stream)
    
    meta_data = read_metadata(file_stream)
    
    return GridDescriptor(
        name=name,
        grid_type=grid_type,
        instance_parent=instance_parent,
        grid_pos=grid_pos,
        block_pos=block_pos,
        end_pos=end_pos,
        compression=compression,
        meta_data=meta_data
    )

def read_metadata(file_stream):
    """
    Reads metadata entries.
    """
    count = read_u32_le(file_stream)
    meta_data = {}
    for _ in range(count):
        name = read_length_prefixed_string(file_stream)
        type_str = read_length_prefixed_string(file_stream)
        length = read_u32_le(file_stream)
        value = parse_metadata_value(type_str, length, file_stream)
        meta_data[name] = value
    return meta_data

def parse_metadata_value(type_str, length, file_stream):
    """
    Parses a metadata value based on its type string.
    """
    if type_str == "string":
        return MetadataValue.String(read_length_prefixed_string(file_stream))
    elif type_str == "bool":
        return MetadataValue.Bool(read_u8(file_stream) != 0)
    elif type_str == "int32":
        return MetadataValue.I32(read_i32_le(file_stream))
    elif type_str == "int64":
        return MetadataValue.I64(read_i64_le(file_stream))
    elif type_str == "float":
        return MetadataValue.Float(read_f32_le(file_stream))
    elif type_str == "vec3i":
        x = read_i32_le(file_stream)
        y = read_i32_le(file_stream)
        z = read_i32_le(file_stream)
        return MetadataValue.Vec3i(x, y, z)
    else:
        data = file_stream.read(length)
        return MetadataValue.Unknown(type_str, data)

def read_root_node(file_stream, grid_descriptor):
    """
    Reads the root node of the tree.
    """
    buffer_count = read_u32_le(file_stream)
    if buffer_count != 1:
        raise ValueError("Multi-buffer trees are not supported")
    
    background = read_u32_le(file_stream) # Converted to T
    num_tiles = read_u32_le(file_stream)
    num_node5s = read_u32_le(file_stream)
    
    root_map = {}
    
    # Read tiles
    for _ in range(num_tiles):
        origin = read_vec3i(file_stream)
        root_key = compute_root_key(origin)
        value = read_u32_le(file_stream) # Converted to T
        active = read_u8(file_stream) == 1
        root_map[root_key] = RootData.Tile(value, active)
    
    # Read Node5s
    for _ in range(num_node5s):
        origin = read_vec3i(file_stream)
        root_key = compute_root_key(origin)
        node5 = read_node5(file_stream, grid_descriptor)
        root_map[root_key] = RootData.Node(node5)
    
    return RootNode(map=root_map, background=background)

def read_node5(file_stream, grid_descriptor):
    """
    Reads a Node5 internal node.
    """
    child_mask = read_u64_le(file_stream) # LSB0 bitvector
    value_mask = read_u64_le(file_stream) # LSB0 bitvector
    data = read_compressed_data(file_stream, grid_descriptor, value_mask)
    
    node5_data = []
    for i in range(32): # Node5 has 32 children
        if (child_mask >> i) & 1:
            if (value_mask >> i) & 1:
                # Child has non-background value
                # Check if it's a tile or a node
                # In OpenVDB, Node5 children can be Tiles or Node4s.
                # The source code implies Node5 contains InternalData which is Tile or Node4.
                # However, the parsing logic for Node5 in the source reads compressed data
                # and then recursively reads Node4s. This suggests Node5 children are Node4s.
                # Let's follow the source: "iterate Node5s... recursively read Node4 children"
                node4 = read_node4(file_stream, grid_descriptor)
                node5_data.append(RootData.Node(node4))
            else:
                # Child is background
                node5_data.append(None) # Or handle appropriately
        else:
            node5_data.append(None)
            
    return Node5(data=node5_data)

def read_node4(file_stream, grid_descriptor):
    """
    Reads a Node4 internal node.
    """
    value_mask = read_u64_le(file_stream) # LSB0 bitvector
    
    node4_data = []
    for i in range(16): # Node4 has 16 children
        if (value_mask >> i) & 1:
            # Child is a Node3 leaf
            node3 = read_node3(file_stream, grid_descriptor)
            node4_data.append(RootData.Node(node3))
        else:
            node4_data.append(None)
            
    return Node4(data=node4_data)

def read_node3(file_stream, grid_descriptor):
    """
    Reads a Node3 leaf node.
    """
    # Node3 is a leaf, so it contains 512 values.
    # The source code reads compressed data for Node3 as well.
    data = read_compressed_data(file_stream, grid_descriptor, None) # No value mask for leaf?
    return Node3(data=data)

def read_compressed_data(file_stream, grid_descriptor, value_mask):
    """
    Reads and decompresses node data.
    """
    meta_data = NodeMetaData.NoMaskAndAllVals
    if grid_descriptor.compression.contains(Compression.NODE_MASK_COMPRESSION):
        meta_data = read_u8(file_stream)
    
    inactive_val0 = T.zeroed()
    inactive_val1 = T.zeroed()
    
    if meta_data in [NodeMetaData.MaskAndOneInactiveVal, NodeMetaData.NoMaskAndOneInactiveVal]:
        inactive_val0 = read_value(file_stream)
    elif meta_data == NodeMetaData.MaskAndTwoInactiveVals:
        inactive_val0 = read_value(file_stream)
        inactive_val1 = read_value(file_stream)
    
    selection_mask = bitvec![u64, Lsb0; 0; size]
    if meta_data in [NodeMetaData.MaskAndNoInactiveVals, NodeMetaData.MaskAndOneInactiveVal, NodeMetaData.MaskAndTwoInactiveVals]:
        read_u64_into(file_stream, selection_mask)
    
    count = compute_active_count(grid_descriptor, meta_data, value_mask, size)
    
    # Handle type conversion
    expected_type = type(T)
    real_type = f16 if grid_descriptor.meta_data.is_half_float() else f32
    
    if expected_type == real_type:
        data = read_raw_compressed_data(file_stream, count)
    elif expected_type == f16 and real_type == f32:
        f32_data = read_raw_compressed_data(file_stream, count)
        data = [f16.from_f32(v) for v in f32_data]
    elif expected_type == f32 and real_type == f16:
        f16_data = read_raw_compressed_data(file_stream, count)
        data = [f32.from_f16(v) for v in f16_data]
    else:
        # Generic conversion
        if real_type == f16:
            f16_data = read_raw_compressed_data(file_stream, count)
            data = [T.from_f16_bites(v) for v in f16_data]
        else:
            f32_data = read_raw_compressed_data(file_stream, count)
            data = [T.from_f32_bites(v) for v in f32_data]
    
    # Expand active mask if needed
    if grid_descriptor.compression.contains(Compression.ACTIVE_MASK) and len(data) != size:
        expanded = [T.zeroed()] * size
        read_idx = 0
        for dest_idx in range(size):
            if value_mask[dest_idx]:
                expanded[dest_idx] = data[read_idx]
                read_idx += 1
            elif selection_mask[dest_idx]:
                expanded[dest_idx] = inactive_val1
            else:
                expanded[dest_idx] = inactive_val0
        data = expanded
    
    return data

def compute_active_count(grid_descriptor, meta_data, value_mask, size):
    """
    Computes the number of active values to read.
    """
    if grid_descriptor.compression.contains(Compression.ACTIVE_MASK) and meta_data != NodeMetaData.NoMaskAndAllVals:
        return value_mask.count_ones()
    else:
        return size
```

### Parameters
-   **File Version**: Determines which fields are present. Key threshold is `OPENVDB_FILE_VERSION_NODE_MASK_COMPRESSION` [S1, unofficial].
-   **Compression Flags**: `ACTIVE_MASK`, `BLOSC`, `NODE_MASK_COMPRESSION` [S1, unofficial].

### Edge Cases and Pitfalls
-   **Multi-buffer Trees**: The reader explicitly panics or TODOs if `buffer_count != 1` [S1, unofficial].
-   **Half-float Storage**: The source code notes uncertainty about whether half-floats take 4 bytes in the file format [S1, unofficial].
-   **Blosc Decompression**: Fails if the uncompressed size (`nbytes`) is 0, returning `UnsupportedBloscFormat` error [S1, unofficial].
-   **Active Mask Expansion**: Requires careful index tracking. Reads from compressed data array only when `value_mask[dest_idx]` is true, otherwise assigns `inactive_val1` or `inactive_val0` based on `selection_mask` [S1, unofficial].

## Operating characteristics
-   **Time Complexity**: Parsing is linear with respect to the number of nodes and tiles in the file. Decompression adds overhead proportional to the compressed data size.
-   **Memory Complexity**: The in-memory structure mirrors the tree topology. Each node stores masks and data. Leaf nodes store 512 values.
-   **Measured Performance**: Not given in the sources.
-   **Scaling**: Performance scales with the number of non-background tiles and nodes. Sparse grids with few tiles are fast to parse.
-   **Strengths**: Supports sparse data, compression, and hierarchical structure.
-   **Limitations**: Multi-buffer trees are not supported. Half-float handling may be incomplete.
-   **When to use**: When loading OpenVDB files for further processing or rendering.
-   **When not to use**: When linear access patterns are required (use NanoVDB instead).

## Background
OpenVDB is a sparse data structure developed by DreamWorks Animation for visual effects. The file format is designed to efficiently store large, sparse volumetric datasets. The parsing method described here is based on the `woxel` library [S1, unofficial].
