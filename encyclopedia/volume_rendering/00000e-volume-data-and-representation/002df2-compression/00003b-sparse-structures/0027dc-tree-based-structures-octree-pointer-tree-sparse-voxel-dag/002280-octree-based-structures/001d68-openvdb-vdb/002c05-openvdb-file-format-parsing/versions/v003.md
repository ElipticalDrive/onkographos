# OpenVDB File Format Parsing

Also called: OpenVDB deserialization, VDB file reader

## Overview
This method parses the binary OpenVDB file format to reconstruct sparse voxel grids in memory [S1, unofficial]. It loads hierarchical, compressed volumetric data from disk into a traversable tree structure consisting of a root node, internal nodes, and leaf nodes [S1, unofficial]. It differs from [NanoVDB Linear Representation](1527-nanovdb-linear-representation.md) by maintaining a hierarchical tree structure in memory rather than a flat linear array, and from [VDB Volume Rendering with OpenVDB/NanoVDB](804-vdb-volume-rendering-with-openvdb.md) by focusing solely on data loading rather than rendering traversal [S1, unofficial].

## How it works
### Inputs and Outputs
- **Input**: A binary file stream conforming to the OpenVDB file format specification [S1, unofficial].
- **Output**: A `GridDescriptor` object containing metadata, and a root tree structure (typically a `RootNode`) containing the voxel data [S1, unofficial].

### Data Structures
The parser constructs the following in-memory structures [S1, unofficial]:
1. **GridDescriptor**:
   - `name`, `grid_type`, `instance_parent`: length-prefixed strings [S1, unofficial].
   - `grid_pos`, `block_pos`, `end_pos`: u64 little-endian integers [S1, unofficial].
   - `compression`: enum/flags indicating compression types (e.g., `ACTIVE_MASK`, `BLOSC`) [S1, unofficial].
   - `meta_data`: `HashMap<String, MetadataValue>` [S1, unofficial].
2. **MetadataValue**:
   - Variants: `String`, `Bool`, `I32`, `I64`, `Float`, `Vec3i`, `Unknown { name: String, data: Vec<u8> }` [S1, unofficial].
3. **NodeHeader** (for Node5 and Node4):
   - `child_mask`: LSB0 bitvector of size $N::SIZE$ (u64) indicating which children exist [S1, unofficial].
   - `value_mask`: LSB0 bitvector of size $N::SIZE$ (u64) indicating which children have non-background values [S1, unofficial].
   - `data`: `Vec<T>` containing compressed or raw values [S1, unofficial].
   - `log_2_dim`: usize [S1, unofficial].
4. **RootNode**:
   - `map`: `HashMap<RootKey, RootData>` [S1, unofficial].
   - `background`: T, the background value for the grid [S1, unofficial].
   - `RootData` variants: `Tile<T>(value: T, active: bool)` or `Node(Box<Node5>)` [S1, unofficial].
5. **Node5**:
   - Contains an array of `InternalData` (either `Tile<T>` or `Node(Box<Node4>)`) [S1, unofficial].
   - Indexed by the 5-bit key derived from the origin [S1, unofficial].
6. **Node4**:
   - Contains an array of `InternalData` (either `Tile<T>` or `Node(Box<Node3>)`) [S1, unofficial].
   - Indexed by the 4-bit key [S1, unofficial].
7. **Node3**:
   - Leaf node containing the actual voxel values [S1, unofficial].
   - Size is $8 \times 8 \times 8 = 512$ values [S1, unofficial].

### Numbered Steps
1. **Read Grid Descriptor**: Read `name`, `grid_type`, `instance_parent` as length-prefixed strings [S1, unofficial]. Read `grid_pos`, `block_pos`, `end_pos` as u64 little-endian integers [S1, unofficial]. If file version $\ge$ `OPENVDB_FILE_VERSION_NODE_MASK_COMPRESSION`, read `compression` flag as u32 little-endian; otherwise, set to default [S1, unofficial]. Read metadata count as u32 little-endian [S1, unofficial]. For each entry, read name and type as length-prefixed strings, length as u32 little-endian, then parse value based on type string ("string", "bool", "int32", "int64", "float", "vec3i", or raw bytes for unknown types) [S1, unofficial].
2. **Read Tree Topology Header**: Read buffer count as u32 little-endian [S1, unofficial]. Read root node background value as u32 little-endian, converted to type T [S1, unofficial]. Read number of tiles and Node5s as u32 little-endian [S1, unofficial].
3. **Iterate Tiles**: For each tile, read origin as `vec3i` [S1, unofficial]. Compute `root_key` from origin [S1, unofficial]. Read value as u32 little-endian, converted to T [S1, unofficial]. Read active flag as u8 (1=active) [S1, unofficial]. Store as `RootData::Tile<T>(value, active)` [S1, unofficial].
4. **Iterate Node5s**: For each Node5, read origin as `vec3i` [S1, unofficial]. Compute `root_key` [S1, unofficial]. Read internal node header: `child_mask` and `value_mask` as u64 bitvectors, and compressed data [S1, unofficial]. Construct `Node5` [S1, unofficial]. For each active child in `child_mask`, recursively read Node4 children [S1, unofficial].
5. **Read Node4 Children**: For each active child in Node5's `child_mask`, read `value_mask` as u64 bitvector [S1, unofficial]. Construct `Node3` leaf [S1, unofficial]. Assign to Node4 data array [S1, unofficial].
6. **Read Compressed Node Data**: For each node (Node5 or Node4) with compressed data, read metadata byte if file version $\ge$ `OPENVDB_FILE_VERSION_NODE_MASK_COMPRESSION` [S1, unofficial]. Determine inactive values: read 0, 1, or 2 inactive values based on metadata [S1, unofficial]. Read selection mask if metadata indicates masked inactive values [S1, unofficial]. Compute active count based on compression flags and metadata [S1, unofficial]. Handle f16/f32 type conversion if necessary [S1, unofficial].     def count_ones(self):
