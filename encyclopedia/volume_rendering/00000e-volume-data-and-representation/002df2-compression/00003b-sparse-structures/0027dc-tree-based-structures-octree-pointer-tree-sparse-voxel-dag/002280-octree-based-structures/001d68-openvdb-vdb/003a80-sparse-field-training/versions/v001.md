# Sparse Field Training

Also called: Active Voxel Sampling, VDB-based Sparse Training

## Overview
Sparse Field Training is a method for training value regression Multi-Layer Perceptrons (MLPs) by restricting data sampling to the active voxels of an existing VDB grid [S1][S2, unofficial]. It solves the problem of inefficient learning in sparse volumetric representations by excluding inactive background values, thereby focusing the model's capacity on significant content [S1][S2, unofficial]. Unlike dense training approaches, it implicitly encodes the VDB's adaptive structure into the network, though it requires external masking to handle out-of-bounds queries [S1][S2, unofficial].

## How it works
**Inputs:**
1. An existing VDB grid (OpenVDB or NanoVDB) [S1][S2, unofficial].
2. A value regression MLP architecture [S1][S2, unofficial].

**Outputs:**
A trained MLP that approximates the values within the active voxel regions of the source VDB grid [S1][S2, unofficial].

**Data Structures:**
The method relies on the hierarchical structure of the source VDB grid. The VDB tree consists of nodes (internal and leaf) and voxels.
- **Active Voxels:** Voxels containing significant data. For a narrow-band level set (truncated signed distance field), active voxels "uniformly sandwich" the zero-crossing surface [S1][S2, unofficial].
- **Inactive Voxels:** Background values encoded in the VDB tree, which are excluded from training [S1][S2, unofficial].
- **Masking Structure:** The hierarchical structure from the source VDB is embedded as part of the NeuralVDB data (excluding dense leaf nodes) to mask out random access outside active voxel regions [S1][S2, unofficial].

**Parameters:**
- **Active Voxel Range:** For a narrow-band level set of width $W$, active voxels are defined in the range $[-W/2 \cdot \Delta x, W/2 \cdot \Delta x]$ [S1][S2, unofficial].
    - Example: For a width of six, the range is $[-3\Delta x, 3\Delta x]$, where $\Delta x$ is the voxel size [S1][S2, unofficial].
    - Note: Fog or normalized density volumes may have wider active value sets, but they remain bounded [S1][S2, unofficial].

**Steps:**
1. Initialize the value regression MLP [S1][S2, unofficial].
2. For each training epoch:
    a. Randomly sample active voxels from the existing VDB grid [S1][S2, unofficial].
    b. Explicitly exclude all inactive values (e.g., background) encoded in the VDB tree [S1][S2, unofficial].
    c. Train the network using only the sampled active voxels [S1][S2, unofficial].
3. Embed the hierarchical structure from the source VDB into the NeuralVDB data (except dense leaf nodes) to create a mask for out-of-bounds access [S1][S2, unofficial].

**Pseudocode:**
```python
def sparse_field_training(vdb_grid, mlp, epochs):
    """
    Train an MLP using only active voxels from a VDB grid.
    
    Args:
        vdb_grid: An OpenVDB or NanoVDB grid object.
        mlp: A value regression MLP model.
        epochs: Number of training epochs.
    """
    # Pre-compute the mask from the VDB hierarchy
    # This mask prevents extrapolation outside active regions
    # The mask is embedded in NeuralVDB data, excluding dense leaf nodes
    out_of_bounds_mask = extract_vdb_hierarchy_mask(vdb_grid)
    
    for epoch in range(epochs):
        # Step 1: Sample active voxels from the VDB tree
        # This explicitly excludes inactive/background values
        active_samples = sample_active_voxels(vdb_grid)
        
        if not active_samples:
            continue
            
        # Step 2: Prepare training batch
        # active_samples contains coordinates and target values
        # for voxels within the active range (e.g., [-3*dx, 3*dx] for width 6)
        coordinates = [sample.coord for sample in active_samples]
        targets = [sample.value for sample in active_samples]
        
        # Step 3: Train the MLP on these samples
        # The network learns to regress values only within the active field
        loss = mlp.train_step(coordinates, targets)
        
        # Note: The network will not extrapolate well outside active voxels
        # This is by-design. The out_of_bounds_mask is used during inference
        # to handle queries outside the trained region.
```

**Edge Cases and Pitfalls:**
- **Extrapolation:** The network will not extrapolate well outside the active voxels [S1][S2, unofficial]. This is by-design [S1][S2, unofficial].
- **Out-of-Bounds Access:** To handle queries outside the active voxel regions, the hierarchical structure from the source VDB must be embedded as part of the NeuralVDB data (except dense leaf nodes) to mask out these regions [S1][S2, unofficial].
- **Dense Leaf Nodes:** Dense leaf nodes are excluded from the masking structure, implying they are handled differently or assumed to be fully active [S1][S2, unofficial].

**Strengths and Limitations:**
- **Strengths:** Simple and efficient way to introduce sparseness in training despite dense tree nodes [S1][S2, unofficial]. Focuses learning capacity on significant content [S1][S2, unofficial]. Implicitly encodes the VDB's adaptive structure into the network [S1][S2, unofficial].
- **Limitations:** The network does not extrapolate well outside active voxels [S1][S2, unofficial]. Requires external masking for out-of-bounds queries [S1][S2, unofficial].

**When to Use:**
Use when training value regression MLPs for sparse volumetric data where background values are insignificant and the adaptive structure of the VDB should be implicitly encoded [S1][S2, unofficial].

**When Not to Use:**
Do not use if extrapolation outside the active voxel region is required without additional masking mechanisms [S1][S2, unofficial].

## Background
**Origin:**
Sparse Field Training was introduced in the NeuralVDB paper [S1][S2, unofficial].

**History and Development:**
The method is part of the NeuralVDB framework, which combines hierarchical neural networks with VDB grids for high-resolution sparse volume representation [S1][S2, unofficial]. It addresses the spectral bias of vanilla MLPs by focusing training on significant data regions [S1][S2, unofficial].

**Where it is Used:**
Used in NeuralVDB for encoding value regression MLPs [S1][S2, unofficial].
