# OpenVDB File Format Parsing

Also called: OpenVDB deserialization, VDB file reader

## Overview
OpenVDB File Format Parsing is the method for reading and reconstructing sparse voxel grids from the binary OpenVDB file format. It solves the problem of loading hierarchical, compressed sparse data structures into memory for rendering or simulation. It is distinguished from generic volume loading by its specific handling of variable-length node types (Node3, Node4, Node5), multi-level compression (Blosc, active masks), and the strict little-endian binary layout defined by the OpenVDB specification [S1, unofficial].

## How it works
**Inputs:** A binary file stream conforming to the OpenVDB format.
**Outputs:** An in-memory representation of the grid, typically consisting of a `GridDescriptor`, a `Metadata` map, and a root node tree structure (`RootNode`) containing tiles and internal nodes.

### Data Structures and Layout
The file is read sequentially. All multi-byte integers are Little-Endian.

1.  **GridDescriptor**:
    *   `name`: Length-prefixed string.
    *   `grid_type`: Length-prefixed string.
    *   `instance_parent`: Length-prefixed string.
    *   `grid_pos`: `u64`.
    *   `block_pos`: `u64`.
    *   `end_pos`: `u64`.
    *   `compression`: Enum/Flags indicating compression types used (e.g., `ACTIVE_MASK`, Blosc variants).
    *   `meta_data`: A map of key-value pairs.

2.  **Metadata**:
    *   Stored as a count (`u32`) followed by entries.
    *   Each entry: `name` (length-prefixed string), `type` (length-prefixed string), `length` (`u32`).
    *   Value parsing depends on `type`:
        *   `"string"`: Read `length` bytes as UTF-8.
        *   `"bool"`: Read 1 byte.
        *   `"int32"`: Read 4 bytes (`i32`).
        *   `"int64"`: Read 8 bytes (`i64`).
        *   `"float"`: Read 4 bytes (`f32`).
        *   `"vec3i"`: Read 3 `i32` values.
        *   Unknown types: Read `length` raw bytes.

3.  **Tree Topology**:
    *   `buffer_count`: `u32`. Must be 1. Multi-buffer trees are not supported [S1, unofficial].
    *   `root_node_background`: `u32` interpreted as the background value of type `T`.
    *   `num_tiles`: `u32`.
    *   `num_node5s`: `u32`.

4.  **Node Structures**:
    *   **Tile**: Origin (`vec3i`), Value (`T`), Active flag (`u8`, 1=active).
    *   **Node5**:
        *   Origin (`vec3i`).
        *   `child_mask`: `u64` bitvector (LSB0), indicating which of the 32 children exist.
        *   `value_mask`: `u64` bitvector (LSB0), indicating which children are active.
        *   `data`: Compressed payload.
    *   **Node4**:
        *   Contains `value_mask` (`u64` bitvector).
        *   Contains 16 children, which are either Tiles or Node3s.
    *   **Node3 (Leaf)**:
        *   Contains 64 values.

### Parsing Steps

1.  **Read Header and Descriptor**:
    *   Read `GridDescriptor` fields as defined above.
    *   If file version $\ge$ `OPENVDB_FILE_VERSION_NODE_MASK_COMPRESSION`, read `compression` flag as `u32`. Otherwise, assume default (no compression).

2.  **Read Metadata**:
    *   Read `meta_data_count` (`u32`).
    *   Loop `meta_data_count` times:
        *   Read `name` and `type` strings.
        *   Read `length` (`u32`).
        *   Parse value based on `type`. Store in `HashMap<String, MetadataValue>`.

3.  **Read Tree Topology**:
    *   Read `buffer_count` (`u32`). Assert `buffer_count == 1`.
    *   Read `root_node_background` (`u32`), cast to type `T`.
    *   Read `num_tiles` (`u32`) and `num_node5s` (`u32`).

4.  **Iterate Tiles**:
    *   Loop `num_tiles` times:
        *   Read `origin` (`vec3i`).
        *   Compute `root_key` from `origin`.
        *   Read `value` (`u32`), cast to `T`.
        *   Read `active` (`u8`).
        *   Store as `RootData::Tile(value, active)`.

5.  **Iterate Node5s**:
    *   Loop `num_node5s` times:
        *   Read `origin` (`vec3i`).
        *   Compute `root_key`.
        *   Read `child_mask` (`u64`) and `value_mask` (`u64`).
        *   Read compressed `data` for the Node5.
        *   Construct `Node5` with `child_mask`, `value_mask`, and `data`.
        *   For each child index `i` where `child_mask[i]` is set:
            *   Read `value_mask` (`u64`) for the child Node4.
            *   Construct `Node3` leaf.
            *   Assign to `Node5`'s data array at index `i`.

6.  **Read Compressed Node Data**:
    *   For each node (Node5 or Node4) with compressed data:
        *   If version $\ge$ `OPENVDB_FILE_VERSION_NODE_MASK_COMPRESSION`, read `meta_data` byte (`u8`).
        *   Determine inactive values based on `meta_data`:
            *   `NoMaskAndAllVals`: No inactive values stored.
            *   `NoMaskAndOneInactiveVal`: Read one inactive value (`T`).
            *   `MaskAndOneInactiveVal`: Read one inactive value (`T`).
            *   `MaskAndTwoInactiveVals`: Read two inactive values (`T`, `T`).
        *   If `meta_data` indicates a selection mask (`MaskAnd...`), read `selection_mask` (`u64`).
        *   Calculate `active_count`:
            *   If `ACTIVE_MASK` compression is enabled and `meta_data` is not `NoMaskAndAllVals`, `active_count = value_mask.count_ones()`.
            *   Otherwise, `active_count = node_size` (e.g., 64 for Node3, 16 for Node4, 32 for Node5).
        *   Read `active_count` values of type `T` (or `f32`/`f16` depending on storage).
        *   Handle type conversion (e.g., `f32` to `f16` or vice versa) if metadata indicates half-float storage.
        *   Expand the data array to full node size if `ACTIVE_MASK` is used:
            *   Initialize `expanded` array of size `node_size` with background or inactive values.
            *   Iterate `dest_idx` from 0 to `node_size - 1`:
                *   If `value_mask[dest_idx]` is true:
                    *   Assign next value from compressed data array.
                *   Else if `selection_mask[dest_idx]` is true:
                    *   Assign `inactive_val1`.
                *   Else:
                    *   Assign `inactive_val0`.

### Pseudocode

```python
def parse_openvdb_file(file_stream):
    """
    Parses an OpenVDB file into a Grid structure.
    Assumes little-endian byte order.
    """
    reader = BinaryReader(file_stream)
    
    # 1. Read Grid Descriptor
    grid_descriptor = GridDescriptor()
    grid_descriptor.name = reader.read_length_prefixed_string()
    grid_descriptor.grid_type = reader.read_length_prefixed_string()
    grid_descriptor.instance_parent = reader.read_length_prefixed_string()
    grid_descriptor.grid_pos = reader.read_u64()
    grid_descriptor.block_pos = reader.read_u64()
    grid_descriptor.end_pos = reader.read_u64()
    
    # Check version for compression flag
    file_version = reader.read_u32() # Assuming version is at start or known offset
    if file_version >= OPENVDB_FILE_VERSION_NODE_MASK_COMPRESSION:
        grid_descriptor.compression = reader.read_u32()
    else:
        grid_descriptor.compression = 0 # Default no compression

    # 2. Read Metadata
    meta_data_count = reader.read_u32()
    grid_descriptor.meta_data = {}
    for _ in range(meta_data_count):
        name = reader.read_length_prefixed_string()
        type_str = reader.read_length_prefixed_string()
        length = reader.read_u32()
        
        value = None
        if type_str == "string":
            value = reader.read_bytes(length).decode('utf-8')
        elif type_str == "bool":
            value = reader.read_u8() != 0
        elif type_str == "int32":
            value = reader.read_i32()
        elif type_str == "int64":
            value = reader.read_i64()
        elif type_str == "float":
            value = reader.read_f32()
        elif type_str == "vec3i":
            value = (reader.read_i32(), reader.read_i32(), reader.read_i32())
        else:
            value = reader.read_bytes(length)
            
        grid_descriptor.meta_data[name] = MetadataValue(value)

    # 3. Read Tree Topology
    buffer_count = reader.read_u32()
    if buffer_count != 1:
        raise ValueError("Multi-buffer trees are not supported")
        
    root_background_raw = reader.read_u32()
    root_background = convert_to_type(root_background_raw, grid_descriptor.meta_data.get_type())
    
    num_tiles = reader.read_u32()
    num_node5s = reader.read_u32()
    
    root_node = RootNode(background=root_background)
    root_node.tiles = {}
    root_node.node5s = {}

    # 4. Iterate Tiles
    for _ in range(num_tiles):
        origin = reader.read_vec3i()
        root_key = compute_root_key(origin)
        value_raw = reader.read_u32()
        value = convert_to_type(value_raw, grid_descriptor.meta_data.get_type())
        active = reader.read_u8() == 1
        
        root_node.tiles[root_key] = Tile(value, active)

    # 5. Iterate Node5s
    for _ in range(num_node5s):
        origin = reader.read_vec3i()
        root_key = compute_root_key(origin)
        child_mask = reader.read_u64()
        value_mask = reader.read_u64()
        
        # Read compressed data for Node5
        compressed_data = read_compressed_node_data(reader, grid_descriptor, node_size=32, value_mask=value_mask)
        
        node5 = Node5(child_mask=child_mask, value_mask=value_mask, data=compressed_data)
        
        # Process children of Node5
        for i in range(32):
            if (child_mask >> i) & 1:
                # Read child Node4 metadata
                child_value_mask = reader.read_u64()
                # Read child Node3 leaf data
                leaf_data = read_compressed_node_data(reader, grid_descriptor, node_size=64, value_mask=child_value_mask)
                node3 = Node3(data=leaf_data)
                node5.set_child(i, node3)
                
        root_node.node5s[root_key] = node5

    return Grid(grid_descriptor, root_node)

def read_compressed_node_data(reader, grid_descriptor, node_size, value_mask):
    """
    Reads and decompresses node data based on compression flags.
    """
    meta_data = NodeMetaData.NoMaskAndAllVals
    
    if grid_descriptor.file_version >= OPENVDB_FILE_VERSION_NODE_MASK_COMPRESSION:
        meta_data_byte = reader.read_u8()
        meta_data = NodeMetaData.from_byte(meta_data_byte)
        
    inactive_val0 = TypeZero(grid_descriptor)
    inactive_val1 = TypeZero(grid_descriptor)
    
    if meta_data in [NodeMetaData.MaskAndOneInactiveVal, NodeMetaData.NoMaskAndOneInactiveVal]:
        inactive_val0 = reader.read_value(grid_descriptor)
    elif meta_data == NodeMetaData.MaskAndTwoInactiveVals:
        inactive_val0 = reader.read_value(grid_descriptor)
        inactive_val1 = reader.read_value(grid_descriptor)
        
    selection_mask = 0
    if meta_data in [NodeMetaData.MaskAndNoInactiveVals, NodeMetaData.MaskAndOneInactiveVal, NodeMetaData.MaskAndTwoInactiveVals]:
        selection_mask = reader.read_u64()
        
    # Determine active count
    if grid_descriptor.compression & Compression.ACTIVE_MASK and meta_data != NodeMetaData.NoMaskAndAllVals:
        active_count = bin(value_mask).count('1')
    else:
        active_count = node_size
        
    # Read active values
    # Note: Actual storage type might differ from logical type (e.g., f32 stored as f16)
    storage_type = get_storage_type(grid_descriptor)
    raw_data = []
    for _ in range(active_count):
        raw_data.append(reader.read_value(storage_type))
        
    # Convert to logical type if necessary
    logical_type = get_logical_type(grid_descriptor)
    data = convert_values(raw_data, storage_type, logical_type)
    
    # Expand if active mask is used
    if grid_descriptor.compression & Compression.ACTIVE_MASK and len(data) != node_size:
        expanded = [TypeZero(logical_type)] * node_size
        read_idx = 0
        for dest_idx in range(node_size):
            if (value_mask >> dest_idx) & 1:
                expanded[dest_idx] = data[read_idx]
                read_idx += 1
            elif (selection_mask >> dest_idx) & 1:
                expanded[dest_idx] = inactive_val1
            else:
                expanded[dest_idx] = inactive_val0
        return expanded
    else:
        return data
```

### Parameters and Edge Cases
*   **File Version**: Determines whether compression flags and metadata bytes are present. Version `OPENVDB_FILE_VERSION_NODE_MASK_COMPRESSION` is the critical threshold [S1, unofficial].
*   **Compression Flags**: `ACTIVE_MASK` indicates that only active values are stored in the compressed data array, requiring expansion using `value_mask` and `selection_mask` [S1, unofficial].
*   **Half-Float Storage**: The sources note uncertainty about whether half-floats take 4 bytes in the file format, suggesting implementation-specific handling or a TODO [S1, unofficial].
*   **Blosc Decompression**: If the uncompressed size (`nbytes`) is 0, Blosc decompression fails with `UnsupportedBloscFormat` [S1, unofficial].
*   **Multi-Buffer**: The reader explicitly panics or errors if `buffer_count != 1` [S1, unofficial].

## Subtopics

### [OpenVDB Import via Python](7124-openvdb-import-via-python.md)
This method converts seismic SEG-Y data into the OpenVDB format using Python, and imports the resulting VDB file into a rendering engine (specifically Unreal Engine 5) for sparse voxel texture (SVT) rendering. It addresses handling massive datasets (e.g., 4.4 GB) that exceed standard 32-bit integer limits for memory addressing and buffer sizes, which causes import crashes and rendering artifacts. It is distinguished from generic VDB loading by its specific focus on the Python-side conversion pipeline and the subsequent engine-side integer overflow fixes required for large-scale sparse volumes.

### [OpenVDB Volume Data Source](14158-openvdb-volume-data-source.md)
The OpenVDB Volume Data Source is a plugin for the Mitsuba renderer that enables ray marching through volumetric data stored in the OpenVDB sparse voxel format. It implements the `VolumeDataSource` interface, providing scalar field lookups via trilinear interpolation and automatic bounding box calculation. It is distinguished from generic import methods by its integration into the rendering pipeline's caching system and its specific handling of OpenVDB's coordinate transforms and metadata.

### [OpenVDB Field Writer](16391-openvdb-field-writer.md)
The OpenVDB Field Writer is a Python-based serialization technique that converts 3D regular volumetric grids into the OpenVDB sparse tree format for export to VFX software like Blender. It differs from dense grid export by leveraging OpenVDB's sparse tree structure to efficiently store volumetric data and prune background values. It builds on [OpenVDB File Format Parsing](5173-openvdb-file-format-parsing.md) by providing the high-level API to construct and persist the grid structure.

## Operating characteristics
*   **Time Complexity**: Parsing is linear with respect to the number of nodes and tiles in the file, plus the cost of decompression (Blosc). Decompression is typically fast but depends on the compression ratio.
*   **Memory Complexity**: The in-memory representation is proportional to the number of non-background nodes and tiles. Sparse structures allow efficient storage of large grids with low occupancy.
*   **Performance**: Reading is generally fast due to the compact binary format and efficient compression. However, decompression overhead can be significant for highly compressed data.
*   **Strengths**: Efficient storage of sparse data, fast random access to nodes after loading, support for various data types and compression methods.
*   **Limitations**: Multi-buffer trees are not supported. Half-float handling may be implementation-specific. Large files may require careful memory management to avoid overflow issues in 32-bit systems [S1, unofficial].

## Background
OpenVDB is an open-source C++ library developed by DreamWorks Animation for the storage and manipulation of large volumetric datasets, particularly for visual effects. The file format is designed to be compact and efficient for sparse data. The parsing method described here is based on the implementation details found in the `woxel` library [S1, unofficial].
