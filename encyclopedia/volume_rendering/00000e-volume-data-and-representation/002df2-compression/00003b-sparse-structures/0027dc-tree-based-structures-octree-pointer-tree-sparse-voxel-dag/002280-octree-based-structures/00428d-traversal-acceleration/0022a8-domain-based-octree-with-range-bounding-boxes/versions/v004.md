# Domain-based Octree with Range Bounding Boxes

Also called: Domain-Based Acceleration (Octree), Domain-based acceleration data-structure (Octree), Octree Acceleration, Range Bounding Box (RBB) Octree

## Overview
This method accelerates fiber surface extraction on tetrahedral meshes by organizing tetrahedra into an octree over the spatial domain, where each node stores a Range Bounding Box (RBB) representing the function's range over its volume [S1]. It solves the problem of efficiently identifying which tetrahedra intersect a given edge of the Fiber Surface Control Polygon (FSCP) by replacing exact polygon-polygon intersection tests with conservative axis-aligned bounding box (AABB) tests in the range space [S1]. Unlike the domain-based BVH, which partitions the range space directly, this structure partitions the spatial domain, resulting in larger memory requirements and potentially more returned tetrahedra, but offering a simpler hierarchical organization based on spatial locality [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A tetrahedral mesh with a scalar function $f$, a Fiber Surface Control Polygon (FSCP) defined by a sequence of edges $e$, and construction parameters $n_T$ (tetrahedra threshold) and $\alpha$ (RBB size fraction).
*   **Output:** An octree data structure where each node contains an RBB, and a list of candidate tetrahedra (if the node is a leaf or below threshold).

**Data Structures:**
*   **Octree Node:**
    *   `children`: Array of 8 child nodes (or null if leaf).
    *   `rbb_min`: Vector3, minimum bounds of the function range in the node's volume.
    *   `rbb_max`: Vector3, maximum bounds of the function range in the node's volume.
    *   `tets`: List of tetrahedra indices (only populated if the node is a leaf or if the number of contained tetrahedra is $\le n_T$).
    *   `is_leaf`: Boolean flag.

**Construction (Off-line):**
1.  Compute the octree of the domain $Dom_f$ in a top-to-bottom fashion by recursively dividing the domain into octants [S1].
2.  For each node, compute its RBB by taking the (min, max) with respect to each component of the RBBs of its child nodes [S1].
3.  If the number of tetrahedra contained in the node's volume is greater than $n_T$, do not descend to individual tetrahedra for RBB computation at this level; instead, compute the base level RBB from the vertices of the tetrahedra if below $n_T$ [S1].
4.  Terminate recursion if a node's RBB size (e.g., volume or max dimension) is smaller than a fraction $\alpha$ of the RBB of the entire mesh [S1].

**Query (On-line):**
1.  Start at the root node.
2.  For a given FSCP edge $e$, check if the node's RBB intersects or overlaps $e$ in the range space [S1].
3.  If they intersect, recursively visit the node's children.
4.  If the node is a leaf (or contains $\le n_T$ tetrahedra), return the list of tetrahedra in the node as candidates [S1].
5.  The union of all returned tetrahedra forms the conservative over-estimate of active cells for fiber surface extraction [S1].

**Pseudocode:**

```python
class OctreeNode:
    def __init__(self, rbb_min, rbb_max, children=None, tets=None):
        self.rbb_min = rbb_min
        self.rbb_max = rbb_max
        self.children = children if children else [None] * 8
        self.tets = tets if tets else []
        self.is_leaf = children is None

def compute_rbb(tetrahedra):
    """Compute the min/max range of a scalar function over a list of tetrahedra."""
    # [G] Implementation detail: Iterate over all vertices of the tetrahedra,
    # evaluate f(v) for each vertex, and track global min and max.
    min_val = infinity
    max_val = -infinity
    for tet in tetrahedra:
        for vertex in tet.vertices:
            val = f(vertex)
            if val < min_val: min_val = val
            if val > max_val: max_val = val
    return (min_val, max_val)

def build_octree(domain_cells, depth=0):
    """Recursively build the domain-based octree."""
    # [G] Determine the spatial bounding box of domain_cells to split into octants.
    spatial_bbox = compute_spatial_bbox(domain_cells)
    
    # Termination criterion: RBB size fraction
    # [G] Compute the RBB of the entire mesh once during initialization.
    global_rbb_size = compute_rbb_size(global_mesh_rbb)
    current_rbb = compute_rbb(domain_cells)
    current_rbb_size = compute_rbb_size(current_rbb)
    
    if current_rbb_size < alpha * global_rbb_size:
        return OctreeNode(current_rbb[0], current_rbb[1], tets=domain_cells)

    # Split domain into 8 octants
    octants = split_octant(spatial_bbox)
    new_cells = [get_cells_in_octant(octant, domain_cells) for octant in octants]
    
    # Recurse
    children = []
    for octant_cells in new_cells:
        if octant_cells:
            children.append(build_octree(octant_cells, depth + 1))
        else:
            children.append(None)
            
    # Compute RBB from children if not leaf
    if len(children) > 0:
        child_rbb_mins = [c.rbb_min for c in children if c]
        child_rbb_maxs = [c.rbb_max for c in children if c]
        rbb_min = min(child_rbb_mins)
        rbb_max = max(child_rbb_maxs)
        return OctreeNode(rbb_min, rbb_max, children=children)
    else:
        return OctreeNode(current_rbb[0], current_rbb[1], tets=domain_cells)

def query_octree(node, edge_e):
    """Recursively query the octree for tetrahedra intersecting edge_e."""
    # Conservative test: Check if edge_e intersects the node's RBB in range space
    if not rbb_intersects_edge(node.rbb_min, node.rbb_max, edge_e):
        return []
    
    if node.is_leaf:
        return node.tets
    
    candidates = []
    for child in node.children:
        if child is not None:
            candidates.extend(query_octree(child, edge_e))
    return candidates
```

**Parameters:**
*   $n_T$: Threshold for the minimum number of tetrahedra per node. If the number of tetrahedra in a node is below $n_T$, the base level RBB is computed from the vertices of the tetrahedra. Default/typical value: 1, but set to 5 for 5-subdivided regular grids in experiments [S1].
*   $\alpha$: Fraction of the entire mesh's RBB used as a termination criterion for octree depth. Typical value: 0.001 offered the best trade-off in experiments [S1].

**Pitfalls:**
*   The octree is not necessarily balanced (except for regular grids), and sub-trees can be arbitrarily deep, leading to many line-bounding-box intersection tests [S1].
*   For 5-subdivided regular grids, the minimum number of tets per octree leaf is 5 (one voxel), causing the RBB of a leaf to intersect a FSCP edge even if none of its tets are actually intersected [S1].
*   The use of conservative AABB tests in the range introduces false positives (cells returned that do not intersect the fiber surface), which are later discarded by the extraction algorithm [S1].

## Subtopics

## Operating characteristics
*   **Time Complexity:** Pre-processing is $O(N)$ where $N$ is the number of tetrahedra, assuming balanced splitting. Query time depends on the depth of the octree and the number of false positives.
*   **Memory Complexity:** $O(N)$ for storing the octree nodes and tetrahedra lists.
*   **Measured Performance:** On the EthaneDiol dataset, an octree with $\alpha=0.001$ used 649.736 MB memory, took 2.362s pre-processing, queried 35.260% of tetrahedra, and took 0.311s for extraction [S1]. Average speedup over non-accelerated algorithm: 18x [S1].
*   **Strengths:** Provides a conservative over-estimate of active cells, ensuring no valid tetrahedra are missed. Simple to implement using standard octree structures.
*   **Limitations:** Can return more tetrahedra than the range-based BVH due to less precise culling in the range space. Unbalanced trees can lead to deep recursion and slower queries.
*   **When to use:** When spatial locality is important or when the range space is complex and difficult to partition directly. Suitable for interactive visualization where pre-processing time is acceptable.

## Background
This method was introduced in the context of fast and exact fiber surface extraction for tetrahedral meshes [S1]. It extends the traditional use of octrees for storing interval ranges of scalar functions to the more complex case of polygon-polygon intersection tests required for fiber surfaces [S1]. The approach leverages the rich literature on collision detection by replacing exact tests with conservative AABB tests in the range space [S1].
