# Sparse Voxel Tree (SVO Tree)

Also called: ESVO, Hierarchical Voxel Storage, Sparse voxel octrees, Voxel Tree

## Overview
The Sparse Voxel Tree (SVO) is a hierarchical data structure that represents 3D volumetric data by recursively subdividing space into octants, storing data only in non-empty leaf nodes [S2]. It solves the problem of excessive memory usage in dense voxel grids by exploiting spatial sparsity, allowing for the representation of large, detailed scenes with minimal storage [S2]. Unlike its siblings, the standard SVO uses a fixed octree topology with pointer-based or block-indexed navigation, distinguishing it from the DAG's shared nodes [Parent](4139-tree-based-structures-octree-pointer-tree-sparse-voxel-dag.md) and the Hashed-Octree's constant-time access [7486-hashed-octree.md].

## How it works
The SVO maps 3D coordinates to a hierarchical tree where each internal node has up to 8 children. The implementation relies on a memory pool system to manage node and voxel blocks, avoiding dynamic allocation overhead during traversal [S1, unofficial].

### Inputs and Outputs
- **Input:** 3D voxel position (integer coordinates), voxel data (color, density, etc.), and configuration parameters (bounds, depth).
- **Output:** A pointer to the voxel data structure or a boolean indicating success/failure of allocation or retrieval.

### Data Structures
The core structure is a template class `tree<FORMAT_T, BIT_WIDTH, DETAILS>` [S1, unofficial].

1.  **`node_format`**: Represents an internal tree node.
    -   `_depth` (`uint32_t`): The depth of the node in the tree.
    -   `_mask` (`uint32_t`): A bitmask indicating which of the 8 children exist. Bit $i$ is set if child $i$ is present.
    -   `_block_index` (`uint32_t`): An index into the memory pool's block array, pointing to the block containing this node's children or the node itself if it is a leaf container.
2.  **`mem_pool<T>`**: Manages fixed-size blocks of memory.
    -   `_blocks`: An array of pointers to blocks, where each block holds exactly 8 elements of type $T$ (nodes or voxels) [S1, unofficial].
    -   `_free`: A free list of available block indices.
    -   Capacity: Each block holds 8 elements [S1, unofficial].
3.  **`_root_node`**: The root of the tree, initialized with `_depth=0` and a newly allocated node block [S1, unofficial].
4.  **`_node_pool`**: Manages `node_format` instances.
5.  **`_voxel_pool`**: Manages `FORMAT_T` (voxel data) instances.

### Parameters
-   **`BIT_WIDTH`**: Template parameter determining coordinate precision. Values are 16 or 32 [S1, unofficial].
    -   If 16, `SPACE_ABSOLUTE_MAX_DEPTH` is 5 ($32^3$ volume).
    -   If 32, `SPACE_ABSOLUTE_MAX_DEPTH` is 10 ($1024^3$ volume) [S1, unofficial].
-   **`BOUNDS`**: Maximum bounds per axis. Derived from `DETAILS._limit_max_bounds` or `ABSOLUTE_AXIS_WIDTH` if not specified [S1, unofficial].
-   **`DETAILS._discard_overflow`**: Boolean flag. If `true`, out-of-bounds voxels are silently dropped; if `false`, an assertion triggers [S1, unofficial].

### Algorithm Steps

#### 1. Allocation (`alloc`)
Inserts a voxel at a specific 3D position.

1.  **Overflow Check**: Compare `voxel_position` components against `BOUNDS[0..2]`. If any exceed bounds, return immediately if `_discard_overflow` is true, else assert [S1, unofficial].
2.  **Coordinate Transform**: Shift `voxel_position` left by 1 bit (multiply by 2) to align with the even-space grid [S1, unofficial].
3.  **Initialization**: Set `node_` to `_root_node`. Set `node_position` to `{0, 0, 0}`.
4.  **Internal Node Traversal**: Iterate `i` from 0 to `MAX_DEPTH - 2`:
    -   Compute `depth_ = i`.
    -   Compute `node_extent = AXIS_WIDTH >> depth_`.
    -   **Index Calculation**: Determine the child index, child bit, existence flag, and `next_node_position` based on `voxel_position` and `node_extent`. This logic (`SVO_NODE_RELATION_MATH_IMPL`) typically involves:
        -   `index = (voxel_position.x >> depth_) & 1 | ((voxel_position.y >> depth_) & 1) << 1 | ((voxel_position.z >> depth_) & 1) << 2`
        -   `child_bit = 1 << index`
        -   `exist = (node_->_mask & child_bit) != 0`
        -   `next_node_position = node_position + (index & 1 ? node_extent/2 : 0, ...)`
    -   Update `node_->_mask |= child_bit`.
    -   Fetch `node_block_` from `_node_pool._blocks[node_->_block_index]`.
    -   If `!exist`:
        -   Allocate a new node block.
        -   Create `new_node_` with `_depth = depth_ + 1`, `_mask = 0`.
        -   Set `new_node_->_block_index = _node_pool.acquire_next_index()`.
        -   Store `new_node_` in `node_block_[index]`.
        -   Allocate a new block in `_node_pool`.
        -   Update `node_` to point to `node_block_[index]`.
    -   Else:
        -   Update `node_` to point to `node_block_[index]`.
    -   Update `node_position = next_node_position`.
5.  **Voxel Octant Allocation**:
    -   Set `depth_ = MAX_DEPTH - 1`.
    -   Set `node_extent = 4`.
    -   Run index calculation logic.
    -   Set mask.
    -   If `!exist`:
        -   Create node with `_depth = MAX_DEPTH - 1`.
        -   Set `_block_index = _voxel_pool.acquire_next_index()`.
        -   Store in current node's block.
        -   Allocate new block in `_voxel_pool`.
        -   Update `node_`.
6.  **Voxel Allocation**:
    -   Set `node_extent = 2`.
    -   Run index calculation logic.
    -   Fetch `voxel_block_` from `_voxel_pool._blocks[node_->_block_index]`.
    -   Store `voxel` in `voxel_block_[index]` [S1, unofficial].

#### 2. Retrieval (`get`)
Retrieves a pointer to a voxel at a specific position.

1.  **Overflow Check**: Same as allocation. Return `nullptr` if out of bounds and `_discard_overflow` is true [S1, unofficial].
2.  **Initialization**: Start at `_root_node`, `node_position = {0,0,0}`.
3.  **Traversal Loop**: Iterate `i` from 0 to `MAX_DEPTH - 2`:
    -   Compute `depth_ = i`, `node_extent = AXIS_WIDTH >> depth_`.
    -   Calculate index and existence.
    -   If `!exist`, return `nullptr`.
    -   Fetch `node_block_` from `_node_pool`.
    -   Update `node_` to `node_block_[index]`.
    -   Update `node_position`.
4.  **Final Voxel Lookup**:
    -   Set `node_extent = 2`.
    -   Calculate index.
    -   If `!exist`, return `nullptr`.
    -   Return pointer to `_voxel_pool._blocks[node_->_block_index][index]` [S1, unofficial].

#### 3. Deallocation (`dealloc`)
Removes a voxel and cleans up empty nodes.

1.  **Trace Path**: Call `get_traced(voxel_position, &path_, &child_bits_, &depth_)` to retrieve the voxel pointer and fill the path array up to the reached depth. Return false if not found [S1, unofficial].
2.  **Voxel Block Deallocation**:
    -   Clear the child bit from `path_[depth_]->_mask`.
    -   If `mask != 0`, return true (node still has children).
    -   Else, dealloc voxel block via `_voxel_pool.dealloc(path_[depth_]->_block_index)`.
    -   Clear child bit from `path_[depth_-1]->_mask`.
    -   Decrement `depth_`.
3.  **Node Block Deallocation**:
    -   Loop `depth_` from current down to 1.
    -   If `path_[depth_]->_mask != 0`, break (parent has other children).
    -   Else, dealloc node block via `_node_pool.dealloc(path_[depth_]->_block_index)`.
    -   Clear child bit from `path_[depth_-1]->_mask`.
    -   Decrement `depth_` [S1, unofficial].

### Pseudocode
```python
# Constants
MAX_DEPTH = 10 # Example for 32-bit
AXIS_WIDTH = 1 << MAX_DEPTH
BOUNDS = [1024, 1024, 1024]

class Node:
    depth: int
    mask: int
    block_index: int

class Tree:
    root: Node
    node_pool: MemPool[Node]
    voxel_pool: MemPool[Voxel]

    def alloc(self, pos: Vec3, voxel: Voxel):
        # Overflow check
        if any(p >= b for p, b in zip(pos, BOUNDS)):
            if discard_overflow: return
            else: assert False

        # Transform
        pos = pos << 1
        
        node = self.root
        node_pos = Vec3(0, 0, 0)
        
        # Traverse internal nodes
        for i in range(MAX_DEPTH - 2):
            depth = i
            extent = AXIS_WIDTH >> depth
            
            # Calculate child index (0-7) based on pos and depth
            # Bit 0: x, Bit 1: y, Bit 2: z
            idx = ((pos.x >> depth) & 1) | (((pos.y >> depth) & 1) << 1) | (((pos.z >> depth) & 1) << 2)
            child_bit = 1 << idx
            
            node.mask |= child_bit
            
            block = self.node_pool.blocks[node.block_index]
            child_node = block[idx]
            
            if child_node is None:
                # Allocate new node
                new_node = Node()
                new_node.depth = depth + 1
                new_node.mask = 0
                new_node.block_index = self.node_pool.acquire_next_index()
                block[idx] = new_node
                self.node_pool.alloc() # Allocate new block for children
                node = new_node
            else:
                node = child_node
            
            # Update position for next level
            # If bit is set, add extent/2 to that axis
            if idx & 1: node_pos.x += extent // 2
            if idx & 2: node_pos.y += extent // 2
            if idx & 4: node_pos.z += extent // 2

        # Allocate voxel container (leaf node)
        depth = MAX_DEPTH - 1
        extent = 4
        idx = ((pos.x >> depth) & 1) | (((pos.y >> depth) & 1) << 1) | (((pos.z >> depth) & 1) << 2)
        child_bit = 1 << idx
        node.mask |= child_bit
        
        block = self.node_pool.blocks[node.block_index]
        child_node = block[idx]
        
        if child_node is None:
            new_node = Node()
            new_node.depth = MAX_DEPTH - 1
            new_node.mask = 0
            new_node.block_index = self.voxel_pool.acquire_next_index()
            block[idx] = new_node
            self.voxel_pool.alloc()
            node = new_node
        else:
            node = child_node
            
        # Store voxel
        voxel_block = self.voxel_pool.blocks[node.block_index]
        voxel_block[idx] = voxel

    def get(self, pos: Vec3) -> Voxel:
        if any(p >= b for p, b in zip(pos, BOUNDS)):
            if discard_overflow: return None
            else: assert False
            
        pos = pos << 1
        node = self.root
        node_pos = Vec3(0, 0, 0)
        
        for i in range(MAX_DEPTH - 1):
            depth = i
            extent = AXIS_WIDTH >> depth
            idx = ((pos.x >> depth) & 1) | (((pos.y >> depth) & 1) << 1) | (((pos.z >> depth) & 1) << 2)
            
            block = self.node_pool.blocks[node.block_index]
            child_node = block[idx]
            
            if child_node is None:
                return None
            
            node = child_node
            if idx & 1: node_pos.x += extent // 2
            if idx & 2: node_pos.y += extent // 2
            if idx & 4: node_pos.z += extent // 2
            
        # Final voxel lookup
        depth = MAX_DEPTH - 1
        extent = 2
        idx = ((pos.x >> depth) & 1) | (((pos.y >> depth) & 1) << 1) | (((pos.z >> depth) & 1) << 2)
        
        block = self.node_pool.blocks[node.block_index]
        child_node = block[idx]
        
        if child_node is None:
            return None
            
        voxel_block = self.voxel_pool.blocks[child_node.block_index]
        return voxel_block[idx]
```

## Subtopics

### [Morton-coded Sparse Voxel Tree](5212-morton-coded-sparse-voxel-tree.md)
A Morton-coded Sparse Voxel Tree is a flat-array sparse voxel tree that uses Morton codes for spatial ordering and an 8-bit mask per node to track children. It avoids recursive pointers by storing nodes in contiguous blocks of 8 elements, indexed via `node_format::_block_index`. This structure is designed for zero-tolerance overhead in traversal, distinguishing it from pointer-based SVO trees by eliminating indirection costs.

### [Hashed-Octree](7486-hashed-octree.md)
The Hashed-Octree is a sparse voxel representation that combines sparse voxel octrees (SVOs) with hash tables to provide constant-time data access for huge 3D environments. It solves the problem of increasing data access complexity in standard SVOs, which scales as $O(d)$ with tree depth $d$. By using a hash table to access root nodes of small internal octrees (typically depth $d=1$), it reduces access complexity to $O(d_b)$, offering a significant speedup over standard SVOs.

### [Spatio-Temporal Sparse Voxel Octree (STSVO)](7493-spatio-temporal-sparse-voxel-octree-stsvo.md)
The Spatio-Temporal Sparse Voxel Octree (STSVO) is a hierarchical data structure for representing the geometry of time-variable 3D scenes by treating the scene as a 4D static space (3 spatial dimensions + 1 time dimension). It uses a single SVO-like structure instead of a set of separate SVOs for each time frame. Compared to storing each time frame as a separate SVO (SVO set), STSVO provides a more compact binary representation, achieving 1.73 to 2.08 times more compactness.

### SVO Culling and Sorting
Post-processing steps for the SVO include culling unfilled branches, breadth-sorting for cache locality, and depth-sorting for traversal order [S3, unofficial].
-   **Cull unfilled**: Recursively traverse from root. If leaf node has color 0, return false (cull). If internal node, recursively cull children. If a child is culled, remove its bit from parent.occupancy. If parent becomes a leaf (only 1 child or 0 children depending on logic, code checks is_leaf after loop), return false. Otherwise update parent in nodes array and return true [S3, unofficial].
-   **Breadth-sort**: Create new nodes vector. Queue root. While queue not empty, pop node_ref. Clone node. For each child, push child_ref to queue front, update child reference in node to cursor, increment cursor. If node has color, encode node_ref into color (shifted and masked). Push node to new nodes vector [S3, unofficial].
-   **Depth-sort**: Create new nodes vector. Recursively traverse from root. For each node, create new reference (current nodes.len()), clone node, push to new nodes. Recursively update child references. Update node in new nodes array with updated children. Return new reference [S3, unofficial].

### VOLA (Octree with branching factor 64)
An efficient file format for storing quantized point cloud data with no attributes other than geometry, using an octree where two layers are combined into one [S4].
-   Store voxels as an octree rather than an array [S4].
-   Combine two layers of the octree into one, creating a tree with a branching factor of 64 [S4].

## Operating characteristics
-   **Time Complexity**: $O(MAX\_DEPTH)$ for allocation, retrieval, and deallocation. Since `MAX_DEPTH` is a small constant (3 to 10), operations are effectively $O(1)$ with a small constant factor [S1, unofficial].
-   **Memory Complexity**: $O(N)$ where $N$ is the number of allocated voxels. Each block holds exactly 8 elements (nodes or voxels). Overhead includes block metadata and free lists [S1, unofficial].
-   **Measured Performance**:
    -   Requires about 5 bytes per voxel with color, normal, and contour, or 6.67 bytes per finest-level sample once the mip hierarchy is counted [S2].
    -   If only surfaces are encoded, memory usage drops to $O(N^2)$ [S2].
    -   Traversal can suffer from branch/pipeline overhead on MSVC; loop unrolling yields ~2x speedup on Clang/Windows (~1.6M ns -> ~800k ns) [S1, unofficial].
    -   Octree traversal is worse than hierarchical-grid methods by as much as 60% [S2].
-   **Strengths**: Efficient storage for sparse data; supports dynamic updates via relative pointers in blocks [S2].
-   **Limitations**: Not ideal for dense data; traversal performance can be inferior to grid-based methods; bulk allocation estimation is difficult, so default vector strategies are used [S1, unofficial].
-   **When to use**: Storage and rendering of sparse volumetric data [S2].
-   **When not to use**: Dense volumes or scenarios requiring faster-than-tree traversal access [S2].

## Background
The Sparse Voxel Octree (SVO) was popularized by Laine and Karras (2010) for efficient rendering of large-scale environments [S2]. The structure builds on the principles of recursive subdivision and sparsity encoding shared by the parent family [Parent](4139-tree-based-structures-octree-pointer-tree-sparse-voxel-dag.md). It is primarily used in real-time rendering and VFX accelerators where polygonal models are unsuited for effects like global illumination [S4].
