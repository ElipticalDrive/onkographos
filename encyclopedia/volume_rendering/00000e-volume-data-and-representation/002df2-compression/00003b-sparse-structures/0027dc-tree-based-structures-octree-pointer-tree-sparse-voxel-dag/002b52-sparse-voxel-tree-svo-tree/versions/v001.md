# Sparse Voxel Tree (SVO Tree)

Also called: Hierarchical Voxel Storage, Voxel Tree

## Overview
The Sparse Voxel Tree (SVO Tree) is a hierarchical data structure for storing 3D voxel data, building on [Tree-based structures (Octree, Pointer Tree, Sparse Voxel DAG)](4139-tree-based-structures-octree-pointer-tree-sparse-voxel-dag.md) by using a fixed-depth, pointer-based octree where each node explicitly manages a block of 8 children or voxels. It solves the problem of efficiently storing and accessing sparse volumetric data with constant-time $O(1)$ (bounded by depth) allocation, lookup, and deallocation, distinguishing itself from siblings like [Sparse Voxel DAGs](2791-sparse-voxel-dags.md) by avoiding global deduplication in favor of simple, localized block management [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** 3D voxel position (integer coordinates), voxel data (format $T$), and optional bulk array of voxels.
- **Output:** Modified tree structure with allocated nodes/voxels, or retrieved voxel pointer.

**Data Structures:**
The structure is defined by the template `tree<FORMAT_T, BIT_WIDTH, DETAILS>` [S1, unofficial].

1.  **`node_format`**:
    -   `_depth` (`uint32_t`): Current depth in the tree (0 to `MAX_DEPTH`).
    -   `_mask` (`uint8_t`): 8-bit bitmask indicating which of the 8 children exist. Bit $i$ is set if child $i$ is allocated.
    -   `_block_index` (`uint32_t`): Index into the memory pool's `_blocks` array.
2.  **`mem_pool<T>`**:
    -   Manages fixed-size blocks of 8 elements of type $T$.
    -   `_blocks`: Array of pointers to blocks, where each block holds 8 contiguous $T$ elements.
    -   `_free`: Free list of available block indices.
    -   `alloc()`: Returns a new block index and allocates memory.
    -   `dealloc(index)`: Frees the block at `index` and adds to `_free`.
    -   `acquire_next_index()`: Returns the next available block index without immediate allocation (used for lazy allocation in some paths).
3.  **`tree` members**:
    -   `_root_node`: `node_format` instance, initialized at depth 0.
    -   `_node_pool`: `mem_pool<node_format>` for internal nodes.
    -   `_voxel_pool`: `mem_pool<FORMAT_T>` for leaf voxels.

**Constants and Parameters:**
-   `BIT_WIDTH`: Template parameter, typically 16 or 32 [S1, unofficial].
-   `SPACE_ABSOLUTE_MAX_DEPTH`: 5 if `BIT_WIDTH` is 16, 10 if 32 [S1, unofficial].
-   `ABSOLUTE_AXIS_WIDTH`: $2^{\text{SPACE\_ABSOLUTE\_MAX\_DEPTH}}$ (32 or 1024) [S1, unofficial].
-   `BOUNDS[3]`: Maximum bounds per axis. Defaults to `ABSOLUTE_AXIS_WIDTH` if `DETAILS._limit_max_bounds` is 0 [S1, unofficial].
-   `MAX_DEPTH`: Derived from `BOUNDS`, effectively the depth required to cover the bounding box [S1, unofficial].
-   `AXIS_WIDTH`: $2^{\text{MAX\_DEPTH}}$ [S1, unofficial].
-   `DETAILS._discard_overflow`: Boolean. If `true`, silently drops out-of-bounds voxels; if `false`, asserts on overflow [S1, unofficial].

**Algorithm Steps:**

1.  **Overflow Check:**
    Let $P = (x, y, z)$ be the voxel position. If any $P[i] \ge \text{BOUNDS}[i]$, return immediately (drop or assert) based on `DETAILS._discard_overflow` [S1, unofficial].

2.  **Coordinate Transform:**
    Shift position left by 1 bit: $P' = P \ll 1$. This aligns coordinates with an even-space grid [S1, unofficial].

3.  **Initialization:**
    Set `node_` to `_root_node`. Set `node_position` to $(0, 0, 0)$. Set `node_block_index` to `_root_node._block_index` [S1, unofficial].

4.  **Internal Node Traversal:**
    Iterate $i$ from $0$ to $\text{MAX\_DEPTH}-2$:
    -   Set `depth_` = $i$.
    -   Compute `node_extent` = $\text{AXIS\_WIDTH} \gg \text{depth\_}$ [S1, unofficial].
    -   Compute child index, bit, existence, and next position using `SVO_NODE_RELATION_MATH_IMPL()` (see below).
    -   Update `node_->_mask` with `child_bit`.
    -   Fetch `node_block_` from `_node_pool._blocks[node_->_block_index]`.
    -   If `!exist`:
        -   Allocate new node block: Set `new_node_._depth` = `depth_` + 1, `new_node_._mask` = 0.
        -   Set `new_node_._block_index` = `_node_pool.acquire_next_index()`.
        -   Store `new_node_` in `node_block_[index]`.
        -   Allocate new block in `_node_pool`.
        -   Update `node_` to `&node_block_[index]`.
    -   Else:
        -   Update `node_` to `&node_block_[index]`.
    -   Update `node_position` to `next_node_position` [S1, unofficial].

5.  **Voxel Octant Allocation (Pre-Leaf):**
    Set `depth_` = $\text{MAX\_DEPTH}-1$. Set `node_extent` = 4.
    Run `SVO_NODE_RELATION_MATH_IMPL()`.
    Update `node_->_mask` with `child_bit`.
    If `!exist`:
    -   Create node with `new_node_._depth` = $\text{MAX\_DEPTH}-1$, `new_node_._block_index` = `_voxel_pool.acquire_next_index()`.
    -   Store in `node_block_[index]`.
    -   Allocate new block in `_voxel_pool`.
    -   Update `node_` to `&node_block_[index]` [S1, unofficial].

6.  **Voxel Allocation (Leaf):**
    Set `depth_` = $\text{MAX\_DEPTH}$. Set `node_extent` = 2.
    Run `SVO_NODE_RELATION_MATH_IMPL()`.
    Update `node_->_mask` with `child_bit`.
    Fetch `voxel_block_` from `_voxel_pool._blocks[node_->_block_index]`.
    Store `voxel` in `voxel_block_[index]` [S1, unofficial].

**Helper: `SVO_NODE_RELATION_MATH_IMPL()`**
This macro/function computes the child index and existence based on the current node position, extent, and transformed voxel position [S1, unofficial]:
1.  Compute relative position: $R = P' - \text{node\_position}$.
2.  Compute child index: $idx = \sum_{k=0}^{2} \lfloor R[k] / \text{node\_extent} \rfloor \cdot 2^k$.
3.  Compute child bit: $bit = 1 \ll idx$.
4.  Check existence: $exist = (\text{node\_}->_mask \& bit) \neq 0$.
5.  Compute next position: $\text{next\_node\_position}[k] = \text{node\_position}[k] + \lfloor R[k] / \text{node\_extent} \rfloor \cdot \text{node\_extent}$.

**Deallocation:**
1.  **Trace:** Call `get_traced(voxel_position, &path_, &child_bits_, &depth_)` to retrieve the voxel pointer and fill `path_` (array of node pointers) and `child_bits_` (array of child bits) up to the reached depth. Return false if not found [S1, unofficial].
2.  **Voxel Block Deallocation:**
    -   Clear `child_bit` from `path_[depth_]->_mask`.
    -   If `path_[depth_]->_mask` != 0, return true (node still has children).
    -   Else, dealloc voxel block via `_voxel_pool.dealloc(path_[depth_]->_block_index)`.
    -   Clear `child_bit` from `path_[depth_-1]->_mask`.
    -   Decrement `depth_` [S1, unofficial].
3.  **Node Block Deallocation:**
    -   Loop `depth_` from current down to 1.
    -   If `path_[depth_]->_mask` != 0, break.
    -   Else, dealloc node block via `_node_pool.dealloc(path_[depth_]->_block_index)`.
    -   Clear `child_bit` from `path_[depth_-1]->_mask`.
    -   Decrement `depth_` [S1, unofficial].

**Pseudocode:**

```python
def alloc(tree, voxel_position, voxel):
    # 1. Overflow check
    if (voxel_position[0] >= tree.BOUNDS[0] or
        voxel_position[1] >= tree.BOUNDS[1] or
        voxel_position[2] >= tree.BOUNDS[2]):
        if tree.DETAILS._discard_overflow:
            return
        else:
            assert False, "Out of bounds"

    # 2. Coordinate transform
    voxel_transformed = voxel_position << 1

    # 3. Initialization
    node = tree._root_node
    node_position = [0, 0, 0]
    
    # 4. Internal Node Traversal
    for i in range(tree.MAX_DEPTH - 2):
        depth_ = i
        node_extent = tree.AXIS_WIDTH >> depth_
        
        # SVO_NODE_RELATION_MATH_IMPL
        relative = [voxel_transformed[k] - node_position[k] for k in range(3)]
        index = sum((relative[k] // node_extent) << k for k in range(3))
        child_bit = 1 << index
        exist = (node._mask & child_bit) != 0
        next_node_position = [node_position[k] + (relative[k] // node_extent) * node_extent for k in range(3)]
        
        node._mask |= child_bit
        
        node_block = tree._node_pool._blocks[node._block_index]
        
        if not exist:
            new_node = NodeFormat()
            new_node._depth = depth_ + 1
            new_node._mask = 0
            new_node._block_index = tree._node_pool.acquire_next_index()
            node_block[index] = new_node
            tree._node_pool.alloc()
            node = node_block[index]
        else:
            node = node_block[index]
            
        node_position = next_node_position

    # 5. Voxel Octant Allocation (Pre-Leaf)
    depth_ = tree.MAX_DEPTH - 1
    node_extent = 4
    
    # SVO_NODE_RELATION_MATH_IMPL
    relative = [voxel_transformed[k] - node_position[k] for k in range(3)]
    index = sum((relative[k] // node_extent) << k for k in range(3))
    child_bit = 1 << index
    exist = (node._mask & child_bit) != 0
    next_node_position = [node_position[k] + (relative[k] // node_extent) * node_extent for k in range(3)]
    
    node._mask |= child_bit
    
    node_block = tree._node_pool._blocks[node._block_index]
    
    if not exist:
        new_node = NodeFormat()
        new_node._depth = tree.MAX_DEPTH - 1
        new_node._mask = 0
        new_node._block_index = tree._voxel_pool.acquire_next_index()
        node_block[index] = new_node
        tree._voxel_pool.alloc()
        node = node_block[index]
    else:
        node = node_block[index]
        
    node_position = next_node_position

    # 6. Voxel Allocation (Leaf)
    depth_ = tree.MAX_DEPTH
    node_extent = 2
    
    # SVO_NODE_RELATION_MATH_IMPL
    relative = [voxel_transformed[k] - node_position[k] for k in range(3)]
    index = sum((relative[k] // node_extent) << k for k in range(3))
    child_bit = 1 << index
    exist = (node._mask & child_bit) != 0
    
    node._mask |= child_bit
    
    voxel_block = tree._voxel_pool._blocks[node._block_index]
    voxel_block[index] = voxel

def dealloc(tree, voxel_position):
    # 1. Trace
    path, child_bits, depth = get_traced(tree, voxel_position)
    if not path:
        return False
    
    # 2. Voxel Block Deallocation
    current_depth = depth
    node = path[current_depth]
    node._mask &= ~child_bits[current_depth]
    
    if node._mask != 0:
        return True
    
    tree._voxel_pool.dealloc(node._block_index)
    
    # 3. Node Block Deallocation
    current_depth -= 1
    while current_depth >= 1:
        node = path[current_depth]
        node._mask &= ~child_bits[current_depth]
        
        if node._mask != 0:
            break
            
        tree._node_pool.dealloc(node._block_index)
        current_depth -= 1
        
    return True
```

## Subtopics

### [Morton-coded Sparse Voxel Tree](5212-morton-coded-sparse-voxel-tree.md)
A flat-array sparse voxel tree that uses Morton codes for spatial ordering and an 8-bit mask per node to track children. It avoids recursive pointers by storing nodes in contiguous blocks of 8 elements, indexed via `node_format::_block_index`.

### SVO Culling and Sorting
Post-processing steps for the SVO: culling unfilled branches, breadth-sorting for cache locality, and depth-sorting for traversal order [S2, unofficial].
-   **Cull unfilled:** Recursively traverse from root. If leaf node has color 0, return false (cull). If internal node, recursively cull children. If a child is culled, remove its bit from parent.occupancy. If parent becomes a leaf (only 1 child or 0 children depending on logic, code checks is_leaf after loop), return false. Otherwise update parent in nodes array and return true [S2, unofficial].
-   **Breadth-sort:** Create new nodes vector. Queue root. While queue not empty, pop node_ref. Clone node. For each child, push child_ref to queue front, update child reference in node to cursor, increment cursor. If node has color, encode node_ref into color (shifted and masked). Push node to new nodes vector [S2, unofficial].
-   **Depth-sort:** Create new nodes vector. Recursively traverse from root. For each node, create new reference (current nodes.len()), clone node, push to new nodes. Recursively update child references. Update node in new nodes array with updated children. Return new reference [S2, unofficial].

## Operating characteristics
-   **Time Complexity:** $O(\text{MAX\_DEPTH})$ for alloc, get, dealloc. Since `MAX_DEPTH` is constant (3 to 10), operations are effectively $O(1)$ with a small constant factor [S1, unofficial].
-   **Memory Complexity:** $O(N)$ where $N$ is allocated voxels. Each block holds exactly 8 elements (nodes or voxels). Overhead includes block metadata and free lists [S1, unofficial].
-   **Performance:** Significant branch/pipeline overhead on MSVC during traversal loop. Applying `LOOP_UNROLL` macro yields ~2x speedup on Clang/Windows (~1.6M ns -> ~800k ns) [S1, unofficial].
-   **Strengths:** Simple implementation, constant-time operations, good cache locality due to block-based storage [S1, unofficial].
-   **Limitations:** No global deduplication (unlike DAGs), potential memory fragmentation if not managed carefully, bulk allocation estimation is difficult [S1, unofficial].
-   **When to use:** When simple, fast, and predictable memory management is prioritized over maximum compression or global deduplication [S1, unofficial].
-   **When not:** When global deduplication is critical or when memory efficiency for highly repetitive data is the primary concern [S1, unofficial].

## Background
The Sparse Voxel Tree (SVO Tree) is an implementation of a hierarchical voxel storage structure, often used in real-time volume rendering and ray tracing. The specific implementation details described here are from the `rapid-svo` repository by Severi Suominen [S1, unofficial]. The structure builds on the principles of octrees and pointer trees, adapting them for efficient voxel storage with block-based memory management [S1, unofficial].
