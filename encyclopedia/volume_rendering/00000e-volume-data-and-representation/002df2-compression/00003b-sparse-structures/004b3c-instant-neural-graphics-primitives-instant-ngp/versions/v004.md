# Instant Neural Graphics Primitives (Instant NGP)
Also called: INGP

## Overview
Instant Neural Graphics Primitives (Instant NGP) is a high-performance neural radiance field method that drastically accelerates training and inference by replacing the large, deep Multi-Layer Perceptron (MLP) of Vanilla NeRF with a compact structure using multi-resolution learnable hash grids [S1][S2, unofficial][S5]. It solves the bottleneck of slow convergence and high memory usage in implicit neural representations by explicitly encoding spatial information into trainable feature embeddings stored on grid vertices, which are then interpolated and fed into a shallow decoder [S2, S6, unofficial]. Unlike its siblings, it combines this multi-resolution hash encoding with advanced ray marching techniques (exponential stepping, empty space skipping) and fully fused CUDA kernels to achieve real-time rendering and convergence in minutes rather than hours [S1, S3][S6, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of training images with known camera poses; a 3D scene domain.
*   **Outputs:** A trained model consisting of multi-resolution hash feature embeddings, an occupancy grid, and a small rendering MLP; rendered pixel colors $\hat{C}(\mathbf{r})$ for arbitrary viewpoints.

**Data Structures:**
1.  **Multi-Resolution Hash Grids:** A hierarchy of $L$ levels. At each level $l \in \{1, \dots, L\}$, there is a 3D grid of resolution $R_l$ (e.g., ranging from 16 to 2048) [S4][S6, unofficial].
    *   **Feature Embeddings ($\Theta$):** Instead of storing a unique vector for every vertex, a fixed-size hash table is used per level. Each vertex index is mapped to this table via a spatial hash function [S2, unofficial][S4].
    *   **Embedding Vector:** Each entry in the hash table is a trainable feature vector $\theta_{il} \in \mathbb{R}^F$ [S4].
    *   **Parameters:** $F$ is the feature dimension (typical value: 8) [S4]. $T_l$ is the size of the hash table at level $l$ [S4].
2.  **Occupancy Grid:** A sparse grid used to accelerate rendering by identifying empty space [S4].
3.  **Rendering MLP:** A shallow neural network (decoder) that takes concatenated features and outputs density and color [S2, unofficial][S4].

**Numbered Steps:**

1.  **Initialization:** Define $L$ levels of 3D grids with increasing resolutions. Initialize the hash tables for feature embeddings $\Theta$ and the occupancy grid [S2, unofficial][S4].
2.  **Feature Retrieval (Hash Encoding):** For a 3D query point $\mathbf{x}$:
    *   For each level $l \in \{1, \dots, L\}$, identify the voxel containing $\mathbf{x}$ [S4].
    *   If the grid resolution exceeds a threshold, use a spatial hash function to map the voxel vertex indices to the hash table $\Theta$ to retrieve the feature vectors [S4].
    *   Perform trilinear interpolation of the 8 surrounding vertex features to obtain the feature vector $\mathbf{f}_l(\mathbf{x})$ for level $l$ [S2, unofficial][S4]:
        $$ \mathbf{f}_l(\mathbf{x}) = \text{interp}(\mathbf{x}, \Theta) $$
3.  **Feature Concatenation:** Concatenate the interpolated features from all $L$ levels into a single feature vector [S2, unofficial][S4]:
    $$ \mathbf{f}_{\text{concat}} = [\mathbf{f}_1(\mathbf{x}); \mathbf{f}_2(\mathbf{x}); \dots; \mathbf{f}_L(\mathbf{x})] $$
4.  **Decoding:** Pass $\mathbf{f}_{\text{concat}}$ (and potentially view direction $\mathbf{d}$) through the shallow rendering MLP to predict density $\sigma(\mathbf{x})$ and color $\mathbf{c}(\mathbf{x}, \mathbf{d})$ [S2, unofficial][S4].
5.  **Ray Marching:** Cast a ray $\mathbf{r}(v) = \mathbf{o} + v\mathbf{d}$ from the camera origin $\mathbf{o}$:
    *   Use the **Occupancy Grid** to skip empty space along the ray [S4].
    *   Sample points along the ray. Use **exponential stepping** to adapt step size based on density [S1].
    *   Accumulate color and transmittance using volume rendering integration [S4]:
        $$ \hat{C}(\mathbf{r}) = \int_{v_n}^{v_f} T(v) \sigma(\mathbf{r}(v)) \mathbf{c}(\mathbf{r}(v), \mathbf{d}) dv $$
        where transmittance $T(v) = \exp \left( - \int_{v_n}^{v} \sigma(\mathbf{r}(u)) du \right)$ [S4].
    *   Use **sample compaction** to discard samples with negligible contribution [S1].
6.  **Training:** Optimize the hash embeddings $\Theta$ and the MLP weights via gradient descent. Updates are local to the embeddings near the sampled points, unlike global weight updates in Vanilla NeRF [S2, S6, unofficial].

## Subtopics

### [Context-based NeRF Compression (CNC)](16592-context-based-nerf-compression-cnc.md)
Context-based NeRF Compression (CNC) is a compression framework for multi-resolution Instant-NGP-based NeRFs that utilizes context models to predict probabilities for entropy encoding feature embeddings, quantizes the rendering MLP, and compresses a binary occupancy grid. It achieves significant rate-distortion improvements over prior methods by excavating level-wise and dimension-wise context dependencies to reduce information entropy. Unlike previous methods that rely on pruning and quantization (Deep Compression concept), CNC decreases information uncertainty (entropy) of voxel feature encoding using efficient entropy codecs like Arithmetic Coding.

## Operating characteristics
*   **Time Complexity:** Training convergence is significantly faster than Vanilla NeRF, reducing from hours to minutes per scene [S2, unofficial][S3]. Inference is optimized for real-time rendering [S5][S6, unofficial].
*   **Memory Complexity:** Memory consumption is drastically reduced compared to unique feature vectors per vertex due to embedding sharing via hashing [S2, unofficial]. The total storage includes feature embeddings, occupancy grid, and rendering MLP, with feature embeddings accounting for over 99% of the storage size [S4].
*   **Performance:** Enables real-time rendering and training within a minute [S6, unofficial]. On an RTX 3090, training the Lego model (800x800 resolution, 20,000 iterations) took 170 seconds [S6, unofficial].
*   **Strengths:** High training speed, real-time rendering capability, continuous representation avoiding blocky artifacts, local constraint during training improves stability [S2, S6, unofficial].
*   **Limitations:** Storage cost is still dominated by hash embeddings, which can be large for high-resolution scenes [S4]. Requires GPU memory for training [S7, unofficial].
*   **When to use:** When fast training and real-time rendering are required for neural radiance fields.
*   **When not to use:** When extreme storage compression is the primary goal without considering the complexity of context-based compression techniques like CNC.

## Background
Instant Neural Graphics Primitives (Instant NGP) was introduced by NVIDIA in January 2022 [S1]. It was developed to address the slow training and inference speeds of previous Neural Radiance Field (NeRF) methods. The key contribution is the multi-resolution hash encoding, which maps input coordinates to a higher-dimensional embedding space using a cascade of hash tables [S5]. This approach, combined with fully fused CUDA kernels and mixed-precision computation, allows for efficient GPU utilization [S5]. The method has become a staple in modern NeRF architectures due to its balance of speed and quality [S4].
