# Dense-to-Sparse Voxel Octree Conversion


## Overview
This method converts a fixed-size dense 3D voxel grid into a sparse octree structure by recursively hashing child nodes to detect and merge identical subtrees [S1, unofficial].

## How it works
**Inputs:** A dense voxel grid (`DenseVoxelData`) of depth $d$ [S1, unofficial].
**Outputs:** A sparse octree (`VoxelTree`) with merged identical subtrees [S1, unofficial].

**Data Structures:**
*   `DenseVoxelData`:
    *   `size` (usize): Side length of the cube, $2^d$.
    *   `depth` (usize): Tree depth + 1.
    *   `data` (Vec<VoxelNode>): Flat array of size $2^{3d}$.
*   `VoxelNode`:
    *   `childmask` (u8): Bitmask of valid children.
    *   `flags` (u8): Status flags.
    *   `colour` ([u8; 3]): RGB color.
    *   `emission` (u8): Emissive intensity.
    *   `metalness` (u8): Metallic factor.
    *   `roughness` (u8): Roughness factor.
    *   *Note:* The node data is approximately 10 bytes, followed by dynamic pointers in the tree structure [S1, unofficial].
*   `VoxelTree`:
    *   `base` (*mut u32): Pointer to the contiguous node data buffer.
    *   `allocator` (*mut u32): Current allocation offset within the buffer.
    *   `layout` (std::alloc::Layout): Memory layout for allocation.

**Algorithm Steps:**

1.  **Initialize Dense Grid:** Set `size` to $2^d$. Allocate `data` vector of size $2^{3d}$ containing empty `VoxelNode` instances [S1, unofficial].
2.  **Pre-calculate Capacity:** Estimate initial sparse tree capacity for memory pre-allocation. Calculate the sum of $2^{3i}$ for $i$ from 1 to $depth$, multiply by 10 (bytes per node) plus 1, then multiply by 4 (bytes per u32) [S1, unofficial].
3.  **Initialize Level Buckets:** Create a `levels` vector where `levels[0]` is reserved for 1 node, and `levels[x]` is reserved for $8^{x+1}$ nodes [S1, unofficial].
4.  **Recursive Traversal and Hashing (`do_child`):**
    *   Traverse the dense grid recursively.
    *   **Leaf Level:** Copy the `VoxelNode` to a temporary sparse node. Set `childmask` to 0. Compute a hash of the `SparseNode` (combining node ID and 8 child hashes). Push the result to `levels[level]` [S1, unofficial].
    *   **Internal Node:** Allocate 8 children. Recursively call `do_child` for each child using offset coordinates based on the octant index $i$. Compute the `child_hashes` array from the results [S1, unofficial].
    *   **Empty Subtrees:** Flag empty children during hash computation to allow removal later [S1, unofficial].
5.  **Sort for Deduplication:** Sort the nodes at each level (from 1 to max depth) by their computed hash value. This groups identical subtrees together [S1, unofficial].
6.  **Iterative Deduplication:**
    *   Iterate through the sorted nodes at level $i$.
    *   If the current hash matches the previous hash, replace the child pointer with the previous node's reference (deduplication) [S1, unofficial].
    *   If the hash is different, allocate a new node in the intermediate tree and record the mapping in a `HashMap` [S1, unofficial].
7.  **Remove Empty Children:** Traverse parent nodes and remove empty children if the child subtree was flagged as empty during the hash computation phase [S1, unofficial].
8.  **Rebuild Final Tree (`look_node`):**
    *   Recursively copy nodes from the intermediate tree to the final tree (`tree2`).
    *   Use the `HashMap` to deduplicate identical subtrees during the copy.
    *   **`look_node` Logic:** If a node is already in the `HashMap`, return the mapped pointer. Otherwise, allocate a new node, copy data, mark as processed, recursively process children, and update the `HashMap` [S1, unofficial].
9.  **Finalize:** Free the original intermediate tree. Reallocate `tree2` to fit the exact memory usage of the final sparse structure [S1, unofficial].

**Pseudocode:**

```python
class VoxelNode:
    def __init__(self):
        self.childmask = 0
        self.flags = 0
        self.colour = [0, 0, 0]
        self.emission = 0
        self.metalness = 0
        self.roughness = 0

class SparseNode:
    def __init__(self, data, childmask, children_hashes=None):
        self.data = data
        self.childmask = childmask
        self.children_hashes = children_hashes or []
        self.ptr = None

class HashEntry:
    def __init__(self, hash_val, node):
        self.hash = hash_val
        self.node = node

def compute_hash(node_id, child_hashes):
    return hash((node_id,) + tuple(child_hashes))

def octant_coords(octant, level, base_x, base_y, base_z, size):
    # Standard Morton/Z-order offset calculation [G]
    x, y, z = base_x, base_y, base_z
    step = size >> (level + 1)
    if octant & 1: x += step
    if octant & 2: y += step
    if octant & 4: z += step
    return x, y, z

def do_child(x, y, z, level, max_depth, dense_data, levels, node_counter):
    node_id = next(node_counter)
    if level == max_depth:
        idx = (x * dense_data.size**2 + y * dense_data.size + z)
        node_data = dense_data.data[idx]
        sparse_node = SparseNode(data=node_data, childmask=0)
        h = compute_hash(node_id, [0] * 8)
        levels[level].append(HashEntry(h, sparse_node))
        return h

    child_hashes = []
    for i in range(8):
        cx, cy, cz = octant_coords(i, level, x, y, z, dense_data.size)
        child_hashes.append(do_child(cx, cy, cz, level + 1, max_depth, dense_data, levels, node_counter))

    sparse_node = SparseNode(data=None, childmask=0xFF, children_hashes=child_hashes)
    h = compute_hash(node_id, child_hashes)
    levels[level].append(HashEntry(h, sparse_node))
    return h

def convert_dense_to_sparse(depth):
    size = 1 << depth
    dense_data = DenseVoxelData(size=size, depth=depth + 1, data=[VoxelNode()] * (size ** 3))

    # Pre-calculate capacity
    capacity = (sum(2**(3*i) for i in range(1, depth + 1)) * 10 + 1) * 4

    # Initialize levels
    levels = [[] for _ in range(depth + 1)]
    levels[0].append(HashEntry(0, SparseNode(data=None, childmask=0)))

    node_counter = iter(range(1, 10**9))
    do_child(0, 0, 0, 0, depth, dense_data, levels, node_counter)

    # Sort for deduplication
    for l in range(1, len(levels)):
        levels[l].sort(key=lambda e: e.hash)

    # Iterative deduplication
    tree2 = VoxelTree()
    hash_map = {}
    for l in range(1, len(levels)):
        prev_entry = None
        for entry in levels[l]:
            if entry.hash == prev_entry.hash:
                entry.node.ptr = prev_entry.node.ptr
            else:
                entry.node.ptr = tree2.allocate(entry.node)
                hash_map[entry.hash] = entry.node.ptr
            prev_entry = entry

    # Remove empty children (flagged during hash computation)
    # Implementation detail: traverse and clear childmask bits for empty subtrees

    # Rebuild final tree using look_node
    final_tree = VoxelTree()
    final_map = {}
    def look_node(node, parent_map, target_tree):
        if node.hash in parent_map:
            return parent_map[node.hash]
        new_ptr = target_tree.allocate(node)
        parent_map[node.hash] = new_ptr
        if node.children_hashes:
            for ch_hash in node.children_hashes:
                child_node = next(n for e in levels if e.hash == ch_hash for n in [e.node])
                look_node(child_node, parent_map, target_tree)
        return new_ptr

    look_node(levels[0][0].node, final_map, final_tree)

    # Free original and reallocate
    del dense_data
    final_tree.reallocate_exact()
    return final_tree
```

**Parameters:**
*   `chunksize`: 1000. Used in parallel iteration for CPU rendering to balance workload across threads [S1, unofficial].

**Pitfalls:**
*   **Hash Collisions:** Using a default hasher (e.g., `DefaultHasher`) may result in collisions where two different subtrees produce the same hash, leading to incorrect merging [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$ for the initial traversal where $N$ is the number of dense voxels, plus $O(M \log M)$ for sorting where $M$ is the number of sparse nodes, plus $O(M)$ for rebuilding the tree [S1, unofficial].
*   **Memory Complexity:** Proportional to the number of unique subtrees $M$. The method pre-allocates based on a theoretical maximum capacity before reallocating to exact size [S1, unofficial].
