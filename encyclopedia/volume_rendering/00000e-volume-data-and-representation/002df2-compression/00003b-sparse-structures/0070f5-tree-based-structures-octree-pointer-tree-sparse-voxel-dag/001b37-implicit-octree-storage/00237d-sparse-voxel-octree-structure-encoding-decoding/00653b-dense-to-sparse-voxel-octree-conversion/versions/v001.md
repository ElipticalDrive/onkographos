# Dense-to-Sparse Voxel Octree Conversion

Also called: Sparse Voxel Octree Construction, Octree Deduplication

## Overview
This method converts a fixed-size dense 3D voxel grid into a memory-efficient sparse octree structure by recursively hashing child nodes to detect and merge identical subtrees [S1, unofficial]. It sets itself apart from sibling methods like [Tolerance-based Voxel Fusion](5866-tolerance-based-voxel-fusion.md) by performing exact structural deduplication rather than geometric approximation, and from [Sparse Voxel DAG](5984-sparse-voxel-dag.md) by using a hash-based grouping phase rather than explicit pointer sharing during construction [S1, unofficial].

## How it works
**Inputs:** A dense voxel grid (`DenseVoxelData`) of depth $d$.
**Outputs:** A sparse octree (`VoxelTree`) with merged identical subtrees.

**Data Structures:**
*   `DenseVoxelData`:
    *   `size` (usize): Side length of the cube, $2^d$.
    *   `depth` (usize): Tree depth + 1.
    *   `data` (Vec<VoxelNode>): Flat array of size $2^{3d}$.
*   `VoxelNode`:
    *   `childmask` (u8): Bitmask of valid children.
    *   `flags` (u8): Status flags.
    *   `colour` ([u8; 3]): RGB color.
    *   `emission` (u8): Emissive intensity.
    *   `metalness` (u8): Metallic factor.
    *   `roughness` (u8): Roughness factor.
    *   *Note:* The node data is approximately 10 bytes, followed by dynamic pointers in the tree structure [S1, unofficial].
*   `VoxelTree`:
    *   `base` (*mut u32): Pointer to the contiguous node data buffer.
    *   `allocator` (*mut u32): Current allocation offset within the buffer.
    *   `layout` (std::alloc::Layout): Memory layout for allocation.

**Algorithm Steps:**

1.  **Initialize Dense Grid:** Set `size` to $2^d$. Allocate `data` vector of size $2^{3d}$ containing empty `VoxelNode` instances [S1, unofficial].
2.  **Pre-calculate Capacity:** Estimate initial sparse tree capacity for memory pre-allocation. Calculate the sum of $2^{3i}$ for $i$ from 1 to $depth$, multiply by 10 (bytes per node) plus 1, then multiply by 4 (bytes per u32) [S1, unofficial].
3.  **Initialize Level Buckets:** Create a `levels` vector where `levels[0]` is reserved for the root node, and `levels[x]` is reserved for $8^{x+1}$ nodes [S1, unofficial].
4.  **Recursive Traversal and Hashing (`do_child`):**
    *   Traverse the dense grid recursively.
    *   **Leaf Level:** Copy the `VoxelNode` to a temporary sparse node. Set `childmask` to 0. Compute a hash of the `SparseNode` (combining node ID and 8 child hashes). Push the result to `levels[level]` [S1, unofficial].
    *   **Internal Node:** Allocate 8 children. Recursively call `do_child` for each child using offset coordinates based on the octant index $i$. Compute the `child_hashes` array from the results [S1, unofficial].
    *   **Empty Subtrees:** Flag empty children during hash computation to allow removal later [S1, unofficial].
5.  **Sort for Deduplication:** Sort the nodes at each level (from 1 to max depth) by their computed hash value. This groups identical subtrees together [S1, unofficial].
6.  **Iterative Deduplication:**
    *   Iterate through the sorted nodes at level $i$.
    *   If the current hash matches the previous hash, replace the child pointer with the previous node's reference (deduplication) [S1, unofficial].
    *   If the hash is different, allocate a new node in the intermediate tree and record the mapping in a `HashMap` [S1, unofficial].
7.  **Remove Empty Children:** Traverse parent nodes and remove empty children if the child subtree was flagged as empty during the hash computation phase [S1, unofficial].
8.  **Rebuild Final Tree (`look_node`):**
    *   Recursively copy nodes from the intermediate tree to the final tree (`tree2`).
    *   Use the `HashMap` to deduplicate identical subtrees during the copy.
    *   **`look_node` Logic:** If a node is already in the `HashMap`, return the mapped pointer. Otherwise, allocate a new node, copy data, mark as processed, recursively process children, and update the `HashMap` [S1, unofficial].
9.  **Finalize:** Free the original intermediate tree. Reallocate `tree2` to fit the exact memory usage of the final sparse structure [S1, unofficial].

**Pseudocode:**

```python
# Data Structures
class VoxelNode:
    childmask: u8
    flags: u8
    colour: [u8; 3]
    emission: u8
    metalness: u8
    roughness: u8

class DenseVoxelData:
    size: usize
    depth: usize
    data: Vec[VoxelNode]

class VoxelTree:
    base: *u32
    allocator: *u32
    layout: Layout

# Step 1: Initialize
def init_dense(depth: usize) -> DenseVoxelData:
    size = 1 << depth
    data = [VoxelNode() for _ in range(size ** 3)]
    return DenseVoxelData(size=size, depth=depth + 1, data=data)

# Step 4: Recursive Hashing
def do_child(node: VoxelNode, level: usize, max_depth: usize, levels: List[List[HashEntry]]) -> HashEntry:
    if level == max_depth:
        # Leaf level
        sparse_node = SparseNode(data=node, childmask=0)
        hash_val = compute_hash(sparse_node.id, [0]*8) # No children
        levels[level].append(HashEntry(hash=hash_val, node=sparse_node))
        return HashEntry(hash=hash_val, node=sparse_node)
    
    # Internal node
    children_hashes = []
    for i in range(8):
        # Recursively process children based on octant index
        child_entry = do_child_recursive_child(i, level + 1, max_depth, levels)
        children_hashes.append(child_entry.hash)
    
    # Compute hash of current node based on children hashes
    current_hash = compute_hash(node.id, children_hashes)
    
    # Create sparse node with children hashes
    sparse_node = SparseNode(data=node, childmask=0xFF, children_hashes=children_hashes)
    levels[level].append(HashEntry(hash=current_hash, node=sparse_node))
    
    return HashEntry(hash=current_hash, node=sparse_node)

# Step 5: Sort
def sort_levels(levels: List[List[HashEntry]]):
    for level in levels:
        level.sort(key=lambda x: x.hash)

# Step 6: Deduplication
def deduplicate_levels(levels: List[List[HashEntry]]) -> VoxelTree:
    tree = VoxelTree()
    hash_map = HashMap<u64, NodePtr>
    
    for level in range(1, len(levels)):
        prev_entry = None
        for entry in levels[level]:
            if entry.hash == prev_entry.hash:
                # Deduplicate: point to previous node
                entry.node.ptr = prev_entry.node.ptr
            else:
                # Allocate new node
                new_ptr = tree.allocate(entry.node)
                hash_map[entry.hash] = new_ptr
                entry.node.ptr = new_ptr
            prev_entry = entry
            
    return tree

# Step 8: Rebuild
def look_node(node: SparseNode, hash_map: HashMap[u64, NodePtr], tree: VoxelTree) -> NodePtr:
    if node.hash in hash_map:
        return hash_map[node.hash]
    
    new_ptr = tree.allocate(node)
    hash_map[node.hash] = new_ptr
    
    # Recursively process children
    for child_hash in node.children_hashes:
        # Find corresponding child node in previous level or intermediate structure
        # This step assumes access to the intermediate structure built in do_child
        child_node = find_node_by_hash(child_hash)
        look_node(child_node, hash_map, tree)
        
    return new_ptr

# Main Execution
def convert_dense_to_sparse(dense_data: DenseVoxelData) -> VoxelTree:
    levels = [[] for _ in range(dense_data.depth)]
    levels[0].append(HashEntry(hash=0, node=RootNode())) # Reserve root
    
    # Traverse and hash
    do_child(dense_data.data[0], 0, dense_data.depth - 1, levels)
    
    # Sort and deduplicate
    sort_levels(levels)
    tree = deduplicate_levels(levels)
    
    # Remove empty children (implementation detail omitted, see Step 7)
    remove_empty_children(tree)
    
    # Rebuild final tree with exact sizing
    final_tree = VoxelTree()
    hash_map = HashMap[u64, NodePtr]()
    look_node(levels[0][0].node, hash_map, final_tree)
    
    # Free intermediate structures and reallocate
    free_intermediate()
    final_tree.reallocate_exact()
    
    return final_tree
```

**Parameters:**
*   `chunksize`: 1000. Used in parallel iteration for CPU rendering to balance workload across threads [S1, unofficial].

**Pitfalls:**
*   **Hash Collisions:** Using a default hasher (e.g., `DefaultHasher`) may result in collisions where two different subtrees produce the same hash, leading to incorrect merging. A robust implementation should use a stronger hash function or verify equality on hash match [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$ for the initial traversal where $N$ is the number of dense voxels, plus $O(M \log M)$ for sorting where $M$ is the number of sparse nodes, plus $O(M)$ for rebuilding the tree [S1, unofficial].
*   **Memory Complexity:** Proportional to the number of unique subtrees $M$. The method pre-allocates based on a theoretical maximum capacity before reallocating to exact size [S1, unofficial].
*   **Strengths:** Significantly reduces memory usage for scenes with repetitive structures (e.g., natural terrain, repeated objects) by merging identical subtrees.
*   **Limitations:** The sorting step ($O(M \log M)$) can be a bottleneck for very large, diverse scenes with few identical subtrees. Hash collisions can corrupt the structure if not handled [S1, unofficial].
*   **When to use:** Ideal for static scenes with high redundancy. Not suitable for highly dynamic or unique data where deduplication gains are minimal.

## Background
This method originates from the implementation details of the `svdag` project by Sam H. Smith, which explores sparse voxel octree and DAG structures for volume rendering [S1, unofficial]. It is part of a broader effort to optimize memory usage in real-time volume rendering by leveraging structural redundancy.
