# Dense-to-Sparse Voxel Octree Conversion


## Overview
This method converts a fixed-size dense 3D voxel grid into a sparse octree structure by recursively hashing child nodes to detect and merge identical subtrees [S1, unofficial].

## How it works
**Inputs:** A dense voxel grid (`DenseVoxelData`) of depth $d$ [S1, unofficial].
**Outputs:** A sparse octree (`VoxelTree`) with merged identical subtrees [S1, unofficial].

**Data Structures:**
*   `DenseVoxelData`:
    *   `size` (usize): Side length of the cube, $2^d$ [S1, unofficial].
    *   `depth` (usize): Tree depth + 1 [S1, unofficial].
    *   `data` (Vec<VoxelNode>): Flat array of size $2^{3d}$ [S1, unofficial].
*   `VoxelNode`:
    *   `childmask` (u8): Bitmask of valid children [S1, unofficial].
    *   `flags` (u8): Status flags [S1, unofficial].
    *   `colour` ([u8; 3]): RGB color [S1, unofficial].
    *   `emission` (u8): Emissive intensity [S1, unofficial].
    *   `metalness` (u8): Metallic factor [S1, unofficial].
    *   `roughness` (u8): Roughness factor [S1, unofficial].
    *   *Note:* The node data is approximately 10 bytes, followed by dynamic pointers in the tree structure [S1, unofficial].
*   `VoxelTree`:
    *   `base` (*mut u32): Pointer to the contiguous node data buffer [S1, unofficial].
    *   `allocator` (*mut u32): Current allocation offset within the buffer [S1, unofficial].
    *   `layout` (std::alloc::Layout): Memory layout for allocation [S1, unofficial].

**Algorithm Steps:**

1.  **Initialize Dense Grid:** Set `size` to $2^d$ [S1, unofficial]. Allocate `data` vector of size $2^{3d}$ containing empty `VoxelNode` instances [S1, unofficial].
2.  **Pre-calculate Capacity:** Estimate initial sparse tree capacity for memory pre-allocation [S1, unofficial]. Calculate the sum of $2^{3i}$ for $i$ from 1 to $depth$, multiply by 10 (bytes per node) plus 1, then multiply by 4 (bytes per u32) [S1, unofficial].
3.  **Initialize Level Buckets:** Create a `levels` vector where `levels[0]` is reserved for 1 node, and `levels[x]` is reserved for $8^{x+1}$ nodes [S1, unofficial].
4.  **Recursive Traversal and Hashing (`do_child`):**
    *   Traverse the dense grid recursively [S1, unofficial].
    *   **Leaf Level:** Copy the `VoxelNode` to a temporary sparse node [S1, unofficial]. Set `childmask` to 0 [S1, unofficial]. Compute a hash of the `SparseNode` (combining node ID and 8 child hashes) [S1, unofficial]. Push the result to `levels[level]` [S1, unofficial].
    *   **Internal Node:** Allocate 8 children [S1, unofficial]. Recursively call `do_child` for each child using offset coordinates based on the octant index $i$ [S1, unofficial]. Compute the `child_hashes` array from the results [S1, unofficial].
    *   **Empty Subtrees:** Flag empty children during hash computation to allow removal later [S1, unofficial].
5.  **Sort for Deduplication:** Sort the nodes at each level (from 1 to max depth) by their computed hash value [S1, unofficial]. This groups identical subtrees together [S1, unofficial].
6.  **Iterative Deduplication:**
    *   Iterate through the sorted nodes at level $i$ [S1, unofficial].
    *   If the current hash matches the previous hash, replace the child pointer with the previous node's reference (deduplication) [S1, unofficial].
    *   If the hash is different, allocate a new node in the intermediate tree and record the mapping in a `HashMap` [S1, unofficial].
7.  **Remove Empty Children:** Traverse parent nodes and remove empty children if the child subtree was flagged as empty during the hash computation phase [S1, unofficial].
8.  **Rebuild Final Tree (`look_node`):**
    *   Recursively copy nodes from the intermediate tree to the final tree (`tree2`) [S1, unofficial].
    *   Use the `HashMap` to deduplicate identical subtrees during the copy [S1, unofficial].
    *   **`look_node` Logic:** If a node is already in the `HashMap`, return the mapped pointer [S1, unofficial]. Otherwise, allocate a new node, copy data, mark as processed, recursively process children, and update the `HashMap` [S1, unofficial].
9.  **Finalize:** Free the original intermediate tree [S1, unofficial]. Reallocate `tree2` to fit the exact memory usage of the final sparse structure [S1, unofficial].

**Pseudocode:**

```python
class VoxelNode:
    childmask: u8
    flags: u8
    colour: [u8; 3]
    emission: u8
    metalness: u8
    roughness: u8

class SparseNode:
    data: VoxelNode | None
    childmask: u8
    children_hashes: list[u64]
    hash_val: u64
    ptr: u32 | None
    children: list[SparseNode]

def compute_hash(node_id: u32, child_hashes: list[u64]) -> u64:
    return hash((node_id,) + tuple(child_hashes))

def octant_coords(octant: u3, level: u3, base_x: u32, base_y: u32, base_z: u32, size: u32) -> tuple[u32, u32, u32]:
    step = size >> (level + 1)
    x, y, z = base_x, base_y, base_z
    if octant & 1: x += step
    if octant & 2: y += step
    if octant & 4: z += step
    return x, y, z

def do_child(x: u32, y: u32, z: u32, level: u3, max_depth: u3, dense_data: DenseVoxelData, levels: list[list[SparseNode]], node_counter: iter) -> u64:
    node_id = next(node_counter)
    if level == max_depth:
        idx = (x * dense_data.size**2 + y * dense_data.size + z)
        node_data = dense_data.data[idx]
        sparse_node = SparseNode(data=node_data, childmask=0, children_hashes=[], hash_val=0, ptr=None, children=[])
        sparse_node.hash_val = compute_hash(node_id, [])
        levels[level].append(sparse_node)
        return sparse_node.hash_val

    child_hashes = []
    for i in range(8):
        cx, cy, cz = octant_coords(i, level, x, y, z, dense_data.size)
        child_hashes.append(do_child(cx, cy, cz, level + 1, max_depth, dense_data, levels, node_counter))

    sparse_node = SparseNode(data=None, childmask=0xFF, children_hashes=child_hashes, hash_val=0, ptr=None, children=[])
    sparse_node.hash_val = compute_hash(node_id, child_hashes)
    levels[level].append(sparse_node)
    return sparse_node.hash_val

def convert_dense_to_sparse(depth: u3) -> VoxelTree:
    size = 1 << depth
    dense_data = DenseVoxelData(size=size, depth=depth + 1, data=[VoxelNode()] * (size ** 3))

    # Pre-calculate capacity
    capacity = (sum(2**(3*i) for i in range(1, depth + 1)) * 10 + 1) * 4

    # Initialize levels
    levels = [[] for _ in range(depth + 1)]
    levels[0].append(SparseNode(data=None, childmask=0, children_hashes=[], hash_val=0, ptr=None, children=[]))

    node_counter = iter(range(1, 10**9))
    do_child(0, 0, 0, 0, depth, dense_data, levels, node_counter)

    # Sort for deduplication
    for l in range(1, len(levels)):
        levels[l].sort(key=lambda n: n.hash_val)

    # Iterative deduplication
    tree2 = VoxelTree()
    hash_map = {}
    for l in range(1, len(levels)):
        prev_node = None
        for node in levels[l]:
            if prev_node is not None and node.hash_val == prev_node.hash_val:
                node.ptr = prev_node.ptr
            else:
                node.ptr = tree2.allocate(node)
                hash_map[node.hash_val] = node.ptr
            prev_node = node

    # Remove empty children (flagged during hash computation)
    # Implementation detail: traverse and clear childmask bits for empty subtrees

    # Rebuild final tree using look_node
    final_tree = VoxelTree()
    final_map = {}
    def look_node(node: SparseNode, parent_map: dict, target_tree: VoxelTree) -> u32:
        if node.hash_val in parent_map:
            return parent_map[node.hash_val]
        new_ptr = target_tree.allocate(node)
        parent_map[node.hash_val] = new_ptr
        for child_node in node.children:
            look_node(child_node, parent_map, target_tree)
        return new_ptr

    look_node(levels[0][0], final_map, final_tree)

    # Free original and reallocate
    del dense_data
    final_tree.reallocate_exact()
    return final_tree
```

**Parameters:**
*   `chunksize`: 1000. Used in parallel iteration for CPU rendering to balance workload across threads [S1, unofficial].

**Pitfalls:**
*   **Hash Collisions:** Using a default hasher (e.g., `DefaultHasher`) may result in collisions where two different subtrees produce the same hash, leading to incorrect merging [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$ for the initial traversal where $N$ is the number of dense voxels, plus $O(M \log M)$ for sorting where $M$ is the number of sparse nodes, plus $O(M)$ for rebuilding the tree [S1, unofficial].
*   **Memory Complexity:** Proportional to the number of unique subtrees $M$ [S1, unofficial]. The method pre-allocates based on a theoretical maximum capacity before reallocating to exact size [S1, unofficial].
