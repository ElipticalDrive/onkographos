# Snapped Grid Extent Quantization

Also called: 2^16-1 bins quantization, AABB Quantization for BVH Nodes, BVH layout for sg-eq, sg-eq

## Overview
Snapped Grid Extent Quantization (sg-eq) is a BVH data layout technique that compresses axis-aligned bounding box (AABB) coordinates into fixed-point integers relative to a global coordinate frame anchored at the root [S1]. It solves the trade-off between memory footprint and computational cost by achieving aggressive compression (12 bytes per node) compared to standard layouts, though it relies on directed rounding modes for watertight dequantization [S1]. Unlike its successor [pbrt-q16](19485-pbrt-q16.md), which uses 16-bit quantization and standard arithmetic, sg-eq uses 10-bit quantization and expensive directed rounding intrinsics, making it less portable across architectures without explicit support [S1].

## How it works
**Inputs and Outputs:**
- Input: A BVH tree structure with world-space bounding boxes for each node [S1].
- Output: A compact binary layout where internal nodes store quantized bounds and child offsets, and leaf nodes store quantized bounds and primitive offsets [S1].

**Data Structures:**
The layout consists of a root header and a contiguous group of nodes indexed by `u32` [S1].

1.  **Root Header:**
    - `primitive_count`: `u32`
    - `primitives`: Array of `Triangle` of size `primitive_count`
    - `wlow`: `f32x3` (World-space minimum bounds)
    - `whigh`: `f32x3` (World-space maximum bounds)
    - `bins`: `f32x3` (Bin scales)
    - `bins_inv`: `f32x3` (Reciprocal bin scales)
    - `node_count`: `u32`

2.  **Node Group:**
    Each node in the `nodes` array (size `node_count`) contains:
    - `q_min`: `u30` (Quantized minimum bound, 10 bits per axis packed)
    - `q_max`: `u30` (Quantized maximum bound, 10 bits per axis packed)
    - `nprims`: `u4` (Number of primitives, 0 for interior nodes)
    - Derived fields (computed during traversal):
        - `low = fadd_rd(wlow, dequantize(q_min, bins))` [S1]
        - `high = fsub_ru(whigh, dequantize(q_max, bins))` [S1]
    - Split based on `nprims`:
        - If `nprims == 0` (Interior):
            - `offset`: `u32` (Offset to right child)
            - `left = index + 1`
            - `right = index + offset`
        - If `nprims > 0` (Leaf):
            - `poffset`: `u32` (Offset into primitives array)
            - `data = primitives[poffset : poffset + nprims]` [S1]

**Numbered Steps:**

1.  **Root Initialization:**
    - Compute world-space bounds `wlow` and `whigh` from the root node's AABB [S1].
    - Compute `bins_inv` as the reciprocal of the bin scales derived from the world extent, clamping the extent to a minimum of 1.0 to avoid division by zero [S1].
    - Compute `bins` as the inverse of `bins_inv` [S1].

2.  **Quantization (Low Bound):**
    - For a node with low bound `low`, compute the quantized value `q_min` using directed rounding down (`rd`):
      $$ q_{low} = \lfloor (low - wlow) \times bins\_inv \rfloor $$
    - Pack the 10-bit per axis values into a 30-bit integer:
      $$ v = ((x \& 1023u) \ll 20u) \mid ((y \& 1023u) \ll 10u) \mid (z \& 1023u) $$
      where $x, y, z$ are the quantized components for each axis [S1].

3.  **Quantization (High Bound):**
    - For a node with high bound `high`, compute the quantized value `q_max` using directed rounding up (`ru`), implemented as floor of the reversed difference:
      $$ q_{high} = \lfloor (whigh - high) \times bins\_inv \rfloor $$
    - Pack similarly to `q_min` [S1].

4.  **Clamping:**
    - Clamp quantized values to the range $[0, 1023]$ before packing to ensure they fit within the 10-bit per axis allocation [S1].

5.  **Node Construction:**
    - **Interior Node:**
        - Set `nprims = 0`.
        - Build left child.
        - Build right child.
        - Compute `offset = right_index - current_index`.
        - Store `q_min`, `q_max`, and `offset` [S1].
    - **Leaf Node:**
        - Set `nprims` to the number of primitives.
        - Append primitive data to the `primitives` array.
        - Store `poffset` (index in primitives array).
        - Store `q_min`, `q_max` [S1].

**Formulas:**
- Bin inverse: $\text{bins\_inverse} = \frac{1023.0}{\max(1.0, \text{extent})}$ [S1].
- Bin scale: $\text{bins} = \text{frcp}(\text{bins\_inverse})$ [S1].
- Quantization packs 10-bit per axis values into a 30-bit integer: $v = ((x \& 1023u) \ll 20u) \mid ((y \& 1023u) \ll 10u) \mid (z \& 1023u)$ [S1].
- Dequantization reconstructs coordinates: $c = \text{floor}(\frac{v_{\text{axis}}}{1023.0} \times \text{extent}) + \text{origin}$ [S1].

**Parameters:**
- Node size: 12 bytes [S1].
- Quantization precision: 10-bit fixed-point encoding per axis [S1].
- Quantization grid size: $2^{10}$ bins (1024 bins, values 0-1023) [S1].
- World-space bounds and bin scales are stored at the root [S1].

**Pseudocode:**

```python
import math

def quantize_lo(low: tuple, wlow: tuple, bins_inv: tuple) -> int:
    x = math.floor((low[0] - wlow[0]) * bins_inv[0])
    y = math.floor((low[1] - wlow[1]) * bins_inv[1])
    z = math.floor((low[2] - wlow[2]) * bins_inv[2])
    x = max(0, min(x, 1023))
    y = max(0, min(y, 1023))
    z = max(0, min(z, 1023))
    return ((x & 1023) << 20) | ((y & 1023) << 10) | (z & 1023)

def quantize_hi(high: tuple, whigh: tuple, bins_inv: tuple) -> int:
    x = math.floor((whigh[0] - high[0]) * bins_inv[0])
    y = math.floor((whigh[1] - high[1]) * bins_inv[1])
    z = math.floor((whigh[2] - high[2]) * bins_inv[2])
    x = max(0, min(x, 1023))
    y = max(0, min(y, 1023))
    z = max(0, min(z, 1023))
    return ((x & 1023) << 20) | ((y & 1023) << 10) | (z & 1023)

def dequantize(q: int, bins: tuple) -> tuple:
    x = (q >> 20) & 1023
    y = (q >> 10) & 1023
    z = q & 1023
    return (x * bins[0], y * bins[1], z * bins[2])

def build_root(low: tuple, high: tuple) -> dict:
    wlow = low
    whigh = high
    extent = (whigh[0]-wlow[0], whigh[1]-wlow[1], whigh[2]-wlow[2])
    bins_inv = tuple(1023.0 / max(1.0, e) for e in extent)
    bins = tuple(1.0 / b for b in bins_inv)
    return {'wlow': wlow, 'whigh': whigh, 'bins_inv': bins_inv, 'bins': bins}

def build_interior(low: tuple, high: tuple, wlow: tuple, whigh: tuple, bins_inv: tuple, current_index: int, primitives: list) -> dict:
    q_min = quantize_lo(low, wlow, bins_inv)
    q_max = quantize_hi(high, whigh, bins_inv)
    nprims = 0
    left = build_node(low, high, wlow, whigh, bins_inv, current_index + 1, primitives)
    right = build_node(low, high, wlow, whigh, bins_inv, current_index + 1, primitives) # Placeholder for actual right child bounds
    offset = right['index'] - current_index
    return {'q_min': q_min, 'q_max': q_max, 'nprims': nprims, 'offset': offset, 'index': current_index}

def build_leaf(low: tuple, high: tuple, wlow: tuple, whigh: tuple, bins_inv: tuple, current_index: int, data: list, primitives: list) -> dict:
    q_min = quantize_lo(low, wlow, bins_inv)
    q_max = quantize_hi(high, whigh, bins_inv)
    nprims = len(data)
    poffset = len(primitives)
    primitives.extend(data)
    return {'q_min': q_min, 'q_max': q_max, 'nprims': nprims, 'poffset': poffset, 'index': current_index}

def build_node(low: tuple, high: tuple, wlow: tuple, whigh: tuple, bins_inv: tuple, current_index: int, primitives: list) -> dict:
    # Simplified traversal logic matching the build specification
    if nprims == 0:
        return build_interior(low, high, wlow, whigh, bins_inv, current_index, primitives)
    else:
        return build_leaf(low, high, wlow, whigh, bins_inv, current_index, data, primitives)
```

**Edge Cases and Pitfalls:**
- **Directed Rounding:** Requires hardware support for directed rounding modes (round down for low, round up for high) to ensure watertight dequantization, causing substantial computational overhead on architectures without explicit intrinsics support [S1].
- **Division by Zero:** The extent is clamped to a minimum of 1.0 to avoid division by zero when computing bin scales [S1].
- **Precision:** 10-bit quantization may introduce representational errors in bounding volume extents, potentially leading to false negative intersections if not handled carefully [S1].

## Subtopics

### [pbrt-q16](19485-pbrt-q16.md)
A compact BVH layout using 16-bit fixed-point quantization relative to a global coordinate frame. It eliminates the need for directed rounding intrinsics by using standard arithmetic operations, improving portability at the cost of slightly larger node size (16 bytes vs 12 bytes) and higher memory usage compared to sg-eq. Choose pbrt-q16 when portability and standard arithmetic are prioritized over minimal memory footprint.

## Operating characteristics
- **Memory Complexity:** 12 bytes per node, a 62.5% reduction from PBRTv4's 32 bytes per node [S1].
- **Measured Performance:** On GPU tracing the "lucy" scene, sg-eq uses 25% less memory than pbrt-q16 but exhibits a 3.7% slowdown for coherent primary rays and a 20.8% slowdown for incoherent secondary rays [S1].
- **Scaling:** Performance depends on ray distribution and scene geometry, requiring Pareto-optimal layout selection that considers both factors [S1].
- **Strengths:** Aggressive compression and small memory footprint [S1].
- **Limitations:** Relies on directed rounding modes, which are expensive on architectures without explicit support, reducing portability [S1].

## Background
Snapped Grid Extent Quantization (sg-eq) was introduced as a method to reduce the memory footprint of BVH node layouts through aggressive compression using 10-bit fixed-point encoding relative to a global coordinate frame anchored at the root [S1]. It was developed by Joseph Gyurgyik, Alexander J. Root, and Fredrik Kjolstad in the paper "Decoupling Data Layouts from Bounding Volume Hierarchies" (2026) [S1]. The method is part of a broader effort to optimize BVH data structures for modern hardware, balancing compression ratios with traversal performance [S1].
