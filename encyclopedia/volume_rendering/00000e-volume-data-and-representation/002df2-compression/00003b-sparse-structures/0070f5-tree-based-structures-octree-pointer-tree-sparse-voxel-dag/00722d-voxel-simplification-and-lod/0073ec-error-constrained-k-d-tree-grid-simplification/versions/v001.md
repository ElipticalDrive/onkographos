# Error-constrained k-d tree grid simplification

Also called: In-metric, K-d Tree Error Metrics, On-metric, Out-metric, Simplification error metrics, k-d tree simplification via error metrics

## Overview
Error-constrained k-d tree grid simplification is a method for reducing the complexity of k-d tree representations of isosurfaces by removing partitioning faces while ensuring the geometric deviation remains within user-defined bounds [S1]. Unlike QEF-based minimization which computes an optimal vertex position, this method evaluates error metrics based on the positional distance of points relative to the simplified object's surface, interior, and exterior [S1]. It is distinguished from sibling methods like [Tiny LOD](6968-tiny-lod.md) and [Voxel Simplification for LOD](9737-voxel-simplification-for-lod.md) by its specific use of on-metric, in-metric, and out-metric thresholds to constrain topological modifications during the simplification of the k-d tree grid [S1].

## How it works
The method simplifies a k-d tree grid by iteratively removing the partitioning face that introduces the minimal error, stopping when any error metric exceeds a specified threshold [S1].

### Inputs and Outputs
*   **Input:** A k-d tree grid representing an isosurface, defined by intersection points and normals on grid edges.
*   **Input:** User-defined error thresholds $\theta_{on}, \theta_{in}, \theta_{out}$ for the on-metric, in-metric, and out-metric respectively [S1].
*   **Output:** A simplified k-d tree grid with fewer partitioning faces, satisfying $E_{on} \leq \theta_{on}$, $E_{in} \leq \theta_{in}$, and $E_{out} \leq \theta_{out}$ [S1].

### Data Structures
The method relies on the **dual quadric** $P = (A, b, c)$ to efficiently compute error metrics [S1].
*   $A$: A symmetric $3 \times 3$ matrix representing the sum of outer products of points.
*   $b$: A 3-vector representing the sum of points.
*   $c$: A scalar representing the count of points.

For optimization, $A$ and $b$ may be stored as 10 floats rather than separate matrices [S1].

### Steps
1.  **Initialization:** Identify the set of planes $S$ representing the primitive shape of the isosurface, derived from intersection points and normals of the k-d tree's working grid edges [S1].
2.  **Iteration:**
    a. Identify the minimal partitioning face in the current grid.
    b. Remove this face to create a simplified representation.
    c. Compute the error metrics $E_{on}, E_{in}, E_{out}$ for the simplified representation.
    d. If any metric exceeds its respective threshold ($\theta_{on}, \theta_{in}, \theta_{out}$), terminate the process and revert the removal [S1].
    e. Otherwise, accept the simplification and repeat from step 2a.

### Formulas
The error metrics are defined as follows [S1]:

**On-metric ($E_{on}$):**
Measures the distance between the original and simplified isosurface representations. It is the maximum average squared distance of points $v \in P_s$ (points nearest to plane $s$) from their closest plane $s \in S$ [S1].

$$ E_{on} = \max_{s \in S} \frac{1}{|P_s|} \sum_{v \in P_s} d_S(v)^2 $$

where $d_S(v)$ is the distance of point $v$ from plane $s$ [S1].

**In-metric ($E_{in}$) and Out-metric ($E_{out}$):**
Originally defined by distances to the exit of the inside ($I$) and exterior ($O$) [S1]:

$$ E_{in} = \max_{p_{in} \in P_{in}} d_I(p_{in}) $$
$$ E_{out} = \max_{p_{out} \in P_{out}} d_O(p_{out}) $$

However, since $d_I$ and $d_O$ correlate with the distance to the surface planes $S$ when points are inside or outside, these are rewritten as [S1]:

$$ E_{in} = \max_{p_{in} \in IP_{in}} d_S(p_{in}) $$
$$ E_{out} = \max_{p_{out} \in OP_{out}} d_S(p_{out}) $$

where $IP_{in}$ is the set of interior points and $OP_{out}$ is the set of exterior points [S1].

**Computing $E(n, d)$ via Dual Quadric:**
The summation of squared distances $E(n, d)$ for a plane defined by normal $n$ and scalar $d$ is computed efficiently using the dual quadric coefficients [S1]:

$$ E(n, d) = \frac{1}{k} \sum_{i=1}^k (n^T v_i + d)^2 $$

Substituting the coefficients $A = \sum_{i=1}^k v_i v_i^T$, $b = \sum_{i=1}^k v_i$, and $c = k$:

$$ E(n, d) = \frac{1}{k}(n^T A n - 2dn^T b + d^2 c) $$

**Covariance Matrix:**
To find the optimal plane orientation (normal $n$) passing through the mean of points, the covariance matrix $Z$ is computed [S1]:

$$ Z = \frac{1}{k-1} \left( A - \frac{bb^T}{c} \right) $$

The normal $n$ corresponds to the eigenvector of $Z$ associated with the least eigenvalue [S1]. If the plane passes through the mean, the scalar $d$ is given by $d = -\frac{n^T b}{c}$ [S1].

### Pseudocode

```python
def simplify_kd_tree_grid(grid, theta_on, theta_in, theta_out):
    """
    Simplifies a k-d tree grid by removing partitioning faces 
    until error metrics exceed thresholds.
    
    Args:
        grid: The k-d tree grid structure containing planes S and points.
        theta_on: Threshold for on-metric error.
        theta_in: Threshold for in-metric error.
        theta_out: Threshold for out-metric error.
        
    Returns:
        Simplified k-d tree grid.
    """
    # Identify initial set of planes S from intersection points and normals
    planes_S = extract_planes_from_grid(grid)
    
    while True:
        # Find the minimal partitioning face to remove
        face_to_remove = find_minimal_partitioning_face(grid)
        
        if face_to_remove is None:
            break
            
        # Temporarily remove the face to evaluate error
        grid.remove_face(face_to_remove)
        
        # Compute On-metric
        # E_on = max over s in S of (1/|Ps|) * sum(d_S(v)^2) for v in Ps
        e_on = compute_on_metric(grid, planes_S)
        
        # Compute In-metric
        # E_in = max over p_in in IP_in of d_S(p_in)
        e_in = compute_in_metric(grid, planes_S)
        
        # Compute Out-metric
        # E_out = max over p_out in OP_out of d_S(p_out)
        e_out = compute_out_metric(grid, planes_S)
        
        # Check thresholds
        if e_on > theta_on or e_in > theta_in or e_out > theta_out:
            # Error exceeds threshold, revert removal
            grid.add_face(face_to_remove)
            break
        else:
            # Accept simplification
            pass
            
    return grid

def compute_on_metric(grid, planes_S):
    max_error = 0.0
    for plane_s in planes_S:
        # Identify points Ps nearest to plane s
        points_Ps = get_nearest_points(grid, plane_s)
        if not points_Ps:
            continue
        
        # Compute average squared distance
        sum_sq_dist = 0.0
        count = len(points_Ps)
        
        # Use dual quadric for efficiency if applicable
        # A = sum(v_i v_i^T), b = sum(v_i), c = k
        # E(n, d) = (1/k) * (n^T A n - 2*d*n^T b + d^2 * c)
        
        # For simplicity, assuming direct distance calculation or 
        # pre-computed dual quadric P=(A,b,c) for the plane
        avg_sq_dist = compute_squared_distance_sum(points_Ps, plane_s)
        error = avg_sq_dist / count
        
        if error > max_error:
            max_error = error
            
    return max_error

def compute_in_metric(grid, planes_S):
    max_error = 0.0
    interior_points = get_interior_points(grid)
    for p_in in interior_points:
        # Distance to surface plane S
        dist = distance_to_closest_plane(p_in, planes_S)
        if dist > max_error:
            max_error = dist
    return max_error

def compute_out_metric(grid, planes_S):
    max_error = 0.0
    exterior_points = get_exterior_points(grid)
    for p_out in exterior_points:
        # Distance to surface plane S
        dist = distance_to_closest_plane(p_out, planes_S)
        if dist > max_error:
            max_error = dist
    return max_error

def distance_to_closest_plane(point, planes_S):
    min_dist = infinity
    for plane in planes_S:
        dist = perpendicular_distance(point, plane)
        if dist < min_dist:
            min_dist = dist
    return min_dist
```

### Parameters
*   $\theta_{on}$: User-specified threshold for the on-metric [S1].
*   $\theta_{in}$: User-specified threshold for the in-metric [S1].
*   $\theta_{out}$: User-specified threshold for the out-metric [S1].

### Edge Cases and Pitfalls
*   **Precision:** The computation of the covariance matrix $Z$ involves division by $k-1$. If $k=1$, this is undefined. The sources do not specify a guard for $k<2$ [S1].
*   **Boundary Conditions:** The definition of $P_{in}$ and $P_{out}$ relies on the k-d tree grid representation. Degenerate cases where points lie exactly on the boundary may require specific handling for distance calculations [S1].
*   **Metric Correlation:** The simplification assumes that $d_I$ and $d_O$ correlate with $d_S$. If this correlation breaks down (e.g., in highly complex topologies), the rewritten metrics (9) and (10) may not accurately reflect the true topological error [S1].

### QEF-based Octree Simplification
Uses Dual Contouring QEFs to minimize vertex position error. Differs from k-d tree error metrics by focusing on minimization value rather than point-to-object distance [S1]. [QEF-based Octree Simplification](link)

Simplifies via clustering vertices. Differs by not using explicit error metrics based on point distances to planes [S1]. [Manifold Vertex Clustering](link)

## Operating characteristics
*   **Time Complexity:** Not given in the sources. The iterative removal of faces and recalculation of metrics suggests a complexity dependent on the number of faces and points.
*   **Memory Complexity:** Requires storage of the dual quadric coefficients $(A, b, c)$ for efficient error computation. Optimization stores these as 10 floats [S1].
*   **Strengths:** Provides explicit control over geometric fidelity via three distinct error metrics (on, in, out). Efficient computation using dual quadrics [S1].
*   **Limitations:** Relies on the correlation between exit distances and surface plane distances. Performance on highly complex or noisy data is not specified [S1].
*   **When to use:** When explicit control over the deviation of the simplified isosurface from the original is required, and the data is represented in a k-d tree structure [S1].

## Background
The method was introduced in the context of evaluating manifold dual contouring algorithms based on k-d tree and octree data structures [S1]. It is part of a broader effort to improve isosurface extraction and simplification, contrasting with QEF-based and vertex clustering approaches [S1].
