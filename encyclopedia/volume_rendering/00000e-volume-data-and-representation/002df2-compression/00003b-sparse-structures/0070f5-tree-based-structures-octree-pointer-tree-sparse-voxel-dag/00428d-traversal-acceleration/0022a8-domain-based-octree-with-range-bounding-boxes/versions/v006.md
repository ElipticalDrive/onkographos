# Domain-based Octree with Range Bounding Boxes

Also called: Domain-Based Acceleration (Octree), Domain-based acceleration data-structure (Octree), Octree Acceleration, Range Bounding Box (RBB) Octree

## Overview
This method accelerates fiber surface extraction on tetrahedral meshes by organizing tetrahedra into an octree over the spatial domain, where each node stores a Range Bounding Box (RBB) representing the function's range over its contained cells [S1]. It solves the problem of efficiently identifying which tetrahedra intersect a given edge of the Fiber Surface Control Polygon (FSCP) by replacing exact polygon-polygon intersection tests with a conservative 2D axis-aligned bounding box (AABB) intersection test in the range space [S1]. Unlike the range-based BVH variant, which partitions the range space directly, this method partitions the spatial domain, resulting in larger memory requirements and potentially more returned tetrahedra, but remains effective for interactive visualization [S1, Subtopics].

## How it works
**Inputs:**
- A tetrahedral mesh with a scalar function $f$ defined on it [S1].
- A Fiber Surface Control Polygon (FSCP), defined as a sequence of 2D points (edges $e$) [S1].
- Parameters: $n_T$ (minimum tetrahedra per node threshold) [S1], $\alpha$ (RBB size termination fraction) [S1].

**Outputs:**
- A set of candidate tetrahedra that may intersect the FSCP edges, ready for exact fiber surface extraction [S1].

**Data Structures:**
- **Octree Node:**
  - `children`: Array of 8 child nodes (or null if leaf) [S1].
  - `rbb_min`: 2D vector $(min_u, min_v)$ representing the minimum range values of the function over the node's domain [S1].
  - `rbb_max`: 2D vector $(max_u, max_v)$ representing the maximum range values [S1].
  - `tets`: List of tetrahedra indices (only present if the node is a leaf or below threshold $n_T$) [S1].

**Construction (Off-line):**
1. Compute the octree of the domain $Dom_f$ in a top-to-bottom fashion by recursively dividing the domain into octants [S1].
2. For each node, compute its RBB by taking the component-wise minimum and maximum of the RBBs of its children:
   $$ RBB_{node}.min = \min_{c \in children} (RBB_c.min) $$
   $$ RBB_{node}.max = \max_{c \in children} (RBB_c.max) $$
   [S1]
3. Determine if the node should be a leaf or continue splitting:
   - Let $N_{tets}$ be the number of tetrahedra in the node's domain [S1].
   - If $N_{tets} > n_T$, split the node into 8 children and recurse [S1].
   - If $N_{tets} \le n_T$, compute the base level RBB from the vertices of the tetrahedra contained in this node and store the tetrahedra list [S1].
4. Termination Criterion: During recursion, if a node's RBB size is smaller than a fraction $\alpha$ of the RBB of the entire mesh, terminate recursion regardless of $n_T$ [S1]. This prevents arbitrarily deep sub-trees in regions where the function range concentrates [S1].

**Query (On-line):**
1. For each edge $e$ of the FSCP [S1].
2. Start at the root node [S1].
3. Recursively visit children only if the child's RBB intersects or overlaps the FSCP edge $e$ in the 2D range space [S1].
4. Collect all tetrahedra from visited leaf nodes (or nodes below $n_T$) into a candidate set [S1].
5. Pass the candidate set to the standard fiber surface extraction algorithm, which discards false positives during its ordinary operation, so no additional geometry is created [S1].

**Pseudocode:**

```python
from typing import List, Tuple, Optional

class Node:
    def __init__(self, children: Optional[List['Node']], rbb_min: Tuple[float, float], rbb_max: Tuple[float, float], tets: List[int]):
        self.children = children
        self.rbb_min = rbb_min
        self.rbb_max = rbb_max
        self.tets = tets

def compute_rbb(tetrahedra: List[Tuple[Tuple[float, float, float], Tuple[float, float, float], Tuple[float, float, float], Tuple[float, float, float]]], f) -> Tuple[Tuple[float, float], Tuple[float, float]]:
    min_u, min_v = float('inf'), float('inf')
    max_u, max_v = float('-inf'), float('-inf')
    for tet in tetrahedra:
        for vertex in tet:
            val = f(vertex)
            min_u = min(min_u, val[0])
            min_v = min(min_v, val[1])
            max_u = max(max_u, val[0])
            max_v = max(max_v, val[1])
    return (min_u, min_v), (max_u, max_v)

def split_domain(tetrahedra: List[Tuple[Tuple[float, float, float], Tuple[float, float, float], Tuple[float, float, float], Tuple[float, float, float]]]) -> List[List[Tuple[Tuple[float, float, float], Tuple[float, float, float], Tuple[float, float, float], Tuple[float, float, float]]]]:
    min_x = min(t[0][0] for tet in tetrahedra for t in tet)
    max_x = max(t[0][0] for tet in tetrahedra for t in tet)
    min_y = min(t[0][1] for tet in tetrahedra for t in tet)
    max_y = max(t[0][1] for tet in tetrahedra for t in tet)
    min_z = min(t[0][2] for tet in tetrahedra for t in tet)
    max_z = max(t[0][2] for tet in tetrahedra for t in tet)
    mid_x, mid_y, mid_z = (min_x + max_x) / 2, (min_y + max_y) / 2, (min_z + max_z) / 2
    octants = [[] for _ in range(8)]
    for tet in tetrahedra:
        cx, cy, cz = sum(v[0] for v in tet)/4, sum(v[1] for v in tet)/4, sum(v[2] for v in tet)/4
        idx = 0
        if cx >= mid_x: idx += 1
        if cy >= mid_y: idx += 2
        if cz >= mid_z: idx += 4
        octants[idx].append(tet)
        break
    return octants

def build_octree(domain_cells: List[Tuple[Tuple[float, float, float], Tuple[float, float, float], Tuple[float, float, float], Tuple[float, float, float]]], f, nT: int, alpha: float, global_rbb_size: float) -> Node:
    rbb_min, rbb_max = compute_rbb(domain_cells, f)
    current_rbb_size = max(rbb_max[0] - rbb_min[0], rbb_max[1] - rbb_min[1])
    if current_rbb_size < alpha * global_rbb_size:
        return Node(children=None, rbb_min=rbb_min, rbb_max=rbb_max, tets=domain_cells)
    if len(domain_cells) > nT:
        octants = split_domain(domain_cells)
        children = [build_octree(oct, f, nT, alpha, global_rbb_size) for oct in octants]
        p_min = (min(c.rbb_min[0] for c in children), min(c.rbb_min[1] for c in children))
        p_max = (max(c.rbb_max[0] for c in children), max(c.rbb_max[1] for c in children))
        return Node(children=children, rbb_min=p_min, rbb_max=p_max, tets=[])
    return Node(children=None, rbb_min=rbb_min, rbb_max=rbb_max, tets=domain_cells)

def aabb_segment_intersect(aabb_min: Tuple[float, float], aabb_max: Tuple[float, float], segment: Tuple[Tuple[float, float], Tuple[float, float]]) -> bool:
    p1, p2 = segment
    dx, dy = p2[0] - p1[0], p2[1] - p1[1]
    tmin, tmax = 0.0, 1.0
    for i in range(2):
        coord = dx if i == 0 else dy
        if abs(coord) < 1e-9:
            if p1[i] < aabb_min[i] or p1[i] > aabb_max[i]:
                return False
        else:
            t1 = (aabb_min[i] - p1[i]) / coord
            t2 = (aabb_max[i] - p1[i]) / coord
            if t1 > t2: t1, t2 = t2, t1
            tmin = max(tmin, t1)
            tmax = min(tmax, t2)
            if tmin > tmax:
                return False
    return True

def query_octree(node: Node, edge_segment: Tuple[Tuple[float, float], Tuple[float, float]]) -> List[int]:
    if not aabb_segment_intersect(node.rbb_min, node.rbb_max, edge_segment):
        return []
    if node.children is None:
        return node.tets
    candidates = []
    for child in node.children:
        candidates.extend(query_octree(child, edge_segment))
    return candidates
```

**Parameters:**
- $n_T$: Threshold for minimum number of tetrahedra per node. Default/typical value: 1 if desired, but set to 5 for 5-subdivided regular grids in experiments [S1].
- $\alpha$: Fraction of the entire mesh's RBB used as a termination criterion for octree depth. Typical value: 0.001 offered the best trade-off in experiments [S1].

**Edge Cases and Pitfalls:**
- The octree is not necessarily balanced (except for regular grids), and sub-trees can be arbitrarily deep, leading to many line-bounding-box intersection tests [S1].
- For 5-subdivided regular grids, the minimum number of tets per octree leaf is 5 (one voxel), causing the RBB of a leaf to intersect a FSCP edge even if none of its tets are actually intersected [S1].
- The conservative AABB test may return tetrahedra that do not intersect the fiber surface, but the ordinary operation of the fiber surface extraction will discard them, so no additional geometry is created [S1].

## Subtopics

### [Domain-based BVH with Range Bounding Boxes](2808-domain-based-bvh-with-range-bounding-boxes.md)
This method accelerates fiber surface extraction on tetrahedral meshes by organizing tetrahedra into a Bounding Volume Hierarchy (BVH) over the 2D range space, where each node stores a Range Bounding Box (RBB) and a list of tetrahedra whose RBBs are contained within it. It solves the problem of efficiently identifying which tetrahedra intersect a given edge of the Fiber Surface Control Polygon (FSCP) by reducing the query to a 2D intersection test between the FSCP edge and the node's RBB. Unlike the domain-based octree, which partitions the spatial domain, the BVH partitions the range space directly, resulting in fewer returned tetrahedra, smaller memory requirements, and faster queries for the same dataset.

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Measured Performance:** On the EthaneDiol dataset, the octree with $\alpha=0.001$ used 649.736 MB memory, took 2.362s for pre-processing, queried 35.260% of tetrahedra, and took 0.311s for extraction [S1]. The average speedup over the non-accelerated algorithm is 18x [S1].
- **Strengths:** Provides interactive rates for fiber surface extraction; conservative test is fast; handles complex FSCP shapes better than point-isovalue methods [S1].
- **Limitations:** Unbalanced trees can lead to deep recursion; conservative test returns false positives (handled by downstream exact test); higher memory usage compared to range-based BVH [S1].
- **When to use:** When spatial locality is important or when the domain structure is naturally hierarchical; when memory is not the primary constraint compared to the BVH variant [S1].
- **When not to use:** When the range space is highly non-uniform and the BVH variant offers significantly better pruning; when memory is extremely constrained [S1].

## Background
The method was introduced in the context of fast and exact fiber surface extraction for tetrahedral meshes [S1]. It extends the concept of using octrees for isovalue interval testing (where a scalar function's range is stored at each node) to the more complex case of fiber surfaces, which are defined by polygons in the range space rather than single points [S1]. The approach leverages the rich literature on collision detection, specifically replacing expensive polygon-polygon intersection tests with conservative AABB tests in the range space [S1].
