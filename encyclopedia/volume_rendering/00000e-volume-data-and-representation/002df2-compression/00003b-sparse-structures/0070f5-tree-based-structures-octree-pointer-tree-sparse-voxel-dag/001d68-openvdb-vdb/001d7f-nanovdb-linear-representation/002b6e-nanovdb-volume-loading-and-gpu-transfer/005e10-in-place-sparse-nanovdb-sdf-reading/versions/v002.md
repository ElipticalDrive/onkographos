# In-place Sparse NanoVDB SDF Reading

Also called: Sparse NanoVDB SDF, readSparseSignedDistanceFieldNVDB

## Overview
This method reads sparse NanoVDB signed distance fields (SDFs) in their native sparse tree structure without densifying them into a full voxel grid, allowing memory usage to scale with surface geometry rather than the bounding box volume [S1, unofficial]. It differs from dense readers by maintaining the grid's sparse form and querying active voxels directly, while providing configurable interpolation strategies to ensure gradient continuity for physics simulations [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A byte buffer containing a NanoVDB file, a `band_clamp` value (float), and a `scale` factor (float) [S1, unofficial].
*   **Output:** A `SignedDistanceField` object capable of returning distance and gradient values for arbitrary 3D points within the grid's domain [S1, unofficial].

**Data Structures**
*   **SignedDistanceFieldLayer:** A structure containing a `NanoVDB::FloatGrid` and its associated `band_clamp` value. The layered constructor currently accepts exactly one layer [S1, unofficial].
*   **Cereal Archive Format:** Version 1. Stores interpolation settings. A sparse field is stored as its grid/layer. Unversioned archives are rejected [S1, unofficial].

**Validation and Loading**
1.  **Version Check:** Ensure the grid is NanoVDB major version 32. Reject other versions [S1, unofficial].
2.  **Type Check:** Ensure the grid is not a fog (density) volume. Reject if it is [S1, unofficial].
3.  **Buffer Integrity:** Ensure every node array is contained within the provided buffer. Reject if data is missing [S1, unofficial].
4.  **Decompression:** Decompress the buffer if necessary. The grid and tree headers must be parsed from the *decompressed* data, not the compressed bytes. The grid buffer is authoritative [S1, unofficial].
5.  **Storage:** Store the grid once as its uncompressed grid buffer. Do not densify the data into a full voxel grid [S1, unofficial].

**Domain Computation**
1.  Compute the domain as the grid's exact active bounds [S1, unofficial].
2.  Derive these bounds from the leaf masks and record them in the stored grid's root box [S1, unofficial].

**Query Logic**
1.  **Active Voxel Check:** A read is answered only where every voxel required for the interpolation kernel is active. An inactive voxel holds the grid's background value, which is not a valid distance [S1, unofficial].
2.  **No Data Handling:** Where the grid has no data (outside the active bounds or in inactive regions), return the `band_clamp` value. If `band_clamp` is 0, return infinity. The sign of the returned value is determined by the value the grid stores in that region: for level sets, interior tiles store `-background`, so points deep inside an object still read as inside (negative distance) [S1, unofficial].

**Interpolation Configuration**
1.  **Distance Interpolation:** Use `setInterpolation()` to choose between:
    *   **Trilinear:** Default. Results are unchanged from standard implementations [S1, unofficial].
    *   **Tricubic Catmull-Rom:** Passes through samples and provides a continuous gradient, preventing contact direction jumps at cell faces [S1, unofficial].
2.  **Gradient Interpolation:** Use `setGradientInterpolation()` to read the direction with a method independent of the distance interpolation. For example, use trilinear distance (which never overshoots samples) with tricubic direction (which is continuous and suits gradient-based optimizers) [S1, unofficial].
3.  **Joint Query:** Use `getDistanceAndGradient()` to return both distance and gradient from a single lookup operation [S1, unofficial].

**I/O Interface**
1.  Use `readSparseSignedDistanceFieldNVDB(bytes, band_clamps, scale)` to read a NanoVDB file as a sparse field [S1, unofficial].
2.  The `band_clamp` is passed as a parameter to the reader, not stored in the file. This allows the clamp to be adjusted per-use or per-scene without modifying the source asset [S1, unofficial].

**Pitfalls and Edge Cases**
*   **Blosc Compression:** If Blosc is not compiled into the build, BLOSC-compressed files must be rejected. Older readers failed to compile Blosc and incorrectly reported success for undecoded data [S1, unofficial].
*   **Header Parsing Order:** Parsing headers from compressed bytes leads to corruption. Always parse after decompression [S1, unofficial].
*   **Name Terminator Misalignment:** Do not skip name terminators manually. The upstream `libnanovdb` already counts the terminator in the name size. Skipping it misaligns every subsequent field. Use the upstream reader without local patches [S1, unofficial].
*   **Legacy Files:** NanoVDB files written with legacy NanoVDB0 magic or non-standard name layouts (e.g., by older Tesseract versions) are rejected [S1, unofficial].

**Pseudocode**

```python
def read_sparse_signed_distance_field_nvdb(bytes: bytes, band_clamp: float, scale: float) -> object:
    # 1. Validation
    # [G] Check NanoVDB major version 32 in header
    if not check_nanovdb_version_32(bytes):
        raise ValueError("Only NanoVDB major version 32 is supported")
    # [G] Check grid type is not fog/density
    if is_fog_volume(bytes):
        raise ValueError("Fog/density volumes are not supported")
    # [G] Verify every node array offset is within buffer bounds
    if not all_node_arrays_in_buffer(bytes):
        raise ValueError("Node arrays are not fully contained in the buffer")

    # 2. Decompression and Header Parsing
    # [G] Decompress if Blosc is available; reject if Blosc is missing and file is compressed
    decompressed = decompress_if_needed(bytes)
    # [S1, unofficial] Parse headers from decompressed data, not compressed bytes
    grid_header = parse_grid_header(decompressed)
    tree_header = parse_tree_header(decompressed)

    # 3. Construct Sparse Field
    # [S1, unofficial] SignedDistanceFieldLayer contains the FloatGrid and band_clamp
    layer = SignedDistanceFieldLayer(grid=FloatGrid(decompressed), band_clamp=band_clamp)
    sdf = SignedDistanceField(layers=[layer], scale=scale)

    # 4. Configure Interpolation
    # [S1, unofficial] Default to trilinear for distance
    sdf.set_interpolation(InterpolationMode.TRILINEAR)
    # [S1, unofficial] Default to trilinear for gradient
    sdf.set_gradient_interpolation(InterpolationMode.TRILINEAR)

    # 5. Domain Computation
    # [S1, unofficial] Compute domain from leaf masks and root box
    domain = compute_active_bounds_from_leaf_masks(layer.grid)
    sdf.set_domain(domain)

    return sdf

def query_distance_and_gradient(sdf: object, point: tuple) -> tuple:
    # [S1, unofficial] Check domain
    if not sdf.is_in_domain(point):
        background = sdf.get_background_value()
        sign = -1 if background < 0 else 1
        dist = -sdf.band_clamp if sdf.band_clamp > 0 else float('inf')
        return (sign * dist, (0.0, 0.0, 0.0))

    # [S1, unofficial] Active Voxel Check
    if not sdf.are_all_voxels_active(point, sdf.get_interpolation_mode()):
        background = sdf.get_background_value()
        sign = -1 if background < 0 else 1
        dist = -sdf.band_clamp if sdf.band_clamp > 0 else float('inf')
        return (sign * dist, (0.0, 0.0, 0.0))

    # [S1, unofficial] Joint Query
    return sdf.get_distance_and_gradient(point)

# Helper definitions for self-contained pseudocode
def check_nanovdb_version_32(bytes: bytes) -> bool:
    # [G] Standard header check for NanoVDB major version 32
    return bytes[0:4] == b'NVDB' and bytes[4] == 32

def is_fog_volume(bytes: bytes) -> bool:
    # [G] Check grid type flag in header
    return get_grid_type(bytes) != SDF_TYPE

def all_node_arrays_in_buffer(bytes: bytes) -> bool:
    # [G] Verify every node array offset is within buffer bounds
    return all(offset < len(bytes) for offset in get_node_array_offsets(bytes))

def decompress_if_needed(bytes: bytes) -> bytes:
    # [G] Decompress if Blosc is available; reject if Blosc is missing and file is compressed
    if is_blosc_compressed(bytes):
        if not blosc_available():
            raise ValueError("Blosc compression is required but not compiled in")
        return blosc_decompress(bytes)
    return bytes

def parse_grid_header(decompressed: bytes) -> dict:
    # [G] Read grid magic/version from decompressed data
    return {"magic": decompressed[0:4], "version": decompressed[4]}

def parse_tree_header(decompressed: bytes) -> dict:
    # [G] Read tree structure from decompressed data
    return {"root_offset": read_uint32(decompressed, 8)}

class SignedDistanceFieldLayer:
    def __init__(self, grid: object, band_clamp: float):
        self.grid = grid
        self.band_clamp = band_clamp

class SignedDistanceField:
    def __init__(self, layers: list, scale: float):
        self.layers = layers
        self.scale = scale
        self.interpolation = InterpolationMode.TRILINEAR
        self.gradient_interpolation = InterpolationMode.TRILINEAR
        self.domain = None

    def set_interpolation(self, mode: InterpolationMode):
        self.interpolation = mode

    def set_gradient_interpolation(self, mode: InterpolationMode):
        self.gradient_interpolation = mode

    def set_domain(self, domain: tuple):
        self.domain = domain

    def is_in_domain(self, point: tuple) -> bool:
        # [G] Standard bounds check
        return all(min_val <= coord <= max_val for coord, (min_val, max_val) in zip(point, self.domain))

    def get_background_value(self) -> float:
        # [G] Standard accessor for grid background
        return self.layers[0].grid.get_background()

    def are_all_voxels_active(self, point: tuple, mode: InterpolationMode) -> bool:
        # [G] Check if all voxels required for the interpolation kernel are active
        return all(is_voxel_active(self.layers[0].grid, voxel_coord) for voxel_coord in get_interpolation_voxels(point, mode))

    def get_distance_and_gradient(self, point: tuple) -> tuple:
        # [S1, unofficial] Joint query returning distance and gradient
        distance = interpolate_distance(self.layers[0].grid, point, self.interpolation)
        gradient = interpolate_gradient(self.layers[0].grid, point, self.gradient_interpolation)
        return (distance, gradient)

class InterpolationMode:
    TRILINEAR = 0
    TRICUBIC = 1

def get_grid_type(bytes: bytes) -> int:
    # [G] Standard header accessor
    return bytes[12]

def SDF_TYPE() -> int:
    # [G] Standard constant
    return 1

def get_node_array_offsets(bytes: bytes) -> list:
    # [G] Standard header accessor
    return [read_uint32(bytes, i) for i in range(16, 64, 4)]

def is_blosc_compressed(bytes: bytes) -> bool:
    # [G] Standard magic check
    return bytes[0:4] == b'BLOSC'

def blosc_available() -> bool:
    # [G] Standard build check
    return True

def blosc_decompress(bytes: bytes) -> bytes:
    # [G] Standard decompression
    return bytes[8:]

def read_uint32(bytes: bytes, offset: int) -> int:
    # [G] Standard byte unpacking
    return int.from_bytes(bytes[offset:offset+4], 'little')

def is_voxel_active(grid: object, coord: tuple) -> bool:
    # [G] Standard leaf mask check
    return True

def get_interpolation_voxels(point: tuple, mode: InterpolationMode) -> list:
    # [G] Standard kernel neighbor calculation
    return [point]

def interpolate_distance(grid: object, point: tuple, mode: InterpolationMode) -> float:
    # [G] Standard interpolation
    return 0.0

def interpolate_gradient(grid: object, point: tuple, mode: InterpolationMode) -> tuple:
    # [G] Standard interpolation
    return (0.0, 0.0, 0.0)
```

## Operating characteristics
*   **Time Complexity:** Loading is faster than dense reading. For a 474x470x144 sample field, sparse loading takes 0.11s compared to 0.40s for dense loading [S1, unofficial].
*   **Memory Complexity:** Memory usage follows the surface geometry. For the same 474x470x144 field, sparse reading uses 149 MB compared to 257 MB for dense reading [S1, unofficial].
*   **Accuracy:** Dense and sparse readings agree to $5 \times 10^{-14}$ mm over 200,000 points near the surface [S1, unofficial].
*   **Gradient Continuity:** Trilinear interpolation causes contact directions to jump 9.6 times per 10 mm walk (2 mm off the surface) at cell faces. Tricubic interpolation and trilinear distance with tricubic direction do not jump at all [S1, unofficial].
*   **Strengths:** Significant memory savings for sparse data; faster loading; continuous gradients with tricubic interpolation; flexible distance/gradient interpolation split [S1, unofficial].
*   **Limitations:** Requires NanoVDB major version 32; rejects fog volumes; requires Blosc for compressed files; legacy NanoVDB0 files are rejected; band clamp must be provided externally [S1, unofficial].
*   **When to use:** When memory is constrained, when the SDF is sparse (narrow band), or when gradient continuity is critical for physics simulations (e.g., collision detection) [S1, unofficial].
*   **When not to use:** When dense access patterns are required, when the grid is not a signed distance field, or when using legacy NanoVDB files [S1, unofficial].

## Background
This method was introduced in the Tesseract project to replace the dense `readSignedDistanceFieldNVDB` reader, which expanded sparse files into full boxes of doubles and refused boxes over 256 M voxels [S1, unofficial]. It leverages `libnanovdb` and `tinyvdb` for low-level parsing, correcting previous bugs in local patches such as Blosc handling, header parsing order, and name terminator misalignment [S1, unofficial]. It is used in Bullet and FCL collision detection backends to query SDFs in place [S1, unofficial].
