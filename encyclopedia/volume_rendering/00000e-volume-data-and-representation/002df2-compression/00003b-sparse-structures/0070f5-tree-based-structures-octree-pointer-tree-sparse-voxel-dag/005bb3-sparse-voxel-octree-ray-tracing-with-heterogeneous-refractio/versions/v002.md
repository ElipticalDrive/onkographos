# Sparse Voxel Octree Ray Tracing with Heterogeneous Refraction

Also called: Real-time GPU Ray Tracing with Volumetric Effects

## Overview
A real-time GPU ray tracing method that represents volumes as a sparse voxel octree and bends light through see-through objects with spatially varying indices of refraction [S1, unofficial]. It differs from standard SVO ray tracing by storing per-voxel optical properties (IOR, reflectivity) to enable heterogeneous refraction, where light rays are re-bent at every voxel boundary with a different index of refraction, rather than treating the volume as a homogeneous medium or refracting only at the surface [S1, unofficial].

## How it works
**Inputs:** A scene represented as a Sparse Voxel Octree (SVO) generated from meshes (e.g., via `TreeGen`), camera parameters, and light definitions [S1, unofficial]. The SVO is built with a typical depth of ~8 for quick generation, supporting up to 2048³ resolution [S1, unofficial].

**Outputs:** A rendered image written directly to an OpenGL texture [S1, unofficial].

**Data Structures:**
*   **Sparse Voxel Octree:** Recursive subdivision where empty space is never stored [S1, unofficial]. Nodes are traversed using the Laine & Karras algorithm [S1, unofficial].
*   **Voxel Attachment:** Stored at leaf nodes (or hit points) [S1, unofficial]. It packs four fields into **12 bytes**: Colour (3 bytes), Normal (3 bytes), Reflectivity (1 byte), and Index of Refraction (IOR) (5 bytes) [S1, unofficial].

**Algorithm Steps:**
1. Convert the scene to a sparse voxel octree, ensuring empty space is never stored [S1, unofficial].
2. Assign one CUDA thread per pixel [S1, unofficial].
3. Cast the primary ray through the octree using the Laine & Karras traversal algorithm [S1, unofficial].
4. On a hit, look up the voxel attachment containing colour, normal, reflectivity, and IOR [S1, unofficial].
5. Calculate lighting using ambient, diffuse, and specular components based on the hit normal and material properties [S1, unofficial].
6. Cast a shadow ray to each light source, applying attenuation and a spotlight cone check [S1, unofficial].
7. If the voxel is see-through, bend the ray using Snell's law and step through the volume, re-bending at each voxel boundary with the new IOR [S1, unofficial].
8. Write the final result directly to an OpenGL texture [S1, unofficial].

**Formulas & Parameters:**
*   Point light attenuation: $\text{attenuation} = \frac{1.0}{\text{light.constant\_att} + \text{light.linear\_att} \cdot \text{light\_distance} + \text{light.quadratic\_att} \cdot \text{light\_distance}^2}$ [S1, unofficial].
*   Spotlight cone check: $\text{clampedCosine} = \max(0.0, \text{dot}(\text{light\_dir}, \text{normalize}(\text{light.direction})))$ [S1, unofficial]. If $\text{clampedCosine} < \cos(\text{light.cutoff})$, $\text{attenuation} = 0.0$; otherwise, $\text{attenuation} = \text{attenuation} \cdot \text{clampedCosine}^{\text{light.exponent}}$ [S1, unofficial].
*   Shadow ray origin outset: $\text{origin} = \text{hit\_pos} + \text{direction} \cdot \sqrt{10} \cdot 2^{-\text{hit\_scale}}$ [S1, unofficial].
*   Reflection vector: $\text{refl} = \text{norm} \cdot (2.0 \cdot \text{dot}(\text{dir}, \text{norm})) - \text{dir}$ [S1, unofficial].
*   Parameters: $\text{MAX\_REFLECTION\_ITERATIONS} = 0$ (limits recursive reflection bounces to zero) [S1, unofficial]. Octree depth is typically ~8 [S1, unofficial].

**Pseudocode:**

    hit = traverse_svo(octree, ray_origin, ray_direction)
    if hit is None:
        return [0.0, 0.0, 0.0]

    colour, normal, reflectivity, ior = hit.voxel_attachment
    color = [0.0, 0.0, 0.0]

    for light in lights:
        light_dir = normalize(light.position - hit.position)
        light_distance = length(light.position - hit.position)

        outset = math.sqrt(10.0) * (2.0 ** (-hit.scale))
        shadow_origin = [hit.position[i] + light_dir[i] * outset for i in range(3)]
        shadow_ray = Ray(shadow_origin, light_dir)

        if is_occluded(octree, shadow_ray):
            continue

        att = 1.0 / (light.constant_att + light.linear_att * light_distance + light.quadratic_att * light_distance * light_distance)

        clamped_cosine = max(0.0, dot(light.direction, light_dir))
        if clamped_cosine < math.cos(light.cutoff):
            att = 0.0
        else:
            att *= clamped_cosine ** light.exponent

        diffuse = max(0.0, dot(normal, light_dir))
        view_dir = normalize(camera.position - hit.position)
        half_dir = normalize([light_dir[i] + view_dir[i] for i in range(3)])
        specular = pow(max(0.0, dot(normal, half_dir)), light.shininess)

        color = [color[i] + att * light.color[i] * (diffuse + specular) for i in range(3)]

    if ior != 1.0:
        refracted_dir = refract(ray_direction, normal, 1.0 / ior)
        vol_color = trace_heterogeneous_volume(hit.position, refracted_dir, octree, ior)
        color = [color[i] + vol_color[i] for i in range(3)]

    return color

## Operating characteristics
*   **Performance:** On an NVIDIA GTX 670 at 1024³ resolution: 768x768 yields 85 fps (no effects), 65 fps (shadows), 59 fps (reflection), 32 fps (translucency) [S1, unofficial]. 1024x1024 yields 54 fps (no effects), 42 fps (shadows), 38 fps (reflection), 20 fps (translucency) [S1, unofficial]. 1920x1080 yields 26 fps (no effects), 19 fps (shadows), 17 fps (reflection), 8 fps (translucency) [S1, unofficial].
*   **Scaling:** Frame rate halves every time pixel count doubles past 1024x1024 [S1, unofficial]. Translucency performance drops to single digits at 1080p [S1, unofficial]. Octree resolution scaling is efficient: each step up in resolution (8x voxels) costs only ~15% frame rate [S1, unofficial].
*   **Memory Usage:** 34 MB at 512³, 137 MB at 1024³, 544 MB at 2048³ [S1, unofficial].
*   **Limitations:** One thread per pixel causes warp divergence, making translucency expensive [S1, unofficial]. Voxel cubes cause self-shadowing artifacts on smooth surfaces, requiring normal-aware ray casting which increases cost [S1, unofficial].

## Background
This method was developed as a BSc dissertation in Computer Games Programming at the University of Derby (2013-2014) by Catchouli [S1, unofficial]. It addresses the limitation of rasterization, which only handles surfaces, by enabling real-time GPU ray tracing for volumetric effects like clouds, smoke, and glass with internal structures [S1, unofficial]. It builds on the efficient sparse voxel octree traversal algorithm by Laine and Karras (2010) [S1, unofficial].
