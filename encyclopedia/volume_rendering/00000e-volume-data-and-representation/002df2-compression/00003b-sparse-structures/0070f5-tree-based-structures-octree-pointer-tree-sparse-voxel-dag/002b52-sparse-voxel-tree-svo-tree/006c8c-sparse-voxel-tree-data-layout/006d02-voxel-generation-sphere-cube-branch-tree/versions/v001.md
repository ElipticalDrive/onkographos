# Voxel Generation: Sphere, Cube, Branch, Tree

Also called: Voxelization primitives, SVO voxel generation, sp4cerat voxelizer

## Overview
This method defines a set of procedural voxelization routines used to populate a sparse voxel octree (SVO) data structure with occupancy and color data. It provides specific algorithms for generating spherical, cubical, and hierarchical branching/tree structures directly into a voxel grid. It is distinct from general-purpose marching cubes or ray-marching voxelizers by operating as a direct bit-setting rasterizer on a pre-allocated grid, optimized for the specific memory layout of the SVO tree described in [Sparse Voxel Tree Data Layout](21134-sparse-voxel-tree-data-layout.md).

## How it works

### Inputs and Outputs
*   **Input**: A voxel grid represented by arrays `voxel` (occupancy), `voxel_col1`, and `voxel_col2` (color). The grid dimensions are defined by `vx8` (width in 8-voxel blocks) and `vx8vy` (height in 8-voxel blocks).
*   **Input**: Geometric parameters (position, radius, bounds, recursion depth).
*   **Output**: Modified `voxel`, `voxel_col1`, and `voxel_col2` arrays reflecting the generated shape.

### Data Structures
The voxel grid is stored in a linear array. The offset for a voxel at integer coordinates $(x, y, z)$ is calculated as:
$$ \text{ofs} = \lfloor x/8 \rfloor + y \cdot \text{vx8} + z \cdot \text{vx8vy} $$
The occupancy bit within the byte at `ofs` is determined by:
$$ \text{bit} = x \pmod 8 $$
Color bits are packed into `voxel_col1` and `voxel_col2` using the same `bit` index.

### Algorithms

#### 1. Sphere Generation
Generates a solid sphere of radius $r$ centered at `pos`.

**Steps:**
1.  Iterate $x$ from $\lfloor \text{pos}.x - r \rfloor$ to $\lceil \text{pos}.x + r \rceil$.
2.  Iterate $y$ from $\lfloor \text{pos}.y - r \rfloor$ to $\lceil \text{pos}.y + r \rceil$.
3.  Iterate $z$ from $\lfloor \text{pos}.z - r \rfloor$ to $\lceil \text{pos}.z + r \rceil$.
4.  Compute squared distance: $a = (\text{pos}.x - x)^2 + (\text{pos}.y - y)^2 + (\text{pos}.z - z)^2$.
5.  If $a \le r^2$:
    *   Calculate `ofs` and `bit` as defined above.
    *   Set occupancy: `voxel[ofs] |= bit`.
    *   **Mode 0 (Color)**: If the mode is 0, update color arrays. Let `color` be the input color value.
        *   `voxel_col1[ofs] |= (color & 1) << bit`
        *   `voxel_col2[ofs] |= (color >> 1) << bit`
    *   **Mode 1 (Clear)**: If the mode is 1, clear the occupancy bit: `voxel[ofs] &= ~bit`.

#### 2. Cube Generation
Generates a solid axis-aligned cube defined by two corner points `pos1` and `pos2`.

**Steps:**
1.  Iterate $x$ from $\min(\text{pos1}.x, \text{pos2}.x)$ to $\max(\text{pos1}.x, \text{pos2}.x)$.
2.  Iterate $y$ from $\min(\text{pos1}.y, \text{pos2}.y)$ to $\max(\text{pos1}.y, \text{pos2}.y)$.
3.  Iterate $z$ from $\min(\text{pos1}.z, \text{pos2}.z)$ to $\max(\text{pos1}.z, \text{pos2}.z)$.
4.  Clamp $x, y, z$ to the valid grid dimensions $[0, \text{width}-1] \times [0, \text{height}-1] \times [0, \text{depth}-1]$.
5.  Calculate `ofs` and `bit`.
6.  Set occupancy: `voxel[ofs] |= bit`.

#### 3. Branch Generation
Generates a recursive branching structure between two points `a` and `b`.

**Parameters**: `a` (start point), `b` (end point), `thicknessA` (thickness at a), `thicknessM` (thickness at midpoint), `iA` (iteration index at a), `iM` (iteration index at midpoint), `iB` (iteration index at b).

**Steps:**
1.  Compute midpoint: $\text{middle} = \frac{a+b}{2} + \text{rnd} \cdot \text{length} \cdot 0.1$.
    *   Note: `length` is the distance $|b-a|$. `rnd` is a random vector.
2.  Call `sphere(middle, thicknessM)`.
3.  Compute offset vector `add` using sine/cosine of `iM` and `thicknessM`.
    *   $ \text{add} = (\cos(\text{iM}), \sin(\text{iM}), 0) \cdot \text{thicknessM} $ (Assumed 2D rotation in XY plane based on typical implementation patterns, exact formula not fully specified in source but implied by `sin/cos of iM`).
4.  Call `sphere(middle + add, thicknessM / 3)` with color 3.
5.  Recursively call `branch(a, middle, thicknessA, thicknessM, iA, iM)`.
6.  Recursively call `branch(middle, b, thicknessM, thicknessB, iM, iB)`.

#### 4. Tree Generation
Generates a fractal tree structure starting from `root1` to `root2`.

**Parameters**: `root1` (current base), `root2` (target end), `thickness` (current thickness), `iteration` (current depth).

**Steps:**
1.  **Base Case**: If `iteration > 5` or `thickness < 2`:
    *   Call `sphere(root1, thickness)` with color 2.
    *   Return.
2.  Increment `iteration`.
3.  Call `branch(root1, root2, thickness, thickness * 0.4f)`.
4.  Compute delta: $\delta = \text{root2} - \text{root1}$.
5.  Compute length: $L = |\delta| \cdot 0.5$.
6.  Loop 4 times:
    *   Generate random direction `rnd`.
    *   Adjust vertical component: $\text{rnd}.y += 0.6 \cdot \text{iteration} - 0.5$.
    *   Normalize `rnd` to length $L$.
    *   Compute branch vector: $\text{branch} = \delta \cdot 0.6 + \text{rnd}$.
    *   Recursively call `tree(root2, root2 + branch, thickness * 0.4f)`.
7.  Decrement `iteration`.

def sphere(pos, radius, color=0, mode=0):
    """
    Generates a sphere in the voxel grid.
    pos: (x, y, z) center
    radius: float
    color: int (bit-packed color)
    mode: 0 for set color, 1 for clear occupancy
    """
    x_min = int(pos[0] - radius)
    x_max = int(pos[0] + radius)
    y_min = int(pos[1] - radius)
    y_max = int(pos[1] + radius)
    z_min = int(pos[2] - radius)
    z_max = int(pos[2] + radius)

    r_sq = radius * radius

    for x in range(x_min, x_max + 1):
        for y in range(y_min, y_max + 1):
            for z in range(z_min, z_max + 1):
                dx = pos[0] - x
                dy = pos[1] - y
                dz = pos[2] - z
                dist_sq = dx*dx + dy*dy + dz*dz

                if dist_sq <= r_sq:
                    ofs = (x // 8) + y * vx8 + z * vx8vy
                    bit = 1 << (x % 8)

                    if mode == 1:
                        # Clear occupancy
                        voxel[ofs] &= ~bit
                    else:
                        # Set occupancy
                        voxel[ofs] |= bit
                        # Set color bits
                        voxel_col1[ofs] |= (color & 1) << (x % 8)
                        voxel_col2[ofs] |= (color >> 1) << (x % 8)

def cube(pos1, pos2):

### Edge Cases and Pitfalls
*   **Precision**: Squared distance calculations should use floating point to avoid integer truncation errors in radius checks.
*   **Boundaries**: Cube generation must clamp coordinates to grid dimensions to prevent out-of-bounds memory access.
*   **Recursion Depth**: Tree generation has a hard limit of `iteration > 5`. Exceeding this without the base case check will cause stack overflow.
*   **Randomness**: Branch and Tree generation rely on `rnd`. For deterministic results, a seeded random number generator must be used.
*   **Color Packing**: The color bits are packed into `voxel_col1` and `voxel_col2` using the x-coordinate's bit index. This means color data is interleaved with occupancy data in a non-standard way, requiring careful unpacking during rendering.

## Operating characteristics

### Time and Memory Complexity
*   **Sphere**: $O(r^3)$ where $r$ is the radius. Each voxel is checked once.
*   **Cube**: $O(w \cdot h \cdot d)$ where $w, h, d$ are the dimensions of the bounding box.
*   **Branch/Tree**: Exponential in recursion depth. For Tree, roughly $O(4^d)$ where $d$ is depth (max 5).

### Measured Performance
*   **Hardware**: CPU-based voxelization.
*   **Resolution**: Depends on grid size `vx8`, `vx8vy`.
*   **Scene**: Simple geometric primitives.

### Strengths and Limitations
*   **Strengths**: Simple implementation, direct memory access, no complex geometry processing.
*   **Limitations**: Low resolution for large objects (voxel aliasing), no smooth surfaces, limited to simple shapes.

### When to Use
*   When generating test data for SVO raycasting.
*   When simplicity of implementation is prioritized over visual fidelity.

### When Not to Use
*   For high-quality rendering requiring smooth surfaces.
*   For large-scale scenes with complex geometry.
