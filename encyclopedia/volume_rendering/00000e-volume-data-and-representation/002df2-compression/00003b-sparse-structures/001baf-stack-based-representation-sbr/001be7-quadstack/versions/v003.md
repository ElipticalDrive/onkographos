# QuadStack

Also called: QuadStack Construction

## Overview
QuadStack is a data structure and algorithm for the compression and direct rendering of layered volumetric datasets [S1, unofficial]. It exploits directional anisotropy and spatial coherence in the vertical sequence of layer attributes to decouple attribute data (color, density) from geometric data (layer heights) [S1, unofficial]. Unlike Stack-Based Representation (SBR), which stores stacks in a flat list, QuadStack organizes similar stacks into a quadtree to identify and compress regions with constant layer topology, achieving significantly higher compression rates while maintaining real-time rendering performance [S1, 1081-stack-based-representation-sbr.md, unofficial].

## How it works
**Inputs:** A 3D voxel grid $V$ of resolution $w \times h \times d$, where layers are parallel to the $xy$-plane [S1, unofficial]. Each voxel has an associated attribute value (e.g., material type, density) [S1, unofficial].
**Outputs:** A QuadStack data structure consisting of a quadtree of gstacks, where each gstack contains an ordered sequence of attribute intervals and corresponding heightfields [S1, unofficial].

### Data Structures
**Stack:** A vertical column of voxels at position $(x, y)$ [S1, unofficial]. Represented as a run-length encoded vertical column [S1, unofficial].
**Gstack (Group of Stacks):** A collection of similar stacks grouped together [S1, unofficial]. Contains an ordered sequence of attribute intervals and corresponding heightfields [S1, unofficial]. The attribute sequence is decoupled from the heightfields [S1, unofficial].
**QuadStack Node:** Internal nodes represent layered structures or common attributes across a region [S1, unofficial]. Leaf nodes contain a gstack [S1, unofficial]. A wildcard `*` is used to group non-matching attributes during merging [S1, unofficial].

### Algorithm Steps
The construction proceeds in two phases: Top-Down Subdivision and Bottom-Up Merging [S1, unofficial].

1. **Top-Down Subdivision:** Recursively subdivide the $xy$-plane into quadrants [S1, unofficial]. A node becomes a leaf if all stacks within its domain share the **same attribute sequence** [S1, unofficial]. Leaf nodes are encoded as gstacks [S1, unofficial].
2. **Bottom-Up Merging:** Process nodes from leaves to root [S1, unofficial]. Extract and merge duplicate intervals into ancestor nodes [S1, unofficial].
3. **Attribute Mapping:** For an internal node with four children, map the attribute values of the children's gstacks to a common sequence [S1, unofficial]. Use `*` to group non-matching attributes [S1, unofficial].
4. **Maximization:** Find the mapping that yields the highest number of **terminal intervals** (intervals where all four children agree on the attribute) [S1, unofficial]. The problem is related to finding common motifs with gaps [S1, unofficial]. A brute-force algorithm evaluates permutations to maximize terminal intervals [S1, unofficial].
5. **Merge:** If the derived parent gstack contains at least one terminal interval, merge it into a single gstack at the parent node [S1, unofficial].
6. **Heightfield Generation:** Pack the four heightfields from the children's intervals into the parent's heightfield [S1, unofficial].
7. **Cleanup:** Delete the derived gstacks from the children [S1, unofficial]. Convert every propagated interval in the children's gstacks to a `*` (wildcard) interval, grouping adjacent wildcards if necessary [S1, unofficial].
8. **Pruning:** If a child gstack ends up as a single `*` interval, it provides no information and is safely deleted from the node [S1, unofficial].

### Pseudocode
```python
import itertools

class Stack:
    def __init__(self, attr_sequence):
        self.attr_sequence = attr_sequence  # List of attr_ids from bottom to top

class Gstack:
    def __init__(self, attr_sequence, heightfields):
        self.attr_sequence = attr_sequence  # List of attr_ids or '*'
        self.heightfields = heightfields    # List of 2D arrays matching attr_sequence

class QuadStackNode:
    def __init__(self, is_leaf=False, gstack=None, children=None):
        self.is_leaf = is_leaf
        self.gstack = gstack
        self.children = children if children else []

def build_quadstack(voxel_grid, width, height, depth):
    root = QuadStackNode()
    build_subdivision(root, voxel_grid, 0, width, 0, height, depth)
    merge_bottom_up(root)
    return root

def build_subdivision(node, voxel_grid, x0, x1, y0, y1, depth):
    if x1 - x0 == 1 and y1 - y0 == 1:
        x, y = x0, y0
        attr_seq = [voxel_grid[x][y][z] for z in range(depth)]
        node.is_leaf = True
        node.gstack = Gstack(attr_seq, [None])  # Heightfields not needed at leaf level for structure
        return

    mid_x, mid_y = (x0 + x1) // 2, (y0 + y1) // 2
    children = []
    for dx, dy in [(0,0), (1,0), (0,1), (1,1)]:
        child = QuadStackNode()
        cx0, cy0 = x0 + dx * (mid_x - x0), y0 + dy * (mid_y - y0)
        cx1, cy1 = cx0 + (mid_x - x0), cy0 + (mid_y - y0)
        build_subdivision(child, voxel_grid, cx0, cx1, cy0, cy1, depth)
        children.append(child)
    
    # Leaf criterion: same attribute sequence
    ref_seq = children[0].gstack.attr_sequence
    if all(c.gstack.attr_sequence == ref_seq for c in children):
        node.is_leaf = True
        # Pack heightfields from children into parent leaf gstack
        node.gstack = Gstack(ref_seq, [c.gstack.heightfields[0] for c in children])
        node.children = []
    else:
        node.is_leaf = False
        node.children = children

def merge_bottom_up(node):
    if node.is_leaf:
        return
    
    for child in node.children:
        merge_bottom_up(child)
    
    children_gstacks = [c.gstack for c in node.children]
    parent_gstack, wildcard_intervals = find_optimal_mapping(children_gstacks)
    
    if parent_gstack and any(a != '*' for a in parent_gstack.attr_sequence):
        node.is_leaf = True
        node.gstack = parent_gstack
        
        for i, child in enumerate(node.children):
            convert_to_wildcards(child.gstack, wildcard_intervals)
            if child.gstack.is_all_wildcards():
                node.children[i] = None  # Mark for deletion
        node.children = [c for c in node.children if c is not None]
    else:
        node.is_leaf = False

def find_optimal_mapping(children_gstacks):
    # Brute-force search over permutations of children intervals to maximize terminal matches [S1, unofficial]
    best_gstack = None
    best_terminal_count = -1
    best_wildcards = set()
    
    # Align sequences: pad/trim to max length, use '*' for mismatches
    max_len = max(len(g.attr_sequence) for g in children_gstacks)
    padded = []
    for g in children_gstacks:
        seq = g.attr_sequence + ['*'] * (max_len - len(g.attr_sequence))
        padded.append(seq)
        
    # Try all permutations of children order
    for perm in itertools.permutations(range(4)):
        aligned = [[padded[perm[i]][j] for i in range(4)] for j in range(max_len)]
        terminal_count = sum(1 for col in aligned if len(set(col)) == 1 and col[0] != '*')
        
        if terminal_count > best_terminal_count:
            best_terminal_count = terminal_count
            best_aligned = aligned
            # Identify which positions are wildcards in children
            best_wildcards = set(j for j, col in enumerate(aligned) if '*' in col)
            
    # Construct parent gstack
    parent_seq = [best_aligned[j][0] if len(set(best_aligned[j])) == 1 else '*' for j in range(max_len)]
    # Pack heightfields: for terminal intervals use common boundary, for wildcards pack children's
    parent_hfields = []
    for j in range(max_len):
        if parent_seq[j] != '*':
            parent_hfields.append(best_aligned[j][0])  # Common boundary
        else:
            parent_hfields.append([best_aligned[i][j] for i in range(4)])  # Pack children
            
    return Gstack(parent_seq, parent_hfields), best_wildcards

def convert_to_wildcards(gstack, wildcard_indices):
    for i in wildcard_indices:
        if i < len(gstack.attr_sequence):
            gstack.attr_sequence[i] = '*'

def is_all_wildcards(self):
    return all(a == '*' for a in self.attr_sequence)

Gstack.is_all_wildcards = is_all_wildcards
```

### Value Retrieval
To retrieve the attribute at $(x, y, z)$:
1. Traverse the quadtree from the root to the leaf corresponding to $(x, y)$ [S1, unofficial].
2. In the leaf gstack, sample the corresponding heightfields to determine which interval contains $z$ [S1, unofficial].
3. Total access time is $O(\log n + m)$, where $n = w \times h$ and $m$ is the maximum stack size [S1, unofficial]. In practice, $m \ll n$, so the method is assumed to run in logarithmic time [S1, unofficial].

### Parameters and Edge Cases
*   **Layer Direction:** Assumes layers are parallel to the $xy$-plane [S1, unofficial].
*   **Wildcards:** If a gstack consists entirely of `*` intervals, it is deleted [S1, unofficial].
*   **Complexity:** Construction time is $O(n \log n)$ for subdivision and $O(n \times (m!)^4)$ for merging, where $n$ is the number of stacks and $m$ is the max intervals per gstack [S1, unofficial].

## Operating characteristics
*   **Compression:** Achieves 4× to 54× compression of the original voxel memory footprint [S1, unofficial]. Uses 66% to 99% less memory than uncompressed data [S1, unofficial].
*   **Rendering Performance:** 18-79 MRays/s on an NVIDIA 970 GTX [S1, unofficial]. Comparable to state-of-the-art algorithms [S1, unofficial].
*   **Access Time:** $O(\log n + m)$ for value retrieval [S1, unofficial].
*   **Strengths:** High compression for layered data; direct rendering without mesh conversion; decoupled attributes and geometry allow transfer function optimization [S1, unofficial].
*   **Limitations:** Only effective for data with strong directional anisotropy and spatial coherence in layer sequence [S1, unofficial].

## Background
QuadStack was introduced by Alejandro Graciano, Antonio J. Rueda, Adam Pospíšil, Jiří Bittner, and Bedřich Benes [S1, unofficial]. It builds upon the Stack-Based Representation (SBR) [1081-stack-based-representation-sbr.md], extending it with quadtree compression [S1, unofficial]. It is applied to datasets from geology, industrial models, microstructural data, and magnetic reconnection simulations [S1, unofficial].
