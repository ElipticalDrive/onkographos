# Stack-Based Representation (SBR)
Also called: Stacks
## Overview
Stack-Based Representation (SBR) decomposes a voxel grid $V$ of resolution $w \times h \times d$ into a set $S$ of vertical stacks, where each stack $S_{x,y}$ represents the column of voxels at position $(x,y)$ [S1, unofficial]. Each stack is compacted as a run-length encoding of voxels sharing the same attribute value, represented as a sequence of intervals along the $z$-axis [S1, unofficial]. It serves as the base representation for hierarchical variants like [QuadStack](1113-quadstack.md) [S1, unofficial].
## How it works
**Inputs and Outputs:**
*   **Input:** A voxel grid $V$ of resolution $w \times h \times d$, where each voxel $v_{x,y,z}$ stores one or more attributes (e.g., color, material, density) [S1, unofficial].
*   **Output:** A set $S$ of vertical stacks, where each stack $S_{x,y}$ corresponds to a column at position $(x,y)$ [S1, unofficial].

**Data Structures:**
Each stack $S_{x,y}$ is represented as a sequence of intervals $i_1, i_2, \dots, i_n$ sorted by height [S1, unofficial].
*   **Interval ($i_k$):** A tuple $\langle a_k, h_k \rangle$.
    *   $a_k$: The attribute value shared by all voxels in the interval [S1, unofficial].
    *   $h_k$: The cumulative height (absolute $z$-coordinate) of the top voxel of the interval [S1, unofficial].
*   **Implicit Geometry:** The interval $i_k$ covers voxels from $z = 1 + h_{k-1}$ to $z = h_k$ [S1, unofficial]. For the first interval ($k=1$), $h_0$ is assumed to be $0$ [S1, unofficial].

**Formulas:**
The stack is the union of voxels in the column:
$$S_{x,y} \cong V_{x,y} = \bigcup_{i=1}^d v_{x,y,i}$$

An interval $i_k$ represents the space of voxels with identical attribute value $a_k$:
$$i_k \cong \bigcup_{i=1+h_{k-1}}^{h_k} v_{x,y,i}$$

Intervals are strictly sorted by height:
$$h_k < h_{k+1} \quad \text{for any given } k \text{ such that } 1 \le k \le n$$

**Algorithm:**
1. Iterate through each column $(x,y)$ in the grid dimensions $w \times h$ [S1, unofficial].
2. Initialize an empty interval list for the stack and set the previous cumulative height $h_{k-1}$ to $0$ [G].
3. Iterate through $z$ from $1$ to $d$ [S1, unofficial].
4. Compare the attribute value of the current voxel $v_{x,y,z}$ with the attribute of the active interval [G].
5. If the attribute changes, append the active interval as $\langle a_k, z-1 \rangle$ to the list, then start a new interval with the current attribute value [G].
6. After the loop, append the final interval as $\langle a_n, d \rangle$ [G].
7. Store the completed interval sequence for stack $S_{x,y}$ [S1, unofficial].

**Pseudocode:**
```python
def build_sbr(voxel_grid, width, height, depth):
    stacks = {}
    for x in range(width):
        for y in range(height):
            intervals = []
            current_attr = None
            prev_h = 0  # h_{k-1}, initialized to 0
            
            for z in range(1, depth + 1):
                attr = voxel_grid[x][y][z]
                if attr != current_attr:
                    if current_attr is not None:
                        # Finalize previous interval: top height is z-1
                        intervals.append({'attr': current_attr, 'height': z - 1})
                    current_attr = attr
                    prev_h = z - 1  # Update h_{k-1} for the next interval
            
            # Finalize the last interval with height = depth
            if current_attr is not None:
                intervals.append({'attr': current_attr, 'height': depth})
            
            stacks[(x, y)] = intervals
    return stacks
```

**Edge Cases and Pitfalls:**
*   **Parallelism:** Construction is embarrassingly parallel because stack construction does not require information about neighboring stacks [S1, unofficial].
*   **Boundary Conditions:** The first interval always starts at $z=1$ and the last always ends at $z=d$, ensuring full coverage of the column without gaps or overlaps [S1, unofficial].

## Subtopics          

### [QuadStack](1113-quadstack.md)
Organizes similar stacks into a quadtree to compress regions with constant layer topology, achieving higher compression rates than flat SBR by exploiting attribute uniformity across neighboring columns. Choose it when spatial coherence in layer topology is high and maximum compression is required over flat storage.

### [Group of Stacks (gstack)](1169-group-of-stacks-gstack.md)
Represents a rectangular region of vertical stacks sharing identical attribute sequences and interval counts, compressing common attributes while storing varying geometry as non-intersecting heightfields. Choose it when attribute values are spatially clustered but heights vary significantly.

## Operating characteristics
*   **Time Complexity:** Construction is $O(n)$, where $n = w \times h \times d$, because each voxel is processed exactly once [S1, unofficial].
*   **Memory Complexity:** Not given in the sources. [S1, unofficial]
*   **Strengths:** Embarrassingly parallel construction [S1, unofficial].
