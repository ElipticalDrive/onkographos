# SparseGrid
Also called: SparseGrid Data Structure
## Overview
SparseGrid is a sparse adaptive grid that allocates memory only for cells explicitly added to the domain, making it suitable for large volumetric spaces containing small iso-surface regions [S1, unofficial]. It differs from dense grids by storing only active cell indices and their associated data on the device, and from tree-based structures by using a flat linear index mapping rather than hierarchical pointers [S1, unofficial]. It serves as the foundational data container for GPU-accelerated marching tetrahedra and dual mesh generation pipelines [S1, unofficial].

## How it works
### Inputs and Outputs
- **Inputs**:
  - `shape`: A 3D vector (`uint3`) defining the number of sample points in each dimension (x, y, z) of the implied lattice [S1, unofficial].
  - `aabb_min`: The minimum corner of the bounding box, default `[-1, -1, -1]` [S1, unofficial].
  - `aabb_max`: The maximum corner of the bounding box, default `[1, 1, 1]` [S1, unofficial].
  - `default_value`: The scalar value for unset points, default `FLT_MAX` [S1, unofficial].
  - `cell_indices`: A 1D `int32` tensor of linear cell indices to add [S1, unofficial].
- **Outputs**:
  - `values`: An `(N, 8)` `float32` tensor of scalar values at the corners of the $N$ active cells [S1, unofficial].
  - `points`: An `(N, 8, 3)` `float32` tensor of corner coordinates for the active cells [S1, unofficial].
  - `cell_indices`: A 1D `int32` tensor of linear indices of all active cells [S1, unofficial].
  - `GridView`: A struct containing `shape`, `aabb_min`, `aabb_max`, pointers to `values` and `cell_indices`, and a validity flag [S1, unofficial].

### Data Structures
The `SparseGrid` class stores data on the GPU using Thrust device vectors [S1, unofficial].

**Private Members:**
- `thrust::device_vector<float> values`: Stores scalar values. Size is $N \times 8$, where $N$ is the number of active cells [S1, unofficial].
- `thrust::device_vector<uint> cell_indices`: Stores the linear indices of active cells. Size is $N$ [S1, unofficial].
- `uint3 shape`: Dimensions of the implied lattice [S1, unofficial].
- `float3 aabb_min`: Bounding box minimum [S1, unofficial].
- `float3 aabb_max`: Bounding box maximum [S1, unofficial].
- `float default_value`: Value for non-active cells [S1, unofficial].

**Linear Indexing:**
Cells are identified by a linear index $I$ [S1, unofficial]. Given a cell coordinate $(x, y, z)$ in the implied lattice of size $(S_x, S_y, S_z)$, the linear index is calculated as:
$$ I = x \cdot (S_y \cdot S_z) + y \cdot S_z + z $$
Conversely, given $I$:
$$ z = I \pmod{S_z} $$
$$ y = (I / S_z) \pmod{S_y} $$
$$ x = I / (S_y \cdot S_z) $$
The coordinates of the 8 corners of a cell with linear index $I$ are retrieved via `get_points_by_cell_indices`, returning an $(N, 8, 3)$ tensor [S1, unofficial].

### Algorithm Steps

1. **Initialization**: Construct the grid with `shape`, `aabb_min`, `aabb_max`, and `default_value` [S1, unofficial]. Initialize `values` and `cell_indices` as empty device vectors [S1, unofficial].
2. **Adding Cells**: To add cells, call `add_cells` with a 1D `int32` tensor of linear indices [S1, unofficial]. Append new indices to `cell_indices` [S1, unofficial]. For each new cell, allocate space in `values` for 8 corners [S1, unofficial].
3. **Removing Cells**: To remove cells, call `remove_cells` with a 1D `int32` tensor of linear indices [S1, unofficial]. Identify indices in `cell_indices` that match the input [S1, unofficial]. Remove corresponding entries from `cell_indices` and `values` [G].
4. **Retrieving Data**: `get_points()` returns an $(N, 8, 3)$ tensor [S1, unofficial]. For each active cell index $I_k$, compute its 8 corner coordinates in world space using `aabb_min`, `aabb_max`, and `shape` [S1, unofficial]. `get_values()` returns an $(N, 8)$ tensor of scalar values at active cell corners [S1, unofficial]. `get_cell_indices()` returns the 1D `int32` tensor of active linear indices [S1, unofficial].
5. **Iso-surface Filtering**: Call `filter_cell_indices(cell_indices, values, level)` to find cells crossing the iso-surface [S1, unofficial]. For each cell, check if the 8 corner values span the `level` [S1, unofficial]. Return a 1D `int32` tensor of indices for cells where $\min(values) < level < \max(values)$ [G].
6. **Dual Quad Generation**: Call `get_dual_quads(edges, is_out)` to generate dual mesh primitives [S1, unofficial]. Input: `edges` (`NDArray<uint2>`), `is_out` (`NDArray<bool>`) [S1, unofficial]. Output: Tuple of `thrust::device_vector<int4>` (quad indices), `thrust::device_vector<bool>` (orientation/outside flag), `thrust::device_vector<uint2>` (deduplicated edges) [S1, unofficial].

### Pseudocode

```python
import numpy as np
from typing import Tuple, List

class SparseGrid:
    def __init__(self, shape: Tuple[int, int, int], 
                 aabb_min: Tuple[float, float, float] = (-1.0, -1.0, -1.0), 
                 aabb_max: Tuple[float, float, float] = (1.0, 1.0, 1.0), 
                 default_value: float = float('inf')):
        self.shape = shape
        self.aabb_min = np.array(aabb_min)
        self.aabb_max = np.array(aabb_max)
        self.default_value = default_value
        self.cell_indices: List[int] = []
        self.values: List[List[float]] = []  # List of 8 floats per cell

    def add_cells(self, indices: List[int]):
        """Add cells to the grid."""
        for idx in indices:
            if idx not in self.cell_indices:
                self.cell_indices.append(idx)
                # Initialize 8 corners with default value
                self.values.append([self.default_value] * 8)

    def remove_cells(self, indices: List[int]):
        """Remove cells from the grid."""
        indices_set = set(indices)
        new_indices = []
        new_values = []
        for i, idx in enumerate(self.cell_indices):
            if idx not in indices_set:
                new_indices.append(idx)
                new_values.append(self.values[i])
        self.cell_indices = new_indices
        self.values = new_values

    def get_points_by_cell_indices(self) -> np.ndarray:
        """Return (N, 8, 3) tensor of corner coordinates."""
        N = len(self.cell_indices)
        points = np.zeros((N, 8, 3))
        for i, idx in enumerate(self.cell_indices):
            # Convert linear index to 3D grid coordinates
            x = idx // (self.shape[1] * self.shape[2])
            y = (idx // self.shape[2]) % self.shape[1]
            z = idx % self.shape[2]
            
            # Compute corner coordinates in world space
            # Assuming uniform grid spacing based on shape as point count
            dx = (self.aabb_max[0] - self.aabb_min[0]) / (self.shape[0] - 1) if self.shape[0] > 1 else 0.0
            dy = (self.aabb_max[1] - self.aabb_min[1]) / (self.shape[1] - 1) if self.shape[1] > 1 else 0.0
            dz = (self.aabb_max[2] - self.aabb_min[2]) / (self.shape[2] - 1) if self.shape[2] > 1 else 0.0
            
            corners = []
            for cx in [x, x+1]:
                for cy in [y, y+1]:
                    for cz in [z, z+1]:
                        wx = self.aabb_min[0] + cx * dx
                        wy = self.aabb_min[1] + cy * dy
                        wz = self.aabb_min[2] + cz * dz
                        corners.append([wx, wy, wz])
            points[i] = corners
        return points

    def get_values(self) -> np.ndarray:
        """Return (N, 8) tensor of scalar values."""
        return np.array(self.values)

    def get_cell_indices(self) -> List[int]:
        """Return 1D int32 tensor of linear indices."""
        return self.cell_indices

    def filter_cell_indices(self, level: float = 0.0) -> List[int]:
        """Return indices of cells crossing the iso-surface."""
        crossing_indices = []
        for i, idx in enumerate(self.cell_indices):
            vals = self.values[i]
            if min(vals) < level < max(vals):
                crossing_indices.append(idx)
        return crossing_indices

    def get_dual_quads(self, edges: np.ndarray, is_out: np.ndarray) -> Tuple:
        """
        Generate dual quads.
        Input: edges (N, 2) uint2, is_out (N,) bool
        Output: quad_indices (M, 4) int4, is_out_flags (M,) bool, dedup_edges (K, 2) uint2
        """
        # Source does not provide the exact intersection and quad assembly logic.
        # Implementation requires processing edges and is_out flags to build dual mesh primitives.
        raise NotImplementedError("Dual quad generation logic not provided in source.")

    def get_grid_view(self) -> dict:
        """Return GridView struct."""
        return {
            "shape": self.shape,
            "aabb_min": self.aabb_min,
            "aabb_max": self.aabb_max,
            "values": np.array(self.values),
            "cell_indices": np.array(self.cell_indices),
            "valid": True
        }
```

### Edge Cases and Pitfalls
- **Precision**: Linear indexing uses `uint` in the source implementation [S1, unofficial].
- **Boundaries**: Cells at the boundary may have corners outside the `aabb` if not clipped [S1, unofficial]. The source provides a `clip` function to clamp coordinates to `aabb_min` and `aabb_max` [S1, unofficial].
- **Degenerate Input**: If `shape` contains zeros, division by zero occurs in coordinate calculation [G].
- **Default Value**: Using `FLT_MAX` as default value may cause issues in distance calculations if not handled [S1, unofficial].

## Operating characteristics
- **Time Complexity**: Add/Remove operations are O(1) amortized for vector append, but O(N) if searching for existing indices without a hash set [G]. Retrieving points, values, and filtering all scale linearly with the number of active cells, O(N) [S1, unofficial].
- **Memory Complexity**: O(N) where N is the number of active cells. Each cell stores 8 floats and 1 integer index [S1, unofficial].
- **Measured Performance**: Not given in the sources.
- **Scaling**: Scales linearly with the number of active cells [S1, unofficial].
- **Strengths**: Simple implementation, low memory overhead for sparse data, easy to integrate with GPU pipelines [S1, unofficial].
- **Limitations**: No spatial coherence exploitation, poor cache locality for random access, no built-in LOD [G].
- **When to Use**: Small iso-surface regions in large domains, simple adaptive grids [S1, unofficial].
- **When Not to Use**: Dense volumes, need for hierarchical LOD, complex spatial queries [G].

## Background
The data structure is implemented in C++ with CUDA device functions within the `isoext` repository [S1, unofficial]. It is designed to work with marching tetrahedra and dual mesh generation, providing a flexible sparse data structure for active cells [S1, unofficial].
