# ExaBricks Hierarchy

Also called: ExaBricks, ExaBricks data structure

## Overview
ExaBricks is a rendering method for Block-Structured Adaptive Mesh Refinement (BS-AMR) data that re-organizes input cells into compact, non-overlapping bricks and uses a secondary spatial partitioning called Active Brick Regions (ABRs) to enable smooth, high-quality interpolation across level boundaries [S1]. It sets itself apart from prior methods by eliminating costly per-sample cell location kernels (required by the basis method [37]) and deep AMR hierarchy traversals, instead relying on ABRs for fast sample reconstruction and an RTX BVH for hardware-accelerated ray marching [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of AMR cells, each defined by lower-left unit coordinates $(i, j, k)$, level $l$, and a scalar data value $C_v$. Level 0 is the finest level (implicit cell size $1^3$); level $l$ has cell size $2^l$ [S1].
*   **Output:** A set of bricks, a hierarchy of Active Brick Regions (ABRs), and an RTX Bounding Volume Hierarchy (BVH) over the ABRs, enabling ray traversal and volume rendering [S1].

**Data Structures:**

1.  **Brick:**
    *   `lower_left`: Tuple $(i, j, k)$ of integer coordinates [S1].
    *   `level`: Integer $l$ [S1].
    *   `dims`: Tuple $(N, M, K)$ representing the number of cells in each dimension [S1].
    *   `scalars`: A 3D array of size $N \times M \times K$ storing the data values [S1].

2.  **Active Brick Region (ABR):**
    *   `bbox`: Bounding box of the region [S1].
    *   `active_bricks`: List of brick IDs that influence this region [S1].
    *   `min_val`: Minimum scalar value of any cell whose support overlaps the region [S1].
    *   `max_val`: Maximum scalar value of any cell whose support overlaps the region [S1].
    *   `finest_cell_width`: Cell width of the finest AMR level influencing the region [S1].

**Algorithm Steps:**

1.  **Brick Generation:**
    *   Build a k-d tree top-down from the input AMR cells [S1].
    *   For a current node, check if all cells are on the same AMR level and completely fill their combined bounding box [S1].
    *   If yes, create a leaf node (a brick) [S1].
    *   If no, split the node along the longest axis of its bounding box [S1].
    *   Round split positions to an integer multiple of the current coarsest cell width [S1].
    *   Limit leaf size to at most 32 cells wide on any axis to ensure fine granularity for space skipping [S1].
    *   Discard the internal hierarchy; store only the leaf bricks [S1].

2.  **ABR Construction:**
    *   Create a list of "brick support fragments". Each fragment is a box representing the support of a brick and its brick ID [S1].
    *   Compute the bounding box of all fragments [S1].
    *   Recursively subdivide the bounding box:
        *   For the current region and its overlapping fragments, find a partitioning plane from the fragment boundaries closest to the region's spatial center [S1].
        *   Prefer the widest dimension for the split [S1].
        *   If no valid plane exists, create a leaf ABR containing the current list of brick IDs [S1].
        *   Otherwise, partition the region, sort fragments into left/right subtrees, and recurse [S1].
    *   For each leaf ABR, compute `min_val`, `max_val`, and `finest_cell_width` from the active bricks [S1].

3.  **BVH Construction:**
    *   Build an RTX BVH over the leaf ABRs [S1].

4.  **Ray Traversal and Rendering:**
    *   Use the RTX BVH to iterate over ABRs a ray intersects, skipping those it is safe to ignore [S1].
    *   For samples within an ABR leaf, retrieve the list of active bricks [S1].
    *   Perform basis reconstruction using the cells within those bricks [S1].

**Reconstruction Formula:**
The method uses the basis function by Wald et al. [37] for smooth interpolation [S1]. For a cell $C$ of width $C_w$, the basis function is:

$$ \hat{H}_C(p) = \hat{h}\left(\frac{|C_{p_x} - p_x|}{C_w}\right) \hat{h}\left(\frac{|C_{p_y} - p_y|}{C_w}\right) \hat{h}\left(\frac{|C_{p_z} - p_z|}{C_w}\right) $$

where $\hat{h}(x) = \max(1 - x, 0)$ [S1].

The reconstruction at position $p$ is:

$$ B(p) = \frac{\sum_{C_i} \hat{H}_{C_i}(p) C_{v_i}}{\sum_{C_i} \hat{H}_{C_i}(p)} $$

where $C_i$ are cells with non-zero support at $p$, and $C_{v_i}$ is the data value [S1].

**Cell Support Definition:**
*   The support of a cell $C$ is a rectangular box extending exactly half a cell width beyond the cell itself [S1].
*   The support of a brick $B$ is the union of the supports of its cells, resulting in a box exactly half the brick's cell width larger than the brick [S1].

**Pseudocode:**

```python
def generate_bricks(cells):
    """
    Re-organize AMR cells into non-overlapping bricks.
    cells: List of dicts with keys 'i', 'j', 'k', 'l', 'bbox'
    Returns: List of Brick objects
    """
    # Build k-d tree top-down
    root = KDNode(cells)
    bricks = []
    stack = [root]
    
    while stack:
        node = stack.pop()
        # Check if leaf condition is met
        if is_leaf(node):
            bricks.append(create_brick(node))
        else:
            # Split along longest axis
            split_axis = node.longest_axis()
            # Round split position to integer multiple of coarsest cell width
            split_pos = round_to_multiple(node.bbox.center()[split_axis], node.coarsest_cell_width)
            
            left_cells, right_cells = split_cells(node.cells, split_axis, split_pos)
            
            if left_cells:
                stack.append(KDNode(left_cells))
            if right_cells:
                stack.append(KDNode(right_cells))
                
    return bricks

def is_leaf(node):
    """
    Leaf if all cells are same level, fill bounding box, and size <= 32 on any axis.
    """
    if not node.cells:
        return False
    
    levels = set(c['l'] for c in node.cells)
    if len(levels) > 1:
        return False
        
    # Check if cells completely fill bounding box
    if not cells_fill_bbox(node.cells, node.bbox):
        return False
        
    # Check size limit
    dims = node.bbox.size()
    if any(d > 32 for d in dims):
        return False
        
    return True

def create_brick(node):
    """
    Create Brick object from leaf node cells.
    """
    cells = node.cells
    # Assume all cells are same level and contiguous
    l = cells[0]['l']
    # Determine lower-left and dimensions from cells
    # [G] Implementation detail: Sort cells to find min coordinates and max dimensions
    min_i = min(c['i'] for c in cells)
    min_j = min(c['j'] for c in cells)
    min_k = min(c['k'] for c in cells)
    
    # [G] Determine N, M, K by counting unique coordinates or bounding box size / cell_size
    cell_size = 2 ** l
    max_i = max(c['i'] for c in cells)
    max_j = max(c['j'] for c in cells)
    max_k = max(c['k'] for c in cells)
    
    N = (max_i - min_i) // cell_size + 1
    M = (max_j - min_j) // cell_size + 1
    K = (max_k - min_k) // cell_size + 1
    
    # [G] Extract scalar values into 3D array
    scalars = zeros((N, M, K))
    for c in cells:
        idx_i = (c['i'] - min_i) // cell_size
        idx_j = (c['j'] - min_j) // cell_size
        idx_k = (c['k'] - min_k) // cell_size
        scalars[idx_i, idx_j, idx_k] = c['value']
        
    return Brick(lower_left=(min_i, min_j, min_k), level=l, dims=(N, M, K), scalars=scalars)

def construct_abrs(bricks):
    """
    Build Active Brick Regions from bricks.
    """
    # Create support fragments
    fragments = []
    for brick in bricks:
        support_box = compute_brick_support(brick)
        fragments.append({'box': support_box, 'brick_id': brick.id})
        
    # Compute global bounding box
    global_bbox = union_boxes([f['box'] for f in fragments])
    
    # Recursive subdivision
    abrs = []
    build_abr_recursive(global_bbox, fragments, abrs)
    return abrs

def compute_brick_support(brick):
    """
    Support is brick bbox extended by half cell width.
    """
    cell_size = 2 ** brick.level
    half_cell = cell_size / 2.0
    bbox = brick.bbox # [G] Derived from lower_left and dims
    # Extend bbox by half_cell in all directions
    return bbox.extend(half_cell)

def build_abr_recursive(region_bbox, overlapping_fragments, abrs):
    """
    Recursively subdivide region to create ABRs.
    """
    if not overlapping_fragments:
        return
        
    # Find partitioning plane
    plane = find_best_split_plane(region_bbox, overlapping_fragments)
    
    if plane is None:
        # Create leaf ABR
        abrs.append(ABR(
            bbox=region_bbox,
            active_bricks=[f['brick_id'] for f in overlapping_fragments],
            min_val=compute_min_val(overlapping_fragments),
            max_val=compute_max_val(overlapping_fragments),
            finest_cell_width=compute_finest_width(overlapping_fragments)
        ))
    else:
        left_frags, right_frags = split_fragments(overlapping_fragments, plane)
        left_bbox, right_bbox = split_bbox(region_bbox, plane)
        
        if left_frags:
            build_abr_recursive(left_bbox, left_frags, abrs)
        if right_frags:
            build_abr_recursive(right_bbox, right_frags, abrs)

def find_best_split_plane(region, fragments):
    """
    Find fragment boundary closest to region center, preferring widest dimension.
    """
    center = region.center()
    best_plane = None
    best_dist = infinity
    best_dim = -1
    
    # Iterate fragment boundaries
    for frag in fragments:
        for dim in [0, 1, 2]:
            # Get min and max of fragment in dim
            min_val = frag['box'].min[dim]
            max_val = frag['box'].max[dim]
            
            # Check if boundary is inside region
            if min_val > region.min[dim] and min_val < region.max[dim]:
                dist = abs(min_val - center[dim])
                if dist < best_dist:
                    best_dist = dist
                    best_plane = {'dim': dim, 'pos': min_val}
                    best_dim = dim
            if max_val > region.min[dim] and max_val < region.max[dim]:
                dist = abs(max_val - center[dim])
                if dist < best_dist:
                    best_dist = dist
                    best_plane = {'dim': dim, 'pos': max_val}
                    best_dim = dim
                    
    # Prefer widest dimension if distances are equal? 
    # Note: Sources say "prefer widest dimension" but also "closest to center".
    # Implementation: If multiple planes have same min distance, pick widest.
    # Simplified: Just pick closest. If tie, pick widest.
    
    return best_plane

def basis_reconstruct(p, abrs, bricks):
    """
    Reconstruct value at point p using ABRs and bricks.
    """
    # Find ABR leaf containing p
    abr = find_abr_leaf(abrs, p)
    
    total_weight = 0.0
    total_value = 0.0
    
    for brick_id in abr.active_bricks:
        brick = bricks[brick_id]
        # Find cells in brick that influence p
        # [G] Determine which cells in the 3D array have non-zero support
        cell_width = 2 ** brick.level
        half_cell = cell_width / 2.0
        
        # Iterate over relevant cells in brick
        # [G] Optimization: Only iterate cells whose support overlaps p
        # Support of cell (i,j,k) is [i-half, i+half] x ...
        # p is in support if |p_coord - cell_center| < half_cell
        
        for i in range(brick.dims[0]):
            for j in range(brick.dims[1]):
                for k in range(brick.dims[2]):
                    cell_center = brick.lower_left + (i + 0.5) * cell_width
                    # Check if p is in cell support
                    if is_in_support(p, cell_center, cell_width):
                        # Compute basis function
                        h_x = max(1.0 - abs(p.x - cell_center.x) / cell_width, 0.0)
                        h_y = max(1.0 - abs(p.y - cell_center.y) / cell_width, 0.0)
                        h_z = max(1.0 - abs(p.z - cell_center.z) / cell_width, 0.0)
                        
                        weight = h_x * h_y * h_z
                        value = brick.scalars[i, j, k]
                        
                        total_weight += weight
                        total_value += weight * value
                        
    if total_weight == 0:
        return 0.0 # Or handle as empty space
    return total_value / total_weight

def is_in_support(p, cell_center, cell_width):
    half = cell_width / 2.0
    return (abs(p.x - cell_center.x) < half and
            abs(p.y - cell_center.y) < half and
            abs(p.z - cell_center.z) < half)
```

## Subtopics

### [Octant Method](2648-octant-method.md)
A reconstruction strategy for cell-centered Block-Structured Adaptive Mesh Refinement (BS-AMR) data that maps a sample point $p=(x,y,z)$ to a scalar value $F(p)$ by decomposing the domain into non-overlapping rectilinear octants, ensuring continuity across level boundaries and supporting fast implicit ray-isosurface intersections.

## Operating characteristics
*   **Time Complexity:** Rendering time is dominated by ray traversal through the RTX BVH and basis reconstruction. The ABR structure allows $O(1)$ retrieval of influencing bricks for a given region, avoiding the $O(\log N)$ or worse per-sample k-d tree traversals required by prior methods [S1].
*   **Memory Complexity:** Memory usage is proportional to the number of bricks and ABRs. Bricks store only the necessary cells, and ABRs store metadata and lists of brick IDs. The structure avoids storing the full AMR hierarchy [S1].
*   **Measured Performance:** The method supports interactive high-quality direct volume rendering with smooth AMR reconstruction and gradient-based shading [S1]. It enables adaptive sampling that adapts to the finest level cell size while keeping total sample counts tractable [S1].
*   **Strengths:**
    *   Smooth interpolation across level boundaries using the basis method [S1].
    *   Fast sample reconstruction without costly cell location kernels [S1].
    *   Hardware-accelerated ray marching and space skipping via RTX BVH [S1].
    *   Supports interactive transfer function and iso-surface editing [S1].
*   **Limitations:**
    *   The basis method's support is not truncated at the first sample on the neighboring side, leading to larger support overlap between cells from neighboring blocks compared to some prior methods [S1].
    *   Requires re-organizing input data into bricks, discarding the original AMR hierarchy [S1].
*   **When to use:** When rendering BS-AMR data with smooth interpolation requirements and hardware-accelerated ray tracing capabilities (RTX) are available.
*   **When not to use:** When the input data is Tree-Based AMR and the overhead of brick generation is prohibitive, or when nearest-neighbor interpolation is sufficient and the complexity of ABR construction is not justified.

## Background
ExaBricks was introduced by Wald et al. in 2020 [S1]. It builds on the brick-based organization proposed by Kähler et al. [17] and the basis reconstruction method by Wald et al. [37]. The method addresses the limitations of prior AMR rendering work, such as the costly cell location kernels used in [37] and the lack of smooth interpolation in methods like [21]. It is designed for Block-Structured AMR layouts but can be applied to a wide range of AMR refinement schemes [S1].
