# Neuralangelo Hashgrid Configuration
Also called: Neuralangelo Hashgrid Parameters

## Overview
Neuralangelo Hashgrid Configuration specifies the hyperparameters for the multi-level hashed grid construction used in the Neuralangelo neural implicit surface reconstruction method [S1]. It is distinguished from generic hash grid implementations by its specific adherence to the Sdfstudio baseline configuration, which prioritizes fine-grained detail recovery for indoor scenes [S1].

## How it works
**Inputs and Outputs:**
- Input: 3D spatial coordinates $\mathbf{x} \in \mathbb{R}^3$ [G].
- Output: Feature vector $\mathbf{f} \in \mathbb{R}^{d}$, where $d$ is the feature size [G].

**Data Structures:**
The configuration consists of $L=16$ levels of hash grids [S1]. Each level $l$ has a resolution $R_l$ ranging from 32 to 4096 [S1]. The exact sequence of 16 resolution values is not provided in the sources [S1]. Each level shares a hash map size of $H=2^{19}$ entries [S1]. The feature size is $d=8$ [S1]. The hash map layout is an array of $H$ entries, each storing a feature vector of size $d=8$ (typically 32-bit floating-point) [G]. The hash function maps a coordinate to an index in $[0, H-1]$ [G].

**Parameters:**
- Training Epochs: 100,000 [S1].
- Scheduling: Learning rate schedulers and coarse-to-fine duration are scaled down proportionally to match the 100k epoch limit compared to the original 500k epoch baseline [S1].
- Scene Contraction: Removed for synthetic indoor datasets (e.g., Replica) [S1].
- Background MLPs: Removed for synthetic indoor datasets [S1].
- Appearance Embedding: Removed for synthetic indoor datasets [S1].

**Pseudocode:**
The following pseudocode defines the configuration constants and the basic hash grid lookup logic implied by the parameters.

```python
import numpy as np

# Configuration constants from [S1]
NUM_LEVELS = 16
HASHMAP_SIZE = 2**19  # 524288
FEATURE_SIZE = 8
RESOLUTION_MIN = 32
RESOLUTION_MAX = 4096

# The sources do not give the exact sequence of 16 resolutions between 32 and 4096 [S1].
RESOLUTIONS = [0] * NUM_LEVELS  # Replace with actual sequence from reference implementation

class NeuralangeloHashGrid:
    def __init__(self):
        # Initialize feature grids for each level [G]
        self.grids = [np.zeros((HASHMAP_SIZE, FEATURE_SIZE), dtype=np.float32) for _ in range(NUM_LEVELS)]

    def _hash(self, x, y, z, level):
        # Deterministic hash mapping coordinates and level to [0, HASHMAP_SIZE-1] [G]
        val = (x * 73856093) ^ (y * 19349663) ^ (z * 83492791) ^ (level * 1048576)
        return val % HASHMAP_SIZE

    def forward(self, coords):
        # coords: Array of shape (N, 3)
        N = coords.shape[0]
        aggregated_features = np.zeros((N, FEATURE_SIZE), dtype=np.float32)

        for l in range(NUM_LEVELS):
            res = RESOLUTIONS[l]
            # Compute integer grid indices [G]
            ix = np.floor(coords[:, 0] * res).astype(np.int32)
            iy = np.floor(coords[:, 1] * res).astype(np.int32)
            iz = np.floor(coords[:, 2] * res).astype(np.int32)

            # Compute hash indices
            indices = np.array([self._hash(int(ix[i]), int(iy[i]), int(iz[i]), l) for i in range(N)], dtype=np.int32)

            # Gather features
            features = self.grids[l][indices]
            aggregated_features += features

        # Average features across levels [G]
        return aggregated_features / NUM_LEVELS
```

**Edge Cases and Pitfalls:**
- Resolution Sequence: The exact sequence of 16 resolution values is not provided in the sources [S1].
- Scene Contraction: Scene contraction is explicitly removed for synthetic indoor datasets, which may affect performance on real-world or large-scale scenes [S1].
- Epoch Scaling: The training schedule must be scaled down to 100k epochs to match the evaluation protocol; using the original 500k schedule may lead to overfitting or mismatched convergence [S1].

## Subtopics

### [Adaptive Feature Grids](10458-adaptive-feature-grids.md)
Adaptive Feature Grids replaces fixed uniform grid placement with multiple spatially adaptive grids equipped with learnable transformation matrices to concentrate representational capacity in high-error regions. Unlike standard hash encodings which rely on collision averaging for sparse data, this approach optimizes parameter distribution via a feature density loss, making it superior for dense, complex scientific volumes but underperforming on highly sparse datasets. Choose it for dense scientific volumes; use standard hash grids for sparse data.

### Wu INR Compression
Wu INR Compression scales INR compression to tera-scale data on consumer hardware using hash grids combined with small fully fused MLPs and three engineering optimizations [S2, unofficial]. It implements sample-streaming rendering, macro-cell acceleration for empty-space skipping, and out-of-core training for volumes exceeding GPU memory [S2, unofficial]. Performance on a 10,240 × 7,680 × 1,536 DNS volume (~950 GB double precision) reached 35.9 dB PSNR with a 1.5 GB model in under two hours on a single consumer GPU [S2, unofficial]. Choose it for tera-scale scientific volumes on limited hardware [S2, unofficial].

## Operating characteristics
- Memory Usage: The hash map size is $2^{19}$ entries [S1]. With a feature size of 8 (assuming 32-bit floats), the memory per level is $2^{19} \times 8 \times 4$ bytes $\approx 64$ MB [S1]. With 16 levels, the total memory for the hash grids is approximately 1 GB [S1].
- Training Time: The configuration is evaluated over 100,000 epochs [S1]. The original Neuralangelo configuration used 500,000 epochs, so this is a 5x reduction in training duration [S1].
- Performance: The configuration is designed for high-fidelity reconstruction of indoor scenes (e.g., Replica dataset) [S1]. Hash encodings benefit from collision averaging on highly sparse data, unlike methods like APMGSRN which underperform in that regime [S2, unofficial].
- Scalability: The fixed resolution range (32 to 4096) limits the maximum detail resolution [S1].

## Background
The Neuralangelo Hashgrid Configuration is based on the basic configuration implemented by Sdfstudio [S1]. It was adopted in the RING-NeRF paper for evaluating neural fields on synthetic indoor datasets [S1]. The configuration was modified from the original 500k epoch schedule to 100k epochs to match the evaluation protocol of the RING-NeRF study [S1]. The method is part of the broader Neuralangelo framework for high-fidelity neural surface reconstruction [S1].
