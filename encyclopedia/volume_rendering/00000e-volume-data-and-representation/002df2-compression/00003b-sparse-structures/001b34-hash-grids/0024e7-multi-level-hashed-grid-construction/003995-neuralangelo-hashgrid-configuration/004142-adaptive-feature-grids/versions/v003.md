# Adaptive Feature Grids


## Overview
Adaptive Feature Grids is a neural volume compression method that replaces fixed uniform grid placement with multiple spatially adaptive grids, each equipped with learnable transformation matrices to concentrate representational capacity in high-error regions [S1, unofficial]. Unlike standard hash encodings which rely on collision averaging for sparse data, this approach optimizes parameter distribution via a feature density loss, making it superior for dense, complex scientific volumes but underperforming on highly sparse datasets [S1, unofficial].

## How it works
**Inputs and Outputs**
- **Input:** A large-scale scientific volume dataset (e.g., $4096^3$ or larger) and a target compression ratio [S1, unofficial].
- **Output:** A compressed model consisting of learnable transformation matrices and feature grid weights, capable of reconstructing the volume via an MLP [S1, unofficial].

**Data Structures**
- **Adaptive Grids:** A set of $N$ grids ($N \in [16, 32]$) [S1, unofficial].
- **Transformation Matrices:** Learnable matrices within each grid that define spatial orientation and scaling [S1, unofficial].
- **Feature Density:** A scalar field or loss term used to guide the placement of capacity [S1, unofficial].
- **Bricks:** Sub-volumes of the original data used for out-of-core processing [S1, unofficial].
- **Ghost Cells:** Boundary cells surrounding each brick to handle interpolation across brick edges [S1, unofficial].

**Steps**
1. **Initialization:** Initialize $N$ adaptive grids (typically 16–32) with learnable transformation matrices [S1, unofficial].
2. **Domain Decomposition:** For volumes exceeding GPU memory, split the data into bricks. Process these bricks in parallel across multiple GPUs [S1, unofficial].
3. **Boundary Handling:** Apply ghost cells around each brick to mitigate boundary artifacts during interpolation and training [S1, unofficial].
4. **Training with Feature Density Loss:** Train the grids using a feature density loss. This loss function guides the learnable transformation matrices to concentrate capacity in regions with high reconstruction error [S1, unofficial].
5. **Reconstruction:** Use the trained grids and transformation matrices within a coordinate-based MLP to reconstruct the volume at any point [S1, unofficial].

**Edge Cases and Pitfalls**
- **Highly Sparse Data:** The method underperforms hash encodings on highly sparse data (e.g., Asteroid volume) where hash collision averaging is beneficial [S1, unofficial].
- **GPU Memory Limits:** Volumes exceeding GPU memory require domain decomposition; failure to implement ghost cells leads to boundary artifacts [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Training time scales with the number of bricks and GPUs. Average training time is 35 seconds per brick on 8 GPUs for large volumes [S1, unofficial].
- **Memory Complexity:** Model size is significantly smaller than the original volume. For a 250 GB volume, the model is 55 MB; for a 450 GB volume, the model is 97 MB [S1, unofficial].
- **Measured Performance:**
    - On a $4096^3$ Rotstrat volume (250 GB): 41.32 dB PSNR at 4791× compression with a 55 MB model [S1, unofficial].
    - On a Channel flow volume ($7680 \times 1568 \times 10240$, 450 GB): 40.06 dB PSNR with a 97 MB model [S1, unofficial].
- **Strengths:** High compression ratios for dense scientific volumes; efficient parallel processing via domain decomposition.
- **Limitations:** Poor performance on highly sparse data; requires careful handling of brick boundaries.
- **When to Use:** Dense scientific volumes where high compression is needed and data is not highly sparse.
- **When Not to Use:** Highly sparse volumes where hash encodings are more effective.

## Background
Adaptive Feature Grids, also known as APMGSRN, was introduced to address the inefficiency of fixed uniform grid placement in neural volume representations. It builds on the concept of hash grids but introduces spatial adaptivity through learnable transformation matrices and feature density loss. The method is particularly relevant for scientific volume data, where high-fidelity reconstruction at high compression ratios is essential.
