# Multi-Grid Merging

Also called: Merging Multiple Grids, Min Compositing

## Overview
Multi-Grid Merging combines two sparse hash grids into a single structure by taking the union of their active voxels [S1, unofficial]. It differs from [Replace Compositing](7905-multi-grid-merging.md) by resolving overlaps via an aggregation function rather than overwriting, preserving information from both inputs [S1, unofficial].

## How it works
**Inputs:**
*   Grid `a`: Source sparse hash grid [S1, unofficial].
*   Grid `b`: Source sparse hash grid [S1, unofficial].

**Outputs:**
*   `data`: A new sparse hash grid containing the merged result [S1, unofficial].

**Data Structures:**
*   `data`: A hash map or sparse array mapping voxel coordinates to values [S1, unofficial].

**Steps:**
1.  Copy all active voxels from grid `a` to `data` [S1, unofficial].
2.  Upsample the merged grid to double the resolution of the individual propagation grids to prevent undersampling due to arbitrary grid orientations [S2].
3.  Iterate active voxels from grid `b`. If coordinate `c` exists in `data`, update `data[c] = min(existing, v)`. Else, set `data[c] = v` [S1, unofficial].

**Formulas:**
*   `data[c] = min(existing, v)` for Min Compositing [S1, unofficial].
*   `data[c] = max(existing, v)` for Max Compositing [S1, unofficial].
*   `data[c] = existing + v` for Sum Compositing [S1, unofficial].
*   Where `c` is the voxel coordinate, `existing` is the value already stored at `c`, and `v` is the value from grid `b`.

**Parameters:**
*   `mode`: Determines the overlap resolution strategy (e.g., `"min"`, `"max"`, or `"sum"`) [S1, unofficial].

**Edge Cases and Pitfalls:**
*   Not given in the sources.

**Pseudocode:**
```python
def merge_grids(grid_a, grid_b, mode="min"):
    """
    Merges two sparse hash grids.
    
    Args:
        grid_a: Dict-like object mapping coordinates to values.
        grid_b: Dict-like object mapping coordinates to values.
        mode: String, one of "min", "max", "sum".
        
    Returns:
        data: Dict-like object representing the merged grid.
    """
    data = {}
    
    # Step 1: Copy all active voxels from grid a
    for c, v in grid_a.items():
        data[c] = v
        
    # Step 2: Upsample merged grid to double resolution to prevent undersampling [S2]
    # Implementation depends on specific upsampling kernel; omitted for brevity.
    
    # Step 3: Iterate active voxels from grid b
    for c, v in grid_b.items():
        if c in data:
            existing = data[c]
            if mode == "min":
                data[c] = min(existing, v)
            elif mode == "max":
                data[c] = max(existing, v)
            elif mode == "sum":
                data[c] = existing + v
        else:
            data[c] = v
            
    return data
```

## Subtopics

### [Multiply Compositing](8122-multiply-compositing.md)
Merges two sparse hash grids by taking the union of their active voxels, where overlapping values are multiplied together. It differs from [Replace Compositing](7905-multi-grid-merging.md) by preserving both contributions in overlapping regions rather than letting one overwrite the other.

### Max Compositing
Returns a new grid whose active voxels are the union of two grids, taking the maximum value at overlapping coordinates [S1, unofficial].

### Sum Compositing
Returns a new grid whose active voxels are the union of two grids, summing overlapping values [S1, unofficial].

### Grid Deformation with Entropy Coding
Compresses the data differences between registered adjacent data slices using entropy coding [S3, unofficial].

### Multi-Level Grid Coarsening
Generates multi-resolution grids by selecting vertices based on opacity [S4]. After 10,000 epochs, sampling points are randomly selected within each grid to calculate opacity, and the vertex of the grid with the highest opacity among eight grids is selected as the vertex of the merged grid [S4]. This generates grids of 64×64×64, 32×32×32, 16×16×16, and 8×8×8 sequentially [S4]. Each grid level is tailored for specific observation heights to minimize rendering cost [S4]. For the same block, different levels use the same network, but gradients in rough levels only update mesh vertex coordinates to prevent coarse-scale meshes from providing undue supervision to shared networks [S4].

## Background
Multi-grid merging is implemented in systems using hash grids, such as Lyr.jl [S1, unofficial]. The concept is also applied in neural radiance field rendering for large-scale scenes, where opacity-based selection is used for grid coarsening [S4].
