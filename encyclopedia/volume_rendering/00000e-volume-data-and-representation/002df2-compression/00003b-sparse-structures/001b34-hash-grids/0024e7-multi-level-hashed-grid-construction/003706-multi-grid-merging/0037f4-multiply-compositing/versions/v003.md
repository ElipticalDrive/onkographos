# Multiply Compositing
## Overview
Multiply Compositing merges two sparse hash grids by returning a new grid whose active voxels are the union of the inputs, with overlapping values multiplied together [S1, unofficial]. It differs from [Replace Compositing](7905-multi-grid-merging.md) by preserving both contributions in overlapping regions rather than letting one overwrite the other [S1, unofficial].
## How it works
**Inputs:** Two sparse hash grids, `a` and `b`, containing active voxels with associated values [S1, unofficial].
**Outputs:** A new sparse hash grid, `data`, containing the merged result [S1, unofficial].
**Data Structures:** The output `data` is a hash map (dictionary) mapping voxel coordinates `c` to their scalar values `v` [S1, unofficial].
**Steps:**
1. Initialize an empty hash map `data` [S1, unofficial].
2. Copy all active voxels from grid `a` to `data` [S1, unofficial]. For each active voxel in `a` with coordinate `c` and value `v`, set `data[c] = v` [S1, unofficial].
3. Iterate active voxels from grid `b` [S1, unofficial]. For each active voxel in `b` with coordinate `c` and value `v`: if `c` exists in `data`, update `data[c] = data[c] * v`; else, set `data[c] = v` [S1, unofficial].
**Formulas:** Not given in the sources [S1, unofficial].
**Parameters:** Not given in the sources [S1, unofficial].
**Edge Cases and Pitfalls:** Not given in the sources [S1, unofficial].
**Pseudocode:**
```python
def multiply_compositing(grid_a, grid_b):
    data = {}
    for c, v in grid_a.active_voxels():
        data[c] = v
    for c, v in grid_b.active_voxels():
        if c in data:
            data[c] = data[c] * v
        else:
            data[c] = v
    return data
```
## Subtopics

### Replace Compositing
Returns a new grid starting with `a`'s active voxels, then overwriting with `b`'s active voxels, so `b` stamps on top of `a` [S1, unofficial]. It is chosen when the second grid should completely dominate the first in overlapping regions [S1, unofficial]. The method copies all active voxels from grid `a` to `data`, iterates active voxels from grid `b` to set `data[c] = v`, and finally builds the grid using `build_grid(data, a.tree.background)` [S1, unofficial]. Exact parameters for the build step are not given in the sources [S1, unofficial].
