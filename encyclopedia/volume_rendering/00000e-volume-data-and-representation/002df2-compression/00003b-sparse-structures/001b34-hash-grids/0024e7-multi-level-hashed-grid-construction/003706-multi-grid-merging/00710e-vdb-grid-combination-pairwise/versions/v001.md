# VDB Grid Combination (Pairwise)

Also called: Flatten Combine, Grid Combine SOP, OpenVDB Grid Arithmetic & CSG, Pairwise Combine, SOP_OpenVDB_Combine Flatten, SOP_OpenVDB_Combine Pairwise, VDB Grid Combination & CSG/Blending Pipeline

## Overview
VDB Grid Combination (Pairwise) is a method for merging multiple OpenVDB grids into a single output grid by iteratively applying binary operations to pairs of grids. It solves the problem of combining sparse volumetric data from multiple sources (e.g., simulation outputs, noise fields, or CSG primitives) into a unified representation. Unlike [Multi-Grid Merging](7905-multi-grid-merging.md) which may handle complex tree structures or parallel reductions, this method strictly follows a linear, left-associative reduction pattern. It sets itself apart by explicitly handling transform alignment, background value consistency, and topology-only operations within a single iterative loop, making it suitable for SOP-based workflows where grids are combined sequentially.

## How it works
### Inputs and Outputs
**Inputs:**
- `aVdbVec`: A vector of input VDB objects (grids), denoted as $A_0, A_1, \dots, A_{N-1}$.
- `bVdbVec`: A vector of input VDB objects, denoted as $B_0, B_1, \dots, B_{M-1}$.
- `op`: The binary operation to perform (e.g., ADD, SUB, MUL, OP_BLEND1, OP_BLEND2, OP_TOPO_UNION).
- `resample`: Resampling mode enum (`RESAMPLE_OFF`, `RESAMPLE_LO_RES`, `RESAMPLE_HI_RES`).
- `samplingOrder`: The interpolation order for resampling.
- `prune`: Boolean flag to remove empty tiles/branches.
- `flood`: Boolean flag to propagate background values.
- `deactivate`: Boolean flag to deactivate inactive voxels based on tolerance.
- `amult`, `bmult`: Scalar multipliers for grids A and B, respectively.

**Outputs:**
- A single output VDB grid containing the result of the pairwise combination.

### Data Structures
- `GridBase::Ptr`: Pointer to an OpenVDB grid, containing a tree, transform, and metadata.
- `CoordBBox`: Bounding box in index space.
- `Vec3d`: 3D vector for voxel size and coordinates.
- `MetaMap`: Metadata map for grid attributes.

### Steps
1. **Initialization**:
   - If `aVdbVec` is empty, return null or error.
   - Initialize `aGrid` as the grid pointer from `aVdbVec[0]`.
   - Initialize `aGridName` as the name of `aVdbVec[0]`.
   - Initialize `needA` to `true` (indicates whether to preserve attributes from A).

2. **Iterative Combination**:
   - Iterate through each grid `bVdb` in `bVdbVec` (index $j$ from $0$ to $M-1$):
     - Retrieve `bGrid` from `bVdb`.
     - Retrieve `bGridName` from `bVdb`.
     - Call `combineGrids(op, aGrid, bGrid, aGridName, bGridName, resample, samplingOrder, amult, bmult, prune, flood, deactivate)` to produce `outGrid`.
     - Update `aGrid` to `outGrid`.
     - Update `aGridName` to `outGrid.getName()`.
     - Update `needA` to `false` (since the result now carries the combined state, and subsequent operations will treat the previous result as A).

3. **Final Output Construction**:
   - Create a new geometry primitive `GU_PrimVDB`.
   - Build the primitive from `aGrid` (the final accumulated grid).
   - Copy attributes from the original `aVdbVec[0]` if `needA` is true, otherwise from the last `bVdb` processed.
   - Set the primitive name to `aGridName`.

### combineGrids Function Details
The core logic for combining two grids `aGrid` and `bGrid` involves:

1. **Voxel Volume Calculation**:
   - Calculate voxel volume for A: $aVoxVol = aVoxSize[0] \times aVoxSize[1] \times aVoxSize[2]$.
   - Calculate voxel volume for B: $bVoxVol = bVoxSize[0] \times bVoxSize[1] \times bVoxSize[2]$.

2. **Resampling Decision**:
   - Determine `resampleWhich`:
     - If `resample == RESAMPLE_LO_RES` and $aVoxVol > bVoxVol$, set `resampleWhich = RESAMPLE_A`.
     - If `resample == RESAMPLE_HI_RES` and $aVoxVol < bVoxVol`, set `resampleWhich = RESAMPLE_A`.
     - Otherwise, set `resampleWhich = RESAMPLE_B`.

3. **Transform Alignment**:
   - If the constant transforms of `aGrid` and `bGrid` differ and `resample != RESAMPLE_OFF`:
     - If `resampleWhich == RESAMPLE_A`, resample `aGrid` into `bGrid`'s index space.
     - If `resampleWhich == RESAMPLE_B`, resample `bGrid` into `aGrid`'s index space.
     - Use `resampleToMatch(src, dst, samplingOrder)`.

4. **Multiplier Application**:
   - Evaluate `aMult` and `bMult`.
   - For binary operations, create a temporary grid `tempGrid` to avoid modifying input grids.
   - Apply multipliers:
     - `MulAdd<GridT>(aMult).process(aGrid, tempGrid)`
     - `MulAdd<GridT>(bMult).process(bGrid, tempGrid)` (or similar accumulation depending on op).

5. **Operation Execution**:
   - **Arithmetic/CSG**: Use OpenVDB's `combine2` tool with the appropriate functor.
   - **Blending (OP_BLEND1, OP_BLEND2)**:
     - Compute new background value using `Blend1` or `Blend2` functor.
     - Update result grid's background via `changeBackground`.
     - Call `combine2` with `prune=false`.
   - **Topology-Only (OP_TOPO_UNION, OP_TOPO_INTERSECTION, OP_TOPO_DIFFERENCE)**:
     - Scale only grid A.
     - Call the corresponding topology method on the result grid without scaling grid B.

6. **Post-Processing**:
   - If `prune` is true, remove empty tiles/branches.
   - If `flood` is true, propagate background values.
   - If `deactivate` is true, deactivate inactive voxels.

### Pseudocode
```python
def combine_vdb_grids(a_vdb_vec, b_vdb_vec, op, resample_mode, sampling_order, amult, bmult, prune, flood, deactivate):
    if not a_vdb_vec:
        return None
    
    # Initialize with the first grid from A
    a_grid = a_vdb_vec[0].get_grid_ptr()
    a_grid_name = a_vdb_vec[0].get_name()
    need_a = True
    
    # Iterate over B grids
    for b_vdb in b_vdb_vec:
        b_grid = b_vdb.get_const_grid_ptr()
        b_grid_name = b_vdb.get_name()
        
        # Combine A and B
        out_grid = combine_grids(
            op=op,
            a_grid=a_grid,
            b_grid=b_grid,
            a_grid_name=a_grid_name,
            b_grid_name=b_grid_name,
            resample_mode=resample_mode,
            sampling_order=sampling_order,
            amult=amult,
            bmult=bmult,
            prune=prune,
            flood=flood,
            deactivate=deactivate
        )
        
        # Update A for next iteration
        a_grid = out_grid
        a_grid_name = out_grid.get_name()
        need_a = False  # Result now carries combined state
    
    # Build output primitive
    output_prim = GU_PrimVDB.build_from_grid(
        gdp,
        a_grid,
        copy_attrs_from=a_vdb_vec[0] if need_a else b_vdb_vec[-1],
        name=a_grid_name
    )
    
    return output_prim

def combine_grids(op, a_grid, b_grid, a_grid_name, b_grid_name, resample_mode, sampling_order, amult, bmult, prune, flood, deactivate):
    # Get voxel sizes
    a_vox_size = a_grid.transform().voxel_size()
    b_vox_size = b_grid.transform().voxel_size()
    
    # Calculate voxel volumes
    a_vox_vol = a_vox_size[0] * a_vox_size[1] * a_vox_size[2]
    b_vox_vol = b_vox_size[0] * b_vox_size[1] * b_vox_size[2]
    
    # Determine resampling target
    resample_which = RESAMPLE_B
    if resample_mode == RESAMPLE_LO_RES and a_vox_vol > b_vox_vol:
        resample_which = RESAMPLE_A
    elif resample_mode == RESAMPLE_HI_RES and a_vox_vol < b_vox_vol:
        resample_which = RESAMPLE_A
    
    # Align transforms
    if a_grid.transform() != b_grid.transform() and resample_mode != RESAMPLE_OFF:
        if resample_which == RESAMPLE_A:
            # Resample A into B's space
            src_grid = a_grid.copy_grid_replacing_transform(b_grid.transform())
            dst_grid = b_grid
            resample_to_match(src_grid, dst_grid, sampling_order)
            a_grid = dst_grid
        else:
            # Resample B into A's space
            src_grid = b_grid.copy_grid_replacing_transform(a_grid.transform())
            dst_grid = a_grid
            resample_to_match(src_grid, dst_grid, sampling_order)
            b_grid = dst_grid
    
    # Apply multipliers
    temp_grid = a_grid.deep_copy_grid()
    mul_add_a = MulAdd(temp_grid.value_type())
    mul_add_a.set_multiplier(amult)
    mul_add_a.process(a_grid, temp_grid)
    
    temp_grid_b = b_grid.deep_copy_grid()
    mul_add_b = MulAdd(temp_grid_b.value_type())
    mul_add_b.set_multiplier(bmult)
    mul_add_b.process(b_grid, temp_grid_b)
    
    # Perform operation
    if op in [OP_BLEND1, OP_BLEND2]:
        # Blending logic
        if op == OP_BLEND1:
            # (1 - A) * B
            blend_functor = Blend1()
        else:
            # A + (1 - A) * B
            blend_functor = Blend2()
        
        new_bg = blend_functor(a_grid.background(), b_grid.background())
        result_grid = temp_grid.deep_copy_grid()
        result_grid.change_background(new_bg)
        combine2(result_grid, temp_grid_b, prune=False)
    elif op in [OP_TOPO_UNION, OP_TOPO_INTERSECTION, OP_TOPO_DIFFERENCE]:
        # Topology-only logic
        result_grid = temp_grid.deep_copy_grid()
        if op == OP_TOPO_UNION:
            result_grid.topology_union(temp_grid_b)
        elif op == OP_TOPO_INTERSECTION:
            result_grid.topology_intersection(temp_grid_b)
        elif op == OP_TOPO_DIFFERENCE:
            result_grid.topology_difference(temp_grid_b)
    else:
        # Arithmetic/CSG logic
        result_grid = combine_arithmetic(temp_grid, temp_grid_b, op)
    
    # Post-processing
    if prune:
        result_grid.prune()
    if flood:
        result_grid.flood()
    if deactivate:
        result_grid.deactivate(deactivate_tolerance)
        
    return result_grid
```

### Parameters
- `prune`: Boolean. Default: `true`. Controls removal of empty tiles/branches.
- `flood`: Boolean. Default: `false`. Controls propagation of background values.
- `deactivate`: Boolean. Default: `false`. Controls deactivation of inactive voxels.
- `resample`: Enum. `RESAMPLE_OFF`, `RESAMPLE_LO_RES`, `RESAMPLE_HI_RES`. Default: `RESAMPLE_OFF`.
- `amult`, `bmult`: Float. Default: `1.0`. Scalar multipliers.

### Edge Cases and Pitfalls
- **Level Set Background Mismatch**: If both grids are level sets (`GRID_LEVEL_SET`) and their background values differ, the output grid will not be a valid level set. The algorithm handles this by resampling/rebuilding one grid to match the other's background value, or logging a warning if `resample == RESAMPLE_OFF` [S1, unofficial].
- **Transform Divergence**: If transforms differ and `resample == RESAMPLE_OFF`, the grids are combined in their respective index spaces, which may lead to misaligned data if not intended.
- **Empty Input**: If `aVdbVec` is empty, the method should return null or error.

## Operating characteristics
- **Time Complexity**: $O(N \times V)$, where $N$ is the number of grids in `bVdbVec` and $V$ is the number of active voxels in the combined grid. Resampling adds overhead proportional to the volume of the grid being resampled.
- **Memory Complexity**: $O(V)$, where $V$ is the number of active voxels in the output grid. Temporary grids are created during combination, doubling memory usage temporarily.
- **Strengths**: Simple iterative logic, handles transform alignment automatically, supports various operations (arithmetic, blending, topology).
- **Limitations**: Linear reduction may be slow for large numbers of grids. Resampling can be expensive. Level set background mismatch requires careful handling.
- **When to Use**: When combining a small to moderate number of grids with potentially different transforms. When blending or topology operations are needed.
- **When Not to Use**: When combining a very large number of grids (consider parallel reduction). When grids are already aligned and no resampling is needed (use simpler addition).

## Background
VDB Grid Combination (Pairwise) is part of the OpenVDB library ecosystem, specifically implemented in the NVIDIA-Omniverse extension for Houdini SOPs. It is designed to provide a flexible way to combine VDB grids in a node-based workflow. The method is inspired by the need to handle complex volumetric operations in visual effects and simulation pipelines.
