# Empty Space Caching with Bit Vector E

Also called: Empty block skipping

## Overview
Empty Space Caching with Bit Vector E is a fine-granular empty space skipping mechanism that reduces memory usage and lookup latency by marking regions of invisible data [S1]. It complements the parent method, [Adapted Cuckoo Hashing for Voxel Labels](10183-adapted-cuckoo-hashing-for-voxel-labels.md), by introducing a compact bit vector $E$ that allows the renderer to skip hash table lookups for entire blocks of voxels known to be invisible [S1]. While the parent hash table $M$ stores explicit labels for cached voxels, $E$ provides a 1-bit-per-8-voxel summary, reducing the storage cost for fully invisible regions from 64 bits per voxel in $M$ to 1/8 bits per voxel in $E$ [S1].

## How it works
**Inputs and Outputs**
*   **Input:** Voxel coordinate $v$ (in finest LOD), level of detail $l$, visibility transfer function [S1].
*   **Output:** Label $\lambda$ or `INVISIBLE` [S1].

**Data Structures**
*   **Bit Vector $E$:** A bit array where each bit corresponds to an "empty block" of $2^3 = 8$ voxels on the finest LOD [S1].
    *   Size: $N_{blocks} = \lceil N_{voxels} / 8 \rceil$ bits.
    *   Layout: $E[e] = 1$ if all 8 voxels in block $e$ have invisible labels; $E[e] = 0$ otherwise [S1].
    *   Initialization: All zeros $(000...000)_2$. Reset whenever the visibility transfer function changes [S1].
*   **Hash Table $M$:** Provided by the parent method [Adapted Cuckoo Hashing for Voxel Labels](10183-adapted-cuckoo-hashing-for-voxel-labels.md). Stores pairs $(k, \lambda)$ [S1].

**Parameters**
*   **Empty Block Size:** $2^3$ voxels (8 voxels) [S1].
*   **Brick Size $b$:** Used for coarse skipping (from parent context/CSGV) [S1].

**Algorithm Steps**
The voxel access method integrates brick skipping, empty block checking, hash lookup, and dynamic caching [S1]:

1.  **Brick Skipping:** Check if voxel $v$ belongs to a brick marked as invisible. If so, return `INVISIBLE` [S1].
2.  **Empty Block Check:** Calculate the empty block index $e$ for voxel $v$. If $E[e] == 1$, return `INVISIBLE` [S1].
3.  **Hash Lookup:** Compute hash positions $p_1 \leftarrow h_1(v, l)$ and $p_2 \leftarrow h_2(k, p_1)$ in $M$ [S1]. Retrieve $(k_1, \lambda_1) \leftarrow M[p_1]$ and $(k_2, \lambda_2) \leftarrow M[p_2]$ [S1]. If $k_1 = k$, return $\lambda_1$ [S1]. If $k_2 = k \mid 0x80000000$, return $\lambda_2$ [S1].
4.  **Decode and Verify:** If hash miss, decode label $\lambda \leftarrow \text{decodeLabel}(v, l)$ [S1]. If $\lambda$ is visible, cache $(k, \lambda)$ in $M[p_1]$ and return $\lambda$ [S1]. If $\lambda$ is invisible, check all 8 voxels $v'$ in empty block $e$ at finest LOD ($l=0$) [S1]. If any $v'$ has a visible label, set `allInvisible = False` [S1]. If `allInvisible` is True, set $E[e] \leftarrow 1$ and return `INVISIBLE` [S1]. Otherwise, cache $(k, \lambda)$ in $M[p_1]$ and return `INVISIBLE` [S1].

**Pseudocode**
```python
def get_label_of_voxel(v, l, E, M, brick_invisible_map, decode_label, label_visible, h1, h2, grid_dims, brick_size):
    # 1. Brick Skipping
    brick_idx = tuple(v[i] // brick_size for i in range(3))
    if brick_invisible_map[brick_idx]:
        return INVISIBLE

    # 2. Empty Block Check
    e = (v[0] // 2) * (grid_dims[1] // 2) + (v[1] // 2) * (grid_dims[2] // 2) + (v[2] // 2)
    if E[e] == 1:
        return INVISIBLE

    # 3. Hash Lookup
    k = hash_key(v, l) & 0x7FFFFFFF
    p1 = h1(v, l)
    k1, lambda1 = M[p1]
    if k1 == k:
        return lambda1

    p2 = h2(k, p1)
    k2, lambda2 = M[p2]
    if k2 == (k | 0x80000000):
        return lambda2

    # 4. Decode and Verify
    lambda_decoded = decode_label(v, l)

    if not label_visible(lambda_decoded):
        all_invisible = True
        base_v = [v[i] & ~1 for i in range(3)]
        for dx in (0, 1):
            for dy in (0, 1):
                for dz in (0, 1):
                    v_prime = (base_v[0] + dx, base_v[1] + dy, base_v[2] + dz)
                    if label_visible(decode_label(v_prime, 0)):
                        all_invisible = False
                        break
                if not all_invisible:
                    break
            if not all_invisible:
                break

        if all_invisible:
            E[e] = 1
            return INVISIBLE
        else:
            M[p1] = (k, lambda_decoded)
            return INVISIBLE
    else:
        M[p1] = (k, lambda_decoded)
        return lambda_decoded
```

**Edge Cases and Pitfalls**
*   **Partially Visible Blocks:** If an empty block contains both visible and invisible voxels, $E[e]$ remains 0. All voxels in such a block must be decoded and cached in $M$ individually. The bit vector $E$ only marks *fully* invisible blocks [S1].
*   **Transfer Function Changes:** $E$ must be reset to all zeros whenever the visibility transfer function changes, as the invisibility status of voxels may change [S1].
*   **Atomicity:** Insertions into $E$ and $M$ should be atomic if accessed in parallel [S1].

## Operating characteristics
*   **Memory:** $E$ uses 1 bit per 8 voxels for invisible regions. $M$ uses 64 bits per voxel (32 for $\lambda$, 32 for $k$) for cached voxels. $E$ provides significant memory savings for large invisible regions [S1].
*   **Performance:** Reduces hash table lookups for invisible voxels by checking $E$ first. Partially visible blocks require full decoding and caching, potentially increasing workload for those regions [S1].

## Background
This method is part of the CSGV-R (Compressed Segmentation Volume Random Access) framework for interactive volume rendering [S1]. It builds on the CSGV brick skipping mechanism and the Adapted Cuckoo Hashing for Voxel Labels method [S1]. The approach was introduced to address the insufficiency of brick-level skipping alone, providing a finer granularity for empty space optimization [S1].
