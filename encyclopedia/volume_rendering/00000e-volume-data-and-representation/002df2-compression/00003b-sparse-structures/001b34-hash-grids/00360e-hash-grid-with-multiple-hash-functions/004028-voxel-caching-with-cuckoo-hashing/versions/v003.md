# Voxel Caching with Cuckoo Hashing

Also called: CSGV-R Cuckoo Caching, Voxel Cache

## Overview
An optional voxel cache using Cuckoo hashing to store labels $\lambda$ for tuples of voxel coordinates $v \in \mathbb{N}^3$ and requested LODs $l$, allowing direct access without one-frame latency [S1]. It differs from its parent [Hash Grid with Multiple Hash Functions](7678-hash-grid-with-multiple-hash-functions.md) by using a single combined table with a compact 32-bit key and specific rounding to handle multi-resolution queries, and from its sibling [Adapted Cuckoo Hashing for Voxel Labels](10183-adapted-cuckoo-hashing-for-voxel-labels.md) by its specific 4D tuple handling and PCG hash integration [S1].

## How it works
**Inputs:** Voxel coordinates $v \in \mathbb{N}^3$ (in finest resolution), requested LOD $l$, and label $\lambda$ [S1].
**Outputs:** Hash table $M$ containing entries $(\lambda, k)$ [S1].

**Data Structures:**
*   $M$: A single array of size $|M|$ (power of two) storing a label $\lambda$ and a 32-bit key $k$ at each position [S1].
*   The table $M$ conceptually holds two hash tables $M_1$ and $M_2$ of size $|M|/2$ each, packed contiguously [S1].

**Hash Functions:**
The method uses the PCG family [O'N14, JO20] instead of the universal family [PR04] for 3D/4D tuples [S1].
1.  **Base Hash $h^a(x)$:**
    $$h^a(x) = (ax \bmod 2^{32}) / 2^{32-m}$$
    where $a$ is an odd number and $m$ is the MSB of the power-of-two hash table size [S1].
2.  **Coordinate Rounding:**
    Voxels are rounded to powers-of-two to force collisions for different LODs in the same spatial region:
    $$\mathbf{s} = \lfloor v/2^l \rfloor \cdot 2^l$$
    This ensures different LODs of a region are never accessed simultaneously [S1].
3.  **Key Hash $h_k(\mathbf{v}, l)$:**
    Computes a 32-bit key $k$ to identify collisions [S1]. Let $\mathbf{t} = pcg4d(\mathbf{s}, l)$ be a 4D vector hash [S1].
    $$k = h^5(\mathbf{t}, x) \oplus h^{149}(\mathbf{t}, y) \oplus h^{61}(\mathbf{t}, z) \oplus h^{2877}(\mathbf{t}, w)$$
    where $\oplus$ is bitwise XOR [S1].
4.  **First Position Hash $h_1(\mathbf{v}, l)$:**
    Computes the index in $M$. Let $\mathbf{s} = pcg3d(\lfloor v/2^l \rfloor \cdot 2^l)$ [S1].
    $$h_1(\mathbf{v}, l) = h^{19}(\mathbf{s}, x) \oplus h^{47}(\mathbf{s}, y) \oplus h^{101}(\mathbf{s}, z) \bmod |M|$$
    [S1].

**Algorithm:**
*   **Lookup:** Constant time. Check $M[h_1(\mathbf{v}, l)]$ and $M[u]$ where $u$ is the alternative position [S1].
*   **Insertion:**
    1.  Compute $p_1 = h_1(\mathbf{v}, l)$ [S1].
    2.  If $M[p_1]$ is empty, store $(\lambda, k)$ and set MSB of $k$ to 0 [S1].
    3.  If occupied by $k'$, check if $k' == k$ (collision) [S1]. If so, update $\lambda$ [S1].
    4.  If occupied by different $k'$, evict $k'$ [S1]. Store new $(\lambda, k)$ with MSB 0 [S1].
    5.  Move evicted $k'$ to its second position $p_2$ [S1]. The alternative position is determined with $u = pcg2d(h_k(\mathbf{v}, l), h_1(\mathbf{v}, l))$ [S1].
    6.  If $M[p_2]$ is empty, store $k'$ with MSB 1 [S1].
    7.  If occupied, recursively evict and swap until an empty slot is found, a loop depth limit is reached, or a cycle is detected [S1].

**Pseudocode:**
```python
def h_a(a, x_val, table_size):
    m = table_size.bit_length() - 1
    val = (a * x_val) & 0xFFFFFFFF
    return val >> (32 - m)

def pcg3d_hash(v):
    # Standard PCG 3D hash function [G]
    return (v[0] ^ 0x9E3779B9, v[1] ^ 0x9E3779B9, v[2] ^ 0x9E3779B9)

def pcg4d_hash(v, l):
    # Standard PCG 4D hash function [G]
    return (v[0] ^ 0x9E3779B9, v[1] ^ 0x9E3779B9, v[2] ^ 0x9E3779B9, l ^ 0x9E3779B9)

def pcg2d_hash(k1, k2):
    # Standard PCG 2D hash function [G]
    return (k1 ^ 0x9E3779B9) ^ (k2 ^ 0x9E3779B9)

def lookup(M, v, l, table_size):
    s = (v[0] // (1 << l)) * (1 << l), (v[1] // (1 << l)) * (1 << l), (v[2] // (1 << l)) * (1 << l)
    s_3d = pcg3d_hash(s)
    p1 = (h_a(19, s_3d[0], table_size) ^ h_a(47, s_3d[1], table_size) ^ h_a(101, s_3d[2], table_size)) % table_size
    t = pcg4d_hash(s, l)
    k = (h_a(5, t[0], table_size) ^ h_a(149, t[1], table_size) ^ h_a(61, t[2], table_size) ^ h_a(2877, t[3], table_size)) & 0xFFFFFFFF
    p2 = pcg2d_hash(k, p1)
    if M[p1].key == k:
        return M[p1].label
    if M[p2].key == k:
        return M[p2].label
    return None

def insert(M, v, l, lambda_val, table_size, max_steps=64):
    s = (v[0] // (1 << l)) * (1 << l), (v[1] // (1 << l)) * (1 << l), (v[2] // (1 << l)) * (1 << l)
    s_3d = pcg3d_hash(s)
    p1 = (h_a(19, s_3d[0], table_size) ^ h_a(47, s_3d[1], table_size) ^ h_a(101, s_3d[2], table_size)) % table_size
    t = pcg4d_hash(s, l)
    k = (h_a(5, t[0], table_size) ^ h_a(149, t[1], table_size) ^ h_a(61, t[2], table_size) ^ h_a(2877, t[3], table_size)) & 0xFFFFFFFF
    p2 = pcg2d_hash(k, p1)

    current_k = k
    current_label = lambda_val
    current_msb = 0
    visited = set()

    for step in range(max_steps):
        if current_k in visited:
            return False # Cycle detected
        visited.add(current_k)

        alt_pos = p2 if current_msb == 0 else p1
        if M[alt_pos].key is None:
            M[alt_pos].key = current_k
            M[alt_pos].label = current_label
            M[alt_pos].msb = current_msb
            return True

        evicted_k = M[alt_pos].key
        evicted_label = M[alt_pos].label
        evicted_msb = M[alt_pos].msb

        if evicted_k == current_k:
            M[alt_pos].label = current_label
            return True

        M[alt_pos].key = current_k
        M[alt_pos].label = current_label
        M[alt_pos].msb = current_msb

        current_k = evicted_k
        current_label = evicted_label
        current_msb = evicted_msb

    return False
```

**Edge Cases:**
*   **Cycle Detection:** If an element is inserted into a position it occupied before, stop and report failure [S1].
*   **Loop Depth Limit:** Stop if a predetermined number of swaps is reached [S1].
*   **Precision:** Use 32-bit arithmetic for hash components [S1].

## Operating characteristics
*   **Time Complexity:** Lookup is constant time $O(1)$ [S1]. Insertion is amortized constant time but can degrade with high load factors or cycles [S1].
*   **Memory:** Single table $M$ stores label and 32-bit key per entry [S1].
*   **Strengths:** Direct access without one-frame latency; handles multi-resolution queries via rounding [S1].
*   **Limitations:** Requires careful handling of cycles and eviction limits; PCG hash implementation required [S1].

## Background
The voxel cache using Cuckoo hashing is an optional component introduced for CSGV-R to avoid one-frame latency when operating completely in the compression domain is slow [S1]. Based on Cuckoo hashing [PR04] and PCG hash functions [O'N14, JO20] [S1]. Used to cache decoded voxel labels for fast access during rendering [S1].
