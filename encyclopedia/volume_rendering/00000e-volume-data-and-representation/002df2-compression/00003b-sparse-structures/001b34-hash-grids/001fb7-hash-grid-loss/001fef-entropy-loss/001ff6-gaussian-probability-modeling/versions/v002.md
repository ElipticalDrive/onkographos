# Gaussian Probability Modeling

Also called: Context model Gaussian modeling

## Overview
Gaussian Probability Modeling estimates bit consumption for quantized anchor attributes in sparse volume representations by fitting them to Gaussian distributions [S1, unofficial]. It differs from uniform or discrete entropy models by leveraging the Gaussian-like distribution of neural network features, allowing a context network to output adaptive mean and variance parameters for each attribute component [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Quantized anchor attributes $\hat{\mathbf{f}}_i$ for $i=1 \dots N^{\text{at}}$, where $N^{\text{at}}$ is the number of anchors [S1, unofficial].
*   **Output:** Probability density estimates $p(\hat{\mathbf{f}}_i)$ derived from Gaussian parameters [S1, unofficial].

**Data Structures:**
The context model outputs three scalar values per attribute component $i$:
1.  Refinement factor $r_i$ to adaptively adjust the predefined quantization step $Q$ [S1, unofficial].
2.  Mean $\mu_i$
3.  Variance $\sigma_i$

**Steps:**
1.  **Quantization:** Original anchor attributes are quantized using a predefined step $Q$ [S1, unofficial]. The quantization step $Q$ varies by component due to different numerical scales, empirically set to $1$ for $\mathbf{f}_a$, $0.001$ for $\mathbf{l}_s$ and $\mathbf{l}_r$, and $0.2$ for $\Delta \mathbf{x}_g$ [S1, unofficial]. During training, the quantized attribute $\hat{\mathbf{f}}_i$ substitutes the original to achieve quantization-aware training [S1, unofficial].
2.  **Parameter Generation:** The context model processes the data to output the refinement factor $r_i$, mean $\mu_i$, and variance $\sigma_i$ for each quantized attribute $\hat{\mathbf{f}}_i$ [S1, unofficial].
3.  **Probability Estimation:** The probability $p(\hat{\mathbf{f}}_i)$ is formulated using the Gaussian distribution $\mathcal{N}(\mu_i, \sigma_i)$ [S1, unofficial].
4.  **Entropy Loss Calculation:** The total entropy loss is computed as the sum of negative log-probabilities:
    $$L_{\text{entropy}} = \sum_{\mathbf{f} \in \{\mathbf{A}\}} \sum_{i=1}^{N^{\text{at}}} \left( -\log_2 p(\hat{\mathbf{f}}_i) \right)$$
    where $\mathbf{A}$ represents the set of attributes and $N^{\text{at}}$ is the number of anchors [S1, unofficial].

**Pseudocode:**
```python
import math

def gaussian_probability_modeling(attributes, context_model, quantization_steps):
    """
    Computes entropy loss by modeling quantized attributes as Gaussian distributions.
    """
    total_loss = 0.0
    num_anchors = len(attributes)
    log2 = math.log(2)

    for i in range(num_anchors):
        attr = attributes[i]
        Q = quantization_steps.get(i, 1.0)
        
        # Quantize: round to nearest multiple of Q
        quantized_attr = round(attr / Q) * Q

        # Get parameters from context model
        # Returns: refinement_factor, mean, variance
        _, mu_i, sigma_i = context_model(quantized_attr)
        
        # Guard against zero variance [G]
        sigma_i = max(sigma_i, 1e-9)

        # Gaussian log-PDF: log(p) = -0.5*log(2*pi*sigma^2) - 0.5*((x-mu)/sigma)^2
        log_p = -0.5 * math.log(2 * math.pi * sigma_i**2) - \
                0.5 * ((quantized_attr - mu_i) / sigma_i)**2

        # Entropy loss component: -log2(p)
        loss_component = -log_p / log2
        total_loss += loss_component

    return total_loss
```

**Edge Cases and Pitfalls:**
*   **Variance Zero:** If $\sigma_i$ approaches zero, numerical instability occurs in the log-probability calculation. A small epsilon should be added to $\sigma_i$ [G].
*   **Quantization Step Selection:** The sources specify fixed empirical $Q$ values per component rather than a general selection rule [S1, unofficial].

## Subtopics

### Quantized Gaussian Sampling
A 3D normal distribution quantized to integer coordinates to provide a prior about where the output is expected and where the loss is defined, centered at the middle of the voxel grid [S2]. It is used to guide training by sampling loss according to these quantized coordinates, effectively masking out non-empty voxels with low density that are not visible in rendering [S2].

## Operating characteristics
*   **Computational Cost:** The method iterates over all anchors and attributes to compute Gaussian parameters and log-probabilities [S1, unofficial].
*   **Performance:** Enables efficient compression by adapting the probability model to the specific statistical properties of each attribute component [S1, unofficial].
*   **Limitations:** Requires a context model capable of accurately predicting mean and variance; performance depends heavily on correct quantization step selection [S1, unofficial].

## Background
The method is used within entropy loss calculations for sparse volume representations, specifically in compressive neural Gaussian splats for volume visualization [S1, unofficial]. It addresses the need for efficient entropy coding of sparse 3D representations by leveraging the Gaussian nature of quantized features [S1, unofficial].
