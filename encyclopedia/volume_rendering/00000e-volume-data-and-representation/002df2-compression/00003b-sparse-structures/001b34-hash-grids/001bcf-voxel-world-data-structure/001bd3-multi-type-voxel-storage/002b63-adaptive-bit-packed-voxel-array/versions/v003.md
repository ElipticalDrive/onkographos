# Adaptive Bit-Packed Voxel Array

Also called: SectionStorage, SectionStorage Adaptive Bit-Packed Voxel Array, Voxel Section

## Overview
The Adaptive Bit-Packed Voxel Array is a storage structure for a fixed-size 16×16×16 voxel section (4096 voxels) that dynamically adjusts its memory layout based on the number of unique voxel IDs present [S1, unofficial]. It supports Empty, Uniform, and Palette states to optimize memory usage for homogeneous or sparse sections [S1, unofficial]. Unlike [Typed Voxels](1399-typed-voxels.md), which may use fixed-size arrays or more complex sparse structures, this method uses a single palette and bit-packed indices, allowing it to collapse to zero heap memory for empty or uniform data [S1, unofficial].

## How it works
### Inputs and Outputs
- **Input**: A sequence of voxel updates `(position, id)` or a bulk array of 4096 `VoxelId`s [S1, unofficial].
- **Output**: A `SectionStorage` object that resolves to `VoxelId` values at any local position, or an iterator over all 4096 voxels [S1, unofficial].

### Data Structures
The structure uses a `Representation` enum (mapped to `StorageKind`) to manage state:

1.  **Empty**: No heap memory. Represents all voxels as `VoxelId::AIR` [S1, unofficial].
2.  **Uniform**: Stores a single `VoxelId` inline. No heap memory [S1, unofficial].
3.  **Palette**: Stores a `Palette` struct on the heap [S1, unofficial].
    -   `entries`: `Vec<PaletteEntry>`. Each contains `id: VoxelId` and `count: u16` (number of voxels referencing this entry, enabling uniform/empty collapse checks without scanning all 4096 voxels) [S1, unofficial].
    -   `words`: `Vec<u64>`. Bit-packed indices [S1, unofficial].
    -   `bits`: `u8`. Bits per index (1 to 12) [S1, unofficial].

Memory accounting fields include `inline_bytes`, `heap_used_bytes`, `heap_capacity_bytes`, `palette_entries`, and `bits_per_index` [S1, unofficial].

### Parameters
-   `SECTION_VOLUME`: 4096 (total voxels) [S1, unofficial].
-   `SECTION_EDGE`: 16 (side length) [S1, unofficial].
-   `bits_per_index`: Capped at 12 bits, supporting up to $2^{12} = 4096$ unique IDs [S1, unofficial].

### Numbered Steps

1.  **Initialization**:
    -   `SectionStorage::default()` creates an `Empty` section with 0 heap capacity [S1, unofficial].
    -   `SectionStorage::filled(id)` creates a `Uniform` section if `id != AIR`, or `Empty` if `id == AIR`, using 0 heap capacity [S1, unofficial].

2.  **Bulk Construction (`from_voxels`)**:
    -   If all 4096 voxels are identical, return `Uniform` or `Empty` [S1, unofficial].
    -   Otherwise, scan all voxels to build a `Palette`:
        -   Count occurrences of each `VoxelId` [S1, unofficial].
        -   Assign a slot index (0 to N-1) to each unique ID [S1, unofficial].
        -   Calculate `bits = ceil(log2(N))` [S1, unofficial].
        -   Allocate `words` vector of size `ceil(4096 * bits / 64)` [S1, unofficial].
        -   Write indices into `words` using bit-packing [S1, unofficial].

3.  **Single Update (`set`)**:
    -   Calculate `index = position.x + position.y * 16 + position.z * 256` [G].
    -   If `Representation` is `Empty` or `Uniform`:
        -   If the new `id` matches the current value, return `false` (no change) [S1, unofficial].
        -   If `id` is `AIR` and current is `Uniform`, switch to `Empty` [S1, unofficial].
        -   Otherwise, transition to `Palette` with the current `id` and new `id` as the two entries, set `bits = 1`, and write the new index [S1, unofficial].
    -   If `Representation` is `Palette`:
        -   Read current slot: `old_slot = read_index(words, bits, index)` [S1, unofficial].
        -   If `palette.entries[old_slot].id == id`, return `false` [S1, unofficial].
        -   If `palette.entries[old_slot].count == 1`:
            -   Replace `palette.entries[old_slot].id` with `id` in place [S1, unofficial].
            -   Return `true` [S1, unofficial].
        -   Else, check if `id` exists in `palette.entries`:
            -   If yes, update `count` for old slot (decrement) and new slot (increment) [S1, unofficial].
            -   If no, check for a dead slot (`count == 0`) to reuse without repacking [S1, unofficial].
            -   If a dead slot exists, reuse it; otherwise, add `id` to `palette.entries` [S1, unofficial].
            -   Update counts, write the new index, and if the palette crosses a bit-width boundary, trigger repacking (increase `bits`, resize `words`, rewrite all indices) [S1, unofficial].
        -   Return `true` [S1, unofficial].

4.  **Batch Update (`set_batch`)**:
    -   Apply `set` for each `(position, id)` in the list [S1, unofficial].
    -   Return the count of voxels that actually changed value [S1, unofficial].

5.  **Compaction (`compact`)**:
    -   Scan `palette.entries` to find entries with `count > 0` (live entries) [S1, unofficial].
    -   Remove entries with `count == 0` (dead slots) [S1, unofficial].
    -   Rebuild the palette mapping:
        -   Create a new `entries` vector with only live entries [S1, unofficial].
        -   Calculate new `bits = ceil(log2(live_count))` [S1, unofficial].
        -   If `bits < old_bits`, resize `words` and rewrite indices [S1, unofficial].
        -   If `bits == old_bits`, rewrite indices to reflect new slot positions [S1, unofficial].
    -   Return `true` if changes were made [S1, unofficial].

6.  **Iteration (`iter` / `copy_voxels`)**:
    -   For each index `i` from 0 to 4095:
        -   `slot = read_index(words, bits, i)` [S1, unofficial].
        -   `id = palette.entries[slot].id` [S1, unofficial].
        -   Yield `id` [S1, unofficial].

### Pseudocode

```python
SECTION_VOLUME = 4096
SECTION_EDGE = 16
MAX_BITS = 12

def index_bits(n_unique):
    if n_unique <= 1: return 1
    bits = 1
    while (1 << bits) < n_unique:
        bits += 1
    return min(bits, MAX_BITS)

def word_count(bits):
    return (SECTION_VOLUME * bits + 63) // 64

def read_index(words, bits, index):
    bit_offset = index * bits
    word_idx = bit_offset // 64
    bit_in_word = bit_offset % 64
    val = words[word_idx] >> bit_in_word
    if bit_in_word + bits > 64:
        val |= words[word_idx + 1] << (64 - bit_in_word)
    return val & ((1 << bits) - 1)

def write_index(words, bits, index, slot):
    bit_offset = index * bits
    word_idx = bit_offset // 64
    bit_in_word = bit_offset % 64
    mask = (1 << bits) - 1
    words[word_idx] &= ~(mask << bit_in_word)
    words[word_idx] |= (slot & mask) << bit_in_word
    if bit_in_word + bits > 64:
        words[word_idx + 1] &= ~(mask >> (64 - bit_in_word))
        words[word_idx + 1] |= (slot & mask) << (64 - bit_in_word)

class SectionStorage:
    def __init__(self):
        self.data = None  # None, ("Uniform", id), or ("Palette", entries, words, bits)

    @staticmethod
    def default():
        return SectionStorage.filled(0)  # 0 represents AIR

    @staticmethod
    def filled(id):
        s = SectionStorage()
        s.data = ("Uniform", id) if id != 0 else None
        return s

    def set(self, position, id):
        index = position[0] + position[1] * SECTION_EDGE + position[2] * SECTION_EDGE * SECTION_EDGE
        if self.data is None:  # Empty
            if id == 0: return False
            entries = [{"id": 0, "count": SECTION_VOLUME - 1}, {"id": id, "count": 1}]
            words = [0] * word_count(1)
            write_index(words, 1, index, 1)
            self.data = ("Palette", entries, words, 1)
            return True
        elif self.data[0] == "Uniform":
            current_id = self.data[1]
            if current_id == id: return False
            if id == 0:
                self.data = None
                return True
            entries = [{"id": current_id, "count": SECTION_VOLUME - 1}, {"id": id, "count": 1}]
            words = [0] * word_count(1)
            write_index(words, 1, index, 1)
            self.data = ("Palette", entries, words, 1)
            return True
        else:  # Palette
            entries, words, bits = self.data[1], self.data[2], self.data[3]
            old_slot = read_index(words, bits, index)
            old_id = entries[old_slot]["id"]
            if old_id == id: return False
            new_slot = next((i for i, e in enumerate(entries) if e["id"] == id), None)
            if new_slot is not None:
                entries[old_slot]["count"] -= 1
                entries[new_slot]["count"] += 1
                write_index(words, bits, index, new_slot)
                return True
            # Dead slot reuse or append
            dead_slot = next((i for i, e in enumerate(entries) if e["count"] == 0), None)
            if dead_slot is not None:
                new_slot = dead_slot
                entries[new_slot]["id"] = id
                entries[new_slot]["count"] = 1
            else:
                new_slot = len(entries)
                entries.append({"id": id, "count": 1})
            entries[old_slot]["count"] -= 1
            write_index(words, bits, index, new_slot)
            if len(entries) > (1 << bits):
                new_bits = index_bits(len(entries))
                if new_bits > bits:
                    new_words = [0] * word_count(new_bits)
                    for i in range(SECTION_VOLUME):
                        s = read_index(words, bits, i)
                        write_index(new_words, new_bits, i, s)
                    self.data = ("Palette", entries, new_words, new_bits)
            return True
        return False

    def set_batch(self, edits):
        return sum(1 for pos, id in edits if self.set(pos, id))

    def compact(self):
        if self.data is None or self.data[0] != "Palette": return False
        entries, words, bits = self.data[1], self.data[2], self.data[3]
        live = [e for e in entries if e["count"] > 0]
        if len(live) == len(entries): return False
        slot_map = {i: new_i for new_i, i in enumerate([idx for idx, e in enumerate(entries) if e["count"] > 0])}
        new_entries = [{"id": e["id"], "count": e["count"]} for e in live]
        new_bits = index_bits(len(new_entries))
        new_words = [0] * word_count(new_bits)
        for i in range(SECTION_VOLUME):
            old_slot = read_index(words, bits, i)
            write_index(new_words, new_bits, i, slot_map.get(old_slot, 0))
        self.data = ("Palette", new_entries, new_words, new_bits)
        return True

    def get(self, position):
        index = position[0] + position[1] * SECTION_EDGE + position[2] * SECTION_EDGE * SECTION_EDGE
        if self.data is None: return 0
        if self.data[0] == "Uniform": return self.data[1]
        entries, words, bits = self.data[1], self.data[2], self.data[3]
        return entries[read_index(words, bits, index)]["id"]

    def copy_voxels(self, out_array):
        if self.data is None:
            out_array[:] = [0] * SECTION_VOLUME
            return
        if self.data[0] == "Uniform":
            out_array[:] = [self.data[1]] * SECTION_VOLUME
            return
        entries, words, bits = self.data[1], self.data[2], self.data[3]
        for i in range(SECTION_VOLUME):
            out_array[i] = entries[read_index(words, bits, i)]["id"]
```

### Edge Cases and Pitfalls
-   **Palette Width Limit**: The implementation caps `bits_per_index` at 12 bits. If more than 4096 unique IDs are introduced, the behavior is constrained by this limit [S1, unofficial].
-   **Dead Slot Reuse**: When a palette entry is no longer referenced, its slot is marked dead (count=0) but not removed immediately. New unique IDs can reuse dead slots without repacking the indices [S1, unofficial].
-   **Boundary Conditions**: Indices 0, 63, 64, 2048, 4095 are tested to ensure bit-packing handles word boundaries and edge indices correctly [S1, unofficial].
-   **Uniform Collapse**: If all voxels become identical after updates or compaction, the section collapses to `Uniform` state, freeing heap memory [S1, unofficial].
-   **Empty Collapse**: If all voxels become `AIR`, the section collapses to `Empty` state with 0 heap capacity [S1, unofficial].

## Operating characteristics
-   **Memory**:
    -   `Empty` and `Uniform` states use 0 heap bytes [S1, unofficial].
    -   `Palette` state uses heap for `entries` (N × sizeof(PaletteEntry)) and `words` (ceil(4096 × bits / 64) × 8 bytes) [S1, unofficial].
    -   Memory is optimized for homogeneous sections, which are common in voxel worlds [S1, unofficial].
-   **Time Complexity**:
    -   `get`: O(1) [S1, unofficial].
    -   `set`: O(1) amortized, O(N) if repacking is triggered (rare) [S1, unofficial].
    -   `compact`: O(N) where N is the number of palette entries [S1, unofficial].
    -   `iter`: O(4096) [S1, unofficial].
-   **Strengths**:
    -   Extremely low memory overhead for empty or uniform sections [S1, unofficial].
    -   Efficient for sections with a small number of unique voxel types [S1, unofficial].
    -   Supports fast bulk updates and iteration [S1, unofficial].
-   **Limitations**:
    -   High memory usage if all 4096 voxels are unique (12 bits × 4096 / 8 = 6144 bytes for indices + palette overhead) [S1, unofficial].
    -   Repacking can be expensive if triggered frequently [S1, unofficial].
    -   Not suitable for highly heterogeneous sections with many unique IDs [S1, unofficial].

## Background
The Adaptive Bit-Packed Voxel Array is implemented in the voxel-forge repository as an unofficial voxel engine implementation [S1, unofficial]. It is designed to efficiently store and manage voxel data in a 3D grid, leveraging the sparsity and homogeneity often found in voxel-based games and simulations [S1, unofficial].
