# Memoization for Hash Lookup

Also called: Chunk Hashing for Synchronization, External Hash Table Caching for Hash Grids, Hash Cache

## Overview
Memoization for Hash Lookup caches computed node hashes in an external hash table keyed by memory address to avoid redundant recursive computation during searches [S1, unofficial]. It complements Universal Hash Optimization by reducing traversal overhead while maintaining uniform node distribution across buckets [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A target chunk or node, an external hash table (`hashCache`), and an optional array of chunk keys [S2, unofficial].
- Output: An array of `[key, hash]` pairs for the processed chunks [S2, unofficial].

**Data Structures:**
- `hashCache`: A map where keys are memory addresses (or chunk keys) and values are objects containing:
  - `v`: The version number of the node at caching time.
  - `h`: The computed hash value [S2, unofficial].

**Steps:**
1. Initialize or retrieve the `hashCache` map [S2, unofficial].
2. For each target chunk (or all chunks if `keys` is null), check if a cache entry exists and if the stored version matches the current node's version [S2, unofficial].
3. If the version mismatches or the entry is missing, compute the hash:
   - If the chunk contains an SDF: $h = \text{FNV-1a}(c.\text{mat}, \text{FNV-1a}(\text{Uint8Array}(c.\text{sdf.buffer}, c.\text{sdf.byteOffset}, c.\text{sdf.byteLength})))$ [S2, unofficial].
   - If the chunk is uniform (no SDF): $h = \text{FNV-1a}(\text{Uint8Array}([c.\text{fill} \ \& \ 255, c.\text{fillMat}]))$ [S2, unofficial].
4. Cache the result as `{v: c.version, h}` [S2, unofficial].
5. Return the array of `[key, hash]` pairs [S2, unofficial].
6. When a node's structure is modified, remove its entry from the external hash table to prevent stale results [S1, unofficial].

**Pseudocode:**
```python
def fnv1a(data):
    """FNV-1a hash over a sequence of integers (bytes)."""
    h = 0x811c9dc5
    for b in data:
        h ^= b
        h = (h * 0x01000193) & 0xFFFFFFFF
    return h

def memoized_hash_lookup(chunks, hash_cache, keys=None):
    if hash_cache is None:
        hash_cache = {}
    target_keys = keys if keys is not None else chunks
    results = []
    for c in target_keys:
        addr = id(c)
        if addr in hash_cache:
            entry = hash_cache[addr]
            if entry['v'] == c.version:
                results.append([addr, entry['h']])
                continue
        if c.has_sdf:
            sdf_bytes = c.sdf.buffer[c.sdf.byteOffset : c.sdf.byteOffset + c.sdf.byteLength]
            inner = fnv1a(sdf_bytes)
            h = fnv1a((c.mat, inner))
        else:
            h = fnv1a((c.fill & 255, c.fillMat))
        hash_cache[addr] = {'v': c.version, 'h': h}
        results.append([addr, h])
    return results

def invalidate_on_modify(node, hash_cache):
    addr = id(node)
    if addr in hash_cache:
        del hash_cache[addr]
```

**Parameters:**
- `keys`: Optional array of chunk keys to hash. If null, hashes all chunks [S2, unofficial].

**Edge Cases and Pitfalls:**
- **Structure Modification**: When a node's structure is modified, its entry must be removed from the external hash table to prevent stale results [S1, unofficial].
- **Hash Collisions**: Collisions are possible but mitigated by the Universal Hash function used in the broader context [S1, unofficial].
