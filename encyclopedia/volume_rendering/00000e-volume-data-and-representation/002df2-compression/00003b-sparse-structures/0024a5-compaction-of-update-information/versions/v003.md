# Compaction of Update Information

Also called: HistoPyramids Reduction, Node-List Compaction

## Overview
This method reduces the bandwidth of node update information sent from the GPU to the CPU by removing duplicate node references using spatial coherence and HistoPyramids [S1, unofficial]. It solves the problem of limited bandwidth when transferring sparse voxel tree navigation data for adaptive rendering [S1, unofficial]. It differs from sibling methods by using a 2D-locality-optimized prefix-sum scan (HistoPyramids) on selection masks derived from local list comparisons, rather than global sorting or hash-based deduplication [S1, unofficial].

## How it works
**Inputs:**
- Node lists generated during ray traversal [S1, unofficial].
- A set of node-list textures (MRTs) [S1, unofficial].

**Outputs:**
- A compact node index texture containing unique node indices and their associated ray pixel positions [S1, unofficial].
- A bitmask indicating which nodes were kept [S1, unofficial].

**Data Structures:**
1. **Node List Entry:** A 32-bit integer per node [S1, unofficial].
   - Bits 0–29: Node index (30 bits) [S1, unofficial].
   - Bit 30: Subdivision tag (1 bit). Indicates if the CPU should reset the timestamp (node present) or induce subdivision (node missing/terminal) [S1, unofficial].
   - Bit 31: Unused in the entry itself, but used in the final compacted texture for pixel position encoding [S1, unofficial].
2. **Node-List Textures:** Multiple render targets (MRTs) [S1, unofficial].
   - Each texture provides room for four encountered nodes (one per RGBA channel) [S1, unofficial].
   - The subdivision tag is stored alongside the node index in the same 32-bit value [S1, unofficial].
   - The method uses seven node-list textures, allowing for a $7 \times 4 = 28$-node output per ray [S1, unofficial].
3. **Selection Mask Texture:** Stores a bitvector per pixel [S1, unofficial]. The $i$-th bit indicates if the $i$-th element in the node list should be kept [S1, unofficial].
4. **Compact Node Index Texture:** A single RGBA32 texture storing indices of up to four nodes per pixel, along with ray pixel position [S1, unofficial].

**Steps:**
1. **Render Target Setup:** Reserve the first render target for output color. Use the remaining buffers as node-list textures [S1, unofficial].
2. **Node List Generation:** During rendering, traverse the tree. Stop at the required level-of-detail. If data is present, add the current node index to the node-list. If the level-of-detail is missing or the node is terminal, add it to the node-list. The CPU manages the pool and timestamps [S1, unofficial].
3. **Selection Mask Derivation (First Pass):** Compare the center node list against surrounding lists (2D locality pattern) [S1, unofficial]. An entry is kept only if it does not appear in the surrounding lists [S1, unofficial]. **Approximate Comparison:** For efficiency, the $i$-th list element is tested only against the $(i-1)$-th, $i$-th, and $(i+1)$-th elements of neighboring lists [S1, unofficial]. This is conservative and may induce "false positives" (keeping duplicates), but avoids costly full comparisons [S1, unofficial]. Output a bitvector to the selection mask texture [S1, unofficial].
4. **HistoPyramids Reduction:** Apply HistoPyramids (a GPU-optimized prefix-sum scan exploiting 2D locality) to the selection mask [S1, unofficial]. This reduces the selection mask to determine the final compacted indices [S1, unofficial].
5. **Index Recovery and Encoding:** During reduction, original pixel positions are lost. To recover node indices later, encode the ray's pixel position in the remaining 20 bits (over 32) of the 12 node entries per list [S1, unofficial]. After reduction, each pixel contains a ray pixel-position and a bitmask [S1, unofficial].
6. **Compact Texture Creation:** Create a compact node index texture from the bitmask and position [S1, unofficial]. Typically, the bitmask contains 2–3 non-zero entries. Store indices of four nodes in a single RGBA32 texture [S1, unofficial]. If the bitmask exceeds the limit (more than 4 nodes), postpone requests to the next frame [S1, unofficial].
7. **CPU Transfer:** Transfer the compacted texture to the CPU [S1, unofficial].

**Pseudocode:**
```python
def compaction_of_update_information(node_lists, ray_pixel_positions):
    # Step 1: Render Target Setup
    # Reserve first render target for output color; use remaining 7 buffers as node-list textures [S1, unofficial].
    node_list_textures = allocate_mrt_textures(count=7) # Each texture holds 4 nodes (RGBA channels) [S1, unofficial].

    # Step 2: Node List Generation (GPU Kernel)
    # Traverse tree, stop at required LOD. Add node index to list. 
    # If LOD missing or node terminal, add to list. CPU manages pool/timestamps [S1, unofficial].
    for pixel_idx, node_list in enumerate(node_lists):
        for i, node in enumerate(node_list):
            # Pack node index (30 bits) and subdivision tag (1 bit) into 32-bit value [S1, unofficial].
            packed_node = (node.index << 1) | node.subdivision_tag
            channel = i % 4
            node_list_textures[pixel_idx][channel] = packed_node

    # Step 3: Selection Mask Derivation
    selection_mask = allocate_texture(width, height)
    for pixel_idx in range(width * height):
        center_list = node_list_textures[pixel_idx]
        # [Comment: Sources do not give exact neighbor lookup logic; assumes 2D locality pattern access]
        surrounding_lists = get_neighbor_lists(pixel_idx, node_list_textures) 
        mask = 0
        for i, packed_node in enumerate(center_list):
            is_unique = True
            # Approximate comparison: test against (i-1), i, (i+1) of neighbors [S1, unofficial].
            for neighbor_list in surrounding_lists:
                for j in range(max(0, i-1), min(len(neighbor_list), i+2)):
                    if (neighbor_list[j] >> 1) == (packed_node >> 1): # Compare 30-bit indices
                        is_unique = False
                        break
                if not is_unique:
                    break
            if is_unique:
                mask |= (1 << i)
        selection_mask[pixel_idx] = mask

    # Step 4: HistoPyramids Reduction
    # Apply HistoPyramids (GPU-optimized prefix-sum scan exploiting 2D locality) to the selection mask [S1, unofficial].
    # [Comment: Sources do not give exact HistoPyramids implementation; standard prefix-sum scan applies]
    reduced_data = apply_prefix_sum_scan(selection_mask) 

    # Step 5: Index Recovery and Encoding
    # During reduction, original pixel positions are lost. Encode ray pixel position in remaining 20 bits [S1, unofficial].
    compact_texture = allocate_rgba32_texture(width, height)
    for pixel_idx in range(width * height):
        bitmask = reduced_data[pixel_idx].bitmask
        pixel_pos = reduced_data[pixel_idx].pixel_position # Recovered from encoded 20 bits
        nodes_to_keep = []
        for i in range(len(bitmask)):
            if bitmask & (1 << i):
                channel = i % 4
                packed_node = node_list_textures[pixel_idx][channel]
                nodes_to_keep.append(packed_node)
        
        # Store up to 4 nodes in single RGBA32 texture [S1, unofficial].
        for c in range(4):
            if c < len(nodes_to_keep):
                # [Comment: Sources do not give exact bit-packing formula for pixel_pos encoding]
                compact_texture[pixel_idx][c] = encode_node(packed_node, pixel_pos)
            else:
                compact_texture[pixel_idx][c] = 0

    # Step 6: CPU Transfer
    # If bitmask exceeds limit (>4 nodes), postpone to next frame [S1, unofficial].
    if count_set_bits(reduced_data.bitmask) <= 4:
        send_to_cpu(compact_texture)
    else:
        postpone_to_next_frame()
```

## Background
Originates from the Ray-Guided Streaming for Efficient and Detailed Voxel Rendering paper (CNLE09) [S1, unofficial]. It is used in adaptive sparse voxel rendering pipelines to manage CPU-GPU bandwidth for node update information, establishing a lazy evaluation scheme that simplifies previous solutions requiring active tree maintenance [S1, unofficial].
