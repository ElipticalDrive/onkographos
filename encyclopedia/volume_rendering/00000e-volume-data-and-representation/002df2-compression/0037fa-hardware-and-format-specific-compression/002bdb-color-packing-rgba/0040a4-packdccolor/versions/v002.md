# packDCColor
Also called: CreateSimpleColorDataJob, DC SH coefficient packing, Simple Color Data Encoding
## Overview
Packs the DC spherical harmonic coefficient (RGB) and alpha into a single 32-bit unsigned integer for GPU texture storage [S1, unofficial]. It differs from the parent method [Color Packing (RGBA)](5142-color-packing-rgba.md) by explicitly applying the DC spherical harmonic basis function scaling to the color channels before quantization [S1, unofficial].
## How it works
### Inputs and outputs
- **Input**: Spherical harmonic color vector `sh` (3 floats, RGB), alpha value `alpha` (1 float), and quantization constant `k_SH0` [S1, unofficial].
- **Output**: A 32-bit unsigned integer containing packed R, G, B, A channels [S1, unofficial].

### Data structures
- `sh`: Array of 3 floats representing the DC SH coefficients for red, green, and blue channels [S1, unofficial].
- `alpha`: Single float representing opacity [S1, unofficial].
- `k_SH0`: Constant float value $0.28209479177387814$ [S1, unofficial].

### Steps
1. Define a quantization function `quant(value)` that clamps `value` to the range $[0, 1]$, multiplies by 255, adds 0.5, casts to `uint32`, and masks with `0xFF` [S1, unofficial].
2. Compute the red channel: $R = \text{quant}(k_{SH0} \times sh[0] + 0.5)$ [S1, unofficial].
3. Compute the green channel: $G = \text{quant}(k_{SH0} \times sh[1] + 0.5)$ [S1, unofficial].
4. Compute the blue channel: $B = \text{quant}(k_{SH0} \times sh[2] + 0.5)$ [S1, unofficial].
5. Compute the alpha channel: $A = \text{quant}(alpha)$ [S1, unofficial].
6. Pack the channels into a 32-bit integer: `result = R | (G << 8) | (B << 16) | (A << 24)` [S1, unofficial].

### Pseudocode
```python
def pack_dc_color(sh_r: float, sh_g: float, sh_b: float, alpha: float) -> int:
    k_sh0 = 0.28209479177387814

    def quant(value: float) -> int:
        clamped = max(0.0, min(1.0, value))
        return int(clamped * 255.0 + 0.5) & 0xFF

    r = quant(k_sh0 * sh_r + 0.5)
    g = quant(k_sh0 * sh_g + 0.5)
    b = quant(k_sh0 * sh_b + 0.5)
    a = quant(alpha)

    return r | (g << 8) | (b << 16) | (a << 24)
```

### Parameters
- $k_{SH0} = 0.28209479177387814$: The DC spherical harmonic coefficient $Y_0^0$ [S1, unofficial].

### Edge cases and pitfalls
- **Precision**: The quantization adds 0.5 before casting to ensure rounding to nearest integer [S1, unofficial].
- **Boundaries**: Values outside $[0, 1]$ are clamped before quantization [S1, unofficial].

## Operating characteristics
- **Time Complexity**: $O(1)$ per splat.
- **Memory Complexity**: $O(1)$ per splat (4 bytes output) [G].
- **Strengths**: Compact storage for GPU textures; integrates SH basis directly into color packing [S1, unofficial].
- **Limitations**: Lossy quantization to 8-bit per channel; specific to DC SH coefficients [S1, unofficial].
- **When to use**: When storing splat colors in 32-bit texture formats and using DC SH coefficients [S1, unofficial].
