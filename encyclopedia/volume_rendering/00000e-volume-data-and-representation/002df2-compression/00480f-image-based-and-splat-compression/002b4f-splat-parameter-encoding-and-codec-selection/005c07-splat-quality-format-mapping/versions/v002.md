# Splat Quality Format Mapping
## Overview
Splat Quality Format Mapping is a codec selection strategy that maps a target quality level to specific data storage formats for position, scale, color, and spherical harmonics (SH) coefficients [S1, unofficial]. It balances visual fidelity against memory usage and download size by selecting from a predefined set of compression levels [S1, unofficial]. It differs from raw storage by introducing a discrete set of presets (VeryHigh to VeryLow) that dictate the bit-depth and encoding scheme for each splat attribute [S1, unofficial].

## How it works
**Inputs:** A target quality level from the `SplatQuality` enum [S1, unofficial].
**Outputs:** A tuple of four format identifiers `(posFormat, scaleFormat, colorFormat, shFormat)` used by the processing pipeline [S1, unofficial].

**Data Structures:**
The mapping is defined by the `SplatQuality` enum, which contains five levels [S1, unofficial]. Each level maps to specific formats for four attributes:
1.  **Position:** `Float32`, `Norm11`, or `Norm6` [S1, unofficial].
2.  **Scale:** `Float32`, `Norm11`, or `Norm6` [S1, unofficial].
3.  **Color:** `Float32x4`, `Float16x4`, `Norm8x4`, or `BC7` [S1, unofficial].
4.  **Spherical Harmonics (SH):** `Float32`, `Float16`, `Norm6`, `Cluster64k`, or `Cluster4k` [S1, unofficial].

**Format Definitions:**
*   `Float32`: 32-bit floating point [S1, unofficial].
*   `Float16`: 16-bit half-precision floating point [S1, unofficial].
*   `Norm11`: 11-bit normalized integer [S1, unofficial].
*   `Norm8`: 8-bit normalized integer [S1, unofficial].
*   `Norm6`: 6-bit normalized integer [S1, unofficial].
*   `BC7`: Block-compressed 7 texture format applied to color [S1, unofficial].
*   `Cluster64k` / `Cluster4k`: Cluster-based compression for SH coefficients [S1, unofficial].

**Mapping Table:**
The `GetFormats(quality)` function returns the format tuple based on the input `SplatQuality` [S1, unofficial]:

| Quality Level | Position | Scale | Color | SH |
| :--- | :--- | :--- | :--- | :--- |
| `VeryHigh` | `Float32` | `Float32` | `Float32x4` | `Float32` |
| `High` | `Norm11` | `Norm11` | `Float16x4` | `Float16` |
| `Medium` (Default) | `Norm11` | `Norm11` | `Norm8x4` | `Norm6` |
| `Low` | `Norm6` | `Norm6` | `Norm8x4` | `Cluster64k` |
| `VeryLow` | `Norm6` | `Norm6` | `BC7` | `Cluster4k` |

**Pseudocode:**
The following Python-like pseudocode implements the mapping logic [S1, unofficial]. It assumes `SplatQuality` is an enum and `GetFormats` returns a tuple of strings representing the format names [S1, unofficial].

```python
def GetFormats(quality: SplatQuality) -> tuple:
    """
    Returns the format tuple (posFormat, scaleFormat, colorFormat, shFormat)
    based on the requested quality level.
    """
    if quality == SplatQuality.VeryHigh:
        return ("Float32", "Float32", "Float32x4", "Float32")
    elif quality == SplatQuality.High:
        return ("Norm11", "Norm11", "Float16x4", "Float16")
    elif quality == SplatQuality.Medium:
        return ("Norm11", "Norm11", "Norm8x4", "Norm6")
    elif quality == SplatQuality.Low:
        return ("Norm6", "Norm6", "Norm8x4", "Cluster64k")
    elif quality == SplatQuality.VeryLow:
        return ("Norm6", "Norm6", "BC7", "Cluster4k")
    else:
        return ("Norm11", "Norm11", "Norm8x4", "Norm6")

class SplatQuality:
    VeryHigh = 0
    High = 1
    Medium = 2
    Low = 3
    VeryLow = 4
```

**Edge Cases and Pitfalls:**
*   **Resolution Fallback:** If the requested resolution key from the `SplatResolution` enum (`FullRes` mapped to `"full_res"`, `_500k` mapped to `"500k"`, `_100k` mapped to `"100k"`) is missing from the world assets, the pipeline falls back to `GetBestResolutionUrl()` to avoid download failure [S1, unofficial].
