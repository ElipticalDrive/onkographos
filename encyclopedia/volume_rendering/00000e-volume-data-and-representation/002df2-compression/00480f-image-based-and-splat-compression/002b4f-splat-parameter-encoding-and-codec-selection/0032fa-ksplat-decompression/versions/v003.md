# Ksplat Decompression

Also called: .ksplat format decoder, Kevin Kwok's compressed splat format, Splat Transform Ksplat Reader, ksplat reader, readKsplat

## Overview
Ksplat Decompression reads and decompresses `.ksplat` files, which contain spatially bucketed and quantized 3D Gaussian Splat data, into a structured `DataTable` format suitable for rendering [S1]. It handles position quantization, scale/rotation compression, and spherical harmonics decoding [S1]. Unlike raw PLY formats, it supports three distinct compression modes (Float32, Float16, Uint8) to balance file size and precision, and uses spatial bucketing to optimize position storage [S1].

## How it works
**Inputs and Outputs:**
- **Input:** A binary `.ksplat` file [S1].
- **Output:** A structured object (`DataTable`) containing 14 base columns (`x, y, z, scale_0, scale_1, scale_2, f_dc_0, f_dc_1, f_dc_2, opacity, rot_0, rot_1, rot_2, rot_3`) and additional columns for spherical harmonics (`f_rest_i`) [S1].

**Data Structures:**
The file layout is defined by a Main Header and Section Headers [S1].

**Main Header (4096 bytes):**
- Offset 0: `majorVersion` (u8) [S1]
- Offset 1: `minorVersion` (u8) [S1]
- Offset 4: `maxSections` (u32 LE) [S1]
- Offset 16: `numSplats` (u32 LE) [S1]
- Offset 20: `compressionMode` (u16 LE) [S1]
- Offset 36: `minHarmonicsValue` (f32 LE) [S1]
- Offset 40: `maxHarmonicsValue` (f32 LE) [S1]

**Section Header (1024 bytes):**
- Offset 0: `sectionSplatCount` (u32 LE) [S1]
- Offset 4: `maxSectionSplats` (u32 LE) [S1]
- Offset 8: `bucketCapacity` (u32 LE) [S1]
- Offset 12: `bucketCount` (u32 LE) [S1]
- Offset 16: `spatialBlockSize` (f32 LE) [S1]
- Offset 20: `bucketStorageSize` (u16 LE) [S1]
- Offset 24: `quantizationRange` (u32 LE) [S1]
- Offset 32: `fullBuckets` (u32 LE) [S1]
- Offset 36: `partialBuckets` (u32 LE) [S1]
- Offset 40: `harmonicsDegree` (u16 LE) [S1]

**Parameters:**
The `COMPRESSION_MODES` array defines byte sizes for each component based on `compressionMode` (0, 1, or 2) [S1].
- **Mode 0 (Float32):** center=12, scale=12, rotation=16, color=4, harmonics=4. `scaleStart`=12, `rotStart`=24, `colorStart`=40, `harmStart`=44. `quantRange`=1 [S1].
- **Mode 1 (Float16):** center=6, scale=6, rotation=8, color=4, harmonics=2. `scaleStart`=6, `rotStart`=12, `colorStart`=20, `harmStart`=24. `quantRange`=32767 [S1].
- **Mode 2 (Uint8):** center=6, scale=6, rotation=8, color=4, harmonics=1. `scaleStart`=6, `rotStart`=12, `colorStart`=20, `harmStart`=24. `quantRange`=32767 [S1].

**Steps:**
1. **Load and Validate:** Read the entire file into a buffer [S1]. Validate `totalSize >= 4096` [S1]. Parse the main header [S1]. Check `majorVersion === 0` and `minorVersion >= 1` [S1]. Check `compressionMode <= 2` [S1]. Check `numSplats > 0` [S1].
2. **Initialize Columns:** Create 14 base `Float32Array`s of size `numSplats` for `x, y, z, scale_0/1/2, f_dc_0/1/2, opacity, rot_0/1/2/3` [S1].
3. **Determine Harmonics:** Iterate section headers to find `maxHarmonicsDegree` [S1]. Calculate `maxHarmonicsComponentCount` using `HARMONICS_COMPONENT_COUNT[maxHarmonicsDegree]` [S1]. Add `f_rest_i` columns for `i` from 0 to `maxHarmonicsComponentCount - 1` [S1].
4. **Calculate Byte Sizes:** Get `compressionConfig` from `COMPRESSION_MODES[compressionMode]` [S1]. Calculate `bytesPerSplat = centerBytes + scaleBytes + rotationBytes + colorBytes + harmonicsComponentCount * harmonicsBytes` [S1].
5. **Process Sections:** Iterate `sectionIdx` from 0 to `maxSections - 1` [S1]. Read section header at `MAIN_HEADER_SIZE + sectionIdx * 1024` [S1]. If `sectionSplatCount === 0`, skip [S1].
6. **Calculate Bucket Info:** Determine `bucketCapacity` and `bucketCount` from the section header [S1]. Calculate `fullBuckets` and `partialBuckets` [S1].
7. **Read Bucket Centers:** Read `bucketCount * 3` Float32s for bucket centers [S1].
8. **Read Partial Bucket Sizes:** Read `partialBuckets` Uint32s for partial bucket sizes [S1].
9. **Iterate Splats:** For each splat in the section (0 to `sectionSplatCount - 1`):
    a. **Calculate Offset:** `splatByteOffset = splatIdx * bytesPerSplat` [S1].
    b. **Determine Bucket Index:** If `splatIdx < fullBucketSplats`, `bucketIdx = Math.floor(splatIdx / bucketCapacity)` [S1]. Else, track `currentPartialBucket` and `currentPartialBase` using `partialBucketSizes` to find the correct bucket [S1].
    c. **Decode Position:** If `compressionMode == 0`, read three Float32s [S1]. Else, read three Uint16s, subtract `quantizationRange`, multiply by `positionScale`, and add `bucketCenters[bucketIdx * 3 + i]` [S1].
    d. **Decode Scales:** If `compressionMode == 0`, read three Float32s [S1]. Else, read three Uint16s and decode to Float16 [S1]. If `scaleX > 0`, store `Math.log(scaleX)`, else store `-10` [S1].
    e. **Decode Rotation:** If `compressionMode == 0`, read four Float32s [S1]. Else, read four Uint16s and decode to Float16 [S1]. Store in `rot_0..rot_3` [S1].
    f. **Decode Color/Opacity:** Read four Uint8s for R, G, B, Opacity [S1]. Convert R/G/B from 0-255 to 0-1, subtract 0.5, divide by `SH_C0` (0.28209479177387814) [S1]. Clamp `opacity/255.0` to `[epsilon, 1-epsilon]` where `epsilon=1e-6` [S1]. Apply inverse sigmoid: `Math.log(normalizedOpacity / (1.0 - normalizedOpacity))` [S1].
    g. **Decode Spherical Harmonics:** Loop `i` from 0 to `harmonicsComponentCount - 1` [S1]. Map `i` to channel and coefficient based on band packing (Band 0: 9 coeffs, Band 1: 15 coeffs) [S1]. Calculate column index `col = channel * (harmonicsComponentCount / 3) + coefficient` [S1]. Decode Harmonics: Mode 0 reads Float32 [S1]. Mode 1 reads Uint16 and decodes Float16 [S1]. Mode 2 reads Uint8, normalizes by 255, then maps to `[minHarmonicsValue, maxHarmonicsValue]` [S1]. Store in `columns[14 + col]` [S1].

**Formulas:**
- `positionScale = spatialBlockSize / 2.0 / quantizationRange` [S1].

**Pseudocode:**
```python
import struct
import math

def decode_float16(encoded: int) -> float:
    sign_bit = (encoded >> 15) & 1
    exponent = (encoded >> 10) & 0x1f
    mantissa = encoded & 0x3ff
    if exponent == 0:
        if mantissa == 0:
            return -0.0 if sign_bit else 0.0
        m = mantissa
        exp = -14
        while not (m & 0x400):
            m <<= 1
            exp -= 1
        m &= 0x3ff
        final_exp = exp + 127
        final_mantissa = m << 13
        bits = (sign_bit << 31) | (final_exp << 23) | final_mantissa
        return struct.unpack('f', struct.pack('I', bits))[0]
    if exponent == 0x1f:
        if mantissa == 0:
            return -math.inf if sign_bit else math.inf
        return math.nan
    final_exp = exponent - 15 + 127
    final_mantissa = mantissa << 13
    bits = (sign_bit << 31) | (final_exp << 23) | final_mantissa
    return struct.unpack('f', struct.pack('I', bits))[0]

def decode_ksplat(data: bytes) -> dict:
    if len(data) < 4096:
        raise ValueError("File too small")
    
    major_version = data[0]
    minor_version = data[1]
    max_sections = struct.unpack_from('<I', data, 4)[0]
    num_splats = struct.unpack_from('<I', data, 16)[0]
    compression_mode = struct.unpack_from('<H', data, 20)[0]
    min_harmonics_value = struct.unpack_from('<f', data, 36)[0]
    max_harmonics_value = struct.unpack_from('<f', data, 40)[0]
    
    if major_version != 0 or minor_version < 1:
        raise ValueError("Unsupported version")
    if compression_mode > 2:
        raise ValueError("Invalid compression mode")
    if num_splats == 0:
        raise ValueError("Empty file")
        
    COMPRESSION_MODES = [
        {'center': 12, 'scale': 12, 'rotation': 16, 'color': 4, 'harmonics': 4, 'scale_start': 12, 'rot_start': 24, 'color_start': 40, 'harm_start': 44, 'quant_range': 1},
        {'center': 6, 'scale': 6, 'rotation': 8, 'color': 4, 'harmonics': 2, 'scale_start': 6, 'rot_start': 12, 'color_start': 20, 'harm_start': 24, 'quant_range': 32767},
        {'center': 6, 'scale': 6, 'rotation': 8, 'color': 4, 'harmonics': 1, 'scale_start': 6, 'rot_start': 12, 'color_start': 20, 'harm_start': 24, 'quant_range': 32767}
    ]
    config = COMPRESSION_MODES[compression_mode]
    
    columns = {
        'x': [0.0] * num_splats, 'y': [0.0] * num_splats, 'z': [0.0] * num_splats,
        'scale_0': [0.0] * num_splats, 'scale_1': [0.0] * num_splats, 'scale_2': [0.0] * num_splats,
        'f_dc_0': [0.0] * num_splats, 'f_dc_1': [0.0] * num_splats, 'f_dc_2': [0.0] * num_splats,
        'opacity': [0.0] * num_splats,
        'rot_0': [0.0] * num_splats, 'rot_1': [0.0] * num_splats, 'rot_2': [0.0] * num_splats, 'rot_3': [0.0] * num_splats
    }
    
    max_harmonics_degree = 0
    section_headers = []
    for i in range(max_sections):
        offset = 4096 + i * 1024
        section_splat_count = struct.unpack_from('<I', data, offset)[0]
        max_section_splats = struct.unpack_from('<I', data, offset + 4)[0]
        bucket_capacity = struct.unpack_from('<I', data, offset + 8)[0]
        bucket_count = struct.unpack_from('<I', data, offset + 12)[0]
        spatial_block_size = struct.unpack_from('<f', data, offset + 16)[0]
        quantization_range = struct.unpack_from('<I', data, offset + 24)[0]
        full_buckets = struct.unpack_from('<I', data, offset + 32)[0]
        partial_buckets = struct.unpack_from('<I', data, offset + 36)[0]
        harmonics_degree = struct.unpack_from('<H', data, offset + 40)[0]
        
        if section_splat_count > 0:
            section_headers.append({
                'splat_count': section_splat_count, 'max_splats': max_section_splats,
                'bucket_capacity': bucket_capacity, 'bucket_count': bucket_count,
                'spatial_block_size': spatial_block_size,
                'quantization_range': quantization_range if quantization_range > 0 else config['quant_range'],
                'full_buckets': full_buckets, 'partial_buckets': partial_buckets,
                'harmonics_degree': harmonics_degree
            })
            if harmonics_degree > max_harmonics_degree:
                max_harmonics_degree = harmonics_degree
                
    HARMONICS_COMPONENT_COUNT = {0: 9, 1: 24, 2: 45, 3: 63} [G]
    max_harmonics_component_count = HARMONICS_COMPONENT_COUNT.get(max_harmonics_degree, 0)
    for i in range(max_harmonics_component_count):
        columns[f'f_rest_{i}'] = [0.0] * num_splats
        
    current_splat_idx = 0
    current_offset = 4096 + max_sections * 1024
    
    for section in section_headers:
        partial_buckets = section['partial_buckets']
        bucket_count = section['bucket_count']
        spatial_block_size = section['spatial_block_size']
        quantization_range = section['quantization_range']
        full_buckets = section['full_buckets']
        bucket_capacity = section['bucket_capacity']
        
        position_scale = spatial_block_size / 2.0 / quantization_range
        
        # Read Partial Bucket Sizes
        partial_bucket_sizes = []
        for i in range(partial_buckets):
            partial_bucket_sizes.append(struct.unpack_from('<I', data, current_offset)[0])
            current_offset += 4
            
        # Read Bucket Centers
        bucket_centers = []
        for i in range(bucket_count * 3):
            bucket_centers.append(struct.unpack_from('<f', data, current_offset)[0])
            current_offset += 4
            
        bytes_per_splat = config['center'] + config['scale'] + config['rotation'] + config['color'] + max_harmonics_component_count * config['harmonics']
        
        current_partial_bucket = 0
        current_partial_base = 0
        
        for splat_idx in range(section['splat_count']):
            splat_byte_offset = current_offset + splat_idx * bytes_per_splat
            
            if splat_idx < full_buckets * bucket_capacity:
                bucket_idx = splat_idx // bucket_capacity
            else:
                while current_partial_bucket < partial_buckets and current_partial_base + partial_bucket_sizes[current_partial_bucket] <= splat_idx:
                    current_partial_base += partial_bucket_sizes[current_partial_bucket]
                    current_partial_bucket += 1
                bucket_idx = full_buckets + current_partial_bucket
                
            # Decode Position
            if compression_mode == 0:
                x = struct.unpack_from('<f', data, splat_byte_offset)[0]
                y = struct.unpack_from('<f', data, splat_byte_offset + 4)[0]
                z = struct.unpack_from('<f', data, splat_byte_offset + 8)[0]
            else:
                x_raw = struct.unpack_from('<H', data, splat_byte_offset)[0]
                y_raw = struct.unpack_from('<H', data, splat_byte_offset + 2)[0]
                z_raw = struct.unpack_from('<H', data, splat_byte_offset + 4)[0]
                x = (x_raw - quantization_range) * position_scale + bucket_centers[bucket_idx * 3]
                y = (y_raw - quantization_range) * position_scale + bucket_centers[bucket_idx * 3 + 1]
                z = (z_raw - quantization_range) * position_scale + bucket_centers[bucket_idx * 3 + 2]
                
            columns['x'][current_splat_idx] = x
            columns['y'][current_splat_idx] = y
            columns['z'][current_splat_idx] = z
            
            # Decode Scales
            scale_offset = splat_byte_offset + config['center']
            if compression_mode == 0:
                scale_0 = struct.unpack_from('<f', data, scale_offset)[0]
                scale_1 = struct.unpack_from('<f', data, scale_offset + 4)[0]
                scale_2 = struct.unpack_from('<f', data, scale_offset + 8)[0]
            else:
                scale_0 = decode_float16(struct.unpack_from('<H', data, scale_offset)[0])
                scale_1 = decode_float16(struct.unpack_from('<H', data, scale_offset + 2)[0])
                scale_2 = decode_float16(struct.unpack_from('<H', data, scale_offset + 4)[0])
                
            columns['scale_0'][current_splat_idx] = math.log(scale_0) if scale_0 > 0 else -10.0
            columns['scale_1'][current_splat_idx] = math.log(scale_1) if scale_1 > 0 else -10.0
            columns['scale_2'][current_splat_idx] = math.log(scale_2) if scale_2 > 0 else -10.0
            
            # Decode Rotation
            rot_offset = splat_byte_offset + config['scale_start']
            if compression_mode == 0:
                rot_0 = struct.unpack_from('<f', data, rot_offset)[0]
                rot_1 = struct.unpack_from('<f', data, rot_offset + 4)[0]
                rot_2 = struct.unpack_from('<f', data, rot_offset + 8)[0]
                rot_3 = struct.unpack_from('<f', data, rot_offset + 12)[0]
            else:
                rot_0 = decode_float16(struct.unpack_from('<H', data, rot_offset)[0])
                rot_1 = decode_float16(struct.unpack_from('<H', data, rot_offset + 2)[0])
                rot_2 = decode_float16(struct.unpack_from('<H', data, rot_offset + 4)[0])
                rot_3 = decode_float16(struct.unpack_from('<H', data, rot_offset + 6)[0])
                
            columns['rot_0'][current_splat_idx] = rot_0
            columns['rot_1'][current_splat_idx] = rot_1
            columns['rot_2'][current_splat_idx] = rot_2
            columns['rot_3'][current_splat_idx] = rot_3
            
            # Decode Color/Opacity
            color_offset = splat_byte_offset + config['rot_start']
            r = data[color_offset] / 255.0
            g = data[color_offset + 1] / 255.0
            b = data[color_offset + 2] / 255.0
            opacity_raw = data[color_offset + 3] / 255.0
            
            epsilon = 1e-6
            opacity_clamped = max(epsilon, min(1.0 - epsilon, opacity_raw))
            opacity_logit = math.log(opacity_clamped / (1.0 - opacity_clamped))
            
            sh_c0 = 0.28209479177387814
            columns['f_dc_0'][current_splat_idx] = (r - 0.5) / sh_c0
            columns['f_dc_1'][current_splat_idx] = (g - 0.5) / sh_c0
            columns['f_dc_2'][current_splat_idx] = (b - 0.5) / sh_c0
            columns['opacity'][current_splat_idx] = opacity_logit
            
            # Decode Spherical Harmonics
            harm_offset = splat_byte_offset + config['harm_start']
            for i in range(max_harmonics_component_count):
                if compression_mode == 0:
                    val = struct.unpack_from('<f', data, harm_offset + i * 4)[0]
                elif compression_mode == 1:
                    val = decode_float16(struct.unpack_from('<H', data, harm_offset + i * 2)[0])
                else:
                    raw_val = data[harm_offset + i]
                    val = (raw_val / 255.0) * (max_harmonics_value - min_harmonics_value) + min_harmonics_value
                    
                # Map i to channel and coeff based on band packing
                channel = i % 3
                coeff = i // 3
                col_idx = channel * (max_harmonics_component_count // 3) + coeff
                columns[f'f_rest_{col_idx}'][current_splat_idx] = val
                
            current_splat_idx += 1
            
        current_offset += section['splat_count'] * bytes_per_splat
        
    return columns
```

**Edge Cases and Pitfalls:**
- File size < 4096 bytes, `numSplats == 0`, `compressionMode > 2`, or unsupported version must throw errors [S1].
- `quantizationRange` in section header may be 0; fallback to `scaleQuantRange` from `COMPRESSION_MODES` [S1].
- Scale must be positive for log conversion; if not, store -10 [S1].
- Opacity must be clamped away from 0 and 1 before inverse sigmoid to avoid infinity [S1].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of splats and sections.
- **Memory Complexity:** Linear with respect to the number of splats, storing all columns in memory.
- **Performance:** Mode 0 (Float32) offers highest precision but largest file size. Modes 1 (Float16) and 2 (Uint8) reduce file size significantly but introduce quantization artifacts [S1]. Mode 2 is the most compact but lowest precision.
- **Strengths:** Efficient storage for large Gaussian Splat scenes, spatial bucketing for position data.
- **Limitations:** Limited to 3 compression modes, potential precision loss in Modes 1 and 2.
