# Self-Organizing Gaussians (SOG)
Also called: SOG Grid, Structured 2D Grid Mapping, gsplat Grid
## Overview
Self-Organizing Gaussians (SOG) solves the compression bottleneck of unstructured 3D Gaussian Splatting by mapping scattered Gaussian attributes onto a structured 2D grid [S1]. This spatial organization groups similar attributes together, transforming the data into a format compatible with standard image codecs such as PNG, JPEG, and EXR [S2, unofficial]. Unlike methods that predict feature planes, SOG directly projects attributes into 2D maps to leverage existing image compression pipelines [S1].
## How it works
**Inputs and Outputs:**
*   **Input:** A set of unstructured 3D Gaussians [S1].
*   **Output:** A set of 2D texture maps (grids) representing the Gaussian attributes, ready for image-based compression [S2, unofficial].

**Data Structures:**
The method uses a structured 2D grid where each cell corresponds to a spatial region in the 3D scene [S1]. The grid stores flattened attribute vectors for the Gaussians assigned to that region [G]. The exact layout depends on the attribute being mapped, but typically each pixel in the 2D grid maps to a specific Gaussian or a cluster of Gaussians [S1].

**Steps:**
1.  **Grid Initialization:** Define a 2D grid of fixed resolution [G].
2.  **Spatial Mapping:** Project each unstructured Gaussian onto the 2D grid by determining the grid cell that best represents its 3D position [S1].
3.  **Attribute Assignment:** Store the Gaussian's attributes into the corresponding grid cells [S1]. If multiple Gaussians map to the same cell, they are merged or averaged [G].
4.  **Smoothing Regularization:** During training, a smoothing regularization term is added to the loss function to penalize large attribute differences between adjacent grid cells, promoting locally smooth configurations [S1].
5.  **Compression:** Encode the resulting 2D grids using standard image codecs [S2, unofficial].

**Formulas:**
Not given in the sources. The smoothing regularization conceptually minimizes the squared difference between attribute vectors of neighboring grid cells during optimization [S1].

**Parameters:**
*   Grid Resolution ($W \times H$): Not given in the sources [S1].

**Pseudocode:**
```python
def self_organizing_gaussians(gaussians, grid_width, grid_height, smoothing_weight):
    """
    Maps unstructured Gaussians to a 2D grid for compression.
    
    Args:
        gaussians: List of dicts with keys 'pos', 'opacity', 'scale', 'rotation', 'sh_coeffs'.
        grid_width: Width of the 2D grid.
        grid_height: Height of the 2D grid.
        smoothing_weight: Weight for the smoothing regularization term.
        
    Returns:
        grid: 2D list of shape (grid_height, grid_width) containing flattened attribute lists.
        total_loss: Computed smoothing regularization loss.
    """
    # Initialize grid to store flattened attributes per cell [G]
    grid = [[None] * grid_width for _ in range(grid_height)]
    
    # Map Gaussians to grid cells and assign attributes [S1]
    for g in gaussians:
        # Normalize 3D position to [0, 1] range for grid mapping [G]
        u = int(min(max(g['pos'][0], 0.0), 1.0) * grid_width)
        v = int(min(max(g['pos'][1], 0.0), 1.0) * grid_height)
        
        # Flatten attributes: position(3), opacity(1), scale(3), rotation(4), SH(27) [G]
        attrs = list(g['pos']) + [g['opacity']] + list(g['scale']) + list(g['rotation']) + list(g['sh_coeffs'])
        
        # Handle collisions by averaging or overwriting [G]
        if grid[v][u] is None:
            grid[v][u] = attrs
        else:
            grid[v][u] = [(a + b) / 2.0 for a, b in zip(grid[v][u], attrs)]
            
    # Compute smoothing regularization loss for training [S1]
    smoothing_loss = 0.0
    for y in range(grid_height):
        for x in range(grid_width):
            if grid[y][x] is None:
                continue
            current_attrs = grid[y][x]
            # Check 4-connected neighbors [G]
            for dy, dx in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
                ny, nx = y + dy, x + dx
                if 0 <= ny < grid_height and 0 <= nx < grid_width and grid[ny][nx] is not None:
                    neighbor_attrs = grid[ny][nx]
                    smoothing_loss += sum((a - b) ** 2 for a, b in zip(current_attrs, neighbor_attrs))
                    
    total_loss = smoothing_weight * smoothing_loss
    return grid, total_loss
```

## Operating characteristics
*   **Time Complexity:** $O(N)$ for spatial mapping of $N$ Gaussians; compression time depends on the chosen image codec [G].
*   **Memory Complexity:** $O(W \times H \times \text{num\_attributes})$ for the 2D grid storage [G].
*   **Strengths:** Leverages mature, highly optimized image codecs; simple to implement and integrate [G].
*   **Limitations:** Grid resolution limits spatial detail; collision handling requires explicit merging logic [G].
*   **When to use:** When standard image compression is preferred for simplicity and compatibility [G].
*   **When not to use:** When high spatial fidelity is required without grid quantization artifacts [G].
## Background
Self-Organizing Gaussians (SOG) was introduced as a method to compress 3D Gaussian Splatting representations by organizing them into a structured 2D grid [S1]. It is used in conjunction with the gsplat library [S1]. The method addresses the inefficiency of storing unstructured Gaussian data by exploiting spatial coherence [S1].
