# Sparse Coding with K-SVD and Coresets

Also called: Coreset Subsampling, K-SVD Dictionary Training, K-SVD with Coresets, Sparse Coding Global Processing, Sparse Coding with Coresets

## Overview
This method addresses the prohibitive computational cost of training data-specific dictionaries on massive volume datasets by combining the K-SVD algorithm with coreset-based data reduction [S1]. Unlike uniform subsampling, which fails to capture critical information at material boundaries, this approach uses importance sampling to construct a small, weighted subset of training blocks that approximates the original data distribution [S1]. It builds on [Sparse Representation Modeling](5392-sparse-representation-modeling.md) by providing a scalable training pipeline for dictionary-based sparse representations.

## How it works
**Inputs:**
- A set of $N$ training blocks extracted from the volume data.
- Target coreset size $C$ (where $C \ll N$).
- Dictionary size $K$ for the K-SVD algorithm.

**Outputs:**
- A trained dictionary matrix $D \in \mathbb{R}^{m \times K}$, where $m$ is the dimensionality of a block.
- Sparse coefficients for the training blocks (implicit in the training process).

**Data Structures:**
- **Training Blocks:** A list or matrix of shape $(N, m)$.
- **Importance Scores:** An array $\iota$ of length $N$, where $\iota_i$ is the importance of block $i$.
- **Coreset:** A subset of indices $I \subset \{1, \dots, N\}$ with $|I|=C$, and associated weights $w$.

**Algorithm Steps:**

1. **Compute Importance Scores:**
   Calculate the importance $\iota_i$ for each training block $i$. The sources specify that $\iota_i$ is proportional to the standard deviation of the block [S1].
   $$ \iota_i \propto \sigma_i $$
   where $\sigma_i$ is the standard deviation of the pixel/voxel values in block $i$.

2. **Normalize Probabilities:**
   Convert importance scores into picking probabilities $p_j$ for each block $j$.
   $$ p_j = \frac{\iota_j}{\sum_{k=1}^{N} \iota_k} $$

3. **Construct Coreset via Importance Sampling:**
   Select $C$ blocks from the original $N$ blocks. Each block $j$ is picked with probability $p_j$. This is typically done using a streaming method or repeated sampling with replacement [S1]. Let the selected indices be $j_1, j_2, \dots, j_C$.

4. **Assign Weights:**
   For each selected block $j$ in the coreset, assign a weight $w_j$ to remove bias introduced by the non-uniform sampling. The weight is calculated as:
   $$ w_j = \frac{1}{\sqrt{p_j}} $$
   where $p_j$ is the probability with which block $j$ was selected [S1].

5. **Train Dictionary with K-SVD:**
   Apply the K-SVD algorithm [AEB06] to the resampled and re-weighted set of $C$ blocks. The K-SVD algorithm iteratively updates the dictionary atoms and the sparse coefficients to minimize the reconstruction error, weighted by $w_j$ [S1][S2, unofficial].

**Pseudocode:**

```python
def train_sparse_coding_coreset(blocks, target_coreset_size C, dict_size K):
    """
    blocks: numpy array of shape (N, m), N training blocks of dimension m.
    C: integer, number of blocks to select for the coreset.
    K: integer, number of atoms in the dictionary.
    """
    N, m = blocks.shape
    
    # Step 1: Compute importance scores (proportional to standard deviation)
    # [S1] importance is proportional to standard deviation
    std_devs = np.std(blocks, axis=1)
    importance = std_devs
    
    # Step 2: Normalize to get probabilities
    total_importance = np.sum(importance)
    probabilities = importance / total_importance
    
    # Step 3: Select C blocks using importance sampling
    # [S1] C elements are picked with probability proportional to importance
    # Using multinomial sampling with replacement or streaming selection
    selected_indices = np.random.choice(N, size=C, p=probabilities, replace=True)
    
    # Step 4: Calculate weights to remove bias
    # [S1] w_j = 1 / sqrt(p_j)
    selected_probabilities = probabilities[selected_indices]
    weights = 1.0 / np.sqrt(selected_probabilities)
    
    # Extract the coreset blocks
    coreset_blocks = blocks[selected_indices]
    
    # Step 5: Train dictionary using K-SVD on the weighted coreset
    # [S1][S2, unofficial] Apply learning algorithm to the resampled and re-weighted set
    # Note: Standard K-SVD implementations may not natively support sample weights.
    # Implementation detail [G]: If the K-SVD solver does not support weights,
    # one must either:
    # 1. Repeat each block in coreset_blocks according to weight magnitude (approximate).
    # 2. Modify the K-SVD update step to include weight matrix W in the error term:
    #    min || W * (X - D * A) ||_F^2

    dictionary, coefficients = k_svd_algorithm(coreset_blocks, weights, K)
```

**Edge Cases and Pitfalls:**
- **Uniform Subsampling Failure:** Uniform sub-sampling is explicitly rejected because material boundaries carry more information than empty or uniform space [S1].
- **Numerical Instability:** Massive datasets can lead to numerical instabilities during K-SVD calculations [S1]. The coreset approach mitigates this by reducing the dataset size.
- **Computational Cost:** Direct K-SVD on massive volumes is prohibitively expensive in time and memory [S1][S2, unofficial].

## Operating characteristics
- **Time Complexity:** The dominant cost is the K-SVD training on the coreset of size $C$. Since $C \ll N$, this is significantly faster than training on $N$ blocks. The sampling step is $O(N)$ for computing standard deviations and $O(C \log N)$ or $O(C)$ for selection.
- **Memory Complexity:** Reduced from $O(N \cdot m)$ to $O(C \cdot m)$ for the training data held in memory during K-SVD.
- **Performance:** Results demonstrate that extremely good approximations can be obtained using a tiny fraction of the original data [S1].
- **Strengths:** Scalability to massive volumes; captures critical features (boundaries) better than uniform sampling.
- **Limitations:** Requires careful tuning of $C$; relies on the assumption that standard deviation is a good proxy for information content [S1].

## Background
- **Origin:** The method was introduced by Gobbetti et al. [GIM12] for volume rendering compression, applying the concept of coresets [AHPV05, CS07] to K-SVD dictionary training [S1].
- **Development:** Prior approaches for BTF compression by Ruiters and Klein [RK09] used truncated SVD for data reduction. Gobbetti et al. improved upon this by using importance sampling based on standard deviation [S1].
- **Context:** It is part of the global processing techniques for sparse coding, aiming to improve upon vector quantization by using data-specific dictionaries [S1][S2, unofficial].
