# Sparse Representation (Dictionary Based)

Also called: Dictionary based sparse coding

## Overview
Sparse Representation (Dictionary Based) encodes volume data blocks by finding a sparse linear combination of atoms from a pre-computed dictionary, solving an optimization problem to minimize reconstruction error under a sparsity constraint [S1][S2, unofficial]. It differs from Vector Quantization (VQ) by allowing each input block to be represented by a linear combination of multiple dictionary elements rather than a single nearest-neighbor prototype, offering higher fidelity at the cost of significantly more complex encoding [S1][S2, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A volume dataset partitioned into cubic blocks of size $M \times M \times M$. A pre-computed dictionary $\mathbf{D} \in \mathbb{R}^{m \times K}$, where $m = M^3$ is the dimension of a flattened block and $K$ is the number of atoms in the dictionary.
*   **Output:** For each block, a sparse coefficient vector $\boldsymbol{\lambda}_i \in \mathbb{R}^K$ containing at most $S$ non-zero entries, and the indices of these non-zero entries.

**Data Structures**
*   **Dictionary $\mathbf{D}$:** A matrix of shape $(m, K)$. Each column $\mathbf{d}_j$ is an atom of size $m$.
*   **Sparse Representation $\boldsymbol{\lambda}_i$:** A vector of size $K$. Stored efficiently as a list of pairs $(index, value)$ for non-zero entries.

**Algorithm Steps**
1.  **Vectorization:** For each volume block $i$, extract the voxel values and map them to a column vector $\mathbf{y}_i \in \mathbb{R}^m$.
2.  **Optimization:** Solve for $\boldsymbol{\lambda}_i$ to minimize the reconstruction error subject to a sparsity constraint:
    $$ \min_{\boldsymbol{\lambda}_i} \left\{ \| \mathbf{y}_i - \mathbf{D}\boldsymbol{\lambda}_i \|^2 \right\} \quad \text{subject to} \quad \| \boldsymbol{\lambda}_i \|_0 \leq S $$
    where $\| \boldsymbol{\lambda}_i \|_0$ denotes the number of non-zero entries in $\boldsymbol{\lambda}_i$ [S1][S2, unofficial].
3.  **Approximation:** Since the exact solution is NP-hard, use a greedy pursuit approximation algorithm [S1][S2, unofficial]. Specifically, Orthogonal Regularized Matching Pursuit (ORMP) via Choleski decomposition is employed for its simplicity and efficiency [S1][S2, unofficial].
4.  **Compression:** Store the sparse representation $\boldsymbol{\lambda}_i$ by recording the indices of the non-zero elements and their corresponding magnitudes [S1][S2, unofficial].

**Pseudocode**
```python
def encode_block_dictionary_based(y_i, D, S):
    """
    Encodes a single volume block using sparse representation.
    
    Args:
        y_i: numpy array of shape (m,), the flattened volume block.
        D: numpy array of shape (m, K), the dictionary matrix.
        S: int, maximum number of non-zero coefficients.
        
    Returns:
        indices: list of int, indices of non-zero coefficients.
        values: list of float, magnitudes of non-zero coefficients.
    """
    m, K = D.shape
    
    # Initialize coefficients to zero
    lambda_i = np.zeros(K)
    
    # ORMP via Choleski Decomposition
    # Note: Exact ORMP implementation details are not provided in sources [S1][S2, unofficial].
    # The following is a placeholder for the greedy pursuit logic described.
    # In practice, this involves iteratively selecting the atom most correlated 
    # with the residual, updating the coefficients via least-squares (using Cholesky),
    # and updating the residual.
    
    residual = y_i.copy()
    selected_indices = []
    
    for step in range(S):
        # 1. Select atom most correlated with residual
        correlations = np.abs(D.T @ residual)
        best_idx = np.argmax(correlations)
        
        if best_idx in selected_indices:
            break
            
        selected_indices.append(best_idx)
        
        # 2. Update coefficients using least-squares on selected atoms
        # Let D_selected be the submatrix of D with columns in selected_indices
        D_selected = D[:, selected_indices]
        
        # Solve min || y_i - D_selected * lambda_selected ||^2
        # Using Cholesky decomposition: (D_selected^T D_selected) lambda = D_selected^T y_i
        A = D_selected.T @ D_selected
        b = D_selected.T @ y_i
        
        # Cholesky decomposition of A
        L = np.linalg.cholesky(A)
        
        # Solve L z = b
        z = np.linalg.solve(L, b)
        
        # Solve L^T lambda_selected = z
        lambda_selected = np.linalg.solve(L.T, z)
        
        # Update residual
        residual = y_i - D_selected @ lambda_selected
        
        # Store coefficients in full vector
        for idx, val in zip(selected_indices, lambda_selected):
            lambda_i[idx] = val
            
    # Extract non-zero entries
    indices = [i for i, val in enumerate(lambda_i) if val != 0]
    values = [lambda_i[i] for i in indices]
    
    return indices, values
```

**Parameters**
*   $M$: Block side length. Not given in the sources.
*   $K$: Dictionary size. Not given in the sources.
*   $S$: Sparsity level (max non-zero entries). Not given in the sources.

**Edge Cases and Pitfalls**
*   **NP-Hardness:** The optimization problem is NP-hard; greedy approximations do not guarantee global optimality [S1][S2, unofficial].
*   **Precision:** Floating-point errors in Cholesky decomposition may require regularization if the matrix is ill-conditioned [G].
*   **Boundaries:** Blocks at the volume boundary must be handled (e.g., padding or smaller blocks). Not given in the sources.

## Subtopics

### [Sparse Representation Modeling](5392-sparse-representation-modeling.md)
Represents a signal as a sparse linear combination of atoms from an overcomplete dictionary. Distinguished by its specific implementation of dictionary training via K-SVD and data reduction via importance sampling coresets to handle massive volumes.

### [Sparse Coding](5842-sparse-coding.md)
Decompresses volume data by reconstructing voxel blocks as linear combinations of codewords from a learned dictionary. Distinguished by focusing on the decomposition and reconstruction mechanics of voxel blocks, explicitly utilizing a linear combination of multiple codewords rather than a single best match.

## Operating characteristics
*   **Complexity:** Encoding is computationally expensive due to the need for iterative greedy pursuit algorithms (e.g., ORMP) and matrix decompositions (Cholesky), unlike the trivial nearest-neighbor search in VQ [S1][S2, unofficial].
*   **Memory:** Compression is achieved by storing only the indices and magnitudes of the sparse coefficients, reducing memory occupancy compared to storing full block data [S1][S2, unofficial].
*   **Performance:** Not given in the sources.
*   **Strengths:** Higher reconstruction fidelity than VQ by using linear combinations of multiple atoms [S1][S2, unofficial].
*   **Limitations:** High encoding complexity; NP-hard optimization requires approximations [S1][S2, unofficial].

## Background
Sparse representation for volume data compression was introduced in the context of compressed GPU-based direct volume rendering. The method was notably employed by Gobbetti et al. [GIM12] using ORMP via Choleski decomposition [CARKD99] [S1][S2, unofficial]. It builds on the general concept of sparse coding in signal processing [Ela10] [S1][S2, unofficial].
