# 3D Seismic Data Compression Pipeline

Also called: .sdc v3 3D Volume Compression Pipeline, SDC3D, SeismicDataCompressor pipeline, compressSegyToSdc3D

## Overview
The 3D Seismic Data Compression Pipeline is a lossy compression method for 3D seismic data that processes volumes in 3D blocks (cubes), applying normalization, closed-loop differential pulse-code modulation (DPCM) with quantization, and Deflate compression to reduce file size while preserving trace integrity [S1, unofficial]. It operates on fixed 3D spatial-temporal blocks rather than semantic segments or arbitrary partitions [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A SEG-Y dataset, a `CompressionProfile` (defining bit depth and compression level), and block dimensions (`blockInline`, `blockXline`, `blockTime`) [S1, unofficial].
- Output: An `.sdc` (v3) file containing a header, an index table, and compressed payloads, along with a `CompressionResult` object containing metrics (PSNR, ratios) [S1, unofficial].

**Data Structures:**
1. `CompressedVolumeBlock3D`: fields are `blockMeta` (a `VolumeBlock3D` object containing positions and dimensions), `min` (float), `max` (float), and `payload` (byte array) [S1, unofficial].
2. Sdc3D File Layout: `[SdcHeader version=3, traceCount, samplesPerTrace] [inlineCount][xlineCount][timeCount] [blockInline][blockXline][blockTime] [blockCount] Index Table (blockCount entries: inlineStartIndex, xlineStartIndex, timeStartIndex, inlineCount, xlineCount, timeCount, min, max, payloadSize) Compressed Payloads (blockCount entries: payloadBytes...)` [S1, unofficial].

**Parameters:**
- `blockInline`: Integer. Default 8 if <= 0 [S1, unofficial].
- `blockXline`: Integer. Default 8 if <= 0 [S1, unofficial].
- `blockTime`: Integer. Default `timeCount` if <= 0 or > `timeCount` [S1, unofficial].
- `bitDepth`: Integer from `CompressionProfile`. Controls quantization precision [S1, unofficial].
- `compressionLevel`: Integer from `CompressionProfile`. Controls Deflate compression level [S1, unofficial].

**Steps:**
1. Read Input: Load the SEG-Y dataset. Determine `traceCount` and `samplesPerTrace`. Calculate `segyBytes` (raw file size) and `rawDataBytes` (`traceCount * samplesPerTrace * 4` bytes, assuming 32-bit floats) [S1, unofficial].
2. Partition into Blocks: Divide the 3D volume into non-overlapping blocks of size `blockInline x blockXline x blockTime` [S1, unofficial].
3. Process Each Block:
   a. Calculate Min/Max: Iterate over all samples in the block to find global `min` and `max` [S1, unofficial].
   b. Normalize: Map samples to `[-1, 1]`. If `max == min` (degenerate case), set all normalized values to `0f` to avoid division by zero [S1, unofficial]. Otherwise: $norm = \frac{v - min}{max - min} \times 2 - 1$ [S1, unofficial].
   c. Closed-Loop DPCM with Quantization: Apply 3D differential encoding based on the `bitDepth` [S1, unofficial]. Predict the current sample based on previously processed neighbors. Calculate the difference $diff = v_{norm} - v_{pred}$. Quantize the difference. Crucially, use the *quantized* reconstructed value for subsequent predictions (closed-loop), not the original normalized value, ensuring decoder synchronization without transmitting original floats [S1, unofficial].
   d. Compress Payload: Create a self-describing payload by storing bit depth information and compressing the quantized data using Deflate with the `compressionLevel`. Store `min`, `max`, and the compressed `payload` in a `CompressedVolumeBlock3D` structure [S1, unofficial].
4. Write SDC3D File: Write the header, volume/block dimensions, index table, and compressed payloads [S1, unofficial].
5. Reconstruct and Evaluate: Read the SDC3D file. Reconstruct traces from the volume. Iterate traces, compute PSNR per trace. Track min, max, mean PSNR [S1, unofficial].
6. Return Result: Return `CompressionResult` with metrics [S1, unofficial].

**Pitfalls:**
- Missing traces (`traceIdx < 0`) are handled by filling the corresponding cube samples with `0f` [S1, unofficial].
- Degenerate normalization case where `max == min` results in all normalized values being `0f` to avoid division by zero [S1, unofficial].

**Pseudocode:**
```python
import zlib
import math

def compress_segy_to_sdc3d(segy_data, profile, block_inline=8, block_xline=8, block_time=None):
    # Step 1: Read Input
    trace_count = len(segy_data)
    samples_per_trace = len(segy_data[0])
    time_count = samples_per_trace
    inline_count = len(segy_data[0][0]) if segy_data else 0
    xline_count = len(segy_data[0][0][0]) if segy_data else 0
    
    segy_bytes = len(segy_data) * samples_per_trace * 4
    raw_data_bytes = trace_count * samples_per_trace * 4
    
    if block_time is None or block_time <= 0 or block_time > time_count:
        block_time = time_count
        
    index_table = []
    payloads = []
    
    # Step 2 & 3: Partition and Process Blocks
    for i_start in range(0, inline_count, block_inline):
        for j_start in range(0, xline_count, block_xline):
            for k_start in range(0, time_count, block_time):
                i_end = min(i_start + block_inline, inline_count)
                j_end = min(j_start + block_xline, xline_count)
                k_end = min(k_start + block_time, time_count)
                
                i_len = i_end - i_start
                j_len = j_end - j_start
                k_len = k_end - k_start
                
                # Extract block data
                block_data = [[[segy_data[i][j][k] for k in range(k_start, k_end)] for j in range(j_start, j_end)] for i in range(i_start, i_end)]
                
                # Step 3a: Calculate Min/Max
                min_val = min(min(row) for row in block_data)
                max_val = max(max(row) for row in block_data)
                
                # Step 3b: Normalize
                if max_val == min_val:
                    norm_data = [[[0.0 for _ in range(k_len)] for _ in range(j_len)] for _ in range(i_len)]
                else:
                    range_val = max_val - min_val
                    norm_data = [[[(block_data[i][j][k] - min_val) / range_val * 2 - 1 for k in range(k_len)] for j in range(j_len)] for i in range(i_len)]
                
                # Step 3c: Closed-Loop DPCM with Quantization
                quantized_diffs = [[[0.0 for _ in range(k_len)] for _ in range(j_len)] for _ in range(i_len)]
                reconstructed = [[[0.0 for _ in range(k_len)] for _ in range(j_len)] for _ in range(i_len)]
                
                bit_depth = profile.bit_depth
                quant_range = 2 ** (bit_depth - 1)
                
                for i in range(i_len):
                    for j in range(j_len):
                        for k in range(k_len):
                            v_norm = norm_data[i][j][k]
                            
                            # Predict based on neighbors (closed-loop uses reconstructed values)
                            pred = 0.0
                            neighbors = 0
                            if k > 0: pred += reconstructed[i][j][k-1]; neighbors += 1
                            if i > 0: pred += reconstructed[i-1][j][k]; neighbors += 1
                            if j > 0: pred += reconstructed[i][j-1][k]; neighbors += 1
                            
                            if neighbors > 0:
                                pred /= neighbors
                            else:
                                pred = 0.0
                            
                            diff = v_norm - pred
                            
                            # Quantize difference to [-quant_range, quant_range]
                            quantized_diff = max(-quant_range, min(quant_range, round(diff * quant_range)))
                            quantized_diffs[i][j][k] = quantized_diff
                            
                            # Reconstruct for closed-loop
                            reconstructed[i][j][k] = pred + quantized_diff / quant_range
                
                # Step 3d: Compress Payload
                flat_diffs = [quantized_diffs[i][j][k] for i in range(i_len) for j in range(j_len) for k in range(k_len)]
                payload_bytes = zlib.compress(bytes(flat_diffs), profile.compression_level)
                
                block_meta = {'inlineStartIndex': i_start, 'xlineStartIndex': j_start, 'timeStartIndex': k_start,
                              'inlineCount': i_len, 'xlineCount': j_len, 'timeCount': k_len}
                index_table.append({**block_meta, 'min': min_val, 'max': max_val, 'payloadSize': len(payload_bytes)})
                payloads.append(payload_bytes)
                
    # Step 4: Write SDC3D File (simulated)
    # In practice, this writes to disk according to the Sdc3D File Layout.
    
    # Step 5: Reconstruct and Evaluate (simulated)
    psnr_values = []
    for t_idx in range(trace_count):
        # Simulate PSNR calculation
        psnr_values.append(30.0) 
        
    psnr_min = min(psnr_values) if psnr_values else 0
    psnr_max = max(psnr_values) if psnr_values else 0
    psnr_mean = sum(psnr_values) / len(psnr_values) if psnr_values else 0
    
    # Step 6: Return Result
    sdc_bytes = sum(len(p) for p in payloads) + 100 # Header overhead approximation
    ratio_file = sdc_bytes / segy_bytes if segy_bytes > 0 else 0
    ratio_data = sdc_bytes / raw_data_bytes if raw_data_bytes > 0 else 0
    savings_percent = (1.0 - ratio_file) * 100.0
    
    return {
        'segy_path': 'input.sgy', 'sdc_path': 'output.sdc',
        'segy_bytes': segy_bytes, 'sdc_bytes': sdc_bytes, 'raw_data_bytes': raw_data_bytes,
        'trace_count': trace_count, 'samples_per_trace': samples_per_trace,
        'ratio_file': ratio_file, 'ratio_data': ratio_data, 'savings_percent': savings_percent,
        'psnr_first': psnr_values[0] if psnr_values else 0,
        'psnr_mean': psnr_mean, 'psnr_min': psnr_min, 'psnr_max': psnr_max
    }
```

## Subtopics

### [3D Volume Block Compression (Closed-Loop)](11729-3d-volume-block-compression-closed-loop.md)
This method compresses 3D seismic data blocks by normalizing samples to a fixed range, applying closed-loop differential pulse-code modulation (DPCM) with quantization, and packing the result with Deflate compression. It differs from open-loop DPCM by feeding the reconstructed (quantized) value back into the predictor, ensuring the decoder can exactly reproduce the quantization steps without requiring the original float values during decoding. It is a core component of the 3D Seismic Data Compression Pipeline [11727-3d-seismic-data-compression-pipeline.md].

### .sdc v2 Trace Compression Pipeline
This is a legacy variant that processes data trace-by-trace rather than in 3D blocks [S1, unofficial]. It reads a SEG-Y dataset, compresses each trace individually using a `CompressionProfile`, and writes an `.sdc` file [S1, unofficial]. It computes compression ratios based on `segyBytes` and `rawDataBytes` (`traceCount * samplesPerTrace * 4`) and evaluates quality via PSNR per trace [S1, unofficial]. It is simpler but lacks the 3D spatial redundancy exploitation of the v3 pipeline [S1, unofficial].

## Operating characteristics
- **Time Complexity**: $O(N)$ where $N$ is the total number of samples, as each sample is processed once for normalization, DPCM, and quantization [S1, unofficial]. Deflate compression is also roughly linear in practice [S1, unofficial].
- **Memory Complexity**: $O(B)$ where $B$ is the block size, as only one block is processed at a time [S1, unofficial].
- **Measured Performance**: Not given in the sources.
- **Scaling**: Scales well with block size; larger blocks may yield better compression due to more spatial redundancy but increase memory usage per block [S1, unofficial].
- **Strengths**: Preserves trace integrity (important for seismic interpretation), lossy but controllable via bit depth, efficient for large 3D volumes [S1, unofficial].
- **Limitations**: Lossy compression may introduce artifacts; closed-loop DPCM requires careful implementation to avoid error propagation; block boundaries may cause discontinuities if not handled [S1, unofficial].
- **When to Use**: When compressing large 3D seismic datasets for storage or transmission, and trace-level fidelity is important [S1, unofficial].
- **When Not to Use**: When lossless compression is required, or when data has very low spatial correlation (e.g., random noise) [S1, unofficial].

## Background
The 3D Seismic Data Compression Pipeline originates from the SeismicDataCompressor repository, an unofficial open-source tool for compressing seismic data [S1, unofficial]. It represents an evolution from the 1D trace-based compression (.sdc v2) to a more efficient 3D block-based approach, leveraging spatial redundancy in seismic volumes [S1, unofficial].
