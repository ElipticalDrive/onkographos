# HDF5 JSON (H5J) File Parsing
Also called: H5J Attribute Parsing

## Overview
Parses HDF5 JSON (H5J) file attributes to extract volume size, voxel size, and channel specifications, applying word alignment to volume dimensions [S1, unofficial]. It differs from raw binary readers by interpreting the JSON metadata structure to construct the `volSize`, `voxSize`, and `chanSpecs` objects required for subsequent voxel loading and quantization [S1, unofficial].

## How it works
**Inputs:** A parsed JSON object representing the HDF5 file's attribute hierarchy [S1, unofficial].
**Outputs:** An object containing `volSize` (`[number, number, number]`), `voxSize` (`[number, number, number]`), and `chanSpecs` (`Array<{name: string, content: string}>`) [S1, unofficial].
**Data Structures:** `volSize` and `voxSize` are arrays of 3 numbers; `chanSpecs` is an array of objects with `name` and `content` fields [S1, unofficial].
**Steps:**
1. Initialize `volSize` and `voxSize` arrays to `[0, 0, 0]` [S1, unofficial].
2. Check if the `attrs` object contains the key `'image_size'` [S1, unofficial]. If present, assign `attrs.image_size` to `volSize` [S1, unofficial].
3. Check if the `attrs` object contains the key `'voxel_size'` [S1, unofficial]. If present, assign `attrs.voxel_size` to `voxSize` [S1, unofficial].
4. Extract `attrs.channels` [S1, unofficial]. If `attrs.channels` contains `'width'`, set `volSize[0]` to `attrs.channels.width[0]` [S1, unofficial]. If it contains `'height'`, set `volSize[1]` to `attrs.channels.height[0]` [S1, unofficial]. If it contains `'frames'`, set `volSize[2]` to `attrs.channels.frames[0]` [S1, unofficial].
5. Align `volSize[0]` and `volSize[1]` to 8-byte word boundaries using the formula `alignedSize = Math.ceil(size / 8) * 8` [S1, unofficial].
6. Construct `chanSpecs` from `attrs.channels.names` and `attrs.channels.content_types` by mapping name to content for each index `i` [S1, unofficial].
7. Return the object `{ volSize, voxSize, chanSpecs }` [S1, unofficial].
**Pseudocode:**
```python
import math

def parse_h5j_attributes(attrs):
    vol_size = [0, 0, 0]
    vox_size = [0, 0, 0]

    if 'image_size' in attrs:
        vol_size = list(attrs['image_size'])

    if 'voxel_size' in attrs:
        vox_size = list(attrs['voxel_size'])

    if 'channels' in attrs:
        channels = attrs['channels']
        if 'width' in channels:
            vol_size[0] = channels['width'][0]
        if 'height' in channels:
            vol_size[1] = channels['height'][0]
        if 'frames' in channels:
            vol_size[2] = channels['frames'][0]

    vol_size[0] = math.ceil(vol_size[0] / 8) * 8
    vol_size[1] = math.ceil(vol_size[1] / 8) * 8

    chan_specs = []
    if 'channels' in attrs:
        channels = attrs['channels']
        names = channels['names']
        content_types = channels['content_types']
        for i in range(len(names)):
            chan_specs.append({
                "name": names[i],
                "content": content_types[i]
            })

    return {
        "volSize": vol_size,
        "voxSize": vox_size,
        "chanSpecs": chan_specs
    }
```
**Parameters:** Word alignment size is 8 bytes [S1, unofficial].
**Edge Cases:** Missing `image_size` or `voxel_size` leaves the arrays as `[0, 0, 0]` unless populated by channel-specific attributes [S1, unofficial].

## Subtopics

### H5J Volume Data Loading with Cross-Origin Isolation
Loading H5J format volumes (HDF5 container with 12-bit HEVC compressed 3D data) uses `web-h5j-loader`, which relies on multi-threaded `ffmpeg.wasm` via `SharedArrayBuffer` [S1, unofficial]. The server must be served with `Cross-Origin-Opener-Policy: same-origin` and `Cross-Origin-Embedder-Policy: require-corp` headers to enable `SharedArrayBuffer` [S1, unofficial]. If these headers are missing, loading H5J produces the exception `'SharedArrayBuffer is not defined'` [S1, unofficial]. Security risks prevent `SharedArrayBuffer` usage unless cross-origin isolation is enabled [S1, unofficial].

## Background
Originating from the Janelia Research Campus's web-based volume viewer tools, this parsing method is part of the `web-vol-viewer` ecosystem [S1, unofficial]. It is designed to handle the specific metadata conventions used in Janelia's HDF5 JSON (H5J) format [S1, unofficial].
