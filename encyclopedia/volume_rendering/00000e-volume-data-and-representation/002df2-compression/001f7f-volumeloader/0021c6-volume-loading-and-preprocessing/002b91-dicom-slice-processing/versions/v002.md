# DICOM Slice Processing
Also called: DICOM Slice Loading and Sorting

## Overview
DICOM Slice Processing loads 2D DICOM image slices from a directory, determines the global intensity range, and sorts the slices into a structured array [S1, unofficial].

## How it works
**Inputs:** A directory path containing DICOM files (specifically with extension `*.IMA` in the reference implementation) [S1, unofficial].
**Outputs:** A sorted array of `Slice` objects and global intensity bounds (`_minIntensity`, `_maxIntensity`) [S1, unofficial].

**Data Structures:**
*   `Slice`: An object representing a single DICOM slice. It contains metadata fields including `LargestImagePixelValue` and `SmallestImagePixelValue` [S1, unofficial].
*   `Slice[]`: An array of `Slice` objects [S1, unofficial].

**Steps:**
1.  **File Discovery:** Retrieve all files in the specified directory with the extension `*.IMA` [S1, unofficial].
2.  **Initialization:** Initialize `max_intensity` to -1 and `min_intensity` to 99999 [S1, unofficial].
3.  **Intensity Aggregation:** Iterate through each discovered slice file: create a `Slice` object, update `max_intensity` if `slice.info.LargestImagePixelValue` is greater than the current `max_intensity`, and update `min_intensity` if `slice.info.SmallestImagePixelValue` is less than the current `min_intensity` [S1, unofficial].
4.  **Global Bounds Storage:** Store the final `min_intensity` and `max_intensity` in `_minIntensity` and `_maxIntensity` respectively [S1, unofficial].
5.  **Sorting:** Sort the `slices` array. The exact sorting key is not specified in the source [S1, unofficial].

def process_dicom_slices(directory_path):

    # 2. Initialize max intensity to -1 and min intensity to 99999
    max_intensity = -1
    min_intensity = 99999

    # 3. Iterate through each slice file

        # Create a Slice object
        slice_obj = load_slice(os.path.join(directory_path, file))
        
        # Update max/min based on info.LargestImagePixelValue and info.SmallestImagePixelValue
        if slice_obj.info.LargestImagePixelValue > max_intensity:
            max_intensity = slice_obj.info.LargestImagePixelValue
        if slice_obj.info.SmallestImagePixelValue < min_intensity:
            min_intensity = slice_obj.info.SmallestImagePixelValue
            
        slices.append(slice_obj)
        
    # 4. Store the global min and max intensities
    _minIntensity = min_intensity
    _maxIntensity = max_intensity
    
    # 5. Sort the slices array
    # Note: The exact sorting key is not specified in the source [S1, unofficial]
    slices.sort(key=lambda s: s.spatial_index)
    
    return slices, _minIntensity, _maxIntensity

## Subtopics

### Slice to Binary Volume Conversion
Converts a directory of 2D image slices into a binary volume file (`.bin`) [S2, unofficial]. It assumes slices are already ordered and calculates bounding box dimensions based on a fixed X width [S2, unofficial]. It reads the first slice to determine width ($w$) and height ($h$), then calculates grid dimensions as $(w, h, N)$ where $N$ is the number of slices [S2, unofficial]. The bounding box size is calculated as $bbox\_size[0] = BBOX\_SIZE\_X$ and $bbox\_size[1] = (BBOX\_SIZE\_X / grid\_dim[0]) \times (vol\_size[1] / vol\_size[0]) \times grid\_dim[1]$ [S2, unofficial]. The parameter $BBOX\_SIZE\_X$ is a fixed width of the bounding box in world units, with a default value of 5.0 [S2, unofficial].
