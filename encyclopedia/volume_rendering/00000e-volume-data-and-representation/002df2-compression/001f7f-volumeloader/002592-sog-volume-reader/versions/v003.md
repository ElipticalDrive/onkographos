# SOG Volume Reader

Also called: Recursive SOG Loader, Spherical Octree Grid Reader

## Overview
The SOG Volume Reader is a recursive algorithm that loads a hierarchical volumetric format (SOG) into a dense 3D grid by parsing a binary header and traversing internal, empty, leaf, and pseudo-leaf node types [S1, unofficial][S2, unofficial]. It differs from flat raw readers by reconstructing the full voxel array from a compressed octree-like structure, enabling efficient storage of sparse or block-structured medical imaging data [S1, unofficial][S2, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A binary file in SOG format containing a header and a sequence of node records [S1, unofficial][S2, unofficial].
- **Output:** A 3D `Volume` array of dimensions $(sx+1) \times (sy+1) \times (sz+1)$ filled with voxel values [S1, unofficial][S2, unofficial].

**Data Structures:**
- **Header:** A single 32-bit integer `sx` stored at the file start [S1, unofficial][S2, unofficial].
- **Node Types:** Each node begins with a `char type` byte [S1, unofficial]:
    - `0`: Internal node.
    - `1`: Empty node.
    - `2`: Leaf node.
    - `3`: Pseudo-leaf node.
- **Volume Interface:** A container with `setDataAt(int x, int y, int z, float val)` to write voxel values at grid coordinates [S1, unofficial].

**Parameters:**
- `off[3]`: The 3D offset of the current node's top-left corner in the global grid [S1, unofficial].
- `len`: The side length of the current node's sub-volume, which halves at each recursion level ($nlen = len / 2$) [S1, unofficial].
- `sg`: A signed char encoding the state for empty or leaf nodes [S1, unofficial].
- `writeData`: A boolean flag that defaults to `true`; when `false`, data writing is skipped during pseudo-leaf traversal [S1, unofficial].
- **Spacing:** Hardcoded to 1.0 for x, y, and z axes [S2, unofficial].

**Algorithm Steps:**
1. Open the file in binary mode and read the header integer `sx` [S1, unofficial][S2, unofficial].
2. Set `sy = sx` and `sz = sx` to enforce a cubic volume [S1, unofficial][S2, unofficial].
3. Allocate a `Volume` array of size $(sx+1, sy+1, sz+1)$ [S1, unofficial][S2, unofficial].
4. Call the recursive function `readSOG(fin, vol, {0, 0, 0}, sx)` [S1, unofficial][S2, unofficial].
5. Inside `readSOG(fin, vol, off, len, writeData = true)`:
    a. Read `type` (char) from the file [S1, unofficial].
    b. If `type == 0` (Internal):
        i. Calculate `nlen = len / 2` [S1, unofficial].
        ii. Loop `i, j, k` from 0 to 1:
            1. Compute `noff[0] = off[0] + i * nlen`, `noff[1] = off[1] + j * nlen`, `noff[2] = off[2] + k * nlen` [S1, unofficial].
            2. Recursively call `readSOG(fin, vol, noff, nlen, writeData)` [S1, unofficial].
    c. If `type == 1` (Empty):
        i. Read `sg` (signed char) [S1, unofficial].
        ii. If `writeData` is true:
            1. Loop `i, j, k` from 0 to `len` [S1, unofficial].
            2. Call `vol->setDataAt(off[0]+i, off[1]+j, off[2]+k, -sg)` [S1, unofficial].
    d. If `type == 2` (Leaf):
        i. Read `sg` (signed char) [S1, unofficial].
        ii. Read `coord[3]` (three floats) [S1, unofficial].
        iii. If `writeData` is true:
            1. Initialize bit counter `t = 0` [S1, unofficial].
            2. Loop `i, j, k` from 0 to 1:
                1. Compute `noff[0] = off[0] + i`, `noff[1] = off[1] + j`, `noff[2] = off[2] + k` [S1, unofficial].
                2. Set `vol->setDataAt(noff[0], noff[1], noff[2], -((sg >> t) & 1))` [S1, unofficial].
                3. Increment `t` [S1, unofficial].
    e. If `type == 3` (Pseudo-leaf):
        i. Read `sg` (signed char) [S1, unofficial].
        ii. Read `coord[3]` (three floats) [S1, unofficial].
        iii. Loop `i, j, k` from 0 to 1:
            1. Compute `noff[0] = off[0] + i * nlen`, `noff[1] = off[1] + j * nlen`, `noff[2] = off[2] + k * nlen` [S1, unofficial].
            2. Recursively call `readSOG(fin, vol, noff, nlen, false)` [S1, unofficial].
    f. If `type` is not 0-3, handle error (e.g., print "Wrong! Type: %d") [S1, unofficial].

**Pseudocode:**
```python
import struct

class Volume:
    def __init__(self, sx, sy, sz):
        self.data = [[[0.0 for _ in range(sz + 1)] for _ in range(sy + 1)] for _ in range(sx + 1)]
    def set_data_at(self, x, y, z, val):
        self.data[x][y][z] = val

def read_sog(fin, vol, off, length, write_data=True):
    """Recursively reads an SOG node.
    :param fin: File object, current position is at the node type byte.
    :param vol: Volume object with method set_data_at(x, y, z, val).
    :param off: Tuple (x, y, z) offset of the current node's top-left corner.
    :param length: Side length of the current node's sub-volume.
    :param write_data: Boolean flag to skip data writing for pseudo-leaves.
    """
    type_byte = fin.read(1)
    if not type_byte:
        raise EOFError("Unexpected end of file")
    node_type = type_byte[0]

    if node_type == 0:  # Internal node
        nlen = length // 2
        for i in range(2):
            for j in range(2):
                for k in range(2):
                    noff = (off[0] + i * nlen, off[1] + j * nlen, off[2] + k * nlen)
                    read_sog(fin, vol, noff, nlen, write_data)

    elif node_type == 1:  # Empty node
        sg_byte = fin.read(1)
        if not sg_byte:
            raise EOFError("Unexpected end of file")
        sg = struct.unpack('b', sg_byte)[0]
        if write_data:
            for i in range(length + 1):
                for j in range(length + 1):
                    for k in range(length + 1):
                        vol.set_data_at(off[0] + i, off[1] + j, off[2] + k, -sg)

    elif node_type == 2:  # Leaf node
        sg_byte = fin.read(1)
        if not sg_byte:
            raise EOFError("Unexpected end of file")
        sg = struct.unpack('b', sg_byte)[0]
        
        coord = []
        for _ in range(3):
            coord_bytes = fin.read(4)
            if not coord_bytes:
                raise EOFError("Unexpected end of file")
            coord.append(struct.unpack('f', coord_bytes)[0])

        if write_data:
            t = 0
            for i in range(2):
                for j in range(2):
                    for k in range(2):
                        noff = (off[0] + i, off[1] + j, off[2] + k)
                        val = -((sg >> t) & 1)
                        vol.set_data_at(noff[0], noff[1], noff[2], val)
                        t += 1

    elif node_type == 3:  # Pseudo-leaf node
        sg_byte = fin.read(1)
        if not sg_byte:
            raise EOFError("Unexpected end of file")
        sg = struct.unpack('b', sg_byte)[0]
        
        coord = []
        for _ in range(3):
            coord_bytes = fin.read(4)
            if not coord_bytes:
                raise EOFError("Unexpected end of file")
            coord.append(struct.unpack('f', coord_bytes)[0])

        nlen = length // 2
        for i in range(2):
            for j in range(2):
                for k in range(2):
                    noff = (off[0] + i * nlen, off[1] + j * nlen, off[2] + k * nlen)
                    read_sog(fin, vol, noff, nlen, False)

    else:
        raise ValueError(f"Wrong! Type: {node_type}")

def load_sog(filename):
    with open(filename, 'rb') as fin:
        sx_bytes = fin.read(4)
        if not sx_bytes:
            raise EOFError("Empty file")
        sx = struct.unpack('i', sx_bytes)[0]
        
        sy = sx
        sz = sx
        
        vol = Volume(sx + 1, sy + 1, sz + 1)
        read_sog(fin, vol, (0, 0, 0), sx)
        
    return vol
```

**Edge Cases and Pitfalls:**
- **Precision:** The coordinates in leaf and pseudo-leaf nodes are stored as `float`, while voxel values are derived from bit manipulation of a `char`, resulting in binary values (0 or 1) negated [S1, unofficial].
- **Boundaries:** The volume array is allocated with size `sx+1`, and the offsets and loops must respect this boundary [S1, unofficial].
- **Degenerate Input:** If the file ends prematurely, an EOF error should be raised [S1, unofficial].
- **Empty Node Loop:** The source specifies looping `0` to `len` for empty nodes [S1, unofficial].

## Background
The SOG Volume Reader originates from Tao Ju's dual contouring library for implicit modeling and surface reconstruction [S1, unofficial][S2, unofficial]. It was developed to support the loading of volumetric data specifically formatted for hierarchical octree-based processing [S1, unofficial][S2, unofficial]. The format and reader are associated with Tao Ju's work on dual contouring and intersection-free surface reconstruction [S1, unofficial][S2, unofficial].
