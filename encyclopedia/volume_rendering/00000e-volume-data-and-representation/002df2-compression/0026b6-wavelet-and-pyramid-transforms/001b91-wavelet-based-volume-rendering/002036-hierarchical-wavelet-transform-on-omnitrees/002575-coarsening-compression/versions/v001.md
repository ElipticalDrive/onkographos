# Coarsening Compression

Also called: Wavelet pruning

## Overview
Coarsening compression is a lossy compression step that prunes small wavelet detail coefficients to reduce the number of leaf nodes in a hierarchical omnitree, while preserving the integral of the represented function [S1, unofficial]. It differs from sibling methods like [Downsplit](3404-downsplit.md) by operating directly on coefficient magnitudes to merge nodes, whereas downsplit restructures the tree topology to expose new coarsening opportunities [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A hierarchized omnitree with wavelet coefficients $w_\tau^v$ associated with each node $v$ and dimension subset $\tau \subseteq \sigma(v)$, and an error density threshold $\varepsilon \ge 0$ [S1, unofficial].
*   **Output:** A modified omnitree with fewer leaf nodes and a corresponding set of wavelet coefficients [S1, unofficial].

**Data Structures:**
The omnitree consists of nodes $v$. Each node $v$ has:
*   $\sigma(v)$: The set of dimensions active at node $v$.
*   $\text{rect}(v)$: The spatial bounding box (hyperrectangle) of node $v$.
*   $w_\tau^v$: Wavelet coefficients for each non-empty subset $\tau \subseteq \sigma(v)$.
*   Children: A list of child nodes.

**Steps:**
1.  **Identify Candidate Nodes:** Iterate through the tree bottom-up, starting from the parents of leaves (last-level parents) [S1, unofficial]. Identify nodes $v$ where all children are leaves [S1, unofficial].
2.  **Check Coefficient Bounds:** For a candidate node $v$, determine the set of dimensions $C \subseteq \sigma(v)$ in which the node can be coarsened. A dimension $j$ is included in $C$ if all detail coefficients $w_\tau^v$ where $\tau \cap \{j\} \neq \emptyset$ satisfy the bound:
    $$ |w_\tau^v| \leq \varepsilon \quad \forall \tau \cap C \neq \emptyset \quad (16) $$
    [S1, unofficial]
3.  **Perform Coarsening:**
    *   **Full Coarsening:** If all detail coefficients for all dimensions satisfy the criterion (i.e., $C = \sigma(v)$), the node $v$ is fully coarsened into a single leaf node. The new node $v'$ has $\sigma(v') = \emptyset$ (or effectively becomes a scalar leaf) [S1, unofficial].
    *   **Partial Coarsening:** If only a subset of dimensions satisfies the criterion, perform partial coarsening. The node $v$ is coarsened in dimensions $C$. The detail coefficients $w_\tau^v$ with $\tau \cap C \neq \emptyset$ are pruned (set to zero). The remaining coefficients form the coefficient vector of the coarsened node $v'$, with $\sigma(v') = \sigma(v) \setminus C$ [S1, unofficial].
    *   **Integral Preservation:** Coarsening preserves the integral of the function because the discarded wavelet functions have an integral of exactly zero due to orthogonality against constant functions [S1, unofficial].
4.  **Iterate:** Repeat the coarsening pass bottom-up until no further coarsening passes are possible [S1, unofficial].

**Pseudocode:**
```python
def coarsen_omnitree(root, epsilon):
    """
    Performs coarsening compression on an omnitree.
    root: The root node of the omnitree.
    epsilon: Error density threshold.
    """
    # Get all nodes in bottom-up order (parents of leaves first)
    # Note: In a real implementation, this requires traversing the tree
    # to identify leaf parents and processing them in reverse depth order.
    nodes_to_process = get_bottom_up_leaf_parents(root)
    
    changed = True
    while changed:
        changed = False
        for v in nodes_to_process:
            # Check if all children are leaves
            if not all(is_leaf(child) for child in v.children):
                continue
            
            # Determine dimensions C that can be coarsened
            C = []
            for dim in v.sigma:
                # Check if all coefficients involving this dim are within epsilon
                can_coarsen_dim = True
                for tau in v.coefficients.keys():
                    if dim in tau:
                        if abs(v.coefficients[tau]) > epsilon:
                            can_coarsen_dim = False
                            break
                if can_coarsen_dim:
                    C.append(dim)
            
            if not C:
                continue
            
            # Perform coarsening
            # Prune coefficients associated with dimensions in C
            coeffs_to_remove = []
            for tau in v.coefficients.keys():
                if any(dim in tau for dim in C):
                    coeffs_to_remove.append(tau)
            
            for tau in coeffs_to_remove:
                del v.coefficients[tau]
            
            # Update sigma
            v.sigma = [dim for dim in v.sigma if dim not in C]
            
            # If sigma is empty, the node becomes a leaf
            if not v.sigma:
                v.is_leaf = True
                v.children = []
                # The node is now a leaf, potentially allowing its parent to be processed
                # in the next iteration if its other children are also leaves.
            
            changed = True
        
        # Re-evaluate bottom-up list as tree structure may have changed
        nodes_to_process = get_bottom_up_leaf_parents(root)

    return root

def get_bottom_up_leaf_parents(root):
    """
    Returns a list of nodes that are parents of leaves, ordered bottom-up.
    This is a helper to ensure correct processing order.
    """
    # Implementation detail: Traverse tree, collect parents of leaves, sort by depth.
    # For simplicity, we assume a recursive traversal that processes children before parents.
    parents = []
    def traverse(node):
        if node.is_leaf:
            return
        children_are_leaves = all(child.is_leaf for child in node.children)
        if children_are_leaves:
            parents.append(node)
        else:
            for child in node.children:
                traverse(child)
    traverse(root)
    return parents

def is_leaf(node):
    return node.is_leaf
```

**Parameters:**
*   $\varepsilon$: Error density threshold. If $\varepsilon = 0$, only nodes with exactly zero detail coefficients are coarsened, yielding lossless compression [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Overestimation of Error:** The a priori bound (Eq. 17) greatly overestimates the actual L1 error when $\varepsilon > 0$ [S1, unofficial]. A tighter a posteriori estimate should be obtained by aggregating coefficient magnitudes from nodes actually selected for coarsening [S1, unofficial].
*   **Heuristic Scope:** In practice, focusing only on parents and grandparents of leaves can yield significant savings, but may not exploit all redundancy [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Preserves the integral of the function exactly [S1, unofficial]. Can be combined with [Downsplit](3404-downsplit.md) to expose more redundancy [S1, unofficial].
*   **Limitations:** The a priori error bound is loose [S1, unofficial]. May not exploit all redundancy if used alone [S1, unofficial].

## Background
Coarsening compression is part of the wavelet-based volume rendering compression strategy on omnitrees, introduced in the paper "Towards Fully Dynamic Omnitrees: Moment-Conserving Anisotropic Compression With Wavelets" [S1, unofficial]. It operates in the wavelet domain, allowing reconstruction of nodal function values only at the end for output file writing and error evaluation [S1, unofficial].
