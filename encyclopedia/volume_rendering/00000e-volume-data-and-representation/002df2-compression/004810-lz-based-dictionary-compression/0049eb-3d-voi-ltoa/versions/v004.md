# 3D-VOI-LtoA

Also called: Hybrid Lossless Compression with Selective Bounding Volume, L to A codec, L to A coding with VOI extraction, Object-based 3D medical image compression, three-dimensional-volume of interest-LtoA Method

## Overview
3D-VOI-LtoA is a two-phase lossless compression technique for 3D medical images that separates foreground data from zero-intensity background using a Selective Bounding Volume (SBV) method, then encodes the resulting Volume of Interest (VOI) using a hybrid Lempel-Ziv-Welch (LZW) and Arithmetic Coding pipeline [S1]. It distinguishes itself from sibling methods like [LZV Algorithm](8069-lzv-algorithm.md) by explicitly excluding large regions of empty background voxels before dictionary-based compression, thereby reducing the data volume processed by the encoder and achieving higher compression ratios on sparse medical datasets [S1].

## How it works

### Inputs and Outputs
*   **Input:** A 3D medical image volume (typically 8-bit depth) containing a foreground object surrounded by a zero-intensity background [S1].
*   **Output:** A compressed bit stream representing the VOI, accompanied by metadata defining the Bounding Volume coordinates and the original volume dimensions [S1].

### Data Structures
The method relies on the following structures:
1.  **Input Volume:** A 3D array of voxels $V[x, y, z]$ with 8-bit depth, implying values $0$–$255$ [S1].
2.  **Bounding Volume Metadata:** A set of global coordinates $(X_{min}, X_{max}, Y_{min}, Y_{max}, Z_{min}, Z_{max})$ defining the axis-aligned bounding box of the VOI [S1].
3.  **Compressed Stream:** The binary output of the Arithmetic Encoder [S1].

### Steps

#### Phase 1: VOI Extraction via Selective Bounding Volume (SBV)
1.  **Input:** 3D volume $V$ [S1].
2.  **Identify Null Slices:** Scan the volume along the depth axis ($z$) and mark slices where all voxels are zero [S1].
3.  **Determine Active Range:** Identify the minimum and maximum indices along the depth axis that contain at least one non-zero voxel, denoted as $Z_{min}$ and $Z_{max}$ [S1].
4.  **Construct Bounding Box:** For all slices $z$ where $Z_{min} \le z \le Z_{max}$, determine the minimum and maximum non-zero coordinates in the $x$ and $y$ dimensions [S1].
    *   Let $x_{min}(z), x_{max}(z), y_{min}(z), y_{max}(z)$ be the bounds of non-zero voxels in slice $z$ [S1].
    *   Compute global bounds:
        $$ X_{min} = \min_{z} x_{min}(z) $$
        $$ X_{max} = \max_{z} x_{max}(z) $$
        $$ Y_{min} = \min_{z} y_{min}(z) $$
        $$ Y_{max} = \max_{z} y_{max}(z) $$
    *   The sources describe applying a bounding box morphological operation to confine these global coordinates [S1].
5.  **Extract VOI:** Define the VOI as the sub-volume $V_{VOI}$ bounded by $[X_{min}, X_{max}] \times [Y_{min}, Y_{max}] \times [Z_{min}, Z_{max}]$ [S1].
6.  **Store Metadata:** Record the global coordinates and the original volume dimensions $(W, H, D)$ [S1].

#### Phase 2: Hybrid L to A Encoding
1.  **Input:** The extracted VOI $V_{VOI}$ [S1].
2.  **LZW Encoding:** Apply the Lempel-Ziv-Welch (LZW) algorithm to the voxel data of $V_{VOI}$ to produce a sequence of LZW codes $C_{LZW}$ [S1].
3.  **Arithmetic Encoding:** Apply Arithmetic Coding to the sequence $C_{LZW}$ to produce the final compressed bit stream $B_{final}$ [S1].
4.  **Output:** Transmit $B_{final}$ along with the Bounding Volume metadata [S1].

#### Phase 3: Decoding and Reconstruction
1.  **Input:** Compressed bit stream $B_{final}$ and Bounding Volume metadata [S1].
2.  **Arithmetic Decoding:** Decode $B_{final}$ using Arithmetic Decoding to recover the sequence of LZW codes $C_{LZW}$ [S1].
3.  **Inverse LZW:** Apply Inverse LZW to $C_{LZW}$ to reconstruct the voxel data of the VOI, $V'_{VOI}$ [S1].
4.  **Reconstruction:**
    *   Build an empty 3D volume of the original dimensions $(W, H, D)$ initialized to zero [S1].
    *   Fuse $V'_{VOI}$ into the empty volume at the position defined by the Bounding Volume coordinates to reconstruct the actual 3D volume [S1].

### Formulas
The method evaluates performance using the following metrics [S1]:
*   **Compression Ratio (CR):** $CR = n_1 / n_2$, where $n_1$ is the number of bits in the original image and $n_2$ is the number of bits in the compressed image.
*   **Bit Rate (BR) / Bits Per Voxel (BPV):** $BR = C / N$, where $C$ is compressed image bits and $N$ is the total number of voxels.
*   **Peak Signal to Noise Ratio (PSNR):** $PSNR = 10 \times \log_{10}(MAX^2 / MSE)$, where $MAX$ is the maximum intensity pixel value.
*   **Mean Squared Error (MSE):** $MSE = \frac{1}{MN} \sum_{y=1}^{M} \sum_{x=1}^{N} (I_{m_{x,y}} - I'_{m_{x,y}})^2$, where $I_m$ is the original and $I'_m$ is the compressed image.
*   **Structural Similarity Index (SSIM):** $SSIM_{x,y} = l_{x,y}^{\alpha} c_{x,y}^{\beta} s_{x,y}^{\gamma}$, where $l_{x,y}$, $c_{x,y}$, and $s_{x,y}$ are luminance, contrast, and structure comparison functions [S1].
*   **Luminance comparison:** $l_{x,y} = \frac{2\mu_x\mu_y + c_1}{\mu_x^2 + \mu_y^2 + c_1}$, where $\mu_x$ and $\mu_y$ are local means [S1].
*   **Contrast comparison:** $c_{x,y} = \frac{2\sigma_x\sigma_y + c_2}{\sigma_x^2 + \sigma_y^2 + c_2}$, where $\sigma_x$ and $\sigma_y$ are standard deviations [S1].
*   **Structure comparison:** $s_{x,y} = \frac{2\sigma_{xy} + c_3}{\sigma_x\sigma_y + c_3}$, where $\sigma_{xy}$ is cross covariance [S1].

### Parameters
*   **Image Depth:** 8-bit (values 0–255) [S1].
*   **Background Intensity:** Assumed to be 0 (zero-intensity) [S1].
*   **Dictionary Size:** Standard LZW initial size of 256 entries for 8-bit data [S1].

### Edge Cases and Pitfalls
*   **Lossless Nature:** Since the method is lossless, MSE is exactly 0, PSNR tends to infinity, and SSIM is 1 for all tested volumes [S1].
*   **Blank Slices:** Slices at the foremost and end that are entirely zero must be correctly identified and excluded from the VOI extraction to maximize compression [S1].
*   **Boundary Conditions:** The bounding box calculation must strictly include all non-zero voxels to prevent data loss during reconstruction [S1].

## Operating characteristics

### Time and Memory Complexity
*   **Time Complexity:** Encoding time is dominated by the LZW and Arithmetic Coding stages on the VOI, with reported times ranging from 19.23s to 408.01s depending on volume size [S1]. Decoding times range from 3.17s to 50.28s [S1].
*   **Memory Complexity:** Requires storing the original volume, the extracted VOI, and the LZW dictionary [S1].

### Measured Performance
Performance was tested on 3D medical images (MRI, CT, PET) from TCIA, IBSR, and Radiopedia [S1].

*   **Comparison:** The method yields almost double the compression ratio of standard methods like Huffman, RLC, LZW, and Arithmetic Coding applied directly to the full volume [S1].
*   **VOI Impact:** Using VOI extraction increases CR by an average of 7.26 and reduces Bit Rate by an average of 1.77 bits compared to methods without VOI extraction [S1].

### Strengths and Limitations
*   **Strengths:** High compression ratios for sparse medical images, lossless fidelity, and reduced computation time for decoding compared to full-volume encoding [S1].
*   **Limitations:** Performance depends heavily on the size of the background, where larger backgrounds yield better compression, and the method is specific to 3D medical images with zero-intensity backgrounds [S1].

## Background

### Origin
The 3D-VOI-LtoA method was proposed in a study on hybrid lossless compression techniques for three-dimensional medical images [S1]. It combines object-based features (VOI extraction) with statistical-based coding (LZW and Arithmetic Coding) [S1].

### History and Development
The method addresses the need for efficient transmission of high-quality medical data for telemedicine and remote diagnosis [S1]. It builds upon the concept of Region of Interest (ROI) or Volume of Interest (VOI) coding, which separates clinically important objects from background [S1]. The "L to A" codec specifically refers to the pipeline of LZW followed by Arithmetic Coding [S1].

### Usage
It is used for compressing 3D medical images (MRI, CT, PET) from repositories such as the Cancer Imaging Archive (TCIA), Internet Brain Segmentation Repository (IBSR), and Radiopedia [S1].

def encode_3d_voi_ltoa(volume_3d):
    """
    Encodes a 3D medical image using 3D-VOI-LtoA.
    volume_3d: 3D list of lists of lists, 8-bit integers.
    Returns: (compressed_bits, metadata)
    """
    # Phase 1: SBV Extraction
    # 1. Identify active slices (non-zero)
    active_slices = []
    for z in range(len(volume_3d)):
        slice_data = volume_3d[z]
        if any(any(row) for row in slice_data):
            active_slices.append(z)

    if not active_slices:
        return b'', {'z_min': 0, 'z_max': 0, 'x_min': 0, 'x_max': 0, 'y_min': 0, 'y_max': 0, 'dims': (len(volume_3d), len(volume_3d[0]), len(volume_3d[0][0]))}

    z_min = min(active_slices)
    z_max = max(active_slices)

    # 2. Determine global X/Y bounds for active slices
    x_min_global = float('inf')
    x_max_global = float('-inf')
    y_min_global = float('inf')
    y_max_global = float('-inf')

    for z in range(z_min, z_max + 1):
        slice_data = volume_3d[z]
        for y in range(len(slice_data)):
            for x in range(len(slice_data[y])):
                if slice_data[y][x] != 0:
                    if x < x_min_global: x_min_global = x
                    if x > x_max_global: x_max_global = x
                    if y < y_min_global: y_min_global = y
                    if y > y_max_global: y_max_global = y

    # 3. Extract VOI
    voi = []
    for z in range(z_min, z_max + 1):
        voi.append([row[x_min_global:x_max_global+1] for row in volume_3d[z][y_min_global:y_max_global+1]])

    metadata = {
        'z_min': z_min, 'z_max': z_max,
        'x_min': x_min_global, 'x_max': x_max_global,
        'y_min': y_min_global, 'y_max': y_max_global,
        'dims': (len(volume_3d), len(volume_3d[0]), len(volume_3d[0][0]))
    }

    # Phase 2: L to A Encoding
    # Flatten VOI to 1D list of integers
    voi_flat = [voxel for z_slice in voi for row in z_slice for voxel in row]

    # LZW Encoding
    lzw_codes = lzw_encode(voi_flat)

    # [G] Standard arithmetic coding implementation required here.
    compressed_bits = arithmetic_encode(lzw_codes)

    return compressed_bits, metadata

def decode_3d_voi_ltoa(compressed_bits, metadata):

    Decodes a 3D medical image using 3D-VOI-LtoA.
    Returns: 3D list of lists of lists
    """
    # Phase 3: Decoding

    lzw_codes = arithmetic_decode(compressed_bits)
    voi_data = lzw_decode(lzw_codes)

    # Reconstruction
    reconstructed = [[[0 for _ in range(metadata['dims'][2])] for _ in range(metadata['dims'][1])] for _ in range(metadata['dims'][0])]

    voi_shape = (
        metadata['z_max'] - metadata['z_min'] + 1,
        metadata['y_max'] - metadata['y_min'] + 1,
        metadata['x_max'] - metadata['x_min'] + 1
    )
    # Reshape flat list back to 3D VOI
    voi_3d = []
    idx = 0
    for z in range(voi_shape[0]):
        slice_data = []
        for y in range(voi_shape[1]):
            row = voi_data[idx:idx+voi_shape[2]]
            slice_data.append(row)
            idx += voi_shape[2]
        voi_3d.append(slice_data)

    # Map VOI back
    for z in range(metadata['z_max'] - metadata['z_min'] + 1):
        for y in range(metadata['y_max'] - metadata['y_min'] + 1):
            for x in range(metadata['x_max'] - metadata['x_min'] + 1):
                reconstructed[metadata['z_min'] + z][metadata['y_min'] + y][metadata['x_min'] + x] = voi_3d[z][y][x]

    return reconstructed

def lzw_encode(data):
    """Standard LZW encoding for a list of integers (0-255)."""
    dictionary = {i: i for i in range(256)}
    code = 256
    result = []
    if not data:
        return result
    w = (data[0],)
    for c in data[1:]:
        wc = w + (c,)
        if wc in dictionary:
            w = wc
        else:
            result.append(dictionary[w])
            dictionary[wc] = code
            code += 1
            w = (c,)
    result.append(dictionary[w])
    return result
