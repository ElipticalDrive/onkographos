# 3D-VOI-LtoA

Also called: Hybrid Lossless Compression with Selective Bounding Volume, L to A codec, L to A coding with VOI extraction, Object-based 3D medical image compression, three-dimensional-volume of interest-LtoA Method

## Overview
3D-VOI-LtoA is a two-phase lossless compression technique for 3D medical images that extracts a Volume of Interest (VOI) using a Selective Bounding Volume (SBV) method to separate foreground from zero-intensity background, then encodes the VOI using a hybrid algorithm combining Lempel-Ziv-Welch (LZW) and Arithmetic Coding [S1]. It differs from standard dictionary methods like [LZV Algorithm](8069-lzv-algorithm.md) by explicitly excluding the large, uniform background regions typical of medical scans before compression, thereby reducing the data volume processed by the encoder and decoder [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D medical image volume (typically 8-bit depth, e.g., MRI, CT, PET) [S1].
*   **Output:** A compressed bit stream containing the encoded VOI data and the Bounding Volume coordinate details required for reconstruction [S1].

**Data Structures:**
*   **Bounding Volume Coordinates:** A set of global coordinates defining the 3D bounding box of the VOI. These coordinates are transmitted alongside the compressed bit stream [S1].
*   **Compressed Bit Stream:** The output of the L to A encoder applied to the VOI data [S1].

**Algorithm Steps:**

1.  **VOI Extraction (Selective Bounding Volume):**
    *   Identify and ignore blank/null slices at the foremost and end of the volume that contain no content [S1].
    *   Apply a Bounding Box operation to the remaining slices to record coordinate values [S1].
    *   Identify global coordinates that encompass all active (non-zero) portions of the volume [S1].
    *   Construct the Bounding Volume using these confined global coordinates, applying a bounding box morphological operation on the volume excluding the blank slices [S1].
    *   Extract the VOI data contained within this Bounding Volume [S1].

2.  **LZW Encoding:**
    *   Apply the Lempel-Ziv-Welch (LZW) algorithm to the extracted VOI data [S1].
    *   Record the output symbols from the LZW encoder [S1].

3.  **Arithmetic Encoding:**
    *   Feed the LZW output symbols into an Arithmetic Encoder [S1].
    *   Generate the final compressed bit stream [S1].

4.  **Transmission:**
    *   Send the compressed bit stream and the Bounding Volume coordinate details to the decoder [S1].

5.  **Decompression (Decoder):**
    *   Perform Arithmetic Decoding on the received bit stream to recover the LZW symbols [S1].
    *   Apply Inverse LZW to the symbols to reconstruct the original VOI data [S1].

6.  **Reconstruction (Fusion):**
    *   Build an empty 3D volume with the dimensions of the original input image [S1].
    *   Use the transmitted Bounding Volume coordinate details to map the decompressed VOI data into the correct spatial positions within the empty volume [S1].
    *   The remaining regions (background) remain at zero intensity, effectively fusing the VOI with the background to reconstruct the actual 3D volume [S1].

def encode_3d_voi_lto_a(volume_3d):
    """
    Encodes a 3D medical image using 3D-VOI-LtoA.
    volume_3d: 3D numpy array or similar structure of 8-bit integers.
    Returns: (compressed_bits, bounding_coords)
    """
    # Phase 1: VOI Extraction via SBV
    # Step 1: Ignore blank/null slices at the foremost and end
    # Identify first and last non-null slices
    first_slice_idx = find_first_non_null_slice(volume_3d)
    last_slice_idx = find_last_non_null_slice(volume_3d)
    
    # Step 2: Apply Bounding Box to find global coordinates of active portions
    # Extract the sub-volume between first and last non-null slices
    # Note: The source mentions applying bounding box morphological operation 
    # on the volume except blank slices to construct the Bounding Volume.
    # We assume this results in a tight 3D bounding box [x_min, x_max, y_min, y_max, z_min, z_max]
    # relative to the original volume dimensions.
    bounding_coords = compute_bounding_box(volume_3d, first_slice_idx, last_slice_idx)
    
    # Extract VOI based on bounding_coords
    voi_data = extract_sub_volume(volume_3d, bounding_coords)
    
    # Phase 2: L to A Encoding
    # Step 3: LZW Encoding
    lzw_symbols = lzw_encode(voi_data)
    
    # Step 4: Arithmetic Encoding
    compressed_bits = arithmetic_encode(lzw_symbols)
    
    return compressed_bits, bounding_coords

def decode_3d_voi_lto_a(compressed_bits, bounding_coords, original_dims):
    """
    Decodes a 3D medical image compressed with 3D-VOI-LtoA.
    compressed_bits: bit stream from encoder
    bounding_coords: coordinates of the VOI bounding box
    original_dims: tuple (D, H, W) of the original volume size
    Returns: reconstructed 3D volume
    """
    # Step 5: Arithmetic Decoding
    lzw_symbols = arithmetic_decode(compressed_bits)
    
    # Step 6: Inverse LZW
    voi_data = lzw_decode(lzw_symbols)
    
    # Step 7: Fusion with Background
    # Build empty 3D volume of original size
    reconstructed_volume = create_empty_volume(original_dims)
    
    # Fuse decompressed VOI into the empty volume using bounding_coords
    reconstructed_volume = fuse_voi(reconstructed_volume, voi_data, bounding_coords)
    
    return reconstructed_volume

def find_first_non_null_slice(volume_3d):
    """Returns the index of the first slice (along depth) containing non-zero data."""
    for i in range(volume_3d.shape[0]):
        if np.any(volume_3d[i] != 0):
            return i
    return 0

def find_last_non_null_slice(volume_3d):
    """Returns the index of the last slice (along depth) containing non-zero data."""
    for i in range(volume_3d.shape[0] - 1, -1, -1):
        if np.any(volume_3d[i] != 0):
            return i
    return volume_3d.shape[0] - 1

def compute_bounding_box(volume_3d, z_min, z_max):
    """
    Computes the 3D bounding box [x_min, x_max, y_min, y_max, z_min, z_max]
    for all non-zero voxels in the volume.
    """
    # Get coordinates of all non-zero voxels
    coords = np.argwhere(volume_3d != 0)
    
    if len(coords) == 0:
        # Handle case where volume is entirely empty/null
        return (0, 0, 0, 0, z_min, z_max)
        
    # Calculate min and max for each dimension
    x_min, y_min, z_min_actual = np.min(coords, axis=0)
    x_max, y_max, z_max_actual = np.max(coords, axis=0)
    
    # The source specifies using confined global coordinates.
    # We return the tightest bounding box around the active data.
    return (x_min, x_max, y_min, y_max, z_min_actual, z_max_actual)

**Formulas:**

*   **Compression Ratio (CR):**
    $$CR = \frac{n_1}{n_2}$$
    where $n_1$ is the number of bits in the original image and $n_2$ is the number of bits in the compressed image [S1].

*   **Bit Rate (BR) / Bits Per Voxel (BPV):**
    $$BR = \frac{C}{N}$$
    where $C$ is the compressed image bits and $N$ is the total number of voxels in the 3D volume [S1].

*   **Peak Signal to Noise Ratio (PSNR):**
    $$PSNR = 10 \times \log_{10}\left(\frac{\text{MAX}^2}{\text{MSE}}\right)$$
    where MAX is the maximum intensity pixel value [S1].

*   **Mean Squared Error (MSE):**
    $$MSE = \frac{1}{MN} \sum_{y=1}^{M} \sum_{x=1}^{N} (I_{m_{x,y}} - I'_{m_{x,y}})^2$$
    where $I_m$ is the original image and $I'_m$ is the compressed image [S1].

*   **Structural Similarity Index (SSIM):**
    $$SSIM_{x,y} = l_{x,y}^{\alpha} c_{x,y}^{\beta} s_{x,y}^{\gamma}$$
    where $l_{x,y}$, $c_{x,y}$, and $s_{x,y}$ are luminance, contrast, and structure comparison functions [S1].

*   **Luminance Comparison:**
    $$l_{x,y} = \frac{2\mu_x\mu_y + c_1}{\mu_x^2 + \mu_y^2 + c_1}$$
    where $\mu_x$ and $\mu_y$ are local means [S1].

*   **Contrast Comparison:**
    $$c_{x,y} = \frac{2\sigma_x\sigma_y + c_2}{\sigma_x^2 + \sigma_y^2 + c_2}$$
    where $\sigma_x$ and $\sigma_y$ are standard deviations [S1].

*   **Structure Comparison:**
    $$s_{x,y} = \frac{2\sigma_{xy} + c_3}{\sigma_x\sigma_y + c_3}$$
    where $\sigma_{xy}$ is the cross covariance [S1].

**Parameters:**
*   **Background Intensity:** Assumed to be zero. Medical images are considered to have a zero-intensity background which is excluded from the VOI [S1].
*   **Image Depth:** Tested images are 8-bit depth [S1].

**Edge Cases and Pitfalls:**
*   **Lossless Nature:** Since the method is lossless, MSE is zero, PSNR tends to infinity, and SSIM is 1 for all tested volumes [S1].
*   **Blank Slices:** The algorithm explicitly ignores blank/null slices at the foremost and end of the volume. If the entire volume is blank, the bounding box logic must handle empty sets gracefully [S1].
*   **Bounding Volume Transmission:** The coordinate details of the Bounding Volume must be sent alongside the bit stream. Failure to transmit these coordinates prevents correct reconstruction of the original volume size and position [S1].

## Operating characteristics
*   **Time Complexity:** Encoding and decoding times vary significantly with image size and VOI ratio. For a 128x128x27 MRI, encoding took 19.23s and decoding 3.17s. For a 256x256x99 CT, encoding took 408.01s and decoding 48.99s [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:**
    *   3D Image 1 (128x128x27 MRI): CR=3.22, BPV=2.48 [S1].
    *   3D Image 2 (256x256x99 CT): CR=2.16, BPV=3.7 [S1].
    *   3D Image 4 (256x256x63): CR=12.57, BPV=0.64 [S1].
    *   3D Image 6 (256x256x63): CR=15.61, BPV=0.51 [S1].
    *   3D Image 12 (256x256x298 PET): CR=13.66, BPV=0.59 [S1].
*   **Scaling:** Compression Ratio (CR) increases with larger amounts of null intensity background. A shorter VOI leads to higher compression performance [S1].
*   **Strengths:** Yields better compression results than standard lossless methods including Huffman Coding, Run Length Coding, LZW, and Arithmetic Coding. VOI coding increases CR by an average of 7.26 and reduces Bit Rate by an average of 1.77 bits compared to methods without VOI extraction [S1].
*   **Limitations:** The cost and complexity of object-based coding (VOI extraction and coordinate transmission) can be a constraint in terms of compression efficiency [S1].
*   **When to use:** Suitable for compressing 3D medical images (MRI, CT, PET) where lossless reconstruction is required for telemedicine or remote diagnosis, and the images have significant zero-intensity background [S1].

## Background
The 3D-VOI-LtoA method was proposed as a hybrid lossless compression technique for three-dimensional medical images. It utilizes object-based features to separate the Volume of Interest (VOI) from the background. The method combines Lempel-Ziv-Welch (LZW) coding followed by Arithmetic Coding (L to A) for the encoding phase. It was tested on 3D brain volumes from repositories such as the Cancer Imaging Archive (TCIA), Internet Brain Segmentation Repository (IBSR), and Radiopedia [S1].
