# LZV Algorithm
Also called: LZV, Lempel-Ziv-Welch, Lembel‐Ziv‐Welch Coding, Lempel–Ziv–Welch (LZW) Coding

## Overview
The LZW (Lempel-Ziv-Welch) algorithm, also referred to as LZV in some literature, is a dictionary-based lossless compression method that identifies repetitive sequences in input data by mapping them to single indices from a dynamically built dictionary [S1]. It is particularly effective for volume data and differential data, offering faster compression and decompression speeds compared to Huffman coding [S3, unofficial]. Unlike sibling methods such as [3D-VOI-LtoA](12632-3d-voi-ltoa.md) or the [Vendored Blosc+LZ4 Compression Pipeline](17429-vendored-blosc-lz4-compression-pipeline.md), LZW relies exclusively on dynamic pattern matching within a fixed-capacity dictionary rather than spatial partitioning or hybrid pipeline stages [S1].

## How it works
**Inputs and Outputs:**
- Input: A stream of symbols (e.g., image pixels or volume voxel values) [S1][S2, unofficial].
- Output: A stream of dictionary indices representing the input [S1].

**Data Structures:**
- **Dictionary:** A lookup table mapping character sequences to integer indices, dynamically updated during processing [S1]. The dictionary supports a maximum of 4096 character sequences [S1].
- **Input Buffer:** The remaining unprocessed input symbols [G].

**Algorithmic Steps:**
1. **Initialization:** Initialize the dictionary such that all input strings have a length of one [S1].
2. **Search:** Identify the longest string for the current input symbol using the dictionary [S1].
3. **Emit:** Emit the dictionary index for this string as output and remove it from the input [S1].
4. **Advance:** Move to the next symbol and repeat the process until all input symbols are processed [S1].

**Parameters:**
- **Dictionary Size:** Maximum 4096 entries [S1].

**Edge Cases and Pitfalls:**
- **Dictionary Capacity:** The dictionary is capped at 4096 entries [S1]. When full, standard implementations typically reset or flush the dictionary, though specific reset mechanics are not detailed in the provided sources [G].
- **Precision:** As a lossless method, it preserves exact data values, which is critical for medical imaging where lossy compression may cause diagnostic errors [S3, unofficial].

**Pseudocode:**
```python
def lzw_compress(input_symbols):
    # Step 1: Initialize dictionary with single-character strings
    dictionary = {}
    next_index = 0
    # Assuming 8-bit symbols (0-255)
    for i in range(256):
        dictionary[bytes([i])] = i
        next_index += 1
        
    output_indices = []
    current_string = ""
    
    for symbol in input_symbols:
        current_symbol = bytes([symbol])
        candidate = current_string + current_symbol
        
        # Step 2: Identify longest string in dictionary
        if candidate in dictionary:
            current_string = candidate
        else:
            # Step 3: Emit index for longest match and remove from input
            if current_string in dictionary:
                output_indices.append(dictionary[current_string])
            
            # Standard LZW expansion (not explicitly listed in source steps 1-4) [G]
            if next_index < 4096:
                dictionary[candidate] = next_index
                next_index += 1
            
            # Step 4: Move to next symbol
            current_string = current_symbol
    
    # Emit final match
    if current_string in dictionary:
        output_indices.append(dictionary[current_string])
        
    return output_indices
```

## Operating characteristics
- **Time Complexity:** The algorithm operates as a greedy method where the dictionary is modified in each iteration [S1]. Specific time complexity metrics are not provided in the sources [G].
- **Memory Complexity:** The dictionary size is limited to 4096 entries [S1].
- **Performance:** Dictionary-based methods like LZW offer faster compression and decompression speeds compared to Huffman coding [S3, unofficial].
- **Strengths:** Effective for volume data and differential data; lossless preservation of data integrity [S3, unofficial].
- **Limitations:** Dictionary size is capped at 4096, which may limit compression efficiency for highly diverse or large datasets [G].

## Background
The LZW algorithm, also referred to as LZV in some literature, is a dictionary-based compression technique originally developed for image compression and adapted for volume data [S1]. It is widely used in medical MRI volume data compression, where lossless preservation is often required to avoid diagnostic errors [S3, unofficial]. The method builds on the principles of LZ-based dictionary compression, leveraging dynamic dictionary construction to identify repetitive patterns [S1].
