# LZV Algorithm
Also called: Lembel‐Ziv‐Welch Coding, Lempel–Ziv–Welch (LZW) Coding

## Overview
The LZV algorithm is a dictionary-based lossless compression method that identifies repetitive sequences in input data by mapping them to single indices from a dynamically built dictionary [S1]. It is particularly effective for volume data and differential data, offering faster compression and decompression speeds compared to Huffman coding [S2, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A stream of symbols (e.g., image pixels or volume voxel values).
- Output: A stream of dictionary indices representing the input.

**Data Structures:**
- **Dictionary:** A lookup table mapping character sequences to integer indices. The dictionary supports a maximum of 4096 character sequences [S1].
- **Input Buffer:** The remaining unprocessed input symbols.

**Algorithmic Steps:**
1. **Initialization:** Initialize the dictionary such that all possible single-character input strings are present with their corresponding indices. The dictionary starts with strings of length one [S1].
2. **Search:** For the current input symbol, identify the longest string already present in the dictionary that matches the beginning of the remaining input [S1].
3. **Emit:** Output the dictionary index corresponding to this longest matching string [S1].
4. **Advance:** Remove the matched string from the input buffer and move to the next symbol [S1].
5. **Update:** Add the new sequence formed by the matched string plus the next input symbol to the dictionary, if the dictionary is not full [S1].
6. **Repeat:** Continue steps 2–5 until all input symbols are processed [S1].

**Parameters:**
- **Dictionary Size:** Maximum 4096 entries [S1].

**Edge Cases and Pitfalls:**
- **Dictionary Fullness:** When the dictionary reaches 4096 entries, no new sequences can be added. The algorithm must handle this state, typically by resetting the dictionary or using a fixed-size subset, though specific reset mechanics are not detailed in the provided sources [S1].
- **Precision:** As a lossless method, it preserves exact data values, which is critical for medical imaging where lossy compression may cause diagnostic errors [S2, unofficial].

**Pseudocode:**
```python
def lzv_compress(input_symbols):
    # Initialize dictionary with single characters
    # Assuming symbols are integers or bytes
    dictionary = {}
    next_index = 0
    
    # Standard initialization: map all possible single-byte values to indices 0-255
    # Note: The exact initialization range depends on the symbol domain.
    # For a general 8-bit symbol space:
    for i in range(256):
        dictionary[bytes([i])] = i
        next_index += 1
        
    output_indices = []
    current_string = ""
    
    for symbol in input_symbols:
        current_symbol = bytes([symbol])
        candidate = current_string + current_symbol
        
        if candidate in dictionary:
            current_string = candidate
        else:
            # Emit the index for the longest match found so far
            if current_string in dictionary:
                output_indices.append(dictionary[current_string])
            
            # Add the new sequence to the dictionary if space allows
            if next_index < 4096:
                dictionary[candidate] = next_index
                next_index += 1
            
            # Start new string with current symbol
            current_string = current_symbol
            
    # Emit the last match
    if current_string in dictionary:
        output_indices.append(dictionary[current_string])
        
    return output_indices
```

## Subtopics

### 3D-VOI-LtoA

## Operating characteristics
- **Time Complexity:** The algorithm is described as a greedy algorithm where the dictionary is modified in each iteration [S1]. Specific time complexity metrics are not provided in the sources.
- **Memory Complexity:** The dictionary size is limited to 4096 entries [S1].
- **Performance:** Dictionary-based methods like LZV offer faster compression and decompression speeds compared to Huffman coding [S2, unofficial].
- **Strengths:** Effective for volume data and differential data; lossless preservation of data integrity [S2, unofficial].
- **Limitations:** Dictionary size is capped at 4096, which may limit compression efficiency for highly diverse or large datasets without reset mechanisms [S1].

## Background
The LZV algorithm, also known as Lempel–Ziv–Welch (LZW) coding, is a dictionary-based compression technique originally developed for image compression and adapted for volume data [S1]. It is widely used in medical MRI volume data compression, where lossless preservation is often required to avoid diagnostic errors [S2, unofficial]. The method builds on the principles of LZ-based dictionary compression, leveraging dynamic dictionary construction to identify repetitive patterns [S1].
