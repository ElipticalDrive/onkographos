# Delimiter-Escaped Block Compression

Also called: Compression Pipeline (Snappy/Miniz with Delimiter Escaping)

## Overview
Delimiter-Escaped Block Compression is a text-based serialization and compression method for volumetric tree structures (specifically Sparse Voxel Octrees) that ensures robust parsing by escaping control characters within compressed binary data [S1, unofficial]. It differs from binary-only formats by using human-readable delimiters (`|`, `$`) to structure nodes, while wrapping the payload in a standard compressor (Snappy or Miniz) and escaping carriage returns and newlines to prevent delimiter corruption [S1, unofficial]. This approach prioritizes debuggability and error recovery over raw throughput, making it suitable for development pipelines where data integrity and inspection are critical [S1, unofficial].

## How it works
**Inputs:** A tree structure (e.g., Sparse Voxel Octree) containing nodes with fields such as `m_Data`, `m_ChildrenBase`, and `m_ChildrenOffset`.
**Outputs:** A compressed text file containing escaped blocks of node data.

**Data Structures:**
*   **Node:** Contains integer fields (`m_Data`, `m_ChildrenBase`) and a character array (`m_ChildrenOffset`).
*   **Block:** A serialized unit representing a set of nodes, delimited by `$SNAPPY$` or `$MINIZ$`.
*   **Field Separator:** The pipe character `|`.
*   **Node Terminator:** The dollar sign `$`.

**Parameters:**
*   **Compression Type:** `NONE`, `SNAPPY`, or `MINIZ` [S1, unofficial].
*   **Delimiters:** `|` for fields, `$` for node termination, `$SNAPPY$`/`$MINIZ$` for block boundaries [S1, unofficial].

**Steps:**

1.  **Serialization (Write):**
    1.  Format each node's fields into a string separated by `|`.
    2.  Append `$` to mark the end of the node.
    3.  Concatenate all node strings.
    4.  If compression is enabled (`SNAPPY` or `MINIZ`):
        a. Compress the concatenated string using the selected algorithm.
        b. Iterate through the compressed bytes.
        c. If a byte is `\r` (carriage return), append the literal string `[RR]`.
        d. If a byte is `\n` (newline), append the literal string `[NN]`.
        e. Append the block delimiter (`$SNAPPY$` or `$MINIZ$`) to the end of the escaped stream.
    5.  If compression is `NONE`, append the block delimiter directly to the raw string.

2.  **Deserialization (Read):**
    1.  Read the file content.
    2.  Split the content by block delimiters (`$SNAPPY$` or `$MINIZ$`) to isolate blocks.
    3.  For each block:
        a. Identify the compression type from the delimiter.
        b. If compressed, reverse the escaping: replace `[RR]` with `\r` and `[NN]` with `\n`.
        c. Decompress the escaped string using the identified algorithm.
        d. Split the resulting string by `$` to extract individual node strings.
        e. For each node string, split by `|` to extract fields.
        f. Parse fields into the Node structure.
        g. **Error Handling:** If a numeric field (e.g., `m_Data`) does not start with a digit, default it to `0` and log a warning [S1, unofficial]. If a `m_ChildrenOffset` field is a single space, set it to `(char)-1` [S1, unofficial].

**Pseudocode:**

```python
import re

def serialize_node(node):
    """Convert a node object to a delimited string."""
    # Format: Data|ChildrenBase|Offset0|Offset1|...
    parts = [str(node.m_Data), str(node.m_ChildrenBase)]
    for offset in node.m_ChildrenOffset:
        parts.append(str(offset))
    return "|".join(parts) + "$"

def escape_compressed_data(compressed_bytes):
    """Escape control characters in compressed binary data."""
    # Convert bytes to string for processing, assuming latin-1 or similar 1:1 mapping
    # In practice, this operates on the byte stream.
    result = bytearray()
    i = 0
    while i < len(compressed_bytes):
        byte = compressed_bytes[i]
        if byte == 0x0D: # \r
            result.extend(b'[RR]')
        elif byte == 0x0A: # \n
            result.extend(b'[NN]')
        else:
            result.append(byte)
        i += 1
    return result

def unescape_compressed_data(escaped_bytes):
    """Reverse the escaping of control characters."""
    # Replace literal strings back to bytes
    # Note: Order matters if escape sequences overlap, but [RR] and [NN] are distinct from \r\n
    text = escaped_bytes.decode('latin-1')
    text = text.replace('[RR]', '\r')
    text = text.replace('[NN]', '\n')
    return text.encode('latin-1')

def compress_node_block(nodes, compression_type):
    """Compress a list of nodes."""
    if compression_type == "NONE":
        raw_data = "".join([serialize_node(n) for n in nodes])
        return raw_data.encode('utf-8')
    
    raw_data = "".join([serialize_node(n) for n in nodes])
    raw_bytes = raw_data.encode('utf-8')
    
    if compression_type == "SNAPPY":
        # Placeholder for Snappy compression logic
        compressed = snappy_compress(raw_bytes) 
    elif compression_type == "MINIZ":
        # Placeholder for Miniz compression logic
        compressed = miniz_compress(raw_bytes)
    else:
        raise ValueError("Unknown compression type")
        
    escaped = escape_compressed_data(compressed)
    delimiter = "$SNAPPY$" if compression_type == "SNAPPY" else "$MINIZ$"
    return escaped + delimiter.encode('utf-8')

def parse_node_string(node_str):
    """Parse a single node string into a Node object."""
    fields = node_str.split('|')
    node = Node()
    
    # Parse m_Data
    val = fields[0]
    if not val[0].isdigit():
        node.m_Data = 0
        print("Problem loading in Node Data... Attempting to correct.")
    else:
        node.m_Data = int(val)
        
    # Parse m_ChildrenBase
    val = fields[1]
    if not val[0].isdigit():
        node.m_ChildrenBase = 0
        print("Problem loading in Node Children Base... Attempting to correct.")
    else:
        node.m_ChildrenBase = int(val)
        
    # Parse m_ChildrenOffset
    # Assuming fixed size or known count for offsets
    for i in range(2, len(fields)):
        offset_str = fields[i]
        if offset_str == " ":
            node.m_ChildrenOffset[i-2] = -1 # (char)-1
        else:
            node.m_ChildrenOffset[i-2] = offset_str[0]
            
    return node

def decompress_block(block_data):
    """Decompress a single block and return nodes."""
    # Identify compression type from delimiter
    if block_data.endswith(b'$SNAPPY$'):
        comp_type = "SNAPPY"
        delimiter_len = len(b'$SNAPPY$')
    elif block_data.endswith(b'$MINIZ$'):
        comp_type = "MINIZ"
        delimiter_len = len(b'$MINIZ$')
    else:
        comp_type = "NONE"
        delimiter_len = 0
        
    payload = block_data[:-delimiter_len]
    
    if comp_type != "NONE":
        payload = unescape_compressed_data(payload)
        if comp_type == "SNAPPY":
            raw_bytes = snappy_decompress(payload)
        elif comp_type == "MINIZ":
            raw_bytes = miniz_decompress(payload)
    else:
        raw_bytes = payload
        
    raw_text = raw_bytes.decode('utf-8')
    node_strings = raw_text.split('$')
    # Filter out empty strings resulting from trailing delimiter
    node_strings = [s for s in node_strings if s]
    
    nodes = []
    for ns in node_strings:
        nodes.append(parse_node_string(ns))
        
    return nodes
```

## Operating characteristics
*   **Time Complexity:** Decompression is linear with respect to the compressed size, plus the overhead of escaping/unescaping bytes. Parsing is linear with respect to the number of nodes.
*   **Memory Complexity:** Requires holding the entire uncompressed block in memory during parsing. The escaping process may increase the size of the compressed payload slightly (up to 3x for `\r`/`\n`), but this is bounded.
*   **Strengths:** Human-readable structure allows for easy debugging and partial recovery. Escaping ensures that binary compression artifacts do not corrupt the text-based parsing logic.
*   **Limitations:** Text-based overhead (delimiters, escape sequences) reduces compression efficiency compared to pure binary formats. Parsing is slower than binary deserialization due to string operations.
*   **When to use:** Development, debugging, or scenarios where data corruption from binary control characters is a significant risk.
*   **When not to use:** High-performance production rendering where memory bandwidth and CPU cycles are constrained, or when maximum compression ratio is required.

## Background
This method originates from the implementation details of the Sparse Voxel Octree (SVO) builder described in Giles Penfold's Master's Thesis [S1, unofficial]. It was designed to handle the serialization of octree data in a way that was robust against the specific control characters generated by Snappy and Miniz compressors, which could otherwise interfere with delimiter-based parsing in C++ string streams.
