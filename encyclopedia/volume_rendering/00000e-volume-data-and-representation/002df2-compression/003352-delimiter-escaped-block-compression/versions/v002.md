# Delimiter-Escaped Block Compression

Also called: Compression Pipeline (Snappy/Miniz with Delimiter Escaping)

## Overview
Delimiter-Escaped Block Compression is a serialization and compression method for volumetric tree structures that ensures robust parsing by escaping control characters within compressed data [S1, unofficial]. It structures nodes using human-readable delimiters (`|`, `$`) while wrapping the payload in a standard compressor (Snappy or Miniz) and escaping carriage returns and newlines to prevent delimiter corruption [S1, unofficial].

## How it works
**Inputs:** A tree structure containing nodes with fields `m_Data`, `m_ChildrenBase`, and `m_ChildrenOffset` [S1, unofficial].
**Outputs:** A compressed text file containing escaped blocks of node data [S1, unofficial].

**Data Structures:**
* **Node:** Contains integer fields `m_Data` and `m_ChildrenBase`, and an array `m_ChildrenOffset` [S1, unofficial].
* **Block:** A serialized unit representing a set of nodes, delimited by `$SNAPPY$` or `$MINIZ$` [S1, unofficial].
* **Field Separator:** The pipe character `|` [S1, unofficial].
* **Node Terminator:** The dollar sign `$` [S1, unofficial].

**Parameters:**
* **Compression Type:** `NONE`, `SNAPPY`, or `MINIZ` [S1, unofficial].
* **Delimiters:** `|` for fields, `$` for node termination, `$SNAPPY$`/`$MINIZ$` for block boundaries [S1, unofficial].

**Steps:**

1.  **Serialization (Write):**
    1.  Format each node's fields into a string separated by `|` and terminated by `$` [S1, unofficial].
    2.  Concatenate all node strings [S1, unofficial].
    3.  If compression is enabled (`SNAPPY` or `MINIZ`), compress the concatenated string [S1, unofficial].
    4.  Iterate through the compressed bytes: if `\r`, append `[RR]`; if `\n`, append `[NN]` [S1, unofficial].
    5.  Append the block delimiter (`$SNAPPY$` or `$MINIZ$`) to the end of the escaped stream [S1, unofficial].
    6.  If compression is `NONE`, append the block delimiter directly to the raw string [S1, unofficial].

2.  **Deserialization (Read):**
    1.  Split the file content by block delimiters (`$SNAPPY$` or `$MINIZ$`) to isolate blocks [S1, unofficial].
    2.  Identify the compression type from the delimiter [S1, unofficial].
    3.  If compressed, reverse the escaping: replace `[RR]` with `\r` and `[NN]` with `\n` [S1, unofficial].
    4.  Decompress the escaped string using the identified algorithm [S1, unofficial].
    5.  Split the resulting string by `$` to extract individual node strings [S1, unofficial].
    6.  For each node string, split by `|` to extract fields [S1, unofficial].
    7.  Parse fields into the Node structure, defaulting to `0` if a numeric field is non-numeric [S1, unofficial]. If a `m_ChildrenOffset` field is a single space, set it to `(char)-1` [S1, unofficial].

**Pseudocode:**

```python
class Node:
    m_Data: int
    m_ChildrenBase: int
    m_ChildrenOffset: list[int]

def serialize_node(node: Node) -> str:
    parts = [str(node.m_Data), str(node.m_ChildrenBase)]
    for offset in node.m_ChildrenOffset:
        parts.append(str(offset))
    return "|".join(parts) + "$"

def escape_compressed(compressed_bytes: bytes) -> bytes:
    result = bytearray()
    for b in compressed_bytes:
        if b == 0x0D:
            result.extend(b'[RR]')
        elif b == 0x0A:
            result.extend(b'[NN]')
        else:
            result.append(b)
    return bytes(result)

def unescape_compressed(escaped_bytes: bytes) -> bytes:
    text = escaped_bytes.decode('latin-1')
    text = text.replace('[RR]', '\r')
    text = text.replace('[NN]', '\n')
    return text.encode('latin-1')

def compress_block(nodes: list[Node], comp_type: str) -> bytes:
    raw_text = "".join(serialize_node(n) for n in nodes)
    raw_bytes = raw_text.encode('utf-8')
    if comp_type == "NONE":
        return raw_bytes
    # Compress raw_bytes using Snappy or Miniz algorithm [G]
    compressed = raw_bytes
    escaped = escape_compressed(compressed)
    delimiter = b'$SNAPPY$' if comp_type == "SNAPPY" else b'$MINIZ$'
    return escaped + delimiter

def decompress_block(block_data: bytes) -> list[Node]:
    if block_data.endswith(b'$SNAPPY$'):
        comp_type = "SNAPPY"
        delim_len = len(b'$SNAPPY$')
    elif block_data.endswith(b'$MINIZ$'):
        comp_type = "MINIZ"
        delim_len = len(b'$MINIZ$')
    else:
        comp_type = "NONE"
        delim_len = 0

    payload = block_data[:-delim_len]
    if comp_type != "NONE":
        payload = unescape_compressed(payload)
        # Decompress payload using Snappy or Miniz algorithm [G]
        raw_bytes = payload
    else:
        raw_bytes = payload

    raw_text = raw_bytes.decode('utf-8')
    node_strings = raw_text.split('$')
    node_strings = [s for s in node_strings if s]

    nodes = []
    for ns in node_strings:
        fields = ns.split('|')
        node = Node()
        node.m_ChildrenOffset = [0] * max(0, len(fields) - 2)
        val = fields[0]
        if not val or not val[0].isdigit():
            node.m_Data = 0
        else:
            node.m_Data = int(val)
        val = fields[1]
        if not val or not val[0].isdigit():
            node.m_ChildrenBase = 0
        else:
            node.m_ChildrenBase = int(val)
        for i in range(2, len(fields)):
            offset_str = fields[i]
            if offset_str == " ":
                node.m_ChildrenOffset[i-2] = -1
            else:
                node.m_ChildrenOffset[i-2] = ord(offset_str[0])
        nodes.append(node)
    return nodes
```

## Operating characteristics
* **Time Complexity:** Not given in the sources. Parsing is linear with respect to the number of nodes [G].
* **Memory Complexity:** Not given in the sources. Requires holding the entire uncompressed block in memory during parsing [G].
* **Strengths:** Human-readable structure allows for debugging; escaping ensures binary compression artifacts do not corrupt delimiter-based parsing [S1, unofficial].
* **Limitations:** Text-based overhead (delimiters, escape sequences) reduces compression efficiency compared to pure binary formats [G].
* **When to use:** Scenarios where data corruption from binary control characters is a significant risk [S1, unofficial].
* **When not to use:** High-performance production rendering where memory bandwidth and CPU cycles are constrained, or when maximum compression ratio is required [G].

## Background
This method originates from the implementation details of the Sparse Voxel Octree (SVO) builder described in Giles Penfold's Master's Thesis [S1, unofficial]. It was designed to handle the serialization of octree data in a way that was robust against the specific control characters generated by Snappy and Miniz compressors, which could otherwise interfere with delimiter-based parsing in C++ string streams [S1, unofficial].
