# VQ-HEVC Hybrid Compression for SH-AC

Also called: Two-Stage VQ with HEVC

## Overview
This method replaces the direct HEVC coding of Spherical Harmonics (SH) coefficient (SH-AC) attribute maps in the Video-based GSC Anchor pipeline with a Vector Quantization (VQ)-based representation, targeting the low spatial correlation of SH-AC data [S1]. It preserves the anchor procedure for all other attributes (position, scale, rotation, opacity, SH-DC), isolating the effect of the SH-AC representation change [S1]. Unlike standalone methods that prune Gaussians or modify multiple attributes, this approach integrates VQ indices into the existing video coding framework by packing them into 2D index maps compressed via HEVC lossless mode [S1].

## How it works
**Inputs:** A trained 3D Gaussian Splatting (3DGS) model with $N$ Gaussians, each having 45 SH-AC coefficients (assuming degree 3).
**Outputs:** Compressed bitstream containing HEVC-coded index maps and metadata (codebooks, grouping info, normalization parameters).

### Data Structures
1.  **Codebooks:**
    *   **Stage 1 Codebook ($C_1$):** Size $K_1 \times 45$. Stores 45-dimensional centroid vectors.
    *   **Stage 2 Codebooks ($C_{2,g}$):** For each group $g \in \{1, \dots, G\}$, a codebook of size $K_2 \times D_g$. $D_g$ is the number of dimensions in group $g$.
2.  **Index Maps:**
    *   **Coarse Index Map ($I_1$):** 2D array of shape $(H, W)$, storing 10-bit integers (indices into $C_1$).
    *   **Residual Index Maps ($I_{2,g}$):** $G$ separate 2D arrays of shape $(H, W)$, storing indices into respective $C_{2,g}$.
3.  **Metadata:**
    *   Min/Max values for each of the 45 SH-AC dimensions (original and residual).
    *   Grouping permutation vector (mapping original dimension $d$ to group $g$ and local index $k$).
    *   Codebook entries for $C_1$ and all $C_{2,g}$.

### Algorithm Steps

1.  **PLAS Reordering:** Apply PLAS-based reordering to the 3DGS model to spatially correlate attributes, as defined in the parent [Video-based GSC Anchor (TMCV)](19527-video-based-gsc-anchor-tmcv.md) [S1].
2.  **Normalization:** Normalize the 45 SH-AC coefficient dimensions independently across all $N$ Gaussians.
    *   For dimension $d \in \{1, \dots, 45\}$, find min $x_d^{min}$ and max $x_d^{max}$.
    *   Compute normalized coefficient $\tilde{x}_{i,d}$ for Gaussian $i$:
        $$ \tilde{x}_{i,d} = \frac{x_{i,d} - x_d^{min}}{\max(x_d^{max} - x_d^{min}, \epsilon)} $$
        where $\epsilon = 10^{-8}$ [S1].
3.  **Stage 1 VQ (Coarse Quantization):**
    *   Train a codebook $C_1$ of size $K_1=1024$ on the full 45-dimensional normalized vectors $\tilde{\mathbf{x}}_i$ using MiniBatch K-means [S1].
    *   For each Gaussian $i$, find the nearest codeword $\mathbf{c}_{1,i} \in C_1$.
    *   Store the index $idx_{1,i}$ and compute the residual vector $\mathbf{r}_i = \tilde{\mathbf{x}}_i - \mathbf{c}_{1,i}$ [S1].
4.  **Residual Processing and Grouping:**
    *   For each dimension $d$, collect residuals across all Gaussians: $\mathbf{r}_d = [r_{1,d}, r_{2,d}, \dots, r_{N,d}]^T$ [S1].
    *   Normalize each dimension-wise residual vector independently:
        $$ \bar{r}_{i,d} = \frac{r_{i,d} - r_d^{min}}{\max(r_d^{max} - r_d^{min}, \epsilon)} $$
        where $r_d^{min}, r_d^{max}$ are min/max of $\mathbf{r}_d$ [S1].
    *   Define normalized residual-dimension vector $\bar{\mathbf{r}}_d = [\bar{r}_{1,d}, \dots, \bar{r}_{N,d}]^T$ [S1].
    *   Compute pairwise Euclidean distance between dimensions $d$ and $j$:
        $$ \delta(d,j) = ||\bar{\mathbf{r}}_d - \bar{\mathbf{r}}_j||_2 $$
        [S1].
    *   Perform KNN-based greedy grouping: Select an unassigned dimension as reference, greedily add nearest unassigned dimensions until the group size $D_g = 45/G$ is reached. Repeat until all 45 dimensions are assigned to $G$ non-overlapping groups [S1].
5.  **Stage 2 VQ (Residual Quantization):**
    *   For each group $g$, extract the sub-vectors of residuals corresponding to the dimensions in group $g$.
    *   Train a codebook $C_{2,g}$ of size $K_2=1024$ on these sub-vectors using MiniBatch K-means [S1].
    *   Perform Product Quantization (PQ): For each Gaussian $i$, find the nearest codeword $\mathbf{c}_{2,i,g} \in C_{2,g}$ for each group $g$.
    *   Store indices $idx_{2,i,g}$ [S1].
6.  **Zero-Masked Residual VQ:**
    *   Identify residual vectors with small magnitudes (e.g., below a threshold or simply those that are effectively zero after coarse quantization).
    *   Explicitly map these small residual vectors to the zero index in the respective codebooks to increase sparsity in the index maps [S1].
7.  **Index Map Packing:**
    *   Pack $idx_{1,i}$ into a 2D map $I_1$ (YUV400 format, 10-bit depth) [S1].
    *   Pack $idx_{2,i,g}$ for each group $g$ into separate 2D maps $I_{2,g}$ (YUV400 format) [S1].
    *   Total frames: $G + 1$ [S1].
8.  **HEVC Encoding:**
    *   Compress the sequence of $G+1$ index maps using HEVC in **lossless mode** [S1].
    *   Transmit codebooks and metadata as side information [S1].
9.  **Decoding (Reconstruction):**
    *   Decode HEVC bitstream to retrieve indices $idx_{1,i}$ and $idx_{2,i,g}$ [S1].
    *   Retrieve coarse codeword $\mathbf{c}_{1,i}$ from $C_1$ [S1].
    *   Retrieve residual codewords $\mathbf{c}_{2,i,g}$ from $C_{2,g}$ [S1].
    *   Reorder residual codewords according to the grouping metadata [S1].
    *   Sum coarse and residual codewords: $\tilde{\mathbf{x}}_i^{rec} = \mathbf{c}_{1,i} + \sum_g \mathbf{c}_{2,i,g}$ [S1].
    *   Inverse-normalize using stored min/max values to obtain final SH-AC coefficients [S1].

### Pseudocode

```python
import numpy as np
from sklearn.cluster import MiniBatchKMeans

def vq_hevc_shac_compress(gaussians, N, G=9, K1=1024, K2=1024, epsilon=1e-8):
    """
    Compress SH-AC coefficients using Two-Stage VQ with HEVC.
    
    Args:
        gaussians: List of N Gaussians, each with 45 SH-AC coefficients.
        N: Number of Gaussians.
        G: Number of residual groups.
        K1: Size of Stage 1 codebook.
        K2: Size of Stage 2 codebooks.
        epsilon: Numerical stability constant.
        
    Returns:
        metadata: Dict containing codebooks, grouping, min/max values.
        index_maps: List of 2D numpy arrays (coarse + G residual maps).
    """
    # 1. Extract and Normalize SH-AC
    # Shape: (N, 45)
    sh_ac = np.array([g.sh_ac for g in gaussians])
    
    # Min/Max for normalization
    sh_min = np.min(sh_ac, axis=0)
    sh_max = np.max(sh_ac, axis=0)
    
    # Normalize
    sh_norm = (sh_ac - sh_min) / np.maximum(sh_max - sh_min, epsilon)
    
    # 2. Stage 1 VQ
    # Train codebook on full 45-dim vectors
    kmeans1 = MiniBatchKMeans(n_clusters=K1, random_state=42)
    kmeans1.fit(sh_norm)
    c1 = kmeans1.cluster_centers_
    
    # Get indices and residuals
    idx1 = kmeans1.predict(sh_norm)
    # Reconstruct coarse vectors
    c1_recon = c1[idx1]
    residuals = sh_norm - c1_recon  # Shape: (N, 45)
    
    # 3. Residual Grouping
    # Normalize residuals per dimension
    res_min = np.min(residuals, axis=0)
    res_max = np.max(residuals, axis=0)
    res_norm = (residuals - res_min) / np.maximum(res_max - res_min, epsilon)
    
    # Compute pairwise Euclidean distance between dimensions
    # res_norm shape: (N, 45). We need distance between columns.
    # Distance matrix D[d, j] = ||res_norm[:, d] - res_norm[:, j]||_2
    D = np.zeros((45, 45))
    for d in range(45):
        for j in range(45):
            D[d, j] = np.linalg.norm(res_norm[:, d] - res_norm[:, j])
            
    # KNN-based greedy grouping
    groups = []
    unassigned = set(range(45))
    dim_per_group = 45 // G
    
    while unassigned:
        # Pick first unassigned as reference
        ref = min(unassigned)
        group = [ref]
        unassigned.remove(ref)
        
        # Greedily add nearest unassigned
        while len(group) < dim_per_group and unassigned:
            # Find unassigned dimension with min distance to any in current group
            best_dim = None
            best_dist = float('inf')
            for u in unassigned:
                # Distance to group: min distance to any member in group
                dist_to_group = min(D[u, g] for g in group)
                if dist_to_group < best_dist:
                    best_dist = dist_to_group
                    best_dim = u
            
            group.append(best_dim)
            unassigned.remove(best_dim)
            
        groups.append(group)
        
    # 4. Stage 2 VQ (PQ)
    idx2_maps = []
    c2_list = []
    
    for g_idx, group_dims in enumerate(groups):
        # Extract sub-vectors for this group
        # Shape: (N, len(group_dims))
        sub_vectors = residuals[:, group_dims]
        
        # Train codebook
        kmeans2 = MiniBatchKMeans(n_clusters=K2, random_state=42)
        kmeans2.fit(sub_vectors)
        c2 = kmeans2.cluster_centers_
        c2_list.append(c2)
        
        # Quantize
        idx2 = kmeans2.predict(sub_vectors)
        
        # Zero-masking: Map small residuals to index 0
        # Heuristic: if residual norm is very small, force index 0
        # Note: The source mentions "explicitly map small residual vectors to the zero index"
        # Implementation detail: Check magnitude of original residual sub-vector
        sub_residuals_norm = np.linalg.norm(sub_vectors, axis=1)
        # Threshold could be derived from data distribution or fixed. 
        # For implementation, we assume a threshold or simply rely on the fact that 
        # if the residual is negligible, the index might naturally be close to a centroid,
        # but explicit masking is required. Let's assume a simple threshold based on 
        # the normalized residual magnitude or just map index 0 if it's the "zero" codeword.
        # The source says "explicitly map... to increase sparsity". 
        # We will assume index 0 is used for zero-masked values.
        # A robust way: if the residual vector is close to zero vector, set index to 0.
        # However, PQ codebooks are centered. Let's assume the codebook includes a 
        # "zero" centroid or we force index 0 for small residuals.
        # Given the source doesn't specify the threshold, we note it as a parameter.
        # For the sake of the algorithm, we assume index 0 is the target for masking.
        
        # Simple masking: if residual norm < threshold, set index to 0
        # Threshold not given, so we leave it as a comment or assume a small value.
        # [G] Assuming a threshold of 1e-6 on the L2 norm of the residual sub-vector.
        threshold = 1e-6
        small_residuals = sub_residuals_norm < threshold
        idx2[small_residuals] = 0
        
        idx2_maps.append(idx2)
        
    # 5. Pack Index Maps
    # Reshape (N,) to 2D grid (H, W) based on PLAS ordering
    # Assuming H, W are known from the PLAS reordering step in the parent method.
    # [G] H and W are derived from the number of Gaussians N and the spatial layout.
    # For this article, we assume a function `reshape_to_2d` exists from the parent context.
    H, W = get_grid_dimensions(N)
    
    coarse_map = idx1.reshape(H, W)
    residual_maps = [idx.reshape(H, W) for idx in idx2_maps]
    
    index_maps = [coarse_map] + residual_maps
    
    # 6. Metadata
    metadata = {
        'c1': c1,
        'c2': c2_list,
        'groups': groups,
        'sh_min': sh_min,
        'sh_max': sh_max,
        'res_min': res_min,
        'res_max': res_max,
        'epsilon': epsilon
    }
    
    return metadata, index_maps

def vq_hevc_shac_decode(metadata, index_maps):
    """
    Reconstruct SH-AC coefficients from decoded index maps.
    """
    c1 = metadata['c1']
    c2_list = metadata['c2']
    groups = metadata['groups']
    sh_min = metadata['sh_min']
    sh_max = metadata['sh_max']
    res_min = metadata['res_min']
    res_max = metadata['res_max']
    epsilon = metadata['epsilon']
    
    coarse_map = index_maps[0]
    residual_maps = index_maps[1:]
    
    # Flatten maps to 1D
    idx1 = coarse_map.flatten()
    idx2_list = [idx.flatten() for idx in residual_maps]
    
    N = len(idx1)
    sh_ac_recon = np.zeros((N, 45))
    
    # Stage 1 Reconstruction
    c1_recon = c1[idx1]
    sh_ac_recon += c1_recon
    
    # Stage 2 Reconstruction
    for g_idx, group_dims in enumerate(groups):
        idx2 = idx2_list[g_idx]
        c2 = c2_list[g_idx]
        c2_recon = c2[idx2]
        
        # Add to corresponding dimensions
        sh_ac_recon[:, group_dims] += c2_recon
        
    # Inverse Normalization
    sh_ac_final = sh_ac_recon * np.maximum(sh_max - sh_min, epsilon) + sh_min
    
    return sh_ac_final
```

## Subtopics

### HEVC-Based Encoding of VQ Indices
This variant specifies the exact encoding parameters for the index maps. It uses HEVC lossless mode to ensure exact preservation of indices, as any change in an index selects a different codeword [S1]. The index frames are arranged as a YUV400 video sequence (single-channel scalar values) [S1]. The layout consists of 1 frame for coarse 10-bit indices and $G$ frames for residual indices (one per sub-vector group), totaling $G+1$ frames [S1].

## Operating characteristics
*   **Time Complexity:** Dominated by the MiniBatch K-means training for Stage 1 ($O(N \cdot 45 \cdot K_1 \cdot T_1)$) and Stage 2 ($O(N \cdot \sum D_g \cdot K_2 \cdot T_2)$), where $T$ is the number of iterations. The KNN grouping is $O(45^2 \cdot N)$ for distance calculation and $O(45^2)$ for grouping. HEVC encoding is $O(H \cdot W \cdot \text{complexity})$.
*   **Memory Complexity:** Requires storing $N \times 45$ coefficients, codebooks ($K_1 \times 45 + G \times K_2 \times D_g$), and index maps ($N$ integers).
*   **Strengths:** Isolates the SH-AC compression problem, allowing the use of efficient VQ for low-spatial-correlation data while leveraging HEVC for the rest. Zero-masking increases sparsity, improving HEVC lossless coding efficiency [S1].
*   **Limitations:** Requires lossless HEVC for indices, which may have higher bitrate than entropy-coded indices if sparsity is not high enough. Two-stage VQ adds computational overhead during training and decoding [S1].
*   **When to use:** When the GSC anchor pipeline is already in use and SH-AC coefficients are the bottleneck. When high fidelity is required (lossless indices) and computational resources allow for VQ training.

## Background
This method was proposed to address the inefficiency of directly HEVC-coding SH-AC coefficients in the video-based MPEG GSC anchor [S1]. It builds on the observation that SH-AC vectors have low spatial correlation, making them poor candidates for standard video coding without transformation [S1]. The method integrates Residual Vector Quantization (RVQ) and Product Quantization (PQ) into the GSC anchor framework [S1]. It was evaluated under the GSC Common Test Conditions (CTC) on datasets like Bartender and Cinema [S1].
