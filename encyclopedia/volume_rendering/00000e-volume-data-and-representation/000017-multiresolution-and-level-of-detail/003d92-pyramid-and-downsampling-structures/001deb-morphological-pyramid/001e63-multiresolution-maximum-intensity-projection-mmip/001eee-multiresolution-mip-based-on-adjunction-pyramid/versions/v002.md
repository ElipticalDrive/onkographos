# Multiresolution MIP based on adjunction pyramid
Also called: Progressive refinement from adjunction pyramid

## Overview
This method performs progressive Maximum Intensity Projection (MIP) volume rendering by refining the image directly in the 2D plane using an adjunction pyramid, avoiding 3D volume reconstruction [S1]. It leverages the commutativity of MIP and dilation to update the projection by taking the maximum of the expanded detail projection and the previous approximation [S1]. Unlike general detail pyramids that require 3D reconstruction, this variant exploits the specific properties of adjunction pyramids where detail signals are non-negative, allowing for simpler, purely 2D progressive refinement [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** An adjunction detail pyramid sequence $d_0, d_1, \dots, d_{L-1}$ and the coarsest approximation $f_L$ of the input volume data $f$. The parameter $\Theta$ defines the viewing coordinate system orientation [S1].
*   **Output:** A sequence of progressively refined approximation images $M_\Theta^{(j)}(f)$ for $j=L, \dots, 0$ [S1].

**Data Structures:**
*   **Pyramid Levels:** The pyramid has depth $L$. Each level $j$ corresponds to detail data $d_{j-1}$ (for $j=1 \dots L$) and the coarsest approximation $f_L$ [S1].
*   **Operators:**
    *   $\psi_A$: The 3D analysis operator (REDUCE) of the adjunction pyramid.
    *   $\tilde{\psi}_A$: The 2D synthesis operator (EXPAND) applied in the image plane. Specifically, $\tilde{\psi}_A^{k}$ denotes $k$-fold composition of $\tilde{\psi}_A$ with itself [S1].
    *   $\vee$: The pointwise maximum operator, defined as $(g_0 \vee g_1)(x) = \max(g_0(x), g_1(x))$ [S1].

**Algorithm Steps:**
1.  **Initialize:** Choose the viewing orientation $\Theta$. Compute the coarsest approximation image by applying the 2D synthesis operator $\tilde{\psi}_A$ $L$ times to the MIP of the coarsest volume approximation $f_L$:
    $$ M_\Theta^{(L)}(f) = \tilde{\psi}_A^L (M_\Theta(f_L)) $$
    [S1]

2.  **Progressive Refinement:** Loop from $j = L$ down to $1$:
    a.  Compute the MIP of the detail signal at level $j-1$: $P = M_\Theta(d_{j-1})$.
    b.  Expand this projection $j-1$ times using the 2D synthesis operator: $E = \tilde{\psi}_A^{j-1}(P)$.
    c.  Update the current approximation by taking the maximum of the expanded detail projection and the previous approximation:
        $$ M_\Theta^{(j-1)}(f) = E \vee M_\Theta^{(j)}(f) $$
        [S1]

**Pseudocode:**
```python
def multiresolution_mip_adjunction(detail_pyramid, coarsest_approx, L, theta):
    """
    detail_pyramid: list of 3D volumes [d_0, d_1, ..., d_{L-1}]
    coarsest_approx: 3D volume f_L
    L: integer, decomposition depth
    theta: viewing orientation parameter
    """
    # Standard operations (defined for self-containment):
    # compute_mip(volume): projects 3D volume along theta to 2D by taking max along rays
    # morphological_expand(image): applies 2D dilation (synthesis operator) to image
    # pointwise_max(a, b): returns element-wise maximum of arrays a and b
    
    # Step 1: Coarsest approximation
    current_mip = compute_mip(coarsest_approx)
    for _ in range(L):
        current_mip = morphological_expand(current_mip)
        
    # Step 2: Progressive refinement
    for j in range(L, 0, -1):
        detail_proj = compute_mip(detail_pyramid[j-1])
        expanded_detail = detail_proj
        for _ in range(j-1):
            expanded_detail = morphological_expand(expanded_detail)
        current_mip = pointwise_max(current_mip, expanded_detail)
        
    return current_mip
```

**Parameters:**
*   $L$: Decomposition depth [S1].
*   $\Theta$: Viewing orientation. Determines the projection direction [S1].

**Pitfalls:**
*   **Monotonicity:** Because detail signals $d_{j-1}$ in an adjunction pyramid are non-negative, the projections $M_\Theta^{(j-1)}(f)$ are guaranteed to be greater than or equal to $M_\Theta^{(j)}(f)$. The image intensity increases pointwise as one goes down the pyramid (from coarse to fine) [S1].

## Subtopics

### Multiresolution MIP based on approximation pyramid
A variant that uses an approximation pyramid instead of a detail pyramid. It avoids 3D reconstruction by applying MIP directly to approximation data at each level, which is suitable when 3D dilation is inefficient on compressed data [S1].
*   **Difference:** Uses approximation data $f_0 \dots f_L$ rather than detail data. The synthesis operator must be a dilation [S1].
*   **Algorithm:** Loop $j$ from $L$ down to $0$. Compute $M_\Theta^{(j)}(f) = \tilde{\psi}_A^j (M_\Theta(f_j))$ [S1].
*   **Memory:** Requires storing all approximation data $f_0 \dots f_L$, which uses memory storage of the same order of magnitude as storing detail and coarsest approximation data [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Direct 2D refinement avoids expensive 3D reconstruction steps required by general detail pyramids [S1].
*   **Limitations:** Relies on the specific properties of adjunction pyramids (non-negative details) [S1].

## Background
This method was introduced in the context of comparing different morphological pyramid structures for volume rendering [S1]. The approach builds on the commutativity of MIP and dilation, allowing the projection to be refined in the image plane [S1]. It is similar to wavelet splatting but replaces linear summation with maximum computation and linear wavelet filters with morphological filters [S1].
