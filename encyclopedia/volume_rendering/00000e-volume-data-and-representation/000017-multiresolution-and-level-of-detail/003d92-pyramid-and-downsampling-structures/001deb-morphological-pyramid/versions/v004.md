# Morphological Pyramid

Also called: Adjunction Pyramid, Erosion/Dilation Pyramid, Morphological Adjunction Pyramid, Morphological Pyramid Construction, Pyramid Synthesis for MIP

## Overview
The Morphological Pyramid is a multiresolution representation for Maximum Intensity Projection (MIP) volume rendering that uses morphological erosion and dilation combined with dyadic downsampling and upsampling to create a hierarchy of approximations and detail signals [S1, S2]. Unlike linear pyramid-based MIP methods which rely on additive reconstruction, the Morphological Pyramid exploits the commutativity of the MIP operator with morphological dilation, allowing the projection to be performed on coarse levels and expanded in 2-D, thereby avoiding expensive 3-D reconstruction for certain pyramid types [S1, S2].

## How it works
**Inputs and Outputs:**
*   **Input:** A signal $f_0$ defined on a discrete grid $Z^d$ ($d=2$ or $3$) taking non-negative integer values, and a structuring element $A \subset Z^d$ [S1, S2].
*   **Output:** An approximation pyramid $\{f_0, f_1, \dots, f_L\}$ and a detail pyramid $\{d_0, d_1, \dots, d_{L-1}, f_L\}$ where $f_j$ has increasingly reduced size [S1].

**Data Structures:**
*   **Approximation Pyramid:** A sequence of arrays where level $j$ stores the reduced approximation $f_j$ [S1].
*   **Detail Pyramid:** A sequence of arrays where level $j$ stores the detail signal $d_j$, with the coarsest approximation $f_L$ stored as the final component [S1].
*   **Structuring Element $A$:** A subset of $Z^d$ defining the local neighborhood for morphological operations [S2].

**Morphological Operators:**
The core operations replace each signal value by the maximum or minimum in a neighborhood defined by $A$ [S1, S2]:
1.  **Dilation** $\delta_A(f)(x) = \max_{y \in A, x-y \in F} f(x-y)$ [S1, S2].
2.  **Erosion** $\epsilon_A(f)(x) = \min_{y \in A, x+y \in F} f(x+y)$ [S1, S2].

**Pyramid Construction Steps:**
1.  **Define Reduction and Expansion:** The analysis operator REDUCE applies erosion followed by dyadic downsampling: $\psi_A^\uparrow(f) = \text{DOWNSAMPLE}(\epsilon_A(f))$ [S2]. The synthesis operator EXPAND applies dyadic upsampling followed by dilation: $\psi_A^\downarrow(f) = \delta_A(\text{UPSAMPLE}(f))$ [S2].
2.  **Verify Pyramid Condition:** The structuring element $A$ must satisfy the condition that there exists an $a \in A$ such that the translates of $a$ over an even number of grid steps are never contained in $A$ [S1, S2]. This condition guarantees perfect reconstruction [S2].
3.  **Compute Approximations:** For $j = 1$ to $L$, compute $f_j = \text{REDUCE}(f_{j-1}) = \psi_A^\uparrow(f_{j-1})$ [S1, S2].
4.  **Compute Detail Signals:** For $j = 0$ to $L-1$, compute $d_j = f_j \dot{-} \text{EXPAND}(f_{j+1}) = f_j \dot{-} \psi_A^\downarrow(f_{j+1})$ [S2].
5.  **Generalized Subtraction:** The operator $\dot{-}$ is defined as $t \dot{-} s = t$ if $t > s$, else $0$, where $0$ is the smallest possible voxel value [S1, S2]. This ensures all detail signals are nonnegative [S2].
6.  **Reconstruction:** The original volume is recovered using the maximum operation (generalized addition $\dot{+} = \max$): $f_0 = \psi_A^\downarrow L(f_L) \vee \bigvee_{k=0}^{L-1} \psi_A^\downarrow k(d_k)$, where $\vee$ denotes the pointwise maximum [S1].

**Pseudocode for Pyramid Construction:**

```python
def morphological_pyramid(volume, A, levels):
    """
    Constructs a Morphological (Adjunction) Pyramid.
    Args:
        volume: 3D list/array f_0.
        A: List of coordinate offsets defining the structuring element.
        levels: Number of decomposition levels L.
    Returns:
        approximations: List [f_0, f_1, ..., f_L]
        details: List [d_0, d_1, ..., d_{L-1}, f_L]
    """
    approximations = [volume]
    current = volume
    
    # Step 3: Compute Approximations
    for _ in range(levels):
        eroded = _erosion(current, A)
        approx = _downsample(eroded)
        approximations.append(approx)
        current = approx
        
    # Step 4: Compute Details
    details = []
    details.append(approximations[-1]) # f_L
    
    for j in range(levels - 1, -1, -1):
        f_j = approximations[j]
        f_j1 = approximations[j + 1]
        upscaled = _upsample(f_j1)
        expanded = _dilation(upscaled, A)
        detail = _generalized_subtraction(f_j, expanded)
        details.append(detail)
        
    # Reverse to get [d_0, ..., d_{L-1}, f_L]
    details.reverse()
    return approximations, details

def _get_value(grid, x, y, z):
    """Returns grid value, clamping to 0 at boundaries [G]."""
    if 0 <= x < len(grid) and 0 <= y < len(grid[0]) and 0 <= z < len(grid[0][0]):
        return grid[x][y][z]
    return 0

def _erosion(grid, A):
    """Computes erosion: min over neighborhood A [S1, S2]."""
    h, w, d = len(grid), len(grid[0]), len(grid[0][0])
    result = [[[0 for _ in range(d)] for _ in range(w)] for _ in range(h)]
    for x in range(h):
        for y in range(w):
            for z in range(d):
                min_val = float('inf')
                for dx, dy, dz in A:
                    val = _get_value(grid, x + dx, y + dy, z + dz)
                    if val < min_val:
                        min_val = val
                result[x][y][z] = min_val
    return result

def _dilation(grid, A):
    """Computes dilation: max over neighborhood A [S1, S2]."""
    h, w, d = len(grid), len(grid[0]), len(grid[0][0])
    result = [[[0 for _ in range(d)] for _ in range(w)] for _ in range(h)]
    for x in range(h):
        for y in range(w):
            for z in range(d):
                max_val = -float('inf')
                for dx, dy, dz in A:
                    val = _get_value(grid, x - dx, y - dy, z - dz)
                    if val > max_val:
                        max_val = val
                result[x][y][z] = max_val
    return result

def _downsample(grid):
    """Keeps every 2nd voxel in each dimension [S2]."""
    return [grid[x][::2][::2] for x in range(0, len(grid), 2)]

def _upsample(grid):
    """Inserts zeros between voxels [S2]."""
    h, w, d = len(grid), len(grid[0]), len(grid[0][0])
    new_h, new_w, new_d = 2 * h, 2 * w, 2 * d
    upscaled = [[[0 for _ in range(new_d)] for _ in range(new_w)] for _ in range(new_h)]
    for x in range(h):
        for y in range(w):
            for z in range(d):
                upscaled[2 * x][2 * y][2 * z] = grid[x][y][z]
    return upscaled

def _generalized_subtraction(t, s):
    """t dot-minus s: t if t > s, else 0 [S1, S2]."""
    h, w, d = len(t), len(t[0]), len(t[0][0])
    result = [[[0 for _ in range(d)] for _ in range(w)] for _ in range(h)]
    for x in range(h):
        for y in range(w):
            for z in range(d):
                result[x][y][z] = t[x][y][z] if t[x][y][z] > s[x][y][z] else 0
    return result
```

**Edge Cases and Pitfalls:**
*   **Pyramid Condition Violation:** If the structuring element $A$ does not satisfy the even-grid-step translate condition, perfect reconstruction fails [S1, S2].
*   **Detail Signal Size:** If too few small features are present in the data, they may be retained in higher pyramid levels, causing detail signals to be "too large" and reducing approximation accuracy [S1].
*   **Boundary Conditions:** Erosion and dilation require careful handling at volume boundaries, typically resolved by padding the volume or clamping coordinates [G].

## Subtopics

### [Multiresolution Maximum Intensity Projection (MMIP)](1745-multiresolution-maximum-intensity-projection-mmip.md)
Multiresolution Maximum Intensity Projection (MMIP) is a progressive rendering algorithm that uses the Morphological Pyramid to compute MIPs interactively. It computes coarse MIPs from the approximation pyramid and progressively refines them with detail coefficients. Unlike linear MIP methods, MMIP exploits the commutativity of the MIP operator with morphological dilation. This allows the projection to be performed on coarse 2-D slices and expanded, avoiding expensive 3-D reconstruction. The refinement step from level $j$ to $j-1$ involves computing the MIP of the detail signal $d_{j-1}$, applying the 2-D synthesis operator $\psi_{\tilde{A}}^\downarrow$ (where $\tilde{A}$ is the MIP of $A$), and taking the maximum with the previous approximation.

### Sun-Maragos Pyramid
The Sun-Maragos Pyramid is an alternative morphological pyramid scheme for MIP rendering [S1]. It differs from the standard Adjunction Pyramid by using a morphological opening for the analysis (REDUCE) operator instead of erosion, while the synthesis (EXPAND) operator remains a dilation [S1]. The opening is defined as $\alpha_A(f) = \delta_A(\epsilon_A(f))$ [S1]. This variant improves approximation accuracy when rendering from higher levels of the pyramid, addressing the issue where standard adjunction pyramids retain too few small features, leading to "too large" detail signals [S1].

*   **Limitations:** Requires careful selection of the structuring element to satisfy the pyramid condition, and may lose small features if $A$ is too large [S1, S2].

## Background
The Morphological Pyramid was introduced in the context of multiresolution algorithms for Maximum Intensity Projection (MIP) volume rendering [S1]. It is based on morphological adjunction pyramids, which allow progressive refinement and perfect reconstruction [S1]. The specific publication years and author attributions are not given in the sources. It is applied to medical imaging modalities such as magnetic resonance angiography (MRA) and ultrasound data due to the computational simplicity of MIP [S1].
