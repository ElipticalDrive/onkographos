# Morphological Pyramid

Also called: Adjunction Pyramid, Erosion/Dilation Pyramid, Morphological Adjunction Pyramid, Morphological Pyramid Construction, Pyramid Synthesis for MIP

## Overview
The Morphological Pyramid is a multiresolution representation for Maximum Intensity Projection (MIP) volume rendering that uses morphological erosion and dilation combined with dyadic downsampling/upsampling to create a hierarchy of approximations and detail signals [S1, S2]. It solves the problem of interactive rendering latency by allowing coarse approximations to be computed rapidly, with progressive refinement using detail coefficients [S1]. Unlike linear pyramid-based MIP methods which rely on additive reconstruction, the Morphological Pyramid exploits the commutativity of the MIP operator with morphological dilation, allowing the projection to be performed on coarse levels and expanded in 2-D, thereby avoiding expensive 3-D reconstruction for certain pyramid types [S1, S2].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D volume dataset $f_0$ defined on a discrete grid $Z^d$ ($d=3$ for volumes, $d=2$ for images), taking non-negative integer values. A structuring element $A \subset Z^d$.
*   **Output:** An approximation pyramid $\{f_0, f_1, \dots, f_L\}$ and a detail pyramid $\{d_0, d_1, \dots, d_{L-1}, f_L\}$, where $f_j$ has size reduced by a factor of $2^j$ in each dimension compared to $f_0$.

**Data Structures:**
*   **Approximation Pyramid:** A list of arrays. Level $j$ contains the reduced approximation $f_j$.
*   **Detail Pyramid:** A list of arrays. Level $j$ contains the detail signal $d_j$. The coarsest level $f_L$ is stored as the final detail component.
*   **Structuring Element $A$:** A subset of $Z^d$ defining the local neighborhood. For "flat" pyramids, $A$ is typically a small cube or cross centered at the origin.

**Morphological Operators:**
The core operations are dilation and erosion [S1, S2]:
1.  **Dilation** $\delta_A(f)$: Replaces each signal value by the maximum in the neighborhood defined by $A$.
    $$ \delta_A(f)(x) = \max_{y \in A, x-y \in F} f(x-y) $$
2.  **Erosion** $\epsilon_A(f)$: Replaces each signal value by the minimum in the neighborhood defined by $A$.
    $$ \epsilon_A(f)(x) = \min_{y \in A, x+y \in F} f(x+y) $$

**Pyramid Construction Steps:**
1.  **Define Reduction and Expansion:**
    *   **REDUCE** (Analysis): $\psi_A^\uparrow(f) = \text{DOWNSAMPLE}(\epsilon_A(f))$. This applies erosion followed by dyadic downsampling (factor of 2 in each dimension).
    *   **EXPAND** (Synthesis): $\psi_A^\downarrow(f) = \delta_A(\text{UPSAMPLE}(f))$. This applies dyadic upsampling followed by dilation.
2.  **Verify Pyramid Condition:** The structuring element $A$ must satisfy the condition that there exists an $a \in A$ such that the translates of $a$ over an even number of grid steps are never contained in $A$. This ensures perfect reconstruction [S1, S2].
3.  **Compute Approximations:** For $j = 1$ to $L$:
    $$ f_j = \text{REDUCE}(f_{j-1}) = \psi_A^\uparrow(f_{j-1}) $$
4.  **Compute Detail Signals:** For $j = 0$ to $L-1$:
    Use generalized subtraction to compute the detail signal $d_j$:
    $$ d_j = f_j \dot{-} \text{EXPAND}(f_{j+1}) = f_j \dot{-} \psi_A^\downarrow(f_{j+1}) $$
    The generalized subtraction operator $\dot{-}$ is defined as:
    $$ t \dot{-} s = \begin{cases} t, & \text{if } t > s \\ 0, & \text{if } t = s \end{cases} $$
    where $0$ is the smallest possible voxel value. This ensures $d_j \geq 0$ [S1, S2].

**Reconstruction:**
The original volume $f_0$ can be perfectly reconstructed using the maximum operation (generalized addition $\dot{+} = \max$):
$$ f_0 = \psi_A^\downarrow L(f_L) \vee \bigvee_{k=0}^{L-1} \psi_A^\downarrow k(d_k) $$
where $\vee$ denotes the pointwise maximum [S1].

**Pseudocode for Pyramid Construction:**

```python
def morphological_pyramid_construction(volume, structuring_element_A, levels):
    """
    Constructs a Morphological (Adjunction) Pyramid.
    
    Args:
        volume: 3D array f_0.
        structuring_element_A: Set of coordinates defining the structuring element.
        levels: Number of decomposition levels L.
        
    Returns:
        approximations: List [f_0, f_1, ..., f_L]
        details: List [d_0, d_1, ..., d_{L-1}, f_L]
    """
    approximations = [volume]
    current_level = volume
    
    # Step 1: Compute Approximations
    for j in range(1, levels + 1):
        # Erosion
        eroded = morphological_erosion(current_level, structuring_element_A)
        # Dyadic Downsampling (keep every 2nd voxel in each dimension)
        approx = dyadic_downsample(eroded)
        approximations.append(approx)
        current_level = approx
        
    # Step 2: Compute Details
    details = []
    # The coarsest approximation f_L is stored as the last detail component
    details.append(approximations[-1])
    
    for j in range(levels - 1, -1, -1):
        f_j = approximations[j]
        f_j_plus_1 = approximations[j + 1]
        
        # EXPAND: Upsample then Dilate
        upscaled = dyadic_upsample(f_j_plus_1)
        expanded = morphological_dilation(upscaled, structuring_element_A)
        
        # Generalized Subtraction
        detail_signal = generalized_subtraction(f_j, expanded)
        details.append(detail_signal)
        
    # Reverse details to match index order d_0, ..., d_{L-1}, f_L
    # Note: The loop appended f_L, then d_{L-1}, ..., d_0.
    # So details is [f_L, d_{L-1}, ..., d_0]. We need [d_0, ..., d_{L-1}, f_L].
    details.reverse()
    
    return approximations, details

def morphological_erosion(volume, A):
    """Computes erosion: min over neighborhood A."""
    # Implementation detail: For each voxel x, find min(volume[x+y] for y in A)
    # Boundary handling: Assume 0 or clamp. Since values are non-negative, 
    # treating out-of-bounds as infinity for min is standard, 
    # but typically volumes are padded or A is small enough.
    # [G] Assuming volume is padded with infinity or A is strictly within bounds.
    result = np.zeros_like(volume)
    for x in indices(volume):
        min_val = infinity
        for y in A:
            neighbor = volume[x + y] # Handle boundary check
            if neighbor < min_val:
                min_val = neighbor
        result[x] = min_val
    return result

def morphological_dilation(volume, A):
    """Computes dilation: max over neighborhood A."""
    result = np.zeros_like(volume)
    for x in indices(volume):
        max_val = -infinity
        for y in A:
            neighbor = volume[x - y] # Handle boundary check
            if neighbor > max_val:
                max_val = neighbor
        result[x] = max_val
    return result

def dyadic_downsample(volume):
    """Keeps every 2nd voxel in each dimension."""
    return volume[::2, ::2, ::2]

def dyadic_upsample(volume):
    """Inserts zeros between voxels."""
    new_shape = tuple(2 * s for s in volume.shape)
    upscaled = np.zeros(new_shape, dtype=volume.dtype)
    upscaled[::2, ::2, ::2] = volume
    return upscaled

def generalized_subtraction(t, s):
    """t dot-minus s: t if t > s, else 0."""
    # 0 is the smallest possible value (e.g., 0 for unsigned int)
    return np.where(t > s, t, 0)
```

**Edge Cases and Pitfalls:**
*   **Pyramid Condition Violation:** If the structuring element $A$ does not satisfy the condition (translates of $a \in A$ over even grid steps are never contained in $A$), perfect reconstruction fails [S1, S2].
*   **Detail Signal Size:** If too few small features are present in the data, they may be retained in higher pyramid levels, causing detail signals to be "too large" and reducing compression efficiency or approximation accuracy [S1].
*   **Boundary Conditions:** Erosion and dilation require careful handling at volume boundaries. Standard practice is to pad the volume or restrict the structuring element to valid regions [G].

## Subtopics

### [Multiresolution Maximum Intensity Projection (MMIP)](1745-multiresolution-maximum-intensity-projection-mmip.md)
Multiresolution Maximum Intensity Projection (MMIP) is a progressive rendering algorithm that uses the Morphological Pyramid to compute MIPs interactively. It solves the problem of interactive rendering latency by computing coarse MIPs from the approximation pyramid and progressively refining them with detail coefficients. Unlike linear MIP methods, MMIP exploits the commutativity of the MIP operator with morphological dilation. This allows the projection to be performed on coarse 2-D slices and expanded, avoiding expensive 3-D reconstruction. The refinement step from level $j$ to $j-1$ involves computing the MIP of the detail signal $d_{j-1}$, applying the 2-D synthesis operator $\psi_{\tilde{A}}^\downarrow$ (where $\tilde{A}$ is the MIP of $A$), and taking the maximum with the previous approximation.

### Sun-Maragos Pyramid
The Sun-Maragos Pyramid is an alternative morphological pyramid scheme for MIP rendering [S1]. It differs from the standard Adjunction Pyramid by using a morphological **opening** for the analysis (REDUCE) operator instead of erosion, while the synthesis (EXPAND) operator remains a dilation [S1]. The opening is defined as $\alpha_A(f) = \delta_A(\epsilon_A(f))$ [S1]. This variant improves approximation accuracy when rendering from higher levels of the pyramid, addressing the issue where standard adjunction pyramids retain too few small features, leading to "too large" detail signals [S1].

## Operating characteristics
*   **Time Complexity:** Pyramid construction is $O(N)$ where $N$ is the number of voxels, as each level involves constant-time morphological operations per voxel. Rendering MIP using MMIP is also efficient, as it operates on 2-D slices and uses max operations, which are fast on GPUs [S1, S2].
*   **Memory Complexity:** Requires storing the approximation pyramid and detail pyramid, totaling approximately $N + N/2 + \dots + N/2^L + N + N/2 + \dots + N/2^{L-1} \approx 2N$ voxels, plus overhead for the structuring element [S1, S2].
*   **Performance:** Measured performance shows significant speedup for interactive MIP rendering compared to direct ray-casting, especially for large datasets [S1, S2].
*   **Strengths:** Perfect reconstruction, progressive refinement, efficient 2-D projection, suitability for GPU acceleration.
*   **Limitations:** Requires careful selection of the structuring element to satisfy the pyramid condition; may lose small features if $A$ is too large; non-linear nature makes it less intuitive than linear wavelets for some applications.
*   **When to use:** Interactive MIP visualization of large volumetric datasets (e.g., MRA, ultrasound) where latency is critical.
*   **When not to use:** When linear superposition is required, or when the data contains features smaller than the structuring element that must be preserved exactly in coarse levels.

## Background
The Morphological Pyramid was introduced in the context of multiresolution algorithms for Maximum Intensity Projection (MIP) volume rendering [S1]. It is based on morphological adjunction pyramids, which allow progressive refinement and perfect reconstruction [S1]. The concept was developed by researchers including Roerdink and colleagues, with key papers published in the early 2000s (e.g., [S1] 2002, [S2] 2007) [S1, S2]. It is widely used in medical imaging, particularly for magnetic resonance angiography (MRA) and ultrasound data, due to the computational simplicity and effectiveness of MIP [S1].
